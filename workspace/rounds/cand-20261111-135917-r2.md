# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；本轮灵感：「可解释性」×「检索增强生成」）

> 第 54 轮已把技能组合提升为「动作剖面 + 鲁棒性谱」的双证书，并建立云边协同闭环。但证书越攒越多却难以复用；解释越写越像「事后叙事」，缺少证据支撑。本轮聚焦 **证据记忆化、有效性感知检索、解释的归因忠实性**。核心矛盾：H22：证书体系碎片化且不可检索，跨任务无法复用，所有认证每次从零推导，解释沦为不可证伪的叙事；H23：RAG 的「语义相似」不等于「因果/域内有效」，检索到过期或跨域证书会产生 **检索污染**，把规划引向错误先验、让解释引用无效证据。

## 0. 直觉与动机

**灵感 1（证据记忆 → 把证书从一次性产物变成可检索先验）**
直觉：前 54 轮产出的 `J`、`C_comp`、`Explain`、反例、仿真日志，本质是一个巨大的 **经验证据库 `E`**。它应该像人类研究者的「实验记录 + 文献库」：新任务先检索相似历史（同技能对、动作交集相近、`ρ` 维度相同、云边映射版本一致），用其作为先验，而不是每次从公理重推。检索不是「查文本」，而是 **结构化索引 + 语义嵌入的混合证据检索**。

**灵感 2（检索只给先验，不给证明 → proposal 与 proof 分离）**
直觉：LLM/RAG 擅长「提出候选」，不擅长「保证正确」。因此把系统拆成两半：**生成器**（检索增强的规划/解释 proposer）与**证明器**（证书检查器）。检索到的证书只能初始化搜索、缩小候选空间、给出 `δ_a/compat` 的先验；最终部署前必须用当前 `α_S`、`γ_ce`、`K` **独立再验证**。一句话：**检索是加速器，不是神谕**。

**灵感 3（可解释性 = 归因，不是叙事 → 接地解释证书 GEX）**
直觉：真正的可解释性不是「生成一段像样的理由」，而是「每个结论都能指到支撑它的证据」。我们把解释写成 **`GEX = (claim, S, ⊢, minimal, fresh, γ_prov)`**：`S ⊆ E` 是最小支撑集，`⊢` 是可检查的蕴含关系，`γ_prov` 是可追溯的引用。找不到支撑就把 claim 降级为 **hypothesis** 并显式标注不确定性，绝不假装确定。这样「幻觉」可被度量：**attribution soundness rate**。

**灵感 4（反事实检索 → 对照式解释）**
直觉：人理解「为什么可行」往往靠「为什么另一个更接近的却不行」。检索最近的失败证据 `e⁻` 与当前计划证据 `e⁺` 做对照，把差异定位到具体动作维/鲁棒性维：`Δ = diff(ctx(e⁻), ctx(e⁺))`，得到 **contrastive explanation**。它比单条正向解释更可操作，也直接服务于云边回传的修复。

**灵感 5（证据闭环 → 解释暴露缺口，缺口驱动采集）**
直觉：当 `GEX` 无法凑齐支撑集，缺口本身就是最有价值的信号：它指出「缺哪类证据」。于是形成 **检索 → 认证 → 解释 → 补证（仿真/主动采样）→ 证据库更新** 的闭环。证据库不是静态文档，而是随解释缺口有方向地生长。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（证据项与证据库）**
证据项 `e = (id, type, ctx, payload, prov, t, conf)`：
- `type ∈ {cert, counterexample, sim_log, explanation}`；
- `ctx = (S_i, S_j, A_scope, 𝔇_ρ, γ_ce_version, sim_version)` 为证据适用的上下文；
- `payload` 为证书 `J`/`C_comp` 或反例轨迹；
- `prov` 为不可篡改来源（仿真种子、规划日志哈希、第 54 轮证书编号）；
- `t` 为时间戳，`conf` 为置信度。
证据库 `E = {e}`。

**定义 122（有效性感知混合检索）**
查询 `q = (task, α_S, γ_ce, 𝔇_ρ)`。检索打分
```
score(e|q) = λ_s·sim_dense(q,e) + λ_k·sim_struct(ctx_e, ctx_q)
           - λ_t·stale(e,t) - λ_d·dist_domain(ctx_e, ctx_q)
```
返回 `R(q,E,k) = TopK(score)`。**迁移有效性** `valid(e,q)=1` 当且仅当
```
dist_domain(ctx_e, ctx_q) ≤ τ_r  ∧  fresh(e,t)  ∧  ¬contradicts(e, E_q)
```
只有 `valid` 的证据可进入证明链；其余仅可作为「检索提示」展示给人类，不得用于认证或解释的支撑集。

**定义 123（接地解释证书 GEX）**
`GEX = (claim, S, ⊢, minimal, fresh, γ_prov)`，其中 `S ⊆ E` 且每项 `valid`。**归因可靠**（attribution sound）当且仅当
```
(1) S ⊢ claim                 （蕴含可被检查器验证）
(2) ∀ e∈S: S\{e} ⊬ claim      （最小性）
(3) γ_prov 给出每项证据到 payload 的可追溯引用
```
不满足 (1) 的 claim 标记为 `hypothesis`，禁止以确定语气输出。

**定义 124（检索增强先验与强制再验证）**
检索先验 `π_R(compat, ρ, δ_a | q) = aggregate{payload(e) : e∈R(q,E,k), valid(e,q)}`。检索增强认证算子
```
ReVal: (π_R, α_S, γ_ce, K) → J'      （必须用当前上下文独立重算）
```
认证接受条件：`J'` 通过第 54 轮 AEC/JTC 检查，且 `ReVal` **不引用检索证据作为证明前提**。检索仅影响搜索顺序、剪枝与候选生成。

**定义 125（反事实证据对与对照解释）**
反事实证据对 `(e⁻, e⁺)`：`e⁻` 为最近的有效失败证据，`e⁺` 为当前计划证据，二者在 `ctx` 上的最小差异 `Δ = diff(ctx(e⁻), ctx(e⁺))`。对照解释
```
CX(claim) = (Δ, claim⁺, claim⁻, support⁺ = S⁺, support⁻ = S⁻)
```
解释可操作性 `I_CX = |Δ| / (1 + H(e⁻,e⁺))`，其中 `H` 为对齐后的上下文距离；`|Δ|` 越大、`H` 越小越可操作。

**定义 126（证据图、解释缺口与闭环收敛）**
证据图 `EG = (E, E_sup ∪ E_con)`，边为 `support` / `contradict`。解释缺口
```
Gap(claim) = min_{S⊆E} { |S| : S ⊢ claim }   （无解则为 ∞）
```
补证动作 `a_acq` 选择最大化期望信息增益 `IG(a_acq) = H(claim) - E[H(claim | evidence(a_acq))]` 的仿真/采样。闭环收敛条件：连续 `m` 轮 `Gap` 不降且证据增长超过预算即停止，避免无限补证。

### IP-121 REM（Retrieval Evidence Memory）

```python
def build_evidence_memory(certs, counterexamples, logs):
    E = []
    for c in certs:
        E.append(Evidence(type='cert', ctx=context_of(c),
                          payload=c, prov=hash_of(c), t=c.timestamp))
    for x in counterexamples:

                          payload=x.trace, prov=hash_of(x)))
    for l in logs:
        E.append(Evidence(type='sim_log', ctx=context_of(l),
                          payload=l, prov=hash_of(l)))
    return HybridIndex(E, dense=embed, struct=index_by_action_rho)
```

### IP-122 RGC（Retrieval-Grounded Certification）

```python
def validity_gate(e, q, E_q):
    return (dist_domain(e.ctx, q.ctx) <= tau_r
            and fresh(e, q.now)
            and not contradicts(e, E_q))

def retrieval_augmented_certify(task, E, alpha_S, gamma_ce, K, k=8):
    q = Query(task, alpha_S, gamma_ce)
    retrieved = E.hybrid_search(q, k)
    valid = [e for e in retrieved if validity_gate(e, q, E)]
    prior = aggregate_prior(valid)                      # 仅作先验
    candidates = search_with_prior(task, alpha_S, prior)  # 加速搜索
    for plan in candidates:
        cert = independently_revalidate(plan, alpha_S, gamma_ce, K)  # 定义 124
        if cert.ok:                                     # 不看检索结论
            return ('ok', cert, provenance=valid)
    return ('reject', gap_report(retrieved, valid))
```

### IP-123 GEX（Grounded EXplanation）

```python
def grounded_explanation(claim, E, max_support=6):
    pool = [e for e in E if validity_gate(e, claim.query, E)]
    S = minimal_support(claim, pool, entailment_checker)   # 贪心 + 反例剔除
    if S is None:
        return ('hypothesis', claim, uncertainty=estimate(claim))
    if not is_minimal(S, claim, entailment_checker):
        S = minimize(S, claim, entailment_checker)
    return GEX(claim=claim, support=S, entailment='checked',
               minimal=True, provenance=[e.prov for e in S])
```

### IP-124 CXR（Counterfactual eXplanation Retrieval）

```python
def counterfactual_explain(claim_plus, E, k_fail=5):
    fails = [e for e in E.hybrid_search(claim_plus.query, k_fail)
             if e.type == 'counterexample'
             and validity_gate(e, claim_plus.query, E)]
    if not fails:
        return ('no_counterfactual', claim_plus)
    e_minus = min(fails, key=lambda e: diff_cost(e.ctx, claim_plus.ctx))
    delta = diff(e_minus.ctx, claim_plus.ctx)            # 最小差异
    return CX(delta, claim_plus, e_minus.claim,
              support_plus=claim_plus.support, support_minus=e_minus.support)
```

### IP-125 ECL（Evidence Closed Loop）

```python
def evidence_closed_loop(claim, E, budget):
    while budget > 0:
        rep = grounded_explanation(claim, E)
        if rep.type == 'gex':
            return rep
        gap = diagnose_gap(claim, E)                     # 缺哪类证据
        action = argmax_gain(gap, candidate_acquisitions)  # 定义 126
        new_ev = run_simulation_or_sampling(action)      # 主动补证
        E.add(new_ev); budget -= cost(action)
    return ('budget_exhausted', rep)
```

### IP-126 ECG（Evidence Conflict Graph）

```python
def evidence_conflict_graph(E):
    G = nx.DiGraph()
    for e in E:
        G.add_node(e.id)
    for e1, e2 in candidate_pairs(E):        # 同 ctx / 技能对 / 维度
        r = relation(e1, e2)                 # support / contradict / none
        if r != 'none':
            G.add_edge(e1.id, e2.id, kind=r, strength=conf(r))
    return G

def resolve_conflicts(G, policy='fresh_valid_stronger'):
    # 冲突边：优先保留更新、更新鲜、来源更强的一条进入证明候选
    return prune_contradicted(G, policy=policy)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| REM | O(N) 构建 / O(log N) 查询 | O(N·d) | 上下文索引完备、来源可追溯 |
| RGC | O(k·d + search) | O(N·d) | validity gate sound、再验证独立 |
| GEX | 最坏 O(2^{\|S\|}) / 贪心 O(\|S\|·\|E\|·c⊢) | O(\|E\|) | 蕴含检查 sound、最小性可证 |
| CXR | O(k·d + k·c_diff) | O(k) | 反事实在域内、差异最小 |
| ECL | O(轮数·(GEX+仿真)) | O(\|E\|) | 缺口诊断准、信息增益单调 |
| ECG | O(\|E\|²) 候选对 / 稀疏索引可降 | O(\|E\|+\|E_con\|) | 矛盾检测 sound、消解可追溯 |

**正确性定理 1（Retrieval Never Weakens Certification）**
假设 **(A29)** validity gate 对域内/新鲜/无矛盾的判定 sound；**(A30)** 蕴含检查器对证据片段 sound；**(A31)** `ReVal` 用当前 `α_S, γ_ce, K` 独立重算证书且不把检索证据当证明前提。则 RGC 接受计划的部署可靠性与第 54 轮相同：
```
P(success) ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a) - P(compat<θ_a)
```
检索只可能影响 **完备性 / 搜索成本**，不影响 **可靠性**：`Retrieval ⊆ acceleration`。

**正确性定理 2（Grounded Explanation Attribution Soundness）**
在 (A29)(A30) 且 `validity_gate` 无误判下，任何被接受的 `GEX` 满足：`claim` 被最小有效支撑集 `S` 蕴含，故
```
P(unsupported_claim_accepted) ≤ ε_ent + ε_val
```
其中 `ε_ent` / `ε_val` 分别为蕴含检查器与有效性门控的错误率。**可解释性被转化为可测量的归因可靠度，而非主观「像不像解释」。**

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 检索污染：相似 ≠ 有效 | 高 | validity gate + 域距离阈值 + 矛盾检测 |
| 过期证书被复用 | 高 | freshness + 版本化 ctx + 强制再验证 |
| 检索先验导致确认偏误 | 中 | 独立再验证 + 反事实检索 + 红队负例 |
| 最小支撑集组合爆炸 | 中 | 贪心 + 剪枝 + 支撑集上限 |
| 解释缺口无法收敛 | 中 | 预算上限 + 单调性监控 + 人工降级 |
| 证据来源不可追溯 | 高 | provenance 哈希 + 不可变日志 |

## 6. 本轮最大风险

**一句话**：把 RAG 引入证书体系能把「一次性证明」升级为「可复用证据 + 可归因解释」，但其可靠性系于 **检索有效性门控、蕴含检查的 sound、以及再验证的独立性**；一旦「语义相似」被误当成「域内有效」，过期/跨域证据就会污染先验并让解释引用错误支撑，形成 **自信却虚假的接地解释**，故必须以 **validity gate + 强制独立再验证 + 反事实负例** 三重护栏，坚持「检索只加速、证明必重算」，宁可少检索，绝不把检索到的东西当作已证明。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-EviRAG（REM×RGC×GEX×CXR×ECL×ECG）

> 承接第 54 轮产物 v31。本轮在「动作-鲁棒性双证书」之上，增加 **证据记忆、有效性感知检索、接地解释、反事实解释、证据闭环、证据冲突图** 六大算子：
> - **REM（Retrieval Evidence Memory）**：把 `J`、`C_comp`、反例、仿真日志组织为可检索证据库 `E`；
> - **RGC（Retrieval-Grounded Certification）**：检索先验 + 强制独立再验证，保证「检索只加速、证明必重算」；
> - **GEX（Grounded EXplanation）**：带最小支撑集与 provenance 的解释证书，把解释变成可验证归因；
> - **CXR（Counterfactual eXplanation Retrieval）**：最近失败证据对照，产出可操作的对照解释；
> - **ECL（Evidence Closed Loop）**：解释缺口驱动定向补证，证据库有方向地生长；
> - **ECG（Evidence Conflict Graph）**：support/contradict 证据图与冲突消解，防止矛盾证据进入证明链。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-118/120/117 以纳入证据来源与解释归因。

def grounded_explanation(claim, E, max_support=6):
    pool = [e for e in E if validity_gate(e, claim.query, E, TAU_R)]
    S = minimal_support(claim, pool, entailment_checker)
    if S is None or len(S) > max_support:
        return ('hypothesis', claim, uncertainty=estimate(claim),
                missing=diagnose_gap(claim, E))
    if not is_minimal(S, claim, entailment_checker):
        S = minimize(S, claim, entailment_checker)
    return GEX(claim=claim, support=S, entailment='checked',
               minimal=True, fresh=all(fresh(e, NOW) for e in S),
               provenance=[e.prov for e in S])

def minimize(S, claim, checker):
    for e in list(S):
        if checker.entails(set(S) - {e}, claim):
            S = set(S) - {e}
    return S
```

def counterfactual_explain(claim_plus, E, k_fail=5):
    fails = [e for e in E.hybrid_search(claim_plus.query, k_fail)
             if e.type == 'counterexample'
             and validity_gate(e, claim_plus.query, E, TAU_R)]
    if not fails:
        return ('no_counterfactual', claim_plus)
    e_minus = min(fails, key=lambda e: diff_cost(e.ctx, claim_plus.ctx))
    delta = diff(e_minus.ctx, claim_plus.ctx)
    return CX(delta=delta, claim_plus=claim_plus,
              claim_minus=e_minus.claim,
              support_plus=claim_plus.support,
              support_minus=e_minus.support,
              actionability=|delta| / (1 + H(e_minus, claim_plus)))
```

### IP-125 ECL

```python
def evidence_closed_loop(claim, E, budget, patience=3):
    history = []
    while budget > 0:
        rep = grounded_explanation(claim, E)
        if rep.type == 'gex':
            return rep
        gap = diagnose_gap(claim, E)
        history.append(gap.size)
        if len(history) > patience and min(history[-patience:]) >= history[-1]:
            return ('no_progress', rep)                  # 防止无限补证
        action = argmax_gain(gap, candidate_acquisitions)
        new_ev = run_simulation_or_sampling(action)
        E.add(new_ev)
        budget -= cost(action)
    return ('budget_exhausted', rep)
```

def evidence_conflict_graph(E):
    G = nx.DiGraph()
    for e in E:
        G.add_node(e.id, ctx=e.ctx, t=e.t, conf=e.conf)
    for e1, e2 in candidate_pairs(E):
        r = relation(e1, e2)          # support / contradict / none
        if r != 'none':
            G.add_edge(e1.id, e2.id, kind=r, strength=conf(r))
    return G

def resolve_conflicts(G, policy='fresh_valid_stronger'):
    keep = []
    for comp in nx.weakly_connected_components(G):
        contradicted = [n for n in comp
                        if any(G[n][m]['kind'] == 'contradict'
                               for m in G.successors(n))]
        keep.append(select_by(contradicted, policy))     # 新/鲜/强优先
    return keep

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| REM | O(N) 构建 / O(log N) 查询 | O(N·d) | 上下文索引完备、prov 可追溯 |
| RGC | O(k·d + search) | O(N·d) | validity gate sound、ReVal 独立 |
| GEX | 最坏 O(2^{\|S\|}) / 贪心 O(\|S\|·\|E\|·c⊢) | O(\|E\|) | 蕴含 sound、最小性可证 |
| CXR | O(k·d + k·c_diff) | O(k) | 反事实在域内、差异最小 |
| ECL | O(轮数·(GEX+仿真)) | O(\|E\|) | 缺口诊断准、信息增益单调 |
| ECG | O(\|E\|²) 候选对 / 稀疏索引可降 | O(\|E\|+\|E_con\|) | 矛盾检测 sound、消解可追溯 |

**正确性定理 1（Retrieval Never Weakens Certification）**
假设第 54 轮 (A26)-(A28) 成立；**(A29)** `validity_gate` 对域内/新鲜/无矛盾的判定 sound；**(A30)** 蕴含检查器对证据片段 sound；**(A31)** `ReVal` 用当前 `α_S, γ_ce, K` 独立重算且不引用检索证据作证明前提。则 RGC 接受计划的部署可靠性不低于第 54 轮：
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a) - P(compat<θ_a)
```
检索只影响 **完备性/搜索成本**，不影响 **可靠性**：`Retrieval ⊆ acceleration`。

**正确性定理 2（Grounded Explanation Attribution Soundness）**
在 (A29)(A30) 下，任何被接受的 `GEX` 均满足「`claim` 被最小有效支撑集 `S` 蕴含」，故
```
P(unsupported_claim_accepted) ≤ ε_ent + ε_val
```
其中 `ε_ent`、`ε_val` 为蕴含检查器与有效性门控的错误率。可解释性由此从「主观叙事」转为 **可测量归因可靠度**。

## 6. 本轮最大风险

**一句话**：把 RAG 引入证书体系能把「一次性证明」升级为「可复用证据 + 可归因解释」，但其可靠性系于 **检索有效性门控、蕴含检查的 sound、以及再验证的独立性**；一旦「语义相似」被误当成「域内有效」，过期/跨域证据就会污染先验并让解释引用错误支撑，形成 **自信却虚假的接地解释**，故必须以 **validity gate + 强制独立再验证 + 反事实负例** 三重护栏，坚持「检索只加速、证明必重算」，宁可少检索，绝不把检索到的东西当作已证明。
