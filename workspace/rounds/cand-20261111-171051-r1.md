# 第 56 轮（承接第 55 轮 v32 GroundSem-GenSim+++；灵感循环第 2 轮；本轮灵感：「SLAM」×「地形适应」）

> 第 55 轮把「语义标签」升级为「接触可供性」，并用全身生存核与语义护盾保证接触可行。本轮再向下追问一层：**承载这些接触的地图几何，在 SLAM 回环与漂移下是否仍然可信？** 核心矛盾：**H24**：SLAM 的地图修正是回溯性、非局部的形变场，而地形适应的落脚/步态决策是前瞻性、局部且不可逆的——地图“事后变准”救不了已经压上错误支撑的脚；**H25**：地形适应同时消费两种不等价表示——拓扑图（能否走通）与度量地形（脚能否落稳），拓扑假边（感知别名）与度量漂移是两种独立失效模式，单个不确定性标量无法同时覆盖。

## 0. 直觉与动机

**灵感 1（SLAM → 地图是形变场，而非静态几何）**
直觉：位姿图优化解出的不只是一串坐标，而是对整张地图施加的一次非刚性变形 `D_LC`；回环闭合尤其会“远处拉直、近处错位”。地形适应若直接使用当前帧拼接出的地形高度，就等于默认 `D_LC=0`。正确姿势是把地形当作 **带形变分布的随机场**，只使用“在形变上界内仍满足落脚约束”的区域，而不是信任某一时刻的拼接结果。

**灵感 2（地形适应 → 落脚 = 位姿不确定性在支撑多边形上的投影）**
直觉：同一个斜坡，正面爬和横切走，成功率先差很多——因为位姿协方差是各向异性的：沿行进方向漂移大、横向被约束强。因此落脚可行性应把位姿协方差椭球与地形漂移球一起投影到足端支撑多边形，而不是只看坡度与摩擦的点估计。地形适应的“敢不敢踩”本质是一次 **不确定性投影**。

**灵感 3（拓扑 × 度量 → 双层地形证书，合取而非乘积）**
直觉：能不能“走通”和能不能“落稳”是两类问题。假回环会把两个不同地点合并，凭空造出一条拓扑边；局部漂移会让“平地”变成“暗坑”。用单一标量加权平均，会让一侧的崩塌被另一侧的高分掩盖，所以必须 **拓扑可通行 ∧ 度量可通行**，且二者不可互相补偿。

**灵感 4（回环是假设 → 承诺视界）**
直觉：回环检测本质是假设检验：假阳性会全局拉扯地图，假阴性会让人过度自信。地形适应的不可逆动作（步态切换、重心转移、落脚锁定）应被限制在 **承诺视界** `τ_c` 内：只对“预期回环风险足够低”的近场地形做承诺，视界之外只保持或探测。这把“地图有多准”翻译成“我敢往前走多久”。

**灵感 5（主动地形探测 → 认知型地形适应）**
直觉：与其被动信任一张会变的地图，不如在关键不确定块上主动探一脚、侧扫一次，用接触结果同时更新 SLAM 与地形置信。地形适应因此不只是“执行”，而是 **用最小安全代价换取最大信息增益** 的主动感知——探测动作本身就是地图维护的一部分。

## 1. 形式化定义（增量：定义 127–133）

**定义 127（SLAM-地形信念）**
位姿图 `G=(V,E)`，节点 `ξ={x_i}`，边约束 `z_ij` 与信息矩阵 `Ω_ij`。地形场 `T: ℝ³→(h, slope, rough, μ)`。信念
`M = (G, T, Σ_ξ)`，其中 `Σ_ξ` 为位姿后验协方差（回环前的可观测子空间），`T` 每格携带测量方差 `σ_T²`。

**定义 128（回环形变场与地形漂移上界）**
候选回环集合 `L`，每个 `ℓ∈L` 有内容校验分 `s_ℓ` 与相对位姿 `z_ℓ`。被接受回环诱导地形点 `p` 的位移 `D_ℓ(p)=J_p Δξ_ℓ`。定义漂移上界
`r_d(p)=sup_{ℓ∈L, s_ℓ≥θ_LC} ||D_ℓ(p)||`，保守地形 `T⁺(p)=T(p)⊕B(r_d(p))`（坡度/粗糙度取上界、摩擦取下界）。

**定义 129（位姿条件化落脚可行性）**
给定落脚点 `p`、足端支撑多边形 `P_f`、步态 `g`：
`F(p,g|M)=1 ⇔ ∀δ∈Σ_x^{1/2}B₂: slope(T⁺(p+δ))≤slope_max(g) ∧ μ(T⁺(p+δ))≥μ_min(g) ∧ clear(p+δ,P_f)≥θ_cl`。
即把位姿协方差椭球与地形漂移球同时投影到落脚判定，取代点估计阈值。

**定义 130（双层地形可通行性）**
度量可通行 `V_m(e,g|M) = inf_{p∈e} P(F(p,g|M)=1)`；拓扑可通行
`V_t(e|M)=1 ⇔ e 在拓扑图中存在 ∧ place_conf(e)≥θ_pl ∧ 无未决回环跨越 e`。
边可通行 `⇔ V_m(e,g|M)≥θ_m ∧ V_t(e|M)≥θ_t`，**合取**：一侧为 0 不能被另一侧补偿。

**定义 131（承诺视界）**
`τ_c(x)=max{ h | P(∃未检出回环 ℓ，在 h 步内使某已承诺点位移 > β_commit | 历史) ≤ ε_c }`。
地形适应只允许在 `τ_c` 内做不可逆承诺（步态切换、重心转移、落脚锁定）；超出视界进入“保持/探测”模式。

**定义 132（SLAM-地形联合证书）**
`J_ST=(G_core, T_core, τ_c, r_d, V_m⁻, V_t⁻, ρ_map, evidence)`：核心子图与地形块、承诺视界、漂移上界、双层可通行下界、地图鲁棒性谱、回环反例证据。
可部署条件：`τ_c≥τ_min ∧ r_d≤β_commit ∧ V_m⁻≥θ_m ∧ V_t⁻≥θ_t ∧ ρ_map≥ρ_min`。

**定义 133（认知地形探测）**
探测动作 `a_p`（踏点/探足/侧扫）的信息增益 `IG(a_p)=H(T(c))-E_{o}[H(T(c)|o)]`；在安全约束 `x_{t+1}∈𝒳_safe`、时间预算 `Δt` 下最大化 `IG(a_p)/Δt`，并以接触结果回写 `M` 的地形格后验与回环校验分。

## 2. 关键算法 伪代码

### IP-127 PGD（Pose-Graph Deformation bound）

```python
def deformation_bound(pg, loops, theta_lc):
    r = {}
    for p in pg.terrain_cells:
        worst = 0.0
        for l in loops:
            if l.score < theta_lc:            # 内容校验未过，不进入承诺
                continue
            d = pg.jacobian(p) @ pg.delta_xi(l)   # D_l(p) = J_p Δξ_l
            worst = max(worst, norm(d))
        r[p] = worst
    return r
```

### IP-128 DTI（Deformation-aware Terrain Inflation）

```python
def inflate_terrain(T, r_d, Sigma_x):
    T_plus = {}
    for p, cell in T.items():
        B = ball(r_d[p]) + ellipsoid(Sigma_x)
        cells = sample_bounding(T, p, B)
        T_plus[p] = TerrainInterval(
            h=(min(c.h for c in cells), max(c.h for c in cells)),
            slope=max(c.slope for c in cells),
            rough=max(c.rough for c in cells),
            mu=min(c.mu for c in cells),
        )
    return T_plus
```

### IP-129 THG（Trust Horizon Gate）

```python
def trust_horizon(state, loop_posterior, beta_commit, eps_c, horizon_max):
    tau = 0
    for h in range(1, horizon_max + 1):
        risk = p_undetected_loop_exceeds(state, loop_posterior, h, beta_commit)
        if risk > eps_c:
            break
        tau = h
    return tau

def gate(action, tau, committed_so_far):
    if action.irreversible and committed_so_far + action.horizon > tau:
        return ('hold_or_probe', action)
    return ('commit', action)
```

### IP-130 TAC（Topological-Anchored Certification）

```python
def two_level_traversability(edge, gait, M, T_plus, theta_m, theta_t):
    V_m = min(feasible(p, gait, M, T_plus) for p in densify(edge))
    V_t = (edge in M.topo and place_conf(edge) >= theta_pl
           and not pending_loop_crosses(edge))
    if V_m < theta_m or not V_t:
        return ('reject', {'V_m': V_m, 'V_t': V_t})   # 合取，禁止补偿
    return ('ok', {'V_m': V_m, 'V_t': 1.0})
```

### IP-131 ETP（Epistemic Terrain Probing）

```python
def epistemic_probe(candidates, M, budget):
    best, best_ig = None, -1.0
    for a in candidates:
        if not safe_precondition(a, M):
            continue
        ig = mutual_information(M.T, observation_model(a)) / a.duration
        if ig > best_ig and a.cost <= budget:
            best, best_ig = a, ig
    return best
```

### IP-132 STC（SLAM-Terrain Certificate）

```python
def slam_terrain_certificate(traj, M, budgets):
    G_core = core_subgraph(traj, M)
    T_core = core_terrain(traj, M)
    r_d = max(deformation_bound(G_core, M.loops, budgets.theta_lc)[p] for p in T_core)
    tau = trust_horizon(traj.state, M.loop_posterior, budgets.beta_commit,
                        budgets.eps_c, budgets.horizon_max)
    V_m, V_t = min_metric(traj, T_core), min_topo(traj, G_core)
    if r_d > budgets.beta_commit or tau < budgets.tau_min:
        return ('reject', 'deformation_or_horizon', r_d, tau)
    if V_m < budgets.theta_m or not V_t:
        return ('reject', 'traversability', V_m, V_t)
    rho_map = map_robustness_spectrum(M, budgets.eps_map)
    if rho_map < budgets.rho_min:
        return ('reject', 'map_robustness', rho_map)
    return ('ok', SlamTerrainCert(G_core, T_core, tau, r_d, V_m, V_t, rho_map))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| PGD | O(|T|·|L|) | O(|T|) | Jacobian 包络 sound、回环候选完备 |
| DTI | O(|T|·B) | O(|T|) | 区间取保守界、椭球外接 |
| THG | O(H·N_loop) | O(1) | 回环假阴性率校准、风险单调 |
| TAC | O(|e|/ds·QP) | O(|e|) | 双层合取、拓扑无未决回环 |
| ETP | O(N_probe·IG) | O(1) | 探测前提安全、观测模型可积 |
| STC | O(|traj|·(|T|+|G|)) | O(|T|+|G|) | 预算闭合、证书不可补偿 |

**正确性定理（SLAM-Terrain Anchored Soundness）**
假设第 55 轮 (A29)–(A32) 成立；**(A33)** 回环候选分经内容校验校准，假阴性率 `≤ ε_fn`；**(A34)** 形变上界 `r_d` 对任意被接受回环成立（Jacobian 包络 sound）；**(A35)** 双层可通行下界 sound 且不可补偿；**(A36)** 承诺视界估计保守（不高估 `τ_c`），探测动作满足 `x_{t+1}∈𝒳_safe`。
则部署后单步安全概率：
```
P_safe ≥ 1 - P(未检出回环) - P(r_d > β_commit) - P(V_t 假边) - P(V_m 假稳) - P(probe 不安全)
```
关键：**回环风险进视界、形变进地形包络、拓扑与度量分开认证且合取**——任何一层失守，都不允许把“当前地图看起来一致”当作“回环后仍然一致”。

## 6. 本轮最大风险

**一句话**：SLAM-地形联合认证把“地图几何”升级为“带形变与承诺视界的可执行地形”，但其 soundness **三重依赖回环假阴性率的校准、形变上界的紧致、以及拓扑/度量双层不可补偿的贯彻**；一旦回环假阴性被低估，机器人会在“自认为近场稳定”的地形上做不可逆落脚与步态切换，随后被真实回环的整体拉扯错位而跌倒——因此必须以 **回环假阴性上界校准 + 形变包络保守化 + 双层可通行合取** 三重护栏，宁可在视界外保持或探测，绝不把“当前地图一致”当作“回环后仍一致”。

# 第 55 轮产物 · 创新点清单 v32：GroundSem-GenSim+++（SCG×WBV×SSF×SCC×SRS×CEB）

### IP-121 SCG

```python
def semantic_contact_map(rgbd, seg_model, kappa, theta_k, theta_conf):
    Sigma = seg_model.predict_soft(rgbd)
    C = set()
    for p in grid(rgbd):
        l = argmax(Sigma[p])
        if confidence(Sigma[p]) < theta_conf:
            continue
        for c in CONTACT_TYPES:
            if kappa[l][c] >= theta_k:
                C.add((p, c))
    M = boundary_margin(Sigma)
    return Sigma, C, M
```

### IP-122 WBV

```python
def viability_kernel(Sigma, C_plus, x0, horizon, eps):
    K, margins = set(), []
    for x in sample_state_space(x0, horizon):
        feas, u, lam = solve_contact_dynamics(x, C_plus, friction_cone=mu)
        if feas:
            K.add(x)
            margins.append(distance_to_infeasible(x, C_plus))
    return KernelApprox(K_in=inner_hull(K),
                        K_out=outer_hull(K, eps),
                        margin=min(margins) if margins else 0.0)
```

```python
    if not C_core:
        return ('reject', 'no_core_contact')
    K_margin = min(distance_to_boundary_K(x, Sigma) for x in traj)
    delta_s = semantic_perturbation(Sigma_core, calibrated_eps)
    if K_margin < budgets.theta_K or delta_s > budgets.Theta_s:
        return ('reject', 'semantic_budget_exceeded', K_margin, delta_s)
    if rho_sem(delta_s) < budgets.rho_min:
        return ('reject', 'semantic_robustness_fail')
    return ('ok', SemanticCert(Sigma_core, C_core, K_margin, rho_sem, delta_s))
```

**正确性定理（Whole-Body Semantic-Contact Soundness）**
