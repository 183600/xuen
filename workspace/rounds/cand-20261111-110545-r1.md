# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「模型蒸馏」×「自主导航」）

> 第 54 轮把技能组合推进为动作-鲁棒性双证书（ACS/SCOM/CEC/AEC/JTC），但仍默认"证书可在云边、教师-学生之间原样对齐"。本轮引入 **模型蒸馏** 与 **自主导航**：教师（云端大模型 / 特权规划器）拥有全局地图与完整动作剖面，学生（边端轻量策略）只有机载观测；蒸馏不是复制答案，而是 **压缩证书**。核心矛盾：H22：教师的能力 `(α_T, ρ_T)` 不会自动迁移给学生，存在随分布漂移放大的"蒸馏鸿沟" `δ_D`，离线蒸馏证书在学生真实动作分布上失效；H23：自主导航是安全闭环，学生一旦驶出教师监督覆盖的可认证导航域 `D_nav`，任何离线证书都不再 sound；H24：多技能组合会放大单技能蒸馏鸿沟，组合证书的误差上界需按 Lipschitz 链式累积。

## 0. 直觉与动机

**灵感 1（蒸馏不是搬答案，而是搬"能力剖面 + 鲁棒性谱"）**
直觉：普通 KD 只对齐 logits / 动作，学生学到"教师在这个状态怎么做"，却学不到"教师为什么在扰动下仍稳"。把第 53–54 轮的 `ρ` 与 `α` 当作 **暗知识（dark knowledge）** 一起蒸馏：学生不仅要模仿动作，还要在动作空间上复现教师的覆盖剖面，并在扰动维度上复现鲁棒性排序。这样蒸馏的产物不是一个策略，而是一张 **可迁移的能力证书**。

**灵感 2（蒸馏鸿沟 δ_D → 证书里的"误差预算"而不是事后指标）**
直觉：教师 `T` 与学生 `S` 的差距在动作空间非均匀：常见动作几乎无损，长尾/极限动作急剧恶化。定义逐动作鸿沟 `δ_D(a)=|α_T(a)-α_S(a)|` 与逐维鲁棒性保持 `ret_ρ(d)=ρ_S(d)/ρ_T(d)`，把 `max`/累积鸿沟作为证书的显式预算；部署前先问"学生在这块动作上的鸿沟是否小于 `Θ_D`"，而不是只看平均精度。

**灵感 3（自主导航 → 可认证导航域 D_nav 与 CBF 前向不变）**
直觉：导航是安全关键闭环，证书必须在"状态 × 动作"上成立。用控制屏障函数 `h(x)` 定义安全集 `C`，教师只在 `D_nav` 上给出可信监督；学生要在 `D_nav` 上满足 CBF 前向不变条件，才可声称"沿学生策略不会离开安全集"。`D_nav` 之外不宣称任何保证，直接交给保守控制器或请求云端。

**灵感 4（在线蒸馏校正 → 边端"教师影子"与漂移绊线）**
直觉：离线蒸馏无法覆盖所有长尾。边端保留一个极小的 **教师影子**（缓存的特权查询 / 一致性锚点），在线比较学生与影子的动作差异 `δ_D^online(x)`；超过阈值或 OOD 检测命中，就触发问云、切换保守策略或局部再蒸馏。这把第 54 轮的 Explain 回传扩展为 **蒸馏漂移解释**：告诉云端是哪一维动作 / 哪一类场景发生了能力流失。

**灵感 5（蒸馏后的组合要重建图 → 学生动作空间上的 SCOM）**
直觉：技能在学生端蒸馏后，动作剖面从 `α_T` 变为 `α_S`，原来的组合边可能不再成立。必须在 **学生剖面** 上重建组合图 `G_S^stu`，并把每条组合边的鸿沟累积纳入证书：组合不是"教师能力的并集"，而是"学生能力的保守交集"。这直接承接第 54 轮 SCOM，但把 `compat` 换成带鸿沟惩罚的 `compat_stu`。

## 1. 形式化定义（增量：定义 121–127）

**定义 121（蒸馏能力对偶）**
教师 `T=(π_T,α_T,ρ_T)`，学生 `S=(π_S,α_S,ρ_S)`。在可认证导航域 `D_nav` 上定义：
- 动作分布保持 `κ_α(S|T)=inf_{x∈D_nav}(1-TV(π_S(·|x),π_T(·|x)))`；
- 鲁棒性保持 `κ_ρ(S|T,d)=inf_{x∈D_nav} min(1, ρ_S(d|x)/ρ_T(d|x))`；
- 逐动作蒸馏鸿沟 `δ_D(a)=|α_T(a)-α_S(a)|`，证书鸿沟 `δ_D(D_nav)=sup_{a∈D_nav} δ_D(a)`。

**定义 122（可认证导航域，NAD）**
状态 `x∈X`、动作 `a=(v,ω)∈A`。安全集 `C={x|h(x)≥0}`，`h` 为控制屏障函数。可认证导航域
`D_nav = {x∈C | ḣ(x,π_S(x)) + α_cbf(h(x)) ≥ 0 ∧ margin(x) ≥ m_min}`，
其中 `margin(x)` 为到最近障碍 / 边界的可微距离，`α_cbf` 为 class-κ 函数。**只有 `D_nav` 内的学生行为可被证书覆盖**。

**定义 123（蒸馏证书）**
`Dcert = (α_T, α_S, ρ_T, ρ_S, κ_α, κ_ρ, δ_D, D_nav, h, evidence)`。可部署条件：
```
δ_D(D_nav) ≤ Θ_D ∧ κ_ρ(S|T,d) ≥ ρ_min ∀d ∧ CBF_forward_invariant(S,D_nav)
```
`evidence` 至少包含：长尾动作采样日志、扰动一致性测试、`D_nav` 边界反例。

**定义 124（谱蒸馏损失，RKD）**
`L_RKD = L_task + λ_a·d_A(α_S,α_T) + λ_ρ·Σ_d w_d·max(0, ρ_T(d)-ρ_S(d)) + λ_n·E_{x,ε∈B_D}[d_A(π_S(x),π_S(x+ε))]`
其中 `ε` 为 `D_nav` 内的对抗扰动，第三项是 **动作一致性正则**，把教师的"扰动不变性"蒸馏成学生的局部 Lipschitz 性。

**定义 125（蒸馏鸿沟上界，CDG）**
若 `π_T,π_S` 在 `D_nav` 上分别对观测 / 地图扰动是 `L_T,L_S`-Lipschitz，且传感器噪声 `‖Δo‖≤ε_o`、地图误差 `‖ΔM‖≤ε_M`，则
`δ_D(D_nav) ≤ L_S·ε_o + L_T·ε_M + δ_D^cal`，
`δ_D^cal` 为校准集上的经验鸿沟。该上界把"蒸馏好坏"从经验指标变成可预算的证书项。

**定义 126（在线蒸馏校正，ODC）**
边端保留教师影子 `π_T^shadow` 与锚点集 `A_anchor`。在线鸿沟
`δ_D^online(x)=d_A(π_S(x),π_T^shadow(x))`。
触发规则：`δ_D^online(x)>τ_D ∨ OOD(x)=true → {ask_cloud, fallback_conservative, local_redistill}`，并回传 `Explain_distill=(动作维, 场景类, 鸿沟值)`。

**定义 127（蒸馏组合证书，DCC / NTC）**
组合 `S_1⊗…⊗S_k` 在 `D_nav` 上满足
`δ_D(S_1⊗…⊗S_k) ≤ Σ_i δ_D(S_i)·Π_{j>i} L_j`（Lipschitz 链式累积），
组合证书 `NTC=(J, Dcert_1..k, δ_D^comp, D_nav, CBF_margin, evidence)`，其中 `J` 为第 54 轮联合证书。若 `δ_D^comp > Θ_D` 或任一边界 CBF 余量不足，则组合否决。

## 2. 关键算法 伪代码

### IP-121 DCS（Distillation Certificate Synthesis）

```python
def distill_certificate(T, S, D_nav, sampler, theta_D, rho_min):
    alpha_T = sampler.profile(T, D_nav)
    alpha_S = sampler.profile(S, D_nav)
    delta_D = max(abs(alpha_T[a] - alpha_S[a]) for a in D_nav)
    kappa_rho = {d: inf_ratio(S.rho[d], T.rho[d], D_nav) for d in DIMS}
    cbf_ok = all(cbf_condition(S, x) for x in boundary_samples(D_nav))
    if delta_D > theta_D or not cbf_ok or min(kappa_rho.values()) < rho_min:
        return ('reject', delta_D, kappa_rho, cbf_ok)
    return ('ok', Dcert(alpha_T, alpha_S, T.rho, S.rho,
                        kappa_alpha(S, T, D_nav), kappa_rho,
                        delta_D, D_nav, S.h, evidence=[]))
```

### IP-122 RKD（Robustness-Preserving Knowledge Distillation）

```python
def robust_distill_step(T, S, batch, D_nav, lam=(1.0, 0.5, 0.5)):
    x, y = batch
    loss_task  = task_loss(S(x), y)
    loss_alpha = action_profile_divergence(S, T, D_nav)
    loss_rho   = sum(w[d] * max(0.0, T.rho[d] - S.rho[d]) for d in DIMS)
    eps = adversarial_perturb(x, D_nav, radius=R_D)
    loss_cons = action_divergence(S(x), S(x + eps))
    return loss_task + lam[0]*loss_alpha + lam[1]*loss_rho + lam[2]*loss_cons
```

### IP-123 NAD（Navigable Assured Domain）

```python
def navigable_domain(S, C, h, alpha_cbf, m_min):
    D = set()
    for x in C.grid(resolution):
        hdot = grad(h, x) @ S.f(x)
        if hdot + alpha_cbf(h(x)) >= 0 and margin(x) >= m_min:
            D.add(x)
    return prune_connected(D, start=robot_pose)
```

### IP-124 ODC（Online Distillation Correction）

```python
def online_distill_guard(x, S, T_shadow, anchor_set, tau_D):
    d = action_divergence(S(x), T_shadow(x))
    if d > tau_D or ood_detector(x):
        cause = explain_channel(S, T_shadow, x)   # 动作维 + 场景类
        return ('drift', d, cause)                # ask_cloud / fallback / redistill
    return ('ok', d)
```

### IP-125 CDG（Certified Distillation Gap）

```python
def certified_gap(S, T, D_nav, eps_o, eps_M):
    L_S = lipschitz_estimate(S, D_nav, wrt='observation')
    L_T = lipschitz_estimate(T, D_nav, wrt='map')
    delta_cal = empirical_gap(S, T, calibration_set(D_nav))
    return L_S * eps_o + L_T * eps_M + delta_cal
```

### IP-126 DCC（Distillation Composition Certificate）

```python
def composed_distill_certificate(seq, D_nav, cbf_margin_min, theta_D):
    delta, L = 0.0, 1.0
    for i in reversed(range(len(seq))):
        delta += seq[i].delta_D * L
        L *= seq[i].L
    if delta > theta_D:
        return ('reject', 'distill_gap_exceeded', delta)
    if min(cbf_margin(x) for x in boundary(D_nav)) < cbf_margin_min:
        return ('reject', 'cbf_margin_insufficient')
    return ('ok', NTC(seq, delta, D_nav, cbf_margin_min))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| DCS | O(|D_nav|·|A|) | O(|D_nav|) | 边界采样覆盖、CBF 可判定 |
| RKD | O(N·|A|·|DIMS|) / step | O(|A|) | 扰动半径有界、损失单调 |
| NAD | O(|C.grid| + |D_nav|) | O(|D_nav|) | 离散化误差有界、连通剪枝 sound |
| ODC | O(|A_anchor| + |A|) | O(|A|) | 触发延迟 ≤ τ_guard、Explain 因果 |
| CDG | O(|D_nav|·|DIMS|) | O(|D_nav|) | Lipschitz 估计置信、校准集同分布 |
| DCC | O(k·|A|) | O(k) | Lipschitz 链闭合、预算单调 |

**正确性定理（Certified Distillation Navigation Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** `δ_D(D_nav) ≤ Θ_D`，蒸馏证书 sound；**(A30)** 学生策略在 `D_nav` 上满足 CBF 前向不变；**(A31)** `κ_ρ(S|T,d) ≥ ρ_min` 且教师在 `D_nav` 上 `ρ_T(d) ≥ ρ_T^min`；**(A32)** ODC 在离开 `D_nav` 前的检测延迟 ≤ `τ_guard`。则
```
P(安全导航成功) ≥ 1 - Σ_d(1-ρ_S(d)) - P(δ_D>Θ_D) - P(x∉D_nav ∧ ODC 漏检) - β_E
```
关键：**证书只在可认证导航域内成立**，**蒸馏鸿沟有显式上界**，**组合鸿沟按 Lipschitz 链保守累积**。

## 4. 实验设计 E162–E167

| 实验 | 指标 | 目标 |

| E162 蒸馏鸿沟估计 | `|δ̂_D - δ_D^real|` | MAE ≤ 0.03 |
| E163 鲁棒性保持率 | `κ_ρ(S|T,d)` vs 普通 KD | ≥ 0.85（普通 KD ≈ 0.60） |
| E164 可认证导航域 | `D_nav` 覆盖率 / CBF 违反率 | 覆盖率 ≥ 70%，违反率 ≤ 1e-4 |
| E165 在线漂移检测 | 检测延迟 / 误报率 | P95 ≤ 100ms，误报 ≤ 3% |
| E166 组合鸿沟紧致性 | 实际上界比 / 部署成功率 | 比值 ≤ 0.8，成功率提升 ≥ 15% |
| E167 长尾导航泛化 | 新障碍 / 逆光 / 传感器退化成功率 | 相对普通 KD 提升 ≥ 20% |

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 教师自身盲区被学生继承 | 高 | 教师先认证 + 只在 `D_nav` 蒸馏 + 不确定度过滤 |
| `D_nav` 外无任何保证 | 高 | OOD 检测 + CBF 保守回退 + 人工 / 云端接管 |
| 鲁棒性谱蒸馏不可微、噪声大 | 中 | 排序蒸馏 + 代理损失 + 校准集回填 |
| 组合鸿沟上界过保守 | 中 | 分层紧化 + 实测鸿沟回填 + 局部重新认证 |
| 在线教师影子带来边端开销 | 中 | 稀疏锚点 + 事件触发 + 影子量化 |

## 6. 本轮最大风险

**一句话**：蒸馏把"教师能力"压缩成"学生证书"，但证书的 soundness 依赖 **教师本身在 `D_nav` 内可信、学生鸿沟 `δ_D` 被真实上界覆盖、以及 ODC 在驶出认证域前及时触发**；一旦教师盲区被当作可用能力继承、或离线鸿沟上界在分布漂移下失效，学生会在长尾导航场景中"带着合法证书系统性失效"，故必须以 **教师先认证 + 可认证导航域硬边界 + 在线蒸馏漂移绊线** 三重护栏，宁可缩小可宣称域，也不把"蒸馏出的像教师"当作"安全等于教师"。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-DistillNav（DCS×RKD×NAD×ODC×CDG×DCC）

> 承接第 54 轮产物 v31。本轮在动作-鲁棒性双证书（ACS/SCOM/CEC/AEC/JTC）之上，引入 **模型蒸馏** 与 **自主导航** 两条主线，增加六大算子：
> - **DCS（Distillation Certificate Synthesis）**：合成教师-学生蒸馏证书 `Dcert`；
> - **RKD（Robustness-Preserving Knowledge Distillation）**：把动作剖面与鲁棒性谱作为暗知识一起蒸馏；
> - **NAD（Navigable Assured Domain）**：用 CBF 刻画只在域内成立的自主导航认证域 `D_nav`；
> - **ODC（Online Distillation Correction）**：边端教师影子 + 在线鸿沟绊线 + Explain 回传；
> - **CDG（Certified Distillation Gap）**：以 Lipschitz 与传感器 / 地图误差给出鸿沟上界；
> - **DCC（Distillation Composition Certificate）**：蒸馏后重组技能图，并按 Lipschitz 链累积组合鸿沟。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-115/116/118/120 以纳入蒸馏鸿沟与可认证导航域。

```python
    if d > tau_D or ood_detector(x):
        cause = explain_channel(S, T_shadow, x)
        return ('drift', d, cause)   # ask_cloud / fallback_conservative / local_redistill
    return ('ok', d)
```

### IP-125 CDG

```python
def certified_gap(S, T, D_nav, eps_o, eps_M):
    L_S = lipschitz_estimate(S, D_nav, wrt='observation')
    L_T = lipschitz_estimate(T, D_nav, wrt='map')
    delta_cal = empirical_gap(S, T, calibration_set(D_nav))
    return L_S * eps_o + L_T * eps_M + delta_cal
```

### IP-126 DCC

```python
def composed_distill_certificate(seq, D_nav, cbf_margin_min, theta_D):
    delta, L = 0.0, 1.0
    for i in reversed(range(len(seq))):
        delta += seq[i].delta_D * L
        L *= seq[i].L
    if delta > theta_D:
        return ('reject', 'distill_gap_exceeded', delta)
    if min(cbf_margin(x) for x in boundary(D_nav)) < cbf_margin_min:
        return ('reject', 'cbf_margin_insufficient')
    return ('ok', NTC(seq, delta, D_nav, cbf_margin_min))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| DCS | O(|D_nav|·|A|) | O(|D_nav|) | 边界采样覆盖，CBF 可判定 |
| RKD | O(N·|A|·|DIMS|) / step | O(|A|) | 扰动半径有界，损失单调 |
| NAD | O(|C.grid| + |D_nav|) | O(|D_nav|) | 离散化误差有界，连通剪枝 sound |
| ODC | O(|A_anchor| + |A|) | O(|A|) | 触发延迟 ≤ τ_guard，Explain 因果 |
| CDG | O(|D_nav|·|DIMS|) | O(|D_nav|) | Lipschitz 估计置信，校准同分布 |
| DCC | O(k·|A|) | O(k) | Lipschitz 链闭合，预算单调 |

**正确性定理（Certified Distillation Navigation Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** `δ_D(D_nav) ≤ Θ_D`；**(A30)** 学生策略在 `D_nav` 上满足 CBF 前向不变；**(A31)** `κ_ρ(S|T,d) ≥ ρ_min` 且教师在 `D_nav` 上 `ρ_T(d) ≥ ρ_T^min`；**(A32)** ODC 在离开 `D_nav` 前检测延迟 ≤ `τ_guard`。则
```
P(安全导航成功) ≥ 1 - Σ_d(1-ρ_S(d)) - P(δ_D>Θ_D) - P(x∉D_nav ∧ ODC 漏检) - β_E
```
关键：**证书只在可认证导航域内成立**，**蒸馏鸿沟有显式上界**，**组合鸿沟按 Lipschitz 链保守累积**。

## 5. 与本轮灵感的两条直接落点

1. **模型蒸馏**：不再只蒸馏动作，而蒸馏 `(α,ρ)` 能力证书；`δ_D` 进入证书预算，`RKD` 把扰动不变性一并迁移，`CDG` 给出可计算的鸿沟上界。
2. **自主导航**：以 `D_nav`（CBF 前向不变 + 安全余量）作为"可宣称保证"的硬边界；`ODC` 在驶出边界前触发问云 / 保守回退，使蒸馏在安全关键闭环中可部署。

## 6. 本轮最大风险

**一句话**：蒸馏把"教师能力"压缩成"学生证书"，但证书的 soundness 依赖 **教师本身在 `D_nav` 内可信、学生鸿沟 `δ_D` 被真实上界覆盖、以及 ODC 在驶出认证域前及时触发**；一旦教师盲区被当作可用能力继承、或离线鸿沟上界在分布漂移下失效，学生会在长尾导航场景中"带着合法证书系统性失效"，故必须以 **教师先认证 + 可认证导航域硬边界 + 在线蒸馏漂移绊线** 三重护栏，宁可缩小可宣称域，也不把"蒸馏出的像教师"当作"安全等于教师"。
