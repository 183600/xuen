### 第 1 轮灵感驱动研究记录（v26 谱系）

**灵感词**：Isaac Sim、数据增强

**直觉与动机**：
承接 SRC-USC v25 七证链，一个长期被默认接受的前提浮出水面：所有证书的「证据」最终都来自数据——conformal 校准集、语义真值、碰撞日志、应力实测。真实世界数据稀缺、昂贵，且难以覆盖接触丰富、透明/形变、非刚体摩擦等长尾。Isaac Sim 提供 GPU 物理仿真（PhysX 5）、RTX 光线追踪与可微传感器，可在完美标签下批量生成域随机化场景；「数据增强」则进一步在已有样本邻域内扩展分布。但直觉上合成数据不是免费的：它把「真实世界的风险」替换成了「仿真器保真度的风险」。若仿真器在接触/形变/透明物体上与真实世界有系统性偏差，用其生成的证书会在真实部署时悄悄失效。因此本轮核心洞见是：**数据增强不是「凭空造样本」，而是在可证分布邻域内扩展「证书的证据质量」；Isaac Sim 不是「数据工厂」，而是「带保真度预算的证书工厂」。v26 新增的不是更多数据，而是「关于数据的证书」（meta-certificate）——用可证 TV 界、支持集覆盖、有效样本量三条界，把仿真证据转换为真实世界的准入承诺。**

**形式化目标**：
1. 定义仿真保真度证书（SFC）：在配对观测上以置信 1-δ 证明 d_TV(ℙ_S, ℙ_R) ≤ ε_fid，并额外覆盖接触力/能量等动力学通道与 GPU 可复现性。
2. 定义域随机化证书（DRC）：随机化参数 ξ~P_ξ 的支持集以概率 1-β 覆盖真实参数 ξ*，且域判别器不可区分（AUC ≤ 0.5+γ），并满足物理先验区间。
3. 定义合成增强证书（SDAC）：增广算子保标签、物理可行；以设计效应定义有效样本量 N_eff = N_total/(1+(m-1)ρ)，给出 conformal 分位数漂移界，防止覆盖率虚高。
4. 定义仿真-现实迁移证书（SRTC）：把 SFC+DRC+SDAC 合成为真实覆盖率下界 cov_R ≥ 1-α-Δ_tr，其中 Δ_tr = ε_fid + √(log(1/δ)/(2N_eff))。
5. 构建 v26 准入门：Exec_v26 = Exec_v25 ∩ Fil_s2r ⊆ Exec_v25，并把「Isaac Sim 数字孪生回归」作为部署前强制关卡。
6. 证明迁移、增强、物理过滤、重放四类操作的单调退化与失效回退性。

**与 v25 的关系**：v25 的 SMC/RMC/MCC/USMC 全部保留；v26 只增加一层「证据来源合法性」过滤器，不替换任何既有安全承诺，因此天然向下兼容。

**本轮最大风险**：仿真保真度证书只能在「被真实数据测到的区域」验证，而最危险的接触/形变/透明长尾恰恰是测不到的区域，可能导致 SFC 在未覆盖区给出过于乐观的 TV 界，使合成证书在真实部署时系统性失效。

## 1. 关键算法骨架（在 IP-444–447 骨架上扩展）

```python
# ============================================================
# IP-448 Simulation Fidelity Certificate (SFC) — 仿真保真度证书
# ============================================================
@dataclass
class SimulationFidelityCertificate:
    """以 TV 距离上界 + 动力学残差 + 可复现性证明仿真器可信度"""
    sim_id: str
    eps_fid: float = 0.05          # 允许的 TV(ℙ_S, ℙ_R) 上界
    delta_fid: float = 0.01        # 证书置信水平
    eps_force: float = 0.05        # 接触力相对残差容差
    eps_rep: float = 1e-4          # 同 seed 重复运行统计量方差容差
    c2st: 'ClassifierTwoSampleTest' = None
    seeds: tuple = (0, 1, 2)

    def tv_upper_bound(self, sim_obs: Tensor, real_obs: Tensor) -> float:
        """C2ST 估计 TV + Hoeffding 上置信界（保守，绝不低估）"""
        if self.c2st is None:
            return 1.0
        auc = self.c2st.fit_evaluate(sim_obs, real_obs)     # ∈[0,1]
        tv_hat = 2.0 * abs(auc - 0.5)                       # 判别器与 TV 的关系
        n = min(len(sim_obs), len(real_obs))
        slack = math.sqrt(math.log(1.0 / self.delta_fid) / (2.0 * n))
        return min(1.0, tv_hat + slack)

    def verify_observational_fidelity(self, sim_obs, real_obs) -> bool:
        return self.tv_upper_bound(sim_obs, real_obs) <= self.eps_fid

    def verify_dynamical_fidelity(self, sim_contact: Tensor,
                                  real_contact: Tensor) -> bool:
        """成对接触力/冲量通道：逐通道相对残差 ≤ eps_force"""
        if sim_contact.shape != real_contact.shape:
            return False
        rel = (sim_contact - real_contact).norm(dim=-1) / (
            real_contact.norm(dim=-1) + 1e-8)
        return bool((rel <= self.eps_force).all())

    def verify_energy_consistency(self, traj: 'Trajectory') -> bool:
        """仿真轨迹满足能量守恒/耗散，排除穿透与「永动」样本"""
        return traj.energy_drift() <= 1e-3 and not traj.has_penetration()

    def verify_reproducibility(self, runner: Callable[[int], Tensor]) -> bool:
        """GPU 非确定性：同 seed 多次运行，观测统计量方差 ≤ eps_rep"""
        stats = torch.stack([runner(s) for s in self.seeds])
        return bool(stats.var(dim=0).max() <= self.eps_rep)

    def verify_all(self, sim_obs, real_obs, sim_contact, real_contact,
                   runner) -> bool:
        return (self.verify_observational_fidelity(sim_obs, real_obs)
                and self.verify_dynamical_fidelity(sim_contact, real_contact)
                and self.verify_reproducibility(runner))


# ============================================================
# IP-449 Domain Randomization Certificate (DRC) — 域随机化证书
# ============================================================
@dataclass
class DomainRandomizationCertificate:
    """随机化支持集覆盖 + 不可区分性 + 物理先验区间"""
    xi_dist: 'ParameterDistribution'     # ξ = (μ, damping, friction, mass, light, latency,…)
    beta: float = 0.01                   # 支持集覆盖风险
    gamma: float = 0.02                  # |AUC-0.5| 上界
    support_estimator: 'SupportEstimator' = None
    prior_box: Optional[dict] = None     # 例如 {"friction": (0.1,1.2), "mass": (0.8,1.2)}

    def verify_support_coverage(self, real_xi_est: Tensor) -> bool:
        """ℙ(ξ* ∈ Ξ_supp) ≥ 1-β；conformal/极值理论估计支持集边界"""
        if self.support_estimator is None:
            return False
        return self.support_estimator.coverage(real_xi_est) >= 1.0 - self.beta

    def verify_indistinguishability(self, sim_obs: Tensor, real_obs: Tensor,
                                    c2st: 'ClassifierTwoSampleTest') -> bool:
        auc = c2st.fit_evaluate(sim_obs, real_obs)
        return abs(auc - 0.5) <= self.gamma

    def verify_prior_box(self) -> bool:
        """随机化区间必须覆盖物理先验（否则支持集是自证循环）"""
        if self.prior_box is None:
            return True
        for name, (lo, hi) in self.prior_box.items():
            if not self.xi_dist.covers(name, lo, hi):
                return False
        return True

    def verify_all(self, real_xi_est, sim_obs, real_obs, c2st) -> bool:
        return (self.verify_support_coverage(real_xi_est)
                and self.verify_indistinguishability(sim_obs, real_obs, c2st)
                and self.verify_prior_box())


# ============================================================
# IP-450 Synthetic Augmentation Certificate (SDAC) — 合成增强证书
# ============================================================
@dataclass
class SyntheticAugmentationCertificate:
    """组级有效样本量 + 标签保持 + 物理可行 + 分位数漂移界"""
    base_size: int
    groups: int                          # 独立基场景/轨迹数（非增广后的名义计数）
    per_group: int                       # 每组样本数 m
    rho_intra: float                     # 组内相关系数 ICC（由 ANOVA 估计）
    augment_ops: list = field(default_factory=list)
    eps_aug: float = 0.02                # 增广引起的分位数漂移容差
    delta_aug: float = 0.01
    phys_filter: 'PhysicalPlausibilityFilter' = None

    @property
    def n_total(self) -> int:
        return self.groups * self.per_group

    @property
    def effective_sample_size(self) -> float:
        """Kish 设计效应：N_eff = N_total / (1 + (m-1)ρ)"""
        m, rho = max(1, self.per_group), min(1.0, max(0.0, self.rho_intra))
        return self.n_total / (1.0 + (m - 1) * rho)

    def conformal_slack(self) -> float:
        return math.sqrt(math.log(1.0 / self.delta_aug) /
                         (2.0 * max(1.0, self.effective_sample_size)))

    def verify_effective_sample_size(self, n_min: float) -> bool:
        return self.effective_sample_size >= n_min

    def verify_label_preservation(self, y: Tensor, y_aug: Tensor,
                                  op: 'AugOp') -> bool:
        """增广必须保持任务标签，或按已知等变律变换"""
        return bool(op.label_preserving) and bool(
            torch.equal(op.transform_label(y), y_aug))

    def verify_physical_plausibility(self, episodes: list) -> bool:
        """剔除穿透、非物理能量增益、接触互补性违约的增广样本"""
        if self.phys_filter is None:
            return False
        return all(self.phys_filter.check(ep) for ep in episodes)

    def verify_quantile_drift(self, scores_base: Tensor, scores_aug: Tensor,
                              alpha: float) -> bool:
        """仅用组级独立分数重标定，确认增广没有把覆盖率「刷」高"""
        q_base = empirical_quantile(scores_base, 1.0 - alpha)
        q_aug = grouped_empirical_quantile(scores_aug, self.groups, 1.0 - alpha)
        return abs(q_aug - q_base) <= self.eps_aug

    def verify_all(self, scores_base, scores_aug, episodes, alpha,
                   n_min) -> bool:
        return (self.verify_effective_sample_size(n_min)
                and self.verify_physical_plausibility(episodes)
                and self.verify_quantile_drift(scores_base, scores_aug, alpha))


# ============================================================
# IP-451 Sim-to-Real Transfer Certificate (SRTC) — 迁移证书
# ============================================================
@dataclass
class SimToRealTransferCertificate:
    """把仿真证据转换为真实准入承诺：cov_R ≥ 1-α-Δ_tr"""
    sfc: SimulationFidelityCertificate
    drc: DomainRandomizationCertificate
    sdac: SyntheticAugmentationCertificate
    alpha: float = 0.05
    min_coverage: float = 0.90

    def transfer_gap(self) -> float:
        return self.sfc.eps_fid + self.sdac.conformal_slack()

    def certified_real_coverage(self) -> float:
        return 1.0 - self.alpha - self.transfer_gap()

    def admits(self, sim_plan: 'Plan', real_obs, sim_obs,
               sim_contact, real_contact, real_xi_est, runner,
               scores_base, scores_aug, episodes) -> bool:
        if self.certified_real_coverage() < self.min_coverage:
            return False                              # 预算不足，直接拒证
        if not self.sfc.verify_all(sim_obs, real_obs,
                                   sim_contact, real_contact, runner):
            return False
        if not self.drc.verify_all(real_xi_est, sim_obs, real_obs, self.sfc.c2st):
            return False
        if not self.sdac.verify_all(scores_base, scores_aug, episodes,
                                    self.alpha, n_min=30):
            return False
        return sim_plan.verified_under_v25


# ============================================================
# 扩展：Isaac Sim 场景生成 + 数字孪生回归 + v26 流水线
# ============================================================
class IsaacSimScenarioGenerator:
    """Isaac Sim 场景采样：域随机化 + 物理过滤 + 数字孪生重放"""
    def __init__(self, sim_app: 'IsaacSimApp',
                 dr: DomainRandomizationCertificate,
                 phys_filter: 'PhysicalPlausibilityFilter', seed: int = 0):
        self.app, self.dr, self.phys_filter = sim_app, dr, phys_filter
        self.rng = torch.Generator().manual_seed(seed)

    def sample_episode(self) -> Optional['Episode']:
        xi = self.dr.xi_dist.sample(self.rng)
        ep = self.app.rollout(xi)             # PhysX 物理 + RTX 传感器渲染
        if not self.phys_filter.check(ep):    # 穿透/能量/接触互补性
            return None
        return ep

    def replay_certificates(self, plan: 'Plan', xi: Tensor) -> 'ReplayResult':
        """数字孪生回归：在 Isaac Sim 中重放 v25 七证，失败即拒绝部署"""
        self.app.reset(xi)
        return self.app.replay(plan)          # USMC/SMC/RMC/MCC 重放结果

    def augment(self, base: list, ops: list, groups: int) -> list:
        """按组增广：同一基场景派生的增广共享 group_id，用于 N_eff 计算"""
        out = []
        for g, ep in enumerate(base):
            ep.group_id = g
            out.append(ep)
            for op in ops:
                aug = op.apply(ep)
                aug.group_id = g
                if self.phys_filter.check(aug):
                    out.append(aug)
        return out


class SimAugmentedCertificatePipeline:
    def __init__(self, config: dict):
        self.v25 = config['v25_pipeline']
        self.sfc = config['sfc']
        self.drc = config['drc']
        self.sdac = config['sdac']
        self.srtc = SimToRealTransferCertificate(
            self.sfc, self.drc, self.sdac, alpha=config['alpha'])
        self.gen = IsaacSimScenarioGenerator(
            config['sim_app'], self.drc, config['phys_filter'],
            seed=config['seed'])
        self.ipam.register_module("sfc", ["IP-448"],
            ["tv_fidelity_bound", "dynamical_fidelity", "gpu_reproducibility"])
        self.ipam.register_module("drc", ["IP-449"],
            ["support_coverage", "c2st_indistinguishability", "prior_box"])
        self.ipam.register_module("sdac", ["IP-450"],
            ["effective_sample_size", "physical_plausibility", "quantile_drift"])
        self.ipam.register_module("srtc", ["IP-451"],
            ["sim_to_real_transfer", "digital_twin_replay", "v26_monotonic_chain"])

    def step(self, sensor_data: dict,
             cloud_update: Optional[dict] = None) -> tuple:
        # 1. 真实世界先跑 v25，保住既有安全链（v25 失败则无 v26 之谈）
        admitted_v25, info_v25 = self.v25.step(sensor_data, cloud_update)
        if not admitted_v25:
            return False, {'stage': 'v25_reject', 'info': info_v25}

        # 2. Isaac Sim 数字孪生回归（同一计划重放七证）
        replay = self.gen.replay_certificates(
            info_v25['multi_plan'], sensor_data['xi_est'])
        if not replay.all_passed:
            return False, {'stage': 'digital_twin_replay_fail', 'replay': replay}

        # 3. 生成 + 按组增广校准/压力场景，并做物理过滤
        episodes = [e for _ in range(sensor_data['n_scenes'])
                    if (e := self.gen.sample_episode()) is not None]
        augmented = self.gen.augment(
            episodes, self.sdac.augment_ops, groups=len(episodes))

        # 4. SRTC 准入（含真实覆盖率下界）
        admitted = self.srtc.admits(
            info_v25['multi_plan'],
            sensor_data['real_obs'], sensor_data['sim_obs'],
            sensor_data['sim_contact'], sensor_data['real_contact'],
            sensor_data['xi_est'],
            lambda s: self.gen.app.rollout(sensor_data['xi_est']).stats,
            sensor_data['scores_base'], sensor_data['scores_aug'], augmented)
        return admitted, {
            'stage': 'v26' if admitted else 'srtc_reject',
            'real_coverage_lb': self.srtc.certified_real_coverage(),
            'transfer_gap': self.srtc.transfer_gap(),
            'n_eff': self.sdac.effective_sample_size,
            'replay': replay,
            'v25': info_v25,
        }


# ============================================================
# 辅助：物理可行性过滤 + 分位数
# ============================================================
class PhysicalPlausibilityFilter:
    """能量、穿透、接触互补性、标签一致四道物理过滤"""
    def __init__(self, max_energy_gain: float = 1e-3,
                 max_penetration: float = 1e-4,
                 max_complementarity: float = 1e-3):
        self.max_energy_gain = max_energy_gain
        self.max_penetration = max_penetration
        self.max_complementarity = max_complementarity

    def check(self, ep: 'Episode') -> bool:
        return (ep.energy_gain() <= self.max_energy_gain
                and ep.max_penetration() <= self.max_penetration
                and ep.contact_complementarity() <= self.max_complementarity)

def empirical_quantile(scores: Tensor, q: float) -> float:
    return torch.quantile(scores.flatten().float(), q).item()

def grouped_empirical_quantile(scores: Tensor, groups: int, q: float) -> float:
    """每组建模为独立单元：先组内聚合，再在组级分布上取分位数"""
    per_group = scores.reshape(groups, -1)
    group_scores = per_group.max(dim=1).values     # 保守：取组内最差分
    return torch.quantile(group_scores.float(), q).item()
```

## 2. 复杂度分析（增量）

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 |
|---|---|---|---|
| SFC 观测保真 TV/C2ST | O((N_S+N_R)·d·E) 训练；O(N·d) 推断 | O(N·d) 特征 | N≤10⁴, d≤512, E≤50 |
| SFC 动力学保真 | O(N_c·n) 逐样本残差 | O(N_c·n) | N_c≤10⁴, n≤7 |
| SFC 可复现性 | O(k·T·n) 重复 rollout | O(k·T·n) | k=3, T≤500 |
| DRC 支持集覆盖 | O(N_ξ log N_ξ) 排序/极值 | O(N_ξ·d_ξ) | N_ξ≤10⁴, d_ξ≤20 |
| DRC 不可区分 C2ST | O((N_S+N_R)·d·E) | O(N·d) | 与 SFC 共享判别器 |
| SDAC ICC/设计效应 | O(N_total·d) ANOVA | O(G) 组统计 | G≤10³ |
| SDAC 物理过滤 | O(Ep·T·n) 能量/穿透/互补性 | O(Ep·T) | Ep≤10⁴, T≤500 |
| SDAC 分位数漂移 | O(N_total log N_total) | O(G) | - |
| SRTC 准入判定 | 上述之和（离线校准，在线 O(1) 查表） | O(1) 在线 | Δ_tr 预计算 |
| Isaac Sim 场景生成 | 离线 GPU，~10³ episode/min | 显存 O(batch) | 不占在线关键路径 |
| 端到端真实单步（增量） | +O(N log N) 分位/统计 + O(1) 覆盖率比较 | +O(N) | 数字孪生重放异步/部署前完成 |

**实时性保证**：SFC/DRC/SDAC 的主体是**离线或部署前**校准，在线只做阈值比较与计数器更新；Isaac Sim 生成与数字孪生重放放在部署前/异步线程，不进入 50Hz 控制环。在线关键路径仅增加 O(N log N) 的分位数统计，P99 增量 <1ms。

## 3. 正确性论证（增量）

### 引理 13（TV 保真度 ⇒ conformal 覆盖率迁移）
**陈述**：设仿真分布 ℙ_S 与真实分布 ℙ_R 满足 d_TV(ℙ_S,ℙ_R) ≤ ε_fid（置信 1-δ），且 `C_α` 在 ℙ_S 上覆盖率 `cov_S ≥ 1-α`。则真实覆盖率 `cov_R ≥ 1-α-ε_fid`（减去有限样本 slack）。
**证明**：令事件 `A = {Y ∈ C_α(X)}`。由 TV 定义 `|ℙ_R(A)-ℙ_S(A)| ≤ d_TV(ℙ_S,ℙ_R) ≤ ε_fid`，故 `cov_R = ℙ_R(A) ≥ ℙ_S(A)-ε_fid ≥ 1-α-ε_fid`。TV 由 C2ST 判别器给出并用 Hoeffding 上置信界保守修正，保证不低估。∎

### 引理 14（域随机化的支持-可辨二重保证）
**陈述**：若 (H1) `ℙ(ξ*∈Ξ_supp) ≥ 1-β`；(H2) 观测核 `k_ξ` 关于 ξ 的 W₁ 连续性模为 L_ξ；(H3) 随机化混合分布与真实的 C2ST 可区分度 `|AUC-0.5|≤γ`，则 `d_TV(ℙ_S^DR,ℙ_R) ≤ min(ε_C2ST, L_ξ·diam(Ξ_supp))`（概率 ≥1-β）。
**证明**：(H1) 保证真实环境参数落在仿真可生成的支持集内；(H2) 给出同参数邻域内观测分布的距离上界 `L_ξ·diam(Ξ_supp)`；(H3) 给出与数据无关的判别器残差上界。取两者较小者为上界，任一成立即得 TV 界；与引理 13 合成即得随机化仿真的迁移承诺。∎

### 引理 15（数据增强的有效样本量与覆盖率稀释）
**陈述**：设增广数据 `D_aug` 含 G 个独立基组、每组 m 个（组内相关），组内相关系数 ρ。则有效样本量 `N_eff = N_total/(1+(m-1)ρ)`；有限样本 conformal 覆盖率下界为 `1-α-√(log(1/δ_aug)/(2N_eff))`。特别地，当增广完全确定于基样本（ρ=1）时 `N_eff=G`，名义增广不增加证据量。
**证明**：把每组视为一个独立单元，组间独立、组内相关，用 Kish 设计效应折算方差；对组级经验 CDF 应用 DKW/Hoeffding 不等式即得有限样本项。ρ=1 时设计效应为 m，N_eff 回落到 G。故「数据变多」不等于「证据变多」。∎

### 引理 16（物理可行过滤 + 重标定保持有效性）
**陈述**：设物理过滤器 `F_phys` 仅依赖 (x,y)（不看未来标签泄漏），在过滤后的增广集上重新校准。若真实样本落在可行流形内概率 ≥1-β_phys，则过滤后证书对真实分布的覆盖率 ≥1-α-β_phys。
**证明**：过滤后样本在条件分布 `ℙ(·|feasible)` 内仍交换，conformal 覆盖对该条件分布成立；再用全概率公式把条件覆盖与不可行概率 β_phys 合并即得。**关键**：若沿用过滤前的分位数而不重标定，则分数分布被截断，覆盖率会被高估——这正是「增强污染证书」的机制。∎

### 引理 17（数字孪生回归与 v26 单调退化）
**陈述**：`Exec_v26 = Exec_v25 ∩ Fil_s2r ⊆ Exec_v25`；当数字孪生重放失败或 SRTC 拒证时，回退到 v25 的真实世界保守执行，单调链不断裂。
**证明**：交集对子集封闭。回退路径：重放失败 → 禁用所有合成证据 → 仅用真实数据维持 v25 证书（覆盖率按 v25 保证）；SFC/DRC/SDAC 任一失败 → 丢弃对应合成部分，按缺失维度保守收紧 α 或冻结任务。组合失效取交集，仍为子集。∎

### 定理（v26 仿真增强准入门的安全-迁移-增强完备性）
**陈述**：对任意计划 π，`SRTC.admits(π)=True` ⟺ π 同时满足：
(1)-(10) v25 的十项（物理安全、云边一致、少样本覆盖、专利保护、结构/力控/轻量化、语义/重构/协同），
(11) 仿真保真 `d_TV(ℙ_S,ℙ_R)≤ε_fid` 且动力学/可复现性达标，
(12) 域随机化支持覆盖与不可区分，
(13) 增强有效样本量与物理可行性达标，
(14) 数字孪生回归通过，
(15) 真实覆盖率下界 `1-α-Δ_tr ≥ min_coverage`。
**证明**：由 `SRTC.admits` 的合取条件、引理 13–17 直接可得；必要性由每条拒绝路径对应一类未被缓解的仿真/数据风险；充分性由引理 13 的覆盖率迁移 + 引理 17 的单调回退保证。∎

## 6. 本轮最大风险（最终确认）

**一句话**：**SFC 的 TV 界只在被真实数据锚定的区域可信，而接触/形变/透明长尾恰恰缺少真实锚点；DRC 的支持集又依赖对不可直接观测的 ξ* 的反演；SDAC 的 N_eff 还需可信的 ICC 估计——三者在「未覆盖物理现象 + 参数反演误差 + 组内相关被低估」叠加时，可能让 v26 在仿真证据系统性乐观的情况下仍通过 SRTC，使合成证书在真实部署中静默失效。**
