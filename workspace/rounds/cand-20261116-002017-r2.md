# 第 11 轮（新灵感循环第 2 轮；本轮灵感：「能耗优化」×「社会影响」）
> **基线**：第 10 轮 MetricVoiceGauge-STF-NRB-LS（定义 540–548；引理 87–91；实验 E571–E590）。
> 本轮纪律：**慢变量核算 + 外部价值 + 只收紧不放宽**。v10 把"安全"做成了快变量证书（块级 Ĉ⁺、50Hz 四检），却把两类**慢变量**当成静态预算：**能量债**（E_m 只是配额上限，"中止机动是否有能量执行"从未进证书）、**社会债**（NRB 只审逐事件个体规范，累计外部性/分配正义/价值争议无机制、无核算、无失败语义）。本轮把两者升级为**可观测、被证书条件化、有硬预算与失明收缩**的慢变量。铁律：慢变量只许**收紧**快安全约束，绝不放宽；慢变量预算越界或核算失明 ⇒ 收缩剖面 Π_s。必须保持 v10 铁律：任一新模块失效 ⇒ 注入声明中立元，行为严格**等价**（EG 失效 ⇒ 回归 v10 静态配额）或**支配**（SIA 失效 ⇒ Π_s ⊆ Π_r ⊆ v9 可行集）于 v10，而非行为漂移。

## 0. 直觉与动机

**灵感 1（能耗优化 → 能量是证书的前提，不只是预算）**
直觉：v10 的块证书证明"几何上停得住"，却默认"中止动作执行得动"。但在电量耗尽、热节流、25W 功率争用下，中止机动本身可能**不可达或更慢**——这是与 v9 的 β 前提同构的**未验证全局前提**，只是换了名字。能耗优化的第一性事实：能量是**慢状态**，它决定执行器带宽、传感器帧率与前向模型的有效不确定性。核心创新：**能量治理器（EnergyGovernor, EG）**——(i) **能量可行中止证书**：E_res − E_abort(ζ) ≥ E_reserve 才发证书，把"停得住"升级为"有能量停得住"；(ii) **能量/热条件化**：d_brake 与 β_STF 随可测降额比 ρ_E、ρ_Θ 单调膨胀（引理 93），低电量不再只是"提醒充电"，而是直接加厚证书余量；(iii) **按瓦特安全值的降级序**：功率紧张时按**声明表**先卸重计算（块生成 → K=1 逐步，峰值功耗反而下降），安全守卫（语义检/快规范/停车不变式/能量储备检）**永不可卸**；(iv) **能量感知块长**：K_eff^E = min(K_eff^v10, K_E)，只收紧不放宽。

**灵感 2（社会影响 → 从逐事件规范到累计影响核算与分配正义）**
直觉：v10 的 NRB 是**逐块、逐事件、个体规范**的治理；但社会影响是**累计的、分布式的、跨主体的、且价值有争议的**——每次都合规的"抄近路 / 优先服务熟客 / 夜间提示音"仍可能累积成对他人的系统性负担。更关键：社会影响**不能由机器人自己定义什么是"好"**，否则就是价值自赋与 Goodhart 灾难。核心创新：**社会影响核算器（SocialImpactAccountant, SIA）**——(i) **影响向量** I=(可及性, 置换, 注意力税, 声学, 分配公平, 信任)，由可观测代理量在滑动时域上核算；(ii) **外部声明价值**（P16 价值不可自赋律）：权重 w_I 与预算 B_I 是外部签署、版本化、可审计的**数据**，机器人只核算、遵守、报告，绝不学习或优化自己的价值函数；(iii) **累计影响预算 + 分配公平债** D_f：跨用户累计服务差异超阈即强制补偿（优先服务弱势/欠服务者），防系统性劣势；(iv) **外部性硬帽**：严重外部性（夜间噪声、挤压个体、可及性剥夺）无论任务得分多高一律否决。**字典序**：安全 ≻ 影响 ≻ 任务。

**协同（慢变量治理 = 本轮统一框架）**
两个灵感共享同一结构：能量与社会影响都是 v10 当作静态预算的**慢变量**，v11 把它们变成**可观测、被证书条件化、有硬预算与失明收缩**的状态。更关键的咬合：v10 最大风险是 τ_sem 分割面对抗穿透——SIA 提供一条**独立的滞后观测通道**（引理 98）：被漏检的"非显著"语义变化若真实伤害人，会以投诉/回避/注意力激增的形式进入 I(t)，虽不能恢复实时保守性，但能**有界地限制系统性伤害的持续时间**并触发 τ_sem 重标定。EG 则从另一侧加厚前提：低能量/热节流下 β 膨胀，压缩"轻量化量化误差吃掉分割安全边际"的空间。二者共同把 v10 证书升级为**慢变量条件化证书 Ĉ^E = (ĝ_min, ê_max, γ̂_grasp, β_STF^E, n_t, E_abort)**，并新增治理闸门。

## 1. 研究问题（轮次升级版）

- **Q1（能量条件化安全）**：如何把"中止机动可执行"从隐含前提变为可测、可入证书的约束，使低电量/热节流下证书仍保守（β_STF^E 覆盖 ≥99%），且能量约束只缩小可行块集、不改变任何 v10 已认证行为？
- **Q2（功率-安全权衡）**：在 25W 预算下，如何按"每瓦特安全值"声明式地降级，使守卫永不被卸、峰值功耗下降、而决策保守性单调不降（K 只减不增）？
- **Q3（社会影响可核算且不自赋价值）**：如何把累计外部性与分配正义形式化为可核算的影响向量 + 外部声明权重/预算 + 硬帽，使机器人在**不优化自身价值函数**的前提下，把跨主体系统性伤害压到有界，并让影响账本可审计、权重版本可追责？
- **Q4（语义-社会交叉校验）**：社会影响能否作为 τ_sem 分割面漏检的**独立滞后观测通道**，使被漏检的"静默语义故障"在有限时长内被检出并触发重标定？

## 2. 设计原则（在 P13–P15 基础上新增 P16–P17）

**P16 价值不可自赋律（No Self-Authored Values, SIA）**
机器人不得设置、学习或优化自身的社会影响权重 w_I 与预算 B_I；二者必须是外部签署、版本化、可审计的**数据**。机器人只做三件事：核算（account）、遵守（respect）、报告（report）。任何价值参数变更必须来自外部治理流程并写入账本；机器人单方面改动权重即视为完整性故障 ⇒ Π_s。此律把"价值争议"留在人类治理侧，机器人不僭越。

**P17 慢变量守恒律（Slow-Variable Conservation, EG/SIA）**
快安全证书的前提（中止可执行、制动距离、预测误差界）必须**以慢变量为条件**；慢变量优化只许**收紧**快安全约束（K_eff←min、β↑、d_brake↑、可行块集⊆），永不放宽。慢变量硬预算越界或核算失明（能量模型超时、影响账本缺口、权重版本不可验）⇒ 治理剖面 Π_s（⊇ Π_r），物理可行集单调收缩。

## 3. 与基线的接口（如何退化）

- **EG 失效**（能量模型超时/热传感器失效）⇒ E_abort←v10 隐含"能量充足"假设、ρ_E=ρ_Θ=0、d_brake←d_brake、β←β_STF：**严格等价 v10**（退回静态 E_m 配额），不新增保守税也不新增乐观；
- **SIA 失效**（影响核算超时/权重不可验/账本缺口）⇒ Π_s（⊇ Π_r）：物理可行集 ⊆ v10，任务可完成性可能下降，失败路径为安全停驻 + 语音披露（v10 兼容中止）；
- **STF 失效** ⇒ K=1、β←β_base（v10 Level-1 原样）；**NRB 失效** ⇒ Π_r（v10 原样，Π_s 在其上加严）；
- **AC 证书失效** ⇒ K=1（v10 Level-3 原样）；**ID 失效** ⇒ 全模块 active、归因冻结（新增能量守卫与影响核算一律 φ^elig=false 永不消融，仅"能量模型离线重标定/影响代理量离线校准"可蒸馏）；
- **MW 失效** ⇒ v10 手写网关（代码保留）；v8 组件失效 ⇒ v9 中立元 ⇒ v7 ⇒ v6。

## 4. 预期贡献

1. **能量条件化证书**：把"中止可执行"从隐含全局前提变为可测入证书的约束，低电量/热节流下 β 膨胀、d_brake 加严，且能量约束只缩小可行集（引理 92–93）；
2. **声明式功率降级**：按每瓦特安全值的降级序，守卫永不可卸、峰值功耗下降、K 单调收紧（引理 94）；
3. **不自赋价值的社会影响核算**：影响向量 + 外部权重/预算 + 分配公平债 + 外部性硬帽 + 字典序，跨主体系统性伤害有界且全程留痕（引理 95–96）；
4. **语义-社会交叉校验**：社会影响作为 τ_sem 漏检的独立滞后通道，有界系统性伤害持续时间（引理 98）；
5. **E591–E605** 覆盖能量可行中止、降额标定、功率降级、影响构念效度、分配公平、价值审计、交叉校验、长跑与竞赛。

## 5. 本轮最大风险

**一句话**：把慢变量估计（能量模型 E_abort、热降额曲线、社会影响代理量）耦合进快安全证书，等于重新引入一个**不可证的强前提**——"能量模型准确、代理量有效"；若 E_abort 在意外地形/负载下被低估，或影响代理量被 Goodhart 化（靠回避人群压低"注意力税"却牺牲可及性），系统会以**指标改善的假象**同时失去能量可行性与真实社会福利，而社会交叉校验是滞后的，无法在单次事故前恢复实时保守性。

**新增定义 549（慢变量向量）** S(t)=(E_res 剩余能量, Θ 温度, P 瞬时功率, B_soc 社会预算消耗, D_f 公平债, v_w 权重版本)。慢变量时间常数 ≥ 分钟，与 50Hz 快回路解耦，仅在块边界（5Hz）更新。

**新增定义 550（中止能量）** E_abort(ζ) = (P_act+P_comp)·T_abort(ζ) + E_hold，T_abort 取块内**最远可达点**最坏中止机动时长，E_hold 为中止后安全停驻能量。E_abort 是块的保守上界（最坏情形，非均值）。

**新增定义 551（能量/热降额比）** ρ_E = clip((E_min−E_res)/(E_min−E_floor), 0, 1)；ρ_Θ = clip((Θ−Θ_nom)/(Θ_throttle−Θ_nom), 0, 1)。二者均由实测降额曲线给出（E592），非解析假设。

**新增定义 552（能量条件化制动与余量）** d_brake^E = d_brake·(1+κ_E ρ_E+κ_Θ ρ_Θ)；β_STF^E = β_STF + λ_E ρ_E + λ_Θ ρ_Θ。κ、λ 经 E592/E594 标定。单调非减：能量/热状况只能加厚安全裕量，永不削减。

**新增定义 553（慢变量条件化证书）** Ĉ^E valid ⇔ Ĉ⁺ valid（v10 定义 543 全条件）∧ E_res − E_abort(ζ) ≥ E_reserve ∧ Θ ≤ Θ_throttle。几何安全与能量可行**同时**成立才发证书；任一不成立 ⇒ K=1 或安全停驻。

**新增定义 554（功率感知降级序）** 声明表 σ_E 按每瓦特安全值升序排列；G_safe（证书检/停车不变式/语义检/快规范/能量储备检）安全值记为 ∞，永不可卸。卸块生成 ⇒ K=1（峰值功耗下降）；卸全审查 ⇒ 仅快规范；SIA 降频但 SL 写不可卸。

**新增定义 556（影响向量）** I(t)=(I_acc 可及性, I_dis 置换, I_att 注意力税, I_aco 声学, I_equ 分配公平, I_tru 信任)，各维由可观测代理量（请求满足率/等待、人类路径偏移或让行数、视线侵入或近似事件、超环境规范声压、D_f、投诉/接管/退出率）在滑动时域 H_I 上核算并归一化到 [0,1]。代理量是**经验构念**，其效度由 E596 检验，非先验真理。

**新增定义 557（外部声明权重与预算，P16）** w_I∈Δ^5（6 维去掉一维归一化），B_I∈R^6_+，二者带外部签名与版本 v_w，由外部治理流程产生，**非机器人可写**。机器人计算加权影响 I·w_I、预算消耗 Σ_H I_j，越界即 Π_s；权重不可验（签名/版本失败）即 Π_s。

**新增定义 558（分配公平债）** D_f(t)=max_{u,u'}|S_u(t)−S_{u'}(t)|/(mean_u S_u+ε)，S_u 为用户 u 的累计服务量子。D_f>D_f,max ⇒ 规划器必须优先服务欠服务者（补偿排队）；仅改变**选哪个合法块**，不改变安全性。

**新增定义 559（外部性硬帽与字典序评分）** 块 ζ 的外部性增量 ΔI(ζ) 逐维检查：若 ΔI_j > cap_j（严重外部性：夜间噪声、挤压个体、可及性剥夺）⇒ 无论任务得分一律拒绝。否则 score'(ζ) = score(ζ) − μ·(ΔI(ζ)·w_I)，**仅在证书合法块之间**作次级排序。字典序：安全（证书合法）≻ 影响（硬帽与预算）≻ 任务（score）。

**新增定义 560（治理剖面与治理账本）** Π_s = Π_r ∪ {E_res ≥ E_reserve^hard, K_eff≤2, 暴露上限（避开密集人群）, 强制披露（能量/影响状态）, 账本缺口标记}。Π_s 严格严于 Π_r，故 actions(Π_s) ⊆ actions(Π_r) ⊆ actions(v9)。SL 扩展 Λ：追加慢变量记录 rec=H(prev‖t‖E_res‖Θ‖I(t)‖B_soc‖v_w‖event)，块边界批量写，每 C_w=64 块链头校验。

**新增定义 561（语义-社会交叉校验）** 若某块 ζ 发生社会影响异常（I 某维突增且可归因于 ζ），而该块执行期 sup ν̄ ≤ τ_sem（语义守卫未响），则记为一次**静默语义故障**并写入 SL。窗口 W 内 N_silent ≥ N_silent,max ⇒ 触发 τ_sem 下修重标定 + 进入 Π_s，直至重标定通过（E600）。此为**滞后**通道：不提供单次实时保护，只**有界系统性伤害持续时间**。

# IP-361 EnergyGovernor：能量治理器（慢变量 → 证书条件）
class EnergyGovernor:
    def __init__(self, E_reserve=0.08, E_min=0.20, E_floor=0.05,
                 kappa_E=1.0, kappa_T=0.5, lam_E=0.5, lam_T=0.3,
                 Theta_nom=45.0, Theta_throttle=70.0, P_budget=25.0):
        self.E_reserve, self.E_min, self.E_floor = E_reserve, E_min, E_floor
        self.kE, self.kT, self.lE, self.lT = kappa_E, kappa_T, lam_E, lam_T
        self.Th_nom, self.Th_thr, self.P_budget = Theta_nom, Theta_throttle, P_budget

    def derate(self, S):                                  # 定义 551
        rho_E = clip((self.E_min - S.E_res) / (self.E_min - self.E_floor), 0, 1)
        rho_T = clip((S.Theta - self.Th_nom) / (self.Th_thr - self.Th_nom), 0, 1)
        return rho_E, rho_T

    def brake_dist(self, d_brake, S):                     # 定义 552
        rE, rT = self.derate(S)
        return d_brake * (1 + self.kE * rE + self.kT * rT)

    def beta_inflate(self, beta_stf, S):                  # 定义 552
        rE, rT = self.derate(S)
        return beta_stf + self.lE * rE + self.lT * rT

    def abort_energy(self, chunk):                        # 定义 550（最坏上界）
        T_abort = chunk.worst_abort_duration()
        return (chunk.P_act + chunk.P_comp) * T_abort + chunk.E_hold

    def energy_feasible(self, chunk, S):                  # 定义 553
        if not self.model_fresh():
            return True                                   # 失效 ⇒ 等价 v10 假设（Level-0）
        return (S.E_res - self.abort_energy(chunk) >= self.E_reserve
                and S.Theta <= self.Th_thr)

    def energy_cap_K(self, state, S):                     # 定义 555：只收紧
        K = self.K_max
        while K > 1 and not self.energy_feasible(
                self.estimate_chunk(state, K), S):
            K -= 1
        return K


# IP-362 SocialImpactAccountant：社会影响核算器（外部价值，不自赋）
class SocialImpactAccountant:
    def __init__(self, weights, budgets, caps, ledger,
                 Df_max=0.15, N_silent_max=3, H_I=3600.0, mu=0.05):
        self.w, self.B, self.caps = weights, budgets, caps   # 外部签署（P16）
        self.ledger, self.Df_max = ledger, Df_max
        self.N_silent_max, self.H_I, self.mu = N_silent_max, H_I, mu
        self.N_silent = 0

    def impact_vector(self, obs_window, service_state):     # 定义 556
        I = {
            'acc': service_state.fulfill_rate,
            'dis': obs_window.path_displacement_norm,
            'att': obs_window.attention_intrusion_norm,
            'aco': obs_window.spl_over_ambient_norm,
            'equ': self.fairness_debt(service_state),       # 定义 558
            'tru': obs_window.complaint_or_override_norm,
        }
        return I

    def fairness_debt(self, service_state):                 # 定义 558
        S = service_state.cumulative_per_user
        return max(abs(S[u] - S[v]) for u in S for v in S) / (mean(S) + 1e-9)

    def budget_ok(self, I):                                 # 定义 557
        return all(self.B[j] - I[j] * self.H_I >= 0 for j in I)

    def externality_caps_ok(self, dI):                      # 定义 559：硬帽
        return all(dI[j] <= self.caps[j] for j in dI)

    def score(self, chunk, task_score, dI):                 # 定义 559：字典序
        if not self.externality_caps_ok(dI):
            return None                                     # 严重外部性 ⇒ 拒绝
        return task_score - self.mu * sum(dI[j] * self.w[j] for j in dI)

    def cross_check(self, chunk, surprise_sup, I_anomaly):  # 定义 561：滞后通道
        if I_anomaly and surprise_sup <= self.tau_sem:
            self.N_silent += 1
            self.ledger.append(chunk.id, 'silent_semantic_fault', self.N_silent)
            if self.N_silent >= self.N_silent_max:
                return 'recalibrate_and_shrink'             # τ_sem↓ + Π_s
        return 'ok'

## 4. 推导

**引理 92（能量可行中止保安全且支配 v10）** 设证书要求 E_res−E_abort(ζ) ≥ E_reserve 且 d_brake^E ≥ d_brake（定义 552 单调），则 v10 停车不变式与引理 82 在 d_brake^E 下成立，且中止机动按构造能量可行。证明：E_abort 取块内最远可达点的最坏上界 ⇒ 任一执行点到中止点所需能量 ≤ E_abort；余量 E_reserve 覆盖停驻。d_brake^E ≥ d_brake ⇒ 停车不变式更易满足（保守）。支配性：能量约束只**拒绝**部分候选块（energy_feasible 与 K_E 只缩可行集），不新增任何 v10 不可执行的动作 ⇒ actions(v11) ⊆ actions(v10)。∎

**引理 93（能量/热条件化 β 覆盖）** 若标定（E592/E594）给出降额区上 sup‖F̂_q−F‖ ≤ β_STF + λ_E ρ_E + λ_Θ ρ_Θ 以概率 ≥1−ε 成立，则 v10 引理 87 以 β_STF^E 替换 β_STF 原样成立；且 β_STF^E 关于 (ρ_E,ρ_Θ) 单调非减，能量恢复只回落至 β_STF 下界，永不更低。证明：线性加性膨胀直接代入引理 87 的 A3；单调性由 λ≥0、ρ∈[0,1] 给出。注：此为**证据支撑的膨胀**（实测降额曲线），非任意放大——符合 P15 有据轻量化律。∎

**引理 94（功率感知降级保守卫且保守性单调）** 降级序 σ_E 只卸安全值/瓦特低的模块；G_safe 安全值为 ∞ 永不卸。卸块生成 ⇒ K=1：峰值功耗下降（无 64 候选 rollout）且决策粒度最保守（v10 Level-1/引理 82 覆盖）。故功率稀缺下 actions ⊆ v10(K=1) ⊆ v10，安全单调不降。活性注记：任务完成率可能下降（E595），失败路径为安全停驻 + 披露（v10 兼容中止）。∎

**引理 95（影响核算不自赋价值，P16）** w_I、B_I、caps 均为外部签署数据，机器人评分 score' 是其固定函数；机器人无写权限、无学习通道。故机器人不能提高自身"许可"或放松预算；任何价值变更经外部版本化并写入 SL，可离线追责。价值争议留在治理侧。∎

**引理 96（影响约束保安全支配）** 影响项仅在证书合法块之间作次级排序（定义 559 字典序），硬帽只**拒绝**块、预算越界只触发 Π_s（收缩），分配公平补偿只改变**选哪个合法块**。故 SIA 下执行的动作仍为 v10 证书合法（或更保守）⇒ actions(v11) ⊆ actions(v10) ⊆ actions(v9)。∎

**引理 97（治理账本完整性与缺口自检）** SL 在 Λ 哈希链上追加慢变量记录，κ_h=256 ⇒ 历史删改以 ≥1−2^{−256} 被离线检出；每 C_w=64 块链头校验使在线缺口至多存续 64 块即触发 Π_s；写入摊销 O(1) 且在契约预算内（≤0.1ms/块边界）。证明同 v10 引理 90，记录域扩展不改变链结构。∎

**引理 98（语义-社会交叉校验：v10 风险的独立滞后通道）** 设 (A4) 真实造成人群可观测反应的语义漏检，在时域 H_I 内以正概率使 I(t) 某维越常（E596 构念效度支撑）。则任一"静默语义故障"（ν̄≤τ_sem 但实际显著）在 N_silent,max 次累积或单次严重外部性硬帽下，最迟于 W 窗口内触发 τ_sem 下修重标定 + Π_s，从而**有界**其系统性伤害持续时间。证明：交叉校验对每次 I 异常且 surprise_sup≤τ_sem 记数（定义 561），计数达阈即进入重标定与收缩，收缩集 ⊆ Π_r ⊆ v9。**边界诚实**：该通道是滞后的、代理量驱动的、非实时证书机制——它**不**恢复单次事故前的实时保守性（那仍由 STF 领先检 + β_STF^E 负责），只限制"已漏检系统性伤害"的持续时间并驱动重标定。∎

**引理 99（Π_s 的严格支配与活性）** Π_s ⊇ Π_r ⇒ actions(Π_s) ⊆ actions(Π_r) ⊆ actions(v9)（传递支配）。Π_s 额外项（能量下限、暴露上限、披露）均只收缩或增广审计面，不回灌控制（先执行后写账）。活性：能量硬下限下若不可安全继续，唯一合法动作是安全停驻/返航（v10 兼容中止），任务可完成率下降为已知代价（E595/E605）。∎

## 8. 本轮最大风险

**一句话**：把慢变量估计（能量模型 E_abort、热降额曲线、社会影响代理量）耦合进快安全证书，等于重新引入一个**不可证的强前提**——"能量模型准确、代理量有效"；若 E_abort 在意外地形/负载下被低估，或影响代理量被 Goodhart 化（靠回避人群压低"注意力税"却牺牲可及性），系统会以**指标改善的假象**同时失去能量可行性与真实社会福利，而社会交叉校验是滞后的，无法在单次事故前恢复实时保守性。
