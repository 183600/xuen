# 第 63 轮（承接第 62 轮「ROSE 鲁棒在线场景进化闭环」IP-183~192；灵感循环 II 第 2 轮；本轮灵感：「原型验证」×「强化学习」）

> 第 62 轮 ROSE 把对齐变成在线学习（OLP）、把偏差变成 CVaR 球（WCV+RSC）、把经验变成场景银行（SBR+SHC），并自称最大风险是 A72：**RSC 靠执行残差反演物理偏差，若 J_φ 病态或残差被控制回路吸收，球半径 r_t 系统性低估，全部安全保证退化为纸面**。第 63 轮认为这不是一个系数没调好，而是三个结构性缺陷：
> 1. **自证循环（closed-loop identification bias）**：残差 resid_t 由被控系统自身产生。控制器越强，越会把物理偏差"抵消"进零残差里——系统用自己的模型出题、又用自己的控制器判卷，越不健康越显得健康。
> 2. **激励不足（PE 失效）**：被动任务轨迹的回归量高度共线，信息矩阵近奇异；A72 的 σ_J>0 只是假设，不是可设计、可检验的性质。信息不会自己来，必须主动去"问"。
> 3. **没有外部真值**：φ̂ 从未与物理原型（标准件/测力台/计量溯源）对表，sim2real 系统偏差永远在模型内部被自洽地解释掉。
> 4. **保证没被真正攻击过**：「球覆盖」从未被主动证伪；通过测试不等于安全，只说明测试不够强。

## 0. 直觉与动机

**灵感 1（原型验证 → 从"自证"到"他证"）**
直觉：验证必须来自被验证对象之外。两个动作：① **物理黄金原型**（已知摩擦/刚度的标准件、测力台、标定块）定期给出真实 φ 的地面真值，给数字孪生"对表"（计量学的溯源链）；② **保形预测（conformal prediction）**把原型验证残差变成**无分布假设的有限样本覆盖**——不再赌次高斯噪声，而用可交换标定集直接给出 P[φ*∈B]≥1−α。这把 A72 从"信仰"换成"可复核的统计契约"。

**灵感 2（强化学习 → 主动探测即对偶控制）**
直觉：RSC 是被动等残差，但可辨识性是可以主动设计的。把"下一次执行哪个识别原型动作"形式化为**对偶控制（dual control, Feldbaum）**：动作同时承担任务与辨识两职。用 RL 求解：奖励 = 信息增益（局部 D-最优 ½·logdet(I+J_φᵀΣ⁻¹J_φ)）− λ_s·安全代价 − λ_e·任务代价，CVaR 约束。所有探测动作先过第 62 轮 Shield，且受探测占空比与安全包络约束。**A72 的"J_φ 良态"由此从假设变成可设计的 PE 条件**：APEX 显式最大化信息矩阵最小特征值。

**灵感 3（强化学习 → 证伪器）**
直觉：安全声明的强度 = 它经受过的攻击强度。训练**对抗 RL 证伪器** FAR：奖励 = 找到使 K_safe 在 φ* 下违规的 (φ,场景,动作) 或压缩鲁棒裕度 ρ_rob。证伪成功不掩盖，而是扩球/报警/把反例写入原型库。这把"覆盖声明"升级为"红队攻击后仍存活"的可信声明，并给 SBR 一个主动生成最坏情况的上游。

**灵感 4（信念化 → 点估计到后验）**
直觉：φ̂ 是点、r_t 是标量球，但真实不确定性是非对称、多峰的（干摩擦双模态、材料退化）。用粒子滤波维护后验 b_t(φ)，球只是后验的粗投影；RL 在**信念 MDP**上决策，探测奖励=后验熵下降，覆盖=后验可信域的保形校准。这是"强化学习"对 RSC 最深的结构性升级。

**灵感 5（合流 → PROVE）**
PROVE = ROSE + {APEX, BEL, CPQ, PVG, FAR, DCRL, PRB}。闭环：PVG 对表给外部锚 → BEL 更新后验 → CPQ 给无分布覆盖球 → WCV 编译兜底 → APEX 选信息增益最大的安全原型 → FAR 攻击证书 → 反例入 PRB → 回喂 PVG/APEX/MEL-OA。第 62 轮是"偏差驱动半径"，本轮是"**可辨识性驱动探测 + 外部真值驱动校准 + 对抗驱动可信度**"。

## 1. 形式化定义（增量：定义 185–196）

- **定义 185（PROVE 原型验证鲁棒进化闭环）**：PROVE = (ROSE, APEX, BEL, CPQ, PVG, FAR, DCRL, PRB, J_prove)。定位：ROSE 的"可验证化"升级，不推翻任何接口；全部学习/训练只在语义流与后台，实时路径仍零学习写。
- **定义 186（可辨识性与 PE 条件）**：局部线性化 y_t ≈ J_φ·u_t + ε；信息矩阵 M_W = Σ_{t∈W} J_φᵀ Σ_ε⁻¹ J_φ。称窗口 W **γ-持续激励（γ-PE）**，若 λ_min(M_W) ≥ γ。
- **定义 187（APEX 主动原型激励）**：探测策略 π_p: b_t → u_p ∈ 𝒰_probe；奖励 r_p = ΔI(u_p) − λ_s·ℓ_safe(u_p; φ̂, r) − λ_e·cost_task(u_p)；𝒰_probe 为经 Shield 与安全包络认证的原型动作库；探测占空比 Σ 1[probe] ≤ ρ_p·T。
- **定义 188（信息增益）**：ΔI(u) = ½·logdet(I + J_φ(u)ᵀ Σ_ε⁻¹ J_φ(u))（高斯后验互信息）；非线性下用局部线性化或粒子熵降 H(b_t) − E[H(b_{t+1})]。
- **定义 189（BEL 信念状态）**：b_t(φ) ∝ b_{t-1}(φ)·p(resid_t | φ, K_t)，粒子集 {φ_t^{(i)}, w_t^{(i)}}_{i=1}^N；φ̂_t = 加权均值，Σ_t = 加权协方差。
- **定义 190（CPQ 保形覆盖球）**：标定分数 s_i = d(φ_i, φ̂_i)，i∈cal；q̂ = Quantile_{⌈(n+1)(1−α)⌉/n}({s_i})；B_t = {φ: d(φ, φ̂_t) ≤ q̂}。分布漂移下用加权保形：w_i ∝ p_deploy/p_cal，取加权分位数。
- **定义 191（PVG 原型验证门）**：物理原型集 G = {g_j}，测量 y_j^phys 与模型预测 y_j^model(φ̂)，验证残差 e_j = y_j^phys − y_j^model。门控 Valid_pvg ⇔ 保形覆盖检验通过 ∧ e_j 无显著趋势；失败则触发 BEL 重标定与球重算。
- **定义 192（FAR 证伪强化学习）**：对手策略 π_f: (b_t, K_safe) → (φ_attack, scenario)；奖励 r_f = 1[ℓ(K_safe;φ_attack)>ℓ_lim] + μ·(ρ_rob⁰−ρ_rob(φ_attack))/ρ_rob⁰；成功反例写入 PRB 并膨胀 r_t。
- **定义 193（DCRL 对偶控制鲁棒策略）**：信念 MDP (ℬ, 𝒜, P, r, γ_d)，策略 π_d: b → a ∈ {task_action, request_probe}；max_π E[Σ_t r_t] s.t. CVaR_ε[ℓ(K;φ)] ≤ η_safe；拉格朗日/约束策略优化求解，策略冻结后部署。
- **定义 194（PRB 原型回放库）**：PRB = PRB_phys ∪ PRB_falsify ∪ PRB_incident，带 φ 标签与来源；供 MEL-OA 回放、FAR 初始化、APEX 价值估计。
- **定义 195（PROVE 证书 J_prove）**：J_prove = (J_rose, γ_PE, q̂_CPQ, pvg_hash, far_survived, probe_duty, dcrl_ver)。Valid ⇔ Valid(J_rose) ∧ λ_min(M_W)≥γ ∧ CPQ 覆盖检验通过 ∧ PVG 通过 ∧ FAR 在 ε_adv 预算内未发现漏洞。
- **定义 196（PROVE 闭环算子）**：语义流 [PVG 对表 → BEL 更新 → CPQ 球 → ARA 提交 → Shield(含探测动作) → APEX 计划 → OLP/WCV/MEL-OA 更新 → PRB 记账]；后台 [FAR 红队 → DCRL 训练]；实时流 [锚点读 → OLP 前向 → WCV 编译 → 派发]，零学习写。

## 2. 关键算法骨架（完整伪代码见产物区）

```python
# 1) 原型验证 → 后验 → 无分布覆盖（语义流，低频）
y_phys = pvg.measure(phi_true_prototypes)          # 物理黄金原型对表
b = bel.update(y_phys, resid)                       # 粒子滤波后验

# 2) 信息驱动探测（后台训练，语义流冻结执行）
u_p = apex.argmax(b, candidates=shield.filter(U_probe))   # 安全原型中最增信息者
# 3) 红队证伪（后台）
phi_adv = far.attack(K_safe, B)                     # 找违规 φ / 场景
if far.violates(phi_adv): prb.add(phi_adv); r = expand(B)
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **命题 1（可辨识性替代 A72）**：若窗口 W 满足 λ_min(M_W)≥γ，则最小二乘误差 ‖φ̂−φ*‖ ≤ ‖Σ_ε^{-1/2}·resid‖/γ。J_φ 病态不再是"运气"，而是可被 APEX 设计排除的条件。
- **定理 1（无分布有限样本覆盖）**：标定集与部署样本可交换时，P[d(φ*,φ̂) ≤ q̂] ≥ 1−α（有限 n，无高斯假设）；协变量漂移下加权保形给出同样的边际覆盖（权重需已知或可估）。
- **命题 2（探测安全）**：𝒰_probe 经 Shield 与安全包络认证 ⇒ 探测期间安全违规率 = 0（机制保证，继承第 62 轮）。
- **命题 3（信息增益的近似次模性）**：ΔI 对探测集合近似次模 ⇒ 预算约束下贪心达到 (1−1/e) 近似；APEX 用贪心/UCB 实现。
- **命题 4（证伪强度）**：证书可信度随 FAR 搜索覆盖 ε_adv 单调；未发现漏洞只保证"在 ε_adv 网内无漏洞"，不保证全局——必须显式报告残余风险。
- **实时性**：所有 RL 训练与探测规划在语义流/后台；实时流仍只读锚点 + 前向 + WCV，保持 ≤1ms（A75）。

## 2. 形式化定义（完整版）

**定义 185（PROVE 原型验证鲁棒进化闭环）** PROVE 是 ROSE 的"可验证化"升级：保留 OLP/WCV/RSC/ARA/SBR/SHC/MEL-OA/Shield/OCB 全部接口，新增 APEX、BEL、CPQ、PVG、FAR、DCRL、PRB 七个组件与 J_prove 证书。不变式：**全部学习、探测规划与红队训练只发生在语义流或后台；实时路径只做锚点原子读 + OLP 前向 + WCV 编译 + 派发（零学习写）**。

**定义 186（可辨识性与 PE 条件）** 设观测局部线性化 y_t = J_φ(φ̂_t, K_t)·u_t + ε_t，ε_t ~ (0, Σ_ε)。窗口 W 的信息矩阵 M_W = Σ_{t∈W} J_φᵀ Σ_ε⁻¹ J_φ。称 W 满足 γ-持续激励（γ-PE），若 λ_min(M_W) ≥ γ > 0。PE 是"J_φ⁺ 可用"的可检验替代：它由探测轨迹设计，而非由物理运气保证。

**定义 187（APEX 主动原型激励）** 原型动作库 𝒰_probe = {小幅扫频 chirp、已知标准件按压、自由空间质量辨识摆、小幅旋转抖动、接触刚度阶跃…}，每个 u 经安全包络与 Shield 双重认证。APEX 在信念 b_t 下选择
u_p = argmax_{u∈𝒰_probe} [ ΔI(u) − λ_s·LCVaR_{ε}(ℓ_probe(u); b_t) − λ_e·cost_task(u) ]，
受占空比约束 Σ_{τ≤t} 1[probe_τ] ≤ ρ_p·t。ΔI 用局部 D-最优近似或粒子熵降估计；跨原型类型用 UCB 平衡估计误差。

**定义 188（信息增益）** 对高斯后验 φ ~ N(μ, Σ_φ)、观测 y = h(φ)+ε、ε~N(0,Σ_ε)，互信息
I(φ;y|u) = ½·logdet(I + Σ_ε^{-1/2} J_φ Σ_φ J_φᵀ Σ_ε^{-1/2})。
当 Σ_φ 各向同性或做归一化时近似为 ΔI(u) = ½·logdet(I + J_φ(u)ᵀ Σ_ε⁻¹ J_φ(u))（D-最优）。非线性/多峰后用粒子熵降 H(b_t) − E_{y}[H(b_{t+1})] 的一步蒙特卡洛估计。

**定义 189（BEL 信念状态）** 后验 b_t(φ) ∝ b_{t-1}(φ)·p(resid_t | φ, K_t)，用粒子滤波维护：粒子按 likelihood 加权，ESS < N/2 时系统重采样，过程噪声按执行模式注入（探测期小、被动期大）。输出 (φ̂_t, Σ_t, 多峰度 κ_mode)，供 CPQ、WCV、APEX、DCRL 消费。

**定义 190（CPQ 保形覆盖球）** 标定集 cal = {(φ_i, φ̂_i, s_i)}（来自 PVG 物理原型与历史证伪样本），s_i = d(φ_i, φ̂_i)（默认 Mahalanobis 距离）。取 q̂ 为 ⌈(n+1)(1−α)⌉/n 经验分位数，则 B_t = {φ : d(φ, φ̂_t) ≤ q̂}。部署分布漂移时用加权保形：权重 w_i ∝ p_deploy(φ_i)/p_cal(φ_i)，q̂ 为加权分位数；无原型可用时退化 r_t = max(q̂, r_RSC)，保证至少不弱于第 62 轮。

**定义 191（PVG 原型验证门）** 物理黄金原型集 G = {g_j}（已知摩擦标准件、测力台、标准刚度弹簧、温控板）。每个周期执行 g_j 并在同一观测口径下比较 y_j^phys 与 y_j^model(φ̂)。门控：
Valid_pvg ⇔ (CPQ 覆盖检验 p_value ≥ α) ∧ (残差趋势检验无显著漂移) ∧ (原型哈希与固件版本匹配)。
失败则触发 BEL 重标定、CPQ 标定集扩充、必要时扩大球并降级任务策略。

**定义 192（FAR 证伪强化学习）** 对手在仿真/数字孪生中训练，观测 (b_t, K_safe)，输出 (φ_attack, scenario_attack)：
max_πf E[ 1[ℓ(K_safe; φ_attack) > ℓ_lim] + μ·(ρ_rob⁰ − ρ_rob(φ_attack))/ρ_rob⁰ ]。
训练采用 RL 全局搜索（SAC/PPO + 域随机化）叠加梯度局部搜索（对 φ 的符号梯度）。发现违规即写入 PRB_falsify 并报警；证书记录 far_survived 与 ε_adv。

**定义 193（DCRL 对偶控制鲁棒策略）** 信念 MDP (ℬ, 𝒜, P, r, γ_d)，𝒜 含任务动作与"请求探测"。优化
max_π E[Σ_t r_t] s.t. CVaR_ε[ℓ(K;φ)] ≤ η_safe，
用拉格朗日乘子/约束策略优化（PPO-Lagrangian）求解；训练在后台，部署时策略冻结。DCRL 决定"何时值得探测"（value of information），APEX 决定"探测哪一个"。

**定义 194（PRB 原型回放库）** PRB = PRB_phys（物理原型对表记录）∪ PRB_falsify（FAR 反例）∪ PRB_incident（SBR 险情）。每条带 φ 标签、来源、K、损失与证书版本。供 MEL-OA 回放、FAR 热启动、APEX 奖励模型估计；回放采样按第 62 轮 SHC 的集群权重 w_c。

**定义 195（PROVE 证书 J_prove）** J_prove = (J_rose, γ_PE, q̂_CPQ, pvg_hash, far_survived, probe_duty, dcrl_ver)。
Valid(J_prove) ⇔ Valid(J_rose) ∧ λ_min(M_W) ≥ γ ∧ CPQ 覆盖检验通过 ∧ Valid_pvg ∧ far_survived(ε_adv) ∧ probe_duty ≤ ρ_p。
证书显式携带 ε_adv：**"在覆盖半径 ε_adv 的对抗搜索内未发现漏洞"**，而不是"全局安全"。

**定义 196（PROVE 闭环算子）** 语义流执行 [PVG 对表 → BEL 更新 → CPQ 球 → ARA 提交 → Shield(DMS/探测) → PE-Gate 检查 → APEX 计划 → 执行回传 → OLP/WCV 更新 → RSC 兜底 → PRB 记账/挖掘 → DCRL 门控]；后台执行 [FAR 红队 → PRB 回归 → DCRL/APEX 训练]；实时流执行 [锚点原子读 → OLP 前向 + Shrink → WCV 编译 → 派发 → J_rose 构建]。

```python
class ActivePrototypeExcitation:
    def __init__(self, U_probe, rho_p=0.05, gamma=GAMMA_PE, lambda_s=2.0):
        self.U, self.rho_p, self.gamma, self.lam_s = U_probe, rho_p, gamma, lambda_s
        self.M = np.zeros((D_PHI, D_PHI))     # 滑动窗口信息矩阵
        self.ucb = {u.id: (0.0, 0.0) for u in U_probe}  # (mean, count)
        self.probe_steps = 0

    def update_info(self, J_phi, Sigma_eps):
        self.M += J_phi.T @ np.linalg.inv(Sigma_eps) @ J_phi
        return np.linalg.eigvalsh(self.M).min()      # λ_min(M_W)

    def identifiability(self):
        return np.linalg.eigvalsh(self.M).min() >= self.gamma

    def plan(self, b, shield, safety_ok, t):
        if self.probe_steps >= self.rho_p * t:       # 占空比硬约束
            return None
        best, best_score = None, -np.inf
        for u in self.U:
            if not (safety_ok(u) and shield.is_safe(u)):   # 安全包络 + Shield
                continue
            dI = info_gain(b, u)                       # 定义 188
            risk = self.lam_s * lcvar_probe(u, b, eps=0.05)
            mean, n = self.ucb[u.id]
            bonus = np.sqrt(2 * np.log(t + 1) / (n + 1))   # UCB 处理估计误差
            score = dI - risk - 0.1 * u.cost + bonus
            if score > best_score: best, best_score = u, score
        return best

    def commit(self, u):
        self.probe_steps += 1
        self.ucb[u.id] = (self.ucb[u.id][0] * self.ucb[u.id][1] + 1,
                          self.ucb[u.id][1] + 1)

def info_gain(b, u):
    J, S = local_jacobian(b.mean, u), b.noise_cov
    return 0.5 * np.linalg.slogdet(np.eye(J.shape[0]) + J.T @ np.linalg.inv(S) @ J)[1]

def lcvar_probe(u, b, eps):
    # 粒子上的尾部均值：最坏 5% 探测损失
    losses = sorted(execution_loss(u, p) for p in b.particles)
    k = max(1, int(eps * len(losses)))
    return np.mean(losses[-k:])
```

### IP-194 BEL（粒子滤波信念）

```python
class BeliefEstimator:
    def __init__(self, N=512, phi_prior=None, rng=np.random.default_rng(0)):
        self.N, self.rng = N, rng
        self.particles = phi_prior.sample(N) if phi_prior else None
        self.w = np.ones(N) / N

    def update(self, resid, K, mode='passive'):
        if self.particles is None: return None
        sigma = SIGMA_PROBE if mode == 'probe' else SIGMA_PASSIVE
        loglik = np.array([-0.5 * np.sum(((resid - predict_resid(p, K)) / sigma) ** 2)
                           for p in self.particles])
        loglik -= loglik.max()
        self.w *= np.exp(loglik)
        self.w /= self.w.sum() + 1e-12
        if 1.0 / np.sum(self.w ** 2) < self.N / 2:      # ESS 过低 → 重采样
            idx = self.rng.choice(self.N, self.N, p=self.w)
            self.particles = self.particles[idx] + self.rng.normal(0, PROCESS_NOISE, (self.N, D_PHI))
            self.w = np.ones(self.N) / self.N
        mean = self.w @ self.particles
        cov = (self.particles - mean).T @ np.diag(self.w) @ (self.particles - mean)
        return Belief(mean=mean, cov=cov, particles=self.particles, w=self.w)

    def entropy(self):
        return -np.sum(self.w * np.log(self.w + 1e-12))
```

### IP-195 CPQ（加权保形覆盖球）

```python
class ConformalCoverageBall:
    def __init__(self, alpha=0.05, metric='mahalanobis'):
        self.alpha, self.metric = alpha, metric
        self.scores, self.weights = [], []

    def calibrate(self, phi_true_list, phi_hat_list, w=None):
        self.scores = [self._d(t, h) for t, h in zip(phi_true_list, phi_hat_list)]
        self.weights = np.ones(len(self.scores)) if w is None else np.asarray(w)

    def _quantile(self, q):
        s = np.asarray(self.scores); w = self.weights / self.weights.sum()
        order = np.argsort(s); s, w = s[order], w[order]
        cw = np.cumsum(w)
        return s[np.searchsorted(cw, q)]

    def radius(self):
        n = len(self.scores)
        # 有限样本修正：should use ceil((n+1)(1-alpha))/n
        q = min(1.0, np.ceil((n + 1) * (1 - self.alpha)) / n)
        return self._quantile(q)

    def covers(self, phi_hat, phi_probe):
        return self._d(phi_probe, phi_hat) <= self.radius()
```

```python
class FalsificationAdversary:
    def __init__(self, env, policy, mu=1.0, eps_adv=0.05):
        self.env, self.pi, self.mu, self.eps = env, policy, mu, eps_adv

    def attack(self, K_safe, ball, budget=2000):
        best = (None, -np.inf)
        # 全局：RL 对手在球与场景空间探索
        for _ in range(budget // 2):
            phi, scen = self.pi.act(self.env.observe())
            loss = self.env.evaluate(K_safe, phi, scen)
            score = float(loss > L_LIM) + self.mu * (RHO0 - margin(K_safe, phi)) / RHO0
            if score > best[1]: best = ((phi, scen), score)
            self.pi.learn(score)
        # 局部：对 φ 的梯度上升精修
        phi = best[0][0] if best[0] else ball.mean
        for _ in range(budget // 2):
            phi = phi + self.eps * grad_loss(K_safe, phi)
            phi = project_to_ball(phi, ball)
            if env.violates(K_safe, phi): return Falsification(phi, violated=True)
        return Falsification(phi, violated=env.violates(K_safe, phi), eps_adv=self.eps)
```

```python
class DualControlRobustPolicy:
    def __init__(self, actor, critic, lagrangian, eta_safe=0.02):
        self.actor, self.critic, self.lam, self.eta = actor, critic, lagrangian, eta_safe

    def act(self, belief, task_ctx):
        a = self.actor(belief, task_ctx)               # 含 request_probe 选项
        if a.type == 'request_probe':
            return ('probe', a)
        return ('task', a)

    def train_step(self, batch):
        # PPO-Lagrangian：任务回报 - λ·(CVaR 估计 - η)
        adv = self.critic.advantage(batch)
        cvar = empirical_cvar(batch.losses, eps=0.05)
        self.lam = max(0.0, self.lam + LR_LAM * (cvar - self.eta))
        loss = -torch.mean(adv * self.actor.logprob(batch)) + self.lam * (cvar - self.eta)
        self.actor.optimize(loss)
```

## 4. 推导

**命题 1（PE ⇒ 参数误差有界，替代 A72）** 设 y_t = J_φ u_t + ε_t，ε_t ~ (0, Σ_ε) 且 E[ε_t]=0。最小二乘估计 φ̂ = M_W⁻¹ Σ_{t∈W} J_φᵀ Σ_ε⁻¹ y_t，误差 φ̂−φ* = M_W⁻¹ Σ_{t∈W} J_φᵀ Σ_ε⁻¹ ε_t。于是
‖φ̂−φ*‖ ≤ ‖M_W⁻¹‖·‖Σ_{t} J_φᵀ Σ_ε⁻¹ ε_t‖ ≤ (1/γ)·‖Σ_ε^{-1/2}·resid‖，
其中用了 λ_min(M_W) ≥ γ ⇒ ‖M_W⁻¹‖ ≤ 1/γ。**可辨识性不再依赖 A72 的"J_φ 恰好良态"，而由 APEX 的探测设计使 M_W 满足 γ-PE。** ∎

**命题 2（可辨识性监控的有效性）** PE-Gate 计算 λ_min(M_W)；当 λ_min < γ 时 APEX 的奖励项 ΔI 与 λ_min 单调相关（D-最优提升 logdet = log Π λ_i，E-最优直接抬升 λ_min），故贪心探测在有限步内把 λ_min 抬过 γ（存在非零激励方向时）。证明用信息矩阵的秩单调性：加入线性无关的 J_φ u 使 rank 增加、最小特征值上升；若所有 u 均与当前零空间正交则不可辨识，此时报告"结构性不可辨识"而非假装安全。∎

**定理 1（无分布有限样本覆盖）** 设标定分数 {s_1,…,s_n} 与部署分数 s_{n+1} 可交换，q̂ 为 ⌈(n+1)(1−α)⌉/n 经验分位数，则
P[s_{n+1} ≤ q̂] ≥ 1−α，
对任意（未知）分布成立，**不要求次高斯、不要求对称、不要求 n→∞**。当部署分布 P_deploy ≠ P_cal 且密度比 w = dP_deploy/dP_cal 已知（或可估）时，加权保形给出
∫ P[s ≤ q̂ | φ] dP_deploy(φ) ≥ 1−α
（Tibshirani 等加权保形）。这把第 62 轮 A72 的"次高斯偏差带 + EWMA"换成可审计的统计契约；若权重不可估，则显式报告该假设为残余风险。∎

**命题 3（探测安全）** 对任意 u ∈ 𝒰_probe，Shield 保证 u ∈ 𝒞_safe(C_exec, φ̂, r) 且安全包络 sup_{φ∈B_t} ℓ(u;φ) ≤ η_probe。因此探测期间安全违规率 ≤ 0 + P[φ*∉B_t] ≤ α（定理 1）。**探测不是"为了学习而冒险"，而是"在已认证安全集内的信息最优动作"。** ∎

**命题 4（信息增益近似次模）** 高斯熵 H(b) = ½logdet(2πeΣ)。观测选择后的熵降 ΔI(S) = ½logdet(I + Σ_ε^{-1/2} J_S Σ_φ J_Sᵀ Σ_ε^{-1/2}) 是集合函数，对高斯过程传感器选择已知为次模（Krause–Guestrin）；在局部线性化下成立。故预算约束下贪心 ≤ (1−1/e)·OPT + UCB 估计误差。APEX 用贪心 + UCB 即得近似最优探测序列。∎

**命题 5（证伪强度与残余项）** 设损失 ℓ(K;φ) 对 φ 为 L-Lipschitz。若 FAR 在 B_t 的 ε_adv-网 𝒩_{ε_adv} 上未发现违规，则对任意 φ∈B_t，ℓ(K;φ) ≤ max_{φ'∈𝒩} ℓ(K;φ') + L·ε_adv ≤ ℓ_lim + L·ε_adv。因此证书结论必须是
**"ρ_rob ≥ −L·ε_adv"**，而非"ρ_rob ≥ 0"。
这显式量化了"未找到 ≠ 不存在"：ε_adv→0 时退化为全局保证，ε_adv 大时保证随之减弱。J_prove 必须携带 ε_adv，否则证书不可复核。∎

**命题 6（双证据合成不弱于 ROSE）** r_t = max(q̂_CPQ, r_RSC)。因两球均以 φ̂_t 为心，max 半径球包含两者；故 P[φ*∈B_t] ≥ max(P_CPQ, P_RSC) ≥ 1−α（只要任一有效）。无原型时 q̂=0 退化为纯 RSC，接口向后兼容。∎

**命题 7（DCRL 约束满足，条件性）** 在约束 MDP 满足 Slater 条件、CVaR 估计无偏且策略类足够表达时，PPO-Lagrangian 收敛到约束问题的 KKT 点，部署策略满足 CVaR_ε[ℓ] ≤ η_safe + O(1/√T)。这是**条件性经验保证**，需 E216 校验；不宣称有限样本硬界。∎

**正确性定理（PROVE-Complete）** 假设 A61–A76（第 62 轮）及：
- **(A77) 探测设计可达 PE**：存在 u∈𝒰_probe 使信息矩阵秩增加；APEX 在预算内使 λ_min(M_W)≥γ（否则显式报告结构性不可辨识）。
- **(A78) 原型可交换/可加权**：PVG 标定集与部署分布可交换，或密度比可估（加权保形）。
- **(A79) 证伪覆盖**：FAR 在 ε_adv-网上的搜索覆盖 B_t，且损失 L-Lipschitz。
- **(A80) 探测安全包络**：𝒰_probe 由 Shield 与安全包络认证，非空；占空比 ≤ρ_p。
- **(A81) 信念一致性**：粒子滤波后验一致，N 足够表达多峰。
- **(A82) 离线训练**：APEX/DCRL/FAR 训练只在后台，部署策略冻结，实时路径零学习写。

则：
1. **偏差可观测（替代 A72）**：λ_min(M_W)≥γ ⇒ ‖φ̂−φ*‖ ≤ ‖Σ_ε^{-1/2}resid‖/γ，RSC 的"病态 J_φ"被探测设计排除或显式报告——第 62 轮单点风险被**条件化**：不是保证永不发生，而是发生时能被检测并降级。
2. **无分布覆盖**：P[φ*∈B_t] ≥ 1−α 有限样本成立，覆盖不再依赖次高斯假设；漂移下由加权保形或显式风险报告处理。
3. **探测安全**：探测期安全违规率 ≤ α，且探测为信息最优；"学习"不再以安全为代价。
4. **可信证伪**：证书强度 = 1 − P[存在 ε_adv-网外漏洞]，且残余项 L·ε_adv 可量化、可审计；"未发现漏洞"不再被误报为"安全"。
5. **闭环可验证**：J_prove 同时记录 PE、CPQ、PVG、FAR、占空比、策略版本——任何一条不满足，证书即失效并触发保守降级。
6. **实时性不变**：实时流仍零学习写、≤1ms（A82/A75）。

## 7. 已知风险

**一句话**：若物理原型的标定集与部署分布不可交换（A78 被 sim2real 协变量漂移破坏），保形覆盖就退化为"有数字、无意义"的半径；更隐蔽的是，FAR 找不到漏洞只证明"攻击不够强"，而非"系统安全"——PROVE 可能把"未被证伪"误读为"已证实"，这是本轮全部可信度论证共同依赖的单点假设。

**次级风险与缓解**：
1. **原型不可得/成本高**：并非每个部署都有计量级原型 → 退化到 max(q̂, r_RSC)，并在 J_prove 中标记 pvg_hash=None、自动降低证书等级（不冒充已验证）。
2. **加权保形的权重不可估**：密度比估计本身有误差 → 用保守上界权重 + 敏感性分析，报告覆盖率的置信下界而非点估计。
3. **探测影响任务/磨损**：占空比与安全包络硬约束；DCRL 的 value-of-information 门控避免过度探测；长期磨损计入 PRB_phys 漂移趋势检验。
4. **FAR 的 RL 训练不稳定/模式坍塌**：RL 全局 + 梯度局部双通道；固定随机种子集与 ε_adv-网覆盖度量；证书显式携带 ε_adv 与搜索预算。
5. **BEL 粒子退化/多峰丢失**：ESS 重采样 + 过程噪声注入 + 多峰度监控；多峰时 CPQ 用混合模型分数而非单球半径。
6. **双学习耦合（OLP/MEL-OA/BEL/DCRL 同时更新）**：分层交替调度（探测期只更新 BEL/APEX，任务期只更新 OLP/MEL-OA），DCRL 与 APEX 训练离线分离，门控联锁防止互相追逐。
7. **PE 提升与安全性张力**：高信息激励可能靠近安全边界 → 安全包络以最坏球损失为约束，宁可牺牲部分信息增益也不越界；E211/E214 校验可辨识-安全权衡曲线。
