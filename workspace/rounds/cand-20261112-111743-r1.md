# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC × IP-153~160；灵感循环第 1 轮；本轮灵感：「伦理与合规」×「差异化定位」）

> 第 60 轮完成了「认知驱动的场景-执行闭环」：SSM 把场景转为阻抗先验、CIEC 把对话意图锁为实时约束、EPIR 用序列号+哈希守住 EV-exec 证据链、SERC 统一三者、PCE++++ 给出四维认知预算。但它仍建立在三个未言明的前提上：
> 1. **认知可错性被当成性能问题，而非伦理问题**：SSM 误判、CIEC 误读时，第 60 轮的处置是「回退通用先验 / 超时释放」——这是可权衡的软处理。真实系统里「人类在场却高速运动」是不可逆伤害，不能与节拍、产能、算力做加减。缺一层**不可交易**的伦理底线。
> 2. **证据完整 ≠ 合规可证**：EPIR 的 seq+hash 只回答「ROS 消息有没有丢、顺序对不对」，不回答「这段历史有没有被改」「执行是否满足某条标准条款」「监控器本身判得对不对」。合规需要三值谓词、跨 episode 的防篡改历史与外部可验证的证书。
> 3. **定位仍停留在性能叙事**：前 60 轮都在「更快/更准/更低延迟」轴上迭代，没有一个可计算判据回答「本架构在哪个坐标轴上是**结构上不可替代**的」。差异化若不能形式化，就退化为包装。

## 0. 直觉与动机

**灵感 1（伦理与合规 → 伦理硬约束 EHC）**
直觉：安全约束和伦理约束不是同一种东西。安全约束通常可以权衡（慢一点、省一点、少探一次），伦理约束不能——「机器人不得在人类在场时以可能致伤的速度运动」不能被更高的产能或更低的时延「买断」。因此不能把伦理塞进同一个标量目标函数，而必须放在**词典序（lexicographic）第一位**：先满足 E_hard，再谈 P/A/E。
关键洞见：第 60 轮的 `'danger'→stop` 只是意图映射表里的一行，理论上仍可被 CIEC 的锁定、PCE 的降级或预算耗尽绕过。本轮把伦理提升为**不可交易、不可降解、不可被预算交换**的约束层 V_E：它在每一次编译之后、每一次降级之后、每一次重新入环之后都被重新施加。

**灵感 2（伦理与合规 → 合规谓词 CAC 与溯源账本 CPL）**
直觉：物理安全是 τ∈Safe；合规是「我能用证据 E 证明 τ⊨s」。二者不等价，且合规是**证据相对**（evidence-relative）的。审计员不看系统「感觉安全」，只问证据能否支撑条款。于是把合规从形容词变成三值谓词 Comp(τ,s,E) ∈ {pass, fail, unknown}，并让 unknown 成为一等状态：unknown 不是错误，而是触发降级的义务。
第 60 轮 EPIR 的 seq+hash 只保证消息级「到达完整」；本轮 CPL 把 EV-exec 串成哈希链 h_i=H(h_{i-1}‖seq_i‖ts_i‖H(EV-exec_i)‖h_I‖h_D)，周期性把 Merkle 根锚定到外部只追加存储。任何修改/删除/重排都会破坏其后所有哈希。
关键洞见：**防篡改（tamper-evidence）不等于真实性（truth-evidence）**。账本只能证明「没被改过」，不能证明「监控器判对了」。这一区分是本轮全部形式化的地基，也是最大风险的来源。

**灵感 3（伦理与合规 → 证据充分性降级 ESD）**
直觉：当合规后验 p=P(τ⊨s|E) 不够高时，正确动作不是乐观放行，而是**预防原则**：证不出来就当作不安全，主动降到「可由构造直接证明安全」的运行域（限速、限力、人机分离、停机）。降级不是失败，而是把「未知」转成「已知安全」的唯一合法手段。
关键洞见：降级等级 ℓ 只应**立即升、迟滞降**——风险上升瞬时响应，风险恢复需连续 H 个周期确认，避免在阈值附近抖动，把一次真实的伦理越界「平均掉」。

**灵感 4（差异化定位 → 差异化前沿定位 DFP）**
直觉：如果继续在「更快/更准/更低延迟」这条拥挤轴上竞争，本架构永远只是「性能 + 一个日志插件」。真正要问的是：**在哪个坐标轴上，基线不是「做得差一点」，而是「结构上做不到」？** 答案是「可证明合规 + 伦理不可交易 + 审计可重建」——因为外挂日志层无法生成**控制回路内生**的证书，也无法让合规成为编译约束的一部分。
把能力写成 c=(comp,P,A,E)：comp 为合规可行性（0/1），P 性能，A 可审计性，E 伦理保证。用**词典序支配**比较：先比 comp，再比 (P,A,E) 的 Pareto 支配。差异化区域 D 就是词典序下不被任何基线支配的点集。定位算子不最大化性能，而最大化**结构差异边际** Δ=α(A−A_b)+β(E−E_b)+γ(comp−comp_b)−δ·max(0,P_b−P)。

**灵感 5（合流 → 合规内生闭环 CECL / 五维预算 / 责任归因 RAT）**
直觉：场景（SSM）→意图（CIEC）→伦理否决（EHC）→阻抗编译（EEIS）→差异化选点（DFP）→执行监控→证书（CAC）→账本（CPL）→证据充分性（ESD）→模态更新（XMC++），形成「合规内生」闭环。预算从四维升为五维，新增 B_comp：审计存储、锚定频率、证书时延、验证带宽。若 B_comp 耗尽，不是「少记一点」，而是**不允许执行无法被证明的行为**（强制 ℓ≥2 或停机）——「不能证明，就不许高速执行」。
同时用责任归因链 RAT 记录每个决策的 agent 角色、输入意图、施加约束与证据引用，并计算控制力 κ(v)；伦理规则「高风险 ∧ 无有意义人类控制（¬MHC）⇒ 禁止自主执行」由 RAT 提供证据基底。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（伦理硬约束 EHC）** 伦理硬约束集 E_hard = {e_1, …, e_k}，每个 e_i : (τ, I) → {0,1} 是轨迹 τ 与意图 I 上的可判定谓词。其诱导的约束区域为
K_{e_i} = { K : ∀τ ∈ Traj(K,I), e_i(τ,I)=1 }。
给定候选约束集 C（C 为参数可行域，越小越保守），伦理否决算子定义为
V_E(C, I) = C ⊓ K_{e_1} ⊓ … ⊓ K_{e_k}，
其中 ⊓ 为约束的交（取更严者）。性质：
- **幂等**：V_E∘V_E = V_E；
- **单调**：C₁ ⊆ C₂ ⇒ V_E(C₁) ⊆ V_E(C₂)；
- **预算不变**：对任意预算向量 b 与任意降级路径，V_E 在每次编译后重新施加，`V_E` 的语义不随 b 改变；
- **不可交易**：目标函数为词典序 `(E_hard, P, A, E)`，不存在标量权重 λ 使「违反 E_hard 换性能」成为最优。
典型条款：`e_human`：人进入工作区 ⇒ v≤0.05 m/s ∧ F≤F_safe（ISO/TS 15066）；`e_danger`：I='danger' ⇒ stop；`e_mhc`：高风险 ∧ ¬MHC ⇒ 禁止自主执行。

**定义 162（合规谓词与可审计证书 CAC）** 给定标准条款集 S={s_1,…,s_M} 与证据 E，合规谓词为三值映射
Comp : (τ, s, E) → {pass, fail, unknown}。
- **可靠性（soundness）**：Comp(τ,s,E)=pass ⇒ τ⊨s；
- **完备性（completeness）**：Comp(τ,s,E)=fail ⇒ τ⊭s；
- **未知义务**：Comp=unknown ⇒ 必须交由 ESD 处理（见定义 165），禁止默认为 pass。
可审计证书 J_comp = (J_exec, Π, r_CPL, r_RAT, sig, t)，其中 Π={(s_j, Comp_j, ev_ref_j)}，ev_ref_j 指向 CPL 条目；r_CPL、r_RAT 分别为账本根与责任归因根；sig 为签发者对 (J_comp 内容, r_CPL, r_RAT) 的签名。
- **不可否认性**：sig 绑定签发身份与时间戳；
- **外部可验证性**：任何持锚定根 R_anchor 的第三方可独立验证 r_CPL 与 sig，无需信任云端。

**定义 163（合规溯源账本 CPL）** 账本链定义为
h_0 = H(genesis)，
h_i = H( h_{i-1} ‖ seq_i ‖ ts_i ‖ H(EV-exec_i) ‖ h_I(i) ‖ h_D(i) )，
其中 h_I、h_D 分别为意图与决策节点的哈希。窗口 W_k 的 Merkle 根 R_k=MerkleRoot({h_i}_{i∈W_k})，每 T_anchor 秒或每 n_max 条锚定到外部只追加存储。
验证：Verify(i, EV-exec_i, π_i, R_anchor) = MerkleVerify(h_i,π_i,R_anchor) ∧ 重算 h_i。
**防篡改定理**：在 H 抗碰撞假设下，对已锚定窗口内任一 EV-exec 的修改/删除/重排，会使 R 改变的概率 ≥ 1−negl(λ)；未锚定窗口只能提供本地链检测。
与 EPIR 的分工：EPIR 管「消息级到达完整」，CPL 管「跨 episode 的历史完整」；二者不互相替代。

**定义 164（差异化前沿定位 DFP）** 能力向量 c=(comp,P,A,E) ∈ {0,1}×[0,1]³，基线集合 B={b_1,…,b_n}。
**词典序支配** ⪰_L：c ⪰_L b 当且仅当
`comp > comp_b`，或 `comp = comp_b` 且 P≥P_b、A≥A_b、E≥E_b（至少一维严格）。
差异化区域 D = { c : ¬∃b∈B, b ⪰_L c }。
**结构差异边际** Δ(c;b)=α(A−A_b)+β(E−E_b)+γ(comp−comp_b)−δ·max(0, P_b−P)，α,β,γ,δ>0。
**定位算子**：在伦理可行且合规可证的候选集内
K* = argmax_{K∈K_adm, Comp=P} Δ(c(K); b*)，要求 Δ>0；否则退化为词典序兜底（先保 comp=1，再最大化 min(A,E,P)）。
**结构性判据**：若 comp=1 且 A、E 由控制回路**内生**（CAC/CPL 在环内生成），则基线无法通过外挂日志层复制该 c——因为其 comp 仍为 0（缺少运行期监控准入），且其证据不参与约束编译。差异化因此是结构性的，而非叙事性的。

**定义 165（证据充分性降级 ESD）** 合规后验 p_t=P(τ⊨s|E_{1:t})，证据不确定性 u_t=1−p_t。
降级阶梯 ℓ∈{0,1,2,3}：D0 正常；D1 证据增强（加密探针/更细日志）；D2 可证明安全域（v、F 限到可直接由遥测验证的信封）；D3 安全停机。
阈值 τ_0>τ_1>τ_2>0，ℓ_t = min{ ℓ : u_t ≤ τ_ℓ }。
- **上升无界**：u_t 增大时 ℓ 立即增大；
- **下降迟滞**：仅当 u_t ≤ τ_{ℓ−1}−η 连续 H 个周期，才允许 ℓ→ℓ−1；
- **预防安全**：u_t>τ_2 ⇒ ℓ=3，即「证不出来 ⇒ 不以该速度执行」；
- **单调性**：u_t 增大 ⇒ ℓ_t 不减。
该定义把「未知」从被动日志状态转成主动安全动作。

**定义 166（五维预算 PCE+++++）** B=(B_scene, B_intent, B_ros, B_exec, B_comp)，其中
B_comp=(S_audit, R_anchor, L_cert, W_verify)，
cost_comp=λ_S·Storage + λ_R/T_anchor + λ_L·L_cert + λ_W·W_verify。
**预算-合规耦合规则**：若 B_comp 耗尽 ⇒ policy='provable_only' ⇒ 强制 ℓ_t≥2；若当前 ℓ<2，则必须把执行压到 D2 或 D3 后才允许继续。「不能证明，就不许高速执行」。
单调消耗、非负；任一维耗尽触发其对应安全策略，且 B_comp 的耗尽**不得**通过放弃 E_hard 或降低 Comp 要求来缓解。

**定义 167（合规内生闭环 CECL）** 算子 CECL(M, z, I, δ_f_req)：
```
① z ← SSM.update(telemetry)                       # 场景语义
② C_I ← ϕ_intent→constraint(I); ERTC.lock(C_I)     # 认知意图约束
③ C_E ← V_E(C_I ⊓ EEIS.scene_prior(z,δ_f_req), I)  # 伦理否决（只收紧）
④ C_c ← EEIS.compile(C_E) with postcondition Comp ∈ {pass, unknown}
⑤ K* ← DFP.position(C_c)                           # 差异化选点（在 EHC 域内）
⑥ (τ, EV-exec) ← Execute(K*; runtime_monitor)
⑦ J_comp ← CAC.certify(EV-exec, CPL.root(), RAT.root())
⑧ h ← CPL.append(EV-exec, H(I), H(K*.decision))
⑨ u ← ESD.posterior(EV-exec); ℓ ← ESD.level(u)
⑩ if ℓ ≥ 2: return CECL(M, z, I, tighten(δ_f_req, ℓ))   # 重新入环，只收缩不放松
⑪ XMC++.update(EV-exec); RAT.record(role, I, K*, EV-exec)
⑫ if CPL.should_anchor(): CPL.anchor(external_store)
⑬ Return (K*, J_comp, ℓ, Δ, CPL.status(), RAT.root())
```
三条不变量：(i) ③ 之后 ④⑤⑩ 任一重入都只能收紧约束，`K* ⊆ V_E(·)` 永远成立；(ii) ⑦⑧⑨ 的证据生产与执行同周期发生，不做事后补记；(iii) ⑩ 的降级不以牺牲 E_hard 为代价。

**定义 168（责任归因链 RAT）** 归因 DAG G_R=(V_R,E_R)，节点 v=(role, input_intent, applied_constraint, evidence_ref, ts)，role∈{human, planner, learned_policy, executor, veto_layer}。
- **因果边**：v→w 当且仅当 v 的输出落在 w 的输入支撑集内；
- **归因集**：事件 φ 的归因 A(φ)={v : v 位于某条到 φ 的因果路径上}；
- **控制力**：κ(v)=P(φ 不发生 | do(移除 v 的决策))，用反事实估计；
- **有意义人类控制**：MHC = ∃h∈A(φ)，role(h)=human ∧ ts(h)<ts(exec) ∧ κ(h)≥θ_h；
- **伦理规则**：high_risk ∧ ¬MHC ⇒ e_mhc ∈ E_hard 触发，禁止自主执行。
RAT 不是可选日志，而是 `e_mhc` 的证据基底：没有可重建的归因链，就不能声称「人在环上」。

### IP-161 EHC（伦理硬约束层）

```python
class EthicalHardConstraintLayer:
    def __init__(self, clauses):
        self.clauses = clauses  # 每个 clause 提供 tighten(C) -> C'

    def veto(self, C, intent):
        C_out = C
        for e in self.clauses:
            if e.applicable(intent, C_out):
                C_out = e.tighten(C_out)   # 只取交集，绝不放松
        return C_out

    def contains(self, C, intent):
        return self.veto(C, intent) == C   # 用于准入断言
```

### IP-162 CAC（合规证书）

```python
class ComplianceCertificateAuthority:
    def __init__(self, monitor, signer, standards):
        self.monitor = monitor
        self.signer = signer
        self.standards = standards

    def certify(self, ev_exec, cpl_root, rat_root):
        portfolio = []
        for s in self.standards:
            verdict = self.monitor.verify(ev_exec, s)   # pass / fail / unknown
            portfolio.append((s.id, verdict, ev_exec.evidence_ref))
        content = CertificateContent(
            exec_ref=ev_exec.id, portfolio=portfolio,
            cpl_root=cpl_root, rat_root=rat_root, ts=now())
        sig = self.signer.sign(content.digest())
        return JComp(content, sig)

    def third_party_verify(self, jc, anchor_root):
        return (self.signer.verify(jc.sig, jc.content.digest())
                and merkle_verify_root(jc.content.cpl_root, anchor_root))
```

### IP-163 CPL（合规溯源账本）

```python
class ComplianceProvenanceLedger:
    def __init__(self, genesis):
        self.chain = [sha256(genesis)]
        self.pending = []
        self.seq = 0

    def append(self, ev_exec, intent_hash, decision_hash):
        self.seq += 1
        prev = self.chain[-1]
        h = sha256(prev + encode(self.seq) + encode(now())
                   + sha256(ev_exec) + intent_hash + decision_hash)
        self.chain.append(h)
        self.pending.append(h)
        return h

    def anchor(self, external_store):
        root = merkle_root(self.pending)
        external_store.append(root)       # 只追加
        self.pending = []
        return root

    def verify(self, i, ev_exec, proof, anchor_root):
        if not merkle_verify(self.chain[i], proof, anchor_root):
            return False
        return recompute_chain(i) == self.chain[i]
```

### IP-164 DFP（差异化前沿定位）

```python
class DifferentiationPositioner:
    def __init__(self, alpha, beta, gamma, delta, baseline):
        self.a, self.b, self.g, self.d, self.base = alpha, beta, gamma, delta, baseline

    def margin(self, c):
        b = self.base
        return (self.a * (c.A - b.A) + self.b * (c.E - b.E)
                + self.g * (c.comp - b.comp)
                - self.d * max(0.0, b.P - c.P))

    def position(self, candidates):
        feasible = [c for c in candidates if c.comp == 1 and c.eth_admissible]
        if not feasible:
            return None
        best = max(feasible, key=self.margin)
        if self.margin(best) > 0:
            return best
        return min(feasible, key=lambda c: (-c.comp, -min(c.A, c.E, c.P)))
```

### IP-165 ESD（证据充分性降级）

```python
class EvidentialSufficiencyGovernor:
    def __init__(self, tau=(0.05, 0.02, 0.005), eta=0.01, H=3):
        self.tau, self.eta, self.H = tau, eta, H
        self.recover_count = 0

    def level(self, u_t, prev_level):
        l = prev_level
        while l < 3 and u_t > self.tau[l]:   # 立即升
            l += 1
        if l > 0 and u_t <= self.tau[l - 1] - self.eta:
            self.recover_count += 1
            if self.recover_count >= self.H:  # 迟滞降
                l -= 1
                self.recover_count = 0
        else:
            self.recover_count = 0
        return l
```

### IP-166 PCE+++++（五维预算）

```python
class FiveBudget:
    def __init__(self, scene, intent, ros, exec_budget, comp):
        self.B_scene, self.B_intent = scene, intent
        self.B_ros, self.B_exec, self.B_comp = ros, exec_budget, comp

    def compliance_policy(self):
        if self.B_comp.is_exhausted():
            return 'provable_only'   # 强制 ESD 等级 >= 2
        return 'normal'

    def admit(self, esd_level):
        if self.compliance_policy() == 'provable_only' and esd_level < 2:
            return False             # 不能证明 => 不许高速执行
        return True
```

### IP-167 CECL（合规内生闭环）

```python
def compliance_embedded_loop(M, z, intent, delta_f_req):
    z = M.scene_model.update(M.telem_force, M.telem_pos)
    c_intent = M.intent_ctrl.receive_intent(intent)
    C_E = M.ehc.veto(M.eeis.scene_prior(z, delta_f_req) & c_intent, intent)
    c_star = M.dfp.position(M.eeis.enumerate(C_E))
    if c_star is None:
```

**正确性定理（CGEC）** 假设：
**(A66)** E_hard 谓词在观测窗口上可判定，且对 ⊓ 封闭；V_E 幂等、单调。

**(A69)** 基线能力向量 b 与 c 在同一任务分布上测量；A,P,E 有界。

1. **伦理不可交易性**：对任意预算 b 与任意降级/重入路径，最终 K*⊆V_E(·)；不存在标量权重使「违反 E_hard 换性能」成为最优（由词典序目标与 V_E 预算不变性）。
2. **合规可证性**：若 Comp=pass 则 τ⊨s；若 Comp=unknown 则必然进入 ESD 且 ℓ≥1（不默认放行）。
3. **历史防篡改**：任何已锚定 EV-exec 的修改/删除/重排，检测概率 ≥1−negl(λ)（由抗碰撞哈希链与 Merkle 根）。

```python
class EthicalHardConstraintLayer:
    def __init__(self, clauses):
        self.clauses = clauses  # clause.tighten(C) -> C' 且 C' ⊆ C

    def veto(self, C, intent):
        C_out = C
        for e in self.clauses:
            if e.applicable(intent, C_out):
                C_out = e.tighten(C_out)   # 只取交集，绝不放松
        return C_out

    def contains(self, C, intent):
        return self.veto(C, intent) == C   # 准入断言
```

```python
class ComplianceProvenanceLedger:
    def __init__(self, genesis):
        self.chain = [sha256(genesis)]
        self.pending = []
        self.seq = 0

    def append(self, ev_exec, intent_hash, decision_hash):
        self.seq += 1
        h = sha256(self.chain[-1] + encode(self.seq) + encode(now())
                   + sha256(ev_exec) + intent_hash + decision_hash)
        self.chain.append(h)
        self.pending.append(h)
        return h

    def anchor(self, external_store):
        root = merkle_root(self.pending)
        external_store.append(root)         # 只追加
        self.pending = []
        return root

    def verify(self, i, ev_exec, proof, anchor_root):
        return (merkle_verify(self.chain[i], proof, anchor_root)
                and recompute_chain(i) == self.chain[i])
```

### IP-164 DFP（差异化前沿定位）

```python
class DifferentiationPositioner:
    def __init__(self, alpha, beta, gamma, delta, baseline):
        self.a, self.b, self.g, self.d, self.base = alpha, beta, gamma, delta, baseline

    def margin(self, c):
        b = self.base
        return (self.a * (c.A - b.A) + self.b * (c.E - b.E)
                + self.g * (c.comp - b.comp)
                - self.d * max(0.0, b.P - c.P))

    def position(self, candidates):
        feasible = [c for c in candidates if c.comp == 1 and c.eth_admissible]
        if not feasible:
            return None
        best = max(feasible, key=self.margin)
        if self.margin(best) > 0:
            return best
        return min(feasible, key=lambda c: (-c.comp, -min(c.A, c.E, c.P)))
```

### IP-165 ESD（证据充分性降级）

```python
class EvidentialSufficiencyGovernor:
    def __init__(self, tau=(0.05, 0.02, 0.005), eta=0.01, H=3):
        self.tau, self.eta, self.H = tau, eta, H
        self.recover_count = 0

    def level(self, u_t, prev_level):
        l = prev_level
        while l < 3 and u_t > self.tau[l]:    # 立即升
            l += 1
        if l > 0 and u_t <= self.tau[l - 1] - self.eta:
            self.recover_count += 1
            if self.recover_count >= self.H:  # 迟滞降
                l -= 1
                self.recover_count = 0
        else:
            self.recover_count = 0
        return l
```

- `V_E∘V_E=V_E` 与 `C₁⊆C₂ ⇒ V_E(C₁)⊆V_E(C₂)` 保证重入闭环不会把约束放松；
- 词典序支配的第一个坐标 comp 使「基线只优化 P」无法改变支配关系，从而给出「结构性差异化」的充分条件；
- Merkle 根的外部锚定把「防篡改」从本地信任域提升到第三方可验证，但**不提供真实性**（见风险）。

## 5. 本轮最大风险

**一句话**：最大风险是「自证合规」——CPL 只能证明账本未被篡改，不能证明监控器本身判对了；若监控器、签发者与审计标准共享同一信任根，系统会把「一致性」误当「真实性」，在差异化叙事下演化为一个逻辑自洽却与现实脱节的合规剧场。
