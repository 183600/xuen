# 第 70 轮（承接第 69 轮「FLUID-RAS」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「手势识别」×「真实世界泛化」）

> R69 把不确定性一分为二（aleatoric / epistemic），用「流匹配多模态策略 + 主动交互」去消解 epistemic：问一句、看一眼、触一下。但 R69 埋了一个从未言明的前提——**意图的字典是封闭且平稳的**。它的「模态身份 M」是一个固定的小集合：绕左/绕右、接住/避让、开心/紧张。R69 的 VoI 只会回答「**已知几选一**」，却永远不会问「**我的选项里根本没有正确答案，怎么办**」。
>
> 「手势识别」正是一台专门打穿这个前提的机器：真实手势是**开放词表**的（人随时可能比一个你没见过的姿势）、**指示性**的（同一个指向，指的对象不同则意思不同）、**个体化**的（方言、习惯、残障适配的替代手势）、**文化相对**的（竖拇指在多数地方是"赞"，在少数地方是冒犯）、**连续流**的（要分割、有共发音）。「真实世界泛化」则把问题钉死：实验室里 20 名被试、固定机位、20 类数据集，到野外是上千用户、多传感器、长尾开放词表、跨视角/光照/遮挡/设备/文化——**测试集不只是输入分布挪了一点，而是"输入到含义的映射本身变了"**。
>
> 核心命题：**R69 处理的是"已知假设空间里的不确定性"；R70 必须处理"假设空间本身是否够用"的不确定性**。为此引入第三类不确定性 **U_open（本体层 / 开放世界）**：真意图不在当前词表里，或其语义已漂移。核心纪律：**永不把 U_open 静默塞进最近的已知类**——因为"反向含义"的手势与"含义相近"的手势在输入空间几乎不可分，而代价可以无界。命名 **GRACE-RAS**（Gesture Real-world Adaptation with Conformal Epistemics）。
>
> 一句话定位：R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我甚至不知道该问什么——我的词典够用吗**」。

## 0. 直觉与动机

**灵感 1（手势是"开放、指示、文化相对"的交流动作）**
直觉：把手势当成"第 K 类"来分类，从第一步就错了。手势至少四类：指示性（point，必须接一个世界指称）、图示性（用手描摹动作）、规约性/象征性（thumbs-up，词义依文化而变）、节律性（打拍子，调节交互）。指示性手势的意义根本不在手上，而在"指向哪个物体"；象征性手势的意义根本不在轨迹上，而在"这群人约定它是什么"。所以手势识别不是 pattern classification，而是 **grounding**：把物理动作接到"共享世界里的指称 + 共享语言里的词义"上。这正是"真实世界泛化"最难的所在——世界和语言都会变。

**灵感 2（真实世界泛化不是协变量微扰，而是语义映射漂移）**
直觉：常规泛化担心 p(X) 变了（光照、视角、设备）。但手势的要命之处是 **p(Y|X) 也会变**：同一个竖拇指，换个文化就从"赞"变"辱"；同一个划过喉咙的手势，换个用户从"停"变"我嗓子疼"。这类漂移**几乎不动 p(X)**，任何只盯输入的 OOD/新颖性检测都会瞎。这给了本轮最重要的判断：**能靠分布偏移检出的"未知"是简单的；检不出的"语义重标定"才是真威胁。**

**灵感 3（三级不确定性：aleatoric / epistemic / open）**
直觉：R68 的 U 是 aleatoric（噪声，收紧）；R69 的 U_epi 是已知模态间的歧义（问一句能解决）；新增的 U_open 是"字典外 / 语义漂移"——**它不是"选哪个"，而是"根本没有这个选项"**。三者处置完全不同：
- U_ale → 收紧（问不出来）；
- U_epi → R69 的 VoI 交互（问一句能解决）；
- U_open → **不能进 VoI**（VoI 是在已知 M 上算熵，若真值不在 M 里，熵算得再准也是错的），必须走"注册 / 澄清 / 保守"协议。
把 U_open 混进 U_epi 是 R70 绝不能犯的错：那等于"在一本缺页的词典里自信地查一个词"。

**灵感 4（conformal 作为外生的语义第二意见）**
直觉：R69 有个漂亮结构——FMA 用"动作似然"给"传感器标定"提供一条**不能被告密方吸收**的第二意见。R70 正好有它的镜像：**conformal prediction** 给"模型自己的模态置信度"提供一条**不依赖模型自校准**的第二意见。共形只用一份校准集和一个非一致性分数，就能给出**分布无关的覆盖保证**，并把输出变成三态：预测集为空=新颖、含多个=歧义、只含一个=自信。空/多/单 完美对接 U_open / U_epi / 可用。这让"不确定性"第一次有了**外生的、可证明的**语义侧审计，而不是只信网络自己的 softmax 或 R69 的 ECE。

**灵感 5（泛化失败应"退化为安全"，而非"自信地犯错"——本轮核心安全姿态）**
直觉：conformal 最妙之处在于安全方向天然对齐：当测试群体没有校准数据（新用户、新域），覆盖保证失效，我们唯一能做的正确动作是**把预测集加宽**——集合加宽就更容易变空或多，于是系统更倾向弃权/提问。也就是说，**"泛化能力不足"只会让系统更保守，而不会让它更自信地出错**。这与"ECE 越界即退回保守"（R69 的 MCG）同一种哲学，但更强：共形给的是**结构性的**安全退化，不是统计平均意义上的。唯一例外——也正是本轮最大的风险——是语义一致的重标定（见灵感 6 与引理 22）。

**灵感 6（循环一致只能抓"不一致的漂移"，抓不到"一致的错"）**
直觉：一个自然廉价的漂移探针是**双向循环一致**：把识别出的意图再"渲染/比划"回手势，与原手势比对；对不上即模型内部自相矛盾（大概是漂移或新颖）。但要命的是：**若模型一致地错**——它把竖拇指稳定读成"停"、又稳定把"停"比划成竖拇指——循环完美闭合，探针完全失效。所以 SDP 必须两段式：循环一致（免费，抓不自洽）+ **主动注册探询**（花预算，问真值，抓自洽的错）。而"用预算问真值"这件事，恰被 R69 的交互预算和"别打扰人"的保守性压着——这就是本轮风险的种子。

## 1. 形式化定义（增量：定义 310–327）

**定义 310（GRACE-RAS 总览）** GRACE-RAS = (OVG, CND, CFG, DRG, SDP, OAP, GAC, RAS-WM†)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i；CFG 只写情景原型缓存，不改权重）；
(ii) **永不静默误接地**：预测集为空（新颖）、指称缺失、或漂移可疑时，禁止在已知模态中选一执行；
(iii) **外生证据优先**：conformal 覆盖与循环一致是独立于模型自校准的通道，二者任一报警即降级；
(iv) **泛化失败→保守**：任何群体校准缺失或域散度超阈，只能加宽集合与增大退避，不得提高置信。

**定义 311（手势观测与连续流）** 手势观测 x = {p_t}_{t=1}^{T}，p_t = (关节/手部关键点, 朝向, 速度) 或深度/IMU/雷达特征；连续流先分割并处理共发音得手势段，每段映射为观测 x。附带场景上下文 s（物体、人物、指称候选）与说话人群体标签 g（用于群条件校准）。

**定义 312（开放词表意图的组合语义空间）** 意图 y ∈ 𝒴_open 不预设有限类别，而表示为**语义程序** y = (c_1,…,c_k; r)，其中原语 c_i ∈ 𝒟（共享原语字典：{指、划、握、停、推、示数、否定…} × 修饰 {向、离、快、反复…}），r ∈ ℛ_s ∪ {⊥} 为指称槽（⊥ 表示非指示性）。组合由语法 G 生成候选；|𝒴_open| 随 𝒟 与 G 增长而开放。

**定义 313（OVG 开放词表接地）** 手势编码 f_θ: x ↦ e_x ∈ ℝ^d；意图编码 g_φ: y ↦ e_y ∈ ℝ^d（对任意组合 y 在线编码，无固定分类头）；相似度 s(x,y)=cos(e_x,e_y)。朴素接地是 argmax_{y∈𝒴_open} s(x,y)，但 R70 不直接取 argmax——取 argmax 正是"在缺页词典里硬查"。

**定义 314（三级不确定性分解）**
- U_ale：已知模态内不可约噪声（R69 定义 297，来自流策略模态内协方差）；
- U_epi：**与 conformal 预测集一致**的已知模态间歧义（R69 模态熵，限制在 C(x) 内）；
- U_open = ψ(1 − 𝟙[真值∈候选词表], margin) 的单调打分，操作化为三重证据：预测集为空、指称无解、语义漂移可疑。任一为真 ⇒ U_open > 0。语义：**当前假设空间可能不含真值**。

**定义 315（共形校准与非一致性分数）** 校准集 D_cal = {(x_i, y_i)}（已知意图的注册手势），非一致性分数 s_i = 1 − s(x_i, y_i)。给定显著性 α，q̂ = Quantile_{⌈(n+1)(1−α)⌉/n}({s_i})。对测试 x，候选集 C(x) = {y ∈ Cand(x) : s(x,y) ≤ q̂}，Cand(x) 为组合语法在预算 B 下生成的候选（或检索库平价 Top-B）。

**定义 316（群条件与加权共形）** 按说话人群体 g（用户/设备/视角/文化域）分组校准得 q̂_g；对未见群体 g*∉G，q̂_{g*} = Inflate(q̂_pool, D̂_div)，Inflate 随估计域散度 D̂_div 单调增。协变量偏移下用似然比权重 w(x)=p_test(x)/p_cal(x) 的**加权分位数** q̂_w 取代 q̂，以在 p(X) 漂移下恢复覆盖。

**定义 317（预测集三态）** state(x) = NOVEL 若 C(x)=∅；AMBIGUOUS 若 |C(x)|>1；CONFIDENT 若 |C(x)|=1。三态分别进入 U_open / U_epi（→R69 MINT）/ 已知路径。

**定义 318（CND 新颖性判据与误报控制）** 仅当 C(x)=∅ 且 nonconformity 超出 q̂ 的裕度 δ_s 超过 τ_nov 时，判 U_open>0。**免责声明（并入引理 19）**：C(x) 非空**不保证** y 正确——若真值是词表外但与某已知词很像，C(x) 会"自信地"包含那个错词；这正是 open-set 假自信，CND 单靠空集无法发现，必须由 DRG/SDP 与主动注册补充。

**定义 319（CFG 组合式少样本接地）** 给定 SDP 采集的支持集 S={(x_j,y_j)}_{j≤J}（重演/澄清得到少量新样例），不更新权重，只做：原语分解 → 在语法 G 上重组候选 → 情景原型 π_y = mean_j e_{x_j}（或模长归一化的 Fréchet 均值）→ 按 s(x,·) 重排 C(x)。关键：**接地自由度是"组合结构"，不是"新类别中心"**，故样本复杂度远低于扁平分类（引理 21）。若不满足组合可分解性（原子性新象征），CFG 拒绝接地并保持 U_open。

**定义 320（DRG 指示性接地）** 指示手势诱导指向锥 cone(x) ⊂ ℝ³；指称候选 𝒪 = {o ∈ 场景 : o ∩ cone ≠ ∅}。r* = argmax_{o∈𝒪} P(o∈cone)·salience(o)。若 𝒪=∅ ⇒ 指称缺失（U_open）；若 |𝒪|>1 或因遮挡导致锥内多目标 ⇒ 指称歧义（U_epi，走"哪一个"问询）。意义：**指示性手势的正确性由世界接地决定，而非由手部轨迹分类决定。**

**定义 321（SDP 语义漂移探针，双向循环一致）** 前向 y_hat = argmax_{y∈C} s(x,y)；逆向 x_hat = Render(e_{y_hat})（由意图嵌入生成规范手势原型）；循环不一致度 c_cycle = d(x, x_hat)（轨迹距离/嵌入距离）。c_cycle > τ_cycle ⇒ **不自洽**漂移可疑。**但**：一致的错（前向稳定错、逆向稳定把错词渲染成同一手势）使 c_cycle ≈ 0——循环一致原理性无法检出（引理 22）。

**定义 322（语义漂移指示量与主动注册探询）** 漂移指示量 D_drift = w_1·Ê[c_cycle] + w_2·CrossGroupDisagreement(p(y|x)) + w_3·(1 − ProbeCoverage)。主动注册探询：在低风险时机、预算内向用户提**语义确认问题**（"你比这个 = 好，还是 = 停？"）或请求**重演**，以花交互预算获取真值 Y。这是唯一能抓"一致的语义重标定"的通道（与 R69 的指称性"问哪一句"不同，这里问的是"这个词什么意思"）。

**定义 323（开放世界弃权-注册协议 OAP）** 当 U_open>0（NOVEL / 指称缺失 / 漂移可疑）：
(a) 若预算允许且动作非高危：执行 CFG 少样本接地 或 SDP 注册探询（须过 R69 定义 293-iii 证据纪律与定义 302 信息动作认证）；
(b) 若接地成功且通过一致性复核：进入已知路径执行，λ 用 resolution bonus；
(c) 否则：**禁止在已知模态中选一**，λ = λ_floor(U_ale + U_epi + U_open_max)，动作退到 R68 最保守（停/缓/最小可逆动作）。
⇒ OAP 是 R69 MINT 的严格扩张：MINT 只在"已知可问"时用；OAP 额外处理"未知/不可问"。

**定义 324（泛化感知证书 GAC）** J_GRACE = (J_FLUID, coverage_gap_g, novel_rate, drift_indicator, cycle_inconsistency_p95, group_divergence_hat, enrollment_budget_used, grace_ver)。Valid ⇔ Valid(J_FLUID) ∧ 覆盖缺口在群内富集不超阈 ∧ (drift_indicator ≤ τ_drift ∨ 已花探询预算锁定) ∧ 无静默误接地。

**定义 325（群覆盖缺口与域散度界）** 群覆盖缺口 Gap_g = |Cov_g − (1−α)|。有限样本下 Gap_g = O(√(log(1/δ)/n_g))；域散度下 ε_test ≤ ε_cal + ½ d_{HΔH}(𝒟_cal,𝒟_test) + λ*（Ben-David 界）。两者共同给出**可审计的"泛化到什么程度、还差多少"**，而非一个不可解释的准确率。

**定义 326（开放世界威胁模型 ℰ_open）** 手势冒充（模仿他人做高危指令）、跨文化冒犯/欺诈（恶意利用文化歧义）、指示诱骗（指向诱饵物体使机器人误操作）、语义投毒（注册阶段喂错误标签污染 q̂_g）、新颖性洪水（持续喂词表外手势耗尽询问预算）。并入 AIC：ℰ_GRACE = ℰ_FLUID × ℰ_open。

**定义 327（安全耦合与分级退避）** 手势通道是**建议**而非**命令**：任何由手势触发的任务动作都必须再过 C-RAS-WM 前缀认证（继承 R69 定义 302/定理 17）。分级退避：CONFIDENT→正常；AMBIGUOUS→R69 VoI；NOVEL/漂移→OAP；OAP 失败→R68 最保守。λ 沿该链单调不降。

```python
# IP-264 OVG：开放词表组合接地
class OpenVocabGrounder:
    def embed_gesture(self, x):  return self.f_theta(make_features(x))   # 骨架/深度/IMU
    def embed_intent(self, y):   return self.g_phi(y)                    # 任意组合，无固定头
    def sim(self, x, y):         return cos(self.embed_gesture(x), self.embed_intent(y))

# IP-265 / IP-271 CND：群条件 + 加权共形，输出三态
class ConformalNovelty:
    def calibrate(self, D_cal):
        for g, data in by_group(D_cal).items():
            sc = [1 - sim(x, y) for x, y in data]
            self.q[g] = quantile(sc, ceil((len(sc)+1)*(1-self.alpha))/len(sc))
        self.q_pool = quantile(all_scores(D_cal), 1-self.alpha)
    def predict_set(self, x, g, div_hat, weights=None):
        q = self.q.get(g, inflate(self.q_pool, div_hat))     # 未见群体→加宽
        cand = composition_candidates(x, budget=B)           # 组合语法候选
        return {y for y in cand if 1 - sim(x, y) <= q}
    def tri_state(self, C):
        return "NOVEL" if not C else ("CONFIDENT" if len(C)==1 else "AMBIGUOUS")

# IP-266 CFG：组合式少样本接地（零权重更新，只写情景原型缓存）
def few_shot_ground(S, x, grammar):
    prims = decompose_primitives(S)                 # 在共享原语字典上分解
    if not composable(prims): return None           # 原子性新象征→拒绝，保持 U_open
    hyps  = grammar.compose(prims)                  # 组合→候选语义程序
    return rank_by_sim(x, hyps)                     # 样本复杂度 ~ O(k log m)，引理 21

# IP-267 DRG：指示性接地
def resolve_referent(x, scene):
    cone = pointing_cone(x)
    cand = [o for o in scene.objects if intersects(o, cone)]
    if not cand:            return None             # 指向"无物" → U_open
    if len(cand) > 1:       return ("AMBIGUOUS", cand)
    return cand[0]

# IP-268 SDP：漂移探针（免费循环一致 + 花费主动注册）
def semantic_drift(x, y_hat, render):
    x_hat = render(embed_intent(y_hat))             # 意图回渲染成手势
    return dist(x, x_hat)                           # 只能抓"不自洽"，见引理 22

def drift_indicator(M, x, y_hat, group):
    c  = semantic_drift(x, y_hat, M.sdp.render)
    dg = M.sdp.cross_group_disagreement(x)
    pc = M.sdp.probe_coverage(group)
    return w1*c + w2*dg + w3*(1 - pc)

# IP-269 OAP + IP-274 GRACE 主闭环（继承 FLUID，仅在假设空间层插入）
def GRACE_RAS_round(M, obs, gesture=None):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    if gesture is None:                             # 无手势通道 → 严格退化 R69
        return FLUID_RAS_round(M, obs)
    C     = M.cnd.predict_set(gesture.x, obs.group, obs.div_hat, obs.shift_w)
    state = M.cnd.tri_state(C)                      # 外生语义第二意见
    r     = M.drg.resolve_referent(gesture.x, obs.scene)
    drift = drift_indicator(M, gesture.x, best(C) if C else None, obs.group)
    open_ = (state == "NOVEL") or (r is None) or (drift > TAU_DRIFT)
    if open_:
        y = M.oap.enroll_or_ask(gesture, obs, M.budget)   # few-shot 重演 / 语义确认
        if y is None:                                      # 预算不足/被投毒/不可信
            U_open = U_open_max
            lam = max(M.efs.risk_scale(...), lam_floor(U_ale + U_epi + U_open))
            return conservative_commit(M, obs, lam)        # 回 R68 最保守
        C = M.cfg.ground(y)                                # 情景原型，零权重更新
    # 已知词表：只把与 conformal 证据一致的模态交给 R69
    modes = M.fmp.sample(o, K=adaptive(len(C)))
    keep  = [k for k in modes if intent(k) in C]
    U_ale, U_epi, modes2, _ = M.aud.decompose(keep)
    g = M.mint.choose_interaction(modes2, o, M.budget) if state == "AMBIGUOUS" else None
    # ... 其余继承 FLUID：风险缩放 / 认证 / 审计
    M.vqa_o.submit_async(gesture, C, state, drift, r)      # 开放世界审计
    return fluid_commit(M, modes2, g, U_ale, U_epi, obs)
```

## 3. 推导

**引理 19（共形新颖性的校准性与 open-set 盲区）** 设 D_cal 与测试点可交换。(a) 对真值 y∈Cand 的点，P(y∉C(x)) ≤ α（边缘覆盖）；(b) 若真值在词表外，P(C(x)=∅) 只有当该手势与所有候选的非一致性都超过 q̂ 时才高；(c) **关键盲区**：若词表外手势与某已知词高度相似，则 C(x) 非空且极可能只含那个错词——conformal 的覆盖命题对"真值不在候选集"的情形**不可证伪**，于是给出"自信的错"。推论：CND 的空集判据只能抓"远离已知"的新颖，抓不到"贴近已知的错"；后者必须靠 DRG（世界接地）、CFG（组合证据）或 SDP（主动问真值）三方之一兜住。**这就是为什么 R70 不能只加一个 conformal 层就收工。**

**引理 20（群覆盖缺口与泛化安全退化）** (a) 对群体 g 的 n_g 个校准点，|Cov_g − (1−α)| ≤ √(log(2/δ)/(2n_g))，故小群体必须 inflate q̂_g；(b) 域散度界 ε_test ≤ ε_cal + ½d_{HΔH}(𝒟_cal,𝒟_test)+λ*。合起来：当群体校准缺失、或 d_{HΔH} 大、或 λ* 大（标号语义不相容），任何有限覆盖保证都无法平移到目标域，正确做法是让 q̂_{g∗}→∞，于是 C(x) 加宽到空或多，系统自动多弃权/多提问。系：**"泛化不够"在本架构里被结构性映射为"更保守"，而非"更自信"**——安全方向天然对齐。

**引理 21（组合式接地的样本复杂度）** 若意图是共享原语字典 𝒟（|𝒟|=m）上深度 k 的组合，且原语含义跨用户/文化共享，则识别其组合结构达到 ε 误差所需样例为 O(k·log(m/δ)/ε²)；对照扁平分类需在 m^k 个意图上区分，样本量指数级。系：手势少样本泛化之所以可能，**不是因为新用户数据少，而是因为原语可复用**；一旦遇到原子性、不可组合的新象征（无共享原语），该保证消失，CFG 必须弃权。这划出了"可泛化/不可泛化"的可证明边界。

**引理 22（语义一致重标定的输入侧不可检性）** 设两世界 𝒲₁, 𝒲₂ 满足 p_{𝒲₁}(X)=p_{𝒲₂}(X) 但 p(Y|X) 不同。任何只依赖 x（或只依赖 p(X)）的检测器 D(x) 在两世界下输出分布相同，故其错误率相同，却对应不同的最优动作；因此**不存在仅凭输入分布就能发现的语义重标定**。循环一致性 c_cycle 依赖模型自身的"意图→手势"渲染，只能发现 p(y|x) 与 p(x|y) 的**不自洽**；若模型一致地学错（或文化一致地不同），c_cycle≈0。推论：**一致的语义漂移只能靠查询真值（主动注册探询）或外部语义先验发现**，而查询消耗预算、且被"少打扰"约束压制——这是本轮唯一无法用算法免费消除的残余风险。

**定理 18（GRACE 严格包含 FLUID-RAS）** 当 (i) 无手势通道，或 (ii) 新颖率=0、群体可交换、无漂移，则 C(x) 以概率 ≥1−α 为单点，OAP 不触发，所有决策与 FLUID-RAS 逐指令相同。由定义 323/327，弃权链上 λ ≥ λ_FLUID。故 R69 是 GRACE 在"封闭、平稳本体 + 不注册"边界上的退化，安全侧不让步。

**定理 19（开放世界弃权安全与无静默误接地）** 在定义 323 的协议（NOVEL/指称缺失/漂移可疑 ⇒ 禁止在已知模态中选一；要么经证据纪律与安全认证完成注册，要么退化 R68 最保守）下，执行不可逆/高代价动作于**被静默误接地**手势的概率 ≤ P(一致语义漂移 ∧ 群体外 ∧ 未花探询预算)·(1 − safety_cert_block)；且漂移可疑时 λ 沿 CONFIDENT→AMBIGUOUS→OAP→R68 链条单调不降 ⇒ 控制连续、无突变（继承 R69 定理 17 的换装不变式）。

## 6. 本轮最大风险

**一句话**：GRACE 把"未知"寄托在**能被输入分布或循环一致性检出**的偏移上，但真实世界最常见的失败是**语义一致的重标定**——同一个手势在另一个用户或文化那里是另一个意思，p(X) 不变、p(Y|X) 翻转，模型甚至自洽地学错（循环闭合、共形覆盖满），系统于是以"已校准"的把握执行**反向含义**；而唯一真正能戳破它的通道（花预算主动问真值）恰恰被 R69 的交互预算与本轮"少打扰"的保守姿态压制——**最危险的不是不知道，而是自洽地知道错了。**

**次级风险与缓解**：
1. **open-set 假自信**（词表外但贴近已知）→ 引理 19(c)；DRG 世界接地 + CFG 组合证据 + SDP 探询三方，任一不足即弃权；
2. **未见群体覆盖失效** → 引理 20；群条件校准 + q̂ 加宽 + 覆盖缺口进证书，泛化失败只许退化不许提置信；
3. **少样本在小群体上失效** → 引理 21 的原子性判据；不可组合即拒绝接地、保持 U_open；
4. **过度弃权/交互疲劳** → 预算调度 + 分级安全动作（最小可逆/可持续等待）+ E311 疲劳曲线；
5. **跨文化冒犯/冒充/投毒** → ℰ_open 对抗训练 + 内容安全（不仅"识别"还要"该不该响应"）+ 语义投毒检测；
6. **循环一致的原理盲区** → 明确其为"只抓不自洽"，把一致漂移列为**不可免费消除**的残余风险，写入证书并要求外部语义先验/主动注册兜底。

## 3. 关键算法伪代码

```python
# IP-264 OVG：开放词表组合接地
class OpenVocabGrounder:
    def embed_gesture(self, x): return self.f_theta(make_features(x))
    def embed_intent(self, y):  return self.g_phi(y)          # 任意组合，无固定头
    def sim(self, x, y):        return cos(self.embed_gesture(x), self.embed_intent(y))

# IP-265/271 CND：群条件 + 加权共形
class ConformalNovelty:
    def calibrate(self, D_cal):
        for g, data in by_group(D_cal).items():
            sc = [1 - sim(x, y) for x, y in data]
            self.q[g] = quantile(sc, ceil((len(sc)+1)*(1-self.alpha))/len(sc))
        self.q_pool = quantile(all_scores(D_cal), 1-self.alpha)
    def predict_set(self, x, g, div_hat, weights=None):
        q = self.q.get(g, inflate(self.q_pool, div_hat))       # 未见群体→加宽
        return {y for y in composition_candidates(x, B)
                if 1 - sim(x, y) <= q}
    def tri_state(self, C):
        return "NOVEL" if not C else ("CONFIDENT" if len(C)==1 else "AMBIGUOUS")

# IP-266 CFG：组合式少样本（零权重更新）
def few_shot_ground(S, x, grammar):
    prims = decompose_primitives(S)
    if not composable(prims): return None                     # 原子性新象征→拒绝
    return rank_by_sim(x, grammar.compose(prims))             # O(k log m)

# IP-267 DRG：指示性接地
def resolve_referent(x, scene):
    cand = [o for o in scene.objects if intersects(o, pointing_cone(x))]
    if not cand:      return None                             # 指向"无物"→U_open
    if len(cand) > 1: return ("AMBIGUOUS", cand)              # →问"哪一个"
    return cand[0]

# IP-268 SDP：循环一致 + 漂移指示
def semantic_drift(x, y_hat, render):
    return dist(x, render(embed_intent(y_hat)))               # 只抓"不自洽"

def drift_indicator(M, x, y_hat, group):
    return (w1*semantic_drift(x, y_hat, M.sdp.render)
            + w2*M.sdp.cross_group_disagreement(x)
            + w3*(1 - M.sdp.probe_coverage(group)))

# IP-269/274 GRACE 主闭环（无手势即严格退化为 FLUID）
def GRACE_RAS_round(M, obs, gesture=None):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    if gesture is None: return FLUID_RAS_round(M, obs)
    C     = M.cnd.predict_set(gesture.x, obs.group, obs.div_hat, obs.shift_w)
    state = M.cnd.tri_state(C)
    r     = M.drg.resolve_referent(gesture.x, obs.scene)
    drift = drift_indicator(M, gesture.x, best(C) if C else None, obs.group)
    if (state == "NOVEL") or (r is None) or (drift > TAU_DRIFT):
        y = M.oap.enroll_or_ask(gesture, obs, M.budget)       # 重演 / 语义确认
        if y is None:
            lam = max(M.efs.risk_scale(...),
                      lam_floor(U_ale + U_epi + U_open_max))
            return conservative_commit(M, obs, lam)           # 回 R68 最保守
        C = M.cfg.ground(y)                                   # 情景原型
    modes = M.fmp.sample(o, K=adaptive(len(C)))
    keep  = [k for k in modes if intent(k) in C]              # 仅留证据一致模态
    U_ale, U_epi, modes2, _ = M.aud.decompose(keep)
    g = M.mint.choose_interaction(modes2, o, M.budget) if state == "AMBIGUOUS" else None
    M.vqa_o.submit_async(gesture, C, state, drift, r)
    return fluid_commit(M, modes2, g, U_ale, U_epi, obs)
```

## 4. 推导

**引理 19（共形校准性与 open-set 盲区）** 可交换下 P(y∉C)≤α（真值在候选集时）；词表外且贴近已知时 C 非空且只含错词，覆盖命题不可证伪 → 自信的错。故空集判据只抓"远离已知"，"贴近已知的错"须靠 DRG/CFG/SDP 兜底。

**引理 20（群覆盖缺口与泛化安全退化）** |Cov_g−(1−α)|≤√(log(2/δ)/(2n_g))；ε_test≤ε_cal+½d_{HΔH}+λ*。群体缺失/大散度/大 λ* ⇒ q̂→∞ ⇒ 集合加宽 ⇒ 多弃权。系：泛化不足被结构性映射为更保守，而非更自信。

**引理 21（组合接地样本复杂度）** 共享原语字典（m）深度 k 组合：O(k log(m/δ)/ε²)，远优于扁平分类的 m^k；原子性不可组合新象征无此保证，CFG 必须弃权——划出可泛化边界。

**引理 22（语义一致重标定的输入侧不可检性）** p(X) 相同、p(Y|X) 不同的两世界，任何只依赖 x 的检测器错误率相同却对应不同最优动作 ⇒ 输入分布无法发现一致重标定；循环一致只抓 p(y|x)/p(x|y) 不自洽，一致地学错时 c_cycle≈0。故一致漂移只能靠主动问真值或外部语义先验，且受预算压制——不可免费消除。

**定理 18（严格包含 FLUID-RAS）** 无手势、或新颖率=0 且可交换无漂移时，C(x) 以 ≥1−α 为单点、OAP 不触发，决策与 FLUID 逐指令相同；弃权链 λ≥λ_FLUID。R69 = GRACE 的"封闭平稳本体 + 不注册"退化。

**定理 19（弃权安全与无静默误接地）** OAP 协议下，不可逆/高代价动作被执行于静默误接地手势的概率 ≤ P(一致语义漂移 ∧ 群体外 ∧ 未花探询预算)·(1−safety_cert_block)；漂移可疑时 λ 沿 CONFIDENT→AMBIGUOUS→OAP→R68 单调不降 ⇒ 控制连续、无突变。

## 7. 本轮最大风险

**一句话**：GRACE 把"未知"寄托在**能被输入分布或循环一致性检出**的偏移上，但真实世界最常见的失败是**语义一致的重标定**——同一手势在另一用户/文化那里是另一个意思，p(X) 不变、p(Y|X) 翻转，模型甚至自洽地学错（循环闭合、共形覆盖满），系统于是以"已校准"的把握执行**反向含义**；而唯一真正能戳破它的通道（花预算主动问真值）恰被 R69 的交互预算与"少打扰"姿态压制——**最危险的不是不知道，而是自洽地知道错了。**

**次级风险与缓解**：open-set 假自信（引理 19c，DRG/CFG/SDP 三方兜底）；未见群体覆盖失效（群条件校准 + q̂ 加宽 + 覆盖缺口入证书）；少样本小群体失效（引理 21 原子性判据，不可组合即弃权）；过度弃权/交互疲劳（预算调度 + 分级安全动作 + E311）；跨文化冒犯/冒充/投毒（ℰ_open 对抗 + 内容安全 + 投毒检测）；循环一致原理盲区（定位为"只抓不自洽"，一致漂移列为不可免费消除的残余风险，由外部语义先验/主动注册兜底）。
