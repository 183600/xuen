# 第 75 轮（承接第 74 轮「SENTGAUGE-RAS 哨兵审计闭环」IP-303~309；本轮灵感：「消融实验」×「用户测试」）

> R74 用 anytime-valid 哨兵把「自信地组合一个错误世界」改造为「诚实地发现并退出错误世界」。但 R71–R74 的整条论证链，仍有两个从未被计量学处理的**证据来源**：
> - **归因证据（消融）**：C1–C4 的「显著更优」全部来自 AB1–AB4。但这些消融是**组件基准式**的（换实现、关模块、跑对比），不是**因果干预式**的。组件共享 SEAL 校准集、共享随机种子、共享仿真环境、共享人类被试；在模块图上，它们有大量**未声明的共同父节点**。于是「组件全绿、组合失败」不是偶然，而是混杂与交互效应的必然：AB 测到的是「谁被换掉了」，不是「安全究竟由谁承载」。更反讽的是，R73 的 ECG 已经是一张因果图、R74 的联合哨兵已经承认隐耦合，但我们从未用它来**设计消融**。
> - **人的证据（用户测试）**：NCM 的再授权、ERVOI 的交互成本、E402–E404 的跨人群校准、R74 的「人类再授权 token」，全部把人放进回路；但人始终只是**成本项**或**开关**，从未被当作一个带不确定度、可校准、可被审计的**证据模态**。R74 最大风险（声明族先验）的最终判据其实落在「SEAL 是否代表真实部署分布」——而真实部署分布里最不稳定、最会适应、也最会欺骗的，就是人。没有用户测试，C4 的外部有效性是空的；没有信任校准，「人类否决」可能是橡皮图章，「人类再授权」可能是自动化偏见。
>
> 本轮两个灵感，是同一种严谨性在两个层面的展开：
> - **消融实验 → CAB（Causal Ablation Binding）**：把消融重新定义为对模块图/ECG 的**合法干预** do(module ← stub / impl′ / EC′)，用后门准则判定可识别性，用传递归约 + 覆盖阵列把 2^|V| 的消融空间压到可执行的最小基，产出与安全证书**正交互补**的**消融证书** J_ABL——安全证书说「若契约成立则安全」，消融证书说「安全由哪条契约承载」。
> - **用户测试 → HEM/HTC（Human Evidence Metrology / Trust Calibration）**：把人变成第一类证据模态——五分量人证据、Human EC、χ_H 反作用通道、行为哨兵、橡皮图章负对照、SEAL-Human。用户测试不是满意度问卷，而是**人的校准程序**：它标定「人能否看见 YELLOW/RED」「依赖是否过度」「再授权是否只是点确认」。
>
> 核心命题：**把 R74 的「诚实地发现并退出错误世界」再推进一步——不仅要知道「系统还安不安全」，还要知道「安全是谁的功劳」以及「对谁安全」。** 把 SENTGAUGE-RAS 升级为 **VALIDGAUGE-RAS**（VALidity-audited, Intervention-based, human-verified evidence metrology）：**归因有效性 × 外部有效性** 双审计。

## 0. 直觉与动机

**灵感 1（消融实验 → 消融是干预，不是对比）**
直觉：一个工程师关掉深度模块，发现碰撞率没变，就说「深度模块不重要」——这几乎总是错的。深度模块的贡献可能被触觉模块补偿了（交互）；也可能它本来就没被激活（有效域为空）；还可能关掉它同时改变了控制器的风险缩放 λ，从而掩盖了净效果（中介）。要问的不是「关掉后指标变了吗」，而是「在因果图上，do(关掉) 沿哪条路径改变了目标变量」。R73 的模块图恰好是一张**类型化 DAG**：数据流、预算、否决、追溯都沿边传播。这使我们第一次可以**从结构上**判断：哪些消融是干净的，哪些被共同父节点污染。消融设计因此从「跑几组」变成「图上的可识别性计算」——这是模块化设计免费送给实验方法论的礼物。

形式直觉：do(i=stub) 只影响 i 的后代（消融局部性）；两个模块若共享父节点（同一 SEAL 集、同一随机种子、同一环境扰动、同一批被试），它们的主效应就不可分，必须联合消融，或对其父节点做环境级干预。R74 的「环境级共因审计」恰好是这里的第三方干预工具。

**灵感 2（用户测试 → 人是未被建模的模态）**
直觉：整个体系为机器人传感器写了六分量、四分量、五分量，却从没给「人」写过一个分量。可系统每次进入 YELLOW/RED、每次请求再授权、每次在「澄清 vs 执行」间选择，都依赖一个人正确地看见、正确地理解、并且不过度信任。人不看见，警告等于没有；人过度信任，再授权等于自动放行；人误解，κ 适应会被反向塑造（AIC-SOCIAL 的核心攻击面）。人不是外生成本，而是闭环中的**一个传感器 + 一个执行器 + 一个可被攻击的校准源**。

形式直觉：人证据五分量——u_comp（理解正确）、u_detect（预警可辨识，信号检测论）、u_react（反应延迟）、u_reliance（依赖校准：过度/不足）、u_intent（意图推断）。前三者由用户测试标定；u_reliance 必须用**行为**（遵从率、接管率、监控频率）而非自评来测；且**过度信任与不足信任代价不对称**（前者直接吃掉安全否决），故校准是单侧目标。R74 的声明族风险在此获得可操作的外部判据：SEAL-Human 的人群覆盖 = 部署分布覆盖的下界。

**灵感 3（两者统一：同一个因果问题，两个层面）**
直觉：消融问「去掉这个模块，效果还在吗」；用户测试问「去掉这个提示，人还看得见吗」。后者本质上是把 CAB 的干预对象从 MReg 换到 HEC（Human Evidence Contract）的**呈现层**。HRI 消融（去解释、去置信度、去 YELLOW 视觉、去再授权）与模块消融共享同一套估计量、同一套盲法与负对照。于是本轮不是「加两个实验」，而是把**因果识别**确立为整个纲领的第二类有效性（第一类是安全证明），把**人的校准**确立为第三类（外部有效性）。

## 1. 形式化定义（增量：定义 398–412）

**定义 398（VALIDGAUGE-RAS 总览）** VALIDGAUGE-RAS = (CAB, HEM, HTC, ABX, J_ABL, J_HUMAN, SENTGAUGE-RAS†)。在 R74 六不变式上增加两条：
- (vii) **归因完备性**：每条主张 C1–C6 必须绑定一个预注册的消融估计量与其可识别性证明（否则该主张只算相关性观察，不得写成因果结论）；
- (viii) **人证据完备性**：每个涉及人类判断的安全谓词（看见、理解、依赖、再授权）必须挂接 HEC 通道与 SEAL-Human 校准，缺一环则视为外部有效性未建立。

**定义 399（消融干预算子 do）** 在 MReg 上定义三类合法干预：`do(i ← stub)`（同契约保守实现，定义 381）、`do(i ← impl′)`（同契约换实现，引理 35）、`do(EC_i ← EC_i′)`（契约扰动的压力测试）。**干预一致性**：干预必须由 MReg 的合法编辑实现，可被同一套组合校验复算——因此消融不是「另开一套实验代码」，而是对已认证图的**可审计编辑**。

**定义 400（消融估计量）** 给定预注册目标 Y（C1–C6 的指标）与干预集 S：
- 主效应 ATE_i = E[Y | do(i ← stub)] − E[Y]；
- 条件效应 CATE_i(context) 在 κ 画像/材质/距离等分层上定义；
- 交互 I_ij = E[Y|do(i,j←stub)] − E[Y|do(i←stub)] − E[Y|do(j←stub)] + E[Y]；
- 归因 φ_i = Shapley value，价值函数 v(S) = E[Y | do(S ← stub)]，按 ECG 的合法联盟求和。
所有估计量**必须在干预前预注册**（目标、分层、α、功效），事后改目标即视为 p-hacking，J_ABL 失效。

**定义 401（ECG 后门与可识别性）** 把每个模块的干预节点加入 ECG。若 i、j 之间存在未被调整的**后门路径**（共同父节点：共享 SEAL 集、共享种子、共享环境扰动、共享人类被试、共享温度/光照/振动），则 (i,j) 交互与各自 CATE **不可识别**。处理：要么对共同父节点做环境级/随机化干预（R74 的第三方共因输入），要么只报告联合效应 do(i,j)，禁止分解归因。**推论**：R73 的「隐共享物理过程」在 R74 是「可检出的检测功效问题」，在 R75 进一步变成「消融设计必须先解决的混杂结构」。

**定义 402（最小消融基与覆盖阵列）** 不是所有 2^|V| 子集都要跑。由消融局部性（引理 42），只需覆盖传递归约后每个节点的祖先闭包；再由交互阶数上限 2，构造强度 t=2 的覆盖阵列。**最小消融基** B =（骨架干预集）∪（共同父节点的联合干预集）∪（二阶交互覆盖集），规模 O(n log n) 而非 O(2^n)。任何超出 B 的消融只作为探针，不进入归因结论。

**定义 403（消融证书 J_ABL）** J_ABL = (估计量清单, 干预日志, 可识别性证明, 覆盖阵列, 功效与预注册, 负对照结果, 效应界)。Valid(J_ABL) ⇒ 主张的**因果表述**在声明置信度下成立；**注意**：J_ABL 与 J_SENT **正交**——前者不保证安全，后者不保证归因（引理 43）。

**定义 404（人证据计量 HEM）** 人作为证据模块，五分量
u_human² = u_comp² + u_detect² + u_react² + u_reliance² + u_intent²。
- u_comp：理解正确性（解释后复述/选择测试的错误率）；
- u_detect：预警可辨识（以信号检测论的 d′ 与虚警率度量，而非「看见了没」的自评）；
- u_react：反应延迟（事件到接管/确认的分布，超时即失效）；
- u_reliance：依赖校准（过度/不足的单侧风险，见定义 406）；
- u_intent：从人类交互推断其真实意图的剩余熵。
有效域 D_human = {负荷 ≤ L_max} ∧ {技能先验在 SEAL-Human 支撑内} ∧ {无 AIC-SOCIAL 注入指示}。

**定义 405（人证据契约 HEC）** HEC = (T_in, T_out, 𝒰_in, 𝒰_out, χ_H, D_human, τ_merge, I⊥^H, W_H, SEAL-Human)。T_out 是**独立证据类型**（人证据不得被当作机器人传感器证据的别名，防止「人说了算」变成「人替代了计量」）。I⊥^H = {安全否决, 拒绝再授权}，进入 COMP-VETO 非补偿通道。HEC 作为普通模块进 MReg，因此**自动继承** R73 组合代数、R74 门控与哨兵。

**定义 406（信任隐状态与单侧校准 HTC）** 信任 τ_t 为不可直接观测的状态，观测量取行为代理：遵从一个错误建议（过度信任 O）、否决一个正确建议（不足信任 U）、监控频率、反应延迟。校准目标为**单侧**：P(O) ≤ α_T（过度信任是安全侧风险），under-trust 只作为可用性约束（P(U) ≤ β_T）。要求：再授权在**注入的不安全提案**上必须有非平凡拒绝率（橡皮图章负对照，定义 409），否则记 u_reliance = ∞、人再授权降级为「无证据」。

**定义 407（行为哨兵与人的双源规则）** 人类反应可作为一条独立的 e-process 通道（行为哨兵），用于检出「哨兵致盲」（YELLOW 出现但无人注意）与「解释失败」。但人可被社会工程欺骗（AIC-SOCIAL），故**人的证据不得单源缩窄机器人侧不确定度**：PAR 缩窄仍要求双源一致（定义 389 的 GATE-CCA†），人只能**追加否决**，不能替机器人「变好」。这条与 R71 安全否决、R74 σ 地板同构：**保守方向可单源，放松方向必须双源。**

**定义 408（χ_H 反作用通道与 h 层）** 机器人动作 g（解释时机、模态、告警等级、运动速度）调制人的 u_detect/u_react/u_reliance 与 D_human：χ_H: g ↦（注意资源、认知负荷、信任偏移）。它作为 ΣREFLEX 的一个**新通道**（h 层）并入预算 c_reflex^h = E[Δu_human | g]；层数仍由模块声明（R73 灵感 4），主闭环不需要新分支。稳态集 H_safe = {E[u_human^{next}] ≤ τ_h}。

**定义 409（用户测试协议 ABX-H）** 强制纪律：预注册（假设、主指标、α、功效、排除规则）；组间/组内设计 + 顺序平衡；**盲法**（被试不知条件）；**安慰剂 stub**（移除模块但 UI 不变，用于区分「真实证据」与「界面暗示」）；**负对照**（注入不安全提案测橡皮图章；注入明显故障测「人是否只会说好」）；人群分层（κ 画像、专业度、文化）；SEAL-Human 密封保持集；IRB 与退出机制；样本量与最小可检测效应（MDE）预先声明。

**定义 410（HRI 消融）** 对 HEC 呈现层做与 CAB 同构的干预：do(去解释)、do(去置信度)、do(去 YELLOW 视觉)、do(去再授权)、do(改时机)。这些干预**不是 UI 迭代**，而是识别「哪一个人因要素真正承载 u_detect/u_reliance」的因果实验；它与模块消融共享估计量、盲法与负对照。

**定义 411（外部有效性证书与 SEAL-Human 覆盖）** 把 R74 的「SEAL 代表性」操作化：外部有效性证书 J_EXT =（SEAL-Contract 对部署分布覆盖的估计, SEAL-Human 对人群分布覆盖的估计, 覆盖缺口 δ_ext 的置信上界, 分布偏移哨兵）。Valid(J_EXT) ⇒ C4–C6 的结论可外推到声明人群与声明场景；反之只能写成「在 SEAL 内成立」。

**定义 412（主张扩展 C5/C6 与 CPB†）** 在 C1–C4 之上：
- **C5（消融归因）** ← (CAB, J_ABL) ← MB5 ← AB5（契约级消融 vs 组件基准消融 vs 全因子）←（归因偏差, 交互检出率, 可识别性违例数, 消融成本比）；
- **C6（人证据闭环）** ← (HEM, HTC, ABX-H) ← MB6 ← AB6（有/无 HEC，有/无信任校准）←（过度信任率, 橡皮图章拒绝率, 检测 d′, 负荷, 可用性）。
不绑定 C5/C6 的新增组件只能是工程附件。

# IP-310 CAB：消融因果绑定（设计期离线，构建期+部署前）
class CausalAblationBinder:
    def design(self, mreg, ecg, target, order=2):
        G = transitive_reduction(mreg.dag)              # 消融局部性（引理 42）
        conf = find_shared_parents(ecg)                 # 共享 SEAL/种子/环境/被试
        skeleton = [do_stub(v) for v in G.roots]        # 骨架干预
        joint = [do_joint(p) for p in conf]             # 混杂对的联合干预
        inter = covering_array(G, strength=order)       # t=2 覆盖阵列
        return AblationBasis(skeleton, joint, inter, conf)

    def estimate(self, basis, run):
        ate  = {i: run.y(do_stub(i)) - run.y0 for i in basis.skeleton}
        ints = {ij: interaction(run, *ij) for ij in basis.inter}
        shap = shapley(basis, v=lambda S: run.y(do_joint(S)))
        ident = self.identifiability(basis, run.ecg)     # 后门准则
        return Ate(ate, ints, shap, ident)

    def certify(self, ate, prereg, negative_ctrls):
        assert ate.target == prereg.target and prereg.locked
        assert ate.identifiability.violations == 0
        assert all(negative_ctrls.passed)
        return J_ABL(ate, prereg, negative_ctrls)       # 与 J_SENT 正交

# IP-311 HEM：人证据计量（感知/交互域，事件触发）
class HumanEvidenceMetrology:
    def update(self, explain_ev, alert_ev, interaction_log, load):
        u_comp = self.comp_test.error(explain_ev)        # 复述/选择测试
        dprime, far = self.sdt.detect(alert_ev)          # 信号检测论
        u_det  = self.sdt.to_unc(dprime, far)
        u_react= self.latency.entropy(interaction_log)   # 反应延迟分布
        u_rel  = self.trust.reliance_risk(interaction_log)# 单侧（定义 406）
        u_int  = self.intent.entropy(interaction_log)
        valid  = load <= L_MAX and self.social.injection_free()
        return HumanEvidence(u=sqrt(u_comp**2+u_det**2+u_react**2+u_rel**2+u_int**2),
               valid=valid, chi_H=chi_explain(explain_ev), tau=self.tchain.merge(...))

# IP-312 HTC：单侧信任校准 + 橡皮图章负对照
def calibrate_trust(trials, alpha_T, beta_T):
    O = [t for t in trials if t.user_complied and not t.system_correct]
    U = [t for t in trials if t.user_overrode and t.system_correct]
    if clopper_pearson_upper(len(O), len(trials)) > alpha_T: return FAIL_OVERTRUST
    if clopper_pearson_upper(len(U), len(trials)) > beta_T:  return FAIL_UNDERTRUST
    return PASS

def rubber_stamp_test(reauth_ui, unsafe_proposals):
    rej = [p for p in unsafe_proposals if reauth_ui.response(p) == 'reject']
    rate = len(rej) / len(unsafe_proposals)
    return rate >= TAU_RUBBERSTAMP               # 否则 u_reliance = inf

# IP-315 VALIDGAUGE 主闭环（复用 SENTGAUGE 三域 + 人通道 + 消融审计）
def VALIDGAUGE_round(M, obs, audio, tac_frame, depth_img, det_set, tracks, hum_ev):
    d_ev = M.dpe.update(depth_img, rgb, M.cam_state, M.motion, M.peers)
    o_ev = M.oem.update(det_set, tracks, d_ev, rgb, M.tac_blobs)
    h_ev = M.hem.update(hum_ev.explain, hum_ev.alert, M.interaction_log, hum_ev.load)
    if not h_ev.valid: h_ev = stub(M.hem)                    # 人证据缺省=保守
    for ev, mod in ((d_ev, M.dpe), (o_ev, M.oem), (h_ev, M.hem)):
        st, E = mod.sent.step(ev.resid, M.hist); ev.sent_state = st
        if st == 'RED': ev = stub(mod)
    t_ev = M.dmem.update(tac_frame, M.last_action)
    if M.clock.due_metric():
        b_t = M.bse.step_full(..., d_ev=d_ev, o_ev=o_ev, t_ev=t_ev, h_ev=h_ev)
        g = M.ervoi.choose(b_t, psi_hat, z_dist, t_ev.c_dist, M.budget, M.fmp, M.bse)
        if g:
            s2, cost = sent_reflex_step(M.mods | {'HEM': M.hem}, g, M.state, M.budget)
            if s2 is not None: M.last_g, M.state = g, s2
        if M.human_veto(): g = None                          # 人否决非补偿
        M.mreg.audit(); M.ecg_edge_sentinels.step()
        M.cert = write_sent_cert(M)
    return M.cert, M.abl_cert, M.human_cert

## 3. 推导

**引理 42（消融局部性）** 在类型化 MReg（DAG）上，`do(i ← stub)` 只改变 i 的后代节点的输入，祖先节点与不可达节点逐指令不变。故 i 对任意非后代目标节点的因果效应为 0；因果效应支集 = descendants(i)。系：**消融空间从 2^|V| 降为各节点祖先闭包的并，且「无关模块」可被结构证明为无关，而不是靠实验运气。**

**引理 43（干预合法性与证书正交）** stub 是同契约实现（定义 381），impl′ 同契约（引理 35），故 do 是 MReg 的合法编辑，可由组合校验复算。但 J_SENT 只断言「给定契约，安全成立」，不提供任何反事实对比；J_ABL 只断言「在预注册分布与可识别条件下，效应可归因」，不断言安全。二者互不蕴含。系：**「有证书」不等于「知道证书为何有效」；审计必须同时要求保证证据与机制证据。**

**引理 44（人证据的不可约性）** 存在安全谓词 H（「人在 YELLOW 期正确接管」「再授权不是橡皮图章」）使得在机器人动作集与传感器集下不存在充分统计量：无论机器人侧观测多充分，H 的取值依赖被试的内部状态与人群分布。故人证据是**必要模态**，不能用机器人侧代理变量替代（代理只会把 u_human 静默压成 0）。系：**用户测试不是可用性装饰，而是安全论证的一部分；这也是 C6 可证伪的根基。**

**引理 45（单侧信任校准的样本复杂度与橡皮图章下界）** 在 Bernoulli 依赖试验下，用 Clopper–Pearson 上界检验 P(O) ≤ α_T 需 n = Ω(α_T^{-1} log(1/δ)) 量级样本；若再授权拒绝率在注入不安全提案上低于 τ，则 u_reliance 不可被任何有限试验「证明为有限」，只能置 ∞ 并降级。系：**「人再授权」作为证据的价值，取决于它能否拒绝坏提案；不能拒绝的确认不是证据。**

**定理 32（C5：消融可识别性与最小基）** 在 A117–A119（干预一致性、ECG 后门完备、覆盖阵列功效足够）下：所有可识别的模块主效应与二阶交互可由最小消融基 B（规模 O(n log n)）估计；不可识别对由共同父节点集合精确刻画；且**组件基准归因是有偏的**——存在合法 MReg 使组件基准给出非零「重要模块」，而 do 干预下其 ATE = 0（例：被下游补偿的冗余模块），反之亦然。**证明重量落在「ECG 是否真的包含全部共同父节点」——即 R73/R74 的隐耦合风险，在 R75 变成可审计的图完备性假设 A118。**

**定理 33（C6：人证据闭环与外部有效性）** 在 ABX-H 纪律与 HTC 单侧校准下，Valid(J_HUMAN) ⇒ (i) 过度信任率 ≤ α_T、橡皮图章拒绝率 ≥ τ；(ii) 人证据只能追加否决、不能单源缩窄（定义 407），故 R73 安全单调性与 R74 门控引理 40 保持；(iii) SEAL-Human 的人群覆盖给出 C4–C6 外推的显式缺口 δ_ext，把 R74 的「隐式地基」变为可报告的置信上界。系：**「对谁安全」第一次有了可证伪的量化答案，而不是「我们做了用户研究」。**

**定理 34（VALIDGAUGE 严格包含）** 取 CAB 为平凡（所有 do 为恒等）、HEM 为 stub（无人类证据）、HTC 为恒 PASS，则 VALIDGAUGE 逐指令退化为 SENTGAUGE；再退化到 MODGAUGE→EMBODIED→R71→R68。安全侧只增不减，且新增的只是**离线归因与人证据**，不改变在线控制域的最坏时延。系：**R75 的性能代价主要不在运行时，而在实验与认证的组织成本——这是本轮风险的性质变化。**

## 6. 本轮最大风险

**一句话**：消融只能归因**图内已声明的模块**，用户测试只能验证**已实现且被人使用的交互**——两者共享同一个盲区：**它们认证的是「我们造出来的系统」，而不是「我们本应造出的系统」**。若最大的安全失效来自一个未建模的模块、一个未声明的共同父节点、或一个用户测试里根本没出现的交互（例如人机长期共同适应后长出的新用法），那么 VALIDGAUGE 会用最严格的因果识别与人群证据，给一个**错误的设计**颁发「归因清晰、用户认可」的双证书；而预注册只锁定「问题是什么」，从不保证「这个问题重要」。

次级风险与缓解：
1. **ECG 不完备（A118）** → 共同父节点清单版本化 + 环境级第三方传感器强制入图 + 未声明耦合探针（E412）；发现即升为 VETO 级。
2. **目标指标可测量但无意义（benchmark gaming）** → 预注册「目标相关性论证」+ 下游真实任务指标 + 负对照（指标应随真实安全变化）。
3. **用户测试生态效度** → 实验室/现场双轨 + 长时程 E428 + 安慰剂 stub 分离界面暗示。
4. **小样本与多重比较** → 预注册功效/MDE + 分层 + 校正 + SEAL-Human 密封保持集。
5. **过度信任测量效度（自评≠行为）** → 只认行为代理（遵从/接管/监控/延迟），自评仅作辅助。
6. **AIC-SOCIAL 攻击人通道** → 双源规则（人只追加否决）+ 橡皮图章负对照 + 身份双源 + κ 回滚。
7. **消融-用户测试耦合本身改变系统** → 把测试视为干预并纳入 J_ABL 的干预日志（E429），禁止「测完再改口径」。

**定义 400（估计量）** 预注册目标 Y 下：ATE_i、CATE_i、I_ij、φ_i（Shapley，v(S)=E[Y|do(S←stub)]）。预注册锁定目标/分层/α/功效/MDE；事后改目标 ⇒ J_ABL 失效。

**定义 401（ECG 后门与可识别性）** 干预节点入 ECG；i、j 间存在未调整后门路径（共享 SEAL/种子/环境/被试/温度/光照/振动）⇒ CATE 与交互不可识别。处理：对共同父节点做环境级/随机化干预，或只报联合效应 do(i,j)，禁止分解归因。

**定义 402（最小消融基）** 由消融局部性只需覆盖传递归约后祖先闭包；交互阶≤2 ⇒ 强度 t=2 覆盖阵列。B 规模 O(n log n)，超 B 的消融仅为探针、不入结论。

**定义 403（J_ABL）** =（估计量, 干预日志, 可识别性证明, 覆盖阵列, 功效/预注册, 负对照, 效应界）。Valid(J_ABL) ⇒ 因果表述成立；与 J_SENT 正交。

**定义 404（HEM）** 五分量人证据；有效域 D_human = {负荷≤L_max} ∧ {技能在 SEAL-Human 支撑内} ∧ {无 AIC-SOCIAL 注入}。

**定义 405（HEC）** (T_in, T_out, 𝒰_in⊆𝒰_out, χ_H, D_human, τ_merge, I⊥^H, W_H, SEAL-Human)；T_out 为独立证据类型；I⊥^H={安全否决,拒绝再授权} 进 VETO 非补偿通道；HEC 作为普通模块进 MReg，自动继承 R73 组合与 R74 门控。

**定义 406（HTC 单侧校准）** τ_t 隐状态，行为代理测 O/U；P(O)≤α_T（安全侧），P(U)≤β_T（可用性）；橡皮图章负对照不达标 ⇒ u_reliance=∞、再授权降级为无证据。

**定义 407（行为哨兵与双源规则）** 人类反应为独立 e-process，检出「哨兵致盲」与「解释失败」；但人可被社会工程欺骗，故**人的证据不得单源缩窄**机器人侧不确定度——PAR 缩窄仍要求双源一致，人只能追加否决。

**定义 408（χ_H 与 h 层）** χ_H: g↦（注意资源, 认知负荷, 信任偏移）；c_reflex^h=E[Δu_human|g] 并入 ΣREFLEX 预算，稳态集 H_safe；层数由模块声明（R73 灵感 4）。

**定义 409（ABX-H）** 预注册、组间/组内 + 顺序平衡、盲法、安慰剂 stub、负对照（不安全提案/明显故障）、人群分层、SEAL-Human 保持集、IRB/退出、预声明 MDE。

**定义 410（HRI 消融）** 对 HEC 呈现层做 do(去解释/去置信度/去 YELLOW/去再授权/改时机)；与 CAB 共享估计量、盲法与负对照。

**定义 411（J_EXT）** =（SEAL-Contract 覆盖, SEAL-Human 覆盖, δ_ext 置信上界, 分布偏移哨兵）。Valid(J_EXT) ⇒ C4–C6 可外推到声明人群/场景；否则只能写「在 SEAL 内成立」。

**定义 412（C5/C6 绑定）**
- C5 ← (CAB, J_ABL) ← MB5 ← AB5（契约级 vs 组件基准 vs 全因子）←（归因偏差, 交互检出率, 可识别性违例, 消融成本比）；
- C6 ← (HEM, HTC, ABX-H) ← MB6 ← AB6（有/无 HEC × 有/无 HTC）←（过度信任率, 橡皮图章拒绝率, d′, 负荷, 可用性）。

# IP-310 CAB：消融因果绑定（设计期，部署前）
class CausalAblationBinder:
    def design(self, mreg, ecg, target, order=2):
        G = transitive_reduction(mreg.dag)
        conf = find_shared_parents(ecg)          # SEAL/种子/环境/被试
        return AblationBasis(
            skeleton=[do_stub(v) for v in G.roots],
            joint=[do_joint(p) for p in conf],
            inter=covering_array(G, strength=order),
            confounds=conf, target=target)

    def estimate(self, basis, replay):
        ate  = {i: replay.y(do_stub(i)) - replay.y0 for i in basis.skeleton}
        ints = {ij: replay.y(do_joint(ij)) - replay.y(do_stub(ij[0]))
                    - replay.y(do_stub(ij[1])) + replay.y0 for ij in basis.inter}
        shap = shapley(basis.skeleton, v=lambda S: replay.y(do_joint(S)))
        ident = backdoor_check(basis, replay.ecg)   # 定义 401
        return Ate(ate, ints, shap, ident)

    def certify(self, est, prereg, neg):
        assert prereg.locked and est.target == prereg.target
        assert est.ident.violations == 0 and neg.all_passed
        return J_ABL(est, prereg, neg)

            u=math.sqrt(u_comp**2+u_det**2+u_react**2+u_rel**2+u_int**2),
            breakdown=(u_comp,u_det,u_react,u_rel,u_int), valid=valid,
            chi_H=chi_explain(explain), tau=self.tchain.merge(...))

## 4. 推导（证明骨架）

**引理 42（消融局部性）** 类型化 DAG 上 do(i←stub) 只改变 i 后代输入；祖先与不可达节点逐指令不变 ⇒ 非后代效应=0。*证*：结构归纳于拓扑序；stub 只改写 i 输出，不回溯。系：消融空间 2^|V| → 祖先闭包并。

**引理 43（干预合法性与证书正交）** stub 同契约（定义 381）、impl′ 同契约（引理 35）⇒ do 为合法 MReg 编辑。J_SENT 只断言「契约⇒安全」，J_ABL 只断言「可识别反事实效应」，互不蕴含。*证*：J_SENT 的结论在 do 干预下不变（引理 35），故不含归因信息；J_ABL 不对安全作断言。

**引理 44（人证据不可约性）** 存在安全谓词 H（YELLOW 期正确接管、再授权非橡皮图章），在机器人动作/观测集下无充分统计量。*证*：构造两被试内部状态不同但机器人侧观测同分布的情形，H 取值不同。系：用户测试是安全论证必要模态，非装饰。

**引理 45（单侧校准与橡皮图章下界）** Clopper–Pearson 单侧检验 P(O)≤α_T 需 n=Ω(α_T^{-1}log(1/δ))；若注入不安全提案的拒绝率 < τ，则任何有限试验都无法证明 u_reliance 有限。系：不能拒绝坏提案的确认不构成证据。

**定理 32（C5 可识别性与最小基）** A117–A119 下：可识别主效应+二阶交互由 B（O(n log n)）估计；不可识别对由共同父节点精确刻画；组件基准归因有偏。*证*：后门准则 + 覆盖阵列功效；反例构造「被下游补偿的冗余模块」：组件基准测得其「重要」，do 下 ATE=0。**证明重量在 A118（ECG 后门完备）**——即 R73/R74 隐耦合风险变为可审计的图完备性假设。

**定理 33（C6 人证据闭环）** ABX-H + HTC 下 Valid(J_HUMAN) ⇒ (i) P(O)≤α_T、τ_rubber≥τ；(ii) 人只追加否决 ⇒ R73 单调性与 R74 引理 40 保持；(iii) δ_ext 显式。*证*：(i) 引理 45；(ii) 定义 407 + 引理 40；(iii) 定义 411。

**定理 34（VALIDGAUGE 严格包含）** CAB 平凡 + HEM stub + HTC 恒 PASS ⇒ 逐指令退化为 SENTGAUGE→MODGAUGE→EMBODIED→R71→R68。新增只改变离线实验/认证，不改变在线控制域最坏时延。

## 7. 本轮最大风险

**一句话**：消融只能归因**图内已声明模块**，用户测试只能验证**已实现且被人使用的交互**——两者共享同一盲区：认证的是「我们造的系统」，不是「我们本应造的系统」；若最大失效来自未建模模块、未声明共同父节点、或用户测试中根本不存在的新用法，VALIDGAUGE 会用最严格的因果识别与人群证据，给一个**错误设计**颁发「归因清晰、用户认可」的双证书，而预注册只锁定问题、从不保证问题重要。

次级风险与缓解：
1. **ECG 不完备（A118）** → 共同父节点清单版本化 + 环境级第三方传感器强制入图 + 未声明耦合探针（E412），发现即升 VETO。
2. **指标可测但无意义** → 预注册「目标相关性论证」+ 下游真实任务指标 + 负对照（指标须随真实安全变化）。
3. **用户测试生态效度** → 实验室/现场双轨 + 长时程 E428 + 安慰剂 stub 分离界面暗示。
4. **小样本/多重比较** → 预注册功效与 MDE + 分层 + 校正 + SEAL-Human 密封保持集。
5. **过度信任测量效度** → 只认行为代理（遵从/接管/监控/延迟），自评仅辅助。
6. **AIC-SOCIAL 攻击人通道** → 双源规则（人只追加否决）+ 橡皮图章负对照 + 身份双源 + κ 回滚。
7. **测试本身改变系统** → 把用户测试视为干预并写入 J_ABL 干预日志（E429），禁止「测完再改口径」。
