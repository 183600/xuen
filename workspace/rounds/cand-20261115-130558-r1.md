# 第 6 轮（新灵感循环第 1 轮；本轮灵感：「步态规划」×「技术路线图」）

> **基线**：第 5 轮 InstructGauge-RTDI（IP-334–339；定义 468–492；引理 63–68；实验 E473–E492）。LeanGauge → MODGAUGE → ToolGauge → InstructGauge v3 → InstructGauge-WR → InstructGauge-RTDI 的严格退化链全部继承。
> 本轮纪律：**把「块」从时间步升级为「接触相位」，把「研究计划」从承诺升级为「带闸门的可回滚路线图」**。两个灵感各沿一条轴升级 RTDI，任一环节不可用都必须一键退回 v5。

## 0. 直觉与动机

### 灵感 1（步态规划 → 可截断的最小单位不是动作，而是「接触相位」）

直觉：RTDI 的动作分块默认「每一步都可停」，但双足/轮足机器人在单腿支撑期根本停不下来——抬起的脚必须落下，否则就是摔倒。也就是说，步态规划揭示了一个此前被忽略的事实：**「前缀封闭」只是程序语义上的可截断，物理上还要求「可捕获」**。真正安全的截断点不是任意动作边界，而是**接触相位边界**（双支撑、或可执行捕获步的时刻）。因此本轮的「块」不是 K 个动作，而是若干相位 φ（支撑集 S_φ、时长 T_φ、落脚点 p_φ）的序列；块的安全性从「前缀合法」升级为「相位封闭 + 平衡可捕获」。

步态规划还给出一条重要的定量直觉：在线性倒立摆（LIPM）下，发散分量（DCM）ξ 在开环下以 e^{ωT} 指数发散，但如果在每个相位边界用实测状态与落脚点重锚定（capture-step），误差就变成逐相位可加的线性量。这正好对应 RTDI 的「证据陈旧窗口」：**块长应按相位数计量，而不是按动作数计量；边界重锚定是把误差从指数压回线性的关键。**

### 灵感 2（技术路线图 → 能力获取不是一次规划，而是一条带闸门与杀点的可回滚 DAG）

直觉：技术路线图的本质不是「列出未来要做的事」，而是**在不确定下对有限资源做有序下注**：每个里程碑有前置依赖、成本、就绪度（TRL）、验收实验和杀点（kill criteria）。把它搬到具身系统上，就是「能力路线图」：原语库 Π 的扩张、技能包的晋升、参数盒的放宽，都应是路线图上的节点，而不是拍脑袋的增量。关键纪律有三条：**闸门必须预注册**（不能事后找指标）、**证据必须独立且新鲜**（不能用正在被晋升的策略自己产出的证据自证）、**UNKNOWN ≠ PASS**（样本不足/证据过期只能算未知，不能算通过）。

更具体地说，路线图把「研究主张」变成可执行对象：每个里程碑 n 携带能力包 (Π_n, K_n, box_n)、前置依赖 dep(n)、闸门 gate(n)、成本 cost(n) 与 TRL。系统每一步只允许在**前沿**（所有前置已 PASS）里按「单位成本覆盖率增益」选下一个里程碑，且任何晋升都必须先通过独立证据闸门。这样「扩库」不再是信念，而是**有账本、有杀点、可回滚的投资**。

### 灵感 3（耦合 → 慢时钟的路线图 × 快时钟的步态，最危险的是「执行中途换版本」）

直觉：路线图是慢变量（周/月级、版本级），步态是快变量（20ms 级）。二者耦合时最隐蔽的失败不是「规划错了」，而是**在一个正在执行的块中间，路线图把一个新版本/新参数/新原语推上了生产路径**：这个块的平衡证书、空间证书、契约都是用旧版本证明的，却由新版本执行——证书与执行体不再同一。解法是一堵**时间尺度防火墙**：路线图的晋升只能发生在**静默边界** Q（双支撑 ∧ 无在飞块 ∧ 无活跃恢复），在此之前执行器对版本**钉扎**；再叠加**回滚语义**，让「晋升失败」退化为「回到上一个已认证版本」，而不是全链路崩溃。

二者的正交互补也很清楚：步态规划回答「一个块在物理上能被切到哪里」，路线图回答「一个能力在证据上能被推到哪一步」。前者给后者提供**接触相位级的检查点**，后者给前者提供**版本级的稳定性约束**。耦合后的核心产物是「相位检查点 + 证据闸门 + 版本钉扎」三件套。

## 1. 研究问题（本轮要回答什么）

- **Q1（相位可截断性）**：在接触约束下，「前缀封闭」应如何加强为「相位封闭」？哪些截断点物理上安全、哪些必须被屏障禁止？
- **Q2（平衡证据的陈旧）**：块长从动作数变为相位数后，平衡误差如何随相位数累积？边界重锚定是否足以把指数发散压成线性？
- **Q3（路线图的可信度）**：能力晋升的闸门如何做到不可自证、证据新鲜、未知不通过？回滚能否给出无回归界？
- **Q4（时间尺度一致性）**：如何保证任一执行块的所有证书与执行它的版本严格同一？

## 2. 五条设计原则（正式化见产物区定义 493–512）

**P1 相位封闭（Contact-Phase Closure）**
合法截断点必须落在接触相位边界 B(G)，且截断后 DCM 属于可行捕获集 VC。单支撑相内部禁止截断——这不是保守，而是物理事实：抬起的脚不能「撤销」。

**P2 平衡证书（Balance Certificate）**
每个块必须携带 ZMP 裕度、相位边界 DCM 可行性、逐相位漂移上界三项证据；任一项不满足即降级为 K=1 或重规划。这是 SpatialCert 在接触动力学上的对偶。

**P3 证据独立（Evidence Independence）**
路线图闸门只接受「非当前晋升版本产生、在新鲜度窗口内、在留出场景上、带分布偏移证书」的证据；`UNKNOWN` 不得晋升。这条把「自证」从工程纪律升级为类型级条件。

**P4 时间尺度钉扎（Time-Scale Pinning）**
版本晋升只在静默边界 Q 生效，块提交时固定版本，块生命周期内版本不可变。证书与执行体必须同版本。

**P5 可回滚优先（Rollback First）**
任何晋升都必须有预注册的回滚点与回滚时延上界；晋升失败不是灾难，而是回到上一认证版本并留下可审计证据。

## 3. 与基线的接口（如何退化）

- 无接触调度 / 无平衡模型 ⇒ 所有动作视为双支撑，相位封闭退化为 v5 的前缀封闭；`BalanceCert` 不可用 ⇒ 强制 K=1，等价 RTDI 逐步执行。
- 无路线图 ⇒ 固定原语集与固定参数盒，等价 RTDI v5。
- 闸门证据不足 / 过期 / 自证 ⇒ `UNKNOWN`，不晋升，保持当前钉扎版本。
- 防火墙不可用 ⇒ 冻结路线图（只读），等价 RTDI v5。
- RTDI 失效 ⇒ InstructGauge-WR ⇒ InstructGauge v3 ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE 原样。

## 4. 预期贡献

1. 把「可截断」从程序语义升级为「接触相位 + 可捕获」的物理语义，并区分**截断屏障**（能否停）与**执行屏障**（能否撤销）；
2. 给出平衡漂移的线性/指数二分：相位边界重锚定 ⇒ 线性可加；无重锚定 ⇒ 指数发散；
3. 一个不可自证、证据新鲜、三值闸门的能力路线图，附**回滚无回归界**；
4. 时间尺度防火墙，保证块级证书与执行版本同一；
5. 一条完整可证伪路径：E493–E512 覆盖相位识别、截断安全、漂移线性、闸门自证、回滚、端到端步态与 50Hz 时序保全。

## 5. 本轮最大风险

**一句话**：相位边界与路线图闸门都依赖「被在线估计的前提」（接触状态、质心模型、证据分布），一旦这些前提本身漂移，系统会在最需要保守的边界处最自信，并把一次相位误判沿长期路线图放大成不可回滚的能力债。

## 2. 形式化定义（要点）

**定义 493（接触步态计划）**
```
G = (σ, {p_φ}, {T_φ}, {x_φ})
σ = (φ_1 … φ_M),  φ_i = (mode_i, S_i, T_i),  mode_i ∈ {LS, RS, DS},  S_i ⊆ {L,R}
```
约束：相邻相位支撑集变化连续；步行无飞行相；`T_i ≤ T_swing_max`；`p_φ ∈ F(q)`（腿可达且无碰撞的落脚域）。

**定义 494（相位边界与步态一致块）**
```
B(G) = { Σ_{i≤k} T_i | k = 0…M }
C ≼ G  ⇔  ∃ 单调 κ:[K]→[M],  ∀t: pre(a_t) ⊇ S_{κ(t)},  且 footseq(C) = {p_φ}
```
直觉：块只能在「脚已经踩实」的语义下执行；κ 把动作映射到当前支撑相位。

**定义 495（DCM 与可行捕获集）**
```
LIPM: ẍ = ω²(x − p),  ω = √(g/z_c),  ξ = x + ẋ/ω,  ξ̇ = ω(ξ − p)
VC(S) = { ξ | ∃ p' ∈ F(q): ‖ξ − p'‖ ≤ L_max  ∧  conv(S ∪ {p'}) 可容纳 ZMP }
```
`VC(S)` 是「再走一步就能停住」的状态集合；它是相位封闭截断的物理判据。

**定义 496（平衡证书 BalanceCert）**
```
BalanceCert(C,G) = (zmp_ok, dcm_ok, drift, valid)
zmp_ok   ⇔ ∀t, zmp(t) ∈ conv(S_{κ(t)}) ⊖ B_ε
dcm_ok   ⇔ ∀k ∈ B(G), ξ(t_k) ∈ VC(S_{κ(t_k)})
ρ_k      = (e^{ωT_k} − 1) · ε_state
drift    = Σ_{k=1}^{m} ρ_k ≤ ρ_max
valid    ⇔ zmp_ok ∧ dcm_ok ∧ drift
```
`valid = false` ⇒ 截断到最近合法相位边界，或降级 K=1，或重规划。

**定义 497（相位封闭与安全截断）**
```
PhaseClosed(C,G) ⇔ ∀j: (j 合法截断点) ⇒ j ∈ B(G) ∧ ξ(t_j) ∈ VC(S_{κ(t_j)})
trunc_phase(C,j) = (C[1..j], x(t_j))  若 j ∈ B(G)
trunc_phase(C,j) = ⊥                 若 j ∉ B(G)（单支撑内部，禁止）
```
关键：`trunc_phase` 返回的不仅是动作前缀，还返回**边界状态**，供下一块重锚定。

**定义 498（截断屏障、执行屏障与承诺代价）**
```
TB(G) = B(G)                                  // 能否停
EB(G) = { 不可逆接触事件：触地、材料去除、热作用 }  // 能否撤销
Commit(φ) = ρ_max − Σ_{已消耗相位} ρ_k
```
`Commit(φ) < 0` ⇒ 禁止把 φ 纳入当前块；`EB` 中的事件一旦越过，必须执行到下一个 `TB`，不能中途反悔。这比 v3 的「不可逆动作 K=1」更精细：不可逆事件不一定要求 K=1，但要求**两侧都有可捕获边界**。

**定义 499（能力路线图）**
```
R = (N, E, dep, gate, cost, trl)
n ∈ N:  n = (Π_n, K_n, box_n),  box_n ⊆ T₀
dep: N → 2^N,  gate(n) = {(exp_i, θ_i, power_i)},  cost(n) ∈ ℝ⁺,  trl(n) ∈ {1…9}
```
路线图可采纳 ⇔ 存在 E 的拓扑序；任何 `box_n ⊄ T₀` 的节点在类型层即被拒绝（继承能力闭包）。

**定义 500（证据闸门三值）**
```
Eval(n,E_obs) = PASS     若 ∀g∈gate(n): pass(g,E_obs) ∧ power(g)≥power_min
                               ∧ fresh(e) ∧ independent(e,n)
              = FAIL     若 ∃g∈gate(n): ¬pass(g,E_obs)
              = UNKNOWN  其余（样本不足 / 证据过期 / 自证 / 场景不独立）
```
晋升规则：`Eval(n) = PASS` 是**必要非充分**条件；还需定义 505 的静默边界。

**定义 501（证据独立性与新鲜度）**
```
independent(e,n) ⇔ version(e) ≠ version_promote(n)
                   ∧ scene(e) ∈ HeldOut
                   ∧ HasShiftCert(scene(e), benchmark)
fresh(e) ⇔ age(e) ≤ τ_fresh
```
直觉：用被晋升版本自己跑出的证据去证明它自己，等于让考生自己出卷；`independent` 直接把这种证据判为 `UNKNOWN`。

**定义 502（前沿与下一步选择）**
```
Frontier(R,E_obs) = { n | ∀m∈dep(n): Eval(m)=PASS  ∧  Eval(n)≠FAIL }
Next(R,E_obs,B) = argmax_{n∈Frontier, cost(n)≤B} ΔCov(n)/cost(n)
ΔCov(n) = Cov(K_n) − Cov(K_prev)   在路线图留出基准上测量
```
`ΔCov` 必须由**留出场景**测量，禁止用训练/演示场景的覆盖率冒充泛化增益。

**定义 503（静默边界与版本钉扎）**
```
Q(t) ⇔ double_support(t) ∧ ¬inflight_chunk(t) ∧ ¬active_recovery(t)
pin(C) = v    // 块提交时固定，C 的生命周期内 version(C) ≡ v
```

**定义 504（晋升与回滚语义）**
```
promote(v → v') 可执行 ⇔ Q(t) ∧ Eval(n_{v'})=PASS
rollback(v') = v  // v 为预注册回滚点
latency(rollback) ≤ T_Q   // 一个静默窗口内完成
```

**定义 505（版本一致性）**
```
VersionConsistent(t) ⇔ version(executing controller at t) = version(certificates at t)
```

**定义 506（GaitRM-8C 闭环）**
```
W: 感知（含 WristCam + 接触/IMU 估计）
R: 推理（Hypothesis + Γ_parse + 步态路线选择）
C: 契约规划（IAC + Kinematic-Loop + RT-CVC + ContactGaitModel）
E: 执行（phase-chunk：仅在相位边界可截断/抢占）
Balance-C: 平衡证书（ZMP + DCM + 漂移）
Diag: 诊断（FaultCert 根因分类）

V: 验证（CVC + SpatialCert + BalanceCert + 版本一致性）
U: 更新（Dbox + 主张绑定 + 路线图账本）
```

**定义 507（综合安全不变式）**
```
Safe(t) ⇔ CapabilityClosure ∧ PhaseClosed(C) ∧ BalanceCert.valid
          ∧ VersionConsistent(t)
```
四项缺一不可：能力不扩权、截断点物理安全、平衡证据有效、证书与执行同版本。

**定义 508（退化映射 D）**
```
D(no_contact_schedule) = 全双支撑 ⇒ 前缀封闭（v5）
D(no_balance_cert)     = K=1（v5）
D(no_roadmap)          = 固定 Π, 固定 box（v5）
D(no_gate)             = 不晋升、只读（v5）
D(no_firewall)         = 冻结路线图（v5）
D(all_fail)            = RTDI ⇒ WR ⇒ v3 ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE
```

**定义 509（漂移预算分配）**
```
ρ_max = α · (1 − exp(−ω T_horizon)) / ω   // 与可用平衡裕度成比例
ρ_k   = (e^{ωT_k} − 1) · ε_state
Σρ_k ≤ ρ_max  ⇒ 块可提交；否则按相位数二分截断
```

**定义 510（路线图覆盖率）**
`Cov(K) = 在留出基准上，能力域 K 内成功完成的任务比例`；`ΔCov` 必须是**边际**增益，避免重复计算已覆盖能力。

**定义 511（回滚点与回滚时延）**
`rollback_point(v') = v` 在晋升前预注册；`latency(rollback) ≤ T_Q`，且回滚期间执行冻结版本，不得探索。

**定义 512（路线图杀点）**
每个里程碑 n 预注册 `kill(n) = (exp_k, θ_k)`；若 `exp_k` 在预算内未达 `θ_k`，则 `Eval(n)=FAIL` 且该子树被剪枝，预算回流到其它前沿。

# IP-340 ContactGaitModel：接触步态计划与一致性检查
class ContactGaitModel:
    def __init__(self, omega, l_max, eps_state):
        self.omega = omega          # sqrt(g / z_com)
        self.l_max = l_max          # 最大步长
        self.eps = eps_state        # 状态估计噪声上界

    def plan_phases(self, chunk, terrain):
        sigma = self._contact_schedule(chunk)      # LS/RS/DS 序列
        p = self._footsteps(sigma, terrain)        # 落脚点
        T = self._phase_durations(sigma)           # 相位时长
        return GaitPlan(sigma=sigma, p=p, T=T)

    def verify_gait_consistent(self, C, G):
        kappa = match_actions_to_phases(C, G)
        if kappa is None:
            return False
        return (all(C.actions[t].pre >= G.S[kappa(t)] for t in range(len(C.actions)))
                and foot_sequence(C) == G.p)

    def rho(self, T_k):
        return (math.exp(self.omega * T_k) - 1.0) * self.eps

# IP-342 BalanceCert：ZMP + DCM + 漂移
class BalanceCert:
    def __init__(self, omega, B_eps, rho_max):
        self.omega, self.B_eps, self.rho_max = omega, B_eps, rho_max

    def verify(self, C, G):
        kappa = match_actions_to_phases(C, G)
        zmp_ok = all(zmp(t) in shrink(conv(G.S[kappa(t)]), self.B_eps)
                     for t in action_times(C))
        dcm_ok = all(dcm(t_k) in viable_capture(G.S[k], G.p[k + 1], G)
                     for k, t_k in enumerate(boundaries(G)))
        drift = sum((math.exp(self.omega * T_k) - 1.0) * self.eps
                    for T_k in G.T)
        return BalanceCertificate(zmp_ok and dcm_ok and drift <= self.rho_max,
                                  drift=drift, zmp_ok=zmp_ok, dcm_ok=dcm_ok)

# IP-341 PhaseClosureChunker：只在相位边界截断
class PhaseClosureChunker:
    def legal_truncations(self, C, G):
        return [k for k, t_k in enumerate(boundaries(G))
                if dcm(t_k) in viable_capture(G.S[k], G.p[k + 1], G)]

    def truncate(self, C, j, G):
        if j not in boundaries(G):
            raise IllegalTruncation("single-support interior is not truncatable")
        return C.prefix(j), state_at(j)   # 返回前缀 + 边界状态供重锚定

    def commit_budget(self, G, consumed):
        return self.rho_max - sum(rho(T_k) for T_k in consumed)

# IP-343 RoadmapGraph：前沿 + 单位成本增益
class RoadmapGraph:
    def __init__(self, nodes, deps, gates, costs, trls, benchmark):
        self.N, self.dep, self.gate = nodes, deps, gates
        self.cost, self.trl, self.bench = costs, trls, benchmark

    def frontier(self, ledger, evidence):
        return [n for n in self.N
                if all(ledger.eval(m, evidence) == PASS for m in self.dep[n])
                and ledger.eval(n, evidence) != FAIL]

    def next(self, ledger, evidence, budget):
        cand = [n for n in self.frontier(ledger, evidence)
                if self.cost[n] <= budget]
        if not cand:
            return None
        return max(cand, key=lambda n: self.delta_cov(n) / self.cost[n])

    def delta_cov(self, n):
        return self.bench.coverage(n.K) - self.bench.coverage(self.dep_cover(n))

# IP-344 GateLedger：三值闸门，不可自证
class GateLedger:
    def __init__(self, power_min, tau_fresh, held_out, shift_cert):
        self.power_min, self.tau_fresh = power_min, tau_fresh
        self.held_out, self.shift_cert = held_out, shift_cert

    def eval(self, n, evidence):
        if any(self._stale(evidence, g) or self._underpowered(evidence, g)
               for g in gate(n)):
            return UNKNOWN
        if any(not self._independent(evidence, n) for g in gate(n)):
            return UNKNOWN
        if all(self._passes(evidence, g) for g in gate(n)):
            return PASS
        return FAIL

    def _independent(self, e, n):
        return (e.version != version_promote(n)
                and e.scene in self.held_out
                and self.shift_cert.has(e.scene))

    def _stale(self, e, g):
        return age(e) > self.tau_fresh

# IP-345 TimeScaleFirewall：静默边界 + 版本钉扎
class TimeScaleFirewall:
    def __init__(self, T_Q):
        self.T_Q = T_Q

    def quiescent(self, M):
        return (M.gait.double_support()
                and not M.inflight_chunk
                and not M.recovery.active)

    def can_promote(self, n, ledger, evidence, M):
        return self.quiescent(M) and ledger.eval(n, evidence) == PASS

    def pin(self, C, version):
        return VersionTag(block_id=C.id, version=version)

    def rollback_latency_ok(self, v):
        return self.T_Q >= rollback_latency(v)

# IP-346 GaitRM-8C 主闭环
def instructgauge_gaitrm(M, s, ell=None):
    # 1. 版本钉扎（快时钟开始）
    v = M.firewall.current_version()
    pin = M.firewall.pin(block_id=pending_block_id(), version=v)

    # 2. 原语图接地（v5，继承能力闭包）
    iota_seq = M.pgraph.ground(ell) if ell else [M.default_iota]
    if not M.pgraph.verify_capability_closure(iota_seq):
        iota_seq = [M.default_iota]

    # 3. 接触步态计划 + 步态一致块
    G = M.gait.plan_phases(iota_seq, M.terrain)
    C = M.iac.plan_chunk(iota_seq[0], M.lbox.hypothesize(s, iota_seq[0]),
                         M.tools, M.budget_left(s), M.drift_bound(s))
    if not M.gait.verify_gait_consistent(C, G):
        C = M.iac.plan_chunk(iota_seq[0], M.lbox.hypothesize(s, iota_seq[0]),
                             M.tools, 1, M.drift_bound(s))

    # 4. 相位封闭 + 平衡证书
    cert = M.balance.verify(C, G)
    if not cert.valid:
        C, x0 = M.phase_chunker.truncate(C, M.phase_chunker.legal_truncations(C, G)[0], G)
        G = M.gait.plan_phases(C, M.terrain)
        cert = M.balance.verify(C, G)
        if not cert.valid:
            C = C.truncate(0)  # K=1 退化（v5）

    # 5. 快时钟执行：只在相位边界检查抢占/晋升
    for k, phase in enumerate(G.phases):
        if not M.cvc.joint_pre(phase) or not still_grounded(iota_seq[0], M.env):
            break
        M.env.apply_phase(phase)
        if phase.is_irreversible_event:
            M.tcv.require_cross_check(phase)  # 执行屏障：独立回执

        # 相位边界：允许截断、抢占、晋升
        if phase.end in boundaries(G):
            if M.scheduler.pending_higher_priority():
                return M.scheduler.preempt(pin, state_at(phase.end))
            if M.firewall.quiescent(M):
                n = M.roadmap.next(M.ledger, M.evidence, M.budget)
                if n and M.firewall.can_promote(n, M.ledger, M.evidence, M):
                    M.firewall.promote(v, n.version)
                    v = n.version
                    pin = M.firewall.pin(C.id, v)

    # 6. 平衡证书 + SpatialCert + CVC 发布（均绑定 pin.version）
    spatial_cert = generate_spatial_cert(C, M.wristcam.trajectory(), M.epsilon_vis)
    M.ros_cvc.publish_cvc(C.id, len(C.actions), C.actions,
                          C.pre_conditions, C.post_conditions,
                          [spatial_cert, cert], version=pin.version)
    M.roadmap.ledger.record(pin.version, C, cert, spatial_cert)
    return C, cert, spatial_cert

## 4. 推导

**引理 69（相位封闭截断的安全性）**
若 `C ≼ G`、`PhaseClosed(C,G)`、`BalanceCert(C,G).valid`，则对任意合法截断点 `j ∈ B(G)`，执行前缀 `C[1..j]` 后存在捕获步，使机器人在 LIPM 模型内不摔倒。
证明：由 `PhaseClosed`，`ξ(t_j) ∈ VC(S_{κ(t_j)})`；由 `VC` 定义存在可达落脚 `p'` 使 DCM 一步被捕获，且 `conv(S ∪ {p'})` 可容纳 ZMP；截断只移除后续相位，不改变已执行前缀的动力学；故存在恢复动作。需假设捕获步原语在 `Π` 内且 `WCET` 满足 50Hz。

**引理 70（重锚定下的线性漂移界）**
若每个相位边界都用实测状态重锚定，则块内 DCM 误差满足 `‖ξ(t_m) − ξ̂(t_m)‖ ≤ Σ_{k=1}^{m} (e^{ωT_k}−1)ε_state ≤ m·ρ_max`，即随相位数线性。
证明：每个相位内 LIPM 开环把边界误差放大 `e^{ωT_k}`；重锚定把上一边界误差清零，故误差不跨相位相乘累积，仅由本相位测量噪声与模型误差贡献。

**引理 71（无重锚定的指数下界）**
若整块开环执行、无相位边界重锚定，则误差下界 `≳ e^{ωΣT_k}·ε_0`。
证明：DCM 不稳定特征值为 `e^{ωT}`；无修正时误差按乘积放大。推论：块长必须以相位数计，且必须在边界重锚定——这正是「分块放大证据陈旧」在接触动力学中的精确形态。

**引理 72（闸门不可自证）**
若 `GateLedger` 强制 `independent(e,n)`，则任何晋升都不能仅由被晋升版本自身的执行证据通过。
证明：`independent` 要求 `version(e) ≠ version_promote(n)`；自证证据版本相同，直接判 `UNKNOWN`；`PASS` 以 `independent` 为必要条件，故不可自证。

**引理 73（时间尺度一致性）**
若所有晋升只在 `Q(t)` 发生且 `pin` 在块提交时固定版本，则任一执行块满足 `VersionConsistent(t)`。
证明：`Q` 排除在飞块与活跃恢复，晋升只能发生在块之间；`pin` 保证块生命周期内版本不变；故证书与执行体同版本。

**引理 74（回滚无回归界）**
若回滚点预注册且 `latency(rollback) ≤ T_Q`，则晋升失败后的最坏行为 ≤ 上一认证版本的证书界 + 一个静默窗口内的冻结行为。
证明：回滚恢复到已认证版本；窗口内执行冻结版本且不探索，其证书仍由旧版本的闸门保证；回滚完成后行为回到旧版本基线。

**引理 75（退化等价性扩展）**
- 无接触调度 ⇒ 全双支撑，`PhaseClosed ≡ PrefixClosed`（v5）；
- `BalanceCert` 不可用 ⇒ 强制 K=1（v5）；
- 路线图不可用 ⇒ 固定 `Π` 与 `box`（v5）；
- 闸门不可用 ⇒ 不晋升、只读（v5）；
- 防火墙不可用 ⇒ 冻结路线图（v5）；
- 全部失效 ⇒ RTDI v5 ⇒ WR ⇒ v3 ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE。

## 8. 本轮最大风险

**一句话**：相位边界与路线图闸门都依赖被在线估计的前提（接触状态、质心模型、证据分布），一旦这些前提本身漂移，系统会在最需要保守的边界处最自信，并把一次相位误判沿长期路线图放大成不可回滚的能力债。
