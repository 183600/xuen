# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；新灵感循环第 1 轮；本轮灵感：「长期记忆」×「抓取规划」）

> 第 54 轮把技能组合推进到动作-鲁棒性双证书（`α_S`、`J`），但证书只服务于单轮规划。本轮转向 **抓取规划的情节性与时间维度**：抓取不是一次性几何求解，而是跨轮累积的“经验-证书”复用问题。核心矛盾：
> **H22：没有长期记忆，抓取规划每轮从零开始，重复踩坑，第 54 轮证书无法跨任务持久化（抓取失忆）。**
> **H23：仅按几何相似度检索记忆，会把过期、跨本体、跨物体的抓取证书当作可用先验，产生“记忆幻觉”并触发负迁移。**

## 0. 直觉与动机

**灵感 1（抓取规划的第一性资源是“带证书的情节”，不是轨迹）**
直觉：人越抓越稳，不是因为记住了关节轨迹，而是记住了“这个物体、这种夹爪、这个接近方向，上次为什么滑/为什么成”。因此长期记忆的最小单元应是 **抓取情节 `e`**：它把第 54 轮的动作剖面 `α_S`、鲁棒性谱 `ρ`、联合证书 `J`、本体签名 `φ_emb`、结果与反向解释 `Explain` 封存在一起。记忆存的是 **可复核的证书与证据**，轨迹只是附属。这样，第 54 轮的证书第一次获得跨轮寿命。

**灵感 2（记忆检索必须是有效性门控，而非纯相似度）**
直觉：抓取的“看起来像”极具欺骗性：外形相似但质心、摩擦、可抓区域已变；换了夹爪，旧姿态可能根本不在动作剖面内。故检索键不能只有几何嵌入，必须叠加 **本体签名、动作剖面兼容性、证书域包含、时间衰减**，并做硬门控：`valid(e,c,t)=false` 的记忆一律隔离（quarantine），只用于漂移分析，不参与规划。**相似不等于可用**。

**灵感 3（失败记忆是负先验，成功记忆是采样先验）**
直觉：成功抓取高度冗余，常落在同一吸引域；near-miss 失败反而携带接触几何的边界信息。故记忆增强抓取规划应双通道：成功情节提供采样初始化与打分先验，失败情节膨胀成 **禁入盆地 `B_fail`** 作为硬约束，near-miss 再给软惩罚。失败记忆的长期价值高于成功记忆，不能被遗忘策略优先丢弃。

**灵感 4（巩固与遗忘 → 抓取图式 σ 的保守证书继承）**
直觉：情节无限增长会爆炸且被陈旧样本污染。巩固把同类情节压缩为 **抓取图式 `σ`**：动作剖面取交、鲁棒性谱取下确界、有效性条件取交，形成保守的证书继承；遗忘在预算下最大化未来效用，但必须满足 **失败覆盖不变量**——任何支持度足够的失败盆地都要保留见证样本，绝不为了省空间丢掉罕见但致命的负例。

**灵感 5（记忆漂移 → 证书回溯失效 + 云边分层一致性）**
直觉：物体分布、夹爪磨损、光照、桌高变化会让旧记忆的预测与重放背离。需要 **漂移检测**：某类物体的重放结果分布与记忆预测的 KL 超阈值时，撤销相关图式并回溯失效证书，复用第 54 轮的反向解释证据通道。云边结构下，云端存长期巩固记忆与版本，边端存工作记忆；同步冲突遵循 **“已认证的失败不可被未认证的成功覆盖”**，防止单次偶发成功污染长期记忆。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（抓取情节）**
抓取情节 `e = (κ_o, g, α_S, ρ, J, φ_emb, t, y, prov)`：
- `κ_o` 为物体-可供性描述子（几何 + 质心 + 摩擦 + 可抓区域）；
- `g` 为抓取姿态/抓取图；
- `α_S` 为第 54 轮动作剖面，`ρ` 为鲁棒性谱，`J` 为联合证书；
- `φ_emb` 为本体签名（夹爪、臂、传感器、控制器版本）；
- `t` 为时间戳；
- `y = (outcome, Explain, δ_nm)`，`outcome∈{success, fail, near_miss}`，`Explain` 为失败根因，`δ_nm` 为 near-miss 边界裕度；
- `prov` 为来源与签名（写入者、仿真/真机、证据哈希）。
情节空间记 `𝔈`，长期记忆 `M ⊆ 𝔈` 带索引。

**定义 122（记忆有效性）**
记忆 `e` 相对当前上下文 `c=(κ_o^c, φ_c, T_c, t)` 的有效性：
```
valid(e,c,t) = prov_ok(e)
             ∧ compat_emb(φ_emb(e), φ_c)
             ∧ A_core(e) ⊆ A(c)
             ∧ dom_{J_e}(T_c) = in
             ∧ (t - t_e) ≤ τ_mem(κ_o)
```
其中 `A(c)` 为当前动作空间，`A_core(e)` 为情节证书核心动作集。**陈旧度** `stale(e,t) = 1 - conf(e)·exp(-(t-t_e)/τ_mem)`。无效记忆进入隔离区 `Q`，保留但不参与规划。

**定义 123（有效性门控检索）**
```
R(c,M,k) = MMR_topk{ e∈M | valid(e,c,t) ∧ rel(e,c,t) ≥ θ_r }
rel(e,c,t) = w_o·sim(κ_o(e),κ_o^c) + w_a·compat(α_e,α_c)
           - w_s·stale(e,t) + w_n·info(e)
```
`info(e)` 对 near-miss 与罕见域加权；MMR 用动作剖面差异做多样性约束，防止检索退化为同一吸引域的自我强化（反馈回路）。

**定义 124（记忆增强抓取规划）**
```
g* = argmax_{g∈G_c} [ s_geo(g)
        + λ⁺ Σ_{e∈M⁺} rel(e,c,t)·y_e
        - λ⁻ Σ_{e∈M⁻} rel(e,c,t)·w_nm(e)
        - λ_ρ·risk(g; ρ_e) ]
s.t.  cover(S, A_T) = 1  ∧  g ∉ B_fail
B_fail = ⋃_{e∈M⁻} inflate(g_e, δ_nm(e))
```
`M⁺`/`M⁻` 分别为有效成功/失败记忆；负记忆既形成硬禁入盆地，也提供软惩罚。记忆同时条件化动作剖面 `α_{S|M}`，供第 54 轮 SCOM 组合图复用。

**定义 125（记忆巩固与遗忘）**
巩固算子 `Cons: 𝔈* → 𝔖`，图式 `σ=(κ_σ, g_σ, α_σ, ρ_σ, V_σ, E_σ)`，其中支持集 `E_σ ⊆ M`。**保守证书继承**：
```
α_σ(a) = inf_{e∈E_σ} α_e(a)
ρ_σ(d) = inf_{e∈E_σ} ρ_e(d)
A_core(σ) = ⋂_{e∈E_σ} A_core(e)
V_σ = ⋂_{e∈E_σ} V_e
```
遗忘在预算 `B` 下最大化 `E[future utility] - redundancy`，并满足 **失败覆盖不变量**：对任意支持度 `≥ m` 的失败盆地，保留集必须含至少一个见证情节。受保护集 `P = near-miss 代表 ∪ 罕见域代表 ∪ 高 ρ 图式`。

**定义 126（记忆漂移与证书回溯失效）**
对域 `κ`，漂移度
```
D(κ,t) = D_KL( P_mem(y|κ) ‖ P_replay(y|κ) )
```
若 `D(κ,t) > Θ_d` 且持续 `w` 个窗口，则生成漂移告警 `(κ,D)`，**回溯失效**所有覆盖 `κ` 的图式与证书，将相关情节移入 `Q`，并把根因经 Explain 通道回传云端。要求检测延迟 `≤ τ_d`，残余失效率 `≤ ε_d`。

## 2. 关键算法 伪代码

### IP-121 GEM（Grasp Episodic Memory）

```python
def encode_episode(o, g, skill, J, emb, outcome, explain, clock):
    alpha = action_profile(skill, A_c=skill.A_c, A_e=skill.A_e, sampler=skill.sampler)
    key = hash_episode(o, g, emb, alpha)
    e = Episode(
        key=key,
        kappa_o=object_descriptor(o),
        g=g, alpha=alpha, rho=J.rho, J=J,
        phi_emb=emb, t=clock.now(),
        y=Outcome(outcome, explain, delta_nm=explain.margin),
        prov=sign(key, outcome, explain))
    return e

def store_episode(M, index, e):
    index.upsert(e.kappa_o, e.phi_emb, e.key)
    M[e.key] = e
    return M
```

### IP-122 MVR（Memory Validity Retrieval）

```python
def retrieve_valid(M, index, c, t, k=8, theta_r=0.0):
    cand = index.candidates(c.kappa_o, c.phi_emb)
    scored = []
    for e in cand:
        if not valid(e, c, t):          # 硬门控：无效即隔离
            quarantine(M, e, reason='invalid')
            continue
        r = rel(e, c, t)
        if r >= theta_r:
            scored.append((r, e))
    return mmr(scored, k, key=lambda e: e.alpha)
```

### IP-123 MGP（Memory-Guided Grasp Planner）

```python
def memory_guided_grasp(o, task, skill, M, index, cfg):
    c = context(o, task, skill.alpha, skill.emb, now())
    R = retrieve_valid(M, index, c, c.t)
    Mpos = [e for e in R if e.y.outcome == 'success']
    Mneg = [e for e in R if e.y.outcome in ('fail', 'near_miss')]

    B_fail = union(inflate(e.g, e.y.delta_nm) for e in Mneg)
    best, best_s = None, -inf
    for g in grasp_candidates(o, skill, prior=Mpos):
        if g in B_fail:                       # 失败盆地硬约束
            continue
        if not cover_check(skill.alpha, task.A_T):
            continue
        s = geo_score(o, g)
        s += cfg.lam_p * sum(rel(e, c, c.t) for e in Mpos)
        s -= cfg.lam_n * sum(rel(e, c, c.t) * e.y.delta_nm for e in Mneg)
        s -= cfg.lam_r * robust_risk(g, Mpos)
        if s > best_s:
            best, best_s = g, s
    if best is None:
        return ('replan', 'no_valid_prior')   # 宁可重规划，不冒险复用
    return ('ok', best, Mpos, Mneg, B_fail)
```

### IP-124 MCO（Memory Consolidation & Forgetting）

```python
def consolidate_and_forget(M, budget, m_support=3, dims=None):
    schemas = []
    for cluster in cluster_by_kappa_and_pattern(M):
        if len(cluster) < m_support:
            continue
        sigma = Schema(
            kappa=cluster.kappa,
            g=mean_grasp(cluster),
            alpha=inf_profile([e.alpha for e in cluster]),
            rho={d: min(e.rho[d] for e in cluster) for d in dims},
            V=intersect_validity(cluster, dims),
            E=[e.key for e in cluster])
        schemas.append(sigma)

    protected = (near_miss_representatives(M)
                 | rare_domain_representatives(M)
                 | high_rho_representatives(M))
    keep = select_under_budget(M, schemas, budget, protected)
    if not failure_cover_invariant(keep, m_support):
        raise AssertionError('failure basin witness lost')
    return keep, schemas
```

### IP-125 MDR（Memory Drift & Retroactive Invalidation）

```python
def detect_drift(M, replay_fn, t, theta_d, window, tau_d):
    alarms = []
    for kappa in sampled_domains(M, window):
        E_k = recent_episodes(M, kappa, window)
        p_mem = outcome_dist(E_k)
        p_rep = outcome_dist([replay_fn(e) for e in E_k])
        d = kl_divergence(p_mem, p_rep)
        if d > theta_d:
            alarms.append(Alarm(kappa, d, delay=window))
            invalidate_schemas(M, kappa, reason='drift')
            rollback_certificates(M, kappa)
            quarantine(M, E_k, reason='drift')
    return alarms
```

### IP-126 MCS（Cloud-Edge Memory Sync）

```python
def sync_memory(cloud_M, edge_M, version, tau_sync):
    upstream = diff(edge_M.since(version), cloud_M)
    merged = merge_episodes(
        cloud_M, upstream,
        policy='certified_failure_beats_uncertified_success')
    downstream = diff(merged, edge_M)
    if not causal_consistent(downstream, tau_sync):
        return ('reject', 'memory_divergence', downstream)
    return ('ok', merged, merged.version, downstream)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| GEM | O(|A_c|·|A_e| + H) | O(|M|) | 情节证书完整、来源可验 |
| MVR | O(|C|·(|A|+log k)) | O(k) | 有效性门控 sound、隔离不丢证据 |
| MGP | O(|G_c|·(|M⁺|+|M⁻|)) | O(|M⁺|+|M⁻|) | 失败盆地覆盖、无有效先验则重规划 |
| MCO | O(|M|·|A| + |M|log|M|) | O(|M|) | 保守继承、失败覆盖不变量 |
| MDR | O(|𝔇|·w·L_replay) | O(w) | 检测延迟 ≤ τ_d、误报有界 |
| MCS | O(|ΔM|+同步日志) | O(|ΔM|) | 认证优先、因果一致 |

**正确性定理（Memory-Certified Grasp Planning Soundness）**
承接第 54 轮 (A26)–(A28)；新增假设：
**(A29)** 每个进入 `M` 的情节都附带 sound 的 `J` 与可验证 `prov`；
**(A30)** `valid` 门控无假阳性（即不会把已失效记忆判为有效）；
**(A31)** 巩固是保守的（`ρ_σ ≤ inf ρ_e`，`A_core(σ) ⊆ ⋂ A_core(e)`），且满足失败覆盖不变量；
**(A32)** 漂移检测延迟 `≤ τ_d`，残余失效率 `≤ ε_d`。

则记忆增强抓取的成功概率满足：
```
P_success ≥ 1 - Σ_d (1-ρ_min(d)) - β_E
              - P(stale retrieved) - P(drift undetected) - P(consolidation_loss)
```
其中三项分别由 (A30)、(A32)、(A31) 约束。关键：**记忆只能缩小而不能扩大可部署域**；任何无法通过有效性门控的记忆都必须被拒绝，而不是被相似度“抬进来”。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 陈旧记忆被相似度召回 | 高 | 有效性硬门控 + 时间衰减 + 动作剖面包含检查 |
| 检索自我强化（成功偏差） | 高 | MMR 多样性 + 负记忆配额 + 定期重放审计 |
| 记忆投毒 / 伪造情节 | 高 | 来源签名 + 证书复核 + 隔离区 + 异常来源降权 |
| 巩固丢失罕见失败盆地 | 高 | 失败覆盖不变量 + near-miss 受保护集 |
| 记忆规模爆炸 | 中 | 图式巩固 + 预算化遗忘 + 动作哈希去重 |
| 云边记忆不一致 | 中 | 版本化同步 + 因果一致校验 + 认证优先合并 |
| 漂移检测滞后 | 中 | 滑窗 KL + 主动重放采样 + 漂移即回溯失效 |

## 6. 本轮最大风险

**一句话**：长期记忆把抓取规划从“每轮几何求解”升级为“跨轮证书复用”，但其 soundness **三重依赖有效性门控无假阳性、巩固的保守继承、以及漂移检测的低延迟**；一旦用几何相似度替代有效性校验，或遗忘策略丢掉罕见失败盆地，系统就会在分布漂移下自信地复用过期抓取，形成系统性“记忆幻觉”负迁移，故必须以 **有效性硬门控 + 失败覆盖不变量 + 漂移即回溯失效** 三重护栏，宁可遗忘并重规划，也绝不把“看起来像”当作“可以用”。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（GEM×MVR×MGP×MCO×MDR×MCS）

> 承接第 54 轮产物 v31。本轮在动作-鲁棒性双证书体系之上，增加 **抓取情节长期记忆** 与 **记忆增强抓取规划**：
> - **GEM（Grasp Episodic Memory）**：以“带证书的情节”为最小记忆单元，持久化 `α_S / ρ / J / Explain`；
> - **MVR（Memory Validity Retrieval）**：有效性硬门控 + 陈旧度衰减 + 多样性检索，杜绝“相似即可用”；
> - **MGP（Memory-Guided Grasp Planner）**：成功记忆做采样先验，失败记忆膨胀为禁入盆地，形成双通道规划；
> - **MCO（Memory Consolidation & Forgetting）**：图式巩固 + 保守证书继承 + 失败覆盖不变量下的预算化遗忘；
> - **MDR（Memory Drift & Retroactive Invalidation）**：重放 KL 漂移检测 + 证书回溯失效；
> - **MCS（Cloud-Edge Memory Sync）**：云端长期记忆 ↔ 边端工作记忆的版本化同步与认证优先合并。
>
> IP 编号：IP-121~IP-126（共 6 个新增）；升级 IP-115/118/120，使动作剖面、联合证书与跨层迁移证书可被记忆持久化与复用。

### IP-122 MVR

```python
def retrieve_valid(M, index, c, t, k=8, theta_r=0.0):
    scored = []
    for e in index.candidates(c.kappa_o, c.phi_emb):
        if not valid(e, c, t):
            quarantine(M, e, reason='invalid')
            continue
        r = rel(e, c, t)
        if r >= theta_r:
            scored.append((r, e))
    return mmr(scored, k, key=lambda e: e.alpha)

def valid(e, c, t):
    return (prov_ok(e)
            and compat_emb(e.phi_emb, c.phi_emb)
            and subset(e.A_core, c.A)
            and domain_check(e.J, c.T) == 'in'
            and (t - e.t) <= tau_mem(e.kappa_o))
```

### IP-123 MGP

```python
def memory_guided_grasp(o, task, skill, M, index, cfg):
    c = context(o, task, skill.alpha, skill.emb, now())
    R = retrieve_valid(M, index, c, c.t)
    Mpos = [e for e in R if e.y.outcome == 'success']
    Mneg = [e for e in R if e.y.outcome in ('fail', 'near_miss')]
    B_fail = union(inflate(e.g, e.y.delta_nm) for e in Mneg)

    best, best_s = None, -inf
    for g in grasp_candidates(o, skill, prior=Mpos):
        if g in B_fail or not cover_check(skill.alpha, task.A_T):
            continue
        s = geo_score(o, g)
        s += cfg.lam_p * sum(rel(e, c, c.t) for e in Mpos)
        s -= cfg.lam_n * sum(rel(e, c, c.t) * e.y.delta_nm for e in Mneg)
        s -= cfg.lam_r * robust_risk(g, Mpos)
        if s > best_s:
            best, best_s = g, s
    return ('replan', 'no_valid_prior') if best is None else \
           ('ok', best, Mpos, Mneg, B_fail)
```

### IP-124 MCO

```python
def consolidate_and_forget(M, budget, m_support=3, dims=None):
    schemas = []
    for cluster in cluster_by_kappa_and_pattern(M):
        if len(cluster) < m_support:
            continue
        schemas.append(Schema(
            kappa=cluster.kappa,
            g=mean_grasp(cluster),
            alpha=inf_profile([e.alpha for e in cluster]),
            rho={d: min(e.rho[d] for e in cluster) for d in dims},
            V=intersect_validity(cluster, dims),
            E=[e.key for e in cluster]))

    protected = (near_miss_representatives(M)
                 | rare_domain_representatives(M)
                 | high_rho_representatives(M))
    keep = select_under_budget(M, schemas, budget, protected)
    assert failure_cover_invariant(keep, m_support)
    return keep, schemas
```

### IP-125 MDR

```python
def detect_drift(M, replay_fn, theta_d, window):
    alarms = []
    for kappa in sampled_domains(M, window):
        E_k = recent_episodes(M, kappa, window)
        d = kl_divergence(outcome_dist(E_k),
                          outcome_dist([replay_fn(e) for e in E_k]))
        if d > theta_d:
            alarms.append(Alarm(kappa, d))
            invalidate_schemas(M, kappa, reason='drift')
            rollback_certificates(M, kappa)
            quarantine(M, E_k, reason='drift')
    return alarms
```

### IP-126 MCS

```python
def sync_memory(cloud_M, edge_M, version, tau_sync):
    upstream = diff(edge_M.since(version), cloud_M)
    merged = merge_episodes(
        cloud_M, upstream,
        policy='certified_failure_beats_uncertified_success')
    downstream = diff(merged, edge_M)
    if not causal_consistent(downstream, tau_sync):
        return ('reject', 'memory_divergence', downstream)
    return ('ok', merged, merged.version, downstream)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| GEM | O(|A_c|·|A_e| + H) | O(|M|) | 证书完整、来源可验 |
| MVR | O(|C|·(|A|+log k)) | O(k) | 门控 sound、隔离不丢证据 |
| MGP | O(|G_c|·(|M⁺|+|M⁻|)) | O(|M⁺|+|M⁻|) | 失败盆地覆盖、无先验即重规划 |
| MCO | O(|M|·|A| + |M|log|M|) | O(|M|) | 保守继承、失败覆盖不变量 |
| MDR | O(|𝔇|·w·L_replay) | O(w) | 延迟 ≤ τ_d、误报有界 |
| MCS | O(|ΔM|+日志) | O(|ΔM|) | 认证优先、因果一致 |

**正确性定理（Memory-Certified Grasp Planning Soundness）**
承接第 54 轮 (A26)–(A28)；新增：
**(A29)** 进入 `M` 的情节均带 sound `J` 与可验证 `prov`；**(A30)** `valid` 门控无假阳性；**(A31)** 巩固保守且满足失败覆盖不变量；**(A32)** 漂移检测延迟 `≤ τ_d`、残余失效率 `≤ ε_d`。
则：
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E
            - P(stale retrieved) - P(drift undetected) - P(consolidation_loss)
```
关键：**记忆只能缩小可部署域，不能扩大**；无法通过有效性门控的记忆一律拒绝，绝不以相似度替代有效性。

## 6. 本轮最大风险

**一句话**：长期记忆把抓取规划从“每轮几何求解”升级为“跨轮证书复用”，但其 soundness **三重依赖有效性门控无假阳性、巩固的保守继承、以及漂移检测的低延迟**；一旦用几何相似度替代有效性校验，或遗忘策略丢掉罕见失败盆地，系统就会在分布漂移下自信地复用过期抓取，形成系统性“记忆幻觉”负迁移，故必须以 **有效性硬门控 + 失败覆盖不变量 + 漂移即回溯失效** 三重护栏，宁可遗忘并重规划，也绝不把“看起来像”当作“可以用”。
