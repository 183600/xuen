# 第 43 轮 · 课程化人机共签证书（C³）：把「课程学习」「人机协作」装进证书飞轮，让自主性成为可考试、可共签、可撤销的执照（四层架构 v8）

> 承接第 42 轮 v19（Sim-Cert-RAG）。第 42 轮自陈最大风险是「仿真偏差累积 + 检索幻觉 → 证书在自信中静默失效」。本轮灵感词「课程学习」「人机协作」恰好补上飞轮缺失的两个社会—认知环节：飞轮会自我进化，却**没有一张决定“何时该更信任它”的日程表**；飞轮把人只当最终审计员，却**没有把稀缺的人类注意力用在信息量最大的地方**。本轮核心命题：把“自主权”从全局开关，改造为**按状态区域授予、按考试放行、按偏移撤销的执照（license）**；用课程学习自动生成“安全考试”，用人机协作构建“有界预言机 + 共签责任”，使证书体系从“证明当下安全”升级为“证明已经学会了多少、还剩多少不确定、谁为哪一部分负责”。三者的直觉关系是：**课程是飞轮的时钟，人类是老师/考官/共签人，飞轮是教材与题库**，合起来是一个 teach→practice→exam→graduate→monitor→revoke 的能力生命周期。

## 0. 直觉与动机

**灵感 1（课程学习 → 证书的「最近发展区」与毕业考试）**：第 42 轮的 IP-50 课程引擎只从知识库检索相位序列、按难度排课，但“难度”是任务层的，不是**安全层**的。课程学习的直觉是：不要一上来就把最难分布丢给机器，而应沿着**证书边缘**逐步扩张有效域——当前证书“差一点就能覆盖”的区域，恰是学习信号最大、风险又可控的“证书最近发展区（C-ZPD）”。把课程重新定义为**一串安全考试**：每一阶段只在留出的对抗考试集上通过、且人类独立审计通过，才允许把该区域的自主等级升一级。课程学习由此从“训练技巧”升格为“**自主权的授予协议**”——它天然回答“何时可以更信任机器”。

**灵感 2（人机协作 → 有界预言机、主动查询与共签责任）**：人机协作的直觉不是“人随时在环”，而是承认**人类注意力是最稀缺资源**。第 42 轮 CAR 只在边际跌破阈值时报警，没有回答“这一次该不该问人、问哪个问题最值”。本轮把人类建模为**有界预言机**：有成本、有延迟、有可靠度；查询策略以“单位人类代价换来的证书体量/不确定性消减”（价值信息量 VoI）排序，只在证书差集、未决守卫、冲突模板、执照异议上提问。人类的答案——标注、反例、模板否决、降级要求——全部作为**黄金证据**回流 CKB/CEGAR/课程。进一步，人类不只是被咨询者，还是**共签人**：机器证书 M 与人类审计证书 H 共同构成“人机共签证书”，明确“谁为哪块区域背书”。但共签必须是**独立证据**而非橡皮图章，否则协作退化为自动化偏见。

**灵感 3（把两者接到飞轮上 → 教学—考试—毕业—撤销闭环）**：第 42 轮的 Sim→RAG→Edge→Sim 是“学习飞轮”，缺一个“**评估与授权飞轮**”。本轮补上：CKB 提供教材（历史证书/反例/相位），SCV（Isaac Sim）提供题库（可程控生成考试），CCE 负责出题与排课，HOR 负责人力查询路由，ALM 负责发照/降级/冻结。实机运行时的边际下探与分布漂移直接触发“重考”而非直接停机；执照是**可撤销、可按区域、可组合**的。证书由此从“状态谓词”进化为“**能力凭证 + 责任凭证**”。

## 1. 形式化定义（增量：定义 38–43）

**定义 38（证书课程 C-curriculum）**：一条课程是任务分布序列 𝒟 = (D_0, D_1, …, D_K)，满足证书硬度单调不减。证书硬度 h(D; C) = E_{x∼D}[ (θ − m_lo(x))₊ ] + λ₁·T_horizon(D) + λ₂·ρ_counter(D)，其中最后一项为 D 中已知反例密度。每个阶段 D_k 配一个**与训练分布不相交**的考试分布 D_k^exam。

**定义 39（证书最近发展区 C-ZPD）**：F_t = { D : pass_rate(D; C_t) ∈ [p_lo, p_hi] ∧ coverage(D; C_t) ∈ [c_lo, c_hi] }。课程每次从 F_t 中选使“下一阶段证书体量期望增益 / 硬度”最大的分布；若 F_t 为空则进入**前沿扩展**（在证书边界外做小步对抗采样），保证课程不停摆也不越级。

**定义 40（人类有界预言机与查询路由）**：人类预言机 O_h 对查询 q 返回标签 y，带代价 c_h(q)（注意力/时间）、延迟 τ_h(q)、可靠度 ρ_h(q)。查询策略 π_q 在预算 B_h 下选择查询集，最大化价值信息量 VoI(q; C) = E_y[ Vol(C | y) − Vol(C) ] / (c_h(q)+τ_h(q))，只在 VoI 超阈值且属于证书差集时提问。

**定义 41（自主等级执照 license）**：状态区域 R 的自主等级 L(R) ∈ {0,…,5}，由证书强度 s(x) = min_e m_lo,e(x)/θ_e 经单调映射 g 得到；**毕业规则**：L(R) 升到 k+1 当且仅当 (i) 在 D_k^exam 上 pass_rate ≥ 1−δ_k 且零不安全；(ii) 独立人类审计样本通过；(iii) 无未解释反例。执照可按 R 分片，且**可撤销**：降级先于禁用，重复撤销达阈值则冻结该区域（重考题库须重新生成）。

**定义 42（人机共签证书）**：Cert_co = (M, H, Σ)，M 为机器证书（覆盖范围/强度），H 为人类在**独立抽样**审计上的背书，Σ 为责任划分账本（哪些区域机器负责、哪些人类负责、哪些共担）。共签证书的可用范围 = M 的 sound 区域 ∪ H 显式背书的区域；只有当 H 的抽样由人类独立播种、机器无法预知或挑选时，H 才计入 sound。

**定义 43（信任校准与课程冻结）**：信任校准误差 TCE = | override_rate − predicted_failure_rate |（按风险分桶取 ECE）。若 TCE 连续超阈，说明人类要么过度依赖、要么过度怀疑机器：前者触发**共签强审计**（隐藏机器结论让人类独立判断），后者触发**解释增强**。若某区域重复撤销或考试与实机持续背离，触发**课程冻结**：该区域退回全人工，并作废由该课程阶段授予的全部执照。

## 2. 三大产出设计（新增 IP-57/58/59 + 升级 IP-50/51/52/53/54/55/56/45/47）

### 2.1 IP-57 CERT-CURRICULUM-ENGINE（CCE，证书课程引擎）
1. **硬度函数与前沿扩张**：用证书边界距离、时程、反例密度定义硬度；C-ZPD 为空时做小步对抗扩张，禁止跳级。
2. **考试协议**：每阶段考试 = 留出对抗集（反向可达 + 域随机化）+ Sim-to-Real 迁移集（复用 IP-54 的 α_e）+ 历史回归集（防遗忘）；考试分布与训练分布**签名隔离**，机器不能预选。
3. **毕业门与重考**：三重门（自动考试 / 人类独立审计 / 无未解释反例）；漂移或边际下探触发对应区域重考，而非全系统 SafeStop。
4. **防灾难性遗忘**：每升一级随机回考旧阶段（rehearsal exam），旧执照按区域保留；遗忘超阈则冻结相关执照并回收课程学分。

### 2.2 IP-58 HUMAN-ORACLE-ROUTER（HOR，人机查询路由器）
1. **查询合成**：候选查询来自证书差集、未决守卫、模板冲突、执照异议四类；按 VoI/代价排序，预算内取最优子集。
2. **工作负载感知调度**：查询/小时硬上限、批处理、按紧迫度分级（安全否决 > 差集补全 > 模板偏好）；避免“人机节奏失配”。
3. **证据入账**：人类答案带 (fingerprint, source=human, confidence=ρ_h) 写入 CKB，反例进 CEGAR，否决进 ALM 复核；全部可审计、可回滚。
4. **解释与人因**：给人类的不是原始数字，而是“证书差集 Δ + 反事实：若按机器建议，最坏会损失哪块区域”，降低认知负担、抑制橡皮图章。

### 2.3 IP-59 AUTONOMY-LICENSE-MANAGER（ALM，自主执照管理器）
1. **分片执照**：按状态区域（语义图节点/度量格）发照，而非全局一刀切；许可证随 CKB 指纹与硬件版本绑定。
2. **毕业与共签工作流**：机器出考试报告，人类对**独立抽样**背书；共签要求独立证据（人类自选种子/隐藏机器结论的盲审），否则拒绝授予。
3. **在线撤销**：偏移/边际下降 → 先降一级；重复撤销 → 冻结并作废该阶段学分；全部动作进责任账本 Σ。
4. **执照组合**：与 IP-47 组合代数对接——新技能组合的执照 = 子执照的乘积取保守（min 等级、合取守卫、接口契约检查）；不兼容即拒绝组合。

## 4. 实验设计（E87–E94 硬门槛，承接 E79–E86）

回退：E87 课程崩塌 → 冻结自动排课，退回人工设定固定课表；E88 查询无收益 → 关闭 VoI，只在安全否决点问人；E89 毕业不单调 → 锁定执照为全局单一等级并强制人工逐阶段签核；E90 校准失败 → 引入盲审与强制双人复核；E92 考试不过 → 该阶段不毕业，回退上一轮 Flywheel 证书；E94 负载不降 → 降低自主上限，优先保安全。

## 5. 本轮最大风险

**一句话**：课程化自主最危险之处，是它可能把第 42 轮遗留的「仿真偏差 / 检索幻觉」通过“**我们已经通过考试**”的叙事合法化为**不可逆的自主升级**——一旦考试集被机器预选、共签退化为自动化偏见下的橡皮图章，安全阀不是被打破，而是被制度性地绕过，且比任何单次失效都更难事后归因。

| F_t = {D : pass∈[p_lo,p_hi] ∧ cover∈[c_lo,c_hi]} | 证书最近发展区 | 当前证书“差一点能覆盖”的分布集合 |
| O_h(q) ↦ (y, c_h, τ_h, ρ_h) | 人类有界预言机 | 带代价/延迟/可靠度的回答模型 |
| VoI(q;C) = E_y[Vol(C|y)−Vol(C)]/(c_h+τ_h) | 价值信息量 | 单位人类代价换来的证书体量增益 |
| L(R) ∈ {0,…,5} | 区域自主执照 | 由 s(x)=min_e m_lo,e/θ_e 经单调映射 g 给出 |
| Cert_co = (M, H, Σ) | 人机共签证书 | 机器证书 + 独立人类审计背书 + 责任账本 |
| TCE = \|override_rate − predicted_failure_rate\| | 信任校准误差 | 按风险分桶取 ECE |
| Freeze(R) | 课程冻结 | 冻结区域内作废该课程阶段授予的全部执照，退回全人工 |

## 2. 关键算法（伪代码）

### IP-57 CCE：证书课程、考试与毕业门
```python
def certificate_hardness(D, C, lam1=0.5, lam2=0.3):
    # 证书硬度：任务分布到当前证书边界的距离 + 时程 + 已知反例密度
    return (expect(D, lambda x: relu(C.theta - C.m_lo(x)))
            + lam1 * T_horizon(D)
            + lam2 * density(D, C.known_counterexamples))

def select_curriculum_task(C_t, candidates):
    # 1) C-ZPD 内选“单位硬度增益最大”的分布
    F = [D for D in candidates
         if p_lo <= pass_rate(D, C_t) <= p_hi
         and c_lo <= coverage(D, C_t) <= c_hi]
    if F:
        return argmax(F, lambda D: certificate_gain(C_t, D) / certificate_hardness(D, C_t))
    # 2) 前沿为空：小步对抗扩张，禁止跳级
    return expand_frontier(candidates, max_step=delta_h)

def certificate_gain(C, D):
    C_next = learn_on(C, D)
    return volume(C_next.valid_region - C.valid_region)

def build_exam(C_k, D_train, D_deploy, sim):
    # 三类考试，全部与训练分布签名隔离，机器不得预选
    D_adv   = sim.adversarial_backward_reachable(C_k, seeds=exam_seeds)   # 对抗
    D_trans = sim.domain_randomized(D_deploy, delta_dyn, delta_sens)      # 迁移
    D_reg   = replay_old_stages(history)                                  # 回归防遗忘
    assert signature_disjoint(D_adv | D_trans, D_train)
    return ExamSuite(adv=D_adv, transfer=D_trans, regression=D_reg)

def exam(C_k, suite, delta_k, alpha_e):
    stats = run_exam(C_k, suite)
    passed = (stats.pass_rate >= 1 - delta_k
              and stats.unsafe == 0
              and stats.transfer_violation <= alpha_e * stats.theoretical_bound)
    return passed, stats

def graduation_gate(C_k, stats, human_audit, unexplained):
    # 三重门：自动考试 + 独立人类审计 + 无未解释反例
    return (stats.passed
            and human_audit.seed_chosen_by_human
            and human_audit.approved
            and len(unexplained) == 0)

def reexam_if_needed(license, drift):
    # 漂移/边际下探 → 仅对相关区域重考，不做全局 SafeStop
    return [R for R, L in license.regions.items()
            if drift[R] > L.drift_budget or margin_drop(R) > L.eps]
```

### IP-58 HOR：有界预言机与 VoI 查询路由
```python
def frontier_queries(C, x, state):
    # 四类查询候选：证书差集 / 未决守卫 / 模板冲突 / 执照异议
    return (gap_states(C, x)
            | undecided_guards(C, state)
            | conflicting_templates(C, x)
            | license_objections(state))

def value_of_information(q, C, human):
    gain = expect_labels(q, lambda y: volume(C.with_label(q, y)) - volume(C))
    cost = human.cost_est(q) + human.latency(q)
    return gain / max(cost, EPS)

def route_queries(C, x, state, budget_h, voi_threshold):
    # 按 VoI/代价排序，预算内贪心选取（可证明近似最优，子模性）
    cand = sorted(frontier_queries(C, x, state),
                  key=lambda q: value_of_information(q, C, human), reverse=True)
    selected = []
    for q in cand:
        if value_of_information(q, C, human) < voi_threshold:
            break
        if budget_h.remaining < human.cost_est(q):
            break
        selected.append(q); budget_h.consume(q)
    return selected

def ingest_human_answer(q, y, human):
    # 人类答案 = 黄金证据；反例入 CEGAR，否决入执照复核，全部可审计
    CKB.insert(record=(q.fingerprint, y, source='human',
                       confidence=human.reliability(q), ts=now()))
    CEGAR.add_constraint(q, y)
    if getattr(y, 'veto', None):
        ALM.flag_license_review(region=q.region, reason='human_veto')
    return CEGAR.step()

def explain_for_human(C, q):
    # 不暴露原始张量：给出差集 + 反事实“若采纳机器建议最坏损失哪块区域”
    return Explanation(delta=find_gaps(C, q.region),
                       counterfactual=worst_case_loss(C, q.suggestion))
```

### IP-59 ALM：分片执照、独立共签与撤销
```python
def license_level(x, C):
    s = min_e(C.m_lo_e(x) / C.theta_e)
    s -= calibration_penalty(x)          # 信任校准惩罚
    return monotone_map(s, bins=[0, .2, .4, .6, .8, .95])  # 0..5

def grant_license(region, level, exam_stats, human_cosign, delta):
    # 共签必须是独立证据：人类自选种子/盲审，机器不能预选样本
    if not human_cosign.independent_evidence():
        return Reject("co-sign requires independent audit, not rubber stamp")
    if exam_stats.pass_rate < 1 - delta[level]:
        return Reject("exam not passed")
    if not exam_stats.zero_unsafe or exam_stats.unexplained_counterexamples:
        return Reject("unexplained counterexamples")
    return License(region, level, evidence=[exam_stats, human_cosign],
                   responsibility=split_responsibility(region, level),
                   revocable=True, bound_to=[CKB.version, hw.version])

def revoke_on_shift(region, drift, margin_drop, license):
    # 先降级、后禁用；重复撤销 → 冻结并作废该课程阶段学分
    if drift > license[region].drift_budget or margin_drop > license[region].eps:
        new = max(license[region].level - 1, 0)
        license.set(region, new, reason='shift')
        if new == 0 and repeated_revocations(region) >= k_freeze:
            return freeze(region)          # 退回全人工，作废阶段学分
    return license

def co_sign(M_cert, audit):
    # sound(H) 要求：样本量≥n_min、种子由人类选择、机器无法预知或挑选
    if audit.size < n_min or audit.seed_chosen_by_machine:
        return None
    return CoSignedCertificate(scope=M_cert.scope,
                               machine=M_cert,
                               human=audit.attestation,
                               responsibility=account_ledger(M_cert, audit))

def compose_licenses(L_a, L_b, contract):
    # 与 IP-47 组合代数对接：等级取 min，守卫合取，契约必须兼容
    if not contract.compatible(L_a.interface, L_b.interface):
        return Reject("interface contract mismatch")
    return License(region=L_a.region ∩ L_b.region,
                   level=min(L_a.level, L_b.level),
                   guards=conjunction(L_a.guards, L_b.guards),
                   responsibility=union_ledger(L_a, L_b))
```

### 既有 IP 的飞轮—授权耦合补丁
```python
# IP-56 ECR：运行时同时给出可授予的自主等级
def ecr_step(x):
    m = cert_lookup_L0(x)
    A = license_level(x, m)              # 当前区域可授予等级
    if m.margin < m.theta or m.confidence < conf_lo:
        HOR.route_queries(m.cert, x, state, budget_h, voi_threshold)
    return m, A

# IP-51 CAR：守卫叠加区域执照等级（低等级 → 更保守或先问人）
def car_guard(e, x, cert, license):
    theta_real = cert.alpha_e[e] * cert.theta_sim[e]
    if license.level(x) <= 2:
        theta_real *= conservative_factor(license.level(x))
        if margin_uncertain(x):
            HOR.route_queries([query_for_edge(e)], x, state, budget_h, voi_threshold)
    return cert_lookup_L0(x).m_lo[e] >= theta_real
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性保证 |
|---|---|---|---|
| IP-57 CCE 选课 | O(|𝒰|·(pass+cover)) 每阶段，离线 | 课程/考试元数据 O(K) | F_t 非空即取最大增益；空则小步扩张 ⟹ 硬度单调、不越级 |
| IP-57 考试 | O(|D_exam|·T_sim)，可并行 | 考试日志 O(|D_exam|) | 考试分布与训练签名隔离 + 三重门 ⟹ 毕业不依赖训练集过拟合 |
| IP-57 回考/冻结 | O(|R|) 触发、O(|D_reg|) 回考 | 历史回归集 | 回考失败或重复撤销 ⟹ Freeze(R)，作废该阶段学分 |
| IP-58 VoI 路由 | O(|Q|·log|Q|)，查询集子模 ⟹ 贪心 1−1/e 近似 | 查询队列 O(B_h) | VoI 单调子模 ⟹ 贪心近似最优；预算约束显式 |
| IP-58 人类证据入账 | O(log N) 索引 + O(1) 账本 | 证据记录 O(q) | 人类答案带可靠度与来源，可审计/可回滚 |
| IP-59 发照/毕业 | O(|R|) 映射 + 审计校验 | 执照表 O(|R|) | 独立证据 + 考试零不安全 + 无未解释反例 ⟹ 才授予 |
| IP-59 撤销/冻结 | O(1) 降级、O(|R|) 冻结 | 责任账本 O(events) | 先降级后禁用；重复撤销 ⟹ 冻结，安全优先 |
| IP-59 执照乘积 | O(|R_a|+|R_b|) 区域交 + 契约检查 | 同子执照 | 等级取 min、守卫合取、契约兼容 ⟹ 组合不弱化安全 |
| 信任校准 TCE | O(B·n)，B=风险桶数 | 滑窗 O(B) | ECE 超阈 ⟹ 触发盲审/解释增强，抑制自动化偏见 |

**授权安全命题（非形式化陈述）**：若每阶段考试对“部署分布在证书相关投影上”是充分的（考试支撑覆盖部署支撑的证书投影），考试零不安全，且毕业需独立人类审计、撤销召回率 ≥ 1−δ_r，则沿课程累计的不安全暴露 ≤ Σ_k δ_k + δ_r；且执照等级沿已毕业课程单调不减，冻结操作为全局安全兜底。

## 6. 本轮最大风险

**一句话**：课程化自主最危险之处，是它可能把第 42 轮遗留的「仿真偏差 / 检索幻觉」通过“**我们已经通过考试**”的叙事合法化为**不可逆的自主升级**——一旦考试集被机器预选、共签退化为自动化偏见下的橡皮图章，安全阀不是被打破，而是被制度性地绕过，且比任何单次失效都更难事后归因。
