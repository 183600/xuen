# 第 69 轮（承接第 68 轮「CALM-RAS 标定感知风险自适应闭环」IP-243~252；灵感循环新循环第 1 轮；本轮灵感：「需求洞察」×「灵巧手」）

> 第 68 轮 CALM-RAS 把「测量可信度」做成一等公民，但它仍默认了一个更深的常数：**任务需求（到底要满足什么）是已知且不变的**。R68 全篇是 verification——把给定需求执行得更准、更安全；却从未做 validation——确认我们执行的是不是「那个需求」。本轮两个灵感词恰好把这个缺口撕开：**需求洞察**指出需求是潜在的、会说一套做一套的、且随交互漂移的；**灵巧手**指出被高自由度/高接触丰富度长期当作控制负担的冗余，其实是最好的主动提问信道。
>
> 核心命题：
>
> **把「需求」从输入常数升级为一等公民的在线潜变量，用灵巧手的冗余自由度做安全的信息获取实验（探询物体 + 澄清人类），用四源归因把「需求变了 / 世界变了 / 传感器歪了 / 真故障」分开——NEEDLE（Need-Eliciting, Envelope-bounded Dexterous Loop）。**
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「**我满足的是谁的需求，而且是正确的那个吗**」。

## 0. 直觉与动机

**灵感 1（需求洞察 → 需求不是输入，而是会说谎的潜变量）**
直觉：产品需求研究最稳定的发现是 **stated vs revealed 的鸿沟**——用户说「我要快」，但每次纠正都往「稳」拉；用户说「随便抓」，但看到易碎物时动作明显紧绷。形式上，存在真实需求 h*，系统只能看到两路含噪证据：显式陈述 s（语言/UI/指令）与行为揭示 e（演示、纠正、注视、情感、结果反馈）。需求洞察不是「听懂指令」，而是**检测 b(h|s) 与 b(h|e) 的系统性分歧 I_t，并决定相信哪一路**。更关键：需求不是被动等待被读出的，它可以被**安全的主动实验**降低不确定度——这正是灵巧手能提供而夹爪提供不了的东西。

**灵感 2（灵巧手 → 冗余不是控制负担，而是「提问的自由度」）**
直觉：多指手的 n_c 个接触、冗余关节与阻抗可调范围，通常被当作逆运动学/力分配的麻烦。但每一次安全接触都是一次**测量**：轻捏感知脆性、侧推感知摩擦、微抬感知质量与重心、滚动感知形状/滑移。灵巧手的冗余恰好提供**并行、低扰动、可分级**的信息获取通道。把「灵巧度」重新定义为「在满足任务的同时还能施加多少个安全的探询自由度」——**dexterity as inquiry bandwidth**。这把需求洞察从被动观察升级为主动 Bayesian 实验设计。

**灵感 3（与 R68 的接缝 → 需求漂移是缺失的第四种归因）**
直觉：R68 的残差 r_t 被解释为 cal（标定漂移）/ fault（真实故障）/ real（世界变化）。但同一股系统性偏移还有第四种来源：**需求变了**。用户从「搬」切到「递」，力/速度目标整体平移；若没有需求假设，系统会把这股偏移记到「传感器漂移」或「故障」账上——于是 R68 越会标定，越可能把「用户改主意」标成「传感器坏了」。加入 need 作为第四假设后归因空间才闭合；而人类纠正信号 e_human 是区分 need 与 cal/fault 的**正交证据源**：物理链路退化不会让人产生系统性同向纠正，需求变化会。

**灵感 4（合流 → NEEDLE 六组件 + 两个护栏）**
需求给出潜变量与信念，灵巧手给出主动探询与能力包络，四源归因给出与 R68 的接缝。合成闭环：
1. **NBE Need Belief Estimator**：双信念（陈述 vs 揭示）+ 分歧 I_t + 双时间尺度漂移检测；
2. **DCE Dexterity Capability Envelope**：把抓取力锥/关节限/柔顺范围投影到需求坐标，判定「这只手/这个物体到底能不能满足」；
3. **AIP Active Inquiry Planner**：安全约束下的信息增益最优探询 + 澄清（问物 vs 问人统一为信息预算问题）；
4. **FDA Four-way Drift Attribution**：cal / fault / world / need 四源归因，用 e_human 打破混淆；
5. **CSI Conservative-Satisfying Intersection**：需求不确定时执行「可行需求的逐坐标保守交集」；
6. **DAC Dexterity Allocation Controller**：把灵巧手的控制权限在任务与探询之间分配。
两个护栏：**HIL Human Insight Ledger**（把 stated-revealed 分歧显式呈现给人类确认——需求的可认证性只能来自人类，或来自保守交集，二者必居其一）；**NRC Need-aware Risk Certificate**（J_NEED 证书，接入 R68 的 J_CALM）。

**灵感 5（对 R68 风险的对症下药，以及反噬）**
R68 的最大风险是「缓变故障被标定吸收而隐形」。需求层提供了一个**独立于物理链路的正交证据源**：缓变故障通常不改变人的纠正方向，而需求漂移会——FDA 因此能把两者分开，给 R68 的单一防线加一道校验。但反面同样成立：需求层会引入 R68 没有的失效——**观察者效应**：主动探询会改变用户对任务的期望，系统可能测到自己的回声，把「探询/建议塑造出的需求」当成「用户真实需求」高置信执行（见第 6 节与定理 18）。

## 1. 形式化定义（增量：定义 293–309）

**定义 293（NEEDLE 总览）** NEEDLE = (NBE, DCE, AIP, FDA, CSI, DAC, HIL, NRC, RAS-WM†)。三不变式：
(i) **需求不可自证**：任何自主执行的需求结论，要么经 HIL 人类确认，要么执行 CSI 保守交集——二者必居其一，禁止「系统自认读懂了需求」直接放开；
(ii) **探询非破坏**：所有 probe 必须满足 P(损伤) ≤ δ_probe，且探询预算 B_probe、探询时长 T_probe 为硬上限；
(iii) **需求不确定 → 保守交集 + 风险收紧**：与 R68 的 λ_floor 合并为单一总闸，任何不确定性（测量/需求/能力）只导向收紧，绝不放宽。

**定义 294（需求潜变量）** h_t ∈ ℋ ⊂ ℝ⁶：h = (f_max, v_max, ε_pos, κ, p_slip^max, c_area)。f_max 力上限（温柔度）、v_max 速度上限、ε_pos 定位容差、κ 柔顺偏好、p_slip^max 可接受滑移概率、c_area 接触面积偏好。真实需求 h* 慢变：h*_{t+1} = h*_t + η_t，η ~ 𝒩(0, Q_need)。

**定义 295（双路需求证据）**
- 陈述证据 s_t（指令/UI/语言嵌入）→ 似然 p(s_t | h)；
- 揭示证据 e_t = (demo_t, correction_t, gaze_t, affect_t, outcome_t) → 似然 p(e_t | h)；
双信念：b^s_t(h) ∝ p(s_t|h)·b^s_{t−1}(h)，b^e_t(h) ∝ p(e_t|h)·b^e_{t−1}(h)。两路证据独立采集、独立更新，**不early fuse**——分歧本身就是信号。

**定义 296（需求分歧与需求熵）** I_t = W₂(b^s_t, b^e_t)（2-Wasserstein 距离）；H_need(t) = H(b_t)，b_t 为定义 299 的融合信念。语义：I_t 高 = 「说一套做一套」；H_need 高 = 「两路都读不准」。

**定义 297（灵巧手能力包络）** 抓取 q、接触集 𝒞、抓取矩阵 G(q)、手雅可比 J(q)、摩擦锥 FC_i(μ_i)、关节力矩界 [τ⁻, τ⁺]、阻抗可调范围 [κ⁻, κ⁺]。
𝓦(q) = { G(q)w : w_i ∈ FC_i(μ_i), J(q)ᵀw ∈ [τ⁻, τ⁺] }；
能力包络是把可行扳手集合投影到需求坐标上的可满足集合：
𝓔_cap(q, o) = { h ∈ ℋ : ∃ 策略 π 使 f_max、v_max、ε_pos、κ、p_slip、c_area 均可达 }。
需求可行域 Φ_t = 𝓔_cap(q_t, o_t)。

**定义 298（需求-能力差距）** g_t = ‖[(h_t − proj_{Φ_t} h_t)_+ / h_scale]‖_∞。
g_t > 0 ⇒ 当前手/物体/姿态**物理上满足不了**该需求（例如要求 < 2N 的力上限，但物体自重需 8N 才能稳持）。此时正确行为是**澄清或拒绝**，而不是硬做——「说做不到」本身就是一种需求洞察。

**定义 299（融合信念与保守交集）** b_t(h) ∝ b^s_t(h)^{w_s}·b^e_t(h)^{w_e}。当 I_t > τ_I 或 H_need > τ_H 时，CSI 执行
h_exec = ⊓ supp_ε(b_t) := (min f_max, min v_max, min ε_pos, max κ, min p_slip^max, min c_area)（逐坐标取最保守）。
语义：不确定用户要多快多用力时，**用能满足所有候选需求的最保守方式执行**。

**定义 300（探询动作集）** 探询原语 𝒰_probe = {轻捏, 侧推, 微抬, 滚动, 表面滑移测试, 分级加载}，每个 u 产生观测 z_u（脆性/摩擦/质量/重心/形状/滑移系数）。探询必须满足非破坏约束：
P(stress_max(u) > σ_damage | b_t) ≤ δ_probe，且累计探询时间 ≤ T_probe（默认 1.5s/回合）、次数 ≤ B_probe（默认 3）。

**定义 301（探询信息增益与安全化选择）**
IG(u; b_t) = H(b_t) − E_{z~p(z|u,b_t)}[H(b_{t+1})]；
u*_t = argmax_{u ∈ 𝒰_probe^safe} [ IG(u; b_t) − λ_cost·cost(u) − λ_risk·Risk(u|b_t) ]。

**定义 302（澄清动作与中断代价）** 澄清原语 𝒜_clar = {问力, 问速, 问柔顺, 确认不可行, 让用户演示一次, 不澄清}。每次澄清有中断代价 c_int(a)（时间/注意力）。把「问物」与「问人」统一为同一信息预算问题：
a*_t = argmax_a E[ΔRegret(a) | b_t] − c_int(a) − λ_probe·probe_cost(a)。

**定义 303（四源残差归因）** 把 R68 定义 280 的 cause 从 {cal, fault, real} 扩为 {cal, fault, world, need}：
P(cause | r_t, e_human, σ_stat) ∝ p(r_t | cause, ĉ)·p(e_human | cause)·P(cause)。
可分性关键：
- p(e_human | need) 高：人类纠正方向与残差方向**同向且持续**；
- p(e_human | cal/fault) 低：物理链路退化不改变人的意图，人不会系统性地同向纠正；
- p(r_t | need) 宽：需求变化主要通过 e_human 体现，而非跨模态物理残差。
⇒ need 与 cal/fault 的混淆被人类证据这条正交信道打破。

**定义 304（需求漂移检测）** 双时间尺度：快信念 b_t 用于响应，慢承诺 h̄_t 用于稳定。CUSUM 统计量 S_t = max(0, S_{t−1} + I_t − ν)；超过 τ_drift 且被 HIL 确认（或连续 N_d 次同向）才更新 h̄_t，否则判为瞬态误读。速率限制 ‖h̄_t − h̄_{t−1}‖_∞ ≤ Δ_need，防止「一次误纠正改掉整个人格」。

**定义 305（需求条件化风险）** λ_floor^need = max(0.6, 0.8·1[H_need > τ_H 或 I_t > τ_I 或 g_t > 0])；
k_need 收缩：H_need 高或 g_t > 0 ⇒ 认证前缀 k ← min(k, k_need)。
与 R68 的 λ_floor(U) 取 max，形成总闸：λ_floor^all = max(λ_floor(U), λ_floor^need)——**任何不确定性只导向收紧**。

**定义 306（灵巧度分配）** α_t ∈ [0,1] 为控制权限中分配给探询的比例（时间/接触/力矩预算）。任务收益 R_task(α) 与信息收益 R_info(α) 均凹；α*_t 平衡 ∂R_task/∂α = ∂R_info/∂α。探询带宽 B_inq ≈ α_t·min(n_c, n_red)·(1/T_probe)，n_red = n_dof − n_task 为冗余自由度。

**定义 307（J_NEED 证书）** J_NEED = (J_CALM, need_belief_hash, I_t, H_need, h_exec, Φ_t, probe_ledger, clarify_ledger, human_confirm, need_ver)。
Valid ⇔ Valid(J_CALM) ∧ (human_confirm = CONFIRMED ∨ mode = CONSERVATIVE_INTERSECTION) ∧ g_t 已处理（澄清/拒绝）∧ 探询未越非破坏界。

**定义 308（干扰集）** ℰ_NEED = ℰ_CALM × ℰ_need × ℰ_probe × ℰ_echo；
ℰ_need = {需求误读, 需求漂移漏检, 需求不可行未识别}；ℰ_probe = {探询损伤, 探询被利用, 探询预算耗尽}；ℰ_echo = {观察者效应, 回声室（把系统自己的建议当用户证据）}。

**定义 309（管线）** 离线：多用户需求语料 + 灵巧手探询仿真（含物体脆性/摩擦/质量参数）预训练 NBE/DCE/AIP；在线：双信念更新 → 四源归因 → 若 H_need/I_t/g_t 越界则探询或澄清 → CSI 保守交集 → NRC 出证 → 执行；每回合记录 probe_ledger / clarify_ledger。

# IP-253 NBE：双信念 + 分歧 + 双时间尺度漂移
class NeedBeliefEstimator:
    def __init__(self, k=6):
        self.bs = Belief(k); self.be = Belief(k)
        self.hbar = None; self.cusum = 0.0

    def update(self, s_t, e_t):
        self.bs.update(s_t); self.be.update(e_t)          # 独立更新，不 early fuse
        I  = wasserstein2(self.bs.mean(), self.be.mean())
        b  = geometric_fuse(self.bs, self.be, w_s=0.5, w_e=0.5)
        Hn = entropy(b)
        self.cusum = max(0.0, self.cusum + I - NU)         # 需求漂移 CUSUM
        if self.cusum > TAU_DRIFT and self.confirm_or_persist():
            self.hbar = rate_limited_update(self.hbar, b.mean(), DELTA_NEED)
            self.cusum = 0.0
        return b, I, Hn, self.hbar


# IP-254 DCE：能力包络（扳手锥 → 需求坐标）
def capability_envelope(grasp, object_params):
    W = wrench_cone(grasp, object_params)   # G(q)w, w_i ∈ FC_i, J^T w ∈ [τ⁻,τ⁺]
    return project_to_need_coords(W)        # → (f_max_cap, v_max_cap, ε_cap, κ_cap, ...)


# IP-257 CSI：可行需求的逐坐标保守交集
def conservative_intersection(b, eps=0.05):
    support = credible_set(b, eps)          # 覆盖概率 ≥ 1−eps 的 h 集合
    return meet(support)                    # 逐坐标最保守


# IP-255 AIP：安全探询 + 澄清，统一信息预算
class ActiveInquiryPlanner:
    def __init__(self, probes, clarifications, B=3, T=1.5):
        self.probes, self.clar, self.B, self.T = probes, clarifications, B, T
        self.used = 0

    def plan(self, b, envelope, human_avail=True):
        cands = []
        for u in self.probes:
            if self.used >= self.B or not safe(u, b, DELTA_PROBE):
                continue                                   # 非破坏硬闸
            score = info_gain(u, b) - LAM_C*probe_cost(u) - LAM_R*risk(u, b)
            cands.append((score, ('probe', u)))
        if human_avail:
            for a in self.clar:
                score = expected_regret_reduction(a, b) - c_int(a) - LAM_P*probe_cost(a)
                cands.append((score, ('clarify', a)))
        return max(cands, key=lambda x: x[0]) if cands else (0.0, ('clarify', 'none'))


# IP-256 FDA：四源归因（人类证据打破 cal/fault 混淆）
def four_way_attribution(r, e_human, c_hat, sigma_stat):
    post = {}
    for cause in ('cal', 'fault', 'world', 'need'):
        post[cause] = (p_r(r, cause, c_hat)
                       * p_human(e_human, cause)
                       * prior[cause])
    return normalize(post)


# IP-262 主闭环：NEEDLE round
def NEEDLE_round(M, obs):
    s_t, e_t, r, q, o = obs
    # 1) 双信念 + 需求分歧/熵
    b, I, Hn, hbar = M.nbe.update(s_t, e_t)
    # 2) 能力包络与需求-能力差距
    Ecap = M.dce.envelope(q, o)
    g    = need_capability_gap(b.mean(), Ecap)
    # 3) 四源归因（承接 CALM-RAS 的 cal/fault/world，新增 need）
    cause = M.fda(r, e_t, M.c_hat, sigma_stat(M))
    # 4) 主动探询 / 澄清（仅在需求侧不确定时启动）
    confirmed = False
    if cause == 'need' or Hn > TAU_H or I > TAU_I or g > 0:
        _, (kind, u) = M.aip.plan(b, Ecap, human_avail=M.human_available)
        if kind == 'probe':
            z = M.hand.execute_probe(u)               # 非破坏探询
            b = M.nbe.assimilate(z)
        elif kind == 'clarify':
            b, confirmed = M.hil.ask(u, b)            # 人类确认 or 演示一次
    # 5) 不可行 ⇒ 澄清/拒绝，绝不硬做
    if g > 0:
        M.hil.surface_infeasible(b, Ecap)
        return 'REFUSE_OR_CLARIFY', (b, I, Hn, g)
    # 6) 需求执行量：确认则用 h̄，否则保守交集
    h_exec = hbar if confirmed else M.csi.intersect(b)
    # 7) 风险缩放：与 R68 测量层总闸合并
    lam = max(M.efs.risk_scale(M.joint_post),
              lam_floor(M.U),
              lam_floor_need(Hn, I, g))
    k = min(M.c_ras_wm.certified_prefix(M.A, M.joint_post, M.m_ras, M.alpha_chunk, M.wm_preds),
            k_need(Hn, g))
    # 8) 控制：把 h_exec 映射为力/速/柔顺，再走 R68 的 ERS-WM
    tau = M.pi_sigma.prefix_dispatch(M.A[:k]) * lam
    tau = need_conditioned_compliance(tau, h_exec)     # f_max / v_max / κ 生效
    tau = emotion_response_shaping_wm(tau, M.joint_post, M.wm_preds)
    # 9) 出证 + 影子提交（继承 R68 CAC）
    M.nrc.issue(J_CALM=M.jcalm, I=I, Hn=Hn, h_exec=h_exec,
                Phi=Ecap, probe=M.aip.ledger, clarify=M.hil.ledger,
                human_confirm=confirmed)
    M.cac.maybe_commit(M.shadow, M.time_since_last_commit)
    return k, lam, h_exec, (b, I, Hn, g, cause)

## 3. 推导

**引理 16（探询信息增益的预算上界）** 设每次探询的观测信道容量 ≤ C_max，且探询在非破坏约束下最多 B_probe 次，则累计互信息 I(h; z_{1:B}) ≤ B_probe·C_max。又因需求维度 k = 6，当 B_probe ≥ k 后，边际信息增益受信道秩（≤ k）限制而饱和。系：**探询并非越多越有洞察——超过 k 次的探询只增加损伤暴露与时间成本，不增加需求信息**；这给出 B_probe 默认值 3 的理由（少于 k，因每次多通道接触可降不止一维）。

**引理 17（冗余自由度 = 探询带宽）** 手有 n_dof，任务占用 n_task，则可用于探询而不破坏任务的冗余自由度 n_red = n_dof − n_task；受接触约束，可并行的安全探询通道数 ≤ min(n_red, n_c)，故 B_inq = O(min(n_red, n_c)/T_probe)。系：**灵巧手相对二指夹爪的需求洞察优势随冗余度近似线性增长**——这正是「灵巧手」在这一问题里不可替代的量化理由。

**引理 18（需求漂移 vs 传感器漂移的可分性）** 设人类纠正信号 e_human 在给定 cause 下与物理残差 r 条件独立，且 cal/fault 下不产生系统性同向纠正（P(同向 | cal/fault) ≈ 0.5），need 下 P(同向 | need) = 1/2 + Δ。则 n 次观测后贝叶斯错误率 P(err) ≤ exp(−2nΔ²)（Chernoff）。系：need 与 cal/fault 的可分性随交互轮数指数提升；但在「需求漂移与故障并发」的混淆集上，可分性退化为 min 项，需要 S_t 与 U(ĉ) 联合判据。

**定理 16（需求对齐 regret 界与向后兼容）** 在 A95–A98（需求慢变、探询非破坏、人类证据正交、能力包络可估）下，π_NEEDLE 相对已知 h* 的 oracle 的 regret：
Regret ≤ √(2·H_need·C_probe) + (1 − 1[confirmed])·g_t·R_scale + λ_floor^need·R_max，
即「探询未消除的需求熵」「未确认时的能力差距」「保守交集的机会成本」三项。特别地，当 H_need → 0 或 human_confirm = CONFIRMED 时前两项消失，NEEDLE 退化为 R68 的 CALM-RAS——**向后兼容，不推翻既有保证**。

**定理 17（保守交集的需求层安全性）** 若 b_t 以概率 ≥ 1 − δ 覆盖 h*，则 CSI 的交集执行对 supp_ε(b_t) 内任意 h 的违反概率 ≤ δ + 机会成本项；即「不确定时逐坐标取最保守」以效率换取**支撑集内零需求违反**。这是 λ_floor（测量层）在需求层的严格对应物：两者共享同一「不确定只许收紧」的公理。

**定理 18（观察者效应 / 回声下界）** 设探询 u 对用户期望的塑造为 h*_obs = h* + β·u + noise（β 为观察者效应系数）。当 β 不可辨识时，仅用自我探询证据做需求估计的偏差下界 ≥ β·E[u]，且该偏差**不能靠增加同类探询消除**——因为探询本身持续制造偏差，估计量收敛到不动点 h* + β·u* 而非 h*。故必须引入与探询独立的证据源（第三方演示 / 人类确认 / 跨会话历史），HIL 不是可选装饰而是**打破回声的数学必要条件**。

## 6. 本轮最大风险

**一句话**：NEEDLE 把「需求」当作可以被安全探询还原的固定潜变量，但需求是社会建构且会被探询本身塑造的——**系统可能用灵巧手极其精准地满足一个自己「探测/建议出来」的伪需求（观察者效应与回声室，定理 18），而用户从未真正提出它，甚至会在被系统暗示后误以为那就是自己想要的**；需求洞察越主动，越可能测到自己的回声，这是「用能力去定义需求」范式的原罪。

## 4. 推导

**引理 16（探询信息增益预算上界）** 每次探询信道容量 ≤ C_max、最多 B_probe 次 ⇒ 累计互信息 ≤ B_probe·C_max；需求维度 k=6 使边际增益在 B_probe ≥ k 后饱和。系：超过 k 次的探询只增加损伤暴露，不增加洞察 ⇒ B_probe 默认 3。

**引理 17（冗余自由度 = 探询带宽）** n_red = n_dof − n_task，可并行安全探询通道 ≤ min(n_red, n_c)，B_inq = O(min(n_red,n_c)/T_probe)。系：灵巧手相对二指夹爪的需求洞察优势随冗余度近似线性增长。

**引理 18（需求漂移 vs 传感器漂移可分性）** 人类纠正 e_human 在 cal/fault 下同向概率 ≈0.5、在 need 下为 1/2+Δ ⇒ n 次后错误率 ≤ exp(−2nΔ²)。系：交互轮数越多越可分；需求漂移与故障并发时退化为 min 项，需 S_t × U(ĉ) 联合判据。

**定理 16（需求对齐 regret 界与向后兼容）** Regret ≤ √(2·H_need·C_probe) + (1−1[confirmed])·g_t·R_scale + λ_floor^need·R_max。当 H_need→0 或人类确认时前两项消失 ⇒ 退化为 CALM-RAS，**不推翻 R68 既有保证**。

**定理 17（保守交集的需求层安全）** 若 b_t 以概率 ≥ 1−δ 覆盖 h*，则 CSI 对 supp_ε(b_t) 内任意 h 的违反概率 ≤ δ + 机会成本 ⇒ 以效率换取支撑集内零需求违反，是 λ_floor 在需求层的严格对应。

**定理 18（观察者效应下界 / 回声）** 探询塑造 h*_obs = h* + β·u + noise；β 不可辨识时，仅用自我探询的估计偏差 ≥ β·E[u]，且**不随同类探询增多而消除**（收敛到不动点 h*+β·u*）⇒ 必须引入独立证据源（第三方演示/人类确认），HIL 是数学必要条件。

## 7. 本轮最大风险

**一句话**：NEEDLE 把「需求」当作可被安全探询还原的固定潜变量，但需求会被探询本身塑造——**系统可能用灵巧手精准满足一个自己「探测/建议出来」的伪需求（观察者效应与回声室，定理 18），而用户从未真正提出它**；需求洞察越主动，越可能测到自己的回声。

**次级风险与缓解**：需求误读 → 双信念不 early fuse + HIL 确认；漂移漏检/人格突变 → CUSUM + 速率限制 Δ_need；探询损伤 → δ_probe 硬闸 + 引理 16 预算；探询被恶意利用 → ANC 干扰语料 + 非破坏约束；能力包络估计偏差 → DCE 保守投影 + g_t 触发拒绝而非硬做。
