# 第 70 轮（承接第 69 轮「FLUID-RAS」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「指标体系」×「多模态融合」）

> R69 让系统学会「问」，却把一个更深的假设留在地下：**它用来判断「该不该问、问得对不对」的那整套分数（VoI、ECE、Δa、r_res、U_ale/U_epi、k 源一致）被当成了上帝视角。** 摊开看，这恰恰是一个最典型的多模态指标体系——单位各异（bit、nat、米、焦耳、概率、秒），来源相关（r_geo 与 r_sync 同出相机），却被一个 `voi − cost` 或 `max(...)` 的标量运算揉在一起。这正是「综合指标」方法论的老病：**用加权和把「价值偏好」伪装成「测量事实」，用相加把「相关证据」当成「独立证据」。**
>
> 本轮两个灵感从两个方向切进来：
> - **指标体系**：指标不是一堆数，而是带类型（可公度性）、带偏序（不可补偿）、带溯源（可归因）、带校准基准（reference frame）的**结构对象**；综合不等于求和。
> - **多模态融合**：融合只应发生在「可公度、已校准、已去相关」的测量层；把评价与决策也塞进融合，就是把偏好混进物理量。
>
> 核心命题：**把 R69 的「一锅烩分数」拆成三层——测量层（多模态、可公度、去相关、带元不确定性）／评价层（显式偏好、非补偿、输出偏序而非标量）／决策层（可审计、抗操纵）；多模态融合只允许发生在测量层内，评价与决策绝不再被「融合」成单一分数。** 命名 **MERIDIAN-RAS**（Multimodal Evidence Reference-frame Integration with Decision-audited Indicator Aggregation, Non-compensatory）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我用什么尺子判断求证是否成功——而尺子本身可不可信**」。

## 0. 直觉与动机

**灵感 1（标量综合的原罪 → 测量、评价、决策是三件事）**
直觉：R69 的 `score = VoI(g) − c(g)` 看起来是算术，其实是**一个被藏起来的价值判断**——「减少 1 bit 不确定性值多少焦耳/多少社交尴尬」。换一组权重，同一个物理场景会翻转决策，但没有任何物理量变过。这正是「综合指标」最深的病：**它把「我们偏好什么」伪装成「世界是什么样」。** 严格地说，测量回答「是多少」（有单位、可校准、主体间可复现），评价回答「哪个更好」（带偏好、本质多目标），决策回答「做什么」（必须显式且可审计）。三者一旦压成一个标量，就再也无法把任何一次事故归因到「测量错了」「偏好错了」还是「决策错了」。

**灵感 2（单位不可公度 → 融合必须有公共基准，而不是归一化）**
直觉：把 r_res（米）、Δa（nat）、ECE（概率）、VoI（bit）各自 min-max 归一化后相加，是「多模态融合」里最常见的偷懒。问题是归一化的分母来自当前数据分布——**分布漂移时分母变了，同一个物理状态会得到不同的综合分**。真正的多模态融合需要一把「本初子午线」：把每个模态指标经一个**校准映射**投到统一的、外部可验证的物理基准上（本轮取「期望伤害当量」RRE）。只有落在同一个基准上的量，相加才有意义；不能投射的（纯信息量）就不许进风险账本，而是进另一本「信息预算账」。

**灵感 3（相关证据的重复计数 → 「k 源正交」从未验证正交）**
直觉：R69 引理 18 承诺「k 个正交源一致可把错误率压到 ≤ δ_p·ρ^{k−1}」，但 ρ 从未被测量。而 r_geo 与 r_sync 同出相机、r_emo 与 r_wm 共享同一段表征——它们高度共模。**把相关的证据当成独立证据相加，就是重复计数：你以为有 k 票，实际只有 N_eff < k 票。** 多模态融合的第一个技术动作不是「加起来」，而是「先量相关性、再折成有效票数」。

**灵感 4（交互让指标可被操纵 → Goodhart 被推高一层）**
直觉：R69 一旦会「问」，被测的人就可以反过来学习这套指标：知道系统重视频繁确认，就故意给「看起来很配合」的答案；知道某分数决定是否追问，就专门优化那个分数。**任何被测系统能观测并优化的指标，都会逐渐脱离它本来要测的真值**（Goodhart）。R69 用「k 源一致」防单点撒谎，但如果所有源都受同一被测者影响，一致性只是「共谋的成功」。指标体系必须自带「代理-真值间隙」监测，并在间隙扩大时**撤销该指标的权威**。

**灵感 5（非补偿不是更保守，而是让偏好可证伪 → 但要防死锁）**
直觉：安全的本质是**不可补偿**——再高的任务收益也不能「买回」一次越界。加权和允许补偿，所以能被「补偿攻击」击穿（用巨大收益抵消一次违规）。把安全写成硬约束、把评价输出成 Pareto 偏序而非标量，就堵死了这条通道。但代价是**可行集可能为空**（F=∅）：所有动作都违反某条硬约束，系统会僵住。所以非补偿必须配一个**显式的降级阶梯**（F=∅ → 退回 R69 → 退回 R68），而不是默默放宽约束。这也是本轮与 R69 的接口：新层必须能退化成旧层。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（MERIDIAN-RAS 总览）** MERIDIAN-RAS = (TML, RRE, CAF, NCE, ADM, G3, MAL)。三不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **层间单向**：信息只能 测量 → 评价 → 决策 单向流动；决策不得回写测量（禁止「为了做决定而篡改测量」）；评价层的偏好必须显式记录、可审计、可被外部否决；
(iii) **融合禁区**：多模态融合仅发生在测量层；评价层输出偏序集而非标量；决策层若做任何 scalarization，必须携带**偏好签名**（preference signature），无签名的标量视为非法。

**定义 311（三层指标账本 TML）** L0 测量层 = 原始模态 {μ_m} 与派生指标 {ι_j}，每个 ι_j 带类型 τ_j、单位 u_j、溯源 prov_j、元误差 meta_j；L1 评价层 = (H, O, ≼_pref)，H 为硬约束集、O 为软目标集、≼_pref 为显式偏好关系；L2 决策层 = 选择规则 D: Feasible → 𝒜。三层之间只允许单向引用，账本每层独立可审计。

**定义 312（统一风险当量 RRE 与可公度校准 κ）** 存在校准映射 κ_j: I_j → ℝ_{≥0} 投到「参考风险当量」（Reference Risk Equivalent，外部可验证的物理量，如期望碰撞能/期望伤害）。要求 κ_j 为 ratio-scale（κ(ax)=aκ(x)）且在留出参照集上报告校准误差。**不能投到 RRE 的指标（如纯信息量 VoI）禁止进入风险账本**，改记于独立的「信息预算账本」；两类账本不得相减。

**定义 313（指标类型系统与可公度性）** τ ∈ {ratio, interval, ordinal, nominal}，只有 ratio/interval 允许算术融合；ordinal 只许比较，nominal 只许计数。两指标可公度（ι_i ~ ι_j）⇔ 共享同一参照系且都按兼容尺度投到 RRE。跨不可公度指标做融合是**类型错误**（undefined），而不是「权重取 0」。

**定义 314（测量层多模态融合 CAF）** 对可公度校准证据 {e_j = κ_j(ι_j)}，用广义最小二乘融合：
e_fused = (1ᵀR⁻¹e)/(1ᵀR⁻¹1)，Var(e_fused) = 1/(1ᵀR⁻¹1)，
其中 R 为误差相关矩阵（由「共源 DAG + 残差相关」估计并做收缩）。融合同时写出一条溯源 DAG，记录哪些原始模态、哪个融合算子、哪个校准版本参与。

**定义 315（有效证据数与相关折扣 N_eff）** 令 ρ̄ 为 R 的非对角平均相关，N_eff = N / (1 + (N−1)ρ̄)。ρ̄=0 ⇒ N_eff=N；ρ̄=1 ⇒ N_eff=1。任何「k 源一致」的置信必须用 N_eff 而非名义 N 计算（见引理 19）。

**定义 316（元不确定性与二阶传播）** 每个 κ_j 携带校准不确定度 meta_j；用 delta 法/区间算术传播到 e_fused，得到二阶可信区间 [e_lo, e_hi]。安全约束一律用最坏侧 e_hi，收益估计用 e_lo——**决策必须对该区间稳健**。

**定义 317（评价层：硬约束 + Pareto，非补偿）** 可行集 F(a) = {a : ∀h∈H, e_hi(h,a) ≤ θ_h}（硬性、非补偿、最坏侧）；在 F 上取软目标 O 的 Pareto 前沿 P。**禁止任何跨 H 与 O 的补偿性加权**：补偿分数 S=Σw_j s_j(a) 不得覆盖 H 的否决。

**定义 318（显式偏好与风险-信息交换曲线）** 偏好 ≼_pref 是显式、版本化、可审计的对象（不是藏在阈值里的隐式权重），可编码字典序 H ≻ O_1 ≻ …。是否花信息预算由一条显式的**风险-信息交换曲线 β** 决定（多少 RRE 降幅值一单位交互成本），β 必须被声明与签名，默认取保守值。R69 的 `voi − cost` 是 β 被隐式硬编码的特例。

**定义 319（决策层：可审计选择 ADM）** 给定 F 与 P：(1) F=∅ ⇒ 安全降级（R69 → R68）；(2) |P|=1 ⇒ 直取；(3) 否则按 ≼_pref 选，平手时取「离 H 边界最大余量」（max-min slack）。每次决策输出带溯源链接的 justification。

**定义 320（抗操纵指标与操纵增益 MG）** 被测者可影响指标。操纵增益 MG_j = 在被测者策略集上 sup (Δι_j)/(Δ 真值)。MG_j > τ_mg 的指标降级为「仅审计」；安全硬约束 H 只许用低 MG 指标。

**定义 321（Goodhart 间隙门 G3）** 代理-真值间隙 D_GT(t) = |ι_j − truth_proxy| 在「ι_j 正被优化」的同等条件下度量。若 dD_GT/dt > 0 且 dι_j/dt > 0 持续出现 ⇒ 撤销 ι_j 的权威（冻结到校准时刻值），写 AuditBuf。G3 不是消灭 Goodhart，而是把它变成**有界且有记录**的漂移。

**定义 322（指标溯源账本 DAG）** 每个派生指标存储 provenance = (原始模态, 融合算子, 校准版本, 算子版本, 偏好签名)，支持反事实归因：判定是由哪个模态/哪个融合/哪条偏好造成的。

**定义 323（指标体系自审计 MetricAuditor，深度上限 2）** 只审计一阶指标与融合算子，**不审计自身**（把回退在设计上截断到 2 阶）；由外部签名的参照集离线验证审计器。未通过的元指标一律进「仅审计」，永不进 H。

**定义 324（威胁模型 ℰ_metric）** 单位混淆（篡改尺度）、相关伪造（隐藏共模误差使 N_eff 虚高）、指标投毒（训练期污染 κ）、评价投毒（篡改偏好或交换曲线 β）、Goodhart 诱导（被测者学习指标）。ℰ_MERIDIAN = ℰ_FLUID × ℰ_metric。

**定义 325（证书 J_MERIDIAN）** J_MERIDIAN = (J_FLUID, rre_cal_error, N_eff, meta_coverage, preference_signature_hash, g3_alarms, mg_p95, metric_audit_hash, meridian_ver)。Valid ⇔ Valid(J_FLUID) ∧ rre_cal ≤ τ_rre ∧ meta_coverage ≥ 1−α ∧ 偏好签名有效 ∧ 无未处理 G3 告警。

**定义 326（退化与两级退避扩展）** 若所有指标 ratio 可公度、ρ̄=0（N_eff=N）、MG=0、且 ≼_pref 退化为单一线性权重 ⇒ MERIDIAN 决策**逐指令等于** R69 FLUID 决策。若 F=∅、G3 触发或偏好签名失效 ⇒ 依次降级到 R69、再 R68。安全侧永不弱于 R69。

## 2. 关键算法骨架

```python
# IP-265 RRE：把每个模态指标校准到统一风险当量（不可投射者进信息账本）
def calibrate_to_rre(indicators, ref_frame):
    risk_book, info_book = {}, {}
    for j, iota in indicators.items():
        if iota.type in ("ratio", "interval") and ref_frame.can_map(iota):
            risk_book[j] = ref_frame.kappa[j](iota)          # ratio-scale, 带 meta_j
        else:
            info_book[j] = iota                               # VoI 等禁止进风险账本
    return risk_book, info_book

# IP-266 CAF：相关感知的 GLS 融合 + 溯源（绝不 naive sum）
def fuse_correlation_aware(evidence, R, prov):
    w = solve(R, ones)                       # R^{-1} 1
    e_fused = (w @ evidence) / (w @ ones)
    var     = 1.0 / (w @ ones)
    rho_bar = mean_offdiag(R)
    N_eff   = len(evidence) / (1 + (len(evidence) - 1) * rho_bar)
    prov.record(evidence.keys(), "GLS", R.version)        # 溯源 DAG
    return e_fused, (var, rho_bar, N_eff)

# IP-267 NCE：非补偿评价（最坏侧硬约束 + Pareto，不做跨层加权）
def noncompensatory_evaluate(actions, risk_book, H, O):
    feasible = [a for a in actions
                if all(worst_case(risk_book, h, a) <= H[h].theta for h in H)]
    if not feasible:
        return None                                       # F=∅ → 降级 R69/R68
    return pareto_front(feasible, O)                      # 输出偏序，不输出标量

# IP-268 ADM：可审计决策（字典序偏好 + 最大安全余量）
def auditable_decide(P, pref, H, risk_book):
    if len(P) == 1: return P[0], emit_justification(P[0], H)
    ranked = sort_by(P, pref)                             # 显式偏好签名驱动
    best_score = max(min_margin(a, H, risk_book) for a in ranked[:k_tie])
    return argmax_margin(ranked[:k_tie], H, risk_book), emit_justification(...)

# IP-271 G3：Goodhart 间隙门（权威可撤销，只做有界漂移）
def goodhart_gate(iota_hist, truth_hist, authority):
    d_gt  = [abs(i - t) for i, t in zip(iota_hist, truth_hist)]
    if trend(d_gt) > 0 and trend(iota_hist) > 0:
        authority.revoke(iota_hist.name)                  # 冻结到校准时刻值
        audit_buf.push("G3", iota_hist.name)
    return authority

# IP-270/272 抗操纵 + 指标体系自审计（深度上限 2）
def metric_audit(indicators, R, ref_frame):
    for j, iota in indicators.items():
        if manipulation_gain(iota) > TAU_MG:
            iota.set_authority("audit_only")              # 不进 H
    return MetricAuditor(ref_frame, depth=2).verify(indicators, R)

# IP-276 主闭环（继承 R69 FLUID_RAS_round，仅在"分数如何合成"处替换为三层账本）
def MERIDIAN_round(M, obs):
    z, c, U_cal, thr = M.floyd_forward(obs)               # R69 一次前向 + 标定
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(obs, K)
    U_ale, U_epi, modes = M.aud.decompose(samples, z, M.fmp.mode_head)
    # L0 测量层：先量相关性、再融合；不可公度者分账
    risk_book, info_book = calibrate_to_rre(M.indicators(obs, samples), M.ref)
    e_risk, (var, rho_bar, N_eff) = fuse_correlation_aware(
        list(risk_book.values()), M.corr_est(obs), M.prov)
    M.prov.attach(z, modes)
    # L1 评价层：硬约束（最坏侧）+ Pareto；偏好显式，不隐式加权
    P = noncompensatory_evaluate(M.candidates(modes), risk_book, M.H, M.O)
    # L2 决策层：可审计选择；F=∅ 或 G3 触发则降级
    if P is None or M.g3.alarm:
        return M.r69_degrade(obs)                         # 严格回到 FLUID → CALM
    mode, just = auditable_decide(P, M.pref, M.H, risk_book)
    # 信息动作：走信息预算账本，用显式交换曲线 β，绝不与风险当量相减
    g = M.mint.choose_interaction(modes, info_book, M.budget, beta=M.beta)
    if g is not None:
        answer = M.cia.execute(g)
        U_epi  = M.cia.update_belief(modes, answer, discipline="k_eff_agree")
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + (U_epi if g is None else 0.0)))
    k   = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    M.vqa_i.submit_async(g, just, N_eff, rho_bar, e_risk)
    return k, lam, mode, (U_ale, U_epi, N_eff)
```

## 3. 推导

**引理 19（相关证据的重复计数）** 设 N 个来源两两平均相关 ρ̄。朴素独立融合（对数似然相加）使证据量按 N 增长，但真实独立证据只按 N_eff = N/(1+(N−1)ρ̄) 增长，过度自信因子为 N/N_eff。R69 引理 18 的 δ_p·ρ^{k−1} 上界要求 k 个来源**真正独立**；存在共模时实际上界退化为 δ_p·ρ_eff^{N_eff−1}。当 N_eff < k 时该界严格更松，**R69「≤1%」的承诺在未测 ρ 时并不成立**。系：多模态融合必须先估 R 再融合，否则「多源一致」只是共谋的另一种写法。

**引理 20（可公度/单位不变性）** 采用 RRE ratio-scale 与 GLS 融合时，对任一模态单位做正仿射重标定（相应重算 κ）不改变可行集 F 与 Pareto 前沿 P——因为约束全部表达在 RRE 上（测量不变性）。反之，min-max 归一化加权和的综合分随总体 min/max 漂移而改变，**分布漂移下可在物理状态不变时翻转决策**。故 RRE+GLS 可复现，归一化加权和不可复现。

**引理 21（非补偿消除补偿攻击）** 加权和 S = Σ_j w_j s_j(a) 中令安全分量在越界时取有限负值、收益分量无界，则对任意越界动作 a* 与任意阈值都存在足够大的收益使其 S(a*) ≥ 阈值（补偿）。在硬约束 F = {a : e_hi(h,a) ≤ θ_h} 下，任何越界 a* ∉ F，且不可被任何收益重新接纳（字典序可采纳性）。⇒ 非补偿封住补偿攻击面，代价是可能 F=∅（见定义 319 的降级阶梯）。

**定理 18（MERIDIAN 严格包含 FLUID-RAS）** 在退化条件（ratio 可公度、N_eff=N、MG=0、≼_pref 为单一线性显式权重）下，MERIDIAN 决策逐指令等于 FLUID-RAS；一般情况下在安全约束集上风险(MERIDIAN) ≤ 风险(FLUID-RAS)，因为 (a) ρ>0 时 GLS 融合方差 ≤ 朴素相加；(b) 硬约束不可被收益补偿；(c) G3 阻止被游戏或过期的指标进入 H。F=∅ 时降级链精确返回 R69 再 R68。安全侧不作让步，效率侧获得「可审计的偏好收益」。

**定理 19（Goodhart 有界）** 若 G3 在 D_GT 超过 τ_GT 的时刻 τ 撤销权威，则被游戏指标造成的决策误差 ≤ 撤销时刻的校准误差 + 检测窗内累积漂移。权威撤销阻止误差无界发散（但不消除：检测窗内仍有一块有界盲区）。系：指标体系的鲁棒性上限由「检测窗长度 × 漂移率」决定，必须把窗长写进证书 J_MERIDIAN。

## 6. 本轮最大风险

## 3. 关键算法伪代码

```python
# IP-265 RRE：校准分账（可投射→风险账本；不可投射→信息账本）
def calibrate_to_rre(indicators, ref):
    risk, info = {}, {}
    for j, iota in indicators.items():
        (risk if ref.can_map(iota) else info)[j] = (
            ref.kappa[j](iota) if ref.can_map(iota) else iota)
    return risk, info

# IP-266 CAF：相关感知 GLS 融合 + N_eff + 溯源（绝不 naive sum）
def fuse_correlation_aware(evidence, R, prov):
    w = solve(R, ones)
    e = (w @ evidence) / (w @ ones)
    var = 1.0 / (w @ ones)
    rho = mean_offdiag(R); n = len(evidence)
    prov.record(evidence.keys(), "GLS", R.version)
    return e, var, n / (1 + (n - 1) * rho)

# IP-267 NCE：非补偿评价（最坏侧硬约束 + Pareto）
def noncompensatory_evaluate(actions, risk, H, O):
    feasible = [a for a in actions
                if all(worst_case(risk, h, a) <= H[h].theta for h in H)]
    return pareto_front(feasible, O) if feasible else None   # F=∅ → 降级

# IP-271 G3：Goodhart 间隙门（权威可撤销，漂移有界）
def goodhart_gate(iota, truth, authority):
    if trend([abs(i - t) for i, t in zip(iota, truth)]) > 0 and trend(iota) > 0:
        authority.revoke(iota.name); audit_buf.push("G3", iota.name)
    return authority

# IP-276 主闭环（继承 R69，仅在"分数如何合成"处替换为三层账本）
def MERIDIAN_round(M, obs):
    z, c, U_cal, thr = M.floyd_forward(obs)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes = M.aud.decompose(M.fmp.sample(obs, K), z, M.fmp.mode_head)
    risk, info = calibrate_to_rre(M.indicators(obs), M.ref)          # L0
    e, var, N_eff = fuse_correlation_aware(list(risk.values()), M.corr_est(obs), M.prov)
    P = noncompensatory_evaluate(M.candidates(modes), risk, M.H, M.O) # L1
    if P is None or M.g3.alarm:
        return M.r69_degrade(obs)                                     # 严格回 FLUID→CALM
    mode, just = auditable_decide(P, M.pref, M.H, risk)               # L2
    g = M.mint.choose_interaction(modes, info, M.budget, beta=M.beta) # 信息账本，不与风险相减
    if g is not None:
        U_epi = M.cia.update_belief(modes, M.cia.execute(g), "k_eff_agree")
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + (U_epi if g is None else 0.0)))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    M.vqa_i.submit_async(g, just, N_eff, e)
    return k, lam, mode, (U_ale, U_epi, N_eff)
```

## 4. 推导

**引理 19（相关证据的重复计数）** N 源两两相关 ρ̄ 时，朴素独立融合的过度自信因子为 `N/N_eff`（`N_eff=N/(1+(N−1)ρ̄)`）。R69 引理 18 的 `δ_p ρ^{k−1}` 要求真正独立；共模下实际界退化为 `δ_p ρ_eff^{N_eff−1}`。当 `N_eff<k` 时 R69 的「≤1%」承诺不成立——多模态融合必须先估 R 再融合。

**引理 20（可公度/单位不变性）** RRE+GLS 下，对任一模态做正仿射重标定（相应重算 κ）不改变 F 与 P（测量不变性）；而 min-max 归一化加权和随总体极值漂移，可在物理状态不变时翻转决策。⇒ RRE+GLS 可复现，归一化加权和不可复现。

**引理 21（非补偿消除补偿攻击）** 加权和 S=Σw_j s_j 令安全越界取有限负值、收益无界，则任意越界动作都能被足够大收益「买回」；硬约束 `F={a:e_hi(h,a)≤θ_h}` 下越界动作永不入 F，任何收益都无法重新接纳（字典序可采纳性）。代价是可能 F=∅。

**定理 18（MERIDIAN 严格包含 FLUID-RAS）** 退化条件（ratio 可公度、N_eff=N、MG=0、线性显式偏好）下逐指令等于 FLUID-RAS；一般情形安全约束集上风险 ≤ R69（GLS 方差 ≤ 朴素相加、硬约束不可补偿、G3 阻挡被游戏/过期指标进 H）；F=∅ 时精确降级 R69→R68。

**定理 19（Goodhart 有界）** G3 在 `D_GT>τ_GT` 时撤销权威，则被游戏指标导致的决策误差 ≤ 撤销时校准误差 + 检测窗内累积漂移；权威撤销阻止无界发散，但留一块有界盲区——其大小须写入 J_MERIDIAN。

## 7. 本轮最大风险

**一句话**：MERIDIAN 的改进全押在「评价层能显式声明真正偏好」这一前提上，而交互场景里偏好恰恰未知且可被诱导——**一旦把某个推测偏好固化成不可补偿硬约束，系统就可能以「安全」之名锁死一个错误的价值判断；同时防操纵的元指标（ρ、元不确定性、D_GT）本身成为新的可操纵目标，Goodhart 只是被推高一层，而「审计审计者」在定义 323 被硬性截断为 2 阶，留下承认但未消除的盲区。**

**次级风险与缓解**：F=∅ 决策僵死（定义 319 降级阶梯 + E305）；共模相关估计不准使 N_eff 虚高（多窗收缩 + 定义 324 + E302）；RRE 校准被投毒（外部签名参照集 + MetricAuditor + E310）；指标类型误用（定义 313 编译期拒绝跨不可公度融合）；偏好签名治理与版本污染（J_MERIDIAN + E312）。
