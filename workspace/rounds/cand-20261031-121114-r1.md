# 第 13 轮 · 想法区（2026-10-31）

> 灵感词：**数据集构建 / 扩散策略 / 结构优化**
> 赛道：宇树 UniBot 世界挑战赛（G1 + Dex1，32 任务，单模型，远程真机 API）

## 0. 一句话押注

**用 5 类测试轴定向、几何一致且动作可验证的数据构建，把 33k 条名义演示扩成接近测试分布的 10–20 万条训练数据；模型侧只保留两项轻量结构适配（joint/EE 跨空间一致性 + 阶段感知双臂/单臂门控），扩散头在 8 步执行 chunk 上做 4 关键帧，不做 30 步稠密预测，也不从零训更大的 VLA。**

### 1.5 本轮思考路径

1. 先把 3 个灵感词分别落到挑战赛约束上：数据集构建 → 5 个测试轴；扩散策略 → 执行 chunk/关键帧；结构优化 → joint/EE 与双臂接口。
2. 查官网/手册，发现排行榜下线、测试 100% 是 OOD 泛化；这直接推翻了“更大模型优先”的直觉。

5. 把“结构优化”收敛到两个能吃到 API 红利的点：joint/EE 跨空间一致性、阶段感知双臂/单臂门控。

## 2. 诊断：为什么“更大 VLA”不是本轮最优解

### 2.1 测试分布是 5 个轴的混合
官方手册把测试拆成 5 类泛化，每类 2 次，共 10 次/任务。也就是说，测试分布近似为

`P_test ≈ (1/5) · (P_pos + P_distract + P_bg + P_unseen + P_human)`。

训练集 33k 演示几乎全部是“正常位置、正常背景、已知物体、无人干扰”的成功轨迹。用统计学习的话说，测试误差上界由三部分组成：nominal 误差、分布距离、假设类复杂度。上一轮把注意力放在“更大模型/更强执行器”，但 **分布距离项才是当前最大的可压缩项**；而它主要靠数据构建，不靠参数量。

### 2.2 演示覆盖的是 nominal 成功轨迹
HangCup 的实测可以说明“演示很窄”：
- 前 250 episodes 的初始右 EE 位置标准差为 **[34.2, 63.9, 10.9] mm**（x/y/z），90% 区间约 **15×8×3 cm**；
- 而右臂全轨迹的 p5–p95 范围约 **21×28×18 cm**。初始位置覆盖远小于可用空间，位置轴增广有明确空间。
- 右臂 `action - state` 的 EE 位移中位数 **16.2 mm**、p95 **39.9 mm**；关节角中位数 **0.0174 rad**、p95 **0.0904 rad**。动作增量很小，说明“相对动作 + 绝对组合”的重定向是可行的。
- HangCup 是单臂任务：300 个 episode 中右夹爪 100% 有开合，左夹爪 100% 静止（range < 0.05）。这提醒我们：**双臂结构不能无条件套到所有任务**，必须有单臂门控。

### 2.3 关键帧的负结果与正结果（本地实测）
在 300 个 HangCup episode 的右臂轨迹上，用 Douglas–Peucker 选关键帧、三次样条重建，统计“位置最大误差 ≤5 mm 且姿态最大误差 ≤5°”的窗口比例（125,253 个 active windows，位移 >5 mm）：

| 执行 chunk W | K=2 | K=3 | K=4 | K=5 | K=8 | K=10 |
|---|---|---|---|---|---|---|
| 8 | 69% | **93%** | **96%** | 98% | 100% | – |
| 10 | 58% | 86% | 90% | 95% | 99% | 100% |
| 15 | 29% | 62% | 71% | 83% | 95% | 97% |
| 20 | 11% | 39% | 50% | 64% | 89% | 94% |
| 30 | 1% | 10% | 21% | 37% | 67% | 81% |

结论很明确：
- **整段 6s episode 用 5–8 个关键帧是灾难**：右臂 K=8 的位置最大误差中位数 **86.5 mm**，K=15 仍有 **33.5 mm**；naive “稀疏关键帧替代 30 步稠密扩散”应当剪枝。
- **8 步执行 chunk 用 3–4 个关键帧是可行的**：K=3 有 93%、K=4 有 96% 的窗口在 5 mm / 5° 内。参考实现默认 `ACTION_CHUNK_SIZE = 8`，这不是巧合，而是可以主动利用的接口自由度。
- 注意这是 **oracle 关键帧 + 样条插值** 的“表示容量”上界，不是模型预测精度；真实系统还要加预测误差，所以 K=4 比 K=3 更稳。

### 2.4 阶段结构是真实存在的
HangCup 400 个 episode 中，右夹爪闭合发生在 episode 的 **39%**（p5–p95：24–45%），打开发生在 **81%**（42–85%）；89.2% 的 episode 恰好一次闭合、一次打开。也就是说，“approach → grasp/transport → hang/release”是稳定的阶段结构，但阶段边界有显著方差。这支持“阶段感知”的结构优化，而不是固定时间的硬编码。

## 3. 候选创新点（迭代清单）

### A. AXIS-FACTORY（主押注，数据集构建）

- **一句话**：把每条演示拆成“场景 / 物体 / 动作”三层，按 5 个测试轴做几何一致、动作可验证的增广，并用轴平衡课程混采。
- **动机**：测试 100% 是 5 类 OOD；公开演示是 nominal；位置/背景/干扰物三轴可以用视觉编辑低成本覆盖，未见物体/人为干扰需要几何与恢复数据。33k 演示 + 4 路相机 + 已知标定，是现成的“数据工厂”原料。
- **与现有工作的差异**：RoboAug、Pose6DAug、InfiNoVA、DREAMS 等做的是通用增广；本方案是 **测试轴条件化** 的：每个增广样本都带 axis 标签，按测试的 20%/20%/20%/20%/20% 配比混采；并且用 G1 的 FK/IK、`recomputed_ee_valid` 和动作回放做 **动作可验证过滤**，而不是只看图像真实感；4 路相机做多视角一致性，而不是只改头相机。
- **可行性**：高-中。SAM2 + 扩散 inpainting 做背景/干扰物；头双目 + 腕部内参做 3D 重建/重渲染；G1 URDF + Pinocchio/IsaacLab 做 IK/碰撞检查；官方数据 Apache 2.0；1×H100 或 4×A100 可跑。
- **实施步骤**：
  1. **A0 数据审计**：32 任务逐条标 axis 可用性（哪些任务适合位置重定位、哪些适合物体替换、哪些只能做视觉增广）；统计每任务 episode 数、夹爪事件、阶段边界。
  2. **A1 视觉编辑**：背景替换、干扰物插入、光照/纹理变化；动作不变；用深度/分割保证遮挡关系；先覆盖 background + distractor 两轴。
  3. **A2 几何重定位**：从双目 + 腕部重建物体 mesh/6D pose 与桌面平面；采样新物体位姿；重渲染 4 路；保持“抓取相对位姿”和“放置相对位姿”，用 IK 重定向 EE 轨迹；用 `recomputed_ee_valid` + 碰撞检查 + 动作回放过滤。
  4. **A3 恢复拼接**：按阶段切分演示，建立状态库；用 DINO/物体位姿最近邻匹配，把“被移动后的状态”接到另一条恢复段；短混合 + FK/IK 验证；覆盖人为干扰轴。
  5. **A4 可选 sim cousin**：G1 URDF + IsaacLab/MuJoCo，脚本化/TAMP 生成位置、未见物体、人干扰数据；域随机化 + real2sim 视觉迁移；只作为补充，不作为唯一来源。
  6. **A5 轴平衡课程**：按 axis 配额采样；保留 nominal 回放防止遗忘；按任务难度/成功率动态调权。
- **资源/时间**：1–2 人 × 3–4 周做 A0–A2；A3 再 1–2 周；A4 视人力 3–6 周。存储 1–2 TB；渲染 1×H100。
- **风险/淘汰条件**：遮挡与接触丰富任务的重渲染不真实；动作重定向在抓取/放置之外可能不可行；合成数据可能引入 shortcut；规则对合成数据的允许程度未完全核实。若 G2 增广有效率 <50%，或 G4 真机 A/B 无增益，则降级为“只做 A1 视觉增广”。

### B. CROSS-SPACE（结构优化）

- **一句话**：共享 VLM/trunk，加 joint（23D）与 EE（21D）双动作头，用 FK 一致性做辅助损失与不确定性信号，推理时只输出一个控制空间。
- **动机**：挑战赛同时支持 `joint` 和 `ee`，且两者互斥；数据集同时有 joint/EE 标注；`recomputed_ee_valid` 提供了质量标志；官方 WLA 原生输出相对 EE，但挑战赛 `ee` 要绝对位姿，`joint` 要关节角。双头能把“接口约束”变成“结构先验”。
- **与现有工作的差异**：不是简单的模型集成；用 **FK(q) 与 EE 的交叉一致性** 作为训练信号，并在推理时用该一致性选择/校准输出；相对动作头先预测 `Δ`，再与当前状态 compose 成绝对位姿，显式处理 WLA 与挑战赛的表示差异。
- **可行性**：高。G1 FK/IK 可用；数据里两套动作都有；在 WLA action expert 上加两个输出头 + LoRA 即可；24GB GPU 可训。
- **实施步骤**：构建 (q, EE) 配对并过滤 `recomputed_ee_valid=0`；训练双头 + FK 一致性损失；在验证集上按任务比较 joint vs EE；选择整体更好的控制空间（建议 EE），另一个头作为辅助/回退；真机调试通道验证。
- **风险/淘汰条件**：joint 与 EE 的标定/坐标系不一致；双头互相竞争；`pivot` 语义未逐维定义。若 G6 双头在验证集上不如单头，或真机 A/B 无增益，则只保留“相对动作适配器”。

### C. PHASE-DUAL（结构优化）

- **一句话**：阶段感知的双臂动作专家：共享 coordination latent + 每臂 residual latent + cross-arm attention + phase embedding；单臂任务用门控退化为单臂。
- **动机**：约一半任务（按任务名/夹爪活跃度初判）需要双臂协调（FoldTowel、ArrangePlates、PackBag、ToolboxStorage 等）；Co-VLA 在紧协调任务 +27%、OOD 13%→27%；TwinVLA 去掉 joint attention 在真机掉 27%；PAMAE 用 phase-aware MoE 在 π0 上 73.8→83.0。HangCup 的单臂统计又说明必须有门控。
- **与现有工作的差异**：把 Co-VLA 的 shared/residual 结构与 PAMAE 的 phase-aware 路由结合，并 **显式处理单臂/双臂混合任务**；不是复制 TwinVLA 的双 VLM（参数翻倍），而是在 WLA action expert 内做轻量 cross-arm attention + phase embedding。
- **可行性**：中。需要改 action expert 结构；双臂数据足够；LoRA/部分解冻可控制显存；但单臂任务多，门控设计是关键。
- **实施步骤**：从夹爪事件 + 速度谷 + VLM 阶段标签构造 phase 监督；加 shared token、arm residual、cross-arm attention、phase embedding；用单臂检测/任务语言做门控；先在 bimanual 子集上训，再混单臂数据。
- **风险/淘汰条件**：过拟合到少数双臂任务；单臂回归；结构复杂度超过收益。若 G7 双臂任务 <+5pp 或单臂回归 >2pp，则剪枝。

### D. KDIFF-8（扩散策略）

- **一句话**：把执行 chunk 设为 8，扩散头只预测 4 个关键帧（位姿 + 时间），用三次/最小 jerk 插值生成 8 步动作；可选学习型残差。
- **动机**：本地实测 8 步 chunk、K=4 有 96% 窗口在 5 mm/5° 内；30 步 chunk、K=8 只有 67%，K=10 才 81%。挑战赛参考实现默认 chunk=8，说明“短 chunk + 高频重规划”是官方认可的用法。
- **与现有工作的差异**：不是 SKIP 那种视频关键帧，也不是整段 episode 的子目标；是 **执行 chunk 级的关键帧扩散 + 插值**，并且把 chunk size 作为可调设计变量；关键帧选择用 DP/速度谷 + 夹爪事件，而不是均匀采样。
- **可行性**：中-高。只需改 action head 的输出维度与训练目标；插值用样条/最小 jerk；可在 WLA 30 步输出上只取前 8 步，避免改位置编码；先做离线重建，再做真机 A/B。
- **实施步骤**：离线提取关键帧；训练 K×D + timing 头；插值；与 dense 8 步基线比；若预测误差大，加轻量 residual 或退回 dense。
- **风险/淘汰条件**：预测误差 > 表示误差；timing 抖动；双臂关键帧预算翻倍；推理延迟。若 G5 真机回归或延迟无改善，则剪枝，只保留“chunk=8 高频重规划”的工程结论。

### E. SMRS / FAIL-MINE（数据集构建，人为干扰轴）

- **一句话**：状态匹配的恢复拼接：把成功演示按阶段切开，用 DINO/物体位姿找“被扰动后的相似状态”，拼接恢复段，生成“中断-恢复”训练数据。
- **动机**：人为干扰占测试 20%，公开数据几乎没有；RESample 用失败恢复增广在 ≤20% 额外样本下 +12% abs；33k 演示里已有大量“抓取失败后重抓/放置修正”的片段，可以复用。
- **与现有工作的差异**：RESample 主要做失败片段重采样；本方案做 **跨演示、阶段感知、状态匹配的拼接**，并用 FK/IK + 动作回放验证；目标不是“更多失败”，而是“从被扰动状态恢复成功”。
- **可行性**：中。不需要新真机数据；DINOv2/物体位姿匹配可跑；但视觉相似 ≠ 物理同状态，拼接处可能不连续。
- **实施步骤**：阶段切分；状态库；最近邻匹配；拼接 + 短混合；验证；混入训练。
- **风险/淘汰条件**：接触/遮挡导致匹配错误；拼接抖动；恢复段与当前物体位姿不一致。若 G8 人为干扰轴无增益，则剪枝。

### F. SIM-COUSIN（备选）

- **一句话**：用 G1 URDF + IsaacLab/MuJoCo 搭 32 任务 digital cousin，脚本化/TAMP 生成位置、未见物体、人干扰数据，域随机化 + real2sim 视觉迁移。
- **动机**：未见物体/位置/人干扰三轴在真实数据里最难覆盖；AutoRSR 用 real2sim2real 每任务 1K episodes 达到 73.3–86.7%；RoboCousin 证明 digital cousin 可补双臂数据。
- **差异**：面向 G1/Dex1 和挑战赛 32 任务，而不是通用 benchmark；用真实数据做视觉/物理校准。
- **可行性**：低-中。需要 sim 资产、任务脚本、接触建模；3–6 周；sim2real gap 大。
- **淘汰条件**：G2 sim 动作回放 <80%，或 G4 真机无增益。

### G. DATA-CURRICULUM（廉价补充）

- **一句话**：按 axis 配额 + 任务难度 + nominal 回放做数据配比；避免“增广数据淹没 nominal”。
- **动机**：5 轴各 20%，但采集成本差异巨大；简单均匀混采会让便宜的 background 数据淹没昂贵的人干扰数据。
- **差异**：把“测试分布”作为配比目标，而不是训练集自然分布。
- **可行性**：高；只是采样器 + 日志。
- **风险**：过拟合 axis 标签；用验证集调配额。

### H. CHUNK-SERVO（保留的执行层）

- **一句话**：保留上一轮的 chunk 级伺服/延迟监控思想：执行 chunk 的前若干步，按推理延迟动态调整 `action_chunk_size`，并监控 p99 延迟、端口隔离、内存。
- **定位**：工程执行层，不是本轮主创新；与 D 的 chunk=8 结合。

# 第 13 轮 · 产物区（2026-10-31）

## 摘要

本轮把 UniBot 世界挑战赛的核心矛盾重新定义为 **测试分布工程**：官方 32 任务 × 10 次运行中，每次都是 5 类泛化之一（位置、干扰物、桌面背景、未见物品、人为干扰），即 **100% 测试 trial 是 OOD 变体**；而公开的 33,276 条演示基本是 nominal 成功轨迹。因此，最大的可压缩项不是模型参数量，而是训练分布与测试分布之间的差异。

主方案 **AXIS-FACTORY** 把每条演示拆成“场景 / 物体 / 动作”三层，按 5 个测试轴做几何一致、动作可验证的增广，并用轴平衡课程混采；目标是把 33k 名义演示扩成 10–20 万条带 axis 标签的训练数据。模型侧只保留两项轻量结构适配的候选：**CROSS-SPACE**（主，joint 23D / EE 21D 双头 + FK 一致性 + 相对动作适配）和 **PHASE-DUAL**（第二波，阶段感知双臂/单臂门控）；扩散策略只保留 **KDIFF-8**（8 步执行 chunk、4 关键帧 + 插值），并明确剪枝“整段 episode 5–8 关键帧”的 naive 方案。执行层保留上一轮 CHUNK-SERVO 的延迟监控与 chunk 级伺服。

本地实测给出了三条硬约束：
1. HangCup `file-000` 有 719 episodes / 130,565 frames，episode 长度中位数 175 帧（约 5.8s），与 30fps、6s/任务一致；
2. 右臂 `action - state` 的 EE 位移中位数 16.2 mm、p95 39.9 mm，关节角中位数 0.0174 rad、p95 0.0904 rad——相对动作重定向可行；
3. 8 步 chunk 用 3–4 个关键帧可达到 93–96% 的“位置 ≤5 mm 且姿态 ≤5°”窗口比例；30 步 chunk 用 8 个关键帧只有 67%，整段 episode 用 8 个关键帧位置误差中位数 86.5 mm。**关键帧必须和执行 chunk 一起设计，不能直接替代 30 步稠密扩散。**

预期收益：若 A1+A2 能把位置/背景/干扰物三轴的训练覆盖从接近 0 提到 ≥15–20%，按 5 轴等权的测试分布，理论上可在不改变模型的情况下显著降低分布距离项；B/C 在双臂与接口一致性上提供 5–10pp 的二次增益；D 主要降低延迟与提高重规划频率，不承担主要成功率增益。最终押注是：**先把测试分布造出来，再用轻量结构适配吃到 API 红利；不从零训更大的 VLA。**

## 2. 问题形式化

### 2.1 测试分布与误差分解

设训练分布为 `P_demo`（nominal 成功演示），测试分布为

`P_test = (1/5) Σ_{a∈A} P_a`，`A = {pos, distractor, bg, unseen, human}`。

对任意策略 `h`，标准协变量偏移分解给出

`ε_test(h) ≤ ε_demo(h) + d_H(P_demo, P_test) + λ`，

其中 `d_H` 是 H-divergence，`λ` 是理想联合假设的误差。`ε_demo` 可以通过在 33k 演示上训练降到较低；`λ` 由模型容量/优化决定；**`d_H` 是当前最大的可操作项**。AXIS-FACTORY 的目标不是降低 `ε_demo`，而是把 `P_train` 往 `P_test` 推，降低 `d_H`。

一个实用的代理指标是轴覆盖：

`C_a = N_a / N_total`，目标 `C_a ≥ 0.15–0.20`，且 `N_a` 的 effective sample size 足够（避免大量重复样本）。

### 2.2 数据工厂的三层分解

把 episode 写成 `(S, O, A)`：`S` 是场景（背景、光照、相机、桌面），`O` 是物体（类别、位姿、形状、材质），`A` 是动作/机器人轨迹。5 个测试轴对应：

| 轴 | 主要变化 | 最小改动 | 需要动作重定向？ |
|---|---|---|---|
| 位置 | 物体 6D 位姿 | `O` | 是（抓取/放置相对位姿保持） |
| 干扰物 | 额外物体/遮挡 | `S` + `O` | 通常否，但需碰撞/遮挡检查 |
| 桌面背景 | 纹理/颜色/光照 | `S` | 否 |
| 未见物品 | 物体类别/形状/尺寸 | `O` | 是（抓取宽度/位姿/放置） |
| 人为干扰 | 人手臂/物体被移动 | `S` + `O` + `A` | 是（恢复段） |

这个分解直接决定成本：background/distractor 最便宜（视觉编辑，动作不变）；position/unseen 需要几何与 IK；human 需要恢复数据。**按“每美元覆盖的测试轴比例”排序，先做 A1，再做 A2，最后 A3/A4。**

### 2.3 关键帧表示误差

对一段长度为 `W` 的执行 chunk，选 `K` 个关键帧，用分段三次插值重建。经典误差界为

`||f - p||_∞ ≤ (h^4 / 384) · max |f^{(4)}|`，`h = W/(K-1)`。

接触丰富轨迹的 `f^{(4)}` 很大，解析界不紧，因此必须实测。本地实测（HangCup 右臂，300 episodes，125,253 个 active windows，DP 关键帧 + 三次样条，位置+姿态一起算）给出：

| W | K=2 | K=3 | K=4 | K=5 | K=8 | K=10 |
|---|---|---|---|---|---|---|
| 8 | 69% | 93% | 96% | 98% | 100% | – |
| 10 | 58% | 86% | 90% | 95% | 99% | 100% |
| 15 | 29% | 62% | 71% | 83% | 95% | 97% |
| 20 | 11% | 39% | 50% | 64% | 89% | 94% |
| 30 | 1% | 10% | 21% | 37% | 67% | 81% |

表中数字是“位置最大误差 ≤5 mm 且姿态最大误差 ≤5°”的窗口比例。关键结论：

- `W=8, K=4` 的表示容量足够（96%）；`W=30, K=8` 只有 67%，`W=30, K=10` 才 81%；
- 整段 episode（W≈180）用 K=8 的位置最大误差中位数 **86.5 mm**，K=15 仍 33.5 mm，K=30 才 12.4 mm——**整段关键帧方案不可行**；
- 这是 oracle 关键帧的表示上界，真实模型还要加预测误差，所以 K=4 比 K=3 更稳，且应保留 dense 回退。

### 2.4 统计功效

32 任务 × 10 次 = 320 trials。若真实成功率 `p≈0.25`，总成功率的标准误

`SE = sqrt(p(1-p)/320) ≈ 2.42pp`。

单任务 10 trials、`p≈0.3` 时 `SE ≈ 14.5pp`，所以单任务 A/B 只能看方向，不能宣称显著。正式比较用 **paired bootstrap**（同一任务/同一初始条件配对），报告 95% CI；全量 320 trials 的 2.42pp 是最小可检测量级。

## 3. 方法：AXIS-FACTORY 数据工厂

### 3.1 A0：审计与轴标签

对 32 个任务逐条建立元数据表：

- episode 数、帧数、时长、夹爪事件、阶段边界；
- 相机内参/外参可用性、腕部内参、头双目基线；
- 动作类型：单臂/双臂、EE 有效性、`recomputed_ee_valid` 比例；
- 任务适合的轴：position / distractor / bg / unseen / human；
- 资产：可重建的物体 mesh、可替换的物体类别、桌面平面。

产出：`axis_manifest.json`（每任务每轴的可用性、成本、预期增益）和 `phase_labels.parquet`（阶段边界）。这是后续所有增广的路由表。

### 3.2 A1：视觉编辑（background / distractor）

**背景**：
1. 用 SAM2/GroundingDINO 分割机器人、物体、桌面；
2. 用扩散 inpainting 替换背景/桌面纹理/光照；保留机器人/物体/阴影；
3. 用深度/分割保证遮挡顺序；对 4 路相机做一致的背景编辑（头双目用视差约束，腕部用局部 inpainting）；
4. 动作完全不变；只增加 `axis=bg` 标签。

**干扰物**：
1. 从资产库采样物体，按桌面平面/深度放置到机器人工作空间边缘；
2. 用深度感知合成 + 阴影/反射；检查与机器人/目标物体的碰撞；
3. 动作不变，但如果干扰物遮挡目标，需用 A2 的轨迹重定向或丢弃；
4. 标签 `axis=distractor`，并记录干扰物位姿/类别。

**成本控制**：不要逐帧跑视频扩散。先在 5–10 个关键帧上编辑，再用光流/视频传播或 3D 投影把编辑传播到全帧；背景是低频信号，传播误差可接受。

### 3.3 A2：几何重定位（position / unseen）

这是数据工厂的核心，分“静态场景重建 + 物体替换 + 动作重定向”三步。

**场景重建**：
- 用头双目 + 腕部 RGB 做多视角重建（3DGS / TSDF / mesh），得到桌面平面、目标物体 mesh、机器人 URDF 对齐；
- 用 G1 URDF + 标定把机器人模型对齐到相机系；桌面平面用 RANSAC；
- 每个任务只建一次静态场景，后续通过物体位姿采样生成新 episode，避免逐 episode 重建。

**物体替换/重定位**：
- 位置轴：在桌面可行域内采样新的物体 6D 位姿（避开机器人奇异位形/碰撞）；
- 未见物体轴：从 Dex1 资产库/生成资产中替换物体，保持功能可供性（可抓取宽度、放置面、重心）；
- 用 3DGS 重渲染 4 路相机；腕部视角要用物体局部坐标系渲染，保证与头视角一致。

**动作重定向**：
- 对源演示，记录抓取时刻的物体位姿 `T_obj^grasp` 和放置时刻的 `T_obj^place`；
- 新物体位姿 `T_obj'` 下，保持相对变换：
  - `T_ee^grasp' = T_obj' · (T_obj^grasp)^{-1} · T_ee^grasp`（等价于保持抓取相对位姿）；
  - 放置同理，保持“物体-目标容器”的相对位姿；
- 用 G1 IK 把新的 EE 关键位姿转成关节轨迹；用碰撞检查 + 关节限位 + 速度/加速度限制；
- 对源轨迹做时间缩放/速度重参数化，保持 30fps 和动作平滑；
- 用 `recomputed_ee_valid`、FK 回放、以及“动作回放成功率”过滤。

**适用边界**：
- 优先做刚性 pick-and-place、摆放、堆叠、收纳类任务；
- 对铰接物体（ZipUp、Unlock）、柔性物体（FoldTowel）、流体（SyringeWaterTransfer）不做 A2，改用 A1/A3/A4；
- 对接触丰富的抓取，重定向后必须用真机调试通道验证，不能只看渲染。

### 3.4 A3：状态匹配恢复拼接（human / distractor）

目标：从“被扰动后的状态”生成“恢复成功”的轨迹。

1. **阶段切分**：用夹爪事件 + 速度谷 + VLM 阶段标签，把每条演示切成 approach / grasp / transport / place / retreat；HangCup 实测闭合在 39%、打开在 81%，说明阶段边界有方差，不能用固定时间。
2. **状态库**：在每个阶段边界存 `(图像特征, EE 位姿, 夹爪状态, 物体位姿估计, 动作段)`；图像特征用 DINOv2/CLIP，物体位姿用 A2 的重建或 6D 估计。
3. **扰动采样**：从源演示的某个阶段边界出发，模拟“物体被移动/被人手遮挡/被推离”的新状态；在状态库里找最近邻的恢复段（相同阶段、相似物体位姿、相似 EE）。
4. **拼接**：把恢复段接到扰动状态后；在拼接点做 3–5 帧的最小 jerk 混合；用 IK/FK 验证连续性和关节限位；如果恢复段与当前物体位姿不一致，用 A2 的重定向修正。
5. **验证**：动作回放 + 碰撞检查 + 真机单任务调试；只保留“从扰动状态能回到成功”的样本。
6. **标签**：`axis=human` 或 `axis=distractor`，并记录扰动类型/幅度。

**与 RESample 的区别**：RESample 主要重采样失败片段；这里做跨演示、阶段感知、状态匹配的“中断-恢复”拼接，目标是从被扰动状态恢复，而不是简单增加失败样本。

### 3.5 A4：Sim Cousin（可选）

- G1 URDF + IsaacLab/MuJoCo；32 任务中优先做 10–15 个刚体 pick-and-place/收纳任务；
- 脚本化/TAMP 生成成功轨迹；随机化物体位姿、形状、桌面、干扰物、光照、相机；
- 用真实数据做视觉校准（风格迁移/real2sim）和物理参数校准（摩擦、质量）；
- 每个任务 1K episodes，按轴配额混入；用 A2 的验证器做动作回放过滤；
- 只作为补充：sim2real gap 大，不能替代 A1/A2/A3。

### 3.6 A5：轴平衡课程

- 采样权重 `w_a ∝ (target_a / current_a)^α`，`α∈[0.5,1]`；target 按 5 轴各 20%，但保留 nominal 回放（≥30%）防止遗忘；
- 按任务难度/成功率动态调权：难任务/低成功率任务上采样，但设上限防止过拟合；
- 训练日志记录每个 batch 的 axis 分布、任务分布、nominal 比例；验证集按 axis 分层。

### 3.7 质量门（数据侧）

每个合成样本必须过：

1. **几何一致**：4 路相机重投影误差 <5 px；物体-机器人碰撞检查通过；桌面接触合理。
2. **动作一致**：IK 收敛；关节限位/速度/加速度通过；FK 回放 EE 误差 <5 mm/2°；`recomputed_ee_valid=1`。
3. **视觉一致**：分割 mask IoU >0.8；深度边缘 <3 mm；阴影/反射方向一致。
4. **语义一致**：语言指令与场景/物体匹配；阶段顺序合法（approach→grasp→transport→place→retreat）。
5. **多样性**：同一源 episode 的增广样本不能只改一个像素/一个固定偏移；用嵌入距离/物体位姿分布去重。

## 4. 模型：CROSS-SPACE + PHASE-DUAL + KDIFF-8

### 4.1 CROSS-SPACE：joint/EE 双头 + FK 一致性

**结构**：
- 共享 WLA VLM/trunk（冻结）；
- 两个 action head：
  - `H_joint`: 23D = 左臂 7 + 右臂 7 + 左夹爪 1 + 右夹爪 1 + pivot 7；
  - `H_ee`: 21D = 左 EE 6 + 右 EE 6 + 左夹爪 1 + 右夹爪 1 + pivot 7；
- 两个头都输出 chunk（默认 8 步，内部可保留 30 步位置编码，只取前 8 步）；
- `pivot` 先做安全默认（零/标定值），不参与主损失；等真机调试确认后再学习。

**损失**：
- 动作回归/扩散损失：`L_joint + L_ee`；
- FK 一致性：`L_fk = ||FK(q_t) - T_ee_t||_2^2`，只在 `recomputed_ee_valid=1` 的帧上算；
- 相对动作适配：EE 头预测 `ΔT_t = T_t · T_{t-1}^{-1}`（或相对当前状态），推理时 compose 成绝对位姿；joint 头直接预测关节角；
- 不确定性：用两个头的预测在 FK 空间的差异 `u_t = ||FK(q_t^{joint}) - T_t^{ee}||` 作为置信度；差异大时回退到验证集上更稳的头。

**推理**：挑战赛只能选一个 `control_space`。建议默认 `ee`（与 WLA 原生表示接近、绝对位姿接口直接），joint 头作为辅助训练/回退；如果某任务在验证集上 joint 明显更好，可以在提交前按任务汇总选择，但仍是单模型、单控制空间。

### 4.2 PHASE-DUAL：阶段感知双臂/单臂门控

**动机**：约一半任务（按任务名/夹爪活跃度初判）需要双臂协调；Co-VLA 在紧协调任务 +27%、OOD 13%→27%；TwinVLA 去掉 joint attention 真机掉 27%；PAMAE 用 phase-aware MoE 在 π0 上 73.8→83.0。HangCup 单臂统计说明必须门控。

**结构（轻量版）**：
- 在 WLA action expert 的 cross-attention 前加：
  - **shared coordination token**：捕捉任务级协调意图；
  - **arm-specific residual adapters**：左右臂各一个低秩 adapter；
  - **cross-arm attention**：左右臂 token 互相 attend（TwinVLA/MoT 风格），只共享 self-attention 的 Q/K/V，其他投影保持臂特定；
  - **phase embedding**：`φ_t = [gripper, Δgripper, ||a_{t-1}||, progress]`，用 PAMAE 的轻量阶段描述符；phase 监督来自 A0 的阶段标签；
- **单臂门控**：用任务语言/单臂检测器/夹爪活跃度预测一个 gate `g∈[0,1]`；`g→0` 时关闭 cross-arm attention 和 residual，退化为单臂；避免单臂任务被双臂结构拖累。

**训练**：
- 先冻结 VLM，只训 action expert + adapters + phase router；
- 两阶段：先标准扩散/流匹配损失 warmup，再加 phase-consistent routing 辅助损失；
- 用 LoRA 控制显存；单卡 24GB 可跑。

### 4.3 KDIFF-8：8 步 chunk 的 4 关键帧扩散

**表示**：
- 执行 chunk `W=8`；从源动作轨迹用 DP/速度谷 + 夹爪事件选 `K=4` 个关键帧（含首尾）；
- 每个关键帧包含：时间 `τ_k`、左 EE 6D、右 EE 6D、夹爪 2D、pivot 7D（可选）；
- 插值：三次样条/最小 jerk；在关键帧之间生成 8 步；
- 可选学习型残差：一个小 MLP 以关键帧和当前观测为条件，输出 8 步残差；残差幅度限制在 ±5 mm/±2°，防止破坏关键帧。

**扩散头**：
- 输入：VLM 特征 + 当前状态 + phase embedding；
- 输出：`K×(6+6+2)` 关键帧参数 + `K` 个 timing；
- 去噪步数 4（与 WLA 一致）；训练目标：关键帧回归 + 端点损失 + 平滑损失；
- 推理：预测关键帧 → 插值 → 可选 residual → 取 8 步执行；下一轮重规划。

**为什么不直接替代 30 步**：本地实测 W=30 K=8 只有 67% 窗口在 5 mm/5°，整段更差；W=8 K=4 有 96%。所以 KDIFF-8 是“短 chunk + 高频重规划”的 co-design，不是“稀疏关键帧压缩长程”。

### 4.4 与官方 WLA 的适配

1. **动作维度**：WLA 54D → 挑战赛 21D/23D。写一个 adapter：
   - EE 模式：取 WLA 左/右 EE 相对 6D + 夹爪 1D，compose 当前状态成绝对位姿；`pivot` 用安全默认；丢弃灵巧手/腿/腰槽位；
   - joint 模式：用 joint head 直接输出 23D，或用 IK 把 EE 转关节；
   - rotation vector → rpy；注意坐标系（base 系、右手系、x 前/y 左/z 上）。
2. **chunk**：WLA 内部 30 步；挑战赛 `action_chunk_size=8`，返回前 8 步；每 8 步重规划。若 WLA 位置编码不允许改 chunk，保持 30 步内部预测，只切片，不改结构。
3. **归一化**：WLA 用 zscore/minmax_q；挑战赛数据统计不同，必须在挑战赛 33k 上重算 `dataset_statistics.json`；EE 相对动作用 zscore，夹爪用 minmax。
4. **服务**：用 `PolicyService`/`RemotePolicy` 的 websocket + msgpack + JPEG；注意 4 路 480×640 的带宽；`obs_delta_indices` 只声明必要观测；`image_resize` 可把腕部降到 128/160 以降延迟。
5. **延迟**：目标 p99 <150 ms（8 步 @30Hz = 267ms 预算）；如果 6B 模型单次 forward 超预算，用 FP16/BF16、TensorRT/编译、KV cache、或减小 `image_resize`；实在不行退回 `action_chunk_size=15`，但 KDIFF 的 K 要相应增加（W=15 K=6 有 89%）。

### 5.2 动作重定向

```python
def retarget_ee(traj, T_obj_old, T_obj_new):
    # keep grasp/place relative transforms
    T_ee_grasp_old = traj.grasp_pose
    T_ee_place_old = traj.place_pose
    T_ee_grasp_new = T_obj_new @ inv(T_obj_old) @ T_ee_grasp_old
    T_ee_place_new = T_obj_new @ inv(T_obj_old) @ T_ee_place_old
    # rebuild Cartesian waypoints, keep timing/speed profile
    waypoints = rebuild_waypoints(traj, T_ee_grasp_new, T_ee_place_new)
    q = ik(waypoints, seed=traj.q0, limits=G1_LIMITS)
    q = time_scale(q, traj.timing)
    assert collision_free(q)
    assert fk(q) ~= waypoints  # <5mm/2deg
    return q
```

### 5.3 CROSS-SPACE 损失

```python
def loss(obs, a_joint, a_ee):
    p_joint = H_joint(trunk(obs))
    p_ee = H_ee(trunk(obs))
    L = diff_loss(p_joint, a_joint) + diff_loss(p_ee, a_ee)
    valid = obs.recomputed_ee_valid.bool()
    L_fk = ||fk(p_joint) - (obs.ee_state @ p_ee)||^2 * valid
    L_rel = ||(obs.ee_state @ p_ee) - a_ee_abs||^2  # relative->absolute
    return L + λ1 * L_fk + λ2 * L_rel
```

### 5.4 KDIFF-8 训练/推理

```python
def train_kdiff(batch):
    kf, timing = select_keyframes(batch.action, K=4)   # DP + gripper/speed
    pred = diffusion_head(batch.obs, batch.phase, kf, timing)
    dense = interpolate(pred.kf, pred.timing, W=8)
    L = ||pred.kf - kf||^2 + ||dense - batch.action||^2 + smoothness(dense)
    return L

def act(obs):
    kf, timing = diffusion_sample(head(obs), steps=4)
    dense = interpolate(kf, timing, W=8)
    dense = dense + residual_mlp(obs, kf)  # optional, bounded
    return to_challenge_space(dense[:, :8])
```

## 8. 风险、合规与备选

### 8.1 技术风险

| 风险 | 影响 | 缓解 |
|---|---|---|
| 重渲染不真实/遮挡错误 | 策略学到 shortcut | 多视角重投影检查；A1 优先；真机 A/B |
| 动作重定向在接触段失败 | 合成数据不可执行 | IK/FK + 碰撞 + 回放；接触丰富任务不做 A2 |
| 状态匹配错误 | 恢复数据物理不一致 | DINO+物体位姿双匹配；短混合；验证 |
| sim2real gap | sim 数据拖累 | 只做补充；real2sim 校准；小比例混入 |
| 合成数据淹没 nominal | 遗忘/过拟合 | 轴平衡 + nominal 回放 ≥30% |
| 关键帧预测误差 | KDIFF 回归 | K=4 + dense 回退；G5 严格 A/B |
| 双臂结构拖累单臂 | 单臂任务回归 | 门控；单臂数据混训；G7 |
| 推理延迟 | 180s 内完不成/控制不稳 | chunk=8；FP16/编译；降分辨率；p99 监控 |

### 8.2 合规/规则风险

- **合成数据规则未完全核实**：手册未明确禁止合成/外部数据，但必须继续查规则；保守方案是“以官方 33k 为主，合成数据只做增广，不替代真实数据”。
- **单模型**：双头/适配器仍是一个 checkpoint；数据工厂只在训练时用。
- **不得用测试集/评测 token 做训练**：单任务调试通道只用于验证，不把评测观测回流训练。
- **安全**：`pivot` 语义未定义；先零/标定值，真机调试通道验证；动作限幅/限速；异常时输出零/保持。
- **许可**：WLA/数据集 Apache 2.0；第三方资产/生成模型（SAM2、扩散模型、3DGS）需检查许可证和商用条款。
- **网络**：N 机器人端口 8765 起；服务要支持多端口/健康检查/超时重连；不要假设固定 IP。

### 8.3 备选/回退

- **保守方案**：A1 视觉增广 + B 跨空间 + H 执行层；不做 A2/A3/A4。
- **数据不足**：先用 A1 覆盖 bg/distractor 两轴（40% 测试），再逐步做 position/unseen。
- **模型不收敛**：回到官方 WLA 直接微调 + chunk=8 + 相对动作适配；结构创新全部关掉。
- **时间不够**：优先 G0–G4；KDIFF/PHASE-DUAL 作为消融，不作为提交必需。

---

## 9. 结论与一句话押注

本轮的核心判断是：**UniBot 挑战赛的胜负手在测试分布，而不在模型大小**。官方测试 100% 是 5 类 OOD 变体，公开数据却是 nominal 成功轨迹；因此，按测试轴定向、几何一致、动作可验证的数据构建，是当前性价比最高的创新点。模型侧只需要两项轻量适配：joint/EE 跨空间一致性，以及阶段感知的双臂/单臂门控；扩散策略只在 8 步 chunk 上做 4 关键帧，不碰整段关键帧。

**一句话押注：用 5 类测试轴定向、几何一致且动作可验证的数据构建，把 33k 名义演示扩成接近测试分布的 10–20 万条训练数据；模型侧只做跨空间一致性与阶段感知双臂/单臂门控，扩散头在 8 步 chunk 上做 4 关键帧，不从零训更大的 VLA。**
