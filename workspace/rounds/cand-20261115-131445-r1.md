# 第 6 轮（新灵感循环第 1 轮；本轮灵感：「关节空间控制」×「用户需求分析」）

> **基线**：第 5 轮 InstructGauge-RTDI（IP-334–339；定义 468–492；引理 63–68；实验 E473–E492）。LeanGauge → MODGAUGE → ToolGauge → InstructGauge v3 → InstructGauge-WR → InstructGauge-RTDI 的严格退化链全部继承。
> 本轮纪律：**需求只收紧验收、不扩张能力；关节空间只增加证书、不替换笛卡尔证书**。两个新灵感各沿一条轴升级 RTDI，任一环节不可用都必须一键退回 v5。

## 0. 直觉与动机

### 灵感 1（用户需求分析 → 指令是需求的样本，不是需求本身）

直觉：用户说「把那个红杯子递给我」时，他真正想要的往往不是「抓住红杯子」这个动作，而是「在几秒内、不洒水、不碰倒旁边的东西、以我顺手的方向递到我手里」。指令只是需求的一次**有损投影**：它省略了验收条件、优先级、适用对象与失败时的可接受退路。此前几轮把 ℓ 接地成受类型约束的 ι，解决了「语言不能扩权」；但没有解决「**满足了字面指令，却没有满足用户需求**」。用户需求分析（URA）给出的正是缺失的那一层：需求不是一句话，而是一个可验收对象——包含**验收谓词、优先级、证据方法、来源与适用范围**；并且需求需要被**主动澄清**，而不是一次性解析。

更具体地说，URA 的核心纪律有三条：其一，**需求与规格分离**——N（need）是用户视角的期望，α（acceptance predicate）是可在执行轨迹上判定的验收谓词，ψ（CVC 契约）是 α 的保守操作化；其二，**可追溯**——每一条需求都要能追到契约、块、关节轨迹与证据回执，既能发现「执行了但没有需求依据」的孤儿块，也能发现「有需求但没有任何证据」的空头需求；其三，**优先级显式**——安全、任务成功、时限、舒适不是同权相加，而是字典序；语言只能在其允许的层级内调整偏好。

这里必须提前承认一个认识论事实：从 N 到 α 的这一步**不可形式化地保证等价**。我们能保证的是「α 是可测的、ψ 对 α 是 sound 的（ψ 通过 ⇒ α 通过）」，但不能保证 α 就是 N。因此本轮把「需求代理误差」当作一等公民显式度量，而不是假装它不存在。

### 灵感 2（关节空间控制 → 笛卡尔证书看不见的约束，恰好住在关节空间）

直觉：SpatialCert 检查的是腕部相机/坐标变换层面的时空一致性，它回答「末端看起来有没有偏」。但机器人真正执行的是关节轨迹，而**关节限位、速度/加速度上限、力矩饱和、奇异位形、自碰撞裕度**都只在关节空间可见。一个末端轨迹可以在笛卡尔空间里漂亮地贴着直线，却在接近工作空间边界时要求某个关节速度趋于无穷；反过来，一条在关节空间里平滑、限位安全、力矩宽裕的插值轨迹，其末端可能画出一条明显弯曲的弧线，直接违反「沿直线接近」的任务需求。两者不是谁更强，而是**互不蕴含**——这将是本轮的核心引理。

关节空间还带来一个建设性机会：冗余机械臂的零空间。用户需求中那些「次要但真实」的条目——保持肘部姿态让操作员顺手、让腕部相机始终看得见目标、远离关节限位、降低接触力——可以放进零空间里优化，而**不改变主任务的验收**。这正好延续前几轮「语言只改偏好、不改能力」的分层：次要需求只在零空间里花自由度，绝不挤占主任务的可行性。

### 灵感 3（两者耦合 → 需求空间—任务空间—关节空间的三段映射，缺口在最后一段）

直觉：需求通常用任务空间语言表达（「沿直线」「对准杯口」「轻放」），而执行必须落到关节空间。中间隔着两次映射：需求 → 任务目标（几何/力/时间），任务目标 → 关节轨迹（逆运动学/冗余分解）。最危险的失败不是任一段算错，而是**证书只覆盖了前两段**：需求验收谓词在任务空间可测，SpatialCert 也在任务空间可测，于是「双绿」；但关节空间里的限位、奇异、力矩问题从未被任何证书检查。反过来，只做关节证书又会漏掉任务语义。解法不是二选一，而是三根结构支柱：**双空间证书**（SpatialCert ∧ JointCert ∧ 坐标一致性，且承认二者不可互相替代）、**需求可追溯账本**（每条验收谓词绑定到实际证据，孤儿执行与空头需求都可检测）、**零空间需求分配**（次要需求只能进入动力学一致零空间，且力矩饱和时按优先级退回）。再叠加**歧义预算 + 安全默认需求**与**需求版本钉扎**，避免澄清不足或执行中途改需求把语义缺口放大成物理动作。

## 1. 研究问题（本轮要回答什么）

- **Q1（需求的可验收性）**：如何把自然语言需求变成可执行、可追溯、对用户真正关心的失败模式敏感的验收谓词，而不是又一个「看起来对」的代理指标？
- **Q2（双空间证书的必要性）**：在什么条件下笛卡尔证书与关节空间证书互不蕴含？同时验证二者的额外代价是否可被 50Hz 预算吸收？
- **Q3（冗余自由度该怎么花）**：次要用户需求能否只在零空间中优化而不降低主任务验收？力矩饱和、关节限位、奇异边界附近如何优雅退回？
- **Q4（需求漂移与歧义）**：澄清预算有限、需求可能中途变化时，如何保证执行块使用的需求版本与证书版本严格同一，并在歧义未解时退回安全默认？

## 2. 五条设计原则（正式化见产物区定义 493–512）

**P1 需求可验收且 sound（Sound Operationalization）**
每条需求 ρ 必须携带三值验收谓词 α（通过/失败/未知）与验证方法 V；CVC 契约 ψ 必须是 α 的保守操作化，满足 `ψ(τ)=1 ⇒ α(τ)=1`。未知不得记为通过。形式化方向：`Compile(ρ) = (ψ_post, oracle_α, trace)`，并单独度量 N 与 α 之间的**验证缺口**。

**P2 双空间证书（Dual-Space Certificate）**
每个提交块同时携带 SpatialCert 与 JointCert；`Valid = SC.valid ∧ JC.valid ∧ FrameConsistent`。二者互不替代：末端贴线不代表关节不超速，关节平滑不代表末端满足几何需求。JointCert 覆盖关节位置/速度/加速度/力矩、奇异裕度、可操作度、自碰撞与正运动学一致性。

**P3 零空间才花冗余（Redundancy Only in Null Space）**
次要需求（姿态舒适、相机可见、限位裕度、柔顺）只能通过动力学一致零空间投影作用，满足 `J M⁻¹ Nᵀ = 0`，因而一阶意义上不改变主任务加速度；一旦力矩饱和或零空间维数不足，按需求优先级依次缩减，最终退化为纯主任务。需求不能借冗余「偷偷扩权」。

**P4 可追溯且无孤儿（Traceability Completeness）**
账本 T 把每条需求绑定到验收 oracle、CVC 契约、执行块、关节轨迹与证据回执；提交前检查两类缺陷：`OrphanBlock`（执行了但没有需求依据）与 `OrphanReq`（有需求但没有足够证据）。追溯不是文档工作，而是提交闸门。

**P5 歧义预算 + 版本钉扎（Ambiguity Budget + Pinning）**
澄清轮数与用户负担有预算；歧义未降到 ε 以下时退回**安全默认需求 ρ₀**（等价 v5 默认目标），而不是猜。需求在块生命周期内版本钉扎；任何需求变更只在安全边界生效，并触发重新编译与重新验收。

## 3. 与基线的接口（如何退化）

- 需求澄清不可用 / 歧义超预算 ⇒ 使用安全默认 ρ₀，等价 RTDI 目标；
- 需求编译失败 / 验收谓词不可测 ⇒ 退回原 ι 与 SpatialCert 验证，等价 v5；
- JointCert 不可用 / 无关节模型 ⇒ 只保留 SpatialCert，强制 K=1，等价 RTDI 逐步执行；
- 零空间分配不可用 / 力矩饱和 ⇒ 关闭次要需求，只执行主任务，验收不降级；
- 需求账本不完整 ⇒ 拒绝提交该块（或按预注册规则降级为探索块并标记 UNKNOWN）；
- RTDI 失效 ⇒ InstructGauge-WR ⇒ InstructGauge v3 ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE 原样。

## 4. 预期贡献

1. 一个「需求 → 验收谓词 → 契约」的 sound 编译口径，并显式区分**执行验证缺口**（ψ vs α）与**需求代理缺口**（N vs α），避免把「证书全绿」误当成「用户满意」；
2. 一条双空间证书的非支配性结论：存在 SpatialCert 通过而 JointCert 失败、以及 JointCert 通过而任务空间需求失败的轨迹，因此二者都不可省略；
3. 一个动力学一致零空间的需求分配器，给出主任务一阶非干扰条件与饱和时的优先级回退规则；
4. 一个需求—块—关节轨迹—证据的可追溯账本，可检测孤儿执行与空头需求，并支持需求版本钉扎；
5. 一条完整可证伪路径：E493–E512 覆盖需求澄清、验收一致性、双空间检出、零空间非干扰、截断安全、需求冲突、退化等价与 50Hz 时序保全。

## 5. 本轮最大风险

**一句话**：把用户需求压缩成可测验收谓词的那一刻，就已经用代理替换了「用户真正想要的东西」，而双空间证书又只覆盖被建模的笛卡尔与关节空间——系统可能以全绿证书、完整追溯和高置信度，系统性地交付一个「可验证但不被想要」的结果。

## 2. 形式化定义（要点）

**定义 493（需求对象 RequirementModel）**
```
ρ = (id, N, α, μ, V, Prov, Scope)
α_ρ : (Trace × Env) → {1, 0, ⊥}
```
- `N`：受控自然语言陈述，词表仅含预注册对象/关系/量纲；
- `α_ρ`：三值验收谓词；`⊥` 表示证据不足（**不得记为通过**）；
- `μ ∈ ℕ`：优先级，配合类别序构成字典序（安全 ≻ 任务成功 ≻ 时限 ≻ 舒适）；
- `V ∈ {Test, Inspection, Analysis, Demonstration}`：验收证据方法；
- `Prov`：来源（语句 id、用户 id、时间戳、会话轮次）；
- `Scope = (O, X, T)`：作用对象集、空间 ∈ {task, joint, force, hybrid}、时间窗。
良构性：`α_ρ` 必须可由 `V` 类证据在有限时间内判定；否则 `ρ` 不可编译。

**定义 494（需求规格 RequirementSpec）**
```
R = (ρ₁…ρ_n, ≻_req, U),  U = (ε, b_q)
```
`≻_req` 是优先级全预序：`ρ_i ≻ ρ_j` 当且仅当类别更高，或同类且 `μ_i > μ_j`。`ε` 为可接受的残余歧义，`b_q` 为查询预算。
冲突：若不存在轨迹同时满足 `ρ_i, ρ_j`，称二者冲突；冲突消解见定义 505。安全默认需求：
```
ρ₀ = (default, N₀, α₀, μ=∞, V=Test, Prov=system, Scope=当前场景)
```
`ρ₀` 是 v5 默认目标的验收化封装，保证「不知道用户要什么时」仍可安全执行。

**定义 495（主动需求澄清 ReqElicitor）**
```
E(ℓ, H, S) = (R, Q, amb)
q* = argmax_{q ∈ Queries(R)} IG(q) / cost(q)
IG(q) = H(Interpret(R)) − E_{a∼P(a|q)}[H(Interpret(R) | q=a)]
amb(R) = Σ_i w_i · unresolved_i(R)
```
终止条件：`amb(R) ≤ ε` 或 `Σ cost(q) > b_q`。若超预算仍未达阈值，输出 `(SafeDefault, Q, amb)`。
歧义分类：`{指代, 量, 范围, 优先级, 验收}`；每类有预注册的可用查询模板，避免自由文本追问造成新的注入面。

**定义 496（需求编译与可靠操作化 ReqCompiler）**
```
Compile(ρ) = (ψ_post^ρ, oracle_α^ρ, trace_ρ)
Sound(ψ_post^ρ, α_ρ) ⇔ ∀τ: ψ_post^ρ(τ)=1 ⇒ α_ρ(τ)=1
```
编译必须做到：
1. `ψ_post^ρ` 只引用 CVC 已有可观测谓词与 JointCert 可判定量；
2. `oracle_α^ρ` 是 `α_ρ` 在证据上的可判定实现；
3. `trace_ρ` 给出 `ρ` 到契约槽位与证据类型的静态绑定；
4. 若无法满足 sound，则编译返回 `⊥`，退回 v5 默认目标。
两个缺口分开度量：
```
G_exec  = P(α=0 | ψ=1)        // 执行验证缺口，sound 下应为 0
G_proxy = |P(α=1) − P(N=1)|   // 需求代理缺口，靠留出用户审计估计
```

**定义 497（关节空间证书 JointCert）**
设块 `C` 对应关节轨迹 `θ_{0:K}`，关节速度/加速度由差分与控制器给出，力矩由逆动力学 `τ = M(q)q̈ + C(q,q̇) + g(q)` 给出。定义裕度向量：
```
m_q    = min_t min( (q_t − q_min − δ_q), (q_max − δ_q − q_t) )
m_ṙ    = min_t ( q̇_max − |q̇_t| )
m_r̈    = min_t ( q̈_max − |q̈_t| )
m_τ    = min_t ( τ_max − |τ_t| )
m_σ    = min_t ( σ_min(J(q_t)) − σ₀ )
m_w    = min_t ( √det(J(q_t)J(q_t)ᵀ) − w₀ )
m_c    = min_t ( d_self(q_t) − d₀ )
m_fk   = ε_fk − max_t ‖FK(q_t) − x_t^cart‖
```
```
JC.valid ⇔ ∀ m_i ∈ m : m_i ≥ 0
```
`σ₀, w₀, d₀, ε_fk` 为预注册安全阈值。`JC` 的谓词是**逐点**的（除终端制动项），这为前缀截断提供结构基础。

**定义 498（双空间证书 DualSpaceVerifier）**
```
Φ : 任务空间帧 ↔ 关节空间帧（含基座/工具/相机外参）
DC = (SC, JC, Φ)
Valid(DC) ⇔ SC.valid ∧ JC.valid ∧ Consistent_Φ
```
`Consistent_Φ` 要求参与比较的两个坐标系在时间戳、外参版本与标定不确定度上一致；外参版本变化即视为无证书。违规定位：
```
Attr(v) = TASK 若 SC 违反且 JC 通过
        = JOINT 若 JC 违反且 SC 通过
        = BOTH 若二者同违（优先按更高优先级需求归因）
```

**定义 499（需求条件化的字典序目标）**
主任务验收裕度 `f₀(τ) = min_ρ_primary margin_α(τ,ρ)`；次要需求目标 `f₁…f_m`（姿态舒适、相机可见、限位裕度、接触力小）。求解：
```
lexicographic:  max f₀  s.t. f₀ ≥ 0
                then max f₁ s.t. f₀ ≥ 0
                then max f₂ s.t. f₀ ≥ 0, f₁ ≥ f₁*
                ...
```
注意：次要目标**不能以降低 f₀ 为代价**；这正是「需求只收紧验收、不扩张能力」在优化层的表达。

**定义 500（零空间需求分配与饱和回退 NullSpaceAllocator）**
动力学 `M(q)q̈ + h(q,q̇) = τ`，任务雅可比 `J(q)`，`Λ = (J M⁻¹ Jᵀ)⁻¹`：
```
J̄ = M⁻¹ Jᵀ Λ
N = I − J̄ J
τ = Jᵀ F₀ + Nᵀ u,   u = Σ_k w_k ∇f_k
```
非干扰条件：`rank(J)=m`、`Λ` 可逆、且 `τ` 不触发位置/速度/力矩限幅时，
```
J M⁻¹ Nᵀ = 0  ⇒  末端加速度不受 u 的一阶影响
```
饱和保护：若 `|JᵀF₀| + |Nᵀu| > τ_max`，按优先级从低到高将 `u` 的分量置零并重新投影，直至可行；最终允许 `u=0`（纯主任务）。

**定义 501（关节空间块与可停前缀）**
```
C_θ = (Δθ₁…Δθ_K),  θ_t = θ_{t−1} + Δθ_t
PrefixClosed(C_θ) ⇔ ∀ j ≤ K: prefix_j 是可执行程序
StopSafe(C_θ, j) ⇔ ∃ 制动序列 β_j 使 θ̇→0 且全程 (q,q̇,q̈,τ) 满足限幅
```
安全截断算子：
```
trunc_θ(C_θ, j*) = prefix_{j*},  j* = max{ j : StopSafe(C_θ,j) ∧ JC.valid(prefix_j) }
```
不可逆动作（材料去除、热灼烧、接触挤压）仍受 v5 的不可逆屏障约束：跨不可逆动作强制 `K=1`，且此处额外要求 `m_τ` 与 `m_c` 有正裕度。

**定义 502（需求追溯账本 ReqTraceLedger）**
```
T ⊆ R × O_α × Ψ × C × Θ × E
T(ρ, o, ψ, C, θ, e)  ⇔  o=oracle_α^ρ, ψ=Compile(ρ).ψ_post, C 使用 ψ,
                        θ 是 C 的关节实现, e 是 C 的执行证据且 Verify(V_ρ,e,α_ρ) ≠ ⊥
```
```
Cov_R      = |{ρ : ∃e, T(ρ,·,·,·,·,e)}| / |R|
Orphan_B   = |{C : ∄ρ, T(ρ,·,·,C,·,·)}| / |C|
Orphan_R   = |{ρ : ∄e, T(ρ,·,·,·,·,e)}| / |R|
```
提交闸门：`Orphan_B = 0`；`Orphan_R ≤ δ_R`（预注册）；每个安全类需求至少一条独立证据。

**定义 503（需求可行性证书 FeasibilityCert）**
```
Feas(ρ, Env) → (true, 见证轨迹 θ*) | (false, 见证约束 c*)
```
`Env` 为关节包线、力矩包线、可达工作空间与时间预算的外近似。语义：
- 返回 `false` 时，`c*` 是区间/优化证书证明的不可满足约束，**可靠**（在模型内不存在可行轨迹）；
- 返回 `true` 时，只说明外近似内存在候选，**乐观**，仍须执行验证。
不可行需求必须在规划前进入协商（放宽/澄清/放弃），而不是执行到一半才发现。

**定义 504（需求版本钉扎与变更）**
```
ver(ρ) ∈ ℕ,  pin(C, v) ⇔ C 生命周期内 ver(ρ)=v
VersionConsistent(t) ⇔ ver(C_t) = ver(ρ_t) = ver(cert_t)
```
需求变更 `ρ → ρ'`（α、Scope、μ 任一改变）只在安全边界 `Q` 生效：
```
Q(t) = 无在飞块 ∧ 无活跃恢复 ∧ 机械臂处于静止/双支撑安全态
```
边界之前到达的变更进入待生效队列；在飞块继续使用旧版本证书。变更生效后必须重新 `Compile` 与重新验收，必要时重规划。

**定义 505（需求冲突消解与放宽 Waiver）**
对冲突集 `S`，按 `≻_req` 依次满足最高优先级需求，低优先级需求进入放宽集合：
```
Waiver(ρ_j) = (ρ_j, 冲突对象 ρ_i, 理由, 过期时间, 用户确认 id)
```
硬规则：安全类需求不可被任务/时限/舒适类需求放宽；语言只能调整**同类内部**的优先级。任何放宽必须显式记录，禁止静默丢弃。

**定义 506（证据充分性与独立性）**
```
Indep(e, ρ)   ⇔ e 不是由当前待认证策略自身产生
Fresh(e, Δ)   ⇔ t_e ≥ now − Δ
Sufficient(ρ) ⇔ ∀ v ∈ V_ρ : ∃ e (Indep(e,ρ) ∧ Fresh(e,Δ) ∧ Verify(v,e,α_ρ) ≠ ⊥)
              ∧ (安全类 ρ ⇒ 独立证据数 ≥ 2)
```
`UNKNOWN` 不等于 `PASS`：证据不足时验收结果为 `⊥`，块不得标记为完成。

**定义 507（RJC-8C 闭环）**
```
W: 感知（含 WristCam 与关节编码器）
R: 需求层（E 澄清 → R → Compile → 需求规格）
C: 契约规划（IAC + Kinematic-Loop + RT-CVC-TaskModel + Feas）
E: 执行（joint-chunk + 零空间分配 + 实时 JointCert 监控）
Dual-C: 双空间证书（SpatialCert ∧ JointCert ∧ Φ）
Diag/Recover: 故障诊断与需求条件化恢复
V: 需求验收（oracle_α）+ 追溯审计（Cov_R/Orphan）
U: 更新（Dbox、主张绑定、需求账本、代理缺口审计）
```

**定义 508（综合安全不变式）**
```
Safe(C) ⇔ CapabilityClosure
        ∧ PrefixClosed ∧ IrreversibilityBarrier
        ∧ SC.valid ∧ JC.valid ∧ Consistent_Φ
        ∧ Sound(Compile(ρ), α_ρ)
        ∧ LedgerComplete(C)
```
其中 `LedgerComplete(C)` 要求 `Orphan_B=0` 且 `C` 的每条安全相关需求都有充分独立证据。

**定义 509（退化映射 D）**
```
D(无澄清或无编译)        = RTDI（默认 ι₀ + SpatialCert）
D(无 JointCert)          = RTDI + K=1
D(无零空间或饱和)        = 纯主任务（次要需求置零）
D(无追溯或审计失败)      = 拒绝提交 / UNKNOWN 探索块
D(以上全部失效)          = RTDI v5
```
退化必须保持 v5 的行为等价性（实验 E508 以 diff=0 检验）。

**定义 510（代理质量指标）**
```
Precision(ψ,α) = P(α=1 | ψ=1)            // sound 下恒为 1
Recall(ψ,α)    = P(ψ=1 | α=1)            // 契约是否过窄
G_proxy        = |P(α=1) − P(N=1)|        // 留出用户审计估计
```
`Recall` 低说明大量可接受行为被契约误拒（保守但可用）；`G_proxy` 高说明验收谓词本身偏离真实需求（**不可由系统内部发现**，必须外部审计）。

**定义 511（裕度感知块长）**
设基础单步需求违反概率 `p_base`、关节裕度最小值 `m_min = min_i m_i`、残余歧义 `amb`。定义：
```
p_t = p_base · exp(−λ · m_min) + κ · amb
Risk(K) = 1 − Π_{t≤K} (1 − p_t)
K*(m,amb) = max{ K ≤ K_max : Risk(K) ≤ ε_req ∧ StopSafe(C_θ,K) }
```
直观：关节裕度越小、歧义越大，块必须越短；当 `m_min < 0` 或 `Risk(1) > ε_req` 时强制 `K=1`，等价 v5 逐步执行。

**定义 512（需求条件化诊断与恢复）**
恢复不再只按故障根因选择预案，还必须带上**受影响需求**与**优先级约束**：
```
Recover(FaultCert, ρ_affected, R) = τ_rec
s.t. τ_rec 保持所有 ρ_i ≻ ρ_affected 的验收
     且 tools(τ_rec) ⊆ tools(C)（不扩权）
     且若 cause = SEM：只在安全边界重新澄清/编译，不在执行中改需求
```
若恢复无法保持更高优先级需求，则截断并回到安全默认 ρ₀，而不是强行恢复。

```python
# IP-341 ReqElicitor：歧义预算下的主动澄清
class RequirementElicitor:
    def __init__(self, templates, user_model, epsilon=0.1, budget=3):
        self.templates = templates      # 预注册查询模板，按歧义类型索引
        self.user = user_model
        self.eps = epsilon
        self.budget = budget

    def elicit(self, utterance, history, scene):
        R = self._parse_to_requirements(utterance, history, scene)
        Q = []
        while self._ambiguity(R) > self.eps and len(Q) < self.budget:
            candidates = self.templates.available(R)
            if not candidates:
                break
            q = max(candidates, key=lambda x: self._info_gain(x, R) / self._cost(x))
            a = self.user.answer(q)          # 受控选项，不是自由文本
            R = self._update(R, q, a)
            Q.append((q, a))
        if self._ambiguity(R) > self.eps:
            return SafeDefault(scene), Q, self._ambiguity(R)
        return R, Q, self._ambiguity(R)

    def _ambiguity(self, R):
        # 指代/量/范围/优先级/验收五类的未解槽位加权和
        return sum(self._weights[k] * self._unresolved(R, k)
                   for k in self._weights)

    def _info_gain(self, q, R):
        # 解析假设分布上的熵减；模板离散，解析计算
        return entropy(self._hypotheses(R)) - self._expected_entropy(q, R)

    def _cost(self, q):
        return self.user.time_cost(q) + self.user.cognitive_cost(q)

# IP-342 ReqCompiler：需求 → 契约 + 验收 oracle + 追溯绑定
class RequirementCompiler:
    def __init__(self, cvc, joint_predicates):
        self.cvc = cvc
        self.joint = joint_predicates   # JointCert 可判定谓词集合

    def compile(self, rho):
        # 只允许使用预注册可观测谓词，杜绝自由文本直达执行器
        psi = self._operationalize(rho.alpha, self.cvc.predicates,
                                   self.joint.predicates)
        if psi is None:
            return None                 # 不可编译 ⇒ 退回 v5 默认目标
        if not self._check_sound(psi, rho.alpha):
            return None                 # sound 失败 ⇒ 拒绝编译
        oracle = AcceptanceOracle(rho.alpha, rho.V)
        trace = TraceBinding(rho.id, psi.slots, oracle.evidence_types)
        return CompiledRequirement(psi, oracle, trace)

    def _check_sound(self, psi, alpha):
        # 离线：在预注册反例集 + 随机轨迹上验证 psi=1 ⇒ alpha=1
        return all(alpha(tau) == 1 for tau in self.counterexamples
                   if psi(tau) == 1)

# IP-343 JointCert：逐前缀关节空间证书
class JointCertGenerator:
    def __init__(self, robot, limits, sigma0, w0, d0, eps_fk):
        self.robot = robot
        self.lim = limits
        self.sigma0, self.w0 = sigma0, w0
        self.d0, self.eps_fk = d0, eps_fk

    def certify(self, theta_seq, cart_seq):
        margins = []
        for t, q in enumerate(theta_seq):
            qd, qdd = self._derivatives(theta_seq, t)
            tau = self.robot.inverse_dynamics(q, qd, qdd)
            J = self.robot.jacobian(q)
            margins.append({
                'q': self._margin_box(q, self.lim.q_min, self.lim.q_max),
                'qd': self.lim.qd_max - np.abs(qd).max(),
                'qdd': self.lim.qdd_max - np.abs(qdd).max(),
                'tau': self.lim.tau_max - np.abs(tau).max(),
                'sigma': np.linalg.svd(J, compute_uv=False).min() - self.sigma0,
                'w': np.sqrt(np.linalg.det(J @ J.T)) - self.w0,
                'self': self.robot.self_distance(q) - self.d0,
                'fk': self.eps_fk - np.linalg.norm(
                    self.robot.fk(q) - cart_seq[t]),
            })
        return JointCert(theta_seq, margins,
                         valid=all(all(v >= 0 for v in m.values())
                                   for m in margins))

    def stop_safe_prefix(self, theta_seq):
        # 从后往前找最后一个可在限位/力矩内制动到静止的前缀
        for j in range(len(theta_seq) - 1, -1, -1):
            brake = self.robot.brake_trajectory(theta_seq[j], self.lim)
            if brake is not None and self.certify(brake).valid:
                return j
        return 0

# IP-344 DualSpaceVerifier：两个证书都通过才算通过
class DualSpaceVerifier:
    def __init__(self, spatial, joint, frame):
        self.spatial = spatial
        self.joint = joint
        self.frame = frame

    def verify(self, block, theta_seq, tf_seq):
        sc = self.spatial.generate(block, tf_seq)
        jc = self.joint.certify(theta_seq, sc.cart_seq)
        consistent = self.frame.consistent(tf_seq, theta_seq,
                                           sc.extrinsics_version)
        valid = sc.valid and jc.valid and consistent
        return DualCert(sc, jc, consistent, valid,
                        self._attribute(sc, jc, consistent))

    def _attribute(self, sc, jc, consistent):
        if not consistent:
            return 'FRAME'
        if sc.valid and not jc.valid:
            return 'JOINT'
        if jc.valid and not sc.valid:
            return 'TASK'
        if not sc.valid and not jc.valid:
            return 'BOTH'
        return 'NONE'

# IP-345 NullSpaceAllocator：次要需求只在零空间里花自由度
class NullSpaceAllocator:
    def __init__(self, robot, tau_max):
        self.robot = robot
        self.tau_max = tau_max

    def allocate(self, q, qd, J, F0, secondary_grads, priority):
        M = self.robot.mass_matrix(q)
        Lambda = np.linalg.inv(J @ np.linalg.inv(M) @ J.T)
        Jbar = np.linalg.inv(M) @ J.T @ Lambda
        N = np.eye(len(q)) - Jbar @ J
        tau0 = J.T @ F0
        u = sum(w * g for w, g in zip(priority, secondary_grads))
        tau_sec = N.T @ u
        # 饱和保护：按优先级从低到高缩放/置零，绝不挤占主任务
        while np.abs(tau0 + tau_sec).max() > self.tau_max and priority:
            priority = priority[:-1]
            u = sum(w * g for w, g in zip(priority, secondary_grads))
            tau_sec = N.T @ u
        return tau0 + tau_sec, N

# IP-346 ReqTraceLedger：提交前的追溯审计
class RequirementTraceLedger:
    def __init__(self):
        self.edges = []

    def bind(self, rho, compiled, block, theta_trace, evidence):
        self.edges.append((rho, compiled.oracle, compiled.psi,
                           block, theta_trace, evidence))

    def audit(self, R, blocks):
        justified = {e[3] for e in self.edges}
        orphan_blocks = [C for C in blocks if C not in justified]
        orphan_reqs = [r for r in R if not self._has_evidence(r)]
        unsafe = [r for r in R if r.is_safety and not self._two_independent(r)]
        return AuditResult(orphan_blocks, orphan_reqs, unsafe)

    def _has_evidence(self, rho):
        return any(e[0].id == rho.id and e[5] is not None for e in self.edges)

    def _two_independent(self, rho):
        ev = [e[5] for e in self.edges if e[0].id == rho.id]
        return len({e.source for e in ev if e.independent}) >= 2

# IP-347 RJC-8C 主闭环
def instructgauge_rjc(M, s, ell=None):
    # 1. 需求澄清与编译（慢路径，可异步）
    if ell:
        R, Q, amb = M.elicitor.elicit(ell, M.dialogue, M.scene)
    else:
        R, Q, amb = M.default_requirement_set, [], 0.0
    compiled = [M.compiler.compile(r) for r in R.requirements]
    if any(c is None for c in compiled):
        R = M.default_requirement_set          # 编译失败 ⇒ v5 默认目标
        amb = 0.0
        compiled = [M.compiler.compile(r) for r in R.requirements]

    # 2. 可行性前置：不可行需求先协商，不进入执行
    for r, c in zip(R.requirements, compiled):
        ok, witness = M.feas.check(r, M.envelope)
        if not ok:
            R = M.negotiator.relax_or_default(r, witness)
            compiled = [M.compiler.compile(x) for x in R.requirements]

    # 3. 主任务规划 + RT-CVC
    rho0 = R.primary()
    C = M.iac.plan_chunk(compiled[0].psi, M.hypothesize(s), M.tools,
                         M.budget_left(s), M.drift_bound(s))
    if not M.kloop.verify_prefix_closed(C)[0]:
        C = M.iac.plan_chunk(compiled[0].psi, M.hypothesize(s), M.tools,
                             1, M.drift_bound(s))
    tau_C = M.rt_model.make_task(C, M.env.time())

    # 4. 关节轨迹生成 + 双空间预检
    theta_seq = M.kinematics.joint_trajectory(C, R)
    jc = M.joint_cert.certify(theta_seq, M.kinematics.cartesian(theta_seq))
    j_star = M.joint_cert.stop_safe_prefix(theta_seq)
    K_star = min(len(theta_seq), M.chunk_len_budget(jc, amb))
    theta_seq = theta_seq[:K_star]
    if not jc.valid or K_star < 1:
        theta_seq = theta_seq[:1]                # 强制 K=1
    dc = M.dual.verify(C, theta_seq, M.wristcam.tf_sequence(C))
    if not dc.valid:
        C = C.truncate(M.joint_cert.stop_safe_prefix(theta_seq))
        theta_seq = theta_seq[:len(C.actions)]
        dc = M.dual.verify(C, theta_seq, M.wristcam.tf_sequence(C))

    # 5. 执行：零空间需求 + 实时双证书监控
    for t, (action, q) in enumerate(zip(C.actions, theta_seq)):
        if t in tau_C.preempt_points and M.scheduler.pending_higher_priority():
            M.scheduler.preempt(tau_C, C.get_prefix_state(t))
            return PREEMPTED
        F0 = M.task_controller.task_force(q, action)
        grads = M.requirement_gradients.secondary(R, q)   # 舒适/可见/限位
        tau, N = M.nullspace.allocate(q, None, M.kinematics.J(q),
                                      F0, grads, R.secondary_priority())
        M.env.apply_joint(q, tau)
        dc_t = M.dual.verify(C, theta_seq[:t + 1],
                             M.wristcam.tf_sequence(C)[:t + 1])
        if not dc_t.valid:
            fc = M.diagnoser.diagnose(dc_t, C, theta_seq[:t + 1], rho0)
            C, R = M.recovery.recover(fc, R, C, theta_seq, t)
            break

    # 6. 需求验收 + 追溯审计
    evidence = M.tcv.get_receipts(C)
    for r, c in zip(R.requirements, compiled):
        M.ledger.bind(r, c, C, theta_seq, evidence.for_requirement(r))
    audit = M.ledger.audit(R, [C])
    if audit.orphan_blocks or audit.unsafe:
        return REJECTED, audit
    M.ros_cvc.publish_cvc(C.id, len(C.actions), C.actions,
                          C.pre_conditions, C.post_conditions, [dc.sc, dc.jc])
    claims = bind_claims(C, compiled[0].psi, evidence)
    M.pgraph.record_execution(R, C, dc, audit)
    return C, dc, claims, audit

def InstructGauge_RJC_round(M, obs, audio, tac, depth, det, ell=None):
    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight:
            M.inflight.add(s)
            spawn_async(instructgauge_rjc, M, s, ell)
    return MODGAUGE_round(M, obs, audio, tac, depth, det)
```

## 4. 推导

**引理 69（双空间证书非支配）**
存在轨迹 τ₁ 使 `SC(τ₁)=1` 且 `JC(τ₁)=0`，也存在轨迹 τ₂ 使 `JC(τ₂)=1` 且 `SC(τ₂)=0`；因此 `SC ⇏ JC`、`JC ⇏ SC`，双空间证书缺一不可。
证明：
(a) 取平面 2R 机械臂，任务为沿一条靠近工作空间边界的直线运动。笛卡尔轨迹可在误差 ε 内精确跟随（`SC=1`），但逆解在接近全伸展位形时 `σ_min(J)→0`，所需关节速度超过 `q̇_max`（或 `m_σ<0`），故 `JC=0`。
(b) 取同一机械臂两构型 `q_A,q_B`，令关节空间线性插值 `q(s)=(1−s)q_A+s q_B` 且速度/加速度/力矩均在限内（`JC=1`）。由于正运动学非线性，`FK(q(s))` 一般是一条曲线；当任务要求严格直线且横向偏差阈值小于该曲线的弓高时，`SC=0`。
两类轨迹均构造存在，故二者互不蕴含。∎

**引理 70（关节前缀截断安全性）**
若 `JC` 的所有非终端谓词在 `prefix_j` 上逐点成立，且 `StopSafe(C_θ,j)` 成立，则 `JC(trunc_θ(C_θ,j))=1`。
证明：`JC` 的位置/速度/加速度/力矩/奇异/可操作度/自碰撞/FK 谓词均为逐点谓词，取前缀不改变已检查点的取值；终端制动项由 `StopSafe` 保证存在满足限幅的制动序列。因此截断后的轨迹满足全部 `m_i≥0`。∎

**引理 71（动力学一致零空间的一阶非干扰）**
设 `rank(J)=m`、`JM⁻¹Jᵀ` 可逆、力矩不饱和，且 `J̄=M⁻¹Jᵀ(JM⁻¹Jᵀ)⁻¹`，`N=I−J̄J`。对 `τ=JᵀF₀+Nᵀu`，有 `J M⁻¹ Nᵀ = 0`，即次要需求产生的关节加速度不改变末端加速度的一阶项。
证明：由 `J̄ᵀ = (JM⁻¹Jᵀ)⁻¹ J M⁻¹`（`Λ` 对称），
```
J M⁻¹ Nᵀ = J M⁻¹ (I − Jᵀ J̄ᵀ)
         = J M⁻¹ − (J M⁻¹ Jᵀ)(JM⁻¹Jᵀ)⁻¹ J M⁻¹
         = J M⁻¹ − J M⁻¹ = 0.
```
代入 `ẍ = J q̈ + J̇ q̇` 与 `q̈=M⁻¹(τ−h)`，含 `u` 的项消失。∎
注意：该结论是一阶、无约束的；位置/速度/力矩限幅会破坏精确性，故定义 500 要求饱和时按优先级缩减 `u`。

**引理 72（需求澄清的歧义收敛界）**
设解释假设空间熵为 `H₀`，在歧义未达 ε 前每个可选查询至少降低熵 δ>0，且用户回答真实。则澄清至多 `⌈(H₀−ε)/δ⌉` 轮即可达到 `amb≤ε`。
证明：每轮 `H_{t+1} ≤ H_t − δ`，故 `H_n ≤ H₀ − nδ`；取 `n=⌈(H₀−ε)/δ⌉` 得 `H_n≤ε`。`amb` 是熵的单调上界（每个未解槽位权重有界），故同轮满足阈值。若预算先耗尽，则按定义 495 退回 `ρ₀`，终止性仍成立。∎

**引理 73（sound 编译 ⇒ 已验证执行满足验收）**
若 `Compile(ρ)=(ψ,oracle,trace)` 且 `Sound(ψ,α)`，并且 CVC 验证执行轨迹 `τ` 满足 `ψ(τ)=1`，则 `α(τ)=1`。
证明：由 `Sound(ψ,α)` 的直接定义与 `ψ(τ)=1` 即得。∎
该引理只保证「执行验证缺口为零」，**不保证** `α` 等于真实需求 `N`；后者是定义 510 的 `G_proxy`，必须靠留出用户审计估计。

**引理 74（可行性证书的单侧可靠性）**
设 `Env` 是真实可行域的外近似。若 `Feas(ρ,Env)=(false,c*)`，则真实可行域内不存在满足 `α_ρ` 的轨迹；若返回 `true`，仅说明外近似内存在候选，不能推出真实可行。
证明：外近似满足 `Real ⊆ Env`。`false` 由在 `Env` 上的不可满足证书给出，故在更小的 `Real` 上更不可满足；`true` 的候选可能落在 `Env∖Real`，故只是乐观存在性。∎
因此规划前用 `false` 做硬拦截，用 `true` 进入执行验证，避免「乐观可行」被误当保证。

**引理 75（退化等价性扩展）**
- 关闭需求澄清/编译 ⇒ 使用 `ρ₀` 与 v5 目标，`Safe` 退化为 RTDI 的 `Safe`；
- 关闭 JointCert ⇒ `DC=SC` 且 `K=1`，等价 RTDI 逐步执行；
- 关闭零空间分配 ⇒ `u=0`，`τ=JᵀF₀`，主任务不变；
- 关闭追溯 ⇒ 审计失败，按预注册拒绝提交或标记 UNKNOWN；
- 全部关闭 ⇒ 行为与 InstructGauge-RTDI 完全一致。
证明：逐项代入定义 509 的映射即可；各关闭操作只移除增强项，不改变 v5 的 CVC、SpatialCert、RT-CVC 与故障恢复路径。∎

**推论 1（裕度感知块长的风险上界）**
在定义 511 的独立单步假设下，`K` 步块的需求违反概率满足 `Risk(K) ≤ 1 − Π_{t≤K}(1−p_t) ≤ Σ_{t≤K} p_t`；因此取 `K ≤ ε_req / p_max` 可保证块级违反概率不超过 `ε_req`。
证明：并集界。当 `p_t` 随 `m_min` 减小而增大时，`K*` 随之减小；若 `p_base·exp(−λ m_min)+κ·amb > ε_req`，则只能取 `K=1`，与定义 511 一致。∎

## 8. 本轮最大风险

**一句话**：需求形式化把「用户真正想要的东西」替换成可测验收谓词，而双空间证书只覆盖被建模的笛卡尔与关节空间——力/接触/热/长期人因等未建模维度完全在证书之外，于是系统可能以全绿证书、完整追溯和高置信度，**系统性地**交付一个「可验证但不被想要」的结果；更危险的是，零空间需求分配会让这种偏差看起来「既满足主任务又照顾了用户」，从而抑制外部审计的警觉。
