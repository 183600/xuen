# 第 69 轮（承接第 68 轮「CALM-RAS 自标定风险自适应闭环」IP-243~252；本轮灵感：「数据采集」×「在线学习」）

> 第 68 轮把「标定」升级为在线潜变量，却在自陈风险里留下一个致命的自反结构：**标定能力越强，缓变故障越隐形**。这不是滤波器的参数问题，而是**数据层的认识论问题**——在完全被动的观测流里，「传感器慢慢歪了」与「世界慢慢变了 / 故障慢慢发作了」是**观测等价的**：同一慢频带、同一残差通道、同一量纲，残差只是二者的和。任何后验、任何带宽限制都无法把不可辨识的东西分开；R68 只能靠「频率分界」赌快变故障，缓变故障天然落在盲区。
>
> 本轮灵感恰好给出破解这一层的两块积木：**数据采集**把「记录发生了什么」升级为「设计能回答问题的实验」（主动辨识 / 干预）；**在线学习**把「拿流数据继续训练」升级为「控制与学习对偶、且可证明安全的持续更新」（对偶控制 + 约束学习）。核心命题：
>
> **把数据采集当作主动干预（do-operator），用差分增益探针把漂移与缓变故障从「观测等价」变成「可辨识」；把在线学习当作对偶控制 + 安全约束更新，用覆盖证书与反确认采样斩断「策略决定数据、数据决定策略」的自噬回路——ACID-RAS（Active-Collection, Identifiable, Constrained-learning RAS）。**
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「测量还准吗」，R69 问「**我凭什么知道它准——我采的数据够格回答吗？我能在不制造新风险的前提下边做边学吗？**」。

## 0. 直觉与动机

**灵感 1（数据采集 → 被动观测的观测等价，是 R68 风险的根因）**
直觉：设力传感器有 0.3 N/s 的缓慢零漂，同时末端存在 0.3 N/s 的缓慢泄漏负载。在任何**被动**残差序列上两者逐点相同——残差只给出它们的和。R68 的 COF 会把总和吸收进力零偏 ĉ，CFA 于是判 H_cal，真实故障被「标定掉」。这不是 bug，是**不可辨识**：被动数据的信息矩阵在 (漂移 c, 故障 h) 张成空间里秩亏，存在使残差完全不变的平移方向。
出路：让系统做「已知答案的实验」。加载两档已知载荷——零偏是**加性、与载荷无关**，缓慢松动导致的刚度/增益漂移是**乘性、随载荷变化**，两点即分；或让视觉与触觉从两个已知位姿闭合同一几何——外参漂移随视角变化、传感器本体形变不随视角变化；或做两档已知速度运动——时间同步误差随速度线性放大、事件检测故障不随速度变。探针使 J_c 与 J_h 的**方向/比例不同**，信息矩阵从秩亏补到满秩。数据采集因此不是「多存点数据」，而是**选择能最大化 (c,h) 可辨识性的干预**。

**灵感 2（在线学习 → 对偶控制：动作同时是控制与实验）**
直觉：经典控制把动作当纯执行；Feldbaum 的对偶效应（dual effect）说，动作同时改变状态与**信息状态**。本系统每一次「回零位 / 轻触 / 换曝光 / 变速」都是探针，都会轻微偏离任务最优——这是**为了学习的控制代价**，可称为「信息税」。所以探针不是外挂的校准程序，而是内嵌在任务动作里的双目标最优控制：控制代价 + 信息收益。R68 的 COF 只是它的一个被动特例（探针恒为零、且只许吸收慢分量）。把「数据采集」纳入控制目标，R68 的「标定带宽」就不再是信息获取的唯一边界。

**灵感 3（在线学习 → 闭环数据自噬，是第二个元失败）**
直觉：在线学习最危险的敌人不是灾难性遗忘，而是**自我确认**：策略决定它遇到什么，遇到什么决定它学到什么，学到什么又加固策略。系统越自信，越只采集支持自己的数据；长尾故障、罕见漂移、分布外情境被系统性地**不采样**，于是「未观测到故障」被误读为「没有故障」。R68 的 CAC 金标集是离线固定的，恰恰不随这个回路更新——金标会越来越像旧世界，而世界已经在漂移。
对策：**反确认采样**（对失败层、高残差层、高不确定层强制配额）+ **覆盖证书**（每个故障模式 × 情境层的有效样本数有下界）+ **冻结留出集**（永不参与训练/标定/提交，只做审计）+ **OOD 探针**。斩断自噬的关键一句：**学习器不能决定审计集，审计集不能用来训练。**

**灵感 4（合流 → ACID-RAS 四组件 + 三证书）**
1. **AID Active Identification Designer**：D-最优探针设计 u\* = argmax log det(I₀ + B(u)ᵀΣ⁻¹B(u))，在安全包络与任务预算内选最小侵入探针；无自由动作时退化为**机会式探针**（借用任务中自然出现的回零、接触、静止、光照切换）。
2. **DCP Data Collection Policy**：分层覆盖 + D-最优/次模最大化 + 反确认配额 + 隐私预算；输出采集批次与重要性权重。
3. **SOL Safety-constrained Online Learner**：保守在线更新（安全下置信界门控）+ 有效信息步长 + 与 R68 CAC 对接；「学习只进影子、认证才换装」的不变式保留并加强。
4. **ICE Identifiability & Coverage Evaluator**：每轮出具三张证书——**ID-cert**（(c,h) 可辨识秩 / 条件数 / 不可辨识子空间基）、**COV-cert**（分层覆盖度）、**DRIFT-cert**（闭环分布偏移）；三者并入 J_ACID。任一失效 → **认识论降级**：把不可辨识 / 未覆盖方向标记为「只能外部计量或人工复核」，而不是假装知道。
5. **CALM-RAS† 继承核**：R68 的 MTM / SSG / COF / CFA / CAC 全部保留；COF 从「被动吸收」改为「被 AID 探针主动喂观测」；CFA 的后验条件于 ID-cert（不可辨识子空间上的 h 分量禁止被自信归因）。

**灵感 5（对 R68 风险的对症下药）**
- R68「缓变故障被标定吸收」：AID 差分探针 → 引理 16/17 给出被动 CRLB 发散、主动后条件数可控；不可辨识分量显式标记，绝不静默吸收。
- R68「CAC 金标未覆盖新故障」：DCP 覆盖证书 + 反确认采样 + 冻结留出集，把「没覆盖」从隐性假设变成显式可观测、可报警的量。
- R68「伪标签自毒 / 坏适配器」：SOL 的保守门控与 CAC 五关串联；数据来源与权重可审计（VQAuditor-D）。
- 新增「探索安全」风险：探针必须过安全包络（PSE），任一探针风险上界超限即否决；探索预算与任务 KPI 显式权衡，而非默认免费。

## 1. 形式化定义（增量：定义 293–308）

**定义 293（ACID-RAS 总览）** ACID-RAS = (AID, DCP, SOL, ICE, CALM-RAS†)。四不变式：
(i) **实时流零学习写操作**（继承 R68）+ **实时流探针白名单**：探针只从「已认证安全动作集」中选，每步信息收益与风险均经 PSE 预算；
(ii) **可辨识性红线**：ID-cert 未覆盖的子空间上的故障分量，禁止被 CFA 自信归因为 H_cal；
(iii) **审计集隔离**：留出集 D_hold 永不参与训练 / 标定 / 提交，只用于 ICE 与 VQAuditor-D；
(iv) **覆盖下限**：任一 (故障模式 × 情境层) 的有效样本数低于 n_min 时，对应后验必须做不确定膨胀（epistemic inflation）。

**定义 294（漂移–故障观测等价类）** 残差生成模型 r_t = F(c_t, u_t) + G(h_t, u_t) + n_t，u 为探针（被动时 u=∅）。线性化 r ≈ J_c c + J_h h + n。定义等价关系 (c,h) ~ (c′,h′) ⇔ J_c c + J_h h = J_c c′ + J_h h′。**被动不可辨识度** κ₀ = dim N([J_c J_h])；κ₀ > 0 时存在非零 (δ_c, δ_h) 使残差完全不变，c 与 h 在任何被动估计器下都不可分。R68 的速率限制只是对「非共线且 ω_f > ω_cal」的分量有效。

**定义 295（探针与差分增益）** 探针 u ∈ 𝒰 是系统可执行、答案已知的干预（加载已知质量、回零位/卸载、已知位姿双视角、已知速度往返、已知曝光切换）。标定通道增益 B_c(u) = ∂F/∂u，故障通道增益 B_h(u) = ∂G/∂u。**差分探针**：∃u 使 B_c(u) 与 B_h(u) 不成固定比例（不共线）。**A95（差分增益假设）**：存在有限探针集使 {B(u)} 张成 ℝ^{d_c+d_h} 中被动零空间的正交补。

**定义 296（可辨识 Fisher 信息与 D-最优探针）** 探针序列 U=(u₁..u_m)：
I(U) = I₀ + Σᵢ J(uᵢ)ᵀ Σ_n⁻¹ J(uᵢ)，J(u)=[∂F/∂cᵀ; ∂G/∂hᵀ](u)。
AID：u\*₁:ₘ = argmax_{U⊂𝒰_safe} log det I(U) − λ_task·TaskCost(U) − λ_risk·Risk(U)，受 m ≤ m_max、PrivacyBudget(U) ≤ ε_dp。D-最优解用最少探针把不可辨识子空间张满。

**定义 297（ID 证书）** ID-cert = (rank_ε(I(U)), cond(I(U)), basis(N_ε(I(U))), residual_null_dim)。rank_ε 为数值秩（奇异值 > ε）。**Valid_ID ⇔ residual_null_dim = 0**；若 > 0，输出不可辨识子空间 N_ε，并把其中 h 方向标记 `UNIDENTIFIABLE`——CFA 必须对这些方向取最坏情况后验。

**定义 298（采集策略与覆盖证书）** 分层 S = ℳ × 𝒳（故障模式 × 情境层）。采集策略 π_collect(s) 给出各层采样概率；有效样本数 n_eff(s) = Σᵢ 1[sᵢ=s]·wᵢ（w 为重要性权重）。覆盖 K_s = min(1, n_eff(s)/n_min)，**COV-cert = min_s K_s**，**Valid_COV ⇔ COV-cert ≥ c_min**。采集目标：max Σ_s VOI_s·K_s（次模 / D-最优）s.t. 安全、隐私、任务预算。

**定义 299（反确认采样 ACS）** 对闭环访问分布 p_θ(s) 做重要性重加权 wᵢ = 1/max(p_θ(sᵢ), p_floor)，并对三类层强制配额：① 失败 / 近失层；② 高残差层；③ 模型高不确定层（OOD 探针）。**反确认不等式**：强制探索配额 ρ 下，任意层 s 的覆盖 n_eff(s)/N ≥ ρ/|S| − o(1)，与策略多自信无关。

**定义 300（数据价值 VOI 与采集预算）** 单样本价值 VOI(x) = E[Δ Risk-uncertainty | 加入 x]，近似为后验熵/方差在关键风险方向上的投影缩减。采集预算 B_coll 按 VOI/成本 贪心或 D-最优分配；预算耗尽后 AID 退化为仅允许零成本机会式探针。

**定义 301（SOL 安全约束更新）** 候选 θ′ = θ − η∇L(batch)。**保守门控**：仅当 LCB_{D_hold}(θ′) ≥ (1−α_safe)·LCB_{D_hold}(θ) 且 J_ACID 各证书不退化时接受；否则拒绝并记入 ℰ_sol。接受后仍须过 R68 CAC 五关才换装——**策略安全 + 提交安全双保险**。

**定义 302（有效信息步长与新鲜度）** η_t = η₀ / √(1 + n_info(t))，n_info(t) = Σ tr(Σ_post⁻¹ ΔΣ_i)（按 Fisher 信息 / 后验方差缩减计，而非原始样本数）。**新鲜度** Fresh = n_info(t)/t；Fresh < ν 说明采集在重复、无新信息，触发 FEX。

**定义 303（闭环数据自噬与强制探索）** 闭环分布 P_θ^loop(s) 由当前策略诱导，参考分布 P_ref(s) 由分层定义。**自噬度** Aut = D_KL(P_θ^loop ‖ P_ref)。Aut > τ_aut ⇒ 触发 FEX 强制探索配额 ρ_t ↑，并按 wᵢ 降权自噬样本，防止污染学习。

**定义 304（VQAuditor-D 数据审计）** 审计四问：① 这批数据是否来自采集策略允许的层？② 重要性权重是否合理（未被自噬放大）？③ 留出集是否被泄漏进训练？④ 隐私/同意预算是否越界？结论回灌 AuditBuf，并作为 CAC 提交前置条件。

**定义 305（探针安全包络 PSE 与机会式探针）** 探针 u 的风险上界 R_probe(u)（力 / 位移 / 速度 / 暴露时间 / 人因扰动）必须 ≤ R_budget。若无自由探针可执行，退化为**机会式探针**：借用任务中自然发生的回零、接触、静止、光照切换，仅在其发生时提高 COF 观测权重，不主动改变轨迹。

**定义 306（隐私与同意预算）** 面部情绪数据受 ε_dp 差分隐私预算、采集最小化（data minimization）与同意状态约束；DCP 可行域含 PrivacyBudget(U) ≤ ε_dp。同意撤回 ⇒ 该时段数据从训练/审计中可删除（可遗忘性），J_ACID 仅保留哈希与聚合统计量。

**定义 307（ICE 三证书与 J_ACID）**
J_ACID = (J_CALM, ID-cert, COV-cert, Aut, Fresh, explore_spent, dp_spent, data_provenance_hash, acid_ver)。
**Valid ⇔ Valid(J_CALM) ∧ Valid_ID ∧ Valid_COV ∧ Aut ≤ τ_aut ∧ 无隐私越界**。任一失败 → 认识论降级：不可辨识 / 未覆盖方向按最坏情况处理（λ_risk ≥ 0.8、k 收缩、禁用自信归因）。

**定义 308（ACID-RAS 管线）** 离线：D_sim 预训练 + AID 在仿真中预计算探针库。在线每轮：AID 在安全包络内选探针 → DCP 按 VOI/覆盖采集 → SOL 保守更新（影子）→ ICE 出三证书 → CAC 五关 → 原子换装；VQAuditor-D 异步审计来源与自噬。**不可辨识分量永远走「外部计量 / 人工复核」通道，绝不进入自动自信归因。**

```python
# IP-253 AID：D-最优探针设计（控制代价 + 信息收益的对偶）
class ActiveIdentificationDesigner:
    def __init__(self, probe_lib, safe_env, task_cost, risk_model, Sn):
        self.lib, self.safe, self.cost, self.risk, self.Sn = probe_lib, safe_env, task_cost, risk_model, Sn

    def design(self, I0, budget, m_max):
        I, U = I0.copy(), []
        for _ in range(m_max):
            best, best_u = -np.inf, None
            for u in self.safe.actions():
                B = self.lib.jacobian(u)                     # [J_c(u); J_h(u)]
                gain = logdet(I + B.T @ inv(self.Sn) @ B) - logdet(I)
                score = gain - self.cost.lam*self.cost(u) - self.risk.lam*self.risk(u)
                if score > best and self.risk(u) <= budget.R_probe:
                    best, best_u = score, u
            if best_u is None or best < EPS: break
            U.append(best_u); I += self.lib.jacobian(best_u).T @ inv(self.Sn) @ self.lib.jacobian(best_u)
        return U, I                                        # I 满秩 ⇒ residual_null_dim=0


# IP-254 DCP：分层覆盖 + 反确认配额 + 重要性权重
class DataCollectionPolicy:
    def collect(self, strata, budget, privacy, p_theta):
        probs = softmax({s: voI(s)/max(cost(s), EPS) for s in strata})
        batch = sample_by(probs, budget, privacy)                    # 隐私预算内采样
        batch += forced_quota(fails, high_resid, ood, rho=self.rho)  # 反确认配额
        w = [1.0/max(p_theta[s], P_FLOOR) for s in batch]            # 重要性重加权
        return batch, clamp_weights(w)


# IP-255 SOL：保守在线更新（策略安全门控）
class SafeOnlineLearner:
    def step(self, theta, batch, weights):
        theta2 = theta - self.eta(theta)*grad(theta, batch, weights)  # 有效信息步长
        if LCB(self.holdout, theta2) < (1-self.alpha)*LCB(self.holdout, theta):
            log_to_esol(theta2); return theta                         # 拒绝，不换装
        if not self.certs_non_regress(theta2):                        # ID/COV 不退化
            log_to_esol(theta2); return theta
        return theta2                                                 # 仍需 R68 CAC 五关


# IP-256/260 ICE + FEX：三证书 + 强制探索
class IdentifiabilityCoverageEvaluator:
    def certify(self, I, coverage, loop_dist, ref_dist, fresh):
        id_cert  = (numerical_rank(I), cond(I), null_space_basis(I))
        cov_cert = min(coverage.values())
        aut      = kl(loop_dist, ref_dist)
        action   = None
        if id_cert[3] > 0 or cov_cert < C_MIN or aut > TAU_AUT or fresh < NU:
            action = 'epistemic_degrade'          # 不可辨识/未覆盖 → 最坏情况
        if aut > TAU_AUT:
            action = 'forced_exploration'          # 提高 rho，降权自噬样本
        return {'id': id_cert, 'cov': cov_cert, 'aut': aut,
                'fresh': fresh, 'action': action}


# IP-262 ACID-RAS 主闭环（CALM-RAS† 外层）
def ACID_RAS_round(M, obs):
    # 0) 认识论前置：先问「现在的问题可辨识吗、数据够吗」
    U_probe, I = M.aid.design(M.ice.I0, budget=M.explore_budget, m_max=M.m_probe)
    batch, w    = M.dcp.collect(M.strata, M.coll_budget, M.privacy, M.policy_dist)

    # 1) R68 CALM-RAS 核（MTM 前向 / COF / CFA / C-RAS-WM / ERS-WM 全保留）
    z, o = M.mtm.forward(obs.pack, M.a_prev, M.scene_ctx)
    r    = residuals(obs, o, M.wm_residual_cache, probes=U_probe)   # 探针反馈进残差
    c, U, thr = M.cof.step(o['cal'], r, sigma_stat(M), probe_gain=U_probe)
    rho  = M.fir_signature(z, M.residual_log)
    joint_post = M.cfa(rho, o['pi'], c, U, id_cert=M.ice.last_id)   # 条件于可辨识性

    # 2) ICE 三证书 → 认识论降级或放行
    cert = M.ice.certify(I, M.coverage, M.policy_dist, M.ref_dist, M.fresh)
    if cert['action'] == 'epistemic_degrade':
        joint_post = worst_case_post(joint_post)
        thr['lam_floor'] = max(thr['lam_floor'], 0.8)
    if cert['action'] == 'forced_exploration':
        M.dcp.rho = min(1.0, M.dcp.rho + 0.05)

    # 3) 控制（继承 R68）
    A = M.ach.propose(obs.x_prime, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, joint_post, min(M.vista.m, M.m_emo),
                                    M.alpha_chunk, M.wm_preds)
    lam = max(M.efs.risk_scale(joint_post), thr['lam_floor'])
    tau = emotion_response_shaping_wm(M.pi_sigma.prefix_dispatch(A[:k])*lam,
                                      joint_post, M.wm_preds)

    # 4) 在线学习（影子）+ 认证提交（继承并加强）
    M.sol.step(M.shadow, batch, w)                  # 会写日志，不碰实时流参数
    M.vqa_d.submit_async(batch, cert)               # 数据审计
    M.cac.maybe_commit(M.sol.shadow, M.time_since_last_commit)
    return k, lam, joint_post, (c, U), cert
```

## 3. 推导

**引理 16（被动不可辨识下界）** 在定义 294 下，若存在 h₀ 使 J_h h₀ ∈ span(J_c)（如加性慢零偏与加性慢泄漏共线，J_h h₀ = α J_c c₀），则 (αc₀, −h₀) 属于 N([J_c J_h])，残差沿该方向恒不变。于是信息矩阵奇异，**该方向上不存在有限 Cramér–Rao 下界**：任意被动估计器对 h₀ 的误差都不能被一致压小。系：**频率分界救不了共线通道**——R68 的反吸收界（引理 13）只覆盖非共线的快分量。

**引理 17（探针可辨识性）** 若探针 u 使 J_c(u) 与 J_h(u) 的"通道夹角" θ(u) ≥ θ_min，则加入该探针后 I(U) 在 (c,h) 空间的数值秩至少 +1，且 cond(I(U)) ≤ cond(I₀)·(1 + κ_u·cot θ_min·‖u‖)。存在 m ≤ d_c + d_h 个差分探针使 residual_null_dim = 0。**推论（廉价探针）**：① 两档已知载荷分离「加性零偏 vs 乘性刚度漂移」；② 双视角闭合分离「外参漂移 vs 本体形变」；③ 两档速度分离「时间同步误差 vs 事件故障」——它们分别只增加一维信息，却足以拆开一个共线对。

**引理 18（自噬下覆盖衰减与配额纠正）** 若采集策略贪心于当前模型，某层 s 的访问概率 p_θ(s) ≤ p_floor，则其有效样本按 (1−p_θ(s))^t 指数衰减，未观测故障层被系统性遗忘。加入强制配额 ρ 后 n_eff(s)/N ≥ ρ/|S| − O(1/N)，COV-cert 以 1−δ 概率 ≥ c_min。**代价（覆盖约束后悔）**：regret = O(√(T·d_eff/(ρ·|S|))) + O(|S|/ρ)。**用一点探索后悔换回可辨识与覆盖，这是一笔有明确上界的保险费。**

**定理 16（ACID 端到端风险一致性）** 在 A87–A95 下：
1. P(|τ_cmd − τ\*| > ε) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_vqa + α_cal + **α_id + α_cov + α_sol**；α_id 由 residual_null_dim 控制（满秩 → 0，引理 17），α_cov 由覆盖下界控制（引理 18），α_sol 由 SOL 保守门控控制；
2. **ID / COV 任一证书失效 ⇒ λ_risk ≥ 0.8 ∧ k 收缩 ∧ 禁用自信归因**——「不知道」永远导向收缩，绝不导向放宽；
3. 探针总风险 Σ R_probe ≤ R_budget（PSE），任务 KPI 损失 ≤ λ_task·Σ TaskCost（显式信息税）；
4. Aut ≤ τ_aut ⇒ 训练分布偏移可控；超限则强制探索 + 降权，违规概率受 ρ 与留出集审计共同限制。

**定理 17（安全–后悔权衡，不可兼得）** SOL 的保守门控保证每步以 1−δ 概率不劣于基线安全下界；覆盖约束下累计后悔 ≤ O(√(T·d_eff/(ρ|S|))) + O(|S|/ρ)。**不存在既零后悔又零探索的安全学习**——ACID-RAS 把「必须探索」的代价显式化、预算化，而不是像 R68 那样默认被动数据足够。这是本方案与 R68 的根本分野：**可辨识性不是免费的，它必须被买来。**

## 2. 形式化定义（要点版）

**定义 293（总览与四不变式）** 实时流零学习写操作 + 探针白名单；可辨识性红线（不可辨识子空间禁止自信归因 H_cal）；审计集隔离（D_hold 永不训练/标定/提交）；覆盖下限（低覆盖层后验必须膨胀）。

**定义 294（观测等价）** `(c,h)~(c′,h′) ⇔ J_c c + J_h h = J_c c′ + J_h h′`。κ₀>0 时存在残差完全不变的平移方向；R68 的速率限制只对非共线且 `ω_f>ω_cal` 的分量有效。

**定义 295–296（探针 / AID）** 探针是答案已知的干预（已知载荷、双视角、双速度、已知曝光）；差分探针使 `B_c(u) ∦ B_h(u)`。AID 求 D-最优：`argmax logdet I(U) − λ_task·Cost − λ_risk·Risk`，受 `m≤m_max`、`PrivacyBudget≤ε_dp`。

**定义 297（ID-cert）** `(rank_ε(I), cond(I), basis(N_ε), residual_null_dim)`；`Valid_ID ⇔ residual_null_dim = 0`；否则零空间内 h 方向标 `UNIDENTIFIABLE`，CFA 取最坏情况。

**定义 298（DCP / COV-cert）** 分层 `S=ℳ×𝒳`；`K_s=min(1,n_eff(s)/n_min)`，`COV-cert=min_s K_s`；`Valid_COV ⇔ COV-cert≥c_min`；次模/D-最优采集 s.t. 安全、隐私、任务预算。

**定义 299（ACS）** `wᵢ=1/max(p_θ(sᵢ),p_floor)`；失败层/高残差层/OOD 层强制配额 ρ；覆盖 `n_eff(s)/N ≥ ρ/|S| − o(1)`，与策略自信无关。

**定义 300（VOI）** `VOI(x)=E[ΔRisk-uncertainty|x]`；预算按 VOI/成本分配，耗尽后退化为机会式探针。

**定义 301–302（SOL）** 候选 θ′ 仅在 `LCB_{D_hold}(θ′) ≥ (1−α_safe)·LCB(θ)` 且证书不退化时接受；`η_t = η₀/√(1+n_info)`，`Fresh=n_info/t` 过低触发 FEX；接受后仍须过 CAC 五关。

**定义 303–304（自噬与审计）** `Aut=D_KL(P_θ^loop‖P_ref)`，超阈值 → 强制探索 + 降权；VQAuditor-D 四问（来源层 / 权重合理 / 留出集未泄漏 / 隐私未越界）作为 CAC 前置。

**定义 305–306（PSE / 隐私）** 探针风险上界 ≤ R_budget，无自由动作则用机会式探针；面部数据受 ε_dp、采集最小化、同意状态约束，同意撤回可删除（可遗忘性）。

**定义 307–308（证书 / 管线）** `Valid ⇔ Valid(J_CALM) ∧ Valid_ID ∧ Valid_COV ∧ Aut≤τ_aut ∧ 隐私不越界`；任一失败 → 认识论降级（λ≥0.8、k 收缩、禁自信归因）；不可辨识分量永远走外部计量/人工复核。

```python
# IP-253 AID：D-最优探针（控制代价 + 信息收益）
class ActiveIdentificationDesigner:
    def design(self, I0, budget, m_max):
        I, U = I0.copy(), []
        for _ in range(m_max):
            u = argmax_safe(lambda u: logdet(I + Jc(u).T@inv(Sn)@Jc(u))
                                       - lam_c*cost(u) - lam_r*risk(u))
            if u is None or gain(u) < EPS: break
            U.append(u); I += info(u)
        return U, I                          # 满秩 ⇒ 慢故障可辨识

# IP-254 DCP：覆盖 + 反确认 + 重要性权重
class DataCollectionPolicy:
    def collect(self, strata, budget, privacy, p_theta):
        batch = sample_by(voi_over_cost(strata), budget, privacy)
        batch += forced_quota(fails, high_resid, ood, rho=self.rho)
        return batch, clamp([1/max(p_theta[s], P_FLOOR) for s in batch])

# IP-255 SOL：保守在线更新（安全门控 + 有效信息步长）
class SafeOnlineLearner:
    def step(self, theta, batch, w):
        theta2 = theta - eta(theta)*grad(theta, batch, w)
        if LCB(self.holdout, theta2) < (1-self.alpha)*LCB(self.holdout, theta):
            return theta                      # 拒绝；接受也仍须过 CAC 五关
        return theta2 if self.certs_non_regress(theta2) else theta

# IP-256/260 ICE + FEX：三证书 → 降级/探索
class IdentifiabilityCoverageEvaluator:
    def certify(self, I, coverage, loop, ref, fresh):
        id_cert = (rank(I), cond(I), null_space(I))
        cov, aut = min(coverage.values()), kl(loop, ref)
        action = None
        if id_cert.null_dim > 0 or cov < C_MIN or aut > TAU_AUT or fresh < NU:
            action = 'epistemic_degrade'
        if aut > TAU_AUT: action = 'forced_exploration'
        return {'id': id_cert, 'cov': cov, 'aut': aut, 'fresh': fresh, 'action': action}

    M.sol.step(M.shadow, batch, w)                                     # 3) 影子学习
    M.vqa_d.submit_async(batch, cert); M.cac.maybe_commit(M.sol.shadow, M.dt)
    return k, lam, joint_post, (c, U), cert
```

## 4. 推导

**引理 16（被动不可辨识下界）** 若 `J_h h₀ = α J_c c₀`（如加性慢零偏与加性慢泄漏共线），则 `(αc₀, −h₀) ∈ N([J_c J_h])`，残差沿该方向恒不变，信息矩阵奇异 ⇒ 该方向无有限 CRLB，任意被动估计器都不能一致压小 h₀ 误差。**频率分界救不了共线通道；R68 引理 13 只覆盖非共线快分量。**

**引理 17（探针可辨识性）** 若探针使 `J_c(u)` 与 `J_h(u)` 通道夹角 `θ(u) ≥ θ_min`，则 `I(U)` 数值秩至少 +1，`cond(I(U)) ≤ cond(I₀)(1+κ_u·cotθ_min·‖u‖)`；存在 `m ≤ d_c+d_h` 个差分探针使 residual_null_dim=0。系：两档载荷分「加性零偏 vs 乘性刚度」、双视角分「外参 vs 形变」、两档速度分「时间同步 vs 事件故障」。

**引理 18（自噬下覆盖衰减 / 配额纠正）** 贪心采集下低访问层按 `(1−p_θ)^t` 指数衰减；配额 ρ 后 `n_eff(s)/N ≥ ρ/|S| − O(1/N)`，COV-cert 以 1−δ 概率 ≥ c_min；覆盖约束后悔 `O(√(T·d_eff/(ρ|S|))) + O(|S|/ρ)`。

**定理 16（端到端风险一致性）** A87–A95 下：
1. `P(|τ_cmd−τ*|>ε) ≤ α_chunk+δ_fi+α_emotion+α_wm+α_vqa+α_cal+α_id+α_cov+α_sol`（后三项分别由引理 17/18/SOL 门控控制）；
2. ID/COV 任一失效 ⇒ `λ_risk ≥ 0.8 ∧ k 收缩 ∧ 禁自信归因`（不知道 → 收缩）；
3. `ΣR_probe ≤ R_budget`（PSE），KPI 损失 ≤ `λ_task·ΣTaskCost`（显式信息税）；
4. `Aut ≤ τ_aut` ⇒ 训练分布可控，超限强制探索 + 降权。

**定理 17（安全–后悔权衡）** SOL 门控保证每步以 1−δ 概率不劣于基线安全下界；覆盖约束下后悔 `O(√(T·d_eff/(ρ|S|))) + O(|S|/ρ)`。**不存在既零后悔又零探索的安全学习**——ACID-RAS 把探索代价显式预算化，这是与 R68「默认被动数据足够」的根本分野：**可辨识性必须被买来。**

## 7. 本轮最大风险

**一句话**：ACID-RAS 把「看」变成了「动」——探针是让慢故障可辨识的唯一手段，但探针本身是可预测的周期性扰动：若故障（或对手）与探针同频/反相，它会恰好落在探针的**频闪盲点**里，被系统自己的标定更新「调制掉」；更糟的是在线学习会把这个盲区当成「已辨识」写进策略，形成自我确认的闭环——**系统越擅长设计实验，故障越擅长藏在实验的间隙里**。

**次级风险与缓解**：① 探索安全（PSE + 机会式探针 + 风险预算）；② 覆盖证书被伪造/权重作弊（VQAuditor-D + 哈希审计）；③ 留出集泄漏（定义 293-iii + E293）；④ 隐私与同意（ε_dp + 可遗忘性）；⑤ 「可辨识性 = 探针可执行性」的硬件依赖（无探针时只能显式标记 UNIDENTIFIABLE 并外部复核）。
