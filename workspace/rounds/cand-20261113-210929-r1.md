# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「自监督学习」×「基准测试」）

> R69 把不确定性一分为二，并给了漂亮的答案：可约的歧义就去**问**——看、问、触。但它整套「问得对不对」的论证，建立在一个从未被测量的假设上：**证据源是正交的**。R69 定义 293-iii 要求「至少两个正交证据源一致」，可它所有的证据（几何残差、同步残差、零速残差、流似然、情绪一致性、WM 残差）都来自同一副传感器、同一个 MTM trunk、同一批数据——它们高度相关。一个作用于共享编码器的共模扰动，可以让所有「证人」一起点头；R69 的「k 源一致」于是退化成「1 源重复 k 次」。R69 自陈的最大风险（把人类的误导性回答盖上「已验证」的章），正是这个漏洞的下游：不是证人太少，而是**证人会串供**。
>
> 更隐蔽的是，R69 用来证明自己可信的东西——ECE < 0.05、AUC ≥ 0.85、覆盖率 ≥ 90%——全部是**基准测试**。如果基准泄漏、被污染、或已经被优化到饱和，那么「证书」只是在证明「我们通过了自己出的题」。R70 要问的正是元问题：**我的证人凭什么可信？我的尺子凭什么准？**
>
> 两个灵感刚好补两块：
> - **自监督学习**：在没有标签的日常数据流里，用时间箭头、掩码重建、跨视角/跨模态互预测、群等变性、动作条件预测、时序装配等 pretext 任务，**批量制造「视角不同」的证人**；安全标签只在功效评估时出现，不在训练时出现——这让稀有事件也有机会被覆盖，而不必先有稀有标签。
> - **基准测试**：把「可信」从一句形容词变成一个**有功效分析、有污染审计、有负对照、有预注册、有不可触碰保留集**的可证伪测量；并且给基准本身做基准（元基准），防止 Goodhart。
>
> 核心命题：**把 R69 的「证据纪律」从「假设正交」升级为「测量正交」：用自监督生成多方证人，用基准测试测量它们的功效、条件独立性与有效性；用 e-value/e-BH 在任意相关下控制误验证率；用元基准与不可触碰保留集保证尺子本身没被调歪。只有当证人可采、基准有效、且合成证据通过统计判决时才允许定案；否则输出 UNVERIFIED 并单调退化。R69 是 WITNESS 在「证人完美独立、基准完美有效」时的逐指令退化。** 命名 **WITNESS-RAS**（Witnessed Independent Testimony with Normalized Evidence under Self-Supervision）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我的证人会不会串供，我的考卷是不是泄题**」。

## 0. 直觉与动机

**灵感 1（自监督 → 不靠标签也能造证人，而且能造出「看到不同东西」的证人）**
直觉：R69 的证据源不正交，根因是它们共享同一条信息通路：同一传感器、同一编码器、同一数据分布。自监督的妙处不只是「省标签」，而是它天然提供**多条不同的信息通路**：同一段经历可以分别用「时间箭头对不对」「被遮住的部分能不能从其余部分重建」「视觉与本体感觉能否互相预测」「施加已知变换后预测是否按同一律移动」「做了 a 是否真的看到 y」「片段装配后整体是否自洽」去检验。每条通路看到的异常不同、犯错的理由也不同，因此**近似条件独立**。人验证一个陌生人也从不把同一个问题问三遍，而是看「说的、做的、换角度看的」是否一致。

**灵感 2（自监督 → 把无标签数据变成覆盖，而不是变成自信）**
直觉：安全关键的稀有事件几乎没有标签，但**无标签的正常很多**。自监督可以用大量正常数据学「世界本该如何演化」，于是稀有事件表现为**可预测性崩塌**。但这里有个陷阱：一个会预测背景纹理的模型，对「前方是玻璃」毫无帮助。所以自监督证人必须经过**基准测试的功效检验**——判据不是「pretext loss 降了」，而是「它在预注册留出集上能区分我们真正关心的失败模式」。无标签只负责扩大覆盖，不负责签发结论。

**灵感 3（基准测试 → 正交性是可测的，不是可假设的）**
直觉：R69 说「k 个正交证据源」，但相关系数 ρ 从未被量过。其实可以量：给定真实模态/真实损坏状态后，计算证人残差之间的条件互信息或偏相关；得到相关矩阵 R 后，用**有效独立数 k_eff**（类似有效样本量）代替名义 k。若 k_eff < 2，则「两源一致」根本没有发生，只是同一个证人说了两遍。这把一句不可证伪的话（「它们正交」）变成一张可审计、可复核的表。注意：k_eff 决定的是**检验功效**，不是**有效性**——相关性不会让 e-value 失效，只会让证据变弱。

**灵感 4（基准测试 → 尺子会因被优化而失效，所以必须给尺子做尺子）**
直觉：基准测试只有两种死法：**泄漏/污染**（训练见过测试）与 **Goodhart**（指标变成目标就不再是好指标）。R69 的 E287/E289 一旦成为优化目标，模型就会去拟合基准捷径（拍摄日期、站点 id、传感器指纹、标注者习惯）。解药不是「再换一个基准」，而是**元基准**：保留一块永不参与选择的「不可触碰保留集」，加负对照（标签打乱、时间反转、模态打乱后指标必须回到随机水平），并监测「基准分数上涨、保留集不涨」的背离。尺子必须报告自己的误差棒与失效条件，否则它只是另一个黑箱。

**灵感 5（合流 → 「已验证」必须是统计判决，而「不可验证」是合法结论）**
直觉：一个只会加模块的纲领，最终会把「我不知道」重新命名为「我验证过了」。WITNESS 必须允许第三种状态：**UNVERIFIED**。当证人功效不足、k_eff 太低、共模异常、基准失效、或元基准显示 Goodhart 时，系统不能把「没证据反对」当成「证据支持」，必须退回 R69 的保守分支再退 R68，并在证书里明确写「本轮未验证」，而不是盖一个空的「已验证」章。**沉默不是同意。** 同时，R69 的「k 源一致」从一条无统计含义的口诀，升级为在任意相关结构下可控制误验证率（FDR ≤ α）的判决规则。

## 1. 形式化定义（增量：定义 310–324）

**定义 310（WITNESS-RAS 总览）** WITNESS-RAS = (SWF, WPR, EVB, WVG, CMD, BRC, MBM, BDR, RAS-WM§)。三不变式：
(i) **证人可采性**：任何参与定案的证人必须同时通过功效、不变性、有效性、成本四检验（定义 312）；
(ii) **基准有效性**：任何进入证书的指标必须来自通过 BRC 的基准（定义 318–319），且评估只用不可触碰保留集或预注册留出集；
(iii) **不可验证即保守**：证人/基准任一失效 ⇒ 输出 UNVERIFIED，禁止交互定案，单调退化为 R69 的保守分支再退 R68。

**定义 311（证人）** 对假设 H（「哪个模态正确」「观测是否被共模污染」「是否存在表示外缺口」），证人 w: 𝒪 × 𝒜_info → 𝒯 把观测（及可选交互回应）映射为带强度的证词 t ∈ 𝒯（e-value / 置信分 / 序贯检验统计量）。证人必须**可复算**（给定种子确定）、**可审计**（输出中间量）、**可退役**（漂移后停用，定义 321）。

**定义 312（证人可采性四检验）** w 可采当且仅当：
(a) **功效**：在预注册留出集上，对目标失败模式在效应 δ 下的检测功效 ≥ 1−β；
(b) **不变性**：对无害 nuisance 群 G（光照、语速、站点、传感器增益等）满足 w(g·o)=w(o) 或已知等变律，且不变性检验通过；
(c) **有效性**：零假设下 w 是合法 e-value（E[w]≤1）或 conformal p-value（有限样本有效）；
(d) **成本**：摊销延迟与内存落在预算内（定义 324）。
四项缺一 ⇒ w 只能作「提示」，不能作「定案证据」。

**定义 313（自监督证人工厂 SWF）** 在无标签流 𝒟_u 上训练六族 pretext 证人：
- w_time：时间箭头/顺序判别（检测逆动力学、回放攻击）；
- w_mask：多组**独立掩码**下的重建一致性（模态内 epistemic 分歧）；
- w_cross：跨模态/跨视角互预测（视觉↔本体↔音频↔语言）；
- w_equiv：已知变换下的等变性残差（检测 shortcut / 风格特征）；
- w_pred：动作条件预测残差（「做了 a 却看到 y」的惊讶度，复用 R69 的 FMA）；
- w_asm：时序片段装配/拼图（检测局部合理、整体不合理）。
pretext 训练不使用下游安全标签；标签只在定义 312(a) 的功效评估中出现。

**定义 314（功效与有效独立数 WPR）** 证人集合 W={w_i}，给定 H 后的残差相关矩阵 R=[ρ_ij]，条件互信息 I(w_i;w_j|H)。定义功效权重 λ_i 与
`k_eff = (Σ_i λ_i)² / (Σ_i Σ_j λ_i λ_j ρ_ij)`（ρ_ii=1）。
两两条件独立时 k_eff=k；存在共模因子使 ρ_ij→1 时 k_eff→1。**R69 的「k 源一致」只在 k_eff ≥ k_min（默认 2）时才真正发生。**

**定义 315（证据合成 EVB：任意相关下的误验证控制）** 每个可采证人输出 e-value e_i（零假设下 E[e_i]≤1）。对「模态 m 正确」这一族假设，用 **e-BH** 或 e-value 平均做多重检验；e-BH 在**任意相关结构**下控制 FDR ≤ α。仅当某模态的合成证据通过 e-BH（或序贯 e-process 越过预注册阈值）才标记 VERIFIED，否则 UNVERIFIED。这把 R69 的「多数一致」替换为「在测得的 k_eff 与相关结构下仍可控制的统计判决」。

**定义 316（证人有效性门 WVG）** 实时阶段只用廉价可采子集 W_fast（w_pred、w_time、w_equiv 的轻量版）；若 W_fast 报异常或 U_epi 超阈，才升 K 并调用 W_slow。WVG 规则：仅当 |W_fast| ≥ 2、k_eff(W_fast) ≥ k_min、且所有证人当前有效（未因漂移退役）时，才允许 MINT 用证人证据做交互决策；任一不满足 ⇒ 不交互、标记 UNVERIFIED、走 R69 保守分支。

**定义 317（共模检测 CMD）** 在异常片段上计算证人残差的协方差谱。若第一主成分解释比 η_1 > τ_cm 且所有证人同向偏移，判为**共模异常**（共享编码器漂移 / 传感器偏置 / 对抗共谋）。共模异常是 k_eff 崩塌的可观测征兆：此时即使所有证人「一致」，也一律不得定案，并直接触发 R69 的 slow_fault_suspect 与 R68 的最保守退避。

**定义 318（基准胶囊 BC）** 一个基准不是一个数据集，而是一个胶囊：
BC = (task_spec, split_provenance, contamination_report, power_analysis, invariance_suite, negative_controls, prereg_hash, version)。
任何数据、阈值、划分的改动都升版本；旧证书不可跨版本复用。

**定义 319（基准可靠性证书 BRC）** BRC(B) 有效当且仅当：
(i) 功效分析通过：声明效应 δ 下检验功效 ≥ 1−β；
(ii) 污染审计通过：训练↔测试重叠、时间泄漏、站点泄漏、预训练语料泄漏均低于 c_max；
(iii) 负对照通过：标签打乱/时间反转/模态打乱后，指标回到随机区间；
(iv) 不变性套件通过：无害变换不改变结论；
(v) 保留集完整：不可触碰保留集未被用于任何选择（哈希承诺 + 访问日志）。
任一失败 ⇒ B 不可用于证书，只能作「诊断」输出。

**定义 320（元基准 MBM 与 Goodhart 监测）** 令 s_B 为基准分数、s_R 为不可触碰保留集（或预注册 shadow）分数。定义泛化背离 `g_gap = s_B − s_R` 与优化压力 `o_press = 选择轮数 × 每轮调参量`。MBM 对 g_gap 做序贯检验：若显著为正（基准涨、保留集不涨）⇒ 判定 Goodhart，冻结该基准的「选择」用途、只保留「报告」用途，并强制换用保留集或新版本。**对尺子做尺子。**

**定义 321（不可触碰保留集与基准漂移 BDR）** 保留集 R 的访问需哈希承诺与配额；每次使用消耗「窥探预算」并降低其有效性等级。世界漂移用自监督分布距离（证人残差分布、表征 MMD）监测；漂移超阈 ⇒ R 可能过期，证书降级为「历史有效」，需按预注册刷新策略重建。

**定义 322（自监督基准刷新与选择偏差控制）** 刷新只能使用**预先声明**的规则（采样窗口、分层、样本量、标签获得方式），触发条件与脚本哈希预注册。禁止「看了结果再决定刷新」，否则等于用保留集调参。自监督可提供覆盖/分歧/难度分层，但**不得替代真实标签做结论**。

**定义 323（威胁模型 AIC-WITNESS）** ℰ_WITNESS = ℰ_FLUID × ℰ_witness × ℰ_bench。
ℰ_witness：无标签数据投毒/后门、证人共谋（共享 shortcut）、共模扰动、证人漂移。
ℰ_bench：泄漏/污染、负对照作弊、保留集窥探、Goodhart 攻击、基准版本回滚、选择性上报。
其新颖处：攻击对象是**「可信度」本身**——不改变动作，而让验证机制说谎。

**定义 324（证书 J_WITNESS 与三级退化）** J_WITNESS = (J_FLUID, witness_power_profile, k_eff, e_values_hash, WVG_status, CMD_flag, BRC_hash, g_gap, reserve_integrity, bench_version, witness_version)。
Valid ⇔ Valid(J_FLUID) ∧ 所有定案证人可采 ∧ k_eff ≥ k_min ∧ CMD 未触发 ∧ BRC 有效 ∧ 保留集完整。
退化链：WITNESS →（证人失效/基准失效/UNVERIFIED）→ R69 保守分支（不交互）→ R68（永不交互）。安全侧单调不弱。

## 2. 关键算法骨架

```python
# IP-264 SWF：自监督证人工厂（离线；不用下游安全标签）
class WitnessFactory:
    def __init__(self, trunk, pretexts):
        self.trunk = trunk                 # 复用 R68/R69 表征，冻结或轻量适配
        self.pretexts = pretexts           # time/mask/cross/equiv/pred/asm
    def fit(self, unlabeled_stream):
        for task in self.pretexts:
            task.fit(self.trunk, unlabeled_stream)   # 只学 pretext，不碰安全标签
        return [w for w in self.pretexts if power_ok(w)]

# IP-265 WPR：功效 + 条件独立性 + 有效独立数
def witness_report(witnesses, heldout, H):
    power = {w: detection_power(w, heldout, H) for w in witnesses}
    R     = conditional_corr(witnesses, heldout, H)   # 给定 H 的残差相关
    lam   = normalize(power)
    k_eff = (sum(lam)**2) / sum(lam[i]*lam[j]*R[i][j]
                               for i in range(len(lam)) for j in range(len(lam)))
    return power, R, k_eff

# IP-266 EVB：任意相关下的 e-BH 证据合成（有效性不依赖独立性）
def combine_evidence(testimonies, alpha):
    e_vals   = [t.e_value for t in testimonies if t.admissible]
    selected = e_BH(e_vals, alpha)          # FDR <= alpha，任意相关
    return VERIFIED if selected else UNVERIFIED

# IP-267/268 WVG + CMD：不可采/共模即 UNVERIFIED
def gate(w_fast, w_report, anomaly_window):
    if len(w_fast) < 2 or w_report.k_eff < K_MIN:   return UNVERIFIED
    if not all(w.valid_now for w in w_fast):        return UNVERIFIED
    if common_mode(anomaly_window, tau_cm):         return COMMON_MODE
    return combine_evidence([w.testify() for w in w_fast], ALPHA)

# IP-269/270 BRC + MBM：基准胶囊与元基准
def valid_benchmark(cap):
    return (cap.power_ok and cap.contamination <= C_MAX
            and cap.negative_controls_at_chance and cap.invariance_ok
            and cap.reserve_intact)

def goodhart_monitor(s_B, s_R):
    return sequential_test(s_B - s_R > 0)   # 显著为正 ⇒ 冻结「选择」用途

# IP-275 主闭环（继承 R69；插入「证人可采 / 基准有效」门）
def WITNESS_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    # R70-1 廉价自监督证人（摊销，不新增重网络）
    T_fast = M.swf.testify_fast(o, M.last_action, z)
    # R70-2 可采性与共模：不可采即 UNVERIFIED，禁止交互定案
    status = M.wvg.gate(T_fast, M.wpr, M.cmd.window(o))
    # R70-3 只有「可验证的歧义」才值得问
    ask_ok = (U_epi > TAU_EPI and status is VERIFIED
              and M.wpr.k_eff >= K_MIN and not M.fma.slow)
    g = M.mint.choose_interaction(modes, o, M.budget) if ask_ok else None
    if g is not None:
        ans = M.cia.execute(g)
        if not M.wvg.verify_answer(ans, T_fast):    # 回答也要过证人一致
            ans, status = None, UNVERIFIED
        if ans is not None:
            U_epi = M.cia.update_belief(modes, ans)
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    if status is not VERIFIED or M.cmd.triggered:
        lam = max(lam, LAM_WITNESS)                 # 未验证 → 更保守
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_t.submit(T_fast, status, M.mbm.g_gap, M.bench_version)
    return k, lam, mode, (U_ale, U_epi, status)
```

## 3. 推导

**引理 19（共模否决 / R69 的 k 源一致有下界）** 设证人以概率 δ_c 遭遇共模扰动而**全体**误接受，其余情形各自独立误接受 δ_p。则 k 源一致规则的错误接受率为
`P_err = δ_c + (1−δ_c)·P_ind(k)`，其中 P_ind(k)→0 随 k 增大（独立多数投票）。
故 **k 再大也压不掉 δ_c 这个地板**；R69 的「k 个正交源」在共模存在时不是冗余，而是同义反复。系：必须测量 ρ_ij 与共模谱，否则「正交」是一个未经检验的强假设。

**引理 20（e-BH 在任意相关下的 FDR 控制）** 若每个零假设下的 e-value 满足 E[e]≤1，则 e-BH 在**任意依赖结构**下控制 FDR ≤ α；且 e-value 的平均仍是合法 e-value。故**相关性破坏的是功效，不是有效性**：k_eff 低时结论更保守（更难通过），但一旦通过，误验证率仍受 α 控制。这为「不假设正交也能定案」提供了统计基础。

**引理 21（nuisance 不变性 → shortcut 抑制）** 设群 G 作用在观测上，H 对 G 不变，而捷径特征 S 在 G 的轨道内变化。任何 G-不变证人 w 在每个轨道上是常数，因此无法区分轨道内不同的 S 值；若 S 的变异完全发生在轨道内，则 I(w;S|H)=0。系：w_equiv 这类等变证人天生对光照/站点/风格等无害变化免疫，从结构上排除 R69 最怕的「模型学到数据集指纹」。

**引理 22（污染放大与保留集下界）** 设测试集中比例 c 的样本曾出现在训练中，模型对被记住样本的收益上界为 B，则测得指标 R̂ 与真实指标 R 满足 |R̂−R| ≤ c·B。若不可触碰保留集 R_res 未被污染，则其估计无此偏差，且 `g_gap = s_B − s_R` 是 c·B 与 Goodhart 的联合估计。故**只有真正未被看过的保留集，才能把『尺子被调歪了多少』量出来**；这也解释了为什么保留集访问必须记账与承诺。

**定理 18（WITNESS 是 R69 的保守扩展）** 在定义 310–324 下，WITNESS 的可行动作集是 R69 可行集的**子集**（新增的证人可采性、k_eff 门槛、BRC 有效性均为合取约束），故任意状态点态风险 ≤ R69；当证人完美可采且条件独立（k_eff=k）、基准完美有效、无共模异常时，两者**逐指令相同**。⇒ R68 ⊂ R69 ⊂ WITNESS；安全侧不让步，效率侧只在「可验证」时兑现。

**定理 19（无假「已验证」/ 误验证率受控）** 在证人可采（零假设下 e-value 合法）且定案只经 e-BH 的前提上，任意相关结构与有限样本下，
`P(把错误模态标为 VERIFIED) ≤ FDR ≤ α`。
若证人可能被投毒以致有效性不成立，WVG 无法证明其 e-value 合法性，则返回 UNVERIFIED（拒绝定案）。
系：R69 的「k 源多数一致」在共模下 FDR 可趋于 1；WITNESS 把它压回 α，代价是更多 UNVERIFIED。

**定理 20（元基准守恒 / 尺子有效性）** 在保留集完整、刷新严格按定义 322 预注册的前提下，MBM 对零假设「基准分数 = 保留集分数」的序贯检验在水平 γ 下控制第一类错误。因此任何「基准声称的改进」若未被保留集支持，将以 ≥1−γ 的概率被拒绝；反之，若 g_gap 显著，则证书对该基准降级。**这是「证书的证书」：它不保证模型对，只保证『说它对』这件事有据可查。**

## 6. 本轮最大风险

**一句话**：WITNESS-RAS 的最大风险是**把「可测量」误当成「已测量正确」**——自监督证人只在无标签 pretext 代理任务上被证明有功效，基准测试又只在它自己声明的分布与污染模型内被证明可靠；一旦代理任务与真实安全目标脱钩、或基准被优化到饱和/被污染，系统就会带着一份「统计上显著」的证书，自信地验证一个错误。**最危险的不是没有尺子，而是一把被反复校准到基准上的尺子。**

```python
# IP-264 SWF：自监督证人工厂（离线，无下游安全标签）
class WitnessFactory:
    def fit(self, unlabeled_stream):
        for task in self.pretexts:                 # time/mask/cross/equiv/pred/asm
            task.fit(self.trunk, unlabeled_stream)
        return [w for w in self.pretexts if power_ok(w)]

# IP-265 WPR：功效 + 条件相关 + 有效独立数
def witness_report(witnesses, heldout, H):
    power = {w: detection_power(w, heldout, H) for w in witnesses}
    R     = conditional_corr(witnesses, heldout, H)
    lam   = normalize(power)
    k_eff = (sum(lam)**2) / sum(lam[i]*lam[j]*R[i][j]
                               for i in range(len(lam)) for j in range(len(lam)))
    return power, R, k_eff

# IP-266 EVB：任意相关下控制 FDR 的证据合成
def combine_evidence(testimonies, alpha):
    e_vals = [t.e_value for t in testimonies if t.admissible]
    return VERIFIED if e_BH(e_vals, alpha) else UNVERIFIED

# IP-267/268 WVG + CMD：不可采/共模即拒绝定案

    if not all(w.valid_now for w in w_fast):    return UNVERIFIED

    return combine_evidence([w.testify() for w in w_fast], ALPHA)

            and cap.negative_controls_at_chance and cap.invariance_ok

    return sequential_test(s_B - s_R > 0)       # 显著为正 ⇒ 冻结「选择」用途

# IP-275 主闭环（继承 R69）
def WITNESS_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    T_fast = M.swf.testify_fast(o, M.last_action, z)      # 摊销，不加重网络
    status = M.wvg.gate(T_fast, M.wpr, M.cmd.window(o))    # 可采/共模门
    ask_ok = (U_epi > TAU_EPI and status is VERIFIED
              and M.wpr.k_eff >= K_MIN and not M.fma.slow)
    g = M.mint.choose_interaction(modes, o, M.budget) if ask_ok else None
    if g is not None:
        ans = M.cia.execute(g)
        if not M.wvg.verify_answer(ans, T_fast): ans, status = None, UNVERIFIED
        if ans is not None: U_epi = M.cia.update_belief(modes, ans)
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    if status is not VERIFIED or M.cmd.triggered: lam = max(lam, LAM_WITNESS)
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_t.submit(T_fast, status, M.mbm.g_gap, M.bench_version)
    return k, lam, mode, (U_ale, U_epi, status)
```

## 4. 推导

**引理 19（共模否决）** 若证人以概率 δ_c 被共模扰动全体误接受，其余情形独立误接受 δ_p，则 k 源一致的错误接受率 `P_err = δ_c + (1−δ_c)·P_ind(k)`，P_ind(k)→0 但 δ_c 是**不可通过增加 k 消除的地板**。系：不测 ρ 与共模谱，「k 个正交源」就是同义反复。

**引理 20（e-BH 任意相关下的 FDR 控制）** 零假设下 E[e]≤1 时，e-BH 在任意依赖结构下控制 FDR ≤ α；e-value 平均仍是合法 e-value。故相关性削弱功效而非有效性：k_eff 低更难通过，但通过即受控。

**引理 21（不变性抑制 shortcut）** G-不变证人无法区分同一 G-轨道内的捷径特征 S，故 I(w;S|H)=0（当 S 的变异在轨道内）。系：w_equiv 从结构上排除光照、站点、传感器指纹等数据集捷径。

**引理 22（污染放大与保留集下界）** 训练↔测试重叠比例 c、记忆收益上界 B 时，|R̂−R| ≤ c·B。未被污染的保留集无此偏差，`g_gap=s_B−s_R` 联合估计污染与 Goodhart。故只有真正没被看过的保留集能量出「尺子歪了多少」。

**定理 18（WITNESS 是 R69 的保守扩展）** 新增证人可采性、k_eff 门槛、BRC 有效性均为合取约束，故可行动作集 ⊆ R69 可行集，点态风险 ≤ R69；当证人完美可采且条件独立、基准完美有效、无共模时逐指令相同。⇒ R68 ⊂ R69 ⊂ WITNESS。

**定理 19（无假「已验证」）** 证人可采且只经 e-BH 定案时，`P(错误模态被标为 VERIFIED) ≤ FDR ≤ α`，任意相关结构与有限样本下成立；若证人有效性无法证明（疑投毒），WVG 返回 UNVERIFIED。系：R69 的多数一致在共模下 FDR 可趋于 1；WITNESS 压回 α，代价是更多 UNVERIFIED。

**定理 20（元基准守恒）** 保留集完整且刷新按定义 322 预注册时，MBM 对「基准分数=保留集分数」的序贯检验在水平 γ 下控制第一类错误；未被保留集支持的「改进」以 ≥1−γ 概率被拒，g_gap 显著则证书对该基准降级。它不保证模型对，只保证「说它对」有据可查。

## 7. 本轮最大风险

**一句话**：WITNESS-RAS 的最大风险是**把「可测量」误当成「已测量正确」**——自监督证人只在无标签 pretext 代理任务上被证明有功效，基准测试又只在它自己声明的分布与污染模型内被证明可靠；一旦代理任务与真实安全目标脱钩、或基准被优化到饱和/被污染，系统就会带着一份「统计上显著」的证书，自信地验证一个错误。**最危险的不是没有尺子，而是一把被反复校准到基准上的尺子。**

**次级风险与缓解**：
1. **代理任务错位**（pretext 与安全目标无关）→ 定义 312(a) 功效检验 + E301/E315，未通过不得定案；
2. **证人共谋/共模**（同一 trunk 的 shortcut）→ WPR 测 ρ 与 k_eff + CMD 谱检测 + 定义 313 的多通路设计；
3. **基准污染与 Goodhart** → BRC 污染审计/负对照 + MBM 元基准 + BDR 不可触碰保留集（引理 22、定理 20）；
4. **无标签数据投毒/后门** → ℰ_witness 对抗训练 + 证人隔离 + E310，疑投毒即 UNVERIFIED；
5. **「未验证」被误读为「已验证」** → 证书强制三态（VERIFIED / UNVERIFIED / COMMON_MODE）+ VQAuditor-T 审计 + 定理 19 的统计含义写入对外说明。
