# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「安全对齐」×「数据集构建」）

> R69 教会系统「向谁求证、还能问什么」：把不确定性拆成 aleatoric/epistemic，用流匹配采样得到有形状的歧义，再用注视、探针、问句去消解。但 R69 有一个从未明说的地基假设——**数据集是给定的、静态的、可信的**。它自陈的最大风险（流模型幻觉出不存在的模态、或把真模态坍缩掉），本质上不是推断问题，而是**覆盖问题**：如果训练分布里从来没有「绕右」这个模态，再好的模态校准、再精确的 VoI、再灵敏的流似然第二意见，都不可能凭空把它变出来；流模型硬要生成，只会产生幻觉模态。**用运行时推断去补数据空洞，是缘木求鱼。**
>
> 本轮两个灵感正好补上这块地基，而且互补：
> - **安全对齐**提醒我们：对齐不是盖在权重上的一个章，而是**有前提、有作用域、可被证伪**的断言；最难的不是「正常情况做对」，而是「只差一点就错」的边界，以及测试/证书本身被 Goodhart 化。
> - **数据集构建**把数据从「背景」变成**控制变量**：收集哪些轨迹、在什么上下文、由谁标注、带什么对比、冒多大风险，本身就是安全闭环的第一层决策——它决定系统「能表示什么」、「能对什么产生可消解的歧义」、以及「凭什么说自己安全」。
>
> 核心命题：**把「安全对齐」重新定义为「数据可证明的作用域约束」。每条对齐断言必须绑定可证伪的见证集（正例 × 近失负例 × 配对反事实 × 反例搜索记录）；可部署的 ODD 由证据充分度决定，而不是由愿望决定；数据构建本身是一个受安全预算约束、以「反例发现 + 证据增益」为目标的信息动作。** 命名 **SEAM-RAS**（Safety-Evidence Alignment at the support Margin：在数据支持边界上结算的安全对齐风险自适应闭环；SEAM 即「覆盖与未覆盖之间那条对齐的缝」）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**它没见过的世界，我们凭什么说它是安全的**」——对齐不是训练出来的属性，而是数据买来的、按作用域结算的、可被撤稿的证据。

## 0. 直觉与动机

**灵感 1（安全对齐 → 对齐不是属性，是有作用域的断言）**
直觉：我们习惯说「这个模型已经对齐了」，好像对齐是一枚可以盖在权重上的章。真实的物理安全对齐恰恰相反：它是一句**有前提、有范围、可被证伪**的话——「在有行人的路口、速度低于 X、传感器健康时，它会在接触前把速度降到零」。离开前提，这句话没有真值。R69 的问题正在这里：J_FLUID 只对单次决策负责，却默认「模型的模态分布可信」；一旦问的是训练里从没出现过的情形，任何证书都只是在给一个空集盖章。所以对齐必须被拆成一条条 claim，每条 claim 绑定自己的作用域与见证。

**灵感 2（数据集构建 → 覆盖决定可问性）**
直觉：R69 的流模型只能生成它见过的模态的邻近版本。数据集不是布景，而是策略的**构成性基质**：训练分布的支持集划定了「系统能表示什么」，也就划定了「它能在运行时对什么产生可消解的歧义」。数据里没有「绕右」，VoI 再精确也算不出绕右的值；流模型若硬要生成，只会产出幻觉模态——这正是 R69 自陈的死穴。因此**数据集构建不是部署前的杂务，而是安全闭环的第一层控制**：先决定世界以什么方式被经历，再谈运行时怎么问。

**灵感 3（对比而非堆量 → 对齐需要「差一点」的样本）**
直觉：安全对齐最难的不是「正常情况做对」，而是边界。「行人突然出现时它会停」要成立，必须排除「它其实是被雨天/路口/速度带出来的刹车」。纯 i.i.d. 堆量只能提高平均精度，不能提高可辨识性：正例再多，也证明不了一条反事实。数据里必须有**控制变量的配对**——同一场景只改安全相关因子，其余不变。因此数据集构建的核心产物不是「更多轨迹」，而是**见证集**：正例 + 近失负例 + 配对反事实 + 反例搜索记录。

**灵感 4（统计证据 → 对齐是可以结算价格的）**
直觉：如果一条 claim 说「失败率 ≤ δ」，要在 1−α 置信度上成立需要多少次独立试验？答案可算：零失败时约 (1/δ)ln(1/α) 次。这把「对齐」从形容词变成一张**账单**：想覆盖更大的 ODD，就得付更多、更多样的独立数据；而数据高度相关（同一车队、同一标注组、同一仿真器），有效样本远小于名义样本。对齐税从此不能被藏进「平均性能」里。

**灵感 5（双向威胁 → 采集会伤人，证据会造假）**
直觉：R69 已经知道「问错比不问更危险」；R70 要补上两把同构的刀。第一刀在**采集侧**：为拿到罕见危险场景的数据而把系统开进危险区，是以安全换证据——必须被采集预算和同一套 C-RAS-WM† 认证约束，且「观测 / 受护干预 / 开放干预」要分级，不许「撞车学习」。第二刀在**证据侧**：偏好投毒、标注者被俘获、基准污染、仿真器过拟合，以及「应试数据」（专挑容易通过的切片堆证据）都会让账本看起来更可信、实际更脆弱。**能买来证据的机制，也一定能被用来买假证据。**

## 1. 形式化定义（增量：定义 310–328）

**定义 310（SEAM-RAS 总览）** SEAM-RAS = (SEL, DOC, DAP, FAL, AMM, CVX, S2R, DPC, RLG, GATE, RAS-WM†)。继承 R69 定义 293 的三条不变式（实时流零学习写、交互预算硬约束、证据纪律），并新增三条：
(iv) **断言-见证完备**：任何进入证书的安全/对齐断言必须绑定账本中可核验的见证集与出处；无见证的断言视为不成立，其作用域按最保守方式处理；
(v) **采集安全**：数据采集动作 u 与任务/信息动作受同一 C-RAS-WM† 认证与同一风险预算约束；不得以不可恢复的伤害换取证据；
(vi) **证据单调与可撤销**：证据只允许扩张已认证 ODD 或保持不变；任何证据失效（污染、撤稿、sim2real 失配）立即收缩相应 ODD，并回溯依赖它的证书，绝不因旧证书存在而拒绝收缩。

**定义 311（对齐断言 Alignment Claim）** κ = (φ, ψ, δ, α, R)：φ 为 ODD 前置条件（地理/天气/参与者/传感器健康等），ψ 为可观测的行为性质（「在接触前减速至零」），δ 为目标失败率上界，α 为置信水平，R 为 φ 定义的作用域。断言是部署的最小单位：系统不声称「已对齐」，只声称「在 R 上以 1−α 置信度失败率 ≤ δ」。R 越大、δ 越小，所需证据越多（定义 319、引理 21）。

**定义 312（安全证据账本 SEL）** 把每个 κ 映射到证据元组 E(κ) = (W⁺, W⁻, W_cf, F, P)：W⁺ 正例见证（满足 ψ 的轨迹）；W⁻ 近失负例（只差一点就违反 ψ，用于刻画边界）；W_cf 配对反事实（只改变安全相关因子、其余受控的成对样本）；F 反例搜索记录（搜索过的上下文、覆盖度、未发现反例的预算）；P 出处与血统（采集者、传感器栈、标注面板、仿真器版本、时间）。Valid(κ) ⇔ E(κ) 满足定义 319 的充分度且 P 通过定义 321 的污染审计。

**定义 313（数据集卡 DOC）** D = (S, Prov, Consent, Panel, Process, Contam, hash)：切片构成 S、来源与许可、标注者构成 Panel（谁的价值被编码）、采集过程 Process（观测/干预、是否受护）、污染报告 Contam、版本哈希。DOC 的核心纪律是**把「数据里有什么」与「数据为什么长这样、由谁决定」分开记录**——后者往往才是安全风险所在。

**定义 314（支持、覆盖与支持洞）** 策略在数据分布 p_D 上训练，其可表示模态集 M_supp(D) = cl(supp(p_D))。对上下文 c，覆盖 Cov_c(D) 度量 c 的安全相关因子上可被对比辨识（定义 315）的份额。**支持洞** H(D) = {m : m 在安全语义上可达，但 p_D(m) ≈ 0}。U_epi 只有在 m ∈ M_supp(D) 时才可能被运行时交互消解；m ∈ H(D) 时是数据问题，不是推断问题。

**定义 315（对比可辨识性 CVX）** 设 f 为安全相关因子（行人意图、路面摩擦、载荷），z 为其余混杂因子。断言 κ 关于 f 可辨识，当且仅当 D 中存在匹配对 (x, x′)，使 f 改变而 z 近似不变，且 p_D(f|x,z) 有正重叠。若只有观测性正例、无配对或干预，则关于 f 的对齐断言不可辨识（引理 20）。

**定义 316（数据采集动作）** u = (slice, intervention, modality, ask_who) ∈ 𝒜_data：选择切片/上下文、选择观测或干预、选择传感模态、选择向谁取证。采集有物理/社交风险 risk(u)、成本 c(u)、以及改变未来证据分布的信息效应。𝒜_data 与 R69 的 𝒜_+ 正交扩展：ξ̂ = (a, g, u)。

**定义 317（数据价值 VoD）** 对当前约束最紧的断言集 K_bind，定义
VoD(u) = [ max_{κ∈K_bind} UCB_κ(E) − E_{e′~p(·|u)} max_{κ∈K_bind} UCB_κ(E∪e′) ] / (c(u) + λ·risk(u))，
选择 u* = argmax_u VoD(u)，s.t. risk(u) ≤ ε_data 且预算未超；若 max VoD ≤ 0 则不采集。与 R69 的 VoI 对偶：VoI 买「这一次判断的确定性」，VoD 买「这一整类断言的确定性」，且分母是风险而非熵。

**定义 318（证伪引擎 FAL）** 主动搜索 κ 的反例，而非靠平均样本提高精度：对抗上下文生成、罕见模式挖掘、近失合成（仿真/受护实采）、红队数据请求。目标函数是**在预算内最大化「发现违反 ψ 的轨迹」的概率**；一旦发现即触发定义 328 撤稿。FAL 同时是 W⁻ 与 F 的来源。

**定义 319（证据充分度 AMM）** 设 κ 在 n_eff 次独立见证中观测到 k 次失败，取 Beta(1,1) 后验，失败率上界 UCB_κ = Beta^{-1}(1−α; k+1, n_eff−k+1)。定义充分度 ES(κ) = 1 − UCB_κ/δ（≥ 0 即通过）。零失败时 n_eff ≥ ln α / ln(1−δ) ≈ (1/δ)ln(1/α)。这把「对齐」变成可计算的样本账单（引理 21）。

**定义 320（有效样本与独立血统）** 名义样本 n 经血统图折算 n_eff = n / (1 + (m̄−1)ρ)，m̄ 为平均簇大小、ρ 为簇内相关（同一车、同一标注组、同一仿真种子、同源传感器）。独立血统数 l(κ) 为账本中互不共享祖先的见证簇数；自我采集且自我标注的数据对 κ 的升权贡献按定义 324 折扣。

**定义 321（数据威胁模型 ℰ_data）** ℰ_data = ℰ_contam（基准污染）× ℰ_label（标注/偏好投毒）× ℰ_capture（标注者/机构俘获）× ℰ_cherry（应试数据：只采易过测试的切片）× ℰ_prov（出处伪造）× ℰ_sim（仿真器过拟合）。防御：随机留出审计切片（vault）、出处签名、血统独立性、污染/重复检测、采集分布报告。并入 R69 的 AIC。

**定义 322（对齐成熟度与 ODD 收缩门 GATE）** 对每个作用域 R 与风险等级，要求成熟度 μ(R) ≥ μ_req(risk)；μ 由约束最紧的断言的 ES 与独立血统共同给出。未达标时**不「带风险放行」，而是收缩 R**：把 φ 中无法被证据支持的分量移出 ODD（限速、限天气、限参与者、需远程监督），使部署仍落在已被见证的子域内。安全靠缩小作用域实现，而不是靠调大阈值。

**定义 323（采集安全认证）** u 分三级：(a) **观察**（被动读传感，不进入未认证状态）；(b) **受护干预**（低速/可恢复/远程兜底/物理隔离）；(c) **开放干预**。仅 (a)(b) 可产生实采见证；(c) 只允许在经验证的仿真中进行。任何 u 必须过 C-RAS-WM† 前缀认证，risk(u) 计入总风险预算；不得用不可恢复伤害换数据。

**定义 324（Sim2Real 证据折扣 S2R）** 仿真见证的等效样本按 S2R 证书折扣：n_sim^eff = γ_sim(v, gap)·n_sim，γ_sim ∈ [0,1]，由仿真-现实匹配对（同上下文实测对照）校准；无匹配对时 γ_sim = 0，即**仿真见证不能单独升级 claim**。原则：仿真擅长找反例（证伪），不擅长发合格证（证实）——证伪只需一个真实反例，证实需要可迁移的支持。

**定义 325（对齐税与数据预算）** 对齐税 Tax = 在给定任务性能目标下，为达到 μ_req 所放弃的任务指标（成功率/时延/场景覆盖）与所消耗的采集风险。系统必须在部署证书中显式申报 (Tax_task, Risk_collected, Budget_used)；禁止把安全数据成本隐藏在「平均性能」里。

**定义 326（证书 J_SEAM）** J_SEAM = (J_FLUID, {claim_id, evidence_hash, ES, n_eff, l, coverage, contam_ok, sim_discount, collection_risk_used, seam_ver})。Valid ⇔ Valid(J_FLUID) ∧ 所有 R 上的约束断言 Valid ∧ 采集预算未越界 ∧ 无未决污染警报 ∧ 依赖图无被撤稿祖先。

**定义 327（严格包含与退化）** 当 D 固定且已认证、𝒜_data = ∅、所有断言继承自 R69 的隐含假设时，SEAM-RAS 逐指令等价于 R69（定理 18）。允许采集时，运行期保守度单调不增且永不低于 R69 的 λ_floor；一旦证据失效立即回到 R69 的最保守侧。R69 是 SEAM 在「数据封闭、无采集」边界上的退化。

**定义 328（撤销与血统传播 RLG）** 维护断言 → 证书 → 动作 → 部署的依赖 DAG。若 κ 被撤稿（反例/污染/sim2real 失配/出处伪造），所有传递依赖 κ 的证书立即失效，对应 ODD 切片回到未认证状态并触发定义 322 收缩。撤销是**单调**的：恢复需要新证据重新走完整充分度，而不是「删掉反例」。

## 2. 关键算法骨架

```python
# IP-264 SEL：把每条对齐断言绑定到可核验的见证
class SafetyEvidenceLedger:
    def binding_claims(self, odd_slice):          # 该动作/切片上约束最紧的断言
        return [k for k in self.claims if k.scope.overlaps(odd_slice)]
    def valid(self, k):
        return self.amm.ucb_failure(k) <= k.delta and self.dpc.clean(k) \
               and self.rlg.no_revoked_ancestor(k)

# IP-269 AMM：Beta-Binomial 上界 + 有效样本（血统相关折算）
def evidence_sufficiency(k, e):
    n_eff = independent_lineage(e) * sim_discount(e)   # 定义 320/324
    ucb   = beta_ppf(1 - k.alpha, e.failures + 1, max(n_eff - e.failures, 0) + 1)
    return 1.0 - ucb / k.delta, n_eff                  # ES >= 0 即过门

# IP-267 DAP：数据采集是安全预算内的信息动作（VoD，不是 VoI）
def choose_acquisition(claims, data, budget):
    best = None
    for u in acquisition_candidates(claims, data):
        if not budget.allow(u):                 continue
        if not c_ras_wm.certify_data(u):        continue   # 不许“撞车学习”
        gain = risk_bound(claims, data) - expected_risk_bound(claims, data, u)
        vod  = gain / (cost(u) + LAM * risk(u))
        if best is None or vod > best.vod: best = (u, vod)
    return best if best and best.vod > 0 else None     # 无利可图 → 不采

# IP-268 FAL：主动找反例（证伪），而不是找更多同分布样本（证实）
def falsify(k, dm):
    for c in adversarial_contexts(k.scope, dm):        # 混杂/边界/罕见模式
        tr = dm.rollout_or_synthesize(c)               # 仿真优先；实采需受护
        if k.violated_by(tr): return Counterexample(tr, c, provenance=dm.prov(c))
    return None

# IP-265 CVX：见证集设计——正例 + 近失 + 配对反事实
def design_witness(k, data):
    pairs = matched_counterfactuals(k.scope, data)      # 只改 f，其余受控
    near  = near_miss_mining(k.psi, data, margin=eps)   # “差一点”
    return WPlus(data), near, pairs                     # 交 SEL 登记

# IP-275 主闭环（R69 之上“包一层”；运行期几乎零成本）
def SEAM_RAS_round(M, obs):
    out = R69_round(M, obs)                          # 运行期策略完全继承
    # 1) 运行时：每条动作都挂在断言上，证据不足就缩圈而非放行
    for k in M.sel.binding_claims(out.odd_slice):
        es, n_eff = evidence_sufficiency(k, M.sel.evidence(k))
        if es < 0:
            out.odd = M.gate.contract(out.odd, k, es)
            out.lam = max(out.lam, lam_floor_from_gap(k, es))
    # 2) 数据侧：只买“当前最紧断言”的证据（VoD），采集也要认证
    u = M.dap.choose_acquisition(M.sel.claims, M.data, M.budget)
    if u is not None:
        M.data = M.dap.collect(u)                    # 观察/受护干预/仿真
        M.sel.absorb(u, M.data)
    # 3) 证伪优先于证实：主动搜反例，发现即撤稿并回溯
    for k, cex in M.fal.sweep(M.sel.claims):
        M.rlg.revoke(k, reason=cex, via=M.cit)
    # 4) 发证：证据不足的断言绝不进证书
    return out, M.sel.issue_certificate(out, M.gate)
```

## 3. 推导

**引理 19（支持边界：运行时补不了数据洞）** 设策略在 p_D 上训练、生成分布为 p_θ。对离 supp(p_D) 至少 r 的模态 m，p_θ(m) ≤ ε_app + C·exp(−r²/2σ²)，其中 ε_app 为函数逼近误差、σ 为核尺度。故 **m ∈ H(D) 时，U_epi(m) 不可被交互消解**；流模型在支持洞上的「模态」是边界伪影（幻觉），不是可询问的对象。系：R69 的 MCG（校准门）能识别「权重不可信」，却识别不了「根本没有这个模态」——**校准只能防止过度自信，覆盖才能防止无中生有**。

**引理 20（对比可辨识：正例堆不出反事实）** 若数据对因子 f 无配对/干预、只有观测，则存在两个在所有观测上似然相同、但在 f 的反事实上行为相反的策略。故关于 f 的对齐断言不可辨识；任何仅由 W⁺ 得出的 UCB 都只在「f 的分布内」有效，跨 f 外推不成立。系：**数据集构建必须是干预式/配对式的**，否则「堆量」只买到平均精度、买不到安全断言。

**引理 21（证据的样本复杂度）** 对 claim (δ, α)，n 次独立试验中 k 次失败时，Clopper–Pearson 上界为 Beta^{-1}(1−α; k+1, n−k+1)。k=0 时 n ≥ ln α / ln(1−δ) ≈ (1/δ)ln(1/α)。系：ODD 的每一次扩张都有显式数据价格；「声明对齐」在统计上没有意义。

**引理 22（有效样本由血统决定）** 若 n 个样本来自 c 个相关簇、簇内相关 ρ，则 n_eff ≈ n / (1 + (m̄−1)ρ)。系：单源采集（同一车队/同一传感器栈/同一标注组）几乎不能提高独立血统 l；**独立复现是唯一能真正加权的证据**，这也解释了为什么第三方审计不是形式主义。

**引理 23（VoD 的边际递减与「缝」定位）** 新样本的边际价值正比于「它成为当前约束断言的反例」的概率。对已通过的区域继续采样，UCB 改善可忽略；对未覆盖的边界（the seam）采样，一次失败即可重定价整条 claim。系：应以「最紧且证据最薄的断言」为采集目标，而非平均精度——这也是通用主动学习对安全对齐次优的原因。

**引理 24（投毒/应试下的证据偏差）** 若对手控制占比 β、出处不透明或可择优上报，则名义 UCB 相对真实失败率至少乐观 β·(1−δ)（省略高阶项）；随机留出审计切片给出的下界才是无偏的。系：出处签名与随机审计是**必需项**，自采自证不构成证据；「能通过测试」与「被测试证明」是两件事。

**定理 18（严格包含 R69 且证据单调）** 在 R69 的假设 A95–A98 上加两条：(P1) 账本证据独立且未被污染；(P2) 采集动作经定义 323 认证。则：(a) 当 D 固定、𝒜_data = ∅ 时，SEAM 与 R69 逐指令相同；(b) 允许采集时，运行期保守度关于证据单调不增，且永不低于 R69 的 λ_floor；(c) 任一证据失效都会使受影响切片立即回到 R69 最保守侧。故 R69 是 SEAM 在「数据封闭」边界上的退化，安全侧不做任何让步。

**定理 19（对齐即作用域：不存在免费的全局对齐）** 对任意有限数据集，可被认证的断言集满足引理 21 的样本复杂度下界；若部署要求覆盖区域 R，则要么证据达到 (δ, α) 要求，要么必须把 R 收缩到可被见证的子域。因此「在所有情形下都已对齐」是不可支持的断言；**安全对齐必然是作用域有界、按证据定价、可撤销的**。这是本轮的核心重构：对齐不是模型的性质，而是「模型 × 数据 × 作用域」的联合性质。

**定理 20（撤销传播正确性与采集无突变）** 依赖 DAG 上的撤稿按可达性传播，保证不存在仍有效、却传递依赖已撤稿证据的证书；采集门控保证 Σ risk(u) ≤ ε_data，且三级采集分级使实采见证不进入未认证状态。收缩是单调的（只减不增），故控制连续、无「突然扩张」突变，继承并加强 R69 定理 17。

## 6. 本轮最大风险

**一句话**：SEAM-RAS 的整个安全论证都押在「账本里的证据是独立且未被污染、sim2real 折扣是准的」这一前提上——**一旦数据管道被俘获、偏好被投毒、仿真器把现实鸿沟伪装成零，系统就会用一张统计上严谨、前提上虚假的证书，在错误的地方扩张 ODD、在正确的地方收缩 ODD，把「不可证伪」包装成「已被证明」——用可证明的严谨掩盖不可证明的前提，比没有证书更危险。**

**次级风险与缓解**：
1. **采集本身不安全**（为数据撞车、为罕见场景冒险）→ 定义 323 三级采集分级 + 风险预算 + C-RAS-WM† 认证 + 定理 20；
2. **证据 Goodhart / 应试数据** → 随机 vault 审计 + 反例搜索优先于证实 + ℰ_cherry 对抗切片 + 定义 319 的独立血统；
3. **价值歧义被抹平**（标注者多数压过真实分歧）→ E312 保留分歧层，把「意图歧义」显式登记为未消解断言，而非伪造共识；
4. **ODD 收缩诱发新的分布漂移与用户过度信任**（剩余包络内更激进）→ 收缩需连带调整人机交互提示 + 长时程监测；
5. **数据飞轮自噬**（只采模型已擅长的区域）→ VoD 以「最紧断言」为目标 + 强制探索配额 + 第三方复现。

## 3. 关键算法伪代码

```python
# IP-264/269 证据账本与充分度：把“对齐”变成可结算的样本账单
def evidence_sufficiency(k, e):
    n_eff = independent_lineage(e) * sim_discount(e)      # 血统 × sim2real 折扣
    ucb   = beta_ppf(1 - k.alpha, e.failures + 1, max(n_eff - e.failures, 0) + 1)
    return 1.0 - ucb / k.delta                            # >= 0 才允许进证书

# IP-267 DAP：数据采集 = 受安全预算约束的 VoD 信息动作
def choose_acquisition(claims, data, budget):
    best = None
    for u in acquisition_candidates(claims, data):
        if not budget.allow(u) or not c_ras_wm.certify_data(u): continue
        vod = (risk_bound(claims, data) - expected_risk_bound(claims, data, u)) \
              / (cost(u) + LAM * risk(u))
        if best is None or vod > best.vod: best = (u, vod)
    return best if best and best.vod > 0 else None        # 无利可图 → 不采

# IP-268 FAL：主动找反例（证伪），而不是堆同分布样本（证实）
def falsify(k, dm):
    for c in adversarial_contexts(k.scope, dm):
        tr = dm.rollout_or_synthesize(c)                  # 仿真优先，实采需受护
        if k.violated_by(tr): return Counterexample(tr, c, dm.prov(c))
    return None

# IP-275 主闭环：在 R69 之外包一层，运行期几乎零成本
def SEAM_RAS_round(M, obs):
    out = R69_round(M, obs)                               # 运行期完全继承 R69
    for k in M.sel.binding_claims(out.odd_slice):          # 证据不足 → 缩圈，不放行
        es, _ = evidence_sufficiency(k, M.sel.evidence(k))
        if es < 0:
            out.odd = M.gate.contract(out.odd, k, es)
            out.lam = max(out.lam, lam_floor_from_gap(k, es))
    u = M.dap.choose_acquisition(M.sel.claims, M.data, M.budget)
    if u is not None:                                      # 采集也过 C-RAS-WM†
        M.data = M.dap.collect(u); M.sel.absorb(u, M.data)
    for k, cex in M.fal.sweep(M.sel.claims):               # 发现反例 → 撤稿回溯
        M.rlg.revoke(k, reason=cex, via=M.cit)
    return out, M.sel.issue_certificate(out, M.gate)
```

## 4. 推导

**引理 19（支持边界）** 离 `supp(p_D)` 至少 r 的模态 m，`p_θ(m) ≤ ε_app + C·exp(−r²/2σ²)` ⇒ `m∈H(D)` 时 `U_epi(m)` 不可被交互消解。系：MCG 能防「过度自信」，覆盖才能防「无中生有」。

**引理 20（对比可辨识）** 无配对/干预时，存在观测似然相同、反事实行为相反的两个策略 ⇒ 关于 f 的对齐断言不可辨识。系：数据集构建必须干预式/配对式，堆量只买平均精度。

**引理 21（证据样本复杂度）** Clopper–Pearson：零失败需 `n ≥ lnα/ln(1−δ) ≈ (1/δ)ln(1/α)`。系：ODD 每扩一寸都有显式数据价格。

**引理 22（有效样本由血统决定）** `n_eff ≈ n/(1+(m̄−1)ρ)`。系：独立复现是唯一真正升权的证据，第三方审计非形式主义。

**引理 23（VoD 的缝定位）** 新样本边际价值 ∝ 它成为「当前最紧断言的反例」的概率。系：应采「最紧且证据最薄」的边界，而非平均精度；通用主动学习对安全对齐次优。

**引理 24（投毒/应试偏差）** 对手控制占比 β 且出处不透明时，名义 UCB 至少乐观 `β(1−δ)`；只有随机 vault 审计给出无偏下界。系：出处签名与随机审计是必需项，自采自证不构成证据。

**定理 18（严格包含 R69 且证据单调）** 加 P1（证据独立未污染）、P2（采集经认证）：数据封闭时与 R69 逐指令相同；允许采集时运行期保守度单调不增且不低于 R69 的 `λ_floor`；证据失效即回到 R69 最保守侧。

**定理 19（对齐即作用域）** 有限数据下可认证断言受引理 21 下界约束；要覆盖 R，要么证据达标，要么收缩 R 到可被见证的子域。故「全局已对齐」不可支持——**对齐是「模型 × 数据 × 作用域」的联合性质**。

**定理 20（撤销正确性与采集无突变）** 撤稿按 DAG 可达性传播，无证书能依赖已撤稿祖先仍有效；采集门控保证 `Σ risk(u) ≤ ε_data`；收缩单调 ⇒ 控制连续、无突然扩张，加强 R69 定理 17。

## 7. 本轮最大风险

**一句话**：SEAM-RAS 的整个安全论证都押在「账本证据独立且未被污染、sim2real 折扣准确」这一前提上——**一旦数据管道被俘获、偏好被投毒、仿真器把现实鸿沟伪装成零，系统就会用一张统计上严谨、前提上虚假的证书，在错误的地方扩张 ODD、在正确的地方收缩 ODD，把「不可证伪」包装成「已被证明」——用可证明的严谨掩盖不可证明的前提，比没有证书更危险。**

**次级风险与缓解**：采集本身不安全（定义 323 三级采集 + 风险预算 + 定理 20）；证据 Goodhart/应试（随机 vault 审计 + 证伪优先 + ℰ_cherry + 独立血统）；价值歧义被多数抹平（E312 保留分歧层并登记为未消解）；ODD 收缩诱发新漂移与过度信任（收缩连带调整交互提示 + 长时程监测）；数据飞轮自噬（VoD 锁最紧断言 + 强制探索配额 + 第三方复现）。
