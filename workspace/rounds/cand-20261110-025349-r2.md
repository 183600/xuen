# 第 41 轮 · 双灵感落地 v8：个性化证书画像 × 异常哨兵 × 反事实重协商（四层架构 v6）

> 承接第 40 轮（v17：可认证流匹配执行 × 度量语义几何锚定 × 证书驱动课程引擎，四层架构 v5）。本轮灵感词「异常检测、个性化交互」不指向新骨干，而指向 v17 证书体系的两个**主语缺口**：证书为「谁」而证？证书「何时已不成立」由谁监视？前者把群体证书推进为个性化契约，后者把离线承诺推进为 anytime-valid 的运行时哨兵；再以反事实审计给个性化装上刹车。四层架构 v6 只做增量。

**事实锚点（先于推理，2026-11-10 复核）**：UniBot-V1 是定基座桌面操作，官方评测观测为 4 路 RGB + 双臂本体状态 + 夹爪 + episode 语言，不提供 LiDAR/深度通道；排名以平均成功率为主、步骤分为平局裁决；必须单 checkpoint 覆盖 32 任务。故 v17 的 LiDAR-LIO/ESDF 在本赛道只作为可选后端；本轮哨兵只消费实际下发通道，个性化只通过同一 checkpoint 内的条件化实现，不引入第二模型。

## 0. 直觉与动机

**灵感 1（异常检测 → 证书的运行时哨兵，而不是又一个分类器）**：v17 把证书做成了离线可计算的承诺，但运行时只「消费」证书，不「监视」证书。分布漂移、物体替换、光照突变、接触异常、执行器退化，都会先以微小残差出现；等到失败发生，证书早已悄悄失效。朴素异常检测解决不了这个问题：它没有误报保证，而且「异常」与「证书失效」不是同一个量。关键转向是**把证书自身的边际做成异常统计量**：输入共形分数、流 ODE 残差、证书边际下降速率，三者各自构成 e-process；只要参考分布可交换，Ville 不等式就给出 anytime-valid 的误报控制（P(任一时刻误报) ≤ α）。于是异常检测从「找坏样本」变成「检测证书前提被破坏」，并天然给出**哪一条前提坏了**的诊断，触发对应的重协商而非一刀切熔断。

**灵感 2（个性化交互 → 证书的坐标系，而不是给每个用户训一个模型）**：v17 的证书是群体证书：在混合任务分布上一次性认证，对所有任务实例、物体、布局、交互偏好用同一套阈值和同一个采样步数。这在统计上「平均安全」，在个体上要么过度保守（拖慢步骤分），要么对某些个体失效（成功率掉）。个性化交互的正确翻译不是 per-user model（违反单模型规则），而是学一个低维画像 z（任务、物体、本体、可选偏好），把证书参数变成 z 的函数：N*(z)、margin(z)、韵律 s(z)、准入阈值(z)。但个性化必须**带不确定球**：只在 z 的邻域 B_ρ(z) 内同时成立，ρ 由共形校准与证书余量共同决定；否则就是把评测集逐 episode 背下来。

**灵感 3（耦合 → 画像定义「正常」，哨兵定义「何时重协商」，审计定义「不许偷降低标准」）**：个性化会改变「什么是正常」：同一动作对 A 画像正常，对 B 画像可能是异常。因此异常分数必须**按画像校准**，否则个性化越细，误报越多。反过来，异常检测给个性化提供了**更新触发**：只有当证据表明当前 z 失配（而非噪声）时才重协商，避免持续漂移。两者形成闭环，但闭环有一个致命陷阱——**自我正常化**：画像更新会吸收漂移，使异常哨兵永远检测不到分布变化；另一个陷阱是**奖励黑客**：对困难画像悄悄降低安全阈值，用成功率换分数。反事实审计（独立审计集 + placebo 画像交换 + 分组无伤害约束）是这两个陷阱的唯一刹车。

**一句话直觉**：v17 证明了「动作可证、几何可锚、课程可进化」；本轮补上「证书为谁而证、何时失效、如何不被个性化偷走」——异常检测是哨兵，个性化是坐标系，审计是刹车。

## 1. 形式化定义

**定义 27（个性化上下文与画像不确定球）**：画像 z = (z_task, z_obj, z_emb, z_user^opt) ∈ Z ⊂ R^d（d≤16），由同一 checkpoint 内的编码器 q_ψ(z | o_0, ℓ, f^opt) 推断，o_0 为首帧观测，ℓ 为 episode 语言，f^opt 为可选交互反馈（UniBot-V1 无此通道时退化为前两项）。定义画像度量 d_Z 与不确定球 B_ρ(z) = {z' ∈ Z : d_Z(z,z') ≤ ρ}。ρ 不是超参，而是由「画像推断误差分位 + 证书余量」联合校准的半径。

**定义 28（个性化证书 Cert_z 与鲁棒个性化）**：Cert_z = {θ(z), B_ρ(z), p_min, δ, S_budget}，θ(z) = (L_v(z), κ(z), ε_ode(z), N*(z), margin(z), s(z))。要求
- ∀z'∈B_ρ(z)：P(success | z') ≥ p_min 且 P(cert violation | z') ≤ δ；
- 目标：min_z E_{z~P}[steps(z) + λ·latency(z)]，且成功率不降（UniBot 成功率先行）。

**定理 8（鲁棒个性化余量）**：若群体证书余量为 m₀，画像到证书参数的映射 θ(·) 对 z 的 Lipschitz 常数为 L_θ，证书余量对参数的 Lipschitz 常数为 L_m，则 ∀z'∈B_ρ(z)，margin(z') ≥ m₀ − L_m L_θ ρ。故给定安全下限 m_min，可行个性化半径为 ρ* = (m₀ − m_min)/(L_m L_θ)；超过 ρ* 的个性化必须被裁剪或拒绝。个性化收益随 ρ 增大，但安全余量线性缩小——这把「个性化强度」变成一个可证的旋钮，而不是调参直觉。

**定义 29（证书异常分数与共形 e-process）**：在画像 z 的参考校准集上定义三层非一致性分数：
- s^in_t：输入层（图像/对象状态嵌入的 kNN 距离或重建残差）；
- s^ode_t：执行层（流 ODE 残差 ‖x_{t+1} − Φ_{N*}(x_t)‖）；
- s^m_t：证书层（边际向量 m_t 的归一化赤字 max_i (1 − m_{t,i}/c_i)）。
对每层用共形 p 值 p^j_t = (1 + #{校准分数 ≥ s^j_t})/(n+1)，构造 betting e-value e^j_t = (1/2)(p^j_t)^{-1/2}（非负且 ∫₀¹ e(u)du = 1），累积 E^j_t = ∏_{i≤t} e^j_i。**定理 9（anytime-valid 误报控制）**：在序列可交换且参考分布未变的零假设下，E^j_t 为非负测试鞅，Ville 不等式给出 P(∃t: E^j_t ≥ 1/α) ≤ α。多通道用 Bonferroni 把 α 分配到三层，或用 e-value 乘积/平均组合；告警时刻 τ_α = inf{t : max_j E^j_t ≥ 1/α}。与普通阈值相比，这个保证**不依赖异常分数分布**，也不要求固定视界。

**定义 30（异常触发重协商与状态机）**：状态 N（名义）→ S（可疑）→ R（重协商）→ F（安全回退）。告警时诊断 d 记录哪一层/哪条证书前提被破坏，动作集 A = {维持但加宽 margin、重估画像 z、重颁证书、降级到安全技能、请求澄清（若有通道）}。选择 a* = argmin_a E[risk(a) | d,z] + c(a)，满足安全约束与步骤预算；用滞回与冷却时间防抖。重协商证书记为 R = (τ_α, d, a, z_new, 有效期)，进入审计账本。

**定义 31（反事实个性化审计 C_audit）**：审计集 D_audit 必须与画像训练、共形校准、阈值调参**三重分离**。C_audit = (覆盖, 分组无伤害, placebo 通过, 画像敏感度)：
- 分组无伤害：∀组 g，R_g(θ(z)) ≤ R_g(θ_pop) + ε；
- placebo 画像交换：把同一任务的 z 随机换成 z_placebo，定义画像特异收益 G_spec = perf(z_true) − perf(z_placebo)；若标准评测提升但 G_spec ≤ 0，说明提升来自分布记忆而非画像，拒绝部署；
- 画像敏感度 S = ‖θ(z)−θ(z')‖/d_Z(z,z') 必须在合理区间：过高=过拟合，过低=个性化无效；
- 只有通过审计的画像映射才可进入 IP-45 路由；每次异常触发的重协商都要留下「个性化债务」记录，并在漂移后复审。

## 2. 三大产出设计

### 2.1 IP-51 PERSONA-CONTRACT（个性化契约画像）
1. 画像编码：语言 + 首帧 + 本体状态 → z（信息瓶颈压到 ≤16 维）；同一 checkpoint 内 FiLM/AdaLN 条件化，不新增模型。
2. 鲁棒条件化：θ(z) 的 Lipschitz 约束（复用 IP-48 的谱归一化 + 幂迭代工具），按定理 8 裁剪 ρ*；N*(z) 与 margin(z) 同步条件化，「个性化即证书参数重分配」。
3. 稀疏更新：只有证据量超过阈值且审计通过才更新 z；EWMA + 滞回，避免每帧漂移。
4. 预算感知：个性化收益必须覆盖其鲁棒性代价（ρ 增大→margin 缩小→可能触发更保守技能）；收益为负则退回群体证书。
5. 可选交互偏好：未来若有偏好通道，z_user 只允许在预定义安全锥内移动；UniBot-V1 无通道时 z_user 置零并显式标注。

### 2.2 IP-52 CERT-ANOMALY-SENTINEL（证书异常哨兵）
1. 三层分数（定义 29），按画像校准；校准集冻结，不随在线更新而漂移。
2. e-process + Ville 误报控制；多通道 Bonferroni/e-value 组合；输出诊断而非单一标量。
3. 告警联动：N→S→R→F 状态机（定义 30），接 IP-45 熔断与 IP-38 安全回退；重协商不静默改阈值。
4. 异常即课程：被判定为「真实能力边界」的异常轨迹进入 IP-50 回放池（高价值高难度样本）；被判定为「校准失配」的轨迹进入校准复审，不进入训练，防止污染。
5. 防自我正常化：画像更新与哨兵校准使用不同数据分片；任何画像更新后，旧校准集上的 e-process 必须重新过一遍「回溯告警测试」。

### 2.3 IP-53 COUNTERFACTUAL-PERSONA-AUDIT（反事实个性化审计）
1. 独立审计集与三重分离（定义 31）；审计集规模按 Hoeffding/Bennett 计算，保证分组风险上界。
2. 分组无伤害检验 + placebo 画像交换 + 画像敏感度带；不通过则回退群体证书。
3. 个性化债务账本：每次重协商记录「为什么改、改了什么、谁批准、何时复审」；漂移后按账本批量复审。
4. 对抗审计：主动构造「伪装画像」「奖励黑客画像」「漂移吸收画像」三类反例，作为 E77 的硬测试。

## 3. 四层架构 v6

```
L1: TRI-FUSE（4×RGB + 双臂本体 + 夹爪 + 语言）→ 对象/本体状态；IP-52 输入层共形分数
L2: CTC + VLM + IP-35 仲裁 → 任务画像 z_task/对象 z_obj；IP-51 画像编码器 → z（同 checkpoint）
L3: IP-47 任务代数（Cert_z 类型检查）→ IP-39 规划 → IP-45 总线（按 z 路由 + 哨兵熔断）
    → IP-48 认证流执行（N*(z)）+ IP-43 韵律（s(z)）→ RCA（Cert_z + E_t + 诊断 d）
L4: IP-44 蒸馏 + IP-50 课程（画像轴 + 异常回放）→ IP-53 反事实审计 → RCA 重颁 → 契约热更新
运行期：画像条件化 + 三层哨兵 + 重协商状态机 + 独立审计账本
```

## 5. 本轮最大风险

**一句话**：最大风险不是异常检测不准，而是个性化与哨兵形成「自我正常化」闭环——画像更新把漂移吸收成新常态，哨兵又用被污染的数据重新校准，最终证书在排行榜上更漂亮却悄悄失去可迁移性；因此独立审计集与「回溯告警测试」必须作为第一守门，E77 优先于 E76。

## 2. 关键算法

### IP-51 个性化契约（伪代码）
```
def personalize(z, theta_pop, m0, m_min, eps_tol):
    delta = persona_head(z)                      # FiLM/AdaLN, same checkpoint
    L_theta = lip_z(delta)                       # spectral norm + power iteration
    L_m     = lip_margin(theta_pop)              # reuse IP-48 certification
    rho_star = (m0 - m_min) / max(L_m * L_theta, tiny)
    B_rho = Ball(z, min(rho_star, rho_calibrated))
    theta = theta_pop + clip(delta, radius=L_theta * B_rho.radius)
    N_star = solve_steps(theta, eps_tol)         # v17 closed form
    return Cert_z(theta, B_rho, N_star)

def maybe_update_persona(evidence, cert, audit):
    if evidence.n_eff >= n_min and audit.passes(cert):
        z_new = ema(z_old, evidence.z_hat, alpha=alpha_z)
        if audit.retrospective_alarm_test(z_new) == PASS:
            return z_new
    return z_old                                  # 稀疏更新 + 审计门控
```

### IP-52 证书异常哨兵（伪代码）
```
def sentinel_step(o_t, x_t, m_t, z, calib, E_prev):
    s = [input_score(o_t, z),                  # kNN / reconstruction
         ode_residual(x_t, z),                 # ||x_{t+1} - Phi_N*(x_t)||
         margin_deficit(m_t, z)]               # max_i (1 - m_i/c_i)
    E = E_prev.copy()
    for j in range(3):
        p = (1 + count(calib[j] >= s[j])) / (len(calib[j]) + 1)
        E[j] *= 0.5 * p ** -0.5                # e-value, E[e] <= 1 under H0
    if max(E) >= 1 / alpha:                    # Ville: P(any false alarm) <= alpha
        d = argmax(E)                          # diagnosis: input / ODE / margin
        return Alarm(tau=t, d=d, E=E)
    return Nominal(E=E)

def renegotiate(alarm, z, budget):
    a_star = argmin_a expected_risk(a, alarm.d, z) + cost(a)
             s.t. safety_constraint(a) and steps(a) <= budget
    return transition(N, S, R, F; action=a_star)   # hysteresis + cooldown
```

def audit_persona(theta_z, z, D_audit, G):

## 3. 推导与正确性

**定理 8（鲁棒个性化余量）证明骨架**：margin(θ) 对 θ 为 L_m-Lipschitz，θ(z) 对 z 为 L_θ-Lipschitz，复合得 margin(z') ≥ margin(z) − L_m L_θ·d_Z(z,z') ≥ m₀ − L_m L_θ ρ。令其 ≥ m_min 即得 ρ*。**推论**：个性化收益随 ρ 增大，但安全余量线性下降；当 ρ→ρ* 时余量耗尽，必须停止个性化或增加群体余量 m₀。

**定理 9（anytime-valid 误报控制）证明骨架**：共形 p 值在可交换零假设下超均匀，P(p ≤ u) ≤ u；e(u)=(1/2)u^{-1/2} 非负且 ∫₀¹ e(u)du=1，故 E[e(p)] ≤ 1。逐层累积 E_t 为非负测试鞅，Ville 不等式给出 P(sup_t E_t ≥ 1/α) ≤ α。多层用 Bonferroni 分配 α/3 或用 e-value 乘积；该保证不依赖异常分数分布，也不要求固定测试视界。

**命题 10（审计无伤害的分组上界）**：若审计集对每组 g 有 n_g 个独立样本，风险取值于 [0,1]，则 Hoeffding 给出以概率 ≥1−η：R_g(θ) ≤ R̂_g(θ) + sqrt(log(1/η)/(2n_g))。只有当该上界对所有组均不超过 R_g(θ_pop)+ε 时，才允许部署个性化映射。

|---|---|---|

## 6. 风险与缓解

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 自我正常化：画像吸收漂移，哨兵失效 | 高 | 冻结校准集 + 独立审计集 + 每次更新做回溯告警测试；E77 第一守门 |
| 个性化过拟合评测分布 | 高 | ρ* 裁剪 + placebo 画像交换 + 分组无伤害 + 稀疏更新 |
| 误报导致重协商抖动 | 中 | e-process 的 anytime 保证 + 滞回 + 冷却 + 最小证据量 |
| 画像不可识别/未知画像 | 中 | 低维信息瓶颈 + unknown token + 回退群体证书 |
| 步骤分与成功率冲突 | 中 | 成功率先行硬约束；步骤分只在 p≥p_min 后优化 |
| 单模型合规 | 低 | 画像条件化在同一 checkpoint 内（FiLM/AdaLN），无 per-task 权重 |
| 通道诚实 | 低 | 哨兵只用实际下发通道；LiDAR/深度仅作可选后端，不作为主路径假设 |

## 7. 本轮最大风险

**一句话**：最大风险不是异常检测不准，而是个性化与哨兵形成「自我正常化」闭环——画像更新把漂移吸收成新常态，哨兵又用被污染的数据重新校准，最终证书在排行榜上更漂亮却悄悄失去可迁移性；因此独立审计集与「回溯告警测试」必须作为第一守门，E77 优先于 E76。
