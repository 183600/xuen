# 第 58 轮（承接第 57 轮「少样本×多模态×个性化」IP-133~138；灵感循环新篇第 1 轮；本轮灵感：「四足机器人」×「轻量化结构」）

> 第 57 轮把安全的赌注从"模型置信"换到"证据质量"，又用少样本元推断、跨模态对账、个性化信任把证据质量本身做成可校准、可对账、可问责的对象；但它仍默认一个从未被审视的前提：**取证的身体是一个抽象的、刚性的、恒定的点探针**。真实平台是四足机器人，且正被推向轻量化——腿会弯、质量会随载荷与电池变化、关节会磨损、结构模态会与地形模态混叠。于是第 57 轮的"模态"只覆盖了外部传感器，漏掉了最贴近接触的那一个模态：**本体**。本轮把"本体"提升为一等证据源，同时把它当作最可疑的证人：先让本体自证（结构自辨识与证据溯源），再让它作证（三足支撑下的全身载荷重分布探针、步态-阻抗多样性证据），最后用质量-证据预算约束"能问多大力、能问多久、问完能否撤得回来"。核心命题由"少样本可校准、跨模态可对账、个性化有界的证据说可信"升级为 **"本体可自证、载荷可预算、步态可对账的证据说可信"**。

核心矛盾：
- **H29（本体漂移 vs 证据可比）**：轻量化结构的刚度、惯量、关节间隙随载荷、温度、磨损而变；同一地形在不同本体状态下产生不同本体信号。若不显式建模，"地形信念"会悄悄变成"身体信念"，跨到访证据不可比——这是比第 57 轮"单模态共谋"更隐蔽的共谋：**身体与地形一起骗传感器**。
- **H30（四足耦合 vs 单足独立）**：足点决策通过载荷分配与支撑多边形强耦合；单足证据在数学上欠定全身安全。把四条腿当四个独立证人，既可能因共享本体而"同错"，也可能因忽略载荷转移而漏掉弱支撑。
- **H31（轻量 vs 探针权限）**：减重降低冲击能量（更安全），却也降低法向力权限、接触信噪比与结构刚度（更看不清、更问不动）。固定的探针预算与"探得到=探得准"假设在轻量化平台上同时失效；探针能力本身必须是本体状态与载荷的函数。

## 0. 直觉与动机

**灵感 1（四足机器人 → 三足支撑 + 一足探针的"静态触诊"）**
直觉：四足最被低估的能力不是走得快，而是**总有一条腿可以空出来做实验**。三条腿构成支撑三角形，第四条腿在质心仍位于安全多边形内的前提下，对候选足点施加可控法向力、缓慢转移质心、观察四条腿的地面反力如何重新分配——像医生用三指固定、一指按压。轮式与双足都难以同时做到"静态稳定"与"单点可控加载"；四足天然具备这种**分布式接触阵列 + 冗余支撑**。这把第 57 轮的"探针"从一个抽象动作变成一个有几何、有力学、有支撑约束的实验设计问题。

**灵感 2（轻量化结构 → 本体是可变、可弯、可损的"软传感器"）**
直觉：轻量化不是简单地"把质量调小"，而是把结构做得更薄、更拓扑、更接近其强度极限——于是本体成为一个会随载荷弯曲、会随温度漂移、会随疲劳损伤的传感器。它既提供最贴近接触的信息（关节力矩、腿部形变、IMU、足端沉陷），也引入最大的混淆：**你测到的柔顺，可能来自地形，也可能来自你自己的腿**。因此本轮先要求"本体自证"：在线辨识质量/质心/惯量/关节刚度阻尼/腿健康，并给每条证据打上"取证时的身体版本"；身体版本一变，旧证据立即隔离，而不是继续参与跨到访融合。

**灵感 3（轻量化 vs 可探测性 → "轻量悖论"与比刚度约束）**
直觉：更轻的机器人撞上弱支撑时冲击更小，这是安全收益；但更轻也意味着法向力更小、结构更软，可能**压不出弱支撑的屈服**，也分不清"地形软"与"腿软"。定义支撑 interrogation 能力 C_sup∝m g：当弱支撑的屈服载荷高于 C_sup 时，探针进入"盲带"——它能说"我没压坏"，却不能说"它足够强"。更反直觉的是，串联柔度会把地形刚度信号按 (k_s/(k_s+k_t))² 衰减：**轻量化若以牺牲结构比刚度为代价，会直接摧毁地形可观测性**。所以正确的设计目标不是最小质量，而是"在质量约束下最大化安全×证据质量"的比刚度前沿。

**灵感 4（四足步态 → 步态/阻抗多样性作为主动感知）**
直觉：同一地形在 walk/trot/pace、不同支撑时长、不同虚拟阻抗下会被"问"出不同的模态响应。单一步态像单模态：它可能恰好落在结构共振或传感器盲区。让机器人在**非不可逆层**用两种控制条件各问一次，比较地形参数估计是否一致——一致是证据，分歧是警报。但必须先把结构模态从地形模态中分离出去（双激励方向 + 模态矩阵条件数），否则"跨步态一致"只是"同一个身体错误问了两次"。

**灵感 5（合流 → 证据门扩为七类、证书 J_q、PCE++）**
直觉：第 57 轮的 EV-probe*/visit/margin/xmodal/human 在本轮获得"本体维度"：所有证据先过**溯源匹配**与**本体证书**；新增 **EV-load±**（载荷重分布）与 **EV-gait**（步态多样性），但二者都只限非不可逆层，且 EV-load 的正证据受 C_sup 截断、负证据永远可用。不可逆接触的必要证据集仍是 {EV-probe*∨EV-margin}，只是当候选属弱支撑风险类时额外要求 EV-load⁺ 或等效外部佐证。击穿安全需要：本体自证错 ∧ 溯源误配 ∧ 载荷探针落在盲带 ∧ 步态一致性假 ∧ 无裕度 ∧ 人也错——纵深从五层到六层。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（本体状态与结构自辨识 SSI）** 本体状态 β=(m_b,c_b,I_b,K_leg,B_leg,h_leg,p)，其中 h_leg=(h_1..h_4) 为腿健康等级，p 为载荷。自辨识器 q_ψ(β|τ_{1:t},a_{1:t},p) 由激励轨迹训练；本体证书 BCE 声明 P(‖β̂−β‖_W≤δ_β)≥1−ε_β，并显式绑定参数版本 v_β 与健康版本 h。定义本体归一化观测 ô=T_{β̂,g}(o) 与不变性误差 ε_inv(β̂,g)=sup_{θ_r} d(p(ô|θ_r,β̂,g),p(ô|θ_r,β,g))。每条证据携带溯源元组 π_e=(L_e,g_e,p_e,v_β,h_e,τ_e)。证据可跨到访合并 ⇔ π_e~_π π_now（声明等价类：同腿集、同步态类、载荷差≤p_tol、同 v_β/h）或经 T 校正且 ε_inv≤ε_inv^max；否则隔离。结构漂移检测用残差 CUSUM：r_t=τ_meas−τ_model(β̂)，若超阈则 v_β++，并**回溯隔离**所有旧版本证据（第 57 轮事后证伪的"本体版"）。

**定义 140（全身载荷重分布探针 WLR）** 候选足点 f，三足支撑集 L_s（|L_s|=3），质心准静态路径 c(u)，观测地面反力 λ(t)∈R^4 与足端沉陷 z_f(t)。定义载荷灵敏度 S_f=∂λ_f/∂c、支撑刚度 k_f^sup、屈服载荷 F_f^y=inf{F: ∂²λ_f/∂c² 超阈}。安全载荷转移包络 𝒰_safe(f,β,p)={c(u): c(u)∈P_supp⊖B(η), |λ_i|≤λ_max, λ_i∈摩擦锥, z_f≤z_max, 捕获点 ξ∈𝒮_rec}。支撑 interrogation 能力 C_sup(f)=max_{u∈𝒰_safe} λ_f(u)≈α(η,μ,a_max)·m g。证据二值化且**不对称**：观测到 F_f^y≤C_sup ⇒ EV-load⁻（弱支撑，强负证据，永远可用且只会使动作更保守）；未观测到屈服 ⇒ 仅声明 EV-load⁺(C_sup)（"在 C_sup 内未压坏"），若需求载荷 F_need+p·g > C_sup 则判为**盲带**、不得当作强支撑证据。EV-load 仅限 L1，力上限 F_cap(β,p)，且不得单独授权不可逆接触。

**定义 141（步态-阻抗多样性证据 GDE）** 控制条件 x=(g,ζ,τ_st,u_exc)（步态、虚拟阻抗、支撑时长、激励方向）；在固定 β̂ 下由观测 o_x 得地形参数估计 θ̂_x。条件间一致性 R_gait=max_{x≠x'} d(θ̂_x,θ̂_{x'})。结构模态可分性：由双激励方向辨识模态矩阵 Φ，要求 κ(Φ)≤κ_max，且各条件共享同一 v_β/h（否则不算"同体对照"）。EV-gait ⇔ R_gait≤θ_gait ∧ κ(Φ)≤κ_max ∧ BCE 有效 ∧ 接触等级∈{L0,L1}；可在 L1 替代一次佐证，但**不得与 EV-xmodal 叠加**计为两次（防重复计数），且不得进入不可逆接触必要证据集。

**定义 142（质量-证据预算 MEB 与轻量化悖论）** 探针权限 A_probe(β,p)=max{F_probe≤F_cap(β,p): 加载过程满足 𝒰_safe，且撤力后 ξ∈𝒮_rec}；撤力恢复时间 τ_rec(m,I,μ,p)。证据预算满足 k_p·e_p+e_WLR+e_gait≤E_batt，且每次承诺前须有卸载逃逸计划 τ_esc≤τ_rec。质量-证据前沿 ℱ_m={(m,J_T(m),Safety(m))}，J_T 为地形参数 Fisher 信息。**命题（轻量悖论）**：串联柔度下可测刚度 k_m=(1/k_t+1/k_s)⁻¹，地形灵敏度 s=∂k_m/∂k_t=(k_s/(k_s+k_t))² 随结构刚度 k_s 单调增；故"减重若同时降 k_s"会压低地形可观测性。设计证书 OLD 要求 max_design U=w_s·Safety(m)+w_e·logdet J_T−w_m·m，s.t. m≤m_budget、k_s/m≥ρ_stiff^min、σ_max≤σ_yield——**轻量化≠软化，正确目标是比刚度而非最小质量**。

**定义 143（本体证据门 EEG 与证书 J_q）** 证据类扩为 {EV-probe*, EV-visit, EV-margin, EV-xmodal, EV-human, EV-load±, EV-gait}。规则：(R0 溯源) 所有证据须 π_e~_π π_now 且 BCE 有效，否则隔离而非仅拒绝；(R1 本体先行) BCE 失效时禁用本体归一化，退回"未归一化 + 更宽区间 + 更低步态"的保守路径；(R2 载荷不对称) EV-load⁻ 永远可用且只导向绕行/降档，EV-load⁺ 仅在 F_need≤C_sup 时可用，盲带一律判 unknown；(R3 步态受限) EV-gait 仅 L0/L1、结构模态可分、不得与 EV-xmodal 叠加；(R4 不可逆) 必要证据={EV-probe*∨EV-margin}（候选属弱支撑风险类时 ∧ (EV-load⁺∨外部佐证)）∪佐证，EV-xmodal/EV-gait/EV-load 均不得单独进入；(R5 逃逸) 承诺须有 τ_esc≤τ_rec(β,p) 的卸载计划。J_q 在 J_p 上增 body_cal_log、provenance_log、wlr_log、gait_log、health_log、mass_log。

**定义 144（探-诺-演++ 算子 PCE++）** 每会话先做本体自证；每检查点：①元推断（ID→摊销后验/OOD→共形带）；②跨模态对账；③若候选属弱支撑风险类→在 𝒰_safe 内做 WLR：EV-load⁻→直接绕行/降档，盲带→标 unknown 并强制 EV-probe*/margin/外部佐证；④仅 L0/L1 且预算/稳定性允许时做两次控制条件的 GDE；⑤承诺 ⇔ R≤δ_f ∧ EEG 过 ∧ 逃逸计划成立；否则 argmax_π[VOI_本体悲观(π)−cost(π)]；探尽→绕行→降档→按 auth 的 L2 协商或安全停。VOI 的 cost 含能量与结构磨损，gain 含对本体参数与地形参数的联合信息增益。

## 2. 关键算法伪代码（完整版见产物区）

```python
def body_self_id(proprio, payload, health):            # IP-139
    beta = q_psi(proprio, payload)                     # m,c,I,K,B
    if cusum(residual(proprio, beta)) > theta_beta:    # 结构漂移
        health.bump(); quarantine_old_evidence(health) # 旧证据回溯隔离
        return beta, Cert(valid=False)
    return beta, bce(beta, proprio, version=health.version)

def wlr_probe(M, r, f, beta, p):                       # IP-140
    Ls = support_triangle(r, f)
    U = safe_load_shift_envelope(beta, p, Ls, eta)     # 含摩擦锥/捕获点
    if U.empty: return LoadResult('infeasible')
    lam, z = execute_quasi_static(design_shift(U, f), cap=F_cap(beta, p))
    Fy = fit_yield(lam); Csup = alpha(beta, p) * beta.m * g
    return LoadResult('weak', Fy) if Fy <= Csup else LoadResult('npw', Csup, blind=True)

def gait_diversity(M, r, beta, conds):                 # IP-141
    est = {x: terrain_est(execute_gait_condition(x), T(beta, x)) for x in conds[:2]}
    if modal_condition(Phi) > kappa_max: return None
    return 'EV-gait' if max_pairwise_dist(est) <= theta_gait else None
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| SSI | O(d_ψ)/次；CUSUM O(1) | O(H_body) | BCE 诚实、漂移即隔离（A41） |
| WLR | O(q·\|L\|·d_λ) | O(q·\|L\|) | 𝒰_safe 内、F≤F_cap、盲带不冒充正证据（A42） |
| GDE | O(2·d_φ+特征分解) | O(\|𝒢\|·d_b) | 同体对照、κ(Φ)≤κ_max、仅 L0/L1（A43） |
| MEB | O(1)/次评估；离线前沿 | O(\|𝒟_design\|) | 比刚度下界、逃逸计划（A44） |
| EEG | O(\|σ\|) | O(\|σ\|) | 溯源先于证据、负证据单调 |
| PCE++ | O(\|CP\|·(k_p+k_c+q+2)·(C_VOI+d_φ)+\|CP\|·A*) | O(\|V\|+\|σ\|) | 盲带终止、k_p+k_c+q+2 有界 |

**正确性定理（EPCS 概要）**：在 A33–A40 上加 (A41) 本体证书 P(‖β̂−β‖≤δ_β)≥1−ε_β、漂移检测与回溯隔离诚实；(A42) WLR 始终在 𝒰_safe 内、力不超 F_cap、C_sup 声明诚实且盲带不产生正证据；(A43) GDE 同体对照、结构模态可分 κ(Φ)≤κ_max、仅 L0/L1；(A44) 探针权限与逃逸计划声明诚实、τ_esc≤τ_rec。则：(i) 本体归一化证据误差 ≤ε_β+ε_inv+ε_meta+ε_h；(ii) **负证据单调性**：EV-load⁻ 与溯源失配只能缩小承诺集，不能扩大；(iii) **正证据有界性**：EV-load⁺ 的作用上限为 C_sup，超出即 unknown；(iv) 交互单调性保持：本体机制只经"信念更准（含加宽）"或"动作更保守"影响系统；(v) PCE++ 在 k_p+k_c+q+2 内终止。部署界在联合界中新增 ε_β+ε_inv+ε_load+ε_gait+δ_blind。

## 6. 本轮最大风险

def body_self_id(proprio, payload, health, meta_body):
    beta = q_psi(proprio, payload)                  # m,c,I,K,B

    if cusum(r) > theta_beta:                       # 本体漂移/损伤

### IP-140 WLR（全身载荷重分布探针，含盲带）

```python
def wlr_probe(M, r, f, beta, payload):
    Ls = support_triangle(r, f)                      # 三足支撑，|Ls|=3
    U  = safe_load_shift_envelope(beta, payload, Ls, eta, mu)
    if U.empty:                                      # 不安全/无法加载
        return LoadResult('infeasible')
    c_path = design_shift(U, f)                      # 准静态质心转移
    lam, z = execute_quasi_static(c_path, cap=F_cap(beta, payload))
    if abort_condition(lam, z, U):                   # 倾斜/打滑/沉陷超限
        return LoadResult('aborted')
    S  = fit_sensitivity(lam, c_path)
    Fy = fit_yield(lam, c_path)                      # 线性-屈服拐点
    Csup = alpha(eta, mu, a_max) * beta.m * g        # 能力上限
    if Fy is not None and Fy <= Csup:
        return LoadResult('weak', Fy=Fy, S=S, cert='EV-load-')
    need = F_need(current_gait(), payload)
    if need > Csup:
        return LoadResult('npw_blind', Csup=Csup, S=S)  # 盲带：只报 unknown
    return LoadResult('npw', Csup=Csup, S=S, cert='EV-load+')  # 能力内未压坏
```

**设计要点**：`EV-load⁻` 是强负证据（观测到低载荷屈服），任何情况下都只能触发绕行/降档/更强探针；`EV-load⁺` 只声明"在 C_sup 内未压坏"，当需求载荷超过 C_sup 时必须返回盲带而不是"通过"。

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SSI | O(d_ψ)/次 + O(1) CUSUM | O(H_body) | BCE 诚实、漂移即隔离、激励不足不声明（A41） |
| WLR | O(q·\|L\|·d_λ + T_shift) | O(q·\|L\|) | 𝒰_safe 内、F≤F_cap、盲带不冒充正证据（A42） |
| GDE | O(2·d_φ + d_Φ³) | O(\|𝒢\|·d_b) | 同体对照、κ(Φ)≤κ_max、仅 L0/L1（A43） |
| MEB | O(1)/候选；离线前沿 O(\|𝒟_d\|·d_ψ) | O(\|𝒟_d\|) | 探针权限/逃逸时间声明诚实（A44） |
| EEG | O(\|σ\|) | O(\|σ\|) | 溯源先行、负证据单调、正证据截断 |
| PCE++ | O(\|CP\|·(k_p+k_c+q+2)·(C_VOI+d_φ)+\|CP\|·A*) | O(\|V\|+\|σ\|) | 盲带终止、每检查点 WLR≤q、GDE≤2 |

**正确性定理（Embodied-Provenance Calibrated Soundness, EPCS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 本体证书：P(‖β̂−β‖_W≤δ_β)≥1−ε_β，激励不足/漂移时不声明有效，回溯隔离完整；**(A42)** WLR 安全：所有加载在 𝒰_safe 内、力不超 F_cap、C_sup 与盲带声明诚实、观测误差 ≤δ_load；**(A43)** GDE：两条件同体对照（同 v_β/h）、结构模态可分 κ(Φ)≤κ_max、仅 L0/L1、ρ_m 与证据类不重复计数；**(A44)** 质量-证据预算：A_probe 与 τ_rec 声明诚实，承诺满足 τ_esc≤τ_rec。则：

1. **本体归一化健全性**：合并后的地形信念误差 ≤ ε_β+ε_inv+ε_meta(k)+ε_h(w_max)+δ_probe；溯源失配的证据被隔离而非误用。
2. **负证据单调性**：EV-load⁻、漂移隔离、盲带判 unknown 三种操作只能缩小承诺集/增加保守动作，不能扩大；因此不会引入新的升险路径。
3. **正证据有界性**：EV-load⁺ 的效力上界为 C_sup；当 F_need>C_sup 时强制 unknown，须由 EV-probe*/EV-margin/外部佐证补足。
4. **交互单调性**：SSI/WLR/GDE/MEB 只经 (a) 更准/更宽的本体归一化信念，或 (b) 更保守的动作参数（降步态、绕行、外呼、τ_int↓）影响系统。
5. **终止性**：每检查点 WLR≤q 次质心转移、GDE≤2 个控制条件，PCE++ 在 k_p+k_c+q+2 内有界终止于 {承诺, 绕行, L2 协商, 安全停}。
6. **部署界**（检查点联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1]
                   + ε_β + ε_inv + δ_load·1[WLR] + δ_gait·1[GDE] + δ_blind)
             − P(𝓜 陈旧未检出) − P(护盾回退失败) − P(τ_int∧τ_mm 超时∧安全停失效)
```

**两条可检验命题（轻量化的证据代价）**：

- **命题 1（轻量悖论）**：串联柔度下 s=(k_s/(k_s+k_t))²。若减重使 k_s 下降，则即使质量下降带来冲击能量 ½m_eff v² 降低，地形刚度可观测性也按平方衰减。因此"软超轻"平台在 E180 中应显著劣于"拓扑优化刚性轻"平台；设计必须约束比刚度 k_s/m。
- **命题 2（探测盲带）**：C_sup≈α(η,μ,a_max)·m g，故减重会线性压缩可 interrogation 的支撑强度上限。对屈服强度 >C_sup 的弱平台，WLR 只能给 unknown；轻平台必须依赖外部佐证，或接受更大的绕行率。

**预期结果解释**：E180 是本文的"设计层判决实验"——它检验的不是某个算法模块，而是"轻量化必须同时轻且刚"这一跨学科命题。若刚性轻平台不能在 J_T 上显著优于软超轻，则命题 1 被证伪，本轮的核心设计约束需要重写。

## 6. 本轮最大风险

**一句话**：本轮把"本体"提升为证据源，最大风险从"坏先验普遍"变为"**本体自证错误 + 溯源洗白**"——若结构自辨识把载荷/磨损造成的本体漂移误判为地形差异，provenance 归一化会把系统性错误包装成"跨步态一致"，而轻量化又同时削弱力权限与刚度可观测性、使 WLR 更容易落入盲带；必须以安全载荷转移包络、本体证书失效即隔离、EV-load/EV-gait 仅限非不可逆接触三重护栏，宁可承认"我不知道我的身体"，也不把本体状态当成地形证据。
