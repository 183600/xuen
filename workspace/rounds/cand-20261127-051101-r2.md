### 第 2 轮灵感驱动研究记录

**灵感词**：因果推理、通信延迟

**直觉与动机**：
v24 的 USMC 把「结构-力控-轻量化」纳入证书链，但其证据默认「同刻、同源、可信」。真实云边系统中证据总是滞后的：云端版本一致性承诺、conformal 覆盖、结构损伤告警都经带延迟的信道抵达。延迟不只是时间偏移——它与网络拥塞、传感器降采样、时钟漂移共同构成混杂，使「观测到相关」不等于「因果上成立的安全谓词」。受「因果推理」启发，证书不应只证明「证据越过阈值」，而应证明「该证据在给定延迟下仍是安全谓词的因果有效代理」；受「通信延迟」启发，延迟本身应成为证书的显式预算项，而非事后补偿。核心洞见：**安全证书的效力 = 因果可识别性 × 时延可界性；延迟是证书的消耗项，因果是证书的兑换率**。

**形式化目标**：
1. 定义因果延迟证书（CDC）：在结构因果模型 M 下，延迟证据 e_{t-τ} 对安全谓词 φ_t 的因果间隙 Δ_τ(φ) 可识别且有界（Δ_τ ≤ ε_c）。
2. 定义因果证据搬运（CET）：用 do-calculus 与后门调整把 e_{t-τ} 反事实搬运到 t，并给出搬运误差界 ε_model(τ)。
3. 定义时序证书（TC）：延迟 τ、抖动 J、陈旧度 s、丢包率 ℓ 与截止期 d 的硬约束，构成证书的时延预算。
4. 构建因果-时序准入门（CTCG）：USMC ∪ CDC ∪ CET ∪ TC 五证一体，Exec_v25 ⊆ Exec_v24。
5. 证明「延迟超限 / 因果不可识别 / 搬运误差超界」三条退化路径下的单调退化链，并定义边缘回退（edge-only）与安全停（safe-stop）两级兜底。

**一句话最大风险**：若延迟与隐藏网络变量共同造成未观测混杂，而 CDC 的「无隐藏混杂 + 马尔可夫/忠实性」假设恰在此失效，则 Δ_τ 会被系统性低估，CTCG 会在因果证据已失效时仍然放行。

# ============================================================
# IP-444 Causal Delay Certificate (CDC) — 因果延迟证书
# ============================================================
@dataclass
class CausalDelayCertificate:
    """延迟证据对安全谓词的因果有效性证书"""
    scm: 'StructuralCausalModel'          # 延迟增广 SCM（含 τ, C 节点）
    adjustment_set: list[str]             # 后门调整集 Z（可观测 QoS）
    treatment: str = "A"
    outcome: str = "phi"
    epsilon_c: float = 0.05               # 允许因果间隙
    gamma_sens: float = 1.0               # Γ-敏感性参数（1=无未观测混杂）
    L_phi: float = 1.0                    # 谓词 Lipschitz 常数

    def verify_identifiability(self) -> bool:
        """后门准则 + s-admissibility：延迟证据是否可识别"""
        if not self.scm.is_acyclic():
            return False
        if not self.scm.backdoor_criterion(
                self.adjustment_set, self.treatment, self.outcome):
            return False
        # 延迟选择节点 S_τ 必须被 Z 阻断（transportability）
        return self.scm.s_admissible(self.adjustment_set, "S_tau")

    def unidentifiable_bound(self) -> float:
        """不可识别时的 Γ-敏感性上界；Γ=1 表示可忽略"""
        if self.verify_identifiability():
            return 0.0
        # Rosenbaum 型界：未观测混杂强度 Γ 放大观测优势比
        return (self.gamma_sens - 1.0) / (self.gamma_sens + 1.0)

    def causal_gap_bound(self, tau: float, r_tau: float,
                         eps_model: float) -> float:
        """Δ_τ(φ) ≤ L_φ·r(τ) + ε_model(τ) + δ_unident"""
        return (self.L_phi * r_tau + eps_model
                + self.unidentifiable_bound())

    def verify_gap(self, tau: float, r_tau: float,
                   eps_model: float) -> bool:
        return self.causal_gap_bound(tau, r_tau, eps_model) <= self.epsilon_c

    def adjusted_effect(self, a, e_delayed) -> float:
        """g-formula：P(φ | do(a), e_{t-τ}) = Σ_z P(φ | a, e, z) P(z)"""
        total = 0.0
        for z, pz in self.scm.prior(self.adjustment_set).items():
            total += self.scm.conditional(self.outcome,
                                          {self.treatment: a,
                                           "E": e_delayed, **z}) * pz
        return total


# ============================================================
# IP-445 Causal Evidence Transport (CET) — 因果证据搬运
# ============================================================
@dataclass
class CausalEvidenceTransport:
    """把延迟证据反事实搬运到当前时刻，并给出误差界"""
    scm: 'StructuralCausalModel'
    dynamics_lipschitz: float = 1.0       # L_x
    evidence_lipschitz: float = 1.0       # L_E
    contraction_rate: float = 0.0         # λ（>0 收缩）
    disturbance_bound: float = 0.0        # w̄
    r0: float = 0.0                       # 初始估计误差

    def error_radius(self, tau: float) -> float:
        """收缩动力学下的延迟误差半径 r(τ)，关于 τ 单调不减"""
        lam = self.contraction_rate
        if lam <= 1e-9:
            return self.r0 + self.disturbance_bound * tau
        decay = math.exp(-lam * tau)
        return decay * self.r0 + (self.disturbance_bound / lam) * (1 - decay)

    def model_error(self, tau: float) -> float:
        """ε_model(τ) = L_E·τ + O(τ²)，二阶项用 0.5·L_E²·τ² 保守估计"""
        return self.evidence_lipschitz * tau + 0.5 * self.evidence_lipschitz**2 * tau**2

    def transport(self, e_delayed, tau: float):
        """沿 SCM 结构方程前推 τ 步（do-calculus 的干预式前向模拟）"""
        e_hat = e_delayed
        for _ in range(max(1, int(math.ceil(tau)))):
            e_hat = self.scm.evolve_evidence(e_hat)
        return e_hat

    def counterfactual_margin(self, x_hat, tau: float):
        """搬运后状态的可信域半径"""
        return self.error_radius(tau) + self.model_error(tau)

# IP-446 Timing Certificate (TC) — 时序证书
# ============================================================
@dataclass
class TimingCertificate:
    """延迟/抖动/陈旧度/丢包/截止期的硬预算证书"""
    tau_max: float
    jitter_max: float
    loss_max: float
    deadline: float
    window: int = 100

    def __post_init__(self):
        self.tau_hist: deque = deque(maxlen=self.window)
        self.arrive_hist: deque = deque(maxlen=self.window)
        self.loss_hist: deque = deque(maxlen=self.window)

    def observe(self, tau: float, arrive: float, lost: bool):
        self.tau_hist.append(tau)
        self.arrive_hist.append(arrive)
        self.loss_hist.append(1.0 if lost else 0.0)

    def stats(self) -> dict:
        tau = float(np.max(self.tau_hist)) if self.tau_hist else math.inf
        jit = (float(np.max(self.tau_hist) - np.min(self.tau_hist))
               if self.tau_hist else math.inf)
        loss = float(np.mean(self.loss_hist)) if self.loss_hist else 1.0
        return {"tau": tau, "jitter": jit, "loss": loss}

    def verify(self, now: float) -> tuple[bool, float]:
        """返回 (是否通过, 时延预算余量 b_t)"""
        st = self.stats()
        staleness = now - (self.arrive_hist[-1] if self.arrive_hist else now)
        ok = (st["tau"] <= self.tau_max
              and st["jitter"] <= self.jitter_max
              and st["loss"] <= self.loss_max
              and staleness <= self.deadline)
        return ok, self.tau_max - st["tau"]

# IP-447 CTCG 因果-时序统一准入门
# ============================================================
class FallbackMode(Enum):
    FULL = "full"            # 五证齐备
    EDGE_ONLY = "edge_only"  # 丢弃云端证据，仅边缘本地证书
    SAFE_STOP = "safe_stop"  # 无法保证因果有效性，安全停

@dataclass
class CausalTemporalCertificateGate:
    usmc: 'UnifiedStructuralMechanicalCertificate'
    cdc: CausalDelayCertificate
    cet: CausalEvidenceTransport
    tc: TimingCertificate
    margin_req: float = 0.0

    def admits(self, plan, x, v, z, E_res, modules,
               F_hist, v_hist, volume, rho_solid,
               margin_t: float, now: float) -> tuple[bool, FallbackMode]:
        # 1. 结构-力学-能量-合规基础四证（v24）
        if not self.usmc.admits(plan, x, v, z, E_res,
                                self.margin_req, modules):
            return False, FallbackMode.SAFE_STOP

        # 2. 时序证书：延迟超预算 → 边缘回退
        timing_ok, b_t = self.tc.verify(now)
        if not timing_ok:
            return self._edge_only_admits(plan, x, v, z, E_res,
                                          modules), FallbackMode.EDGE_ONLY

        # 3. 因果可识别性：不可识别则用敏感性上界；超界 → 拒证
        st = self.tc.stats()
        tau = st["tau"]
        if not self.cdc.verify_identifiability():
            if self.cdc.unidentifiable_bound() > self.cdc.epsilon_c:
                return False, FallbackMode.SAFE_STOP

        # 4. 搬运误差 + 因果间隙合成
        r_tau = self.cet.error_radius(tau)
        eps_model = self.cet.model_error(tau)
        delta = self.cdc.causal_gap_bound(tau, r_tau, eps_model)

        # 5. 因果-时序安全裕度：m_t > margin_req + Δ_τ + r(τ)
        if margin_t <= self.margin_req + delta + r_tau:
            return False, FallbackMode.SAFE_STOP

        return True, FallbackMode.FULL

    def _edge_only_admits(self, plan, x, v, z, E_res, modules) -> bool:
        """延迟超限时丢弃云端证据，只保留本地可验证证书"""
        local_modules = [m for m in modules if m not in ("cesc", "fsvc")]
        return self.usmc.admits(plan, x, v, z, E_res,
                                self.margin_req, local_modules)

## 3. 正确性论证（增量）

### 定义 1（延迟增广 SCM 与安全谓词）
延迟增广 SCM 为 M = (U, V, F)，V = X ∪ A ∪ E ∪ Y ∪ {τ, C}，结构方程：
- X_{t+1} = f_X(X_t, A_t, U_X)
- τ_t = f_τ(C_t, U_τ)，E_t = f_E(X_t, τ_t, C_t, U_E)（C_t 为潜在拥塞混杂）
- φ_t = 1[X_t ∈ S_safe]，m_t = dist(X_t, ∂S_safe)

**直觉**：C_t 同时驱动延迟与证据质量，是「延迟—证据」相关性的混杂源；不调整 C_t（或其可观测代理 Z）就无法把 e_{t-τ} 当作 φ_t 的因果证据。

### 定义 2（因果间隙）
Δ_τ(φ) := sup_{a∈A} d_TV( P(φ_t | do(a), e_{t-τ}), P(φ_t | do(a), e_t) )，其中 d_TV 为总变差距离。

### 定义 3（可识别性）
若 Z 在延迟增广 DAG 中满足 (A, φ) 的后门准则，且对选择节点 S_τ 满足 s-admissibility，则 P(φ_t | do(a), e_{t-τ}) 可识别；否则以 Γ-敏感性上界 δ_unident(Γ) = (Γ-1)/(Γ+1) 替代。

### 定义 4（因果-时序安全裕度）
计划 π 在 t 时刻满足 CTCG，当且仅当 m_t > margin_req + Δ_τ(φ) + r(τ)，且 TC 的 τ、J、s、ℓ 全部在预算内。

### 引理 9（延迟误差半径的单调性）
**陈述**：CET.error_radius(τ) 关于 τ 单调不减，且 r(0)=r_0；在收缩动力学（λ>0）下有 r(τ) ≤ r_0 e^{-λτ} + (w̄/λ)(1-e^{-λτ}) ≤ max(r_0, w̄/λ)。

**证明**：对 d r/dτ = -λ r_0 e^{-λτ} + w̄ e^{-λτ} = e^{-λτ}(w̄ - λ r_0)，当 r_0 ≤ w̄/λ 时导数 ≥0，单调不减；λ≤0 时 r(τ)=r_0+w̄τ 显然单调。极限由 e^{-λτ}→0 得。∎

### 引理 10（因果间隙的分解上界）
**陈述**：若 φ 关于状态 L_φ-Lipschitz、搬运估计满足 ‖X_t - X̂_{t|t-τ}‖ ≤ r(τ)，且 SCM 模型误差 ≤ ε_model(τ)，则
Δ_τ(φ) ≤ L_φ·r(τ) + ε_model(τ) + δ_unident。

**证明**：由三角不等式，‖X_t - X̂‖ ≤ r(τ)+ε_model(τ) 的偏差经 L_φ-Lipschitz 谓词放大至 L_φ(r+ε_model)；未观测混杂对干预分布的扰动由 Γ-敏感性界 δ_unident 控制。总变差不超过各扰动项之和（d_TV 的三角不等式）。∎

### 引理 11（时序证书蕴含陈旧度上界）
**陈述**：若 TC.verify(now)=True，则 s_t ≤ d 且 b_t = τ_max - τ_t ≥ 0。

**证明**：verify 直接连言 τ≤τ_max、J≤J_max、ℓ≤ℓ_max、s≤d；b_t 的定义即 τ_max-τ_t，由 τ≤τ_max 得 b_t≥0。∎

### 引理 12（搬运误差关于延迟的增长）
**陈述**：ε_model(τ) = L_E τ + ½L_E²τ² 关于 τ 单调递增，且 ε_model(0)=0；因此长延迟下 CTCG 的裕度条件单调收紧。

**证明**：对 τ 求导 L_E + L_E²τ ≥ 0；代入 τ=0 得 0。∎

### 引理 13（五证一体的单调退化链）
**陈述**：任意单点/组合失效下，
Exec_v25 ⊆ Exec_v24 ⊆ Exec_v23 ⊆ Exec_v22 ⊆ Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18。

**证明**：Exec_v25 = Exec_v24 ∩ Fil_tc ∩ Fil_cd ∩ Fil_cet ∩ Fil_margin，交集只会缩小集合。三种退化路径：
- 延迟超限（TC=false）→ 进入 edge-only：丢弃云端模块但保留 USMC，仍 ⊆ Exec_v24；
- 因果不可识别且 δ_unident>ε_c → safe-stop：空集 ⊆ Exec_v24；
- 搬运误差超界（m_t ≤ margin_req+Δ_τ+r）→ safe-stop：空集 ⊆ Exec_v24。
组合失效取交集，单调性保持。∎

### 定理（CTCG 五证准入门的安全-合规-可部署-可保护-结构-因果-时序完备性）
**陈述**：对任意计划 π，`CTCG.admits(π)=True` ⟺ π 同时满足：
(1) v24 的七项（物理接地、版本一致、conformal 覆盖、专利保护、结构、力控、轻量化）；
(2) 因果可识别（或敏感性上界 ≤ ε_c）；
(3) 因果间隙 Δ_τ(φ) ≤ ε_c；
(4) 时延预算 τ≤τ_max、J≤J_max、ℓ≤ℓ_max、s≤d；
(5) 因果-时序安全裕度 m_t > margin_req + Δ_τ + r(τ)。

**证明**：由 `CTCG.admits` 的连言结构与引理 9–13 直接可得。必要性：任一条件缺失即拒证或降级，对应「结构/力控/轻量化/因果/时序」五类风险之一未被缓解。充分性：五条件全满足时，引理 10 保证延迟证据与同刻证据对 φ 的判定一致，引理 11 保证证据未过期，引理 13 保证降级链单调，故闭环成立。∎

## 6. 本轮最大风险（最终确认）

**一句话**：**延迟与隐藏网络拥塞共同构成未观测混杂，而 CDC 的无隐藏混杂/忠实性假设恰在此失效时，Δ_τ 会被系统性低估，使 CTCG 在「证据已因延迟失去因果有效性」的情况下仍判定安全——因果证书的可靠性上限，最终取决于我们对延迟生成机制的可观测程度。**
