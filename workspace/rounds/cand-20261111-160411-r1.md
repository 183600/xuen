# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「续航能力」×「时空推理」）

> 第 54 轮把技能组合推进到动作空间剖面 α_S、组合图 G_S、云边协同与动作-鲁棒性联合证书 J。本轮引入两个此前被当作常量的东西：**能量（续航）**与**时间-空间（时空）**。核心矛盾：H22：既有证书假设能量充裕且静态，而续航沿时空轨迹被连续消耗，静态“可部署”的路径可能在执行中途断电；H23：时空推理只回答“何时到达/是否可达”，不回答“以多少剩余能量到达、能否安全返航/中止”，导致时间最优路径与能量最优路径系统性冲突。

## 0. 直觉与动机

**灵感 1（续航剖面 → 把技能从动作占用升级为能量消耗场）**
直觉：第 54 轮的 `α_S(a)` 说的是技能“能不能做这个动作”；本轮补上“做这个动作要花多少电”。技能 S 在动作 a、位置 x、时刻 t 上有能耗率 `e_S(a,x,t)`，续航状态 `E(t)` 是沿轨迹积分出来的。于是可部署不再是静态谓词，而是一条**能量预算不等式**：`E(t)=E(0)-∫e_S dt-∫e_move dt+∫r dt ≥ E_res`。动作空间决定“可达”，能量决定“可达多久”。

**灵感 2（时空-能量可达集 → 可达性从 (x,t) 升到 (x,t,E)）**
直觉：普通时空推理算“到 t 时刻能不能到 x”；续航感知版本算“在 t 时刻到达 x 时，剩余能量最多能是多少”。这构成一个 **时空-能量管（tube）**，其下边界是**时间-能量帕累托前沿**：想更快就要更猛地耗能，想更省就要用更多时间。计划可行当且仅当存在一条落在管内的轨迹，且管底始终高于安全储备 `E_res`。这里天然是多目标，不能把能量压成单一标量权重。

**灵感 3（返航与中止 → 续航不是“到达”，而是“有退路”）**
直觉：机器人真正需要的不是“能到”，而是“到了还回得来、随时能安全停”。因此证书必须包含 **中止可保证性 `AbortSafe`**：沿路径每个时空点，都有一块足够能量退到最近安全点/充电点。这把第 54 轮的一次性成功证书升级为**全轨迹不变式**（invariant），类似控制里的安全集，但能量是消耗型、不可逆状态。

**灵感 4（充电/换电 → 把续航事件嵌入时空扩展图）**
直觉：充电站/换电站是时空中的离散事件。把第 54 轮的技能组合图扩展为 **时空-能量扩展图 STEG**：节点是 `(技能, 位置, 时间带, 能量带)`，边带向量成本 `(Δt, ΔE, Δρ)`。规划不再是单目标最短路，而是 **截止时间 + 电量约束下的帕累托路径搜索**；“先做 A 再充电再做 B”与“先充电再连续做完”成为同一张图上的可比较路径。

**灵感 5（续航-鲁棒性耦合 → 安全冗余有能量价格）**
直觉：第 54 轮的 ρ 越高往往越保守：降速、绕行、加大容错带都多耗电。于是存在 **ρ-E 帕累托前沿 `ℱ_ρE`**。这带来“续航改善悖论”：为提升 ρ 而增大的保守裕度，可能反而让 E 越界。跨域迁移还会造成 **续航负迁移**：同一技能在山地/低温下能耗曲线改变，动作仍兼容、鲁棒性尚可，但续航预算失效。本轮把能量维度正式并入联合证书与迁移证书。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（续航剖面与能耗动力学）**
技能 S 在动作 `a∈A`、位置 `x∈X`、时刻 `t` 的**能耗率场** `e_S(a,x,t) ∈ R_{≥0}`，其支撑 `supp(e_S) ⊆ supp(α_S)`（不能执行的动作不产生能耗）。续航状态满足
```
dE/dt = r(x,t) - e_S(a(t),x(t),t) - e_move(v(t),x(t)),   E(t) ≥ E_res
```
其中 `r` 为充电率（放电时为 0），`E_res` 为安全储备（返航/中止预算）。称轨迹 `π` **续航可行**当且仅当 `∀t∈[t0,tf], E(t) ≥ E_res`。

**定义 122（时空-能量可达集与帕累托前沿）**
从 `(x0,E0,t0)` 出发，**时空-能量可达集**
```
R_{x0,E0}(t) = { (x,E) | ∃ 技能/动作序列，使 x(t)=x, E(t)=E 且全程续航可行 }
```
对固定目标 x，定义**时间-能量帕累托前沿** `F(x) = { (τ,E) ∈ R | ¬∃(τ',E')∈R, τ'≤τ ∧ E'≥E, (τ',E')≠(τ,E) }`。计划可判定当且仅当 `∃(τ,E)∈F(x_goal), τ≤D ∧ E≥E_res`，D 为任务截止时间。

**定义 123（中止/返航安全域）**
设安全点集 `Z`（充电点、停机点、起点）。路径 `π` 的**中止安全裕度**
```
m_abort(t) = E(t) - E_res - min_{z∈Z} e_cost(x(t)→z)
AbortSafe(π) = 1  ⇔  ∀t∈[t0,tf], m_abort(t) ≥ 0
```
`e_cost(x→z)` 为在目标能量模型下从 x 退到 z 的最小能耗。`AbortSafe` 是比单点成功更强的全轨迹不变式。

**定义 124（时空-能量扩展图 STEG）**
`G_𝔈=(V_𝔈,E_𝔈)`，节点 `v=(S_i, x, [t_a,t_b], [E_a,E_b])`，即技能-位置-时间带-能量带四元组；边 `(u,v)` 带向量标签 `(Δt, ΔE, Δcompat, Δρ)`，覆盖执行、移动、充电、换技能四类转移。路径 `P=(v_0,...,v_k)` 可行当且仅当
```
Σ Δt ≤ D - t0  ∧  E0 + Σ ΔE - Σ r·Δt ≥ E_res  ∧  ∀ 前缀, 能量 ≥ E_res
```
即时间预算与能量预算同时闭合，且任意前缀不跌破储备。

**定义 125（续航-鲁棒性耦合前沿与续航负迁移）**
技能 S 的**续航-鲁棒性前沿**
```
ℱ_ρE(S) = { (ρ_S(θ), E_S(θ)) | θ∈Θ }
```
θ 为保守化旋钮（速度系数、容错带宽、绕行半径）。若 `ρ_S(θ1) ≥ ρ_S(θ2)` 逐维成立则 `E_S(θ1) ≥ E_S(θ2)`，称**续航单调性**成立（鲁棒性有能量价格）。组合的能量算子为可加 `E_{S1⊗S2}=E_{S1}⊕E_{S2}`。对域迁移 φ，**续航负迁移**
```
ΔE_transfer(φ) = ∫_{A_core×[t0,tf]} | e_target(φ(a),φ(x),t) - e_source(a,x,t) | dt da
```
若 `ΔE_transfer(φ) > B_e` 或迁移后 `AbortSafe=0`，则拒绝迁移，即使动作兼容与 ρ 均通过。

**定义 126（时空-能量联合证书 EEC）**
```
𝔈 = (ρ, A_cert, γ_ce, δ_a, E_profile, E_res, AbortSafe, τ_slack, e-evidence)
```
`E_profile` 为沿路径的能量轨迹，`τ_slack = D - t_end` 为时间裕度，`e-evidence` 至少含能耗场标定残差与在线能量观测。部署条件：
```
dom_J(T)=in ∧ δ_a<Θ_a ∧ min_t E(t) ≥ E_res ∧ AbortSafe(π)=1 ∧ τ_slack ≥ 0
```
第 54 轮联合证书 `J` 扩展为 `J⁺ = J ⊕ 𝔈`，形成**动作-鲁棒-续航-时空四元证书**。

## 2. 关键算法 伪代码

### IP-121 EPE（Endurance Profile Estimator）

```python
def endurance_profile(skill, A, X, covariates, sampler):
    e = {}
    for a in A:
        for x in X:
            # 结构化仿真 + 稀疏 GP，地形/温度/负载作为协变量先验
            e[(a, x)] = sampler.estimate(skill, a, x, covariates[x])
    return EnergyField(e, support={k for k, v in e.items() if v > 1e-6})

def integrate_energy(field, traj, E0, E_res, recharge):
    E = E0
    for (a, x, t, dt) in traj:
        E += (recharge(x, t) - field.eval(a, x, t)) * dt
        if E < E_res:
            return ('violate', t, E)
    return ('ok', E)
```

### IP-122 STER（Spatio-Temporal Energy Reachability）

```python
def ste_reachable(field, model, x0, E0, t0, D, dt, E_res):
    # labels[(x,t)] = 该时空点可达的最大剩余能量（能量支配前沿）
    labels = {(x0, t0): E0}
    for t in np.arange(t0, D, dt):
        for (x, tp), E in list(labels.items()):
            if tp != t: continue
            for a in model.actions(x):
                x2 = model.next_state(x, a, dt)
                E2 = E + (model.recharge(x, t) - field.eval(a, x, t)) * dt
                if E2 < E_res: continue
                key = (x2, t + dt)
                if E2 > labels.get(key, -np.inf):
                    labels[key] = E2          # 同点更高能量支配更低能量
    return pareto_frontier(labels)            # 按 (τ,E) 去支配
```

### IP-123 STEG（Spatio-Temporal Energy Graph）+ 续航路由

```python
def build_steg(skills, locations, time_bands, energy_bands, field, charger):
    G = LabeledDiGraph()
    for (S, x, tb, eb) in product(skills, locations, time_bands, energy_bands):
        G.add_node((S, x, tb, eb))
        for a in actions(S):
            if (a, x) not in field.support: continue
            for (S2, x2) in transitions(S, a, x):
                dt = transfer_time(S, a, x, x2)
                dE = field.eval(a, x, tb.lo) * dt - charger.rate(x, tb.lo) * dt
                G.add_edge((S, x, tb, eb), (S2, x2, shift(tb, dt), shift(eb, dE)),
                           dt=dt, dE=dE, dcomp=compat(S, S2),
                           drho=rho_delta(S, S2), path=(a,))
    return G

def endurance_route(G, start, goal, D, E0, E_res):
    labels = {start: [Label(t=0, E=E0, rho=1.0, path=[])]}
    for node in temporal_toposort(G):
        for lab in list(labels.get(node, [])):
            for e in G.out_edges(node):
                lab2 = extend(lab, e)
                if lab2.t > D or lab2.E < E_res: continue
                if any(dominates(l, lab2) for l in labels.get(e.head, [])):
                    continue
                labels[e.head] = [l for l in labels.get(e.head, [])
                                  if not dominates(lab2, l)] + [lab2]
    return pareto(labels[goal])
```

### IP-124 ASG（Abort-Safety Guard）

```python
def abort_safe(path, field, safe_points, E_res, model):
    worst = np.inf
    for (x, t, E) in path.dense():
        d_min = min(e_cost(x, z, field, model) for z in safe_points)
        margin = E - E_res - d_min
        worst = min(worst, margin)
        if margin < 0:
            return ('unsafe', t, x, margin)
    return ('safe', worst)     # 返回全轨迹最小中止裕度
```

### IP-125 EET（Endurance-aware Explain & Transfer）

```python
def endurance_transfer_certify(E_src, L_tgt, phi, B_e, rho_min):
    e_tgt = warp_energy_field(E_src.field, phi, L_tgt)
    dE = integral_abs_diff(e_tgt, E_src.field, area=E_src.A_core,
                           horizon=E_src.horizon)
    if dE > B_e:
        return ('reject', 'endurance_negative_transfer', dE)
    rho_tgt = coupling_correction(E_src.rho, K, phi)
    if min(rho_tgt.values()) < rho_min:
        return ('reject', 'robustness_fail', rho_tgt)
    if abort_safe(E_src.path, e_tgt, L_tgt.safe_points,
                  E_src.E_res, L_tgt.model) != 'safe':
        return ('reject', 'abort_unsafe')
    return ('ok', EEC(E_src, E_field=e_tgt, delta_E=dE,
                      evidence=(dE, frontier_shift(E_src, e_tgt))))
```

### IP-126 EEC（Endurance-Stamped Certificate）

```python
def endurance_stamped_certificate(path, field, J, E_res, D, model, Z):
    E_prof = integrate_energy(field, path, path.E0, E_res, model.recharge)
    if E_prof[0] == 'violate':
        return ('reject', 'energy_violation', E_prof)
    if path.t_end > D:
        return ('reject', 'deadline_miss', path.t_end - D)
    abort = abort_safe(path, field, Z, E_res, model)
    if abort[0] != 'safe':
        return ('reject', 'abort_unsafe', abort)
    slack_E = min(E_prof.energies) - E_res
    return ('ok', EEC(J, E_profile=E_prof, E_res=E_res,
                      AbortSafe=True, tau_slack=D - path.t_end,
                      energy_slack=slack_E))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| EPE | O(\|S\|·\|A\|·\|X\|·n_s)（GP 拟合 n_s 样本） | O(\|A\|·\|X\|) | 能耗场覆盖、残差界 |
| STER | O(\|X\|·\|A\|·(D/dt)·L) | O(\|X\|·D/dt) | 离散化上界、能量支配剪枝 |
| STEG | O(\|V_𝔈\| log\|V_𝔈\| + \|E_𝔈\|·L) | O(\|V_𝔈\|·L) | 标签设定完备、帕累托剪枝 sound |
| ASG | O(\|π\|·\|Z\|·\|A\|) | O(\|π\|) | 安全点完备、退路能耗上界 |
| EEC | O(\|π\| + STER) | O(\|V_𝔈\|·L) | 能量裕度闭合、证书 sound |

**正确性定理（Endurance-Spatiotemporal Deployment Soundness）**
在 (A26)–(A28) 成立的基础上，新增：**(A29)** 能耗场估计在全支撑上满足 `‖ê_S-e_S‖_∞ ≤ ε_e`；**(A30)** 能量动力学对 (x,a) 关于 Lipschitz 常数 `L_E`；**(A31)** STEG 离散化单边能量误差不超过 `δ_g`；**(A32)** 充电率模型无系统偏差。若证书 `𝔈` 通过且最小能量裕度 `S_min = min_t(E(t)-E_res)`，则
```
P(success ∧ ¬energy_violation) ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a)
                                  - P(‖ê-e‖_∞ > ε_e) - P(S_min < ε_e·T + δ_g·|P|)
```
其中能量估计误差若为次高斯 `σ_e`，则 `P(S_min < ε_e T) ≤ 2exp(-2S_min²/(T²σ_e²))`。关键：**先验能量前沿保留多目标**，**全轨迹中止安全**，**迁移前先查续航负迁移**。

| 风险 | 等级 | 缓解 |
|---|---|---|
| 能耗场随时间/温度/电池老化漂移 | 高 | 在线能量残差监测 + 周期性重标定 + 域随机化 |

## 6. 本轮最大风险

**一句话**：续航-时空证书把“可部署”从单点成功升级为全轨迹能量不变式，但其 soundness 依赖**能耗场在时空上的平稳性、估计误差界、以及充电/退路能耗的可预测性**；一旦温度、负载或电池老化使 `e_S` 分布漂移，乐观估计会导致中途断电，悲观估计则会用过大储备吞噬任务可用性，故必须以 **在线能量残差监测 + 自适应 E_res + 返航绊线** 作为护栏，绝不把离线能耗模型当作全域真值。

## 2. 关键算法 伪代码

### IP-121 EPE

```python
def endurance_profile(skill, A, X, covariates, sampler):
    e = {}
    for a in A:
        for x in X:
            # 结构化仿真 × 稀疏 GP：地形/温度/负载为协变量，输出能耗率后验
            mu, var = sampler.estimate(skill, a, x, covariates[x])
            e[(a, x)] = (mu, var)
    support = {k for k, (mu, _) in e.items() if mu > 1e-6}
    assert support <= supp(skill.alpha)          # 能耗支撑 ⊆ 动作剖面支撑
    return EnergyField(e, support=support)

def integrate_energy(field, traj, E0, E_res, recharge):
    E, energies = E0, []
    for (a, x, t, dt) in traj:
        E += (recharge(x, t) - field.mean(a, x)) * dt
        energies.append(E)
        if E < E_res:
            return ('violate', t, E)
    return ('ok', min(energies), energies)
```

### IP-122 STER

```python
def ste_reachable(field, model, x0, E0, t0, D, dt, E_res):
    # 每个 (x,t) 只保留最大剩余能量：能量是越大越好的单调资源
    labels = {(x0, t0): E0}
    for t in np.arange(t0, D, dt):
        for (x, tp), E in [kv for kv in labels.items() if kv[0][1] == t]:
            for a in model.actions(x):
                x2 = model.next_state(x, a, dt)
                E2 = E + (model.recharge(x, t) - field.mean(a, x)) * dt
                if E2 < E_res:
                    continue
                key = (x2, t + dt)
                if E2 > labels.get(key, -np.inf):
                    labels[key] = E2
    return pareto_frontier(labels)     # F(x) 按时间升/能量降去支配
```

### IP-123 STEG + 续航路由

```python
def build_steg(skills, locations, time_bands, energy_bands, field, charger):
    G = LabeledDiGraph()
    for (S, x, tb, eb) in product(skills, locations, time_bands, energy_bands):
        for a in actions(S):
            if (a, x) not in field.support:
                continue
            for (S2, x2) in transitions(S, a, x):
                dt = transfer_time(S, a, x, x2)
                dE = field.mean(a, x) * dt - charger.rate(x, tb.lo) * dt
                G.add_edge((S, x, tb, eb),
                           (S2, x2, shift(tb, dt), shift(eb, dE)),
                           dt=dt, dE=dE, dcomp=compat(S, S2),
                           drho=rho_delta(S, S2))
    return G

def endurance_route(G, start, goal, D, E0, E_res):
    labels = {start: [Label(t=0, E=E0, rho=1.0, path=[])]}
    for node in temporal_toposort(G):
        for lab in list(labels.get(node, [])):
            for e in G.out_edges(node):
                lab2 = extend(lab, e)
                if lab2.t > D or lab2.E < E_res:
                    continue
                if any(dominates(l, lab2) for l in labels.get(e.head, [])):
                    continue
                labels[e.head] = [l for l in labels.get(e.head, [])
                                  if not dominates(lab2, l)] + [lab2]
    return pareto(labels.get(goal, []))   # (t,E,ρ) 三维帕累托
```

### IP-124 ASG

```python
def abort_safe(path, field, safe_points, E_res, model):
    worst = np.inf
    for (x, t, E) in path.dense():
        d_min = min(e_cost(x, z, field, model) for z in safe_points)
        margin = E - E_res - d_min
        worst = min(worst, margin)
        if margin < 0:
            return ('unsafe', t, x, margin)
    return ('safe', worst)
```

### IP-125 EET

```python
def endurance_transfer_certify(E_src, L_tgt, phi, B_e, rho_min):
    e_tgt = warp_energy_field(E_src.field, phi, L_tgt)
    dE = integral_abs_diff(e_tgt, E_src.field,
                           area=E_src.A_core, horizon=E_src.horizon)
    if dE > B_e:
        return ('reject', 'endurance_negative_transfer', dE)
    rho_tgt = coupling_correction(E_src.rho, K, phi)
    if min(rho_tgt.values()) < rho_min:
        return ('reject', 'robustness_fail', rho_tgt)
    abort = abort_safe(E_src.path, e_tgt, L_tgt.safe_points,
                       E_src.E_res, L_tgt.model)
    if abort[0] != 'safe':
        return ('reject', 'abort_unsafe', abort)
    return ('ok', EEC(E_src, E_field=e_tgt, delta_E=dE,
                      evidence=(dE, frontier_shift(E_src, e_tgt))))
```

### IP-126 EEC

```python
def endurance_stamped_certificate(path, field, J, E_res, D, model, Z):
    E_prof = integrate_energy(field, path, path.E0, E_res, model.recharge)
    if E_prof[0] == 'violate':
        return ('reject', 'energy_violation', E_prof)
    if path.t_end > D:
        return ('reject', 'deadline_miss', path.t_end - D)
    abort = abort_safe(path, field, Z, E_res, model)
    if abort[0] != 'safe':
        return ('reject', 'abort_unsafe', abort)
    return ('ok', EEC(J,
                      E_profile=E_prof,
                      E_res=E_res,
                      AbortSafe=True,
                      tau_slack=D - path.t_end,
                      energy_slack=E_prof[1] - E_res))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| EPE | O(\|S\|·\|A\|·\|X\|·n_s) | O(\|A\|·\|X\|) | 能耗支撑对齐 α_S，残差界 ε_e |
| STER | O(\|X\|·\|A\|·(D/dt)·L) | O(\|X\|·D/dt) | 离散化误差有界，能量支配剪枝 sound |
| STEG | O(\|V_𝔈\| log\|V_𝔈\| + \|E_𝔈\|·L) | O(\|V_𝔈\|·L) | 标签设定完备，帕累托最优 |
| ASG | O(\|π\|·\|Z\|·\|A\|) | O(\|π\|) | 安全点完备，退路能耗上界 |
| EEC | O(\|π\| + STER) | O(\|V_𝔈\|·L) | 能量裕度闭合，四元证书 sound |
| EET | O(\|A_core\|·\|T\| + \|π\|·\|Z\|) | O(\|A_core\|·\|T\|) | 负迁移预算闭合，中止安全 |

**正确性定理（Endurance-Spatiotemporal Deployment Soundness）**
假设第 54 轮 (A26)-(A28) 成立；新增 **(A29)** `‖ê_S-e_S‖_∞ ≤ ε_e`；**(A30)** 能量动力学关于 `(x,a)` Lipschitz（常数 `L_E`）；**(A31)** STEG 离散化单边误差 `≤ δ_g`；**(A32)** 充电率模型无系统偏差。若 `𝔈` 通过且 `S_min = min_t(E(t)-E_res)`，则
```
P(success ∧ ¬energy_violation) ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a)
                                  - P(‖ê-e‖_∞>ε_e) - P(S_min < ε_e·T + δ_g·|P|)
```
且当估计误差次高斯（尺度 σ_e）时
```
P(energy_violation) ≤ 2·exp(-2·S_min² / (T²·σ_e²))
```
关键：**能量前沿保留多目标而非加权标量化**，**全轨迹 AbortSafe 不变式**，**迁移先查续航负迁移**。

## 6. 与 UniBot 场景的落点

- **长时巡检/配送**：续航路由与充电计划天然对应 STEG 上的双约束路径；
- **多机协同**：`AbortSafe` 可作为跨机能量互助（换电/接力）的安全前提；
- **仿真到真机迁移**：`ΔE_transfer(φ)` 正好刻画“动作能复制、但电池不认账”的负迁移；
- **可解释性**：能量根因（哪一段轨迹耗尽、退路不足）通过 `e-evidence` 回传云端重规划。

## 7. 本轮最大风险

**一句话**：续航-时空证书把“可部署”从单点成功升级为全轨迹能量不变式，但其 soundness 依赖**能耗场在时空上的平稳性、估计误差界、以及充电/退路能耗的可预测性**；一旦温度、负载或电池老化使 `e_S` 分布漂移，乐观估计会导致中途断电，悲观估计则会用过大储备吞噬任务可用性，故必须以 **在线能量残差监测 + 自适应 E_res + 返航绊线** 作为护栏，绝不把离线能耗模型当作全域真值。
