# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环第 3 轮；本轮灵感：「虚实迁移」×「语义地图」）

> R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」。R69 把不确定性二分，并让系统学会「提问」。但 R69 有一个始终未言明的前提：**它的先验、策略密度、模态权重与 VoI 模型，全部诞生于一个「虚拟世界」**（训练分布 / 仿真 / 离线日志），而它部署在「真实世界」。R68 的标定层与 R69 的 MCG 校准门，本质上都只给出一个**全局标量信任**（一个 ECE、一个 λ_floor）。可 sim-to-real 的落差不是标量，它是一个**场（field）**：地板、杯子、门把手或许迁移得很好；透明玻璃、反光湿地、软体、没见过的路人行为则可能瞬间失效。用全局最坏情况去标定，全场都过度保守；用平均值去标定，某处就是致命盲区。
>
> 本轮两个灵感正好补上：
> - **语义地图**把「我在哪」从米制坐标升级为「我处在什么概念/区域、这里的知识被现实验证过几次」；
> - **虚实迁移**把「虚拟先验 vs 真实观测」的落差变成一等公民——目标不是一次消除 gap，而是知道 **gap 在哪里、有多大、多久没被现实校对了**。
>
> 核心命题：**把「信任」从全局标量升级为语义地图上的一张场；用逐语义单元的局部保形风险控制替代全局最坏情况标定，让安全约束在「已被现实验证」的单元更松（local trust bonus），在「gap 活跃 / 久未接地 / 疑似别名」的单元更紧；并把 R69 的提问层上移一层——不再只问「哪个动作模态该消歧」，而是问「哪个语义单元最值得花真实预算去重新接地」。** 命名 **ATLAS-RAS**（Adaptive Transfer-Localized Assurance via Semantic maps）。
>
> 一句话定位：R69 的不确定性是一只可以开口的嘴；R70 的问题是「**这张嘴说的话，在世界的哪个角落还算数？**」——信任必须有地址，否则它只是一个平均值。

## 0. 直觉与动机

**灵感 1（语义地图 → 信任是有地址的）**
直觉：我们从不「普遍地」信任一个模型，只信任它在某些情形下。语义地图恰好提供了「情形」的坐标系：不是米制坐标，而是「厨房台面 / 玻璃门 / 人群边缘 / 反光湿地」这样的语义单元。把每个单元的「现实验证次数、上次接地时间、历史分歧、来源可靠性」记在地图上，信任就有了地址。R68/R69 的全局 λ 相当于给整座城市一个平均降雨量；地图给的是逐街区降雨——同样的总预算，后者能把伞送到真正下雨的地方。

**灵感 2（虚实迁移 → gap 是场，不是标量）**
直觉：sim-to-real 的传统问法是「策略迁移成功率多少」，一个全局数字。但真实部署里失败几乎总是**局部**的：某个材质、某种光照、某类交互。语义地图给出分区，于是可以逐单元估计「虚拟模型预测的观测分布」与「真实观测分布」的散度，得到一张**现实落差场（reality gap field）**。这张场不必准确到能修正物理，只需准确到能说「这一格别再信仿真了」。

**灵感 3（局部保形 → 分区不是冒险，而是更紧的安全）**
直觉：全局标定要对最坏单元安全，所以全局阈值被最坏单元拖高，好单元被连累。若在每个语义单元内维持**逐单元覆盖**（Mondrian / conditional conformal），则每个单元的安全保证与全局相同，但阈值可以各自不同。**分区不削弱安全，反而释放了被最坏单元吞掉的效率**——这正是 R69「resolution bonus」的信任版：R69 因「消解了歧义」而放松，R70 因「现实验证过这一格」而放松。

**灵感 4（接地账本 → 信任会过期）**
直觉：一次现实验证不是永久真理。世界会漂移：家具被挪动、光照改变、季节更替、人的习惯变化。地图必须给每个单元记「上次被现实接地的时刻」与「历史漂移率」，让信任**随时间衰减**，并在衰减到阈值以下时触发重新接地。这把探索/利用变成一个可调度问题：真实预算稀缺，应花在「信任即将过期 × 该单元重要 × 不确定性高」的地方。

**灵感 5（语义别名 → 地图最危险的不是空白，而是「看起来认识」）**
直觉：地图最致命的错误不是「这一格我没见过」（那会被保守处理），而是**感知别名（perceptual aliasing）**：一个危险的新区域在语义上长得像某个已充分验证的安全区域，于是系统把旧信任错误地迁移过去。这是 R69「问错比不问更危险」的地图版：**信错地方比不信任更危险**。所以本轮必须同时交付别名守卫、地图一致性不变量，以及「空白格默认不可信」的显式纪律。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（ATLAS-RAS 总览）** ATLAS-RAS = (S2RSM, TVF, RGF, DGL, MRS, T-VoI, B2S, SRM, MCI, RAS-WM‡)。四不变式：
(i) 继承 R69 的实时流零学习写操作与交互预算硬约束；
(ii) **空白即不可信（default-untrusted）**：任何未被至少 n_min 次现实验证接地的语义单元，其迁移有效度取先验下界 T_∅，不得高于任何已验证单元；
(iii) **逐单元安全**：风险缩放按单元取值 λ_i，但每个单元须满足与全局相同的覆盖下界 1−α；
(iv) **地图可审计、可回滚**：地图每次更新入 AuditBuf，证书绑定地图版本号。

**定义 311（语义状态与语义地图）** 语义状态 s=(x,c)，x∈ℝ³ 度量位置，c∈𝒞 语义概念（材质/物体/活动/场景类型）。语义地图 M=(𝒫, Φ, L)：𝒫={C_i} 为 𝒞×空间上的单元划分；Φ: C_i↦φ_i 单元描述子（语义类别、几何范围、外观原型）；L 为逐单元账本（定义 314）。查询 q(s) 返回单元索引 i，无法解析到单元时返回 ⊥（走默认保守）。

**定义 312（迁移有效度场 TVF）** 对单元 C_i，给定虚拟模型 p_V、真实分布 p_R 与风险函数 ℓ，单元风险 R_i(π)=E_{s~p_R|C_i}[ℓ(π(s))]。TVF 为逐单元保形阈值 T_i(α)=Q_{1−α}({ℓ_j : s_j∈C_i})（Mondrian conformal），并在单元内可交换假设 A_cond 下给出 P(R_i≤T_i)≥1−α。T_i 越小表示该单元越可信；样本不足的单元取 T_i=T_∅=sup_j T_j。

**定义 313（现实落差场 RGF）** 逐单元估计虚拟观测分布 p_V(y|s,C_i) 与真实观测 p_R(y|s,C_i) 的散度 G_i=D(p_R‖p_V)（逐单元 MMD / 密度比 / 两样本检验统计量估计）。G_i>τ_gap ⇒ 单元标记 gap-active，进入「仿真先验降权」集合 𝒢。RGF 是「仿真需要被修正的地图」，TVF 是「策略可以被信任的地图」，二者独立记录。

**定义 314（接地账本 DGL）** 账本 L(C_i)=(n_i, t_i^last, ρ_i^{src}, Ḡ_i, ν_i)：n_i 现实验证样本数、t_i^last 上次接地时刻、ρ_i^{src} 逐来源可靠性、Ḡ_i 历史平均落差、ν_i 观测漂移率。信任衰减：T_i(t)=min(T_i(α), T_i(α)+κ(t−t_i^last)ν_i) 随久未接地单调收紧，接地后重置。

**定义 315（地图条件风险缩放 MRS）** λ_i = clip(λ_base·(T_i(t)/T_ref)^{−γ}, λ_min, λ_max)。已验证单元（T_i 小）得到更小、更不保守的 λ_i；gap-active / 空白 / 久未接地单元得到更大 λ_i。**每个单元的 λ_i 不弱于其在全局最坏情况下的取值**（定理 18）。

**定义 316（迁移感知 VoI，T-VoI）** 把 R69 的 VoI 上移一层：状态是地图的「单元知识状态」，动作是「对单元 C_i 花一次真实接地预算」。T-VoI(i)=E[H(T_i)−H(T_i|接地)]−c_i，c_i 为移动到该单元并采集一个真实标签的物理/时间成本。g*=argmax_i T-VoI(i)，与 R69 的 MINT 共享预算与证据纪律。**R69 问「对哪个模态求证」，R70 问「对哪个格子求证」。**

**定义 317（双向迁移 B2S）** 虚拟→真实：策略在单元 C_i 的采用权重按 T_i 与 G_i 降权（map-versioned policy demotion）。真实→虚拟：把已接地单元的真实观测回灌仿真器/数字孪生，校正 p_V|C_i 并更新 G_i。两个方向共享地图版本，但**写操作离线**（继承 R68 零实时学习写）。

**定义 318（来源可靠性地图 SRM）** 逐单元、逐证据来源 s 维护可靠性 ρ_i^s（历史一致率）。R69 的「固定 k 个正交源一致」升级为**按单元自适应 k_i**：k_i=min{k : δ_p·(ρ_i)^{k−1} ≤ ε_σ}，在保证引理 18 上界的前提下最少提问。地图把投毒防御从全局规则变成局部学习到的规则。

**定义 319（别名守卫 MCI）** 语义匹配须过两道门：(a) 外观/几何原型距离低于 τ_alias；(b) 时序一致性（连续 N 帧归入同一单元，排除瞬时误配）。任一不满足 ⇒ 视为新单元而非已知单元，取 T_∅。地图一致性不变量：单元划分须覆盖观测流形（无未索引观测）、单元间边界不重叠、版本更新单调（不删除仍被引用的单元）。

**定义 320（证书 J_ATLAS）** J_ATLAS=(J_FLUID, map_ver, per-cell(T_i,G_i,n_i,age_i), alias_reject_rate, regrounding_count, gap_field_p95, atlas_ver)。Valid ⇔ Valid(J_FLUID) ∧ 各单元覆盖满足 ∧ 无单元违反 default-untrusted ∧ 别名拒绝率在界内。

**定义 321（接地调度预算）** 单位时间真实接地 ≤ N_g 次（真实数据昂贵），且不得与 R69 的信息动作预算叠加超过共享上限；优先级 score_i=importance_i·urgency_i(age_i,ν_i)·uncertainty_i(n_i^{−½})。这是探索/利用的可调度形式。

**定义 322（新单元准入）** 查询返回 ⊥ 或别名拒绝产生的新单元进入「候选」状态，只可观不可执行高风险动作，直到 n_min 次接地或 T_i 收敛；候选单元的行动退化为 R68 纯保守。

**定义 323（gap 触发重划分）** 若某单元内部 G 的方差过大（说明单元内部不同质、分区过粗），触发局部分裂（split），直到单元内落差同质或达到最小样本约束；分裂提升分辨率但增加样本需求（定理 20 的权衡）。

**定义 324（地图版本化策略降权）** 策略采用权重 w_i=σ((T_ref−T_i)/τ)·1[¬gap-active]。地图版本变化导致 w_i 单调不增地回退（安全侧），除非新版地图有更多接地证据。

**定义 325（审计 VQAuditor-M）** 审计地图决策：空白格是否被误当已验证、别名是否被放过、gap-active 单元是否仍被仿真先验驱动、重划分是否过拟合噪声。结论回灌 AuditBuf，成为 T-VoI 成本与阈值的先验。

**定义 326（整体闭环的阶段划分）** 五阶段：感知 → 地图查询 → 逐单元信任 → T-VoI 接地调度 → 逐单元风险缩放与执行。地图查询 O(log|𝒫|)（空间+语义索引），逐单元运算只对命中单元执行。

# IP-264 S2RSM：语义地图与账本查询
class Sim2RealSemanticMap:
    def __init__(self, partition, index, prior_T_inf):
        self.P, self.idx, self.T_inf = partition, index, prior_T_inf
        self.ledger = {}                 # cell_id -> (n, t_last, rho_src, G_bar, nu)
    def query(self, s):                  # s = (x, c)
        i = self.idx.lookup(s.x, s.c)
        if i is None: return None        # ⊥ -> default conservative
        return Cell(i, self.ledger.get(i, EMPTY), self.T_inf)

# IP-265 TVF：逐单元保形阈值（空白即不可信）
def cell_threshold(cell, scores, alpha):
    if cell.n < N_MIN: return cell.T_inf
    return mondrian_quantile(scores[cell.id], 1 - alpha)

# IP-266 RGF：逐单元现实落差
def reality_gap(cell, real_obs, sim_obs):
    stat = mmd_two_sample(real_obs[cell.id], sim_obs[cell.id])
    return stat, stat > TAU_GAP          # gap-active flag

# IP-267 MRS：地图条件风险缩放
def map_risk_scale(cell, base_lam, T_ref, gamma):
    ratio = min(cell.T(now) / T_ref, 1.0)      # 越不可信越大
    return clip(base_lam * ratio ** (-gamma), LAM_MIN, LAM_MAX)

# IP-269 T-VoI：哪个格子最值得接地（R69 MINT 的元层对偶）
def choose_regrounding(map_state, budget):
    best = None
    for i in map_state.unknown_or_stale():
        if not budget.allow(i): continue
        voi = ent(map_state.T[i]) - exp_ent_after_grounding(map_state.T[i], i)
        score = voi * map_state.importance[i] - map_state.cost(i)
        if best is None or score > best.score: best = (i, score)
    return best if best and best.score > 0 else None

# IP-270 B2S：双向更新（离线写）
def bidirectional_update(map_state, cell, real_y, sim):
    map_state.ledger[cell.id] = ground(map_state.ledger[cell.id], real_y)  # real -> map
    sim.recalibrate(cell.id, real_y)                                       # real -> virtual
    map_state.G[cell.id] = reality_gap(cell, ...)                          # refresh RGF

# IP-271 SRM：按单元自适应证据纪律
def adaptive_k(cell, delta_p, eps_sigma):
    for k in range(2, K_MAX + 1):
        if delta_p * cell.rho ** (k - 1) <= eps_sigma: return k
    return K_MAX

# IP-274 主闭环（承接 R69 FLUID，在不确定性处置前插入「地图信任」层）
def ATLAS_RAS_round(M, obs):
    z, o = M.mtm.forward(obs); c, U_cal, thr = M.cof.step(...)
    cell = M.smap.query(o.semantic_state)              # ⊥ -> default untrusted
    if cell is None or cell.is_candidate:              # 空白/候选 -> R68 保守
        return M.r68_conservative(o), cell
    T_i = M.tvf.cell_threshold(cell, M.risk_scores, alpha)
    G_i, gap = M.rgf.reality_gap(cell, M.real_buf, M.sim_buf)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o_obs, o_calibrated)
    # 只有「已接地且非 gap-active」才允许 R69 的交互层生效
    if gap or T_i > TAU_TVF or M.fma.slow_suspect(a_hat, M.last_r_res):
        return M.r68_conservative(o), cell
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    s = M.fmp.sample(o, K); U_ale, U_epi, modes, _ = M.aud.decompose(s, z, M.fmp.mode_head)
    g = M.mint.choose_interaction(modes, o, M.budget) if U_epi > TAU_EPI else None
    if g is not None: U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    # 逐单元风险缩放：信任越差，λ 越大
    lam_i = M.mrs.map_risk_scale(cell, M.efs.risk_scale(...), T_ref, gamma)
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), M.efs.lam_floor(U_floor), lam_i)
    A = M.ach.propose(x_prime, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    # 元层：是否值得花真实预算给某个格子重新接地（与任务动作共享预算）
    r = M.tvoi.choose_regrounding(M.smap, M.budget)
    if r is not None: M.smap.schedule_grounding(r)
    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_m.audit_async(cell, lam_i, G_i, T_i, r)
    return k, lam, mode, (U_ale, U_epi, T_i)

## 3. 推导

**引理 19（逐单元保形覆盖）** 设 A_cond：给定单元 C_i，样本在 (s,y) 上条件可交换。则 Mondrian 阈值 T_i 满足 P(R_i≤T_i)≥1−α，且与其它单元无关。要点：分区不消耗覆盖保证；每单元独立付出 (1−α) 的「税」，换来互不拖累。系：若 A_cond 不成立（单元内异质），引理 22 的 gap 检验以高概率报警，触发定义 323 的重划分。

**引理 20（全局与局部阈值的支配关系，local trust bonus 的来源）** 设 T_glob 为合并所有单元的全局 (1−α) 分位数，T_i 为逐单元分位数。则 T_i≤T_glob 当且仅当单元 C_i 的尾部轻于混合尾部；且 max_i T_i≥T_glob。因此全局阈值必然被最坏单元支配，而逐单元阈值在「好单元」上严格更松。**安全上界（每单元 1−α）不变，效率在良好迁移单元上严格提升**。

**引理 21（信任衰减与接地调度）** 若单元观测分布漂移速率 ≤ν_i，则从未接地时长 Δt 内风险增量 ≤ν_i·Δt，故 T_i(t) 的收紧速率可由 ν_i 界定；要使单元信任不劣于 T_max，需最大接地间隔 Δt_i≤(T_max−T_i)/ν_i。系：定义 321 的 urgency_i=max(0,(t−t_i^last)ν_i−(T_max−T_i))，给出可调度的硬约束。

**引理 22（落差可检测性与样本复杂度）** 若单元 C_i 上 D(p_R‖p_V)≥δ，则逐单元两样本检验在 n_i≥c·(d/δ²)·log(1/β) 样本下以概率 ≥1−β 检出 gap（d 为有效维度）。系：地图的验证成本可算——这正是需要 T-VoI 决定先验证哪一格、而非均匀验证的原因。

**定理 18（ATLAS 严格包含 FLUID 与 R68）** 在 A_cond 与别名守卫正确（定义 319）成立时：
(i) 若所有单元同质（单一单元，T_i≡T_glob，G≡0），ATLAS 逐指令退化为 R69 FLUID；
(ii) 若进一步 R69 的全部退化条件成立，则退化为 R68；
(iii) 一般情形下，对任意单元 C_i，ATLAS 的单元期望风险 ≤ R69 使用全局标量时的单元风险（引理 19–20），故全局期望风险不劣于 R69，且在低 T_i 单元严格更低。
因此 ATLAS 是 R69 的严格泛化：安全侧永不让步，效率侧获得「局部信任 bonus」。

**定理 19（别名守卫的误迁移上界）** 设已验证单元 C_i 与危险单元 C_j 的语义原型距离为 d_ij，观测噪声 ε；若 d_ij>2ε 且时序一致窗口 N 足够，则把 C_j 误判为 C_i 的概率 ≤exp(−N·d_ij²/(8ε²))。系：**别名风险随语义可分性与观测时长指数下降**；语义地图的价值恰在于让「可分性」显式化，从而选择「多看一眼」而非「猜」。

**定理 20（分辨率–样本权衡，无免费午餐）** 设单元数 |𝒫|=m、总真实样本 B，则平均每单元 B/m；由引理 22，单元越多，逐单元可检测的最小落差 δ_min∝√(m/B) 越大。即**更细的地图能更好地隔离 gap，但每格更难过验证；存在最优 m* 使「隔离收益 − 验证成本」最大**。这解释了定义 323 的重划分必须 gap 驱动而非越细越好。

## 6. 本轮最大风险

**一句话**：ATLAS-RAS 的全部安全论据建立在「语义分区是对的」这一前提上——**若分区过粗，好单元与坏单元被平均，gap 被藏进同一个格子（全局标量问题的原样重演）；若分区过细，每格样本太少，逐单元保形保证变得空洞，而地图却仍以「已验证」的姿态发放更松的 λ**；更致命的是感知别名让危险区域「长得像」已验证区域，地图于是把信任错误迁移过去——**地图把 unknown-unknowns 非法地改写成 known-knowns，而且它最自信的地方恰恰是它最没有资格自信的地方**。此时「有地图」比「没地图」更危险。

**次级风险与缓解**：
1. **地图过拟合/幸运验证**（少数样本偶然通过）→ n_min 硬门槛 + 保形覆盖下界 + 可信区间而非点估计；
2. **别名 / 语义投毒**（危险区伪装成熟知区）→ 定义 319 双门守卫 + 定理 19 指数上界 + E307/E315 对抗测试；
3. **信任永不衰减**（世界漂移后仍用旧地图）→ 定义 314 衰减 + 引理 21 最大接地间隔 + E305/E313；
4. **接地预算被 T-VoI 滥用**（不断追问低价值格）→ 与 R69 共享预算上限 + score>0 才执行 + E306 Pareto；
5. **重划分过拟合噪声**（split 越拆越碎）→ gap 驱动 + 最小样本约束 + 定理 20 的最优分辨率论证 + E311。

**一句话收束**：信任一旦有了地图，就等于承认「我并非普遍地可靠」，而安全的关键从来不是把空白格填满，而是**在填满它之前，永不假装它已经被填满**。

## 4. 推导

**引理 19（逐单元保形覆盖）** A_cond（单元内条件可交换）下，Mondrian 阈值 T_i 满足 P(R_i≤T_i)≥1−α 且与其它单元无关。分区不消耗覆盖，只把 (1−α) 的税分摊到每格；异质则被引理 22 的 gap 检验报警并触发重划分。

**引理 20（全局 vs 局部阈值支配）** 全局阈值必被最坏单元支配（max_i T_i≥T_glob），逐单元阈值在尾部较轻的单元上严格更松。故安全上界不变而效率在良好迁移单元上提升——local trust bonus。

**引理 21（信任衰减与接地调度）** 漂移速率 ≤ν_i 时风险增量 ≤ν_i·Δt；最大接地间隔 Δt_i≤(T_max−T_i)/ν_i。urgency_i=max(0,(t−t_last)ν_i−(T_max−T_i)) 给出可调度硬约束。

**引理 22（落差可检测性与样本复杂度）** D(p_R‖p_V)≥δ 时，n_i≥c·(d/δ²)·log(1/β) 样本下以概率 ≥1−β 检出 gap。故验证成本可算，应由 T-VoI 决定先验证哪一格。

**定理 18（ATLAS 严格包含 FLUID 与 R68）** A_cond + 别名守卫正确时：单元同质 ⇒ 逐指令退化为 R69 FLUID；再满足 R69 退化条件 ⇒ 退化为 R68；一般情形下每单元风险 ≤ R69 全局标量方案，全局不劣且低 T_i 单元严格更优。安全永不让步，效率获局部信任 bonus。

**定理 19（别名守卫误迁移上界）** 原型距离 d_ij>2ε、时序窗口 N 足够时，把危险单元 C_j 误判为已验证单元 C_i 的概率 ≤exp(−N·d_ij²/(8ε²))。别名风险随语义可分性与观测时长指数下降。

**定理 20（分辨率–样本权衡）** 单元数 m、真实样本 B 时，δ_min∝√(m/B)：越细越能隔离 gap，但每格越难过验证；存在最优 m* 使「隔离收益 − 验证成本」最大，故重划分必须 gap 驱动而非越细越好。

## 7. 本轮最大风险

**一句话**：ATLAS-RAS 的全部安全论据建立在「语义分区是对的」这一前提上——**分区过粗则好单元与坏单元被平均、gap 被藏进同一格（全局标量问题原样重演）；分区过细则每格样本太少、逐单元保形保证空洞，而地图仍以「已验证」姿态发放更松的 λ**；更致命的是感知别名让危险区域「长得像」已验证区域，地图便把信任错误迁移过去——**地图把 unknown-unknowns 非法改写成 known-knowns，而且它最自信之处恰是它最没资格自信之处**；此时「有地图」比「没地图」更危险。

**次级风险与缓解**：地图过拟合/幸运验证（n_min 硬门槛 + 保形覆盖下界 + 可信区间）；别名/语义投毒（定义 319 双门守卫 + 定理 19 指数上界 + E307/E315）；信任永不衰减（定义 314 衰减 + 引理 21 最大接地间隔 + E305/E313）；接地预算被 T-VoI 滥用（与 R69 共享预算上限 + score>0 才执行 + E306）；重划分过拟合噪声（gap 驱动 + 最小样本约束 + 定理 20 + E311）。

**一句话收束**：信任一旦有了地图，就等于承认「我并非普遍地可靠」；而安全的关键从来不是把空白格填满，而是**在填满它之前，永不假装它已经被填满**。
