# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「视觉语言模型」×「异常检测」）

> 第 54 轮把技能组合提升为「动作空间占用 + 鲁棒性谱」的双证书体系。本轮引入视觉语言模型（VLM）作为开放世界语义先验，并把异常检测从全局标量升级为 **任务条件化、动作可执行的预期违反**。核心矛盾：H22：VLM 语义覆盖广但空间校准差、置信度未校准，直接拿其相似度/困惑度当异常分数会产生 **语义-几何错配**，在分布漂移下既误报又漏报；H23：具身异常是任务-动作条件化的，纯标量异常分数 **不可行动**——它既无法触发恢复技能，也无法进入第 54 轮的证书体系。

## 0. 直觉与动机

**灵感 1（VLM 是“语义温度计”，不是“物理温度计” → 保形校准）**
直觉：VLM 能指出“悬空的椅子不合理”，却常给“物理上不可能但语言上常见”的画面高似然；反过来，一枚罕见但无害的夹具会被它判成异常。VLM 度量的是语义合理性，不是物理可行性，更不是校准过的异常概率。因此不能把 `1 - s_VLM` 直接当异常分数，而要用 **保形预测（conformal prediction）** 把它变成有有限样本误报控制的 p 值：`p(o) = (1 + #{校准样本分数 ≥ s(o)})/(n+1)`，只有 `p(o) < α` 才判异常。这样 VLM 的“开放语义”被保留，过度自信被统计护栏压住。

**灵感 2（异常 = 任务条件化的预期违反 → TEV）**
直觉：同一个杯子放在桌上不异常，但作为“抓取目标”却躲在障碍物后面，就是任务相关异常；一把螺丝刀对“拧螺丝”正常，对“切菜”则是语义异常。异常不是无条件的“画面怪异”，而是 **当前任务 T 与动作 a 下期望分布的偏离**。于是定义期望图 `E_exp(T,a)`（期望物体、空间/功能关系、动作前置条件），异常分数分解为语义、几何、程序三类残差。这让异常检测第一次与任务/技能语义对齐。

**灵感 3（异常必须落到动作空间 → 异常证书 + A2A 桥接）**
直觉：检测到异常只是半步。机器人需要知道“哪里异常、什么类型、多严重、根因是什么、该用哪个技能救场”。因此异常输出不应是标量，而应是 **异常证书 `Anom_Cert = (R_anom, τ_type, σ_sev, c_cause, a_recover, p_val, τ_detect)`**，再经 **Anomaly-to-Action（A2A）桥接** 映射到与第 54 轮 ACS 相同的动作空间：选择与异常区域动作覆盖重叠、恢复成功率达标、转换成本可控的恢复技能；若无可行恢复，则升级云端或安全停机。

**灵感 4（异常作为鲁棒性新维度 → ρ_anom 与 J⁺）**
直觉：第 54 轮的 `ρ` 只描述“已知扰动下性能保持”，缺一个维度：“未知异常下能否发现并恢复”。新增 `ρ_anom = (TPR@FPR=α, FAR_shift, IoU_loc, τ_detect, abstain_rate)`，并把 `ρ_anom` 与 `ρ`、`A_cert`、`Anom_Cert` 一起写入增强联合证书 `J⁺`。异常检测由此不再是外挂模块，而是鲁棒性证书体系的一等公民。

**灵感 5（云边分层 + 反事实闭环）**
直觉：边端跑蒸馏 VLM + 保形头做毫秒级筛查；不确定带上传云端大 VLM 做语义仲裁与本体更新。再用 GenSim 生成 **反事实异常**（把正常场景编辑成指定类型异常），主动挖掘困难负样本，更新异常记忆与校准集；漂移检测器触发加权保形重校准。这形成 **边筛查 - 云仲裁 - 证书回传 - 反事实合成 - 重校准** 的闭环，直接接上第 54 轮的云边协同。

## 1. 形式化定义（增量：定义 121–127）

**定义 121（任务条件化观测期望）**
给定任务 `T`、当前动作 `a`、上下文 `c`，存在期望观测分布 `P_exp(o | T, a, c)`。其离散化为期望图 `E_exp = (O_exp, R_exp, Π_exp)`：`O_exp` 为期望物体/部件集合，`R_exp` 为期望空间/功能关系，`Π_exp` 为动作前置条件集合。异常即观测图 `o` 相对 `E_exp` 的偏离。

**定义 122（语义-几何-程序异常分数）**
```
s_anom(o|T,a) = λ_s·(1 - s_VLM(o|T,a)) + λ_g·d_geo(o,E_exp) + λ_p·u_proc(o,Π_exp)
```
其中 `λ_s,λ_g,λ_p ≥ 0` 且和为 1；`s_VLM ∈ [0,1]` 为 VLM 在任务提示下的语义合理性；`d_geo ∈ [0,1]` 为几何/物理残差（穿模、支撑、可达性）；`u_proc ∈ [0,1]` 为前置条件违反度。三项共同把“语义流畅”与“物理可行”解耦。

**定义 123（保形异常判定）**
校准集 `D_cal = {o_i}`，非一致性分数 `s_i = s_anom(o_i|T,a)`。对测试观测 `o`，保形 p 值
```
p(o) = (1 + |{i : s_i ≥ s(o)}|) / (n + 1)
```
异常判定 `A_α = {o : p(o) < α}`。在可交换假设下 `P(o_benign ∈ A_α) ≤ α`。在协变量漂移下使用密度比 `w(o)` 的加权保形：
```
p_w(o) = (Σ_{i:s_i≥s(o)} w_i + w_max) / (Σ_i w_i + w_max)
```

**定义 124（异常证书）**
```
Anom_Cert = (R_anom, τ_type, σ_sev, c_cause, a_recover, p_val, τ_detect)
```
`R_anom` 为异常在图像/动作空间中的定位；`τ_type ∈ {semantic, geometric, procedural, temporal}`；`σ_sev ∈ [0,1]` 为严重度；`c_cause` 为最简根因（物体/关系/前置条件）；`a_recover` 为建议恢复动作（可为空）；`p_val` 为保形 p 值；`τ_detect` 为检测时延。

**定义 125（异常-动作桥接 A2A）**
桥接函数 `bridge: (R_anom, τ_type) → a_recover ∈ A`。恢复矩阵 `M_anom[s,τ] = P(recover | 使用技能 s 处理类型 τ)`。可行恢复集
```
Rec(R,τ) = { s ∈ S : IoU(A_s, R) ≥ θ_loc ∧ M_anom[s,τ] ≥ θ_rec ∧ c_trans(s,a_cur) ≤ τ_rec }
```
若 `Rec = ∅`，则 `escalate`（云端仲裁或安全停机）。桥接把异常检测与第 54 轮的技能动作剖面 `α_S` 直接缝合。

**定义 126（异常鲁棒性谱与增强联合证书）**
```
ρ_anom(S) = (TPR@FPR=α, FAR_shift, IoU_loc, τ_detect, abstain_rate)
J⁺ = (ρ, ρ_anom, A_cert, Anom_Cert, γ_ce, δ_a, evidence)
```
部署条件：
```
dom_{J⁺}(T)=in ∧ δ_a < Θ_a ∧ TPR@α ≥ θ_anom ∧ FAR_shift ≤ θ_far
```
`J⁺` 是第 54 轮 `J` 的严格扩展：可部署性不再只看“已知维度鲁棒”，还要看“未知异常可发现、可定位、可恢复”。

**定义 127（异常记忆与反事实合成）**
异常记忆 `M_anom = {(o, τ, label, w, task)}`。反事实合成器 `S_anom = Gen(o, τ, R, T)` 将正常观测编辑为指定类型异常。校准集迭代：
```
D_cal^{t+1} = filter_realism( D_cal^t ∪ Active(M_anom) ∪ Gen_counterfactual(·) )
```
漂移统计 `D_shift = d(P_t(o), P_cal(o))`，超过阈值 `Θ_shift` 时触发加权保形与重校准。

## 2. 关键算法 伪代码

### IP-121 CVA（Conformal VLM Anomaly scoring）

```python
def cva_score(vlm, o, T, a, geom, proc, lam=(0.5, 0.3, 0.2)):
    s_sem = vlm.plausibility(o, prompt=prompt_for(T, a))
    s_geo = geom.residual(o, T, a)
    s_proc = proc.residual(o, T, a)
    return lam[0]*(1-s_sem) + lam[1]*s_geo + lam[2]*s_proc

def conformal_pvalue(s, calib_scores):
    n = len(calib_scores)
    return (1 + sum(1 for si in calib_scores if si >= s)) / (n + 1)

def detect(o, T, a, model, calib, alpha):
    s = cva_score(model.vlm, o, T, a, model.geom, model.proc)
    p = conformal_pvalue(s, calib.scores(T))
    return (p < alpha), p, s
```

### IP-122 TEV（Task-conditioned Expectation Violation）

```python
def expectation_graph(T, a, ontology, memory):
    return ExpectationGraph(
        objects=ontology.expected_objects(T, a),
        relations=ontology.expected_relations(T, a),
        prereqs=ontology.expected_prereqs(T, a),
        allowed=ontology.allowed_objects(T, a))

def tev_residual(o, E_exp):
    obs = parse_scene_graph(o)
    missing    = E_exp.objects - obs.objects
    unexpected = obs.objects - E_exp.allowed
    rel_err    = normalize(graph_edit_distance(obs.relations, E_exp.relations))
    proc_err   = [p for p in E_exp.prereqs if not obs.satisfies(p)]
    return dict(missing=missing, unexpected=unexpected,
                rel=rel_err, proc=proc_err)
```

### IP-123 A2A（Anomaly-to-Action bridge）

```python
def anomaly_to_action(cert, skills, theta_loc, theta_rec, tau_rec):
    cands = [s for s in skills
             if localize_iou(s.alpha, cert.R_anom) >= theta_loc
             and s.M_anom[cert.tau_type] >= theta_rec
             and transition_cost(s, cert.a_cur) <= tau_rec]
    if not cands:
        return ('escalate', cert, None)
    s_star = min(cands, key=lambda s: recovery_cost(s, cert))
    return ('recover', s_star, extend(cert, a_recover=s_star))
```

### IP-124 ARM（Anomaly Robustness Metric）

```python
def anomaly_robustness(detector, D_anom, D_benign):
    tpr = mean(detector.detect(o).flag for o in D_anom)
    far = mean(detector.detect(o).flag for o in D_benign)
    iou = mean(localize_iou(detector.detect(o).R_anom, o.gt_region) for o in D_anom)
    lat = mean(detector.detect(o).latency for o in D_anom + D_benign)
    return AnomRho(tpr=tpr, far=far, iou=iou, latency=lat,
                   abstain=detector.abstain_rate)
```

### IP-125 ACL（Anomaly Continual Learning）

```python
def anomaly_continual_learn(M, gen, validator, budget, alpha):
    queries = active_query(M, criterion='boundary_uncertainty')
    synthetic = []
    for o, tau, R, T in queries:
        for _ in range(budget):
            o2 = gen.counterfactual(o, tau, R, T)
            if validator.realistic(o2) and validator.label_consistent(o2, tau):
                synthetic.append((o2, tau, T))
    M = M ∪ queries ∪ synthetic
    calib = weighted_conformal_fit(M, alpha)
    return M, calib
```

### IP-126 EAC（Edge-Anomaly-Cloud coordination）

```python
def edge_cloud_anomaly(o, T, a, edge, cloud, alpha_low, alpha_high, tau_a):
    p, s = edge.detect(o, T, a)
    if p >= alpha_high:
        return ('normal', None)                       # 高 p 值：正常
    if p >= alpha_low:
        verdict = cloud.verify(o, T, a, timeout=tau_a) # 不确定带：云端仲裁
        return ('arbitrated', verdict)
    return ('anomaly', edge.build_cert(o, T, a, p))    # 低 p 值：本地快反
```

### IP-127 ACO（Anomaly-aware Composition）

```python
def anomaly_aware_compose(G, T, A_T, theta_anom, anom_budget):
    for e in G.edges:
        e.risk = e.P_anom * (1 - e.recovery_coverage)
    path = a_star(G, start='root', goal=T,
                  cost=lambda e: cost_align(e) + w_anom * e.risk)
    rho_a = compose_anom_robustness([s.rho_anom for s in path])
    if rho_a.tpr < theta_anom or path.recovery_coverage < 1 - anom_budget:
        return ('reject', 'anomaly_risk', path)
    return ('ok', path, J_plus(path, rho_a))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| CVA | O(\|R\|·C_VLM + n log n) | O(n) | 校准可交换、分数单调 |
| TEV | O(\|O\|+\|R\|+\|E_exp\|) | O(\|E_exp\|) | 期望图 sound、本体覆盖 |
| A2A | O(\|S\|·\|A\|) | O(\|S\|·\|A\|) | 桥接覆盖、恢复成本有界 |
| ARM | O((\|D_anom\|+\|D_benign\|)·C_det) | O(\|D\|) | 指标无偏、FPR 口径一致 |
| ACL | O(budget·C_gen + n log n) | O(\|M\|) | 合成真实、校准不退化 |
| EAC | O(C_edge + q·C_cloud) | O(1) | 仲裁时延 ≤ τ_a |
| ACO | O(\|V\| log\|V\| + \|E\|) | O(\|V\|+\|E\|) | 风险单调、路径最优 |

**正确性定理（Anomaly-Aware Embodied Deployment Soundness）**
承接第 54 轮 (A26)–(A28)，并新增：
**(A29)** 在给定任务上下文内，校准与测试可交换；或漂移受密度比上界 `W` 约束；
**(A30)** `s_anom` 对异常强度单调（语义分数不与物理异常反序）；
**(A31)** 语义、几何、程序三类残差互补，至少一类对给定异常类型可靠（覆盖假设）；
**(A32)** A2A 桥接对可检测异常存在恢复技能，`M_anom ≥ θ_rec` 且恢复成本 `≤ τ_rec`；
**(A33)** 云边仲裁延迟 `≤ τ_a`，且漂移触发重校准窗口内异常率有界。
则部署成功概率：
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a) - P(compat<θ_a)
             - (1 - TPR_LB) - β_rec - α_eff·γ_FA
```
其中 `α_eff = min(1, W·α)` 为漂移下有效误报率，`TPR_LB` 为校准集上召回率的置信下界，`β_rec` 为恢复失败概率，`γ_FA` 为一次误报造成的性能损失（若误报仅触发保守复核，则 `γ_FA ≈ 0`）。关键：**误报有统计上界，漏报要靠 TPR_LB 与互补残差兜底，恢复失败必须显式计入**。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| VLM 语义流畅 ≠ 物理正确 | 高 | 几何/程序残差交叉验证 + 保形弃权 |
| 具身漂移破坏保形可交换性 | 高 | 加权保形 + 漂移检测 + 窗口重校准 |
| 开放本体长尾异常漏检 | 高 | 反事实合成 + 主动困难负样本 + 云端仲裁 |

| 云边带宽/延迟超预算 | 中 | 蒸馏边端头 + 事件触发上传 + 语义压缩 |
| 合成不真实污染校准 | 高 | 真实性验证器 + 留出集 + 影响力剔除 |

## 6. 本轮最大风险

**一句话**：VLM 语义先验 + 保形异常检测让体系第一次具备“发现未知偏离并给出可执行恢复”的能力，但其 soundness **几乎完全押在保形可交换性与 VLM 语义分数同物理异常的同序性**上；一旦具身分布漂移使可交换性失效、或 VLM 把语言上常见但物理上致命的场景判为正常，漏检会绕过所有证书变成 **静默失败**——这比误报更危险，故必须以 **加权保形 + 几何/程序互补残差 + 高严重度异常强制云端仲裁** 三重护栏，宁可高频弃权，绝不把“语义上说得通”当作“物理上安全”。

## 2. 关键算法 伪代码

### IP-121 DRT（Dynamics Reachability Tube）

```python
def dynamics_envelope(skill, dims, T, rho_min, grid):
    # 混合系统鲁棒前向可达集：外逼近 + 分解 + SOS/区间松弛
    E = {d: approx_reachable(skill, d, T, rho_min[d]) for d in dims}
    E_core = reduce(intersection, E.values())
    delta = {x: safety_margin(skill, x) for x in E_core}
    return E, E_core, delta

def approx_reachable(skill, d, T, rho_min):
    # 返回真实可达集的外逼近，禁止内逼近用于安全判据
    return solve_viability(skill.f, skill.U, skill.W,
                           skill.Inv_S, T, rho_min, mode='outer')
```

### IP-122 DCG（Dynamics Composition Graph）

```python
def build_dynamic_graph(skills, theta_d, tau_dwell, B_budget):
    G = nx.DiGraph()
    for i, s1 in enumerate(skills):
        for j, s2 in enumerate(skills):
            if i == j: continue
            Sigma = switching_manifold(s1, s2)
            Tij = transition_tube(s1, s2, Sigma, tau_dwell)
            if not Tij: continue
            lam = contraction_rate(switched_field(s1, s2), Sigma, Tij)
            e_sw = switching_energy(Tij)
            compat = envelope_overlap(s1.E_core, s2.E_core, Tij)
            if compat >= theta_d and lam > 0 and e_sw <= B_budget:
                rho = compose_coop_spectrum(s1.rho, s2.rho, K_dyn)
                G.add_edge(i, j, compat=compat, lam=lam,
                           E_switch=e_sw, rho_coop=rho, tube=Tij)
    return G
```

### IP-123 CSC（Cooperative Synthesis & Contract）

```python
def synthesize_coop_contract(G, agents, tau_max, metrics):
    controller = design_interconnection(G, agents, metrics)
    nu = {i: passivity_index(agents[i], controller) for i in agents}
    lam_min = min_contraction_rate(controller, metrics)
    tau_margin = delay_margin_from_passivity(nu, controller)
    B = {i: init_energy_tank(agents[i]) for i in agents}
    if sum(nu.values()) <= 0 or lam_min <= 0 or tau_max > tau_margin:
        return ('reject', 'interconnection_not_passive',
                dict(nu=nu, lam=lam_min, tau_margin=tau_margin))
    return ('ok', CCoop(G, nu, B, metrics, lam_min, tau_margin))
```

### IP-124 DCC（Dynamical-Cooperative Certificate）

```python
def joint_dyn_coop_certificate(seq, contract, gamma_ce, budgets):
    E_core = reduce(intersection, [s.E_core for s in seq])
    if not E_core:
        return ('reject', 'empty_envelope')
    rho_coop = compose_coop_spectrum_chain([s.rho for s in seq], K_dyn)
    A_cert = action_certificate(seq, gamma_ce)
    nu_min, B_min = min(contract.nu.values()), min(contract.B.values())
    if (nu_min <= 0 or contract.lam_min <= 0
            or budgets.tau_max >= contract.tau_margin
            or B_min < 0 or min(rho_coop.values()) < budgets.rho_min):
        return ('reject', 'coop_or_dynamics_fail',
                dict(nu_min=nu_min, lam=contract.lam_min,
                     tau=contract.tau_margin, B_min=B_min))
    return ('ok', JDC(E_core, rho_coop, A_cert, gamma_ce,
                      nu_min, contract.lam_min,
                      contract.tau_margin, B_min, evidence=collect_evidence()))
```

### IP-125 DRP（Dynamics ReProfiling）

```python
def dynamics_reprofile(skill_seq, E_old, signature, eps_lam):
    for cand in propose_reprofiles(signature):  # 收缩包络/增驻留/降增益/扩容
        E_new, rho_new = recompute_envelope(cand, signature)
        lam_new = estimate_contraction(cand)
        B_new = update_energy_tanks(cand, signature)
        tau_new = delay_margin_from_passivity(cand)
        if (subset(E_new, E_old) and lam_new >= lam_old - eps_lam
                and min(B_new.values()) >= 0 and tau_new >= signature.tau_max):
            return ('ok', cand, E_new, rho_new)
    return ('reject', 'no_monotone_reprofile')
```

### IP-126 PES（Passivity-Energy Supervisor）

```python
def energy_supervise(B, nu, y, u, delay, tau_limit, kappa):
    B_new = B + nu * norm(y)**2 - norm(u)**2 - kappa * (delay > tau_limit)
    if B_new < 0:
        return downgrade_mode(gain_scale=0.5, dwell_scale=2.0), B_new
    return keep_mode(), B_new
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| DRT | O(|grid|·VI(T))，高维最坏 O(exp(dim M)) | O(|M|) | 外逼近 sound、约束保守 |
| DCG | O(|S|²·|Σ|·sim(T)) | O(|S|²+|E|) | 转移管非空、收缩率正、能量闭合 |
| CSC | O(iter·(|E_H|+|V|)·dim M) | O(|V|+|E_H|) | 无源性可测、延迟裕度保守 |
| DCC | O(|S|·|M|+|𝔇_dyn|) | O(|M|+|𝔇_dyn|) | 包络非空、互联稳定证明 |
| DRP | O(|cand|·(|M|+sim)) | O(|M|) | 单调收缩、收缩不退化、能量可行 |
| PES | O(|V|) 每步 | O(|V|) | 能量罐非负、降级可回滚 |

**正确性定理（Dynamical-Cooperative Composition Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** 每个技能在 `E_core` 上关于 `M_c` 增量收缩，`λ_i>0`；**(A30)** 互联满足 `Σ_i ν_i>0`；**(A31)** `τ_i≤τ_margin` 且 `B_i≥0`；**(A32)** `T_ij` 为真实切换可达集外逼近且 `τ_dwell≥τ_min`。则协同闭环在 `E_core` 上增量指数稳定，且
```
P_success ≥ 1 - P(E_core=∅) - P(Σν_i≤0) - P(τ_max>τ_margin)
             - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a) - P(B_min<0)
```
**关键**：先证可达、再证组合、最后证互联；静态动作兼容只在 `T_ij≠∅` 后作为次级判据。

## 6. 本轮最大风险

**一句话**：动力学包络与协同证书把“技能能做”升级为“状态可达且互联稳定”，但其 soundness **同时依赖高维可达集外逼近精度、无源/收缩假设在接触丰富任务上的成立、以及延迟裕度的在线保守估计**；一旦粗包络把不安全状态误判为 `E_core`、或无源证书在未建模接触与抖动延迟下失效，协同闭环会被“形式正确”的证书放行却在真实机器人上累积能量发散，故必须以 **可达性反例引导细化 + 硬件在环无源辨识 + 能量罐/延迟绊线** 三重护栏，宁可拒绝部署，绝不把相空间上的“可达假象”当作协同稳定的证明。
