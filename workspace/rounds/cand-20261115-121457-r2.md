# 第 6 轮（灵感循环第 6 轮；本轮灵感：「零样本泛化」×「痛点分析」）

> **基线**：第 5 轮 InstructGauge-RTDI（IP-334–339；定义 468–492；引理 63–68；实验 E473–E492）。第 1–4 轮 LeanGauge / MODGAUGE / ToolGauge / InstructGauge 骨架继续继承不变。
> 本轮纪律：**增量升级 + 严格退化**。零样本泛化与痛点分析各沿一条轴升级 RTDI，任一环节不可用都必须能一键退回 v5，两者是增强项、不是依赖项。

## 0. 直觉与动机

**灵感 1（零样本泛化 → 不是「猜得准」，而是「知道自己不知道」）**
直觉：人类专家第一次见到新任务，并不是凭空输出动作，而是把它拆成熟悉的「可供性 + 不变式」（能抓、能推、能照、能插），再用已知原语组合；一旦发现拆不动，就停下来问人。零样本泛化的真正难点不是覆盖率，而是**可审计的边界**：系统必须能说清「这次泛化建立在哪些已知原语/不变式上、覆盖了多少、哪里是猜的」。因此正确的口径不是「零样本 = 无先验」，而是「零样本 = 组合先验 + 显式新颖性证书」。这与 RTDI 的退化纪律天然一致：泛化失败不是崩溃，而是退回已知路径、降级为单步、或请求示范。

**灵感 2（痛点分析 → 把「扩库」从拍脑袋变成按痛点排序的投资）**
直觉：团队最常见的浪费是「哪里都能加点东西」，但真正的瓶颈往往集中在少数高严重度、高不可逆、高暴露的痛点上。痛点分析的价值是：从执行轨迹、FaultCert、失败日志里聚类出痛点，用 `暴露 × 严重度 × (1 + λ·不可逆)` 排序，再把有限的原语获取预算投到「单位成本覆盖增益最大」的洞上。它同时是对研究本身的元分析：本轮最大的痛点不是能力不够，而是**自信地做错**。

**灵感 3（两者耦合 → 痛点定义「覆盖前沿」，零样本在边界上必须自我否决）**
直觉：零样本引擎会说「这个任务我可以组合出来」，痛点分析会说「这类失败以前发生过」。把两者接起来：痛点图给出「已知的坏」，新颖性证书给出「未知的险」。最危险的是二者都缺席时的「自信盲区」——既不在痛点图上，又没被新颖性检测拦住。解法是三根支柱：**组合覆盖证书**（每次零样本执行都附带覆盖度与依据）、**新颖性闸门**（覆盖不足或离流形过远时拒绝/退回/求示范）、**痛点排序获取**（预算优先补最痛的洞）。核心纪律：**未知不可怕，未知而自信才可怕**。

## 1. 研究问题（本轮要回答什么）

- **Q1（可审计泛化）**：能否让每次零样本执行都携带「组合覆盖证书」，把泛化能力变成可检查的对象，而不是黑箱自信？
- **Q2（痛点驱动）**：如何从部署轨迹中稳定挖掘痛点，并转成有预算约束的获取计划，且收益可度量、可复现？
- **Q3（耦合边界）**：如何用新颖性检测压住「自信地做错」，使零样本在不可逆或低覆盖场景下**必然**自我否决？

## 2. 四条设计原则（雏形，正式化见产物区定义 493–516）

**P1 组合覆盖（Compositional Coverage）**
零样本任务必须能分解为「预注册原语 + 不变式签名」的合法前后置链；不能分解的部分显式标记为「未覆盖」，**绝不静默补全**。形式化方向：`Cover(κ, Π)` 取所有合法分解的最大加权签名匹配度，并附带 `uncovered_slots`。

**P2 新颖性证书（Novelty Certificate）**
每个任务额外输出「覆盖度 + 离已知任务流形的距离 + 决策」四元组 `(cover, d_man, class, decision)`，决策集为 `{EXEC, EXEC_K1, FALLBACK, REFUSE, DEMO}`。硬规则：**不可逆且 cover < 1 ⇒ REFUSE**，优先于其他所有分支。

**P3 痛点排序获取（Pain-Ranked Acquisition）**
扩库按痛点排序投资：`rank = 暴露 × 严重度 × (1 + λ·不可逆)`；原语选择按 `Σ rank·Δcover / cost` 贪心。这把「加什么」从经验判断变成带回溯记录的优化问题。

**P4 不变式迁移（Invariant Transfer）**
跨对象、跨具身迁移靠「可供性-关系不变式」而非类别标签；标签缺失不构成失败理由。形式化方向：对象签名 `σ(o) = (几何, 材质, 可供性, 关系)`，与已知原语签名距离足够近即可绑定。

## 3. 与基线的接口（如何退化）

- 新颖性检测 / 覆盖证书不可用 ⇒ 只走 v5 已注册任务路径（保守拒绝未知）；
- 痛点图不可用 ⇒ 原语库冻结为 v5 版本（无痛点驱动扩库）；
- 组合分解失败 / 类型检查失败 ⇒ 退 v5 单指令 NLI-Box；
- 可观性签名不可用 ⇒ 仅用已注册类别，退 v5 接地；
- 零样本引擎失效 ⇒ 退 v5 RTDI；RTDI 失效 ⇒ v4 InstructGauge-WR；后续同前代退化链。

## 4. 预期贡献

1. 一个「组合覆盖 + 新颖性证书」的可审计零样本口径，把泛化从黑箱自信变成可检查对象；
2. 一个痛点挖掘与排序获取闭环，把扩库从经验行为变成有预算、有近似的投资决策；
3. 一条「未知而自信」的硬闸门，保证不可逆场景永不靠猜；
4. 一条完整可证伪路径：E493–E512 覆盖组合泛化、未见对象、新颖性检测、覆盖校准、拒绝安全、痛点获取、跨具身、对抗注入与 50Hz 保全。

## 5. 本轮最大风险

**一句话**：覆盖度是系统自证的（签名匹配），可能与真实语义正确性脱钩；痛点图只覆盖「已发生过的痛」，对真正的未知未知天然失明——两者叠加会制造「高覆盖 + 低痛点」的虚假安全感，让罕见但灾难性的 OOD 任务恰好穿过新颖性闸门被自信执行。

## 2. 形式化定义（要点）

**定义 493（痛点 PainPoint 与痛点图 PainMap）**
对轨迹集 `T = {τ_i}` 抽取失败/降级特征 `x_i = (failure_type, task_family, object_class, reversibility, latency, recovery_cost)`，密度聚类得 `C = {C_j}`。对每个簇：
```
pp_j = (repr_j, S_j, F_j, I_j, E_j)
S_j ∈ [1,5]                  // 严重度，由 FaultCert 等级 + 人工抽检校准
F_j = |C_j| / |T|            // 频率
I_j = 1[簇内含不可逆失败]      // 不可逆指示
E_j = 该任务族暴露 / 总暴露     // 暴露
rank(pp_j) = E_j · S_j · (1 + λ·I_j),  λ ≥ 1
PainMap = sort_{j}({pp_j}, key = rank ↓)
```

**定义 494（组合覆盖度 CompositionalCoverage）**
任务实例 `κ`。分解 `d = (π₁…π_k) ∈ Decomp(κ, Π)` 当且仅当：
```
pre(π₁) ⊆ s,
post(π_i) ⊨ pre(π_{i+1})  (1 ≤ i < k),
post(π_k) ⊨ ψ_goal(ℓ)
```
签名匹配 `μ(π, κ) ∈ [0,1]` 综合前/后置满足、可供性匹配与关系不变式吻合度。则：
```
Cover(κ, Π) = max_{d∈Decomp(κ,Π)} (1/k) Σ_{i=1..k} μ(π_i, κ)
Decomp(κ,Π)=∅ ⇒ Cover = 0
CoverageCert(κ) = (κ.id, d*, Cover, {μ_i}, {slot | μ_i < τ_μ})
```

**定义 495（新颖性证书与闸门 NoveltyCertifier）**
设已知任务流形 `M_known`，`d_man(κ)` 为到 `M_known` 的 k-NN 距离（按局部尺度归一）。阈值 `τ_cov, τ_nov`：
```
if κ.irr and Cover(κ,Π) < 1:            decision = REFUSE     // 硬规则，最高优先
elif Cover = 1 and d_man ≤ τ_nov:       decision = EXEC
elif Cover ≥ τ_cov and d_man > τ_nov:   decision = EXEC_K1    // 强制 K=1，加强监控
elif Cover ≥ τ_cov:                     decision = FALLBACK   // 退回最近已知任务 / ι₀
else:                                   decision = DEMO       // 求人示范，不发动作
NoveltyCert = (Cover, d_man, class(κ), decision)
```

**定义 496（可供性签名与不变式迁移 AffordanceSignature）**
对象 `o` 的签名 `σ(o) = (g_geo, m_mat, a_grasp, r_rel)`：几何描述子、材质/反光/摩擦代理、可供性向量（可抓/可推/可吸/可照）、与场景锚点的关系图。零样本绑定：
```
o 未注册，若 ∃π ∈ Π 使 dist(σ(o), σ_ref(π)) ≤ τ_sig
则绑定 j(π, o)，无需类别标签。
```

**定义 497（痛点排序获取 PainDrivenAcquisition）**
候选原语集 `A`，预算 `B`，获取成本 `cost(π)`（示范次数/标注量/WCET 增量）。对 `π ∈ A`：
```
Δcover_j(π) = E_{κ∈family_j}[Cover(κ, Π∪{π}) - Cover(κ, Π)]
g(π) = ( Σ_j rank_j · Δcover_j(π) ) / cost(π)
贪心：Π_{t+1} = Π_t ∪ { argmax_{π∈A\Π_t} g(π) }，直到预算耗尽
AcquisitionPlan = (选中的 π 序列, 预期覆盖增益)
```

**定义 498（ZSP-6C 闭环扩展）**
```
W: 感知 (含 WristCam)
R: 推理 (Hypothesis + Γ_parse)
Front: 前沿闸门 (CompositionalCoverage + NoveltyCertifier)

# IP-340 痛点挖掘
class PainPointMiner:
    def __init__(self, lam=1.5, tau_min_cluster=5):
        self.lam = lam
        self.tau_min = tau_min_cluster

    def mine(self, traces, fault_certs):
        feats = [self._featurize(t, fault_certs) for t in traces]
        clusters = hdbscan(feats, min_cluster_size=self.tau_min)
        pain_map = []
        for c in clusters:
            S = self._severity(c)                 # FaultCert 等级 + 人工抽检校准
            F = len(c) / max(len(traces), 1)
            I = 1.0 if any(x.reversibility == 'irreversible' for x in c) else 0.0
            E = self._exposure(c)
            rank = E * S * (1 + self.lam * I)
            pain_map.append(PainPoint(repr=c.medoid, S=S, F=F, I=I, E=E, rank=rank))
        return sorted(pain_map, key=lambda p: -p.rank)

    def _featurize(self, trace, fault_certs):
        return Feature(
            failure_type=trace.failure_type,
            task_family=trace.task_family,
            object_class=trace.object_class,
            reversibility=trace.reversibility,
            latency=trace.latency,
            recovery_cost=trace.recovery_cost,
        )

# IP-341 组合覆盖证书
class CompositionalCoverage:
    def __init__(self, primitive_lib, tau_mu=0.6, beam=32):
        self.Pi = primitive_lib
        self.tau_mu = tau_mu
        self.beam = beam

    def cover(self, kappa):
        decomps = self._beam_decompositions(kappa, self.Pi, self.beam)
        if not decomps:
            return CoverageCert(kappa.id, None, 0.0, [], kappa.slots)
        best = max(decomps, key=lambda d: self._score(d, kappa))
        mus = [self._mu(pi, kappa) for pi in best]
        uncovered = [slot for slot, mu in zip(kappa.slots, mus) if mu < self.tau_mu]
        return CoverageCert(kappa.id, best, sum(mus) / len(mus), mus, uncovered)

    def _score(self, d, kappa):
        return sum(self._mu(pi, kappa) for pi in d) / len(d)

    def _mu(self, pi, kappa):
        pre_ok = self._pre_covered(pi.pre, kappa.s)
        post_ok = self._goal_entailed(pi.post, kappa.goal)
        aff_ok = self._affordance_match(pi.afford, kappa.s)
        rel_ok = self._invariant_match(pi.inv, kappa.s)
        return 0.25 * (pre_ok + post_ok + aff_ok + rel_ok)

# IP-342 新颖性证书与闸门
class NoveltyCertifier:
    def __init__(self, known_manifold, tau_cov=0.8, tau_nov=1.0):
        self.M = known_manifold
        self.tau_cov = tau_cov
        self.tau_nov = tau_nov

    def certify(self, kappa, cover_cert):
        cover = cover_cert.cover
        d_man = self.M.knn_distance(kappa) / self.M.local_scale(kappa)
        if kappa.irr and cover < 1.0:
            return NoveltyCert(cover, d_man, 'irreversible', 'REFUSE')
        if cover >= 1.0 and d_man <= self.tau_nov:
            return NoveltyCert(cover, d_man, 'known', 'EXEC')
        if cover >= self.tau_cov and d_man > self.tau_nov:
            return NoveltyCert(cover, d_man, 'novel_scene', 'EXEC_K1')
        if cover >= self.tau_cov:
            return NoveltyCert(cover, d_man, 'partial', 'FALLBACK')
        return NoveltyCert(cover, d_man, 'unknown',
                           'REFUSE' if kappa.irr else 'DEMO')

# IP-343 不变式签名迁移
class AffordanceGrounder:
    def __init__(self, primitive_lib, tau_sig=0.25):
        self.Pi = primitive_lib
        self.tau_sig = tau_sig

    def signature(self, obj):
        return Signature(
            g_geo=self._geometry_descriptor(obj),
            m_mat=self._material_proxy(obj),
            a_grasp=self._affordance_vector(obj),
            r_rel=self._relation_graph(obj),
        )

    def bind_zero_shot(self, obj, Pi):
        sig = self.signature(obj)
        best, best_d = None, float('inf')
        for pi in Pi:
            d = sig_distance(sig, pi.sigma_ref)
            if d < best_d:
                best, best_d = pi, d
        if best is not None and best_d <= self.tau_sig:
            return best, best_d
        return None, best_d          # 未绑定 ⇒ 走 DEMO/FALLBACK

# IP-344 痛点排序获取
class PainDrivenAcquisition:
    def __init__(self, candidates, cost_fn):
        self.A = candidates
        self.cost = cost_fn

    def plan(self, pain_map, Pi, budget):
        selected, spent = [], 0.0
        while True:
            best, best_g = None, -1.0
            for pi in self.A:
                if pi in selected:
                    continue
                dc = self._expected_gain(pi, pain_map, Pi)
                g = sum(p.rank * d for p, d in zip(pain_map, dc)) / self.cost(pi)
                if g > best_g:
                    best, best_g = pi, g
            if best is None or spent + self.cost(best) > budget:
                break
            selected.append(best)
            spent += self.cost(best)
            Pi = Pi | {best}
        return AcquisitionPlan(selected, spent)

    def _expected_gain(self, pi, pain_map, Pi):
        return [self._cover_delta(pp, pi, Pi) for pp in pain_map]

    # 1. 解析 + 组合覆盖
    G_tau = M.pgraph.parse(ell)                          # v5 双阶段接地
    kappa = TaskInstance(ell, M.scene, slots=G_tau.slots,
                         irr=G_tau.has_irreversible())
    cover_cert = M.coverage.cover(kappa)

    # 2. 新颖性闸门（含不可逆硬拒绝）
    nov = M.novelty.certify(kappa, cover_cert)
    if nov.decision == 'REFUSE':
        return Refusal(kappa, cover_cert, nov)            # 不执行任何动作
    if nov.decision == 'DEMO':
        M.demo_queue.push(kappa); return RequestDemo(kappa, nov)
    if nov.decision == 'FALLBACK':
        iota_seq = [M.default_iota]                       # 退回 v5 默认目标
        K_max = 1
    else:
        iota_seq = M.pgraph.instantiate(G_tau, M.scene)
        for iota in iota_seq:
            if iota.unresolved_object is not None:        # 零样本对象绑定
                pi, d = M.affordance.bind_zero_shot(iota.unresolved_object,
                                                    M.pgraph.Pi)
                if pi is None:
                    return RequestDemo(kappa, nov)
                iota.bind(pi, d)
        K_max = 1 if nov.decision == 'EXEC_K1' else M.iac.max_chunk

    # 3. 规划（块长受 decision 约束）+ RTDI 执行
    C = M.iac.plan_chunk(iota_seq[0], H=None, tools=M.tools,
                         budget=K_max, drift=M.drift_bound(s))
    result = M.rtdi.execute(C, iota_seq, kappa)          # 复用 v5 实时执行/证书/恢复

    # 4. 轨迹回流：痛点挖掘 + 周期获取
    M.pain_miner.ingest(result.trace, result.fault_certs)
    if M.acquisition_due():
        plan = M.pain_planner.plan(M.pain_map, M.pgraph.Pi,
                                   M.candidates, M.budget)
        M.pgraph.add_primitives(plan)                     # 下一轮生效，不热改在建块
    M.known_manifold.update(kappa, cover_cert, result)
    return result
```

## 4. 推导

**引理 69（零样本执行的能力闭包与后置保持）** 若 `decision ∈ {EXEC, EXEC_K1}` 且 `Cover(κ,Π)=1`、所选分解的前后置链验证通过，则由该分解实例化的 `ι_seq` 满足 `tools(ι_seq) ⊆ T₀`，且执行成功时 `post(π_k) ⊨ ψ_goal(ℓ)`。证明：分解定义给出前后置链式蕴含，故后置逐级传递至目标；每个 `π∈Π` 预注册满足 `tools(π) ⊆ T₀`（引理 66 的能力闭包），并集仍在 `T₀` 内；零样本对象绑定只替换参数、不新增工具。

**引理 70（覆盖前沿单调性）** 对任意 κ，`Π₁ ⊆ Π₂ ⇒ Cover(κ,Π₁) ≤ Cover(κ,Π₂)`。证明：`Decomp(κ,Π₁) ⊆ Decomp(κ,Π₂)`，候选集单调扩张，最大值单调不减；对固定分解，签名匹配 `μ` 与原语库无关。故痛点排序获取只会让前沿外扩、不会内缩。

**引理 71（痛点排序获取的近似最优）** 若各 `Δcover_j(·)` 非负、单调、子模（submodular），则在预算约束下按 `Σ rank·Δcover / cost` 的贪心获取达到最优覆盖增益的 `1-1/e` 近似。证明：子模函数最大化（带代价）的贪心近似标准结论（Nemhauser–Wolsey–Fisher）；痛点排序是各 `Δcover_j` 的非负线性组合，非负加权保持子模性；代价归一化不改变子模结构，只改变选序。

**引理 72（拒绝安全性）** 若 κ 含不可逆动作且 `Cover(κ,Π) < 1`，则 `decision = REFUSE`，系统不执行任何动作。证明：定义 495 的不可逆硬规则先于其余分支求值，`REFUSE` 路径在算法骨架第 2 步即返回，未进入 `instantiate` 与 `execute`；因此不存在"未覆盖分解实例化出不可逆动作"的执行路径。

**引理 73（零样本退化等价）**
- 关闭 NoveltyCertifier / CompositionalCoverage ⇒ 仅接受 `Cover=1` 的已注册任务，行为等价 RTDI（diff = 0）；
- 关闭 PainDrivenAcquisition ⇒ `Π` 冻结为 v5 库，无痛点回流，行为等价 RTDI；
- 关闭 AffordanceGrounder ⇒ 只绑定已注册类别，未解析对象走 v5 的 FALLBACK；
- 全部关闭 ⇒ RTDI，后续同 v4/v3 退化链。
证明：逐条对照算法骨架的接线，关闭开关后所走分支与 v5 执行路径逐语句一致，随机源与调度顺序不变。

**引理 74（痛点挖掘稳定性，条件性）** 若特征空间有界、密度估计一致，且聚类采用固定 `min_cluster_size` 的密度聚类，则样本量 n 下聚类偏差为 `O(√(d/n))`；由于 `rank` 对 `(S,F,I,E)` 连续且局部 Lipschitz，前 m 名痛点集合在重采样下以高概率稳定。证明思路：密度估计一致性 + rank 的 Lipschitz 连续性 + 有限样本集中不等式。**注**：该引理依赖分布平稳假设，分布漂移时需触发重挖（E508）。

## 8. 本轮最大风险

**一句话**：覆盖度由系统自证的签名匹配给出，可能与真实语义正确性脱钩；痛点图又只覆盖「已发生过的痛」，对真正的未知未知天然失明——两者叠加会制造「高覆盖 + 低痛点」的虚假安全感，让罕见但灾难性的 OOD 任务恰好同时躲过新颖性闸门与痛点预警而被自信执行；缓解必须落在**外部锚**上：不可逆硬拒绝、独立语义验证器、以及按保守共形下界而非点估计来驱动 `EXEC` 决策。
