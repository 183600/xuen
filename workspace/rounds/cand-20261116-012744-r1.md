# 第 10 轮（灵感循环续；本轮灵感：「分布外泛化」×「夹爪控制」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**分布外泛化 + 接触感知夹爪**。两个灵感分别治理 v9 的两处软肋：(a) 块证书的 β 是"信任域内"离线标定的常数，而信任域门控 Δ_dom 有 20 帧滑窗滞后；(b) 抓取证书 γ̂_grasp 只是一个布尔量，而夹爪接触动力学恰恰是最 OOD、最不该用布尔量担保的地方。总纪律：**共形只增补、不替换**——共形模块失效即注入 v9 的固定 β / 布尔 γ，逐位等价退回 v9（引理 91），而非行为漂移。

## 0. 直觉与动机

**灵感 1（分布外泛化 → 共形信任域）**
直觉：v9 的块证书把安全寄托在"信任域内前向模型误差 ≤ β"这一假设上，但 β 是离线标定常数，而真正危险的是分布已经变了、DA-ML 却还没报。分布外泛化的正确工具不是"训练一个更强的模型去外推"，而是**不做模型分布假设、只对残差做分布无关的覆盖保证**。共形预测（conformal prediction）恰好提供这一点：用非一致性分数 s = max_k(ĝ_k − g_k) 的校准分位数 q̂ 作为安全下界，只需层内可交换性即可给出有限样本覆盖 P(g_min ≥ ĝ_min − q̂) ≥ 1−α；再用自适应共形推断（ACI）在线更新 α_t，可在**任意分布漂移**下保持长期覆盖率。于是 β 从常数变成随残差自动膨胀/收缩的 q̂_t：模型在陌生域变差时，证书自己变宽、K_eff 自己变短，**不再依赖 DA-ML 先报警**。核心创新：**共形信任校准器（ConformalTrustCalibrator, CTC）**。

**灵感 2（夹爪控制 → 接触感知的共形抓取证书 + 接触相位分段）**
直觉：抓取是整条任务里最接触密集、最容易 OOD 的环节——物体质量、摩擦、刚度、几何训练时没见过，前向模型在接触瞬间误差最大。v9 只用 γ̂_grasp∈{valid, invalid} 一个布尔量担保它，信息量太低。夹爪控制的正确做法是：把抓取的物理裕度显式化——定义力裕度 m_g = μ̂F_n − F_t（摩擦上限减实际切向力），用共形下界 m_low 给出"抬升阶段不打滑"的分布无关置信；用触觉/力信号做滑移前兆检测与阻抗力钳。并让一个物理事实指导分块：**动作块绝不跨越接触相位边界**（接近→接触→闭合→抬升→搬运→释放），接触切换处强制 K=1，因为那里正是前向模型最不可信、中止点最易失效的地方。核心创新：**共形抓取证书器（ConformalGraspCertifier, CGC）** + **接触相位分段器（ContactPhaseSegmenter, CPS）**，以及支撑**分层共形校准**的**抓取支撑集记忆（GraspSupportMemory, GSM）**——按物体/触觉簇分组校准，组内样本不足时保守回退池化。

## 1. 研究问题（轮次升级版）

- **Q1（共形安全性）**：非一致性分数 s = max_k(ĝ_k − g_k) 的共形下界能否在块级粒度上给出可信的安全证书？ACI 的长期覆盖保证在突变 OOD 起始的有限个块上意味着什么——覆盖率"平均"达标是否足以支撑单块安全？
- **Q2（夹爪 OOD 与抓取证书）**：力裕度的共形下界在摩擦/质量突变时是否仍覆盖？分层（Mondrian）校准能否把"新物体"从"新摩擦系数"中区分出来？接触相位分段能否把前向模型误差局部化到可校准的区间？
- **Q3（退化等价）**：CTC/CGC/GSM/CPS 任一失效时，注入 v9 的固定 β 与布尔 γ，能否逐位复现 v9 行为？共形证书与 v9 的分块证书在可观测层面如何对齐？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 共形安全下界律（Conformal Safety Lower Bound, CTC）**
块证书的最大安全量不是固定 β，而是校准集上非一致性分数 s = max_k(ĝ_k − g_k) 的 (1−α_t) 分位数 q̂_t：g_low = ĝ_min − q̂_t。α_t 按 ACI 更新 α_{t+1} = α_t + η(α − err_t)，err_t 为真实最小间隙是否跌破 g_low 的指示。共形只作用于"证书宽度"、不放松物理安全裕度：K_eff 与中止点集仍由 g_low ≥ d_safe 与停车不变式共同把关。

**P14 接触相位局部化律（Contact-Phase Locality, CPS）**
动作块须落在单一接触相位内；相位边界（接触起始/脱离）一律 K=1 逐步执行。理由：前向模型在接触相位切换处存在不可约的动力学不连续，跨度分块会使引理 82 的一致误差假设失效；把不连续移出块内，块证书的误差界才可局部标定。

**P15 抓取物理裕度律（Grasp Margin Certificate, CGC/GSM）**
抓取证书以力裕度 m_g = μ̂F_n − F_t 为核心，输出分层共形下界 m_low；有效 ⇔ m_low ≥ m_safe ∧ f_min ≤ F_n ≤ f_max ∧ 支撑集新义度 ρ_grip < τ_support。分层校准（按物体类别/触觉簇）保证组条件覆盖；组样本不足退回池化并做保守膨胀。

## 3. 与基线的接口（如何退化）

- CTC 失效 ⇒ q̂ ← β_v9（固定），K_eff 仍由 Δ_dom 门控，逐位等价 v9；
- CGC/GSM 失效 ⇒ γ ← γ̂_grasp（v9 布尔），抓取 K_eff ← 1 且仅保留保守力钳，等价 v9 抓取路径；
- CPS 失效 ⇒ 块可跨相位但 K_eff 整体减半（保守），安全仍由 v9 中止点集兜底；
- AC 失效 ⇒ K_eff ← 1，等价 v9 Level-1；
- MW 失效 ⇒ 切换 v8 手写网关代码路径，等价 v8 集成方式；
- ID 失效 ⇒ 全模块 active、归因冻结，等价 v9 全模块常开；
- v8 的 DA/SPR/Cal 任一失效 ⇒ 中立元注入（Δ_dom≡0 / risk_SLAM≡0 / sensor_weight≡1），等价 v7；全失效 ⇒ 完整退回 v6。

## 4. 预期贡献

1. **共形信任域**：把 v9 的固定 β 换成分布无关的共形分位数，用 ACI 获得任意漂移下的长期覆盖，直接缓解 v9"DA-ML 滞后 → 失效块仍取大 K"的最大风险；
2. **接触感知夹爪证书**：力裕度共形下界 + 分层校准 + 接触相位分段，将最 OOD 的抓取环节从布尔担保升级为带覆盖保证的物理裕度担保；
3. **共形-分块-契约三层叠加的严格退化**：新增模块全部可选，失效即注入 v9 值，保持逐位等价；
4. **新实验族 E571–E590**：共形覆盖/自适应/分层、抓取 OOD、接触相位、反应时延对照、长跑漂移、退化等价与端到端。

## 5. 本轮最大风险

**一句话**：共形证书给的是"层内可交换"的有限样本边际覆盖、ACI 给的是长期平均覆盖，而不是逐块最坏情况保证——在突变 OOD 起始的少数过渡块上覆盖率可以合法地跌破 1−α，而这恰是最危险的时刻；再叠加支撑集对"触觉传感器漂移"的误判，系统可能用一份"统计上正确、当块却失效"的证书为大 K 背书。

## 1. 符号体系增量（定义 540–549）

| 符号 | 含义 |
|---|---|
| s_t | 块级非一致性分数：s_t = max_{k≤K}(ĝ_k − g_k)（前向模型对最小间隙的最坏乐观偏差） |
| q̂_t | (1−α_t) 共形分位数，替代 v9 固定 β 的安全裕度校正量 |
| s^e_t | 用力上界非一致性：s^e_t = max_k(e_k − ê_k) |
| α_t | ACI 在线覆盖水平，α_{t+1} = clip(α_t + η(α − err_t), α_min, α_max) |
| m_g | 夹爪力裕度：m_g = μ̂ F_n − F_t（摩擦上限减实际切向力） |
| m_low | 力裕度的分层共形下界（Mondrian，必要时池化+膨胀） |
| ρ_grip | 支撑集新义度：φ_tac 到支撑集的第 k 近邻距离（或共形 p 值） |
| φ_tac | 触觉-物体嵌入（触觉阵列 + 力史 + 物体外观的编码） |
| ℘ | 接触相位集合 {APPROACH, CONTACT, CLOSE, LIFT, TRANSPORT, RELEASE} |
| W, W_cov, H_drift | 共形分数滑窗长度、覆盖监控窗、漂移触发连续窗数 |
| B_g | 层 g 的抓取支撑集（成功抓取的 φ_tac 记忆库） |

**新增定义 540（块级非一致性分数 ChunkConformityScore）** 对一次块执行，事后由实测轨迹计算
```
s = max_{k≤K}( ĝ_k − g_k )，   s^e = max_{k≤K}( e_k − ê_k )
```
s 度量前向模型对间隙的"最坏乐观偏差"，s^e 度量对力/能耗的"最坏低估"。二者分别进入间隙下界与力上界的共形校准（与 v9 定义 533 的 β 对应，但不再假设信任域）。

**新增定义 541（自适应共形推断 AdaptiveConformalInference, ACI）** 维护最近 W 个 s 的滑窗。q̂_t = 该滑窗在水平 1−α_t 的经验分位数；覆盖指示 err_t = 1[g_min,t < ĝ_min,t − q̂_t]。在线更新
```
α_{t+1} = clip( α_t + η(α − err_t), α_min, α_max )
```
冷启动或有效样本 < n_min 时 q̂_t ← β_v9（定义 533），保证与 v9 对齐。目标覆盖率 α 为预注册常数（默认 0.05）。

**新增定义 542（共形抓取证书 ConformalGraspCertificate）** 夹爪力裕度 m_g = μ̂ F_n − F_t（μ̂ 为标定/估计摩擦系数）。层 g 内共形下界
```
m_low^(g) = Q_{α_g}( {m_g^(i) : i ∈ 校准集 S_g, 未打滑} )
```
抓取证书有效 ⇔ m_low^(g) ≥ m_safe ∧ f_min ≤ F_n ≤ f_max ∧ ρ_grip < τ_support ∧ 力钳未触发。m_safe 为打滑安全余量（默认 0.15 N 当量）。

**新增定义 543（触觉支撑集与新义度 TactileSupportNovelty）** 成功抓取后把 φ_tac 存入 B_g。新观测的新义度
```
ρ_grip = d_(k)(φ_tac, B_g)          （第 k 近邻距离）
p_val  = (1 + #{b∈B_g : ‖φ−b‖ ≥ d_(1)}) / (|B_g|+1)   （共形 p 值，越小越陌生）
```
ρ_grip ≥ τ_support（或 p_val < α_novel）判为"支撑集外"，触发保守抓取模式与 K_eff ← 1。

**新增定义 544（夹爪力/阻抗安全钳 GripperForceSafetyClamp）** 低层命令力被钳制在 [f_min, f_max]，力变化率 |dF_n/dt| ≤ ṙ_max；采用阻抗控制 F = K_d (x_d − x) + D_d ẋ + F_ff，K_d/D_d 依刚度估计自适应。滑移前兆检测器（切向/法向比与微振动）须在 τ_slip ≤ 2 个控制周期内给出 re-grasp/abort 信号。

**新增定义 545（分层共形校准 StratifiedConformalCalibration）** 按物体类别或触觉簇分层，层 g 用 S_g 单独校准（Mondrian 组条件覆盖）。若 |S_g| < n_min，回退到池化集合，并把分位数向保守侧平移
```
m_low = Q_{α_g}(pooled) − sqrt( log(1/α_g) / max(1,|S_g|) )
```
确保小样本层不因乐观估计而误认证。

**新增定义 546（v10 有效块长 OOD 门控）**
```
K_eff(t) = 1                                                   若 ¬U_t ∨ ρ_grip ≥ τ_support
                                                               ∨ m_low < m_safe ∨ 相位边界
         = max(1, ⌊K_max·(1 − max(Δ_dom/τ_dom, ρ_grip/τ_support))⌋)   否则
```
并再与 CPS 的相位剩余步数取 min：K_eff ← min(K_eff, steps_in_phase)。K=1 即退回 v9/v8 逐步语义。

**新增定义 547（接触相位与相位块 ContactPhaseChunk）** 相位序列 ℘ 由触觉接触、夹爪开合、抬升高度与释放信号切分。一次块 ζ 必须 phase(ζ 起点) = phase(ζ 终点)；跨相位候选在生成期即被 CPS 封顶为 K=1。每个相位维护独立的中止点集与刹停模型（接触相位的刹停动力学与自由空间不同）。

**新增定义 548（共形重标定与漂移监测 ConformalRecalibration）** 滚动窗口 W_cov 上监控经验覆盖率；若连续 H_drift 个窗口覆盖率 < 1−α−δ_cov，触发用近期数据重标定（ACI 的 α_t 继续运行，不清空）。触觉嵌入均值漂移检测用于区分"新物体"（φ 远但分布连续）与"传感器漂移"（整体均值平移），后者强制进入保守抓取模式并要求线上下线复标。

**新增定义 549（退化注入映射 v10→v9）** 形式化三张注入表：CTC off ⇒ (q̂→β_v9, s 缓冲冻结)；CGC/GSM off ⇒ (γ→γ̂_grasp 布尔, 仅保留力钳, m_low→m_safe)；CPS off ⇒ (K_eff→⌊K_eff/2⌋, 相位=pseudo-single)。该映射是引理 91 的证明对象。

## 2. 形式化定义（要点与升级）

- **升级定义 496（软证书，v10）**：δ_trigger 在 v9 五条件（σ<τ_safe ∧ γ_grasp ∧ Δ_dom<τ_dom ∧ risk_SLAM<τ_SLAM ∧ Ĉ_t valid）基础上，把 `γ_grasp` 细化为 `m_low ≥ m_safe ∧ ρ_grip < τ_support`，把 `Ĉ_t valid` 细化为 `ĝ_min − q̂_t ≥ d_safe`；六条件同尺度触发 M₀ 硬检查，不留"块内软通过、硬失"空洞。
- **升级定义 531（软硬约束衔接）**：M₀ 判据增加抓取入口——力钳触发、滑移前兆或 m_low < m_safe 任一成立，立即 re-grasp 或切换最近中止点，不等块边界。
- **升级定义 533（块证书）**：固定 β 由定义 541 的 q̂_t 取代；证书分量变为 (g_low, e_high, m_low)，分别对应间隙下界、力上界、抓取裕度下界。
- **升级定义 534（中止点）**：中止点按相位分别构造，接触相位的刹停距离用接触动力学模型 d_brake^℘(v)，避免用自由空间刹停距离高估可行性。
- **升级定义 539（有效块长）**：由定义 546 取代，新增 ρ_grip、m_low 与相位封顶三项门控。

        self.n_min, self.beta_v9 = n_min, beta_v9
        self.alpha_t = alpha
        self.scores = deque(maxlen=W)         # 间隙非一致性
        self.e_scores = deque(maxlen=W)       # 力上界非一致性

    def chunk_score(self, g_hat, g_true, e_hat, e_true):
        s = max(gh - gt for gh, gt in zip(g_hat, g_true))
        se = max(et - eh for eh, et in zip(e_hat, e_true))
        return s, se

    def observe(self, s, se, miscovered):
        self.scores.append(s)
        self.e_scores.append(se)
        self.alpha_t = min(self.alpha_max,
                           max(self.alpha_min,
                               self.alpha_t + self.eta * (self.alpha - float(miscovered))))

    def _q(self, buf):
        if len(buf) < self.n_min:
            return self.beta_v9                  # 冷启动/退化：回到 v9 固定 β
        return quantile(buf, 1 - self.alpha_t)

    def lower_bound(self, g_hat_min):
        return g_hat_min - self._q(self.scores)

    def upper_bound(self, e_hat_max):
        return e_hat_max + self._q(self.e_scores)


# IP-358 ConformalGraspCertifier：共形抓取证书器
class ConformalGraspCertifier:
    def __init__(self, alpha_g=0.05, m_safe=0.15, f_min=5.0, f_max=45.0,
                 n_min=30, tau_support=0.35):
        self.alpha_g, self.m_safe = alpha_g, m_safe
        self.f_min, self.f_max = f_min, f_max
        self.n_min, self.tau_support = n_min, tau_support
        self.margins = defaultdict(list)          # stratum -> 校准力裕度

    def margin(self, Fn, Ft, mu_hat):
        return mu_hat * Fn - Ft

    def calibrate(self, stratum, m):
        self.margins[stratum].append(m)

    def lower_bound(self, stratum):
        pool = self.margins.get(stratum, [])
        if len(pool) >= self.n_min:
            return quantile(pool, self.alpha_g)          # 分层（Mondrian）
        pooled = [m for v in self.margins.values() for m in v]
        if not pooled:
            return -float('inf')                          # 无证据 ⇒ 不认证
        infl = math.sqrt(math.log(1 / self.alpha_g) / max(1, len(pool)))
        return quantile(pooled, self.alpha_g) - infl      # 池化 + 保守膨胀

    def certify(self, Fn, Ft, mu_hat, stratum, rho_grip, clamp_ok):
        m_low = self.lower_bound(stratum)
        ok = (m_low >= self.m_safe
              and rho_grip < self.tau_support
              and self.f_min <= Fn <= self.f_max
              and clamp_ok)
        return GraspCert(ok, m_low, rho_grip)


# IP-359 GraspSupportMemory：抓取支撑集记忆
class GraspSupportMemory:
    def __init__(self, k=5, alpha_novel=0.05):
        self.k, self.alpha_novel = k, alpha_novel
        self.bank = defaultdict(list)                # stratum -> [phi_tac]

    def add(self, stratum, phi):
        self.bank[stratum].append(phi)

    def novelty(self, stratum, phi):
        B = self.bank.get(stratum, [])
        if not B:
            return float('inf')
        d = sorted(np.linalg.norm(phi - b) for b in B)
        return d[min(self.k, len(d)) - 1]

    def pvalue(self, stratum, phi):
        B = self.bank.get(stratum, [])
        if not B:
            return 0.0
        d_new = min(np.linalg.norm(phi - b) for b in B)
        ge = sum(1 for b in B if np.linalg.norm(phi - b) >= d_new)
        return (1 + ge) / (len(B) + 1)

class ContactPhaseSegmenter:

## 4. 推导（引理 87–92）

**引理 87（共形安全下界，层内交换）** 设校准块与测试块在层 g 内可交换，非一致性分数 s_i = max_k(ĝ_k − g_k)，q̂ 取升序第 ⌈(n+1)(1−α)⌉ 位（越界取 ∞）。则 P(g_min ≥ ĝ_min − q̂) ≥ 1−α。证明：事件 g_min < ĝ_min − q̂ ⇔ s_test > q̂；由可交换性的秩统计，P(s_test > q̂) ≤ α。∎ 该式把 v9 定义 533 中"信任域内 ‖F̂−F‖∞ ≤ β"的模型假设换成对残差分位数的分布无关覆盖；代价是它只保证层内可交换意义下的**边际**覆盖，跨块强相关或工况突变时需引理 88 兜底。

**引理 88（ACI 长期覆盖与漂移自适应）** 在 ACI 更新 α_{t+1} = clip(α_t + η(α − err_t)) 下，长期平均误覆盖率相对 α 的偏差由 O(η) + O((α_max−α_min)/(ηT)) 界定（Gibbs–Candès 型结果，要求 err_t ∈ {0,1} 且 α_t 有界）。且当残差 s 增大时，滑窗经验分位数 q̂ 在至多 W 个块内上升，于是 g_low 下降、K_eff 收缩——**不依赖 DA-ML 先报警**。关键限定：该保证是长期/平均意义，不是单块最坏情况；突变 OOD 起始的过渡块可以合法地误覆盖。∎

**引理 89（夹爪共形抓取裕度界）** 层内交换下 P(m_g ≥ m_low) ≥ 1−α_g。若 m_low ≥ m_safe，则以 ≥1−α_g 概率实际施加力在摩擦锥内留有余量 m_safe，故在库仑模型 |F_t| ≤ μF_n 下抬升阶段不打滑。分层样本不足时用池化分位数减膨胀项，覆盖率按保守侧成立。∎ 限定：该界以 μ̂ 与准静态摩擦模型为条件；μ̂ 偏差与动态滑移不在覆盖内，需力钳（定义 544）给最坏界。

**引理 90（接触相位局部化）** 若块完全落在单一相位 ℘_i 内，则其动力学在块时域内局部连续，前向模型误差可按相位分层校准（q̂_{℘_i}），引理 82 的一致误差假设在相位内成立。若候选块跨相位边界，CPS 强制 K=1（定义 547），故不存在"块内含动力学不连续"的证书。于是 v9 中"跨接触突变"这一最坏误差源被系统性移出块内。∎

**引理 91（严格退化等价 v9）** CTC 关闭 ⇒ q̂ ← β_v9，g_low 退化为 v9 定义 533 的 ĝ_min − β；CGC/GSM 关闭 ⇒ γ ← γ̂_grasp（布尔）且仅保留力钳；CPS 关闭 ⇒ K_eff 按相位无关公式减半，但中止点集与执行逻辑不变。三个新端口都只做"值注入"，不改变下游算子，故可观测输出逐位等价 v9（复合引理 83）。∎

**引理 92（OOD 反应时延对照）** 新义度 ρ_grip 与共形分位数都由当前观测/已实现残差驱动，不经 20 帧滑窗。若分布跳变使 φ_tac 的 k-NN 距离在首周期越过 τ_support，则 ρ_grip(t) ≥ τ_support，K_eff(t)=1，先于 DA-ML 报警。形式上：当 ‖φ_t − φ_{t−1}‖ > 2τ_support 且支撑集半径 < τ_support 时该式成立。∎ 反例边界：若跳变只改隐藏动力学（如摩擦下降）而不改触觉嵌入，ρ_grip 不动，只能由 ACI 在首个误覆盖块之后把 q̂ 抬起修正——正是最大风险所指。
