# 第 55 轮（承接第 54 轮 v16++ GroundEdge-GenSim+++；灵感循环第 1 轮；本轮灵感：「知识图谱」×「动作空间」）

> 第 54 轮把技能刻画为动作空间剖面 `α_S`，用两两动作兼容性建技能组合图并做云边闭环。但它只回答 **局部能否接上**，没回答 **全局能否走通**：一条语义上合理、逐对兼容的技能路径，仍可能因动作空间拓扑受阻（禁区、连通分量、缠绕类）或语义-物理接地错位而整体不可执行。本轮引入 **动作接地知识图谱 AGKG**，用 **接地函子** 把语义路径与动作路径缝合，并以 **拓扑一致性证书** 与 **溯源式动态更新** 守护。

## 0. 直觉与动机

**灵感 1（知识图谱是离散骨架，动作空间是连续身体）**
直觉：知识图谱擅长表达长程语义结构（物体—部件—可供性—因果—先后），却不知道「手能不能真的转过去」；动作空间擅长表达连续可行域（关节、位形、接触、禁入区），却不知道「这串动作在任务语义上意味着什么」。把两者用 **接地边** `g=(c,a,κ)` 缝合，就得到 **动作接地知识图谱 AGKG**：语义节点与动作单元共处一图，每条语义边都必须在动作空间里有支撑集 `supp(e) ⊆ A`。组合的第一性问题由「两两交集是否非空」升级为「**语义路径是否存在一条可提升（lift）到动作自由域 `A_free` 中的连续实现**」。

**灵感 2（接地不是标注，而是函子）**
直觉：给每个概念挂一个动作标签是脆弱的，因为复合语义（如「先旋开再提起」）不是两个标签的拼接。正确的对象是 **接地函子** `F_κ : 𝒯_s → 𝒯_a`：它把语义路径范畴的对象与态射映射到动作空间路径范畴，并要求 **保单位、保复合**（`F(p∘q)` 与 `F(p)∘F(q)` 至多差一个重参数化）。一旦复合保持失败，就说明语义上的「先后关系」在动作空间里无法串接——这正是第 54 轮 H20 所说语义-时序错配的根因。函子失真度 `ε_F` 因而比 Jaccard 兼容性更本质。

**灵感 3（逐对兼容的两种全局谬误）**
直觉：存在两个反例说明两两兼容既非充分也非「可加」的。
- **组合谬误**：`A_1={a,b}, A_2={b,c}, A_3={c,a}`，三对交集都非空，但 `A_core=∩_i A_i=∅`；逐对 `compat≥θ_a` 无法推出组合支撑非空。
- **拓扑谬误**：自由域 `A_free` 是带洞圆环，`S_1` 与 `S_2` 的支撑集相交（`compat` 很高），但唯一能实现该语义关系的迁移绕洞一圈，改变了 `π_1` 缠绕类；对打结/绕线任务这条路径不可采纳，而两两兼容性完全看不见。
所以必须把判据从「交集」升级为「**路径可提升 + 同伦类匹配**」。

**灵感 4（拓扑一致性：连通分量与缠绕类）**
直觉：动作空间不是一马平川。禁区 `A_forbid`（自碰撞、关节限位、危险区、不可穿越障碍）把 `A_free` 切成多个连通分量；抓取、绕线、打结还要求保持回路类/缠绕数。于是即使 `F_κ(p)` 每段都落在 `A_free` 内，它仍可能被迫穿越禁区或改变同伦类而不可执行。**拓扑一致性证书 TCC** 同时检查 `β_0`（是否连通到目标任务分量）与 `π_1`（回路/缠绕类是否匹配），并给出到禁区的安全裕度 `margin`。

**灵感 5（知识图谱补全必须被物理可行性先行约束）**
直觉：KG 补全会「想象」出语义合理但物理不存在的边，这是具身智能里最危险的幻觉。对策是 **隔离层**：补全候选边先进入 `E_q`（quarantine，`conf<θ_q`），只有经动作仿真/实际执行验证并附带物理接地证书 `PGC` 后才迁入可用边集 `E`。这把图谱的「联想能力」与「可执行性」解耦。

**灵感 6（执行即写回：带溯源的动态知识更新）**
直觉：每次执行 `(p,outcome,ρ,Explain)` 都应写回图谱：贝叶斯更新边置信、追加不可篡改溯源 `prov(e)`、并依据 `Explain` 定位的动作单元 `a*` **收缩该边支撑集** `supp(e) ← supp(e) \ N(a*)`，必要时写入负证据。图谱因此随经验增长并能自我纠偏，而非静态先验。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（动作接地知识图谱 AGKG）**
两排序图 `𝒦 = (V_s ∪ V_a, E_s ∪ E_a ∪ E_g)`：
- `V_s`：语义节点（对象/状态/可供性概念），`E_s`：类型化语义关系（is-a, part-of, causes, precedes）；
- `V_a`：动作单元（`A` 的离散化胞腔），`E_a ⊆ V_a×V_a`：带支撑集 `supp(e)⊆A` 与转换成本 `c_trans(e)` 的动作迁移；
- `E_g ⊆ V_s × V_a × 𝒦_ctx`：**接地边** `(c,a,κ)`，`κ` 为接地上下文（本体/物体集/环境），置信 `conf_g∈[0,1]`。

**定义 122（上下文相关接地函子）**
对上下文 `κ`，`F_κ : 𝒯_s → 𝒯_a` 给出 `F_κ(c) ⊆ 2^{V_a}`、`F_κ(r) ⊆ 2^{E_a}`，满足：
1. **保单位**：`id_c` 的像停留在 `F_κ(c)` 内；
2. **保复合**：`F_κ(r_2∘r_1) ⊆ F_κ(r_2)∘F_κ(r_1)`（至多差重参数化）；
3. **支撑覆盖**：任务动作需求 `A_T` 存在提升 `a∈F_κ(p)` 使 `supp(a) ⊇ A_T`。
失真度 `ε_F(κ) = sup_p d_H(F_κ(p), A_exec(p))`，`d_H` 为 Hausdorff 距离，`A_exec` 为真实可执行动作集。

**定义 123（语义-物理间隙与可提升性）**
语义路径 `p` 的接地间隙 `gap(p) = d_H(F_κ(p), A_exec(p))`。`p` **可提升** 当且仅当存在连续动作轨迹 `γ:[0,1]→A_free`，`γ(0)∈F_κ(p_0)`、`γ(1)∈F_κ(p_n)`，且 `γ` 覆盖 `A_T`。可提升是组合可执行的必要条件。

**定义 124（物理接地证书 PGC）**
每条可用边 `e` 携带 `cert(e) = (supp(e), pre(e), post(e), ρ_e, prov(e), conf(e))`。`e` **可部署** 当且仅当 `supp(e)≠∅`、在状态不变式 `I` 下 `pre/post` 相容、且 `min_d ρ_e(d) ≥ ρ_min`。

**定义 125（拓扑一致性证书 TCC）**
`tcc(p) = (comp(F_κ(p)), [F_κ(p)], margin)`：
- `comp(·)`：`A_free` 中的连通分量（`β_0`）；
- `[F_κ(p)] ∈ π_1(A_free)`：回路/缠绕同伦类（`β_1`），仅对需保持缠绕的任务启用；
- `margin = dist(F_κ(p), A_forbid)`：到禁区的安全裕度。
`p` **拓扑可采纳** 当且仅当 `comp(F_κ(p)) = comp(A_T)`、`[F_κ(p)] = [γ*]`（若任务要求）、且 `margin > δ_topo`。

**定义 126（溯源式动态知识更新 DKU）**
执行 `(p,outcome,ρ,Explain)` 后更新 `𝒦`：
- 贝叶斯置信：`conf'(e) = conf(e)·L / (conf(e)·L + 1 - conf(e))`，`L` 为结果似然比；
- 溯源追加：`prov'(e) = prov(e) ∪ {(p,outcome,ρ,Explain)}`；
- 解释驱动收缩：若 `Explain` 定位 `a*`，则 `supp'(e) = supp(e) \ N(a*)` 并写入负证据 `neg(e,a*)`；
- 幻觉隔离：补全候选 `e_q` 仅在通过 PGC+TCC 后由 `E_q` 迁入 `E`。

## 2. 关键算法 伪代码

### IP-121 KAG（Knowledge-Action Grounding）

```python
def ground_action_kg(K_s, A, alpha_lib, ctx, theta_g=0.8):
    K = TwoSortedGraph()
    K.add_semantic(K_s)                       # 语义层原样载入
    K.add_action_cells(discretize(A))         # 动作单元 = A 的胞腔
    for c in K_s.nodes:
        for a in affordance_to_cells(c, A, ctx):        # 候选动作单元
            conf = calibrate_grounding(c, a, alpha_lib, ctx)
            if conf >= theta_g:
                K.add_grounding(c, a, ctx, conf)        # 接地边 E_g
    K.quarantine_completions(theta_q=0.6)               # 补全边全部入 E_q
    return K
```

### IP-122 ASG（Action-Semantic Graph Planning）

```python
def plan_with_grounding(K, task, A_T, gamma_ce, rho_min, delta_topo):
    best = None
    for p_s in k_shortest_paths(K.semantic, task.src, task.dst, k=8):
        Fp = lift_grounding(K, p_s, task.ctx)           # F_κ(p)
        if Fp is None or not cover_support(Fp, A_T):    # 定义 122(3)
            continue
        pgc = physical_certificate(Fp, rho_min)         # IP-123
        if pgc.status != 'ok':
            continue
        tcc = topological_check(Fp, A_T, delta_topo,   # IP-124
                                require_pi1=task.preserve_winding)
        if tcc.status != 'ok':
            continue
        cost = path_cost(Fp, gamma_ce, pgc.rho, tcc.margin)
        best = argmin(best, (cost, Fp, pgc, tcc))
    return best if best else ('reject', 'no_grounded_path')
```

### IP-123 PGC（Physical Grounding Certificate）

```python
def physical_certificate(Fp, rho_min):
    edges = flatten(Fp)
    if any(e.supp is EMPTY for e in edges):
        return Cert('reject', 'empty_support')
    for e in edges:
        if not invariant_consistent(e.pre, e.post, I):
            return Cert('reject', 'pre_post_conflict', e)
        if min(e.rho.values()) < rho_min:
            return Cert('reject', 'robustness_fail', e)
    return Cert('ok', supp=intersection([e.supp for e in edges]),
                rho=min_rho(edges), prov=merge_prov(edges))
```

### IP-124 TCC（Topological Consistency Certificate）

```python
def topological_check(Fp, A_T, delta_topo, require_pi1=False):
    free = A - A_forbid
    comp_src, comp_dst = component(free, Fp.start), component(free, Fp.goal)
    if comp_src != comp_dst or comp_src != component(free, A_T.ref):
        return Topo('reject', 'disconnected', comp_src, comp_dst)
    margin = min_distance(Fp, A_forbid)          # A_forbid 为过近似
    if margin <= delta_topo:
        return Topo('reject', 'forbidden_margin', margin)
    if require_pi1 and homotopy_class(free, Fp) != homotopy_class(free, A_T.ref_path):
        return Topo('reject', 'winding_mismatch', homotopy_class(free, Fp))
    return Topo('ok', comp_src, margin)
```

### IP-125 DKU（Dynamic Knowledge Update）

```python
def update_kg_from_execution(K, p, outcome, rho, explain, L_succ, L_fail):
    for e in edges_used(p):
        L = L_succ if outcome == 'success' else L_fail
        e.conf = bayes_update(e.conf, L)
        e.prov.append((p, outcome, rho, explain))
        if outcome == 'fail' and explain.root_cell is not None:
            e.supp -= neighborhood(explain.root_cell)
            e.neg.add(explain.root_cell)
        if e.conf < theta_drop:
            K.quarantine(e)                       # E → E_q，等待再验证
    for e_q in list(K.quarantined):
        if validate_pgc_tcc(e_q):                 # 物理 + 拓扑双验证
            K.promote(e_q)                        # E_q → E
```

### IP-126 XEG（Cross-Embodiment Grounding）

```python
def cross_embodiment_ground(F_s, target_A, gamma_ce_t, delta_g_budget):
    transfer = {}
    for c, cells_s in F_s.items():
        cells_t = target_ground_candidates(c, target_A)   # 目标本体候选
        T = match_action_cells(cells_s, cells_t)          # 部分映射
        if T is None:
            continue
        drift = action_space_distortion(T, gamma_ce_t)
        if drift > delta_g_budget:                        # 超预算不迁移
            continue
        transfer[c] = (T, drift)
    return transfer        # 宁可不迁移，避免负迁移
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| KAG | O(\|V_s\|·\|V_a\|·\|κ\|) | O(\|E_g\|+\|E_q\|) | 接地校准、上下文限定 |
| ASG | O(k·(\|E_s\|+\|E_a\|) + \|Fp\|·\|A\|) | O(\|V\|+\|E\|) | 函子保复合、支撑覆盖 |
| PGC | O(\|Fp\|·\|A\|+\|𝔇_ρ\|) | O(\|A\|) | pre/post 不变式、ρ 下界 |
| TCC | O(\|A_free\| log\|A_free\| + cost(π_1)) | O(\|A_free\|) | 禁区过近似、同伦类匹配 |
| DKU | O(\|e_used\|·\|𝔇_ρ\|) | O(\|prov\|) | 贝叶斯无偏、解释定位可靠 |
| XEG | O(\|V_s\|·\|V_a^t\|) | O(\|transfer\|) | 失真预算、负迁移检测 |

**正确性定理（Grounding-Sound Composition Soundness）**
假设第 54 轮 (A26)–(A28) 成立，并新增：
**(A29)** `F_κ` 由上下文限定的结构化校准得到，`ε_F(κ) ≤ ε_max`；
**(A30)** 禁区 `A_forbid` 被 **过近似**（宁可多禁），`δ_topo` 校验安全裕度；
**(A31)** KG 补全边全部经 `E_q` 隔离并通过 PGC+TCC 才可入图；
**(A32)** DKU 的贝叶斯更新无偏，`Explain` 定位动作单元的错误率 `≤ β_E`。
则对任意语义路径 `p`，若 ASG 判定可部署，则：
```
P_success(p) ≥ 1 - [ Σ_d(1-ρ_min(d)) + β_E
                    + P(ε_F > ε_max) + P(topogap) + P(E_q 幻觉边迁移) ]
```
三条充分条件：**接地函子保复合**、**动作路径拓扑可采纳**、**补全边物理验证后方可入图**。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 接地函子不保复合（语义-物理错位） | 高 | 上下文限定接地 + 复合保持审计 + 反例回灌 |
| 禁区 `A_forbid` 欠近似导致假拓扑可采纳 | 高 | 保守过近似 + 红队探索 + 裕度复审 |
| KG 补全幻觉污染溯源 | 高 | `E_q` 隔离 + PGC/TCC 双验证 + 溯源审计 |
| 高维动作空间同伦类计算昂贵 | 中 | 降维骨架 + 采样近似 + 仅在缠结任务启用 π_1 |
| 跨本体失真预算过松引发负迁移 | 高 | 失真预算 `δ_g` + 迁移前目标域仿真 + 绊线回滚 |

## 6. 本轮最大风险

**一句话**：本轮把「技能组合」从两两动作兼容升级为「语义路径的接地函子 + 拓扑可采纳性 + 补全边物理验证」，但其 soundness **三重依赖接地函子的保复合性、禁区模型 `A_forbid` 的过近似完整性、以及 `Explain` 定位的可靠性**；一旦接地在上下文之外被过度泛化、或禁区被欠近似，语义上合理的路径会被错误认证为可执行，而真实动作路径可能穿越禁区或落在错误同伦类，产生看似局部一致、实则系统性失败的负迁移，故必须以 **上下文限定接地 + 保守禁区过近似 + `E_q` 隔离与溯源审计** 三重护栏，宁可判定「不可提升」，也绝不把图谱的语义联想当作身体的可执行性。

| `comp(·)` | `A_free` 中的连通分量（`β_0`） |
| `[F_κ(p)] ∈ π_1(A_free)` | 回路/缠绕同伦类（`β_1`） |
| `margin=dist(F_κ(p),A_forbid)` | 到禁区的安全裕度 |
| `E_q` | 补全候选边的隔离层（quarantine） |
| `prov(e)` | 边 `e` 的不可篡改执行溯源 |

## 1.5 关键推导：逐对兼容 ≠ 全局可执行

**推导 A（组合谬误，集合层）**
取三技能支撑集 `A_1={a,b}, A_2={b,c}, A_3={c,a}`。任意两两 Jaccard 兼容性均为 `1/3`（取 `θ_a≤1/3` 则两两均通过），但 `A_core=∩_i A_i=∅`。于是第 54 轮定义 116 的逐对判据会接受一个**组合支撑为空**的技能序列，AEC 的 `A_core=reduce(intersection,...)` 直接失败。结论：局部兼容性对交集运算**不可加**，必须显式求全局交集或改用路径提升。

**推导 B（拓扑谬误，同伦层）**
设 `A_free` 为带洞圆环，`S_1,S_2` 支撑集相交于环上一段，故 `compat(S_1,S_2)≥θ_a`。但实现该语义关系的唯一迁移 `e_{12}` 绕洞一圈，使 `[F_κ(p)]` 相对参考路径 `γ*` 的缠绕数改变 `+1`。对 `preserve_winding=True` 的任务（打结、绕线、线缆布线），`[F_κ(p)]≠[γ*]` 直接违反定义 125，路径不可采纳。结论：兼容性只看「有没有交集」，看不见「交集属于哪个同伦类」。

**推论**
组合可执行性判据应写成 `compat ∧ lift(F_κ(p)) ∧ PGC ∧ TCC`，其中后三者分别负责支撑非空、连续可提升、拓扑类正确。这正是 ASG 的搜索约束。

### IP-122 ASG

```python
def plan_with_grounding(K, task, A_T, gamma_ce, rho_min, delta_topo):
    best = None
    for p_s in k_shortest_paths(K.semantic, task.src, task.dst, k=8):
        Fp = lift_grounding(K, p_s, task.ctx)
        if Fp is None or not cover_support(Fp, A_T):
            continue
        pgc = physical_certificate(Fp, rho_min)
        if pgc.status != 'ok':
            continue
        tcc = topological_check(Fp, A_T, delta_topo,
                                require_pi1=task.preserve_winding)
        if tcc.status != 'ok':
            continue
        cost = path_cost(Fp, gamma_ce, pgc.rho, tcc.margin)
        best = argmin(best, (cost, Fp, pgc, tcc))
    return best if best else ('reject', 'no_grounded_path')
```

### IP-123 PGC

```python
def physical_certificate(Fp, rho_min):
    edges = flatten(Fp)
    if any(e.supp is EMPTY for e in edges):
        return Cert('reject', 'empty_support')
    for e in edges:
        if not invariant_consistent(e.pre, e.post, I):
            return Cert('reject', 'pre_post_conflict', e)
        if min(e.rho.values()) < rho_min:
            return Cert('reject', 'robustness_fail', e)
    return Cert('ok', supp=intersection([e.supp for e in edges]),
                rho=min_rho(edges), prov=merge_prov(edges))
```

### IP-124 TCC

```python
def topological_check(Fp, A_T, delta_topo, require_pi1=False):
    free = A - A_forbid
    comp_src, comp_dst = component(free, Fp.start), component(free, Fp.goal)
    if comp_src != comp_dst or comp_src != component(free, A_T.ref):
        return Topo('reject', 'disconnected', comp_src, comp_dst)
    margin = min_distance(Fp, A_forbid)
    if margin <= delta_topo:
        return Topo('reject', 'forbidden_margin', margin)
    if require_pi1 and homotopy_class(free, Fp) != homotopy_class(free, A_T.ref_path):
        return Topo('reject', 'winding_mismatch', homotopy_class(free, Fp))
    return Topo('ok', comp_src, margin)
```

def update_kg_from_execution(K, p, outcome, rho, explain, L_succ, L_fail):

def cross_embodiment_ground(F_s, target_A, gamma_ce_t, delta_g_budget):
    transfer = {}

        cells_t = target_ground_candidates(c, target_A)

| XEG | O(\|V_s\|·\|V_a^t\|) | O(\|transfer\|) | 失真预算、负迁移检测 |

**正确性定理（Grounding-Sound Composition Soundness）**
假设第 54 轮 (A26)–(A28) 成立，并新增：
**(A29)** `F_κ` 由上下文限定的结构化校准得到，`ε_F(κ) ≤ ε_max`；
**(A30)** 禁区 `A_forbid` 被过近似，且 `δ_topo` 校验安全裕度；
**(A31)** KG 补全边全部经 `E_q` 隔离并通过 PGC+TCC 才可入图；
**(A32)** DKU 贝叶斯更新无偏，`Explain` 定位动作单元错误率 `≤ β_E`。
则对任意语义路径 `p`，若 ASG 判定可部署，则部署成功概率：
```
P_success(p) ≥ 1 - [ Σ_d(1-ρ_min(d)) + β_E
                    + P(ε_F > ε_max) + P(topogap) + P(E_q 幻觉边迁移) ]
```
关键：**接地函子保复合**、**动作路径拓扑可采纳**、**补全边物理验证后方可入图**。

## 6. 本轮最大风险

**一句话**：本轮把技能组合从两两动作兼容升级为「语义路径的接地函子 + 拓扑可采纳性 + 补全边物理验证」，但其 soundness **三重依赖接地函子的保复合性、禁区模型 `A_forbid` 的过近似完整性、以及 `Explain` 定位的可靠性**；一旦接地在上下文之外被过度泛化、或禁区被欠近似，语义上合理的路径会被错误认证为可执行，而真实动作路径可能穿越禁区或落在错误同伦类，产生看似局部一致、实则系统性失败的负迁移，故必须以 **上下文限定接地 + 保守禁区过近似 + `E_q` 隔离与溯源审计** 三重护栏，宁可判定「不可提升」，也绝不把图谱的语义联想当作身体的可执行性。
