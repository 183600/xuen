# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配×主动交互消歧」IP-253~263；灵感循环第 3 轮；本轮灵感：「小样本学习」×「长程任务」）

> R69 给闭环装上了「嘴」和「眼」：把不确定性拆成 aleatoric / epistemic，epistemic 用流匹配多模态策略 + 主动交互去消解，并用 FMA 似然做「标定不可吸收」的第二意见。但 R69 的两个隐含假设在真实部署里都站不住：
>
> 1. **短视（myopia）**：MINT 是单步贪心 VoI，问完这一次就结束；它不知道「现在问什么」会改变「以后还值不值得问、还问得起吗」。真实的长程任务里，问题是**串起来**的——先问 A 才能判断 B 值不值得问，而等待本身可能**免费**揭示答案。
> 2. **失忆（amnesia）**：每次消歧都从零开始。同一类歧义在第 3 天、第 30 天、第 300 天还会出现，系统每次都重新花一次交互预算。交互不是一次性的信息，而是**极少量、带选择偏差的标注样本**——这正是小样本学习的战场。
>
> 更尖锐的是：一旦允许从交互中学习，R69 的最大风险会**升级**而非消失。R69 担心「问错比不问更危险」；到了 R70，若把「自己问出来的、只在不确定处采样的少量标签」拿去适配，系统会**把选择偏差和缓变故障一起固化成知识**——它会在最该问的地方停止提问，而且安全门的验证集也来自同一条被污染的查询流，于是门也被骗过。
>
> 核心命题：**把每一次交互当作一枚「一次性小样本」，把整段任务当作「长程带漂移的序贯决策」；用长程 VoI 规划决定「何时问、问谁、还是等着」，用一个隔离在实时环之外的、带信任域与不回退保证的小样本适配器把答案沉淀为「下次少问」；并在学习层再加一道不能被泛化吸收的防吸收门（drift vs fault）。** 命名 **LORE-RAS**（Long-horizon One-shot Risk-bounded Episodic adaptation）——像一位在漫长考察中只遇到几个可靠线人的野外研究者：问得少、记得牢、从不把器材故障当成新发现。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**问过之后我学到了什么、下次还要再问吗、这漫长旅途里我有没有把故障学成知识**」。

## 0. 直觉与动机

**灵感 1（小样本学习 → 每次交互都是一枚昂贵的 1-shot 样本）**
直觉：R69 把交互看作「当轮消歧工具」，用完即弃。但人类不是这样：同一个新同事的口音听错一次、被纠正一次，之后就不再问；这套「一次性纠正」之所以有效，是因为人有一个关于「人怎么变、口音怎么变」的**先验**，外加一个很小的、被反复复用的**情景记忆**。小样本学习（meta-learning / episodic training）正是把「如何从 k 个样本快速适应」本身学出来。于是本轮把每次交互的 (状态, 歧义, 信息动作, 回答, 结果) 当作一枚 1-shot 样本，喂给一个在任务族上元训练过的适配器：第 k 次遇到同类歧义时，本来要问 3 次，现在问 1 次甚至不问。**问题从「如何消歧」变成「如何把消歧结果压缩成先验」。**

**灵感 2（长程任务 → 信息有「时间价值」，提问是一段序贯计划而非一次贪心）**
直觉：R69 的 VoI 是单步的：这个信息动作当下能降多少熵。但长程里三件事被它漏掉：
- **次序**：先问「那是人还是模特」再问「他情绪如何」，比反过来省一次提问；问题之间存在**前置依赖**，贪心熵减不满足最优子结构。
- **等待**：很多信息会**免费**到来（再走两步就看清了），所以「现在问」可能被「等一等」严格支配——R69 有 wait 这个动作，却没有给它估值。
- **预算的跨期分配**：交互预算是一条随时间的硬约束（每天的打扰次数、社交信用），今天问光了，明天遇到更关键的分叉就只能瞎猜。**最优策略会把提问当作一种可储存的稀缺资源来跨期配置。**
把这三点合起来，交互控制从「单步 bandit」升级为「信念空间上的有限期 POMDP」，其解是**长程 VoI（H-VoI）**：一次提问的价值 = 它省下的未来提问 + 它避免的错动作 − 它的成本。

**灵感 3（选择偏差 → 你只在自己不确定的地方采样，于是你学到的是「不确定的地方」）**
直觉：这是本轮最容易被忽略、也最致命的一点。适配器的训练分布不是世界分布 p(x)，而是**被查询策略筛选过的** p(x | π_q 选中) ∝ p(x)·π_q(x)。系统倾向在 U_epi 高处提问，于是样本几乎全来自高歧义区；在低歧义区它从没被纠正过，会越来越自信——**甚至把「从不提问」本身学成正确**。这是自确认回路（self-confirming loop）：查询策略 → 有偏数据 → 适配器 → 更偏的查询策略。小样本学习里这叫协变量偏移 + 支持集缺失。必须用 propensity 重加权（IPS / DR）纠正，并强制留出一条**随机审计查询通道**（探索下限 ε_audit）保证 positivity，否则回路会坍缩到一个「自信地错」的固定点。

**灵感 4（安全适配 → 学习必须关在实时环之外，且可原子回退）**
直觉：R69 用三条不变式守住实时安全，其中一条是「实时流零学习写操作」。本轮绝不能为了「学习」破这条铁律。于是适配只发生在**轮次之间的整备窗（consolidation window）**：离线、可回放、可验证、可整体回滚。适配更新被约束在基座策略的信任域内（‖Δ‖ ≤ ρ），并强制在**安全关键回放集 S\*** 上验证无退化；只有通过门控的适配才被原子提交，否则逐字节回退到 R69 基座。**学习是一个事务，不是一个副作用。** 这使「R70 在失败时严格退化为 R69」成为可证明的性质，而不是一句口号。

**灵感 5（学习的反吸收 → 别把故障学成知识）**
直觉：R68 的风险是「缓变故障被标定吸收而隐形」；R69 用动作似然做第二意见。到了 R70，同样的骗局在**更高一层**重演：真实世界确实在变（新家具、新口音、新偏好），系统应当适配；但传感器缓变故障在统计上**看起来也像**分布漂移。若不加分辨地去适配，系统会把「镜头脏了导致的偏色」学成「这个世界变黄了」，从此永久戴着黄色眼镜——**故障被泛化吸收**。所以适配门必须复用 R69 的 (r_res, Δa) 对偶判据：只有当「新颖性不能被故障签名解释」时才允许适配；疑似慢变故障时**冻结适配**（甚至回滚最近若干次适配）。这是「每一层都要有下一层吸收不了的证据通道」这一递归原则在学习层的实例。

**灵感 6（贡献归因 → 长程里，不是每次提问都有用）**
直觉：300 天里会有大量查询，其中相当一部分是冗余的（信息后来免费到了）、幸运的（结论本来就会对）、或被污染的（投毒回答）。若把整段历史不加区分地倒进记忆，适配器会被噪声和毒样本稀释。需要对每条查询做**反事实归因**：去掉这条回答，最终决策会不会不同？边际价值≈0 的查询不进记忆；被 k 源证据否定过的查询进「反面教材集」而不是正样本。这把 R69 的「k 个正交证据一致」纪律延伸到**记忆卫生**。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（LORE-RAS 总览与四不变式）** LORE-RAS = (HVIP, EPIC, FAB, DAB, STR, DGR, QAC, CBB, CONS, RAS-WM†)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i / R69 293-i）——所有适配只发生在 CONS 整备窗；
(ii) **长程交互预算硬约束**：滚动时窗内信息动作 ≤ B_win，社交信用 credit ≥ 0，任何 g 仍过 C-RAS-WM 认证；
(iii) **证据纪律**（继承 R69 293-iii：单源/单次交互不得定案）；
(iv) **适配可回退**：任何提交的适配都有唯一父版本与可复现回滚点，回滚代价 O(1)（版本指针切换）。

**定义 311（信念-查询 POMDP）** 在 R69 的模态身份 M 与任务参数 Θ 之上定义信念 b_t = p(M, Θ | h_t)。查询规划是有限期、预算约束的信念 MDP：状态 (b_t, B_t, credit_t)，动作 a_t ∈ 𝒜_task ∪ 𝒜_info ∪ {wait}，转移 b_{t+1} = τ(b_t, a_t, y_t)，y_t ~ p(· | b_t, a_t)。任务回报 r_task，查询成本 c(g)，社交信用约束 credit_t ≥ 0。

**定义 312（长程 VoI，H-VoI）** 对查询策略 π_q，
H-VoI(π_q | b_0) = E_{π_q}[ Σ_{t=0}^{H−1} γ^t ( L(b_t) − L(b_t^{¬q}) ) ] − E[Σ_t γ^t c(g_t)]，
其中 L(b) 是信念 b 下的期望任务损失，b^{¬q} 为「同轨迹但不执行查询」的反事实信念。关键性质：H-VoI 允许**延迟与序贯**；R69 的单步 VoI 是 H=1、γ=0 的特例。定义**等待期权价值** W(b) = H-VoI(wait) − H-VoI(立即问)，W>0 表示「等更划算」。

**定义 313（HVIP：摊销查询规划器）** 用元训练得到的价值函数 V_ψ(b, B, credit) 近似最优查询价值；在线以 1-step lookahead + V_ψ 做 rollout（代价可控）。V_ψ 在任务族上元训练（见定义 316），使新任务上 k 个真实交互即可校准。

**定义 314（EPIC：受保护情景记忆）** 容量 C 的分层记忆：S\* 安全关键集（不可驱逐）、S_amb 歧义样本、S_neg 被否定的毒/错样本、S_audit 随机审计样本。每条记录 (b, g, y, outcome, propensity π, value_attr, t)。驱逐策略：覆盖优先（drift-aware reservoir + 子模覆盖），并保证 S\* 与 S_audit 永不被驱逐。

**定义 315（FAB：小样本信任域适配器）** 基座参数 θ0（R69 的 trunk / mode_head 副本）。适配 Δ ∈ 𝒯_ρ（低秩因子 + 谱范数球 ‖Δ‖₂ ≤ ρ），仅作用于 mode_head 与条件编码的最后一层，产出 θ = θ0 + Δ。冻结速度场主干与安全认证器（它们不在适配范围内）。

**定义 316（元训练目标）** 在任务族分布 p(𝒯) 上，采样 k-shot 支持集 D_k^tr 与查询集 D^val：
min_{θ0} E_{𝒯} [ L( Adapt(θ0, D_k^tr), D^val ) ]，Adapt 为定义 315 的 ρ-约束内循环。这是「学怎么从 k 次交互快速收敛」，θ0 是**先验**而非最终策略。

**定义 317（选择偏差与倾向校正 DAB）** 训练分布 p_sel(x) ∝ p(x)·π_q(x)。用 IPS / DR 权重 w(x)=1/max(π_q(x), ε_w) 修正适配损失；并强制 ε_audit 比例的查询为均匀随机（positivity / 重叠保证）。定义**审计覆盖** κ = P(π_q(x) ≥ ε_w) 作为回路健康度指标；κ 过小 ⇒ 暂停适配。

**定义 318（安全信任域与不回退门 STR / NFC）** 适配提交前须通过：
(a) 在 S\* 上 max 风险 ≤ ε_safe；
(b) 回放 S\* 与 S_audit 的任务损失不升（允许统计等价带）；
(c) 忘记界：ΔL_{S\*} ≤ L_φ·ρ（引理 21）。
任一不过 ⇒ 拒绝并回退。门控是**单向**的：只允许「更安全或等价」的方向被提交。

**定义 319（整备窗 CONS）** 仅在任务间歇（非实时）开启；执行：回放 → 归因 → 去偏 → 适配 → 门控 → 原子提交/回退。与主控回路时间隔离，且有独立看门狗；CONS 失败不影响 R69 实时路径（实时路径读的永远是已提交的不可变版本）。

**定义 320（漂移-故障门 DGR）** 新颖性分 novel = D(p_new, p_mem)（记忆覆盖距离）。适配许可 = (novel > τ_n) ∧ ¬slow_fault_suspect，其中 slow_fault_suspect 复用 R69 定义 309 的 (r_res↓, Δa↑) 联合判据。若 slow_fault_suspect：冻结适配，并把近期适配标记为「待复核」，必要时回滚（防止故障已经被学进去）。

**定义 321（查询归因 QAC）** 对查询 g_i 的反事实边际价值 v_i = L(决策 | 历史) − L(决策 | 历史去掉 y_i)。用轨迹级 Shapley / 值函数近似。v_i < τ_v ⇒ 不进正样本；被 k 源否定的回答 ⇒ 进 S_neg。

**定义 322（跨期预算 CBB）** 滚动窗预算 B_win（如每日打扰上限）+ 信用额 credit_t ≥ 0（可缓慢再生）。HVIP 在 (B, credit) 上做规划；预算耗尽 ⇒ 只能 wait / 看（免费动作），绝不允许越界。

**定义 323（证书 J_LORE）** J_LORE = (J_FLUID, adapter_version, parent_version, k_shot, audit_coverage κ, IPS_ess, forget_bound, drift_gate_flag, rollback_point_hash, lore_ver)。Valid ⇔ Valid(J_FLUID) ∧ 门控通过 ∧ κ ≥ κ_min ∧ ESS ≥ ess_min。

**定义 324（威胁模型 AIC-LORE）** ℰ_LORE = ℰ_FLUID × ℰ_mem × ℰ_feedback，其中 ℰ_mem：毒化记忆 / 后门适配样本、陈旧样本污染；ℰ_feedback：用重复提问诱导系统自我确认、用「免费信息」制造虚假相关性、缓慢投毒使适配漂移。重点防御**反馈投毒**：少量毒样本随查询回路放大。

**定义 325（长程审计 VQAuditor-H）** 审计从「单轮交互」升级到「跨轮记忆」：适配是否可归因、被驱逐样本是否仍被依赖、门控验证集是否与训练集独立（防自证）、回滚是否可复现。结论回灌 CONS 的成本先验与门控阈值。

**定义 326（退化边界）** 当 H=1、k=0（无记忆）、ρ=0、DGR 恒为假时，LORE-RAS 逐指令等于 R69（FLUID-RAS）；再令 VoI ≤ 成本，逐指令等于 R68。⇒ 三层严格嵌套，安全侧单调不减。

# IP-264 HVIP：长程 VoI 查询规划（摊销 critic + 1-step lookahead）
def plan_query(belief, budget, credit, V, H):
    cands = [None] + info_action_candidates(belief)   # None = wait
    best = None
    for g in cands:
        if g is not None:
            if not budget.allow(g, credit):           continue
            if not c_ras_wm.certify_info(g, belief):  continue
        # 反事实：问 vs 不问的未来价值差（含等待期权）
        q  = expected_over_answers(belief, g,
               lambda b2, y: V(b2, budget.after(g), H - 1))
        q0 = V(belief, budget, H - 1)                  # 不采取该信息动作
        score = q - q0 - (0 if g is None else cost(g, belief))
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > TAU_Q else (None, 0.0)  # 不值 → wait/不交互

# IP-265 CONS+EPIC+FAB+DAB：整备窗内的小样本安全适配
def consolidate(epic, base, task_family):
    if not drift_gate(epic):                 return base      # DGR：故障/无漂移不学
    D = epic.sample_debiased()               # IPS/DR + audit 覆盖
    if coverage(epic) < KAPPA_MIN or ess(D) < ESS_MIN:
        return base                          # 查询回路不健康 → 不学
    Dtr, Dval = split(D)
    trial = adapt_in_trust_region(base, Dtr, rho=RHO)          # FAB，仅 mode_head/条件末层
    if not safety_gate(trial, epic.S_star, epic.S_audit):      # STR/NFC
        return base                          # 拒绝 → 回退父版本
    return commit_atomic(base, trial)        # 事务提交，保留 rollback 指针

# IP-266 DGR：漂移-故障门（学习层反吸收）
def drift_gate(epic):
    novel = coverage_distance(epic.recent(), epic.memory)
    slow  = (epic.last_r_res < TAU_RES) and (epic.last_delta_a > TAU_FMA)  # 复用 R69
    return (novel > TAU_N) and (not slow)    # 慢变故障疑似 → 冻结适配

# IP-267 QAC：查询反事实归因 + 记忆卫生
def attribute(epic):
    for rec in epic.recent():
        rec.value_attr = marginal_value(rec, epic.memory)      # 去掉它的反事实差
    epic.drop(lambda r: r.value_attr < TAU_V and r not in epic.S_neg)

# IP-268 主闭环：实时路径 = R69（不学习），仅把交互结果写入 EPIC
def LORE_RAS_round(M, obs):
    k, lam, mode, U = M.fluid.round(obs)            # 完全复用 R69
    g = M.last_interaction
    if g is not None:
        M.epic.append(snapshot(M, obs, g, M.last_answer,
                               propensity=M.query_prop, t=M.clock))
    M.budget.spend(g)                                # 跨期预算扣减
    if M.clock.at_task_boundary():
        M.cons.submit_async(M.epic)                  # 异步整备，实时环不等待
    return k, lam, mode, U

## 3. 推导

**引理 19（等待期权严格占优条件）** 若存在免费观测 y_free 且 I(M; y_free) > 0，则存在非空状态集使 H-VoI(wait) > H-VoI(立即问)，而贪心单步 VoI 仍会误选立即问。要点：单步规划看不见「免费信息」，长程规划可以；这解释了为什么 R69 的 wait 动作若缺少正确估值就会系统性过度提问。

**引理 20（元先验的小样本界）** 设任务族上元训练获得的先验 θ0 的偏差为 B_prior，适配内循环 k 步、复杂度为 C 的假设类，则适配后超额风险 ≤ B_prior + O(√(C/k + log(1/δ)/k))（PAC-Bayes 风格）。系：**问得越少（k 小），先验越重要；先验越好，所需交互越少**——这就是「小样本」与「长程少问」之间的桥。

**引理 21（信任域遗忘界）** 若 Δ 满足 ‖Δ‖₂ ≤ ρ，且任务损失对参数 L_φ-Lipschitz，则在安全关键集 S\* 上 |L(θ0+Δ) − L(θ0)| ≤ L_φ·ρ。系：ρ 既是「学得动」的油门，也是「忘得少」的刹车；NFC 门把这个上界变成可验证的提交条件。

**引理 22（选择偏差下适配的一致性）** 若 π_q(x) ≥ ε_w > 0 处处成立（由审计下限保证），则 IPS 加权适配目标与全分布目标是同一 minimizer；若 ε_w = 0（无审计），存在自确认固定点使适配器在低歧义区系统性过自信。系：**没有随机审计，就没有可信的小样本适配**。

**引理 23（故障-漂移可分的充分条件）** 若缓变故障的可观测签名落在 (r_res, Δa) 的低残差-高似然差象限，而真实分布漂移不改变策略密度（只改变模态权重），则两类新颖性在该二维统计上可分；分离裕度随故障幅值单调。系：DGR 是一个**廉价的两样本检验**，不必先训练一个漂移检测器。

**定理 18（LORE 严格包含 R69 / R68）** 在定义 326 的退化条件下，LORE 与 R69 逐指令一致；一般情形下，实时路径行为与 R69 相同（学习只发生在 CONS），故实时安全界不弱于 R69；适配只在通过 STR/NFC 且 DGR 许可时改变未来的查询 / 动作分布，且每次改变都是可回退事务。故 LORE 的安全侧单调嵌套 R69 ⊇ R68。

**定理 19（长程查询的亚线性增长与稳定性）** 在引理 20–22、滚动预算 B_win 与探索下限 ε_audit > 0 下，累计交互次数随任务长度 T 呈 O(T^{1−β})（β 由先验质量决定）而非线性；且查询回路在适配步长 η ≤ η_max(ε_audit) 时是压缩映射，不发散。反面：ε_audit = 0 时存在线性下界（自确认回路）。**系：少量探索不是成本，是让「越学越少问」成立的必要条件。**

## 6. 本轮最大风险

**一句话**：LORE-RAS 的全部收益押在「那几枚自己问出来、带选择偏差的标签能把先验改对」上——而验证这件事的 S\* / 审计集也来自同一条被查询策略筛选过的数据流；**一旦选择偏差或缓变故障被适配器当成「世界变了」吸收进去，系统会在最该提问处永久闭嘴，并让证书替它背书——学习层把 R69 的「被证实的错误」升级成了「被泛化、被证书认证的错误」。**

**次级风险与缓解**：
1. **自确认回路**（越学越偏）→ 随机审计下限 ε_audit + κ 健康度门 + 定理 19 压缩映射条件；

3. **毒化记忆 / 后门适配** → S_neg + QAC 归因 + AIC-LORE + ESS 门；
4. **灾难遗忘** → 信任域 ρ + S\* 回放 + NFC 门（引理 21）；
5. **实时预算被整备饿死** → CONS 全异步 + 实时路径逐指令复用 R69，零新增延迟。

# IP-264 HVIP：长程 VoI 查询规划（摊销 critic + 1-step lookahead，含 wait）
def plan_query(belief, budget, credit, V, H):
    cands, best = [None] + info_action_candidates(belief), None   # None = wait
    for g in cands:
        if g is not None:
            if not budget.allow(g, credit) or not c_ras_wm.certify_info(g, belief):
                continue
        q  = expected_over_answers(belief, g,
               lambda b2, y: V(b2, budget.after(g), H - 1))
        score = q - V(belief, budget, H - 1) - (0 if g is None else cost(g, belief))
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > TAU_Q else (None, 0.0)   # 不值 → wait/不交互

# IP-265/266/267/268 CONS：回放→去偏→适配→门控→原子提交
def consolidate(epic, base):
    if not drift_gate(epic):                  return base        # DGR：故障/无漂移不学
    D = epic.sample_debiased()                # IPS/DR + audit 覆盖
    if coverage(epic) < KAPPA_MIN or ess(D) < ESS_MIN:
        return base                           # 回路不健康 → 不学
    Dtr, Dval = split(D)
    trial = adapt_in_trust_region(base, Dtr, rho=RHO)             # FAB
    if not safety_gate(trial, epic.S_star, epic.S_audit):         # STR/NFC
        return base                           # 拒绝 → 回退父版本
    return commit_atomic(base, trial)

# IP-269 DGR：学习层反吸收（复用 R69 的 (r_res, Δa) 对偶）
def drift_gate(epic):
    novel = coverage_distance(epic.recent(), epic.memory)
    slow  = (epic.last_r_res < TAU_RES) and (epic.last_delta_a > TAU_FMA)
    return (novel > TAU_N) and (not slow)

# IP-270 QAC：反事实归因 + 记忆卫生
def attribute(epic):
    for rec in epic.recent():
        rec.value_attr = marginal_value(rec, epic.memory)
    epic.drop(lambda r: r.value_attr < TAU_V and r not in epic.S_neg)

# IP-275 主闭环：实时路径逐指令 = R69，仅把交互写入 EPIC / 扣预算
def LORE_RAS_round(M, obs):

## 4. 推导

**引理 19（等待期权严格占优）** 若存在免费观测 y_free 且 I(M; y_free) > 0，则存在非空状态集使 H-VoI(wait) > H-VoI(立即问)，而单步贪心仍会误选立即问。系：R69 有 wait 动作却缺估值，会系统性过度提问。

**引理 20（元先验小样本界）** 先验偏差 B_prior、内循环 k、复杂度 C 下，适配后超额风险 ≤ B_prior + O(√(C/k + log(1/δ)/k))。系：问得越少，先验越重要；先验是「长程少问」的引擎。

**引理 21（信任域遗忘界）** ‖Δ‖₂ ≤ ρ 且损失 L_φ-Lipschitz ⇒ 在 S\* 上 |L(θ0+Δ) − L(θ0)| ≤ L_φ·ρ。系：ρ 既是学习油门也是遗忘刹车；NFC 把它变成可验证提交条件。

**引理 22（选择偏差下的一致性）** π_q ≥ ε_w > 0 ⇒ IPS 目标与全分布目标同 minimizer；ε_w = 0 ⇒ 存在自确认固定点，低歧义区系统性过自信。系：无随机审计，无可信小样本适配。

**引理 23（故障-漂移可分充分条件）** 缓变故障落在 (r_res↓, Δa↑) 象限，真实漂移只改模态权重而不改策略密度 ⇒ 两类新颖性在二维统计上可分。系：DGR 是廉价两样本检验，无需另训漂移检测器。

**定理 18（LORE 严格包含 R69 / R68）** 退化条件（H=1, k=0, ρ=0）下逐指令等于 R69；一般情形实时路径与 R69 相同（学习仅在 CONS），安全界不弱于 R69；适配每次变更均可回退。⇒ 安全侧单调嵌套。

**定理 19（长程查询亚线性增长与稳定性）** 引理 20–22 + 滚动预算 + ε_audit > 0 下，累计交互 O(T^{1−β})（β 由先验质量定）而非线性；适配步长 η ≤ η_max(ε_audit) 时查询回路为压缩映射。反面：ε_audit = 0 存在线性下界（自确认回路）。系：少量探索不是成本，是「越学越少问」的必要条件。

## 7. 本轮最大风险

**一句话**：LORE-RAS 的全部收益押在「那几枚自己问出来、带选择偏差的标签能把先验改对」上——而验证这件事的 S\* / 审计集也来自同一条被查询策略筛选过的数据流；**一旦选择偏差或缓变故障被适配器当成「世界变了」吸收进去，系统会在最该提问处永久闭嘴，并让证书替它背书——学习层把 R69 的「被证实的错误」升级成「被泛化、被证书认证的错误」。**

**次级风险与缓解**：自确认回路 → ε_audit + κ 健康度门 + 定理 19 压缩映射条件；故障被泛化吸收 → DGR 复用 (r_res, Δa) + 冻结 / 回滚；毒化记忆 / 后门适配 → S_neg + QAC + AIC-LORE + ESS 门；灾难遗忘 → 信任域 ρ + S\* 回放 + NFC（引理 21）；实时预算被整备饿死 → CONS 全异步 + 实时路径逐指令复用 R69，零新增延迟。
