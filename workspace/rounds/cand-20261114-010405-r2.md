# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧闭环」IP-253~263；灵感循环新循环第 2 轮；本轮灵感：「意图理解」×「视觉伺服」）

> R69 问「我该向谁求证、还能问什么」，把 epistemic 歧义交给「流匹配多模态策略 + 看 / 问 / 触」。但它有两个从未被检验的隐含前提：**（1）歧义是「动作模态」的歧义，而不是「意图」的歧义；** **（2）消歧只能靠一次性信息动作把后验熵压下去。** 这两个前提一起造成了 R69 的盲点：它会把预算花在「与任务无关的意图差异」上（问了也白问），也会在「问了问不出、但动起来就能看出来」的歧义上束手无策（只会退化为保守）。
>
> 本轮两个灵感正好补上：
> - **意图理解**：歧义的本体不是左 / 右动作，而是驱动动作的**潜在目标 / 偏好 θ**——即「对方到底想要什么」。把 R69 的模态身份 M 升级为分层贝叶斯心智理论（ToM）下的意图后验 b(θ)，并显式区分**可辨识（identifiable）**与**不可辨识（non-identifiable）**方向。
> - **视觉伺服**：消歧不必是「一次性查询」，可以是**闭环**——把相机 / 末端伺服到能放大意图差异的视角（判别性伺服 / 主动感知），并在得到目标后用图像空间反馈把任务误差驱动到零。视觉伺服还有一个 R68 梦寐以求的性质：**它的不动点对相机标定误差不敏感**。
>
> 核心命题：**把「意图不确定性」分解为「与任务相关 / 无关」×「可辨识 / 不可辨识」；只对「既相关又可辨识」的部分花交互预算；无关的歧义直接由 ISVO 的零空间不变性「免费消解」（resolution bonus 2.0）；相关但被动不可辨识的歧义，用「判别性视觉伺服」主动改变观测去辨识，而不是干问；只有当歧义相关、且预算内不可辨识、或被投毒 / 漂移时，才退化为 R69 / R68 的保守。** 命名 **TELOS-RAS**（Task-rElevant Epistemic-Latent Observable Servoing；telos = 目的 / 意图）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**求证的对象到底想要什么，而这件事值不值得知道**」——意图不是要被彻底读出的答案，而是一个只需被「商掉」到任务等价类的等价类。

## 0. 直觉与动机

**灵感 1（意图理解 → 歧义有「相关性」）**
直觉：R69 面对「绕左还是绕右」会去问。但如果两条路最终通向同一个门口、代价也相同，那这个歧义**对任务没有意义**，问了纯属浪费社交预算。人的意图是一个高维潜在目标 θ，而任务只依赖其中一个低维投影（比如「最终停在哪个桌位」）。意图差异若落在任务的零空间里，就是**行为无关的**。所以第一件事不是「消歧」，而是先问「这个歧义会不会改变我该做的动作」——用意图-任务雅可比 J = ∂φ*/∂θ 的零空间来判定。

**灵感 2（视觉伺服 → 消歧有「闭环」）**
直觉：R69 的「看 / 问 / 触」本质上是一次性、开环的估计（执行 g → 得到 y → 更新后验）。视觉伺服告诉我们另一条路：**让误差本身驱动控制**。如果我拿不准对方是想让我抓杯子还是抓瓶子，与其问一句，不如把相机移到「杯子 vs 瓶子」在图像里差异最大的视角——这一步移动既推进任务（更接近目标）又放大意图信号。到执行阶段，图像空间闭环只要把 φ(o) − φ*(θ̂) 驱动到零，即使 θ̂ 略偏、相机标定略错，末端仍会停在正确的视觉构型上。**这等价于把「意图估计误差」变成闭环可抑制的扰动，而不是必须先消除的障碍。**

**灵感 3（对偶 → 视觉伺服是终极「标定吸收器」，也是终极「错误隐藏器」）**
直觉：R68 最怕「缓变故障被标定吸收」，R69 用流似然 FMA 做第二意见。视觉伺服把这件事推到极致：它靠闭环把图像残差控制到零，因此**对模型错误极其鲁棒——同时把「我错了」的证据也一起清零**。R69 的 FMA 依赖「条件在错世界上 → 动作落入低密度区」的残差；而一个收敛的伺服环根本不留残差。所以 R70 必须正面回答：**当闭环本身会隐藏错误时，意图层面的第二意见从哪来？** 答案是正交证据：声称的意图（stated）、行为揭示的意图（revealed，逆规划）、结果回看的意图（outcome）、以及图像特征与本体 / 世界模型预测的一致性（feature attestation）。单一通道可被伺服吸收，四条通道同时被骗的成本极高。

**灵感 4（意图是移动靶 → 时标分离）**
直觉：视觉伺服假设目标 φ* 固定。但人的意图会变：被试中途改主意、环境暗示改变目标。若意图变化的时间尺度 τ_intent 不比伺服收敛时间 τ_servo 大很多，闭环就变成「自信地追逐一个幻影」，稳态跟踪误差 ~ W·τ_intent。因此「伺服到意图」必须带时标分离判据 ISI = τ_intent / τ_servo；ISI 不足时不是硬追，而是退回「安全不变集伺服」（只维持不违反约束的最小承诺）。

**灵感 5（意图可被欺骗 → 会撒谎的目标比会撒谎的答案更危险）**
直觉：R69 已经担心「人类撒谎」。但 R70 更糟：一旦系统按「意图」伺服，攻击者只需让**目标**错，闭环会**完美收敛到错误目标**，收敛得越好，错误越隐蔽。这是「被证实的错误」的升级版：不是「问错」，而是「**做对了一个错的目标**」。所以必须交付：意图证书（正交证据）、特征级认证（防对抗贴片劫持 φ）、安全不变集兜底、以及「单次意图声明不得单独改变伺服目标」的纪律。

## 1. 形式化定义（增量：定义 310–327）

**定义 310（TELOS-RAS 总览）** TELOS = (GIP, ISVO, RIM, DVS, ISI, AIG, SIS, RAS-WM†)。四不变式：
(i) 实时流零学习写操作（继承 R68 定义 276-i）；
(ii) **伺服安全**：所有由意图目标驱动的运动必须通过 C-RAS-WM 前缀认证，图像误差不得把末端 / 相机驱出认证安全包络，且任务误差与控制量满足控制障碍函数（CBF）约束；
(iii) **意图证据纪律**：任何改变伺服目标的意图声明，须由 ≥2 条正交通道一致（stated / revealed / outcome / feature-attested），否则视为受污染，目标退回安全不变集；
(iv) **时标分离**：仅当 ISI ≥ S_min 时允许把伺服目标更新为 φ*(θ̂_t)；否则在漂移感知的 λ 下伺服到安全不变集。

**定义 311（意图后验 GIP）** 意图 θ ∈ Θ（目标 / 偏好 / 规范）。观察他人动作 u 与上下文 c，采用玻尔兹曼理性逆规划 p(u|c,θ) = exp(βQ_θ(c,u)) / Z(θ,c)；结合可能被投毒的声明 q，得后验 b_t(θ) ∝ p(q|θ) p(u|c,θ) b_{t−1}(θ)。意图 Fisher 信息 F_θ = E[∇log p(u|c,θ) ∇log p(u|c,θ)^T]；可辨识投影子 P_id = Π_{range(F_θ)}，不可辨识投影子 P_null = I − P_id。CRLB：Cov(θ̂) ⪰ F_θ^{-1}。

**定义 312（意图-任务相关子空间 RIM 的几何）** 任务由期望可观测量 φ* 定义；意图敏感雅可比 J = ∂φ*/∂θ ∈ ℝ^{m×d_θ}。相关投影子 P_rel = Π_{range(J^T)}（行空间），无关零空间 ker(J) = range(I − P_rel)。意图差异 δθ 是**任务相关**的 iff P_rel δθ ≠ 0。

**定义 313（ISVO：意图充分视觉可观测量）** 映射 φ: O → ℝ^m 是关于 (task, Θ) 的 ISVO，若：
(a) **充分性**：存在目标映射 φ*: Θ → ℝ^m，使任务完成 ⟺ φ(o) → φ*(θ)（在容差内）；
(b) **商不变性**：φ* 透过 Θ/ker(J) 分解，即 φ*(θ) 只依赖任务等价类 [θ]，且 J 在相关集上常秩（商为流形）；
(c) **伺服可观测性**：交互矩阵 L_φ = ∂φ/∂r 在可达位姿集上条件数 κ(L_φ) ≤ κ_max（IBVS 局部收敛）。
ISVO 残差 r_ISVO = φ(o) − φ*(θ̂)。

**定义 314（零空间免费消解 / Resolution Bonus 2.0）** 记 P_rel,id = Π_{range(J^T) ∩ range(F_θ)}（相关且可辨识子空间的投影子）。有效歧义熵 H_eff(b) = H(P_rel,id θ)。若 H_eff ≈ 0 而 b 在 ker(J) 或 ker(F_θ) 上仍有质量，则**不做交互**，直接按 φ*(θ̂) 伺服：落在 ker(J) 的歧义对任务无关（引理 19），落在 ker(F_θ) 的歧义任何被动观测都消解不了（问了也白问）。

**定义 315（三路决策 RIM）** 每轮按 H_eff 与 VoI 分三支：
- **伺服支**（H_eff ≤ τ_rel）：不交互，用当前 φ*(θ̂) 闭环；
- **探询支**（H_eff > τ_rel 且 ∃g: VoI_task(g) > c(g)）：在「问」与「判别性伺服」间按 VoI / 成本择优；
- **保守支**（其余，或意图受污染，或 ISI < S_min）：退化为 R69 / R68，λ = λ_floor(U_ale + 未消解 U_epi)。
其中 VoI_task(g) = I(P_rel,id θ ; y_g | g, o)，所有熵与互信息都在商空间 Θ/ker(J) 上计算。

**定义 316（判别性视觉伺服 DVS）** 主动选择信息视角 / 位姿：
g* = argmax_{g∈𝒜_info} I(P_rel,id θ ; y_g | g, o) / c(g)，s.t. C-RAS-WM 认证、位姿包络、ISI ≥ S_min。
随后用 IBVS 把相机 / 末端伺服到 g*（信息伺服），观测后更新 b，再伺服到 φ*(θ̂)。这是**对偶控制（dual control）**：同一个运动既推进任务又探询意图。

**定义 317（IBVS 不动点的标定不变性）** 伺服律 ṙ = −λ L̂_φ^+ (φ(o) − φ*(θ̂))。误差动力学 ė = −λ L_φ L̂_φ^+ e。在 e = 0 处运动为零，与 L̂_φ 无关 ⇒ **不动点对交互矩阵误差（含相机标定误差）不变**；标定误差只改变收敛率与瞬态，不改变收敛点（局部、在 L_φ L̂_φ^+ 正实特征值条件下）。

**定义 318（意图漂移与 ISI）** 意图随机游走 θ_t = θ_{t−1} + w_t，‖w_t‖ ≤ W，相关时间 τ_intent；伺服收敛时间 τ_servo ≈ (1/λ_min) ln(‖e_0‖/ε)。ISI = τ_intent / τ_servo。稳态跟踪误差上界 E‖e_ss‖ ≤ c·W τ_intent / λ_min。ISI < S_min ⇒ 目标视为移动靶，禁用 φ*(θ̂) 更新，转安全不变集。

**定义 319（意图证书 AIG）** 意图声明改变伺服目标前，需四通道中至少两条一致：stated（显式声明 q）、revealed（逆规划后验峰值）、outcome（事后状态回看是否匹配该意图）、attested（特征与本体的独立一致性，见定义 320）。一致则放行；否则 b 判为受污染，投影到鲁棒安全集 Θ_safe（最坏情形损失最小）并仅允许安全不变集伺服。

**定义 320（特征级认证 FAA）** 独立于 φ 的预测特征 φ_WM(o_{t−k:t}, 动作历史)（来自 R67 VISTA / 本体感受）。特征残差 r_feat = ‖φ(o) − φ_WM‖。**对抗贴片 / 特征劫持判据**：r_feat ↑ 而 r_ISVO → 0（闭环正常收敛）⇒ 图像特征被伪造，闭环把误差「藏」起来了。这是 R68 反吸收引理（引理 13）在图像特征空间的镜像。

**定义 321（安全不变集伺服 SIS）** 当目标不可信 / 漂移 / ISI 不足时，不伺服到 φ*(θ̂)，而伺服到满足安全约束的最小承诺集 𝒮_safe：min_{r ∈ 𝒮_safe} max_{θ∈Θ_safe} ℓ_task(φ(r), φ*(θ))，s.t. CBF(r) ≥ 0。保证在意图最坏情形下仍不违反硬约束（宁可少做，不可做错）。

**定义 322（参与式审计 VQAuditor-S）** 审计对象新增意图与伺服决策：意图声明是否有正交证据、ISVO 是否漏掉安全相关意图维度、零空间判定是否被误用、特征是否被劫持、漂移是否被后验滞后掩盖。结论回灌 AuditBuf，成为下一轮 RIM 的先验。

**定义 323（对抗意图干扰集 ℰ_TELOS）** ℰ_TELOS = ℰ_FLUID × ℰ_intent_deception × ℰ_feature_patch × ℰ_drift × ℰ_goal_hijack。其中意图欺骗 = 用一条与目标观测一致、但真实意图不同的声明 / 行为；特征贴片 = 小扰动 δo 使 φ(o) 偏移；目标劫持 = 通过改变场景诱导 φ* 漂移。

**定义 324（证书 J_TELOS）** J_TELOS = (J_FLUID, intent_identifiability = tr(F_θ^{-1}) 或 CRLB 迹, relevance_gain = H_eff 前后差, isvo_rank / κ, ISI, intent_certificate(通道一致位图), feature_attack_margin, servo_convergence_rate, telos_ver)。Valid ⇔ Valid(J_FLUID) ∧ 意图证书满足 ∧ CBF 未越界 ∧ ISI 判据满足。

**定义 325（严格包含）** 当 J 满列秩（无零空间）且 F_θ 满秩（全可辨识）且 ISI ≥ S_min 时，伺服支为空、RIM 退化为 R69 的两路（问 vs 保守），DVS 退化为 R69 的信息动作（动作空间连续化）；当 b 为点质量时退化为 R68。

**定义 326（实时预算与分频）** 意图后验与 RIM 在慢环（10–30 Hz）更新；DVS 目标选择在慢环；IBVS 伺服在快环（100–1000 Hz）。两环通过 φ*(θ̂) 与 ISI 门控耦合，快环在慢环两次更新之间保持目标不变（零阶保持），保证控制连续、无突变。

**定义 327（意图等价类商度量）** 在 Θ/ker(J) 上定义商度量 d_Θ([θ],[θ']) = min_{δ∈ker J} ‖θ − θ' − δ‖；所有 VoI / 熵 / 证书都在这个商空间上计算，避免在无关方向上浪费预算。

# IP-264 GIP：分层 ToM 意图后验 + 可辨识性
class GoalIntentPosterior:
    def update(self, b, u, c, q=None):
        b = b * boltzmann_rational_likelihood(u, c)      # p(u|c,θ)，逆规划
        if q is not None:
            b = b * report_likelihood(q)                 # 可能被投毒的声明
        b = normalize(b)
        F = fisher_information(b, u, c)                  # 意图 Fisher（定义 311）
        return b, F

# IP-265 ISVO：构造 / 选择意图充分视觉可观测量
def build_isvo(task_spec, theta):
    J     = jacobian_target_wrt_intent(task_spec, theta)  # ∂φ*/∂θ
    P_rel = projector(range(J.T));  P_null = I - P_rel
    phi   = select_features(task_spec, require_rank=True) # 常秩 + κ(L_φ) ≤ κ_max
    return phi, J, P_rel, P_null

# IP-266 RIM：三路决策（伺服 / 探询 / 保守）
def rim_decision(b, F, P_rel, budget):
    P_id  = projector(range(F))
    P_ri  = projector(range(J.T) & range(F))             # 定义 314
    H_eff = entropy(project(b, P_ri))
    if H_eff <= TAU_REL:
        return ('servo', None)                           # 零空间 / 不可辨识 → 免费消解
    best = None
    for g in info_candidates() + dvs_candidates():
        if not budget.allow(g) or not c_ras_wm.certify_info(g): continue
        voi   = mutual_info(project(theta, P_ri), y(g), g)   # 只在相关∩可辨识子空间
        score = voi - cost(g)
        if best is None or score > best.score: best = (g, score)
    if best and best.score > 0: return ('inquire', best[0])
    return ('conservative', None)

# IP-269/270/271：意图证书 + 特征认证 + 安全不变集
def certify_intent(b, q, u, outcome, phi, o, hist):
    votes = {
      'stated':   peak_matches(b, q),
      'revealed': peak_matches(b, u),
      'outcome':  outcome_consistent(b, outcome),
      'attested': norm(phi(o) - phi_wm(o, hist)) < TAU_FEAT,

def feature_attestation(phi, o, hist):

    return r_feat < TAU_FEAT                            # r_feat↑ ∧ r_ISVO→0 = 劫持

# IP-275 主闭环（继承 R69，仅在不确定性处置处插入意图-伺服层）
def TELOS_round(M, o, u, q=None):
    b, F = M.gip.update(M.b, u, o.ctx, q)
    phi, J, P_rel, P_null = M.isvo
    if not feature_attestation(phi, o, M.hist):         # 特征被劫持（定义 320）
        return M.sis.safe_invariant_servo(phi, M.Theta_safe)
    ok, votes = certify_intent(b, q, u, M.last_outcome, phi, o, M.hist)
    if not ok:                                          # 意图受污染（定义 319）
        return M.sis.safe_invariant_servo(phi, M.Theta_safe)
    if M.isi(M) < S_MIN:                                # 意图是移动靶（定义 318）
        return M.sis.safe_invariant_servo(phi, M.Theta_safe)
    route, g = M.rim.rim_decision(b, F, P_rel, M.budget)
    if route == 'servo':                                # 免费消解 + 闭环
        return M.dvs.servo_ibvs(phi, phi_star(b))
    if route == 'inquire':
        if is_dvs(g): b = M.dvs.dvs_then_servo(phi, phi_star, o)
        else:         b = M.cia.update_belief(b, M.cia.execute(g))  # 复用 R69
        return M.dvs.servo_ibvs(phi, phi_star(b))
    # 保守支：R69 / R68 兜底
    U_ale, U_epi = M.fluid_decompose(M, o)
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + U_epi))
    return M.ras_wm.certified_execute(lam)
```

## 3. 推导

**引理 19（零空间免费消解）** 若 θ1 − θ2 ∈ ker(J)，则 φ*(θ1) = φ*(θ2)，故伺服误差、闭环轨迹、任务成败对 θ1、θ2 完全相同；无需交互即可在任务意义下「消解」。系：R69 的 H(M) 高估了有效歧义；应以 H_eff = H(P_rel,id θ) 计。这给出**无查询的 resolution bonus**，且不牺牲安全——前提是 ISVO 把安全相关意图维度纳入 φ（否则见风险）。

**引理 20（IBVS 不动点的标定不变性）** 沿定义 317，e = 0 ⇒ ṙ = 0 与 L̂_φ 无关；局部稳定时误差指数收敛到 0，标定误差 δ 只改变收敛率（特征值实部有界下移），不改变极限点。故在任务相关流形上，R68 最担心的相机标定误差**不改变任务的稳态正确性**。系：这不能替代 FMA——它用「隐藏残差」换取鲁棒，检测仍须独立通道（定义 320）。

**引理 21（意图欺骗在伺服环内的不可观测性）** 若攻击者选 θ_adv 使 φ*(θ_adv) 为期望的错误目标，并让行为 / 声明与之自洽，则闭环收敛到 e = 0，任何基于 r_ISVO 的检测器在该点上的判别力不超过其误报率（两条假设给出同一残差分布）。故正交证据（定义 319）是**必要**而非锦上添花。系：单通道意图声明改变目标 = 可被完美欺骗。

**引理 22（意图漂移下的跟踪误差下界）** 在定义 318 的随机游走意图下，任何带宽有限（λ_min）的伺服环稳态误差 E‖e_ss‖ ≥ c·W τ_intent / λ_min（c 为与维度相关的常数）；当任务容差 < 该下界时，继续追踪意图必然违反任务容差 ⇒ 必须提高带宽（物理受限）或转安全不变集。系：ISI 是「该不该追」的硬判据，而非调参。

**定理 18（TELOS 严格包含 FLUID 与 CALM）** 在 A99–A101 下：
- 若 ker(J) = ∅ 且 F_θ 满秩且 ISI ≥ S_min，伺服支为空、RIM ≡ R69 两路决策，TELOS 与 FLUID 逐指令一致；
- 若 b 为点质量，意图无 epistemic，退化为 R68；
- 若意图受污染 / 漂移 / ISI 不足 / 特征劫持，TELOS 走 SIS，风险 ≤ R68 保守路径。
因此 TELOS 的安全侧不做任何让步，效率侧新增两类收益：零空间免费消解 + 闭环扰动抑制。R68 / R69 分别是「无视意图」与「只问不闭环」的边界。

**定理 19（三路决策的风险支配）** 设三路线在每状态的风险为 R_servo、R_inquire、R_cons。RIM 仅在 H_eff ≤ τ_rel 时选 servo（引理 19 保证其任务风险 = 最优相关意图下的风险），在 VoI > 成本时选 inquire（消歧只会收缩相关后验，风险 ≤ 保守支），否则选 cons。故在给定证据质量下 E[R_TELOS] ≤ E[R_cons]；且当意图证据不可信时，cons 分支保证不劣于 R68。

**引理 23（安全不变集的最坏情形保证）** SIS 解 min_{r∈𝒮_safe} max_{θ∈Θ_safe} ℓ_task 满足 max_θ ℓ_task ≤ ℓ_max(Θ_safe)（由 Θ_safe 直径决定），且 CBF(r) ≥ 0 对任意 θ 不变（只依赖 r，不依赖 θ̂）；故即使意图完全错误，硬约束仍不违反。系：安全由「几何承诺集」担保，不由「意图估计正确」担保。

## 6. 本轮最大风险

**一句话**：TELOS-RAS 的全部收益押在「ISVO 真的把任务（含安全）所需的一切意图维度都收进了 φ，且意图在伺服时标上足够平稳」这一前提上——**若 φ 漏掉一个安全相关意图维度，零空间的「无关」判定会把危险歧义当成免费消解而直接伺服；若意图本身可被伪造，闭环会以教科书级的收敛精度抵达一个错误目标：收敛得越完美，错得越彻底。**

**次级风险与缓解**：
1. **ISVO 误设**（把安全相关意图维度判进 ker(J)）→ E302 / E313 边界测试 + 审计 VQAuditor-S 复核 J 的秩与安全维度；

4. **非平稳意图被当固定目标追** → ISI 硬门控 + 引理 22 下界 + SIS 兜底；
5. **不可辨识歧义被误当成可问** → H_eff 只在相关∩可辨识子空间计算，ker(F_θ) 方向直接免费消解或保守，不再浪费预算。

    while not cbf_ok(r): r = project_to_cbf(r)
    return servo_to(r)

# IP-275 主闭环
def TELOS_round(M, o, u, q=None):
    b, F = M.gip.update(M.b, u, o.ctx, q)
    phi, J, P_rel = M.isvo
    if not feature_attestation(phi, o, M.hist): return M.sis.safe_invariant_servo(phi, M.Theta_safe)
    ok, _ = certify_intent(b, q, u, M.last_outcome, phi, o, M.hist)
    if not ok or M.isi(M) < S_MIN: return M.sis.safe_invariant_servo(phi, M.Theta_safe)
    route, g = M.rim.rim_decision(b, F, J, M.budget)
    if route == 'servo':    return M.dvs.servo_ibvs(phi, phi_star(b))
    if route == 'inquire':
        b = M.dvs.dvs_then_servo(phi, phi_star, o) if is_dvs(g) else M.cia.update_belief(b, M.cia.execute(g))
        return M.dvs.servo_ibvs(phi, phi_star(b))
    U_ale, U_epi = M.fluid_decompose(M, o)               # 保守支：R69/R68
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + U_epi))
    return M.ras_wm.certified_execute(lam)
```

## 4. 推导

**引理 19（零空间免费消解）** 若 `θ1−θ2 ∈ ker(J)`，则 `φ*(θ1)=φ*(θ2)`，伺服误差、闭环轨迹、任务成败对二者完全相同 ⇒ 无需交互即「消解」。系：R69 的 `H(M)` 高估有效歧义，应以 `H_eff=H(P_rel,id θ)` 计；这给出无查询的 resolution bonus，前提是 ISVO 覆盖安全相关意图维度。

**引理 20（IBVS 不动点的标定不变性）** `e=0⇒ṙ=0` 与 `L̂_φ` 无关；局部稳定时误差指数收敛，标定误差只改变收敛率不改变极限点。故任务相关流形上，R68 最担心的相机标定误差**不改变稳态正确性**；但它靠隐藏残差换鲁棒，检测仍须独立通道（FAA）。

**引理 21（意图欺骗在伺服环内的不可观测性）** 若 θ_adv 使 `φ*(θ_adv)` 为期望错误目标且行为 / 声明自洽，则闭环收敛到 `e=0`，任何基于 `r_ISVO` 的检测器在该点判别力 ≤ 误报率。故正交证据（AIG）是**必要**而非锦上添花；单通道声明改变目标可被完美欺骗。

**引理 22（漂移下的跟踪误差下界）** 随机游走意图下任何有限带宽伺服环 `E‖e_ss‖ ≥ c W τ_intent/λ_min`；当任务容差低于该下界时继续追踪必然违规 ⇒ 提带宽（物理受限）或转 SIS。ISI 是硬判据而非调参。

**引理 23（安全不变集的最坏情形保证）** SIS 解 `min_{r∈𝒮_safe} max_{θ∈Θ_safe} ℓ_task` 满足 `max_θ ℓ_task ≤ ℓ_max(Θ_safe)`，且 `CBF(r)≥0` 对任意 θ 不变（只依赖 r）；故意图完全错误时硬约束仍不违反——安全由几何承诺集担保，而非由意图估计正确担保。

**定理 18（TELOS 严格包含 FLUID 与 CALM）** A99–A101 下：`ker(J)=∅ ∧ F_θ满秩 ∧ ISI≥S_min ⇒` 伺服支为空、RIM≡R69 两路，TELOS 与 FLUID 逐指令一致；`b` 点质量 ⇒ 退化为 R68；意图污染 / 漂移 / ISI 不足 / 特征劫持 ⇒ SIS，风险 ≤ R68 保守路径。安全侧不让步，效率侧新增「零空间免费消解 + 闭环扰动抑制」两类收益。R68 / R69 分别是「无视意图」与「只问不闭环」的边界。

**定理 19（三路决策的风险支配）** RIM 只在 `H_eff≤τ_rel` 选 servo（引理 19 保证其任务风险 = 最优相关意图下的风险），在 `VoI>c` 选 inquire（消歧只收缩相关后验，风险 ≤ 保守支），否则选 cons。故给定证据质量下 `E[R_TELOS] ≤ E[R_cons]`；证据不可信时 cons 分支不劣于 R68。

## 7. 分析性预演（非实验数据，仅作可证伪的解析检查）

- **免费消解的量级**：若某状态 `H(M)=1.2 nats`（R69 会触发探询）但歧义全在 `ker(J)`，则 `H_eff=0`，TELOS 把该状态的交互预算从 1 降为 0；在歧义均匀分布于相关/无关各半的合成设定下，预期交互次数下降约 50%×覆盖率，与 E302 的 −35% 目标同向。
- **标定不变的稳态误差**：由引理 20，`e_ss=0` 与标定误差 δ 无关；因此 E303 中若观察到稳态误差随 δ 单调上升，即证伪 ISVO 的常秩 / 局部稳定假设（可能落入 `L_φL̂_φ^+` 非正实或 IBVS 局部极小）。
- **漂移下界自检**：取 `W=0.02 rad/frame`、`τ_intent=2s`、`λ_min=2/s`，得 `E‖e_ss‖ ≳ 0.02·2/2=0.02`（归一化特征单位）；若任务容差取 0.01，则 ISI 判据必须判「不可追」，与引理 22 一致。
- **欺骗不可观测自检**：在无 FAA / 无四通道的消融里，构造 `φ*(θ_adv)` 与真实 `φ*(θ_true)` 不同但闭环可达的假意图，应观察到 `r_ISVO→0` 且任务末态偏离；这直接检验引理 21 的「检测力 ≤ 误报率」。

## 8. 本轮最大风险

**一句话**：TELOS-RAS 的全部收益押在「ISVO 真的把任务（含安全）所需的一切意图维度都收进了 φ，且意图在伺服时标上足够平稳」这一前提上——**若 φ 漏掉一个安全相关意图维度，零空间的「无关」判定会把危险歧义当成免费消解而直接伺服；若意图本身可被伪造，闭环会以教科书级的收敛精度抵达一个错误目标：收敛得越完美，错得越彻底。**

**次级风险与缓解**：ISVO 误设（E302 / E313 边界测试 + VQAuditor-S 复核 J 秩与安全维度）；意图欺骗 / 目标劫持（AIG 四通道 + 引理 21 必要性 + ℰ_intent_deception 对抗训练）；对抗特征贴片（FAA + 随机平滑 + E306）；非平稳意图被当固定目标追（ISI 硬门控 + 引理 22 下界 + SIS 兜底）；不可辨识歧义被误当成可问（H_eff 只在相关∩可辨识子空间计算，`ker(F_θ)` 方向免费消解或保守）。
