# 第 57 轮（承接第 56 轮「证据地图-探询-协商」IP-127~132；灵感循环第 1 轮；本轮灵感：「产学研合作」×「物体泛化」）

> 第 56 轮把安全赌注从"模型置信"换到"证据"，让证据可积累、可探询、可协商，并用证据门把单点过度自信挡在承诺之外。但它默认了两件事：**(1) 证据是区域级的**；**(2) 证据由"自家系统"产出，且产出者与安全后果无关**。真实部署恰好相反：威胁常是**物体级、批次级**的（新供应商、新批次、透明玻璃、泡沫石头）；证据来自**多机构**（高校实验室、工厂、第三方测试、现场操作者），每个机构有不同的对象分布、不同的利益、不同的责任。于是第 56 轮的 `src_set` + 标量权重无法表达一个关键问题——**谁为哪一根物体属性、在哪一个人群/批次上、以多大责任担保**。本轮两条灵感各补一刀：**物体泛化**把证据索引从"区域"升级为"对象 × 属性轴 × 分布"；**产学研合作**把证据从"带权似然"升级为**带范围、带保证、带托管、带血缘、可召回的合约**。核心命题由"证据说可信"升级为 **"合约说：谁为哪根属性、在哪批对象上、以什么代价担保"**。

核心矛盾：
- **H26（来源 ≠ 责任）**：第 56 轮的溯源只有 `(n_visits, t_last, src_set)` 与标量权重，它把"实验室 98% 的基准"与"工厂同批次 20 次实测"当成同一种证据。二者覆盖的**对象分布不同**、出错时的**责任不同**；标量权重把"分布失配"和"激励不一致"压成一个数，既不可审计，也不可追责，更不可召回。
- **H27（区域正确 ≠ 对象正确）**：证据门是区域级的。区域信念完全正确，今天新放进去的陌生物体仍可让依赖它的承诺全错；反过来，实验室里验证过的物体，也未必能泛化到某工厂这一批。"见过这个区域"不等于"认识这个物体"，更不等于"知道这根属性在**这一批**上的分布"。物体泛化不是布尔量，而是**属性轴 × 分布**上的有界外推。

## 0. 直觉与动机

**灵感 1（产学研合作 → 证据是合约，不是似然）**
直觉：真实产学研里，一份数据从来不是"一份数据"：它带着**谁出的、覆盖什么、按什么标准测的、出了事谁负责**。高校给的是泛化先验与基准，工厂给的是同批次实测与工艺边界，第三方测试给的是可追责的合格证，操作者给的是现场佐证。把它们都压成一个 `w_h` 或 `w_cloud` 是巨大的信息损失。应把证据升格为**合约** `K = (issuer, scope, warranty, escrow, term, lineage)`：范围说"覆盖哪些属性、哪个人群/批次"，保证说"在此范围内失效率 ≤ w"，托管说"若违约，押金/信任分被扣"，期限说"什么时候失效"，血缘说"这份证据的上游数据集/产线是哪条"。合约可以被**签发、质疑、复核、撤销、召回**——这恰好把第 56 轮最大的软肋（坏证据长寿）从"等它衰减"变成"能把它召回"。

**灵感 2（产学研合作 → 跨机构融合必须先做"血缘去重"）**
直觉：三家机构各交一份"独立验证"，若它们其实用了同一份上游数据集、同一条产线、同一个仿真器，把它们当三份独立证据相乘，就是把**同一份误差数了三遍**——我称之为**证据洗白（evidence laundering）**。真正的独立性应按**血缘簇**计有效样本量，而不是按文件数。否则联盟越大、证据越多，系统反而越自信、越危险。

**灵感 3（物体泛化 → 泛化有坐标，且坐标挂在分布上）**
直觉：机器人见过很多箱子，能泛化箱子的"几何"，却未必泛化它的"质量分布"；能泛化实验室的箱子，却未必泛化某工厂这一批的箱子。所以"泛化到新物体"应拆成**属性轴**（几何 / 材料柔顺 / 质量分布 / 可动性 / 表面摩擦）上的**有界迁移**，且支撑集 `S_a(D)` 是**分布条件**的。新颖 = 至少一根**负载轴**跑出了支撑集，**或**对象跑出了合约覆盖的分布（新批次/新供应商）。

**灵感 4（物体泛化 → 只承诺"有覆盖或有独立佐证"的负载属性）**
直觉：第 56 轮证据门挂的是"区域证据类"；本轮把它细化为**对象属性覆盖门**。承诺 `c` 有一个负载属性集 `P(c)`（踏石承载依赖材料与质量分布，抓取依赖几何与表面摩擦）。每根负载轴必须被某个**有效合约**覆盖（范围内 + 承诺期内 + 未撤销 + 未污染），或有本地正交探针在保证下独立佐证；无覆盖的负载轴 → 探询 / 换批次 / 绕行 / 降档 / 协商。系统不必"认识整个物体"才敢行动，只需"本次承诺所依赖的那几根轴有覆盖"。

**灵感 5（见证对象与批次探针 → 泛化的可检验性）**
直觉：工业界验货用**标准试块/见证件**。把它搬进探询：用同批次见证对象做轻触/称重，或让视觉先验预测触觉再测残差——"泛化是否成立"从训练口号变成**每个检查点可测的量**。关键细节：见证对象必须与目标对象**同一血缘簇**，其证据在血缘去重后仍然有效；否则它只是另一次"独立"的假象，会重新制造证据洗白。

**灵感 6（违约归因与证据召回 → 从"衰减"到"追责"）**
直觉：一条坏证据不该只是慢慢过期，而应能**定责、扣托管、连带撤销同源证据**。地图记录每条信念依赖哪些合约；违约时沿依赖图做**溯源召回**，把污染信念立即移出证据门，强制重新承保。这样"坏证据长寿"被召回机制直接掐断，而不是靠半衰期祈祷。

## 1. 形式化定义（增量：定义 133–138）

**定义 133（对象属性束、分布与泛化坐标）**
对象 `o` 分解为属性束 `φ(o) = (φ_geo, φ_mat, φ_mass, φ_art, φ_surf)`，并携带制造溯源 `β(o) = (supplier, line, batch, lot)`。分布 `D` 是对象上的分布，可具体到供应商/产线/批次族。每根轴 `a` 有表示空间 `Z_a`、分布条件支撑集 `S_a(D) ⊆ Z_a`、距离 `d_a` 与支撑半径 `r_a`：
- **泛化坐标** `g_a(o; D) = d_a(φ_a(o), S_a(D)) / r_a`，`g_a ≤ 1` 称在支撑内；
- **迁移可靠度** `T_a(g; D→D')` 单调不增、`T_a(0; D→D)=1`，为跨分布外推时下游接触参数预测的可靠度**上界**；**泛化间隙** `γ_a = 1 − T_a(g_a)`；
- **负载属性集** `P(c)`：承诺 `c` 的可行性与安全判定实际依赖的属性子集。
新颖判据：`nov(o; D) ⇔ ∃a∈P(c): g_a(o;D) > 1`；**批次新颖** = 目标分布 `D_tgt` 不在合约覆盖的源分布族内。

**定义 134（证据合约 K）**
`K = (i, P_K, D_K, w_K, e_K, [t0,t1], payload, lin(K), σ_i)`：签发机构 `i`；覆盖属性集 `P_K`；覆盖分布 `D_K`（含 `β` 约束）；保证 `w_K` 为"对完全被 K 覆盖的接触、在 `D_K` 上失效率 ≤ `w_K`"的声明上界；托管 `e_K ≥ 0`（违约可扣）；期限；血缘 `lin(K)`（上游数据集/产线/仿真器簇）；机构签名 `σ_i`（不可抵赖）。
**覆盖谓词** `cov(K,c,o,t) ⇔ P(c) ⊆ P_K ∧ o∈D_K ∧ t∈[t0,t1] ∧ ¬revoked(K) ∧ ¬tainted(K)`。
**承保门**：承诺 `c` 成立当且仅当 `∀a∈P(c)` 存在 `K` 使 `cov ∧ a∈P_K`（取最紧 `w_K`），或存在本地正交证据且其上界 `≤ w_local`。

**定义 135（血缘去重与跨机构融合）**
证据 `e_{i,k}` 带血缘簇 `ℓ(e)`。**有效样本量** `ESS(E) = |{ℓ(e)}|_eff`，不是 `|E|`。机构权重 `w_i^eff = τ_i · ρ_i · π_i(z)`：`τ_i` 为由审计得到的信任后验；`ρ_i` 为有效独立因子（簇内 `1/√m_ℓ`，使一个簇不能靠文件数压倒别簇）；`π_i(z) = p_{D_tgt}(z)/p_{D_i}(z)` 为面向目标分布的似然比重要性权重，截断到 `[π_min,π_max]`，分布不重叠处置零。若重叠度 `O(D_tgt,D_i) < θ_ov`，则 `K` 的范围判定为**无效**而不是"低权重"。融合
`p(φ | E) ∝ Π_ℓ Π_{e∈ℓ} p(e | φ, δ_i, D_i)^{w_i^eff / m_ℓ} · p(φ)`——**显式不假设机构条件独立**。

**定义 136（对象泛化探询 OGP）**
探针 `π = (m, action, o_ref)`，`o_ref` 可为目标对象、**同血缘见证对象**或良性孪生件；代价 `(τ_p,e_p)`，似然诚实且非破坏（继承 A34）。最紧轴 `a* = argmax_{a∈P(c)} max(γ_a, ζ_a)`，其中 `ζ_a` 为未解决的覆盖/范围风险。`VOI` 对 `S_a(D)` 之外取悲观包络；见证探针只有在 `lin(o_ref)=lin(o)` 时才计入独立证据，否则仅作交叉检查（权重 `w_witness < 1`）。预算 `k_probes` 保证终止，`VOI_pess < θ_voi` 则拒绝承诺。

**定义 137（违约归因、托管清算与证据召回）**
在区域 `r` 的承诺接触失效或探针与合约矛盾时，对覆盖它的签发机构做归因后验 `P(i | F) ∝ P(F | i)·prior(i)`。若 `max_i P(i|F) ≥ θ_attr`：扣减 `e_{i*}`、`τ_{i*} ← τ_{i*}·κ_slash`，并**召回**所有满足 `dep(b) ∩ {K : lin(K) ~ lin(K_{i*})} ≠ ∅` 的信念 `b`——标记 `tainted`、立即移出证据门、等待重新承保。召回半径由 `ρ_recall` 控制；若污染闭包超过爆炸半径 `B_max`，升级 L2 协商或安全停，而不是静默全局失效。撤销单调：被撤销的 `K` 未经新证据不得复活。

**定义 138（承保-泛化证书 OGC）**
`J_o(c) = (o, β(o), P(c), {K_j 覆盖}, { (g_a, γ_a, ζ_a) }_{a∈P(c)}, local_probes, lineage_dedup, retraction_state, trust_snapshot)`。校验：每根负载轴有有效覆盖；`o∈D_K` 判定可靠；无污染/撤销；泛化坐标在支撑内或有独立本地佐证；无未解冲突；继承第 56 轮 MEC/SCC 全部检查与 L2 同意日志完备。证书是**条件证书**：以"合约保证诚实、范围判定 sound、血缘去重保守"为条件。

**正确性定理（Underwritten Generalization Soundness, UGS）**
在 A29–A36 基础上加：**(A37)** 合约保证诚实且校准——范围内接触的真实失效率 `≤ w_K`，概率 `≥ 1−δ_w`；**(A38)** 范围成员判定 sound——`o∈D_K` 与分布重叠检测的错误率 `≤ δ_scope` 且对不重叠保守拒绝；**(A39)** 血缘去重保守——估计 `ESS` 不大于真实独立证据数，重复证据不能抬高后验确定性；**(A40)** 依赖图完备——每条信念记录其依赖的合约，污染闭包在 `k_retract` 内可达且无孤儿信念；**(A41)** 见证探针同源假设诚实、非破坏（继承 A34）。则：
1. **承保健全性**：若承诺 `c` 通过 OGC，则 `P(fail(c)) ≤ Σ_{a∈P(c)} [ w_{K(a)} + δ_scope + γ_a + δ_probe ] + ε_fuse + ε_retract`；
2. **反洗白引理**：同血缘证据至多贡献一个有效单位，增加重复证据不能使一个未覆盖的负载轴通过承保门；
3. **问责单调性**：同一机构反复违约使其 `τ_i` 单调下降，其证据有效权重随之下调；不存在"大到不能倒"的签发者，被撤销/污染的合约不得进入证书；
4. **召回完备性**：若 `K` 在 `t` 被撤销，则所有"某负载轴仅由 K 覆盖"的承诺，必在 `t + k_retract` 前被重新承保或拒绝；
5. **覆盖单调性**：对象更陌生（`g_a` 增大）或范围更窄，可接受承诺集单调收缩——系统不会因"更陌生"而"更敢承诺"。

### IP-133 OAM（对象属性模型）

```python
def object_coordinates(o, M, D):
    phi  = encode_attributes(o)                    # geo/mat/mass/art/surf
    beta = provenance(o)                           # supplier/line/batch/lot
    g = {}
    for a in AXES:
        S = M.support[a][D]                        # 分布条件支撑集
        g[a] = dist(phi[a], S) / M.support_radius[a][D]
    return ObjModel(o, beta, phi, g)

def transfer_gap(g, D_src, D_tgt, a):
    if not M.overlap_ok(D_src, D_tgt): return 1.0  # 无重叠：最大间隙
    return 1.0 - T[a](g, D_src, D_tgt)             # 单调、校准上界
```

### IP-134 ECO（证据合约与承保门）

```python
def contract_covers(K, c, o, t):
    return (set(load_axes(c)) <= set(K.P) and
            in_distribution(o, K.D) and            # 含批次/供应商/产线
            K.t0 <= t <= K.t1 and
            not K.revoked and not K.tainted)

def underwriting_gate(c, o, t, M):
    need = load_axes(c)
    covered = {a: [K for K in M.contracts
                   if a in K.P and contract_covers(K, c, o, t)]
               for a in need}
    missing = [a for a in need if not covered[a]]
    if missing:                                    # 无覆盖：转探询/绕行/降档
        return GateResult(ok=False, missing=missing)
    return GateResult(ok=True,
                      w={a: min(K.w for K in covered[a]) for a in need})
```

### IP-135 FEC（联盟证据融合，含血缘去重）

```python
def consortium_fuse(M, E, D_tgt):
    out = M.b.copy()
    for r in touched_regions(E):
        for ell, es in group_by_lineage(E, r).items():
            if not overlap_ok(dist(ell), D_tgt):    # 分布不重叠：范围无效
                continue
            rho = 1.0 / sqrt(len(es))               # 簇内不重复计数
            pi  = clipped_lr(dist(ell), D_tgt)      # 截断重要性权重
            w   = [trust(e.issuer) * rho * pi for e in es]
            out[r] = bayes_update(M.b[r],
                                  weighted_likelihood(es, w))
    return out
```

### IP-136 OGP（对象泛化探询）

```python
def object_probe(c, o, M, budget):
    a_star = max(load_axes(c), key=lambda a: max(gap[a], scope_hazard[a]))
    best = None
    for p in admissible_probes(o, a_star, M, F_abs):   # 非破坏过滤（A34）
        eff = 1.0 if same_lineage(p.o_ref, o) else w_witness
        v = eff * voi_pess(p, a_star, M) - cost(p) - lam * risk_probe(p)
        best = max(best, (v, p))
    return best[1] if best and best[0] >= theta_voi else None
```

### IP-137 RAR（归因-召回）

```python
def attribute_and_recall(F, M, ledger):
    covering = [K for K in M.contracts if K in F.coverage]
    post = attribution_posterior(F, covering)      # P(issuer | F)
    i_star, p_star = argmax(post)
    if p_star < theta_attr:                        # 归因不足：只降权不追责
        soften(covering, factor=kappa_soft); return M
    slash(ledger, i_star, M.contracts[i_star].e)   # 托管清算
    decay_trust(i_star, kappa_slash)
    taint = lineage_closure(i_star, M, ledger)     # 同血缘/依赖闭包
    if size(taint) > B_max:
        return ('escalate', 'blast_radius', taint) # L2 协商 / 安全停
    for b in taint: M.belief[b].state = 'tainted'  # 证据门立即失效
    ledger.append(Revocation(i_star, taint, t_now))
    return M
```

### IP-138 OGC（承保-泛化证书）

```python
def object_generalization_certificate(c, o, M, ledger):
    gate = underwriting_gate(c, o, t_now, M)
    if not gate.ok: return ('reject', 'uncovered_axis', gate.missing)
    for a in load_axes(c):
        K = tightest(gate.w, a)
        if not scope_sound(K, o):      return ('reject', 'scope', a)
        if M.belief[a].tainted:        return ('reject', 'tainted', a)
        if not (g[a] <= 1 and gap[a] <= gamma_max) and not local_oe(a, M):
            return ('reject', 'generalization', a)
    if not all(l2.resolved for l2 in M.consent_log):
        return ('reject', 'consent_open')
    if not inherited_MEC_checks(M):    return ('reject', 'MEC')
    return ('ok', OGC(o, provenance(o), load_axes(c), gate.w,
                      gaps, local_probes, dedup_summary,
                      retraction_state, trust_snapshot))
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| OAM | O(\|P\|·d_a) | O(\|φ\|) | 支撑集分布条件、迁移上界单调 |
| ECO | O(1) 签署 / O(\|P(c)\|) 覆盖判定 | O(\|K\|) | 范围+期限+撤销+污染四查 |
| FEC | O(\|E\|·d + \|lineage\|log) | O(\|V\|·d_b) | 血缘去重保守（ESS 不放大） |
| OGP | O(k_p·(C_VOI+\|E\|)) | O(\|σ\|) | 悲观 VOI、见证同源、k_p 终止 |
| RAR | O(\|E\|+\|deps\|) 闭包 | O(\|deps\|) | 归因阈值、召回完备、爆炸半径 |
| OGC | O(\|P(c)\|+\|K\|) | O(\|J_o\|) | 无覆盖即拒绝、撤销即失效 |

```python
def contract_covers(K, c, o, t):
    return (set(load_axes(c)) <= set(K.P) and
            in_distribution(o, K.D) and            # 含批次/供应商/产线
            K.t0 <= t <= K.t1 and

def underwriting_gate(c, o, t, M):

    covered = {a: [K for K in M.contracts
                   if a in K.P and contract_covers(K, c, o, t)]
               for a in need}

    if missing:                                    # 无覆盖：转探询/绕行/降档
        return GateResult(ok=False, missing=missing)
    return GateResult(ok=True,
                      w={a: min(K.w for K in covered[a]) for a in need})
```

```python
def attribute_and_recall(F, M, ledger):
    covering = [K for K in M.contracts if K in F.coverage]
    post = attribution_posterior(F, covering)      # P(issuer | F)

    for b in taint: M.belief[b].state = 'tainted'  # 证据门立即失效

def lineage_closure(i_star, M, ledger):
    roots = {K for K in M.contracts if K.issuer == i_star}
    same  = {K for K in M.contracts
             if any(lineage_overlap(K.lin, r.lin) for r in roots)}
    return {b for b in M.beliefs if M.deps[b] & (roots | same)}
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| OAM | O(\|P\|·d_a) | O(\|φ\|) | 支撑集分布条件、迁移上界单调（A37） |
| ECO | O(1) 签发 / O(\|P(c)\|) 覆盖 | O(\|K\|) | 属性+分布+期限+撤销+污染五查 |
| FEC | O(\|E\|·d + \|lineage\|log) | O(\|V\|·d_b) | 血缘去重保守、分布不重叠即无效（A39） |
| OGP | O(k_p·(C_VOI+\|E\|)) | O(\|σ\|) | 悲观 VOI、见证同源、k_p 终止（A34/A41） |
| RAR | O(\|E\|+\|deps\|) 闭包 | O(\|deps\|) | 归因阈值、召回完备、爆炸半径（A40） |
| OGC | O(\|P(c)\|+\|K\|) | O(\|J_o\|) | 无覆盖即拒绝、撤销/污染即失效 |

**正确性定理（Underwritten Generalization Soundness, UGS）**
假设 A22–A28（第 53/54 轮）、A29–A36（第 55/56 轮）成立；并新增：
**(A37)** 合约保证诚实且校准——对 `D_K` 上被 `K` 完全覆盖的接触，真实失效率 `≤ w_K`，概率 `≥ 1−δ_w`；
**(A38)** 范围成员判定 sound——`o∈D_K` 与分布重叠检测错误率 `≤ δ_scope`，不重叠时保守拒绝；
**(A39)** 血缘去重保守——`ESS` 估计不大于真实独立证据数，重复证据不能抬高后验确定性；
**(A40)** 依赖图完备——每条信念记录其依赖的合约，污染闭包在 `k_retract` 内可达且无孤儿信念；
**(A41)** 见证探针同源假设诚实、且非破坏（继承 A34）。
则：

1. **承保健全性**：若承诺 `c` 通过 OGC，则
   `P(fail(c)) ≤ Σ_{a∈P(c)} [ w_{K(a)} + δ_scope + γ_a + δ_probe ] + ε_fuse + ε_retract`；
2. **反洗白引理**：同血缘证据至多贡献一个有效单位；增加重复证据不能使一个未覆盖的负载轴通过承保门；
3. **问责单调性**：同一机构反复违约使其 `τ_i` 单调下降，其证据有效权重随之下调；不存在"大到不能倒"的签发者；被撤销/污染的合约不得进入证书；
4. **召回完备性**：若 `K` 在 `t` 被撤销，则所有"某负载轴仅由 `K` 覆盖"的承诺，必在 `t+k_retract` 前被重新承保或拒绝；
5. **覆盖单调性**：对象更陌生（`g_a` 增大）或合约范围更窄，可接受承诺集单调收缩——系统不会因"更陌生"而"更敢承诺"；
6. **部署界**（对检查点与合约取联合界）：

```
P_safe ≥ 1 − Σ_cp [ Σ_{a∈P(c)}(w_{K(a)} + δ_scope + γ_a + δ_probe) + ε_fuse ]
             − P(归因失败) − P(召回超时 > k_retract) − P(污染闭包 > B_max 且升级失败)
```

关键：**证据门从"区域标签"变成"合约覆盖"**；**联盟不是把证据相加，而是先按血缘去重再融合**；**坏证据不再只是过期，而是可归因、可扣托管、可连带召回**；**不可逆接触仍以本地探针兜底**，合约绝不替代证据。

其中新增：`o` 当前对象标识；`β(o)` 供应商/产线/批次/料号；`K_set` 生效合约集；`τ_i` 机构信任快照；`taint_state` 污染/召回状态；`J_o` 承保-泛化证书；`retraction_log` 撤销与召回日志。

**联盟证据交换协议（产学研闭环）**
云端维护版本化 **承保账本**（underwriting ledger），边端只持有本地 `probe_log` 与 `taint_state`。合约生命周期：

```
draft → issued(签名+托管) → challenged(边端反证/探针矛盾)
      → re-underwritten(复核/缩窄范围/提高 w_K 或托管)
      → revoked/expired → recall(taint 闭包) → 重新承保
```

角色分工：**高校**签发泛化先验与基准合约（`w_K` 宽、托管低、范围大，只能做"弱证据"）；**工厂**签发批次域合约（范围窄、`w_K` 紧、托管高）；**第三方测试**签发合格证类合约（强问责）；**操作者**提供现场佐证（走第 56 轮 L1/L2 与隔离）；**边端**拥有反证权——探针与合约矛盾即发起 `challenge`，云端必须复核。这样产学研不是"数据汇总"，而是**带责任边界的证据供应链**。

## 6. 本轮最大风险

**一句话**：本轮把安全赌注从"证据质量"换到"合约问责"，但合约由利益未必与安全一致的机构书写——一份范围写得漂亮、签名齐全、`w_K` 看似很紧的合约，可以把坏先验洗成"有担保"的信念，而血缘去重与违约归因本身也会出错；最深的风险是系统把"有人负责"误当成"它安全"，因此必须以**范围诚实审计、真能扣的托管、保守 ESS 下界**为护栏，且**不可逆接触永远保留一次本地探针**，绝不让合约替代证据。
