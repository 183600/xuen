# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「用户画像」×「参数高效微调」）

> R69 把不确定性一分为二，让系统学会「问」：aleatoric 收紧、epistemic 去交互消解，并用流似然做一条标定不可吸收的第二意见。但 R69 有一个几乎没被审视的隐藏假设——**它面前的那个「人」是无脸的**。VoI 用同一套成本模型、证据纪律用同一个 k-正交阈值、流策略用同一份模态分布去面对所有人。可现实里，「谁在回答」恰恰决定了「这个回答值多少」：领域专家的一次判断可能胜过三个外行的共识；一个爱面子、习惯性附和、或已经疲劳的用户，其「多方一致」不过是共谋的另一种写法。
>
> 本轮两个灵感各补一块：
> - **用户画像**给出「证据源的条件可信度」：不是给用户贴标签做推荐，而是给每个回答者一个**带不确定性的可靠性与沟通约定模型**，让 VoI 与证据纪律变成 source-conditioned；
> - **参数高效微调**给出「画像如何落地」：把「这个用户的感知-动作约定」存成一个**低秩、可热插拔、可撤销、可审计**的 ΔW_u，而不必为每人重训。
>
> 但两者合起来会制造一个比 R69 更隐蔽的陷阱：**画像是一个被压缩的信念，而低秩让它便宜到可以悄悄部署、又便宜到可以悄悄投毒**。更致命的是，画像会**自我实现**——一旦把某人标成「可靠」，系统就更少向他求证，因而更少获得纠正证据，画像于是永不更新，错误被固化。**画像错了不可怕，可怕的是画像让系统不再去发现它错了。**
>
> 核心命题：**把画像从「隐藏的先验」升级为「可证伪、可撤销、带证书的对象」；用 PEFT 让画像便宜到人人可适配，同时用「画像-数据对偶校核 + 画像证伪调度 + 探索配额」保证它不会变成认知牢笼。冷启动/空画像必须逐指令退化为 FLUID-RAS。** 命名 **PERSONA-RAS**（Profile-adaptive Epistemic Reliability & Source-weighted Negotiated Adaptation）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我到底在向谁求证、我凭什么信他、我怎么知道自己认错了人**」——不确定性管理第一次把「人」本身也当成一个需要持续校准、并主动证伪的变量。

## 0. 直觉与动机

**灵感 1（用户画像 → 证据源不是无脸的）**
直觉：R69 的 VoI 公式 `H(M|o) − E[H(M|o,y)]` 里，`y` 被默认是「一个诚实但可能模糊的回答」。但同一个 `y` 由不同人说，信息量天差地别：专家说「是」近乎判决，陌生人说「是」只是弱证据，习惯性附和者说「是」甚至可能是负信息（他越是附和，越说明你没问对）。用户画像在这里的正确用法不是推荐系统那套「猜你喜欢」，而是构造一个**回答者模型**：对这个人的专业域、诚实度、表达约定、当前疲劳/可用状态给出带方差的估计，于是 VoI 从「问什么能消歧」升级为「**问谁、问什么、以什么方式问，才最划算**」。

**灵感 2（参数高效微调 → 画像是低秩、可撤销的信念对象）**
直觉：为每个用户重训策略既贵又不可审计。PEFT（LoRA / adapter / hypernetwork）让我们把「这个用户的感知-动作约定」压缩成 `ΔW_u = B_u A_u`（rank r ≪ d），热插拔、可回滚。但这里有一个必须正面承认的事实：**低秩本身就是一种「画像即压缩信念」的声明**——它只能表达少数自由度，所以它既可审计（维数低）、也可欺骗（后门能藏进低秩子空间）。PEFT 降低了适配成本，也同等降低了投毒与过拟合的成本。

**灵感 3（对偶 2.0 → 符号画像 vs 隐式适配器）**
直觉：R69 的对偶是「传感器残差 vs 动作似然」，检的是「世界有没有被标定骗」。R70 的对偶是 **显式符号画像**（可读：信任向量、专长域、沟通约定、疲劳度）与 **隐式适配器**（不可读：ΔW_u），检的是「**人有没有被画像骗**」。二者应当一致：如果符号画像说「该用户可信」，但适配器条件化后的策略在这位用户的实际行为上持续低似然，则画像自相矛盾——这是一条全新的异常通道，恰好是 R69 最大风险（模态分布不可信）的「个性化版」：不是模态分布错了，而是**模态分布被一个错误画像条件化了**。

**灵感 4（自我实现牢笼 → 画像必须被主动证伪）**
直觉：这是本轮最重要的伦理/安全直觉。一个被标为「可靠」的用户会被问得更少；问得更少就得到更少纠正；更少纠正就让画像更不更新——**画像成了确认偏误的机器**。更糟的是，它会自我加固：少数几次被问到时，用户若为了维持「可靠」形象而附和，系统就得到「看，果然一致」的伪证据。破解办法只有一个：把「了解这个人」本身当作一个有信息价值的动作，把 VoI 拆成 `VoI_task + β·VoI_profile`，并划出一份**固定的探索/证伪配额**，专门用来检验那些「高影响、低置信、久未验证」的画像维度，哪怕它当下不消歧、不提效。

**灵感 5（新攻击面 → 画像投毒与适配器后门）**
直觉：一旦系统「认人」，就有了四种新攻击者：往历史数据里投毒让画像误判、在低秩子空间埋触发器做后门、用「一致性」换取被信任的迎合陷阱（sycophancy trap）、新身份冒充高可信专家（cold-start spoofing）。画像越是被用来「少问」，这些攻击的收益就越高。所以画像与适配器必须带**部署证书**（行为漂移上界、安全层零改动、触发词扫描、数据来源 hash），且「单次证据不单独改变信任等级」——把 R69 的证据纪律上移一层。

**灵感 6（严格包含 → 空画像是 R69 的边界）**
直觉：延续前几轮的理论姿态——新层必须是旧层的严格泛化。没有画像、画像被撤销、或适配器未过证书时，系统必须逐指令退化为 FLUID-RAS（进而退化为 R68）。否则每加一层就多一个需要独立信任的黑箱，而这一轮的黑箱恰恰是「对人的判断」，最不该无证据地信任。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（PERSONA-RAS 总览）** PERSONA-RAS = (UPM, PEA, SCV, PDC, PFS, IBG†, ORS, RAS-WM‡)。三不变式：
(i) **实时流零学习写操作**继承 R69（定义 293-i）：快环只读画像，画像更新全部走异步慢环；
(ii) **画像可撤销 + 冷启动退化**：画像禁用/为空/适配器未过证书时，策略逐指令退化为 FLUID-RAS；
(iii) **画像纪律**：单次交互/单源回答既不单独定案，也**不单独改变信任等级**；信任与画像更新需 ≥k 个正交证据源一致或显式人工确认，并按半衰期衰减。

**定义 311（双层画像 UPM）** 显式符号画像 `P_u^sym = (τ_u, e_u, κ_u, f_u, h_u)`：`τ_u` 为对各证据源/回答者的可信度分布（带方差）、`e_u` 为专长域映射、`κ_u` 为沟通约定（如「点头」在此人身上是否表示肯定）、`f_u` 为疲劳/可用状态、`h_u` 为历史证据 hash。隐式适配器 `P_u^imp = ΔW_u`。联合画像 `P_u = (P_u^sym, P_u^imp)`。前者可读可审计，后者表达感知-动作的连续约定。

**定义 312（参数高效适配 PEA）** 基础策略 `π_θ` 冻结；用户条件通过低秩增量 `ΔW_u = B_u A_u`（`A_u∈ℝ^{r×d}, B_u∈ℝ^{d×r}, r≪d`）注入到非安全层（条件编码器/速度场）。或用共享超网 `h_φ(P_u^sym)` 直接生成 adapter（`φ` 只训一次，避免逐人训练）。**安全层（C-RAS-WM 认证、λ_floor、安全包络）永远只跑基础 θ，不接受任何 adapter 改写。**

**定义 313（画像条件策略）** `π_{θ,u}(ξ|o) = π_θ(ξ|o; ΔW_u)`。R69 的模态分解（定义 296）在 `π_{θ,u}` 下进行，得 `{m_k^u}, ŵ_k^u, H_mode^u, Δ_min^u`。空画像时 `π_{θ,u}=π_θ`。

**定义 314（源条件可信度 SCV）** 每个回答者 `i` 有可信度后验 `ρ_i`（均值 + 方差），由符号画像与历史战绩更新。回答 `y_i` 的似然为 `p(y_i|M,g,ρ_i)`。证据合并采用**信任加权 + 正交一致**：`w_i ∝ ρ_i · agree_i`；低置信的 `ρ_i` 自动收缩向均匀（不确信就别偏信），`k`-正交一致的阈值随 `ρ_i` 自适应——对低可信源要求更多正交源一致。

**定义 315（画像条件 VoI）** `VoI_total(g) = VoI_task(g) + β_u · VoI_profile(g)`，其中 `VoI_profile(g) = I(P_u ; y | g,o)` 是这次交互能减少多少「关于回答者本身」的不确定性。选择 `g* = argmax_g [VoI_total(g) − c(g)]`，s.t. 安全、预算、探索配额。`β_u` 随画像置信度自适应：画像越不确定，`β_u` 越大。

**定义 316（画像-数据对偶 PDC）** 符号画像预测的「该用户行为分布」`q_u(y)` 与适配器下实测似然 `p_{θ,u}(ξ|o)` 的失配 `D_u = D_KL(q_u ‖ p_{θ,u})`（或等价的校准失配分）。**`D_u` 高 ⇒ 画像与行为打架 ⇒ 冻结该画像的信任提升、强制回基础策略并标记复检。** 这是 R69 `(r_res, Δa)` 对偶的个性化镜像：R69 检「世界是否被标定骗」，R70 检「人是否被画像骗」。

**定义 317（画像证伪调度 PFS）** 为每个画像维度维护三张待办：`stale`（久未验证）、`conflict`（近期证据冲突）、`high_stakes`（高影响低置信）。以固定探索配额 `η`（总交互预算的固定比例）分配给「最可能被证伪」的维度做主动探询。**即便 task-VoI 不高也要花这份预算**——它的收益不是当前任务，而是「防止画像永久错误」。

**定义 318（画像半衰期、遗忘与撤销 ORS）** 每个画像维度按时间与证据做指数遗忘 `γ^Δt`（半衰期 `T_½` 可配）；信任等级设**单次增长率上限**，防止一次好印象永久提权。撤销：任一 adapter 可整体卸下回到基础策略，且撤销必须留下可审计 diff（记入 `J_PERSONA.profile_diff_hash`）。

**定义 319（画像投毒与后门威胁 ℰ_persona）** `ℰ_persona = {profile_poison（历史数据投毒致画像误判）, adapter_backdoor（低秩子空间埋触发器）, sycophancy_trap（以一致性换取被信任）, coldstart_spoof（新身份冒充专家）}`。并入 AIC：`ℰ_PERSONA = ℰ_FLUID × ℰ_persona`。

**定义 320（适配器部署证书 ACP）** adapter 上机前必须通过四检：(a) 行为漂移上界 `KL(π_θ ‖ π_{θ,u}) ≤ δ_beh`（仅允许落在该用户相关维度）；(b) 安全层零改动（安全认证只跑基础 θ）；(c) 触发词/后门扫描（输入无关扰动下 adapter 激活的稳定性）；(d) 训练数据与来源 hash 可追溯。

**定义 321（画像纪律 IBG†）** 单次交互/单源回答既不单独定案，也不单独更新信任等级；信任更新需 ≥k 个正交源一致或人工确认；**画像更新与任务决策分离**（慢环 / 快环），快环只读。

**定义 322（冷启动严格退化）** `P_u` 为空/禁用/证书失效时：`π_{θ,u}=π_θ`、`VoI_profile=0`、SCV 退化为均匀信任、PFS 不触发 ⇒ 逐指令等于 FLUID-RAS。⇒ R69 是 R70 在「无画像」边界上的严格退化。

**定义 323（证书 J_PERSONA）** `J_PERSONA = (J_FLUID, profile_conf_ece, D_u, adapter_cert_hash, profile_diff_hash, exploration_ratio, stale_high_stakes_dims, persona_ver)`。`Valid ⇔ Valid(J_FLUID) ∧ profile_conf_ece ≤ τ_p ∧ adapter_cert 有效 ∧ 探索配额满足 ∧ 无高危 stale 维度`。

**定义 324（双环时序）** 快环（实时决策）继承 FLUID，仅用当前 `P_u` 条件化；慢环（画像更新）异步、批处理、带 k 源一致与半衰期。快环**零画像写操作**保持不变式 (i)。

**定义 325（画像数据最小化 DMP）** 只保留「对决策有可测影响」的画像维度：影响分 `= 去掉该维度后策略行为/风险的变化`。无影响维度不画像、不存储。这是把「数据最小化」从口号变成工程判据——防止画像膨胀成监控，也压缩后门可藏的子空间。

```python
# IP-264 UPM + IP-265 PEA：双层画像与参数高效适配
class PersonaAdapter:
    def __init__(self, base_flow, hyper, store, cert):
        self.flow, self.hyper = base_flow, hyper      # 基础策略冻结；h_phi 共享超网
        self.store, self.cert = store, cert

    def resolve(self, u):
        P = self.store.get(u)
        if P is None or P.disabled:                    # 冷启动/撤销 → 严格退化 FLUID
            return self.flow, None
        dW = P.dW or self.hyper(P.sym)                 # 无人手 adapter 时由符号画像生成
        if not self.cert.valid(P.cert_hash) or P.stale_high_stakes:
            return self.flow, None                     # ACP 未过 → 不个性化
        return self.flow.with_lora(dW), P              # 仅注入非安全层

# IP-266 SCV：源条件可信度（带方差，低置信自动收缩向均匀）
def source_trust(P, modes):
    rho = P.sym.tau if P else uniform_trust()          # 空画像 → 均匀
    for i in rho: rho[i] = shrink_to_uniform(rho[i], conf=rho[i].var)
    return rho

def choose_info(modes, o, rho, P, budget):
    best = None
    for g in info_action_candidates(modes):
        if not budget.allow(g) or not c_ras_wm.certify_info(g, o): continue
        assert c_ras_wm.uses_base_policy(g)            # 信息动作安全永远走基础 θ
        voi_task    = entropy(modes.w) - expected_entropy(modes.w, g, o)
        voi_profile = mutual_info_profile(P, g, o) if P else 0.0   # 了解「人」本身
        score = voi_task + beta(P) * voi_profile - cost(g, rho)    # 低可信源提问成本更高
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None

# IP-267 PDC：画像-数据对偶校核（发现「认错人」）
def profile_data_mismatch(P, pol, o, xi_obs):
    if P is None: return 0.0
    q  = P.sym.predict_behavior(o)                     # 符号画像预测的行为分布
    p  = pol.density(xi_obs, o)                        # 适配器条件下的实测似然
    return kl_divergence(q, p)                         # 高 → 画像与行为打架

# IP-268 PFS：画像证伪调度（用固定探索配额打破自我实现牢笼）
def falsification_probe(P, o, budget):
    if P is None: return None
    dims = rank_by(P.dims, key=lambda d: stakes(d) * staleness(d) * (1 - conf(d)))
    for d in dims[:budget.explore_slots]:              # 不按 task-VoI，而按「最可能错」
        g = probe_for(d, o)
        if budget.allow(g, stage='explore') and c_ras_wm.certify_info(g, o):
            return g
    return None

# IP-275 主闭环：快环（决策）+ 慢环（画像），零实时画像写
def PERSONA_RAS_round(M, u, obs):
    pol, P = M.adapter.resolve(u)                      # 空画像 → 等价 FLUID
    modes  = pol.sample_decompose(obs)                 # R69 定义 296，在 π_{θ,u} 下
    rho    = M.scv.source_trust(P, modes)
    D_u    = M.pdc.mismatch(P, pol, obs, M.last_action)
    suspect_profile = (D_u > TAU_PDC)
    g_explore = M.pfs.falsification_probe(P, obs, M.budget) if P else None
    g_task    = M.mint.choose_info(modes, obs, rho, P, M.budget) \
                if (modes.epi > TAU_EPI and not suspect_profile) else None
    g = merge_by_budget(g_explore, g_task)             # 探索配额优先，再 task-VoI
    if g is not None:
        y = M.cia.execute(g)                           # 看/问/触，k-正交证据纪律
        modes = M.cia.update_belief(modes, y, rho)     # 信任加权 + 多源一致
    U_floor = modes.ale + (modes.epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    lam, k = M.safety.base_policy_guard(lam, modes, U_floor)   # 安全层永不接受 adapter
    mode = select_mode(modes, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.slow_q.push(u, g, y, D_u, modes)                # 画像更新只入慢环，快环零写
    return k, lam, mode, (modes.ale, modes.epi, D_u)

# IP-324 慢环：证据纪律上移到画像（k 源一致 + 半衰期 + 增长率上限）
def update_profile_slow(M, batch):
    for u, ev in group_by_user(batch):
        ev = require_k_orthogonal_agreement(ev)        # 单源不更新（IBG†）
        P = M.store.get(u)
        P.sym.tau = forget_and_bounded_update(P.sym.tau, ev, half_life=T_HALF,
                                              max_gain=DG_MAX)
        if M.pdc.batch_mismatch(P, ev) > TAU_PDC:
            P.flag_recheck()                           # 只标记，不自动提权
        P.dW = M.hyper(P.sym) if P.needs_refresh else P.dW
        P.cert_hash = M.acp.certify(P, M.base_flow)    # ACP 重检后才可再上机
        M.store.put(u, P)
```

## 3. 推导

**引理 19（画像消歧的方向性收益与方向性风险）** 设某歧义实为「用户特定约定」（如该用户的「笑」恒指紧张），在基础分布下表现为 `H_mode>0` 的多模态；若画像正确，`U_epi` 降到 0，按 R69 引理 16 期望任务误差下降 `≥ c·Δ_min(1−e^{−ΔH})`。但若画像以概率 `π_c` 正确、`1−π_c` 张冠李戴，则期望误差变化为 `(2π_c−1)·c·Δ_min(1−e^{−ΔH})` 的一阶形式：**收益是有方向的**——只有 `π_c>1/2` 时个性化才净有益；`π_c` 低于此，个性化会主动把多模态「错误地收敛」到单一错误模态，比不做画像更差。系：**个性化不是免费的方差缩减，它是一次有符号的押注**；这正是必须把 `π_c` 写进证书、并用 PDC 持续检验的原因。

**引理 20（源条件加权证据的正确性依赖信任校准）** 设真实欺骗率 `δ_p`、各源欺骗相关 `ρ<1`。若信任权重 `ρ_i` 校准（ECE ≤ τ_p）且与欺骗倾向正相关，则加权 k-正交一致的错误采纳率 `≤ δ_p·ρ^{k−1}·(1+2τ_p/ρ̄)`，优于均匀信任的 R69 上界；但若信任被系统性高估（把不可信源当可信），加权会**放大**错误，最坏可达均匀策略的数倍。系：**信任加权不是无条件改进，它的收益恰好等于「信任估计的校准度」**；因此画像纪律（定义 321）和 ACP 是前提而非装饰。

**引理 21（自我实现牢笼与探索配额的必要性）** 设某个错误画像维度 `d` 的探询概率为 `p_d`。若 `p_d=0`（因为系统总信它、从不验证），则 `d` 永远错误，期望检出时间为 `∞`。若每单位时间总探索配额 `η>0` 且均摊到 `|D|` 个高影响维度，则 `p_d ≥ η/|D|`，检出时间服从几何分布，期望 `≤ |D|/η`。故：**探索配额不是效率损失，而是画像可辨识性的必要条件**；`η=0` 的「纯利用」画像是数学上不可纠正的。

**定理 18（PERSONA 严格包含 FLUID/R68）** 在空/禁用/证书失效画像下，按定义 322 逐指令等于 FLUID-RAS（进而 R68）。在 A99（`profile_conf_ece ≤ τ_p`、探索配额 `η ≥ η_min`、adapter 通过 ACP）下，PERSONA 在任意状态的期望风险 `≤` FLUID；当画像信息无增益（`VoI_profile=0` 且 `π_c≤1/2`）时两阶段退化为 FLUID。安全侧：由于 adapter 永不进入安全层（定义 312/320-b），认证前缀与安全包络逐位相同，故**安全侧不做任何让步**；个性化只在「选哪个模态/问谁」上取得 resolution bonus。

**定理 19（适配器安全、无突变、可撤销）** ACP 约束 (a)(b) 保证非安全层行为漂移有界、安全层零改动，故 `C-RAS-WM` 认证结果与基础策略一致；ORS 的撤销把策略单调地（沿 KL 不增方向）拉回基础 θ，且慢环更新不触碰快环零写不变式 ⇒ 控制连续、无突变；画像误判最坏退化为「更保守/更保守地少问」，不会越过安全包络。

## 6. 本轮最大风险

**一句话**：PERSONA-RAS 的全部收益押在「画像可信」这一前提上，而画像恰恰是**最容易被污染、最容易过期、又最容易自我实现**的对象——若画像因投毒、迎合或冷启动冒充而错误，个性化不会只是「没帮上忙」，它会**系统性地关闭能纠正它的证据通道**（少问→少纠错→画像更不改），于是系统对这个人的错误既自信又不可见；PEFT 又把这种错误做成低秩、便宜、可悄然部署且难以从行为外表看出的形态——**R69 的风险是「问错」，R70 的风险是「认错人」：认错人之后，连该问谁都不会再问对**。

**次级风险与缓解**：
1. **画像自我强化/确认偏误** → PFS 固定探索配额 + `VoI_profile` 项 + 引理 21 的检出时间界；
2. **画像投毒/适配器后门** → 定义 319–320（ACP 四检 + k 源一致更新 + 触发词扫描）+ E305–E306；
3. **迎合陷阱/冷启动冒充** → 信任用带方差分布、低置信收缩 + 单次增长率上限 + E307–E308；
4. **画像过期/漂移** → 半衰期指数遗忘 + PDC 复检 + E309；
5. **隐私泄漏与画像膨胀** → 定义 325 数据最小化判据 + E315（敏感属性推断与分组公平）；
6. **适配器破坏安全** → 定义 312：安全层永不接受 adapter，认证只跑基础 θ + 定理 19。

```python
class PersonaAdapter:
    def resolve(self, u):
        P = self.store.get(u)
        if P is None or P.disabled:                    # 冷启动/撤销 → 严格退化 FLUID
            return self.flow, None
        dW = P.dW or self.hyper(P.sym)                 # 符号画像驱动超网生成 adapter
        if not self.cert.valid(P.cert_hash) or P.stale_high_stakes:

# IP-266 SCV：源条件可信度 + 画像条件 VoI
def choose_info(modes, o, rho, P, budget):
    best = None
    for g in info_action_candidates(modes):
        if not budget.allow(g) or not c_ras_wm.certify_info(g, o): continue
        assert c_ras_wm.uses_base_policy(g)            # 信息动作安全走基础 θ
        voi_task    = entropy(modes.w) - expected_entropy(modes.w, g, o)
        voi_profile = mutual_info_profile(P, g, o) if P else 0.0
        score = voi_task + beta(P) * voi_profile - cost(g, rho)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None

    return kl_divergence(P.sym.predict_behavior(o), pol.density(xi_obs, o))

        P.sym.tau = forget_and_bounded_update(P.sym.tau, ev,
                                              half_life=T_HALF, max_gain=DG_MAX)
        if M.pdc.batch_mismatch(P, ev) > TAU_PDC:
            P.flag_recheck()                           # 只标记，不自动提权
        P.dW = M.hyper(P.sym) if P.needs_refresh else P.dW
        P.cert_hash = M.acp.certify(P, M.base_flow)    # ACP 重检后才可再上机
        M.store.put(u, P)
```

## 4. 推导

**引理 19（画像消歧的方向性收益与风险）** 若歧义实为用户特定约定，画像正确时 `U_epi→0`、误差降 `≥ c·Δ_min(1−e^{−ΔH})`；若画像以概率 `π_c` 正确，则净收益与 `(2π_c−1)` 同号。**个性化是一次有符号的押注**：`π_c≤1/2` 时它会把多模态「错误地收敛」到单一错误模态，比不做画像更差。⇒ 必须把 `π_c` 写进证书并用 PDC 持续检验。

**引理 20（源条件加权证据的正确性依赖信任校准）** 信任 `ρ_i` 校准（ECE ≤ τ_p）且与欺骗倾向正相关时，加权 k-正交一致错误采纳率 `≤ δ_p·ρ^{k−1}(1+2τ_p/ρ̄)`，优于均匀信任；若信任被系统性高估，加权会**放大**错误，最坏数倍于均匀策略。⇒ 信任加权的收益恰等于「信任估计的校准度」。

**引理 21（自我实现牢笼与探索配额的必要性）** 错误画像维度 `d` 的探询概率 `p_d=0` ⇒ 永远错误、期望检出时间 `∞`。若每单位时间探索配额 `η>0` 均摊到 `|D|` 个高影响维度，则 `p_d ≥ η/|D|`，检出时间几何分布、期望 `≤ |D|/η`。⇒ **`η=0` 的纯利用画像是数学上不可纠正的**；探索配额是可辨识性的必要条件，不是效率损失。

**定理 18（PERSONA 严格包含 FLUID/R68）** 空/禁用/证书失效画像下按定义 322 逐指令等于 FLUID（进而 R68）。在 A99（`profile_conf_ece ≤ τ_p`、`η ≥ η_min`、adapter 过 ACP）下，任意状态期望风险 `≤` FLUID；画像无信息增益时退化为 FLUID。安全侧：adapter 永不进入安全层 ⇒ 认证前缀与安全包络逐位相同，**安全不做让步**，收益只在「选模态/问谁」的 resolution bonus。

**定理 19（适配器安全、无突变、可撤销）** ACP (a)(b) 保证非安全层漂移有界、安全层零改动，认证结果与基础策略一致；ORS 撤销把策略沿 KL 不增方向拉回 θ；慢环不触碰快环零写不变式 ⇒ 控制连续、无突变；画像误判最坏退化为「更保守地少问」，不越安全包络。

## 7. 本轮最大风险

**一句话**：PERSONA-RAS 的全部收益押在「画像可信」这一前提上，而画像恰是最易被污染、最易过期、又最易自我实现的对象——若画像因投毒、迎合或冷启动冒充而错误，个性化不会只是「没帮上忙」，它会**系统性地关闭能纠正它的证据通道**（少问→少纠错→画像更不改），使系统对这个人的错误既自信又不可见；PEFT 又把这种错误做成低秩、便宜、可悄然部署、难以从行为外表看出的形态——**R69 的风险是「问错」，R70 的风险是「认错人」：认错人之后，连该问谁都不会再问对**。

**次级风险与缓解**：画像自我强化 → PFS 探索配额 + `VoI_profile` + 引理 21；投毒/后门 → ACP 四检 + k 源一致 + E305–E306；迎合/冒充 → 带方差信任 + 低置信收缩 + 增长率上限 + E307–E308；过期漂移 → 半衰期 + PDC 复检 + E309；隐私膨胀 → 定义 325 数据最小化 + E315；适配器破坏安全 → 定义 312 安全层永不接受 adapter + 定理 19。
