# 灵感驱动研究循环·新灵感第 1 轮；本轮灵感：「意图理解」×「手势识别」

> **基线**：第 3 轮产出 MetricVoiceGauge-NCD-HUTDH-v23 + IP-431–439（HDL / ACSC / DCSC / HPC-E / CFC++ / CESC / FSVC / IPAM / HPC-E+），其上承 v22 分层 PGEV（P37/P41/P42）、v21 语义-规范层（SDC / CAC / DCL / GIC）、v20 联邦感知（PCA / CTS / CFC / HPC / CFCtrl）、v19 的 DCM / OGCC / CCV / DRS / OGC 与 v17 的 CLP / S2C / HCG / PSV / APS / AMC。
> **本轮纪律**：**意图是"关于未来目标的、可撤销的承诺"；手势是"有相位、有受众、有指称的沟通行为"；一切意图证据必须先过"共同基础"这道门，才配拥有规范力**。不推倒 v23：所有证书与单调链 `Exec_v23 ⊆ … ⊆ Exec_v18` 原样保留。本轮只做一件事：**把 v21 里被当作"标签"的意图，升级为"受众已核验的承诺"——新增意图接地层 IGL，并把意图的两副面孔（只加障碍的危险预测 / 只减计划的许可钥匙）同时接入，且用"意图-危险对偶"保证两条路都只往保守方向走。**

## 0. 直觉与动机

### 灵感 1（意图理解 → 意图不是标签，而是"可撤销的承诺"，且必须先回答"说给谁听"）

**直觉。** v21 的 GIC 把意图当成一个分类标签：`g_state ∈ {STOP, YIELD, HANDOVER}`，用 conformal 集 `Γ` 与 TTL 管理。这在"人正对着机器人做动作"的实验室场景里够用，但真实意图理解至少多出三件事：

1. **意图是关于未来目标的承诺，不是当前姿态。** 手举起来的一瞬间，人的目标可能是"让机器人停"、"把东西交给机器人"、"只是挠头"。标签化会丢掉"承诺"这一时间结构：承诺可以被**兑现**、被**保持**、也可以被**撤销**。
2. **意图有指称对象。** "让一下"让谁过？"给你"给的是哪个目标区？指称（deixis）是意图的组成部分，不是事后补的注释。
3. **最关键的——一个动作只有在"共同基础 (common ground)"下，才成为对机器人的沟通行为。** 同一只手举起：人看着机器人时，是"停下/交接"；人看着机器人**身后的人**时，只是"跟别人打招呼"。前几轮默默假设"凡是识别出的手势都是冲我来的"——这是整条证书链上最危险、也最未被审计的隐含假设。

**严谨定义（意图作为部分可观测承诺）。** 把意图建模为四元组

```
κ = (g, r, T, Γ_α)
```

其中 `g ∈ H` 是目标/承诺类别，`r` 是指称对象（referent：机器人 / 某目标区 / 第三人 / 无），`T` 是承诺时域，`Γ_α(x) ⊆ H` 是以 ≥1-α 覆盖真意图假设的**集合值**预测（split conformal / APS）。区分**信息意图**（想让你知道什么）与**沟通意图**（想让你因此做什么，Sperber–Wilson 关联理论）：机器人**只对"以机器人为受众的沟通意图"赋予规范力**；信息意图再强，若受众不是机器人，规范力恒为零。

**反直觉点。** 意图理解的难点不在"分类更准"，而在"**受众判定**"：把 90% 的分类精度花在"这是什么手势"上，却用 0% 的精力确认"这手势是不是对我做的"，等于把整条许可链建在一个未经验证的谓词上。**受众误判的代价是不对称的**——把"对别人打招呼"误判成"对我交接"会**解锁**危险接近；把"对我交接"误判成"没对我"只损失活性。

### 灵感 2（手势识别 → 手势是有相位的沟通行为，且"指向"同时携带指称与在场双重证据）

**直觉。** 静态手势分类器把一帧图像映射成一个标签，但手势是**有时间结构的行为**：准备 (preparation) → 击打 (stroke) → 保持 (hold) → 撤回 (retraction)（Kendon 相位）。语义主要由 **stroke** 承载；**hold 才是持续许可的"心跳"**；**retraction 是撤销信号**。把手势当静态标签，必然产生"**粘滞许可**"——手早放下了，许可还在飞。另一方面，**指向 (deixis)** 是信息量最大的一类手势：它同时 (a) 把注意力引到一个目标区（指称），(b) 构造性地证明"手的主人在场"（在场证据），(c) 若指向机器人，则强化"受众是机器人"（受众证据）。这正是"手势识别"与"意图理解"真正咬合的地方：**指 = 意图去指称**。

**严谨定义（手势行为证书 GAC）。** GAC 输出 `g = (phase_spans, sem_class, addressee_evidence, ray)`：相位用带时长先验的 HMM / CTC 分割；`sem_class` 在 stroke 上取值；`addressee_evidence = (gaze_on_robot, head/body_orientation, proximity, pointing_at_robot)` 经校准打分；`ray` 是指向射线及其误差锥。**只有 stroke 完成且 `addressee_evidence` 达阈值的手势，才可能升级为"对机器人的沟通意图"**；否则降级为"环境运动"——只作为障碍/在场证据，零规范力。

**反直觉点。** 直觉会想"手势越多信息越好"，但**hold 的心跳语义**意味着：许可不是"签一次就一直有效"，而是"**必须持续被证明仍然成立**"。这把"意图状态"从离散标签变成了**带续约的租约 (lease)**——没有心跳就自动过期，比任何 TTL 都更贴近人类沟通的真实语义。

### 灵感 3（统一：意图-危险对偶 + 共同基础前置）

**直觉。** 意图理解对安全有**两个方向相反、但都安全**的用法：

- **危险预测（只加障碍）**：由意图推断人**未来**会去哪 → 得到预测占据区 `Occ_pred` → 并入障碍集。它只会让机器人更胆小；预测错了（人没去那）只是浪费活性，不会撞。
- **许可钥匙（只减计划）**：由意图解锁 DCL 里**已经预留**的许可（如交接时允许靠近）→ 必须满足共同基础 + conformal + 模态佐证，fail-closed。它只会让机器人更少做事；判错了（人其实没同意）也只是退回保守，而"误判成同意"被多重门槛挡死。

两条路都朝保守方向犯错，因此可以**同时**接入而不互相拆台。统一为一层 **意图接地层 (Intent Grounding Layer, IGL)**，共享状态

```
ζ_ig = ζ_v23 ∪ (H, Γ_α, Occ_pred, g_phase, addressee_ev, CG, κ_state, ref_set, clarify_log)
```

**统一准入门 HPC-I：**

```
HPC-I = HPC-E+
      ∧ (Occ_pred 已并入障碍，障碍单调不减)
      ∧ ∀ 被解锁许可 p: CGC ∧ (ICF=Committed) ∧ (Γ_α ⊆ H_permit)
                        ∧ AbsCert(target(p)) ∧ (模态佐证 ≥2)
```

于是 `Exec_v24 = Exec_v23 ∩ Fil_intent ⊆ Exec_v23`，且 `Obs_t^{v24} = Obs_t^{v23} ∪ Occ_pred ⊇ Obs_t^{v23}`。**一句话：意图只能让机器人"看见更多危险"或"解锁更少动作"，永远不能反过来。**

## 1. 研究问题（轮次升级版）

- **Q1（意图的集合值校准与歧义）**：如何用 split conformal / APS 得到 `Γ_α(x) ⊆ H` 使 `P(h* ∈ Γ_α) ≥ 1-α`？当 `Γ_α` 同时含"交接"与"路过"两个**安全相关且不相容**的意图时，如何定义"歧义"并 fail-closed？`Γ_α ⊆ H_permit` 的集合包含判定在连续参数（交接目标区）上如何离散化而不引入漏判？

- **Q2（共同基础的可靠判定与循环标注）**：`CG`（受众是机器人）如何由 gaze / head / body / proximity / pointing 的校准打分给出，并把**假受众率** `P(CG=1 | 实际非受众) ≤ α_cg` 用 Clopper–Pearson 界住？标注"是否对机器人说话"本身依赖同一套共同基础假设，这种**循环标注**如何被检测与约束（审计集、第三人同场对抗样本、反事实扰动）？

- **Q3（手势相位、心跳与撤销）**：prep/stroke/hold/retract 的在线分割延迟（100–300ms）如何与 50Hz 控制环解耦？hold 心跳缺失多久判定租约过期？retraction / 转身 / 后退等**撤销信号**如何以最高优先级打断 `Committed` 状态？指向射线 `ray` 的误差锥如何与 AbsCert、目标区绑定，使"指了哪"可审计？

- **Q4（意图-危险对偶与既有模块的叠加）**：`Occ_pred` 如何以 conformal 覆盖 ≥1-β 给出未来占据区，并与 v20 Hull、v21 CertBox、v22 ACSC 臂空间障碍做**只增不减**的并？意图许可解锁如何与 v21 DCL 的 O/F/P 编译、v20 margin_col_fed、v23 CFC+++ 模态仲裁叠加而不破坏 `Exec_v24 ⊆ Exec_v23`？澄清请求（机器人反问）如何做到**不阻塞控制环**且自身安全？

## 2. 设计原则（在 P37–P42 基础上新增 P43–P46）

**P43 共同基础前置律（Common-Ground Precondition）**
手势/意图证据只有在 `CGC`（受众是机器人）成立时，才从"环境运动"升格为"沟通意图"，才拥有规范力；否则 `g` 只作为障碍/在场证据，许可力恒为零。受众不确定时**默认非受众**（fail-closed）。任何"跳过 CGC 直接解锁"的路径在结构上不存在。

**P44 意图-危险对偶单调律（Intent-Hazard Duality Monotonicity）**
意图的两副面孔都必须向保守：
`Obs_t^{v24} = Obs_t^{v23} ∪ Occ_pred`（预测占据只增不减；预测失效即丢弃该项，退回 v23 障碍）；
`Exec_v24 = Exec_v23 ∩ Fil_intent`，而 `Fil_intent` 只**删除**"需要许可却未被认证"的计划，从不新增自由空间。
故 `Obs^{v24} ⊇ Obs^{v23}` 且 `Exec_v24 ⊆ Exec_v23`，二者均由构造保证，而非事后验证。

**P45 歧义失效关闭律（Ambiguity Fail-Closed）**
若 `Γ_α` 不包含于单一"安全相容"意图类，或 `Γ_α` 含任一**危险意图**（如未确认的交接），则**禁止任何许可解锁**；只能发起澄清请求（有截止期），截止未消歧即回落最严默认。歧义**绝不允许**用先验/多数票"猜"掉——`argmax` 置信度不是许可依据，**集合包含才是**。

**P46 承诺可撤销律（Commitment Revocability / Non-Sticky Intent）**
意图许可是**带心跳的租约**，不是一次性状态：`Committed` 需 hold 心跳续约；沉默超时、撤回手势、转身/后退、或任一 STOP 通道触发，**立即且不可逆地**撤销（在租约内不得由旧证据复活，必须重新经 CGC 认证）。许可本身有界（时域 `τ_perm`、距离、速度），且**永远不能解除 v23 几何证书的硬约束**。

## 3. 与基线的接口（如何退化）

- **IPC 失效（未来占据预测不可信）** ⇒ 丢弃 `Occ_pred`，障碍退回 v23 的 `Hull ∪ CertBox`；同时意图许可全部失效（无 IPC 即无意图证据）⇒ 等价 v23（更保守或相等）；
- **CGC 失效（受众不可判）** ⇒ 全部手势降级为环境运动，许可力为零，只剩在场/障碍证据 ⇒ 子集；
- **GAC 失效（手势分割/识别故障）** ⇒ 无手势证据、无 hold 心跳 ⇒ 无许可续约；CAC 失去"手势在场翻转"冗余 ⇒ 缺席证书更保守 ⇒ 子集；
- **ICF 失效（承诺状态机崩溃）** ⇒ 无 `Committed`，全部许可关闭 ⇒ 子集；
- **IACP 失效（澄清协议不可用）** ⇒ 歧义一律按最严处理、不解锁 ⇒ 子集；
- **DRC 失效（指向不可解析）** ⇒ 无指称目标区，交接许可不可签发；在场仍由 GAC 提供（若有）⇒ 子集；
- **全部失效** ⇒ 完全回退 v23 ⇒ `Exec_v24 ⊆ Exec_v23 ⊆ Exec_v22 ⊆ … ⊆ Exec_v18`。
- **安全继承**：IPC 只加障碍；GAC 只提供证据不给许可；CGC 是许可的必要条件（去掉只会减许可）；ICF 只关不开；IACP 只更严；DRC 只补指称。任意失效都向保守方向退化。

## 4. 预期贡献

1. **意图作为可撤销承诺**：把意图从"标签 + TTL"升级为"部分可观测承诺 `κ=(g,r,T,Γ_α)` + 带心跳租约"，首次给出"沉默≠同意、撤回即失效"的形式语义；
2. **共同基础前置**：首次把"这手势是不是对我做的"提升为**许可链的必要证书** `CGC`，并显式界住假受众率 `α_cg`，正面处理"对别人打招呼被误读成交接"这一最危险的隐含假设；
3. **意图-危险对偶**：给出同一意图证据的两种安全用法（只加障碍的 `Occ_pred` / 只减计划的许可钥匙），并证明两者同时接入仍保持 `Obs↑`、`Exec↓` 的单调链；
4. **手势相位与指称**：用 prep/stroke/hold/retract 相位把"粘滞许可"变成"心跳租约"，用指向射线把"指了哪"变成可审计指称；
5. **集合值许可判定**：以 `Γ_α ⊆ H_permit`（而非 argmax）作为许可依据，配合歧义 fail-closed 与澄清协议，使"假许可概率"有显式上界；
6. **HPC-I 统一门**：`HPC-E+ ∧ CGC ∧ ICF ∧ Γ_α⊆H_permit ∧ AbsCert ∧ 模态佐证` 六证一体，`Exec_v24 ⊆ Exec_v23` 闭环，并把意图审计链接入 v23 的 IAC 式 merkle 账本。

## 5. 本轮最大风险

**一句话**：`CGC` 的假受众率界 `α_cg` 是拿"人是否在对机器人说话"的人工标注校准出来的，而该标注**本身就在同一套共同基础假设下完成**——在机器人身旁/身后有第三人的真实场景里，gaze 朝向机器人附近、手举起、身体朝向这些可观测特征可以被"正在跟机器人身后那人打招呼"的人**同时满足**；conformal 覆盖在统计上依然成立，语义上却已错位，于是机器人拿到一张"校准合规、账本齐全、可审计"的假许可，**合规地走向一个从未同意它靠近的人**——即"**共同基础的循环标注 / 合规的误归属**"。

## 1. 关键算法骨架（在 IP-431–439 骨架上扩展）

```python
# ============================================================
# IP-440 Intent Predictive Certificate (IPC) — 意图条件化未来占据（只加障碍）
# ============================================================
class IntentPredictiveCertificate:
    def __init__(self, predictor, beta: float = 0.01, horizon_T: float = 3.0,
                 min_inflation: float = 0.15):
        self.predictor = predictor          # 输出多模态未来轨迹 {τ_k, p_k}
        self.beta = beta                    # 覆盖 ≥1-β
        self.T = horizon_T
        self.min_inflation = min_inflation
        self.q_beta = 0.0                   # 轨迹误差 conformal 分位数
        self.D_calib: list[tuple[float, float]] = []  # (score, err)

    def update_quantile(self):
        """split conformal：取误差的 (1-β) 分位数（有限样本覆盖）"""
        if len(self.D_calib) < 30:
            self.q_beta = float("inf")      # 样本不足 → 无穷膨胀（最保守）
            return
        errs = sorted(e for _, e in self.D_calib)
        k = math.ceil((1 - self.beta) * (len(errs) + 1)) - 1
        self.q_beta = errs[min(k, len(errs) - 1)]

    def predict_occupancy(self, obs, intent_set: set) -> "OccupancySet":
        """给定意图集，并集化未来轨迹并按 q̂_β 膨胀 → 只增障碍"""
        occ = OccupancySet.empty()
        for traj in self.predictor.multi_modal(obs, horizon=self.T):
            if not (traj.intent in intent_set):   # 意图不相容的轨迹不纳入
                continue
            # 以 conformal 分位数膨胀每时刻位置，取时域并集
            occ = occ.union(traj.swept_volume().inflate(
                max(self.q_beta, self.min_inflation)))
        return occ   # 由调用方与 v23 障碍取并：Obs_v24 = Obs_v23 ∪ occ


# ============================================================
# IP-441 Gesture Act Certificate (GAC) — 手势相位、心跳与撤销
# ============================================================
@dataclass
class GestureAct:
    phase: str                    # prep/stroke/hold/retract
    sem_class: Optional[str]      # 仅 stroke/hold 有效
    t_start: float
    t_end: float
    addressee_ev: dict            # gaze/head/body/proximity/pointing 打分
    ray: Optional["Ray"] = None

class GestureActCertificate:
    def __init__(self, segmenter, classifier, hb_period: float = 0.2):
        self.segmenter = segmenter            # HMM/CTC 相位分割
        self.classifier = classifier
        self.hb_period = hb_period            # hold 心跳周期
        self.last_hold_hb: Optional[float] = None

    def update(self, frame, t: float) -> Optional[GestureAct]:
        phase = self.segmenter.phase(frame)
        if phase in ("stroke", "hold"):
            sem = self.classifier.classify(frame)
            ev = {
                "gaze_on_robot": gaze_on(frame, robot_region()),
                "head_to_robot": head_yaw_pitch(frame) < HEAD_TOL,
                "body_to_robot": body_orientation(frame) < BODY_TOL,
                "proximity": dist(frame.human, robot) < PROX_TOL,
                "pointing_at_robot": pointing_hits(frame, robot_region()),
            }
            if phase == "hold":
                self.last_hold_hb = t            # 心跳续约时间戳
            return GestureAct(phase, sem, t, t, ev,
                              ray=pointing_ray(frame) if ev["pointing_at_robot"] else None)
        if phase == "retract":
            self.last_hold_hb = None             # 撤销：心跳清零
            return GestureAct("retract", None, t, t, {})
        return None

    def heartbeat_alive(self, t: float) -> bool:
        """hold 心跳是否仍在租约内（供 ICF 续约判定）"""
        return (self.last_hold_hb is not None
                and t - self.last_hold_hb <= self.hb_period + HB_JITTER)


# ============================================================
# IP-442 Common Ground Certificate (CGC) — 受众判定与假受众率控制
# ============================================================
class CommonGroundCertificate:
    def __init__(self, addressee_model, alpha_cg: float = 0.01,
                 delta: float = 1e-3):
        self.model = addressee_model
        self.alpha_cg = alpha_cg
        self.delta = delta
        self.tau_cg = 0.99
        self.neg_scores: list[float] = []   # 非受众（第三人）校准打分

    def calibrate_threshold(self):
        """选 τ_cg 使 Clopper–Pearson 上界 FPR ≤ α_cg"""
        self.neg_scores.sort()
        n = len(self.neg_scores)
        if n < 50:
            self.tau_cg = 1.0               # 样本不足 → 只接受满分（最保守）
            return
        for i in range(n):
            # 阈值取 neg_scores[i]，其假阳性计数 = n - i
            fp = n - i
            if clopper_pearson_upper(fp, n, self.delta) <= self.alpha_cg:
                self.tau_cg = self.neg_scores[i]
                return
        self.tau_cg = 1.0

    def certify(self, gest: GestureAct) -> bool:
        """CG 谓词：受众打分过阈值 + 统计假受众率受控"""
        if gest.sem_class is None or gest.phase not in ("stroke", "hold"):
            return False
        a = self.model.score(gest.addressee_ev)
        # 额外必要条件：至少一个"方向性"证据（gaze 或 pointing）
        directional = gest.addressee_ev["gaze_on_robot"] or \
                      gest.addressee_ev["pointing_at_robot"]
        return (a >= self.tau_cg) and directional


# ============================================================
# IP-443 Intent Commitment Filter (ICF) — 带心跳租约的承诺状态机
# ============================================================
class IntentCommitmentFilter:
    def __init__(self, tau_hb: float = 0.3, tau_perm: float = 2.0):
        self.tau_hb = tau_hb
        self.tau_perm = tau_perm
        self.state = "Idle"
        self.kappa = None
        self.commit_t0 = None

    def step(self, t: float, gest: Optional[GestureAct], cg: bool,
             gamma: set, corroboration: int, abs_cert_ok: bool) -> str:
        # 1) 撤销优先级最高：retract / 撤回 / STOP 立即撤销
        if gest is not None and gest.phase == "retract":
            self._revoke(t); return self.state
        if STOP_CHANNEL.triggered():
            self._revoke(t); return self.state
        # 2) 租约与心跳过期
        if self.state == "Committed":
            if t - self.commit_t0 > self.tau_perm:
                self._expire(t); return self.state
            if not (gest and gest.phase == "hold"):
                self._expire(t); return self.state     # 无心跳 → 过期
        # 3) 只有 CG + 集合包含 + 佐证 + AbsCert 才允许进入/保持 Committed
        permit_ok = (cg and gamma <= H_PERMIT
                     and corroboration >= 2 and abs_cert_ok)
        if gest is not None and gest.phase in ("stroke", "hold"):
            if permit_ok:
                if self.state in ("Idle", "Proposed", "Expired"):
                    self.state = "Proposed"
                if self.state == "Proposed":
                    self.state = "Committed"
                    self.kappa = (gest.sem_class, gest.ray, t + self.tau_perm, gamma)
                    self.commit_t0 = t
            else:
                # 证据不足：不升级；已提交则立即降级
                if self.state == "Committed":
                    self._revoke(t)
                else:
                    self.state = "Proposed" if cg else "Idle"
        return self.state

    def _revoke(self, t):
        self.state = "Revoked"; self.kappa = None; self.commit_t0 = None
    def _expire(self, t):
        self.state = "Expired"; self.kappa = None; self.commit_t0 = None

    def grants(self, permission: str, target_region) -> bool:
        """只有 Committed 且指称匹配目标区才授予许可"""
        if self.state != "Committed" or self.kappa is None:
            return False
        g, ray, _, _ = self.kappa
        return permission in PERMISSION_TABLE.get(g, set()) and \
               ray is not None and ray.targets(target_region)


# ============================================================
# IP-444 Intent Ambiguity Clarification Protocol (IACP)
# ============================================================
class IntentAmbiguityClarificationProtocol:
    def __init__(self, deadline: float = 1.5, max_rounds: int = 2):
        self.deadline = deadline
        self.max_rounds = max_rounds
        self.pending = None

    def check(self, t: float, gamma: set) -> str:
        """返回 'permit' / 'clarify' / 'conservative'"""
        if gamma <= H_PERMIT:
            return "permit"
        if gamma & H_DANGER and not (gamma & H_PERMIT == gamma):
            # 歧义且含危险意图 → 必须澄清，不得猜
            if self.pending is None:
                self.pending = {"t0": t, "rounds": 0, "deadline": t + self.deadline}
                issue_clarification(question=disambiguate(gamma))  # 灯光/箭头/语音
            return "clarify"
        return "conservative"

    def resolved_or_timeout(self, t: float, response: Optional[set]) -> bool:
        if self.pending is None:
            return True
        if response is not None and response <= H_PERMIT:
            self.pending = None
            return True
        if t > self.pending["deadline"]:
            self.pending = None
            return False                    # 超时未消歧 → 最严
        return False


# ============================================================
# IP-445 Deictic Reference Certificate (DRC) — 指向即指称
# ============================================================
class DeicticReferenceCertificate:
    def __init__(self, eps_ang: float = math.radians(5.0)):
        self.eps_ang = eps_ang

    def resolve(self, gest: GestureAct, scene) -> Optional["RefSet"]:
        if gest.ray is None:
            return None
        cone = Cone(gest.ray, self.eps_ang)
        # 手射线 ∩ 视线射线 一致 → 指称置信提升
        gaze = gaze_ray(scene)
        agree = gaze is not None and angle(gest.ray.dir, gaze.dir) < 2 * self.eps_ang
        target = scene.region_hit_by(cone)
        if target is None:
            return None
        # 指向构造性蕴含：pointer 在场 + 被指目标区可能有实体
        return RefSet(pointer=gest.ray.origin, target_region=target,
                      eps_ang=self.eps_ang, gaze_agree=agree)

    def presence_evidence(self, ref: RefSet) -> set:
        """指称同时给 CAC 提供在场冗余：pointer 处 ∧ 目标区处"""
        return {ref.pointer, ref.target_region}


# ============================================================
# IP-446 HPC-I — 意图接地统一准入门
# ============================================================
@dataclass
class HPCIntent:
    hpc_e_plus: "HPCEPlus"          # v23 四证门
    ipc: IntentPredictiveCertificate
    gac: GestureActCertificate
    cgc: CommonGroundCertificate
    icf: IntentCommitmentFilter
    iacp: IntentAmbiguityClarificationProtocol
    drc: DeicticReferenceCertificate

    def admits(self, plan, obs, t, gamma, corroboration, target_region) -> bool:
        # 1) v23 四证门（几何/规范/负信息/能量/差距/云边/少样本/IP）
        if not self.hpc_e_plus.admits(plan, obs.x, obs.v, obs.z,
                                      obs.E_res, obs.margin_req, obs.modules):
            return False
        # 2) 危险增补：Obs 必须已并入 Occ_pred（只增不减）
        if not obs.obstacles.superset_of(self.ipc.predict_occupancy(obs, gamma)):
            return False
        # 3) 若计划需要意图许可，则必须六证齐备
        if plan.requires_intent_permission:
            cg = self.cgc.certify(self.gac.last_act)
            if not cg:
                return False                       # 无共同基础 → 零规范力
            if self.icf.state != "Committed":
                return False                       # 无承诺 → 无许可
            if not (gamma <= H_PERMIT):
                return False                       # 集合不包含于可许可集 → fail-closed
            if self.iacp.check(t, gamma) != "permit":
                return False                       # 歧义 → 澄清/最严
            if not self.icf.grants(plan.permission, target_region):
                return False
            if not obs.abs_cert.valid(target_region):
                return False                       # 目标区缺席证书必须有效
            if corroboration < 2:
                return False                       # 单模态不可解锁
        return True

# IP-447 Intent Audit Chain (IAC) — 意图可审计链
# ============================================================
class IntentAuditChain:
    def __init__(self):
        self.leaves: list[bytes] = []
        self.root: bytes = GENESIS

    def append(self, t: float, obs_digest: bytes, gest: GestureAct,
               cg: bool, gamma: set, kappa_state: str,
               granted: Optional[str], clarify: Optional[dict]):
        leaf = hash_json({
            "t": t, "obs": obs_digest.hex(), "gesture": gest_to_json(gest),
            "cg": cg, "gamma": sorted(map(str, gamma)),
            "kappa_state": kappa_state, "granted": granted,
            "clarify": clarify, "prev": self.root.hex(),
        })
        self.leaves.append(leaf)
        self.root = merkle_root(self.leaves)
        return self.root

    def prove_permission(self, permission: str) -> "MerkleProof":
        """证明某次靠近是被哪张手势/共同基础/承诺/缺席证书共同授权的"""
        return merkle_proof(self.leaves, find_grant(self.leaves, permission))
```

## 2. 复杂度分析

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 |
|---|---|---|---|
| IPC 预测占据 | O(K·T·d)（K 轨迹数，T 时域采样，d 维度） | O(K·T) 增量 | K≤8, T=3s@10Hz, β=0.01 |

| IACP 澄清协议 | O(1) 均摊 | O(1) | deadline=1.5s, max_rounds=2 |

**实时性保证**：意图状态机（GAC/CGC/ICF/IACP/DRC）以 **10Hz 事件方式**离线于控制环，控制路径只做 O(1) 状态查询（`icf.state == "Committed"`、`cg`、`gamma <= H_PERMIT`）；IPC 的轨迹预测可预计算并缓存，控制环只做占据集并运算。端到端关键路径无阻塞 I/O，满足 50Hz。

## 3. 正确性论证

### 引理 1（共同基础必要性 → 许可单调）
**陈述**：任何由意图解锁的许可都要求 `CG=1 ∧ ICF=Committed ∧ Γ_α⊆H_permit`。因此移除 `CGC` 或使 `ICF` 不处于 `Committed`，只会**删除**许可，不会新增。

**证明**：`HPCIntent.admits` 在 `plan.requires_intent_permission` 分支中对 `cg`、`icf.state`、`gamma <= H_PERMIT` 逐一连言；任一为假即返回 `False`。许可集合是这些连言的真值集，减少连言只可能使其变小。故许可随证据缺失单调收缩。∎

### 引理 2（危险增补单调）
**陈述**：`Obs_v24 = Obs_v23 ∪ Occ_pred ⊇ Obs_v23`；IPC 失效时 `Occ_pred` 被丢弃，`Obs_v24 = Obs_v23`，仍不扩张。

**证明**：`Occ_pred` 以并集形式并入（`OccupancySet.union`），集合运算的并单调；`HPCIntent.admits` 第 2 步要求 `obs.obstacles ⊇ Occ_pred`，确保预测占据确实进入几何校验。IPC 不可信时 `q̂_β` 取 `+inf` 或直接丢弃该项，均不会使障碍集小于 v23。∎

### 引理 3（集合值许可的可靠性 / 歧义 fail-closed）
**陈述**：若 `Γ_α` 满足 conformal 覆盖 `P(h*∈Γ_α) ≥ 1-α`，且许可要求 `Γ_α⊆H_permit`，则"被许可但真实意图不在 `H_permit`"的概率 ≤ α。

**证明**：若 `h* ∉ H_permit` 却签发了许可，则因许可要求 `Γ_α⊆H_permit` 必有 `h* ∉ Γ_α`，即覆盖失败；其概率 ≤ α。当 `Γ_α` 同时含 `H_permit` 与 `H_danger`（歧义），`Γ_α⊆H_permit` 为假，`IACP` 返回 `clarify/conservative`，不签发许可——故歧义不会以 argmax 猜测被"消解"。∎

### 引理 4（承诺租约与可撤销性）
**陈述**：`Revoked` 或 `Expired` 状态不能在同一租约内无新证据地回到 `Committed`；`Committed` 在无 hold 心跳超过 `τ_hb` 或超过 `τ_perm` 时必转为 `Expired`；`retract`/STOP 必转为 `Revoked`。

**证明**：状态机中进入 `Committed` 的唯一转移来自 `Proposed`，且要求 `permit_ok`（含 `CG` 与集合包含）；`_revoke/_expire` 清空 `kappa` 与 `commit_t0`，无路径从终态直达 `Committed`；`step` 开头优先处理 `retract`/STOP 与租约超时。故旧意图不能"粘滞"。∎

### 引理 5（退化链保持）
**陈述**：任一子模块失效下，`Exec_v24 ⊆ Exec_v23 ⊆ Exec_v22 ⊆ … ⊆ Exec_v18`。

**证明**：IPC 失效 → 丢 `Occ_pred` 且无意图证据 → 等价 v23；CGC/GAC/ICF/IACP/DRC 失效 → 对应许可连言为假 → 许可收缩；全部失效 → `HPC-I` 退化为 `HPC-E+` → 等价 v23。所有退化方向均为集合收缩。∎

### 定理（HPC-I 意图接地门的安全-可靠-可审计完备性）
**陈述**：对任意计划 π，`HPCIntent.admits(π)=True` ⟺ π 同时满足：
(1) v23 的物理接地安全（几何∧规范∧负信息∧能量∧差距∧云边∧少样本∧IP）；
(2) 未来人体占据 `Occ_pred` 已并入障碍（危险只增）；
(3) 每个被解锁的意图许可都满足：共同基础 `CGC` ∧ 承诺 `ICF=Committed` ∧ 集合包含 `Γ_α⊆H_permit` ∧ 目标区 `AbsCert` ∧ 模态佐证 ≥2 ∧ 非歧义。
且 `Exec_v24 ⊆ Exec_v23`。

**证明**：充分性由 `admits` 的四个连言分支直接给出；必要性：任一分支为假即拒证，对应"几何不安全 / 危险未增补 / 许可证据不足"三类风险之一未被缓解。单调性由引理 1–5 给出。∎

## 6. 本轮最大风险（最终确认）

**一句话**：`CGC` 的假受众率界依赖"人是否在对机器人说话"的人工标注，而该标注本身在同一套共同基础假设下完成——机器人身旁/身后有第三人时，gaze 朝向机器人附近、手举起、身体朝向这些可观测特征可被"正在与机器人身后那人打招呼"的人同时满足，conformal 覆盖统计上成立而语义上错位，于是机器人持一张**校准合规、账本齐全、可审计**的假许可，**合规地走向一个从未同意它靠近的人**——即"**共同基础的循环标注 / 合规的误归属**"。
