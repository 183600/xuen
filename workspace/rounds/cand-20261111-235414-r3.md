# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「多机协作」×「异常检测」）

> 第 54 轮已把技能组合推进为「动作空间剖面 α_S + 鲁棒性谱 ρ」的双证书，并建立云规划—边校验—反向解释—重剖分的闭环。本轮把视角从单机/单技能提升到 **多机团队**，并把 **异常检测** 从附属监控提升为一等证据层。核心矛盾：H22：单机的 ρ 与 A_cert 无法直接合成为团队保证——协作边既是能力放大器，也是异常传播通道，个体的 sound 证书在团队中可能被同伴的污染输入证伪；H23：多机冗余本应用来三角测量异常，但当异常是共模的（同源传感器漂移、同一模型盲区、同一时钟/通信故障），agent 间共识会同步失明，冗余反而制造虚假安全感。

## 0. 直觉与动机

**灵感 1（团队不是个体并集 → 协作图上的团队鲁棒性谱）**
直觉：把 N 个 agent 建模为协作图 `C_G=(N,E_c)`，边 `e=(i,j)` 表示二者存在共享动作承诺、共享观测或任务依赖。团队鲁棒性不是 `min_i ρ_i`，而是沿协作边的 **最弱割集** 与 **最坏边界的耦合放大**。沿边传播的污染用耦合增益 `κ_ij` 描述；直觉上：一个强 agent 救不了一个被弱 agent 持续喂坏输入的团队，木桶的短板现在是一条“被污染的缝”，而不是某一块板。

**灵感 2（异常检测剖面 → 把检测能力写成可组合的函数）**
直觉：检测器不是“有/无”，而是在 **异常空间 Ω** 上的覆盖剖面 `β_i : Ω → [0,1]`，并附延迟 `ℓ_i(ω)` 与误报率 `f_i(ω)`。`β_i` 可组合的前提，是明确“在什么异常类型上、以多大延迟、多高误报”被覆盖，而不是笼统报告一个 AUROC。这样异常检测才能像 ρ 一样进入证书，而不是停留在 dashboard 上。

**灵感 3（多机三角测量 → 残差共识而非多数投票）**
直觉：多机的价值不在投票，而在 **重叠约束的多余度**：agent i 的动作/观测与 j 的预测在共享状态上应满足一致性约束 `g_ij(x_i,x_j,a_i,a_j)=0`，异常表现为残差 `r_ij=||g_ij||` 偏大。用 **残差共识图 RCC** 可以定位“哪个 agent 违反了最多约束”，而不是“哪一票少”。但若异常共模，`r_ij` 对所有 i,j 同时偏小——这正是最危险区。

**灵感 4（共模失明 → 多样性证书是第一性防线）**
直觉：要抗共模，检测器/传感器/模型必须在异常类型上 **互补而非同质**。定义多样性覆盖 `DCC(Ω)=|∪_i supp(β_i)|/|Ω|` 与同源相关惩罚 `corr(β_i,β_j|ω)`；当覆盖不足或高相关，团队必须主动降级：收缩任务、请求外部锚点或人工确认。多机协作的第一原则应从“更多 agent 更可靠”翻转为“**检测多样性才可靠**”。

**灵感 5（检测即隔离 → 用动作空间信任半径做异常遏制）**
直觉：检测到异常后，最危险的动作是“继续按原计划执行”。把第 54 轮的 `α_S` 与 `A_cert` 改造成 **动态信任半径** `α_i^τ(a)=α_i(a)·exp(-ρ_i^τ(a)/λ)`：一旦 agent i 在动作子集上被异常污染，就收缩其可执行动作域 `A_i^τ={a | α_i^τ(a) ≥ θ_iso}` 并重新规划团队任务。这是 **ACG 异常遏制护栏**：检测 → 归因（复用 Explain）→ 动作域收缩 → 协作边重连，而不是全局急停。

**灵感 6（团队异常证书与金字塔扩展）**
直觉：在第 54 轮动作-鲁棒性双证书 `J` 之上加 **团队异常证书 `TAC=(ρ_team, β_team, DCC, iso, evidence)`**；金字塔新增协作层 `ℂ`：`ℂ_0` 单机物理极限，`ℂ_1` 协作拓扑，`ℂ_2` 异常空间覆盖，`ℂ_3` 团队任务保证。跨层只传递“带隔离边界与多样性证明”的证书。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（多机协作图与传播增益）**
协作图 `C_G=(N,E_c,Φ_shared,K^ext)`：
- `N={1..n}` 为 agent 集合；`E_c⊆N×N` 为协作边；
- `Φ_shared` 为共享动作承诺/共享观测/任务依赖的接口集合；
- `K^ext∈[0,1]^{n×n}` 为沿边的**污染传播增益**，`κ_ij` 表示 j 的异常进入 i 的输入通道后未被过滤的比例。
`C_G` 的割 `(S,S̄)` 表示把团队分成两组任务耦合区，割边集合 `δ(S)={(i,j)∈E_c | i∈S, j∉S}`。

**定义 122（团队鲁棒性谱）**
对维度 d，团队鲁棒性谱定义为最弱割的净保证：
```
ρ_team(d) = clip( min_{(S,S̄)} [ min_{i∈S} ρ_i(d) - Σ_{(i,j)∈δ(S)} κ_ij·(1-ρ_j(d)) ], 0, 1 )
```
即：团队保证由最脆弱的耦合割决定，并被割边上未过滤的污染项扣减。若某割的扣减超过其成员保证，则该割直接判 0。

**定义 123（异常空间与检测剖面）**
异常空间 `Ω=Ω_sensor×Ω_act×Ω_comm×Ω_sem`。agent i 的检测剖面：
```
β_i : Ω → [0,1],   ℓ_i : Ω → ℝ_{≥0},   f_i : Ω → [0,1]
```
分别为检测概率、检测延迟、误报率。对 `Ω'⊆Ω`，覆盖度 `cov_i(Ω')=∫_{Ω'} β_i(ω)dω / |Ω'|`。**可组合检测保证**要求三元组 `(β_i,ℓ_i,f_i)` 同时被声明，缺一不可。

**定义 124（残差共识与三角可辨识性）**
对边 `(i,j)` 定义一致性约束残差 `r_ij(t)=||g_ij(x_i,x_j,a_i,a_j)||`，标准化 `z_ij=r_ij/σ_ij`。agent i 的异常定位分数 `Z_i=median_{j: (i,j)∈E_c} z_ij`。
**三角可辨识**：若雅可比 `J_S=[∂g_ij/∂x_i]_{(i,j)∈δ(S)}` 对 `x_i` 列满秩，则 `S` 内异常可被定位。
**共模盲集**：`B={ω∈Ω | max_{(i,j)} z_ij(ω) < θ_r}`，即所有约束残差都“看起来正常”的异常集合。

**定义 125（多样性覆盖证书 DCC）**
`DCC=(Ω_cover, corr_max, B_cover, ψ)`：
- `Ω_cover=∪_i supp(β_i)` 为检测器联合支撑集；
- `corr_max=max_{i≠j,ω} corr(β_i(ω),β_j(ω))` 为同源相关上界；
- `B_cover=cov_{∪β}(B)` 为对共模盲集的覆盖度；
- `ψ` 为多样性来源清单（不同物理量/不同模态/不同模型族/外部锚点）。
**可接受条件**：`B ⊆ Ω_cover` 且 `B_cover ≥ θ_B` 且 `corr_max ≤ θ_corr`。

**定义 126（团队异常证书 TAC）**
`TAC=(N, C_G, ρ_team, β_team, DCC, iso, evidence)`：
- `ρ_team` 为定义 122 的团队谱；
- `β_team` 为团队级检测剖面（含定位与延迟）；
- `DCC` 为多样性覆盖证书；
- `iso: (i, ω) ↦ A_i^τ` 为隔离策略：把疑似 agent 的动作域收缩到信任子集；
- `evidence` 至少包含跨机残差日志、共模盲区测试、隔离后重规划轨迹。
**可部署条件**：`∀d, ρ_team(d) ≥ ρ_min(d)`，`DCC` 可接受，`iso` 保持任务图连通且隔离代价 `cost_iso ≤ Θ_iso`。

## 2. 关键算法 伪代码

### IP-121 TRS（Team Robustness Spectrum）

```python
def team_spectrum(agents, C_G, dims):
    rho_team = {}
    for d in dims:
        best = 0.0
        for S in cuts(C_G):                      # 枚举/最小割近似
            inner = min(agents[i].rho[d] for i in S)
            leak = sum(C_G.kappa[i][j] * (1 - agents[j].rho[d])
                       for (i, j) in delta_edges(C_G, S))
            best = max(best, clip(inner - leak, 0, 1))
        rho_team[d] = best
    return rho_team
```

### IP-122 ADM（Anomaly Detection Mesh）

```python
def anomaly_profile(agent, Omega, sampler, budget):
    beta, lat, far = {}, {}, {}
    for omega in sampler.cover(Omega, budget):      # 分层 + 共模定向采样
        alarms, delays = [], []
        for _ in range(sampler.repeats):
            t0 = now()
            hit = agent.detector(agent.inject(omega))
            alarms.append(hit); delays.append(now() - t0)
        beta[omega] = mean(alarms)
        lat[omega]  = percentile(delays, 95)
        far[omega]  = false_alarm_rate(agent, omega)
    return DetectionProfile(beta, lat, far)
```

### IP-123 RCC（Residual Consensus Check）

```python
def residual_consensus(agents, C_G, theta_r):
    Z = {i: [] for i in agents}
    for (i, j) in C_G.edges:
        r = norm(consistency(agents[i].state, agents[j].state,
                             agents[i].action, agents[j].action))
        z = r / sigma_ij(agents[i], agents[j])
        Z[i].append(z); Z[j].append(z)
    score = {i: median(Z[i]) for i in agents}
    flagged = {i for i, s in score.items() if s > theta_r}
    blind = max(score.values()) < theta_r          # 全体“正常” → 共模警报
    return flagged, score, blind
```

### IP-124 DCC（Diversity Coverage Certificate）

```python
def diversity_certificate(profiles, blind_set, theta_B, theta_corr):
    cover = union_support(profiles)
    if not blind_set <= cover:
        return ('reject', 'blind_set_uncovered', blind_set - cover)
    B_cover = mean([max(p.beta.get(w, 0) for p in profiles) for w in blind_set])
    corr_max = max_pairwise_corr(profiles)
    if B_cover < theta_B or corr_max > theta_corr:
        return ('reject', 'diversity_insufficient', B_cover, corr_max)
    return ('ok', DCC(cover, corr_max, B_cover, diversity_sources(profiles)))
```

### IP-125 ACG（Anomaly Containment Guard）

```python
def contain_and_replan(flagged, agents, alpha, task_graph, rho_tau, lam, theta_iso):
    iso = {}
    for i in flagged:
        trust = {a: alpha[i][a] * exp(-rho_tau[i].get(a, 1.0) / lam)
                 for a in alpha[i]}
        iso[i] = {a for a, v in trust.items() if v >= theta_iso}
        agents[i].action_domain = iso[i]          # 收缩而非停机
    new_task = replan(task_graph, isolated=iso)
    if not connectivity_preserved(task_graph, new_task) or cost_iso(new_task) > THETA_ISO:
        return ('escalate', 'need_external_anchor', iso, new_task)
    return ('ok', iso, new_task)
```

### IP-126 TAC（Team Anomaly Certificate）

```python
def team_anomaly_certify(agents, C_G, Omega, alpha, task_graph, budgets):
    rho_team = team_spectrum(agents, C_G, DIMS)
    if any(rho_team[d] < budgets.rho_min[d] for d in DIMS):
        return ('reject', 'team_robustness_fail', rho_team)
    profiles = [anomaly_profile(a, Omega, SAMPLER, budgets.budget) for a in agents]
    dcc = diversity_certificate(profiles, blind_set(profiles), budgets.theta_B, budgets.theta_corr)
    if dcc[0] == 'reject':
        return ('reject', 'common_mode_blind', dcc)
    flagged, score, blind = residual_consensus(agents, C_G, budgets.theta_r)
    if blind:
        return ('degrade', 'common_mode_suspected', ask_external_anchor())
    iso = contain_and_replan(flagged, agents, alpha, task_graph,
                             rho_tau=score, lam=budgets.lam, theta_iso=budgets.theta_iso)
    if iso[0] != 'ok':
        return iso
    return ('ok', TAC(agents, C_G, rho_team, profiles, dcc, iso, evidence_log()))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| TRS | O(2^{|N|}·|N|) 精确；最小割近似 O(|E_c|·|N|²) | O(N²) | 割枚举完备/增益上界 sound |
| ADM | O(|Ω|·repeats·|N|) | O(|Ω|·|N|) | 异常空间分层覆盖、共模定向采样 |
| RCC | O(|E_c|·c_g) | O(|E_c|) | 约束可辨识（列满秩）、σ 校准 |
| DCC | O(|Ω|·|N| + |N|²) | O(|Ω|·|N|) | 盲集显式枚举、相关性估计置信 |
| ACG | O(|N|·|A| + replan) | O(|N|·|A|) | 隔离保持连通、重规划收敛 |
| TAC | O(TRS + ADM + RCC + DCC + ACG) | O(|Ω|·|N| + |A|·|N|) | 五者联合 sound |

**正确性定理（Team Anomaly-Aware Collaboration Soundness）**
承接第 53/54 轮 (A22)–(A28)；新增：**(A29)** 每个 agent 的个体证书 `J_i` sound；**(A30)** 传播增益 `κ_ij` 有上界且经在线校准；**(A31)** `DCC` 覆盖共模盲集 `B`，且检测/隔离延迟 `ℓ ≤ τ_iso`；**(A32)** 隔离后任务图连通且重规划收敛。
则：
```
P(团队任务成功 ∧ 无未检测污染传播)
  ≥ 1 - Σ_d (1 - ρ_team(d))
      - (1 - B_cover) - P(ω ∈ Ω \ Ω_cover)
      - P(ℓ > τ_iso) - P(Σ κ_ij·残差 > θ_leak)
      - P(iso 破坏连通) - β_E
```
关键：**团队谱按最弱割扣减污染**，**共模盲集必须被多样性检测器显式覆盖**，**隔离是动作域收缩而非停机**。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 共模盲集枚举不全 | 高 | 对抗生成异常 + 物理故障注入 + 外部锚点 |
| 传播增益 κ_ij 估计失真 | 高 | 在线校准 + 区间上界 + 保守扣减 |
| 协作图规模/割枚举爆炸 | 中 | 最小割近似 + 分层聚类 + 关键割缓存 |
| 隔离导致任务碎片化 | 高 | 连通性约束 + 渐进收缩 + 回滚计划 |
| 假阳性触发过度隔离 | 中 | 双阈值 + 时序确认 + 隔离代价预算 |
| 约束不足导致不可辨识 | 高 | 冗余约束设计 + 可辨识性预检查 |

## 6. 本轮最大风险

**一句话**：把多机协作与异常检测纳入证书体系，使团队保证从 `min_i ρ_i` 升级为「最弱割 + 共模盲集覆盖 + 隔离连通性」的联合判据，但其 soundness **三重依赖共模盲集的完备枚举、传播增益 κ_ij 的保守上界、以及隔离后重规划的连通收敛**；一旦盲集漏枚举或 κ 被低估，团队会在“所有 agent 都报警正常”的共模故障下集体失明并沿协作边级联污染，故必须以 **对抗共模采样 + κ 区间上界 + 外部锚点降级** 三重护栏，宁可误报降级，绝不把“多机冗余”当作“多机可靠”。

## 2. 关键算法 伪代码

### IP-121 TRS

```python
def team_spectrum(agents, C_G, dims):
    rho_team = {}
    for d in dims:
        best = 0.0
        for S in cuts(C_G):
            inner = min(agents[i].rho[d] for i in S)
            leak = sum(C_G.kappa[i][j] * (1 - agents[j].rho[d])
                       for (i, j) in delta_edges(C_G, S))
            best = max(best, clip(inner - leak, 0, 1))
        rho_team[d] = best
    return rho_team
```

### IP-122 ADM

```python
def anomaly_profile(agent, Omega, sampler, budget):
    beta, lat, far = {}, {}, {}
    for omega in sampler.cover(Omega, budget):      # 分层 + 共模定向
        hits, delays = [], []
        for _ in range(sampler.repeats):
            t0 = now(); hit = agent.detector(agent.inject(omega))
            hits.append(hit); delays.append(now() - t0)
        beta[omega] = mean(hits)
        lat[omega]  = percentile(delays, 95)
        far[omega]  = false_alarm_rate(agent, omega)
    return DetectionProfile(beta, lat, far)
```

### IP-123 RCC

```python
def residual_consensus(agents, C_G, theta_r):
    Z = {i: [] for i in agents}
    for (i, j) in C_G.edges:
        r = norm(consistency(agents[i].state, agents[j].state,
                             agents[i].action, agents[j].action))
        z = r / sigma_ij(agents[i], agents[j])
        Z[i].append(z); Z[j].append(z)
    score = {i: median(v) for i, v in Z.items()}
    flagged = {i for i, s in score.items() if s > theta_r}
    blind = max(score.values()) < theta_r
    return flagged, score, blind
```

### IP-124 DCC

```python
def diversity_certificate(profiles, blind_set, theta_B, theta_corr):
    cover = union_support(profiles)
    if not blind_set <= cover:
        return ('reject', 'blind_set_uncovered', blind_set - cover)
    B_cover = mean([max(p.beta.get(w, 0) for p in profiles) for w in blind_set])
    corr_max = max_pairwise_corr(profiles)
    if B_cover < theta_B or corr_max > theta_corr:
        return ('reject', 'diversity_insufficient', B_cover, corr_max)
    return ('ok', DCC(cover, corr_max, B_cover, diversity_sources(profiles)))
```

### IP-125 ACG

```python
def contain_and_replan(flagged, agents, alpha, task_graph, rho_tau,
                       lam, theta_iso):
    iso = {}
    for i in flagged:
        trust = {a: alpha[i][a] * exp(-rho_tau[i].get(a, 1.0) / lam)
                 for a in alpha[i]}
        iso[i] = {a for a, v in trust.items() if v >= theta_iso}
        agents[i].action_domain = iso[i]          # 收缩而非停机
    new_task = replan(task_graph, isolated=iso)
    if (not connectivity_preserved(task_graph, new_task)
            or cost_iso(new_task) > THETA_ISO):
        return ('escalate', 'need_external_anchor', iso, new_task)
    return ('ok', iso, new_task)
```

### IP-126 TAC

```python
def team_anomaly_certify(agents, C_G, Omega, alpha, task_graph, budgets):
    rho_team = team_spectrum(agents, C_G, DIMS)
    if any(rho_team[d] < budgets.rho_min[d] for d in DIMS):
        return ('reject', 'team_robustness_fail', rho_team)
    profiles = [anomaly_profile(a, Omega, SAMPLER, budgets.budget) for a in agents]
    dcc = diversity_certificate(profiles, blind_set(profiles),
                                budgets.theta_B, budgets.theta_corr)
    if dcc[0] == 'reject':
        return ('reject', 'common_mode_blind', dcc)
    flagged, score, blind = residual_consensus(agents, C_G, budgets.theta_r)
    if blind:
        return ('degrade', 'common_mode_suspected', ask_external_anchor())
    iso = contain_and_replan(flagged, agents, alpha, task_graph,
                             rho_tau=score, lam=budgets.lam,
                             theta_iso=budgets.theta_iso)
    if iso[0] != 'ok':
        return iso
    return ('ok', TAC(agents, C_G, rho_team, profiles, dcc, iso, evidence_log()))
```

|---|---|---|---|
| TRS | O(2^{|N|}·|N|) 精确；最小割 O(|E_c|·|N|²) 近似 | O(N²) | 割完备 / κ 上界 sound |

| TAC | Σ 上述 | O(|Ω|·|N| + |A|·|N|) | 联合证书 sound |

**正确性定理（Team Anomaly-Aware Collaboration Soundness）**
承接 (A22)–(A28)；新增 **(A29)** 个体证书 `J_i` sound；**(A30)** `κ_ij` 有上界并在线校准；**(A31)** `DCC` 覆盖共模盲集 `B` 且 `ℓ ≤ τ_iso`；**(A32)** 隔离后任务图连通且重规划收敛。
则：
```
P(团队成功 ∧ 无未检测污染传播)
  ≥ 1 - Σ_d(1-ρ_team(d)) - (1-B_cover) - P(ω∈Ω\Ω_cover)
      - P(ℓ>τ_iso) - P(Σκ_ij·残差>θ_leak)
      - P(iso 破坏连通) - β_E
```
关键：**团队谱先按最弱割扣污染**，**共模盲集必须被异构检测器覆盖**，**隔离通过动作域收缩实现**。

## 5. 本轮最大风险

**一句话**：多机协作与异常检测的引入，把团队保证从 `min_i ρ_i` 升级为「最弱割 + 共模盲集覆盖 + 隔离连通性」的联合判据，但其 soundness **三重依赖共模盲集的完备枚举、传播增益 κ_ij 的保守上界、以及隔离后重规划的连通收敛**；一旦盲集漏枚举或 κ 被低估，团队会在“所有 agent 都报警正常”的共模故障下集体失明并沿协作边级联污染，故必须以 **对抗共模采样 + κ 区间上界 + 外部锚点降级** 三重护栏，宁可误报降级，绝不把“多机冗余”当作“多机可靠”。
