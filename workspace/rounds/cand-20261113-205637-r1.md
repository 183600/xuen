# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「语义建图」×「强化学习」）

> R69 教会系统「问」——把不确定性拆成 aleatoric / epistemic，用流匹配策略显式呈现动作模态，用 VoI 选择注视/探针/问句去消解可约的歧义。但它有两个结构性缺陷，恰好是一个「记忆问题」和一个「信用分配问题」。
>
> 第一，**系统是金鱼记忆**：每次交互的结论只用于更新当前后验，答完即忘。同一个房间、同一类歧义，明天还要再问一遍；「这张桌子上次被确认是杯子」「这个反光面上的深度不可信」「上回问这句话得到了误导答案」——这些用代价换来的知识没有沉淀，既不积累、不复用，也无法迁移。
>
> 第二，**VoI 是短视的**：R69 定义 298 只算「这次问值不值」，不算「问完之后我的世界模型/策略是否变得更好」，也从不从「问了没用」中学到「这类问题别问」。更根本地，R69 自陈的最大风险——流模型模态分布不可信时 VoI 建立在错误信念上——源于 VoI 只有一个来源：当前流模型的即时后验。
>
> 本轮两个灵感正好补上这两块：
> - **语义建图**把交互产物沉淀为**持久、带来源、带不确定性、会过期**的语义地图：不仅记「那里有什么」，还记「我有多确定、凭什么确定、上次怎么问清楚的、这条信息多久失效」。地图还提供**免费先验**（空间/语义共现）在交互前压低歧义，并提供 RL 的可迁移状态抽象。
> - **强化学习**把「一次性 VoI」升级为**长时程信息价值**：问的价值 = 它让未来多少步的期望回报变好。用离线、保守的 RL 从 R69 的安全日志中学习「在什么地图情境下问什么值不值」，把探索限制在地图认证的安全交互区内，用悲观下界保证不比 R69 更冒险。
>
> 核心命题：**语义建图负责「记住并结构化不确定性」，强化学习负责「从后果中学习何时/如何消解它」；二者互为对方缺失的部分——地图给 RL 可迁移的状态与免费先验，RL 给地图非短视的、经验校准的价值判断。** 命名 **ATLAS-RAS**（Adaptive Topological-semantic Learned Action Selection for Risk-aware systems）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**问过之后，我记住了吗？下次还问吗？问了到底改变了什么？**」——不确定性管理从「现场消歧」升级为「可积累的认知资产」。

## 0. 直觉与动机

**灵感 1（语义建图 → 记忆让消歧可复用）**
直觉：R69 的交互像一次性查询；语义建图把它变成写入。人不会每次都重新认识房间，而是维护一张不断更新的地图：哪里是门、哪里是桌、哪个杯子上次是空的、哪个角落的传感器总在反光时出错。关键是这张图不只记事实，还记**关于事实的可信度与来历**。于是「问」的产物不再随回合蒸发，而是成为下一次决策的先验、下一次交互的案例、以及 RL 的状态。
严谨地说，地图是一个关于语义标签的**结构化信念** SEM_t，每个节点携带标签分布、R69 意义下的 (U_ale,U_epi)、来源集、信任度、状态（未知/歧义/已确认/有争议/隔离）、以及交互记忆。它不是真值表，而是「我知道什么、凭什么、多确定、何时失效」的账本。

**灵感 2（强化学习 → 信用分配让消歧学会「值不值」）**
直觉：R69 的 MINT 是一步贪心：VoI(g) − c(g) > 0 就问。但「问」的收益常在未来兑现（避免一次错误抓取、少绕一段路、建立可复用知识），成本也可能在未来摊销。这正需要 RL 的信用分配。把交互策略写成半马尔可夫决策过程，信息动作的价值 = 它对**未来回报**的贡献，而非仅对**当前后验熵**的贡献。
严谨地说，长时程 VoI 就是优势函数 A^π(s,g)=Q^π(s,g)−V^π(s)；R69 的 VoI 是它在 γ=0、单步、无自举、空地图下的特例（引理 19）。RL 不是推翻 MINT，而是把它嵌入一个会为「未来可复用的信息」付钱的价值函数里。

**灵感 3（两者的真正耦合 → 地图是 RL 的状态，RL 是地图的估值器）**
直觉：把两个灵感简单叠加（地图 + RL）是平庸的。真正的耦合是双向的：
- 语义地图给 RL 一个**拓扑抽象的、可迁移的状态** s=φ(G_t^r,{b_n,U_n},budget,phase)，使「语义相似的处境」共享策略，极大降低样本复杂度（引理 23：近似 MDP 同态）；
- RL 给地图一个**后果校准的价值判断**：不是「地图说这里有歧义」就值得问，而是「从这张地图出发、问这一句、按历史经验未来回报能提高多少」——这是对 R69 模型式 VoI 的经验式第二意见。
于是地图与 RL 共同构成一个**非短视的、可复用的消歧系统**，而不是两个各自需要独立信任的黑箱。

**灵感 4（对 R69 最脆弱处的正面回应 → 经验 VoI 作为第二意见）**
直觉：R69 的 VoI 完全由流模型的模态后验算出，若模态分布幻觉/坍缩，VoI 就在错误信念上最优。ATLAS 增加一条**经验通道**：离线 RL 从「R69 当时问了、后来结果如何」的日志里学 Q。当模型式 VoI 与经验式价值**冲突**时，按保守原则取较低的交互意愿——两条通道都要点头才行动。这与 R69 用流似然给 R68 残差做第二意见是同一手法：**新层为旧层最脆弱的假设提供一条不可被该假设污染的冗余通道**。

**灵感 5（记忆与 RL 都是双刃剑 → 新的威胁模型与新的纪律）**
直觉：一旦系统会「记」和「学」，错误就有了复利。R69 的风险是「问错一次」；ATLAS 的风险是「把问错的结果写进地图、被 RL 反复利用、再自我确认」。所以本轮必须同时交付：来源信任传播与隔离、地图校准门、反自确认探针、离线 RL 的悲观下界、安全交互区、地图审计。否则记忆会把一次噪声放大成一条长期偏见——**记错，比问错更危险**。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（ATLAS-RAS 总览）** ATLAS-RAS = (SEM, MPA, LIVE, CIRL, SIR, PROV, MEM, MCG-M, RAS-WM‡)。三不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）：语义地图的更新与 RL 训练只在回合之间/离线进行；实时环路只读冻结快照 SEM† 与冻结策略 π_R†；
(ii) **预算与安全**（继承 R69 定义 293-ii）：信息动作仍需过 C-RAS-WM，且其物理部分必须留在「安全交互区」SIR 内；
(iii) **来源纪律**（强化 R69 定义 293-iii）：任何用于**降低** λ 或**跳过**交互的持久地图断言，必须有 ≥2 个独立来源或通过审计；单源断言只能停留在「歧义」。

**定义 311（语义认知地图 SEM）** SEM_t=(V_t,E_t,{b_n,(U_n^ale,U_n^epi),P_n,τ_n,σ_n,μ_n})。节点 n 表示地标/栅格/物体/关系；边 e 表示空间、语义或功能关系。b_n 为语义标签信念；U^ale/U^epi 沿用 R69 定义 297；P_n={(src_i,eid_i,t_i,κ_i)} 为来源集（κ_i 为独立性类别）；τ_n∈[0,1] 为信任度；σ_n∈{未知, 歧义, 已确认, 有争议, 隔离} 为认识状态；μ_n 为交互记忆：(模态对, 信息动作 g) → (试验数, 平均增益, 平均成本)。SEM 是对语义的**结构化信念**而非真值表。

**定义 312（地图先验消歧与免费信息）** 以半径 r 的局部子图 G_t^r 为上下文，模式 M 的后验为 p(M|o_t,SEM_t) ∝ p(M|o_t)·exp(−E_map(M;G_t^r))，E_map 编码语义共现与空间相容性。定义免费熵减 ΔH_map = H(M|o_t) − H(M|o_t,SEM_t) = I(M;SEM_t|o_t)。若 ΔH_map ≥ τ_map 且 MCG-M 通过，则模式合并/歧义在**不交互**的情况下被消解（resolution by memory）。

**定义 313（地图抽象状态 MPA）** φ(o_{0:t},SEM_t) = s_t = (Topo(G_t^r), {b_n,(U_n)}_{n∈G}, phase, budget_rem, mode_summary)。Topo 为关系类型保持的图拓扑（对米制位姿不敏感）⇒ 语义相似处境共享策略。这是 CIRL 的状态。

**定义 314（长时程信息价值 LIVE）** 半马尔可夫决策过程，折扣 γ、时域 H。V^π(s)=E[Σ_{k=0}^{H} γ^k (r_task − c_int·1[g_k≠∅] − c_risk)]；Q^π(s,g) 为提交信息动作 g 后按 π 延续的价值。定义长时程 VoI：𝒱_γ(g)=Q^π(s,g)−V^π(s)=A^π(s,g)（优势）。γ=0、H=1、无自举、空地图时退化为 R69 的 VoI−c（引理 19）。

**定义 315（保守离线交互 RL CIRL）** 离线数据集 D 来自 R69 MINT 的安全交互日志（行为策略即 MINT）。集成 {Q̂_j}，悲观下界 Q_lcb(s,g)=Q̄(s,g)−β·u(s,g)，u 为集成分歧+密度惩罚。决策 g*=argmax_{g∈𝒢_safe(s)} Q_lcb(s,g)，仅当 Q_lcb≥0 且状态在离线支撑内（密度≥τ_sup，support check）才交互；否则退回 MINT/不交互。实时环路内无任何梯度更新。

**定义 316（安全交互区 SIR）** R_safe(SEM)={n∈V: risk_lcb(n)≤ε_sir ∧ τ_n≥τ_min ∧ σ_n≠隔离}。信息动作的物理部分（转身注视、探针、靠近）的预测轨迹必须落在 R_safe 内并过 C-RAS-WM，否则 g 作废、U_epi 视为未消解。探索只在离线/影子/仿真中进行，且不得越出 R_safe。

**定义 317（来源信任传播与隔离 PROV）** τ_n=clip(Σ_{i∈P_n} w(κ_i,depth_i)·conf_i,0,1)，同类相关来源被**次可加**封顶（两个同源来源计数≤1.2×单源）。证据冲突 ⇒ σ_n=有争议且 τ_n 取冲突分支最小值（不做平均抹平）。隔离节点 σ_n=隔离，其出边权重乘 ρ_q<1，直到被独立再确认；隔离节点不得用于降低 λ。单源（即使高置信）无法把节点升为「已确认」——把 R69 的 k-正交纪律从单次决策提升为持久记忆。

**定义 318（交互记忆与案例复用 MEM）** 案例 c_j=(s_j,g_j,ΔU^epi_obs,outcome_j,t_j)。按地图抽象度量 d_topo 检索最近案例；若 d≤τ_case、τ_case≥τ_min 且未陈旧，则把 g_j 作为**先验提议**交给 CIRL（缩小候选、可跳过 VoI 枚举）。复用永远不能绕过安全与证据纪律，每次复用记入审计；跟踪复用精度。

**定义 319（地图校准门 MCG-M）** ECE_map 度量 b_n 与预测 U_n^epi 的校准误差。若 ECE_map>τ_eceM，地图只能用于**保守**用途（抬高 λ、禁止探索、收缩 SIR），不得用于降低 λ、跳过交互或扩张 R_safe。不可信的地图只允许让系统更谨慎，不允许让它更大胆。

**定义 320（地图-观测矛盾通道 MAP-FMA）** 语义惊奇 S_map=−log p(o_t|SEM_t)（或地标/关系失配）。三通道 (r_res, Δa, S_map) 联合诊断：残差↑⇒传感器漂移；流似然差↑⇒行为/世界失配；S_map↑且 r_res 低⇒地图损坏或世界变更。后者与 R69 的缓变故障判据正交，用审计区分「该更新地图」与「该保守」。

**定义 321（反自确认纪律）** 防止地图-策略反馈环自我强化：(1) 预留 β_dis 比例交互预算做**反确认探针**，优先探测「有争议/高 U_epi」节点，最大化「地图是否错了」的期望信息而非确认既有先验；(2) 审计「先验一致性」：若某节点近期证据几乎总与先验一致，标记潜在确认偏差/投毒；(3) 仅有先验一致历史的节点，未经一次独立或反确认检验不得升为「已确认」。

**定义 322（参与式地图审计 VQAuditor-M）** 审计地图写入：来源完整性、单源升格、陈旧却高信任节点、地图投毒特征、RL 奖励黑客特征（如某信息动作学习价值异常高但经验增益低）、案例复用错误。写入先隔离（σ=隔离），审计通过才生效；审计结论回灌地图信任与离线 RL 训练。

**定义 323（ATLAS 干扰集 AIC-ATLAS）** ℰ_ATLAS=ℰ_FLUID×ℰ_map×ℰ_rl。ℰ_map：伪造地标注入、来源伪造、陈旧节点重放、语义边投毒；ℰ_rl：离线数据投毒、价值高估利用（推向高 Q_lcb 的坏动作）、交互成本奖励黑客、探索陷阱。

**定义 324（证书 J_ATLAS）** J_ATLAS=(J_FLUID, map_ece, provenance_coverage, contested_ratio, quarantine_used, rl_support_gap, reuse_precision, atlas_ver)。Valid ⇔ Valid(J_FLUID) ∧ map_ece≤τ ∧ 任何降低 λ 的节点来源完整 ∧ 未使用隔离节点 ∧ 离线支撑检查通过。

**定义 325（三级保守退避）**
- **L0（最佳）**：MCG-M 通过 + 地图先验 + Q_lcb≥0 + 证据纪律满足 ⇒ 允许交互/跳过；λ=λ_floor(U_ale)（resolution bonus）。
- **L1（R69）**：地图 ECE 越界 / 离线支撑不足 / CIRL 不确定 / 来源不足 / 有争议 ⇒ 弃用地图与 RL 做**决策**，退回 R69 MINT 短视 VoI；λ=λ_floor(U_ale+未消解 U_epi)。
- **L2（R68）**：慢变故障 / S_map 异常未证实 / 路径含隔离节点 / 预算耗尽 / OOD ⇒ R68 纯保守，λ=λ_floor(U_ale+U_epi)，不交互。
沿退化链 λ 单调不减，安全侧永不让步；R69 是 L1 在空地图、无 RL 时的特例，R68 是 L2 的特例。

**定义 326（地图-策略稳定性与零实时写）** 地图更新与 RL 训练只在回合之间、经审计、按每回合写配额 Δ_SEM≤quota 执行；运行时只读冻结快照。任何会跨越「改变控制选择」阈值的地图写入需审计并在下一回合生效。由此保持 R68 定理 15 的无突变与实时零学习写不变式。

```python
# IP-264 SEM：语义认知地图（持久信念 + 来源 + 交互记忆；离线写）
class SemanticEpistemicMap:
    def query_context(self, o_t, r=3.0):
        return self.local_subgraph(o_t.pose, r)            # G_t^r，只读快照 SEM†

    def mode_prior(self, modes, G):                        # 定义 312
        return normalize([m.w * exp(-self.energy(m, G)) for m in modes])

    def propose_cases(self, s, topk=3):                    # IP-270 MEM
        return self.case_bank.nearest(s, k=topk, metric=topo_dist)

    def stage_write(self, node, evidence, prov):           # 只在回合之间
        if not self.mcg_m.ok:                              # 不可信地图不得扩张
            return
        self.quarantine[node] = merge(node, evidence, prov)
        self.vqa_m.submit(node)                            # 审计前隔离

# IP-265 MPA + IP-266 LIVE：地图抽象状态与非短视信息价值
def atlas_state(o_t, SEM, budget, phase):
    G = SEM.query_context(o_t)
    return phi(Topo(G), [(n.b, n.U) for n in G.nodes], phase, budget)

class LongHorizonInfoValue:
    def q_lcb(self, s, g):                                 # 集成 + 悲观
        qs = [q(s, g) for q in self.ensemble]
        return mean(qs) - self.beta * (std(qs) + density_penalty(s, g))

# IP-267 CIRL：保守离线交互策略（实时只推理，不学习）
def choose_interaction_atlas(M, s, modes, budget):
    if not M.mcg_m.ok or not M.prov.trusted_path(s):
        return None, 'L1'                                  # 退回 R69 MINT
    cases = M.sem.propose_cases(s)
    cands = [c.g for c in cases] or info_action_candidates(modes)
    best = None
    for g in cands:
        if not budget.allow(g) or not M.sir.contains(g, s):  continue
        if not M.c_ras_wm.certify_info(g, s.o):              continue
        q = M.live.q_lcb(s, g)
        if best is None or q > best[1]: best = (g, q)
    if best is None or best[1] < 0: return None, 'L1'      # 下界为负 → 不问
    return best[0], 'L0'

# IP-268 SIR + IP-269 PROV：安全交互区与来源信任
def sir_contains(g, s):
    return all(risk_lcb(n) <= EPS_SIR and tau[n] >= TAU_MIN and status[n] != 'Q'
               for n in predicted_footprint(g, s))

def trust(node):
    groups = cap_correlated(node.P)                        # 次可加封顶
    if has_conflict(node.P):
        node.status = 'contested'
        return min(branch_conf(b) for b in conflict_branches(node.P))
    return clip(sum(w(k, depth) * conf for k, depth, conf in groups), 0, 1)

# IP-276 ATLAS 主闭环（继承 R69，仅在不确定性处置处插入地图/RL 层）
def ATLAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    G = M.sem.query_context(o)                             # 只读 SEM†
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    modes = M.sem.mode_prior(modes, G)                     # 免费先验 ΔH_map
    s = atlas_state(o, M.sem, M.budget, M.phase)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o_obs, o_calibrated)
    s_map = M.map_fma.surprise(o, M.sem)                   # 定义 320
    slow  = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    level = 'L2' if (slow or s_map > TAU_MAP) else 'L0'
    g = None
    if level != 'L2' and U_epi > TAU_EPI:
        g, level = M.cirl.choose_interaction_atlas(M, s, modes, M.budget)
    if g is not None:
        ans = M.cia.execute(g)                             # 看/问/触：认证 + 证据纪律
        U_epi_after = M.cia.update_belief(modes, ans)
        M.sem.stage_write(node_of(g), ans, prov_of(g))     # 写入先隔离，回合后审计
    else:
        U_epi_after = U_epi
    U_floor = U_ale + (0.0 if g is not None else U_epi_after)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    if level == 'L2': lam = max(lam, 0.8); k = min(k, k_cal_shrink(x_prime, U_cal))
    mode = select_mode(modes, U_epi_after, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_m.submit_async(g, U_epi, U_epi_after, a_hat, s_map, level)
    return k, lam, mode, (U_ale, U_epi_after, level)
```

## 3. 推导

**引理 19（长时程 VoI 严格包含 R69 短视 VoI）** 取 γ=0、H=1、无自举、空地图，则 A^π(s,g)=E[r_task−c_int|s,g]−V^π(s)，它与 R69 的 VoI(g)−c(g) 在 r_task 取负任务误差时逐项一致。故 R69 的 MINT 是 CIRL 在 (γ=0, SEM=∅) 的边界；γ>0 时 LIVE 额外计入「本次信息在未来被复用」的收益，这正是 MINT 结构上缺失、因而系统性**少问**的部分。系：短视 VoI 不会高估长期价值，但会漏掉可复用信息的复利。

**引理 20（语义先验的免费熵减与交互次数）** 对任意地图上下文 I(M;SEM_t|o_t)≥0，故 H(M|o_t,SEM_t)≤H(M|o_t)。若地图校准（ECE_map≤τ，A-map），用地图先验的期望任务误差不高于无地图；达到目标残余熵 H* 所需的交互次数期望满足 E[N]∝(H(M|o_t)−ΔH_map−H*)/E[ΔH_int]，故 ΔH_map>0 时交互次数严格下降。系：**记忆的价值首先体现为「不用再问」**；但若 A-map 不成立，此收益反向（故有 MCG-M 门）。

**引理 21（保守离线 RL 的交互价值下界）** 设离线 Q̂ 以高概率落在 [Q*−b,Q*+b]，令 Q_lcb=Q̄−βu。若 βu≥2b，则任何被 CIRL 采纳的交互满足真实长时程优势 A^π(s,g)≥0；若 Q_lcb<0 或支撑不足则退回 R69/不交互。故 ATLAS 不会采取「下界为负」的交互，其期望风险不高于一个可能被错误模型 VoI 误导的策略。系：悲观不是保守主义口号，而是「只在有下界保证时才敢用经验价值」的可证条件。

**引理 22（持久地图的投毒隔离上界）** 单源伪造把节点升为「已确认」需跨过 k 个独立类别，成功率 ≤ δ_p·ρ^{k−1}+ε_σ（同 R69 引理 18）；且信任沿来源图按深度 ρ^{depth} 衰减、相关来源次可加封顶，故单个谎言对邻域的影响被限制在局部，且隔离节点不参与 λ 降低。系：**记忆不会把一次谎言放大成全局偏见，前提是来源纪律与隔离先于写入。**

**引理 23（地图抽象的样本复杂度）** 若 φ 是从完整 POMDP 到地图抽象 MDP 的 ε_h-近似同态（转移与回报误差 ≤ε_h），则交互策略的样本复杂度按 |S_abs|·|𝒢| 而非 |S_full|·|𝒢| 缩放，价值误差 ≤ε_h/(1−γ)。故语义抽象是让离线 RL 在有限交互日志上可行的关键，而非装饰。

**定理 18（ATLAS 严格包含 FLUID 与 CALM）** 在 A-map（用于决策时地图已校准）与 A-rl（悲观惩罚压过离线偏差）下，ATLAS 在任意状态的期望风险 ≤ R69 ≤ R68。当 MCG-M 越界、离线支撑不足、Q_lcb<0、来源不足、慢变故障或路径含隔离节点时，ATLAS 逐指令退化为 R69（L1）或 R68（L2）。故新层是旧层的严格泛化：安全侧不让步，效率收益只来自校准地图上的免费先验与非短视价值。

**定理 19（地图-策略闭环的稳定性与无突变）** 回合间写、每回合写配额 Δ_SEM≤quota、运行时冻结快照、审计隔离、λ 沿 L0→L1→L2 单调不减，共同保证控制连续、无突变；反自确认探针预算与审计上界自确认反馈环，离线 RL 无在线写操作。故加入记忆与 RL 不破坏 R68 定理 15 的换装不变式与实时零学习写不变式。

## 6. 本轮最大风险

**一句话**：ATLAS 把一次交互的结论写进持久地图、再由 RL 反复利用——**若地图吸收了一个被投毒或幻觉的语义断言，错误就不再是 R69 的一次性「问错」，而是被固化、被空间与时间扩散、并被策略主动优化的「记错」；地图-策略自确认环会让系统越来越自信地错**——**记错，比问错更危险**。

**次级风险与缓解**：
1. 地图自确认/反馈放大 → 反确认探针预算（定义 321）+ 先验一致性审计 + 隔离写入；
2. 地图投毒与来源伪造 → PROV 次可加封顶 + k 独立来源 + 引理 22 局部化上界；
3. 离线 RL 分布偏移/价值高估 → 悲观下界 Q_lcb + 离线支撑检查 + 引理 21，越界即退回 R69；
4. RL 奖励黑客 → VQAuditor-M 审计「学习价值 vs 经验增益」背离（定义 322）+ E312；
5. 非平稳导致陈旧先验 → 信任指数衰减 + ECE_map 门 + 回合间写配额（定义 312/319/326）。

```python
# IP-264 SEM：语义认知地图（持久信念 + 来源 + 交互记忆；离线写）
class SemanticEpistemicMap:
    def query_context(self, o_t, r=3.0):
        return self.local_subgraph(o_t.pose, r)            # G_t^r，只读 SEM†

    def mode_prior(self, modes, G):                        # 定义 312
        return normalize([m.w * exp(-self.energy(m, G)) for m in modes])

    def propose_cases(self, s, topk=3):                    # IP-270
        return self.case_bank.nearest(s, k=topk, metric=topo_dist)

    def stage_write(self, node, evidence, prov):           # 只在回合之间
        if not self.mcg_m.ok: return                       # 不可信地图不得扩张
        self.quarantine[node] = merge(node, evidence, prov)
        self.vqa_m.submit(node)                            # 审计前隔离

# IP-265 MPA + IP-266 LIVE
def atlas_state(o_t, SEM, budget, phase):
    G = SEM.query_context(o_t)
    return phi(Topo(G), [(n.b, n.U) for n in G.nodes], phase, budget)

class LongHorizonInfoValue:
    def q_lcb(self, s, g):                                 # 集成 + 悲观
        qs = [q(s, g) for q in self.ensemble]
        return mean(qs) - self.beta * (std(qs) + density_penalty(s, g))

# IP-267 CIRL：保守离线交互策略（实时只推理，不学习）
def choose_interaction_atlas(M, s, modes, budget):
    if not M.mcg_m.ok or not M.prov.trusted_path(s):
        return None, 'L1'
    cases = M.sem.propose_cases(s)
    cands = [c.g for c in cases] or info_action_candidates(modes)
    best = None
    for g in cands:
        if not budget.allow(g) or not M.sir.contains(g, s):  continue
        if not M.c_ras_wm.certify_info(g, s.o):              continue
        q = M.live.q_lcb(s, g)
        if best is None or q > best[1]: best = (g, q)
    return (best[0], 'L0') if best and best[1] >= 0 else (None, 'L1')

# IP-268 SIR + IP-269 PROV
def sir_contains(g, s):
    return all(risk_lcb(n) <= EPS_SIR and tau[n] >= TAU_MIN and status[n] != 'Q'
               for n in predicted_footprint(g, s))

def trust(node):
    groups = cap_correlated(node.P)                        # 次可加封顶
    if has_conflict(node.P):
        node.status = 'contested'
        return min(branch_conf(b) for b in conflict_branches(node.P))
    return clip(sum(w(k, depth) * conf for k, depth, conf in groups), 0, 1)

# IP-276 主闭环（继承 R69，仅在不确定性处置处插入地图/RL 层）
def ATLAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    G = M.sem.query_context(o)                             # 只读 SEM†
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    modes = M.sem.mode_prior(modes, G)                     # ΔH_map
    s = atlas_state(o, M.sem, M.budget, M.phase)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o_obs, o_calibrated)
    s_map = M.map_fma.surprise(o, M.sem)
    slow  = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    level = 'L2' if (slow or s_map > TAU_MAP) else 'L0'
    g = None
    if level != 'L2' and U_epi > TAU_EPI:
        g, level = M.cirl.choose_interaction_atlas(M, s, modes, M.budget)
    if g is not None:
        ans = M.cia.execute(g)
        U_epi_after = M.cia.update_belief(modes, ans)
        M.sem.stage_write(node_of(g), ans, prov_of(g))     # 先隔离，回合后审计
    else:
        U_epi_after = U_epi
    U_floor = U_ale + (0.0 if g is not None else U_epi_after)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    if level == 'L2': lam = max(lam, 0.8); k = min(k, k_cal_shrink(x_prime, U_cal))
    mode = select_mode(modes, U_epi_after, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_m.submit_async(g, U_epi, U_epi_after, a_hat, s_map, level)
    return k, lam, mode, (U_ale, U_epi_after, level)
```

## 4. 推导

**引理 19（长时程 VoI 严格包含 R69 短视 VoI）** `γ=0,H=1,无自举,空地图` 时 `A^π(s,g)=E[r_task−c_int|s,g]−V^π(s)`，与 R69 的 `VoI(g)−c(g)`（令 r_task 为负任务误差）逐项一致。故 R69 的 MINT 是 CIRL 在 `(γ=0, SEM=∅)` 的边界；`γ>0` 时 LIVE 额外计入「本次信息在未来被复用」的收益，这正是 MINT 结构上缺失、因而系统性**少问**的部分。系：短视 VoI 不会高估长期价值，却会漏掉可复用信息的复利。

**引理 20（语义先验的免费熵减与交互次数）** 对任意地图上下文 `I(M;SEM_t;o_t)≥0`，故 `H(M|o_t,SEM_t)≤H(M|o_t)`。若地图校准（`ECE_map≤τ`，A-map），用地图先验的期望任务误差不高于无地图；达到目标残余熵 `H*` 所需交互次数期望满足 `E[N]∝(H(M|o)−ΔH_map−H*)/E[ΔH_int]`，故 `ΔH_map>0` 时交互次数严格下降。系：**记忆的价值首先体现为「不用再问」**；但 A-map 不成立时此收益反向，故设 MCG-M 门。

**引理 21（保守离线 RL 的交互价值下界）** 设离线 `Q̂` 以高概率落在 `[Q*−b,Q*+b]`，令 `Q_lcb=Q̄−βu`。若 `βu≥2b`，则任何被 CIRL 采纳的交互满足真实长时程优势 `A^π(s,g)≥0`；若 `Q_lcb<0` 或支撑不足则退回 R69/不交互。故 ATLAS 不会采取「下界为负」的交互，其期望风险不高于一个可能被错误模型 VoI 误导的策略。系：悲观不是保守主义口号，而是「只在有下界保证时才敢用经验价值」的可证条件。

**引理 22（持久地图的投毒隔离上界）** 单源伪造把节点升为「已确认」需跨过 k 个独立类别，成功率 `≤ δ_p·ρ^{k−1}+ε_σ`（同 R69 引理 18）；且信任沿来源图按深度 `ρ^{depth}` 衰减、相关来源次可加封顶，故单个谎言对邻域的影响被限制在局部，隔离节点不参与 λ 降低。系：**记忆不会把一次谎言放大成全局偏见，前提是来源纪律与隔离先于写入。**

**引理 23（地图抽象的样本复杂度）** 若 φ 是从完整 POMDP 到地图抽象 MDP 的 `ε_h`-近似同态（转移与回报误差 `≤ε_h`），则交互策略的样本复杂度按 `|S_abs|·|𝒢|` 而非 `|S_full|·|𝒢|` 缩放，价值误差 `≤ε_h/(1−γ)`。故语义抽象是让离线 RL 在有限交互日志上可行的关键，而非装饰。

**定理 18（ATLAS 严格包含 FLUID 与 CALM）** 在 A-map（用于决策时地图已校准）与 A-rl（悲观惩罚压过离线偏差）下，ATLAS 在任意状态的期望风险 `≤ R69 ≤ R68`。当 MCG-M 越界、离线支撑不足、`Q_lcb<0`、来源不足、慢变故障或路径含隔离节点时，ATLAS 逐指令退化为 R69（L1）或 R68（L2）。故新层是旧层的严格泛化：安全侧不让步，效率收益只来自校准地图上的免费先验与非短视价值。

**定理 19（地图-策略闭环的稳定性与无突变）** 回合间写、每回合写配额 `Δ_SEM≤quota`、运行时冻结快照、审计隔离、λ 沿 L0→L1→L2 单调不减，共同保证控制连续、无突变；反自确认探针预算与审计上界自确认反馈环，离线 RL 无在线写操作。故加入记忆与 RL 不破坏 R68 定理 15 的换装不变式与实时零学习写不变式。

## 7. 本轮最大风险

**一句话**：ATLAS 把一次交互的结论写进持久地图、再由 RL 反复利用——**若地图吸收了一个被投毒或幻觉的语义断言，错误就不再是 R69 的一次性「问错」，而是被固化、被空间与时间扩散、并被策略主动优化的「记错」；地图-策略自确认环会让系统越来越自信地错**——**记错，比问错更危险**。

**次级风险与缓解**：
1. 地图自确认/反馈放大 → 反确认探针预算（定义 321）+ 先验一致性审计 + 隔离写入；
2. 地图投毒与来源伪造 → PROV 次可加封顶 + k 独立来源 + 引理 22 局部化上界；
3. 离线 RL 分布偏移/价值高估 → 悲观下界 Q_lcb + 离线支撑检查 + 引理 21，越界即退回 R69；
4. RL 奖励黑客 → VQAuditor-M 审计「学习价值 vs 经验增益」背离（定义 322）+ E312；
5. 非平稳导致陈旧先验 → 信任指数衰减 + ECE_map 门 + 回合间写配额（定义 312/319/326）。
