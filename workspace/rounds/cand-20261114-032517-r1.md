# 第 71 轮（承接第 70 轮「BELIEF-RAS 贝叶斯状态估计交互消歧闭环」IP-264~274；灵感循环第 1 轮；本轮灵感：「论文创新点」×「强化学习」）

> R70 把 epistemic 从「动作模态」推进到「世界状态后验 b_t(s)」，并交付了基线协议与原型验收。但它自陈的最大风险从未被正面处理：**p(o|s) 与 π_θ 都在源分布上训练，部署时世界变了，BSE 仍会给出熵很低、却离真相很远的后验——H[b_t] 变小反而意味着风险变大。** 更根本的是，R66–R70 五轮全部是「推断」：标定、预测、消歧、状态估计；没有一层真正**从交互结果中学习并改进策略**。交互产生的 (b_t, g, y, r, c, b_{t+1}) 只被用来更新信念，从未被用来更新策略；MINT 的 VoI 是手写启发式，既没证明接近最优，也没测过它到底贡献了多少。
>
> 本轮两个灵感指向同一个数学对象：
> - **强化学习**的核心是**信用分配（credit assignment）**：哪个动作、哪个模块对回报负责？它恰好补上 R66–R70 缺失的学习闭环，并把「该问什么、该保守到什么程度」从手写规则变成可学习、可证明改进的策略。
> - **论文创新点**的诚实定义也是一个**反事实因果命题**：「把 X 从系统里拿掉，Y 会显著变差」——它和 RL 的信用分配是同一件事的两个名字，一个对科学负责，一个对控制负责。
>
> 核心命题：**给 BELIEF-RAS 补上「学习层」与「证伪层」——用信念空间约束强化学习（BRL）联合学习任务动作与信息动作；用离策略评估置信区间（OPE-CI）与反事实归因（CGA）把每一个所谓创新点变成带置信区间的可证伪假设；只有通过安全改进门（SIG）认证的策略更新才允许部署，未通过者原样退回 R70。** 命名 **NOVA-RAS**（Novelty-gated Off-policy Value Assurance for safe belief-space Reinforcement learning）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「测量还准吗」，R69 问「该向谁求证」，R70 问「该信哪个世界状态」，R71 问「**我到底学到了什么、这些层真的有用吗；没用就删掉，有用要能被证明**」。

## 0. 直觉与动机

**灵感 1（RL 是缺失的那一层：推断不等于学习）**
直觉：R70 的闭环像一位极其谨慎的测量员——每一步都在问「我的信念还准吗」，却从不停下来问「我上次做的决定，事后看对不对」。交互动作 g 发出了、回答 y 收到了、结果 r 与安全成本 c 也观测到了，但这些信号只进了 BSE 的后验更新，没进策略参数。于是系统可以永远重复同样的错误决策而不自知：信念越来越准，行为却停在原处。RL 把这条断掉的回路接上：把 (b_t, (a,g), r, c, b_{t+1}) 当成转移，学习 π(a,g|b_t)，再用约束优化保证安全成本不越界。**这是 R66–R70 缺的「改进」，不是又一层「检查」。**

**灵感 2（论文创新点 = 可证伪的反事实）**
直觉：一篇论文说「我们的模块 M 带来了提升」，严谨版本必须是「在协议 P 下，移除 M 相比保留 M，指标 Y 的差异 Δ 的置信下界 > 0，且经多重校正」。这句话在数学上就是 RL 的**反事实信用分配**：用同一份日志估计「有 M / 无 M」两个策略的价值差。于是「写论文」和「训练策略」共享同一个估计器——离策略评估（OPE）。把每个模块的 Shapley 值算出来，谁在裸泳一目了然。这直接治疗 R66–R70 的「层膨胀」：每轮都声称「严格包含上一轮」，却从没做过 leave-one-out 的因果检验。**创新点不是新增代码行数，而是一个能被打假的因果效应。**

**灵感 3（创新点的第二种读法：情境的新颖度）**
直觉：「创新点」也可读作 novelty——这个情境我训练时见过吗？R70 的 H[b_t] 度量「我看不清」，却不度量「这根本是另一类题」。模型失配在世界里表现为**支撑外样本**：密度比偏高、重要度权重爆炸、OPE 方差失控。因此新颖性检测不是又一层保守，而是**让 OPE 的统计假设（支撑覆盖）在运行时可见的仪表**。走出支撑域时，SIG 必须拒绝，而不是拿外推的 Q 值自欺。

**灵感 4（安全 RL 的核心不是奖励，而是「能证明的改进」）**
直觉：安全 RL 常被误解为「加个惩罚项」。真正难的是：在**不牺牲安全**的前提下证明新策略比旧策略好。这要求三件事同时成立：(i) 改进估计有置信区间（OPE-CI）；(ii) 成本约束有高概率上界（shield + 成本 critic）；(iii) 数据覆盖支持这个估计（novelty gate）。缺一件，「改进」就只是噪声。SIG 把三者合成一个布尔门：**过门才部署，不过门就冻结**。冻结不是失败，冻结是可认证的安全下界。

**灵感 5（快慢双环：学习不能进实时环）**
直觉：RL 训练慢、随机、可能灾难性遗忘；机器人控制快、确定、不能抖。R68「实时流零学习写操作」必须保持。于是拆成慢环（离线/夜间：OPE、CGA、SIG、训练）与快环（实时：R70 推断 + novelty 查表 + 只读策略）。慢环说「这个新策略可以上」，快环原子换装、可回滚。**学习发生在慢环，责任发生在快环。**

## 1. 形式化定义（增量：定义 326–345）

**定义 326（NOVA-RAS 总览）** NOVA-RAS = (BRL, NAX, OPE-CI, CGA, SIG, NPG, CL, VQA-III, AIC-NOVA, J_NOVA)，继承 BELIEF-RAS† 全部组件。三不变式：
(i) **实时流零学习写操作**：快环只做推断与只读查表，任何参数更新/策略换装只在慢环发生（继承 R68 定义 276-i）；
(ii) **认证改进才部署**：任何策略或模块变更必须通过 SIG（定义 333），否则保持当前策略（冻结）；
(iii) **可证伪归因**：任何对外宣称的「创新点/贡献」必须对应一个预注册的 leave-one-out 因果检验与带置信区间的效应量（定义 335）；未通过者记为 inconclusive/refuted，不得写进证书。

**定义 327（信念空间约束 MDP）** 以 BSE 后验 b_t 为状态（或 φ(b_t) 为特征，定义 328），动作 x_t=(a_t,g_t)，回报 r_t，成本 c_t≥0（安全/社交）。目标 π* = argmax_π J_r(π)=E_π[Σγ^t r_t]，s.t. J_c(π)=E_π[Σγ^t c_t] ≤ d 且动作恒过 C-RAS-WM shield。称 (J_r, J_c) 为双目标。R70 的 π_BELIEF 是本问题的一个可行但从未被优化的策略。

**定义 328（信念特征与近似充分性）** φ(b_t) = [后验均值, top-k 语义假设概率, H[b_t], U_ale, novelty ν, 上一步动作/回答]。A102：φ 是 b 的 ε_φ-充分统计量（其 Bellman 残差 ≤ ε_φ）。

**定义 329（BRL 学习器）** Actor π_θ(x|φ)，双 critic Q_r^ψ、Q_c^ψ。离线用保守 Q（CQL/pessimistic）训练，在线用带安全投影的 PPO/Lagrangian 微调：L_BRL = L_actor(Adv_r − λ_c·Adv_c) + L_critic + β·L_conservative，对偶变量 λ_c 自适应。策略头可复用 R69 的流头以保持多模态；训练绝不进入快环。

**定义 330（新颖性分数）** ν(x)=p_deploy(x)/p_train(x)，用判别器或密度比估计；τ_α 取训练集 ν 的 (1−α) 分位（conformal）。支撑域 𝒮_α={x: ν(x)≤τ_α}。区分协变量新颖（观测没见过）与后果新颖（回报/成本没见过）。**ν 的首要用途不是保守，而是检验 OPE 的支撑覆盖假设是否成立。**

**定义 331（NAX 安全探索）** 内在奖励 r_int = β·IG(b_t; x_t) − η·max(0, ν(x_t)−τ_α)，其中 IG = H[b_t] − γE[H[b_{t+1}]]。探索动作仅在「存在经认证的恢复策略 ρ_rec 能在 H 步内回到安全集」时允许；否则只允许安全信息动作 g。学到的因此是「有后路的探索」。

**定义 332（OPE-CI）** 用行为策略 π_b 的日志 D，对 Δ_r=J_r(π_new)−J_r(π_old) 与 Δ_c 做双重稳健（DR）/边际重要度估计，配合 conformal 或 bootstrap 给出 [L_r,U_r]、[L_c,U_c]（名义覆盖 1−α）。有效性条件 A103：支撑覆盖（concentrability ≤ C_0）、平稳性、无未观测混杂（或敏感性界 Γ）。

**定义 333（SIG 安全改进门）** SIG(π_new)=1 ⇔ L_r ≥ δ_min ∧ U_c ≤ d ∧ supp(π_new) ⊆ 𝒮_α ∧ shield_sound ∧ OPE_coverage_passed。δ_min 是最小实际显著效应，用来挡「统计显著但工程无意义」的更新。SIG=0 ⇒ 不部署、冻结、把负结果记入账本。

**定义 334（CGA 反事实归因）** 模块集 M={cal, belief, inter, safe, learn}，对任意子集 S 定义策略 π_S。Shapley φ_i = Σ_{S⊆M\{i}} [|S|!(|M|−|S|−1)!/|M|!]·(J(π_{S∪{i}})−J(π_S))；每个 J 用 OPE-CI 估计，得 φ_i 的区间。|M|≤6 ⇒ 至多 2^6=64 次 OPE，慢环可行。

**定义 335（贡献账本 CL）** 每条 = (claim_id, 假设, baseline, treatment, 指标, 效应量, CI, 检验, p, 多重校正, 种子, 数据快照哈希, 代码哈希, 状态 ∈ {supported, refuted, inconclusive})。预注册先于实验，状态由与 SIG 同源的统计判定。**这是「论文创新点」的机器可读形式。**

**定义 336（NPG 新颖性门控策略调速）** 快环：若 ν(x)>τ_α 或 SIG 证书过期 ⇒ λ←max(λ,λ_freeze)、k←min(k,k_freeze)、禁用 BRL 的激进动作、只保留 R70 兜底；慢环：NPG 限定 BRL 可探索的状态集合（受限支撑 ∪ 有恢复保证的邻域）。

**定义 337（非平稳再认证）** 漂移检测器（继承 R68 FMA 并加分布检验）报漂移 ⇒ 立即作废 SIG 与 OPE 证书、回到 R70 保守；只有在新数据快照上重估的证书才有效，跨快照不复用。

**定义 338（奖励/成本建模与防 hack）** r 来自任务目标加人类偏好模型；c 来自 shield 与安全裕度。用 held-out 探针和反事实扰动检测 reward hacking；成本 critic 单独校准，绝不与 r 共享最后一层。

**定义 339（慢环训练与原子换装）** 慢环产出 (π_new, J_NOVA)；快环原子替换策略指针并保留旧指针用于回滚（继承 R68 定理 15 无突变），换装窗口内保持输出连续。

**定义 340（支撑覆盖假设 A103）** 对 π_new 的可达 (b,x)，π_b(x|b) ≥ c_0>0 且重要性权重二阶矩有界；否则 OPE-CI 无效。NPG 把「A103 是否成立」变成可在线检查的 novelty 报表。

**定义 341（VQAuditor-III）** 审计：预注册合规、SIG 统计有效性、OPE 覆盖、Shapley 稳定性、账本无选择性报告、探索-安全两难是否被掩盖。结论回灌慢环，成为下一轮 δ_min 与采样预算的先验。

**定义 342（AIC-NOVA）** ℰ_NOVA = ℰ_BELIEF × ℰ_RL，ℰ_RL={非平稳漂移, reward hacking, 支撑违反/重要性权重爆炸, 日志投毒, 仿真-现实差距, SIG 假阳性}。

**定义 343（证书 J_NOVA）** J_NOVA=(J_BELIEF, policy_version, data_snapshot_hash, ope_ci, sig_evidence, novelty_calibration, shapley_table, ledger_hash, ncg_pass)。Valid ⇔ Valid(J_BELIEF) ∧ (SIG ∨ 冻结态)。

**定义 344（新颖性/OPE 校准门 NCG）** 用历史「SIG 通过但事后变差」的样本校准 OPE 覆盖与 ν 阈值；经验覆盖 < 名义覆盖 − ε ⇒ 禁用 SIG（强制冻结），直到重新校准。这是对「用不可信统计做改进」的硬闸。

**定义 345（快慢双环主流程）** 见算法骨架。慢环以夜为单位产出证书；快环每次决策只读。二者以哈希与数据快照解耦。

## 2. 关键算法骨架

```python
# IP-275 BRL：信念空间约束策略（双 critic，离线保守 + 在线安全投影）
class BeliefConstrainedRL:
    def __init__(self, trunk, actor, q_r, q_c, bse, gamma=0.99):
        self.trunk, self.actor = trunk, actor
        self.q_r, self.q_c, self.bse, self.gamma = q_r, q_c, bse, gamma

    def act(self, b_t, deterministic=False):
        phi = belief_features(b_t)                 # 定义 328
        a, g = self.actor(phi, deterministic)      # 任务动作 + 信息动作
        return a, g, phi

    def update_offline(self, D):                   # 慢环；CQL 保守
        for phi, x, r, c, phi_n, done in D:
            self.q_r.update(phi, x, r, phi_n, done)   # + CQL penalty
            self.q_c.update(phi, x, c, phi_n, done)   # 独立成本 critic
        self.actor.update(Adv_r - self.lam_c * Adv_c)

# IP-276 NAX：信息增益内在奖励 + 有后路的探索
def intrinsic_reward(b_t, b_next, x, novelty, beta, eta, gamma):
    ig = entropy(b_t) - gamma * entropy(b_next)
    return beta * ig - eta * max(0.0, novelty - TAU_NOV)

def explore_allowed(x, recovery, H):
    return recovery.exists_within(x, H) or is_safe_info_action(x)

# IP-277 OPE-CI：双重稳健 + 保形/自助置信区间
def ope_ci(D, pi_new, pi_old, alpha=0.05):
    dr_r = doubly_robust(D, pi_new, pi_old, what='reward')
    dr_c = doubly_robust(D, pi_new, pi_old, what='cost')
    Lr, Ur = conformal_bootstrap_ci(dr_r, alpha)
    Lc, Uc = conformal_bootstrap_ci(dr_c, alpha)
    return (Lr, Ur), (Lc, Uc)

# IP-279 SIG：安全改进门（认证不过则冻结）
def safe_improvement_gate(D, pi_new, pi_old, shield):
    if not support_covered(D, pi_new):      return False   # A103
    (Lr, Ur), (Lc, Uc) = ope_ci(D, pi_new, pi_old)
    return (Lr > DELTA_MIN) and (Uc <= D_COST) and shield.sound()

# IP-278 CGA：模块反事实归因（小 M 用精确 Shapley）
def shapley_contributions(modules, D, alpha=0.05):
    M = len(modules); phi = {}
    for i in modules:
        total = 0.0
        for S in subsets(modules - {i}):
            w = fact(len(S)) * fact(M - len(S) - 1) / fact(M)
            L, U = ope_ci(D, policy_with(S | {i}), policy_with(S), alpha)
            total += w * midpoint(L, U)
        phi[i] = total
    return phi                                    # 每项附 CI，见账本

# IP-287 NOVA 慢环（夜间；不碰实时路径）
def NOVA_slow_loop(M):
    D = M.replay.snapshot()                       # 带快照哈希
    M.brl.update_offline(D)                       # 1) 学习
    pi_new = M.brl.policy()
    if not M.npg.supported(pi_new, D):            # 2) 新颖性/支撑
        return M.freeze(reason='support')
    (Lr, Ur), (Lc, Uc) = M.ope.estimate(D, pi_new, M.current)
    if not M.sig.certify(Lr, Uc):                 # 3) 认证改进
        return M.freeze(reason='sig')
    phi = M.cga.shapley(M.modules, D)             # 4) 归因
    M.cl.record(phi, (Lr, Ur), (Lc, Uc), hashes=M.hashes(D))
    cert = J_NOVA(M.belief_cert, pi_new, D, (Lr, Ur), (Lc, Uc), phi)
    return M.deploy_atomic(pi_new, cert)          # 5) 原子换装 + 回滚点

# 快环：R70 推断不变，只多一次只读 novelty 查表
def NOVA_fast_loop(M, obs):
    k, lam, mode, U = M.belief_round(obs)         # R70 原样
    nu = M.novelty.score(obs)                     # <0.1ms
    if nu > M.tau_alpha or not M.cert_valid():
        lam = max(lam, 0.9); k = min(k, M.k_freeze)   # 出支撑即保守
    return k, lam, mode, U, nu
```

## 3. 推导

**引理 23（信息增益探索 = 多步 VoI，MINT† 是贪心特例）** 在 A102/A103 下，NAX 的单步内在奖励等于 R69 定义 298 的 VoI；MINT† 的 argmax_g[VoI−c] 是 BRL 在「只优化下一步信息、策略类受限」时的贪心解。故 BRL 严格泛化 MINT†，且多步回报能越过贪心的近视。系：交互动作从「规则」变成「可学习、可评估」的对象。

**引理 24（OPE-CI 的覆盖与保守改进）** 若 A103 成立、重要性权重二阶矩有界、DR 估计无偏或渐进正态，则 Δ̂ 的 conformal/自助 CI 以 ≥1−α 覆盖真值；取悲观下界 L_r 决策使接受更新的假阳性率 ≤ α。系：SIG 的「证据纪律」不是口号，而是把第一类错误控制在 α。

**引理 25（探索-安全支撑两难）** 设 novelty gate 允许的数据支撑为 𝒮_α，BRL 只能在 𝒮_α 内认证改进。存在 δ_support>0，只要真实最优策略 π* 在 𝒮_α 外的动作概率质量超过 δ_support，可认证改进上界就 ≤ O(C_0·δ_support)（由重要度方差与覆盖度决定）。即：**保护安全的门同时限制了可被证明的进步。** 系：这是 NOVA 的根本张力，不是实现缺陷；绕开它只能先扩大可认证支撑（更安全的探索或更好的先验），不能靠放宽 SIG。

**定理 20（SIG 下的单调安全改进）** 若 (i) A103 成立且 OPE-CI 覆盖有效，(ii) shield 对成本约束 sound（R66–R70 已证），(iii) 每次部署都经 SIG，则任意时刻 t 的真实 J_r(π_t) 以 ≥1−α 概率单调不降，且 J_c(π_t) ≤ d 恒成立。R70 的 π_BELIEF 是「SIG 永不通过」的冻结边界。⇒ 安全侧不让步，效率侧只在有证据时进步。

**定理 21（贡献归因的可证伪性与层膨胀抑制）** 在 A104（模块效应可识别、OPE 误差 ≤ ε、Shapley 采样误差 ≤ ε_s）下，每个 φ_i 的区间宽度 ≤ O(2^{|M|}·(ε+ε_s))；若某模块 φ_i 的置信上界 ≤ 0，则移除它后 J_r 的下降以 ≥1−α 概率 ≤ ε_rem。⇒ 得到「证书化的最小栈」：任何新层必须以 δ_min 的优势击败最强基线，否则应被删除。这直接回应「论文创新点」——创新点是可被证伪的正向因果效应，不是新增代码行数。

**定理 22（NOVA 严格包含 BELIEF 严格包含 R68）** 在 A102–A104 与 R69/R70 假设下，NOVA 的期望风险 ≤ BELIEF ≤ R68；且在「SIG 永不通过 / ν>τ_α / NCG 不过」时，NOVA 逐指令等于 BELIEF（BRL 只读、不换装）。⇒ 逐层退化，安全侧层层不让步。

**推论 6（反脆弱的最小系统）** 反复应用「认证归因 → 剪枝 → 重认证」，系统收敛到一个 Pareto 最小模块集：不再随轮次单调膨胀，而是随证据增减。研究循环从「加层竞赛」转为「留强去弱的进化」。

## 6. 本轮最大风险

**一句话**：NOVA-RAS 把「能进步多少」完全押在「离线数据对反事实策略的支撑覆盖」上，而保护安全的 novelty gate 恰恰限制了产生这种覆盖的探索——**一旦世界漂移出支撑域，SIG 要么永远拒绝更新（安全但冻结），要么在失效的 OPE 假设下认证一次假改进（进步但危险）**；这条「探索-安全两难」是本方案的结构性风险，不是靠调参能消除的。

**次级风险与缓解**：
1. **OPE 支撑假设被违反**（重要性权重爆炸）→ A103 在线检查 + NCG 覆盖校准 + 越界即冻结；
2. **Shapley 归因被模块交互混淆** → 固定模块顺序/预注册 + 区间报告 + 不单独采信点估计；
3. **奖励模型被 hack** → 独立成本 critic + held-out 探针 + 人类抽检；
4. **RL 灾难性遗忘** → 离线保守 Q + 在线安全投影 + 原子换装可回滚；
5. **慢环结论过期** → 证书绑定数据快照哈希 + 漂移即作废 + 过期冻结。

```python
# IP-275 BRL：信念空间约束策略
class BRL:
    def __init__(self, trunk, actor, q_r, q_c, bse, gamma=0.99):
        self.trunk, self.actor, self.q_r, self.q_c = trunk, actor, q_r, q_c
        self.bse, self.gamma, self.lam_c = bse, gamma, 0.0

    def act(self, b_t, deterministic=False):
        phi = belief_features(b_t)
        a, g = self.actor(phi, deterministic)
        return a, g, phi

    def update_offline(self, D):
        for phi, x, r, c, phi_n, done in D:
            self.q_r.update(phi, x, r, phi_n, done)   # + CQL 保守项
            self.q_c.update(phi, x, c, phi_n, done)   # 独立成本 critic
        self.actor.update(Adv_r - self.lam_c * Adv_c)
        self.lam_c = project_lambda(self.lam_c, J_c_est(D) - D_COST)

# IP-276 NAX：有后路的信息增益探索
def intrinsic_reward(b_t, b_next, x, novelty, beta, eta, gamma):
    ig = entropy(b_t) - gamma * entropy(b_next)
    return beta * ig - eta * max(0.0, novelty - TAU_NOV)

def explore_allowed(x, recovery, H):
    return recovery.exists_within(x, H) or is_safe_info_action(x)

# IP-277 OPE-CI：双重稳健 + 置信区间
def ope_ci(D, pi_new, pi_old, alpha=0.05):
    dr_r = doubly_robust(D, pi_new, pi_old, what='reward')
    dr_c = doubly_robust(D, pi_new, pi_old, what='cost')
    return (conformal_bootstrap_ci(dr_r, alpha),
            conformal_bootstrap_ci(dr_c, alpha))

# IP-278 CGA：模块反事实归因
def shapley_contributions(modules, D, alpha=0.05):
    M = len(modules); phi = {}
    for i in modules:
        total = 0.0
        for S in subsets(modules - {i}):
            w = fact(len(S)) * fact(M - len(S) - 1) / fact(M)
            (Lr, _), _ = ope_ci(D, policy_with(S | {i}), policy_with(S), alpha)
            total += w * Lr                       # 悲观：用下界
        phi[i] = total                            # 附完整 CI
    return phi

# IP-279 SIG
def safe_improvement_gate(D, pi_new, pi_old, shield):
    if not support_covered(D, pi_new):  return False     # A103
    (Lr, Ur), (Lc, Uc) = ope_ci(D, pi_new, pi_old)
    return (Lr > DELTA_MIN) and (Uc <= D_COST) and shield.sound()

    M.brl.update_offline(D)
    pi_new = M.brl.policy()
    if not M.npg.supported(pi_new, D):
        return M.freeze(reason='support')
    (Lr, Ur), (Lc, Uc) = M.ope.estimate(D, pi_new, M.current)
    if not M.sig.certify(Lr, Uc):
        return M.freeze(reason='sig')
    phi = M.cga.shapley(M.modules, D)
    M.cl.record(phi, (Lr, Ur), (Lc, Uc), hashes=M.hashes(D))
    cert = J_NOVA(M.belief_cert, pi_new, D, (Lr, Ur), (Lc, Uc), phi)
    M.vqa_iii.submit_async(cert, M.cl.last())
    return M.deploy_atomic(pi_new, cert)

# 快环：R70 推断不变，多一次只读 novelty 门控
def NOVA_fast_loop(M, obs):
    k, lam, mode, U = M.belief_round(obs)         # R70 原样
    nu = M.novelty.score(obs)
    if nu > M.tau_alpha or not M.cert_valid():
        lam = max(lam, 0.9); k = min(k, M.k_freeze)
    return k, lam, mode, U, nu
```

## 4. 推导

**引理 23（信息增益探索 = 多步 VoI）** A102/A103 下，NAX 单步内奖励等于 R69 定义 298 的 VoI；MINT† 是「只看下一步信息、策略类受限」的贪心特例。BRL 严格泛化 MINT†，多步回报越过贪心近视。系：交互从手写规则变成可学习、可评估对象。

**引理 24（OPE-CI 覆盖与保守改进）** A103 + 权重二阶矩有界 + DR 无偏/渐近正态 ⇒ CI 以 ≥1−α 覆盖真值；悲观下界决策使假阳性 ≤ α。系：SIG 把第一类错误控制在 α。

**引理 25（探索-安全支撑两难）** novelty gate 支撑 𝒮_α 限制了可认证改进；若 π* 在 𝒮_α 外动作质量 > δ_support，则可认证改进上界 ≤ O(C_0·δ_support)。系：这是结构性张力；只能先扩大可认证支撑，不能靠放宽 SIG。

**定理 20（SIG 单调安全改进）** A103 + OPE-CI 覆盖 + shield sound + 每次部署经 SIG ⇒ J_r(π_t) 以 ≥1−α 概率单调不降，J_c(π_t)≤d 恒成立；R70 为「SIG 永不通过」的冻结边界。

**定理 21（归因可证伪与层膨胀抑制）** A104（模块效应可识别、OPE 误差≤ε、Shapley 误差≤ε_s）下，φ_i 区间宽度 ≤ O(2^{|M|}(ε+ε_s))；若 φ_i 上界 ≤0，移除该模块后 J_r 下降以 ≥1−α 概率 ≤ ε_rem。⇒ 证书化最小栈：新层须以 δ_min 击败最强基线，否则删除。创新点 = 可被证伪的正向因果效应。

**定理 22（NOVA 严格包含 BELIEF 严格包含 R68）** A102–A104 下期望风险 NOVA ≤ BELIEF ≤ R68；当 SIG 永不通过 / ν>τ_α / NCG 不过时，NOVA 逐指令等于 BELIEF。⇒ 逐层退化，安全侧不让步。

**推论 6（反脆弱最小系统）** 反复「认证归因→剪枝→重认证」收敛到 Pareto 最小模块集；研究循环从「加层」变为「留强去弱」。

## 7. 本轮最大风险

**一句话**：NOVA-RAS 把「能进步多少」完全押在「离线数据对反事实策略的支撑覆盖」上，而保护安全的 novelty gate 恰恰限制了产生这种覆盖的探索——**世界一旦漂移出支撑域，SIG 要么永远拒绝更新（安全但冻结），要么在失效的 OPE 假设下认证一次假改进（进步但危险）**；这是结构性两难，不是调参能消除的。

**次级风险与缓解**：
1. **OPE 支撑假设被违反** → A103 在线检查 + NCG 覆盖校准 + 越界即冻结（定义 340/344）；
2. **Shapley 被模块交互混淆** → 预注册 + 区间报告 + 不采信点估计（定义 334/335）；
3. **奖励模型被 hack** → 独立成本 critic + 探针 + 人类抽检（定义 338）；
4. **灾难性遗忘** → 离线保守 Q + 在线安全投影 + 可回滚原子换装（定义 329/339）；
5. **慢环结论过期** → 证书绑定快照哈希 + 漂移作废 + 过期冻结（定义 337/343）。
