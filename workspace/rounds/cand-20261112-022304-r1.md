# 第 59 轮（承接第 58 轮「KG-SFT-UX」IP-139~144；灵感循环第 1 轮；本轮灵感：「语义分割」×「语义建图」）

> 第 58 轮把安全论证的支柱换成"结构化记忆"——知识图谱同时驱动检索/OOD/校准/微调/证据合成/心智预测，却也因此把风险集中成"KG 共模失效"：一张图错了，六条机制一起错。它留下的三个未解问题正是本轮入口：**(a)** KG 是稀疏的离散知识，而真实世界的"表面是什么"是稠密的——稀疏边无法覆盖每平方米，边与边之间的大片区域实际上仍是"未知"，却可能被规划器当成"已知"；**(b)** 第 58 轮的证据主要回答"这块区域安不安全"，却很少回答"这块区域是什么、为什么安全"——语义（材质/可通行性/欺骗模式）只是零散边，未成为一等公民，因此"未知区域"没有显式的、可传播的表示；**(c)** 人机之间没有一个被显式对齐的语义层——操作者说"这里滑"，机器人理解的是另一组物理谓词，双方的"安全"可能根本不同义，而第 58 轮的 μ_mis 只估"懂没懂"，不估"懂的是不是同一件事"。本轮两个灵感各补一条腿：**语义分割**把稠密世界压成有限、可证伪的标签假设，让"探哪里、探什么"从几何不确定升级为语义不确定；**语义建图**把逐帧标签沿时间融合成带溯源、带三态（假设/接地/证伪）的持久语义图，把"地图写满标签"与"证据支持标签"强制分离。核心命题由"结构化记忆守护下的自适应"升级为 **"语义知其伪、溯其源、对齐其义"的证据承诺**——分割不是信念来源而是问题生成器，建图不是自信累积而是接地状态的传播，语义只有被物理探针接地后才可进入证据门，且只限非不可逆层级。

核心矛盾：
- **H29（稠密语义 vs 稀疏接地）**：分割给出"每处都有标签"的稠密假设，探针只能稀疏接地；若把"地图上有标签"误当"证据"，就产生**假覆盖**——规划器以为已知，实际从未验证；而若要求每处都接地，探测成本又会爆炸，"已接地"退化为一层薄漆。
- **H30（语义共谋 / 伪独立）**：同一相机、同一模型、同一光照下多视角看到同一错误标签，看起来是"多观测一致"，实则是同一个错误被问了很多遍；语义图、KG、人若共享同一错误先验，三向交叉校验就不是独立验证，而是**同一错误的自证**。
- **H31（闭集标签 vs 开放世界）**：闭集分割会把新材质强行塞进旧类或"未知"，而标签税则的漂移是系统性的——"未知"若被 argmax 静默吸收成最近已知类，错误会沿整张图传播，且比单帧更难回溯。

## 0. 直觉与动机

**灵感 1（语义分割 → 假设生成器与接地路由器）**
直觉：分割是一次**有损压缩**：把连续的、无限可能的物理世界压成有限标签集。有损压缩本身没错，错的是不给误差条。于是本轮把分割输出重新定位为**可证伪假设**——"这块像冰"是一条物理断言（应低摩擦、低形变），因此可以被一条便宜的探针证伪或证实。机器人不再问"分割置信多少"，而问"哪条假设最值得用最小实验去接地"。语义熵 × 时间翻转率 × 下坡风险 决定探针优先级：**在会疼的地方，先问最不确定的问题**。这一转念把语义从"已经知道"变成"待验证的清单"，直接对抗假覆盖。

**灵感 2（语义建图 → 三态接地图与时间/陈旧性）**
直觉：建图不是"多帧投票让标签更绿"，而是维护每个标签的**接地状态**：`H`（仅假设，从未被物理验证）、`G`（已由判别性探针接地）、`F`（已被证伪）。只有 `G` 能进证据门且必须新鲜；`F` 是吸收态，并触发 KG 边回溯删除与下游规划重算；`G` 会因环境变化/超时**退认证**回 `H`。最关键的一条：`G` **不按相似边免费继承**——接地一小块只会让邻域得到 `H` 的类比提示，绝不整片变绿。语义图的产物因此是一张"问号地图"，而不是"答案地图"。

**灵感 3（稠密-稀疏-几何三向一致性 DSG → 筛选而非认证）**
直觉：一条语义标签会**蕴含物理后果**（冰 ⇒ 低摩擦、低形变；深水 ⇒ 支撑力异常）。把这些后果与分割后验、KG 蕴含、几何导出的坡度/粗糙度/自由空间做三向对账：矛盾是最强警报（一条即可降级），一致却很弱——因为三源可能同源于视觉，根本不独立。所以 DSG 只做**筛选**（已经被第 57 轮的跨模态对账教育过：一致要看独立性），认证权永远留给物理探针。

**灵感 4（开集分割 + 共形弃权 → 未知必须显式）**
直觉：闭集分类器面对新材质没有"我不知道"这个出口，只有"塞进最近类"。共形预测给每个区域一个**标签集** `C_α(c)` 并保证真值以 ≥1−α 概率在集合里；当集合太大或"未知"分数过高时，系统必须**弃权**：该区域保持 `H`、禁止 `EV-sem`、规划按未知处理（减速/绕行/探询）。标签漂移用类条件覆盖率监测——某一类突然掉覆盖，就全局再校准并降级该类，而不是继续用旧税则硬套。

**灵感 5（人机共享语义台账 SSL → 先对齐义，再谈信）**
直觉：操作者的"安全"和机器人的"安全"可能是两个谓词。本轮给每个解释/协商用词 `t` 挂一个机器人谓词 `π_t` 和一个**物理后果集** `Φ_t`，并维护一个对齐分 `a_t`——它只由**结果验证过的确认**更新（不是"我懂了"，是"事后证明你真的懂"）。若术语未被 grounded-shared，操作者的标注修正先入隔离区并触发**语义澄清对话**（摆出 Φ_t 对照与反例），澄清前不得进入不可逆必要证据。这把第 57 轮的个性化信任与第 58 轮的心智模型推进到"义"的层面：信任可以购买速度，但必须先证明我们说的是同一件事。

**灵感 6（PCX+++ → 语义证据门只放行 L1）**
直觉：语义证据 `EV-sem` 是本轮新增的第六/第七类证据，但它有一个不可谈判的硬禁令：**只能支持 L1 非不可逆决策，且永不可作为不可逆接触的必要或唯一证据**。理由很简单——语义是稠密但可被共谋的，物理探针是稀疏但独立的；不可逆赌注只认后者。语义的全部正向作用必须经由"探询更准（探哪里）"或"动作更保守（未知就减速/绕行）"两条安全通道。

## 1. 形式化定义（增量：定义 145–150）

**定义 145（语义接地状态格 SGL）** 稠密语义图 𝓢=(𝒞,L,{ℓ̂(c),p_c,stat(c),prov(c),τ_c})：𝒞 为区域/单元格，L⊇{unknown} 为开放标签集，p_c∈Δ(L)，stat∈{H,G,F}，prov 为溯源（帧/探针/操作者 id 与版本），τ_c 为最近更新时刻。迁移：①初始 stat=H；②`H→G` 仅当存在**接地证书** `g_cert(c,ℓ)=(π, LR(π;ℓ)≥θ_disc, Cons(c)=1, calib_ok, t)`（判别性物理探针 + DSG 通过 + 校准有效）且接地仅作用于**被探区域**，邻域经 `similar_to` 类比只得 H 不得 G；③任意 stat→F（探针证伪或 DSG 矛盾被物理证实），F 吸收且触发 KG 边回溯删除与下游重算；④陈旧：τ_c 超过 T_stale 或环境变化检测触发 ⇒ `G→H`（去认证）。仅 `stat=G ∧ 新鲜 ∧ |C_α(c)|=1` 可产生 EV-sem。

**定义 146（语义假设接地路由器 SGR）** 语义不确定度 `H_sem(c)=H(p_c)`、时间翻转率 `Inst(c)`（窗口内标签翻转频率）、风险 `Risk(c)`、探针代价 `Cost(π)`。优先级 `π_g(c)=w1·H_sem+w2·Inst+w3·Risk−w4·Cost`。选探针 `π*=argmax_π E[IG(ℓ | π)]`，约束 `contact_level(π) ≤ allowed(c)`：高价值/不可逆区域只允许 L1 接地，L2 必须先绕行或进入协商。**硬约束（假覆盖=0）**：未接地（stat=H）标签禁止进入任何安全论证；规划器必须以"未知"而非标签最大值处理 H 区域。接地率 `η_ground=|G|/|probed|`。

**定义 147（稠密-稀疏-几何三向一致性 DSG）** 对 c 定义三源：dense `d(c)`（分割后验）；sparse `s(c)`（KG 由 ℓ 蕴含的物理后果集 `Φ_ℓ`，如 Material=ice ⇒ μ∈[μ_lo,μ_hi] 且形变低）；geometric `g(c)`（深度/坡度/粗糙度/自由空间导出的物理约束）。`Cons(c)=1[TV(p_c,π_s)≤θ1] ∧ [g(c)∈Φ_ℓ±margin] ∧ ¬Contradiction(c)`；矛盾 := `d(c)` 蕴含的物理性质与 `g(c)`/`s(c)` 实测越界。**DSG 是筛选非认证**：三源可能同源（皆出视觉）不独立，故 Cons=1 不充分推出 G；只有 Cons=0 充分推出非 G（降级并告警）。

**定义 148（开集语义分割与共形弃权 OSSA）** 每区域输出共形标签集 `C_α(c)`，保证类条件覆盖 `P(ℓ_true∈C_α | ℓ_true=k)≥1−α, ∀k`（union bound）。若 `|C_α(c)|>K` 或 `unknown_score(c)>θ_u` ⇒ **弃权**：stat 保持 H、禁 EV-sem、规划按未知处理。标签漂移监测：类条件经验覆盖率 `c_k(t)<1−α−δ_drift` ⇒ 全局再校准并降级受影响类；禁止用 argmax 覆盖弃权（未知不得静默并入最近已知类）。

**定义 149（人机共享语义台账 SSL）** 共享语义台账 `Λ={(t,π_t,Φ_t,a_t,H_t)}`：解释/协商用词 t、机器人谓词 π_t、物理后果集 Φ_t、对齐分 a_t、对齐历史 H_t。术语 **grounded-shared** ⇔ `a_t≥θ_a ∧ Φ_t` 与当前语义图一致。`a_t` 仅由**结果验证过的确认**更新（事后实测证明该词所指后果正确），"我懂了"不更新。操作者标签修正：所用术语 grounded-shared 方可直接入证据；否则该修正入隔离区并触发**语义澄清对话**（呈现 Φ_t 对照与反例），澄清前不得进入不可逆必要证据集。μ_mis 增加语义分歧项；L2 协商必须用 grounded-shared 术语渲染。

**定义 150（语义证据门 SE-gate 与 PCX+++）** 新增 `EV-sem`：有效 ⇔ `stat=G ∧ 新鲜 ∧ |C_α|=1 ∧ Cons=1 ∧ (面向人时)术语 grounded-shared ∧ level≤L1 ∧ 非不可逆接触的唯一/必要证据`。**不可逆接触必要证据集沿用第 58 轮**（EV-probe*/EV-margin/EV-visit ∪ 佐证），语义永不进入。PCX+++ 每检查点：①稠密语义更新→②假设队列与接地路由（预算 k_ground）→③DSG 筛选→④开集弃权→⑤承诺门（EV-sem 仅 L1）→⑥陈旧传播与下游重算。证书 `J_p+++` 增加 semantic_map_version, grounding_cert, dsg_log, oss_abstain_log, shared_term_ledger。

## 2. 关键算法伪代码（完整版见产物区）

```python
def semantic_ground_and_commit(M, cp, budget_sem, meta):        # IP-145/146/147/150 合流
    # ① 稠密语义：输出标签集而非单标签，未知必须显式
    C_alpha = conformal_segment(M.obs[cp.region], alpha=alpha_conf)
    if abstain(C_alpha, K=K_set, theta_u=theta_u):               # IP-148
        return mark_unknown(cp, M)                               # 禁止 EV-sem，规划按未知
    M.S = update_semantic_map(M.S, cp.region, C_alpha, prov='vision', stat='H')

    # ② 只有 H 且高价值/高不确定才值得接地；G 绝不按相似边免费继承
    for c in hypothesis_queue(cp, M, budget_sem):               # IP-146
        pi = argmax_probe(c, M, allowed=contact_level(cp))       # L2 前须绕行/协商
        obs = execute_probe(pi, cap=F_abs)
        if not DSG_consistent(c, obs, M):                        # IP-147: 矛盾即降级
            M.S.stat[c] = 'F'; M.kgmm.falsify_retract(c, obs)
            continue
        if discriminates(obs, c, theta_disc):                    # 唯一认证官=探针
            M.S.stat[c] = 'G'; M.S.g_cert[c] = make_cert(pi, obs)

    # ③ 承诺门：语义只放行 L1，且不满足任何不可逆必要证据
    ev = tag_evidence_ppp(cp, M)
    return enforce_se_gate(ev, cp, M, meta)                       # IP-150

def semantic_stale_scan(M, env_change):                         # IP-145: 陈旧退认证
    for c in M.S.cells:
        if env_change(c) or age(c) > T_stale:
            if M.S.stat[c] == 'G':
                M.S.stat[c] = 'H'                               # 不是删知识，是去认证
    propagate_unknown_to_planner(M)                             # 假覆盖=0 硬约束
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| SGMM/SGL | O(1)/单元更新 | O(\|𝒞\|·(\|L\|+\|prov\|)) | 仅探针可 H→G、G 不免费继承、F 吸收 |
| SGR | O(\|hypotheses\|·C_IG) | O(\|queue\|) | 接地仅作用于被探区域、L2 前绕行/协商 |
| DSG | O(\|𝒞\|·\|Φ\|) | 复用语义图 | 矛盾充分降级、一致不充分认证 |
| OSSA | O(\|L\|)/区域 | O(\|L\|·\|𝒞\|) | 类条件覆盖 ≥1−α、未知不可被 argmax 吞并 |
| SSL | O(1)+O(\|Λ\|) | O(\|terms\|) | a_t 仅结果验证更新、未对齐先澄清 |
| PCX+++ | O(\|CP\|·(k_p+k_c+k_g+k_ft+k_ux)·C) | O(\|V\|+\|σ\|+\|𝒢\|+\|𝓢\|) | EV-sem 仅 L1、必要证据集不变、陈旧传播 |

**正确性定理（Semantic-Grounded Soundness, SGS 概要）**：在 A22–A45 上加 (A46) 接地权威：仅判别性物理探针（或经 proper level 的显式同意）可 H→G，多帧视觉一致与语义共谋不计为独立证据；(A47) 开集共形类条件覆盖 ≥1−α、弃权规则生效；(A48) DSG 矛盾在 ≤1 检查点内降级并回溯；(A49) 语义陈旧自动去认证，且规划器对 H 区域以未知处理（假覆盖=0）；(A50) 共享语义 a_t 仅由结果验证更新、未对齐术语不得承载不可逆修正。则：(i) **语义泄漏界**：任何不可逆承诺的失效率不含语义项（语义未进入其必要证据集）；L1 承诺额外风险 ≤ P(接地错误)+α_conf+δ_drift；(ii) **假覆盖=0**：不存在被规划器当作已知但 stat=H 的区域；(iii) **语义共谋不成立**：因 G 需外部物理探针、且视觉共识被显式排除出独立性计数，语义/KG/人的一致不能自证；(iv) PCX+++ 在 k_p+k_c+k_g 内终止于 {承诺, 绕行, L2 协商, 安全停}。

### IP-145 SGMM（语义接地图记忆，升级 IP-139 KGMM）

```python
class SemanticGroundedMapMemory:
    def __init__(self, KGMM, T_stale=7*24*3600):
        self.S = SemanticMap()                 # 𝓢: 稠密语义图
        self.kg = KGMM                         # 复用第 58 轮稀疏 KG
        self.T_stale = T_stale

    def update_from_vision(self, c, C_alpha, p, prov):
        """分割只写 H，绝不直接写 G"""
        self.S.set(c, label_set=C_alpha, p=p, stat='H',
                   prov=(prov, self.S.version), tau=now())

    def ground(self, c, ell, probe, obs):
        """唯一认证官：判别性物理探针"""
        if self.S.stat[c] == 'F':
            return False                       # F 吸收，需新一轮证据才可重开
        if not discriminates(obs, ell, probe, theta_disc):
            return False
        if not DSG_consistent(c, obs, self):
            self.falsify(c, obs); return False
        g = GroundingCert(probe=probe, LR=likelihood_ratio(obs, ell),
                          Cons=True, calib=self.S.calib_ok, t=now())
        self.S.set(c, stat='G', g_cert=g)
        self.kg.add_grounded_edge(c, ell, g)   # 仅接地标签可写 KG（第 58 轮隔离）
        return True

    def inherit_by_analogy(self, c, sim_nodes):
        """相似边只给 H，绝不给 G：防‘接地一小块、整片变绿’"""
        for u in sim_nodes:
            if self.S.stat[u] == 'G':
                self.S.set(c, hint_label=self.S.label[u], stat='H',
                           prov=('analogy', u))

    def falsify(self, c, obs):
        self.S.set(c, stat='F')
        self.kg.falsify_retract(c, obs)        # 回溯删边（第 58 轮复用）
        propagate_to_planner(c, 'retract')

    def stale_scan(self, env_change):
        for c in self.S.cells:
            if self.S.stat[c] == 'G' and (env_change(c)
                                          or age(c) > self.T_stale):
                self.S.set(c, stat='H', prov=('stale', now()))
        propagate_unknown_to_planner(self)     # 假覆盖=0 硬约束
```

```python
def semantic_grounding_router(M, cp, budget_ground):
    """分割提出假设，探针负责接地；在会疼的地方先问最不确定的问题"""
    q = [c for c in cp.region.cells
         if M.S.stat[c] == 'H']                      # 只对未接地假设探询
    q.sort(key=lambda c: (w1*entropy(M.S.p[c])
                          + w2*instability(M.S, c)
                          + w3*risk(M, c)
                          - w4*probe_cost(c)), reverse=True)
    grounded = 0
    for c in q:
        if budget_ground.left <= 0: break
        allowed = contact_level(cp)                  # 高价值/不可逆仅 L1
        pi = max(admissible_probes(c, M, F_abs),
                 key=lambda p: (expected_info_gain(p, c, M)
                                if contact_level(p) <= allowed else -inf))
        if contact_level(pi) > 'L1' and contact_level(cp) == 'L2':
            continue                                 # L2 先绕行/协商，不硬接地
        obs = execute_probe(pi, cap=F_abs)
        budget_ground.spend()
        if M.SGMM.ground(c, top_label(M.S, c), pi, obs):
            grounded += 1
    enforce_false_coverage_zero(M, cp)               # 未接地标签禁入安全论证
    return grounded

def enforce_false_coverage_zero(M, cp):
    """规划器只能把 stat=G 的区域当作已知"""
    for c in cp.region.cells:
        if M.S.stat[c] != 'G':
            cp.mark_unknown(c)
    assert not any(cp.is_treated_known(c) and M.S.stat[c] != 'G'
                   for c in cp.region.cells)
```

```python
def DSG_consistent(c, obs, M):
    """返回一致；但注意：一致只是必要条件，不是认证"""
    p_dense = M.S.p[c]                              # 分割后验
    ell = argmax(p_dense)
    Phi = M.kg.physical_consequences(ell)           # 稀疏 KG 蕴含后果集
    g = geometric_properties(obs, M)                # 坡度/粗糙度/自由空间

    # 1) 稠密与稀疏蕴含是否相容
    pi_s = M.kg.to_label_distribution(Phi)
    if TV(p_dense, pi_s) > theta1:
        return False
    # 2) 几何实测是否落在语义蕴含的物理后果区间
    if not in_interval(g, Phi, margin):
        M.dsg_log.contradiction(c, 'geom_vs_consequence', ell, g, Phi)
        return False
    # 3) 显式矛盾检测（如“可通行”却几近垂直）
    if contradicts_traversability(g, p_dense):
        M.dsg_log.contradiction(c, 'traversability', ell)
        return False
    return True

def DSG_screen(c, obs, M):
    """矛盾=强警报（降级）；一致=弱信号（不得单独认证）"""
    if not DSG_consistent(c, obs, M):
        M.SGMM.falsify(c, obs)
        return 'demote'
    return 'screen_only'          # 认证仍必须走 SGMM.ground 的物理探针
```

```python
class OpenSetSegmentation:
    def __init__(self, alpha_conf=0.1, K_set=3, theta_u=0.5,
                 delta_drift=0.05):
        self.alpha = alpha_conf; self.K = K_set
        self.theta_u = theta_u; self.delta_drift = delta_drift
        self.class_cov = defaultdict(lambda: SlidingCoverage())

    def predict(self, c, logits):
        C_alpha = conformal_label_set(logits, self.alpha)   # 类条件覆盖
        u = unknown_score(logits)
        if len(C_alpha) > self.K or u > self.theta_u:
            return Abstain(C_alpha=C_alpha, unknown=u)      # 显式未知
        return C_alpha

    def monitor(self, actual_label):
        """类条件覆盖监测：漂移则全局再校准 + 降级受影响类"""
        for k, cov in self.class_cov.items():
            cov.record(actual_label == k)
            if cov.rate() < 1 - self.alpha - self.delta_drift:
                self.recalibrate()
                return DriftAlert(k, cov.rate())
        return None

    def recalibrate(self):
        self.quantiles = refit_conformal(self.heldout)
```

**正确性定理（Semantic-Grounded Soundness, SGS）**
假设 A22–A45（第 53–58 轮）成立；**(A46)** 接地权威：仅判别性物理探针（或经 proper level 的显式同意）可执行 `H→G`，多帧视觉一致与跨机制语义一致不计为独立证据；**(A47)** 开集共形类条件覆盖 ≥1−α，弃权规则在 `|C_α|>K ∨ u>θ_u` 时生效；**(A48)** DSG 矛盾在 ≤1 检查点内降级并回溯删边；**(A49)** 语义陈旧（超 T_stale 或 env_change）自动 `G→H`，规划器对 `stat≠G` 区域一律按未知处理；**(A50)** 共享语义 a_t 仅由结果验证事件更新，未 grounded-shared 的术语不得承载不可逆修正。则：

1. **语义泄漏界**：任何不可逆（L2）承诺的失效率不含 `EV-sem` 项——因为 EV-sem 被硬禁令排除出其必要证据集；L1 承诺由语义引入的额外风险 ≤ `P(接地错误) + α_conf + δ_drift + δ_stale`，其中 P(接地错误) 由 θ_disc 控制。
2. **假覆盖=0**：任意时刻不存在"规划器当作已知但 stat=H/F"的区域（由 `enforce_false_coverage_zero` 与 stale_scan 的 `propagate_unknown_to_planner` 保证）。
3. **语义共谋不成立**：G 需外部物理探针；视觉多帧一致被显式排除出独立性计数；KG/语义/人共享先验不构成认证路径，故"三方一致"不能自证。
4. **接地不扩散**：类比继承只产生 H，故 `|{c: stat=G}| ≤ |被探且判别成功的单元数|`，假覆盖无法沿 similar_to 边级联。
5. **终止性**：PCX+++ 在 `k_probes+k_cons+k_ground+k_ft+k_ux` 内终止于 {承诺(L1), 绕行, L2 协商, 安全停}；接地预算与探针预算均单调耗尽。
6. **部署界**（对检查点取联合界，语义项只出现在 L1）：

```
P_safe ≥ 1 − Σ_cp [ δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1]
                    + δ_ft·1[回滚窗口] + δ_kg·1[检索失败] + δ_ux·1[μ_mis>θ_mis]
                    + (δ_ground + α_conf + δ_drift + δ_stale)·1[L1 且用 EV-sem] ]
         − P(𝒢 结构性错误未检出) − P(𝓢 语义共谋未检出) − P(护盾回退失败)
         − P(τ_int 超时 ∧ 安全停失效)
```

关键：**语义图是"问号地图"不是"答案地图"**；**探针是唯一认证官**；**G 不沿相似边免费继承**；**陈旧自动去认证**；**人机术语先对齐后果再承载修正**；**EV-sem 只放行 L1**。四类正向作用全部经「探询更准（接地路由）」「不确定性更大（弃权→未知）」「动作更保守（未接地即减速/绕行）」三条安全单向通道。

## 6. 本轮最大风险

**一句话**：本轮让语义成为一等公民，但语义的最大危险不是"错"而是**共谋式的对**——稠密分割、语义图、KG、甚至操作者可能共享同一个错误先验，多视角与多机制的一致看起来像强证据，实则是同一个错误被反复询问；一旦为省探针而让 `G` 沿相似边继承、或让视觉共识充当独立验证，"已接地"就退化成一层薄漆，假覆盖以大范围、低告警的方式铺满地图——必须以「物理探针唯一认证官、G 不继承、未接地即未知、陈旧即去认证、语义永不入不可逆必要证据集」五条硬护栏，宁可地图上到处是问号，也绝不接受"图里写着所以已知"。
