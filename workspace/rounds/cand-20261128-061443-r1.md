### 第 1 轮灵感驱动研究记录（新循环起点，继承第 5 轮 CADVS-v5）

**灵感词**：Gazebo、最优控制

**继承关系**：第 5 轮 CADVS-v5（IP-493~496）把提议升级为条件流匹配、记忆升级为嵌入固化、人因升级为情感调制，并以定理 6「证书不变性」把框架推广为「任意生成器 + 认证边界」（CGE），执行集链为 Exec_CADVS-v5 ⊆ Exec_CADVS-v4 ⊆ … ⊆ Exec_v29。但 v5 有两个始终被当作「环境」而非「被认证对象」的隐含前提：(H1) **模型即真值假设**——七门在解析名义模型（刚体动力学、几何场景图、接触/摩擦模型）上求值，证书只断言「模型内安全」，而模型本身可能错；这正是 R57 自指回路的根：铸证与提议共享同一个可能失真的模型。(H2) **开环点估计 + 无最优性假设**——证书是规划时刻的点态谓词，选证只是「通过者中取边际最大」，既不能保证闭环反馈与扰动下**持续**不越界，也没有把「安全」与「最优」分离的语义。本轮两个灵感词恰好分别攻击这两个前提：**Gazebo** 提供一个与解析门**独立实现**的高保真数字孪生，实际执行候选轨迹作为外部佐证；**最优控制**把点态可行性升级为**受控不变性（viability/可达性）**、把「取最大边际」升级为**约束最优控制**。二者统一为主题「数字孪生验证的认证最优控制」（Digital-Twin-Verified Certified Optimal Control, DT-COC），形成 CADVS-v6（IP-497~500）。本轮自律：**硬门数量仍为七**——新增的不是门，而是证书的两个维度：**出处**（twin-corroborated）与**时域**（闭环不变 / 租约），以及一层与可行性正交的**最优性**层；执行集升级为 Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ … ⊆ Exec_v29。

**直觉与动机**：

1. **Gazebo → 数字孪生作为独立认证者，并用「场景规划」把仿真不确定性变成可证界**。直觉：如果证书由提议它的同一套模型算出，它就是自我背书（R57）。Gazebo 用另一份独立实现的物理引擎，在接触、摩擦、执行器饱和、延迟、噪声下**真的把候选轨迹跑一遍**——这是一次独立佐证。但仿真不是现实，它只是一个参数可随机化的模型。于是分两步严谨化：(a) **场景认证**：令物理参数 θ ~ P_θ（质量、摩擦、恢复系数、增益、延迟、噪声），对 N 个 i.i.d. 场景 {θ_j} 要求门全部通过；由 Campi–Garatti 场景理论，只要 N ≥ N_min(ε,β,d)，则以概率 ≥1−β 保证**在孪生参数分布下**的违反概率 ≤ ε——这是分布无关的有限样本界。(b) **现实差距**：孪生 ≠ 现实，必须在真实标定集上测出轨迹差距 g_real，并把门的 Lipschitz 常数乘上它作为**现实差距附加项** δ_i^gap = L_i·g_real，只紧不松地抬阈值。这样证书从「模型内为真」升级为「以显式 ε、β、g_real 为条件的孪生相对保证」，并把不可证的剩余部分诚实地标注出来。

2. **最优控制 → 从「点态可行」升级为「受控不变」，从「取最大边际」升级为「约束最优」**。直觉：一条轨迹在规划时刻通过七门，不等于在反馈与扰动下**永远**不越界——它可能下一步就漂进禁区。最优控制给出的正确对象是**可行性核（viability kernel）**：从其中任一点都存在控制策略使状态永远留在门内。严谨化：令门定义状态安全集 K = ∩_i{s : s_i(s) ≥ τ_i^6}，动力学 ṡ = f(s,u,w), w∈W；Viab(K) 为 K 的最大受控不变子集，闭环证书可写成控制障碍函数 h_i（ḣ_i ≥ −α(h_i)）或 Hamilton–Jacobi 可达性值函数 V。同时，把 v5「取最大边际」这个 ad hoc 规则替换为**约束最优控制问题** x* = argmin_{x∈Exec_v6} J(x)（门与不变性为约束，J 为任务代价），并把 v5 的流提议 π_FM 当作 OCP 的热启动初值。关键定理（**证书对目标的不变性**，与 v5 定理 6 对偶）：代价函数与优化器只在**已认证集内部排序**，永不扩大可行域——这把「允许什么」（认证）与「什么最好」（最优）干净分离。

3. **合流 → 三层架构：提议（FMPP）→ 认证（解析门 + 孪生佐证 + 不变性）→ 优化（认证集上的 OCP）**。直觉：v5 已经会「生成」，但生成器不知道自己在一个可能错的世界里；v6 给生成器配一个独立的世界（孪生）和一套「持续安全」的语义（不变性），再用最优控制做「在安全里的最优」。工程上三层时域分离：OCP 与孪生滚动在准入/慢时域（10 Hz 级，离线可并行），不变性约束以 CBF-QP 的形式进入控制环（1 kHz），控制环只解一个小 QP，不跑仿真、不跑 OCP。

**关键洞见**：v5 回答「换提议器是否改变证书边界」；v6 回答「**边界本身是在一个可能错的模型上算的，且它是否在反馈下持续成立**」。答案分两半：边界改为「孪生相对 + 现实差距附加」的概率保证（出处维度），并把点态谓词加强为受控不变（时域维度）；而最优性被证明是**与可行性正交的排序层**。七硬门记号 kc_evidence_forged_v5 原样复用；新增的只有 DTCK（孪生佐证）、VCK（可行性核/不变性）、OCCK（认证 OCP）与 EFA-v6 装配，执行集 Exec_v6 ⊆ Exec_v5 由「孪生门 ⇒ 名义门（θ 取名义值）+ 不变性 ⇒ 点态可行 + 差距附加只紧」三重保证。

**形式化目标（增量）**：
1. 孪生：x' = Sim_θ(x), θ~P_θ；场景门 kc_i^DT(x) = ∧_{j=1}^N kc_i(Sim_{θ_j}(x))；N_min(ε,β,d) 由场景理论给出，保证 P_θ(违反) ≤ ε 以概率 ≥1−β。
2. 现实差距：g_real 由真实标定集估计；δ_i^gap = L_i·g_real；τ_i^6 = γ_i·τ_i^4 + δ_i^gap（只紧不松）。
3. 可行性核：K = ∩_i{s : s_i(s) ≥ τ_i^6}；Viab(K) 最大受控不变子集；CBF h_i / HJ 值 V 作为闭环证书。
4. 认证 OCP：x* = argmin_{x∈Exec_v6} J(x)，约束含七门 + 不变性；π_FM 热启动；V* 作软评分。
5. 定理 9（孪生场景可靠性）、定理 10（不变性单调与嵌套）、定理 11（证书对目标不变性）、定理 12（现实差距迁移界）、定理 13（七锚完备性）；引理 45~47。
6. Exec_v6 = {x ∈ supp(π_FM) : ∧_i kc_i^DT(x;τ_i^6)=1 ∧ traj(x) ⊆ Viab(K) ∧ g_real ≤ g_max} ⊆ Exec_v5。

**本轮最大风险**：**共模模型误差**——Gazebo 与解析门都是刚体接触模型，若它们以同一方式失真（都低估摩擦锥、都忽略柔顺/形变），则「独立佐证」退化为「同一错误的两个副本」，场景随机化只能覆盖参数不确定性而覆盖不了结构性模型误差；而现实差距恰恰在最有价值的接触丰富任务上最大，使孪生相对保证与真实安全之间留下无法自证的缝隙。

### IP-497 DTCK：数字孪生独立佐证核（离线/准入慢时域；GPU 并行）

```python
@dataclass
class DigitalTwinCorroborationKernel:
    """DTCK：Gazebo 孪生独立佐证 + 场景认证 + 现实差距附加。
    定理 9：N 场景全过 ⇒ 孪生分布下每门违反 ≤ ε（概率 ≥1−β）。
    定理 12：真实违反 ≤ ε + P(g_real 超出标定)。"""
    sim: Any                       # gz-sim，独立于解析门的物理引擎
    N: int = 64
    eps: float = 0.05
    beta: float = 0.05
    g_max: float = 0.02            # 差距上限；超限拒绝迁移（fail-closed）
    gap_calib: Any = None          # 真实标定集上的 g_real 估计器

    def scenario_count(self, d: int) -> int:
        # Campi–Garatti 非凸保守式：N ≥ (2/eps)(ln(1/beta)+d)
        return max(self.N, int(np.ceil((2.0 / self.eps) * (np.log(1.0 / self.beta) + d))))

    def sample_theta(self, j: int) -> dict:
        # 域随机化：质量±10%、摩擦锥±25%、恢复系数、增益/饱和、延迟 0–20 ms、噪声
        ...

    def certify(self, x, gates, tau6) -> TwinCert:
        N = self.scenario_count(d_x)
        viol = np.zeros(len(gates), dtype=int)
        for j in range(N):                       # 可 GPU/多 worker 并行
            x_real = self.sim.rollout(x, theta=self.sample_theta(j))
            for i, g in enumerate(gates):
                viol[i] += int(not g.check(x_real, tau6[i]))
        return TwinCert(ok=bool((viol == 0).all()), viol=viol, N=N,
                        eps=self.eps, beta=self.beta)

    def gap_surcharge(self, gates, L) -> np.ndarray:
        # 只紧不松：现实差距 × 门 Lipschitz 常数
        g = self.gap_calib.estimate()
        return np.array([L[i] * g for i in range(len(gates))]), g
```

```
离线/慢时域（分钟~小时，GPU 并行）：
  孪生标定：真机标定集 ──▶ g_real 估计 + 差距模型 ──▶ Φ_global 差距基线（DP）
  可行性核：门集 K(τ⁶) + 扰动集 W ──▶ Viab(K)（HJ/level-set/网格近似）
  提议固化（继承 v5，条件加强）：铸证 ∧ 孪生佐证 ∧ 真机结局 ∧ 抽检
       ──▶ DP-SGD + KL 正则 ──▶ θ_FM（只改提议器，门冻结）

在线准入（异步，10 Hz 级）：
  FAMK γ + 差距附加 δ^gap ──▶ τ⁶ = γ·τ⁴ + δ^gap
  FMPP.propose(K=8) ──▶ 廉价/名义门 ──▶ DTCK 场景佐证（N 场景并行）
       ──▶ VCK 不变性筛选 ──▶ OCCK 约束 OCP（热启动 + 重新认证）
       └─ 全灭 ──▶ fail-closed 回退（仍须孪生 + 不变性）

在线控制环（目标 < 0.6 ms）：
  每周期：EEK(kc_ee) + BCK（事件触发/缓存）+ CBF-QP 安全过滤（小 QP）
  证书消费：检查 t − t_cert ≤ T_lease；超期 → 重新认证或安全保持
  DTCK / OCCK / HJ 全部与 1 kHz 环解耦，控制环只消费预计算阈值与缓存证书
```

## 3. 复杂度分析（增量更新）

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 | 实时性指标 |
|---|---|---|---|---|
| DTCK.certify | O(N·C_sim·H)（N 场景 × 仿真步） | O(N·d_x)（并行） | N≈64–256, H≈2 s | 离线/准入；GPU 并行 ~0.5–5 s/候选 |

| VCK.cbf_qp | O((n_u+n_c)³) 小 QP | O((n_u+n_c)²) | n_u≤20, n_c≤16 | **~0.1–0.4 ms，1 kHz 环内** |
| OCCK.solve | O(iter·(n_x+n_u)³) | O(n_x·H) | iter≈20–50, H≈50 | 准入 10 Hz，热启动 ~5–30 ms |
| 差距附加 δ^gap | O(#gates) | O(1) | — | <0.01 ms |
| EFA-v6 硬门 | O(1)（阈值预计算） | O(1) | — | <0.05 ms |
| 端到端控制环 | — | — | — | **P99 ~0.58 ms（v5 0.55 ms）** |

**通信开销**：孪生配置与差距基线 ~KB/站（DP）；可行性核可按站本地近似或下发压缩水平集；原始仿真与真机数据不出站。固化只在站内进行，策略权重经签名下发。

**实时性说明（诚实）**：孪生场景认证是**主要成本**（N 次高保真仿真），只能放在离线/准入慢时域，绝不进控制环；1 kHz 层只解 CBF-QP（~0.1–0.4 ms）并消费缓存证书。若 GPU 抖动导致 DTCK 超时，按 fail-closed 回退到 v5 规则提议（带名义门），不阻塞控制环。

## 4. 正确性论证（增量更新）

### 引理 45（场景违反概率的有限样本界）

**陈述**：设 θ_1,…,θ_N ~ P_θ i.i.d.，若候选 x 在全部 N 个场景下满足某门（viol=0），则对任意 ε∈(0,1)、β∈(0,1)，只要 N ≥ N_min(ε,β,d)（非凸保守式 N_min ≈ (2/ε)(ln(1/β)+d)），就有 P_θ(kc_i(Sim_θ(x))=0) ≤ ε 以概率 ≥1−β 成立。∎

**诚实边界**：该界**相对于孪生参数分布 P_θ**，且要求 i.i.d./可交换与参数化模型类；它覆盖参数不确定性，**不覆盖结构性模型误差**（模型类本身错）。

### 引理 46（现实差距迁移）

**陈述**：设门边际 s_i 对轨迹 sup-范数 L_i-Lipschitz，且真实与孪生轨迹满足 ‖x_real − x_sim‖_∞ ≤ g_real。则 s_i(x_real) ≥ s_i(x_sim) − L_i·g_real。故若 s_i(x_sim) ≥ τ + L_i·g_real，则 s_i(x_real) ≥ τ。∎

**意义**：这正是 δ_i^gap = L_i·g_real 的来源——把「孪生内安全」迁移为「真实安全」的充分条件，代价是抬阈值。

### 引理 47（可行性核的极大性与单调）

**陈述**：Viab(K) 是 K 的最大受控不变子集；Viab(K) ⊆ K；K' ⊆ K ⇒ Viab(K') ⊆ Viab(K)。若 W={0} 且控制权限足以驻留任意状态，则 Viab(K)=K。∎

**证明**：受控不变集对包含关系单调；极大性由并集封闭性（受控不变集之并仍受控不变）。∎

### 定理 9（孪生场景可靠性）

**陈述**：若 kc_i^DT(x)=1（N 场景全过），则对每门 i，P_θ(kc_i(Sim_θ(x))=0) ≤ ε 以概率 ≥1−β（引理 45）；对七门取 ε_i=ε/7 的 Bonferroni 分配，则孪生相对违反概率 ≤ ε。∎

**工程含义**：证书从「对单一模型的断言」升级为「对孪生参数分布的、带显式 ε/β 的概率保证」。

### 定理 10（不变性单调与嵌套）

**陈述**：(i) Viab(K) ⊆ K ⇒ 不变性约束比点态门更严；(ii) τ_i^6 = γ_i·τ_i^4 + δ_i^gap ≥ τ_i^5 ⇒ K(τ^6) ⊆ K(τ^5)；(iii) 孪生门在 θ=名义值时退化为名义门。故 Exec_v6 ⊆ Exec_v5；(iv) 且 K'⊆K ⇒ Exec(K')⊆Exec(K)。∎

**证明**：逐条由引理 47、阈值单调、以及 θ 取名义值。∎

### 定理 11（证书对目标的不变性——与 v5 定理 6 对偶）

**陈述**：对任意任务代价 J 与任意优化器（含局部最优、失败、任意热启动），被接受的轨迹集恒为 {x : kc^DT(x)=1 ∧ traj(x)⊆Viab(K) ∧ g_real≤g_max}，与 J 和优化器无关。优化器只能在认证集内改善代价，永不扩大可行域。∎

**证明**：OCCK 的每条输出都必须重新通过同一套认证（solve_then_recertify），失败即回退候选；认证谓词不含 J。∎

**工程含义**：安全与最优被干净分离——**坏优化器只会更差，不会更危险；好优化器只会更好，不会更安全**。这是 v5「提议不变性」在目标侧的镜像。

### 定理 12（现实差距迁移界）

**陈述**：若孪生门成立（定理 9）、g_real ≤ g_max、且 δ_i^gap = L_i·g_real，则真实门违反概率 ≤ ε + P(g_real > g_max)。∎

**证明**：引理 46 给出确定性迁移；g_real 的尾部概率单独计入。∎

**诚实边界**：若差距模型类错误（真实差距分布与标定集不同），P(g_real > g_max) 无界；接触丰富任务中该尾部最厚。

### 定理 13（七锚完备性在孪生与最优控制下保持）

**陈述**：v6 不增删锚点：七锚 {3DCF, MSRG, HICK, EEK, LTEM, VACK, BCK} 完备性（v4 定理 4）保持。DTCK 是「所有门的独立佐证通道」（非新锚），VCK 是「门的时间维度强化」（非新锚），OCCK 是「认证集内的目标层」（非新锚），δ^gap 是「阈值收紧」（非新锚）。∎

### 定理 v6（总装：数字孪生验证的认证最优控制）

**陈述**：在 v4 假设 (B1)~(B6)、v5 假设 (B7) 及新增 (B8) 孪生场景 i.i.d. 可交换、(B9) 门边际 L_i-Lipschitz 且差距有界 g_real≤g_max 下：
(i) Exec_v6 ⊆ Exec_v5 ⊆ … ⊆ Exec_v29（定理 10）；
(ii) 孪生相对可靠性：P_θ(违反) ≤ ε（概率 ≥1−β，定理 9）；
(iii) 闭环不变：接受轨迹的状态始终在 Viab(K)（定理 10 + VCK）；
(iv) 目标不变：安全边界与 J/优化器无关（定理 11）；
(v) 现实迁移：真实违反 ≤ ε + 差距尾概率（定理 12）；
(vi) 七锚完备性保持（定理 13）。
**证明**：逐条由定理 9–13 与嵌套定义。∎

**诚实声明**：(B8)(B9) 只覆盖参数化模型不确定性，**不覆盖结构性模型误差**；HJ 可行性核在 n_s>6 时只能近似（CBF + 采样验证，非精确）；g_real 的尾部在接触丰富任务上无先验界；OCP 的局部最优可能显著劣于全局最优（但不影响安全）。

## 7. 本轮最大风险（最终确认）

**一句话**：**共模模型误差**——Gazebo 与解析门都是刚体接触模型，若二者以同一方式失真（都低估摩擦锥、都忽略柔顺/形变），则「独立佐证」退化为「同一错误的两个副本」，场景随机化只能覆盖参数不确定性而覆盖不了结构性模型误差，而现实差距恰恰在最有价值的接触丰富任务上最大，使孪生相对保证与真实安全之间留下无法自证的缝隙。
