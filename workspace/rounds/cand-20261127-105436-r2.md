### 第 3 轮灵感驱动研究记录

**灵感词**：碰撞检测、低成本方案

**直觉与动机**：
上一轮的 KEMPC 证书体系解决了「该不该做某动作」（常识 + 动力学可行性），但留下一个更底层、更高频的空洞：「这一步会不会撞」。传统双足机器人碰撞检测依赖连续碰撞检测（CCD）+ 稠密 ESDF + 精确网格求交；对 12+ 自由度、每 5ms 一次的步态查询，再叠加多机协同，成本会指数级膨胀。而「低成本」的正确含义不是降低安全，而是**把昂贵检测的调用次数降下来**——利用上一轮已生成的 nominal 轨迹、DCC 的 κ 一致性界、以及 WLKB/SSKL 的语义知识，把碰撞检测从「每步从零精确查询」改写成「事件触发的证书维护」。

**关键洞见**：碰撞检测本质上是一个带几何结构的「时空证书」问题，可沿四个维度降本而不降安全：
- **空间维（Lipschitz 球证书）**：SDF 满足 |d(x)−d(y)| ≤ L_d‖x−y‖，因此只需在锚点 x_a 求一次 d(x_a)，即可一次性认证整个球域 B(x_a, r)：∀x, d(x) ≥ d(x_a) − L_d·r。球内免检。
- **时间维（保守扫掠）**：把两帧之间的运动视为扫掠体，采样间距 h 由 L_d 反推：h ≤ 2·(d_sample − ε)/L_d，即可保证采样点之间不穿透。
- **语义维（碰撞候选剪枝）**：用上一轮知识库剪掉「不可能相撞」的（身体部位, 地形语义类）组合，例如站立时只查双足与支撑面，不查摆动腿与远端障碍。
- **事件维（按需升级）**：维护证书剩余寿命 τ = (d(x_a) − ε)/L_d − v_max·Δt；仅当 τ<0、证书过期、速度突变或 DCC 偏差超界时，才升级到高保真 CCD。

**形式化目标**：
1. 定义保守几何代理 𝒢 = ∪_j 𝒫_j（球/胶囊并集）与带符号距离 d(x)，给出保守膨胀界 ‖d̂ − d‖ ≤ η。
2. 定义低成本碰撞证书 LCCC = (x_a, r, ε, L_d, [t₀,t₁])，语义为 ∀x ∈ B(x_a, r): d(x) ≥ ε。
3. 定义事件触发检测器 ETCD：触发谓词 Trig(x, 𝒞, Δt) = [τ(x) < 0 ∨ age(𝒞) > T_max ∨ ‖Δv‖ > v* ∨ κ_dcc > κ*]。
4. 定义证书缓存与复用 𝒞 = {(region_hash, time_bucket) → LCCC}，并给出地图更新时的失效规则。
5. 定义语义剪枝算子 SCP：Candidates(mode, terrain_sem) ⊆ BodyParts × ObstacleClasses。
6. 定义低成本碰撞门 LCCG，在 KACG 上新增 Fil_collision，得到 Exec_v28 = Exec_v27 ∩ Fil_collision。
7. 证明 Fil_collision 的**不漏检性（soundness）**，并给出「保守性–成本」权衡的复杂度与实验设计。

**本轮最大风险**：L_d 被低估或地图更新后缓存证书未及时失效，会把「低成本」悄悄变成「漏检」——漏检是静默的、不像崩溃那样显眼，在线极难察觉，且会被下游证书链当作「已通过碰撞检查」而放大。

## 2. 关键算法骨架（在 IP-455~464 骨架上扩展）

### IP-465 / IP-469 Low-Cost Collision Certificate + 保守代理

```python
@dataclass
class ConservativePrimitiveProxy:
    """球/胶囊并集，保守包裹真实网格；保证 d(x) >= d_hat(x) - eta"""
    primitives: list            # [(center, radius), ...] 或胶囊
    eta: float                  # Hausdorff 膨胀界（代理比真实更保守）

    def sdf(self, x: Tensor) -> float:
        # 代理 SDF：取所有图元距离的最小值
        return min(self._primitive_sdf(x, p) for p in self.primitives)

    def certified_clearance(self, x: Tensor) -> float:
        # 保守下界：真实间隙不小于代理间隙减去膨胀界
        return self.sdf(x) - self.eta


@dataclass
class LowCostCollisionCertificate:
    """LCCC：以锚点一次查询认证整个球域，球内免检"""
    anchor: Tensor
    radius: float
    margin: float               # 要求的余隙 epsilon
    L_d: float                  # SDF Lipschitz 常数（须保守上界）
    t0: float
    t1: float
    proxy: ConservativePrimitiveProxy

    def covers(self, x: Tensor) -> bool:
        return torch.norm(x - self.anchor) <= self.radius

    def certify_ball(self) -> bool:
        # 认证条件：d(x_a) - L_d * r >= margin
        d_anchor = self.proxy.certified_clearance(self.anchor)
        return d_anchor - self.L_d * self.radius >= self.margin

    def valid_at(self, x: Tensor, t: float) -> bool:
        # 时间窗 + 球域 + Lipschitz 三重校验
        if not (self.t0 <= t <= self.t1) or not self.covers(x):
            return False
        d_anchor = self.proxy.certified_clearance(self.anchor)
        return d_anchor - self.L_d * torch.norm(x - self.anchor) >= self.margin
```

### IP-470 Swept-Volume Certifier（时间维）

```python
class SweptVolumeCertifier:
    """用 L_d 反推采样间距，保证采样帧之间的扫掠体也不穿透"""

    def __init__(self, proxy: ConservativePrimitiveProxy, L_d: float,
                 margin: float = 0.02):
        self.proxy, self.L_d, self.margin = proxy, L_d, margin

    def certify_segment(self, q0: Tensor, q1: Tensor,
                        max_samples: int = 32) -> tuple[bool, int]:
        length = torch.norm(q1 - q0).item()
        if length < 1e-9:
            return self.proxy.certified_clearance(q0) >= self.margin, 1
        # 采样间距需满足 L_d * h / 2 <= clearance - margin
        d_min = min(self.proxy.certified_clearance(q0),
                    self.proxy.certified_clearance(q1))
        slack = max(d_min - self.margin, 0.0)
        h = max(2.0 * slack / self.L_d, 1e-4) if self.L_d > 0 else length
        n = int(min(max_samples, max(2, math.ceil(length / h) + 1)))
        # 若所需采样数超过上限，则判为「无法低成本认证」，交给高保真检测
        if math.ceil(length / h) + 1 > max_samples:
            return False, n
        for i in range(n):
            q = q0 + (q1 - q0) * (i / (n - 1))
            if self.proxy.certified_clearance(q) < self.margin:
                return False, n
        return True, n
```

### IP-466 Event-Triggered Collision Detector

```python
class EventTriggeredCollisionDetector:
    """只在证书失效/风险升高时升级到高保真 CCD"""

    def __init__(self, L_d: float, margin: float, t_max: float = 0.5,
                 v_star: float = 1.0, kappa_star: float = 0.05):
        self.L_d, self.margin = L_d, margin
        self.t_max, self.v_star, self.kappa_star = t_max, v_star, kappa_star

    def remaining_life(self, cert: LowCostCollisionCertificate,
                       x: Tensor, dt: float, v_max: float) -> float:
        d_anchor = cert.proxy.certified_clearance(cert.anchor)
        tau = (d_anchor - self.margin) / self.L_d - v_max * dt
        return tau

    def should_recheck(self, cert, x, t, dt, v_max,
                       kappa_dcc: float) -> bool:
        return (
            self.remaining_life(cert, x, dt, v_max) < 0.0
            or (t - cert.t0) > self.t_max          # 证书过期
            or not cert.covers(x)                  # 离开认证球域
            or v_max > self.v_star                 # 速度突变
            or kappa_dcc > self.kappa_star         # DCC 偏差超界
        )

    def step(self, x, cert, t, dt, v_max, kappa_dcc, ccd_query):
        # 低成本路径：复用证书；事件路径：调用高保真 CCD 并重建证书
        if not self.should_recheck(cert, x, t, dt, v_max, kappa_dcc):
            return True, cert
        return ccd_query(x)
```

### IP-467 Certificate Collision Cache

```python
class CertificateCollisionCache:
    """以 (region_hash, time_bucket) 索引 LCCC；地图更新时整体失效"""

    def __init__(self, bucket: float = 0.1):
        self.bucket = bucket
        self.map_version = 0
        self.store: dict = {}

    def _key(self, region_hash: str, t: float) -> tuple:
        return (region_hash, int(t / self.bucket), self.map_version)

    def get(self, region_hash, t, x) -> LowCostCollisionCertificate | None:
        cert = self.store.get(self._key(region_hash, t))
        if cert is not None and cert.valid_at(x, t):
            return cert
        return None

    def put(self, region_hash, t, cert) -> None:
        self.store[self._key(region_hash, t)] = cert

    def invalidate_on_map_update(self) -> None:
        # 地图变化使所有既有证书的障碍假设失效
        self.map_version += 1
        self.store.clear()
```

### IP-468 Semantic Collision Pruning

```python
class SemanticCollisionPruner:
    """复用 WLKB/SSKL 语义，剪除不可能的（身体部位 × 障碍类）候选对"""

    STANDING_PAIRS = {("left_foot", "ground"), ("right_foot", "ground")}
    WALKING_PAIRS = {
        ("left_foot", "ground"), ("right_foot", "ground"),
        ("torso", "obstacle"), ("swing_leg", "obstacle"),
    }

    def candidates(self, mode: str, terrain_sem: dict) -> set:
        if mode == "standing":
            return self.STANDING_PAIRS
        if mode == "walking":
            return self.WALKING_PAIRS
        # transition：保守取并集，不做激进剪枝
        return self.STANDING_PAIRS | self.WALKING_PAIRS
```

### IP-471 Low-Cost Collision Gate（接入 KACG）

```python
@dataclass
class LowCostCollisionGate:
    """在 KACG 上新增 Fil_collision：先证书、后事件、再高保真"""
    proxy: ConservativePrimitiveProxy
    certifier: SweptVolumeCertifier
    detector: EventTriggeredCollisionDetector
    cache: CertificateCollisionCache
    pruner: SemanticCollisionPruner

    def admits(self, plan, t: float, dt: float, v_max: float,
               kappa_dcc: float, ccd_query) -> bool:
        # 1. 语义剪枝
        pairs = self.pruner.candidates(plan.mode, plan.terrain_sem)
        # 2. 缓存命中直接放行
        region = plan.region_hash
        cert = self.cache.get(region, t, plan.state)
        if cert is not None:
            return True
        # 3. 低成本扫掠认证
        ok, _ = self.certifier.certify_segment(plan.q_prev, plan.q_now)
        if ok:
            new_cert = LowCostCollisionCertificate(
                anchor=plan.q_now, radius=plan.ball_radius,
                margin=self.certifier.margin, L_d=self.certifier.L_d,
                t0=t, t1=t + self.detector.t_max, proxy=self.proxy)
            if new_cert.certify_ball():
                self.cache.put(region, t, new_cert)
                return True
        # 4. 事件升级：仅此处调用昂贵 CCD
        ok_hi, _ = ccd_query(plan, pairs)
        return ok_hi
```

## 3. 复杂度分析（增量）

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 |
|---|---|---|---|
| LCCC 单次认证 | O(1) 次 SDF 查询 | O(1) | 每图元 1 次距离计算 |
| SVC 段认证 | O(n) 次查询，n≈⌈L/h⌉ | O(1) | n ≤ max_samples |
| ETCD 调度 | O(1) | O(1) | 仅算术比较 |
| CCC 命中 | O(1) 哈希查找 | O(N_cert) | bucket 粒度 |
| SCP 剪枝 | O(1)（查表） | O(1) | 模式固定 |
| 高保真 CCD | O(N_pair · N_tri) | O(N_tri) | 仅在事件点触发 |

**成本模型**：设规划步数 N、事件触发率 p、每次高保真 CCD 成本 C_hi、每次低成本认证成本 C_lo（C_lo ≪ C_hi）。总成本 ≈ N·C_lo + p·N·C_hi；当 p 很小（平稳步态 p≈0.02–0.1）时相对「每步 C_hi」可降 5–20×。**代价**是保守性：认证球半径 r 与余隙 ε 正相关，ε 越大越安全但越易判「无法低成本认证」而升级。

## 4. 正确性论证（增量）

### 引理 23（Lipschitz 球证书的可靠性）

**陈述**：若 d(x_a) − L_d·r ≥ ε，则 ∀x ∈ B(x_a, r)，d(x) ≥ ε。

**证明**：由 Lipschitz 性质 |d(x) − d(x_a)| ≤ L_d‖x − x_a‖ ≤ L_d·r，故 d(x) ≥ d(x_a) − L_d·r ≥ ε。∎

**注意**：证明依赖 L_d 是**保守上界**；若 L_d 被低估，结论不成立——这是 soundness 的唯一命门。

### 引理 24（扫掠体采样的不漏检性）

**陈述**：若沿线段 q(s) 以间距 h 采样且每个采样点 d(q_i) ≥ ε + L_d·h/2，则线段上任意点 d ≥ ε。

**证明**：任意 s 落在相邻采样点 q_i, q_{i+1} 之间，‖q(s) − q_i‖ ≤ h/2，由 Lipschitz 性 d(q(s)) ≥ d(q_i) − L_d·h/2 ≥ ε。∎

### 引理 25（事件触发调度的安全性）

**陈述**：若 ETCD 在区间 [t₀,t₁] 内从未触发重检，且初始证书成立，则整个区间内碰撞检测结论保持有效。

**证明**：不触发意味着 τ ≥ 0、未过期、未出球域、v ≤ v*、κ_dcc ≤ κ*；由引理 23 与 DCC 的 κ 界，实际状态始终落在已认证球域内且余隙不衰减至 ε 以下。∎

### 定理（LCCG 的 soundness 与保守包含）

**陈述**：若 `LCCG.admits(π) = True` 且 L_d 为真实 Lipschitz 上界、代理膨胀界 η 正确、地图版本未过期，则 π 在执行中不与障碍穿透。且由于保守代理可能拒绝本来可行的轨迹，有 Exec_v28 ⊆ Exec_v27。

**证明**：admits 的每条通过路径分别由缓存证书（引理 23）、扫掠认证（引理 24）或高保真 CCD 保证无穿透；事件升级只在证书失效时发生（引理 25 的逆否）。保守性来自代理膨胀与 ε>0，只会多拒不会少拒，故为子集。∎

**明确的边界**：本框架**只保证 soundness（不漏检），不保证 completeness（不误报）**；误报会导致规划器保守甚至死锁，需在实验中量化。

## 5. 实验设计（低成本 vs 高保真）

**基线**：MuJoCo + FCL，每 5ms 对全网格做一次精确 CCD/离散碰撞查询。

**变量**：本方案 = SCP 剪枝 + LCCC + SVC + ETCD + CCC。

**场景**：平地行走、碎石坡、窄梁、动态障碍横穿、walking↔standing 切换，各 100 次随机种子。

**指标**：
1. 每步平均碰撞查询耗时（期望降 5–20×）；
2. 高保真 CCD 触发率 p；
3. **假阴性数（必须为 0，否则 soundness 被证伪）**；
4. 假阳性率 / 规划器保守拒绝率（衡量保守代价）；
5. 缓存命中率与证书平均寿命；
6. 任务成功率与跌倒率（安全性总指标）。

**消融**：分别关闭 SCP / CCC / SVC，量化各模块对成本与保守性的贡献；对 L_d 取 0.8×、1.0×、1.5× 真值，检验 soundness 对低估的敏感性（预期 0.8× 出现假阴性，作为反例验证）。

**预期**：p≈0.02–0.1 时耗时显著下降，假阴性为 0；但 L_d 低估或地图更新未失效时会出现假阴性——这正是最大风险的可复现证据。

## 6. 已知风险与缓解（增量）

| 风险编号 | 描述 | 严重度 | 缓解措施 | 剩余风险 |
|---|---|---|---|---|

## 7. 本轮最大风险（最终确认）
