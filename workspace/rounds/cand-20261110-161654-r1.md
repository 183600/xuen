# 第 44 轮（新循环第 4 轮） · Torque-Cert × ROS-Native：把「物理证伪通道」与「中间件证书契约」纳入可验证闭环（四层架构 v9 + 物理反射平面 PRP）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 自陈最大风险是「共形边际覆盖被欺骗 + 多用户契约求交为空」，但这仍是**同一类证据内部**的风险。它压着两个从未写进不变式的单点假设：**(H1) 证书的证据全部是“预测”**——VLM 语义、几何证书、共形边际都来自模型或数据，存在共同模式失效：透明物体、反光、遮挡、接触瞬间可以同时骗过它们；系统里没有一个**低延迟、接触接地、与感知模型物理独立**的通道去证伪“此刻没有碰撞 / 没有超力”。**(H2) 证书运行时被默认为理想调度器**——租约、原子快照、有界 WCET 都写在抽象层；真实基底是 ROS 2 + DDS，默认 QoS 会静默丢样本或排队，回调组会串行化，回调不可抢占，而 CycloneDDS 甚至不提供 message-lost 事件，于是“证书在 t 时刻 sound”与“执行器实际看到的最新证书”之间有一条未被计量的缝。本轮灵感词精确命中：**力矩传感**把「接触力」这一操作的物理真值引入闭环，提供**只可否决、不可授权**的快速证伪通道；**ROS** 把证书从“文档 / 结论”变成**可送达、可过期、可审计的 DDS 运行时对象**——QoS 的 deadline / liveliness / lifespan 恰好就是租约语义。二者耦合出的新问题是：**快通道（约 1 kHz 力矩）不能做重认证，慢通道（VLM / 几何）不能实时否决**——必须建立“慢证明、快证伪”的双时间尺度证书代数，并证明快通道即使被延迟、丢包、漂移或欺骗，也只能收缩安全域，不能扩张。

## 0. 直觉与动机

**灵感 1（力矩传感 → 接触是操作的物理真值，力矩是证伪器而不是证明器）**：直觉上，视觉可以说“前方是空的”，但只有力 / 力矩能在接触发生的那一毫秒说“你已经碰到了”。因此不要把力矩当成又一个“传感器输入”塞进 VLM，而应把它放在**权威层级的另一侧**：慢通道（感知、几何、共形）负责**提出**可执行假设，快通道（力矩 / 电流 / 足端力）只负责**否决**。这在认识论上就是证伪主义：证明一个动作安全需要覆盖未来，成本高且依赖模型；证伪一个动作不安全只需要一次真实违例，成本低且物理接地。形式上给快通道一个**单调否决权**：它只能与可容许集取交，永远不能扩张。于是快通道可以异步、高频、独立运行，而其最坏情况只是误否决（可用性下降），绝不会漏否决（安全性下降）——这正是把“物理”接进证书系统而不破坏 v20 并发生存性的关键。

**灵感 2（ROS → 证书是运行时对象，QoS 就是租约，执行器就是调度证明）**：直觉上，证书不是写进论文的结论，而是一条要在网络上**送达、被及时看到、在过期前被使用**的消息。ROS 2 的 QoS 早已长出了租约的器官：`deadline` 是“多久没来就算失约”，`liveliness + lease_duration` 是“发布者还活着吗”，`lifespan` 是“样本何时作废”，`reliability` / `KEEP_LAST` 决定迟到样本会不会被静默丢弃。v20 用自造租约重新发明了这些；v9 应直接把“证书 QoS 契约”变成证书的一部分，并要求**用源时间戳判定新鲜度，而不是到达时间**。更危险的是执行器：默认 `MutuallyExclusive` 回调组会让一个长 VLM 回调把安全监控堵在队列里，`MultiThreadedExecutor` 不保证优先级，跨执行器共享锁仍会优先级反转。因此关键级必须落到**回调组 / 执行器 / lifecycle 节点**上，并用 RTA 把监控器 WCET、执行器派发开销与 DDS 序列化抖动一起算进去。

**灵感 3（耦合 → 双时间尺度与远程接入的端到端新鲜度）**：力矩在 1 kHz，证书在 10–30 Hz，两者不可能同步认证；正确结构是**慢证明、快证伪 + 命令绑定**：慢证书给任务授权，快反射只能在授权域内收缩，每条命令携带证书纪元 `e_cmd`，执行器拒绝纪元不匹配的命令。UniBot 的部署形态又迫使这张图跨出本机：选手模型远程接入，控制链是 `传感 → 推理主机 → DDS 桥 → 机器人执行`，端到端延迟 `δ_e2e` 必须显式从租约中扣除；`δ_e2e` 一旦超过预算，就只能退化为“反射 + 保持 / 降速”，不能继续用陈旧语义证书。一个新问题由此出现：**物理独立性不能靠“接口存在”自证**——G1 的 `tau_est` 很可能来自电流 / 模型估计，若它与控制器共享电机模型，那么它和被它“见证”的失效是相关的。独立性必须被测量（E101），而不是被假设。

**耦合升级**：TRF（力矩反射证伪器）在 L0 硬件接口层提供力域否决与 sim2real 残差见证；RCR（ROS 2 证书契约运行时）把 v20 的租约 / 混合关键级映射为 QoS / 回调组 / 执行器 / lifecycle，并做源时间与纪元一致性校验；PDV（物理多样性验证器）用故障注入与 rosbag2/MCAP 重放测量快慢通道的共同失效。四层架构由 v8 的「人格并发证书」升级为 v9：**在 L1 之下新增贯穿式『物理反射平面 PRP』**，并把整条证书链ROS 2 原生化。

## 1. 形式化定义（增量：定义 44–50）

**定义 44（双通道证书与单调否决权）**：证书系统 C=(P,V)。慢通道 P 输出可容许集 A_P ⊆ A（可授权扩张）；快通道 V 输出否决谓词 v: State→{0,1}。运行时可执行集 **A_t = A_P(t) ∩ {a : v_t(a)=0}**，且当慢通道未更新时任何快通道更新满足 **A_{t+1} ⊆ A_t**（只取交）。**定理（否决权安全）**：若 (i) P 在其声明域上 sound，(ii) V 无漏否决（凡真实物理违例，在延迟 δ_v 内必触发），则任意交错下系统不会执行物理违例动作；V 的错误只会导致**误否决**（可用性损失），不会导致**漏否决**（安全性损失）。**推论**：快通道无需与慢通道共享模型即可独立运行，这是“物理见证”可被安全接入的形式基础。

**定义 45（外部力矩估计与力域安全包络）**：关节实测 / 估计力矩 τ_meas，模型力矩 τ_model(q,q̇,q̈)=M(q)q̈+C(q,q̇)q̇+g(q)+τ_fric(q̇)。外部力矩 **τ_ext = τ_meas − τ_model − τ_known**。末端等效力 **F_ext = (J(q)^T)^† τ_ext**（最小范数解；零空间分量不可观）。**力域包络** Φ_F(q)={τ : ‖(J^T)^†τ‖ ≤ F_max}。**命题（力矩域守卫不 sound）**：仅用 ‖τ_ext‖ ≤ τ_max 守卫时，存在构型 q 使合法 τ 对应 ‖F‖ > F_max（力臂变短 / 雅可比病态）；反之用保守界 **‖F‖ ≤ ‖τ_ext‖ / σ_min(J^T)** 并令其 ≤ F_max 是 sound。**推论**：守卫必须在力域，且对租约时域内可达构型取 σ_min 的最坏值；单关节力矩阈值只能作为硬件后备，不能作为安全证书。

**定义 46（力矩残差作为 sim2real 间隙的在线见证）**：r_t = τ_meas − τ_model − τ_ext_expected。把“持续、跨任务、与接触无关”的分量记为模型残差 r_model，把“瞬态、与接触几何相关”的分量记为 r_contact。用分位数 / EVT 维护 **R̂_t** 作为 r_model 的 sound 上界（校准时注入已知负载、磨损、温漂）。**界限更新**：λ_t = L_m·(v_max + c·R̂_t)，力域上限收紧 **F_max^t = F_max − L_F·R̂_t**。**命题**：若 R̂_t 是工作集上模型残差的 sound 上界，则用其膨胀后的守卫 sound；反之，若 R̂_t 把接触残差吸收进“模型误差”，真实接触会被当噪声抹掉，形成**残差估计器自我致盲**——这是本轮最隐蔽的失效，必须由 E97 的时间尺度分离实验证伪。

**定义 47（ROS 2 证书契约与观测时间 sound 性）**：证书样本 c=(e, s, ts_src, m, λ, θ, κ, D, δ_e2e)。发布 / 订阅 QoS 契约 Q(c)=(reliable, KEEP_LAST(k), deadline=D, lifespan=L, liveliness=lease)。**观测时间判据**：在时刻 t 有效当且仅当
`s > s_last`（无回退、无缺口）、`t − ts_src ≤ L`、deadline / liveliness 均未触发、且 `m − λ·(t − ts_src) − λ·δ_e2e ≥ θ`。**定理（QoS-lease sound）**：若 QoS 契约被遵守且 δ_e2e 上界成立，则观测时间判据不弱于 v20 的本地租约；若发生 deadline missed / liveliness lost / 序号缺口任一事件，证书**立即失效**，与墙钟是否还在租约内无关。**注**：CycloneDDS 不提供 message-lost 事件，因此 **seq 连续性检查是强制项**，不能依赖 QoS 回调补洞。

**定义 48（证书纪元与命令绑定）**：证书状态维护单调纪元 e∈ℕ，每次认证更新发布 (e, cert)。每条执行命令携带 e_cmd。安全门仅当 **e_cmd = e_latest_valid** 且该 e 的证书满足定义 47 的观测时间判据时放行。**命题（防 TOCTOU）**：“读旧证书、发新命令”的竞态不可能进入执行器；证书回退 / 撕裂由 e 单调性检出；DDS 桥接器必须透传 (e, ts_src)，不得重新打时间戳。

**定义 49（关键级到 ROS 2 执行器的映射与可调度性）**：κ 映射为回调组 / 执行器：安全反射与监控 → 专用实时执行器 + `MutuallyExclusive` 回调组 + 最高优先级 + 零堆分配；语义 / VLM → `Reentrant` 组 + 低优先级执行器；对话 / 个性化 → 可取消、可裁剪。LO/HI 由 lifecycle 节点原子切换：HI 仅 deactivate 低关键节点，不新增、不放松阈值，并递增证书纪元。**可调度判据**：R_monitor = C_monitor + B_monitor + O_exec + O_dds ≤ D_monitor，其中 B 为共享锁 / 分配阻塞。**命题**：若监控器独占回调组与执行器、且与其它任务无共享阻塞临界区，则长 VLM 回调不会造成监控器优先级反转；**残余反转只来自跨执行器共享资源**，须用无锁 SPSC / 三缓冲或 LET 消除。

**定义 50（物理多样性证书）**：设快通道 T（力矩 / 电流 / 足端力）与慢通道 S（视觉 / 几何）。在故障注入分布 D_f 上定义共同失效概率 p_common = P(T 与 S 同时错过同一物理事件) 与相关系数 ρ。**独立性证书**：若 p_common ≤ ε_ind 且 ρ ≤ ρ_max，则 T 可作为 S 的独立见证；否则 T 只能算“同源冗余”，**不得用于降低 S 的保守性**。**注**：G1 的 `tau_est` 很可能是电流 / 模型估计而非独立标定力矩传感器；若它与控制器共享电机模型，其“物理独立性”必须由 E101 实测，不能用“存在力矩接口”自证。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 TORQUE-REFLEX-FALSIFIER（力矩反射证伪器 TRF）
1. **外部力矩与力域包络**：RNEA 模型力矩 + 摩擦模型 → τ_ext；用 σ_min(J^T) 的最坏值把 τ_ext 转为力域上界，拒绝“只看力矩”。
2. **只否决的 1 kHz 快路径**：跑在 `ros2_control` 硬件接口 / 实时线程，零堆分配、定点或轻量浮点；输出 Allow / Veto，**无权扩张证书**。
3. **残差见证**：在线维护 R̂_t，驱动 λ 衰减与 F_max 收紧；按时间尺度区分模型残差与接触残差。
4. **硬件后备**：电流 / 力矩硬限幅 + 独立 e-stop，不依赖任何软件证书仍能止住超力。

### 2.2 IP-61 ROS2-CERT-CONTRACT-RUNTIME（ROS 2 证书契约运行时 RCR）
1. **QoS 契约编译器**：证书类（grant / veto / heartbeat）→ 明确的 reliability、history depth、deadline、lifespan、liveliness 配置，并静态校验兼容性。
2. **源时间租约验证器**：以 `ts_src` 与单调时钟计算新鲜度；强制 seq 连续性、deadline、liveliness 三类失效检测。
3. **纪元绑定**：证书更新与执行命令共享 `e`；桥接器透传，拒绝回退 / 撕裂。
4. **关键级映射**：回调组 / 执行器 / lifecycle 的自动化映射与 RTA 检查，HI 模式只删不增。
5. **端到端新鲜度令牌**：跨推理主机与机器人的 `δ_e2e` 预算分摊与超预算降级。

### 2.3 IP-62 PHYSICAL-DIVERSITY-VALIDATOR（物理多样性验证器 PDV）
1. **力矩通道故障注入**：偏置、尺度、饱和、卡死、丢帧、延迟、重放、欺骗；验证定义 44 的“无漏否决”。
2. **共同模式测试**：透明 / 反光 / 遮挡 / 低纹理 × 接触事件，测量快慢通道的 p_common 与 ρ。
3. **rosbag2 / MCAP 确定性重放**：把 QoS 事件、seq 缺口、executor 时间线与证书判定一起入库，做可审计复现。
4. **独立性证书签发**：未达标的通道组合只能作为同源冗余，强制回到 v20 的保守租约。

## 2. 关键算法（伪代码）

### IP-60 TRF：外部力矩、力域包络与只否决快路径
```
def reflex_step(rt, cfg):
    # 1 kHz、零堆分配；只读实时状态，不分配、不加锁
    tau_model = rnea(rt.q, rt.dq, rt.ddq) + friction(rt.dq) + rt.tau_known
    tau_ext   = rt.tau_meas - tau_model

    # 力域而非力矩域：σ_min 取租约时域内可达构型的最坏下界
    s_min = sigma_min_lower_bound(rt.q, cfg.reachable_horizon)
    F_ub  = norm(tau_ext) / max(s_min, cfg.s_min_floor)

    # 残差见证：模型误差大时收紧，而不是放宽
    F_ub = F_ub + cfg.L_F * rt.residual_hat
    F_max = cfg.F_max - cfg.L_F * rt.residual_hat

    if F_ub > F_max or norm(tau_ext) > cfg.tau_hard_max:
        return Veto(reason="force_envelope")      # 只能收缩
    if rt.seq_gap or rt.deadline_missed:
        return Veto(reason="stale_evidence")       # 证据不新也否决
    return Allow()                                 # 注意：Allow 不等于授权
```

### IP-60 残差见证与仿真到现实间隙
```
def update_residual(rt, calib):
    r = rt.tau_meas - rnea(rt.q, rt.dq, rt.ddq) - friction(rt.dq)
    # 时间尺度分离：持续/跨任务 = 模型残差；瞬态/随接触几何变化 = 接触残差
    if is_persistent(r, calib.window) and not contact_like(rt):
        calib.r_model_buf.append(max(0.0, abs(r) - calib.r_contact_floor))
    R_hat = evt_quantile(calib.r_model_buf, calib.beta)   # sound 上界估计
    leaky_update(rt.residual_hat, R_hat, calib.alpha)
    return rt.residual_hat

def inflate_lease(lease, residual_hat, cfg):
    lease.lam = cfg.L_m * (cfg.v_max + cfg.c_res * residual_hat)
    return lease       # 只让租约更快过期，绝不延长
```

### IP-61 RCR：源时间租约、seq 缺口与纪元绑定
```
def cert_valid(c, t_now, last, qos):
    if c.seq <= last.seq:            return False   # 回退 / 重复
    if c.seq != last.seq + 1:        return False   # CycloneDDS 无 message-lost 事件
    if qos.deadline_missed:          return False
    if qos.liveliness_lost:          return False
    if t_now - c.ts_src > c.L:       return False
    age = t_now - c.ts_src
    return c.m - c.lam * age - c.lam * c.delta_e2e >= c.theta

def gate_command(cmd, gate, t_now):
    if cmd.cert_epoch != gate.latest_valid_epoch:
        return SafeStop(reason="epoch_mismatch")    # 防 TOCTOU
    if not cert_valid(gate.cert, t_now, gate.last, gate.qos):
        return SafeStop(reason="stale_certificate")
    return cmd

def compile_cert_qos(cert_class):
    # grant 必须可靠且不允许静默丢失；veto 要求最短 deadline
    return {
        "grant":     QoS(reliable=True,  keep_last=1, deadline=D_g, lifespan=L_g,
                         liveliness=LEASE(lease_g)),
        "veto":      QoS(reliable=True,  keep_last=1, deadline=D_v, lifespan=D_v,
                         liveliness=LEASE(lease_v)),
        "heartbeat": QoS(reliable=False, keep_last=1, deadline=D_h, lifespan=D_h,
                         liveliness=LEASE(lease_h)),
    }[cert_class]
```

```
def independence_test(torque_log, percept_log, fault_cases):
    events = make_common_mode_events(fault_cases)   # 透明/反光/遮挡 × 接触
    p_t = miss_rate(torque_log, events)
    p_s = miss_rate(percept_log, events)
    p_c = joint_miss_rate(torque_log, percept_log, events)
    rho = corr(residual_series(torque_log), disagreement_series(percept_log))
    ok = (p_c <= EPS_IND) and (rho <= RHO_MAX)

def replay_and_audit(bag_path, cert_pipeline):
```

## 5. 与 UniBot / G1 的落地路径

1. **底座事实**：G1 为 29 DoF 人形（腿 6×2、腰 3、臂 7×2），低层状态可读到 `tau_est`（估计力矩）与部分型号的足端力；官方 `unitree_ros2` 走 CycloneDDS，G1 底层与 ROS 2 在 DDS 层兼容，可用 `ros2_control` 的 `effort` 状态 / 命令接口接入。**注意 `tau_est` 不等于独立标定力矩传感器**，因此先做 E101 独立性测量，再决定它能否降低感知保守性。
2. **部署拓扑**：选手模型在推理主机，通过标准化 API / DDS 桥接入 G1。L0 TRF 跑在机器人侧 `ros2_control` 硬件接口（1 kHz，只否决）；L1–L4 慢证书在推理侧（10–30 Hz）；证书样本经 DDS 发布，携带 `(e, s, ts_src, δ_e2e)`。
3. **端到端预算**：把 `δ_e2e` 拆成传感、推理、DDS、桥、网络、执行六段；每段有上界，总预算超限则只保留 TRF + 保持 / 降速，不继续用陈旧语义证书。这直接对应 UniBot「远程部署模型 + 标准化 API」的评测形态。
4. **任务映射**：32 项桌面任务中的抓取 / 放置 / 双手协调天然是接触密集任务，最适合以力域证书取代“纯视觉间隙”保守判断；透明 / 反光 / 遮挡正是 E97/E101 的共同模式测试集。
5. **最小可行版本（先做窄的）**：只实现「τ_ext + σ_min 力域否决 + cert_epoch 命令绑定 + 源时间租约」四项，不引入 R̂ 自适应与投机并行；先在 Isaac Sim + rosbag2 重放上过 E95/E96/E98/E99，再上实机。

## 8. 本轮最大风险

**一句话**：G1 上可用的“力矩”很可能只是电流 / 模型估计的 `tau_est`，它与控制器共享同一套电机与动力学假设——一旦把这种**同源信号**误当成“物理独立见证”，再叠加 ROS 2 默认 QoS 与执行器的静默丢包 / 串行化，快通道就会在“看起来 sound”的同时既陈旧又自我指涉；因此 E101（物理独立性）与 E98（QoS-lease）必须设为红线实验，默认安全底线始终是硬件力矩 / 电流限幅 + 独立 e-stop。
