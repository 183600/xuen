# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「路径规划」×「智能体」）

> 第 54 轮把技能组合升级为动作空间剖面 α_S、组合图 G_S 与云边联合证书 J。本轮从「路径规划」与「智能体」切入，发现一个被忽略的断点：**证书是路径相关的状态量，而非路径无关的边权**；同时，**执行路径的智能体对自身能力只有一个可能失校准的自证书**。核心矛盾：H22：局部边证书 sound 不推出整条路径 sound，路径越长、上下文漂移越大，证书债务越高；H23：用未校准自证书做规划等价于在失真地图上求测地线，多智能体交接时证书也无法隐式传递。

## 0. 直觉与动机

**灵感 1（从"路径"到"证书路径"：局部 sound 不等于全局 sound）**
直觉：第 54 轮的 SCOM 把每条边附上证书，然后做最短路，隐含假设"证书可像边权一样沿路径无损相加"。但执行是有状态的：每走一步都会引入动作对齐漂移、分布偏移、热耗与标定误差。于是真正该规划的对象不是状态路径，而是 **证书配置路径** `π = χ_0→χ_1→…→χ_n`，`χ=(x,J)`。一条路径必须满足 **前缀不变式**：任何前缀都不能先把证书"透支"再靠后续动作补回来。这把"路径可行性"从终点检查变成全程可监控的不变式。

**灵感 2（从"最短"到"证书测地线"：风险敏感路径规划）**
直觉：如果漂移随动作偏离而放大，`δ_k = δ_0·(1+κ·||a_k-a*||)`，那么"最短路径"恰好可能贴着动作空间边缘走，成为 **证书债务最高的路径**。正确目标应是在由鲁棒性退化、动作对齐成本和能耗共同诱导的 **证书度量** 下求测地线：`d_J(χ_a,χ_b)=inf_π∫[λ_ρ(1-ρ)+λ_a c_align+λ_e e+λ_d Ḋ]dt`。因为漂移有方向性，`d_J` 一般不对称，路径规划变成 **有向准度量上的风险敏感搜索**，A* 必须使用有向一致启发式。

**灵感 3（从"能力"到"自证智能体"：自证书是被校准出来的，不是声称出来的）**
直觉：执行智能体对自身能力的认知是一个 **自证书** `S_self=(α_self,ρ_self,κ_self,E_self)`，其中 `κ_self(a)` 是它对动作成功率的自评。自评会系统性过度自信，尤其在新环境。于是必须区分"声称能做的"与"校准后敢承诺的"：用 conformal prediction 在标定集上把 `κ_self` 转成 **校准能力包络** `E_self(θ,τ)`，智能体只在包络内做自我承诺。这把"智能体"从一个执行器变成 **带有限样本保证的自证实体**。

**灵感 4（从"执行"到"认知路径规划"：路径也是获取证据的路径）**
直觉：当自证书不确定性高时，最优策略不是硬走任务路径，而是插入 **认知动作**（探测、试探、短程标定）来降低证书不确定性。定义信息增益 `IG(e)=I(J;z|H)` 与认知预算 `B_epi`，目标从"最短"变为"任务收益−风险+信息增益"的双目标 Pareto：一条既推进任务、又沿路把"未知"变成"已证"的 **认知测地线**。关键是给探索设硬预算，防止智能体用"再测一下"无限拖延任务。

**灵感 5（从"单智能体"到"多智能体交接证书"：证书不能靠默契传递）**
直觉：多智能体路径规划的难点不在各自走路，而在 **交接点**。在 rendezvous `(x_r,t_r)` 上，接收方必须能闭合 `H_{i→j}=(A_i∩A_j⊇A_task, ||ρ_i−ρ_j||_∞≤ε_ρ, T_{i→j})`。信任传递算子 `T` 必须 **非扩张**，否则链式交接会把局部过度自信逐级放大。多智能体路径的可行性 = 各段证书保持 **且** 每个交接闭合，形成一个可审计的证书链。

**灵感 6（"证书债务账本"作为跨轮粘合剂）**
直觉：第 54 轮的联合证书 J 只描述"当前能力快照"，没有描述"能力如何随路径消耗"。本轮给它配一个 **债务账本** `Ledger(π) = {Δ_i, Res_k}`，记录每一步的退化与残差。Explain 一旦触发，就能定位到账本中第一个违反单调性的前缀，做 **后缀重规划** 而不是全局重来。这让第 53 轮的 Explain 与第 54 轮的 J 真正闭环。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（证书配置与证书路径）**
证书配置 `χ=(x,J)`，`x∈X` 为物理/任务状态，`J` 为定义 120 的联合证书。证书配置空间 `𝕏 = X × 𝕁`。证书路径 `π = χ_0→…→χ_n`，边 `e_i=(χ_{i-1},χ_i)` 带局部证书 `J_i` 与退化算子 `Δ_i`。路径证书
```
J_π = ⊕_{i=1}^{n} J_i ,   ⊕ 单调：J_i ⊒ J_i' ⇒ (J_{i-1}⊕J_i) ⊒ (J_{i-1}⊕J_i')
D(π) = Σ_i ||J_{i-1} ⊖ J_i||_w
```
路径 **B-可采纳** 当且仅当对每个前缀 `π_{0:k}` 有 `D(π_{0:k}) ≤ B_k`（前缀预算可随进度增长，但不允许先透支后补偿）。

**定义 122（证书残差与路径保持性）**
需求 `J_req`。残差 `Res(π) = J_req ⊖ J_π`（逐分量取正部）。路径 **J_req-保持** 当且仅当
```
Res(π) = 0  ∧  ∀k, Res(π_{0:k}) 单调不增
```
即终点满足需求，且途中任何前缀都不允许"先违反后恢复"。这把第 54 轮的单点可部署条件提升为整条路径的 **前缀不变式**。

**定义 123（证书度量与证书测地线）**
有向准度量
```
d_J(χ_a,χ_b) = inf_{π:a→b} ∫_0^1 [ λ_ρ(1-ρ(t)) + λ_a·c_align(t) + λ_e·e(t) + λ_d·Ḋ(t) ] dt
```
证书测地线 `π*_J = argmin_π d_J`。`d_J` 一般不对称（漂移与方向相关），且三角形的成立依赖 `Δ` 的可加性假设（见 A30）；搜索时用有向一致启发式 `h(χ)=d_J(χ,goal)` 的下界（由 ρ 上界与 c_align 下界构造）。

**定义 124（智能体自证书与校准能力包络）**
自证书 `S_self=(α_self,ρ_self,κ_self,E_self)`，`κ_self:A→[0,1]` 为动作成功率自评，`E_self` 为标定证据。校准间隙 `Δ_cal = sup_c |P(success | κ_self=c) − c|`；**τ-校准** 指 `Δ_cal ≤ τ`。**校准能力包络**
```
E_self(θ,τ) = { a∈A : κ_self(a) ≥ θ + τ }
```
并要求真实成功率下界 `P(success|a) ≥ θ`（由 conformal 有限样本覆盖保证）。智能体只在 `E_self` 内做自我承诺。

**定义 125（认知动作与认知路径规划）**
认知动作 `e∈A_epi` 产生观测 `z`，信息增益 `IG(e)=I(J;z|H)`。认知路径目标
```
U(π) = E[success] − λ_c·C(π) − λ_r·Risk(π) + λ_i·Σ_{e∈π∩A_epi} IG(e)
s.t.  Σ_{e} cost(e) ≤ B_epi ,  H(J|π) ≤ H_max
```
其解为任务-认知双目标 **Pareto 测地线**：既推进任务，又沿路降低证书不确定性。

**定义 126（多智能体交接证书）**
交接点 `(x_r,t_r)` 上，交接证书
```
H_{i→j} = ( A_i∩A_j ⊇ A_task ,  ||ρ_i−ρ_j||_∞ ≤ ε_ρ ,  T_{i→j} )
```
`T_{i→j}` 为信任传递算子，须 **非扩张**：`||T_{i→j}(ρ)|| ≤ ||ρ||`。多智能体路径 `π_1⊎…⊎π_m` **证书连续** 当且仅当每段保持、每个交接闭合、且链式交接满足 `T_{i→k} ⊒ T_{i→j}∘T_{j→k}` 而不放大误差。

## 2. 关键算法 伪代码

### IP-121 CPP（Certificate-Preserving Path planning）

```python
def cert_path_plan(G_chi, chi0, J_req, B, metric):
    open = heap([(h(chi0), 0.0, chi0, empty_cert(), empty_path())])
    best = {chi0: 0.0}
    while open:
        f, g, chi, J_acc, path = heappop(open)
        if residual(J_acc, J_req) == 0 and prefix_sound(path):
            return path
        for e in G_chi.successors(chi):
            J_new = compose(J_acc, e.J)
            if debt_of(J_new) > budget(prefix_len(path) + 1):
                continue                      # 前缀预算硬约束，禁止透支
            g2 = g + metric.edge_cost(chi, e, J_new)
            if g2 >= best.get(e.dst, inf):
                continue
            best[e.dst] = g2
            heappush(open, (g2 + h(e.dst), g2, e.dst, J_new, path + [e]))
    return None
```

### IP-122 CGM（Certificate Geodesic Metric）

```python
def certificate_geodesic(G_chi, s, goal, w):
    # 有向准度量：先用势函数 phi 把边权变换为非负 reduced cost
    phi = feasible_potential(G_chi, w)        # 满足 w(e)+phi[v]-phi[u] >= 0
    dist, parent = {s: 0.0}, {}
    pq = [(0.0, s)]
    while pq:
        d, u = heappop(pq)
        if u == goal:
            return reconstruct(parent, goal), d + phi[goal] - phi[s]
        for v, e in G_chi.out_edges(u):
            nd = d + w(e) + phi[v] - phi[u]
            if nd < dist.get(v, inf):
                dist[v], parent[v] = nd, u
                heappush(pq, (nd, v))
    return None, inf

def w(e):  # 证书度量边权
    return (LAM_RHO*(1 - e.J.rho_min) + LAM_A*(1 - e.compat)
            + LAM_E*e.energy + LAM_D*e.debt_rate)
```

### IP-123 SCA（Self-Certifying Agent）

```python
def calibrate_self_cert(agent, calib_set, alpha=0.05):
    # split-conformal：非一致性分数 = 1 - 自评成功率
    scores = sorted(1.0 - agent.kappa(x) for x in calib_set)
    q = scores[min(len(scores)-1, ceil((len(scores)+1)*(1-alpha)) - 1)]
    def lower_bound(a):
        return max(0.0, agent.kappa(a) - q)
    return SelfCert(alpha=agent.alpha_self, rho=agent.rho_self,
                    kappa_lb=lower_bound, envelope={a for a in agent.A
                    if lower_bound(a) >= THETA}, evidence=calib_set)
```

### IP-124 EPP（Epistemic Path Planning）

```python
def epistemic_path_plan(G_chi, J_req, B_epi, H_max):
    frontier = [Node(chi0, belief0, task=0.0, epi_cost=0.0, H=H0)]
    while frontier:
        n = pop_max_utility(frontier)          # 按 U 的乐观上界排序
        if residual(n.J, J_req) == 0 and n.H <= H_max:
            return n.path
        for e in task_actions(n) + info_actions(n):
            c = e.cost if e.is_epistemic else 0.0
            if n.epi_cost + c > B_epi:
                continue                        # 认知预算硬上限
            child = n.apply(e)
            child.voi = IG(e) - LAM_C * c
            if child.voi < -TAU_VOI:            # 低价值信息动作剪枝
                continue
            push(frontier, child)
    return None
```

### IP-125 MAH（Multi-Agent Handoff Certificate）

```python
def multi_agent_handoff_plan(agents, task, rendezvous, eps_rho):
    best = None
    for r in rendezvous:
        if not all(handoff_closed(i, j, r, task, eps_rho)
                   for i, j in handoff_edges(agents)):
            continue
        plan = concat(cert_path_plan(a.G, a.chi, task[a.id], a.B) for a in agents)
        if plan and trust_chain_nonexpansive(plan):
            best = min(best, plan, key=total_cost)
    return best
```

def certificate_replan(path, event, J_req):

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| CPP | O(|𝕏| log|𝕏| + |E_χ|) | O(|𝕏|) | 前缀预算闭合、启发式有向下界 |
| CGM | O(|E_χ| + |𝕏| log|𝕏|) | O(|𝕏|) | 势变换非负、准度量方向正确 |
| SCA | O(|A|·|E_self|) | O(|E_self|) | conformal 可交换性、覆盖 ≥1−α |
| EPP | O(|𝕏|·|A_epi|·|H|) | O(|𝕏|·|H|) | VOI 可估、认知预算硬约束 |
| MAH | O(m·|𝕏| log|𝕏| + |R|·m²) | O(m·|𝕏|) | 交接闭合、T 非扩张 |
| CRR | O(|π_suffix|·|𝕏| log|𝕏|) | O(|𝕏|) | 违反点定位 sound、预算重设单调 |

**正确性定理（Certificate-Preserving Path Soundness, CPPS）**
在 (A22)–(A28) 承接第 54 轮的基础上，假设：
**(A29)** 局部边证书由结构化仿真校准，单边 soundness 误差 ≤ β_E；
**(A30)** 组合算子 ⊕ 单调且债务可加（`D(π_1⊎π_2)=D(π_1)+D(π_2)`），路径 B-可采纳；
**(A31)** 自证书在运行分布上 τ-校准（conformal 可交换性成立）；
**(A32)** 交接证书闭合且信任算子 `T` 非扩张。
则
```
P(mission success) ≥ 1 − Σ_d max(0, ρ_req(d) − ρ_π(d)) − β_E − τ − P(D(π)>B) − P(handoff fail)
```
关键：**路径级 soundness 来自前缀不变式，而非终点抽查**；**自证承诺来自校准下界，而非自评**；**多智能体安全来自交接闭合与非扩张信任，而非默契**。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 证书度量不满足三角不等式或方向错判 | 高 | 有向一致启发式下界 + 势函数变换 + 在线三角审计 |
| 自证书在分布漂移下失校准 | 高 | conformal + 滑窗重校准 + 漂移检测熔断 |
| 认知动作拖累任务进度 | 中 | VOI 阈值 + 认知预算硬上限 + anytime 回退任务路径 |
| 多智能体信任链逐级放大 | 高 | 非扩张 T + 链长惩罚 + 交接红队与断链回滚 |
| 债务预算过保守导致无解 | 中 | 分级预算 + "债务换能"（降速/降精度/换技能）机制 |

## 6. 本轮最大风险

**一句话**：证书路径规划与自证智能体把"路径"从最短几何升级为"可审计的证书测地线"，但其 soundness **三重依赖证书度量的准度量性质、自证书在分布漂移下的校准保持、以及多智能体信任传递的非扩张性**；一旦证书度量三角不等式失效导致 A* 剪掉真正安全路径、或自证书在新环境中过度自信，智能体会以"已校准"的姿态走完一条形式上优雅、实际上高债务的路径，故必须以 **在线度量审计 + conformal 滑窗重校准 + 信任链非扩张硬约束** 三重护栏，宁可承认"当前不可证"，绝不把"证书路径"当作"安全路径"。

### IP-121 CPP

```python
def cert_path_plan(G_chi, chi0, J_req, B, metric):
    open = heap([(h(chi0), 0.0, chi0, empty_cert(), empty_path())])
    best = {chi0: 0.0}
    while open:
        f, g, chi, J_acc, path = heappop(open)
        if residual(J_acc, J_req) == 0 and prefix_sound(path):
            return path
        for e in G_chi.successors(chi):
            J_new = compose(J_acc, e.J)
            if debt_of(J_new) > budget(prefix_len(path) + 1):
                continue
            g2 = g + metric.edge_cost(chi, e, J_new)
            if g2 >= best.get(e.dst, inf):
                continue
            best[e.dst] = g2
            heappush(open, (g2 + h(e.dst), g2, e.dst, J_new, path + [e]))
    return None
```

### IP-122 CGM

```python
def certificate_geodesic(G_chi, s, goal, w):
    phi = feasible_potential(G_chi, w)       # w(e)+phi[v]-phi[u] >= 0
    dist, parent = {s: 0.0}, {}
    pq = [(0.0, s)]
    while pq:
        d, u = heappop(pq)
        if u == goal:
            return reconstruct(parent, goal), d + phi[goal] - phi[s]
        for v, e in G_chi.out_edges(u):
            nd = d + w(e) + phi[v] - phi[u]
            if nd < dist.get(v, inf):
                dist[v], parent[v] = nd, u
                heappush(pq, (nd, v))
    return None, inf

def w(e):  # 风险敏感证书度量
    return (LAM_RHO*(1 - e.J.rho_min) + LAM_A*(1 - e.compat)
            + LAM_E*e.energy + LAM_D*e.debt_rate)
```

def calibrate_self_cert(agent, calib_set, alpha=0.05):
    scores = sorted(1.0 - agent.kappa(x) for x in calib_set)
    q = scores[min(len(scores)-1, ceil((len(scores)+1)*(1-alpha)) - 1)]
    def lower_bound(a):
        return max(0.0, agent.kappa(a) - q)
    return SelfCert(alpha=agent.alpha_self, rho=agent.rho_self,
                    kappa_lb=lower_bound,
                    envelope={a for a in agent.A if lower_bound(a) >= THETA},
                    evidence=calib_set)

### IP-124 EPP

```python
def epistemic_path_plan(G_chi, J_req, B_epi, H_max):
    frontier = [Node(chi0, belief0, task=0.0, epi_cost=0.0, H=H0)]
    while frontier:
        n = pop_max_utility(frontier)
        if residual(n.J, J_req) == 0 and n.H <= H_max:
            return n.path
        for e in task_actions(n) + info_actions(n):
            c = e.cost if e.is_epistemic else 0.0
            if n.epi_cost + c > B_epi:
                continue
            child = n.apply(e)
            child.voi = IG(e) - LAM_C * c
            if child.voi < -TAU_VOI:
                continue
            push(frontier, child)
    return None
```

def multi_agent_handoff_plan(agents, task, rendezvous, eps_rho):
    best = None
    for r in rendezvous:
        if not all(handoff_closed(i, j, r, task, eps_rho)
                   for i, j in handoff_edges(agents)):

## 3. 为什么最短路会系统性失败（推导）

设路径第 k 步的鲁棒性退化
```
δ_k(d) = δ_0(d) · (1 + κ_d · ||a_k − a*||)
ρ_π(d) = ρ_0(d) − Σ_k δ_k(d)
```
则最短路径（最小化 `Σ||a_{k+1}−a_k||`）只有在 `δ_k` 与动作无关时才等于最安全路径。真实场景中 `κ_d>0`，最短路径倾向贴动作空间边缘，`δ_k` 被放大；而证书测地线把 `δ_k` 直接计入边权 `w(e)`，因此会主动选择动作空间内部、对齐成本低的"安全绕行"。**结论：v31 的最短路不是 v32 的证书最短路，二者在极限动作附近系统性背离。**

## 4. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CPP | O(|𝕏| log|𝕏| + |E_χ|) | O(|𝕏|) | 前缀预算闭合、启发式有向下界 |
| CGM | O(|E_χ| + |𝕏| log|𝕏|) | O(|𝕏|) | 势变换非负、准度量方向正确 |
| SCA | O(|A|·|E_self|) | O(|E_self|) | conformal 覆盖 ≥1−α |
| EPP | O(|𝕏|·|A_epi|·|H|) | O(|𝕏|·|H|) | VOI 可估、认知预算硬约束 |
| MAH | O(m·|𝕏| log|𝕏| + |R|·m²) | O(m·|𝕏|) | 交接闭合、T 非扩张 |
| CRR | O(|π_suffix|·|𝕏| log|𝕏|) | O(|𝕏|) | 违反点定位 sound |

**正确性定理（Certificate-Preserving Path Soundness, CPPS）**
假设第 54 轮 (A22)–(A28) 成立；**(A29)** 局部边证书单边 soundness 误差 ≤ β_E；**(A30)** 组合算子 ⊕ 单调且债务可加，路径 B-可采纳；**(A31)** 自证书在运行分布上 τ-校准；**(A32)** 交接证书闭合且信任算子非扩张。则
```
P_success ≥ 1 − Σ_d max(0, ρ_req(d) − ρ_π(d)) − β_E − τ − P(D>B) − P(handoff fail)
```
与 v31 的关键差异：v31 的证书是 **点态** 的，v32 的证书是 **路径态** 的；v31 的安全性靠"每条边 sound"，v32 的安全性靠"每个前缀 sound + 债务不超预算 + 自证不越包络 + 交接不放大利己误差"。

## 6. 本轮最大风险

**一句话**：证书路径规划与自证智能体把"路径"升级为可审计的证书测地线，但其 soundness **三重依赖证书度量的准度量性质、自证书在分布漂移下的校准保持、以及多智能体信任传递的非扩张性**；一旦证书度量三角不等式失效导致 A* 剪掉真正安全路径、或自证书在新环境中过度自信，智能体会以"已校准"的姿态走完一条形式上优雅、实际上高债务的路径，故必须以 **在线度量审计 + conformal 滑窗重校准 + 信任链非扩张硬约束** 三重护栏，宁可承认"当前不可证"，绝不把"证书路径"当作"安全路径"。
