# 第 69 轮（承接第 68 轮「CALM-RAS 自标定风险自适应闭环」IP-243~252；灵感循环新循环第 2 轮；本轮灵感：「机器人基础模型」×「语义分割」）

> 第 68 轮 CALM-RAS 把「标定」升级为在线潜变量，问出了「我的测量还准吗」，却也在自陈风险里留下一个结构性缺陷：**它的全部参照都来自系统自身**——跨模态环一致 r_geo、WM 残差 r_wm、静态段自标定 r_zero，本质是「用自己校验自己」。当所有模态被同一扰动推动（共同模式漂移：整机温漂、统一坐标系偏移、同源固件 bug），R68 的标定会把这种漂移当成一致噪声整体吸收，残差恒为 0——**自指涉参照对共模漂移的检出增益结构性为零**。这正是「缓变故障被标好」的原罪：不是滤得不够快，而是根本没有站在系统之外的尺子。
>
> 本轮的两块灵感恰好提供了系统之外的「参照标准」与「可审计的中层语言」：**机器人基础模型**（跨本体语义先验）与**语义分割**（像素级、开放词表、可检验的落地表征）。核心命题：
>
> **把参照系从系统内部搬到系统外部——用跨本体机器人基础模型提供与部署传感器近似独立的语义先验，用开放词表语义分割把它落地成可检验的语义计量层；系统第一次拥有「三重独立见证」，能区分「传感器漂了 / 参照自己漂了 / 世界真的变了」——SEM-RAS（Semantic External-reference Metrology RAS）。**
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「**我的参照本身可信吗**」——当参照之间互相矛盾时，系统不再赌，而是降级为最坏情况。

## 0. 直觉与动机

**灵感 1（机器人基础模型 → 唯一近似「外部」的参照标准）**
直觉：计量学区分「漂移」与「变化」，靠的是**溯源到外部标准**，而不是自证。R68 缺的正是这个：它把标定当作自洽回归，所有证据都来自同一条正在漂移的传感器链。机器人基础模型（RFM）在成千上万本体、场景、传感器上预训练，其语义先验的误差与本台机器人此刻的漂移**近似不相关**（ρ_ref 小）。它就像计量实验室里那台「与生产设备无关的基准仪」：价值不在于更准，而在于**错得不一样**。这就是打破循环论证的支点。

**灵感 2（语义分割 → 把不可审计的基础模型变成可审计的中层语言）**
直觉：RFM 是十亿参数黑箱，直接审计它等价于审计一切。语义分割是天然的**中层表征（interlingua）**：像素级、开放词表、可被几何/触觉/语言交叉检验、可被低维安全盾消费。把 RFM 的隐式场景理解投影到分割空间（预期影响区域、可通行性、可供性），就把「信任一个黑箱」换成「在可检验的语义空间里比对两个作者（author）」。分割不是又一个感知头，而是**黑箱与证书之间的罗塞塔石碑**。

**灵感 3（三重见证 → 从「自证」到「独立互证」）**
直觉：要同时区分四种成因（传感器可标定漂移 H_cal、传感硬故障 H_sensor^trans、参照自身漂移 H_ref、世界真新奇 H_novel），至少需要三个**彼此误差不相关**的见证：T0 系统自洽（R68 残差）、T1 语义地标/几何落地（外部标准物）、T2 RFM 跨本体先验。三见证的残差签名矩阵 W（4 成因 × m 观测）必须满列秩；若参照之间高相关，W 条件数爆炸，三角定位退化为「互相背书」——所以必须**显式估计并约束参照相关性 ρ_ref**，这是 R68 完全没有的变量。

**灵感 4（共模漂移 → R68 的最大风险第一次被形式化地堵上）**
直觉：R68 的标定只能吸收落在标定雅可比张成空间内的漂移；共模漂移恰好整体落在其中，于是被「标好」。外部参照的残差不落在这个子空间里，因此即便所有模态同步漂移，外部残差仍保留 (1−ρ_ref) 倍的分量（引理 17）。**参照越独立，可检测的漂移子空间越大**；ρ_ref→1 时退化回 R68。参照独立性与初值精度一样，是必须在证书里被量化、被版本化的计量学量，而不是一句口号。

**灵感 5（开放世界 → 第四种成因：世界真的变了）**
直觉：R68 的假设集是闭集（cal/fault/real），但真实世界会出现词表外的新物体、新材质、新危险源。开放词表分割给出**本体漂移（ontology drift）**信号：持续高熵、空间相干的「未知区」不是噪声，而是「我的本体不够用了」。正确反应不是强行归类，而是扩展本体或保守停驻——这是 R68 无法表达的第四类归因。

**灵感 6（双系统 → 安全层绝不能依赖慢而黑的基础模型）**
直觉：RFM 推理 50–200ms，控制环要求毫秒级。若把安全判定挂在 RFM 上，等于把刹车交给最慢、最不可解释的部件。架构必须是双系统：RFM 在 5–10Hz 的 deliberative 层提议动作块与语义先验；语义盾在 <3ms 的 reactive 层只消费低维语义风险场与计量后残差。**基础模型负责上限，计量 + 盾负责下限。**

**灵感 7（合流 → SEM-RAS 七组件）**
1. **RFM†**：冻结（或轻量 LoRA）的跨本体基础模型，提供动作块 + 语义先验 + 可供性先验；
2. **SGS** Semantic Grounding Stack：开放词表分割 + 实例掩码 + 场景图 + 可供性图；
3. **SMH** Semantic Metrology Hierarchy：T0/T1/T2 三层参照 + 溯源图 + 参照信任 ψ；
4. **SRA** Semantic Reference Attribution：三见证三角定位（升级 R68 的 CFA，四成因）；
5. **SOD** Semantic Ontology Drift：开放世界本体漂移检测与候选新类提案；
6. **SSD** Semantic Shield Dispatch：低维语义风险场 → λ/k（快速安全盾）；
7. **CAC-S** Certified Semantic Commit：在 R68 五关上加「参照独立性 / 语义 canary / 可溯源」三关。
继承核 **CALM-RAS†**：MTM/COF/CFA/CAC 全部保留，只是被 SMH/SRA 从外面包了一层外部参照。

## 1. 形式化定义（增量：定义 293–310）

**定义 293（SEM-RAS 总览）** SEM-RAS = (RFM†, SGS, SMH, SRA, SOD, SSD, CAC-S, CALM-RAS†)。三条新不变式：
(i) **参照独立性**：外部参照与部署传感器链的误差相关系数 ρ_ref ≤ ρ_max（默认 0.5），超界则该参照降权；
(ii) **语义可溯源**：任一 λ/k 决策必须能追溯到 ≥2 个独立参照层的证据链（溯源图中存在长度 ≥2 的见证路径）；
(iii) **参照不确定只收紧**：min_i ψ_i < τ_ψ ⇒ λ_floor 抬升、k 收缩，绝不放宽。

**定义 294（RFM† 与参照独立性假设 A95）** π_RFM: (o_t, ℓ, q_t) → (A_t^{chunk}, p_RFM(·|o_t))，其中 A 为动作块、p_RFM 为语义先验（像素/实例标签分布 + 可供性）。A95：RFM 在 N_emb 个本体上训练，与本台部署传感器漂移的误差相关系数 ρ_ref ≤ ρ_max。注意 A95 是**可证伪的工程假设**，不是自然律——见第 6 节。

**定义 295（SGS 语义落地栈）** Seg_φ: o_t → {p_t(x, c)} + {mask_i} + 场景图 G_t=(对象, 关系, 可供性) + 可供性图 F_t ∈ [0,1]^{H×W×K}（可通行/可抓取/易碎/人）。开放词表：任意文本查询 c 可即时查询，无需闭集类别。

**定义 296（语义计量层级 SMH）** 三层见证：
- T0（自洽）：R68 残差 r_t^{(0)} 与标定 ĉ；
- T1（地标）：已知语义类且几何已知的标准物/标定板/Fiducial 的度量残差 r^{(1)} = pose_meas − pose_canonical；
- T2（先验）：RFM 语义先验与分割的跨作者残差 r^{(2)} = D_KL(p_seg ‖ p_RFM) + d_edit(G_seg, G_RFM)。
参照信任 ψ=(ψ_0,ψ_1,ψ_2)，由各自残差历史、与其余见证的独立性、以及漂移检测器在线更新。

**定义 297（语义地标标定 SLC）** 对地标集 L：ĉ = argmin_c Σ_{l∈L} ‖r_l^{(1)}(c)‖²_{Σ_l}，其中 Σ_l 随分割置信度与未知质量 M_unk 放大。这把 R68 的 COF 从「自洽回归」升级为「溯源到外部标准的回归」——地标是外部标准，不是自证。

**定义 298（语义参照残差 SRR）** r^{(2)}_t = α·D_KL(p_seg(·|x) ‖ p_RFM(·|x)) + β·d_edit(G_seg, G_RFM) + γ·‖F_seg − F_RFM‖。跨作者而非跨模态：两者若同错，说明共享了同一个错误世界模型（这时独立性也失效，见第 6 节）。

**定义 299（三见证三角定位 SRA）** 观测残差 r = (r^{(0)}, r^{(1)}, r^{(2)})ᵀ ∈ ℝ^m，成因 δ = (δ_cal, δ_trans, δ_ref, δ_novel)ᵀ。线性化见证模型 r = W δ + n，W ∈ ℝ^{m×4} 为各成因的残差签名矩阵。后验 ∝ p(r|δ)p(δ)，δ̂ = (WᵀΣ⁻¹W)⁻¹WᵀΣ⁻¹r；若 κ_ind = σ_min(WᵀΣ⁻¹W) < κ_min 则判不可辨识，退回最坏情况归因。

**定义 300（参照相关性估计）** ρ_ref = corr(e_ref, e_sensor)，用三类探针估计：跨本体残差相关、传感器扰动受控实验、留出地标的交叉验证。若 ρ_ref > ρ_max，则 ψ_2 ← ψ_2·(1−ρ_ref)/(1−ρ_max)，并在证书中记录。**ρ_ref 是 SEM-RAS 新增的一等公民量。**

**定义 301（语义本体漂移 SOD）** 未知质量 M_unk(t) = (1/|Ω|)∫_Ω 1[H_x > τ_H] dx，其中 H_x 为像素标签熵；本体漂移判据：M_unk 持续 > τ_M 且空间相干长度 > ℓ_coh ⇒ H_novel。输出候选新类提案 + 保守等级，不强行归类。

**定义 302（语义风险场 SRF）** R_sem(x) = Σ_c w_c·F_c(x)·risk(c)，risk 表：人 1.0、玻璃 0.9、液体/线缆 0.7、未知 0.6（保守）、可通行 0.0。这是低维、可审计、可快速计算的安全信号。

**定义 303（语义盾调度 SSD）** λ_sem = σ(∫R_sem dx)；k_sem = max{k: A[:k] ⊂ Safe_sem}，Safe_sem = {轨迹 | 途经 R_sem < τ_R 且不穿越人/未知高险区}。最终 k = min(k_RAS, k_cal, k_sem)，λ = max(λ_RAS, λ_floor(U,ψ), λ_sem)。

**定义 304（参照感知下限）** λ_floor(U, ψ) = max(0.6, 0.8·1[U > τ_cal ∨ min_i ψ_i < τ_ψ])；这是 R68 定义 285 的二维扩展：测量不可信与参照不可信都只收紧。

**定义 305（SEM 目标族）** L_SEM = λ_land·1[L]‖r^{(1)}‖² + λ_srr·r^{(2)} + λ_ont·L_ont（未知区对比/熵正则）+ λ_cal·L_cal(R68) + λ_seg·L_seg^{self}（时域掩码一致、跨视图一致）。T1/T2 也用于自监督，但**只进影子流**，实时零写操作不变式保留。

**定义 306（CAC-S 认证式语义提交）** 在 R68 五关（金标回归 / 审计回放 / 分布界 / 风险界 / canary 不可修复）外加三关：
6. **参照独立性关**：adapter 诱导的 ρ_ref ≤ ρ_max；
7. **语义 canary 关**：危险类 canary（人/玻璃/液体的合成样本）不得被重分类为低风险，若 risk 下降 > 30% 一票否决；
8. **可溯源关**：新决策路径在溯源图中存在 ≥2 层独立见证。
全过 → 双缓冲原子换装；否则拒绝并记入 ℰ_ref/ℰ_ont。

**定义 307（J_SEM 证书）** J_SEM = (J_CALM, ψ, ρ_ref, ontology_version, semantic_canary_verdict, srr_stats, sem_ver)。Valid ⇔ Valid(J_CALM) ∧ ρ_ref ≤ ρ_max ∧ ψ_min ≥ τ_ψ ∧ 语义 canary PASS ∧ 可溯源关 PASS。

**定义 308（AIC-SEM 干扰集）** ℰ_SEM = ℰ_CALM × ℰ_ref × ℰ_ont × ℰ_shield；ℰ_ref = {参照污染、相关失效、地标投毒}；ℰ_ont = {本体坍缩、新奇物伪装、语义对抗补丁}；ℰ_shield = {盾过宽、人/危险类误分割、梯度掩蔽}。

**定义 309（双系统管线）** 离线：RFM 冻结 + SGS 训练 + 风险表标定 + 地标库建立 → CAC-S 首提交。在线：慢环（5–10Hz）RFM 出动作块与语义先验；快环（控制率）SGS 分割 + SMH 残差 + SRA 归因 + SSD 盾；每 60s 影子训练 + CAC-S 认证换装；异步审计「这次把参照漂移误判成传感器漂移了吗？」

**定义 310（审计投影 Π_seg）** Π_seg: RFM 的隐式归因（对动作块的注意力/梯度/预测可供性）→ 分割空间中的预期影响区域与可供性图。Π_seg 使黑箱可被低维语义盾比对，是「RFM 提议、SGS 落地、SMH 计量、SSD 否决」的接口。

```python
# IP-253/254 RFM† + SGS：慢环提议、快环落地
class FoundationSemanticStack:
    def __init__(self, rfm, seg):
        self.rfm, self.seg, self.cache = rfm, seg, SemanticCache()

    @torch.no_grad()
    def slow_loop(self, obs, goal, q):
        A_chunk, prior = self.rfm(obs, goal, q)        # 5-10Hz，动作块 + 语义先验
        self.cache.update(A_chunk, prior, t=now())     # 带时间戳，供快环消费
        return A_chunk, prior

    def fast_loop(self, obs):
        p_seg, masks, G, F = self.seg(obs)             # 开放词表分割 + 场景图 + 可供性
        return SemanticObs(p_seg, masks, G, F)


# IP-255/256/257 SMH：三层见证 + 语义地标标定 + 跨作者残差
class SemanticMetrologyHierarchy:
    def residual_t0(self, obs, cal):   return residuals_r68(obs, cal)        # 自洽
    def residual_t1(self, G, landmarks): return landmark_residual(G, landmarks)  # 外部地标
    def residual_t2(self, p_seg, p_prior, G_seg, G_prior):
        return (KL(p_seg, p_prior), graph_edit(G_seg, G_prior))              # 跨作者
    def calibrate(self, G, landmarks, c0):
        L_eff = [l for l in landmarks if seg_confidence(l) > tau]
        return argmin_c sum(norm(landmark_residual(l, c))**2 / Sigma_l for l in L_eff)


# IP-258 SRA：四成因三角定位（不可辨识即最坏情况）
def triangulate(r0, r1, r2, W, Sigma, kappa_min):
    r = concat([r0, r1, r2])
    A = W.T @ inv(Sigma) @ W
    kappa = smallest_eig(A)
    if kappa < kappa_min:
        return worst_case_attribution()               # 参照相关/秩亏 → 不赌
    delta = inv(A) @ W.T @ inv(Sigma) @ r
    return normalize_causes(delta, kappa)


# IP-259/260 SOD + SSD：本体漂移 + 语义盾
class SemanticShield:
    def field(self, F, risk_table):                   # 定义 302
        return sum(F[..., c] * risk_table[c] for c in F.classes)

    def dispatch(self, A, R_sem, lam_ras, psi, U):
        lam_floor = 0.8 if (U > TAU_CAL or min(psi) < TAU_PSI) else 0.6
        lam = max(lam_ras, lam_floor, sigmoid(R_sem.sum()))
        k = min(certified_prefix(A), max_k_safe(A, R_sem))
        return k, lam

    def ontology_drift(self, p_seg):
        M_unk = unknown_mass(p_seg, tau_H)
        return M_unk > TAU_M and coherence(p_seg) > L_COH   # H_novel


# IP-261 CAC-S：R68 五关 + 参照独立性 / 语义 canary / 可溯源
class CertifiedSemanticCommit:
    GATES = [gold_regression, auditbuf_replay, tv_bound, risk_bound,
             canary_unfixable, reference_independence,
             semantic_canary, traceability]
    def maybe_commit(self, shadow, dt):
        if dt < T_COMMIT: return None
        verdict = {g.__name__: g(shadow) for g in self.GATES}
        if all(verdict.values()):
            atomic_swap(self.live_ptr, shadow); return 'PASS'
        log_to_esem(verdict); return 'REJECT'


# IP-264 主闭环：SEM-RAS round
def SEM_RAS_round(M, obs, goal, q):
    # 慢环（异步/缓存）：基础模型提议
    A_chunk, prior = M.fss.slow_loop(obs, goal, q)

    # 快环（控制率）：分割落地 + 三层残差 + 三角定位
    s = M.fss.fast_loop(obs)
    r0 = M.smh.residual_t0(obs, M.cal)
    r1 = M.smh.residual_t1(s.G, M.landmarks)
    r2 = M.smh.residual_t2(s.p_seg, prior, s.G, prior.graph)
    causes = M.sra.triangulate(r0, r1, r2, M.W, M.Sigma, M.kappa_min)

    # 语义盾：风险场 + 本体漂移 + 参照感知下限
    R_sem = M.shield.field(s.F, M.risk_table)
    novel = M.shield.ontology_drift(s.p_seg)
    k, lam = M.shield.dispatch(A_chunk, R_sem, M.lam_ras, M.psi, M.cal.U)
    if causes.ref_drift:   lam = max(lam, 0.8); k = min(k, k_ref_shrink)
    if novel:              lam = max(lam, 0.8); k = min(k, k_new_shrink)

    # 证书与异步审计
    M.cac_s.maybe_commit(M.shadow, M.time_since_last_commit)
    M.audit.submit_async(causes, s, {'rho_ref': M.rho_ref, 'psi': M.psi})
    return k, lam, causes, R_sem
```

## 3. 推导

**引理 16（参照独立性与可辨识性）** 记三见证残差 r = Wδ + n，W ∈ ℝ^{m×4}。最优线性无偏估计误差协方差 Cov(δ̂) = (WᵀΣ⁻¹W)⁻¹。定义独立裕度 κ_ind = σ_min(WᵀΣ⁻¹W)。若三见证误差两两相关 ≤ ρ_ref，则 Σ 的非对角使 WᵀΣ⁻¹W 收缩：κ_ind(ρ_ref) ≥ (1−ρ_ref)·κ_ind(0)，且 ρ_ref→1 时 κ_ind→0（见证线性相关）。于是 ‖δ̂ − δ‖ ≤ ‖WᵀΣ⁻¹n‖/κ_ind。**系**：当 κ_ind < κ_min 时必须判不可辨识并退回最坏情况；R68 相当于只有 T0 一个见证（m 列秩 ≤ 3 且全部相关），四成因在结构上不可分。

**引理 17（共模漂移可检性——直击 R68 原罪）** R68 的标定残差 r^{(0)} 在标定雅可比 J_cal = ∂r/∂c 的最小二乘下被投影掉：r^{(0)}_cal = (I − P_{J})r，P_J 为到 colspan(J_cal) 的投影。共模漂移 d_common 若整体落在 colspan(J_cal)（所有模态同步移动），则 (I−P_J)d_common = 0——**自洽见证对它的检出功率等于虚警率 α**。外部参照残差 r^{(1)}, r^{(2)} 含独立噪声分量，且 d_common 不落在其零空间，标定后统计量保留 (1−ρ_ref)‖d_common‖ 的均值。取阈值 τ_det，若 (1−ρ_ref)‖d_common‖ > τ_det 则检出概率 ≥ 1−δ。**系**：引入独立外部参照使可检测漂移子空间从 span(J_cal)^⊥ 扩大到整个空间减去 ρ_ref 相关方向。

**引理 18（语义锚定界）** 设地标分割误差 ≤ ε_seg、度量先验误差 ≤ ε_met、有效地标数 n_eff = (1−M_unk)·n_land。SLC 的标定误差满足 ‖ĉ − c*‖ ≤ ε_seg·κ_seg + ε_met + C·σ_noise/√n_eff。**系**：本体漂移（M_unk↑）以 1/√(1−M_unk) 的方式优雅退化，而不是突然失效；当 M_unk→1 时退化为无地标（回到 R68 自洽标定并应声降级）。

**定理 16（SEM-RAS 端到端安全）** 在 A87–A94、A95（参照独立性）与 A96–A101（有界分割误差、有界 W 条件数、有界地标误差、有界风险表误差）下，输出 τ_cmd 满足：
1. P(|τ_cmd − τ*| > ε) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_vqa + α_cal + **α_ref + α_ont**，其中 α_ref ≤ exp(−c·n_witness·(1−ρ_ref)²)（三角定位集中不等式），α_ont ≤ P(M_unk > τ_M)；
2. **共模漂移**：若 (1−ρ_ref)‖d_common‖ > τ_det，检出概率 ≥ 1−δ（引理 17）；ρ_ref→1 时退化为 R68（诚实的能力边界）；
3. **参照不可信**：min_i ψ_i < τ_ψ ⇒ λ_risk ≥ 0.8 ∧ k ≤ k_ref_shrink——参照不确定永远导向收缩；
4. **语义 canary**：危险类被语义适配器降级的概率 ≤ (1−r_sc)·p_h，r_sc ≥ 0.95。

**定理 17（认证语义提交安全性）** 八关中「参照独立性关」阻止会抬高 ρ_ref 的适配器上线（否则外部参照被同化）；「语义 canary 关」拦截把危险类重分类为低风险的对抗/后门适配器（检出率 r_sc ≥ 0.95）；「可溯源关」保证每个新决策仍有 ≥2 层独立见证。提交窗口内快环参数冻结、λ/k 连续 ⇒ 换装无控制突变；回滚失败触发全局降级（k=0、λ=1）。

## 6. 本轮最大风险

**一句话**：SEM-RAS 的全部安全增益押在「参照独立性 ρ_ref 可被持续估计并保持足够小」这一条上——**一旦 RFM 与部署传感器在训练数据、厂商、微调或环境上同源（参照污染），三见证就退化为高相关背书，见证矩阵 W 秩亏，三角定位会以更高置信度制造「共模漂移已被外部证实」的假共识；更危险的是，一个自信的 RFM 幻觉可以伪造外部共识，使系统对真实缓变故障的检出能力反而低于 R68。**

**次级风险与缓解**：
1. **语义分割自身域偏移/危险类误分割**：风险表 + 语义 canary + 人安全几何/触觉冗余（分割永不单独放行人安全）；
2. **开放词表被对抗补丁/新奇物投毒**：SOD 不自动归类，只提案；本体扩展走 CAC-S + 人工审计 + 版本链；
3. **RFM 幻觉且 Π_seg 投影不可靠**：投影保留多假设，T0/T1 兜底，参照冲突即最坏情况；
4. **双系统时序不一致（慢环动作块过期）**：动作块带时间戳与有效期，过期即收缩，快环永远可独立否决；
5. **计算预算**：RFM 冻结+量化+蒸馏+缓存，慢环不参与急停，安全只在快环；
6. **溯源图被污染（地标被移动/遮挡）**：多类地标冗余 + 未知质量门控 + 地标健康度 ψ_1 在线监控。

```python
             semantic_canary, traceability]
    def maybe_commit(self, shadow, dt):
        if dt < T_COMMIT: return None
        v = {g.__name__: g(shadow) for g in self.GATES}
        if all(v.values()): atomic_swap(self.live_ptr, shadow); return 'PASS'
        log_to_esem(v); return 'REJECT'

# IP-264 主闭环
def SEM_RAS_round(M, obs, goal, q):
    A_chunk, prior = M.fss.slow_loop(obs, goal, q)          # 慢环（异步）
    s = M.fss.fast_loop(obs)                                # 快环
    r0 = M.smh.residual_t0(obs, M.cal)
    r1 = M.smh.residual_t1(s.G, M.landmarks)
    r2 = M.smh.residual_t2(s.p_seg, prior, s.G, prior.graph)
    causes = M.sra.triangulate(r0, r1, r2, M.W, M.Sigma, M.kappa_min)
    R_sem = M.shield.field(s.F, M.risk_table)
    novel = M.shield.ontology_drift(s.p_seg)
    k, lam = M.shield.dispatch(A_chunk, R_sem, M.lam_ras, M.psi, M.cal.U)
    if causes.ref_drift: lam = max(lam, 0.8); k = min(k, k_ref_shrink)
    if novel:            lam = max(lam, 0.8); k = min(k, k_new_shrink)
    M.cac_s.maybe_commit(M.shadow, M.time_since_last_commit)
    M.audit.submit_async(causes, s, {'rho_ref': M.rho_ref, 'psi': M.psi})
    return k, lam, causes, R_sem
```

## 4. 推导

**引理 16（参照独立性与可辨识性）** r=Wδ+n。Cov(δ̂)=(WᵀΣ⁻¹W)⁻¹，独立裕度 κ_ind=σ_min(WᵀΣ⁻¹W)。三见证两两相关 ≤ ρ_ref ⇒ κ_ind(ρ_ref) ≥ (1−ρ_ref)·κ_ind(0)，ρ_ref→1 时 κ_ind→0。误差界 ‖δ̂−δ‖ ≤ ‖WᵀΣ⁻¹n‖/κ_ind。R68 实为单见证（秩≤3 且全相关），四成因结构上不可分；κ_ind<κ_min 必须退最坏情况。

**引理 17（共模漂移可检性）** R68 残差 r^{(0)}_cal=(I−P_J)r，J_cal=∂r/∂c。共模漂移 d_common 若落入 colspan(J_cal)，则被完全吸收，检出功率=虚警率 α。外部参照标定后保留 (1−ρ_ref)‖d_common‖ 均值，若 > τ_det 则检出概率 ≥ 1−δ。**系**：可检测漂移子空间从 span(J_cal)^⊥ 扩大到除 ρ_ref 相关方向外的整个空间。

**引理 18（语义锚定界）** 地标分割误差 ε_seg、度量先验 ε_met、n_eff=(1−M_unk)n_land ⇒ ‖ĉ−c*‖ ≤ ε_seg·κ_seg+ε_met+Cσ/√n_eff。本体漂移以 1/√(1−M_unk) 优雅退化；M_unk→1 退化为无地标并应声降级。

**定理 16（端到端安全）** A87–A101 下：
1. P(|τ_cmd−τ*|>ε) ≤ α_chunk+δ_fi+α_emotion+α_wm+α_vqa+α_cal+α_ref+α_ont，α_ref ≤ exp(−c·n_witness·(1−ρ_ref)²)，α_ont ≤ P(M_unk>τ_M)；
2. (1−ρ_ref)‖d_common‖>τ_det ⇒ 共模漂移检出 ≥ 1−δ；ρ_ref→1 诚实退化回 R68；
3. ψ_min<τ_ψ ⇒ λ≥0.8 ∧ k≤k_ref_shrink；
4. 危险类被语义适配器降级概率 ≤ (1−r_sc)·p_h，r_sc≥0.95。

**定理 17（认证语义提交安全性）** 参照独立性关阻止同化外部参照的适配器；语义 canary 关拦截危险类降级的对抗/后门适配器（r_sc≥0.95）；可溯源关保证新路径 ≥2 层独立见证；换装期快环冻结、λ/k 连续 ⇒ 无控制突变，回滚失败即 k=0、λ=1 全局降级。

## 7. 本轮最大风险

**一句话**：SEM-RAS 的全部安全增益押在「参照独立性 ρ_ref 可被持续估计并保持足够小」这一条上——一旦 RFM 与部署传感器在训练数据、厂商、微调或环境上同源（参照污染），三见证就退化为高相关背书，见证矩阵 W 秩亏，三角定位会以更高置信度制造「共模漂移已被外部证实」的假共识；更危险的是，一个自信的 RFM 幻觉可以伪造外部共识，使系统对真实缓变故障的检出能力反而低于 R68。

**次级风险与缓解**：语义分割域偏移/危险类误分割（风险表 + 语义 canary + 人安全几何/触觉冗余，分割永不单独放行人安全）；开放词表对抗补丁/投毒（SOD 只提案、本体扩展走 CAC-S + 人工审计 + 版本链）；RFM 幻觉且 Π_seg 不可靠（多假设投影 + T0/T1 兜底 + 冲突即最坏情况）；双系统时序不一致（动作块时间戳与有效期，过期即收缩）；计算预算（RFM 冻结+量化+蒸馏+缓存，安全只在快环）；溯源图污染（多类地标冗余 + ψ_1 健康度监控）。
