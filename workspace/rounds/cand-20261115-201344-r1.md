> R69 把「不确定」一分为二（aleatoric / epistemic），并让系统学会「问」。但它有一个从未被追问的前提：**λ 会收紧、VoI 值钱、证书 J_FLUID 成立——这一整套结论，都是在「模型的世界」里被验证的，而验证环境本身没有被审计。** R68 怕标定把故障吸收掉，R69 怕模态分布撒谎；R70 怕的是更高一层、也更隐蔽的东西——**验证台（test bench）撒谎**。一份只在自己的仿真里成立的安全证书，不是「证明」，而是「把未验证洗成已验证」。
>
> 本轮两个灵感正好补上这条缺失的「计量—验证」轴：
> - **抗干扰**给出一个关键直觉：鲁棒性不是「能不能」的二元问题，而是**有预算、可测量、可分配**的连续量（处理增益 G_p、干扰裕度 M_J）。安全应当从「满足约束」升级为「**在干扰强度 ‖I‖ ≤ M_J 内满足约束**」；而 R69 的「k 个正交证据源一致」纪律，本质就是**在证据域上扩频**。

>
> 核心命题：**在 R69 之上加一个「验证层 / 干扰裕度层」：把闭环证书从「成立/不成立」升级为「在干扰球 B(I_0, M̂_J^cert) 内成立」，其中 M̂_J^sim 由 Gazebo 注入干扰测得、再被显式的外生 sim-to-real 差距界 δ̄_gap 保守折算；新增第三类不确定性 U_valid（「我的证据基还适不适合现实」），它不可由仿真交互消解，只能由少量真实锚点 + 分布鲁棒/共形 + 显式差距先验压住；并交付一条逐级实测、单调不升的抗干扰降级阶梯。** 命名 **AEGIS-RAS**（Anti-interference Envelope, Gazebo-grounded, Interval-certified, Sim-to-real Safety）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我在哪里被验证过？那份验证本身可信吗？在多大的干扰下它还成立？**」

## 0. 直觉与动机

**灵感 1（抗干扰 → 鲁棒性是有预算、可测量的连续量）**
直觉：通信里抗干扰从来不是「能不能」的二元问题，而是「能扛多大 J/S」的连续量——处理增益 G_p、干扰裕度 M_J、扩频/跳频/多天线分集。R68/R69 的安全只有一个旋钮：不确定就收紧 λ 或退化。像一辆只会踩刹车的车。抗干扰理论说：鲁棒性是**可分配的资源**——用时间冗余、频率/空间分集、纠错编码去换裕度。映射到本闭环：多模态证据 = 频率分集；k-正交一致 = 纠错码；主动换证据对（R69 的 CIA）= 跳频；λ 收紧 = 降速。于是「安全」从「满足约束」升级为「**带干扰裕度 M_J 的约束**」——一个可以被测量、被证书携带的实数。

**灵感 2（处理增益 ↔ 证据多样性；R69 的证据纪律其实是扩频）**
直觉：扩频之所以抗干扰，是因为干扰机功率有限、压不扁整个带宽；只要信号摊得比干扰宽，就仍有解调余量。R69 要求「k 个正交证据源一致才定案」——这正是**在证据域上扩频**：单一通道被投毒（jamming）只毁掉一个 chip，其余 chip 仍能解出同一比特。于是 R69 的纪律不是拍脑袋的保守，而是一个有定量「处理增益」的机制 G_e ≈ −log(δ_p ρ^{k−1})。它把「对抗投毒」与「环境干扰」统一进同一套预算语言，也让 R69 的曲线可以被 R70 定量地读。

**灵感 3（Gazebo → 可复现的干扰注入靶场，即干扰 oracle）**
直觉：在真实世界做干扰实验危险、昂贵、不可复现。Gazebo 有插件化的传感器、物理与时钟，可**按种子复现地注入**六类干扰：加性/脉冲噪声（js）、GPS/位姿欺骗（spoof）、传感器丢包（drop）、延迟抖动（lat）、质量/摩擦等物理参数摄动（phys）、光照天气等视觉扰动（vis）。这使得「干扰裕度」成为**可在受控条件下统计估计、并可逐帧回放**的量。Gazebo 因此不只是测试台，而是一个**干扰 oracle**：它能回答「这个闭环在半径 r 的干扰球里是否仍然安全」。

**灵感 4（Gazebo 也是模型 → 验证者悖论）**
直觉：Gazebo 的物理是近似，传感器模型也是近似。**你无法只用仿真去估计仿真与现实的差距**——存在两个不同的真实世界，它们在仿真能观测到的范围内诱导出同一个仿真假设。所以纯仿真证书会系统性地乐观：它可能是一份关于「错误世界」的严密证明。这是 R68「标定吸收故障」、R69「模态撒谎」之上的第三层——**验证台撒谎**。处置方式只能是：把 δ_gap 显式写进证书，并**承认它不可由仿真内部消解**，只能靠少量真实锚点、物理先验、分布鲁棒界从外部压住。

**灵感 5（抗干扰的「包络」与「降级阶梯」）**
直觉：抗干扰接收机不是「扛不住就死」，而是按干扰强度走阶梯：全功能 → 降速/降阶 → 只保底 → 静默。闭环也应如此：随干扰 I 增大，逐级切到**已实测、已折算**的认证档（全 AEGIS → 停交互退 R68 → 纯保守退 R67 → 安全停）。每级切换阈值是**在 Gazebo 里测量、再被 δ̄_gap 保守下压**得到的。这把 R68/R69 的「突变式回退」变成「有证据的、单调的、可预演的降级」——既更安全，也更可被审计。

**灵感 6（干扰是对抗的，验证本身也是攻击面）**
直觉：一旦承认 Gazebo 是验证台，它就成了目标：攻击者可以让仿真「看起来温和」（削弱噪声模型）、在测试干扰族上过拟合（对抗训练的下游过拟合）、或隐藏真实会发生的故障模式。**验证投毒（validation poisoning）** 让「通过测试」变得廉价而危险。所以 AEGIS 必须审计验证器本身：留出未见干扰族、封存测试集、对抗性验证配置，并为每份证书附一个**可证伪实验（falsification test）**——真的去现实里跑一次、一旦观测到什么即证明证书是错的实验。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（AEGIS-RAS 总览与三不变式）** AEGIS-RAS = (FLUID-RAS, IIM, JMC, GAP, LDG, VQAuditor-V)。三不变式：
(i) **继承 R69 三不变式**（零学习实时写、交互预算、证据纪律）；
(ii) **证书必带裕度**：任何 J_AEGIS 都形如「在 ‖I−I_0‖ ≤ M̂_J^cert 内成立」，禁止给出无条件「安全」；
(iii) **差距外生**：sim-to-real 差距界 δ̄_gap 必须来自仿真之外（真实锚点/物理先验/外部保守界），**禁止用仿真数据自证 δ̄_gap = 0**。

**定义 311（干扰空间与干扰球）** 干扰参数 I = (I_js, I_spoof, I_drop, I_lat, I_phys, I_vis) ∈ ℝ^m，分别对应干扰功率/欺骗幅度/丢包率/延迟/物理摄动/视觉扰动；标称 I_0。干扰球 B(I_0, r) = {I : ‖I−I_0‖ ≤ r}，r 以统一白化范数（或无量纲 ISR，干扰信号比）计量。

**定义 312（干扰注入 oracle IIM）** Gazebo 侧注入算子 ℐ：(seed, I) ↦ 可复现的观测/扰动轨迹。ℐ 至少覆盖六类干扰族；每族独立开关与幅度。任何证书实验必须记录 (种子集, I, 干扰族配置) 的哈希，保证可回放。

**定义 313（闭环安全泛函）** S(I) = 在干扰 I 下运行闭环的加权安全/任务泛函（如 1{零违规}·成功率 − κ·违规严重度），在干扰随机性上取期望或给定分位数（如 P99 安全）。证书阈值 S_min。

**定义 314（干扰裕度 M_J）** M_J(θ; I_0) = sup{ r ≥ 0 : ∀I ∈ B(I_0,r), S(I) ≥ S_min }，即标称干扰周围「仍满足安全」的最大球半径。**抗干扰 = 最大化 M_J**；这是对 R68/R69「是否安全」这份二元判断的连续化。

**定义 315（仿真侧估计 M̂_J^sim）** 用 ℐ 在自适应二分的球面方向上估计：取 r，令 S_sim(r) = min_{‖u‖=1} 有限样本估计的 S_sim(I_0 + r·u)，再减去有限样本共形/UCB 修正；M̂_J^sim = 最大 r 使修正后 S_sim ≥ S_min。此估计**仅覆盖注入过的干扰族**，故天然乐观。

**定义 316（sim-to-real 差距 δ_gap 及其不可识别性）** δ_gap ≥ d(P_real, P_sim)，d 为闭环响应分布间距离（TV/Wasserstein）。**关键约束**：仅用 ℐ 产生的样本无法给出一致估计（引理 20）；δ_gap 只能由真实锚点集 𝒜_real 或外生上界 δ̄_gap 提供。

**定义 317（差距保守折算 GAP 界）** 设安全泛函对世界差异是 L_s-Lipschitz：|S_real(I) − S_sim(I)| ≤ L_s·δ_gap。定义**证书干扰裕度**
M̂_J^cert = sup{ r : inf_{I∈B(I_0,r)} S_sim(I) ≥ S_min + L_s·δ̄_gap }。
即「用仿真先把安全垫垫高 L_s·δ̄_gap，再读半径」。由引理 21，这给出真实干扰裕度的**下界（sound）**。

**定义 318（第三类不确定性 U_valid）** 除 U_ale、U_epi 外新增**证据基有效性不确定性** U_valid = P(证书在真实部署成立 | 现有仿真 + 锚点证据)。它**不随仿真样本数增大而必然减小**（受 δ_gap 主导），只能由真实锚点数 n_real、域随机化覆盖、外生先验压住。操作代理：U_valid ≈ f(δ̄_gap, n_real, 干扰族覆盖缺口 |ℱ_unseen|)。

**定义 319（证据域处理增益 G_e 与裕度分解）** 把 R69 的 k-正交证据纪律量化为处理增益 G_e = −log(δ_p ρ^{k−1})（错误采纳概率的对数下界，接引理 18）；干扰裕度分解
M_J ≈ G_e − Δ_conf(S_min) − L_model·ε_model，
即经典 M_J = G_p − (S/N)_req − L_system 在证据域的对应。系：增加正交证据 = 增加处理增益 = 扩大 M_J；但 ρ→1（相关欺骗）时增益饱和——与经典「相关干扰压不扁扩频」同构。

**定义 320（抗干扰降级阶梯 LDG）** 一序列认证档 r = 0..R：档 0 全 AEGIS（含交互）；档 1 停交互（退 R69→R68）；档 2 纯保守（R67 式）；档 3 安全停。档 r 的实测阈值 τ_r = M̂_J^cert(r)，要求 τ_0 ≥ τ_1 ≥ … ≥ τ_R。当 ‖I‖ > τ_r 时单调降档；降档动作本身经 C-RAS-WM 认证，且降档不得增大物理风险。

**定义 321（验证投毒威胁 ℰ_valid）** 攻击者操纵仿真配置/噪声模型使 M̂_J^sim 偏乐观；在测试干扰族上过拟合；隐藏真实故障模式；篡改锚点或选择偏差。并入 AIC：ℰ_AEGIS = ℰ_FLUID × ℰ_valid。

**定义 322（可证伪证书 J_AEGIS）** J_AEGIS = (J_FLUID, M̂_J^cert, δ̄_gap, n_real, L_s, interference_log_hash, LDG 阈值表, falsification_test_spec, verdict)。Valid ⇔ Valid(J_FLUID) ∧ δ̄_gap 外生给定 ∧ 锚点覆盖/交换性满足 ∧ 降级阈值单调。**强制**携带 falsification_test_spec：一个「在现实中观测到什么即证伪本证书」的可执行实验；未执行则 verdict 标注 **UNFALSIFIED**。

**定义 323（真实锚点与共形覆盖）** 锚点集 𝒜_real = {(I_i, S_i)}_{i=1..n}。在可交换性下，用共形分位数给出下界覆盖：以概率 ≥ 1−α，S_real(I) ≥ Ŝ_real(I) − q_{1−α}(𝒜_real)。锚点用于给 δ_gap 提供**下界证据**（可与物理先验合并）；n_real=0 时退为纯先验界（最保守）。

**定义 324（未建模干扰的元鲁棒性 MRF）** 留出干扰族集合 ℱ_hold（调参/训练时不可见）。要求在 ℱ_hold 上 M̂_J^sim 相对 ℱ_seen 的下降 ≤ ε_meta。用于防止「只在注入过的干扰上鲁棒」（对抗训练过拟合）。这是 R69 E298 OOD 的「干扰维度版」。

**定义 325（验证器审计 VQAuditor-V）** 审计对象升级为**验证过程**：证书实验是否封存测试集、是否覆盖 ℱ_hold、δ̄_gap 来源是否外生、falsification test 是否执行、锚点是否被篡改/选择偏差。结论回灌 AuditBuf，成为下一轮 U_valid 先验。

## 2. 关键算法骨架

```python
# IP-264 IIM：Gazebo 干扰注入 oracle（种子化、可复现、六类干扰族）
class InterferenceInjector:
    FAMILIES = ("js", "spoof", "drop", "lat", "phys", "vis")
    def run(self, seed, I, policy, episodes):
        gz = gazebo_session(seed)
        for fam in self.FAMILIES:
            gz.inject(fam, I[fam])                    # 可回放的干扰注入
        logs = [rollout(gz, policy) for _ in range(episodes)]
        return safety_functional(logs)                # S_sim(I) 及分位数

# IP-265 JMC：仿真侧干扰裕度（球面方向自适应二分 + 共形/UCB 有限样本纠偏）
def estimate_margin_sim(inj, policy, I0, S_min, conf):
    lo, hi = 0.0, R_MAX
    while hi - lo > EPS:
        r = 0.5 * (lo + hi)
        S = min(inj.run(sI, I0 + r*u, policy, N) for u in sphere_dirs())
        S_ucb = S - conformal_gap(conf, N)            # 有限样本保守下压
        lo, hi = (r, hi) if S_ucb >= S_min + L_s*dgap_bar() else (lo, r)
    return lo                                         # M_hat_sim（乐观）

# IP-266 GAP：把 sim-to-real 差距折算成证书裕度（外生 dgap_bar）
def cert_margin(M_hat_sim, L_s, dgap_bar, slope):
    # 由定义 317：S_sim 需高出 S_min 至少 L_s*dgap_bar；slope=dS/dr 做一阶换算
    return max(0.0, M_hat_sim - (L_s * dgap_bar) / max(slope, EPS))

# IP-267 LDG：抗干扰降级阶梯（阈值含 dgap 折算，单调）
def degrade_level(I_norm, thresholds):
    for r, tau in enumerate(thresholds):
        if I_norm <= tau: return r
    return len(thresholds) - 1                        # 安全停

# IP-268/269/270：U_valid、证据处理增益、真实锚点共形
def validity_uncertainty(dgap_bar, n_real, unseen_fams):
    return clip(a*dgap_bar + b/sqrt(n_real+1) + c*unseen_fams, 0, 1)

def evidence_gain(delta_p, rho, k):                   # 定义 319
    return -log(delta_p * rho**(k-1) + EPS)

def anchor_lower_bound(S_hat, anchors, alpha):        # 定义 323
    return S_hat - conformal_quantile(anchors, 1-alpha)

# IP-274 主闭环：AEGIS = R69 闭环 + 干扰监控 + 降级 + 裕度证书
def AEGIS_round(M, obs, I_norm):
    level = M.ldg.degrade_level(I_norm, M.thresholds)  # O(R) 阈值查表
    if level >= M.ldg.SAFE_STOP:
        return M.safe_stop()                          # 档 3：安全停
    if level >= 1:
        M.disable_interaction()                       # 档 1+：退 R68，不“问”
    k, lam, mode, U = FLUID_RAS_round(M, obs)         # R69 本体
    if level >= 2:
        lam = max(lam, LAM_CONSERV)                   # 档 2：纯保守
    if M.monitor.interference_anomalous(I_norm):      # 干扰越界/受攻击迹象
        M.vqa_v.flag_validity(I_norm); lam = max(lam, LAM_CONSERV)
    M.cert.emit(M.cert_margin_sim, M.dgap_bar, n_real=M.anchors.n)
    return k, lam, mode, (U, M.validity_uncertainty())
```

## 3. 推导

**引理 19（处理增益—干扰裕度对应）** 在 R69 证据纪律下，若各证据源被独立投毒概率 δ_p、两两相关 ρ<1，则错误采纳的对数下界 G_e = −log(δ_p ρ^{k−1}) 随 k 近似线性增长；相应地，在「错误模态致安全违规」上，干扰裕度增量 ΔM_J ≥ c·G_e（c 为模态间距常数，接 R69 引理 16）。系：**正交证据就是干扰域上的扩频**；但 ρ→1 时 G_e 饱和，扩频失效——与经典相关干扰一致。

**引理 20（sim-to-real 差距的不可识别性）** 仅用注入 oracle ℐ 的输出无法一致估计 δ_gap。构造：存在两个真实环境 P_real^(1)、P_real^(2)，它们在仿真可达观测量上诱导同一 P_sim（仿真的假设对两者都成立），但二者 TV 距离 = δ > 0。任何只依赖 ℐ 样本的估计量 δ̂(samples) 对两者取值相同，故 δ̂ 与真实差距的误差至少 δ/2。**结论：仿真不能自证差距，δ̄_gap 必须外生。**（系：把 δ̄_gap 设为 0，等于宣称验证台与现实的差距为零——这是本层级最危险、也最常见的隐含假设。）

**引理 21（差距保守折算的正确性）** 若 |S_real(I) − S_sim(I)| ≤ L_s·δ_gap 对 B(I_0,r) 一致成立，且 inf_{B(I_0,r)} S_sim ≥ S_min + L_s·δ̄_gap，则 inf_{B(I_0,r)} S_real ≥ S_min。故定义 317 的 M̂_J^cert 是**有效的（sound）**下界；其锐度取决于 L_s 与 δ̄_gap 是否松。

**定理 18（AEGIS 在零差距时严格包含 FLUID）** 当 δ̄_gap = 0（验证台等同现实）且 L_s 有限时，M̂_J^cert = M̂_J^sim，LDG 仅在 ‖I‖ 进入各档阈值时降级；此时 R70 的每一档分别退化为对应的 R69 / R68 / R67 行为。故 FLUID 是 AEGIS 在「零差距 + 零干扰」边界上的严格退化；安全侧不做让步（由引理 21 保证）。**新增的是「裕度」这一维度，而不是一个新黑箱。**

**定理 19（抗干扰降级的安全单调与无突变）** 若阈值 τ_0 ≥ τ_1 ≥ …（皆含 δ̄_gap 折算）且各档动作经 C-RAS-WM 认证，则随 ‖I‖ 增大，档位单调不升（更保守）、λ 单调不降，切换时刻控制连续、无突变；且降档只可能缩小安全包络、不扩大。⇒ 抗干扰层不引入新的不安全回退路径。

**定理 20（真实锚点的有限样本价值）** 在可交换性下，n_real 个锚点使 U_valid 的纯先验界收缩为共形覆盖界 S_real ≥ Ŝ_real − q_{1−α}(𝒜_real)，收缩速率 O(n_real^{−1/2})；n_real = 0 时必须退为最保守外生界。系：**锚点是「解除不可识别性」的唯一通道**；少量锚点的边际价值在 U_valid 上递减但非零——这正是「先做小规模实地校验」的理论依据。

## 6. 本轮最大风险

**一句话**：AEGIS 把「安全」从「成立」改写成「在差距折算后的干扰裕度内成立」，但**如果那台验证台（Gazebo + 注入模型 + 锚点）本身系统性地偏乐观，M̂_J^cert 就是一份关于「错误世界」的严密证明**——最危险的不是「没证」，而是「证错」，因为它把「未验证」洗成了「已验证」；而 sim-to-real 差距的**不可识别性**（引理 20）意味着再多的仿真也补不上这个洞，只有真实锚点或外生界能压住。

**次级风险与缓解**：
1. **验证台低估干扰**（噪声模型太温和）→ 封存测试集 + 对抗性验证配置 + ℰ_valid + VQAuditor-V；
2. **测试干扰族过拟合**（对抗训练下游过拟合）→ 定义 324 的 ℱ_hold 元鲁棒 + E308；
3. **δ̄_gap 给得过松/过紧**（过松则证书无效，过紧则过度保守、失去 resolution bonus）→ 真实锚点 + E303/E304 敏感性分析；
4. **降级阈值在真实域漂移**→ 定理 19 单调保护 + 在线干扰监控 + 越界即快速退到安全停；
5. **锚点被篡改/选择偏差**→ 锚点签名 + 冲突检测 + VQAuditor-V；
6. **可证伪测试被跳过**→ 证书显式标注 UNFALSIFIED + 审计罚分，决不让「未测」冒充「已验证」。

**一句话总风险**：R70 的成败最终不在仿真里，而在「我们敢不敢承认验证台可能是错的」——把 δ_gap 当作一等公民写进证书，而不是当作一个可以被无限仿真抹平的细节。

## 3. 关键算法伪代码

```python
# IP-264 IIM：Gazebo 干扰注入 oracle（种子化、可复现、六类干扰族）
class InterferenceInjector:
    FAMILIES = ("js", "spoof", "drop", "lat", "phys", "vis")
    def run(self, seed, I, policy, episodes):
        gz = gazebo_session(seed)
        for fam in self.FAMILIES: gz.inject(fam, I[fam])
        return safety_functional([rollout(gz, policy) for _ in range(episodes)])

# IP-265 JMC：仿真侧干扰裕度（球面方向二分 + 共形纠偏，得乐观 M_hat_sim）
def estimate_margin_sim(inj, policy, I0, S_min, conf):
    lo, hi = 0.0, R_MAX
    while hi - lo > EPS:
        r = 0.5*(lo+hi)
        S = min(inj.run(sI, I0+r*u, policy, N) for u in sphere_dirs())
        ok = (S - conformal_gap(conf, N)) >= S_min + L_s*dgap_bar()
        lo, hi = (r, hi) if ok else (lo, r)
    return lo

# IP-266 GAP：差距折算（外生 dgap_bar；slope=dS/dr）
def cert_margin(M_hat_sim, L_s, dgap_bar, slope):
    return max(0.0, M_hat_sim - (L_s*dgap_bar)/max(slope, EPS))

# IP-267 LDG：降级阶梯（阈值已含差距折算，单调）
def degrade_level(I_norm, thresholds):
    for r, tau in enumerate(thresholds):
        if I_norm <= tau: return r
    return len(thresholds) - 1

# IP-268/269/270：U_valid、证据处理增益、共形锚点下界
def validity_uncertainty(dgap_bar, n_real, unseen): 
    return clip(a*dgap_bar + b/sqrt(n_real+1) + c*unseen, 0, 1)
def evidence_gain(delta_p, rho, k):  return -log(delta_p*rho**(k-1) + EPS)
def anchor_lower_bound(S_hat, anchors, alpha):
    return S_hat - conformal_quantile(anchors, 1-alpha)

# IP-274 主闭环：AEGIS = R69 + 干扰监控 + 单调降级 + 裕度证书（在线仅查表）
def AEGIS_round(M, obs, I_norm):
    level = M.ldg.degrade_level(I_norm, M.thresholds)
    if level >= M.ldg.SAFE_STOP: return M.safe_stop()
    if level >= 1: M.disable_interaction()             # 退 R68，不“问”
    k, lam, mode, U = FLUID_RAS_round(M, obs)          # R69 本体
    if level >= 2: lam = max(lam, LAM_CONSERV)         # 纯保守
    if M.monitor.interference_anomalous(I_norm):
        M.vqa_v.flag_validity(I_norm); lam = max(lam, LAM_CONSERV)
    M.cert.emit(M.cert_margin_sim, M.dgap_bar, M.anchors.n)
    return k, lam, mode, (U, M.validity_uncertainty())
```

## 4. 推导

**引理 19（处理增益—干扰裕度对应）** R69 证据纪律下，独立投毒率 δ_p、相关 ρ<1，则错误采纳对数下界 `G_e=−log(δ_p ρ^{k−1})` 随 k 近线性增长，干扰裕度增量 `ΔM_J ≥ c·G_e`（c 为模态间距常数）。系：正交证据即证据域扩频；ρ→1 时增益饱和——与经典相关干扰一致。

**引理 20（sim-to-real 差距的不可识别性）** 仅用 ℐ 样本无法一致估计 δ_gap：存在两个真实环境 P_real^(1)、P_real^(2) 在仿真可达观测量上诱导同一 P_sim，但彼此 TV 距离 δ>0；任何只依赖 ℐ 的估计量对两者相同，误差 ≥ δ/2。**故 δ̄_gap 必须外生；设 δ̄_gap=0 是本层级最危险的隐含假设。**

**引理 21（差距折算的正确性）** 若 `|S_real−S_sim| ≤ L_s δ_gap` 在 B(I_0,r) 一致成立，且 `inf_B S_sim ≥ S_min + L_s δ̄_gap`，则 `inf_B S_real ≥ S_min`。故 `M̂_J^cert`（定义 317）是有效（sound）下界。

**定理 18（零差距时严格包含 FLUID）** 当 `δ̄_gap=0`、`L_s` 有限，`M̂_J^cert=M̂_J^sim`，LDG 仅在 ‖I‖ 过阈值时降级；各档分别退化为 R69/R68/R67。故 FLUID 是 AEGIS 在「零差距 + 零干扰」边界的严格退化；安全不让步，新增的只是「裕度」维度。

**定理 19（降级的安全单调与无突变）** 阈值 `τ_0≥τ_1≥…`（含差距折算）且各档经 C-RAS-WM 认证 ⇒ 随 ‖I‖ 增大，档位单调不升、λ 单调不降，切换连续无突变，降档只缩小不扩大安全包络。

**定理 20（真实锚点的有限样本价值）** 可交换性下，n_real 个锚点把 U_valid 从纯先验界收缩为共形覆盖界，速率 `O(n_real^{−1/2})`；n_real=0 必须退最保守外生界。系：锚点是解除不可识别性的唯一通道——这就是「先做小规模实地校验」的理论依据。

## 7. 本轮最大风险

**一句话**：AEGIS 把「安全」改写成「差距折算后的干扰裕度内成立」，但**若验证台（Gazebo+注入模型+锚点）系统性地偏乐观，M̂_J^cert 就是一份关于「错误世界」的严密证明**——最危险的不是「没证」，而是「证错」，它把「未验证」洗成「已验证」；而 sim-to-real 差距的**不可识别性**（引理 20）意味着再多仿真也补不上，只有真实锚点或外生界能压住。

**次级风险与缓解**：验证台低估干扰（封存集 + 对抗验证配置 + ℰ_valid + VQAuditor-V）；测试族过拟合（ℱ_hold 元鲁棒 + E308）；δ̄_gap 给得过松/过紧（真实锚点 + E303/E304 敏感性）；降级阈值真实域漂移（定理 19 单调保护 + 在线监控 + 快速安全停）；锚点被篡改/选择偏差（锚点签名 + 冲突检测 + VQAuditor-V）；可证伪测试被跳过（显式 UNFALSIFIED + 审计罚分）。

**总风险**：R70 的成败不在仿真里，而在「敢不敢承认验证台可能是错的」——把 δ_gap 当作一等公民写进证书，而不是当作能被无限仿真抹平的细节。
