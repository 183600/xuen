### 第 4 轮灵感驱动研究记录

**灵感词**：物体泛化、长期记忆

**继承关系**：第 3 轮 CADVS-v3（IP-485~488）在 v2 三锚点（空间 3DCF、物理 MSRG、人因 HICK）之上追加末点锚 EEK（kc_ee）与记忆锚 LTEM（kc_mem），得到五硬门 kc_evidence_forged_v3 = kc_coverage ∧ kc_physics ∧ kc_human ∧ kc_ee ∧ kc_mem，执行集 Exec_CADVS-v3 ⊆ Exec_CADVS-v2 ⊆ Exec_CADVS-v1 ⊆ Exec_v29。本轮不推翻 v3，而是修补 v3 暴露的结构性缺口：LTEM 以 object_class 等做「逐上下文精确查表」，任何新物体类都退化为冷启动 novelty=1，既无法把「物体 A 的经验」迁移给「相似物体 B」，也无法在相似物体上继承已知失败。本轮以「物体泛化」为主轴、以「长期记忆的巩固（consolidation）」为机制，形成 CADVS-v4（IP-489~492）。

**直觉与动机**：

1. **物体泛化：从「每个物体从零开始」到「在相似物体间迁移证据」**。v3 的记忆键含 object_class，类一变就查不到。但真实机器人抓过上百次「圆柱金属杯」后，第一次见「圆柱陶瓷杯」不该完全从零。人会把物体抽象为「几何 + 材质 + 质量 + 摩擦 + 可供性」的潜表示，在相似物体间迁移抓取证据。可迁移性是双刃剑：特征空间相似并不等于物理行为等价；带着「我有经验」自信的错误迁移（负迁移）比冷启动更危险。因此泛化必须附带「可证明的适用域」，而不是一个拍脑袋的相似度阈值。

2. **长期记忆：从扁平 KV 到互补学习系统式的双存储巩固**。v3 的 LTEM 只增不减（LRU 淘汰），没有抽象、没有巩固、没有遗忘曲线。神经科学的互补学习系统（CLS）假说提示：海马做快速 episodic 记忆，新皮层做慢速语义/原型记忆，二者通过离线 replay 巩固，既保留细节又抽取共性，并缓解灾难性遗忘。把 LTEM 升级为 CLTM：episodic 快存储 E + semantic 慢存储 S + 巩固算子 + 衰减遗忘。语义原型层正是物体泛化的载体。

3. **把泛化从启发式升级为分布无关的风险控制**。用 split conformal prediction：在已知结果的校准物体集上构造非一致性分数并取分位数 q̂，对新物体给出预测集 C_α(o) ⊆ {成功, 失败}。仅当 C_α = {成功}、最近原型相似度落在适用域内、且分布漂移守卫 GVG 判定可交换时，才授予「泛化证书 GEC」并进入自主执行。于是泛化的选择性假接受率有 ≤ α/P(accept) 的分布无关上界，而不是靠经验阈值。

**关键洞见**：v3 把记忆当「查表」，v4 把记忆当「可巩固、可抽象、可校准的证据源」。v3 用执行集单调收缩换安全，代价是对新物体几乎零自主性；v4 明确区分「许可集 Exec」与「自主集 AutoExec」：Exec 仍单调收缩（新增 kc_gen 硬门只删不增），AutoExec 在 conformal 风险控制下做有界扩张。泛化不是免费能力，而是「用可证明的适用域换取自主性」。六硬门 kc_evidence_forged_v4 = kc_coverage ∧ kc_physics ∧ kc_human ∧ kc_ee ∧ kc_mem ∧ kc_gen，fail-closed；软评分 ECS_v4 仅用于分级与仪表盘，不参与安全决策。

**形式化目标（增量）**：
1. 物体描述子 φ(o) ∈ ℝ^d 与相似度 s(o,c) = exp(−d_φ(φ(o), φ̄_c))；episodic 存储 E、语义原型存储 S。
2. CLTM：巩固算子 Consolidate(E,S)、k-NN 检索 Retrieve(φ,k) → (支持数 n, 加权成功率 p̂, 最近相似度 s_min, 最近原型 c*)、遗忘权重 w = exp(−λ_mem·Δt)。
3. OGK 泛化证书 GEC = (o, c*, s_min, C_α, g, t)，其中 C_α 为 split conformal 预测集，g = p̂ 为泛化置信度。
4. kc_gen 硬门：精确 episodic 命中则委托 kc_mem；否则要求 C_α = {成功} ∧ s_min ≥ s_gen ∧ GVG 判定可交换（无漂移）。
5. EFA-v4 六硬门；Exec_CADVS-v4 ⊆ Exec_CADVS-v3，AutoExec_CADVS-v4 = AutoExec_CADVS-v3 ∪ Gen_Certified，且 Gen_Certified ⊆ {C_α={成功}}。

**本轮最大风险**：**相似性度量不是物理等价的充分条件**——学到的物体描述子把「看起来像」当成「行为上一样」，conformal 的可交换性假设在新物体分布漂移时被打破，而长期记忆的巩固又把偶然相关的原型固化成「语义真理」，使负迁移随时间自我强化，这是比 v3 单条记忆中毒更隐蔽、更难回滚的证据链污染。

### IP-490 CLTM：双存储长期记忆（episodic O(1)，semantic 检索 O(|S|+k)）

```python
from dataclasses import dataclass, field
from collections import OrderedDict
import numpy as np

@dataclass
class Prototype:
    pid: int
    phi_bar: np.ndarray          # 语义原型（描述子加权质心）
    n_pos: int = 0               # 成功计数
    n_neg: int = 0               # 失败计数
    t: float = 0.0               # 最近更新时刻

    @property
    def n(self) -> int:
        return self.n_pos + self.n_neg

@dataclass
class ConsolidatedLongTermMemory:
    """CLTM：episodic（快、精确）+ semantic（慢、原型）；CLS 式巩固 + 衰减遗忘"""
    gamma_mem: float = 0.2
    k_nn: int = 8
    lambda_mem: float = 1e-6      # 遗忘衰减率（1/s）
    merge_radius: float = 0.15    # 描述子距离合并半径（类内异质性来源）
    min_support: int = 5          # 原型最少支持数
    max_episodes: int = 1 << 18
    replay_batch: int = 256

    def __post_init__(self):
        self.E: dict[str, tuple] = {}      # ctx -> (phi, n_pos, n_neg, t_last, s2rc_fp)
        self.S: list[Prototype] = []
        self._next_pid = 0
        self._lru: OrderedDict[str, None] = OrderedDict()

    # ---- 快系统：精确 episodic（v3 LTEM 语义原样保留）----
    def exact_lookup(self, object_class, geo_sig, theta_fp, rule_id):
        """返回 None（无条目，冷启动）或 (pass_mem, eta_mem)"""
        ctx = f"{object_class}|{geo_sig}|{theta_fp}|{rule_id}"
        if ctx not in self.E:
            return None
        _, n_pos, n_neg, _, _ = self.E[ctx]
        total = n_pos + n_neg
        eta = n_pos / total if total > 0 else 0.5
        pass_mem = not (total > 0 and n_neg / total > 1.0 - self.gamma_mem)
        return pass_mem, eta

    def record_episode(self, ctx, phi, success, t_now, s2rc_fp):
        _, n_pos, n_neg, _, _ = self.E.get(ctx, (phi, 0, 0, -np.inf, ""))
        n_pos += int(success); n_neg += int(not success)
        self.E[ctx] = (phi, n_pos, n_neg, t_now, s2rc_fp)
        self._lru[ctx] = None; self._lru.move_to_end(ctx)
        if len(self.E) > self.max_episodes:
            old, _ = self._lru.popitem(last=False)
            self.E.pop(old, None)

    # ---- 慢系统：离线 replay 巩固 ----
    def consolidate(self, t_now):
        if not self.E:
            return
        items = list(self.E.values())
        idx = np.random.choice(len(items), size=min(self.replay_batch, len(items)),
                               replace=False)
        for phi, n_pos, n_neg, t, _ in (items[i] for i in idx):
            w = float(np.exp(-self.lambda_mem * max(0.0, t_now - t)))
            j, d = self._nearest_proto(phi)
            if j is None or d > self.merge_radius:
                self.S.append(Prototype(self._next_pid, phi.copy(), n_pos, n_neg, t_now))
                self._next_pid += 1
            else:
                p = self.S[j]
                p.phi_bar = (p.phi_bar * p.n + w * phi) / (p.n + w)
                p.n_pos += n_pos; p.n_neg += n_neg; p.t = t_now
        self.S = [p for p in self.S if p.n >= self.min_support]

    def _nearest_proto(self, phi):
        if not self.S:
            return None, np.inf
        ds = [float(np.linalg.norm(phi - p.phi_bar)) for p in self.S]
        j = int(np.argmin(ds))
        return j, ds[j]

    def retrieve(self, phi, t_now):
        """k-NN 语义检索；返回 (n, p_hat, s_min, c*)"""
        if not self.S:
            return 0, 0.5, 0.0, None
        ds = np.array([float(np.linalg.norm(phi - p.phi_bar)) for p in self.S])
        order = np.argsort(ds)[: self.k_nn]
        num = den = 0.0
        for j in order:
            p = self.S[j]
            w = float(np.exp(-self.lambda_mem * max(0.0, t_now - p.t)))
            num += w * p.n_pos; den += w * p.n
        p_hat = num / den if den > 0 else 0.5
        j0 = int(order[0]); c = self.S[j0]
        return int(c.n), float(p_hat), float(np.exp(-ds[j0])), c
```

### IP-489 OGK：split conformal 泛化证书（物体切换/规则准入时，非控制环）

```python
from math import ceil

@dataclass
class GEC:
    phi: np.ndarray
    proto_id: int
    s_min: float
    C_alpha: frozenset
    g: float
    t: float

@dataclass
class ObjectGeneralizationKernel:
    """OGK：split conformal 预测集 → 泛化证书；kc_gen 硬门"""
    alpha_gen: float = 0.05
    s_gen: float = 0.85
    min_support: int = 5
    cltm: ConsolidatedLongTermMemory = None
    calib_scores: list = field(default_factory=list)
    q_hat: float = float('inf')

    def _score(self, phi, y, t_now):
        _, p_hat, _, _ = self.cltm.retrieve(phi, t_now)
        return (1.0 - p_hat) if y == 1 else p_hat

    def calibrate(self, calib, t_now):
        """calib: [(phi, y)]；q̂ 取第 ceil((m+1)(1-α)) 小的分数。
        注意：校准后须冻结 CLTM 快照，否则打分函数漂移破坏可交换性。"""
        self.calib_scores = sorted(self._score(phi, y, t_now) for phi, y in calib)
        m = len(self.calib_scores)
        k = ceil((m + 1) * (1.0 - self.alpha_gen))
        self.q_hat = self.calib_scores[k - 1] if k <= m else float('inf')

    def prediction_set(self, phi, t_now):
        return {y for y in (0, 1) if self._score(phi, y, t_now) <= self.q_hat}

    def kc_gen(self, phi, t_now, gvg):
        """返回 (pass, GEC|None, reason)"""
        n, p_hat, s_min, c = self.cltm.retrieve(phi, t_now)
        if c is None or n < self.min_support:
            return False, None, 'GEN_COLD'
        if s_min < self.s_gen:
            return False, None, 'OUT_OF_DOMAIN'
        if not gvg.exchangeable(phi, t_now):
            return False, None, 'DIST_SHIFT'
        C = self.prediction_set(phi, t_now)
        if C != {1}:
            return False, None, ('GEN_AMBIGUOUS' if C else 'GEN_FAIL')
        return True, GEC(phi, c.pid, s_min, frozenset(C), p_hat, t_now), 'GEN_FORGED'
```

### IP-491 GVG：分布漂移守卫（破坏可交换性即 fail-closed）

```python
@dataclass
class GeneralizationValidityGuard:
    """GVG：滑动窗 MMD² 置换检验；P_t 与校准分布 P_0 不可交换时否决泛化"""
    shift_alpha: float = 0.01
    window: int = 512
    bandwidth: float = 1.0
    ref_phi: np.ndarray = None          # 校准集描述子快照
    seen: list = field(default_factory=list)
    _thr: float = None

    def _rbf(self, X, Y):
        d2 = ((X[:, None, :] - Y[None, :, :]) ** 2).sum(-1)
        return np.exp(-d2 / (2.0 * self.bandwidth ** 2))

    def mmd2(self, X, Y):
        return float(self._rbf(X, X).mean() + self._rbf(Y, Y).mean()
                     - 2.0 * self._rbf(X, Y).mean())

    def exchangeable(self, phi, t_now):
        self.seen.append(phi)
        if len(self.seen) > self.window:
            self.seen.pop(0)
        if self.ref_phi is None or len(self.seen) < 32:
            return False                       # 校准不足：fail-closed
        X, Y = np.asarray(self.seen), np.asarray(self.ref_phi)
        if self._thr is None:
            self._thr = self._perm_threshold(X, Y)
        return self.mmd2(X, Y) <= self._thr   # 超阈值 → 不可交换 → 关闭 kc_gen

    def _perm_threshold(self, X, Y, n_perm=200):
        """置换检验的 (1-shift_alpha) 分位阈值（按窗长缓存）"""
        Z = np.vstack([X, Y]); n = len(X); stats = []
        for _ in range(n_perm):
            np.random.shuffle(Z)
            stats.append(self.mmd2(Z[:n], Z[n:]))
        return float(np.quantile(stats, 1.0 - self.shift_alpha))
```

### IP-492 EFA-v4：六硬门 + Exec/AutoExec 分离

```python
@dataclass
class EvidenceForgingAssemblerV4:
    """EFA-v4：六硬门 fail-closed；Exec 单调收缩，AutoExec 有界扩张"""
    scf: SpatialCoverageFieldKernel
    msrg_cache: dict
    hic: HumanIntentCertificateKernel
    eek: EndEffectorFidelityKernel
    cltm: ConsolidatedLongTermMemory
    ogk: ObjectGeneralizationKernel
    gvg: GeneralizationValidityGuard
    mu_S: float = 0.75

    def hard_gate(self, x, t_now, rule_id, hic, eec, object_class,
                  geo_sig, theta_fp, phi_o):
        if self.hic.veto_active(hic):           return False, 'HIC_STOP', None
        if not self.scf.kc_coverage(x, t_now):  return False, 'COVERAGE_BLIND', None
        s2rc = self.msrg_cache.get(rule_id)
        if s2rc is None or s2rc.verdict != 'accept' or s2rc.mu_pass < self.mu_S:
            return False, 'PHYSICS_UNPROVEN', None
        if not self.eek.kc_ee(eec):             return False, 'EE_UNPROVEN', None
        exact = self.cltm.exact_lookup(object_class, geo_sig, theta_fp, rule_id)
        if exact is not None:                   # 已知上下文：v3 语义，精确优先
            pass_mem, eta = exact
            if not pass_mem:                    return False, 'MEMORY_REJECT', None
            return True, 'FORGED', ('exact', eta, None)
        ok, gec, why = self.ogk.kc_gen(phi_o, t_now, self.gvg)   # 未见物体：泛化
        if not ok:                              return False, why, None
        return True, 'FORGED|GEN', ('gen', gec.g, gec)

    def membership(self, verdict, tag):
        """Exec_v4：六门通过；AutoExec_v4：exact 或 GEN（无需教师）"""
        if verdict not in ('FORGED', 'FORGED|GEN'):
            return (False, False)
        auto = tag[0] in ('exact', 'gen')
        return (True, auto)
```

### 集成流水线（v3 → v4）

```
慢时域（离线，非控制环）：
  各站 episodic 结果 ──▶ CLTM.consolidate(replay) ──▶ 语义原型 S
       ──▶ 校准物体集 (φ, y) ──▶ OGK.calibrate ──▶ q̂（冻结 CLTM 快照）
       ──▶ GVG.ref_phi 快照；FFA 跨站原型须经 per-site 验证（防 R43/R44）

在线物体切换 / 规则准入（ms 级，非 200 Hz）：
  φ(o) ──▶ CLTM.exact_lookup
      ├─ 命中 ──▶ kc_mem（v3 语义）
      └─ 未命中 ──▶ OGK.kc_gen
             ├─ GEN_COLD / OUT_OF_DOMAIN ──▶ 冷启动 novelty=1 + 教师（不进 AutoExec）
             ├─ DIST_SHIFT ───────────────▶ GVG 否决，回退教师
             ├─ GEN_AMBIGUOUS / GEN_FAIL ─▶ 拒绝自主执行
             └─ GEN_FORGED ───────────────▶ GEC，进入 AutoExec（Gen_Certified）

在线控制环（沿用 v3，< 0.1 ms 增量）：
  每周期：EEK 读力/力矩/触觉 → EEC → kc_ee
  证书消费前：EFA-v4.hard_gate(...)
      六门任一失败 → fail-closed 回退（HIC_STOP / COVERAGE_BLIND /
      PHYSICS_UNPROVEN / EE_UNPROVEN / MEMORY_REJECT / GEN_*）
```

## 4. 正确性论证（增量更新）

### 引理 41（split conformal 的选择性假接受界）

**陈述**：设校准物体 (φ_i,Y_i) 与新物体 (φ,Y) 可交换，非一致性分数 score 在校准后冻结，q̂ 为第 ⌈(m+1)(1−α_gen)⌉ 小分数，C_α(φ)={y: score(φ,y) ≤ q̂}。则 (a) 边缘覆盖 P(Y ∈ C_α(φ)) ≥ 1−α_gen；(b) 若门只在 C_α={1} 时接受，令 A={C_α={1}}，则选择性假接受率满足 P(Y=0 | A) ≤ α_gen / P(A)。

**证明**：(a) 为 split conformal 标准结论（分数可交换 + 分位数构造）。(b) 令 E={Y ∉ C_α}，则 P(E) ≤ α_gen。在 A∩{Y=0} 上，Y=0 ∉ C_α={1}，故 Y ∉ C_α，即 A∩{Y=0} ⊆ E，于是 P(A∩{Y=0}) ≤ α_gen；两边除以 P(A) 得 P(Y=0|A) ≤ α_gen/P(A)。∎

**工程含义**：泛化假接受不再由经验阈值拍板，而有分布无关上界；`P(A)`（接受率）越小，条件风险上界越松，故需同时监控接受率，避免「只在极少数样本上接受却宣称低风险」。

### 引理 42（巩固不越出 episodic 结果的凸包）

**陈述**：设原型 c 由若干 episodic 结果 {(y_i, w_i)} 加权合并，w_i > 0，则其加权成功率 p̂_c = Σ w_i y_i / Σ w_i ∈ [min_i y_i, max_i y_i]；遗忘只改变 w_i，不改变凸组合性质。因此巩固本身不会「无中生有」地创造成功证据。泛化的额外误差只可能来自 merge_radius 内的类内异质性（语义混叠），其条件假接受率上界为类内结果方差项加 conformal 的 α_gen。

**证明**：加权平均是凸组合，直接得 p̂_c 落在观测结果的 min/max 之间。类内异质时，合并等价于把若干真实成功率不同的子群混为单一原型，p̂ 为混合均值；引理 41 的覆盖只保证边缘概率，条件覆盖退化由子群间结果方差决定。∎

**工程含义**：巩固是安全的「证据压缩」，不是「证据放大」；真正危险的是把行为不同的物体并入同一原型（语义混叠），故需 merge_radius 与原型纯度监控。

### 引理 43（漂移守卫的失效边界）

**陈述**：若新物体分布 P_t 与校准分布 P_0 的 MMD² ≥ ρ，则 split conformal 的可交换性假设不成立，引理 41 的覆盖保证失效。GVG 以显著性 shift_alpha 的置换检验检测漂移：当 ρ ≥ ρ_min(window)（当前窗长可检测的最小效应量）时，检测概率随样本量 → 1，kc_gen 关闭（fail-closed）；当 0 < ρ < ρ_min 时存在检测盲区，泛化风险不受控。

**证明**：MMD 两样本置换检验在 H0（P_t=P_0）下控制第一类错误 ≤ shift_alpha，在 H1 下功效随 ρ 与窗长增大（MMD 估计量的一致性）；ρ_min 由窗长与核带宽决定，低于它的漂移不可区分于抽样噪声。∎

**工程含义**：GVG 把「可检测的大漂移」转成 fail-closed，但小/慢漂移是结构性盲区，必须靠定期重校准与实机回灌兜底。

### 定理 v4（Exec 单调收缩与 AutoExec 有界扩张）

**陈述**：在以下假设下：(C1) 校准与测试物体在同一巩固 epoch 内可交换，且校准后冻结 CLTM 打分快照；(C2) GVG 对 MMD² ≥ ρ 的漂移可检测；(C3) 语义原型的类内纯度 ≥ 1−ε_c；(C4) 继承 v3 的 (B1)~(B4)。则：
(i) Exec_CADVS-v4 ⊆ Exec_CADVS-v3（许可集单调收缩）；
(ii) AutoExec_CADVS-v4 = AutoExec_CADVS-v3 ∪ Gen_Certified，且 Gen_Certified ⊆ {C_α={1}}，其选择性假接受率 ≤ α_gen/P(accept)（引理 41）；
(iii) 巩固不创造凸包外成功证据，类内混叠的额外风险 ≤ ε_c 项（引理 42）；
(iv) 当漂移 MMD² ≥ ρ 且被 GVG 检出时，Gen_Certified = ∅（引理 43，fail-closed）。

**证明**：(i) v4 在 v3 五门之上追加 kc_gen 合取；GEN 失败会移除 v3 冷启动放行的路径，正向泛化不会放行 v3 未放行的对象，故只缩不涨。(ii) AutoExec_v3 不含冷启动 novelty 路径；v4 把 GEN_FORGED 加入自主集，故为并集；Gen_Certified 由 kc_gen 的 C_α={1} 条件直接界定，风险由引理 41。(iii) 由引理 42。(iv) 由引理 43。∎

**诚实声明**：本定理的核心脆弱点是 (C1)/(C2)。conformal 只给**边缘**覆盖，不给特定物体族的**条件**覆盖；记忆巩固会在校准后改变打分函数，若不冻结快照或按 epoch 重校准，可交换性即被自身破坏；GVG 对缓慢/小幅漂移存在盲区。更根本的是：φ(o) 与 d_φ 若只是「视觉相似」而非「物理等价」，则相似度与真实可迁移性脱钩，conformal 只能保证「在错误的分数下仍然边缘覆盖」，无法阻止系统性负迁移。

## 7. 本轮最大风险（最终确认）

**一句话**：**相似性度量不是物理等价的充分条件**——学到的物体描述子把「看起来像」当成「行为上一样」，conformal 的可交换性假设在新物体分布漂移时被打破，而长期记忆的巩固又把偶然相关的原型固化成「语义真理」，使负迁移随时间自我强化，这是比 v3 单条记忆中毒更隐蔽、更难回滚的证据链污染。
