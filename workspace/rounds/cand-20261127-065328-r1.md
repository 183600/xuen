### 第 1 轮灵感驱动研究记录

**灵感词**：跌倒恢复、运动控制

**直觉与动机**：
现有 v25（SRC-USC 七证一体）有一个未言明的共同前提：所有证书都在证明「如何不失败」——执行轨迹始终停留在名义安全包络内。但人形/足式机器人在真实世界中必然经历失衡、跌倒、触地冲击、自我起身这一系列「模式相变」，而且这些阶段会**故意越界**：大接触力、非最小相位、质心短暂失控、关节进入力矩饱和。把跌倒当作证书链的例外，证书链就会在最需要它的时刻失效。受「跌倒恢复」启发，安全应从「单侧不变集」升级为「包含恢复的韧性包络」——不仅要证明不会跌倒，还要证明「若跌倒，则伤害有界、状态可辨识、可恢复或可安全静置」。受「运动控制」启发，恢复不是开环动作序列，而是混合自动机上的闭环模式切换：每个模式有不变式、每条迁移有守卫与入口证书；接触力锥（CWC）、捕获点（capture point）、质心动力学、ISS-Lyapunov 提供统一形式化语言。核心洞见：**跌倒恢复 = 证书链的「故障穿越」（fault ride-through）；运动控制 = 在混合自动机上为每个模式与每条迁移签发证书**。

**形式化目标**：
1. 定义跌倒可检测证书（FDC）：在认证扰动集 𝒟_cert 内，检测延迟 τ_det ≤ τ_max、召回 ≥ 1-α_f、误报 ≤ β_f、预撞击提前量 Δt_lead ≥ τ_react。
2. 定义保护性着陆证书（PLC）：撞击冲量 J ≤ J_max、峰值接触力 F_peak ≤ F_safe、关节力矩 τ ≤ τ_max、吸收能量 E_abs ≤ E_budget，四重上界由柔顺律与力矩限幅共同保证。
3. 定义自起身证书（SGC）：跌倒状态 x_f ∈ ℬ_rec（可恢复域，即能到达直立集 𝒰 的可行核），存在满足关节/力矩/接触约束的起身轨迹，且恢复裕度 γ_rec > 0；否则必须能到达安全静置集 ℛ_rest。
4. 定义全身运动控制证书（WBMCC）：任务跟踪误差 ≤ ε_task、接触力锥可行（摩擦/单侧/CoP 在支撑多边形内）、质心动力学一致、ISS-Lyapunov 证书 V̇ ≤ -λV + γ‖d‖²。
5. 构建跌倒-恢复-运动统一准入门（FRM-USC v26）：在 SRC-USC 上增加混合模式自动机，定义韧性包络 ℛ = 𝒮_nom ∪ 𝒮_protect ∪ ℬ_rec ∪ ℛ_rest，要求 ℛ 前向不变且从 ℛ\𝒮_nom 有限时间进入 𝒮_nom 或 ℛ_rest；Exec_v26 = Exec_v25 ∩ Fil_fall ∩ Fil_recover ∩ Fil_motion ⊆ Exec_v25，并证明任意模式迁移不破坏单调退化链。

```python
import math

# ============================================================
# IP-448 Fall Detectability Certificate (FDC) — 跌倒可检测证书
# ============================================================
@dataclass
class FallDetectabilityCertificate:
    """认证扰动集内的检测延迟 / 召回 / 误报 / 预撞击提前量联合证书"""
    D_cert: 'DisturbanceSet'          # 认证扰动集（推力/地形/负载范围）
    detector: 'FallDetector'
    tau_max: float = 0.15             # 检测延迟上界 (s)
    tau_react: float = 0.10           # 最小反应时间 (s)
    alpha_f: float = 0.02             # 漏检率上界
    beta_f: float = 0.05              # 误报率上界

    def verify_detection_latency(self, fall_traces: list['Trace']) -> bool:
        """∀τ∈D_cert: t_detect - t_onset ≤ τ_max"""
        for tr in fall_traces:
            t_det = self.detector.first_alarm(tr.observations)
            if t_det is None or (t_det - tr.onset_time) > self.tau_max:
                return False
        return True

    def verify_recall_precision(self, labeled: list['Trace']) -> bool:
        """召回 ≥1-α_f，误报 ≤β_f（在 D_cert 上分层采样）"""
        tp = sum(self.detector.fires(tr) for tr in labeled if tr.is_fall)
        fn = sum(not self.detector.fires(tr) for tr in labeled if tr.is_fall)
        fp = sum(self.detector.fires(tr) for tr in labeled if not tr.is_fall)
        recall = tp / max(tp + fn, 1)
        fpr = fp / max(sum(1 for tr in labeled if not tr.is_fall), 1)
        return recall >= 1.0 - self.alpha_f and fpr <= self.beta_f

    def verify_lead_time(self, fall_traces: list['Trace']) -> bool:
        """t_impact - t_detect ≥ τ_react：保证保护性动作来得及"""
        for tr in fall_traces:
            t_det = self.detector.first_alarm(tr.observations)
            if t_det is None or (tr.impact_time - t_det) < self.tau_react:
                return False
        return True

    def verify_all(self, fall_traces, labeled) -> bool:
        return (self.verify_detection_latency(fall_traces) and
                self.verify_recall_precision(labeled) and
                self.verify_lead_time(fall_traces))


# ============================================================
# IP-449 Protective Landing Certificate (PLC) — 保护性着陆证书
# ============================================================
@dataclass
class ProtectiveLandingCertificate:
    """冲量 / 峰值力 / 关节力矩 / 吸收能量四重上界"""
    J_max: float = 8.0                # 冲量上界 (N·s)
    F_safe: float = 1200.0            # 峰值力上界 (N)
    tau_max: float = 80.0             # 关节力矩上界 (N·m)
    E_budget: float = 150.0           # 吸收能量上界 (J)
    k_eff: float = 2.0e4              # 有效接触刚度 (N/m)
    m_eff: float = 35.0               # 有效质量 (kg)

    def peak_force_bound(self, v_impact: float) -> float:
        """线性弹簧冲击能量守恒：½m v² = ½k x² ⇒ F_peak = v√(km)"""
        return v_impact * math.sqrt(self.k_eff * self.m_eff)

    def verify_impact_bound(self, v_impact: float) -> bool:
        F_peak = self.peak_force_bound(v_impact)
        J = self.m_eff * v_impact
        E_abs = 0.5 * self.m_eff * v_impact ** 2
        return F_peak <= self.F_safe and J <= self.J_max and E_abs <= self.E_budget

    def verify_joint_torque(self, tau_traj: 'Tensor') -> bool:
        """∀t,j: |τ_j(t)| ≤ τ_max（柔顺律 + 力矩限幅）"""
        return bool(tau_traj.abs().max() <= self.tau_max)

    def verify_compliance_law(self, Z: 'ImpedanceLaw') -> bool:
        """保护相阻抗满足：低刚度 + 高阻尼 + 被动耗散 ∫Fᵀv dt ≤ 0"""
        return (Z.K.min() >= 0 and Z.B.min() >= 0 and Z.is_passive())

    def verify_all(self, v_impact: float, tau_traj, Z) -> bool:
        return (self.verify_impact_bound(v_impact) and
                self.verify_joint_torque(tau_traj) and
                self.verify_compliance_law(Z))


# ============================================================
# IP-450 Self-Righting / Get-Up Certificate (SGC) — 自起身证书
# ============================================================
@dataclass
class SelfRightingCertificate:
    """可恢复域隶属 + 起身轨迹可行性 + 恢复裕度"""
    B_rec: 'RecoverabilityBasin'      # 离线计算的可行核（HJ reachability / 采样）
    U: 'UprightSet'                   # 直立集
    gamma_rec: float = 0.05           # 恢复裕度下界
    joint_limits: 'Box' = None
    torque_limits: 'Box' = None

    def verify_recoverability(self, x_fall) -> bool:
        """x_f ∈ ℬ_rec 且到边界距离 ≥ γ_rec"""
        return (self.B_rec.contains(x_fall) and
                self.B_rec.distance_to_boundary(x_fall) >= self.gamma_rec)

    def verify_getup_feasibility(self, traj: 'Trajectory', model: 'RobotModel') -> bool:
        """起身轨迹满足关节/力矩/接触约束，终点 ∈ 𝒰"""
        if not self.joint_limits.contains(traj.q):
            return False
        if not self.torque_limits.contains(model.inverse_dynamics(traj)):
            return False
        if not traj.contact_feasible():
            return False
        return self.U.contains(traj.q[-1])

    def verify_quasi_static(self, traj: 'Trajectory') -> bool:
        """质心投影序列逐步进入支撑多边形（准静态起身的必要条件）"""
        for q in traj.q:
            if not point_in_polygon(com_projection(q), support_polygon(q)):
                return False
        return True

    def verify_all(self, x_fall, traj, model) -> bool:
        if not self.verify_recoverability(x_fall):
            return False  # 不可恢复 → 上层强制走 M2→M4 安全静置分支
        return (self.verify_getup_feasibility(traj, model) and
                self.verify_quasi_static(traj))


# ============================================================
# IP-451 Whole-Body Motion Control Certificate (WBMCC)
# ============================================================
@dataclass
class WholeBodyMotionControlCertificate:
    """任务跟踪 + 接触力锥 + 质心一致性 + ISS-Lyapunov"""
    eps_task: float = 0.02            # 任务空间误差上界 (m/rad)
    mu: float = 0.6                   # 摩擦系数
    lam: float = 1.0                  # ISS 衰减率
    gamma: float = 0.1                # 扰动增益
    V_safe: float = 1.0               # 安全 Lyapunov 上界

    def verify_task_tracking(self, errors: 'Tensor') -> bool:
        return bool(errors.abs().max() <= self.eps_task)

    def verify_contact_feasibility(self, wrenches, normals) -> bool:
        """单侧 + 摩擦锥 + CoP∈支撑多边形"""
        for w, n in zip(wrenches, normals):
            if w.dot(n) <= 0:                       # 单侧接触
                return False
            tangent = w - w.dot(n) * n
            if tangent.norm() > self.mu * w.dot(n): # 摩擦锥
                return False
        return True

    def verify_centroidal_consistency(self, c, cdd, Ldot, contacts) -> bool:
        """ṁċ + m cddot = ΣF, Ldot = Σ(r×F + τ)"""
        return centroidal_residual(c, cdd, Ldot, contacts) <= 1e-3

    def verify_iss_lyapunov(self, V, Vdot, d_norm2) -> bool:
        """V̇ + λV ≤ γ‖d‖² 且最终界 γ/λ·max‖d‖² ≤ V_safe"""
        for v, vd, d2 in zip(V, Vdot, d_norm2):
            if vd + self.lam * v > self.gamma * d2 + 1e-6:
                return False
        V_ub = (self.gamma / self.lam) * max(d_norm2)
        return V_ub <= self.V_safe

    def verify_all(self, errors, wrenches, normals, c, cdd, Ldot,
                   contacts, V, Vdot, d_norm2) -> bool:
        return (self.verify_task_tracking(errors) and
                self.verify_contact_feasibility(wrenches, normals) and
                self.verify_centroidal_consistency(c, cdd, Ldot, contacts) and
                self.verify_iss_lyapunov(V, Vdot, d_norm2))

# IP-452 FRM-USC 跌倒-恢复-运动统一准入门

@dataclass
class FallRecoveryMotionUnifiedCertificate:
    src_usc: 'SemanticReconfigCoordUnifiedCertificate'  # v25 七证
    fdc: FallDetectabilityCertificate
    plc: ProtectiveLandingCertificate
    sgc: SelfRightingCertificate
    wbmcc: WholeBodyMotionControlCertificate
    mode: str = 'M0'
    dwell_min: float = 0.05           # 防抖最小驻留时间

    def transition_guard(self, x, mode: str, ctx: dict) -> Optional[str]:
        if mode == 'M0' and self.fdc.detector.fires(ctx['trace']):
            return 'M1'
        if mode == 'M1' and ctx['impact_settled']:
            return 'M2'
        if mode == 'M1' and ctx.get('capture_step_ok', False):
            return 'M0'
        if mode == 'M2' and self.sgc.verify_recoverability(x):
            return 'M3'
        if mode == 'M2' and not self.sgc.verify_recoverability(x):
            return 'M4'
        if mode == 'M3' and self.sgc.U.contains(x):
            return 'M0'
        return None

    def admits_mode(self, mode: str, ctx: dict) -> bool:
        if mode == 'M0':
            return self.wbmcc.verify_all(**ctx['wbmcc'])
        if mode == 'M1':
            return self.fdc.verify_all(ctx['fall_traces'], ctx['labeled'])
        if mode == 'M2':
            return self.plc.verify_impact_bound(ctx['v_impact'])
        if mode == 'M3':
            return self.sgc.verify_all(ctx['x_fall'], ctx['getup_traj'], ctx['model'])
        if mode == 'M4':
            return ctx['x_fall'] in ctx['R_rest']
        return False

    def admits(self, plan, sensor_data: dict) -> bool:
        # 1) v25 七证（单机 + 语义 + 重构 + 协同）
        if not self.src_usc.admits(plan, sensor_data):
            return False
        # 2) 当前模式不变式与入口证书
        if not self.admits_mode(self.mode, sensor_data):
            return False
        # 3) 迁移守卫：只允许进入已签发入口证书的模式
        nxt = self.transition_guard(sensor_data['x'], self.mode, sensor_data)
        if nxt is not None and not self.admits_mode(nxt, sensor_data):
            return False
        # 4) 韧性包络前向不变（离线验证的集合隶属）
        if sensor_data['x'] not in sensor_data['R_envelope']:
            return False
        return True

# 端到端流水线扩展
# ============================================================
class FallRecoveryMotionPipeline:
    def __init__(self, config: dict):
        self.frm = FallRecoveryMotionUnifiedCertificate(
            src_usc=config['src_usc'],
            fdc=FallDetectabilityCertificate(
                D_cert=config['D_cert'], detector=config['detector'],
                tau_max=config['tau_max'], tau_react=config['tau_react'],
                alpha_f=config['alpha_f'], beta_f=config['beta_f']),
            plc=ProtectiveLandingCertificate(**config['plc']),
            sgc=SelfRightingCertificate(
                B_rec=config['B_rec'], U=config['U'],
                gamma_rec=config['gamma_rec'],
                joint_limits=config['joint_limits'],
                torque_limits=config['torque_limits']),
            wbmcc=WholeBodyMotionControlCertificate(**config['wbmcc']),
        )
        self.ipam.register_module("fdc", ["IP-448"],
            ["fall_detectability", "certified_disturbance_set", "lead_time"])
        self.ipam.register_module("plc", ["IP-449"],
            ["protective_landing", "impact_bound", "energy_budget"])
        self.ipam.register_module("sgc", ["IP-450"],
            ["recoverability_basin", "getup_feasibility", "recovery_margin"])
        self.ipam.register_module("wbmcc", ["IP-451"],
            ["whole_body_control", "contact_wrench_cone", "iss_lyapunov"])
        self.ipam.register_module("frm_usc", ["IP-452"],
            ["hybrid_automaton", "resilience_envelope", "fault_ride_through"])

    def step(self, sensor_data: dict) -> tuple[bool, dict]:
        # 1) 模式感知：跌倒检测优先于名义控制
        nxt = self.frm.transition_guard(sensor_data['x'], self.frm.mode, sensor_data)
        if nxt is not None and self.frm.admits_mode(nxt, sensor_data):
            self.frm.mode = nxt
        # 2) 模式相关控制器
        if self.frm.mode == 'M1':
            self._protective_controller(sensor_data)   # 收拢 + 柔顺 + 限幅
        elif self.frm.mode == 'M3':
            self._getup_controller(sensor_data)        # 跟踪 SGC 轨迹
        elif self.frm.mode == 'M4':
            self._safe_rest_controller(sensor_data)    # 稳定静置
        # 3) 十一证准入
        admitted = self.frm.admits(sensor_data['plan'], sensor_data)
        return admitted, {
            'mode': self.frm.mode,
            'fall': {'detected': self.frm.mode != 'M0',
                     'lead_time': sensor_data.get('lead_time')},
            'impact': {'F_peak': self.frm.plc.peak_force_bound(
                           sensor_data.get('v_impact', 0.0))},
            'recover': {'in_basin': self.frm.sgc.verify_recoverability(sensor_data['x'])},
            'motion': {'iss_ok': self.frm.wbmcc.verify_iss_lyapunov(
                           sensor_data['V'], sensor_data['Vdot'],
                           sensor_data['d_norm2'])},
        }

    def _protective_controller(self, sd): ...
    def _getup_controller(self, sd): ...
    def _safe_rest_controller(self, sd): ...
```

## 3. 正确性论证（增量）

### 引理 13（跌倒可检测证书的延迟-召回-提前量联合保证）
**陈述**：若真实跌倒轨迹属于认证扰动集 𝒟_cert，则 `FDC.verify_all=True` 蕴含：检测延迟 ≤τ_max、漏检率 ≤α_f、误报率 ≤β_f、且预撞击提前量 ≥τ_react。

**证明**：检测延迟与提前量是逐轨迹的时序谓词，`verify_detection_latency`/`verify_lead_time` 在 𝒟_cert 的分层样本上逐条检验，样本覆盖由 𝒟_cert 的定义保证；召回/误报为经验频率，按 Clopper–Pearson 区间取上界后与 α_f/β_f 比较。注意这是**条件保证**：𝒟_cert 之外不承诺，由包外保守策略（被动柔顺 + 直接进入 M1）兜底。∎

### 引理 14（保护性着陆的四重上界）
**陈述**：若 M0→M1 迁移满足 Δt_lead≥τ_react，且保护控制器满足柔顺律与力矩限幅，则撞击时 F_peak≤F_safe、J≤J_max、E_abs≤E_budget、τ≤τ_max。

**证明**：将撞击近似为有效质量 m_eff 以速度 v_impact 压缩有效刚度 k_eff 的线性弹簧。能量守恒 ½m_eff v² = ½k_eff x²，峰值力 F_peak=k_eff x=v√(k_eff m_eff)；冲量 J=m_eff v；吸收能量 E_abs=½m_eff v²。`verify_impact_bound` 直接检验三式；`verify_joint_torque` 逐时刻检验力矩；`verify_compliance_law` 要求 K,B 半正定且无源，保证柔顺律不注入能量。四者同时成立即得四重上界。∎

### 引理 15（自起身的可行性与安全静置的完备性）
**陈述**：若 x_f∈ℬ_rec 且存在满足约束的起身轨迹，则 `SGC.verify_all=True`，系统可在有限时间到达 𝒰；若 x_f∉ℬ_rec，则 SGC 拒绝，混合自动机强制 M2→M4，进入 ℛ_rest。

**证明**：ℬ_rec 定义为可行核，即存在满足关节/力矩/接触约束、终点 ∈𝒰 的轨迹的状态集合；`verify_recoverability` 检查隶属与裕度，`verify_getup_feasibility` 检查候选轨迹的全部约束与终点，`verify_quasi_static` 检查质心投影逐步进入支撑多边形（准静态充分条件）。不可恢复分支由 `transition_guard` 的显式守卫 M2→M4 保证，且 M4 的不变式 x∈ℛ_rest 由 `admits_mode('M4')` 检查。∎

### 引理 16（全身运动控制的 ISS 最终界）
**陈述**：若 `WBMCC.verify_all=True`，则闭环在扰动 d 下有界：V(t)≤e^{-λt}V(0)+(γ/λ)sup‖d‖²，且任务误差 ≤ε_task、接触力锥可行、质心动力学残差 ≤1e-3。

**证明**：ISS-Lyapunov 不等式 V̇≤-λV+γ‖d‖² 两边乘以 e^{λt} 并积分得 V(t)≤e^{-λt}V(0)+(γ/λ)sup‖d‖²(1-e^{-λt})。`verify_iss_lyapunov` 逐样本检查不等式并检查最终界 ≤V_safe；任务误差、接触力锥、质心一致性为独立逐点约束，四项合取得证。∎

### 引理 17（混合自动机的单调退化保持）
**陈述**：任意模式迁移 M→M' 只有在 `admits_mode(M')=True` 时发生，且若任一新增证书失败，系统退化到不依赖该证书的模式；因此 Exec_v26⊆Exec_v25 恒成立。

**证明**：`transition_guard` 返回目标模式后，`admits` 立即要求 `admits_mode(nxt)`；失败则拒绝迁移并停留在当前模式或退化到 M1/M4。由于 FRM-USC 的第一条检查就是 `src_usc.admits`，所有通过 v26 的计划必先通过 v25，故 Exec_v26⊆Exec_v25。新增四证只做交集过滤，交集单调性保证退化链不扩张。∎

### 定理（FRM-USC 十一证准入门与韧性包络完备性）
**陈述**：对任意计划 π，`FRM-USC.admits(π)=True` 蕴含 π 同时满足：v25 七证条件；FDC/PLC/SGC/WBMCC 四证条件；存在韧性包络 ℛ=𝒮_nom∪𝒮_protect∪ℬ_rec∪ℛ_rest 使 ℛ 前向不变，且从 ℛ\𝒮_nom 出发有限时间进入 𝒮_nom 或 ℛ_rest。

**证明**：前两部分由 `admits` 中 `src_usc.admits` 与 `admits_mode` 的合取直接得到。前向不变性由 `sensor_data['x']∈R_envelope` 与每条迁移的入口证书共同保证：M0 保持 𝒮_nom，M1 保持 𝒮_protect（引理 14），M2/M3 保持 ℬ_rec（引理 15），M4 保持 ℛ_rest。有限时间到达由引理 15 的起身可行性或 M2→M4 守卫给出。∎

## 6. 本轮最大风险（最终确认）

**一句话**：**FDC 的认证扰动集 𝒟_cert 与 SGC 的可恢复域 ℬ_rec 都建立在名义动力学/接触模型之上，因此一个真正新颖的跌倒（未建模接触、执行器饱和、湿滑地面、不可逆结构损伤）可能同时击穿检测提前量、使 PLC 的冲击力界失效、并把机器人置于 ℬ_rec 之外——此时 FRM-USC 的「认证故障穿越」会在它最该起作用的极端跌倒中变成一纸空诺，把「可恢复」误判为「已恢复」。**
