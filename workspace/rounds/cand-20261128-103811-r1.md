### 第 7 轮灵感驱动研究记录

**灵感词**：用户需求分析、大语言模型、面部表情识别

**继承关系**：第 6 轮 CADVS-v6（IP-497~IP-500）确立「指令-几何-力学三元凿」框架：GGC 提供抓取几何可达性约束、MCTM 注入空间拓扑图、STM 实现跨模态指令-轨迹映射，七硬门保持 fail-closed 边界。本轮延续「硬门不增」原则，聚焦「**需求-意图-一致性三角桥**」：在保持证书边界不变的前提下，直接从「用户需求分析」出发，设计「需求意图建模器」(DIM)，引入「需求一致性软评分」η_demand，使系统从「被动接受指令」转向「主动推导意图」。

**直觉与动机**：

1. **用户需求 → 从「指令响应」到「意图推导」**。第 6 轮的 STM 负责「语言→查询向量」的映射，但它无法区分「用户真正想要的」与「用户不够清晰说出的」。引入「需求意图建模器」(Demand Intent Model, DIM)：从用户的历史交互记录、当前环境约束、任务目标三方面推断「用户真正的需求目标」ρ_demand。关键洞见是：**行为从「指令驱动」转向「需求驱动」**——只有当推断的需求意图与指令意图高度一致时，才执行STM生成的轨迹；否则，触发「需求导向回退」。

2. **大语言模型 → 从「静态映射」到「动态推理」**。第 6 轮的 STM 采用 CLIP-style 对齐训练，对指令进行向量化。第 7 轮引入「需求推理链」(Demand Reasoning Chain, DRC)：将LLM连接到DIM，使得从「用户说了什么」到「用户可能需要什么」的推理过程可解释、可审计。关键洞见是：**LLM 充当「需求解释器」**——它的推理链被量化为 η_demand，若推理置信度低于阈值，系统自动切换到历史记忆中的「典型需求响应」。

3. **面部表情识别 → 从「情感调制」到「需求态度捕获」**。第 6 轮的 FAMK 调制阈值 γ_i。第 7 轮提出「需求态度捕获」(Demand Affect Capture, DAC)：基于面部表情识别，捕获用户当前的「需求态度」(desire_affect)——如焦虑表情可能意味着「需要快速、稳妥的解决方案」，而放松表情可能意味着「愿意探索创新方案」。关键洞见是：**情感态度调制需求优先级**——DAC 输出的 desire_affect 调节 ρ_demand 的稀疏性和探索度。

**关键洞见**：第 6 轮回答「如何在不新增硬门的前提下，让提议符合物理、空间、意图」；第 7 轮回答「如何从「用户需求」出发，让系统主动推导「正确的行为」，而不是被动接受指令」。七硬门 kc_evidence_forged_v5 记号原样复用；本轮新增的只有：
- IP-501 DIM（需求意图建模器），
- IP-502 DRC（需求推理链，LLM驱动），
- IP-503 DAC（需求态度捕获），
- IP-504 EFA-v7（软评分 η_demand 纳入四软因子链）

**形式化目标（增量）**：

1. **DIM（Demand Intent Model）**：<br>
   - 需求编码器 E_demand: (history, context, env) ⟼ ρ_demand ∈ ℝ^d_demand<br>
   - 损失 L_DIM = ||ρ_demand - ρ_gold||² + β·KL(π_demand || π_prior)<br>
   - 软因子：η_demand = 1 - H(ρ_pred || ρ_demand)，其中 H 为交叉熵<br>
   - 只有当 η_demand > τ_demand 时，STM 输出的指令才被采纳；否则触发「需求导向回退」

2. **DRC（Demand Reasoning Chain）**：<br>
   - LLM 推理链 R = {r_1, r_2, ..., r_n}，其中 r_i 为推理步骤<br>
   - η_demand = 1 - (1/n)·Σ_i H(r_i)，衡量推理链的整体确定性<br>
   - L_DRC = α·链长度惩罚 - η_demand，鼓励简洁且确定的推理

3. **DAC（Demand Affect Capture）**：<br>
   - 表情编码器 E_affect: face ⟼ affect ∈ {-1, 0, +1}（负面/中性/正面）<br>
   - desire_affect 调节 ρ_demand 的探索度：exploration_scale = 1 + κ·affect<br>
   - 软因子：η_affect = 1 + affect/3 ∈ [2/3, 4/3]，调制 STM 检索的广度

4. **EFA-v7（七硬门 + 四软因子链）**：<br>
   - ECS_v7 = ECS_v6 · η_g · η_topo · η_interp · η_cmd · η_demand · η_affect<br>
   - τ_i^v7 = γ_i·τ_i^v6·Π_factor_i，其中 Π_factor_i = ∏_{j=1}^5 η_j ∈ [1, 1+ε]，设计上限仍为 1.3<br>
   - 新增硬门 kc_demand：η_demand ≥ τ_demand，确保「用户需求」被必要检验

5. **形式化定义**：给定指令 L，目标 ρ_target，记忆 M：<br>
   - ρ_demand = DIM(history, context, env)；<br>
   - η_demand = 1 - H(STM(L) || ρ_demand)；<br>
   - 若 η_demand < τ_demand：<br>
     - q_demand = E_demand(ρ_demand)；<br>
     - m_demand = Top-k(Retr_M(q_demand, K=4))；<br>
     - c_demand = (obj, g_emb, θ_fp, task, ŝ_emo, m_demand, ρ_target, t_topo, q_demand)；<br>
     - x_demand = FMPP.propose(c_demand, K=8)；<br>
   - 若 η_demand ≥ τ_demand：<br>
     - 执行第 6 轮的 EFA-v6 流程<br>

**直觉与动机（本轮迭代扩展）**：

1. **碰撞检测 → 从「硬门约束」到「需求驱动碰撞 guard」**：现有七硬门保证 fail-closed，但未在需求导向回退路径中引入几何碰撞检测。关键洞见：**需求推断的轨迹若存在几何碰撞，即便一致性 η_demand 高，也应拒绝或触发安全回退**。引入 η_collision 软因子，基于 GGC 碰撞网格实时评估 x_demand 与环境的碰撞概率。

2. **语义地图 → 从「向量近似」到「结构化语义映射」**：当前 DIM 的 ρ_demand ∈ ℝ^d_demand 仅作为稠密向量，缺乏语义结构化表征。关键洞见：**引入语义地图，将 ρ_demand 投射到任务语义簿，通过 k-NN 检索确保 ρ_demand 与实际可达任务的语义一致性**，从而 η_demand 有了结构化依据而非纯统计近似。

3. **痛点分析 → 从「假设致盲」到「三层防护机制」**：核心风险是用户意图的非线性突变与自我否定。痛点分析指向三层防护：① **Dual-track DIM**（主需求路径 + 备选路径，经一致性投票），② **η_demand 实时可解释性检查**（每一步 η_demand 的变化趋势而非单点阈值），③ **需求演化检测**（连续 3 轮 η_demand 变化率超过阈值时强制回退）。

**关键洞见**：第 7 轮已回答「如何主动推导正确行为」；本轮迭代回答「如何在推导过程中 guards 多维度防止『正确但有风险』的行为」；七硬门依然保持 fail-closed，新增的只有软因子扩展与两层防护机制。

**形式化目标（增量）**：

1. **η_collision（碰撞软因子）**：
   - 基于 GGC 碰撞网格：η_collision = 1 - (碰撞体素计数 / 总体素数) ∈ [0,1]
   - 仅在需求导向回退路径中计算；常规 EFA-v6 流程不受影响

2. **语义地图投射**（Semantic Map Projection，SMP）：
   - S(ρ_demand) = Top-k(Retr_M(q_semantic, K=8))，其中 q_semantic = W·ρ_demand + b 为可学习投影
   - 一致性验证：η_semantic = 1 - (1/k)·Σ_j sim(ρ_demand, ρ_target_j)，sim 为余弦相似度
   - 若 η_semantic < τ_semantic（默认 0.6），触发语义一致性回退

3. **Dual-track DIM**：
   - 主路径：ρ_demand^main = DIM.encode(history, context, env)
   - 备路径：ρ_demand^alt = DIM.encode(history_tail, context, env) 其中 history_tail 为最近 3 条交互
   - 投票：若 sim(ρ_demand^main, ρ_demand^alt) > τ_vote（默认 0.7），则使用主路径；否则使用备路径并标记「需求不稳定」

4. **EFA-v7 增强**：
   - ECS_v7 = ECS_v6 · η_g · η_topo · η_interp · η_cmd · η_demand · η_affect · η_collision
   - 软因子链 Π_factor_i = ∏_{j=1}^7 η_j ∈ [1, 1.3]（已含 η_collision，设计上限 1.3 保持不变，意味着 η_collision 默认置 1 或在常规流程中不计）

5. **形式化定义（增量）**：
   - ρ_demand = DIM(history, context, env)；<br>
   - （主路径）ρ_demand^main = ρ_demand；<br>
   - （备路径）ρ_demand^alt = DIM(history_tail, context, env)；<br>
   - η_semantic = 1 - (1/k)·Σ_j sim(ρ_demand, ρ_target_j)；<br>
   - η_collision = 1 - (collision_voxels / total_voxels)；<br>
   - 若 η_demand < τ_demand  或  η_semantic < τ_semantic  或  η_collision < τ_collision（默认 0.5）：<br>
     - 走需求导向回退，并额外检查 η_collision<br>
   - 若 所有 软因子 ≥ 阈值：<br>
     - 执行 EFA-v6 在线流程 + 软因子链 × η_demand × η_affect × η_collision

**本轮最大风险**：**需求意图的非线性突变与自我否定**：尽管引入 dual-track 与语义地图，但用户意图仍可能在短期内发生非线性突变（如 suddenly switching from「放置到桌子」到「拿走到柜子」），此时 dual-track 可能因历史权重过大而滞后，语义地图的投影投影也可能过旧。这种结构上的捕获难题在维持七硬门 fail-closed 边界时，仍可能导致「正确但时机不当」或「正确但错误目标」的行动。

### 第 1 轮灵感驱动研究记录

**灵感词**：语义建图、多端口部署

**继承关系**：第 7 轮 CADVS-v7（IP-501~IP-504）把系统从「指令驱动」推进到「需求驱动」：DIM 从历史/上下文/环境推断 ρ_demand，DRC 用 LLM 推理链给出可解释的 η_demand，DAC 用面部表情调制探索度，EFA-v7 在七硬门不变的前提下延长软因子链。但第 7 轮留下的最大隐患是：**ρ_demand 仍是一个漂浮的稠密向量**，它既没有落到可核验的「世界结构」上，也无法在异构硬件之间迁移与审计。本轮以「语义建图」和「多端口部署」为轴，把需求意图从「向量空间的一致性」改写为「语义地图上的可落地性」，并把同一份语义契约推广到多端口部署。

**直觉与动机**：

1. **语义建图 → 从「稠密向量」到「可核验的语义-几何结构」**。ρ_demand ∈ ℝ^d 只能说明「两个向量像不像」，却说不清「像在哪个物体、哪种可供性、哪段空间关系上」。引入「语义落地图」(Semantic Grounding Map, SGM)：把场景组织为分层语义图 G_t=(V_t,E_t)，节点是物体/区域/可供性，边是空间关系（on/in/near/supports）与功能关系（affords-grasp/affords-place）。关键洞见：**需求必须先落到图上，才谈得上一致性**——把 ρ_demand 检索为子图 S_demand，用语义一致度 η_sem 与几何锚定残差 η_geo 取代单一向量相似度。

2. **多端口部署 → 从「单站点标定」到「端口无关的语义契约」**。同一套策略若部署到不同机械臂、不同底盘、不同相机与不同标定版本，语义标签相同不代表物理可实现性相同。引入「多端口部署契约」(Multi-Port Deployment, MPD)：每个端口 p 登记能力描述 cap(p)（自由度、传感器集、坐标系、标定版本、负载、安全档），共享契约 C（本体版本、动作模式版本、门参数版本）。关键洞见：**语义地图就是跨端口共享的契约**——各端口把自身锚点注册到统一规范坐标系，用 η_port 量化跨端口一致性，部署准入在离线完成、运行时七硬门不动。

3. **两者合流 → 「语义即契约，契约须落地」**。语义建图提供共享的、可追溯的世界结构；多端口部署提供「哪些端口有资格消费这份结构」的准入边界。合流后的关键洞见是：**需求推断的正确性 = 语义落地性 × 端口可实现性**。一条轨迹即便在语义图上自洽，只要在目标端口的能力/标定残差下不可实现，也必须被收紧而非放行。为此本轮引入「语义-几何耦合校准」(SGC) 与 EFA-v8。

**关键洞见**：第 7 轮回答「如何主动推导需求」；本轮回答「如何让推导出的需求落在可核验的语义-几何结构上，并在多端口之间保持可审计的一致性」。七硬门 kc_evidence_forged_v5 原样复用；本轮新增：
- IP-505 SGM（语义落地图），
- IP-506 MPD（多端口部署契约），
- IP-507 SGC（语义-几何耦合校准），
- IP-508 EFA-v8（质量分数与收紧因子分离的软评分）

**形式化目标（增量）**：

1. **SGM（Semantic Grounding Map）**：<br>
   - 分层图 G_t=(V_t,E_t)：节点 v=(id,c,x,φ,a,conf,prov,ver)，c 为类别，x∈SE(3) 为规范系位姿，φ 为几何原语（点云凸包/体素集），a 为可供性向量，conf∈[0,1]，prov 为来源（传感器/时间/端口），ver 为版本戳；<br>
   - 增量更新 G_t = Merge(G_{t-1}, Δ_t)，冲突判定：属性键 k 若 |attr_new-attr_old| > δ_k 则标记 conflict，须「双源确认」方可覆盖，否则降 conf；<br>
   - 语义一致度 η_sem = (1/k)·Σ_j sim(q_sem, emb(S_demand[j])) ∈ [0,1]；<br>
   - 几何锚定残差 η_geo = exp(-r̄/σ_geo)，r̄ 为子图节点到最近可行几何支撑的平均残差。

2. **MPD（Multi-Port Deployment）**：<br>
   - 端口 p：cap(p)=(n_dof, sensor_set, frame_id, calib_version, payload, safety_profile)；<br>
   - 共享契约 C=(o, a, g)：本体版本、动作模式版本、门参数版本；<br>
   - 跨端口锚点残差 r_p=(1/|A_p|)·Σ ||T_{p→0}·x_p - x_0||，η_port = exp(-r_p/σ_p)·1[calib_version 匹配]；<br>
   - 离线准入：p 被接纳当且仅当 cap(p) ⊇ req(task) ∧ C 版本匹配 ∧ r_p ≤ r_max；不满足的端口在部署层 fail-closed（拒绝执行），但不新增运行时硬门。

3. **SGC（Semantic-Geometric Coupling）**：<br>
   - 求每端口锚点变换 T_{p→0}，最小化 Σ ||T_{p→0}·x_p - x_0||²，并输出 η_geo；<br>
   - 漂移检测：对 η_sem、η_port 序列做 CUSUM，超过阈值即隔离该端口并触发局部重建。

4. **EFA-v8（质量分数 + 收紧因子分离）**：<br>
   - 质量分数 η_sem, η_geo, η_port ∈ [0,1]；<br>
   - 收紧因子 η̃_j = 1 + ε_j·(1-η_j) ∈ [1, 1+ε_j]，取 ε_sem=ε_geo=ε_port=0.09，使 Π = ∏ η̃_j ∈ [1, 1.295] ≤ 1.3；<br>
   - ECS_v8 = ECS_v7 · η_sem · η_geo · η_port；<br>
   - τ_i^v8 = γ_i·τ_i^v7·Π_i，七硬门不变。这样「质量越低 → 分数越低且阈值越高」，两侧同时收紧，避免 v7 中 η∈[0,1] 直接充当收紧因子的符号不一致。

5. **形式化定义**：给定指令 L、需求 ρ_demand、端口 p、契约 C：<br>
   - S_demand = Top-k_{subgraph}(sim(E_sem(ρ_demand), emb(G_t)))；<br>
   - 若 η_sem < τ_sem 或 η_geo < τ_geo 或 η_port < τ_port：<br>
     - 触发「语义落地回退」：扩大检索半径 → 请求澄清 → 回退 v7 需求导向回退；<br>
   - 否则执行 EFA-v7 在线流程，并乘 η_sem·η_geo·η_port、按 η̃ 收紧阈值。

**本轮最大风险**：**语义契约的跨端口一致性假设**：语义锚点与能力描述可能标定错误或随时间漂移，于是「在共享语义图上自洽、在规范系里残差也小」的轨迹，在某个具体端口上仍可能物理不可实现；而由于语义、几何、端口三项检查都通过，七硬门的 fail-closed 边界并不会捕获这种「一致但不可做」的错误。

| E_sem | 需求→语义查询编码器 |
| S_demand = Top-k_{subgraph}(...) | 需求落地子图 |
| η_sem ∈ [0,1] | 语义一致度 |
| r̄ | 子图节点到最近几何支撑的平均残差 |
| η_geo = exp(-r̄/σ_geo) ∈ [0,1] | 几何锚定质量 |
| cap(p) | 端口能力描述 |
| C=(o,a,g) | 共享契约：本体/动作模式/门参数版本 |
| T_{p→0} | 端口 p 到规范系 0 的锚点变换 |
| r_p | 跨端口锚点残差 |
| η_port = exp(-r_p/σ_p)·1[calib match] ∈ [0,1] | 端口一致质量 |
| η̃_j = 1 + ε_j·(1-η_j) ∈ [1,1+ε_j] | 收紧因子（质量越低越收紧） |
| Π_i = ∏_{j∈{sem,geo,port}} η̃_j ∈ [1,1.295] | 阈值收紧预算 |
| ECS_v8 = ECS_v7·η_sem·η_geo·η_port | v8 软评分 |
| τ_i^v8 = γ_i·τ_i^v7·Π_i | v8 阈值 |
| τ_sem, τ_geo, τ_port | 落地/几何/端口质量阈值（默认 0.6/0.5/0.7） |
| CUSUM_t | 漂移累积统计量 |

## 2. 关键算法骨架

### IP-505 SGM：语义落地图

```python
@dataclass
class SemanticGroundingMap:
    """SGM：分层语义图构建与增量更新。
    节点：物体/区域/可供性；边：空间关系 + 功能关系。"""
    node_dim: int = 128
    delta: dict[str, float] = field(default_factory=lambda: {"pose": 0.05, "conf": 0.2})
    tau_conflict: float = 0.6

    def merge(self, G_prev: Graph, delta_obs: Graph) -> Graph:
        """G_t = Merge(G_{t-1}, Δ_t)：双源确认 + 版本戳 + 来源保留"""
        G = G_prev.clone()
        for v_new in delta_obs.nodes:
            v_old = G.find(v_new.id)
            if v_old is None:
                G.add_node(v_new, ver=G_prev.ver + 1)
                continue
            if self._conflict(v_old, v_new):
                v_old.conf *= 0.5                     # 冲突降置信，不直接覆盖
                v_old.conflicts.append(v_new.prov)
                if v_old.conf < self.tau_conflict:
                    v_old.status = "QUARANTINE"        # 待第二来源确认
            else:
                v_old = self._ema_update(v_old, v_new) # 一致则指数平滑
        for e_new in delta_obs.edges:
            G.upsert_edge(e_new, ver=G_prev.ver + 1)
        G.ver = G_prev.ver + 1
        return G

    def _conflict(self, old: Node, new: Node) -> bool:
        pose_gap = se3_distance(old.x, new.x)
        conf_gap = abs(old.conf - new.conf)
        return pose_gap > self.delta["pose"] and conf_gap > self.delta["conf"]

    def ground_demand(self, rho_demand, G: Graph, k: int = 8) -> tuple[Graph, float]:
        """把 ρ_demand 落地为子图 S_demand 并计算 η_sem"""
        q = self.encoder(rho_demand)                   # E_sem
        scored = [(sim(q, self.node_emb(v)), v) for v in G.nodes if v.status != "QUARANTINE"]
        scored.sort(key=lambda t: t[0], reverse=True)
        top = scored[:k]
        S = G.subgraph([v.id for _, v in top])
        eta_sem = sum(s for s, _ in top) / max(1, len(top))
        return S, eta_sem
```

### IP-506 MPD：多端口部署契约

```python
@dataclass
class MultiPortDeployment:
    """MPD：端口注册 + 共享契约 + 离线准入。运行时七硬门不变。"""
    ports: dict[str, PortCapability]
    contract: Contract                              # (ontology, action_schema, gate_params)
    r_max: float = 0.02
    sigma_p: float = 0.01

    def register(self, p: str, cap: PortCapability, anchors: dict[str, SE3]) -> bool:
        self.ports[p] = cap
        self.anchor_registry[p] = anchors
        return True

    def consistency(self, p: str, T_p0: SE3) -> float:
        """η_port = exp(-r_p/σ_p)·1[calib match]"""
        anchors = self.anchor_registry[p]
        if not anchors:
            return 0.0
        residuals = [se3_distance(T_p0 @ x_p, self.canonical[a])
                     for a, x_p in anchors.items()]
        r_p = sum(residuals) / len(residuals)
        calib_ok = self.ports[p].calib_version == self.contract.calib_version
        return math.exp(-r_p / self.sigma_p) * float(calib_ok)

    def admit(self, p: str, task_req: CapabilitySet, T_p0: SE3) -> tuple[bool, str]:
        """离线准入：能力覆盖 + 契约版本 + 锚点残差；不满足即端口级 fail-closed"""
        cap = self.ports.get(p)
        if cap is None:
            return False, "PORT_UNKNOWN"
        if not task_req <= cap.as_set():
            return False, "CAPABILITY_MISSING"
        if not self.contract.compatible(cap):
            return False, "CONTRACT_VERSION_MISMATCH"
        if self.consistency(p, T_p0) < 0.7:
            return False, "ANCHOR_RESIDUAL_TOO_HIGH"
        return True, "ADMITTED"
```

### IP-507 SGC：语义-几何耦合校准

```python
@dataclass
class SemanticGeometricCoupling:
    """SGC：估计 T_{p→0}、计算 η_geo、做 CUSUM 漂移检测。"""
    sigma_geo: float = 0.02
    cusum_k: float = 0.05
    cusum_h: float = 0.5

    def estimate_transform(self, anchors_p: dict[str, SE3], canonical: dict[str, SE3]) -> SE3:
        """最小化 Σ ||T·x_p - x_0||² 的刚体配准（SVD/Umeyama）"""
        return umeyama(list(anchors_p.values()), [canonical[a] for a in anchors_p])

    def geometric_quality(self, S: Graph, scene: SceneGeometry) -> float:
        """η_geo = exp(-r̄/σ_geo)，r̄ 为节点到最近可行几何支撑的平均残差"""
        residuals = []
        for v in S.nodes:
            if v.phi is None:
                residuals.append(self.sigma_geo * 10)   # 无几何锚点重罚
                continue
            residuals.append(scene.distance_to_support(v.phi, v.x))
        r_bar = sum(residuals) / max(1, len(residuals))
        return math.exp(-r_bar / self.sigma_geo)

    def drift_detect(self, eta_seq: list[float], tau: float) -> tuple[bool, float]:
        """CUSUM：监测 η_sem / η_port 相对基线的下漂"""
        cusum, peak = 0.0, 0.0
        for eta in eta_seq:
            cusum = max(0.0, cusum + (tau - eta) - self.cusum_k)
            peak = max(peak, cusum)
        return peak > self.cusum_h, peak
```

### IP-508 EFA-v8：质量分数 + 收紧因子分离

```python
@dataclass
class EvidenceForgingAssemblerV8:
    """EFA-v8：七硬门原样复用；ECS_v8 = ECS_v7·η_sem·η_geo·η_port，
    阈值按 η̃_j = 1+ε_j(1-η_j) 收紧，Π∈[1,1.295]。"""
    v7: EvidenceForgingAssemblerV7
    sgm: SemanticGroundingMap
    mpd: MultiPortDeployment
    sgc: SemanticGeometricCoupling
    eps: dict[str, float] = field(default_factory=lambda: {"sem": 0.09, "geo": 0.09, "port": 0.09})
    tau_sem: float = 0.6
    tau_geo: float = 0.5
    tau_port: float = 0.7

    def select(self, L, t_now, context, port_id: str) -> tuple[bool, Trajectory | None, str]:
        # 1. 端口准入（离线结果的运行时查表，不新增硬门）
        admitted, why = self.mpd.admit(port_id, context.task_req, context.T_p0)
        if not admitted:
            return False, None, f"PORT_REJECTED:{why}"

        # 2. 需求落地到语义图
        rho_demand = self.v7.dim.encode(self.v7.lmem.get_history(),
                                        context.__dict__, context.env)
        S_demand, eta_sem = self.sgm.ground_demand(rho_demand, context.G_t)

        # 3. 几何耦合与端口一致性
        eta_geo = self.sgc.geometric_quality(S_demand, context.scene)
        eta_port = self.mpd.consistency(port_id, context.T_p0)

        # 4. 语义落地回退（不满足则逐级降级）
        if eta_sem < self.tau_sem or eta_geo < self.tau_geo or eta_port < self.tau_port:
            return self._grounding_fallback(L, t_now, context, port_id,
                                            rho_demand, eta_sem, eta_geo, eta_port)

        # 5. 收紧因子与阈值预算
        eta_t = {"sem": eta_sem, "geo": eta_geo, "port": eta_port}
        pi = 1.0
        for j, e in self.eps.items():
            pi *= 1.0 + e * (1.0 - eta_t[j])
        pi = min(pi, 1.3)

        # 6. 复用 v7 流程，质量分数进入 ECS，收紧因子进入阈值
        ok, x, tag = self.v7.select(L, t_now, context)
        if not ok:
            return False, None, tag
        score = self.v7.ecs_v7(x, context.n_flow, context.s_emo, context.eta_factors)
        score *= eta_sem * eta_geo * eta_port
        if score < self._tau_v8(context, pi):
            return self._grounding_fallback(L, t_now, context, port_id,
                                            rho_demand, eta_sem, eta_geo, eta_port)
        return True, x, "FORGED_CGE_V8"

    def _grounding_fallback(self, L, t_now, context, port_id, rho_demand,
                            eta_sem, eta_geo, eta_port):
        """三级降级：扩大检索 → 请求澄清 → v7 需求导向回退"""
        S_wide, eta_sem2 = self.sgm.ground_demand(rho_demand, context.G_t, k=16)
        if eta_sem2 >= self.tau_sem:
            context.G_t = context.G_t.focus(S_wide)
            return self.v7.select(L, t_now, context)
        if eta_geo < self.tau_geo or eta_port < self.tau_port:
            self.sgc.drift_detect(context.eta_history, self.tau_port)
            return False, None, "REQUEST_CLARIFICATION_OR_RECALIBRATE"
        return self.v7._demand_guided_fallback(rho_demand, t_now, context,
                                               context.affect, context.eta_affect)

    def _tau_v8(self, context, pi: float) -> float:
        """τ^v8 = γ·τ^v7·Π，七硬门参数版本随契约 C 冻结"""
        return context.gamma * context.tau_v7 * pi
```

### 集成流水线（v7 → v8）

```
离线/慢时域：
  SGM 建图：多传感器增量 Merge → 双源冲突消解 → 版本戳
  SGC 标定：各端口锚点配准 → T_{p→0}、r_p → η_port
  MPD 准入：cap(p) ⊇ req(task) ∧ C 版本匹配 ∧ r_p ≤ r_max
  联邦下发：语义本体 o、动作模式 a、门参数 g、各端口 T_{p→0} → 站内签名分发

在线准入（亚秒级）：
  MPD.admit(port) ──▶ 端口级 fail-closed（不进入运行时七硬门）
  SGM.ground_demand(ρ_demand) ──▶ S_demand, η_sem
  SGC.geometric_quality(S_demand) ──▶ η_geo
  MPD.consistency(port) ──▶ η_port
  若任一质量 < 阈值：语义落地回退（扩检索 → 澄清 → v7 需求回退）
  否则：EFA-v7 在线流程 × η_sem·η_geo·η_port，阈值 × Π(η̃)

在线控制环（目标 < 0.9 ms）：
  七硬门调用链不变；SGM 子图检索与 MPD 查表可缓存
  SGC 几何残差 0.1~0.2 ms；CUSUM 漂移检测 O(1) 增量
```

## 4. 正确性论证（增量更新）

### 定理 13（语义落地单调收紧）

**陈述**：设质量分数 η_sem, η_geo, η_port ∈ [0,1]，收紧因子 η̃_j=1+ε_j(1-η_j) ≥ 1，Π=∏η̃_j ≤ 1.3。则对任意候选轨迹 x：
- ECS_v8(x) = ECS_v7(x)·η_sem·η_geo·η_port ≤ ECS_v7(x)；
- τ_i^v8 = γ_i·τ_i^v7·Π_i ≥ τ_i^v7；
- 因而 Exec_CADVS-v8 ⊆ Exec_CADVS-v7 ⊆ … ⊆ Exec_CADVS-v6，语义建图只收紧、不扩张执行集。

**证明**：η_sem·η_geo·η_port ≤ 1 ⇒ ECS_v8 ≤ ECS_v7；Π_i ≥ 1 ⇒ τ_i^v8 ≥ τ_i^v7。若 x 通过 v8，则 ECS_v7(x) ≥ ECS_v8(x) ≥ τ^v8 ≥ τ^v7，故 x 亦通过 v7；逐级归纳即得执行集包含链。七硬门判定 1[s≥τ] 在 τ 增大时只会更严格或不变，故 fail-closed 边界保持。

### 定理 14（跨端口可迁移性的条件界）

**陈述**：设端口 p 与 p' 共享契约 C 且锚点残差分别为 r_p、r_p'，锚点变换误差有界 ||T_{p→0} - T*_{p→0}|| ≤ δ_p。若某轨迹在 p 上通过 v8，则其在 p' 上的几何可行性误差 ≤ δ_p + δ_p' + r_p + r_p' + ε_geo（ε_geo 为 SGC 配准残差）。当且仅当该上界小于任务容差 τ_task 时，迁移是可证安全的；否则只能降级为「需在 p' 上重新校准/复验」。

**证明**：三角不等式分解：p' 上的位姿误差 ≤ 自身标定误差 δ_p' + 共享锚点不一致 (r_p+r_p') + p 侧已含误差 (δ_p) + 配准残差 ε_geo。该界是保守上界，非等式；因此迁移保证是**条件性**的，不能无条件宣称「一处通过、处处可执行」。

### 诚实声明

- SGM 的语义标签来自感知模型，标签漂移与遮挡会导致节点冲突；双源确认只能降低、不能消除误合并。
- η_port 依赖标定精度与锚点选取，锚点若集中在局部区域，全局残差可能被低估。
- 定理 14 给出的是保守误差上界，实际迁移成功率需实测；「同一标签、不同可供性」的跨端口差异无法由标量 η_port 完全表达。
- 收紧因子预算 ε=0.09×3 是在「不突破 1.3」约束下的分配；若后续再加质量项，必须重新分配预算或引入归一化几何平均。
