# 第 62 轮（承接第 61 轮「具身语义进化闭环」ESEC IP-173~182；灵感循环第 8 轮；本轮灵感：「需求洞察」×「异常检测」）

> 第 61 轮用 USR（统一语义表征）、MEL（多模态具身大模型）、DMS（多轮对话管理）、SRT-Dual（语义-实时双流）、PCE+++++（六维预算）把「场景→意图→约束→执行→证据」做成了可微、可审计的闭环。但它仍有**四个被本轮灵感直接击中的盲点**：
> 1. **需求是「被说出来的」，不是「被发现的」**：DMS 的状态更新依赖 `receive_user_utterance`，`b_intent` 只是对显式话语的信念。用户说「快一点」时可能已经疲劳，说「没事」时手却在回撤；**真正的需求（偏好、舒适边界、风险容忍）大量存在于隐式行为中**，第 61 轮完全无法洞察。
> 2. **异常只是「报警」，不是「语义」**：EFGP 把滑移/振动/力超限直接映射为约束提案，**默认异常=物理故障**。但同一异常可能来自四种完全不同的原因：物理故障、模型错误、需求漂移、主动探索。误判会导致「该停不停」或「过度打扰」。
> 3. **需求与异常在表征上是割裂的**：USR 里有 `intent_emb`、`evidence_emb`，却**没有 `need_emb` 与 `anom_emb`**；需求无法被异常修正，异常也无法被需求解释。
> 4. **异常检测缺乏分布漂移下的误报保证**：第 61 轮的 `D⁺_sem > τ_sem` 是固定阈值，**在真实非平稳交互中阈值会失效**——要么误报淹没用户，要么漏报真实故障；缺乏 anytime-valid 的统计保证。

## 0. 直觉与动机

**灵感 1（需求洞察 → 层次化需求状态 HNS）**
直觉：用户的需求不是一个分类标签，而是**三层隐变量**：`h_intent`（要做什么）、`h_pref`（希望怎么做：快/稳/轻/省力）、`h_boundary`（舒适与安全边界：最大力、最大速度、可接受等待）。系统维护的是信念 `b_need ∈ Δ(H_need)`，而不是一个确定意图。关键洞见：**需求洞察 = 降低需求信念熵**，而不仅是提高意图分类准确率；用户说「轻一点……不对，是稳住」时，真正变化的是 `h_pref` 的协方差，而非 `h_intent` 的类别。

**灵感 2（需求洞察 → 隐式反馈观测模型 IFOM）**
直觉：人不会把效用函数说出来，但会用行为投票：**犹豫时延、重复纠正、力余量、注视停留、放弃率、回撤动作**都是需求信号。关键洞见：把这些信号建成 `p(o_impl | h_need)` 的似然，而不是启发式规则；并显式区分「疲劳/分心」这类**混淆变量**，否则系统会把“用户累了”误读成“用户想要更慢”。

**灵感 3（异常检测 → 异常即需求证据 AaNE）**
直觉：异常不是系统的敌人，而是**模型与用户之间失配的证据**。滑移可能是地面真的滑（物理故障），也可能是用户其实想要更轻的接触（需求漂移），还可能是 MEL 把材质认错（模型错误），或系统在安全区内主动试探（探索）。关键洞见：**先归因，再响应**；把异常从「阈值报警」升级为「因果证据」，用最小安全反事实探针区分四种原因。

**灵感 4（异常检测 → 语义-物理双域异常检测 SPAD）**
直觉：第 61 轮的异常只看执行证据，**看不到语义异常**：用户意图突然漂移、场景 OOD、USR 投影漂移、锚点过期、MEL 幻觉，都是异常。构建四域检测：物理域、语义域、交互域、系统域；并用 **conformal e-process** 给出分布漂移下 anytime-valid 的误报控制，而不是拍一个 `τ`。

**灵感 5（双灵感合流 → NICE：需求-异常耦合演化闭环）**
直觉：需求洞察与异常检测不是两个模块，而是**同一个推断问题的两个方向**：需求解释异常（这个滑移是因为用户想要更轻），异常修正需求（这次力超限说明边界估计偏低）。构建 **NICE（Need-Insight & anomaly-Coupled Evolution）**：USR 扩展 `need_emb`、`anom_emb`；DMS++ 维护需求假设与异常解释；PNM 只在「需求洞察增益 > 打扰成本」时主动提问；SPAD 的异常证据回写需求信念；NACP 保证「需求-异常-约束」三方一致。

**灵感 6（PCE++++++ → 八维认知-需求-异常预算）**
直觉：第 61 轮六维预算没有为「主动提问」和「异常归因探针」付费。拓展为 **B_cog8 = (B_scene, B_intent, B_ros, B_exec, B_mel, B_usr, B_need, B_anom)**：`B_need` 管提问次数/需求维度/洞察增益阈值/记忆更新率；`B_anom` 管 conformal α、e-value 阈值、检测时延、归因探针次数。预算耗尽时，系统必须**从「主动洞察」退化为「被动响应 + 保守安全」**，而不是继续打扰用户。

## 1. 形式化定义（增量：定义 173–185）

**定义 173（层次化需求状态 HNS）** 需求状态为三层隐变量：
```
H_need = H_intent × H_pref × H_boundary
h_intent ∈ I             # 任务目标（继承第 61 轮意图空间）
h_pref   ∈ ℝ^{d_pref}    # 交互风格偏好：速度、刚度、力度、话术密度
h_boundary ∈ ℝ^{d_b}     # 舒适/安全边界：F_max, v_max, 可接受等待, 可接受澄清次数
b_need ∈ Δ(H_need)       # 需求信念（后验分布）
```
信念更新（贝叶斯）：
```
b'_need(h') ∝ b_need(h) · p(o_exp | h) · p(o_impl | h) · p(EV_exec | h, K_safe)
H_need(b) = -Σ_h b(h) log b(h)          # 需求熵
```
其中 `o_exp` 为显式话语观测，`o_impl` 为隐式行为观测，`EV_exec` 为执行证据。

**定义 174（隐式反馈观测模型 IFOM）** 隐式观测向量与似然：
```
o_impl = (τ_hesit, n_correct, m_force_margin, g_dwell, r_repeat, a_abandon, v_retract)
p(o_impl | h) = ∏_k p_k(o_impl,k | h) · (1/Z) · exp(-E_conf(o_impl, z_conf))
```
- `τ_hesit`：指令后到首次动作的犹豫时延
- `n_correct`：单位任务内的重复纠正次数
- `m_force_margin = F_max - F_peak`：力余量（越小越接近边界）
- `g_dwell`：注视/接近目标前的停留时间
- `r_repeat`：同一指令的重复率
- `a_abandon`：放弃/接管事件
- `v_retract`：接触后回撤速度（回避信号）
- `z_conf`：混淆变量（疲劳、分心、噪声），用 `E_conf` 做**去混淆校正**，避免把疲劳误读为“想要更慢”

**定义 175（需求洞察增益 NIG）** 给定动作 `a`（提问/试探/直接执行/仅观察）：
```
NIG(a) = H_need(b_need) - E_{o~p(·|b_need,a)}[H_need(b'_need(a,o))]
```
即“执行该动作后需求熵的期望下降”。`NIG=0` 表示该动作对理解需求无信息量。

**定义 176（主动需求挖掘 PNM）** 需求感知 POMDP：
```
M_need = (S_need, A_probe, T_need, O_need, R_need, γ)
A_probe = {ask_clarify, safe_probe, vary_impedance, observe_only, act}
VOI_need(a) = NIG(a) - λ_cog·cost_cog(a) - λ_safe·risk(a) - λ_lat·τ(a)
a* = argmax_{a ∈ A_probe, Safe(a)} VOI_need(a)
```
安全约束：`a` 必须在 ERTC 实时契约与物理安全包络内；`ask_clarify` 还受 `B_need.probe_budget` 与用户可接受澄清次数约束。**洞察不是多问，而是“只在值得问的时候问”**。

**定义 177（语义-物理双域异常检测 SPAD）** 四域观测与 conformal e-process：
```
x_t = (EV_exec, anchor_t, D⁺_sem, o_impl)
域: D_phys (力/滑移/振动), D_sem (意图漂移/OOD/投影误差),
    D_inter (纠正爆发/放弃/回撤), D_sys (锚点过期/版本异常/校验失败)
非一致性分数 A(x_t) ∈ ℝ（能量模型或重建残差）
conformal p-value: p_t = (1 + #{i ≤ t : A(x_i) ≥ A(x_t)}) / (t + 1)
e-value: e_t = 1/(2√p_t),  E_t = ∏_{i=1}^t e_i,  log E_t = Σ_i (-0.5 log p_i - log 2)
告警: E_t ≥ 1/α   （Ville 不等式保证 P(sup_t E_t ≥ 1/α) ≤ α）
```
四个域各维护一个 e-process，任一触发即进入归因；**α 可按安全等级与需求不确定性自适应，但必须有上界 α_max，防止“需求越不确定越不报警”**。

**定义 178（异常因果归因 ACA）** 异常原因空间与后验：
```
C = {c_phys, c_model, c_need, c_explore}
P(c | E_t, a_probe, response) ∝ P(response | c, a_probe) · P(c | E_t)
```
- `c_phys`：物理故障（摩擦突变、负载变化、传感器故障）
- `c_model`：模型错误（MEL 幻觉、USR 投影漂移、场景误判）
- `c_need`：需求漂移（用户偏好/边界变化，物理世界未变）
- `c_explore`：主动探索（系统在安全包络内有意试探）

**可辨识性条件**：存在安全反事实探针 `a_cf`（保持物理参数不变、仅改变交互策略），使得
```
P(response | c_need, a_cf) ≠ P(response | c_phys, a_cf)
```
即“需求漂移对策略干预敏感、对物理重执行不敏感；物理故障对两者都敏感”。探针选择：
```
a_cf* = argmax_{a ∈ A_probe} I(response; C | a)
```

**定义 179（异常-需求对账 ANR）** 根据归因后验执行不同响应：
```
if argmax_c P(c|·) = c_need:
    b_need ← b_need · p(o_impl | h) 并重估 h_pref/h_boundary
    C_pending ← revise_constraints(b_need)   # 提出新的需求约束
elif argmax_c P(c|·) = c_phys:
    K_safe ← conservative_fallback(); 触发安全停机/人工接管评估
elif argmax_c P(c|·) = c_model:
    MEL.infer(force=True); USR.realign(); 降低该模态置信度
else:  # c_explore
    继续监测，不改变需求信念，不打扰用户
```
决策同时受风险约束：`c_phys` 的后验只要超过 `τ_phys`（即使不是最大后验）就必须走安全路径（**安全优先于归因置信度**）。

**定义 180（需求感知对话管理 DMS++）** 在第 61 轮 DMS 上扩展：
```
S++ = (H_diag, b_intent, b_need, C_exec, C_pending, A_anom, U_mel, turn_id)
A++ = A_DMS ∪ {explain_anomaly, propose_need, request_feedback, defer}
R++ = 𝕀[task] + λ_need·need_satisfaction - λ_cog·cognitive_load
      - λ_safe·safety_risk - λ_lat·latency - λ_annoy·annoyance
```
`A_anom` 为当前未解决的异常证据链；`explain_anomaly` 只在归因后验熵低于阈值时使用，避免“解释自己也没搞懂的事”。

**定义 181（需求-异常一致性协议 NACP）** 三方一致性：需求信念、异常归因、执行约束必须互不矛盾。联合证书：
```
J_need_anom = (J_sem_exec, hash(b_need), P(c|·), E_t, probe_log, NIG, need_constraint)
Valid(J_need_anom) ⇔ Valid(J_sem_exec)
    ∧ (E_t < 1/α ∨ argmax_c P(c|·) 已解决)
    ∧ need_constraint ⊆ SafetyEnvelope
    ∧ 无未解决的高风险异常（P(c_phys) ≤ τ_phys）
    ∧ probe_log 可审计（每个探针都有安全证书）
```

**定义 182（跨会话需求记忆 NIM）** 用户长期需求先验与遗忘：
```
b_need^0(user) = NIM.prior(user_id)
NIM.update(b_need^0, b_need^session) 采用分层贝叶斯 + 遗忘因子 λ_mem:
    μ_pref ← (1-λ_mem)·μ_pref + λ_mem·μ_session
    Σ_pref ← (1-λ_mem)·Σ_pref + λ_mem·Σ_session + Q_process
隐私: 记忆更新满足 ε_dp-差分隐私；用户可一键清除/冻结。
```

**定义 183（八维认知-需求-异常预算 PCE++++++）**
```
B_cog8 = (B_scene, B_intent, B_ros, B_exec, B_mel, B_usr, B_need, B_anom)
B_need = (Probe_budget, Need_dim, NIG_threshold, Memory_update_rate)
B_anom = (Conformal_alpha, E_threshold, Detection_delay_budget, Attribution_probe_budget)
cost_cog8 = cost_cog5
          + λ_need·(probes/Probe_budget + NIG_regret/NIG_threshold)
          + λ_anom·(log(1/E_t)/log(1/α) + probes_cf/Attribution_probe_budget)
```
降级策略：
- `B_need` 耗尽 ⇒ 停止 `ask_clarify`/`safe_probe`，只允许 `observe_only` + 保守执行；
- `B_anom` 耗尽 ⇒ 冻结 conformal 阈值、停止反事实探针，未解决异常一律升级人工；
- **安全降级优先于任务完成**，与第 61 轮一致。

**定义 184（需求-异常耦合演化闭环 NICE）**
```

AEC_entry = (t, x_t, p_t, e_t, E_t, domain_flags, P(c|·), a_cf, response,
```

## 2. 关键算法伪代码

### IP-183 HNS（层次化需求状态）

```python
class HierarchicalNeedState:
    def __init__(self, d_pref=16, d_bound=8, need_dim=64):
        self.d_pref, self.d_bound = d_pref, d_bound
        self.need_dim = need_dim
        self.b_need = NeedBelief.uniform()  # over h_intent x h_pref x h_boundary
        self.encoder = NeedEncoder(need_dim)

    def update(self, o_exp, o_impl, ev_exec, confounder=None):
        # 去混淆：先从隐式信号中扣除疲劳/分心分量
        o_clean = self.deconfound(o_impl, confounder)
        lik = self.likelihood(o_exp, o_clean, ev_exec)
        self.b_need = normalize(self.b_need * lik)
        return self.b_need

    def entropy(self):
        return -(self.b_need * torch.log(self.b_need + 1e-12)).sum().item()

    def deconfound(self, o_impl, confounder):
        # 例：用 z_conf=(疲劳评分, 任务时长) 回归掉与需求无关的时延/纠正
        if confounder is None:
            return o_impl
        return o_impl - self.confusion_regressor(confounder)

    def encode(self):
        return self.encoder(self.b_need)  # need_emb
```

### IP-184 PNM（主动需求挖掘）

```python
class ProactiveNeedMining:
    def __init__(self, budget, lambda_cog=0.1, lambda_safe=10.0, lambda_lat=0.05):
        self.budget = budget
        self.lam = (lambda_cog, lambda_safe, lambda_lat)

    def voi(self, b_need, action):
        nig = self.expected_entropy_reduction(b_need, action)
        cost = self.lam[0] * self.cog_cost(action)
        risk = self.lam[1] * self.safety_risk(action)
        lat = self.lam[2] * self.latency(action)
        return nig - cost - risk - lat

    def select(self, b_need, C_exec, B_need):
        if B_need.exhausted or b_need.entropy() < B_need.nig_threshold:
            return ObserveOnly()               # 不值得问，就不问
        cands = [a for a in self.candidates(b_need, C_exec) if safe(a)]
        return max(cands, key=lambda a: self.voi(b_need, a))

    def expected_entropy_reduction(self, b_need, action):
        # 对候选观测做蒙特卡洛采样估计 E[H(b'|a,o)]
        samples = self.simulate_observations(b_need, action, n=32)
        return b_need.entropy() - np.mean([self.posterior_entropy(o) for o in samples])

    def select_counterfactual(self):
        # 选信息量最大且安全的反事实探针
        return max(self.cf_candidates, key=lambda a: self.mutual_info_cause(a))
```

### IP-185 SPAD（语义-物理双域异常检测）

```python
class SemanticPhysicalAnomalyDetector:
    def __init__(self, alpha=0.01, alpha_max=0.05, window=200):
        self.alpha, self.alpha_max = alpha, alpha_max
        self.log_E = {d: 0.0 for d in ['phys', 'sem', 'inter', 'sys']}
        self.calib = {d: ConformalCalibrator(d) for d in self.log_E}
        self.scores = {d: deque(maxlen=window) for d in self.log_E}

    def nonconformity(self, domain, x):
        if domain == 'phys':  return self.phys_energy(x.EV_exec)
        if domain == 'sem':   return self.sem_residual(x.anchor, x.D_sem)
        if domain == 'inter': return self.interaction_surprise(x.o_impl)
        if domain == 'sys':   return self.system_integrity(x.anchor, x.checksum)

    def update(self, EV_exec, anchor, D_sem, o_impl):
        x = Obs(EV_exec, anchor, D_sem, o_impl)
        alarms = {}
        for d in self.log_E:
            A = self.nonconformity(d, x)
            p = self.calib[d].p_value(A)          # (1+#{A_i>=A})/(n+1)
            p = max(p, 1e-12)
            self.log_E[d] += -0.5 * np.log(p) - np.log(2.0)   # e_t = 1/(2 sqrt p)
            alarms[d] = self.log_E[d] >= np.log(1.0 / self.alpha)
        return alarms, self.log_E

    def adaptive_alpha(self, safety_level, need_entropy):
        # 安全等级越高 alpha 越小；需求熵高时只允许更保守的放大，且有上界
```

```python
class AnomalyNeedReconciler:
    def __init__(self, safety_env, tau_phys=0.2):
        self.safety_env = safety_env
        self.tau_phys = tau_phys

    def reconcile(self, b_need, post, C_pending):
        # 安全优先：只要 phys 后验超过阈值，就走安全路径
        if post['phys'] >= self.tau_phys:
            return b_need, C_pending, 'SAFE_FALLBACK'
        c = max(post, key=post.get)
        if c == 'need':
            b_need = self.update_need_from_anomaly(b_need, post)
            C_pending = self.revise_constraints(b_need, C_pending)
            return b_need, C_pending, 'NEED_REVISED'
        if c == 'model':
            self.trigger_reinfer(); self.trigger_realign()
            return b_need, C_pending, 'MODEL_REPAIR'
        return b_need, C_pending, 'MONITOR'             # explore

    def revise_constraints(self, b_need, C_pending):
        new_c = {
            'F_max': min(self.safety_env.F_max, b_need.boundary.F_max),
            'K_p': self.pref_to_gain(b_need.pref),
        }
        assert self.safety_env.contains(new_c)          # 需求永不越过安全包络
        C_pending['need_revision'] = new_c
        return C_pending
```

### IP-183 HNS（层次化需求状态）

```python
class HierarchicalNeedState:
    def __init__(self, d_pref=16, d_bound=8, need_dim=64):
        self.d_pref, self.d_bound = d_pref, d_bound
        self.need_dim = need_dim
        self.b_need = NeedBelief.uniform()   # over h_intent x h_pref x h_boundary
        self.encoder = NeedEncoder(need_dim)
        self.confusion_regressor = ConfusionRegressor()

    def update(self, o_exp, o_impl, ev_exec, confounder=None):
        o_clean = self.deconfound(o_impl, confounder)
        lik = self.likelihood(o_exp, o_clean, ev_exec)
        self.b_need = normalize(self.b_need * lik)
        return self.b_need

    def likelihood(self, o_exp, o_clean, ev_exec):
        p_exp = self.exp_model(o_exp)              # p(o_exp | h_intent)
        p_impl = self.impl_model(o_clean)          # p(o_impl | h_pref, h_boundary)
        p_exec = self.exec_model(ev_exec)          # p(EV_exec | h_boundary, K_safe)
        return p_exp * p_impl * p_exec

    def deconfound(self, o_impl, confounder):
        # 扣掉疲劳/分心可解释的时延与纠正，避免把“累”误读为“想慢”
        if confounder is None:
            return o_impl
        return o_impl - self.confusion_regressor(confounder)

    def entropy(self):
        return -(self.b_need * torch.log(self.b_need + 1e-12)).sum().item()

    def boundary_changed(self):
        return self.kl(self.b_need.marginal('boundary'), self.last_boundary) > self.tau_change

    def encode(self):
        return self.encoder(self.b_need)           # need_emb
```

### IP-184 PNM（主动需求挖掘）

```python
class ProactiveNeedMining:
    def __init__(self, budget, lambda_cog=0.1, lambda_safe=10.0, lambda_lat=0.05):
        self.budget = budget
        self.lam = (lambda_cog, lambda_safe, lambda_lat)
        self.safety_env = SafetyEnvelope()

    def voi(self, b_need, action):
        nig = self.expected_entropy_reduction(b_need, action)
        cost = self.lam[0] * self.cog_cost(action)
        risk = self.lam[1] * self.safety_risk(action)
        lat = self.lam[2] * self.latency(action)
        return nig - cost - risk - lat

    def select(self, b_need, C_exec, B_need):
        if B_need.exhausted or b_need.entropy() < B_need.nig_threshold:
            return ObserveOnly()                  # 不值得问，就不问
        cands = [a for a in self.candidates(b_need, C_exec)
                 if self.safety_env.permits(a)]
        return max(cands, key=lambda a: self.voi(b_need, a))

    def expected_entropy_reduction(self, b_need, action):
        samples = self.simulate_observations(b_need, action, n=32)
        return b_need.entropy() - np.mean([self.posterior_entropy(o) for o in samples])

    def select_counterfactual(self):
        # 选“最能把 need 与 phys 分开”的安全探针
        return max(self.cf_candidates, key=lambda a: self.mutual_info_cause(a))

    def safety_risk(self, action):
        return 0.0 if self.safety_env.strictly_inside(action) else float('inf')
```

```python
class SemanticPhysicalAnomalyDetector:
    def __init__(self, alpha=0.01, alpha_max=0.05, window=200):
        self.alpha, self.alpha_max = alpha, alpha_max
        self.log_E = {d: 0.0 for d in ['phys', 'sem', 'inter', 'sys']}
        self.calib = {d: ConformalCalibrator(d) for d in self.log_E}
        self.scores = {d: deque(maxlen=window) for d in self.log_E}

    def nonconformity(self, domain, x):
        if domain == 'phys':  return self.phys_energy(x.EV_exec)       # 力/滑移/振动
        if domain == 'sem':   return self.sem_residual(x.anchor, x.D_sem)  # OOD/漂移
        if domain == 'inter': return self.interaction_surprise(x.o_impl)   # 纠正爆发/放弃
        if domain == 'sys':   return self.system_integrity(x.anchor, x.checksum)

    def update(self, EV_exec, anchor, D_sem, o_impl):
        x = Obs(EV_exec, anchor, D_sem, o_impl)
        alarms = {}
        for d in self.log_E:
            A = self.nonconformity(d, x)
            p = max(self.calib[d].p_value(A), 1e-12)
            self.log_E[d] += -0.5 * np.log(p) - np.log(2.0)  # e_t = 1/(2 sqrt p)
            alarms[d] = self.log_E[d] >= np.log(1.0 / self.alpha)
        return alarms, self.log_E

    def adaptive_alpha(self, safety_level, need_entropy):
        # 安全等级越高 alpha 越小；需求熵高只允许有限放大，且有上界
        a = self.alpha * np.exp(-safety_level) * (1 + 0.1 * need_entropy)
        return min(a, self.alpha_max)
```

```python
class AnomalyCausalAttribution:
    CAUSES = ['phys', 'model', 'need', 'explore']

    def attribute(self, E_t, a_cf, response, context):
        prior = self.prior(E_t, context)
        lik = {c: self.response_likelihood(response, c, a_cf) for c in self.CAUSES}
        post = normalize({c: prior[c] * lik[c] for c in self.CAUSES})
        if self.identifiability(a_cf) < self.tau_id:
            post = self.widen(post)                # 不可辨识 -> 保守集覆盖真实原因
        return post

    def prior(self, E_t, context):
        # 语义域先触发 -> model/need 先验高；物理域先触发 -> phys 先验高
        return self.domain_prior(context.domain_flags, context.anchor_age)

    def response_likelihood(self, response, cause, a_cf):
        mu = {'need': self.mu_need, 'phys': self.mu_phys,
              'model': self.mu_model}.get(cause)
        if mu is None:
            return self.uniform_low(response)      # explore: 预期响应弱
        return self.gaussian(response, mu[a_cf], self.sigma[cause][a_cf])

    def identifiability(self, a_cf):
        # need 对策略干预敏感、对物理重执行不敏感；phys 对两者都敏感
        return self.fisher_information(a_cf) / self.fisher_ref
```

### IP-187 ANR（异常-需求对账）

```python
class AnomalyNeedReconciler:
    def __init__(self, safety_env, tau_phys=0.2):
        self.safety_env = safety_env
        self.tau_phys = tau_phys

    def reconcile(self, b_need, post, C_pending):
        # 安全优先：只要 phys 后验超阈，即使不是最大后验也走安全路径
        if post['phys'] >= self.tau_phys:
            return b_need, C_pending, 'SAFE_FALLBACK'
        c = max(post, key=post.get)
        if c == 'need':
            b_need = self.update_need_from_anomaly(b_need, post)
            C_pending = self.revise_constraints(b_need, C_pending)
            return b_need, C_pending, 'NEED_REVISED'
        if c == 'model':
            self.trigger_reinfer(); self.trigger_realign()
            return b_need, C_pending, 'MODEL_REPAIR'
        return b_need, C_pending, 'MONITOR'        # explore: 不打扰用户

    def revise_constraints(self, b_need, C_pending):
        new_c = {
            'F_max': min(self.safety_env.F_max, b_need.boundary.F_max),
            'K_p': self.pref_to_gain(b_need.pref),
        }
        assert self.safety_env.contains(new_c)     # 需求约束只能收缩，不能扩张
        C_pending['need_revision'] = new_c
        return C_pending
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| HNS | O(\|H_need\|·d_need) | O(\|H_need\|·d_need) | 校准良好且无混淆时，需求熵单调不增 |
| PNM | O(\|A_probe\|·n_mc) / 决策 | O(\|A_probe\|) | VOI 最优探针；安全包络硬约束 |
| SPAD | O(1) 每域更新 | O(window·4) | `P(sup_t E_t ≥ 1/α) ≤ α`（Ville） |
| ACA | O(\|C\|) | O(1) | 可辨识时后验一致；不可辨识时保守集覆盖真因 |
| ANR | O(1) | O(1) | 需求约束恒 ⊆ SafetyEnvelope；phys 超阈强制安全 |
| DMS++ | O(1) 轮次 | O(N_turns) | 打扰率受 B_need 约束；任务完成率不降 |
| NIM | O(d_pref + d_b) | O(N_users·d_need) | ε_dp 隐私；遗忘因子适应非平稳需求 |
| PCE++++++ | O(1) | O(1) | 任一预算耗尽触发安全降级 |
| NICE | 语义流 10-100Hz / 实时流 1-10kHz | 共享内存 + AEC | 实时流不依赖异常归因时序 |

**正确性定理（NICE-Complete）**：
假设 A61–A70 及 **(A71)** HNS 似然校准良好（ECE ≤ 0.05），混淆变量可观测或可去混淆。**(A72)** SPAD 在无异常原假设下 conformal p-value 超均匀；e-value 构造满足 `E[e(p)] ≤ 1`。**(A73)** ACA 的响应似然在四类原因下可区分，且存在满足可辨识性条件的安全反事实探针。**(A74)** ANR 的 `SafetyEnvelope` 由 ERTC 与物理约束预先给出，需求约束更新只能收缩、不能扩张。**(A75)** NIM 的记忆更新满足 ε_dp-差分隐私；遗忘因子 λ_mem ∈ (0,1)。**(A76)** PCE++++++ 预算单调消耗，降级策略安全优先。**(A77)** AEC 链式哈希不可篡改，探针均有安全证书。

则：
1. **需求洞察有效性**：在 A71 下，`NIG(a*) ≥ 0`，且若 `max_a NIG(a) < NIG_threshold` 则系统不提问（不产生无价值打扰）。
2. **异常误报控制**：在 A72 下，对任意停时 τ，`P(sup_{t≤τ} E_t ≥ 1/α) ≤ α`，即分布漂移下仍 anytime-valid。
3. **归因一致性**：在 A73 下，ACA 后验随证据更新收敛到真实原因（可辨识时）；不可辨识时保守集覆盖真实原因。
4. **需求-异常对账安全**：在 A74 下，任何由需求修正产生的约束都不越过 `SafetyEnvelope`；`P(c_phys) > τ_phys` 时强制安全路径。
5. **跨会话适应**：在 A75 下，NIM 先验的贝叶斯遗憾随会话数 `O(√N)` 增长；遗忘因子使非平稳需求可跟踪。
6. **预算安全**：在 A76 下，`B_need`/`B_anom` 耗尽时系统退化为「被动响应 + 保守安全」，不违反 ERTC 实时契约。
