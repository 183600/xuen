# 第 56 轮（承接第 55 轮 v32 语义-接触接地；灵感循环第 1 轮；本轮灵感：「数据规模」×「双足机器人」）

> 第 55 轮把可行性判据推进到“接触在语义上是否可信、全身耦合下是否可行”，但它默认 `κ(l,c)`、生存核 `K(Σ)`、语义裕度 `m_s` 这些证书知识已经“在那里”。本轮追问一个更底层的问题：**这些知识到底由多少、什么样、来自哪里的数据支撑？** 双足机器人让这个问题变得尖锐，因为跌倒不可逆、硬件有损耗、靠近边界的数据既最有用又最危险。核心矛盾：
> **H24**：证书可信度不是样本数 `N` 的函数，而是“跌倒相关状态空间覆盖”的函数。大量平地行走样本只会让证书在安全区内部变密，却不会让危险边界变窄——**置信度上升而覆盖不上升**，是最隐蔽的虚假安全感。
> **H25**：双足机器人的数据采集本身是一个受约束的控制问题。越靠近跌倒边界信息量越大，边际跌倒成本也越高；数据规模的增长不是免费的，必须把“跌倒预算”当成与算力、存储并列的一等资源。
> **H26**：数据来源异质且相关（仿真、真机、他机、云端）。把混合数据当 iid 会系统性低估证书偏差；sim-to-real gap 主要是**偏差而非方差**，再多样本也压不下去，只能靠换域而不是加量。

## 0. 直觉与动机

**灵感 1（数据规模 → 跌倒相关覆盖，而非样本计数）**
直觉：对双足机器人来说，一百万步平地行走并不告诉你会不会摔。真正决定可行性的，是状态在 **跌倒相关坐标** 上的分布：发散运动分量（DCM/捕获点）、质心动量、支撑多边形裕度、接触力旋量锥裕度、地形坡度/粗糙度、接触模式。把数据规模从标量 `N` 换成覆盖剖面 `μ_D`，才能回答“这些数据到底照亮了生存核的哪一块”。第 55 轮的语义边界裕度 `m_s` 与本轮的动力学边界裕度 `m_d` 一起，构成“双边界”：接触点越靠近任一边界，越需要证据。

**灵感 2（双足机器人 → 跌倒预算与可恢复采集）**
直觉：信息最富集的地方恰是不可逆代价最高的地方。因此数据采集应写成 **跌倒预算约束下的主动学习**：在捕获点可恢复集内做push-recovery、在低摩擦面上做受控滑移，而不是靠真实跌倒换样本。第 55 轮的语义护盾在这里改变角色：它不再只保护部署，也保护**数据采集过程本身**，把探索限制在“摔了也能救回来”的集合里。

**灵感 3（尺度律 → 证书尺度律与交叉点）**
直觉：性能随数据量呈幂律，证书裕度也一样，但多了一项 **偏差地板**：`m_N ≈ m_∞ - c·N_eff^{-β} + b`。`b` 来自仿真-现实差、未建模接触、执行器磨损，它不随 `N` 下降。于是存在两个关键点：`N*`（经验证书首次比解析先验更紧，在此之前该信物理先验）与 `N_b`（数据量超过偏差地板后，再加同类数据毫无收益，该去**换域**而不是**加量**）。这把“数据规模”从越多越好，变成一张有拐点的数据策略图。

**灵感 4（异质数据 → 证据溯源与有效样本量）**
直觉：仿真一小时与真机一小时不是同一种“数据单位”。数据规模应是向量 `(N_sim, N_real, N_xfer)`，每个来源有自己的有效域与证据汇率。用重要性加权与积分概率度量把来源偏差显式化，得到 **有效样本量** `N_eff`。证书携带数据溯源，才能在“云端数据很多但都在别的机器人/别的材质上”时保持诚实。

**灵感 5（云边 → 数据飞轮接口，而非原始数据搬运）**
直觉：云端聚合大规模数据，产出先验、尺度律系数与充分统计量；边端只有少量本地样本，负责本地校准并回传 **覆盖缺口与偏差证据**。接口传的不是数据，而是“充分统计量 + 覆盖证书”。云端据此决定下一批数据该采哪里——这正是第 54/55 轮云边闭环的数据版本：把动作重剖分升级为 **数据重采集**。

## 1. 形式化定义（增量：定义 127–132）

**定义 127（跌倒相关投影与边界覆盖）**
投影 `φ: 𝒳 → 𝒵`，
`φ(x) = (ξ, h, m_sup, m_wr, s_terr, c)`，
其中 `ξ` 为 DCM/捕获点，`h` 为质心动量，`m_sup` 为支撑多边形裕度，`m_wr` 为接触力旋量锥裕度，`s_terr` 为地形坡度/粗糙度，`c` 为接触模式。对数据集 `D={x_i}`，
`μ_D(A) = (1/N)Σ_i 1[φ(x_i)∈A]`，
覆盖半径 `r_D = sup_{x∈K} min_i ||φ(x)-φ(x_i)||`，
跌倒边界覆盖 `cov_∂(D) = μ_D(B_δ(∂K))`。
**数据规模**在本轮指覆盖剖面 `(μ_D, r_D, cov_∂)`，而非 `N`。

**定义 128（数据条件生存核）**
给定置信 `δ`，`K_N(Σ)` 是满足
`Pr[K_N(Σ) ⊆ K(Σ)] ≥ 1-δ`
的内近似，由场景优化/共形 `ε`-网构造。认证裕度 `m_N(x)=dist(x, ∂K_N)`，认证体积 `V_N=vol(K_N ∩ 𝒳_safe)`。`K_N` 只在其数据支撑域内有意义。

**定义 129（证书尺度律）**
在覆盖支撑域内，
`m_N = m_∞ - c·N_eff^{-β} + b`，
`b≥0` 为偏差地板。经验证书与解析先验的交叉点
`N* = inf{N : m_N^{emp} ≥ m_N^{prior}}`，
偏差饱和点 `N_b = (c/b)^{1/β}`。尺度律只允许在 `supp(μ_D)` 内插值；越界外推必须返回“换域采集”，而不是“再加样本”。

**定义 130（跌倒预算数据采集）**
跌倒预算约束 MDP `M_B = (𝒳, 𝒰, P, r_info, c_fall, B)`，
`s.t. E[Σ_t c_fall] ≤ B`，并由护盾保证 `x_{t+1}∈ℛ`（可恢复集，含捕获点回拉能力）。采集策略
`u* = argmax_u ΔI(u) / (ε + E[c_fall(u)])`
`s.t. Pr[x_{t+1}∈ℛ] ≥ 1-δ_r` 且累计跌倒 ≤ `B`；`ΔI` 为证书不确定度（边界覆盖/核体积）的期望下降。

**定义 131（证据溯源与有效样本量）**
溯源图 `G_D=(V_s,E_s)`；来源 `s` 有有效域 `Ω_s`、可靠度 `ρ_s`、重要性权重 `w_i`。
`ESS = (Σ_i w_i)^2 / Σ_i w_i^2`，
来源偏差 `b = max_s d_H(P_target, P_s)`（积分概率度量），
`N_eff = ESS / (1 + b/b_0)`。
仅当 `overlap(Ω_s, Ω_target) ≥ θ_sup` 时该来源计入；否则只作先验、不作证据。

**定义 132（数据-证书联合证书）**
`J_d = (D_prof, cov_∂, β, N*, b, ESS, B_spent, K_N, evidence)`。
若 `cov_∂ ≥ θ_cov`、`ESS ≥ θ_ess`、`b ≤ Θ_b`、外推误差 `≤ Θ_ext`、`B_spent ≤ B`，且本地数据机制落在已认证机制内，则数据-证书可部署。`D_prof` 记录来源、覆盖剖面与采集所耗跌倒预算，使“部署”同时意味着“在可覆盖、可溯源、可负担的数据机制内”。

## 2. 关键算法 伪代码

### IP-127 FRC（Fall-Relevant Coverage）

```python
def fall_relevant_projection(x):
    return {
        'dcm': x.dcm,
        'h': centroidal_momentum(x),
        'm_sup': support_polygon_margin(x),
        'm_wr': wrench_cone_margin(x),
        'slope': x.terrain_slope,
        'mode': x.contact_mode,
    }

def coverage_profile(D, K, delta, grid):
    Z = [fall_relevant_projection(x) for x in D]
    mu = grid_histogram(Z, grid)
    r = covering_radius(Z, grid_of(K))
    boundary = grid_of(boundary_K(K))
    cov_b = mean(any(dist(z, z_i) <= delta for z_i in Z) for z in boundary)
    return Coverage(mu=mu, radius=r, boundary=cov_b)
```

### IP-128 DKV（Data-conditioned Viability Kernel）

```python
def data_conditioned_kernel(Sigma, C_plus, D, delta, eps_phi):
    samples = [fall_relevant_projection(x) for x in D]
    K_emp = inner_hull(samples)
    r = covering_radius(samples, state_grid(K_emp))
    K_N = erode(K_emp, r + eps_phi)           # phi-Lipschitz 保守化
    delta_eff = pac_bound(len(D), delta)      # 场景/共形修正
    if not contact_modes_covered(D, C_plus):
        return ('reject', 'contact_mode_gap')
    return KernelApprox(K_in=K_N, confidence=1-delta_eff)
```

### IP-129 CSL（Certificate Scaling Law）

```python
def certificate_scaling_law(profiles):
    # profiles: (N_eff, m_N) 来自多档数据预算
    m_inf, c, beta = robust_fit(profiles)     # m = m_inf - c*N^-beta
    b = bias_floor(profiles)                  # 平台值 + 溯源偏差
    N_star = crossover(m_inf, c, beta, m_prior)
    N_b = saturation(c, beta, b)              # (c/b)^(1/beta)
    return ScalingLaw(m_inf, c, beta, b, N_star, N_b)

def extrapolate(law, N, in_support):
    if not in_support:
        return ('reject', 'out_of_support', 'collect_new_domain')
    if N > law.N_b:
        return ('reject', 'bias_limited', 'collect_new_domain')
    return ('ok', law.m_inf - law.c * N**(-law.beta) + law.b)
```

### IP-130 FBA（Fall-Budgeted Acquisition）

```python
def fall_budgeted_acquisition(policy, D, B, delta_r, alloc):
    b, D = B, set(D)
    while b > 0 and alloc.remaining():
        cand = propose(policy, D)                 # 边界附近高信息候选
        if shield.expected_falls(cand, D) > b:
            cand = recovery_first_candidate(D)    # 捕获点可恢复动作
        if not shield.recoverable(cand, delta_r):
            continue
        roll = execute(cand)
        D.add(roll)
        b -= roll.falls
        update_coverage(D, roll)
    return D, b
```

### IP-131 EPR（Evidence Provenance Reweighting）

```python
def evidence_profile(D, G_D, target):
    w = []
    for x in D:
        s = source_of(x, G_D)
        if support_overlap(s, target) < theta_sup:
            continue
        w.append(importance_weight(x, s, target) * reliability(s))
    ess = (sum(w)**2) / sum(wi**2 for wi in w if wi > 0)
    b = max(ipm(target, s) for s in sources(G_D) if support_overlap(s, target) >= theta_sup)
    return Evidence(ess=ess, bias=b, n_eff=ess / (1 + b/b0))
```

### IP-132 DCC（Data-Certificate Composite）

```python
def data_certificate(traj, D, Sigma, budgets):
    cov = coverage_profile(D, K(Sigma), budgets.delta)
    ev = evidence_profile(D, budgets.provenance, target=traj.domain)
    law = certificate_scaling_law(profiles_from(ev))
    K_N = data_conditioned_kernel(Sigma, C_plus, D, budgets.delta, budgets.eps_phi)
    if cov.boundary < budgets.theta_cov:
        return ('reject', 'fall_boundary_uncovered', cov.boundary)
    if ev.ess < budgets.theta_ess or ev.bias > budgets.Theta_b:
        return ('reject', 'evidence_insufficient', ev.ess, ev.bias)
    if law.N_b < ev.n_eff:
        return ('reject', 'bias_limited', law.N_b)
    if K_N is None or distance_to_boundary_K(traj, K_N) < budgets.theta_m:
        return ('reject', 'data_kernel_margin_fail')
    return ('ok', DataCert(cov, ev, law, K_N, budgets.B_spent))

def cloud_edge_data_flywheel(cloud, edge):
    stats = cloud.sufficiency_statistics()        # 先验/尺度律/溯源
    cov_e = edge.local_coverage()
    if not within_certified_regime(cov_e, stats.law):
        return ('collect', edge.coverage_gap(), edge.bias_evidence())
    return ('ok', edge.local_kernel(stats.prior),
            stats.merge_uncertainty(cov_e))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| FRC | O(N·d + \|grid\|·log N) | O(\|grid\|) | `φ` 保留跌倒相关性、边界网格覆盖 |
| DKV | O(N·QP + \|X\|) | O(\|X\|) | 内近似 high-prob、`φ` Lipschitz 保守化 |
| CSL | O(K·N_eff) | O(K) | 只在支撑域内拟合、偏差地板显式 |
| FBA | O(T·(BO+QP)) | O(\|D\|) | 跌倒预算硬约束、可恢复集护盾 |
| EPR | O(N·\|S\|) | O(N) | 来源有效域、IPM 偏差上界 |
| DCC | O(\|轨迹\|+N) | O(N) | 覆盖/ESS/偏差三项闭合、越界拒绝 |

**正确性定理（Data-Conditioned Viability Soundness）**
假设第 55 轮 (A29)–(A32) 与第 54 轮 (A26)–(A28) 成立；新增：
**(A33)** `φ` 对可行性标签 Lipschitz，`||φ(x)-φ(x')||≤ε_φ ⇒ |viable(x)-viable(x')|≤L_φε_φ`；
**(A34)** 各溯源层内样本可交换，重要性权重纠正协变量偏移，且 IPM 偏差 `≤ b`；
**(A35)** 场景/共形内近似在置信 `δ` 下有效；
**(A36)** 采集全程满足跌倒预算 `B`，护盾保持 `x∈ℛ`。
则部署后单步安全概率：
```
P_safe ≥ 1 - δ_PAC - P(cov_∂ < θ_cov) - P(b > Θ_b)
        - P(extrapolation outside support) - P(fall budget violated)
        - P(因果关系层失守)        # 第 55 轮项
```
关键：**数据规模通过“覆盖、有效样本量、偏差上界”三个量进入证书，而不是通过裸样本数 `N`**；任何一个量不达标，都不允许把“数据很多”当作“证书很紧”。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 覆盖度量漏掉真正危险的维度 | 高 | 对抗边界搜索 + 随机投影集成 + 残差风险项 |
| 尺度律外推在生产分布外失效 | 高 | 仅支撑域内插值 + 保守包络 + “换域而非加量”触发器 |
| 混合来源数据偏差被低估 | 高 | 溯源图 + IPM 上界 + 分源重校准 |
| 跌倒预算对稀有事件过于乐观 | 高 | 共形稀有事件界 + 恢复优先采集 + 硬预算 |
| 采集改变被控对象（磨损/漂移） | 中 | 在线漂移检测 + 分段尺度律重估 |

## 6. 本轮最大风险

**一句话**：把“数据规模”从裸样本数升级为“跌倒相关覆盖 + 有效样本量 + 偏差上界”能让证书对数据诚实，但整套 soundness 押在**覆盖度量确实抓住了跌倒相关维度、且尺度律的偏差地板被正确估计**这两件事上；一旦覆盖度量漏掉某个危险自由度，或混合来源的 sim-to-real 偏差被当作方差而继续“加量”，证书会带着更高的置信度在未覆盖的边界上放行，最终让双足机器人以“数据充足”的名义摔进从未被样本照亮的区域——因此必须以对抗边界搜索、溯源偏差上界与硬跌倒预算三重护栏，宁可承认数据不够，绝不把“样本更多”当作“安全更近”。

# 第 56 轮产物 · 创新点清单 v33：ScaleEdge-GenSim++++（FRC×DKV×CSL×FBA×EPR×DCC）

> 承接第 55 轮 v32 语义-接触接地（IP-121~126）与第 54 轮 v31 动作-协同层（IP-115~120）。本轮在“语义可信、接触可行”之上增加 **数据-证书层**，回答第 55 轮遗留的元问题：`κ`、`K(Σ)`、`m_s` 这些证书知识由多少、什么样、来自哪里的数据支撑？四个转换：
> - **数据规模 → 跌倒相关覆盖**：不再用 `N`，而用 DCM/质心动量/支撑与力锥裕度/地形/接触模式的覆盖剖面，尤其看跌倒边界 `∂K` 的覆盖；

### IP-127 FRC

```python
def fall_relevant_projection(x):
    return (x.dcm, centroidal_momentum(x), support_polygon_margin(x),
            wrench_cone_margin(x), x.terrain_slope, x.contact_mode)

def coverage_profile(D, K, delta, grid):
    Z = [fall_relevant_projection(x) for x in D]
    mu = grid_histogram(Z, grid)
    r = covering_radius(Z, grid_of(K))
    cov_b = mean(nearest_dist(z, Z) <= delta for z in grid_of(boundary_K(K)))
    return Coverage(mu=mu, radius=r, boundary=cov_b)
```

### IP-128 DKV

```python
def data_conditioned_kernel(Sigma, C_plus, D, delta, eps_phi):
    Z = [fall_relevant_projection(x) for x in D]
    K_emp = inner_hull(Z)
    r = covering_radius(Z, state_grid(K_emp))
    K_N = erode(K_emp, r + eps_phi)
    delta_eff = pac_bound(len(D), delta)
    if not contact_modes_covered(D, C_plus):
        return ('reject', 'contact_mode_gap')
    return KernelApprox(K_in=K_N, confidence=1 - delta_eff)
```

### IP-129 CSL

```python
def certificate_scaling_law(profiles):
    m_inf, c, beta = robust_fit(profiles)
    b = bias_floor(profiles)
    N_star = crossover(m_inf, c, beta, m_prior)
    N_b = (c / b) ** (1 / beta) if b > 0 else inf
    return ScalingLaw(m_inf, c, beta, b, N_star, N_b)

def extrapolate(law, N, in_support):
    if not in_support:
        return ('reject', 'out_of_support', 'collect_new_domain')
    if N > law.N_b:
        return ('reject', 'bias_limited', 'collect_new_domain')
    return ('ok', law.m_inf - law.c * N ** (-law.beta) + law.b)
```

### IP-130 FBA

```python
def fall_budgeted_acquisition(policy, D, B, delta_r, alloc):
    b, D = B, set(D)
    while b > 0 and alloc.remaining():
        cand = propose(policy, D)
        if shield.expected_falls(cand, D) > b:
            cand = recovery_first_candidate(D)
        if not shield.recoverable(cand, delta_r):
            continue
        roll = execute(cand)
        D.add(roll)
        b -= roll.falls
        update_coverage(D, roll)
    return D, b
```

### IP-131 EPR

```python
def evidence_profile(D, G_D, target):
    w = []
    for x in D:
        s = source_of(x, G_D)
        if support_overlap(s, target) < theta_sup:
            continue
        w.append(importance_weight(x, s, target) * reliability(s))
    ess = (sum(w) ** 2) / sum(wi ** 2 for wi in w if wi > 0)
    b = max(ipm(target, s) for s in sources(G_D)
            if support_overlap(s, target) >= theta_sup)
    return Evidence(ess=ess, bias=b, n_eff=ess / (1 + b / b0))
```

### IP-132 DCC + 云边数据飞轮

```python
def data_certificate(traj, D, Sigma, budgets):
    cov = coverage_profile(D, K(Sigma), budgets.delta)
    ev = evidence_profile(D, budgets.provenance, target=traj.domain)
    law = certificate_scaling_law(profiles_from(ev))
    K_N = data_conditioned_kernel(Sigma, C_plus, D, budgets.delta, budgets.eps_phi)
    if cov.boundary < budgets.theta_cov:
        return ('reject', 'fall_boundary_uncovered', cov.boundary)
    if ev.ess < budgets.theta_ess or ev.bias > budgets.Theta_b:
        return ('reject', 'evidence_insufficient', ev.ess, ev.bias)
    if law.N_b < ev.n_eff:
        return ('reject', 'bias_limited', law.N_b)
    if K_N is None or distance_to_boundary_K(traj, K_N) < budgets.theta_m:
        return ('reject', 'data_kernel_margin_fail')
    return ('ok', DataCert(cov, ev, law, K_N, budgets.B_spent))

def cloud_edge_data_flywheel(cloud, edge):

    if not within_certified_regime(cov_e, stats.law):

    return ('ok', edge.local_kernel(stats.prior),
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SCG/WBV/SSF（第 55 轮） | O(\|Ω\|·(\|L\|+\|C\|)) / O(\|X\|·T·QP) / O(QP) | O(\|Ω\|·\|L\|) / O(\|X\|) | 语义接触 sound、护盾回退 |
| FRC | O(N·d + \|grid\|·log N) | O(\|grid\|) | `φ` 保留跌倒相关性、边界网格完备 |
| DKV | O(N·QP + \|X\|) | O(\|X\|) | 内近似 high-prob、`φ`-Lipschitz 保守 |
| CSL | O(K·N_eff) | O(K) | 仅支撑域拟合、偏差地板显式 |
| FBA | O(T·(BO+QP)) | O(\|D\|) | 跌倒预算硬约束、`ℛ` 内探索 |
| EPR | O(N·\|S\|) | O(N) | 来源有效域、IPM 上界 |
| DCC | O(\|轨迹\|+N) | O(N) | 覆盖/ESS/偏差闭合、越界拒绝 |

**正确性定理（Data-Conditioned Viability Soundness）**
假设第 55 轮 (A29)–(A32) 与第 54 轮 (A26)–(A28) 成立；新增：
**(A33)** `φ` 对可行性标签 Lipschitz，`||φ(x)-φ(x')||≤ε_φ ⇒ |viable(x)-viable(x')|≤L_φε_φ`；
**(A34)** 各溯源层内样本可交换，重要性权重纠正协变量偏移，且 IPM 偏差 `≤ b`；
**(A35)** 场景/共形内近似在置信 `δ` 下有效；
**(A36)** 采集全程满足跌倒预算 `B`，护盾保持 `x∈ℛ`。
则部署后单步安全概率：
```
P_safe ≥ 1 - δ_PAC - P(cov_∂ < θ_cov) - P(b > Θ_b)
        - P(extrapolation outside support) - P(fall budget violated)
        - P(语义/接触层失守)          # 第 55 轮项
```
关键：**数据规模经由“覆盖、有效样本量、偏差上界”进入证书；裸样本数 `N` 不再出现在安全界里**。这正是把“数据很多”与“证书很紧”解耦的地方。

## 6. 本轮最大风险

**一句话**：数据-证书层把“数据规模”从裸样本数升级为“跌倒相关覆盖 + 有效样本量 + 偏差上界”，使证书第一次能对数据诚实，但其 soundness **双重押注在覆盖度量确实抓住跌倒相关自由度、以及尺度律偏差地板被正确估计**上；一旦覆盖度量漏掉某个危险维度，或把混合来源的 sim-to-real 偏差误当方差而继续加量，证书会以更高置信度在未照亮的边界上放行动作，让双足机器人在“数据充足”的名义下摔进从未被采样的区域——因此必须以 **对抗边界搜索 + 溯源 IPM 偏差上界 + 硬跌倒预算** 三重护栏，宁可承认数据不够，绝不把“样本更多”当作“安全更近”。
