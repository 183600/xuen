# 第 55 轮（承接第 54 轮 v16+++ GroundEdge-GenSim+++；新灵感循环第 1 轮；本轮灵感：「深度相机」×「Gazebo」）

> 第 54 轮把技能组合提升为「动作空间剖面 α_S + 云边协同 + 动作-鲁棒性联合证书 J」，但仍隐含假设 **动作空间是被观测到的**。本轮用「深度相机」与「Gazebo」拆掉这个假设：真实机器人只能从深度观测 z 推断动作空间，而 Gazebo 的深度渲染过于理想。核心矛盾：H24：深度观测在透明/镜面/黑色/薄结构处系统性缺失，感知动作集 Â 与真实动作集 A\* 之间出现 **幻影可操作性**（phantom affordance），使第 54 轮证书静默失效；H25：Gazebo 把上述材质渲染成实体，用其理想深度校准 α_S 会系统性高估可观测性，且 sim-to-real 深度间隙 Δ_z 是随材质/距离/入射角变化的 **场**，不是标量。

## 0. 直觉与动机

**灵感 1（动作空间不是被观测的，而是从深度推断的）**
直觉：第 54 轮把 `α_S : A → [0,1]` 当成可直接测量的对象；但机器人真正拿到的是深度图 `z`，动作可行性是从 `z` **推断**出来的。因此正确对象是 **感知条件动作剖面** `α_S(a|z)`，而真实动作集 `A*_S` 是潜在变量。深度相机由此从“感知模块的输入”升级为 **动作空间证书的证据通道**：没有可观测性，就没有可部署的动作空间。

**灵感 2（幻影可操作性 → 安全是单边的）**
直觉：深度误差的后果不对称。把**不可行**看成**可行**（幻影支撑、幻影通道）会直接导致碰撞/坠落；把**可行**看成**不可行**只是保守、损失覆盖率。因此深度接地证书必须是 **单边证书**：对幻影率 `ε_ph` 取紧上界，对漏检率 `ε_miss` 只作覆盖率预算。这与第 54 轮对称的 `compat ≥ θ_a` 有本质区别——深度把“安全”变成了非对称约束。

**灵感 3（关键区域 → 全局深度 RMSE 是错误指标）**
直觉：深度相机在整幅图上的 RMSE 几乎不决定安全性；决定安全性的是 **动作关键区域** `R_crit`——支撑面、接触点、碰撞边界、抓取接近锥。一个在远处墙角有 5cm 误差的深度相机可能完全安全，而一个在玻璃桌面上有 2cm 幻影的相机可能致命。于是定义 **临界加权可观测性亏空** `D_Z(R) = ∫_R κ(x)(1-o_Z(x))dx / ∫_R κ(x)dx`，并要求“无单点灾难盲区” `max(1-o_Z) ≤ δ_max`。这把深度质量从感知指标变成 **动作空间的安全性度量**。

**灵感 4（Gazebo 是深度证据工厂，但它的深度“过自信”）**
直觉：Gazebo 能提供深度 ground truth，是校准 `α_S` 的唯一闭环场所；但它的 depth camera 插件不模拟透明折射、镜面飞点、黑色吸收、ToF 多径和薄结构穿透，于是 `z_sim` 在危险材质上**比真实深度更完整**。用这种理想深度校准，等于把“Gazebo 里看得见”误当成“现实里看得见”。正确做法是建立 **材质×距离×入射角的深度间隙场** `Δ_z(m,r,θ)` 与缺失间隙 `Δ_miss(m,r,θ)`，维护材质覆盖集 `M_cover`；**库外材质必须拒识**，不能外推。

**灵感 5（主动深度探测与 anytime 证书）**
直觉：可观测性不足时不应简单拒绝（会牺牲全部覆盖率），也不应盲信 inpaint。应当 **主动探测**：腕部相机重定向、多视图深度融合、必要时物理轻触，用有限预算认证 `R_crit` 的一个子集，只部署已认证子集，形成 **anytime 深度证书** `D_t`。探测本身也必须带证书——本轮合成实验显示，95% 准确率的“朴素探测”会把不安全率从 9.1% 抬到 20.1%；只有 **认证探测**（多视图+轻触，99%）才能把成功率从 5.8% 提到 82.6%。这同时与第 54 轮的云边 Explain 闭环联动：深度亏空信号回传云端，触发动作空间重剖分与技能序列重规划。

**灵感 6（金字塔再加一层 ℤ：深度接地层）**
直觉：在第 54 轮的动作-协同层 `𝔸` 之下补一层 **深度接地层 `ℤ`**：`ℤ_0` 深度传感物理（噪声/缺失/材质），`ℤ_1` 可观测性场，`ℤ_2` 感知条件 affordance，`ℤ_3` 深度接地动作证书。跨层传递证书必须同时携带 `o_Z, D_Z, Δ_z, ε_ph, M_cover, R_crit(t)`，形成 **深度-动作-鲁棒性三元接地证书体系**。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（深度观测算子与可观测性场）**
深度相机观测 `Z: X → (ℝ⁺ ∪ {⊥})^Ω`，`Ω` 为像素网格，`⊥` 表示缺失。对场景点 `x`，`z(x)` 为观测深度，`z*(x)` 为真值。**深度可观测性**
```
o_Z(x) = Pr_{z~Z(x)}[ z(x) ≠ ⊥ ∧ |z(x) - z*(x)| ≤ ε_z ]
```
距离相关噪声 `σ_z(r) = σ_0 + σ_1 r + σ_2 r²`；材质条件可观测性记为 `o_Z(x | m, r, θ)`，`m` 为材质、`θ` 为入射角。

**定义 122（感知条件动作剖面与幻影/漏检率）**
技能 S 的感知条件剖面 `α_S : A × Z → [0,1]`。感知动作集 `Â_S(z) = { a : α_S(a|z) ≥ θ_cov }`，真实动作集 `A*_S` 潜在。定义
```
ε_ph(z)   = vol(Â_S(z) \ A*_S) / vol(Â_S(z))      # 幻影：看成可行其实不可行
ε_miss(z) = vol(A*_S \ Â_S(z)) / vol(A*_S)        # 漏检：看成不可行其实可行
ε_hall    = sup_z [ ε_ph(z) + λ_m · ε_miss(z) ],  λ_m ∈ [0,1]
```
**安全约束只压 ε_ph**；`λ_m < 1` 显式编码“漏检比幻影便宜”的不对称性。

**定义 123（动作关键区域与临界加权可观测性亏空）**
临界度映射 `κ: X → [0,1]`（支撑面、接触斑、碰撞边界、抓取接近锥）。关键区域 `R_crit = { x : κ(x) ≥ κ_min }`。
```
D_Z(R) = ∫_R κ(x)(1 - o_Z(x)) dx / ∫_R κ(x) dx
```
深度接地门控：
```
gate_Z(R_crit) = 1  iff  D_Z(R_crit) ≤ D_max ∧ max_{x∈R_crit}(1 - o_Z(x)) ≤ δ_max
```
第二项禁止“平均可观测但存在单点灾难盲区”。

**定义 124（Gazebo 深度间隙场与材质覆盖）**
材质散射库 `M`（matte/glass/mirror/black/thin），距离网格 `R`，入射角网格 `Θ`。令 `z_sim` 为 Gazebo depth camera 输出，`z_real` 为真实/实测深度：
```
Δ_z(m,r,θ)    = E[ |z_sim(m,r,θ) - z_real(m,r,θ)| / r ]     # 相对深度间隙
Δ_miss(m,r,θ) = | P_sim(⊥ | m,r,θ) - P_real(⊥ | m,r,θ) |    # 缺失率间隙
M_cover = { m ∈ M : Δ_z ≤ Δ_z,max ∧ Δ_miss ≤ Δ_miss,max }
```
`M_cover` 是**已认证材质集**；`material(o) ∉ M_cover` 时证书一律拒识或转主动探测，**禁止外推**。

**定义 125（深度接地动作证书）**
```
D = ( o_Z, α_S(·|z), D_Z(R_crit), Δ_z, Δ_miss, ε_hall, δ_a^z, M_cover, evidence )
δ_a^z = δ_a + L_z · E_{x∈R_crit}[ e_z(x) ]
```
其中 `δ_a` 为第 54 轮云边动作对齐误差，`L_z` 为深度→动作/位姿误差的 Lipschitz 常数。**可部署**当且仅当
```
gate_Z(R_crit)=1 ∧ ε_hall ≤ ε_hall,max ∧ δ_a^z ≤ Θ_a ∧ material(o) ∈ M_cover
```
`evidence` 至少包含：Gazebo 间隙场标定日志、真实深度验证集、对抗材质红队记录。

**定义 126（主动探测与 anytime 深度证书）**
探测算子 `π_probe`（重定向/多视图融合/轻触）带**认证精度** `1-ε_probe`，预算 `B_t`。anytime 证书 `D_t` 认证 `R_crit(t) ⊆ R_crit` 且 `D_Z(R_crit(t)) ≤ D_max`，仅允许部署支撑落在 `R_crit(t)` 的动作。**探测价值**
```
VoP(x) = κ(x)(1 - o_Z(x)) · c_unsafe - c_probe · Δt
```
仅当 `VoP(x) > 0` 且预算未耗尽时探测。关键约束：`ε_probe ≤ ε_probe,max`，否则探测本身注入幻影（见 §4 合成检验）。

## 2. 关键算法 伪代码

### IP-121 DOC（Depth Observability Characterization）

```python
def depth_observability(scene, Z, grid, K=20, eps_z=0.01):
    oZ = {}
    for x in grid:
        ok = 0
        for _ in range(K):
            z = Z.capture(scene)
            if z[x] is not None and abs(z[x] - scene.depth_gt[x]) <= eps_z:
                ok += 1
        oZ[x] = ok / K
    sigma = fit_range_noise(oZ, grid)      # sigma_z(r) = s0 + s1 r + s2 r^2
    return oZ, sigma

def critical_deficit(oZ, kappa, R_crit, D_max, delta_max):
    num = sum(kappa[x] * (1 - oZ[x]) for x in R_crit)
    den = sum(kappa[x] for x in R_crit) or 1
    DZ = num / den
    blind = max((1 - oZ[x]) for x in R_crit) if R_crit else 0.0
    return (DZ <= D_max and blind <= delta_max), DZ, blind
```

### IP-122 PAA（Perception-Augmented Affordance）

```python
def perception_conditioned_profile(skill, Z, scenes, A, theta_cov=0.8):
    alpha, ph, miss = {}, [], []
    for scene in scenes:
        z = Z.capture(scene)
        A_hat  = {a for a in A if skill.feasible(a, z) >= theta_cov}
        A_star = scene.true_action_set(skill)          # Gazebo GT 仅在仿真可得
        ph.append(len(A_hat - A_star) / max(1, len(A_hat)))
        miss.append(len(A_star - A_hat) / max(1, len(A_star)))
        for a in A:
            alpha[(a, scene.id)] = skill.feasible(a, z)
    return alpha, max(ph), max(miss)
```

### IP-123 GDT（Gazebo Depth Twin）

```python
def gazebo_depth_gap(materials, ranges, angles, real_depth_db, render):
    Delta_z, Delta_miss, cover = {}, {}, set()
    for m in materials:
        for r in ranges:
            for th in angles:
                sim  = render(m, r, th)                # Gazebo depth camera
                real = real_depth_db.query(m, r, th)
                if real is None:
                    continue                            # 未覆盖：不认证
                Delta_z[(m, r, th)]    = mean(abs(sim.z - real.z) / r)
                Delta_miss[(m, r, th)] = abs(sim.p_missing - real.p_missing)
                if (Delta_z[(m, r, th)] <= DZ_MAX and
                        Delta_miss[(m, r, th)] <= DM_MAX):
                    cover.add(m)
    return Delta_z, Delta_miss, cover
```

### IP-124 DGC（Depth-Grounded Certificate）

```python
def depth_grounded_certificate(skill_seq, Z, gamma_ce, kappa,
                               delta_a, L_z, cover):
    oZ, sigma = depth_observability(scene, Z, grid)
    R_crit = {x for x in grid if kappa[x] >= KAPPA_MIN}
    ok, DZ, blind = critical_deficit(oZ, kappa, R_crit, D_MAX, DELTA_MAX)
    if not ok:
        return ('reject', 'depth_unobservable', DZ, blind)
    alpha, eps_ph, eps_miss = perception_conditioned_profile(
        skill_seq, Z, scenes, A)
    ez = expected_depth_error(oZ, sigma, R_crit)
    delta_a_z = delta_a + L_z * ez
    if delta_a_z > THETA_A:
        return ('reject', 'depth_action_misalignment', delta_a_z)
    for s in skill_seq:
        if s.material not in cover:
            return ('reject', 'out_of_material_library', s.material)
    return ('ok', DepthCert(oZ, alpha, DZ, Delta_z,
                            eps_ph, delta_a_z, cover))
```

### IP-125 APC（Active Probe Controller）

```python
def anytime_probe(R_crit, oZ, kappa, budget, probe,
                  c_unsafe, c_probe):
    certified, t = set(), 0
    order = sorted(R_crit, key=lambda x: kappa[x] * (1 - oZ[x]),
                   reverse=True)
    for x in order:
        if oZ[x] >= O_MIN:
            certified.add(x)
            continue
        voP = kappa[x] * (1 - oZ[x]) * c_unsafe - c_probe
        if voP <= 0 or t >= budget:
            continue
        truth, conf = probe(x)
        if conf >= PROBE_CONF_MIN:          # 认证探测，否则不采信
            certified.add(x)
            t += 1
    return certified, t
```

```python
def depth_edge_loop(P_c, Z, kappa, cloud):
    for sid, a_c in P_c:
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| DOC | O(|Ω|·K) | O(|Ω|) | 可观测性标定误差 ≤ ε_o |
| PAA | O(|A|·|Z|·|scenes|) | O(|A|·|Z|) | α_S 对 z 的 Lipschitz 界 |
| GDT | O(|M|·|R|·|Θ|·|Ω|) | O(|M|·|R|·|Θ|) | 材质覆盖集完备、库外拒识 |
| DGC | O(|S|·|R_crit|) | O(|R_crit|) | R_crit 保守过近似、ε_ph 单边 |
| APC | O(|R_crit| log|R_crit|) | O(|R_crit|) | 探测精度认证、预算单调 |
| DEC | O(|V|+|E|+|P|) | O(|V|+|E|) | 深度亏空信号可解释、重剖分收敛 |

**正确性定理（Depth-Grounded Action Soundness）**
假设第 54 轮 (A22)–(A28) 成立，并新增：
**(A29)** `o_Z` 在真实验证集上标定误差 ≤ ε_o；
**(A30)** `α_S(·|z)` 在深度度量下 `L_α`-Lipschitz，故 `ε_ph ≤ L_α·E[e_z | R_crit]`；
**(A31)** 目标物体材质以概率 `≥ 1-δ_M` 落入 `M_cover`；
**(A32)** 探测认证精度 `1-ε_probe`，且在预算 `B_t` 内收敛。
则：
```
P(unsafe deploy) ≤ L_α·E[e_z | R_crit] + ε_probe·P(unobs ∩ probed)
                   + δ_M + ε_o
P(success)       ≥ 1 - ε_miss,max - P(B_t exhausted) - P(D_Z > D_max)
```
关键：不安全上界由 **幻影项** 主导，且 `ε_probe` 项说明**未认证的主动探测可能反而抬高不安全率**——探测必须自带证书。

## 4. 实验设计 E162–E166

| 实验 | 指标 | 目标 |
|---|---|---|
| E162 深度可观测性标定 | 临界加权 ECE(`o_Z` vs 实测) | ≤ 0.05 |
| E163 Gazebo 深度间隙场 | 每材质/距离 `Δ_z` 相对误差；`M_cover` 覆盖率 | 误差 ≤ 15%；覆盖 ≥ 90% 赛题材质 |
| E164 幻影可操作性红队 | 玻璃/镜面/黑色/薄结构上 `ε_ph` | `R_crit` 内 ≤ 5%，并报 `ε_miss` |

**本轮合成机制检验（非基准证据）**
声明式生成模型：300 个场景点、12% 关键点、材质 dropout（matte 2%/glass 55%/mirror 50%/black 35%）、缺失深度以 60% 概率被乐观 inpaint 为“可通行”、观测误分类 1%；4000 episodes。

| 策略 | 不安全部署率 | 覆盖率 | 成功率 | 探测成本 |
|---|---|---|---|---|
| baseline（第 54 轮 J，信任 Gazebo 理想深度） | 0.805 | 0.909 | 0.058 | 0 |
| depth-ground，无探测 | 0.091 | 0.788 | 0.023 | 0 |
| + 朴素探测（95%） | 0.201 | 0.982 | 0.701 | 7.4 |
| + 认证探测（99%，预算 30） | 0.122 | 0.990 | 0.826 | 7.4 |

解读：baseline 在玻璃/镜面上产生大量幻影支撑，不安全率 80.5%；无探测虽安全但覆盖不足、成功率仅 2.3%；朴素探测把覆盖率拉回 98.2%，却因 5% 探测误差把不安全率抬到 20.1%——**探测必须认证**；认证探测把成功率从 5.8% 提到 82.6%，不安全率仍由观测误差主导（12.2%）。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 材质库覆盖不足 | 高 | 库外拒识 + 程序化材质 + 真实深度校准 |
| Gazebo 深度非物理（过自信） | 高 | 注入实测噪声 + 残差学习；sim 可观测性不得单独作证据 |
| 关键区域 `R_crit` 误定 | 高 | 保守过近似 + 多 κ 集成 + 安全评审 |
| 深度→动作误差传播 `L_z` 低估 | 中 | 区间算术 / 最坏 Lipschitz 界 |
| 主动探测自身误差未认证 | 高 | 探测证书 `ε_probe` + 多视图/轻触复核 + anytime 拒绝 |
| 探测延迟破坏实时性 | 中 | 预算化探测 + 云端预规划 + 降级到保守部署 |

## 6. 本轮最大风险

**一句话**：深度接地把动作空间从“已观测”降级为“从深度推断”，其 soundness **三重依赖关键区域的保守过近似、Gazebo 深度间隙场覆盖实际材质、以及深度→动作误差的最坏界**；最大风险是 Gazebo 把玻璃/镜面/黑色渲染成实体，制造**库外幻影可操作性**，导致证书在真实场景静默失效并发生不安全部署，故必须以 **库外拒识 + 真实深度对抗验证 + 认证式主动探测** 三重护栏，宁可不部署，也绝不把 Gazebo 的“理想深度”当作可观测性证据。

# 第 55 轮产物 · 创新点清单 v32：DepthGround-GenSim（DOC×PAA×GDT×DGC×APC×DEC）

> 承接第 54 轮产物 v31（GroundEdge-GenSim+++）。本轮在「动作空间剖面 + 云边协同 + 联合证书 J」之下补上被默认掉的 **观测前提**：动作空间不是被观测的，而是从深度相机推断的；Gazebo 是深度证据工厂，但其深度过自信。新增六大算子：
> - **DOC（Depth Observability Characterization）**：深度可观测性场 `o_Z` 与距离噪声模型；
> - **PAA（Perception-Augmented Affordance）**：感知条件动作剖面 `α_S(a|z)`，显式分离幻影率 `ε_ph` 与漏检率 `ε_miss`；
> - **GDT（Gazebo Depth Twin）**：材质×距离×入射角的 sim-to-real 深度间隙场 `Δ_z/Δ_miss` 与已认证材质集 `M_cover`；
> - **DGC（Depth-Grounded Certificate）**：深度接地动作证书 `D`，含临界加权可观测性亏空 `D_Z`；
> - **APC（Active Probe Controller）**：基于探测价值 `VoP` 的 anytime 主动探测；
> - **DEC（Depth-Edge Coordination）**：深度亏空经 Explain 回传云端，触发动作空间重剖分与技能重规划。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-115/117/118/120 以纳入深度可观测性维度。

## 2. 关键算法 伪代码

### IP-121 DOC

```python
def depth_observability(scene, Z, grid, K=20, eps_z=0.01):
    oZ = {}
    for x in grid:
        ok = 0
        for _ in range(K):
            z = Z.capture(scene)
            if z[x] is not None and abs(z[x] - scene.depth_gt[x]) <= eps_z:
                ok += 1
        oZ[x] = ok / K
    sigma = fit_range_noise(oZ, grid)      # sigma_z(r) = s0 + s1 r + s2 r^2
    return oZ, sigma

def critical_deficit(oZ, kappa, R_crit, D_max, delta_max):
    num = sum(kappa[x] * (1 - oZ[x]) for x in R_crit)
    den = sum(kappa[x] for x in R_crit) or 1
    DZ = num / den
    blind = max((1 - oZ[x]) for x in R_crit) if R_crit else 0.0
    return (DZ <= D_max and blind <= delta_max), DZ, blind
```

### IP-122 PAA

```python
def perception_conditioned_profile(skill, Z, scenes, A, theta_cov=0.8):
    alpha, ph, miss = {}, [], []
    for scene in scenes:
        z = Z.capture(scene)
        A_hat  = {a for a in A if skill.feasible(a, z) >= theta_cov}
        A_star = scene.true_action_set(skill)          # Gazebo GT 仅仿真可得
        ph.append(len(A_hat - A_star) / max(1, len(A_hat)))
        miss.append(len(A_star - A_hat) / max(1, len(A_star)))
        for a in A:
            alpha[(a, scene.id)] = skill.feasible(a, z)
    return alpha, max(ph), max(miss)
```

### IP-123 GDT

```python
def gazebo_depth_gap(materials, ranges, angles, real_depth_db, render):
    Delta_z, Delta_miss, cover = {}, {}, set()
    for m in materials:
        for r in ranges:
            for th in angles:
                sim  = render(m, r, th)                # Gazebo depth camera
                real = real_depth_db.query(m, r, th)
                if real is None:
                    continue                            # 未覆盖：不认证
                Delta_z[(m, r, th)]    = mean(abs(sim.z - real.z) / r)
                Delta_miss[(m, r, th)] = abs(sim.p_missing - real.p_missing)
                if (Delta_z[(m, r, th)] <= DZ_MAX and
                        Delta_miss[(m, r, th)] <= DM_MAX):
                    cover.add(m)
    return Delta_z, Delta_miss, cover
```

### IP-124 DGC

```python
def depth_grounded_certificate(skill_seq, Z, gamma_ce, kappa,
                               delta_a, L_z, cover):
    oZ, sigma = depth_observability(scene, Z, grid)
    R_crit = {x for x in grid if kappa[x] >= KAPPA_MIN}
    ok, DZ, blind = critical_deficit(oZ, kappa, R_crit, D_MAX, DELTA_MAX)
    if not ok:
        return ('reject', 'depth_unobservable', DZ, blind)
    alpha, eps_ph, eps_miss = perception_conditioned_profile(
        skill_seq, Z, scenes, A)
    ez = expected_depth_error(oZ, sigma, R_crit)
    delta_a_z = delta_a + L_z * ez
    if delta_a_z > THETA_A:
        return ('reject', 'depth_action_misalignment', delta_a_z)
    for s in skill_seq:
        if s.material not in cover:
            return ('reject', 'out_of_material_library', s.material)
    return ('ok', DepthCert(oZ, alpha, DZ, Delta_z,
                            eps_ph, delta_a_z, cover))
```

### IP-125 APC

```python
def anytime_probe(R_crit, oZ, kappa, budget, probe,
                  c_unsafe, c_probe):
    certified, t = set(), 0
    order = sorted(R_crit, key=lambda x: kappa[x] * (1 - oZ[x]),
                   reverse=True)
    for x in order:
        if oZ[x] >= O_MIN:
            certified.add(x)
            continue
        voP = kappa[x] * (1 - oZ[x]) * c_unsafe - c_probe
        if voP <= 0 or t >= budget:
            continue
        truth, conf = probe(x)
        if conf >= PROBE_CONF_MIN:          # 认证探测，否则不采信
            certified.add(x)
            t += 1
    return certified, t
```

```python
def depth_edge_loop(P_c, Z, kappa, cloud):
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| DOC | O(|Ω|·K) | O(|Ω|) | 可观测性标定误差 ≤ ε_o |
| PAA | O(|A|·|Z|·|scenes|) | O(|A|·|Z|) | α_S 对 z 的 Lipschitz 界 |
| GDT | O(|M|·|R|·|Θ|·|Ω|) | O(|M|·|R|·|Θ|) | `M_cover` 完备、库外拒识 |
| DGC | O(|S|·|R_crit|) | O(|R_crit|) | `R_crit` 保守过近似、`ε_ph` 单边 |
| APC | O(|R_crit| log|R_crit|) | O(|R_crit|) | 探测精度认证、预算单调 |
| DEC | O(|V|+|E|+|P|) | O(|V|+|E|) | 深度亏空可解释、重剖分收敛 |

**正确性定理（Depth-Grounded Action Soundness）**
假设第 54 轮 (A22)–(A28) 成立，并新增：
**(A29)** `o_Z` 在真实验证集上标定误差 ≤ ε_o；
**(A30)** `α_S(·|z)` 在深度度量下 `L_α`-Lipschitz，故 `ε_ph ≤ L_α·E[e_z | R_crit]`；
**(A31)** 目标材质以概率 `≥ 1-δ_M` 落入 `M_cover`；
**(A32)** 探测认证精度 `1-ε_probe`，且在预算 `B_t` 内收敛。
则：
```
P(unsafe deploy) ≤ L_α·E[e_z | R_crit] + ε_probe·P(unobs ∩ probed)
                   + δ_M + ε_o
P(success)       ≥ 1 - ε_miss,max - P(B_t exhausted) - P(D_Z > D_max)
```
要点：
1. 不安全上界由 **幻影项** 主导，`ε_miss` 只进覆盖率，不进安全项；
2. `ε_probe` 项显式警告：**未认证的主动探测可能抬高不安全率**；
3. `δ_M` 项要求材质库覆盖，库外必须拒识，不能用 Gazebo 外推。

## 4. 合成机制检验（非基准证据）

`exp/depth_ground_sim.py`（seed 20261112，4000 episodes，300 场景点，12% 关键点）。声明式生成模型：材质 dropout（matte 2%/glass 55%/mirror 50%/black 35%）、缺失深度以 60% 概率被乐观 inpaint 为“可通行”、观测误分类 1%。

| 策略 | 不安全部署率 | 覆盖率 | 成功率 | 探测成本 |
|---|---|---|---|---|
| baseline（第 54 轮 J，信任 Gazebo 理想深度） | 0.805 | 0.909 | 0.058 | 0 |
| depth-ground，无探测 | 0.091 | 0.788 | 0.023 | 0 |
| + 朴素探测（95%） | 0.201 | 0.982 | 0.701 | 7.4 |
| + 认证探测（99%，预算 30） | 0.122 | 0.990 | 0.826 | 7.4 |

**结论**：
- 第 54 轮 J 在玻璃/镜面上不安全率 80.5%，说明“可观测”假设是致命漏洞；
- 只做拒绝（无探测）安全但覆盖不足，成功率仅 2.3%；
- 朴素探测把覆盖率拉回 98.2%，却因 5% 探测误差把不安全率抬到 20.1%——**探测必须认证**；
- 认证探测（99%）把成功率从 5.8% 提到 82.6%，不安全率仍由观测误差主导（12.2%），符合定理中 `L_α·E[e_z]` 项。

## 6. 本轮最大风险

**一句话**：深度接地把动作空间从“已观测”降级为“从深度推断”，其 soundness **三重依赖关键区域的保守过近似、Gazebo 深度间隙场覆盖实际材质、以及深度→动作误差的最坏界**；最大风险是 Gazebo 把玻璃/镜面/黑色渲染成实体，制造**库外幻影可操作性**，导致证书在真实场景静默失效并发生不安全部署，故必须以 **库外拒识 + 真实深度对抗验证 + 认证式主动探测** 三重护栏，宁可不部署，也绝不把 Gazebo 的“理想深度”当作可观测性证据。
