# 第 43 轮（新循环第 3 轮） · 轮足机器人 × 状态估计：把「接触/滑移/地形模态」升格为证书一等变量 —— 信念条件证书 BCC 与证书感知模态调度 CALMS（四层架构 v8）

> 承接第 42 轮 v19（SCV × CKB × ECR 飞轮）。前 42 轮的所有证书都隐含一个从未被点破的假设：**当前运动模态是已知且稳定的**。CAR 的每条转移边、LCS 的每一档、SCV 的域随机化，都建立在一套固定的动力学/约束模型上。轮足机器人（wheel-legged）恰好把这一假设击穿——它天生是**混合动力系统**：轮行、足行、轮足协同，接触集、滑移、地形在秒级频繁切换。而状态估计（尤其接触/滑移估计）正是判断「我现在处于哪个模态」的唯一手段。本轮核心命题：**模态不是背景条件，而是证书的显式索引；状态估计不是前端脏活，而是证书是否 sound 的守门人**。据此把 v19 的飞轮升级为「估计—证书—调度」互锁的 v8。

## 0. 直觉与动机

**灵感 1（轮足 = 会走路的混合自动机，模态是证书的索引）**：轮足的价值直觉是「平地省能、烂地越障」——轮行滚阻低、效率高，足行落脚离散、越障强。但对证书而言更重要的性质是：**每个模态都有各自干净的约束结构**。轮行近似满足非完整滚动约束（打滑是扰动项），足行是接触约束 + 冲击，轮足协同是过约束。于是可以给每个模态 r 定义各自的动力学 f_r、安全集 S_r、边际 m_r。直觉上，轮足机器人不是一个「系统」，而是一族由调度器切换的「证书化子系统」；模态 r 就是证书表的索引键。第 42 轮的 L0 查表只需在键高维上加一位 regime id，就能把「一套保守证书」拆成「多套贴合证书」——这恰好正面缓解 v19 自陈的可用性崩塌：在可辨识的干净模态里用紧证书，把保守性只留给模糊模态。

**灵感 2（状态估计 = 证书的守门人，而非前端的脏活）**：轮足状态估计的难点集中在**接触与滑移**：哪个轮/足着地？接触力多大？轮子打滑多少？脚下是硬地/碎石/沙/冰？这些量大多**不可直接观测**，只能从 IMU、轮编码器、关节编码器、力/触觉、LiDAR/视觉残差反推。传统估计器输出均值 + 协方差，供控制器用；但证书需要的是**最坏情况下的下界**。直觉上要做两件事：(a) 估计器额外输出离散**模态信念** b(r) 与**可辨识性标志**（此刻分得清吗？）；(b) 证书不再对点估计 x̂ 求边际，而是对**模糊集**求最坏模态边际 m_b = min_{r∈A} [m_r − L_m·δ_r]。一句话：**证书必须与估计器的不确定性同生共死**——当估计器说「分不清硬地还是冰面」时，证书要自动退到冰面那一档。

**灵感 3（证书感知模态调度：把「省能」和「可证」放进同一目标）**：性能型模态调度只看能耗/速度/越障；安全型调度只会一直保守慢行。轮足的独特机会是：**不同模态的可证性不同**。足行在复杂地形更可证（离散落脚、接触明确），轮行在平地更可证（滚动约束强、模型贴合）但在低摩擦坡道滑移不可辨。于是调度器应解一个「证书约束下的效率最优」问题：max 效率 s.t. 目标模态的信念条件边际 ≥ θ，且模态切换本身不破坏证书。这自然导出「证书限制的性能包络」：估计越不确定，可用模态越保守、速度上限越低；估计恢复，性能包络自动张开。这把第 42 轮的「可用性」从被动恢复变成主动经营。

**耦合升级**：状态估计向证书提供模态信念与可辨识性（BCC）；证书向调度器提供边际预算（CALMS）；调度器向估计器提供「注意先验」（切换前预告需重点辨识的接触/滑移）；估计器再把切换反例回灌 SCV/CKB（v19 飞轮）。形成 **Estimate→Certify→Schedule→Estimate** 的模态级内环，套在 v19 的 Sim→RAG→Edge→Sim 外环之上。

## 1. 形式化定义（增量：定义 38–43）

**定义 38（轮足混合模态空间与模态条件动力学）**：模态 r = (r_loco, r_contact, r_slip, r_terrain) ∈ R = R_loco × R_contact × R_slip × R_terrain，其中 R_loco = {轮行, 足行, 轮足协同}，R_contact ⊆ 2^{轮∪足} 为接触集，R_slip 为滑移等级（无/微/显著/失稳），R_terrain 为地形类（硬地/碎石/沙/冰/台阶）。每个 r 配一套动力学 ẋ = f_r(x,u)+w_r、安全集 S_r、证书边际 m_r(x)。**关键**：安全约束 S = ∩_r S_r 通常过保守，故不对全域用单一 S_r，而在当前信念下按 r 选取。

**定义 39（模态信念、模糊集与可辨识性）**：给定观测历史 z_{0:t}，模态信念 b_t(r) = P(r | z_{0:t})（由切换卡尔曼/HMM 后验给出）。**模糊集** A_ε(t) = {r : b_t(r) ≥ ε}，ε 为尾部截断阈值。**可辨识性** ρ(ε;t) = P(r*_t ∈ A_ε(t))，可用 Top-1/Top-2 信念间隔与似然间隔的校准映射估计。ρ 是「估计器是否配得上被信任」的量化。

**定义 40（信念条件证书 BCC）**：m_b(x,b) = min_{r∈A_ε} [ m_r(x) − L_m(r)·δ_r(b) ]，其中 δ_r(b) 为模态 r 下的连续状态估计误差界（由该模态的滑移可观测性/协方差给出）。**Sound 条件**：真实 r* ∈ A_ε 且 δ_r 成立 ⟹ 实际边际 ≥ m_b。**单调保守性**：A ⊆ A' ⟹ m_b(A') ≤ m_b(A)（模糊集越大越保守）。**可辨识门**：若 ρ(ε;t) < ρ_min 或 A_ε 含无法在 T_resolve 内排除的不安全模态，则定义 m_b := −∞（无证书），强制降级/SafeStop。门是 fail-closed 的。

**定义 41（滑移可观测性与协方差膨胀）**：以接触雅可比 J_c 与滑移观测模型构建可观测性 Gramian O = Σ J_c^T Σ^{-1} J_c。若 dim(null(O)) > 0，则存在**不可观测滑移方向**（典型：轮行于无横向激励的冰面/低摩擦坡），该方向上的轮式里程计不可信。据此定义**协方差膨胀** δ_odo = σ_max·√(λ_min(O)^{-1})，并把它并入该模态的 δ_r；若 δ_odo > δ_max，该模态在 BCC 中自动视为「不可证」。

**定义 42（证书感知模态调度 CALMS）**：调度策略 π: (x̂, b, P) ↦ (r_cmd, v_cmd)。优化目标 max E[效率(r_cmd, 地形)] s.t. (i) m_b(x,b; r_cmd) ≥ θ_{r_cmd}；(ii) 切换安全：x ∈ Inv_trans(r_from→r_to) 且切换窗口 T_sw 内最坏边际 ≥ θ_sw；(iii) 速率/动力学可行。形式化为**约束 MDP**，工程上用「安全盾（shield）+ 滚动时域」实现：由性能策略提议，盾过滤一切违反 (i)(ii) 的提议并回退到安全模态。

**定义 43（估计触发的证书降级阶梯）**：LCS 的档位按模态信念重索引：T-1 = 模态索引 L0 查表（rg = argmax b 且 ρ 达标）；T0 = 接收 regime one-hot 的 INT8 监控器；若 ρ 不足则升到 T1 = 对 A_ε 做最坏模态证书（等价 BCC）；若 A_ε 含不安全模态且 T_resolve 内不可排除则 T2 = SafeStop/降速保持。**阶梯 soundness**：每一步只允许「扩大模糊集 / 降低边际」，禁止反向乐观跳档。

## 2. 四大产出设计（增量 IP-57/58/59 + 升级 IP-49/50/51/52/53/55/56）

### 2.1 IP-57 REGIME-ESTIMATOR（轮足模态状态估计器 RSE）
1. **多假设连续估计**：对每个候选模态 r 维护一套 TRI-FUSE 状态/协方差（复用 IP-56 L2 定点核），观测更新按 r 的接触/滑移模型分别计算残差。
2. **接触/滑移/地形证据三通道**：力-关节残差判接触集；轮速-IMU 残差判滑移；LiDAR/视觉语义与几何残差判地形类。三通道 log-likelihood 经切换转移矩阵融合成信念 b。
3. **可辨识性打分**：Top-1/Top-2 信念间隔 + 似然间隔 + 校准曲线（ECE）输出 ρ；同时维护「融合退化」标志（长时间无激励、全向均似然）。
4. **滑移可观测性检查**：增量式 Gramian，检测不可观测滑移方向，输出 δ_odo 与「轮式里程计不可信」布尔位。
5. **切换注意先验**：在调度器预告的切换窗口 T_sw 内，临时提高接触/滑移证据权重（主动辨识），并把证据不足上报为反例候选。

### 2.2 IP-58 BCC（信念条件证书引擎）
1. **模糊集构造**：A_ε = {r : b(r) ≥ ε}，并对 ε 做保守校正（按 ρ 的校准误差上浮）。
2. **最坏模态边际**：对 A_ε 逐模态取 m_r 再减 L_m·δ_r，取 min；δ_r 含连续估计误差与滑移协方差膨胀。
3. **可辨识门（fail-closed）**：ρ < ρ_min 或含未排除不安全模态 → 返回无证书，触发 IP-52 阶梯降级。
4. **证书输出附加字段**：m_b、A_ε、argmin 模态、δ_r 分解、门状态、恢复所需的证据类型（供调度器/课程主动采集）。
5. **与 CKB 联动**：把 (φ, ψ, r, A_ε, 反例) 作为检索键，相同地形/切换模式直接复用最坏模态证书模板。

### 2.3 IP-59 CALMS（证书感知模态调度器）
1. **性能提议器**：以能耗/时间/越障为效用，滚动时域提议 (r_cmd, v_cmd)。
2. **证书盾**：一步过滤，剔除 m_b < θ 或切换不安全的提议；无可行提议时按「最安全可达模态」回退（通常降速→足行→停）。
3. **性能包络管理**：以 m_b − θ 作为「证书余量」，余量小则收紧速度/模态，余量大则放开；形成显式的（速度, 模态, 可证性）Pareto 面。
4. **切换守卫**：切换不变式 Inv_trans、最小保持时间、切换期间禁用高增益动作；切换反例自动入库。

## 3. 四层架构 v8

```
L1: 轮足多传感器(IMU/轮编/关节/力触/LiDAR/视觉) → IP-57 RSE
    输出: b_t(模态信念) + {x̂_r, P_r} + ρ(可辨识性) + δ_odo(滑移膨胀)
    连续核: IP-56 L2 定点 TRI-FUSE (按 r 多假设)
L2: 地形/语义分类 → ψ 指纹(含地形/滑移先验) + IP-35 仲裁残差 → CKB 检索键 (φ, ψ, r)
L3: IP-58 BCC(最坏模态边际 m_b + 可辨识门) → IP-51 CAR(RegimeGate + m_b 守卫)
    → IP-59 CALMS(证书盾 + 性能包络) → IP-39 规划(regime-robust CBF margin=m_b)
    → IP-47 乘积模板(含模态) → IP-45 总线(模态/信念/门状态心跳)
    → IP-48 流匹配 + IP-43 韵律 → IP-53 CMC(regime-aware 监控器)
L4: IP-55 CKB(按 regime 分片) ← IP-54 SCV(轮足域随机化: 滑移/台阶/沙/冰 + 切换注入)
    → IP-52 估计触发降级阶梯 → RCA 重颁证书(含 A_ε 与门状态) → 契约热更新
运行期: b/ρ 每拍更新 → BCC 求 m_b → CALMS 选模态/限速 → 切换反例回灌 SCV → CKB 更新
```

## 5. 本轮最大风险

**一句话**：轮足把「证书最需要生效的时刻」（模态切换、滑移起始、冲击落地）与「状态估计最不可靠的时刻」重合，形成**估计—证书恶性循环**——可辨识门放太松则在误判模态上给出「自信但错误」的证书而静默失效，放太紧则频繁 fail-closed 令轮足退化为爬行/停机、可用性崩塌；因此 E87（ρ 校准）与 E88（BCC 零违例）必须作为红线实验，且门必须是可证明的 fail-closed（任何不确定一律降级），而非调参乐观。

| 符号 | 含义 | 定义 |
|---|---|---|
| r = (r_loco, r_contact, r_slip, r_terrain) ∈ R | 轮足模态 | 运动方式 × 接触集 × 滑移级 × 地形类 |
| f_r, S_r, m_r | 模态条件动力学/安全集/边际 | 每个 r 各自的模型与证书切片 |
| b_t(r) = P(r | z_{0:t}) | 模态信念 | 切换卡尔曼/HMM 后验 |
| A_ε(t) = {r : b_t(r) ≥ ε} | 模态模糊集 | 尾部截断的候选模态集合 |
| ρ(ε;t) | 模态可辨识性 | P(r*_t ∈ A_ε(t))，由 Top-1/2 间隔校准 |
| m_b = min_{r∈A_ε}[m_r − L_m(r)·δ_r] | 信念条件边际 | 最坏模态下的保守下界 |
| δ_r(b) | 模态误差界 | 连续估计误差 + 滑移协方差膨胀 δ_odo |
| O = Σ J_c^T Σ^{-1} J_c | 滑移可观测性 Gramian | null(O) 非空 ⟹ 存在不可观测滑移方向 |
| δ_odo = σ_max·√(λ_min(O)^{-1}) | 滑移协方差膨胀 | 并入 δ_r；超 δ_max 则该模态不可证 |
| π: (x̂,b,P) ↦ (r_cmd, v_cmd) | 证书感知调度 | 约束 MDP，证书盾一步过滤 |
| m_b := −∞ if ρ<ρ_min | fail-closed 可辨识门 | 无证书，强制阶梯降级 |

## 2. 关键算法（伪代码）

### IP-57 RSE：模态信念 + 可辨识性 + 滑移可观测性
```
def regime_estimate(sensors, prev_belief):
    R_cand = support(prev_belief) | neighbor_modes(prev_top)
    x_hat, P = {}, {}
    loglik = {}
    for r in R_cand:
        # 每个模态各自跑一套定点 TRI-FUSE（复用 IP-56 L2）
        x_hat[r], P[r] = trifuse_predict_update(sensors, model[r])
        contact_ev = contact_residual(sensors.force, sensors.joint, x_hat[r])
        slip_ev    = wheel_slip_residual(sensors.enc, sensors.imu, x_hat[r])
        terr_ev    = terrain_likelihood(sensors.lidar, sensors.vision, r)
        loglik[r]  = contact_ev + slip_ev + terr_ev
    # 切换有惯性：HMM 前向
    belief = normalize(prev_belief @ trans_matrix * exp(loglik))
    # 可辨识性：Top-1/Top-2 信念间隔 + 似然间隔（校准映射到概率）
    r1, r2 = top2(belief)
    rho = calibrate_identifiability(belief[r1] - belief[r2],
                                    loglik[r1] - loglik[r2])
    # 滑移可观测性
    O = observability_gramian(contact_jacobian(sensors), slip_model(sensors))
    slip_unobs = (nullspace_dim(O) > 0)
    delta_odo  = sigma_max * sqrt(1.0 / max(1e-9, lambda_min(O))) if slip_unobs else 0.0
    return Beta(belief, x_hat, P, rho, delta_odo, slip_unobs)
```

### IP-58 BCC：模糊集最坏模态边际 + 可辨识门
```
def belief_conditioned_margin(x_hat, beta, cert_table,
                              eps=0.05, rho_min=0.90, delta_max=0.15):
    A = {r for r in R if beta.belief[r] >= eps}
    # fail-closed 门：可辨识性不足 / 含未排除的不安全模态
    if beta.rho < rho_min or contains_unresolved_unsafe(A, cert_table):
        return Cert(-inf, A, beta.rho, gate='CLOSED')
    m_best, arg = +inf, None
    detail = {}
    for r in A:
        delta_r = max(beta.delta_odo, cert_table[r].est_error_bound(beta.belief, r))
        if delta_r > delta_max:
            return Cert(-inf, A, beta.rho, gate='REGIME_UNPROVABLE')
        m_r = cert_table[r].lookup(x_hat[r]).m_lo      # L0 regime-indexed
        m_r_safe = m_r - cert_table[r].L_m * delta_r
        detail[r] = (m_r, delta_r, m_r_safe)
        if m_r_safe < m_best:
            m_best, arg = m_r_safe, r
    return Cert(m_best, A, beta.rho, argmin=arg, detail=detail, gate='OPEN')

# 调度器预取：给定候选目标模态，求该模态是否可证
def margin_if_mode(x_hat, beta, cert_table, r_cmd):
    return belief_conditioned_margin(x_hat, beta,
                                     cert_table_with_mode(cert_table, r_cmd))
```

### IP-59 CALMS：证书盾 + 性能包络 + 切换守卫
```
def calms_select(x_hat, beta, goal, cert_table, current_r):
    best = None
    for r_cmd in feasible_modes(x_hat, goal):
        cert = margin_if_mode(x_hat, beta, cert_table, r_cmd)
        if cert.gate != 'OPEN' or cert.m_b < theta[r_cmd]:
            continue
        if not transition_safe(current_r, r_cmd, x_hat, beta):
            continue
        eff = expected_efficiency(r_cmd, terrain_belief(beta), goal)
        slack = cert.m_b - theta[r_cmd]           # 证书余量
        score = eff - lam * max(0.0, tau_slack - slack)   # 余量不足罚分
        if best is None or score > best.score:
            best = Proposal(r_cmd, eff, cert.m_b, score)
    if best is None:
        return safe_fallback(x_hat, beta)         # 降速 → 足行 → 停
    return best

def transition_safe(r_from, r_to, x, beta):
    # 切换不变式 + 切换窗口 T_sw 内最坏模态仍可证
    if x not in Inv_trans[(r_from, r_to)]:
        return False
    A_sw = ambiguity_during_switch(beta, r_from, r_to)   # 保守扩集
    return worst_case_margin_over(A_sw) >= theta_sw[(r_from, r_to)]

def safe_fallback(x_hat, beta):
    # 按可证性从高到低：降速轮行 / 足行 / 原地保持 / SafeStop
    for r in fallback_order:
        if margin_if_mode(x_hat, beta, cert_table, r).m_b >= theta_safe[r]:
            return Proposal(r, eff=0.0, m_b=theta_safe[r], fallback=True)
    return SafeStop()
```

def certify_lcs_v3(x, beta, guards, budget_us=300):

## 6. 本轮最大风险

**一句话**：轮足把「证书最需要生效的时刻」（模态切换、滑移起始、冲击落地）与「状态估计最不可靠的时刻」重合，形成**估计—证书恶性循环**——可辨识门放太松则在误判模态上给出「自信但错误」的证书而静默失效，放太紧则频繁 fail-closed 令轮足退化为爬行/停机、可用性崩塌；因此 E87（ρ 校准）与 E88（BCC 零违例）必须作为红线实验，且门必须是可证明的 fail-closed（任何不确定一律降级），而非调参乐观。
