# 第 10 轮（新灵感循环第 1 轮；本轮灵感：「开源生态」×「零样本泛化」）

> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**供应链可信 + 组合泛化**。两个灵感分别治理 v9 的两笔债：**封闭债**（14 个 IP、契约表、冻结前向模型与 β 全部本地手工维护，无出处、无依赖图、无复现、无版本语义）与**陌生域能力债**（v9 在陌生域只会 K_eff→1 + 中立元，安全但能力塌缩，且 Δ_dom 的 20 帧滑窗滞后于真实跳变）。所有新组件必须经 v9 的中立元退化链接入：任一失效 ⇒ 注入零样本中立元 z^⊥（固定 pin 的 v9 契约表 + K_eff=1），逐位退回 v9，而非行为漂移。

## 0. 直觉与动机

### 灵感 1（开源生态 → 契约供应链与安全物料清单）

直觉：开源生态真正值钱的不是"免费代码"，而是一套**出处与治理基础设施**——内容寻址、签名发布、SBOM（软件物料清单）、语义版本、一致性测试套件、fork/回滚、弃用与漏洞披露、可复现构建、"many eyes" 的对抗性测试。v9 的 14 个 IP 恰好缺这一整套：κ_m 是本地配置文件，F̂ 是冻结黑盒，β 是本地标定，模块之间没有依赖声明，也没有"这个结论是在什么 ODD、什么数据、什么构建、什么随机种子下得到的"证据链。一个人维护的契约表，无法回答"这条安全结论三年后还成立吗"。

核心创新：**开放契约注册表（OpenContractRegistry, OCR）+ 安全物料清单（SafetyBillOfMaterials, SBoM）+ 语义精化检查器（SemanticRefinementChecker, SRC）**。把每个模块/权重/标定数据升级为**签名契约制品** α=⟨κ, h, ρ, dep, ev, lic, lim⟩（内容哈希、出处、依赖闭包、证据包、许可、已知限制）；运行期 SBoM guard 校验 pin 住的哈希与签名，禁止未声明的动态加载；跨版本组合必须显式证明语义精化 `P ⊑_φ P'`，否则 δ_sem=∞、禁止组合。v9 的契约表由此从"本地配置"变成"可审计供应链"：退化不再是"我记得它等价"，而是"这条 pin 的制品集可以复现出等价行为"。

### 灵感 2（零样本泛化 → 等变证书、共形新颖性与组合证书代数）

直觉：v9 进入陌生域时只有一条路——降级。安全，但把一个本可解决的新任务也一起降没了；而它的信任域判据 Δ_dom 恰恰是一个 20 帧滑窗，最需要果断的时刻最迟钝。零样本泛化的启示是：如果新任务只是已知任务的**语义/对称变换**，且系统能从生态里检索到带证书的可复用原语，那么无需目标域数据也能保持能力。零样本的可信度不来自"模型很大"，而来自三件事：**对称性带来的精确迁移**、**组合结构的可推导性**、**对"陌生"的分布无关判定**。

核心创新：**零样本组合器（ZeroShotComposer, ZSC）** 按类型化代数组合注册表原语；**等变证书检查器（EquivarianceCertificateChecker, ECC）** 在声明的对称群 G（SE(2) 平移/旋转、物体重命名、尺度）下证明行为迁移；**新颖性共形门（NoveltyConformalGate, NCG）** 用共形 p 值 + CUSUM 变点检测给出与分布无关的"陌生度"判定；**组合证书代数（CompositionCertificateAlgebra, CCA）** 为组合程序推导证书，推不出即 fail-closed；**见证账本（WitnessLedger, WL）** 把每次失败变成签名见证，驱动注册表**单调收紧**修订。

### 两个灵感的桥

零样本泛化的可信度，上限就是它所复用组件的**出处与语义兼容性**；开源生态正好提供这条审计链。反过来，零样本任务是对生态最自然的"模糊测试"工作负载：它在陌生域里不断暴露语义漂移与版本不兼容。于是本轮不是一个模块堆叠，而是一个闭环：**注册表 → 零样本组合 → 证书化执行 → 见证 → 单调修订**。这个闭环的"货币"是证据，不是参数。

## 1. 研究问题（轮次升级版）

- **Q1（组合证书可靠性）**：在叶子证据、语义精化与 Lipschitz 组合假设下，组合证书何时可靠？组合新颖性风险能否被 `ρ(P) ≤ Σρ_i + L·Σδ_sem + ρ_mon` 界住，从而把"零样本组合"从启发式拼接变成可审计推导？
- **Q2（零样本迁移边界）**：什么对称群 G 与等变容差 ε 使"无目标域数据"的迁移是可靠的？共形新颖性 + CUSUM 能否**严格收紧** v9 信任域，并消除 20 帧滑窗的检测滞后？
- **Q3（生态治理与单调安全）**：见证驱动的注册表修订如何做到"只收紧不放松"（安全不回退、活性可下降）？如何抵御供应链投毒与未声明的语义漂移，使"证书为真"不会退化成"系统为假"？

## 2. 设计原则（在 P7–P12 基础上新增 P13–P15）

**P13 供应链可审计律（Auditable Supply Chain, OCR/SBoM）**
每个参与执行的组件（模块、权重、标定数据、前向模型、原语库）必须对应一个签名契约制品 α，含内容哈希 h、出处 ρ、依赖闭包 dep、证据包 ev、许可 lic、限制 lim。运行期只允许执行 `SBOM_ok` 的闭包；哈希/签名/依赖任一不符即注入 z^⊥。可复现性定义为：同 h + 同种子 ⇒ 逐位一致的行为。

**P14 组合证书律（Compose-or-Fallback, ZSC/CCA）**
零样本执行仅当存在组合证书推导 `⊢_E P : ⟨Pre, Post, ρ, E⟩` 时允许；E 中每个叶子必须引用注册表制品哈希（"无免费证据"）。生产模式禁止任何形式的放宽：不得弱化 Pre、不得强化 Post、不得在线学习。推不出证书即 fail-closed 到 z^⊥。

**P15 新颖性只收紧律（Novelty Shrinks Trust, NCG）**
零样本信任集定义为 `U_t^zs = U_t^{v9} ∧ (p(o_t) ≥ α_nov) ∧ (C_t ≤ h_cusum) ∧ SBOM_ok`。新门只能**交集** v9 的信任域，永不放大；共形与变点两个独立判据必须同时通过。零样本要么 COMPOSE、要么 FALLBACK，没有"边试边学"的中间态。

## 3. 与基线的接口（如何退化）

- OCR / SBoM / SRC 失效 ⇒ 零样本禁用，加载最后已知良好（LKG）pin 的 v9 契约表，等价 v9；
- ZSC / CCA 失效 ⇒ 无组合，注入 z^⊥，K_eff=1，等价 v9 决策粒度；
- ECC 失效 ⇒ 对称群视为空集 G=∅，无迁移，等价 v9；
- NCG 失效 ⇒ 新颖性 p≡0、C_t 视为越界，保守回退 v9；
- WL 失效 ⇒ 注册表转只读 pin，不再接受新制品，等价 v9 冻结配置；
- 全部失效 ⇒ 完整退回 MetricVoiceGauge-ACMD v9，再退回 v8、v7、v6。

## 4. 预期贡献

1. **开放契约供应链**：OCR + SBoM + SRC，把 v9 契约表升级为可签名、可复现、可回滚、可审计的制品 DAG，首次让"退化等价"具备出处证据；
2. **组合证书代数**：零样本组合的可靠性从"接口匹配"升级为"证据可推导 + 语义可精化"，并给出组合新颖性风险的三项界；
3. **三重零样本门**：等变（精确迁移）+ 共形（分布无关覆盖）+ CUSUM（快速变点）；三者只收紧 v9 信任域，直接治理 v9 的 20 帧滞后风险；
4. **开放世界闭环实验 E571–E590**：组合证书故障注入、零样本任务套件、投毒/语义漂移、单调修订、跨本体迁移与端到端竞赛。

## 5. 本轮最大风险

**一句话**：零样本组合的可信度建立在"注册表声明的语义 = 真实世界语义"之上，而组合证书只能证明"在声明的 φ 下自洽"——一旦上游组件发生未声明的语义漂移或被投毒，系统会带着一张在注册表语义下有效、在真实世界语义下失效的证书执行，即「证书为真、系统为假」的供应链级失效。

**新增定义 540（契约制品 ContractArtifact）** 一个可独立签名、可复现的执行单元：
```
α = ⟨κ, h, ρ, dep, ev, lic, lim⟩,
h = H(κ ∥ binary ∥ config ∥ ev_manifest),
dep ⊆ ArtifactID（带 pin 哈希）, ev = {conformance, calib_sheet, seeds, failures},
```
其中 κ 为 v9 定义 535 的契约；ρ 记录源码仓库、commit、构建配方哈希、签名者；ev 是**证据包**（一致性测试、标定数据表、随机种子、已知失败）。部署要求 `h` 与 `sig_K(h)` 均可验证，且 `lim` 显式列出不适用的 ODD。

**新增定义 541（开放契约注册表 OpenContractRegistry）** 追加式 Merkle-DAG `R=(A,≺)`，`≺` 为依赖与版本偏序。检索 `Retrieve(ℓ,o) → {α_i}` 可按任务类型、接地 affordance、ODD、许可兼容性与证据充分性过滤。一个制品**可部署**当且仅当：
```
Deployable(α) ⇔ SBOM_ok(TC(α.dep)) ∧ sig_ok(α) ∧ EvSuff(α.ev, ODD_task) ≥ 1
                ∧ SRC.refines(α.κ, LKG.κ[name]).
```
安全序 `α ⪯_S α'` 定义为 `Pre' ⇒ Pre ∧ Post' ⇒ Post`（后者更紧）。注册表允许任意实验分支，但生产 pin 只接受 `⪯_S` 意义下不弱化的制品。

**新增定义 542（安全物料清单 SafetyBillOfMaterials）** 程序 P 的执行闭包
```
B(P) = (V, dep, h),  V = 模块 ∪ 权重 ∪ 标定数据 ∪ 前向模型 ∪ 原语库,
```
`SBOM_ok(B)` 校验：(i) 每个 `v∈V` 的哈希与 pin 一致；(ii) 签名链回溯到信任根；(iii) **无未声明动态加载**（插件/`dlopen`/远程权重必须先登记）；(iv) 许可兼容。运行期 `sbom_guard` 在模型换载与每 `T_sbom=5s` 重算（增量 Merkle 校验，O(log|V|)）。

**新增定义 543（零样本任务与接地的可证性）** 零样本任务 `Z=(ℓ,o)`：新指令 ℓ（可含未见过的概念组合）与新域观测 o；**无目标域梯度更新、无目标域示范**。接地映射 `γ: ℓ×o → (T,A,O)` 输出类型化任务、可操作集与物体集，并必须**携带接地见证**（用了哪个检测器/分割/affordance 及其置信），否则视为接地失败。这防止"零样本"退化为不可审计的语义漂移。

**新增定义 544（语义精化 SemanticRefinement）** 给定观察映射 φ（如"末端执行器位姿 + 物体质心 + 抓取状态"），
```
P ⊑_φ P'  ⇔  ∀s∈ODD: d_φ(φ(P(s)), φ(P'(s))) ≤ ε_sem
```
以一致性测试套件作统计判定（置信下界）。跨版本/跨实现组合**必须**携带 `⊑_φ` 证明；否则 `δ_sem(α_i,α_j)=∞`，组合被禁止。φ 是显式声明的契约字段，不是隐含假设。

**新增定义 545（组合证书代数 CompositionCertificateAlgebra, CCA）** 判断
```
⊢_E P : ⟨Pre, Post, ρ, E⟩
```
的推导规则：
```
Leaf:   α with ev, cid=h(α)  ⇒  ⊢_{ {cid} } α : ⟨α.κ.Pre, α.κ.Post, α.κ.ρ, {cid}⟩
Seq:    ⊢_{E1} P1:⟨Pre,Mid,ρ1,E1⟩, ⊢_{E2} P2:⟨Mid,Post,ρ2,E2⟩,
        φ1 = φ2 或 SRC.refines(φ1,φ2)
        ⇒ ⊢_{E1∪E2} P1;P2 : ⟨Pre, Post, ρ1+ρ2+ρ_iface, E1∪E2⟩
Par:    non_interfering(P1,P2) ⇒ ⊢_{E1∪E2} P1‖P2 : ⟨Pre1∧Pre2, Post1∧Post2, max(ρ1,ρ2), E1∪E2⟩
React:  存在监控不变式 I, 监控失效风险 ρ_mon
        ⇒ ⊢_{E} while(I){P1} : ⟨Pre, Post, ρ1+ρ_mon, E⟩
```
生产模式**只允许收紧**：不得弱化 Pre、不得强化 Post、不得删除 E 中任何叶子证据。推不出即 `NoCertificate`，fail-closed 到 `z^⊥`。E 的每个元素必须是注册表可验证的 `cid`——**无免费证据**。

**新增定义 546（等变证书 EquivarianceCertificate）** 程序 P 关于群 G 与容差 ε 等变，若
```
∀g∈G, ∀s∈ODD:  dist(P(g·s), g·P(s)) ≤ ε.
```
G 的元素为任务语义保持的变换：SE(2) 平移/旋转、物体重命名（relabeling）、尺度、左右手镜像（若任务语义允许）。等变证书由原语的等变性与其组合闭包推导；若某变换改变任务语义（如"把杯子放到左边"），该变换**不属于** G，零样本不得据此迁移。

**新增定义 547（新颖性共形门 NoveltyConformalGate）** 校准集来自注册表证据包（按任务族分层），得分 `s(o)`。共形 p 值
```
p(o) = (1 + #{i: s_i ≥ s(o)}) / (n + 1),
```
分布无关：在校准与测试可交换时 `Pr[p(o) < α_nov] ≤ α_nov`。并行 CUSUM：
```
C_t = max(0, C_{t-1} + s(o_t) − μ₀ − k),   alarm ⇔ C_t > h_cusum.
```
联合接受 `accept ⇔ p(o) ≥ α_nov ∧ C_t ≤ h_cusum`。`s` 取多模态嵌入的马氏距离/能量分数，`μ₀,k` 由证据包校准。关键：`accept` **只与** v9 的 `U_t` 取交集。

**新增定义 548（零样本执行模式 ZeroShotMode）** 生产模式只有两个值：
```
mode = COMPOSE   若 CCA 推得出 ∧ ECC(ε≤ε₀) ∧ NCG.accept ∧ SBOM_ok,
     = FALLBACK  否则（= z^⊥ = v9，K_eff=1）。
```
**没有**在线适配/边试边学模式；少样本适应只能作为新的、签名的注册表制品离线完成，再经 SRC 精化后进入生产。

**新增定义 549（见证账本 WitnessLedger）** 任一失败或近失写入
```
w = ⟨h(P), s_t, ℓ, o, expected Post, observed Post, trace, seed, cert_id⟩, sig_K(w).
```
修订规则 `Δ` 只允许：(i) 收紧 Pre 或增大 ρ；(ii) 增加一致性测试/见证；(iii) 提高 β 或 α_nov；(iv) 缩小声明的 ODD。**禁止**放宽 Post、删除证据、扩大 ODD。见证可被任意第三方复现（含种子与构建哈希）。

**新增定义 550（证据充分性 EvidenceSufficiency）** 对 ODD 的显式覆盖 `Cover(ODD)={c_j}`：
```
EvSuff(ev, ODD) = min_j ( n_j / n_min ) · 1[ β 分位覆盖 ≥ 1−α_ev ] · 1[ 种子可复现 ],
```
`<1` ⇒ 制品不可部署。这把"我觉得标定够了"变成可审计门槛。

**新增定义 551（组合新颖性风险界 CompositionalNoveltyRisk）** 对组合程序 P：
```
ρ(P) ≤ Σ_i ρ_i + L · Σ_i δ_sem,i + ρ_mon,
```
其中 L 为原语对状态的 Lipschitz 常数，δ_sem,i 为第 i 个叶子相对部署语义的未声明漂移。任一项不可界 ⇒ 无证书、回退。该式是"零样本能力"与"安全"的兑换率：要更多组合能力，就必须压低 δ_sem（更强 SRC）或 ρ_i（更强证据）。

**新增定义 552（零样本中立元 ZeroShotNeutralElement）** `z^⊥ :=` 加载 LKG pin 的 v9 契约表、关闭零样本代码路径、`K_eff=1`、ID 全唤醒。其代数性质是**吸收元**而非恒等元：
```
P ; z^⊥ = z^⊥,    z^⊥ ; P = z^⊥
```
（回退后不得继续执行旧组合，直到重新取证）。这继承并推广了 v9 定义 536 中 AC 端口 `a^⊥` 的吸收元思想。

class EquivarianceCertificateChecker:
    def certify(self, P, G, probes, eps=EPS0):

# ---------- IP-362：新颖性共形门 ----------
class NoveltyConformalGate:
    def __init__(self, scores, alpha=0.05, k=0.5, h=5.0, mu0=0.0):
        self.sorted = sorted(scores); self.alpha=alpha
        self.k, self.h, self.mu0, self.C = k, h, mu0, 0.0
    def p_value(self, o):
        s = self.score(o); n = len(self.sorted)
        return (1 + sum(x >= s for x in self.sorted)) / (n + 1)
    def step(self, o):
        s = self.score(o)
        self.C = max(0.0, self.C + s - self.mu0 - self.k)
        p = self.p_value(o)
        return (p >= self.alpha and self.C <= self.h), p, self.C

## 3. 推导

**引理 87（组合证书可靠性）** 设每个叶子 α_i 在其 ODD 内满足 `Pr[¬Post_i | Pre_i] ≤ ρ_i`，相对部署语义的漂移为 δ_i；组合接口误差 ≤ ρ_iface；监控失效风险 ≤ ρ_mon；每个原语对状态 L-Lipschitz。若 `⊢_E P:⟨Pre,Post,ρ,E⟩` 由定义 545 推导，则部署 P 在 Pre 下违背 Post 的概率 ≤ `Σ_i ρ_i + ρ_mon + L·Σ_i δ_i`，即定义 551。证明：对推导树归纳。Leaf 由假设；Seq 用 `Post_1 ⇒ Pre_2` 拼接，风险相加，语义漂移经 Lipschitz 放大；Par 由非干涉性使风险取 max；React 用监控不变式 I 归纳保持，并计入 ρ_mon；收紧规则保证 Pre 只变强、Post 只变弱信任，故结论单调。∎

**引理 88（等变零样本迁移的保守性）** 设新任务 `Z'=g·Z` 且 `g∈G` 是任务语义保持的变换；P 为 (G,ε)-等变；P 在 Z 上的证书余量为 `m_Z>0`；群作用实现误差为 δ_g。则 P 在 Z' 上的余量下界为 `m_{Z'} ≥ m_Z − L_P·(ε+δ_g)`；若右端 >0，则证书无需目标域数据即可迁移。证明：若 P 在 gZ 上违背 Post，因 g 保任务语义，把违反轨迹用 g⁻¹ 拉回 Z，等变性与 Lipschitz 给出 Z 上一个余量被压缩不超过 L(ε+δ_g) 的违反，与 m_Z 矛盾。∎（边界：g 必须真的保语义；"杯子放左"经镜像后语义改变，不在 G 内。）

**引理 89（新颖性门只收紧且消除 20 帧滞后）** (i) 由定义 547/548，`U_t^zs = U_t^{v9} ∧ accept ⊆ U_t^{v9}`，零样本永不放大可执行域；(ii) 在校准/测试可交换下，共形覆盖 `Pr[p(o)<α_nov] ≤ α_nov`；(iii) 对均值漂移 δ>k 的 CUSUM，期望检测延迟 `E[τ] ≤ h/(δ−k)`，零漂移下误报平均运行长度随 h 指数增长；(iv) 当真实跳变幅度大时，CUSUM 在 1–3 帧内报警，而 v9 的 20 帧 Δ_dom 滑窗至少滞后约 20 帧，故存在严格更早拒绝的区间。价格是误回退：`Pr[FALLBACK | 同分布] ≤ α_nov + ARL₀⁻¹`。∎

**引理 90（供应链失效 ⇒ v9 逐位等价）** 哈希不符、签名无效、依赖缺失、SRC 精化失败、ECC 失败、NCG 拒识、CCA 推不出、WL 失效，任一发生即注入定义 552 的 `z^⊥`：只加载 LKG pin 的 v9 契约表，K_eff=1，零样本代码路径不执行。因新代码路径完全不参与取值，且 MW 只追加了只读观测器，故对外可观测行为与 v9 在相同输入/种子下逐位一致。∎

**引理 91（生态修订单调安全）** 定义可采纳集 `Adm(R)={P : ∃E, ⊢_E P 可由 R 推导}`。若每次修订满足定义 549 的只收紧规则，则约束集单调增强，`Adm(R_{t+1}) ⊆ Adm(R_t)`。故对 R_t 证明的任何安全性质在 R_{t+1} 仍成立；代价是活性/完成任务集合单调不增（可能丢任务），这是显式的安全-活性兑换。∎

**引理 92（无语义精化的组合不可靠）** 若 `δ_sem(α_i,α_j)>0` 且未携带 `⊑_φ` 证明，则存在输入 s 使 `φ(P(s)) ≠ φ(P'(s))`（δ_sem 的定义即存在语义区分见证）。由于 Post 定义在 φ 可观测量上，可构造 s 使 Post 在一个语义下成立、另一个下不成立，故组合证书不可靠。因此 SRC 是安全关键组件，必须 `φ^elig=false`，永不可被 ID 蒸馏休眠。∎

**引理 93（预算与 50Hz 守恒）** ZSC 检索/组合在独立线程以 2–5Hz 运行，beam 宽 b≤8、深 d≤6、候选数上限 `b^d` 由证书剪枝与 `budget_ms` 截断；主路径只做 O(1) 快照读取 + O(1) NCG + v9 原有守卫，故 50Hz 周期总执行不增。若组合超预算即返回 None ⇒ `z^⊥`，不产生部分执行。∎

| 许可审计（E586） | 100%/0 冲突 | 注册表准入加许可检查 |

## 7. 本轮最大风险

**一句话**：零样本组合的可信度建立在"注册表声明的语义 = 真实世界语义"之上，而组合证书只能证明"在声明的 φ 下自洽"——一旦上游组件发生未声明的语义漂移或被投毒，系统会带着一张在注册表语义下有效、在真实世界语义下失效的证书执行，即「证书为真、系统为假」的供应链级失效。
