# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「力觉传感」×「关节驱动」）

> R69 问出了「我该向谁求证、还能问什么」，但它的所有问法都发生在**非接触世界**：看一眼、问一句。它的信息动作里虽然写了 `g_probe`（定义 294），却只是一个没有接触动力学、也不会改变世界状态的占位向量——「触」被降级成了「另一种看」。真实具身系统的不确定性大量发生在**接触的那一毫秒**：抓住了没有、会不会滑、这物体是软是硬、关节是不是卡住了、是不是有人在推我。这些问题**语言回答不了**（没人能靠一句话告诉你"这个杯子在 0.3 N 侧向力下会不会滑"），只能靠**用力去试**；而"试"会改变世界——可能捏碎、可能推倒、可能把物体从手里挤掉。于是接触信息既是最硬的信息，也是**不可逆的信息**。
>
> 更关键的是，R69 自陈的最大风险是「模态分布不可信 → 问错比不问更危险」，其根源在于它的两条证据通道（视觉、语言）**伪造成本几乎为零**：标定层能吸收视觉残差，人会撒谎。本轮两个灵感补上两条新通道：
> - **力觉传感**给出一个"撒谎必须做功"的物理通道；但它有自己的骗术——接触遮挡、量程饱和、柔顺掩蔽、自接触混叠；
> - **关节驱动**给出两样东西：一是探询力**只能由关节产生**（探询是一个承诺，不是一次接收），二是**关节本身就是独立见证者**——efference copy（运动命令的感觉副本）与本体感受构成一条不经过视觉标定层的残差通道。
>
> 核心命题：**把"接触"变成提问，把"关节"变成见证，把 efference copy 变成测谎仪；接触处的可约不确定性用"可恢复的主动触觉探询"消解，不可约部分用"风险自适应阻抗"兜底；只有物理锚定证据一致时才定案，物理不一致拥有高于语言/视觉的否决权。** 命名 **PACT-RAS**（Proprioceptive-Actuation Contact-grounded Trust）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我的手到底碰到了什么、它会不会滑、我能不能在弄坏它之前知道**」——"摸一下"既是提问，也是承诺。

## 0. 直觉与动机

**灵感 1（力觉传感 → 最硬的通道，也有最硬的骗术）**
直觉：视觉可以靠标定"解释掉"一个偏移（R68 的洞），语言可以被一句谎话骗过（R69 的洞），但要让力传感器读到一个不存在的接触，攻击者必须**真的施加力**——欺骗第一次有了能量价格。然而力觉不是"更可信的传感器"，而是**一类失效模式完全不同的传感器**：没接触时读数为零，和"轻触但被低通滤波抹平"在观测上不可分（遮挡/混叠）；大力时量程截断，恰好在最危险的时刻失明（饱和）；软物体把接触力分散，看起来像没接触（柔顺掩蔽）；自己的手臂碰到自己（自接触）。所以本轮的正确姿态不是"换成力觉就安全了"，而是**把力觉作为一个新的、带显式失效模式的证据源纳入不可信集合**，并为其专门建模。

**灵感 2（关节驱动 → 探询要用力，而力来自关节；关节同时是见证者）**
直觉：R69 的"看/问"都是**接收**动作，几乎不改变世界；力觉的信息动作必须是**施加**——由关节力矩产生法向力剖面。这一下把两件事绑死了：信息增益与"施加多大能量"直接挂钩，探询因此有了物理代价和不可逆性。更妙的是，产生探询力的同一套关节，还是一个**独立的测量通道**：编码器给关节角、力矩传感器给关节力矩，它们都不经过视觉标定层。视觉说手在 A、编码器经正运动学说手在 B、力说"被推了"——三条通道在接触点上互相作证。R69 用流似然做"第二意见"；R70 有了**第三意见，而且这条意见是本体感受的、无法被视觉标定吸收的**。

**灵感 3（神经科学：efference copy / corollary discharge → 自接触与外接触的可分性）**
直觉：大脑发出运动命令时，会同时发出一份副本去预测"这个动作应该产生什么感觉"；实际感觉减去预测，就是 reafference 残差。残差小 ⇒ 是我自己碰的（agency，自接触）；残差大 ⇒ 外部扰动、模型错、或传感器坏。这正是本轮的形式化钥匙：`e_eff = τ_ext,est − τ̂_eff`，其中 `τ̂_eff` 是"我预期这个动作会遇到的接触力矩"。它一身二任：作为**探询读数**，它把"摸到了什么"变成可推断量；作为**测谎仪**，外部施力无法同时伪造 efference copy 的一致性——因为你不知道我下一拍要发什么力矩。这把 R69 的"多源一致"从"两个信息源别串供"升级为"物理因果链必须自洽"。

**灵感 4（人类主动触觉的 exploratory procedures → VoI 升级为 VoHI，并引入不可逆预算）**
直觉：人识别物体不是"被动摸一下"，而是用特定探索动作：横向滑动辨纹理/摩擦、法向按压辨硬度、包握辨形状、无支撑托举辨重量（Lederman & Klatzky 的 exploratory procedures）。每种探询动作只对某一类接触假设有判别力——这天然给出了"候选信息动作"的构造法。但接触探询与 R69 的"问一句"有本质差别：问错了可以再问，**捏碎了不能再来**。所以 R69 的 VoI 必须升级为 **VoHI（value of haptic information）**，并显式减去**不可逆度**，且不可逆探询要被"可恢复性证书"门控：先轻后重、先夹持后推、先预载后加载。

**灵感 5（阻抗即策略 → 不确定性映射到"柔顺/刚硬"，而不是仅速度）**
直觉：R69 用标量 λ 缩放速度来保守。但对接触不确定性，"慢"不是正确的保守——摸黑时人的第一反应是**把手放软**（低刚度、低惯量、力饱和保护），而不是慢慢摸。关节驱动给的是一整个阻抗椭球 (K_d, B_d, M_d) 与力矩包络，不确定性可以直接映射到**阻抗**。但柔顺也是双刃剑：夹得太软会滑、精度不够、甚至失稳；所以需要**双向安全包络**——刚度下限由防滑/稳定性给出，上限由力安全给出。若区间为空，说明当前接触根本无法安全完成，必须中止/移交，而不是硬做。R69 的 λ_floor 成为 RAI 在无接触时的对角特例。

**灵感 6（对 R69 最大风险的正面回应：物理锚定）**
直觉：R69 怕"问错"。R70 的答案是给证据纪律加一条**物理锚**：语言/视觉可以提议，但**不能单独定罪**；定案必须至少有一个"需要做功才能伪造"的通道与另一个独立通道一致。物理不一致比两个语言源不一致拥有更强的否决权，因为力觉欺骗要付能量、语言欺骗不付。注意这不是"力觉永远对"的教条——引理 19 会给出对抗成本下界，也会明确它失效的条件（攻击者有无界力权限）。**物理锚降低的是欺骗概率，不是把概率变成零。**

## 1. 形式化定义（增量：定义 310–326）

**定义 310（PACT-RAS 总览）** PACT-RAS = (CTM, ECD, VoHI, RAI, CAG, CCA, RAS-WM‡)。四条不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i、R69 定义 293-i）；
(ii) **接触安全硬包络**：法向力 `f_n ≤ f_max`、接触能量 `∫|f·ẋ|dt ≤ e_max`、不可逆度 `Irr ≤ irr_max`，任何探询必须通过 CAG 认证（定义 324）；
(iii) **物理锚定证据纪律 PAED**：定案需至少一个"做功才可伪造"的通道（力/力矩/本体）与另一独立通道一致；单次探询只提供似然、不单独定案（定义 321）；
(iv) **可恢复性优先**：探询按"最小能量、最大可恢复"序展开；进入不可逆区必须先有可恢复性证书与 ex ante 价值下界（定义 317–318）。

**定义 311（接触混合状态）** 接触模式 `m ∈ M_c = {free, stick, slip, soft, hard, saturated, occluded, self}`，其中 `saturated/occluded` 是**传感失效伪模式**而非物理模式，必须与 `free/soft` 显式区分。转移由接触混合自动机 `𝒜_c` 给出；观测映射 `h: (m, θ_c) ↦ y^c` 在失效模式下**非单射**，其混叠集合 `Alias(y)={m: h(m,θ_c)=y, ∃θ_c}` 是全部"看起来一样"的假设——遮挡/饱和的危害正是让 `Alias` 变大。

**定义 312（接触观测与本体）** 接触观测 `y^c_t = (f_t ∈ ℝ³, τ^s_t ∈ ℝ⁶, T_t ∈ ℝ^{H×W} 触觉图)`；本体观测 `y^p_t = (q_t, q̇_t, τ^m_t)`，其中 `τ^m` 为**实测关节力矩**、与指令 `τ^c` 严格区分。记 `y_t = (y^c_t, y^p_t, o_t)`。

**定义 313（关节驱动与阻抗指令）** 关节层指令 `u_t = (q^d, τ^ff, K_d, B_d, M_d)`，阻抗律 `τ^c = τ^ff + K_d(q^d − q) + B_d(0 − q̇) + M_d(q̈^d − q̈)`；驱动签名 `σ_t = (τ^c, K_d, B_d)`。探询 `g` 在关节层就是一段**带力学剖面的签名轨迹** `σ_{g}`（法向力上升速率、峰值、保持时长、卸载），而非抽象向量。

**定义 314（efference copy 残差 ECD）** 由刚体动力学反解外力矩 `τ_ext,est = ID(q,q̇,q̈) − τ^m`（含 `J^T f_ext` 的投影）；efference 预测 `τ̂_eff = ContactPred(u_{0:t}, q_{0:t}, θ̂_c)`。残差 `e_eff = τ_ext,est − τ̂_eff ∈ ℝⁿ`。判别：`‖e_eff‖ ≤ ε_eff` 且预测接触由自身动作引起 ⇒ **reafferent / 自接触**；`‖e_eff‖ > ε_eff` ⇒ **exafferent 外部扰动或模型失配**。ECD 是 R70 的"agency 检测器"。

**定义 315（接触不确定性二分）** `U^c_ale = tr Σ_f + E[σ²_microslip]`（传感器噪声与微观滑移，不可约）；`U^c_epi = H(m) + H(θ_c | m)` 的**可分性加权版**：`U^c_epi = [H(m)+H(θ_c|m)] · g(Δ_min^c)`，`Δ_min^c` 为接触假设在观测空间的最小可分距离。当 `Alias` 因饱和/遮挡变大时 `g(Δ_min^c)↓`：**分不开的歧义不配得到探询预算**（R69 引理 16 的接触版）。

**定义 316（接触假设后验）** `p(m, θ_c | y_{0:t}, u_{0:t})`，`θ_c = (k_n 法向刚度, μ 摩擦系数, m_p 负载, c_n 接触阻尼, 接触几何)`；由接触混合粒子滤波维护（≤64 粒子，模式 ≤8）。后验需经**接触校准门**：模态 ECE ≤ τ_ece^c，否则禁用 VoHI（对应 R69 MCG 的接触版）。

**定义 317（可恢复性与不可逆度）** 对探询 `g`：`Irr(g) = E[D(s_{t+H}, s_t)]`，`D` 为任务相关损伤度量（塑性变形、不可逆位移、滑移距离、掉落高度）；`ρ(g) = Pr(s_{t+H} ∈ C_rec)`，`C_rec` 为可恢复到探询前安全集的状态锥。`Irr` 是**状态改变的下界**，不是普通成本：捏碎无法用"多试一次"补回，故其预算 `irr_max` 与力/能量预算并列，不可交易。

**定义 318（VoHI 主动触觉价值）** `VoHI(g) = I(m, θ_c; y_g | o, u) − c_e(g) − λ_irr·Irr(g)`，s.t. `CAG(g)=pass`、`ρ(g) ≥ ρ_min`（除非 ex ante 下界证明值得不可逆）。选择 `g* = argmax VoHI`；若 `max VoHI ≤ 0` ⇒ **不探询**，退化为 R69/R68 兜底。系：接触歧义"值不值得摸"由**可分辨性 × 可恢复性**共同决定，而不是由"有多不确定"单独决定。

**定义 319（主动触觉探索基元）** `𝒢 = {slide, press, enclosure, lift, dither}`，其判别方向分别为：`slide → (μ, 纹理)`、`press → k_n`、`enclosure → 形状/位姿`、`lift → m_p / 滑移裕度`、`dither（小幅交变力）→ 接触阻尼/稳定性`。每个基元参数化为 `(方向, 力上升率, 峰值, 保持, 卸载)` 的五元组，且必须可被 CAG 逐段认证。

**定义 320（风险自适应阻抗 RAI）** 映射 `U^c ↦ (K_d, B_d, M_d)`，满足**双向包络**：
`K_slip(m,θ_c) ≤ K_d ≤ K_force(f_max, Δx)`，其中 `K_slip` 由"防滑所需最小夹持力/允许位置误差"导出，`K_force` 由力上限导出；另加稳定性上界 `K_stab(B_d,M_d)`。若区间为空 ⇒ 当前接触无法安全完成 ⇒ 进入 L2（定义 326）。无接触时约束失效，`K_d=K_nom`，RAI **逐指令退化为 R69 的 λ 缩放**。

**定义 321（物理锚定证据纪律 PAED）** 证据源 `ℰ = {r_geo, r_sync, r_zero, r_emo, r_wm, r_force, r_eff, r_kin}`，每源带伪造成本 `c_forge(e) ∈ [0,∞]`。称 `e` 为**物理锚**若 `c_forge(e) ≥ W_min > 0`（伪造它必须注入能量/力）。定案规则：接受假设 `h` 需 `∃` 物理锚与 `h` 一致，**且**另有独立源与 `h` 一致（或两个物理锚）；仅有语言/视觉一致 ⇒ 只登记为"提议"。**物理不一致拥有否决权**：若物理锚与语言回答冲突，语言回答作废并记入审计。

**定义 322（接触跨通道对齐 CCA）** 三类残差：`r_kin = q_enc − IK(T_cam)`（视觉-本体运动学）、`r_eff = τ_ext,est − τ̂_eff`（力-驱动）、`r_tac = f_tac − f_pred`（触觉-预测）。主动选判别力最大的通道对 `pair* = argmax IG(m,θ_c; r_{ij} | g*)`，把 R69 定义 300 的被动环一致性推广到接触层。

**定义 323（驱动见证 ACT-Witness）** 定义 `Δw = |r_eff(o) − r_eff(o_cal)|` 与 `r_kin`。判据：**`r_res↓ ∧ Δa↑`（R69 的缓变故障）之外，新增 `r_res↓ ∧ r_kin↑ ∧ Δw↑`**——视觉标定吸收了偏移，但编码器/力矩通道不吸收，故驱动见证与流似然**正交**。二者构成三维判别区，用于分离"真漂移 / 缓变故障 / 接触模型失配"。

**定义 324（接触动作护栏 CAG）** 对探询 `g` 在混合自动机 `𝒜_c` 上做前向可达与解析裕度检查：`f_n≤f_max`、`e≤e_max`、滑移裕度 `|f_t|/μ ≤ f_grip`、不可逆守卫 `Irr(g)≤irr_max`、自接触守卫。任一不过 ⇒ `g` 作废、`U^c_epi` 视为未消解。CAG 是 R69 定义 302（信息动作安全）的**接触动力学版**。

**定义 325（证书 J_PACT）** `J_PACT = (J_FLUID, contact_ece, f_n_p95, e_used, irr_used, ρ_min, e_eff_p95, paed_verdict, act_witness_p95, pact_ver)`。Valid ⇔ `Valid(J_FLUID)` ∧ `contact_ece≤τ_ece^c` ∧ PAED 满足 ∧ 接触/能量/不可逆预算未越界。

**定义 326（三级退避）** 
- **L0 消解**：接触歧义在预算内消解、PAED 一致、可恢复 ⇒ `λ=λ_floor(U^c_ale)`，RAI 正常，获 resolution bonus；
- **L1 保守接触**：未消解/饱和/遮挡/`VoHI≤0` ⇒ R69 兜底 `λ=λ_floor(U^c_ale+U^c_epi)` 且阻抗压向 `K_slip` 一侧（柔顺但不失稳）；
- **L2 冻结/移交**：驱动见证判定模型或标定被污染，或 `K_slip>K_force`（包络为空）⇒ 阻抗冻结到安全保持、限力回撤、请求移交。
R69 是"无接触通道"边界，R68 是"无接触且不交互"边界；**安全侧逐级单调不降**。

## 2. 关键算法骨架

```python
# IP-264 CTM：接触混合模型（模式后验 + 失效伪模式 + 混叠集）
class ContactModel:
    def update(self, y, u):
        post = self.hybrid_particle_filter.step(y, u, self.theta_prior)
        post.alias = alias_set(post, self.h)          # 饱和/遮挡导致的不可分集合
        return post                                    # p(m, theta | y, u), U_ale, U_epi

# IP-265 ECD：efference copy 残差（agency / 外部扰动 / 模型失配）
def efference_residual(robot, u, y):
    tau_ext = robot.inverse_dynamics(y.q, y.qd, y.qdd) - y.tau_m
    tau_hat = robot.contact_predict(u, y.q, y.qd, robot.theta_hat)
    return tau_ext - tau_hat                           # ||e_eff|| 小 => reafferent

# IP-266 VoHI：可恢复性门控的主动触觉探询（无利可图即退化 R69）
def choose_probe(post, o, budget):
    best = None
    for g in exploratory_primitives(post):             # slide/press/enclosure/lift/dither
        if not budget.allow_energy(g):               continue
        if not cag.certify(g, post, o):              continue   # 力/能量/滑移/自接触
        if (irr(g) > IRR_MAX or cag.recoverability(g, post) < RHO_MIN) \
           and not worth_irreversible(g, post):      continue   # 不可逆门控
        v = mutual_info(post.mode, post.theta, g) - energy_cost(g) - LAM_IRR*irr(g)
        if best is None or v > best.v: best = (g, v)
    return best if best and best.v > 0 else None       # VoHI<=0 => 不摸

# IP-267 RAI：不确定性 -> 双向阻抗包络（无接触退化为 R69 λ）
def risk_adaptive_impedance(post, lam, mode):
    K_lo = slip_safe_stiffness(post)                   # 防滑/防失稳下界
    K_hi = force_safe_stiffness(post, F_MAX)           # 力安全上界
    K_lo = max(K_lo, stability_lower(post))
    K_hi = min(K_hi, stability_upper(post))
    if K_lo > K_hi: return None                        # 包络为空 => L2 冻结/移交
    K = project(K_nom * (1 + ALPHA * post.U_epi)**-1, [K_lo, K_hi])
    return Impedance(K=K, B=adapt_damping(K), M=M_nom)

# IP-268 CAG：接触动作护栏（混合自动机可达 + 解析裕度）
def certify(g, post, o):
    reach = forward_reachable(contact_automaton, post, g)
    return (reach.f_n_peak <= F_MAX and reach.energy <= E_MAX
            and reach.slip_margin >= 0 and reach.irr <= IRR_MAX
            and not reach.self_contact)

# IP-270 PAED：物理锚定证据纪律（语言/视觉不能单独定罪）
def verdict(post, evidence):
    anchors = [e for e in evidence if forge_cost(e) >= W_MIN]
    if not anchors: return False                        # 只有语言/视觉 => 只是提议
    if any(conflicts(e, post.mode) for e in anchors):
        veto_language(evidence); return False           # 物理不一致 => 否决
    return any(consistent_with(e, post.mode) for e in evidence if e not in anchors)

# IP-274 主闭环（两级时标：外层 100Hz 推理，内层 1kHz 阻抗不阻塞）
def PACT_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)      # R68 标定
    samples = M.fmp.sample(o, 1 if M.fmp.mode_head(z) < TAU_MODE else 4)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)  # R69
    # 1) 接触后验 + efference copy + 视觉-本体残差
    post = M.ctm.update(obs.y, M.last_u)
    e_eff = M.ecd.residual(obs, M.last_u)
    r_kin = M.cca.kinematic_residual(obs)
    slow = ((M.last_r_res < TAU_RES) and (M.last_a_hat > TAU_FMA)) \
           or (abs(e_eff) > TAU_EFF and abs(r_kin) > TAU_KIN)   # 驱动见证补 R69
    # 2) 物理锚定的接触探询（缓变故障时不摸，先查模型/标定）
    g = (M.vohi.choose_probe(post, o, M.budget)
         if (post.U_epi > TAU_C_EPI and not slow) else None)
    if g is not None:
        post = M.cca.execute_and_update(g, M.paed)               # 看/按/握/托/振
    # 3) 随机不确定性 -> 阻抗；退避是单调的
    imp = M.rai.solve(post, lam) if not slow else None
    if imp is None:
        imp = M.rai.freeze_safe(post)                            # L2：限力保持
        M.audit.request_handover(post, e_eff, r_kin)
    lam = max(M.efs.risk_scale(...), lam_floor(post.U_ale + (0 if g else post.U_epi)))
    # 4) 只有物理锚一致才认作已消解
    if not M.paed.verdict(post, M.evidence):
        post.U_epi = max(post.U_epi, post.U_epi_before)          # 证据不足 => 不消解
    # 5) 内层 1kHz：阻抗目标 + 认证前缀，限力执行
    k = M.c_ras_wm.certified_prefix(M.ach.propose(imp), ..., wm_preds)
    tau = M.pi_sigma.prefix_dispatch(k) * lam
    tau = M.cag.force_limit(tau, F_MAX)
    M.vqa_p.submit_async(g, post, e_eff, r_kin, imp)
    return k, lam, imp, post
```

## 3. 推导

**引理 19（物理锚定的对抗成本下界）** 设攻击者要在探询 `g` 期间让系统接受错误接触假设 `h'`。PAED 要求至少一个物理锚与 `h'` 一致。力/力矩通道要与 efference 预测在 `ε_eff` 内一致，攻击者必须注入广义外力 `w`，使其沿探询方向的分量 `≥ f_min(h') − ε_eff`；于是所需机械功 `W ≥ ∫ w·ẋ dt ≥ W_min > 0`。语言源的伪造成本 `≈0`。故同等欺骗率下，物理锚把攻击者的有效成功率压到 `δ_phys ≤ δ_p · Pr(E_adv ≥ W_min)`。**要点与边界**：物理锚降低的是欺骗概率、不是消灭它；若攻击者拥有无界力权限（例如整个人压在机器人上），该下界退化——此时必须靠 CAG 限力与 L2 移交，而不是靠"证据更多"。

**引理 20（可恢复性门控的保守性）** 设探询 `g` 的最坏损失 `L_max(g) ≥ Irr(g)·D_unit`。若 `g` 进入不可逆区（`ρ(g)<ρ_min`）且 `I(g;h) ≤ L_max(g)`，则 `VoHI(g) ≤ 0`，门控自动拒绝。即：**信息价值必须显式超过最坏不可逆损失，才允许不可逆探询**。系：在 `ρ≥ρ_min` 的可恢复锥内，探询的损失上界被可逆变形限制，探索的期望安全不劣于"不探询"基线；这使"轻碰—观察—再加载"成为默认序。

**引理 21（双向阻抗包络的存在性）** 防滑要求夹持力 `f_g ≥ |f_t|/μ`，而阻抗在允许位置误差 `δ` 内可调出的最大力约 `Kδ`，故 `K ≥ |f_t|/(μδ) =: K_slip`；力安全要求 `K ≤ f_max/δ =: K_force`。区间非空 ⇔ `|f_t|/μ ≤ f_max`，即摩擦锥非空且力上限足够。加入稳定界后可行域为 `[max(K_slip,K_stab^{lo}), min(K_force,K_stab^{hi})]`。若为空，任何阻抗都无法同时防滑与防损伤 ⇒ **不是调参问题，是任务不可安全完成**，必须 L2。无接触时约束不激活，`K_d=K_nom`，RAI 退化为 R69 的 λ 缩放。

**定理 18（PACT 严格包含 FLUID/R68）** 在 A99（接触模型与传感器失效模式可辨识）–A101（PAED 物理锚可用）下：当无接触通道（`f≡0`）、`VoHI≤0`、或 PAED 不成立时，PACT 逐指令退化为 FLUID；当进一步不交互时退化为 R68。其余情形下，接触歧义的消解以物理锚为据，期望风险 ≤ FLUID；安全侧因 CAG 与三级单调退避不做任何让步。故 R68 ⊂ R69 ⊂ R70 是一条**安全单调的包含链**，而不是三个并列黑箱。

**定理 19（驱动见证对视觉标定吸收的可检测性）** 若慢变视觉偏移被标定吸收（`r_res≈0`），R69 的流似然若训练分布也偏置则可能同向失效；但编码器与力矩通道独立于视觉标定。此时 `r_kin = q_enc − IK(T_cam,cal)` 随偏移线性增长，`Δw = |r_eff(o) − r_eff(o_cal)|` 因接触模型不再匹配而升高。在 A100（编码器/力矩不与视觉共标定）下，检测概率随偏移/噪声比 →1。故 `(r_res↓, r_kin↑, Δw↑)` 是缓变故障的**第三意见**，与 R69 的 `(r_res↓, Δa↑)` 正交；两者同时高 ⇒ 高置信故障，单高则按判别区分别归因于视觉漂移/接触模型失配。

**定理 20（接触安全与无突变）** CAG 认证保证 `f_n≤f_max`、`e≤e_max`、`Irr≤irr_max`；RAI 的连续投影 + bumpless transfer（指令在 `K_lo/K_hi` 间连续插值）保证阻抗切换不产生冲击力；探询失败/超时/包络为空时，退避序列 λ 单调不降、阻抗单调压向安全保持。结合 R68 提交/换装不变式（R68 定理 15）与 R69 无突变（定理 17）⇒ 控制连续、无脉冲、无突变。

## 6. 本轮最大风险

**一句话**：PACT-RAS 把「物理锚」当成不会撒谎的证人，但**物理锚的可信度完全依赖于接触/驱动模型（质量、摩擦、关节柔顺、未建模负载）与力/力矩传感链本身没有被共模污染**——一旦 efference copy 算错（例如没建模的负载或关节柔顺），系统会得到一个**自信而错误的物理确定性**，它比 R69 的"诚实的不知道"更危险，因为这次系统**有力量去执行**：用假确定性否决一个正确的语言提醒，或为一个不可逆探询（捏碎、滑脱、掉落）盖上"物理已验证"的章。

**次级风险与缓解**：
1. **力觉失效模式被忽略**（饱和/遮挡/柔顺掩蔽/自接触把"没摸到"伪装成"轻触"）→ 定义 311 显式伪模式 + `Alias` 集 + E301/E306；
2. **不可逆探询**（探询本身造成损伤）→ 定义 317–318 可恢复性门控 + 引理 20 + "轻碰—观察—再加载"默认序 + E304；
3. **阻抗包络为空仍强行接触**（防滑与防损伤不可兼得）→ 引理 21 + L2 冻结/移交，禁止硬做；
4. **内外时标耦合**（接触推理拖垮 1kHz 力控）→ 双时标 + 外层不阻塞 + 保守沿用；
5. **共模污染**（编码器/力矩与视觉一起被标定吸收或一起坏）→ 定理 19 的 A100 前提必须在证书中显式声明，A100 不成立时物理锚降级、退回 R68 纯保守，绝不让一条"可能一起坏的见证"单独定罪。

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** `PACT-RAS=(CTM,ECD,VoHI,RAI,CAG,CCA,RAS-WM‡)`；零学习写操作继承；接触安全硬包络（`f_n≤f_max, e≤e_max, Irr≤irr_max`）；PAED 物理锚证据纪律；可恢复性优先（先轻后重、先夹后推、先预载后加载）。

**定义 311–312（接触混合状态与观测）** 8 种模式，其中 `saturated/occluded` 为传感伪模式；观测映射在伪模式下非单射，`Alias` 集显式建模。接触/本体观测并列，`τ^m`（实测）与 `τ^c`（指令）严格区分。

**定义 313–314（驱动与 efference copy）** 关节指令 `u=(q^d,τ^ff,K_d,B_d,M_d)`，阻抗律 `τ^c=τ^ff+K_d(q^d−q)+B_d(0−q̇)+M_d(q̈^d−q̈)`；`e_eff=τ_ext,est−τ̂_eff`，小则 reafferent（自接触），大则 exafferent/失配。

**定义 315–316（接触不确定性二分与后验）** `U^c_ale` 进 R69 λ floor；`U^c_epi` 由模式/参数熵与可分性给出，进入 VoHI；后验经接触 ECE 门控，越界禁用 VoHI。

**定义 317–318（可恢复性与 VoHI）** `Irr(g)` 为状态改变下界（非普通成本）；`VoHI=I−c_e−λ_irr·Irr`，s.t. CAG pass 且 `ρ≥ρ_min`（或 ex ante 价值下界证明值得不可逆）；`VoHI≤0` 则不摸、退化 R69。

**定义 319–320（探索基元与 RAI）** `slide→μ`、`press→k_n`、`enclosure→形状`、`lift→负载/滑移`、`dither→阻尼/稳定`；阻抗双向包络 `K_slip≤K_d≤K_force`，空则 L2；无接触退化为 R69 的 λ 缩放。

**定义 321–322（PAED 与 CCA）** 证据源带 `c_forge`；定案须有物理锚（`c_forge≥W_min`）且另有独立源一致；物理不一致可否决语言。`r_kin, r_eff, r_tac` 主动配对，R69 的被动环一致成为"不探询"特例。

**定义 323–324（驱动见证与 CAG）** `(r_res↓, r_kin↑, Δw↑)` 检视觉标定吸收；CAG 做混合自动机前向可达 + 解析裕度（力/能量/滑移/自接触/不可逆），不过则探询作废、`U^c_epi` 未消解。

**定义 325–326（证书与三级退避）** `J_PACT=(J_FLUID, contact_ece, f_n_p95, e_used, irr_used, ρ_min, e_eff_p95, paed, act_witness, ver)`；L0 消解→`λ_floor(U^c_ale)`（resolution bonus）；L1 保守接触→`λ_floor(U^c_ale+U^c_epi)` 且压向 `K_slip`；L2 冻结/移交（模型污染或包络为空）。R69/R68 为无接触边界。

## 3. 关键算法伪代码

```python
# IP-264 CTM：接触混合模型（模式后验 + 失效伪模式 + 混叠集）
class ContactModel:
    def update(self, y, u):
        post = self.hybrid_particle_filter.step(y, u, self.theta_prior)
        post.alias = alias_set(post, self.h)
        return post                                     # p(m,theta|y,u), U_ale, U_epi

# IP-265 ECD：efference copy 残差
def efference_residual(robot, u, y):
    tau_ext = robot.inverse_dynamics(y.q, y.qd, y.qdd) - y.tau_m
    return tau_ext - robot.contact_predict(u, y.q, y.qd, robot.theta_hat)

# IP-266 VoHI：可恢复性门控的主动触觉探询
def choose_probe(post, o, budget):
    best = None
    for g in exploratory_primitives(post):              # slide/press/enclosure/lift/dither
        if not budget.allow_energy(g) or not cag.certify(g, post, o): continue
        if (irr(g) > IRR_MAX or cag.recoverability(g, post) < RHO_MIN) \
           and not worth_irreversible(g, post): continue
        v = mutual_info(post.mode, post.theta, g) - energy_cost(g) - LAM_IRR*irr(g)
        if best is None or v > best.v: best = (g, v)
    return best if best and best.v > 0 else None        # VoHI<=0 => 不摸，退化 R69

# IP-267 RAI：不确定性 -> 双向阻抗包络
def risk_adaptive_impedance(post, lam):
    K_lo = max(slip_safe_stiffness(post), stability_lower(post))
    K_hi = min(force_safe_stiffness(post, F_MAX), stability_upper(post))
    if K_lo > K_hi: return None                         # 包络为空 => L2
    K = project(K_nom * (1 + ALPHA*post.U_epi)**-1, [K_lo, K_hi])
    return Impedance(K=K, B=adapt_damping(K), M=M_nom)

# IP-268 CAG：接触动作护栏
def certify(g, post, o):
    reach = forward_reachable(contact_automaton, post, g)
    return (reach.f_n_peak <= F_MAX and reach.energy <= E_MAX
            and reach.slip_margin >= 0 and reach.irr <= IRR_MAX
            and not reach.self_contact)

# IP-270 PAED：物理锚定证据纪律
def verdict(post, evidence):
    anchors = [e for e in evidence if forge_cost(e) >= W_MIN]
    if not anchors: return False                        # 只有语言/视觉 => 仅提议
    if any(conflicts(e, post.mode) for e in anchors):
        veto_language(evidence); return False           # 物理不一致 => 否决
    return any(consistent_with(e, post.mode) for e in evidence if e not in anchors)

# IP-274 主闭环（外层 100Hz，内层 1kHz 不阻塞）
def PACT_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)       # R68
    samples = M.fmp.sample(o, 1 if M.fmp.mode_head(z) < TAU_MODE else 4)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)  # R69
    post  = M.ctm.update(obs.y, M.last_u)               # 接触后验
    e_eff = M.ecd.residual(obs, M.last_u)               # efference copy
    r_kin = M.cca.kinematic_residual(obs)               # 视觉-本体
    slow  = ((M.last_r_res < TAU_RES and M.last_a_hat > TAU_FMA)
             or (abs(e_eff) > TAU_EFF and abs(r_kin) > TAU_KIN))
    g = (M.vohi.choose_probe(post, o, M.budget)
         if (post.U_epi > TAU_C_EPI and not slow) else None)
    if g is not None: post = M.cca.execute_and_update(g, M.paed)
    imp = M.rai.solve(post, lam) if not slow else None
    if imp is None:
        imp = M.rai.freeze_safe(post); M.audit.request_handover(post, e_eff, r_kin)
    lam = max(M.efs.risk_scale(...), lam_floor(post.U_ale + (0 if g else post.U_epi)))
    if not M.paed.verdict(post, M.evidence):
        post.U_epi = max(post.U_epi, post.U_epi_before)  # 证据不足 => 不消解
    k   = M.c_ras_wm.certified_prefix(M.ach.propose(imp), ..., wm_preds)
    tau = M.cag.force_limit(M.pi_sigma.prefix_dispatch(k) * lam, F_MAX)
    M.vqa_p.submit_async(g, post, e_eff, r_kin, imp)
    return k, lam, imp, post
```

## 4. 推导

**引理 19（物理锚定的对抗成本下界）** 要接受错误接触假设 `h'`，物理锚须与之一致：攻击者必须注入广义外力 `w`，沿探询方向分量 `≥ f_min(h')−ε_eff`，所需机械功 `≥ W_min > 0`。故物理锚将有效欺骗率压到 `δ_phys ≤ δ_p·Pr(E_adv ≥ W_min)`。**边界**：攻击者力权限无界时下界退化，必须靠 CAG 限力与 L2 移交，而非"证据更多"。

**引理 20（可恢复性门控的保守性）** `L_max(g) ≥ Irr(g)·D_unit`。若 `ρ(g)<ρ_min` 且 `I(g;h) ≤ L_max(g)`，则 `VoHI(g)≤0`，门控自动拒绝——**信息价值必须显式超过最坏不可逆损失**。系：在可恢复锥内损失有界，探索期望安全不劣于"不探询"基线，"轻碰—观察—再加载"成为默认序。

**引理 21（双向阻抗包络的存在性）** 防滑需 `K ≥ |f_t|/(μδ)=K_slip`，力安全需 `K ≤ f_max/δ=K_force`；区间非空 ⇔ 摩擦锥非空且力上限足够。加稳定界后为 `[max(K_slip,K_stab^lo), min(K_force,K_stab^hi)]`；为空 ⇒ 任务不可安全完成 ⇒ L2。无接触时约束不激活，RAI 退化为 R69 的 λ 缩放。

**定理 18（PACT 严格包含 FLUID/R68）** A99–A101 下，无接触通道 / `VoHI≤0` / PAED 不成立 ⇒ 逐指令退化为 FLUID；再不交互 ⇒ 退化为 R68；其余情形接触歧义以物理锚消解，期望风险 ≤ FLUID，安全侧由 CAG 与三级单调退避保证不减。故 `R68 ⊂ R69 ⊂ R70` 是安全单调包含链。

**定理 19（驱动见证对视觉标定吸收的可检测性）** 视觉偏移被标定吸收（`r_res≈0`）时，R69 流似然可能同向失效；但 `r_kin=q_enc−IK(T_cam,cal)` 随偏移线性增长、`Δw` 因接触模型失配升高。A100（编码器/力矩不与视觉共标定）下检测概率随偏移/噪声比 →1。`(r_res↓,r_kin↑,Δw↑)` 与 R69 `(r_res↓,Δa↑)` 正交，构成第三意见。

**定理 20（接触安全与无突变）** CAG 保证力/能量/不可逆预算；RAI 连续投影 + bumpless transfer 使阻抗切换无冲击；探询失败/超时/包络为空时 λ 单调不降、阻抗单调压向安全保持；结合 R68 定理 15 与 R69 定理 17 ⇒ 控制连续、无脉冲、无突变。

## 7. 本轮最大风险

**一句话**：PACT-RAS 把「物理锚」当成不会撒谎的证人，但**物理锚的可信度完全依赖接触/驱动模型（质量、摩擦、关节柔顺、未建模负载）与力/力矩传感链本身没有被共模污染**——一旦 efference copy 算错，系统会得到一个**自信而错误的物理确定性**，它比 R69 的"诚实的不知道"更危险，因为这次系统**有力量去执行**：用假确定性否决正确的语言提醒，或为不可逆探询（捏碎、滑脱、掉落）盖上"物理已验证"的章。

**次级风险与缓解**：力觉失效模式（饱和/遮挡/柔顺掩蔽/自接触）→ 定义 311 伪模式 + `Alias` + E301/E306；不可逆探询 → 定义 317–318 可恢复门控 + 引理 20 + E304；阻抗包络为空仍强行接触 → 引理 21 + L2 冻结/移交；内外时标耦合 → 双时标 + 外层不阻塞；共模污染（编码器/力矩与视觉一起坏或一起被标定吸收）→ 定理 19 的 A100 必须在证书中显式声明，不成立时物理锚降级、退回 R68 纯保守，绝不让"可能一起坏的见证"单独定罪。
