# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「竞品分析」×「语义建图」）

> R69 把不确定性一分为二，并用主动交互去消解 epistemic。但它留下三处结构性空白：
> 1. **信任是自指的**：MCG 用模型自己的可靠图/ECE 校准模态权重。若流模型系统性过度自信，温度缩放可以把 ECE 压到阈值以下而不改变任何错误，系统仍会自信地追问幻影——**自己给自己发合格证**。
> 2. **没有记忆**：每个回合从零消歧。同一个歧义反复花钱，过去的消歧结论、信息源可信度、地点/物体/指称的语义全部丢弃；交互成本无法随时间摊薄，也无法跨回合保持一致。
> 3. **没有指称与反证**：`g_ask` 解码成自然语言，却没有显式「我在问哪个实体/哪条关系」；幻觉模态可以生成关于不存在实体的问句，而一个被投毒的回答能被直接写进「已验证」，没有来源链、没有有效期、没有谁能推翻它。
>
> 本轮两个灵感恰好补上：
> - **竞品分析**：不问「我的候选好不好」，而问「**它对谁、在哪个维度、用什么证据赢**」。把每个候选假设（含 FMP 的模态）放进一个显式竞品集，用 proper scoring rule 做头对头锦标赛；置信不再来自自我标定，而来自**击败明确对手的边际**（anytime-valid 下界）。更进一步：把 **R69 冻结为 incumbent/champion**，新假设是 challenger——只有显著击败冠军才允许改变行为。
> - **语义建图**：消歧的产物不应是一个瞬时模态，而应是一条**带来源、有效期、可废止条件的语义地图编辑**。地图是跨回合记忆、是语言的共同 ground（指称 = 节点 ID）、也是矛盾检测与最小变更修复的载体。
>
> 核心命题：**把「我该信谁」变成「它击败了谁、证据链在哪」；把「这一次选哪个」变成「地图怎么改、改哪一小块、谁能推翻它」。** 命名 **ATLAS-RAS**（Adversarial Tournament with Lexically-Anchored Semantics）。
>
> 一句话定位：R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我凭什么相信它、这份信任存在哪里、谁能推翻它**」。

## 0. 直觉与动机

**灵感 1（竞品分析 → 置信是相对的，不是绝对的）**
直觉：产品经理不会孤立地说「我的产品好」，而是说「相比 X，在延迟这一维，我用实测赢了」。R69 的模态权重是一个**绝对自评**（模型自己说 0.8），而绝对自评最容易被系统性偏差整体平移。竞品分析把它换成**相对量**：候选 h 必须在一个明确的对手集合上赢出边际。对手越强、越像自己，赢出来的信息量越大；击败一个「不存在的模态」和击败一个「看起来一模一样的诱饵」，才算真的分得开。这把 ECE 门（校准自己的分数）升级为**可证伪的锦标赛门**（打败别人）。

**灵感 2（语义建图 → 消歧的产物是记忆，不是瞬时状态）**
直觉：人不会每次都重新认识「厨房在走廊尽头」；语义地图把「哪里是什么、谁是谁、这个词指什么」沉淀下来。R69 每次消歧的结果用完即弃，等价于每次进门都失忆。语义建图让消歧**复利**：一次交互得到的「这个杯子是马克杯 / 那位老人是可信的 / 左边通道通向厨房」进入地图，后续回合直接查表；同时地图把「我说的是哪个东西」变成显式节点 ID，问句不再是自由漂浮的文本。

**灵感 3（竞品分析的第二层：champion-challenger 部署纪律）**
直觉：线上系统换模型从不看「新模型训练损失更低」，而看「在对照实验中是否显著打败线上冠军」。把 R69 冻结为 champion，任何 ATLAS 新假设都是 challenger；**只有 challenger 在锦标赛中认证领先，才允许它改变行为**，否则逐指令执行 R69。于是「新层必须是旧层的严格泛化」不再是理论口号，而是运行时的部署闸门：安全侧永远有冠军兜底，效率侧只在赢的时候兑现。

**灵感 4（语义建图作为反证结构 → 投毒无法全局改写）**
直觉：一张好地图不是「一堆事实」，而是「每个事实都记得从哪来、什么时候有效、什么能推翻它」。R69 的投毒防线是「k 个正交源一致」，但结论不落账；R70 让它落账：单源事实只是 provisional，**不能给 resolution bonus、不能降低 λ**；矛盾事实不覆盖，而是进入 contested 并把双方都保留，撤回的进墓碑。这样一次欺骗最多污染它的依赖闭包，无法把整张图变成谎话。

**灵感 5（分歧定位 → 交互该发生在「地图最不一致处」）**
直觉：R69 的 VoI 用模态熵，容易把预算花在「很大但与决策无关」的模糊上。语义地图天然给出**分歧的空间位置**：哪条边、哪个子图的标签最不确定，且该边对当前动作影响最大，就去看/问那里。竞品分析进一步说：只关心**最接近的那场比赛**——把交互花在能真正拉开冠军与最强挑战者边际的地方，而不是熵最大的地方。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（ATLAS-RAS 总览）** ATLAS-RAS = (RHT, SGM, CMD, MRA, PDL, TIG, RAS-WM†)。五条不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i；地图只在异步侧更新）；
(ii) **可证伪性**：任何假设只有在 proper scoring rule 下**认证领先其竞品集**后，才可驱动 VoI 或改变行为；自报置信度单独不得作为依据；
(iii) **来源纪律**：任何用于降低 λ 的地图事实，必须有可追溯来源与显式废止条件；单源事实恒为 provisional；
(iv) **champion-challenger**：R69 冻结为冠军；challenger 未认证领先 ⇒ 逐指令执行 R69；
(v) **交互预算与安全**继承 R69 定义 293-(ii)，信息动作仍过 C-RAS-WM 认证。

**定义 311（假设与竞品集）** 假设 h 是对未来证据 y（下次观测 / 探针回答 / 交互结果）的预测分布 p_h(y)。时刻 t 的竞品集
ℋ_t = {h_0(challenger), h_R69(冻结冠军), h_null(指称或模态不存在), h_phys(物理/仿真), h_human(人类告知者模型), h_decoy(诱饵)}。
`h_null` 与 `h_R69` 恒在：前者保证「没什么可问」能赢，后者保证「不变的旧策略」能赢。竞品集是**开放**的，允许在线注入新对手（定义 320）。

**定义 312（竞争评分与认证边际 RHT）** 取 proper scoring rule S（对数分 / CRPS / Brier 之一）。累计差
D_t(i,j) = Σ_{s≤t} [S(h_i,y_s) − S(h_j,y_s)]。
用有界增量 e-process：E_t^{(i,j)} = Π_{s≤t} exp(λ_s ΔS_s − λ_s²/2)，ΔS_s ∈ [−1,1]。在「h_i 不优于 h_j」下 E 为上鞅，Ville 不等式给出任意时刻 I 型错误 ≤ α。对 m 个对手做 Bonferroni（阈值 m/α），定义
**认证边际** M_t(h_i) = min_{j≠i} LCB_t( mean ΔS_{i,j} )，若所有 E_t^{(i,j)} > m/α 则 M_t > 0 记作 **certified lead**。只有 certified lead 才可改变行为（不变式 ii）。

**定义 313（语义地图 SGM：置信图）** M_t = (V_t, E_t, Λ_t, P_t, T_t, Tomb_t)：
- V：实体/地点/智能体（信息源）/概念节点；E：带类型的关系边（is-a, at, part-of, refers-to, caused-by, trust-of）；
- Λ_t: E → Δ(L) 为每条边的**标签对手分布**（保留歧义，不强行单真值）；
- P_t: 每条边/节点的来源集 {(source_id, evidence_hash, cert_hash, t)}；
- T_t: 有效期 [t_start, t_end) 与状态 ∈ {provisional, confirmed, contested, retired}；
- Tomb_t：被撤回事实的墓碑（含推翻它的证据），只增不删，供审计。
地图是可版本化的：`hash(M_t)` 单调递增（定义 325）。

**定义 314（动作相关地图分歧 CMD）** 边权 w_t(e) = 该边标签对当前策略动作的影响（策略对地图编码的 Jacobian / 注意力质量，归一化）。地图分歧
Dis(M_t) = Σ_{e∈E_t} w_t(e) · H(Λ_t(e))，
其中 H 为标签分布的熵。它把 R69 的「模态熵」升级为**结构 + 动作相关**的不确定性：同样一团模糊，若与当前动作无关则不计。

**定义 315（地图条件 VoI）** 候选信息动作 g 的信息增益
VoI_map(g) = E_{y~p(·|g,o)}[ Dis(M_t | o) − Dis(M_t | o, y) ]。
选择 g* = argmax_g [VoI_map(g) − c(g)]，s.t. 安全与预算；VoI_map ≤ 0 则不交互、退回 R69。注意：这里优化的是**动作相关结构分歧**的下降，而非原始熵。

**定义 316（分歧定位）** 在 M_t 上找贡献最大的子图 R* = argmax_{R 连通, |R|≤b} Σ_{e∈R} w_t(e) H(Λ_t(e))；交互候选 g 的注视/探针/指称必须落在 R* 的空间-语义邻域内（定义 322）。这把「看哪里/问什么」变为地图上的定位问题。

**定义 317（最小变更地图修复 MRA）** 新证据 y 与区域 R 的当前地图矛盾（p(y|M_R) < τ_con 且存在对手解释）时，做 AGM 式部分交修正：在 R 的**依赖闭包** Δ(R) 内选编辑距离最小的 M' 使 M' ⊨ y；只重开 Δ(R)，不全局覆写；被撤回的边/节点进 Tomb 并保留其击败证据。修复是异步的，且**不改变在线控制路径的时延**（定义 326）。

**定义 318（来源与可废止账本 PDL）** 每个事实 f 记 src(f)、provenance chain 哈希、defeater 集 D(f)、状态。纪律：
(a) 单源 ⇒ provisional：可被用于「形成更好的问题」，但**不得授予 resolution bonus、不得降低 λ**；
(b) 冲突 ⇒ contested：双方共存，直到锦标赛或新证据裁决；
(c) confirmed 需 ≥2 个正交来源一致，或认证边际超过高阈值且击败 `h_decoy`；
(d) 信息源信任本身是地图节点（定义 319），不是常数。

**定义 319（信息源可信度的锦标赛更新）** 信息源 a 的 trust(a) 为地图节点，其后验由「可验证回答」上的命中率更新（延迟真相到达时补分）；trust(a) 作为该项竞品 `h_human(a)` 的先验参与 RHT。被投毒/长期失准的源在锦标赛中落败并被降级；这与 R69 的 ℰ_poison 兼容，但结论**跨回合沉淀**。

**定义 320（诱饵与竞品生成 HexRival）** 构造难以分辨的对手：与目标相似的**指称诱饵**（外观相同的另一个物体）、标签别名、模仿型告知者、以及 `h_null`。诱饵用于训练与在线证伪：只有候选同时击败 `h_null` 与 `h_decoy`，才认为它真的分得开，而非赢在稻草人上。竞品集开放：E308 专门做「遗漏对手」压力测试。

**定义 321（锦标赛校准门 TIG）** 允许模态驱动 VoI 的门：`certified_lead(h_mode, ℋ_t)` ∧ `Dis(M_t) > τ_dis` ∧ 锦标赛有效性成立（多重比较已控制、无 optional-stopping 泄漏）。TIG 通过才允许交互决策；否则退回 R69 纯保守。ECE 仍记入证书作为诊断，但**不再是唯一门**（修复自指信任）。

**定义 322（指称接地的语言解码）** `g_ask` 只在 V_t 的节点 ID 与关系槽上解码：q = Decode_LLM(g_ask, refs = {v ∈ R*})。不得对 V_t 外或已被 `h_null` 认证为不存在的指称发问。回答反解为 (节点/边, 标签, 来源) 三元组写回 PDL。这把 R69 的自由文本问句升级为**有指称、可核验**的问句。

**定义 323（地图条件风险缩放与 resolution bonus）** λ = max(λ_efs, λ_floor(U_ale + U_epi_unresolved + U_map))，其中 U_map = Dis(M_{R*}) 仅计与当前动作相关的争议区域。**只有 confirmed 且通过 TIG 的消歧**才能把对应 U_epi 从 floor 中扣除（resolution bonus）；provisional/contested 一律照 R68 计入。⇒ 地图永远只能让系统「更有依据地不保守」，不能凭猜测更激进。

**定义 324（冷启动与退化边界）** 若竞品未认证、地图为空/只读、或 TIG 不通过，则 U_map = 0 且 ATLAS 逐指令执行 R69。因此 R69 是 ATLAS 在「永不认证」边界上的严格退化；champion-challenger 保证退化时行为差为 0。

**定义 325（证书 J_ATLAS）** J_ATLAS = (J_FLUID, tournament_margin, eprocess_valid, map_version_hash, contested_edge_ratio, provenance_completeness, map_repair_count, atlas_ver)。Valid ⇔ Valid(J_FLUID) ∧ 任何降低 λ 的地图事实均 confirmed 且 TIG 通过 ∧ provenance 完整 ∧ 地图版本单调。

**定义 326（在线/离线分离与预算）** 在线路径只做：RHT 的增量打分、局部子图查表（预计算 top-k）、TIG 判定、指称检查，目标 < 0.3ms；完整锦标赛、MRA 图修复、HexRival 生成、审计全部异步/离线，按 amortized 预算执行。实时环仍无学习写操作（不变式 i）。

## 2. 关键算法骨架

```python
# IP-264 RHT：竞品分析式假设锦标赛（proper scoring rule + anytime-valid e-process）
class RivalTournament:
    def __init__(self, alpha=0.05, tau=0.0):
        self.alpha, self.tau, self.E, self.h = alpha, tau, {}, {}

    def register(self, hypotheses):                 # 必含 h_null 与 h_R69；h0 为 challenger
        self.h = hypotheses
        self.E = {(i, j): 1.0 for i in self.h for j in self.h if i != j}

    def update(self, y):                            # 在线只做打分，不做图搜索
        for i, hi in self.h.items():
            for j, hj in self.h.items():
                if i == j: continue
                dS = hi.score(y) - hj.score(y)      # proper scoring rule，ΔS ∈ [-1,1]
                lam = self._lambda(self.E[(i, j)])
                self.E[(i, j)] *= exp(lam * dS - lam * lam / 2)

    def certified_lead(self, i):
        m = len(self.h) - 1                         # Bonferroni 控制多重比较
        return all(self.E[(i, j)] > m / self.alpha for j in self.h if j != i)

    def margin(self, i):                            # 认证边际（下界）
        m = len(self.h) - 1
        return min(log(self.E[(i, j)]) / self._rate() for j in self.h if j != i)

# IP-265/266/269 ATLAS 在线路径（保持实时、零图搜索）
def ATLAS_round(M, obs):
    z, o = M.mtm.forward(obs)                       # R69 一次前向
    U_ale, U_epi, modes, _ = M.aud.decompose(...)   # R69 不确定性二分
    # 1) 竞品分析：候选模态必须击败 h_null / h_R69 / 诱饵
    hyps = build_rivals(modes, incumbent=M.r69_frozen, null=NullHypothesis(),
                        decoy=M.hexrival.nearest(o))
    M.rht.update(o)                                 # 增量 e-process
    if not M.rht.certified_lead(modes.best):
        return M.r69_round(obs)                     # champion-challenger：逐指令退回
    # 2) 语义地图：局部 top-k 争议子图（预计算，在线不做图搜索）
    region = M.sgm.localize(o, modes, budget_k=8)
    dis    = M.sgm.disagreement(region)
    # 3) 地图条件 VoI：只在「最接近的比赛」上花钱
    g = None
    if dis > TAU_DIS and M.budget.allow():
        g = M.tig.margin_greedy(modes, region, M.rht, M.budget)
    # 4) 交互 → 指称接地 → 账本 → 异步最小变更修复
    if g is not None and M.c_ras_wm.certify_info(g, o):
        y = M.cia.execute(g)                        # 指称限定在 region 的节点 ID
        M.pdl.append(y, src=g.source, cert=M.last_j_fluid)
        M.mra.revise_async(o, y, region)            # 只重开依赖闭包，撤回收进 Tomb
    # 5) 风险缩放：只有 confirmed + TIG 的消歧才给 resolution bonus
    U_map = M.sgm.action_relevant_uncertainty(region) if dis > TAU_DIS else 0.0
    lam = max(M.efs.risk_scale(...),
              lam_floor(U_ale + M.sgm.unresolved_epi(region) + U_map))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_i.submit_async(g, region, M.rht, M.pdl)   # 参与式审计（定义见产物区）
    return k, lam, mode, (U_ale, M.sgm.unresolved_epi(region), U_map)

# IP-270 MRA：最小变更地图修复（异步，不在实时环）
def revise(M, o, y, region):
    delta = M.sgm.dependency_closure(region)
    if M.sgm.predicted(y, delta) >= TAU_CON:        # 无矛盾，仅增强置信
        M.sgm.confirm(delta, y); return
    M2 = minimal_edit(M, delta, constraint=y)       # AGM 部分交：编辑距离最小
    for fact in M.sgm.diff(M, M2):
        M.tombstone(fact, defeater=y)               # 只增不删，供审计
    M.sgm = M2; M.sgm.bump_version()
```

## 3. 推导

**引理 19（适当评分下的锦标赛可证伪性）** 设 ΔS_s 有界、proper scoring rule 严格适当（A99）。在零假设「h_i 不优于 h_j」下，e-process E_t^{(i,j)} 为非负上鞅，Ville 不等式给出 P(∃t: E_t > m/α) ≤ α/m；对 m 个对手 Bonferroni 合并后，**任意时刻**的错误认证概率 ≤ α。系：一个系统性偏差的模态即使 ECE 很低，只要存在一个真实更优的对手在竞品集内，它就无法长期保持 certified lead——**自指过自信在原理上被堵死**。

**引理 20（地图修复的局部性与投毒隔离）** 在 A101（依赖图稀疏、修复只作用于依赖闭包 Δ(R)）下，单条被投毒的 provisional 事实至多使 Δ(R) 变为 contested，不能授予 resolution bonus、不能降低 λ；全局改写需同时欺骗 Δ(R) 内 ≥k 个正交来源。结合 R69 引理 18，错误采纳率 ≤ δ_p·ρ^{k−1} + ε_σ，而墓碑保留了攻击痕迹供 VQAuditor 追责。

**引理 21（指称接地压制幻影追问）** 若问句只能指向 V_t 内节点，且 `h_null` 恒在竞品集，则发出「关于不存在实体」的问句需先让该指称通过 certified lead（击败 h_null 与诱饵）。由引理 19，幻影问句率 ≤ α（单次决策的误认证上界）+ ε_parse。E304 检验这一上界。

**定理 18（champion-challenger 安全包含）** 在 A99–A101 下，ATLAS 每一步要么执行 R69，要么执行一个在锦标赛中认证领先（含击败 `h_R69`）的 challenger。故对任意状态，ATLAS 的期望 regret 不高于 R69；且当锦标赛未认证、地图为空或 TIG 不通过时，两者**逐指令相同**（定义 324）。R69 = ATLAS 在「永不认证」边界上的严格退化；安全侧由冠军兜底，效率侧只在赢时兑现。

**定理 19（交互的边际贪心效率）** 在 A100（对手有限且可分辨，最强对手的得分差均值 Δ>0）下，margin-greedy（定义 315/321）达到认证的交互次数 ≤ O((1/Δ²) log(m/α))（LUCB/racing 型界）；而熵贪心可能把预算花在与决策无关的高熵模态上。系：**交互应发生在「最接近的比赛」与「动作相关分歧最大处」的交集**；当二者不重合时，margin-greedy 严格更省预算（E302）。

**定理 20（地图条件控制的单调安全）** 对任意地图版本，U_map ≥ 0 且只有 confirmed + TIG 的消歧可把 U_epi 从 λ_floor 中扣除；因此 λ 的**上界**不低于 R68 的保守基线，而**下界**（resolution bonus）只在有来源、可废止、且击败了冠军与诱饵的证据下才打开 ⇒ 与 R69 相比，ATLAS 不会在任何状态下采取比「R69 + 未被推翻的事实」更激进的动作。结合定理 18，安全侧单调不劣。

## 6. 本轮最大风险

1. **开放世界竞品遗漏**（未知的未知）→ 恒在 `h_null`/`h_R69`/诱饵 + E308 遗漏对手压力测试 + 保守退化；

5. **共享地图的跨智能体投毒** → 每条边独立 provenance + 来源信任节点 + 墓碑审计；
6. **冷启动过保守** → 接受退化为 R69（安全优先），效率损失计入 E309。

```python
# IP-264 RHT：竞品分析式假设锦标赛
class RivalTournament:
    def register(self, hypotheses):                  # 必含 h_null 与冻结的 h_R69；h0 为 challenger
        self.h = hypotheses
        self.E = {(i, j): 1.0 for i in self.h for j in self.h if i != j}

    def update(self, y):
        for i, hi in self.h.items():
            for j, hj in self.h.items():
                if i == j: continue
                dS = hi.score(y) - hj.score(y)       # proper scoring rule，有界
                lam = self._lambda(self.E[(i, j)])
                self.E[(i, j)] *= exp(lam * dS - lam * lam / 2)

    def certified(self, i):
        m = len(self.h) - 1                          # Bonferroni
        return all(self.E[(i, j)] > m / self.alpha for j in self.h if j != i)

    def margin(self, i):
        return min(log(self.E[(i, j)]) / self._rate() for j in self.h if j != i)
```

## 4. 推导

**引理 19（锦标赛可证伪性）** 有界 proper scoring rule 下，`E_t^{(i,j)}` 在「h_i 不优于 h_j」下为上鞅；Ville + Bonferroni 给出任意时刻错误认证 ≤ α。系：系统性能偏差的模态即使 ECE 低，只要竞品集内有真实更优者，就无法长期保持 certified lead——自指过自信被堵死。

**引理 20（投毒隔离）** 依赖图稀疏且修复只作用于闭包 Δ(R) 时，单条 provisional 投毒事实至多使 Δ(R) 变 contested；不得降 λ；全局改写需欺骗 Δ(R) 内 ≥k 个正交源，退化为 R69 引理 18 的 `δ_p·ρ^{k−1}+ε_σ` 上界，且墓碑留痕。

**引理 21（幻影追问压制）** 问句只指向 V 内节点且 h_null 恒在时，幻影问句需先击败 h_null 与诱饵；由引理 19，其率 ≤ α + ε_parse。

**定理 18（champion-challenger 安全包含）** ATLAS 每步要么执行 R69，要么执行认证领先（含击败 h_R69）的 challenger。故期望 regret ≤ R69；且未认证/空地图/TIG 不通过时逐指令相同。R69 = ATLAS 在「永不认证」边界的严格退化。

**定理 19（边际贪心效率）** 在有限可分辨对手（最强 Δ>0）下，margin-greedy 认证所需交互 ≤ O((1/Δ²)log(m/α))（LUCB/racing 型），熵贪心可能浪费在决策无关模态上；当「最接近比赛」与「最大熵」不重合时 margin-greedy 严格更省。

**定理 20（地图条件单调安全）** U_map ≥ 0，且只有 confirmed + TIG 的消歧可扣减 U_epi；故 λ 上界不低于 R68 保守基线，resolution bonus 只在有来源、可废止、且击败冠军与诱饵时打开 ⇒ 不会比「R69 + 未被推翻的事实」更激进。

## 7. 本轮最大风险

**一句话**：ATLAS 的全部新置信度都建立在**竞品集完备**这一假设上——若真实失效模式不在对手名单里，候选可以「击败所有稻草人」被 anytime-valid 地自信认证，而语义地图又会反过来条件化感知、把错误标注变成下一次观测的先验，形成**自我确认的回音室**；届时系统不是「问错」，而是**用一条漂亮的证据链证明了错误的东西**。

**次级风险与缓解**：开放世界竞品遗漏（h_null/h_R69/诱饵恒在 + E308 + 保守退化）；地图自我确认/语义漂移（provisional 不得降 λ + TTL + 最小变更 + 无地图盲测对账）；多重比较与 optional stopping 膨胀（e-process + Bonferroni/Holm + 预注册停止规则）；离线成本（在线/离线分离，仅 top-k 入环）；共享地图跨体投毒（边级 provenance + 来源信任节点 + 墓碑审计）；冷启动过保守（接受退化为 R69，效率损失计入 E309）。
