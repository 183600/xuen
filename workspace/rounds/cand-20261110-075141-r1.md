# 第 41 轮 · 双灵感落地 v18：开放词汇安全接地 × 块级不可逆守护（「可扩展安全」横切层，四层架构 v6）

> 承接第 40 轮（v17：热预算治理 × 步数感知规划 × 学习-TO 混合轨迹，四层架构 v5）。本轮灵感词「安全性 / 开放词汇」。第一反应是「给 v17 加一个 CBF 安全层」，但把官方提交仓库 README（本轮逐字重读，F67）与 2026 年这批安全文献并排读完以后，冒出来的不是「再加一层过滤器」，而是一个 v17 从未处理的结构性矛盾：**评测按跨任务/跨物品/抗干扰的开放词汇泛化打分（F68），而任何预先枚举的安全约束——黑名单、固定避障物、固定间隙、固定力限——在开放词汇下必然不完备；更糟的是，开放词汇感知恰好在最关键的新物体上最不可靠**（HazardArena 发现安全微调反而提高危险执行，F73）。于是 v18 的主轴是：**把「安全」从一张预先写死的约束表，升级为一台用带覆盖保证的开放词汇感知在线合成安全规格的机器——「可扩展安全」**。安全在这里不是独立分数，而是**不可逆失败的最小化**：它保护成功率，也保护步骤分。

## 0. 联网核实（先事实后推理；检索/核验口径 2026-11-10，来源见产物区 §5）

- **事实 F67（官方提交仓库 README.md，本轮逐字直接核验，https://github.com/unitreerobotics/unibot_submission）**：`metadata` 在握手时**只读一次**，含 `control_space`（`joint`/`ee` 互斥）、`obs_delta_indices`（键=传哪些观测、值=时间堆叠偏移）、`image_resize`（评测端 `cv2.resize` 后发送）、`action_chunk_size=T_a`（`int≥1`）、`token`；**评测端把整个 chunk 按 index 0..T_a−1 顺序执行完，才再次调用 `get_action`——块内无观测、无反馈**；动作是**绝对目标**（joint 双臂 `[7]×2`，或 ee 双臂 `[6]×2`），另有共享 `left/right_gripper` 与 `pivot`；观测**只有 4 路 RGB（480×640）+ 本体关节/EE/夹爪/lower_body + 单条静态语言指令**——**没有深度、没有力/力矩/触觉、没有温度/电流/电压**；N 台测试机随机顺序、N 个从 8765 起的连续端口可并发、每端口 reset/历史必须隔离；**§6 记录每步时延及其稳定性、动作的统计规律性，作为结果可信度依据**。
- **事实 F68（官方赛事站，https://unibot.unitree.com，2026-11-10）**：UniBot-V1 = **32 项真实世界桌面操作任务、32000 条演示、169 小时数据**；榜单按**平均成功率 + 步骤分**综合排序（当前 Coming Soon）；官方把「跨任务、跨物品、抗干扰的泛化操作」列为核心目标——**「抗干扰」意味着桌面上存在未在训练词表里枚举的物体，这既是泛化考点，也是安全风险源**。
- **事实 F69（WBAG，arXiv 2610.01083）**：把「抓取前保护机器人本体、抓取后保护本体+被夹持物体」的**抓取条件安全集**用可微 SDF 表达，转成 CBF 直接约束 VLA 的原生 6D 操作空间动作，无需重训；SafeLIBERO 上场景安全 97.38%、安全成功 59.38%，**而只扩大场景覆盖但不建模被夹持物时安全成功降到 46.25%**——证明「附着几何」与「安全成功」是两个不同的东西。
- **事实 F70（VLPSA，arXiv 2609.22462）**：在线合成 Poisson 安全函数作 CBF，双分辨率布尔组合保证实时性；SafeLIBERO 上碰撞规避从 base π0.5 的 23.1% 提到 91.2%，且任务成功率不降。
- **事实 F71（CORE，arXiv 2602.19983）**：VLM 从视觉**在线推理上下文相关的安全规则**，用开放词汇分割（SAM3）把规则接地成空间安全集，再用 CBF 执行；**在感知不确定性下给出概率安全保证**——这是「安全规格本身开放词汇」的直接先例。
- **事实 F72（SafeStage，arXiv 2609.21223）**：97 个风险场景分三阶段（初始状态隐患 / 执行期安全 / 终态隐患）；发现**名义任务成功经常与安全违规共存**，且不同策略的失败谱不同。
- **事实 F73（HazardArena，arXiv 2604.12447）**：用「安全/危险孪生场景」隔离语义风险；**只在安全场景上微调会提高良性成功率、同时提高危险场景的危险执行**；结论是「更强的执行能力不等于更安全」，语义风险必须一等对待。
- **事实 F74（ManiGuard，arXiv 2608.17386）**：200 个锁定任务 × 5 种扰动 = 1000 场景，用 LTLf 自动机监控物理谓词；**成功 rollout 中有 6–21% 违反规格**；安全微调能把安全完成率从近 0 提到 7.5–29.8%，但仍有 21–42% 的 engaged rollout 违规——**规格化安全是必要的，但零样本远不够**。
- **事实 F75（ForesightSafety-VLA，arXiv 2606.27079）**：13 类安全分类学（Safe-Core 物理 / Safe-Lang 指令 / Safe-Vis 感知），含**双臂间距、热/能区、时序前置、边缘禁入、遮挡与对抗补丁**；用累计安全代价 CC 与风险暴露时间 RET 度量过程风险；**结构/视觉扰动对安全的破坏远大于普通语言扰动**。
- **事实 F76（SafeVLA-Bench，arXiv 2606.00773）**：把任务相关安全需求编码成 STL 不变式，报成功率、安全率、成功但不安全率 SBU、最坏违规深度 VSI；**15 个成功率 >90% 的桌面策略仍有 18–28% 的不安全 episode**。
- **事实 F77（SafeManip，arXiv 2605.12386）**：用 LTLf 模板覆盖 8 类时序安全：碰撞/接触、抓取稳定、**释放稳定**、交叉污染、动作起始、机构恢复、物体容纳、围栏进入；**长时程/复杂任务暴露更多违规**，且成功率的提升不可靠地转化为更安全执行。
- **事实 F78（STeP，arXiv 2607.18580）**：用 **STL 作高层语言推理与低层执行的显式接口**；VLM 把语言指令形式化为任务级规格并分解为子任务规格，在线监控鲁棒度、违规时带鲁棒度反馈重规划；LIBERO-Constrained 上 80% safe success，真机四类任务最高 +45pp。
- **事实 F79（CoSMO，arXiv 2610.18321）**：在 **VLM 嵌入空间**做 conformal 非一致性打分，构造**在线校准的覆盖集**与**按类别膨胀的语义障碍**；嵌入距离与词表大小无关，词表扩张不会作废阈值；用 ACI 跟踪分布漂移，并支持有界延迟的专家反馈；MP3D 上语义碰撞比纯几何基线降 61.6%，真机长期覆盖 90.73%（目标 90%）。**这是「开放词汇 + 覆盖保证 + 安全接地」三者第一次在导航里合体**。
- **事实 F80（Perceive With Confidence，PMLR v270/Dixit25a）**：对预训练感知做 conformal 校准后接任意安全规划器，可获得**未见环境下的端到端统计安全保证**；四足未知室内场景实测安全提升最多 40%。
- **事实 F81（SLLCP，arXiv 2610.02765）**：把冻结 VLM 的安全预测做**标签局部化 conformal 校准**，在 15k CARLA 未见轨迹上把「会碰撞轨迹」检出率从 base VLM 的 4.6%/39.1% 提到 89.6%/88.4%——**原始 VLM 的安全判断几乎不可用，校准后才可用**。
- **事实 F82（开放词汇抓取流水线，arXiv 2603.07866）**：语言指令 → 开放词汇检测 + 可提示实例分割 → 目标点云（含遮挡下的深度补偿与两阶段补全）→ 生成并碰撞滤波 6-DoF 抓取 → 安全启发式（可达、接近可行性、间隙）选执行；四足+机械臂在杂乱桌面 90%（9/10）vs 基线 30%（3/10）。
- **事实 F83（VoLo / VoLoAgent，2026，项目页）**：把开放词汇长程操作建模为「物理编排」：VLM 以**可中断工具**的方式编排 VLA/WAM、感知模型与抓/放原语，边执行边监控、失败后恢复；**安全感知的空转（safety-aware idling）**允许在必须继续推理时先让机器人停住；真机 Franka 上 42.9% vs π0.5 14.3%。这提示：**在该接口上「停下来想」本身是一种可用的安全动作**。

## 1. 研究者直觉（先直觉与动机，后形式化）

**直觉 1（开放词汇既是安全的敌人，也是安全唯一的出路）。** 传统安全工程的隐含前提是「危险物可枚举」：固定黑名单、固定禁入区、固定力限。但本赛题明确考跨物品与抗干扰（F68），桌面上会出现在训练词表里根本没见过的物体。**任何预先写死的安全集，在开放词汇下都必然漏掉某个危险物；而漏掉的那一个恰好可能是唯一会毁掉 episode 的。** 反过来，若想覆盖新物体，就只能靠同一套开放词汇感知去**在线合成**安全集。于是安全与开放词汇不是两个话题，而是同一个问题的两面：**安全必须开放词汇化（open-vocabulary safety grounding）**。CORE 已经把「VLM 在线推理安全规则 + 开放词汇分割 + CBF」跑通（F71），CoSMO 已经证明可以给开放词汇语义加覆盖保证（F79），但都还没进桌面操作的开环 chunk 接口。

**直觉 2（在这个赛道上，安全不是第六项分数，而是「不可逆失败」的避免）。** 榜单只按成功率 + 步骤分排（F68），没有公开的「安全分」。所以如果把安全当成独立目标去最大化，就会陷入 v17 自述的过度设计陷阱。正确的定位是：**安全违规之所以值钱，是因为它常常是「不可逆」的**——掉落、碰倒、把物体推出桌面、夹持中滑脱、双臂互撞锁死、碰到人。普通失败可以重试（只吃点步骤分），不可逆失败直接把「本可成功」变成「失败」，并且毁掉后续所有步。因此 v18 的优化目标是 v17 的 E_score 加一条**机会约束**：`max E[score] s.t. P(不可逆失败) ≤ δ`。安全是手段，不是目的；它的预算必须用成功率与步骤分的机会成本来审计。SafeStage/SafeManip/SafeVLA-Bench 反复证明的「成功 ≠ 安全」（F72/F76/F77）在这里被翻译成一句更冷的话：**我们不为安全而安全，我们为「别把已经拿到的成功弄丢」而安全。**

**直觉 3（接口决定了安全必须是「块前」的，不是「块内」的）。** F67 最硬的一条：chunk 被整段顺序执行完才再次调用，块内无观测、无反馈；而且观测里没有深度、没有力/力矩/触觉。这意味着 WBAG/VLPSA 那一类**逐点 CBF**（F69/F70）在本接口上**根本来不及介入**——等你观测到要撞，chunk 已经执行完了。所以安全只能在**返回 chunk 之前对整个 horizon 认证**：给定当前本体状态、伪深度风险图、跟踪误差界，算一条**稳健可达管**，要求它不进入危险集，并保持到不可逆集的裕度；不满足就把动作**最小投影**到安全侧，实在不行就**截断 + 尾部驻留**（停下，等待下一边界重规划——这也呼应 VoLo 的 safety-aware idling，F83）。这不是「安全层做得更弱」，而是**把安全从连续时间控制问题改写成离散 horizon 的可行性问题**——恰好是这套接口允许的唯一形式。

**直觉 4（乐观-悲观对偶：任务用 MAP，安全用最坏情况）。** 开放词汇感知的输出天然不确定，VLM 的置信度又严重失校准（SLLCP：原始 VLM 仅检出 4.6% 的碰撞轨迹，F81）。一个优雅的解法是**非对称使用同一套感知**：**任务侧取 MAP/argmax 标签**（要行动，必须赌一个最可能的解释，否则永远不动）；**安全侧取 conformal 覆盖集上的最坏情况并集**（要保护，就假设所有「不能被排除」的标签都可能成立）。于是「未知/歧义」在任务侧表现为最可能的猜测，在安全侧自动升级为最高风险。**词表越大、歧义越多，安全集合只会单调变保守，永远不会因为漏标签而变得不安全**——这正好对冲 F73「越会做越危险」的悖论。CoSMO 的嵌入空间 conformal 与 ACI（F79）给了这套机制在分布漂移下仍然可用的工程骨架。

**直觉 5（修剪即深化：v17 最贵的三件套，恰好是最不可验证的三件套）。** v17 的最大风险自己已经点名：电机热只能代理、步骤分公式不可见、URDF/跟踪模型未备。本轮逐条对照 F67，发现这三件套之外还有两件：v17 的**完整离线学习-TO**依赖 URDF 与跟踪模型辨识，而 F67 的块内无反馈会让离线全解的收益被块内漂移抵消；v17 的**四级热状态机**依赖电机热遥测，而 F67 明确观测里没有温度/电流/电压。按规则 51（每轮至少修剪 ≥2 项能力展示型设计），本轮果断把 **IP-50 完整离线 TO 收窄为「块级安全投影/参考整形」（并入 IP-56）**、**IP-48 四级热机降为二级时延守护**、**IP-44 三阶段渐进蒸馏降为 P1**、**IP-25 SLO 证书并入时延守护/降 P2**。**省下的复杂度预算全部投给 Ω 安全平面**——因为安全是本轮唯一「可当场验证」的东西：像素/几何/释放稳定性都能测，而热与元学习不能。

## 2. 灵感词 → 落地线（新增 + 重构 + 修剪登记）

- 「**开放词汇（安全侧）**」→ **IP-55 OV-SAFE-GROUND（P0 新增）**：开放词汇安全语义图。对每个检测/分割实体，构造 `(几何包络 E_i, 伪深度协方差 Σ_i, conformal 标签集 C_i^α, 风险向量 r_i, 约束模板 τ_i)`；**安全风险 = 覆盖集上的最坏情况并集**（乐观任务 / 悲观安全的对偶）；未知/未覆盖标签默认 `r_max`；把风险向量经 STL 模板文法合成为**每 episode 一份**安全规格 `φ`；提供「未知即危险 + 主动查看清除」两种模式。
- 「**安全性（执行侧）**」→ **IP-56 CHUNK-SAFE-PROJECT（P0 新增，吸收 IP-50）**：**块前安全证书 + 最小投影**。对返回的整段 chunk 计算稳健可达管 `R_ε(x_0,U)`，要求 `R_ε ∩ H = ∅`、STL 鲁棒度 `ρ_φ ≥ 0`、不可逆裕度 `min ρ(x_t) ≥ 0`；不满足就在 `||U−U_nom||_W` 下做最小修改（小规模 SQP），并约束动作一阶差分 ≤ `Δ_max`（官方可信度条款）；不可行/超时则**截断到最后安全步 + 尾部驻留**。**释放稳定性**（抓取物落地前的高度、支撑多边形、姿态）是终态硬约束——它是桌面任务里最典型的不可逆失败。
- 「**开放词汇（任务侧）**」→ **IP-57 REFERENTIAL-SAFETY（P1 新增）**：指涉安全。静态指令可一次解析成指涉约束；用 conformal 目标候选集 `C_α^target` 判断「是否已经足以确定要抓/要放的到底是哪一个」；当 `|C|>1` 且错抓的不可逆代价高于多花一步的代价时，执行**信息获取动作**（腕部相机扫视/轻触前退避），否则按 MAP 直接行动；**永不向人类提问**（接口里没有人类可问），只「看」或「做」。
- **升级**：IP-36（语义图增**风险属性 + 碰撞/附着包络 + 伪深度不确定度 + STL 原子命题**）、IP-30（VLM 判别器兼**开放词汇风险接地器**，输出结构化风险而非只判进度）、IP-49（E_score 加**不可逆机会约束** `P(I)≤δ`，规划器吃 `H/φ`）、IP-50（**降 P1**，收窄为块级参考整形/可行解热启动，不再要求离线全解）、IP-43（chunk 尾部驻留 = 安全停机原语；平滑投影满足动作规律性）、IP-33（CBF **仅作末级兜底**，不再是主安全层）、IP-22/31（双目伪深度 + 不确定度）、IP-26（相机/光照/遮挡增广）、IP-45（保留最小并发/隔离）。
- **修剪登记（规则 51）**：**IP-50 完整离线学习-TO → P1**（URDF/跟踪模型未核实；块内无反馈使离线全解边际收益下降；改为 IP-56 的安全投影）；**IP-48 四级热状态机 → P1 二级时延守护**（电机热无遥测，GPU 热时间尺度长于 episode，官方只记录时延/动作规律）；**IP-44 三阶段渐进蒸馏 → P1**（训练成本高、边际得分低，P0 用 LoRA + 数据配比）；**IP-25 热稳态 SLO 证书 → 并入 IP-48 二级守护，证书化降 P2**（无可验证对象）。**本轮不为新增而新增：Ω 平面的复杂度预算完全来自这四项修剪。**

## 3. 形式化直觉（严格版见产物区 §3）

**定义 29（开放词汇安全实体）**：对检测/分割实体 `e_i`，安全描述子 `σ_i = (E_i, Σ_i, C_i^α, r_i, τ_i)`，其中 `E_i` 为几何包络（两路高位相机立体伪深度 + 腕部单目尺度），`Σ_i` 为位姿/深度不确定度，`C_i^α` 为 conformal 标签集（覆盖 `P(ℓ_i^*∈C_i^α) ≥ 1−α`），`r_i ∈ [0,1]^K` 为风险属性（尖锐/易碎/液体/热/带电/活体或人/重/未知），`τ_i` 为约束模板（最小间隙、接近速度上限、抓取区域、释放高度/姿态、禁入区）。

**定义 30（乐观-悲观对偶接地）**：任务接地 `ℓ̂_i = argmax_ℓ s_i(ℓ)`；安全风险 `r_i = ⊔_{ℓ∈C_i^α} r(ℓ, context, l)`（逐属性取上确界并集），未覆盖/低置信 → `r_max`。危险集 `H = ∪_i (E_i ⊕ (m(r_i)+κ·σ_i))`，`m` 随风险与不确定度单调增。**单调性**：`C_i^α ⊆ C_i'^α ⇒ H(C) ⊆ H(C')`——歧义/词表扩张只增不减安全保守度。

**定义 31（安全规格合成）**：`φ = Synthesize(l, {σ_i})`，由 STL 模板文法实例化（间隙、双臂间距、直立、非人接触、先验证后抓、释放稳定、容纳、禁入），指令欠定/未知指涉时**回落到保守默认子句**；`ρ_φ(U)` 为轨迹 `U` 的 STL 鲁棒度。

**定义 32（不可逆失败集与裕度）**：`I = {x : 任务在 x 后无法完成}`（物体离桌/出工作区、夹持滑脱且高于阈值、倾覆、双臂锁死、人接触）；`ρ(x)=dist(x,I)`；要求整段 chunk 上 `min_t ρ(x_t) ≥ 0`。

**定义 33（块级安全证书）**：给定 `x_0`、chunk `U`、跟踪误差界 `ε_trk`、感知误差界 `ε_perc`，稳健可达管 `R_ε(x_0,U)`；证书 `s(U)=1` 当且仅当 `R_ε(x_0,U) ∩ H = ∅ ∧ min_t ρ_φ(U) ≥ 0 ∧ min_t ρ(x_t(U)) ≥ 0`。

**定义 34（最小安全投影）**：`U^* = argmin_U ||U−U_nom||_W^2 s.t. s(U)=1 ∧ ||u_{t+1}−u_t|| ≤ Δ_max`；按字典序「安全 ≻ 规律性 ≻ 贴近名义」；不可行/超时 → 截断到最后安全步 `n_safe` 并尾部驻留 `hold`。

**定义 35（指涉安全的信息获取）**：目标候选集 `C_α^target(o)`；信息动作 `a_info`（改变腕部视角/轻退避再接近）的期望收益 `E[Δ] = P(wrong|C)·L_wrong − c_step·E[ΔN]`；当且仅当 `E[Δ] > 0` 才获取信息，否则按 MAP 行动。

**定义 36（安全-得分机会约束）**：`π^* = argmax_π E_score(π) s.t. P(不可逆失败 | π) ≤ δ`，`E_score` 沿用定义 27；`δ` 由「多保守值得」的机会成本曲线标定，而非固定为 0。

## 4. 关键决断

1. **安全 = 不可逆失败避免**：不追求抽象安全率，追求「别把本可成功的 episode 弄成不可逆失败」，并用步骤/成功率机会成本审计每一次保守。
2. **开放词汇安全必须在线合成**：固定安全集只作先验与兜底；未知即危险；用带覆盖保证的 conformal 标签集把「未知」显式变成「最高风险」。
3. **安全做在块前，不做在块内**：本接口块内无反馈、无力/深度，逐点 CBF 只作末级兜底；主安全层是 horizon 级证书 + 最小投影 + 截断驻留。
4. **乐观任务 / 悲观安全**：同一套开放词汇感知，任务取 MAP、安全取最坏情况并集；词表扩张只提高保守度。
5. **修剪四项换预算**：离线全解 TO、四级热机、渐进蒸馏、SLO 证书降级；省下的复杂度全部投 Ω 安全平面。
6. **复用官方模型**：UnifoLM-VLM-Base（qwen2_5_vl 底座，F62 延续）可直接充当开放词汇风险接地器，SAM3/GroundingDINO 作检测分割；不引入外部闭源依赖。

## 5. 本轮最大风险（一句话）

**若开放词汇风险接地恰好在真正的新物体上系统性失准（HazardArena 已证明「越会做越危险」，F73）、若没有深度使伪深度包络的不确定度大到只能全保守从而吃掉步骤分、若评测根本不把碰撞/掉落计入安全而我们的保守只换来成功率下降——那么「校准风险图 → 块级安全证书」就会把 v17 的得分效率重新拖回不可验证的猜测量；必须以 E73–E79 七重守门，任一失败即回退到「仅释放稳定性 + 未知即避让」的最小安全集。**

### 3.2 IP-55 OV-SAFE-GROUND（开放词汇安全接地，完整设计）

**IP 卡片（六字段）**
- **动机**：官方按跨物品/抗干扰评分（F68），未在词表枚举的物体既是泛化目标也是危险源；固定安全集在开放词汇下必然不完备（F69–F77 一致显示「成功≠安全」）；原始开放词汇/VLM 置信度严重失校准（F81：4.6% 碰撞检出），必须用覆盖保证把「未知」显式变成「最高风险」（F79/F80）。
- **与现有方案差异**：(a) WBAG/VLPSA 做逐点 CBF，但依赖可干预的连续控制与较可靠几何，本接口块内无反馈、无深度（F67）；(b) CORE 做 VLM 在线安全规则 + 开放词汇分割 + CBF，但没有「任务 MAP / 安全最坏情况」的显式对偶，也没处理桌面伪深度不确定度；(c) CoSMO 做开放世界校准语义图，但面向导航、非桌面操作与静态指令；(d) **本 IP 的独特点是「非对称接地 + 静态指令一次成规格 + 未知即危险/主动查看的两种模式」**——把统计覆盖保证直接接到桌面操作的块级安全证书上。
- **技术可行性**：检测/分割可用 SAM3 / GroundingDINO / CLIPSeg（F71/F79/F81）；风险接地复用官方 UnifoLM-VLM-Base（qwen2_5_vl，F62 延续）或本地小 VLM；立体伪深度来自两路高位相机（IP-31）；conformal 校准只需 2–5k 条「对象×风险标签」离线样本；STL 合成用模板文法（STeP，F78）+ 保守默认子句。检测/接地在块边界做，单次几十毫秒；规格每 episode 只合成一次。
- **所需资源**：校准集（对象裁剪、标签、风险属性、约束模板）；已知物体伪深度误差标定；8 类 SafeManip 时序模板（F77）+ 人接触/双臂间距（F75）；算力 <100ms/块边界，可缓存。
- **落地步骤**：① E73 建校准集与风险属性问卷；② 嵌入空间 conformal + ACI 上线；③ 风险→模板映射与 STL 文法；④ 风险图接入 IP-36；⑤ 与 IP-56 联调；⑥ E73/E76 验收。
- **风险**：校准漂移（跨机/光照）→ ACI + 局部化校准（F79/F81）；词表扩张使覆盖集变大 → 最坏情况风险上升（这是**设计意图**，但需 E76 审计步骤代价）；VLM 接地延迟 → 只在块边界/场景变化时调用 + 缓存；伪深度无深度 → 保守膨胀 + 「未知即危险」。

**符号表**

| 符号 | 含义 | 来源/取值 |
|---|---|---|
| `e_i` | 第 i 个开放词汇实体 | SAM3/GroundingDINO 检测分割 |
| `C_i^α` | conformal 标签集，`P(ℓ_i^*∈C_i^α)≥1−α` | 嵌入空间非一致性 + 校准集（F79） |
| `r_i∈[0,1]^K` | 风险属性向量（尖/碎/液/热/电/活体/重/未知） | VLM 结构化问卷；`C_i^α` 上最坏情况并集 |
| `E_i, Σ_i` | 几何包络与不确定度 | 立体伪深度 + 单目尺度 |
| `τ_i` | 约束模板 | 风险→模板映射表 |
| `m(r,σ)` | 安全裕度 | `m_0 + μ·||r|| + κ·σ` |
| `H` | 危险集 | `∪_i inflate(E_i, m+κσ)` ∪ 语义禁入区 |
| `φ` | 每 episode STL 规格 | 模板文法实例化 |
| `ρ_φ(U)` | STL 鲁棒度 | 在线/离线监控（F78） |

**风险属性问卷（VLM 只回答结构化问题，降低幻觉面）**：对每个 mask，问 8 个二值/三值问题（「它是否有可割伤的刃/尖？」「是否易碎？」「是否装液体/可洒？」「是否热/带电？」「是否活体或人？」「是否重到单臂不可控？」「是否属于官方指令的目标？」「是否无法归入以上任何类？」），温度缩放后取阈值；**「无法归入任何类」= unknown ⇒ r_max**。

**算法**
```
输入: 4RGB, 本体状态, 静态指令 l, conformal 校准集, 上一帧风险图（缓存）
1. 若首帧或场景变化(像素/位姿差>θ):
   {mask_i, box_i, s_i} ← OpenVocabDetectSegment(4RGB)          # SAM3/GroundingDINO
   z_i, Σ_i ← StereoPseudoDepth(left_high,right_high,wrist_scale) # IP-31
   C_i^α ← {ℓ : nonconformity(ℓ) ≤ q_α}                          # 嵌入空间 conformal(F79)
   ℓ̂_i ← argmax_ℓ s_i(ℓ)                                        # 任务侧 MAP
   r_i ← ⊔_{ℓ∈C_i^α} RiskQuestionnaire(ℓ, crop_i, l, context)   # 安全侧最坏情况
   若 C_i^α 为空或含 unknown: r_i ← r_max
   E_i^+ ← inflate(E_i(z_i), m(r_i,Σ_i))
   H ← ∪_i E_i^+ ∪ SemanticNoGo(l)                               # 语义禁入区
2. φ ← SynthesizeSTL(l, {σ_i})                                   # 每 episode 一次；模板文法+默认子句
   默认子句: □clearance(robot∪grasped,H)≥0; □arm_sep≥d_min; □upright(grasped);
             □¬contact(human); grasp(o)→verified(o); release(o)→stable(o)∧contained(o,goal)
3. 若存在未观测/高不确定区域且其可能进入工作空间:
   选择 look-to-clear（腕部扫视/侧移观察）或按 unknown-as-hazard 保守绕行
返回 H, φ, {ℓ̂_i}（任务）, {C_i^α, r_i}（安全）
```
**复杂度**：检测/分割 O(#mask·HW)；conformal 仅查表 O(#labels)；风险问卷 O(#entities) 次 VLM（可在块边界批处理，缓存；场景不变时复用）。总开销 <100ms/块边界；**规格每 episode 一次 <300ms**，摊到整段 episode 可忽略。

**正确性论证**
- **P51（conformal 最坏情况可靠性）**：若 `ℓ_i^*∈C_i^α` 以概率 ≥1−α 成立，且风险并集 `r_i=⊔_{C_i^α} r(ℓ)` 是逐属性上界（`r(ℓ^*) ≤ r_i` 逐分量），则实例化的危险集 `H(C_i^α)` 以概率 ≥1−α 包含真实危险集。于是任何对 `H` 成立的块级证书，对真实危险集的违反概率 ≤ α + 感知/跟踪误差项。**注意**：这是边际保证；跨机偏移下用 ACI/局部化（F79/F81）把 α 的失效降到可控。
- **P52（词表/歧义的单调安全性）**：`C⊆C' ⇒ H(C)⊆H(C')`（并集单调 + 膨胀单调）。故新增标签或歧义**只会增大**危险集与裕度，不会因「漏了一个没见过的危险标签」而降低安全性；代价是步骤/可达空间，须由 E76 的机会成本曲线审计。这正是 F73「越会做越危险」的结构性对冲。
- **P53（未知即危险的下界）**：当 `C_i^α` 含 unknown 或为空时 `r_i=r_max`，故 `H` 至少包含该实体的最大膨胀包络；在**没有任何先验**时，这是不依赖分类正确性的安全下界。

### 3.3 IP-56 CHUNK-SAFE-PROJECT（块级安全证书与投影，完整设计）

**IP 卡片（六字段）**
- **动机**：F67 说 chunk 整段执行、块内无反馈且无力量测——逐点 CBF 在本接口上无法及时介入；而桌面最典型的不可逆失败是**释放不稳定**（F77 明确列「释放稳定」；F76 成功不安全率 18–28%）。因此安全必须在**返回 chunk 前**对整个 horizon 认证，并对不安全的 chunk 做**最小修改**，而不是事后补救。
- **与现有方案差异**：WBAG/VLPSA/CORE 的安全过滤器都是**逐步**的（每步解 CBF-QP）；本 IP 是**离散 horizon 的可行性/投影问题**——对 `T_a` 步整段证书，且把「块内不可干预」当作一等约束。这是接口原生创新，不是把 CBF 调小。
- **技术可行性**：`T_a` 一般 8–32，状态 ≤21 维、控制 ≤20 维；稳健可达管用区间/椭球过近似 + 跟踪误差界（可由示范辨识，A44；退化用保守 box）；投影是 `T_a×d` 变量的小规模 SQP，热启动 `U_nom`，毫秒–十毫秒级；不可行时截断+驻留（`hold`）天然可行。
- **所需资源**：跟踪误差界 `ε_trk`（每机一次辨识或保守上界）；近似身体模型（URDF 可得则用，否则用示范拟合的**胶囊代理**，A43）；可选 MuJoCo 校验（IP-35）；`H/φ` 来自 IP-55。
- **落地步骤**：① E75 在仿真/已知几何上标定可达管与投影；② 实现截断+驻留原语（IP-43）；③ 与 IP-55 联调；④ 真机 A/B（E76）；⑤ 上线门控（默认开，超时自动退化）。
- **风险**：可达管过保守 → 投影频繁不可行 → 截断吃掉步骤分（E76 审计；按场景调 `κ`）；跟踪模型 OOD（线搜索收紧 + 默认退化为 VLA 伺服）；solve 超时（硬 deadline = 0.5·chunk 窗口，超时截断）；释放稳定阈值无标定（A45）。

**符号表**：`x_0` 当前状态；`U∈R^{T_a×d}` chunk；`f` 名义闭环（目标→实际）；`ε_trk,ε_perc` 误差界；`R_ε(x_0,U)` 稳健可达管；`H` 危险集；`I` 不可逆集；`ρ` 可恢复裕度；`ρ_φ` STL 鲁棒度；`W` 投影度量；`Δ_max` 动作一阶差分上界（可信度）。

**算法**
```
输入: x_0, U_nom(来自 VLA/流式/可选 IP-50 整形), H, φ, ε_trk, ε_perc, Δ_max, deadline
1. R ← RobustReachableTube(x_0, U_nom, f, ε_trk, ε_perc, horizon=T_a)
2. if R ∩ H = ∅ and min_t ρ_φ(U_nom) ≥ 0 and min_t ρ(x_t(U_nom)) ≥ 0:
       return U_nom                              # 名义已安全，零修改
3. 解最小安全投影（warm start = U_nom）:
   U* = argmin_U ||U − U_nom||_W^2
        s.t.  R_ε(x_0,U) ∩ H = ∅                # 几何安全（含被夹持物附着几何）
              ρ_φ(U) ≥ 0                         # 时序/语义规格（STL）
              min_t ρ(x_t(U)) ≥ 0                # 不可逆裕度
              ||u_{t+1} − u_t|| ≤ Δ_max          # 动作规律性（官方可信度）
        # 小规模 SQP/序列凸；字典序：安全 ≻ 规律性 ≻ 贴近名义
4. if 不可行 or 超时(>0.5·chunk窗口):
       n_safe ← max{n : 前 n 步满足证书}
       return U_nom[0:n_safe] + Hold(x_{n_safe})  # 截断 + 尾部驻留（安全停机）
5. 块边界: 观测实际结果；若 ||x_actual − x_pred|| > ε_trk:
       收紧 ε_trk / 标记跟踪模型失配 / 触发重规划；若发生安全事件 → 写入失败记忆
```
**释放稳定终态约束（显式）**：`release(o) → (h_release ≤ h_max) ∧ (com(o) ∈ support_polygon(o, surface)) ∧ (tilt(o) ≤ θ_max) ∧ (o ∈ goal_region)`；其中 `com/support/tilt` 由开放词汇 6D 位姿 + 伪深度估计，阈值由 E74/E79 标定。**这一条直接对撞「最后一厘米」失败**，且比离线高精度 TO 便宜、可验证。

**复杂度**：可达管 `O(T_a·d²)`；SQP 每迭代 `O(T_a·d³)`，`T_a≤32,d≤20` ⇒ 毫秒–十毫秒；每块最多一次投影；超时硬截断保证最坏退化为「安全停机」。

**正确性论证**
- **P53（截断-驻留可行性）**：若 `x_0` 安全（`ρ(x_0)≥0`）且名义轨迹的前 `n_safe` 步可证安全，则「执行前 `n_safe` 步 + 驻留`hold`」在 `hold` 保持状态不变的假设下仍安全；因此**投影问题总有可行解**（可能退化为 `n_safe=0`，即本块不动）。这保证 IP-56 不会把系统置于「无安全动作可返回」的死局。
- **P54（字典序投影的最优性/规律性）**：在安全可行集非空时，最小 `W`-范数投影是到安全集的最近点（凸近似下最优）；`Δ_max` 约束保证投影后的动作仍落在官方动作规律性包络内，避免「安全修正被可信度条款判为离群」的次生风险。若安全与规律性冲突，按字典序先保安全、再在下一步用驻留/减速恢复规律性，并在日志中标记。
- **P57（块边界充分性）**：由于块内不可干预，任何在块内发生的安全事件都无法在块内被阻止；因此**在返回前认证整个 horizon** 是唯一能改变结果的手段，块边界的观测只用于「检测已发生的事件 + 收紧下一块」。这把「检测延迟」从安全问题降级为恢复问题。

### 3.4 IP-57 REFERENTIAL-SAFETY（指涉安全，完整设计）

**IP 卡片（六字段）**
- **动机**：开放词汇指令会用没见过的名词指涉目标（「把 spork 放到 ramekin 旁边」）；抓错物体是**语义级不可逆错误**（移动/消耗了错误对象），HazardArena 证明同一动作在不同语义下由安全变危险（F73）。静态指令的好处是**指涉约束可以在 episode 开始时解析一次**。
- **与现有方案差异**：常规开放词汇抓取直接取 argmax（F82），不量化「还不确定」；本 IP 用 conformal 候选集判断是否已足够确定，并用**错抓代价 vs 多花一步**的决策阈值决定是否做信息获取动作。**不向人提问**（接口无人可问），只「看」。
- **技术可行性**：目标候选集来自 IP-55 的同一套 conformal 机制；信息动作 = 腕部相机扫视/侧向观察/轻退避再接近（不需要额外硬件）；阈值由 E77 标定。
- **所需资源**：指涉解析（VLM 一次性把指令拆成「目标/参考物/关系/终态」）；错抓代价表 `L_wrong`（按任务类型/物体可逆性）；步数成本估计。
- **落地步骤**：① 指令→指涉约束解析；② conformal 目标候选集；③ 信息动作库；④ 阈值标定（E77）；⑤ 接入 IP-49。
- **风险**：多花步数吃步骤分（E77 明确审计）；指令本身歧义（回落保守默认：先看后动）；伪深度下候选集过大（设上限，超过则保守抓取最大/最稳候选）。

**算法（阈值规则）**：`commit` MAP 当 `E[Δ]=P(wrong|C_α)·L_wrong − c_step·E[ΔN] ≤ 0`；否则执行 `a_info`，更新 `C_α`，重复；最多 `k_info` 次（默认 1–2），之后必须 commit（避免无限观察）。
**正确性论证 P55**：在单步 lookahead 下，当且仅当上式 `>0` 时获取信息的期望收益为正；因此该阈值规则在给定 `C_α`、`L_wrong`、步数成本下是局部最优的「看 vs 做」决策。多步版本用动态规划/rollout 近似，但单步阈值已能消除大部分「自信抓错」。

### 3.5 v18 四层架构 v6（Ω 安全横切）

```
      ┌────────────── Ω 安全规格平面（IP-55 → IP-57 → IP-56）──────────────┐
      │ 开放词汇实体 → conformal 标签集 → 最坏情况风险 → STL 规格 φ          │
      │ 指涉候选集/信息获取 → 块前 horizon 证书 → 最小投影/截断驻留          │
      └──────────────────────────────────────────────────────────────────┘
      ┌────────────── Δ 资源平面（IP-48'：二级时延守护 + 并发准入）──────────┐
```

```python
# ===== 离线：开放词汇安全校准（IP-55，E73）=====
def calibrate_open_vocab_safety(calib_set):
    # calib_set: (image_crop, true_label, risk_attrs, constraint_template)
    embed = FrozenVLMEmbedder()                    # 官方 UnifoLM-VLM / qwen2_5_vl
    scores = [nonconformity(embed(x), y) for x, y, *_ in calib_set]
    q_alpha = quantile(scores, 1 - alpha)          # 嵌入空间 conformal（F79）
    risk_table = fit_risk_grounder(calib_set)      # 结构化问卷 + 温度缩放
    return q_alpha, risk_table

# ===== 离线：跟踪误差界与释放稳定阈值（IP-56，E74/E79）=====
def calibrate_chunk_safety(robot_if, sim):
    traj = collect_target_vs_actual(minutes=30)    # 目标→实际
    eps_trk = fit_error_bound(traj)                # 分位数保守界
    release_stats = sim.sweep_release_heights()    # 倾倒/滑移阈值
    return eps_trk, release_stats

# ===== 运行期：安全接地 + 块级证书 =====
def act_v18(obs, state):
    # 1) 开放词汇风险图（块边界，缓存；场景变化才重算）
    risk = state.risk_map
    if risk is None or scene_changed(obs, state.last_obs):
        risk = ov_safe_ground(obs, state.instruction,
                              q_alpha=state.q_alpha, risk_table=state.risk_table)
        state.risk_map, state.phi = risk.H, risk.phi
        state.last_obs = obs

    # 2) 指涉安全：是否已足以确定目标？（IP-57）
    if state.need_target and not target_confident(risk, state.instruction):
        if worth_looking(risk, state.cost_model):          # P(wrong)·L_wrong > c_step·E[ΔN]
            return info_gathering_action(obs, state)       # 腕部扫视/侧移观察
        # 否则按 MAP commit

    # 3) 规划（机会约束）与可选整形
    if state.need_plan:
        state.plan = step_score_planner(obs.language, risk, state.p_s, state.W,
                                        scenario=state.sigma, budget=state.knobs,
                                        delta_irreversible=state.delta)
    U_nom = state.plan.next_chunk(obs, state)              # VLA/流式/可选 IP-50 整形

    # 4) IP-56：块前安全证书 + 最小投影（含释放稳定终态）
    U = chunk_safe_project(U_nom, x0=obs.state, H=state.phi.H,
                           phi=state.phi, eps_trk=state.eps_trk,
                           eps_perc=risk.eps_perc, delta_max=state.delta_max,
                           deadline=0.5 * state.chunk_window)
    if U is None:
        U = truncate_and_hold(U_nom, state)                # 安全停机
    # 5) 末级 CBF 兜底（只在单步可判时）
    U = guard_cbf(U, risk.H)                               # IP-33
    return U

# ===== 块边界：用结果校正 =====
def after_chunk(obs_next, state):
    if tracking_mismatch(obs_next, state.pred, state.eps_trk):
        state.eps_trk = tighten(state.eps_trk)
        state.need_plan = True
    if safety_event_detected(obs_next, state.phi):
        state.failure_memory.log(event="irreversible", scene=state.sigma)
```

## 6. 清单迭代规则（继承 27–51 + 本轮新增 52–55）

- 继承规则 27–51（通道诚实/映射验证/SLO/fail-safe/灵感-现实校验/单模型合规/步骤分双解释/稠密监督/方法论遗产/元数据重照亮/语言口径分离/摊销/验证器分级/灵感词落地/层级联合规划/跨本体运动/流式韵律/渐进蒸馏/服务化/证书化/组合代数/热预算/期望得分规划/学习-TO 三段式/修剪优先）。
- **52（新增）：可扩展安全原则**——安全约束必须由开放词汇感知**在线实例化**；任何预先枚举的固定安全集只能作先验与兜底；**未知即危险（unknown-as-hazard）**是默认，主动查看（look-to-clear）是可选的、需用步数机会成本审计的反例。
- **53（新增）：乐观-悲观对偶原则**——任务接地取 MAP/argmax，安全接地取 conformal 覆盖集上的**最坏情况并集**；词表/歧义扩张只能提高安全保守度，不能降低；概率保证必须显式标注 α 与失效条件（分布漂移用 ACI/局部化）。
- **54（新增）：块前证书原则**——在块内无反馈的接口上，安全必须在**返回 chunk 前**对整个 horizon 认证；块内逐点 CBF 只作末级兜底；不可行时以「截断 + 尾部驻留」作为保底安全动作。
- **55（新增）：不可逆优先原则**——安全预算优先花在不可逆失败（释放稳定、掉落、人接触、自碰撞、倾覆），可恢复碰撞只做轻量避让；每一次安全保守都要用成功率/步骤分的机会成本审计，禁止无限保守。

**本轮最大风险一句话**：开放词汇风险接地在新物体上失准 + 无深度使包络过保守 + 评测可能不把碰撞/掉落计入——三者叠加会让「校准风险图 → 块级安全证书」退化为吃掉步骤分的过度保守；以 E73–E79 七重守门，全败即回退「仅释放稳定性 + 未知即避让」最小安全集。

**当前最值得押注**：**IP-56 CHUNK-SAFE-PROJECT（块级安全证书与最小投影）**——它是唯一**接口原生、可单点证伪、且同时保护成功率与步骤分**的落地点：不依赖热遥测、不依赖 URDF（可退化）、不依赖深度（用保守包络），只依赖「返回前对整段 chunk 做一次可行性检查」；E75 一个实验就能判定「开环 chunk 上做块前安全证书」是否真的比逐点 CBF/无守护更安全且不伤分，其余两条线（IP-55 风险图、IP-57 指涉安全）都为它提供输入或减少它的无效触发。
