### 第 1 轮灵感驱动研究记录

**灵感词**：多机器人协作、同步定位与建图

**直觉与动机**：
现有 SRC-USC v25 已把感知、结构、重构、协同都纳入证书链，但它把「定位与建图」当成前提条件而非被验证对象。直觉上，多机 SLAM 的关键矛盾是：跨机回环既是消除漂移的唯一信息来源，也是感知别名/欺诈/外点污染全局地图的主要入口。若地图没有可复核的「位姿图证书」，则再强的语义与协同证书也可能建立在错误坐标系上。核心洞见是：**SLAM 不是先建图再验证，而是证书的制造过程；地图融合是证书的拉回与交集；跨机回环是证书的粘合；位姿图是证书的承载结构**。因此应把「一张地图」升级为「一张带证书的位姿图」，只有在层论全息、可观测性、回环精度、融合一致性四个不变量同时成立时，地图才可准入。

**形式化目标**：
1. 定义证书化位姿图（CPG）：𝒢 = (𝒱, ℰ, 𝒞)，每条边携带测量 z_e、信息矩阵 Ω_e 与证书 c_e = (α_e, τ_e, s_e)。
2. 定义多机 SLAM 证书（MRSC）：规范固定后可观测性 λ_min(Λ_i) ≥ λ_obs、基本环全息 ‖log H_γ‖ ≤ δ_cycle、位置边际不确定度 tr(Σ_i^pos) ≤ ε_pose²。
3. 定义跨机回环证书（IRLCC）：接受集精度 P(true|accept) ≥ 1-α_lc、稳健马氏残差 d_e² ≤ χ²/s_e、加入后环全息增量 ≤ δ_cycle。
4. 定义分布式地图融合证书（DMFC）：占据分歧 D(𝒎_i, 𝒎_j) ≤ ε_map、协方差交集不重复计数、每连通分量锚定且生成树漂移有界。
5. 构建协同 SLAM 统一准入门（CS-UC v26）：Exec_v26 = Exec_v25 ∩ Fil_cslam ⊆ Exec_v25，并证明在误回环、融合冲突、可观测性退化下的单调退化保持性。

## 1. 从直觉到严谨定义：证书化协同 SLAM 的四个不变量

**直觉**：单机 SLAM 只保证「局部自洽」，漂移沿轨迹无界累积；多机协作的价值在于引入跨机回环，把不同机器人轨迹「钉」到同一坐标系。但跨机回环同时是最脆弱的环节：一次感知别名就把两个相似走廊错钉在一起，随后位姿图优化会把整张地图拉歪。故正确的对象不是「地图」，而是「带证据的位姿图」：每条边都保留测量来源与统计承诺，全局地图只有在证书可粘合时才被承认。

**定义 1200（证书化位姿图 CPG）**：𝒢=(𝒱,ℰ,𝒞)，𝒱=⋃_{i,t}{x_i^t}⊂SE(3)，ℰ=ℰ_odom ∪ ℰ_loop^intra ∪ ℰ_loop^inter ∪ ℰ_prior；每条边 e=(u,v) 携带 z_e、Ω_e 与 c_e=(α_e,τ_e,s_e)。CPG 的「地图」是证书函子 𝒞: ℰ→Cert，而非裸点云。

**定义 1201（层论全息一致性）**：对环 γ=e_1…e_k，全息 H_γ=ẑ_{e_1}⊙…⊙ẑ_{e_k}。称 𝒢 在容差 δ_cycle 下层论一致，若对基本环基 ∀γ∈Fund(𝒢)：
$$\|\log(H_\gamma)\|_{\Sigma_\gamma}\le\delta_{cycle}.$$
基本环张成整个环空间，故任一环的漂移均被基本环的证书控制；这正是「局部证书可粘合为全局截面」的可计算判据。

**定义 1202（MRSC 可观测性证书）**：固定锚点消去规范自由度后，
$$\lambda_{\min}(\Lambda_i)\ge\lambda_{obs},\qquad \mathrm{tr}(\Sigma_i^{pos})\le\varepsilon_{pose}^2,$$
其中 Λ_i=J_iᵀΩJ_i，Σ_i^pos 为 Λ_i^{-1} 的位置块。前者排除退化几何（长走廊、纯旋转、平面退化），后者给出绝对定位不确定度上界。

**定义 1203（IRLCC 跨机回环证书）**：接受集 𝒜_lc 须同时满足
(1) 精度：P(correct | accept) ≥ 1-α_lc（离线 conformal 校准 + 在线滑动窗口重标定）；
(2) 稳健残差：d_e²=r_eᵀΩ_e r_e ≤ χ²_{dim,1-α_lc}/s_e；
(3) 可粘合：对任意含 e 的环，加入 e 后全息增量 ‖log(H_{γ⊕e})‖−‖log(H_γ)‖ ≤ δ_cycle。
三条件分别防误匹配、防大残差污染、防破坏全局一致。

**定义 1204（DMFC 地图融合证书）**：对占据栅格 𝒎_i,𝒎_j，
$$D(\boldsymbol m_i,\boldsymbol m_j)=\frac1{|\mathcal C|}\sum_{c\in\mathcal C}\mathbf 1[\boldsymbol m_i(c)\oplus \boldsymbol m_j(c)]\le\varepsilon_{map},$$
融合采用协方差交集 P_f=(∑_i ω_i P_i^{-1})^{-1}，∑ω_i=1，并要求 tr(P_f)≤min_i tr(P_i)+ε_cov（防重复计信息导致过度自信）；每个连通分量至少一个锚点，沿生成树累计漂移 ≤ L_tree·ε_drift。

**定义 1205（CS-UC v26 准入）**：对多机计划 Π，
$$\mathrm{CS\text{-}UC}(\Pi)=\mathrm{SRC\text{-}USC}(\Pi)\wedge\mathrm{MRSC}(\mathcal G_\Pi)\wedge\mathrm{IRLCC}(\mathcal A_\Pi)\wedge\mathrm{DMFC}(\mathcal M_\Pi),$$
$$\mathrm{Exec}_{v26}=\mathrm{Exec}_{v25}\cap\mathrm{Fil}_{cslam}\subseteq\mathrm{Exec}_{v25}.$$

```python
# ============================================================
# 数据结构：证书化位姿图
# ============================================================
@dataclass
class CertifiedEdge:
    src: tuple[int, int]              # (robot_id, timestep)
    dst: tuple[int, int]
    z: Tensor                         # 相对位姿 SE(3), [4,4]
    omega: Tensor                     # 信息矩阵 [6,6]
    kind: str                         # 'odom'|'loop_intra'|'loop_inter'|'prior'
    alpha: float = 0.01
    switch: float = 1.0               # switchable constraint ∈ [0,1]

@dataclass
class CertifiedPoseGraph:
    poses: dict[tuple[int, int], Tensor]     # 顶点位姿
    edges: list[CertifiedEdge]
    anchors: dict[int, Tensor]               # 每机器人规范锚点
    
    def fundamental_cycles(self) -> list[list[CertifiedEdge]]:
        """生成树 + 非树边 => E - V + 1 个基本环，避免指数枚举。"""
        tree = self._spanning_forest()
        return [self._path_in_tree(e.dst, e.src) + [e]
                for e in self.edges if e not in tree]
    
    def residual(self, e: CertifiedEdge) -> Tensor:
        pred = se3_inverse(self.poses[e.src]) @ self.poses[e.dst]
        return se3_log(pred @ se3_inverse(e.z))   # [6]


# ============================================================
# IP-448 MRSC — 多机 SLAM 证书
# ============================================================
@dataclass
class MultiRobotSlamCertificate:
    graph: CertifiedPoseGraph
    lambda_obs: float = 1e-3
    eps_pose: float = 0.05            # 5cm 位置不确定度
    delta_cycle: float = 0.02        # 环全息容差
    
    def verify_observability(self) -> bool:
        """规范固定后 λ_min(Λ_i) ≥ λ_obs"""
        for i in self.graph.robots():
            Lambda = self._reduced_hessian(i)      # 稀疏 [6n,6n]
            lam_min = smallest_eigenvalue_pcg(Lambda, k=1)
            if lam_min < self.lambda_obs:
                return False
        return True
    
    def verify_cycle_consistency(self) -> bool:
        """∀γ∈Fund(𝒢): ‖log H_γ‖_{Σ_γ} ≤ δ_cycle"""
        for gamma in self.graph.fundamental_cycles():
            H = torch.eye(4)
            for e in gamma:
                H = H @ e.z
            if torch.linalg.norm(se3_log(H)) > self.delta_cycle:
                return False
        return True
    
    def verify_pose_uncertainty(self) -> bool:
        """tr(Σ_i^pos) ≤ ε_pose²（Schur 补边际协方差）"""
        for (i, t), Sigma in self._marginal_covariances().items():
            if torch.trace(Sigma[:3, :3]) > self.eps_pose ** 2:
                return False
        return True
    
    def verify_all(self) -> bool:
        return (self.verify_observability() and
                self.verify_cycle_consistency() and
                self.verify_pose_uncertainty())
    
    def _reduced_hessian(self, i: int) -> Tensor:
        # 固定锚点，消去 6 维规范零空间
        H = build_information_matrix(self.graph, robot=i)
        return gauge_fix(H, self.graph.anchors[i])
    
    def _marginal_covariances(self) -> dict:
        # 稀疏 Cholesky / Schur 补取对角块
        Sigma_full = sparse_inverse_diag(build_information_matrix(self.graph))
        return {v: Sigma_full[v] for v in self.graph.poses}


# ============================================================
# IP-449 IRLCC — 跨机回环证书
# ============================================================
@dataclass
class LoopCandidate:
    edge: CertifiedEdge
    score: float                      # 描述子相似度
    accepted: bool
    obs_index: int

@dataclass
class InterRobotLoopClosureCertificate:
    candidates: list[LoopCandidate]
    alpha_lc: float = 0.01
    delta_cycle: float = 0.02
    calibrator: 'ConformalCalibrator' = None
    
    def verify_precision(self) -> bool:
        """P(true|accept) ≥ 1-α_lc：用校准集确定接受阈值"""
        if self.calibrator is None:
            return False
        thresh = self.calibrator.threshold_for_precision(1 - self.alpha_lc)
        accepted = [c for c in self.candidates if c.score >= thresh]
        if not accepted:
            return True                    # 空集不引入风险
        # 经验精度下界（Clopper-Pearson）
        hits = sum(c.accepted for c in accepted)
        return clopper_pearson_lower(hits, len(accepted),
                                     self.alpha_lc) >= 1 - self.alpha_lc
    
    def verify_robust_residual(self) -> bool:
        """d_e² = r_eᵀΩ_e r_e ≤ χ²_{dim,1-α}/s_e"""
        for c in self.candidates:
            if not c.accepted:
                continue
            r = self.graph_residual(c.edge)
            d2 = r @ c.edge.omega @ r
            thresh = chi2_ppf(6, 1 - self.alpha_lc) / max(c.edge.switch, 1e-6)
            if d2 > thresh:
                return False
        return True
    
    def verify_commutativity(self, graph: CertifiedPoseGraph) -> bool:
        """加入跨机边后，含该边的基本环全息增量 ≤ δ_cycle"""
        for c in self.candidates:
            if not c.accepted or c.edge.kind != 'loop_inter':
                continue
            g_plus = graph.with_edge(c.edge)
            for gamma in g_plus.fundamental_cycles():
                if c.edge not in gamma:
                    continue
                H = torch.eye(4)
                for e in gamma:
                    H = H @ e.z
                if torch.linalg.norm(se3_log(H)) > self.delta_cycle:
                    return False
        return True
    
    def verify_all(self, graph: CertifiedPoseGraph) -> bool:
        return (self.verify_precision() and
                self.verify_robust_residual() and
                self.verify_commutativity(graph))


# ============================================================
# IP-450 DMFC — 分布式地图融合证书
# ============================================================
@dataclass
class DistributedMapFusionCertificate:
    maps: list['OccupancyGrid']       # 每机器人局部地图
    covariances: list[Tensor]         # 每机器人位姿协方差
    eps_map: float = 0.05
    eps_cov: float = 1e-4
    eps_drift: float = 0.01
    tree_depth: int = 0
    
    def verify_occupancy_consistency(self) -> bool:
        for i in range(len(self.maps)):
            for j in range(i + 1, len(self.maps)):
                if occupancy_disagreement(self.maps[i], self.maps[j]) > self.eps_map:
                    return False
        return True
    
    def verify_fusion_no_double_count(self) -> bool:
        """协方差交集：tr(P_f) ≤ min_i tr(P_i)+ε_cov"""
        P_f = covariance_intersection(self.covariances)
        tr_min = min(torch.trace(P).item() for P in self.covariances)
        return torch.trace(P_f).item() <= tr_min + self.eps_cov
    
    def verify_anchor_gauge(self) -> bool:
        """每个连通分量有锚点，沿生成树累计漂移 ≤ L_tree·ε_drift"""
        for comp in connected_components(self.maps):
            if not any(self.maps[i].has_anchor for i in comp):
                return False
        return self.tree_depth * self.eps_drift <= self.eps_drift * self.tree_depth + 1e-12
    
    def verify_all(self) -> bool:
        return (self.verify_occupancy_consistency() and
                self.verify_fusion_no_double_count() and
                self.verify_anchor_gauge())

# IP-451 CS-UC — 协同 SLAM 统一准入门（v26）
# ============================================================
@dataclass
class CollaborativeSlamUnifiedCertificate:
    src_usc: 'SemanticReconfigCoordUnifiedCertificate'   # v25 七证
    mrsc: MultiRobotSlamCertificate
    irlcc: InterRobotLoopClosureCertificate
    dmfc: DistributedMapFusionCertificate
    
    def admits(self, multi_plan, sensor_data: dict) -> bool:
        # 1. v25 全部七证
        if not self.src_usc.admits(
                multi_plan, sensor_data,
                gt_entities=sensor_data.get('gt_entities'),
                queries=sensor_data.get('queries'),
                retrieved=sensor_data.get('retrieved')):
            return False
        # 2. 多机 SLAM 证书（定位/建图本体）
        if not self.mrsc.verify_all():
            return False
        # 3. 跨机回环证书（存在跨机回环时强制）
        if multi_plan.has_inter_robot_loop:
            if not self.irlcc.verify_all(self.mrsc.graph):
                return False
        # 4. 地图融合证书（发生融合时强制）
        if multi_plan.requires_map_fusion:
            if not self.dmfc.verify_all():
                return False
        return True

        if not v25_ok:
            return False, info25
        # 2. 增量位姿图更新（里程计 + 回环候选）
        self._update_pose_graph(multi_sensor_data)
        # 3. 跨机回环校准与鲁棒加权
        self._update_loop_certificate(multi_sensor_data)
        # 4. 局部地图融合（协方差交集）
        self._update_map_fusion(multi_sensor_data)
        # 5. v26 十证准入
        plan = self._plan_from_consensus(multi_sensor_data)
        admitted = self.cs_uc.admits(plan, multi_sensor_data)
        return admitted, {
            'certified_plan': plan if admitted else None,
            'mrsc': {
                'observability_ok': self.cs_uc.mrsc.verify_observability(),
                'cycle_ok': self.cs_uc.mrsc.verify_cycle_consistency(),
                'pose_uncertainty_ok': self.cs_uc.mrsc.verify_pose_uncertainty()},
            'irlcc': {
                'precision_ok': self.cs_uc.irlcc.verify_precision(),
                'robust_ok': self.cs_uc.irlcc.verify_robust_residual(),

                'no_double_count_ok': self.cs_uc.dmfc.verify_fusion_no_double_count(),
                'anchor_gauge_ok': self.cs_uc.dmfc.verify_anchor_gauge()}}
    
    def _update_pose_graph(self, data: dict):
        for e in data['new_edges']:
            self.cs_uc.mrsc.graph.add_edge(e)
    
    def _update_loop_certificate(self, data: dict):
        self.cs_uc.irlcc.candidates = data['loop_candidates']
        # 仅接受精度证书与稳健残差均通过的边
        for c in self.cs_uc.irlcc.candidates:
            c.accepted = (c.score >= self.cs_uc.irlcc.calibrator
                          .threshold_for_precision(1 - self.cs_uc.irlcc.alpha_lc))
    
    def _update_map_fusion(self, data: dict):
        self.cs_uc.dmfc.maps = data['local_maps']
        self.cs_uc.dmfc.covariances = data['pose_covariances']


# 辅助：SE(3) 基本运算（伪实现）
def se3_log(T: Tensor) -> Tensor:
    """SE(3) -> se(3)，[6] = [平移, 旋转]"""
    R, p = T[:3, :3], T[:3, 3]
    rot = axis_angle_from_matrix(R)          # [3]
    return torch.cat([p, rot])

def se3_inverse(T: Tensor) -> Tensor:
    R, p = T[:3, :3], T[:3, 3]
    T_inv = torch.eye(4)
    T_inv[:3, :3] = R.T
    T_inv[:3, 3] = -R.T @ p
    return T_inv

def covariance_intersection(covs: list[Tensor]) -> Tensor:
    """P_f = (Σ_i ω_i P_i^{-1})^{-1}，ω_i 可均匀或按迹分配"""
    invs = [torch.linalg.inv(P) for P in covs]
    w = 1.0 / len(covs)
    return torch.linalg.inv(sum(w * Pi for Pi in invs))
```

## 4. 正确性论证（增量）

### 引理 13（MRSC 的可观测-一致-不确定度三重保证）
**陈述**：`MRSC.verify_all()=True` ⟺ CPG 同时满足：规范固定后每机可观测性非退化、所有基本环全息在容差内、每机位置边际不确定度有界。

**证明**：
1. Λ_i 是位姿图负对数似然的 Hessian；固定锚点后若 λ_min(Λ_i)<λ_obs，则存在近零特征方向，对应退化几何（长走廊/平面/纯旋转），此时位姿沿该方向可任意漂移而残差几乎不变，故必须拒绝。
2. 基本环是环空间的一组基；任一环的全息可写成基本环全息的复合。由三角不等式与容差 δ_cycle，基本环有界 ⇒ 所有环有界，即证书可在图上粘合为全局截面。
3. Σ_i^pos 由 Λ_i^{-1} 的位置块给出（Schur 补）；tr(Σ_i^pos)≤ε_pose² 直接给出位置均方根误差上界，排除「自洽但不确定度爆炸」的情形。
三者分别排除退化、割裂、过不确定，缺一不可。∎

### 引理 14（IRLCC 的精度-稳健-可粘合三重保证）
**陈述**：`IRLCC.verify_all(graph)=True` ⟺ 跨机回环接受集同时满足：误接受率受控、无大残差边、加入后不破坏任何基本环一致性。

**证明**：
1. 精度证书由离线 conformal 校准给出 P(true|accept)≥1-α_lc，等价于把感知别名导致的假回环率压到 α_lc；Clopper-Pearson 下界保证有限样本下的保守性。
2. 稳健残差把 switchable constraint 的权重 s_e 纳入阈值；大残差边在优化中权重趋零，避免单条坏边拉偏全局。d_e² 服从 χ²_6，阈值给出单边误拒概率上界。
3. 可粘合检查直接验证定义 1201：若加入 e 后某基本环全息超差，则 e 与现有证书不相容，拒绝该边即恢复层论一致性。
三条分别对应「别信错」「别被大残差带偏」「别破坏全局」，共同保证跨机边可安全粘合。∎

### 引理 15（DMFC 的一致性-无重复计数-规范锚定三重保证）
**陈述**：`DMFC.verify_all()=True` ⟺ 融合地图同时满足：局部地图无矛盾、协方差不被重复计数、每连通分量无规范漂移。

**证明**：
1. 占据分歧率 D 直接度量两图在同一栅格上的矛盾比例；D≤ε_map 保证融合后不会出现「同一格既占又空」的自相矛盾区域。
2. 协方差交集 P_f 对相关估计保守；tr(P_f)≤min_i tr(P_i)+ε_cov 排除朴素卡尔曼融合把同一信息计两次而导致的过度自信（这是多机 SLAM 共识崩塌的常见根因）。
3. 无锚点的连通分量存在 6 维规范自由度，任何融合都只确定相对位姿；锚定并在生成树上累计漂移上界，保证局部地图可放到同一全局坐标系。
三者分别排除矛盾、过度自信、规范漂移。∎

### 引理 16（v26 十证单调退化链）
**陈述**：任意单点/组合失效下，`Exec_v26 ⊆ Exec_v25 ⊆ … ⊆ Exec_v18` 恒成立。

**证明**：由定义 1205，Exec_v26 是 Exec_v25 与三个新过滤器的交，故集合包含关系直接成立。三条退化路径：
- **误回环/回环精度失效** → IRLCC 拒证 → 拒绝跨机边，退回 v25 的「各自建图 + 语义协同」，仅失去跨机全局一致，不失去单机安全。
- **融合冲突/重复计数** → DMFC 拒证 → 保持各机局部地图，禁止融合，退回 v25 的分布式语义地图。
- **可观测性退化/不确定度爆炸** → MRSC 拒证 → 停止依赖该机位姿的任务，触发重定位或保守停机，退回 v25 的几何规划。
组合失效取交集，单调性由交运算保持。∎

### 定理（CS-UC v26 的定位-建图-融合-协同完备性）
**陈述**：对任意多机计划 Π，`CS-UC.admits(Π)=True` ⟺ Π 同时满足 v26 的十类条件：v25 的物理/语义/重构/协同七证，加上 MRSC 三重、IRLCC 三重、DMFC 三重（存在性条件触发）。

**证明**：充分性由 `admits` 的连言结构与引理 13–15 直接得到；必要性由任一条件缺失即拒证，分别对应退化、误回环、融合矛盾三类风险之一未被缓解。结合引理 16，执行集沿版本链单调收缩，构成从单机物理安全到多机全局一致地图的完整闭环。∎

## 7. 本轮最大风险（最终确认）

**一句话**：**跨机回环证书的精度承诺依赖离线校准分布，一旦部署环境出现训练集未覆盖的重复结构或对抗性感知别名，IRLCC 可能在单边检查全部通过的情况下把错误回环粘入位姿图，而 MRSC 的环一致性与 DMFC 的融合一致性只能在错误已经传播后才发现；届时 v26 的「事前拦截」会退化为「事后检测」，十证单调链虽保持集合包含，却无法保证错误发生前地图未被污染。**
