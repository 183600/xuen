# 第 1 轮 · 双灵感落地 v18：微事件读心 × 闭链协同（「他者平面」Ω-Plane，四层架构 v6）

> 承接 v17（第 40 轮：热预算治理 × 步数感知规划 × 学习-TO 混合轨迹）。本轮灵感词「面部表情识别 / 协同控制」。先给出两个可能让人失望、但决定整轮方向的核实结论：(1) 官方把「人为干扰」列为 5 类泛化场景之一（F67），但公开示范集是**以机器手为主体的桌面视域、没有人类意图标签，也没有声明人脸在画面内**（F68），且 HRI 实证显示**单靠面部情绪远弱于全身动作**（F70）——所以「读脸做协作」不能当 P0，FER 真正可迁移的是**微事件 spotting 的方法论**。(2) 我对 12 个公开任务的连续状态做了协同含量审计（E1，9,600 帧）：**双臂同时运动占 47.1%，但双夹爪同时闭合只占 7.0%**；且「双闭合」帧里相对末端距离的标准差平均 **31.2mm**（只有 PlugInEthernet 低到 1.4mm，像真闭链）——**闭链共持是少数派，绝大多数「协同」是共享工作空间里的非接触协调与顺序交接**。因此 v18 的主轴不是「加一个读心模块 + 一个双臂闭链控制器」，而是：**把「他者」升格为一等建模对象（Ω 平面：意图信念 × 协调图 × 权限），并让协同控制按协调图模式门控；把 FER 的微事件方法论用于「失败前兆 / 人类意图」的早期 spotting**。主轴从 v17 的「单智能体交付物理学」推进到「**多智能体交互可靠性**」。

- **事实 F67（五类泛化场景，官方任务页 + 2026-07 赛事报道，2026-11-10 复核）**：评分明确覆盖 **位置变化 / 干扰物存在 / 桌面背景差异 / 未见物品 / 人为干扰** 五类场景；赛事愿景写明「跨任务、跨物品、抗干扰」。→ **「人为干扰」是官方场景，不是我们假想的边角料**；但它是否包含可观测的人脸/情绪信号，公开材料未承诺（A52）。

- **事实 F69（微表情 spotting 方法论，2025–2026）**：MELDAE（arXiv 2510.22575）用 **boundary-aware loss** 惩罚 onset/offset 误差，把「定位+识别」统一；prior-guided video-level regression（arXiv 2508.18834）显式建模 **onset–apex–offset** 三相与类别不均衡；OFCT（Springer 2025）用主/次方向光流 + 低通/EMD 去噪 + NMS 做候选段；D-FACE（ICLR 2026）把面部微动离散成 **identity/domain-invariant 的 action token**；AULLM++（arXiv 2603.08387）用 **AU 关系图** 做稀疏、低信噪比的多标签解码。→ 可迁移的不是「表情类别」，而是：**稀疏低幅短时事件的定位、三相边界、不均衡、跨主体/域不变、可解释单元分解、校准阈值**。
- **事实 F70（HRI 意图检测的诚实边界，arXiv 2512.17958）**：融合 2D 骨架姿态 + 面部情绪、跑在 CPU-only 树莓派；跨主体/跨场景/跨相机部署；**emotion-only 显著更差，whole-body motion 才是主导预测信号**；用 MINT-RVAE 合成时序样本缓解类别不均衡。→ **人脸至多是弱辅助，身体/轨迹才是主证据**。
- **事实 F71（双臂协同控制，2025–2026）**：CRISP（arXiv 2611.07268，2026-11-05）在 **G1 人形**上把双臂-物体闭链建成完整约束，用 Lagrange 乘子参数化交互力/内部力，NMPC 在线优化 wrench 与全身协调；ICARA 2026 的双臂位置/力协同用**非对称**策略（一臂视觉位置、一臂力控内部力）；2026 的反应式同步运动控制器用**闭链约束 + 主从切换**处理动态障碍；RAS 2025 的自适应协调阻抗面向对称双臂任务；Frontiers 2025 的「合作双任务空间」用**固定相对位姿 + 绝对位姿 + 任务优先级 + CBF 安全滤波**。→ 可迁移的核心是：**相对雅可比/合作任务空间、内部运动与内部力、同步误差、主从/对称切换、CBF 安全包络**。
- **事实 F72（人机共享工作空间的反应式安全）**：上述 Frontiers 2025 与 2026 同步控制器都把「动态、以人为中心的环境」作为主要场景，安全滤波在参考层实时重塑轨迹。→ 支持「**非接触协调 + 安全滤波**」作为默认模式，而闭链控制只在真共持时启用。

- **实证 E1（本轮协同含量审计，脚本 `exp/r41_coop_audit.py`，结果 `exp/r41_coop_audit_results.json`）**：对 12 个 `G1_Dex1_*` 任务的 800 帧连续段（合计 9,600 帧）计算：**双臂同时运动 47.1%**、**双夹爪同时闭合 7.0%**、单左/单右操作 15.0%/22.3%、双开 55.8%、一臂闲置另一臂活跃 9.4%；**双臂速度相关系数均值仅 0.28**；双闭合帧的相对末端速度 p50=0.089 m/s、p95=0.259 m/s，**相对距离标准差均值 31.2mm**。逐任务看，只有 PlugInEthernet 的相对距离标准差低到 **1.4mm**（像真闭链），FoldTowel 28mm、Unlock 32mm、ZipUp 42mm、PackDoll 52mm。→ **「双臂协同」在本赛道上主要是共享工作空间的并发避让 + 顺序交接，而不是全程刚性闭链**；闭链模式必须有门控，否则会把大多数独立双臂动作错误耦合。
- **实证 E2（本轮复算的纠偏 churn 审计，`exp/v41/active_interaction_audit_results.json`）**：12 任务、21,448 帧；**纠偏核心帧占比 24.4%（左）/23.0%（右）**，dwell 约 10–11%，方向反转约 4.6/3.9 次每 10s，**超额路径比 7.4/15.3 倍**。→ 约 **四分之一**的示范帧是「停顿/折返/重抓」类纠偏；这正是微事件 spotting 与提前消解不确定性的步数收益空间。

## 1. 研究者直觉（先直觉与动机，后形式化）

**直觉 1（FER 的价值不在「读情绪」，在「spotting 微事件」）。** 我第一反应是「桌面操作里没有脸可读，这个灵感是噪声」。但把 FER 拆到方法层后，结论反转：微表情研究的真正困难是**在极低信噪比、强类别不均衡、跨主体/跨域条件下，定位一段幅度很小、持续很短、有 onset–apex–offset 结构的事件**（F69）。这与操作里最值钱的两类信号同构：(a) **失败前兆**——滑动、接触丢失、对齐偏差、抓取将脱，在视觉上出现前往往只有微小的相对运动/光流异常；(b) **人类干扰意图**——人伸手、靠近、准备接管，先于显式动作出现的是身体姿态与轨迹的微变化（F70 明确说 body motion 主导）。所以我把 FER 迁移为 **micro-event spotting 方法论**：三相边界、不均衡感知、域不变动作 token、AU 式可解释单元、校准阈值；而不是训练一个情绪分类器。人脸 AULM 通道只作为**人类在画面内时的弱辅助证据**，绝不作为主触发器。

**直觉 2（协同控制的价值不在「全程闭链」，在「按协调图门控」）。** 我原以为这个赛道的双臂任务应该在合作任务空间里做闭链控制（相对雅可比 + 内部力）。但 E1 把这个想象校正了：公开数据里**双夹爪同时闭合只有 7% 帧**，双臂速度相关只有 0.28，大多数时间是一臂操作、另一臂待命/支撑/转移，或者两臂各拿各的物体。真正的协同需求是三层，而不是一层：(a) **共享工作空间的非接触协调**（两臂同时动 47%，碰撞/抢位/让行是常态）；(b) **顺序交接**（一手放、一手接，需要时序同步而不是刚性约束）；(c) **少量真闭链共持**（PlugInEthernet/ZipUp/FoldTowel/PackDoll 的某些段），这里才需要相对位姿约束与内部运动抑制。因此 IP-52 的正确形态是一个**协调图驱动的模式机**：`free / shared-workspace / handover / co-hold`，而不是一个万能的双臂闭链 MPC。

**直觉 3（「面部表情识别」与「协同控制」的接缝是「他者」）。** 两个词单独看都很远，合起来却精确指向 v17 的同一个盲区：v17 把世界建模成**一个智能体 + 被动环境**。它没有第二个臂的意图模型，也没有人的意图模型；人类干扰在 v17 里只是「触发软重规划的扰动」，双臂只是「14 个关节 + 碰撞约束」。FER 提供**从微线索估计他者意图**的方法，协同控制提供**在耦合与权限下行动**的理论。两者共享一个对象——**他者状态**：他者想做什么（intent belief）、他者与我在物理上如何耦合（coordination graph）、谁在这块空间/时刻说了算（authority α）。所以本轮新增一个横切平面 **Ω-Plane（他者平面）**，坐标是 `(b^H, G, α)`，与 v17 的 Δ-Plane（热/时延/步数）正交：**Δ 管「花多少资源」，Ω 管「和谁、以什么权限、共同做什么」**。

**直觉 4（早期 spotting 直接兑换步骤分，且与 v17 的账本同构）。** 官方按成功率 + 步骤分排序（F59），而 E2 显示约 24% 的示范帧是纠偏 churn。若能在失败**可见之前** 3–5 帧 spot 到前兆并立即改策略（换抓取点/微调/提前松手），就能把「撞墙后重试」变成「撞墙前绕开」，同时省步数、省热、省时延——一条信号同时喂三个账本。反之，若微事件检测假阳性高，就会触发无谓重规划，**反而吃步骤分**。所以 IP-51 的验收标准不是 AUROC，而是**固定误报率下的提前量与净步数收益**（与 IP-49 的 E_score 直接耦合）。

**直觉 5（权限是一个连续变量，不是一个布尔「避让」）。** v17 对人为干扰的处理是「软重规划 + chunk 安全截断」，本质是**全有或全无**：要么机器人继续、要么停/退。协同控制里的人-机共享权限给了更好的形态：α∈[0,1] 连续分配「这块工作空间/这个时刻」的控制权，机器人可以**平滑让行**（局部减速、绕行、把物体递过去）而不是整段冻结。冻结/后退是最吃步骤分的反应；平滑让行既安全又省步，还能避免「不必要离群动作」触碰官方可信度条款（F60 §6）。α 的驱动量正是 IP-51 的意图信念——**读得越早，让行越平滑**。

**直觉 6（修剪仍然是深化：v18 必须为「他者」腾复杂度）。** v17 已经自述「组合爆炸」是最大敌人。本轮再添 Ω 平面与三个 IP，若不剪就会变成五个平面互相打架。我把 v17 中与单一 G1/Dex1 本体、纯形式证书、冗余服务化相关的四项降级：**IP-42 跨本体运动 → P2**（只有一个本体，测试价值近零）、**IP-26 物理增广轴 → P2**（32 任务真实数据 + 扰动已覆盖多样性）、**IP-46 形式鲁棒证书 → P2**（保留解析 CBF 即可，形式化 μ/D-K 过度保守）、**IP-45 的契约/追踪形式化收缩为最小注册表**（不做的能力展示不占 P0）。**读者应把本轮理解为「用四个旧包袱换一个他者平面」，而不是又加一层。**

## 2. 灵感词 → 落地线（新增 + 重构 + 修剪登记）

- 「**面部表情识别**」→ **IP-51 MICRO-EVENT-SPOTTING（P0 新增，升级 IP-24）**：把 FER 的 spotting 方法论迁到操作与协作——(a) **失败前兆 spotting**（滑动/接触丢失/对齐失败，输入=双腕光流 + 本体微动 + 夹爪电流代理）；(b) **人类意图 spotting**（伸手/靠近/接管/撤离，输入=头部相机的人体姿态/轨迹；人脸 AU 仅弱辅助）；(c) **动作单元分解**（approach/align/press/lift/release 的 micro-signature，偏离即异常）；(d) **三相边界 + 不均衡 + 校准阈值 + 跨任务不变表示**；输出 `(onset, apex, offset, class, confidence)` 与**固定误报下的提前量**，直接触发 IP-49 软重规划与 IP-53 权限分配。
- 「**协同控制**」→ **IP-52 COOPERATIVE-COORDINATION（P0 新增，升级 IP-50/39）**：**协调图驱动的四模式机**——`free`（单臂主导）/`shared-workspace`（并发避让 + 任务分配 + 共享工作空间 CBF）/`handover`（时序同步 + 交接窗口）/`co-hold`（相对雅可比 + 闭链约束 + 内部运动抑制 + 主从/对称切换）。默认模式由 E1 的先验决定（co-hold 先验仅约 7%），模式切换由抓取图与相对位姿稳定性门控；内部力不可观测时，用**相对位姿/速度差**作为内部运动代理，不冒充力控。
- 「**两词交叉**」→ **IP-53 SHARED-AUTHORITY（P1 新增，升级 IP-49/38）**：人在回路时的连续权限 α∈[0,1]；由 IP-51 的意图信念驱动，目标函数 = 期望任务得分 − 碰撞风险 − 不必要让行/离群动作惩罚；带平滑率约束与回差，保证「早让、缓让、可恢复」，而不是「冻结/后退」。
- **横切**：**Ω-Plane（他者平面）**——坐标 `(b^H_t, G_t, α_t)`：意图信念、协调图（谁与谁刚性/支撑/竞争/自由）、权限分配；与 Δ-Plane 正交（Δ 管资源，Ω 管交互）。
- 升级：**IP-24**（失败监测 → 前兆 spotting，提前量入 E_score）、**IP-49**（规划吃人类意图信念与协调图；人为干扰从「反应式重规划」升级为「预测式让行/接管」）、**IP-50**（独立 14-DoF TO → 按协调图选择闭链/非闭链参数化）、**IP-39**（中层任务输出协调模式与交接窗口）、**IP-36**（语义图加「他者/人」节点与共享区域）、**IP-43**（流式执行加权限门 α 与让行韵律）、**IP-38**（恢复档加「平滑让行/安全接管」）、**IP-25**（新增权限门与 spotting 的时延预算）、**IP-33**（CBF 同时守共享工作空间与非接触协调）。
- 修剪登记：**IP-42 跨本体运动 → P2**（单 G1/Dex1）；**IP-26 物理增广轴 → P2**（真实 32 任务数据 + 扰动覆盖）；**IP-46 形式鲁棒证书 → P2**（保留解析 CBF/收缩性最小版）；**IP-45 契约/追踪形式化 → 收缩为最小技能注册表**。

## 3. 形式化直觉（严格版见产物区 §3）

**定义 29（他者状态与协调图）**：`Ω_t = (G_t, b_t^H, α_t)`，其中 `G_t=(V,E_t)`，`V={L,R,O,H}`（左臂/右臂/物体/人），`E_t ⊆ V×V` 的标签取自 `{co-hold(刚性), support(支撑), handover(交接), contest(共享区域竞争), free}`。闭链指示 `ρ_t = 1[L 与 R 通过同一物体形成闭合运动链且相对位姿稳定]`。`b_t^H` 是人的意图/目标/接管时机的信念分布；`α_t∈[0,1]` 是机器人在当前工作空间/任务上的权限。

**定义 30（微事件 spotting）**：给定窗口 `X_{t-W:t}`（视频 + 本体 + 夹爪代理），spotting 算子 `S` 输出事件集 `{(τ_on, τ_ap, τ_off, c, s)}`，类别 `c∈{slip, contact_loss, misalign, grasp_fail, approach, reach, takeover, withdraw}`。目标是**在误报率 ≤ ε 下最大化提前量** `L = τ_event − τ_on`，并满足每步时延 ≤ `L_max`。阈值用保形/校准方法设定（分布无关的误报控制）；「真事件 vs 伪事件」用**两路独立证据的一致性**判定（例如腕部光流异常 ∧ 本体相对运动异常），对应 FER 里「genuine vs posed」的判别。

**定义 31（动作单元分解）**：把末端/夹爪轨迹 `x_{0:T}` 分解为运动单元序列 `m_1..m_K`（approach/align/press/lift/transport/release），每个单元有名义 micro-signature `(速度剖面, 夹爪开合, 接触代理)`；spotting 同时检测**单元内偏离**与**单元切换异常**。这把 FER 的 AU 结构映射成可解释、可校准的操作单元，避免端到端黑箱的假阳性。

**定义 32（协同任务空间与内部运动）**：相对位姿 `x_rel = T_L^{-1} T_R`，相对雅可比 `J_rel`；闭链约束 `‖x_rel − x_rel*‖ ≤ ε_ρ`。内部运动代理 `e_int = x_rel − x_rel*`（无真力传感器时的可观测替代）；闭链模式最小化 `∫(e_intᵀ Q e_int + τ̂ᵀ R τ̂)dt`，非闭链模式只保留共享工作空间 CBF 与任务分配。**模式选择由 `ρ_t` 与 `G_t` 门控**，不是全局假设。

**定义 33（共享权限与协同期望得分）**：权限 `α_t` 下的期望效用
`Q(α) = E[score] − λ_c·P(collision|α) − λ_r·P(interference_penalty|α) − λ_s·|Δα|`，
取 `α* = argmax_α Q(α)`，并约束 `|α_t − α_{t−1}| ≤ Δα_max`（平滑让行）。协同期望得分
`E_score_v18(π) = Π_s p_s(s|σ, G) · g(N) − λ P(fail) − κ P(interfere) − c_ρ·1[模式错配]`，
其中 `c_ρ` 惩罚「非共持却用闭链」或「真共持却用独立」——把 E1 的经验先验直接写进规划目标。

## 4. 关键决断

1. **FER 只取方法论**：微事件 spotting（三相、不均衡、域不变、AU 分解、校准阈值），不取「情绪分类」；人脸仅弱辅助。
2. **协同按图门控**：四模式机（free/shared-workspace/handover/co-hold），默认按 E1 先验偏向非接触协调；闭链是少数派特权模式。
3. **Ω 平面横切**：`(b^H, G, α)` 与 Δ 平面正交；所有层都能读/写他者状态，但不改变 Δ 的资源账本口径。
4. **权限连续化**：人为干扰从「停/退」升级为「早让/缓让/可恢复」，直接省步骤分、避开可信度条款。
5. **内部力诚实**：无 F/T 传感器，只用相对位姿/速度差 + τ̂ 代理；不声称力控，只声称内部运动抑制。
6. **四剪一横切**：IP-42/IP-26/IP-46 → P2，IP-45 收缩；用省下的复杂度买 Ω 平面。

## 5. 本轮最大风险（一句话）

**FER 在本赛道可迁移的主要是「微事件 spotting」而非「读情绪」，而协同控制的闭链部分在公开数据里只占约 7% 帧——若把两者当成「读人脸 + 全程双臂闭链」的主设计，就会既读不到可靠的人类意图、又为少数段付出过多复杂度与时延；本轮最大风险是这两个灵感词真正有用的部分都不在它们最显眼的地方，必须用 E73–E78 六重守门按「先微事件 spotting、再非接触协调、最后闭链与权限」的优先序保底，任一失败即退到对应单线最小实现。**

## 3. 重点展开

### 3.1 为什么是这两个词的「隐藏部分」（E1/E2 的经验教训）

E1 给出了一个反直觉但可复现的结论：**这个赛道的「双手协调」并不等于「双手闭链」**。在 12 个公开任务里，双臂同时运动接近一半，但双夹爪同时闭合只有 7%，且多数「双闭合」段的相对末端距离漂移 28–52mm。真正发生的协同是：

1. **共享工作空间并发**（47% 帧）：两臂同时动，主要风险是抢位/碰撞/遮挡，而不是内部力；对应 `shared-workspace` 模式（任务分配 + 共享空间 CBF）。
2. **顺序交接/支撑**：一臂持物、另一臂接近/接住；对应 `handover` 模式（交接窗口 + 时序同步），不是刚性约束。
3. **少量真共持**：PlugInEthernet 这类相对位姿只有 1.4mm 漂移的段；对应 `co-hold` 模式（相对雅可比 + 内部运动抑制），且需要门控而非全程。
4. **单臂主导**（37%）：另一臂应主动进入「支撑/待命/避让」，而不是被规划器强行同步。

E2 则说明：约四分之一的示范帧是纠偏 churn。**如果微事件 spotting 能把一部分「撞墙后重试」前移成「撞墙前改策略」，就直接省步骤分；但假阳性会制造无谓重规划，反而多走步。** 所以本轮把 spotting 的验收从「分类准确率」改成「固定误报下的提前量 + 净步数收益」。

### 3.2 IP-51 MICRO-EVENT-SPOTTING（FER 方法论迁移，完整设计）

**IP 卡片（六字段）**
- **动机**：人为干扰是官方 5 类场景之一（F67）；公开数据无人类意图标签（F68），HRI 实证显示身体动作主导、面部情绪弱（F70）；FER 领域已把「稀疏低幅短时事件的定位」做成成熟方法（F69）。E2 显示 24% 帧是纠偏 churn，提前 spotting 有直接步数收益。
- **与现有方案差异**：v17 的 IP-24 是**失败后/失败时**监测（CTC 进度、VLM 判别、guard 触发），没有「失败前兆」的显式时间定位；FER 方案直接搬情绪分类器则在本赛道无数据、无视野、且被 F70 证伪。本 IP 只迁**方法**（三相边界、不均衡、域不变、AU 分解、校准），不迁**语义**（情绪类别）。
- **技术可行性**：输入全部来自 F60 已有通道（4 相机 + 本体 + 夹爪），无需新传感器；腕部光流与本体相对运动都是毫秒级可算；人体姿态检测只在人类进入头部视野时按 5–10Hz 触发（不阻塞 chunk）；阈值用保形预测校准，误报可控。
- **所需资源**：数据=公开成功示范（无失败标签，用弱信号：夹爪开合/方向反转/dwell 作为微事件代理）+ 仿真扰动注入 + 少量真机失败；算力=光流/姿态小模型 <5ms，旁路异步；接口=仅读观测，不新增控制通道。
- **落地步骤**：① 在公开示范上建立「动作单元 + 微事件」弱标注流水线；② 训练/蒸馏轻量 spotting 头（双腕光流 + 本体 + 夹爪）；③ 保形校准阈值（按任务/场景分桶）；④ 接入 IP-24/IP-49/IP-53 与 Δ-Plane 的预算；⑤ E74 验收（提前量/误报/净步数）。
- **风险**：弱标签不真（把 churn 当失败）→ 用「预测下一帧夹爪/方向反转」的自监督做预训练，再少量真失败微调；假阳性触发无谓重规划 → 误报预算写进 E_score，超过阈值自动降为纯监测；人脸不可见/无数据 → 人脸通道默认关闭，只作条件启用（A52）。

**可迁移的 FER 方法 ↔ 操作微事件映射**

| FER 方法 | 原始作用 | 本赛道映射 |
|---|---|---|
| onset–apex–offset 三相 | 定位微表情起止与峰值 | 定位滑动/接触丢失/人伸手的起止与峰值时刻 |
| AU 分解与关系图 | 可解释的局部肌肉单元 | approach/align/press/lift/release 动作单元 + 偏离检测 |
| 边界感知损失 | 惩罚起止定位误差 | 惩罚前兆的早/晚报警（早报=误报，晚报=无收益） |
| 类别不均衡/合成 | 稀有事件样本少 | churn/失败前兆天然稀疏；用物理一致的轨迹合成补 |
| 跨主体/域不变 token | 换人不失效 | 跨任务/物体/背景不变；不把「某任务专属轨迹」当事件 |
| genuine vs posed 判别 | 真表情 vs 伪装 | 真前兆 vs 噪声：要求两路独立证据一致 |
| 校准阈值/保形 | 控制误报 | 把每步误报率控制写进运行约束 |

**符号与算法**
- 输入窗口 `X_{t-W:t}`：双腕 RGB（低分辨率可）、双臂关节/EE、夹爪、可选头部人体姿态。
- 输出 `{(τ_on, τ_ap, τ_off, c, s)}`，`c` 为事件类，`s` 为校准置信。
- 提前量 `L = τ_onset_true − τ_on`；运行目标：在 `FAR ≤ ε` 与 `latency ≤ L_max` 下最大化 `E[L]`。

```
每步（异步，不阻塞 chunk）：
1. 特征：腕部光流直方图 + EE 相对速度 + 夹爪一阶差分 +（可选）人体关键点
2. 动作单元分割：按名义 micro-signature 把最近轨迹分为 m_k；计算偏离 d_k
3. 事件解码：spotting 头输出候选 (on, ap, off, c, s)
4. 双证据校验：若 c 属失败前兆，要求 (光流异常 ∧ 本体相对运动异常) 同时成立；
   若属人类意图，要求（姿态/轨迹 ∧ 共享区域接近度）同时成立
5. 校准门：s ≥ θ_cal(task, scenario) 才发布；θ_cal 由保形校准给出
6. 发布：失败前兆 → IP-49 软重规划 / IP-52 模式切换；人类意图 → IP-53 权限 α
7. 预算：Δ-Plane 若进入 CONSERVATIVE/CRITICAL，spotting 降频到 2–5Hz 或关闭人脸通道
```

**正确性论证（P51–P53）**
- **P51（提前量-收益单调）**：若前兆事件在 `τ` 可观测且策略在 `τ_on+δ` 前可切换，则切换越早，已浪费步数越少；在事件真实率与动作可逆性不变时，净步数收益随 `L` 单调增（上界为事件发生前的无效步）。
- **P52（误报预算）**：保形校准保证 marginal far ≤ ε；把每次误报的重规划成本 `c_r` 计入 E_score，则最优发布阈值满足 `∂E[score]/∂θ = 0`，避免「为抓一个前兆付出十步」。
- **P53（双证据降假阳）**：若两路证据在前兆下的联合命中率 ≥ 单路，且噪声近似独立，则 `P(FP)` 降低；只在两路同时超阈时发布，把单路背景运动（遮挡、光照、人走过）过滤掉。

### 3.3 IP-52 COOPERATIVE-COORDINATION（协调图门控的双臂协同，完整设计）

**IP 卡片（六字段）**
- **动机**：E1 证明「双臂同时动 47.1%、闭链共持 7.0%」；F71 给出闭链协同的成熟工具（相对雅可比、内部力、同步、主从、CBF），但直接全程套用会错误耦合大多数独立动作；F72 证明人中心动态环境需要参考层安全滤波。
- **与现有方案差异**：v17 的 IP-50 把双臂当 **14 个独立关节 + 自碰撞约束** 做联合 TO，优化器不知道「两臂是否共同持物」；CRISP 等作品做**全程闭链 NMPC**，在真共持任务上强，但本赛道多数帧不是共持。本 IP 首次把**协调图作为控制参数化的选择器**：不同模式用不同的任务空间、约束与权重。
- **技术可行性**：相对雅可比与闭链约束是成熟公式（F71）；共享工作空间 CBF 可复用 IP-33；内部力不可观测时用相对位姿/速度差代理；模式切换用抓取图（IP-36）与相对位姿稳定性，计算量 O(1)。
- **所需资源**：URDF/几何（A17 延续）；抓取图（IP-36）；相对位姿估计（已有双 EE 通道）；算力=模式判定 <1ms，闭链 TO 仅在 co-hold 段触发。
- **落地步骤**：① 从公开数据统计模式先验（E1 已给初值）；② 实现协调图与模式机；③ 在 MuJoCo 里分别验证 shared/handover/co-hold；④ 接入 IP-50 的 TO 权重与 IP-39 的任务输出；⑤ E75 验收。
- **风险**：模式误判（把独立双抓当共持）→ 用相对位姿稳定性 + 抓取图 + 物体身份三重门控，误判时保守回 independent；内部运动代理不真实 → 只用它做「抑制目标」不做「力控承诺」；闭链 TO 超时 → 退回独立伺服（deadline 硬截断）。

**四模式定义**

| 模式 | 触发（协调图） | 控制形态 | 主要风险 | 关键项 |
|---|---|---|---|---|
| `free` | 单臂持物/操作，另一臂空闲 | 单臂 TO/伺服；另一臂进入待命/避让 | 空闲臂挡路 | 待命位姿 + 共享空间 CBF |
| `shared-workspace` | 两臂同时动但无共同物体 | 任务分配 + 相对运动约束 + 共享空间 CBF | 碰撞/抢位/遮挡 | 时空预留 + 优先级 |
| `handover` | 一臂持物、另一臂接近接手 | 时序同步 + 交接窗口 + 抓取点预对齐 | 交接瞬间掉落/碰撞 | 同步误差 + 夹爪时序 |
| `co-hold` | 双夹爪同持一物且相对位姿稳定（`ρ=1`） | 相对雅可比 + 闭链约束 + 内部运动抑制 + 主从/对称 | 内部力/挤压/滑移 | 相对位姿误差 `e_int` |

**符号与算法**
- `x_rel = T_L^{-1} T_R`，`J_rel` 为相对雅可比；`x_rel*` 为期望相对位姿。
- `e_int = x_rel − x_rel*`；闭链模式目标 `min ∫(e_intᵀ Q e_int + τ̂ᵀ R τ̂)dt + w_T·T + w_P·精度`。
- 模式判定：`mode = switch(G_t, ρ_t, stability, deadline, governor_state)`。

```
每段（waypoint 切换或抓取图变化时）：
1. 从 IP-36 读协调图 G_t 与物体身份；估计相对位姿稳定性
2. 若 governor=CRITICAL 或 deadline 紧 → 优先 free/shared（低算力）
3. 按模式选择参数化：
   - free: 单臂任务 + 空闲臂避让位
   - shared: 双任务分配 + CBF: h_shared(x) ≥ 0
   - handover: 交接窗口 [t1,t2] + 同步误差约束 + 夹爪时序
   - co-hold: 闭链约束 ||x_rel - x_rel*|| ≤ ε_ρ + 内部运动抑制
4. 调用 IP-50 的 iLQR：co-hold 用相对雅可比参数化；其它模式用独立/任务空间
5. 输出前过 MuJoCo 门 + IP-33 CBF；失败 → 降级到上一模式
6. 记录 e_int / 同步误差 / 模式切换次数入 Ω 平面
```

**正确性论证（P54–P56）**
- **P54（模式匹配的收益）**：若真实耦合为 `co-hold` 而用独立控制，相对位姿误差 `e_int` 会因两臂跟踪残差不同而累积；闭链参数化把 `e_int` 直接作为受控量，`‖e_int‖` 上界由约束满足度决定，故 `E[e_int]` 降低。
- **P55（非共持不误耦合）**：当 `ρ=0` 时闭链约束不激活，避免把两臂独立动作强行同步造成的额外内部运动/能耗；`c_ρ·1[模式错配]` 在规划层再惩罚一次。
- **P56（安全兜底）**：共享空间 CBF 与 MuJoCo 门并联，任一模式失效仍有下一层；co-hold 模式额外受 `ε_ρ` 与内部运动上限保护，超限即退出闭链。

### 3.4 IP-53 SHARED-AUTHORITY（连续权限，完整设计）

**IP 卡片（六字段）**
- **动机**：人为干扰是官方场景（F67）；v17 的「软重规划 + chunk 截断」是全有或全无，冻结/后退最吃步骤分；F70/F72 表明身体线索可提前预测人意图、参考层安全滤波可在不冻结的前提下让行。
- **与现有方案差异**：现有安全方案多把人类当**动态障碍**（避让/停机），本 IP 把人类当**有意图的协作者**：用 `b^H_t` 估计其目标与接管时机，用连续 α 平滑分配权限；不是「检测到人就停」。
- **技术可行性**：α 是一个标量门，作用于速度上限、工作空间预留、夹爪/力限与任务选择；不需要人类命令通道；所有输入来自已有相机与 IP-51。
- **所需资源**：IP-51 的意图信念；共享区域几何（IP-36）；算力可忽略；接口无新增。
- **落地步骤**：① 定义共享区域与让行动作库（减速/绕行/递物/停手）；② 用 E2/churn 与仿真脚本构造干扰场景；③ 训练/规则化 α 策略；④ 接入 IP-43 的流式韵律（让行要平滑）；⑤ E76 验收。
- **风险**：人类意图不可读 → 退化为「保守共享空间 CBF + 标准避让」，不主动让行；让行过度 → 加不必要让行惩罚与成功率回差；让行动作本身离群 → 平滑率约束 + 官方可信度条款监控。

**权限模型**
- `α=1`：机器人全权（人不在共享区域/无接管意图）。
- `α=0`：机器人完全让出（人明确接管/占位）。
- 效用：`Q(α)=E[score|α] − λ_c P(collision|α) − λ_r P(interfere|α) − λ_s|Δα|`。
- 平滑：`|α_t − α_{t−1}| ≤ Δα_max`；回差：进入让行与退出让行的阈值不同，防抖。
- 让行动作：按 α 连续插值「继续原任务 → 减速 → 绕行 → 递物/停手」，而不是二值停/走。

**正确性论证（P57–P59）**
- **P57（早让省步）**：若 `b^H` 在人类实际占位前 `L` 帧给出高置信，则提前让行避免的「碰撞后重试」步数正比于 `L`；相比碰撞后恢复，净步数不增。
- **P58（平滑不触发可信度风险）**：`|Δα|` 有界 ⇒ 动作无突变离群；让行是任务内连续运动，不是异常模式。
- **P59（不误让）**：不必要让行惩罚 `λ_r` 与成功率回差保证：当 `P(interfere)` 低时 α 保持高位，避免「见人就停」的步数浪费。

### 3.5 修剪登记（v17 → v18 的「用旧包袱换他者平面」）

### 3.7 训练/服务伪代码（v18 增量）

```python
# ===== 离线：微事件弱标注 + spotting 校准（IP-51）=====
def build_spotter(demos):
    units = segment_motion_units(demos)              # approach/align/press/lift/release
    weak = label_micro_events(units)                 # gripper transitions / reversals / dwell
    spotter = train_temporal_spotter(units, weak)    # wrist flow + proprio + gripper
    theta = conformal_calibrate(spotter, demos, target_far=0.05)
    return spotter, theta

# ===== 离线：协调图先验（IP-52，E1 初始化）=====
def build_coordination_prior(audit):
    return {"cohold_prior": audit.both_closed,      # ≈0.07
            "concurrent_prior": audit.both_moving,  # ≈0.47
            "per_task_mode": audit.per_task_modes}

# ===== 运行期：Ω + Δ 双平面主循环 =====
def act_v18(obs, state):
    ledger = update_ledger(...)                       # v17 Δ-Plane
    knobs = governor(ledger)                          # 资源预算
    # 1. 旁路微事件 spotting（不阻塞 chunk）
    events = [] if knobs.spotting_off else spotter(
        obs.wrist_rgb, obs.proprio, state.gripper_hist,
        human_pose=detect_human(obs.head_rgb) if knobs.human_channel else None)
    events = publish_calibrated(events, theta, far_budget=knobs.far_budget)
    # 2. 更新 Ω-Plane
    state.G = update_coordination_graph(state.semantic_map, obs, state.actions_hist)
    state.bH = update_intent_belief(state.bH, events)       # human intent
    state.rho = closed_chain_indicator(state.G, obs, state.rel_pose_hist)
    # 3. 规划（吃他者状态）
    if state.need_plan or any_failure_precursor(events):
        state.plan = step_planner(obs.language, state.semantic_map,
                                  p_s, state.W, state.Mf,
                                  bH=state.bH, G=state.G, budget=knobs)
    # 4. 模式选择 + 协同 TO
    if state.need_refine:
        mode = switch_mode(state.G, state.rho, knobs)
        task = midlevel(state.waypoints, obs, mode=mode, budget=knobs)
        warm = stream_policy_head(state.plan.skill, obs)
        refined = hybrid_to(task, warm, mode=mode, envelopes=state.semantic_map.objects,
                            rel_jac=(mode == "co-hold"), f_track=state.f_track,
                            weights=(w_E, knobs.hot, w_P))
        state.traj = refined if refined is not None else warm
    # 5. 权限仲裁（人机共享）
    if state.bH.confidence > th_on or state.human_in_shared_region:
        state.alpha = authority_policy(state.bH, state.alpha, lam_c, lam_r, lam_s)
    else:
        state.alpha = recover_authority(state.alpha)
    # 6. 流式执行 + CBF
    chunk = state.traj.next_chunk(T_a_eff)
    chunk = scale_by_authority(chunk, state.alpha)          # 平滑让行/减速
    if not guard.cbf_check(chunk, state.G, state.alpha):    # IP-33 共享空间 CBF
        chunk = safe_resample(state, chunk, state.alpha)
    # 7. 失败/恢复
    if failure_monitor(obs) > TAU_FAIL:
        state.Mf.log(...); state.need_plan = True
    return chunk
```

## 6. 清单迭代规则（继承 27–51 + 本轮新增 52–55）

- 继承规则 27–51（通道诚实/映射验证/SLO/fail-safe/灵感-现实校验/单模型合规/步骤分双解释/稠密监督/方法论遗产/元数据重照亮/语言口径分离/摊销/验证器分级/灵感词落地/层级联合规划/跨本体运动/流式韵律/渐进蒸馏/服务化/证书化/组合代数/热预算/期望得分规划/学习-TO/修剪优先）。
- **52（新增）：他者一等公民原则**——任何「人/第二臂/协作者」相关能力必须落在显式的 `(b^H, G, α)` 上，可观测、可校准、可降级；禁止用「读心」式不可验证叙事替代状态估计。
- **53（新增）：微事件方法论迁移原则**——迁移 FER 只迁 spotting 方法论（三相、不均衡、域不变、AU 分解、校准），不迁情绪语义；验收必须是「固定误报下的提前量 + 净步数收益」，不是分类准确率。
- **54（新增）：协同模式门控原则**——闭链/同步/让行都是**受门控的特权模式**，默认按数据先验选择；任何全程假设（全程闭链、全程避让、全程读人）都必须先被数据审计证伪或证实。
- **55（新增）：隐私与可信度双约束原则**——人类相关感知只使用任务必需的最低信息（姿态/轨迹优先于身份/人脸），并遵守 F60 §6 的时延平滑与动作统计规律性；不因「读人」引入额外的离群或隐私暴露。

**本轮最大风险一句话**：FER 真正可迁移的是「微事件 spotting」而非「读情绪」，协同控制真正占多数的是「非接触协调」而非「全程闭链」——若把两个灵感词最显眼的部分当主设计，就会在无人脸数据、无意图标签、仅 7% 共持帧的现实里同时失准；以 E74–E78 五重守门按「先 spotting、再非接触协调、最后闭链与权限」的优先序保底，任一失败即退到对应单线最小实现。

**当前最值得押注**：**IP-51 MICRO-EVENT-SPOTTING**——它是唯一同时被两条实证夹住的点：E2 显示约 24% 帧是纠偏 churn（收益空间真实存在），E1 显示双臂并发 47% 但共持仅 7%（协调需求真实但闭链是少数）；而微事件 spotting 不依赖新传感器、不依赖人脸、可旁路异步、可用保形校准控误报，且它的输出同时喂 IP-49（省步）、IP-52（模式切换）、IP-53（权限）。先用 E74 在公开成功示范 + 仿真扰动上跑通「提前 3 帧、误报 ≤5%、净步数 ↓8%」，再决定是否为闭链与权限付复杂度。
