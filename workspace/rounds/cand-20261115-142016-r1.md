# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「可扩展性」×「演示方案」）

> R69 让系统学会「问」，并自陈最大风险：模态权重不可信时，系统会自信地追问一个幻影，把「诚实的不知道」升级为「被证实的错误」。这暴露了一个更深的问题——**R69 从未回答「我凭什么说它有效，以及这个『有效』对谁成立」**。前六轮都在造更强的闭环，却没有一层负责**让闭环的可信度可被第三方检验、可被复制、可被搬到别的机器上**。
>
> 本轮两个灵感正好补这块：
> - **演示方案**不是「录一段视频」，而是一份**可重放、对抗采样、带统计保证的证据协议**——它是「我已验证」这句话的唯一合法来源；
> - **可扩展性**不是「更多算力」，而是**证书能否在不逐台重验的前提下，跨机器、跨站点、跨生命周期地传递与组合，且错误不随规模放大**。
>
> 核心命题：**把 R69 的标量证书 J_FLUID 升级为「有包络、可迁移、可聚合、可分级」的证书代数；用 anytime-valid 的演示协议产生证据；并显式度量『伪重复』——一万台同一个模型不是一万个样本。** 命名 **SCALE-RAS**（Scalable Certificate Algebra with Live Evidence）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我凭什么向监管者/用户/隔壁工厂证明它有效，而且这个证明经得起搬家和时间**」。

## 0. 直觉与动机

**灵感 1（演示 = 证据协议，不是表演）**
直觉：一段精剪 demo 之于安全性，等同于训练集上的高分之于泛化——都是过拟合。真正该交付的不是「我们演示了」，而是「我们以可复现的方式、在预先声明的分层上、被对抗选择过的输入里，用 anytime-valid 的统计检验证明了风险低于 α」。严谨定义里，演示协议必须自带：预先登记的 strata、审计方独立持有的 hold-out 层、可位级重放的日志哈希。演示是**测量仪器**；仪器不校准，读数就是装饰。

**灵感 2（可扩展性的真瓶颈是证书，不是算力）**
直觉：R69 运行时 2.6ms 已足够快，把 K 从 1 升到 4 也只到 3.4ms。真正卡住规模的，是每一台机器都要重新标定 ECE、FMA 阈值、VoI 成本与风险缩放。可扩展性于是被重新定义为：**证书能否在不逐台重验的前提下迁移与组合**，而不是「同样的代码能不能跑在更多卡上」。

**灵感 3（伪重复：一万台 ≠ 一万个样本）**
直觉上「我们有一万台在跑，全都没出事」听起来是海量证据。但同一权重、同一环境的一万台机器是高度相关的：一台的对齐缺陷会同时出现在所有机器上。设计效应给出有效样本量 n_eff = N/(1+(N−1)ρ)；ρ→1 时 n_eff→1。**规模幻觉**就发生在这里——把相关样本当独立样本，是最常见也最危险的统计错误。本轮把它变成硬约束：联邦聚合只在 ρ ≤ ρ_max 时给信用，否则宣布「不可组合」。

**灵感 4（证书迁移的「无免费校准」公理）**
直觉：你可以把「A 的决策逻辑」搬给 B，但不能把「A 的自信」搬给 B。严谨地看，ECE = ∫|P(correct | conf=u) − u|·w(u)du，其中 w(u) 是置信度分布；一次改变困难/简单状态混合比例的协变量漂移就会改变 w(u)，从而改变 ECE，即便逐点条件校准曲线完全不变。因此**复制 ECE 是非法操作**；迁移只在「决策不变」这一侧成立，校准必须在目标机的极小锚点集上重估。这条公理是防止「证书漂白」的闸门。

**灵感 5（生命周期也是可扩展性）**
直觉：从实验室到车队到十年运维，跨度不是空间而是时间。一次通过 demo 不代表永远通过。本轮把部署建模为**自主度阶梯** D0 离线演示 → D1 影子（只推理不驱动）→ D2 监督 → D3 有界自主 → D4 全自主。晋升只认**在线流**证据（不认 demo，demo 可被优化），降级由 R68 的 COF 与 R69 的 FMA 漂移检测单调触发。这样，可扩展性在时间维上也有了明确的「谁在什么阶段被允许做什么」。

**灵感 6（演示即红队：把 R69 的最大风险变成可测量量）**
直觉：R69 怕的是「模型自信地错」。那就别等它错——在演示时就主动搜。定义校准间隙 CG(x) = |conf_mode(x) − 真实模态熵代理|；构造红队最大化 CG，把 top-CG 状态强制纳入 strata。于是「模型说无歧义但其实多峰」（危险，会跳过交互）与「模型说有歧义但其实单峰」（浪费，会追问幻影）都成为**演示时可被计数**的失败，而不是发布后才发现的事故。演示因此不只是证明，更是主动证伪。

**灵感 7（理论姿态：SCALE 是统计层，不是又一层控制器）**
直觉：每加一层黑箱就多一个要独立信任的东西。所以本轮刻意**不触碰运行时闭环**：R69 的 FMP/AUD/MINT/CIA/FMA 逐点保留，SCALE 只在其外增加「包络、迁移、聚合、分级、复现」五件事。N=1、单点包络、无迁移、无联邦、无红队时，SCALE 逐指令退化为 R69；安全侧永不更弱，只是把「有效性声明」从口号变成可审计的对象。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（SCALE-RAS 总览）** SCALE-RAS = (COE, CTA, LDP, FCA, SCA, RAS-WM‡)。四不变式：
(i) **运行时不变**（继承 R69 定义 293-i）：新层全部在离线/异步侧，逐点额外开销 ≤ 0.05ms（仅证书阶段查表 + 包络成员判定）；
(ii) **无免费校准**（定义 312-iii）：ECE 与安全阈值默认不迁移，必须在目标锚点集上重验；
(iii) **证据独立性**（定义 316-ii）：聚合只在证据正交时给信用，相关失效一律判为不可组合；
(iv) **证书必有包络**：任何有效声明都写成 (J_FLUID, Ω, α, δ)，不允许脱离 Ω 的裸「通过」。

**定义 311（认证运行包络 COE）** R69 的 J_FLUID 升级为三元组 (J_FLUID, Ω, α, δ)：在可测状态集 Ω 上，风险 ≤ α 且置信度 ≥ 1−δ。点证书是 Ω={x_t} 的退化情形。运行时对每个 x_t 做包络成员判定 mem(x_t)∈{in, out, borderline}；out 时刻证书不覆盖，直接落回 R69 最保守分支（λ 单调不降），borderline 触发在线 e-检验加严。

**定义 312（证书迁移代数 CTA）** 迁移映射 T: A→B 合法当且仅当：
(i) **散度上界**：d_f(P_A, P_B) ≤ ε_T，其中 d_f 由共享重放集上的 anytime-valid 两样本 e-过程给出高概率上界（A99：损失有界于 [0,1]）；
(ii) **锚点重验**：在 B 的锚点集 𝒜_B（极小、按 CG 与 OOD 分层抽样）上重估 ECE_B 与阈值，满足 ECE_B ≤ τ_ece；
(iii) **无免费校准**：禁止令 ECE_B := ECE_A 或阈值_B := 阈值_A；若锚点不足（|𝒜_B| < n_anchor），迁移判为未认证。
误差界：risk_B ≤ risk_A + L·d_f(P_A,P_B) + est_err，L 为损失 Lipschitz 常数。

**定义 313（活体演示协议 LDP）** 预先登记分层 S = (歧义等级, OOD 距离, 交互类型, 对抗类型)。每层独立运行 e-过程（定义 314）；episode 全程记录可位级重放的种子与 I/O 哈希。审计方保留一个**销售方不可见、随轮次旋转**的 hold-out 层 𝒮_audit（Goodhart 防线，定义 319）。红队（定义 318）负责把 top-CG 状态注入 strata。

**定义 314（e-过程演示判据）** 对层 s，episode 损失 L_t∈[0,1]（安全/决策准则失败记 1）。原假设 H0: E[L] ≥ α（风险过高）。取可预测赌注 λ_t∈[0, 1/(1−α)]，财富过程 K_t = Π_{i≤t}(1 + λ_i(α − L_i))。H0 下 K 为非负超鞅，Ville 不等式给出 P(∃t: K_t ≥ 1/δ_s) ≤ δ_s。当 K_t ≥ 1/δ_s 时拒绝 H0、该层认证为「风险 < α」。anytime-valid ⇒ 可随时停、无多重比较惩罚；H1 均值 μ<α 下期望样本量 ≤ O(log(1/δ_s)/(α−μ)²)，**与机队规模 N 无关**——这正是统计可扩展性。

**定义 315（覆盖账本）** 演示分布 D_demo 必须附带覆盖账本：每层权重下界 w_s、样本数 n_s、未测层的显式声明（未测层不得隐含「安全」）。账本与 Ω 绑定：Ω 之外的层不计入证书覆盖。

**定义 316（联邦证书聚合 FCA 与有效样本量）** N 台机器共享演示证据。有效样本量 n_eff = N / (1 + (N−1)ρ)，ρ 为单元间同层损失的组内相关系数（设计效应）。聚合规则：
(i) 仅当 n_eff ≥ n_min 且 ρ ≤ ρ_max 时，共享证据才可收紧单机证书；
(ii) 证据须按层正交（定义 310-iii），同源同环境的重复只增加 N 不增加信息；
(iii) ρ 由在线与演示的联合统计估计；ρ 越界 ⇒ 宣布「不可组合」，退回逐台认证，且明确告知「N 台不等价于 n_eff 台」。

**定义 317（分级认证与自主度阶梯 SCA）** 阶段 D0 离线演示 → D1 影子 → D2 监督 → D3 有界自主 → D4 全自主。晋升 D_{j}→D_{j+1} 只接受**在线部署流**上的 e-过程证据（不接受 demo 证据，demo 可被优化）；降级由 COF（R68）或 FMA（R69）漂移信号单调触发，降级步长与漂移幅度成正比，且 λ 单调不降。每阶段有独立 J_SCALE 与更高的 α 要求（阶段越高 α 越严）。

**定义 318（幻影模态红队 RMG 与校准间隙）** 校准间隙 CG(x) = |conf_mode(x) − Ĥ(M|x)|，其中 Ĥ 为真实模态熵的代理（多源证据一致度给出）。红队求解 x* = argmax_x CG(x)（投影梯度 + 约束在 Ω 内），把 top-CG 的 K_rt 个状态强制注入 strata。两类致命样本：**假明确**（模型低熵、真实多峰 ⇒ 跳过交互）与**假歧义**（模型高熵、真实单峰 ⇒ 追问幻影）。二者在演示中被显式计数。

**定义 319（演示污染 / Goodhart 检测 DCD）** 在旋转 hold-out 层 𝒮_audit 上，对「演示分布 vs 部署流」做 anytime-valid 两样本 e-检验。若散度上界 > ε_T，证书立即挂起并进入再演示队列。审计层由审计方选择、演示方不可见，防止「按考试出题训练」。

**定义 320（SCALE 证书 J_SCALE）** J_SCALE = (J_FLUID*, Ω, α, δ, n_eff, ρ, transport_chain, demo_hash, audit_hash, stage)。Valid ⇔ Valid(J_FLUID) 在 Ω 上逐点成立 ∧ 每层 e-过程认证 ∧ n_eff ≥ n_min ∧ ρ ≤ ρ_max ∧ 演示-部署散度 ≤ ε_T ∧ 所有红队层均已认证。任一不满足 ⇒ 证书降级或挂起，运行时按 R69 最保守分支执行。

**定义 321（运行时零回归与异步门）** 运行时策略与 R69 完全一致；SCALE 只增加一次 O(1) 的阶段查表与 mem(x_t) 判定。所有迁移、聚合、e-检验、红队均在离线或异步执行，不进实时环路。复杂度目标：逐点额外 ≤ 0.05ms，总延迟仍 < 2.65ms。

**定义 322（迁移链与不可传递性）** 迁移可组合 A→B→C，但误差按定义 312 累加；链长上限 L_trans，超过则强制直接再演示。原因：TV 距离不满足沿链的紧三角不等式，长链会把证书漂白成「名义有效」。这是对「证书 laundering」的结构性防御。

**定义 323（失效相关性预算）** 为每个共享组件（权重、传感器型号、环境族）维护共模失效相关 ρ_c。机队风险上界不是 Nα，而是 Nα 在独立性下的乐观值与「全部同时失效」在 ρ_c=1 下的悲观值之间；证书必须同时报告 ρ_c 与保守上界，禁止只报乐观值。

**定义 324（演示预算的经济学）** 设演示成本 c_demo、漏检成本 c_miss、残余风险 α。最优演示量 n* = argmin_n [n·c_demo + c_miss·α(n)]，其中 α(n) 由 e-过程样本复杂度给出。规模化的意义是让 n* 与 N 解耦（定义 314），而不是把 n* 乘以 N。

**定义 325（组织可扩展性：可复现签名与第三方重放）** 每次演示输出二进制可重放的种子、输入、模型哈希与证书；任何第三方可在无原始数据访问下重放判定路径（通过哈希承诺 + 差分隐私化的结果日志）。这把「信任某个团队」降级为「信任一段可重放的证据」——组织扩展性的本质。

**定义 326（退化边界）** N=1、Ω={x}、无迁移（L_trans=0）、无联邦（FCA off）、无红队（K_rt=0）、e-过程替换为全量评估时，SCALE-RAS 逐指令等于 R69 FLUID-RAS。故 R69 是本轮在「单机、单点、无部署层」边界上的严格退化。

## 2. 关键算法骨架

```python
# IP-264 COE：证书 = (J_FLUID, Ω, α, δ)；运行时仅做 O(1) 包络判定
class CertifiedEnvelope:
    def __init__(self, j_fluid, omega, alpha, delta):
        self.j, self.omega, self.alpha, self.delta = j_fluid, omega, alpha, delta

    def membership(self, x):                       # O(1)：阈值/凸包/密度门
        if self.omega.contains(x):        return 'in'
        if self.omega.border(x):          return 'borderline'   # 触发在线加严
        return 'out'                                            # 落回 R69 最保守

# IP-265 CTA：证书迁移，含“无免费校准”公理
def transport(cert_A, unit_B, shared_replay, anchor_B, eps_T):
    d_f = twosample_eprocess_upper(shared_replay, delta=1e-3)   # anytime-valid 上界
    if d_f > eps_T:                       return None           # 不可迁移
    if len(anchor_B) < N_ANCHOR:          return None           # 锚点不足 → 未认证
    ece_B = estimate_ece(unit_B, anchor_B)                      # 必须重估！禁止复制
    if ece_B > TAU_ECE:                   return None
    return CertifiedEnvelope(
        j_fluid=cert_A.j, omega=deduce_envelope(cert_A.omega, d_f),
        alpha=cert_A.alpha + L_LIP * d_f, delta=cert_A.delta)   # 风险上界单调涨

# IP-266 LDP：分层 + 赌注 e-过程，可随时停
def demo_protocol(strata, model, budget, alpha, delta):
    per = delta / len(strata)                                   # Bonferroni 跨层
    for s in strata:
        K, t = 1.0, 0
        while K < 1.0 / per and t < budget.max_per_stratum:
            x = s.sample() if not s.adversarial else REDTEAM.next(s)
            L = episode_loss(model, x, alpha)                   # ∈[0,1]
            lam = min(1.0 / (1.0 - alpha), KELLY_STAKE(alpha, K))
            K *= (1.0 + lam * (alpha - L))                      # 超鞅；Ville 保证
            t += 1
        if K < 1.0 / per:  return 'UNVERIFIED', s, t            # 证据不足
    return 'VERIFIED', None, None                               # 全部层认证通过

# IP-267 FCA：有效样本量——一万台不一定是一万个样本
def effective_n(unit_losses_by_stratum):
    rho = intraclass_correlation(unit_losses_by_stratum)        # 设计效应
    N   = unit_losses_by_stratum.n_units
    n_eff = N / (1.0 + (N - 1) * rho)
    composable = (rho <= RHO_MAX) and (n_eff >= N_MIN)
    return n_eff, rho, composable                               # 不可组合则逐台认证

# IP-269 RMG：红队最大化校准间隙，找“假明确/假歧义”
def calibration_gap(model, x):
    return abs(model.mode_conf(x) - true_mode_entropy_proxy(x))

def redteam_states(model, omega, K_rt):
    xs = project_gradient_ascent(calibration_gap, model, omega, steps=200)
    return top_k(xs, K_rt)                                      # 强制注入 strata

# IP-270 DCD：演示污染 / 协变量漂移检测（Goodhart 防线）
def demo_contamination(demo_stream, deploy_stream, eps_T):
    d = twosample_eprocess_upper((demo_stream, deploy_stream), delta=1e-3)
    return d > eps_T                                            # True → 证书挂起

# IP-274 SCALE 部署/生命周期流水线（运行时继承 R69，不改动逐点策略）
def SCALE_round(M, obs):
    x_t = M.encode_state(obs)
    stage = M.j_scale.stage                                     # 查表 O(1)
    mem   = M.coe.membership(x_t)                               # 包络判定 O(1)
    if mem == 'out':
        return M.fluid_ras_round(obs, force_conservative=True)  # 证书不覆盖 → R69 最保守
    if mem == 'borderline':
        M.online_eprocess.tighten(alpha_stage=stage)            # 在线加严
    k, lam, mode, U = M.fluid_ras_round(obs)                    # 逐点等价 R69
    if M.sca.should_demote(M.cof, M.fma, stage):                # 漂移 → 单调降级
        M.sca.demote(stage, lam=max(lam, 0.8))
    M.ledger.append(sample_hash=(x_t, k, lam, mem))             # 异步入证据账本
    return k, lam, mode, U
```

## 3. 推导

**引理 19（有效样本量）** 设 N 台单元同层损失 Y_i 具有共同均值 μ、方差 σ²、两两相关 ρ（可交换假设）。则样本均值的方差 Var(Ȳ) = σ²/N · (1+(N−1)ρ)，等价样本量 n_eff = N/(1+(N−1)ρ)。系：ρ→1 时 n_eff→1，机队规模对推断的边际收益趋于零；ρ→0 时 n_eff→N。这是「一万台全过」可能统计上等于「一台过了一次」的严格来源。

**引理 20（证书迁移的误差界与校准不可搬运）** 损失有界于 [0,1]，则 |risk_A − risk_B| ≤ d_TV(P_A,P_B) + est_err。但 ECE = ∫|P(correct|conf=u) − u| w(u)du 依赖置信度分布 w(u)；即使条件校准曲线逐点不变，只要漂移改变 w(u)，ECE 就改变。故「ECE_B := ECE_A」在一般漂移下非法；唯一的合法迁移是「决策逻辑 + 散度上界」，校准必须在锚点集上重估（定义 312-iii）。系：证书迁移的代价是「必须付出锚点样本」，不存在零成本搬家。

**引理 21（e-过程的 anytime-valid 与规模无关性）** 对每层，赌注财富 K_t 在 H0 下为非负超鞅，Ville 不等式给出 P(∃t: K_t ≥ 1/δ) ≤ δ，故任意停时都合法、无需多重比较校正。H1（均值 μ<α）下期望样本量 ≤ O(log(1/δ)/(α−μ)²)，**只依赖 (α, δ, μ)，不依赖 N**。系：演示成本可随部署规模摊薄到接近零——这才是可扩展性的统计形式。

**引理 22（开销下界与达界）** 任意单点证书查询必读取 Ω 的有限描述与当前 x_t，故下界 Ω(1)；定义 311 的成员判定达到 O(1)（阈值/凸包/密度门）。故「证书有形」与「运行时零回归」不矛盾：包络把绝大部分复杂度搬到离线，在线只留一次比较。

**定理 18（SCALE 严格包含 R69 且运行时不变）** 在定义 326 的退化参数下，SCALE 与 R69 逐指令相同；一般情形下运行时策略不变、仅置换成保守分支的概率上升，故安全侧不弱于 R69。效率侧：在 n_eff 达标且散度 ≤ ε_T 时，迁移与联邦把演示成本从 O(N·n*) 降到 O(n*)，获得「部署 resolution bonus」，而 α 不降低。

**定理 19（共模失效下的机队风险上界）** 设单元独立失效概率 α、共模相关 ρ_c。机队失效概率位于 [1−(1−α)^N, α] 的 ρ_c 插值带内（ρ_c=0 取左端，ρ_c=1 取右端）。故任何只报告 1−(1−α)^N 或只报告 α 的证书都隐瞒了另一半；J_SCALE 必须同时给出 ρ_c 与保守上界（定义 320、323）。系：机队级安全声明不能由单机证书通过简单乘法得到。

**定理 20（Goodhart 不可证与演示污染的必然失效）** 若演示分布可被演示方针对审计准则自适应优化（即 D_demo 可在审计反馈下迭代），则不存在仅凭 D_demo 就能对任意部署 P_deploy 成立的证书——这是 no-free-lunch 在「证明」上的版本。定义 319 的旋转不可见审计层使「针对审计优化」退化为「对未知目标优化」，从而把演示污染转化为可检测的散度超限；一旦超限即挂起。**演示不能被证明「没被污染」，只能被设计成「污染会被测出」。**

## 6. 本轮最大风险

**一句话**：SCALE-RAS 的全部部署收益押在「演示是真的、迁移是实的、样本是独立的」这三件事上——**而这三件事恰恰是规模化最容易造假的地方：演示被优化成「通过」（Goodhart 剧场），迁移把一个没挣到的证书沿链扩散到整个机队（证书漂白），伪重复让「一万台全过」在统计上等价于「一台过了一次」**；于是系统不是变安全，而是把「没有证据」包装成「已被证明」，并让这个错误以机队速度传播——**证错，比不证更危险**。

**次级风险与缓解**：
1. **演示污染 / Goodhart** → 旋转不可见审计层 + 两样本 e-检验（定义 319、定理 20），污染只能被设计成「会被测出」；
2. **证书漂白 / 长链传播** → 无免费校准公理（定义 312-iii）+ 锚点重验 + 迁移链上限 L_trans（定义 322）；
3. **伪重复与共模失效** → n_eff 与 ρ_c 硬约束（定义 316、323、定理 19），ρ 越界即拒绝聚合；
4. **红队覆盖不足** → RMG 强制注入 top-CG 状态（定义 318），未认证层不得隐含安全；
5. **运行时被证书查询击穿** → 包络判定 O(1)、迁移/检验全离线（定义 321、引理 22），P99 < 2.65ms。

class CertifiedEnvelope:

        if self.omega.border(x):    return 'borderline'   # 在线加严
        return 'out'                                     # 落回 R69 最保守

def transport(cert_A, unit_B, shared_replay, anchor_B, eps_T):
    d_f = twosample_eprocess_upper(shared_replay, delta=1e-3)
    if d_f > eps_T or len(anchor_B) < N_ANCHOR: return None
    ece_B = estimate_ece(unit_B, anchor_B)                # 必须重估，禁止复制
    if ece_B > TAU_ECE: return None
    return CertifiedEnvelope(cert_A.j, deduce_envelope(cert_A.omega, d_f),
                             cert_A.alpha + L_LIP * d_f, cert_A.delta)

# IP-266 LDP：分层赌注 e-过程，anytime-valid
def demo_protocol(strata, model, budget, alpha, delta):
    per = delta / len(strata)
    for s in strata:
        K, t = 1.0, 0
        while K < 1.0 / per and t < budget.max_per_stratum:
            x = REDTEAM.next(s) if s.adversarial else s.sample()
            L = episode_loss(model, x, alpha)             # ∈[0,1]
            lam = min(1.0/(1.0-alpha), KELLY_STAKE(alpha, K))
            K *= (1.0 + lam * (alpha - L))                # 非负超鞅
            t += 1
        if K < 1.0/per: return 'UNVERIFIED', s            # 证据不足，不得隐含安全
    return 'VERIFIED', None

# IP-267 FCA：伪重复——一万台不一定是一万个样本
def effective_n(unit_losses_by_stratum):
    rho = intraclass_correlation(unit_losses_by_stratum)
    N   = unit_losses_by_stratum.n_units
    n_eff = N / (1.0 + (N - 1) * rho)
    return n_eff, rho, (rho <= RHO_MAX and n_eff >= N_MIN)

def calibration_gap(model, x):

## 4. 推导

**引理 19（有效样本量）** 可交换单元、两两相关 ρ 下，Var(Ȳ)=σ²/N·(1+(N−1)ρ)，故 n_eff=N/(1+(N−1)ρ)。系：ρ→1 时 n_eff→1，机队规模对推断的边际收益趋于零——「一万台全过」可能等于「一台过了一次」。

**引理 20（迁移误差界与校准不可搬运）** 损失 ∈[0,1] 时 |risk_A−risk_B| ≤ d_TV(P_A,P_B)+est_err；但 ECE=∫|P(correct|conf=u)−u|w(u)du 依赖置信度分布 w(u)，漂移改变 w(u) 即改变 ECE，故 `ECE_B:=ECE_A` 一般非法，必须在锚点集重估。系：证书搬家必须付出锚点样本，不存在零成本迁移。

**引理 21（anytime-valid 与规模无关性）** 赌注财富 K_t 在 H0 下为非负超鞅，Ville 给出 P(∃t:K_t≥1/δ)≤δ，任意停时合法、无需多重比较校正；H1 下期望样本量 ≤ O(log(1/δ)/(α−μ)²)，只依赖 (α,δ,μ)，不依赖 N。系：演示成本可随规模摊薄——可扩展性的统计形式。

**引理 22（包络查询下界与达界）** 单点证书查询必读 Ω 的有限描述与 x_t，下界 Ω(1)；定义 311 达 O(1)，故「证书有形」与「运行时零回归」不矛盾。

**定理 18（SCALE 严格包含 R69 且运行时不变）** 定义 326 退化参数下逐指令相同；一般情形运行时策略不变、仅保守分支概率上升，安全不弱于 R69；n_eff 达标且散度 ≤ ε_T 时演示成本从 O(N·n*) 降到 O(n*)，α 不降。

**定理 19（共模失效下机队风险上界）** 机队失效概率位于 [1−(1−α)^N, α] 的 ρ_c 插值带内，故证书必须同报 ρ_c 与保守上界；单机证书不能靠乘法得到机队声明。

**定理 20（Goodhart 不可证与演示污染必然失效）** 若 D_demo 可针对审计准则自适应优化，则不存在仅凭 D_demo 对任意 P_deploy 成立的证书；定义 319 的旋转不可见审计层把「针对审计优化」退化为「对未知目标优化」，使污染转为可检测的散度超限。**演示不能被证明「没被污染」，只能被设计成「污染会被测出」。**

## 7. 本轮最大风险

**一句话**：SCALE-RAS 的全部部署收益押在「演示是真的、迁移是实的、样本是独立的」上——**而这三件事恰是规模化最易造假处：演示被优化成「通过」（Goodhart 剧场）、迁移把没挣到的证书沿链扩散到机队（证书漂白）、伪重复让「一万台全过」统计上等价于「一台过了一次」**；于是系统不是变安全，而是把「没有证据」包装成「已被证明」，并让错误以机队速度传播——**证错，比不证更危险**。

**次级风险与缓解**：演示污染/Goodhart（旋转不可见审计层 + 两样本 e-检验，定义 319、定理 20）；证书漂白/长链（无免费校准 + 锚点重验 + L_trans，定义 312/322）；伪重复与共模（n_eff、ρ_c 硬约束，定义 316/323、定理 19）；红队覆盖不足（RMG 强制注入 top-CG，定义 318）；运行时被证书查询击穿（包络 O(1)、迁移/检验全离线，定义 321、引理 22）。
