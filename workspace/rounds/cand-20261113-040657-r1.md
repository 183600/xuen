# 第 3 轮迭代（灵感循环 v3：「低成本方案」×「强化学习」）—— 把"贵的仿真"换成"免费的演示"，让 RL 只发生在选项层

> 本轮是新种子的第 1 轮（全局第 3 轮），承接 v2 的 UIP-01′~15。**保留**与规则强绑定的"验证-重做 / 可变块长 / 多端口隔离 / 单模型"骨架，但把 v2 最贵的两个部件——32 个 Gazebo 场景（UIP-11 GSO）与脚本化干扰数据工厂（UIP-12 DRF）——**降级为可选高保真层**。新两词给出的重构方向是：奖励不必来自仿真，恢复数据不必来自采集；**32k 条按时间排序的成功演示本身就是免费的进度标签与可逆扰动源**。RL 也不该在像素/关节上做（评测端每 episode reset、端口隔离、延迟被审计，根本不给在线试错），而应做在只有 5~7 个离散动作的**选项元层**。

## 0. 直觉先行（人话）

1. **我们缺的不是数据量，是"每步值多少分"**。公开数据没有 reward，但每条演示都是从起点走到成功的轨迹；**"还剩多少时间/距离"就是天然稠密奖励**。把它学成一个标量 φ，φ 上升=得分，φ 下降=被干扰或走错——正好对上 v2 从 `human_*` 读出的"反向撤回"。
2. **RL 的正确粒度不是动作，是元决策**。在 7+7 维关节上做在线 RL：贵、慢、且评测期不允许探索。把动作空间压成 `{继续, 再观测, 重做当前, 重做上一步, 重抓}`，状态压成 ~30 维进度特征，用离散 CQL/IQL 离线训练，一张卡几小时就能收敛。
3. **恢复数据可以"捡"和"倒放"**。32k 条遥操作里天然有人类"退回去重来"的片段（自纠正）；开/合、插/拔、叠/取这些**可逆技能**还能把正向演示倒放成"撤回"。低成本数据工厂 = **挖掘 SCR + 反向增强 RDA**，不需要 Gazebo 机械手。
4. **最贵的真机时段不该用来试错，而该用来校准**。把有限评测 slot 花在"验证 φ 与真实步骤分的单调映射"上，而不是盲目刷任务。

## 3. 两个灵感词 → 两条硬约束

### 3.1 低成本（直觉 → 定义）

**直觉**：低成本不是"少干活"，而是"把一次性工程换成可复用的离线计算"。

**定义**：设成本 `C = c_s·N_sim + c_e·E_days + c_g·GPU_h + c_r·Robot_slots + c_d·|D_new|`。v2 的 `N_sim=32`、`|D_new|` 大；v3 目标 `N_sim≈0`、`|D_new|=0`、`Robot_slots` 只做校准，把成本搬到 `GPU_h`（可并行、可复现）。

**可检验预测**：在相同榜单分数下，v3 的 `E_days` 与 `Robot_slots` 应显著低于 v2；若 φ 的代理相关性不足，则省下的成本会以"错误重做"的形式在真机上还回来（见 §8 风险）。

### 3.2 强化学习（直觉 → 定义）

**直觉**：RL 的价值是"在错误后学会恢复"，不是"从零学抓取"。

**定义**：可选三层 RL——
- **L1 动作层**（像素/关节 PPO）：样本效率最低、需在线环境、评测不允许 → **否决**。
- **L2 技能层**（每技能一个策略）：仍高维、仍需大量交互 → **仅用模仿/离线**。
- **L3 选项/元决策层**（离散 5~7 动作）：状态低维、可离线、可用 100 分结构做奖励 → **本轮采用**。

**关键约束**（从 README 推出）：`reset()` 每 episode 一次 + N 端口隔离 + 延迟/动作规律性审计 ⇒ **评测期无跨 episode 在线学习、不能长搜索**；因此 RL 必须是 **离线 + 保守 + 低维**。这也是本轮与"堆一个在线 RL 大训练"路线的根本分叉。

## 4. 核心定义 A：进度势能 PPR（UIP-16）

**直觉**：把"完成任务的过程"压成 0→1 的进度；进度增量就是奖励，进度回退就是撤回。

**定义**：对任务语言 `l` 与观测 `o`，学 `φ_θ(o,l)∈[0,1]`；离线用数据集含的特权状态 `s_priv` 训练教师 `φ_T`，再蒸馏到接口可观测 `o_api`（4 图 + ee + gripper + 关节）。

损失（四项）：

```
L = L_rank + λ1·L_anchor + λ2·L_ground + λ3·L_smooth
L_rank   = Σ_{t<t'} max(0, φ(o_t) − φ(o_{t'}) + m)          # 同 episode 时间序单调
L_anchor = φ(o_1)^2 + (φ(o_T) − 1)^2                        # 起点 0、终点 1
L_ground = Σ max(0, φ(o_t, l_wrong) − 0.2)                  # 错语言应低（抗看错任务）
L_smooth = (Δφ_t − Δφ̂_t)^2                                  # 与时间步插值一致
```

**步骤伪标签对齐 SPA（低成本关键）**：公开数据无 step 标签，但每个任务的计分步数 `K∈{2,3,4,5}` 是已知的。对每条演示的 φ 曲线做**单调分段 DP**，强制切 K 段，得到伪步骤边界；从而把 100 分结构变成**每段一个奖励权重**。这把"只有终点成功"升级为"接近步骤分"的稠密奖励。

**回归检测**：`Δφ_t < −δ` 连续 `m` 次 ⇒ `regressed`；`δ,m` 由留出集 FPR 标定。

**奖励**：`r_t = w(t)·max(0,Δφ_t) − w_r·max(0,−Δφ_t) − λ_lat·Δt`，其中 `w(t)` 由 SPA 段对应的计分点给出（后步分值 ≥ 前步 ⇒ 权重随 φ 递增）。

**可检验假设 H-φ**：φ 与"真实步骤分"在留出集上单调相关（Spearman ρ>0.7）；不成立则整个 PPR 奖励不可用。

## 5. 核心定义 B：零成本恢复数据（UIP-17 SCR + UIP-18 RDA）

**直觉**：人类演示里本来就有"做错→退回→重来"；可逆动作还能倒放。

**定义 1（自纠正片段 / SCR）**：沿演示算 φ。若存在 `[a,b]` 使 `φ_a=h`，φ 在中间跌到 `≤h−δ`，随后回到 `≥h`，且伴随 gripper 开合或 ee 方向反转，则把 `(o_a, a_{a:b}, o_b)` 标为一条"撤回→恢复"样本。它给的是**真实恢复演示**，不是仿真。

**定义 2（可逆配对 / RDA）**：对技能对 `(skill, undo)`，在数据中找片段 `i,j`，使 `state_sig(end_i) ≈ state_sig(start_j)` 且 `state_sig(end_j) ≈ state_sig(start_i)`，其中 `state_sig = [ee_pose, gripper, 视觉嵌入]`；若循环误差 `<ε` 且运动准静态（速度低、无抛掷），则把 `j` 的帧/动作倒序拼到 `i` 后，合成"撤回"。它给的是**受控撤回样本**。

**产出**：两者都不需要新采集、不需要 Gazebo。SCR 覆盖真实纠错分布，RDA 补足"人为撤回"的时序与幅度多样性。

**可检验假设 H-data**：32k 演示中至少 3–5% 含可挖自纠正；可逆任务对至少覆盖 8–10 个任务。若产出 < 数百条，则恢复策略退化为规则重做。

## 6. 核心定义 C：选项级离线元 RL（UIP-19 OMR）

**直觉**：把"要不要重做/何时再观测"交给一个小 RL 策略，而不是拍脑袋阈值。

**定义 MDP**：`M=(Z,A,P,r,γ)`
- `z_t = [φ_t, Δφ_{t−k:t}, ee_pose, gripper, |v_ee|, 估计步骤索引, 验证置信度, 剩余延迟预算, 当前块长 k]`
- `A = {CONTINUE, REOBSERVE(k'), REDO_CURRENT, REDO_PREV, REGRASP, SAFE_ABORT}`
- `r_t = 步骤分增量（由 Δφ 与 SPA 映射） − λ_lat·latency − λ_retry·1[retry] − λ_bad·1[不可逆操作]`
- 数据：名义演示（CONTINUE）+ SCR（REDO 的真实后继）+ RDA（regression 转移）+ 可选潜空间模型 rollout
- 算法：**离散 CQL（保守 Q 学习）+ 行为克隆正则**；离线数据覆盖不全，保守项防 OOD 动作被高估。

**为什么便宜**：`|Z|~30`、`|A|~6`、数据百万级、MLP/小 Transformer，CPU/单卡小时级；不需要仿真器，也不需要在线交互。

**运行时**：仍由 UIP-01′ 的状态机执行；OMR 只替换"规则阈值"，UIP-13 选 `k`、UIP-15 设延迟/重做预算。

## 7. v3 清单变化（详见产物区）

- **保留/升级**：UIP-01′（运行时状态机）、02′（计分步调度）、05（语言条件）、08′（多端口）、09′（恢复）、13（ACS）、14（MSGR）、15（CSG）。
- **降级为可选**：UIP-11 GSO、UIP-12 DRF（只在 3–5 个代表任务做高保真 sanity check）。
- **新增**：UIP-16 PPR、UIP-17 SCR、UIP-18 RDA、UIP-19 OMR、UIP-20 PVS（进度价值测试时搜索，可选、受延迟预算约束）。
- **新旗舰：UIP-16+17+18+19 的"离线进度-RL 闭环"**；UIP-01′/13/15 是运行时外壳。

## 8. 本轮最大风险

**一句话**：φ 是从"成功且大体单调"的演示里自监督出来的代理，在未见物品/非单调接触任务上"φ 回退"未必等于"步骤分丢失"，于是 OMR 可能学会**刷进度而不是真恢复**——这是用免费奖励替代真实计分必然带来的"奖励幻觉"，必须用集成不确定度、跨任务负样本与少量真机锚点压制。

## 1. 旗舰总览：离线"进度-RL"闭环

```
32k 公开演示 D
   │
   ├─(A) 特征缓存 + 特权教师 φ_T ──蒸馏──> 接口学生 φ_S        [UIP-16 PPR]
   │                                          │
   │                                          ├─ 奖励 r=Δφ−成本
   │                                          └─ 回退检测 Δφ<−δ
   │
   ├─(B) φ 曲线 → 自纠正片段 (SCR) ───────────┐                [UIP-17]
   │                                          ├─> 离线转移集 T
   └─(C) 可逆配对 → 倒放/拼接 (RDA) ──────────┘                [UIP-18]
                                              │
                                    离线离散 CQL                  [UIP-19 OMR]
                                              │
运行时: VLA 基座 + UIP-01′ 状态机 + UIP-13 选 k + UIP-15 护栏
        └─ 每 k 步: φ → z → OMR 元动作 → 继续/重做/重抓/再观测
```

**关键闭环**：φ 既提供奖励（训练 OMR），又提供回退检测（运行时）；SCR/RDA 既造恢复数据（训练 OMR），又提供回归样本来校准 φ。三者共用同一表征，成本主要是一次离线特征缓存。

## 2. UIP-16 · PPR（Progress-Potential Reward）

### 2.1 训练与蒸馏

- **教师**：输入离线特权状态 `s_priv`（ee pose in torso/d435、torso、waist、`recomputed_ee_valid` 等）+ 语言，输出 φ_T。
- **学生**：输入接口可观测 `o_api`（4 图 + 左右 ee pose + gripper + 左右臂 + lower_body）+ 语言，输出 φ_S。
- **蒸馏**：`L_distill = MSE(φ_S, sg(φ_T))`；推理期只用学生。

```python
def train_phi(demos, phi_T, phi_S, lang_emb):
    for (o_api, s_priv, l, t, T, l_wrong) in loader:
        pT = phi_T(s_priv, lang_emb(l))
        pS = phi_S(o_api, lang_emb(l))
        pS_wrong = phi_S(o_api, lang_emb(l_wrong))
        # 同一 episode 内 t < t'
        L_rank   = relu(pS_t - pS_tp + m).mean()
        L_anchor = pS_start.pow(2).mean() + (pS_end - 1).pow(2).mean()
        L_ground = relu(pS_wrong - 0.2).mean()
        L_smooth = (pS[1:] - pS[:-1] - 1.0/(T - t)).pow(2).mean()
        L = L_rank + 1.0*L_anchor + 0.5*L_ground + 0.1*L_smooth \
            + 1.0*F.mse_loss(pS, pT.detach())
        L.backward(); opt.step()
```

### 2.2 步骤伪标签对齐 SPA

设一条演示的 φ 序列为 `φ_0..φ_T`，已知该任务计分步数 `K`。求 K 段单调切分 `0=b_0<...<b_K=T`：

```
minimize  Σ_k Var(φ[b_{k-1}:b_k]) − η·(μ_k − μ_{k-1})
s.t.      b_k − b_{k-1} ≥ 1,  μ_k ≥ μ_{k-1}
```

用 O(K·T²) DP 求解（T~200，K≤5，单条毫秒级）。段 k 的奖励权重取该任务第 k 个计分点分值 `v_k/100`（v2 §2 全表）。

- **作用 1**：把"终点成功"变成"步骤级稠密奖励"。
- **作用 2**：给 φ 提供步骤锚点，减少"整段线性"假设带来的偏差。
- **风险**：若某步在演示中与相邻步同时完成，硬切分会错位 → 用软分配/多解集成，并在验证集上看步骤分类一致性。

### 2.3 回归检测与奖励

```python
def regressed(phi_hist, delta=0.08, m=2):
    d = [phi_hist[i+1] - phi_hist[i] for i in range(len(phi_hist)-1)]
    return len(d) >= m and all(x < -delta for x in d[-m:])

def reward(phi_prev, phi_now, dt, w_step, wr=0.5, lam=0.01):
    d = phi_now - phi_prev
    return w_step * max(0.0, d) - wr * max(0.0, -d) - lam * dt
```

`w_step` 来自 SPA 段分值；`wr` 惩罚回退（人为干扰/走错）；`lam` 惩罚时间（延迟/可信度）。

## 3. UIP-17 · SCR（Self-Correction Retrieval）

### 3.1 挖掘算法

```python
def mine_corrections(demo, phi, delta=0.06, min_len=8):
    out = []
    a = 0
    while a < len(phi) - min_len:
        h = phi[a]
        # 找一次显著回退
        b = next((i for i in range(a+1, len(phi)) if phi[i] <= h - delta), None)
        if b is None: break
        # 找回退后的恢复（回到 >= h）
        c = next((i for i in range(b+1, len(phi)) if phi[i] >= h), None)
        if c is not None and (c - a) >= min_len:
            if has_gripper_cycle(demo, a, c) or has_ee_reversal(demo, a, c):
                out.append((a, c, "undo_recover"))
            a = c
        else:
            a = b + 1
    return out
```

- **过滤**：只保留准静态、无外部抛掷、`recomputed_ee_valid==1` 的片段；剔除"相机遮挡/检测抖动"造成的伪回退（要求视觉嵌入也回退，而非只有 φ 抖动）。
- **标签**：`(o_a, a_{a:c}, o_c, l)`，动作段即"撤回+恢复"的联合轨迹；训练时可切成"撤回"和"恢复"两段。
- **产出估计（待验证）**：若 3–5% 的 episode 含 1–3 个片段，则 32k×0.03≈**960 条起**，足以训练一个低维 OMR/恢复头。

### 3.2 为什么比 Gazebo 便宜

- 不建场景、不写机械手脚本、不做渲染；
- 数据分布来自真实遥操作，**天然包含真机的接触/摩擦/遮挡**；
- 缺点：干扰形态受限于人类自然纠错，覆盖不到"规则里那种故意使坏"的极端时机 → 由 RDA 补。

### 4.1 可逆任务对（初筛）

| 正向 | 反向来源 | 备注 |
|---|---|---|
| T26 PlugInEthernet 插网线 | T05 DisconnectEthernet 拔网线 | 天然成对，视觉相反 |
| T14 PourOutMedicine 拧开 | 同任务"拧回"段 / 倒放 | 螺纹准静态可逆 |
| T16 FoldTowel 折叠 | 倒放"展开"段 | 布料可逆性较弱，需筛选 |
| T17 OrganizeStationery 合上 | 倒放"打开"段 | 铰链可逆 |
| T19 ZipUp 拉上拉链 | 倒放"拉开"段 | 准静态可逆 |
| T27 StackBowls 叠碗 | 倒放"取碗"段 | 需检查抓取时序 |
| T24 ConveyorSorting 放上 | 倒放"放回起点"段 | 传送带有方向性，慎用 |
| T31 OrganizePencilCase 拉拉链 | 倒放"打开"段 | 与 T17/T19 同族 |

### 4.2 状态签名与循环一致性

```
sig(o) = [ee_pose(6), gripper(2), vis_emb(o)]        # vis_emb 用同一学生编码器
cycle_err(i,j) = ||sig(end_i) − sig(start_j)||² + ||sig(end_j) − sig(start_i)||²
accept if cycle_err < ε and quasi_static(i) and quasi_static(j)
```

- **准静态判据**：`max|v_ee| < v_max`、gripper 闭合且接触持续、无自由飞行段。
- **增强**：`τ_aug = τ_i ⊕ reverse(τ_j)`，动作与帧同步倒序；时间戳重排；语言不变。
- **保守性**：只对白名单任务启用；对布料/液体（T16/T32）默认关闭或低权重，因为倒放物理不成立。

### 4.3 与 SCR 的分工

- SCR：真实、但稀疏、干扰幅度小（人类自然纠错）。
- RDA：受控、可批量、干扰幅度大（更接近规则里的"故意撤回"），但可能不物理。
- **训练配比建议**：SCR 60% + RDA 30% + 名义演示 10%（用于保持基本技能）；RDA 权重要按验证集调，避免"学会倒放"。

## 5. UIP-19 · OMR（Option-level Meta RL）

### 5.1 形式化

- 状态 `z_t ∈ R^30`：φ、Δφ 窗口、ee pose、gripper、|v_ee|、估计步骤索引、φ 集成方差、剩余延迟预算、当前 k。
- 动作 `A = {CONTINUE, REOBSERVE(k'), REDO_CURRENT, REDO_PREV, REGRASP, SAFE_ABORT}`。
- 奖励：`r_t = Σ_k v_k·1[完成步骤 k] − λ_lat·latency − λ_retry·1[retry] − λ_bad·1[不可逆操作]`。
- 折扣：episode 内 `γ=0.99`；终止于 episode 结束或 `SAFE_ABORT`。
- 约束：`REDO_*` 仅在 `φ` 置信度 > τ 且 UIP-15 预算内可用；不可逆步（插网线已入、已倒液体）禁止 `REDO`，只允许 `REGRASP`/`CONTINUE`。

### 5.2 离线离散 CQL（伪代码）

```python
def train_omr(T, Q, Q_targ, alpha=0.5, beta=0.1, gamma=0.99):
    for z, a, r, z2, done in T:
        with torch.no_grad():
            a2 = Q_targ(z2).argmax(-1, keepdim=True)
            y = r + gamma * (1 - done) * Q_targ(z2).gather(1, a2).squeeze(1)
        q = Q(z)
        td = F.mse_loss(q.gather(1, a.view(-1,1)).squeeze(1), y)
        # 保守项：压低所有动作，抬高数据动作
        cql = (torch.logsumexp(q, dim=1) - q.gather(1, a.view(-1,1)).squeeze(1)).mean()
        bc  = F.cross_entropy(q / 1.0, a)          # 行为克隆正则
        loss = td + alpha * cql + beta * bc
        loss.backward(); opt.step()
        soft_update(Q_targ, Q, 0.005)
```

- **为什么用 CQL 而不是纯 BC**：BC 只能模仿"人怎么纠错"，不能优化"何时纠错最省步骤分"；CQL 在离线数据上做保守策略改进，正是"低成本 RL"的落点。
- **为什么离散**：动作少、可枚举、训练稳；避免连续 RL 的探索/方差问题。
- **数据规模**：名义演示可造 `~10^6` 个 CONTINUE 转移；SCR+RDA 提供 `~10^4–10^5` 个重做/回退转移；类别不平衡用重采样/代价敏感损失。

### 5.3 运行时整合伪代码

```python
class LowCostRLPolicy:                    # UIP-16/19 + UIP-01′/13/15
    def __init__(self, vla, phi, omr, csg, skill_graph, K_MAX=8):
        ...
    def reset(self):
        self.vla.reset(); self.phi_hist = []; self.redo = 0; self.buf = []

    def get_action(self, obs):
        phi = self.phi(obs, obs["observation.language"])
        self.phi_hist.append(phi)
        if self._need_meta(obs):                       # 每 k 步
            z = self._features(obs, phi)
            a = self.omr.act(z) if self.csg.allow() else "CONTINUE"
            if a in ("REDO_CURRENT", "REDO_PREV"):
                self.redo += 1
                self.vla.rewind(a)                     # 回到子目标检查点
            elif a == "REOBSERVE":
                self.buf = []                          # 强制下次重取
            elif a == "SAFE_ABORT":
                return self.csg.safe_action(obs)
        if not self.buf:
            k = self._pick_k(obs, phi)                 # UIP-13 ACS
            self.buf = list(self.vla.get_action(obs, k))[:k]
        return self.buf.pop(0)

    def _need_meta(self, obs):
        return regressed(self.phi_hist) or (len(self.buf) == 0)
```

> 注：`rewind` 只能回到"内部检查点"（记录的子目标起点观测/技能），不是真机状态回滚；若技能不可逆，OMR 被约束为 `REGRASP`/`CONTINUE`。真正的"重做"是重新执行该子目标技能，不是时间倒流。

## 6. UIP-20 · PVS（可选：进度价值测试时搜索）

- **机制**：从 VLA 采样 `M` 个候选动作块 `{A_m}`，用离线学的 `Q(z, A_m)`（块级价值头，训练目标同 OMR 的回报）选 `argmax`；`M` 由剩余延迟预算动态决定（通常 2–4）。
- **为什么算 RL**：这是"用离线价值函数做一步策略改进/规划"，不需要环境交互。
- **成本**：多 `M−1` 次前向；对 7B 级 VLA 可能显著抬延迟 → **默认关闭**，只在低延迟小模型或非接触段启用。
- **风险**：Q 对 OOD 动作块高估 → 用集成 + 支持约束 + CSG 延迟门控。

## 9. 合规、风险与缓解

- **单模型合规（待手册确认）**：φ 与 OMR 优先作为**同一骨干上的小头**导出在同一个 policy class 内；推理期不调用外部 VLM/API。若规则禁止多组件，则把 OMR 退化为固定阈值规则（UIP-01′），φ 仅作验证器。
- **奖励幻觉（最大风险）**：φ 是代理，不是计分器。缓解：φ 集成 + 不确定性门控、SPA 步骤锚点、真实步骤分锚定（E208）、对"只涨 φ 不完成任务"的对抗样本做负训练。
- **离线 RL 的 OOD 高估**：离散 CQL + BC 正则 + 支持约束；`REDO` 只在可逆步开放。
- **RDA 物理不真实**：白名单 + 准静态 + 循环一致性；布料/液体默认关闭。
- **数据泄漏/评测过拟合**：任务级留出；RDA 配对跨集禁止；真机结论必须标注"代理/校准"。
- **规则未公开**：不对"外部数据/预训练模型/训练算力"做假设；方案可在"仅公开数据 + 单模型"下运行。
- **延迟可信度**：OMR/PVS 的额外前向必须计入 UIP-15 预算；宁可 `CONTINUE` 不搜索。

## 11. 本轮最大风险 & 押注

**一句话**：若 φ 在未见物品/非单调接触任务上把"视觉变化"误当"进度"，OMR 会学会刷进度而非真恢复；因此最大风险始终是**用自监督代理替代真实计分所产生的奖励幻觉**。

**→ 押注：UIP-16 PPR × UIP-17 SCR × UIP-18 RDA × UIP-19 OMR 的"离线进度-RL 闭环"**——它把 v2 最贵的仿真/采集换成 32k 演示的免费监督，把 RL 压到低维离散元层，完全落在"离线算力 + 选手 API 权限"之内；即使 φ 最终只达到"结构代理"精度，SCR+RDA 与 OMR 仍可作为 UIP-01′/09′ 的低成本数据与决策增强独立生效。
