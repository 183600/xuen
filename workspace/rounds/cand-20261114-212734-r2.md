# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「MuJoCo」×「多机器人协作」）

> R69 教会系统「问」，但它是在一个**光滑、单机、私有信念**的世界里问的：问一句，答案就是关于世界的干净证据；探一下，代价只算自己的时间与社交成本；安全边界是单体的、连续的、可被 Lipschitz 世界模型认证的。一旦进入 MuJoCo 式的**接触丰富**世界、进入**多机器人**团队，这三个默认同时破裂：
> - **非光滑**：接触模式（粘/滑、接触/分离）是离散隐变量；接触瞬间策略密度、动作似然、风险界都会合法地跳变。R69 的 FMA 会把「换接触模式」误报成「缓变故障」，R68/R69 的平滑前缀认证在 guard 处直接失效。
> - **共享且混杂**：我探询得到的响应 y，可能不是世界对我的回答，而是**队友同时动作的回声**；R69 的 VoI 是观测性的、被混杂的，不是 interventional 的。
> - **物理外溢**：探询不是免费的「看/问」，触觉探针会向**共享负载**注入力，可能伤害队友、暴露隐私、改变所有人赖以决策的状态；它是有外部性的信息动作。
>
> 核心命题：**把「不确定性」再按来源拆分（自 / 他 / 联合），把「信息动作」放进共享物理世界（有混杂、有外溢），把「安全认证」拆成不可互相替代的双钥匙（仿真反例 + 现实不变量）。** 命名 **ECHO-RAS**（Evidence under Confounding, Hybrid-contact, and Others — Risk-Adaptive Safety）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**这个观测是关于世界的证据，还是我队友刚才动作的回声？我的探询值不值得它对整队造成的扰动？**」

## 0. 直觉与动机

**灵感 1（MuJoCo → 接触世界是混合系统，不是光滑流形）**
直觉：MuJoCo 的接触由互补条件刻画（不可穿透、摩擦锥、最大耗散），动力学是**分段光滑的混合系统**：粘/滑、接触/分离是离散模式，模式切换处速度与力合法地跳变。R69 把策略、似然、认证都建在「光滑、Lipschitz」的假设上；而在接触丰富操作里，**最需要判断的恰恰是模式切换点**。用 Heun 积分跨过 guard、用单一高斯近似接触冲量、用连续 Lipschitz 界认证碰撞，都会在物理上给出「看起来严谨、实际无效」的结论。MuJoCo 的第一课不是「有个更好的仿真器」，而是：**世界在接触处是混合的，不确定性里有离散的一半。**

**灵感 2（MuJoCo → 数字孪生的正确用法是反例引擎，不是证明引擎）**
直觉：高保真仿真最大的诱惑是「仿真里没撞，所以安全」。但 sim-to-real gap 在接触处最大：摩擦系数、质量分布、执行器延迟、软接触参数都可能错。仿真能可靠提供的不是「安全证明」，而是**反例**：在参数与场景的对抗搜索下找到一条会违反不变式的轨迹。更进一步，仿真还能做**干预沙盒**：回放队友的真实动作、对「我的探询 g」做 do(g) 反事实，从而把「世界对我的回答」与「队友动作的回声」分开。前者是安全上的怀疑论，后者是因果上的实验台——这两件事才是 MuJoCo 在本轮的真实角色。

**灵感 3（多机器人协作 → 不确定性是共享的，且按来源分账）**
直觉：R69 把不确定性分成 aleatoric/epistemic，但两者都还是「关于世界」的。团队里至少要按**来源**再分三本账：
- **自账 U_self**：我对自己的传感/执行/标定的不确定 → 修复：自检、局部探针、收紧；
- **他账 U_other**：我对队友意图、能力、状态、是否合作的不确定 → 修复：通信、观察、约定协议、保守让行；
- **联合账 U_joint**：我们对共享隐变量（接触模式、负载质量、摩擦、相对位姿）的不确定 → 修复：联合实验、同步动作、共享观测。
三本账的**修复动作不同**。用「再问一句」去解决「根本不会」，或用「再练一练」去解决「接触模式判错」，都是把不同病喂同一副药。

**灵感 4（多机器人协作 → 信息动作有混杂，也有物理外部性）**
直觉：单机时，观测 y 近似只由我选的 g 决定，VoI 是干净的。团队里，y 同时由 g 和队友的并发动作 a₋ᵢ 决定：我推一下负载，感觉到滑，可能是我的探针太轻，也可能是队友同时松了手。此时 R69 的 VoI(g)=H(M|o)−E[H(M|o,y)] 估计的是**观测性**的量，却被当成**干预性**的量使用——这是典型的因果混杂。更糟的是，探询会往共享系统注力：一次「摸一下」可能让队友的抓取失稳。于是信息动作的收益是个人的，成本却是团队的。**私有信息、社会成本**，这是团队信息论与单机信息论的分水岭。

**灵感 5（两把钥匙 → 仿真认证与现实认证不可互相替代）**
直觉：R69 的安全认证只依赖一个世界模型（C-RAS-WM），它既是「预测未来的依据」又是「验证未来的依据」，单点失效。MuJoCo 孪生看似提供了第二个独立来源，但如果两把钥匙都插在同一个孪生上（仿真既做因果识别又做安全认证），它们其实是一把钥匙的两段。真正的双钥匙必须是**不同证据通道**：Key-1 是仿真对抗反例（覆盖度可审计），Key-2 是现实在线不变量与可逆逃逸（真实传感器、真实力限、真实回退）。任一不过都不放行；**仿真单独永不放行接触动作**。

**灵感 6（归因先于学习：别让队友的错记到技能上）**
直觉：R69 的失败可归因于「执行歧义」。团队里失败可能来自计划错、技能不会、世界模型错、队友错、通信错、规格错。若把「队友没按约定松手」导致的失败记到我的技能上，技能会被训练得越来越胆小；若把「我侥幸成功」记到技能上，技能会被过度泛化。**在混杂的团队数据里，归因本身就需要干预**：用同步/随机化协议与孪生反事实，把「谁造成的」与「谁碰巧在场」分开，才允许更新技能或信任。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（ECHO-RAS 总览）** ECHO-RAS = (HMA, MC-FMP, TUA, C-VoI, SDC, BCCA, DTF, IT, HCP, TKG, JFA, DMD, RAS-WM‡)。五条不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **模式诚实**：任何生成或认证的前缀都必须显式绑定一条接触模式日程 σ；模式不可辨时只能**加宽**不确定性，绝不允许默认其为光滑单模式（禁止「模式隐式平均」）；
(iii) **分布式证据纪律**：单机、单模态、单次观测不得单独定案；需跨智能体 + 跨模态的 k 源一致，并容忍最多 f 个 Byzantine 源；
(iv) **双钥匙权威**：接触丰富的联合动作，仿真反例通过**不能单独**授权，必须同时满足现实不变量与可逆逃逸；
(v) **单调退化**：通信丢失、模式不可辨、孪生-现实分歧、Byzantine 嫌疑任一发生 ⇒ λ 单调不降、k 单调不增，逐级退化为 R69（单机交互）再退化为 R68（纯保守）。

**定义 311（团队信念与信念公地）** 智能体 i∈[n]，共享信念 b_t 定义在（世界状态 x、接触模式 q、队友意图/能力 θ₋ᵢ）上。每个 i 只发布**已校准摘要** 𝒮ᵢ = (均值, 协方差, 本地 ECE, 证据来源哈希, 时间戳)；公地信念 b_t ∝ ∏ᵢ 𝒮ᵢ^{wᵢ}（信任权重 wᵢ，按历史校准与一致性更新）。关键：**每条证据带来源标签**，因此可计算「去掉 i 后信念变化了多少」（Shapley 式贡献度），这正是后文归因与反混杂的接口。

**定义 312（接触模式混合自动机 HMA）** 模式 q∈Q 编码接触图（哪些刚体对接触）与每个接触的粘/滑状态；连续状态 x；每个模式有流 f_q（MuJoCo 互补动力学在该模式内的光滑分支）、guard 集合 G_{q→q'}、reset 映射 R_{q→q'}（含接触冲量）。一条**模式日程** σ=(q₀,t₁,q₁,…)。模式不确定性是**离散隐变量**，不是连续噪声；不得用高斯把它抹平。

**定义 313（模式条件流策略 MC-FMP）** 在 R69 的 FMP 上增加模式条件：v_θ(x_s,s | z_t, q, σ)。训练损失 L_MC = L_FM + λ_c·L_comp，其中 L_comp 是 MuJoCo 互补残差（穿透深度、摩擦锥越界、粘滑互补）的惩罚；采样时按 σ 逐段积分，**在 guard 处用 reset 而非 Heun 跨越**。模式未知时对 Q 做边缘化：p(ξ|o)=Σ_σ p(σ|o)p(ξ|o,σ)，并报告每个 σ 的后验权重。R69 的 FMP 是本定义在 |Q|=1 时的退化。

**定义 314（三源不确定性 TUA）** 把 R69 的 (U_ale,U_epi) 按来源张成六格：
U_self^ale/U_self^epi（自身噪声/自身无知）、U_other^ale/U_other^epi（他人策略随机性/我对他人意图能力无知）、U_joint^ale/U_joint^epi（共享物理隐变量噪声/我们对其共同无知）。总账不求和，而是分别路由：self→自检/收紧；other→通信/观察/让行；joint→联合实验/同步探询。对偶通道（R69 的 FMA）继续保留，但必须在**模式边缘化后**计算，否则接触切换会污染第二意见。

**定义 315（混杂 VoI 与干预 VoI）** 观测性信息增益 VoI_obs(g)=H(M|o)−E_{y~p(y|g,o)}[H(M|o,y)]，其中 y 同时受 g 与队友并发动作 a₋ᵢ 影响。干预性增益 VoI_do(g)=H(M|o)−E_{y~p(y|do(g),o)}[H(M|do(g),y)]。定义**混杂缺口** Γ(g)=|VoI_obs(g)−VoI_do(g)|。当 Γ>τ_Γ：不得用 VoI_obs 决策，须改用可识别的干预协议（时间切片：探询窗口内只有 i 动；随机指派谁来探；或孪生反事实并显式标注其 sim-to-real 折扣），否则该信息动作视为不可识别、退回保守。

**定义 316（共享扰动成本 SDC）** c_team(g) = c_self(g) + Σ_{j≠i} [E risk_j(g) + E dist_j(g)]，dist_j 含注入共享负载的力、遮挡 j 的传感、占用的通信/时隙、社交打扰。团队设扰动预算 D_max：任一信息动作若会消耗其他智能体的安全裕度，直接否决。信息动作的接受条件从 R69 的 VoI>c 升级为 **VoI_do(g) > c_self(g) + λ_team·externality(g)**，其中 externality 是外部性货币化系数。

**定义 317（Byzantine 跨智能体佐证 BCCA）** 证据源集合 ℰ = 智能体 × 模态 × 时间窗。最多 f 个源 Byzantine（撒谎、重放、共谋、伪造接触读数）。聚合规则：在信任图上做 k 源一致 + 稳健统计（中位数/截尾均值），并满足 n ≥ 2f+1 的**法定人数**（要强一致则 n ≥ 3f+1）。R69 的「k 个正交证据源一致」是本定义在 n=1、f=0 的退化。**任何单一智能体（包括被标为「可信」的）都不得单独定案**——这是防止「一个自信的队友把整队带沟里」的结构性约束。

**定义 318（数字孪生反例器 DTF）** 给定联合动作前缀 A 与待验不变量 φ（无碰撞、力限、负载水平、相对位姿包络），在参数/场景分布 Θ 上做对抗搜索，寻找 (θ,σ) 使 MuJoCo 回放违反 φ。输出 (反例, 搜索覆盖度 ρ, 未覆盖区域清单)。**「未找到反例」≠「安全」**：DTF 只提供可审计的**证伪置信度**，报告 ρ 与生成的反例族；ρ 不足则不得作为钥匙。

**定义 319（干预孪生 IT）** 用记录到的队友动作 a₋ᵢ 回放，计算 do(g) 的反事实 y，并估计 Γ(g) 与「若我不探询、队友照常动作」的对照。IT 的输出必须带 **sim-to-real 折扣** κ_sim（由历史迁移误差估计），且不得覆盖现实证据；κ_sim 越界即关闭 IT，改用现场同步/随机化。

**定义 320（混合可认证前缀 HCP）** 把 R68/R69 的 certified prefix 扩展到 HMA：在每个模式 q 内用平滑界认证 k_q 步；到达 guard 时，要求 (a) 对所有可达后继模式 q' 存在一个**有界冲量**的 reset，(b) 在 q' 中至少存在一条可认证的续段，否则 k 截断在 guard 前。接触冲量用**冲量感知裕度** η_imp 替代速度连续性假设。输出 k 与「模式日程前件」σ_{1:k}，认证随模式切换而**失效重证**，绝不复用跨模式的平滑界。

**定义 321（双钥匙门 TKG）** 接触丰富的联合动作 A 放行 ⇔ Key-1（DTF 在覆盖度 ρ≥ρ₀ 下无 φ 反例）∧ Key-2（现实在线不变量：实测力/位/距离裕度保持 + 可逆逃逸在 τ_esc 内可用）∧ 证据纪律满足。Key-1 单独**永不**授权；Key-2 单独则退化为 R68 的纯保守。两钥匙必须**证据独立**：若 Key-1 与 Key-2 都依赖同一孪生，则记为**相关失效**，强制降级（见定义 326 的独立性检查）。

**定义 322（联合风险预算与角色分配）** 团队风险预算 R_team 按技能合同与计划段分配；角色（谁主导、谁跟随、谁探询、谁保持可逆）由「在预算与通信约束下最大化期望任务进度」选出。**领导者不是决策者，而是风险账本的聚合者与双钥匙的持有者**；角色可动态切换，但切换必须有 dwell-time 防抖。R69 的单机风险缩放是本定义在 n=1 的退化。

**定义 323（联合失败归因 JFA）** 失败后，先在 {计划, 技能, 世界模型, 队友, 通信, 规格} 上做因果归因：用同步/随机化协议与 IT 反事实估计每个因素的反事实必要性/充分性，输出归因分布与置信。**只有归因为「技能」的失败允许更新技能**；归因为队友/通信的进入信任更新，归因为计划的进入重规划，归因为规格的进入人审。禁止把混杂的团队失败直接写进技能参数（避免选择偏差与错误泛化）。

**定义 324（分布式单调退化 DMD）** 触发条件：通信超时/丢包、模式后验熵超阈、DTF 与 Key-2 持续分歧、BCCA 检出 Byzantine 嫌疑。响应：各智能体本地 λ 单调不降、k 单调不增；团队退化为「独立安全控制器 + 不移动共享负载」；必要时由 Key-2 触发可逆逃逸（松手/支撑/回撤）。退化是**逐指令**的，不依赖全局同步，避免「等共识时已经撞了」。

**定义 325（威胁模型 ℰ_ECHO）** ℰ_ECHO = ℰ_FLUID × ℰ_byz × ℰ_confound × ℰ_sim：Byzantine 队友与共谋、通信伪造/重放/延迟注入、遮挡与接触模式欺骗（对手操纵接触让证据指向错误模式）、因果混杂攻击（队友故意同时动作以污染我的探询）、孪生投毒（训练/校准数据污染使 DTF 乐观）。每条攻击都对应一条结构防线，而不是一条调参。

**定义 326（证书 J_ECHO）** J_ECHO = (J_FLUID, mode_posterior_entropy, mode_coverage, Γ_p95, team_disturbance_used, byzantine_quorum, falsifier_coverage ρ, keys_status, key_independence_score, attribution_log_hash, echo_ver)。Valid ⇔ Valid(J_FLUID) ∧ 模式日程显式 ∧ 证据纪律满足 ∧ 双钥匙均过且**独立性检查通过** ∧ 团队扰动未越界。独立性检查失败（两钥匙共享孪生/共享数据源）⇒ 证书降级为「仅 R68 保守可用」。

```python
class ModeConditionedFlowPolicy:
    def sample(self, o_t, Q, K, N_step=2):
        z = self.trunk(o_t)

        return out

            if gamma > TAU_GAMMA: continue         # 混杂过强：不探询
        else:
            voi_do, gamma = voi_obs, 0.0
        score = voi_do - c_self(g) - lam_team * externality(g, belief)
        if best is None or score > best.score: best = (g, score, gamma)
    return best if best and best.score > 0 else None   # 无利可图 → R69/R68

# IP-267 BCCA：跨智能体 + 跨模态 k 源一致（容忍 f 个 Byzantine）
def corroborate(evidence, trust, f):
    if len(evidence) < 2*f + 1: return None, "no_quorum"
    groups = robust_consensus(evidence, trust)          # 中位数/截尾 + 信任图
    agree = [g for g in groups if g.support >= k_src]
    return agree[0] if agree else (None, "no_consensus")

# IP-268 DTF+IT：孪生只做反例与反事实，不做证明；关键路径外异步
def falsify(prefix, phi, theta_dist, rho_target):
    cex = adversarial_search(mujoco_rollout, prefix, phi, theta_dist)
    rho = estimate_coverage(theta_dist, cex)
    return {"counterexamples": cex, "coverage": rho, "provable": False}

def interventional_gap(g, recorded_actions, twin, kappa_sim):
    if kappa_sim > KAPPA_MAX: return None, "sim_untrusted"
    y_do  = twin.replay_do(g, recorded_actions)
    return abs(voi_obs(g) - voi_do(g, y_do)), "ok"

# IP-269 HCP+TKG：混合认证只在模式内有效；双钥匙独立才放行
def certify_and_gate(A, mode_schedule, phi, twin, real_monitor):
    k = 0
    for seg in segments(mode_schedule):
        k_seg = c_ras_wm.certified_prefix(A[:H], q=seg.q, eta_imp=ETA_IMP)
        k += k_seg
        if k_seg < seg.length: break                # guard 前截断，不跨模式复用界
    key1 = falsify(A[:k], phi, theta_dist, RHO_TARGET)["coverage"] >= RHO_TARGET
    key2 = real_monitor.holds(phi) and real_monitor.escape_available(TAU_ESC)
    independent = key1 and key2 and twin.provenance() != real_monitor.provenance()
    if not (key1 and key2 and independent):
        return 0, "two_key_fail"                    # 双钥匙任一不过 → 不放行
    return k, "ok"

# IP-270 主闭环（继承 R69，替换不确定性路由、交互选择与认证）
def ECHO_RAS_round(M, obs, team):

    mode_post = M.hma.posterior(z, o)               # P(σ|o)，离散后验

                   if g is not None else (None, "no_interaction"))
    # 2) 归因后才更新；失败不得直接写进技能
    M.jfa.submit(g, answer, why, mode_post, team.belief)
    # 3) 接触模式边缘化后的对偶似然（避免把换模式误判成缓变故障）
    a_hat = M.fma.flow_anomaly_marginalized(M.mcfmp, M.last_action, o, o_cal)

    # 4) 风险：self/other/joint 分账；未消解则各自收紧

    # 5) 混合认证 + 双钥匙；仿真单独永不放行
    A = M.ach.propose(x_prime, H=M.vista.H)
```

## 3. 推导

**引理 19（模式错配的似然膨胀）** 设真实模式日程 σ*，若策略/似然实际条件在 σ≠σ*，则接触事件处的负对数似然期望上升量 ≥ E[‖r_comp(x,σ)‖²]/(2σ_in²) − log p(σ*/σ)，其中 r_comp 是 MuJoCo 互补残差（穿透、摩擦锥、粘滑）。系：**不先边缘化接触模式就计算 FMA，会把「合法换模式」误报为「缓变故障」**；R69 在接触丰富场景的 FMA 假阳性率随接触频率线性增长。

**引理 20（混杂缺口与可识别性）** 设 y = f(g, a₋ᵢ, x)+ε，a₋ᵢ 与 g 相关 ρ_c。则 Γ(g)=|VoI_obs−VoI_do| ≤ C·ρ_c·Var(a₋ᵢ)^{1/2}/(σ_ε)，C 为耦合增益。故：(i) 时间切片使 ρ_c=0 ⇒ Γ=0（可识别）；(ii) 随机指派探询者使 ρ_c→0；(iii) 队友越活跃、耦合越强、传感噪声越低，混杂越严重——**「安静的团队」反而让单机式 VoI 更可信**。这是反直觉但可检验的推论（E304 设计依据）。

**引理 21（信息动作的社会外部性）** 团队最优探询频率满足：仅在 VoI_do(g) > c_self(g)+λ_team·externality(g) 时探询；若 externality 单调随共享负载耦合度上升，则存在耦合阈值 κ*，超过后**任何探询都不如直接保守地同步执行**。系：多机器人里「多问一句」可能不如「一起稳稳抬起来」；信息不是越多越好，而是**信息的社会净收益**才重要。

**引理 22（Byzantine 佐证的错误上界）** n 个证据源、f 个 Byzantine、各诚实源独立错误率 δ；采用法定人数 n≥2f+1 的 k 源一致时，错误采纳率 ≤ Σ_{j=k-f}^{k} C(k,j)δ^j(1−δ)^{k−j} + ε_σ；若需强一致（n≥3f+1）且诚实源多数，则错误率随 k 指数下降。系：R69 的 k 正交一致在分布式下**必须叠加 Byzantine 法定人数**，否则「多问几个队友」只是多问了几个可能共谋的源。

**定理 18（ECHO 严格包含 FLUID 与 R68）** 当 |Q|=1（无接触切换）、n=1、通信/扰动预算为 0、IT 关闭时，定义 310–326 逐条退化为 R69 定义 293–309：模式边缘化恒等、TUA 退化为 (U_ale,U_epi)、C-VoI 退化为 VoI、BCCA 退化为单机证据纪律、TKG 退化为 C-RAS-WM 认证。故 ECHO 在「光滑单机」边界上逐指令等于 FLUID；在「永不交互 + 单模式」边界上进一步等于 R68。安全侧不做任何让步。

**定理 19（双钥匙的必要性与相关失效）** 设 sim-to-real 误差有上界 ε_sim>0 且不可观测。仅用孪生授权时，存在参数族使 P(现实违反 φ | 仿真通过) ≥ 1−δ_DTF − ε_sim 的下界失效，即**仿真单独授权无有限安全保证**。双钥匙门把授权条件改为 Key-1∧Key-2，其中 Key-2 由现实不变量与可逆逃逸构成；仅当两钥匙证据独立时，失效概率 ≤ δ_DTF·δ_real（乘积）。**若两钥匙共享孪生/数据源，则退化为单钥匙**，故定义 326 强制独立性检查。

**定理 20（混合退化与无抖振）** 在 HMA 的每个模式内，λ 单调不降、k 单调不增；模式切换只在 guard 且带冲量感知裕度 η_imp，命令不连续量被接触冲量界 ‖Δv‖≤I_max/m 约束；DMD 的退化不依赖全局共识，故通信丢失时仍满足逐指令单调性；加 dwell-time 后无 Zeno 抖振。⇒ 团队退化连续可控，不会因「等共识」而错过安全窗口。

## 6. 本轮最大风险

**一句话**：ECHO-RAS 把「物理可信」与「因果可识别」都押在**接触模式可观测 + 数字孪生可信**上——一旦接触模式被误判，或孪生在关键接触处失真，那么「仿真没找到反例」就会被误读成「安全」，「孪生反事实」就会被误读成「因果证据」；更危险的是双钥匙可能**共享同一孪生**而并非独立，多机耦合会把一个单点认知错误放大成整队事故。

**次级风险与缓解**：
1. **模式边缘化爆炸**（|Q| 大时组合爆炸）→ 只对预测接触窗口做边缘化 + 模式后验 top-k + guard 前截断；
2. **DTF 覆盖度造假/乐观** → 覆盖度由独立审计方估计、对抗场景族版本化、Key-2 永远独立于孪生；
3. **因果识别仍不充分**（同步协议降低效率）→ 随机化探询者 + 倾向权重 + 只在高 Γ 时启用；
4. **Byzantine 与相关失效**（队友与我共享同一错模型）→ 法定人数 + 信任图去相关 + 定期独立审计探针；
5. **团队退化时的责任真空** → DMD 预置「谁松手/谁支撑/谁回撤」的可逆契约，离线演练，在线只执行。

**定义 312–313（HMA 与 MC-FMP）** 接触模式是离散隐变量，不得用高斯抹平；流策略条件在 σ 上，guard 处用带冲量 reset，模式未知时 `p(ξ|o)=Σ_σ p(σ|o)p(ξ|o,σ)`；|Q|=1 时退化为 R69 的 FMP。

**定义 314（三源不确定性 TUA）** `U_self/U_other/U_joint` 各含 ale/epi 六格；self→自检收紧、other→通信观察让行、joint→联合实验同步探询；FMA 必须在模式边缘化后计算。

**定义 315（C-VoI）** `VoI_obs` 被 `a₋ᵢ` 混杂；改用 `VoI_do(g)=H(M|o)−E_{y~p(y|do(g),o)}H(M|do(g),y)`；混杂缺口 `Γ=|VoI_obs−VoI_do|>τ_Γ` ⇒ 需时间切片/随机指派/孪生反事实（带折扣），否则不探询。

**定义 316（SDC）** 探询接受条件升级为 `VoI_do > c_self + λ_team·externality`；会消耗队友安全裕度者直接否决；累计团队扰动 ≤ D_max。

**定义 317（BCCA）** 跨智能体 + 跨模态 k 源一致，稳健统计 + 信任图；`n≥2f+1` 才能定案，强一致需 `n≥3f+1`；单源（含「可信」队友）永不定案。

**定义 318–319（DTF 与 IT）** DTF 只做对抗反例搜索并报告覆盖度 ρ，**「未找到反例」≠ 安全**；IT 做 do(g) 反事实并带 κ_sim 折扣，不得覆盖现实证据，κ_sim 越界即关闭。

**定义 320–321（HCP 与 TKG）** 模式内认证、guard 前截断、冲量感知裕度；接触动作放行 ⇔ Key-1（ρ≥ρ₀ 无 φ 反例）∧ Key-2（现实不变量 + 可逆逃逸）∧ 证据纪律；两钥匙必须证据独立，否则记为相关失效并降级。

**定义 322–324（风险预算 / 归因 / 退化）** 领导者是风险账本聚合者与钥匙持有者，非独裁决策者；失败先在 {计划,技能,世界,队友,通信,规格} 归因，只有「技能」可更新技能；通信丢失/模式歧义/孪生-现实分歧 ⇒ 本地 λ 单调升、k 单调降、退化为独立安全控制器。

**定义 325–326（威胁与证书）** `ℰ_ECHO=ℰ_FLUID×ℰ_byz×ℰ_confound×ℰ_sim`；`J_ECHO` 增列模式熵、Γ_p95、团队扰动、法定人数、反例覆盖度、双钥匙状态与**独立性分数**；独立性失败 ⇒ 证书降级为「仅 R68 保守可用」。

## 3. 关键算法伪代码

```python
# IP-264 MC-FMP：模式条件流策略（guard 用 reset，模式未知则边缘化）
class ModeConditionedFlowPolicy:
    def sample(self, o_t, Q, K, N_step=2):
        z = self.trunk(o_t); post = self.mode_posterior(z, o_t)
        out = []
        for sigma, w in topk(post, K):
            xs = randn(1, D)
            for seg in segments(sigma):
                for i in range(N_step):
                    xs = xs + (1.0/N_step) * self.v(xs, i/N_step, z, seg.q)
                xs = self.hma.reset(xs, seg.q_next)       # 冲量 reset，不跨 guard 用 Heun
            out.append((self.decode(xs), w, sigma))
        return out

# IP-266 C-VoI：先可识别、再算干预增益、再扣共享外部性
def choose_interaction(cands, o_t, belief, budget, twin):
    best = None
    for g in cands:
        if not budget.allow(g) or not c_ras_wm.certify_info(g, o_t): continue
        voi_obs = entropy(belief.M) - expected_entropy(belief.M, g, o_t)
        if not synchronized_or_randomized(g):
            voi_do, gamma = twin.do_counterfactual(g, o_t)
            if gamma > TAU_GAMMA: continue                # 混杂过强：不探询
        else:
            voi_do, gamma = voi_obs, 0.0
        score = voi_do - c_self(g) - lam_team * externality(g, belief)
        if best is None or score > best.score: best = (g, score, gamma)
    return best if best and best.score > 0 else None      # 无利可图 → R69/R68

# IP-269 BCCA：跨智能体 + 跨模态 k 源一致（容忍 f 个 Byzantine）
def corroborate(evidence, trust, f):
    if len(evidence) < 2*f + 1: return None, "no_quorum"
    groups = robust_consensus(evidence, trust)
    agree = [g for g in groups if g.support >= k_src]
    return agree[0] if agree else (None, "no_consensus")

# IP-270/271 DTF + IT：孪生只做反例与反事实，不做证明
def falsify(prefix, phi, theta_dist, rho_target):
    cex = adversarial_search(mujoco_rollout, prefix, phi, theta_dist)
    return {"counterexamples": cex, "coverage": estimate_coverage(theta_dist, cex),
            "provable": False}

# IP-272/273 HCP + TKG：模式内认证 + 双钥匙独立才放行
def certify_and_gate(A, mode_schedule, phi, twin, real_monitor):
    k = 0
    for seg in segments(mode_schedule):
        k_seg = c_ras_wm.certified_prefix(A[:H], q=seg.q, eta_imp=ETA_IMP)
        k += k_seg
        if k_seg < seg.length: break                      # guard 前截断
    key1 = falsify(A[:k], phi, theta_dist, RHO_TARGET)["coverage"] >= RHO_TARGET
    key2 = real_monitor.holds(phi) and real_monitor.escape_available(TAU_ESC)
    independent = key1 and key2 and twin.provenance() != real_monitor.provenance()
    return (k, "ok") if (key1 and key2 and independent) else (0, "two_key_fail")

# IP-274 主闭环（继承 R69，替换不确定性路由、交互选择与认证）
def ECHO_RAS_round(M, obs, team):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    mode_post = M.hma.posterior(z, o)
    samples   = M.mcfmp.sample(o, M.hma.Q, K=1 if mode_post.entropy < TAU_Q else 4)
    U_src     = M.tua.decompose_sources(samples, z, team.belief, mode_post)
    g = M.cvoi.choose_interaction(info_candidates(U_src), o, team.belief, M.budget, M.it)
    answer, why = (M.bcca.corroborate(M.cia.execute(g), team.trust, team.f)
                   if g is not None else (None, "no_interaction"))
    M.jfa.submit(g, answer, why, mode_post, team.belief)
    a_hat = M.fma.flow_anomaly_marginalized(M.mcfmp, M.last_action, o, o_cal)
    slow  = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    lam   = max(M.efs.risk_scale(...), lam_floor(U_src, slow))
    A = M.ach.propose(x_prime, H=M.vista.H)
    k, status = M.tkg.certify_and_gate(A, mode_post.map(), PHI, M.dtf, M.real_monitor)
    if status != "ok":
        lam = max(lam, 0.8); k = min(k, 0); M.real_monitor.escape()
    mode = select_mode(samples, U_src, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    return k, lam, mode, (U_src, status)
```

## 4. 推导

**引理 19（模式错配的似然膨胀）** 若真实日程 σ*，似然却条件在 σ≠σ*，接触事件处负对数似然期望上升 ≥ `E‖r_comp(x,σ)‖²/(2σ_in²) − log p(σ*/σ)`。系：不先边缘化接触模式就算 FMA，会把合法换模式误报为缓变故障；R69 的 FMA 假阳性随接触频率线性上升。

**引理 20（混杂缺口与可识别性）** `y=f(g,a₋ᵢ,x)+ε`，`a₋ᵢ` 与 `g` 相关 ρ_c，则 `Γ ≤ C·ρ_c·Var(a₋ᵢ)^{1/2}/σ_ε`。时间切片或随机指派使 ρ_c→0 ⇒ Γ=0；队友越活跃、耦合越强、传感越准，混杂越重——「安静的团队」反而让单机式 VoI 更可信（E304 可检验）。

**引理 21（信息动作的社会外部性）** 团队最优探询条件为 `VoI_do > c_self + λ_team·externality`；当 externality 随共享负载耦合度单调上升，存在 κ* 使耦合超过后**任何探询都不如直接同步保守执行**。系：多机里「多问一句」可能不如「一起稳稳抬起来」。

**引理 22（Byzantine 佐证上界）** n 源、f Byzantine、诚实源独立错误率 δ，`n≥2f+1` 的 k 源一致错误率 ≤ `Σ_{j=k-f}^{k} C(k,j)δ^j(1−δ)^{k−j} + ε_σ`；强一致 `n≥3f+1` 下随 k 指数下降。系：R69 的 k 正交一致必须叠加 Byzantine 法定人数，否则「多问几个队友」只是多问了几个可能共谋的源。

**定理 18（ECHO 严格包含 FLUID 与 R68）** `|Q|=1, n=1, D_max=0, IT 关闭` 时，定义 310–326 逐条退化为 R69 的 293–309：模式边缘化恒等、TUA 退化为 (U_ale,U_epi)、C-VoI 退化为 VoI、BCCA 退化为单机证据纪律、TKG 退化为 C-RAS-WM 认证。故光滑单机边界上逐指令等于 FLUID；再叠加「永不交互」等于 R68，安全侧不让步。

**定理 19（双钥匙必要性与相关失效）** sim-to-real 误差 `ε_sim>0` 不可观测时，仅用孪生授权存在参数族使安全下界失效（`P(违反|仿真通过) ≥ 1−δ_DTF−ε_sim` 的保证不成立）。双钥匙把条件改为 `Key-1∧Key-2`，仅当两钥匙证据独立时失效概率 ≤ `δ_DTF·δ_real`；若共享孪生/数据源则退化为单钥匙，故证书强制独立性检查。

**定理 20（混合退化与无抖振）** 各模式内 λ 单调不降、k 单调不增；模式切换仅在 guard 且带冲量裕度，命令不连续量受 `‖Δv‖≤I_max/m` 约束；DMD 不依赖全局共识，通信丢失仍逐指令单调；dwell-time 排除 Zeno 抖振 ⇒ 团队退化连续、不会因等共识错过安全窗口。

## 7. 本轮最大风险

**一句话**：ECHO-RAS 把「物理可信」与「因果可识别」都押在**接触模式可观测 + 数字孪生可信**上——一旦接触模式被误判，或孪生在关键接触处失真，那么「仿真没找到反例」就会被误读成「安全」，「孪生反事实」就会被误读成「因果证据」；更危险的是双钥匙可能**共享同一孪生**而非真正独立，多机耦合会把一个单点认知错误放大成整队事故。

**次级风险与缓解**：模式边缘化组合爆炸（仅接触窗口 + top-k + guard 截断）；DTF 覆盖度乐观/造假（独立审计 + 场景族版本化 + Key-2 永不依赖孪生）；因果识别仍不充分（随机化探询者 + 倾向权重 + 仅高 Γ 启用）；Byzantine 相关失效（法定人数 + 信任图去相关 + 定期独立探针）；退化时责任真空（离线演练「谁松手/谁支撑/谁回撤」的可逆契约，在线只执行）。
