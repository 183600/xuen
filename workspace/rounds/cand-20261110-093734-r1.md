# 第 44 轮（新循环第 4 轮） · GEN-GAIT-CERT：把「步态」变成证书的泛化坐标，把「泛化能力」变成可认证的安全半径（四层架构 v9）

> 承接第 43 轮 v8（SEM-CERT-MAP）。第 43 轮自陈最大风险是「证据自证循环」：地图、证书与采集共用同一套模型，越采越自信而真实盲区被系统性掩盖。本轮灵感词「泛化能力」「步态规划」正好从两个互补方向回应这个风险：**步态规划**告诉我们，机器人安全证书真正的坐标系不是笼统的全局状态，而是「接触相位 × 步态参数 × 地形」；**泛化能力**告诉我们，证书不应只覆盖被采过的点，而必须显式给出「从已证点能向外推多远」的可认证半径。二者结合，把第 43 轮的「证据覆盖」升级为「证据 + 可证明的泛化半径」：证书从「点」变成「球」，采集从「填不确定」变成「扩张/证伪证书球」，步态规划从「先规划再验证」变成「直接在已认证步态球内选参数」。

## 0. 直觉与动机

**灵感 1（步态规划 → 接触相位是证书真正的坐标系，也是非光滑性的来源）**：四足/双足机器人不是一台连续动力学系统，而是一个**混合系统**：每个相位（支撑/摆动、单脚/双脚/四脚触地）内部动力学光滑，但 touchdown/liftoff 的瞬时接触切换会让安全边际发生跳变。第 42/43 轮的 Lipschitz 常数 L_m 是在整个状态空间上估的，因此被最坏的接触切换拖大，导致证书过度保守。步态规划的直觉是：**先按相位分解**，在每个相位内用很小的局部 L_m^q 做证书；接触切换不再交给 Lipschitz 去「硬吃」，而是用**显式的守卫 + reset 安全性**单独证明。这样同一份安全边际能推出大得多的泛化半径——这不是近似放宽，而是把非光滑性放到它该在的地方精确处理。更进一步，步态参数 g（步长、步高、节拍、占空比、躯干高度、落足偏置）本身就是规划器的可调自由度，证书若能给出「哪些 g 安全」，规划就从「试错」变成「在证书球内优化」。

**灵感 2（泛化能力 → 证书从「点」到「球」，并且必须显式声明适用域）**：机器学习的泛化讲的是「训练分布上的好表现能否推到未见样本」。安全证书的泛化有更硬的单边要求：不是平均表现好，而是**未见上下文里也不能低于阈值**。直觉上有三层：其一，**结构化的度量**——把步态/地形/负载压到一个低维、证书相关的特征空间，若安全边际对该特征满足 L_gen-Lipschitz，则从一个已证点出发，半径 r=(m_lo−θ)/L_gen 内的所有上下文都被同一条证书覆盖；其二，**不变表示**——不是所有特征都影响安全，训练一个「证书保持」的编码器 E，把与安全无关的 nuisance 压掉，可显著降低有效 L_gen；其三，**分布无关校准**——用 conformal / 单边分位数把有限样本的乐观偏差扣掉，并对 OOD 上下文显式返回 UNKNOWN 而非硬猜。核心口号：**证书不是一个布尔值，而是一个带适用域和置信度的「安全球」**。

**灵感 3（二者耦合 → 安全步态规划、泛化前沿采集、组合泛化）**：把灵感 1、2 合起来：(a) **安全步态规划** = 在认证泛化集合 {g : GenCert(g,τ,w)=1} 内最小化任务代价；无可行解时退回保守步态，而不是冒险。(b) **泛化前沿采集** = 主动采集不再追「不确定度最大」，而是追「规划器真正想走、但证书球边界外的步态/地形组合」，用一次实验把边界往外推最多；同时保留独立「证伪 holdout」，专测「证书说安全、实际不安全」。(c) **组合泛化** = 把 walk/trot/pace/climb 等认证步态原语当作积木，新步态 = 原语组合 + 接触状态接口契约，用 IP-47 的乘积自动机做组合证书。这样，第 43 轮的「证据自证」被一个**可被独立证伪的泛化半径**约束：半径是预测，holdout 是检验，预测错就必须撤销。

**耦合关系**：步态相位提供「证书的分解坐标」，泛化半径提供「证书的覆盖半径」，主动采集提供「半径的扩张与证伪」，语义证据场/EPL 提供「半径挂在哪个地图区域、凭什么信」。四者叠加成 **Phase→Radius→Acquire/Falsify→Compose** 的泛化飞轮，与第 42 轮 Sim→RAG→Edge 飞轮、第 43 轮 Map→Acquire→Prove 飞轮正交。

## 1. 形式化定义（增量：定义 44–49）

**定义 44（接触相位混合自动机与步态参数）**：步态系统 H_g = (Q, X, U, G, F, E, R, Δ)。Q 为接触相位集（每条腿的支撑/摆动组合），X ⊂ R^n 为状态，G ⊂ R^{d_g} 为步态参数（步长 ℓ、步高 h、节拍 f、占空比 β、躯干高度 z_b、落足偏置），F={F_q}_{q∈Q} 为各相位内光滑向量场，E 为 touchdown/liftoff 转移边，R={R_e} 为 reset 映射，Δ 为接触不确定集（摩擦、柔顺、滑移、传感延迟）。步态计划 π_g 是相位序列与驻留时间；规划器可选的步态参数集记为 G_plan。

**定义 45（相位索引证书 PIC）**：对每个相位 q 与步态 g，证书 C_q(g) = (Inv_q, m_q, θ_q, T_hold_q, {Guard_{q→q'}})，其中
m_q(x;g) = min{ ZMP/CoP 支撑多边形裕度, 摩擦锥裕度, 捕获点裕度, 关节限位裕度, 自碰撞裕度 }。
**相位内健全性**：若 x(t) 在 q 内满足 x ∈ Inv_q 且 m_q(x) ≥ θ_q 持续 T_hold_q，则相位内安全。**转移健全性**：守卫 Guard_{q→q'}(x;g) 必须同时蕴含 (i) 物理接触事件成立，(ii) reset 像安全，即 m_{q'}(R_e(x);g) ≥ θ_{q'} 且 R_e(x) ∈ Inv_{q'}。称轨迹在 g 下被认证，当且仅当所有相位满足相位内健全性且所有转移满足转移健全性。

**定义 46（证书泛化度量与证书保持不变表示）**：上下文 c = (g, τ, w)，τ 为地形特征（坡度、摩擦、粗糙度、台阶高度、柔顺），w 为负载/扰动。设证书相关的上下文度量 d_c。学习编码器 E: c → z ∈ R^{d_z} 与证书模型 M: z → m̂，满足**证书保持性**：
|m(x;c) − m̃(x;E(c))| ≤ ε_inv，且 E 为 L_E-Lipschitz、m̃ 对 z 为 L_m̃-Lipschitz。
则**有效泛化 Lipschitz** L_gen = L_m̃ · L_E + ε_inv/δ_c。相位内用 L_gen^q（小），跨接触切换用定义 45 的 reset 守卫承担，不并入 L_gen。

**定义 47（认证泛化半径与单边泛化界）**：给定标定集 S={(c_i, x_i)}，每条标定给出单边下界 m_lo(c_i)（已扣有限样本修正 β(n,δ)）。对任意上下文 c，
m_gen(c) = max_{i: d_c(c,c_i) ≤ R_supp} [ m_lo(c_i) − L_gen·d_c(c,c_i) ]。
**认证泛化判定**：GenCert(c)=1 ⇔ m_gen(c) ≥ θ(c) 且 c 在支持域 R_supp 内。**认证泛化半径**：r_cert(c_i) = (m_lo(c_i) − θ)/L_gen。**命题（单边 soundness）**：若不变表示误差 ≤ ε_inv、L_gen 为上界、m_lo 为单边 (1−δ) 下界，则对认证集内所有 c，P(m(x;c) ≥ θ) ≥ 1−δ；支持域外一律返回 UNKNOWN，不得当作安全。

**定义 48（泛化覆盖剖面、泛化前沿与「可用泛化」）**：在任务相关测度 μ_task 下，认证泛化体积 V_cert(t)=μ_task({c: GenCert(c)=1})；泛化前沿 F_t=∂{GenCert=1}。定义**可用泛化** V_use(t)=μ_task({c: GenCert(c)=1 ∧ c 被规划器请求})，以及 **泛化校准缺口** gap_gen = |预测认证率 − holdout 实测安全率|。V_use 而非 V_cert 才是机器人真正能用的安全自由度；gap_gen 是第 43 轮自证循环的直接监控量。

**定义 49（泛化驱动采集与安全步态规划）**：
(a) 安全步态规划：g* = argmin_{g∈G_plan} J(g) s.t. GenCert(g,τ,w)=1；若无可行解，退回预认证保守步态集合 G_safe0。
(b) 泛化前沿采集：a* = argmax_{a∈A_adm} E[V_use(t+1; a) − V_use(t)] / (C(a)+λ_R·R(a))，s.t. R(a) ≤ R_budget，且强制以比例 ρ_hold 的预算执行**证伪 holdout**（独立于训练/采集的步态-地形分层抽样），任何「预测认证但实测不安全」立即触发 EPL 撤销与 L_gen 重估。

## 2. 产出设计（增量 IP-60/61/62 + 升级 IP-49/50/51/54/55/56/57/58/59/45/47）

### 2.1 IP-60 GAIT-PHASE-CERT-AUTOMATON（GPCA，相位证书自动机）
1. **相位分解**：由步态计划与足端接触传感器/本体感知估计当前相位 q_t；每个相位单独建 Inv_q、m_q、θ_q、T_hold_q。
2. **转移守卫合成**：Guard_{q→q'} 由「物理事件 + reset 安全 + reset 保持不变式」三者合取，避免把接触跳变塞进 L_m。
3. **与 CAR 对接**：CAR 的每条边增加相位标签；CAR 状态 = (模式, 相位)，守卫查询走相位证书；相位未知/接触不确定时按最保守守卫降级。
4. **reset 压力测试**：把 touchdown 速度、落足角、地形台阶、摩擦突变作为 Δ 的显式维度，交由 IP-54 注入。

### 2.2 IP-61 GEN-CERT-RADIUS（GCR，认证泛化半径引擎）
1. **证书保持不变表示**：E 用「证书排序保持 + 对比不变 + Lipschitz 惩罚」训练；禁止丢掉摩擦/接触/姿态等安全相关特征（反事实不变性测试兜底）。
2. **L_gen 估计**：相位内分位数估计 L_gen^q；reset 损失由 IP-60 守卫单独界；对外只发布上界。
3. **单边校准**：conformal/分位数 + 有限样本修正 β(n,δ)；输出 (m_gen, r_cert, 支持域 R_supp, 版本)。
4. **查询接口**：GenCert(c) 返回 CERTIFIED / UNKNOWN / UNCERTIFIED 三态，附带最近标定点与半径；支持域外一律 UNKNOWN。

### 2.3 IP-62 GEN-GAIT-ACQUISITION（GGA，泛化前沿采集与证伪）
1. **任务加权的信息增益**：只对「规划器请求 ∩ 前沿邻域」的上下文计增益，避免采集自嗨。
2. **动作库**：调步态参数试跑（仿真/护盾下实机）、地形探针、云端仿真、人工示范；全部走第 43 轮 A_adm 安全护盾。
3. **证伪 holdout**：固定比例预算做分层 holdout，专打「预测认证」的边界；失败样本强制入 EPL、撤销对应证书球、重估 L_gen。
4. **课程联动**：按接触难度（单脚支撑时长、台阶高度、摩擦下降）排序生成步态课程，优先解锁规划器需要但尚未认证的 g。

回退：E96 校准失败 → 缩小 R_supp、提高 ρ_hold、退回经验区间；E97 无收益 → 关闭相位分解，回退第 43 轮全局证书；E98 无可行政 → 扩大 G_safe0 并降级为保守步态；E99 无增益 → 退回不确定度采集；E100 组合失败 → 禁止未认证组合，仅单原语；E101 OOD 失效 → 收紧支持域并提高人审比例；E102 证伪率超标 → 熔断泛化半径、全量回退已认证点。

## 5. 本轮最大风险

**一句话**：最大风险是「泛化半径的空洞化与被误读」——若相位分解后有效 L_gen 仍大、或不变表示丢掉了摩擦/接触等安全关键特征，认证泛化半径会退化为 0，规划器无可行步态而「可用性崩塌」；反过来若把半径外推误当成任意地形担保，又会在未覆盖的接触模式上静默失效，因此 E96/E97/E101 必须作为红线实验，且每条泛化证书必须携带显式适用域与证伪记录。

### IP-57 CBH：基准构建、评测与泄漏防火墙

```
def build_cbs(zoo, calib_set, ood_shards, seed):
    items = []
    items += load_counterexample_zoo(zoo)            # 真实事故 + 对抗搜索
    items += stratify_by_margin_quantile(calib_set)  # 覆盖全谱系
    items += ood_shards
    train, sealed = split(items, seed, sealed_ratio=0.3)
    rotating = rotate_hash(sealed, period='1_round') # 分片轮换
    manifest = sign(version=hash(items), config=seed)
    return CBS(train=train, sealed=sealed, rotating=rotating, manifest=manifest)

def benchmark_eval(cert, CBS, delta=1e-3):
    rec = []
    for it in CBS.sealed:
        m_lo = cert.lower_bound(it.x)                # 预测下界
        m    = realized_margin(it)                   # 真值实测
        rec.append((m_lo, m, cert.decide(it.x), it.truth))
    kappa = mean(m >= m_lo for m_lo, m, *_ in rec)
    gap   = mean(m - m_lo for m_lo, m, d, t in rec if t == SAFE)
    ece   = reliability_ece(pred=[r[0] for r in rec], real=[r[1] for r in rec])
    oc    = roc_curve([r[2] for r in rec], [r[3] for r in rec])
    ci    = confidence_sequence([r[1] < r[0] for r in rec], delta)  # anytime-valid
    return Report(kappa=kappa, gap=gap, ece=ece, oc=oc,
                  violation_upper=ci.upper, version=CBS.manifest)

def leakage_firewall(x, CBS, rho_dup):
    if min_embedding_dist(x, CBS.sealed) < rho_dup: return LEAK
    if trajectory_hash(x) in CBS.sealed_hashes:     return LEAK
    return OK

def gate(report):
    # 门禁：违反上界必须为 0（任何正上界即拒绝上线）
    return report.violation_upper == 0.0 and report.kappa == 1.0
```

### IP-58 SC：结构化证书与误差预算
```
def structure_certificate(cert, sparsity_k, basis):
    # 1. 选基：用证书基（如各约束 barrier）逼近边际
    Phi = select_basis(cert.margin, basis, k=sparsity_k)
    # 2. 活跃集：区间剪枝剔除对当前 x 不可能的约束
    A = lambda x: interval_active_set(cert, x, Phi)
    # 3. 组合契约
    Gc = task_coupling_graph(cert)
    Contract = extract_interface_contract(cert)
    return StructuredCert(Phi=Phi, A=A, G_C=Gc, Contract=Contract)

def structure_error(T, cert):
    if T.kind == 'low_rank':  return sigma_residual(cert, rank=T.rank)   # 尾奇异值
    if T.kind == 'prune':     return certified_prune_bound(cert, T.mask)
    if T.kind == 'quantize':  return qat_conservative_bound(cert, T.bits)
    if T.kind == 'quotient':  return 0.0                                  # 语言等价
    raise ValueError(T.kind)

def allocate_budget(transforms, slack_CBS, reserve=0.1*slack_CBS):
    budget = slack_CBS - reserve
    # 背包：max Σ Δcost_i，s.t. Σ e_i ≤ budget
    return knapsack(transforms, weight=lambda T: structure_error(T, current),
                    value=lambda T: delta_cost(T), capacity=budget)

def apply_structures(cert, chosen):
    total_e = 0.0
    for T in chosen:
        e = structure_error(T, cert)
        cert = T.apply(cert)          # 例如低秩/剪枝/商化
        total_e += e
    assert total_e <= slack_CBS - reserve
    return cert, total_e
```

### IP-59 OCC：最优决策树、保语言商化与结构化压缩
```
def compile_lcs_tree(checks, dist_D, theta, cost):
    # 最优 anytime 决策树：
    #   内部节点 = 证书检查（成本 c_i），叶子 = Nominal/Degraded/SafeStop
    #   目标 min E_D[Σ c_i]，约束：所有叶子 sound（margin ≥ theta）
    #   非对称代价：miss ≫ false_trip，作为叶子代价项
    return ao_star(checks, dist_D,
                   node_cost=cost, leaf_penalty={MISS: 1e6, FALSE_TRIP: 1.0},
                   constraint=lambda leaf: leaf.margin_lo >= theta)

def minimize_automaton_cert_preserving(A):
    # 划分细化：以 (guard 等价类, 目标块) 为签名迭代分裂
    partition = init_partition(A.states)
    while True:
        sig = lambda s: (guard_label_class(s, partition),
                         partition[delta(A, s)])
        new = refine(partition, sig)
        if new == partition: break
        partition = new
    Aq = quotient(A, partition)
    assert language_equiv(A, Aq)      # 保安全语言等价，e_T = 0
    return Aq

def structured_compress_monitor(net, e_budget):
    net2 = structured_prune(net, channel_ratio=0.25)     # 约束级稀疏
    net2 = low_rank_factorize(net2, rank_ratio=0.25)     # 尾奇异值残差
    e = structure_error(PruneT(), net) + structure_error(LowRankT(), net2)
    assert e <= e_budget
    return net2, e

def template_lattice(KB):
    # 偏序格：模板 t1 ⪯ t2 当且仅当 t2 的适用域 ⊆ t1
    # 合并 = 格 join（取更保守的共同上界），差集 = 格差
    join = lambda a, b: least_upper_bound(a, b)
    diff = lambda a, b: lattice_difference(a, b)
    return Lattice(KB, join=join, diff=diff)
```

```
def car_transition_guard_min(Aq, e, x, cert_obj):

def certify_light_v3(x, tree, budget_us):
    node, spent = tree.root, 0.0
    while node.is_internal:
        r = run_check(node.check, x)          # L0 查表 / L1 INT8
        spent += node.cost_us
        if spent > budget_us:
```

## 5. 风险与缓解（增量）

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 基准腐化 / Goodhart：结构优化过拟合封存集，盲区静默失 sound | 高 | 封存分片轮换 + 独立封存 OOD；每步变换自带独立于 CBS 的 e_T；E87/E94 红线门禁 |
| 误差预算被低估：e_T 计算过乐观导致 Σe_T 实际超支 | 高 | e_T 由可验证上界给出（尾奇异值/剪枝界/QAT 界）；reserve 预留 10% 松弛；超支即撤销变换 |
| 活跃集误判：把非活跃约束当零贡献，实际触发 | 高 | 区间剪枝给出严格不可能性证明；活跃集保守超集；边界附近强制降级重证 |

| 商自动机等价证明实现错误 | 中 | 形式化互模拟检查 + 差分测试；e_T=0 需机器可验证证明，否则退回原自动机 |

## 6. 本轮最大风险

**一句话**：**基准腐化 + Goodhart**——结构优化会精确回收「基准看得见处」的保守性，却在基准的盲区（封存集未覆盖的真实偏移、长尾、跨硬件）静默失 sound，使测得的 κ 上升而真实安全性下降；因此基准只是**门禁而非证明**，必须留出分片轮换 + 封存 OOD + 每个结构变换自带**独立于 CBS 的误差证书**，任一结构变更的 e_T 不可独立验证即视为红线、全链路熔断。
