## 1. 直觉与动机（两个灵感的碰撞）

### 灵感 1 · 在线学习：赛题禁止「改权重」，但允许「改状态」

**直觉**：一看到「在线学习」，多数人的第一反应是「评测时用观测更新模型」——这是诚信红线，也是工程灾难（灾难遗忘、延迟抖动、跨 episode 泄漏）。但机器人控制里的「在线」从来不止一种：卡尔曼滤波、在线系统辨识、SLAM 的局部优化，都是「在线」的，却一行梯度都不算。真正的问题不是「能不能在线学」，而是**在线更新的对象是什么**。

**严谨定义（在线学习三层分解）**：设策略为 `π_θ(a_t | o_{1:t}, ℓ)`。

1. **参数层 `L_θ`**：`θ ← θ − η∇L(o_t)`，评测期改权重。**禁止**（公平性 + 遗忘 + 延迟 + 跨集泄漏）。
2. **状态层 `L_h`**：`h_t = A(h_{t-1}, o_t)`，`θ` 全程冻结，只更新 episode 隐状态（递归估计、记忆、检索缓存）。**允许**，且是本轮唯一采用的形态。
3. **元层 `L_meta`**：离线训练一个「会快速适应」的策略，评测期靠前向上下文适应。允许但重，本轮不做。

**反直觉点**：180 秒 episode 里最值钱的在线信号，不是「适应策略」，而是「估计场景」。因为评测分布未知，但**场景是物理的**——物体的三维位置、桌面的平面、人手的侵入，都是可以用几何在线估计出来的。把「在线学习」翻译成「在线估计」，红线就变成了护城河。

### 灵感 2 · 深度相机：你没有被给深度，但你被给了一只被扔掉的第二目

**直觉**：接口只给 RGB，看起来「没有深度相机」。但事实是：头部左右目是一对**已校正的立体相机**（F34），而官方部署端只读左目、把右目丢进垃圾桶（F32/F33）。这不是缺少传感器，而是**官方主动放弃了一个免费的测距通道**。深度不是「有没有传感器」的问题，而是「能不能从已有观测里推断出来」的问题。

**严谨定义（深度的可推断性）**：对已校正立体对，视差 `d = x_L − x_R`，深度 `Z = fB/d`，其中 `f` 为焦距（像素）、`B` 为基线（米）。误差传播：

`σ_Z = (Z² / (fB)) · σ_d`。

若标定未知，只能得到相似深度 `Z = s·Z̃`；此时用**机器人运动学做度量锚**：夹爪在头部视野中可见时，其 FK 位置 `z_FK` 与立体深度中位数之比即尺度 `s`。单目退化（透明/弱纹理）时，退回「相对深度 + FK 锚定」，并降低置信度。

**反直觉点**：这场比赛里最强的「深度相机」，不是再买一台 D435，而是**被官方丢弃的右目 + 已知的机器人运动学**。它零额外硬件、零额外下载（数据里本来就有右目），只多传一路 0.9MB 的图像。

### 统一：几何层 = 在线估计的载体，深度 = 在线估计的观测量

**直觉**：两个灵感不是并列的两个点子，而是同一个缺失能力的两个侧面——**缺少对「度量三维场景」的在线维护**。没有它，VLA 只能在 2D 外观空间里做统计拟合；有了它，VLA 的末端目标可以被投影到物理可行的度量流形上，人手的侵入可以被当成三维遮挡物检测，透明物体的抓取可以靠几何而不是纹理。

**本轮论点（对 v1.1 的修正）**：v1.1 说「中期胜负手在数据引擎」。本轮修正为：**数据引擎决定上限，几何层决定上限能被兑现多少**。在 5 轴各占 20% 的词典序计分下（F20/F22），几何层直接压的是「位置 / 干扰物 / 人为干扰」三条轴的方差（60% 权重），并通过深度辅助训练外溢到「未见物品」轴。它不替代 I2，而是给 I2 的训练成果装一个「度量稳定器」。

## 2. 对前序痛点的增量修订

- **P2（泛化缺口）**：新增「深度方向不可见」这一子缺口——单目/单视角对沿光轴的位置偏移几乎不敏感，而位置轴恰占 20%。几何层把它变成可观测量。
- **P3（人为干扰）**：从「RGB 手部检测 + 停持」升级为「三维遮挡物分割 + 物体位姿跳变 CUSUM」，恢复段的重规划有了度量依据。
- **P4（无触觉）**：深度/腕部几何提供「接触邻近度」这一伪触觉信号，是 I3 之外的第二条缓解路径。
- **P5（时间压力）**：几何估计只做 reset + 每 k 步一次，不进入每步热路径；深度辅助训练在离线完成，推理零成本。
- **P8（示教质量）**：立体深度可作为「示教几何一致性」的质量维度（轨迹是否在物理可行流形上），并入 I2 的质量加权。
- **新增 P9（几何假设风险）**：整个方案押在「右目是同步、已标定、可用的立体对」上；该假设不成立时，投影会从增益翻转为负迁移（见 §6）。这是本轮第一个必须先验证、再放量的点。

## 3. 研究问题（本轮立项 Q9–Q11，Q1–Q8 保留）

- **Q9（立体可用域）**：在 G1 头部立体对的基线/焦距/同步/校正状态下，桌面 0.4–1.2m 范围内的深度误差分布如何？透明/反光/弱纹理物体的失效比例与可检测性（左右一致性、代价曲线唯一性）如何？
- **Q10（估计结果如何注入冻结 VLA）**：投影（project）、守护（guard）、条件化（conditioning）三种注入方式，在「不重训 VLA」约束下各自的增益/风险边界是什么？置信门控如何避免 `proj_always` 式的负迁移？

# UniBot-V1 参赛创新点清单（第 1 轮 v1.2 · 灵感循环重启）

> 检索日期：2026-11-26（遗产 v1.0）、2026-11-27（遗产 v1.1 与本轮）；来源见 §6。承接 v1.1：I1/I3/I4/I5/I9 深化，**I10/I11 新增**，I2/I6/I7/I8 维持。清单只增改不重置。

## 0. 本轮新增与修订的创新点

### I10 在线几何自标定与动作投影（OGSC）★★★★★

- **一句话**：把官方部署端丢弃的 `cam_right_high`（头部立体右目）变成每 episode 在线维护的度量三维场景；用置信门控把冻结 VLA 的末端目标投影到物理可行流形上，不确定时退回纯 VLA。
- **动机**：评测只给 RGB（F31），官方基线只读 3 路图像、右目直接丢弃（F32/F33），而头部左右目是已校正立体对（F34）。位置轴（20%）、干扰物轴（20%）、人为干扰轴（20%）的失败，很大一部分是「沿光轴深度不可见」「遮挡物没有三维身份」「被移动后不知道物体去哪了」——这些恰是几何层能直接观测的量。
- **与现有方案差异**：
  1. 直接 SFT / 官方基线：3 路 RGB，2D 统计拟合，深度方向不可观；
  2. 盲目加增广：不解决推理期的度量误差；
  3. 换更大模型：成本高、延迟高、仍缺深度；
  4. 本点：**不重训 VLA、不加第二个学习模型**，只在推理期加一个确定性几何层（立体匹配 + 递归估计 + 门控投影/守护）。
- **技术可行性**：中-高。立体匹配用 OpenCV SGBM（CPU 5–10ms @320×448）或模型自带深度头；尺度用 FK 锚定（夹爪在头视野中可见时，`s = z_FK / median(Z̃)`）；物体聚类用「桌面平面 RANSAC + 深度不连续分割」，不需要开放词汇检测器；人手用深度前景/运动分割。全部是确定性算法，不更新权重。
- **所需资源**：无额外数据下载（右目本来就在 32 任务与 110 语料里）；1×GPU 日做离线立体健康度统计；工程 1–2 人周；推理每 k 步一次，预算见 §4。
- **落地步骤**：①E0 立体健康度探针（单任务通道，见 §3）；②离线统计 32 任务的视差有效率/深度噪声；③实现「桌面平面 + 物体簇 + 人手」估计器；④实现 SE(3) 投影与守护；⑤L0 回放消融；⑥L2 单任务通道 A/B；⑦通过后再上 32 任务提交。
- **风险**：透明/反光/弱纹理导致立体失效；右目与左目不同步或未校正；基线过小导致远距深度噪声爆炸；投影到错误目标（语义错，不是几何错）。缓解：左右一致性 + 代价曲线唯一性 + 视差有效率构成置信度 `c`，`c<c0` 强制 VLA-only；投影只做「软吸附」并限幅；与 VLA 分歧过大时触发一次重规划（沿用 I5 的恢复逻辑）。

### I11 深度辅助几何蒸馏（DAGD）★★★★

- **一句话**：离线用立体派生深度给 VLA 的视觉表征加辅助监督，让冻结/半冻结的基座「看见几何」；推理时丢弃深度头，仍是单模型、零额外延迟。
- **动机**：未见物品轴（20%）的域偏移主要在外观（纹理/颜色），而抓取可行性主要由局部几何（宽度、曲率、对偶面）决定。把几何变成视觉特征的一部分，等于缩小外观域偏移的有效距离。
- **与现有方案差异**：纯数据增广改变输入分布但不改变表征的归纳偏置；本点用辅助任务把「几何敏感性」写进表征，且推理不增加任何输入/模型。
- **技术可行性**：中。用立体对离线生成伪深度（无需人工标注，F34/F35），在视觉编码器/DiT 条件通路上挂一个轻量 DPT-style head，损失 = scale-invariant log depth + 左右视图一致性；只训 LoRA + head（官方单卡 24GB 配方，F11）。推理时 head 可丢弃。
- **所需资源**：1×24GB GPU；训练时长 +10–20%；无需额外数据。
- **落地步骤**：①在 32 任务 + 孪生语料上批量生成立体深度；②挂 head + LoRA；③L1 消融（depth-aux on/off）测「位置/外观扰动」下的动作误差；④确认不伤标称后并入主训练。
- **风险**：辅助任务不迁移（负迁移）；伪深度噪声污染表征；透明物体深度本身错误。缓解：先用 L0/L1 小规模验证；损失权重从 0.1 起步；对低置信度像素做 mask。

### 对既有创新点的本轮修订（只列变化）

- **I1 v3 立体一致增广**：v2 的二维「位置重拼接」在立体模式下会破坏极线对应。v3 改为：用深度把图像 lift 到点云，施加同一个 SE(3) 变换后重投影到**左右两目**，并对两目施加**完全相同**的光度扰动；透明/反光区域用深度置信度 mask 掉。这样既保留「按考纲出模拟题」，又保证几何物理一致，直接消解 v2 的「不可行动作占比 >5%」风险。
- **I3 v2 伪触觉**：腕部相机看到夹爪与物体，夹爪几何已知（开度来自 `state.*_gripper`），可用「夹爪指面到物体表面的深度距离」估计接触邻近度；配合头部深度，形成无触觉条件下的接触段回退触发。
- **I4 v2 三维遮挡**：人手进入时，深度图出现新的前景簇且物体位姿发生跳变；用 CUSUM 检测位姿跳变（见 §1.4），比 RGB 手部检测更少受肤色/光照/背景影响。检测到后进入停持→重估→续做。
- **I5 v3 度量进度**：把「学习型进度头」换成/融合「物体到目标的几何距离」这一度量进度；它天然对齐官方得分点的空间里程碑，标签噪声更低，且不需要为每个任务单独训练分类器。
- **I9 v2 几何检索**：检索表示从「外观嵌入」扩展为「外观嵌入 + 形状描述子（深度直方图/点云 FPFH/包围盒比例）」，检索目标从「像不像」改为「怎么抓」；对未见物品轴更稳。

## 1. 关键推导

### 1.1 立体深度误差与可用域

对已校正立体对，`Z = fB/d`，`σ_Z = (Z²/(fB))·σ_d`。取 `f=600px`、`σ_d=0.5px`：

| 基线 B \ 距离 Z | 0.4 m | 0.7 m | 1.0 m |
|---|---|---|---|
| 0.03 m | 4.4 mm | 13.6 mm | 27.8 mm |
| 0.05 m | 2.7 mm | 8.2 mm | 16.7 mm |
| 0.10 m | 1.3 mm | 4.1 mm | 8.3 mm |

对应视差 `d=fB/Z`：B=0.05 时，0.4/0.7/1.0 m → 75/43/30 px；B=0.03 时，0.7/1.0 m → 26/18 px。桌面任务（0.4–1.2 m）在 B≥0.03 m 时视差充足；**精度任务的可用性取决于 B，必须实测**。透明/反光/弱纹理表面会使匹配代价曲线多峰，此时左右一致性（LRC）失败、有效视差比例骤降，正好可作为置信度 `c` 的观测。

### 1.2 投影增益的严格表达

设每阶段 VLA 末端目标误差 `e_v ~ N(0, σ_v² I₂)`，几何估计误差 `e_g ~ N(0, σ_g² I₂)`，容差 `τ`。二维各向同性高斯下：

`P_succ(σ, τ) = 1 − exp(−τ²/(2σ²))`。

| 场景 | τ | σ_v | σ_g | VLA 成功率 | 投影后 | 增益 |
|---|---|---|---|---|---|---|
| 自由放置 | 50 mm | 15 mm | 6 mm | 0.996 | ≈1.000 | +0.004 |
| 一般抓取 | 30 mm | 15 mm | 6 mm | 0.865 | ≈1.000 | +0.135 |
| 精密插入 | 12 mm | 12 mm | 4 mm | 0.393 | 0.989 | **+0.596** |

**关键结论**：几何层的增益高度集中在精密/接触任务；对已经很宽松的自由放置任务几乎无增益。这决定了 I10 的优先级应绑定「精密任务族」（PlugCharger、ArrangeTestTubes、SyringeWaterTransfer、PickOutBatteries 等），而不是全任务平均用力。

**语义偏差的边界**：若误差含系统偏差 `b`（抓错目标/错误朝向），则 `e = b + noise`，投影无法消除 `b`，反而可能「自信地投到错误目标」。因此必须有「VLA 与几何分歧过大 → 不投影/重规划」的止损，而不是 `proj_always`。

### 1.3 计分轴映射（5 轴 × 20%）

| 泛化轴 | 几何层作用机制 | 预期效果 | 证据级别 |
|---|---|---|---|
| 位置（轴1） | 立体深度恢复沿光轴位置；投影消除深度方向误差 | **大**（精密任务最大） | 推导 + 机制仿真 B |
| 干扰物（轴2） | 深度聚类区分目标/干扰物；守护避免碰撞 | 中-大 | 推导 |
| 桌面背景（轴3） | 几何对纹理不敏感 | 小 | 推导 |
| 未见物品（轴4） | I11 几何表征 + I9 几何检索 | 中 | 待 L1 验证 |
| 人为干扰（轴5） | 三维遮挡分割 + 位姿跳变 CUSUM + 重估 | **大（恢复段）** | 推导 + 小规模仿真 |

### 1.4 已有机制仿真与 CUSUM 小检

本地已有一份机制仿真（`exp/twin_proj_results.json`，证据级别 B，**非榜单证据**）恰好隔离了「rectified head stereo + FK 的在线度量孪生投影」：

| 策略 | 总体成功率 | 精密任务 | 自由任务 | 可变形任务 |
|---|---|---|---|---|
| VLA-only | 0.427 | 0.139 | 0.753 | 0.043 |
| verify（分歧重规划） | 0.490 | 0.169 | 0.857 | 0.057 |
| **proj（置信门控投影）** | **0.718** | **0.731** | 0.960 | 0.094 |
| proj_always（无门控） | 0.607 | 0.648 | 0.793 | 0.081 |
| proj_oracle（完美几何） | 0.867 | 1.000 | 1.000 | 0.333 |

两个必须记住的边界：①**门控很重要**——`proj_always` 比 `proj` 低 11 个百分点；②**OOD-G（透明/反光导致几何与 VLA 共享错误先验）下 proj 从 0.718 掉到 0.527**，仍高于 VLA-only，但增益大幅缩水。这与 §1.1 的透明物体失效一致，说明「置信度 + 分歧止损」不是可选项，是主件。

**CUSUM 小检（合成，仅示数量级）**：设无扰动时物体位姿 innovation `~|N(0, 2mm)|`，人为移动造成 30mm 阶跃；取 `k=6mm, h=15mm`，在 3000 条 × 600 帧的合成 episode 中，误报 0 次，检测延迟 ≤1 帧（15Hz 下 ≈66ms）。这意味着 I4 的「停持」可以在人手进入后的 1–2 个控制周期内触发；真实阈值需用单任务通道标定。

## 2. 关键伪代码

### 2.1 立体深度 + 尺度锚定

```python
def metric_depth(left, right, calib, ee_pose=None, gripper_mask=None):
    L, R = rectify_if_needed(left, right, calib)   # eval 若为 raw，需要标定外参
    D = sgbm.compute(L, R).astype(np.float32)      # 视差（像素）
    Z = calib.f * calib.B / np.maximum(D, 1e-3)    # 米
    c = lrc_confidence(D)                          # 左右一致性 + 唯一性 + 有效率
    if not calib.metric and ee_pose is not None and gripper_mask is not None:
        s = ee_pose.z / np.median(Z[gripper_mask]) # FK 锚定尺度
        Z *= s
    return Z, c
```

### 2.2 在线几何估计 + 门控投影/守护（I10 主循环）

```python
class GeoLayer:                     # 确定性模块；不更新任何权重（PR6）
    def reset(self):
        self.x = None               # {plane, objects, hand}
        self.cusum = 0.0
        self.prev_obj = None

    def update(self, obs):
        Z, c = metric_depth(obs.left_high, obs.right_high, self.calib,
                            obs.ee_pose, obs.gripper_mask)
        plane = ransac_plane(Z, obs.cam_K)
        objs  = cluster_above_plane(Z, plane)     # 深度不连续 + 连通域
        hand  = foreground_motion_cluster(Z)      # 人手/遮挡物
        jump  = 0.0 if self.prev_obj is None else dist(objs.target, self.prev_obj)
        self.cusum = max(0.0, self.cusum + jump - K)
        self.disturbed = self.cusum > H
        self.prev_obj = objs.target
        self.x, self.c = {"plane": plane, "objs": objs, "hand": hand}, c
        return self.x, c

    def act(self, obs, vla_chunk):
        x, c = self.update(obs)
        if c < C0 or x is None:
            return vla_chunk, "VLA_ONLY"          # 立体不可信 -> 不投影
        if self.disturbed:
            return hold_and_reestimate(vla_chunk, x), "INTERFERENCE"
        # 只对末端目标做有界软吸附；不做整段轨迹重写
        target = estimate_grasp_target(x)          # 目标物体上的抓取点 + 接近方向
        chunk  = project_ee_target(vla_chunk, target, max_delta=DELTA)
        chunk  = clip_above_plane(chunk, x["plane"])
        chunk  = avoid_clusters(chunk, x["objs"], x["hand"])
        return chunk, "PROJECT"
```
