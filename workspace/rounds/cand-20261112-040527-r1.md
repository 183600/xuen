# 第 60 轮（承接第 59 轮「执行接地层」IP-145~151；灵感循环第 6 轮；本轮灵感：「排行榜」×「意图识别」）

> 第 59 轮把「执行接地」做到了极致：BUQ 在线辨识电机结构性不确定性、ERTC 把嵌入式实时性契约化、EEIS 把概率安全界编译成阻抗参数+证书、CLEP 双向闭环、PCE+++ 四预算耦合。但整条链仍有一个**从未被审计的起点**：它假设「要执行什么意图」是给定的——任务、检查点、目标由人类或规划器以**单点**形式提供。真实具身场景里，意图是**潜变量**：多意图并存、语言模糊、随交互修订、随环境漂移。**证据层与执行层再精确，若意图错了，整套安全论证只是在错误目标上的「自洽幻觉」。** 本轮两个灵感精准击中这个**意图抽象泄漏**：**意图识别**把「意图」还原为需要推断、需要主动消歧、需要检测漂移的**后验对象**；**排行榜**把「选哪个意图/策略」还原为**带统计保证的排序问题**，并暴露一个致命陷阱——**Goodhart 榜单过拟合**：当系统拿排行榜指标优化自身，指标会被玩坏，排名越漂亮、真实安全越差。本轮核心命题：**「把意图从单点给定升级为带置信集的意图排行榜；把排行榜从评测工具升级为安全排序协议；只允许在排序稳定且通过抗操纵审计时承诺。」**

核心矛盾：
- **H32（意图单点假设·目标层抽象泄漏）**：前 59 轮所有 δ_f、证据门、承诺都条件于「意图 ι 已知」。但 p(ι|e) 本身有熵；当 top-1 与 top-2 的效用差落在统计噪声 + 模型不确定性之内，任何「按 top-1 承诺」都是**脆弱承诺（fragile commitment）**。安全必须显式包含 **P(ι₁ ≠ ι_true)**，而不是把它当作 0。
- **H33（排行榜 Goodhart·代理指标反噬）**：系统用 ECE、成功率、排序稳定指数等**代理指标**做自我评测与策略选择。一旦这些指标进入优化回路，就会出现**榜单过拟合**：in-distribution 指标单调上升，而 hold-out / 对抗意图上的真实安全下降。排行榜从「照妖镜」变成「化妆镜」——而系统会**自信地按被玩坏的榜单承诺**。
- **H34（排序不稳定与意图漂移·承诺时效）**：意图会**中途修订**（人改主意、环境变化、多轮对话补充约束）。若承诺在意图漂移后仍被执行，等价于在**过期目标**上做不可逆动作。需要**排序稳定证书 + 漂移检测 + 脆弱承诺撤销**，且承诺必须绑定「意图版本号」。

## 0. 直觉与动机

**灵感 1（意图识别 → 意图后验与排行榜 ILB）**
直觉：不要问「用户的意图是什么」，要问「在证据 e 下，各意图的后验是多少、排序有多稳」。把意图空间 𝓘 分成**封闭意图库**与**开放未知意图 UNK**；用语言、行为（遥操作/纠正）、上下文（场景/用户画像）、历史交互四路证据做**校准融合**，得到 p(ι|e)。关键洞见：**意图识别的输出不是标签，而是「带置信集的排行榜」**——系统需要知道「我有多确定 ι₁ 排第一」，而不是只知道「我认为是 ι₁」。这直接接上第 53~59 轮的校准（ECE）与共形（ACC）传统：把「意图分类」升级为「意图排序的校准覆盖」。

**灵感 2（排行榜 → 排序统计保证 IRL）**
直觉：排行榜的本质是**在不确定性下做序关系判断**。用 bootstrap / 深度集成给出每个意图的分数分布 s(ι)；用 Bradley-Terry / Plackett-Luce 处理只有成对比较（用户二选一、演示偏好）的场景；用 **split-conformal** 构造 **top-k 置信集** C_k^α，使 P(ι_true ∈ C_k) ≥ 1−α。定义**排序稳定指数 RSI = Δ/τ_margin**（top-1 与 top-2 的间隔除以噪声阈值）；只有 RSI > 1 且 |C₁^α| = 1 才发**排序稳定证书 Cert_rank**。这把「我觉得是这个意图」变成「我能证明这个意图以 1−δ 概率排第一」。

**灵感 3（排行榜的反面 → 抗 Goodhart 审计 LAG）**
直觉：排行榜一旦成为优化目标就会被操纵。系统必须对自己的评测做**元评测**：维护 hold-out 意图分布、注入**对抗意图**（专门让代理指标好看、真实安全变差的意图）、监测 in-distribution 与 hold-out 的**排序反转率**（Kendall τ）、监测 **Goodhart 间隙 G = m − S_holdout**。若「指标升而 hold-out 安全降」持续出现 ⇒ 触发 Goodhart 告警：代理指标降权、依赖该指标的承诺冻结、扩大 hold-out、重新校准。**排行榜必须先通过「自己没被玩坏」的审计，才有资格给承诺排序。**

**灵感 4（意图漂移 → 脆弱承诺撤销 IDD）**
直觉：意图是时变量。用贝叶斯在线变点 / CUSUM 监测 p(ι|e_{1:t}) 的漂移：KL 散度或对数预测似然突变超阈 ⇒ 漂移告警。漂移时：撤销 Cert_rank、把在途承诺标记为**脆弱**、重跑主动消歧；若已进入不可逆承诺窗口，则**冻结后续步骤并请求确认**（而不是硬着头皮执行）。承诺绑定「意图版本号」，版本一变旧承诺自动失效。

**灵感 5（合流 → 意图榜单层 ILL 与 CLEP+）**
直觉：把意图层叠在证据/执行层**之上**：CLEP+ = 意图后验 → 排行榜 →（不稳定则主动消歧）→ Cert_rank → 现有 CLEP（BUQ/ERTC/EEIS）→ 承诺绑定 (ι₁, Cert_rank, Cert_eeis, intent_version)。三条安全单向通道向上延伸：**意图更不确定 ⇒ 排序更不稳 ⇒ 承诺更少/更软/更爱提问**；**榜单被玩坏 ⇒ 指标降权、动作保守**；**意图漂移 ⇒ 撤销承诺**。绝不出现「排序更自信 ⇒ 承诺更激进」的反向通道。

## 1. 形式化定义（增量：定义 153–160）

**定义 153（意图空间与校准后验）** 意图 ι=(g,c,s,rev,h)∈𝓘：g 目标、c 约束、s 成功判据、rev 可逆等级、h 时域。𝓘=𝓘_closed ∪ {UNK}。证据 e=(e_lang,e_beh,e_ctx,e_hist)。后验：
```
p(ι|e) ∝ p₀(ι)·L_lang(e_lang|ι)^{w_l}·L_beh(e_beh|ι)^{w_b}·L_ctx(e_ctx|ι)^{w_c}·L_hist(e_hist|ι)^{w_h}
p(UNK|e) = σ_ood(energy(e))
```
权重 w 由各证据源可靠性 ρ 归一化得到，p₀ 为用户画像/场景先验。校准契约：对任意 ι，|P̂(ι_true=ι | p(ι|e)=q) − q| ≤ ε_intent（ECE 意义下）。

**定义 154（意图排行榜与 top-k 置信集）** 对每个意图定义分数
```
s(ι) = Û(ι) − λ·R̂(ι),   Û = E_{p(θ)}[U(ι,θ)],   R̂(ι) = δ_f(ι) + ρ_infeas(ι)
```
其中 Û 为期望任务效用，R̂ 为失效概率加执行不可行惩罚（调用第 59 轮 EEIS 的 K_safe 非空指示）。用 B 个 bootstrap/集成样本得 {s^(b)(ι)}，估计均值 s̄(ι)、标准差 σ_s(ι)、排序分布 p(rank(ι)=r)、成对占优概率 π_ij = P(s(ι_i) > s(ι_j))。**top-k 置信集**：
```
C_k^α = { ι : P̂(rank(ι) ≤ k) ≥ 1 − α_k }
```
α_k 由 split-conformal 在意图校准集上取非一致性分数 1−P̂(rank≤k) 的 (1−α) 分位数确定，保证边际覆盖 P(ι_true ∈ C_k) ≥ 1−α。

**定义 155（排序稳定证书 Cert_rank）** Cert_rank=(ι₁, Δ, RSI, |C₁^α|, π₁₂, unk_mass, audit_id, intent_version)。通过条件：
```
(1) |C₁^α| = 1                     # top-1 集合为单点
(2) Δ = s̄(ι₁) − s̄(ι₂) > τ_margin
    τ_margin = z_{1−α/2}·√(σ_s(ι₁)² + σ_s(ι₂)²) + q_conf + γ_model·σ_model
(3) π₁₂ ≥ 1 − δ_rank               # 成对占优概率
(4) p(UNK|e) < δ_unk               # 开放集未知不占优
(5) LAG 审计通过（定义 157）
RSI = Δ / τ_margin > 1
```
q_conf 为分离度在零假设下的共形分位数，σ_model 来自第 59 轮 BUQ 的执行不确定性传播，γ_model 为其敏感系数。**只有五条全过才发证**；任何一条不过 ⇒ 不得进入不可逆承诺。

**定义 156（主动意图消歧 AID）** 候选查询 π∈Π_intent（提问、请求演示、安全试探动作、展示候选计划让用户选）。意图 VOI：
```
voi_intent(π) = E_{o∼π}[ H(p(ι|e)) − H(p(ι|e,o)) ] − λ_c·cost(π) − λ_r·Risk(π)
```
选 π* = argmax voi_intent，仅当 voi_intent(π*) > θ_intent 且 π* **安全**（可逆、力 ≤ F_safe、不触发不可逆承诺）时执行。消歧预算 B_intent 独立于 B_probe，可向 B_probe 借但借还记账。目标不是最大化熵减，而是**最大化 RSI 增量**——因为承诺只认 RSI。

**定义 157（榜单抗 Goodhart 审计 LAG）** 代理指标 m=(ECE, success_rate, RSI)；真实安全 S 用 hold-out 意图分布 D_ho 与对抗意图集 𝓘_adv 估计。审计量：
```
τ_K   = Kendall τ(rank_Din, rank_Dho) ≥ ρ_min        # 排序反转率
G_t   = m_t − S_ho,t ；禁止「Δm>0 ∧ ΔS_ho≤0」持续 W 窗口
r_adv = |{ι_adv : 注入后 m↑ ∧ S↓}| / |𝓘_adv| ≤ δ_adv
```
任一失败 ⇒ LAG 告警：λ_metric ← λ_metric·β (β<1)，冻结依赖 m 的承诺，扩 hold-out，重校准；**告警未清除前 Cert_rank 条件(5) 不通过**。

**定义 158（意图漂移检测 IDD）** 以窗口 W 计算
```
KL_t = KL( p(ι|e_{1:t}) ‖ p(ι|e_{1:t−W}) )
g_t  = max(0, g_{t−1} + ℓ_t − κ)      # CUSUM 累积对数预测似然比
漂移 ⇔ KL_t > θ_KL ∨ g_t > θ_CUSUM
```
检测延迟 ≤ N_detect；漂移 ⇒ 撤销 Cert_rank、在途承诺标 fragile、intent_version += 1、重跑 AID；不可逆承诺窗口内漂移 ⇒ **冻结并请求确认**。

**定义 159（意图-承诺编译 ICP 与 CLEP+）**
```
CLEP+(M, cp, δ_f_req, budget):
 ① p(ι|e) ← intent_update(M.obs_window)
 ② ILB, C_k^α ← build_leaderboard(p(ι|e), M.risk_model)
 ③ while |C₁^α|>1 or RSI≤1:
      if budget.intent_left≤0: return abstain_or_clarify(M, cp)
      π* ← argmax voi_intent; if π* is None: return abstain_or_clarify(M, cp)
      o ← execute_safe(π*); M ← absorb(M,o); budget.intent_spend()
      p(ι|e) ← intent_update(...); ILB ← rebuild(...); C₁^α, RSI ← recompute(...)
 ④ Cert_rank ← certify_rank(ILB, C₁^α, M.lag_audit)
    if not Cert_rank.passed: return abstain_or_clarify(M, cp)
 ⑤ M, fused, D, EV_exec, Cert_eeis ← closed_loop_exec_probe(M, cp(ι₁), δ_f_req, budget)
 ⑥ return commit(ι₁, Cert_rank, Cert_eeis, intent_version)
```
承诺三元组：**（意图证书 Cert_rank，执行证书 Cert_eeis，意图版本号 intent_version）**，缺一不可。

### IP-152 IntentBeliefUpdater（校准意图后验）

```python
class IntentBeliefUpdater:
    def __init__(self, intent_library, calib_set):
        self.I_closed = intent_library
        self.calib = calib_set
        self.w = {'lang': 1.0, 'beh': 0.8, 'ctx': 0.5, 'hist': 0.6}
        self.temp = 1.0                      # 温度缩放

    def update(self, e, prior=None):
        prior = prior or {i: 1.0/len(self.I_closed) for i in self.I_closed}
        logp = {}
        for i in self.I_closed:
            lp = np.log(prior.get(i, 1e-6))
            lp += self.w['lang'] * np.log(self.L_lang(e.lang, i) + 1e-9)
            lp += self.w['beh']  * np.log(self.L_beh(e.beh, i) + 1e-9)
            lp += self.w['ctx']  * np.log(self.L_ctx(e.ctx, i) + 1e-9)
            lp += self.w['hist'] * np.log(self.L_hist(e.hist, i) + 1e-9)
            logp[i] = lp
        p = softmax(np.array(list(logp.values())) / self.temp)
        p_unk = self.ood_score(e)             # 能量/密度开放集
        return IntentPosterior(dict(zip(logp, (1 - p_unk) * p)), p_unk)

    def calibrate(self, e_calib, y_calib):
        # 温度缩放 + 证据权重再校准，最小化 ECE（约束 ECE ≤ ε_intent）
        self.temp, self.w = fit_temperature_weights(e_calib, y_calib)
```

### IP-153 IntentLeaderboard（排行榜与共形 top-k 集）

```python
class IntentLeaderboard:
    def __init__(self, B=500, alpha=0.05, conf_calib=None):
        self.B, self.alpha, self.conf_calib = B, alpha, conf_calib

    def score_samples(self, post, risk_model):
        S = []
        for _ in range(self.B):
            theta_b = post.sample()           # 后验/参数集成采样
            s_b = {}
            for i in post.support():
                U = risk_model.expected_utility(i)
                R = risk_model.delta_f(i) + risk_model.infeasibility(i)
                s_b[i] = U - risk_model.lam * R
            S.append(s_b)
        return S                              # B × M

    def build(self, post, risk_model):
        S = self.score_samples(post, risk_model)
        keys = list(S[0])
        mean = {i: float(np.mean([s[i] for s in S])) for i in keys}
        std  = {i: float(np.std ([s[i] for s in S])) for i in keys}
        rank_dist = {i: np.zeros(len(keys)) for i in keys}
        for s in S:
            order = sorted(keys, key=s.get, reverse=True)
            for r, i in enumerate(order):
                rank_dist[i][r] += 1.0 / self.B
        pi_pair = {(i, j): float(np.mean([s[i] > s[j] for s in S]))
                   for i in keys for j in keys if i != j}
        C1 = self._conformal_topk(rank_dist, k=1, alpha=self.alpha)
        return ILB(mean, std, rank_dist, pi_pair, C1, post.p_unk)

    def _conformal_topk(self, rank_dist, k, alpha):
        scores = {i: 1.0 - rank_dist[i][:k].sum() for i in rank_dist}
        if self.conf_calib is None:
            return {i for i, sc in scores.items() if sc < alpha}
        q = np.quantile(self.conf_calib, 1 - alpha)
        return {i for i, sc in scores.items() if sc <= q}
```

### IP-154 RankStabilityCertifier（排序稳定证书）

```python
class RankStabilityCertifier:
    def __init__(self, alpha, delta_rank, delta_unk, tau_conf, gamma_model):
        self.alpha, self.delta_rank, self.delta_unk = alpha, delta_rank, delta_unk
        self.tau_conf, self.gamma_model = tau_conf, gamma_model
        self.version = 0

    def certify(self, ILB, lag_audit):
        order = sorted(ILB.mean, key=ILB.mean.get, reverse=True)
        i1, i2 = order[0], order[1]
        Delta = ILB.mean[i1] - ILB.mean[i2]
        tau = (z(1 - self.alpha / 2) * np.sqrt(ILB.std[i1]**2 + ILB.std[i2]**2)
               + self.tau_conf + self.gamma_model * ILB.sigma_model)
        RSI = Delta / max(tau, 1e-9)
        passed = (len(ILB.C1) == 1 and i1 in ILB.C1 and RSI > 1.0
                  and ILB.pi_pair[(i1, i2)] >= 1 - self.delta_rank
                  and ILB.p_unk < self.delta_unk and lag_audit.passed)
        self.version += 1
        return RankCertificate(i1, Delta, RSI, len(ILB.C1),
                               ILB.pi_pair[(i1, i2)], ILB.p_unk,
                               lag_audit.audit_id, self.version, passed)
```

### IP-155 ActiveIntentDisambiguator（VOI 主动消歧）

```python
class ActiveIntentDisambiguator:
    def __init__(self, theta_intent, kappa, F_safe):
        self.theta, self.kappa, self.F_safe = theta_intent, kappa, F_safe

    def select(self, ILB, budget):
        best, best_voi = None, -np.inf
        for pi in self.candidate_queries(ILB):
            if not self.is_safe(pi):          # 可逆、力≤F_safe、不触发不可逆
                continue
            dH   = self.expected_entropy_drop(pi, ILB)
            dRSI = self.expected_rsi_gain(pi, ILB)
            voi = max(dH, self.kappa * dRSI) - self.cost(pi) - budget.shadow_price()
            if voi > best_voi:
                best_voi, best = voi, pi
        return best if best_voi > self.theta else None
```

### IP-156 LeaderboardAuditor（抗 Goodhart 审计）

```python
class LeaderboardAuditor:
    def __init__(self, rho_min, delta_adv, W=20, beta=0.5):
        self.rho_min, self.delta_adv, self.W, self.beta = rho_min, delta_adv, W, beta
        self.G, self.alarm, self.lambda_metric = [], False, 1.0

    def audit(self, m_t, S_ho_t, rank_in, rank_ho, adv_results):
        tau_k = kendalltau(rank_in, rank_ho).statistic
        cond_tau = tau_k >= self.rho_min
        cond_adv = np.mean(adv_results) <= self.delta_adv
        self.G.append(m_t - S_ho_t)
        cond_goodhart = not self._sustained_gap_increase(self.W)
        passed = cond_tau and cond_adv and cond_goodhart
        if not passed:
            self.alarm = True
            self.lambda_metric *= self.beta      # 代理指标降权
            freeze_metric_dependent_commitments()
            expand_holdout_set()
        return AuditResult(passed, tau_k, self.G[-1], cond_adv, self.alarm)

    def _sustained_gap_increase(self, W):
        if len(self.G) < W + 1:
            return False
        dg = np.diff(self.G[-W:])
        return bool(np.mean(dg) > 0 and np.min(dg) > 0)
```

### IP-157 IntentDriftDetector（意图漂移）

```python
class IntentDriftDetector:
    def __init__(self, W=10, theta_kl=0.5, theta_cusum=8.0, kappa=0.5):
        self.W, self.theta_kl, self.theta_cusum, self.kappa = W, theta_kl, theta_cusum, kappa
        self.g = 0.0

    def update(self, post_t, post_tW, ell_t):
        kl = kl_divergence(post_t, post_tW)
        self.g = max(0.0, self.g + ell_t - self.kappa)
        drift = (kl > self.theta_kl) or (self.g > self.theta_cusum)
        if drift:
            self.g = 0.0
        return DriftEvent(drift, kl, self.g)
```

```python
def clep_plus(M, cp, delta_f_req, budget):
    # ① 意图后验
    M.intent_belief = M.intent_updater.update(M.obs_window)
    # ② 排行榜
    ILB = M.leaderboard.build(M.intent_belief, M.risk_model)
    # ③ 不稳定则主动消歧
    while len(ILB.C1) > 1 or ILB.RSI <= 1.0:
        if budget.intent_left <= 0:
            return abstain_or_clarify(M, cp, "intent_ambiguous")
        pi = M.aid.select(ILB, budget)
        if pi is None:
            return abstain_or_clarify(M, cp, "no_safe_query")
        o = execute_safe(pi); M = absorb(M, o); budget.intent_spend()
        M.intent_belief = M.intent_updater.update(M.obs_window)
        ILB = M.leaderboard.build(M.intent_belief, M.risk_model)
    # ④ 排序稳定证书 + 抗 Goodhart 审计
    cert_rank = M.rank_certifier.certify(ILB, M.lag_audit)
    if not cert_rank.passed:
        return abstain_or_clarify(M, cp, "rank_unstable_or_goodhart")
    # ⑤ 接第 59 轮执行接地闭环
    M, fused, D, EV_exec, cert_eeis = closed_loop_exec_probe(
        M, cp.with_intent(cert_rank.i1), delta_f_req, budget)
    # ⑥ 承诺绑定意图证书 + 执行证书 + 版本
    return commit(cert_rank.i1, cert_rank, cert_eeis, M.intent_version)

def abstain_or_clarify(M, cp, reason):
    # 保守动作：请求澄清 / 展示候选计划 / 安全停（绝不按 top-1 硬承诺）
    if M.operators.active.auth >= 'A1' and M.operators.active.mu_mis <= theta_mis:
        return request_clarification(cp, M.intent_belief.top_candidates(k=3), reason)
    return safe_stop(cp, reason)
```

### IP-153 IntentLeaderboard（排行榜与共形 top-k 集）

```python
class IntentLeaderboard:
    def __init__(self, B=500, alpha=0.05, conf_calib=None):
        self.B, self.alpha, self.conf_calib = B, alpha, conf_calib

    def score_samples(self, post, risk_model):
        S = []
        for _ in range(self.B):
            theta_b = post.sample()
            s_b = {}
            for i in post.support():
                U = risk_model.expected_utility(i)
                R = risk_model.delta_f(i) + risk_model.infeasibility(i)
                s_b[i] = U - risk_model.lam * R
            S.append(s_b)
        return S

    def build(self, post, risk_model):
        S = self.score_samples(post, risk_model)
        keys = list(S[0])
        mean = {i: float(np.mean([s[i] for s in S])) for i in keys}
        std  = {i: float(np.std ([s[i] for s in S])) for i in keys}
        rank_dist = {i: np.zeros(len(keys)) for i in keys}
        for s in S:
            for r, i in enumerate(sorted(keys, key=s.get, reverse=True)):
                rank_dist[i][r] += 1.0 / self.B
        pi_pair = {(i, j): float(np.mean([s[i] > s[j] for s in S]))
                   for i in keys for j in keys if i != j}
        C1 = self._conformal_topk(rank_dist, k=1, alpha=self.alpha)
        return ILB(mean, std, rank_dist, pi_pair, C1, post.p_unk,
                   sigma_model=post.sigma_model)

    def _conformal_topk(self, rank_dist, k, alpha):
        scores = {i: 1.0 - rank_dist[i][:k].sum() for i in rank_dist}
        if self.conf_calib is None:
            return {i for i, sc in scores.items() if sc < alpha}
        q = np.quantile(self.conf_calib, 1 - alpha)
        return {i for i, sc in scores.items() if sc <= q}
```

```python
class RankCertificate:

class RankStabilityCertifier:
    def __init__(self, alpha, delta_rank, delta_unk, tau_conf, gamma_model):
        self.alpha, self.delta_rank, self.delta_unk = alpha, delta_rank, delta_unk
        self.tau_conf, self.gamma_model = tau_conf, gamma_model
        self.version = 0

    def certify(self, ILB, lag_audit):

        i1, i2 = order[0], order[1]
        Delta = ILB.mean[i1] - ILB.mean[i2]
        tau = (z(1 - self.alpha / 2) * np.sqrt(ILB.std[i1]**2 + ILB.std[i2]**2)
```

```python
class ActiveIntentDisambiguator:
    def __init__(self, theta_intent, kappa, F_safe):
        self.theta, self.kappa, self.F_safe = theta_intent, kappa, F_safe

    def candidate_queries(self, ILB):
        # 提问（澄清目标/约束）、请求演示、安全试探、展示候选计划让用户选
        return (self.questions(ILB) + self.demo_requests(ILB)
                + self.safe_probes(ILB) + self.plan_selection(ILB))

    def select(self, ILB, budget):
        best, best_voi = None, -np.inf
        for pi in self.candidate_queries(ILB):
            if not self.is_safe(pi):
                continue
            dH   = self.expected_entropy_drop(pi, ILB)
            dRSI = self.expected_rsi_gain(pi, ILB)
            voi = max(dH, self.kappa * dRSI) - self.cost(pi) - budget.shadow_price()

                best_voi, best = voi, pi
        return best if best_voi > self.theta else None

    def is_safe(self, pi):
        return (pi.reversible and pi.force_bound <= self.F_safe
                and not pi.triggers_irreversible_commitment)
```

```python
        self.rho_min, self.delta_adv, self.W, self.beta = rho_min, delta_adv, W, beta
        self.G, self.alarm, self.lambda_metric = [], False, 1.0
        self.audit_id = 0

    def audit(self, m_t, S_ho_t, rank_in, rank_ho, adv_results):
        tau_k = kendalltau(rank_in, rank_ho).statistic
        cond_tau = tau_k >= self.rho_min
        cond_adv = np.mean(adv_results) <= self.delta_adv
        self.G.append(m_t - S_ho_t)
        cond_goodhart = not self._sustained_gap_increase(self.W)
        passed = cond_tau and cond_adv and cond_goodhart
        if not passed:
            self.alarm = True
            self.lambda_metric *= self.beta
            freeze_metric_dependent_commitments()
            expand_holdout_set()
        self.audit_id += 1
        return AuditResult(passed, tau_k, self.G[-1], float(np.mean(adv_results)),
                           self.alarm)

    def _sustained_gap_increase(self, W):
        if len(self.G) < W + 1:
            return False
        dg = np.diff(self.G[-W:])
        return bool(np.mean(dg) > 0 and np.min(dg) > 0)
```

```python
            self.g = 0.0
            self.intent_version += 1
            invalidate_rank_certificates()
            mark_inflight_commitments_fragile()
        return DriftEvent(drift, kl, self.g)
```

```python
@dataclass
class IntentCertificate:
    posterior_traj: list          # 每窗口意图后验
    cert_rank_chain: list         # 排序稳定证书链
    ILB_snapshots: list           # 排行榜快照

    linked_J_exec: list           # 与执行证书交叉引用

        # 1. 版本单增
        for a, b in zip(self.cert_rank_chain, self.cert_rank_chain[1:]):
            if b.intent_version <= a.intent_version:

        # 2. 所有证书 passed 且 RSI > 1

            return False

        return all(c.intent_version == self.intent_version
                   for c in self.cert_rank_chain[-1:])
```

| 组件 | 时间 | 空间 | 正确性保证 |

| J_intent | O(1)/承诺追加 | O(承诺数) | 版本单增、证书 passed、LAG 通过、版本对齐 |

**正确性定理（Intent-Grounded Commitment Soundness, IGCS）**
假设 A22–A55（第 53–59 轮）成立；新增 A56–A60：
**(A56)** 意图后验校准诚实：ECE ≤ ε_intent；开放集 UNK 质量诚实、漏检 ≤ δ_unk。
**(A57)** 排序估计一致：bootstrap/Bradley-Terry 分数分布收敛；split-conformal top-k 边际覆盖 ≥ 1−α。
**(A58)** AID 查询安全且诚实：可逆、力 ≤ F_safe、观测无操纵；VOI 为真实信息增益的诚实下界。
**(A59)** LAG 审计有效：hold-out 与 in-distribution 排序相关 ≥ ρ_min 时，代理指标为 ρ_min-一致代理；对抗注入能发现 ≥ 1−δ_adv 的操纵模式。
**(A60)** IDD 检测有效：漂移检测延迟 ≤ N_detect，误报 ≤ δ_drift。
则：
1. **意图健全性**：若 Cert_rank 通过，则 P(ι_true = ι₁) ≥ 1 − δ_intent，δ_intent = δ_rank + δ_unk + δ_lag + δ_audit；C₁^α 覆盖 ≥ 1−α。
2. **抗 Goodhart 健全性**：若 LAG 通过，则 |m − S| ≤ (1−ρ_min)·range(S) + δ_adv；依赖被操纵指标的承诺被冻结，不得发 Cert_rank。
3. **脆弱承诺单调性**：意图熵 ↑ ⇒ RSI ↓ ⇒ 承诺概率 ↓（严格不增）；不存在「排序更自信 ⇒ 动作更激进」通道。
4. **漂移安全**：漂移在 N_detect 内检出 ⇒ 在途脆弱承诺被撤销；不可逆承诺窗口内漂移 ⇒ 冻结并请求确认，不执行后续步骤。
5. **终止性**：CLEP+ 在 k_intent + k_probes + k_cons + k_ft + k_ux + k_exec 内终止于 {承诺(带 Cert_rank∧Cert_eeis), 请求澄清, 绕行, 降档, L2 协商, 安全停}。
6. **部署界**（对检查点取联合界）：
```
P_safe ≥ 1 − Σ_cp ( 第 59 轮全部项
                   + δ_intent·1[Cert_rank] + δ_unk·1[开放意图]
                   + δ_drift·1[意图漂移] + δ_lag·1[Goodhart 告警]
                   + δ_aid·1[AID 查询不安全] )
         − P(意图空间不可枚举导致 top-1 自信错误) − P(榜单审计自身被操纵)
```

关键：**意图识别输出「带共形置信集的排行榜」而非标签**；**排行榜是「稳定 + 抗操纵」才允许承诺的安全协议**；**LAG 让系统对自己的代理指标保持怀疑**；**IDD 让承诺绑定意图版本、过期即废**。三条安全单向通道延伸到目标层：**意图更不确定 ⇒ 排序更不稳 ⇒ 承诺更少/更软/更爱提问；榜单被玩坏 ⇒ 指标降权、动作保守；意图漂移 ⇒ 撤销承诺**。

## 6. 本轮最大风险

**一句话**：本轮把「意图」从给定单点升级为「带共形置信集的排行榜」，但**整个方案建立在「真实意图落在可枚举意图空间 𝓘 内」这一开放世界假设上**——若真实意图根本不在 𝓘（开放意图、复合意图、对抗性误导意图），则 top-1 置信集可以「高置信地错」，排行榜反而成为**虚假的安全神谕**；再叠加 Goodhart 审计自身也可能被更强的优化压力操纵（系统学会「稳定地自信犯错」以通过 RSI 与覆盖审计），必须以「UNK 质量硬门 + 开放意图拒识 + 对抗意图注入 + hold-out 排序反转监测 + 意图版本漂移撤销」五重护栏，宁可频繁请求澄清、显得「又慢又烦」，绝不允许「排行榜漂亮但意图错误」。
