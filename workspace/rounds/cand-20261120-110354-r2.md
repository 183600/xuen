# 第 2 轮（UniBot 线 · 第 2 轮；本轮灵感：「数据规模」×「联邦学习」）

> **本轮性质**：不是推倒重来，而是对第 1 轮做一次**认识论修正 + 机制升级**。第 1 轮的三层栈（接地/技能/适应/工程）保留；但两条核心量化依据（Kendall τ≈0.064、oracle +4.26）所依赖的 teaser 表被其生成脚本自证为"randomly-generated"，因此本轮先把"技能异质性"当作**待检验假设**而非既成事实，再用联邦学习的 non-IID 个性化理论重写技能层，用"数据规模=覆盖"重写接地层的数据来源。
> **编号**：沿用 U1–U12 / L1–L7 / E601–E618；本轮新增 U13–U20 / L8–L13 / E619–E636。IP-01 保留为"朴素个性化"消融基线，主推 IP-09。

## 0. 第 1 轮基线的压缩保留（供本轮对照）

- 路线：接地层（抓握隐变量）→ 技能层（任务×阶段 token 专家混合）→ 适应层（上下文调制）→ 工程层（chunk 缝合/延迟/端口隔离）。
- MVP：IP-06 代理评测 + IP-02 抓握确认 + IP-03 chunk 缝合 + 通用 VLA 基线。
- 已识别的最大风险：抓握漏判把可救失败变硬失败；间接标签在未见物体上漂移。

## 1. 直觉（两个灵感的第一性原理）

### 灵感 1 ·「数据规模」→ 规模不是"数量"，是"对失败流形的覆盖"

**直觉**：32k episodes / 169 h 听起来很多，但摊到 32 个任务每个只有约 1k 条，且**几乎全是成功示范**。机器人真正会死的地方——没抓住、滑移、对不准、插不进、释放时带倒——在数据里**几乎没有正样本**。于是"再采更多成功示范"对决策边界的边际收益很低；真正缺的是**失败与恢复的覆盖**。

**两条推论**：
1. **规模律要按任务诊断**：在 1k 量级上，有的任务加数据就涨（data-limited），有的任务加数据不涨、换结构才涨（capacity/structure-limited）。不诊断就统一"堆数据/堆参数"，是把预算扔进黑洞。
2. **负样本可以"合成"而非"采集"**：成功轨迹里天然含有"抓握前/抓握中/抓握后"的时序结构，用**时间反事实**（把 t 时刻的视觉与 t+Δ 的夹爪状态错配）和**位姿/时刻扰动重放**可以低成本造出 hard negatives。这是"数据规模"的杠杆：不是多采，而是**重排与反事实**。

### 灵感 2 ·「联邦学习」→ 32 个任务就是 32 个 non-IID client

**直觉**：联邦学习最核心的难题不是通信，而是**客户端数据非同分布（non-IID）**。第 1 轮观察到的"任务间强弱近乎准正交"，如果为真，就是极端 non-IID。联邦学习对此的答案不是"训一个更大的全局模型"，而是四件事：
1. **共享表示 + 本地个性化**（Ditto：一个全局模型 + 每个 client 一个正则化到全局的本地模型）；
2. **近端正则防漂移**（FedProx：本地更新加 ‖θ−θ_global‖²，抑制小样本 client 跑飞）；
3. **客户端聚类**（clustered FL：先按表示相似度分组，再组内联邦，组间不共享）；
4. **leave-one-client-out 评测**：留出一个 client 检验共享表示对**未见 client** 的迁移。

**映射到 UniBot**：32 个任务 = 32 个 client；"单 checkpoint 通才" = "一个全局模型 + 个性化模块"；"每专家至少服务 2 个任务" = "聚类数 K 由数据选，而非拍脑袋"；"留出物体/背景/位置" = "leave-one-task-out"。

**关键校正**：第 1 轮把"任务 token 选 32 个专家"当成默认解，这在每任务约 1k 样本上必然过拟合（每个专家只见到 1k 条）。联邦学习告诉我们：**个性化要受数据量约束**，小样本 client 只能做低维/低秩个性化，且必须先**检验异质性是否真实**——否则个性化就是在拟合噪声。

### 合成

> **数据规模决定"能不能学到失败边界"，联邦学习决定"在哪一层、以什么粒度个性化才不辜负这点数据"。**
> 二者合成一条纪律：**先识别（异质性/规模律），后个性化（聚类/深度），再补覆盖（失败数据）**。

## 2. 对第 1 轮的关键修正（本轮最重要的产出之一）

### 修正 R1（识别性）：+4.26 的 oracle 上界不能证明专长存在

teaser 表由 `gen_leaderboard.py` "randomly-generated"。在一个**可交换零假设**下（8 个模型在 32 个任务上无系统差异，仅任务难度 μ_t 不同、单元格噪声标准差 σ），有：
- 每任务 oracle 的期望 ≈ μ_t + c_M·σ，其中 c_M = E[max of M 标准正态] ≈ 1.424（M=8）；
- 最好单模型（32 任务平均）的期望 ≈ μ̄ + c_M·σ/√T，T=32；
- 于是 **oracle − best_single ≈ c_M·σ·(1 − 1/√T) ≈ 1.172·σ**。

用第 1 轮报告的跨模型任务内标准差 σ≈5.6 代入，纯噪声下该差距的期望约 **6.6 分**，**不小于**观测到的 4.26 分。⇒ 观测到的 oracle 红利完全落在噪声/选择偏差范围内；若还存在"全局模型质量"主效应，差距只会更小。**结论：不能拒绝"无任务专长"的零假设。**

### 修正 R2（可识别性）：单格单观测下，专长方差不可识别

把分数写成 `Y_{m,t} = μ + a_m + b_t + c_{m,t} + ε_{m,t}`。`c_{m,t}`（模型×任务交互 = 专长）与 `ε`（重复噪声）在**每个单元格只有一个数**时完全混淆，`Var(c)` 不可识别。要识别专长，必须有**重复观测**（同一模型-任务多次评测/多种子），或用 per-episode 数据做层次模型。teaser 榜每格只有一个数 ⇒ 从它推"32 维技能向量"在统计上不成立。

### 修正 R3（数据偏置）：成功示范集不能训练失败检测器

抓握/插入的负样本在官方数据中**支持集为零**。仅靠重要性加权无法修正（positivity 不成立：`p_demo(失败区)≈0`，权重无定义）。必须**合成**失败/近失败样本（IP-10），否则 IP-02 的校准在未见物体上无依据。

### 修正 R4（个性化粒度）：手工"每专家≥2任务"改为可检验的聚类数选择

用 clustered FL 的偏差-方差分解选 K，并以 leave-one-task-out 交叉验证定 K，而不是先验约束。

## 3. 研究问题（本轮新增/改写）

- **Q6（异质性识别）**：在 n=8×32 的单格观测下，如何用置换检验/层次方差分解判断专长是否真实？最小可检测交互效应是多少？需要多少重复？
- **Q7（规模律）**：每个任务的 success(n) 曲线形状如何？哪些 data-limited、哪些 structure-limited？跨任务预训练的**有效样本倍率** κ 是多少？
- **Q8（失败数据合成）**：时间反事实 + 扰动重放能否生成**校准的**失败样本，使抓握确认器在未见物体上的 AUROC 不塌？
- **Q9（联邦个性化形态）**：Ditto 式"全局+本地"、聚类 FL、个性化层深度，在单 checkpoint 合规下哪种用最少参数兑现最多迁移？
- **Q10（在线联邦的合规边界）**：评测期 N 端口只共享**无标签统计量**（非梯度、非任务标签）是否违反隔离？跨 episode 聚合是否越界？

## 4. 设计原则（本轮新增/改写）

- **P7 先识别后个性化**：任何个性化结构必须先过异质性检验（置换 p<0.05 或层次模型交互方差显著），否则退回全局模型。负结果也是贡献。
- **P8 数据规模 = 覆盖**：数据预算优先投失败流形（负/恢复样本），而非重复成功示范。
- **P9 个性化深度 ∝ 数据量**：本地参数量随该任务有效样本量线性增长；小样本任务只允许低秩/偏置个性化。
- **P10 联邦只做统计、不做标签**：跨端口/跨 episode 共享仅限无标签统计量，默认关闭，可一键回退。
- **P11 单 checkpoint = 一个全局模型 + 个性化模块**：合规叙述统一为"single global policy with personalization"。

## 5. 本轮 MVP 与退化链（更新）

**MVP = IP-06（代理评测）+ IP-11（规模律诊断）+ IP-10（失败数据引擎）+ IP-02（抓握确认，改用失败增强数据）+ IP-03（工程）+ IP-09（异质性检验与聚类个性化，条件启用）**。

**退化链新增**：
- Level-0'：异质性检验不显著 ⇒ 不做聚类专家，退回**单全局模型 + 轻量 FiLM**（省算力、降过拟合）；
- Level-1'：失败数据合成不可信（校准差）⇒ 抓握确认器只在高置信区间启用，其余退回开环；
- Level-2'：在线联邦统计被判定违规 ⇒ 关闭跨端口/跨 episode 共享，只保留离线 FL 训练范式。

## 6. 预期贡献（可验收）

1. 一个**零假设校准**：给出随机榜单下 oracle 差距的选择偏差闭式/模拟估计，纠正第 1 轮外推（可复现脚本）。
2. 一套**任务级规模律诊断**（data-limited vs structure-limited），指导数据/算力预算。
3. 一个**反事实失败数据引擎**，把成功示范转成校准的失败/恢复样本。
4. 一个**联邦个性化配方**（Ditto + 聚类 + 深度约束），在单 checkpoint 合规下最大化跨任务迁移。
5. 一个**leave-one-task-out 联邦评测协议**，直接测"共享表示对未见任务的价值"。
6. 一份**负结果报告规范**：若异质性不显著，明确记录并据此剪枝，而不是继续堆结构。

## 7. 本轮最大风险（一句话）

**一句话**：本轮最大的风险是"**异质性检验很可能不显著**"——若真实数据上任务专长并不显著（teaser 的 +4.26 只是噪声+选择偏差），则第 1 轮的 IP-01 与本轮的聚类个性化会同时失去依据，整条"技能路由"叙事退化为"单全局模型 + 轻量适配"；我们必须把这个负结果当作可交付的贡献并据此剪枝，而不是继续为一个未识别的假设堆结构。

## 8. 下一轮迭代计划

- **深化**：把 IP-09 的检验与聚类做成标准流程；把 IP-10 的失败数据引擎做成可复现管线；把 IP-06 六因子与 IP-12 leave-one-task-out 合并为统一 OOD 协议。
- **修剪预案**：Q6 不显著 ⇒ 砍 IP-01/聚类，保留全局+FiLM；Q10 不合规 ⇒ 砍在线联邦，仅保留离线 FL 训练；IP-10 校准不达标 ⇒ 抓握确认收缩到少数相位。
- **保留项**：IP-06、IP-10（失败数据版 IP-02 的燃料）、IP-03 三项不砍。

## 2. 新 IP 详述

### IP-09 · FedPersonalize（P0，替代 IP-01 主线）

- **动机**：第 1 轮把"任务专长"当既成事实，但 teaser 表随机生成，且单格单观测使交互方差不可识别（L8/L9）。若不做检验就上 32 专家，等于用 32×1k 样本拟合噪声。
- **与 IP-01 的差异**：IP-01 是"任务 token → 32 专家"；IP-09 是"**检验 → 聚类 → 组内联邦 → 组间不共享 → 深度受 n_t 约束**"。个性化不是默认，而是通过检验后的条件动作。
- **技术可行性**：中–高。检验用置换 + 层次方差分解；聚类用表示相似度（任务间特征分布距离/梯度余弦）；训练用 Ditto（全局 + 本地正则）+ FedProx 近端项。
- **落地步骤**：
  1. **E619 异质性检验**：在本地 per-episode 数据上构造 `Y_{m,t}`（可用不同种子/不同数据子集训练的模型，或不同超参），做置换检验与方差分量估计；给出最小可检测交互效应。
  2. **E620 重复观测**：每模型-任务至少 R≥2 次独立评测（不同 episode 子集/种子），使交互可识别。
  3. **E621 聚类**：以任务表示距离做层次聚类；K 由 leave-one-task-out CV 选（L12）。
  4. **E625 个性化形态对比**：global-only vs Ditto vs per-task experts vs clustered；固定总参数预算比较。
  5. **E626 深度扫描**：FiLM / LoRA rank r / 全专家，验证 d_t ∝ n_t（L10）。
  6. **合规**：单一 global checkpoint + personalization 模块；提供 global-only 降级并实测损失。
- **风险**：①检验功效不足（样本少）⇒ 报告置信区间而非二元结论；②聚类不稳 ⇒ 用 bootstrap 稳定性选择；③个性化过拟合 ⇒ 近端项 + 深度上限 + 早停。

### IP-10 · FailureForge（P0，IP-02 的燃料）

- **动机**：官方数据是成功示范集，失败区支持集为零；重要性加权无法修正（positivity 不成立，L11）。抓握确认器最需要负样本的地方恰是它没有数据的地方。
- **与现有方案的差异**：不是"再采失败"（成本高、不可控），而是从成功轨迹**合成**失败/近失败：
  1. **时间反事实负样本**：把 t 时刻的腕部视觉与 t+Δ 的夹爪状态/EE 速度错配，构造"看起来要抓但还没闭合"的 hard negative；反之构造"已闭合但物体未随动"的失败正样本。
  2. **扰动重放**：对抓握时刻 ±Δt、接近位姿 ±δ、接近速度缩放做扰动；有动力学代理（官方 WMA/学习到的前向模型）时重放并自动标注；无代理时用几何规则 + 腕部光流标注。
  3. **恢复样本**：对"扰动后重抓成功"的轨迹保留为正样本，训练"失败→恢复"状态机。
  4. **校准**：按物体/背景/位置分层做可靠性图与 ECE；对未见物体做 leave-one-object-out。
- **技术可行性**：中–高。时间反事实零成本；扰动重放依赖动力学代理质量。
- **所需资源**：官方数据 + 小算力（检测器单卡数小时）+ 可选 WMA 代理。
- **风险**：①合成分布与真实失败分布不一致（sim-to-real gap）⇒ 用少量真机失败做锚点校准；②时间错配引入伪相关 ⇒ 严格按 episode 分组切分，禁止跨集泄漏；③负样本过多压垮正样本 ⇒ 分层采样 + 损失重加权。

### IP-11 · ScaleProbe（P0，预算分配器）

- **动机**：32 任务每任务约 1k episodes，且难度分层明显（第 1 轮：Stack Cups 30.3 vs Plug In Ethernet 17.7）。统一"堆数据/堆参数"是浪费；需要知道每个任务的边际收益。
- **方法**：
  1. **任务内学习曲线**：对每个任务按 n = 100, 200, 400, 800, 1000 子采样训练（或微调），拟合 `success(n) = a_t − b_t·n^{−c_t}`（或饱和指数），估计斜率与饱和点。
  2. **跨任务有效样本倍率**：在 T−1 任务上预训练，留出任务 t 上用 n 条微调；与从零训练对比，定义 `κ_t = n_eff/n`。
  3. **分类**：斜率大且未饱和 ⇒ data-limited（加数据/加合成数据）；斜率≈0 且低 ⇒ structure-limited（改结构/改动作空间/改原语）。
- **可验收**：学习曲线拟合 R²≥0.9；对 3 个留出任务的外推误差 ≤10%；预算建议能改变实际分配。
- **风险**：子采样训练噪声大 ⇒ 多种子 + bootstrap 置信带；任务难度与数据量混淆 ⇒ 任务内比较，不做跨任务绝对比较。

### IP-12 · FedOOD（P1，评测协议）

- **动机**：第 1 轮的 OOD 切分是"留出物体/背景/位置"，但没有直接测"共享表示对未见任务的价值"。
- **方法**：把 32 任务当 32 client，做 leave-one-task-out：在 31 任务上训练全局表示，在留出任务上少样本微调/零样本评测；与"只在留出任务上训练"对比，得到迁移收益与负迁移风险。与 IP-06 六因子合并：不仅看终态成功，还看迁移发生在哪一因子。
- **风险**：留出任务与训练任务差异过大 ⇒ 分层留出（同簇/跨簇各留几个）；计算量大 ⇒ 只对 P0 任务做。

### IP-13 · FedStatsGuard（P2，合规探针）

- **动机**：字面意义的"评测期联邦"（N 端口共享）有吸引力，但官方要求每端口独立、`reset()` 隔离。
- **方法**：只共享**无标签、预计算的总体统计量**（如视觉特征 running mean/var、延迟分布），加 DP 噪声；绝不共享 per-episode 梯度/状态/任务标签；默认关闭，配置开关；提供端口隔离自检。
- **判据**：Q10 合规答复；隔离测试通过；开启后收益 > 风险才启用。
- **风险**：被判定为"跨端口串扰" ⇒ 默认关；统计量仍可能泄漏任务 ⇒ 只在全局层面聚合，不按端口/任务分桶。

## 3. 符号与定义（新增 U13–U20）

| 符号 | 含义 |
|---|---|
| `H` | 异质性统计量（交互方差比 / 置换统计量） |
| `K` | 任务聚类数 |
| `C_k` | 第 k 个任务簇（client cluster） |
| `d_t` | 任务 t 的个性化参数量（深度预算） |
| `κ_t` | 跨任务预训练的有效样本倍率 |
| `F` | FailureForge 合成算子（时间反事实 + 扰动重放） |
| `s_t(n)` | 任务 t 在 n 条样本下的成功率学习曲线 |
| `LOTO` | leave-one-task-out 评测 |

**定义 U13（异质性统计量）** 令 `Y_{m,t}` 为模型 m 在任务 t 的分数，拟合可加模型 `Y = μ + a_m + b_t + c_{m,t}`。定义 `H = Var(c) / Var(ε)`；在零假设 `Var(c)=0` 下用置换（打乱 m 与 t 的对应）得到 H 的零分布，p 值 = P(H_null ≥ H_obs)。
**定义 U14（聚类个性化）** `π(a|o,ℓ) = E_{k=k(ℓ)}[ V(o,ℓ; θ_global, φ_{C_k}) ]`，其中 `k(ℓ)` 把任务映射到簇 `C_k`，`φ_{C_k}` 为簇级个性化模块；簇内共享，簇间不共享；`K` 由 LOTO CV 选。
**定义 U15（个性化深度预算）** `d_t = min(d_max, ⌊c·n_t⌋)`，`n_t` 为任务 t 的有效样本量；对应 LoRA rank `r_t` 满足 `2·d_model·r_t ≤ d_t`；`c` 由 E626 校准。
**定义 U16（反事实失败算子）** `F(x_t, g_{t+Δ}) = (x_t, g_{t+Δ}, y)`，把 t 时刻观测与 t+Δ 的夹爪/EE 状态错配，标签 y 由"错配后物理一致性"规则或动力学代理给出；另含扰动重放 `F_δ(x, δ)`。
**定义 U17（规模律）** `s_t(n) = a_t − b_t·n^{−c_t}`，`a_t` 为渐近成功率，`c_t` 为数据效率指数；data-limited ⇔ `c_t` 大且 `s_t(n_max) < a_t − ε`。
**定义 U18（有效样本倍率）** `κ_t = n_eff / n`，其中 `n_eff` 为"仅在任务 t 上从零训练达到同等成功率所需的样本量"；`κ_t>1` 表示跨任务预训练带来正迁移。
**定义 U19（leave-one-task-out）** 对每个任务 t，在 `T\{t}` 上训练，评测 t；迁移收益 `Δ_t = s_t^{LOTO} − s_t^{scratch}`。
**定义 U20（联邦统计共享）** 仅共享 `S = Aggregate(无标签统计量)`，不共享梯度/标签/逐 episode 状态；DP 噪声 `N(0,σ²)`，隐私预算 ε；默认关闭。

> U1–U12 沿用第 1 轮定义（π, z_task, z_phase, E_k, g_t, c_t, T_a, φ, Π, Ŝ, L_τ, Ψ）。

def heterogeneity_test(Y, M, T, n_perm=10000):
    # Y: [M, T] scores; H0: no model x task interaction
    def stat(Y):
        mu = Y.mean()
        a = Y.mean(axis=1, keepdims=True) - mu
        b = Y.mean(axis=0, keepdims=True) - mu
        C = Y - mu - a - b
        return (C ** 2).mean() / ((Y - mu) ** 2).mean()   # 交互方差占比
    h_obs = stat(Y)
    null = []
    for _ in range(n_perm):
        Yp = Y.copy()
        for t in range(T):
            Yp[:, t] = np.random.permutation(Yp[:, t])
        null.append(stat(Yp))
    return h_obs, (np.array(null) >= h_obs).mean()

def choose_K(task_embeddings, Y, Ks=range(1, 9)):
    # leave-one-task-out CV over cluster count
    best = (float("-inf"), 1)
    for K in Ks:
        labels = cluster(task_embeddings, K)
        score = loto_cv(labels, Y)
        if score > best[0]:
            best = (score, K)
    return best[1]

def ditto_train(tasks, K, d_budget):
    global_model = init()
    for _ in range(R):
        global_model = fedavg([
            local_step(t, global_model, d_budget[t]) for t in tasks
        ])
    local = {
        t: regularized_finetune(global_model, tasks[t], d_budget[t])
        for t in tasks
    }
    return global_model, local

## 5. 推导（L8–L13）

**引理 L8（专长的可识别性）** 若每个 (m,t) 单元格只有一个观测，则模型×任务交互方差 `Var(c)` 与残差方差 `Var(ε)` 在可加模型下不可分离；任何"技能向量"结论都不可证伪。需要 R≥2 次重复（或 per-episode 层次模型）才能识别。∎

**引理 L9（随机榜单下 oracle 差距的选择偏差）** 在可交换零假设下，`E[oracle − best_single] ≈ c_M·σ·(1 − 1/√T)`，`c_M=E[max of M 标准正态]`。M=8,T=32 时系数 ≈1.172。以 σ≈5.6 计期望约 6.6 分，大于观测 4.26 ⇒ 观测差距不能拒绝零假设。∎

**引理 L10（个性化深度 ∝ 数据量）** 对 d 维适配器、n 条样本，泛化超额风险 `≤ C√(d/n)`。若要求各任务超额风险相同，则 `d_t ∝ n_t`；等价地，LoRA 秩 `r_t ≲ C'·n_t/d_model`。∎

**引理 L11（成功偏置不可用重加权修正）** 设示范分布 `p_demo`、评测分布 `p_eval`。重要性加权 `w=p_eval/p_demo` 仅在 `supp(p_eval) ⊆ supp(p_demo)`（positivity）时无偏。失败区 `p_demo≈0` ⇒ positivity 失败 ⇒ 必须合成负样本（IP-10），不能只重加权。∎

**引理 L12（聚类数 K 的偏差-方差）** 设簇内异质性偏差 `B(K)` 随 K 增大而减小、簇内样本方差 `V(K) ∝ 1/|C_k|` 随 K 增大而增大，则风险 `R(K)=B(K)+V(K)` 存在内点最优；`K` 应由 leave-one-task-out CV 选，而非先验约束。∎

**引理 L13（在线联邦的隔离条件）** 若各端口只读取**全局预计算**的无标签统计量、且 per-episode 状态完全隔离，则 `reset()` 语义与端口独立性保持；若共享 per-episode 梯度/状态，则隔离被破坏，且可能违反官方"每端口独立交互"要求。∎

> **本轮最大风险（一句话）**：异质性检验很可能不显著，届时整条"技能路由"叙事必须体面地退化为"单全局模型 + 轻量适配"，而团队是否愿意接受并执行这个负结果，比任何模型结构都更决定本轮的真实价值。
