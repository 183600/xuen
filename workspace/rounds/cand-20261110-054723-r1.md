# 第 41 轮 · 价值倾斜扩散策略 v1：对齐即约束采样 × 可信集价值证书 × 对齐守护（四层架构 v6）

> 承接第 40 轮（v17：可认证流匹配执行 × 度量语义几何锚定 × 证书驱动课程引擎，四层架构 v5；研究线累计第 41 轮，本灵感循环第 1 轮）。本轮灵感词「扩散策略、价值对齐」把第 40 轮的「可认证执行」推进为「可对齐执行」：不把价值写进奖励项，而把价值写成**生成分布的约束**——在去噪/概率流轨迹上做价值倾斜与可行域投影，并用保形风险控制给出**分布无关**的对齐证书。

## 0. 直觉与动机

**灵感 1（扩散策略 → 生成过程本身就是对齐接口）**：第 40 轮为了「可证」把扩散换成流匹配，但这是一个假两难。扩散与流匹配共享同一条概率流 ODE：前者强调多步去噪的**可干预性**，后者强调误差界。**可认证**解决的是「执行误差有界」，**可对齐**需要的是「每一步都能把样本拉向价值可行域」。分类器/能量引导已经证明：无需重训生成器，只在去噪步加一个价值梯度，就能把动作分布转向。于是扩散策略的最大价值不再是「多模态生成」，而是「推理时可被人类价值实时转向的生成」。这与第 40 轮的 CertFlow 不冲突：用 CertFlow 做基础生成器（负责误差界），用扩散式价值引导做外层对齐（负责价值方向）。

**灵感 2（价值对齐 → 约束而非奖励项）**：现有架构把价值塞进 R_φ 的奖励权重 w₁~w₆，这是奖励塑形，不是对齐。奖励项的本质缺陷是 Goodhart：策略会找到「指标高但价值错」的捷径（快但不安全、任务完成但不礼貌、省电但突兀）。价值对齐的正确对象是**动作分布**，而不是标量回报。两个直接推论：a) 对齐应表达为「KL 最小改动 + 硬可行域」，即信息投影/约束采样，天然抗奖励黑客；b) 价值是**轨迹级**的（不伤害、不冒犯是整段动作块的性质），扩散策略一次生成动作块，正好提供轨迹级约束接口。

**灵感 3（价值不确定性 → 可信集 + 保形证书）**：真实部署中价值不是单点：不同标注者、不同场景、不同文化给出不同 λ；价值模型本身也会错。若用一个点估计 λ 去「对齐」，得到的是「对齐到某个标注者的偏见」。本轮立场是：**价值是一个可信集 Λ_δ，对齐是对 Λ_δ 中所有价值模型都成立**。用 Bradley-Terry 后验/bootstrap 构造 Λ_δ，用保形风险控制（conformal risk control）给约束满足率一个有限样本、分布无关的保证。Λ_δ 越大多保守，就用价值信息增益（VoI）主动问人来收缩它——把「问人」也变成有理论依据的闭环。

**四者耦合**：扩散策略提供「可转向的生成过程」，价值对齐提供「对齐目标」，可信集提供「价值多元的诚实表达」，保形证书提供「分布无关的兑现」。第 40 轮的 CertFlow 是「执行证书」，IP-49 的几何证书是「安全价值的物理锚点」，IP-50 的课程是「对齐边界的进化机制」——本轮把三证书扩成「执行 + 几何 + 对齐」三证合一。

**一句话押注**：第 40 轮让机器人「证得住跑得对」，本轮让机器人「证得住做得对」。

## 1. 形式化定义

**定义 27（价值倾斜扩散策略）**：设基础策略 p_θ(a|s) 由概率流 ODE 实现（复用第 40 轮 CertFlow 生成器），a ∈ A ⊂ R^{H·d_a} 为动作块。价值模型 V_φ: S×A → R^m 输出 m 个价值分量（安全、任务保真、舒适、社交规范、能耗、可解释性），价值剖面 λ ∈ Δ^{m−1}。对齐目标分布定义为

p_{β,λ}(a|s) = p_θ(a|s)·exp(β·λ^T V_φ(s,a)) / Z_{β,λ}(s),

等价于 KL 正则价值倾斜（信息投影）：

p_{β,λ} = argmin_q KL(q(·|s) ‖ p_θ(·|s)) − β·E_q[λ^T V_φ(s,a)].

去噪步的价值引导近似为

∇_{a_t} log p_{β,λ,t}(a_t|s) ≈ ∇_{a_t} log p_{θ,t}(a_t|s) + β·λ^T ∇_{a_t} V_φ(s, â_0(a_t)),

其中 â_0(a_t) 为当前步的一步去噪估计（Tweedie 公式）。β→0 退化为基策略；β→∞ 退化为在 V_φ 上的贪心。**注意：这是分布层面的对齐，不是把 βλ^T V 加进训练回报**。

**定义 28（价值可行域与退火投影采样）**：价值约束 g_j(s,a) ≤ 0, j=1..J（几何 CBF、语义谓词、运动学/动力学界、任务谓词），可行域 K(s) = {a : g_j(s,a) ≤ 0, ∀j}。约束对齐分布

p*_{β,λ}(a|s) ∝ p_θ(a|s)·exp(β·λ^T V_φ(s,a))·1[a ∈ K(s)].

为避免后段投影把样本压到低密度区，采用退火可行域 K_0 ⊇ K_1 ⊇ … ⊇ K_N = K(s)，每步

a_{t−1} = Proj_{K_{N−t}} ( denoise_θ(a_t) + η·β·λ^T ∇V_φ(s, â_0(a_t)) ).

K 为闭凸时欧氏投影唯一且非扩张；非线性约束用 QP/CBF 滤波投影。

**定义 29（对齐证书 CertAlign）**：CertAlign(h) = (β, λ, V_φ, α, δ, ε_val, ρ_align, τ_tax, Λ_δ)，对技能 h 给出四条可核查保证：

- (i) **约束满足**：P_{a~p̂}(g_j(s,a) ≤ 0, ∀j) ≥ 1 − α（保形风险控制：有限样本、分布无关）；
- (ii) **价值间隙**：|E_{p̂}[λ^T V*] − E_{p*}[λ^T V*]| ≤ ε_val（V* 为真实价值，不是代理 V_φ）；
- (iii) **鲁棒半径**：∀λ′ ∈ Λ_δ 且 ‖λ′−λ‖₁ ≤ ρ_align，(i) 仍成立；
- (iv) **对齐税**：E_{p_θ}[R_task] − E_{p̂}[R_task] ≤ τ_tax（为对齐付出的任务性能代价上界）。

其中 p̂ 为实际采样器分布，p* 为定义 28 的理想分布。

**定理 4（对齐间隙界）**：若 (a) V_φ 关于 a 为 L_V-Lipschitz、∇V_φ 为 L_∇-Lipschitz；(b) 分值估计误差 ‖∇log p̂_t − ∇log p_t‖₂ ≤ ε_s；(c) 保形校准给出 |V_φ − V*| ≤ ε_m（覆盖 ≥1−α）；(d) 投影精确且 K 闭凸；(e) 基础生成器满足 CertFlow 的 ε_ode 界。则

W₂(p̂, p*) ≤ C₁·(ε_s + β·L_V·ε_m + ε_ode)，
P_{p̂}(a ∉ K) ≤ α + C₂·(ε_s + β·L_V·ε_m + ε_ode)。

**证明思路**：用 Tweedie/score 分解把引导误差拆成「分值误差 + 价值模型误差×βL_V + 积分误差」三块；投影非扩张性保证可行域误差不被放大；再用保形风险控制的单调性把逐点误差转成期望违约率。该界最重要的含义是：**价值模型误差被 β 线性放大**——这正是奖励黑客的对齐版本。

**命题 2（反 Goodhart 的最优对齐强度）**：设真实价值与代理价值偏差 ‖λ^T(V*−V_φ)‖_∞ ≤ ε_m。对指数倾斜在 β=0 处一阶展开：

d/dβ E_{p_{β,λ}}[λ^T V*] |_{β=0} = Cov_{p_θ}[λ^T V*, λ^T V_φ]
= Var_{p_θ}[λ^T V_φ] + Cov_{p_θ}[λ^T(V*−V_φ), λ^T V_φ].

第二项的量级为 O(ε_m·L_V) 且符号可负，因此存在 β* 使真实价值增益饱和；β>β* 时代理价值继续涨而真实价值不涨——这就是「奖励黑客」的形式化。**推论**：应以保形下界 λ^T V_φ^− 作为优化目标（悲观优化），把误差的线性项压成二阶项；于是 β 从手工超参变成由 ε_m、L_V 和约束裕度共同决定的证书量。

**定义 30（价值可信集与鲁棒对齐）**：偏好数据 D={(s,a⁺,a⁻)}。由 Bradley-Terry/人类反馈维护 (1−δ) 相容集

Λ_δ = { λ ∈ Δ^{m−1} : ∀(a⁺,a⁻)∈D, λ^T(V_φ(s,a⁺) − V_φ(s,a⁻)) ≥ 0 }（在 (1−δ) 置信下）。

价值歧义半径 ρ_amb = diam_{‖·‖₁}(Λ_δ)，在正则条件下随 |D| 以 O(|D|^{-1/2}) 收缩。鲁棒对齐分布

p*_robust = argmin_q max_{λ∈Λ_δ} [ KL(q‖p_θ) − β·E_q λ^T V_φ ]  s.t. ∀λ∈Λ_δ: E_q[λ^T g] ≤ 0.

对偶化为「最坏价值剖面倾斜 + 约束收紧」的单点问题，可用线性规划在线求解。主动询问准则：

(s,a) ∈ argmax VoI(s,a) = E_{λ,λ′~post}[ D_KL(p_{β,λ} ‖ p_{β,λ′}) ]，

即用最小的人类标注换取 Λ_δ 的最大收缩（或对齐税的最大下降）。

**定义 31（组合对齐契约）**：技能 h_i 的对齐契约 A_i = (K_i, CertAlign_i)。组合 h₁∘h₂：

K_comp = K₁ ∩ K₂（轨迹拼接处再加 C⁰/C¹ 连续性约束）；
ρ_comp = min(ρ₁, ρ₂)（值映射复合的 Lipschitz 下界可更紧地计算）；
τ_comp ≤ τ₁ + τ₂（对齐税次可加）。

若 K_comp 在 Λ_δ 下鲁棒不可行（∀a, ∃λ∈Λ_δ, λ^T g > 0），返回 ValueConflict(K₁,K₂,Λ_δ)，交 IP-35 仲裁（优先级：安全 > 法律/伦理硬约束 > 任务 > 舒适/效率），或触发主动询问。

## 2. 三大产出设计

### 2.1 IP-51 VALUE-TILTED CERTIFIED DIFFUSION（价值倾斜可认证扩散）

1. **骨干**：第 40 轮 CertFlow 概率流 ODE 作基础生成器 p_θ；外层叠加价值引导 + 退火 QP 投影；保留 IP-43 流式发射与韵律条件。
2. **价值头**：V_φ 为多分量轻量 Transformer/MLP head，条件 (s, a, g, 语义图)；输出 m 维价值 + 保形校准区间。
3. **约束族**：g_j 由四类组成——(a) ESDF/CBF 几何安全（IP-49），(b) 语义图上的社交/易碎/私密区谓词（IP-36），(c) 运动学/动力学界，(d) 任务谓词与韵律连续性。
4. **证书**：执行期用保形校准产 CertAlign；训练期用偏好数据（BT/DPO）学 V_φ；RCA 在线核查。
5. **少步蒸馏**：教师 N=32 带引导 → 学生 N=4，β、λ 作为条件；蒸馏损失含「价值/约束一致性」项，防蒸馏后对齐失效。

### 2.2 IP-52 CREDAL-VALUE-ALIGNMENT（可信集价值对齐）

1. **可信集**：偏好数据 → BT 后验 → bootstrap/保形 → Λ_δ；显式输出 ρ_amb。
2. **鲁棒对齐**：最坏价值剖面 + 约束收紧；对 Λ_δ 全体给出 CertAlign。
3. **主动询问**：VoI 采样把「价值歧义最大」的状态送人类在环；与 IP-50 课程联动（价值边界也是难度轴）。
4. **价值冲突检测**：组合时检验 K_comp 的鲁棒可行性；冲突交 IP-35，附冲突证据（哪两个价值在哪个状态不可同时满足）。

### 2.3 IP-53 ALIGNMENT-GUARDIAN（对齐守护）

1. **在线监测**：用判别器估计 p̂ 与 p* 的差异，或监控价值残差 + 约束残差；EWMA/CUSUM 检测漂移。
2. **触发**：违反 CertAlign 任一保证 → 降级到 value-safe 子策略（保守投影 / 提高 β / 回退 IP-38）→ RCA 重颁 → 契约热更新。
3. **可观测**：把对齐指标（违约率、税、ρ_amb、β*）纳入 IP-45 服务网格的追踪与指标。

## 5. 本轮最大风险

**一句话**：本方案的最大风险是「可信集/保形校准的分布假设」——一旦部署分布偏离校准集（exchangeability 破裂），CertAlign 会给出形式正确但实质失效的保证，产生比无证书更危险的「有证书的错位」，因此必须把 E75/E78 作为第一守门实验，并配套协变量偏移下的加权保形与在线重校准。

## 1. 符号体系（承接定义 19–31）

| 符号 | 含义 | 定义 |
|---|---|---|
| p_θ(a\|s) | 基础策略 | CertFlow 概率流 ODE 实现，带第 40 轮误差界 |
| V_φ(s,a) | 价值模型 | R^m 多分量（安全/任务/舒适/社交/能耗/可解释） |
| λ, Λ_δ | 价值剖面 / 可信集 | λ∈Δ^{m−1}；Λ_δ 为 (1−δ) 偏好相容集 |
| β | 对齐强度 | 指数倾斜系数；由反 Goodhart 命题 2 选 β* |
| p_{β,λ} | 价值倾斜分布 | ∝ p_θ exp(β λ^T V_φ) |
| p*_{β,λ} | 约束对齐分布 | p_{β,λ}·1[a∈K] |
| g_j, K(s) | 价值约束 / 可行域 | g_j≤0；(安全/社交/动力学/任务) |
| K_0…K_N | 退火可行域 | K_0⊇…⊇K_N=K，防投影坍缩 |
| CertAlign | 对齐证书 | (β,λ,V_φ,α,δ,ε_val,ρ_align,τ_tax,Λ_δ) |
| α | 违约率上界 | 保形风险控制给出 P(a∉K)≤α |
| ε_m | 价值模型误差 | 保形校准的 |V_φ−V*| 上界 |
| ρ_align / ρ_amb | 鲁棒半径 / 歧义半径 | 可信集直径；VoI 询问使其收缩 |
| τ_tax | 对齐税 | 任务性能代价上界 |
| VoI | 价值信息增益 | 用最小标注换 Λ_δ 最大收缩 |

## 2. 关键算法

### IP-51 价值倾斜可认证扩散（伪代码）
```
def certalign(v_theta, V_phi, D_cal, alpha, delta):
    V_lo, V_hi = conformal_calibrate(V_phi, D_cal, coverage=1-alpha)
    K          = build_constraints(esdf, semantic_value_tags, kinematics)
    beta       = choose_beta_anti_goodhart(V_lo, L_V)      # 优化保形下界
    eps_val    = bound_value_gap(V_phi, K, beta)           # 定理 4
    rho_align  = robust_radius(Lambda_delta, K)
    tau_tax    = bound_task_tax(v_theta, beta, K)
    return CertAlign(beta, lambda_, V_phi, alpha, delta,
                     eps_val, rho_align, tau_tax, Lambda_delta)

def value_guided_project_sample(s, v_theta, V_phi, K_anneal, beta, lam, N=8):
    a = prior_sample()
    for t in range(N):
        a0 = one_step_denoise(v_theta, a, t)
        grad = lam @ jacobian_a(V_phi, s, a0)              # m 维价值梯度
        a = denoise_step(v_theta, a, t) + eta * beta * grad
        a = project_qp(a, K_anneal[t])                     # 退火投影
    if not certalign_holds(a, s):
        guardian.trigger(h)                                # IP-53 兜底
    return a
```

### IP-52 可信集价值对齐（伪代码）
```
def robust_credal_align(D_pref, K, beta, delta):
    Lambda  = bt_posterior_bootstrap(D_pref, delta)        # 可信集
    lam_wc  = worst_case_profile(Lambda, grad_buffer)      # 最坏价值剖面
    K_tight = tighten_constraints(K, Lambda)               # 鲁棒约束收紧
    rho_amb = diameter_1(Lambda)
    return lam_wc, K_tight, rho_amb

def active_value_query(state_buffer, Lambda, beta):
    return argmax_{s,a} E_{lam,lam'~post}[KL(p_beta_lam || p_beta_lam')]

def compose_align(A1, A2, Lambda):
    K_comp = A1.K & A2.K
    rho    = min(A1.rho, A2.rho)
    if robust_infeasible(K_comp, Lambda):
        return ValueConflict(A1, A2, Lambda)                # -> IP-35 仲裁 / VoI
    return AlignContract(K_comp, rho, tau=A1.tau + A2.tau)
```

def alignment_guardian(p_hat, p_star, cert, window):

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 正确性保证 |
|---|---|---|
| 价值引导采样 | 每步 O(m·d_a) 梯度 + QP O(J·d_a²)；N=4~8 | **定理 4**：W₂(p̂,p*) ≤ C(ε_s+βL_Vε_m+ε_ode) |
| 约束满足 | 投影 O(J·d_a²)（小 J） | **保形风险控制**：P(a∉K)≤α，有限样本、分布无关 |
| 保形校准 | 离线 O(n log n) | 覆盖 ≥1−α（可交换性假设） |
| 可信集 | bootstrap O(B·n·m)；在线 O(1) | Λ_δ 为 (1−δ) 偏好相容集；ρ_amb→0 速率 O(n^{-1/2}) |
| 鲁棒最坏剖面 | 线性规划 O(poly(m)) | 对 Λ_δ 全体成立的最坏情形保证 |
| 反 Goodhart | 一阶展开闭式 | **命题 2**：β* 由 Var、ε_m、L_V 决定 |
| 组合对齐 | O(|V|+|E|) + 1 个 LP | K_comp 可行性检验 + τ 次可加 + ρ 取 min |
| 对齐守护 | 判别器 O(d)；CUSUM O(1) | 漂移检出后必降级/重颁（无静默失效） |

## 5. 风险与缓解

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 分布偏移导致「有证书的错位」（exchangeability 破裂） | 高 | 协变量偏移加权保形 + OOD 检测 + 在线重校准 + 人工审计；E75/E78 第一守门 |
| 价值模型失准 / 奖励黑客 | 高 | 悲观下界优化（命题 2）、β* 证书化、留出真值探针；E77 守门 |
| 对齐税过高 / 可行域坍缩 | 高 | 退火投影 + 软硬约束分层 + value-safe 降级；E74 守门 |

## 6. 本轮最大风险

**一句话**：最大风险是「可信集/保形校准的分布假设」——部署分布一旦偏离校准集，CertAlign 会给出形式正确但实质失效的保证，制造比无证书更危险的「有证书的错位」；故 E75/E78 为本轮成败判据，且必须配套协变量偏移加权保形与在线重校准。
