# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「夹爪控制」×「可解释性」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 493–539；引理 69–86；实验 E531–E570）。
> 本轮纪律：**接触安全 + 解释即证书**。两个灵感分别治理 v9 的两笔债：**末端债**——所有安全证书都在自由空间，唯一不可逆的接触时刻反而只剩二值 `γ̂_grasp`；**可信债**——证书只会说 invalid、不会说 why，14+ IP 的归因与退化对操作员和审计者不可核验。新增模块继续遵守中立元退化，但必须区分**恒等元（⊕）**与**吸收安全元（⊗）**：夹爪的"安全释放/柔顺保持"不是恒等元，误当恒等元会把吸收态当成可逆，直接破坏 v9 的退化代数。

## 0. 直觉与动机

**灵感 1（夹爪控制 → 接触级证书 + 反射层）**
直觉：v9 把安全论证局部化到"块证书 + 中止点"，但这些证书几乎都在自由空间；真正不可逆的是接触瞬间——抓空、滑落、过力压碎都发生在毫秒级，50Hz 的中块守卫根本来不及反应。夹爪控制给出了三样现成武器：力封闭/摩擦锥（静态可抓性）、触觉滑移检测（动态失稳）、阻抗/力限/柔顺（接触柔化）。核心创新：**抓握证书（GraspCertificate, GC）**把 `γ̂_grasp` 从二值升级为带余量的接触级证书 Ĝ=(μ̂_fc, ŝ_slip, f̂_n, ρ̂_align)，并设 **1kHz 接触反射层（CRG）** 在主环之外独立执行滑移反射与力限——主环崩溃也不影响"不捏碎、不掉落"这条底线。关键设计：**接触窗口内 K_eff 强制 = 1**——可逆的"块"假设在接触点失效，分块抽象必须在接触处让位给逐接触步。

**灵感 2（可解释性 → 解释作为一致性证书）**
直觉：v9 的证书只回答"是否有效"，不回答"凭什么"；当归因、退化、块中止发生时，操作员看到的是一串数字。更致命的是 v9 的最大风险——证书静默过期——恰恰因为没人能追问"你凭什么说它安全"。核心创新：**解释账本（ExplanationLedger, XPL）+ 反事实一致性监视器（CCM）**：每个决策产出最小、可核验、反事实的解释 E=(d, S, Δ, ℓ)，S 为被引用证据集、Δ 为"去掉 S 后决策是否翻转"。若解释忠实度不足（**解释缺口 G_t** 超阈）或反事实不稳定，则把**解释缺口本身当作证书可疑的证据**：K_eff←1、触发 M₀ 硬检查、必要时退回 v9。原则：**解释不是事后点缀，而是决策一致性的运行时证书（P14）**；解释端口也有中立元（v^⊥ = unexplained 标记），缺失解释只会让系统更保守，绝不允许阻塞 50Hz 环。

**桥接（跨学科）**：抓握是最高风险、最缺解释的事件。用解释去审计抓握——每次抓取都要求解释"为什么这一步抓取在力封闭与滑移余量下安全"；反事实检查在物体质量/摩擦变化时抓出"只在过时假设下才安全"的抓取。接触安全与可解释性在**承诺瞬间**汇合。

## 1. 研究问题（轮次升级版）

- **Q1（接触证书可靠性）**：在触觉标定误差、摩擦系数不确定、滑移不可直接观测的条件下，如何定义抓握证书，使"证书有效 ⇒ 真实力封闭且滑移余量 > 0"？
- **Q2（解释忠实度与预算）**：如何定义可测的忠实度与解释缺口，使其既能检测前向模型/域漂移的静默过期，又能在 20ms 决策预算内完成且永不阻塞控制？
- **Q3（双类中立元代数）**：夹爪的柔顺保持/安全释放是吸收元而非恒等元；如何把恒等元（⊕）与吸收安全元（⊗）分型，使 v9 的退化代数在接触端口上仍组合正确？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 抓握证书律（Grasp-Certificate, GC）**
抓握不是布尔事件而是证书事件：Ĝ_t=(μ̂_fc, ŝ_slip, f̂_n, ρ̂_align)，其中 μ̂_fc 为最坏摩擦锥下的力封闭余量、ŝ_slip 为滑移余量、f̂_n 为法向力上界、ρ̂_align 为指面-物体对齐度。Ĝ_t 有效 ⇔ μ̂_fc ≥ ε_fc ∧ ŝ_slip ≥ ε_slip ∧ f̂_n ≤ f_max ∧ ρ̂_align ≥ ρ_min；任一失效即拒绝该抓取候选或由 CRG 反射接管。抓握证书并入 M₀ 硬检查（M_grasp），不再只是软层的一个布尔门。

**P14 解释即证书律（Explanation-as-Certificate, XL）**
每个决策 d 产出一个解释证书 E=(d, S, Δ, ℓ)。忠实度 F(E) 定义为对被引用证据集 S 做反事实掩蔽后决策翻转的概率/裕度（定义 545）。解释缺口 G_t = F_target − F_measured。G_t 超阈或 Δ 不稳定 ⇒ 视为证书可疑 ⇒ 保守升级（K_eff←1、强制 M₀ 硬检查）。解释有硬预算契约：超预算时注入 v^⊥ = unexplained 标记而不阻塞，系统只会更保守（引理 90）。账本只追加、可重放、有界存储，安全关键解释全量保留，其余摘要化。

**P15 双类中立元律（Sort-aware Neutral Elements, SNR）**
每个端口携带类型 σ ∈ {⊕ 恒等型, ⊗ 吸收型}。恒等型（DA 的 Δ_dom≡0、Cal 的 weight≡1 等）满足 x ⊕ v^⊥ = x；吸收型（夹爪的柔顺保持/安全释放、AC 的安全停驻）满足 x ⊗ v^⊥ = v^⊥，且 v^⊥ 必须落在安全集内。组合运算要求两端同型；把吸收型误标为恒等型会破坏幂等性并允许"已释放"被后续块重新解释为"仍持有"。v10 的契约表比 v9 多一列 σ，部署期静态校验型匹配。

## 3. 与基线的接口（如何退化）

- GC/CRG 失效（触觉中断、标定漂移、滑移不确定）⇒ v_g^⊥ 注入：已持物时**柔顺保持**、未接触时**拒绝抓取**；K_eff←1；等价 v9 的"γ_grasp 二值 + 位置控制轻抓"。
- XPL/CCM 失效（超预算或忠实度不可测）⇒ v^⊥ = unexplained 标记，强制 M₀ 硬检查 + K_eff←1；等价 v9（无解释）但更保守。
- AC 失效 ⇒ K_eff←1，逐步执行，等价 v9 Level-1；
- MW 失效 ⇒ 切 v9 契约表/再退 v8 手写网关；ID 失效 ⇒ 全模块 active，等价 v8 全开；
- DA/SPR/Cal 失效 ⇒ 中立元注入（Δ_dom≡0 / risk_SLAM≡0 / sensor_weight≡1），等价 v7；
- 全部失效 ⇒ 完整退回 MetricVoiceGauge-ACMD v9，再退回 v7、v6。

## 4. 预期贡献

1. **接触级抓握证书 + 1kHz 反射层 + 接触窗口去分块**：把安全论证推进到最不可逆的接触瞬间，并给出"分块在接触处必须让位"的形式化判据；
2. **解释即证书**：可测忠实度、解释缺口作为域漂移/证书过期的运行时探针、可重放解释账本——把 v9 的"静默过期"风险变成可观测信号；
3. **双类中立元代数**：区分恒等元与吸收安全元，把 v9 的退化链正确扩展到执行器/接触端口；
4. **接触-解释-分块三耦合**：E571–E590 覆盖抓握证书、滑移反射、去分块过渡、解释忠实度、解释缺口检测、预算与账本、操作员信任与端到端任务。

## 5. 本轮最大风险

**一句话**：解释的忠实度由模型打分、抓握证书由模型预测，而二者共享同一套可能已过时的表征——当 F̂ 与归因器一起错时，解释会"自洽地"通过检查，解释缺口在最该报警的时刻静默为零，即「我们用模型解释模型的错误，只会得到自洽的错误」。

# 第 10 轮产物 · 创新点清单 v10：**MetricVoiceGauge-GripX**（Grasp-certified eXplainable execution，抓握证书 · 解释账本）

> 背景：第 9 轮 MetricVoiceGauge-ACMD（定义 493–539；引理 69–86；实验 E531–E570）。
> 本轮灵感：「夹爪控制」×「可解释性」
> **继承纪律**：MetricVoiceGauge 九不变式与 v9 的 AC/MW/ID 全部保留。新组件一律为**可选增强**：任一环节不可用 ⇒ 注入相应中立元，严格等价退回 v9 行为（引理 92）。本轮新增的**唯一代数改动**是把中立元分为恒等型 ⊕ 与吸收型 ⊗（P15），因为夹爪的"安全释放"若被当作恒等元，退化代数会在接触端口失配。

## 1. 符号体系增量（定义 540–548）

| 符号 | 含义 |
|---|---|
| Ĝ_t=(μ̂_fc, ŝ_slip, f̂_n, ρ̂_align) | 抓握证书：力封闭余量、滑移余量、法向力上界、对齐度 |
| M_grasp | 并入 M₀ 的接触安全硬指标（力封闭 ∨ 滑移 ∨ 力限 ∨ 对齐） |
| d_contact, τ_contact | 接触窗口：dist ≤ d_contact 后持续 τ_contact 的时段 |
| v_g^⊥ | 夹爪吸收安全元：已持物=柔顺保持，未接触=拒绝抓取（⊗ 型） |
| R_t | 1kHz 反射动作：{hold, tighten, loosen, release}，由 CRG 独占 |
| E_t=(d,S,Δ,ℓ) | 解释证书：决策、被引用证据集、反事实翻转量、自然语言模板 |

| σ_m ∈ {⊕,⊗} | 端口中立元类型：恒等型 / 吸收型 |
| τ_gap, n_gap | 解释缺口阈值与连续确认块数 |
| L_E, W_E | 解释账本容量与单条最大字节（有界） |

**新增定义 540（抓握证书 GraspCertificate）** 由视觉-触觉融合估计器在抓取前与持物期给出：
```
μ̂_fc  = min_{i∈接触点} ( (1/μ_max) · (f_t,i / f_n,i) )   # 摩擦锥最坏余量，μ_max 取下界
ŝ_slip = α·(f_n − f_hold) + (1−α)·(1 − ‖v_tactile‖/v_slip) # 滑移余量（触觉剪切流）
f̂_n   = 预测法向力上界（含物体质量不确定 δm）
ρ̂_align = cos∠(指面法向, 抓取轴) 的接触点最小值
```
Ĝ_t 有效 ⇔ μ̂_fc ≥ ε_fc ∧ ŝ_slip ≥ ε_slip ∧ f̂_n ≤ f_max ∧ ρ̂_align ≥ ρ_min。

**新增定义 541（接触反射层 ContactReflex）** CRG 以 1kHz 运行，输入触觉剪切流与力传感，输出 R_t 并拥有**对夹爪执行器的抢占权**：
```
R_t = release        若 ‖v_tactile‖ > v_drop ∧ 不可挽回（防拖拽/防拽倒）
    = tighten(Δf)    若 μ̂_fc < ε_fc ∧ f̂_n + Δf ≤ f_max
    = loosen(Δf)     若 f̂_n > f_max − ε_f
    = hold           否则（柔顺阻抗保持）
```
CRG 不依赖主环结果；主环崩溃时 `hold/release` 仍成立。

**新增定义 542（接触窗口去分块 ContactWindowDeChunking）**
```
K_eff(t) = 1                             若 dist(s_t,O) ≤ d_contact 或接触状态=holding
         = min(K_eff^v9(t), K_contact)   否则
```
进入接触窗口时，当前块的剩余动作作废，改由逐接触步 + CRG 反射接管；退出后按 v9 门控重新生成块。

**新增定义 543（抓握安全不变式 GraspSafetyInvariant）** 作为 M₀ 的接触分量：
```
Φ_grasp:  有效抓握 ⇒ (μ̂_fc ≥ ε_fc) ∧ (ŝ_slip ≥ ε_slip) ∧ (f̂_n ≤ f_max) ∧ (ρ̂_align ≥ ρ_min)
          已持物 ⇒ 任意时刻 f_n ≤ f_max 且 |v_tactile| ≤ v_drop + v_reflex·Δt_1kHz
```
Φ_grasp 违反即硬触发：CRG 反射 + 块终止，不等块边界。

**新增定义 544（解释证书 ExplanationCertificate）** E_t=(d_t, S_t, Δ_t, ℓ_t)。S_t 为影响 d_t 的最小证据集（如某层指标、Ĝ_t 的某项、Δ_dom 读数）；Δ_t 为对 S_t 做反事实掩蔽/替换后决策裕度的变化；ℓ_t 为由模板生成的自然语言（含"因为…所以…若不…就会…"三元结构）。

**新增定义 545（忠实度与解释缺口 Faithfulness & ExplanationGap）** 对掩蔽算子 do(¬S)：
```
F(E) = (1/|P|) Σ_{x'∈P} 1[ d(x'|do(¬S)) ≠ d(x') ]     # 必要性；P 为审计扰动集
G_t  = max(0, F_target − F(E_t))
```
F_target=0.9。G_t 超 τ_gap 持续 n_gap 块 ⇒ 证书可疑（定义 546）。

**新增定义 546（反事实一致性监视 CounterfactualCoherence）** CCM 在块边界运行（≤1ms）：
```
suspect = (G_t > τ_gap for n_gap consecutive chunks) ∨ (Var(Δ_t) > τ_cf)
if suspect: K_eff ← 1; 强制 M₀ 硬检查; 若连续三次 suspect: 退回 v9 无解释模式
```
解释缺口不改变安全动作集，只把系统推向更保守的格点（引理 90）。

**新增定义 547（解释预算契约 ExplanationBudget）** XPL/CCM 作为 MW 模块声明 D_E=1.0ms、Ŵ_E=1.0ms、v^⊥=unexplained。超时 ⇒ 记录 unexplained 标记并强制 M₀ 硬检查；解释缺失**永不**阻塞控制（P14）。

**新增定义 548（有界解释账本 Bounded ExplanationLedger）** 追加式环形缓冲 L_E 条 + 事件触发全量快照；安全关键解释（M₀ 触发、退化、抓握中止）永不摘要化；账本可离线重放且重放决策与在线一致（引理 92 的审计分量）。

## 2. 升级定义（要点）

**升级定义 496（软证书，v10）** 六条件：
`δ_trigger = {σ<τ_safe ∧ Φ_grasp ∧ Δ_dom<τ_dom ∧ risk_SLAM<τ_SLAM ∧ Ĉ_t valid ∧ (Ĝ_t valid ∨ 未进入接触窗口)}`。
抓握证书失效与单步条件同尺度触发 M₀ 硬检查。

**升级定义 531（软硬衔接，v10）** M₀ 判据增加接触入口：接触窗口内任一中块守卫或 CRG 反射违规 ⇒ 立即改走 `hold/release` 或最近中止点，绝不等块边界。

**升级定义 535（契约，v10）** κ_m 增加 σ_m 与吸收安全元；部署期校验：Σ_m Ŵ_m ≤ B_dec、同型组合（⊕ 只与 ⊕、⊗ 只与 ⊗）、吸收元幂等（x ⊗ v^⊥ = v^⊥）且 v^⊥ ∈ SafeSet。

## 3. 关键算法骨架

```python
# IP-357 GraspCertificateManager
class GraspCertificateManager:
    def __init__(self, fusion, mu_lower=0.5, eps_fc=0.15, eps_slip=0.20,
                 f_max=40.0, rho_min=0.7, dm=0.15):
        self.fusion, self.mu_lower = fusion, mu_lower
        self.eps_fc, self.eps_slip = eps_fc, eps_slip
        self.f_max, self.rho_min, self.dm = f_max, rho_min, dm

    def evaluate(self, vis, tac, mass_hat):
        c = self.fusion.contact_points(vis, tac)            # 接触点集
        mu_fc = min((1.0/self.mu_lower) * (p.ft / max(p.fn,1e-3)) for p in c)
        slip  = 0.5*(p.fn - p.f_hold) + 0.5*(1 - p.shear/max(p.v_slip,1e-6))
        f_n   = max(p.fn for p in c) + self.dm * 9.81       # 质量不确定余量
        align = min(p.align for p in c)
        G = GraspCert(mu_fc, slip, f_n, align)

                   and f_n <= self.f_max and align >= self.rho_min)
        return G

class ContactReflexGuard:

        self.state = 'hold'

    def tick(self, tac, fn, dt=1e-3):

            self.state = ('tighten', self.eps_f)
        else:
            self.state = 'hold'                             # 柔顺阻抗保持
        return self.actuate(self.state)

    def actuate(self, cmd):
        return cmd                                          # 抢占夹爪，主环不可覆盖

class CounterfactualCoherenceMonitor:
    def __init__(self, tau_gap=0.15, n_gap=3, tau_cf=0.02):
        self.tau_gap, self.n_gap, self.tau_cf = tau_gap, n_gap, tau_cf
        self.gap_run = 0

    def check(self, E, audit_set, decision_fn):
        flips = [decision_fn(x, mask=E.S) != E.d for x in audit_set]
        F = sum(flips) / max(len(flips), 1)
        G = max(0.0, 0.9 - F)
        self.gap_run = self.gap_run + 1 if G > self.tau_gap else 0
        suspect = self.gap_run >= self.n_gap or E.var_delta > self.tau_cf
        return suspect, G
```

## 4. 推导

**引理 87（抓握证书可靠性）** 设触觉力/剪切标定误差有界 ‖f̂−f‖∞ ≤ β_t，摩擦系数真值 μ ∈ [μ_lower, μ_upper]，且证书用 μ_lower 计算。则 Ĝ_t 有效 ⇒ 真实摩擦锥余量 ≥ μ̂_fc − β_t/μ_lower > 0，且 f_n ≤ f_max + β_t；当 β_t ≤ min(ε_fc·μ_lower, ε_slip) 时可取安全裕度补偿，保证不因标定误差把"真实不可抓"判为"可抓"。证明：由最坏点 min 的单调性与误差界逐项代入即可；滑移项对剪切流速率的 Lipschitz 常数给出同样的保守性。∎

**引理 88（接触反射的滑移上界）** 若 CRG 每 Δt=1ms 采样且滑移速度估计误差 ≤ β_v，则从真实滑移起始到反射动作生效的位移 ≤ (v_drop+β_v)·(Δt+L_act)，其中 L_act 为执行器延迟；只要该位移小于指面接触长度余量，物体不脱手。主环是否正常不影响该界（CRG 独立抢占）。∎

**引理 89（双类中立元代数）** 令恒等型端口满足 x⊕v^⊥=x，吸收型端口满足 x⊗v^⊥=v^⊥ 且 v^⊥∈SafeSet。若契约表每组合同型且吸收元幂等，则任意失效组合的注入结果唯一且位于 v9 退化格点或 SafeSet 内；(v_g^⊥)⊗(安全停驻 a^⊥)=(安全停驻 a^⊥)，即"已释放/已停驻"不可被后续块重新解释为"仍持有/仍在运动"。证明：对失效集合按端口类型归纳；异型混用会破坏幂等（给出反例：柔顺保持 ⊗ 新块动作 ≠ 保持），故型检查是组合正确性的充分条件。∎

**引理 90（解释单调保守性）** 记 A(Ĉ,G) 为动作集，XPL/CCM 只能把 K 映射为非增值并在 suspect 时触发 M₀ 硬检查；即 A(Ĉ,G) ⊆ A(Ĉ)（v9 动作集）。故加入解释模块不扩大不安全动作集；解释缺失/超预算只注入 unexplained 并保守升级，不改变 50Hz 时序（引理 86 的预算仍成立）。∎

**引理 91（解释缺口检测静默过期，条件性）** 设审计扰动集 P 与"过时区域"重叠比例 ≥ κ，且忠实度估计无偏。若真实前向误差 > β（证书已过期），则存在决策 d 使被引用证据 S 的掩蔽能翻转 d，故 E[F(E)] ≤ 1−κ·p_flip，从而 E[G_t] ≥ κ·p_flip − slack。即解释缺口是过期的一个**有偏但非零**信号；κ=0（审计集完全落在信任域内）时该检测失效，这正是本轮最大风险的代数形式。∎

**引理 92（v10 严格退化与账本可重放）** 令 v10 的全部新模块失效：SNR 退化后与 v9 契约表同构、GC/CRG 注入 v_g^⊥ 等价 v9 的 γ_grasp 二值轻抓、XPL/CCM 缺失等价 v9 无解释、接触窗口去分块在无接触时为空操作 ⇒ v10 ≡ v9（逐位）。账本重放：解释只读决策 d 与证据 S 的不可变快照，重放不重新推理 ⇒ 重放决策与在线一致。∎

## 8. 本轮最大风险

**一句话**：解释的忠实度由模型打分、抓握证书由模型预测，而二者共享同一套可能已过时的表征——当 F̂ 与归因器一起错时，解释会"自洽地"通过检查，解释缺口在最该报警的时刻静默为零（引理 91 中 κ→0 的退化分支），即「我们用模型解释模型的错误，只会得到自洽的错误」。
