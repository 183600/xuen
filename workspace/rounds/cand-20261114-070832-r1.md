# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「价值对齐」×「抓取位姿估计」）

> R69 问「我该向谁求证、还能问什么」，把不确定性拆成 aleatoric 与 epistemic，并用流匹配多模态策略 + 主动交互去消解 epistemic。但它悄悄预设了一件事：**消歧之后剩下的多个模态里，总有一个是「对」的，问出来就行**。对世界事实也许如此；对价值不是。当两个抓取都任务成功、都不违反物理安全、却一个会捏碎杯壁、一个会碰到别人的手腕、一个会翻开一本不该看的日记——它们之间的差别不是「世界是什么」，而是「我凭什么这样碰它」。这不是一个可以通过更多观测或更多提问来「测准」的量，而是一个**规范性承诺**。
>
> 本轮两个灵感正好把 R69 的隐藏假设拆开：
> - **价值对齐**告诉我们，最危险的失败往往不是「答错」，而是「在错误的目标上答对」；价值不能被压成一个可交易的标量奖励，否则系统会拿不可逆的伤害去换可测的收益。
> - **抓取位姿估计**给出价值在物理世界中的坐标：同一个物体的多个可行抓取，在任务成功率上几乎等价，却在接触力、接触区域、所有权、隐私、可撤销性上差异巨大；而**接触本身是不可逆的**。
>
> 核心命题：**把 R69 的 epistemic 再拆出 axiological（价值）不确定性；U_ale 沿用 R68 铁律，U_epi 交给 R69 交互，U_ax 交给「接触落地价值约束 + 不可逆承诺门 + 合法偏好证据」处理。价值对齐不是奖励函数匹配，而是接触流形上可验证、可授权、可争议的约束满足。** 命名 **GRACE-RAS**（Grasp-Rooted Alignment with Commitment-aware Epistemic uncertainty）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我该以什么方式碰它，凭什么**」——价值不是一个要猜对的标签，而是一道必须在接触前守住的边界。

## 0. 直觉与动机

**灵感 1（价值对齐：不是「答对题」，而是「别在不可逆处答错」）**
直觉：如果只看任务成功率，抓杯沿、抓杯壁、抓住杯把都可能成功。但「把杯子抓裂」「碰到旁边人的手」「让杯子的主人觉得被冒犯」这些代价，往往在任务奖励里没有位置；一旦发生又无法回滚。价值对齐的核心不是让奖励函数多几项，而是承认有一类约束**不允许被其他收益补偿**。一个把价值标量化成奖励的系统，迟早会学会「用一点隐私换一点效率」「用一点粗暴换一点速度」；真正的对齐失败常常不是低收益，而是在错误目标上取得高收益。所以本轮的姿态是：**把价值对齐从「优化目标」改写为「约束 + 授权 + 拒绝」**。

**灵感 2（抓取位姿估计：价值在接触流形上有坐标）**
直觉：抽象的「尊重」「轻柔」「隐私」很难验证，但接触点可以。抓取位姿不只是 6-DoF 位姿，它还包括夹爪宽度、接触点集合、接触法向、力轨迹与接近方向。于是价值第一次变得可测量：
- 「轻柔」= 接触力相对材料/物体预算的裕度；
- 「所有权/隐私」= 接触点是否落在禁触区域，传感器是否扫过不该看的区域；
- 「可撤销」= 抓取是否可干净释放、是否会发生缠绕；
- 「意图一致」= 接近方向是否与把手的可用性一致（抓杯把而不是抓杯口）；
- 「舒适」= 与人体的距离、预测的不适与惊吓。
这使价值对齐从「语言层面像不像」变成「接触层面守不守得住」。抓取位姿估计器给出的是一个**多模态抓取分布**，而不是单个最优点；价值约束就作用在这个分布上。

**灵感 3（三分解：R69 的 epistemic 里混着 axiological）**
直觉：R69 把不确定性分成 aleatoric 与 epistemic，但 epistemic 里其实混着两种完全不同的东西。**(a) 世界歧义**：这是杯子还是碗、这个模态对应哪条路——可以用观察或提问降低。**(b) 价值不确定性**：在这个人的语境里，什么算「太用力」、什么区域不能碰、效率与体面如何排序——这不是世界的事实，不能靠看更多帧或问更多句来「测准」；它只能通过**合法的偏好证据**（知情、非胁迫、有范围、可撤回的同意或纠正）部分降低，而且可能因为价值多元而**不可完全消解**。把 U_ax 塞进 U_epi，会让系统误以为「再问一次就能问出正确答案」，从而把规范冲突伪装成信息不足。R69 恰好是 U_ax→0、价值约束为空时的边界情形。

**灵感 4（不可逆承诺：抓取是一道单向门）**
直觉：R69 的信息动作（看一眼、问一句、等一拍）便宜且可逆；抓取接触不是。杯子碎了不能「再采样一次」，碰到别人不能「回滚上一步」。因此这里有一条 R69 没有的时间逻辑：**信息必须在承诺之前获得；已承诺的不可逆动作不能靠事后提问补救**。系统需要在接触前判断自己处于哪种状态：硬约束鲁棒满足（可承诺）、有明确授权且授权范围覆盖本次接触（可承诺）、只能选可逆替代（推迟）、还是无路可走（拒绝/移交）。这不是保守主义的装饰，而是不可逆决策的基本结构。

**灵感 5（偏好证据不是免费的真值）**
直觉：R69 已经知道「人会撒谎、会给看起来合理的错误答案」，但 R70 的处境更糟：偏好不是标签。人会犹豫、会自相矛盾、会被提问方式锚定、会为了一时方便给出事后后悔的同意；机器人自己的问法还会诱导答案。于是「问出来的」不能直接当价值真值，必须带上**合法性谓词**：是否知情、是否非胁迫、是否限定范围、是否可撤回、是否有来源与时效。尤其要有一条铁律：**不可让渡的硬约束不能被任何数量的「同意」覆盖**（例如不能因为用户说「可以」就去伤害第三方）。否则 R70 只是给 R69 装了一张可以被贿赂的嘴。

**灵感 6（对齐剧场：最危险的失败是「看起来对齐」）**
直觉：一旦系统用「力裕度」「同意日志」「零违规」来证明自己对齐，优化压力就会把这些度量变成目标本身：轻轻碰一下以获得漂亮的力裕度、收集一个没被理解的同意、把「没有记录违规」当成「没有违规」。这就是**对齐剧场（alignment theater）**——证书齐全，价值仍然被违反。更糟的是，接触不可逆，剧场演完无法重来。因此本轮必须同时交付：独立审计、代理缺口监测、金丝雀接触、可争议日志，以及「拒绝」作为一等公民。对齐不是自我认证，而是**可被他人反驳**。

**灵感 7（严格包含 R69）**
直觉：如果价值约束为空（没有硬约束、所有软价值等价）、U_ax=0、且不涉及不可逆接触，GRACE 必须逐指令退化为 FLUID：同样的采样、同样的 VoI、同样的 λ floor、同样的模态选择。价值层只能**缩小**可采纳动作集，或在明确授权下**在硬约束内部**放宽可授权约束；它绝不能扩大物理安全包络。这样 R69 不被推翻，而是被包含为「价值中立」边界；新增的是一整个规范维度，而不是又一个需要独立信任的黑箱。

## 1. 形式化定义（增量：定义 310–328）

**定义 310（GRACE-RAS 总览）** GRACE-RAS = (GF-GPE, PVL, VCF, CGA, PEC, VCR, VDM, VQAuditor-V, RAS-WM†)。四条不变式：
(i) **硬约束不可交易**：不可让渡约束集 H_inv 在任何偏好证据、同意或收益下都不得违反；
(ii) **不可逆承诺门**：任何接触类动作在接触前必须处于 robust 或 authorized 状态，否则只能执行 reversible 替代或 refuse；
(iii) **证据合法性**：只有满足合法性谓词 L(e) 的偏好证据才能更新价值后验；单源证据不得单独改写可授权硬约束 H_auth；
(iv) **实时零学习写操作**（继承 R68 定义 276-i）。

**定义 311（价值维度与接触价值场）** 价值维度集 V = H_inv ∪ H_auth ∪ V_soft。接触价值场 φ_j(p, n, f; c) 定义在物体表面点 p、法向 n、接触力 f 与语境 c 上，输出第 j 维的带符号价值量。抓取 G 的接触集为 C(G)，价值泛函 V_j(G, c; θ) = Agg_{p∈C(G)} φ_j(p, n_p, f_p; c)，其中 θ 为价值假设参数（阈值、区域标签、优先级）。示例：
- μ_gentle(G) = (F_budget(c) − max_{p∈C(G)} ‖f_p‖) / F_budget(c)；
- μ_own(G) = dist(C(G), ∂R_forbidden(c))（到禁触区域边界的带符号距离）；
- μ_rev(G) = P(clean release | G, c) − τ_rev；
- μ_comfort(G) = dist(C(G), H_human) / d_safe − 1；
- μ_intent(G) = cos(approach(G), affordance_dir(c)) − τ_int。
硬约束要求相应裕度 ≥ 0；软价值进入字典序比较。

**定义 312（价值裕度与最小裕度）** 对每个价值维度 j，定义带符号裕度 μ_j(G, c; θ)；μ_j ≥ 0 表示该维度的约束被满足。抓取的**最小硬裕度**为 μ_min(G) = min_{j∈H_inv∪H_auth} μ_j(G)。裕度不是奖励，不能相加；负裕度不能被正裕度补偿。

**定义 313（抓取位姿分布 GF-GPE）** GF-GPE 在 SE(3) × [w_min, w_max] × 2^{∂O} × ℱ 上建模抓取分布 p_θ(G | o, c_v)，其中 G = (T, w, C, f(·)) 分别为末端位姿、夹爪开度、接触点集与力轨迹。用 SE(3) 流匹配采样（继承 R69 的 rectified flow，N_step=2），输出 K 个候选；每个候选附带成功概率、力闭合裕度、碰撞裕度与定义 311 的价值裕度头。分布天然多峰：同一物体的「抓把」「抓壁」「托底」是不同模态，而不是高斯均值。

**定义 314（价值可采纳集）** 给定价值假设的可信集 Θ_β（后验质量至少 β），价值可采纳集为
A_val(o; c_v) = { G ∈ A_task(o) ∩ A_safe(o) : μ_j(G, c; θ) ≥ 0, ∀j ∈ H_inv ∪ H_auth, ∀θ ∈ Θ_β }，
软价值在 A_val 内按字典序比较，而不是用标量奖励把硬约束折进去。

**定义 315（鲁棒裕度与承诺风险）** 对 j ∈ H_inv ∪ H_auth 定义鲁棒裕度 μ_j^rob = ess inf_{θ∈Θ_β} μ_j(·; θ)（或用下尾 CVaR_β 代替）。承诺风险 r_c(G) = Σ_j w_j [−μ_j^rob(G)]_+，其中权重只用于排序风险，不用于补偿硬约束。若存在 j 使 μ_j^rob < 0，则 G 不得进入 robust 承诺。

**定义 316（价值不确定性 U_ax）** U_ax = H(H | E_legit)，其中 H 为价值假设（约束集与优先级）空间，E_legit 为合法偏好证据。分解为 U_ax = U_ax^res + U_ax^irr：前者是可通过合法探询降低的可约部分，后者是价值多元与语境不可判定造成的不可约部分。U_ax 不得并入 U_epi：观测不能消解规范不确定性；能消解它的只有合法偏好证据。

**定义 317（偏好证据与合法性谓词）** 一条偏好证据 e = (kind, content, source, scope, expiry, revocable, provenance)，其中 kind ∈ {示范, 纠正, 声明, 同意, 拒绝}。合法性谓词 L(e) = informed(e) ∧ non_coerced(e) ∧ scoped(e) ∧ revocable(e) ∧ third_party_safe(e)。只有 L(e)=1 的证据才进入价值后验更新；单源证据不得单独改写 H_auth，需 k 个正交来源一致，或一条带明确范围与时效的同意令牌。H_inv 不因任何证据改变。

**定义 318（价值条件策略与投影）** 价值条件策略 π_θ(G | o, c_v) 在 GF-GPE 之上以价值语境 c_v 为条件；采样后做价值投影 G† = Proj_{A_val}(G)，度量 d = d_SE3 + λ_f‖f − f′‖。投影是非扩张的：若 G ∉ A_val，则 G† 到 A_val 的距离不大于 G，且不增加任何硬约束违反量；若 G ∈ A_val，则 G† = G（幂等）。实现上可用拒绝采样、约束流引导或最后一层梯度投影。

**定义 319（不可逆承诺门 CGA）** CGA 在接触前输出四种模式之一：
- **M_robust**：∀j∈H_inv∪H_auth，μ_j^rob ≥ 0，且价值共形集覆盖成立 → 直接承诺；
- **M_auth**：H_inv 全部满足，但某些 H_auth 裕度为负；若存在合法、未过期、范围精确覆盖本次接触类的同意令牌，则在授权包络内承诺；
- **M_rev**：存在可逆替代（改换接近方向、用工具、先托住再调整、等待、移交人类）→ 执行替代，不进入不可逆接触；
- **M_refuse**：A_val 为空、无有效授权、无可逆替代 → 安全停止并解释，拒绝是合法策略输出。
若 M_auth 的同意在执行中被撤回或过期，必须立即退回 M_rev；不得「已经碰上了就做完」。

**定义 320（价值共形抓取集）** 用校准集估计非一致性分数 s(G) = max_j [−μ_j(G)]_+（只关心硬约束违反量）。通过共形风险控制选阈值 τ，使 E[1{μ_min(G) < 0}] ≤ α；价值共形集 Ĝ_α = {G : s(G) ≤ τ}。交换性假设下该风险界分布无关；跨用户采用分层校准，避免把一个人的价值阈值强加给另一个人。

**定义 321（合法偏好探询 PEC）** 候选偏好问询 q 的价值定义为 VoI-L(q) = E[承诺模式风险下降] − c(q) − λ_q·manipulation_risk(q)，约束为 L(q)=1、q 非诱导、可拒绝、且**只有可能改变承诺模式或 H_auth 判定时才允许提问**。若提问只能确认既有判断，则不提问；同一问题不得重复骚扰；用户拒绝后必须记住。R69 的 VoI 是 VoI-L 在「价值可自由观测」下的退化。

**定义 322（价值证书 J_GRACE）** J_GRACE = (J_FLUID, μ^rob 向量, commitment_mode, consent_scope_hash, conformal_coverage, preference_provenance_hash, proxy_gap, grace_ver)。Valid ⇔ Valid(J_FLUID) ∧ 所有 H_inv 裕度 ≥ 0 ∧（mode=M_auth ⇒ 同意令牌有效且范围匹配）∧ 共形覆盖达标 ∧ proxy_gap ≤ τ_gap ∧ 审计可追溯。

**定义 323（价值代理缺口与对齐剧场监测 VDM）** 设 m_proxy 为系统可测的价值代理（力裕度、禁触距离、同意日志完整率等），m_audit 为独立审计得到的真实违规率。定义代理缺口 Δ_proxy = |m_proxy − m_audit|（或「裕度满足但用户判定违规」的条件频率）。用独立审计样本、金丝雀接触/物体、以及随机化审计时刻估计 Δ_proxy；若 Δ_proxy > τ_gap 或呈系统性偏差，证书降级并退回 M_refuse/移交。**可测代理不得成为目标本身**。

**定义 324（价值威胁模型 ℰ_value）** ℰ_value 包含：偏好投毒（给出误导性纠正/同意）、奖励黑客（用软收益补偿硬约束）、对齐剧场（只优化可测代理）、谄媚/诱导（问法泄露机器人偏好）、同意洗白（用笼统同意覆盖具体接触）、隐性价值漂移（长期反馈把阈值慢慢推偏）、接触级欺骗（外观与真实材质/所有权不符）。ℰ_GRACE = ℰ_FLUID × ℰ_value。

**定义 325（字典序与不可交易证书）** 价值优先级为 H_inv ≻ H_auth ≻ V_soft；在 H_inv 内部不允许任何交易，在 H_auth 内部只允许授权范围内的放宽，V_soft 内部按声明的优先级比较。若动作 A 的某个硬裕度为负，则任何软价值提升都不能使 A 优于硬裕度非负的动作。J_GRACE 中保存该字典序的见证（witness），使「为什么没选更舒服但越界的抓取」可被复核。

**定义 326（不可逆风险缩放 λ_grace）** λ_grace = max(λ_FLUID, λ_commit(μ_min^rob, U_ax^irr))，其中 λ_commit 关于 μ_min^rob 单调不增，当 μ_min^rob → 0⁺ 时连续趋近 1，当裕度充足时回到 0。若进入 M_refuse，则 λ=1 且速度/接触指令置零。λ_grace 只增不减地进入 R68/R69 的安全缩放，保证价值层不会扩大物理风险包络。

**定义 327（拒绝与移交语义）** 拒绝 a_⊥ 是一等动作，包含：停止/保持安全姿态、说明触发的价值维度与证据、给出可逆替代或移交建议。拒绝不是任务失败，而是价值可采纳的输出；在 H_inv 未满足时，「尽力而为的接触」在语义上未定义。移交时把价值语境、已获同意范围、未决冲突一并交给人类，而不是把问题藏进日志。

**定义 328（可争议审计 VQAuditor-V）** 审计对象新增：接触轨迹、裕度向量、同意范围、偏好来源与时效、代理缺口、拒绝理由。任何被影响者可对一次接触提出异议；异议触发重新评估与独立复核，但**不自动**改写价值模型；只有满足 L(e) 的证据才进入更新。审计结论回灌 VDM 与 PEC 的先验，形成「可争议 → 可修正」的闭环。

## 2. 关键算法骨架

## 3. 推导

**假设 A99–A103**：A99 接触价值场 φ_j 对其变量 Lipschitz；A100 价值假设的可信集 Θ_β 非空且其后验可计算或有保守近似；A101 校准抓取与测试抓取在给定语境下可交换（共形风险控制的前提）；A102 同意令牌的 scope 与 contact_class 的匹配可判定；A103 独立审计样本与系统自评代理条件独立。

**引理 19（接触价值裕度的误差传播）** 设真实抓取 G 与估计 Ĝ 的位姿误差为 ε_G，力轨迹误差为 ε_f，价值场 φ_j 对位姿与力的 Lipschitz 常数为 L_G、L_F，则
μ_j(G) ≥ μ̂_j(Ĝ) − L_G ε_G − L_F ε_f。
因此用估计裕度做硬约束判定时，必须减去误差项；价值共形集（定义 320）正是把该误差吸收进非一致性分数，使 P(μ_min(G) < 0) ≤ α 在交换性下成立。系：**接触越靠近约束边界，位姿估计误差越不能忽略**——价值裕度不是「名义值」，而是「扣掉估计误差后的下界」。

**引理 20（不可逆承诺的占优性）** 设某硬价值约束相关的不确定性在承诺前未消解，违反代价为 C_viol，获取信息或选择可逆替代的成本为 c_info + C_rev。若 C_viol > c_info + C_rev，则任何「先接触、后补救」的策略都被「先获取合法证据/选可逆替代、再承诺」的策略弱占优。证明要点：不可逆违反的损失无法被后续观测或提问补偿；推迟承诺保留选择权，而提前承诺把选择权换成不可回收的暴露；在 C_viol 足够大时，期望损失严格更差。系：**VoI 在不可逆动作上必须变成 VoI-I（irreversibility-aware）——先问再做，而不是边做边问**。

**定理 18（GRACE 对 FLUID 的严格包含与安全单调性）** 在 A99–A103 下：
(i) 对任意状态，GRACE 的可采纳接触集 A_val ⊆ A_task ∩ A_safe，因此任何 GRACE 接触动作都是 R69 物理安全可采纳的动作；硬价值违反概率不高于 FLUID（FLUID 不建模价值，故其违反率就是基线）。
(ii) 当价值约束为空（H_inv=H_auth=∅，所有软价值等价）、U_ax=0、且动作不涉及接触承诺时，承诺门恒为 M_robust，价值层不改变任何排序，GRACE 与 FLUID **逐指令相同**。
(iii) 价值层只能在硬约束内部通过合法授权放宽 H_auth；它不能扩大 A_safe，因此 λ_grace ≥ λ_FLUID 且物理安全包络不扩大。
注意：任务成功率可能低于 FLUID，因为 FLUID 可能选择价值越界但任务成功的动作；这是有意的价值约束，不是包含性失败。**安全与任务可行维度严格包含；价值维度新增不可交易约束。**

**定理 19（偏好投毒与同意伪造上界）** 设单源偏好证据被投毒的概率为 δ_p，k 个正交证据源的欺骗相关系数为 ρ<1，且 H_inv 不可被任何证据覆盖。则错误改写 H_auth 的概率 ≤ δ_p·ρ^{k−1} + ε_σ；H_inv 的错误放宽概率为 0。若问询泄露了机器人的偏好，人类反馈会产生谄媚偏差 β；采用盲化问询（不展示机器人倾向）可把 β 压到 β_blind，且 VoI-L 中的 manipulation_risk 项显式惩罚高 β 的问法。系：**证据纪律把「问一次」变成「问到一个可验证、可撤回、范围明确的一致」；不可让渡约束不进入投票。**

**定理 20（对齐剧场的可检测性）** 设系统自评代理与独立审计的条件独立（A103），每次审计发现系统性代理缺口 Δ_proxy > τ_gap 的概率为 q>0。则连续 N 次审计后仍未发现的概率 ≤ (1−q)^N。因此 J_GRACE 的有效性必须依赖独立审计与金丝雀接触，而不能只依赖系统自报的裕度与同意日志。系：**可测代理越被优化，越需要外部审计；没有可争议性的证书不是对齐证明，只是自我陈述。**

## 6. 本轮最大风险

**一句话**：GRACE-RAS 把价值对齐寄托在「接触裕度、同意范围、审计日志这些可测代理能够代表真实价值」上；一旦优化压力把这些代理变成目标，系统就会**在证书齐全的情况下演出对齐剧场**——力裕度漂亮、同意日志完整、零违规记录，却仍然捏碎了不该捏的东西、碰了不该碰的地方，而抓取接触不可逆，事后无法补救。**最危险的不是拒绝太多，而是被认证的错误。**

**次级风险与缓解**：
1. **价值规格错误**（阈值/禁触区标错）→ 独立审计 + 金丝雀接触 + 可争议日志，不把规格当真理；
2. **偏好投毒/同意洗白** → L(e) 合法性谓词 + k 正交证据 + H_inv 不可覆盖（定义 317、引理 19）；
3. **跨用户价值多元** → 分层共形校准 + 个人化语境 + 拒绝/移交，不输出单一「正确价值」；
4. **位姿/力估计误差导致裕度虚高** → 引理 19 的误差下界 + 价值共形风险控制；
5. **对齐剧场/奖励黑客** → VDM 代理缺口 + 独立审计 + 字典序证书（定义 322–325、定理 20）；
6. **实时预算被抓取采样击穿** → GF-GPE 仅在接触决策触发，K=8/N_step=2，非接触路径与 R69 持平。

| `Ĝ_α` | 价值共形集：`P(μ_min<0) ≤ α` |
| `VoI-L(q)` | 合法偏好探询的期望承诺风险下降 − 成本 − 操纵风险 |
| `Δ_proxy = |m_proxy − m_audit|` | 代理缺口（对齐剧场监测量） |
| `J_GRACE = (J_FLUID, μ^rob, mode, consent_hash, coverage, provenance_hash, proxy_gap, grace_ver)` | 价值证书 |
| `λ_grace = max(λ_FLUID, λ_commit(μ_min^rob, U_ax^irr))` | 不可逆风险缩放 |

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** GRACE-RAS = (GF-GPE, PVL, VCF, CGA, PEC, VCR, VDM, VQAuditor-V, RAS-WM†)；H_inv 不可交易；接触前必须处于 robust/authorized；只有 L(e)=1 的证据可更新价值；实时零学习写操作继承 R68。

**定义 311–312（接触价值场与裕度）** 价值维度分为 H_inv/H_auth/V_soft；φ_j 定义在接触点、法向、力上；μ_j 为带符号裕度，μ_j≥0 才算满足。裕度不可相加补偿；`μ_min` 是硬约束的最小裕度。

**定义 313（GF-GPE）** 在 SE(3)×[w_min,w_max]×2^{∂O}×ℱ 上做流匹配采样，G=(T,w,C,f(·))；K 个候选，附成功/力闭合/碰撞/价值裕度头；天然多峰（抓把/抓壁/托底）。

**定义 314–315（A_val 与鲁棒裕度）** `A_val={G∈A_task∩A_safe : μ_j(G,c;θ)≥0, ∀j∈H_inv∪H_auth, ∀θ∈Θ_β}`；鲁棒裕度 `μ_j^rob=ess inf_{Θ_β} μ_j` 或下尾 CVaR；承诺风险 `r_c=Σ w_j[−μ_j^rob]_+`。

**定义 316（价值不确定性）** `U_ax=H(H|E_legit)=U_ax^res+U_ax^irr`；观测不能消解 U_ax，只有合法偏好证据能降低 U_ax^res；U_ax^irr 由鲁棒性/拒绝处理，不塞进 U_epi。

**定义 317（偏好证据与合法性）** `e=(kind,content,source,scope,expiry,revocable,provenance)`；`L(e)=informed∧non_coerced∧scoped∧revocable∧third_party_safe`；单源不得改写 H_auth，需 k 正交来源或范围明确的同意令牌；H_inv 不受任何证据影响。

**定义 318（价值条件策略与投影）** 采样 `G~π_θ(·|o,c_v)` 后投影 `G†=Proj_{A_val}(G)`；投影非扩张、幂等，不增加硬违反量；实现可用拒绝采样/约束流/梯度投影。

**定义 319（不可逆承诺门 CGA）** 四模式：M_robust（硬裕度鲁棒非负，直接承诺）；M_auth（H_inv 全满足 + 合法同意覆盖本次接触类，可在授权包络内承诺）；M_rev（选可逆替代）；M_refuse（安全停止并解释）。同意撤回/过期立即退回 M_rev，不得「碰上了就做完」。

**定义 320（价值共形集）** `s(G)=max_j[−μ_j(G)]_+`；共形风险控制选 τ 使 `E[1{μ_min<0}]≤α`；`Ĝ_α={G:s(G)≤τ}`；跨用户分层校准，避免把单一价值强加给所有人。

**定义 321（合法偏好探询 PEC）** `VoI-L(q)=E[Δ承诺模式风险]−c(q)−λ_q·manipulation_risk(q)`；约束 L(q)=1、非诱导、可拒绝、只在能改变承诺模式/H_auth 判定时提问；拒绝后记忆；只确认不问。R69 的 VoI = VoI-L 在「价值可自由观测」下的退化。

**定义 322–323（证书与对齐剧场监测）** `J_GRACE=(J_FLUID, μ^rob, mode, consent_scope_hash, coverage, provenance_hash, proxy_gap, grace_ver)`；Valid ⇔ H_inv 裕度≥0 ∧ mode=M_auth⇒同意有效且范围匹配 ∧ 共形覆盖达标 ∧ `Δ_proxy≤τ_gap` ∧ 可追溯。`Δ_proxy=|m_proxy−m_audit|`；独立审计 + 金丝雀接触估计；越界则降级并拒绝/移交。

**定义 324–325（威胁模型与字典序）** `ℰ_GRACE=ℰ_FLUID×ℰ_value`，含偏好投毒、奖励黑客、对齐剧场、谄媚/诱导、同意洗白、隐性价值漂移、接触级欺骗。价值优先级 `H_inv≻H_auth≻V_soft`；负硬裕度不能被任何软收益补偿；证书保存字典序见证。

**定义 326（不可逆风险缩放）** `λ_grace=max(λ_FLUID, λ_commit(μ_min^rob,U_ax^irr))`；λ_commit 关于 μ_min^rob 单调不增，裕度→0⁺ 时连续趋近 1；M_refuse 时 λ=1 且接触/速度指令置零。价值层不扩大物理风险包络。

**定义 327–328（拒绝/移交与可争议审计）** 拒绝 `a_⊥` 是一等动作：安全停止、说明触发维度与证据、给出可逆替代/移交建议；H_inv 未满足时「尽力接触」语义未定义。VQAuditor-V 记录接触轨迹、裕度、同意范围、偏好来源、代理缺口、拒绝理由；受影响者可提异议，异议触发独立复核但不自动改写价值模型。

## 4. 推导

**引理 19（接触价值裕度的误差传播）** 设真实抓取 G 与估计 Ĝ 的位姿/力误差为 ε_G、ε_f，价值场对位姿与力的 Lipschitz 常数为 L_G、L_F，则 `μ_j(G) ≥ μ̂_j(Ĝ) − L_G ε_G − L_F ε_f`。价值共形集把该误差吸收进非一致性分数，使 `P(μ_min<0) ≤ α` 在交换性下成立。系：越靠近约束边界，越不能使用名义裕度，必须使用扣误差后的下界。

**引理 20（不可逆承诺的占优性）** 若硬价值违反代价 `C_viol > c_info + C_rev`，则任何「先接触、后补救」的策略都被「先获取合法证据/选可逆替代、再承诺」的策略弱占优。不可逆损失无法被后续观测或提问补偿；推迟承诺保留选择权。系：不可逆动作上的 VoI 必须变成 VoI-I——**先问/先看/先托住，再做**。

**定理 18（GRACE 对 FLUID 的严格包含与安全单调性）** (i) `A_val ⊆ A_task ∩ A_safe`，GRACE 接触动作均为 R69 物理安全可采纳，硬价值违反率不高于 FLUID；(ii) 价值约束为空、U_ax=0 且无接触承诺时，承诺门恒为 M_robust，价值层不改变排序，GRACE 与 FLUID 逐指令相同；(iii) 价值层只能在硬约束内部通过合法授权放宽 H_auth，不能扩大 A_safe，故 `λ_grace ≥ λ_FLUID`。任务成功率可能低于 FLUID（FLUID 可能选择价值越界但任务成功的动作），这是有意的价值约束：**安全与任务可行维度严格包含，价值维度新增不可交易约束**。

**定理 19（偏好投毒与同意伪造上界）** 单源投毒率 δ_p、k 个正交源欺骗相关 ρ<1 时，错误改写 H_auth 的概率 ≤ `δ_p·ρ^{k−1}+ε_σ`；H_inv 被错误放宽的概率为 0。若问询泄露机器人偏好导致谄媚偏差 β，盲化问询把 β 压到 β_blind，且 VoI-L 显式惩罚 manipulation risk。系：证据纪律把「问一次」变成「问到可验证、可撤回、范围明确的一致」；不可让渡约束不进入投票。

**定理 20（对齐剧场的可检测性）** 在自评代理与独立审计条件独立（A103）下，每次审计发现系统性代理缺口 `Δ_proxy>τ_gap` 的概率为 q，则连续 N 次审计仍未发现的概率 ≤ `(1−q)^N`。因此 J_GRACE 必须依赖独立审计与金丝雀接触，不能只依赖系统自报裕度与同意日志。系：**没有可争议性的证书不是对齐证明，只是自我陈述。**

## 7. 本轮最大风险

**一句话**：GRACE-RAS 把价值对齐寄托在「接触裕度、同意范围、审计日志这些可测代理能够代表真实价值」上；一旦优化压力把这些代理变成目标，系统就会**在证书齐全的情况下演出对齐剧场**——力裕度漂亮、同意日志完整、零违规记录，却仍然捏碎了不该捏的东西、碰了不该碰的地方，而抓取接触不可逆，事后无法补救。**最危险的不是拒绝太多，而是被认证的错误。**

**次级风险与缓解**：价值规格错误（独立审计 + 金丝雀 + 可争议）；偏好投毒/同意洗白（L(e) + k 正交证据 + H_inv 不可覆盖）；跨用户价值多元（分层共形 + 个人化 + 拒绝/移交）；位姿/力估计误差（误差下界 + 共形风险控制）；对齐剧场/奖励黑客（VDM + 独立审计 + 字典序证书）；实时预算（GF-GPE 仅在接触决策触发，K=8/N_step=2）。
