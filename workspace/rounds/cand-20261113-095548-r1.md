# 第 66 轮（承接第 65 轮「VISTA 故障可归因闭环」IP-214~223；灵感循环第 3 轮；本轮灵感：「伦理审查」×「失败恢复」）

> 第 65 轮把"几何可证伪"升级为"故障可归因"，其自述的最大风险一针见血：**归因依赖有限假设集 ℋ、且视觉与几何失效独立；未知复合故障会被 FIR 强行塞进最近假设、只膨胀错误的球，而系统因"已经归因"更自信地继续执行。** 本轮的转向不是再补一个 `H_unknown`，而是承认一个更根本的事实：**"知道自己可能错了"与"知道为什么错"是两件事，而安全不能把前者建立在后者之上。** 伦理审查恰好提供了在"原因不明"时仍能负责行动的成熟制度——预注册协议、独立审查、停止规则、脆弱对象保护、持续复审与撤销权；失败恢复则提供了把"未知"降级为"可承受的一次事件"的工程手段——检查点、回滚/补偿、重认证、渐进恢复。于是本轮核心命题是：
>
> **把"故障可归因"升级为"可问责且可恢复"：把行动权从诊断中分离出来；用独立审查者的 anytime-valid 停止规则在无归因时也能负责地暂停；用带检查点的失败恢复把误归因的伤害压成有界一次事件；用"恢复必须重新举证"阻止系统凭时间自动恢复自信。**

## 0. 直觉与动机

**灵感 1（伦理审查 → 归因是认识论问题，问责是程序问题）**
直觉：IRB 从不要求"先证明是哪个环节导致了不良事件"才暂停试验。它依靠**预注册协议 + 停止规则 + 独立审查 + 持续复审 + 撤销权**，在因果不明时仍能负责地行动。这正是 VISTA 缺的东西：VISTA 把"继续执行"的默认值绑在"归因置信度"上，而未知故障恰恰让归因置信度不可信。伦理审查的核心不是更聪明的诊断，而是**权力分离**——提议者（策略/世界模型）不能同时是批准者、执行者与审计者。严格地说，协议是一个**先于部署冻结的承诺**：作用域、风险预算、停止规则、易损对象政策、恢复计划、有效期；审查者只能在协议内授权，且可以**限制、暂停、撤销、升级人工**。这把安全从"模型内部的后验"变成"外部可检查的契约"。

**灵感 2（伦理审查 → 不知道也要披露：知情同意与脆弱性分级）**
直觉：知情同意不是"保证没有风险"，而是**如实披露已知与未知**。VISTA 把 `visual_unobservable`、`ambiguous` 埋在证书字段里却继续执行；CURATOR 要求把这些"已知的未知"提升为一等公民：不可观测、归因模糊、未知故障簇都必须显式披露，并由审查者决定"是否允许在该披露下继续"。同时，伦理审查区分普通参与者与**脆弱对象**（人、易损物体、不可逆操作）：脆弱对象享受更低的默认风险预算、更强的保护与更高的授权门槛。这把 VISTA 的"易损物体禁用接触探针"从一条局部规则升级为**全局分级授权**。

**灵感 3（失败恢复 → 恢复把"不可逆的归因错误"变成"可承受的一次事件"）**
直觉：VISTA 的最大恐惧是"归因错了还更自信地继续"，因为继续可能越过不可逆点。失败恢复改写风险结构：只要 (i) 每个块边界有安全检查点（RPO ≤ m），(ii) 每条已执行动作都是可回滚或可补偿的（可逆性 R1 以内），(iii) 暂停后必须重新举证才能恢复，那么一次错误归因最多造成**一个有界 episode + 一次回滚成本**，而不是灾难。恢复不是"重启"，而是**受治理的状态迁移**：hold → compliant retreat → rollback/compensate → re-attest → reduced-scope resume → human takeover。它与第 65 轮的 k* 天然衔接：**检查点落在认证前缀边界，恢复时间上界由不可逆视界 m 决定**。

**灵感 4（两灵感合流 → CURATOR：Certificate-gated Uncertainty-aware Recovery And Temporary Authorization of Robots）**
闭环：协议预注册（PRC）→ 运行中独立审查（IRS）→ 无归因 anytime-valid 暂停（URM）→ 比例响应与可逆性分级（RCL）→ 检查点/回滚/补偿（CPS/RGE）→ 重认证与恢复证书（RAC）→ 恢复后缩小作用域（棘轮）→ 不良事件账本（AEL）→ 持续复审与协议修订（URM→PRC）。第 65 轮是"语义流 × 实时流"；CURATOR 增加第三条**权流（authority stream）**：提议、批准、执行、审计四种角色分离，任何一方都不能单独把系统从"暂停"改回"继续"。

**灵感 5（VISTA 组件的原位升级 / 挂载）**
- **FIR → FIR+**：归因不再是继续执行的前提；后验只用于选择**最小限制的处置**，不作为通行证。
- **CSC → CSC-C**：认证前缀同时产出检查点；k* 既是不越界承诺，也是 RPO 上界。
- **AFA → AFA-C**：探针先过协议审查（信息增益 vs 风险）；易损对象默认只批 `visual_probe` / `null_test`。
- **AIC-V → AIC-C**：干扰集增"审查者与策略共因失效""检查点投毒/重放""恢复后重复失效"。
- **J_vista → J_curator**：证书增 protocol/approval/scope/suspension/checkpoint/RAC/AEL/independence/RTO。
- **新增 PRC / IRS / URM / AEL / CPS / RGE / RAC / RCL**：把审查与恢复做成可执行基础设施，而非事后文档。

## 1. 形式化定义（增量：定义 233–246）

- **定义 233（CURATOR 闭环）**：CURATOR = (VISTA, PRC, IRS, URM, RCL, CPS, RGE, RAC, AEL, J_curator)。定位：VISTA 的"可问责 + 可恢复"升级。不变式：**语义流做推断与归因；权流做批准、暂停、撤销、复审；实时流只执行已批准的认证前缀与预编译恢复原语，零学习写、零在线授权扩张。** 三流之间只通过签名的证书与账本通信。
- **定义 234（操作协议与批准包）**：协议 P=(𝒮 作用域, ε_p 风险预算, τ_stop 停止规则, 𝒱_p 脆弱对象政策, Π_rec 恢复计划, T_exp 有效期, amend 修订史)。批准 A=(hash(P), 条件, 作用域, 到期, reviewer_sig)。执行合法 ⇔ a_t∈𝒮 ∧ Valid(J_vista) ∧ Valid(A, t)。协议必须**在部署前冻结**；任何修订都要重新审查，禁止运行时自改标准。
- **定义 235（可逆性分级与比例响应格）**：动作按物理后果分为 R0 可逆、R1 可补偿、R2 不可逆。响应集合 ℒ={continue, restrict_scope, hold, compliant_retreat, rollback, compensate, human_takeover, safe_stop}，按限制强度构成偏序。比例响应 = 在恢复不变式的前提下选**限制最轻**的元素（least restrictive means）；R2 动作需 2-of-2（策略证书 + 独立审查/人工确认）。这把"一有异常就全停"换成"按可逆性与风险分级处置"。
- **定义 236（无归因暂停：e-process）**：将阶段残差压成健康零假设 H0 下的非负检验鞅 E_t=∏_{s≤t}(1+λ_s·(g(z_s)−μ0))（或 betting e-process）。由 Ville 不等式，对任意停止时间 τ，P_{H0}[sup_{t≤T} E_t ≥ 1/α_stop] ≤ α_stop。**该保证不需要指定对立假设**，因此对未知/复合故障同样有效：系统在"不知道为什么"时也能按预注册规则合法暂停。暂停规则写入协议，避免可选的连续检验膨胀假阳性。
- **定义 237（失败恢复关系与恢复算子）**：恢复算子 R_Π: s→s′，带成本 c(R)（时间、能量、任务损失）与残余风险 ρ(R)。称 s 在预算 B 内可恢复至批准包络 ℰ_A，若存在恢复计划使 c(R)≤B、s′∈ℰ_A，且恢复轨迹始终留在安全集内。物理对应：恢复点 = 最近安全检查点（RPO），恢复时间 = 从检出到重新批准（RTO）。**恢复不是假设，而是需要被证书证明的能力。**
- **定义 238（安全检查点与 RPO）**：在认证前缀边界 k* 处落检查点，快照 (φ̂, 力偏置 b̂, 标定版本, 几何哈希, 任务状态, protocol_id, J 哈希)。检查点可恢复 ⇔ 其 provenance 与当前硬件/标定版本匹配；不匹配则必须先重认证。RPO = 两个检查点之间的最大工作量 ≤ k* ≤ m。检查点本身要防投毒/重放（哈希链 + 版本号 + 只读存储）。
- **定义 239（重认证与恢复证书 RAC）**：RAC=(checkpoint_id, 重认证证据 {null_test, geom_reverify, conformal_recalib, Δb̂}, post_recovery_J_vista, suspension_event_id, hysteresis h)。恢复执行资格 ⇔ Valid(RAC) ∧ 协议仍有效 ∧（预授权范围内自动，否则独立审查批准）。重认证必须回答"**世界是否真的回到了检查点语义**"，而不只是"软件是否重启成功"。
- **定义 240（有界伤害界）**：总伤害 H_total ≤ H_episode + H_recovery，H_episode ≤ h_max·τ_detect。若故障相对健康分布的 KL 下界为 κ，则 E[τ_detect] ≤ log(1/α_stop)/κ。若所有已执行动作 r(a)≤R1，则**不可逆伤害为 0**，只剩可补偿成本。即：恢复能力把"归因错误"从不可逆灾难降级为有界 episode。
- **定义 241（未知故障发现与协议修订）**：URM 对未被 ℋ 解释的残差签名做 conformal novelty / 密度聚类；当某簇质量超过阈值 δ_unk，开启"不良事件调查"，产出新假设 H_new 或协议修订案，经审查后**离线**并入 ℋ 与 P，禁止在线即时扩张假设集来"解释掉"异常。定义发现延迟与遏制率；未知故障的正确处置是**遏制 + 调查**，不是强行归因。
- **定义 242（审查者独立性）**：审查者不得与被审策略共享参数、训练数据与标定集；其统计量只用残差流、外部账本与独立通道（IMU/本体感觉/人工）。独立性等级 I0 同源、I1 数据分离、I2 传感器分离、I3 人工独立。**共因失效的根因不是"没归因"，而是"审查者与被审者共享同一个盲区"**；I 等级写入 J_curator，低等级时默认降低风险预算。
- **定义 243（棘轮原则 / 单调恢复）**：一旦发生暂停、未知故障或归因冲突，安全包络只能收缩，直到 RAC 提供新证据；恢复后的作用域 𝒮′ ⊆ 𝒮（可测收缩），禁止仅凭"过了一段时间"自动恢复。形式化：ℰ_{t+1} ⊆ ℰ_t，除非新增证据证书；这防止系统在未解决问题上反复"恢复—再失效"的振荡。
- **定义 244（权限格与可争辩性）**：权限格 𝒜={autonomous, supervised, human_approval, human_only}，升级由风险预算、可逆性、脆弱对象与独立性共同决定。可争辩性：人工否决/接管必须记录理由；系统必须给出"审查包"，说明**哪一条协议子句**触发了暂停/限制，以及恢复需要哪些证据。知情同意：证书必须显式列出已知未知（`visual_unobservable`, `ambiguous`, `unknown_cluster`），不得把不确定性折叠成一个漂亮的后验。
- **定义 245（CURATOR 证书 J_curator）**：J_curator=(J_vista, protocol_hash, approval_scope, suspension_state, checkpoint_id, rac_hash, ael_head, independence_level, rto_bound, next_review_at)。Valid ⇔ Valid(J_vista) ∧ in_scope ∧ (未暂停 ∨ Valid(RAC)) ∧ 协议未过期 ∧ 审查者独立性达标 ∧ RTO≤m ∧ 账本可审计。证书从"我安全"升级为"**我在被批准的范围内、可被审计、且能退回**"。
- **定义 246（三流算子）**：语义流 [VISTA 全链 → 阶段签名 → 归因（仅用于选处置） → 提议块]；权流 [PRC 协议匹配 → IRS 批准/限制/暂停/撤销 → URM e-process → RCL 比例响应 → RAC 重认证]；实时流 [锚点读 → 残差采集 → 预编译暂停原语 → 检查点落盘 → 前缀执行/早停]。权流是低频但**有否决权**的线程；实时流永不自行解除暂停。

## 2. 关键算法骨架

```python
# URM：无归因暂停（anytime-valid，权流）
E = 1.0
for z in residual_stream(phases):
    E *= 1.0 + lam * (score(z) - mu0)        # 非负检验鞅 / e-process
    if E >= 1.0 / alpha_stop:                # Ville：全程假暂停 ≤ alpha_stop
        irs.suspend(event='anytime_alarm', evidence=E)
        break

# IRS：审查状态机（提议者 ≠ 批准者 ≠ 执行者 ≠ 审计者）
state = 'APPROVED'
if not in_scope(action) or not Valid(j_vista):      state = 'RESTRICT'
if urm.alarm or unknown_cluster or disclosure_gap:  state = 'SUSPEND'
if common_cause() or protocol_expired():            state = 'REVOKE'
if state == 'SUSPEND':
    rge.run_ladder(last_certified_checkpoint)       # 实时只跑预编译原语
    state = 'PENDING_RAC'

# RGE：恢复阶梯（比例响应）
def recover(s):
    hold(); compliant_retreat()
    s = rollback(last_checkpoint)                   # RPO ≤ m
    compensate(undo_log)                            # 仅 R1
    if not re_attest(s): return escalate_human()
    return restricted_resume(scope=s.shrink())      # 棘轮：不自动扩张

# RAC：重认证（回答"世界是否真的回去了"）
rac = ReAttestationCertificate(
    checkpoint_id, null_test_bias, geom_reverify, conformal_recalib,
    post_recovery_J, hysteresis=h)
if Valid(rac) and irs.approve(rac):
    lift_suspension()                               # 只有权流能解除
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（无归因暂停的 anytime 有效性）**：e-process 在 H0 下为非负鞅，Ville 不等式给出 P[sup E_t≥1/α] ≤ α，**无需指定对立假设**。因此对未知/复合故障，暂停规则仍有全程假暂停率控制；这是 VISTA 的逐块 α 做不到的，也是"原因不明也能负责地停"的统计基础。
- **引理 10（恢复能力给出有界伤害）**：若检查点间隔 ≤k*≤m、已执行动作 r(a)≤R1，则即使归因完全错误，H_total ≤ h_max·τ_detect + c(R)，且不可逆伤害为 0；τ_detect 的期望由 KL 下界 κ 与 α_stop 控制。**误归因不再是一次不可逆事故，而是一次有界 episode。**
- **命题（归因优先 vs 问责优先）**：VISTA 的继续概率 = P[后验集中]；未知故障常被映射到最近的 H 并获得虚高置信，继续概率→1；CURATOR 的继续概率 ≤ α_stop + β_detect，与 ℋ 是否正确无关。**把"继续"的默认值从后验改成协议与检验。**
- **定理 9（CURATOR 端到端可问责）**：Valid(J_curator) ⇒ (i) 动作在批准作用域内；(ii) 误归因至多造成一个有界 episode 且可回滚/补偿；(iii) 任何恢复都必须有 RAC 重新举证且包络单调；(iv) 未知故障被遏制并进入协议修订，而非被强行归类；(v) 全过程有不可篡改账本可复审。即使 ℋ 不完备，结论仍成立——**因为暂停不依赖 ℋ**。
- **定理 10（最小限制与权力分离）**：比例响应格在恢复不变式的可行集中给出最小限制元素；四角色分离使任何单一组件无法把系统从暂停改回继续，从而消除"归因越自信越危险"的反馈回路。
- **实时性**：CURATOR 的实时增量为检查点落盘（≤0.3ms，块边界做）与预编译暂停原语（≤0.1ms）；e-process/审查/恢复规划全在权流。目标 ≤2.8ms（A94 修订契约）。

## 5. 本轮最大风险

## 2. 形式化定义（完整版）

**定义 233（CURATOR 闭环）** CURATOR 是 VISTA 的"可问责 + 可恢复"升级，由三条流组成：
- **语义流**：VISTA 的几何/视觉/力推断、阶段签名、故障归因（仅用于选择最小限制处置，不作为继续执行的通行证）、块提议。
- **权流（authority stream）**：协议匹配与批准（PRC/IRS）、无归因暂停（URM）、比例响应（RCL）、重认证（RAC）、持续复审与撤销（AEL）。
- **实时流**：残差采集、认证前缀执行、预编译暂停原语、块边界检查点落盘。

不变式：**语义流不能自我批准；实时流不能解除暂停；权流不能改写物理证据。** 三流只通过签名的证书（J_vista/J_curator/RAC）与只读账本通信。所有学习写操作只在语义流，权流只做低频决策，实时流零学习写。

**定义 234（操作协议与批准包）** 协议是部署前冻结的安全承诺
P=(𝒮, ε_p, τ_stop, 𝒱_p, Π_rec, T_exp, amend)，
其中 𝒮 为作用域（任务族、物体类别、环境包络），ε_p 为风险预算，τ_stop 为预注册停止规则（含 URM 的 α_stop 与 CSC 的 α_chunk），𝒱_p 为脆弱对象政策（人/易损物/不可逆操作的保护级别），Π_rec 为恢复计划（检查点策略、回滚/补偿原语、重认证清单、RTO 上界），T_exp 为有效期，amend 为修订史。批准包
A=(hash(P), conditions, scope, expiry, reviewer_sig)。
执行合法 ⇔ a_t∈𝒮 ∧ Valid(J_vista) ∧ Valid(A,t)。**协议冻结先于部署**：任何修订必须重新审查；禁止运行时修改风险预算、停止规则或作用域来自证合规。

**定义 235（可逆性分级与比例响应格）** 每个动作按物理后果分为：R0 可逆（移动、松手、退让）、R1 可补偿（可反向恢复且无残留，如推后可拉回、可取回的重放）、R2 不可逆（切割、粘接、塑性变形、接触人、污染、跌落）。响应集合
ℒ={continue, restrict_scope, hold, compliant_retreat, rollback, compensate, human_takeover, safe_stop}，
在四维（作用域收缩、运动停止程度、状态回退程度、权限上移）上构成乘积偏序 ≼。比例响应定义为
resp*(s)=min_{≼}{ℓ∈ℒ : Inv(s,ℓ) ∧ c(ℓ)≤B}，
即恢复不变式可行集中限制最轻的元素。R2 动作需要 2-of-2 授权：`Valid(J_curator)` ∧（独立审查或人工确认）；任一缺失即降级为 hold。**这条把"一有异常就全停"的过度保守与"归因自信就继续"的过度冒险同时替换为分级处置。**

**定义 236（无归因暂停：e-process）** 将阶段残差压为标量得分 g(z_t)（由 VISTA 的 ρ 经固定、部署前冻结的映射得到），在健康零假设 H0 下构造非负检验鞅
E_t=∏_{s=1}^{t}(1+λ_s(g(z_s)−μ0))，λ_s 有界且可预注册，
或等价的 betting e-process / 混合似然比。由 Ville 不等式，对任意停止时间 τ，
P_{H0}[sup_{t≤T} E_t ≥ 1/α_stop] ≤ α_stop。
关键：**该界不要求指定对立假设**，因此对未知/复合故障仍成立；系统可在"不知道为什么"时依法暂停。暂停规则 τ_stop 必须在协议中预注册，避免连续监测下的可选停止导致假阳性膨胀。当 e-process 增长不足（κ≈0，故障不可观测）时，系统不假装能检测，而是依赖 R1 可逆性与 2-of-2 授权兜底（诚实退化）。

**定义 237（失败恢复关系与恢复算子）** 给定恢复计划 Π_rec，恢复算子 R_Π: s→s′ 由恢复阶梯复合而成。恢复成本 c(R) 含时间、能量与任务损失，残余风险 ρ(R) 含恢复动作自身引入的风险。称状态 s 在预算 B 内可恢复至批准包络 ℰ_A，若存在 R_Π 使
c(R)≤B， ρ(R)≤ε_p， R_Π(s)∈ℰ_A，
且恢复轨迹 {s_τ} 始终留在安全集内。定义
RTO = min{t : 从检出起经恢复与重认证重新批准}，RPO = 最近可恢复检查点与当前状态的语义距离。
**恢复能力不是口头承诺，而是必须由 CPS/RGE/RAC 证书证明的对象；无法证明时不得执行相应动作。**

**定义 238（安全检查点与 RPO）** 在认证前缀边界 k* 处落检查点
ckpt=(φ̂, b̂, calib_ver, geom_hash, task_state, protocol_hash, J_hash, prev_hash)。
检查点可恢复 ⇔ provenance 与当前硬件/标定版本匹配（calib_ver、序列号、固件哈希一致）；否则必须先重认证。RPO≤k*≤m。检查点存储只读、哈希链、带单调版本号，防投毒与前缀重放；恢复时校验链首与 IRS 记录一致。**检查点是"物理世界可退回"的锚，而不是软件快照。**

**定义 239（重认证与恢复证书 RAC）** 重认证回答"世界是否真的回到了检查点语义"：
RAC=(ckpt_id, null_test(b̂), geom_reverify, conformal_recalib(q_vis), Δb̂, post_recovery_J_vista, suspension_event_id, hysteresis h)。
Valid(RAC) ⇔ 零力窗偏置复测通过 ∧ 几何复核与 ckpt 的 geom_hash 一致 ∧ conformal 残差覆盖恢复 ∧ 无新的未知簇 ∧ 迟滞 h 满足。恢复执行资格 ⇔ Valid(RAC) ∧ 协议仍有效 ∧（在预授权范围内自动，否则 IRS 批准）。**软件重启成功不算恢复；只有物理证据算。**

**定义 240（有界伤害界）** 设风险率上界 h_max、检出时延 τ_detect、恢复成本 c(R)。则
H_total ≤ h_max·τ_detect + c(R)。
若故障相对健康分布的 KL 下界为 κ，anytime e-process 在备择下的期望检出时延满足
E[τ_detect] ≤ log(1/α_stop)/κ（量级）。
若所有已执行动作 r(a)≤R1，则**不可逆伤害为零**，只剩可补偿成本；若某动作 r(a)=R2，则必须 2-of-2 且其风险预算单独核算。推论：**恢复能力把"归因错误"从不可逆灾难降级为有界 episode；而 R2 动作是这条界唯一不能兜底的地方。**

**定义 241（未知故障发现与协议修订）** URM 对未被 ℋ 解释的签名 ρ 计算 conformal novelty p 值；p<α_unk 进入"未解释池"。对池内样本聚类（DBSCAN/密度），当某簇质量 m_c 超过 δ_unk 且持续 T_unk，开启不良事件调查：
investigate(c)→(H_new, ΔP)，
经 IRS 审查后**离线**并入 ℋ 与协议。禁止在线即时扩张假设集来"解释掉"异常；未知故障的正确处置是**遏制 + 调查 + 修订**，不是强行归因。定义发现延迟 T_disc 与遏制率 C_rate。

**定义 242（审查者独立性）** 审查者不得与被审策略共享参数、训练数据与标定集；其统计量只用残差流、外部账本与独立通道。独立性分级：
- I0 同源（共享传感器/标定），
- I1 数据分离（独立标定集），
- I2 传感器分离（独立物理通道，如 IMU/本体感觉/外部相机），
- I3 人工独立（人工作为审查者）。
定义失效模式重叠率 λ_ind =（同时骗过审查者与被审策略的注入故障数）/（总注入故障数）。要求执行时 I≥I1 且 λ_ind≤λ_max；否则风险预算 ε_p 按 (1−λ_ind) 缩减，低到阈值以下时强制 human_only。**共因失效的根因不是"没归因"，而是"审查者与被审者共享同一个盲区"。**

**定义 243（棘轮原则 / 单调恢复）** 一旦发生暂停、未知簇或归因冲突，安全包络只能收缩：
ℰ_{t+1} ⊆ ℰ_t，除非新增证据证书 RAC（且 RAC 只能把包络恢复到最近一次审查批准的子集）。
恢复后的作用域 𝒮′⊆𝒮 为可测收缩（如缩小速度/力限、排除可疑物体类）。禁止仅凭"过了一段时间"或"策略置信度回升"自动解除暂停。形式化：解除暂停的谓词只依赖证据（RAC/人工），不依赖时间或模型自评。

**定义 244（权限格与可争辩性）** 权限格
𝒜={autonomous, supervised, human_approval, human_only}，
升级映射由风险预算、可逆性、脆弱对象与独立性共同决定：R2 或含人或 λ_ind>λ_max ⇒ ≥human_approval。可争辩性：人工否决/接管必须记录理由；系统必须给出**审查包**
review_packet=(触发子句 id, 证据摘要, 当前 J_curator, 恢复所需证据清单, 可选处置)，
使人类能在有限时间内判断"为什么停、怎么恢复"。知情同意：J_curator 必须显式列出 `visual_unobservable`、`ambiguous`、`unknown_cluster`，不得把不确定性折叠成一个漂亮的后验后当作已知。

**定义 245（CURATOR 证书 J_curator）** 
J_curator=(J_vista, protocol_hash, approval_scope, suspension_state, checkpoint_id, rac_hash, ael_head, independence_level, rto_bound, next_review_at)。
Valid(J_curator) ⇔
Valid(J_vista)
∧ a_t∈𝒮 ∧ Valid(A,t)
∧ (suspension_state=APPROVED ∨ Valid(RAC))
∧ protocol 未过期
∧ independence_level≥I1 ∧ λ_ind≤λ_max
∧ RTO≤m
∧ ael_head 与只读账本一致（未被篡改）。
审计链新增：为什么允许这一动作（协议子句）、为什么暂停（e-process/未知簇）、凭什么恢复（RAC）、谁批准（reviewer_sig）。

**定义 246（三流算子）** 
- **语义流**：[LSF/几何 → VISTA 全链 → 阶段签名 → 归因（仅选处置） → 块提议 → J_vista]。
- **权流**：[PRC 协议匹配 → IRS 状态机 → URM e-process/未知簇 → RCL 比例响应 → RAC 重认证 → AEL 追加 → 持续复审/撤销]。
- **实时流**：[锚点读 → 残差采集 → 预编译暂停原语 → k* 执行/早停 → 块边界检查点落盘 → J_curator 构建]。
权流低频但**有否决权**；实时流永不自行解除暂停；语义流不得修改协议与账本。

```python
class ProtocolReview:
    """把安全论证编译为部署前冻结的协议；运行时只做匹配，不改协议。"""
    def register(self, task_family, safety_case, reviewer):
        P = freeze(
            scope=task_family.scope,
            epsilon=safety_case.risk_budget,
            stop_rule={'alpha_stop': safety_case.alpha_stop,
                       'alpha_chunk': safety_case.alpha_chunk},
            vulnerable=safety_case.vulnerable_policy,
            recovery_plan=safety_case.recovery_plan,
            expiry=now() + safety_case.valid_for,
            amend=[])
        return Approval(hash_of(P), conditions=safety_case.conditions,
                        scope=P.scope, expiry=P.expiry,
                        reviewer_sig=reviewer.sign(hash_of(P)))

    def match(self, action, P, A, t):
        if t > A.expiry or hash_of(P) != A.protocol_hash:
            return 'REVOKE'
        if not P.contains(action):
            return 'RESTRICT'
        return 'APPROVED'
```

### IP-225/226 IRS + URM（独立审查 + 无归因暂停）

```python
class IndependentReviewSupervisor:
    """四角色分离：proposer(policy) / approver(IRS) / executor(RGE) / auditor(AEL)。"""
    STATES = ('APPROVED', 'RESTRICT', 'SUSPEND', 'PENDING_RAC', 'REVOKE')

    def review(self, j_vista, urm, scope, protocol, ael):
        state = 'APPROVED'
        if not protocol.contains(scope.action) or not Valid(j_vista):
            state = 'RESTRICT'
        if urm.alarm() or urm.unknown_cluster_active() or j_vista.disclosure_gap:
            state = 'SUSPEND'
        if self.common_cause_detected() or protocol.expired():
            state = 'REVOKE'
        self._log_state(state, j_vista, ael)      # 只追加，不可改
        return state

    def lift(self, rac, protocol):
        # 只有权流能解除；且只依赖证据，不依赖时间或模型自信
        return Valid(rac) and protocol.still_valid() and self.approve(rac)


class UnattributableResidualMonitor:
    """e-process：无需指定对立假设的 anytime-valid 暂停。"""
    def __init__(self, alpha_stop, mu0, lam, delta_unk=0.05, alpha_unk=0.01):
        self.E, self.alpha_stop, self.mu0, self.lam = 1.0, alpha_stop, mu0, lam
        self.delta_unk, self.alpha_unk = delta_unk, alpha_unk
        self.unexplained = []

    def update(self, z, explained_by_H):
        g = frozen_score(z)                        # 部署前冻结，禁止在线调参
        self.E *= max(0.0, 1.0 + self.lam * (g - self.mu0))
        if not explained_by_H:
            if conformal_pvalue(z) < self.alpha_unk:
                self.unexplained.append(z)         # 未知簇候选
        return self.E >= 1.0 / self.alpha_stop

    def unknown_cluster_active(self):
        return cluster_mass(self.unexplained) > self.delta_unk
```

```python
def CURATOR_round(M, obs, protocol, approval, reviewer):
    V, T, P, L, W, tactile, img, depth, flow = obs
    # ———— 语义流 ————
    x_prime = M.lsf.fuse(M.usr.fuse(V, T, P, L))
    visual = M.vpg.verify_and_predict(M.f_vis(img, depth, flow), None, M.contacts)
    post, h_star, ambiguous = M.fir.attribute(M.stage.split(M.residual_log, visual))
    j_vista = build_j_vista(M, post, ambiguous, visual)

    # ———— 权流（有否决权）————
    alarm = M.urm.update(M.stage.last_z(), explained_by_H=(not ambiguous))
    state = reviewer.review(j_vista, M.urm, protocol, M.ael)
    if alarm or state == 'SUSPEND':
        M.ael.append(event='suspension', post=post, urm_E=M.urm.E,
                     disclosure=j_vista.disclosure)
        ckpt = M.cps.restore(M.cps.last_committed())
        M.rge.run_ladder(M.state, ckpt, M.undo_log, M.rcl)
        return safe_hold(), 'SUSPEND'

    # ———— 规划 + 认证前缀 + 检查点 ————
    A = M.ach.propose(x_prime, H=M.H)
    resp = M.rcl.least_restrictive(j_vista, ambiguous, M.state)   # 比例响应
    k_star = M.csc.certified_prefix(A, post, M.m, protocol.alpha_chunk)
    ckpt_id = M.cps.commit(k_star, M.state, protocol, j_vista)
    # ———— 实时流：只执行被批准的前缀 ————
    for a in A[:k_star]:
        if M.rcl.class_of(a) == 'R2' and not two_of_two(j_vista, reviewer):
            break
        dispatch(a)
        if M.urm.alarm() or M.csc.monitor_step(a, post).abort:
            break
    # ———— 事后：账本 + 复审 ————
    M.ael.append(event='block', k_star=k_star, ckpt=ckpt_id,
                 protocol=hash_of(protocol), j_hash=hash_of(j_vista))
    return j_vista, resp, ckpt_id
```

## 4. 推导

**引理 9（无归因暂停的 anytime 有效性）** 设 {E_t} 在 H0 下为非负鞅且 E_0=1。由 Ville 不等式，对任意（可能依赖数据的）停止时间 τ，
P_{H0}[∃t≤τ: E_t ≥ 1/α_stop] ≤ α_stop·E[E_0] = α_stop。
由于构造中未指定或拟合任何具体对立假设，该界对任意未知/复合故障 H_u 的"健康与否"二分仍成立：我们检验的是"H0 是否仍能解释残差"，而不是"是哪一个 H"。因此暂停不需要归因正确，也不需要 ℋ 完备。报文中的 e-process 需用有界得分与有界 λ 保证非负性；若某个 λ_s 使因子为负，则钳到 0 并终止（等价于提前拒绝）。∎

**引理 10（恢复能力给出有界伤害）** 设检查点间隔 ≤k*≤m，已执行动作 r(a)≤R1。故障在 t0 激活，τ_detect 内被 e-process 检出（或未被检出但动作可补偿）。则累计伤害
H_total ≤ ∫_{t0}^{t0+τ_detect} h(t)dt + c(R) ≤ h_max·τ_detect + c(R)。
对备择故障 H_u，若 KL(H_u‖H0)=κ>0，e-process 的对数增长率期望 ≥κ，达到 log(1/α_stop) 的期望时间 ≤log(1/α_stop)/κ（可选停止下的 Wald 型界）。R1 动作存在补偿算子使状态语义回到检查点，故不可逆伤害为 0。若存在 R2 动作，则定义 235 要求 2-of-2，且其风险不在此界内，需单独预算。∎

**命题（归因优先 vs 问责优先）** 设未知故障 H_u 不在 ℋ 中，且 FIR 将其映射到最近假设 H_j，后验置信 1−δ_j。VISTA 的继续条件为 max_H P(H|ρ)≥1−δ_fi，故当 δ_j≤δ_fi 时继续概率为 1；未知故障恰恰常产生"在错误假设下很典型"的签名，导致高置信误归因，继续概率→1。CURATOR 的继续条件为"无 anytime 报警 ∧ 在协议内 ∧ 可恢复"，与 ℋ 无关；对可观测故障（κ>0），不安全继续概率 ≤β_detect + α_stop（β_detect 为 e-process 在不可逆点前的漏检）；对不可观测故障（κ≈0），由 R1 可逆性与 2-of-2 兜底，把不可逆伤害压到 0。**这就是"把继续的默认值从后验改成协议与检验"的收益。** ∎

**定理 9（CURATOR 端到端可问责）** 在 A94–A98 下，若 Valid(J_curator)，则：
1. **作用域安全**：动作在协议批准范围内，且 J_vista 有效；
2. **误归因有界**：即使 ℋ 不完备或 FIR 归因错误，引理 10 给出 H_total≤h_max·τ_detect+c(R)，且 r(a)≤R1 时不可逆伤害为 0；
3. **恢复受证据门控**：任何解除暂停都必须有 Valid(RAC)；RAC 校验物理世界（偏置/几何/conformal）而非软件重启；
4. **包络单调**：棘轮原则保证 ℰ_{t+1}⊆ℰ_t，恢复后作用域收缩；
5. **未知故障被遏制而非被解释掉**：URM 未解释簇触发调查与协议修订，禁止在线强行归类；
6. **审计完整**：AEL 哈希链记录 suspension/k_star/ckpt/protocol/J_hash，可重放复审。
即使 VISTA 的"故障属于有限假设集"假设失效，1–6 仍成立，因为暂停与恢复**不依赖归因正确**。∎

**定理 10（最小限制与权力分离）** 比例响应在恢复不变式 Inv 的可行集 ℱ={ℓ∈ℒ: Inv(s,ℓ)∧c(ℓ)≤B} 上取 ≼ 最小元；因 ℒ 在四维乘积偏序下是有限格，ℱ 非空时最小元存在。权力分离把"提议—批准—执行—审计"映射到四个不相交组件：策略只能 propose，IRS 只能 approve/suspend/revoke，RGE 只能执行预编译恢复原语，AEL 只能 append。任何单一组件都无法单独构造"继续"的合法状态（继续需 Valid(J_vista)∧Valid(A)∧¬suspension），从而切断"归因越自信→越敢继续→越危险"的正反馈。∎

**推论（合规表演的形式边界）** 若 independence_level=I0 或 RAC 未验证物理恢复，则 J_curator 的 Valid 谓词直接为假；因此"有审查文档但无独立性/无物理恢复"在 CURATOR 中不是弱安全，而是**不可执行**。这把"合规表演"从一种隐性风险变成显式的证书失败——但前提是我们真的执行独立性审计与物理重认证（见风险节）。

## 7. 已知风险

**一句话**：CURATOR 的安全性建立在两个未经证明的假设上——**审查者真的独立，且"可恢复"真的可恢复**；现实中审查者常与策略共享传感器、标定与共因盲区（透明/镜面/对抗 patch 同时骗过两者），而物理世界的形变、污染、夹伤与人身受伤害往往只可"名义回滚"、不可真正撤销——此时 CURATOR 会产出一份程序完美、审计合规的失败记录，把"暂停"变成**事后追认的合规表演**，系统获得的是问责的幻觉而非安全。

**次级风险与缓解**：
1. **合规表演 / 纸面安全**：审查变成盖章。缓解：独立性等级与 λ_ind 写入 Valid 谓词；I0 直接不可执行；账本对外部只读；定期红队审计审查者本身。
2. **名义恢复 ≠ 物理恢复**：软件回滚无法撤销塑性变形/污染/人身伤害。缓解：动作分级 R0/R1/R2；R2 一律 2-of-2；RAC 必须做物理复测；对不可逆动作单独风险预算。
3. **共因失效**：审查者与策略共享盲区。缓解：I2/I3 独立通道（IMU/本体感觉/人工）；低独立性自动降风险预算；共因下只要求遏制与人工升级。
4. **e-process 统计功效不足**：κ 小、故障缓慢漂移时检出慢。缓解：预注册 α_stop 与得分函数；多通道 e-process 组合（Fisher/混合）；不可观测时诚实退化为 R1 + 人工。
5. **检查点投毒/重放**：攻击者篡改检查点让恢复回到不安全状态。缓解：只读存储 + 哈希链 + 单调序号 + provenance 绑定；恢复时与 AEL 交叉校验。
6. **协议覆盖不足 / 分布外任务**：协议没写到的情形被拒或误用。缓解：作用域外默认 RESTRICT；定期复审扩域；OOD 检测触发协议修订而非静默扩权。
7. **恢复振荡 / 反复暂停-恢复**：未根治就恢复导致抖动。缓解：棘轮原则 + 迟滞 h + 连续暂停计数升级人工；包络只缩不涨。
8. **审查延迟影响实用性**：权流低频决策可能拖慢任务。缓解：预授权范围内自动批准；R0/R1 走快速通道；恢复原语预编译；把复杂调查全部离线。
9. **责任归属仍可能悬空**：多角色分离后"谁负责"可能更难界定。缓解：AEL 记录 reviewer_sig 与人工理由；审查包显式给出触发子句；保留人工最终否决权。
10. **评测自证**：用自家协议/账本证明安全。缓解：外部审计、独立红队、预注册评测契约、报告统计功效而非只报"违规=0"。
