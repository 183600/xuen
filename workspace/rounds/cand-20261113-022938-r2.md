# 第 3 轮迭代（灵感循环 v3：「异常检测」×「深度相机」）—— 把"进度"变成可测量的物理量

> 承接状态文件里的 v2（UIP-01′~15）。本轮不是继续加模块，而是**替换"裁判"**：v2 的验证器靠"手写几何谓词 + 外部 VLM + Gazebo 全场景计分神谕"，脆弱、昂贵、且有单模型合规风险。两个新词给出一条更硬的合并路线：**用双目深度把"进度"从语义概念变成米制物理量，用自监督异常检测把"被撤回/被挪动/被卡住"统一成同一种偏离，再用保形预测给"误重做"一个可证明的误报上界。**
>
> 同时本轮**修正 v2 的一个接口级硬错误**：`action_chunk_size` 在 metadata 里一次声明，`get_action` 返回的每个动作数组必须**恰好** `(T_a, …)`（`example/example_env.py:164` 逐键硬校验）。因此 v2 的"运行期自适应块长 / 每次返回 ≤k 步"不成立——只能**固定 T_a + 在块边界做恢复决策**。

**一句话**：深度不是"现成输入"，而是**必须从已校正双目自己重建**；而这是经典几何，不是第二个学习模型——恰好绕开单模型合规。

## 1. 直觉：深度不是"多一路输入"，而是"进度的量尺"

RGB 回答"看起来像什么"，深度回答"差多少"。操纵任务的计分步，绝大多数本质上是**米制量**：物体离桌面的高度、插头进入插口的深度、毛巾折叠后的覆盖面积、拉链两边的间隙、碗叠了几层、目标与物体的横向距离。语义模型要从像素里猜这些量，深度可以直接测。

异常检测则把"干扰"从一个**枚举问题**变成**偏离问题**。规则里写的是"合上再打开""拉上再拉开""叠好后翻开""中途把锁拿走"——它们不是 32 种互不相关的招式，而是同一件事的四种表现：

- **撤回**：进度信号出现正常轨迹里不该有的负导数；
- **位移**：场景点云相对"该进度下应有的几何"整体错位；
- **移除**：某块点云体积直接消失；
- **卡住**：命令在动、观测不动，或末端跟踪误差持续偏大。

于是我们不需要为每个任务写谓词，只需要（i）一个**任务条件化的进度坐标**，和（ii）一个在 32k 条**正常**演示上拟合的"正常流形"，然后监控偏离。关键是：**公开数据全是正常演示，这恰好是异常检测最标准的训练条件（one-class / predictive coding），而不像监督式干扰识别那样缺标签。**

## 2. 严谨定义（先给骨架，完整式见产物区 §1）

**观测与深度。** 第 t 个决策时刻的观测
`o_t = (I_t^{L,high}, I_t^{R,high}, I_t^{L,wrist}, I_t^{R,wrist}, q_t, s_t^{ee}, g_t, l)`。
对已校正双目做半全局匹配得到视差 `d_t(u,v)`，则 `Z_t = fB / d_t`，反投影得点云 `P_t`。`f, B` 由离线自标定给出（UIP-17）。

**进度坐标。** 共享骨干 `z_t = E_θ(o_t; D_t)`，任务语言为 `l`。进度头
`p_t = h_ψ(z_t, G(P_t, ROI(l)), l) ∈ [0,1]`，
只在**成功**演示上训练，监督信号是"时间先后"而不是分数标注：同一条成功轨迹上 `t<t' ⇒ p_t ≤ p_{t'}`（成对排序损失）+ 时间反演对比（UIP-18）。**不需要每条演示的计分点标签。**

**异常分量。** `a_t = (a_rev, a_stall, a_dyn, a_scene, a_contact)`：

- `a_rev = [ -ḟ p_t ]_+`，但阈值按**任务在该进度桶内的合法导数分布**取（因为"拧开/合上/翻开"本身可能是合法逆向）；
- `a_stall = 1[|Δp|≈0] · 1[‖a_t‖>δ]`；
- `a_dyn = ‖z_{t+1} − F_φ(z_t, a_t)‖²`（隐空间前向模型残差）；
- `a_scene = TrimmedChamfer(P_t, \bar P_{bucket(p_t)})`（与"该进度下典型点云模板"的配准残差）；
- `a_contact = ‖s^{ee}_{t+1} − (s^{ee}_t + Δs^{cmd})‖`。

**判据（保形）。** 非一致性分数 `S_t = Σ w_i a_i`。在**正常**校准集上取分位数 `\hat q_{1-α}`，`S_t > \hat q_{1-α}` 才报警。若正常窗口可交换，则正常流量上的误报率 ≤ α。这是给"重做"装的**统计保险丝**。

**响应不是一刀切。** 按主导分量 + 物体是否仍在场，分派到 `redo / relocalize / wait-resume / retry`；**不可逆移除**（如 T12 锁被拿走）不重做，而是保守止损、保留已得步骤分。这是对 v2"检测到撤回就重做"的关键修正。

## 3. 三条可检验命题

- **P1（可测性）**：多数计分步存在一个深度可测的充分统计量（高度/插入深度/覆盖/间隙/层数/距离），且它对颜色与光照不敏感。（产物 §3 逐任务族列表）
- **P2（流形性）**：在同一任务语言下，成功演示的 `(p_t, P_t)` 落在低维流形附近；四类干扰分别对应"导数异常 / 配准残差 / 体积缺失 / 跟踪残差"。（可用正常 vs 合成干扰的 AUROC 检验）
- **P3（误报可控）**：保形阈值使正常 episode 的误报率 ≤ α；因此恢复机制不会在正常任务上自伤。（E203 直接检验）

## 4. 对 v2 的修剪、升级、修正

- **升级/合并**：UIP-01′（滚动验证）与 UIP-09′（撤回检测）→ **UIP-16 D-MPA**（学习式、深度落地、保形门控）；UIP-15 CSG → 并入 UIP-16 的阈值与预算。
- **新增**：UIP-17 SCR（双目自标定，前置件）、UIP-18 TR-CL（时间反演对比，人扰数据的廉价来源）、UIP-19 AGR（块边界异常门控恢复）、UIP-20 DPR（深度点云配准/未见物体几何抓取）、UIP-21 DSA（深度 sim-real 对齐）。
- **修正**：UIP-13 ACS 的"运行期变块长"作废 → 改为"离线选固定 `T_a` + 块边界恢复"（UIP-19）。检测延迟下界就是 `T_a` 步，这是硬约束，必须写进实验。
- **降级**：UIP-11 GSO 从"32 任务全场景"降为"3–5 任务探针 + 深度对齐"，因为全场景成本高且 v2 已承认 sim-real gap；UIP-14 MSGR 保留，但只作为**子目标图**给 D-MPA 提供"该重做哪一步"。
- **封存**：外部 VLM 验证器（合规风险）、学习式世界模型 MPC（被隐空间前向模型 `F_φ` 以极小代价替代）。

## 5. 瓶颈假设（更新）

- **H1′**：真正决定得分的是"干扰可逆性"而非"干扰有无"；不可逆移除时，**最优策略是止损**而不是重做。
- **H2′**：深度误差的主要来源是**尺度（fB）自标定偏差**，不是匹配噪声；标定误差会等比放大所有进度量。
- **H3′**：任务本身存在合法逆向（T14 拧开、T17 合上、T19 拉上）；把"负斜率"一律当干扰 = 自毁，必须任务条件化。
- **H4′**：**时间反演**是比 Gazebo 建场景便宜一个数量级的人扰数据来源，但只能用于**表征/验证器**训练，不能用于动作克隆（反演后的接触/夹爪动力学不物理）。

## 6. 本轮最大风险

**→ 本轮最值得押注：UIP-16 D-MPA × UIP-17 SCR × UIP-18 TR-CL 组成的"深度进度异常守护"，用 UIP-19 在块边界执行恢复。** 它把 v2 里最贵、最脆的裁判层（手写谓词/VLM/全场景仿真）替换成可离线校准、误报可控、且完全在接口内的几何+自监督方案。

**一句话最大风险：整套方案把"双目可重建出足够精度的米制深度、且进度在任务条件化后近似单调"当作前提；但接口只传 JPEG 压缩的双目 RGB、不传标定与真值深度，且部分任务合法地需要"反向"操作——一旦自标定偏差或合法逆向被误判，异常检测就会从护栏变成自伤开关。**

## 1. 旗舰：UIP-16 · D-MPA（Depth-grounded Monotone Progress Anomaly）

### 1.1 直觉

正常演示里，"任务进度"是一个**有方向、近似单调**的量；人为干扰不是新任务，而是把这个量**往回推**、把场景几何**挪走**、或把物体**拿走**。所以与其为 32 个任务写 32 套判据，不如学一个任务条件化的进度坐标 `p_t`，再监控它的导数、场景配准残差与动力学残差。

### 1.2 形式定义

- 观测：`o_t = (I_t^{L,h}, I_t^{R,h}, I_t^{L,w}, I_t^{R,w}, q_t, s_t^{ee}, g_t, l)`。
- 深度：对已校正头部双目做 SGBM，得视差 `d_t`、深度 `Z_t = fB/d_t`、点云 `P_t = π^{-1}(u,v,Z_t; f,c)`。
- 共享骨干：`z_t = E_θ(o_t, D_t)`；几何描述子 `x_t = G(P_t, ROI(l))`（ROI 由语言与首帧确定）。
- 进度头：`p_t = σ(h_ψ(z_t, x_t, l)) ∈ [0,1]`。
- 隐空间前向模型：`ẑ_{t+1} = F_φ(z_t, a_t)`，其中 `a_t` 是我们上一块发出的动作序列的聚合（均值/首末/统计量）。

### 1.3 训练：只用成功演示，不用干扰标签

设成功演示集 `D⁺`。对同一 episode 内 `t < t'` 采样成对样本：

- **排序损失**（方向性）：
  `L_rank = E_{(t,t')∈D⁺, t<t'} max(0, m − (p_{t'} − p_t))`；
- **方差正则**（防塌缩到常数）：
  `L_var = E[ (std_t(p_t) − 1)² ]`，或对每个 episode 做 `p ← (p − min)/(max − min)` 后再算；
- **时间反演对比**（UIP-18）：
  `L_TCL = −log [ exp(s(z_t,z_{t+Δ})) / Σ_{neg} exp(s(z_t,z_{neg})) ]`，负样本取**反序窗口**与**跨任务窗口**；
- **可选弱锚**：v2 的 32 任务计分表给出步数与分值，可在**步级变化点**检测后把 `p` 对齐到累计分位（没有逐帧标注也能用步序约束）。

总损失 `L = L_rank + λ₁L_var + λ₂L_TCL (+ λ₃L_anchor)`。注意：`L_rank` 只约束"先后"，**不需要知道每条演示在第几帧完成了第几步**，这正是公开数据可直接用的原因。

### 1.4 五个异常分量

| 分量 | 定义 | 直觉 | 能抓的干扰 |
|---|---|---|---|
| `a_rev` | `[-ḟ p_t]_+`，阈值按任务×进度桶的正常导数分位取 | 进度倒退 | 合上再打开、拉上再拉开、叠好翻开、拧回 |
| `a_stall` | `1[|Δp|<ε]·1[‖a_t‖>δ]` | 命令在动、进度不动 | 被人按住、卡住、底座被挪 |
| `a_dyn` | `‖z_{t+1} − F_φ(z_t,a_t)‖²` | 下一步"不该长这样" | 任何未建模的人手介入 |
| `a_scene` | `TrimmedChamfer(P_t, \bar P_{bucket(p_t)})` | 场景几何与"该进度应有的样子"错位 | 物体被挪走、位置泛化、物体被拿走 |
| `a_contact` | `‖s^{ee}_{t+1} − (s^{ee}_t + Δs^{cmd})‖` | 命令与到达不一致 | 插入卡死、抓取打滑、碰撞 |

**任务条件化导数阈值**：对每个任务 `l`、每个进度桶 `b`，在正常演示上统计 `Δp` 的经验分布 `\hat F_{l,b}`，报警条件为
`Δp_t < \hat F_{l,b}^{-1}(α/2)`。
这样 T14 的"拧开"、T17 的"合上"等**合法逆向**只要在正常分布里，就不会被当成干扰；真正的"反向撤回"落在分布尾部。这是 H3′ 的直接落实。

### 1.5 保形门控（给"重做"上保险）

非一致性分数 `S_t = Σ_i w_i·ã_i`（`ã_i` 为各分量的标准化值，权重可在校准集上用**最大化正常/合成干扰分离度**学习）。在正常校准集（按 episode 划分，绝不按帧划分，避免泄漏）上计算
`\hat q = Quantile({S_t}, 1−α)`（有限样本用 `⌈(n+1)(1−α)⌉/n` 分位）。
仅当 `S_t > \hat q` 且满足 `m-of-n` 去抖（例如 3 个块中至少 2 个超阈值）才报警。

**保证的边界（必须写清）**：若正常窗口可交换，正常流量上误报率 ≤ α；干扰使可交换性失效，因此**检测率只能经验评估，不能由保形给出保证**。这不是缺陷，而是我们只对"别自伤"要硬保证。α 建议 0.5%–1%，用块自助法给置信区间。

### 1.6 响应表：可逆 vs 不可逆

| 主导分量 | 几何证据 | 干扰类型 | 例 | 响应 |
|---|---|---|---|---|
| `a_rev` | 物体仍在场、状态可逆 | 撤回 | T16/T17/T19/T27 | `redo` 当前子目标（有次数上限） |
| `a_scene` | 残差集中在某簇、簇仍在 | 位移 | T08/T25/T26 | `reloc`：DPR 重定位目标，重规划下一块 |
| `a_scene` | 该簇体积骤降/消失 | 移除 | T12 锁被拿走 | `wait`：**不重做**，止损、保留已得分，监控是否放回 |
| `a_stall`/`a_contact` | 命令与到达背离 | 卡住/打滑 | T10/T26 插入 | `retry`：换抓取/微退再插/换手 |
| `a_dyn` 为主、几何正常 | 未建模接触但物体可抓 | 人手短暂介入 | 任意 | `verify`：下一块保守推进，加密观察 |
| 无异常 | — | — | — | `task`：正常技能图推进 |

“不可逆移除不重做”是本轮相对 v2 最重要的策略修正：**重做拿不回被拿走的物体，只会浪费时间并把动作统计弄乱、伤可信度。**

## 2. UIP-17 · SCR（Stereo self-Calibration via proprioception）

### 2.1 为什么必须自标定

接口**没有**内参/基线字段，HF 仓库也**没有**标定文件；但深度 `Z=fB/d` 同时需要 `f`（像素→角度）和 `fB`（视差→深度）。缺标定，深度只有相对结构、没有米制尺度，而"进度量"恰恰要米制。

### 2.2 用已知末端轨迹当标定靶

数据集提供 `left/right_ee_pose_gripper_base`（末端在基座系的位姿）与关节角，可算出末端点 `x_i ∈ R³` 的**已知米制轨迹**。设左头相机位姿 `(R,t)`、焦距 `f`、主点 `(c_x,c_y)`、基线 `B`。对末端可见的帧，观测到左图像素 `(u_i,v_i)` 与视差 `d_i`，最小化鲁棒重投影+视差残差：

```
min_{R,t,f,B,c}  Σ_i ρ( (u_i − π_x(f,R x_i+t,c))²
                      + (v_i − π_y(f,R x_i+t,c))²
                      + λ (d_i − fB/(R x_i+t)_z)² )
```

其中 `π_x = f X/Z + c_x`，`π_y = f Y/Z + c_y`，`ρ` 为 Huber。未知量 9 个（`R,t` 6 + `f,B,c_x,c_y` 4，可固定主点为图像中心降到 7）。用 Levenberg–Marquardt 求解；多 episode 联合标定。

**可观测性**：需要末端轨迹**有深度变化**（区分 `f` 与 `B`）且**离轴**（定主点）；操纵任务天然有丰富的 6-DoF 运动。若某任务轨迹近似平面，改用跨任务联合标定。

**末端像素对应**：三条路径，按可靠性排序：
1. 用 `state_d435` 位姿作先验（若头双目与 D435 刚性共装），先固定 `(R,t)` 只解 `f,B,c`；
2. 在头部双目里用腕相机/FK 提示的时空窗口 + 模板/分割检测夹爪；
3. 兜底：向主办方索取内参，或用已知尺寸的标准物（数据集里反复出现的碗/杯/纸盒）做尺度锚。

### 2.3 质量指标（不通过就降级）

- 重投影 RMSE（px，目标 < 2）；
- 视差残差（px，目标 < 1）；
- 已知末端位移的**尺度误差**（%，目标 < 3%）；
- 桌面平面拟合残差 std（mm，目标 < 5）；
- 左右一致性通过率（%）。

### 2.4 双腕广基线（可选增强）

`wrist_left` 与 `wrist_right` 不是同一刚体的双目，但当两只手腕**同时看到同一物体**时，可用 FK 给出两相机相对位姿，做**广基线三角化**。头双目基线短（远距离深度误差大），双腕在近距接触步（插入/折叠）可补精度。代价：需要腕相机相对末端的离线手眼标定，且要求视场重叠；只作为机会性增强，不作为主路径。

### 2.5 降级路径

若自标定置信度低（纹理少、反光、视差有效率低）：切换到 **RGB-only 进度头** + 几何先验（物体尺寸表、桌面平面），并把 `a_scene` 降权；同时在策略内标记 `depth_conf=low`，禁止用未校准深度触发"重做"（只允许触发"加密观察/保守推进"）。**绝不能让坏深度直接驱动重做。**

## 3. 深度进度可观测量表（逐任务族）

> 原则：深度负责**几何量**，RGB 负责**颜色/语义**；两者融合，而不是用深度替代颜色。`ROI(l)` 由语言 + 首帧确定，所有量都在 ROI 内计算。

| 任务族 | 代表任务 | 典型计分步 | 深度可观测量 | 进度/异常判据 |
|---|---|---|---|---|
| 堆叠/叠放 | T27 碗、T20 纸杯 | 放第 1/2/3 个 | 垂直层数、顶层高度、质心横向对齐、支撑接触 | 层数↑=进度；层数↓=撤回；横向跳变=位移 |
| 插入/插接 | T26 网线、T10 插头、T29 手机 | 对准/接触/插到底 | 沿插入轴深度、轴夹角、接触面积、间隙 | 插入深度单调↑；深度回退=拔出/撤回 |
| 拉链/开合 | T19 拉链、T31 文具袋 | 拉开/拉上/闭合 | 两边点云间隙长度、拉头位置、闭合率 | 间隙↓=拉上；间隙↑=被拉开 |
| 折叠 | T16 毛巾 | 折第 1/2/… 折 | 织物掩膜覆盖面积、折线高度、残余平整度 | 覆盖率↑=折好；覆盖率↓=被翻开 |
| 开锁/拧盖 | T12 锁、T14 药瓶 | 抓锁/转动/取下 | 盖子体积在场/消失、顶面高度下降、末端旋转角 | 顶面高度↓+物体仍在=拧开；物体消失=被拿走 |
| 分拣/传送 | T24、T04、T06 | 抓取/放入正确位 | 物体-料箱归属、各箱计数、料箱占用体积 | 计数↑=进度；物体回起点=撤回 |
| 倒出/转移 | T14、T32 针管 | 对准/倾倒/归位 | 容器倾角（末端）、接收容器占用/液面高度、物体计数 | 接收侧占用↑=进度；倾角回正但占用不变=空倒 |
| 放置/悬挂 | T01 挂杯、T07 相框、T23 球拍 | 抓取/对准/放入 | 目标相对位姿、支撑/悬挂接触、间隙 | 目标残差↓=进度；残差突增=被挪动 |

**读表结论**：至少 8 个任务族存在"一个深度标量就能覆盖多数计分步"的强可观测量；这支持 P1，也说明 D-MPA 不必为每个任务单独建模型。

## 4. UIP-18 · TR-CL（Time-Reversal Contrastive Learning）

### 4.1 机制

V2 已确认 `human_*` 大量是"把已完成进度撤回"。于是**时间反演**就是最贴近干扰分布的免费负样本：

- 正样本：同一 episode 中 `(窗口 t, 窗口 t+Δ)`（前向）；
- 负样本：把窗口的时间顺序**反转**、或跨任务/跨 episode 打乱；
- 目标：学一个"前向性"打分/能量，使正样本得分高、反序得分低。用 InfoNCE 或 margin ranking。
- 进度头 `h_ψ` 与之共享骨干，于是 `p_t` 天然对"方向"敏感。

### 4.2 合成干扰 episode（仅表征层）

取一条成功演示，在进度点 `t₀` 处拼接"反序后缀"（模拟撤回），再回到前向（模拟恢复），得到 `(前向 → 撤回 → 恢复)` 的特征序列。用途：
1. 校准 `a_rev` 阈值与 `m-of-n` 去抖参数；
2. 训练响应分类器（撤回/位移/移除/卡住）；
3. 做 E204 的可控检测实验。

**红线**：反序后的动作**不物理**（夹爪开合、接触、摩擦都不对），因此**绝不用于动作克隆或策略行为训练**；只用于表征/验证器/阈值校准。

### 4.3 为什么划算

Gazebo 建 32 个场景 + 脚本化人手的成本是"周"级；时间反演是"分钟"级，且直接复用 32k 条正常演示。它把"人扰数据空白"从**采数据问题**转成**表征学习问题**——这是本轮最便宜的高杠杆动作。

## 5. UIP-19 · AGR（Anomaly-Gated Recovery，块边界）

### 5.1 先修正接口事实

`action_chunk_size` 握手时一次声明；`example_env.py:164` 要求每个动作数组形状严格等于 `(T_a, …)`。所以：

- **不能**在运行时返回更短的块；
- **不能**在块执行中途请求重观测；
- 只能在**块边界**（每次 `get_action` 被调用时）根据最新观测做下一次决策。

因此 v2 的 UIP-13"自适应块长/投机预计算"中"可变块长"部分作废；保留其"按任务阶段离线选 `T_a`"的思想。

### 5.2 固定 T_a 的选择（离线）

候选 `T_a ∈ {1,2,4,8,16}`。对每个任务族在小规模真机/GSO 上扫：

- **检测延迟下界 = `T_a` 步**；撤回造成的步骤分损失约 `v_step × (T_a/fps + t_react)`；
- 小 `T_a`：反应快、但往返次数多、延迟/带宽高、易触发可信度抖动；
- 大 `T_a`：省带宽，但撤回可能持续一整个块，步骤分损失大。

经验规则：**接触密集/高价值末步用小 `T_a`；远距离搬运/低风险步用大 `T_a`**。由于 metadata 全局一次，最终取一个保守折中；若评测允许 N 端口各自独立 metadata，则**按任务族给不同端口不同 `T_a`**（注意：这在"单模型"口径下可能被视为多模型集合，需谨慎，见 §10）。

### 5.3 块边界状态机

```
TASK ──(S>q̂, a_rev)──────▶ REDO ──(完成或超次数)──▶ VERIFY ──(S≤q̂)──▶ TASK
  │                              └──(超 redo_max)──▶ VERIFY
  ├──(S>q̂, a_scene+位移)──▶ RELOC ──(重定位成功)──▶ TASK
  ├──(S>q̂, a_scene+体积消失)▶ WAIT ──(物体回来)──▶ TASK
  │                              └──(超时)──────▶ WAIT（保持止损）
  ├──(S>q̂, a_stall/a_contact)▶ RETRY ──(成功)──▶ TASK
  └──(S>q̂, a_dyn 为主)─────▶ VERIFY（保守推进，加密观察）
```

所有恢复动作都受 **最大次数 + 延迟预算 + 动作平滑**约束（继承 UIP-15），防止"反复重做"把延迟和可信度一起拖垮。

## 6. UIP-20 · DPR（Depth Point-cloud Registration & geometric grasping）

### 6.1 场景配准

1. 桌面平面：RANSAC 拟合，得到法向/高度，剔除非任务支撑面；
2. 物体聚类：欧氏聚类 + 深度不连续分割；
3. 模板配准：从成功演示按进度桶构建典型点云 `\bar P_b`，用 FPFH + RANSAC 粗配 + ICP 精配；
4. 残差：`a_scene` = trimmed Chamfer；若残差**集中在某簇**→该物体被挪动（`reloc`）；若该簇**消失/体积骤降**→被拿走（`wait`）。

### 6.2 未见物体的几何抓取

对 `unseen_object_*` 不依赖类别模型：

- 从点云估计有向包围盒/主轴与尺度；
- 在局部几何上采样**对跖抓取**（两指沿法向对夹），约束 Dex1 开度 `[0, 5.5]`、接近方向无遮挡、抬升时重心在指间；
- 用"抓取稳定性评分"（接触面积、力闭合近似、质心投影）排序；
- 颜色类语义（如"红杯"）由 RGB 分支提供，几何抓取由深度提供，二者在语言条件化下融合。

这直接把"未见物品"从**识别问题**转成**几何问题**，与单模型合规天然一致（无额外类别模型）。

---

## 7. UIP-21 · DSA（Depth-based Sim-real Alignment）

v2 的最大风险是"用仿真过拟合仿真"。深度给了一个可量化的解：

1. 用真深拟合桌面平面、物体位姿/尺寸、头相机外参；
2. 用这些量实例化 Gazebo 场景（G1 固定底座 + Dex1 + 同名相机位）；
3. 在匹配进度点比较真/仿点云：Chamfer、MMD、占用 IoU、平面残差；
4. 得到**深度域间隙分** `gap(task)`；**只有 `gap < τ` 的任务才信任 GSO 分数**，否则降权或标为"仅结构参考"。

这把 v2 的"GSO 只当结构裁判"从口号变成**可计算的准入条件**。

## 8. 端到端伪代码

```python
import numpy as np

class DMPAPolicy:
    def __init__(self, trunk, progress, fwd, anomaly, skills, calib, token,
                 T_A=8, alpha=0.01, W=6, redo_max=2):
        self.trunk, self.progress, self.fwd = trunk, progress, fwd
        self.anom, self.skills, self.calib = anomaly, skills, calib
        self.token = token
        self.T_A, self.alpha, self.W, self.redo_max = T_A, alpha, W, redo_max
        # 每个任务族的保形阈值，离线校准后随模型一起打包
        self.qhat = calib.conformal_thresholds(alpha)

    @property
    def metadata(self):
        return {
            "control_space": "joint",
            # 关键：必须同时声明左右 high 才能重建双目深度；wrist 仅作语义/近距
            "obs_delta_indices": {
                "observation.language": [0],
                "observation.images.cam_left_high":   [0],
                "observation.images.cam_right_high":  [0],
                "observation.images.cam_left_wrist":  [0],
                "observation.images.cam_right_wrist": [0],
                "observation.state.left_arm":  [0],
                "observation.state.right_arm": [0],
                "observation.state.left_ee_pose_gripper_base":  [0],
                "observation.state.right_ee_pose_gripper_base": [0],
                "observation.state.left_gripper":  [0],
                "observation.state.right_gripper": [0],
            },
            # 深度精度优先：high 保持原分辨率；wrist 降分辨率省带宽
            "image_resize": {
                "observation.images.cam_left_high":   [480, 640],
                "observation.images.cam_right_high":  [480, 640],
                "observation.images.cam_left_wrist":  [240, 320],
                "observation.images.cam_right_wrist": [240, 320],
            },
            "action_chunk_size": self.T_A,   # 固定，不可运行期改
            "token": self.token,
        }

    def reset(self):
        self.hist = []          # 内部历史，不用 obs_delta_indices 堆叠（省带宽）
        self.mode = "task"
        self.g = 0              # 当前子目标/计分步索引（由 MSGR 技能图给出）
        self.redo = 0
        self.last_a = None
        self.wait_ticks = 0

    def get_action(self, obs):
        # 1) 双目深度（经典几何，不是第二个学习模型）
        D = self.calib.stereo_depth(
            obs["observation.images.cam_left_high"],
            obs["observation.images.cam_right_high"],
        )
        P = self.calib.cloud(D)
        # 2) 共享骨干 + 进度
        z = self.trunk(obs, D)
        p = self.progress(z, P, obs["observation.language"])
        # 3) 异常分量（用内部历史，不用时间堆叠）
        comp = self.anom(z, P, obs, self.hist, self.last_a,
                         task=obs["observation.language"])
        S = self.anom.combine(comp)

        # 4) 只在块边界决策（无块内反馈）
        if len(self.hist) >= self.W and self.calib.depth_conf(D) > 0.5:
            self.mode, self.g = self._decide(S, comp, P, self.mode, self.g)

        self.hist.append((z, p, self.calib.downsample(P)))
        self.hist = self.hist[-self.W:]

        # 5) 技能/恢复头输出，形状严格 (T_A, ...)
        act = self.skills[self.mode](obs, D, self.g, self.T_A)
        self.last_a = act
        out = {"meta.token": self.token}
        out.update(act)
        return out

    def _decide(self, S, comp, P, mode, g):
        q = self.qhat[self._task_bucket()]          # 任务族阈值
        if S <= q:
            self.redo = 0
            return ("task" if mode in ("task", "verify") else "verify", g)

        if comp.scene_volume_drop > self.tau_drop:  # 移除：不可逆
            self.redo = 0
            return ("wait", g)                       # 止损，不重做
        if comp.scene_translation > self.tau_move:  # 位移：可重定位
            return ("reloc", g)
        if comp.reversal > self.tau_rev:            # 撤回：可重做
            if self.redo < self.redo_max:
                self.redo += 1
                return ("redo", g)
            return ("verify", g)
        if comp.stall > self.tau_stall or comp.contact > self.tau_contact:
            return ("retry", g)
        return ("verify", g)                         # 未建模介入：保守推进
```

**关键工程点**：历史在策略内部维护（`self.hist`），**不要**用 `obs_delta_indices` 堆叠来取历史——每多叠一帧就是多一张 JPEG，直接抬延迟与带宽；而块边界之间本来就有 `T_a` 步的间隔，内部缓存足够做导数/残差。

| 实验 | 问题 | 对照 | 指标 | 判据 |
|---|---|---|---|---|

| E208 | 类型化响应是否优于一律重做 | 一律 redo vs 可逆/不可逆分流 | 移除场景的步骤分与延迟 | 分流显著↑（H1′） |

| E210 | DSA 是否让 GSO 更可信 | 无对齐 vs 深度对齐 | GSO-真机 Spearman ρ、gap 分 | ρ 显著↑ |

> 所有真机结论提测前标注为**代理结论**（GSO/离线），不得当真机结论；反之，所有仿真结论必须附 `gap(task)` 与深度置信度。

## 10. 合规、接口、实时

- **深度来源合规**：经典 SGBM/三角化不是"第二个学习模型"；进度头、前向模型、异常头**共享同一条骨干**，是单模型多任务。**不要**引入外部 VLM 或独立类别模型。
- **接口红线**：`obs_delta_indices` 必须同时声明左右 high 才能有双目；动作数组形状严格 `(T_a,…)`、dtype `float32`；`meta.token` 每步携带；`reset()` 清理每端口状态。
- **带宽**：4 张 JPEG/块边界。high 保持 480×640 以保深度精度，wrist 降到 240×320；若带宽吃紧，先降 wrist、再考虑 high 降到 360×480（注意视差减半会让深度相对误差约翻倍）。
- **实时**：SGBM 480×640 约 5–20 ms/对（CPU，需实测）；只在块边界算一次，不逐帧算。恢复动作加平滑，避免动作统计异常伤可信度。
- **深度置信度门控**：视差有效率、纹理度、左右一致性低于阈值 → `depth_conf=low` → 禁用基于深度的"重做"触发，退回 RGB 进度头 + 保守推进。
- **多端口**：每端口独立 `reset`/历史/阈值；若用不同端口跑不同 `T_a`/任务族，需评估是否被判定为"多模型集合"——**保守起见，默认所有端口共享同一权重，仅允许阈值/任务配置不同**。
- **阈值打包**：保形阈值按任务族（或端口）离线校准后写入模型产物；在线不重新估计，避免分布漂移导致阈值失控。

## 12. 风险与押注

**→ 押注：UIP-16 D-MPA（进度异常）× UIP-17 SCR（深度尺度）× UIP-18 TR-CL（反序监督），由 UIP-19 在块边界执行类型化恢复；UIP-20/21 负责未见物体与仿真可信度。** 它把 v2 最脆的裁判层替换成"可离线校准、只依赖正常数据、且完全在接口内"的几何+自监督方案，直接对准规则写明而公开数据空白的人为撤回轴。

**一句话最大风险：接口不提供真值深度与标定，尺度自标定误差会沿所有"进度量"等比放大；而"合法逆向"与"人为撤回"在进度导数上可能同形——若不用任务条件化阈值与深度置信度做双重门控，D-MPA 会把正常操作误判为干扰并反复重做，结果同时损失步骤分与可信度。**
