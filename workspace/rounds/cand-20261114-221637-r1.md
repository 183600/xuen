# 第 3 轮（灵感循环第 3 轮；本轮灵感：「课程学习」×「排行榜」）

> **基线继承**：第 2 轮 **ToolGauge**（IP-315–320；定义 416–431；引理 46–50；实验 E426–E440），
> 其下依次是 LeanGauge（第 1 轮）与 MODGAUGE 主控。
> 本轮纪律：**只改「顺序」与「选择」，不改「安全闸门」**——课程学习升级修复调度序，
> 排行榜升级校准器的选择与监控；λ 风险门、β 增益注、V 交叉验证、契约回归、热替换/回滚全部原样继承，
> MODGAUGE 五不变式保持（另加两条只收紧、不放宽的元不变式）。

## 二元灵感 + 第三维（耦合）

| 灵感词 | 第 2 轮对象 | 升级为 | 一句话动机 |
|---|---|---|---|
| 课程学习 | IP-320 主闭环按 `detect_blind_spot()` 的**到达序**异步修复 | **C-Box + C-Sched**：锚定难度分 → 分层 → 自步晋升 → 无遗忘晋升 | 修复顺序不是中立的：先易后难能在**最便宜**的盲区上暴露有偏先验，而不是让它在最贵的盲区上爆 |
| 排行榜 | IP-318/428 的单一标量断路器 P-Quarantine（K=q=3 符号序列） | **LB-Select + RankAudit**：冻结候选池 + 封存评测 + 冠军-挑战者 + 排名稳定性 | n=3 的符号检验几乎没有统计功效；把"选哪个校准器"升级为**可审计的模型选择**问题 |
| （耦合） | 两者各自为政 | **课程×排行榜单向耦合**（定义 442） | 排行榜→课程只影响顺序，课程→排行榜只影响层均衡采样；信息流单向，防止互相洗白 |

**核心命题**：把 ToolGauge 的「**到达序修复 + 单一标量断路**」升级为
「**锚定难度分驱动的课程化修复 + 预注册封存的排行榜式校准器选择**」。
课程回答"先在哪里检验先验"，排行榜回答"用哪套证据来裁判"；
两者都是**上游过滤器**，不触碰任何数值安全闸门——因此这是严格意义上的"只加审计、不加权限"。

**不变式保持声明**
- MODGAUGE 五不变式全部保留；
- **新增元不变式 O（排序不变式）**：课程只改变执行顺序，`A₃ ⊆ A₂`（本轮可执行修复集合是 ToolGauge 的子集）；
- **新增元不变式 S（选择不变式）**：排行榜只能在预注册、且通过全部闸门的候选间选择，**不得放宽** λ/β/V/契约回归/回滚；
- **严格退化链延长**：LadderGauge 失效（课程停滞 / 排行榜置信不足 / 排名结构漂移 / 预算耗尽）
  ⇒ ToolGauge 到达序 + P-Quarantine ⇒ LeanGauge 纯数值探测 ⇒ MODGAUGE。

## 0. 直觉与动机

**灵感 1（课程学习 → 修复的「顺序即证据」）**
直觉：ToolGauge 每发现一个盲区就立刻异步修复，谁先被 D-Box 扫到谁先修。但不同盲区的
**修复成本、物理风险、可观测性**差异巨大（一个光照可扫描的格子 vs 一个必须敲击/变光的格子）。
更重要的是：如果 AP-Cal 的先验被预训练分布偏移污染，它会在**所有**盲区上同时偏；
按到达序修复等于"随机选一个盲区来当第一块试金石"，可能恰好选中最贵、最危险的那块。
课程学习的工程智慧是：**把便宜、可观测、低风险的样本排在前面**，用它们建立/否证先验，
再逐级晋升到困难样本。这里的深层论证是：第 2 轮的最大风险恰是**跨盲区强相关偏差**——
正因为偏差是相关的，易盲区的失败才是难盲区失败的**早期可观测代理**。
课程学习正是把"相关性"从风险转化为**早期预警资产**。
但反过来也必须承认：若偏差是**异质稀疏**的（只在个别难层出现），课程无法在易层提前暴露，
且"易层全过"会制造晋升假信心——这条限制被写成引理 51 的显式前提与 E442 的证伪目标。

**灵感 2（排行榜 → 校准器选择从「标量断路」到「可审计模型选择」）**
直觉：P-Quarantine 用最近 K=q=3 次（预测收缩, 实际收缩）残差的**符号**做断路。
这是一个 n=3 的单侧符号检验：零假设下同号概率 1/8，几乎不可能区分噪声与系统性偏差，
且完全丢弃了幅度信息、忽略了多重比较。
排行榜的工程智慧是：维护一个**预注册候选池**（AP-Cal / 夹紧 AP-Cal / BP-Cal / 分片 AP-Cal / 保守 stub），
在同一**封存评测集**上算多指标向量（覆盖率、ECE、|z| 通过率、修复增益、P99 尾部风险、违约数），
用**配对 bootstrap + 冠军-挑战者 δ 余量**决定是否切换，同分保留现任。
这既补上了统计功效，也把"为什么选这个校准器"变成可复算、可审计的决策。

**灵感 3（耦合 → 为什么两者不能各自为政，且为什么都自带毒）**
直觉：课程需要难度分，排行榜需要评测切片，二者天然想互相喂数据——这正是危险所在。
(1) 若难度分由**被测先验**计算（VLA score / AP-Cal 后验），就是"被测者给自己出题"，
先验一旦误判某类为"简单"，课程会把它排到最前面，把污染源变成第一块试金石——
因此定义 432 强制**锚定正交原则**：难度分只能由与被测先验正交的计量量测量。
(2) 排行榜是 Goodhart 温床：优化覆盖率会让假设集无限变宽，优化增益会推高尾部风险，
自报指标会被投毒——因此定义 437–440 强制**冻结候选池哈希、封存评测集、签名回执计分、安全字典序**。
(3) 课程与排行榜的单向耦合（定义 442）保证：榜单只影响修复顺序，课程只影响评测采样均衡，
**都不写回数值契约**——否则就会出现"为了榜单好看而放宽闸门"的洗白通道。

## 1. 形式化定义（增量：定义 432–446）

**定义 432（锚定难度分 D⊥ 与正交原则）**
盲区 s 的难度分
`D⊥(s) = w_c·(1−cov(s)) + w_a·A_obs(s) + w_r·R_env(s) + w_n·(n_min(s)/n̄) ∈ [0,1]`，
其中 `cov(s)` 来自 D-Box 位图（定义 398/399，继承）；`A_obs(s)` 是已收到 cross.modal 回执的
**跨通道残差离散度**（直接由计量读数计算）；`R_env(s)` 由 Pre 包络裕度（定义 416）给出；
`n_min(s)` 为解析样本下界（定义 426）。
**正交原则（硬约束）**：D⊥ 的每个输入必须由**与被评估先验正交**的计量通道测得；
**禁止**把 VLA 打分、AP-Cal 摊销后验、排行榜分数作为 D⊥ 的任何输入。
（理由：难度分若由被测者生成，课程顺序可被污染源反向操纵；E452 检验正交性。）

**定义 433（课程分层与前置偏序）**
按 D⊥ 的分位数把候选盲区划入 K 层 `L₀ ⪯ L₁ ⪯ … ⪯ L_{K−1}`（默认 K=4，分层边界部署前冻结）。
前置关系：`s ∈ L_k` 仅当 `L_{k−1}` 的晋升门槛（定义 434）通过后才可进入修复。
层内按 `(D⊥(s), seq_min(s))` 确定性升序，保证可复现、无饥饿的 tie-break。

**定义 434（自步晋升门槛 CompetenceGate）**
对第 k 层维护滑动窗统计：修复成功率 `ŝ_k`、V 交叉验证通过率 `ĉ_k`、实测/预测收缩比 `r̂_k`。
晋升 `L_k → L_{k+1}` 当且仅当
`ŝ_k ≥ 1−ε_s ∧ ĉ_k ≥ 1−ε_c ∧ r̂_k ∈ [1−δ_r, 1+δ_r] ∧ n_k ≥ n_gate`（默认 ε_s=ε_c=0.1, δ_r=0.2）。
任一**硬失败**（V 失败、契约回归失败）或 `r̂_k` 越界 ⇒ 冻结晋升，并触发 P-Quarantine（定义 428）复审。
门槛只用"是否通过既有闸门"的统计，不引入新的数值判据。

**定义 435（课程调度器 C-Sched 与活性）**
C-Sched 维护以 `(层, D⊥, age)` 为键的优先队列与准入控制：全局在飞修复 ≤ 1（保守）或每层 ≤ 1；
总预算 `Σc ≤ B_tools`（继承 TB-Contract 定义 424）。
**活性/反饥饿**：若盲区 `age > T_age` 而其下层因门槛未过长期停滞，则**不无限等待**，
而是按退化链把它下放到"先验独立"路径（LeanGauge 纯数值探测，不依赖 AP-Cal），并记 stale 事件入审计日志。
这保证课程不会因先验污染而饿死整个修复系统。

**定义 436（预训练课程 RTrain）**
元训练 episode 序列按环境难度 `D_env` 分阶段 `e₀→e_{K'}`，阶段内 i.i.d.，跨阶段保留
replay buffer 与重要性权重 `w(e) = p_uniform(e)/p_curriculum(e)`：
`min_θ Σ_e w(e)·E[−log p(u*|ctx)] + β_KL·KL(q_θ‖p_phys)`。
replay 防止课程末段对早期环境的灾难性遗忘；`w` 使课程分布下的目标仍无偏估计均匀目标（引理 57）。

**定义 437（审计排行榜与冻结候选池）**
候选校准器池 `C = {AP-Cal, AP-Cal+夹紧, BP-Cal, 分片 AP-Cal, Conservative-Stub}`，
部署前**冻结并哈希承诺** `commit(C)`（不可事后增删，定义 445 记入日志）。
每个候选在同一封存评测集 `V_seal` 上产生指标向量
`m(c) = (coverage, ECE, mean|z|, repair_gain, tail_risk@P99, violations)`。
**选择规则（安全字典序）**：先剔除 `violations > 0` 的候选（gate-violating）；
在剩余集合上按 `(最小 tail_risk, 最大 repair_gain, 最小 ECE)` 字典序比较；同分保留现任（保守）。

**定义 438（冠军-挑战者与统计显著性）**
每轮在**同一评测单元**上做配对 bootstrap，估计 `Δ(c, c_inc)` 的分布；
挑战者仅当 `P(Δ > δ_LB) ≥ 1−β_LB` 才取代现任，否则保留现任。
`δ_LB` 为最小临床显著差，`β_LB` 默认 0.05。排行榜必须报告置信区间，禁止只报点估计或只报冠军。

**定义 439（封存集与反 Goodhart）**
`V_seal` 与训练、候选生成、难度估计**完全隔离**；按周期 `T_rot` 轮换，旧集可解密用于事后分析但**不得回灌**训练。
**报告完整性**：排行榜必须同时报告全部候选的全部指标（含失败），禁止"只报冠军 / 只报单一指标"。
**选择约束**：任何选择规则至少同时包含 `tail_risk` 与一个安全指标，禁止单目标优化。

**定义 440（签名计分与投毒防护）**
环境中可经回执进入系统的信息，其指标可信当且仅当 `trust(m) ⇔ m 由受信计量通道 + 签名回执（定义 417）计算`。
VLA 解说文本、外部自由文本、未签名样本**一律不得写入 V_seal 或排行榜**（与定义 429 白名单一致）。
这是"排行榜投毒"的第一道防线：分数只能来自可验证的计量回执，而不是自报。

**定义 441（排名稳定性 / 漂移检测 RankAudit）**
对若干占位切片 j（区域 / 材质族 / 时段）分别排名，计算 `τ_j = Kendall τ(rank_j, rank_ref)`。
若 `median_j τ_j < τ_min` 或成对反转率 `> ρ_max` ⇒ 判定**排序结构漂移**：
先冻结 LB 切换、回退现任，并触发 P-Quarantine 复审；若同时覆盖 SLA 跌破（引理 48 系），
则 `H_s := {UNKNOWN}`（退化链第 1 级）。漂移检测的统计功效见引理 54。

**定义 442（课程×排行榜单向耦合）**
(a) 排行榜 → 课程：现任 champion 的**分片**预测误差只用于加权 D⊥ 中的 `A_obs`，**仅影响排序**；
(b) 课程 → 排行榜：评测切片按课程层**均衡采样**，防止易例主导榜单（层均衡评测）。
信息流单向、且**均不写回数值契约**；任何试图用榜单分数反向放宽闸门的行为被定义 444 直接禁止。

**定义 443（晋升无遗忘 No-Forgetful Promotion）**
每次晋升（含最高层结束）都对**全部已热替换子图**重跑契约回归测试；任一失败 ⇒
回滚该次晋升及本次全部替换（回到晋升前快照），记 regression 事件。
因此已验证子图集合在安全意义下单调：新增子图独立验证、既有子图在每次晋升时重新验证、
失败则整体回滚——不存在"局部修复静默污染全局快照"的路径（引理 55）。

**定义 444（排序/选择不变式 Order-Select Invariant）**
课程只改变执行顺序，排行榜只在预注册、通过闸门的候选间选择；二者**不得放宽**
λ 风险门、β 增益注、V 交叉验证、契约回归、热替换、回滚中的任何一条。
形式化：本轮可执行修复集合 `A₃ ⊆ A₂`（ToolGauge 可执行集合），候选选择 `c* ∈ C_gate ⊆ C`。

**定义 445（审计日志与决策可复现）**
每次课程排序、晋升、排行榜比较、切换、回滚写入**仅追加**日志：排序键、`commit(C)`、`commit(V_seal)`、
bootstrap 种子、指标向量、决策与置信区间。
日志是 claims（定义 423）的来源：任何语言解说中的排名/分数必须引用日志条目，否则整条剥离。

**定义 446（继承与退化特例）**
令 `K=1`（单一课程层且 `C={AP-Cal}`）⇒ LadderGauge ≡ ToolGauge；
再令 `VLA=∅、T₀={被动观测}、MP-Φ=物理先验 GP`（定义 431）⇒ LeanGauge；再退化 ⇒ MODGAUGE。
退化链：LadderGauge 失效（课程停滞 + 排行榜置信不足 / 排名漂移 / 预算耗尽）⇒ ToolGauge 到达序 + P-Quarantine
⇒ LeanGauge ⇒ MODGAUGE。

## 2. 关键算法骨架

```python
# IP-321 C-Box：锚定难度分（与被测先验正交，定义 432）
def difficulty_anchored(s, dbox, receipts, pre_env):
    cov  = dbox.coverage[s]                        # 位图（继承定义 398/399）
    amb  = cross_channel_dispersion(receipts[s])   # 仅用已测得的 cross.modal 残差
    risk = pre_env.margin(s)                       # Pre 包络裕度（定义 416）
    nmin = analytic_n_min(s)                       # 定义 426
    return (W_C*(1-cov) + W_A*amb + W_R*risk + W_N*nmin)   # 禁止输入 VLA/AP-Cal 分数

# IP-322 C-Sched：分层 + 自步晋升 + 无遗忘晋升
class CurriculumScheduler:
    def enqueue(self, s):
        self.queue[self.stratum[D(s)]].add(s)
    def next(self):
        for k in range(self.k_ready):              # 只在已晋升的层内取
            if self.queue[k]:
                return min(self.queue[k], key=lambda s: (D(s), s.seq))
        return None
    def promote(self, k, stats):
        if stats.n >= self.n_gate and stats.ok(self.eps, self.delta):
            snapshot = M.snapshot()
            self.k_ready = k + 1
            if not rerun_all_regressions(M):       # 定义 443：全量重验
                M.restore(snapshot); self.rollback(k + 1)
                return False
        elif stats.hard_fail() or stats.ratio_out_of_band():
            self.freeze(); M.pquar.review()        # 冻结晋升 + 先验复审
            return False
        return True

# IP-323 RTrain：预训练课程 + replay + 重要性权重（定义 436）
def rtrain(theta, env_stages, replay):
    for stage in env_stages:                       # 由易到难
        for e in stage:
            ctx = sample_episode(e)
            loss = -log_posterior(theta, ctx) * importance_weight(e)
            loss += BETA_KL * kl(amortized(theta), physical_prior)
            theta = step(theta, loss)
            replay.push(ctx)                       # 防遗忘

# IP-324 LB-Select：冻结候选 + 封存评测 + 冠军-挑战者（定义 437/438）
class Leaderboard:
    def __init__(self, pool, sealed):
        assert sha256(canon(pool)) == self.commitment   # 预注册，不可增删
        self.pool, self.sealed = pool, sealed
    def evaluate(self, c):
        return metric_vector(c, self.sealed)       # 全指标、全候选，报告完整性
    def select(self):
        legal = [c for c in self.pool if self.eval[c].violations == 0]  # 安全字典序
        inc = self.incumbent
        for c in legal:
            if paired_bootstrap_p(c, inc, delta=self.delta_LB) >= 1 - self.beta:
                inc = c
        return inc                                 # 同分/未达显著 ⇒ 保留现任

# IP-325 RankAudit：分片排名稳定性（定义 441）
def rank_audit(LB, slices):
    tau = [kendall(LB.rank(sl), LB.ref_rank) for sl in slices]
    if median(tau) < TAU_MIN or inversion_rate(LB) > RHO_MAX:
        LB.freeze(); M.pquar.review(); return "drift"
    return "stable"

# IP-326 LadderGauge 主闭环：只重排 + 选校准器，闸门全继承
def laddergauge_round(M, obs, audio, tac, depth, det):
    for s in M.dbox.detect_blind_spot():           # 继承定义 398/399
        M.csched.enqueue(s, D=difficulty_anchored(s, M.dbox, M.receipts, M.pre_env))
    while (s := M.csched.next()) is not None and M.budget_ok():
        if s not in M.inflight:
            M.inflight.add(s)
            submit_async(toolgauge_6c, M, s)       # 复用 6C，不改任何闸门
    for k in range(M.csched.k_ready):              # 异步/离线晋升检查
        M.csched.promote(k, M.stats[k])
    if M.rank_audit() == "drift" or M.lb.confidence_low():
        M.lb.freeze(); M.use_toolgauge_order = True    # 退化链：到达序 + P-Quarantine
```

## 3. 推导

**引理 51（课程的最优发现成本，含显式前提）**
设污染先验在任意层单次修复暴露失败的概率 `≥ p`（**跨层共享失败模式假设**），
层 0 单次成本 `c₀`、最高层 `c_max`，检测预算 `n₀` 次。则课程顺序在前 `n₀` 次尝试内以概率
`≥ 1−(1−p)^{n₀}` 检出污染，成本 `≤ n₀ c₀`；到达序最坏成本 `≤ n₀ c_max`。
故**发现成本比 ≤ c₀/c_max**。
**显式限制**：若污染是**异质稀疏**的（只在某些难层显现），课程不能在易层提前暴露；
且"易层全过"会制造**晋升假信心**。该假设是本引理成立的前提，也是 E442 的证伪目标。

**引理 52（排序不扩大可执行集合 / 安全单调）**
`A₃ ⊆ A₂`，且每个实际执行的修复仍逐一通过 λ≥γ、β≥γ_B、V 交叉验证、契约回归、回滚。
故 MODGAUGE 五不变式保持，物理副作用不增加，最坏单次修复风险不增加。
证明：准入（定义 435）与选择（定义 444）都是**上游过滤器**，不修改任何下游闸门判定。

**引理 53（排行榜的选择泛化界）**
候选池预注册且 `|C|` 固定，封存集 `N` 个 i.i.d. 评测单元，指标有界于 `[0,1]`，
冠军选择用经验均值 + `δ_LB` 余量。则对任意 `δ>0`：
`P(所选 c 的真实指标比最优差 > δ) ≤ |C|·exp(−2N(δ−δ_LB)²)`（Hoeffding + union bound）。
**推论 53.1**：若候选可**自适应生成**或指标**自报**，则 `|C|` 无界 / 评测单元不同分布，
union bound 失效——这正是必须冻结候选池（定义 437）与使用签名封存指标（定义 439/440）的原因。

**引理 54（排名反转作为漂移探测器，带功效）**
设候选真实分片差距的 Lipschitz 常数为 `L`，部署相对校准的 TV 漂移 `≤ η`。
则只有真实差距 `≤ 2ηL` 的候选对才可能发生分片排名反转；
观测反转率 `ρ` 给出漂移下界的可检验估计 `η̂ ≳ ρ/(2L·N_pairs)`，
并且当 `ρ > ρ_max` 时以 `1−exp(−2Nρ²)` 拒绝"无漂移"原假设。
**系**：RankAudit 是 P-Quarantine 的**多元、带统计功效**升级，替代仅在 `n=3` 上做符号检验的弱断路器。

**引理 55（晋升无遗忘的单调性）**
若每次晋升对全部已热替换子图重跑回归、失败即整体回滚到晋升前快照，
则任意时刻已验证子图集合 `V_t` 满足：新增元素均经独立验证；既有元素的验证状态不因新替换被隐式改变；
回滚恢复的旧状态本身是此前验证过的。故**组合单调性**（MODGAUGE 不变式）保持，
且不存在"局部修复污染全局快照"的静默路径。

**引理 56（时序与并发保持）**
C-Sched、晋升回归、LB 评测全部位于 50Hz 计量路径之外；准入控制限制在飞修复 ≤ 1/层，故并发 `≤ K`；
50Hz 周期新增仅 `O(1)`（读队列头 / 在飞计数）`< 0.2ms`；单盲区修复时延仍 `≤ τ_repair`，
总修复视界受 TB-Contract 与 `B_tools` 硬顶约束 ⇒ 硬实时（引理 45/50）与预算不变式保持。

**引理 57（课程预训练的可证明代价）**
在课程分布 `p_cur` 下训练、目标分布 `p_uni` 下评估，超额风险满足
`R̄(q_θ) ≤ [引理 47 的界] + √(KL(p_cur‖p_uni)/(2M))`。
**系**：课程"过易"会使 KL 增大、界退化——**课程学习并非免费**；
必须用 replay（定义 436）与 E453 实测 KL/增益权衡。

## 6. 本轮最大风险（一句话）

**一句话**：课程与排行榜都依赖一个"裁判量"——难度分和榜单分数——而一旦这个裁判量本身
被污染源或分布偏移**反向操纵**（难例被算成"简单"、违约候选被算成"冠军"），
课程会把污染源排到最前面、排行榜会给系统性偏差盖上"统计显著"的章，
于是第 2 轮的跨盲区相关偏差不但没被抑制，反而获得了"**正当程序的外观**"（Goodhart + 课程错序）。

**次级风险与缓解**
1. **难度分被污染源操纵** → 正交原则（定义 432）+ E452 正交性检验 + 分层边界冻结；
2. **晋升假信心（异质稀疏污染）** → 引理 51 显式前提 + E442 证伪实验 + 每层随机审计抽样（canary）；
3. **排行榜 Goodhart** → 多指标安全字典序 + 封存集轮换 + 禁止单目标（定义 437/439）+ E444；
4. **排行榜投毒** → 签名回执计分、自报指标禁入（定义 440）+ E448；
5. **排行榜过拟合/自适应候选泄漏** → 候选池哈希冻结 + 引理 53.1 + E449；
6. **晋升回归漏检导致全局污染** → 全量重验 + 整体回滚（定义 443、引理 55）+ E446；
7. **课程饥饿** → 年龄阈值下放到先验独立路径（定义 435）+ E447；
8. **排行榜/课程拖慢实时路径** → 全异步/离线 + 并发硬顶（引理 56）+ E451。

## 2. 形式化定义（要点）

**定义 432（锚定难度分 D⊥）** `D⊥ = w_c(1−cov)+w_a·A_obs+w_r·R_env+w_n·(n_min/n̄)`；**正交原则**：所有输入由与被测先验正交的计量通道测得，禁止 VLA/AP-Cal/榜单分数入内。
**定义 433/435（分层与调度）** 按 D⊥ 分位数分层，前置偏序晋升；C-Sched 准入控制在飞 ≤1/层，年龄超阈值则下放先验独立路径（反饥饿）。
**定义 434（自步晋升）** 仅当成功率、V 通过率、实测/预测收缩比全部达标且样本足够才晋升；硬失败或收缩比越界 ⇒ 冻结 + P-Quarantine 复审。
**定义 436（RTrain）** 课程分阶段 + replay + 重要性权重，防止灾难性遗忘并保持均匀目标的无偏估计。
**定义 437/438（排行榜）** 候选池冻结哈希；安全字典序（先剔除违约者，再比 tail_risk/gain/ECE）；配对 bootstrap + δ 余量决定切换，同分保留现任。
**定义 439/440（反 Goodhart / 投毒）** 封存集隔离与轮换、全候选全指标报告、禁单目标；仅签名回执计算的指标可信，自报一律禁入。
**定义 441（RankAudit）** 分片排名 τ / 反转率越界 ⇒ 冻结切换 + P-Quarantine；结合 SLA 跌破 ⇒ H_s := {UNKNOWN}。
**定义 442（单向耦合）** 榜单→课程只影响排序；课程→榜单只影响层均衡采样；都不写回数值契约。
**定义 443（无遗忘晋升）** 晋升时全量重跑已替换子图的契约回归，失败整体回滚到晋升前快照。
**定义 444（排序/选择不变式）** 只换顺序与候选，不放宽 λ/β/V/回归/热替换/回滚。
**定义 445（审计日志）** 仅追加，记录排序键/两次哈希/bootstrap 种子/指标/决策；claims 必须引用日志。
**定义 446（退化特例）** `K=1 ∧ C={AP-Cal}` ⇒ LadderGauge ≡ ToolGauge；继续退化 ⇒ LeanGauge ⇒ MODGAUGE。

## 3. 关键算法骨架

```python
# IP-321 锚定难度分（正交，定义 432）
def difficulty_anchored(s, dbox, receipts, pre_env):
    return (W_C*(1-dbox.coverage[s])
            + W_A*cross_channel_dispersion(receipts[s])
            + W_R*pre_env.margin(s)
            + W_N*analytic_n_min(s))          # 禁止 VLA/AP-Cal 分数

# IP-322 课程调度（分层 + 自步晋升 + 无遗忘，定义 433-435/443）
class CurriculumScheduler:
    def next(self):
        for k in range(self.k_ready):
            if self.queue[k]:
                return min(self.queue[k], key=lambda s: (D(s), s.seq))
        return None
    def promote(self, k, stats):
        if stats.n >= self.n_gate and stats.ok(self.eps, self.delta):
            snap = M.snapshot(); self.k_ready = k + 1
            if not rerun_all_regressions(M):        # 全量重验（无遗忘）
                M.restore(snap); self.rollback(k + 1); return False
        elif stats.hard_fail() or stats.ratio_out_of_band():
            self.freeze(); M.pquar.review(); return False
        return True

# IP-324 审计排行榜（冻结候选 + 封存评测 + 冠军-挑战者，定义 437/438）
class Leaderboard:
    def __init__(self, pool, sealed):
        assert sha256(canon(pool)) == self.commitment
        self.pool, self.sealed = pool, sealed
    def select(self):
        legal = [c for c in self.pool if self.eval[c].violations == 0]
        inc = self.incumbent
        for c in legal:
            if paired_bootstrap_p(c, inc, delta=self.delta_LB) >= 1 - self.beta:
                inc = c
        return inc                                  # 未达显著 ⇒ 保留现任

# IP-325 排名稳定性（带功效的漂移探测，定义 441）
def rank_audit(LB, slices):
    tau = [kendall(LB.rank(sl), LB.ref_rank) for sl in slices]
    if median(tau) < TAU_MIN or inversion_rate(LB) > RHO_MAX:
        LB.freeze(); M.pquar.review(); return "drift"
    return "stable"

# IP-326 主闭环：只重排 + 选校准器，闸门全继承
def laddergauge_round(M, obs, audio, tac, depth, det):
    for s in M.dbox.detect_blind_spot():
        M.csched.enqueue(s, D=difficulty_anchored(s, M.dbox, M.receipts, M.pre_env))
    while (s := M.csched.next()) is not None and M.budget_ok():
        if s not in M.inflight:
            M.inflight.add(s); submit_async(toolgauge_6c, M, s)   # 6C 闸门不变
    for k in range(M.csched.k_ready):
        M.csched.promote(k, M.stats[k])
    if M.rank_audit() == "drift" or M.lb.confidence_low():
        M.lb.freeze(); M.use_toolgauge_order = True               # 退化链
    return MODGAUGE_round(M, obs, audio, tac, depth, det)         # 主控不变
```

## 4. 推导

**引理 51（课程发现成本，含前提）** 跨层共享失败模式（单次暴露概率 ≥p）下，课程在前 `n₀` 次内以 `≥1−(1−p)^{n₀}` 检出污染、成本 `≤n₀c₀`，到达序最坏 `≤n₀c_max` ⇒ 成本比 `≤c₀/c_max`。**限制**：异质稀疏污染下不成立，且易层全过会制造晋升假信心（E442 证伪）。
**引理 52（安全单调）** `A₃⊆A₂`；准入与选择都是上游过滤器，不修改任何下游闸门 ⇒ 五不变式保持、副作用与最坏单次风险不增。
**引理 53（排行榜选择界）** 冻结候选池 `|C|`、封存 `N` 个 i.i.d. 单元、指标有界：`P(所选比最优差>δ) ≤ |C|·exp(−2N(δ−δ_LB)²)`。推论 53.1：自适应生成或自报指标使界失效 ⇒ 必须冻结候选池 + 签名封存指标。
**引理 54（排名反转检测漂移）** Lipschitz `L`、TV≤η 时只有真实差 `≤2ηL` 的候选对会反转；反转率 `ρ` 给出 `η̂≳ρ/(2L·N_pairs)`，`ρ>ρ_max` 时以 `1−exp(−2Nρ²)` 拒绝无漂移 ⇒ RankAudit 是 P-Quarantine 的带功效升级。
**引理 55（无遗忘晋升单调）** 晋升全量回归 + 失败整体回滚 ⇒ 已验证子图集合安全单调，无"局部修复污染全局快照"的静默路径。
**引理 56（时序并发保持）** 课程/晋升/LB 全在 50Hz 路径外；在飞 ≤1/层 ⇒ 并发 ≤K；周期新增 `<0.2ms`；修复时延 `≤τ_repair`，总视界受 TB-Contract 与 `B_tools` 硬顶 ⇒ 硬实时与预算不变式保持。
**引理 57（课程代价）** `R̄(q_θ) ≤ [引理47界] + √(KL(p_cur‖p_uni)/(2M))`；课程过易使界退化 ⇒ 课程非免费，需 replay + E453 实测。

## 8. 本轮最大风险

**一句话**：课程与排行榜的"裁判量"（D⊥ 与榜单分数）一旦被污染源或分布偏移反向操纵，
系统会把污染源排到最前面、并给系统性偏差盖上"统计显著"的章——第 2 轮的跨盲区相关偏差
因此获得"正当程序的外观"，比没有课程/排行榜更难被发现。

**三重兜底**：正交原则（定义 432）+ 异质污染证伪组（E442）；冻结候选池与封存签名计分（定义 437–440、E448/E449）；
排名稳定性断路器与退化链（定义 441/446）。**残余不可消除项**：`D⊥` 的正交性依赖计量通道本身不被攻破；
一旦底层计量回执可信性失守，课程与排行榜都会一致地、可审计地犯错。
