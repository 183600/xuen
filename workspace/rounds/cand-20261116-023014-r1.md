# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「轻量化设计」×「交互设计」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**轻量阶梯 + 有界交互**。两个灵感分别治理 v9 的两笔债：算力债（AC/MW/ID 三模块叠在已满的 v8 上，块证书 12ms 全量前向模型在域偏移时反而最贵）、信任债（v9 的安全证书在 Δ_dom 滞后时恰是最不可靠，而系统没有任何"求援"通道，只能硬扛或急停）。核心手段：**soundness 单调的阶梯证书**让最便宜的 Tier-0 不依赖学习模型、从而对 Δ_dom 免疫；**有界交互包络**把人类作为可选加速器接入退化链，其沉默中立元 ≡ 安全默认。任一新模块失效 ⇒ 严格退回 v9，而非行为漂移。

## 0. 直觉与动机

**灵感 1（轻量化设计 → 阶梯证书与早退）**
直觉：v9 在每个 5Hz 块生成时，对 64 条候选各做 K 步学习前向模型 rollout，12ms 里绝大部分花在"证明已经明显安全"的候选上。轻量化设计的经典手法是 **早期退出 / 级联分类器 / anytime 计算**：先用几乎零成本的判据淘汰大多数情形，只有边缘样本才升级到重模型。核心创新：**阶梯证书器（TieredCertifier, TC）**：三层 soundness 单调的证书 S₀ ⊆ S₁ ⊆ S₂ ⊆ S_true——Tier-0 是纯几何/运动学的解析可达集（刹车距离 + 扫掠体 + 传感器噪声膨胀），不含任何学习参数；Tier-1 是线性/浅代理；Tier-2 才调用 v9 的 LSTM-MPC。默认在 Tier-0 早退；仅当"证书保留量" r(t) 逼近边界或 Δ_dom 上升时才升级。关键红利不仅是省算力，更是**安全**：Tier-0 不依赖前向模型，故 v9 最大风险（域偏移时学习证书最不可靠）被一条与 Δ_dom 正交的解析证书兜底。

**灵感 2（交互设计 → 有界交互包络与可读退化）**
直觉：v9 的 ER 是单向播报（系统→人），人类不在退化链里。交互设计认为：系统的状态、能力边界、失败原因都应被"可读地"呈现，且交互应是有来有回的协商。核心创新：**交互中介（InteractionBroker, IB）**：当系统进入"信任缺口"（任何层级都无证书 ∧ Δ_dom 高），它发出**求助请求（RFG）**，附一张**退化卡片**（用最小认知负荷说清"哪里失效、有哪些已认证选项"）。人类可回传一个**限时信任令牌**，在**预先离线认证的安全包络 E_h** 内选择加速/降速/停驻/细化目标。三条铁律：令牌只在 E_h 内选择（**交互不越安全包络律**）；沉默的中立元 = 安全默认（**交互超时安全律**）；卡片默认只给一眼可辨的 affordance、细节按需展开（**轻量渐进披露律**）。于是人类是可选的加速器，而绝非安全依赖。

## 1. 研究问题（轮次升级版）

- **Q1（阶梯健全性）**：在 S₀ ⊆ S₁ ⊆ S₂ ⊆ S_true 的单调嵌套下，早退证书能否逐位保持 v9 引理 82 的块安全性？如何构造对任意杂乱场景都 sound 的、无学习参数的 Tier-0？高层更"不保守"所能换取的性能上界是什么？
- **Q2（交互安全边界）**：在限时令牌 + 固定包络 E_h 下，人类输入是否可能降低任何安全不变式？T_int 与安全默认之间的时序约束是什么？如何界定"人类误批准/过度信任"带来的净风险，并给它一个可预注册的上界？
- **Q3（轻量交互的信息论）**：给定认知负荷预算 B_cog，保留人类正确决策能力的最小信息集是什么（速率-失真表述）？渐进披露能否在不损理解度的前提下压低负荷？默认 affordance 应传递哪一个"决策最相关位"？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 阶梯证书律（Tiered-Certificate / Early-Exit, TC）**
证书是 soundness 单调的级联：S₀ ⊆ S₁ ⊆ S₂ ⊆ S_true，每层都 sound（认证 ⇒ 真实安全），高层以更大成本换取"更不保守"。按证书保留量 r(t) 早退；Tier-0 仅用 (s, 几何, 运动学, 传感器噪声界)，对 Δ_dom 免疫。任一高层失效 ⇒ 回落到 Tier-0 或 v9 全量证书，不改变决策语义。

**P14 交互不越包络律（Interaction-Within-Envelope, IB）**
人类经限时信任令牌接入，令牌只在预认证包络 E_h 内选取动作/选项；令牌 TTL 到期自动失效；M₀ 硬检查不因令牌放宽；沉默中立元 v_h^⊥ = 安全默认（减速/停驻）。人类是可选加速器，非安全依赖。

**P15 轻量渐进披露律（Progressive-Disclosure / Legibility Budget）**
退化状态的呈现是一个受 B_cog 约束的编码问题：默认最小 affordance（一瞥可辨），按需逐级展开细节；消息须在 T_int 内送达；披露策略在"理解度 vs 认知负荷"的 Pareto 前沿上取点，默认层承载决策最相关位。

## 3. 与基线的接口（如何退化）

- TC 高层失效（Tier-1/2 不可用或校验失败）⇒ 仅用 Tier-0；若 Tier-0 也不认证则回退 v9 全量证书/单步；决策语义与 v9 一致，仅成本/保守度变化；
- IB 失效 / 人类无响应 ⇒ 令牌永远缺失，v_h^⊥=安全默认，K_eff 完全由 v9 门控决定，等价 v9；
- 渐进披露/显示失效 ⇒ 无卡片、静默，等价 v9（ER 单向播报保留）；
- v9 的 AC/MW/ID 失效 ⇒ 依 v9 五级退化链；
- 全部失效 ⇒ 退回 v9 → v8 → v7 → v6。

## 4. 预期贡献

1. **阶梯证书**：soundness 单调级联 + 保留量早退，证书成本 p50 降 ~70%，且 Tier-0 提供域偏移免疫的解析兜底；
2. **有界交互包络**：将人类输入安全地纳入退化链——令牌/包络/TTL/沉默中立元，使"求助"从不确定性来源变成可选加速器；
3. **轻量渐进披露**：把退化沟通形式化为认知负荷约束下的编码问题，给出可测量的理解度-负荷 Pareto；
4. **算力-信任双闭环**：省下的证书算力反哺交互与感知；E571–E590 覆盖阶梯健全性、域免疫、包络遏制、超时安全、理解度、误信任与端到端。

## 5. 本轮最大风险

**一句话**：Tier-0 的域免疫以"几何/运动学模型准确"为前提，而杂乱场景中的未建模物体（软性、透明、动态、可变形）恰恰让解析证书偏乐观；当 Δ_dom 高使 Tier-2 不可信、系统转而信任 Tier-0 时，可能把一个"解析上安全、物理上并不安全"的块判为可执行——即"最轻量的证书在最陌生环境里承担了最重的安全责任"。

## 1. 符号体系增量（定义 540–549）

| 符号 | 含义 |
|---|---|
| T_i = (S_i, w_i), i∈{0,1,2} | 阶梯证书层：可认证动作集、单次认证成本；S₀⊆S₁⊆S₂⊆S_true |
| S_true | 真实动力学下满足安全不变式的动作块集合 |
| r(t) | 证书保留量：当前动作到其所用层级 S_i 边界的余量（归一化） |
| τ_res | 保留量早退阈：r ≥ τ_res 即停在当前层，不再升级 |
| i*(t) | 当前所选最便宜且保留量达标的证书层 |
| κ_h = (M, T_int, B_cog, v_h^⊥, E_h) | 人类端口契约：模态、交互时限、认知负荷预算、沉默中立元、安全包络 |
| τ_h = (o, ttl, issuer, nonce) | 限时信任令牌：在 E_h 内选择选项 o，租约到期失效 |
| E_h ⊆ S_true | 离线预认证的安全信任包络（候选动作/选项的并集的 sound 子集） |
| m_ℓ | 第 ℓ 级退化卡片消息（ℓ=0 最小 affordance，逐级细化） |
| B_cog | 认知负荷预算（消息复杂度/位数上界） |
| a^⊥ | 安全默认动作：从当前状态减速停驻，且已由某层证书认证 |

**新增定义 540（阶梯证书层级 CertificateTier）** 三层证书 T₀,T₁,T₂，满足 soundness 与单调嵌套：
```
x ∈ S_i  ⇒  动作块 x 在真实动力学下安全        （每层都 sound）
S₀ ⊆ S₁ ⊆ S₂ ⊆ S_true                          （高层更不保守）
w₀ ≪ w₁ ≪ w₂                                    （层级越深越贵）
```
Tier-0 仅用 (s_t, 运动学极限, 静态/动态障碍几何, 传感器噪声界与膨胀半径) 构造解析扫掠体可达集；不含任何学习参数。Tier-1 为线性/浅代理；Tier-2 即 v9 的 LSTM-MPC rollout。

**新增定义 541（证书保留量 CertificateReserve）** 对动作块 x 在层 i 上：
```
r_i(x) = dist(x, ∂S_i) / diam(S_i)      （到该层安全边界的归一化余量）
```
r(t)=r_{i*}(x)。r < τ_res 表示"再保守的动作也快要认证不了"，需升级或求助；r ≥ τ_res 表示当前层足够稳，可早退。

**新增定义 542（早退证书策略 EarlyExitPolicy）** 对每个候选块，从 Tier-0 起：
1. 若 Tier-0 认证且 r₀ ≥ τ_res ⇒ 在该层接受（早退，最省）；
2. 若 Tier-0 认证但 r₀ < τ_res，或存在被 Tier-0 拒绝但评分更高的候选 ⇒ 升级到 Tier-1 复核；
3. Tier-1 仍不满足 ⇒ 升级 Tier-2（v9 语义）；
4. 三层皆不认证 ⇒ v9 单步 fallback；若 fallback 也不认证 ⇒ 进入信任缺口（定义 545 与 IB）。
Δ_dom ≥ τ_dom 时强制至少到 Tier-1 复核（但 Tier-0 作为兜底始终保留）。

**新增定义 543（人类端口契约 HumanPortContract）** κ_h = (M, T_int, B_cog, v_h^⊥, E_h)。默认模态为一眼可辨的视觉 affordance + 短音频；T_int 为等待人类响应的时限；v_h^⊥ = 沉默 ⇒ 安全默认 a^⊥；E_h 为离线认证包络。人类端口与 MW 其他端口同构：超时/失效即注入 v_h^⊥，故"人不在"与"人拒绝"在退化语义上等价。

**新增定义 544（信任令牌与租约 TrustToken）** τ_h = (o, ttl, issuer, nonce)，o ∈ E_h。令牌有效 ⇔ 未过期 ∧ nonce 未重放 ∧ o ∈ E_h ∧ M₀ 当前放行。有效令牌可把 K_eff 提升到 min(K_ext(o), K_max) 或选择降速/停驻/细化子目标；令牌失效后立即回到 v9 门控语义。

**新增定义 545（安全信任包络 TrustEnvelope）** E_h ⊆ S_true 由离线用 TC 在候选工况网格上枚举并逐块认证得到，是"人类可选项的并集"的一个 sound 子集。人类只能在 E_h 内选，不能"点"到包络外动作；E_h 可随 load/chunk 版本化下发。

**新增定义 546（退化卡片与可读性预算 DegradationCard）** 卡片 m = (failure_class, options, confidence, recourse) 的四元组编码；其认知负荷 cost(m) 受 B_cog 约束。内容选择是决策论优化：在 cost(m) ≤ B_cog 与送达时延 ≤ T_int 下，最大化人类选对安全有效选项的期望收益。

**新增定义 547（渐进披露策略 ProgressiveDisclosure）** 披露级别 ℓ ∈ {0,1,…,L}，m_0 ⊆ m_1 ⊆ … 为逐级细化（信息单调不减）。默认 ℓ=0 只给决策最相关的一位（"能走 / 需确认 / 已停"）；人类追问或临界度上升才提升 ℓ。等级提升的触发与降级都受迟滞约束，避免闪烁。

**新增定义 548（交互时序与安全默认 InteractionTimingSafeDefault）** 从发出 RFG 起计时，超过 T_int 未收到有效令牌 ⇒ 执行 a^⊥（从当前状态减速停驻，且 a^⊥ ∈ 某层证书或 v9 中止点集）。停驻后若令牌到达，只有在其选项同时通过当前层证书复核时才可恢复，否则维持停驻。故交互等待有界、且不产生未认证动作。

**新增定义 549（轻量预算账本 LightweightBudgetLedger）** 每周期记账：阶梯证书实际花费 Σ 命中层的 w_i、交互/披露开销、v9 继承路径开销；约束"感知 2ms + 决策 20ms"不变，输出 p50/p99 用于 E572/E585 的守恒核验。

## 2. 形式化定义升级

**定义 493（六层指标层级）** 继承 v9：M=(M₀,M₁,M₂,M₃,M_dom,M_SLAM) 不变。
**定义 495/524（MetaWeight/情感，5 维）** 继承 v9 不变。
**定义 521（DA-OTL）** 继承 v9；块证书在 K_eff>1 时由 TC 的 i*(t) 层提供。

**升级定义 535（中间件契约，v10）** 契约 κ_m 扩展出人类端口 κ_h；MW 的 EDF 调度把 κ_h 作为**非阻塞**端口处理：轮询令牌，缺失即注入 v_h^⊥，绝不把主环阻塞在人类响应上。
**升级定义 539（有效块长，v10）**
```
K_eff(t) = K_eff^{v9}(t)                         若无有效令牌（≡ v9）
         = min(K_ext(o), K_max)                  若存在有效令牌 o∈E_h
```
即令牌只可"在包络内加速"，不可越过 K_max 或 M₀；令牌缺席时逐位等于 v9。
**升级定义 496（软证书触发，v10）** δ_trigger 增加两项：TC 至少 Tier-0 sound（否则进入信任缺口）∧ 若处于信任缺口则须有有效令牌或已执行 a^⊥。软触发与块级硬检查仍同尺度，无"块内软通过硬失"空洞。

## 3. 关键算法骨架

```python
# IP-357 TieredCertifier：阶梯证书器（早退 + 域免疫 Tier-0）
class TieredCertifier:
    def __init__(self, tier0, tier1, tier2, tau_res=0.20):
        self.tiers = [tier0, tier1, tier2]      # 每层实现 certify(state, actions) -> Cert|None
        self.tau_res = tau_res

    def certify(self, state, actions, delta_dom, tau_dom):
        """返回 (cert, tier_idx) 或 None（进入信任缺口）。每层均 sound。"""
        best = None
        for i, tier in enumerate(self.tiers):
            cert = tier.certify(state, actions)          # None 表示该层不能认证
            if cert is None:
                if i == 0:
                    best = None                          # Tier-0 都不认证，先记无
                continue
            if i == 0:
                best = (cert, 0)
                # 早退：解析证书稳且域可信 → 不再升级
                if cert.reserve >= self.tau_res and delta_dom < tau_dom:
                    return best
                continue
            if best is None or cert.reserve > best[0].reserve:
                best = (cert, i)                         # 高层换取更大保留量/更优评分
            if cert.reserve >= self.tau_res and i > 0:
                break                                    # 找到足够稳的更高层，早退
        return best

class InteractionBroker:
    def __init__(self, envelope, presenter, T_int=1.5):

        self.presenter = presenter
        self.T_int = T_int

    def in_trust_gap(self, ctx):
        return ctx.tiered_cert is None    # 任何层都无证书

    def poll_token(self, ctx):
        """非阻塞：主环不等待人类；返回有效令牌或 None。"""
        tok = ctx.human_port.read()                       # 读取最新令牌
        if tok is None or tok.expired() or not self.E.contains(tok.option):

        if tok.nonce in ctx.human_port.seen:              # 防重放
            return None
        ctx.human_port.seen.add(tok.nonce)
        return tok

    def safe_default(self, ctx):
        return ctx.chunker.safe_stop_from(ctx.state)      # 定义 548 的 a^⊥

    def escalate(self, ctx):

        self.presenter.render(ctx, level=0)
        ctx.rfg_deadline = now() + self.T_int
```

## 4. 推导

**引理 87（阶梯健全性与早退等价）** 设 S₀⊆S₁⊆S₂⊆S_true 且每层 sound。则 (i) TC 接受的任一块 x 必有 x∈S_{i*}⊆S_true，即在真实动力学下安全（直接扩展 v9 引理 82）；(ii) 若三层对全部候选都给出 v9 定义 533 的同一证书判定，则 i*=2、候选评分与 argmax 逐位同 v9，决策完全一致；(iii) 期望成本 E[w] = w₀ + p₁·(w₁ + p₂·w₂) ≤ w₂ = v9 成本，p₁,p₂ 为升级概率，早退使 p 显著 <1。证明：(i) 由每层 sound 与嵌套传递；(ii) 判定谓词与评分函数未变，仅证书来源标注不同；(iii) 由早退停止规则，只有保留量不足或被拒候选才升级。∎

**引理 88（Tier-0 域免疫）** Tier-0 的认证函数只依赖 (s_t, 几何, 运动学极限, 传感器噪声界与膨胀半径)，不含学习模型参数、也不含任何由训练分布导出的量；故其 soundness 与 Δ_dom 无关。于是当 Δ_dom 使 Tier-2 的误差界 β 失效（引理 82 前提破坏）时，只要 Tier-0 非空，系统仍有 sound 的解析兜底。推论：v9 的"最需要安全时证书最不可靠"在 v10 被一条与域偏移正交的证书链截断。**注意**：免疫的是"对学习模型误差"，不是"对未建模物理"——后者正是 §8 风险。∎

**引理 89（交互包络安全不变式）** 令牌 o 仅在 o∈E_h 时被接受（定义 544），E_h⊆S_true 且离线逐块认证；接受后仍须过 M₀ 当前硬检查（升级定义 496）。故最终执行动作 ∈ E_h ∩ M₀-safe ⊆ S_true。失效/过期/重放/越包络令牌一律返回 None ⇒ 注入 v_h^⊥。因此人类输入无论正确、错误还是恶意，都不能把执行推离安全不变式。∎

**引理 90（交互超时安全性与有界等待）** 从 RFG 发出起，主环每周期轮询令牌且从不阻塞；T_int 到期无有效令牌 ⇒ 执行 a^⊥，而 a^⊥∈某层证书或 v9 中止点集（定义 548），故 a^⊥ 动作及后续停驻安全（引理 82）。等待时长 ≤ T_int，主环保持 50Hz；停驻后的恢复必须重新通过当前层证书复核，杜绝"迟到令牌导致未认证动作"。∎

**引理 91（渐进披露的速率-失真刻画，略证）** 令 U 为人类决策所需变量、L 为任务损失、消息 m 的认知负荷 cost(m)≤B_cog。由率失真逆定理，min E[L] ≥ D(B_cog)（D 为失真-速率函数）；渐进披露是逐级细化码（信息单调），当级别提升时失真单调不增并趋近 D(B_cog)。默认 ℓ=0 取携带最大单位负荷互信息的一位（决策最相关位），故在同等理解度下负荷更低，实现 Pareto 前沿取点。∎（本条为刻画性命题，实验 E579/E580 做实证校验。）

**引理 92（v10 ⊇ v9 严格可选性）** 若 TC 高层不可用 ⇒ 按定义 542 回退 Tier-0 或 v9 全量证书，判定谓词恢复 v9；若 IB 失效/沉默 ⇒ 无令牌，K_eff 由升级定义 539 取 v9 值，且 v_h^⊥ 只在对 v9 本就不可安全执行时才触发 a^⊥；若 LP 失效 ⇒ 无卡片、静默，v9 ER 保留。三种情况下主环执行谓词与 v9 逐位一致，故 v10 是 v9 的严格超集（可选增强），失效即恒等退回。∎

## 8. 本轮最大风险

**一句话**：Tier-0 的域免疫以"几何/运动学模型准确"为前提，而杂乱场景中的未建模物体（软性、透明、动态、可变形）恰恰让解析证书偏乐观；当 Δ_dom 高使 Tier-2 不可信、系统转而信任 Tier-0 时，可能把一个"解析上安全、物理上并不安全"的块判为可执行——即"最轻量的证书在最陌生环境里承担了最重的安全责任"。
