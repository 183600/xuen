# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「工具调用」×「记忆检索」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**认证工具调用 + 准入检索 + 记忆卫生**。两个灵感分别治理 v9 的两种残余债：语义债（MW 只管实时模块，任务级能力仍是硬编码管线，语音/LLM 层无法安全地"调用能力"）、先验债（β、K_max、阈值是静态常数，ID 每 500 周期全量在线消融太贵）。必须保证"工具调用失败"与"检索为空"都注入中立元，严格等价退回 v9，而非行为漂移。

## 0. 直觉与动机

**灵感 1（工具调用 → 认证工具调用 / 能力经纪）**
直觉：v9 的契约中间件把"实时模块"变成可调度、可退化的一等公民，但任务级能力（导航、抓取、查询指标、写入记忆）仍是语音层硬编码 if-else。LLM/语音代理的"工具调用"范式能解耦"意图"与"能力"，却带来三种新故障：**幻觉工具名、参数不落地、副作用未检查**。核心创新：**认证工具调用经纪（CertifiedToolCallBroker, CTB）**：每个能力声明工具契约 τ=(id, In, Out, Pre, Post, D_τ, B_τ, v_τ^⊥, cert_τ)；规划器只能发出对**已注册工具**的类型化调用；broker 在执行前用六层指标层级验证前置条件 Pre、执行后验证 Post，失败/超时/幻觉一律注入中立结果 v_τ^⊥ 并**事务回滚**，绝不留下半执行副作用。工具调用因此从"信任 LLM"变成"信任证书 + 中立元代数"——与 v9 的 MW 共用同一套退化语义。

**灵感 2（记忆检索 → 检索增强安全记忆）**
直觉：v9 的风险先验（前向模型误差 β、块长 K_max、各层阈值）是静态常数，而 ID 的在线消融每 500 周期全量重跑，算力贵且对"相似情境"重复做功。人类操作员靠"回忆相似经历"快速设定先验。核心创新：**检索增强安全记忆（RetrievalAugmentedSafetyMemory, RASM）**：情景记忆条目 e=(φ_context, d_fp, ζ, Ĉ, y, provenance, t, conf, ttl)，其中 d_fp 是域指纹。检索前做**准入过滤**：只有域指纹兼容且未过期的记忆才进入证据集 A(q)；A(q)=∅ 时返回**空检索**（融合算子的中立元），先验退回 v9 静态默认。检索只能写入**性能参数集 Θ_perf**（β̂、K̂_max、工具选择、阈值，且限制在预注册安全包络内），永不触碰**安全参数集 Θ_safe**（M₀ 硬检查、SpatialCert、FaultCert）。"记忆"只再分配性能，不改安全不变式——与 P12 的 φ^elig 同构。

**灵感 3（两者合流 → 有界工具-记忆闭环）**
直觉：工具调用产出新经历，记忆检索又改变下一次工具选择，天然形成 act→remember→retrieve→act 闭环。危险在于**记忆污染**：机器人自己"看起来成功"的轨迹被写回、又被检索出来强化，形成自我确认。核心创新：**记忆卫生律（P15）**：每条记忆携带来源证书与谱系深度；性能记忆按 conf←conf·γ^Δt 衰减；安全事件记忆只追加、不可被自生成记忆覆盖；谱系深度 > L 或证据多样性 < D 时触发隔离（quarantine）。任何单条记忆对未来决策的影响因此几何衰减，闭环是**有界**的而非正反馈放大。

## 1. 研究问题（轮次升级版）

- **Q1（工具调用安全）**：如何用"前置证书 + 事务回滚 + 中立结果"，使幻觉工具名、错误参数、中途中止都退化为安全的中立结果，而非不安全动作或半执行副作用？
- **Q2（检索准入）**：如何定义域指纹与兼容谓词，使"域外/过期/被污染"的记忆不可能进入证据集，从而检索增强不引入域外证据、且安全参数与检索证据解耦？
- **Q3（闭环有界）**：在 act→remember→retrieve→act 闭环下，什么谱系/衰减/多样性条件保证记忆影响有界、无自我强化放大？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 认证工具调用律（Certified Tool Call, CTB）**
每个能力是一个工具契约 τ=(id, In, Out, Pre, Post, D_τ, B_τ, v_τ^⊥, cert_τ, side_effect)。规划器只能调用已注册工具；broker 依次校验类型、前置条件 Pre（基于六层指标层级与预算）、执行、后置条件 Post，全部通过才提交（commit），否则事务回滚并注入中立结果 v_τ^⊥。工具调用图（DAG）逐节点带中立回退，任一必需节点失败即沿中立元传播到安全回退计划，绝不产生半执行副作用。

**P14 检索准入律（Retrieval Admissibility, RASM）**
记忆条目携带域指纹 d_fp。证据集 A(q)={e : sim(d_fp_e,d_fp_q) ≥ τ_sim ∧ |Δ_dom_e−Δ_dom_q| ≤ ε_dom ∧ fresh(e) ∧ ¬quarantined(e)}；空集时 R(q)=∅ 为融合算子的中立元，fuse(θ,∅)=θ。检索只写 Θ_perf 且裁剪到预注册安全包络；Θ_safe 与 R 无关。

**P15 记忆卫生律（Memory Hygiene）**
每条记忆有 provenance、lineage、conf、ttl。安全事件记忆 append-only、不可覆盖；性能记忆按 γ^Δt 衰减；由工具调用派生的记忆打上该调用的证书与父谱系；lineage > L 或有效证据多样性 < D 时隔离并回退静态先验（必要时触发 v9 ID 的在线消融重新接地）。

## 3. 与基线的接口（如何退化）

- CTB 失效 ⇒ 规划器走 v9 硬编码管线（工具层旁路），等价 v9；
- RASM 失效 / 空检索 ⇒ 先验取 v9 静态默认（β、K_eff 公式），等价 v9；
- 记忆写入禁用 ⇒ 无适应，等价 v9；
- 记忆污染隔离 ⇒ 回退到静态先验，等价 v9；
- 以上全失效 ⇒ 完整退回 v9 ACMD，再退回 v8 / v7 / v6。

## 4. 预期贡献

1. **认证工具调用经纪**：把实时模块契约（MW）与语义工具契约（CTB）统一到同一套中立元代数；幻觉工具调用被归约为中立结果，工具副作用具备事务性；
2. **检索增强安全记忆**：域指纹 + 准入过滤 + 安全/性能参数解耦，使记忆增强可证不引入域外证据、不触碰安全不变式；
3. **有界工具-记忆闭环**：来源证书、谱系深度、置信衰减、只追加安全记忆与污染隔离，给出无自我强化放大的充分条件；
4. **闭环反哺**：检索先验降低 ID 在线消融频率，工具调用日志成为可审计的记忆来源；E571–E590 覆盖工具事务、检索准入、污染闭环、先验标定与端到端任务。

## 5. 本轮最大风险

**一句话**：域指纹由 DA-ML 计算，而记忆恰恰被用来纠正 DA-ML 的先验——若域偏移是渐进的，旧记忆会把"漂移后的分布"逐步记为"正常"，域指纹与记忆互相背书，形成**记忆洗白（memory laundering）**，使 β̂ 偏小、K_eff 偏大，在最需要保守的时刻给出最乐观的先验。

**新增定义 540（工具契约 ToolContract）** 每个能力声明 τ=(id, In, Out, Pre, Post, D_τ, B_τ, v_τ^⊥, cert_τ, side_effect)。Pre: State×In×Ctx→Bool 为前置条件（含六层指标层级约束与预算可行性）；Post: State×Out×Ctx→Bool 为后置保证；v_τ^⊥ 为失败时注入的中立结果，满足对下游聚合算子 ⊕ 的恒等性 x ⊕ v_τ^⊥ = x；side_effect=true 的工具必须携带 cert_τ 并在事务中提交。

**新增定义 541（认证工具调用 CertifiedToolCall）** 调用 c=(τ, args, cert, budget)。合法 ⇔ τ 已注册 ∧ args 通过 In 类型检查 ∧ Pre(state,args,ctx)=true ∧ budget 可用。执行语义为**事务性**：仅当 Post 验证通过才 commit；任一阶段失败（未知工具 / 参数错 / Pre 假 / 超时 / Post 假 / 异常）⇒ rollback 并返回 v_τ^⊥，绝不留下半执行副作用。

**新增定义 542（工具调用图 ToolCallGraph）** 规划器（语音/LLM 层）输出 DAG G=(V,E)：节点 v=(τ, args_refs, required)，边表示参数引用上游结果。broker 拓扑排序执行、拒绝环；required 节点返回中立元时沿边传播到**安全回退计划**（v9 硬编码管线），非 required 节点失败仅局部降级。

**新增定义 543（情景记忆条目 EpisodicMemoryEntry）** e=(φ, d_fp, ζ, Ĉ, y, provenance, t, conf, ttl, lineage, kind)。φ 为决策上下文；ζ/Ĉ 为 v9 动作块与块证书；y 为块级结局（任务进展、安全罚、中止事件）；provenance 为来源（工具调用证书 / ID 消融 / 操作员标注）；kind=perf 可更新，kind=safety 只追加不可覆盖。

**新增定义 544（域指纹 DomainFingerprint）** d_fp=(Δ_dom, h_sensor, z_scene, s_slam)：域偏移标量、传感器健康向量、场景嵌入草图、SLAM 风险统计。兼容谓词 compat(d_fp, d_fp') ⇔ sim(d_fp,d_fp') ≥ τ_sim ∧ |Δ_dom−Δ_dom'| ≤ ε_dom。

**新增定义 545（检索准入 RetrievalAdmissibility）** A(q)={e : compat(e.d_fp,q.d_fp) ∧ fresh(e,q.t) ∧ ¬e.quarantined}；R(q)=top-k_{e∈A(q)} sim(e.d_fp,q.d_fp)；A(q)=∅ ⇒ R(q)=∅。

**新增定义 546（检索增强先验 RetrievalAugmentedPrior）** θ_perf = fuse(θ_static, R)。融合算子 fuse(θ,∅)=θ（空检索为恒等元）；R≠∅ 时取置信加权稳健聚合（加权中位数），再裁剪到预注册安全包络：β̂∈[β_min,β_max]、K̂_max∈[1,K_max^0]、τ̂_safe∈[τ_min,τ_max]。**Θ_safe 不参与融合**。

**新增定义 547（记忆写入协议 MemoryWriteProtocol）** kind=safety 的条目 append-only 且不可被自生成记忆覆盖；kind=perf 条目 conf←conf·γ^{Δt} 并受 ttl 约束；由工具调用派生的条目 lineage = parent.lineage+1 且记录来源证书；同上下文重复条目做去重与置信合并。

**新增定义 548（记忆污染检测 ContaminationGuard）** 若 e.lineage > L 或有效证据多样性 effN(R) < D，则 e.quarantined←true，并从 A(q) 永久排除；同时触发一次 v9 ID 在线消融以重新接地，防止自我确认。

**新增定义 549（工具-记忆闭环 ToolMemoryLoop）** 每周期：R←retrieve(q)；θ_perf←fuse(θ_static,R)；规划器依 θ_perf 产出工具调用图 G；CTB 执行 G；结果按定义 547 写回记忆。闭环的每次写回都带证书与谱系，受定义 548 约束。

## 2. 形式化定义（要点与升级）

**定义 493（六层指标层级）** 继承 v8/v9：M=(M₀,M₁,M₂,M₃,M_dom,M_SLAM) 不变；Pre/Post 以 M 为判据。

## 3. 关键算法骨架

```python
# IP-357 CertifiedToolCallBroker：认证工具调用经纪
@dataclass
class ToolContract:
    id: str
    In: type; Out: type
    pre: Callable          # (state, args, ctx) -> bool
    post: Callable         # (state, out, ctx) -> bool
    deadline_ms: float
    budget: float
    neutral: object        # v_τ^⊥
    cert_required: bool
    side_effect: bool

class CertifiedToolCallBroker:
    def __init__(self, tools, mw, journal):
        self.tools = {t.id: t for t in tools}   # 只有已注册工具可达
        self.mw, self.journal = mw, journal

    def call(self, call, state, ctx):
        t = self.tools.get(call.tool_id)
        if t is None:                                  # 幻觉工具名
            return NeutralResult(call.tool_id, "unknown_tool")
        if not self._typecheck(t, call.args):          # 参数不落地
            return NeutralResult(t.id, "bad_args")
        if t.cert_required and not call.cert.valid():  # 缺证书
            return NeutralResult(t.id, "no_cert")
        if not t.pre(state, call.args, ctx):           # 前置条件失败
            return NeutralResult(t.id, "precondition")
        if not self._budget_ok(t, ctx):                # 预算不足
            return NeutralResult(t.id, "budget")
        tx = self.journal.begin(t, call)               # 事务开始
        try:
            with deadline_guard(t.deadline_ms):
                out = self._execute(t, call.args, ctx)
            if not t.post(state, out, ctx):            # 后置校验失败
                raise PostconditionViolation(t.id)
            tx.commit()                                # 提交副作用
            return out
        except (DeadlineOverrun, PostconditionViolation, Exception):
            tx.rollback()                              # 回滚，无半执行
            return NeutralResult(t.id, "failed")       # v_τ^⊥


# IP-360 ToolCallGraph：带中立回退的 DAG 执行
class ToolCallGraph:
    def execute(self, dag, state, ctx):
        results = {}
        for node in topo_sort(dag):                    # 检测并拒绝环
            call = node.bind(results)                  # 参数可引用上游结果
            r = broker.call(call, state, ctx)
            if is_neutral(r) and node.required:
                return self._safe_fallback(dag, node, results)  # 中立元传播
            results[node.id] = r
        return results


# IP-358 RetrievalAugmentedSafetyMemory：检索增强安全记忆
class RetrievalAugmentedSafetyMemory:
    def __init__(self, index, tau_sim=0.85, eps_dom=0.10,
                 gamma=0.999, ttl=3600.0, k=8, L=8, D=3):
        self.index = index
        self.tau_sim, self.eps_dom = tau_sim, eps_dom
        self.gamma, self.ttl, self.k = gamma, ttl, k
        self.L, self.D = L, D

    def admissible(self, e, q):
        return (not e.quarantined
                and e.d_fp.sim(q.d_fp) >= self.tau_sim
                and abs(e.d_fp.delta_dom - q.d_fp.delta_dom) <= self.eps_dom
                and (q.t - e.t) <= self.ttl)

    def retrieve(self, q):
        A = [e for e in self.index.candidates(q) if self.admissible(e, q)]
        if not A:
            return []                                  # 空检索 = 融合中立元
        return sorted(A, key=lambda e: -e.d_fp.sim(q.d_fp))[:self.k]

    def fuse_prior(self, theta_static, R):
        if not R:
            return theta_static                        # fuse(θ, ∅) = θ
        est = robust_weighted_median([(e.y, e.conf) for e in R])
        return clip_envelope(est, theta_static)        # 只裁剪 Θ_perf

    def write(self, e):
        e.lineage = (e.parent.lineage + 1) if e.parent else 0
        if e.kind == "safety":
            self.index.append_immutable(e)             # 只追加
            return
        e.conf *= self.gamma ** max(0.0, now() - e.t)  # 置信衰减
        if e.lineage > self.L or effective_n(self.index, e) < self.D:
            e.quarantined = True                       # 污染隔离
        self.index.upsert(e)
```

## 4. 推导

**引理 87（工具调用事务安全）** 对任意调用 c：(i) 若 c 不合法（未知工具/参数错/无证书/Pre 假/预算不足），broker 在产生任何副作用前返回 v_τ^⊥；(ii) 若执行中途失败或 Post 为假，事务回滚，状态恢复到调用前；(iii) 若所有调用均返回 v_τ^⊥，系统行为等价 v9 硬编码管线。故 CTB 不会使系统离开 v9 的可达状态集。证明：由定义 541 的分阶段校验与事务日志，commit 仅在 Post 通过后发生，rollback 幂等；中立元传播由定义 542 保证。∎

**引理 88（检索准入不引入域外证据，条件于指纹正确）** 设域指纹 d_fp 对真实域的映射忠实。则 e∈A(q) ⇒ compat(e.d_fp,q.d_fp) 且 fresh，故证据集只含信任域内、未过期的记忆；fuse 的输出被裁剪到预注册安全包络，且只写 Θ_perf。因此 Θ_safe 与 R 无关，v9 引理 82–86 的安全结论原样传递。证明：由定义 545/546 直接得到；Θ_safe 不出现在 fuse 的输入或输出中。∎（**注意**：本引理的条件正是本轮最大风险所在。）

**引理 89（工具-记忆闭环有界、无自我强化放大）** 在 conf←conf·γ^{Δt}（γ<1）、lineage>L 隔离、多样性<D 隔离下，任一记忆对第 t 次决策的权重 ≤ conf_0·γ^{t−t_0}；被隔离条目永久退出 A(q)。故单条记忆的累积影响被几何级数界定，闭环不产生正反馈放大。证明：权重衰减单调、隔离单调；对时间求和得几何上界。∎

**引理 90（退化等价）** CTB 不可用 ⇒ 规划器走 v9 管线；RASM 失效或空检索 ⇒ fuse(θ,∅)=θ 为 v9 静态先验；记忆写入禁用 ⇒ 无状态更新。故 v10 在两新模块均中立时与 v9 逐位等价。证明：逐项对应定义 541/545/546 的中立元性质与 v9 定义 532–539。∎

**引理 91（检索与工具图延迟预算）** ANN 检索 O(log N) 次距离比较、k=8、指纹相似度 O(d)；记忆写 O(log N)；工具图 O(V+E) 校验 + 各工具自身 WCET。检索与写回合计 ≤1ms，纳入 MW 感知侧 2ms 预算；工具执行按契约 D_τ 调度。证明：标准 ANN 复杂度 + 定义 540 的截止期约束。∎

**引理 92（安全/性能参数隔离）** Θ_perf∩Θ_safe=∅，且检索只写 Θ_perf、CTB 的 Post 与 M₀ 硬检查只读 Θ_safe。因此不存在"通过检索改写安全阈值"的路径；结合引理 88，检索增强不改变 v9 安全不变式。证明：由定义 546 的融合域与定义 540 的 Pre/Post 只读性。∎

## 8. 本轮最大风险

**一句话**：域指纹由 DA-ML 计算，而记忆恰恰被用来纠正 DA-ML 的先验——若域偏移是渐进的，旧记忆会把"漂移后的分布"逐步记为"正常"，域指纹与记忆互相背书，形成**记忆洗白（memory laundering）**，使 β̂ 偏小、K_eff 偏大，在最需要保守的时刻给出最乐观的先验。
