# 第 4 轮（灵感循环第 4 轮；本轮灵感：「可靠性」×「轻量化设计」）

> **基线**：第 3 轮 InstructGauge（IP-321–327；定义 432–447；引理 51–58；实验 E441–E456）。第 2 轮 ToolGauge、第 1 轮 LeanGauge / MODGAUGE 骨架继续继承不变。
> 本轮纪律：**可靠性是硬约束，轻量化是可选增强**。轻量化只能在可靠度约束内削减整备质量；任一环节不可信都必须一键退回完整 bundle（= InstructGauge），再沿既有退化链下行。可靠性不新造依赖，只加约束。

## 0. 直觉与动机

**灵感 1（可靠性 → 不是单点指标，而是跨阶段可组合的预算）**
直觉：说「这个传感器 99% 可靠」几乎无信息量。端到端可靠性是**串联相乘**：五个环节各自 99%，整体只剩约 95%；再叠加漂移与长时域，实际可能跌到 80% 多。更关键的是，这里要保证的不是「单次测量对」，而是「整份合同在任务时域内持续覆盖真值、且闭环不发出致盲动作」。所以第一件事是把可靠性做成一本**跨阶段账本**：接地、探测、分块、校准、执行各吃一份预算，任何阶段都不能静默借用；端到端可靠度由可靠性框图（RBD）串并联组合给出。`1−Π(1−R_i)` 的并联收益与 `ΠR_i` 的串联惩罚必须显式进账，否则「每层都达标、系统整体违约」是必然。

**灵感 2（轻量化设计 → RBDO，不是「越小越好」，而是「在可靠度约束下最小化整备质量」）**
直觉：结构轻量化不是随便挖洞，而是在刚度/强度/疲劳约束下做拓扑优化——先删「低应力」材料，保留「传力路径」。映射到计量系统：整备质量 = 参数量 + 采样数 + 激活传感器 + 工具子集 + 能耗；可靠度约束 = 覆盖/功能/组件可靠度。于是正确的提法不是「压缩模型」，而是**可靠性约束下的轻量化（RBDO）**：按「单位质量可靠度」从低到高剪枝，且绝不剪掉安全关键主张的最后一条证据路径。还要警惕一个工程常识：**不要把设计点贴在约束边界上**——零裕度设计在估计误差下约有一半概率违约，必须留运行点裕度。

**灵感 3（两者耦合 → 自指可靠性：轻量化会削掉用来证明自身可靠的证据）**
直觉：这是本轮真正的新危险。轻量化的对象（稀疏采样、蒸馏模型、少传感器）**同时**是产生「可靠性证据」的通道。于是系统可能用被削弱的证据去证明「削弱是安全的」——学生自己出卷子自己打分。若认证与轻量化共享同一 bundle，误差会同时抬高「能力」和「感知到的可靠度」，形成**自指可靠性偏差**：又便宜、又自信地错。解法不是禁止轻量化，而是结构性的**认证分离**：留一条不参与剪枝的**认证锚**（独立证据通道）来估计可靠度，并用量化后的**元可靠性**运行点裕度保证「关于可靠性的结论本身可靠」。这与第 3 轮「语言只改偏好、不改能力」是同一种分层思想：可靠性估计也只能读、不能改被它评估的对象。

## 1. 研究问题（本轮要回答什么）

- **Q1（可靠性的可组合性）**：如何定义覆盖 / 功能 / 组件三类可靠性，并让它们沿闭环可核算、不静默借用？
- **Q2（轻量化的边界）**：在可靠度约束下最多能削多少整备质量？剪枝序如何最优、又如何保证不剪断安全关键的证据路径？
- **Q3（自指可靠性）**：当轻量化削掉认证自身所需的证据时，如何打破循环，并保证「可靠性结论」的元可靠性？

## 2. 三条设计原则（雏形，正式化见产物区定义 448–462）

**P1 可靠性预算可组合、不可静默借用（Reliability Ledger）**
端到端目标按 RBD 分解到各阶段；每阶段只能消耗自己的配额，越用即拒绝或降级。形式化方向：`⊗_G(R_i) ≥ 1−α`，串联取乘积、并联取 k-of-n 二项尾；配额按对数分配 `Σ_i log a_i ≥ log(1−α)`。这给出一本可审计的「可靠性账本」，而不是事后拍脑袋的整体 SLA。

**P2 应力—强度与运行点裕度（Stress–Strength + Guard Band）**
把测量需求（容差 ε、漂移率、负载）当「应力」`D_s`，把感知/合同能力当「强度」`C_s`，可靠度 = `P(C_s > D_s)`；轻量化降低 `μ_C`、抬高 `σ_C`，故必须在 `β_op = β_target + z_{1−γ}·se(β̂) + Δβ_drift` 处运行，而不是贴着 `β_target`。贴边优化在工程上是反可靠性的。

**P3 认证分离与冗余优先剪枝（Certification Separation + Redundancy-Aware Pruning）**
认证锚 `A` 不参与剪枝；剪枝只删「单位质量可靠度」`ρ_i` 最低、且不触及安全最小割 `k_safe` 的单元。轻量化永远不能削掉「证明自己安全」的那条独立通道。这与结构拓扑优化「保留传力路径」完全同构。

## 3. 与基线的接口（如何退化）

- 认证锚不可用 / 可靠度 CI 过宽 / 稀有事件样本不足 ⇒ 放弃轻量化，恢复完整 bundle `π₀`（= InstructGauge）；
- 可靠度裕度不足 ⇒ 先缩短块长 `K`（接第 3 轮 `K_MAX^rel`），直至 `K=1`（= ToolGauge 逐步）；
- RBDO 求解失败 / k 割不可满足 ⇒ 不做剪枝，等价于 InstructGauge 原配置；
- InstructGauge 失效 ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE 原样。

## 4. 预期贡献

1. 一本**可靠性账本**：统一覆盖 / 功能 / 组件可靠度，给出跨阶段可组合、不可静默借用的核算口径；
2. 一个**可靠性约束轻量化器（RBDO）**：按单位质量可靠度剪枝，保留 `k_safe` 条安全证据路径，给出剪枝最优性条件与质量—可靠度交换率；
3. 一套**认证分离 + 元可靠性**机制：用不可剪枝的认证锚与运行点裕度打破自指可靠性循环；
4. 一条完整可证伪路径：E457–E472 覆盖账本校准、RBDO 前沿、裕度违约率、k 割安全、稀有事件估计、退化梯、故障注入与跨轮耦合。

## 5. 本轮最大风险

**一句话**：轻量化会同步削掉「用来证明轻量化可靠」的证据通道，一旦认证锚被污染或样本不足，系统会同时变得**又便宜又自信地错**——自指可靠性比第 3 轮的语义-时间放大更隐蔽，因为它不再表现为「动作错了」，而表现为「我们以为动作一定对」。

## 2. 形式化定义（要点）

**定义 448（可靠性三元组 `Rel_s`）** `Rel_s = (R_cov, R_fn, R_cmp)`，其中
`R_cov = P_{δ∼D}(∀t≤H: ‖err_s(t)‖ ≤ ε_s)` 为**覆盖可靠度**（合同在整个任务时域 H 内持续覆盖真值）；
`R_fn = P(闭环不发出致盲/越界动作 ∧ 恢复时间 ≤ T_rec)` 为**功能可靠度**；
`R_cmp = P(所需工具/传感器/模型在需要时可用)` 为**组件可靠度**。
合同可接受当且仅当 `R_cov ≥ 1−α_cov ∧ R_fn ≥ 1−α_fn ∧ R_cmp ≥ 1−α_cmp`（逐项，而非加权平均——任何一项失守都不可用别的项补偿）。

**定义 449（可靠性账本与 RBD 组合）** 闭环分解为阶段 `1..n`，可靠性框图 `G` 给出组合结构。`R_total = ⊗_G(R_1,…,R_n)`：串联 `Π R_i`；并联 `1−Π(1−R_i)`；k-of-n 取二项尾 `Σ_{j≥k} C(n,j) R^j (1−R)^{n−j}`。账本按对数配额分配 `a_i`，满足 `Σ_i log a_i ≥ log(1−α)`；`charge(stage, cost)` 在 `cost > a_i` 时**拒绝**并触发退化。公理：任何阶段不得静默借用他阶段配额。

**定义 450（合同可靠度函数）** `R_s(H) = exp(−∫_0^H λ_s(τ) dτ)`，`λ_s` 为由漂移率、接地失效与证据陈旧合成的风险率；常风险率下 `MTBF = 1/λ_s`。它把「单次测量可靠」与「整个任务时域可靠」区分开。

**定义 451（应力—强度模型与可靠度指标）** 容量 `C_s`（以容差为单位的测量/信息能力），需求 `D_s`（漂移 + 模型误差 + 负载）。裕度 `M_s = C_s − D_s`，可靠度指标
`β_s = (μ_C − μ_D) / sqrt(σ_C² + σ_D²)`，`R_s ≈ Φ(β_s)`（FORM 一阶近似）。
轻量化使 `μ_C ↓` 且 `σ_C ↑`，因此 `β_s ↓`——质量与可靠度之间存在可量化的交换率。

**定义 452（轻量化决策与整备质量）** `π = (m, n, q, toolset)` 分别表示模型参数规模、采样数、激活传感器数、工具子集；
`L(π) = w_m·m + w_n·n + w_q·q + w_t·|toolset| + w_e·E(π)` 为整备质量（计算 + 能量），即要最小化的「质量」。

**定义 453（可靠性约束轻量化 RBDO）**
`π* = argmin_{π ⊆ π₀} L(π)`
`s.t. P(Rel_s(π) ≥ 1−α) ≥ 1−γ`（可靠度约束的置信形式）、`π ⊇ A`（认证锚不可剪）、`k(π,c) ≥ k_safe(c)`（安全最小割）、shield/barrier 不变式保持、`K ≤ K_MAX^rel(π,ι)`。

**定义 454（单位质量可靠度与剪枝序）** `ρ_i = −ΔR_total / ΔL_i`（删去第 i 个单元的边际可靠度损失 / 质量节省）。剪枝按 `ρ_i` **升序**：先删「每省一单位质量、可靠度掉得最少」的单元。安全关键单元与认证锚的 `ρ_i` 记为 `+∞`（不可剪）。

**定义 455（证据路径冗余与安全最小割）** 对主张 `c`，其证据由 `m` 条路径 `P_1..P_m`（独立回执/独立传感器/独立模型）支撑；若任意 `k` 条同时失效才导致证据丢失，称 k-disjoint。`k_safe(c)` 为保持「可验证性」所需的最小路径数。剪枝后必须 `k(π,c) ≥ k_safe(c)`；安全/不可逆主张强制 `k_safe ≥ 2`（与第 3 轮独立回执交叉验证一致）。

**定义 456（认证锚与认证分离公理）** 认证锚 `A ⊆ π₀` 且 `A ∩ (π₀ \ π) = ∅`（锚永不被剪枝）。可靠度只在锚证据上估计：`R̂el_A(π)`。**认证分离公理**：`certify(π) = 1[R̂el_A(π) ≥ TARGET_OP]`，且任何来自 `π \ A` 的证据不得进入该估计。独立性要求：`A` 与剪枝决策之间不存在共同原因（无 d-连通路径），否则自指偏差重新出现。

**定义 457（运行点裕度与元可靠性）** `β_op = β_target + z_{1−γ}·se(β̂) + Δβ_drift`。元可靠性定义为 `P(R̂el ≥ 1−α | 真实 R ≥ 1−α) ≥ 1−γ`，即「关于可靠性的结论本身可靠」。设计点必须放在 `β_op`，不得贴 `β_target`。

**定义 458（RARE 稀有事件可靠度估计）** 当 `α ≪ 1/n` 时朴素 MC 不可行，采用子集模拟：以 `p₀` 为条件层概率，构造嵌套失效域 `F_1 ⊃ … ⊃ F_{L_lvl}`，逐层条件采样，`L_lvl = ⌈log(1−α)/log p₀⌉`；返回 `(R̂el, CI)`。亦可换重要性采样，但必须报告方差与 CI。

**定义 459（轻量化证书 LiteCert）** `LiteCert(π) = (ΔL, R̂el_A, β_op, anchor_ids, cuts, degrade_map)`：记录省了多少质量、锚证据给出的可靠度、运行点、锚标识、保留的 k 割、以及一份「如何一键退回 `π₀`」的退化映射。

**定义 460（可靠性触发退化梯 DG-Ladder）** 有序退化动作：`anchor_lost ∨ CI_width > CI_MAX ⇒ restore(π₀)`；`R̂el_A < TARGET + guard ⇒ shrink_K(factor)`；`β_op < β_min ⇒ K_MAX^rel = 1`；再沿 `π₀ → ToolGauge → LeanGauge → MODGAUGE` 下行。要求**单调**（同一 episode 内不得在未重新认证前再轻量化）与**可逆**（每步可一键恢复并出证）。

**定义 461（可靠性感知块长上限）** `K_MAX^rel(π,ι) = min(K_MAX(ι), K₀^rel)`，其中 `K₀^rel = max(1, ⌊c_rel·(β_op − β_min)⌋ + 1)`。裕度越薄、块越短；`β_op → β_min` 时 `K₀^rel → 1`。这把第 3 轮「语义-时间放大」进一步用可靠性裕度夹住。

**定义 462（六段式修复解释证书 RepairCert″）** `RepairCert″(s) = (ι, π, C, ChunkCert, LiteCert, receipts, claims)`。人类审计可沿「指令 → 轻量化决策 → 块 → 逐步回执 → 轻量化证书 → 主张」六级证据链复现一次修复，并检查「省掉的质量」与「保留的可靠度」是否在同一账本上闭合。

    def compose(self, rels, rbd):
        if rbd == "series":
            return prod(rels)                                   # 串联：可靠性相乘
        return binomial_tail(rels, k=rbd.k)                     # 并联 / k-of-n：二项尾

    def charge(self, stage, cost):
        if cost > self.alloc[stage]:
            return REJECT                                       # 越额 ⇒ 退化，不许借用
        self.alloc[stage] -= cost
        return OK

# IP-329 SSU：应力—强度裕度与运行点（FORM）
class StressStrength:
    def beta(self, capacity, demand):
        return (capacity.mu - demand.mu) / sqrt(capacity.var + demand.var)

    def operating_point(self, beta_target, beta_hat, se, gamma, drift):
        return beta_target + z(1 - gamma) * se + drift         # 运行点，绝不贴边

    def admit(self, beta_op, beta_min):
        return beta_op >= beta_min

# IP-330 RBDO-Pruner：可靠性约束下最小化整备质量
class RBDOPruner:
    def prune(self, pi0, reliability, anchor, cuts):
        pi = pi0
        while True:
            cand = [u for u in pi.units
                    if u not in anchor.A
                    and not touches_safety_cut(u, cuts)]        # 锚与安全割不可剪
            if not cand:
                break
            u = min(cand, key=specific_reliability)             # ρ_i 最小者先剪
            trial = pi.without(u)
            if reliability.lower_bound(trial, anchor.A) >= TARGET:
                pi = trial                                      # 只在约束内前进
            else:
                break                                           # 触约束即停（保留裕度）
        return pi

# IP-331 CA：认证锚（独立、不可剪枝的证据通道，破自指）
class CertificationAnchor:
    def certify(self, pi, ledger):
        rel_hat = ledger.estimate(self.A, pi)                   # 只用锚证据
        if self.unavailable() or rel_hat.ci_width > CI_MAX:
            return LiteCert.fail("anchor")                      # 退化：放弃轻量化
        return LiteCert(pi=pi, rel=rel_hat, anchor_ids=self.ids,
                        beta_op=self.ssu.operating_point(...))

# IP-332 RARE：稀有事件可靠度估计（子集模拟，带 CI）
class RARE:
    def estimate(self, model, alpha, budget):
        levels, samples = subset_simulation(model, p0=P0, budget=budget)
        L = ceil(log(1 - alpha) / log(P0))                       # 条件层数
        return ReliabilityEstimate(levels=levels, samples=samples, ci=...)

# IP-333 DG-Ladder：可靠性触发退化梯（单调、可逆、可审计）
def degrade_ladder(M, lite):
    if lite is None or lite.rel.ci_width > CI_MAX or not M.anchor.healthy():
        return restore_full_bundle(M)                           # 一键回到 π0 = InstructGauge
    if lite.rel.point < TARGET + GUARD:
        return tighten_k(M, factor=REL_K_SHRINK)                # 先缩 K（接第 3 轮）
    if lite.beta_op < BETA_MIN:
        return force_per_step(M)                                # K=1 ⇒ ToolGauge
    return keep(M)

# IP-334 ReliaGauge-8C 闭环：I → R → H → C → E → C → V → U
def reliagauge_8c(M, s, ell):
    iota = M.nlib.ground(ell, M.scene, M.ontology) or M.default_iota   # I
    alloc = M.rledger.budget(M.target, M.stages, M.rbd)                # R：可靠性预算
    if not alloc.ok(M.stages):
        return stub_and_red(s, "rel_budget")                           # 预算不足先退化
    H = M.lbox.hypothesize(s, M.dbox.R[s], iota)                       # H
    C = M.iac.plan_chunk(iota, H, M.tools, M.budget_left(s),
                         M.drift_bound(s), M.rel_chunk_cap(alloc))     # C（K_MAX^rel）
    if not M.rledger.charge("probe", cost(C)):
        return stub_and_red(s, "rel_charge")
    pi = M.pruner.prune(M.bundle, M.reliability, M.anchor, M.cuts)     # 轻量化决策（RBDO）
    cert = M.cvc.commit(C.with_bundle(pi), M.env, iota)                # E + C：块证书
    if not M.ssu.admit(cert.beta_op, BETA_MIN):                        # V：可靠性复核
        return restore_full_bundle(M)
    lite = M.anchor.certify(pi, M.rledger)                             # 认证分离
    if lite is None:
        return restore_full_bundle(M)
    M.mreg.hot_replace_at_quiescence(M.dpe, lite.contract, cert.boundary)
    bind_claims(cert, iota, cert.receipts)                             # 纯投影
    return degrade_ladder(M, lite)                                     # U

# IP-335 主闭环（50Hz 路径不变；轻量化只降算力，不增主路径负担）
def ReliaGauge_round(M, obs, audio, tac, depth, det, ell=None):
    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight:
            M.inflight.add(s)
            submit_async(reliagauge_8c, M, s, ell)                     # RARE/认证均异步
    return MODGAUGE_round(M, obs, audio, tac, depth, det)

## 4. 推导

**引理 59（可靠性组合与预算守恒）** 串联 RBD 下 `R_total = Π R_i`，故 `log R_total = Σ log R_i`。若轻量化把第 i 阶段改为 `R_i'`，则 `R_total'/R_total = R_i'/R_i`：一阶段可消耗的可靠度恰是其对数配额份额。非独立情形用并集界 `R_total ≥ 1 − Σ(1−R_i)`，账本取其保守值。推论：账本拒绝静默借用后，端到端可靠度不会因局部「各自达标」而跌破目标。
*证明骨架*：乘积取对数即加法；并集界由 `P(∩ A_i) ≥ 1−Σ P(A_i^c)`。配额约束 `cost_i ≤ a_i` 归纳到 `log R_total ≥ Σ log a_i ≥ log(1−α)`。

**引理 60（应力—强度单调性与质量—可靠度交换率）** `β = (μ_C−μ_D)/√(σ_C²+σ_D²)` 对 `μ_C` 严格增、对 `μ_D` 与 `σ_C` 严格减。轻量化压低 `μ_C`、抬高 `σ_C`，故 `β` 下降；局部交换率 `dβ/dL = (∂β/∂μ_C)(dμ_C/dL) + (∂β/∂σ_C)(dσ_C/dL) < 0`。RBDO 的 KKT 条件 `∇L = λ∇(β−β_op)` 说明最优解处所有未剪单元的边际可靠度成本相等——这正是「按 `ρ_i` 排序」的连续版本，给出 E458/E460 的可检验预测。
*证明骨架*：对四个偏导直接求导并判号；KKT 给出内点处乘子相等，离散化即阈值序。

**引理 61（剪枝序最优性）** 在独立性与可加质量下，拉格朗日函数 `L + λ(β_op − β)` 的松弛问题按 `ρ_i` 升序剪枝即按 KKT 乘子排序，松弛最优。整数化并加入 k 割约束后，可行集构成一个拟阵（matroid）；用可行性 oracle 的贪心在字典序目标（先最大化省去质量、再最大化可靠度）下最优。故 RBDO-Pruner 的「升序剪枝 + 触约束即停」不是启发式，而是有最优性保证的。
*证明骨架*：交换论证（exchange argument）+ 拟阵贪心定理；k 割约束是独立的拟阵下界约束。

**引理 62（k-of-n 冗余与安全最小割）** 独立路径的 k-of-n 可靠度为 `Σ_{j=k}^n C(n,j) R^j (1−R)^{n−j}`，随 `k` 严格递减。若剪到 `k < k_safe(c)`，则存在一个「剩余路径全失效而真值错误」的赋值，使该主张在**最坏情形下不可验证**（`R_cov(c) = 0`）。因此最多可剪 `n − k_safe` 条冗余路径；安全/不可逆主张强制 `k_safe ≥ 2`，与第 3 轮「不可逆动作独立回执交叉验证」一致。
*证明骨架*：二项尾单调性；构造使剩余 `k−1` 条路径同时失效的对抗赋值，盾与主张无法区分真伪。

**引理 63（元可靠性与运行点裕度）** 设 `β̂ ∼ N(β, se²)`。若在 `β_target` 处运行，则 `P(β < β_target) = Φ(−(β̂−β_target)/se)`，在贴边 `β̂ = β_target` 时趋于 `1/2`——**贴边设计约有一半概率违约**。取 `β_op = β_target + z_{1−γ}se + Δβ_drift` 后，`P(违约) ≤ γ`。推论：可靠性估计本身必须留裕度，否则「高可靠」只是估计噪声。
*证明骨架*：正态尾概率估计；漂移项由引理 60 的单调性折算为 `β` 的额外下移，单调并入同一尾界。

**引理 64（认证分离破除自指）** 若可靠度估计与剪枝共享同一 bundle，则容量误差 `e` 同时抬高 `μ_C` 与 `R̂el`，存在 `π` 使真实 `R(π) < 1−α` 而 `R̂el(π) ≥ 1−α`（自指偏差为正）。若锚 `A` 与剪枝决策 d-分离且 `A` 不被剪，则 `R̂el_A(π)` 仅通过 `π` 的**真实效应**依赖 `π`，不通过估计器自胀；条件独立 `(R̂el_A ⊥ prune | R_true)` 成立，偏差消除且 CI 有效。
*证明骨架*：反例构造给出共享证据时的正偏差；分离时用条件独立与保守下界，把 `R̂el_A` 校准回真实 `R`。这使 E462/E471 能主动证伪「认证锚可省」。

**引理 65（稀有事件估计的样本复杂度）** 朴素 MC 达到相对误差需 `n = O((1/α)·log(1/δ))`；`α = 1e−4` 时不可行。子集模拟以 `p₀` 为层概率需 `L_lvl = ⌈log(1−α)/log p₀⌉` 层，成本 `O(L_lvl·n_{p₀}·d)`，方差随层数近似可加、显著低于朴素 MC。故高可靠目标（`1−α > 0.999`）必须用 RARE，否则账本里的 `R̂el` 本身不可信。
*证明骨架*：相对方差下界；子集模拟的条件分解把稀有概率写成 `p₀^{L_lvl}` 的乘积，逐层估计的方差可加。

**引理 66（可靠性感知块长与退化等价）** `K_MAX^rel = min(K_MAX(ι), K₀^rel)`，`K₀^rel` 对 `β_op` 单调不减，且 `β_op → β_min` 时 `K₀^rel → 1`。故裕度耗尽时块长被压到 1，行为逐指令等同第 3 轮 `K=1` 退化路径（= ToolGauge 逐步）；`β_op` 充足时才允许分块摊销。可靠性约束因此永远不会被分块收益「买断」。
*证明骨架*：定义 461 的单调性；对 K 归纳，`K=1` 时 8C 与 7C 的 E/C/V 步逐指令相同。

**引理 67（轻量化不破坏安全且时序非降）** RBDO 的可行域包含 `π ⊇ A`、`k ≥ k_safe`、shield/barrier 不变式，故 `π*` 上第 1–3 轮全部安全不变量保持（轻量化只删「低应力」证据，不碰「传力路径」）。又 `L(π*) ≤ L(π₀)`，计算/能耗非增；RARE 与认证异步，不进入 50Hz 路径，故时序裕度非降。推论：在约束内，轻量化是纯「降成本、保安全」的动作。
*证明骨架*：可行域交；成本函数单调；异步任务不影响主循环关键路径，沿用第 2 轮引理 50。

## 8. 本轮最大风险

**一句话**：`RBDO-Pruner` 与 `CA` 在接口处形成**自指可靠性**——轻量化会同步削掉「用来证明轻量化可靠」的证据通道，一旦认证锚被污染、被间接剪枝或稀有事件样本不足，`R̂el_A` 就会和被评估对象一起变差，系统会同时变得**又便宜又自信地错**；缓解只能依赖结构（认证锚 d-分离且不可剪、`β_op` 运行点裕度、`k_safe` 安全割、稀有事件估计的 CI、DG-Ladder 一键恢复 `π₀`），并以 E461/E462/E463/E471 主动证伪。
