# 第 1 轮（新灵感循环第 1 轮；本轮灵感：「故障诊断」×「数据配比」；技术基线延续 v15）

> **基线**：第 13 轮 MetricVoiceGauge-NCD-HUTDH v15（技能扩散版：SCD/DSD/DCA/EDC，定义 607–626；引理 125–130；实验 E661–E670）。
> **本轮纪律**：**诊断只给集合不给标签 + 配比只买分辨率不放宽证书 + 故障—数据双轴单调退化 + 失效即退回 v15**。不推倒 v15：v15 的 SCD/DSD/DCA/EDC、v13 的 AIO/CPD/DGC/DDL/RTCR、v12 的 USG/TGC/BAA/GAGP/UC、v11 的 HAS/HCC/HATD/HDT、v10 的 NGE/DSL/CC/CWM/CAE/NCP、v9 的 AC/MW/ID、v8 的 DA/SPR/Cal 与九不变式全部保留。五个新组件——FSC（故障集证书，含故障条件授权）、MCC（配比证书，含加权共形与有效样本量）、MRA（配比分配器）、JDL（故障—数据联合退化阶梯）、CCA（证书叠加审计）——一律以**收缩/中立元**接入：只取交、只收缩授权、只增加约束；失效即严格退回 v15（引理 137），再沿 v15→v14→…→v6 退化链退回。本轮只做三件事：把"故障诊断"从点标签改写为**集合值、以包含性而非准确性换取安全**；把"数据配比"从平均精度改写为**购买故障可分辨性与证书支撑**；把二者合成**诊断分辨率—授权宽度—配比预算**的显式交换。

## 0. 直觉与动机

**灵感 1（故障诊断 → 集合值诊断与故障条件授权）**
直觉：v15 的证书默认"系统健康、前提成立"。故障诊断的通常用法是"检测到故障→停机"，这把一个信息问题误当成一个停机问题：真正危险的不是"知道出故障"，而是"以为没有故障"或"把 A 故障误判成 B 故障后按 B 的证书放行"。人做故障诊断时也不是先给唯一标签再决策，而是先排除不可能、保留一组"还不能排除的故障"，在最坏的那个上做保守决定。核心创新：**故障集证书（Fault-Set Certificate, FSC）**。诊断器不输出点标签 `f̂`，而输出一个共形故障集 `F_δ(x)`，满足 `P(f_true∈F_δ(X))≥1−δ`；授权集取所有未排除故障的交 `Acc_δ(x)=⋂_{f∈F_δ(x)} Acc_f`。关键反直觉点：**安全不要求诊断正确，只要求真实故障被包含**——诊断错成别的故障没关系，只要真实故障仍在集合里，交集就仍然更保守；真正的失败模态是"集合漏掉了真实故障"。

**灵感 2（数据配比 → 用配比购买分辨率与支撑，而不是平均精度）**
直觉：v15 的 DCA 把校准集当铁板一块，用 `ρ_cov` 一个标量概括覆盖率。但机器人数据天然分层：仿真/遥操作/真机、健康/各类故障、常见/长尾任务。配比决定了三件事：每个故障层的校准样本量、诊断器能否分开相邻故障、以及目标分布与混合分布之间的密度比。平均精度最优的配比往往把稀有故障稀释到不可校准——恰恰是安全最需要的地方。核心创新：**配比证书（Mixing Certificate, MCC）+ 配比分配器（Mixing-Ratio Allocator, MRA）**。MCC 在已知密度比上界 `R_max` 下用加权共形给出目标分布的分层覆盖，并报告分层有效样本量 `n_f(w)`；MRA 在样本预算与密度比约束下，最大化"可证授权量"而不是验证集精度。关键反直觉点：**配比不是训练超参，而是一种证书资源**；它可以买来"故障可分辨"与"边界被支撑"，但每倾斜一层都会付出分布偏移（密度比/有效样本量）的代价。

**灵感 3（故障诊断 × 数据配比 → 诊断分辨率换取授权宽度）**
直觉：把两个灵感接起来会看到一个干净的换算关系：诊断不确定时，授权集是多个故障证书的交；要把授权"要回来"，只能靠数据把故障集缩小。而缩小故障集所需样本随"难分辨故障对"的 KL 散度反比增长（Le Cam）。于是"多采一条真机故障数据"与"多放行一个动作"之间存在可计算的边际兑换率。核心创新：把二者合成**故障—数据联合退化阶梯（Joint Degradation Ladder, JDL）+ 证书叠加审计（Certificate Composition Auditor, CCA）**：JDL 沿"故障集大小 × 支撑覆盖"两轴排成嵌套档位，任一轴变差只能向更保守档移动；CCA 用联合风险预算 `δ_sys=δ_v15+δ_diag+δ_mix` 检查诊断误差、配比误差与 v15 残差是否重复计错或同向叠加，并在联合分数可用时用单一共形分数替代 union bound。

**三者如何统一**
统一为 **v15 授权层之上的"故障—数据层"**：v15 回答"健康模型下哪些动作被授权"（`Exec_v15`），v16 回答"在只排除到故障集 `F_δ`、且只有配比 `w` 支撑的校准下，哪些动作仍被授权、还要多少数据才能把授权要回来"（`Exec_v16`）。FSC 把点诊断改为集合值并给出 `Acc_δ`；MCC 把配比翻译成分层共形覆盖与有效样本量；MRA 在预算下选 `w`；JDL 把两轴变差合成单调退化；CCA 守住风险预算不被重复花掉。共享状态 `ζ_fd=(F_δ, Acc_δ, δ_sys, δ_diag, δ_mix, w, n_f, ESS, R_max, rung, drift, mode)`。**FSC 回答"还不能排除哪些故障"，MCC 回答"这些故障的证书有没有被数据撑住"，MRA 回答"下一批数据该按什么配比买哪一段授权"，JDL/CCA 回答"这一帧能站在哪一档、风险预算够不够"**。

## 1. 研究问题（轮次升级版）

- **Q1（集合值诊断的可证语义）**：如何构造 `F_δ` 才使任意时刻查询、任意停止规则下都保持覆盖？故障是复合、渐变、非独立同分布时，共形交换性在哪里失效？条件覆盖（给定 `|F_δ|`、给定场景族）与边际覆盖的差距如何界定？未建模故障如何强制映射到空授权类而不被"相似故障"顶替？
- **Q2（配比证书的可证边界）**：分层加权共形在目标/混合密度比未知、有界、被违反时分别给出什么保证？分层有效样本量、密度比上界与覆盖半径之间的三角关系是什么？配比优化如何在"买稀有故障支撑"与"不破坏健康层交换性"之间取舍？优化后的 `w` 本身是不是分布外选择，会不会使证书失效？
- **Q3（诊断—数据兑换与主动探测）**：用 KL/Le Cam 界能否给出"分开一对故障所需样本 ~ 1/D_KL"的可操作估计？预算有限时，应继续买诊断分辨率（缩小 `F_δ`）还是买故障条件证书边界（加宽 `Acc_f`）？主动诊断的探测动作本身如何在证书保护下执行，何时"不探测"比"探测"更安全？
- **Q4（与 v15 的兼容与活性）**：`Acc_δ` 是否会与 SCD/DSD/DCA/EDC 的收缩叠加而清空可行集？`δ_diag`/`δ_mix` 与 v15 残差是否同向相关、能否用联合分数避免重复花费？塌缩到第 0 档是否导致频繁 `a_ask`？新增模块能否守住 50Hz/p99≤22ms，并严格退回 v15？

## 2. 设计原则（在 P25–P27 基础上新增 P28–P31）

**P28 诊断只给集合、以包含换安全律（Diagnose as a Set, Safety by Containment）**
诊断输出必须是带覆盖保证的故障集，不得以点标签直接放行；授权只能取未排除故障证书的交集。未建模故障、标签缺失故障、无法校准故障一律映射到空授权类（仅回退/`a_ask`），禁止用"相似故障"顶替。诊断准确率只能作为辅助指标，安全声明的唯一依据是集合覆盖。

**P29 配比只买分辨率与支撑、不放宽证书律（Mixing Buys Resolution, Never Relaxes）**
配比只能增加分层校准样本、缩小故障集或补偿已知密度比；不得替代 v15 阈值，不得用平均精度提升抵消单层覆盖不足。任何配比方案必须携带 `R_max`、分层 `n_f`、`ESS` 与目标支撑假设；一旦实际目标落在密度比包络之外，MCC 立即失效并触发降档。

**P30 故障—数据双轴单调退化律（Monotone Two-Axis Degradation）**
JDL 的档位由"故障集大小/歧义度"与"支撑覆盖/密度比"两轴共同索引，且档间授权单调嵌套。任一轴变差只能沿阶梯向更保守方向移动；诊断失效、密度比越界、故障标签缺失或联合风险预算耗尽时必须安全塌缩到第 0 档并触发重校准，禁止用旧配比"赌一把"。

**P31 风险预算不重复花费律（No Double-Spent Risk）**
`δ_diag`、`δ_mix` 与 v15 残差必须显式合成；能构造联合共形分数时必须用联合分数，只有无法联合时才允许 union bound，并记录其保守损失。禁止在不同模块里对同一个失败事件重复计入预算来"显得安全"，也禁止把相关性当作独立来相乘。

## 3. 与基线的接口（如何退化）

- FSC 失效 ⇒ `F_δ≡F`（所有故障），`Acc_δ=⋂_{f∈F} Acc_f`；若故障证书不全则仅回退，**等价 v15 最保守路径**；
- MCC 失效 ⇒ `w=w_v15`、`R_max=1`、`n_f` 用 v15 DCA 的 `ρ_cov`，**等价 v15 的 DCA/EDC 证书路径**；
- MRA 失效 ⇒ 固定 v15 配比，不做优化，**等价"v15 证书 + 静态配比"**；
- JDL 失效 ⇒ 单档，所有故障集与配比直接取交，无阶梯，**等价"v15 + FSC + MCC 的硬合取"**；
- CCA 失效 ⇒ 退回 union bound 并显式预留保守余量，**安全但更紧**；
- 全失效 ⇒ v15，再沿 v15→v14→…→v6 退化链退回；
- **安全继承**：FSC 只取交、MCC 只提供覆盖与支撑、MRA 只选配比、JDL 只排序、CCA 只记账，均不能新增授权或放宽任何 v15 阈值；`Exec_v16⊆Exec_v15`。

## 4. 预期贡献

1. **集合值故障诊断证书**：把诊断从"点标签"改写为"带覆盖的故障集"，并证明安全只需真实故障被包含而非诊断准确，给出诊断风险—活动性的单调前沿；
2. **配比证书**：把数据配比从训练超参改写为可证的证书资源，给出分层加权共形、有效样本量与密度比的显式三角界，并以"分辨率平方 × 有效样本量"不变量刻画稀有故障的不可约代价；
3. **诊断—数据兑换律**：用 KL/Le Cam 给出"买分辨率 vs 买故障边界 vs 买样本"的边际兑换，把"多放行"翻译成"多采集哪一层故障数据"，给出可操作的主动采样目标；
4. **双轴单调退化与联合风险审计**：`δ_sys` 预算、联合共形优先、退化链严格；E671–E680 覆盖故障集覆盖、包含安全、配比有效性、兑换率、退化与端到端。

## 5. 本轮最大风险

**一句话**：整套方案的前提是"真实故障属于预先枚举的故障标签空间且标签正确"，而真实故障常是复合、渐变、未建模的；共形故障集可以在名义覆盖率上完全合格，却因为真实故障根本不在标签空间里而"漏掉"它——于是诊断说集合很小、配比说支撑很好、审计说预算没超，系统却在每一个**已命名**故障下都持证、在**实际**故障下无证的条件下执行了动作，即**集合覆盖的、数据支撑的、却漏掉真实故障的错误安全决定**。

## 1. 关键算法骨架

```python
# IP-402 Fault-Set Certifier：集合值诊断 + 故障条件授权
class FaultSetCertifier:
    def __init__(self, fault_scores, fault_certs, alpha_diag=0.05):
        self.scores = fault_scores       # s(x,f) 非一致性分数
        self.certs = fault_certs         # {f: C_f}
        self.alpha = alpha_diag
        self.qhat = None                 # 校准得到的共形阈值

    def calibrate(self, cal_pairs):
        # cal_pairs: [(x_i, f_i)]，要求在可交换性成立的分层内
        s = [self.scores(x, f) for x, f in cal_pairs]
        n = len(s)
        self.qhat = quantile(s, ceil((1 - self.alpha) * (n + 1)) / n)

    def fault_set(self, x, known_faults):
        # 集合值输出：保留所有分数不超过阈值的故障
        return {f for f in known_faults if self.scores(x, f) <= self.qhat}

    def authorized(self, x, known_faults):
        Fd = self.fault_set(x, known_faults)
        # 未建模/未校准故障一律映射为空授权
        acc = None
        for f in Fd:
            Cf = self.certs.get(f)
            if Cf is None:
                return EMPTY_SET, Fd
            acc = Cf.Acc if acc is None else acc.intersect(Cf.Acc)
        if acc is None:                  # F_δ 为空：要求至少保留空集语义
            return EMPTY_SET, Fd
        return acc, Fd


# IP-403 Mixing Certificate：分层加权共形与有效样本量
class MixingCertificate:
    def __init__(self, strata, target_prevalence, R_max):
        self.strata = strata             # {f: [(x, score)]}
        self.p = target_prevalence       # {f: p_f}
        self.R = R_max
        self.ess = {}

    def _weights(self, f):
        # 目标对混合的密度比，裁剪至 [1/R_max, R_max]
        return [min(self.R, max(1.0 / self.R, r)) for r in self.strata[f].ratios]

    def build(self, w):
        q = self._mixture_mass(w)        # q_f = Σ_{j∈f} w_j
        cert = {}
        total_w, total_w2 = 0.0, 0.0
        for f in self.strata:
            wts = self._weights(f)
            total_w += sum(wts)
            total_w2 += sum(t * t for t in wts)
            # 分层共形阈值
            cert[f] = weighted_quantile(
                scores=[s for _, s in self.strata[f]],
                weights=wts, alpha=self.alpha)
            self.ess[f] = (sum(wts) ** 2) / max(total_w2, 1e-12)
        self.ess_global = (total_w ** 2) / max(total_w2, 1e-12)
        return cert

    def margin(self, f, a, x, theory_margin):
        # 余量 = 理论余量 − 共形半径 − 标签/审计间隙
        return theory_margin - self.cert[f] - self.label_gap(f)

    def envelope_ok(self, r_observed):
        return all(1.0 / self.R <= r <= self.R for r in r_observed)


# IP-404 Mixing-Ratio Allocator：预算下最大化可证授权量
class MixingRatioAllocator:
    def __init__(self, mcc, budget, R_max, min_cov):
        self.mcc = mcc
        self.budget = budget             # 样本/采集预算
        self.R = R_max
        self.min_cov = min_cov           # 每层最低覆盖

    def authorize_value(self, w, x_batch):
        self.mcc.build(w)
        Fd = self.mcc.fault_set(x_batch)     # 复用诊断器
        acc = intersection_over(Fd, self.mcc.cert_acc)
        return expected_value(acc, x_batch)

    def solve(self, iters=50):
        # 约束: p_f/R_max ≤ q_f(w) ≤ R_max·p_f, Σw=1, 分层覆盖≥min_cov
        w = uniform_init(len(self.mcc.strata))
        for _ in range(iters):
            g = finite_difference(self.authorize_value, w)
            w = project_to_mixing_simplex(w + lr * g)
            w = enforce_two_sided_envelope(w, self.mcc.p, self.R)
        return w, self.mcc.build(w)


# IP-405 Joint Degradation Ladder：故障集 × 支撑覆盖双轴退化
class JointDegradationLadder:
    RUNGS = [  # (a_F 允许的最大故障集大小, a_ESS 允许的最小 ESS/R_max)
        (1, 1.0), (2, 0.8), (4, 0.6), (8, 0.4), (float("inf"), 0.0),
    ]

    def select(self, Fd, ess_global, R_max, drift):
        if drift.fired():
            return 0                     # 第 0 档：最保守
        for i, (aF, aE) in enumerate(self.RUNGS):
            if len(Fd) <= aF and ess_global / R_max >= aE:
                return i
        return len(self.RUNGS) - 1

    def collapse(self, rung, reason):
        # 只能向更保守方向移动，禁止跨档回跳
        return min(rung, self.RUNGS.index(reason)) if reason in self.RUNGS else 0


# IP-406 Composition Auditor：风险预算记账，禁止重复花费
class CompositionAuditor:
    def __init__(self, delta_v15, delta_diag, delta_mix):
        self.dv, self.dd, self.dm = delta_v15, delta_diag, delta_mix

    def union_bound(self):
        return self.dv + self.dd + self.dm

    def joint_available(self, joint_score):
        return joint_score is not None

    def choose(self, joint_score=None):
        if self.joint_available(joint_score):
            # 单一联合分数给出更紧的 δ_joint，避免 union 的重复保守
            return joint_score.calibrate(alpha=self.dv + self.dd + self.dm), "joint"
        return self.union_bound(), "union"

    def audit_double_count(self, events):
        # 同一失败事件不得在多个模块重复计入
        seen = set()
        for e in events:
            if e.id in seen:
                return False
            seen.add(e.id)
        return True


# IP-407 Diagnostic Probe Guard：主动诊断的证书门控
class DiagnosticProbeGuard:
    def __init__(self, fsc, dpg_risk=0.01):
        self.fsc = fsc
        self.risk = dpg_risk

    def probe_allowed(self, u, x, acc_delta, info_gain):
        # 探测动作本身必须已被当前故障集证书授权
        if u not in acc_delta:
            return False
        # 信息增益必须超过风险的保守估计
        return info_gain(u, x) > self.risk * probe_risk(u, x)


# 主闭环集成：MetricVoiceGauge-NCD-HUTDH-v16（故障—数据版）
def metricvoicegauge_round_16_fault_data(M, s, obs, fault_pool=None, dataset=None, ctx=None):
    # ---- v15 主路径原样保留（SCD/DSD/DCA/EDC 与 v14 守卫）----
    results = middleware.run_cycle(runners={...}, ctx=ctx)

    # ---- FSC：集合值诊断 ----
    fsc = FaultSetCertifier(fault_pool.scores, fault_pool.certs, ctx.alpha_diag)
    Fd = fsc.fault_set(obs, fault_pool.known_faults)
    acc_delta, Fd = fsc.authorized(obs, fault_pool.known_faults)

    # ---- MCC：配比证书 ----
    mcc = MixingCertificate(dataset.strata, dataset.p, ctx.R_max)
    mcc.build(ctx.w_current)
    if not mcc.envelope_ok(dataset.observed_ratios):
        jdl = 0                       # 密度比越界，强制第 0 档
    else:
        jdl = JointDegradationLadder().select(Fd, mcc.ess_global, ctx.R_max,
                                              drift_detector)

    # ---- CCA：风险预算审计 ----
    auditor = CompositionAuditor(ctx.delta_v15, ctx.alpha_diag, ctx.alpha_mix)
    delta_sys, mode = auditor.choose(ctx.joint_score)
    if not auditor.audit_double_count(ctx.failure_events):
        jdl = 0                       # 记账冲突：直接降档

    # ---- DPG：主动探测（严格在 Acc_δ 内）----
    if jdl > 0 and ctx.probe_candidate is not None:
        u = ctx.probe_candidate
        if DiagnosticProbeGuard(fsc, ctx.probe_risk).probe_allowed(
                u, obs, acc_delta, ctx.info_gain):
            execute(u)                # 探测本身持证

    # ---- 选择并执行已认证动作 ----
    a = select_action(acc_delta, obs)
    if a is None or jdl == len(JointDegradationLadder.RUNGS) - 1:
        execute(fallback(ctx))        # 空集/最低档：认证回退
    else:
        execute(a)

    # ---- 异步：MRA 重新配比、FDL 记账、FTC 闭包 ----
    if cycle_idx % T_mix == 0:
        w_new, _ = MixingRatioAllocator(mcc, ctx.budget, ctx.R_max,
                                        ctx.min_cov).solve()
        ctx.w_current = w_new
        FaultDataLedger.record(mcc, dataset, ctx.authorization_delta)
    if cycle_idx % T_taxonomy == 0:
        FaultTaxonomyClosure.audit(fault_pool, dataset)

    # ---- v15 继承路径 ----
    C, spatial_cert, claims, metrics, rewards = M.inherited_v15_path(ctx)
    return C, spatial_cert, claims, metrics, rewards
```

## 2. 推导

**引理 131（故障集证书的包含式安全）** 设 `P(f_true∈F_δ(X))≥1−δ_diag`，且对每个 `f∈F`，`Acc_f` 在故障 `f` 下是有效证书。令 `Acc_δ(x)=⋂_{f∈F_δ(x)}Acc_f`，则任何在该事件上执行的 `a∈Acc_δ(x)` 在真实故障下持证；系统失败概率不超过 `δ_diag + δ_v15`。
证明：在覆盖事件 `{f_true∈F_δ(X)}` 上，`Acc_δ(X)⊆Acc_{f_true}`，故 `a∈Acc_{f_true}` 由 `C_{f_true}` 的有效性即得安全；剩余失败只来自覆盖失败与 v15 残差。∎
推论：**诊断的准确性不是安全变量，覆盖性是**；把 `f̂` 换成集合 `F_δ` 不会减少安全，只会把"误分类"替换成"集合变大"。

**引理 132（诊断风险—活动性单调前沿）** 采用同一非一致性分数、随 `δ` 单调的阈值构造共形集，则 `δ_1<δ_2 ⇒ F_{δ_1}(x)⊇F_{δ_2}(x)` 逐点成立，从而 `Acc_{δ_1}(x)⊆Acc_{δ_2}(x)`，可证授权量 `V(δ)` 关于 `δ` 单调不降，而覆盖 `1−δ` 单调不增。
证明：阈值随 `1−δ` 单调上升，故低风险（小 `δ`）保留更多故障；交集对集合包含单调。∎
推论：**"更可信"与"更放行"是同一个旋钮的两端**；不存在既提高覆盖又扩大授权的免费午餐，除非引入新数据（引理 135）。

**引理 133（配比下的加权共形有效性与 ESS 界）** 设校准来自 `P_w`，目标 `P_target` 满足 `r=dP_target/dP_w∈[1/R_max,R_max]`。以 `r` 为权重的加权共形给出目标覆盖 `≥1−α`；若 `r` 只能估到误差 `ε_r`，覆盖降为 `≥1−α−ε_r·C`。且全局有效样本量满足
```
ESS(w) = (Σ_i r_i)^2 / Σ_i r_i^2 ≥ n / R_max .
```
证明：加权共形在加权可交换性下成立；由 `r_i≤R_max` 得 `Σ r_i^2 ≤ R_max Σ r_i`，代入 ESS 定义即得下界。∎
推论：**密度比上界 `R_max` 直接把样本量打折**；`R_max=4` 时等效样本最多只剩四分之一。

**引理 134（分辨率—有效样本量不变量与配比三难）** 设配比满足双侧包络 `p_f/R_max ≤ q_f(w) ≤ R_max·p_f`。则对每个故障层 `f`：
```
n_f(w)=n·q_f(w) ≤ n·R_max·p_f ,
ε_f(w) ≳ sqrt(R_max·log(1/α) / n_f(w)) ≥ sqrt(log(1/α)/(n·p_f)) ,
ε_f(w)^2 · ESS(w) ≥ log(1/α) / (p_f · R_max) .
```
证明：共形半径由层内有效样本量给出 `ε_f^2≈R_max log(1/α)/n_f`；由 `q_f≤R_max p_f` 得 `n_f≤n R_max p_f`，代入得第二条；再乘引理 133 的 `ESS≥n/R_max` 得第三条。∎
推论：**稀有故障（`p_f` 小）或宽密度比（`R_max` 大）使分辨率在信息论意义上昂贵**；无论怎么调配比，`ε_f^2·ESS` 都有一个由 `p_f,R_max` 决定的不可约下界。这就是"买稀有故障支撑"的真实价格。

**引理 135（故障可分辨性的 Le Cam 兑换律）** 设故障对 `(f,f')` 的可分辨性 `D_{f,f'}=D_KL(P_f‖P_{f'})`。任何区分二者的检验若错误率 `≤η`，需样本
```
n_{f,f'} ≥ Ω(log(1/η)/D_{f,f'}) .
```
若可用样本低于该量，则任何 sound 的 `F_δ` 必须在一个正测度集合上同时包含 `f` 与 `f'`，于是授权至多退化为 `Acc_f∩Acc_{f'}`。分开该对所能"买回"的授权宽度为 `|Acc_f\Acc_{f'}|`（或对称差的一半），其边际兑换率与 `D_{f,f'}` 成正比。
证明：Le Cam/Chernoff 下界给出检验的样本复杂度；当样本不足时，两个故障在统计上不可分的集合上不可区分，保守证书只能取交。∎
推论：**诊断数据买的是"授权宽度"，不是"诊断准确率"**；应优先采集 `D_{f,f'}` 小且 `|Acc_f\Acc_{f'}|` 大的故障对，即"难分辨但授权差异大"对。

**引理 136（联合证书的合成与不重复花费）** 令 `E_v15` 为 v15 失效事件，`E_diag={f_true∉F_δ}`，`E_mix={r∉[1/R_max,R_max] 或目标落在校准支撑外}`。则
```
P(E_total) ≤ P(E_v15)+P(E_diag)+P(E_mix) .
```
若存在覆盖 `(故障,授权区域)` 对的联合非一致性分数，则单一共形阈值给出 `P(E_diag∪E_mix)≤δ_joint`，比求和更紧。由于稀有故障同时导致诊断欠覆盖与配比欠支撑，`E_diag` 与 `E_mix` 通常正相关，union bound 合法但保守。
证明：并集界；联合分数情形由联合共形的边际覆盖直接得到。∎
推论：**CCA 必须优先尝试联合分数**，否则会在最需要精度的地方（稀有故障）付出双倍保守。

**引理 137（严格退化到 v15）** 按 §3 的接口逐项关闭：FSC 关闭使 `F_δ≡F`，授权取全故障交集（最保守）；MCC 关闭使 `w=w_v15,R_max=1`，加权共形退化为 v15 的 DCA 覆盖；MRA 关闭固定静态配比；JDL 关闭后单档硬合取；CCA 关闭退回 union bound。全关闭时 `F_δ≡F` 且 `w=w_v15`，`Exec_v16=Exec_v15`。
证明：逐条代入定义，交集、权重与阈值均化为 v15 对应量。∎
推论：**v16 的每个收益都必须由至少一个显式开启的证书模块支付**；任何模块失效只会更保守，不会更冒险。

**引理 138（完美诊断上界与授权缺口的可分解性）** 定义 oracle 授权 `Acc_or=Acc_{f_true}`，则 `Acc_δ⊆Acc_or`，且
```
0 ≤ V(w) ≤ E|Acc_or| ,
E|Acc_or| − V(w) = [E|Acc_or| − E|Acc_δ|]  +  [E|Acc_δ| − V(w)]
                    \________ 歧义缺口 ________/   \______ 支撑/配比缺口 ______/
```
其中第一项由引理 135 的故障对数据按 `1/D_{f,f'}` 速率缩小，第二项由引理 134 的 `ε_f^2·ESS` 不变量约束。
证明：`F_δ` 含 `f_true` 时 `Acc_δ⊆Acc_{f_true}`，取期望得第一项；`V(w)` 是 `Acc_δ` 在配比支撑下的可执行价值，与 `E|Acc_δ|` 之差即支撑缺口。∎
推论：**MRA/FDL 的采样预算应按"缩歧义"与"补支撑"两条边的边际收益分配**，而不是按验证集精度分配。

**引理 139（主动探测的持证安全性）** 若 DPG 只允许满足 `u∈Acc_δ(x)` 且 `IG(u,x)>λ·risk(u,x)` 的探测，则探测动作本身不引入新的安全失败事件；探测只能在已有证书内改变信息状态，不能改变授权边界。
证明：`u∈Acc_δ` 已在引理 131 下持证；信息增益门控只影响是否探测，不影响授权集定义。∎
推论：**"不探测"永远是一个安全选项**；探测的收益必须用可证的信息增益来支付，而不是用"也许能更早发现故障"的希望。

## 6. 已知风险与失效模式

1. **故障标签空间不完备**：真实故障是复合、渐变、未建模的，`f_true∉F` 时任何共形集都不含它；名义覆盖合格而安全失效。缓解：FTC 强制 FMEA 闭包、未建模故障映射空授权、异常检测触发第 0 档、定期红队注入未知故障。
2. **复合故障破坏标签语义**：多故障同时发生使单标签共形失效。缓解：多标签/幂集共形、按故障子集建证书、组合爆炸时退回健康交集。
3. **非交换性与时间相关**：故障演化、闭环反馈使校准与部署不交换。缓解：块共形、e-process/时间一致版本、在线重校准与漂移触发。
4. **条件覆盖不足**：边际覆盖合格但给定 `|F_δ|` 或给定稀有场景时覆盖低。缓解：分层/条件共形、按 `|F_δ|` 分箱校准、Mondrian 共形。
5. **密度比被违反**：目标漂移到 `R_max` 包络外，加权共形失效。缓解：在线估计密度比、越界即 MCC 失效降档、扩大校准支撑。
6. **稀有故障样本复杂度爆炸**：`p_f` 极小使 `ε_f` 无法收敛，授权长期为空。缓解：接受空授权、定向采集、合成故障注入、显式报告不可证区域而非偷偷放宽。
7. **配比的分布外选择**：MRA 优化出的 `w` 可能落在训练分布外，导致证书失效。缓解：`w` 裁剪、交叉拟合、留出验证、把配比本身纳入元认证。
8. **风险预算重复花费/相关失效**：`E_diag`、`E_mix`、`E_v15` 正相关，union bound 保守但联合分数可能估计不稳。缓解：CCA 记账、联合分数优先、相关时显式加保守余量。
9. **诊断与配比共享盲点**：两者都用同一批数据/特征，稀有故障既没被诊断也没被校准。缓解：异构诊断器、独立校准集、教师影子抽查、故障对红队。
10. **主动探测激发故障**：探测动作可能加速故障演化或进入未建模状态。缓解：DPG 持证门控、信息增益门槛、探测预算、默认不探测。
11. **标签噪声与审计间隙**：FMEA 标签本身错误，`U_lab` 低估。缓解：标签审计、人工复核、把标签不确定性显式计入余量。
12. **退化链被绕过**：新模块通过共享状态间接放宽 v15 阈值。缓解：`Exec_v16⊆Exec_v15` 形式化检查、端口不相交审计、消融回归。

## 7. 本轮最大风险

**一句话**：整套方案的前提是"真实故障属于预先枚举的故障标签空间且标签正确"，而真实故障常是复合、渐变、未建模的；共形故障集可以在名义覆盖率上完全合格，却因为真实故障根本不在标签空间里而"漏掉"它——于是诊断说集合很小、配比说支撑很好、审计说预算没超，系统却在每一个**已命名**故障下都持证、在**实际**故障下无证的条件下执行了动作，即**集合覆盖的、数据支撑的、却漏掉真实故障的错误安全决定**。
