## 0. 直觉与动机

**灵感 1（多机协同 → 从"投票联邦"到"耦合约束 + 预约化可分离"）**
直觉：v20–v22 的 CFC/CFC+/CFC++ 把多机当成"多张选票"——计数、模态、层级一致性。但两只各自"几何 SAFE"的机器人可以联合不安全：它们各自只对自己的扫掠体负责，却共享同一片空间；窄门对穿、协同搬运、交接瞬间，安全是**联合状态**的性质，不是单机性质的乘积。反过来，若能把共享空间切成互斥的"单元"并做**预约 (reservation)**，联合安全就重新可分离为"各机持有单元内自由 ∧ 单元互斥"。所以核心创新不是"更强的投票"，而是**联合证书空间 (JCS) + 共享单元预约协议 (SCR)**：用预约把耦合问题化归为可分离问题，用联合扫掠体证书 (CIC) 兜住无法化归的协同动作（co-carry / handover / formation）。反直觉点：**多机安全的关键不是让机器人"达成一致"，而是让它们在物理上"互不进入对方的保留区"——共识是认知层的奢侈品，互斥是物理层的必需品**。

**灵感 2（位姿估计 → 证书的信任根与"坐标系幻觉"）**
直觉：整个 v20–v22 栈的每张证书都活在某一个坐标系里，而每个坐标系变换都带误差。机器人 B 说"这块区域是自由的"，这句话只在"B 的位姿估计正确"时成立；若 B 的位姿偏了 ε_pose，则 B 的"自由区"整体平移/旋转了 ε_pose——被认证为空的地方，可能正好站着一个人。位姿估计是所有证书的**信任根 (root of trust)**。更可怕的是自指：同一个位姿误差既让"那块区域自由"为真，也让"机器人自己在哪里"为假——你不知道自己在哪，就无法判断自己是否在自由区内。核心创新：**相对位姿证书 (RPC) + 证书传输算子 (CTO)**：把证书在坐标系间传输时，障碍物**膨胀** ε_pose、自由空间**收缩** ε_pose（不确定性下"信任的逆变律"），且旋转误差的膨胀随离旋转原点的距离线性增长。反直觉点：**位姿不确定时，自由空间和障碍物不能同向膨胀——一个必须缩、一个必须胀，否则证书会在"两边都乐观"中崩塌**。

**两者如何统一**
多机协同的真正前提是**相对位姿**：两台机器人只有在"共享一个带界相对位姿的共同坐标系"时才能交换证书。于是 多机协同 × 位姿估计 的统一产物是 **位姿锚定的联合证书 (Pose-Anchored Joint Certificate, PAJC)**：联合证书只在各机器人**已认证的共同坐标系交集**上有效，共享自由空间必须由**双边证书**（A 对 B 认证 ∧ B 对 A 认证）共同赎回，单边证据只能增补障碍、不能赎回自由。共享状态扩展为 ζ_coop = ζ_pgev ∪ (RPC, JCS, leases, indep_graph, interlock)。统一准入门 **HPC-J = HPC-E ∧ RPC_valid ∧ ReservationGranted ∧ InterlockSafe**。跨机器人证据去重从"模态多样"升级为"**失效独立性**"：同型号同模型同对抗暴露的两台机器人算**一个**见证者，而不是两个。

## 2. 设计原则（在 P42 基础上新增 P43–P47）

**P43 位姿信任根律（Pose Root-of-Trust）**
任何证书只在带 RPC 的共同坐标系内有效；证书传输时障碍**膨胀**、自由**收缩**；RPC 失效（锚点丢失/漂移超界/过期）⇒ 联合证书整体作废并回退单机 v22（更保守）。故 `Exec_v23 ⊆ Exec_v22`。

**P44 协同可分离律（Cooperative Separability）**
若共享空间被互斥单元预约覆盖（含单元间安全裕度 δ_cell），则联合安全 = 各机单元内安全 ∧ 单元互斥；不可化归的协同动作必须持 CIC 联合扫掠体证书。单边证据只增障碍，**双边证书才赎回自由**。

**P45 预约活性律（Reservation Liveness）**
租约按单元全局全序 ≺_cell 获取（消除环形等待）；抢占仅当被抢占者 EVC 可行（到期前到达认证安全态）；不可满足 ⇒ 可审计降级（放弃协同任务，退回单机），绝不静默死锁。STOP 最高优先级，且抢占仍保持互斥（先撤销租约再动作）。

**P46 失效独立性律（Failure Independence）**
共识只统计失效独立见证者；独立性由 (传感器物理 ∧ 模型族 ∧ 位姿源 ∧ 对抗暴露) 的 DAG 判定（无公共单点故障）；相关机器人合并为一个见证者。拜占庭负证据只能增障碍、不能赎回自由。

**P47 协同单调律（Cooperative Monotonicity）**
任何协同模块失效（RPC 丢 / 预约失败 / CIC 不可证 / 独立性不足）都只减少可达集，向单机 v22 退化；绝不因"多机"而扩大任何单机的执行域。

## 3. 与基线的接口（如何退化）

- RPC 失效（共同坐标系不可信）⇒ 各机独立按 v22 运行，共享区按"可能有人 ∧ 可能有他机"最保守处理 ⇒ 子集；
- 预约失败/超时 ⇒ 放弃跨机协同动作，退回单机任务 ⇒ 子集；
- CIC 不可证（协同动作的联合扫掠体无法认证）⇒ 该协同动作被禁止 ⇒ 子集；
- 失效独立性不足（仅同构机器人，共享单点故障）⇒ 联合自由空间不予赎回，只保留障碍增补 ⇒ 比 v22 更保守；
- 传输算子退化（ε_pose → 0 且 RPC 完美）⇒ PAJC 精确化归为 v22 的联邦证书 ⇒ 等价 v22；
- 全部失效 ⇒ 完全回退 v22 ⇒ `Exec_v23 ⊆ Exec_v22 ⊆ Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18`（引理 162 延伸）。
- **安全继承**：位姿不确定下障碍只胀、自由只缩；预约只做互斥；协同只做交；任意失效向保守退化。

## 4. 预期贡献

1. **位姿锚定的联合证书**：首次把位姿估计误差作为所有感知/碰撞证书的信任根，给出 SE(3) 上"障碍膨胀、自由收缩"的证书传输算子与单调性证明；
2. **协同可分离定理**：给出"单元互斥预约 ⇒ 联合安全可分离"的精确条件（含 δ_cell 边界裕度），以及不可化归协同动作的联合扫掠体证书；
3. **预约化协同协议**：全局序 + EVC 可行抢占的无死锁、可串行化租约，把 v22 的能量可行性接入多机协调；
4. **失效独立性共识**：从"模态多样"升级为"失效独立 DAG"，使相关机器人不再冒充独立见证者；拜占庭负证据单向化（只增障碍）；
5. **封堵 v22 分层振荡**：预约的确定性全局序 ≺_cell 给出确定的 tie-break，消除层级退化中的来回振荡源；
6. **HPC-J 统一准入门**：`Exec_v23 ⊆ Exec_v22` 闭环。

## 5. 本轮最大风险

**一句话**：联合证书的全部有效性最终押在"相对位姿误差有界且跨机不相关"这一假设上；若两机共享系统性位姿偏差（同一 SLAM 漂移、反光/玻璃环境、公共地图、同一标定错误），它们会**一致地**把危险平移到认证区域之外，形成"协同坐标系幻觉"——此时投票、模态多样、层级一致性全部通过，因为大家错得一模一样。

## 1. 关键算法骨架（在 IP-431–435 骨架上扩展）

```python
import math

# IP-437 Relative Pose Certificate（conformal over SE(3)）
class RelativePoseCertificate:
    def __init__(self, alpha_pose=0.01, metric=se3_bi_invariant):
        self.alpha = alpha_pose
        self.metric = metric
        self.residuals = []          # 校准集：d_SE3(T_true, T_hat)

    def calibrate(self, T_hat, T_true):
        self.residuals.append(self.metric(T_hat, T_true))

    def eps(self):
        # split-conformal 分位数：ceil((n+1)(1-α))/n 的经验分位
        n = len(self.residuals)
        if n == 0:
            return float("inf")      # 无校准样本 → 无穷保守
        k = min(n - 1, math.ceil((n + 1) * (1 - self.alpha)) - 1)
        return sorted(self.residuals)[k]

    def issue(self, T_hat_ij, anchors, t, expiry):
        # 两机绝对位姿误差合成：ε_pose ≤ ε_i ⊕ ε_j；相关误差**不相消**
        return RPC(T_hat_ij, self.eps(), self.alpha, anchors, t, expiry)


# IP-438 Certificate Transport Operator（信任逆变律）
def transport_obstacle(O, rpc):
    # 障碍单调膨胀；旋转误差位移放大 ~ ε_rot · diam(O)
    r = rpc.eps_trans + rpc.eps_rot * diam(O)
    return minkowski_expand(rpc.T_hat @ O, r)

def transport_free(F, rpc):
    # 自由单调收缩（绝不能同向膨胀，否则假自由）
    r = rpc.eps_trans + rpc.eps_rot * diam(F)
    return minkowski_shrink(rpc.T_hat @ F, r)


# IP-439 Shared-Cell Reservation Protocol（无死锁 + 可串行化）
class SharedCellReservation:
    def __init__(self, evc):
        self.evc = evc
        self.held = {}               # cell -> Lease
        self.log = []                # 可串行化审计日志

    def acquire(self, robot, cells, t0, t1, priority):
        # 全局全序获取，消除环形等待
        for c in sorted(cells, key=lambda c: c.order):
            cur = self.held.get(c)
            if cur is None or cur.expiry <= t0:
                self.held[c] = Lease(robot, c, t0, t1, priority)
                self.log.append(("grant", robot, c, t0, t1))
                continue
            # 抢占仅当被抢占者 EVC 可行：到期前能到认证安全态
            if priority > cur.priority and self.evc.can_reach_safe(
                    cur.robot, within=cur.expiry - t0):
                self.log.append(("preempt", cur.robot, c, t0))
                self.held[c] = Lease(robot, c, t0, t1, priority)
            else:
                return False, f"BLOCKED:{c}"   # 可审计降级，绝不静默死锁
        return True, "GRANTED"


# IP-441 Failure-Independence Consensus（相关机器人合并为一个见证者）
class FailureIndependenceConsensus:
    def __init__(self, q=2, indep_graph=None):
        self.q = q
        self.indep_graph = indep_graph or {}

    def independent_set(self, votes):
        nodes = collapse_correlated(votes)   # 同型号/同模型/同对抗暴露合并
        return greedy_independent_set(nodes, self.indep_graph)

    def arbitrate(self, votes, modality_ok, layer_ok):
        indep = self.independent_set(votes)
        if modality_ok and layer_ok and len(indep) >= self.q:
            return majority(indep)
        # 独立性不足：只增障碍，不赎回自由（保守）
        return "OCCUPIED_CONSERVATIVE"


# IP-442 HPC-J 联合准入门（HPC-E 原样保留，只加门）
@dataclass
class HPCJ:
    hpc_e: HPCE
    rpc: RPC
    lease_ok: bool
    cic: CoupledInterlockCertificate

    def admits(self, plan_i, plan_j, common_frame, now):
        base     = self.hpc_e.admits(plan_i, ...)          # 单机 v22 准入
        pose_ok  = self.rpc.valid(now) and common_frame.consistent(self.rpc)
        lease_ok = self.lease_ok
        cic_ok   = self.cic.covers(plan_i, plan_j, self.rpc)
        return base and pose_ok and lease_ok and cic_ok
```

## 2. 关键命题与证明骨架

**命题 1（传输单调性）**：设 RPC_ij 以 ≥1-δ_pose 成立，则对任意集合 S，
`τ_ij^obs(S) ⊇ T_ij·S` 且 `τ_ij^free(S) ⊆ T_ij·S`（均以 ≥1-δ_pose）。
*骨架*：d_SE3 双不变 ⇒ 真变换与估计变换之差被 ε_pose 球包含；旋转分量对任一点 p 的位移 ≤ ε_rot·‖p‖ ≤ ε_rot·diam(S)。障碍取 Minkowski 膨胀故包含真像；自由取收缩故被真像包含。

**命题 2（协同可分离）**：若共享空间被互斥租约覆盖且相邻单元留 δ_cell 裕度，各机在其租约单元内的认证安全，则联合构型安全。
*骨架*：任一联合状态，各机占据的单元互斥 ⇒ 跨机距离约束退化为各机相对静态障碍的约束；δ_cell 吸收单元边界处的跨机最近距离误差。缺 δ_cell 时在边界可出现"各自安全、联合相撞"的反例。

**命题 3（执行链）**：`Exec_v23 = Exec_v22 ∩ JCS ∩ ReservationGranted ∩ CIC ⊆ Exec_v22`。由交集直接得；各失效路径只移除合取项，故单调。

**命题 4（抢占保安全）**：EVC 可行的抢占不破坏互斥。*骨架*：租约撤销发生在被抢占者被认证到达安全态之后（`can_reach_safe`），且 STOP 先撤租约再动作，故任意时刻每单元至多一个有效租约。

## 3. 实验设计

- **场景**：N=2–4 机共享窄门 / 走廊 / 交接台；注入 (a) 跨机相关位姿偏置（共享 SLAM 漂移、反光面），(b) 相关检测器漏检（同模型同对抗）。
- **指标**：碰撞率；任务完成率（活性）；**协同坐标系幻觉率** = 在相关位姿偏置下"被认证自由却含危险"的体积占比；死锁/抢占次数；假自由率。
- **消融**：去掉 CTO 的"自由收缩"（应出现假自由爆炸）；去掉 FIC 独立性（相关机器人冒充共识，碰撞率上升）；预约 vs. CFC++ 纯投票。
- **对照**：v22 独立运行、CFC++ 投票、PAJC+SCR+FIC 完整方案。
