# 第 66 轮（承接第 65 轮「VISTA 视觉知情安全时序归因闭环」IP-214~223；灵感循环第 3 轮；本轮灵感：「交互设计」×「参数高效微调」）

> 第 65 轮把「几何可证伪」升级为「故障可归因」，其自述的最大风险一针见血：**归因能力依赖「故障属于有限假设集」与「视觉/几何失效相互独立」这两个隐藏假设；未知复合故障会被 FIR 强行塞进最近邻假设、只膨胀错误的球，而系统因「已经归因」反而更自信地继续执行。** 本轮不再加第 6 个传感器，也不重训大模型，而是做两件更根本的事：把**人**引入为「新假设的来源」与「第八条可错证据」，把**人的教学**压缩为「秩与范数有界、可组合、可回滚、带证书的适配器」。本轮核心命题是：
>
> **把「可归因」升级为「可教练」：用交互设计决定「何时问、问什么、怎么显示、如何否决」，用参数高效微调把纠正吸收成安全适配器，让开放世界的未知故障第一次可被命名、吸收与审计——既不把人当新真值，也不让「已认证的适配器」成为新的过度自信来源。**

## 0. 直觉与动机

**灵感 1（交互设计 → 归因的真正瓶颈在接口，不在算法）**
直觉：第 65 轮判 `ambiguous` 时只有两条路——保守等待或安全空转。但人类站在旁边，往往一眼就能提供机器缺的那条假设（"这个杯子是软塑料"、"这里其实没有面，是反光"）。问题从来不是人不知道，而是**系统没有在正确的时刻、用正确的问题、以可理解的证据去问**。交互设计的三条硬约束因此必须进入安全论证，而不是 UX 装饰：(i) **中断预算**——每一次询问都消耗注意力，问得越多越可能被敷衍；(ii) **可读性**——人必须看懂系统"信什么、怕什么、下一步做什么"；(iii) **可控性**——人必须能在不可逆点之前否决、撤销与接管。核心转向：从"系统自己归因"变成"**人机共同维护一个不断扩张的故障假设集**"（mixed-initiative）。

**灵感 2（参数高效微调 → 教学的单位应是可审计的小补丁，而非重训）**
直觉：若把人的纠正当作训练数据去改大模型，代价高、不可审计、灾难遗忘，且可能悄悄破坏已证的安全裕度。参数高效微调（LoRA/Adapter/Prefix）提供了一个更好的单位：低秩增量 `ΔW = BA`，秩 `r` 很小、谱范数可约束。**小，才能被证明**——若模块是 L-Lipschitz，则 `‖Δf‖ ≤ L·ε_ad·‖φ(x)‖`，下游安全裕度变化有界，于是"人可以教，但教不出证书之外"。适配器还可按 scope（操作员/工位/物体类/故障类型）组合与回滚，天然支持个人化而不互相污染。更强的用法：**一条新故障假设本身就是一个"假设适配器"**，从少量人类命名样本学习其签名似然，直接把第 65 轮的封闭假设集打开。

**灵感 3（人也是可错证据 → 可靠性模型与 H_human）**
直觉：人会累、会前后不一致、会被**引导性问题**带偏、会因过度信任自动化而"橡皮图章"、也可能恶意。因此绝不能把人标签当真值。做法是把人反馈 `z` 建成**问题条件化**的噪声通道 `p(z|H,u)`（同一故障，问法不同，答错率不同），并把 `H_human`（反馈通道本身不可靠/问题有歧义）加入假设集。这样人机分歧可以被归因到"人的通道坏了"或"问题问坏了"，而不是默认人赢或机器赢。这严格延续前几轮"视觉/力觉都不是真值，只是可错证据"的立场。

**灵感 4（教学准入 → 不是每条反馈都配进证书）**
直觉：单条噪声标签、被对抗诱导的纠正、或只在某个工位成立的偏好，若立即合并就会投毒。于是把适配器做成四态生命周期：**proposed（影子，不影响执行）→ probation（受限激活，持续监控）→ merged（通过安全回放 + conformal + Lipschitz 界 + 留出校准）→ rolled_back**。教学准入本质是"把微调当成一次安全变更"，用与代码上线同级的回归门禁。

**灵感 5（两灵感合流 → APPRENTICE：师徒式交互微调安全闭环）**
闭环：VISTA 归因 → 新颖性门/开放假设 → 混合主动询问（最大化"交互价值"）→ 人反馈作为可错证据融合（含 H_human）→ 低秩适配器学习（故障似然/技能/世界模型）→ 教学准入与适配器组合回滚 → 可读故障卡与承诺边界 → 异步人类否决通道 → 认证前缀执行 → AIC-I 人类对抗认证。第 65 轮是"几何-技能-干扰-接触-归因"五层，本轮增加一条**横切层"人-适配器-交互"**：它不增加实时模态，只在语义流改变"谁参与归因、如何吸收纠正"；实时流仍执行固定安全盾与认证前缀，**零学习写操作**这一不变式不破。

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（APPRENTICE 闭环）**：APPRENTICE = (VISTA, HMM, OHE, MIX, LFC, RBA, TAG, HOC, ACR, AIC-I, J_apprentice)。定位：VISTA 的"开放假设 + 可教练"升级。不变式：**人类交互、假设扩张、适配器训练与合并、证书构建只在语义流/离线；实时流只执行固定安全盾、认证前缀与预验证的 stop/retreat 覆盖，零学习写操作，且不依赖任何未合并适配器。**
- **定义 234（人类导师的可错通道 HMM）**：反馈 `z_t ∈ Z = {假设标签, 对比纠正 (a⁺,a⁻), 标量评分, 新故障命名+范例, 否决, 接管}`。可靠性模型 `R_c(z|h,u)` 为**按上下文 c 与提问方式 u 条件化**的混淆核（c 含操作员 id、负荷、时压、模态）；`p(z|h,u)=R_c(z|h,u)`。维护信任权重 `w_h` 与校准集；`H_human` 表示"反馈通道/问题本身不可靠"。**人反馈只进入后验，不直接改写几何或安全限。**
- **定义 235（开放故障假设集 OHE）**：`ℋ_t = ℋ_base ∪ ℋ_named ∪ ℋ_latent`。`ℋ_base` 为第 65 轮六假设；`ℋ_named` 由人类命名并经准入的新故障，各带一个少样本"假设适配器"；`ℋ_latent` 为签名空间的新颖簇。新假设先验按 Dirichlet 过程式 `P(new) ∝ α/(α+n)`；当 `max_{H∈ℋ_base} p(ρ|H) < ε_novel` 时置 `novel=True`，**禁止**静默取最近邻，改为询问或安全降级。
- **定义 236（交互动作与交互价值 MIX）**：交互动作 `u ∈ U = {yes/no, which, request_demo, request_touch, show_card, request_override, null}`。交互价值
  `VI(u) = E_{z~p(z|ρ,u)}[H(ℋ|ρ) − H(ℋ|ρ,z,u)] + λ_exp·E[Δ useful H] − λ_c·cost(u) − λ_s·risk(u)`，
  第二项奖励**假设空间扩张**（发现并命名新故障），`cost` 为注意力/时间，`risk` 为请求动作的物理风险。`u* = argmax VI`，s.t. `risk ≤ budget`、`cost ≤ attention_budget`，且仅当 `VI > θ_int` 才打断（迟滞避免打断疲劳）。问题需满足**中立性约束**（避免引导性提问），这会牺牲部分信息增益但保住可靠性模型的可辨识。
- **定义 237（混合主动询问策略）**：维护候选问题集，按子模近似的期望信息增益贪心选择，按批合并（同一故障卡可答多问），在注意力预算 B 下达到 `(1−1/e)` 近似；当 `H(ℋ|ρ) < H_stop` 或 `VI < θ_int` 即停止询问。人可随时主动发起（接管/声明易损），系统必须始终保留"停止-后退-空转"三个固定安全动作。
- **定义 238（可读故障卡与承诺边界 LFC）**：把后验渲染为故障卡：Top-k 假设及**校准后**概率、三阶段证据条、被膨胀的是哪个球（r_geo/r_force/r_model）、认证前缀 `k*`、**承诺边界 m 的倒计时**、当前最值得问的问题、可用覆盖动作。设计遵循渐进披露、一致映射、feedforward、错误可恢复。承诺边界必须在越过不可逆点前显式呈现；卡片异步渲染，不进入实时环。
- **定义 239（秩-范数有界适配器 RBA）**：对语义流模块 `f_ℓ`，适配器 `f'_ℓ(x)=f_ℓ(x)+α/r·B A φ(x)`，`A∈ℝ^{r×d_in}, B∈ℝ^{d_out×r}`，`r≤r_max`，且 `‖BA‖_2≤ε_ad`。若 `f_ℓ` 为 L-Lipschitz，则 `‖f'_ℓ(x)−f_ℓ(x)‖≤(α/r)L ε_ad‖φ(x)‖`；下游安全裕度变化 `≤ L_down·(α/r)L ε_ad·‖φ‖_max`。由此可**反解安全允许的 ε_ad**，把"能教多少"变成可计算预算。
- **定义 240（适配器安全证书与合并门）**：适配器 `Δ` 对状态集 `S_cert` 的合并门：
  `Gate(Δ) ⇔ [∀s∈S_cert: margin(s; f+Δ) ≥ margin(s; f) − δ_gate] ∧ [留出校准上似然不降] ∧ [重算 J_vista 的 Lipschitz 界仍成立] ∧ [Δ 的 provenance 已签名]`。不满足则停留 proposed/probation 或回滚。`δ_gate` 与 conformal 风险预算统一记账。
- **定义 241（适配器组合、干扰与版本回滚 ACR）**：适配器集合以版本 DAG 管理，`Δ_total=Σ_i Δ_i`。干扰度量 `ι(Δ_i,Δ_j)=` 子空间主角/非交换残差；`‖Δ_total‖≤Σ‖Δ_i‖`，故 `Σ(α/r)L ε_ad ≤ margin/L_down` 即证书保持。合并顺序按干扰最小贪心；回滚是**原子**的（切回上一认证版本，含其 J_apprentice 哈希）。
- **定义 242（教学准入生命周期 TAG）**：`proposed → shadow → probation → merged → rolled_back`。shadow 只记录反事实差、不影响执行；probation 仅在低风险域激活并持续比对安全裕度；merged 需通过定义 240；任何回归触发自动回滚与"教学失败"反馈给人类。**未合并适配器绝不进入实时安全路径。**
- **定义 243（人类否决/接管通道 HOC）**：异步通道映射到三个**预验证、无学习**的安全控制器：`stop`、`compliant_retreat`、`safe_idle`；延迟上界 `τ_ov`；对不可逆动作，若 `k*` 将越过 m 且后验置信不足，则要求显式授权。覆盖事件写入证书，且覆盖通道本身在 AIC-I 下做最坏延迟认证。
- **定义 244（交互条件化故障后验）**：`P(H|ρ,z,u) ∝ p(ρ|H)·p(z|H,u)·P(H)`，`p(z|H,u)` 来自定义 234。人机冲突时**不默认人赢**：若 `max_H P(H|ρ,z,u)` 不集中则判 `H_human` 或 `ambiguous`，进入 MIX 继续问或安全降级。
- **定义 245（APPRENTICE 证书 J_apprentice）**：`J_apprentice=(J_vista, human_reliability_ver, interaction_log_hash, hypothesis_set_hash, adapter_set_ver, adapter_norm, scope_cert, trust_calibration, override_channel_ok, commitment_boundary_surfaced)`。Valid ⇔ `Valid(J_vista)` ∧ 新颖样本已处理（低于 ε_novel 或已命名并通过 Gate）∧ 激活适配器均在 `r_max/ε_ad` 预算内 ∧ scope 匹配 ∧ 覆盖通道在线 ∧ 人反馈仅作为可错证据使用 ∧ 承诺边界已向人呈现。
- **定义 246（交互对抗认证 AIC-I）**：干扰集 `ℰ_I = ℰ_V × ℰ_human`，`ℰ_human` 含不可靠、前后矛盾、恶意投毒、延迟反馈、自动化偏见（橡皮图章）、"善意但系统性错误"。认证要求：最坏 `ℰ_human` 下安全不低于 VISTA 基线；适配器对标签噪声有有界影响（trimmed/robust loss）；信任校准误差有界；覆盖延迟 `≤τ_ov`；人类不可用时优雅退化回 VISTA。
- **定义 247（个人化作用域与作用域证书）**：每个适配器带 scope 标签（operator/workspace/object_class/task）与作用域证书；激活需 scope 匹配且作用域内留出验证通过。防止跨用户泄漏、负迁移与"某个工位学到的偏好污染全体"。
- **定义 248（APPRENTICE 闭环算子）**：语义流 `[VISTA 归因 → OHE 新颖性门 → MIX 询问/人反馈融合(含 H_human) → RBA 生成/更新适配器 → TAG 准入 → ACR 组合 → LFC 故障卡 → CSC 认证前缀 → HOC 覆盖检查 → 执行 k* → AIC-I 认证]`；实时流 `[锚点读 → 固定安全盾 → 认证前缀派发 → 固定 stop/retreat 覆盖 → J_apprentice 构建]`。

```python
rho = vista.signature(phases)

card = lfc.render(post, balls, k_star, commitment_boundary=m, top_question=u)

    require_explicit_consent(card)
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（封闭假设集的下界）**：若真实故障 `h* ∉ ℋ_base`，任何仅依赖 `ρ` 的固定假设集决策器，其误归因风险存在由先验质量与 `min_{H∈ℋ_base} KL(p_{h*}‖p_H)` 决定的正下界（Le Cam/Fano）。人类命名新假设并以可靠性 `q>1/2` 提供 `n` 条标签后，后验错误率按 `exp(−n·D(1/2‖q))` 下降，故 `O(log(1/δ)/D)` 条标签足够。**结论：开放假设不是可选项，有限集本身就是瓶颈。**
- **引理 10（有界适配器的证书保持）**：若 `f_ℓ` L-Lipschitz、`‖Δ‖≤ε_ad`，则对任意 `s∈S_cert` 的裕度变化 `|Δmargin|≤L_down L ε_ad ‖φ‖_max`；令 `ε_ad ≤ (δ_gate+margin_min)/(L_down L ‖φ‖_max)` 即保证 `margin(s;f+Δ)≥margin_min−δ_gate`。多适配器 `‖ΣΔ_i‖≤Σ‖Δ_i‖`，故总预算可在合并前一次性校验；干扰仅影响裕度收紧量，不影响该上界。
- **定理 9（APPRENTICE 端到端）**：在 A94–A99 下，(1) 已知故障不劣于 VISTA（不适配或适配器过门才生效）；(2) 人类可命名的未知故障，误归因率随标签数指数下降并受 `q` 控制；(3) 无静默过度自信——新颖性门 + `H_human` + `ambiguous` 必触发询问或安全降级；(4) 有界适配器 + 覆盖通道 ⇒ 安全裕度保持；(5) 人不可用 ⇒ 退化回 VISTA。
- **定理 10（交互代价近最优）**：在条件独立近似下期望信息增益对问题集子模，贪心批选达到 `(1−1/e)` 最优；空腹/打断阈值策略在注意力预算 B 下最小化"遗憾 + λ·打断次数"，误差上界同阶。中立性问题约束可能降低单问增益，但保住可靠性模型可辨识，从而不牺牲校准。
- **实时性**：适配器、可靠性更新、询问、故障卡渲染、合并门全在语义流/离线；实时流只加固定覆盖检查（<0.1ms）与卡片倒计时的只读时间戳，目标仍 ≤2.5ms，且**实时路径不加载任何未合并适配器**。

## 5. 本轮最大风险

## 2. 形式化定义（完整版）

**定义 233（APPRENTICE 闭环）** APPRENTICE 是 VISTA 的「开放假设 + 可教练」升级：在 VISTA 的语义流/实时流骨架上挂载 HMM（人类可错通道）、OHE（开放假设）、MIX（混合主动询问）、LFC（可读故障卡）、RBA（有界适配器）、TAG（教学准入）、HOC（人类覆盖）、ACR（组合回滚），并升级 AIC-V→AIC-I、J_vista→J_apprentice。不变式：**人类交互、假设扩张、适配器训练/合并、证书构建只发生在语义流与离线线程；实时路径只执行固定安全盾、认证前缀与预验证 stop/retreat/safe_idle，零学习写操作，且不加载任何未合并适配器。**

**定义 234（人类导师的可错通道 HMM）** 反馈集合 `Z={label h, contrastive (a⁺,a⁻), scalar rating, new_fault(name, exemplars), veto, takeover}`。人类可靠性为上下文/问题条件化混淆核 `R_c(z|h,u)`，`c` 含操作员 id、负荷指数、时间压力、交互模态（语音/指点/示教）、历史一致性；`p(z|h,u)=R_c(z|h,u)`。维护信任权重 `w_h`、校准集 `𝒞_h` 与版本号 `human_reliability_ver`。新增假设 `H_human`：反馈通道不可靠或问题有歧义。**规则：人反馈只进入后验 `P(H|ρ,z,u)`，绝不直接改写几何先验、力限或安全盾。** 可靠性由定期标定任务与在线一致性统计联合估计，并对 `R_c` 做保守上界（置信区间下界用于安全论证）。

**定义 235（开放故障假设集 OHE）** `ℋ_t=ℋ_base ∪ ℋ_named ∪ ℋ_latent`。`ℋ_base` 为第 65 轮六假设；`ℋ_named` 由人类命名并通过教学准入的新故障，每个带一个「假设适配器」`Δ_H`，把签名 `ρ` 映射到该类似然；`ℋ_latent` 是签名空间中未被任何假设解释的新颖簇。新假设先验 `P(new)=α/(α+n)`（n 为已见签名数），命名后按该簇质量分配。新颖性判据 `novel ⇔ max_{H∈ℋ_base} p(ρ|H)<ε_novel`；`novel` 时**禁止**取最近邻作为归因结论，只能 (i) 触发 MIX 询问、(ii) 进入 `ℋ_latent` 并安全降级。命名新假设需至少 `n_min` 条独立范例与一次教学准入。

**定义 236（交互动作与交互价值 MIX）** 交互动作
`U={yes_no, which_hypothesis, request_demo, request_touch, show_card, request_override, null}`。
交互价值
`VI(u)=E_{z~p(z|ρ,u)}[H(ℋ|ρ)−H(ℋ|ρ,z,u)] + λ_exp·E[Δ useful H] − λ_c·cost(u) − λ_s·risk(u)`，
其中第一项是**判别信息**（降低故障熵），第二项是**扩张信息**（发现/命名当前假设集之外的新故障，只有提出开放问题或请求示教才可能获得），`cost` 为注意力/时间/认知负荷，`risk` 为请求动作的物理风险（如 `request_touch` 对易损物体的风险）。选择
`u*=argmax_{u∈U} VI(u)`，s.t. `risk(u)≤risk_budget`、`cost(u)≤attention_budget`，且 `VI(u*)>θ_int` 才实际打断；否则 `null` 并继续被动观测。问题设计需满足**中立性约束**：不暗示期望答案、不暴露系统倾向（否则 `R_c` 被引导性偏差污染）。人在任意时刻可主动发起交互（见定义 243），系统不得阻塞。

**定义 237（混合主动询问策略）** 在问题候选集上以期望信息增益的单调子模近似做贪心，按批合并（同一故障卡答多问），注意力预算 `B` 下达到 `(1−1/e)` 近似；当 `H(ℋ|ρ)<H_stop` 或 `VI<θ_int` 停止。策略维护"上次打断时间"做迟滞，避免打断疲劳；对高负荷上下文自动提高 `θ_int`（少打扰），对高风险上下文降低 `θ_int`（宁可多问）。安全相关的询问（如"该物体是否易损"）可越过注意力预算，因为其风险削减价值被计入 `risk` 项。

**定义 238（可读故障卡与承诺边界 LFC）** 故障卡包含：Top-k 假设及**经可靠性校准**的概率、三阶段证据条（approach/touch/load）、被膨胀的球（`r_geo/r_force/r_model`）、认证前缀 `k*` 与**承诺边界 m 的倒计时**（"还有 X 步到达不可逆点"）、当前最值一问 `u*`、可用覆盖动作。设计原则：渐进披露（先结论后证据）、一致映射（颜色/图标跨轮固定）、feedforward（提前展示后果）、错误可恢复（撤销/后退）。卡片在语义流异步渲染，实时流只读时间戳；**承诺边界必须在越过 m 前呈现**，否则 `J_apprentice` 置 `commitment_boundary_surfaced=False` 而失效。

**定义 239（秩-范数有界适配器 RBA）** 对语义流模块 `f_ℓ`，适配器
`f'_ℓ(x)=f_ℓ(x)+(α/r)·B A φ(x)`，`A∈ℝ^{r×d_in}`、`B∈ℝ^{d_out×r}`、`r≤r_max`、`‖BA‖_2≤ε_ad`。
若 `f_ℓ` 为 L-Lipschitz，则
`‖f'_ℓ(x)−f_ℓ(x)‖ ≤ (α/r)·L·ε_ad·‖φ(x)‖`，
下游任一安全相关量 `g`（力限、滑移裕度、几何置信）若对 `f_ℓ` 输出是 `L_down`-Lipschitz，则
`|Δg| ≤ L_down·(α/r)·L·ε_ad·‖φ‖_max`。
由安全要求 `|Δg|≤δ_gate` 反解
`ε_ad ≤ δ_gate·r / (α·L_down·L·‖φ‖_max)`。
**这把"人还能教多少"变成合并前可计算的预算。** 新故障假设用一个 `Δ_H`：输入签名 `ρ`，输出该假设的对数似然修正；仅需少量命名范例即可拟合低秩映射。

**定义 240（适配器安全证书与合并门 TAG-gate）** 对候选 `Δ`：
`Gate(Δ) ⇔ [∀s∈S_cert: margin(s;f+Δ) ≥ margin(s;f)−δ_gate] ∧ [留出校准似然不降] ∧ [重算的 Lipschitz 界仍成立且 ε_ad 在预算内] ∧ [provenance 已签名且 scope 匹配]`。
`S_cert` 含正常、边界、OOD、对抗、共因与历史故障回放（`n_gate≥256`）。任一条不满足则停留原状态或回滚；合并门失败原因反馈给人类（"你的纠正会破坏这条安全性质"），并给出最小可行修改建议。`δ_gate` 与 VISTA 的 conformal 风险预算统一记账，`α_chunk` 相应扣减。

**定义 241（适配器组合、干扰与原子回滚 ACR）** 适配器集合用版本 DAG 管理，节点含 `(hash, scope, r, ε_ad, provenance, J_apprentice_ver)`。组合 `Δ_total=Σ_i Δ_i`，`‖Δ_total‖_2≤Σ_i‖Δ_i‖_2`，故合并前可一次性校验 `Σ_i(α_i/r_i)L_i ε_{ad,i} ≤ δ_gate_total/(L_down‖φ‖_max)`。干扰 `ι(Δ_i,Δ_j)` 取两适配器子空间主角正弦或组合非交换残差；合并顺序按 `ι` 最小贪心。回滚原子：切回上一认证版本并重放其 `J_apprentice` 哈希，允许在 <1 个语义周期内完成；回滚事件记入交互日志。

**定义 242（教学准入生命周期 TAG）** 四态：
- `proposed`：由一次或少量交互提出的适配器候选，尚未影响任何执行；
- `shadow`：与主模块并跑，只记录反事实差与若激活会造成的裕度变化，不改变输出；
- `probation`：仅在低风险域（低力、低速、非易损、非不可逆）激活，持续比对预测/实际与安全裕度，任何越界立即回滚；
- `merged`：通过定义 240 的 Gate，进入认证适配器集，参与后续 J_apprentice；
- `rolled_back`：因回归、作用域越界、对抗证据或人工撤销而回退。
**未合并适配器绝不进入实时安全路径。** 教学准入把"微调"变成与代码上线同级的变更管理。

**定义 243（人类否决/接管通道 HOC）** 异步输入映射到三个**预验证、无学习**的安全控制器：`stop`（零速保持）、`compliant_retreat`（柔顺后退）、`safe_idle`（松力保持）。延迟上界 `τ_ov`（从人到安全动作生效）。对不可逆动作，若 `k*` 将越过 m 且后验置信 `<1−δ_fi`，系统必须请求显式授权（人确认后才执行）；人可随时覆盖，覆盖优先于任何学习策略。覆盖事件、延迟与结果写入 `J_apprentice`；覆盖通道本身在 AIC-I 中做最坏延迟与失效认证（含"人按了但消息丢了"）。

**定义 244（交互条件化故障后验）** `P(H|ρ,z,u) ∝ p(ρ|H)·p(z|H,u)·P(H)`，`p(z|H,u)` 来自定义 234。人机冲突处理：
- 若 `max_H P(H|ρ,z,u) ≥ 1−δ_fi`：按该假设定向处置（与 VISTA 一致）；
- 否则若 `P(H_human)` 高：降低 `w_h`、重问一个**不同模态**的问题（语音→指点→示教），并回到被动观测；
- 否则判 `ambiguous`：进入 MIX 继续问或安全降级。
**人赢/机器赢不是规则，后验集中度才是规则。**

**定义 245（APPRENTICE 证书 J_apprentice）**
`J_apprentice=(J_vista, human_reliability_ver, interaction_log_hash, hypothesis_set_hash, adapter_set_ver, adapter_norm, scope_cert, trust_calibration, override_channel_ok, commitment_boundary_surfaced)`。
验证规则：
`Valid(J_apprentice) ⇔ Valid(J_vista)`
`∧ (novel 已处理：低于 ε_novel 或已命名并通过 Gate)`
`∧ (激活适配器集合满足 r≤r_max 且 Σε_ad 在预算内)`
`∧ scope 匹配`
`∧ override_channel_ok 且 τ_ov≤τ_max`
`∧ trust_calibration 误差≤ε_cal`
`∧ (人反馈仅作为可错证据使用：存在对应 reliability_ver)`
`∧ commitment_boundary_surfaced 为真（若本块将接近 m）`。
审计链新增：**谁教了什么（adapter provenance + interaction log）、为什么允许它合并（Gate）、人有多可靠（human_reliability_ver）、人是否在关键点之前被告知并能否决（LFC + HOC）。**

**定义 246（交互对抗认证 AIC-I）** 干扰集 `ℰ_I=ℰ_V×ℰ_human`，`ℰ_human` 含：不可靠（低 `q`）、前后矛盾（flip label）、恶意投毒（定向污染某故障类）、延迟反馈（人看到的是旧状态）、自动化偏见（人盲目批准系统建议）、"善意但系统性错误"（人按错误心智模型一致地教）。认证要求：
1. 最坏 `ℰ_human` 下安全指标不低于 VISTA 基线（适配器可被 Gate 拦住）；
2. 适配器训练用鲁棒损失（trimmed/Huber/影响函数有界），单条或小比例毒样本不能翻转 Gate；
3. 信任校准误差有界（可靠性图/ECE≤ε_cal），且系统在高风险时主动降低人的过度信任（显式不确定性 + 承诺边界）；
4. 覆盖延迟 `≤τ_ov`，含消息丢失与重放；
5. 人类不可用/离场时优雅退化回 VISTA（不阻塞、不假装有人）。
`n_cert` 由 128 增至 160，其中 32 给 `ℰ_human`。**共因人类/传感器故障下不要求归因正确，只要求判 `ambiguous` 并安全降级。**

**定义 247（个人化作用域与作用域证书）** 每个适配器带 `scope(Δ)⊆{operator, workspace, object_class, task}` 与作用域证书：在 scope 内留出集上通过 Gate，scope 外**默认不激活**。激活判据包含 scope 匹配与运行时 OOD 检测；跨 scope 迁移需重新 Gate。作用域设计避免三类失败：跨用户隐私/偏好泄漏、A 工位策略污染 B 工位、单物体过拟合导致负迁移。适配器可组合但 scope 求交，交集为空则不组合。

**定义 248（APPRENTICE 闭环算子）** 语义流：
`[VISTA 归因 → OHE 新颖性门 → MIX 询问/人反馈融合(含 H_human) → RBA 生成/更新适配器 → TAG 准入 → ACR 组合 → LFC 故障卡 → CSC 认证前缀 → HOC 覆盖检查 → 执行 k* 步 → EV_exec → AIC-I 认证]`；
实时流：
`[锚点读 → 固定安全盾 → 认证前缀派发 → 固定 stop/retreat/safe_idle 覆盖 → J_apprentice 构建]`。
不变式：**实时流不含学习、不含未合并适配器、不含人类反馈解析；人类与适配器的影响必须先把结论"编译"成认证前缀与证书，才能进入实时路径。**

```python
class OpenHypothesis:
    def __init__(self, base, eps_novel=1e-3, alpha_dp=1.0, n_min=3):
        self.H_base, self.eps_novel = base, eps_novel
        self.alpha_dp, self.n_min = alpha_dp, n_min
        self.H_named, self.H_latent = {}, []      # named: name -> adapter + exemplars

    def likelihoods(self, rho):
        lik = {h: self.H_base[h].loglik(rho) for h in self.H_base}
        lik.update({h: self.H_named[h].adapter_loglik(rho) for h in self.H_named})
        return lik

    def is_novel(self, rho):
        return max(self.likelihoods(rho).values()) < np.log(self.eps_novel)

    def new_prior(self):
        n = sum(len(v.exemplars) for v in self.H_named.values())
        return self.alpha_dp / (self.alpha_dp + n)

    def absorb_naming(self, name, exemplars, adapter):
        if len(exemplars) < self.n_min:
            return False, 'need_more_exemplars'
        self.H_named[name] = NamedFault(name, exemplars, adapter)
        return True, 'candidate_for_tag'
```

### IP-226 MIX（交互价值与询问选择）

```python
class MixedInitiative:
    def __init__(self, theta_int=0.05, lambda_exp=0.3, lambda_c=0.1, lambda_s=1.0):
        self.theta_int, self.lambda_exp = theta_int, lambda_exp
        self.lambda_c, self.lambda_s = lambda_c, lambda_s

    def value(self, u, post, rho, reliability, risk):
        # 判别信息 + 假设空间扩张 - 注意力 - 物理风险
        ig = expected_info_gain(post, u, reliability)          # H(H|rho) - E[H(H|rho,z,u)]
        exp = expected_expansion(post, rho, u)                 # 新故障被发现的价值
        return ig + self.lambda_exp * exp - self.lambda_c * attention_cost(u) \
               - self.lambda_s * risk.get(u, 0.0)

    def choose(self, post, rho, reliability, budgets, fragile=False):
        cands = [('null', 0.0)]
        for u in self.questions(post, fragile):
            if attention_cost(u) > budgets.attention: continue
            if self.risk(u, fragile) > budgets.risk: continue
            cands.append((u, self.value(u, post, rho, reliability, self.risk(u, fragile))))
        u, v = max(cands, key=lambda z: z[1])
        if u != 'null' and v <= self.theta_int:
            return None, v
        return u, v

    def questions(self, post, fragile):
        qs = ['which_hypothesis', 'show_card', 'request_demo']
        if not fragile:
            qs.append('request_touch')
        return qs                                     # 中立性：不透露系统倾向
```

```python
class RankBoundedAdapter:
    def __init__(self, r_max=8, alpha=8.0):
        self.r_max, self.alpha = r_max, alpha

    def fit(self, module, corrections, eps_ad):
        r = min(self.r_max, estimate_effective_rank(corrections))
        A, B = low_rank_fit(module, corrections, r)
        delta = Adapter(A, B, alpha=self.alpha, rank=r)
        delta = project_norm(delta, eps_ad)            # 强制 ||BA||_2 <= eps_ad
        return delta

    def safety_budget(self, L, L_down, phi_max, delta_gate):
        # eps_ad <= delta_gate*r / (alpha*L_down*L*||phi||_max)
        return delta_gate                           # 由定义 239 反解后传入

class TeachingAdmission:
    STATES = ('proposed', 'shadow', 'probation', 'merged', 'rolled_back')

    def __init__(self, gate, S_cert, delta_gate=0.02, shadow_steps=64):
        self.gate, self.S_cert, self.delta_gate = gate, S_cert, delta_gate
        self.shadow_steps = shadow_steps

    def track(self, delta, module, scope):
        diff = counterfactual_diff(module, delta, self.S_cert)   # shadow：不影响执行
        return {'delta': delta, 'shadow_diff': diff, 'scope': scope,
                'state': 'shadow', 'evidence': []}

    def gate_pass(self, delta, module):
        if not self.gate.margin_ok(module, delta, self.S_cert, self.delta_gate):
            return False
        if not self.gate.heldout_likelihood_nondecreasing(delta):
            return False
        if not self.gate.lipschitz_within_budget(delta):
            return False
        return self.gate.provenance_signed(delta)

    def promote(self, rec, module):
        if rec['state'] == 'shadow' and len(rec['evidence']) >= self.shadow_steps:
            rec['state'] = 'probation'
        if rec['state'] == 'probation':
            if self.gate_pass(rec['delta'], module):
                rec['state'] = 'merged'
            else:
                rec['state'] = 'rolled_back'
        return rec
```

## 4. 推导

**引理 9（封闭假设集的下界与开放假设的必要性）** 设真实故障 `h*`，观测签名分布 `p_{h*}`。固定假设集 `ℋ_base` 下，任何决策器 `δ(ρ)∈ℋ_base` 的风险满足（Le Cam 两两下界/Fano）
`inf_δ max_{H∈ℋ_base∪{h*}} P(δ(ρ)≠H) ≥ (1/2)(1 − TV(p_{h*}, p_{H*}) - ...)`，
其中 `H*=argmin_{H∈ℋ_base} KL(p_{h*}‖p_H)`。若 `p_{h*}` 与所有 `p_H` 的 KL 都大，则无论多少样本，误归因率都有正下界——**这是第 65 轮"未知复合故障被强行归类"的形式化根源**。现允许人类命名 `h*` 并以可靠性 `q>1/2` 提供标签，等价于在 `ℋ_base` 上增加一条独立噪声通道；由 Chernoff/Stein，`n` 条标签后验错误率满足
`P(err) ≤ exp(−n·D(1/2‖q))`，
故 `n=O(log(1/δ)/D(1/2‖q))` 条标签即可把误归因降到 δ。∎

**引理 10（有界适配器的证书保持与可组合性）** 设 `f_ℓ` 为 L-Lipschitz，适配器 `Δ=(α/r)BA` 满足 `‖BA‖_2≤ε_ad`。则对任意输入 `x`，
`‖Δ(x)‖= (α/r)‖BAφ(x)‖ ≤ (α/r)‖BA‖_2‖φ(x)‖ ≤ (α/r)ε_ad‖φ(x)‖`。
若下游安全量 `g` 是 `L_down`-Lipschitz，则
`|g(f(x)+Δ(x))−g(f(x))| ≤ L_down·(α/r)ε_ad‖φ(x)‖`。
取 `ε_ad ≤ δ_gate·r/(α L_down L ‖φ‖_max)`（更保守时用 `L` 直接）即得 `|Δg|≤δ_gate`，从而 `margin(f+Δ)≥margin(f)−δ_gate`，`J_vista` 的裕度约束仍成立。对组合 `Δ_total=Σ_iΔ_i`，三角不等式给 `‖Δ_total‖≤Σ_i‖Δ_i‖`，故只需在合并前校验总范数预算；干扰 `ι(Δ_i,Δ_j)` 只改变各方向上裕度收紧的分配，不破坏该上界。∎

**定理 9（APPRENTICE 端到端归因-安全）** 在 A94–A99 下：
1. **已知故障不退化**：适配器默认关闭；仅通过 Gate 的适配器生效，且引理 10 保证 `|Δmargin|≤δ_gate`，故安全证书不弱于 VISTA。
2. **未知可命名故障可被吸收**：OHE 新颖性门阻止静默最近邻；人类命名 + 引理 9 使误归因随标签数指数下降；假设适配器进入 `ℋ_named` 后由 Gate 校验。
3. **无静默过度自信**：`novel`、`H_human` 或 `ambiguous` 必触发 MIX 或安全降级；`J_apprentice` 要求新颖性已处理，否则证书无效。
4. **物理安全保持**：有界适配器 + 未合并适配器不进实时 + 固定覆盖通道 + `k*≤m`，联合给出单块越界概率 ≤ 第 65 轮预算（`α_chunk+δ_fi+α_vis+δ_gate`）。
5. **优雅降级**：人类不可用/离场 ⇒ 退化回 VISTA；反馈通道判坏 ⇒ `w_h↓`、`H_human` 接管、重问不同模态；适配器回归 ⇒ 原子回滚。∎

**定理 10（交互代价近最优）** 设问题集合 `Q`，期望信息增益 `f(A)=I(ℋ;Z_A|ρ)`。在给定 `ρ` 与条件独立近似下 `f` 单调子模，故贪心批选 `A_greedy` 满足 `f(A_greedy) ≥ (1−1/e) max_{|A|≤B} f(A)`。定义总代价
`J(u_{1:T}) = E[regret(ℋ_T)] + λ_c Σ_t cost(u_t) + λ_s Σ_t risk(u_t)`；
在 `VI>θ_int` 才打断的策略下，每次打断的边际收益 ≥ `θ_int`，否则跳过，故 `J` 与最优的差被 `θ_int·T` 与子模近似因子共同界定；提高 `θ_int` 减少打断但增加遗憾，二者存在可调的帕累托前沿。中立性问题约束把可行问题集限制为 `Q_neutral⊆Q`，可能降低单问增益，但保住 `R_c` 的可辨识性，从而不牺牲长期校准。∎

**命题（交互降低过度保守而非降低安全）** 第 65 轮在 `ambiguous` 时只能统一保守膨胀或空转。APPRENTICE 在 `ambiguous` 时用 `u*` 获取**判别信息**或**扩张假设**：若信息足够则定向膨胀正确球（降低过度保守），若不足则安全降级（不降低安全）。由于人反馈只进后验且适配器受 Gate 约束，故"更少保守"不以"更多违规"为代价。∎

## 7. 已知风险

**一句话**：APPRENTICE 把人变成安全回路里的第一类证据与可训练参数，于是**人本身成了新的攻击面与分布漂移源**——不可靠、前后矛盾、被引导、恶意投毒或"善意但系统性错误"的反馈，会被压缩成局部通过安全门、通过范数证书、看起来"已认证"的低秩适配器，系统与人反而因为"它是有证书的"而更加信任它；若合并门只覆盖有限安全回放与局部 Lipschitz 界，而无法覆盖语义层面的系统性偏移，那么第 65 轮的"归因错误的复合故障"就会升级为"**被教学认证过的复合故障**"，这是本轮全部交互价值与适配器安全论证共同依赖的隐藏假设（A94）。

**次级风险与缓解**：
1. **人类可靠性模型不可辨识/漂移**：`R_c` 依赖上下文与问题，样本稀疏；缓解：定期中立标定任务、跨模态交叉验证、保守置信下界、`H_human` 兜底、漂移检测触发重标定。
2. **引导性问题污染可靠性**：问法暗示答案使 `R_c` 有偏；缓解：中立性问题模板、随机化措辞、A/B 校准、把问题模板作为 `R_c` 的条件变量。
3. **适配器 Gate 只保证局部/回放安全**：有限 `S_cert` 无法覆盖语义级系统性偏移；缓解：分层 Gate（数值裕度 + 语义一致性 + 反事实回放 + 红队集），并对高风险适配器强制 shadow 长尾观察。
4. **适配器组合的非线性干扰**：`Σ‖Δ‖` 界保守但干扰可能局部放大；缓解：合并顺序贪心、子空间正交化、组合后整体重验、限制同时激活数量。
5. **自动化偏见与过度信任**：故障卡与"已认证"标签可能让人盲从；缓解：显式不确定性与承诺边界、要求不可逆前显式授权、定期"系统可能错"的提醒、测量并优化信任校准而非最大化信任。
6. **交互/教学本身导致中断过载**：问得过多使人敷衍；缓解：注意力预算、迟滞阈值、批处理、高负荷自适应少打扰、把关键安全询问优先级与风险绑定。
7. **恶意投毒绕过局部 Gate**：小比例毒样本在局部回放上不可见；缓解：鲁棒损失、影响函数上界、provenance 签名与来源隔离、跨操作员一致性检查、异常适配器隔离区。
8. **作用域泄漏与负迁移**：一个工位/用户学到的适配器污染他人；缓解：scope 求交、scope 外默认不激活、作用域内留出验证、显式版本与审计。
9. **实时路径被间接拖慢**：适配器虽在语义流，但组合/证书/卡片可能挤占预算；缓解：全部异步/离线，实时只保留固定覆盖检查与只读时间戳，目标 ≤2.6ms。
10. **人离场后的能力真空**：过度依赖教学导致无人时退化明显；缓解：始终保留 VISTA 基线能力、人缺席时自动降级并显式提示、关键技能不依赖个人化适配器。
