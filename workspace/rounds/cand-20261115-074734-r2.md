# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环本轮第 2 轮；本轮灵感：「双臂协调」×「模仿学习」）

> R69 把不确定性做成了有形状的对象：多模态动作的模态、权重、间距，以及在预算内主动消解 epistemic 的「看/问/触」。但它仍默认一个隐含前提——**一个身体、一个动作、一个世界模型**。当系统长出第二只手臂，这个前提塌了：左手稳稳托住杯底、右手去拧盖，两只手各自都「很自信」，合起来却可能把杯子拧碎或扯落。**协调不是一个额外的策略，而是两个动作分布之间的相关结构**；而 R69 的模态分解一旦逐臂独立进行，就会把这个相关结构在乘积 p(a_L)p(a_R) 里悄悄抹掉——这正是「边缘可信 ≠ 联合可信」。
>
> 本轮两个灵感正好补上两块缺失：
> - **双臂协调**把不确定性从「每个策略的标量/形状」升级为**关系量**：相对位姿、内外力、角色、相位，都是只在两臂之间才定义的量；
> - **模仿学习**给出协调流形的来源：示教不是逐帧标签，而是在联合动作空间里画出一条「合法耦合」的流形；行为克隆若逐臂拟合，会学到两个自洽的边缘策略，却在流形外生成「自相残杀」的组合。
>
> 核心命题：**协调一致性是新的安全不变量；不确定性必须在联合分布上分解，耦合歧义（模态/角色/相位）交给「双侧证据 + 分布式信息动作」消解；耦合不可信时，安全地拆回 R69 的两个单体闭环。** 命名 **DUET-RAS**（Dual-arm Uncertainty-aware Epistemic-coordination via imitation & flow）：像二重奏，两个演奏者可以各自很准，但只要不在同一小节里，合起来就是错的。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我的两只手，是否在相信同一个世界、同一件事、同一个时刻**」——不确定性不只是刹车、提问，也可以是两只手之间一句无声的「你准备好了吗」。

## 0. 直觉与动机

**灵感 1（双臂协调 → 不确定性是「关系」而非「标量」）**
直觉：R69 的 (U_ale, U_epi) 仍是「一个策略对自己的不确定」。双臂的关键不在两个策略各自多准，而在**两个动作之间的耦合**：两臂各自 95% 置信，联合却可能落在协调流形之外。独立从边缘分布采样，等于假设 I(ξ_L;ξ_R|o)=0；可双臂任务恰恰活在高互信息区。所以第一个新量不是「第二份不确定性」，而是**耦合强度 κ₂ 与协调残差 r_coord**：它们度量「这对动作是否还像同一个任务里长出来的」。

**灵感 2（模仿学习 → 示教给的是协调流形，不是标签）**
直觉：双臂怎么配合极难手写，但人示范一次就清楚。示教在联合动作空间里画的是一条**流形**（相对位姿可行、内部力在包络内、相位合法），而不是两个独立轨迹。行为克隆若逐臂回归，会最小化边缘误差却踩出流形；正确做法是学**联合分布 + 共享协调潜变量**：相对块先定「两手的相对关系」，各臂再在相对关系条件下生成残差。

**灵感 3（角色与相位 → epistemic 的结构化）**
直觉：双臂任务常有**主从**（一手持稳、一手操作）与**相位**（对准→咬合→交接→释放）。示教里没人标注谁是主，但力分配与谁先动会暴露。这个「谁是主、现在到哪一相」正是 R69 意义下的 epistemic（可约），且**只能靠双侧证据共同消解**——单臂看不见自己的角色。

**灵感 4（分布式信息动作 → MINT 的「单体交互」不够用）**
直觉：R69 的信息动作（看/问/触）属于一个身体。双臂里，用右手去探，左手必须**同时补偿**，否则内部力突变或物体掉落。于是信息动作天然是**成对、不可分割**的，VoI 必须在联合后验上算：一次右手探针可能主要消解的是左手的模态（跨臂信息转移）。交互从此多了一个维度：**谁来问、谁来回**。

**灵感 5（示教是新的攻击面）**
直觉：模仿学习把数据变成策略，也把数据变成**投毒入口**。恶意/退化示教能教会一个「协调但危险」的模式；主臂控制器被劫持可诱导从臂跟随；而逐臂标定能各自自洽，却让**相对位姿**悄悄漂移。R69 的 FMA（单臂流似然）对此有盲区，需要**联合似然第二意见**。

## 1. 形式化定义（增量：定义 310–330）

**定义 310（DUET-RAS 总览）** DUET-RAS = (CJI, CUD, CRM, RIL, DIC, LSG, CFM, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **协调一致性**：联合动作样本必须落在示教协调流形 ℳ_c 的 ε_c-邻域内（定义 314–315、326），否则拒绝/投影；
(iii) **双侧证据纪律**：消解角色/相位/耦合模态需 L、R 两个正交证据源一致（继承 293-iii 并升级为跨臂），否则 U_epi 保持未消解；
(iv) **示教来源纪律**：策略更新只接受通过来源/影响校验的示教（定义 322），实时环路只读。

**定义 311（双臂联合动作与相对量）** 场景动作 s∈𝒜_scene；左/右臂动作 a_L,a_R∈ℝ^{d_a}。联合块 ξ=(s,a_L,a_R)∈𝒜_2。位姿 T_L,T_R∈SE(3)，相对变换 T_rel = T_L^{-1}T_R。内部力 f_int 为沿闭合运动链的成对约束力（广义力分解 f = f_ext + f_int），满足 f_int ∈ ℱ_env(o)（定义 328）。外部量（物体位姿、接触点）由 s 承载。

**定义 312（协调潜变量）** 协调码 z_c∈ℝ^{d_c}（共享策略风格/刚度/相对位姿意图）；角色 ρ∈{L-lead, R-lead, symmetric}；相位 φ∈{align, engage, transfer, release}。联合示教分布分解为 p_D(ξ|o) = ∫ p(ξ|o,z_c,ρ,φ) p(z_c,ρ,φ|o) dz_c。z_c 是**两臂共享**的，不是每臂一份。

**定义 313（协调联合模仿 CJI）** 因子化流匹配：联合速度场 v_θ 拆为 v_scene、v_rel、v_L|rel、v_R|rel。相对流先生成 T_rel（或相对动作块），两臂残差以 (z_c, T_rel, ρ) 为条件生成。训练目标 L_CJI = E_{s,x_0,x_1}‖v_θ(x_s,s|o) − (x_1−x_0)‖²，其中 x_1 按 (scene, rel, L|rel, R|rel) 分块且**共享同一 z_c**。关键：条件在 T_rel 上采样两臂，而非独立边缘——联合相关性由相对块承载。z_c,ρ,φ 的先验由 RIL（定义 318）给出。

**定义 314（协调流形 ℳ_c）** 由示教支撑集定义的耦合约束 ℳ_c = {ξ : C(ξ;o) ≤ 0}，C 含 (a) 相对位姿可行域（物体尺寸/铰接/抓取点）；(b) 闭链可解性（两臂末端距离在可达范围内且不奇异）；(c) 内部力包络；(d) 时序相位合法（如未咬合前不得施加拧转力）。是 ℳ_c 的经验逼近。

**定义 315（协调残差 CRM）** r_coord(ξ,o) = ‖T_rel − Ĉ_rel(o)‖²_{Σ_rel} + λ_f‖f_int − f̂_int(o)‖² + λ_p‖φ̇ − φ̂̇‖²。运行时样本若 r_coord > ε_c：拒绝或投影回 ℳ_c。r_coord 是双臂版的「关节自洽残差」，但它**不出现在任何单体传感器残差里**。

**定义 316（协调不确定性 CUD）** 对联合样本做**联合**轨迹聚类（不是逐臂）得联合模态 {m_k}、权重 ŵ_k、联合协方差分块 Σ_k。分解：
- U_ale^self = (1/2)Σ_k ŵ_k [tr Σ_k^{LL} + tr Σ_k^{RR}]（臂内噪声，不可约）；
- U_ale^rel = Σ_k ŵ_k tr Σ_k^{rel}（相对量噪声，不可约，双臂特有）；
- U_epi^mode = H_mode·g(Δ_min)（联合模态歧义，R69 定义 297 的联合版）；
- U_epi^role = H(ρ|o)，U_epi^phase = H(φ|o)（结构化歧义）。
五者语义不同，不做简单加和，分通道处置（定义 325）。

**定义 317（耦合强度 / 协调必要性）** κ₂ = I(ξ_L; ξ_R | o, z_c)（互信息），或等价的 D_KL(p(ξ_L,ξ_R|o)‖p(ξ_L|o)p(ξ_R|o))。κ₂ 高 ⇒ 独立边缘采样必然破坏联合模态；κ₂≈0 ⇒ 两臂近似独立，DUET 退化为 R69 的并行两个单体策略。

**定义 318（角色/相位推断 RIL）** 训练识别器 q_ψ(ρ,φ|o, f_int, φ̇)，以**跨臂证据**（力分配、谁先动、谁承担载荷）为准；角色后验作为 CJI 的条件。角色/相位歧义是 epistemic，可由 DIC 主动消解；其先验错误由 MCG-D（定义 324）门控。

**定义 319（分布式信息动作 DIC，升级 MINT）** 信息动作对 g=(g_L,g_R)∈𝒜_info²。联合 VoI₂(g) = H(mode,ρ,φ|o) − E_{y~p(·|o,g)}[H(mode,ρ,φ|o,y)]；选择 g* = argmax_g [VoI₂(g) − c_L(g_L) − c_R(g_R) − c_couple(g)]，s.t. 双侧认证与预算。**跨臂信息转移**：用 g_R 探询可能主要降低 ρ 或 ξ_L 的歧义（右手轻拉一下，左手的位置才确定）——VoI₂ 的收益矩阵非对角。若无利可图或耦合成本过高 ⇒ 不交互，退化 R69。

**定义 320（双侧认证与内部力安全 IFE）** 信息动作对必须**同时**通过 C-RAS-WM 的两臂前缀认证、自碰撞/互碰撞检查、以及内部力包络 f_int ∈ ℱ_env；单侧越界 ⇒ 整对作废（不能只执行一半）。(定义 328) 定义信息动作的不可分割性：**信息动作不能只由一只手臂完成**。

**定义 321（联合流似然第二意见 CFM）** 在联合块上算 a_score² = −log p_θ(ξ|o)（Hutchinson 对联合维）；Δa² = |a_score²(o) − a_score²(o_cal)|。**逐臂标定可各自吸收自身偏置，但吸收不了相对位姿偏置**：若 T_rel 被偏置，联合似然升高而任一臂的 r_res 都可能很小。故 (r_res^L、r_res^R 均低, Δa² 高) ⇒ 疑似「协调层慢变故障」。这是 R69 引理 17 在关系维度的镜像。

**定义 322（示教投毒与来源纪律 DPG）** ℰ_demo = {退化示教（危险但自洽的协调模式）、主臂控制器劫持、跨臂共谋演示、标签/相位错标}。ℰ_DUET = ℰ_FLUID × ℰ_demo。策略更新用影响函数/来源加权限制单批示教的影响；J_DUET 记录 demo_provenance_hash、influence_p95。实时环路不更新策略，只做前向。

**定义 323（证书 J_DUET）** J_DUET = (J_FLUID, coupling_ECE, κ₂, U_epi^role/phase before/after, r_coord_p95, f_int_p99, demo_provenance_hash, influence_p95, duet_ver)。Valid ⇔ Valid(J_FLUID) ∧ 协调一致性满足 ∧ 双侧认证记录完整 ∧ 示教来源通过。

**定义 324（协调校准门 MCG-D）** 联合模态权重与角色后验需校准；ECE₂ > τ_ece 或角色校准错误 > τ_role ⇒ 禁用联合 VoI、退回**逐臂 R69**（各自保守）。即「耦合不可信时拆成两个单体闭环」——这是 DUET 对 R69 的安全退路，而非并列替代。

**定义 325（两级保守退避，含 Coordination Bonus）** 若联合歧义在预算内消解：λ₂ = λ_floor(U_ale^self + U_ale^rel)（获得 coordination bonus，比直接耦合更松但不更低安全）；若未消解/超时/投毒/耦合不可信：λ₂ = λ_floor(U_ale^self + U_ale^rel + U_epi^mode + U_epi^role + U_epi^phase)，且**两臂取同一 λ 上界**（否则一臂保守、一臂激进，内部力反而突变）。安全侧永不弱于逐臂 R69。

**定义 326（耦合投影与拒绝采样）** 若 r_coord > ε_c：优先投影 ξ ← Proj_{ℳ_c}(ξ)；投影后仍越界 ⇒ 拒绝，回退到示教中最近的安全模态；再不行 ⇒ 不动作（hold），走定义 325 的保守。保证生成的动作对始终在流形 ε_c 邻域。

**定义 327（主从引导 LSG，协作式 DAgger）** 主臂执行其模态 a_L；从臂以 (o, a_L, z_c, ρ) 为条件生成 a_R，而非以自身观测独立生成。训练时从臂向主臂/人类请求标签（协作式 DAgger）以减少复合误差；部署时若从臂条件似然低（CFM 报警），降速并请求人工接管。

**定义 328（内部力包络 ℱ_env）** 由物体材料/抓取点/任务给出 [f_int^min, f_int^max]；f_int < min ⇒ 可能掉落（接触丢失），f_int > max ⇒ 可能损坏/滑移。λ₂ 退避时**同时**收缩内部力上限（不是只降速）。

**定义 329（协调-标定对偶）** 逐臂标定吸收的分量在 (r_res^L, r_res^R) 中消失，但在 Δa²（定义 321）与 r_coord 的**相对**分量中保留；(r_res^L, r_res^R, Δa², r_coord) 的联合分布可分离「单臂真漂移」「协调层慢变故障」「物体参数变化」。R69 引理 13/17 的关系版。

**定义 330（时序耦合与自适应 K₂）** 联合采样的 K 针对**配对的联合模态**（不是每臂各 K），默认 K₂=1；mode_head₂(z) 预测联合歧义，仅当报歧义或 CFM 异常时升 K₂=4。保证配对采样的一致性，避免 K² 组合爆炸。

```python
# IP-264 CJI：协调联合模仿（相对块承载耦合，共享 z_c；复用 R69 trunk）
class CoordinatedJointImitator:
    def __init__(self, trunk, v_rel, v_scene, v_arm, ril, mode_head2, N_step=2):
        self.trunk, self.v_rel, self.v_scene = trunk, v_rel, v_scene
        self.v_arm, self.ril, self.mode_head2 = v_arm, ril, mode_head2

    def sample(self, o_t, K2, N_step=2):
        z = self.trunk(o_t)
        rho, phi = self.ril.posterior(o_t, f_int_hat=0.0, phi_dot=0.0)  # 先验
        zc = self.ril.sample_code(o_t, rho, phi, K2)
        rel = flow_sample(self.v_rel, cond=(z, zc), K=K2, N=N_step)      # 先定相对关系
        L   = flow_sample(self.v_arm, cond=(z, zc, rel, rho, 'L'), K=K2, N=N_step)
        R   = flow_sample(self.v_arm, cond=(z, zc, rel, rho, 'R'), K=K2, N=N_step)
        return [(rel[k], L[k], R[k]) for k in range(K2)]                  # 配对，不交叉组合

# IP-265 CUD：联合不确定性分解（不是逐臂分解）
def decompose_joint(pairs, z, rho_post, phi_post):
    modes = cluster_trajectories(pairs)                    # 联合聚类
    w     = mode_weights(modes)
    U_self = 0.5 * sum(w[k] * (trace(cov(modes[k])['LL']) +
                               trace(cov(modes[k])['RR'])) for k in modes)
    U_rel  = sum(w[k] * trace(cov(modes[k])['rel']) for k in modes)
    U_mode = entropy(w) * sep_factor(modes)
    U_role = entropy(rho_post); U_phase = entropy(phi_post)
    kappa2 = mutual_info(pairs['L'], pairs['R'], cond=z)   # 耦合强度
    return dict(U_self=U_self, U_rel=U_rel, U_mode=U_mode,
                U_role=U_role, U_phase=U_phase, kappa2=kappa2, modes=modes)

# IP-266 CRM：协调残差（相对位姿 + 内部力 + 相位速度）
def coordination_residual(rel, L, R, o):
    return (mahalanobis(rel, C_rel_hat(o), Sigma_rel)
            + LAMBDA_F * norm(f_int(L, R, o) - f_int_hat(o))**2
            + LAMBDA_P * norm(phi_dot(L, R) - phi_dot_hat(o))**2)

# IP-268 DIC：分布式信息动作（成对、跨臂 VoI、双侧认证）
def choose_bilateral_interaction(modes, w, o_t, budget):
    best = None
    for g in paired_info_candidates(modes):                # (gaze,probe,ask)_L/R
        if not budget.allow(g):                      continue
        if not c_ras_wm.certify_pair(g, o_t):         continue   # 两侧同时认证
        if not internal_force_ok(g, o_t):             continue   # IFE，整对
        voi2  = joint_entropy(w) - expected_joint_entropy(w, g, o_t)
        score = voi2 - cost_L(g) - cost_R(g) - coupling_cost(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None

# IP-269 LSG：主从引导的协作式 DAgger
def follower_action(o, a_L, zc, rho):
    return flow_sample(v_arm, cond=(trunk(o), zc, rel_of(a_L), rho, 'R'), K=1)

# IP-270 CFM：联合流似然第二意见（逐臂标定不能吸收相对偏置）
def joint_flow_anomaly(policy, xi_obs, o, o_cal):
    a_o   = -policy.log_likelihood_joint(xi_obs, o)       # 联合似然
    a_cal = -policy.log_likelihood_joint(xi_obs, o_cal)
    return abs(a_o - a_cal)                               # Δa² 高 + 两臂 r_res 低

# IP-275 主闭环（继承 FLUID-RAS，仅在耦合处置处插入 DUET 层）
def DUET_RAS_round(M, obs):
    z, o = M.mtm.forward(obs); c, U_cal, thr = M.cof.step(...)
    # 1) 联合歧义先验；仅歧义时多采样
    K2 = 1 if M.cji.mode_head2(z) < TAU_MODE2 else 4
    pairs = M.cji.sample(o, K2)
    # 2) 协调残差：不在流形上则拒绝/投影（定义 326）
    pairs = [project_or_hold(p, o) for p in pairs
             if coordination_residual(*p, o) < EPS_C or project_ok(p, o)]
    # 3) 联合分解 + 角色/相位后验
    d = M.cud.decompose_joint(pairs, z, M.ril.rho_post(o), M.ril.phi_post(o))
    # 4) 联合似然第二意见（逐臂标定吸收不了相对偏置）
    a2 = M.cfm.joint_flow_anomaly(M.cji, M.last_pair, o, M.calibrated(o))
    slow_pair = (a2 > TAU_FMA2) and (M.r_res_L < TAU_RES) and (M.r_res_R < TAU_RES)
    # 5) 耦合歧义可约则双侧交互；否则保守（或拆回 R69）
    U_epi = d['U_mode'] + d['U_role'] + d['U_phase']
    g = (M.dic.choose_bilateral_interaction(d['modes'], o, M.budget)
         if (U_epi > TAU_EPI2 and not slow_pair and M.mcg_d.ok()) else None)
    if g is not None: U_epi = M.dic.update_belief_joint(d['modes'], M.dic.execute_pair(g))
    # 6) 两臂同一 λ 上界（协调退避）
    U_floor = d['U_self'] + d['U_rel'] + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    if slow_pair or not M.mcg_d.ok():
        lam = max(lam, 0.8); return M.r69_fallback(obs)   # 拆回两个单体闭环
    # 7) 联合选模态 + 主从引导 + 耦合认证
    mode = select_joint_mode(d['modes'], U_epi, lam)
    k    = M.c_ras_wm.certified_pair_prefix(mode, ..., wm_preds)
    tau  = M.pi_sigma.prefix_dispatch_pair(mode, k) * lam
    M.vqa_d.submit_async(g, d, a2, M.demo_provenance)
    return k, lam, mode, d
```

## 3. 推导

**引理 19（独立边缘采样的耦合代价）** 设联合策略 p(ξ|o) 的耦合强度 κ₂ = I(ξ_L;ξ_R|o)，协调流形 ℳ_c 是联合密度的高密度支撑。若用边缘乘积 p_L p_R 采样，则 E_{p_Lp_R}[r_coord] − E_p[r_coord] ≥ c_ℳ·(1 − e^{−κ₂}) − ε_σ，其中 c_ℳ 由流形曲率与 r_coord 的 Lipschitz 常数决定。要点：两臂越耦合（κ₂ 越大），独立采样越必然踩出流形；κ₂→0 时差距消失，退化为两个独立问题。系：**协调收益正比于耦合强度，而非正比于「两臂都很难」**——两臂都难但相互独立时，拆开做反而更简单。

**引理 20（联合似然的相对偏置不可吸收性）** 逐臂标定 o_cal^L = o^L − r_cal^L，o_cal^R = o^R − r_cal^R 可各自吸收本臂偏置；但相对位姿偏置 δ_rel 是两臂偏置的**差**，在 o_cal^L、o_cal^R 中仍保留 δ_rel 分量。若 δ_rel 方向偏离联合策略主脊，则联合动作似然期望上升 ≥ L_rel‖δ_rel‖ − √(tr Σ_flow²)（A99：联合密度对相对条件 Lipschitz）。故 (r_res^L↓, r_res^R↓, Δa²↑) 是「协调层慢变故障」的判别模式，补 R69 单臂 FMA 的盲区。

**引理 21（角色可辨识性与探询的内部力代价）** 设两臂载荷不对称 |f_L − f_R| ≥ δ_f、主从时间差 |τ_lead| ≥ δ_t。在 ℱ_env 内，角色后验错误率 ≤ exp(−c·δ_f·δ_t/σ_f)。但主动增大载荷不对称（用于探询角色）会改变 f_int；当 f_int 触顶 f_int^max 时，角色可辨识性增益被内部力安全约束截断。系：**「问谁是主」会扰动内部力**——DIC 的 VoI 必须减去 IFE 的机会成本，这是 R69 单体 VoI 没有的耦合项。

**引理 22（示教投毒上界）** 设投毒示教比例 δ_d，影响权重 w_i，则策略在 OOD 协调模式上的偏差 ≤ δ_d·(max_i w_i / mean_i w_i) + ε_σ。系：来源加权/影响裁剪把「一批坏示教」的破坏力限制在单批影响分位内；与 R69 引理 18 的交互投毒上界同构——**数据投毒与交互投毒是同一枚硬币的两面**。

**定理 18（DUET 严格包含 FLUID-RAS）** 在 A99–A102 下：(a) 当 κ₂→0、角色/相位无歧义且耦合残差被逐臂残差支配时，DUET 的每臂边缘与 FLUID-RAS 的对应臂**逐指令相同**；(b) 当耦合存在时，DUET 的期望协调残差与内部力越界概率不高于「逐臂 FLUID + 事后检查」。因此 R69 是 DUET 在「解耦边界」上的退化，同时是 DUET 在「耦合不可信」时的安全回退（定义 324）。

**定理 19（协调安全与无突变）** 双侧认证（定义 320）⇒ 信息动作的物理风险 ≤ ε_int 且 f_int ∈ ℱ_env；耦合投影（定义 326）⇒ 执行动作对始终在 ℳ_c 的 ε_c 邻域；两臂共用同一 λ 上界（定义 325）⇒ 相对位姿变化率有界 ⇒ 内部力无冲击；退避只走「拒绝/投影/hold」三档且 λ 单调不降 ⇒ 控制连续、无突变。

**定理 20（协作式 DAgger 的复合误差）** 在 LSG 下，从臂条件于主臂真实动作 a_L 而非自身独立观测，标准 DAgger 论证给出从臂复合误差由 O(T²ε) 降为 O(Tε) + O(κ₂·ε_c)；耦合项随协调一致性提高而减小。系：主从结构不是「省一个策略」，而是**用已知的一臂把另一臂的分布外偏移拉回流形**。

## 6. 本轮最大风险

**一句话**：DUET-RAS 的全部收益押在「示教给出的协调流形 ℳ_c 能代表部署时的耦合」这一前提上——**若示教覆盖不到部署的物体/接触/角色组合，联合流会自信地生成「看似协调、实则在流形外」的动作对，协调残差与内部力在分布外同时失效**；于是它会把 R69 那种「诚实的单体不确定」升级为「被联合模型背书的错误协调」——**在错误的流形上协调得越顺，越危险**。

```python
        z = self.trunk(o_t)
        rho, phi = self.ril.posterior(o_t)
        zc  = self.ril.sample_code(o_t, rho, phi, K2)
        rel = flow_sample(self.v_rel, (z, zc), K=K2, N=N_step)     # 先定相对关系
        L   = flow_sample(self.v_arm, (z, zc, rel, rho, 'L'), K=K2, N=N_step)
        R   = flow_sample(self.v_arm, (z, zc, rel, rho, 'R'), K=K2, N=N_step)
        return [(rel[k], L[k], R[k]) for k in range(K2)]            # 配对，不交叉

# IP-265 CUD：联合分解（不是逐臂分解）
def decompose_joint(pairs, z, rho_post, phi_post):
    modes = cluster_trajectories(pairs); w = mode_weights(modes)
    U_self = 0.5*sum(w[k]*(trace(cov(modes[k])['LL'])+trace(cov(modes[k])['RR']))
                     for k in modes)
    U_rel  = sum(w[k]*trace(cov(modes[k])['rel']) for k in modes)
    U_mode = entropy(w)*sep_factor(modes)
    return dict(U_self=U_self, U_rel=U_rel, U_mode=U_mode,
                U_role=entropy(rho_post), U_phase=entropy(phi_post),
                kappa2=mutual_info(pairs['L'], pairs['R'], cond=z), modes=modes)

# IP-266 CRM：协调残差
def coordination_residual(rel, L, R, o):
    return (mahalanobis(rel, C_rel_hat(o), Sigma_rel)
            + LAMBDA_F*norm(f_int(L, R, o) - f_int_hat(o))**2
            + LAMBDA_P*norm(phi_dot(L, R) - phi_dot_hat(o))**2)

# IP-268 DIC：成对信息动作（跨臂 VoI + 双侧认证 + IFE）
def choose_bilateral_interaction(modes, w, o_t, budget):
    best = None
    for g in paired_info_candidates(modes):                 # (gaze,probe,ask)_L/R
        if not budget.allow(g):                 continue
        if not c_ras_wm.certify_pair(g, o_t):    continue   # 两侧同时认证
        if not internal_force_ok(g, o_t):        continue   # IFE，整对
        score = (joint_entropy(w) - expected_joint_entropy(w, g, o_t)
                 - cost_L(g) - cost_R(g) - coupling_cost(g))
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None         # 无利可图 → R69

# IP-269 LSG：主从引导的协作式 DAgger
def follower_action(o, a_L, zc, rho):
    return flow_sample(v_arm, (trunk(o), zc, rel_of(a_L), rho, 'R'), K=1)

# IP-270 CFM：联合流似然第二意见（逐臂标定吸收不了相对偏置）
def joint_flow_anomaly(policy, xi_obs, o, o_cal):
    return abs(-policy.log_likelihood_joint(xi_obs, o)
               + policy.log_likelihood_joint(xi_obs, o_cal))

# IP-275 主闭环（继承 FLUID-RAS）
def DUET_RAS_round(M, obs):
    z, o = M.mtm.forward(obs); c, U_cal, thr = M.cof.step(...)
    K2 = 1 if M.cji.mode_head2(z) < TAU_MODE2 else 4
    pairs = M.cji.sample(o, K2)
    pairs = [project_or_hold(p, o) for p in pairs]           # CRM 拒绝/投影
    d = M.cud.decompose_joint(pairs, z, M.ril.rho_post(o), M.ril.phi_post(o))
    a2 = M.cfm.joint_flow_anomaly(M.cji, M.last_pair, o, M.calibrated(o))
    slow_pair = (a2 > TAU_FMA2) and (M.r_res_L < TAU_RES) and (M.r_res_R < TAU_RES)
    U_epi = d['U_mode'] + d['U_role'] + d['U_phase']
    g = (M.dic.choose_bilateral_interaction(d['modes'], o, M.budget)
         if (U_epi > TAU_EPI2 and not slow_pair and M.mcg_d.ok()) else None)
    if g is not None: U_epi = M.dic.update_belief_joint(d['modes'], M.dic.execute_pair(g))
    U_floor = d['U_self'] + d['U_rel'] + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    if slow_pair or not M.mcg_d.ok():
        lam = max(lam, 0.8); return M.r69_fallback(obs)      # 拆回两个单体闭环
    mode = select_joint_mode(d['modes'], U_epi, lam)
    k    = M.c_ras_wm.certified_pair_prefix(mode, ..., wm_preds)
    tau  = M.pi_sigma.prefix_dispatch_pair(mode, k) * lam
    M.vqa_d.submit_async(g, d, a2, M.demo_provenance)
    return k, lam, mode, d
```

## 4. 推导

**引理 19（独立边缘采样的耦合代价）** 设耦合强度 `κ₂=I(ξ_L;ξ_R|o)`，ℳ_c 为联合密度高密度支撑。边缘乘积采样满足 `E_{p_Lp_R}[r_coord]−E_p[r_coord] ≥ c_ℳ(1−e^{−κ₂})−ε_σ`。系：协调收益正比于**耦合强度**而非「两臂都难」；两臂独立时拆开做更简单。

**引理 20（联合似然的相对偏置不可吸收性）** 逐臂标定吸收各自偏置，但相对偏置 `δ_rel` 是两臂偏置之**差**，在 `o_cal` 中保留；若偏离联合主脊，`a_score²` 期望上升 `≥ L_rel‖δ_rel‖−√(trΣ_flow²)`。故 `(r_res^L↓,r_res^R↓,Δa²↑)` 判别协调层慢变故障，补 R69 单臂 FMA 盲区。

**引理 21（角色可辨识性与探询的内部力代价）** 载荷不对称 `|f_L−f_R|≥δ_f`、时间差 `|τ_lead|≥δ_t` 时角色错误率 `≤exp(−cδ_fδ_t/σ_f)`；但主动增大载荷不对称会改变 `f_int`，触及 `f_int^max` 时辨识增益被 IFE 截断。系：**「问谁是主」会扰动内部力**，DIC 的 VoI 必须扣除 IFE 机会成本。

**引理 22（示教投毒上界）** 投毒比例 `δ_d`、影响权重 `w_i` 时，策略在 OOD 协调模式上偏差 `≤δ_d(max_i w_i/mean_i w_i)+ε_σ`；与 R69 引理 18 同构——数据投毒与交互投毒是同一枚硬币的两面。

**定理 18（DUET 严格包含 FLUID-RAS）** (a) `κ₂→0`、角色/相位无歧义且耦合残差被逐臂残差支配时，DUET 每臂边缘与 FLUID-RAS 对应臂**逐指令相同**；(b) 耦合存在时，DUET 的期望协调残差与内部力越界概率不高于「逐臂 FLUID + 事后检查」。R69 是 DUET 的「解耦边界」退化，也是「耦合不可信」时的安全回退。

**定理 19（协调安全与无突变）** 双侧认证 ⇒ 物理风险 `≤ε_int` 且 `f_int∈ℱ_env`；耦合投影 ⇒ 动作对恒在 `ε_c` 邻域；两臂共用 λ 上界 ⇒ 相对位姿变化率有界 ⇒ 内部力无冲击；退避只走「拒绝/投影/hold」且 λ 单调不降 ⇒ 控制连续、无突变。

**定理 20（协作式 DAgger 复合误差）** 从臂条件于主臂真实动作而非独立观测，复合误差由 `O(T²ε)` 降为 `O(Tε)+O(κ₂ε_c)`；耦合项随协调一致性提高而减小。系：主从结构是**用已知的一臂把另一臂拉回流形**，不是省一个策略。

## 7. 本轮最大风险

**一句话**：DUET-RAS 的全部收益押在「示教给出的协调流形 ℳ_c 能代表部署时的耦合」这一前提上——**若示教覆盖不到部署的物体/接触/角色组合，联合流会自信地生成「看似协调、实则在流形外」的动作对，协调残差与内部力在分布外同时失效**；于是它把 R69 的「诚实的单体不确定」升级为「被联合模型背书的错误协调」——**在错误的流形上协调得越顺，越危险**。

**次级风险与缓解**：耦合流形外推（CRM 拒绝/投影 + CFM 报警 + E314）；示教投毒/主臂劫持（来源加权 + 影响裁剪 + ℰ_demo 对抗训练 + E307）；角色推断错误（MCG-D 角色校准门 + 双侧证据 + 引理 21）；成对信息动作诱发内部力突变（双侧不可分割认证 + IFE + 定理 19）；联合采样组合爆炸（配对 K₂ 而非 K² + mode_head₂ 门控 + 定义 330）。

## 8. 与 R69 的承接（一句话）

R69 把不确定性从标量变成有形状的对象并学会提问；R70 指出**当有两个身体时，不确定性还有一个维度叫「关系」**——模态、角色、相位都只在两臂之间定义，协调一致性必须成为与安全包络并列的第一类不变量；R69 是 DUET 在耦合强度为零时、以及耦合不可信时的双重退化边界。
