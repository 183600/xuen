## 1. 两个灵感的第一性原理

### 灵感 1 ·「记忆检索」→ 从「≤3 维校准缓存」升级为「路标索引的记忆库」

**直觉解释**：人类专家不是把每一帧都记下来，而是记住「当前这种局面像过去哪一次」——**检索是记忆的接口**。VLA 的弱点恰恰是「只有现在、没有过去」：长程任务里它记不住自己做到第几步、上次为什么失败。检索式策略给它的不是更多参数，而是「按需取回的相关经验」。

**严谨表述**：检索增强策略 `a(o) = π_θ(o, R(o))`，其中 `R(o) = top-k_{j} d(φ(o), k_j)` 是从记忆库 `M={(k_j,v_j)}` 中按特征距离取回的条目；`v_j` 可以是软提示（MAP-VLA）、文本指令（MemER）、动作先验/子轨迹（ExpReS、STRAP）或关键帧（PrediMem）。学界的共识是：**检索能救长程，但会被错误的检索毒化**（负迁移），所以检索的「信任域」与「阶段约束」是关键。

**本轮的关键综合（真想法）**：第 2 轮把「记忆」当成 IP-11 里一个 ≤3 维的校准缓存，又把「路标断言」单独放在 IP-09——这是**同一个东西被拆成了两半**。一个路标的「记忆」天然同时是三样东西：

1. **到点断言**：`q_i(o) = 1[d(φ(o), ref_i) ≤ θ_i]`——「像不像到达该路标的那一次」；
2. **伺服目标**：从记忆条目里取回「专家在该路标附近的下一段状态」作为 PBVS 锚点；
3. **门控置信**：用同一距离 `d` 经滞回函数给出 `β`，决定多大程度交给伺服。

于是 **IP-13 WaypointMemory**：**一个检索度量，同时做断言、伺服目标、门控置信**。这解决了第 2 轮「IP-02/IP-09/IP-11 三套基础设施各自为政」的碎片化，也把「记忆检索」落到了可验证的窄机制上。

**必须切开的合规二分（本轮新增纪律）**：

- **静态记忆库**：从官方 32 项演示离线构建、随 checkpoint 冻结交付、运行时只读——**合规风险≈0**（它就是模型工件的一部分，不跨 episode 累积）。**优先交付这一半**。
- **动态会话记忆**：运行时把本队 episode 写回库、跨 episode 复用——**仍是灰色（Q9）**，且 ExpReS 证明「失败样本」能显著提分，诱惑很大，但默认关。**先用 E635 证明它对静态库的增量是否值得冒红线**。

**顺带解决负样本困境的一半**：静态库里除了成功条目，还可放「近失败的正样本」（专家临界修正段）+ IP-10 合成的失败段，做对比检索；这比第 2 轮「只有成功演示」的监督面宽了一层。

### 灵感 2 ·「专利布局」→ 护城河的「法律半衰期」

**直觉解释**：技术护城河问的是「对手多久能抄」，专利布局问的是「对手抄了你能不能拦、你做了会不会被告」——**这是两件正交的事**。第 2 轮我们只算了前者（可抄速度），把「真机标定工程密度」当成天然护城河；但真机标定做得再好，如果架构落在别人的授权权利要求里，那护城河是**别人家的护城河**。

**严谨表述（初步、非法律意见）**：对机制 `m` 与专利 `p` 的权利要求集合 `C_p`，定义**落入风险** `R(m,p)` 为「`m` 是否满足 `C_p` 中某条权利要求的全部限定」。判专利布局强弱，看四件事：**权利要求范围**、**可检测性**（能不能从产品行为看出你在用）、**可执行性**（管辖/主体）、**自有 prior art**。纯算法在美国受 Alice/§101 约束，通常必须绑定「传感器→策略→执行器」的物理系统才可执行——这正是 Figure/Google 把分层动作模型写成「机器人系统」的原因。

**护城河反转（本轮核心结论）**：当上游宽架构被大厂圈占时，系统的可守性不再等于架构可守性，而等于**窄、可检测、可测量组件的可守性 + 迭代基础设施 + 速度**。据此重估我们自己的 IP（初步）：

| 我们的机制 | 专利面初步判断 | 处置 |
|---|---|---|
| IP-09 的「宽分层执行栈」（VLA 规划 + 伺服低层） | **落入风险高**：Figure US12638859B2（Beta+Alpha+low-level controller）、Google US11210585B1（高/低层+重发信号判定） | **不作为护城河宣称**；只保留窄的「断言置信→滞回 β」作为差异点 |
| IP-13 的「宽检索增强策略」 | 风险中高：Google EP4711097A1 + 大量学术 prior art | 只作组件，不宣称新颖 |
| **IP-13 的窄机制**：路标索引的单一检索度量同时产断言/伺服/门控 | 初步看**窄而可能新颖**（需 claim chart） | **防御性公开**（抢 prior art，防被圈占） |
| **IP-10 的窄机制**：合成负样本的分布闸门（MMD+判别器验收） | 初步看**窄而可能新颖** | 防御性公开；若确要商业化再评估临时申请 |
| **IP-03 的窄机制**：chunk 边界 jerk 最小化缝合 | 窄工程，初步风险低 | 防御性公开 |
| **IP-06 的失败因子分解评测** | 评测方法，专利客体性弱 | **开源建声誉 + 先发**，不申请 |
| 训练配方 / 数据策展 / 课程权重 | 不可检测 | **商业秘密**，绝不公开 |

**一句话策略**：**能开源的开源（评测栈、窄机制），能保密的不说（配方、数据），能专利的极少（只有既窄又可检测又真要商业化的才申请）。** 比赛技术报告本身，就是一次带时间戳的防御性公开。

> **免责**：以上是研究者的技术映射，不是法律意见；实际 FTO 必须由专利律师做 claim chart。且**参加比赛（研究用途、不销售）通常不构成专利侵权**，风险主要在赛后商业化/衍生公司。

## 2. 研究问题（本轮新增，编号接上轮 Q1–Q9）

- **Q10（三合一检索的一致性）**：同一检索度量 `d` 能否同时充当路标断言、伺服目标与门控置信而不互相打架？断言阈值 `θ`、伺服锚点、`β` 滞回三者能否由同一条「距离-精度」曲线统一标定？（E628/E631）
- **Q11（静态记忆的净收益与负迁移）**：从官方演示建静态记忆库，对长程/插入类任务的净增益多大？在 OOD 查询上何时由帮助转为毒化（负迁移）？（E629/E630）
- **Q12（动态记忆的增量是否值得红线）**：跨 episode 动态记忆相对静态库的增量收益是多少？若接近 0，就干脆放弃这条最高合规风险线（把 Q9 一次性关闭）。（E635）
- **Q13（FTO 与可守性）**：我们 14 个 IP 里，哪些落入现有权利要求、哪些落在空白、哪些应防御性公开、哪些留商业秘密？（E633/E634，非法律意见）
- **Q14（赛制 IP 归属，待外部）**：提交物与技术报告的知识产权归属、是否强制公开、能否赛后申请专利？需 Feishu 规则手册可读版本确认。

## 3. 设计原则（新增 P10–P12，接上轮 P1–P9）

- **P10（记忆即断言）**：路标断言、伺服目标、门控置信必须共享同一检索度量与同一记忆库；禁止再新增独立的、彼此不一致的检测器。
- **P11（静态优先，动态存疑）**：只交付随 checkpoint 冻结的静态记忆库；动态跨 episode 记忆必须有 E635 的显著增量证据 + 书面合规确认，否则删除。
- **P12（专利清醒）**：任何被当作「护城河」的机制，先过 FTO/可检测性映射；宽架构不作为护城河宣称；窄机制默认防御性公开，配方默认商业秘密。

## 4. 清单处置（深化 / 修剪 / 新增）

- **深化**：IP-11（SessionMemory）→ 拆为 **IP-13 WaypointMemory（静态记忆库，P0 新增）** 与「动态会话记忆（降级为 P3 条件项）」；IP-09（WaypointServo）**重定界**——护城河价值从「宽分层栈」收缩到「断言置信→滞回 β 的窄门控」，并把断言实现改挂到 IP-13 的检索度量上；IP-02（抓握确认）并入 IP-13 的路标断言家族（抓握=一个特殊路标）。

- **修剪**：IP-11 动态记忆降为 P3（仅当 E635 显著才恢复）；IP-07 DualSpace 继续暂存；IP-08 继续并入 IP-03。

## 5. 本轮最大风险（一句话）

**我们以为在筑护城河，实际是在别人的已授权专利（Figure 分层动作模型、Google 高低层控制器与检索调制）上施工，同时把「检索」误当成免费记忆——静态库在 OOD 查询上会负迁移，动态库的合规红线又未关闭。**

### IP-13 · WaypointMemory 路标索引检索式记忆（P0，新）

## 5. 符号与定义（新增 U16–U18；U1–U15 沿用前两轮）

- **定义 U16（记忆库与检索）**：`M = {(k_j, v_j)}_{j=1..N}`，`k_j` 为键（路标标签 `p_j` + 视觉/位姿描述子），`v_j` 为值（专家子轨迹片段 + 断言参考）。检索 `R(o) = argmin_j d(φ(o), k_j)`，`φ` 为冻结视觉编码器；阶段约束把候选限制在 `|p_j − p_cur| ≤ 1`。
- **定义 U17（三合一检索）**：对路标 `w_i`，设检索距离 `d_i(o)=d(φ(o), ref_i)`。**断言** `q_i(o)=1[d_i ≤ θ_i]`；**伺服目标** `g_i = next_state(v_{i*})`（`i*` 为检索命中条目）；**门控** `β = σ((θ_i − d_i)/τ_h)` 且带滞回（升/降阈值不同）。三者共享同一 `d_i`、同一记忆库（P10）。
- **定义 U18（落入风险与防御性公开）**：对机制 `m` 与专利 `p` 的权利要求 `c ∈ C_p`，`R(m,p)=1` 当 `m` 满足 `c` 的全部限定（初步技术判断）。防御性公开：在时刻 `t0` 以可实施方式公开 `m`，使任何 `priority > t0` 且主张 `m` 的申请丧失新颖性。

```python
# ===== IP-13: 路标索引记忆 + 三合一检索（替换 v2 的 IP-09/IP-11 分离实现）=====
def build_static_memory(demos, labeler):
    M = []
    for ep in demos:                       # 官方成功演示（只读、随 checkpoint 交付）
        wps = labeler.waypoints(ep)        # IP-06 阶段标注
        for kf in extract_keyframes(ep):   # 夹爪跳变 + EE 速度极小/转向
            M.append(dict(key=encode(kf.obs),
                          label=kf.stage,
                          value=kf.subtraj,      # 专家后续子轨迹（动作先验/伺服锚）
                          ref=kf.obs))           # 断言参考帧
    return freeze(M)                       # 冻结：不写回、不跨 episode 累积（P11）

def retrieve(M, o, stage):
    cand = [m for m in M if abs(m.label - stage) <= 1]      # 阶段约束
    return min(cand, key=lambda m: d(phi(o), m.key)) if cand else None

def execute_step(self, s, obs):
    m = retrieve(self.M, obs, s.phase)
    if m is None or d(phi(obs), m.key) > self.rho_trust:    # Level-1.7 回退
        return self.model.act(obs, s.task_token, s.phase, s.ctx)
    di = d(phi(obs), m.key)
    q  = di <= self.theta[m.label]                          # U17 断言
    beta = self.hysteretic_gate(di, self.theta[m.label])    # 门控置信（滞回）
    a_vla = self.model.act(obs, s.task_token, s.phase, s.ctx)
    u = self.servo_to(m.value)                              # 伺服锚点来自记忆
    if q: s.wp_idx += 1; s.assert_fail = 0
    else: s.assert_fail += 1
    if s.assert_fail >= self.patience: return self.intervene(s, obs)
    return (1 - beta) * a_vla + beta * u
```

## 7. 推导（新增引理 L11–L13；L1–L10 沿用前两轮）

**引理 L11（检索-断言一致性）** 设断言由检索距离定义 `q_θ(o)=1[d(o)≤θ]`，到达/未到达两类查询在 `d` 上的分布为 `D_in, D_out`。则误报率 `FP(θ)=P_{D_out}(d≤θ)` 与召回 `TP(θ)=P_{D_in}(d≤θ)` 均关于 `θ` 单调增。故「高精度低召回」的保守介入（第 1 轮要求）等价于**选一个偏小的 `θ`**——精度-召回是单旋钮权衡；若两类在 `d` 上可分（`d_in < d_out` a.s.）则存在零错误阈值。∎

**引理 L12（检索负迁移的信任域）** 设记忆条目的动作先验误差在特征空间 Lipschitz：`‖v_j − π*(o)‖ ≤ L·d(φ(o),k_j)`。检索命中 `j*` 时误差 `≤ L·d_min(o)`。若 `d_min(o) > ρ_trust ≜ sup{d : L·d ≤ err_base(o)}`，则检索先验未必优于基线 VLA，且可能更差（负迁移）。故**仅在 `d_min ≤ ρ_trust` 时启用检索/伺服，否则回退基线**（Level-1.7）。∎

**引理 L13（防御性公开的期望成本）** 设机制 `m` 在 `t0` 被可实施地公开，则任何 `priority>t0` 主张 `m` 的申请因缺乏新颖性而不可授权（假设该公开在其管辖内构成 prior art）。故公开使「被上游圈占」的期望成本降至 0，代价是丧失保密价值 `S`。决策规则：当 `S < E[圈占成本] + 公共品收益` 时公开。推论：**不可检测的配方/数据 `S` 高 → 保密；可检测的窄机制 `S` 低而圈占成本高 → 公开**。∎
