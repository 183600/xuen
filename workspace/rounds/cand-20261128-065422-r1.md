### 第 6 轮灵感驱动研究记录（CADVS-v6：结构-传动-健康一体化认证 CECD）

**灵感词**：结构优化、谐波减速器

**继承关系**：第 5 轮 CADVS-v5（IP-493~496）确立「认证的生成式执行」（CGE）：七硬门 fail-closed 不增（覆盖/物理/人因/末点/记忆/价值/平衡）、条件流匹配提议 π_θ^FM、LMEM-v2 记忆固化、FAMK 情感非对称调制、执行集嵌套 Exec_CADVS-v5 ⊆ Exec_CADVS-v4 ⊆ … ⊆ Exec_v29。本轮不推翻 v5，而是补 v5 的三个结构性短板：(a) v5 的证书隐含「刚性关节 + 理想执行」假设，而真实关节普遍使用**谐波减速器**——柔轮弹性、迟滞、丢失运动、传动误差使「指令位姿 ≠ 实际位姿」，逐点证书在实机上可能失效；(b) v5 只认证「给定机器人做什么」，没有把**本体结构**当作可优化、可认证的对象，而结构（连杆拓扑、柔轮壁厚、齿形、减速比）恰好决定柔度、承载与疲劳，从而决定可执行集的大小；(c) v5 的执行集只随记忆/情感收紧，缺少随**磨损与疲劳**单调收缩的物理机制，也缺少独立于「铸证→学习」回路的物理真值。两个灵感词统一为主题「**认证的具身协同设计**」（Certified Embodied Co-Design, CECD），形成 CADVS-v6（IP-501~504）。本轮自律：**硬门仍为七个**，不增不减；新增能力只走三条非侵入路径——**集合化**（把传动不确定性提升为区间/zonotope 语义，收紧既有门）、**设计化**（结构优化是离线设计时过程，产出冻结的设计证书，只收紧在线限值）、**健康化**（疲劳损伤作为物理记忆，单调降额，收紧 kc_physics）。执行集嵌套升级为 Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ … ⊆ Exec_v29。

**直觉与动机**：

1. **谐波减速器 → 把「指令轨迹」升级为「实际可达轨迹管」，证书从点谓词变为集合谓词**。直觉：谐波减速器像一根有记忆的弹簧——同样一条电机侧指令，轻载与重载、上行与下行、历史不同，输出角都不同；柔轮还会储能，接触突然丢失时把能量放出来。所以 v5 在指令轨迹上成立的 ZMP、摩擦锥、末点误差，**推不出**实际轨迹成立。严谨化：定义关节传动关系 θ_o = θ_m/N − δ + e，其中 δ 为扭转柔度（由单调非线性刚度 K 与有界迟滞 H 给出，|H|≤h_max），并含丢失运动死区与周期传动误差 |e|≤e_max。给定指令轨迹与逆动力学力矩估计，实际输出落入区间集 Θ_j(x)，经雅可比与区间/zonotope 传播得到 Cartesian 可达管 Z(x)。把每个门从点谓词提升为**鲁棒门** kc_i^rob(x)=1[inf_{x'∈Z(x)} s_i(x') ≥ τ_i]。因名义点属于 Z(x)，inf ≤ 名义值，故 kc^rob ⇒ kc，执行集只缩（定理 9）。柔轮储能另给出**弹性储能合取**：E_el=Σ∫_0^{δ_j}K_j(u)du ≤ E_max(q)，E_max 由捕获点裕度反推（定理 10）；它作为 kc_balance 的合取项，只紧不松。

2. **结构优化 → 把「本体结构」提升为设计变量，做证书约束的协同设计**。直觉：如果减速器更刚、迟滞更小、承载更高、疲劳寿命更长，可执行集就更大；但更刚/更强往往更重，且制造公差让实际结构与标称不同。所以目标不是「优化性能」，而是「**在证书约束下最大化可认证执行集**」。严谨化：设计变量 d 含连杆拓扑密度场、截面、柔轮壁厚、齿形、减速比与材料；设计证书 DC(d)=⟨d, Tol(d), E_env, O1~O5⟩，要求对公差盒内所有 d' 与声明包络内所有 x，鲁棒门成立、疲劳寿命 ≥L_min、应力 ≤σ_lim、质量 ≤m_max。目标 max_d Vol(Exec_gate(d))。定义设计占优偏序 d'⪰d（不确定半径更小、认证承载更高、寿命更长），证明 Exec_gate 对 ⪰ 单调（定理 11），于是设计搜索可按占优关系剪枝。结构优化离线小时级，产出冻结证书；在线只消费保守限值 τ_max^cert 与 r_max，绝不改在线门。

3. **疲劳/健康 → 把「磨损与疲劳」变成单调收缩的物理记忆，并提供外生真值**。直觉：柔轮是消耗件，损伤累积后承载下降；继续用新机限值就是过度声明。严谨化：Miner 损伤 D(t)=Σ n_k/N_f(τ_k) 单调不减；降额因子 τ_max(D)=ρ(D)·τ_max^cert，ρ 单调不增；证明 D_2≥D_1 ⇒ Exec_v6(D_2)⊆Exec_v6(D_1)（定理 12），D≥D_crit 时只允许维护位姿（fail-closed）。损伤由力矩/应变传感器测量并用保守上界 D̂_hi 更新（引理 47），这条通道与「铸证→学习」回路不同源，为 R57 提供部分外生锚点。设计令牌 d_fp 与健康状态进入流条件，但按 v5 定理 6 只改提议、不改门（定理 13）。

**关键洞见**：v5 回答「提议任意、记忆反哺、情感调制下证书边界如何不变」；v6 回答「**当执行器本身是有记忆、有柔度、会疲劳的谐波减速器，当本体结构可以被优化，当安全必须随磨损单调收缩时，如何把证书从『刚体点谓词』推广为『集合谓词 + 设计证书 + 健康降额』，且不新增硬门**」。七门 kc_evidence_forged_v5 原样复用；新增只有：传动鲁棒门 kc^HD（对 kc_physics/kc_balance/kc_ee 的集合化收紧）、弹性储能合取 kc_bal^E、设计证书 DC（离线治理）、健康降额 kc_phys^H、设计/健康条件令牌。Exec_v6 = {x∈supp(π(·|c,d_fp,D)) : ∧_i kc_i^rob(x) ∧ kc_bal^E(x) ∧ kc_phys^H(x;D)=1} ⊆ Exec_v5。

**形式化目标（增量）**：
1. 传动模型：δ_j=θ_m,j/N_j−θ_o,j，τ_j=K_j(δ_j)+H_j[δ_j]，|H_j|≤h_max,j；丢失运动 δ∈[δ_lo,δ_hi]，传动误差 |e_j|≤e_max,j；实际输出集 Θ_j(x) 与 Cartesian 管 Z(x)（zonotope，含线性化误差项）。
2. 鲁棒门：kc_i^rob(x)=1[inf_{x'∈Z(x)} s_i(x')≥τ_i]；仿射门用支撑函数精确求下确界，非线性门用 Lipschitz 保守界。
3. 弹性储能：E_el=Σ_j∫_0^{δ_j}K_j(u)du，E_max(q)=½·M_eff(q)·(d_cap(q)/T_cap)²；kc_bal^E=1[E_el≤E_max(q)]。
4. 设计证书：DC(d)=⟨d,Tol(d),E_env,O1~O5⟩；协同优化 max_d Vol(Exec_gate(d)) s.t. DC；设计占优偏序与单调性。
5. 健康：Ḋ=Σ_j(|τ_j|/τ_ref,j)^{m_j}/T_ref,j，τ_max(D)=ρ(D)·τ_max^cert，单调收缩与 D≥D_crit 时 fail-closed。
6. 定理 9（传动鲁棒健全/嵌套）、定理 10（储能安全界）、定理 11（设计单调性/证书健全）、定理 12（健康单调收缩）、定理 13（设计-策略解耦/提议无关性保持）；引理 45~47。
7. EFA-v6：七门 + 鲁棒门 + 储能 + 健康降额；ECS_v6=ECS_v5·η_trans·η_health。

**本轮最大风险**：结构优化会主动把设计推到证书最紧的模型边界，而谐波减速器的迟滞、丢失运动与柔轮疲劳在真实装配、磨损、温度下偏离模型，设计证书在仿真内自洽却在实机上失效——优化越成功，越贴近不可证的边界。

## 2. 关键算法骨架

### IP-501 HTCK：谐波传动证书核（在线，准入时域；控制环只读缓存）

```python
@dataclass
class HarmonicTransmissionCertificateKernel:
    """HTCK：把指令轨迹映射为实际可达管 Z(x)，在管上取门裕度的下确界。
    定理 9：Z(x) 含真实状态 ⇒ 鲁棒门通过 ⇒ 名义门通过 ⇒ Exec_v6 ⊆ Exec_v5"""
    K: list            # 每关节单调非线性刚度 K_j(·)（分段线性/样条，单调）
    h_max: np.ndarray  # 迟滞上界 h_max,j
    delta_lost: np.ndarray
    e_max: np.ndarray
    N: np.ndarray

    def torsion_interval(self, tau):
        # K 单调 ⇒ 由力矩区间反解 δ 区间；迟滞与丢失运动并入端点（保守）
        lo = invK(self.K, tau - self.h_max) - self.delta_lost
        hi = invK(self.K, tau + self.h_max) + self.delta_lost
        return lo, hi

    def reachable_tube(self, x_cmd, tau_est, q):
        lo, hi = self.torsion_interval(tau_est)
        dq = Interval(lo - self.e_max, hi + self.e_max)   # 关节空间盒
        J = jacobian(q)
        Z = zonotope(center=p(q), generators=J @ dq)      # 一阶传播
        Z = Z.minkowski_sum(ball(eps_lin(q, dq)))         # 线性化误差包络
        return Z

    def robust_margin(self, gate, Z):
        # 仿射门：支撑函数给出精确下确界；非线性门：Lipschitz 保守界
        if gate.is_affine:
            return gate.b + gate.a @ Z.c - np.sum(np.abs(gate.a @ Z.G))
        return gate.s(Z.c) - gate.L * Z.radius()

    def kc_robust(self, x_cmd, tau_est, q, gates, tau):
        Z = self.reachable_tube(x_cmd, tau_est, q)
        return all(self.robust_margin(g, Z) >= tau[i] for i, g in enumerate(gates))

    def elastic_energy(self, tau):
        _, hi = self.torsion_interval(tau)
        return sum(intK(self.K[j], hi[j]) for j in range(len(self.K)))  # 保守上界

    def kc_energy(self, tau_est, q):
        E = self.elastic_energy(tau_est)
        E_max = 0.5 * M_eff(q) * (capture_margin(q) / T_cap) ** 2
        return E <= E_max
    # 注：区间传播与支撑函数均为 O(n_joint + G)；准入时域完成，不进 1 kHz 环
```

### IP-502 SCDO：结构协同设计优化器（离线小时级，产出冻结 DC）

```python
@dataclass
class StructuralCoDesignOptimizer:
    """SCDO：证书约束的结构优化（RBDO + 拓扑）。
    定理 11：设计占优 ⇒ 可执行集单调；DC 对公差盒内所有设计成立才冻结"""
    design_space: DesignSpace     # 拓扑密度场、截面、柔轮壁厚、齿形、减速比、材料
    tol: ToleranceBox
    env: OperatingEnvelope        # 声明包络 E_env
    mass_max: float
    L_min: float
    sigma_lim: float

    def worst_case(self, d):
        # 公差盒 + 装配偏差内取最坏：最大柔度、最大迟滞、最小承载、最小寿命
        return argmin_over(self.tol, d, key=lambda d2: feasibility_margin(d2))
```

### IP-503 SHFL：结构健康与疲劳账本（在线 O(1)/周期）

```python
@dataclass
class StructuralHealthFatigueLedger:
    """SHFL：Miner 损伤单调累积 → 单调降额 → 执行集单调收缩。
    定理 12：D2 ≥ D1 ⇒ Exec_v6(D2) ⊆ Exec_v6(D1)；D ≥ D_crit 只允许维护位姿"""
    tau_ref: np.ndarray
    m_exp: np.ndarray
    T_ref: np.ndarray
    D_crit: float = 0.85
    p: float = 1.0
    D: float = 0.0

    def update(self, tau_meas, dt, sigma_meas):
        rate = np.sum((np.abs(tau_meas) / self.tau_ref) ** self.m_exp) / self.T_ref
        # 测量不确定 ⇒ 取保守上界；无测量时用模型最坏力矩，绝不低估
        self.D = min(1.0, self.D + rate * dt + 3.0 * sigma_meas * self.sens)

    def derate(self, tau_max_cert):
        if self.D >= self.D_crit:
            return 0.0                      # 只允许维护位姿（fail-closed）
        rho = 1.0 - (self.D / self.D_crit) ** self.p
        return rho * tau_max_cert
```

## 4. 正确性论证（增量更新）

### 引理 45（传动包络健全性）

**陈述**：设 K_j 单调递增，迟滞 |H_j|≤h_max,j，传动误差 |e_j|≤e_max,j，丢失运动半宽 δ_lost,j。则对任意真实传动状态，输出角 θ_o,j ∈ [θ_m,j/N_j − δ_hi,j + e_j, θ_m,j/N_j − δ_lo,j + e_j]；一阶 zonotope 传播附加的线性化误差可被 ε_lin(q,Δq)=O(‖Δq‖²) 包络，故真实 Cartesian 位姿 ∈ Z(x)。∎

**证明要点**：K 单调 ⇒ τ−h_max ≤ K(δ) ≤ τ+h_max 可反解为 δ 区间；迟滞与丢失运动只会扩大区间；传动误差按界加入；对非线性正运动学在标称点一阶展开，余项由 Hessian 范数乘 Δq² 界定。

### 引理 46（迟滞记忆有界）

**陈述**：Preisach/Bouc-Wen 类迟滞算子输出只依赖输入历史，且存在 h_max 使 |H_j[δ](t)|≤h_max,j 对所有历史成立。因此区间端点与记忆状态无关，引理 45 的区间传播是健全的（可能保守，但绝不低估偏差）。∎

### 引理 47（疲劳损伤保守上界）

**陈述**：设力矩/应变测量噪声有界、S-N 参数取保守分位、无测量时用模型最坏力矩，则 Miner 损伤估计满足 D̂_hi(t) ≥ D_true(t) 以概率 ≥1−δ。用 D̂_hi 降额是 fail-safe 的。∎

### 定理 9（传动鲁棒健全与嵌套）

**陈述**：在引理 45 下，若 kc_i^rob(x)=1，则真实状态通过原门 kc_i；且 kc_i^rob ⇒ kc_i，故 Exec_v6 ⊆ Exec_v5。∎

### 定理 10（弹性储能安全界）

**陈述**：E_el(x) ≤ E_max(q)=½M_eff(d_cap/T_cap)² ⇒ 接触丢失时 CoM 速度扰动 Δv ≤ d_cap/T_cap ⇒ 捕获点裕度不被弹性释放吞没。∎

**诚实边界**：该界把弹性释放全部计入 CoM 动能（保守）；多接触/多关节同时释放时 M_eff 取最小特征值才健全，否则可能低估。

### 定理 11（设计单调性与证书健全）

**陈述**：设计占优 d'⪰d ⇒ Exec_gate(d') ⊇ Exec_gate(d)；若 DC(d) 的 O1~O5 对 Tol(d) 全成立，则在线保守限值 τ_max^cert/r_max 对公差内真实机器人健全。∎

**诚实边界**：单调性只对 gate 定义集成立；提议支撑随 d_fp 变化，采纳率可能下降，但不影响安全。

### 定理 12（健康单调收缩与 fail-closed）

**陈述**：Ḋ≥0、ρ 单调不增 ⇒ D_2≥D_1 ⇒ Exec_v6(D_2)⊆Exec_v6(D_1)；D≥D_crit ⇒ 只允许维护位姿。∎

### 定理 13（设计-策略解耦/提议无关性保持）

**陈述**：d_fp 与 D 只进入提议条件，不进入门谓词；由 v5 定理 6，执行边界与提议无关，换设计/换策略只改采纳率，不改 fail-closed 边界。∎

### 定理 v6（执行集多重收缩，总装）

**陈述**：在 v5 (B1)~(B7) 与新增 (B8) 传动包络健全、(B9) DC 对公差盒成立下：(i) Exec_v6 ⊆ Exec_v5 ⊆ … ⊆ Exec_v29；(ii) 鲁棒健全（定理 9）；(iii) 储能安全（定理 10）；(iv) 设计单调与证书健全（定理 11）；(v) 健康单调收缩（定理 12）；(vi) 提议无关性保持（定理 13）。∎

## 7. 本轮最大风险（最终确认）

**一句话**：**结构优化会主动把设计推到证书最紧的模型边界**——谐波减速器的迟滞、丢失运动与柔轮疲劳在真实装配、磨损、温度下偏离模型，设计证书在仿真内自洽却在实机上失效，且优化越成功越贴近不可证的边界；公差盒 RBDO + 双模型交叉验收 + 破坏性抽检只能降低而无法根除。
