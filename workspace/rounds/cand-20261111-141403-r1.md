# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「模型量化」×「平衡控制」）

> 第 54 轮把技能组合推进到动作空间剖面 `α_S`、组合图 `G_S` 与云边联合证书 `J`。本轮把“部署时的数值现实”引入闭环：**模型量化**改变动作剖面的边界与鲁棒性谱，**平衡控制**提供判定“量化到什么程度仍然安全”的物理标尺。核心矛盾：H22：量化误差不是各向同性的均匀噪声，而是沿鲁棒性维度 `d` 与动作边界 `∂A_S` 非均匀侵蚀，导致 `compat` 与 `cover` 在高精度下成立、在 INT8/INT4 下“虚假成立”；H23：平衡控制回路对量化最敏感，粗粒度位宽分配会把“可接受的平均误差”放大成极限环与瞬态失稳，而现有证书只约束任务成功率、不约束平衡余度。

## 0. 直觉与动机

**灵感 1（量化 → 不是全局误差，而是维度-边界敏感度）**
直觉：把量化看成对模型参数 `θ` 的一次有界扰动 `ε_q`。对任务成功率而言，重要的不是 `||ε_q||` 本身，而是它在鲁棒性维度上的投影 `χ_S(d,b) = ρ_S(d;b_ref) − ρ_S(d;b)`，以及它在动作空间边界上造成的**死区**：原本 `α_S(a) ≥ θ_cov` 的边缘动作，量化后会掉到阈值以下。于是“技能还能不能用”变成一个**敏感度剖面 + 动作收缩**的问题，而不是一个全局精度数字。

**灵感 2（平衡控制 → 量化的物理安全标尺）**
直觉：平衡是机器人最不容忍数值误差的闭环。用 ZMP/CoM 余度 `m_B` 与平衡控制器的 Lyapunov 收缩率 `λ_B` 可以把量化误差翻译成一个可判定的安全条件：`m_B ≥ L_B·ε_q/λ_B + δ_safe`。这把“位宽”从工程超参变成受物理约束的控制量：不是“能压多小”，而是“在给定平衡余度下允许压多小”。

**灵感 3（混合精度 → 按平衡关键性分配位宽）**
直觉：感知/语义层可以 INT8 甚至 INT4，平衡/力控底层必须保留更高位宽。**平衡感知位宽分配 BAQ** 把总比特预算按“边际鲁棒性增益/比特 × 平衡关键性权重”做水填充，并给平衡关键层设**硬性安全位宽地板**。这样量化预算不再是均匀的，而是与第 54 轮的动作剖面和鲁棒性谱耦合。

**灵感 4（量化-平衡契约 → 云全精度、边量化执行）**
直觉：云端可保留 FP16 做规划，边端必须量化部署。二者之间需要一个**精度契约**：云端承诺动作核心 `A_core` 及参考鲁棒性 `ρ_ref`，边端用位宽 `b_e` 执行并回传 `(ε_q, ρ_q, B_cert, Explain_q)`。若边端平衡余度跌破安全线或 `ρ_q` 掉出预算，则触发**升位**或回退云端重规划。这把第 54 轮的 `γ_ce` 扩展为带精度维度的映射。

**灵感 5（自适应位宽平衡 → 带迟滞的闭环，而不是静态配置）**
直觉：负载、温度、电池与场景会改变边端可承受的位宽。**ABQ 闭环**以平衡余度为被控量、以位宽为控制量，做一个离散时间控制器；关键是加**迟滞带 + 安全地板 + 连续松弛**，否则位宽在阈值附近来回跳变会自己制造振荡——这是“平衡控制”与“量化”结合后最危险的涌现行为。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（量化方案与误差界）**
量化方案 `Q = (b, s, z)`，位宽向量 `b = (b_1,...,b_m)`，逐层缩放 `s` 与零点 `z`。逐层误差 `ε_i ≤ Δ_i(b_i) = range_i / (2^{b_i−1}−1)`，聚合误差 `ε_q(b) = sqrt(Σ_i w_i ε_i²)`。预算约束 `Σ_i c_i(b_i) ≤ C_max`，延迟约束 `τ(b) ≤ τ_max`，`b_i ∈ B`（如 {4,8,16}）。

**定义 122（量化敏感度剖面）**
对技能 `S`、鲁棒性维度 `d`、位宽 `b`：
`χ_S(d,b) = ρ_S(d;b_ref) − ρ_S(d;b)`，其中 `b_ref` 为参考位宽（如 FP16）。
临界位宽 `b*_S(d) = min{ b ∈ B | χ_S(d,b) ≤ κ }`。
剖面 `χ_S : D×B → [0,1]` 是第 54 轮 `ρ` 在量化轴上的离散导数近似。

**定义 123（量化动作剖面与量化兼容性）**
`α_S^{(b)}(a) = α_S(a) · 1[ dist(a, ∂supp α_S) > η(b) ]`，死区 `η(b) = L_a·ε_q(b)`。
有效动作集 `A_S^{(b)} = { a | α_S^{(b)}(a) ≥ θ_cov }`。
量化兼容性 `compat^{(b)}(S_i,S_j) = |A_i^{(b)} ∩ A_j^{(b)}| / |A_i^{(b)} ∪ A_j^{(b)}|`。
**嵌套性假设 (A29b)**：`b` 越大，`A_S^{(b)}` 单调扩张；若测量发现非单调，则该技能禁止低比特，并进入红队边界采样。

**定义 124（平衡余度证书）**
平衡相关状态 `x`（CoM/ZMP），支撑多边形 `P`。平衡余度 `m_B(x) = dist(proj(x), ∂P)`。
平衡控制器 Lyapunov 函数 `V(x)`，满足 `V̇ ≤ −λ_B V + L_B ε_q`。
平衡保持条件：`m_B ≥ L_B·ε_q/λ_B + δ_safe`。证书 `B_cert = (m_B, λ_B, L_B, ε_q^max, δ_safe)`。

**定义 125（平衡感知位宽分配）**
```
maximize_{b}  min_{d∈D} ρ_S(d;b)
s.t.  Σ_i c_i(b_i) ≤ C_max,  τ(b) ≤ τ_max,  b_i ∈ B,
      b_i ≥ b_min^bal   ∀ i ∈ L_bal（平衡关键层）,
      m_B(b) ≥ L_B·ε_q(b)/λ_B + δ_safe.
```
其中 `L_bal` 由第 54 轮动作剖面中的平衡关键动作子集确定。

**定义 126（量化联合证书）**
`J_q = (ρ_q, A_cert_q, γ_ce, b, ε_q, B_cert, Explain_q, evidence)`：
- `ρ_q(d) = ρ_S(d;b)`，`A_cert_q = (A_core^{(b)}, A_buffer^{(b)}, δ_a)`；
- `b` 位宽方案，`ε_q` 聚合误差，`B_cert` 平衡余度证书；
- `Explain_q` 至少包含**位消融根因**（哪个层/哪个维度掉点）与边端反例。
部署判定：`dom_J(T)=in ∧ δ_a<Θ_a ∧ min_d ρ_q(d)≥ρ_min ∧ m_B ≥ L_B ε_q/λ_B + δ_safe`。

## 2. 关键算法 伪代码

### IP-121 QSP（Quantization Sensitivity Profile）

```python
def quantization_sensitivity(skill, dims, bit_grid, ref_bits=16, kappa=0.05):
    chi = {}
    rho_ref = robustness_spectrum(skill.model, ref_bits, dims)
    for b in bit_grid:
        qmodel = quantize(skill.model, bits=b)
        rho_b = robustness_spectrum(qmodel, dims)
        for d in dims:
            chi[(d, b)] = rho_ref[d] - rho_b[d]
    critical = {d: min([b for b in bit_grid if chi[(d, b)] <= kappa],
                       default=max(bit_grid))
                for d in dims}
    return chi, critical

def quantized_action_profile(skill, b, eps_q, L_a=1.0, theta_cov=0.8):
    eta = L_a * eps_q
    return {a: prof * (1.0 if dist_to_boundary(a, skill.alpha) > eta else 0.0)
            for a, prof in skill.alpha.items()}
```

### IP-122 BAQ（Balance-Aware Quantization）

```python
def balance_aware_bit_alloc(skill, chi, budget, m_min, lam_B, L_B, delta_safe):
    def eps_q(b): return sqrt(sum(w_i * delta_i(b_i)**2
                                  for i, b_i in enumerate(b)))
    def feasible(b):
        return (cost(b) <= budget and tau(b) <= tau_max
                and all(b[i] >= B_MIN_BAL for i in skill.balance_layers)
                and m_B(skill, b) >= L_B * eps_q(b) / lam_B + delta_safe)
    # 以“每比特最小维度鲁棒性增益”为边际收益的贪心水填充
    b = [min_bits(i) for i in range(skill.num_layers)]
    while cost(b) <= budget:
        cand = [(marginal_gain(skill, chi, b, i, d) / cost_step(i), i)
                for i in range(skill.num_layers) if b[i] < max_bits(i)]
        if not cand:
            break
        _, i = max(cand)
        b[i] += 1
        if not feasible(b):
            b[i] -= 1
            if all_bits_pinned(b):
                break
    return b if feasible(b) else fallback_high_precision(skill)
```

### IP-123 QCC（Quantized Composition Certificate）

```python
def quantized_composition(skills, b_alloc, theta_a, K, delta_a_budget):
    Gq = nx.DiGraph()
    for s1, s2 in ordered_pairs(skills):
        a1 = quantized_action_profile(s1, b_alloc[s1.id], eps_q(b_alloc[s1.id]))
        a2 = quantized_action_profile(s2, b_alloc[s2.id], eps_q(b_alloc[s2.id]))
        if compat(a1, a2) < theta_a:
            continue
        rho_q = compose_robustness_quantized(s1, s2, b_alloc, K)
        if min(rho_q.values()) < rho_min:
            continue
        Gq.add_edge(s1.id, s2.id, compat=compat(a1, a2), rho_q=rho_q,
                    eps_q=max(eps_q(b_alloc[s1.id]), eps_q(b_alloc[s2.id])))
    return Gq
```

### IP-124 ABQ（Adaptive Bit-width Balancing）

```python
def adaptive_bits_control(state, b_cur, m_B, rho_q, explain_q, h=0.02, step=1):
    # 安全地板：平衡关键层永不低于 B_MIN_BAL
    if m_B < m_safe or min(rho_q.values()) < rho_min:
        return raise_bits(b_cur, explain_q.root_cause, step, floor=B_MIN_BAL)
    if m_B > m_safe + h and latency_headroom(state) > 0:
        return lower_bits_noncritical(b_cur, step, floor=B_MIN_BAL)
    return b_cur  # 迟滞带内保持，避免位宽抖动/极限环
```

### IP-125 QBC + IP-126 QJC（契约与联合证书）

```python
def quantized_joint_certificate(skill_seq, b_alloc, gamma_ce, budgets):
    eps_q = aggregate_error(b_alloc)
    A_core_q = reduce(intersection,
        [quantized_action_profile(s, b_alloc[s.id], eps_q(b_alloc[s.id]))
         for s in skill_seq])
    rho_q = compose_robustness_quantized_chain(skill_seq, b_alloc, K)
    B_cert = balance_certificate(skill_seq, b_alloc, lam_B, L_B)
    delta_a = alignment_error(gamma_ce, A_core_q) + L_ce * eps_q
    if delta_a > budgets.delta_a:
        return ('reject', 'action_mismatch', delta_a)
    if min(rho_q.values()) < rho_min:
        return ('reject', 'robustness_fail', rho_q)
    if B_cert.m_B < L_B * eps_q / lam_B + delta_safe:
        return ('reject', 'balance_margin', B_cert)
    return ('ok', J_q(rho_q, A_cert_q(A_core_q, eps_q), gamma_ce,
                      b_alloc, eps_q, B_cert, Explain_q.from_bits(b_alloc)))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| QSP | O(|B|·|D|·T_eval) | O(|B|·|D|) | 位网格覆盖、敏感度可复现 |
| BAQ | O(|B|·|L|·|D|·|B|) | O(|L|·|B|) | 平衡地板、边际增益单调 |
| QCC | O(|S|²·|A|) | O(|S|²) | 量化剖面嵌套、阈值 sound |
| ABQ | O(|L|) / 控制 tick | O(|L|) | 迟滞带、安全地板、无极限环 |
| QJC | O(|S|·|A| + |D|) | O(|A|+|D|) | 误差传播有界、平衡条件闭合 |

**正确性定理（Quantization-Balance Preservation Soundness）**
在 (A22)–(A28) 与第 54 轮结论成立的前提下，新增：
**(A29)** 量化敏感度 `χ_S(d,b)` 有界且对 `b` 单调不增；
**(A30)** 技能闭环映射对参数扰动 Lipschitz 常数 `L_S`，且 `ε_q(b) ≤ ε_max`；
**(A31)** 平衡控制器 Lyapunov 收缩率 `λ_B>0`、扰动增益 `L_B`，且平衡地板 `b_min^bal` 固定；
**(A32)** ABQ 采用迟滞带 `h>0` 且切换频率上界受限，不产生极限环。
则对通过 `J_q` 的部署：
```
P( task_success ∧ balance_preserved | J_q = ok )
  ≥ 1 − Σ_d (1 − ρ_q(d)) − P(ε_q > ε_max)
      − P(m_B < L_B ε_q/λ_B + δ_safe) − β_E
```
直觉：`ρ_q` 管任务维度，`m_B` 管瞬态物理安全，`ε_q` 是二者共同的量化误差源；只要误差传导链的两端都被证书约束，联合失败概率的可加性上界成立。

## 6. 本轮最大风险

**一句话**：模型量化把鲁棒性侵蚀变成维度-边界非均匀的“隐形收缩”，而平衡控制对量化误差最敏感；若敏感度剖面跨硬件不迁移、或 ABQ 的离散位宽切换在平衡阈值附近形成极限环，证书仍可能显示 `ok`、真实系统却已在边界动作与瞬态平衡上失稳，故必须以 **边端在线标定 + 平衡关键层位宽地板 + 迟滞/连续松弛 + 边界动作红队** 四重护栏，任何低于平衡安全地板的“高压缩率”一律否决。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（QSP×BAQ×QCC×ABQ×QBC×QJC）

> 承接第 54 轮产物 v31。本轮将 **模型量化** 与 **平衡控制** 注入动作-鲁棒性双证书体系：
> - **QSP（Quantization Sensitivity Profile）**：把 `ρ` 扩展到量化轴，得到维度-边界敏感度；

> - **ABQ（Adaptive Bit-width Balancing）**：以平衡余度为被控量的自适应位宽闭环；
> - **QBC（Quantization-Balance Contract）**：云全精度 ↔ 边量化执行的精度契约；
> - **QJC（Quantized Joint Certificate）**：量化联合证书 `J_q`，升级 JTC。

```python
                for i in range(skill.num_layers) if b[i] < max_bits(i)]
        if not cand:
            break
        _, i = max(cand)
        b[i] += 1
        if not feasible(b):
            b[i] -= 1
            if all_bits_pinned(b):
                break
    return b if feasible(b) else fallback_high_precision(skill)
```

```python
def quantized_joint_certificate(skill_seq, b_alloc, gamma_ce, budgets):
    eps_q = aggregate_error(b_alloc)
    A_core_q = reduce(intersection,
        [quantized_action_profile(s, b_alloc[s.id], eps_q(b_alloc[s.id]))
         for s in skill_seq])
    rho_q = compose_robustness_quantized_chain(skill_seq, b_alloc, K)
    B_cert = balance_certificate(skill_seq, b_alloc, lam_B, L_B)
    delta_a = alignment_error(gamma_ce, A_core_q) + L_ce * eps_q
    if delta_a > budgets.delta_a:
        return ('reject', 'action_mismatch', delta_a)
    if min(rho_q.values()) < rho_min:
        return ('reject', 'robustness_fail', rho_q)
    if B_cert.m_B < L_B * eps_q / lam_B + delta_safe:
        return ('reject', 'balance_margin', B_cert)
    return ('ok', J_q(rho_q, A_cert_q(A_core_q, eps_q), gamma_ce,
                      b_alloc, eps_q, B_cert, Explain_q.from_bits(b_alloc)))

def quantized_precision_contract(P_c, rho_ref, b_e, budgets):
    # 云端全精度计划 -> 边端量化执行的可判定契约
    eps_q = aggregate_error(b_e)
    if eps_q > budgets.eps_max:
        return ('reject', 'precision_gap', eps_q)
    return ('ok', QBC(P_c, rho_ref, b_e, eps_q, budgets.delta_b))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| QSP | O(\|B\|·\|D\|·T_eval) | O(\|B\|·\|D\|) | 位网格覆盖 ≥ 95%，敏感度可复现 |
| BAQ | O(\|B\|·\|L\|·\|D\|·\|B\|) | O(\|L\|·\|B\|) | 平衡地板不变式、边际增益单调 |
| QCC | O(\|S\|²·\|A\|) | O(\|S\|²+\|E_q\|) | 量化剖面嵌套、阈值 sound |
| ABQ | O(\|L\|)/tick | O(\|L\|) | 迟滞带 h>0、无极限环、看门狗回退 |
| QJC | O(\|S\|·\|A\|+\|D\|) | O(\|A\|+\|D\|) | 误差传播有界、平衡条件闭合 |

**正确性定理（Quantization-Balance Preservation Soundness）**
假设第 54 轮 (A22)–(A28) 成立；新增 **(A29)** `χ_S(d,b)` 有界且对 `b` 单调不增；**(A30)** 技能闭环映射 Lipschitz 常数 `L_S`，`ε_q(b) ≤ ε_max`；**(A31)** 平衡控制器 Lyapunov 收缩率 `λ_B>0`、扰动增益 `L_B`，平衡关键层地板固定；**(A32)** ABQ 迟滞带 `h>0` 且切换频率有界。则：
```
P( task_success ∧ balance_preserved | J_q = ok )
  ≥ 1 − Σ_d(1 − ρ_q(d)) − P(ε_q > ε_max)
      − P(m_B < L_B ε_q/λ_B + δ_safe) − β_E
```
关键：**量化误差经 L_S、L_B 在任务与平衡两端均有界传播**，**位宽水位受平衡地板约束**，**离散切换不产生极限环**。

## 5. 本轮最大风险

**一句话**：模型量化把鲁棒性侵蚀变成维度-边界非均匀的“隐形收缩”，而平衡控制对量化误差最敏感；若敏感度剖面跨硬件不迁移、或 ABQ 的离散位宽切换在平衡阈值附近形成极限环，证书仍可能显示 `ok`、真实系统却已在边界动作与瞬态平衡上失稳，故必须以 **边端在线标定 + 平衡关键层位宽地板 + 迟滞/连续松弛 + 边界动作红队** 四重护栏，任何低于平衡安全地板的“高压缩率”一律否决。
