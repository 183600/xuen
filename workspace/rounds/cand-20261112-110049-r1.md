# 第 58 轮（承接第 57 轮「元推断×跨模态对账×个性化信任」IP-133~138；灵感循环第 4 轮；本轮灵感：「多任务学习」×「放置」）

> 第 57 轮把安全的赌注再往前推了一层——元先验给效率、共形给保底、跨模态对账给警报、个性化信任状态给人类维度；但它自己承认的最大风险是"坏先验普遍"：语料盲区会造出一个自信且系统的错误。本轮两个灵感恰好各自戳中这个风险的盲侧。**多任务学习**提醒我们：真实部署从来不是单一技能在单区域里的考试，而是"行走/攀爬/放置/交接"共享同一张地图与同一个元先验的连续多任务；共享正是摊销效率的来源，也**正是污染的来源**——多数任务（高频、易采证）的证据会淹没少数安全关键任务（低频、难采证），而边际校准恰恰看不见这种淹没。**放置**提醒我们：前几轮所有承诺都停在"接触/探询"层面，接触至少还能退；而放置的**释放**是真正不可逆的放手——证据在释放前最后一刻仍可采，释放后一切交给物理。于是本轮把两个词合流成一个命题：**共享要有隔离、放置要有分段、探针要有公平**——即"多任务可隔离、放置可分段、证据放置可公平分配"的承诺安全。它同时是对第 57 轮"一切判定器走隔离"的自然推广：**跨任务共享也要走隔离**。

核心矛盾：
- **H29（共享 vs 负迁移）**：多任务共享用一份证据喂多个任务，换来摊销效率；但共享是一条双向污染通道——任务 A 的证据进入共享躯干后会被任务 B 无条件采信。共享越成功、语料越偏向高频任务，稀有安全任务就越可能被一个"在多数任务上正确"的共享先验系统性地误导。边际校准（对全部任务平均）对这种按任务分化的错误近乎失明。
- **H30（放置 vs 承诺）**：前几轮把"不可逆接触"当作最坏承诺，但接触尚可减速、卸载、退回；放置的**释放**一旦发生，抓取关系被物理切断，撤销只能靠再抓取且未必成功。证据在释放前最后一段最密集可用，却被"已经放到位了"的完成感催着提前放手——这是不可逆承诺里最典型的"临门一脚"失误。
- **H31（公平 vs 效率）**：多任务探针放置若按总 VOI 分配，稀有安全任务永远抢不到探针（它样本少、VOI 估计方差大，反而显得"不值得探"）；若强行 max-min 平均主义，又会把预算浪费在已经足够安全的任务上。公平与效率在"证据放置"这一层第一次正面冲突。

## 0. 直觉与动机

**灵感 1（多任务学习 → 共享是效率，也是污染）**
直觉：多任务学习的教科书结论是"相关任务共享表征能提升样本效率"，但同一本书的另一半写着"负迁移"：不相关甚至冲突的任务会互相拖累，高频任务会支配共享表征，让低频任务被压成一个几乎恒等的映射。放到本框架里，第 57 轮的元先验 q_φ 就是一个**共享躯干**：它从全体区域/任务史摊销而来。此前我们只问"元先验准不准"，从没问"它是被谁带偏的"。答案通常是：被来访最多、采证最容易的那个任务带偏的。于是本轮的第一性设计是**共享-私有分解 + 迁移安全测试**：证据先证明自己"跨任务似然不变"才准进共享躯干，否则留在任务私有层；共享躯干是被多方托付的公共品，任何外来证据入场都要过安检。

**灵感 2（放置 → 释放是不可逆承诺的原型）**
直觉：把杯子放到桌上，前 99% 的时间你都能反悔（悬停、轻触、抬回），最后 1% 松手的瞬间不能。放置因此不是"一个动作"，而是一条**可撤销度单调下降的动作序列**：rev(悬停)=1 → rev(轻触)=0.7 → rev(半释放)=0.4 → rev(释放)=0。前几轮把承诺二值化为"接触/不接触"，把最丰富的安全结构抹掉了。分段放置换一个问法：**用时间买证据**——每多停一档，就多一次观测去校准支撑面与物体位姿，直到释放门的证据足够才松手；证据不够就退回悬停或再抓取。这正是"探-诺-演"在不可逆操作上的对偶：探针是在接触前买证据，分段是在释放前买证据。

**灵感 3（多任务 × 放置 → 共享边界随任务与阶段变化）**
直觉：一个放置动作从来同时服务多个任务约束——抓稳（不捏碎）、放稳（不倾倒）、不占道（不挡后续路线）、交接安全（不砸人）。这些约束是"多任务"，而它们对证据的需求在放置的不同阶段不一样：悬停阶段最需要物体位姿，接触阶段最需要支撑面刚度，释放前最需要稳定裕度。于是"共享什么证据"本身是一个随任务与阶段变化的决策。冲突时绝不能把两个任务的信念平均——平均等于两个都错一半；正确做法是加宽（承认不知道）并触发一次**区分性探针**（能同时区分两任务假设的那一探）。

**灵感 4（回看第 57 轮最大风险：负迁移就是"坏先验普遍"的机制）**
直觉：第 57 轮说"坏先验普遍"来自语料盲区。多任务学习给了一个更锋利的机制解释：坏先验不是均匀地坏，而是**沿着任务频次梯度坏**——高频任务区域的先验被反复校准得很准，低频安全任务的先验则被共享躯干"顺手带过"。这类错误在边际指标上几乎不可见（被高频任务的正确淹没了），却在恰恰最难采证、后果最重的地方发作。因此第 58 轮把校准从"整体 ECE"改成**逐任务分层校准 + 支配度披露**，把部署界从"平均"改成"逐任务取最坏"。

**灵感 5（PCE++ → 探针放置本身成为公平分配问题）**
直觉：既然证据放置是多任务共享的公共资源，探针选择就不该是"总 VOI 最大"，而应是"**最弱安全任务的信息增益最大**"（max-min）。这与前几轮的经济学一脉相承：安全的赌注永远押在"最可能先崩的那条腿"上。稀有安全任务拿到预算下限，其余预算再按效率分配——先保底、再逐利。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（多任务共享-私有分解 MTSP）** 任务集 𝒯={τ_1,…,τ_T}，每条任务有风险函数 R_τ 与接触/放置计划。区域信念分解为共享躯干与任务私有头：b_{r,τ}=P_ψ(S_θ(r);τ)，S_θ 承载几何/材质/元先验等可迁移结构，P_ψ 承载任务特化修正；任务的任何承诺只读 b_{r,τ}，不直读 S_θ。证据 e=(τ,r,m,ℓ) 进入共享躯干的准入由**迁移安全测试** TST 判定：TST(e,τ') ⇔ sup_θ|ℓ_{τ'}(e|θ)−ℓ_τ(e|θ)|≤ε_tr ∧ NT_{τ→τ'}≤b_tr，其中 NT_{τ→τ'} 是纳入 e 后 τ' 期望损失的增量（负迁移风险）。通过则写共享躯干并记版本 ΔS，未通过则进**负迁移托管** E_τ（定义 143），永不上行、不跨任务可见。共享躯干版本化，任何版本可审计回滚。

**定义 140（任务分层校准与支配度 TSC）** 逐任务、逐探针数声明校准：∀τ,∀k≤k_max，ECE_{τ,k}(q_φ)≤ε_meta(k) 且 ε_meta 随 k 单调不增；不接受"边际 ECE 达标"作为放行依据。支配度 dom(τ)=N_τ/Σ_{τ'}N_{τ'}（N_τ 为该任务的到访/证据量）；稀有安全任务集 𝒯_safe^rare={τ: dom(τ)<θ_dom ∧ R_τ≥θ_R}。预算公平：稀有安全任务至少获得 ρ_rare·B_probe 的探针预算，任一稀有任务不得连续 >H_rare 个检查点未获证据。冲突感知融合：若两任务对同一区域要求矛盾更新（TV(b_{r,τ},b_{r,τ'})>θ_conf 且两者证据均过 TST），**禁止取平均**（平均=两错各半），改为取加宽并集 widen_union 并触发区分性探针；融合结果以"最不确定任务"为准进 P_fail。

**定义 141（放置承诺代数 PCA）** 放置动作 a 带三元组 (rev(a),U(a),C_place(a))：可撤销度 rev∈[0,1]、撤销代价 U、约束集 C_place={不捏碎,不倾倒,不占道,交接安全}。分段放置 σ_place=(a_1,…,a_n)：前 n−1 步 rev>0（悬停/轻触/半释放，可在 τ_rev 内撤销或再抓取），末步 a_n 为释放且 rev=0，是**唯一不可逆步**。释放门 RG：commit(a_n) ⇔ S_support(r)≥s_0 ∧ pose_bound(obj)≤w_pose ∧ K_margin^place≥θ_K^place ∧ 证据门（不可逆释放必要集={EV-probe\*∨EV-margin}∪**任务私有佐证**，不接受纯共享层证据、不接受 EV-xmodal 替代）。性质：分段放置把一次不可逆承诺转成"至多 n−1 次可撤销观测 + 1 次不可逆释放"，中间观测为末步释放累积证据（慢放买证据）；若 τ_rev 内无法达到释放门，退回悬停或再抓取，不硬放。

**定义 142（多任务主动放置 MAP）** 探针放置 p=(位置,时机,模态,任务指向)。多任务价值：VOI_MT(p)=min_{τ∈𝒯_safe} VOI_τ(p)（先保最弱安全任务），在稀少见任务全部达标后按 Σ_τ VOI_τ 逐利（字典序）。共享探针 p_share 仅当其对所有被服务任务均过 TST 才可"一次探多任务"；否则拆成任务私有探针 p_priv(τ)。预算约束：k_share+Σ_τ k_priv(τ)≤B_probe 且稀有任务预留 ≥ρ_rare·B_probe 不可挪用。云边"证据放置"由本定义推广：共享躯干增量 ΔS 在**放置**到边端共享层之前，须过逐任务校准回归（∀τ ECE 不劣化）∧ 负迁移预算（Σ_τ NT≤b_cloud）影子测试；不通过则只放置到对应任务的私有层。

**定义 143（负迁移托管 NTE）** 每任务维护托管区 E_τ：暂存未过 TST、或尚未被该任务私有 verdict 证实的外来证据。证据生命周期：进 E_τ → 任务私有观测证实 → 释放入 b_{r,τ} 并纳入 S_θ 候选；被证伪 → 丢弃并对来源任务 τ_src 的共享贡献回溯降权。**跨任务污染回溯**：若任务 τ' 事后证伪且归因于共享版本 ΔS_k，则把 S_θ 回滚到 ΔS_k 之前、对受影响任务全历史重估，并把 γ_down 施加于 τ_src 的来源可靠性——这是第 57 轮"事后证伪回溯"从单模态/单任务推广到跨任务。

**定义 144（探-诺-放-演 PCPE）** 每检查点：①**任务路由**——按当前动作确定激活任务集 𝒯_act 与共享层可见域；②元推断+跨模态对账（继承 IP-133/134）；③若动作为放置，走分段放置 σ_place 与释放门（PCA），证据不足则悬停/再抓取；④若需探询，按 VOI_MT + 稀有任务预留选择"证据放置"（MAP），冲突更新触发区分性探针而非平均；⑤出口 ∈ {承诺(释放/接触), 绕行, 再抓取/悬停, 降档, L2 协商, 安全停}。终止性：分段 ≤n 步、探针 ≤B_probe、逐任务有限预算。

## 2. 关键算法伪代码（完整版见产物区）

```python
def route_and_infer(M, r, tau, obs, meta):          # IP-139: 共享-私有 + TST
    head = MetaHeads[tau]
    for e in obs_by_task(obs, tau):
        if transfer_safe(e, tau, MetaHeads, eps_tr=meta.eps_tr):
            M.S[r] = shared_absorb(M.S[r], e)       # 过安检才进共享
        else:
            M.escrow[tau].put(e)                    # 否则托管，不跨任务可见
    b = head.decode(M.S[r], M.P[r][tau])            # 承诺只读私有头
    return M, b

def conflict_aware_fuse(b_by_task, theta_conf):     # IP-140: 禁平均
    conflict = [(a,b) for a,b in pairs(b_by_task)
                if TV(b_by_task[a], b_by_task[b]) > theta_conf]
    if conflict:
        return widen_union(b_by_task), conflict     # 加宽 + 触发区分探针
    return fuse_shared(b_by_task), []

def staged_place(x, obj, support, M, tau, persona): # IP-141: 分段释放
    stages = plan_stages(obj, support)              # a_1..a_{n-1} 可撤销, a_n 释放
    for a in stages[:-1]:
        ok, obs = execute_reversible(a, tau_rev=tau_rev)
        if not ok:
            return hold_or_retreat(x, obj)          # 超时→悬停/再抓取
        M = ingest(M, obs, task=tau)
        if not release_gate_ready(M, obj, support, tau, persona):
            return hold_or_retreat(x, obj)
    if release_gate(M, obj, support, tau, persona):
        return release(obj)                         # 唯一不可逆步
    return hold_or_retreat(x, obj)

def release_gate(M, obj, support, tau, persona):
    return (S_support(M, support) >= s0
            and pose_bound(M, obj) <= w_pose
            and K_margin_place(M, tau) >= theta_K_place
            and evidence_gate_place(M, tau, persona,
                                    require_private=True))  # 须任务私有佐证

def place_probe(cands, tau_safe, reserve, B):       # IP-142: 公平放置
    if rare_overdue(tau_safe, reserve, H_rare):
        return most_informative_for(least_observed(tau_safe))
    return argmax(cands, key=lambda q: voi_mt(q, tau_safe))  # min over tasks
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| MTSP | O(T·d_ψ)/证据 + O(d_TST) | O(\|V\|·T·d_ψ+\|E_τ\|) | TST 声明诚实、托管不外泄（A41） |
| TSC | O(T·\|𝒯\|) 校准检查 | O(T) | 逐任务 ECE、稀有任务预留（A42） |
| PCA | O(n) 分段 + O(1) 释放门 | O(\|obj\|+\|C_place\|) | rev 单调下降、释放须私有佐证（A43） |
| MAP | O(\|cands\|·\|𝒯_safe\|) | O(\|cands\|) | VOI_MT 悲观且公平（A44） |
| NTE | O(1)/证据 + O(\|history\|) 回溯 | O(\|E_τ\|) | 托管-释放-回溯完备 |
| PCPE | O(\|CP\|·(T·k_p+n·k_s)·(C_VOI+d_φ)) | O(\|V\|+\|σ\|) | 分段 ≤n、探针 ≤B_probe、逐任务终止 |

**正确性定理（Multi-Task Placement Soundness, MTPS 概要）**：在 A33–A40 上加 (A41) 共享-私有分解诚实：TST 的似然不变性声明诚实、负迁移预算 NT≤b_tr 可审计、托管 E_τ 不外泄；(A42) 逐任务校准 ∀τ,k ECE_{τ,k}≤ε_meta(k) 且支配度披露、稀有任务预留不被挪用；(A43) 分段放置可撤销：前 n−1 步 rev>0、撤销代价 U≤U_max、可在 τ_rev 内撤销/再抓取，释放门证据含任务私有佐证；(A44) VOI_MT 悲观且 max-min 公平。则：
(i) **负迁移有界**：任务 τ 的承诺失效率 ≤ δ_f+ε_meta^{τ}(k)+δ_probe+ε_h+b_tr·1[使用了未私有证实的外来共享证据]；全用任务私有证据时 b_tr 项消失。
(ii) **放置健全性**：不可逆释放失效率 ≤ δ_f^place+P(支撑面误判)+P(pose 越界)+P(K_margin^place<θ)+δ_probe；分段放置使释放前的一切错误都落在可撤销步，最坏后果从"物体坠落/压碎"降为"一次可撤销的轻触或悬停"，即把不可逆失误的概率质量转移到可撤销层。
(iii) **交互单调性延续**：共享层、分段放置、稀有任务预留、冲突加宽只能经"更准（含隔离/加宽）"或"更保守（更多私有佐证、更慢释放、更多探针、更高护栏）"影响系统，不存在升险路径。
(iv) **终止性**：PCPE 在 T·B_probe+n 步内终止于 {释放承诺, 绕行, 再抓取/悬停, 降档, L2, 安全停}。
(v) **部署界**（按任务取联合界，用最坏不用平均）：

```
P_safe ≥ 1 − Σ_τ Σ_cp (δ_f + ε_meta^τ(k) + δ_probe + ε_h
                       + b_tr·1[shared_used] + δ_place)
             − P(共享版本陈旧未检出) − P(托管泄漏) − P(τ_rev 超时 ∧ 再抓取失败 ∧ 安全停失效)
```

关键：**共享给效率、隔离给安全**（TST + escrow 把负迁移挡在共享躯干外）；**分段给不可逆承诺一个可撤销的缓冲层**（释放门要求任务私有佐证）；**公平放置保证稀有安全任务不被高频任务饿死**；三者都只走"更准或更保守"两个安全通道。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 共享躯干被主导任务污染 → 稀有任务系统性失效 | 高 | TST + escrow + 逐任务校准 + 稀有任务预留 + 冲突禁平均 |
| 分段放置拉长任务时间，诱发"赶时间提前释放" | 中高 | τ_rev 预算 + 释放门硬约束 + 完成感偏差检测（与 PTM 警觉度联动） |

## 6. 本轮最大风险

**一句话**：本轮把"证据能不能跨任务共享"的判断交给一个迁移安全测试，风险从"坏先验普遍"收敛为"**负迁移系统性化**"——高频、易采证的任务会把共享躯干校准得越来越准，而低频、后果最重的安全关键任务恰恰最少被单独校准，于是共享会把"在多数任务上正确"的错误沿任务频次梯度精准地灌进最脆弱处；更棘手的是，共享带来的自洽假象（同一份证据在多任务上互相印证）会让这种污染在边际校准上几乎不可见。必须用逐任务分层校准、TST 准入门、escrow 托管、稀有任务预算与"不可逆释放只认任务私有佐证"五重护栏，宁可让稀有任务退回又慢又贵的私有证据路径，也不让它分享一份"别人都验证过"的公共先验。

```python
def route_and_infer(M, r, tau, obs, meta):
    head = MetaHeads[tau]
    for e in obs_by_task(obs, tau):                    # 只处理本任务证据
        if transfer_safe(e, tau, MetaHeads, eps_tr=meta.eps_tr):
            M.S[r] = shared_absorb(M.S[r], e)          # 过安检才进共享躯干

def transfer_safe(e, tau, heads, eps_tr):
    for tp in heads.active:                            # 对所有可迁移目标
        if sup_norm(heads.tp.loglike(e), heads[tau].loglike(e)) > eps_tr:
            return False
        if negative_transfer_risk(e, tau, tp) > heads.tp.b_tr:

    return True
```

```python
def task_stratified_check(q_phi, tasks, k, eps_meta):
    for tau in tasks:
        if ece(q_phi, task=tau, k=k) > eps_meta(k):    # 逐任务，不看边际

def conflict_aware_fuse(b_by_task, theta_conf):
    conflict = [(a, b) for a, b in pairs(b_by_task)
                if TV(b_by_task[a], b_by_task[b]) > theta_conf]
    if conflict:
        # 禁止平均（平均=两错各半）：加宽并集 + 触发区分性探针
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| MTSP | O(T·d_ψ)+O(d_TST)/证据 | O(\|V\|·T·d_ψ+\|E_τ\|) | TST 诚实、托管不外泄（A41） |
| TSC | O(T·\|𝒯\|) 校准检查 | O(T) | 逐任务 ECE、稀有预留（A42） |
| PCA | O(n) 分段+O(1) 门 | O(\|obj\|+\|C_place\|) | rev 单调下降、释放须私有佐证（A43） |
| MAP | O(\|cands\|·\|𝒯_safe\|) | O(\|cands\|) | VOI_MT 悲观且公平（A44） |
| NTE | O(1)/证据+O(\|history\|) 回溯 | O(\|E_τ\|) | 托管-释放-回溯完备 |
| PCPE | O(\|CP\|·(T·k_p+n·k_s)·(C_VOI+d_φ)) | O(\|V\|+\|σ\|) | 分段 ≤n、探针 ≤B_probe、逐任务终止 |

**正确性定理（Multi-Task Placement Soundness, MTPS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 共享-私有分解诚实：TST 的似然不变性声明诚实、负迁移预算 NT≤b_tr 可审计、托管 E_τ 不外泄、共享版本可回滚；**(A42)** 逐任务校准：∀τ,k ECE_{τ,k}≤ε_meta(k)，支配度披露，稀有任务预留不被挪用；**(A43)** 分段放置可撤销：前 n−1 步 rev>0、撤销代价 U≤U_max、可在 τ_rev 内撤销/再抓取，释放门证据含任务私有佐证；**(A44)** VOI_MT 悲观且 max-min 公平、预留有上限不被滥用。则：

1. **负迁移有界**：任务 τ 的承诺失效率 ≤ δ_f+ε_meta^{τ}(k)+δ_probe+ε_h+b_tr·1[使用了未私有证实的外来共享证据]；全用任务私有证据时 b_tr 项消失。
2. **放置健全性**：不可逆释放失效率 ≤ δ_f^place+P(支撑面误判)+P(pose 越界)+P(K_margin^place<θ)+δ_probe；分段放置使释放前错误全部落在可撤销步，最坏后果从"坠落/压碎"降为"可撤销轻触/悬停"——把不可逆失误的概率质量转移到可撤销层。
3. **交互单调性延续**：共享层、分段放置、稀有任务预留、冲突加宽只能经 (a) 更准（含隔离/加宽）或 (b) 更保守（更多私有佐证、更慢释放、更多探针、更高护栏）影响系统，不存在升险路径。
4. **终止性**：PCPE 在 T·B_probe+n 步内终止于 {释放承诺, 绕行, 再抓取/悬停, 降档, L2 协商, 安全停}。
5. **部署界**（按任务取联合界，用最坏不用平均）：

```
P_safe ≥ 1 − Σ_τ Σ_cp (δ_f + ε_meta^τ(k) + δ_probe + ε_h
                       + b_tr·1[shared_used] + δ_place)
             − P(共享版本陈旧未检出) − P(托管泄漏) − P(τ_rev 超时 ∧ 再抓取失败 ∧ 安全停失效)
```

关键：**共享给效率、隔离给安全**（TST + escrow 把负迁移挡在共享躯干外）；**分段给不可逆承诺一个可撤销缓冲层**（释放门只认任务私有佐证）；**公平放置保证稀有安全任务不被高频任务饿死**；三者都只走"更准或更保守"两个安全通道。

```
└─ L6 原型证伪/XFER/LFF/IXD
```

JCPS 输出扩展为：
`(v,a,m,q,ι,κ,g,λ,τ,σ,ρ,Explain,RUR_state,α_S,A_cert,γ_ce,δ_a, Σ/C+ 结构, 𝓜_core, J_m, probe_log, consent_state, w_h, q_φ/k*, D(r), ρ_ℳ, s_op/auth, m_E, ood_state, J_p, S_θ/P_ψ, E_τ, ΔS_k, rev(a)/σ_place, VOI_MT, ρ_rare)`

其中新增：`S_θ/P_ψ` 共享-私有分解；`E_τ` 负迁移托管；`ΔS_k` 共享版本；`rev(a)/σ_place` 放置可撤销度与分段；`VOI_MT` 公平探针价值；`ρ_rare` 稀有任务预算。

云边协议 CEB++ → **CEB+++**：共享躯干增量不再直接接管承诺，而是**作为"证据放置"先过任务路由**——按任务做逐任务校准回归（∀τ ECE 不劣化）、负迁移预算（Σ_τ NT≤b_cloud）与稀有任务覆盖检查的影子测试，通过才放置到边端共享层，否则只放置到对应任务的私有层；任何跨任务证伪事件触发共享版本回滚与受影响任务全历史重估。第 57 轮"一切判定器走隔离"在本轮推广为"**一切跨任务共享走隔离**"。

## 6. 本轮最大风险

**一句话**：本轮把"证据能不能跨任务共享"的判断交给一个迁移安全测试，风险从"坏先验普遍"收敛为"**负迁移系统性化**"——高频、易采证的任务会把共享躯干校准得越来越准，而低频、后果最重的安全关键任务恰恰最少被单独校准，于是共享会把"在多数任务上正确"的错误沿任务频次梯度精准灌进最脆弱处；更棘手的是，共享带来的自洽假象（同一份证据在多任务上互相印证）会让这种污染在边际校准上几乎不可见。必须用逐任务分层校准、TST 准入门、escrow 托管、稀有任务预算与"不可逆释放只认任务私有佐证"五重护栏，宁可让稀有任务退回又慢又贵的私有证据路径，也不让它分享一份"别人都验证过"的公共先验。
