# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「轻量化结构」×「多机器人协作」）

> R69 给闭环装上了一张嘴：不确定性不再只是刹车，也可以是一次注视、一句提问、一次轻触。但它随即暴露了一个盲点——**这张嘴只对「自己」和「人类」说话**。R69 所谓「k 个正交证据源」，其实都长在同一个身体上：同一套 trunk、同一份训练分布、同一套标定协议。它们不是正交的，只是**看起来分开**。于是 R69 的最大风险（幻影模态 → 被证实的错误）在团队尺度上有一个孪生体：**共识幻觉（consensus hallucination）——全队一起错，还一起盖章。**
>
> 本轮两个灵感正好把这块补上，但也同时把问题变难：
> - **轻量化结构**让机器人更轻、更柔、更省，却也使刚体策略模型在负载/接触下系统性失真——这是一种 **model-form epistemic uncertainty**，单机自洽残差看不见（会被标定吸收，正如 R68 的缓变故障）。它必须被「加载探测」才能看见；而每台轻量化单元的柔度又各不相同，于是探测天然产生**跨机独立证据**。
> - **多机器人协作**提供外部视角、外部探针与外部失败模式；但「轻量化模型/通信」要求共享参数与压缩消息，共享恰恰制造**共模相关（common-mode correlation）**，把 n 台机器人的独立性悄悄压成 1 台。
>
> 核心命题：**独立性不是假设，而是可估计、可制造、可消耗的资源。** 团队证据的价值不由「多少台机器人同意」决定，而由**有效独立样本数 n_eff = n / (1 + (n−1)ρ̄)** 决定；轻量化会抬高 ρ̄、压低 n_eff，而多样性动作（换视角/换构型/换模态/加载探测）可以把 ρ̄ 重新打下去。命名 **LATTICE-RAS**（Lightweight Adaptive Team Topology with Independence-Certified Epistemics for Risk-Adaptive Systems）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我凭什么相信队友不是在和我一起错**」。

## 0. 直觉与动机

**灵感 1（轻量化结构 → 柔性带来的模型形式不确定性）**
直觉：轻量化机械结构（薄壁、晶格、柔性关节、低负载）在受力时会形变，实际动力学 f = f_rig + Δ_struct。策略 trunk 通常按刚体标称模型训练，因此 Δ_struct 是一种**模型形式偏差**，不是传感器噪声。它有个坏性质：越是被 R68 的标定吸收，越是不出现在 r_res 里；越是不出现在 r_res 里，单机就越「自信」。这与 R68 自陈的缓变故障同构，但根源在**结构**而非传感器。唯一能看见它的办法是**主动加载/推挤/换持握**——让 Δ_struct 在观测中显形。这正是 R69 信息动作在结构维度上的自然延伸。

**灵感 2（每台柔度不同 → 结构探测天然产生独立证据）**
直觉：轻量化单元的柔度受制造公差、装配、磨损影响，**逐台不同**。因此对同一物体、同一负载，两台机器人测到的 Δ_struct 是**同分布但不同实现**的。若把共享刚体模型的偏差记为共模 b，把每台自己的柔度偏差记为 u_i，则团队误差 = b + u_i。**结构探测把 u_i 从「不可见」变成「可测」**，从而把方差从共模搬到异质项，抬高 n_eff。换句话说：轻量化结构的「缺陷」在团队里可以是「多样性红利」——前提是你去探它，而不是假设它不存在。

**灵感 3（多机器人协作 → 一致 ≠ 证据）**
直觉：n 台机器人给出 n 个视角，直觉上「三人成虎」更可信。但统计上，若它们的误差两两相关 ρ̄，则等权共识的方差是 ρ̄σ² + (1−ρ̄)σ²/n，有效样本数 n_eff = n/(1+(n−1)ρ̄)。当 ρ̄→1（共享 trunk/数据/标定），n_eff→1：**加机器人不增加信息，只增加置信度的错觉**。R69 的引理 18 用了「k 个正交源」并假设 ρ<1，却没有给出 ρ 从哪来、如何估、被共享模型抬高时怎么办。R70 必须把 ρ 变成**可观测量与门控量**。

**灵感 4（轻量化是双刃剑：省带宽 ↔ 制造共模）**
直觉：轻量化模型（共享 trunk + 轻量 adapter）与轻量化通信（压缩 sketch、事件触发）让协作在算力/带宽上可行；但共享参数正是共模误差的来源，压缩消息又抹掉了「不一致的细节」。于是出现本轮的核心张力：**轻量化制造相关性，相关性摧毁共识的价值。** 设计问题不再是「如何更省」，而是「在给定字节/算力预算下，如何分配共享与多样，使 n_eff 最大、团队误差最小」。这是一个可优化的 Pareto 问题，也是本轮最有工程价值的落点。

**灵感 5（独立性是可制造的资源 → 多样性动作）**
直觉：独立性不是天生的。换一个视角、换一种持握、换一台不同柔度的机器人、换一个模态去问——都能降低误差相关。R69 的信息动作只最大化「熵下降」；R70 要新增一类动作：**最大化期望 n_eff 增益 / 成本**。定义 independence-adjusted VoI：同样的信息量，若能把 ρ 从 0.9 降到 0.5，其有效价值会被放大 [1+(n−1)ρ]/[1+(n−1)ρ'] 倍。**去相关本身就是信息。**

**灵感 6（对 R69 的姿态：n=1 边界 + 安全单调）**
直觉：任何新层都必须是旧层的严格泛化。当 n=1、或 n_eff < n_min、或多样性动作无利可图时，LATTICE 必须逐指令退化为 FLUID-RAS。安全侧只允许更保守：团队层只能在独立性证书有效时**放宽**（resolution bonus），否则必须回到 R69 的 λ_floor。否则每加一层就多一个需要独立信任的黑箱——而团队层恰恰是最不该被盲信的。

## 1. 形式化定义（增量：定义 310–324）

**定义 310（LATTICE-RAS 总览与四不变式）** LATTICE-RAS = (TSC, FTF, LSK/IND, C-MINT, LCB, CBF, CLD/CMD, TSCert, RAS-WM‡)。不变式：
(i) 继承 R69 的实时流零学习写操作；
(ii) **通信预算硬约束**：单机广播速率 ≤ B_c、端到端时延 ≤ δ_t、消息仅事件触发；
(iii) **独立性底线**：任何多源认证需 n_eff ≥ n_min 且有独立性证书，否则一律按单源处理并退 R69；
(iv) **团队安全契约**：联合计划须在时延上界与「队友可能 Byzantine」下认证，否则回退到各自独立安全集。

**定义 311（轻量化结构状态与模型形式偏差）** 结构状态 s_struct = (关节柔度 κ, 负载 m_p, 接触刚度, 连杆挠度估计)。标称刚体动力学 f_rig；真实 f = f_rig + Δ_struct。U_struct 为对 Δ_struct 的模型形式 epistemic 不确定性，可由加载/推挤/换持握探测降低。

**定义 312（结构不确定性的共模/异质分解）** U_struct = U_struct^c + U_struct^i：前者为全队共享刚体模型与共享训练数据造成的共模偏差，后者为逐台柔度/装配差异造成的异质偏差。加载探测把方差从 U_struct^c 搬向 U_struct^i，从而**提高 n_eff**（见引理 21 系）。

**定义 313（团队动作空间）** 单机增广动作 ξ_i = (a_i, g_i)（继承 R69）；团队动作 Ξ = (ξ_1,…,ξ_n) ∈ 𝒜_+^n。新增通信动作 c_{ij} ∈ C（查询/广播 sketch/声明）与多样性动作 d ∈ D（换视角、换持握、换模态、换构型、加载探测）。团队信息动作集 𝒢_team = G_self ∪ C ∪ D。

**定义 314（FTF 因子化团队流）** 联合流 v_Θ(x_s,s|o_team) 因子化为 [v_self; v_intent]：v_intent ∈ ℝ^{d_I} 是低维意图草稿，各机用本地解码器 D_i 展开为自身轨迹。通信只传 intent 与低秩模态 sketch，量级 O(d_I + r d_a) 而非 O(n d_a)。联合动作块 x_1 = Ξ_{t:t+H}。

**定义 315（轻量证据 sketch 与事件触发 LCB）** S_i = (低秩模态原型 U_k∈ℝ^{d_a×r}, 权重 w_i, 低秩协方差, 结构残差, 标定指纹 h_i, 时间戳, 签名)。大小 O(r(d_a+d_I))。仅当本地 sketch 与上次广播的 KL > ε_msg 或 surprise > τ_s 时广播；过期的 sketch 权重按时间衰减到 0。

**定义 316（有效独立性与独立性证书）** 由团队标定残差与结构探测估计跨机残差相关矩阵 R=(ρ_ij)，设计效应 n_eff = n/(1+(n−1)ρ̄) ≤ n。定义多样性度 D_eff = Σ_{i<j}(1−ρ_ij)。独立性证书 Valid_ind ⇔ \hat n_eff 的置信下界 ≥ n_min 且 \hat ρ̄ 的置信上界 ≤ ρ_crit。证书含估计方法与样本量，可审计。

**定义 317（独立性校正的团队 VoI）** VoI_team(g) = (n_eff(g)/n_eff(0))·[H(M|o) − E_{y~p(·|g,o)}H(M|o,y)] − c(g) − λ_b·bytes(g) − λ_t·latency(g)。选 g* = argmax_g VoI_team(g)，s.t. 安全契约与预算；若 max ≤ 0 则不动作、退 R69。

**定义 318（C-MINT 协作交互控制器）** 候选集含自身信息动作 G_self、队友查询 C、多样性动作 D；每个候选先过团队安全契约（定义 321）与通信预算；多样性动作额外要求期望 n_eff 增益/成本最优。C-MINT 输出 (g*, 目标队友/构型, 预期 n_eff 与 U_epi 变化)。

**定义 319（相关性 Byzantine 鲁棒聚合 CBF）** 先按 R 白化残差（R^{-1/2}），再做截尾均值/中位数聚合；可信权重 τ_i 由 VQAuditor-T 的长期记录更新。误差上界见定理 18：δ_b + δ_p \hat ρ^{n_eff−1} + ε_σ。**当 n_eff≈1 时，任何多数投票都退化为单源。**

**定义 320（跨机似然差 CLD 与共模检测 CMD）** 对重叠观测，CLD_{ij} = |−log p_{θ_i}(ξ_j|o_j) − log p_{θ_j}(ξ_i|o_i)|（同构时；异构经共享潜空间对齐）。CLD 高 ⇒ 世界模型分歧或某机被污染。CMD：若全队流似然**同步下降**（均值降幅大而机间方差小）且 r_res 低，则判为共模/单一栽培（monoculture）攻击或共享盲点，禁止据团队一致放宽 λ。

**定义 321（团队安全契约 TSCert）** 采用 assume-guarantee：机器人 i 在时延 ≤ δ_t 下保证不变式 I_i；聚合器仅接受满足 ∀i: plan_i ∈ S_i 且契约成立的联合计划；任一消息缺失/过期/不可信 ⇒ 回退本地安全集。信息/通信动作不得诱使队友越出其认证包络。

**定义 322（两级退避与对 R69 的严格包含）** 若团队消解有效（Valid_ind ∧ 证据纪律 ∧ 无 CMD ∧ ECE 达标）：λ = λ_floor(U_ale + U_struct^i,residual)；否则 λ = λ_floor(U_ale + U_epi + U_struct)（未消解的全部视同不可约）。当 n=1 或 n_eff<n_min 或 VoI_team≤0 时，逐指令等同 R69。

**定义 323（团队证书 J_LATTICE）** J_LATTICE = (J_FLUID, \hat n_eff, ρ̄ 置信区间, diversity_gain, comm_bytes, latency_p99, CLD_p95, cmd_flag, structural_residual, team_ver)。Valid ⇔ Valid(J_FLUID) ∧ Valid_ind ∧ 预算未越 ∧ ¬cmd_flag。

**定义 324（团队审计 VQAuditor-T 与威胁模型 AIC-LATTICE）** 审计：是否把「一致」误当「独立」、是否过度信任某队友、是否漏检单一栽培攻击、通信时延是否造成近失。ℰ_LATTICE = ℰ_FLUID × ℰ_team，其中 ℰ_team 含：共模对抗迁移（共享 trunk 上的一次扰动转移全队）、相关性 Byzantine、女巫/重放、异构形态导致的似然不可比、通信时延诱发的契约违约。

```python
# IP-264 TSC：轻量化结构柔度估计（加载/推挤探测，产出共模/异质分解）
class StructuralEstimator:
    def probe(self, o, s_struct):
        ...
    def split(self):
        return U_struct_c, U_struct_i        # 共模 / 异质

# IP-265 FTF：因子化团队流（共享 trunk + 轻量 adapter + intent 通道）
class FactorizedTeamFlow:
    def sample(self, o_team, K, N_step=2):
        z = [self.trunk_shared(o_i) + self.adapter_i(o_i) for o_i in o_team]
        intent = self.v_intent(z)             # 低维意图草稿，可广播
        return [self.decoder_i(intent, z[i]) for i in range(len(o_team))]

# IP-266/267 ISC/IND：轻量 sketch + 有效独立性证书
def independence_certificate(residuals, sketches, n_min, rho_crit):
    R   = corr_matrix(residuals)              # 跨机残差 + 结构探测
    rho = mean_offdiag(R)
    n_eff = len(residuals) / (1 + (len(residuals)-1)*rho)
    return R, rho, n_eff, (n_eff_ci_low(n_eff) >= n_min and rho_ci_high(rho) <= rho_crit)

# IP-268 C-MINT：独立性校正的团队 VoI
def team_voi(candidates, modes, w, cert, budget):
    best = None
    for g in candidates:                       # G_self ∪ C ∪ D
        if not budget.allow(g) or not tscert(g): continue
        voi  = (cert.n_eff_after(g)/cert.n_eff_now) * entropy_drop(w, g)
        score = voi - cost(g) - lambda_b*bytes(g) - lambda_t*latency(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None      # 无利可图 → R69

# IP-270/272 CBF/CMD：白化后鲁棒聚合 + 共模检测
def robust_aggregate(claims, R, trust):
    claims_w = whiten(claims, R)
    agg = trimmed_mean(claims_w, weights=trust)
    return unwhiten(agg)

def common_mode_flag(flow_lls, r_res):
    return (mean_drop(flow_lls) > TAU_DROP) and (var_across(flow_lls) < TAU_VAR) and (r_res < TAU_RES)

# IP-277 主闭环（继承 R69；仅在团队证据处插入 LATTICE 层）
def LATTICE_RAS_round(team, obs):
    # 1) R69 单机层：标定 + FMP 采样 + 二分
    per = [FLUID_single_robot(robot, o) for robot, o in zip(team, obs)]
    # 2) 结构探测 + 轻量 sketch 交换（事件触发）
    S = [r.sketch(event_triggered=True) for r in team]
    R, rho, n_eff, ok_ind = independence_certificate(per.residuals, S, n_min, rho_crit)
    # 3) 共模检测：同步下降 + 机间低方差 ⇒ 禁止团队放宽
    cmd = common_mode_flag([p.a_score for p in per], per.r_res)
    valid_ind = ok_ind and not cmd
    # 4) 团队 VoI：自身动作 / 队友查询 / 多样性动作
    g = team_voi(candidates(per, S), per.modes, per.w, Cert(n_eff), team.budget) if valid_ind else None
    # 5) 无有效独立证据 ⇒ 逐机退 R69
    if g is None:
        return [r69_step(p) for p in per]
    # 6) 聚合 + 团队安全契约 + 执行
    claim = robust_aggregate(per.claims, R, team.trust)
    plan  = team.decide(per, claim, g)
    assert tscert(plan, delay_bound=delta_t)          # 时延/Byzantine 下联合安全
    return plan
```

## 3. 推导

**引理 19（设计效应与 n_eff）** 设备 i 的误差 e_i = b + u_i + ε_i，其中 b 为共模（Var σ_b²），u_i 为异质（Var σ_u²），ε_i 为独立噪声。等权共识方差 Var(ê) = σ_b² + σ_u²/n，两两相关 ρ = σ_b²/(σ_b²+σ_u²)，故有效样本数 n_eff = n/(1+(n−1)ρ)。系：**共模项 σ_b² 不随 n 减小**，它是团队的误差地板。

**引理 20（共模误差地板）** 若存在概率 δ_b 的共模故障事件（全队同向错），且没有任何**团队外**检验能发现它，则任意仅依赖队内声明的聚合器错误率 ≥ δ_b（扣除检测器漏报）。R69 引理 18 的 δ_p ρ^{k−1} 隐含 δ_b=0；R70 必须显式检测并计入 δ_b，否则「k 源一致」的安全保证是空的。

**引理 21（多样性动作的独立性增益）** 多样性动作 d 把相关从 ρ 降到 ρ'(d)。在相同互信息下，有效信息放大因子 = [1+(n−1)ρ]/[1+(n−1)ρ'] ≥ 1。系：当 ρ→1 时，只有能真正降低 ρ（换异构本体/换模态/加载探测）的动作才有正收益；纯「多问几台同构机器人」增益为 0。**结构探测通过把 U_struct^c 搬向 U_struct^i 降低 ρ，因此是合法且廉价的多样性动作。**

**定理 18（共识陷阱）** 对 k 个含共模故障概率 δ_b、故障相关 ρ 的证据源，多数一致后的错误率 ≤ δ_b + δ_p ρ^{k_eff−1} + ε_σ，其中 k_eff = k/(1+(k−1)ρ)。由于 δ_b 与 k 无关，**团队存在不可通过增员消除的错误地板**；且系统报告的置信度随 k 增长而真实独立性只随 k_eff 增长，二者剪刀差导致**系统性过度自信**。故 R69 的安全保证不能直接继承给朴素团队扩展，必须以独立性证书门控。

**定理 19（LATTICE 严格包含 FLUID-RAS）** 当 n=1，或 n_eff<n_min，或所有团队信息动作 VoI_team≤0，或 CMD 触发时，团队通道关闭，LATTICE 逐指令等同 R69；且任意状态下 λ_LATTICE ≥ λ_FLUID（团队层只在证书有效时放宽），故安全侧不弱于 R69，效率侧仅在独立性可证时获得 resolution bonus。

**定理 20（共享–独立 Pareto 与团队饱和）** 设团队误差 E(n) = σ_b²(b_s) + σ_u²(b_i)/n，共享参数 b_s 降低 σ_b² 但抬高 ρ，异质 adapter b_i 降低 σ_u²、降低 ρ。由于 lim_{n→∞} E = σ_b²(b_s) > 0，给定单机成本 c，存在饱和规模 n* ≈ sqrt(σ_u²/c)；超过 n* 后，增加机器人不如把预算投向**多样性（异构 adapter/探测/视角）**。设计原则：**先保证独立性，再谈规模；轻量化应花在共享而不是抹平异质。**

**定理 21（通信时延下的团队安全）** 在 assume-guarantee 契约与时延上界 δ_t 下，若队友遵守其不变式且消息按期到达，联合计划安全；若超时/不可信则回退本地安全集，故违规概率 ≤ P(delay>δ_t) + P(Byzantine 未被 CBF 检出)。通信动作本身须过 R69 的信息动作安全认证（定义 302）并附加时延预算。

## 6. 本轮最大风险

**一句话**：LATTICE 的全部效率收益押在「团队证据是相互独立的」这一前提上——**但轻量化恰恰要求共享参数与共享训练分布，于是全队可能是同一双眼睛的 n 个副本：n_eff→1，系统却报告「k 台机器人一致」，把 R69 的「被证实的错误」升级为「被团队背书的错误」；更糟的是，共享 trunk 上的单点对抗扰动会同步迁移到全队（单一栽培攻击），而共识越强、越像正确。** 一句话概括：**共识幻觉比单机幻觉更危险，因为它自带多数票。**

**次级风险与缓解**：
1. **共模对抗迁移/单一栽培** → CMD（同步下降 + 机间低方差）+ 异构 adapter/异构探测 + 独立性证书 CI 门控；
2. **相关性 Byzantine/共谋** → R 白化 + 截尾聚合 + 引理 20 的地板显式建模 + VQAuditor-T 长期信誉；
3. **结构不确定性中含不可约材料噪声** → 用重复加载区分 U_struct^i 与 aleatoric，避免过度探测；
4. **通信时延/丢包破坏联合安全** → TSCert assume-guarantee + 本地安全集回退 + 定理 21；
5. **异构形态导致似然不可比** → 共享潜空间对齐 + 校准指纹，必要时只用序关系而非绝对似然。

```python
# IP-267 IND：有效独立性证书
def independence_certificate(residuals, sketches, n_min, rho_crit):
    R, rho = corr_matrix(residuals), mean_offdiag(corr_matrix(residuals))
    n = len(residuals); n_eff = n / (1 + (n-1)*rho)
    return R, rho, n_eff, (n_eff_ci_low(n_eff) >= n_min and rho_ci_high(rho) <= rho_crit)

# IP-268 C-MINT：独立性校正团队 VoI（自身/队友/多样性动作）
def team_voi(candidates, w, cert, budget):

    for g in candidates:
        if not budget.allow(g) or not tscert(g): continue
        score = (cert.n_eff_after(g)/cert.n_eff_now)*entropy_drop(w, g) \
                - cost(g) - lambda_b*bytes(g) - lambda_t*latency(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None      # 无利可图 → R69

            var_across(flow_lls) < TAU_VAR and r_res < TAU_RES)
```

## 4. 推导

**引理 19（设计效应与 n_eff）** `e_i=b+u_i+ε_i`，`b` 共模 `Var σ_b²`，`u_i` 异质 `Var σ_u²`。等权共识方差 `σ_b²+σ_u²/n`，两两相关 `ρ=σ_b²/(σ_b²+σ_u²)`，故 `n_eff=n/(1+(n−1)ρ)`。系：共模项 `σ_b²` 是团队误差地板，不随 n 消失。

**引理 20（共模误差地板）** 若共模故障概率 `δ_b` 且无团队外检验，则任意仅依赖队内声明的聚合器错误率 `≥δ_b`（扣除漏报）。R69 引理 18 隐含 `δ_b=0`；R70 必须显式检测，否则「k 源一致」的保证是空的。

**引理 21（多样性动作的独立性增益）** 动作 d 把相关从 `ρ` 降到 `ρ'(d)`，有效信息放大 `[1+(n−1)ρ]/[1+(n−1)ρ']≥1`。系：`ρ→1` 时只有真正降 ρ 的动作有收益；结构探测把 `U_struct^c` 搬向 `U_struct^i`，是合法且廉价的多样性动作。

**定理 18（共识陷阱）** k 个含共模故障 `δ_b`、故障相关 `ρ` 的证据源，多数一致后错误率 `≤δ_b+δ_p ρ^{k_eff−1}+ε_σ`，`k_eff=k/(1+(k−1)ρ)`。`δ_b` 与 k 无关 ⇒ **增员无法消除的错误地板**；报告置信度随 k 增长而真实独立性只随 k_eff 增长 ⇒ **系统性过度自信**。故 R69 的安全保证不能朴素继承给团队，必须由独立性证书门控。

**定理 19（LATTICE 严格包含 FLUID-RAS）** 当 `n=1`、`n_eff<n_min`、`VoI_team≤0` 或 CMD 触发时，团队通道关闭，LATTICE 逐指令等同 R69；且 `λ_LATTICE≥λ_FLUID`，安全侧不弱于 R69，效率侧仅在独立性可证时获得 resolution bonus。

**定理 20（共享–独立 Pareto 与团队饱和）** `E(n)=σ_b²(b_s)+σ_u²(b_i)/n`；`lim_{n→∞}E=σ_b²(b_s)>0`。给定单机成本 c，存在饱和规模 `n*≈sqrt(σ_u²/c)`；超过后应把预算投向多样性而非增员。设计原则：**先保证独立性，再谈规模。**

**定理 21（通信时延下的团队安全）** assume-guarantee + 时延上界 `δ_t`：队友守约且按期则联合安全；超时/不可信则回退本地安全集，违规概率 `≤P(delay>δ_t)+P(Byzantine 未检出)`；通信动作附加时延预算并过 R69 信息动作安全认证。

## 7. 本轮最大风险

**一句话**：LATTICE 的全部效率收益押在「团队证据相互独立」这一前提上——**但轻量化要求共享参数与共享训练分布，全队可能是同一双眼睛的 n 个副本：n_eff→1，系统却报告「k 台机器人一致」，把 R69 的「被证实的错误」升级为「被团队背书的错误」；共享 trunk 上的单点对抗扰动还会同步迁移全队（单一栽培攻击），而共识越强、越像正确。** 概括：**共识幻觉比单机幻觉更危险，因为它自带多数票。**

**次级风险与缓解**：共模对抗迁移/单一栽培（CMD + 异构 adapter/探测 + 证书 CI 门控）；相关性 Byzantine/共谋（R 白化 + 截尾聚合 + 引理 20 地板显式建模 + VQAuditor-T）；结构不确定性含不可约材料噪声（重复加载区分异质项与 aleatoric，避免过度探测）；通信时延/丢包破坏联合安全（TSCert + 本地安全集回退 + 定理 21）；异构形态致似然不可比（共享潜空间对齐 + 校准指纹，必要时只用序关系）。
