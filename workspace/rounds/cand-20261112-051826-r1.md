# 第 58 轮（承接第 57 轮「少样本×多模态×个性化」IP-133~138；灵感循环第 2 轮；本轮灵感：「双臂协作」×「并发推理」）

> 第 57 轮把"证据说可信"推进到少样本可校准、跨模态可对账、个性化有界，但它仍隐含两个"单线程"假设：**(a) 世界在"检查"与"使用"之间不动**——一个检查点的证据被读取后，到真正承诺之前，另一条腿/另一只臂的并发动作可能已经改变了它，这是典型的 TOCTOU 竞态；**(b) 每个检查点的失效率是自足的**——所以可以对检查点直接取 union bound。可一旦多个效应器同时接触，"我安全是因为另一只臂撑着我"就使每个证书变成**有条件的、相互引用的**，串联依赖被误当并联冗余，union bound 不再刻画真实失效率。本轮两个灵感正好补这两刀：**双臂协作**给出角色不对称、接地支撑依赖图与内力预算，把"相互支撑幻觉"变成结构可判定的东西；**并发推理**给出证据事务、乐观并发与推测分支合并，把"检查时成立"升级为"提交时仍成立且未被并发推翻"。二者合流为 **锚-演两阶段物理提交 + 依赖感知可靠性界**，核心命题升级为 **"接地、并发一致的证据说可信"**。

核心矛盾：
- **H29（并行证据耦合 vs 逐检查点独立）**：省事的安全证明把多效应器当独立检查点取 union bound；但耦合支撑是串联不是并联（依赖越多越脆），共享传感器/共同支撑是正相关共模（同错同对），逐点独立界会系统性低估失效。
- **H30（推测提速 vs 承诺一致性）**：并发/推测推理用"先跑后验"换时延；但若提交时不校验读数版本，就会用过期的世界状态下不可逆决定；若校验过严，并发收益归零——需要在"快"与"证据在提交时仍有效"之间划出一条可证的线。
- **H31（双臂冗余 vs 相互支撑幻觉）**：双臂的能力来自一锚一演的冗余；但若两只臂互相把对方写进自己的安全证书，就构成无接地、无终点的循环支撑——没有谁真正站在地上，却每个人都"被支撑"。

## 0. 直觉与动机

**灵感 1（双臂协作 → 角色不对称 + 接地支撑图 + 内力预算）**
直觉：双臂不是"两个单臂相加"。真正的双臂协作是**角色不对称**的：一只当锚（brace）稳住世界，另一只当演（actor）去探、去操作；先有可信的支点，才谈得上冒险的动作。角色带来能力，也带来**借贷**——"我安全，因为另一只臂撑着我"。借贷本身没错，错在借贷可以循环：A 说"有 B 撑我"，B 说"有 A 撑我"，两条腿互相借着对方的信用，谁也没落地。物理上这对应闭合支撑链和过约束（两臂内力互顶，越使劲越不稳）。所以双臂协作的第一性原理不是"加一条臂"，而是：**每个承诺都必须有一条通向已验证地面、且无环的支撑路径；耦合接触的内力必须可被预算约束，超预算就是过约束。**

**灵感 2（并发推理 → 证据事务 + 乐观并发 + 推测执行）**
直觉：真实机器人不是一个线程按检查点排队。感知、推断、控制、另一条腿的动作是**并发**的。并发下最贵的错误不是算得慢，而是**"检查时成立、使用时已失效"（TOCTOU）**：一个线程读到"该表面干燥可承重"，另一个线程同时踩上去扰动/改变了它，等提交时这条证据已经过期。数据库几十年前就解决过同类问题——乐观并发控制：事务在快照上读、记下读写集、提交时校验版本，冲突就中止回滚。把证据地图 𝓜 当版本化共享内存，把每次探针/推断当**证据事务**，把并行假设当**推测执行**：快照内并行推理、提交时校验、冲突则弃分支、保留锚。并发因此不是免费加速，它把"证据足够"重写为**"证据在提交时仍然足够，且没有被并发动作推翻"**。

**灵感 3（合流 → 锚-演两阶段物理提交 + 依赖感知可靠性界）**
直觉：物理动作不能真回滚，所以不能照抄数据库的事务中止。双臂恰好给了一个**物理版两阶段提交**：先提交可卸载的锚，再提交带观察期的演——先让支撑落地，演在 probation 期内持续再验证，失败就卸载回锚。与此同时，安全界的算法必须从"对检查点取 union bound"升级为**在接地支撑的可靠性框图（RBD）上算串并联故障率**：串联（依赖）不是冗余；互相支撑的环是"无接地"而不是"双保险"；共享传感器/共享支撑的共模用 β-factor 显式计入。于是第 57 轮"坏先验普遍"多了一个并发侧的解药（独立多分支、分歧即弃权），也多了一个并发侧的新病（伪独立/回声室）。

**灵感 4（证据门与证书：六类证据 + 两道结构门）**
直觉：本轮不靠堆证据类，而是加两道**结构门**：**接地门 G-gate**（无环 + 接地 + 内力预算）与**并发门 C-gate**（OCC 版本有效 + 可串行化）。证据门 FSE+ 在五类基础上只新增 **EV-cc**（并发独立共识），且它必须同时过 G/C 门、独立性经审计；不可逆接触仍排除 EV-xmodal 与 EV-cc。证书由 J_p 升级为 **J_c = J_p ⊕ (G_s, RBD, β 向量, ver_log, indep_log, commit_log, rollback_log, arb_log)**——从此"证据说"之外还要附上"站在什么上、在哪个版本上"。

**灵感 5（PCE++ → 并发化探-诺-演）**
直觉：把 PCE+ 的串行检查点循环改成"并发分支 + 提交屏障"。对候选步态/接触方案并行做元推断与对账（推测执行）；某分支的证据版本被并发动作推翻就早停；提交前插入 G/C 双门与锚-演排序；内力超预算则降载、换角色或改步态。所有新机制仍只经"更准"（含弃权）或"更保守"（abort/锚优先/降载）两个安全通道，延续交互单调性。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（耦合双臂模型 CAM）** 效应器集 E={e_1,…,e_n}（前肢/后肢/机械臂），配置 x=(x_e)。接触图 G_c=(E,A_c)（边=同时接触/共同承载）。角色 ρ:E→{A(锚),S(演),F(自由)}。支撑依赖图 G_s=(E,A_s)，边 (e→e′) 表示 e 的证书引用了 e′ 的稳定性。**接地性**：存在已验证外部支撑 g0，(i) 每个锚有到 g0 的路径，(ii) G_s 无有向环（禁止相互支撑），(iii) 每个演的路径终止于锚或 g0。**内力预算**：对耦合接触子集 C⊆E，F_int(C)=‖Σ_{e∈C} f_e^int‖_∞ ≤ F_bud(C)，超限即过约束（松弛/换角色/卸载）。**角色语义**：锚承诺不可逆或半不可逆，演承诺 probationary。

**定义 140（证据事务与乐观并发 ETO）** 证据地图 𝓜 带版本 v(𝓜)；证据键 k=(r,modality,claim)。事务 T=(r_T,w_T,v_T)，r_T 记录读键与读版本 v_T(k)。提交校验：**C1** ∀k∈r_T，v(𝓜)(k)=v_T(k)（未被并发动作/事后证伪改动）；**C2** 所有 in-flight 提交的写集冲突图无环（可串行化）；**C3** 若某 in-flight 承诺的证书引用了被 T 改写的键，则 T 不得提交，或该承诺被降级 probationary 并重验。冲突 ⇒ abort(T)，回滚到最近一致快照 v_ckpt，释放演、保留锚。失效窗口 δ_stale=P(提交时读集已失效 ∧ C1 漏检)。

**定义 141（并发推断合并 CIM）** 并行分支 B={b_1,…,b_K}，每分支给候选 (d_i,conf_i,cert_i) 并声明对独立性 ind(b_i,b_j)（不同数据源/模态/元模型/探针史；共享同一 𝒟_meta 或同一传感器的分支视为相关，合并为单票）。合并 ⊕ 产承诺当且仅当：(i) 各 cert_i 可组合（无相互矛盾假设）；(ii) 分歧 Δ_B=max_{i,j} d_TV(b_i,b_j) ≤ θ_merge；(iii) 存在 ≥2 个**独立**同侧分支（独立性经 indep_log 审计，伪独立率 ≤ δ_ind）。否则触发仲裁探针（预算 k_arb）；仲裁仍分歧 ⇒ 弃权。Anytime：分支可在下界证书上提前返回；后到分支与已提交决策矛盾 ⇒ 触发降级/回滚。

**定义 142（锚-演两阶段物理提交 A2C）** 物理动作不可回滚，故按角色排序：
- **P 阶段**：锚以完整证据门（须过 G-gate 与内力预算）准备；演只允许可卸载动作（L0/L1，力矩 ≤ F_act，可退回锚的支撑）。
- **C 阶段**：锚先提交（不可逆/半不可逆）；演仅在锚提交成功 ∧ OCC 校验 C1–C3 ∧ G-gate 通过后，以 probationary 提交，观察期 τ_prob 内每周期重验读版本与支撑；任一失败 ⇒ 卸载到锚、力控回撤、回退，不升级不可逆。
- **换角色**：仅当交换后仍满足接地性与内力预算；接地点不可"交换"。L2 不可逆接触禁止以演的 probationary 证据进入，必要时先转正。

**定义 143（支撑可靠性图 SRD、依赖感知界 DAB 与证书 J_c）** 由 G_s/G_c 构造可靠性框图 RBD：串联依赖为 series，真冗余为 parallel，共享传感器/共享支撑为公共节点并用 β-factor 共模。对含锚的接地连通分量 G_k：
P_fail_k=(1−β_k)·(1−R_ind(G_k))+β_k·p_cm,k，R_k=1−P_fail_k；无接地或含环令 R_k=0（结构拒绝）。**部署界**：P_safe ≥ 1−Σ_k(1−R_k)−δ_stale·N_cp−δ_ind·N_cc−P(𝓜 陈旧未检出)−P(回滚失败)。**证书** J_c=J_p⊕(G_s,RBD,{β_k},ver_log,indep_log,commit_log,rollback_log,arb_log)。

**定义 144（并发双臂探-诺-演算子 PCE++）** 每循环：①并发分支推断（ID→摊销后验/OOD→共形带，多分支 CIM）；②对账：D(r)>θ_D ⇒ 共识探针；③**G/C 双门**：G-gate（接地无环+内力预算）+ C-gate（OCC 版本+可串行化）；④任一门失败 ⇒ abort 当前演分支→保持锚→降档/换角色/改步态→重规划；⑤承诺按 A2C 排序（锚先、演 probationary）；⑥探尽→绕行→L2 协商或安全停。预算 k_probes+k_cons+k_arb，并发分支数 K 受时延预算约束。

## 2. 关键算法伪代码（完整版见产物区）

```python
def grounded(G_s, g0, es):                     # IP-139: 接地 + 无环
    for e in es:
        seen, cur = set(), e
        while cur != g0:
            if cur in seen: return False       # 相互支撑环
            seen.add(cur); cur = G_s.next(cur)
            if cur is None: return False       # 悬空支撑
    return True

def occ_commit(T, M, inflight):                # IP-140: 乐观并发
    if any(M.version(k) != v for k, v in T.read_versions.items()):
        return abort(T, 'stale_read')          # C1: TOCTOU
    if conflict_cycle(T.writes, [c.writes for c in inflight]):
        return abort(T, 'non_serializable')    # C2
    for c in inflight:
        if c.premises & T.writes: c.demote('probationary')   # C3
    M.apply(T.writes); M.bump(); return commit(T)

def a2c_commit(anchor, actor, M, conns):       # IP-142: 锚先演后
    if conns.G_gate(anchor) != 'ok': return reject(anchor)
    commit(anchor, irreversible=True)
    commit(actor, probationary=True)
    if not wait_revalidate(actor, M, tau_prob):
        unload_to(anchor); return rollback(actor)
    promote(actor); return 'ok'
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| CAM/SRD | O(\|E\|+\|A_s\|) 环检测；O(\|C\|) 单约束（子集限于耦合团） | O(\|E\|+\|A_s\|) | 接地点与边须诚实、环即拒 |
| ETO | O(\|r_T\|+\|w_T\|)/提交；冲突图 O(N_c²)（可增量） | O(\|𝓜\|+\|inflight\|) | C1–C3 完备、δ_stale 有界 |
| CIM | O(K²·d_b) 合并；仲裁 O(k_arb) | O(K·\|cert\|) | 独立票计数、伪独立 ≤δ_ind |
| A2C | O(τ_prob/Δt) 观察期 | O(1) | 演可卸载、锚不可逆 |
| DAB | O(\|G_s\|+\|RBD\|) | O(\|RBD\|) | RBD 语义诚实、β 显式 |
| PCE++ | O(K·\|CP\|·(k_p+k_c+k_arb)·(C_VOI+d_φ)) | O(\|V\|+\|σ\|+K·\|cert\|) | 独立票、G/C 门、k 预算终止 |

**正确性定理（DCGS 概要）**：在 A33–A40 上加 (A41) 接地支撑（不可逆承诺位于接地无环 G_s，G-gate 结构完备）；(A42) 证据事务（C1–C3 完备、δ_stale 有界、回滚可实现）；(A43) 独立性声明诚实（伪独立 ≤δ_ind，相关分支合并为单票）；(A44) 内力与角色（F_int 预算可执行、演可卸载、τ_prob 内回滚成功）。则：(i) **接地健全性**——任何已提交不可逆接触属于某接地无环分量；相互支撑环以概率 1 被结构拒绝；(ii) **并发一致性**——已提交承诺的读集在提交时有效（除 ≤δ_stale 漏检），并发提交可串行化，中止演不产生无锚悬空承诺；(iii) **并发不放大置信**——CIM 仅按独立分支计票，伪独立共模假共识 ≤δ_ind+P_cm，故并发只能提速或弃权；(iv) **依赖感知可靠性**——P_fail_k 由 RBD+β 计算，正相关共模显式计入而非独立近似；(v) **终止性**——PCE++ 在 k_probes+k_cons+k_arb 内终止于 {承诺, 绕行, 换角色/降档, L2 协商, 安全停}。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| G_s 的边是自声明 → 假接地/假冗余 | 高 | 未知依赖一律按串联；接地接触需独立实测；G_s 变更走证据门+审计 |
| 伪独立/回声室 → 并发假共识 | 高 | 独立性声明+审计；共享 𝒟_meta/传感器合并单票；分歧即弃权 |

| 内力预算估计误差 → 过约束 | 中 | 力矩/电流实测上限；保守 F_bud；超限降载/换角色 |

## 6. 本轮最大风险

**一句话**：本轮的接地与独立性都是**自声明的元数据**——G_s 的一条边、CIM 的一个 ind 声明，都是"我们说它支撑/独立"，而 OCC 的版本校验只保证"证据没被改过"，不保证"证据是对的、支撑是真的"；一旦把串联依赖误声明为并联冗余、或把悬空支撑误声明为接地，A2C 会先锁定一个并不存在的锚，再让演在 probation 里依赖它，而并发提速会让这个假接地比串行系统更快地变成不可逆承诺。

# 第 58 轮产物 · 创新点清单 v34：MultiRobot-Placement（谱系对账×联合放置×声誉容错×断续共识，CRL×JPP×RRB×DTC×J_c×PCE++）

> 承接第 57 轮 IP-133~138（MFSL/XMC/PTM/MXI/FSE/PCE+）与第 56~55 轮证据-交互栈。本轮把部署主体从"单机证据承诺"升级为 **"多机协作的不可逆放置承诺"**：证据从"同一主体的多模态"扩展到"多主体的多谱系"，动作从"接触"聚焦到"放置"这一不可逆锁点，通信从"免费可靠"降级为"分区可延迟"。第 57 轮"一切判定器走隔离"再推一步：**一切说话者（含机器人）也走隔离**——声誉只加权重，永不把单源升格为多源。
> IP 编号：IP-139~IP-144（共 6 个），升级 IP-134/137/138 以纳入谱系对账、放置门与协作共识。

## 2. 关键算法伪代码

### IP-139 CRL（谱系对账与共同成分饱和）

```python
def lineage_reconcile(ledger):
    S = set()
    for e in ledger:
        group = (e.sensor, e.firmware, e.calib, e.corpus, e.exposure)
        e.lineage = group
        S.add(group)
    H = entropy([count(ledger, g) for g in S])      # 谱系分布熵
    for e in ledger:
        # 饱和律：同谱系的第二份证据对共同成分 φ 的增益 ≤ η_0
        e.phi_gain = I0 if first_of_lineage(e, ledger) else eta0
    return ledger, H, len(S), prov_ok(ledger)       # prov 链逐跳可验

def correlated_corroboration(e1, e2):
    # 只有独立谱系才允许计入"多源佐证"
    return e1.lineage != e2.lineage and I(e1, e2) > 0
```

### IP-140 JPP（联合放置：冲突图 + 测放分离 + 副作用传播）

```python
def joint_placement(robots, candidates, ledger, W):
    Gc = conflict_graph(candidates)                  # 共容积/互相改可行域
    P, assign = [], {}
    for p in greedy(candidates, key=utility_over_cost):
        if any(conflict(p, q, Gc) for q in P):       # 冲突集必须独立
            continue
        if p.irr == 'L2' and not place_gate(p, ledger, quorum, P):
            continue                                 # 不可逆放置硬门
        r = argmin(robots, key=lambda x: travel_cost(x, p.site)
                   if x.free and x.lineage not in p.probe_lineages)  # 测放分离
        P.append(p); assign[r] = p
    return P, assign

def propagate_effect(p, robots, comm):
    for r in robots:                                 # 放置改写共享世界
        if not comm.deliver(r, p.effect):
            r.map.mark_stale(p.site)                 # 未回执者禁 L2
```

### IP-141 RRB（声誉 + 单源否 veto + 拜占庭界）

```python
def reputation_update(r, verdict, audit):
    r.rho = clamp(r.rho + (gamma_up if verdict.correct else -gamma_down),
                  rho_min, 1.0)
    if verdict.falsifies_robot(r):                   # 事后证伪 → 全证据隔离
        r.quarantined = True
        audit.retroactive_demote(r.evidence)         # 回溯降权历史证据
    r.w = min(w_max_r, w0 * r.rho)                   # 声誉只改权重

def single_source_veto(evidence_set):
    return len({e.speaker for e in evidence_set}) == 1   # 单源永远不能授权 L2

def commit_quorum(evidence_set, q_min, h_min):
    return (independent_lineages(evidence_set) >= q_min
            and entropy_of_lineages(evidence_set) >= h_min
            and not unresolved_conflict(evidence_set))
```

### IP-142 DTC（断续通信下的证据共识与中继先行）

```python
def delay_tolerant_commit(P, evidence, reachable, q_min, h_min):
    usable = [e for e in evidence if e.speaker in reachable]  # 不可达不计
    if not commit_quorum(usable, q_min, h_min):
        return ('defer', 'no_quorum')                # 绝不带病提交 L2
    return ('commit', P)

def relay_first_plan(partition, candidates):
    # 中继放置不可逆度 ≤ L1，用可回收放置购买连通性
    relays = [p for p in candidates if p.irr in ('L0', 'L1')
              and p.kind == 'relay' and utility_connectivity(p, partition) > 0]
    return solve_conflict_independent(relays, key=utility_connectivity)
```

### IP-143 PlaceGate（放置门 + 证书 J_c）

```python
def place_gate(p, ledger, quorum, conflicts):
    if p.irr == 'L2':
        ok = (probe_or_margin(ledger)                # EV-probe*/EV-margin 必居其一
              and entropy_of_lineages(ledger) >= h_min
              and not single_source_veto(ledger)     # 单源否 veto
              and quorum.reachable and commit_quorum(ledger, q_min, h_min)
              and conflicts.resolved(p)
              and not stale_endorser(ledger))        # 未收 effect 回执者不算
        return ('ok' if ok else 'reject', 'L2_placement')
    return ('ok' if few_shot_evidence_gate(p, ledger) else 'reject', 'reversible')

def placement_certificate(P, ledger, quota, effects, audit):
    if not all(place_gate(p, ledger, quota, P)[0] == 'ok' for p in P):
        return ('reject', 'gate')
    if any(single_source_veto(e) for e in ledger if e.supports_irreversible):
        return ('reject', 'single_source')
    return ('ok', Jc(prov_chains(ledger), lineages(ledger), conflicts_log(P),
                     quorum_proof(quota), relay_graph(P), effect_receipts(effects),
                     reputation_log(audit)))
```

### IP-144 PCE++/MCP（协作探-诺-放-演）

```python
def collaborative_probe_place_evolve(x0s, M, task, robots, budget, consent):
    route = plan_on_map(M, task, risk_model)
    ledger, sched = [], []
    for cp in route.checkpoints:
        per_robot = [meta_few_shot_infer(M, cp.region, M.obs[r][cp.region], meta)
                     for r in robots]
        ledger += tag_provenance(per_robot)          # 带谱系标签入台账
        ledger, H, nsrc, ok = lineage_reconcile(ledger)
        cands = admissible_placements(cp, M, F_abs)  # 落脚/探针/中继
        P, assign = joint_placement(robots, cands, ledger, M.world)
        # 分区时先买连通性
        if partition(robots) and not commit_quorum(ledger, q_min, h_min):
            R = relay_first_plan(partition(robots), cands)
            execute(R); route = replan_after_relay(route, R); continue
        # 探针预算：VOI 用独立谱系信息增益（同源饱和项为 0）
        while schedule_risk(x0s, P, M).halt and budget.left > 0:
            q = argmax(cands, key=lambda z: voi_lineage(z, ledger, H) - cost(z))
            if voi_lineage(q, ledger, H) < theta_voi: break
            ledger += tag_provenance(execute_probe(q, robots, cap=F_abs))
            ledger, H, nsrc, ok = lineage_reconcile(ledger)
            P, assign = joint_placement(robots, cands, ledger, M.world)
        if all(place_gate(p, ledger, quorum(robots), P)[0] == 'ok' for p in P):
            execute(P); propagate_effect(P, robots, comm)
            sched.append(commit(P, assign)); continue
        alt = reroute(M, cp, risk_model)             # 绕行/降档/安全停
        if alt and feasible(alt): route = alt; continue
        return negotiate_or_stop(cp, M, P, consent, tau_int=tau_int(active(robots)))
    return sched, ledger, M

def distributed_rollback(verdict, robots):
    # 事后证伪：广播 + 全机回溯降权 + 未执行 L2 强制重估
    for r in robots: r.receive(verdict)
    for e in affected_evidence(verdict):
        for r in robots: r.demote(e)                 # prov 链根哈希定位
    for p in pending_irreversible(robots):
        if not place_gate(p, global_ledger(robots), quorum(robots), p.conflicts)[0]:
            cancel(p)                                # 已执行 L2 只能标记受损改路
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CRL | O(\|𝒮\|·d_ℓ) 每轮对账 | O(\|𝒮\|) | 谱系声明诚实、溯源链可验（A41） |
| JPP | O(\|𝒫\|·\|R\|+\|E_c\|) 贪心；精确 NP-hard | O(\|𝒫\|+\|E_c\|) | 冲突集独立、L2 门硬约束（A44） |
| RRB | O(\|R\|) 每次判决 | O(\|R\|) | 单源否 veto、f<f_max（A42） |
| DTC | O(\|𝒮\|·log\|𝒮\|) 每轮 gossip | O(\|𝒮\|) | 分区不采信不可达证据（A43） |
| PlaceGate | O(\|𝒮\|+\|E_c\|) | O(\|𝒮\|) | 同源折叠、L2 双谱系 + quorum |
| PCE++ | O(\|CP\|·\|𝒫\|·(\|R\|+C_VOI)) | O(\|V\|+\|𝒮\|) | quorum 或安全停四态完备 |

**正确性定理（Collaborative Diverse-Placement Soundness, CDPS）**
假设 A37–A40（第 57 轮）成立；**(A41)** 谱系声明诚实，H_L 真实反映独立性，同源饱和 η≤η_0；**(A42)** 拜占庭机器人比例 f<f_max，单源否 veto 不可绕过，声誉只改权重不改证据类别；**(A43)** quorum 只由**可达**独立谱系构成，分区时不采信不可达机器人证据；**(A44)** 放置冲突图与不可逆度声明诚实，effect 广播回执可验且陈旧区域禁 L2。则：

1. **集体承诺健全性**：P(fail) ≤ δ_f + ε_meta(k) + δ_probe + ε_h(w_max) + δ_byz + δ_corr(H_L)。其中 δ_corr(H_L) 随谱系熵 H_L 单调不增，且在 H_L 饱和后不再下降——**诚实承认协作对共同偏差存在天花板**，这是本轮相对第 57 轮唯一不试图消除、而是显式承认的误差项。
2. **协作单调性修复**：把第 57 轮的"交互单调性"从"机器人数量"改写到"独立谱系数"。新增**同谱系**机器人只能降低其自身随机噪声（ψ 维），不降低共同偏差（φ 维），因此**既不缩小 P_fail 上界，也不允许更大胆的 L2 放置**；只有新增**独立谱系**才允许放宽动作。多机器人不再构成单调性反例。
3. **放置协议无死锁**：G_c 上的确定性优先序（不可逆度低者先行、测放分离、中继先行）使联合放置贪心在有限步终止；不可解冲突一律降级为可逆动作或安全停，不存在"互相等对方先放"。
4. **分布式回溯收敛**：verdict 以 prov 链根哈希定位受影响证据，有限轮 gossip 后全机一致降权；已执行 L2 不可撤销，只标记 `world_damaged(site)` 并强制改路，未执行 L2 全部重估。
5. **部署界**（对检查点 × 机器人的联合界）：

```
P_safe ≥ 1 − Σ_cp Σ_{r∈R(cp)} (δ_f + ε_meta(k) + δ_probe + ε_h(w_max) + δ_byz)
             − Σ_cp δ_corr(H_L(cp))
             − P(放置冲突未检出) − P(不可达证据被误用) − P(effect 回执丢失)
```

关键：**谱系给独立性、饱和律给上界**（协作效率不押在机器人数量上，而押在独立谱系数上）；**放置按不可逆度分层**（用可回收的中继/探针去购买不可逆落脚所需的证据与连通性）；**测放分离**把"用不可逆动作买信息"的悖论在角色层面拆开；**单源否 veto + 分布式回溯**保证一个坏说话者或一次事后证伪都不会被物理锁死成永久错误。

## 6. 本轮最大风险

**一句话**：多机器人的"一致"最容易被误当成独立复现，而共享谱系（同传感器/同语料/同标定史）的机队会把同一个共同偏差放大 N 倍后写进**不可逆放置**——放置一旦落地，错误就被物理锁死并随共享地图传染全队，事后只能标记受损、无法撤销；因此必须以谱系熵门、单源否 veto、测放分离与中继先行四道护栏守住"不可回滚的那一步"，宁可让不独立的多数保持沉默。
