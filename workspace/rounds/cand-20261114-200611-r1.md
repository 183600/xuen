# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「人机协作」×「动作空间」）

> R69 把不确定性一分为二（aleatoric / epistemic），并用流匹配多模态策略 + 主动交互去消解「该走哪个动作模态」。但它站着一个未经检验的假设上：**唯一不确定的是机器人该选哪个动作，而动作空间本身是固定、已知、且只属于机器人的**（𝒜_+ = 𝒜_task × 𝒜_info）。在真正的人机协作里，这个假设同时错两处：
>
> 1. **人不是神谕，而是共同行动者。** R69 的「问」假设被问者只提供一个关于固定隐变量的噪声读数。但协作者有自己的动作空间、能力、可用性与承诺；一句提问会占用其注意力、改变其计划、产生期待，一个「递给你」的提议甚至会让某个原本不可行的动作变得可行。**交互不只是减少熵，它还在构造动作空间、制造承诺。**
> 2. **相关的动作空间是「联合」的。** 共享自由度、共享物体、共享时序意味着：真正危险的问题不是「我这个动作安不安全」，而是「我们俩是不是都以为对方在拿」「谁拥有这个自由度」「此刻存在可行的交接会合点吗」。动作空间的**可容许性本身**（角色、权属、可达交接窗口）是未知的，且部分由协作动作**选择出来**。
>
> 核心命题：**把 R69 对「哪个动作」的不确定性，扩展为对「哪些联合动作是可行的、谁拥有哪部分、在什么时刻」的不确定性——一个 2×2 不确定性格（模态/空间 × aleatoric/epistemic）。「模态」这一行是 R69；新的「空间」行是协调不确定性，它不靠提问消除，而靠能扩张/塑造联合动作空间、并建立可撤销承诺的协调动作来消解；所有联合动作过联合安全证书，所有承诺渐进、带履约证据、可撤销；当协调无利可图、信任未标定或联合认证失败时，解耦并退回 R69/R68。** 命名 **DUET-RAS**（Dual-agent Unified action-space, Epistemic coordination & Trust-calibrated risk adaptation）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我们究竟能一起做什么、谁做哪一部分、在什么时候——以及我能否相信这个答案会一直成立**」——不确定性不只是刹车或提问，也可以是一次让位、一次交接、一次「我先做一小步给你看」。

## 0. 直觉与动机

**灵感 1（人机协作 → 从「询问神谕」到「共建动作空间」）**
直觉：R69 眼中的协作者是一台测量仪：问一句，得到一个关于固定隐状态的带噪读数，更新后验。但真实伙伴不是传感器。提问会消耗注意力、改变计划、产生承诺；协作动作还可能**创造**可行性——把手柄转过去、把路让开、放慢速度让出抓取时机、先托住另一端。这些不是「关于世界的观测」，而是「改变世界与双方可行动集」的动作。因此 R70 的第一性对象不是「隐变量 + 噪声回答」，而是「**两个主体共同选择并构造一个可容许的联合动作集**」。这把 R69 的「信息动作」升级为「协调动作」：协调动作既可能降低熵，也可能**扩大可行集**，还可能因承诺而**缩小未来的选项**。

**灵感 2（动作空间 → 不确定性住在「空间」里，而不只在「点」上）**
直觉：R69 在一个固定空间里采 K 个点。但当伙伴的能力未知时，**支撑集本身**就是不确定的：也许他举不起那一端、来不及到达、此刻不可用，或者我们对「谁在拿」理解不一致。把一个「可行集未知」的问题硬表示成「动作点上的分布」，会系统性低估风险：点上分布可能很尖（每个候选动作都很确定），而可行集可能整个是错的。正确的对象是**可容许联合动作的集合**（credal / conformal 集）及其直径与歧义质量。动作空间不确定性是对「支撑集」的认知不确定性，可以在没有任何单点歧义时依然很大。

**灵感 3（2×2 格 → R69 是其中一行，不是竞争对手）**
直觉：两个轴——「不确定什么」（模态 vs 空间）与「为什么不确定」（噪声 vs 无知）。R69 填满「模态」这一行：模态内噪声（U_MA）与模态间歧义（U_ME）。「空间」这一行分成空间内 aleatoric（伙伴运动/时序抖动、耦合残差，U_SA）与空间 epistemic（能力、可用性、权属、承诺，U_SE）。真正新的是 **空间×epistemic = 协调歧义**。R69 的 λ_floor 对噪声与未消解的模态歧义是对的；把它套到协调歧义上，就像「不知道谁在开车就踩更狠的刹车」。新角落需要的是协调，而不是收紧。这保持了本系列的理论姿态：**新层必须严格泛化旧层**，R69 是 U_SE=0、耦合为空时的特例。

**灵感 4（共享自由度 → 权属/仲裁是一个新的安全变量）**
直觉：协同搬运里最致命的不是「我的动作越界」，而是「我们都以为对方在拿」或「我们同时对同一个自由度施力」。共享自由度让两个控制回路在物理上闭环耦合：权属歧义会造成同时松手、同时加力、内部力打架。于是安全必须从「机器人轨迹安全」升级为「**联合轨迹 + 权属唯一性 + 耦合可行性**」安全。动作空间第一次成为一个显式的安全对象，而不是策略的输出容器。

**灵感 5（信任是双向的 → 协作会把冗余变成依赖）**
直觉：R68/R69 始终把人类当作独立的安全备份。一旦开始协调，人可能因为机器人看起来很自信而停止监控；机器人也可能因为人看起来很能干而过度委派。两者都在**移除独立冗余**。于是出现一个反直觉结论：**协作可以在提高任务成功率的同时降低总安全性**。所以信任必须双向标定：机器人对人的委派要落在校准过的能力界内；人对机器人的依赖要靠「诚实地显示残余不确定性」来维持（而不只是显示一个点置信度）。这是本轮最大的新风险，也是 TCG 与渐进承诺存在的理由。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（DUET-RAS 总览与不变式）** DUET-RAS = (JAS, HAM, CUA, CAA, ROL, Co-VoI, PRC, LPG, TCG, JSC, DEC, RAS-WM§)。五条不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **协调预算硬约束**：单位时间协调动作 ≤ 1 次、承诺深度 ≤ D、社交/物理成本 ≤ c_max；任一协调动作必须通过与任务动作相同的 C-RAS-WM 认证；
(iii) **权属唯一性**：任一时刻每个共享自由度必须恰有一个权属主体，或处于显式认证的共享控制律下（定义 315）；
(iv) **承诺纪律**：口头承诺只是假设，不是证据；不可逆动作只在履约证据（定义 317）解锁后执行；任何承诺必须附带安全中止与有界撤销成本；
(v) **可解耦**：任意时刻存在一个只依赖机器人自身、把人类视为独立动态障碍的安全兜底（定义 321）。

**定义 311（联合动作空间与耦合 JAS）** 机器人动作 a_R ∈ 𝒜_R，人类动作 a_H ∈ 𝒜_H（未知、部分可观），耦合变量 c ∈ 𝒞 描述共享物体位姿、接触力旋量、相对位姿与时序相位。联合动作 a_J = (a_R, a_H, c) ∈ 𝒜_J = 𝒜_R × 𝒜_H × 𝒞。机器人不直接输出 a_R，而输出**联合契约** κ = (a_R, r, τ_sched, c_spec)：自己做什么、提议什么角色 r、何时、以何耦合方式。可容许集 Ω(o) ⊆ 𝒜_J 未知，只能估计为 credal 集 Ω̂(o)。

**定义 312（人类动作空间模型 HAM）** 隐变量 θ_H = (C_H, π_H, avail, r_pref, commit_disp)：能力集 C_H（物理上能做哪些动作）、策略 π_H、当前可用性 avail、角色偏好、承诺倾向。用 conformal 估计能力集 Ĉ_H^{1−α}(o)（覆盖率 ≥ 1−α）与可用性概率；对安全预测另取上分位运动预测 y_H^{1−β}(o)。**能力（can）、可用（will now）、承诺（has agreed）三者严格分离**——R69 把它们混成一个「回答」。

**定义 313（协调不确定性代数 CUA）** 四个角落：

| | aleatoric（噪声，不可约） | epistemic（无知，可约） |
|---|---|---|
| **模态** | U_MA = Σ_k ŵ_k tr(Σ_k)（R69 的 U_ale） | U_ME = H_mode·g(Δ_min)（R69 的 U_epi） |
| **空间** | U_SA = 伙伴运动/时序抖动 + 耦合残差（conformal） | U_SE = H(r, O, avail | o)·h(diam Ω̂)（协调歧义） |

其中 r 为角色、O 为权属矩阵、diam Ω̂ 为可行集直径，h 单调递增。R69 ≡ 空间行投影为 0。U_SE 的语义是「我们连能做什么、谁做、何时做都不一致」，与「某个动作的模态分不清」正交，故不与其简单相加，而进入不同通道（定义 316、321）。

**定义 314（协调动作字母表 CAA）** 扩展 R69 的信息动作：𝒜_coord = {offer(r), request(r), commit(r,τ), yield, handover(spec), stabilize, wait, clarify_role}。每个协调动作同时改变双方的可行集与信念；R69 的 g = (g_gaze, g_probe, g_ask) ⊂ 𝒜_coord 是其「只降熵、不扩张、不承诺」的子集。语言部分仍由冻结 LLM 从软提示解码，梯度不回传语言模型。

**定义 315（角色与权属层 ROL）** 角色向量 r ∈ ℛ（leader/follower、holder/receiver、actor/watcher 等）；权属矩阵 O ∈ [0,1]^{d×2}，对每个共享自由度 α_R + α_H = 1（刚性权属）或处于认证的共享控制律（导纳/阻抗混合）。**权属冲突** A_conf = 1[‖α_R·v_R + α_H·v_H − v_obj‖ > δ_v ∨ ‖F_R + F_H − F_obj‖ > δ_F]（双方都以为在控制 / 都不控制）。角色歧义熵 H(r|o) 按冲突代价加权：拿错角色比拿不到角色更贵。

**定义 316（协调价值 Co-VoI）** 对协调动作 g：
Co-VoI(g) = I(θ_H; y | g, o) + λ_exp·E[|Ω̂(g,o)| − |Ω̂(o)|] − λ_opt·OptionLoss(g) − c(g)，
其中第一项是 R69 的 VoI（关于能力/可用性/角色的信息增益），第二项是**可行集扩张**（一次好的 offer/handover 能创造原本不存在的动作），第三项是承诺带来的**期权损失**（不可逆性），c(g) 为物理/社交成本。选 g* = argmax Co-VoI，s.t. risk(g) ≤ ε_coord 且预算未超。若 max ≤ 0：不协调，退回 R69。**R69 的 MINT 是 Ω 固定、OptionLoss=0 的特例。**

**定义 317（渐进可撤销承诺 PRC）** 承诺元组 γ = (role, deadline, φ_ful, rev_cond)，φ_ful 为可核验履约谓词（如「已接触」「已到达会合点」「已承重 ≥ w」）。状态机：proposed → accepted（仅更新信念，**不解锁不可逆动作**）→ evidence-linked（履约证据首次出现）→ discharged；任一安全条件失效 → revoked。承诺深度 d ∈ {0,1,2,3}，每级要求前一级履约率 ≥ θ_d；深度 d 解锁的成本/不可逆性上界为 C_d（递增）。

**定义 318（诚实可读性-可预测性护栏 LPG）** 协作要求人能预测机器人：可读性 L = E[人类对机器人目标/角色的推断精度]。但可读性可被操纵（表演式清晰），且与最优性冲突。护栏要求：人类预测误差 ≤ ε_leg，且**不得通过压低不确定性显示来换取可读性**——显示置信 c_disp 必须满足 |c_disp − c_true| ≤ τ_trust（与定义 319 共用）。诚实可读性是一个约束，不是一个可被优化的奖励。

**定义 319（双向信任标定门 TCG）** 机器人对人的依赖：仅当 P(success | Ĉ_H^{1−α}, r) ≥ 1−δ 且 Co-VoI 足够时，才把角色 r 委派给人，否则保留在机器人侧。人对机器人的依赖：机器人必须显示**校准后的残余风险**（分布/区间，而非点值）；当检测到人类监控投入 e_h 下降而机器人不确定性仍高时（过度依赖代理指标：反应时、注视、接管延迟），提高显式度、放慢、或主动放弃委派。反向的过度不信任则通过可撤销的小步演示提供证据。TCG 同时限制承诺深度 d ≤ d_max(e_h, U_SE)。

**定义 320（联合安全证书 JSC）** 联合轨迹 ξ_J 必须满足：
(a) 分离约束 d(x_R, x_H) ≥ d_min + κ·σ_pred（conformal 人类预测）；
(b) 协同内力/力矩 ≤ w_max；
(c) 权属唯一（定义 315）或认证共享律；
(d) 交接会合可达：∃ t ≤ deadline，‖x_obj(t) − x_H^target(t)‖ ≤ δ_hand；
(e) 安全中止可达：存在解耦动作使机器人留在已认证的单边安全集内；
(f) 人类感知 CBF h_J(x_J) ≥ 0。
JSC = (分离裕度, 耦合可行性, 权属唯一性, 中止可达性, CBF 余量)。任一协调动作不过 JSC 即作废，相关 U_SE 视为未消解。

**定义 321（解耦兜底 DEC 与严格包含）** 解耦映射 D：把人类视为独立动态智能体 + 动态障碍，执行 R69 的单边 FLUID 策略（或 R68），并用定义 320 的人类感知安全层包住。触发 D 的条件：Co-VoI ≤ 0、TCG 失败、JSC 失败、承诺被违、U_SE 超预算未消解。**R69 = DUET 在「人类为外生神谕、耦合 𝒞=∅、角色平凡、Ω 固定」时的投影**（定理 18）。

**定义 322（威胁模型 AIC-DUET）** ℰ_DUET = ℰ_FLUID × ℰ_coop。新增：策略性不合作、**装弱（feigned incapability / sandbagging）**、承诺违约与「承诺诱饵」（先答应再撤，把机器人诱入死角）、以角色提议为名的社交工程、协同施力的对抗性力攻击、**信任劫持**（夸大/压低置信以改变对方依赖）、以及 LLM 幻觉出不存在的协作者或能力（幻影角色）。并入 AIC 对抗训练。

**定义 323（参与式审计 VQAuditor-Coop）** 审计协调决策：角色是否在能力界内被提议、承诺是否单源采纳、权属是否唯一、残余不确定性是否被诚实显示、是否发生了过度委派、解耦是否及时。结论回灌 AuditBuf，成为下一轮 TCG 阈值与 Co-VoI 先验。

**定义 324（证书 J_DUET）** J_DUET = (J_FLUID, role_calibration_ece, U_coord_before, U_coord_after, co_voi_ratio, authority_conflict_count, commitment_fulfillment_rate, trust_calibration_error, joint_safety_margin, decouple_count, duet_ver)。Valid ⇔ Valid(J_FLUID) ∧ ECE ≤ τ_ece ∧ 权属冲突 = 0 ∧ 承诺纪律满足 ∧ 信任标定误差 ≤ τ_trust ∧ 协调预算未越界 ∧ 解耦兜底可用。

**定义 325（共享约定 / 共同基础，慢变量）** 交接手势、角色偏好、时序约定等**共享约定**只在任务间/离线更新，实时流零写（继承不变式 i）；存为带版本的 coordination prior。这样既可积累共同基础，又防止在线漂移与「约定投毒」在环内扩散。

**定义 326（协调预算与自适应深度）** 默认 d=0（不协调，走 R69）。仅当 U_SE > TAU_COORD 且 Co-VoI > 0 时提升深度 d；d 的每一级都需 JSC 与 TCG 双重放行。协调深度是「收益-成本-信任」的三方折中，保证 P99 实时预算。

# IP-264/265 JAS + HAM：联合契约与人类动作空间信念
class JointActionModel:
    def __init__(self, trunk, flow, ham, conformal_q):
        self.trunk, self.flow, self.ham = trunk, flow, ham
        self.q = conformal_q                      # 能力/运动 conformal 分位

    def sample_contracts(self, o_t, K):
        z = self.trunk(o_t)                       # 复用 R69 MTM
        seeds = randn(K, D)
        return [self.decode(x) for x in self.flow(z, seeds)]   # κ=(a_R,r,τ,c)

    def capability_set(self, o_t):                # 能力 ≠ 可用 ≠ 承诺
        return self.ham.conformal_set(o_t, alpha=self.q)

# IP-266 CUA：2×2 不确定性格（R69 模态行 + 新空间行）
def coordination_lattice(samples, ham, o_t):
    U_MA, U_ME = decompose_mode_row(samples)      # 直接复用 R69 AUD
    caps, avail = ham.capability_set(o_t), ham.availability(o_t)
    omega = admissible_set(samples, caps, avail)
    U_SA = ham.motion_residual_p95(o_t)           # aleatoric：抖动/耦合残差
    U_SE = role_entropy(samples) * diam_factor(omega)   # epistemic：协调歧义
    return dict(U_MA=U_MA, U_ME=U_ME, U_SA=U_SA, U_SE=U_SE, omega=omega)

# IP-268/269 ROL + Co-VoI：角色选择与协调价值
def choose_coordination(lat, o_t, budget, trust):
    best = None
    for g in coord_candidates(lat):               # offer/request/commit/yield/handover...
        if not budget.allow(g) or not c_ras_wm.certify_coord(g, o_t):
            continue
        if not jsc.precheck(g, lat, o_t):         # 联合安全预检
            continue
        info = mutual_info(lat, g, o_t)           # ~ R69 VoI
        expand = expected_set_expansion(lat, g, o_t)
        option = option_loss(g)                   # 承诺不可逆性
        score = info + EXP_W * expand - OPT_W * option - cost(g)
        if best is None or score > best.score:
            best = (g, score, choose_role(lat, g, trust))
    return best if best and best.score > 0 else None   # 无利可图 → R69

# IP-270/272 PRC + TCG：渐进承诺与双向信任
def commit(agent_pair, g, depth, trust):
    if depth > trust.max_depth: return 'DECOUPLE'
    gamma = (g.role, g.deadline, g.fulfill_pred, g.revoke_cond)
    propose(gamma)                                # 口头接受只是假设
    if not wait_evidence(gamma.fulfill_pred, g.deadline):
        return 'REVOKE'
    if not trust.display_is_honest() or trust.overreliance_detected():
        return 'SLOW_AND_EXPLAIN'                 # 保留人在环
    return 'DISCHARGE' if depth_ok(depth) else commit(agent_pair, g, depth+1, trust)

# IP-273 JSC：联合安全证书（人类感知 + 权属 + 会合可达）
def joint_safety(xi_J, o_t):
    sep = min_distance(xi_J.robot, human_pred(o_t))
    auth = authority_unique(xi_J.ownership) or certified_shared_law(xi_J)
    rendezvous = exists_reachable_handover(xi_J, o_t)
    abort = exists_decoupling_in_safe_set(xi_J)
    return sep >= d_min + KAPPA*pred_std and auth and rendezvous and abort \
           and min_cbf(xi_J) >= 0

# IP-276 主闭环（继承 R69，只在「空间行」处插入 DUET 层）
def DUET_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, _ = M.cof.step(...)
    # 1) R69 模态层（原样保留）
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_MA, U_ME, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    # 2) R70 空间层：联合契约 + 人类动作空间信念
    lat = M.cua.lattice(M.jas.sample_contracts(o, K), M.ham, o)
    # 3) 协调决策：无利可图/不可信/不安全就不协调
    g = None
    if lat['U_SE'] > TAU_COORD and not M.tcg.untrusted():
        g = M.co_voi.choose(lat, o, M.budget, M.tcg)
    # 4) 渐进承诺 + 联合认证；任一失败立即解耦
    if g is not None:
        status = M.prc.commit(g, depth=M.tcg.depth(lat, o), trust=M.tcg)
        if status not in ('DISCHARGE', 'SLOW_AND_EXPLAIN') or not M.jsc(joint_of(modes, g)):
            M.dec.decouple(); g = None            # 退回 R69 单边策略
    # 5) 风险缩放：协调成功用模态+空间 aleatoric；失败把 U_SE 视同 epistemic
    U_floor = lat['U_MA'] + (lat['U_SA'] if g else 0.0) + \
              (0.0 if g else lat['U_SE'])
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    A = M.ach.propose(x_prime, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    if g is not None:                             # 协调只改角色/共享律，不改安全包络
        k = min(k, M.jsc.authority_prefix(g))
    # 6) 诚实显示残余不确定性（防过度依赖）+ 审计 + 证书
    M.tcg.display(residual_risk=lat['U_SE'], interval=True)
    M.vqa_coop.submit_async(g, lat, status if g else None)
    return k, lam, modes, lat, g

## 3. 推导

**引理 19（联合不确定性格的分解完备性）** 在 A99（联合决策风险对模态与空间两轴可加可分：L(a_J) = L_mode(a_R) + L_space(r,O,c) + o(‖·‖)）下，任意联合决策的期望遗憾可分解为四个角落的贡献之和。R69 的标量不确定性恰是模态行的两个角落；空间行的 U_SE 下界由角色熵与可行集直径共同给出，且不可由模态行的任何统计量一致估计。系：**只做模态消歧的策略在协调歧义大时存在不可消除的遗憾下界**——补 R69 的盲区不是调参能解决的。

**引理 20（协调价值对询问价值的包含与扩张）** 当 Ω 固定、无承诺（OptionLoss=0）时 Co-VoI(g)=VoI(g)，R69 的 MINT 是精确特例。一般地，Co-VoI − VoI = λ_exp·E[Δ|Ω|] − λ_opt·OptionLoss。故：**能扩张可行集且低不可逆性的协调动作（offer、yield、stabilize）价值高于纯询问；高不可逆性的承诺（commit 到深度 3）只有在信息增益足够大且期权损失有界时才值得。** 这给出「先小步、后承诺」的定量理由（PRC 的必要性）。

**引理 21（承诺健全性与无死锁）** 若每个承诺附带 (a) 有界履约期限、(b) 可核验履约谓词、(c) 安全中止动作、(d) 撤销成本上界 C_rev，且耦合依赖图无环或存在固定优先级，则双边承诺协议在有限期限内或完成、或安全中止，且不会进入互相等待的死锁。系：**渐进承诺的每一级都必须自带出口**；「等你先动」的对称等待正是 R69 无法表达、而 HRC 最常见的协调失败。

**引理 22（冗余侵蚀 / 信任吸收上界）** 设人类独立安全贡献 R_H、监控投入 e_h、机器人显示置信与真实置信之差 δ_c = c_disp − c_true。行为模型 ∂e_h/∂δ_c < 0（机器人越显得确定，人越少监控）。则有效冗余 R_eff = R_R + e_h(δ_c)·R_H·(1−overlap)，且当 δ_c > τ_trust 时存在尾部风险增量 Δ_tail ≥ κ·(R_H − R_eff)。故**诚实显示残余不确定性是安全动作，不是交互礼仪**；TCG 的 |δ_c| ≤ τ_trust 给出冗余侵蚀的上界。

**定理 18（DUET 严格包含 R69/R68）** 在 A99–A101 下，把人类设为外生神谕、耦合 𝒞=∅、角色平凡、Ω 固定，则 DUET 的协调层不激活（U_SE=0、Co-VoI≤0），其策略逐指令等于 FLUID；当 TCG/JSC/承诺任一失败或 U_SE 超预算未消解，DEC 退回 FLUID/R68。故任意状态期望风险 ≤ R69，且安全侧不做让步；协调成功只在「已认证的联合可行集」上获得 resolution/expansion bonus。

**定理 19（联合安全与无突变）** 若每个协调动作过 JSC（定义 320）与 C-RAS-WM 认证，则联合物理风险 ≤ ε_joint；协调只改变角色/权属/共享律，不改变机器人安全包络；权属唯一性 + 中止可达性保证解耦总能在有界时间内回到已认证单边安全集；R68 换装不变式与 R69 交互安全（定理 17）保持 ⇒ 控制连续、无突变。若 JSC 失败，λ 单调不降地退回 R69，且不得以「人类会配合」为由放宽包络。

## 6. 本轮最大风险

**一句话**：DUET-RAS 的全部收益押在「伙伴的动作空间模型可信、且协作不会让信任单向迁移」这一前提上——**若角色/能力信念未标定，或被装弱、承诺诱饵、社交工程策略性利用，系统会自信地把一个人委派到他没有能力承担的角色，或让人因为机器人「看起来很确定」而不再监控；协作于是把人类从独立安全备份变成被拖入危险的角色——最危险的不是机器人算错，而是它让人相信它算对了。**

**次级风险与缓解**：
1. **权属歧义 / 共享自由度冲突**（双方都以为对方在拿）→ 权属唯一性约束 + A_conf 检测 + JSC（定义 315、320、定理 19）；
2. **承诺违约与承诺诱饵** → 渐进承诺 + 履约证据 + 安全中止 + k 源证据纪律（定义 317、引理 21、E308）；
3. **过度依赖 / 信任吸收** → 诚实残余不确定性显示 + 监控投入代理 + 承诺深度门（定义 319、引理 22、E307）；
4. **协调动作本身不安全或不可逆** → JSC + C-RAS-WM 认证 + 解耦兜底（定义 320–321、定理 19）；
5. **人类模型 OOD / 装弱** → conformal 能力集 + 分布外检测 + 小步演示取证，绝不把单次观察当能力证据（定义 312、E309、E314）；
6. **协调预算被多轮承诺击穿** → 默认 d=0 + 自适应深度 + 预算硬约束（定义 326、E312）。

**定义 315（ROL）** 角色 `r∈ℛ`；权属 `O∈[0,1]^{d×2}`，每自由度 `α_R+α_H=1` 或认证共享律；冲突 `A_conf=1[‖α_R v_R+α_H v_H−v_obj‖>δ_v ∨ ‖F_R+F_H−F_obj‖>δ_F]`；角色熵按冲突代价加权。

**定义 316（Co-VoI）** `Co-VoI(g)=I(θ_H;y|g,o)+λ_exp E[|Ω̂(g,o)|−|Ω̂(o)|]−λ_opt OptionLoss(g)−c(g)`；`g*=argmax`，s.t. 安全与预算；`≤0` 则不协调、退回 R69。R69 MINT = Ω 固定、OptionLoss=0 特例。

**定义 317（PRC 渐进承诺）** `γ=(role,deadline,φ_ful,rev_cond)`；proposed→accepted（仅更新信念）→evidence-linked→discharged，或 revoked；深度 `d∈{0,1,2,3}`，每级要求前级履约率 ≥θ_d，成本上界 `C_d` 递增，每级自带安全中止。

**定义 318（LPG 诚实可读性）** 人类预测误差 ≤ε_leg；显示置信必须 `|c_disp−c_true|≤τ_trust`；禁止用压低不确定性显示换可读性——可读性是约束，不是可优化奖励。

**定义 319（TCG 双向信任）** 委派仅当 `P(success|Ĉ_H^{1−α},r)≥1−δ`；检测监控投入 `e_h` 下降而 U_SE 仍高（过度依赖）则放慢/显式化/收回委派；反向不信任用可撤销小步演示取证；承诺深度 `d≤d_max(e_h,U_SE)`。

**定义 320（JSC）** 联合轨迹须满足：分离 `d≥d_min+κσ_pred`；协同内力 ≤w_max；权属唯一或认证共享律；交接会合可达（∃t≤deadline，‖x_obj−x_H^target‖≤δ_hand）；解耦安全中止可达；人类感知 CBF `h_J≥0`。任一不过 ⇒ 协调动作作废，U_SE 未消解。

**定义 321（DEC 与严格包含）** 解耦映射 D：人类视为独立动态智能体 + 障碍，执行 R69 单边 FLUID/R68 并加人类感知安全层；触发条件为 Co-VoI≤0 / TCG 失败 / JSC 失败 / 承诺违约 / U_SE 超预算。R69 = 「外生神谕 + 𝒞=∅ + 角色平凡 + Ω 固定」的投影（定理 18）。

**定义 322–323（威胁与审计）** `ℰ_DUET=ℰ_FLUID×ℰ_coop`：策略性不合作、装弱、承诺诱饵、角色提议社交工程、协同力攻击、信任劫持、幻影角色。VQAuditor-Coop 审角色是否在能力界内、承诺是否单源、权属是否唯一、残余不确定性是否诚实显示、是否过度委派。

**定义 324–326（证书/慢变量/预算）** `J_DUET` 并入 role ECE、U_coord 前后、co_voi、权属冲突、履约率、trust ECE、联合裕度、解耦数；共享约定只在任务间离线更新（零实时写），带版本防约定投毒；默认 d=0，仅 U_SE 高且 Co-VoI>0 时升深度，JSC+TCG 双放行。

# IP-264/265 JAS + HAM：联合契约采样与人类动作空间信念
class JointActionModel:
    def sample_contracts(self, o_t, K):                 # 复用 R69 trunk
        z = self.trunk(o_t)
        return [self.decode(x) for x in self.flow(z, randn(K, D))]  # κ=(a_R,r,τ,c)
    def capability_set(self, o_t):
        return self.ham.conformal_set(o_t, alpha=self.q)  # 能力≠可用≠承诺

# IP-266 CUA：2×2 格（R69 模态行 + 新空间行）
def coordination_lattice(samples, ham, o_t):
    U_MA, U_ME = decompose_mode_row(samples)            # 直接复用 R69 AUD
    omega = admissible_set(samples, ham.capability_set(o_t), ham.availability(o_t))
    U_SA  = ham.motion_residual_p95(o_t)                # aleatoric
    U_SE  = role_entropy(samples) * diam_factor(omega)  # epistemic
    return dict(U_MA=U_MA, U_ME=U_ME, U_SA=U_SA, U_SE=U_SE, omega=omega)

# IP-268/269 ROL + Co-VoI：协调动作与角色选择
def choose_coordination(lat, o_t, budget, trust):
    best = None
    for g in coord_candidates(lat):
        if not budget.allow(g) or not c_ras_wm.certify_coord(g, o_t): continue
        if not jsc.precheck(g, lat, o_t): continue       # 联合安全预检
        info   = mutual_info(lat, g, o_t)                # ~ R69 VoI
        expand = expected_set_expansion(lat, g, o_t)     # 可行集扩张
        option = option_loss(g)                          # 承诺期权损失
        score  = info + EXP_W*expand - OPT_W*option - cost(g)
        if best is None or score > best.score:
            best = (g, score, choose_role(lat, g, trust))
    return best if best and best.score > 0 else None     # 无利可图 → R69

# IP-270/272 PRC + TCG：渐进承诺与双向信任
def commit(g, depth, trust):
    if depth > trust.max_depth: return 'DECOUPLE'
    gamma = (g.role, g.deadline, g.fulfill_pred, g.revoke_cond)
    propose(gamma)                                       # 口头接受只是假设
    if not wait_evidence(gamma.fulfill_pred, g.deadline): return 'REVOKE'
    if not trust.display_is_honest() or trust.overreliance_detected():
        return 'SLOW_AND_EXPLAIN'                        # 保留人在环
    return 'DISCHARGE' if depth_ok(depth) else commit(g, depth+1, trust)

# IP-273 JSC：联合安全证书
def joint_safety(xi_J, o_t):
    sep     = min_distance(xi_J.robot, human_pred(o_t))
    auth    = authority_unique(xi_J.ownership) or certified_shared_law(xi_J)
    rendez  = exists_reachable_handover(xi_J, o_t)
    abort   = exists_decoupling_in_safe_set(xi_J)
    return (sep >= d_min + KAPPA*pred_std and auth and rendez and abort
            and min_cbf(xi_J) >= 0)

# IP-276 主闭环（继承 R69，只在「空间行」处插入 DUET 层）
def DUET_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, _ = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4        # R69 模态层原样
    U_MA, U_ME, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    lat = M.cua.lattice(M.jas.sample_contracts(o, K), M.ham, o)   # R70 空间层
    g = None
    if lat['U_SE'] > TAU_COORD and not M.tcg.untrusted():
        g = M.co_voi.choose(lat, o, M.budget, M.tcg)
    if g is not None:                                    # 承诺 + 联合认证
        status = M.prc.commit(g, M.tcg.depth(lat, o), M.tcg)
        if (status not in ('DISCHARGE', 'SLOW_AND_EXPLAIN')
                or not M.jsc(joint_of(modes, g))):
            M.dec.decouple(); g = None                   # 退回 R69 单边策略
    U_floor = lat['U_MA'] + (lat['U_SA'] if g else 0.0) \
              + (0.0 if g else lat['U_SE'])              # 失败把 U_SE 视同 epistemic
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    A = M.ach.propose(x_prime, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    if g is not None: k = min(k, M.jsc.authority_prefix(g))   # 不改安全包络
    M.tcg.display(residual_risk=lat['U_SE'], interval=True)   # 防过度依赖
    M.vqa_coop.submit_async(g, lat, status if g else None)
    return k, lam, modes, lat, g

## 4. 推导

**引理 19（联合不确定性格的分解完备性）** A99（联合损失对模态/空间两轴可加可分）下，任意联合决策期望遗憾分解为四角贡献之和。R69 的标量不确定性是模态行两角；空间行 U_SE 由角色熵与可行集直径共同下界，且不能由模态行统计量一致估计。系：**只做模态消歧的策略在协调歧义大时存在不可消除的遗憾下界**。

**引理 20（Co-VoI 包含 VoI 并多出扩张/期权项）** Ω 固定且 OptionLoss=0 时 Co-VoI=VoI，R69 MINT 为精确特例。一般 `Co-VoI−VoI=λ_exp E[Δ|Ω|]−λ_opt OptionLoss`。故能扩张可行集、低不可逆性的协调动作（offer/yield/stabilize）价值高于纯询问；高不可逆承诺仅在信息增益足够大且期权损失有界时才值得——**给出「先小步、后承诺」的定量理由**。

**引理 21（承诺健全性与无死锁）** 每个承诺若带 (a) 有界期限、(b) 可核验履约谓词、(c) 安全中止动作、(d) 撤销成本上界，且耦合依赖图无环或存在固定优先级，则双边协议在有限时间内或完成、或安全中止，不会死锁。系：**渐进承诺每级都必须自带出口**；对称等待（「你先动」）正是 R69 无法表达、HRC 最常见的失败。

**引理 22（冗余侵蚀 / 信任吸收上界）** 人类独立安全贡献 R_H、监控投入 e_h、显示-真实置信差 δ_c；行为模型 ∂e_h/∂δ_c<0。有效冗余 `R_eff=R_R+e_h(δ_c)R_H(1−overlap)`，δ_c>τ_trust 时尾部风险增量 `Δ_tail≥κ(R_H−R_eff)`。故**诚实显示残余不确定性是安全动作，不是礼仪**；TCG 给出冗余侵蚀上界。

**定理 18（DUET 严格包含 R69/R68）** A99–A101 下，人类为外生神谕、𝒞=∅、角色平凡、Ω 固定 ⇒ U_SE=0、Co-VoI≤0、协调层不激活，逐指令等于 FLUID；TCG/JSC/承诺任一失败或 U_SE 未消解 ⇒ DEC 退回 FLUID/R68。故期望风险 ≤ R69，安全侧不让步，协调成功仅在已认证联合可行集上获 expansion bonus。

**定理 19（联合安全与无突变）** 协调动作过 JSC + C-RAS-WM 后联合物理风险 ≤ ε_joint；协调只改角色/权属/共享律、不改机器人安全包络；权属唯一 + 中止可达保证解耦有界时间回到已认证单边安全集；R68 换装不变式与 R69 定理 17 保持 ⇒ 控制连续、无突变。JSC 失败时 λ 单调不降退回 R69，不得以「人类会配合」放宽包络。

## 7. 本轮最大风险

**一句话**：DUET-RAS 的全部收益押在「伙伴动作空间模型可信、且协作不会让信任单向迁移」这一前提上——**若角色/能力信念未标定，或被装弱、承诺诱饵、社交工程策略性利用，系统会自信地把人委派到他没有能力承担的角色，或让人因为机器人「看起来很确定」而不再监控；协作于是把人类从独立安全备份变成被拖入危险的角色——最危险的不是机器人算错，而是它让人相信它算对了。**

**次级风险与缓解**：权属歧义/共享自由度冲突（权属唯一 + A_conf + JSC + 定理 19）；承诺违约/诱饵（渐进承诺 + 履约证据 + 安全中止 + 引理 21）；过度依赖/信任吸收（诚实残余风险显示 + 监控代理 + 深度门 + 引理 22）；协调动作不安全/不可逆（JSC + C-RAS-WM + DEC + 定理 19）；人类模型 OOD/装弱（conformal 能力集 + OOD 检测 + 小步演示取证）；预算被多轮承诺击穿（默认 d=0 + 自适应深度 + 硬预算）。
