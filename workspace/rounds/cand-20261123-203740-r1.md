# 灵感驱动研究循环 · 本轮：「示教学习」×「ROS2」

> **基线**：v22 = MetricVoiceGauge-NCD-HUTDH-v22 + IP-431–435（HDL / ACSC / DCSC / HPC-E / CFC++），其上承 v21 语义-规范层（SDC / CAC / DCL / GIC）与 v17/v19/v20 全部模块。
> **本轮纪律**：**示教给的是偏好与"存在性见证"，不是授权；ROS2 给的是传输与调度，不是信任；证书仍是唯一准入货币。** 不推倒 v22，只加两翼：**示教先验（LfD）**与**证书传输活性（ROS2）**，并把两翼都钉死在 `Exec_v23 ⊆ Exec_v22` 上。

## 0. 直觉与动机

### 灵感 1（示教学习 → 偏好先验 + 存在性见证，而不是"学会就执行"）

直觉：v22 的证书体系极擅长说"哪里不能去"，却不擅长说"通常怎么去"。结果是两个活性病灶：（a）同样安全的多条轨迹里没有偏好，规划退化成随机并列或最保守并列；（b）O 规则（"≤τ 内进入让位状态"）一旦在计划集上找不到满足者，就直接升级 SafeStop——但人类示范其实反复证明过"这种局面是能解开的"。

示教能补的恰是这两点，但要分成三类严格区分：

1. **偏好**：从示范学成本 `J_θ`，只在**已经通过 v22 证书**的动作集内排序，绝不扩大可行集；
2. **技能先验**：DMP/BC 给出高先验可行候选，作为规划热启动，仍须过证书；
3. **存在性见证（本轮最关键的重新定位）**：每一条**经回放+证书复核**的示范，都是"存在一条满足 F/O/P 的轨迹"的构造性证明。于是 O 规则不可满足时，系统不必立刻 SafeStop，而是可去**见证库**里找同适用域的已认证见证。示范不是"允许这么做的授权"，而是"这条路曾经可走"的候选证据；能否复用，由当前上下文的证书重新裁决。

反直觉点：**示教的价值不在"让机器人更像人"，而在"把义务求解从空集判定变成见证检索"**。因此 LfD 的正确接法是"候选生成 + 排序"，而不是"策略直连执行"。盾（SSC）保证：无论 `J_θ` 学得多错、BC 多自信，只要它只能在 `A_cert` 里挑，安全性与 `J_θ` 的正确性**解耦**。

风险直觉：示范者会违规、会偷懒、会把个人习惯当规范；BC 在分布漂移下会"自信地错"。所以：未复核示范只进偏好训练，不进见证库；从示范反推的规范只能作为**候选规则**，必须人签+版本化后才能生效（P44）。

### 灵感 2（ROS2 → 证书是一种会丢、会老、会假装送到的证据）

直觉：前几轮把证书当成本地同步对象，默认"算出来就等于被执行看到"。真实 ROS2 系统里，证书由感知节点签发，经 DDS 异步送到规划/控制节点，中间至少有六类背叛：丢包、超 deadline、重排/重复、`transient_local` 把陈旧证书发给晚加入者、QoS 不兼容导致双方**静默不连**、executor 饥饿/时钟偏斜让"新鲜"判定失真。

核心创新：把证书从"一个对象"升级为**证书信封（Certificate Envelope, CE）**：`(claim, issuer, hw_root, merkle_root, t_issue, ttl, deadline, seq, signature)`，经 ROS2 QoS 契约传输；接收端**不信总线**，重新验签、验 Merkle、按本地单调时钟硬过期；任何"缺证/过期/不可信时钟/QoS 契约破裂"都按**负证据**处理，向保守方向降级。

反直觉点一：**最危险的不是"收到坏证书"，而是"以为收到了好证书"**——`TRANSIENT_LOCAL` 给晚加入节点的历史证书、QoS 不匹配时的零连接、以及跨时钟域的"看起来还新"，都会让裁决基于陈旧证据。

反直觉点二：CFC++ 的"模态数 ≥2"在分布式下会被**同一物理源的多节点重复签发**骗过。必须用 `hw_root + 签名密钥 + 传感器谱系` 定义**证据等价类**，等价类内多票只算一票（P46）；跨机构拜占庭场景下 `N-F` 的崩溃容错阈值不够，需显式换成带签名的 `2F+1/3F+1` 阈值（详见产物区引理 929 的风险注记）。

### 三者如何统一

v23 = **v22 安全核 + 示教先验翼 + 证书传输翼**：

- **DPC（示教先验编译器）**：示范 → conformal 成本区间 + 技能先验 + OOD 检测；只排序、不增域；
- **WLD（示范见证库）**：经回放+证书复核的示范 → 带适用域的存在性见证，用于缩短 O 规则求解；
- **SSC（技能盾证书）**：`π_safe = argmin_{a ∈ A_cert(x)} J_θ(a)`，`A_cert` 只来自**活证书快照**；空集则 SafeStop；
- **RCTL（ROS2 证书传输与活性）**：信封化 + QoS 契约 + TTL/活性 + 接收端复验；
- **PRL（来源与批准账本）**：示范同意/来源、规则候选、人签、Merkle 版本审计。

统一准入：`HPC-L = (HPC-E 在活快照上成立) ∧ (SSC 选择在 A_cert 内) ∧ (所有被引用证书 Live)`；任一不成立退回 v22 保守收缩，再退 v21/v19。

## 1. 研究问题（在 Q1–Q11 基础上升级）

- **Q12（示教先验的受限影响）**：如何从示范 `D` 学到 `J_θ` 与技能库，使"移除示教只改变排序、不改变可行集"？如何用 conformal 只给成本区间 `P(J_true ∈ [Ĵ−ε, Ĵ+ε]) ≥ 1−α`，而**不给安全背书**？示范分布漂移（新操作员/新布局/新负载）如何用 OOD 分数在 O(1) 内检测并回退到无先验？

- **Q13（示范→义务见证的适用域）**：一条示范要成为可复用的 O 规则存在性见证，需要哪些上下文等价条件（初态邻域、目标、动态参数、参与者/障碍身份、时间预算）？如何用"回放 + HPC-E 复核"把见证适用域**严格化**，避免把 A 场景的让位轨迹搬到 B 场景？见证失配或复核失败如何 fail-safe 而不误触发大面积 SafeStop？

- **Q14（学得规范的治理）**：能否从示范 + 操作员标注中反推 F/O/P 规则候选？如何保证"学到的规则永不自我批准"——必须人签 + Merkle 版本 + 灰度/shadow 评估？示范中的违规如何用 v22 活证书检测并隔离，使其永不能成为授权或见证？

- **Q15（ROS2 证书活性）**：如何为安全关键证书定义 QoS 契约（RELIABLE / VOLATILE 或带 TTL 复核的 TRANSIENT_LOCAL / DEADLINE / LIVELINESS / ownership / depth）？QoS 不兼容、发现延迟、executor 饥饿、时钟偏斜、历史缓存如何在 O(1) 内被检测并映射为"证据缺失"？端到端新鲜度如何在 composition、多 executor、跨时钟域下严格界定？

- **Q16（跨节点去重与拜占庭阈值）**：CFC++ 的"模态数 ≥2"如何防同一物理传感器经多个 ROS2 节点重复投票？如何在部分节点被攻陷时仍保持共识可信——`N−F` 崩溃阈值何时必须升级为带签名的 `2F+1/3F+1`？

## 2. 设计原则（在 P34–P42 基础上新增 P43–P46）

**P43 示教先验受限释放律（Demonstration Prior Bounded Release）**
`J_θ` 与技能库只在**已认证动作集**内起作用：`Exec_v23 = {π ∈ Exec_v22 : π = argmin_{a∈A_cert(x)} J_θ(a)} ⊆ Exec_v22`。移除 `J_θ` 或将其替换为任意恶意函数，只改变并列中的选择与次优性，不改变可行性集合。示范晋升为存在性见证的唯一路径是"回放 + 当前上下文 HPC-E 复核通过"；未复核示范仅进偏好训练，永不影响约束。

**P44 习得规范须批准律（Learned Norms Need Ratification）**
从示范反推的 F/O/P 仅作为**规则候选**进入 PRL，必须经操作员签名、Merkle 版本化、shadow 评估后才能进入 DCL 规则库；运行时**绝不**自修改规则库。候选规则在批准前一律按更严方向解释。任何与活证书冲突的示范被隔离，永久不得授权或作为见证。

**P45 中间件证据活性律（Middleware Evidence Liveness）**
每张证书必须信封化并通过 QoS 契约传输；`Live(CE,t) = 验签 ∧ Merkle ∧ (0 ≤ t−t_issue ≤ min(ttl, max_age)) ∧ 本地时钟可信 ∧ QoS 契约成立`。准入只基于活快照；缺证/过期/时钟不可信/QoS 破裂一律视为负证据并保守降级。接收端在每个谓词上**重新验证**，信任边界不在总线。

**P46 证据等价类去重律（Evidence Equivalence Dedup）**
证据等价类由 `(hw_root, signing_key, sensor_lineage)` 定义；同一等价类对同一 claim 的重复签发只计一票，绝不因"多节点一致"而升级为多模态。跨组织/存在拜占庭风险时，CFC++ 的崩溃阈值 `N−F` 必须显式升级为带签名的 BFT 阈值。

## 3. 与基线接口（如何退化）

- DPC 失效（无示范/成本模型崩）⇒ 无偏好先验，规划在 `A_cert` 内按 v22 默认目标排序 ⇒ 等价 v22（安全不变，仅可能次优）；
- WLD 失效 / 见证复核失败 ⇒ O 规则不可满足时直接 SafeStop ⇒ 比 v23 更保守，退化为 v22 DCL 行为；
- SSC 失效（盾崩溃）⇒ 控制退回 v22 的 HPC-E 准入，不再接受学习策略提议 ⇒ 等价 v22；
- RCTL 失效（证书总线不可信/时钟不可信）⇒ 全部远程证书按过期处理，只在本地已认证快照上运行；无本地快照则进入最大限制模式 ⇒ 比 v22 更保守；
- IDL/PRL 失效 ⇒ 不引入任何学得规则，F/O/P 仅用人工规则库 ⇒ 子集；
- CFC++ 去重与 BFT 阈值无法满足 ⇒ 仲裁退回 v22 CFC（并把跨节点一致票降级为单票）⇒ 等价或更保守；
- 全失效 ⇒ 完全回退 v22 ⇒ `Exec_v23 ⊆ Exec_v22 ⊆ Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19`。
- **安全继承**：示教只排序/只补见证、盾只掩码、信封只做证据活性、去重只减少票数；任意失效都向更保守或"原样"退化，不产生新的自由空间。

## 4. 预期贡献

1. **示教的安全接法**：首次把 LfD 明确拆成"偏好先验 / 技能热启动 / 存在性见证"三类，并证明只有第三类能改善 O 规则活性，且必须经当前上下文复核；
2. **安全-学习解耦定理**：给出 `Exec_v23 ⊆ Exec_v22` 与"`J_θ` 正确性不影响安全性、只影响次优性"的分离结论，使学习模块可以自由迭代而无需重证安全核；
3. **示范见证库**：把"人类曾经解开过这个局面"变成可审计、带适用域、可失效的存在性证据，缓解 v22 的 SafeStop/活性坍缩；
4. **证书信封与 QoS 契约**：把 ROS2 的异步/丢包/QoS 不匹配/时钟偏斜显式纳入证据语义，给出"证据缺失=保守"的故障映射与端到端新鲜度定义；
5. **分布式证据等价类**：用物理源身份去重，封堵"同一传感器多节点伪装多模态共识"，并给出崩溃容错到拜占庭容错的阈值切换条件；
6. **治理闭环**：示范同意/来源、规则候选、人签、Merkle 版本审计打通，使 v23 的安全故事从"算法正确"上升到"证据可追溯、规范须批准"。

## 5. 本轮最大风险

**一句话**：示教先验把"人类常这么做"误当成"此刻允许这么做"，而 ROS2 的异步缓存与时钟偏斜让"曾经安全"冒充"现在安全"——一旦见证适用域判定过宽或 TTL/时钟被宽松处理，v23 会以**可审计、可回放、形式合规**的方式，执行一个只在他时他地成立的示范动作。

## 1. 形式化核心

### 1.1 示教先验：只覆盖成本，不覆盖安全

对示范的非一致性分数取 conformal 分位：

```
q_{1−α} = Quantile_{1−α}({r_i})
```

在可交换性假设下：

```
P( J(ξ_new) ∈ [Ĵ_θ(c_new) − q_{1−α}, Ĵ_θ(c_new) + q_{1−α}] ) ≥ 1 − α_cost
```

**关键限定**：该区间只对"偏好排序"负责。安全由 `A_cert` 与 HPC-E 决定，与 `Ĵ_θ` 是否正确无关（引理 927）。当 `d_OOD(c) > q_ood` 时置 `Ĵ_θ(c) = None`，规划回退到 v22 默认目标。

### 1.2 存在性见证：把"人曾解开"变成候选证据

```
w 可用于上下文 c′  ⇔  c′ ∈ Ω_w
                      ∧ ReplayOK(w, c′)
                      ∧ HPC-E_live(π_w, c′) = true
```

三条同时成立时，`w` 只产出**候选计划** `π_w`；它仍要过 SSC 与 DCL 的 O/F/P 过滤。任何一条不成立，`w` 不得被引用，且不改变 `A_cert`。因此见证提升的是 O 规则的可满足性（活性），不是可达域。

### 1.3 盾：学习与安全的结构性解耦

```
A_cert(x) = { a : plan(a) ∈ Exec_v22 ∧ HPC-E(plan(a), Σ_t) admits }
π_safe    = SafeStop            if A_cert(x) = ∅
          = argmin_{a∈A_cert} J_θ(a)   otherwise
Exec_v23  = { π_safe(x) : x ∈ 认证状态空间 }
```

### 1.4 证书信封与活性

```
Live(CE, t) = VerifySig(CE.σ, CE.issuer)
            ∧ MerkleOK(CE.merkle_root, CE.claim)
            ∧ 0 ≤ (t − CE.t_issue) ≤ min(CE.ttl, TTL_cert(domain))
            ∧ ClockTrusted
            ∧ QoSContract(CE, node_state)
```

`Σ_t = { CE : Live(CE, t) }`。准入只读 `Σ_t`；任何被引用证书不在 `Σ_t`，该计划视为"证据缺失"，退回保守动作集。

### 1.5 引理与证明骨架

**引理 926（安全继承）** `Exec_v23 ⊆ Exec_v22`。
证明：`A_cert(x) ⊆ Exec_v22`；盾若选动作则选 `A_cert` 中元素，否则输出 SafeStop（SafeStop 属于所有层级的公共安全子集）；故 `π_safe ∈ Exec_v22`。∎

**引理 927（成本模型无安全影响）** 固定 `A_cert` 与活快照，将 `J_θ` 替换为任意函数 `J′`，`Exec_v23` 的可行性集合不变，仅所选元素可能改变。
证明：`J_θ` 只出现在 `argmin` 中，不参与 `A_cert` 的构造；`A_cert` 仅由 HPC-E、`Σ_t`、`Exec_v22` 决定。∎

**引理 928（证据丢失单调性）** 若总线只丢失/过期证据而不伪造（`Σ′_t ⊆ Σ_t`），则 `Exec_v23(Σ′_t) ⊆ Exec_v23(Σ_t)`。
证明：HPC-E 对活证据的合取随证据减少而更难满足，`A_cert` 单调收缩；`argmin` 在收缩集上取值，故计划集收缩。∎

**引理 929（共识阈值的故障模型依赖）** CFC++ 的 `N−F` 只对**崩溃停止**故障成立；若节点可拜占庭（伪造/隐瞒/重放），`N−F` 不再提供安全性，必须显式采用经证明的 BFT 阈值（部分同步下如 `3F+1` 类 PBFT），或明确依赖 PKI 与同步假设的签名广播协议。
证明骨架：崩溃故障下"未投票"可安全忽略；拜占庭节点可对同一 claim 向不同接收者发送冲突票，`N−F` 可能被 F 个恶意节点 + 相关故障共同凑出"多数"。∎
**注记**：v23 的默认部署仍是崩溃容错；跨组织/高对抗场景必须把 `BFT_threshold` 写入 `Γ_rules` 并由 PRL 审计。

**引理 930（见证不扩域）** 见证 `w` 的复用不改变 `A_cert` 的定义域；其唯一效果是向计划器提供一个已在当前上下文通过 HPC-E 的候选 `π_w`，因此不产生新的自由空间。
证明：由 1.2 的三条件，`π_w` 必须 `HPC-E_live` 通过，即 `π_w ∈ Exec_v22`；引用见证不修改 `Exec_v22` 与 `Σ_t`。∎

## 2. 关键算法骨架

### 2.1 IP-436 Demonstration Prior Compiler (DPC)

```python
class DemonstrationPriorCompiler:
    """把示教编译成成本区间 + 技能先验 + OOD；绝不产出安全许可。"""

    def __init__(self, alpha_cost=0.05, delta_ood=0.01):
        self.alpha_cost = alpha_cost
        self.delta_ood = delta_ood
        self._calib_scores = []
        self._ctx_bank = []

    def fit(self, demos):
        # demos: [(xi, c, meta)]；meta 含 operator_consent/provenance，进入 PRL
        for xi, c, meta in demos:
            j_hat = self.cost_model.predict(c)          # IRL / BC / 物理先验
            r = abs(self.observed_cost(xi) - j_hat)     # 非一致性分数
            self._calib_scores.append(r)
            self._ctx_bank.append(self.embed(c))
        self.q_cost = conformal_quantile(self._calib_scores, 1 - self.alpha_cost)
        self.q_ood = self._fit_ood_threshold(self._ctx_bank, self.delta_ood)
        self.skill_lib = fit_skill_library(demos)       # DMP / 轨迹聚类

    def prior(self, c):
        if self.ood_score(c) > self.q_ood:
            return None                                  # P43：无先验，回退 v22
        j_hat = self.cost_model.predict(c)
        return Prior(j_hat,
                     lo=j_hat - self.q_cost,
                     hi=j_hat + self.q_cost,
                     skills=self.skill_lib.query(c))

    def ood_score(self, c):
        return knn_distance(self.embed(c), self._ctx_bank, k=5)
```

### 2.2 IP-437 Witness Library from Demonstrations (WLD)

```python
class WitnessLibrary:
    """只有经回放 + HPC-E 复核的示范才可成为见证。"""

    def add(self, demo, hpce, rgc):
        if not demo.meta.consent or not demo.meta.provenance_ok:
            return self.quarantine(demo, "PROVENANCE")
        if not hpce.admits(demo.plan):                    # v22 活证书复核
            return self.quarantine(demo, "CERT_VIOLATION")
        if not rgc.covers(demo.context):                  # 现实差距证书覆盖
            return self.quarantine(demo, "RGC_UNCOVERED")
        w = Witness(
            xi=demo.xi,
            c=demo.c,
            domain=self._infer_domain(demo),              # Ω_w：初态/目标/参数邻域
            root=hpce.merkle_root(demo.plan),
            expiry=demo.t_issue + TTL_WITNESS,
        )
        self._store(w)
        return w

    def lookup(self, c, obligation, hpce, rgc):
        for w in self._candidates(c, obligation):
            if c not in w.domain:                         # 适用域必须严格包含
                continue
            if not rgc.covers(c) or not replay_ok(w.xi, c):
                continue
            if hpce.admits(self._lift(w, c)):             # 当前上下文重新裁决
                return self._lift(w, c)                   # 只是候选
        return None                                       # 不满足 → v22 SafeStop
```

### 2.3 IP-438 Skill Shielding Certificate (SSC)

```python
class SkillShield:
    """安全-学习解耦：J_θ 只在 A_cert 内挑。"""

    def __init__(self, hpce, bus, fallback):
        self.hpce = hpce
        self.bus = bus
        self.fallback = fallback                          # v22 保守动作集

    def act(self, x, prior):
        snap = self.bus.live_snapshot(required=self.required_claims(x))
        if snap is None:                                  # 证据缺失/时钟不可信
            return self.fallback.select(x)                # 向保守退化
        A = self.certified_actions(x, snap)
        if not A:
            return SafeStop(reason="NO_CERTIFIED_ACTION",
                            audit=self.bus.audit_ref())
        if prior is None:                                  # 无示教先验
            return v22_objective.argmin(A)
        return min(A, key=lambda a: prior.rank(a))         # 只排序

    def certified_actions(self, x, snap):
        cands = self.planner.candidates(x, snap)
        return [a for a in cands if self.hpce.admits(plan(a), snap)]
```

### 2.4 IP-439 ROS2 Certificate Transport & Liveness (RCTL)

```python
@dataclass(frozen=True)
class CertificateEnvelope:
    claim: dict
    issuer: str
    hw_root: str
    merkle_root: str
    t_issue_ns: int
    ttl_ns: int
    deadline_ns: int
    seq: int
    signature: bytes

class CertificateBus:
    def live(self, ce, now_ns):
        if not verify_sig(ce):            return False
        if not merkle_ok(ce):            return False
        if not self.clock.trusted:       return False
        age = now_ns - ce.t_issue_ns
        if age < 0 or age > min(ce.ttl_ns, self.max_age_ns): return False
        if not self.qos_contract_ok(ce): return False
        if ce.seq <= self.last_seq.get(ce.issuer, -1):        return False  # 重排/重放
        return True

    def live_snapshot(self, required):
        self.clock.tick()
        if not self.clock.trusted:
            self.enter_safe_state("CLOCK_UNTRUSTED")
            return None
        if not self.discovery.complete(required):
            self.enter_safe_state("DISCOVERY_INCOMPLETE")
            return None
        snap = {k: ce for k, ce in self._cache.items()
                if k in required and self.live(ce, self.clock.now_ns)}
        if set(snap) != set(required):
            return None                                       # 缺证 = 负证据
        return Snapshot(snap)
```

### 2.5 IP-440 Provenance & Ratification Ledger (PRL)

```python
class RatificationLedger:
    def propose_rule(self, cand, shadow_metrics):
        # IDL 只能提案；批准前按最严方向解释
        return self._append(kind="RULE_CANDIDATE", payload=cand,
                            parent=self.head,
                            meta={"shadow": shadow_metrics})

    def ratify(self, cand_id, human_sig):
        cand = self._get(cand_id)
        if not cand.meta["shadow"].ok:
            raise ValueError("SHADOW_NOT_PASSED")
        if not verify_human(human_sig, cand.payload):
            raise ValueError("HUMAN_SIG_INVALID")
        node = self._append(kind="RULE_RATIFIED",
                            payload=cand.payload, parent=self.head,
                            meta={"human_sig": human_sig})
        dcl.load_rules_atomic(node)          # 原子切换，运行时不改规则库
        return node
```

### 3.3 实时与生命周期

- `/shield` 使用独立的 `MutuallyExclusiveCallbackGroup` + 高优先级实时线程，保证每 20 ms（50 Hz）控制周期内完成 O(1) 快照查询；
- 节点采用 lifecycle：`deactivate` 即撤销本地证书，`error` 进入 SafeStop；重新激活须重新发现 + 首帧活证书；
- 启动门：所有 `required` 主题的 publisher 匹配数达标且收到第一帧活证书前，`/shield` 输出保守动作；
- SROS2：每节点独立密钥 + 访问控制；`hw_root` 经 TPM/安全元件绑定；签名在应用层再做一次，不依赖 DDS Security 单独兜底；
- 时钟：年龄计算用本地单调钟（`steady_clock`），ROS 时间仅用于日志；检测到时钟跳变或跨节点偏斜超界 → `ClockTrusted=false` → 全部远程证书按过期处理。

### 3.4 证据等价类去重（IP-435 → v23 接线）

```python
def evidence_key(vote):
    return (vote.claim_hash, vote.hw_root, vote.signing_key, vote.sensor_lineage)

def count_distinct(votes):
    return len({evidence_key(v) for v in votes})   # 同源多节点只算一票
```

`CFC++` 的模态数改为 `len({v.modality for v in distinct(votes)})`；同一相机经三个 ROS2 转发节点仍只贡献一个模态、一票。

## 4. 故障模型 → 保守映射

| 故障 | 检测 | 语义 | 动作 |
|---|---|---|---|
| 丢包 | 序列号缺口 / deadline miss | 证据缺失 | `A_cert` 收缩，必要时 fallback |
| 超 deadline | deadline event / 年龄超 TTL | 证据过期 | 视为未收到 |
| 重排 / 重复 / 重放 | `seq` 单调检查 | 旧证据 | 丢弃 |
| `TRANSIENT_LOCAL` 晚加入 | 历史缓存 + 年龄 | 陈旧证据 | TTL 复核失败即丢弃 |
| QoS 不兼容 | publisher/subscription 匹配数 | 静默不连 | 启动门/运行时门 → 安全态 |
| executor 饥饿 | 周期 watchdog / p99 延迟 | 裁决迟到 | 直接 SafeStop（不得用旧快照续命） |
| 时钟偏斜/跳变 | 双钟对比 / 跳变检测 | 年龄不可信 | `ClockTrusted=false` → 全部过期 |
| 节点崩溃 | liveliness lease 过期 | 证据源消失 | 撤销其证书，重新准入 |
| 节点被攻陷 | 验签失败 / 等价类异常 | 伪造证据 | 丢弃 + PRL 告警；BFT 阈值重配置 |

**单调性**：上表所有行都只减少 `Σ_t` 或降低 `ClockTrusted`，不增加证据，故由引理 928，`Exec_v23` 只收缩。

## 5. 实验设计

### 5.1 平台与数据

- ROS2 Humble；Nav2 + 6-DOF 机械臂；Gazebo/Ignition；3 台移动机器人共享工作面；控制 50 Hz，证书总线 10 Hz，盾 50 Hz。
- 示教：60 条遥操作/动觉示教，10 名操作员 × 3 种布局 × 4 类任务（让位、交接、绕行、协同搬运）；每条含同意与来源元数据。
- 规则：人工编写 F/O/P 共 14 条；IDL 从示范挖掘候选规则，全部经 PRL shadow + 人签。

### 5.2 对比基线

1. **v22**：无示教、无信封（本地同步证书）；
2. **v22+BC**：BC 策略直连规划，无盾（消融"学习必须被盾包住"）；
3. **v23-noWLD**：有 DPC + SSC + RCTL，但无见证库；
4. **v23**：完整方案；
5. **v23-noDedup**：关掉证据等价类去重（暴露同源多节点伪共识）。

### 5.3 故障注入矩阵

丢包 {0, 5, 15, 30}% × 时延 {0, 50, 200, 500} ms × QoS {匹配, 不匹配} × 时钟偏斜 {0, ±50, ±500} ms × 节点崩溃 {0, 1} × `TRANSIENT_LOCAL` {VOLATILE, 历史缓存}；每格 ≥ 30 次随机种子。

### 5.4 指标

- **安全**：碰撞/越界次数（应为 0）、违规进入禁区的次数；
- **活性**：任务成功率、SafeStop 率、平均完成时间、共享区停机时长；
- **学习**：O 规则 ≤τ 满足率、见证复用率、OOD 检出率、成本区间经验覆盖率；
- **实时**：盾 p50/p99 延迟、deadline miss 率、证书端到端年龄 p99；
- **传输**：静默不连检测率、陈旧证书拒收率、重复票去重率；
- **治理**：未经批准规则生效次数（应为 0）、审计链可回放率。

### 5.5 消融与证伪标准

- 若 `v22+BC` 在分布漂移场景下出现 ≥1 次安全违规，而 `v23` 为 0，则支持"盾的必要性"；若 `v23` 也违规，则 `A_cert` 或 HPC-E 有洞，需回查而非调参。
- 若关掉去重后 CFC++ 在"同一相机三节点转发"场景仍判为多模态共识，则 P46 未落地。
- 若 `v23` 的 O 规则满足率不高于 `v22`，则 WLD 的见证复用无价值，应删掉以免增加攻击面。
- 若证书年龄 p99 超过 `TTL_cert`，则端到端新鲜度定义不成立，必须降级实时预算。

## 7. 本轮最大风险

**一句话**：示教先验把"人类常这么做"误当成"此刻允许这么做"，而 ROS2 的异步缓存与时钟偏斜让"曾经安全"冒充"现在安全"——一旦见证适用域判定过宽或 TTL/时钟被宽松处理，v23 会以可审计、可回放、形式合规的方式，执行一个只在他时他地成立的示范动作。
