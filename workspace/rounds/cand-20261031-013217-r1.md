# 第 1 轮 · TRI-SHIELD：给 CHUNK-SERVO 的 5 步执行块加一层「常识时序逻辑 + 扫掠碰撞 CBF + 约束离线 RL」的安全包络

> 检索/复核日期：**2026-10-31（UTC）**。本轮是新一轮灵感循环的第 1 轮，承接第 12 轮 CHUNK-SERVO。赛事身份不变：宇树 **UniBot 世界挑战赛**（G1 + Dex1，32 项桌面任务，通才单模型赛道，选手自部署 + 官方远程真机 API）。三个灵感词是「常识推理」「碰撞检测」「强化学习」。本轮不推倒 CHUNK-SERVO，而是在它的 30→5 双频执行外面加一层可验证的安全包络：**VLA 提议、伺服修正、shield 裁决、RL 学会不触发 shield**。

## 0. 先给结论：CHUNK-SERVO 解决了「反应慢」，还没解决「反应错」

第 12 轮的判断是对的：30 步 action chunk 是吞吐优势，也是接触精度的结构性弱点；把执行块压到 5 步、每块用演示检索的相对目标做视觉伺服，能把反馈周期从约 1 s 降到约 200 ms。但它默认了三件事：

1. **几何上不会撞。** 伺服修正来自图像误差，不是来自安全约束。夹爪在最后 3 厘米可能被修正指令推入桌面、杯壁、网口边缘或另一只手臂；API 没有力/触觉，撞了也未必知道。
2. **语义上不会错。** 动作可以非常平滑、非常对准，却在常识上是错的：杯子还没到杯架就松手、杯子倒着挂、插头反着插、钥匙没对准锁芯就拧、针管倾斜导致液体洒出、叠碗时把碗压进下层。
3. **仲裁是手调的。** 什么时候信 VLA、什么时候信伺服、什么时候停、什么时候重规划，上一轮靠阈值和状态机；阈值对任务、RTT、物体刚性都敏感，手工网格搜索代价高，而且容易过拟合单任务通道。

所以本轮的押注是 **TRI-SHIELD**：

> **在 CHUNK-SERVO 的「30 步规划 + 5 步伺服」之间插入一个确定性安全包络：常识自动机决定「该不该做」，双目 + URDF 的扫掠碰撞 CBF 决定「能不能做」，约束离线 RL 让同一个 VLA 学会「少提出会被拦截的动作」。部署时仍然只有一个学习模型。**

三个灵感词怎么落到方案里：

| 灵感词 | 最诱人的做法 | 在 UniBot 里的陷阱 | 本轮采用的合规版本 |
|---|---|---|---|
| **常识推理** | 再接一个 VLM/LLM 做在线常识判断 | 第二个模型；远程延迟；单模型规则 | **S-SHIELD**：从 33k 成功演示抽取「谓词自动机 + 转移先验」；在线用同一 WLA checkpoint 的 VLM 做低频 yes/no 查询；输出硬/软时序约束 |
| **碰撞检测** | 训一个 6D 物体位姿/占用网络 | 第二个模型；透明/反光不可靠；实时性 | **G-SHIELD**：头双目点云 + 已知物体基元 + G1 URDF 胶囊；5 步扫掠碰撞检查 + CBF-QP 最小修正；无学习权重 |
| **强化学习** | 在线 RL 微调一个大策略 | 真机 180 s/次；单模型规则；样本效率 | **R-SHIELD**：离线 RL 微调**同一个** action head（Q 函数只在训练时存在）；仿真里用约束 PPO/CEM 标定 shield 常数；部署只留一个 checkpoint + 确定性公式 |

一句话：**先把「不撞、不违反常识」变成可验证的硬约束，再让 RL 在安全集内提高成功率；shield 是运行时过滤器，也是训练时的负样本来源。**

## 1. 直觉与动机：三个「最后 3 厘米」的失败

把一次接触失败拆开看，CHUNK-SERVO 只修了中间一段：

```text
t0: 观测 → VLA 30 步 plan → 检索相对目标 → 伺服修正 → 返回 5 步 chunk
t0+0.17s: evaluator 执行完 5 步
        ↑ 夹爪可能已经撞到桌沿/杯壁/网口；或者目标已经被人类挪走
t0+0.20s: 才看到下一帧
```

### 1.1 几何缺口：伺服只对图像负责，不对碰撞负责

IBVS/PBVS 的误差是像素/位姿误差，不是安全距离。一个 5 mm 的横向修正，在插入任务里可能正是「对准」，在叠碗任务里可能正是「压碎」。上一轮的对策是「接触段法向缩幅/低通」，但那是启发式；没有几何上的非穿透保证。

### 1.2 语义缺口：动作对，事情错

32 个任务里至少 19 个是接触密集的 A 档任务。它们的关键失败不是「够不到」，而是「够到了但做错」：

- **HangCup**：夹爪对准了杯沿而不是杯柄；杯子挂上去 0.5 s 后掉落。
- **PlugInEthernet**：插头对准了旁边的口，或者插入了 2 mm 就停；动作 chunk 很平滑，但 `inserted` 谓词从未为真。
- **StackBowls / PaperCupStacking**：碗/杯没有对齐就下压，导致倾覆。
- **Unlock**：钥匙没进锁芯就施加扭矩，打滑。
- **SyringeWaterTransfer**：针管倾斜超过阈值，液体洒出。
- **人为干扰轴**：人把目标挪走，机器人还在对旧位置做高精度伺服；它「看见」了变化，却不知道自己的需求已经失效。

这些都不是「感知更准」能单独解决的，而是缺少一组**物理/任务谓词**：`Grasped`、`Aligned`、`Above`、`Upright`、`Inserted`、`Supported`、`PathClear`、`HumanPresent`。

### 1.3 仲裁缺口：什么时候信谁

CHUNK-SERVO 的状态机是手写的：`SERVO → CONTACT → RECOVER`，阈值 `d_c`、`θ_e`、`K_p` 靠经验和仿真扫。不同任务的接触刚度、RTT、目标可见性不同；同一组阈值不可能同时适合插网线和叠毛巾。更麻烦的是，安全约束与任务性能之间存在耦合：shield 太松会撞，太紧会误杀正确动作。这个耦合需要一个**离线优化器**，而不是更多手调。

### 1.4 为什么是现在：官方基座 + 33k 演示 + 双目 + 可微调 action head

- 官方 **UnifoLM-WLA-1.0** 已开源 Base 权重、模型服务器和微调代码；VLM 冻结、只训 DiT action head + robot-state projector，单张 24 GB GPU 可跑；还支持 LoRA 微调 action head。这意味着「同一个 checkpoint 上做离线 RL」是工程可行的。
- 官方数据 32 任务、33,276 episodes、169.28 h；成功演示不只是模仿数据，也是**谓词/关键帧/转移先验**的来源。
- 头双目已校正，基线 **58.2526 mm**，`fx≈282.37 px`；0.5–1.0 m 工作距离上视差约 16–33 px，能给出厘米级深度。腕部彩色相机也有内参（本轮复核：`wrist_left.color.camera_matrix` 的 `fx≈436.41`，`wrist_right` 的 `fx≈435.12`；第 12 轮「腕部没有内参」的说法应更正）。但 API 只给腕部 RGB，不给 IR 双目，所以腕部可以做 2D IBVS，不能单独做深度碰撞。
- 挑战赛 API 的四路 RGB、`action_chunk_size`、`ee` 动作、`pivot` 语义都已核实；`action.pivot` 在数据里的字段名是 `vx, vy, angle_z, pivot_3, pivot_4, pivot_5, height`，不是上一轮猜测的 `[vx, vy, wz, yaw, pitch, roll, height]`，adapter 必须按真实字段校验。

## 2. 形式化：把「安全」写成可检查的集合

### 2.1 分块 POMDP

定义分块部分可观测马尔可夫决策过程：

```math
\mathcal M=(\mathcal S,\mathcal O,\mathcal A,T,R,\gamma,l),
```

其中：

- `s_t ∈ S`：隐藏状态（机器人、物体、人的意图）；
- `o_t ∈ O`：观测，`o_t = (I_t^{LH}, I_t^{RH}, I_t^{LW}, I_t^{RW}, q_t, x_t^{ee}, g_t, b_t, l)`；
- `l`：语言指令；
- `a_{t:t+H} ∈ A^H`：EE 空间的动作块；
- `T(s_{t+H} | s_t, a_{t:t+H})`：块级转移；
- `π_VLA(a_{t:t+H_p} | o_t, l)`：30 步规划策略，`H_p=30`；
- `π_S(a_{t:t+H_c} | o_t, g_t)`：伺服策略，`H_c∈{3,5,8}`；
- `g_t`：从成功演示检索出的相对目标。

### 2.2 谓词与常识自动机

定义谓词向量：

```math
P_t=(p_{t,1},\dots,p_{t,K}),\qquad
p_{t,k}=(v_{t,k},c_{t,k},\sigma_{t,k}),
```

`v_{t,k}∈{0,1}` 是布尔值，`c_{t,k}∈[0,1]` 是置信度，`σ_{t,k}∈{geom,demo,vlm}` 是来源。谓词库至少包含：

| 谓词 | 含义 | 主要来源 |
|---|---|---|
| `Grasped(o)` | 夹爪闭合且物体随 EE 刚性运动 | 几何 + `r_grasp` |
| `Empty(g)` | 夹爪张开且无物体 | 几何 |
| `Aligned(a,b)` | 横向误差 < 5 mm、角度 < 5° | 几何 |
| `Above(o,c)` | 物体投影落在容器开口内、高度 0–5 cm | 几何 |
| `Inserted(p,h)` | 插入深度 > `d_min` 且横向 < `tol` | 几何 |
| `Upright(o)` | 物体轴与竖直夹角 < 15° | 几何 |
| `Supported(o)` | 物体底部距支撑面 < 1 cm | 几何 |
| `PathClear` | 扫掠碰撞余量 > 5 mm | 几何 |
| `HumanPresent` | 人手/人在工作区 | VLM + 点云 |
| `TaskDone` | 评分谓词合取或 evaluator 成功 | 演示/VLM |

定义任务模板自动机：

```math
\mathcal A_{\text{task}}=(Q,\Sigma,\delta,q_0,F,I,\rho),
\qquad \Sigma=2^{\mathcal P},
```

其中 `I(q)⊆Σ` 是状态 `q` 的硬不变量，`ρ(q,P)` 是 STL 鲁棒度。轨迹是常识可容许的，当且仅当：

```math
\forall t:\quad
P_t\in I(q_t),\quad
q_{t+1}=\delta(q_t,P_t),\quad
\rho(q_t,P_t)\ge 0.
```

32 个任务映射到 8 个模板：`PICK_PLACE`、`INSERT`、`HANG`、`STACK`、`POUR`、`ZIP`、`UNLOCK`、`FOLD`。以 `INSERT` 为例：

```text
q0 approach --[Aligned ∧ PathClear]--> q1 align
q1 align    --[Grasped ∧ AxisAligned]--> q2 insert
q2 insert   --[Inserted]--> q3 seat
q3 seat     --[Seated]--> q4 release
q4 release  --[Released]--> q5 retreat
```

硬约束示例：

- `q2 insert` 只在 `AxisAligned ∧ PathClear` 时允许；
- `q4 release` 只在 `Above(container) ∧ Supported` 时允许；
- 运输阶段 `Grasped ∧ Upright` 必须持续成立；
- 接触段 `v_ee ≤ 10 cm/s`；
- 任何阶段 `h(q) ≥ 0`。

软约束（进入代价，不直接否决）：倾斜角、横向误差、绕行距离、加速度、离人距离。

**演示转移先验**：对每个任务/阶段统计成功演示中的 `(P_t,P_{t+1})` 频次，得到 `P(P_{t+1}|P_t)`。在线用最近 `W=5` 个转移的负对数似然做异常分：

```math
\mathrm{NLL}_t=-\sum_{i=t-W+1}^{t}\log \hat P(P_{i+1}\mid P_i).
```

若 `NLL_t > μ_task + 3σ_task`（成功演示的均值/标准差），触发异常检查。这不是第二个模型，是一张计数表；它能抓住「抓空」「拿错物体」「目标被挪走」「插入不进去」这些几何伺服看不出的异常。

### 2.3 碰撞余量与安全集

把机器人近似为胶囊集合 `{L_i(q)}`，环境近似为基元集合 `{O_j}` 加残差点云：

```math
h(q)=\min_{i,j}\Big(d(L_i(q),O_j)-\epsilon_{\text{safe}}\Big),
\qquad
\mathcal C=\{q:h(q)\ge 0\}.
```

对 5 步执行块，要求离散时间 CBF 条件：

```math
h(q_{t+k})\ge (1-\alpha\Delta t)^k h(q_t),
\quad k=1,\dots,H_c,
```

`α>0` 是 class-K 增益。这样不是「当前不撞」，而是「整个块都不撞，且余量单调不增」。

### 2.4 Shield：最小干预投影

给定 VLA + 伺服提议 `a_prop`，定义可容许动作集：

```math
\mathcal A_{\text{safe}}(o_t)=
\{a\in\mathcal A^{H_c}:
\text{collision-safe}(a)\land
\text{commonsense-safe}(o_t,a)\}.
```

Shield 是投影：

```math
S(o_t,a_{\text{prop}})=
\arg\min_{a\in\mathcal A_{\text{safe}}(o_t)}
\|a-a_{\text{prop}}\|_W^2.
```

性质：

- 若 `a_prop ∈ A_safe`，则 `S(a_prop)=a_prop`（最小干预）；
- 若 `A_safe` 为空，返回 `HOLD`/`RETREAT` 并触发恢复；
- 若按模式固定，`A_safe` 在每个模式内是凸的，投影存在且唯一。

### 2.5 约束离线 RL：让策略学会不触发 shield

部署策略是 `π_θ^S(a|o)=S(o,π_θ(a|o))`。RL 的目标不是替代 shield，而是让 `π_θ` 自己多提议安全动作：

```math
\max_\theta\ \mathbb E_{\tau\sim p_{\pi_\theta^S}}
\Big[\sum_t\gamma^t r_t\Big]
\quad
\text{s.t.}\quad
\mathbb E[\mathbf 1_{\text{collision}}]\le\epsilon_c,\quad
\mathbb E[\mathbf 1_{\text{hard violation}}]\le\epsilon_v.
```

奖励：

```math
r_t=r_{\text{task}}+\lambda_p\Delta\text{progress}_t
-\lambda_c\max(0,\epsilon_{\text{safe}}-h_t)^2
-\lambda_v v_t
-\lambda_i i_t
-\lambda_e\|a_t-a_t^{BC}\|^2,
```

`i_t=1` 表示 shield 干预。关键是最后一项：策略学会「提议得安全」，干预率下降，shield 的保守代价随之下降。

用 IQL/AWR 在离线数据上优化同一个 action head（VLM 冻结）：

```math
w(s,a)=\exp\!\big(\beta(Q_\phi(s,a)-V_\psi(s))\big)
\cdot\exp\!\big(-\lambda_c\max(0,Q_c(s,a)-\epsilon_c)\big)
\cdot\exp\!\big(-\lambda_v\max(0,Q_v(s,a)-\epsilon_v)\big),
```

```math
\mathcal L_\pi=
-\mathbb E_{\mathcal D}[w(s,a)\log\pi_\theta(a|s)]
+\lambda_{bc}\mathbb E_{\mathcal D}
\big[\|\pi_\theta(a|s)-\pi_{BC}(a|s)\|^2\big].
```

`Q_φ,Q_c,Q_v` 只在训练时存在；部署只保留 `π_θ` 和确定性 shield。

### 2.6 Shield 常数的双层标定

Shield 还有一组常数 `θ_s`（安全边距、`α`、谓词置信阈值、硬/软切换、接触降速）。用约束 PPO/CEM 在数字孪生里标定：

```math
\max_{\theta_s}\ 
\mathbb E[\text{success}]
-\lambda_{\text{int}}\mathbb E[i_t]
-\lambda_{\text{time}}\mathbb E[\text{time}]
```

```math
\text{s.t.}\quad
\mathbb E[\text{collision}]\le\epsilon_c,\quad
\mathbb E[\text{violation}]\le\epsilon_v.
```

与策略更新交替进行，形成双层优化：

```math
\theta^*(\theta_s)=\arg\max_\theta J(\theta;\theta_s),
\qquad
\theta_s^*=\arg\max_{\theta_s}J(\theta^*(\theta_s);\theta_s)
-\lambda C(\theta_s).
```

内层是策略微调，外层是 shield 标定。工程上不必严格求最优，交替 2–3 轮即可。

## 3. 算法步骤

### 3.1 离线管线

```text
A. 谓词/自动机
   33k 成功演示 → 相位分割 → 谓词轨迹 → 每任务模板自动机
   → 阈值取成功演示的 5/95 分位 → 转移计数表 → 异常阈值 μ+3σ

B. 几何
   头双目内参/基线 → 去畸变 → SGBM/WLS 深度 → 点云
   → RANSAC 桌面平面 → 物体 OBB/圆柱基元 → 残差体素 KD-tree
   → G1 URDF 胶囊模型 → 自碰撞矩阵 → 安全边距 ε_safe

C. 数字孪生
   G1 + Dex1 URDF；3 个任务族（peg-in-hole / hang-stack / zip-unlock）
   域随机化：外参 ±2 cm/2°、RTT 0–200 ms、物体位姿 ±5 cm、
   摩擦 ±20%、光照/背景/遮挡；扫 H_c、α、K、ε_safe

D. 策略
   D1 BC：官方 WLA action head 微调（LoRA 或全参），VLM 冻结
   D2 数据：π_BC + shield 在仿真里 rollout，标注碰撞/违反/干预/成功
   D3 离线 RL：IQL/AWR 微调同一 action head；BC 正则；早停
   D4 shield 标定：约束 PPO/CEM 调 θ_s；与 D3 交替 2–3 轮

E. 验证
   离线谓词 F1、碰撞非穿透率、QP 时延、单任务 A/B、p99 延迟
```

### 3.2 在线循环（每次 `get_action`）

```text
1. 几何更新
   头双目点云 → 桌面/基元/残差 → 机器人胶囊 FK → 当前 h(q)

2. 谓词更新
   几何谓词每步算；VLM 只在相位切换或置信度 <0.7 时查询；
   查询结果缓存 0.5 s

3. 自动机/STL
   q_t ← δ(q_{t-1}, P_t)；ρ_t ← STL 鲁棒度；
   若 ρ_t < 0 或 NLL_t 超阈值 → 异常标志

4. 提议
   VLA 30 步 plan（异步缓存）→ 相对目标检索 → 伺服修正
   → a_prop（5 步）

5. 几何 shield
   5 步扫掠碰撞检查（30 Hz 采样 + 中点 + conservative advancement）
   若 h_min ≥ ε_safe：通过
   否则：解 chunk QP / 速度缩放 / 降 H_c；仍不可行 → HOLD/RETREAT

6. 语义 shield
   预测块内谓词转移 → 检查 I(q) 与 STL
   硬违反：否决，尝试 SLOW/RETREAT/RELOCALIZE/REPLAN
   软违反：加代价，交给仲裁

7. 仲裁
   用 θ_s 选择模式与 H_c；若干预率连续偏高 → 记录并进入在线降级
   返回合法 5 步 chunk（绝不返回 NaN/错误形状）

8. 日志
   保存 h_min、ρ、谓词、模式、干预、RTT；供离线复盘
```

### 3.3 伪代码

```python
class TriShieldPolicy:
    def get_action(self, obs):
        # perception
        scene = self.geometry.update(obs)          # point cloud, primitives, capsules
        preds = self.predicates.update(obs, scene)
        if self.phase_changed or preds.confidence < 0.7:
            preds = self.vlm.query(obs, preds)     # same WLA checkpoint
        q, rho, nll = self.automaton.update(preds)

        # proposal
        plan = self.vla.get_plan_async(obs)        # 30-step, cached
        goal = self.demo_index.retrieve(self.task, q)
        a_prop = self.servo.compose(plan[:self.H_c], obs, goal)

        # geometric shield
        a_geo, h_min = self.collision_shield.certify_or_project(
            obs, a_prop, scene, self.theta_s)
        if a_geo is None:
            return self.fallback.hold_or_retreat(obs, scene)

        # semantic shield
        a_sem = self.semantic_shield.filter(obs, a_geo, preds, q, self.theta_s)
        if a_sem is None:
            return self.fallback.recover(obs, q, self.theta_s)

        # arbitration
        mode, self.H_c = self.arbiter.select(obs, preds, q, h_min, self.rtt, self.theta_s)
        a_cmd = self.apply_mode(a_sem, mode)
        self.log(intervention=(not np.allclose(a_cmd, a_prop)),
                 mode=mode, h_min=h_min, rho=rho, nll=nll)
        return self.to_api(a_cmd, obs)
```

## 4. 复杂度分析

| 组件 | 复杂度 | 估计时延（单端口 CPU） |
|---|---|---:|
| 头双目 SGBM + 滤波 | `O(W H d)`，240×320，视差 64 | 5–10 ms |
| 点云体素 + KD-tree | `O(N log N)`，N≈5–10k | 3–6 ms |
| 基元拟合（RANSAC/PCA） | `O(N)` 每基元 | 3–5 ms |
| 机器人 FK + 自碰撞 | `O(N_c^2)`，N_c≈20–30 | <1 ms |
| 5 步扫掠碰撞 | `O(H_c N_c N_o)` | 1–2 ms |
| Chunk CBF-QP | 30 变量、≤50 约束，小 QP | 1–3 ms |
| 谓词/自动机/STL | `O(K)`，K≈10–20 | <1 ms |

## 5. 正确性论证

### 定理 1（碰撞安全）

若 (i) 障碍物按 `ε_safe` 保守膨胀，(ii) 机器人胶囊完全包住连杆，(iii) 每个执行块都存在满足离散 CBF 条件的解，(iv) 低层跟踪误差 `≤ ε_track < ε_safe`，则整个执行块内机器人不与障碍物穿透。

证明要点：离散 CBF 条件给出 `h(q_{t+k}) ≥ (1-αΔt)^k h(q_t) ≥ 0`；跟踪误差由保守膨胀吸收；对块内每个采样点成立，保守推进覆盖采样间运动。若 QP 不可行，HOLD/RETREAT 分支保证不继续朝危险方向运动。

### 定理 2（语义安全）

若硬谓词检测器是可靠的（硬约束下无假阳性），且自动机转移是确定性的，则 shielded 策略不会执行硬约束违反。证明：对自动机状态做归纳；shield 只允许预测转移落在 `δ(q,·)` 且满足 `I(q)` 的动作。

注意：这是条件性保证。谓词假阴性/假阳性是最大风险，见 §6。

### 定理 3（最小干预）

若 `A_safe` 在固定模式下是凸集，则 `S(a_prop)` 是 `a_prop` 在 `A_safe` 上的欧氏投影；当 `a_prop ∈ A_safe` 时 `S(a_prop)=a_prop`；投影是非扩张的，不会放大提议误差。证明：凸集投影的标准性质。

### 定理 4（合规）

部署系统中唯一的学习组件是 WLA checkpoint；S-SHIELD 是谓词/计数表/STL，G-SHIELD 是几何算法，R-SHIELD 的 Q 函数只在训练时存在；RL 标定输出固定常数/公式。因此部署满足「同一模型」规则。证明：按构造；提交材料中列出所有在线组件及其是否有学习权重。

### 命题 5（RL 降低干预率）

若 AWR 权重对「成功且无干预」的样本更高，且策略容量足够，则优化后的 `π_θ` 在 `A_safe` 内的概率质量增加，`E[i_t]` 下降。证明思路：AWR 是优势加权 BC；干预样本的 `Q` 因 `-λ_i i_t` 更低，权重更小；策略向高权重区域移动。该命题是渐近/经验性的，需 G11 验证。

## 6. 已知风险

| 风险 | 影响 | 缓解 | 检测 |
|---|---|---|---|
| **感知地基错误**：透明/反光/变形物体让深度和谓词同时失效 | shield 漏拦或误拦 | 置信度门控；低置信时降速/只做保守 PBVS；硬约束只在 c≥0.9 时生效；保留 VLA 开环回退 | G8/G9 的假阳性/假阴性率 |
| **过度保守**：shield 否决太多正确动作 | 成功率下降 | 最小干预投影；软/硬分层；RL 惩罚干预；按任务监控干预率，>20% 时降级 | G11 干预率与成功率 |
| **sim-to-real gap**：RL 标定的常数在真机不优 | 性能损失 | 域随机化；只调低维常数；真机单任务通道复核；保留手工安全默认值 | G10/G11 |
| **VLM 查询错误/延迟** | 语义误判；p99 超预算 | 只在切换/低置信时查；缓存；校准 yes/no 阈值；几何谓词优先 | G8 延迟与准确率 |
| **碰撞模型失配**：薄/透明/动态物体不在点云 | 漏检 | 保守膨胀；本体跟踪误差接触检测；未知障碍降速；人类进入即停 | G9 非穿透率 |
| **单模型解释**：RL 微调被误认为第二个模型 | 合规风险 | 同一 checkpoint；Q 函数不部署；提交材料写清楚；保留纯 BC 回退 | 合规审查 |
| **评测噪声**：320 trials，SE≈2.4pp | 假阳性 | 配对 A/B；bootstrap；重复；不把 +1–2pp 当结论 | G11 |
| **实时性**：CPU 弱/多端口并发 | 延迟抖动 | 点云降采样；QP 热启动；按端口隔离；p99 门 | G5/G6 |

## 7. 一句话最大风险

**当前方案最大的风险是：安全包络依赖的立体几何与常识谓词，恰好在透明/反光/变形物体和人为干扰这些最需要它的场景里最不可靠；一旦感知地基错了，shield 会既漏拦又误拦，而 RL 会把这种错误固化成策略先验。**

## 0. 结论与边界

### 0.1 一句话结论

CHUNK-SERVO 把反馈周期从约 1 s 降到约 200 ms，但「反应快」不等于「反应对」。TRI-SHIELD 在 VLA 提议与执行之间插入三个确定性/离线层：**S-SHIELD** 用演示谓词自动机 + 同一 VLM 的低频查询判断「该不该做」；**G-SHIELD** 用头双目点云 + G1 URDF 胶囊 + 扫掠碰撞 CBF 判断「能不能做」；**R-SHIELD** 用约束离线 RL 微调同一个 WLA action head，并在仿真里标定 shield 常数，让策略学会少提出会被拦截的动作。部署时仍然只有一个学习模型。

### 2.5 碰撞余量

```math

\qquad

```

块级离散 CBF：

```math
h(q_{t+k})\ge (1-\alpha\Delta t)^k h(q_t),
\quad k=1,\dots,H_c.
```

### 2.6 Shield 投影

```math
\mathcal A_{\text{safe}}(o_t)=
\{a:\text{collision-safe}(a)\land\text{commonsense-safe}(o_t,a)\},
```

```math
S(o_t,a_{\text{prop}})=
\arg\min_{a\in\mathcal A_{\text{safe}}(o_t)}
\|a-a_{\text{prop}}\|_W^2.
```

### 2.7 约束离线 RL

```math
\max_\theta\ 
\mathbb E_{\tau\sim p_{\pi_\theta^S}}
\Big[\sum_t\gamma^t r_t\Big]
\quad\text{s.t.}\quad
\mathbb E[\mathbf 1_{\text{collision}}]\le\epsilon_c,\ 
\mathbb E[\mathbf 1_{\text{hard violation}}]\le\epsilon_v.
```

奖励：

```math
r_t=r_{\text{task}}+\lambda_p\Delta\text{progress}_t
-\lambda_c\max(0,\epsilon_{\text{safe}}-h_t)^2
-\lambda_v v_t
-\lambda_i i_t
-\lambda_e\|a_t-a_t^{BC}\|^2.
```

```text
HANG:       approach → align_hook → hang → release → retreat
STACK:      approach → align → place → release → retreat
POUR:       approach → grasp → lift → align → pour → return → release
ZIP:        approach → grasp_tab → pull → release
UNLOCK:     approach → insert_key → turn → pull → release
FOLD:       approach → grasp_corner → fold → release → repeat
```

硬约束（示例）：

```text
G(insert → (AxisAligned ∧ PathClear))
G(release → (Above(container) ∧ Supported))
G(transport → (Grasped ∧ Upright))
G(contact → v_ee ≤ 10 cm/s)
G(h(q) ≥ 0)
```

软约束：

```text
tilt ≤ 20°（运输）
lateral ≤ 1 cm（接近）
human_distance ≥ 30 cm
jerk ≤ J_max
```

### 3.3 STL 鲁棒度

连续信号 `x(t)`：

```math
\rho(x\ge c)=x-c,
\qquad
\rho(\neg\phi)=-\rho(\phi),
```

```math
\rho(\phi\land\psi)=\min(\rho(\phi),\rho(\psi)),
```

```math
\rho(\mathbf G_{[a,b]}\phi)=\min_{t\in[a,b]}\rho(\phi(t)),
\qquad
\rho(\mathbf F_{[a,b]}\phi)=\max_{t\in[a,b]}\rho(\phi(t)).
```

示例：

```math
\phi_{\text{transport}}=\mathbf G(\text{Grasped}\rightarrow\theta_{\text{tilt}}\le20^\circ),
```

```math
\phi_{\text{release}}=\mathbf G(\text{release}\rightarrow
(z_{\text{rel}}\le5\text{cm}\land e_{\text{lat}}\le5\text{mm}\land h\ge0)).
```

`ρ<0` 为违反。硬约束只在谓词置信度 `c≥0.9` 时生效；否则降为软约束并降速，避免感知噪声误杀。

### 3.4 演示转移先验

对每个任务/阶段统计成功演示的转移频次：

```math
\hat P(P_{t+1}\mid P_t)=
\frac{N(P_t,P_{t+1})+\epsilon}{N(P_t)+\epsilon|\Sigma|}.
```

在线异常分：

```math
\mathrm{NLL}_t=-\sum_{i=t-W+1}^{t}\log\hat P(P_{i+1}\mid P_i).
```

若 `NLL_t > μ_task+3σ_task`，触发：

- 目标是否被移动（`edit_score`）；
- 抓取是否失败（`r_grasp`）；
- 对象是否拿错（VLM/外观）；
- 插入是否卡住（深度/位姿无进展）。

这是计数表，不是学习模型；可解释、可审计。

### 3.5 VLM 查询协议

使用 WLA 的同一 VLM checkpoint（Qwen-VL interface），冻结，不加载第二个模型。提示模板：

```text
Q1: Is the robot holding the {object}? Answer yes or no.
Q2: Is the {object} above the {container}? Answer yes or no.
Q3: Is the {object} upright? Answer yes or no.
Q4: Is a human hand touching the {object}? Answer yes or no.
Q5: Is the {object} inside the {container}? Answer yes or no.
Q6: Has the robot completed subgoal "{subgoal}"? Answer yes or no.
```

校准：

- 在演示关键帧上标注 yes/no，拟合温度 `T` 和阈值 `τ`；
- 只在相位切换、`c<0.7`、或异常分超阈值时查询；
- 结果缓存 0.5 s；
- 查询超时 → 回退几何谓词，不阻塞 `get_action`。

VLM 查询不是第二个模型：它是同一 checkpoint 的冻结 VLM 分支，属于 C3 合规模式；若官方对「模型」作最宽解释，可关闭 VLM 查询，只用几何谓词（C1/C2）。

## 4. G-SHIELD：碰撞检测与 CBF

### 4.1 头双目深度

校正后双目：

```math
d=\frac{f_x b}{Z},\qquad
\delta Z=\frac{Z^2}{f_x b}\delta d.
```

`f_x≈282.37 px`，`b=58.2526 mm`：

| `Z` | 视差 | `δd=0.1px` 的深度误差 | `δd=0.5px` 的深度误差 |
|---:|---:|---:|---:|
| 0.6 m | 27.4 px | 2.2 mm | 10.9 mm |
| 0.8 m | 20.6 px | 3.9 mm | 19.4 mm |
| 1.0 m | 16.5 px | 6.1 mm | 30.3 mm |

结论：0.6–0.8 m 上深度是**厘米级**，不是毫米级。`ε_safe` 取 `max(5mm, 2σ_Z)`；透明/反光物体额外膨胀。碰撞层只保证「不穿透」，不保证毫米级插入；毫米级插入仍由 CHUNK-SERVO 的腕部 IBVS + 接触相位完成。

处理链：

```text
去畸变 → SGBM/WLS → 左右一致性过滤 → 小连通域去除
→ 反投影到 base 系（用 lower_body/waist + URDF 恢复头相机外参）
→ 体素 5 mm → 桌面 RANSAC → 物体 OBB/圆柱 → 残差 KD-tree
```

### 4.2 机器人胶囊模型

G1 URDF 的连杆用胶囊近似：

```math
L_i(q)=(p_i(q),q_i(q),r_i),
```

`p_i,q_i` 是胶囊两端，`r_i` 是半径（最大连杆半径 + 1 cm）。自碰撞检查所有非相邻胶囊对；夹爪夹住物体时，把物体作为刚体附加到 EE，一起参与碰撞。

### 4.3 5 步扫掠碰撞

对执行块 `a_{t:t+H_c}`：

1. 用 IK 把 5 个 EE 路点转成关节构型；
2. 在 30 Hz 采样点 + 中点（共 9–10 个）做静态碰撞；
3. 相邻采样点之间用 conservative advancement 或扫掠胶囊做连续碰撞；
4. 输出 `h_min` 和活跃约束集 `{(n_i,h_i)}`。

若 IK 失败或 `h_min<0`，块不可执行。

### 4.4 Chunk CBF-QP

设块内 EE twist 为 `ξ=(ξ_0,...,ξ_{H_c-1})∈R^{6H_c}`。离散 CBF 线性化：

```math
h_i(q_{k+1})\approx h_i(q_k)+\nabla_q h_i(q_k)^\top J(q_k)\xi_k\Delta t.
```

要求：

```math
h_i(q_{k+1})\ge(1-\alpha\Delta t)h_i(q_k)
```

得到线性约束：

```math
\underbrace{\nabla_q h_i(q_k)^\top J(q_k)}_{a_{k,i}^\top}\xi_k
\ge\underbrace{-\alpha h_i(q_k)}_{b_{k,i}}.
```

QP：

```math
\min_{\xi_0,\dots,\xi_{H_c-1}}
\sum_{k=0}^{H_c-1}\|\xi_k-\xi_k^{\text{prop}}\|_W^2
```

```math
\text{s.t.}\quad
a_{k,i}^\top\xi_k\ge b_{k,i},
\quad \|\xi_k\|_\infty\le\xi_{\max}.
```

不可行时加松弛：

```math
\min_{\xi,s}\ 
\sum_k\|\xi_k-\xi_k^{\text{prop}}\|_W^2+\lambda_s\|s\|^2
```

```math
\text{s.t.}\quad
a_{k,i}^\top\xi_k+s_{k,i}\ge b_{k,i},
\quad s_{k,i}\ge0.
```

若 `Σs_{k,i}>ε_s`，进入 `HOLD`/`RETREAT`；不把带大松弛的动作发给 evaluator。

线性化只在局部有效：解完后用非线性 FK 重新验证；若仍违反，二分缩小步长 `γ∈[0,1]` 或降 `H_c`，直到通过或回退。

### 4.5 本体感知接触检测

API 没有力/触觉，但有 joint position/velocity 和 EE 位姿。用速度跟踪残差做伪接触信号：

```math
r_t=\frac{\|v_{ee}^{cmd}-v_{ee}^{obs}\|}{\|v_{ee}^{cmd}\|+\epsilon},
\qquad
r_j=\frac{\|\dot q^{cmd}-\dot q^{obs}\|}{\|\dot q^{cmd}\|+\epsilon}.
```

- `h_min` 小且 `r_t` 突增 → 预期接触，进入 `CONTACT`；
- `h_min` 大且 `r_t` 突增 → 未建模碰撞/外部扰动 → `HOLD`；
- 若低层控制器能提供力矩估计，可换成广义动量观测器，得到更干净的 6D wrench 估计（作为可选增强，不依赖）。

## 5. R-SHIELD：约束离线 RL

### 5.1 数据

```text
D = D_real ∪ D_sim
D_real: 33,276 条成功演示（含语言、四路图、状态、动作）
D_sim:  π_BC + shield 在数字孪生中的 rollout
        标注：碰撞、常识违反、shield 干预、成功、阶段进度
```

按 session/物体/背景分组划分，相邻帧不跨 split，避免数据泄漏。

### 5.2 奖励

```math
r_t=r_{\text{task}}+\lambda_p\Delta\text{progress}_t
-\lambda_c\max(0,\epsilon_{\text{safe}}-h_t)^2
-\lambda_v v_t
-\lambda_i i_t
-\lambda_e\|a_t-a_t^{BC}\|^2.
```

- `r_task`：成功 1，否则 0；
- `Δprogress`：阶段进度变化；
- `c_t`：碰撞余量的二次惩罚（稠密）；
- `v_t`：常识硬违反；
- `i_t`：shield 干预；
- BC 正则：防止离线 RL 跑偏。

### 5.3 IQL / AWR

学三个 Q：

```math
\mathcal L_Q=\mathbb E_{\mathcal D}
\big[(Q_\phi(s,a)-r-\gamma V_\psi(s'))^2\big],
```

```math
\mathcal L_V=\mathbb E_{\mathcal D}
\big[L_\tau^\kappa(Q_\phi(s,a)-V_\psi(s))\big],
```

```math
L_\tau^\kappa(u)=|\tau-\mathbf 1_{u<0}|\cdot u^2,
```

`τ=0.7–0.9`。安全 Q：

```math
\mathcal L_{Q_c}=\mathbb E_{\mathcal D}
\big[(Q_c(s,a)-c-\gamma V_c(s'))^2\big],
```

```math
\mathcal L_{Q_v}=\mathbb E_{\mathcal D}
\big[(Q_v(s,a)-v-\gamma V_v(s'))^2\big].
```

AWR 权重：

```math
w(s,a)=\exp\!\big(\beta(Q_\phi(s,a)-V_\psi(s))\big)
\cdot\exp\!\big(-\lambda_c\max(0,Q_c(s,a)-\epsilon_c)\big)
\cdot\exp\!\big(-\lambda_v\max(0,Q_v(s,a)-\epsilon_v)\big).
```

策略损失：

```math
\mathcal L_\pi=
-\mathbb E_{\mathcal D}[w(s,a)\log\pi_\theta(a|s)]
+\lambda_{bc}\mathbb E_{\mathcal D}
\big[\|\pi_\theta(a|s)-\pi_{BC}(a|s)\|^2\big].
```

`Q_φ,Q_c,Q_v,V_ψ` 是小 MLP（2–3 层，256 隐藏单元），输入是冻结 VLM 特征 + 本体 + 谓词 + 碰撞余量。它们**只在训练时存在**，部署不加载。

### 5.4 策略微调

- 基座：官方 WLA Base；
- 冻结 VLM（`qwen_vl_interface`）；
- 只训 DiT action head + robot-state projector；
- 可用 LoRA（`trainer.lora.action_model`）降低显存；
- 学习率小、1–3 epochs、早停；
- 保留 BC checkpoint 作为回退。

### 5.5 Shield 常数标定

`θ_s` 包括：

```text
ε_safe, α, H_c, v_max, a_max,
θ_edit, θ_coll, θ_conf, θ_align,
λ_hard/λ_soft, T_hold, N_retry
```

约 15–20 个标量。用约束 PPO/CEM 在仿真里优化：

```math
\max_{\theta_s}\ 
\mathbb E[\text{success}]
-\lambda_{\text{int}}\mathbb E[i_t]
-\lambda_{\text{time}}\mathbb E[\text{time}]
```

```math
\text{s.t.}\quad
\mathbb E[\text{collision}]\le\epsilon_c,\quad
\mathbb E[\text{violation}]\le\epsilon_v.
```

约束 PPO 的拉格朗日：

```math
\mathcal L(\theta_s,\lambda)=
-J(\theta_s)
+\lambda_c(\hat C_c-\epsilon_c)
+\lambda_v(\hat C_v-\epsilon_v),
```

```math
\lambda_c\leftarrow\max(0,\lambda_c+\eta(\hat C_c-\epsilon_c)).
```

部署时只用 `θ_s*` 的固定值/公式，不加载 RL 网络。

### 5.6 双层交替

```text
for round in 1..2:
    θ ← offline RL(θ; θ_s)          # inner
    θ_s ← constrained PPO/CEM(θ_s; θ)  # outer
```

工程上不必严格最优；交替 2 轮即可。若 RL 微调不稳定，回退到 BC + shield 标定（仍比第 12 轮多一层安全）。

### 6.1 端口拓扑

### 6.2 `get_action` 伪代码

```python
def get_action(self, obs):
    # 1. geometry
    scene = self.geometry.update(obs)                 # point cloud, primitives, capsules
    h_now = self.collision.margin(scene, obs.q)

    # 2. predicates
    preds = self.predicates.update(obs, scene)
    if self.automaton.phase_changed() or preds.min_conf < 0.7:
        preds = self.vlm.query_cached(obs, preds)

    # 3. automaton / STL / anomaly
    q, rho = self.automaton.update(preds)
    nll = self.automaton.nll(preds)
    anomaly = (rho < 0) or (nll > self.theta_s.nll_thresh)

    # 4. proposal
    plan = self.vla.get_plan_async(obs)               # 30-step, cached
    goal = self.demo_index.retrieve(self.task_id, q)
    a_prop = self.servo.compose(plan[:self.H_c], obs, goal)

    # 5. G-SHIELD
    a_geo, h_min = self.collision.certify_or_project(
        obs, a_prop, scene, self.theta_s)
    if a_geo is None:
        return self.fallback.hold_or_retreat(obs, scene)

    # 6. S-SHIELD
    a_sem = self.semantic.filter(obs, a_geo, preds, q, self.theta_s)
    if a_sem is None:
        return self.fallback.recover(obs, q, anomaly)

    # 7. arbitration
    mode, self.H_c = self.arbiter.select(
        obs, preds, q, h_min, self.rtt, anomaly, self.theta_s)
    a_cmd = self.apply_mode(a_sem, mode)

    # 8. log
    self.log(intervention=not np.allclose(a_cmd, a_prop),
             mode=mode, h_min=h_min, rho=rho, nll=nll,
             conf=preds.min_conf, rtt=self.rtt)
    return self.to_api(a_cmd, obs)
```

### 6.3 模式状态机

```text
INIT ──obs──▶ PLAN ──plan──▶ SERVO
  ▲              ▲              │
  │              │              ├─ h_min < d_far ──▶ APPROACH
  │              │              ├─ h_min < d_c   ──▶ CONTACT
  │              │              └─ anomaly       ──▶ RECOVER
  │              │                                   │
  │              └──────── REPLAN ◀───────────────────┤
  │                                                  ├─ target visible ──▶ RELOCALIZE
  │                                                  └─ collision risk ──▶ RETREAT
  └──────────────── reset ──────────────────────────── HOLD/DONE
```

- `SERVO`：PBVS 主导，IBVS 辅助；
- `APPROACH`：降速，G-SHIELD 紧边距，S-SHIELD 硬约束；
- `CONTACT`：法向缩幅/低通，切向保留，伪接触检测；
- `RECOVER`：停 → 重定位 → 更新 goal → 恢复；
- `RETREAT`：沿碰撞法向反向退出，重新规划；
- `HOLD`：等待下一帧或超时失败。

### 6.4 动作适配

WLA 54D → API 21D（EE 模式）：

```text
left_ee_abs  = compose(T_left_ee_current, exp(left_ee_rel))
right_ee_abs = compose(T_right_ee_current, exp(right_ee_rel))
grippers     = 直通（校验 0–1 方向）
```

要点：

2. rpy↔rot6d 转换；
3. pivot 未验证前返回全零；
4. EE 帧/TCP 偏移用 `example_env.py` + 真实数据手眼标定（≤1 cm/2°）；
5. 形状/NaN/token 检查，任何异常返回上一组合法 chunk 或安全 hold。


## 8. 正确性论证

### 定理 1（碰撞非穿透）

若障碍物按 `ε_safe` 保守膨胀、机器人胶囊完全包住连杆、每个执行块存在满足离散 CBF 的解、低层跟踪误差 `≤ε_track<ε_safe`，则块内不与障碍物穿透。

证明：离散 CBF 给出 `h(q_{t+k})≥(1-αΔt)^k h(q_t)≥0`；保守膨胀吸收跟踪误差；保守推进覆盖采样间运动；QP 不可行时 HOLD/RETREAT 不朝危险方向继续。

### 定理 2（语义安全）

若硬谓词在硬约束下无假阳性、自动机转移确定，则 shielded 策略不执行硬违反。证明：对自动机状态归纳；只允许预测转移满足 `δ` 与 `I(q)` 的动作。

条件性：假阴性/假阳性是最大风险；用置信度门控 + 软/硬分层缓解。

### 定理 3（最小干预）

固定模式下 `A_safe` 为凸集时，`S(a_prop)` 是欧氏投影；`a_prop∈A_safe ⇒ S(a_prop)=a_prop`；投影非扩张。证明：凸集投影标准性质。

### 定理 4（合规）

部署系统唯一学习组件是 WLA checkpoint；S-SHIELD 是谓词/计数表/STL；G-SHIELD 是几何算法；R-SHIELD 的 Q 函数只在训练时存在；RL 标定输出固定常数。证明：按构造；提交材料列出在线组件及权重。

### 命题 5（RL 降低干预率）

若 AWR 对「成功且无干预」样本给更高权重、策略容量足够，则优化后 `π_θ` 在 `A_safe` 内的概率质量增加，`E[i_t]` 下降。证明思路：AWR 是优势加权 BC；干预样本因 `-λ_i i_t` 得低 Q；策略向高权重区域移动。需 G11 验证。

| G7 | CHUNK-SERVO 消融 | 相对目标>绝对；5 步>30 步；伺服>无伺服 | 保留有效部分 |
| G8 | 常识谓词 | 硬谓词 F1 ≥0.90；异常 AUROC ≥0.90；VLM p99 ≤200 ms | 关 VLM，只用几何谓词 |
| G9 | 碰撞 shield | 仿真非穿透 ≥99.9%；误拦 ≤5%；QP p99 <5 ms | 放宽边距/只做速度缩放 |
| G10 | RL 标定/微调 | 仿真成功 +5pp vs 手调；碰撞 ≤1%；≤5k rollouts | 回退 BC + 手调 |
| G11 | 集成 A/B | ≥3/5 任务 +5pp；碰撞 -50%；p99 ≤150 ms；FoldTowel 不回归 | 只保留 G-SHIELD |
| G12 | 全消融 | S/G/R 单独与组合；硬/软；VLM 频率；QP vs scaling | 砍无效部分 |

## 10. 竞赛策略与预算

### 10.1 任务分档

- **A 档（安全层优先，19 个）**：HangCup、DisconnectEthernet、ToolboxStorage、PlugCharger、Unlock、ArrangeTestTubes、OpenPillBottle、OrganizeStationery、PackBag、ZipUp、PaperCupStacking、StoreRacket、StackCups、PlugInEthernet、StackBowls、StoreEarphones、PackPhone、OrganizePencilCase、SyringeWaterTransfer。
- **B 档（VLA 优先，13 个）**：FruitCollection、PackDoll、FruitSorting、ColorArrangement、PlacePhotoFrame、OrganizeBookshelf、PickOutBatteries、OrganizeTools、FoldTowel、ArrangePlates、SpellRobot、ConveyorSorting、RemovePinnedNote。

优先级：

```text
priority_t = q_t * Δ_t / cost_t
```

`q_t`：失败发生在最后 3 厘米/常识违反的比例（先用语义先验，单任务通道后更新）；`Δ_t`：shield 条件增益；`cost_t`：工程/评测成本。

### 10.2 预算

| 方案 | 成本 | 预期收益 | 建议 |
|---|---|---|---|
| WLA 直接适配 + CHUNK-SERVO | 1–2 人周 | 基线 | 必做 |
| G-SHIELD（几何） | 2 人周 + 1 GPU 周 | 碰撞/急停下降；成功率 +1–3pp | 主投 |
| S-SHIELD（常识） | 2 人周 | 语义失败 -30–50%；human +1–2pp | 主投 |
| R-SHIELD（RL 微调/标定） | 2–3 GPU 周 + 1 人周 | +3–5pp（假设） | 过 G10 再投 |
| 完整世界模型 | 8+ GPU 周 | 不确定；延迟更差 | 不做 |
| 32 任务各训策略 | 规则禁止 | — | 不做 |

收益算术（假设）：A 档 19 任务各 +5pp → `19/32×5≈+3.0pp`；human +10pp → `+2pp`；保守合计 +3–5pp，乐观 +6–8pp。若 RL 额外 +2pp，上限约 +8–10pp。所有数字是设计目标，不是承诺。

### 10.3 提交节奏

1. **W0**：WLA + API adapter + CHUNK-SERVO 基线；单任务通道验证 token/pivot/TCP。
2. **W1**：若允许多次提交，先交安全基线锁 tie-break。
3. **W2–W3**：G-SHIELD + 标定；仿真非穿透/时延。
4. **W3–W4**：S-SHIELD + 谓词/异常；真机单任务 A/B。
5. **W5**：R-SHIELD（离线 RL/标定）；过 G10 才进最终包。
6. **W6**：32 任务干跑；最终提交；保留回退开关。

## 11. 合规

| 模式 | 做法 | 风险 | 建议 |
|---|---|---|---|
| C1 纯离线 | 只有 VLA 在线；谓词/碰撞只离线用 | 最低 | 保守回退 |
| C2 确定性控制器 | shield 是几何/逻辑，无学习权重 | 低 | 主推 |
| C3 同 checkpoint | VLM 查询用同一 WLA checkpoint；RL 微调同一 action head | 低–中 | 需要强语义时用 |
| 禁止 | 第二个学习策略/残差网络/独立视觉编码器在线决策 | 高 | 不做 |

提交材料需列出：

- 在线组件清单与是否有学习权重；
- VLM 查询来自同一 checkpoint；
- Q 函数不部署；
- RL 标定只输出固定常数；
- 演示先验是计数表；
- 回退开关（关闭 S/R，只留 G）。

|---|---|---|---|

## 14. 一句话押注与最大风险

**押注**：用同一 WLA 做 30 步规划，用 CHUNK-SERVO 做 5 步伺服，用 S-SHIELD 的常识自动机判断「该不该做」，用 G-SHIELD 的扫掠碰撞 CBF 判断「能不能做」，用 R-SHIELD 的约束离线 RL 让策略学会少触发拦截；先保证不撞、不违反物理常识，再谈最后 3 毫米的精度。

**当前方案最大的风险**：安全包络依赖的立体几何与常识谓词，恰好在透明/反光/变形物体和人为干扰这些最需要它的场景里最不可靠；一旦感知地基错了，shield 会既漏拦又误拦，而 RL 会把这种错误固化成策略先验。
