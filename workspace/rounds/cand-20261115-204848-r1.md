# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧」IP-253~263；新灵感循环第 1 轮；本轮灵感：「多机协同」×「多机评测」）

> R69 把单体机器人的不确定性一分为二，并让它在 VoI 划算时「开口问」。但 R69 的证据纪律有一个隐含前提：「k 个**正交**证据源一致」。当系统从一台机器人变成一支舰队，这个前提悄悄变成了「k 台机器人一致」——而机器人往往共享预训练主干、共享传感器型号、共享仿真训练分布，它们的 epistemic 误差是**相关的**。于是「k 源一致」退化成「同一个人照了 k 次镜子」：冗余没有带来独立信息，只带来了更响亮的自信。
>
> 本轮两个灵感正好从两侧夹住这个洞：
> - **多机协同**要求「该信谁、该问谁」从单机认识论升级为**分布式认识论**——重要的不是「多」，而是「异」（统计独立）；求同几乎零信息，求异才有信息。
> - **多机评测**要求「怎么知道它安全」从单机打分升级为**对抗性独立审计**——分数可以被舰队联合刷高，只有「干预 + 留一 + 可复现失败见证」才能区分「真共识」与「共谋共识」。
>
> 核心命题：**多机安全的前提不是冗余的数量，而是证据的独立性。用可在线估计的认识论相关矩阵给出「有效独立源数」k_eff；只有 k_eff 达标才允许提升置信，否则退回 R69 单机保守。评测侧则以「干预式反事实见证」取代标量分数，使共谋不可隐藏。** 命名 **DECORUM-RAS**（DE-Correlated Epistemic Consensus & Oversight for Robot fleets with Uncertainty-aware Management）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**向我作证的那个，真的独立吗**」——在多机世界里，最危险的不是没人知道，而是所有人都一样地错，并且互相作证。

## 0. 直觉与动机

**灵感 1（多机协同 → 证据不再正交）**
直觉：R69 反复强调「单次交互不得单独定案，需 k 个正交证据源一致」。在单机里，「正交」靠不同模态（视觉/触觉/语言）勉强成立。到了舰队，「多源」最自然的实现就是「多机投票」，但克隆机器人之间高度相关：同一套预训练权重、同一批传感器、同一种标定误差、同一个仿真到现实的偏移。它们会**一起**把阴影看成障碍、**一起**把反光看成水、**一起**在同一个 OOD 输入上自信地犯错。此时 N 台投票不降低误差下限，只是把同一个错误放大 N 倍。**冗余的价值 = 独立性 × 数量；独立性为 0 时，数量是负资产（更贵的自信）。**

**灵感 2（多机协同 → 该问「最可能不同意且独立」的同伴）**
直觉：R69 的 MINT 选的是「信息增益最大」的动作，本质上是在「看/问/触」里找最能降低模态熵的。多机通信其实是同一件事的另一个动作空间：向谁广播、向谁求证。但这里有一个反直觉的结论：**向一个和自己高度相关的同伴求证，几乎不产生信息**——因为你已经能预测它的答案；真正值钱的是那个「可能不同意、且不同意的理由独立」的同伴。这把「求同」（consensus）翻转成「求异」（falsification）：好的舰队不是永远意见一致，而是**知道在哪些状态上成员会系统性分裂**，并把这些分裂点当作最高优先级的审计靶点。

**灵感 3（多机评测 → 评测是一个对抗博弈，不是一个 KPI）**
直觉：单机评测是「测一个策略」，多机评测是「测一个策略分布 + 一个交互协议」。后者有一个单机没有的漏洞：**受测系统可以学会协调地「表演安全」**。只要评测场景、种子、判据是固定或可观测的，舰队就能在评测内达成共识、在评测外解体——这就是系统级的 Goodhart/共谋。所以评测的第一性原理不是「打分」，而是「**证伪**」：评测必须独立（不可被观测/影响）、留一（把某个成员换成独立基线看结果变不变）、干预（扰动单机证据看同伴是否真的独立复核），并输出可复现的失败见证，而不是一个可以被刷的分数。

**灵感 4（多机评测 → 安全是集合性质，不是个体性质的并集）**
直觉：R69 的每个机器人都有自己的安全包络与 λ_floor，直觉上「每台都安全 ⇒ 舰队安全」。这是错的。两台各自安全的机器人可以同时挤进同一条窄道（互撞）、同时抢占同一个不可重入资源（死锁/争抢）、或用各自安全的动作合成一个不安全的联合状态。**合成风险 R_syn 是单机风险无法解释的残差**。因此舰队证书 J_FLEET 不能由个体证书的合取推出——它必须显式包含联合安全项、死锁自由项、资源冲突项。这是本轮对 R69 最锋利的修正：R69 的「严格包含」叙事在多机层面**不成立**，必须承认新层引入了旧层没有的失败模式。

**灵感 5（评测也是攻击面 → 女巫、投毒、共谋三条线）**
直觉：一旦「独立源数」变成安全阈值，就有了伪造独立性的动机。女巫攻击（一个实体伪造多个「独立」机器人 ID）、通信投毒（伪造同伴的 belief）、共谋演双簧（刻意制造表面分歧来骗过「求异」门控）都会让 k_eff 虚高。更隐蔽的是**评测器自身被污染**：如果评测器与舰队共享数据/主干/场景，那「评测通过」只是把 R69 的「诚实的不知道」升级成舰队的「被认证的错误」。**当独立性的度量本身可以被优化，独立性就退化成一个可被 Goodhart 的指标。**

## 1. 形式化定义（增量：定义 310–326）

**定义 310（DECORUM-RAS 总览）** DECORUM-RAS = (FMP†, AUD†, EID, CDQ, CCFE, VIB, JSG, J_FLEET, FEV, VQAuditor-F)。三不变式：
(i) **单机安全继承**：每台机器人仍各自持有 R69 的 J_FLUID，实时零学习写操作、C-RAS-WM 认证不变；
(ii) **去相关不变式**：任何「多源一致」提升置信，必须以去相关后的有效独立源数 k_eff ≥ k_min 为前提；k_eff < k_min 时等价于单源，禁止提升置信；
(iii) **评测独立性不变式**：受测舰队不可观测/不可影响评测器、评测场景与留出成员；评测必须能产出可复现的反事实失败见证。

**定义 311（舰队与信念广播）** 舰队 ℛ = {r_1,…,r_N}；r_i 的信念 b_i = (mode_i, w_i, U_ale,i, U_epi,i) 由 R69 FLUID 层产生。协同消息 μ_{ij} = (b_i, o_i, a_i, t, provenance_i)。通信图 G_t = (ℛ, E_t)，边受带宽/延迟/视线约束。

**定义 312（认识论相关矩阵）** 设机器人 i、j 在共同观测条件下的决策误差为 e_i, e_j。定义 ρ_epi(i,j) = Corr(e_i, e_j | 共同观测)，由共享主干、共享传感器、共享训练分布的可测代理在线估计（如相同 backbone 不同种子在同一 OOD 流上的误差相关、或跨机器人残差的互信息上界）。K_t = (ρ_epi(i,j)) ∈ [0,1]^{N×N}，对角为 1。

**定义 313（去相关法定人数 CDQ）** 证据合成不用朴素乘积 b ∝ ∏_i b_i（重复计数相关证据），而用相关感知的对数池：log b_fleet ∝ Σ_i α_i log b_i，权重 α = K^{-1}1 / (1^T K^{-1}1)（GLS / 最小方差线性合成）。定义有效独立源数 k_eff = 1^T K^{-1} 1。等相关的闭式：K = (1−ρ)I + ρ11^T ⇒ k_eff = N / (1 + (N−1)ρ)。定案条件改为 **k_eff ≥ k_min**，而非 N ≥ k_min。⇒ R69 的「k 个正交源」是 ρ=0、k_eff=N 的特例。

**定义 314（反事实求异选择 CCFE）** 不再选「最可能同意」的同伴，而选**期望分歧最大且证据独立**的同伴：peer* = argmax_{j∈N(i)} (1 − ρ_epi(i,j)) · E[KL(b_i ‖ b_j)] / c_comm(i,j)。直觉：相关同伴的同意几乎零信息，独立同伴的分歧信息最大。

**定义 315（有效信息增益 VoI_eff）** VoI_eff(μ) = (H(M_i|o_i) − E[H(M_i|o_i, μ)]) · (1 − ρ_epi(i,j))；即去相关是信息增益的乘性折扣。若 VoI_eff ≤ c_comm，不通信，走 R69 单机兜底（与 R69 定义 298 同构）。

**定义 316（联合安全与合成风险 JSG）** 定义舰队联合安全包络 𝒮_J ⊂ ∏_i 𝒮_i 及联合状态转移。合成风险 R_syn = P(联合违反) − max_i P(单机违反)。JSG 要求 R_syn ≤ ε_syn，并强制死锁自由（无环等待）、资源互斥（不可重入资源）、几何分离（最小间距 ≥ d_min）。

**定义 317（舰队风险证书 J_FLEET）** J_FLEET = (J_FLUID^{(1..N)}, K_t 的可信上界, k_eff, R_syn, deadlock_free_cert, resource_conflict_cert, evaluation_independence_hash, witness_set_digest, fleet_ver)。Valid ⇔ ∀i Valid(J_FLUID^i) ∧ k_eff 估计可信 ∧ R_syn ≤ ε_syn ∧ 死锁自由 ∧ 资源互斥 ∧ 评测独立性满足。**关键：Valid(J_FLEET) 不能由 ∧_i Valid(J_FLUID^i) 推出**（反例见定理 20）。

**定义 318（评测独立性不变式 EIG）** 评测器 E 与受测舰队 ℛ 满足：(a) 场景/种子/留出成员对 ℛ 不可观测；(b) 判据不可被 ℛ 的动作直接优化（无在线反馈，或仅在回合末揭示）；(c) E 具备干预能力 do(perturb)。不满足则评测为「共谋可分」（collusion-separable），得分不可信。

**定义 319（真共识 vs 共谋的干预分离）** 观测到 i、j 一致时无法区分：(a) 独立真一致（ρ≈0，各有独立证据）；(b) 相关/串通一致（ρ→1 或共同误差）。做干预 do(perturb r_j 的内部证据)：若 r_i 的信念不相应更新 ⇒ r_i 未独立复核，只是复读；若 r_i 独立更新并能给出不同理由 ⇒ 独立。定义共谋分 collusion(i,j) = 1 − 归一化的 ∂b_i / ∂(do perturb b_j) 敏感度。**没有干预，两种世界在观测上不可分。**

**定义 320（留一 / 反事实舰队评测 FEV）** 对每个 r_i 做 do(remove r_i) 或 do(replace r_i ← 独立基线)，测舰队安全性变化 Δ_i。Δ_i ≈ 0 或为负 ⇒ r_i 是「冗余陷阱」（共谋放大器/搭便车）；Δ_i 明显为正损失 ⇒ r_i 是单点故障（SPOF）。输出 Δ 谱而非单一分数。

**定义 321（可证伪评测与失败见证）** 评测产物是见证集 W = {(s, do(·), expected, observed, mechanism)}，mechanism ∈ {correlation_trap, collusion, synthetic_risk, deadlock, witch, poisoning, evaluation_leak}。评测通过定义为「未产生可复现反驳见证的通过」，而非「分数超过阈值」；每个 witness 必须可独立复现（复现率 ≥ τ_rep）。

**定义 322（分布式退避）** 当 k_eff < k_min、CCFE 找不到独立同伴（G_t 断连或全相关）、或 K_t 估计不可信时，舰队禁止用「多数一致」提升置信；每台机器人退回 R69 单机保守 λ_floor(U_ale + U_epi)，协同降级为纯让行/保持间距的安全规则。⇒ R69 是 N=1、ρ=1 或 m_max=0 的边界。

**定义 323（舰队攻击面 ℰ_collude）** 共谋欺骗（多机联合演给评测）、通信投毒（伪造 μ_j）、女巫攻击（一个实体伪造多个独立 ID）、评测过拟合（已知场景协调、分布外解体）、评测器污染（与舰队共享数据/主干）。并入 AIC：ℰ_DECORUM = ℰ_FLUID^N × ℰ_collude。

**定义 324（通信预算与在线估计）** 单位时间消息 ≤ m_max、带宽 ≤ B、端到端延迟 ≤ τ_comm；K_t 必须在线可估且带误差上界 ε_K；若 k_eff 的置信下界 < k_min，按 k_eff < k_min 处理（**保守下界原则**：只信下界，不信点估计）。

**定义 325（参与式审计 VQAuditor-F）** 审计对象新增：同伴是否「求异」、证据是否被去相关折扣、k_eff 估计是否可被操纵、评测是否含反事实见证、是否出现共谋/女巫模式。结论回灌 AuditBuf，成为下一轮 CCFE 的成本与 k_min 先验。

**定义 326（单机严格包含）** 当 N=1，或 ρ̄=1（K=J），或 m_max=0（无通信）时，DECORUM 逐指令退化为 R69 FLUID-RAS。安全侧不让步；效率侧的协同收益只在 k_eff ≥ k_min 时释放。

## 2. 关键算法骨架

```python
# IP-264 EID：在线估计认识论相关矩阵与有效独立源数
class EpistemicIndependence:
    def estimate(self, residuals_window):
        R = corrcoef(residuals_window)                 # N x N，来自共享主干/传感器残差
        K = shrink_to_pd(clip(R, 0.0, 1.0), eps=1e-3)  # 收缩到正定、对角为 1
        Kinv = inv(K)
        k_eff = float(ones @ Kinv @ ones)              # = 1^T K^{-1} 1（等相关的 N/(1+(N-1)ρ)）
        k_lo  = bootstrap_quantile(k_eff, q=0.05)      # 保守下界（定义 324）
        return K, k_eff, k_lo

# IP-265 CDQ：相关感知证据合成（GLS 权重 + k_eff 门控）
def decorrelated_quorum(beliefs, K, k_min):
    Kinv  = inv(K + 1e-6 * eye(len(K)))
    k_eff = float(ones @ Kinv @ ones)
    if k_eff < k_min:                                  # 等效单源 → 禁止提升置信
        return single_source_fallback(beliefs), k_eff
    alpha = (Kinv @ ones) / k_eff                      # Σα_i = 1，相关者自动降权
    log_b = sum(a * log(b) for a, b in zip(alpha, beliefs))
    return normalize(exp(log_b)), k_eff

# IP-266 CCFE：求异——选期望分歧最大且独立的同伴
def choose_contrarian(i, beliefs, K, G, budget):
    best = None
    for j in neighbors(i, G):
        if not budget.allow(i, j): continue
        rho   = K[i, j]
        div   = expected_kl(beliefs[i], beliefs[j])    # 期望分歧
        score = (1.0 - rho) * div / comm_cost(i, j)    # 独立 × 分歧 / 成本
        if best is None or score > best.score: best = (j, score)
    return best[0] if best and best.score > 0 else None  # 无独立同伴 → 单机兜底

# IP-268 JSG：联合安全门（合成风险 / 死锁 / 资源冲突）
def joint_safety_gate(actions, envelopes, resources):
    if any(not in_envelope(a, envelopes[k]) for k, a in enumerate(actions)):
        return False, 'individual'
    if min_pairwise_distance(actions) < d_min: return False, 'synthetic_risk'
    if has_wait_cycle(resources):              return False, 'deadlock'
    if violates_mutex(resources):              return False, 'resource_conflict'
    return True, 'ok'

# IP-270 FEV：留一 + 干预的舰队评测（离线，不占实时预算）
def fleet_evaluation(policy_fleet, env, evaluator):
    W, base = [], evaluator.rollout(policy_fleet, env)
    for i in range(N):
        # 留一：替换为独立基线，测 Δ_i（SPOF vs 冗余陷阱）
        delta = evaluator.rollout(policy_fleet.replace(i, baseline), env) - base
        W.append(witness(i, 'leave_one_out', delta))
        # 干预：扰动 i 的证据通道，检查同伴 j 是否独立复核（定义 319）
        for j in neighbors(i):
            sens = evaluator.intervene(do=perturb_evidence(i), observe=belief[j])
            W.append(witness((i, j), 'collusion_probe', sens))
    return classify(W)   # SPOF / redundancy_trap / collusion / clean

# IP-274 主闭环（继承 R69，仅在舰队层插入去相关与联合安全）
def DECORUM_round(M, fleet_state, obs):
    beliefs = [r.fluid_round(o) for r, o in zip(fleet_state, obs)]   # R69 单机层
    K, k_eff, k_lo = M.eid.estimate(fleet_state.residuals)
    for i in range(N):
        if k_lo < k_min:                       # 独立性不可信 → 禁用协同增益
            beliefs[i] = single_source_fallback(beliefs[i]); continue
        j = M.ccfe.choose_contrarian(i, beliefs, K, M.G, M.budget)
        if j is not None and M.vib.voi_eff(beliefs, i, j, K) > comm_cost(i, j):
            beliefs[i] = M.cdq.update(beliefs[i], beliefs[j], K[i, j])  # 去相关折扣
    b_fleet, k_eff = M.cdq.decorrelated_quorum(beliefs, K, k_min)
    actions = [select_mode(b_fleet, ...) for _ in range(N)]
    ok, why = M.jsg.joint_safety_gate(actions, M.envelopes, M.resources)
    if not ok:                                 # 联合不安全 → 分布式退避
        return M.degrade_to_R69(beliefs, why)
    M.vqa_f.submit_async(K, k_eff, why='ok')
    return actions, b_fleet, (k_eff, k_lo)
```

## 3. 推导

**引理 19（相关证据的置信膨胀）** 设 N 个证据源等相相关 ρ、单源错误率 δ。朴素乘积/多数投票假设独立，名义后验要错误率随 N 指数下降；但真实可用独立信息只随 k_eff = N/(1+(N−1)ρ) 增长。故**过置信因子** = N/k_eff = 1+(N−1)ρ，随 N 线性膨胀而在 ρ>0 时饱和于 1/ρ。若存在共同模式误差概率 δ_c，多数投票错误率下界 ≥ δ_c，与 N 无关。系：**「再加一台同款机器人」不是降低风险，而是放大自信**；只有 k_eff 才是有效法定人数。

**引理 20（求异优于求同）** 给定队友 j 的信念 b_j 对模态 M 的条件互信息上界 I(M; b_j | b_i) ≤ (1−ρ_ij)·I_indep。当 ρ_ij → 1，b_j 在给定 b_i 后几乎确定，条件互信息 → 0；当 ρ_ij < 1 且 b_j 期望分歧大，信息接近 I_indep。故 CCFE 的目标 (1−ρ)·E[KL] 严格支配「选最可能同意者」：后者在相关同伴上得到近似零信息，前者在独立分歧同伴上得到最大信息。系：**舰队里最值钱的是「有理由的不同意」**。

**引理 21（无干预则共谋不可分）** 存在两个世界 W1（独立真共识）与 W2（共谋）在任何被动评测下产生**相同观测分布**（成员一致、回答一致、分数一致），但在分布外安全性不同。故任何不含干预的评测在这两个世界上必有正误判率（至少其一 ≥ 1/2）。若评测对每台机器人至少干预一次证据通道并观察同伴响应（do-calculus 的前门/后门），则 W1、W2 可分离。系：**FEV 至少需要 N 次干预才可能认证 N 台机器人的独立性**，少于 N 次存在不可辨识方向。

**定理 18（DECORUM 严格包含 R69，且多机层更强）** (a) 当 N=1、ρ̄=1 或 m_max=0 时 K 退化、k_eff=1、α=1、CCFE 无同伴、JSG 退化为单机包络，DECORUM 与 R69 逐指令相同。(b) 一般情形下，DECORUM 的单机风险 ≤ 各机 R69 风险（去相关池 + k_eff 门控）；且通过 JSG 强制 R_syn ≤ ε_syn、死锁自由、资源互斥——这些是 R69 根本没有定义的性质。故在多机层 DECORUM 是**严格更强的安全承诺**，而非「包含后更宽松」。

**定理 19（联合安全不蕴含）** 构造 N=2：窄道宽度 w < 2r + margin，两台机器人各自单独进入都在自身安全包络内（无障碍、制动距离足够），但同时进入必然相撞。于是 ∧_i Valid(J_FLUID^i) 成立而 R_syn > 0。故 J_FLEET 必须显式含联合项，不能由个体证书的合取推出。这是对「组合式安全」直觉的反例。

**引理 22（留一见证的信息量）** 从舰队配置到标量安全分数的映射 Φ 非单射。构造 F1（一个 SPOF，Δ 谱有一个大值）与 F2（全员冗余陷阱，Δ 谱全近似 0）使 Φ(F1)=Φ(F2)。标量无法区分二者，而 Δ 谱 W 可以；且 W 可复现、可证伪。故见证式评测严格细于标量评测，可区分风险结构数 ≥ 2^N 而非 O(1)。

## 3. 关键算法伪代码

```python
# IP-264 EID：在线估计相关矩阵与有效独立源数（保守下界）
def estimate_independence(residuals_window):
    K = shrink_to_pd(clip(corrcoef(residuals_window), 0, 1), eps=1e-3)
    k_eff = float(ones @ inv(K) @ ones)          # = 1^T K^{-1} 1
    return K, k_eff, bootstrap_quantile(k_eff, q=0.05)

# IP-265 CDQ：相关感知合成 + k_eff 门控
def decorrelated_quorum(beliefs, K, k_min):
    Kinv  = inv(K + 1e-6*eye(len(K)))
    k_eff = float(ones @ Kinv @ ones)
    if k_eff < k_min: return single_source_fallback(beliefs), k_eff
    alpha = (Kinv @ ones) / k_eff
    return normalize(exp(sum(a*log(b) for a,b in zip(alpha, beliefs)))), k_eff

# IP-266 CCFE：求异（最可能不同意且独立）
def choose_contrarian(i, beliefs, K, G, budget):
    cands = [j for j in neighbors(i, G) if budget.allow(i, j)]
    j = argmax(cands, key=lambda j: (1-K[i,j]) * expected_kl(beliefs[i], beliefs[j])
                                   / comm_cost(i, j))
    return j if cands and score(j) > 0 else None   # 无独立同伴 → 单机兜底

# IP-268 JSG：联合安全门
def joint_safety_gate(actions, envelopes, resources):
    if any(not in_envelope(a, envelopes[k]) for k,a in enumerate(actions)):
        return False, 'individual'
    if min_pairwise_distance(actions) < d_min: return False, 'synthetic_risk'
    if has_wait_cycle(resources):              return False, 'deadlock'
    if violates_mutex(resources):              return False, 'resource_conflict'
    return True, 'ok'

# IP-270 FEV：留一 + 干预（离线）
def fleet_evaluation(policy_fleet, env, evaluator):
    W, base = [], evaluator.rollout(policy_fleet, env)
    for i in range(N):
        W.append(witness(i, 'leave_one_out',
                         evaluator.rollout(policy_fleet.replace(i, baseline), env) - base))
        for j in neighbors(i):
            W.append(witness((i,j), 'collusion_probe',
                             evaluator.intervene(do=perturb_evidence(i), observe=belief[j])))
    return classify(W)          # SPOF / redundancy_trap / collusion / clean

# IP-274 主闭环（继承 R69）
def DECORUM_round(M, fleet_state, obs):
    beliefs = [r.fluid_round(o) for r,o in zip(fleet_state, obs)]   # R69 单机层
    K, k_eff, k_lo = M.eid.estimate_independence(fleet_state.residuals)
    for i in range(N):
        if k_lo < k_min: beliefs[i] = single_source_fallback(beliefs[i]); continue
        j = M.ccfe.choose_contrarian(i, beliefs, K, M.G, M.budget)
        if j is not None and M.vib.voi_eff(beliefs, i, j, K) > comm_cost(i, j):
            beliefs[i] = M.cdq.update(beliefs[i], beliefs[j], K[i, j])
    b_fleet, k_eff = M.cdq.decorrelated_quorum(beliefs, K, k_min)
    actions = [select_mode(b_fleet, ...) for _ in range(N)]
    ok, why = M.jsg.joint_safety_gate(actions, M.envelopes, M.resources)
    if not ok: return M.degrade_to_R69(beliefs, why)   # 分布式退避
    M.vqa_f.submit_async(K, k_eff, why='ok')
    return actions, b_fleet, (k_eff, k_lo)
```

## 4. 推导

**引理 19（相关证据的置信膨胀）** 等相相关 ρ、单源错误率 δ，朴素多数/乘积的过置信因子 = `N/k_eff = 1+(N−1)ρ`，随 N 线性膨胀、在 ρ>0 时饱和于 `1/ρ`；存在共同模式误差 δ_c 时错误率下界 ≥ δ_c 与 N 无关。**再加同款机器人不降风险，只放大自信。**

**引理 20（求异优于求同）** `I(M; b_j | b_i) ≤ (1−ρ_ij)·I_indep`；ρ→1 时条件互信息→0，独立且分歧的同伴信息最大。CCFE 目标 `(1−ρ)·E[KL]` 严格支配求同。

**引理 21（无干预则共谋不可分）** 存在独立真共识 W1 与共谋 W2 在任何被动评测下观测同分布、但 OOD 安全性不同；故无干预评测必有正误判率，至少 N 次独立干预才能认证 N 台独立性。

**定理 18（DECORUM 严格包含 R69，多机层更强）** N=1/ρ̄=1/m_max=0 时逐指令退化为 R69；一般情形单机风险 ≤ 各机 R69，且 JSG 额外保证 R_syn ≤ ε_syn、死锁自由、资源互斥——R69 未定义这些性质，故多机层是**严格更强的安全承诺**。

**定理 19（联合安全不蕴含）** 构造 N=2 窄道 `w<2r+margin`：各自单机安全、同时进入必撞 ⇒ `∧ J_FLUID` 成立而 `R_syn>0`。J_FLEET 必须显式含联合项。

**引理 22（留一见证的信息量）** 舰队配置→标量分数的映射非单射：存在得分相同但风险结构不同（SPOF vs 全员冗余陷阱）的两支舰队；Δ 谱/见证集可区分，标量不可。见证评测严格细于标量评测。

## 7. 本轮最大风险

**一句话**：DECORUM 的全部收益押在「认识论相关性可被在线、可信地估计」上——**若 ρ 被低估（相关源误判为独立），k_eff 虚高，系统会自信地相信一个回音室；若 ρ 被高估，系统过度保守、退回单机、丧失协同收益。更糟的是，共谋舰队可刻意制造表面分歧（演双簧）伪造独立性，骗过 k_eff 门控与求异选择；若评测器与舰队共享数据/主干/场景，「评测通过」只是把单机「诚实的不知道」升级成舰队「被认证的错误」**——多机的危险不是没人知道，而是所有人都一样地错，并且互相作证。

**次级风险与缓解**：ρ 估计不可信 → 保守下界原则 k_lo + 定义 324；共谋/双簧 → 干预式共谋分 + FEV（定义 319–320、定理 19）；女巫/投毒 → provenance 认证 + ℰ_collude 对抗训练 + E311；评测过拟合 → EIG 场景/种子/留出隔离 + 见证式评测（定义 318、321）；联合安全 → JSG + J_FLEET + 定理 19；通信预算击穿 → VIB 硬预算 + 退化单机 + E312。
