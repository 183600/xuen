# 第 1 轮（新灵感循环第 1 轮；本轮灵感：「末端位姿」×「抓取规划」）

> **基线**：第 14 轮 MetricVoiceGauge-NCD-HUTDH-v16（定义 627–656；引理 131–136；实验 E671–E690）。
> **本轮纪律**：**位姿为尺、抓取为证、退化链为安全网**。不推倒 v16：v8 的 DA/SPR/Cal、v9 的 AC/MW/ID、v10 的 NGE/DSL/CC/CWM/CAE/NCP、v11 的 HAS/HCC/HATD/HDT、v12 的 USG/TGC/BAA/GAGP/UC、v13 的 AIO/RTIC/CPD/DGC/DDL/RTCR、v14 的 SCD/DSD/DCA/EDC、v15 的 SCD/DSD/DCA/EDC/守卫、v16 的 BTS/TRM/WBC/CSC/NCS/MCA/WCB 与全部不变式保留。三个新组件——EPC（末端位姿证书）、GCA（抓取证书代数）、GDR（位姿—抓取退化路由器）——一律以**中立元**接入，失效即严格退回 v16（引理 143），再沿 v16→v15→v14→v13→v12→v11→v10→v9→v8→v7→v6 退化链退回。本轮只做三件事：把"末端位姿"改写为**任务相关的共形位姿管**、把"抓取规划"改写为**鲁棒力闭合证书的约束优化**、把"抓取执行"改写为**位姿—抓取耦合的单调退化阶梯**。

## 0. 直觉与动机

**灵感 1（末端位姿 → 任务相关的共形位姿管）**
直觉：末端位姿不是 6 个能各自打盒子的标量。姿态属于 $SO(3)$，两个只差 $1^\circ$ 的旋转在欧拉角/四元数坐标里可能数值差异很大；更关键的是，抓取只关心少数任务方向——**接近方向、闭合轴、绕接近轴的转角**——对与任务无关的方向苛求 $0.1\text{mm}$，只会把证书交集清空。所以需要的不是"位姿误差 $<\varepsilon$"，而是"**落在任务投影下、覆盖概率 $\ge 1-\alpha$ 的 $SE(3)$ 管**"。核心创新：**末端位姿证书（End-effector Pose Certificate, EPC）**。用共形预测把管半径从拍脑袋公差变成**有覆盖保证的分位数**：以位姿残差的加权范数为非一致性分数，取校准分位数 $q_{1-\alpha}$，证书即 $SE(3)$ 中以估计位姿为中心、半径 $q_{1-\alpha}$ 的管。再引入**任务投影证书**：抓取只用投影 $\Pi_\tau$ 的少数方向，投影非扩张，故任务管包含全管——既更紧又仍可证。关键反直觉点：**位姿证书不是"感知精度"，而是"任务还需要多少精度"**；同一台相机，对"把杯子推一下"和"把钥匙插进锁孔"给出的证书完全不同。

**灵感 2（抓取规划 → 鲁棒力闭合的抓取证书）**
直觉：抓取不是"手合上"，而是一个可证承诺：只要物体位姿在感知证书内、外力旋量在这个包络里，所有接触力就都留在摩擦锥内且能抵抗任意方向的扰动。经典力闭合判据是一个几何量——**原点是否落在接触旋量凸包内部、离边界多远**。把这个"离边界多远"当作证书裕度 $\eta$，物体位姿的不确定性就通过一个 Lipschitz 常数直接吃掉裕度：$\underline{\eta}\ge\eta_{nom}-L_\eta\rho_o$。位姿管越粗，抓取证书越薄；当 $\eta_{nom}<L_\eta\rho_o$ 时，这个抓取在当前感知下**根本不可证**。核心创新：**抓取证书代数（Grasp Certificate Algebra, GCA）**。每个抓取携带 $GC=(\eta_{nom},L_\eta,\rho_o^{max},\text{接触模式},\text{回退级})$，其中 $\rho_o^{max}=(\eta_{nom}-\eta_{\min})/L_\eta$ 是该抓取能容忍的最大物体位姿不确定半径。多指/双臂抓取经旋量空间 Minkowski 和合成，取最保守的 $\min$ 裕度。关键反直觉点：**"力闭合"不是布尔值，而是带位姿半径的单调函数**；同一个抓取在精细感知下力闭合、在粗感知下不闭合。

**灵感 3（末端位姿 × 抓取规划 → 位姿—抓取耦合的单调退化阶梯）**
直觉：位姿或抓取哪一维变差，就沿抓取阶梯单调下退：$L_0$ 精细捏取（2–3 指尖、全自由度）→ $L_1$ 包络/力量抓取 → $L_2$ 欠驱动柔顺抓取 → $L_3$ 非抓取推拨/翻转 → $L_4$ 持稳/安全释放。越往下，**适用状态集越大、可完成任务集越小**：$\mathcal S_0\subseteq\cdots\subseteq\mathcal S_M$，$\mathcal T_0\supseteq\cdots\supseteq\mathcal T_M$。核心创新：**位姿—抓取退化路由器（Pose–Grasp Degradation Router, GDR）**，把 v16 的三重预算 $(B_{\text{tick}},m^*,h^*)$ 扩成四重 $(B_{\text{tick}},m^*,h^*,c)$，其中 $c=M-\ell$ 是**抓取能力索引**，退化时只减不增。四维均为单调退格：tick 预算只减、里程碑只退前驱、WBC 阶层只降、抓取能力只降。关键反直觉点：**抓取退化不是"换一个抓取"而是"换一个可证层级"**；能力是可以缓慢恢复的，但必须在显式"重认证纪元"（重校准/里程碑推进）处恢复，绝不允许在单个执行回合内偷偷回升。

**三者如何统一**
统一为 **v16 全身行为层之下的灵巧操作层**：v16 回答"在当前里程碑、当前 WBC 阶层下能安全执行哪条全身行为"（$\mathrm{Exec}_{v16}$）；v17 回答"这条行为里的抓取动作，在末端位姿管与物体位姿管下是否仍有力闭合证书；若没有，单调退到哪一级抓取"（$\mathrm{Exec}_{v17}$）。EPC 把末端位姿变成任务管，GCA 把抓取变成鲁棒力闭合证书，GDR 把"位姿—抓取"联合状态变成单调退格。共享状态 $\zeta_{pg}=(B_{\text{tick}},m^*,h^*,c,\mathcal P_\alpha,\mathcal O,GC,\text{drift}_{pg})$。**EPC 回答"手在哪里、允许多大偏差"，GCA 回答"这个抓取在多粗的位姿下仍闭合"，GDR 回答"这一帧该退到哪一级抓取"**。三者以 `Exec_v17 ⊆ Exec_v16 ⊆ Exec_v15 ⊆ Exec_v13 ⊆ Exec_v12` 串成"感知—接触—行为—路线—实时"的完整退化链。

## 2. 设计原则（在 P25–P27 基础上新增 P28–P30）

**P28 位姿证书即任务管律（Pose Certificate as Task Tube）**
EPC 必须同时满足：(1) **覆盖**：$\mathbb P(T\in\mathcal P_\alpha(x))\ge 1-\alpha$；(2) **任务投影保序**：$\Pi_\tau$ 非扩张，$\mathcal P_\alpha(x)\subseteq\Pi_\tau^{-1}(\mathcal P_\alpha^\tau(x))$；(3) **传播**：沿运动链 $\rho_{EE}\le\sum_i L_{F,i}\rho_i+O(\rho^2)$，关节空间管经 $\rho_{EE}\le\bar\sigma(J(q))r_q+\tfrac12 L_J r_q^2$ 传播；(4) **中立退化**：EPC 失效时注入固定保守盒 $\mathcal P_\alpha^\perp\cap\mathcal P_\alpha$，只收紧、不放宽。

**P29 抓取证书即鲁棒力闭合律（Grasp Certificate as Robust Force Closure）**
$\forall g$，$GC(g,\mathcal O)=(\eta_{nom},L_\eta,\rho_o^{max})$ 必须满足鲁棒裕度 $\underline{\eta}(g,\mathcal O)=\inf_{T_o\in\mathcal O}\eta(g;T_o)\ge\eta_{\min}$，且**耦合不等式** $\underline{\eta}\ge\eta_{nom}-L_\eta\rho_o$ 成立。$L_\eta$ 必须是**可计算上界**（解析界与数值上界取大），而非拟合斜率；证书只在 $\underline\eta\ge\eta_{\min}$ 且 $L_\eta$ 已登记时有效。抓取合成（多指/双臂）只能取旋量空间的保守交/最小裕度，不得新增授权。

**P30 抓取退化链单嵌套律（Grasp Ladder Monotone Nesting）**
阶梯 $L_0,\dots,L_M$ 必须满足适用集 $\mathcal S_0\subseteq\cdots\subseteq\mathcal S_M$ 与任务能力 $\mathcal T_0\supseteq\cdots\supseteq\mathcal T_M$。退化只允许 $\ell\uparrow$（能力索引 $c=M-\ell$ 只减不增）；层级切换必须经过桥梁 $\mathcal B_{\ell\to\ell+1}=\mathcal S_\ell$ 且桥梁非空；能力恢复只允许在显式**重认证纪元**（重校准完成、里程碑推进）发生，禁止回合内回升。

## 3. 与基线的接口（如何退化）

- EPC 失效 ⇒ 固定保守位姿盒中立元，Action NC 退化为 v16 的位姿约束，**等价 v16 抓取路径**；
- GCA 失效 ⇒ 标量力闭合判据（0/1，无位姿半径），退化为经典力闭合检查，**等价 v16（+EPC）路径**；
- GDR 失效 ⇒ 固定最高可用抓取级、无能力索引调度，**等价 v16（+EPC+GCA）路径**；
- 三者全失效 ⇒ MetricVoiceGauge-NCD-HUTDH-v16，再沿退化链退回 v15/v14/v13/v12/v11/v10/v9/v8/v7/v6；
- **安全继承**：EPC 只收紧位姿集，GCA 只收紧抓取集并取最小裕度，GDR 只降低能力索引。三端口互不相交，均不能新增授权或放宽阈值；`Exec_v17 ⊆ Exec_v16` 由引理 143 保证。

## 4. 预期贡献

1. **$SE(3)$ 任务位姿证书**：给出带有限样本覆盖保证、任务投影保序、可沿运动链传播的共形位姿管，解决"姿态误差在 $SO(3)$ 上不可直接打盒子"的问题；
2. **鲁棒力闭合抓取证书**：把经典力闭合裕度升级为"带物体位姿容忍半径"的证书，给出位姿—抓取耦合不等式与可计算的 Lipschitz 上界，填补"抓取质量与感知不确定度脱节"的空白；

4. **位姿—抓取单调退化阶梯**：把精细捏取到安全释放组织成嵌套适用集/反嵌套任务能力的可证阶梯，避免"证书过保守导致操作瘫痪"；
5. **四重单调退化调度**：把 tick 预算、里程碑、WBC 阶层、抓取能力索引统一为同一个单调退格对象，延续"感知—接触—行为—路线—实时"五层分离，用 `Exec_v17 ⊆ Exec_v16 ⊆ Exec_v15 ⊆ Exec_v13 ⊆ Exec_v12` 保持安全继承；E691–E712 覆盖位姿覆盖、抓取鲁棒性、耦合紧致性、阶梯活性、漂移塌缩与端到端。

## 5. 本轮最大风险

**一句话**：整套鲁棒抓取证书依赖"力闭合裕度 $\eta$ 关于物体位姿是 $L_\eta$-Lipschitz 且 $L_\eta$ 可被安全上界"，但**接触丢失/摩擦锥边界处 $\eta$ 不可微、其局部 Lipschitz 常数可能趋于无穷**——于是在抓取"即将打滑"的瞬间，$L_\eta$ 恰被低估，耦合不等式给出乐观的鲁棒裕度，系统执行了一个**位姿证书有效、力闭合证书通过、退化链单调的、却在物理上正在打滑的抓取**。

        self.alpha = alpha
        self.q_hat = None                  # 共形分位数
        self.q_tau = None                  # 任务级分位数

    def score(self, T, T_hat):
        e = pose_error(T, T_hat)           # (log(R_hat^T R)^v, R_hat^T (p - p_hat))
        return float(np.sqrt(e.T @ self.M @ e))

    def fit(self, calib_poses, calib_hats):
        scores = [self.score(T, Th) for T, Th in zip(calib_poses, calib_hats)]
        n = len(scores)
        k = int(np.ceil((n + 1) * (1 - self.alpha)))
        self.q_hat = sorted(scores)[min(k, n) - 1]

    def certificate(self, T_hat):
        # {T : ||e(T,T_hat)||_M <= q_hat} = SE(3) 管
        return PoseTube(center=T_hat, radius=self.q_hat, metric=self.M)

    def task_certificate(self, T_hat):
        # 覆盖保持：Pi 非扩张，故全管 ⊆ 投影管
        return TaskPoseTube(base=self.certificate(T_hat), Pi=self.Pi,
                            radius_tau=self.q_tau)

    def propagate_chain(self, joint_radius, jacobian_fn, jac_lip, q):
        # 关节管 r_q -> 末端位姿管 rho_EE（一阶 + 二阶）
        J = jacobian_fn(q)
        sigma = np.linalg.svd(J, compute_uv=False)[0]
        rho = sigma * joint_radius + 0.5 * jac_lip * joint_radius ** 2
        return PoseTube(center=forward_kinematics(q), radius=rho, metric=self.M)

    def conservative_box(self):
        # 中立元：固定保守盒，且与原证书求交（只收紧）
        box = PoseTube.from_bounds(pos_eps=self.eps_p, rot_eps=self.eps_R)
        return box.intersect(self.certificate(T_hat))


# IP-418 Grasp Certificate Algebra：鲁棒力闭合证书
class GraspCertificateAlgebra:
    def __init__(self, eta_min, contact_delta, safety_factor=1.2):
        self.eta_min = eta_min
        self.delta = contact_delta
        self.k_L = safety_factor

    def wrench_margin(self, grasp, object_pose):
        contacts = transform_contacts(grasp.contacts, object_pose)
        G = [grasp_matrix(c, n) for c, n in contacts]
        prim = []
        for i, (c, n) in enumerate(contacts):
            for f in friction_cone_vertices(n, grasp.mu[i]):
                prim.append(G[i] @ f)
        hull = convex_hull(prim)
        return inscribed_ball_radius_at_origin(hull)   # 归一化旋量裕度

    def tight_lipschitz(self, grasp, obj_pose_nom):
        # 解析上界与数值上界取大（IP-422 WME）
        analytic = self._analytic_bound(grasp, obj_pose_nom)
        numeric = self._numeric_sup(grasp, obj_pose_nom, n_dirs=12)
        return max(analytic, numeric) * self.k_L

    def certificate(self, grasp, pose_cert, obj_pose_nom):
        eta_nom = self.wrench_margin(grasp, obj_pose_nom)
        L_eta = self.tight_lipschitz(grasp, obj_pose_nom)
        rho_o = pose_cert.radius_around(obj_pose_nom)
        eta_rob = eta_nom - L_eta * rho_o          # 耦合不等式（引理 139）
        rho_max = (eta_nom - self.eta_min) / max(L_eta, 1e-9)
        return GraspCertificate(eta_nom=eta_nom, L_eta=L_eta, eta_rob=eta_rob,
                                rho_o_max=rho_max,
                                valid=(eta_rob >= self.eta_min))

    def compose(self, gc_list):
        # 多指/双臂：旋量空间 Minkowski 和 -> 保守取最小鲁棒裕度
        eta = min(gc.eta_rob for gc in gc_list)
        L = max(gc.L_eta for gc in gc_list)
        return GraspCertificate.compose(gc_list, eta_rob=eta, L_eta=L,
                                        valid=all(gc.valid for gc in gc_list))


# IP-417 Certificate-Aware Grasp Planner：证书约束下的抓取选择
class CertificateAwareGraspPlanner:
    def __init__(self, gca, epc, candidate_gen, eta_min):
        self.gca, self.epc = gca, epc
        self.gen = candidate_gen
        self.eta_min = eta_min

    def plan(self, x, obj_pose_cert, task):
        # 1. 召回感知候选生成：覆盖 approach / closure / 接触模式 / 歧义分支
        candidates = self.gen.generate(x, obj_pose_cert, task)
        best, best_val = None, -np.inf
        for g in candidates:
            # 2. 位姿证书先筛：手可达、接近路径位姿管有效
            if not self.epc.approach_certificate_valid(g, x):
                continue
            # 3. 抓取证书：鲁棒力闭合（耦合不等式）
            gc = self.gca.certificate(g, obj_pose_cert, obj_pose_cert.center)
            if not gc.valid:
                continue
            # 4. 证书约束下的任务价值最大化
            val = self.value(g, task) - self.risk_penalty(gc, obj_pose_cert)
            if val > best_val:
                best, best_val = (g, gc), val
        if best is None:
            return None, 'INFEASIBLE'          # 触发 GDR 降级
        return best, 'CERTIFIED'

    def risk_penalty(self, gc, obj_cert):
        # 裕度越薄、位姿管越粗，罚项越大（抑制"擦边"抓取）
        slack = gc.eta_rob - self.eta_min
        return self.lam / max(slack, 1e-6) + self.mu * obj_cert.radius


# IP-420 Pose-Grasp Degradation Router：位姿—抓取单调退化
class PoseGraspDegradationRouter:
    def __init__(self, levels, csc_v16):
        self.levels = levels                   # [L0..LM]，适用集嵌套已校验
        self.csc = csc_v16
        self.current = 0

    def route(self, x, pose_cert, obj_cert, budget, m_star, h_star, drift,
              recert_epoch=False):
        c_prev = len(self.levels) - 1 - self.current
        if drift:
            c_target = 0                       # 最强退化：持稳/安全释放
        elif recert_epoch:
            c_target = self._best_certifiable(x, pose_cert, obj_cert)
        else:
            c_target = min(c_prev,
                           self._best_certifiable(x, pose_cert, obj_cert))
        self.current = len(self.levels) - 1 - c_target
        return self.levels[self.current]

    def _best_certifiable(self, x, pose_cert, obj_cert):
        for ell in range(0, len(self.levels)):
            if (x in self.levels[ell].applicable_set
                    and self.levels[ell].certifiable(pose_cert, obj_cert)):
                return len(self.levels) - 1 - ell   # 最高能力索引
        return 0


# IP-425 Regrasp Bridge：切换证书桥梁
class RegraspBridge:
    def verify(self, gc_from, gc_to, x):
        # 桥梁非空：两级的可证状态集在 x 处有交，且接触模式可连续切换
        overlap = gc_from.contact_mode.intersect(gc_to.contact_mode)
        return (x in overlap
                and gc_from.eta_rob >= self.eta_min
                and gc_to.eta_rob >= self.eta_min)

## 2. 关键推导

**引理 137（位姿证书的覆盖保持与中立退化）**
设 EPC 用可交换校准样本构造共形分位数 $q_{1-\alpha}$，则对新的可交换样本 $\mathbb P(T\in\mathcal P_\alpha)\ge1-\alpha$；若任务投影 $\Pi_\tau$ 非扩张，则 $\mathcal P_\alpha\subseteq\Pi_\tau^{-1}(\Pi_\tau\mathcal P_\alpha)$，即任务证书不漏掉全证书内的任何位姿。EPC 失效时注入 $\mathcal P_\alpha^\perp\cap\mathcal P_\alpha$，则 v17 的位姿可用集只收缩不扩张。
证明：第一句是 split-conformal 的标准覆盖结论；第二句由非扩张映射的原像包含关系直接得到；第三句由交集构造 $\mathcal P_\alpha^\perp\cap\mathcal P_\alpha\subseteq\mathcal P_\alpha$ 得到。∎

**引理 138（位姿证书的链式传播界）**
沿运动链 $F=T_1T_2\cdots T_n$，若每段相对位姿误差为 $\xi_i$ 且复合映射的 Lipschitz 常数为 $L_{F,i}$，则 $\|e_{EE}\|\le\sum_i L_{F,i}\|\xi_i\|+O(\|\xi\|^2)$。特别地，关节空间管半径 $r_q$ 经几何雅可比传播满足
$$\rho_{EE}\le\bar\sigma(J(q))\,r_q+\tfrac12 L_J r_q^2 .$$
证明：$SE(3)$ 指数映射在单位元邻域的局部 Lipschitz 性（BCH 展开）给出一阶项；一阶项正是雅可比作用，二阶项由雅可比沿关节路径的 Lipschitz 常数 $L_J$ 控制。∎

**引理 139（位姿—抓取证书耦合不等式）**
若抓取质量裕度 $\eta(g;T_o)$ 关于物体位姿是 $L_\eta$-Lipschitz，即 $|\eta(T_o)-\eta(T_o')|\le L_\eta d(T_o,T_o')$，且物体位姿证书 $\mathcal O$ 是中心 $T_o^{nom}$、半径 $\rho_o$ 的球，则
$$\underline{\eta}(g,\mathcal O)=\inf_{T_o\in\mathcal O}\eta(g;T_o)\;\ge\;\eta_{nom}-L_\eta\rho_o,\qquad \eta_{nom}=\eta(g;T_o^{nom}).$$
因此该抓取可容忍的最大物体位姿不确定半径为 $\rho_o^{max}=(\eta_{nom}-\eta_{\min})/L_\eta$；当 $\rho_o>\rho_o^{max}$ 时证书失效。
证明：对任意 $T_o\in\mathcal O$ 有 $d(T_o,T_o^{nom})\le\rho_o$，由 Lipschitz 性 $|\eta(T_o)-\eta_{nom}|\le L_\eta\rho_o$，对 $T_o$ 取下确界即得。∎

**引理 140（抓取裕度对接触扰动的 Lipschitz 性）**
设接触点扰动 $\|\delta c_i\|\le\delta$、法线扰动 $\|\delta n_i\|\le\delta$、摩擦系数扰动 $|\delta\mu_i|\le\delta$。则归一化旋量凸包与原凸包的 Hausdorff 距离满足 $d_H\le C_G\delta$，从而内切球半径扰动 $|\delta\eta|\le C_\eta\delta$，其中 $C_G,C_\eta$ 仅依赖接触数 $m$、物体尺度与摩擦系数上界。
证明：抓取矩阵 $G_i$ 对 $c_i$ 仿射且有界；摩擦锥顶点对 $(n_i,\mu_i)$ Lipschitz；Minkowski 和、凸包对 Hausdorff 距离均为 Lipschitz 运算；原点到凸包边界的内切球半径是凸包集合的 1-Lipschitz 函数。∎

**引理 141（抓取退化链的嵌套活性）**
若阶梯满足 $\mathcal S_0\subseteq\cdots\subseteq\mathcal S_M$，$\mathcal S_M$ 包含所有安全停机状态，且退化只降不升，则：(1) 不存在死锁——每步要么找到可证级，要么到达 $L_M$；(2) 最坏退化步数 $\le M$；(3) 若 $L_M$ 的证书由 v16 的 Fallback 兜底，则全失效仍安全。
证明：嵌套性保证随 $\ell$ 增大适用集单调扩大，故必存在最小 $\ell$ 使状态属于 $\mathcal S_\ell$（至少 $\mathcal S_M$ 含安全停机态）；只降不升使序列严格有下界，故有限步终止；$L_M$ 由 v16 Fallback 保证安全。∎

**引理 142（四重单调退化的帕累托最优性）**
设价值 $V(B,m,h,c)$ 关于 $B,m,h,c$ 单调不减，退化只允许 $B\downarrow,m\downarrow,h\downarrow,c\downarrow$。则 v16 的贪心回溯在四维积格上仍返回帕累托最优解：不存在另一可行解在四维上均不劣且至少一维严格更优。
证明：与引理 134 同构。四维积格按字典序 $(m,h,c)$ 自顶向下枚举，$V$ 单增保证任一子域的最优解即该子域帕累托前沿上的一点；归纳覆盖全部不可比点。∎

**引理 143（严格退化为 v16 的安全继承）**
若 EPC/GCA/GDR 均取中立元（EPC→固定保守盒、GCA→标量力闭合判据、GDR→固定最高可用级且不加能力约束），则 v17 在抓取动作上的可用集等于 v16 的可用集；对任意组合失效均有 $\mathrm{Exec}_{v17}\subseteq\mathrm{Exec}_{v16}$，且 v16 的引理 131–136 全部继续成立。
证明：三个端口只做集合交、收紧与单调降级，均不新增授权；取中立元时分别退化为 v16 的位姿约束、经典力闭合判据与无阶梯调度，故可用集相等。∎

## 6. 已知风险与失效模式

1. **共形覆盖依赖可交换性**：物体位姿分布随场景漂移时，校准集与新样本不再可交换，名义 $1-\alpha$ 覆盖失效。缓解：加权共形、在线自适应 $\alpha$、按物体类别分层校准、漂移检测联动。

2. **姿态度量的非唯一性**：不同任务对旋转/平移敏感度不同，单一 $M$ 可能在某些方向过紧、某些方向过松。缓解：任务投影 + 多度量集合、按抓取类型切换度量、可操纵性加权。

3. **$L_\eta$ 可计算上界过松**：解析界偏保守、数值上界受采样限制，二者取大会导致几乎所有抓取被判不可证、系统退化到 $L_4$。缓解：分段 Lipschitz、局部线性化证书、按接触模式分治、保守度监控与自适应收紧。

4. **力闭合裕度的非光滑性**：接触丢失、摩擦锥边界、凸包顶点切换处 $\eta$ 不可微，局部 Lipschitz 常数可能无界。缓解：接触模式枚举、边界邻域单独用保守证书、拒绝"擦边"抓取、加 SCG 打滑前兆。

5. **候选生成漏解**：召回不足会把"其实可抓"误判为不可行，触发不必要的退化。缓解：多假设姿态、approach/closure 网格、采样式候选、失败回灌重规划。

6. **接触/摩擦模型误差**：软指接触、摩擦系数时变、法向单边性近似都会使 $\eta$ 乐观。缓解：摩擦系数区间证书、软接触模型、触觉在线校准、强制安全系数。

7. **物体质心/惯性不确定**：位姿证书不覆盖质心与惯性参数，外力旋量包络可能低估。缓解：把质心不确定并入旋量包络、单独质心证书、动态操作降级。

8. **阶梯适用集在真实硬件上非嵌套**：不同抓取级可能需要互斥的手部构型，导致 $\mathcal S_\ell$ 出现空洞。缓解：GLR 定期审计、空洞处引入过渡级、切换桥接窗口。

9. **Regrasp 接触一致性**：切换瞬间可能同时失去旧接触、未建立新接触。缓解：双接触窗口、RGB 桥梁验证、切换期降速、SCG 监控。

10. **四重退化的累积保守性**：位姿管 ∩ 抓取证书 ∩ WBC 证书 ∩ 里程碑证书逐层求交，下界可能衰减到近零。缓解：证书价值加权、选择性放宽（需形式化证明）、元认证监控、动态 $\alpha$。

11. **持稳/搬运阶段的迟滞打滑**：静态力闭合证书不覆盖动态加速度与振动引起的惯性力。缓解：动态旋量包络、加速度前馈、SCG 振动谱监测、降速搬运。

12. **重认证纪元的能力回升风险**：允许在重校准后恢复能力索引，可能引入"证书刚更新、物理未验证"的缝隙。缓解：回升需通过金丝雀验证、仿真回归、双签名证书、回升限幅。

## 7. 本轮最大风险

**一句话**：整套鲁棒抓取证书把安全性押在"$\eta$ 关于物体位姿的 Lipschitz 常数 $L_\eta$ 可被安全上界"上，但 $\eta$ 在接触丢失与摩擦锥边界处不可微、局部 Lipschitz 常数可能无界，于是**在抓取即将打滑的瞬间 $L_\eta$ 恰被低估，耦合不等式报出乐观裕度，系统执行了一个位姿证书有效、力闭合证书通过、四重退化链单调、却在物理上正在打滑的抓取**。
