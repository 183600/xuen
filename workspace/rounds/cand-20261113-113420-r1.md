# 第 66 轮（承接第 65 轮「VISTA 故障可归因安全时序闭环」IP-214~223；灵感循环第 3 轮；本轮灵感：「物体泛化」×「用户测试」）

> 第 65 轮把「几何可证伪」升级为「故障可归因」，其自述最大风险是全链条的隐藏假设（A88）：**故障必须落在有限假设集内，且视觉与几何的失效相互独立**；未知复合故障会被强行归入最近假设、只膨胀错误的球，而系统因「已经归因」更自信地继续执行。本轮不继续扩充故障类别，而追问一个更根本的问题：**这些保证到底是对「谁」成立的？** VISTA 的全部标定——conformal 覆盖、故障似然 p(ρ|H)、刚度/摩擦先验、块签名分布——都默认部署物体来自标定分布、且验收者与训练者同质。一旦换物体或换用户，保证不是缓慢变差，而是**静默失效**；而最早发现「保证已不成立」的，往往不是机器人自己，而是真实用户。本轮核心命题是：
>
> **把「归因正确」升级为「泛化有效且被人共同验证」：以「物体」而非「帧」为标定与保证的单位，用新物体检测触发证书降级与有界主动辨识；把用户测试从最后验收变成未知故障的采样器与证书的独立审计员，同时把人显式建模成有延迟、会漏报、会过度信任的通道。**

## 0. 直觉与动机

**灵感 1（物体泛化 → 保证的单位错了）**
直觉：VISTA 说「残差在 95% 分位内、故障后验收敛」，但这些数字是在一组训练物体上数出来的。交换性是 conformal 的氧气：它要求标定样本与测试样本同分布且可交换。同一物体的连续帧高度相关，而新物体的刚度、摩擦、质量、几何、外观系统性不同——**帧级 95% 覆盖在换物体时不是缓慢退化，而是整段整段失效**（一个物体判错，它的所有帧一起错）。所以泛化的「一单」应是一个物体而不是一帧：**为新物体买保险，保单单位必须是物体。** 这直接改写第 65 轮 CSC/FIR 的标定口径：覆盖、故障似然、块签名都应在物体子群上分层，而不是在全体帧上摊平。

**灵感 2（用户测试 → 未知故障的采样器 + 证书的审计员）**
直觉：用户测试通常被当成主观验收，但在这里有两个不可替代的作用。(i) **采样未知故障**：VISTA 的假设集有限，只有人会说出「这不对劲、这不是它该有的软硬」；用户的失败报告正是 H_unknown 的采样过程，直接补 A88 的洞。(ii) **审计证书**：证书是一条可证伪断言（「该物体子群覆盖 ≥1−α、Valid(J)=真」），用户观察到的实际结果是独立观测，二者不符即证书违背。但人不是真值：人有反应延迟、会漏报危险、会被「系统说安全」带偏。因此必须把人建模成带混淆矩阵与延迟的**通道**，并测量「人的信任是否与证书匹配」，而不是假定「用户认可 = 安全」。

**灵感 3（合流 → 泛化—用户闭环）**
直觉：把两者接成环。新物体 → 检测到泛化间隙 → 证书降级 + 有界主动辨识（复用 AFA，但探针目标从「分故障」改为「估物体属性、降泛化不确定度」）→ 仍不确定则升级给人 → 人的决定与观察回流为新的故障假设与标定数据，同时审计证书是否说对。**用户测试不是评估阶段，它是泛化证书在开放世界里的接地方式。**

**灵感 4（GUEST：Generalization-Under-Shift & User-in-the-loop Safety Transfer，分布偏移下的泛化与用户在环安全迁移）**
闭环：物体级 conformal 证书（OGC）→ 新物体检测（NOD）→ 属性主动辨识（OAI）→ 子群条件规划（OGS）→ 人类升级通道（HEC，含价值信息决策）→ 信任标定（TCU）→ 未知故障发现（UHT）→ 证书—观测一致性审计（CAG）→ 回写标定与故障库。相对 VISTA，新增的不是第 5 个模态，而是**保证的作用域（scope）与验证者（verifier）**：VISTA 问「谁坏了」，GUEST 问「**这个保证对哪些物体、哪些用户还成立，谁有权说它不成立**」。

**灵感 5（VISTA 组件原位升级）**
- **OGC ← CSC/FIR**：conformal 标定单元从帧改为物体；故障似然按物体子群分层。
- **NOD ← RSC-V**：不确定球增 r_obj（物体分布偏移），由元特征 OOD 触发；只膨胀被触发的那一类。
- **OAI ← AFA**：探针目标从「故障假设互信息」改为「物体属性后验 / 泛化不确定度」，力与形变预算不变。
- **HEC ← SSB/DIR**：安全边界增「人类接管」分支，含反应延迟 τ_h 与漏报率；升级不是免费的。
- **TCU ← J_vista**：证书字段需对人可读、可校准；过度信任作为一等风险而非界面问题。
- **UHT ← FIR**：故障库由有限集升级为开放世界，未知质量 λ_unk 显式进入证书。
- **CAG ← AIC-V**：认证干扰集增「物体长尾 + 用户误用/过度信任」，并审计证书与观测的一致性。
- **J_vista → J_guest**：增 object_calib_ver、coverage_CI、novelty_p、human_escalation、trust_calib、unknown_mass、cag_ver。

## 1. 形式化定义（增量：定义 233–247）

- **定义 233（GUEST 闭环）**：GUEST = (VISTA, OGC, NOD, OAI, OGS, HEC, TCU, UHT, CAG, J_guest)。定位：VISTA 的「作用域可信 + 人机共验」升级。不变式：**物体级标定、泛化审计、信任分析、故障库扩充只在离线/语义流；实时流只读缓存的证书等级与升级标志，做安全前缀执行与早停，零学习写操作。**
- **定义 234（物体级标定单元与可交换性）**：标定集由物体 o_1,…,o_n ~ P_O 组成，而非独立帧。对每个物体把逐帧非一致性分数聚成物体分数 S_o（取块内最大值或 (1−α) 分位）。split-conformal 取 q 为 {S_o} 的 ⌈(n+1)(1−α)⌉/n 分位，则对新物体 O~P_O 有 P[S_O≤q] ≥ 1−α。**帧级标定因物体内相关而不满足可交换性，其有效样本量是物体数而非帧数。**
- **定义 235（物体元特征、条件覆盖与泛化间隙）**：元特征 z_o=φ(o)（刚度 k、质量 m、摩擦 μ、透明度、纹理、尺寸）。按 z 的 Mondrian 分箱 b 分别标定 q_b，得条件覆盖 P[S_O≤q_{b(O)} | O∈b] ≥ 1−α。泛化间隙 G(α)=sup_b|cov_b−(1−α)|，用物体级 bootstrap 给置信区间；协变量偏移下用加权 conformal，权重 w(z)=p_test(z)/p_cal(z)。
- **定义 236（新物体检测与证书降级 NOD）**：新颖度 s_nov(o)=‖z_o−μ_z‖²_{Σ_z⁻¹}+u_ens(o)（元特征马氏距离 + 集成认知方差），其 conformal p 值 p(o)=(1+#{标定物体:s_nov≥s_nov(o)})/(n+1)。若 p(o)<α_nov，置 `object_unverified`，证书等级 ℓ∈{full, conditional, conservative, human-required} 至少降一级。**未验证物体不得声称 full 覆盖。**
- **定义 237（物体属性主动辨识 OAI）**：以最小化泛化不确定度为目标选探针 a*=argmin_a E[G_after(a)]（或等价地最大化 I(z;观测)），s.t. 预测法向力 ≤f_safe、形变 ≤ε_strain；易损物体仅允许 visual_probe/null_test。辨识结果细化 z 的后验，缩小分箱或降低 s_nov。
- **定义 238（人类升级通道 HEC）**：人的决策 h∈{continue, halt, takeover, relabel}，带反应延迟 τ_h 与混淆矩阵 C_h（敏感度 s_h、误报率 f_h）。升级策略在「自动执行」与「请求人」间做价值信息决策：π_esc=argmin_a E[L|a]，L=c_miss·漏报+c_fa·误报+c_delay·τ_h+c_cog·认知负荷。**人不是真值，只在 s_h 高于自动通道时请求才有正收益。**
- **定义 239（信任标定 TCU）**：用户主观安全信念 b∈[0,1] 与证书安全概率 p_cert 的失配 TCE=E[(b−p_cert)²]，过度信任率 OTR=P[b>p_cert+ε]。用反事实故障注入诱发 b；要求 TCE≤ε_T 且 OTR≤ε_O，同时约束欠信任（可用性）。信任是**被测量的量**，不是界面修辞。
- **定义 240（用户测试驱动的未知故障发现 UHT）**：用户失败报告流按 Dirichlet 过程/CRP 分配到已有假设或新类型；未知质量 π_unk 的后验随报告更新。当 π_unk 的上置信界 <r_stop 且故障库覆盖 ≥1−η 时停止扩充。这把「用户测试」形式化为假设集的生长机制。
- **定义 241（证书—观测一致性审计 CAG）**：每次用户测试 episode 有证书声明 c_i=(ℓ,覆盖,CAG 预测) 与实际观测 y_i∈{safe, violation, near-miss}。用 Brier 分数与校准曲线度量，并以 SPRT 在线检验 H0「证书已校准」对 H1「证书过度自信」；拒绝 H0 即降级该物体子群并触发重标定。
- **定义 242（物体子群条件安全规划 OGS）**：在块图上规划，约束按物体分箱 b 条件化；技能可用性依赖证书等级 ℓ；未验证物体只允许保守技能集；代价增 λ_nov·novelty + λ_unk·π_unk + λ_h·P(需人)；仍要求 k*≥1（长预测、短执行不变）。
- **定义 243（AIC-G 开放世界对抗认证）**：干扰集 ℰ_G=ℰ_V×ℰ_obj×ℰ_human，ℰ_obj 含长尾物体（超软/超硬/透明/超重/微小），ℰ_human 含过度信任、误用、延迟接管、标注不一致。ρ_dir 重算；J_dir 增 object_shift_ver、human_ver。**物体偏移下只要求安全降级，不要求归因正确。**
- **定义 244（GUEST 证书 J_guest）**：J_guest=(J_vista, object_calib_ver, coverage_CI, novelty_p, certificate_level, human_escalation, trust_calib, unknown_mass, cag_ver)。Valid ⇔ Valid(J_vista) ∧ 物体子群标定未过期 ∧ (novelty_p≥α_nov ∨ 已完成 OAI ∨ 人已确认) ∧ 覆盖置信下界 ≥1−α−ε ∧ 当前用户群 TCE/OTR 达标 ∧ (unknown_mass≤λ_max ∨ 有人监督) ∧ cag_ver 为当前版本。
- **定义 245（GUEST 闭环算子）**：语义/离线流 [VISTA 全链→OGC 物体级标定→NOD 新颖度→OAI 属性辨识→OGS 子群规划→HEC 升级决策→UHT 故障库扩充→CAG 审计→TCU 信任分析]；实时流 [读证书等级→阶段化残差→CSC 早停→WCV-V 编译→派发前缀→必要时升级人]。
- **定义 246（用户测试统计功效与样本量）**：要证明安全率 ≥p0（置信 1−β、零失败接受），需 n≥lnβ/ln p0（success-run 规则）；要估计 TCE 到 ±ε，需 n=O(σ²/ε²)，并按设计效应 DEFF=1+(m−1)ρ 放大（m 为每用户 trial 数，ρ 为用户内相关）。只报告单侧置信下界，不报告点估计。
- **定义 247（开放世界故障质量与停止规则）**：π_unk 为未知故障后验质量；停止规则为 P(π_unk>r_stop)<β 且故障库对已观测类型的覆盖 ≥1−η。未达停止条件时 J_guest 显式携带 `unknown_mass`，并限制在保守技能集。

## 2. 关键算法骨架

```python
# OGC：以物体为单位的 split-conformal（离线）
S = {o: aggregate_scores(per_frame_scores[o], agg='max') for o in cal_objects}
bins = mondrian_bins({o: phi(o) for o in cal_objects})          # 元特征分箱
q = {b: empirical_quantile([S[o] for o in objs_b], (n_b + 1) * (1 - alpha) / n_b)
     for b, objs_b in bins.items()}
coverage_CI = object_level_bootstrap(S, bins, alpha)            # 物体级 CI，不是帧级

# NOD + 证书降级（语义流）
p_nov = conformal_pvalue(s_nov(z_new), cal_novelty)
level = 'full'
if p_nov < alpha_nov:
    level = 'conservative'
    if oai.expected_gain(z_new) > cost:
        z_new = oai.identify(z_new, f_safe, eps_strain)         # 有界主动辨识
        p_nov = conformal_pvalue(s_nov(z_new), cal_novelty)
    if level != 'full' and human_available:
        level = 'human-required' if p_nov < alpha_nov else 'conditional'

# HEC：价值信息升级
loss_auto = c_miss * (1 - s_auto) * P_danger + c_fa * f_auto
loss_ask  = c_miss * (1 - s_h) * P_danger + c_fa * f_h + c_delay * E[tau_h] + c_cog
ask_human = loss_ask < loss_auto and human_available

# CAG：证书—观测一致性（离线/在线审计）
claim = (level, coverage_CI, predicted_safe)
brier = (predicted_safe - observed_safe) ** 2
sprt.update(brier, llr_overconfident)
if sprt.reject_H0:
    downgrade_subgroup(bin_of(object)); trigger_recalibration()
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（帧级 conformal 在物体系下失效）**：物体内帧强相关使帧级标定不满足可交换性；存在构造使帧级 95% 覆盖对应物体级覆盖任意接近 0。故第 65 轮以帧计数的 coverage 不能作为跨物体保证。
- **引理 10（物体级条件覆盖）**：物体子群内可交换时，Mondrian split-conformal 给出 P[S_O≤q_b|O∈b]≥1−α；有限样本覆盖服从 Beta(n_b+1−⌊(n_b+1)α⌋,⌊(n_b+1)α⌋)，泛化间隙的 bootstrap CI 给出显式不确度。协变量偏移下加权 conformal 的覆盖 ≥1−α−TV(P_test, P̃_cal)。
- **引理 11（新物体降级的安全性）**：若 p(o)<α_nov，则以 ≥1−α_nov 的概率该物体落在标定支撑之外；降级到保守技能集并用最坏界 ρ_bound 后，越界概率 ≤α_chunk+α_nov+α_vis。若升级给人，漏报概率 ≤(1−s_h)·P(danger)+P(τ_h>τ_budget)；**仅当 s_h>s_auto 且延迟可接受时升级才降低总风险。**
- **定理 9（GUEST 端到端）**：在 A94–A99 下，Valid(J_guest) ⇒ (i) 物体级覆盖对已标定子群成立；(ii) 未验证物体绝不获得 full 证书，只执行保守动作或升级人；(iii) 过度信任受 TCE/OTR 约束，不会因证书措辞放大漏报；(iv) 未知故障质量显式有界；(v) VISTA 安全在覆盖子群上保持，在子群外由降级/升级兜底。
- **定理 10（用户测试样本复杂度）**：零失败 success-run 证明安全率 ≥p0 需 n≥lnβ/ln p0；估计 TCE 到 ±ε 需 n=O(σ²/ε²)，用户内相关使需求乘 DEFF=1+(m−1)ρ。**因此「用户测试通过」必须附样本量与置信下界，否则只是轶事。**
- **命题（过度信任是风险放大器）**：若人的有效敏感度 s_h(b) 随其信念 b 下降（越信任越不监控），则总漏报概率 (1−s_h(b))·P(danger) 随 OTR 上升；故发布乐观证书可能使系统总安全性低于不发布证书。**解释不是中性信息，它会改变人的行为。**
- **实时性**：NOD/OAI/OGS/HEC 决策全在语义流；实时流只读缓存证书等级（O(1)）、阶段判定与 CSC 早停不变，目标仍 ≤2.5ms。

## 5. 本轮最大风险

**一句话**：GUEST 的两条保证都建立在有限样本上——物体标定集与用户测试队列；当证书等级、升级阈值和解释话术都在同一批用户测试上调参、又用同一批测试宣称「泛化且经人验证」时，保证会退化为**程序合法性**（procedural legitimacy）：它看起来对「新物体 + 真实用户」成立，实际只是对「这批物体 + 这批用户」成立，而系统因贴着「已泛化、已人验」的标签获得更高信任，下一次面对长尾物体或下一代用户时，过度信任会把局部误判放大成系统性失效——**新的单点故障不是传感器，而是用来验证系统的那个总体本身。**

> 承接第 65 轮 IP-214~223（VISTA：VPG×ACH×FIR×VCV×VSP/AFA×CSC×RSC-V×WCV-V×CSP-V×AIC-V×J_vista）。第 65 轮把「几何可证伪」升级为「故障可归因」，但其最大风险是**有限假设集 + 视觉/几何共因失效**：未知复合故障被强行归入最近假设，且系统因「已归因」更自信。本轮不增加模态，而是审查保证的**作用域与验证者**：VISTA 的所有标定都默认部署物体来自标定分布、验收者与训练者同质。换物体时帧级 conformal 不是缓慢退化而是整段失效；换用户时「用户认可」也不等于安全。因此本轮把保证单位从「帧」改成「物体」，把用户测试从终验改成**未知故障的采样器 + 证书的独立审计员**，并把人建模成有延迟、会漏报、会过度信任的通道。实现 **「保证单位是物体、失效由人共验、过度信任也是一等风险」**。
>
> IP 编号：IP-224~IP-233（共 10 个），全部为 VISTA 组件的原位升级或挂载式新增。

## 2. 形式化定义（完整版）

**定义 233（GUEST 闭环）** GUEST 是 VISTA 的「作用域可信 + 人机共验」升级：在 VISTA 的语义流/实时流骨架上挂载 OGC（物体级 conformal）、NOD（新物体检测与降级）、OAI（物体属性主动辨识）、OGS（子群条件规划）、HEC（人类升级通道）、TCU（信任标定）、UHT（未知故障发现）、CAG（证书—观测审计），并原位升级 AIC-V→AIC-G、J_vista→J_guest。不变式：**物体级标定、泛化审计、信任分析、故障库扩充只在离线/语义流；实时流只读缓存证书等级与升级标志，做阶段化残差采集、安全前缀执行与早停，零学习写操作。**

**定义 234（物体级标定单元与可交换性）** 标定集由物体 o_1,…,o_n 独立采样自物体分布 P_O，而非从轨迹中切出的帧。对每物体先把逐帧非一致性分数 s_{o,t} 聚成物体分数
S_o = max_{t∈o} s_{o,t}（或 (1−α) 分位），
再取 split-conformal 阈值 q 为 {S_o} 的 ⌈(n+1)(1−α)⌉/n 分位。若物体可交换，则新物体 O~P_O 满足
P[S_O ≤ q] ≥ 1−α。
关键：同一物体内帧高度相关，帧级标定不满足帧间可交换性，且有效样本量是物体数 n 而非帧数 n·T；这正是第 65 轮 coverage 在换物体时静默失效的根源。

**定义 235（物体元特征、条件覆盖与泛化间隙）** 元特征 z_o=φ(o)∈ℝ^{d_z}（可通过视觉/短程探针粗估的刚度 k、质量 m、摩擦 μ、透明度、纹理丰富度、特征尺寸）。按 z 的 Mondrian 分箱 b 分别标定 q_b，得条件覆盖
P[S_O ≤ q_{b(O)} | O∈b] ≥ 1−α。
泛化间隙 G(α)=sup_b|cov_b−(1−α)|，用物体级 bootstrap 给上置信界 Ĝ_{1−β}。协变量偏移下改用加权 conformal，权重 w(z)=p_test(z)/p_cal(z)，覆盖 ≥1−α−TV(P_test, P̃_cal)。

**定义 236（新物体检测与证书降级 NOD）** 新颖度
s_nov(o) = ‖z_o−μ_z‖²_{Σ_z⁻¹} + u_ens(o)，
其中 u_ens 为元特征估计器的集成认知方差（对未见区域的额外惩罚）。其 conformal p 值
p(o) = (1 + #{标定物体 i : s_nov(o_i) ≥ s_nov(o)}) / (n+1)。
若 p(o)<α_nov，置 `object_unverified`，证书等级按 ℓ=full→conditional→conservative→human-required 至少降一级。**未验证物体不得声称 full 覆盖，也不得复用其子群以外的标定阈值。**

**定义 237（物体属性主动辨识 OAI）** 在力/形变预算内选探针
a* = argmin_{a∈A} E[G_after(a)]（等价于最大化 I(z; 观测)），
s.t. 预测 f_n≤f_safe(φ̂,f̂_vis)、预测形变≤ε_strain、支持视觉早停。探针集沿用 VISTA 的 {visual_probe,null_test,press,rub,tap,lift}；易损物体仅允许无接触/零力窗探针。辨识更新 z 的后验，用于重新分箱（缩小 G）或降低 s_nov（从 unverified 升回 conditional）。

**定义 238（人类升级通道 HEC）** 人的决策 h∈{continue,halt,takeover,relabel}，反应延迟 τ_h∼D_h，混淆矩阵 C_h 给出敏感度 s_h=P(h=halt|danger)、误报率 f_h=P(h=halt|safe)。升级策略在自动执行 a_auto 与请求人 a_ask 间做价值信息决策：
π_esc = argmin_{a∈{auto,ask}} E[L|a]，
L = c_miss·1[漏报危险] + c_fa·1[误报] + c_delay·τ_h + c_cog·1[请求]。
请求人当且仅当 E[L|ask] < E[L|auto] 且人可用。**人不是真值：仅当 s_h>s_auto 且 E[τ_h] 小于危险时间窗时，请求才净降风险；否则「问人」只是把延迟变成了新的伤害源。**

**定义 239（信任标定 TCU）** 用户在具体情景下的主观安全信念 b∈[0,1]，与证书给出的安全概率 p_cert 比较：
TCE = E[(b−p_cert)²]，OTR = P[b>p_cert+ε]（过度信任率），UTR = P[b<p_cert−ε]（欠信任率）。
用反事实故障注入（同一场景一次安全、一次注入可观测故障）诱发 b，并控制顺序效应。要求 TCE≤ε_T、OTR≤ε_O，同时 UTR≤ε_U（否则可用性崩溃）。信任是**被测量的状态量**，不是界面文案的副作用。

**定义 240（用户测试驱动的未知故障发现 UHT）** 用户失败报告流按 Chinese Restaurant Process 分配到已有故障假设 H 或新类型：
P(新类型) = γ/(γ+n_reports)，P(已有 h) = n_h/(γ+n_reports)。
未知质量 π_unk 的后验随报告更新；当 P(π_unk>r_stop)<β 且故障库对已观测类型覆盖 ≥1−η 时停止扩充。这把用户测试形式化为**假设集的生长机制**，而不是事后打分。

**定义 241（证书—观测一致性审计 CAG）** 每个用户测试 episode 产生证书声明 c_i=(ℓ_i, coverage_CI_i, predicted_safe_i) 与实际观测 y_i∈{safe,violation,near-miss}。定义校准评分
Brier = (predicted_safe − observed_safe)²，
并用 SPRT 序贯检验 H0「证书已校准」对 H1「证书系统性过度自信」，对数似然比累积
Λ_t = Σ_i log[p_1(y_i|c_i)/p_0(y_i|c_i)]。
拒绝 H0 即降级该物体子群、冻结其 full 证书并触发重标定。**证书本身必须可被用户观测证伪。**

**定义 242（物体子群条件安全规划 OGS）** 在 CSP-V 块图上规划，所有约束按物体分箱 b 条件化：
- 证书等级 ℓ 决定技能可用集 A_ℓ；full 用全技能，conditional 去掉高力/高速技能，conservative 仅低速低力并加大 r_model，human-required 只允许停/退/请求。
- 代价增 λ_nov·s_nov + λ_unk·π_unk + λ_h·P(need_human)。
- 仍须 k*≥1（长预测、短执行不变），并以覆盖置信下界而非点估计做安全判定。

**定义 243（AIC-G 开放世界对抗认证）** 干扰集
ℰ_G = ℰ_V × ℰ_obj × ℰ_human，
ℰ_obj 含长尾物体（超软/超硬/透明/超重/微小/异形），ℰ_human 含过度信任、误操作、延迟接管、标注不一致。ρ_dir 在 ℰ_G 上重算（n_cert 128→160，其中 32 用于物体长尾与人类行为）；J_dir 增 object_shift_ver、human_ver。**物体/用户偏移下不要求归因正确，只要求被判为 unverified/ambiguous 并安全降级。**

**定义 244（GUEST 证书 J_guest）** J_guest=(J_vista, object_calib_ver, coverage_CI, novelty_p, certificate_level, human_escalation, trust_calib, unknown_mass, cag_ver)。验证规则：
Valid(J_guest) ⇔ Valid(J_vista)
∧ 物体子群标定未过期
∧ (novelty_p≥α_nov ∨ 已完成 OAI ∨ 人已确认)
∧ coverage_CI 下界 ≥1−α−ε
∧ 当前用户群 TCE≤ε_T ∧ OTR≤ε_O
∧ (unknown_mass≤λ_max ∨ 当前有人监督)
∧ cag_ver 为当前版本。
审计链新增：这个保证对哪个物体子群成立（object_calib_ver/coverage_CI）、这个物体验证过没有（novelty_p/certificate_level）、是否请求了人（human_escalation）、人是否被正确定价（trust_calib）、还有多少未知（unknown_mass）、证书是否说对了（cag_ver）。

**定义 245（GUEST 闭环算子）** 语义/离线流：[VISTA 全链→OGC 物体级标定→NOD 新颖度→OAI 属性辨识→OGS 子群规划→HEC 升级决策→UHT 故障库扩充→CAG 审计→TCU 信任分析]；实时流：[读证书等级→阶段化残差采集→CSC 早停→WCV-V 编译→派发认证前缀→必要时升级人→J_guest 构建]。

**定义 246（用户测试统计功效与样本量）** 要证明安全率 ≥p0（置信 1−β、零失败接受），需
n ≥ lnβ / ln p0
（success-run 规则）。要估计 TCE 到 ±ε，需 n=O(σ²/ε²)，并按用户内相关放大 DEFF=1+(m−1)ρ（m 为每用户 trial 数，ρ 为用户内相关）。报告单侧置信下界（Clopper–Pearson / Wilson），不报告点估计；跨用户异质性用混合效应模型分离 subject random effect 与固定效应。

**定义 247（开放世界故障质量与停止规则）** π_unk 为未知故障后验质量，r_stop 为可接受残差未知率。停止扩充当且仅当
P(π_unk>r_stop)<β 且 覆盖_库(已观测类型)≥1−η。
未达停止条件时，J_guest 显式携带 unknown_mass，并强制 OGS 进入保守技能集（定义 242）。

### IP-224 OGC（物体级泛化证书）

```python
class ObjectGeneralizedConformal:
    def __init__(self, alpha, agg='max'):
        self.alpha, self.agg = alpha, agg

    def aggregate(self, frame_scores):
        return np.max(frame_scores) if self.agg == 'max' else \
               np.quantile(frame_scores, 1 - self.alpha)

    def fit(self, cal_objects, phi):
        self.S = {o: self.aggregate(s) for o, s in cal_objects.items()}
        self.z = {o: phi.get(o) for o in cal_objects}
        self.bins = mondrian_bins(self.z)                 # 物体元特征分箱
        self.q = {}
        for b, objs in self.bins.items():
            vals = np.array([self.S[o] for o in objs])
            n = len(vals)
            k = int(np.ceil((n + 1) * (1 - self.alpha)))
            self.q[b] = np.sort(vals)[min(k, n) - 1] if n else np.inf
        self.coverage_ci = object_bootstrap_ci(self.S, self.bins, self.alpha)

    def threshold(self, z_new):
        return self.q.get(bin_of(z_new), np.inf)          # 未覆盖分箱 → 无穷保守

    def certified(self, z_new, S_new):
        q = self.threshold(z_new)
        return bool(S_new <= q), self.coverage_ci, bin_of(z_new)
```

### IP-225/226 NOD + OAI（未验证物体 → 降级/辨识）

```python
class NovelObjectGate:
    def __init__(self, alpha_nov, cal_novelty, oai, cost_probe):
        self.alpha_nov = alpha_nov
        self.cal = np.sort(np.asarray(cal_novelty))
        self.oai, self.cost = oai, cost_probe

    def pvalue(self, s):
        return (1 + np.sum(self.cal >= s)) / (len(self.cal) + 1)

    def gate(self, z_new, cert_level, human_available):
        s = s_novelty(z_new)                              # 马氏 + 集成方差
        p = self.pvalue(s)
        if p >= self.alpha_nov:
            return cert_level, p, z_new, False
        level = 'conservative'
        if self.oai.expected_gap_reduction(z_new) > self.cost:
            z_new2 = self.oai.identify(z_new)             # 有界力/形变探针
            p = self.pvalue(s_novelty(z_new2))
            if p >= self.alpha_nov:
                level, z_new = 'conditional', z_new2
        if p < self.alpha_nov and human_available:
            level = 'human-required'
        return level, p, z_new, True
```

### IP-227 HEC（价值信息升级）

```python
class HumanEscalationChannel:
    def __init__(self, s_h, f_h, tau_dist, costs):
        self.s_h, self.f_h, self.tau_dist, self.c = s_h, f_h, tau_dist, costs

    def expected_loss(self, auto, p_danger, p_cert, ask):
        c = self.c
        if ask:
            return (c['miss'] * (1 - self.s_h) * p_danger
                    + c['fa'] * self.f_h * (1 - p_danger)
                    + c['delay'] * self.tau_dist.mean() + c['cog'])
        # 自动通道的敏感度由证书等级给出（full 高于 conservative）
        s_auto = auto['sensitivity']
        return (c['miss'] * (1 - s_auto) * p_danger
                + c['fa'] * auto['false_alarm'] * (1 - p_danger))

    def should_ask(self, auto, p_danger, p_cert, human_available):
        if not human_available:
            return False, None
        la = self.expected_loss(auto, p_danger, p_cert, ask=False)
        lk = self.expected_loss(auto, p_danger, p_cert, ask=True)
        # 只有在人能带来足够价值、且延迟在危险时间窗内才升级
        within = self.tau_dist.quantile(0.95) <= auto['danger_window']
        return bool(lk < la and within), lk - la
```

### IP-228 TCU（信任标定）

```python
def trust_calibration(trials):
    """trials: [(p_cert, belief_b, observed_safe)]，belief 由反事实故障注入诱发。"""
    b = np.array([t.belief_b for t in trials])
    p = np.array([t.p_cert for t in trials])
    tce = float(np.mean((b - p) ** 2))
    otr = float(np.mean(b > p + EPS_TRUST))
    utr = float(np.mean(b < p - EPS_TRUST))
    # 用户内相关：混合效应模型估计 subject random effect
    return {'TCE': tce, 'OTR': otr, 'UTR': utr,
            'mixed_effects': fit_subject_random_effects(trials)}
```

### IP-229/230 UHT + CAG（用户测试 → 故障库生长与审计）

```python
class UserTestLoop:
    def __init__(self, gamma, r_stop, beta, eta):
        self.gamma, self.r_stop, self.beta, self.eta = gamma, r_stop, beta, eta
        self.counts, self.n = {}, 0

    def add_report(self, failure_type):
        self.n += 1
        if failure_type not in self.counts:
            self.counts[failure_type] = 0        # CRP 新类型
        self.counts[failure_type] += 1

    def unknown_mass(self):
        known = sum(self.counts.values())
        return self.gamma / (self.gamma + self.n) if self.n else 1.0

    def stop(self, library_coverage):
        return (posterior_upper(self.unknown_mass(), self.beta) < self.r_stop
                and library_coverage >= 1 - self.eta)


class CertificateAudit:
    def __init__(self, llr_fn, thresh):
        self.llr_fn, self.thresh, self.L = llr_fn, thresh, 0.0

    def update(self, claim, observed):
        self.L += self.llr_fn(claim, observed)
        if self.L > self.thresh:                 # 拒绝 H0：证书过度自信
            return 'reject_overconfident'
        return 'monitor'
```

```python
    x_prime = M.lsf.fuse(M.usr.fuse(V, T, P, L))
    y_vis = M.f_vis(img, depth, flow)
    phi_hat_geo, *_ = M.mel.infer_by_mode(M.ocb_skill.choose().mel_mode, V, T, P, L, x_prime)

    # 1) VISTA：块 + 视觉 + 归因
    A = M.ach.propose(x_prime, H=M.H)
    visual = M.vpg.verify_and_predict(y_vis, A, M.mws.last_contacts)
    phases = M.stage.split(M.residual_log, visual)
    post, h_star, ambiguous = M.fir.attribute(phases)

    # 2) OGC + NOD：这个物体被验证过吗？
    z_o = M.ogc.meta_features(y_vis, phi_hat_geo)
    S_o = M.ogc.aggregate(M.residual_log.frame_scores(window=object_window))
    covered, cov_ci, bin_b = M.ogc.certified(z_o, S_o)
    level, p_nov, z_o, asked_ident = M.nod.gate(z_o, M.cert_level, user_ctx.available)

    # 3) OAI：未验证则先有界辨识（探针优先无接触）
    if asked_ident and level in ('conditional', 'conservative'):
        M.execute_probe(M.oai.choose(z_o, M.f_safe, M.object_fragile))
        z_o = M.oai.posterior_update(z_o, M.residual_log)
        level, p_nov, z_o, _ = M.nod.gate(z_o, level, user_ctx.available)

    # 4) OGS：按物体子群与证书等级规划（仍长预测、短执行）
    goal = M.dms.parse_goal((M.usr.U_ep, M.usr.U_al))
    tau = M.ogs.plan(goal, x_prime, phi_hat_geo, M.balls, post, level)
    k_star = M.csc.certified_prefix(tau.A, post, M.m, M.alpha_chunk)

    # 5) HEC：是否请求人接管（价值信息，含延迟）
    p_danger = danger_prob(post, visual, cov_ci)
    ask, vo = M.hec.should_ask(M.auto_stats(level), p_danger, cert_safe(cov_ci), user_ctx.available)
    if ask:
        human = user_ctx.request(tau, post, level, cov_ci, p_nov)   # 人作为通道
        if human.decision in ('halt', 'takeover'):
            return M, None, None, build_j_guest(..., human_escalation=human)
        if human.decision == 'relabel':
            M.uht.add_report(human.failure_type)                    # 故障库生长

    # 6) 执行 + 实时早停
    K_safe, EV_exec, cert_exec = realtime_step_vista(M, delta_f_req, tau, k_star, x_prime, None)

    # 7) 审计与回写（离线/语义流）
    M.cag.update(claim=(level, cov_ci, cert_safe(cov_ci)), observed=EV_exec.safe)
    if M.cag.last == 'reject_overconfident':
        M.ogc.downgrade(bin_b); M.csc.freeze(bin_b)
    M.uht.add_report(EV_exec.failure_type) if EV_exec.failed else None
    return M, K_safe, EV_exec, build_j_guest(
        cert_exec, J_vista=M.j_vista, object_calib_ver=M.ogc.version,
        coverage_CI=cov_ci, novelty_p=p_nov, certificate_level=level,
        human_escalation=ask, trust_calib=M.tcu.last, unknown_mass=M.uht.unknown_mass(),
        cag_ver=M.cag.version)
```

## 4. 推导

**引理 9（帧级 conformal 在物体系下失效）** 设物体 o 的帧分数完全相关，即 s_{o,t}=S_o 对所有 t。帧级标定取全部帧的 ⌈(nT+1)(1−α)⌉/(nT) 分位 q_f。若物体分数 S_o 来自重尾分布且一半物体 S_o=0、一半 S_o=∞，则 q_f 可能落在 S_o=0 的质量内，使帧级覆盖看似 1−α，而物体级覆盖仅 0。更一般地，帧级有效样本量受物体数限制，帧级覆盖不满足对 P_O 的保证。故第 65 轮以帧计数得到的 coverage 不能跨物体迁移。∎

**引理 10（物体级条件覆盖）** 在子群 b 内，物体可交换，split-conformal 阈值 q_b 由 n_b 个物体分数决定。由标准 split-conformal 结论，
P[S_{O} ≤ q_b | O∈b] ≥ 1−α，
且有限样本覆盖随机变量服从 Beta(n_b+1−k_b, k_b)，k_b=⌊(n_b+1)α⌋，故其下置信界可直接给出，泛化间隙 G 的物体级 bootstrap 只是对该分布的经验近似。协变量偏移下，若用权重 w(z) 重加权标定分布到测试分布，覆盖 ≥1−α−TV(P_test,P̃_cal)，其中 P̃_cal 为重加权后的标定分布。∎

**引理 11（新物体降级的安全性）** 由定义 236，p(o)<α_nov 意味着在标定物体中新颖度不低于 s_nov(o) 的比例小于 α_nov，即在 P_O 意义上该物体落在标定支撑外的概率至少 1−α_nov。此时 OGS 只允许保守技能集，且用最坏界 ρ_bound 与 k*≤m 认证；由引理 8（第 65 轮）与联合界，
P[越界] ≤ α_chunk + α_nov + α_vis + α_geo。
若升级给人，漏报概率 ≤(1−s_h)P(danger)+P(τ_h>τ_budget)。只有当 s_h>s_auto 且 95% 分位延迟不超过危险时间窗时，请求人才会降低总损失（定义 238）。∎

**定理 9（GUEST 端到端）** 在 A94–A99 下：
1. **物体作用域**：对每个已标定子群 b，物体级覆盖 ≥1−α，且泛化间隙有显式 CI（引理 10）；帧级 coverage 不再被当作跨物体保证（引理 9）。
2. **未验证即降级**：novelty_p<α_nov 的物体绝不获得 full 证书；只执行 OGS 保守动作或升级人（定义 236/242）。
3. **信任受约束**：只有 TCE≤ε_T 且 OTR≤ε_O 时证书可用于面向人的决策；否则证书被抑制（定义 239/244）。
4. **开放世界有界**：unknown_mass 由 UHT 估计并进入 J_guest；未达停止规则时强制保守（定义 240/247）。
5. **安全保持与优雅降级**：覆盖子群上 Valid(J_guest)⇒Valid(J_vista)；子群外由降级/升级兜底；视觉失效、力失效、两者共因失效沿用第 65 轮处置。
6. **证书可证伪**：CAG 用用户观测对证书做序贯检验，拒绝即在子群上降级、冻结并重标定（定义 241）。
∎

**定理 10（用户测试样本复杂度）** 零失败 success-run：若真实安全率 p≥p0，则 n 次全部安全的概率 p^n；要求 p0^n≤β 得 n≥lnβ/ln p0。估计 TCE：若单 trial 误差方差 σ²，则独立样本需 n=O(σ²/ε²)；用户内 m 个 trial 相关 ρ 时，有效样本量 n_eff=n/(1+(m−1)ρ)，故需乘以 DEFF=1+(m−1)ρ。跨用户异质性用随机效应分离，否则 CI 会被系统性的用户差异撑大或假性收窄。∎

**命题（过度信任是风险放大器）** 设人的有效敏感度 s_h(b) 随信念 b 单调不增（越信任越少监控，∂s_h/∂b≤0），自动通道安全率固定。则当系统发布更高的 p_cert 使 b 上升时，漏报概率
P_miss(b) = (1−s_h(b))·P(danger)
单调不增于 s_h、即单调不减于 b。故存在场景使「发布乐观证书 + 人放松监控」的总安全率低于不发布证书。解释不是中性信息，它通过改变人的行为进入安全方程，因此 TCU 必须与证书同等严格地验证。∎

**推论（升级不是免费的安全）** 由定义 238，E[L|ask]−E[L|auto] = c_miss·P(danger)·(s_auto−s_h) + c_fa·(f_h−f_auto) + c_delay·E[τ_h] + c_cog。若 s_h≤s_auto 或延迟项占优，则 ask 严格更差。**把「请求人」当作无条件安全兜底是错的。**

## 7. 已知风险

**一句话**：GUEST 的两条保证都建立在有限样本上——物体标定集与用户测试队列；当证书等级、升级阈值与解释话术都在同一批用户测试上调参、又用同一批测试宣称「泛化且经人验证」时，保证会退化为**程序合法性**：它看起来对「新物体 + 真实用户」成立，实际只对「这批物体 + 这批用户」成立；而系统因贴着「已泛化、已人验」的标签获得更高信任，下一次面对长尾物体或下一代用户时，过度信任会把局部误判放大成系统性失效——**新的单点故障不是传感器，而是用来验证系统的那个总体本身。**

**次级风险与缓解**：
1. **物体标定集覆盖不足 / 子群样本稀少**：Mondrian 分箱在 n_b 很小时 CI 极宽或阈值退化。缓解：层级/部分池化（hierarchical conformal）共享相邻分箱信息；样本不足时自动并入更粗分箱并降证书等级，不假装精细。
2. **元特征本身不可靠**：z 由视觉/短探针估计，透明/镜面/遮挡下估计错，导致分箱与新颖度失真。缓解：z 的不确定度进入 s_nov；OAI 用多探针交叉验证；visual_unobservable 时不以 z 降级为「已验证」。
3. **用户队列不代表真实人群**：招募偏差、专家 vs 新手、文化差异。缓解：报告队列构成与分层 CI；对已知人群差异做随机效应；把 OTR 按人群分层设阈，而非全pooled。
4. **在测试集上调参（过拟合验证）**：最危险的一条。缓解：物体与用户都做 train/val/test 三分；证书等级与阈值只在 val 上选，test 只做一次性报告；预注册分析计划与停止规则。
5. **过度信任的反向——欠信任**：证书过多降级会让人频繁接管、可用性崩溃。缓解：同时约束 UTR；用分级解释而非二元「安全/不安全」；在安全场景中也展示证书如何被验证。
6. **人的延迟建模失准**：τ_h 依赖任务与界面，离线分布可能过期。缓解：在线测量接管延迟；延迟超过危险窗时禁止仅靠人兜底，改用控制器层 CBF/无源兜底。
7. **未知故障库的无限生长**：CRP 可能不断产生新类型、无法收敛。缓解：r_stop 与 β 显式设定；按严重度聚类而非按措辞；定期合并语义等价类型。
8. **实时预算**：NOD/OGS/HEC 都在语义流，但用户请求与解释渲染可能拖慢交互。缓解：缓存证书等级、异步解释、实时路径只读 O(1) 标志。
9. **CAG 的观测本身有偏**：用户可能漏看 near-miss，把 violation 记成 safe。缓解：多模态日志（力/视觉/用户报告）交叉核对；把用户标注可靠性作为 CAG 的测量误差建模。
