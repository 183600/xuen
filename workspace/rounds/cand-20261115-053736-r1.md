# 第 4 轮（灵感循环第 4 轮；本轮灵感：「强化学习训练」×「机械臂抓取」）

> **基线**：第 3 轮 InstructGauge（IP-321–327；定义 432–447；引理 51–58；实验 E441–E456）。第 2 轮 ToolGauge、第 1 轮 LeanGauge / MODGAUGE 骨架继续继承不变。
> 本轮纪律：**提案-权威分离 + 严格退化**。学习只产生提案，确定性盾与计量非干扰证书才是权威；机械臂抓取是可选增强，不能成为安全依赖。

## 0. 直觉与动机

**灵感 1（RL 训练 → 把「探测策略」从手写目标函数里解放出来，但学习是优化器，会攻击奖励）**
直觉：第 3 轮 IAC 用定义 436 的手写目标 `ΔH + w_align·A − λ_cost·c` 选块，这些权重与效益模型都是人猜的。RL 真正能做的是：在数字孪生里通过与场景反复交互，学到「先探哪个盲区、抓哪个工具、从哪个视角接近」的策略 `π_θ`，使**单位风险的信息增益**最大。但 RL 是一台「让优化器自己去检验奖励写得对不对」的机器——任何奖励漏写（例如只奖励探测通道的误差下降）都会被它找到捷径：反复探容易区域、过拟合校准回执、贴着噪声地板刷分。因此 RL 的正确位置是**提案层**而不是**权威层**：`π_θ` 输出候选 `(盲区, 抓取, 视角, 块)`，由确定性盾与独立验证通道裁决。跨轮看，这与第 3 轮「语言只改偏好、不改能力」是同一条元原则——**学习只改提案，不改权威**。

**灵感 2（机械臂抓取 → 动作空间从「固定工位上的传感器」扩到「抓取并重定位工具/传感器」，代价是接触会改变被测量对象）**
直觉：固定工位的传感器只能看它够得着的方向；机械臂抓取让系统可以主动换视角、换工具、把传感器送进遮挡区。这本质上是 next-best-view 的物理实现。但抓取是**接触干预**：夹持力会形变、工具位姿有运动链误差、手臂本身会遮挡已校准区域。计量学的第一原则是「测量不应改变被测量对象」，所以抓取必须新增一条比「无碰撞」更细的约束——**计量非干扰（MNI）**：被测量状态的改变 ≤ `ε_perturb`，且已校准区域的可见性变化必须被记账，绝不能让陈旧契约在遮挡之后继续被当成有效。

**灵感 3（两者耦合 → 学习把「接触」变成高频动作，必须用接触屏障与支持域门控夹住）**
直觉：RL 最擅长利用动作空间的每一寸。一旦把抓取交给 RL，它会在 sim 里学会**贴着碰撞边界、压着噪声地板**去榨信息增益；而 sim→real 的分布漂移恰好就发生在这些边界上。所以耦合的安全论证不能靠「训练得足够好」，只能靠结构：(a) 确定性盾把任意策略投影回不变量集合；(b) MNI 证书在接触前否决；(c) 支持域门控把 OOD 状态退回启发式；(d) 接触屏障让不可逆接触与策略无关地单步化。学习只负责「更快找到好的**可采纳**提案」，不负责「定义什么可采纳」。

## 1. 研究问题（本轮要回答什么）

- **Q1（学习的安全性）**：一个在 sim 中训练的抓取-探测策略，能否在部署时对其质量「零信任」地保持安全？
- **Q2（接触的计量合法性）**：抓取引入的接触、遮挡与位姿误差，能否被一个可检验的 MNI 证书界住，使校准契约仍然有效？
- **Q3（Goodhart 与 sim→real）**：当 RL 优化「信息增益」、而真实验收走独立通道，能否界定奖励劫持与 sim→real 差距，并让门控在 OOD 时优雅退化？

## 2. 三条设计原则（雏形，正式化见产物区定义 448–463）

**P1 提案-权威分离（Proposal-Authority Separation）**
`π_θ` 只能**提议**；`Shield / MNI / CVC / Barrier` 才是**权威**。权威谓词必须是非学习的、确定性的、在动作前可判定的。要求对任意 `π_θ`（含对抗策略）都有 `Shield∘π_θ` 保持不变量——安全性不依赖策略质量。

**P2 计量非干扰（Metrological Non-Interference）**
任何接触式探测必须满足 MNI 或**显式记账遮挡**：扰动在容差内、运动链位姿误差在容差内、被遮挡的已校准区域**暂停**而非「照旧可信」。不可证 ⇒ 禁止接触抓取，退化为固定工位非接触探测。

**P3 接触屏障（Contact Barrier）**
不可逆接触（力致划伤、热灼烧、不可恢复的表面改变）强制单步执行 + 独立模态交叉验证后才允许继续；该屏障与策略、与块长均无关。这是第 3 轮不可逆屏障在「接触」维度上的推广。

## 3. 与基线的接口（如何退化）

- 策略不可用 / OOD / 支持域不足 ⇒ 退回第 3 轮 IAC 启发式规划；
- MNI 不可证 ⇒ 禁止接触抓取，退回固定工位非接触 ToolGauge；
- 抓取不可达 / 碰撞 / 灵巧度不足 ⇒ 退回 ToolGauge 原动作空间；
- 指令不可接地 ⇒ `ι₀`（第 3 轮）；再往下 LeanGauge → MODGAUGE 原样。

## 4. 预期贡献

1. 一个**提案-权威分离**的组合安全口径：`Shield∘π_θ` 对策略质量零信任，仍逐动作保持不变量；
2. 一份 **MNI 证书**，把计量学「测量不改变被测量」落成可检验约束，并给出抓取遮挡的契约记账；
3. 一套**反 Goodhart 的独立通道 + 支持域门控**，把 RL 的收益限制在可校准支撑内；
4. 一条完整可证伪路径：E457–E472 覆盖可达无碰、非干扰、盾不变性、门控覆盖、sim→real、奖励劫持、子模贪心与 50Hz 保全。

## 5. 本轮最大风险

**一句话**：RL 会在 sim 里贴着安全边界优化信息增益，而 sim→real 漂移恰好发生在这些边界；若支持域门控与 MNI 证书本身也被「学习化」（用同一条通道验收），系统就会在「看起来安全」的 OOD 状态上以高置信执行接触动作。

## 2. 形式化定义（要点）

**定义 448（抓取-探测动作空间）** 抓取动作 `g = (τ, ξ, ν, f, w) ∈ 𝒢`，其中 `τ ∈ T₀` 为预注册工具、`ξ ∈ SE(3)` 为末端位姿、`ν ∈ S²` 为接近方向、`f ∈ [0, f_max]` 为接触力、`w` 为夹持配置。可采纳集
`𝔾_adm(σ) = { g : reach(ξ,σ) ∧ ¬collide(g,σ) ∧ dex(g,σ) ≥ d_min ∧ payload(τ) ≤ p_max }`。
一次探测动作是 `(g, a_{1:K})`：先把工具送到位，再执行第 3 轮的前缀封闭块。关键约束：`𝔾_adm` **只依赖状态与物理参数，不依赖 π_θ**。

**定义 449（计量非干扰证书 MNI）** `MNICert(g,σ) = (Δx, V_occ, ε_pose)`，须同时满足：
(i) 被测量相关状态 `‖x(σ⊕g) − x(σ)‖ ≤ ε_perturb`；
(ii) 遮挡图更新为 `V_occ`，任一已校准区域被遮挡 ⇒ 该区域契约 `suspend(r)`，不得继续当作有效；
(iii) 抓取工具经运动链后的位姿误差 `ε_pose(g) ≤ ε_pose,max`（由标定容差反推）。
任一条不可证 ⇒ `MNICert = ⊥`，接触动作不进入可采纳集。MNI 是「测量不改变被测量」这一计量学公理的可判定近似。

**定义 450（抓取-探测 CMDP）** `M = (S, 𝒢×𝒜, P, r, γ, C)`，奖励
`r = ΔH_info − λ_r·risk − λ_c·cost`，约束 `C` 包含：安全盾不变量 `Inv`、MNI、能力闭包（第 3 轮 CC）、预算 `B_chunk`、不可逆屏障。策略 `π_θ: S → Δ(Π_prop)`，提案 `p = (b, g, V, C)`（盲区、抓取、视角、动作块）。

**定义 451（提案-权威组合）** 部署策略 `π_exec(a|s) = Shield(π_θ(·|s))`，其中 `Shield: Δ(Π_prop) → Π_adm` 是**确定性投影**：
`Π_adm = { p : capability_closed(p) ∧ Inv_preserved(p) ∧ (¬contact(p) ∨ MNICert ≠ ⊥) ∧ Barrier(p) ∧ prefix_closed(p.C) }`。
`Shield` 对每个提案逐条硬过滤，不做“分数加权”，因此其输出与 `π_θ` 的置信度无关。学习只决定**提议的分布**，权威只决定**是否可执行**。

**定义 452（安全批评器与拉格朗日）** 训练时用安全批评器 `Q_C` 估计约束回报，优化 `L(θ,λ)=E[r]−λ(E[C]−d)`，`λ ← [λ + η(E[C]−d)]_+`。关键纪律：`Q_C` 与 `λ` **只塑形训练梯度，绝不进入部署判定**；部署期唯一的安全来源是定义 451 的 `Shield`。这避免「学出来的安全」替代「可判定的安全」。

**定义 453（支持域门控 SG-Gate）** 在特征 `x=(state, g, V)` 上定义新颖度 `ν(x)`（如 kNN 距离或密度比）。用真实无操作/空转流 `D_idle` 做共形校准，取阈值 `τ_ood` 使 `P_{D_idle}(ν ≤ τ_ood) ≥ 1−α`。接受 `Acc = {x : ν(x) ≤ τ_ood}`；`x ∉ Acc` ⇒ 拒绝 `π_θ` 提案，退回 IAC。接受域的覆盖保证与回退损失由引理 62 给出。

**定义 454（反 Goodhart 独立通道）** 奖励只用通道 `Ch_A`（如探测通道的预测信息增益代理），验收只用**不相交**的 `Ch_B`（留出的交叉回执 / 独立标定靶）。训练过程不得读取 `Ch_B`。定义散度 `D_AB = sup_φ |E_{Ch_A}[φ] − E_{Ch_B}[φ]|` 的可估计版本；若 `D_AB > δ_g` ⇒ 拒绝本次策略更新。这把第 2 轮的 `cross_receipt` 从“事后验收”提升为“训练时不可见约束”。

**定义 455（sim→real 差距证书）** 设域随机化分布 `D_sim` 对真实分布 `D_real` 的总变差上界为 `β_gap`（由标定探测集估计）。则对任意有界目标 `F`，`|E_real[F(π)] − E_sim[F(π)]| ≤ L_F·β_gap`。部署门控据此收紧：`τ_ood(β) = τ_ood − c·β_gap`，使「被接受」同时意味着「差距被界住」。差距不可估 ⇒ 门控退化为最保守值，等价于禁用 RL。

**定义 456（训练-部署分离与探索预算）** 探索 `Expl(θ)` **只允许**发生在数字孪生内且盾始终开启；真实部署 `Deploy(θ)` 冻结为贪心 + 盾 + 门控。真实侧的新数据采集只能通过**已认证的非接触动作**触发。探索预算 `B_expl` 有上限，超过即停止训练。此定义排除「在真实产线上边干边学」这一最高风险模式。

**定义 457（抓取下的遮挡记账）** 维护可见性图 `V_t: Region → {visible, occluded}`。抓取改变 `V_t`；若已校准区域 `r` 由 visible 变 occluded，则 `suspend(r)`：该区域契约进入「待复观」而非「继续可信」。复观前不得用旧契约对它做外推。这条把「遮挡」从视觉问题升级为**契约有效性问题**。

**定义 458（NBV-Grasp 信息增益目标）** 视图集 `V` 的目标
`F(V) = H(X_blind | h) − H(X_blind | Y_V, h)`，
在可达性拟阵 `M = (V, ℐ_reach)` 约束下最大化；抓取 `g` 只是实现视角 `V` 的手段，不单独计入奖励（避免「为了抓而抓」）。在遮挡独立模型下 `F` 单调子模，贪心给出 `1−1/e`（基数约束）或 `1/2`（一般拟阵）近似（引理 64）。

**定义 459（接触屏障 CB）** 不可逆接触集 `I_contact`（力致划伤、热、不可恢复表面改变）。若 `g` 以 `f > f_safe` 接触被测量面，或 `τ ∈ I_contact`，则强制单步执行，并要求**独立模态**（力/触觉 + 视觉）交叉验证通过后才允许后续动作。该屏障与 `π_θ`、`K` 均无关。

**定义 460（运动链位姿误差预算）** `ε_pose(g) = ε_cal + ε_kin(g) + ε_comp(f)`，其中 `ε_cal` 为手眼/工具标定误差、`ε_kin(g)` 为抓取构型相关误差、`ε_comp(f)` 为柔顺/夹持力导致的偏移。要求 `ε_pose ≤ ε_pose,max`，`ε_pose,max` 由计量契约的容差反推。超限 ⇒ 先做「在手重标定」或放弃抓取。

**定义 461（提案-权威分离原则 PA）** 元原则：任何学习或语言模块 `L` 只能**限制可采纳集**或在其中**重排**；权威谓词（`Inv, MNI, CVC, Barrier`）必须非学习、确定性、在驱动前可判。跨轮统一：第 3 轮语言在提案层改偏好，第 4 轮学习在提案层改提议；两者都不扩权（引理 51 与引理 61 同构）。

**定义 462（策略卡与抓取-探测证书）** `PolicyCard(π_θ) = (训练数据哈希, sim 配置, DR 范围, 奖励规格, λ, 门控阈值, 已知 OOD 集)`；每次执行记录
`GraspCert = (policy_card_id, proposal, shield_decision, MNICert, ChunkCert, receipts)`。
审计可沿「策略卡 → 提案 → 盾裁决 → MNI → 块证书 → 回执」六级复现一次抓取-探测。

**定义 463（退化接口）** 每个新能力配一个布尔能力标志：`has_policy, has_grasp, has_contact, has_mni`。任一为假即按固定顺序替换：`GraspGauge → InstructGauge → ToolGauge → LeanGauge → MODGAUGE`。替换是**逐指令等价**的语义替换，不是“尽力而为”的降级。

## 3. 关键算法骨架

```python
# IP-328 GRASP-ACT：状态相关可采纳抓取集（只依赖物理，不依赖策略）
class GraspActionSpace:
    def admissible(self, state):
        out = []
        for g in self.candidates(state):          # τ∈T0, ξ∈reachable, ν∈S2
            if not reach(g.pose, state):       continue
            if collide(g, state):              continue
            if dexterity(g, state) < D_MIN:    continue
            if payload(g.tool) > P_MAX:        continue
            out.append(g)
        return out

# IP-329 MNI：接触前的计量非干扰证书
class MNIChecker:
    def certify(self, g, state):
        dx = self.measurand_delta(state, g)
        if dx > EPS_PERTURB:
            return None                            # 不可证 ⇒ 禁止接触
        occ = self.occlusion_update(state, g)
        if occ.occludes_calibrated and not self.compensable(occ):
            return None
        if self.pose_error(g) > EPS_POSE_MAX:      # ε_cal+ε_kin+ε_comp
            return None
        return MNICert(dx, occ, self.pose_error(g))

# IP-330 RL-Prop：只做提案，不执行
class RLProposer:
    def propose(self, state, blind_spots):
        with torch.no_grad():
            return self.policy.sample_candidates(
                state, blind_spots, n=N_PROP)      # 输出 Π_prop

# IP-331 PA-Shield：确定性投影；对任意策略都保持 Inv
class PAShield:
    def project(self, proposals, state):
        adm = []
        for p in proposals:
            if not capability_closed(p, state):          continue
            if not self.inv_preserved(p, state):         continue
            if p.contact and self.mni.certify(p.g, state) is None:
                continue                                  # 无 MNI 不许接触
            p = self.contact_barrier(p)                   # 不可逆接触⇒单步
            if not prefix_closed(p.chunk):
                p = per_step(p)                           # 退回第 3 轮 K=1
            if not self.budget_ok(p, state):              continue
            adm.append(p)
        return adm

# IP-332 SG-Gate：共形新颖度门控
class SGGate:
    def accept(self, feature):
        return self.novelty(feature) <= self.tau_ood   # OOD ⇒ False

# IP-333 NBV-Grasp：子模贪心选视角-抓取束
class NBVGrasp:
    def select(self, adm, state):
        V, gain = set(), 0.0
        while True:
            best = max(adm, key=lambda p: self.marginal(p.view, V, state)
                       if self.feasible(p, V, state) else -1)
            mg = self.marginal(best.view, V, state)
            if mg <= 0: break
            V.add(best.view); gain += mg
        return self.realize(V, state)                  # 找到实现 V 的最小抓取序列

# IP-335 GraspGauge-8C 闭环
def graspgauge_8c(M, s):
    out  = M.nlib.ground(M.ell, M.scene, M.ontology)
    iota = out[0] if out else M.default_iota           # 第 3 轮；⊥ ⇒ 默认
    probs = M.rlprop.propose(M.scene, s)               # 提案（异步）
    adm   = M.pashield.project(probs, M.scene)         # 权威：硬过滤
    feat  = feature(M.scene, s, adm[:1])
    if not adm or not M.sggate.accept(feat):           # 低支持/OOD ⇒ 回退
        C = M.iac.plan_chunk(iota, M.hyp(s), M.tools,
                             M.budget_left(s), M.drift_bound(s))
    else:
        C = M.nbvgrasp.select(adm, M.scene)            # 子模贪心
    cert = M.cvc.commit(C, M.env, iota)                # 第 3 轮块证书
    if cert.aborted: return stub_and_red(s, "chunk_abort")
    receipts = cert.receipts
    if not M.apcal.cross_validate(*M.apcal.calibrate(receipts, M.hyp(s), s),
                                  M.cross_receipt(s)):
        return stub_and_red(s, "cross_failed")
    M.mreg.hot_replace_at_quiescence(M.dpe, cert.boundary)
    M.pquar.record(M.apcal.last_gain, realized_gain(receipts))
    M.audit.log(PolicyCard(M.rlprop), probs, adm, cert)
    return True

# IP-336 主闭环：50Hz 路径不变；训练-部署严格分离
def GraspGauge_round(M, obs, audio, tac, depth, det):
    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight:
            M.inflight.add(s)
            submit_async(graspgauge_8c, M, s)
    return MODGAUGE_round(M, obs, audio, tac, depth, det)

def train_rl(M):
    # 探索仅在数字孪生内，且盾始终开启；真实侧永不探索
    for ep in range(N_EP):
        s = M.sim.reset()
        while not M.sim.done():
            probs = M.rlprop.propose(s, M.sim.blind_spots())
            adm   = M.pashield.project(probs, s)       # sim 里也过盾
            a     = lagrangian_pick(adm, M.lam)
            s2, r, unsafe, info = M.sim.step(a)
            M.replay.add((s, a, r, unsafe, info, s2))
            M.lam = dual_update(M.lam, unsafe, d=M.d)
            s = s2
        M.rlprop.update(M.replay, channel="Ch_A")      # 不读 Ch_B
        if M.reward_vs_accept_divergence() > DELTA_G:
            M.rlprop.rollback()                        # 反 Goodhart 回滚
```

## 4. 推导

**引理 59（策略无关安全性）** 若 `Shield` 是到 `Π_adm` 的确定性投影，且 `Π_adm` 对不变量 `Inv` 封闭，则对**任意** `π_θ`（包括对抗策略）与任意状态，`π_exec = Shield∘π_θ` 的每次驱动都满足 `Inv`。
*证明*：`Shield` 的输出按定义 451 逐条检查 `Inv_preserved`，故 `a ∈ Π_adm`；`Π_adm` 对 `Inv` 封闭给出单步保持；对时间归纳即得全程保持。整个证明不使用 `π_θ` 的任何性质，故对策略质量零信任。

**引理 60（MNI ⇒ 契约有效）** 若接触抓取满足 `MNICert(g,σ)`，则抓取后契约对所有**未遮挡、未扰动**区域仍然有效；被遮挡区域被 `suspend`，不会被静默复用。
*证明*：把测量泛函按区域分解 `x = Σ_r x_r`。扰动界保证 `‖x_r(σ⊕g) − x_r(σ)‖ ≤ ε_perturb`，位姿误差界保证工具坐标系下的偏差不超过标定容差，二者合起来保持每个有效区域的偏差上界；被遮挡区域从求和中移除并标记 suspension，故不产生“用旧值外推”的错误项。

**引理 61（学习不扩权）** 对任意 `π_θ`，`Shield∘π_θ` 产生的可执行计划集合 `Π_exec ⊆ Π_adm ⊆ Π_InstructGauge`（在去掉抓取、把 `g` 投影为工位参数后）。故 RL 不能创造基线不存在的能力；它只能更快地在基线可采纳集里找到好提案。
*证明*：`Π_adm` 定义中显式包含能力闭包与第 3 轮全部硬约束；`Shield` 只做子集选择，不做扩张。与引理 51 的结构归纳同构。

**引理 62（支持域门控的覆盖与有限回退损失）** 在真实流对新颖度校准可交换的假设下，接受域 `Acc` 的共形覆盖 `P(ν ≤ τ_ood) ≥ 1−α`；被拒绝的 `1−α` 质量上系统精确执行第 3 轮启发式，故期望损失
`E[loss] ≤ P_acc·loss_RL(Acc) + P_rej·loss_InstructGauge`，
且 `loss_RL(Acc)` 由奖励通道有效性（引理 65）界住。即使 `loss_RL` 在 OOD 上无界，门控把它的权重压到 `P_acc`，剩余部分回到基线的已知界。
*证明*：共形分位数给出接受率下界；拒绝分支与 `π_θ` 无关，直接继承第 3 轮引理 52/55。

**引理 63（sim→real 差距界）** 若 `D_sim` 对 `D_real` 的 TV 距离 ≤ `β_gap`，则对 `L_F`-Lipschitz 的目标 `F`，`|E_real[F] − E_sim[F]| ≤ L_F·β_gap`。部署门控取 `τ_ood(β) = τ_ood − c·β_gap` 时，「被接受」蕴含差距上界；`β_gap` 不可估 ⇒ 门控取最保守阈值，等价禁用 RL。
*证明*：TV 距离的对偶表示给期望差界；门控收紧使接受域随差距单调收缩。

**引理 64（NBV-Grasp 的子模贪心）** 在遮挡独立模型（各视图以独立概率遮挡各区域）下，`F(V)=H(X|h)−H(X|Y_V,h)` 单调子模；可达性约束构成拟阵 `M`。则贪心给出 `1/2` 近似；若进一步为基数约束 `|V|≤k`，给出 `1−1/e`。
*证明*：条件熵的边际收益随已选集合增大而递减（信息永不增加），单调性由增加视图不增熵给出；拟阵贪心的标准近似界（Nemhauser–Wolsey 族）适用。抓取可行性只影响 `M` 的独立集，不改变 `F` 的子模性。

**引理 65（反 Goodhart 散度界）** 若在 `Acc` 上两通道满足 `|E_{Ch_A}[φ] − E_{Ch_B}[φ]| ≤ δ_g` 对奖励相关函数类成立，则优化 `Ch_A` 导致的 `Ch_B` 退化不超过 `2δ_g` 加优化误差；定义 454 的散度测试拒绝超过 `δ_g` 的更新，故 Goodhart 退化被显式夹住。
*证明*：三角不等式分解 `Ch_B(π*) − Ch_B(π) ≤ [Ch_B−Ch_A](π*) + [Ch_A(π*)−Ch_A(π)] + [Ch_A−Ch_B](π)`，首末项 ≤ `δ_g`，中间项为优化增益。

**引理 66（接触屏障与不可逆损失）** 设不可逆接触单次失败概率上界 `p`、后果 `c_irr`。在 CB 下单步执行并独立验证，则不可逆部分期望损失 `≤ p·c_irr`，**与策略、与块长 K 无关**。可逆部分的放大仍由第 3 轮引理 56 与 `K_MAX(ι)` 夹住。
*证明*：CB 把不可逆接触从任何块中隔离为长度 1 的原子动作，验证在下一步动作前完成；故失败不被后续步骤放大。与引理 56 的分解完全一致。

**引理 67（摊销、门控与 50Hz 保全）** 策略推理异步；盾的判定复杂度 `O(|Π_prop|·|constraints|)` 且可提前退出；MNI 为 `O(|V_occ|)`；子模贪心 `O(|V|·|cand|)`。主循环新增周期 `< 0.2ms`；当提案预算超限或 `SG-Gate` 拒绝时，直接走第 3 轮 IAC，故时序与基线同阶。
*证明*：所有新计算都在异步任务内或常数级判定内；最坏情况回退到已知的 `O(1/K)` 摊销路径（第 3 轮引理 58）。

## 8. 本轮最大风险

**一句话**：`π_θ` 会在 sim 里贴着安全边界优化信息增益，而 sim→real 漂移恰好落在这些边界；缓解只能依赖结构（PA-Shield 使安全性对策略零信任、MNI 使接触前可判定、SG-Gate 把 OOD 退回第 3 轮、CB 使不可逆接触与策略无关地单步化、反 Goodhart 通道使验收不可被训练看见），并以 E458/E460/E461/E463/E465/E470 主动证伪——一旦信任「学出来的安全」，系统就会在看似安全的 OOD 状态上高置信地执行接触动作。
