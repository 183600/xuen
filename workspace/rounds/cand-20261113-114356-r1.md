# 第 67 轮（承接第 66 轮「RAS 情绪驱动闭环」IP-224~233；新灵感循环第 1 轮；本轮灵感：「检索增强生成」×「多模态大模型」）

> 第 66 轮 RAS 把 VISTA 的被动故障闭环升级为「主动意图感知闭环」，用面部表情捕获风险态度，用时空一致性抑制感知噪声。但 RAS 有一个被它自己点破的致命弱点：**它的世界知识全部写在参数里**。情绪分类器的先验、故障签名的似然、`λ_risk` 的标定系数，都是**一次性训练、部署即冻结**的；面对新用户、新物体、新故障模式，它既无法检索“上次这个人做这个动作时是什么表情”，也无法引用“这类几何误差在历史上对应哪一类故障”。更糟的是：RAS 的归因结果**不可溯源**——当它说“这是 H_force+E1”时，没有任何证据链能告诉人类为什么。
>
> 本轮灵感的核心命题是：
>
> **把「参数化、不可溯源的闭环」升级为「检索增强、语义接地、可审计的闭环」：用多模态大模型把多源观测接地为显式证据图，用检索增强从案例记忆中引入非参数知识校正后验，用接地证书把每一条控制决策钉死在可核验的证据上——构成 GRAIL（Grounded Retrieval-Augmented Intent-and-fault Loop，可溯源检索增强意图-故障闭环）。**
>
> GRAIL 问的是 RAS 没问的第三个问题：**凭什么？** 不只是「谁控制、何时控制、控制多少」，而是「**你依据什么证据做这个判断，这条证据能不能被检索、对齐、反驳与追责**」。

## 0. 直觉与动机

**灵感 1（检索增强生成 → 检索增强归因）**
直觉：RAG 的本质不是“把资料塞进上下文”，而是**用非参数记忆对抗参数化模型的遗忘与幻觉**。RAS 的贝叶斯归因是纯参数化的：`P(H,E | ρ, face)` 由固定似然与先验算出，无法回答“历史上类似签名被判成了什么、后来结果如何”。把归因改成 **case-based + parametric 的混合估计**：
- 参数支路提供光滑的泛化先验（覆盖没见过的组合）；
- 检索支路从案例记忆里找 top-k 近邻 `(签名, 场景图, 联合标签, 结果)`，用核权重做非参数校正；
- 两条支路按检索置信度 `β_t` 加权融合。

这带来 RAS 缺失的三种能力：**个性化**（这个用户的基线表情与疼痛阈值）、**长尾**（罕见故障的历史案例）、**可追责**（判决可指向具体案例 ID）。

**灵感 2（多模态大模型 → 语义接地层，而非实时控制器）**
直觉：MLLM 最擅长的不是 2ms 内的控制，而是**把异构观测翻译成可被共同推理的语义**。RAS 的观测是分立的：面部张量、力曲线、点云残差、几何球，人无法直接比较“面部 fear=0.7”与“几何残差 3.2mm”谁更该触发降级。MLLM 可以把它们统一成一条 token 流，输出**接地证据图**：
- 节点：人 / 杯 / 机器人 / 接触事件 / 表情事件；
- 边：因果、共现、支持 / 反驳；
- 每条断言带**证据跨度**（图像 bbox / 时间区间 / 曲线片段）与置信度。

关键工程判断：**MLLM 必须是慢系统**（2–5Hz，异步跑在语义流）。它的输出被缓存为带租约的“接地证书”；实时安全环仍由 VISTA/RAS 的 <2ms 证书执行。这样既得到语义理解，又不牺牲实时安全。

**灵感 3（双系统 → 带租约的双频闭环）**
直觉：快系统（System-1）负责“**不做危险动作**”，慢系统（System-2）负责“**理解发生了什么、为什么**”。二者用**租约（lease）**解耦：System-2 签发接地证书并给出 TTL；TTL 内 System-1 可用证书增强判断，TTL 过期则**自动回落到纯 RAS**。安全性因此不依赖 MLLM 是否按时返回——这是让大模型进入安全关键环路的前提。

**灵感 4（三灵感合流 → GRAIL）**
GRAIL 在 RAS 的六层（ERG×ACH-RAS×EFS×FRAS×C-RAS×ERS）之上插入“接地—检索—审计”三根柱子：
1. **SGL（语义接地层）**：MLLM 输出证据图 `G_t`；
2. **CBR + RAA（检索层）**：案例记忆检索 + 检索增强后验；
3. **EGC + J_GRAIL + PGR（审计层）**：证据蕴含校验 + 溯源证书 + 反事实重放。

**灵感 5（对 RAS 组件的具体升级）**
- RAS 的 `H_emotion` 归因 → **CGD**：用“表情-语言-行为”三模态 + 用户基线案例破解假笑 / 僵硬表情；
- RAS 的 `λ_risk` → **检索标定的 λ_risk**：用相似案例的真实风险结果校正系数，而不是手调 `α_risk, β_risk`；
- RAS 的 `J_RAS` → **J_GRAIL**：证书增 `retrieval_ids, evidence_spans, grounding_iou, citation_support, memory_freshness, lease_ttl`；
- RAS 的 AIC 干扰集 → **AIC-GRAIL**：新增 `ℰ_retrieval`（误检索 / 陈旧 / 毒化）与 `ℰ_hallucination`（MLLM 编造证据）。

## 1. 形式化定义（增量：定义 251–268）

- **定义 251（GRAIL 总览）**：`GRAIL = (SGL, CBR, RAA, EGC, DGL, J_GRAIL, MGM, CGD, AIC-GRAIL, PGR)`。定位：把 RAS 的“参数化意图闭环”升级为“证据接地的可审计闭环”。不变式：MLLM 前向、案例检索、后验校正、证书签发只在语义流；实时流只读带租约的接地证书，零学习写操作、零阻塞等待。
- **定义 252（多模态接地证据图）**：`G_t = (V_t, E_t, Φ_t)`，节点 `v = (type, span, conf)`（type ∈ {person, object, contact_event, expression_event, geometry_event}），边 `e = (rel, src, dst, conf)`（rel ∈ {causes, co_occurs, supports, contradicts}），`Φ_t` 为证据跨度集合（图像 bbox / 时间区间 / 曲线片段）。
- **定义 253（MLLM 语义流）**：`G_t = SGL(instruction, I_t, D_t, face_t, force_trace_t, ρ_t)`，其中 SGL 将多模态观测 token 化后以结构化 schema 生成 `G_t`。SGL 频率 `f_slow ∈ [2,5] Hz`，与实时环 `f_fast ≥ 500 Hz` 解耦。
- **定义 254（联合案例签名）**：`x_t = [ρ_t ⊕ vec(P_RAS(H,E)) ⊕ Emb(G_t)] ∈ ℝ^d`，`ρ_t` 为 VISTA 32 维残差签名，`Emb(G_t)` 为证据图嵌入。
- **定义 255（案例记忆与检索核）**：案例记忆 `M = {(x_i, y_i, s_i, age_i, r_i)}`，`y_i=(h_i,e_i)` 为联合真值标签，`s_i ∈ [0,1]` 为来源可信度，`r_i` 为历史执行结果。检索返回 `C_t = top-k_{x_i∈M} K(x_t, x_i)`，`K` 为 RBF 或学习度量核。
- **定义 256（检索权重与置信度）**：`ω_i = K(x_t,x_i)·s_i·decay(age_i) / Σ_j (...)`，`decay(age)=exp(-λ_o·age)`；检索置信 `β_t = σ(κ_m·margin_top1,top2 + κ_c·coverage)`，`margin` 为 top-1 与 top-2 核值差，`coverage` 为 top-k 覆盖的标签质量。
- **定义 257（检索增强后验）**：`P_GRAIL(H,E|x) = (1-β_t)·P_RAS(H,E|x) + β_t·Σ_i ω_i·1[(h_i,e_i)=(H,E)]`，再做归一化。当 `β_t=0` 严格退化为 RAS。
- **定义 258（证据蕴含与接地）**：断言 `a` 被证据 `e` 接地，当且仅当 `NLI(e.text ⊢ a.text) ≥ τ_entail` 且 `IoU(e.span, a.span) ≥ τ_gIoU`。`citation_support(a) = max_e support(e,a)`。
- **定义 259（接地证书）**：`GCert_t = (retrieval_ids, evidence_spans, grounding_iou, citation_support, memory_freshness, claims, issued_at, lease_ttl)`。`valid ⇔ now - issued_at < lease_ttl ∧ citation_support ≥ τ_cit`。
- **定义 260（双频租约）**：System-1 在时刻 `t` 可用 `GCert` 增强，当且仅当 `valid(GCert_t)`；否则回落到纯 `P_RAS` 与 `J_RAS`。租约过期是**单调**事件，不可被 System-1 续期。
- **定义 261（跨模态欺骗可分性）**：`deception_score = 1 - σ(w_1·consist(face, behavior) + w_2·consist(face, dialogue) + w_3·baseline_affinity(face, user))`。`deception_score > τ_dec` 时把 RAS 的 `E0` 上调为 `E3`，而非直接相信 `face`。
- **定义 262（记忆治理）**：每条案例的生命周期为 `ingest → weigh → decay → isolate → delete`。隔离条件：`s_i < τ_src` 且与多数近邻标签不一致（`|{j∈N(i): y_j=y_i}| < k/2`）。删除保留可审计 tombstone（哈希 + 时间戳）。
- **定义 263（AIC-GRAIL 干扰集）**：`ℰ_GRAIL = ℰ_RAS × ℰ_retrieval × ℰ_hallucination × ℰ_memory`，`ℰ_retrieval`={误检索, 分布漂移, 陈旧}, `ℰ_hallucination`={编造跨度, 过度概括, 证据错配}, `ℰ_memory`={投毒, 删除不彻底, 共因污染}。
- **定义 264（J_GRAIL 证书）**：`J_GRAIL = (J_RAS, GCert, provenance_graph, aic_grail_ver)`。`Valid ⇔ Valid(J_RAS) ∧ (¬valid(GCert) ∨ (citation_support ≥ τ_cit ∧ grounding_iou ≥ τ_giou))`。
- **定义 265（溯源图）**：`PGR = (Obs → G_t → C_t → P_GRAIL → k* → τ_cmd)` 的有向无环图，每条边记录证据跨度与版本哈希，支持逐边反驳。
- **定义 266（参数—检索一致性）**：`consist_param_ret = TV(P_RAS, P_ret)`（全变差距离）。若 `consist_param_ret > τ_conflict` 且 `β_t` 高，则标记冲突并强制 EGC 复核，不得静默融合。
- **定义 267（反事实重放）**：删除任一案例 `i` 后重算 `P_GRAIL^{(-i)}`，定义案例影响力 `Infl(i)=TV(P_GRAIL, P_GRAIL^{(-i)})`；`Infl(i) > τ_infl` 的案例进入人工审计队列。
- **定义 268（安全不变式）**：任何时刻执行的控制前缀必须满足 `Valid(J_GRAIL) ∨ 回落 Valid(J_RAS)`；且 `GCert` 只影响“收紧/放宽”的幅度，不得绕过 `m_ras` 不可逆视界与力/几何硬约束。

class SemanticGroundingLayer:                      # IP-234
    def ground(self, instruction, img, depth, face, force, rho):
        toks = self.tokenize(instruction, img, depth, face,
                             render_plot(force), summarize(rho))
        out = self.mllm.generate(toks, schema=EvidenceGraphSchema)
        return EvidenceGraph(nodes=out.nodes, edges=out.edges)


class CaseBasedRetriever:                          # IP-235
    def signature(self, rho, p_ras, G):
        return concat(rho, flatten(p_ras), graph_embed(G))

    def retrieve(self, x, k=8):
        ids = self.ann.search(x, k)
        return [(self.mem[i], self.kernel(x, self.mem[i].x)) for i in ids]


class RetrievalAugmentedAttribution:               # IP-236
    def posterior(self, x, p_ras, cases):
        if not cases:
            return p_ras, 0.0
        w = {i: ki * c.reliability * decay(c.age)
             for i, (c, ki) in enumerate(cases)}
        z = sum(w.values()) + 1e-9
        p_ret = defaultdict(float)
        for i, (c, _) in enumerate(cases):
            p_ret[c.label] += w[i] / z
        beta = self.confidence(cases)              # margin + coverage
        p = {lab: (1 - beta) * p_ras.get(lab, 0.0) + beta * p_ret.get(lab, 0.0)
             for lab in set(p_ras) | set(p_ret)}
        return normalize(p), beta


class EvidenceGroundingChecker:                    # IP-237
    def verify(self, claims, G, cases,
               tau_entail=0.8, tau_iou=0.5):
        kept = []
        for a in claims:
            sup = [e for e in G.facts() + case_evidence(cases)
                   if self.nli(e.text, a.text) >= tau_entail
                   and self.span_iou(e.span, a.span) >= tau_iou]
            if sup:
                kept.append((a, max(self.nli(e.text, a.text) for e in sup)))
        cit = len(kept) / max(1, len(claims))
        return kept, cit


class GracefulDualRateLoop:                        # IP-238 / IP-259
    def fast_step(self, M, obs, gcert):
        p_ras = M.ras.posterior(obs)               # 参数支路
        if gcert and gcert.valid():
            x = M.cbr.signature(obs.rho, p_ras, gcert.graph)
            p, beta = M.raa.posterior(x, p_ras, gcert.cases)
            allow_release = gcert.citation_support >= M.tau_cit
            if abs(beta - 0.5) < 0.1 and TV(p_ras, p) > M.tau_conflict:
                p, allow_release = p_ras, False    # 冲突不静默融合
        else:
            p, beta, allow_release = p_ras, 0.0, False
        k = M.csc_ras.certified_prefix(p, M.m_ras)
        lam = M.efs.risk_scale(p) * (1.0 if allow_release else M.lam_conservative)
        return k, lam, p

    def slow_step(self, M, obs):                   # 2–5 Hz, 异步
        G = M.sgl.ground(obs.instruction, obs.img, obs.depth,
                         obs.face, obs.force, obs.rho)
        x = M.cbr.signature(obs.rho, M.ras.posterior(obs), G)
        cases = M.cbr.retrieve(x, k=8)
        claims = M.sgl.propose_fault_claims(G)
        kept, cit = M.egc.verify(claims, G, cases)
        return M.issue_gcert(kept, cases, G, cit, ttl=0.5)


def GRAIL_step(M, obs, gcert):
    k, lam, p = M.loop.fast_step(M, obs, gcert)    # 每个控制 tick，<2ms
    tau = M.vista.pi_sigma.prefix_dispatch(obs.A[:k]) * lam
    if M.slow_due():
        M.loop.slow_step(M, obs)                   # 不阻塞快环
    return k, lam, p

## 3. 推导

**引理 11（检索校正的方差收缩）** 设案例 `(x_i,y_i)` 依同一分布 i.i.d. 抽样，核带宽 `h`，`β_t = β` 固定。则混合后验的风险满足
`R(P_GRAIL) ≤ (1-β)·R(P_RAS) + β·R_np(k,h) + O(β(1-β)·TV)`，
其中 `R_np → R_Bayes + O((kh^d)^{-1/2})`。故当参数先验有偏（新用户 / 长尾故障）且 `TV(P_RAS, P*)` 较大时，存在 `β*` 使混合严格优于纯参数支路；当检索不可靠（`β→0`）时安全退化为 RAS。

**引理 12（接地过滤的幻觉上界）** 设 EGC 的假接受率（把未接地断言判为接地）为 `δ_g`，MLLM 每条故障假设平均由 `m` 条断言支撑。则“至少一条未接地断言被接受”的概率满足
`P_halluc ≤ 1 - (1-δ_g)^m ≤ m·δ_g`。
取 `m=4, δ_g=0.02` 得 `P_halluc ≤ 8%`；这正是 GRAIL 要求 `citation_support` 作为硬门槛而非软特征的原因。

**定理 11（GRAIL 端到端证据有效性）** 在 RAS 假设 A87–A91 与新增假设 A92–A95（案例可代表、证据可蕴含、租约单调、毒化比例有界）下，执行指令 `τ_cmd` 满足：
1. `P(τ_cmd 无证据支撑) ≤ α_chunk + δ_fi + α_emotion + δ_retrieval + δ_ground`；
2. 当 `valid(GCert) ∧ citation_support ≥ τ_cit` 时，上界收紧为 `α_chunk + δ_fi`（检索与接地只增强、不削弱 RAS 的硬保证）；
3. 当 `¬valid(GCert)` 时，`τ_cmd` 严格等于 RAS 输出，安全性不依赖 MLLM 是否按时返回。

**定理 12（毒化鲁棒性）** 设 top-k 检索结果中至多 `f` 个被投毒（标签任意错），采用 **median-of-means** 聚合（把 k 个案例分 `g` 组取组内均值再取中位数）。若 `f < k/2`，则
`P(|P_GRAIL - E[P]| ≥ ε) ≤ exp(-2g(k/2 - f)^2 / k^2)`，
即毒化案例只能线性污染均值、无法翻转中位数。当 `k=8, f≤2`，最坏情况下错误标签的聚合权重 `≤ 1/4`，故 `β` 加权也无法把错误假设推过 `τ_fi`。

**定理 13（双频安全不变式）** System-2 仅在语义流写 `GCert`，System-1 只读且不阻塞。若 `GCert` 的租约单调过期，则实时环的最坏反应时间与 `f_slow` 无关；因此 GRAIL 在 `SGL` 超时 / 崩溃 / 输出非法时保持 RAS 的全部安全性质，只损失“个性化与可解释性”，不损失“不碰撞”。

## 6. 本轮最大风险

**一句话**：GRAIL 把“可审计”当成安全增益，但**审计链本身可被伪造**——一旦案例记忆被投毒、或 MLLM 的幻觉恰好落在 EGC 假接受率之内，系统会带着一条看似权威、引用完整的证据链执行错误归因，使得“可溯源”反而成为“更难被人类质疑的误判放行”；这正是本轮全部理论依赖的核心假设：**检索到的案例分布可代表当前情境且未被污染，且基于 NLI 的接地校验是忠实的蕴含判据**。

**次级风险与缓解**：
1. **检索污染**：来源可信度 `s_i` + median-of-means 聚合 + 影响力审计 `Infl(i) > τ_infl` 强制人工复核；
2. **幻觉证据**：EGC 要求跨度对齐 + 蕴含双门槛，并记录“被拒绝的断言”用于红队分析；
3. **分布漂移**：`consist_param_ret > τ_conflict` 时禁止静默融合，回落到参数支路；
4. **慢环延迟**：租约 TTL 兜底，System-1 永不阻塞；必要时启用本地小 MLLM 作为降级接地器；
5. **隐私**：面部与案例入库需脱敏 + 可删除 tombstone，检索只走本地加密索引。

# IP-234 SGL
class SemanticGroundingLayer:
    def ground(self, instruction, img, depth, face, force, rho):
        toks = self.tokenize(instruction, img, depth, face,
                             render_plot(force), summarize(rho))
        out = self.mllm.generate(toks, schema=EvidenceGraphSchema)

# IP-235 CBR
class CaseBasedRetriever:
    def signature(self, rho, p_ras, G):
        return concat(rho, flatten(p_ras), graph_embed(G))

    def retrieve(self, x, k=8):
        ids = self.ann.search(x, k)
        return [(self.mem[i], self.kernel(x, self.mem[i].x)) for i in ids]


# IP-236 RAA
class RetrievalAugmentedAttribution:
    def posterior(self, x, p_ras, cases):
        if not cases:
            return p_ras, 0.0
        w = {i: ki * c.reliability * decay(c.age)
             for i, (c, ki) in enumerate(cases)}
        z = sum(w.values()) + 1e-9
        p_ret = defaultdict(float)
        for i, (c, _) in enumerate(cases):
            p_ret[c.label] += w[i] / z
        beta = self.confidence(cases)
        p = {lab: (1 - beta) * p_ras.get(lab, 0.0) + beta * p_ret.get(lab, 0.0)
             for lab in set(p_ras) | set(p_ret)}
        return normalize(p), beta


# IP-237 EGC
class EvidenceGroundingChecker:
    def verify(self, claims, G, cases, tau_entail=0.8, tau_iou=0.5):
        kept = []
        for a in claims:
            sup = [e for e in G.facts() + case_evidence(cases)
                   if self.nli(e.text, a.text) >= tau_entail
                   and self.span_iou(e.span, a.span) >= tau_iou]
            if sup:
                kept.append((a, max(self.nli(e.text, a.text) for e in sup)))
        return kept, len(kept) / max(1, len(claims))


# IP-238 DGL / IP-268 安全不变式
class GracefulDualRateLoop:
    def fast_step(self, M, obs, gcert):
        p_ras = M.ras.posterior(obs)
        if gcert and gcert.valid():
            x = M.cbr.signature(obs.rho, p_ras, gcert.graph)
            p, beta = M.raa.posterior(x, p_ras, gcert.cases)
            allow_release = gcert.citation_support >= M.tau_cit
            if abs(beta - 0.5) < 0.1 and TV(p_ras, p) > M.tau_conflict:
                p, allow_release = p_ras, False
        else:
            p, beta, allow_release = p_ras, 0.0, False
        k = M.csc_ras.certified_prefix(p, M.m_ras)
        lam = M.efs.risk_scale(p) * (1.0 if allow_release else M.lam_conservative)
        return k, lam, p

    def slow_step(self, M, obs):
        G = M.sgl.ground(obs.instruction, obs.img, obs.depth,
                         obs.face, obs.force, obs.rho)
        x = M.cbr.signature(obs.rho, M.ras.posterior(obs), G)
        cases = M.cbr.retrieve(x, k=8)
        claims = M.sgl.propose_fault_claims(G)
        kept, cit = M.egc.verify(claims, G, cases)
        return M.issue_gcert(kept, cases, G, cit, ttl=0.5)

def audit_case(memory, i, grail_state):

    infl = TV(grail_state.p, p_minus)
    return {'case': i, 'influence': infl,

## 4. 推导

**引理 11（检索校正的方差收缩）** 案例 i.i.d.、核带宽 `h`、`β` 固定时，
```
R(P_GRAIL) ≤ (1-β)·R(P_RAS) + β·R_np(k,h) + O(β(1-β)·TV)
R_np → R_Bayes + O((kh^d)^{-1/2})
```
故参数先验有偏（新用户 / 长尾故障）时存在 `β*` 使混合严格优于纯参数支路；检索不可靠（`β→0`）时安全退化为 RAS。

**引理 12（接地过滤的幻觉上界）** EGC 假接受率 `δ_g`、每条假设由 `m` 条断言支撑时，
```
P_halluc ≤ 1 - (1-δ_g)^m ≤ m·δ_g
```
`m=4, δ_g=0.02 ⇒ P_halluc ≤ 8%`。这是把 `citation_support` 设为硬门槛而非软特征的原因。

**定理 11（GRAIL 端到端证据有效性）** 在 A87–A91 与新增假设 A92–A95 下：
1. `P(τ_cmd 无证据支撑) ≤ α_chunk + δ_fi + α_emotion + δ_retrieval + δ_ground`；
2. 当 `valid(GCert) ∧ citation_support ≥ τ_cit`，上界收紧为 `α_chunk + δ_fi`；
3. 当 `¬valid(GCert)`，`τ_cmd` 严格等于 RAS 输出，安全性不依赖 MLLM 是否按时返回。

**定理 12（毒化鲁棒性）** top-k 中至多 `f` 个被投毒，median-of-means 分 `g` 组聚合，若 `f < k/2`：
```
P(|P_GRAIL - E[P]| ≥ ε) ≤ exp(-2g(k/2 - f)^2 / k^2)
```
`k=8, f≤2` 时错误标签聚合权重 `≤ 1/4`，`β` 加权无法把错误假设推过 `τ_fi`。

**定理 13（双频安全不变式）** System-2 仅写 `GCert`，System-1 只读且不阻塞；租约单调过期，故实时环最坏反应时间与 `f_slow` 无关。SGL 超时/崩溃/非法输出时，GRAIL 保持 RAS 的全部安全性质，只损失“个性化与可解释性”，不损失“不碰撞”。
