# 第 11 轮（新灵感循环第 2 轮；本轮灵感：「ROS2」×「演示方案」）

> **基线**：第 10 轮 MetricVoiceGauge-STF-NRB-LS（定义 540–548；引理 87–91；实验 E571–E590）。
> 本轮纪律：**时基可信 + 演示可证伪**。两个灵感各治 v10 的一笔隐性债：
> **时基债**——v10 把证书在空间（STF）与语义（ν̄）上局部化了，却仍把「输入新鲜、彼此同时刻、没有静默丢帧、QoS 不被悄悄改配」当作未写进证书的前提；ROS2/DDS 恰恰让丢帧、截止期错过、QoS 不匹配、时钟跳变成为常态。
> **证言债**——v10 的贡献由 E571–E590 支撑，但「演示」不是科学对象：它可以是剪辑过的视频、挑过的场景、藏起来的失败，无法被第三方复核。
> 必须保持 v10 铁律：新模块失效 ⇒ 注入声明中立元，行为严格**等价**（仅审计面）或**支配**（动作集收缩）于 v10，不得行为漂移。

## 0. 直觉与动机

**灵感 1（ROS2 → 把「时间与中间件」写进证书）**
直觉：v10 的证书问的是「世界此刻是否安全」，却默认「我看到的正是此刻的世界」。但一个 50Hz 闭环里，状态、检测、电量、地图来自不同 DDS 参与者、不同 QoS、不同时钟域：BEST_EFFORT 会静默丢帧，RELIABLE 在 history 溢出时也会丢，deadline 会错过，liveliness 会丢失，参数/QoS 可被外部悄悄改配，tf 会外推，`/clock` 会跳变。这些都不是模型误差，而是**时基误差**；v10 只检查 `freshness(G_LM) ≤ 2s`，没有检查跨流偏斜、序号缺口、QoS 纪元与时钟一致性。核心创新：**时序溯源证书（Temporal Provenance Certificate, TPC）**——每条关键输入携带 `π=(src, seq, t_sample, t_pub, t_recv, clock_domain, qos_epoch, auth)`；证书 `Ĉ^‡` 的有效性显式依赖时序信任域 `U^τ`（逐流新鲜、互偏斜有界、无未声明缺口、QoS 纪元未变、时钟可信）；时基误差不再是隐含前提，而是被保守折算成余量 `β_τ = v_max·(T_fresh+T_skew) + v_obs,max·T_fresh^det + δ_clk·v_max + ε_prov`。50Hz 守卫由四检升为**五检**（新增时序溯源，O(k)≤0.2ms）。关键一步：把「新鲜」从**布尔直觉**变成**可测的溯源谓词**，把「丢帧」从**性能问题**变成**证书失效事件**。ROS2 在这里不是运行时依赖，而是**可观测契约语言**：QoS profile 被编译进契约表，DDS 事件被映射到既有退化状态。

**灵感 2（演示方案 → 可重放的证据包，而不是视频）**
直觉：研究演示最常见的失败不是系统坏了，而是**演示只证明了演示本身**：场景被挑过、失败被剪掉、指标没有预注册、第三方无法复现。把演示当科学对象，就要让每个主张都携带**可证伪谓词 + 负例卡 + 可重放溯源**。核心创新：**演示契约（Demo Contract, DC）** `D=(C,S,I,A,Θ,M,K_s)`：`C` 为映射到引理/不变式的主张集，`S` 为 ROS2 launch + world + actor 脚本，`I` 为插桩，`A` 为必选的对抗/故障卡（丢帧、时钟跳变、deadline miss、NRB 超时、对抗纹理、未授权发布者），`Θ` 为预注册阈值，`M` 为可重放清单（bag/参数/镜像/QoS 纪元/seed/执行器配置哈希），`K_s` 为安全停驻/急停条件。四条准入判据：**覆盖**（每条引理/不变式至少一正一负）、**可重放**（决策哈希或证书复核一致）、**不加权**（演示模式只许加观测、只许收缩动作，禁止 demo-only 分支）、**安全停驻**（kill switch 实测）。演示通过 = 审计器能从日志重构每张证书并复核每个主张；重放不一致 ⇒ 主张撤回为「未证明」，而不是「通过」。配套**证据台账（EvidenceLedger, Ε）**：把证书哈希、溯源根、QoS 事件根、演示 ID、主张向量串成 append-only 哈希链——运行时的证据与离线时的证据在同一根链上闭合。

**咬合**：TPC 产出**运行时证据**（这张证书凭什么成立），DC 产出**离线证据**（这条主张凭什么可信），Ε 把两者绑定为可审计的 `Ĉ^‡ = (Ĉ⁺, β_τ, π_root, qos_epoch, n_t)`。于是 v10 的「空间/语义局部化信任」升级为「空间/语义/时基三维局部化 + 可重放证据」。代价是把证书从「世界安全」弱化为「在声明时基与可审计演示下世界安全」——这个弱化是诚实的，也是可被攻击的（见第 5 节）。

## 1. 研究问题（轮次升级版）

- **Q1（时基可证）**：如何把证书有效性从隐含的「输入新鲜且同步」升级为可测的时序溯源谓词 `U^τ`，并把时基误差保守折算为 `β_τ`，使任何未声明的丢帧/偏斜/时钟故障要么在 1 帧内使证书失效，要么被膨胀余量覆盖（覆盖率 ≥99%）？
- **Q2（QoS 契约化）**：如何把 v10 的契约表编译为 ROS2 QoS profile + 生命周期状态 + 执行器配置，使每个 DDS 事件（deadline/liveliness/loss/incompatible）确定性地映射到既有退化状态，且不新增任何 v10 不可执行的物理动作？
- **Q3（演示可证伪）**：什么样的演示方案能把「演示剧场」变成「可证伪证据」——主张覆盖、负例卡、不加权、可重放四条判据如何度量，重放不一致时如何自动撤回主张？

## 2. 设计原则（在 P13–P15 基础上新增 P16–P18）

**P16 时基溯源律（Temporal Provenance, TPC）**
任何证书必须声明其时基与溯源；未测量的新鲜度、跨流偏斜、序号缺口、QoS 纪元与时钟状态不得作为前提。「没有时间戳与序号的证据不是证据」；时基误差必须进入余量 `β_τ`，时基破坏必须使证书失效而非静默沿用上一帧。

**P17 演示不加权律（Demo Non-Privilege, DC）**
演示模式只许增加可观测性、只许收缩动作空间（如限速），不得放宽任何安全/规范阈值，不得改变控制律，不得存在 demo-only 代码分支；演示参数哈希与常规参数哈希的差异必须落在白名单内并被记录。

**P18 可证伪演示律（Falsifiable Demonstration, DC）**
每条主张必须有预注册的失败谓词与至少一张负例卡；没有负例的演示不予采信；重放不一致、溯源缺口或参数哈希不符时，主张自动降级为「未证明」，绝不由演示升级为「已证明」。

## 3. 与基线的接口（如何退化）

- TPC 失效（溯源不完整/时钟不可信/新鲜度或偏斜越界）⇒ `U^τ=false` ⇒ 本块证书不可得：K_eff←1，仅用满足最严时基的本体感知做保守单步；若连停驻所需的时基都不满足 ⇒ 安全停驻。动作集 ⊆ v10（**支配**，不新增行为）；
- QCC 失效（QoS 不匹配/编译失败/事件路由超时）⇒ **fail-closed**：拒绝启动或切限制性剖面 `Π_r`；不允许「先跑起来再说」；
- DCA 失效（离线审计器不可用）⇒ 控制面不受影响（不在控制路径），但所有主张标记「未证明」；Ε 缺口 ⇒ 下块 `Π_r`（沿用 v10 引理 90）；
- STF/NRB/AC/ID/MW 沿 v10 原退化链（Level-1…Level-6）；新增安全组件 TPC/QCC/Ε 一律 `φ^elig=false` 永不消融，仅在线插桩可蒸馏。

## 4. 预期贡献

1. **时基证据证书**：把「静默丢帧/时钟跳变/QoS 改配」从不可见的性能问题变成 1 帧内可触发的证书失效，并给出 `β_τ` 的保守覆盖（引理 92–94）；
2. **QoS 编译与生命周期退化代数**：契约表 → ROS2 QoS/lifecycle 的确定性编译，DDS 事件 → 退化状态的可枚举映射，物理行为可证支配于 v10（引理 94）；
3. **可证伪演示协议**：主张覆盖 + 负例卡 + 不加权 + 可重放四判据，把演示从「视频」变成可审计证据（引理 95–98）；
4. **E591–E610** 覆盖 QoS 编译、丢帧/偏斜/时钟注入、β_τ 标定、重放一致性、负例卡、非特权、安全停驻与长跑。

## 5. 本轮最大风险

**一句话**：时序溯源与演示契约只能证明「数据按时到达、证书可被重放复核」，不能证明「数据真实、场景代表」——当 DDS 的数据通道与丢帧报告通道同源失效、或演示场景分布过窄时，系统会以更完备的证据形式把 v10 的语义风险洗白；证据越可审计，越容易让「未被覆盖的世界」看起来已经被证明。

**退化链声明（v10 六级 + 时基层 + 审计面）：**
- Level-0T：时序溯源破坏（`U^τ=false`）⇒ 本块不可得，K_eff←1 保守单步；停驻时基亦不满足 ⇒ 安全停驻；动作 ⊆ v10；
- Level-0Q：QoS 事件（deadline/liveliness/loss/incompatible/spoof）⇒ 按定义 559 映射到 `v^⊥`，生命周期 `Active→Degraded→Inactive`，事件入 `Ε`；
- Level-1：STF 失效（图不可用/嵌入超时/freshness > T_fresh）⇒ `T≡0`、K_eff←1、`β←β_base`，等价 v10 Level-1；
- Level-2：NRB 失效 ⇒ `Π_r`（v10）；
- Level-3：AC 证书失效 ⇒ K=1，等价 v10→v8 决策粒度；
- Level-4：ID 失效 ⇒ 全模块 active、归因冻结，等价 v10 全模块常开；
- Level-5：MW 失效 ⇒ 切换 v10 手写网关代码路径；
- Level-6：v8 组件失效 ⇒ 中立元注入（`Δ_dom≡0 / risk_SLAM≡0 / sensor_weight≡1`）⇒ v7 ⇒ v6；
- 审计面：DCA 不可用 ⇒ 所有主张标记「未证明」，控制面不变；`Ε` 缺口 ⇒ 下块 `Π_r`。

| `Ε` | 证据台账：扩展 `Λ` 的 append-only 哈希链，条目含证书/溯源/QoS/演示/主张向量 |
| `Mode` | 生命周期模式 `NORMAL / RESTRICTED / SAFE_STOP / REPLAY_AUDIT`；演示只在 `NORMAL` 上加观测 |

**新增定义 549（QoS 契约与编译）** 每个契约行 `m` 增 `Q_m=(rel,dur,dl,live,hist,sec)`，编译函数 `Γ: Q_m ↦ QoSProfile_m` 要求 `dl_m ≤ D_m+Ŵ_m`、`live_m ≥ 2·dl_m`；部署期用 `ros2 topic info --verbose` 与 DDS 内省比对实际 QoS，不一致即 `QCC` fail-closed（拒绝进入 `NORMAL`）。`Q_m` 与 v10 的 `(D_m,Ŵ_m,M_m,E_m,v^⊥,φ^elig)` 同表，不引入第二套预算。

**新增定义 550（溯源戳）** 对每条输入 `i∈I_t`：`π_i=(src_i,seq_i,t_i^s,t_i^p,t_i^r,clk_i,e_i,a_i)`。`seq_i` 按源单调递增；`e_i` 为 QoS 纪元哈希；`a_i` 为 SROS2 身份校验结果。缺失任一字段的输入视作「无溯源」，不得进入 `I_t`。

**新增定义 551（时序信任域）** `U_t^τ ⇔` 对所有 `i∈I_t`：`0 ≤ t−t_i^r ≤ T_fresh,i` ∧ `|t_i^s−t_j^s| ≤ T_skew` ∧ `seq_i` 无未声明缺口 ∧ `e_i=e*` ∧ 时钟监视器 `|offset|≤δ_clk` 且近 `W=50` 帧无跳变 ∧ `a_i=true`。任一不满足即 `U_t^τ=false`，且不得以「上一帧有效」替代。

**新增定义 552（时基余量；升级定义 543）** `β_τ = v_max·(T_fresh^state+T_skew) + v_obs,max·T_fresh^det + δ_clk·v_max + ε_prov`，其中 `v_max` 为本体速度上界、`v_obs,max` 为场景障碍速度上界、`ε_prov` 为溯源量化误差（E596 标定）。`ĝ_min = min_k F̂_q,clearance − β_STF − β_τ`，`ê_max = max_k F̂_q,effort + β_STF + β_τ`；`Ĉ_t^‡ valid ⇔` v10 定义 543 全条件（以 `β_STF+β_τ` 替换 `β_STF`）∧ `U_t^τ` ∧ `π_root` 可复算 ∧ `qos_epoch=e*`。

**新增定义 553（五检守卫；升级定义 547）** 50Hz 五检（O(k)，k≤8）：(i) 证书有效性（v9/v10 原检）；(ii) 停车不变式；(iii) 语义创新度 `sup ν̄≤τ_sem`；(iv) 快规范 `ν-PROX/ν-PRIV`；(v) **时序溯源**：`U_t^τ` 且 `π_root` 与当前缓存一致。任一失败 ⇒ 切最近中止点；仅检 5 失败且停驻时基也不满足 ⇒ 安全停驻。总预算 ≤0.7ms。

**新增定义 554（演示契约）** `D=(C,S,I,A,Θ,M,K_s)`：`C` 为有限主张集，每条 `c=(pred_c, scope_c, θ_c)` 是 trace 上的可判定谓词；`S` 为 ROS2 launch + world + actor 脚本 + seed；`I` 为插桩清单（topic、provenance、cert hash、claim vector）；`A` 为必选负例卡集合；`Θ` 为预注册阈值；`M` 为定义 557 的重放清单；`K_s` 为安全停驻/急停条件。`D` 缺任一字段即不合法。

**新增定义 555（覆盖矩阵与准入）** `M_cc` 把每条九不变式、引理 87–98 与核心主张映射到至少一个正例 beat 与至少一张负例 card。`A(D)=(coverage, replay, nonpriv, safestop)`，四项均为布尔；`A(D)=true` 才称「演示合格」。`coverage=1` 要求 `M_cc` 无空项；`replay` 见定义 557；`nonpriv` 见定义 556；`safestop` 要求 `K_s` 在至少一张卡中被实测触发并留痕。

**新增定义 556（演示不加权）** 设 `p_demo`、`p_norm` 为演示与常规参数向量。要求：`p_demo` 与 `p_norm` 的差异仅落在白名单 `W_obs`（日志级别、采样率、可选限速上限），且 `p_demo` 中所有安全/规范阈值与 `p_norm` 逐位相等；二进制/镜像哈希除插桩开关外一致；运行期禁止任何 `if demo_mode: <改变控制>` 分支（构建期静态检查 + 运行期参数哈希校验）。演示动作集 `A_demo ⊆ A_norm`。

**新增定义 557（重放清单与证书复核式重放）** `M=(bag_sha,param_sha,image_sha,qos_epoch,seed,clock_src,executor_cfg,world_sha)`。两种重放模式：(a) **确定性重放**：单线程执行器、虚拟时钟 `/clock`、固定 seed、规划器显式 tie-break，逐周期比对 `H_k`；(b) **证书复核式重放**：不重跑规划器，只从 bag 重建 `Ĉ_t^‡` 的输入与 `π_root`，用同一 checker 复算有效性，与在线记录比对。两种模式任一不一致 ⇒ `replay=false`，相关主张撤回为「未证明」。优先 (b)，因其不要求规划器可复现，但仍要求证书 checker 可复现。

**新增定义 558（证据台账）** `Ε` 在 v10 `Λ` 上扩条目 `(t, ζ_id, cert_hash, π_root, qos_root, demo_id, claim_vector, verdict, mode, h_prev, h_i)`，`h_i=H(h_prev‖payload)`（κ_h=256）；每 `C_w=64` 块一次链头校验点；每个演示结束时写入 `demo_id` 的 Merkle 根。缺口/校验失败 ⇒ 下块 `Π_r` 且该演示 `A(D)=false`。

**新增定义 559（QoS 事件退化代数）** 事件类 `E_Q={DEADLINE_MISSED, LIVELINESS_LOST, SAMPLE_LOST, SAMPLE_REJECTED, INCOMPATIBLE_QOS, UNAUTHORIZED_SRC, QOS_EPOCH_CHANGED}`。映射 `Δ_Q`：`SAMPLE_LOST/SAMPLE_REJECTED` 且可声明补偿 ⇒ `K=1` + 记入 loss mask（必要时抬 `β_τ`）；`DEADLINE_MISSED/LIVELINESS_LOST/UNAUTHORIZED_SRC/QOS_EPOCH_CHANGED/INCOMPATIBLE_QOS` ⇒ 立即 `Level-0T/0Q`，`Mode∈{RESTRICTED,SAFE_STOP}`。映射是全函数，且像集 ⊆ v10 已有 `v^⊥` ∪ {K=1, 安全停驻}。

**新增定义 560（插桩预算与安全停驻）** 在线插桩 ≤0.1ms/cycle、环形缓冲 ≤256KB、不得分配堆内存、不得阻塞控制线程；`K_s` 包括：控制周期超时、`U^τ` 连续 `N_s=3` 帧破坏、`Ε` 写失败、观众急停、审计器请求。演示期间 `K_s` 可达且实测留痕；`SAFE_STOP` 不依赖演示网络。

# IP-361 TemporalProvenanceCertifier：时序溯源证书器（不新增感知组件，只加戳与检查）
@dataclass(frozen=True)
class Provenance:
    src: str; seq: int
    t_sample: float; t_pub: float; t_recv: float
    clk: str; qos_epoch: str; auth_ok: bool

class TemporalProvenanceCertifier:
    def __init__(self, budgets, T_skew=0.030, delta_clk=0.001,
                 v_max=1.2, v_obs=0.8, eps_prov=0.005, W=50):
        self.budgets, self.T_skew, self.delta_clk = budgets, T_skew, delta_clk
        self.v_max, self.v_obs, self.eps_prov = v_max, v_obs, eps_prov
        self.W, self.qos_epoch = W, None
        self.seq_high = {}          # src -> 已见最大 seq
        self.clock_ok = False

    def check(self, critical: dict[str, Provenance], now: float):
        """返回 (U_tau, beta_tau, reason)。O(k)，k<=8，<=0.2ms。"""
        if not critical or any(not p.auth_ok for p in critical.values()):
            return False, 0.0, 'auth'
        if not self.clock_ok:                       # 时钟监视器未确认
            return False, 0.0, 'clock'
        for src, p in critical.items():
            if not (0.0 <= now - p.t_recv <= self.budgets[src].T_fresh):
                return False, 0.0, f'stale:{src}'
            if p.qos_epoch != self.qos_epoch:
                return False, 0.0, f'qos_epoch:{src}'
            if p.seq <= self.seq_high.get(src, -1) - 64:   # 回绕/重放/缺口
                return False, 0.0, f'seq:{src}'
        ages = [now - p.t_sample for p in critical.values()]
        if max(ages) - min(ages) > self.T_skew:
            return False, 0.0, 'skew'
        if any(self.gap(p) for p in critical.values()):
            return False, 0.0, 'gap'
        beta_tau = (self.v_max * (self.budgets['state'].T_fresh + self.T_skew)
                    + self.v_obs * self.budgets['detections'].T_fresh
                    + self.delta_clk * self.v_max + self.eps_prov)
        return True, beta_tau, 'ok'

    def gap(self, p: Provenance) -> bool:
        hi = self.seq_high.get(p.src)
        return hi is not None and p.seq > hi + 1     # 未声明缺口；缺口需走 loss_mask

class DemoContract:
    def __init__(self, claims, scenario, instrumentation, cards,
                 thresholds, manifest, kill_switch):
        self.C, self.S, self.I, self.A = claims, scenario, instrumentation, cards
        self.Theta, self.M, self.Ks = thresholds, manifest, kill_switch

class DemoContractAuditor:
    def audit(self, D: DemoContract, bag) -> dict:
        # (1) 覆盖：每条不变式/引理都有正例 beat + 负例 card
        coverage = self.coverage(D.C, D.A)
        # (2) 可重放：证书复核式重放（优先）或确定性重放
        replay_ok, replay_reason = self.replay(D.M, bag)
        # (3) 不加权：参数/镜像哈希与白名单
        nonpriv_ok = self.nonpriv(D.M, bag.param_hash, bag.image_hash)
        # (4) 安全停驻：至少一张卡触发 K_s 且留痕
        safestop_ok = self.safestop(D.Ks, bag.events)
        A = coverage and replay_ok and nonpriv_ok and safestop_ok
        return dict(admissible=A, coverage=coverage, replay=replay_ok,
                    nonpriv=nonpriv_ok, safestop=safestop_ok,
                    claims=[self.judge(c, bag) if A else 'not_demonstrated'
                            for c in D.C])

    def replay(self, M, bag):
        for cyc in bag.cycles():
            rec = bag.certificate(cyc)
            if rec.provenance_root != bag.provenance_root(cyc):
                return False, f'root_mismatch@{cyc}'
            ok, _, why = self.checker(rec, bag.provenance(cyc))
            if ok != rec.recorded_valid:
                return False, f'cert_mismatch@{cyc}:{why}'
            if bag.decision_hash(cyc) != rec.decision_hash:
                return False, f'decision_mismatch@{cyc}'
        return True, 'ok'


# IP-365（升级）：证据携带证书分块执行器
class EvidenceCarryingCertifier(StructuredChunkCertifier):
    def generate_chunk(self, state, ctx, stf, nrb, tpc):
        ok, beta_tau, why = tpc.check(ctx.critical, ctx.now)
        if not ok:                                   # Level-0T：不生成块
            return self._single_step_fallback(state) # 或 safe_stop（停驻时基亦坏）
        K = self.effective_K(ctx.delta_dom, ctx.tau_dom,
                             trust_ok=stf.trust_ok(ctx),
                             temporal_ok=ok)
        if K == 1:
            return self._single_step_fallback(state)
        best = None
        for cand in self.policy.sample_sequences(state, K, n=64):
            pred = self.Fq.rollout(state, cand)
            beta_stf = (self.beta_base
                        + self.lam * stf.field_on_footprint(pred.corridor))
            beta = beta_stf + beta_tau
            g_min = pred.min_clearance - beta
            e_max = pred.max_effort + beta
            if g_min < self.d_safe or e_max > state.tau_eff:
                continue
            pts = self._abort_points(state, cand, pred)
            if not pts:
                continue
            cert = CertPlus(g_min, e_max, beta_stf, beta_tau,
                            prov_root=ctx.prov_root, qos_epoch=ctx.qos_epoch)
            chunk = Chunk(cand, cert, pts)
            chunk, verdict = nrb.review_chunk(chunk, stf, ctx)
            if chunk is None:
                continue
            score = self.policy.score(chunk, pred)
            if best is None or score > best.score:
                best = chunk
        return best or self._single_step_fallback(state)

    def midchunk_guard(self, chunk, k_exec, live_obs, stf, nrb, tpc):
        """50Hz 五检 <=0.7ms；返回 ('continue', k+1) 或 ('abort', p*) / ('stop', None)"""
        if not chunk.cert_still_valid(live_obs):            # 检 1
            return self._nearest_abort(chunk, k_exec)
        stop_inv = (live_obs.nearest_clearance
                    - self.d_brake(live_obs.speed) - self.d_safe)
        if stop_inv < chunk.remaining_len(k_exec):          # 检 2
            return self._nearest_abort(chunk, k_exec)
        if stf.surprise_near(live_obs.pose) > stf.tau_sem:  # 检 3
            return self._nearest_abort(chunk, k_exec)
        if nrb.fast_norms(live_obs).violated:               # 检 4
            return self._nearest_abort(chunk, k_exec)
        ok, _, why = tpc.check(live_obs.provenance, live_obs.now)  # 检 5
        if not ok:
            if not tpc.stop_feasible(live_obs):
                return ('stop', None)
            return self._nearest_abort(chunk, k_exec)
        return ('continue', k_exec + 1)

## 4. 推导

**引理 92（时基保守性与证书有效性）** 设 (A1) `U_t^τ` 成立：关键输入逐流新鲜、互偏斜 ≤`T_skew`、时钟误差 ≤`δ_clk`、无未声明缺口；(A2) 本体速度 ≤`v_max`、障碍速度 ≤`v_obs,max`；(A3) `β_τ` 按定义 552 取上界。则对执行中任意时刻，真实相对位姿与证书所用估计的相对位姿之差 ≤ `β_τ`；若 `Ĉ_t^‡ valid`（`ĝ_min≥d_safe`、`ê_max≤τ_eff`），则真实间隙 ≥`d_safe`、真实出力 ≤`τ_eff`（在 v10 引理 82 的模型/语义假设下）。证明：新鲜度与偏斜界 ⇒ 本体在采样到执行间位移 ≤`v_max·(T_fresh+T_skew)`；障碍位移 ≤`v_obs,max·T_fresh^det`；时钟误差贡献 ≤`δ_clk·v_max`；溯源量化余 `ε_prov`。三角不等式合并得相对位姿误差上界，代入 `ĝ_min/ê_max` 即得。注意：这是**保守**界，未利用相关性；E596 用于收紧。∎

**引理 93（静默丢帧不可穿过证书）** 设每源有单调 `seq`，且 DDS 的 `SAMPLE_LOST/SAMPLE_REJECTED` 统计与 `DEADLINE/LIVELINESS` 事件可被订阅并写入 `Ε`（定义 558–559）。则任一未声明丢帧必表现为：`seq` 缺口（检 5 的 `gap`）或丢帧统计增量/事件（`Δ_Q`）；二者均使 `U_t^τ=false` 或进入对应 `v^⊥`。若丢帧被显式列入 loss mask，则相应流的 `β_τ` 按缺失窗口膨胀，证书只在膨胀后仍满足 `ĝ_min≥d_safe` 时有效。故不存在「在未声明丢帧上仍 valid」的 `Ĉ_t^‡`。证明：按「数据到达但丢统计丢失」「统计到达但数据丢」「两者同时丢」三类做情形分析；前两类由定义 551/559 直接覆盖，第三类退化为引理 94 的故障面（见风险）。∎

**引理 94（QoS 事件退化支配）** 定义 559 的映射 `Δ_Q` 是全函数，且像集 ⊆ `{K=1, Π_r, SAFE_STOP}` ∪ v10 已有 `v^⊥`。任何事件只导致：证书失效、动作集收缩、或安全停驻；不新增动作、不放宽阈值、不改变控制律。故 v11 在任意 QoS 事件下的物理行为集合 ⊆ v10 可行集（**支配**，非等价，因 v10 可能继续用旧数据）。证明：枚举 `E_Q` 七个事件，逐项对照定义 559 与 v10 退化链；检 1–5 均只会 abort/stop，不产生新候选。∎

**引理 95（重放的单侧可靠性）** 设重放清单 `M` 完整（bag 含全部输入、溯源戳、QoS 事件、参数/镜像哈希、时钟源），且审计器使用与在线相同的 checker。则：(i) 确定性重放模式下，逐周期 `H_k` 一致 ⇒ 在线与重放的证书判定相同；(ii) 证书复核模式下，`π_root` 复算一致且 checker 复算一致 ⇒ 该证书在记录输入上确实有效；(iii) 任一不一致或缺失 ⇒ 该周期/主张标记「未证明」。因此演示只能把主张从「未证明」升级为「在该 trace 上成立」，绝不会把「实际不成立」升级为「成立」（在哈希碰撞与日志未被篡改的假设下，概率 ≥1−2^{−256}）。证明：对周期归纳；哈希链保证前缀不可改；checker 是确定性函数。注意：单侧性只针对「记录下来的 trace」，不针对真实世界。∎

**引理 96（演示合格 ⇒ 结构可证伪）** 若 `A(D)=true`（覆盖、可重放、不加权、安全停驻），则对每条主张 `c∈C`：存在预注册失败谓词 `¬pred_c` 与至少一张负例卡 `a_c∈A`，使得若对应机制失效，`a_c` 的可观测结果应使 `pred_c=false`；且任何试图在演示中隐藏该失败的行为，要么造成 `coverage` 空缺，要么造成 `replay` 不一致，要么违反 `nonpriv`，三者任一都使 `A(D)=false`。故合格演示的通过不能被「剪辑/挑场景/特权控制」单独制造。证明：由 `M_cc` 的覆盖定义与 `A(D)` 四判据直接展开；`nonpriv` 排除特权控制，`replay` 排除事后剪辑，`coverage` 排除只演成功路径。限定：覆盖是**主张层**的，不是**世界分布层**的（见风险）。∎

**引理 97（证据台账完整性与演示绑定）** `Ε` 的 256 位哈希链 + 每 64 块链头校验点 + 每演示 Merkle 根绑定，使对历史证书/QoS 事件/主张向量的任何删除或改写以 ≥1−2^{−256} 概率被离线复盘检出；缺口至多存续 64 块即触发 `Π_r`；演示根与在线证书根不一致 ⇒ 该演示 `A(D)=false`。写开销 ≤0.1ms/块边界，摊销 O(1)。证明：同 v10 引理 90，增加 Merkle 根的分支绑定；碰撞概率界标准。∎

**引理 98（演示不加权保持控制律等价）** 在 `nonpriv=true` 下，演示模式相对常规模式只增加只读插桩（不进入控制输入）并至多收缩动作集（限速/禁某些候选）；因此任一在演示中执行的动作在常规模式下同样可执行。演示性能差异只能来自插桩开销（由定义 560 的预算界定），不能来自特权控制。证明：参数哈希逐位相等 + 动作集包含关系 + 插桩只写日志；对 `if demo_mode` 分支做静态检查。∎

## 7. 演示方案（可执行脚本，而非视频）

**D1 · 90 秒主线（每拍对应一张证书/一条主张）**
1. *0–10s*：正常块执行，语音披露「已获得 0.8s 安全块」；主张 `cert_valid ∧ n_t pass`。
2. *10–25s*：助手突然横穿，STF 语义惊喜触发检 3；主张「1 帧内切最近中止点」。
3. *25–40s*：观众放置带姓名标签的个人物品，NRB 的 `ν-PROP` 软规范触发 `r₂` 重定向 + 语音请求 claim；主张「未擅动 + 留痕」。
4. *40–55s*：观众抽「丢帧卡」（注入 200ms 检测丢帧）；检 5 使证书失效，K=1 或安全停驻；主张「0 例 valid on loss」。
5. *55–70s*：观众抽「时钟跳变卡」（+100ms）；`U^τ` 失效，进入 `SAFE_STOP`；主张「跳变后 ≤1 帧停驻」。
6. *70–90s*：切 `REPLAY_AUDIT`，审计器从 bag 复算 `π_root`/证书/主张向量；大屏显示 `A(D)=true` 与哈希链。

**D2 · 10 分钟压力演示（负例卡为必选，不是可选）**

| 卡 | 注入 | 预期可观测 | 对应主张 |
|---|---|---|---|
| C1 丢帧 | `/detections` 丢 200ms | 检 5 → K=1/安全停驻 | 引理 93 |
| C2 时钟跳变 | `/clock` +100ms | `U^τ` 失效 → `SAFE_STOP` | 引理 92、94 |
| C3 deadline miss | `/state` 发布阻塞 100ms | deadline 事件 → `RESTRICTED` | 定义 559 |
| C4 NRB 超时 | 冻结 NRB 1s | `Π_r` 1 块内生效 | v10 引理 89 |
| C5 对抗纹理 | 投影对抗纹理 | 检 3 不响则回退 Δ_dom 标量门控（E589） | v10 风险显式暴露 |
| C6 未授权发布 | 冒充 `/cmd` 源 | 认证失败 → 拒绝 + `Ε` 留痕 | 定义 550、559 |

**D3 · 取证重放**：取 D2 的 bag，审计器先给出 `A(D)=true`；随后人为翻转日志中 1 字节，审计器必须报 `root_mismatch` 并把相关主张降为「未证明」；再把演示镜像换回基线，审计通过。该拍专门演示**证据可被攻击、且攻击会被记录**。

**非特权自检**：`p_demo` 与 `p_norm` 的哈希在大屏并列显示，差异仅 `log_level` 与可选 `v_cap`；`v_cap` 只收缩动作集。观众可现场要求去掉 `v_cap` 重跑，主张不得改变。

## 9. 本轮最大风险

**一句话**：时序溯源与演示契约只能证明「数据按时到达、证书可被重放复核」，不能证明「数据真实、场景代表」——当 DDS 的数据通道与丢帧报告通道同源失效、或演示场景分布过窄时，系统会以更完备的证据形式把 v10 的语义风险洗白；证据越可审计，越容易让「未被覆盖的世界」看起来已经被证明。
