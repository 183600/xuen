# 第 70 轮（承接第 69 轮「FLUID-RAS 不确定性二分与主动交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「虚拟仿真」×「演示方案」）

> R69 让系统学会了「问」：把不确定性拆成 aleatoric / epistemic，用流匹配策略把歧义显式化成多个模态，再用「看 / 问 / 触」这类信息动作去消解。但它留下一个尚未回答的问题：**在下一次真实交互之前，系统凭什么相信自己对「交互会带来什么」的预测？** R69 的 VoI 是在策略自己的世界模型里算的——那是系统自己的想象。若这个想象有偏，系统会自信地去追问一个幻影，或把一个误导性回答盖章「已验证」。R69 自陈的最大风险，正是「模态分布不可信」。
>
> 本轮两个灵感恰好构成一对张力：
> - **虚拟仿真**提供「先彩排、再上台」的安全沙盒——在真实世界付出代价之前，先把候选假设、信息动作、风险后果预演一遍；
> - **演示方案**提供「上台验收」的证伪协议——但演示一旦被当成展示，就会退化为精心挑选的成功案例秀。
>
> 核心命题：**把「思考」与「证明」分开。仿真用于彩排（筛选、预演、发现不可行），但彩排不构成证据；证据必须来自一次不可被仿真吸收的现实锚点，以及一场由对手出题、预注册、含阴性对照、能失败的演示。** 命名 **REHEARSE-RAS**（Rehearsal-based Epistemic Hypothesis Evaluation with Adversarial Reality-anchored Simulation & Examination）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我的想象可信吗，又该如何在首演夜证明它不是彩排的重复**」。

## 0. 直觉与动机

**灵感 1（虚拟仿真 → 先彩排，后上台）**
直觉：R69 的第一步就是真实交互，代价与风险在接触的瞬间已经支付。人类不这样做——外科医生先在模拟器上练，飞行员先在飞行模拟器里飞，工程师先在数字孪生里跑。仿真的全部意义，是把「试错的代价」从物理世界搬到比特世界：在真实世界付账之前，先在虚拟世界把账算一遍。
严谨：仿真器族 {Ŝ_j} 为每个候选 (g, m_k) 给出预测观测分布，于是 VoI 可以在**动作之前**被估计、风险可以在**接触之前**被筛掉。但必须加一条硬限定：仿真只改变「哪些候选值得真实执行」的**排序**，不改变「最终必须核对现实」的**地位**（定义 310-iv）。

**灵感 2（仿真是镜子，不是神谕 → 自洽 ≠ 正确）**
直觉：如果仿真器和策略共享同一个世界模型（例如都从 VISTA / MTM trunk 长出），那么「仿真里一切自洽」只是「我同意我自己」。R69 已经用流似然 Δa 对抗「标定吸收」；R70 面对的是更隐蔽的「**仿真吸收**」——仿真会把策略的错误当作世界的规律学进去。一个能完美复现你偏见的沙盒，是最危险的沙盒。
严谨：定义仿真-现实散度 Δ_sim 与仿真可信度 κ；只有经**独立现实锚点**校正的仿真才可用于决策。这引出「证伪栈」的第三层：传感器自洽 → 行为自洽 → **世界自洽**，每一层都可能被下一层「吸收」，所以每一层都需要一个不能被吸收的外部锚点（定义 325–326）。

**灵感 3（可证伪模态 → 幻影模态的判据）**
直觉：R69 的「幻影模态」是一个没有现实后果的假设。科学哲学给了一个干净判据：**一个假设只有在能做出差异化预测时才算数**。若两个模态在任何可执行的信息动作下都产生不可区分的观测，那么「区分它们」这件事在物理上就没有信息量——追问它只花预算、不涨知识。
严谨：定义可证伪模态判据 FMC：m_k 可证伪 ⇔ 存在信息动作 g 使仿真可分性 R_sim(m_k, m_{k'}) ≥ ρ_min，且该区分方向不被现实锚点反转（δ_R 小）。不可证伪模态从 VoI 中剔除，权重并入「未知」而非「已消解」。

**灵感 4（演示方案 → 对手出题、预注册、能失败）**
直觉：R69 的 VQAuditor 产出证书，但证书证明的是「系统自认为如何」，不是「系统在未知场景下如何」。真正的验收像临床试验 / 药物审批：先预注册假设与停止规则，再让独立对手构造最可能拆穿声明的场景，并且必须含**阴性对照**——否则一场永远通过的考试什么也没测到。演示的价值不在「好看」，而在「可能失败」。
严谨：演示方案 D = (𝒞, A, π_D, S)。A 是对抗挑战生成器，最大化声明与真实分布的可分性；π_D 预注册样本量与停止规则；S 是在被测版本冻结并哈希后公布的公开随机承诺。演示不是 showcase，是 **falsification test**（定义 314–316）。

**灵感 5（演示的 Goodhart 风险 → 训练即污染）**
直觉：一旦「通过演示」成为目标，系统（以及它的开发者）就会把演示集当成训练集。演示越重要，越容易被优化成表演。这不是恶意，是 Goodhart 定律：指标一旦成为目标，就不再是好指标。一个只报喜的演示方案，比没有演示更危险，因为它会制造「已被验证」的错觉。
严谨：演示独立性门 HGD——版本独立、预注册、周期性旋转、留出集不复用；用 overfit ratio 与 demo-realization gap 实时监控。任何进入证书或对外声明的演示若违反独立性，在 J 中记为无效（定义 315、定理 20）。演示的诚实性不是道德约束，而是证书可被采信的技术前提。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（REHEARSE-RAS 总览）** REHEARSE-RAS = (VSR, RAD, FMC, DAP, NCD, HGD, RAS-WM‡)。五不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **预算硬约束**：交互 ≤ 1 次/单位时间、彩排 ≤ B_sim、演示仅发布/周期门（继承并扩展定义 293-ii）；
(iii) **证据纪律**：单次交互/单模态回答不得单独定案（继承定义 293-iii）；
(iv) **彩排非证据**：仿真结果只可用于筛选与预测，不得单独作为消歧证据；最终必须由现实锚点或正交现实证据确认；
(v) **演示独立性**：任何进入证书或对外声明的演示，必须版本独立、预注册、含阴性对照、周期旋转。

**定义 311（虚拟仿真彩排 VSR）** 仿真器族 Ŝ = {Ŝ_j}_{j=1..J}，Ŝ_j : (o_t, ξ_{t:t+H}) → p(ŷ | o_t, ξ)。彩排对候选 (g, m_k) 采样得：
- 仿真可分性 R_sim(i,j) = W₂(p(ŷ_i), p(ŷ_j)) / (σ_i + σ_j)；
- 仿真信息增益 VoI_sim(g) = H(M|o) − E_{ŷ~Ŝ}[H(M|o,ŷ)]；
- 仿真风险 Risk_sim(ξ) = P_Ŝ(违反安全包络)。
多样性来自不同归纳偏置 / 物理参数 / 数据切片，而非仅随机种子——种子多样性只降方差，不降相关偏置。

**定义 312（仿真-现实散度 RAD）** 现实锚点集 𝒜 = {a_l}，单锚点成本远低于一次完整交互。Δ_sim = D(p_sim(ŷ|g), p_real(y|g))（锚点处），仿真可信度 κ = exp(−Δ_sim/τ_sim)。用 Δ_sim 对仿真做锚定校正得 p̃_sim。κ < κ_min ⇒ 禁用彩排通道，退化为 R69。

**定义 313（可证伪模态判据 FMC）** m_k 可证伪 ⇔ ∃g : R_sim(m_k, m_{k'}) ≥ ρ_min 且 δ_R = |R_sim − R_real| < ρ_R。不可证伪 ⇒ 从 VoI 移除，其权重并入「未消解未知」，绝不当作「已消解」。

**定义 314（演示方案 DAP）** D = (𝒞, A, π_D, S)：𝒞 为可检验声明；A 为对抗挑战生成器，A* = argmax_A E_{c~A}[D_KL(P_real(·|c) ‖ P_claim(·))]，s.t. c ∈ Ω_real；π_D 为预注册评估协议（样本量、停止规则、统计检验）；S 为版本冻结后的公开随机承诺。

**定义 315（演示独立性门 HGD）** I1 版本独立（被测策略已冻结并哈希）；I2 预注册（𝒞 与 π_D 先于结果）；I3 旋转新鲜度（挑战集按 T_rot 更新，历史集不得复用为新证据）；I4 阴性对照。监控 g_demo = |sim 预期成功率 − 实测成功率|、overfit ratio = 演示集表现 / 旋转留出集表现。违反 ⇒ 演示结论在 J 中无效。

**定义 316（阴性对照与检验效力 NCD）** 每批演示含 n_neg 个「应失败」对照。power = P(检出已知失败 | 阴性对照)。power < π_min ⇒ 该批演示无信息量，不得作为「系统有效」的证据。这是科学实验 assay validity 的直接移植。

**定义 317（彩排-现实交接）** 彩排只做两件事：筛掉 Risk_sim 越界或 VoI_sim ≤ c 的候选；对保留候选预计算后验。最终消歧仍需现实锚点/正交证据（定义 310-iv）。若仿真与现实的候选排序反转（rank inversion），以现实为准并下调 κ。

**定义 318（仿真投毒与后门 ℰ_sim）** 威胁：对抗性仿真环境、仿真器后门、仿真数据投毒、借现实锚点反向注入的「演示工程」。ℰ_REH = ℰ_FLUID × ℰ_sim × ℰ_demo，并入 AIC。

**定义 319（证书 J_REH）** J_REH = (J_FLUID, κ, Δ_sim_p95, demo_commitment, pre_reg_hash, power_ncd, demo_realization_gap, rotation_id, rehearse_ver)。Valid ⇔ Valid(J_FLUID) ∧ κ ≥ κ_min ∧ power ≥ π_min ∧ HGD 通过。

**定义 320（三级严格退避）** 彩排可信且消歧成功 → 正常执行（同 R69 的 resolution bonus）；彩排不可信 / 演示无效 → 退化为 R69；R69 的交互也不可信 / 被投毒 → 退化为 R68。⇒ R68 ⊂ R69 ⊂ R70，安全侧单调不降。

**定义 321（演示作为对人类的信息动作）** 对外演示可视为针对监督者的信息动作 g_demo，目标是降低人类对系统可信度的不确定性：max VoI_human(g_demo) − c_demo，s.t. 独立性 + 阴性对照完整性 + 不得选择性隐藏阴性结果。演示由营销问题变成受约束的信息设计问题。

**定义 322（彩排预算分配 RBA）** rehearse* = argmax_h [预期减少的真实交互成本 + 预期避免风险 − 彩排成本]，h 遍历 top-2 模态与最高风险动作。默认只彩排 top-2 模态 + 1 个最高风险动作。

**定义 323（仿真/现实可分性对偶）** δ_R = |R_sim − R_real|。δ_R 大 ⇒ 仿真「幻觉可分」，会诱导系统追问现实不可分的幻影。δ_R 由锚点估计，作为 FMC 门控。

**定义 324（演示序贯检验 SPRT）** H0「声明成立」vs H1「声明不成立」，对数似然比累积到边界即停，控制 α/β。停止规则预注册，防「多跑几次直到通过」的 p-hacking。

**定义 325（仿真不可吸收性）** 若仿真器与策略共享偏置，策略错误在仿真中「自洽」，Δ_sim 也可能很小（同谋）。因此 κ 必须由**独立**锚点估计，正如 R69 的 Δa 必须由独立于标定层的似然通道给出。**自洽不能替代一次外部核对。**

**定义 326（统一证伪栈）** 三层：传感器自洽（R68 残差 r_res）→ 行为自洽（R69 流似然 Δa）→ 世界自洽（R70 的 Δ_sim 与演示阴性对照）。每层都可能被下一层「吸收」，故每层都要一个不能被吸收的外部锚点。方法论：**证伪层级越高，越依赖外部现实，而不是更强的内部一致性。**

# IP-264 VSR：潜在仿真彩排（轻量 recurrent latent sim；仅 U_epi 高时触发）
class VirtualSimulator:
    def rehearse(self, modes, o_t, top=2):
        out = []
        for m in rank(modes)[:top]:
            for g in info_action_candidates(m):
                ys = [sim_j.rollout(o_t, (m.a, g)) for sim_j in self.ensemble]
                out.append(dict(m=m, g=g,
                                R_sim=sep(ys),                        # 定义311
                                voi_sim=entropy(modes.w) - exp_entropy(ys),
                                risk_sim=max(violation(s, g, o_t) for s in self.ensemble)))
        return out

    def risk_ok(self, g):
        return all(violation(s, g, self.o_t) <= EPS_INT for s in self.ensemble)

# IP-265 RAD：用少量现实锚点估计仿真可信度
def anchor_calibrate(rehearsals, anchors):
    dsim = mean(kl(p_sim(anchor), p_real(anchor)) for anchor in anchors)
    return exp(-dsim / TAU_SIM), dsim                # κ, Δ_sim

# IP-266 FMC：剔除不可证伪（幻影）模态
def falsifiable_filter(modes, sim, rad):
    keep = []
    for i, j in combinations(range(len(modes)), 2):
        if sim.R_sim(i, j) >= RHO_MIN and rad.delta_R(i, j) < RHO_R:
            keep += [i, j]
    return unique(keep) or modes[:1]                  # 全不可分 → 只留最保守模态

# IP-268 DAP：对手生成可失败的演示
def build_demo(claim, version_hash, rot_id):
    commit = H(version_hash, claim, rot_id, now())    # 预注册 + 承诺
    A = AdversarialChallenge(Omega_real, target=claim, seed=commit)
    return commit, [A.sample() for _ in range(n_scenarios)]

# IP-269 NCD：阴性对照的检验效力
def power(res):
    return mean(res.detected_failure for res in res.negative_controls)

# IP-274 主闭环（R69 + 彩排预筛 + 演示验收）
def REHEARSE_round(M, obs):
    z, o = M.mtm.forward(...)
    c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z)
    modes = M.fmc.filter(modes, M.vsr, M.rad)          # 幻影模态出局
    # 1) 彩排：只筛候选，不定案
    plan = M.rba.allocate(modes)                       # 定义322
    reh  = M.vsr.rehearse(plan, o)
    kappa, dsim = M.rad.anchor_calibrate(reh, M.anchors)
    if kappa < KAPPA_MIN:                              # 仿真不可信 → R69
        return FLUID_round(M, obs)
    g = M.mint.choose_interaction(modes, reh, M.budget) # VoI_sim 预筛
    if g is not None and not M.vsr.risk_ok(g):
        g = None
    # 2) 现实核对（锚点/一次交互）；彩排本身不作证据
    answer = M.cia.execute(g) if g is not None else None
    U_epi_after = M.cia.update_belief(modes, answer) if answer else U_epi
    U_floor = U_ale + (U_epi_after if answer is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(...)
    if dsim > TAU_SIM:                                 # 仿真-现实背离 → 更保守
        lam = max(lam, 0.8); k = min(k, k_cal_shrink(...))
    mode = select_mode(modes, U_epi_after, lam)
    return k, lam, mode, (U_ale, U_epi_after)

# IP-274 发布/周期验收：对手出题、预注册、含阴性对照、SPRT
def demonstration_gate(M, claim):
    commit, suite = M.dap.build_demo(claim, M.version_hash, M.rotation_id)
    res = M.sprt.run(suite, M)                         # 定义324
    ok = (M.ncd.power(res) >= PI_MIN) and M.hgd.independent(res, commit)
    J  = M.jreh.issue(M, kappa=M.last_kappa, dsim=M.last_dsim,
                      power=M.ncd.power(res), demo_gap=res.gap,
                      commit=commit, rotation=M.rotation_id)
    return ok and Valid(J), J

## 3. 推导

**引理 19（仿真-策略同谋）** 记策略误差 e_π、仿真误差 e_sim，相关系数 ρ。仿真能检出策略错误的概率 P_det ≤ Φ((δ − ρ·e_π) / √(1−ρ²)·σ_sim)。当 ρ → 1，P_det 退化为与策略误差无关的常数——仿真对策略错误「失明」。系：增加独立仿真器只降方差，不降相关偏置；降偏置必须靠与策略误差近独立的现实锚点（ρ_anchor ≈ 0）。

**引理 20（可证伪模态剔除的单调安全）** 对不可证伪模态 m_k（δ_R ≥ ρ_R 或 R_sim < ρ_min），将其纳入 VoI 会以正概率把交互预算花在不可辨识量上，并抬高「虚假消解」概率；剔除 m_k 使期望后悔不增，且不降低真实模态的保留概率。故 FMC 在安全侧单调。

**引理 21（无阴性对照的演示检验效力为零）** 若演示不含已知失败对照，则在「系统真实失效」与「考试本身测不出失效」两种世界下观测分布相同，power ≡ 0，演示通过不提供任何证据。含 n_neg 个独立阴性对照时，power ≥ 1 − β^{n_neg}。系：**能失败的演示才是证据，必过的演示只是仪式。**

**定理 18（三级严格包含）** 在 A95–A99 下，REHEARSE 的期望风险 ≤ FLUID ≤ CALM；当 κ < κ_min 时 REHEARSE 逐指令等于 FLUID；当 κ < κ_min 且 R69 的退化条件（VoI ≤ c / ECE 越界）成立时逐指令等于 CALM。⇒ R68 ⊂ R69 ⊂ R70，安全侧单调不降。

**定理 19（彩排预筛的增益与界限）** 设 κ ≥ κ_min 保证 Δ_sim ≤ τ_sim。彩排预筛使真实交互次数与真实风险 ≤ R69（筛掉越界/无利候选），消歧成功率相对 R69 的损失 ≤ O(Δ_sim)；一旦仿真与现实排序反转，RAD 下调 κ 并触发回退，故最坏情形不劣于 R69。

**定理 20（Goodhart 与旋转界）** 在 I1–I4 下，若挑战集按 T_rot 旋转且留出集不复用，则 overfit ratio ≤ 1 + O(√(log(1/δ)/n_hold))（无分布漂移时）；若演示集被复用，overfit ratio 无上界，证书不得声称泛化。⇒ 演示的诚实性是证书可被采信的技术前提，而非道德修饰。

## 4. 推导

**引理 19（仿真-策略同谋）** 策略误差 e_π、仿真误差 e_sim 相关系数 ρ；仿真检出概率 `P_det ≤ Φ((δ−ρ·e_π)/√(1−ρ²)σ_sim)`。ρ→1 时仿真对策略错误失明。系：加独立仿真器只降方差，降偏置必须靠与策略误差近独立的现实锚点。

**引理 20（FMC 单调安全）** 不可证伪模态纳入 VoI 会以正概率把预算花在不可辨识量上并抬高虚假消解概率；剔除后期望后悔不增，真模态保留概率不降。

**引理 21（无阴性对照 ⇒ 效力为零）** 无已知失败对照时，「真实失效」与「考试测不出失效」观测同分布，power≡0；含 n_neg 独立对照时 power ≥ 1−β^{n_neg}。**能失败的演示才是证据。**

**定理 18（三级严格包含）** A95–A99 下 REHEARSE 期望风险 ≤ FLUID ≤ CALM；κ<κ_min 时逐指令等于 FLUID；κ<κ_min 且 R69 退化条件成立时逐指令等于 CALM。R68⊂R69⊂R70。

**定理 19（彩排预筛增益与界限）** κ≥κ_min（Δ_sim≤τ_sim）时，真实交互次数与风险 ≤ R69，消歧成功率损失 ≤ O(Δ_sim)；排序反转时 RAD 下调 κ 并回退，最坏不劣于 R69。

**定理 20（Goodhart 与旋转界）** I1–I4 下，旋转且不复用留出集时 `overfit ratio ≤ 1+O(√(log(1/δ)/n_hold))`；复用则无上界，证书不得声称泛化。演示诚实性是采信前提。

**次级风险与缓解**：仿真-现实散度被低估（锚点须与策略/仿真误差近独立 + 多锚点交叉 + E301/E305）；Goodhart/演示工程（HGD 预注册 + 版本冻结承诺 + T_rot 旋转 + 留出集不复用 + E308）；演示无信息量（NCD 效力门 + 引理 21 + E307）；彩排开销击穿实时预算（RBA top-2 + κ 门控 + E312）；对抗性仿真投毒（ℰ_sim 并入 AIC + 多仿真器一致 + 锚点异常检测 + E313）。
