# 第 10 轮（承接第 9 轮 v9；本轮灵感：「地形适应」×「伦理审查」）

> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> **本轮纪律**：**地形包络 + 规范授权 + 有向退化**。两个灵感共同戳破 v9 的一个默认假设：系统是在「标称物理世界 + 标称规范世界」里被证明安全的。地形适应说物理包络是时变的（摩擦、坡度、可变形、粗糙度），伦理审查说规范包络也是时变的（同意、监督、可授权范围）。v10 把两者统一为**双包络**问题：物理证书 Ĉ 与规范证书 Â 必须在提交前同时成立；任一失效即**失败关闭**（安全停驻），而非注入中立元继续运行。

## 0. 直觉与动机

**灵感 1（地形适应 → 地形条件化证书）**
直觉：v9 的 ActionChunkCertifier 把刹车距离写成 `d_brake(v)=v²/(2a)` 的常数减速度，隐含「高摩擦、平地、刚性地面」。真实地面会打滑、下坡、下陷。地形适应不是换一个 locomotion 控制器，而是**让证书随地形参数实时收缩**：由本体感知在线估计 θ=(μ,α,κ,ρ) 的置信区间，取区间最坏端计算刹车距离与可达速度——「地面越不确定，中止点越保守、块越短」。附带关键耦合：滑移使轮式里程计漂移，位姿不确定性上升，应直接抬升 risk_SLAM；地形陌生度于是经由 v9 门控自动把 K_eff 压到 1。核心创新：**地形包络估计器（TEE）** + **地形条件化停车不变式（TRC，升级 AC）**。

**灵感 2（伦理审查 → 规范证书与双钥提交）**
直觉：伦理审查在工程上常被写成事后日志或人工免责声明，这不够。严谨做法是把它变成**提交路径上的一道硬门**：每个动作块提交前必须持有一张**授权见证 Â**（谁、在什么范围、到什么时候、针对哪个情境哈希批准了它）。与物理证书不同，规范模块没有「安全的中立元」：审查超时的正确退化不是「假设批准」（那等于放行），而是**拒绝提交并安全停驻**。核心创新：**伦理审查门（ERG）** + **双钥提交（NI）**。关键工程细节：授权可按「任务级常驻授权 + 物质变化即撤销」摊销，否则 50Hz 逐动作审查不可行；但撤销必须是同步的廉价检查，不能依赖被审查的感知模块。

**灵感 3（两者合成的真正新意：单向适应）**
直觉：两个灵感不是并列的两个模块，而是同一治理问题的两面。地形适应会让系统**自动修改自己的安全参数**（限速、刹车余量）；伦理审查真正该审的对象恰恰是这种自修改。于是规定：**自主适应只能在预授权包络 E_auth 内变动，任何越过 E_auth 的放松都必须持有授权见证**（P13 单向地形适应律）。这把「地形适应」从性能优化变成安全单调算子，也把「伦理审查」从动作级审批上移为对系统自我修改的审批——审查频率大幅下降，而审查对象更关键。再叠加 v9 的蒸馏器：ID 想休眠/冻结模块也是一种自修改，必须过联锁（P15/定义 548）。

## 1. 研究问题（轮次升级版）

- **Q1（地形鲁棒证书）**：当只能观测到地形参数置信区间 B_t 时，如何构造中止点集与块证书，使真实地形下的安全性与 v9 逐步执行统计等价？滑移-位姿不确定性是否**单调地**压缩 K_eff（即地形越含糊、块绝不更长）？
- **Q2（规范证书与失败关闭）**：如何把伦理审查表达为可验证、可审计、可撤销的授权见证，使「无授权 ⇒ 无提交」成为可证明不变式，同时把审查延迟摊销到 5Hz 块边界？
- **Q3（有向退化）**：当新模块失效、且其基线假设不可被见证时，如何定义「等价或更保守」的退化关系，使安全论证不被静默削弱？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 单向地形适应律（One-Sided Terrain Adaptation, TEE/TRC）**
设部署期登记**授权包络** E_auth（例如 IRB / 操作方批准的平地最高速度与最小刹车余量）。自主地形适应只能在 E_auth 内改变参数；任何输出 E' 若比 E_auth 更「激进」（v_max 更大、假定减速度更小、安全余量更小），必须持有覆盖「envelope-relax」作用域的授权见证 Â。故 ∀t：E'(t) ⪯_safe E_auth ∨ ∃Â_t。适应只能收紧、不能无授权放宽。

**P14 双钥提交律（Two-Key Commit, ERG/NI）**
动作块 ζ 提交当且仅当**物理钥**有效（Ĉ_t valid，v9 定义 533）**且** **规范钥**有效（Â_t valid，覆盖 scope(ζ)）。两钥是硬 AND：任一缺失 ⇒ 拒绝提交，映射到 v9 的 p=0 安全停驻（定义 534）。规范钥不存在「放行式中立元」。

**P15 有向退化律（Directed Degradation, NI）**
模块按退化语义分成两类：**操作模块**有中立元 v^⊥（失效 ⇒ 注入恒等元、严格退回基线）；**规范/安全模块**（ERG、NI、M₀ 硬检查、TEE 平坦性见证、双向提交门）无安全中立元，只有**失败关闭元** f^⊥（失�� ⇒ 拒绝/停驻）。基线等价不是无条件声称的，而是**见证门控**的：只有当声明的基线假设被一个可检验见证 W_m 证实时才允许 v^⊥，否则取 f^⊥。行为关系因此是「等价，或更保守」（⊑_safe），绝不更激进。

## 3. 与基线的接口（如何退化）

- TRC/TEE 失效但**平坦性见证**通过（IMU 振动、坡度、滑移比均在阈内）⇒ θ←θ_nominal、E←E_nominal，**逐位等价 v9**；
- TRC 失效或信任域破坏（Δ_dom≥τ_dom ∨ risk_SLAM≥τ_SLAM ∨ 滑移超阈 ∨ Δ_terr≥τ_terr）⇒ K_eff←1，逐步执行，等价 v9 决策粒度；
- ERG 失效/超时 ⇒ 若有覆盖当前 scope 的任务级常驻授权则等价 v9，否则**拒绝提交并安全停驻**（失败关闭，不声称 v9 等价）；
- NI 失效 ⇒ 根信任域（进程隔离 + 硬件继电器）默认拒绝，系统停驻；这是**唯一不退回 v9 的降级**，由 P15 明确论证其正当性（规范钥不可旁路）；
- MW/ID 失效 ⇒ 分别为 v9 手写网关 / 全模块常开，等价 v9；
- v9 的 DA/SPR/Cal 任一失效 ⇒ 中立元注入，等价 v8；全部失效 ⇒ v9→v8→v7→v6。

## 4. 预期贡献

1. **地形条件化证书**：把中止点集与前向模型证书参数化为地形置信区间的函数，给出「区间最坏端 + 滑移风险抬升」的保守性证明（引理 87–88），使地形适应与 v9 的分块执行正交组合；
2. **规范证书与双钥提交**：把伦理审查代数化为授权见证与硬 AND 门，给出「无见证 ⇒ 无提交」的可证明不变式（引理 90）与摊销-撤销的有界延迟（引理 92）；
3. **有向退化 / 见证门控等价**：区分中立元退化与失败关闭退化，给出「等价或更保守」的偏序语义（引理 89、91、93），修正 v9「所有模块都可注入 v^⊥」的隐含过强假设；
4. **单向适应的治理闭环**：自主适应被预授权包络约束，ID 的自修改也必须过联锁，使「性能自适应」与「规范约束」不再互相蚕食；E571–E590 覆盖地形估计、中止功效、滑移压缩、授权摊销与撤销、失败关闭、橡皮图章审计与对抗授权。

## 5. 本轮最大风险

**一句话**：双钥提交的规范钥依赖人/组织发放的授权见证，而地形越陌生、决策越危险时审查时延越长，操作员越有动机发放长时效、宽范围的常驻授权——伦理审查会在最需要实质判断的时刻退化为形式橡皮图章，且若「物质变化」的检测本身依赖被审查的感知模块，见证撤销还会滞后一个块，使陈旧授权覆盖已变化的物质情境。

# IP-357 TerrainEnvelopeEstimator
class TerrainEnvelopeEstimator:
    def __init__(self, mu_nom=0.8, alpha_nom=0.0, d_safe=0.15,
                 sigma_floor=0.02, k_sigma=3.0,
                 tau_flat=1.0, tau_slope=0.05, tau_vib=0.3, tau_slip=0.15):

    def update(self, proprio, imu, slip_obs):

        mu_hat, mu_sd = self._friction_posterior(proprio, slip_obs)
        al_hat, al_sd = self._slope_posterior(imu)

            mu_lo=max(0.05, mu_hat - self.k * mu_sd),
            mu_hi=min(1.5, mu_hat + self.k * mu_sd),
            alpha_lo=al_hat - self.k * al_sd,
            alpha_hi=al_hat + self.k * al_sd,
            kappa=self._compliance(proprio), rho=self._roughness(imu),
            novelty=self._novelty(mu_hat, al_hat))
        return box

    def flatness_witness(self, box, imu, slip_obs):
        # 独立可复核；不读取规划器/策略内部状态
        return (box.novelty < self.tau_flat
                and abs(box.alpha_hi) < self.tau_slope
                and imu.vibration < self.tau_vib
                and slip_obs.max_slip < self.tau_slip)

    def envelope(self, box):

                   - G * math.sin(box.alpha_hi)          # 最坏可用减速度

## 4. 推导

**引理 87（地形鲁棒中止安全）** 设真实地形 (μ*,α*)∈B_t，a_dec^lo 由定义 541 取 μ_lo、α_hi 计算，且 a_dec^lo>0。若 p∈P_t 满足 d_brake^lo(v_p)+d_safe ≤ dist(s_p,O)−|traj_{p:K}|，则在真实地形下从 p 起的停车距离 d_brake^*(v_p)≤d_brake^lo(v_p)，故停驻终点距障碍 ≥d_safe，P_t 内任一点均可安全停驻。证明：d_brake(v)=v²/(2a_dec) 对 a_dec 单调减；a_dec(μ,α)=μg cosα−g sinα 对 μ 单调增、对 α 单调减，故 (μ_lo,α_hi) 给出 a_dec 的最小值，从而 d_brake 的最大值。∎

**引理 88（滑移-块长单调压缩）** 若滑移 s_t 使 σ_pose 增大，则定义 542 的 risk_SLAM' 不减；定义 539 的 K_eff 对 risk_SLAM' 单调不增，故 K_eff(t) 不会因地形含糊而增大；当 risk_SLAM'≥τ_SLAM 或 Δ_terr≥τ_terr 时 K_eff=1。证明：σ_pose 对 s 单调、clip 单调、max 单调，复合得 risk_SLAM' 单调；由定义 539 的分段式逐段比较即得。∎

**引理 89（单向适应不扩大已认证安全集）** 记 Ad(E) 为在包络 E 下满足停车不变式的动作集。若 E'⪯_safeE_auth，则 Ad(E')⊆Ad(E_auth)（更小的 v_max、更小的假定减速度、更大的 d_safe 只会收紧允许集）。若无 Â 而 E'⋠_safeE_auth，定义 543 禁止该输出，系统回落到 E_auth。故自主适应在任意时刻都不扩大部署期已认证的安全集。证明：对 ⪯_safe 的三个分量逐一检查 d_brake^lo 与 v_max 的单调性。∎

**引理 90（双钥提交：无未授权提交）** 在假设 A1（NI 位于策略/学习栈不可写、不可蒸馏的根信任域，且位于提交路径）下，任一被执行的动作块在提交时刻均持有有效 Â。证明：对周期数归纳。执行仅发生在 ni.commit 返回 'commit' 时，而该返回要求 erg.valid(Â,…)=真；erg.valid 要求 approve、未过期、scope 覆盖、情境哈希一致、未被撤销。任何不满足分支都返回 abort(p=0)。归纳成立。∎

**引理 91（见证门控的基线等价与退化包含）** (i) 若 TEE 平坦性见证 W_flat 为真，则 B_t 含 θ_nominal，定义 541 的 d_brake^lo 退化为 v9 的常数刹车（取 θ_nominal 时不更保守且仍保守），TRC≡AC；若同时存在覆盖当前 scope 的任务级常驻授权，ERG 返回 approve，NI 在 CertValid 时放行，故 v10 与 v9 逐位等价。(ii) 若 W_flat 为假，无任何等价声称；由定义 547，行为满足 v10⊑_safe v9（只可能更早中止、更短块、更慢速度），不出现比 v9 更激进的执行。证明：(i) 直接代入中立元 θ_nominal 与常驻 Â；(ii) 由引理 87–90 与定义 547 的偏序定义。∎

**引理 92（规范审查摊销与见证新鲜度）** 设授权时效 H_auth，物质变化事件在 50Hz 检查（O(1)），且物质变化与 Â 撤销同步。则：(i) 无物质变化时，每个块边界至多一次审查，摊销成本 ≤WCET_ERG/块长；(ii) 任一被执行块在其提交时刻的 Â 均与当前 χ 一致，且自 Â 签发以来未发生与该 scope 相交的物质变化；(iii) 中块发生物质变化 ⇒ 至多 1 个控制周期（20ms）内撤销生效并 p=0 停驻。证明：(i) 审查仅在块边界/物质变化触发；(ii) 由 erg.valid 的 χ 一致与 revoked 检查；(iii) 物质变化检查位于 50Hz 热路径且为集合/哈希比较。∎

**引理 93（规范不可蒸馏与自修改联锁）** 记 N(st) 为蒸馏状态 st 下的规范约束集合。由定义 548，φ^elig=false 的规范模块不可迁移，且任何降低规范覆盖的自修改需 Â；联锁失败即拒绝。故对所有可达蒸馏状态 st，N(st)⊇N(st₀)：蒸馏只能重分配算力，不能削减规范约束。证明：对 ID 状态迁移序列归纳；每次迁移若触及规范集则被 request_self_modification 拦截，否则 N 不变。∎

## 8. 本轮最大风险

**一句话**：双钥提交的规范钥依赖人/组织发放的授权见证，而地形越陌生、决策越危险时审查时延越长，操作员越有动机发放长时效、宽范围的常驻授权——伦理审查会在最需要实质判断的时刻退化为形式橡皮图章，且若「物质变化」的检测本身依赖被审查的感知模块，见证撤销还会滞后一个块，使陈旧授权覆盖已变化的物质情境。
