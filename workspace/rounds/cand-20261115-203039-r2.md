# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「末端执行器控制」×「事件相机」）

> R69 教会闭环「提问」：把不确定性拆成 aleatoric / epistemic，用流匹配的多模态动作先把歧义显形，再用看 / 问 / 触去消解；只有在预算内解不掉时才退回 R68 的保守铁律。这个框架默认了一件从未被检验的事：**动作是可逆的，时间足够慢，系统可以先问清楚再碰**。
>
> 但在末端执行器真正接触世界的那一厘米里，两条默认同时失效。
> - **接触是不可逆的**。位置误差 e 经过刚度 K 变成力 F≈Ke；一次错误的模态选择不是「走慢一点」，而是压碎、打滑、掉落。R69 的 λ 是速度旋钮，而接触里最危险的增益不是速度，是**刚度**。更糟的是，在接触中「慢下来」可能引发 stick-slip、失去抓握或让力跟踪失稳——保守方向搞反了。
> - **事件发生在亚毫秒尺度**。R69 的策略环在几十赫兹上重采样，等它算出下一个模态，碰撞、滑移、释放已经发生。接触需要的不是更聪明的「下一帧策略」，而是一条 1 kHz 以上、独立于策略的**接触反射弧**。
>
> 本轮两个灵感正好补上这两块：
> - **末端执行器控制**给出「把不确定性变成有界力学后果」的语言：阻抗 / 导纳、力位混合、被动性、能量罐。安全不再只是 λ，而是一个**柔顺包络** Z=(K,D,f_max,E_tank)； epistemic 错误不再被允许直接放大成无穷大力。
> - **事件相机**给出「接触瞬间的微分证人」：微秒级延迟、高动态范围、只看变化。它非常适合捕捉接近、撞击、粘滞、滑移、释放这些**时间不连续**；但它在物理上只测 log 光强的时间导数，不测绝对状态——**事件的沉默是歧义的**（真静止 / 无纹理 / 低对比 / 饱和 / 被闪盲 / 被擦除）。
>
> 核心命题：**接触域里，不确定性不能只按「可约 / 不可约」分，还必须按「可逆 / 不可逆」分。可逆的 epistemic 继续走 R69 的主动交互；不可逆的 epistemic 不许靠「问清楚再碰」解决，而要用「有界后果的接触」去解决：先变柔、限力、限能量，再通过受控的微激励让事件相机看得见，用事件 surprise 触发、用力 / 本体绝对通道确认，事件单独永远无权授权不可逆动作。** 命名 **IMPACT-RAS**（Impedance-Modulated Predictive Active-Contact Tactics for Risk-Adaptive Safety）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**在碰上去的那一毫秒，我还来得及吗；我看到的‘没有变化’，究竟是安全，还是我已经瞎了**」——不确定性不只是刹车和提问，也可以是一次受控的轻触、一段微小的抖动、和一层敢于变软的刚度。

## 0. 直觉与动机

**灵感 1（末端执行器控制 → 刚度是不确定性的放大器，柔顺是后果的保险丝）**
直觉：R69 用 λ 缩放动作，隐含「更慢 = 更安全」。在自由空间大致成立；在接触中，力才是伤害的载体。阻抗控制里 F = K(p_d−p)+D(v_d−v)+f_ff，位置信念的误差 e 被刚度 K 直接放大成力。模态选错、目标偏了、表面高度估错，最终都通过 K 变成压痕、破损、打滑。于是正确的安全变量不是速度，而是**机械导纳**： epistemic 不确定越大，K 越小、D 越大、f_max 越低、能量罐 E_tank 越保守。这给出一个比 λ 更本质的保守化方向：**不是让系统更慢，而是让系统更软、更没劲、更有阻尼**。但柔顺不是免费的：K 太低会失去力分辨率、让接触状态更难辨、也可能抓不住。安全与可观测性在接触域里第一次直接纠缠。

**灵感 2（事件相机 → 接触的微分证人，而不是绝对证人）**
直觉：事件相机不是「更快的相机」，而是**时间导数传感器**。像素在 log 亮度变化超过阈值时发一个事件；静态场景、静止相机、无纹理表面都几乎不产生事件。它的强项恰好是接触过程的时间结构：接近时的 looming / 扩张流、撞击时的同步事件爆发、粘滞时微弱的 micro-slip 事件、打滑时切向高频率事件、释放时的反向边沿。微秒级时间戳让「撞击发生在哪一刻」比传统帧清楚一个数量级。但它的弱点是原理性的：**它只测变化，不测状态**。事件为零可能表示「完全静止所以安全」，也可能表示「没有纹理」「曝光饱和」「相机被闪瞎」「事件被擦除」「物体与相机一起动」。所以事件相机是极好的 **surprise 触发器**，却是极差的 **绝对裁决者**。把它单独当安全证人，等于把「没看见变化」当成「没有危险」。

**灵感 3（主动激励 → 想看见，就必须动；但动本身会扰动接触）**
直觉：事件相机需要相对运动才能产生事件。于是「确认事件通道是否还活着」不能靠等，只能靠**主动微激励**：在末端执行器上叠加一个很小的、受认证的 dither（微位移 / 微力 / 微转矩），看事件流是否按预测出现。这个动作同时是探针和执行：它既维持接触可观测性，也可能触发滑移。这是 R69 的 gaze / probe 在接触域的对应物，但更危险——**为了看清而抖动，可能正是导致失稳的那一下**。所以激励必须进入与任务动作相同的安全包络：幅值、频率、力、能量、位移全部受限；若对象太脆弱、 admissible 激励为空，则接触模式在物理上不可观测，系统必须承认这一点并停在最保守的「限力保持」层，而不是假装自己知道。

**灵感 4（looming / 时间接触 → 交互有物理截止期）**
直觉：事件流天然给出扩张率 div v ≈ (1/A)dA/dt；对迎面目标，TTC ≈ 1/div。这是从「变化率」直接读出的接触倒计时，精度在最后几厘米反而最高。R69 的 VoI 是一个没有截止期的优化：问一次值不值。接触域里它必须变成 **anytime**：在 TTC 减去反射延迟和裕度之前若还没把不可逆不确定性降到阈值以下，就不许再「问」，必须直接切到限力 / 柔顺 / 回退。事件相机在这里不只是传感器，它是**截止期时钟**：用物理的时间接触给交互预算封顶。

**灵感 5（接触是多模态的离散状态，不是连续动作的一个模态）**
直觉：R69 的流匹配把歧义表示为连续动作空间的多个峰：绕左还是绕右。接触不是这样。接触是**混合系统**：FREE → APPROACH → IMPACT → STICK / SLIP → RELEASE，状态是离散的，转移是近乎瞬时的，连续动力学在每个模态内不同。用连续流模型去「平均」接触与不接触，会产生物理上无意义的中间动作。正确结构是混合自动机：事件相机提供高频转移触发，力 / 本体提供绝对确认，流策略只在每个离散模式内部提议连续运动。于是 R69 的「模态」被提升为**接触模式的后验**，而不是动作块的聚类。

**灵感 6（事件通道的新攻击面 → 单通道信任是单点故障）**
直觉：一旦安全依赖事件流，攻击面立刻上移一层，而且攻击的都不是「内容合理性」，而是**时间导数**：强光闪烁注入假事件、事件擦除让真撞击隐形、重放昨天的接触序列、用同步偏移把因果顺序颠倒、用运动伪装让相对运动消失、用事件洪泛把处理器拖垮。对应的防御不是内容似然，而是**物理冗余 + 绝对通道**：力 / 力矩、关节电流、本体位置不会因为相机被闪瞎而一起撒谎（除非共模，见风险）。所以接触授权必须是双通道的：事件说「有变化」，绝对通道说「变化是什么」；两者不一致时，事件无权定案。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（IMPACT-RAS 总览与四不变式）** IMPACT-RAS = (EVM, HCM, TTC, RUD, ICG, AEX, DCR, ECG, DCA, CFL, RAS-WM†)。四条不变式：
(i) **不可逆授权纪律**：任何可能造成不可逆损失的动作，必须由至少一个 T0/T1 绝对通道（力 / 力矩 / 本体 / 认证接触传感）确认；事件通道（T2，微分 / 学习）单独永远无权授权；
(ii) **后果有界**：对任意信念误差，执行接触的力 ≤ f_max、注入能量 ≤ E_tank、位移 ≤ ε_contact，均由机械导纳包络保证，不依赖策略置信；
(iii) **沉默非证据**：事件为零不得提高任何接触模式的置信；未被主动激励或未被绝对通道确认的沉默，一律视为「未知」并触发降级；
(iv) **时标分离与 anytime 降级**：反射弧 < 1ms、接触环 ≥ 1kHz、策略环 ≤ 200Hz；在 TTC 导出的接触截止期之前未消解的不可逆不确定性，必须切换到限力 / 柔顺 / 回退，而不是继续交互。

**定义 311（接触混合自动机 HCM）** 离散模式 q ∈ Q = {FREE, APPROACH, IMPACT, STICK, SLIP, RELEASE, BLIND}；连续状态 x = (p, v, f, τ_ext, u_c)，其中 p/v 为末端位姿与速度，f/τ_ext 为接触力 / 外力矩，u_c 为接触点局部形变。转移由守卫 G_{q→q'}(e_t) 触发，e_t = (E_t, f_t, ḟ_t, p_t, v_t) 为证据。每个模式有最小驻留 τ_d(q)，防止抖振。信念 b_t(q) = P(q_t=q | e_{1:t})，由切换卡尔曼 / 粒子滤波维护；BLIND 是一个**显式模式**，不是「没有证据」。

**定义 312（事件 surprise 监视器 EVM）** 事件流 E = {e_k=(u_k, t_k, s_k)}，u_k 为像素坐标，t_k 为微秒时间戳，s_k ∈ {+1,−1} 为极性。简化事件生成模型：像素发事件当 |∂_t log I(u,t)| > C。给定当前位姿 / 速度 / 指令与场景模型，事件前向模型预测 Ê_t = Φ_ev(Ĩ_t, p̂_t, v̂_t, a_cmd; θ_cam)。定义
- 事件率残差 r_rate = |log((λ_E+ε)/(λ̂_E+ε))|；
- 事件时空残差 r_evt = d_t(E_t, Ê_t)，d_t 为按时间分桶的 Chamfer / 1−IoU / 事件对比度残差；
- 事件 surprise S_evt = −log p(E_t | o_t, a_cmd)。
r_evt 高说明「预测之外的变化」：撞击、滑移、模型错、场景变；r_evt 低只说明「与预测一致」，**不说明预测本身正确**。

**定义 313（事件沉默歧义与主动激励条件 A99）** 对静态场景与静止相机，E=∅ 是期望行为。定义沉默等价类 [x]_∅ = {x' : E(x')=∅}，它同时包含「安全静止」「无纹理」「低对比」「饱和」「传感器故障」「事件被擦除」等不可区分状态。因此仅凭 E 无法对 [x]_∅ 内的 q 做可靠判别。给定激励 η（见定义 319），称 η 满足 **A99（事件持续激励条件）** 当且仅当：
(a) 预测事件率 λ̂_E(η) ≥ λ_min；
(b) 对 [x]_∅ 内任意 q_i ≠ q_j，KL(p(E|q_i,η) ‖ p(E|q_j,η)) ≥ κ_evt；
(c) 激励期间的力 / 能量 / 位移在定义 315 的包络内。
若不存在满足 A99 的 η（例如对象过脆、A_max 太小），则称该接触模式**物理不可观测**，必须按最坏情况处理（定义 323 的 C2/C3），而不是继续追问。

**定义 314（可逆性加权不确定性三分）** 在 R69 的 (U_ale, U_epi) 之外增加第三项：
- U_ale^f：接触力 / 形变 / 摩擦的不可约噪声；
- U_epi^q = H(b(q))·g(Δ_event)：接触模式之间的**可逆歧义**（可再看 / 再激励）；
- U_irr(a) = Σ_q b(q) · L_irr(q, a)：在当前信念下执行 a 的**期望不可逆损失**，L_irr 包括压碎、划伤、掉落、夹伤、任务不可恢复失败。
决策规则：U_ale^f 进入力 / 能量裕度；U_epi^q 进入 R69 的交互 / AEX 通道；U_irr 进入**导纳包络 Z**。R69 只在 U_irr≈0 时才是充分的。

**定义 315（柔顺包络与被动性）** 末端执行器导纳包络 Z = (K_n, K_t, D_n, D_t, f_max, τ_f, E_tank, v_max)，分别在法向 n 与切向 t 定义刚度、阻尼、力上限、力矩上限、能量罐与速度上限。Z 的 admissible 集合
𝒵 = {Z : f ≤ f_max, |τ| ≤ τ_f, E(t)=E_tank + ∫_0^t (f·v + τ·ω) dτ ≥ 0, 全部执行器电流 ≤ I_max}，
其中能量罐条件保证被动性，防止「用控制软件制造能量」在接触瞬间爆冲。定义**后果界** L_irr(Z) 为在包络内最坏接触的不可逆损失上界。

**定义 316（事件 looming 与接触截止期 TTC）** 由事件表面扩张流估计散度 div v ≈ (1/A)(dA/dt)，对迎面目标 TTC ≈ 1/div>0；更稳健的版本用事件对比度最大化或事件光流的仿射扩张分量。定义接触截止期
T_c = T̂TC − τ_reflex − τ_margin，
T̂TC 取保守下界（扩张率上界）。若 T̂TC 不可估（事件沉默且无近距绝对传感器），则 T_c = 0，立即进入 C2/C3。任何 AEX / VoI 决策必须在 T_c 内完成；否则视为「来不及问」。

**定义 317（双通道证据与接触授权 DCA）** 证据通道 ℰ = {E（事件，T2）, f/τ（力 / 力矩，T0）, p/v（本体，T0/T1）, c（接触麦克风 / 声发射，T1）, vis（帧相机，T2）}。对动作 a，定义授权谓词：
Auth(a) ⇔ [U_irr(a) ≤ ε_irr] ∨ [∃ e ∈ ℰ_{T0/T1} : e 与 a 所需接触模式一致且 Δt(e) ≤ τ_confirm]。
即：**不可逆动作要么后果已经小到无需授权，要么必须有绝对通道确认。事件只能提供「去确认」的触发，不能提供「已确认」的结论。** 两通道冲突时，取保守通道，降到 C3。

**定义 318（双通道接触反射弧 DCR）** 一个独立于策略、硬实时的反射层 π_reflex：
if |f| > f_reflex 或 |ḟ| > ḟ_reflex 或 (event_burst(E) ∧ approaching_flow) 或 P_mech > P_max，
then 在 τ_reflex < 1ms 内执行零力 / 回撤 / 制动。
反射弧不读策略、不读 LLM、不读模态后验；它只读绝对通道与事件 burst。策略不可覆盖反射弧。反射弧是 R69「安全侧永不让步」在接触域的物理对应物：不是更慢的 λ，而是更快的力响应。

**定义 319（主动微激励 AEX）** 激励 η = (A, ω, d, T)（幅值、频率、方向、时长），叠加在名义轨迹上。选择
η* = argmax_η [ I(q; E | η) − c_phys(η) − c_task(η) ]，
s.t. η ∈ 𝒵（定义 315）、A ≤ A_max、T ≤ T_c、接触稳定性裕度 ≥ ε_s、任务误差 ≤ ε_task。
其中 I(q;E|η) 用事件前向模型在 b(q) 上估计；c_task 惩罚激励对任务精度 / 节拍的影响。若 η* 不存在，则接触模式不可观测，按定义 313 处理。激励的频带应尽量落在任务带宽之外，避免与力控共振；必要时用**力通道的微响应**作为第二读数，构成事件—力双读数。

**定义 320（阻抗 / 导纳调节器 ICG）** 给定 R69 流策略提议 a_nom 与信念 b(q)，ICG 输出 (a_safe, Z, q_des)：
- FREE：位置控制，K 取中高，f_max 仅作安全上限；
- APPROACH：低 K、高 D、限速、限力，事件 TTC 触发减速；
- CONTACT：法向力跟踪（K_f 小、积分慢），切向阻抗；U_irr 越大，K_t 越小、D_t 越大、f_max 越低；
- SLIP / BLIND：切向刚度进一步降低、力上限降至保持所需最小值，准备回撤。
单调映射示例：K = K_min + (K_max−K_min)·exp(−U_irr/τ_K)，D = 2ζ√(K m_eff)，f_max = min(f_safe, f_task)·exp(−U_irr/τ_f)，E_tank = E_min + (E_max−E_min)·exp(−U_irr/τ_E)。**柔顺不是事后滤波，而是执行通道的前置条件。**

**定义 321（事件 / 接触威胁模型）** ℰ_event = {flood（事件洪泛 / DoS）, erase（事件擦除 / 闪盲）, replay（重放旧事件）, flicker（强光闪烁注入假事件）, camouflage（相对运动伪装）, sync（时间同步偏移）, bias（对比度 / 折射率偏置漂移）, latency（延迟伪装）}；ℰ_contact = {surface_change（表面摩擦 / 纹理突变）, force_drift（力传感器漂移）, compliance_hack（被控对象刚度突变）, load_change（负载突变）}。并入 AIC：ℰ_IMPACT = ℰ_FLUID × ℰ_event × ℰ_contact。它们大多不改变单条消息的内容合理性，只改变**时间导数 / 因果顺序 / 绝对零点**，因此内容级似然检验无效，必须靠双通道与校准门。

**定义 322（接触证书 J_IMPACT）** J_IMPACT = (J_FLUID, contact_mode_ECE, r_evt_p95, event_only_auth_count, force_peak_p99, E_tank_min, reflex_latency_p99, ttc_error_p95, excitation_coverage, event_sync_skew, impact_ver)。Valid ⇔ Valid(J_FLUID) ∧ contact_mode_ECE ≤ τ_q ∧ event_only_auth_count = 0 ∧ force_peak_p99 ≤ f_max ∧ E_tank_min ≥ 0 ∧ reflex_latency_p99 ≤ τ_reflex ∧ event_sync_skew ≤ τ_sync。

**定义 323（接触降级阶梯 CFL）** 按双通道一致性、事件可观测性与包络状态分级：
- C0：双通道一致、A100/事件可观测、U_irr ≤ ε_irr → 全功能（R69 交互 + AEX + 力位混合）；
- C1：可约歧义 / 事件偏盲 → 降低 K、增加 D、限力，允许 AEX 微激励；
- C2：事件通道不可信 / 单通道冲突 → 禁用事件授权，限力守卫运动（guarded move），只用绝对通道；
- C3：不可逆风险高 / TTC 截止 → 柔顺保持或回撤，禁止新的接触探索；
- C4：绝对通道也失效 / 反射弧触发 / 能量罐见底 → 零力 / 自由驱动 / 急停。
包络嵌套：𝒵_{C4} ⊆ 𝒵_{C3} ⊆ 𝒵_{C2} ⊆ 𝒵_{C1} ⊆ 𝒵_{C0}，允许动作集与允许能量只缩不胀；重新升级需重新认证 + 驻留 τ_u。

**定义 324（严格包含 R69 的边界）** 当（i）ρ_irr = 0（全程无接触 / 所有动作可逆），（ii）事件相机被一个完美的绝对传感器替代（r_evt=0 且 E 提供完整状态），（iii）Z 无约束（f_max→∞、E_tank→∞），（iv）DCR / AEX 关闭时，IMPACT-RAS 与 FLUID-RAS **逐指令相同**。故 R69 是 IMPACT 在「无接触、绝对感知、无限柔顺预算」边界上的退化；一般情形下 IMPACT 的 admissible 集是 R69 动作集与 𝒵 的交集，安全侧不弱于 R69。

**定义 325（事件—接触校准门 ECG）** 校准事件前向模型的对比度阈值 C、折射率 / 偏置、延迟、 refractory、时间同步与空间标定；用标定后的模型计算 event ECE 与 sync skew。若 contact_mode_ECE > τ_q 或 event_sync_skew > τ_sync 或 r_evt 的校准残差超界，则事件通道降级为「仅建议」：DCA 必须由绝对通道完成；若绝对通道也不可用，强制 C3。这是 R69 的 MCG 在事件—接触域的对应物：**不让不可信的事件分布驱动不可逆动作**。

## 2. 关键算法骨架

```python
# IP-264/265 EVM + HCM：事件 surprise 与接触模式后验（1 kHz 快环）
def event_surprise(E, obs, a_cmd, ev_model):
    E_hat = ev_model.predict(obs.scene, obs.pose, obs.vel, a_cmd)  # Φ_ev
    r_rate = abs(log((rate(E) + EPS) / (rate(E_hat) + EPS)))
    r_evt  = event_distance(E, E_hat)          # 时间分桶 Chamfer / 1-IoU
    return r_evt, r_rate, -log_prob(E, obs, a_cmd)

def contact_filter(b, E, f, p, v, dt):
    b = propagate_modes(b, dt)                 # 带最小驻留 τ_d
    lik = {
        IMPACT:  gauss(r_evt, mu_i) * sigmoid(f_dot),
        SLIP:    gauss(r_evt, mu_s) * sigmoid(-f_dot) * tangent_event_energy(E),
        STICK:   gauss(r_evt, mu_k) * gauss(f_dot, 0, sigma_f),
        BLIND:   sigmoid(r_rate - tau_rate) * prior_blind,
        FREE:    ...
    }
    return normalize(b * lik)

# IP-266 TTC：事件扩张流给出接触截止期
def contact_deadline(E, obs, ev_model):
    div = event_flow_divergence(E, obs.pose)   # (1/A) dA/dt
    if div <= EPS: return 0.0                  # 无可估扩张 → 立即保守
    ttc = 1.0 / div
    return max(0.0, ttc - tau_reflex - tau_margin)

# IP-267 RUD：可逆性加权三分
def decompose_contact(b, modes, force_noise, loss_irr):
    U_ale = force_noise
    U_epi = entropy(b) * sep_factor(b)         # 可约、可激励
    U_irr = sum(b[q] * loss_irr(q, a_star) for q in b)
    return U_ale, U_epi, U_irr

# IP-268 ICG：把不可逆不确定性变成柔顺包络
def impedance_governor(a_nom, b, U_irr, Z_limits):
    K = K_min + (K_max - K_min) * exp(-U_irr / tau_K)
    D = 2 * zeta * sqrt(K * m_eff)
    f_max = min(Z_limits.f_safe, Z_limits.f_task) * exp(-U_irr / tau_f)
    E_tank = E_min + (E_max - E_min) * exp(-U_irr / tau_E)
    Z = Envelope(K, D, f_max, E_tank, v_max=...)
    assert passivity_ok(Z) and force_ok(Z) and energy_ok(Z)
    return Z, project_into_Z(a_nom, Z)

# IP-269 AEX：主动微激励（受包络、TTC、接触稳定性约束）
def choose_excitation(b, obs, Z, T_c):
    best = None
    for eta in excitation_candidates(b):        # 幅值/频率/方向/时长
        if not in_envelope(eta, Z):        continue
        if not contact_stable(eta, obs, Z): continue
        if eta.duration > T_c:             continue
        ig = mutual_info(b, E | eta)            # 事件前向模型估计
        score = ig - phys_cost(eta) - task_cost(eta)
        if best is None or score > best.score: best = (eta, score)
    return best if best and best.score > 0 else None   # 无激励 → 物理不可观测

# IP-270 DCR：硬实时反射弧（不读策略）
def contact_reflex(E, f, fdot, power, limits):
    if abs(f) > limits.f_reflex or abs(fdot) > limits.fdot_reflex:
        return RETRACT
    if event_burst(E) and approaching_flow(E): return RETRACT
    if power > limits.P_max:                  return BRAKE
    return None

# IP-272 DCA：双通道授权（事件只能触发，不能定案）
def authorize(a, q_required, U_irr, evidence, tau):
    if U_irr <= EPS_IRR: return True           # 后果已小到无需授权
    return any(e.channel in {FORCE, PROPRIO, CONTACT_MIC}
               and e.mode == q_required and e.age <= tau
               for e in evidence.absolute)

# IP-275 主闭环：快环接触控制 + 慢环 R69 提议（异步、anytime）
def IMPACT_round(M, obs):
    # ---- 1 kHz 快环：事件→surprise→模式→反射→截止期 ----
    E = M.cam.drain()
    r_evt, r_rate, S = event_surprise(E, obs, M.last_cmd, M.evm)
    M.b = contact_filter(M.b, E, obs.f, obs.p, obs.v, M.dt)
    T_c = contact_deadline(E, obs, M.evm)
    reflex = contact_reflex(E, obs.f, obs.fdot, obs.power, M.limits)
    if reflex is not None: return M.cfl.enter(C4, reflex)
    # ---- 慢环（R69，异步）：流策略只在离散模式内部提议 ----
    if M.policy_due():
        z = M.mtm.forward(obs)
        modes = M.fmp.sample(obs, K=1 if M.fmp.mode_head(z) < TAU_MODE else 4)
        U_ale, U_epi, _ = M.aud.decompose(modes, z, M.fmp.mode_head)
        a_nom = select_mode(modes, U_epi).a
    U_ale, U_epi, U_irr = decompose_contact(M.b, modes, M.force_noise, M.loss_irr)
    # ---- 柔顺包络：不可逆不确定性 → 更软/更限力 ----
    Z, a_safe = impedance_governor(a_nom, M.b, U_irr, M.Z_limits)
    # ---- 事件可疑或模式未定 → 主动微激励（必须在 T_c 内） ----
    eta = None
    if M.b[BLIND] > TAU_BLIND or U_epi > TAU_EPI:
        eta = choose_excitation(M.b, obs, Z, T_c)
    # ---- 双通道授权：事件单独不得授权不可逆动作 ----
    if not authorize(a_safe, argmax(M.b), U_irr, M.evidence, M.tau_confirm):
        M.cfl.enter(C3, "unconfirmed contact"); Z = M.cfl.envelope(C3)
    # ---- 执行 + 审计 + 证书 ----
    tau = M.endo.dispatch(a_safe, Z, eta)
    M.audit.submit(E, r_evt, M.b, U_irr, Z, eta, reflex, T_c)
    return tau, M.b, Z, M.cert.stamp(...)
```

## 3. 推导

**引理 23（事件沉默的不可辨识性）** 设场景静态、相机静止、无噪声，则对任意满足事件生成阈值的状态 x，E(x)=∅。因此映射 x ↦ E 不是单射；[x]_∅ 内至少包含「安全静止」与「传感器失效 / 无纹理 / 饱和 / 事件被擦除」等不同 q。只依赖 E 的接触分类器在 [x]_∅ 上不可能一致地区分这些 q。系：**事件为零不能作为安全证据**；必须由主动激励（A99）或绝对通道打破等价类。

**引理 24（持续激励下的接触模式可辨识性）** 若激励 η 满足 A99，则对任意 q_i ≠ q_j，事件分布在 η 下 KL 散度 ≥ κ_evt > 0，于是 N 个独立事件时间窗上的 Chernoff 上界给出错误判别概率 ≤ exp(−N·C(κ_evt))。存在最小激励幅值 A_min ∝ σ_noise / (C·|∇I|)，其中 C 为事件阈值、∇I 为局部对比度。故低纹理 / 高噪声 / 低对比表面需要更大的 A_min；当 A_min > A_max（脆弱对象）时，A99 不可满足，模式物理不可观测，必须按最坏情况（C2/C3）处理。这是「想看清就必须动，但动有代价」的严格版本。

**引理 25（柔顺包的后果有界性）** 对定义 315 的导纳包络，接触力满足 |f| ≤ min(f_max, K‖e‖ + D‖ė‖ + ‖f_ff‖)，注入能量满足 E_inj ≤ E_tank + E_ext，其中 E_ext 为环境对系统做的功（被动性下不会由控制器额外放大）。因此对任意信念误差 e（包括模态选错导致的错误目标 / 错误表面），不可逆损失 L_irr ≤ L_irr(Z)，**与策略的置信度无关**。对比刚性位置控制：同样的 e 产生 K e 且 K 可任意大，误差可无界地转化为力。系：**刚度是不确定性到伤害的传递增益；柔顺是把「可能错」变成「错得起」的机械保险丝。**

**引理 26（事件领先 / 力确认的互补性）** 设撞击的真实时刻为 t_0。事件通道在 t_0 后 δ_e 内产生 burst（δ_e 为微秒—亚毫秒级，取决于对比度与速度）；力通道在 t_0 后 δ_f 内产生可检测的力上升（δ_f 由结构柔度、采样率与滤波决定，通常毫秒级）。于是事件通常领先 δ_lead = δ_f − δ_e > 0，适合触发反射；但事件可被 erase / flood / flicker 破坏，而力通道是绝对量，不易被同一物理机制同时欺骗。故双通道融合的检测延迟 ≤ min(δ_e, δ_f) 且漏检需两个通道同时失效。**事件负责「快」，力负责「真」。**

**定理 20（IMPACT 严格包含 R69）** 在定义 324 的退化条件下，IMPACT 与 FLUID-RAS 逐指令相同。一般情形下，IMPACT 的执行动作属于 R69 动作集与 𝒵 的交集，且 DCA 只会在 R69 的授权之上增加约束，故安全侧不弱于 R69；当 ρ_irr=0 时，ICG 不限制动作、DCR 不触发、AEX 不启用，R69 的 λ / VoI / 证据纪律原样保留。R69 = 「无接触、绝对感知、无限柔顺预算」边界。

**定理 21（有界后果的接触安全）** 若（i）Z ∈ 𝒵 且被动性成立；（ii）任何 U_irr > ε_irr 的动作都经过 DCA 绝对通道确认，事件单独不能授权；（iii）DCR 在 τ_reflex 内可执行；（iv）ECG 在事件模型失准时将其降级；则对任意满足 A99 或已降级的接触过程，任一 epistemic 错误或单通道事件攻击造成的不可逆损失不超过 L_irr(Z)，且若错误发生在反射弧可响应的时间尺度上，会在造成不可逆损失前触发回撤。注意这是**条件安全**：它把风险从「策略模态是否正确」搬到「Z 是否真的被动、DCR 是否真的够快、事件前向模型是否校准」，与 R69 把风险搬到「几何证人是否 sound」是同一类假设交换，而不是无条件胜利。

**定理 22（anytime 交互不阻塞保护）** 若 T_c 为保守下界（T̂TC 取扩张率上界）且 AEX / VoI 仅在 T_c 内执行，则交互永远不会推迟保护动作：在 T_c 到期时无论是否完成消歧，CFL 都进入不弱于 C2 的限力 / 柔顺层；而 C2/C3 的包络是 C0 的子集，故风险单调不增。系：接触域的 VoI 不是「值不值得问」，而是「**在 TTC 之前问不问得完**」；问不完就变软，而不是硬着头皮问完。

## 6. 本轮最大风险

**一句话**：IMPACT-RAS 把接触安全押在「柔顺包络真的被动、反射弧真的够快、事件前向模型真的校准」这三件事同时成立上——而这三者共享同一个脆弱点：**为了看清必须微激励，为了不损伤必须变软，但微激励本身可能触发滑移 / 损伤，变软又会让力通道变迟钝、让接触模式更不可观测；一旦事件—接触模型有偏，系统会以「已确认安全」的姿态慢性失效，最后那一下不是被算错的，而是被自己的柔顺与沉默一起放过的。**

**次级风险与缓解**：
1. **事件沉默被误读为安全** → 定义 313 的 A99 + ECG 校准门 + 无激励即视为不可观测（E302）；
2. **主动激励诱发失稳 / 损伤** → 激励进同一 Z 包络 + 接触稳定性裕度 + 力 / 能量硬限 + E305/E306；
3. **事件攻击（flood / erase / replay / flicker）** → 双通道 DCA + DCR 力确认 + ℰ_event 对抗训练 + E307；
4. **柔顺过度导致抓不住 / 任务失败** → 把柔顺显式化为 U_irr 的函数，用 AEX / R69 交互换回可观测性，用 CFL 分级而非一刀切（E304/E306）；
5. **反射弧与策略打架 / 抖振** → 反射弧独立硬实时、策略不可覆盖、C3/C4 单调降级 + 驻留 τ_u（定理 21–22）。

> 承接第 69 轮 IP-253~263（FLUID-RAS）。R69 把不确定性拆成 aleatoric / epistemic，并让系统学会「看、问、触」；但它默认动作可逆、时间足够慢。到了末端执行器接触世界的那一厘米，两条默认同时失效：**接触是不可逆的**（位置误差经刚度变成压碎 / 打滑 / 掉落，R69 的 λ 是速度旋钮，而真正危险的是刚度），**接触发生在亚毫秒尺度**（策略还没重采样完，撞击已经发生）。同时，R69 的模态是连续动作空间的峰，而接触是离散的混合状态（FREE / APPROACH / IMPACT / STICK / SLIP / RELEASE）。
>
> 本轮把两件事补上：
> - **末端执行器控制**提供「把不确定性变成有界力学后果」的语言——阻抗 / 导纳、力位混合、被动性、能量罐；安全从标量 λ 升级为**柔顺包络 Z=(K,D,f_max,E_tank)**。
> - **事件相机**提供亚毫秒级的**微分证人**——它擅长接近、撞击、滑移、释放这些时间不连续，但只测变化、不测绝对状态；**事件的沉默是歧义的**，必须由主动微激励与绝对通道（力 / 本体）打破。
>
> 定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**在碰上去的那一毫秒，我还来得及吗；我看到的‘没有变化’，究竟是安全，还是我已经瞎了**」——不确定性不只是刹车和提问，也可以是一次受控的轻触、一段微小的抖动、和一层敢于变软的刚度。
>
> IP 编号：IP-264~IP-275（共 12 个）；理论姿态为「R69 是本轮在『无接触、绝对感知、无限柔顺预算』边界上的严格退化」，安全侧只交换假设、不做无条件让步。

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** `IMPACT-RAS=(EVM,HCM,TTC,RUD,ICG,AEX,DCR,ECG,DCA,CFL,RAS-WM†)`；(i) 不可逆动作须绝对通道确认，事件单独无权授权；(ii) 力 / 能量 / 位移由 Z 包络有界，不依赖策略置信；(iii) 事件沉默不得提高置信，未激励 / 未确认的沉默视为未知并降级；(iv) 反射 <1ms、接触环 ≥1kHz、策略环 ≤200Hz，T_c 前未消解即切 C2/C3。

**定义 311–312（HCM 与 EVM）** 7 模式混合自动机，守卫 `G_{q→q'}(E,f,ḟ,p,v)`，最小驻留 τ_d；事件由 `|∂_t log I|>C` 生成，`Ê=Φ_ev(Ĩ,p̂,v̂,a_cmd)`，`r_evt=d_t(E,Ê)`，`S_evt=−log p(E|o,a)`。事件残差只表示「预测之外的变化」，低残差 ≠ 预测正确。

**定义 313（沉默歧义与 A99）** 静态场景 E=∅；`[x]_∅` 内安全静止 / 无纹理 / 饱和 / 故障 / 擦除不可分。激励 η 满足 A99 ⇔ λ̂_E≥λ_min ∧ 任意 q_i≠q_j 的 KL≥κ_evt ∧ η∈𝒵。无可行 η ⇒ 物理不可观测，按最坏情况处理。

**定义 314（三分不确定性）** `U_ale^f` 进力 / 能量裕度；`U_epi^q=H(b(q))·g(Δ_event)` 进 R69 交互 / AEX；`U_irr(a)=Σ_q b(q)L_irr(q,a)` 进 ICG 包络。R69 仅在 U_irr≈0 时充分。

**定义 315–316（柔顺包络与 TTC）** `Z` 满足 `f≤f_max`、`|τ|≤τ_f`、能量罐 `E(t)=E_tank+∫(f·v+τ·ω)dτ≥0`；刚度是不确定性到力的增益。事件扩张流 `div v≈(1/A)dA/dt`，`TTC≈1/div`，`T_c=T̂TC−τ_reflex−τ_margin`；不可估则 T_c=0。

**定义 317–318（双通道授权与反射弧）** `Auth(a) ⇔ U_irr(a)≤ε_irr ∨ ∃e∈ℰ_{T0/T1}: e 与所需模式一致 ∧ age≤τ_confirm`；事件只触发、不定案。DCR 读 `|f|,|ḟ|,event_burst,power`，`τ_reflex<1ms` 内零力 / 回撤 / 制动，策略不可覆盖。

**定义 319–320（AEX 与 ICG）** `η*=argmax[I(q;E|η)−c_phys−c_task]`，s.t. `η∈𝒵, A≤A_max, T≤T_c, 接触稳定, 任务误差≤ε_task`；无解即不可观测。ICG 按模式输出 `(a_safe,Z,q_des)`；`K=K_min+(K_max−K_min)e^{−U_irr/τ_K}`，`f_max∝e^{−U_irr/τ_f}`，`E_tank` 随 U_irr 收缩；柔顺是执行前置条件，不是后处理。

**定义 321（威胁模型）** `ℰ_event={flood,erase,replay,flicker,camouflage,sync,bias,latency}`；`ℰ_contact={surface_change,force_drift,compliance_hack,load_change}`；`ℰ_IMPACT=ℰ_FLUID×ℰ_event×ℰ_contact`。它们改时间导数 / 因果顺序 / 绝对零点，内容级似然无效。

**定义 322–323（证书与 CFL）** `J_IMPACT=(J_FLUID,contact_mode_ECE,r_evt_p95,event_only_auth_count,force_peak_p99,E_tank_min,reflex_latency_p99,ttc_error_p95,excitation_coverage,event_sync_skew,impact_ver)`。CFL：C0 全功能；C1 软阻抗 + AEX；C2 限力守卫（禁事件授权）；C3 柔顺保持 / 回撤；C4 零力 / 急停；`𝒵_{C4}⊆…⊆𝒵_{C0}`，升级需重认证 + τ_u。

**定义 324–325（严格包含与校准门）** ρ_irr=0 ∧ 完美绝对事件替代 ∧ Z 无约束 ∧ DCR/AEX 关闭 ⇒ 与 FLUID-RAS 逐指令相同。ECG：事件 ECE / sync / 校准残差越界 ⇒ 事件降为「仅建议」，DCA 必须由绝对通道完成；绝对通道也不可用 ⇒ C3。

## 3. 关键算法伪代码

```python
# IP-264 EVM：事件 surprise（1kHz）
def event_surprise(E, obs, a_cmd, ev_model):
    E_hat = ev_model.predict(obs.scene, obs.pose, obs.vel, a_cmd)
    return (event_distance(E, E_hat),
            abs(log((rate(E)+EPS)/(rate(E_hat)+EPS))),
            -log_prob(E, obs, a_cmd))

# IP-265 HCM：接触模式后验（事件触发、力确认）
def contact_filter(b, E, f, p, v, dt):
    b = propagate_modes(b, dt)
    lik = {IMPACT: gauss(r_evt, mu_i)*sigmoid(f_dot),
           SLIP:   gauss(r_evt, mu_s)*sigmoid(-f_dot)*tangent_event_energy(E),
           STICK:  gauss(r_evt, mu_k)*gauss(f_dot, 0, sigma_f),
           BLIND:  sigmoid(r_rate-tau_rate)*prior_blind,
           FREE:   ...}
    return normalize(b * lik)

# IP-266 TTC：扩张流 → 接触截止期
def contact_deadline(E, obs):
    div = event_flow_divergence(E, obs.pose)      # (1/A) dA/dt
    return 0.0 if div <= EPS else max(0.0, 1.0/div - tau_reflex - tau_margin)

# IP-267 RUD：可逆性加权三分
def decompose_contact(b, force_noise, loss_irr, a_star):
    return (force_noise,
            entropy(b) * sep_factor(b),
            sum(b[q]*loss_irr(q, a_star) for q in b))

# IP-268 ICG：不可逆不确定性 → 柔顺包络
def impedance_governor(a_nom, U_irr, lim):
    K = K_min + (K_max-K_min)*exp(-U_irr/tau_K)
    D = 2*zeta*sqrt(K*m_eff)
    Z = Envelope(K, D, f_max=lim.f*exp(-U_irr/tau_f),
                 E_tank=E_min+(E_max-E_min)*exp(-U_irr/tau_E))
    assert passivity_ok(Z) and force_ok(Z) and energy_ok(Z)
    return Z, project_into_Z(a_nom, Z)

# IP-269 AEX：受包络 / TTC / 稳定性约束的微激励
def choose_excitation(b, obs, Z, T_c):
    best = None
    for eta in excitation_candidates(b):
        if not in_envelope(eta, Z) or not contact_stable(eta, obs, Z): continue
        if eta.duration > T_c: continue
        score = mutual_info(b, E | eta) - phys_cost(eta) - task_cost(eta)
        if best is None or score > best.score: best = (eta, score)
    return best if best and best.score > 0 else None   # None ⇒ 物理不可观测

# IP-270 DCR：硬实时反射弧（不读策略）
def contact_reflex(E, f, fdot, power, lim):
    if abs(f) > lim.f_reflex or abs(fdot) > lim.fdot_reflex: return RETRACT
    if event_burst(E) and approaching_flow(E):               return RETRACT
    if power > lim.P_max:                                    return BRAKE
    return None

# IP-272 DCA：双通道授权（事件只能触发）
def authorize(a, q_req, U_irr, evidence, tau):
    if U_irr <= EPS_IRR: return True
    return any(e.channel in {FORCE, PROPRIO, CONTACT_MIC}
               and e.mode == q_req and e.age <= tau
               for e in evidence.absolute)

# IP-275 主闭环：快环接触控制 + 异步 R69 慢环
def IMPACT_round(M, obs):
    # 1kHz 快环
    E = M.cam.drain()
    r_evt, r_rate, S = event_surprise(E, obs, M.last_cmd, M.evm)
    M.b = contact_filter(M.b, E, obs.f, obs.p, obs.v, M.dt)
    T_c = contact_deadline(E, obs)
    if (r := contact_reflex(E, obs.f, obs.fdot, obs.power, M.limits)):
        return M.cfl.enter(C4, r)
    # 异步 R69 慢环：只在离散模式内部提议
    if M.policy_due():
        z = M.mtm.forward(obs)
        modes = M.fmp.sample(obs, K=1 if M.fmp.mode_head(z) < TAU_MODE else 4)
        U_ale, U_epi, _ = M.aud.decompose(modes, z, M.fmp.mode_head)
        a_nom = select_mode(modes, U_epi).a
    U_ale, U_epi, U_irr = decompose_contact(M.b, M.force_noise, M.loss_irr, a_nom)
    Z, a_safe = impedance_governor(a_nom, U_irr, M.Z_limits)
    eta = (choose_excitation(M.b, obs, Z, T_c)
           if (M.b[BLIND] > TAU_BLIND or U_epi > TAU_EPI) else None)
    if not authorize(a_safe, argmax(M.b), U_irr, M.evidence, M.tau_confirm):
        M.cfl.enter(C3, "unconfirmed contact"); Z = M.cfl.envelope(C3)
    tau = M.endo.dispatch(a_safe, Z, eta)
    M.audit.submit(E, r_evt, M.b, U_irr, Z, eta, T_c)
    return tau, M.b, Z, M.cert.stamp(...)
```

## 4. 推导

**引理 23（事件沉默的不可辨识性）** 静态场景、静止相机下 E=∅；映射 x↦E 非单射，[x]_∅ 同时包含安全静止、无纹理、饱和、故障、事件擦除。仅依赖 E 的分类器在 [x]_∅ 上不可能一致。系：事件为零不能作为安全证据，必须由 A99 激励或绝对通道打破等价类。

**引理 24（持续激励可辨识性）** 若 η 满足 A99，则 q_i≠q_j 的事件分布 KL≥κ_evt，N 个时间窗上的 Chernoff 上界给出错判概率 ≤ exp(−N·C(κ_evt))。最小幅值 A_min ∝ σ_noise/(C·|∇I|)；低纹理 / 高噪声需更大 A_min。若 A_min>A_max（脆弱对象），A99 不可满足，模式物理不可观测，必须按最坏情况处理。

**引理 25（柔顺包的后果有界性）** 在 Z 包络下 `|f|≤min(f_max,K‖e‖+D‖ė‖+‖f_ff‖)`，`E_inj≤E_tank+E_ext`；故任意信念误差 e（含错误目标 / 错误表面）的不可逆损失 `L_irr≤L_irr(Z)`，与策略置信无关。刚性位置控制下同样的 e 产生 Ke 且 K 可任意大。系：刚度是不确定性到伤害的传递增益；柔顺是把「可能错」变成「错得起」的机械保险丝。

**引理 26（事件领先 / 力确认互补）** 撞击时刻 t_0；事件 burst 延迟 δ_e（微秒—亚毫秒），力上升延迟 δ_f（毫秒）；通常 δ_lead=δ_f−δ_e>0，事件适合触发反射。事件可被 erase/flood/flicker 破坏，力是绝对量；双通道检测延迟 ≤ min(δ_e,δ_f)，漏检需两通道同时失效。事件负责「快」，力负责「真」。

**定理 20（IMPACT 严格包含 R69）** 定义 324 退化条件下逐指令相同；一般情形执行动作 ∈ R69 动作集 ∩ 𝒵，DCA 只在 R69 授权之上加约束，故安全侧不弱于 R69。ρ_irr=0 时 ICG/DCR/AEX 不启用，R69 的 λ / VoI / 证据纪律原样保留。R69 = 「无接触、绝对感知、无限柔顺预算」边界。

**定理 21（有界后果接触安全）** 若 Z∈𝒵 且被动性成立；U_irr>ε_irr 的动作均经 DCA 绝对通道确认；DCR 在 τ_reflex 内可执行；ECG 在事件模型失准时降级；则任一 epistemic 错误或单通道事件攻击的不可逆损失 ≤ L_irr(Z)，且在反射弧可响应的时间尺度上会在不可逆损失前触发回撤。注意这是**条件安全**：风险从「策略模态是否正确」搬到「Z 是否真被动、DCR 是否真够快、事件模型是否校准」。

**定理 22（anytime 交互不阻塞保护）** 若 T_c 为保守下界且 AEX/VoI 仅在 T_c 内执行，则交互不推迟保护：到期无论是否消歧都进入不弱于 C2 的限力 / 柔顺层；C2/C3 包络是 C0 子集，风险单调不增。系：接触域 VoI 不是「值不值得问」，而是「在 TTC 之前问不问得完」；问不完就变软。

## 7. 本轮最大风险

**一句话**：IMPACT-RAS 把接触安全押在「柔顺包络真的被动、反射弧真的够快、事件前向模型真的校准」三件事同时成立上——而它们共享同一个脆弱点：**为了看清必须微激励，为了不损伤必须变软，但微激励本身可能触发滑移 / 损伤，变软又会让力通道变迟钝、让接触模式更不可观测；一旦事件—接触模型有偏，系统会以「已确认安全」的姿态慢性失效，最后那一下不是被算错的，而是被自己的柔顺与沉默一起放过的。**

**次级风险与缓解**：事件沉默被误读为安全（A99 + ECG + 无激励即不可观测，E302）；主动激励诱发失稳 / 损伤（激励进同一 Z 包络 + 稳定性裕度 + 硬限，E305/E306）；事件攻击 flood/erase/replay/flicker（DCA 双通道 + DCR 力确认 + ℰ_event 对抗训练，E307）；柔顺过度致任务失败（柔顺显式为 U_irr 函数 + AEX / R69 交互换可观测性 + CFL 分级，E304/E306）；反射弧与策略打架 / 抖振（独立硬实时、不可覆盖、C3/C4 单调降级 + 驻留 τ_u，定理 21–22）。
