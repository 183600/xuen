# 第 11 轮（新灵感循环第 2 轮；本轮灵感：「多传感器融合」×「抓取」）
> **基线**：第 10 轮 MetricVoiceGauge-STF-NRB-LS（定义 540–548；引理 87–91；实验 E571–E590）。
> 本轮纪律：**异构冗余 + 接触接地**。两个灵感分别治理 v10 留下的两笔债：**可分性债**（v10 把"显著/非显著"这一承重假设压在单一语义嵌入的 τ_sem 上；对抗纹理/长尾新颖可同时穿过检测并击穿前向模型——上轮自认最大风险）、**接地债**（v10 证书只覆盖运动段，γ̂_grasp 只是有效性布尔；误差真正致命的接触段没有独立测量，β 校准始终离线开环）。保持 v10 铁律：新模块失效 ⇒ 注入声明中立元，检测行为**等价**于 v10，或安全风险集**子集**（安全支配，允许声明的可用性下降），绝不静默扩权。

## 0. 直觉与动机

**灵感 1（多传感器融合 → 从单通道可分面到异构并集否决面）**
直觉：v10 的 τ_sem 是一条单通道"显著性分界线"，把"能否看见危险"全押在一种嵌入上；对抗者只需在**一个**流形上把 ν 压到阈值下，就能把"显著"伪装成"非显著"。多传感器融合的第一性原理不是"平均更准"——对安全而言**平均是危险的**（一路尖叫会被其余通道稀释）。正确的融合是不对称的：**安全用并集否决（OR），可用性用共识（AND/多数）**。漏检概率因此从单通道的 ε_{s0} 变成"所有健康通道同时漏"的概率，而 P(∩ miss) ≤ min_s ε_s——**不需要通道独立**这个常见但站不住的假设（相交事件的概率不超过任一边际）。更关键：单通道欺骗会**制造跨模态分歧** D；你不需要知道真相，只需知道"独立测量不一致"，不一致本身就是保守信号（分歧税）。这把 v10 的错误形状从"更准的阈值"改成"更难被同时绕过的证据结构"。

**灵感 2（抓取 → 接触锚定证书与"接触即标定"）**
直觉：v10 证书管理的是"接近物体"的净空与力，但任务是**抓取**；抓取是接触丰富、非光滑动力学，恰是 F̂ 误差最大处，v10 只用一个 γ̂_grasp 布尔带过。抓取同时送来两样 v10 没有的东西：(i) **物理耦合的独立测量通道**——触觉、力矩/力觉、滑移检测。外观可被对抗纹理骗，接触残差 c_res = ‖W_meas − Ŵ‖ 却由真实物理交互生成：视觉不可见的动力学误差在接触时会显形（引理 95）。(ii) **在线标定探针**——每次成功抓取都产生一条带标签的前向模型误差样本；用分布无关的有限样本上界（conformal/Hoeffding）把 β 在**接触工况**上证据化地缩小，把 v10 的"离线开环校准"升级为"分工况、有置信度、可审计的闭环校准"（引理 96）。抓取还迫使**相态化中止**：接触段中止到运动中止点 p* 会直接掉物，必须改为后退/保持/放置（定义 554、557）。

两者咬合：HSF 给**检测广度**（异构通道，漏检取交集），GAC/CRC 给**物理锚点**（独立测量 + 分工况标定）；证书余量由标量 β_STF 升级为**通道×工况的余量结构**，并要求**佐证**（corroboration）而非单点信任。

## 1. 研究问题（轮次升级版）

- **Q1（异构可分性）**：如何把"显著/非显著"从单通道标量阈值升级为异构通道的并集否决 + 分歧税，使检测漏报 ≤ min_s ε_s（无需独立性），且单通道对抗欺骗被"自暴露"为跨模态分歧，同时把硬否决的误报控制在可用性预算内？
- **Q2（接触接地与相态安全）**：抓取接触段如何用独立接触通道给出可比证书的抓取证书 Ĝ，并把中止语义相态化，使 v10 在接触段的潜在掉落风险被**显式排除**（安全支配）而非继承？
- **Q3（证据化标定）**：如何用接触残差在**有限样本、分布无关、分工况**条件下缩小 β，使任何缩小都携带置信度 1−δ_c 与交换性检验，且不把接触子分布的结论外推到预接触/新物体工况？

## 2. 设计原则（在 P13–P15 基础上新增 P16–P18）

**P16 异构并集否决律（Heterogeneous OR-Veto, HSF）**
安全判定沿**通道并集**（任一路显著即否决），可用性判定沿**共识**（软风险需 ≥2 路或加严余量）；主通道阈值与 v10 逐位相同，故检测是 v10 的严格超集；禁止用加权平均作安全门。

**P17 分歧即证据律（Disagreement-as-Evidence, CMTF）**
跨模态分歧 D 不得被丢弃或平均；D 必须进入证书余量（分歧税 β_XM）与块长门控。一致不等于正确，但不一致一定意味着有通道在错——分歧是可测、保守、可审计的不确定性代理。

**P18 接触接地与相态支配律（Contact Grounding, GAC/CRC）**
接触段必须有独立物理测量与相态化安全中止；β 的任何缩小必须满足有限样本覆盖（1−δ_c）、交换性检验与硬地板 β_min，并只作用于匹配工况；接触不可用 ⇒ 不进入接触相（安全支配，可用性下降须声明与计量）。

## 3. 与基线的接口（如何退化）

- HSF 失效（健康通道 <2 / 同步超差 / 融合超时）⇒ 仅保留 v10 主通道：σ_XM≡σ_{s0}、D≡0、β_XM←β_STF，**等价 v10**；
- CMTF 失效 ⇒ 同上（分歧项归零，不抬高也不降低余量）；
- GAC/CRC 失效（无触觉/力觉或接触模型不可用）⇒ 不进入接触相（不抓），运动段原样 v10——**安全支配**，可用性损失入台账；
- STF 失效 ⇒ v10 Level-1（K=1、β←β_base）；NRB 失效 ⇒ Π_r；
- AC 失效 ⇒ K=1；ID 失效 ⇒ 全模块 active、归因冻结；MW 失效 ⇒ v10 手写网关；v8 失效 ⇒ 中立元 ⇒ v7 ⇒ v6。

## 4. 预期贡献

1. **异构可分面**：把 v10 的单点 τ_sem 换成"并集否决 + 分歧税"，漏检界 ≤ min_s ε_s 且无需独立性，单通道对抗攻击被分歧自暴露（引理 92–93）；
2. **接触锚定证书**：抓取段首次拥有独立于视觉的误差测量与分相态安全中止，排除 v10 在接触段的潜在掉落（引理 95、97）；
3. **证据化在线标定**：接触残差给出有限样本、分工况、可审计的 β 缩小，把离线开环校准变成闭环证据（引理 96）；
4. **E591–E610** 覆盖异构标定、支配复现、对抗注入、同步、抓取相态、标定覆盖/漂移、相态中止与综合竞赛。

## 5. 本轮最大风险

**一句话**：接触残差只在"够得着、抓得住、接触稳定"的子分布上可得，与真正危险的"高速预接触/首次接触新物体"存在协变量偏移——一旦用接触工况的 β̂ 去缩小预接触或新类余量，v11 的错误就比 v10 更精致：v10 是"没测量"，v11 可能是"用错了测量"；同时双档否决在接触相抬高假中止，而抓取中的假中止本身可能导致掉落。

**新增定义 549（异构通道模型）** 每个通道 s 给出去中心化创新度 ν_s(x,t)=clip(d_s(O_s(obs), M_s(x))/τ_emb,s,0,1)，其中 M_s 是该通道各自的参考模型（外观原型、几何占据、关节预测、力预测、触觉纹理、声学指纹）。通道之间**不要求共享表征**，只要求各自有一个已标定的零假设分布。健康位 h_s(t)=1[自检通过 ∧ t−t_s≤T_stale ∧ 同步误差≤δ_sync]。

**新增定义 550（通道标定与显著指示）** 在无事件集上标定 α_s=P(ν_s>τ_s | H0)；在事件集上标定 ε_s=P(ν_s≤τ_s | E)（E591）。显著指示 σ_s(x)=1[ν_s(x)>τ_s]。主通道 s_0 取 v10 语义通道，且 τ_{s0}≡τ_sem、ε_{s0}≡ε_s，保证逐位承接。

**新增定义 551（并集否决与双档融合）** 硬风险类（不可逆：碰撞、人距、掉落、过载）用并集否决 σ_XM=∨_{s∈S_h}σ_s；软风险类（可逆：舒适、效率、规范软项）用共识否决 σ_XM=1[Σ_{s∈S_h}σ_s≥2] 或加严余量。S_h={s:h_s=1}。**禁止加权平均作安全门**（P16）。

**新增定义 552（跨模态信任场与分歧税）** T^×(x,t)=max_{s∈S_h} w_{s}(x)·ν̄_s / max_{s∈S_h} w_s(x)（保守取 sup 而非均值，防止一路高创新被均值稀释）；D_XM(x,t)=(max_s ν̄_s − min_s ν̄_s)/δ_ν，仅对 S_h 中 ≥2 通道定义。证书余量 β_XM=β_base+λ_T sup_{x∈Φ}T^×+λ_D sup_{x∈Φ}D_XM。分歧是**税**不是噪声：它直接抬高余量、缩短块长。

**新增定义 553（融合信任域）** U_t^× 如符号表。K_eff 与守卫的门控从 v10 的 U_t^sem 升级为 U_t^×：任一硬否决在走廊内触发即 ¬U_t^×。U_t^× ⇒ U_t^sem（当 S_h={s_0} 时两者相同），故融合只可能更保守。

**新增定义 554（抓取相状态机）** φ∈{approach, contact, hold, transfer, release}。转移门：approach→contact 需 GAC 可用且预接触证书有效；contact→hold 需 Ĝ_t 首次有效（摩擦锥/力/滑移）；hold→transfer 需 Ĝ_t 持续有效且无 CRL 反射；transfer→release 需落点有效支撑；任相 CRL 触发 ⇒ 相态安全动作 A_φ。非法转移计数 0（E597）。

**新增定义 555（抓取锚定证书）** Ĝ_t=(µ̂_fric, F̂_contact, η̂_slip, c_res, ρ)。µ̂_fric=摩擦锥裕量（由触觉压力中心与切向力估计）；F̂_contact 为法向力有限区间（由电流/力矩估计）；η̂_slip 为滑移残差；c_res=‖W_meas−Ŵ_q‖（实测六维力/力矩 vs F̂_q 接触预测）；ρ=(φ, 物体粗类, 速度档)。Ĝ_t valid ⇔ µ̂_fric≥µ_min ∧ F̂_contact⊆[F_min,F_max] ∧ η̂_slip≤η_max ∧ c_res≤β_eff(ρ)。

**新增定义 556（接触残差与证据化余量）** 对工况 ρ 的残差样本 r_i=c_res,i，β̂_ρ 取 conformal 分位数 q̂_{1−δ_c} 加有限样本修正 √(ln(2/δ_c)/(2n))；仅当 n≥n_min 且近期样本与历史库通过双样本检验（水平 δ_x）时启用，否则 β_eff(ρ)=β_STF。β_eff(ρ)=max(β_min, min(β_STF, β̂_ρ))，且**只作用于匹配工况**。每次 β 变动连同 (n, β̂_ρ, δ_c, 检验统计量) 写入台账 Λ。

**新增定义 557（相态化中止）** P_φ 与 A_φ：approach→最近中止点 p*（v10 原样）；contact→沿接近矢量后退至预接触位姿；hold→有有效支撑则放置、否则力控保持；transfer→有有效支撑则放置、否则保持；release→受控释放。相态中止动作必须再验证书（定义 543-v11），验不过则保持/语音求助。

# IP-361 HeterogeneousSensorFusion：安全用并集，可用性用共识
class HeterogeneousSensorFusion:
    def __init__(self, channels, tau, alpha, delta_sync=0.01, delta_nu=1.0):
        self.channels, self.tau, self.alpha = channels, tau, alpha
        self.delta_sync, self.delta_nu = delta_sync, delta_nu

    def healthy(self, now):
        return [s for s in self.channels
                if s.h and abs(now - s.t) <= self.delta_sync]

    def indicator(self, s, x, ev):
        return s.nu(x, ev) > self.tau[s.name]        # 定义 550

    def veto(self, x, ev, risk='hard'):
        hs = self.healthy(ev.now)
        if not hs:
            return True                               # 无健康通道 ⇒ 不能认证
        ind = [self.indicator(s, x, ev) for s in hs]
        if risk == 'hard':
            return any(ind)                           # 并集否决：单路即否决
        return sum(ind) >= 2                          # 软风险：双路共识

    def disagreement(self, x, ev):
        hs = self.healthy(ev.now)
        if len(hs) < 2:
            return 0.0                                # 单通道 ⇒ D≡0（等价 v10）
        vs = [s.nu(x, ev) for s in hs]
        return (max(vs) - min(vs)) / self.delta_nu     # 定义 552


# IP-362 CrossModalTrustField：分歧进入余量，而非被平均掉
class CrossModalTrustField:
    def __init__(self, fusion, beta_base=0.02, lam_T=0.1, lam_D=0.15,
                 tau_D=0.4):
        self.fusion, self.beta_base = fusion, beta_base
        self.lam_T, self.lam_D, self.tau_D = lam_T, lam_D, tau_D

    def margin(self, corridor, ev):
        supT = max(self.T_xm(x, ev) for x in corridor)
        supD = max(self.fusion.disagreement(x, ev) for x in corridor)
        return self.beta_base + self.lam_T * supT + self.lam_D * supD

    def trust_ok(self, corridor, ev, delta_dom, tau_dom):
        return (not any(self.fusion.veto(x, ev, 'hard') for x in corridor)
                and self.max_D(corridor, ev) <= self.tau_D
                and delta_dom < tau_dom)

class GraspAnchoredCertificate:
    def __init__(self, Fq, crc, mu_min=0.25, F_range=(2, 40),
                 eta_max=0.02):
        self.Fq, self.crc = Fq, crc
        self.mu_min, self.F_range, self.eta_max = mu_min, F_range, eta_max

    def cert_valid(self, o):                              # 定义 555

        c_res = norm(o.wrench_meas - self.Fq.contact_pred(o))
        beta = self.crc.beta_eff(regime_of(o), c_res)     # 定义 556

                and self.F_range[0] <= o.f_normal <= self.F_range[1]

                and c_res <= beta)


class ContactResidualCalibrator:
    def __init__(self, beta_stf, beta_min=0.01, n_min=30,
                 delta_c=0.01, delta_x=0.05):
        self.beta_stf, self.beta_min, self.n_min = beta_stf, beta_min, n_min
        self.delta_c, self.delta_x = delta_c, delta_x
        self.reservoir, self.recent = defaultdict(list), defaultdict(list)

    def beta_eff(self, rho, r):                           # 定义 556
        self.reservoir[rho].append(r)
        self.recent[rho] = self.recent[rho][-64:] + [r]
        if len(self.reservoir[rho]) < self.n_min:
            return self.beta_stf                          # 样本不足 ⇒ 不缩
        if not exchangeable(self.reservoir[rho], self.recent[rho],
                            self.delta_x):
            return self.beta_stf                          # 交换性不过 ⇒ 不外推
        n = len(self.reservoir[rho])
        q = conformal_quantile(self.reservoir[rho], 1 - self.delta_c)
        b_hat = q + sqrt(log(2 / self.delta_c) / (2 * n))
        return max(self.beta_min, min(self.beta_stf, b_hat))

## 4. 推导

**引理 92（异构并集否决的检测支配，且无需独立性）** 设主通道 s_0 满足 τ_{s0}≡τ_sem、健康集 S_h∋s_0。对显著事件 E，v10 漏检概率 P(ν_{s0}≤τ_{s0}|E)≤ε_{s0}。v11 漏检为 P(∩_{s∈S_h}{ν_s≤τ_s}|E)≤min_{s∈S_h}ε_s≤ε_{s0}（相交事件概率不超过任一边际，**与通道相关性无关**）。故同事件集上检测是 v10 的严格超集；误报 P(∨σ_s|H0)≤Σ_{s∈S_h}α_s，由双档规则与 E595 预算控制。推论：v10 担心的"单通道对抗纹理把 ν 压到 τ_sem 下"只移除了 s_0 这一票，其余健康通道仍在并集内；要完全漏检必须同时让所有健康通道漏，其概率 ≤ min_s ε_s。∎

**引理 93（分歧税与自暴露）** 设欺骗集 A⊂S_h。若诚实通道 s∉A 在 E 下显著（由引理 92 至少一路以 ≥1−min ε 概率成立），则 σ_XM 触发。若 σ_XM 未触发，则所有诚实通道都漏，概率 ≤min_{s∉A}ε_s。同时，欺骗者把 ν_s 压到阈值下而诚实通道保持高创新，则 D_XM≥(ν_honest−τ_s)/δ_ν>0，进入 β_XM 使余量抬升 λ_D·supD、K_eff 收缩——**即使欺骗"成功"不触发硬否决，它也必须支付分歧税**；除非 A=S_h（需同时攻破所有异构通道，违反其独立物理转导），否则无法免费。∎

**引理 94（中性元退化与同步门控）** (i) 去掉任一非主通道：S_h 仍含 s_0，漏检界 ≤ε_{s0}，故检测永不弱于 v10；当 S_h={s_0} 时 D≡0、β_XM=β_STF、σ_XM=σ_{s0}，**逐位等于 v10**。(ii) 同步超差 ⇒ h_s=0，同一单调性保证不会用陈旧数据制造虚假一致（否则"假一致"会同时压低 D 与 T^×，产生伪造的安全）。(iii) 主通道缺失 ⇒ v10 Level-1。故 HSF 的全部失效路径为等价退化，不存在"静默更宽松"。∎

**引理 95（接触通道的物理独立性/可观测性）** c_res=‖W_meas−Ŵ_q‖。W_meas 由真实接触交互经力/触觉转导生成，其测量算子（应变/压阻/电容 → 六维力）与外观通道（光子 → 嵌入）在物理上不同源。因此"对视觉不可见的动力学误差集"一般不对接触通道不可见：当物体有效质量、摩擦、柔顺或质心与模型不符时，接触力/力矩与触觉压力分布会即时反映，且与外观纹理无关。注记：该可观测性以"已到达接触且抓取稳定到可测"为条件——选择偏差真实存在（见第 8 节），故仅用于接触工况。∎

**引理 96（接触即标定的有限样本覆盖）** 设工况 ρ 内残差 r_1..r_n 可交换。取 β̂_ρ=q̂_{1−δ_c}(r)+√(ln(2/δ_c)/(2n))（conformal 分位数 + 有限样本修正），则对同分布未来样本 P(r≤β̂_ρ)≥1−δ_c。仅当 n≥n_min 且近期与历史库通过水平 δ_x 的双样本检验时启用，否则 β_eff(ρ)=β_STF。故任何低于 β_STF 的余量都携带显式置信度 1−δ_c、显式工况与显式检验结果，且被 β_min 兜底。相较 v10 的离线标量 β_STF，v11 把"不可见的校准前提"换成"分工况、有限样本、可审计的覆盖命题"；代价是只在接触工况有效。∎

**引理 97（相态化中止的安全支配与活性代价）** 定义相态动作集 A_φ。对 φ∈{contact,hold,transfer}，v10 的全局中止 p* 被替换为 {后退, 保持, 放置}，这些动作都保持物体受支撑并排除 p* 的掉落转移；每个相态动作仍须重验定义 543-v11（含 β_eff 的净空/力界）。因此接触段的风险集 R_contact(v11)⊆R_contact(v10)∪R_set-down，而 R_set-down 由同一证书机制认证；若无有效支撑则保持+语音，活性损失由 E603 计量。GAC 不可用 ⇒ 拒绝进入 contact 相：不抓不是新风险，是声明的可用性下降。故 v11 在接触段是**安全支配**（非行为等价），并显式补上了 v10 未认证的接触中止。∎

| 融合时延（E606） | ≤0.3ms、抖动不劣 | 通道并行、降采样非关键通道 |
| 预算（E607） | ≤192KB、≤25W | 触觉降采样、残差库分页 |
| 长跑（E608） | 漂移稳定 | 周期重标定（v10 E587 处置沿用） |
| 一致欺骗（E609） | 残余风险可测量并被 K=1 覆盖 | 强制回退标量门控、扩 Π_r |
| 竞赛（E610） | ≥ v10 +10% | 综合调参、失分瓶颈分析 |

## 8. 本轮最大风险

**一句话**：接触残差只在"够得着、抓得住、接触稳定"的子分布上可得，与真正危险的"高速预接触/首次接触新物体"存在协变量偏移——一旦用接触工况的 β̂ 去缩小预接触或新类余量，v11 的错误就比 v10 更精致：v10 是"没测量"，v11 可能是"用错了测量"；同时双档否决在接触相抬高假中止，而抓取中的假中止本身可能导致掉落。
