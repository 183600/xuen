# 第 56 轮（承接第 55 轮语义-接触层 IP-121–126；灵感循环第 2 轮；本轮灵感：「平衡控制」×「仿真到现实迁移」）

> 第 55 轮把“接触在语义上是否可信”写进了全身生存核 `K(Σ)`。本轮把视角从**仿真里的可行动集**翻到**现实里的平衡可迁移性**。核心矛盾：**H24**：`K(Σ)` 是在仿真动力学 `θ_sim` 下算出来的，而平衡控制对接触摩擦、执行器延迟、质心高度/质量分布的微小偏差最敏感——仿真里“可行”的动作，在真实的 DCM（捕获点）坐标里可能已经越过了不可逆的跌倒边界；**H25**：域随机化（DR）能覆盖间隙，但随机化半径通常是拍脑袋的：覆盖不足会漏掉真实参数，覆盖过度会让策略学不到动态步态且过度保守，而两者都不回答“真实参数落在随机化支撑内的概率是多少”；**H26**：辨识真实间隙本身要扰动平衡，而平衡失败不可逆——“为了迁移得更准而去试探”与“试探必须不跌倒”直接冲突。

## 0. 直觉与动机

**灵感 1（平衡控制 → 把高维间隙换算到平衡裕度坐标）**
直觉：sim-to-real gap 有几十个参数，直接用 `||Δθ||` 衡量既没有物理意义，也无法进证书。平衡控制恰好提供了一个天然的统一货币——**捕获点/DCM 到支撑多边形的距离** `m_b`。摩擦从 0.8 掉到 0.5、执行器多 20ms 延迟、质心前移 2cm，最终都折算成“平衡裕度少了几厘米、还剩几步可以落脚”。于是高维间隙被压成一个标量裕度损失 `δ_b(Δθ)`；“能不能迁移”变成“最坏间隙下裕度还够不够”。更关键的是，支撑多边形 `S` 正是第 55 轮语义接触集 `C^+(Σ)` 的凸包——语义决定“哪里能踩”，平衡把“能踩”变成“敢不敢把体重压上去”。

**灵感 2（间隙敏感子空间 → 不是所有参数都值得担心）**
直觉：平衡动力学只对少数方向敏感（摩擦锥、执行器延迟、质心高度/质量分布、IMU 零偏）。用 `m_b` 对 `θ` 的敏感度 `S_b = ∂m_b/∂θ` 定义加权范数 `||Δθ||_{W_b}`，把现实间隙投影到平衡敏感子空间，得到间隙集 `G_ε`。这既让鲁棒核不会因为无关参数维度而爆炸，也告诉辨识模块“只需要测这几个量”。

**灵感 3（鲁棒转移核 → 生存核要按间隙做内收缩）**
直觉：不要相信 `θ_sim` 下的 `K(Σ)`。真实的平衡可行动集应是“在所有可信间隙参数下都可行”的交集：`K_tr = ⋂_{Δθ∈G_ε} K(Σ; θ_sim+Δθ)`，并且额外要求最坏平衡裕度 `m_b ≥ θ_b`。这是对第 55 轮生存核的**间隙鲁棒内收缩** `K_tr ⊆ K(Σ)`。迁移证书因此不再说“仿真里安全”，而说“在间隙预算内、按最坏平衡裕度仍然安全”。

**灵感 4（认证域随机化 → 随机化半径要有覆盖证明）**
直觉：DR 的方向是对的，但必须回答两个问题：半径够不够大（覆盖真实参数）？够不够小（不过度保守）？把 DR 写成带约束的优化：最小化随机化半径，s.t. 真实参数覆盖率 `≥ 1-α` 且平衡迁移谱 `ρ_tr ≥ ρ_min`。覆盖下界由校准后的间隙估计器用共形预测给出；`ρ_tr` 由云端大规模对抗性间隙采样估计。DR 于是从“调参玄学”变成“有覆盖与鲁棒双证书的构造”。

**灵感 5（安全辨识 → 试探只能在平衡裕度大的地方做）**
直觉：辨识 `μ`、`τ` 需要激励，但激励会消耗平衡裕度。因此把辨识限制在**高裕度状态集** `H = {x | m_b(x;θ) ≥ θ_probe}` 内，并约束每次试探造成的裕度损耗与累计风险预算。信息增益最大化必须在 `m_b` 不越界、`x' ∈ K_tr` 的前提下进行；一旦残差报警立即停止激励、收紧核、进入恢复步。这把“主动辨识”从危险动作变成受护盾夹住的信息采集。

**灵感 6（运行时迁移护盾 → 用残差把间隙“看”出来）**
直觉：离线证书有有效期。在线用 IMU/足端力/运动学残差做 CUSUM，检测真实动力学是否已离开 `G_ε`；一旦离开，按残差方向**定向收紧** `K_tr`（而不是全局冻结），优先保留后退步、宽站姿等平衡恢复动作。这样迁移护盾既防跌，又不会一有噪声就瘫痪。

## 1. 形式化定义（增量：定义 127–132）

**定义 127（平衡裕度与捕获点）**
全身状态投影到质心 `x_c=(p,v)`，线性倒立摆自然频率 `ω=√(g/z_c)`，发散分量（DCM/捕获点）`ξ = p + v/ω`。由第 55 轮语义接触集得到支撑多边形 `S(C)=conv{p | (p,c)∈C^+(Σ), c=支撑}`，落脚可行域 `F(x)`（腿长/关节限位/语义接触条件化）。平衡裕度
`m_b(x;θ) = min( dist(ξ, ∂S), dist(ξ, ∂F) )`，
`θ=(μ,τ_act,z_c,β_mass,b_imu)` 为平衡敏感动力学参数。平衡可行集 `B(θ)={x | m_b(x;θ) ≥ 0}`。

**定义 128（现实间隙集与平衡敏感加权范数）**
间隙 `Δθ = θ_real - θ_sim ∈ ℝ^d`。敏感度 `S_b(θ)=∂m_b/∂θ`（沿轨迹取最坏值），加权矩阵 `W_b = S_b^T S_b + λ_r I`。间隙集
`G_ε = {Δθ | ||Δθ||_{W_b} ≤ ε_b}`，其中 `ε_b` 由实测残差在标定集上的 `(1-α)` 分位数（共形预测）确定。于是由 Lipschitz 性有诱导裕度损失 `δ_b(Δθ)=sup_x|m_b(x;θ+Δθ)-m_b(x;θ)| ≤ L_b||Δθ||_{W_b}`，高维间隙被折算为可入证书的标量预算。

**定义 129（间隙鲁棒平衡生存核）**
`K_tr(Σ;G_ε) = { x ∈ K(Σ;θ_sim) | ∀Δθ∈G_ε: x∈K(Σ;θ_sim+Δθ) ∧ m_b(x;θ_sim+Δθ) ≥ θ_b }`。
用 `G_ε` 的外包盒顶点 + 情景采样 + 区间可达性给出 sound 的内/外近似 `K_tr^in ⊆ K_tr ⊆ K_tr^out`；`K_tr^in` 直接替换第 55 轮护盾中的 `K_in`。

**定义 130（平衡迁移谱）**
`ρ_tr(δ) = inf_{Δθ∈G_δ} P_{w~𝒟}( ∀t≤T: m_b(x_t;θ_sim+Δθ) ≥ 0 )`，
即间隙半径 `δ` 下轨迹保持平衡的最坏概率，对 `δ` 单调不增。`ρ_tr(ε_b) ≥ ρ_min` 是迁移可部署的鲁棒性条件，与第 53/55 轮的 `ρ` 维度共享证书框架。

**定义 131（认证域随机化）**
DR 分布 `P_φ`，半径 `r(φ)`。认证 DR 求解
`φ* = argmin_{φ} r(φ)  s.t.  P(θ_real∈supp P_φ) ≥ 1-α-ε_cal, ρ_tr(r(φ)) ≥ ρ_min, E_{P_φ}[cost] ≤ C_max`。
第一项是**覆盖证书**（真实参数不被漏掉），第二项是**平衡鲁棒证书**（漏掉也不至于跌倒），第三项防止随机化过度导致策略退化。

**定义 132（平衡迁移证书）**
`J_b = (Θ_core, W_b, ε_b, m_b^min, ρ_tr, δ_gap, T_valid, evidence)`：
- `Θ_core` 核心可辨识参数（`μ,τ_act,z_c,b_imu`）；
- `m_b^min = min_t min_{Δθ∈G_ε} m_b(x_t;θ_sim+Δθ)` 最坏平衡裕度；
- `δ_gap` 在线残差反演的加权间隙实测量；
- `T_valid` 证书有效期；`evidence` 含辨识激励日志、残差 CUSUM、回退记录。
若 `P(Δθ_real∈G_ε) ≥ 1-α-ε_cal`、`m_b^min ≥ θ_b`、`ρ_tr(ε_b) ≥ ρ_min`、`δ_gap ≤ Θ_g` 且未过有效期，则平衡迁移可部署。

## 2. 关键算法 伪代码

### IP-127 BAM（Balance-Aware Margin）

```python
def balance_margin(x, Sigma, kappa, theta_m, theta_b):
    C_plus = conservative_contacts(*semantic_contact_map(Sigma, kappa), theta_m)
    S = convex_hull([p for (p, c) in C_plus if c == 'support'])
    if S.is_empty():
        return -inf, None
    xi = dcm(x_pom(x))                        # p + v / sqrt(g / z_c)
    m_static = signed_distance(xi, S.boundary)
    F = foot_placement_region(x, S)           # leg reach x semantic contacts
    m_step = signed_distance(xi, F.boundary)
    return min(m_static, m_step), S
```

### IP-128 GSS（Gap-Sensitive Subspace）

```python
def gap_sensitivity(theta, Sigma, traj, params, lambda_r):
    S = {p: finite_diff(lambda th: min_margin(traj, Sigma, th), theta, p) for p in params}
    W_b = outer_product(S) + lambda_r * I
    return W_b, S

def estimate_gap(residual_hist, W_b, calib, alpha):
    dtheta = robust_least_squares(residual_hist, calib.model)
    delta = sqrt(dtheta @ W_b @ dtheta)
    eps_b = conformal_quantile(calib.deltas, 1 - alpha)   # coverage >= 1-alpha
    return dtheta, delta, eps_b
```

### IP-129 RTK（Robust Transfer Kernel）

```python
def robust_transfer_kernel(Sigma, theta_hat, G_eps, theta_b, horizon):
    K_in  = K_sim_inner(Sigma, theta_hat)
    K_out = K_sim_outer(Sigma, theta_hat)
    for dtheta in box_vertices(bounding_box(G_eps)) + sample(G_eps, horizon):
        K_in  = intersect(K_in,  K_sim_inner(Sigma, theta_hat + dtheta))
        K_out = union(K_out,     K_sim_outer(Sigma, theta_hat + dtheta))
    K_in = {x for x in K_in if worst_case_margin(x, Sigma, G_eps) >= theta_b}
    return KernelApprox(K_in, K_out)
```

### IP-130 SIB（Safe Identification for Balance）

```python
def safe_identification_probe(x, K_tr, H_probe, A_exc, R_budget, lambda_r):
    best, best_score = None, -inf
    for u in A_exc:
        x_next = rollout_one(x, u)
        if x_next not in K_tr.K_in:
            continue
        if min_margin(x_next) < H_probe:        # keep balance margin headroom
            continue
        dm = margin_cost(x, u)
        if dm > R_budget:
            continue
        score = fisher_information(u, Theta_core) - lambda_r * dm
        if score > best_score:
            best, best_score = u, score
    return best if best is not None else hold_balance(x)
```

### IP-131 CDR（Certified Domain Randomization）

```python
def certified_domain_randomization(phi_grid, theta_hat, calib, rho_min, alpha):
    feasible = []
    for phi in phi_grid:
        r = randomization_radius(phi)
        if coverage_lower_bound(theta_hat, phi, calib) < 1 - alpha:
            continue
        rho = balance_transfer_spectrum(phi, r, worst_case=True)
        if rho < rho_min or expected_cost(phi) > C_max:
            continue
        feasible.append((r, phi, rho))
    if not feasible:
        return ('reject', 'no_certified_radius')
    return ('ok', min(feasible, key=lambda t: t[0]))
```

### IP-132 BTS（Balance Transfer Shield）

```python
def balance_transfer_shield(u_nom, x, K_tr, W_b, eps_b, e_hist):
    e = balance_residual(x)                    # IMU / foot force / CoM residual
    dtheta, delta, _ = estimate_gap(e_hist + [e], W_b, calib, alpha)
    if cusum(delta, h, k) or delta > eps_b:
        direction = residual_direction(e)
        K_tight = directional_shrink(K_tr, direction, gamma)
        u = qp_filter(u_nom, x, K_tight,
                      prefer=['recovery_step', 'wider_stance'])
        return (u if u is not None else recovery_step(x)), 'gap_alarm', delta
    u = qp_filter(u_nom, x, K_tr.K_in)
    return (u if u is not None else safe_brake(x)), 'ok', delta
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| BAM | O(|C^+| log |C^+|) | O(|C^+|) | 支撑多边形凸包、语义接触保守膨胀 |
| GSS | O(d·T·仿真) | O(d²) | 敏感度线性化有效、共形覆盖成立 |
| RTK | O(|G|·|X|·QP) | O(|X|) | 间隙外包盒 sound、内近似保守 |
| SIB | O(|A_exc|·QP) | O(|A_exc|) | 只在 `K_tr∩H` 内激励、风险预算硬约束 |
| CDR | O(|Φ|·N_adv·T) | O(|Φ|) | 覆盖下界有效、迁移谱对抗采样充分 |
| BTS | O(QP) / step | O(W) | CUSUM 阈值、定向收缩 sound、回退可达 |

**正确性定理（Balance-Aware Sim-to-Real Transfer Soundness）**
假设第 55 轮 (A29)–(A32) 成立；**(A33)** 间隙估计器经残差标定且共形覆盖 `P(Δθ_real∈G_ε) ≥ 1-α-ε_cal`；**(A34)** `m_b` 关于 `θ` 在 `G_ε` 上 `L_b`-Lipschitz 且 `K_tr^in ⊆ K_tr ⊆ K_tr^out`；**(A35)** `ρ_tr` 由覆盖 `∂G_ε` 的对抗采样估计，误差有界；**(A36)** 护盾检测延迟 `τ_g` 内间隙漂移有界，不可行时回退 `u_stop∈𝒳_safe`；**(A37)** 认证 DR 的支撑覆盖真实参数。
则部署后单步平衡安全概率：
```
P_safe ≥ 1 - (α + ε_cal) - P(Δθ_real ∉ G_ε) - P(K_tr^out \ K_tr^in ≠ ∅)
             - P(ρ_tr 估计误差 > e_ρ) - P(shield fallback fails)
```
关键：**平衡裕度作为间隙的统一度量**、**鲁棒核按间隙内收缩**、**DR 半径带覆盖证书**、**在线残差定向收紧**；任何一层失守都不允许把“仿真里平衡”当作“现实里平衡”。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 间隙估计器欠校准（未建模摩擦/延迟） | 高 | 共形标定 + 分材质分层标定 + 在线残差再校准 |
| 敏感度线性化在远离 `θ_sim` 处失效 | 高 | 分段线性化 + 区间包络 + 大间隙触发重辨识 |
| 鲁棒核过保守导致“冻结” | 中 | 分辨率分层核 + 保守度预算 + 定向收缩而非全局冻结 |
| 安全辨识激励不足导致参数不可辨 | 高 | 高裕度窗口 + 多步信息增益 + 主动换地形（宽站姿） |
| 认证 DR 覆盖界在新分布下失效 | 高 | 分布漂移检测 + 覆盖审计 + 超界即降级到 `K_tr` 保守核 |
| 云边残差回传延迟 | 中 | 边端本地 CUSUM + 云端异步重认证 + `T_valid` 过期即失效 |

## 6. 本轮最大风险

**一句话**：把平衡裕度当作 sim-to-real 间隙的统一货币，能让迁移证书从“仿真可行”升级为“间隙预算内最坏平衡仍可行”，但其 soundness **三重依赖敏感度线性化在真实间隙尺度上有效、共形覆盖在材质/负载漂移下仍成立、以及在线残差反演能及时识别出间隙方向**；一旦真实间隙落在敏感子空间之外（如未建模的足端打滑或柔性形变），估计器会给出“低间隙”的假象，护盾就在一个被低估的 `G_ε` 里放行动态步态，把整机推过不可逆的跌倒边界——因此必须以 **残差共形校准 + 敏感子空间外置哨兵 + 定向收缩与恢复步兜底** 三重护栏，宁可退回宽站姿慢走，绝不把“仿真里能站住”当作“现实里不会摔”。

# 第 56 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（BAM×GSS×RTK×SIB×CDR×BTS）

> 承接 v31（IP-115–120 动作-协同层）与第 55 轮语义-接触层（IP-121–126）。本轮新增**平衡感知 sim-to-real 迁移层**，把“迁移”从经验性域随机化升级为**带平衡裕度与覆盖证书的可认证迁移**：
> - **BAM（Balance-Aware Margin）**：用 DCM 捕获点到语义支撑多边形的距离作为间隙的统一货币；
> - **GSS（Gap-Sensitive Subspace）**：平衡敏感加权范数 `W_b`、间隙集 `G_ε` 与共形覆盖标定；
> - **RTK（Robust Transfer Kernel）**：对 `G_ε` 做内收缩的间隙鲁棒平衡生存核 `K_tr`；
> - **SIB（Safe Identification for Balance）**：高裕度窗口内、受 `K_tr` 夹住的安全辨识激励；
> - **CDR（Certified Domain Randomization）**：带覆盖 + 迁移谱双证书的最小半径随机化；
> - **BTS（Balance Transfer Shield）**：在线残差 CUSUM + 定向收缩 + 恢复步兜底。
>
> IP 编号：IP-127~IP-132（共 6 个新增）。

## 2. 关键算法 伪代码

### IP-127 BAM

```python
def balance_margin(x, Sigma, kappa, theta_m):
    C_plus = conservative_contacts(*semantic_contact_map(Sigma, kappa), theta_m)
    S = convex_hull([p for (p, c) in C_plus if c == 'support'])
    if S.is_empty():
        return -inf, None
    xi = x.p + x.v / sqrt(g / x.z_c)
    m_static = signed_distance(xi, S.boundary)
    m_step = signed_distance(xi, foot_placement_region(x, S).boundary)
    return min(m_static, m_step), S
```

### IP-128 GSS

```python
def gap_sensitivity(theta, Sigma, traj, params, lambda_r):
    S = {p: finite_diff(lambda th: min_margin(traj, Sigma, th), theta, p) for p in params}
    return outer_product(S) + lambda_r * I, S

def estimate_gap(residual_hist, W_b, calib, alpha):
    dtheta = robust_least_squares(residual_hist, calib.model)
    delta = sqrt(dtheta @ W_b @ dtheta)
    eps_b = conformal_quantile(calib.deltas, 1 - alpha)
    return dtheta, delta, eps_b            # P(delta <= eps_b) >= 1 - alpha
```

### IP-129 RTK

```python
def robust_transfer_kernel(Sigma, theta_hat, G_eps, theta_b, n_samples):
    K_in, K_out = K_sim_inner(Sigma, theta_hat), K_sim_outer(Sigma, theta_hat)
    for dtheta in box_vertices(bounding_box(G_eps)) + sample(G_eps, n_samples):
        K_in  = intersect(K_in,  K_sim_inner(Sigma, theta_hat + dtheta))
        K_out = union(K_out,     K_sim_outer(Sigma, theta_hat + dtheta))
    K_in = {x for x in K_in if worst_case_margin(x, Sigma, G_eps) >= theta_b}
    return KernelApprox(K_in, K_out)
```

### IP-130 SIB

```python
def safe_identification_probe(x, K_tr, H_probe, A_exc, R_budget, lambda_r):
    best, best_score = None, -inf
    for u in A_exc:
        x_next = rollout_one(x, u)
        if x_next not in K_tr.K_in or min_margin(x_next) < H_probe:
            continue
        dm = margin_cost(x, u)
        if dm > R_budget:
            continue
        score = fisher_information(u, Theta_core) - lambda_r * dm
        if score > best_score:
            best, best_score = u, score
    return best if best is not None else hold_balance(x)
```

### IP-131 CDR

```python
def certified_domain_randomization(phi_grid, theta_hat, calib, rho_min, alpha):
    feasible = []
    for phi in phi_grid:
        r = randomization_radius(phi)
        if coverage_lower_bound(theta_hat, phi, calib) < 1 - alpha:
            continue
        rho = balance_transfer_spectrum(phi, r, worst_case=True)
        if rho < rho_min or expected_cost(phi) > C_max:
            continue
        feasible.append((r, phi, rho))
    if not feasible:
        return ('reject', 'no_certified_radius')
    return ('ok', min(feasible, key=lambda t: t[0]))
```

### IP-132 BTS

```python
def balance_transfer_shield(u_nom, x, K_tr, W_b, eps_b, e_hist):
    e = balance_residual(x)
    dtheta, delta, _ = estimate_gap(e_hist + [e], W_b, calib, alpha)
    if cusum(delta, h, k) or delta > eps_b:
        K_tight = directional_shrink(K_tr, residual_direction(e), gamma)
        u = qp_filter(u_nom, x, K_tight, prefer=['recovery_step', 'wider_stance'])
        return (u if u is not None else recovery_step(x)), 'gap_alarm', delta
    u = qp_filter(u_nom, x, K_tr.K_in)
    return (u if u is not None else safe_brake(x)), 'ok', delta
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| BAM | O(|C^+| log |C^+|) | O(|C^+|) | 支撑凸包与语义接触保守膨胀一致 |
| GSS | O(d·T·仿真) | O(d²) | 共形覆盖 ≥1-α，敏感度局部有效 |
| RTK | O(|G|·|X|·QP) | O(|X|) | 外包盒顶点 sound，内近似保守 |
| SIB | O(|A_exc|·QP) | O(|A_exc|) | 只在 `K_tr∩H` 内激励、风险预算硬约束 |
| CDR | O(|Φ|·N_adv·T) | O(|Φ|) | 覆盖下界有效、`∂G_ε` 对抗采样充分 |
| BTS | O(QP) / step | O(W) | CUSUM 阈值、定向收缩 sound、回退可达 |

**正确性定理（Balance-Aware Sim-to-Real Transfer Soundness）**
假设第 55 轮 (A29)–(A32) 成立；**(A33)** 共形覆盖 `P(Δθ_real∈G_ε) ≥ 1-α-ε_cal`；**(A34)** `m_b` 在 `G_ε` 上 `L_b`-Lipschitz 且 `K_tr^in ⊆ K_tr ⊆ K_tr^out`；**(A35)** `ρ_tr` 对抗采样误差 `≤ e_ρ`；**(A36)** 检测延迟内漂移有界且不可行回退 `u_stop∈𝒳_safe`；**(A37)** DR 支撑覆盖真实参数。
则部署后单步平衡安全概率：
```
P_safe ≥ 1 - (α + ε_cal) - P(Δθ_real ∉ G_ε) - P(K_tr^out \ K_tr^in ≠ ∅)
             - P(ρ_tr 估计误差 > e_ρ) - P(shield fallback fails)
```
关键：**间隙用平衡裕度计量、鲁棒核按间隙内收缩、DR 半径带覆盖证明、在线残差定向收紧**。

## 6. 本轮最大风险

**一句话**：平衡裕度把 sim-to-real 间隙压成可入证书的标量，使迁移从“仿真可行”升级为“间隙预算内最坏平衡仍可行”，但其 soundness **三重依赖敏感度线性化在真实间隙尺度上有效、共形覆盖在材质/负载漂移下仍成立、以及在线残差能及时反演出间隙方向**；一旦真实间隙落在敏感子空间之外（足端打滑、柔性形变、未建模延迟），估计器会给出“低间隙”假象，护盾便在被低估的 `G_ε` 内放行动态步态，把整机推过不可逆跌倒边界——故必须以 **残差共形校准 + 敏感子空间外置哨兵 + 定向收缩与恢复步兜底** 三重护栏，宁可宽站姿慢走，绝不把“仿真里能站住”当作“现实里不会摔”。
