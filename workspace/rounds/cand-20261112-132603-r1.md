# 第 61 轮（承接第 60 轮「认知驱动的场景-执行闭环」SGEC / IP-153~160；本轮灵感：「自然语言指令」×「状态机」）

> 第 60 轮把执行闭环升级为「场景语义 × 认知意图 × ROS 因果隔离」，但仍有三个未解的根本局限：
> 1. **指令的"瞬时化"失真**：CIEC 把一句话压成一组瞬时约束 C_intent 并锁定 2s，可真实自然语言指令是**有顺序、有条件、可中断、需确认**的程序（如「先慢慢靠近，碰到阻力就退半厘米，再轻推两秒，最后停住等我确认」）。把多子句指令塌缩成单点约束，丢掉了**时序语义**，导致「顺序做错」无法被发现——系统只能证明"我做了某个动作"，不能证明"我按你说的顺序做了"。
> 2. **证据与决策的弱耦合**：第 60 轮 EPIR 把 EV-exec 存档、校验哈希与序号，但 EV-exec 并未成为**状态迁移的判定输入**。"碰到阻力"这类守卫条件只有力/位证据能判定；证据若不参与决策，"证据链完整"就只是账本完整，而非"行为可验证"。
> 3. **语言歧义只能事后兜底**：第 60 轮用「意图锁定 2s 超时释放」做兜底，属于**事后护栏**；一旦「轻触」被误解为「加紧」，错误约束已经下发了。缺少**前置的、显式的澄清机制**，也缺少对运行中指令修订（"改轻一点"）的**受约束热更新**能力。

## 0. 直觉与动机

**灵感 1（自然语言指令 = 带守卫的时序程序）**
直觉：人类下指令时会自然携带**时序结构**与**条件结构**——"先…再…"是顺序，"如果…就…"是守卫，"直到…为止"是 Until，"保持…两秒"是区间不变式。这不是"一个意图"，而是一段**可执行的时序程序**。关键洞见：**把自然语言指令解析为受限时序中间表示 NL-IR**，让"顺序/条件/区间"从模糊语用变成可检查的语法对象，从而在**下发执行前**就能发现"子句缺槽位、顺序冲突、守卫不可观测"。

**灵感 2（状态机 = 语言与执行之间的可验证接地桥）**
直觉：描述"带守卫的时序轨迹"最成熟的形式化工具是**分层状态机（HSM）**。第 60 轮的 ϕ_intent→constraint 是一步黑箱跳变；本轮拆成 **语言 → IR（可检查）→ HSM（可执行）→ 状态绑定 ERTC 契约 / EEIS 阻抗（可度量）**。关键洞见：**状态是"承诺的最小单位"**——进入状态 s 就意味着承诺契约 C(s) 与不变式 Inv(s)；只有 EV-exec 满足退出守卫 g_exit(s)，才允许迁移。于是"我照做了"变成一条**逐迁移可核验**的轨迹，而非一句口头承诺。

**灵感 3（EV-exec = 状态机的输入字母表）**
直觉：第 60 轮 EV-exec 是"证据账本"；但"碰到阻力"这种守卫本身就是**力/位证据的函数**。关键洞见：**把 EPIR 的 EV-exec 流当作 HSM 的输入字母表 Σ**——证据不再只是被存储和校验，而是**驱动状态迁移**。这使 EPIR 从"账本"升级为"传感器"，也让第 60 轮的"证据可靠回传"真正转化为"行为可被证据判定"。

**灵感 4（歧义 → 显式澄清态 Clarify）**
直觉：自然语言的歧义不可消除，只能**前置管理**。与其在语言层硬猜，不如让编译出的 HSM 内建 **Clarify 状态**：当歧义度 α(IR) 超过阈值 τ_clar，或槽位接地失败时，状态机**主动进入人机确认态**，用一条最大的可执行子机（conservative sub-machine）先保持安全，再等待确认。关键洞见：**"猜错"应被转化为"问一句"**——把第 60 轮的事后超时兜底，前移为编译期/运行期的显式澄清。

**灵感 5（指令时变 → 受约束状态机补丁）**
直觉：执行到一半用户说"停，改轻一点"——这不是重启，而是对运行中 HSM 的**补丁 P**（增删状态、改守卫、改契约）。关键洞见：补丁必须先通过**不引入新不安全态**的静态检查（H ⊕ P 的所有可达状态仍满足 Inv），才允许在**最近的已验证提交点**原子叠加；否则拒绝补丁并回退。

**灵感 6（合流 → 指令-状态机-证据闭环 NSEC）**
直觉：NL-IR 给结构、ISMC 给可执行机、SMCB 给每态契约、RV 给运行时判定、GAD 给歧义处置、Patch 给热更新；六者合成闭环：**语言→IR→HSM→契约→执行→EV-exec→RV→(推进/回滚/澄清/补丁)**，实现「指令可验证、顺序可核验、歧义可前置、修订可安全」。

## 1. 形式化定义（增量：定义 161–170）

**定义 161（指令时序中间表示 NL-IR）** 自然语言指令 L 经解析得到 IR = (A, ≺, G, Φ)，其中：
- **原子动作集** A = {a₁, …, a_k}，每个原子 a 附带槽位绑定 slot(a)（对象、方向、幅度、时长）
- **时序关系集** ≺ ⊆ A×A，由顺序算子 `;`（先后）、`Until`、`After`、`When`、`Repeat(n)` 生成
- **守卫集** G：每个守卫 g ∈ G 是谓词 g : EV-exec × SceneBelief → {⊤, ⊥, ?}
- **约束集** Φ：区间不变式（如「力 ∈ [0, F_max] 保持 2s」）
- 受限时序逻辑片段（语法）：
  ```
  φ ::= a | ¬φ | φ∧φ | φ∨φ | Xφ | φ U φ | F_{≤T}φ | G_{≤T}φ | φ ; φ | when(g) φ
  ```
  其中 `;` 是派生算子（φ₁;φ₂ ≡ φ₁ U (φ₂ ∧ ¬φ₁ 已完成)），`when(g)` 表示守卫 g 成立窗口内才启用子式。
- **接地函数** gnd : A × S → (SkillExec, SlotBinding)，将原子动作及其槽位映射到可执行技能与具体参数。

**定义 162（指令编译 ISMC：IR → 分层状态机）** 编译算子 C : IR → H，H = (S, s₀, Σ, δ, T, E, Inv)：
- **状态集** S，含复合状态（子机）；s₀ 为初始态；含保留态 SafeHold、Clarify、Done、Abort
- **输入字母表** Σ = Σ_ev ∪ Σ_scene ∪ Σ_human，其中 Σ_ev 是 EV-exec 事件（力阈值、位置阈值、接触/失联、时序戳），Σ_scene 是场景事件（场景转变），Σ_human 是人机事件（确认、修订、急停）
- **迁移函数** δ : S × Σ × B → S（B 为布尔守卫条件），迁移带守卫 g 与动作（进入契约、下发阻抗、请求澄清）
- **契约绑定** T : S → C_rt（每态绑定的 ERTC 契约），E : S → 进入/退出动作
- **不变式** Inv : S → 2^Safe，每态允许的安全参数集
- **保序编译**：C 保持 IR 的时序关系，即若 a ≺ b，则 H 中不存在从 b 对应状态到 a 对应状态的无约束路径（禁止逆序执行）；形式化为 **trace inclusion**：H 的所有可接受证据轨迹，均满足 IR 的时序语义。

**定义 163（接地与消歧 GAD）** GAD = (gnd, α, π_clar, τ_clar)。其中：
- **歧义度** α(IR) ∈ [0,1]：由未绑定槽位数、多义谓词数、缺失守卫可观测量加权得到
- **澄清策略** π_clar：α(IR) > τ_clar 或存在不可观测守卫 ⇒ 进入 Clarify 态，生成最小澄清问句集 Q*（使剩余歧义最小）
- **保守子机** H_cautious：仅由槽位已完整、守卫可观测的原子构成的可执行子机；澄清期间只允许执行 H_cautious
- **误接地率**：ε_gnd = P(gnd 选择与用户意图不一致 | 接地完成)。要求 ε_gnd ≤ τ_gnd 才允许退出 Clarify。

**定义 164（状态-契约绑定 SMCB）** 对每个状态 s ∈ S，绑定四元组 C(s) = (C_enter(s), Inv(s), g_exit(s), D(s))：
- **进入契约** C_enter(s)：由 EEIS 以场景先验 π_scene 与当前任务编译的阻抗/速度/力约束
- **不变式** Inv(s) ⊆ Safe：执行期间必须恒成立的参数集（如 K_safe ∈ K_safe^scene）
- **退出守卫** g_exit(s)：EV-exec 上的可观测谓词（如 F_contact ≥ F_τ 且 |Δx| ≥ δ）
- **期限** D(s)：状态允许停留的最大时长，超时触发 SafeHold 或 Clarify
- **精化关系**：C(s) ⊑ C_rt（状态契约是 ERTC 实时契约的细化）。升级迁移要求 C_enter(s') 与 Inv(s) 兼容，否则拒绝迁移。

**定义 165（运行时验证 RV：LTL3 三值监控）** 监控器 M_H : Σ* → {⊤, ⊥, ?}：
- 对 IR 的时序性质 φ 执行 **三值 LTL 语义**：⊤ 已满足、⊥ 已违反、? 尚未判定
- **四类违例检测**：(a) 顺序违例（发生未预期的原子动作，out-of-alphabet）；(b) 不变式破坏（Inv(s) 被突破）；(c) 期限违约（D(s) 超时）；(d) 守卫不可靠（证据置信度 < τ_ev，无法判定但被迫迁移）
- **违例处置**：任一 ⊥ ⇒ 迁移至 SafeHold 并冻结契约；? 累积超过窗口 ⇒ 强制 Clarify
- **监控开销**：每证据事件 O(|φ|)，|φ| 为公式长度；在线增量更新。

**定义 166（可中断/可恢复 HSM 与提交点）** 为 HSM 增加 (I, Stack, CP)：
- **可中断集** I(s)：允许中断当前态的人机事件集合；中断后压栈 suspend(s)
- **恢复语义**：Resume 时从暂停态恢复，但必须先**回滚到最近已验证提交点** cp ∈ CP
- **提交点** CP：只有在该状态产生**已认证的 EV-exec（J_exec 通过）**后，才把该态标记为 commit point；未认证状态不可作为回滚落点
- **人机确认**：after_confirm 事件作为显式输入字母表元素，支持"做完这步等我确认"的语义
- **回滚保证**：任意中断都能回到"最后一个证据已验证的状态"，而非回到起点重来。

**定义 167（指令热更新：受约束状态机补丁）** 补丁 P = (ΔS, Δδ, ΔC)，可增删状态、改守卫、改契约。运行中 HSM 的叠加记作 H ⊕ P：
- **安全前置检查**：H ⊕ P 的全部可达状态满足 Inv(s) ⊆ Safe，且不引入不可观测守卫；否则拒绝
- **原子叠加**：仅在 **提交点** 原子应用补丁，运行中的迁移不被打断（apply-on-commit）
- **冲突检测**：若 P 与当前 active 子机的时序关系冲突（如删除正在执行的态），降级为 abort-or-clarify
- **回滚**：补丁应用失败则回退至应用前快照 H，并以 EV-exec 对齐差异（证据重放校验）。

**定义 168（指令-状态机-证据闭环 NSEC）** 算子 NSEC(M, L, scene, budget)：
```
① Parse:      IR ← parse(L);  α ← ambiguity(IR)
② GAD:        if α > τ_clar: H ← compile(H_cautious); enter Clarify(Q*)
               else: H ← ISMC(IR)
③ SMCB:       for s ∈ H.S: C(s) ← EEIS.compile_with_scene_prior(π_scene, IR, s)
④ Dispatch:   进入 s₀, 下发 C_enter(s₀) 与 Cert_eeis
⑤ Execute:    Σ_ev ← telemetry_to_events(wait_contact())
⑥ RV:         verdict ← M_H.update(Σ_ev)
⑦ EV-epic:    S_local.append(EV-exec); S_sync.push(); 若 J_exec 通过 ⇒ 标记 commit point
⑧ Transition: if verdict=⊤ ∧ g_exit(s) ⇒ 迁移 s' ; if ⊥ ⇒ SafeHold ; if ?累计 ⇒ Clarify
⑨ Patch:      if 收到修订 L': H ← H ⊕ patch(IR', H) (apply-on-commit)
⑩ Return:     (H, trace, verdict, J_sm, S_local.status)
```

**定义 169（状态机认知预算 PCE+++++）** B_sm = (B_compile, B_ground, B_monitor, B_clarify, B_patch)，与既有 B_cog 合并为 B_all：
- **B_compile**：IR→HSM 编译算力/时间
- **B_ground**：槽位接地与场景先验查询开销
- **B_monitor**：RV 每事件开销 × 证据速率
- **B_clarify**：澄清轮次与等待时延
- **B_patch**：补丁安全检查（可达性 × 不变式）开销
- **降级策略**：B_compile 耗尽 ⇒ 直接用单意图 CIEC（第 60 轮）；B_ground 耗尽 ⇒ 保守子机 + Clarify；B_monitor 耗尽 ⇒ 采样子序列监控；B_clarify 耗尽 ⇒ 默认保守约束 + 记录未消歧；B_patch 耗尽 ⇒ 拒绝热更新、要求停机重编译。

**定义 170（指令-状态机可验证证书 J_sm）** 一次 NSEC 结束产出 J_sm = (ψ_ir, ψ_comp, ψ_rv, ψ_smcb, ρ)：
- **ψ_ir**：IR 良构性证明（时序关系无环、守卫可观测量均已注册）
- **ψ_comp**：编译保序性证明（trace inclusion 成立）
- **ψ_rv**：RV 判定摘要（每条 φ 的 ⊤/⊥/? 与反例前缀）
- **ψ_smcb**：每状态契约精化 C(s) ⊑ C_rt 的证据引用
- **ρ**：残余歧义与未验证区间（residual），用于告知"哪些承诺尚未被证据覆盖"
- **可验证性定义**：J_sm 可被独立检查器重放 EV-exec 轨迹复算 verdict；若重放一致且无 ρ 中未验证承诺被声明为已完成，则称该次指令执行**可验证**。

### IP-161 NL-IR 解析（受限时序文法）

```python
class NLIRParser:
    def __init__(self, lexicon, slot_registry):
        self.lex = lexicon              # 动词/对象/方向词表
        self.slots = slot_registry      # 可接地槽位与可观测量

    def parse(self, utterance: str) -> "IR":
        tokens = self._tokenize(utterance)
        seq = self._parse_sequence(tokens)          # '先…再…最后…' -> listings
        guards = self._parse_when(seq)              # '如果/碰到…就…'
        intervals = self._parse_duration(seq)       # '保持…两秒'
        atoms = [self._make_atom(t) for t in seq]
        ir = IR(atoms=atoms, order=self._order_of(seq),
                guards=guards, invs=intervals)
        ir.alpha = self.ambiguity(ir)
        return ir

    def ambiguity(self, ir):
        unbound = sum(1 for a in ir.atoms if not a.slot_bound())
        unobs = sum(1 for g in ir.guards
                    if not self.slots.observable(g.observable))
        return min(1.0, 0.5*unbound/max(1,len(ir.atoms))
                        + 0.5*unobs/max(1,len(ir.guards)))
```

### IP-162 ISMC 编译（IR → HSM）

```python
def compile_ir(ir: IR) -> HSM:
    H = HSM(states=[INIT], transitions=[],
            inv={INIT: Safe.ALL})
    cur = INIT
    for atom in ir.topo_order():                 # 保序：拓扑序展开
        nxt = State(atom.name, entry=atom.skill)
        H.add_state(nxt, inv=atom.inv)
        H.add_transition(cur, nxt, guard=atom.guard or Always,
                         action=atom.skill)
        cur = nxt
    H.add_state(SAFEHOLD, inv=Safe.ALL)
    H.add_state(CLARIFY, inv=Safe.ALL)
    H.add_state(DONE, inv=Safe.ALL)
    H.add_transition(cur, DONE, guard=ir.final_guard)
    H.monitor = LTL3Monitor(ir.to_ltl())
    assert is_acyclic(ir.order), "IR order must be acyclic"
    assert trace_inclusion(H, ir)                # 保序编译正确性
    return H
```

def bind_contracts(H: HSM, scene_prior, delta_f_req):
    for s in H.states:

### IP-168 NSEC（指令-状态机-证据闭环）

```python
def nsec_loop(M, utterance, scene_prior, budget):
    ir = M.parser.parse(utterance)
    if ir.alpha > TAU_CLAR or not all_guards_observable(ir):
        H = compile_ir(ir.cautious_submachine())
        H.enter(CLARIFY, question=min_clarification_set(ir))
    else:
        H = compile_ir(ir)
    H = bind_contracts(H, scene_prior, M.delta_f_req)
    dispatch(H.enter_contract(INIT), cert=H.cert_eeis)

    trace, verdict, ev_exec = [], UNKNOWN, None
    while H.active not in (DONE, ABORT):
        telem = M.wait_contact()
        events = telemetry_to_events(telem)
        for ev in events:
            trace.append(ev)
            verdict = H.monitor.update(ev)
            if verdict is FALSE:
                H.enter(SAFEHOLD); break
            if H.exit_ready(ev) and H.current.commit_points_ok():
                H.transition(ev)
        ev_exec = build_exec_evidence(telem, H, trace)
        M.epir.append(ev_exec); M.epir.sync()
        if M.j_exec.verify(ev_exec):
            H.mark_commit(H.current)
        if H.unknown_too_long():
            H.enter(CLARIFY, question=min_clarification_set(ir))
        if M.has_pending_patch():
            H = apply_patch_on_commit(H, M.take_patch())
    return J_sm(ir, H, verdict, trace, H.residual)
```

class SMBudget:
    def __init__(self, compile_ops=200, ground_ops=100,
                 monitor_ops=500, clarify_rounds=2, patch_ops=50):
        self.B_compile, self.B_ground = compile_ops, ground_ops
        self.B_monitor, self.B_clarify, self.B_patch = \
            monitor_ops, clarify_rounds, patch_ops

    def mode(self):
        if self.used_compile >= self.B_compile:
            return 'fallback_ciEC'      # 第 60 轮单意图约束

            return 'default_conservative'
        if self.used_patch >= self.B_patch:

## 3. 复杂度与正确性

1. **顺序可核验性**：若 NSEC 以 verdict = ⊤ 结束，则证据轨迹满足 IR 的全部时序性质；不存在"逆序完成"却被判成功的情形（由 A67 + A69）。

### IP-161 NL-IR 解析（受限时序文法）

```python
class NLIRParser:
    def __init__(self, lexicon, slot_registry):
        self.lex = lexicon
        self.slots = slot_registry

    def parse(self, utterance: str) -> "IR":
        tokens = self._tokenize(utterance)
        seq = self._parse_sequence(tokens)          # '先…再…最后…'
        guards = self._parse_when(seq)              # '如果/碰到…就…'
        intervals = self._parse_duration(seq)       # '保持…两秒'
        atoms = [self._make_atom(t) for t in seq]
        ir = IR(atoms=atoms, order=self._order_of(seq),
                guards=guards, invs=intervals)
        ir.alpha = self.ambiguity(ir)
        return ir

    def ambiguity(self, ir):
        unbound = sum(1 for a in ir.atoms if not a.slot_bound())
        unobs = sum(1 for g in ir.guards
                    if not self.slots.observable(g.observable))
        return min(1.0, 0.5*unbound/max(1,len(ir.atoms))
                        + 0.5*unobs/max(1,len(ir.guards)))
```

    H = HSM(states=[INIT], transitions=[], inv={INIT: Safe.ALL})
    cur = INIT
    for atom in ir.topo_order():                 # 拓扑序展开，保序
