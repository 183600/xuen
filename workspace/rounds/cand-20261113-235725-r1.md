# 第 70 轮（承接第 69 轮「FLUID-RAS：流匹配多模态策略 × 主动多模态交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「任务分解」×「知识图谱」）

> R69 把不确定性拆成 aleatoric 与 epistemic，并让系统学会「问」：注视、探针、问句都是可生成、可认证、可审计的物理/语言动作；再用流似然做一条标定不可吸收的第二意见。但 R69 有两个从未被审视的隐含假设：
>
> **A1（任务已知）**：R69 的增广动作 ξ=(a,g) 定义在固定任务、固定时域 H 上，「我在做哪道题」不被视为不确定性来源。真实长时程多任务里，最贵的错误往往不是动作做歪，而是**把子任务拆错、顺序排错、把 A 任务当成 B 任务**——此时所有局部消歧都是在错误问题上求精确最优。
> **A2（证据局部且易失）**：R69 的「k 个正交证据源一致」只在一个交互窗口内成立；交互结果进入 AuditBuf 后仅作为下一轮成本先验，不被持久化、不被跨任务复用、不能参与非局部一致性检查。于是系统每轮从零求证，且同一次欺骗只要在**单轮内自洽**就能通过。
>
> 本轮两个灵感正好补上这两块：
> - **任务分解**把「问题结构」变成可细化、可比较、可带不确定性的对象（DAG + 细化偏序 + 可信反链），分解不确定性 U_dec 是比动作模态歧义更高一层的不确定性，且会**乘性放大**到下游；
> - **知识图谱**把已认证的交互结果变成带来源、时戳、TTL、独立性标签的持久知识；「正交证据」第一次有了可执行定义——**边不相交且来源类不相交的路径**——并支持非局部一致性检查与跨任务迁移。
>
> 核心命题：**把「问题结构」与「已有知识」也纳入 R68/R69 的不确定性纪律：结构未定时，局部交互的收益必须先乘以「分解正确」的概率；消解顺序自顶向下（结构 → 模态 → 动作 → 噪声）；知识图谱在实时环只读、追加写、禁止自证；任何一层证书不过，就逐指令退化为 R69，再退化为 R68。** 命名 **LATTICE-RAS**（Layered Task-Knowledge Lattice with Interactive Trust Certification for Risk-Adaptive Systems）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我到底在解哪道题、我已经知道什么、这些知识还成立吗**」——不确定性第一次上升到「问题本身」与「记忆本身」。

## 0. 直觉与动机

**灵感 1（任务分解 → 计划有形状，错误会乘性放大）**
直觉：人做长任务不是先精确选动作，而是先生成/选择分解：先搬箱子还是先开门？「整理房间」拆成「收衣服→叠→入柜」，还是「按区域清空→分类→归位」？分解错了，后面每一步都可以很「优」但整体全错。把分解表示为有向无环图，节点是子任务（前置条件/效果/后置条件/执行器），边是依赖；不同分解由**细化偏序**联系起来，系统维护一个「可信分解的反链」，而不是过早锁定一个。核心不是「拆得更细」，而是**粒度本身是决策变量，且带不确定性**。这层不确定性高于 R69 的动作模态歧义：它决定 R69 在哪个问题上工作。

**灵感 2（知识图谱 → 正交证据成为路径结构，记忆成为资产）**
直觉：R69 说「k 个正交证据源一致才定案」，却没说什么叫正交、证据存在哪。知识图谱给出可执行答案：每个断言是图上的一条或多条**来源路径**；两条路径正交 ⇔ 边不相交且来源类不相交（不是同一相机、同一人、同一个 LLM 家族）。于是 k_eff 不再是拍脑袋的 k，而是最大独立支撑路径数；欺骗相关性 ρ 由共享来源类决定。更重要的是，交互答案不再随轮次蒸发：它们成为带 provenance/timestamp/TTL 的节点，可被跨任务检索、可与非局部事实冲突、可被证伪器降级——这正面补上 R69「单轮自洽的谎」。

**灵感 3（三层不确定性 → 自顶向下消解是乘性杠杆）**
直觉：不确定性有层级：结构层 U_dec（哪道题/怎么拆）⊃ 模态层 U_epi（R69 的哪个动作模态）⊃ 噪声层 U_ale。局部的信息增益只作用在「分解正确」的那部分概率质量上：若分解正确概率只有 p，则局部消歧的期望收益 ≤ p·ΔR_local。因此共享预算下，先花在结构层往往比先花在动作层更值——不是因为它更「大」，而是因为**它乘在后面所有层上**。这把 R69 的 VoI 从一个标量升级为带杠杆率的调度问题。

**灵感 4（知识图谱不是数据库，而是需要维护的信念 → 真值维护/信念修正）**
直觉：图会旧、会错、会被投毒。所以 PKG 必须：只追加不删除（可审计）、每条边带来源与时戳、每个事实带 TTL 和证伪器、冲突时按来源信任偏序做 AGM 最小改动修正（高信任且新鲜者保留，低者降级为假设）、并禁止「自证」——一个事实的推导链不能包含它自己或由它产出的证书。R69 的 AuditBuf 只是成本先验；R70 把它升级为**有真值维护的记忆**。

**灵感 5（新风险 → 分解器与图谱可以互相作证）**
直觉：最危险的不是不知道，而是**自洽地错**。分解器提出的 DAG 会写进 KG，KG 的检索又会「确认」这个分解；证书由分解生成，分解又引用证书——一个闭环回声室。加上来源伪造、过期事实重放、环境文本注入（prompt injection 通过可读标签/文档进入分解器），系统可能以极高置信度执行一个完全错误的任务：DAG 漂亮、证书齐全、VoI 很高，只是问错了问题。所以本轮必须同时交付：分解证书、来源完整性与无自证规则、三通道异常诊断、以及严格的退化边界。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（LATTICE-RAS 总览）** LATTICE-RAS = (TDG, DUD, KGV, HVS, PKG, TMS, KGA, DCR, RAS-WM‡)。四条不变式：
(i) **实时环零学习写操作**：继承 R68 定义 276-i；实时环对 PKG **只读**，任何写入只发生在认证过的慢路径；
(ii) **分层消解顺序**：结构层 → 模态层 → 动作层 → 噪声层；当高层 U 未消解且预算可及，低层不得宣称「已消解」；
(iii) **来源完整性**：PKG 追加写、推导 DAG 无环、禁止自证；每条写入需 ≥2 条独立支撑路径或一次已认证物理探针；
(iv) **严格包含**：单节点 TDG 且不使用 KG 证据 ⇒ 与 R69 逐指令相同；任一层证书不过 ⇒ λ 单调不降地退化到 R69/R68。

**定义 311（任务分解图 TDG）** D = (V, E, r)，节点 n_i = (id, sub, Pre_i, Eff_i, Post_i, exec_i, cost_i, conf_i)；r 为根任务，Pre_r = 初始状态，Post_r = 目标。E ⊆ V×V 为依赖边。合法分解须：无环、每个节点的 Pre 可由某个前驱 Post（或初始状态）满足、叶子可由 R69 的流策略在 𝒜_+ 上执行、深度 ≤ d_max、资源总量 ≤ B_task。

**定义 312（细化偏序与可信反链）** D_1 ⪯ D_2 当且仅当 D_2 可由 D_1 通过把若干节点展开成子 DAG 得到（D_1 是 D_2 的抽象）。深度截断下公共细化未必存在，故只要求**上半格（join-semilattice）**，不假设 meet 总存在；系统维护「极大可信分解」的反链 𝒟 = {D_1,…,D_m} 及权重 w_D，而不是锁定单一 D*。

**定义 313（分解不确定性 U_dec）** 设 π_cert = 至少存在一个通过证书的分解的后验概率，m = |𝒟|，w = 反链上的归一化权重。定义
U_dec = (1 − π_cert) + π_cert · H(w)/log m ∈ [0,1]，
其中 m=1 时熵项取 0。语义：π_cert=0（无合法分解）时 U_dec=1；唯一合法分解时 U_dec=0；多个都合法且权重均匀时趋近 1。

**定义 314（来源知识图谱 PKG）** 节点类型：实体、事实、计划、证书；边 (s, p, o, t, prov, τ, ttl, indep_class, deriv_hash)。prov 记录来源类 ∈ {probe, certified_sensor, human_verified, human_single, llm_prior}；τ 为信任值；ttl 为有效期；indep_class 标记共同原因（同一相机/同一人/同一模型家族）；deriv_hash 为推导 DAG 哈希。全图 append-only，以哈希链保证不可静默改写。

**定义 315（来源信任偏序与合并）** 来源类上定义偏序 τ(probe) ≻ τ(certified_sensor) ≻ τ(human_verified) ≻ τ(human_single) ≻ τ(llm_prior)。单源结论的信任 ≤ min(支撑 τ)；若存在 ≥2 条独立支撑路径，可提升到这些来源的 join。信任提升不可越过「独立」这一硬条件——共谋的两源仍是单源。

**定义 316（证据独立性与有效证据数 k_eff）** 断言 f 的支撑路径集 Π(f)。π_i ⟂ π_j ⇔ 边不相交且 indep_class 不相交。k_eff = 贪心极大独立路径集的大小（它是真实最大独立集的下界，故安全界仍然成立）。共享来源类的相关性记为 ρ，用于引理 20。

**定义 317（知识引导的信息动作 KGV）** 候选信息动作除 R69 的看/问/触外，新增图查询与判别性探询 g_kg：选择能最大区分 𝒟 中分解假设、或能最大压低某条高杠杆事实不确定性的多跳查询/物理探针。代价 c(g_kg) 含查询延迟、社交成本与安全认证开销。

**定义 318（分层 VoI 调度 HVS）** 对候选信息动作 g 定义优先级
priority(g) = leverage(D_g) · VoI_local(g) − c(g)，
其中 leverage(D_g) = 该动作影响的下游风险质量（结构层近似为任务级损失 L_task 与局部分辨率之比）。调度规则：只要结构层还有正优先级候选且预算允许，就不把预算花在模态层；结构层稳定后再交给 R69 的 MINT。

**定义 319（真值维护与信念修正 TMS）** 冲突时在信任偏序下做 AGM 最小改动：保留高信任且新鲜者，低者降级为 hypothesis 并保留推导链；依赖被降级事实的结论按 TMS 传播降级；不物理删除，只标记 retired。任何修正写入 PKG 的修正日志，参与证书。

**定义 320（陈旧性与证伪器 STG）** 每个事实 f 带 ttl(f) 与证伪器 test_f。过期或证伪失败 ⇒ 降级为 hypothesis，并抬高 U_kg。证伪器在慢路径机会式执行，绝不在实时环运行。

**定义 321（图谱一致性异常 KGA）** 执行轨迹 τ_trace 与当前计划在 PKG 中蕴含的 Pre/Post/Eff 之间的违反代价
a_kg = Σ_j w_j · violation_j(τ_trace, PKG),
形成第三条独立通道。三通道联合 (r_res, Δa, a_kg) 可分离四类故障：
| r_res | Δa | a_kg | 诊断 |
|---|---|---|---|
| 高 | 高 | 低 | 传感器/执行器漂移 |
| 低 | 高 | 低 | 被标定吸收的缓变故障（R68 的洞） |
| 低 | 低 | 高 | 分解错误 / 任务边界错 / KG 事实过期 |
| 高 | 低 | 高 | 环境真实变化 → 旧知识失效 |

**定义 322（图谱写纪律 KWD）** 实时环只读；写入仅发生在慢路径，且满足 ≥2 条独立支撑路径或一次已认证物理探针；若候选事实的 deriv_hash 闭包包含「由该事实参与产出的证书」，则拒绝写入（无自证）。写入前后记录哈希链，供 VQAuditor 审计。

**定义 323（分解证书 DCR）** Valid_D(D) ⇔ 定义 311 的合法性 ∧ 每个叶子的动作空间被 R69 证书覆盖 ∧ 每个节点的安全包络 ⊆ 已认证包络 ∧ 切换点 s*（子任务边界/安全姿态）已标注。任一不满足 ⇒ 禁止执行该分解。

**定义 324（知识不确定性 U_kg）** 设 F_used 为当前计划实际引用的事实集，
U_kg = Σ_{f∈F_used} κ_f · (1 − τ(f)) · s(f) ∈ [0,1]，
其中 κ_f 为使用权重（归一化），s(f) 为陈旧度（TTL 剩余与证伪器通过率的函数）。

**定义 325（证书 J_LATTICE）** J_LATTICE = (J_FLUID, dec_hash, refinement_depth, antichain_size, kg_query_hash, k_eff, conflict_log_hash, staleness_ratio, a_kg_p95, lattice_ver)。Valid ⇔ Valid(J_FLUID) ∧ Valid_D(D*) ∧ 写纪律满足 ∧ 三通道诊断不触发冻结条件。

**定义 326（威胁模型与退化边界）** ℰ_LATTICE = ℰ_FLUID × ℰ_KG × ℰ_dec × ℰ_echo，其中 ℰ_KG = 节点注入 / 来源伪造 / 过期事实重放 / 跨源共谋；ℰ_dec = 环境文本提示注入 / 幻影子任务 / 错误顺序 / 粒度爆炸；ℰ_echo = 分解器与图谱互相作证的自证闭环。当 |V|=1、𝒟 为单元素、且 F_used=∅ 时，U_dec=U_kg=0，LATTICE-RAS 逐指令退化为 R69；再令 U_epi 未消解，则退化为 R68。

## 2. 关键算法骨架

```python
# IP-264/265 TDG + 细化（候选来自冻结 LLM 检索 + R69 流策略，均只读 PKG）
class Decomposer:
    def propose(self, task, o, kg, depth):
        ctx = kg.retrieve(task, hops=2)                     # 只读，带 provenance
        cands = self.llm.propose(task, ctx)                 # 冻结 LLM，输出结构
        cands += self.flow.propose_subgoals(task, o)        # 复用 R69 策略产生子目标
        return [refine(d, depth) for d in cands if acyclic(d)]

# IP-266 DUD：分解不确定性
def decompose_uncertainty(antichain, kg):
    w = softmax([score(d, kg) for d in antichain])
    pi_cert = certified_fraction(antichain)                  # 证书通过率
    H = entropy(w) / log(max(len(antichain), 2))
    U_dec = (1 - pi_cert) + pi_cert * H
    return U_dec, w, pi_cert

# IP-267/269 PKG 查询与独立性
def query_with_independence(kg, assertion, k_max=3):
    paths = kg.paths(assertion, max_hops=k_max)
    keep  = greedy_independent(paths)        # 边不相交 + indep_class 不相交
    return keep, len(keep)                   # k_eff

# IP-270/271 分层 VoI：结构层优先，模态层复用 R69 MINT
def schedule(antichain, modes, kg, budget):
    U_dec, w, pi_cert = decompose_uncertainty(antichain, kg)
    if budget.allow_struct() and U_dec > TAU_DEC:
        g = kgv.choose(antichain, kg, budget)               # 图查询 / 判别探询
        if g is not None and dcr.valid_info(g, kg):
            return ('struct', g)
    if pi_cert > 0 and U_epi(modes) > TAU_EPI:
        return ('mode', R69_MINT(modes, budget))
    return ('none', None)

# IP-272/273 TMS + 陈旧性（只在慢路径）
def revise(kg, new):
    if kg.self_confirms(new): return kg.reject(new, reason='self-confirmation')
    if kg.contradicts(new):
        keep, demote = agm_minimal_change(kg, new, trust_lattice)
        kg.demote(demote)                                  # 传播到依赖结论
        kg.append(keep)
    return kg

def stale_sweep(kg, now):
    for f in kg.facts():
        if now > f.ttl or not run_falsifier(f):
            kg.demote(f)                                   # 只降级，不删除

# IP-274 KGA：第三条独立通道
def kg_anomaly(kg, trace, plan):
    return violation_cost(trace, kg.implied_pre_post_eff(plan))

# IP-278 主闭环：结构 → 模态 → 动作，失败逐级退化
def LATTICE_RAS_round(M, obs):
    r68 = M.mtm_forward(obs)
    r69 = M.fluid_step(r68)                                  # R69 原样路径
    antichain = M.tdg.credible_antichain(r69.z, M.pkg)       # 只读
    U_dec, w_D, pi_cert = M.dud.evaluate(antichain, M.pkg)
    a_kg = M.kga.score(M.pkg, M.trace, M.plan)
    # 1) 结构层：先确认「在做哪道题」，且只在切换点改分解
    if U_dec > TAU_DEC and M.budget.allow_struct():
        g_s = M.kgv.choose(antichain, M.pkg, M.budget)
        if g_s is not None and M.dcr.valid_info(g_s, M.pkg):
            ans = M.execute_info(g_s)
            M.tms.revise(M.pkg, ans)                         # 慢路径写
            antichain, U_dec = M.tdg.update(antichain, M.pkg)
    # 2) 结构未过证书 / 存在未消解冲突 → 精确退化为 R69 保守分支
    if not M.dcr.valid(M.tdg.select(antichain), M.pkg) or M.tms.has_open_conflict():
        return M.r69_round(obs, force_conservative=True)
    # 3) 模态层：交给 R69，分解已认证
    out = M.r69_round(obs)
    # 4) 三通道诊断：只有慢路径允许改知识
    slow = diagnose(r68.r_res, out.delta_a, a_kg)
    if slow == 'kg_or_task_inconsistent':
        out.lam = max(out.lam, 0.8)
        out.k   = M.dcr.freeze_to_last_certified(out.k)      # 冻结，不突变
    # 5) 证书齐全才写知识；实时环绝不写
    if M.certified and M.pkg.two_independent_support(out) and not M.pkg.self_confirms(out):
        M.pkg.slow_write(out)
    return out
```

## 3. 推导

**引理 19（分层杠杆：自顶向下优先）** 设分解正确概率为 p，分解错误时任务级损失为 L_task，正确时局部风险为 R_local，执行局部信息动作可降低 ΔR_local。则局部优先的期望风险为
R_local-first = (1−p)·L_task + p·(R_local − ΔR_local)，
其相对不交互的改善仅为 p·ΔR_local，且被 (1−p)·L_task 的地板卡住。若结构层信息动作把 p 提到 p′，则结构优先的改善为 (p′−p)·(L_task − R_local)。因此当
(p′−p)·(L_task − R_local) ≥ p·ΔR_local
时自顶向下严格占优；当 L_task ≫ R_local 时恒占优。系：**在任务未验证前做局部消歧，期望风险不可能低于 (1−p)·L_task 的地板**——这正是 R69 在错误分解上「把错题做得更精确」的盲点。

**引理 20（来源独立性的欺骗上界）** 设单源欺骗率 δ_p，证据集有 k_eff 条两两独立路径，共享来源类的最大成对相关性为 ρ<1。则错误采纳率
P_err ≤ δ_p · ρ^{k_eff−1} + ε_s，
其中 ε_s 为证伪器漏检率。与 R69 引理 18 同形，但 k 从「假设的正交源数」变成「由路径结构算出的 k_eff」：一条共因边可把 k_eff 降到 1，从而把上界退回 δ_p；反之，两条边不相交、来源类不同的路径才能把错误率指数压低。系：**「问两次」不等于「两个正交证据」**，只有来源路径独立才算。

**引理 21（无自证与真值维护可靠性）** 在 append-only 哈希链、推导 DAG 无环、写入需外部支撑（定义 322）三条约束下，最小改动修正不会提升任何「推导闭包含自身」的事实；依赖被降级事实的结论按 TMS 传播降级；过期/证伪失败事实的存活时间被 TTL 与证伪器覆盖率上界界定。故回声室（ℰ_echo）在该写纪律下不可构造，陈旧知识的影响随时间有界。

**定理 18（LATTICE 严格包含 R69）** 在定义 311–326 与 A95–A99 下：单节点 TDG、单元素 𝒟、F_used=∅ 时 U_dec=U_kg=0，LATTICE 的调度、缩放与执行与 R69 **逐指令相同**；一般情况下，由于 β,γ ≥ 0 且未消解的高层不确定性只进入 λ_floor 而不进入 resolution bonus，λ 单调不降，故任意状态期望风险 ≤ R69。结构层任何证书失败都路由到 R69 保守分支，安全侧不做让步。

**定理 19（分解切换的安全与无突变）** 分解切换 D→D′ 仅在已标注切换点 s* 发生，且需 Valid_D(D′) 与两侧安全包络之并的认证；切换原子执行、旧分解在新分解首个动作提交后退役。若认证失败或超时，冻结在最后已认证分解并令 λ←λ_floor；继承 R68 定理 15 的提交/换装不变式与 R69 定理 17 的交互安全，控制连续、无突变。

## 6. 本轮最大风险

**一句话**：LATTICE-RAS 把「任务分解」与「知识图谱」放到同一个信任闭环里，最危险的失效不是不知道，而是**分解器写下的图被图谱检索确认、图谱的边又被分解器引用、证书再为二者背书——一个自洽的回声室让系统以极高置信度执行一个完全错误的任务**：DAG 漂亮、k_eff 很高、证书齐全，只是问错了问题；这比 R69「追问一个幻影」更高一层，因为现在连「该问什么」都由被污染的图谱决定。

```python
class Decomposer:
    def propose(self, task, o, kg, depth):
        ctx   = kg.retrieve(task, hops=2)                   # 只读，带 provenance
        cands = self.llm.propose(task, ctx)                 # 冻结 LLM，输出结构

def decompose_uncertainty(antichain, kg):
    w = softmax([score(d, kg) for d in antichain])
    pi_cert = certified_fraction(antichain)
    H = entropy(w) / log(max(len(antichain), 2))
    return (1 - pi_cert) + pi_cert * H, w, pi_cert

# IP-267/269 PKG 查询与独立性
def query_with_independence(kg, assertion, k_max=3):
    paths = kg.paths(assertion, max_hops=k_max)
    keep  = greedy_independent(paths)     # 边不相交 + indep_class 不相交
    return keep, len(keep)                # k_eff（真实最大值下界）

# IP-270/271 分层 VoI（结构层优先，模态层复用 R69）
def schedule(antichain, modes, kg, budget):
    U_dec, w, pi_cert = decompose_uncertainty(antichain, kg)
    if budget.allow_struct() and U_dec > TAU_DEC:
        g = kgv.choose(antichain, kg, budget)
        if g is not None and dcr.valid_info(g, kg): return ('struct', g)
    if pi_cert > 0 and U_epi(modes) > TAU_EPI:
        return ('mode', R69_MINT(modes, budget))
    return ('none', None)

# IP-272/273 TMS + 陈旧性（只在慢路径）
def revise(kg, new):
    if kg.self_confirms(new): return kg.reject(new, reason='self-confirmation')
    if kg.contradicts(new):
        keep, demote = agm_minimal_change(kg, new, trust_lattice)
        kg.demote(demote)                 # 依赖结论按 TMS 传播降级
        kg.append(keep)
    return kg

def stale_sweep(kg, now):
    for f in kg.facts():
        if now > f.ttl or not run_falsifier(f): kg.demote(f)
```

## 4. 推导

**引理 19（分层杠杆）** 设分解正确概率 p，错分解任务级损失 L_task，正确时局部风险 R_local，局部交互降 ΔR_local。局部优先的期望风险 `(1−p)L_task + p(R_local−ΔR_local)`，改善仅 `p·ΔR_local` 且被 `(1−p)L_task` 地板卡住；结构层把 p→p′ 的改善为 `(p′−p)(L_task−R_local)`。当 `(p′−p)(L_task−R_local) ≥ p·ΔR_local` 时自顶向下严格占优；`L_task≫R_local` 时恒占优。系：分解未验证前，局部消歧无法把期望风险压到 `(1−p)L_task` 地板以下。

**引理 20（来源独立性上界）** 单源欺骗率 δ_p、k_eff 条两两独立路径、共享来源类最大成对相关 ρ<1 时，`P_err ≤ δ_p·ρ^{k_eff−1}+ε_s`。与 R69 引理 18 同形，但 k 由路径结构算出而非假设：共因边可把 k_eff 压到 1；只有边不相交且来源类不同的路径才指数压低错误率。系：「问两次」≠「两个正交证据」。

**引理 21（无自证与 TMS 可靠性）** append-only 哈希链 + 推导 DAG 无环 + 写入需外部支撑 ⇒ 最小改动修正不会提升任何推导闭包含自身的事实；依赖被降级事实的结论按 TMS 传播降级；陈旧事实存活时间被 TTL 与证伪器覆盖率上界界定。故回声室不可构造，陈旧知识影响随时间有界。

**定理 18（LATTICE 严格包含 R69）** 单节点 TDG、单元素反链、F_used=∅ ⇒ `U_dec=U_kg=0`，调度/缩放/执行与 R69 逐指令相同；一般情形 β,γ≥0 且未消解高层不确定性只进 λ_floor、不进 resolution bonus ⇒ λ 单调不降、期望风险 ≤ R69；结构证书失败一律路由 R69 保守分支。

**定理 19（分解切换安全与无突变）** 切换仅在已标注切换点 s* 发生，需 Valid_D(D′) 与两侧安全包络之并认证；切换原子、旧分解在新分解首动作提交后退役；失败/超时冻结最后认证分解并 λ←λ_floor；继承 R68 定理 15 与 R69 定理 17，控制连续、无突变。

## 7. 本轮最大风险

**一句话**：LATTICE-RAS 把「任务分解」与「知识图谱」放进同一个信任闭环，最危险的失效不是不知道，而是**分解器写下的图被图谱检索确认、图谱的边又被分解器引用、证书再为二者背书——一个自洽的回声室让系统以极高置信度执行一个完全错误的任务**：DAG 漂亮、k_eff 很高、证书齐全，只是问错了问题；这比 R69「追问一个幻影」更高一层，因为现在连「该问什么」都由被污染的图谱决定。
