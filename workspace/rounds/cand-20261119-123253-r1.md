# 第 1 轮（新灵感循环第 1 轮；本轮灵感：「演示数据」×「移动底盘」；技术基线延续 v15）

> **基线**：第 13 轮 MetricVoiceGauge-NCD-HUTDH v15（技能扩散版：SCD/DSD/DCA/EDC，定义 607–626；引理 125–130；实验 E661–E670）。
> **本轮纪律**：**演示是带底盘锚点的条件证据 + 底盘包络是技能证书的定义域 + 支撑空洞只允许收缩或主动补证**。不推倒 v15：v15 的 SCD/DSD/DCA/EDC、v13 的 AIO/CPD/DGC/DDL/RTCR、v12 的 USG/TGC/BAA/GAGP/UC、v11 的 HAS/HCC/HATD/HDT、v10 的 NGE/DSL/CC/CWM/CAE/NCP、v9 的 AC/MW/ID、v8 的 DA/SPR/Cal 与九不变式全部保留。六个新组件——DABE（演示锚定底盘包络）、BIDE（底盘意图估计）、DSC（演示支撑证书）、CACG（底盘锚定一致性守卫）、MDDL（移动—演示退化阶梯）、BSJR（底盘—技能联合路由）——一律以**收缩算子**接入：只收缩授权集、只增加定位/支撑余量；失效即严格退回 v15（引理 140），再沿 v15→v14→…→v6 退化链退回。本轮只做三件事：把“演示”从轨迹重放改写为**带底盘位姿条件的能力证据**、把“移动底盘”从运动学附件改写为**技能证书的定义域变量**、把二者合成一条“证据不足就换锚点/收缩、绝不外推”的可执行阶梯。

## 0. 直觉与动机

**灵感 1（演示数据 → 演示不是策略，而是带底盘锚点的条件能力样本）**
直觉：人类遥操作演示时，总要先决定“把底盘停在哪”。这个决定很少被记录成标签，却悄悄进入了每一条轨迹：手臂的可达性、躯干的遮挡、相机的视场、甚至抓取时的支撑稳定性，都是在某个 `b_i` 条件下才成立的。把演示当成“末端轨迹 + 动作标签”重放到移动底盘上，实际上是在做一次未经声明的条件分布迁移——同一条末端轨迹在另一个底座位姿处可能根本不可达，或者可达但力矩/稳定性余量已经为负。更危险的是，演示数据天然只覆盖人类觉得“顺手”的底座位姿，恰好把新颖任务最需要底盘移动的边界留成空白。核心创新：**演示锚定底盘包络（Demonstration-Anchored Base Envelope, DABE）+ 底盘意图估计（Base-Intent Demonstration Estimator, BIDE）**。DABE 不学一个“底盘策略”，而是对每个技能 `s` 在任务状态 `x` 处构造一个**已演示锚点支撑的底座位姿包络** `E_demo,s(x) ⊆ SE(2)`；BIDE 从演示中恢复人类选择底座位姿的条件倾向 `π_d(b|x)`，用于重加权共形覆盖与主动补证。反直觉点：**演示数据的主要价值不是告诉机器人“怎么动”，而是告诉机器人“站在哪里才算被证据支持”**；底盘位姿应当被当作证书的定义域来认证，而不是被当作策略的额外输出维度去拟合。

**灵感 2（移动底盘 → 底盘位姿是证书的定义域，不是控制器的一个自由度）**
直觉：移动底盘常被当作“多了一个可动基座”：先规划一个底盘位置，再在上面做臂的操作。但底座位姿同时改变可达性、静态/动态稳定性、碰撞几何、相机视场与操作力余量；更关键的是，底盘位姿从来不是精确已知的——轮式里程计会漂移，地面会打滑，悬架会柔顺下沉，重载会改变支撑多边形。于是“先选一个 `b` 再做安全检查”在结构上就错了：安全的对象不是一个点 `b`，而是**以估计位姿为中心、按定位/滑移/柔顺膨胀后的包络**。核心创新：**把每个技能的证书改写为底座位姿的函数 `Acc_s(x;b)`，并要求执行时使用被定位不确定球侵蚀后的包络 `Ê_s(x) ⊖ B(0,r_loc)`**。反直觉点：**底盘定位精度的提升不应主要用来“把包络做大”，而应优先用来“把包络做可信”**；在低纹理、强反光、轮子打滑的场景里，宁可让底盘停在更保守的锚点上，也不要相信一个几何上很大、统计上未被演示覆盖的包络。

**灵感 3（演示×底盘 → 支撑空洞、锚点修复与单调退化）**
直觉：把“几何可行”与“演示支持”叠在一起，会出现一类新的危险区域——**支撑空洞**：几何上 `b` 完全可达、稳定、无碰撞，但演示数据从未在附近成功过。传统模仿学习会在这里外推，传统几何规划会在这里放行，两者都看不见“没有证据”这件事。正确反应不是用更大的模型去填补，而是二选一：**移动到最近的已演示锚点**，或**主动请求一次该锚点处的演示/标定**；如果时间、移动预算或定位置信度都不允许，就沿阶梯收缩到停/问。核心创新：**演示支撑证书（Demonstration Support Certificate, DSC）+ 移动—演示退化阶梯（Mobility–Demonstration Degradation Ladder, MDDL）+ 底盘—技能联合路由（Base–Skill Joint Router, BSJR）+ 主动演示锚点修复（Active Demo-Anchor Repair, ADAR）**。它们把“站在哪、用哪个技能、证据够不够、还来不来得及”合成一次带预算的联合选择。反直觉点：**最保守的档位不一定是原地不动**——原地不动若落在支撑空洞里，反而应主动退到最近的已演示锚点；退化方向应沿“证据密度”而不是沿“移动距离”排序。

**三者如何统一**
统一为 **v15 语义层之上的“底盘—证据”实现层**：v15 回答“在状态 `x` 下哪些技能被授权”（`Exec_v15`），v16 回答“从哪个底座位姿 `b`、凭哪一片演示证据、在什么定位置信度下，这些技能才被认证”（`Exec_v16`）。DABE 把技能证书扩展成底座位姿上的包络；BIDE 把演示中的底盘选择恢复成条件分布；DSC 把“有没有证据”变成可检查的覆盖证书；CACG 在运行时检查真实底盘是否仍落在认证锚点内；MDDL 在时间/定位/覆盖恶化时只向更保守方向移动；BSJR 在可达锚点、技能档位与移动成本之间做一次联合选择。共享状态 `ζ_mob=(b̂, r_loc, E_loc, E_demo, ρ_d, ℓ, B_move, B_time, anchor_ref, mode)`。**DABE 回答“底盘可以站在哪里”，BIDE/DSC 回答“站那里有没有证据”，CACG 回答“现在真的还站在那里吗”，MDDL/BSJR 回答“这一帧到底站哪、做哪一档”**。

## 1. 研究问题（轮次升级版）

- **Q1（演示的条件化与底盘的证据语义）**：如何从 `(x_i,b_i,ξ_i,ℓ_i)` 中区分“任务相关”的底盘选择与“采集便利”的底盘选择？演示成功率 `y_i` 与底盘位姿之间存在选择偏差时，`π_d(b|x)` 的重加权何时仍能给出可信的覆盖证书？一个技能在 `b` 处“演示过”与“被认证”之间的最小差距是什么？
- **Q2（底盘包络的可证构造）**：如何在可达性、碰撞、支撑/倾覆、视场、力矩余量五类约束下构造 `E_s(x)` 的保守外逼近？定位漂移、轮子打滑、悬架柔顺、载荷变化应如何进入 `r_loc` 并做集合侵蚀？底盘在操作中被要求“锁死”时，锁死失败（蠕动、下沉）如何被证书吸收？
- **Q3（支撑空洞与联合路由）**：当几何包络与演示支撑出现空洞时，何时应换锚点、何时应主动补证、何时应收缩技能档位？在移动成本、时间预算、假拒绝率与覆盖之间是否存在可证明的三难下界？联合路由如何在未知的本帧耗下保持单调、无越级、无抖振？
- **Q4（与 v15 的兼容与活性）**：DABE 的包络取交是否会误删 v15 的可行技能？DSC 的覆盖证书与 v15 的 DCA/EDC 是否会重复计错或相互抵消？底盘停在空洞边缘时，MDDL 是否会频繁触发 `a_ask` 造成死锁？新增模块能否守住 50Hz/p99≤22ms，并严格退回 v15？

## 2. 设计原则（在 P22–P24 基础上新增 P25–P27）

**P25 演示即条件证据律（Demonstration as Conditional Evidence）**
演示样本必须写成带底座位姿条件的三元组 `(x_i, b_i, y_i)`；任何从演示得到的技能/策略只能在 `(x,b)` 的演示支撑域内被用于放行。演示支撑之外，只允许用于排序、热身或主动补证，**不得用于授权**。对演示采集分布 `π_d` 与部署分布 `π_task` 的差异，必须显式重加权并给出覆盖下界；差异不可估时按最保守锚点处理。

**P26 底盘即证书定义域律（Chassis as Certificate Domain）**
底座位姿不是外生常量，而是每个技能证书的一个定义域变量：`Acc_s(x;b)`。执行前必须先构造包络、再做定位不确定球侵蚀、再与演示支撑取交；禁止“先选底盘点、再补安全检查”。底盘在操作中必须处于认证锚定模式；若蠕动/下沉/滑移超出 `r_loc`，立即降档，不得把“锁死”当作无条件的物理保证。

**P27 支撑空洞只收缩或补证律（Support Holes: Shrink or Re-Evidence, Never Extrapolate）**
几何可行但演示未覆盖的底座位姿必须被显式标记为支撑空洞。对空洞只允许三种处理：退到最近的已演示锚点、主动请求该锚点处的演示/标定、或收缩到第 0 档停/问。禁止用插值、外推、生成模型或“相邻锚点应该差不多”来填补空洞；禁止在空洞内执行任何非回退技能。

## 3. 与基线的接口（如何退化）

- **DABE 失效** ⇒ 包络退化为固定名义基座处的单点 `{b_0}`，每个技能只按 v15 的 `Acc_s(x)` 认证，**等价 v15 固定基座路径**；
- **BIDE 失效** ⇒ 放弃 `π_d` 重加权，演示锚点按均匀权重处理，覆盖下界退化为未加权共形（更保守而非更激进），**等价“v15 + 均匀锚点”**；
- **DSC 失效** ⇒ 演示支撑退化为仅精确命中的演示锚点集合 `{b_i}`，`ρ_d≡0`，禁止锚点之间插值，**等价“v15 + 离散演示重放”**；
- **CACG 失效** ⇒ 令 `r_loc=∞`，包络侵蚀为空，系统只能停在最后一个已验证锚点并执行停/问，**等价 v15 的固定基座安全回退**；
- **MDDL 失效** ⇒ 只保留单一档位：固定锚点 + 最保守技能，无阶梯、无塌缩，**等价“v15 证书 + 单点底盘”**；
- **BSJR 失效** ⇒ 由 v15 静态调度器按固定顺序调用技能，底盘固定在最后认证锚点，**等价 v15 调度路径**；
- **ADAR 失效** ⇒ 不主动补证，支撑空洞直接触发第 0 档停/问，**等价“只收缩、不修复”的保守策略**；
- **全部失效** ⇒ MetricVoiceGauge-NCD-HUTDH v15，再沿 v15→v14→v13→…→v6 退化链退回；
- **安全继承**：DABE 只做包络取交与不确定球侵蚀，BIDE 只做重加权（只影响证据权重、不影响授权阈值），DSC 只做覆盖检查，CACG 只做一致性检查，MDDL 只做单调降档，BSJR 只做取交后的选档。所有端口均不能新增授权或放宽任何 v15 阈值；`Exec_v16 ⊆ Exec_v15` 由引理 134 与引理 140 保证。

## 4. 预期贡献

1. **演示的条件化证据观**：把演示从“轨迹/动作标签”改写为“带底座位姿锚点的能力证据”，给出 `π_d(b|x)` 的重加权共形覆盖与支撑空洞的可检查定义，填补“模仿学习在底盘自由度上不可证”的空白；
2. **底盘包络证书**：把技能证书扩展为 `Acc_s(x;b)` 的位姿域，显式吸收定位漂移、轮滑、柔顺与锁死失败，并用集合侵蚀给出 sound 的执行包络；
3. **支撑空洞的主动修复与单调阶梯**：把“换锚点、补演示、收缩档位”合成一个带预算的联合路由，证明其单调退化、无越级、无外推，并给出覆盖—移动—假拒绝的三难下界；
4. **语义层—证据层分离**：v15 管“允许什么”，v16 管“在哪个底盘锚点上、凭哪片证据、以多大置信度实现”，用 `Exec_v16⊆Exec_v15` 把移动性增益与安全解耦；E671–E690 覆盖包络 soundness、定位侵蚀、加权覆盖、空洞修复、阶梯单调、平台迁移与端到端消融。

## 5. 本轮最大风险

**一句话**：演示支撑与底盘包络都来自“人类在顺手位置采集的数据”和“几何/统计模型给出的保守外逼近”，而部署时最危险的情形恰恰是底盘停在**几何包络内部、统计覆盖下界之内、定位球也自洽、但演示从未在附近成功过**的支撑空洞边缘——此时系统会同时通过几何检查、共形覆盖检查与锚定一致性检查，执行一个“处处有证书、却从未被任何演示支持过”的底盘—操作联合决定，即**几何可行的、统计覆盖的、却证据上空的错误安全决定**。

## 0. 核心符号体系（定义 627–646）

| 符号 | 含义 |
|---|---|
| `b = (x_b, y_b, θ_b) ∈ SE(2)` | 底盘平面位姿；`b̂_t` 为其在线估计 |
| `B_loc(b̂, r_loc)` | 以 `b̂` 为中心、半径 `r_loc` 的位姿不确定球；`r_loc` 含里程计、轮滑、柔顺、载荷与时间累积项 |
| `d_i = (x_i, b_i, ξ_i, ℓ_i, y_i)` | 第 `i` 条演示：任务状态、底盘位姿、轨迹、语言/技能标签、成功标记 `y_i∈{0,1}` |

| `H_s(x) = E_loc,s(x) \ A_δ(x)` | 支撑空洞：几何可执行、但演示从未在附近成功过的底座位姿 |
| `π_d(b|x)` | 演示采集分布诱导的底盘选择条件密度 |
| `π_task(b|x)` | 部署时任务/人给出的底盘选择条件密度 |
| `w(b|x) = π_task(b|x) / π_d(b|x)` | 密度比；截断上界 `W_max = sup w` |
| `ρ_d(x) = P_{π_task}[x ∈ A_δ]` | 演示支撑覆盖率 |
| `U_demo(x) ≥ 1−α_d−TV(π_task,π_d)` | 加权共形覆盖下界；`TV` 为全变差距离 |
| `κ(b,x) = 1[ B(b, r_loc) ⊆ E_loc,s(x) ∩ A_δ(x) ]` | 锚定一致性指示：定位球整体落在认证支撑内 |
| `ℓ ∈ {0,…,m}` | 移动—演示阶梯档位；`ℓ` 越大，允许的包络与技能越丰富 |
| `E_0 ⊆ E_1 ⊆ … ⊆ E_m`，`A_0 ⊆ A_1 ⊆ … ⊆ A_m` | 阶梯的包络/锚点单调嵌套条件 |
| `B_move, B_demo, B_time` | 本帧移动预算、补证预算、时间预算 |
| `b_ref` | 基准演示锚点；`d_slip` 为实际相对 `b_ref` 的滑移/蠕动量 |
| `J(b,s) = Δprogress − λ_t·τ_move − λ_d/ρ_d − λ_e·E_move` | 联合路由的边际收益分数（`ρ_d>0`） |
| `(b*, a*, ℓ*)` | 本帧选定的底盘锚点、动作、阶梯档位 |
| `Exec_v16` | v16 有效执行集：所有通过 `E_loc ∩ A_δ`、CACG 与 v15 证书的动作—底盘对 |
| `ζ_mob = (b̂, r_loc, E_loc, A_δ, ρ_d, U_demo, ℓ, B_move, B_demo, B_time, b_ref, mode)` | 移动—演示共享状态 |

> 说明：定义 627–646 延续 v15 的 607–626；`647–654` 为组件内部状态与审计量，避免与 v15 的 DCA/EDC 符号冲突。v15 的 `DCA` 管“技能组合的数据集校准”，v16 的 `DSC` 管“底座位姿维度的演示支撑”，二者正交，部署时取交。

# IP-402 Demonstration-Anchored Base Envelope：底座位姿域上的技能证书
class DemoAnchoredBaseEnvelope:
    def __init__(self, v15_cert, chassis, loc_model, delta_x=0.05, delta_b=0.08):
        self.cert = v15_cert              # v15 技能证书 Acc_s(x)
        self.chassis = chassis            # 运动学/动力学/几何/视场模型
        self.loc_model = loc_model        # 里程计、轮滑、柔顺、载荷模型
        self.delta_x, self.delta_b = delta_x, delta_b

    def r_loc(self, x, ground, load, elapsed):
        # 定位不确定球半径：里程计漂移 + 轮滑 + 悬架柔顺 + 载荷引起的下沉
        return self.loc_model.radius(x, ground, load, elapsed)

    def geometric_envelope(self, s, x):
        # 五类约束的保守外逼近：可达 / 无碰撞 / 支撑稳定 / 视场 / 力矩余量
        return (self.chassis.reachable_base_set(s, x)
                & self.chassis.collision_free_base_set(s, x)
                & self.chassis.stability_base_set(s, x)
                & self.chassis.fov_base_set(s, x)
                & self.chassis.manipulation_margin_set(s, x))

    def envelope(self, s, x, r_loc):
        E_hat = self.geometric_envelope(s, x)      # 外逼近 Ê_s(x)
        E_loc = erode(E_hat, r_loc)                # 集合侵蚀，剥离不可确认的边界
        E_loc = E_loc & self.cert.valid_domain(s, x)  # 与 v15 证书定义域取交
        return E_loc, self.min_margin(E_loc, s, x)

    def min_margin(self, E, s, x):
        # 只返回可复算的最小余量；任何一项为负则该点不进入 E
        return min(self.chassis.margin_c(E, s, x) for c in
                   ("reach", "collision", "stability", "fov", "torque"))


# IP-403 Base-Intent Demonstration Estimator：演示中的底盘意图
class BaseIntentDemoEstimator:
    def __init__(self, demos, kernel, W_max=10.0):
        self.demos = demos
        self.kernel = kernel
        self.W_max = W_max

    def intent(self, x):
        # π_d(b|x)：只用成功演示估计；失败演示用于负证据，不进入正支撑
        return self.kernel.conditional(samples=[(d.x, d.b) for d in self.demos
                                                if d.y == 1], query=x)

    def density_ratio(self, x, b, pi_task):
        p_d = max(self.intent(x).density(b), 1e-9)
        return min(pi_task.density(b, x) / p_d, self.W_max)


# IP-404 Demonstration Support Certificate：演示支撑与空洞
class DemoSupportCertificate:
    def __init__(self, demos, delta_x, delta_b, alpha_d=0.05, W_max=10.0):
        self.anchors = [(d.x, d.b) for d in demos if d.y == 1]
        self.delta_x, self.delta_b = delta_x, delta_b
        self.alpha_d, self.W_max = alpha_d, W_max

    def support(self, x):
        # A_δ(x)：成功演示锚点的 δ-邻域并集
        return union(ball_xb(x_i, b_i, self.delta_x, self.delta_b)
                     for (x_i, b_i) in self.anchors)

    def coverage_lower(self, x):
        # 未加权共形：P_{π_d}(x∈A_δ) ≥ 1−α；再用 TV 界迁移到 π_task
        tv_hat = self._tv_estimate(x)              # 由密度比估计 ½E|w−1|
        return max(0.0, 1.0 - self.alpha_d - tv_hat)

    def holes(self, E_loc, x):
        # 支撑空洞：几何可执行但与所有成功锚点都相隔 δ 以上
        return E_loc & complement(self.support(x))

    def _tv_estimate(self, x):
        # 部署时可用在线观测估计；不可估时返回 TV=1，退化为只信精确锚点
        return self._tv_hat.get(x, 1.0)


# IP-405 Chassis Anchor Conformance Guard：现在真的还站在认证锚点上吗
class ChassisAnchorConformanceGuard:
    def __init__(self, loc_model, slip_model, compliance_model):
        self.loc_model = loc_model
        self.slip_model = slip_model
        self.compliance_model = compliance_model

    def check(self, b_hat, b_ref, E_loc, A_delta, ground, load, mode):
        r = (self.loc_model.radius(ground, load)
             + self.slip_model.bound(ground, load)
             + self.compliance_model.bound(load))
        b_safe = subset(B(b_hat, r), E_loc & A_delta)
        if not b_safe:
            return "collapse", r            # 认证锚点已失配：降档 + 重定位
        if mode == "TRANSIT" and not self._transit_certified(b_hat):
            return "freeze", r              # 移动中不得执行精细操作
        if norm(b_hat - b_ref) > r:
            return "degrade", r             # 偏离基准锚点：收缩包络
        return "ok", r


# IP-406 Mobility–Demonstration Degradation Ladder：单调嵌套档位
class MobilityDemoDegradationLadder:
    def __init__(self, envelope, support, tiers=None):
        self.envelope = envelope
        self.support = support
        self.tiers = tiers or self._build_tiers()

    def _build_tiers(self):
        # 档位只沿“证据密度 / 定位置信 / 移动预算”排序，包络与锚点单调嵌套
        return [
            (0, "stop_or_ask_or_nearest_anchor", dict(radius=0.0, skill="fallback")),
            (1, "exact_demo_anchor",            dict(radius=0.0, skill="most_conservative")),
            (2, "shrunk_demo_anchor",           dict(radius=0.5 * self.support.delta_b,
                                                     skill="v15_authorized")),
            (3, "multiple_demo_anchors",        dict(radius=self.support.delta_b,
                                                     skill="v15_authorized")),
            (4, "full_demo_support_intersection", dict(radius=None,
                                                       skill="v15_authorized")),
        ]

    def select(self, x, r_loc, rho_d, B_move, B_time, drift):
        if drift or rho_d < self.support.alpha_d:
            return 0
        budget_level = self._budget_level(B_move, B_time)
        evidence_level = self._evidence_level(rho_d)
        return min(budget_level, evidence_level, len(self.tiers) - 1)


# IP-407 Base–Skill Joint Router：在锚点、技能与移动成本之间联合选档
class BaseSkillJointRouter:
    def __init__(self, dabe, dsc, mddl, v15, weights):
        self.dabe, self.dsc, self.mddl = dabe, dsc, mddl
        self.v15 = v15
        self.lt, self.ld, self.le = weights

    def route(self, x, b_hat, r_loc, B_move, B_time, ground, load):
        E_loc, _ = self.dabe.envelope_for_all(x, r_loc)
        rho_d = self.dsc.coverage_lower(x)
        ell = self.mddl.select(x, r_loc, rho_d, B_move, B_time, drift=None)
        candidates = []
        for b in self.dabe.anchor_candidates(E_loc, ell, x):
            if not self.dsc.is_supported(b, x):
                continue
            if not self.chassis_reach(b_hat, b, B_move, B_time):
                continue
            for s in self.v15.authorized_skills(x):
                delta = self.v15.expected_progress(s, x, b)
                cost = (self.lt * self.move_time(b_hat, b)
                        + self.ld * (1.0 - rho_d)
                        + self.le * self.move_energy(b_hat, b))
                candidates.append((delta - cost, b, s))
        if not candidates:
            return self._degrade_or_ask(x, E_loc, ell, b_hat, B_move)
        score, b_star, s_star = max(candidates, key=lambda t: t[0])
        return b_star, s_star, ell, score


# IP-408 Active Demo-Anchor Repair：支撑空洞的三种处理
class ActiveDemoAnchorRepair:
    def __init__(self, dsc, move_model, demo_budget=1):
        self.dsc, self.move_model = dsc, move_model
        self.demo_budget = demo_budget

    def propose(self, x, holes, b_hat, B_move):
        if not holes:
            return ("none", None)
        anchors = self.dsc.success_anchors_near(x)
        reachable = [(self.move_model.cost(b_hat, b_a), b_a)
                     for (_, b_a) in anchors
                     if self.move_model.cost(b_hat, b_a) <= B_move]
        if reachable:
            cost, b_a = min(reachable)
            return ("move_to_demo_anchor", b_a)
        if self.demo_budget > 0:
            return ("request_demo_at_hole", self._hole_representative(holes))
        return ("hold_tier0", None)


# IP-409 Demo-Chassis Transfer Audit：换底盘后的证书迁移审计
class DemoChassisTransferAudit:
    INVARIANT = {"task_geometry", "object_model", "skill_order"}   # 可迁移项
    PLATFORM = {"r_loc", "slip", "compliance", "fov", "reach", "torque"}

    def audit(self, old_platform, new_platform):
        changed = {k for k in self.PLATFORM
                   if old_platform.get(k) != new_platform.get(k)}
        return {
            "transferable": sorted(self.INVARIANT),
            "must_recalibrate": sorted(changed),
            "stale_envelope": bool(changed),
        }


# 主闭环集成：MetricVoiceGauge-NCD-HUTDH-D-v16（演示锚定移动底盘版）
def metricvoicegauge_round_16_demo_chassis(M, s, obs, demos, chassis, ctx):
    # ---- v15 主路径原样保留（SCD/DSD/DCA/EDC + 继承路径）----
    results = middleware.run_cycle(runners={...}, ctx=ctx)
    nge.update_belief(obs)
    hcc.update_identification(obs.motor_enc, obs.joint_enc, obs.current)

    # ---- 1. 底盘意图与演示支撑 ----
    bide = BaseIntentDemoEstimator(demos, kernel=ctx.kernel, W_max=ctx.W_max)
    dsc = DemoSupportCertificate(demos, ctx.delta_x, ctx.delta_b,
                                 alpha_d=ctx.alpha_d, W_max=ctx.W_max)

    # ---- 2. 底座位姿包络 ----
    r_loc = ctx.loc_model.radius(obs.ground, obs.load, obs.elapsed)
    dabe = DemoAnchoredBaseEnvelope(ctx.v15_cert, chassis, ctx.loc_model,
                                    ctx.delta_x, ctx.delta_b)
    E_loc, margins = dabe.envelope(s, obs.state, r_loc)

    # ---- 3. 支撑空洞与阶梯 ----
    holes = dsc.holes(E_loc, obs.state)
    rho_d = dsc.coverage_lower(obs.state)
    mddl = MobilityDemoDegradationLadder(dabe, dsc)
    ell = mddl.select(obs.state, r_loc, rho_d,
                      ctx.B_move, ctx.B_time_left, ctx.drift.fired())

    # ---- 4. 联合路由 / 主动修复 ----
    if holes and ell <= 1:
        action, b_cmd = ActiveDemoAnchorRepair(dsc, ctx.move_model,
                                               ctx.B_demo).propose(
            obs.state, holes, obs.base_pose, ctx.B_move)
        if action == "hold_tier0":
            execute_safe_ask()
            return M.inherited_v15_path(ctx)   # 严格回退 v15 语义路径
        if action == "move_to_demo_anchor":
            chassis.move_to(b_cmd, budget=ctx.B_move)
            return M.inherited_v15_path(ctx)   # 本帧先完成锚点移动，不执行操作

    bsjr = BaseSkillJointRouter(dabe, dsc, mddl, ctx.v15, ctx.weights)
    b_star, s_star, ell, score = bsjr.route(
        obs.state, obs.base_pose, r_loc, ctx.B_move, ctx.B_time_left,
        obs.ground, obs.load)

    # ---- 5. 底盘锚定一致性守卫 ----
    verdict, r_eff = ChassisAnchorConformanceGuard(
        ctx.loc_model, ctx.slip_model, ctx.compliance_model).check(
            obs.base_pose, ctx.b_ref, E_loc, dsc.support(obs.state),
            obs.ground, obs.load, ctx.mode)
    if verdict == "collapse":
        execute_safe_ask()
        return M.inherited_v15_path(ctx)
    if verdict == "freeze":
        chassis.hold(); execute_safe_ask()
        return M.inherited_v15_path(ctx)

    # ---- 6. 只执行取交后的动作；任何越界即退回 v15 ----
    if (b_star in E_loc) and dsc.is_supported(b_star, obs.state) \
            and s_star in ctx.v15.authorized_skills(obs.state):
        execute(ctx.v15.refine(s_star, b_star), obs)
    else:
        execute_safe_ask()

    # ---- 7. 低频：重标定 / 迁移审计 / 补证缓存 ----
    if ctx.cycle_idx % ctx.T_audit == 0:
        audit = DemoChassisTransferAudit().audit(ctx.old_platform, chassis.fingerprint())
        if audit["stale_envelope"]:
            ctx.v15_cert = ctx.v15_cert.recalibrate(chassis, ctx.audit_data)
        dsc.refresh(ctx.new_demo_buffer)

    C, spatial_cert, claims, metrics, rewards = M.inherited_v15_path(ctx)
    return C, spatial_cert, claims, metrics, rewards

## 2. 推导（引理 131–140）

**引理 131（底盘包络的单调收缩 ⇒ 执行集只减不增）**
设 `E_loc,s(x)=Ê_s(x)⊖B(0,r_loc)`，`A_δ(x)` 为成功演示锚点邻域，`E_demo,s=E_loc,s∩A_δ`。若 `r_loc` 单调不减、`δ_x,δ_b` 单调不减、`Ê_s` 单调不扩，则 `E_demo,s(x)` 单调不增；进一步，`Exec_v16 ⊆ Exec_v15`。证明：集合侵蚀与交运算对集合单调；`E_demo,s ⊆ Ê_s ⊆` v15 证书定义域，故任一 v16 动作—底盘对都对应 v15 已授权动作。∎ 推论：**移动性带来的不是新权限，而是“在何处执行已授权技能”的收紧；任何参数调整只能让 `E_demo` 变小。**

**引理 132（定位侵蚀的 soundness）**
若真实底盘位姿 `b ∈ B(b̂,r_loc)`，且选中的执行位姿 `b_exec` 满足 `B(b_exec,r_loc) ⊆ Ê_s(x)`，则真实 `b` 的证书余量按 `Ê_s` 计算仍成立；若 `b_exec` 只满足 `b_exec∈Ê_s` 而未做侵蚀，则存在 `b∈B(b̂,r_loc)` 使真实约束越界。证明：由球包含关系，任意 `b∈B(b_exec,r_loc)` 都落在 `Ê_s` 内；未侵蚀时取球边界点即反例。∎ 推论：**“估计位姿在包络内”不等于“真实位姿在包络内”；必须侵蚀，且 `r_loc` 必须包含轮滑与柔顺项，而不是只含里程计方差。**

**引理 133（加权共形覆盖与演示/部署分布差）**
设成功演示锚点在 `π_d` 下可交换，未加权共形给出 `P_{π_d}(x∈A_δ) ≥ 1−α_d`。则对部署分布 `π_task`，
```
P_{π_task}(x∈A_δ) ≥ 1 − α_d − TV(π_task, π_d) ≥ 1 − α_d − ½ E_{π_d}|w−1| ,
```
其中 `w=dπ_task/dπ_d` 且截断于 `W_max`。证明：对任意可测集 `A`，`|P_task(A)−P_d(A)|≤TV(P_task,P_d)`；再用 `TV=½∫|dπ_task−dπ_d|`。∎ 推论：**演示覆盖不是“训练集覆盖率”，而是“部署分布与演示分布的全变差惩罚后的下界”**；人类只在顺手位置演示时，`TV` 会直接吃掉覆盖保证。

**引理 134（演示锚定不扩张 v15 授权）**
对任意 `(b,a)∈Exec_v16`，有 `a∈Acc_v15(x)` 且 `b∈E_loc,s(x)∩A_δ(x)`。因此 `Exec_v16 ⊆ Exec_v15 × SE(2)`；投影到动作空间得 `Exec_v16|_A ⊆ Exec_v15`。证明：由主闭环第 6 步的取交条件与 `E_loc⊆Ê_s⊆` v15 定义域直接得到。∎ 推论：**底盘维度只增加一个“在哪儿执行”的约束，不改变“能执行什么”的语义层授权。**

**引理 135（支撑空洞的覆盖—移动—假拒绝三难）**
设几何可行域 `E` 与演示支撑 `A` 的差集 `H=E\A` 测度为 `h>0`，移动预算 `B_move` 有限，补证预算 `B_demo` 有限。任何策略若要求“零假拒绝（对 `E` 内所有点放行）”“零外推（只使用 `A`）”“零移动/补证成本”三者同时成立，则必有 `h=0`。更一般地，
```
P(无认证动作) ≥ P(H) − P(可达锚点) − P(补证成功) ,
```
证明：`E` 内未被 `A` 覆盖的点只能经移动或补证转化为有证据点；两者预算有限时，剩余空洞只能触发假拒绝。∎ 推论：**“底盘可达 + 演示全覆盖 + 零额外数据”不可能同时成立**；必须显式支付移动、补证或假拒绝中的至少一项。

**引理 136（阶梯单调退化与无越级）**
若 MDDL 的档位满足 `E_0⊆E_1⊆…⊆E_m`、`A_0⊆A_1⊆…⊆A_m`，且 `select` 只返回 `min(budget_level, evidence_level, m)`，则当预算或证据单调恶化时，`ℓ` 单调不增；且任意单帧至多沿相邻档位下降一级，除非 CACG 触发 `collapse`。证明：`min` 对两个单调不增的自变量单调不增；`select` 的档位由整数下界给出，正常路径无跨档跳变；`collapse` 是显式安全事件，单独记账。∎ 推论：**退化可以是“跳到底”，但正常退化必须逐级、可审计；禁止在门槛附近来回抖动。**

**引理 137（滑移/蠕动/柔顺下的失效界）**
设真实底盘相对基准锚点的滑移/蠕动量为 `d_slip`，而 CACG 使用的膨胀半径为 `r`。若 `d_slip>r`，则存在非空事件使真实位姿离开 `E_loc∩A_δ`，而守卫仍返回 `ok`；其概率满足
```
P(假接受) ≤ P(d_slip > r) + P(r_loc 被低估) + P(E_demo 边界被穿透) .
```
证明：假接受要求守卫认为安全而真实位姿不安全；由 `d_slip>r` 或半径估计偏低或包络外逼近失效三者之一覆盖。∎ 推论：**“底盘锁死”不是物理保证，只是 `d_slip≤r` 的一个待验证假设；必须在线监测，不能写进静态证书。**

**引理 138（主动补证的样本复杂度）**
要在支撑空洞的一小块测度 `η` 上以置信度 `1−β` 获得覆盖证书，至少需要 `n = Ω((1/η)·log(1/β))` 条该锚点附近的成功演示；若允许在空洞内主动选择锚点并只补局部，则样本量可按空洞的 `δ`-覆盖数 `N_δ(H)` 分摊。证明：覆盖一个测度 `η` 的区域需要至少 `1/η` 量级的独立样本；置信度由 Bernoulli 尾界给出；主动选择把全局 `1/η` 降为按局部覆盖数分摊。∎ 推论：**补证的成本由“空洞的几何大小”而非“任务的总复杂度”决定**；这解释了为什么在底盘维度上主动选锚点比盲目增加演示更划算。

**引理 139（平台迁移不传递）**
设旧底盘与新底盘的 `r_loc`、轮滑、柔顺、视场、可达集或力矩模型任一不同。则旧包络 `Ê_s^{old}` 不能直接作为新底盘的 sound 外逼近；只有与平台无关的 `{任务几何、物体模型、技能顺序}` 可迁移。证明：取任一变化项，构造一个在旧平台上余量为正、在新平台上为负的位姿—动作对，即得反例。∎ 推论：**换轮组、换地面、换载荷谱都必须重新标定 `r_loc` 与包络；“同一套上层证书”只在平台无关项上成立。**

**引理 140（全失效严格退回 v15）**
若 DABE、BIDE、DSC、CACG、MDDL、BSJR、ADAR、DCTA 全部失效，则主闭环只执行 v15 的 `metricvoicegauge_round_15_skill_diffusion`，且 `Exec_v16=Exec_v15`（固定基座情形）。证明：逐一将各端口注入中立元：`r_loc=0`、`A_δ=SE(2)`、`π_d` 均匀、`ℓ=固定档`、底盘固定于 `b_0`；所有取交退化为 v15 定义域，所有路由退化为 v15 静态调度。∎ 推论：**v16 的每一个新增端口都是可拔插的收缩算子，最坏情形严格等价 v15，不会因底盘模块故障引入新授权。**

## 6. 已知风险与失效模式

1. **演示选择偏差被误当成能力**：人类只在顺手位置演示，`π_d` 与部署 `π_task` 差异大，`U_demo` 可能高估覆盖。缓解：密度比截断、TV 惩罚、分层主动补证、报告未覆盖测度。
2. **支撑空洞边界模糊**：`δ_x,δ_b` 取大时空洞被“填平”，取小时锚点稀疏导致频繁假拒绝。缓解：多尺度 `δ`、边界主动采样、把 `δ` 与局部 Lipschitz 常数绑定。
3. **定位膨胀不足**：低纹理、强反光、轮子打滑、地面松软使 `r_loc` 低估，侵蚀后的包络仍不够保守。缓解：在线滑移检测、IMU/轮速/视觉融合、`r_loc` 的 EVT 尾部分位、超界即 `collapse`。
4. **底盘“锁死”假设失效**：操作反力使底盘蠕动、悬架下沉、支撑多边形变化。缓解：锚定模式在线监测、力/位混合限幅、把 `d_slip` 计入 `r_loc`、必要时降速或加支撑。
5. **包络外逼近过松**：五类约束的采样/区间证书在边界处可能漏掉窄缝或非凸区域。缓解：对抗位姿采样、边界加密、用区间/可达集证书替代经验栅格。
6. **DSC 与 v15 DCA/EDC 重复计错**：两者都做数据校准，可能一方“补偿”另一方的错误。缓解：取最保守者而非相加、独立校准集、联合审计、任一失效即第 0 档。
7. **移动成本与任务进度错配**：BSJR 为追求覆盖频繁换锚点，导致移动耗时/耗能超过收益。缓解：显式 `λ_t/λ_e`、滞回、移动预算硬上限、把移动计入 v15 的时间/能耗预算。
8. **补证请求造成交互负担**：ADAR 在空洞处频繁请求演示，用户不愿配合。缓解：补证预算、批量请求、优先退到最近锚点、把“拒绝补证”纳入第 0 档。
9. **平台迁移沿用旧证书**：换轮组/地面/载荷后仍用旧 `r_loc` 与包络。缓解：平台指纹、DCTA 强制审计、变更即 `ℓ=0`、重标定白名单。
10. **底盘模式与操作模式混淆**：TRANSIT 中执行精细操作，或 ANCHORED 中未确认锁死。缓解：模式状态机、CACG 的 `freeze`、移动中只允许认证的粗操作。
11. **演示标签噪声**：失败演示被误标为成功、或成功演示含人工干预。缓解：多源一致性、失败负证据、置信加权、把标签噪声计入 `α_d`。
12. **空洞内“零样本”但几何极顺**：几何指标强烈诱导在空洞内执行，而证书必须拒绝。缓解：硬性支撑检查、可视化空洞、禁止外推的部署前校验、把空洞计入审计指标。

## 7. 本轮最大风险

**一句话**：演示支撑与底盘包络都来自“人类在顺手位置采集的数据”和“几何/统计模型给出的保守外逼近”，而部署时最危险的情形恰恰是底盘停在**几何包络内部、统计覆盖下界之内、定位球也自洽、但演示从未在附近成功过**的支撑空洞边缘——此时系统会同时通过几何检查、共形覆盖检查与锚定一致性检查，执行一个“处处有证书、却从未被任何演示支持过”的底盘—操作联合决定，即**几何可行的、统计覆盖的、却证据上空的错误安全决定**。
