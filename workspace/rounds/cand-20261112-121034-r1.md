# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC/IP-153~160；灵感循环第 7 轮；本轮灵感：「事件相机」×「差异化定位」）

> 第 60 轮 SGEC 用 SSM×CIEC×EPIR×SERC 把「场景」变成阻抗先验、把「意图」变成实时约束、把「证据」变成防丢失的隔离区。但**三个更深的局限**仍在：
> 1. **场景转变的「触后性」**：SSM 的观测是力/位置遥测，本质是**接触后**的低频信号。湿滑→粗糙、平坦→台阶这类转变，要等到第一次接触力签名变化才被识别——"先失败、后建模"。事件相机（DVS）以微秒级异步事件输出**亮度变化**，能在接触前看到边缘、纹理、逼近速度的先兆，但 SSM 没有事件输入。
> 2. **空间归因的「共模污染」**：SERC/EPIR 把 EV-exec 归因到绝对位姿与绝对坐标系，而标定偏差、时钟漂移、轮式里程计尺度误差等**共模误差**会整体平移所有证据，使"哪里出了错"与"哪里没错"无法区分。差异化定位（RTK/相对/差分测量）用两观测之差抵消共模项，但证据层没有差分算子，J_exec 只能证明"绝对合规"，不能证明"相对一致"。
> 3. **时空证据的「异步错配」**：EPIR 的 timestamp+seq_id 假定固定采样率；事件流是**稀疏、异步、微秒时间戳**的，事件、遥测、ROS 消息三者时间基不一致。若按最近邻粗暴对齐，会引入毫秒级错配，把"事件先于接触"的因果顺序在证据里抹平。

## 0. 直觉与动机

**灵感 1（事件相机 → 事件场景签名 ESS）**
直觉：事件相机不给"图像"，只给"哪里在何时变了"。它天然是**变化检测器**：桌沿掠过、纹理由细变粗、接触瞬间的微振动、阴影/反光的极性翻转，都会变成一串 (x,y,t,p)。关键洞见：场景不是"接触后才由力签名定义"，而是**接触前由事件签名先兆定义**。把场景 z 映射为事件签名 σ_e(z)=(ρ_e, β_e, ∇T_e, H_e)：事件率、极性平衡、时间面梯度、事件熵。场景转变检测于是变成**事件签名的 KL 散度越阈**，检测时延从 SSM 的一个控制周期降到事件累积的微秒~毫秒；因为事件相机先"看到"逼近的桌沿/踏步，它能在**接触前**触发 π_scene 的提前切换。

**灵感 2（差异化定位 → 差分证据 DEP）**
直觉：绝对定位像"用一把会热胀冷缩的尺子量绝对长度"，共模误差让所有读数一起漂；差分定位像"用同一把尺子量两点之差"，尺子的热胀冷缩在相减时抵消。机器人执行证据也一样：相邻两次接触、同一事件锚点的两次观测、同一批标定参数下的两次 EV-exec，它们的**差**比它们的**绝对值**更可信。关键洞见：把证据从 EV-exec 升级为 **EV-exec^Δ = EV-exec(t₂) ⊖ EV-exec(t₁)**，并定义**共模抵消比 CCR**：误差协方差中被相减抵消的比例。CCR 越高，差分证据越"抗漂移"。J_exec 相应升级为**差分证书** J_exec^Δ——不证明"绝对合规"，而证明"相对一致且共模误差已抵消"。

**灵感 3（事件 × 差分 → 事件锚定差分证据 EDE）**
直觉：事件相机提供"何时变"（时间差分），差异化定位提供"相对谁变"（空间差分）。把每个事件簇当作一个**时空锚点**，用差分位姿把事件锚定到参考系：EDE=(事件锚点, Δξ, Σ_Δ, τ_e)。于是"某处发生了某变化"不再依赖绝对位姿，而是"相对于上一个事件锚点，变化了 Δξ，且共模误差被抵消"。这直接对准"空间归因共模污染"与"时空异步错配"：事件锚点自带微秒时间戳，差分位姿只依赖锚点间的相对关系。

**灵感 4（三灵感合流 → 时空微分闭环 STDL）**
直觉：串联成闭环：事件流→ESS→事件先兆 EASP（接触前预测场景）→SSM 先验→差分定位 DPE→差分证据 EDE→EEIS 差分编译→执行→EV-exec^Δ→更新场景/锚点信念。与第 60 轮 SERC 的关系是正交的：SERC 管"场景语义如何落地"，STDL 管"场景变化在**何时**、相对**何处**被最先看见并被可信归因"。

**灵感 5（预算 → PCE+++++ 事件-差分预算）**
直觉：事件处理与差分校正都昂贵且可耗尽。新增 B_evt（事件累积窗口、时间面更新率、事件算力）、B_dp（差分锚点可用性、基线长度、校正带宽）。若 B_evt 耗尽⇒退回帧式 SSM 并加宽 κ_scene 阈值；若 B_dp 耗尽或锚点共线退化⇒退回绝对定位、膨胀 Σ、CCR 置 0、差分证据标 unverified；若 B_exec 耗尽⇒沿用第 60 轮降级。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（事件流与事件场景签名 ESS）** 事件流 E={e_k=(x_k,y_k,t_k,p_k)}，t_k 严格递增，p_k∈{+1,-1}。像素时间面 T_e(x,y)=exp(-(t-t_last(x,y))/τ_e)。场景事件签名 σ_e(z)=(ρ_e,β_e,∇T_e,H_e)：
- 事件率 ρ_e(z)=|{e_k: t_k∈[t-W,t]}|/W；
- 极性平衡 β_e(z)=(N₊-N₋)/(N₊+N₋)；
- 时间面梯度 ∇T_e=E[‖(∂_x T_e, ∂_y T_e)‖]；
- 事件熵 H_e=-Σ_b p_b log p_b（对局部时空块的事件分布）。
场景转变检测 κ_e(z_new,z_old)=D_KL(σ_e(z_new)‖σ_e(z_old)) > τ_e，检测时延上界 L_e ≤ τ_e·ln(1/δ_e)+O(1/ρ_e)。

**定义 162（差异化定位 DP）** 两观测 y_a=h(x_a)+b+n_a，y_b=h(x_b)+b+n_b，b 为共模偏差（共享、有界）。差分测量 Δy=y_a-y_b=h(x_a)-h(x_b)+(n_a-n_b)，**b 被抵消**。差分协方差 Σ_Δ=Σ_a+Σ_b-2Σ_ab。共模抵消比
CCR = 1 - σ_Δ²/(σ_a²+σ_b²) = 2Σ_ab/(σ_a²+σ_b²) ∈ [0,1]。
差分位姿 Δξ=J^†Δy，其误差界 ‖Δξ-Δξ*‖_{Σ_Δ} ≤ ε_Δ **与 b 无关**；当两观测完全共模时 CCR→1、σ_Δ²→0。

**定义 163（差分证据 DEP / EV-exec^Δ）** 证据差分算子 ⊖：EV-exec^Δ(t₁,t₂)=EV-exec(t₂)⊖EV-exec(t₁)，位姿分量在 SE(3) 上用右雅可比做差，力/阻抗分量逐维做差。差分证据四元组 EDE=(a_e, Δξ, Σ_Δ, τ_e)，a_e=(x̄_e,ȳ_e,t̄_e) 为事件锚点（事件簇的时空质心）。差分证书 J_exec^Δ=(EDE, CCR, event_integrity, b_free_bound)。

**定义 164（事件锚定场景先兆 EASP）** 接触前场景预测：给定事件签名、参考签名与差分位姿，先兆置信
c_pre = sigmoid( α·tanh(D_KL(σ_e‖σ_e(z))) + β·ρ_e/ρ̄ + γ·‖Δξ‖/Δξ̄ - δ )。
当 c_pre ≥ τ_pre 时，在**接触前**把 SSM 先验切到 z_new 邻域，并冻结 K_safe 的放松方向（只许收紧）。先兆提前量 T_lead=t_contact-t_trigger>0 是该机制的核心指标。

**定义 165（时空微分闭环 STDL）** 算子 STDL(M, δ_f_req)：
```
① ESS:    σ_e ← M.event.signature(E_window)；z* ← argmax π_scene(·|σ_e)
② EASP:   (c_pre, T_lead) ← precursor(σ_e, σ_e_ref, Δξ_prev)
③ SSM:    π_scene(K|z*) ← ssm.update_with_event(σ_e, c_pre)   # 先兆仅收紧
④ DPE:   (Δξ, Σ_Δ, CCR) ← M.dp.estimate(anchor_a, anchor_b)
⑤ EDE:    EV-exec^Δ ← difference(prev_EV, cur_EV)；EDE ← (a_e, Δξ, Σ_Δ, τ_e)
⑥ Compile: K_safe^Δ ← EEIS.compile_differential(π_scene, EV-exec^Δ, δ_f_req)
⑦ Gate:   if CCR < τ_ccr ∨ cond(J) > τ_cond: inflate(Σ_Δ); K_safe^Δ ∩= K_safe^conservative
⑧ Exec:   closed_loop_exec_probe(...) → EV-exec, Cert
⑨ EPIR:   append(EV-exec^Δ)；XMC+ 融合
⑩ Return: (z*, K_safe^Δ, EDE, J_exec^Δ)
```

**定义 166（事件-差分预算 PCE+++++ 与 B_evt/B_dp）** B_cog⁺=(B_evt,B_dp,B_scene,B_intent,B_ros,B_exec)：
- B_evt=(Event_window, TS_update_rate, Event_ops)；
- B_dp=(Anchor_availability, Baseline, Correction_bw)；
- 其余四项沿用第 60 轮。
策略：B_evt 耗尽⇒帧式 SSM+阈值加宽；B_dp 耗尽/锚点共线⇒绝对定位+Σ 膨胀+CCR=0+差分证据 unverified；B_scene/B_intent/B_ros/B_exec 沿用原回退。

**定义 167（事件-差分证书 EDC）** J_exec^Δ 字段：
- event_anchor_hash：事件锚点 (x̄,ȳ,t̄) 与极性直方图的哈希；
- differential_state：Δξ、Σ_Δ、baseline；
- CCR 与 b_free_bound：显式证明误差界 **不含共模项**；
- event_integrity：事件丢包率、时间戳单调性、ROS 序号连续性（复用 EPIR）；
- verdict∈{VALID, DEGRADED, UNVERIFIED}。
签发规则：VALID 当且仅当 CCR≥τ_ccr ∧ event_integrity≥τ_evt ∧ b_free_bound≤ε_Δ ∧ cond(J)≤τ_cond。

**定义 168（共模抵消门 CMC-Gate 与单向性）** 门控算子 G(EV-exec^Δ, J_exec^Δ)：
```
if J_exec^Δ.verdict == VALID:      accept(EV-exec^Δ); π_scene.update(Δ)
elif J_exec^Δ.verdict == DEGRADED: accept with inflated Σ; freeze π_scene relaxation
else:                              reject; fallback to absolute EV-exec + conservative prior
```
**单向性**：门控只允许差分证据在"更紧"方向更新 K_safe；任何 CCR 下降都只能扩大不确定集，不得减小。

## 2. 关键算法伪代码

### IP-161 ESS（事件场景签名）

```python
class EventSceneSignature:
    def __init__(self, height, width, tau_e=0.05, window=0.02):
        self.tau_e, self.W = tau_e, window
        self.surface = np.zeros((height, width))
        self.last_t = np.zeros((height, width))
        self.events = deque(maxlen=20000)

    def ingest(self, x, y, t, p):
        self.surface[y, x] = np.exp(-(t - self.last_t[y, x]) / self.tau_e)
        self.last_t[y, x] = t
        self.events.append((x, y, t, p))

    def signature(self, now):
        win = [(x, y, t, p) for (x, y, t, p) in self.events if now - t <= self.W]
        n = max(1, len(win))
        rho = len(win) / self.W
        n_pos = sum(1 for e in win if e[3] > 0)
        beta = (n_pos - (len(win) - n_pos)) / n
        gy, gx = np.gradient(self.surface)
        grad = float(np.mean(np.hypot(gx, gy)))
        pol = np.bincount([0 if e[3] > 0 else 1 for e in win], minlength=2) / n
        entropy = float(-(pol * np.log(pol + 1e-9)).sum())
        return {"rho": rho, "beta": beta, "grad": grad, "entropy": entropy}

    def transition_kl(self, sig, ref):
        return sum(kl_gauss(sig[k], ref[k]) for k in ("rho", "beta", "grad"))
```

### IP-162 DPE（差异化定位引擎）

```python
class DifferentialPositioningEngine:
    def __init__(self, tau_ccr=0.8, tau_cond=1e3):
        self.anchors = deque(maxlen=32)
        self.tau_ccr, self.tau_cond = tau_ccr, tau_cond

    def estimate(self, a, b):
        dy = a.meas - b.meas
        S_d = a.cov + b.cov - 2 * a.cross_cov(b)      # 共模项在相减中抵消
        J = self._jacobian(a.x, b.x)
        cond = np.linalg.cond(J)
        dxi = np.linalg.pinv(J) @ dy
        ccr = 1.0 - np.trace(S_d) / max(1e-9, np.trace(a.cov) + np.trace(b.cov))
        return dxi, S_d, float(np.clip(ccr, 0.0, 1.0)), float(cond)
```

def build_event_differential_evidence(prev_ev, cur_ev, anchor_e, dpe):
    dxi, S_d, ccr, cond = dpe.estimate(prev_ev.anchor, cur_ev.anchor)
    return {
        "anchor": anchor_e,
        "dxi": dxi,
        "dK": cur_ev.K_safe - prev_ev.K_safe,

### IP-164 EASP（事件锚定场景先兆）

```python
def event_anchored_precursor(sig, sig_ref, dxi_prev,
                             alpha=0.6, beta=0.2, gamma=0.2,
                             delta=0.5, tau_pre=0.7):
    dkl = sig.transition_kl(sig_ref)
    s = (alpha * np.tanh(dkl)
         + beta * sig["rho"] / RHO_BAR
         + gamma * np.linalg.norm(dxi_prev) / DXI_BAR
         - delta)
    c_pre = 1.0 / (1.0 + np.exp(-s))
    return c_pre, c_pre >= tau_pre
```

### IP-165 STDL（时空微分闭环）

```python
def spatiotemporal_differential_loop(M, delta_f_req):
    sig = M.event.signature(now=time.time())
    c_pre, trigger = event_anchored_precursor(
        sig, M.scene_model.event_ref, M.dp_last_dxi)

    if trigger:                                   # 接触前先兆：只许收紧
        M.scene_model.apply_precursor(sig, c_pre)
        M.scene_model.freeze_relaxation()

    M.dp_last_dxi, S_d, ccr, cond = M.dp.estimate(M.prev_anchor, M.cur_anchor)
    prev_ev = M.last_exec_evidence

    M, fused, D_plus, ev, cert = closed_loop_exec_probe(
        M, M.current_cp, delta_f_req, M.budget)

    ede = build_event_differential_evidence(prev_ev, ev, M.cur_anchor, M.dp)
    if ccr < M.tau_ccr or cond > M.tau_cond:
        ev.K_safe = ev.K_safe.intersect(M.conservative_core)
        M.dp.inflate(S_d)
    j = issue_edc(ede, sig, ev, ccr, cond)

    M.epir.append(ede)
    M, fused, D_plus = xmodal_fuse_plus(
        M, M.current_cp.region, M.inf_latest, ede)
    return M, fused, D_plus, ede, j
```

### IP-166 PCE+++++（事件-差分预算）

```python
class EventDifferentialBudget:
    def __init__(self, evt_ops=500, dp_anchors=8, baseline_min=0.05):
        self.B_evt = evt_ops
        self.B_dp = dp_anchors
        self.baseline_min = baseline_min
        self.ops_evt = 0
        self.anchors = 0

    def event_mode(self):
        return "frame_ssm" if self.ops_evt >= self.B_evt else "event"

    def dp_mode(self, baseline):
        if self.anchors <= 0 or baseline < self.baseline_min:
            return "absolute_inflated"
        return "differential"
```

### IP-167/168 EDC 签发与 CMC-Gate

```python
def issue_edc(ede, sig, ev, ccr, cond):
    integrity = compute_event_integrity(sig, ev)      # 丢包/单调性/序号
    b_free = np.trace(ede["sigma"])                    # 与共模 b 无关
    if ccr >= TAU_CCR and integrity >= TAU_EVT \
            and b_free <= EPS_DELTA and cond <= TAU_COND:
        verdict = "VALID"
    elif ccr >= TAU_CCR / 2 and integrity >= TAU_EVT / 2:
        verdict = "DEGRADED"
    else:
        verdict = "UNVERIFIED"
    return {"ede": ede, "ccr": ccr, "cond": cond,
            "event_integrity": integrity, "b_free_bound": b_free,
            "verdict": verdict}

def cmc_gate(ede, j, scene_model, conservative_core):
    if j["verdict"] == "VALID":
        scene_model.update(ede, tighten_only=True)
        return ede
    if j["verdict"] == "DEGRADED":
        scene_model.freeze_relaxation()                # 只膨胀，不放松
        return ede
    return absolute_fallback(conservative_core)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| ESS | O(N_e) / 窗口 | O(H·W + N_e) | 转变检测时延 ≤ 5ms，接触前提前量 ≥ 20ms |
| DPE | O(d³)（d 为位姿维数，小） | O(32) 锚点 | CCR ≥ 0.8，差分漂移降低 ≥ 60% |
| EDE | O(1) | O(1) | 误差界与共模项无关 |
| EASP | O(1) | O(1) | 先兆准确率 ≥ 85% |
| STDL | O(闭环) | 复用 | 场景适应成功率 ≥ 90%，适应时间 −50% |

**正确性定理（STDL）**：
假设 A66–A70 成立：**(A66)** 事件流时间戳严格单调、事件率 ρ_e 有界且局部平稳；**(A67)** 共模偏差 b 有界且两观测共享（协方差非退化）；**(A68)** 差分雅可比 J 满秩、锚点非共线且基线 ≥ baseline_min；**(A69)** EDC 门控单调，只收紧不放松；**(A70)** 各预算单调消耗。

则：
1. **先兆时延界**：若 D_KL 超阈，事件先兆检测时延 L_e ≤ τ_e·ln(1/δ_e)+O(1/ρ_e)；若 T_lead>0，则场景在接触前被识别。
2. **共模抵消**：在 A67、A68 下 ‖Δξ−Δξ*‖_{Σ_Δ} ≤ ε_Δ，且 ε_Δ 不含 b；CCR→1 时绝对漂移项从差分证据中消失。
3. **证据一致性**：J_exec^Δ=VALID ⇒ EV-exec^Δ 在 ROS 乱序/丢包下仍满足第 60 轮 EPIR 的因果约束（差分证据继承 seq_id/hash 校验）。
4. **安全单向性**：CMC-Gate 只收紧 K_safe；差分退化只膨胀不确定集。
5. **预算安全性**：任一 B_evt/B_dp/B_scene/B_intent/B_ros/B_exec 耗尽，触发对应的确定性回退。

## 5. 本轮最大风险

**一句话**：事件相机在低纹理、强反光、高速旋转下事件签名可能退化，而差分锚点共线或基线过短会让 CCR "虚高"——若不设「事件率下限 + 锚点几何条件数 + CCR 与 b_free_bound 双阈值」三重护栏，就可能出现"差分证书显示高置信、绝对轨迹其实已漂移"的自我欺骗。

# 第 61 轮产物 · 创新点清单 v1：STDL（时空微分闭环：事件场景签名×差分证据×事件锚定先兆，ESS×DPE×EDE×EASP×STDL×PCE+++++×EDC×CMC-Gate）

> 承接第 60 轮 IP-153~160（SGEC：SSM×CIEC×EPIR×SERC×PCE++++×SIC×CESC）。本轮把「认知驱动的场景-执行闭环」再向前推一步：用**事件相机**把场景转变检测从「接触后」提前到「接触前」，用**差异化定位**把执行证据从「绝对合规」升级为「相对一致、共模抵消」，并用**事件锚点**把异步事件、遥测与 ROS 消息统一到同一时空参考系。三者在 STDL 中闭环，实现 **「事件先兆提前收紧阻抗、差分证据抵抗共模漂移、锚点对齐保住因果顺序」**。

> IP 编号：IP-161~IP-168（共 8 个）。与第 60 轮正交：SERC 负责「场景语义如何落地」，STDL 负责「场景变化在何时、相对何处被最先看见并被可信归因」。

## 2. 关键算法伪代码

### IP-161 ESS（事件场景签名）

```python
class EventSceneSignature:
    def __init__(self, height, width, tau_e=0.05, window=0.02):
        self.tau_e, self.W = tau_e, window
        self.surface = np.zeros((height, width))
        self.last_t = np.zeros((height, width))
        self.events = deque(maxlen=20000)

    def ingest(self, x, y, t, p):
        self.surface[y, x] = np.exp(-(t - self.last_t[y, x]) / self.tau_e)
        self.last_t[y, x] = t
        self.events.append((x, y, t, p))

    def signature(self, now):
        win = [(x, y, t, p) for (x, y, t, p) in self.events if now - t <= self.W]
        n = max(1, len(win))
        n_pos = sum(1 for e in win if e[3] > 0)
        gy, gx = np.gradient(self.surface)
        pol = np.bincount([0 if e[3] > 0 else 1 for e in win], minlength=2) / n
        return {
            "rho": len(win) / self.W,
            "beta": (n_pos - (len(win) - n_pos)) / n,
            "grad": float(np.mean(np.hypot(gx, gy))),
            "entropy": float(-(pol * np.log(pol + 1e-9)).sum()),
        }

    def transition_kl(self, sig, ref):
        return sum(kl_gauss(sig[k], ref[k]) for k in ("rho", "beta", "grad"))
```

### IP-162 DPE（差异化定位引擎）

```python
class DifferentialPositioningEngine:
    def __init__(self, tau_ccr=0.8, tau_cond=1e3):
        self.anchors = deque(maxlen=32)
        self.tau_ccr, self.tau_cond = tau_ccr, tau_cond

    def estimate(self, a, b):
        dy = a.meas - b.meas
        S_d = a.cov + b.cov - 2 * a.cross_cov(b)     # 共模项相减抵消
        J = self._jacobian(a.x, b.x)
        cond = np.linalg.cond(J)
        dxi = np.linalg.pinv(J) @ dy
        ccr = 1.0 - np.trace(S_d) / max(1e-9, np.trace(a.cov) + np.trace(b.cov))
        return dxi, S_d, float(np.clip(ccr, 0.0, 1.0)), float(cond)
```

### IP-163/164 EDE 与事件先兆

```python
def build_event_differential_evidence(prev_ev, cur_ev, anchor_e, dpe):
    dxi, S_d, ccr, cond = dpe.estimate(prev_ev.anchor, cur_ev.anchor)
    return {"anchor": anchor_e, "dxi": dxi,
            "dK": cur_ev.K_safe - prev_ev.K_safe,
            "dF": cur_ev.F - prev_ev.F,
            "sigma": S_d, "ccr": ccr, "cond": cond, "tau_e": cur_ev.t}

def event_anchored_precursor(sig, sig_ref, dxi_prev,
                             alpha=0.6, beta=0.2, gamma=0.2,
                             delta=0.5, tau_pre=0.7):
    s = (alpha * np.tanh(sig.transition_kl(sig_ref))
         + beta * sig["rho"] / RHO_BAR
         + gamma * np.linalg.norm(dxi_prev) / DXI_BAR - delta)
    c_pre = 1.0 / (1.0 + np.exp(-s))
    return c_pre, c_pre >= tau_pre
```

### IP-165 STDL（时空微分闭环）

```python
def spatiotemporal_differential_loop(M, delta_f_req):
    sig = M.event.signature(now=time.time())
    c_pre, trigger = event_anchored_precursor(
        sig, M.scene_model.event_ref, M.dp_last_dxi)
    if trigger:                                  # 接触前先兆：只许收紧
        M.scene_model.apply_precursor(sig, c_pre)
        M.scene_model.freeze_relaxation()

    M.dp_last_dxi, S_d, ccr, cond = M.dp.estimate(M.prev_anchor, M.cur_anchor)
    prev_ev = M.last_exec_evidence
    M, fused, D_plus, ev, cert = closed_loop_exec_probe(
        M, M.current_cp, delta_f_req, M.budget)

    ede = build_event_differential_evidence(prev_ev, ev, M.cur_anchor, M.dp)
    if ccr < M.tau_ccr or cond > M.tau_cond:
        ev.K_safe = ev.K_safe.intersect(M.conservative_core)
        M.dp.inflate(S_d)
    j = issue_edc(ede, sig, ev, ccr, cond)
    M.epir.append(ede)
    M, fused, D_plus = xmodal_fuse_plus(
        M, M.current_cp.region, M.inf_latest, ede)
    return M, fused, D_plus, ede, j
```

### IP-166 PCE+++++（事件-差分预算）

```python
class EventDifferentialBudget:
    def __init__(self, evt_ops=500, dp_anchors=8, baseline_min=0.05):
        self.B_evt, self.B_dp = evt_ops, dp_anchors
        self.baseline_min = baseline_min
        self.ops_evt, self.anchors = 0, 0

    def event_mode(self):
        return "frame_ssm" if self.ops_evt >= self.B_evt else "event"

    def dp_mode(self, baseline):
        if self.anchors <= 0 or baseline < self.baseline_min:
            return "absolute_inflated"
        return "differential"
```

### IP-167/168 EDC 证书与 CMC-Gate

```python
def issue_edc(ede, sig, ev, ccr, cond):
    integrity = compute_event_integrity(sig, ev)      # 丢包/单调性/序号
    b_free = np.trace(ede["sigma"])                    # 与共模 b 无关
    if ccr >= TAU_CCR and integrity >= TAU_EVT \
            and b_free <= EPS_DELTA and cond <= TAU_COND:
        verdict = "VALID"
    elif ccr >= TAU_CCR / 2 and integrity >= TAU_EVT / 2:
        verdict = "DEGRADED"
    else:
        verdict = "UNVERIFIED"
    return {"ede": ede, "ccr": ccr, "cond": cond,
            "event_integrity": integrity,
            "b_free_bound": b_free, "verdict": verdict}

def cmc_gate(ede, j, scene_model, conservative_core):
    if j["verdict"] == "VALID":
        scene_model.update(ede, tighten_only=True)
        return ede
    if j["verdict"] == "DEGRADED":
        scene_model.freeze_relaxation()                # 只膨胀，不放松
        return ede
    return absolute_fallback(conservative_core)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性 |
|---|---|---|---|
| ESS | O(N_e) / 窗口 | O(H·W + N_e) | 转变检测 ≤ 5ms |
| DPE | O(d³)（小） | O(32) 锚点 | CCR ≥ 0.8 |
| EDE | O(1) | O(1) | 误差界与共模项无关 |
| EASP | O(1) | O(1) | 先兆准确率 ≥ 85% |
| STDL | O(闭环) | 复用 | 场景适应 ≥ 90% |

**正确性定理（STDL）**：
若 A66–A70 成立（事件单调有界；共模偏差共享有界；差分雅可比满秩、锚点非共线；门控单调；预算单调消耗），则：
1. 事件先兆时延 L_e ≤ τ_e·ln(1/δ_e)+O(1/ρ_e)；T_lead>0 ⇒ 场景先于接触被识别。
2. 在 A67、A68 下 ‖Δξ−Δξ*‖_{Σ_Δ} ≤ ε_Δ 且 **ε_Δ 不含共模项 b**；CCR→1 时漂移项消失。
3. J_exec^Δ=VALID ⇒ EV-exec^Δ 在 ROS 乱序/丢包下仍满足第 60 轮 EPIR 因果约束。
4. CMC-Gate 只收紧 K_safe，差分退化只膨胀不确定集。
5. 任一预算耗尽 ⇒ 触发确定性回退（帧式 SSM / 绝对定位 / 原降级）。

## 5. 本轮最大风险

**一句话**：事件相机在低纹理、强反光、高速旋转下事件签名可能退化，差分锚点共线或基线过短会让 CCR "虚高"——若不设「事件率下限 + 锚点几何条件数 + CCR 与 b_free_bound 双阈值」三重护栏，就可能出现"差分证书显示高置信、绝对轨迹其实已漂移"的自我欺骗。
