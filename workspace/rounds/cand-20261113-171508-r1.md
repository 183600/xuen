# 第 66 轮（承接第 65 轮「VISTA 视觉知情安全时序归因闭环」IP-214~223；灵感循环第 3 轮；本轮灵感：「论文创新点」×「故障诊断」）

> 第 65 轮把「几何可证伪」升级为「故障可归因」，其自述的最大风险很准：VISTA 依赖「故障属于有限假设集、且视觉与几何失效相互独立」；未知复合故障会被强行塞进最近假设，透明/镜面/对抗 patch 又让视觉与几何共享同一个分布外失效源，于是 FIR 只膨胀错误的球，且系统因「已经归因」反而更自信。本轮不再加第 6 个模态，而是换一个诊断学提问方式：第 65 轮问「是六类里的哪一类」，DxIP 问「**这组观测到底能区分什么、还有哪些解释没被排除、未知能不能被当作未知、我凭什么叫它创新点**」。本轮核心命题：
>
> **把「闭集点归因」升级为「开集最小诊断 + 可诊断性证书」：用故障诊断理论显式处理多故障、掩蔽与未知，用「论文创新点」的视角把每一个声称的能力也变成一个可被诊断、可被证伪的假设。**

## 0. 直觉与动机

### 灵感 1（故障诊断 → 输出不该是一个后验，而是一个「还没被排除的解释集合」）

直觉：VISTA 的 FIR 输出 P(H|ρ) 再取 argmax。但工程诊断很少这么干。真正的诊断医生不会说「87% 是传感器坏了」，而会说「A、B 还排除不了，C 已被证据排除；要分开 A/B 还得做一个激发试验」。这就是 consistency-based diagnosis：诊断的本体不是点，而是**与观测一致的最小故障集合**；冲突集（conflicts）与最小碰集（minimal hitting sets）才是诊断。它天然处理**多故障**（两个小故障同时发生）和**未知故障**（给部件加 unknown 模式，而不是硬塞进最近类）。VISTA 的六假设 softmax 在数学上把「组合」和「未知」都投影掉了——这正是它最大风险的根。

### 灵感 2（故障诊断 → 掩蔽/抵消是最危险的一类，而 VISTA 完全没建模）

直觉：两个故障可以**互相抵消**。一个 +2 N 的力偏置配上一个 −2 N 的模型误差，残差看起来是「健康」；正负偏差在不同阶段反号，三阶段签名也被抹平。经典 FDI 把这叫 fault masking / cancellation。它在安全上最坏，因为系统会**因为残差小反而更自信**。VISTA 的引理 7 只证了「单故障列近正交」，没有证「多故障之和不会撞车」。本轮把掩蔽当一等公民：可诊断性不是一个标量，而是「**是否存在一对不同的故障集产生相同签名**」。

### 灵感 3（故障诊断 → 可诊断度可计算，而且可被主动提高）

直觉：不是所有故障都「可诊断」。给定传感器、动作与噪声，有些故障在结构上就分不开（同一歧义类）。与其假装全能，不如**先把歧义类算出来**：哪些故障对在当前配置下不可分、需要什么动作/传感器才能分开。于是系统能诚实输出「我现在只能分到 3 个类，其中 {H_force, H_model} 还缠在一起」。进一步，主动诊断（active diagnosis）就是选一个动作去**劈开最大的歧义类**，而不是笼统地「最大化互信息」。这比 VISTA 的 AFA 更精确：AFA 只知道假设熵，不知道「哪些假设根本不可分」。

### 灵感 4（论文创新点 → 新颖性检测就是开集故障诊断；创新点本身也该被诊断）

直觉：有两层同构。
- **技术层**：「论文创新点」的内核是 novelty，而故障诊断里的 open-set / novelty detection 正是「未知故障检测」。把未知故障当作 unknown 模式 + conformal 新颖性分数，而不是强行归类，直接补上 VISTA 的开集缺口。
- **元层**：一篇论文的「创新点」本身就是一个**因果假设**——「提升是我这个机制带来的」。它的混淆项是 baseline、其他模块、数据泄漏、超参、随机种子。要证明创新点，本质上就是**把「我的机制」从一堆混淆假设里诊断出来**，这和把 H_geo 从 H_force 里诊断出来是同一个数学问题：签名矩阵、可辨识性、主动实验（消融）、最小解释集。于是本轮给出一个自指贡献：**每个创新点都附一张可诊断性证书（IPC）**，写明它和哪些混淆项被哪个实验分开、可诊断度多少、什么结果会证伪它。这把「论文创新点」从修辞变成可证伪对象。

### 灵感 5（合流 → DxIP：Diagnosable Innovation-Point 闭环）

直觉：VISTA 的链条是「残差 → 点后验 → 定向膨胀 → 认证前缀」。DxIP 把每一环换成集合语义：因果故障图（DFG，含潜在共因节点与 unknown 模式）→ 一致性签名诊断（CSD，输出最小诊断集）→ 可诊断度分析（DDA，算歧义类/κ_dx/掩蔽对）→ 开集诊断（OSD，未知作为一等诊断 + 诊断包络）→ 主动诊断（ADA，劈歧义类而非降假设熵）→ 诊断包络安全前缀（CSC-Dx）→ 诊断集定向球（RSC-Dx/WCV-Dx）→ 多故障/共因/未知对抗认证（AIC-Dx）→ 创新点证书（IPC）→ J_dx。第 65 轮是「点归因 + 认证前缀」，DxIP 升级为「**集合诊断 + 可诊断性 + 开集 + 自证创新点**」。

### 灵感 6（VISTA 组件原位升级）

- **FIR → CSD**：softmax 点后验 → 最小诊断集 + 冲突/碰集；多故障、未知一等公民。
- **AFA → ADA**：假设熵 → 诊断集熵/歧义类劈分；显式选能破掩蔽的探针。
- **CSC → CSC-Dx**：top-2 假设 → 整个诊断包络，按歧义类 + 严重度单调性压缩。
- **RSC-V → RSC-Dx**：单点定向球 → 诊断集包络的**方向性**膨胀（只沿残差可观测方向）。
- **新增 OSD**：unknown 模式 + conformal novelty + 有界诊断包络。
- **新增 DDA**：可诊断性证书（歧义类、κ_dx、掩蔽对、所需动作/传感器）。
- **AIC-V → AIC-Dx**：干扰集增多故障组合、掩蔽对、共因、未知。
- **新增 IPC**：论文创新点的可诊断性证书（claim vs 混淆项）。
- **J_vista → J_dx**。

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（DxIP 闭环）**：DxIP = (VISTA, DFG, CSD, DDA, OSD, ADA, CSC-Dx, RSC-Dx/WCV-Dx, AIC-Dx, IPC, J_dx)。定位：VISTA 的「开集 + 可诊断 + 自证」升级。不变式：**一致性诊断、可诊断度分析、主动诊断、创新点证书只在语义流；实时流只做残差采集、包络早停、认证前缀执行与派发，零学习写操作。**
- **定义 234（诊断故障图 DFG）**：有向无环图 G_D=(V,E)，V=R∪F∪C：R 为残差节点（力、力矩、视觉、几何、块签名），F 为故障模式节点，每个带模式域 {ok, faulty, unknown} 与严重度 θ_f≥0，C 为潜在共因节点（透明物体、光照、对抗 patch、安装漂移）。结构方程 r_i=g_i(pa(r_i);θ)+ε_i。共因节点同时指向 r_vis 与 r_geo，使二者**条件相关**——这是对 VISTA「视觉/几何独立」假设的显式证伪。
- **定义 235（一致性诊断与最小诊断集）**：给定观测 ρ 与各通道 conformal 残差界 q_i(α)，一个诊断 Δ（对 F 的模式/严重度部分赋值）**一致** ⇔ 存在对未观测变量的赋值使所有残差约束成立。D(ρ) 为全体 **⊆-最小（或基数最小）一致诊断**。用冲突集 C_1,…,C_m（在健康假设下无法同时成立的残差子集）与最小碰集计算 D(ρ)：Δ∈D(ρ) ⇔ Δ 是 {C_j} 的最小碰集。**多故障与 unknown 模式是 D(ρ) 的合法元素，不再被投影掉。**
- **定义 236（多故障签名与掩蔽）**：线性化 S_f=∂E[ρ]/∂θ_f。多故障签名 E[ρ|Δ]=Σ_{f∈Δ}S_fθ_f。Δ 在阶数 k_max 内**可辨识** ⇔ 映射 θ↦Σ S_fθ_f 在非负锥 {θ≥0, |Δ|≤k_max} 上单射：任意两个不同 Δ,Δ′（|Δ∪Δ′|≤2k_max）都不存在非零 θ≥0 使 Σ_{Δ}S_fθ_f=Σ_{Δ′}S_{f′}θ_{f′}。否则称 (Δ,Δ′) 为**掩蔽对**。掩蔽对存在时，两个故障集的观测分布完全相同，任何点归因（含 VISTA FIR）的贝叶斯错误率下界为 1/2——只能判 ambiguous 或主动破掩蔽。
- **定义 237（歧义类与可诊断度）**：给定探针序列 U=(u_1,…,u_T)，堆叠签名 S_f(U)=[S_f(u_1);…;S_f(u_T)]，成对可分性 d_U(f,f′)=‖S_f(U)−S_{f′}(U)‖_{Σ_ρ(U)^{-1}}。以阈值 z_{1−α/2} 连边构造不可分图，其连通分量即**歧义类** [f]。可诊断度 κ_dx(U)=min_{f≠f′}d_U(f,f′)；**可诊断率** δ_dx(U)=单点类数/|F|。主动可诊断度 κ*_dx=max_{U∈U_adm}κ_dx(U)，s.t. 力/形变/视觉安全。
- **定义 238（开集诊断 OSD）**：每个部件加 `unknown` 模式与 conformal 新颖性分数 s_nov(ρ)（到已知模式残差分布并集的距离 / 自由能）。若已知最小诊断的最大证据低于阈值且 s_nov(ρ)>q_nov(α)，输出 Δ_unknown。**未知不被硬塞进最近已知类**；其安全响应走有界诊断包络（定义 239）。
- **定义 239（诊断包络与可诊断性证书）**：残差 ρ 的**诊断包络** E(ρ)={Δ:Δ 与 ρ 一致, |Δ|≤k_max}∪{Δ_unknown（若触发）}。可诊断性证书 J_dx^diag=(歧义类, κ_dx, δ_dx, 掩蔽对, 所需动作/传感器, 残差模型版本)。安全必须对 **∀Δ∈E(ρ)** 成立——这是 VISTA「后验支持集」的诚实版本：不预设闭集，也不假装后验已集中。
- **定义 240（主动诊断 ADA）**：选探针 a*=argmax_a E[H(D(ρ))−H(D(ρ_new(a)))]，即**最大化诊断集熵的期望下降**（等价于最大化对歧义类的劈分），s.t. 预测 f_n≤f_safe、形变≤ε_strain、支持视觉早停。对掩蔽对，额外要求探针使 S_f(u) 与 S_{f′}(u) 不再反平行（破抵消）。易损物体只用 visual_probe/null_test。**与 AFA 的区别：AFA 最大化假设熵，ADA 最大化「不可分集合的劈分」，因此能识别并处理结构不可分。**
- **定义 241（诊断包络安全前缀 CSC-Dx）**：对块 A 与前缀 k，要求 ∀Δ∈E(ρ)、∀s≤k 安全裕度≥0。利用**严重度单调性**（安全裕度随 θ_f 单调不增）把每个歧义类压缩为其最坏严重度 θ_max([Δ])，只验证每类一个代表；选最小 k 使 P[∃s≤k:某 Δ∈E(ρ) 越界]≤α_chunk。约束 k*≤m。
- **定义 242（RSC-Dx 诊断集定向球）**：对每个歧义类 [Δ] 求所需半径 r([Δ])；融合 r=max_{[Δ]}r([Δ])（独立轴用 √Σ）。若为 Δ_unknown，**只沿残差可观测方向膨胀**：r_dir=‖S⁺ρ_residual‖+q_nov，正交补方向保持先验半径，避免各向同性 r_max 的过度保守。WCV-Dx 在包络上取 CVaR 最坏。
- **定义 243（AIC-Dx 多故障/共因/未知对抗认证）**：ℰ_Dx=ℰ_V×ℰ_multi×ℰ_common×ℰ_nov，ℰ_multi 含 ≤k_max 同时故障与掩蔽对，ℰ_common 含潜在共因节点激活，ℰ_nov 含未知模式。认证要求：对每个对抗场景，要么 D(ρ) 为单点且正确，要么包络安全成立并安全降级。**共因/未知下不要求归因正确，只要求不误判健康、不越界。**
- **定义 244（创新点证书 IPC）**：一个创新点 c=(机制 M_c, 效应 E_c, 语境 C_c)。混淆项集合 A(c)={baseline, 其他模块, 数据泄漏, 超参, 种子, 评价偏差}。实验 e(c) 产出的效应签名列 {S_c}∪{S_a:a∈A(c)}。**c 可诊断** ⇔ 该列集满秩且 κ_ip(e)=min_{a∈A(c)}‖S_c−S_a‖/σ_e>z_{1−α}。IPC(c)=(c, A(c), e(c), κ_ip, D_ip(e), 证伪条件, evidence_hash)。
- **定义 245（创新点最小诊断与接受规则）**：D_ip(e) 为「观测到的效应」的最小一致解释集（以创新点与混淆项为候选故障模式）。**c 被接受** ⇔ D_ip(e)={c}（唯一最小解释），且不存在 a∈A(c) 同样解释该效应。若 D_ip(e) 含多个元素，则判「创新点不可归因」，必须补做能劈开该歧义类的实验——**这正是论文里该写 ablation 的地方**。
- **定义 246（DxIP 证书 J_dx）**：J_dx=(J_vista, D(ρ), 歧义类, κ_dx, unknown_flag, 掩蔽对, E(ρ), k*, IPC 集, aic_dx_ver)。Valid ⇔ Valid(J_vista) ∧ (D(ρ) 单点 ∨ 包络安全) ∧ k*≥1 ∧ (unknown ⇒ 用有界包络) ∧ 每个声称 IP 有 IPC ∧ aic_dx_ver 为当前版本。
- **定义 247（创新点-诊断对偶）**：映射 f↦c、ρ↦实验测量、故障模式↦混淆项、主动诊断↦消融/实验设计、D(ρ)↦D_ip(e)，则 IPC 问题与 CSD 问题是同一实例：都是「从残差签名中辨识稀疏因果解释，面对混淆、多故障、未知，并需要主动实验」。故 DxIP 的求解器、可诊断度分析与证书机制可原样复用于论文创新点验证。
- **定义 248（DxIP 闭环算子）**：语义流 [LiDAR→LSF→USR/MEL→VPG→ACH→阶段切分→VCV→DFG/CSD 最小诊断→DDA 可诊断度→OSD→ADA→WCV-Dx→CSP-V→CSC-Dx→Shield→执行 k*→EV_exec→RSC-Dx→OLP→DIR→AIC-Dx→IPC]；实时流 [锚点读→残差采集→阶段判定→包络早停→WCV-Dx 编译→π_σ 前缀派发→J_dx 构建]。

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（多故障可辨识与掩蔽）**：E[ρ|Δ]=Σ_{f∈Δ}S_fθ_f。Δ 在 k_max 内可辨识 ⇔ 映射在非负锥上单射；若存在掩蔽对 (Δ,Δ′)，两故障集的观测分布相同，任何点归因的贝叶斯错误率≥1/2。推论：VISTA 的三阶段签名仍可能被跨阶段反号抵消抹平；必须用非负性、起始时刻或主动输入破掩蔽。
- **引理 10（诊断包络的执行安全）**：若 E(ρ) 以概率≥1−α_nov 包含真实诊断，且 CSC-Dx 对每个 Δ∈E(ρ) 验证了 k*≤m 步安全，则单块越界概率 ≤ α_chunk+α_nov+α_vis+α_model。利用严重度单调性，每类只需验证最坏严重度代表，组合爆炸被压成「歧义类数」。
- **定理 9（DxIP 端到端诊断-安全）**：在 A94–A99 下，Valid(J_dx) ⇒ （单点正确诊断 ∨ 包络安全降级）∧ 未知不被硬塞 ∧ 掩蔽被显式标记 ∧ k* 前缀安全 ∧ IPC 有效。证书链从「几何-技能-干扰-接触-归因」扩到「几何-技能-干扰-接触-诊断-可诊断性-创新点」。
- **定理 10（主动诊断的近最优性）**：设单次探针的信息增益下界 I_min，则把诊断集从 D 缩到单点所需探针数期望 ≤ H(D)/I_min+1；在自适应子模性下贪心 ADA 达到 (1−1/e) 近似；破掩蔽最多需 ⌈log₂|classes|⌉ 个「非反平行」输入。
- **命题（创新点-诊断对偶）**：IPC 是 CSD 的实例；故创新点误归因率 ≤ 该 claim 的掩蔽概率，且「补 ablation」正是「主动诊断劈歧义类」。这把论文的 novelty 论证从叙事变成可计算的诊断问题。
- **实时性**：DFG/CSD/DDA/OSD/ADA/IPC 全在语义流；实时流只增包络早停与阶段判定，目标 ≤2.7ms（A100）。

## 5. 本轮最大风险

**一句话**：DxIP 的全部结论依赖「诊断故障图 DFG 与残差模型在结构上正确」；一旦图漏掉一条潜在共因路径或一个残差通道，一致性诊断会给出一个**自洽但错误的最小诊断集**，更糟的是可诊断性证书会把本不可分的歧义类**认证为可分的**——系统恰恰因为「已经证明可诊断」而更自信地执行，即开集机制只覆盖了未知故障**模式**，却没有覆盖未知的**因果结构**。

## 2. 形式化定义（完整版）

**定义 233（DxIP 闭环）** DxIP 是 VISTA 的「开集 + 可诊断 + 自证」升级：在 VISTA 的「语义流 ∘ 实时流」骨架上挂载 DFG（因果故障图）、CSD（一致性最小诊断）、DDA（可诊断度分析）、OSD（开集诊断）、ADA（主动诊断）、CSC-Dx（包络认证前缀）、IPC（创新点证书），并原位升级 RSC-V→RSC-Dx、WCV-V→WCV-Dx、AIC-V→AIC-Dx、J_vista→J_dx。不变式：**所有一致性诊断、可诊断度分析、主动诊断、创新点证书只发生在语义流与低频线程；实时路径只做残差采集、包络早停、认证前缀执行与派发，零学习写操作。**

**定义 234（诊断故障图 DFG）** 有向无环图 G_D=(V,E)，V=R∪F∪C：
- R 为残差节点，含第 65 轮的 `e_vis, e_force, e_torque, d_chunk, u_chunk` 与几何/接触残差；
- F 为故障模式节点，每个 `f∈F` 带模式域 `{ok, faulty, unknown}` 与严重度 `θ_f≥0`；
- C 为潜在共因节点（透明物体、镜面反光、对抗 patch、安装漂移、温漂）；
- 边编码因果影响，结构方程 `r_i=g_i(pa(r_i);θ)+ε_i`，`ε_i∼(0,Σ_i)`。
共因节点同时指向 `r_vis` 与 `r_geo`（或 `r_force`），使二者**条件相关**。这显式否定了 VISTA 的「视觉与几何失效相互独立」假设：透明物体不是「两个独立故障」，而是**一个共因**。DFG 的每条边带结构版本号，写入 `J_dx.dfg_ver`。

**定义 235（一致性诊断与最小诊断集）** 给定观测 ρ 与各通道 split-conformal 残差界 `q_i(α)`，一个诊断 Δ（对 F 的部分模式/严重度赋值）**一致** ⇔ 存在对未观测变量（`F∖Δ` 的模式、C 的取值）的赋值，使 `dist(r_i(ρ), g_i(pa(r_i);θ)) ≤ q_i(α)` 对所有 `i` 成立。`D(ρ)` 为全体 ⊆-最小（多故障时基数最小）一致诊断。计算用**冲突集**：`C_j ⊆ R` 是在健康假设下无法同时成立的残差子集；由 Reiter 定理，`Δ∈D(ρ) ⇔ Δ` 是全体最小冲突 `{C_j}` 的最小碰集。与 VISTA FIR 的本质区别：`D(ρ)` 可以含多个元素、可以含 `unknown`、可以含两个同时故障，**不再把「组合/未知」投影到最近单点**。

**定义 236（多故障签名与掩蔽）** 线性化 `S_f=∂E[ρ]/∂θ_f`，多故障签名 `E[ρ|Δ]=Σ_{f∈Δ}S_fθ_f`（一阶叠加）。Δ 在阶数 `k_max` 内**可辨识** ⇔ 映射 `θ↦Σ S_fθ_f` 在非负锥 `{θ≥0, |Δ|≤k_max}` 上单射：任意两个不同 `Δ,Δ′`（`|Δ∪Δ′|≤2k_max`）都不存在非零 `θ≥0` 使 `Σ_{Δ}S_fθ_f=Σ_{Δ′}S_{f′}θ_{f′}`。否则称 `(Δ,Δ′)` 为**掩蔽对**。掩蔽对存在时两故障集的观测分布完全相同，任何点归因（含 VISTA FIR 的 argmax）的贝叶斯错误率下界为 1/2；唯一正确做法是判 ambiguous 或用主动输入破掩蔽。典型来源：正力偏置抵消负模型误差；不同阶段反号偏差抹平三阶段签名。非负性、起始时刻差异、跨阶段不同激励是三类可利用的破掩蔽结构。

**定义 237（歧义类与可诊断度）** 给定探针序列 `U=(u_1,…,u_T)`，堆叠签名 `S_f(U)=[S_f(u_1);…;S_f(u_T)]`，成对可分性 `d_U(f,f′)=‖S_f(U)−S_{f′}(U)‖_{Σ_ρ(U)^{-1}}`。以阈值 `z_{1−α/2}` 连边构造不可分图，连通分量即**歧义类** `[f]`。可诊断度 `κ_dx(U)=min_{f≠f′}d_U(f,f′)`；可诊断率 `δ_dx(U)=单点类数/|F|`。主动可诊断度 `κ*_dx=max_{U∈U_adm}κ_dx(U)`，s.t. 力/形变/视觉安全。可诊断度是**配置的属性**（传感器布置 + 动作序列 + 噪声），不是算法的属性——DDA 的职责就是把它算出来并写进证书。

**定义 238（开集诊断 OSD）** 每个部件加 `unknown` 模式与 conformal 新颖性分数 `s_nov(ρ)`（到已知模式残差分布并集的距离，或负对数边缘似然/自由能）。若已知最小诊断的最大证据低于阈值且 `s_nov(ρ)>q_nov(α)`，输出 `Δ_unknown`。未知**不被硬塞**进最近已知类；其安全响应走有界诊断包络（定义 239）。`q_nov(α)` 在标定集上按 split-conformal 取分位数，保证在可交换性下未知样本被标为未知的概率 ≥1−α。

**定义 239（诊断包络与可诊断性证书）** 残差 ρ 的**诊断包络** `E(ρ)={Δ:Δ 与 ρ 一致, |Δ|≤k_max}∪{Δ_unknown（若触发）}`。可诊断性证书 `J_dx^diag=(歧义类, κ_dx, δ_dx, 掩蔽对, 所需动作/传感器, dfg_ver, 残差模型版本)`。安全必须对 `∀Δ∈E(ρ)` 成立——这是 VISTA「后验支持集」的诚实版本：不预设闭集，也不假装后验已集中。若 `E(ρ)` 过大（`|E(ρ)|>N_env` 或 `κ_dx<κ_min`），触发 ADA 或 `safe_idle`。

**定义 240（主动诊断 ADA）** 选探针
`a*=argmax_a E[H(D(ρ))−H(D(ρ_new(a)))]`，
即最大化**诊断集熵的期望下降**（等价于最大化对歧义类的劈分），s.t. 预测 `f_n≤f_safe(φ̂,f̂_vis)`、形变 `≤ε_strain`、支持视觉早停。对掩蔽对，额外要求探针使 `S_f(u)` 与 `S_{f′}(u)` 不再反平行（破抵消）。易损物体只用 `visual_probe/null_test`。**与 VISTA AFA 的区别**：AFA 最大化假设熵，ADA 最大化「不可分集合的劈分」，因此能识别并处理结构不可分；ADA 的探针集显式含 `null_test`（零力窗，识别 F/T 偏置）与 `fi_probe`（破掩蔽的差异化激励）。

**定义 241（诊断包络安全前缀 CSC-Dx）** 对块 A 与前缀 k，要求 `∀Δ∈E(ρ)`、`∀s≤k` 安全裕度 `≥0`。利用**严重度单调性**（安全裕度随 `θ_f` 单调不增），把每个歧义类压缩为其最坏严重度 `θ_max([Δ])`，只验证每类一个代表；选最小 k 使
`P[∃s≤k:某 Δ∈E(ρ) 越界] ≤ α_chunk`，
输出 `k*(A)` 与最小安全裕度。约束 `k*≤m`。相比 VISTA CSC 只取 top-2 假设，CSC-Dx 覆盖整个包络，但计算量由「歧义类数」而非「诊断数」决定。

**定义 242（RSC-Dx 诊断集定向球）** 对每个歧义类 `[Δ]` 求所需半径 `r([Δ])`；融合 `r=max_{[Δ]}r([Δ])`（独立轴用 `√Σ`）。若为 `Δ_unknown`，**只沿残差可观测方向膨胀**：
`r_dir=‖S⁺ρ_residual‖+q_nov`，
正交补方向保持先验半径，避免各向同性 `r_max` 的过度保守。WCV-Dx 在包络上取 CVaR 最坏（`n_worst=8`）；交集为空则 `safe_idle + compliant retreat`，置 `diagnosis_incomplete=True`。方向性膨胀是对 VISTA「只膨胀被归因者」的开集推广：未知时无法知道「谁坏了」，但残差能告诉我们「哪个方向被约束了」，就只在该方向保守。

**定义 243（AIC-Dx 多故障/共因/未知对抗认证）** 干扰集
`ℰ_Dx=ℰ_V×ℰ_multi×ℰ_common×ℰ_nov`，
`ℰ_multi` 含 `≤k_max` 同时故障与掩蔽对，`ℰ_common` 含潜在共因节点激活，`ℰ_nov` 含未知模式。认证要求：对每个对抗场景，要么 `D(ρ)` 为单点且正确，要么包络安全成立并安全降级。**共因/未知下不要求归因正确，只要求不误判健康、不越界。** `n_cert 128→160`（其中 32 给多故障/掩蔽/共因/未知）；`J_dir` 增 `dfg_ver, diag_cert_ver, ipc_ver`。

**定义 244（创新点证书 IPC）** 一个创新点 `c=(机制 M_c, 效应 E_c, 语境 C_c)`。混淆项集合 `A(c)={baseline, 其他模块, 数据泄漏, 超参, 种子, 评价偏差}`。实验 `e(c)` 产出的效应签名列 `{S_c}∪{S_a:a∈A(c)}`。**c 可诊断** ⇔ 该列集满秩且
`κ_ip(e)=min_{a∈A(c)}‖S_c−S_a‖/σ_e > z_{1−α}`。
`IPC(c)=(c, A(c), e(c), κ_ip, D_ip(e), 证伪条件, evidence_hash)`。

**定义 245（创新点最小诊断与接受规则）** `D_ip(e)` 为「观测到的效应」的最小一致解释集（以创新点与混淆项为候选故障模式）。**c 被接受** ⇔ `D_ip(e)={c}`（唯一最小解释），且不存在 `a∈A(c)` 同样解释该效应。若 `D_ip(e)` 含多个元素，判「创新点不可归因」，必须补做能劈开该歧义类的实验——**这正是论文里该写 ablation 的地方**。证伪条件必须**预注册**：在什么测量区域内，效应会被归因于某个混淆项。

**定义 246（DxIP 证书 J_dx）** `J_dx=(J_vista, D(ρ), 歧义类, κ_dx, unknown_flag, 掩蔽对, E(ρ), k*, IPC 集, aic_dx_ver)`。验证规则：
`Valid(J_dx) ⇔ Valid(J_vista)`
`∧ (D(ρ) 单点 ∨ 包络安全)`
`∧ k*≥1 ∧ (unknown ⇒ 用有界包络)`
`∧ 每个声称 IP 有 IPC ∧ aic_dx_ver 为当前版本`。
审计链新增：为什么是这组诊断（D(ρ)）、为什么这些故障不可分（歧义类/κ_dx）、是否存在掩蔽（masking_pairs）、为什么只执行 k* 步（CSC-Dx）、未知是否被诚实标注（unknown_flag）、每个创新点凭什么被归因（IPC）。

**定义 247（创新点-诊断对偶）** 映射 `f↦c`、`ρ↦实验测量`、`故障模式↦混淆项`、`主动诊断↦消融/实验设计`、`D(ρ)↦D_ip(e)`，则 IPC 问题与 CSD 问题是同一实例：都是「从残差签名中辨识稀疏因果解释，面对混淆、多故障、未知，并需要主动实验」。故 DxIP 的求解器、可诊断度分析与证书机制可原样复用于论文创新点验证。该对偶是本轮「论文创新点 × 故障诊断」的数学落点。

**定义 248（DxIP 闭环算子）** 语义流 `[LiDAR→LSF→USR/MEL→VPG→ACH→阶段切分→VCV→DFG/CSD 最小诊断→DDA 可诊断度→OSD→ADA→WCV-Dx→CSP-V→CSC-Dx→Shield→执行 k*→EV_exec→RSC-Dx→OLP→DIR→AIC-Dx→IPC]`；实时流 `[锚点读→残差采集→阶段判定→包络早停→WCV-Dx 编译→π_σ 前缀派发→J_dx 构建]`。

### IP-225 CSD（一致性最小诊断）

```python
class ConsistencyDiagnosis:
    """健康假设下找冲突，再由最小碰集得最小诊断集；多故障/unknown 一等公民。"""
    def __init__(self, dfg, q_alpha, k_max=3, n_env_max=64):
        self.dfg, self.q, self.k_max, self.n_env_max = dfg, q_alpha, k_max, n_env_max

    def conflicts(self, rho):
        # 在 ok 模式下逐通道检验；不可同时成立的残差子集即最小冲突
        bad = [i for i, ri in enumerate(rho)
               if self.dfg.residual_violation(i, ri, modes='ok') > self.q[i]]
        return minimal_conflict_subsets(bad, self.dfg)   # Reiter 冲突集

    def diagnose(self, rho):
        conf = self.conflicts(rho)
        if not conf:                                     # 与健康一致
            return [Diagnosis.healthy()], [Diagnosis.healthy()]
        D = minimal_hitting_sets(conf, k_max=self.k_max)
        D = [d for d in D if self.dfg.consistent(d, rho, self.q)]
        if not D:
            D = [Diagnosis.unknown()]                    # 无已知解释
        env = [self.dfg.worst_severity(d, rho, self.q) for d in D]
        if len(D) > self.n_env_max:                      # 包络过大 → 主动诊断
            D = self.dfg.coarsen_ambiguity_classes(D)
        return D, env

    def diagnose_with_novelty(self, rho, s_nov, q_nov):
        D, env = self.diagnose(rho)
        if max(self.dfg.evidence(d, rho) for d in D) < self.dfg.evidence_floor \
           and s_nov(rho) > q_nov:
            D = [Diagnosis.unknown()]                    # 开集：未知不硬塞
        return D, env
```

### IP-226 DDA（可诊断度与掩蔽）

```python
class DiagnosabilityAnalysis:
    def certificate(self, S_list, Sigma_inv, alpha, k_max):
        F = len(S_list)
        # 1) 成对可分性与不可分图
        d = {(i, j): separation(S_list[i], S_list[j], Sigma_inv)
             for i in range(F) for j in range(i + 1, F)}
        thr = z_value(1 - alpha / 2)
        classes = connected_components(F, [(i, j) for (i, j), v in d.items() if v <= thr])
        kappa = min(d.values()) if d else float('inf')
        delta = sum(1 for c in classes if len(c) == 1) / F
        # 2) 掩蔽对：在非负锥上找 Σ S_f θ_f = Σ S_f' θ_f'
        masking = []
        for i in range(F):
            for j in range(i + 1, F):
                if has_nonneg_cancellation(S_list[i], S_list[j], k_max):
                    masking.append((i, j))
        return DiagCert(classes=classes, kappa=kappa, delta=delta,
                        masking=masking, dfg_ver=self.dfg.ver)

    def required_inputs(self, masking):
        # 破掩蔽所需的最小差异化激励数
        return max(1, int(np.ceil(np.log2(max(2, len(masking)) + 1))))
```

class ActiveDiagnosis:
    PROBES = ('visual_probe', 'null_test', 'press', 'rub', 'tap', 'lift', 'fi_probe')

    def choose_probe(self, D, env, masking, phi_hat, f_safe, fragile):
        if fragile:
            return 'visual_probe' if self._splits(D, 'visual_probe') else 'null_test'
        best, best_gain = None, 0.0
        for a in self.PROBES:
            traj = predict_probe_traj(a, phi_hat)
            if np.max(traj.f) > f_safe or np.max(traj.strain) > EPS_STRAIN:
                continue
            # 诊断集熵下降（而非假设熵）+ 破掩蔽奖励
            gain = expected_entropy_drop(D, a, self.csd) \
                 + BREAK_BONUS * self._breaks_masking(a, masking)
            if gain > best_gain:
                best, best_gain = a, gain
        return best if best_gain > DELTA_DX else None

class EnvelopeChunkCertificate:
    def certified_prefix(self, A, D, env, m, alpha_chunk):
        # 每个歧义类取最坏严重度代表；严重度单调 ⇒ 只验代表
        reps = compress_by_ambiguity_class(D, env)
        k_best = 0
        for k in range(1, min(len(A), m) + 1):
            if any(safety_margin(A[s], d.worst) < 0
                   for d in reps for s in range(k)):
                break
            if self._violation_prob(A[:k], reps) <= alpha_chunk:
                k_best = k
            else:
                break
        return k_best

    def monitor_step(self, a, D):
        rho = acquire_residuals()
        return AbortFlag(abort=not self.csd.consistent_with(D, rho))

def rsc_dx_update(E, S, rho_residual, q_nov, balls):
    if E is unknown_diagnosis(E):
        r_dir = np.linalg.norm(np.linalg.pinv(S) @ rho_residual) + q_nov
        # 只在 S 的行空间膨胀；正交补保持先验

    return balls


def wcv_dx_compile(phi_hat, balls, E, G_set, mu_hat, f_lim, n_worst=8, eps=0.05):
    candidates = []
    for _ in range(n_worst):
        d = sample_from_envelope(E)                      # 包络边缘化

        if phi_c is None:

        K = eeis.compile_with_phys_constraint(olp.project(x_prime), phi_c)
        candidates.append((phi_c, K, safety_margin(K, phi_c)))

class InnovationPointCertificate:
    def certify(self, claim, confounders, experiment):
        # 与 CSD 同构：claim 当作故障，混淆项当作其他故障模式

### IP-233 DxIP 闭环算子（整合）

```python
def DxIP_round(M, obs, delta_f_req):
    V, T, P, L, P_cloud, W_meas, tactile, img, depth, flow = obs
    # ———— 语义流 ————
    M.lsf.update_geometry(P_cloud)
    x_prime = M.lsf.fuse(M.usr.fuse(V, T, P, L))
    y_vis = M.f_vis(img, depth, flow)
    A = M.ach.propose(x_prime, H=M.H)                    # 长视界块
    visual = M.vpg.verify_and_predict(y_vis, A, M.mws.last_contacts)
    f_vis, k_hat, _ = M.vfp.estimate(visual['flow'], M.dt, visual['valid'])
    phases = M.stage.split(M.residual_log, visual)

    # 1) CSD + OSD：最小诊断集（含 unknown）
    D, env = M.csd.diagnose_with_novelty(
        M.signature(phases), M.novelty, M.q_nov)
    # 2) DDA：可诊断性证书
    cert = M.dda.certificate(M.signature_columns(), M.Sigma_inv, M.alpha, M.k_max)
    # 3) ADA：劈歧义类 / 破掩蔽
    if len(cert.classes) > 1 or cert.masking:
        a = M.ada.choose_probe(D, env, cert.masking, M.phi_hat, M.f_safe, M.fragile)
        if a is not None:
            M.execute_probe(a)
            D, env = M.csd.diagnose_with_novelty(
                M.signature(M.stage.split(M.residual_log, visual)), M.novelty, M.q_nov)
    # 4) 诊断集定向球（方向性）
    M.balls = M.rsc_dx.update(D, M.S, M.residual, M.q_nov, M.balls)
    # 5) 包络规划 + 认证前缀
    goal = M.dms.parse_goal((M.usr.U_ep, M.usr.U_al))
    tau = M.csp_v.plan_chunks(goal, x_prime, M.phi_hat, M.balls, D)
    k_star = M.csc_dx.certified_prefix(tau.A, D, env, M.m, M.alpha_chunk)
    # 6) 实时执行 + 包络早停
    K_safe, EV_exec, cert_exec = realtime_step_dxip(M, delta_f_req, tau, k_star)
    # 7) 在线更新 + 认证 + 创新点证书（纯语义流）
    M.olp.online_step(M.olp.fuse_evidence(x_prime, W_meas, tactile, visual, D),
                      execution_loss_grad(K_safe, EV_exec, M.balls))
    M.rsc_dx.update(EV_exec, W_meas, M.phi_hat, D, M.balls)
    M.dir.update(sample_batch_from_history(32))
    rho_dir = M.aic_dx.certify(tau, x_prime, M.phi_hat, M.balls, D, cert)
    ipc = {c: M.ipc.certify(c, M.confounders[c], M.experiments[c])
           for c in M.claimed_ips}
    return M, K_safe, EV_exec, build_j_dx(
        cert_exec, J_grip=M.j_grip, D=D, classes=cert.classes, kappa_dx=cert.kappa,
        unknown=is_unknown(D), masking=cert.masking, env=env, k_star=k_star,
        ipc=ipc, aic_dx_ver=AIC_DX_VERSION)
```

## 4. 推导

**引理 9（多故障可辨识与掩蔽）** 设多故障一阶签名 `E[ρ|Δ]=Σ_{f∈Δ}S_fθ_f`，`θ≥0`。Δ 在阶数 `k_max` 内可辨识 ⇔ 映射在非负锥上单射。若存在 `Δ≠Δ′` 与非零 `θ,θ′≥0` 使 `Σ_{Δ}S_fθ_f=Σ_{Δ′}S_{f′}θ_{f′}`，则两故障集的观测分布相同，任何只依赖 ρ 的点归因的贝叶斯错误率 ≥1/2；因此 VISTA FIR 的 argmax 在此场景下必然以正概率错分，且「残差小」不代表健康。三阶段签名仍可被掩蔽：只要跨阶段反号抵消使每阶段签名相等即可。破掩蔽需要 (i) 非负性约束缩小可行锥、(ii) 起始时刻差异提供时域分离、(iii) 主动输入使 `S_f(u)` 与 `S_{f′}(u)` 非反平行。∎

**引理 10（诊断包络的执行安全）** 设真实诊断以概率 ≥`1−α_nov` 落在 `E(ρ)`（conformal 新颖性 + DFG 模型有效性），CSC-Dx 对每个 `Δ∈E(ρ)` 验证了前 `k*≤m` 步安全。由严重度单调性，每歧义类最坏代表 `θ_max([Δ])` 给出该类最小裕度，验证代表即验证全类。由联合界，
`P[越界] ≤ α_chunk + α_nov + α_vis + α_model`。
由于 `k*≤m`，即使故障在块首激活，检出或强制重规划也发生在越过不可逆点之前。故块承诺不引入超出单步安全的新风险，且该结论对**多故障与未知**同样成立（这是相对 VISTA 引理 8 的关键扩展）。∎

**定理 9（DxIP 端到端诊断-安全）** 在 A94–A99 下：
1. **集合诊断正确性**：`D(ρ)` 包含真实诊断（在 DFG 结构正确、残差模型有效、conformal 覆盖下）；若 `D(ρ)` 为单点则归因正确，否则系统**诚实输出歧义**而非硬塞（定义 235/238）。
2. **掩蔽可见**：若存在掩蔽对，DDA 的 `masking` 非空，`J_dx` 置 `masking_detected`，禁止「残差小 ⇒ 健康」的结论（引理 9）。
3. **未知安全**：`Δ_unknown` 时只用有界方向性包络（定义 239/242），不各向同性膨胀，也不假装已知。
4. **包络前缀安全**：CSC-Dx 覆盖 `∀Δ∈E(ρ)`，`k*≤m`（引理 10）。
5. **可诊断性诚实**：`J_dx^diag` 报告当前配置的歧义类与 κ_dx；`κ_dx<κ_min` 时禁止声称「可归因」，必须 ADA 或 `safe_idle`。
6. **创新点可归因**：每个声称 IP 有 `IPC`，`D_ip={c}` 才接受（定义 245）；否则标记「不可归因」并补消融。
7. **实时性**：实时路径 ≤2.7ms，零学习写操作（A100）。∎

**定理 10（主动诊断的近最优性）** 设单次探针的信息增益下界 `I_min`，诊断集熵 `H(D)`。每次成功劈分使熵至少减 `I_min`，故把 `D` 缩到单点所需探针数期望 `≤ H(D)/I_min+1`。在自适应子模性下，贪心 ADA 的信息增益达到最优的 `(1−1/e)` 近似。破掩蔽需至少 `⌈log₂|classes|⌉` 个使签名非反平行的差异化输入；DDA 的 `required_inputs` 给出该下界。∎

**命题（创新点-诊断对偶）** 由定义 247 的映射，IPC 的列集满秩条件即 CSD 的 `SᵀΣ⁻¹S≻0`，`D_ip(e)` 即 `D(ρ)`，`κ_ip` 即 `κ_dx`。故创新点误归因率 ≤ 该 claim 的掩蔽概率；「补 ablation」正是「主动诊断劈歧义类」。这把论文的 novelty 论证从叙事变成可计算的诊断问题：**一个创新点若不能与混淆项分离，就不是可诊断的创新点，只是相关性叙事。** ∎

**命题（方向性膨胀的保守性）** 设残差对参数的灵敏度矩阵为 `S`，`Δ_unknown` 时的真实参数偏差 `δφ` 只能被 `S` 的行空间约束。各向同性膨胀 `r_max` 的搜索域体积 ∝ `r_max^{d_φ}`；方向性膨胀只在 `rank(S)` 维膨胀，正交补保持 `r_prior`，故当 `rank(S)<d_φ` 时体积比为 `(r_dir/r_max)^{rank(S)}`，显著降低过度保守。∎

## 8. 已知风险

**一句话**：DxIP 的全部结论依赖「诊断故障图 DFG 与残差模型在结构上正确」；一旦图漏掉一条潜在共因路径或一个残差通道，一致性诊断会给出一个**自洽但错误的最小诊断集**，更糟的是可诊断性证书会把本不可分的歧义类**认证为可分的**——系统恰恰因为「已经证明可诊断」而更自信地执行，即开集机制只覆盖了未知故障**模式**，却没有覆盖未知的**因果结构**。

**次级风险与缓解**：
1. **DFG 结构错误**：漏边/错边使诊断自洽但错误；缓解：DFG 版本化、结构消融、共因节点显式化、未知模式下 `safe_idle`、用残差相关性检验补边。
2. **最小诊断组合爆炸**：`|F|` 大、`k_max` 大时碰集数指数增长；缓解：`k_max≤3`、增量冲突、按后验剪枝、歧义类粗化、`n_env_max` 上限。
3. **掩蔽对难枚举**：连续严重度下掩蔽对是流形；缓解：在非负锥上解线性可行性、采样最坏对、主动输入破反平行。
4. **conformal 新颖性在漂移下失准**：未知阈值名不副实；缓解：在线重校准、漂移检测、按工况分桶。
5. **方向性膨胀仍可能过保守/欠保守**：`S` 估计误差导致方向错；缓解：`S` 用鲁棒回归、膨胀加 `q_nov` 安全余量、包络 CVaR。
6. **IPC 被质疑为「元研究」而非机器人贡献**：缓解：把 IPC 定位为**评测协议**，主贡献仍是 C1–C4，IPC 作为可复现性/可证伪性附件；同时报告真实机器人实验。
7. **实时预算**：CSD/DDA/ADA 若误入实时环会超时；缓解：严格语义流、实时只做包络早停、DFG 预编译。
8. **未知 + 共因同时发生**：包络可能过大导致 `safe_idle` 频繁；缓解：方向性膨胀、按残差可观测性排序、任务级恢复策略。
