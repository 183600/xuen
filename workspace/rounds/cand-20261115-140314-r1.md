# 第 7 轮（灵感循环第 7 轮；本轮灵感：「UniBot」×「人机协作」）

> **基线**：第 6 轮 MetricVoiceGauge（定义 493–520；引理 69–72；实验 E493–E512）。
> **本轮纪律**：把「人」从指令源提升为**共同行动者**，但不得破坏既有退化链。两条硬纪律：**(i) 统一体投影**——人不在场时严格退化为 MetricVoiceGauge；**(ii) 权威层级闭合**——协作中的任何时刻都至少有一个被证书覆盖的权威层级，且 M₀ 硬约束永远最高。

## 0. 直觉与动机

**灵感 1（UniBot → 一个身体、两套策略的「统一体」）**
直觉：现有系统把机器人当成独立执行器，人只通过离散指令 ι 介入；但真实协作中，人和机器共享同一个身体与世界模型，区别只在**谁在某一瞬间握有控制权**。于是把 UniBot 理解为「统一体假设」：存在一个共享动力学 `f`，机器人策略 `π_r` 与人类策略 `π_h` 只是对同一状态的两个投影；「人机协作」不是外挂一个人类模块，而是**在统一体上切换投影权重**。关键约束：必须存在投影 `U|¬h`，使得关闭人类通道后系统与第 6 轮**逐周期同构**——否则统一体只是重新包装。

**灵感 2（人机协作 → 从共享自主到「可证书的权威协商」）**
直觉：共享自主最容易出问题的不是能力，而是**权威**：谁负责、何时接管、接管瞬间状态是否连续、信任是否校准。人类过度信任机器会放弃监督（over-trust），信任不足则频繁无谓接管（under-trust）。因此把协作建模为**权威层级 A₀–A₃** 上的可证书迁移：每层都有进入判据、退出判据和到 A₀ 的退化映射；接管/交还必须满足**无扰动切换（bumpless transfer）**，任何时刻不允许出现「无权威真空」。

## 1. 研究问题

- **Q1（统一体的可退化性）**：如何定义共享世界模型与双策略投影，使得人类通道缺席时系统**严格等于** MetricVoiceGauge，而不是行为近似？
- **Q2（权威切换的无空洞性）**：在 50Hz 回路与通信中断条件下，怎样的权威协商 + 接管协议能保证切换期间硬约束持续有效、状态残差有界？
- **Q3（信任与意图的可逆校准）**：如何估计人类可靠性与共同 ground，使得权威分配对信任单调、对风险反单调，并把协作偏差可逆地映射回指令/权威参数，避免 over-/under-trust？

## 2. 三条设计原则（雏形，正式化见产物区定义 521–548）

**P7 统一体投影等价（UniBot Projection Equivalence）**
定义统一体 `U = (f, π_r, H, π_h)`，`H` 为人类通道（可缺席、可噪声、可对抗）。存在投影 `U|¬h`：令人类动作 `u_t = ⊥`、`π_h` 失活，则 `U|¬h` 的状态轨迹与第 6 轮 MetricVoiceGauge 逐周期一致（同随机种子、同 ι 序列下）。

**P8 权威层级闭合（Authority Ladder Closure）**
定义权威层级 `A = (A₀, A₁, A₂, A₃)`：**A₀** 机器硬否决（人类仅建议）、**A₁** 机器主导/人类监督、**A₂** 共享（联合动作需一致）、**A₃** 人类主导/机器辅助。每层有进入判据 `τ_i = (trust_lo_i, risk_hi_i, cg_lo_i)` 与退化映射 `δ_A: A_i → A₀`。**闭合性**：任一时刻存在且仅存在一个有效 `CoCert` 覆盖当前权威；`A_i` 失效则立即退 `A₀`。M₀ 硬约束在**所有**层级之上，A₃ 也不能覆盖。

**P9 信任–意图可逆性（Trust–Intent Reversibility）**
信任估计 `θ̂_h` 与共同 ground `CG` 必须**可校准**（ECE 有界）且**可逆向**：给定协作结果，可归因到「人不可靠 / 意图不一致 / 共同 ground 缺失」三类，并映射为权威参数调整 `Δ_A`，而不是黑箱式地降低自主性。

## 3. 与基线的接口（如何退化）

- 人类通道缺席/静默 `> T_silence` ⇒ `U|¬h`，严格退回第 6 轮 MetricVoiceGauge；
- TrustCalibrator 失效/超时 ⇒ **冻结** `θ̂_h` 并把权威上限钳到 `A₁`（机器主导），不放开到 A₂/A₃；
- IntentReconciler 失效/冲突不可判定 ⇒ 强制澄清一次；仍失败则退 `A₁`，再失败退 `A₀`；
- HandoffProtocol 失效 ⇒ 禁止接管，保持当前层级至下一周期再判定；
- 任意新组件失效 ⇒ 退回 MetricVoiceGauge（等价 `A₀`）。

## 4. 预期贡献

1. **统一体投影等价**：给出 `U|¬h = MetricVoiceGauge` 的形式化与逐周期证明，避免「协作版」破坏既有安全链；
2. **权威层级 + CoCert**：首个把共享自主的「谁负责」写成可退化、可证书、无权威真空的层级结构；
3. **无扰动接管协议**：50Hz 下接管/交还的残差与延迟上界，并覆盖通信中断；
4. **信任/意图的可逆校准**：把 over-/under-trust 转成权威层级的可归因调整，实验 E513–E532 全覆盖。

## 5. 本轮最大风险

**一句话**：UniBot 的统一体投影依赖「对人类策略 π_h 的可观测近似」，一旦真实人类行为落在建模分布之外，信任估计与权威分配会共同漂移，可能在证书全部有效的情况下把控制权交给一个被系统性高估的人——形成「形式上可证明、协作上已错位」的隐性失效。

## 2. 形式化定义（要点）

**定义 521（UniBot 统一体投影）**
统一体为
```
U = (S, A_r, A_h, f, π_r, π_h, O_r, O_h)
s_{t+1} = f(s_t, a_t, u_t),  a_t ~ π_r(·|o_r^t),  u_t ~ π_h(·|o_h^t)
```
其中 `λ_t ∈ {0,1}` 表示人类通道是否在场。投影定义为
```
U|¬h : λ_t ≡ 0,  u_t ≡ ⊥,  π_h := ⊥
```
**等价判据**：同随机种子与同 `ι` 序列下，`∀t, s_t(U|¬h) = s_t(MetricVoiceGauge)`。

**定义 522（权威层级闭合 AuthorityLadder）**
```
A_i ∈ {A₀, A₁, A₂, A₃}
τ_Ai = (trust_lo_i, risk_hi_i, cg_lo_i),  且阈值嵌套：
trust_lo₀ ≤ ... ≤ trust_lo₃,  risk_hi₀ ≥ ... ≥ risk_hi₃,  cg_lo₀ ≤ ... ≤ cg_lo₃
authority(s) = max{ i : CI_lo(θ̂_h) ≥ trust_lo_i
                        ∧ risk(s) ≤ risk_hi_i
                        ∧ cg(s) ≥ cg_lo_i }
```
恒有 `A₀` 可用（`trust_lo₀=0, risk_hi₀=+∞, cg_lo₀=0`），故授权非空。退化：
```
δ_A(A_i) = A₀  ⇔  ¬(CI_lo(θ̂_h) ≥ trust_lo_i ∧ risk(s) ≤ risk_hi_i ∧ cg(s) ≥ cg_lo_i)
```
**闭合性**：任一周期结束时必须存在恰好一个有效 `CoCert`，否则本周期动作被取消并回 `A₀`。

**定义 523（CoCert 协作证书）**
```
CoCert = (i, θ̂_h, CI_δ(θ̂_h), CG, κ_cur, owner, t_expire, δ_A)
valid(CoCert) ⇔ CI_lo(θ̂_h) ≥ trust_lo_i
              ∧ risk(s) ≤ risk_hi_i
              ∧ cg(s) ≥ cg_lo_i
              ∧ now ≤ t_expire
              ∧ M₀(s) 成立
```
`owner ∈ {robot, human, shared}` 由层级唯一确定（A₀/A₁→robot，A₂→shared，A₃→human）。

**定义 524（TrustCalibrator 信任校准）**
以 Beta 后验维护人类可靠性：
```
α_{t+1} = α_t + 1[outcome_h(t) = ok]
β_{t+1} = β_t + 1[outcome_h(t) = bad]
θ̂_h(t) = α_t / (α_t + β_t)
CI_δ(θ̂_h) = [q_{δ/2}(Beta(α_t,β_t)), q_{1-δ/2}(Beta(α_t,β_t))]
```
**风险钳制（防 over-trust）**：即便 `CI_lo` 很高，也强制
```
i* ≤ i_max(risk) = max{ i : risk(s) ≤ risk_hi_i }
```
即高信任只能在低风险区放开到 A₂/A₃；高风险区信任再高也止于 `i_max(risk)`。校准以 ECE 度量，异常时冻结后验。

**定义 525（IntentReconciler 意图协调）**
```
κ(ι_h, ι_r) = 1 - d_τ(ι_h, ι_r) / D_max
```
`d_τ` 为类型化编辑距离（工具集差、幅值差、目标差，各自按类型签名加权）。协调规则：
```
κ ≥ τ_agree        ⇒ ι* = merge(ι_h, ι_r)，授权至多 A₂
τ_clar ≤ κ < τ_agree ⇒ 限时一个控制周期发起澄清，期间维持当前权威
κ < τ_clar         ⇒ ι* = ι_r，权威钳到 ≤ A₁，并记录冲突归因
```
**关键**：协调器不得创造新约束；`ι*` 仍须通过第 6 轮的 VoiceCommandTyping 类型检查。

**定义 526（CommonGround 共同 ground）**
```
CG_t = (B_t, σ_t),  B_t ⊆ ℬ
b 被确认   ⇒ σ_t(b) ← min(1, σ_t(b) + γ)
b 被反驳   ⇒ σ_t(b) ← max(0, σ_t(b) - γ)
cg(s) = min_{b ∈ B_required} σ_t(b)
```
**闭合**：`cg(s) ≥ τ_cg` 且双方在同一周期内 ack，才允许进入 A₂/A₃；否则 `cg` 降低使 authority 自动回退。

**定义 527（HandoffProtocol 无扰动接管）**
```
HO = (t_take, t_return, ε_transfer)
安全条件：∀t ∈ [t_take, t_return], ∃ 有效 CoCert(t) ∧ M₀(s_t)
无扰动条件：||s(t_take) - s(t_take⁻)||_Σ ≤ ε_transfer
          ∧ ||s(t_return) - s(t_return⁻)||_Σ ≤ ε_transfer
通信中断：若 t 时刻起 T_ack 内无人类 ack，则在 1 个控制周期内回 A₀，
          并利用第 6 轮 +20ms 预测窗口维持 M₀。
```

**定义 528（UniGauge 主闭环）**
每周期执行顺序：
```
1. 人类通道采样 H（λ, u, o_h）
2. 若 λ=0 或静默 > T_silence ⇒ 返回 MetricVoiceGauge（U|¬h）
3. TrustCalibrator 更新 θ̂_h 与 CI
4. IntentReconciler 计算 κ，得到 ι*
5. AuthorityLadder 依据 (CI_lo, risk, cg) 计算 authority
6. 生成 CoCert；若无效 ⇒ A₀ + MetricVoiceGauge 兜底
7. HandoffProtocol 执行接管/交还（若触发）
8. 调 metricvoicegauge_rtdi(ι*) 执行联合周期
9. 归因协作结果 ⇒ Δ_A ⇒ 下一周期阈值微调
10. 断言：∃ 有效 CoCert ∧ M₀ 成立；否则本周期动作作废
```

```python
# IP-347 UniBot 统一体投影
class UniBotModel:
    def __init__(self, f, pi_r, pi_h, T_silence=0.5):
        self.f, self.pi_r, self.pi_h = f, pi_r, pi_h
        self.T_silence = T_silence
        self.last_human_t = -1e9

    def human_present(self, lam, now):
        if lam:
            self.last_human_t = now
        return (now - self.last_human_t) <= self.T_silence

    def step(self, s, iota, human_action, now):
        if not self.human_present(human_action is not None, now):
            # U|¬h：严格退回 MetricVoiceGauge
            return metricvoicegauge_rtdi(self.base, s, self.obs,
                                         audio_stream=None, ell=iota)
        a = self.pi_r(s, iota)
        u = human_action if human_action is not None else BOT
        return self.f(s, a, u)

# IP-348 AuthorityLadder
class AuthorityLadder:
    def __init__(self, trust_lo, risk_hi, cg_lo):
        self.trust_lo, self.risk_hi, self.cg_lo = trust_lo, risk_hi, cg_lo

    def authority(self, ci_lo, risk, cg):
        best = 0  # A₀ 恒可用
        for i in range(4):
            if ci_lo >= self.trust_lo[i] and risk <= self.risk_hi[i] \
               and cg >= self.cg_lo[i]:
                best = i
        return best

    def degrade(self, i, ci_lo, risk, cg):
        ok = (ci_lo >= self.trust_lo[i] and risk <= self.risk_hi[i]
              and cg >= self.cg_lo[i])
        return i if ok else 0

# IP-349 TrustCalibrator
class TrustCalibrator:
    def __init__(self, alpha=1.0, beta=1.0, delta=0.1):
        self.a, self.b, self.delta = alpha, beta, delta

    def update(self, outcome_ok):
        if outcome_ok:
            self.a += 1.0
        else:
            self.b += 1.0

    def mean(self):
        return self.a / (self.a + self.b)

    def ci_lower(self):
        # Beta 后验下界（可用 scipy.stats.beta.ppf 或 Wilson 近似）
        return beta_ppf(self.delta / 2, self.a, self.b)

# IP-350 IntentReconciler
class IntentReconciler:
    def __init__(self, tau_agree=0.8, tau_clar=0.5):
        self.tau_agree, self.tau_clar = tau_agree, tau_clar

    def kappa(self, iota_h, iota_r):
        return 1.0 - typed_edit_distance(iota_h, iota_r) / self.D_max

    def reconcile(self, iota_h, iota_r):
        k = self.kappa(iota_h, iota_r)
        if k >= self.tau_agree:
            return merge_typed(iota_h, iota_r), k, "agree"
        if k >= self.tau_clar:
            return iota_r, k, "clarify"     # 限时一周期
        return iota_r, k, "conflict"        # 权威钳到 ≤ A₁

# IP-351 CommonGround
class CommonGround:
    def __init__(self, tau_cg=0.9, gamma=0.1):
        self.B, self.sigma = {}, {}
        self.tau_cg, self.gamma = tau_cg, gamma

    def update(self, belief, confirmed):
        s = self.sigma.get(belief, 0.0)
        self.sigma[belief] = min(1.0, s + self.gamma) if confirmed \
                             else max(0.0, s - self.gamma)

    def cg(self, required):
        return min((self.sigma.get(b, 0.0) for b in required), default=0.0)

# IP-352 HandoffProtocol
class HandoffProtocol:
    def __init__(self, eps_transfer=1e-3, T_ack=0.2):
        self.eps_transfer, self.T_ack = eps_transfer, T_ack

    def takeover(self, s, i, cert, now):
        if not cert.valid(now):
            return 0, s                      # 禁止接管，回 A₀
        if sigma_norm(s - self.last_s) > self.eps_transfer:
            return 0, self.last_s            # 残差超界，拒绝无扰动切换
        return i, s

    def on_comm_loss(self, now):
        return 0 if (now - self.last_ack) > self.T_ack else None

# IP-354 UniGauge 主闭环
def unigauge_round(M, s, obs, human, now):
    if not M.ubot.human_present(human.lam, now):
        return MetricVoiceGauge_round(M.base, obs, None, None, None, None)

    M.trust.update(human.outcome_ok)
    ci_lo = M.trust.ci_lower()
    iota_h, iota_r = human.iota, M.base.default_iota
    iota, kappa, mode = M.reconciler.reconcile(iota_h, iota_r)
    i = M.auth.authority(ci_lo, M.risk(s), M.cg.cg(M.required))
    i = min(i, M.auth.i_max(M.risk(s)))          # 风险钳制
    if mode == "conflict":
        i = min(i, 1)                            # 冲突 ⇒ ≤ A₁

    cert = CoCert(i, M.trust.mean(), ci_lo, M.cg, kappa, owner_of(i),
                  now + M.cert_ttl, M.auth.degrade)
    if not cert.valid(now):
        cert, i = CoCert(0, M.trust.mean(), ci_lo, M.cg, kappa,
                         "robot", now + M.cert_ttl, M.auth.degrade), 0

    if human.wants_takeover:
        i, s = M.handoff.takeover(s, i, cert, now)

    C, sc, claims, metrics, rewards = \
        metricvoicegauge_rtdi(M.base, s, obs, audio_stream=None, ell=iota)

    ΔA = attribute_collaboration(cert, C, metrics)   # 三类归因
    M.auth.adjust(ΔA)                                # 可逆校准
    assert cert.valid(now) and M0_holds(s)           # 硬断言
    return C, cert, claims, metrics, rewards
```

## 4. 推导

**引理 73（统一体投影等价）** 若 `λ_t ≡ 0`（或静默超过 `T_silence`），则 `U|¬h` 与 MetricVoiceGauge 在同随机种子、同 `ι` 序列下逐周期状态相等。
证明：投影令 `u_t ≡ ⊥` 且 `π_h := ⊥`，共享动力学退化为 `s_{t+1}=f(s_t, a_t)`；而 `a_t ~ π_r(·|o_r^t)` 与 MetricVoiceGauge 所用机器人策略相同，对 `t` 归纳即得。∎

**引理 74（权威非真空与无缝切换）** 在定义 522–523 下，任一周期至少存在一个有效 CoCert；若 `A_i → A_j` 切换，则切换前后不存在无证书覆盖的时间区间。
证明：`A₀` 的判据恒真（`0, +∞, 0`），故授权集合非空。切换采用「先建新证书、后失效旧证书」的原子交换；`t_expire` 覆盖整个切换周期，故任意 `t` 均落在至少一个有效证书区间内。∎

**引理 75（权威的信任单调与风险反单调）** `authority(s)` 对 `CI_lo(θ̂_h)` 非减、对 `risk(s)` 非增；在风险钳制下，over-trust 不能把权威推过 `i_max(risk)`。
证明：阈值嵌套使满足集合随 `CI_lo` 增大而扩张、随 `risk` 增大而收缩；`i* = min(authority, i_max(risk))` 直接给出上界。∎

**引理 76（共同 ground 冲突可检测）** 若类型化指令表示有限（工具集、幅值、目标离散化），且每周期计算 `κ`，则任意语义冲突在 `cg ≥ τ_cg` 前提下必于一个周期内被检出（`κ < τ_agree`），不会静默发散。
证明：有限表示下 `d_τ` 可计算且对语义差异敏感；`cg` 闭合保证双方对 `B_required` 的置信不低于 `τ_cg`，故冲突只能体现为 `κ` 的下降，从而触发澄清或降权。∎

## 8. 本轮最大风险

**一句话**：UniBot 的统一体投影依赖「对人类策略 π_h 的可观测近似」，一旦真实人类行为落在建模分布之外，信任估计与权威分配会共同漂移，可能在证书全部有效的情况下把控制权交给一个被系统性高估的人——形成「形式上可证明、协作上已错位」的隐性失效。
