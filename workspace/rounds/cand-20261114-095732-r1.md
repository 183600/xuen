# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧」IP-253~263；灵感循环第 1 轮；本轮灵感：「深度学习」×「力矩控制」）

> R69 把不确定性拆成 aleatoric / epistemic，并给 epistemic 配了一张嘴：看、问、触。它自陈的最大风险是「问错，比不问更危险」——模态分布若不可信，系统会自信地追问一个幻影，或把人类的误导性回答盖上「已验证」的章。R70 认为 R69 漏掉了一个更基本的事实：**不是所有 epistemic 都该向人求证；很多歧义是物理可判的，而人类恰恰是最容易被投毒的那个 oracle。**
>
> 本轮两个灵感正好补上这个缺口：
> - **力矩控制**提供一种「受控的物理提问」：直接指令关节力矩/阻抗，力受限、可反向驱动、可测接触；推一下、掂一掂、敲一敲，就是一次低能量、可观测、可回退的实验。位置控制问「世界应该在哪」，力矩控制问「世界会怎么回应」。
> - **深度学习**既是假设生成器（R69 的流策略）也是接触响应预测器，但它同时是**错误的机器**：会幻觉模态、会在分布外过度自信。所以本轮的分工是——**深度学习负责提出假设，力矩负责证伪假设**。
>
> 核心命题：在「被动观察」与「问人」之间插入一个**物理 oracle 层**——判别性力矩探针。用「每单位风险的信息增益」在 被动 / 探针 / 问人 三级 oracle 间仲裁；探针必须过力矩级安全证书，并承认一条新铁律：**信息不免费**——要分辨两个接触模态，必须注入足够能量，而能量可能超出物体与机器人可承受的不可逆预算。
>
> 命名 **TORQUE-RAS**（Torque-grounded Oracle-verified Uncertainty Resolution under Kinetic/Energy constraints）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**在问人之前，我能不能先用手轻轻试一下**」。

## 0. 直觉与动机

**灵感 1（深度学习 → 假设的机器，也是错误的机器）**
直觉：R69 用流匹配生成多模态假设，这本身就是深度学习。深度学习的强项是在歧义处给出多个「看起来合理」的假设；弱点是把训练分布的统计捷径当成世界的因果结构——它会在数据稀疏处幻觉出新模态，也会在分布外把错误假设说得非常自信。因此 R70 给深度学习安排两个角色：(a) 生成假设、预测接触响应；(b) 作为**被审计对象**，它的每一个假设都必须能被物理事实证伪。R69 把「模态是否可信」押在模态校准（ECE）上；R70 认为校准只能告诉你「模型知不知道自己不确定」，不能告诉你「模型是不是错了」——后者只能靠外部世界。

**灵感 2（力矩控制 → 一种受控的物理提问）**
直觉：位置控制把世界当成「应该到达的目标」，力矩控制把世界当成「会反作用的对象」。给定关节力矩 τ、阻抗 K_d、阻尼 D_d，机器人可以做一个低能量探针：轻推看它多硬、多重、会不会滑；轻敲听接触是否松动；短暂卸载看它是否被人托住。这些正是人类解决物理歧义的方式。力矩层的关键优势是**直接、可测、可限幅**：力/冲量/能量都能在指令层硬约束，接触响应 F_ext 直接可观测。它比语言回答更难被撒谎，但比语言回答更**不可逆**——推出去的动作可能把物体碰坏，收不回来。

**灵感 3（三级 oracle → 先物后人的仲裁，而不是固定流程）**
直觉：R69 的 oracle 只有「看/问」，本轮加入「探」。三个 oracle 各有不同的失败模式：被动观察便宜但信息少；力矩探针诚实但不可逆；人类回答灵活但可被投毒。固定「先探后问」或「先问后探」都不对。正确姿态是按**每单位风险的净信息增益**排序：在可逆、低能量、物理可分时先探；在不可逆、脆弱、或社会性歧义时先问或直接保守。探针不是问人的替代，而是问人的**前置过滤器**：能用一次轻触排除的幻影，就不要去打扰人，也不要把人的错误答案当真。

**灵感 4（不可逆性 → 信息不免费的硬约束）**
直觉：R69 的交互预算主要是「次数/位移/社交成本」，本质上是可逆的。力矩探针引入了一个新量纲：**不可逆性**。要分辨两个接触模态，必须让它们的响应差异被激发出来；激发差异需要冲量/能量；而冲量/能量有安全上限。于是存在一条**信息-安全前沿**：在给定安全预算下，最多只能消解「物理上分得开」的歧义。分不开的歧义，用更大力量去砸不是获取信息，而是在制造损害。这条约束比 R69 的 VoI 更硬，因为它不是「划不划算」，而是「能不能」。

**灵感 5（物理证据也要证书 → 防止「自信的轻推」）**
直觉：物理 oracle 不是天然可信。学习到的接触模型会在分布外胡说；环境也可能是主动的（有人托住物体、地面被移动），让接触响应「撒谎」；探针本身还可能是攻击载体（以试探为名执行危险动作）。所以物理证据必须带三样东西：力矩级安全证书（限幅/力锥/被动性/可回退）、接触模型的共形校准、以及继承 R69 的证据纪律（单次探针不得单独定案）。否则 R70 只是把 R69 的「会撒谎的嘴」换成了「会闯祸的手」。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（TORQUE-RAS 总览）** TORQUE-RAS = (TGP, LCD, CST, DTP, POB, OAO, TSC, RAS-WM†)。三不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **探针可采纳性**：每个力矩探针必须过 TSC（力矩/接触力/冲量/能量/被动性/摩擦锥），并保证探针后状态不越出「备份可控不变集」；不可逆代价必须计入成本；
(iii) **证据纪律**（继承 R69 定义 293-iii）：单次探针/单源回答不得单独定案，需与至少一个正交证据源一致，或信息增益超过高置信阈值；否则 U_epi 保持未消解。

**定义 311（力矩探针空间）** 关节力矩 τ ∈ ℝ^n；探针 g_τ = (τ_probe, K_d, D_d, T) ∈ 𝒯_probe，其中 τ_probe: [0,T]→ℝ^n 满足逐关节限幅 |τ_j| ≤ τ_max,j、冲量 |∫_0^T τ_j dt| ≤ J_max,j、注入能量 ∫_0^T |τ·q̇| dt ≤ E_max；K_d, D_d 为阻抗/导纳参数。响应 y = (q, q̇, τ, F_ext)。探针与任务动作拼成增广动作 ξ = (a, g_τ)。

**定义 312（学习接触动力学 LCD）** 集成模型 {f_φk}_{k=1}^K 在给定模态假设与探针下预测响应 y；用分裂共形（CQR）给出响应区间。模型认知不确定 U_model 取集成预测方差/区间宽度。LCD 只预测「若模态为 m，响应会是什么」，**不直接判定哪个模态为真**——证伪权留给实测。

**定义 313（接触特征与判别度）** 对模态 m，p(y|m,g_τ) 由 LCD 给出；实测 y。判别度 D_ij(g_τ) = D_KL(p(y|m_i,g_τ) ‖ p(y|m_j,g_τ))（或 Bhattacharyya 距离）。模态可辨识矩阵 K_ij = max_{g∈𝒯_probe, c(g)≤B} D_ij(g)。

**定义 314（力矩信息增益）** VoI_τ(g_τ) = H(M|o) − E_{y~p(y|o,g_τ)} H(M|o,y)。稳健版取集成下界 VoI_τ^LCB（5% 分位）。只有 VoI_τ^LCB > 0 的探针才可能值得执行。

**定义 315（探针成本与不可逆性）** c(g_τ) = λ_J J + λ_E E + λ_T T + λ_irr·Irr(g_τ) + λ_model·U_model。Irr 由探针后状态漂移 Δs 是否落在可逆集 𝒟_rev 决定；超出即高代价（塑性变形、掉落、损坏、暴露隐私）。

**定义 316（信息-安全前沿 / 信息不免费）** 在安全预算 (J_safe, E_safe) 下可达到的最大信息增益 ΔH_max(J_safe, E_safe) 随预算单调增；若消解当前歧义所需 J_min(ΔH) > J_safe 或 E_min(ΔH) > E_safe，则称该歧义**在本预算下物理不可解**，禁止探针，转问人或保守。曲线 ΔH_max 即信息-安全前沿。

**定义 317（三级 oracle 仲裁 OAO）** 候选 oracle O = {passive, torque, human}。选择 o* = argmax_{o∈O, admissible} [VoI_o^LCB − c_o]，其中 c_human 含社交成本与投毒期望损失 δ_p·L_wrong（R69 引理 18），c_torque 含不可逆代价。若全部 ≤ 0：不交互，退 R69（若问人仍有正收益）或 R68（纯保守）。顺序不是固定的「先物后人」，而是由边际净收益决定。

**定义 318（力矩安全证书 TSC）** 探针力矩经可采纳集投影 Π_𝒯：逐关节限幅、接触力锥、摩擦锥、能量/冲量上限、被动性 ∫τ·q̇ ≥ −E_store；并要求存在备份控制器 π_b，使探针后 T_rec 内回到受控不变安全集 B。任一不满足 ⇒ 探针作废，U_epi 视为未消解。

**定义 319（证伪感知后验 FCL）** 更新 w'_m ∝ w_m·L_m^robust(y|g_τ)，L_m^robust 用共形下界截断；若物理证据与高置信被动证据冲突，不更新，标记 anomaly（可能是主动环境欺骗或 LCD 分布外），走证据纪律。

**定义 320（探针状态漂移与可回退性）** Δs = s_after − s_before；可采纳要求 Δs ∈ 𝒟_rev 且备份恢复时间 ≤ T_rec。不可逆性不是二值，而是按「恢复到等价状态所需能量/时间」度量。

**定义 321（AIC-TORQUE 威胁模型）** ℰ_TORQUE = ℰ_FLUID × ℰ_contact × ℰ_probe：人类投毒（继承）；主动环境欺骗（有人托住/移动物体使接触响应撒谎）；LCD 分布外过度自信；探针诱发的损伤；「以探针为名」的危险动作。物理 oracle 不是天然可信，只是**不可被语言直接欺骗**。

**定义 322（可辨识图）** 以模态为点、K_ij ≥ τ_D 为边；连通分量内的模态物理可区分；孤立点/断开的歧义即「物理不可辨识」——此时再加力只会增加风险，不应把「探不出来」误判为「需要更用力」。

**定义 323（接触共形校准 MCG-T）** LCD 的区间覆盖率与条件覆盖误差；覆盖率 < τ_cov 或 OOD 分数 > τ_ood ⇒ 物理证据权重下调，禁止单独定案，退 R69/R68。这是 R69 定义 306（MCG）在物理通道上的镜像。

**定义 324（探针深度与信息缩放）** 第 k 次探针的边际比 ρ_k = ΔVoI_k / Δc_k；当 ρ_k < ρ_stop 时停止。信息随探针次数通常递减（类似 scaling law），而安全成本近似线性累加，故存在最优探针次数 k*。

**定义 325（证书 J_TORQUE）** J_TORQUE = (J_FLUID, probe_cert_hash, J_used/J_safe, E_used/E_safe, Δs_irr, D_min, conformal_coverage, oracle_sequence, evidence_consistency, torque_ver)。Valid ⇔ Valid(J_FLUID) ∧ TSC 通过 ∧ D_min ≥ τ_D ∧ 覆盖率达标 ∧ 证据纪律满足。

**定义 326（协议与严格包含）** 协议：R69 分解 → 若 U_epi 且非 slow_fault → 估计 K_ij 与 J_min → 若物理可解且探针可采纳 → 认证探针 → 证伪更新；否则若问人可采纳 → R69 的 MINT；否则 R68 兜底。探针预算为 0 或全不可采纳时，TORQUE-RAS 逐指令退化为 FLUID-RAS；所有 oracle 净收益 ≤ 0 时逐指令退化为 R68。

# IP-264/270 TGP + TSC：只生成「可认证」的力矩探针
def propose_and_certify_probe(modes, o, budget, lcd, tsc):
    best = None
    for g in probe_candidates(modes, budget):        # 方向/幅值/阻抗/时长
        if not budget.allow(g):          continue
        if not tsc.admissible(g, o):     continue    # 限幅/力锥/能量/被动/备份
        D = discriminability(modes, g, lcd)          # 定义 313
        if D < TAU_D:                    continue    # 物理分不开就别推
        voi = robust_voi(modes, g, lcd)              # 集成 5% 下界
        score = voi - probe_cost(g, o)               # 含不可逆性
        if best is None or score > best.score:
            best = (g, score, D)
    return best

# IP-267/268 DTP + POB：信息-安全前沿上的最优探针
def plan_probe(modes, o, budget):
    g = propose_and_certify_probe(modes, o, budget, M.lcd, M.tsc)
    if g is None: return None
    J_need = required_impulse(modes, TAU_EPI, M.lcd)  # 引理 19 反解
    if J_need > budget.J_safe: return None            # 信息不免费
    return g

# IP-266/271 CST + FCL：用实测响应证伪，不做单源定案
def falsify_update(modes, w, g, y, evidence, lcd):
    L = conformal_robust_likelihood(lcd, y, g, modes)  # 定义 319
    if conflicts_with_passive(y, evidence) or lcd.ood(y):
        return w, "anomaly"                            # 标记，不更新
    return normalize(w * L), "updated"

# IP-269 OAO：按净收益仲裁，不固定顺序
def arbitrate_oracles(modes, w, o, budget):
    cands = [
        ("passive", passive_voi_lcb(modes, o)),
        ("torque",  probe_voi_lcb(modes, o, budget)),
        ("human",   mint_voi_lcb(modes, o, budget)),

    return max((c for c in cands if admissible(c)), key=net_gain, default=None)

def TORQUE_RAS_round(M, obs):

## 3. 推导

**引理 19（探针可辨识性随冲量的缩放）** 局部线性接触下，设模态 m 的有效质量、刚度、阻尼为 (m_eff, k_eff, b_eff)，探针冲量 J 的响应差近似 Δy ≈ J·(h_i − h_j) + O(J²)，其中 h_m 为模态的响应核。若观测噪声方差 σ²，则 D_ij(g) ≈ (J²/(2σ²))·‖h_i − h_j‖²。要获得 KL 增益 ΔH，至少需 J_min(ΔH) = σ·√(2ΔH)/‖h_i − h_j‖。要点：**可辨识性由「响应核差异」决定，而不是由推得多猛决定；差异小时加力只是在制造风险，不是在获取信息。**

**引理 20（信息不免费 / 信息-安全前沿）** 结合定义 315–316：若 J_min(ΔH) > J_safe 或 E_min(ΔH) > E_safe，则任何达到该增益的探针都越界；此时最优可采纳策略的剩余后验熵下界为 H_min = H(M|o) − ΔH_max(J_safe, E_safe)。系：**安全的探针最多只能消解「物理上分得开」的歧义；分不开的歧义不要用更大力量去砸。**

**引理 21（不可逆性-可欺骗性的 oracle 权衡）** 探针的期望总代价为 c_τ + E[damage]，问人的期望总代价为 c_h + δ_p·L_wrong（R69 引理 18）。探针严格优于问人当且仅当 c_τ + E[damage] < c_h + δ_p·L_wrong 且探针可采纳；反之问人。物理 oracle 的优势在 δ_p（不易被语言欺骗），劣势在不可逆。系：**在可逆、低能量的接触歧义上先探后问；在不可逆、脆弱或社会性歧义上先问后探，或直接保守。**

**引理 22（幻影模态的物理证伪）** 设幻觉模态 m_h 由流模型产生但无物理支撑；则对任意可采纳探针，若 LCD 在该区域共形校准（覆盖率达标），实测响应的期望对数似然比满足 E[log(L*/L_h)] ≥ D_min > 0，故探针后 m_h 的后验质量以指数速率下降。反之若 LCD 未校准，可能把幻影「证实」。系：**R69 的幻影风险，只有在一个被校准的物理模型上才能被真正证伪；否则只是把幻觉从生成器转移到了接触模型。**

**定理 18（层级严格包含）** 在 A99–A103 下，TORQUE-RAS 的期望风险 ≤ FLUID-RAS ≤ R68；且当探针集合为空/全不可采纳时逐指令等于 FLUID-RAS；当所有 oracle 净收益 ≤ 0 时逐指令等于 R68。安全侧不让步；探针只在「可采纳且净收益 > 0」时启用。

**定理 19（探针安全与无突变）** 若探针过 TSC 且备份恢复时间 ≤ T_rec，则执行探针后系统仍在受控不变安全集内；探针失败/超时/物理证据冲突时 λ 单调不降地退回 R69/R68；力矩指令经 Π_𝒯 投影与阻抗混合，控制连续、无突变（继承 R68 定理 15、R69 定理 17）。

**A99–A103（假设）** A99：探针幅值内局部线性接触近似成立，误差有界；A100：观测噪声次高斯；A101：存在有界恢复时间的备份控制器；A102：LCD 在探针分布上共形校准；A103：模态响应核差异可估且非退化。

## 4. 推导

**引理 19（探针可辨识性随冲量的缩放）** 局部线性接触下 `Δy ≈ J·(h_i−h_j) + O(J²)`，故 `D_ij(g) ≈ (J²/(2σ²))‖h_i−h_j‖²`；要获得信息增益 `ΔH` 至少需 `J_min(ΔH)=σ√(2ΔH)/‖h_i−h_j‖`。系：**可辨识性由响应核差异决定，而不是由推得多猛决定；差异小时加力只制造风险。**

**引理 20（信息不免费 / 信息-安全前沿）** 若 `J_min(ΔH)>J_safe` 或 `E_min(ΔH)>E_safe`，任何达到该增益的探针都越界；最优可采纳策略的剩余后验熵下界为 `H_min=H(M|o)−ΔH_max(J_safe,E_safe)`。系：**安全的探针只能消解物理上分得开的歧义；分不开的歧义不要用更大力量去砸。**

**引理 21（不可逆性-可欺骗性的 oracle 权衡）** 探针代价 `c_τ+E[damage]`，问人代价 `c_h+δ_p·L_wrong`；探针优于问人当且仅当 `c_τ+E[damage] < c_h+δ_p·L_wrong` 且探针可采纳。系：**可逆、低能量的接触歧义先探后问；不可逆、脆弱或社会性歧义先问后探，或直接保守。**

**引理 22（幻影模态的物理证伪）** 若 LCD 在探针区域共形校准，则对无物理支撑的幻觉模态 `m_h`，`E[log(L*/L_h)] ≥ D_min>0`，其后验质量随探针指数下降。系：**R69 的幻影风险只有在被校准的物理模型上才能真证伪；否则只是把幻觉从生成器转移到接触模型。**

**定理 18（层级严格包含）** A99–A103 下，TORQUE-RAS 期望风险 ≤ FLUID-RAS ≤ R68；探针集合为空/全不可采纳时逐指令等于 FLUID-RAS；所有 oracle 净收益 ≤0 时逐指令等于 R68。

**定理 19（探针安全与无突变）** 探针过 TSC 且 `T_rec` 有界 ⇒ 探针后仍在受控不变安全集内；失败/超时/冲突时 `λ` 单调不降退回 R69/R68；力矩经 `Π_𝒯` 投影与阻抗混合，控制连续、无突变（继承 R68 定理 15、R69 定理 17）。

**A99–A103**：局部线性接触近似有界；噪声次高斯；备份控制器有界恢复；LCD 共形校准；响应核差异可估且非退化。

## 7. 本轮最大风险

**一句话**：TORQUE-RAS 把信息获取从「社交层」下移到「物理层」，但物理探针**不可逆**——用扭矩去「问」世界，问的代价可能是把世界碰坏；若学习到的接触模型在分布外过于自信，系统会用一次「自信的轻推」同时制造损害与错误证据——**碰错，比问错更不可逆。**

**次级风险与缓解**：LCD 分布外过度自信（集成 + 共形 + MCG-T 门控）；探针诱发损伤（TSC 硬约束 + 备份可控不变集 + 不可逆性成本）；主动环境欺骗（物理-被动证据冲突检测 + anomaly + 证据纪律）；「以探针为名」的危险动作（探针与任务动作共用 C-RAS-WM 认证）；不可逆性被低估（保守 𝒟_rev + E310 实测 + 不确定即放弃探针）。
