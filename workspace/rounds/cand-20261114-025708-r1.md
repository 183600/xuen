# 第 71 轮（承接第 70 轮「BELIEF-RAS」IP-264~274；灵感循环新循环第 3 轮；本轮灵感：「失败恢复」×「预测性维护」）

> R70 把 R69 的动作模态 epistemic 升级为世界状态后验 b_t(s)，并把「行为自洽」「人类回答」「标定残差」三路证据接进贝叶斯滤波。但 b_t(s) 有一个未被言明的前提：**系统在预测时域内是完好的、动力学是平稳的**。R70 没有「磨损」「老化」「剩余寿命」这些变量；它唯一与故障沾边的是 slow_fault_suspect——那是一个**探测器**，触发后唯一动作是退回 R68 变保守。于是 R70 面对故障只有一种姿态：**被吓一跳，然后刹车**。它既不能提前知道「还有多久会坏」，也不能在坏了之后给出「怎么退、退到哪、退完凭什么相信可以继续」。
>
> 本轮两个灵感正好补上时间轴与事后轴：
> - **预测性维护**把健康本身变成一个可滤波、可外推的状态 h_t：退化有动力学、受负载驱动、有剩余可用寿命 RUL 分布；维护从「坏了再修」变成「在 RUL 下界跌破前置时间之前排程」。
> - **失败恢复**把「坏了怎么办」从异常处理升级为一条**经过认证的恢复阶梯**：安全停 → 隔离/降级 → 恢复尝试 → 人工接管；每一级有进入条件、认证动作、验证谓词、回退关系与重试预算，并用活性监视器保证它一定终止。
>
> 核心命题：**把信念从 b_t(s) 升级为 b_t(s,h)（世界 × 健康），让预后（RUL）只用于「收紧安全下界 / 触发维护」，绝不用于「放宽」；让恢复成为一条可认证、可验证、可审计、且带健康记忆的阶梯。** 命名 **RESIL-RAS**（Reliability- and Remaining-life-aware Safe Interactive Loop，可靠性-剩余寿命感知的安全交互闭环）。
>
> 一句话定位：R68 问「我的测量还准吗」，R69 问「该向谁求证」，R70 问「世界是什么状态」，R71 问「**我还有多少时间；坏掉的那一刻谁来接住我，又凭什么相信真的接住了**」。

## 0. 直觉与动机

**灵感 1（预测性维护 → 健康是状态，不是事件）**
直觉：R68 的「缓变故障被标定吸收」之所以危险，是因为系统把一个**随时间演化的过程**当成了**某一时刻的异常**。预测性维护的根本转向是：磨损不是「t 时刻发生的事故」，而是「一直存在、可被观测、可被外推的状态」。于是把健康写进状态空间：h_t =（故障模式 m，连续退化量 z，负载/使用协变量 u）。退化有转移 p(h_{t+1}|h_t,a_t,u_t)，因此可以前向蒙特卡洛得到 RUL 分布。维护决策因此有了明确对象：不是「现在是否异常」，而是「按当前负载，RUL 的下界还够不够撑到下一次可维护窗口」。

**灵感 2（预测性维护的陷阱 → 单侧公理：预后只能收紧，不能放宽）**
直觉：一个能预测未来的模块最危险的用法，是拿未来为现在的冒险背书——「模型说轴承还有 200 小时，所以这次可以不停机、可以把 λ 调低」。一旦 RUL 模型在尾部乐观（而尾部恰恰数据最少），这个用法会把系统推向故障。因此本轮立一条公理：**预后的输出只能进入「收紧/触发」通道，不能进入「放宽」通道**。形式化即：健康增广后的可行动集合 A_RESIL(b) ⊆ A_BELIEF(b)，预后只能做过滤（删掉在某些可信健康状态下不安全的动作）与触发（维护/恢复），不能新增动作、不能降低 λ 下界。这条公理让新层严格包含旧层，而不是并列替代。

**灵感 3（失败恢复 → 恢复是一条阶梯，不是一个 catch 块）**
直觉：工业系统里最危险的代码是 `except: reset()`。失败恢复必须回答四个问题：**何时进入**（进入条件）、**做什么且凭什么安全**（认证动作）、**做完怎么证明真的好了**（验证谓词）、**如果没好怎么办**（回退与重试预算）。因此把恢复写成一个有限状态阶梯 r_0(安全停) → r_1(隔离/降级) → r_2(恢复尝试) → r_3(人工接管)，状态索引严格单调，失败只能向下一级转移。这样「活性」几乎是免费的：剩余阶梯数严格递减，最多 N 次失败必然吸收到安全态或人工接管。恢复的难点不在策略多聪明，而在**终止性、可验证性与不可自欺**。

**灵感 4（恢复的阴暗面 → 健康记忆与故障遮蔽）**
直觉：反复「重启就好了」会把退化证据一次次擦掉：任务状态被 reset，健康状态却被悄悄继承。于是系统看起来越来越会恢复，实际却在积累不可见的损伤。本轮的对策是**健康记忆**：健康状态与累积风险 H_t 在恢复时**不可重置**；恢复只能清任务态、不能清健康证据。恢复契约的「可以继续」判据必须是「故障模式在后验中被排除」而不是「任务又跑通了」。这把「恢复成功」从奖励信号降级为需要被证明的命题。

**灵感 5（诊断就是健康版的「问一句」 → VoI 的统一）**
直觉：R69 的信息动作是看/问/触，目标是消解世界状态歧义；预测性维护里的自检脉冲、受控激励、换视角观察、问操作员「最近有没有异响」，目标是消解**健康假设**歧义。二者在数学上是同一件事：选一个动作最大化对联合信念 b_t(s,h) 的信息增益。因此 MINT 不需要新机制，只需把 VoI 的目标从 b_t(s) 换成 b_t(s,h)，并新增诊断类候选动作。这也解释了为什么「主动诊断」必须过和任务动作一样的安全认证：探针脉冲本身可能诱发危险运动。

**灵感 6（新攻击面 → 伪故障、恢复循环、维护日志投毒）**
直觉：一旦系统会因为「预测到故障」而停机/维护/降级，攻击者就多了一个杠杆：制造伪故障把系统拖进安全停（**cry wolf = 拒绝服务**），或反复触发恢复让系统长期处于降级模式，或投毒维护日志让 RUL 模型相信设备「刚保养过」。更隐蔽的是**退化伪装**：让真实磨损表现为「可恢复的偶发故障」，诱导系统一次次恢复而不是停机检修。因此本轮必须交付 ℰ_RESIL 威胁模型、恢复 DoS 的可用性上界、以及健康证据的 k-源一致纪律。

## 1. 形式化定义（增量：定义 326–344）

**定义 326（RESIL-RAS 总览与四不变式）** RESIL-RAS = (HSE, RUL-Prog, PMS, RCL, NPD, MINT‡, FMG, VQAuditor-III, ℰ_RESIL, J_RESIL, BELIEF-RAS†)。四不变式：
(i) **实时流零学习写操作**（继承定义 277）；
(ii) **单侧预后**：预后/健康层只允许收缩可行动集合与提高 λ 下界，任何路径不得放宽（定义 332）；
(iii) **恢复认证与有界活性**：每一级恢复动作必须通过 C-RAS-WM 认证，阶梯索引单调、重试总预算有限（定义 334–336）；
(iv) **健康证据不可重置**：恢复只清任务态，健康后验与累积风险跨恢复保留（定义 338）。

**定义 327（健康状态空间）** h = (m, z, u)：故障模式 m ∈ {nominal, actuator_friction, sensor_bias_drift, bearing_wear, encoder_slip, thermal_drift, …}（|m| ≤ 16）；连续退化量 z ∈ ℝ^{d_h}（≥0，按模式分块）；负载/使用协变量 u ∈ ℝ^{d_u}（力矩、速度、温度、循环次数）。健康状态不进入动作空间，只进入信念与安全约束。

**定义 328（健康转移/退化模型）** p(h_{t+1}|h_t,a_t,u_t) = p(m_{t+1}|m_t) · p(z_{t+1}|z_t,a_t,u_t,m_t)，其中模式转移用稀疏马尔可夫链（多数质量在对角），连续退化用单调非减的受驱动随机过程 dz = f_m(z,u)dt + σ_m dW，且 f_m ≥ 0（磨损不可自发逆转）。**负载会加速退化**：u 越大 f_m 越大——这是「维护排程必须看任务计划」的物理根据。

**定义 329（健康增广信念 HAB）** b_t(s,h) = p(s,h | o_{1:t}, ξ_{1:t-1}, g_{1:t-1}, y_{1:t-1})。可因式分解近似 b_t(s,h) ≈ b_t^w(s|h) · b_t^h(h)，其中世界信念以健康为条件（例如关节摩擦大时，同一观测对应的位置后验更宽）。两者共享 R70 的三分解观测模型，健康通过「改变噪声/偏置/动力学参数」进入似然。

**定义 330（剩余可用寿命 RUL）** 给定 b_t^h，定义失效集 ℱ = {h : m ∈ ℳ_fail ∪ z ∉ 𝒵_safe}；RUL_t = inf{τ ≥ 0 : h_{t+τ} ∈ ℱ}。其分布由前向蒙特卡洛（定义 331 的实现）给出 p(RUL_t | b_t^h)。报告分位数、众数、以及**下界** LCB_q(RUL_t)（q 通常取 0.05–0.10）。

**定义 331（RUL 预测器 RUL-Prog）** 前向 rollout：对 b_t^h 采样 N_p 条健康轨迹，每条按定义 328 在给定任务负载计划 û_{t:t+H}（由当前策略的未来动作预算近似）下演化，首次命中 ℱ 的时间即 RUL 样本。为控制成本，健康预测在**慢时间尺度**运行（周期 T_health，默认 200 ms），快环只读取缓存分位数。

**定义 332（单侧预后公理）** 设 A_BELIEF(b) 为 BELIEF 层认证的可行动集合。给定健康可信集 H_{1−α}(b) = {h : b^h(h) ≥ 分位阈值}，定义
A_RESIL(b) = { a ∈ A_BELIEF(b) : ∀ h ∈ H_{1−α}(b), Safe(a,h) }。
要求 A_RESIL(b) ⊆ A_BELIEF(b)，且 λ_floor^RESIL = max(λ_floor^BELIEF, λ_floor(z_worst)) ≥ λ_floor^BELIEF。**预后只许删动作、只许抬 λ，任何「RUL 充足 ⇒ 放宽」的实现都判为违规**（由 J_RESIL 与审计器检查）。

**定义 333（预测性维护调度 PMS）** 决策变量为维护时刻 τ（及维护类型），目标：
min_τ E[ C_mission(t,τ) + C_downtime(τ) + C_fail·1{RUL ≤ τ} ]
s.t. P(RUL_t ≤ τ + T_maintenance + margin) ≤ δ, τ ∈ 可用维护窗口, 成本预算 ≤ B_m。
在单调退化、维护窗口周期性、成本线性化的假设下，最优策略是**阈值策略**：当 LCB_q(RUL) ≤ T_lead(τ) 时触发（T_lead = T_maintenance + margin + 调度延迟）。多设备/多部件时是带约束的递减边际收益排程，用贪心 + LCB 即可。

**定义 334（恢复阶梯 RCL）** 阶梯 R = (r_0,…,r_L)，默认 L=4：
r_0 安全停（进入：任何认证失败的即时兜底）；r_1 隔离/降级（冻结故障子系统，切冗余/受限模式）；r_2 恢复尝试（重定位、重置任务态、重夹、模型回滚）；r_3 人工接管（请求操作员，给出结构化诊断摘要）；r_4 受控停机/返修。
每级 r_i = (E_i, α_i, V_i, β_i, b_i)：进入谓词 E_i ⊆ 2^{b_t}、经认证的动作 α_i ∈ A_RESIL、验证谓词 V_i（需连续 k 次成立）、回退映射 β_i，以及重试预算 b_i（次数与时间）。

**定义 335（恢复契约）** 「可以恢复自主」是一个需被证明的命题，而非默认状态：
Resume ⇔ V_i 连续 k 次成立 ∧ b_t^h(m_fail) ≤ θ_clear ∧ NPD 未报警 ∧ 无新增故障模式 ∧ J_RESIL 子证书有效。
特别地，**任务重新跑通不算数**；必须由健康后验显式排除故障模式（或将其风险降到可接受阈值以下），否则停在降级/人工接管。

**定义 336（无进展检测与活性监视 NPD）** 在窗口 W 内，若任务进度增量 Δprog < δ_prog 且恢复次数 ≥ c_r，则跳过剩余尝试直接升级到 r_3；若任何一级的停留时间 > T_i 或重试超 b_i，则强制 β_i。活性由**索引单调**保证：失败只允许 i → i+1，禁止同层无限重试与回跳。

**定义 337（健康感知 VoI）** 把定义 317 的 VoI 目标替换为联合信念：
VoI(g) = H[b_t(s,h)] − E_{y∼p(·|g,b)}[ H[b_{t+1}(s,h|y)] ]，
候选信息动作新增诊断类 g_diag ∈ {self_test_pulse, controlled_excitation, extra_inspection, ask_operator}。子模性仍在（A100′：诊断观测条件独立于任务观测给定 h），贪心 (1−1/e)。诊断动作与任务动作共用 C-RAS-WM 认证，激励幅度受安全包络约束。

**定义 338（故障遮蔽防护 FMG）** 健康记忆：累积风险 H_t = Σ_{τ≤t} c(r_res, Δa, load) 单调非减，且**在恢复时不被清零**。恢复动作对 b_t^h 只允许「按观测更新」，不允许「按成功重置」。若某故障模式在多次恢复后仍反复出现，则其后验 hazard 必须单调累积并触发升级，而不是被「恢复成功」稀释。判据：Masking = 1 若恢复成功次数上升而 H_t 仍上升且 m_fail 后验未降。

**定义 339（恢复动作认证）** 每一级 α_i 必须通过 C-RAS-WM 前缀认证，且额外满足恢复约束：不得把系统带入比当前更差的健康可达集（h-next 的失效概率不得高于进入时 + ε）、不得越力/位/时间包络、不得在人机共存区执行高速复位。认证失败 ⇒ 直接 β_i，不允许「先试试看」。

**定义 340（威胁模型 ℰ_RESIL）** ℰ_RESIL = ℰ_BELIEF × ℰ_degrad × ℰ_recovery：退化加速/负载投毒、伪故障诱导安全停（cry wolf）、恢复循环占用、维护日志投毒（伪装已保养）、退化伪装成偶发可恢复故障、以及「用恢复成功掩盖健康恶化」。并入 AIC，对抗训练与审计共用。

**定义 341（证书 J_RESIL）** J_RESIL = (J_BELIEF, ECE_RUL, RUL_LCB_coverage, maintenance_schedule_hash, ladder_invocations, resume_certificates, masking_flags, H_t_trajectory, dos_audit, resil_ver)。Valid ⇔ Valid(J_BELIEF) ∧ ECE_RUL ≤ τ_RUL ∧ 单侧公理未违反 ∧ 每次 Resume 都有对应证书 ∧ 健康记忆连续。

**定义 342（参与式审计 VQAuditor-III）** 新增审计：维护是否被推迟到 LCB 之下、恢复是否只是任务级 reset、Resume 是否缺少健康证据、恢复是否被伪故障驱动、健康记忆是否被异常清零。结论回灌，成为 PMS 与 RCL 的先验/成本。

**定义 343（双时间尺度预算）** 快环（控制，≤6.2 ms）只读健康分位数缓存、跑阶梯触发与认证；慢环（健康，200 ms 级）跑 HSE 更新与 RUL rollout。规定：快环不得同步等待 rollout；缓存过期 > T_stale 时按「最坏健康」保守处理（单侧公理的自然推论）。

**定义 344（基线协议 v2）** 在 RAS-Baselines v1 之上固定 5 个维护/恢复基线：Run-to-Failure、Periodic Maintenance、Mean-RUL Threshold、Reactive Recovery（异常才恢复）、Always-Safe-Stop；固定退化生成器、维护成本模型、10 种子、配对检验与报告模板。

# IP-275 HSE：健康状态估计（与 R70 BSE 并列的小滤波器）
class HealthStateEstimator:
    def __init__(self, modes, N=64, hazard_fn=None):
        self.modes, self.N = modes, N
        self.hazard = hazard_fn            # 累积风险，跨恢复保留

    def step(self, b_h_prev, o, a, u, r_res, a_flow):
        # 模式边缘：稀疏马尔可夫 + 观测似然（残差/流似然/负载）
        m_post = update_modes(b_h_prev, o, a, u, r_res, a_flow)
        # 连续退化：受驱动单调粒子（定义 328）
        z_particles = propagate_monotone(b_h_prev.z, a, u, modes=m_post)
        z_particles = reweight(z_particles, o, r_res, a_flow)
        # 健康记忆：只增不减，恢复不清零（定义 338）
        self.hazard = self.hazard + inc_hazard(r_res, a_flow, load=u)
        return HealthBelief(m_post, z_particles, self.hazard)

# IP-276 RUL-Prog：慢环前向 rollout，只给分位数与下界
def rul_distribution(b_h, load_plan, N_p=128, horizon=10_000):
    ruls = []
    for _ in range(N_p):
        h = sample(b_h)
        for t in range(horizon):
            h = transition(h, load_plan(t))        # 定义 328
            if in_failure_set(h):                   # 定义 330
                ruls.append(t); break
        else:
            ruls.append(float('inf'))
    return RULStats(q05=quantile(ruls, .05), median=median(ruls),
                    q95=quantile(ruls, .95), coverage=calibration(b_h))

# IP-277 PMS：约束阈值维护调度（只收紧，不放宽）
def schedule_maintenance(b_h, stats, windows, cost, delta):
    # 用 RUL 下界，而不是均值：乐观尾部在这里被结构性排除
    if stats.q05 <= windows.next_lead + cost.T_maint + cost.margin:
        tau = select_window(windows, before=stats.q05)
        if cost_of(tau) <= cost.B_m and P_fail_before(tau) <= delta:
            return Maintenance(tau, kind=worst_mode(b_h))
    return None

# IP-278 RCL：认证恢复阶梯（索引单调 + 验证 + 回退 + 预算）
class RecoveryLadder:
    RUNGS = ['safe_stop', 'isolate_degrade', 'recover_attempt',
             'human_handoff', 'controlled_shutdown']

    def step(self, b, state):
        while state.i < len(self.RUNGS):
            r = self.RUNGS[state.i]
            if not enter(r, b):                 # 定义 334
                state.i += 1; continue
            if state.retries[r] >= budget(r):    # 同层重试有界
                state.i += 1; continue
            act = certified_recovery_action(r, b)       # 定义 339
            if act is None:                     # 认证失败：不试，直接回退
                state.i += 1; continue
            execute(act); state.retries[r] += 1
            if verified(r, b, k_consecutive=3): # 定义 335
                return 'resume_with_certificate' if r == 'recover_attempt' \
                       else 'degraded_continue'
            state.i += 1                         # 失败只许向下，绝不回跳
        return 'absorbed_safe_state'

# IP-279 NPD：无进展检测（防止恢复循环伪装成高可用）
def no_progress(window_trace, delta_prog=0.01, c_r=2):
    return progress(window_trace) < delta_prog and recovery_count(window_trace) >= c_r

# IP-280 MINT‡：健康感知 VoI（诊断动作 = 健康版的「问一句」）
def choose_info_action(b_sh, candidates, budget, c_ras_wm):
    best = None
    for g in candidates:                        # 含 self_test/excitation/inspect/ask
        if not budget.allow(g) or not c_ras_wm.certify_info(g, b_sh): continue
        voi = entropy(b_sh) - expected_entropy_after(b_sh, g)
        s   = voi - cost(g)
        if best is None or s > best.score: best = (g, s)
    return best if best and best.score > 0 else None

# IP-281 FMG：故障遮蔽防护
def masking_alert(history):
    return (trend(history.resume_success) > 0 and
            trend(history.hazard) > 0 and
            posterior_fail_mode(history) > theta_mode)

# IP-286 RESIL-RAS 主闭环（快慢双环；单侧预后；恢复阶梯）
def RESIL_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    # ---- 快环：世界信念（R70） ----
    b_s = M.bse.step(M.b_prev_s, o, M.last_action, M.last_g, M.last_y)
    # ---- 慢环缓存：健康与 RUL（异步，绝不同步阻塞快环） ----
    if M.health_due():
        b_h = M.hse.step(M.b_prev_h, o, M.last_action, M.last_u,
                         M.last_r_res, M.last_a_flow)
        stats = M.rul.run(b_h, M.load_plan())
        M.cache.put(b_h, stats)
    b_h, stats = M.cache.get_or_worst()        # 过期按最坏健康处理（定义 343）
    # ---- 单侧预后：只过滤、只抬 λ（定义 332） ----
    A = M.ach.propose(x_prime, H=M.vista.H)
    A = [a for a in A if safe_under_health(a, b_h)]     # 只删不加
    lam = max(M.efs.risk_scale(...), lam_floor(health_worst(b_h)))  # 只抬不降

    # ---- 维护触发（慢决策，只收紧） ----
    maint = M.pms.schedule(b_h, stats, M.windows, M.cost, delta=M.delta)
    if maint is not None: M.plan_maintenance(maint)     # 不改本轮控制，只登记

    # ---- 恢复阶梯（仅在故障/活性异常时进入） ----
    if failure_entered(b_s, b_h, M.last_a_flow, M.last_r_res):
        outcome = M.rcl.step(b_t=(b_s, b_h), state=M.recovery_state)
        if outcome == 'resume_with_certificate':
            b_h = M.hse.step(b_h, o, M.last_action, M.last_u,
                             M.last_r_res, M.last_a_flow)   # 恢复不重置健康
        else:
            return outcome                                   # 吸收安全态
    # ---- 健康感知交互（诊断/消歧共用 VoI） ----
    g = M.mint.choose_info_action((b_s, b_h), M.info_candidates(b_h),
                                  M.budget, M.c_ras_wm) \
        if entropy(b_s) + entropy(b_h) > TAU_JOINT else None
    if g is not None:
        y = M.cia.execute(g); b_s = M.bse.step(b_s, o, M.last_action, g, y)
    # ---- 世界侧风险缩放（R69/R70 原路径，不因预后而放宽） ----
    mode = select_mode_from_belief(M.modes, b_s, lam)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    tau = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    # ---- 审计 + 证书 + 健康记忆落盘 ----
    M.vqa_iii.submit_async(b_s, b_h, stats, g, outcome if 'outcome' in dir() else None)
    M.jres.emit(...)
    M.b_prev_s, M.b_prev_h, M.last_u = b_s, b_h, current_load(o)
    return k, lam, mode, (b_h, stats)

## 3. 推导

**引理 23（单侧预后 ⇒ 安全单调）** 若实现满足定义 332（A_RESIL ⊆ A_BELIEF 且 λ_floor^RESIL ≥ λ_floor^BELIEF），则对任意 b 与任意决策步，RESIL 的执行动作在「最坏可信健康」下的风险 ≤ BELIEF 在同一世界信念下的风险；且当健康后验为名义（m=nominal，z 在安全集内）且 RUL 下界 > 时域时，二者逐指令相同。要点：健康层只是**在可行动集合上求交、在 λ 上取 max**；集合运算与 max 都单调，故不引入新风险。

**引理 24（RUL-LCB 触发的失效概率上界）** 设 RUL 预测分布经校准（定义 341 的 ECE_RUL ≤ ε），触发规则为 LCB_q(RUL) ≤ T_lead。则在预测器校准良好的区域内 P(实际失效早于维护完成) ≤ (1−q) + ε + P(运行工况漂出处可校准域)。系：**用下界而不只是均值**，把乐观尾部从决策中结构性剔除；但该保证只在可校准域成立，OOD 时必须退化到最保守维护（下一条风险）。

**引理 25（健康记忆 ⇒ 无故障遮蔽）** 若 H_t 单调非减且恢复不清零，且 Resume 需要 m_fail 后验 ≤ θ_clear，则任意有限次「恢复成功」都不降低后续触发维护的概率下界：P(升级 | 恢复 n 次) ≥ P(升级 | 恢复 0 次)。要点：恢复只更新任务态，不提供「健康变好」的似然，故不会稀释 hazard；这把「重启大法」从可用手段里移除。

**引理 26（恢复阶梯终止性）** 阶梯索引严格单调、每级重试预算有限、每次失败只允许 i→i+1，则任何执行路径在至多 Σ_i (b_i+1) ≤ B 步内到达吸收态（安全停或人工接管），不会出现同层无限循环或回跳；若 NPD 在窗口 W 内触发，终止步数进一步有上界 W + B。系：活性不依赖策略多聪明，只依赖**拓扑**（DAG + 有界重试）。

**引理 27（恢复 DoS 可用性上界）** 设伪故障到达率 λ_f，单次进入阶梯的平均占用 T_r，维护/安全停平均占用 T_s，则可用性 ≥ 1 − λ_f·(π_r T_r + π_s T_s)，其中 π_r,π_s 为阶梯各级稳态占比，且由引理 26 有界。审计若发现触发与外部扰动相关（可检测的共谋），升级为对抗模式并收紧触发阈值——**但收紧本身受「不得因伪故障而降低任务安全」约束**。

**引理 28（诊断 VoI 的可分解性）** 在 A100′（给定 h 时诊断观测与任务观测条件独立）下，联合 VoI 可分解为世界项与健康项之和：VoI(g) = VoI_s(g) + VoI_h(g) + I(s;h)，第三项是耦合项。故诊断动作只在该项（健康歧义）显著时被选中；当世界歧义大而健康歧义小时，MINT‡ 自动退回 R69/R70 的消歧动作。这解释了「预测性维护的自检」与「交互式消歧的追问」为何能共用一套控制器。

**定理 20（RESIL 严格包含 BELIEF 严格包含 FLUID 严格包含 R68）** 在 A99–A100′ 下，RESIL 的期望风险 ≤ BELIEF ≤ FLUID ≤ R68；当健康名义、RUL 下界充足、无恢复触发时，四者逐指令相同；当预后不确定/过期时，RESIL 退化为「按最坏健康收紧」的 BELIEF 特例。故安全侧层层不让步，效率侧只在**有认证的恢复/维护**上获得收益。

**定理 21（恢复安全与无突变）** 若每级 α_i 经定义 339 认证、Resume 需定义 335 证书、且阶梯索引单调，则恢复过程不会把系统带入比进入时更差的健康可达集，控制量在级间切换处连续（C-RAS-WM 前缀不变式），且最终吸收到安全态或人工接管；恢复失败/超时/被投毒时 λ 单调不降地退回最保守。系：**「恢复」不是「冒险」，而是「在安全包络内逐级收窄」**。

**定理 22（阈值维护策略的最优性）** 在退化单调、维护窗口周期、成本线性、失效不可逆的假设下，定义 333 的约束问题的最优策略是阈值策略，阈值为 T_lead 与 δ 的函数；多部件时边际收益递减 ⇒ 贪心 + RUL-LCB 达到 (1−1/e) 近似。系：预测性维护不需要复杂 RL 也能有可解释的最优性；RL 只在非平稳/多部件耦合时作为改进项。

## 6. 本轮最大风险

**一句话**：RESIL-RAS 把安全与效率的收益押在「健康状态可辨识、RUL 在尾部可信」上——而故障样本天然稀疏、非平稳、且**恰好在最需要它的尾部最少**；一旦 RUL 系统性高估，预测性维护就退化为**预测性自满**（把维护排得太晚），而恢复阶梯又会用「任务跑通了」制造高恢复成功率的假象，系统于是**越会恢复、积累的隐性损伤越多**。更糟的是，健康记忆只能防止「忘记坏过」，不能防止「从未见过这种坏法」——**恢复指标越漂亮，真实健康可能越差**。

| `A_RESIL(b) = {a ∈ A_BELIEF(b) : ∀h∈H_{1−α}, Safe(a,h)}` | 单侧收缩后的可行动集合 |
| `λ_floor^RESIL = max(λ_floor^BELIEF, λ_floor(z_worst))` | 只升不降的安全下界 |

## 2. 形式化定义（要点版）

**定义 326（总览与四不变式）** RESIL-RAS 继承 BELIEF 全部组件（† 升级），新增 HSE、RUL-Prog、PMS、RCL、NPD、FMG。四不变式：(i) 零学习写操作；(ii) 单侧预后（只收缩、只抬 λ）；(iii) 恢复认证 + 索引单调 + 有界重试；(iv) 健康证据不可重置。

**定义 327（健康状态空间）** h=(m,z,u)，|m|≤16，z∈ℝ^{d_h} 分块非负，u 为力矩/速度/温度/循环数等负载协变量。

**定义 328（健康转移）** p(h'|h,a,u)=p(m'|m)·p(z'|z,a,u,m)；dz=f_m(z,u)dt+σ_m dW，f_m≥0，且 ∂f_m/∂u ≥ 0。

**定义 329（健康增广信念）** b_t(s,h)=p(s,h|o_{1:t},ξ_{1:t-1},g_{1:t-1},y_{1:t-1})，近似因式分解；世界观测噪声/偏置/动力学参数以 h 为条件。

**定义 330（RUL）** ℱ = {m∈ℳ_fail} ∪ {z∉𝒵_safe}；RUL_t = inf{τ≥0: h_{t+τ}∈ℱ}；报告 q05/中位/q95 与覆盖率。

**定义 331（RUL-Prog）** 在慢环用 N_p=128 条健康轨迹，按任务负载计划 û 前向演化，首次命中 ℱ 即为样本；T_health=200ms，快环只读缓存分位数。

**定义 332（单侧预后公理）** A_RESIL(b)={a∈A_BELIEF(b):∀h∈H_{1−α}(b),Safe(a,h)}；要求 A_RESIL⊆A_BELIEF 且 λ_floor^RESIL≥λ_floor^BELIEF。**任何「RUL 充足 ⇒ 放宽 λ / 放大动作」的实现都判违规**。

**定义 333（预测性维护）** min_τ E[C_mission+C_downtime+C_fail·1{RUL≤τ}] s.t. P(RUL_t≤τ+T_maint+margin)≤δ。单调退化+线性成本下最优为阈值策略：LCB_q(RUL)≤T_lead(τ) 即触发。

**定义 334（恢复阶梯）** R=(r_0 安全停, r_1 隔离降级, r_2 恢复尝试, r_3 人工接管, r_4 受控停机)；每级 r_i=(E_i,α_i,V_i,β_i,b_i)。

**定义 335（恢复契约）** Resume ⇔ V_i 连续 k 次成立 ∧ b^h(m_fail)≤θ_clear ∧ ¬NPD ∧ 无新增故障模式 ∧ 子证书有效。**任务重新跑通不构成 Resume 证据**。

**定义 336（NPD 与活性）** 窗口 W 内 Δprog<δ_prog 且恢复次数≥c_r ⇒ 升级 r_3；超时/超预算强制 β_i；失败只许 i→i+1。

**定义 337（健康感知 VoI）** VoI(g)=H[b(s,h)]−E_y H[b(s,h|y)]；候选含诊断动作；子模性下贪心 (1−1/e)；诊断动作同过 C-RAS-WM。

**定义 338（健康记忆/FMG）** H_t 单调非减、恢复不清零；Masking=1 若 resume_success↑ ∧ H_t↑ ∧ m_fail 后验未降。

**定义 339（恢复动作认证）** α_i 过 C-RAS-WM；额外要求 h-next 失效概率不高于进入时 +ε、不越力/位/时间包络、人机共存区禁高速复位；认证失败直接 β_i。

**定义 340（威胁模型）** ℰ_RESIL=ℰ_BELIEF×ℰ_degrad×ℰ_recovery：退化/负载投毒、伪故障 cry-wolf、恢复循环占用、维护日志投毒、退化伪装为偶发可恢复故障、用恢复成功掩盖健康恶化。

**定义 341（证书）** J_RESIL 字段见上表；Valid ⇔ Valid(J_BELIEF) ∧ ECE_RUL≤τ_RUL ∧ 单侧公理未违反 ∧ 每次 Resume 有证书 ∧ 健康记忆连续。

**定义 342（VQAuditor-III）** 审维护拖延、任务级 reset 冒充恢复、Resume 缺健康证据、伪故障驱动、健康记忆被异常清零。

**定义 343（双时间尺度）** 快环 ≤6.5ms 只读缓存与触发；慢环 200ms 跑 HSE/RUL；缓存过期 >T_stale 按最坏健康处理。

**定义 344（基线协议 v2）** 5 基线 + 退化生成器 + 维护成本模型 + 固定种子/配对检验/报告模板。

# IP-275 HSE：模式边缘 + 受驱动单调退化 + 不可重置 hazard
class HealthStateEstimator:
    def __init__(self, modes, N=64, hazard_fn=inc_hazard):
        self.modes, self.N, self.hazard_fn = modes, N, hazard_fn
        self.hazard = 0.0

    def step(self, b_h, o, a, u, r_res, a_flow):
        m = update_modes(b_h.m, o, a, u, r_res, a_flow)      # 稀疏马尔可夫后验
        z = propagate_monotone(b_h.z, a, u, modes=m)          # dz=f_m(z,u)dt+σdW, f_m>=0
        z = reweight(z, o, r_res, a_flow, m)
        self.hazard += self.hazard_fn(r_res, a_flow, u)       # 只增；恢复不清零
        return HealthBelief(m, z, self.hazard)

# IP-276 RUL-Prog：慢环 rollout，只对外暴露分位数与下界
def rul_distribution(b_h, load_plan, N_p=128, horizon=10_000):
    ruls = []
    for _ in range(N_p):
        h = sample(b_h)
        for t in range(horizon):
            h = transition(h, load_plan(t))                   # 定义 328
            if h.m in FAIL_MODES or h.z not in Z_SAFE:        # 定义 330
                ruls.append(t); break
        else:
            ruls.append(float('inf'))
    return RULStats(q05=quantile(ruls,.05), median=median(ruls),
                    q95=quantile(ruls,.95),
                    coverage=empirical_coverage(ruls, b_h.calib))

# IP-277 PMS：阈值维护（只用 LCB，均值不参与触发）
def schedule_maintenance(b_h, stats, windows, cost, delta):
    lead = cost.T_maint + cost.margin + windows.next_delay
    if stats.q05 <= lead:
        tau = select_window(windows, before=stats.q05)
        if tau is not None and cost_of(tau) <= cost.B_m \
           and P_fail_before(tau, stats, delta) <= delta:
            return Maintenance(tau, kind=worst_mode(b_h))
    return None

# IP-278 RCL：索引单调的认证恢复阶梯
class RecoveryLadder:
    RUNGS = ['safe_stop', 'isolate_degrade', 'recover_attempt',
             'human_handoff', 'controlled_shutdown']

    def step(self, b, st):
        while st.i < len(self.RUNGS):
            r = self.RUNGS[st.i]
            if not enter(r, b):                 # E_i
                st.i += 1; continue
            if st.retries[r] >= budget(r):      # b_i 用尽
                st.i += 1; continue
            act = certified_recovery_action(r, b)   # IP-278 + 定义 339
            if act is None:
                st.i += 1; continue             # 认证失败不试
            execute(act); st.retries[r] += 1
            if verified(r, b, k=3):             # V_i
                cert = make_resume_certificate(b, r)
                return ('resume_with_certificate' if r == 'recover_attempt'
                        else 'degraded_continue', cert)
            st.i += 1                           # 失败只许向下
        return ('absorbed_safe_state', None)

# IP-279 NPD：无进展检测
def no_progress(trace, delta_prog=0.01, c_r=2):
    return progress(trace) < delta_prog and recovery_count(trace) >= c_r

# IP-280 MINT‡：联合信念上的 VoI，含诊断动作
def choose_info_action(b_sh, cands, budget, c_ras_wm):
    best = None
    for g in cands:
        if not budget.allow(g) or not c_ras_wm.certify_info(g, b_sh):
            continue
        voi = entropy(b_sh) - expected_entropy_after(b_sh, g)
        s = voi - cost(g)
        if best is None or s > best.score:
            best = (g, s)
    return best if best and best.score > 0 else None

# IP-281 FMG：故障遮蔽报警
def masking_alert(hist, theta_mode=0.6):
    return (trend(hist.resume_success) > 0 and trend(hist.hazard) > 0
            and posterior_fail_mode(hist) > theta_mode)

# IP-286 主闭环：快慢双环 + 单侧预后 + 恢复阶梯
def RESIL_RAS_round(M, obs):

    # 快环：世界信念（R70）

    # 慢环缓存：健康与 RUL（异步，快环绝不等待）

    b_h, stats = M.cache.get_or_worst()            # 过期按最坏健康（定义 343）
    # 单侧预后：只过滤、只抬 λ

         if safe_under_health(a, b_h)]
    lam = max(M.efs.risk_scale(...), lam_floor(health_worst(b_h)))
    # 维护触发（只登记，不改本轮控制）

        if outcome != 'resume_with_certificate':

        b_h = M.hse.step(b_h, o, M.last_action, M.last_u,
                         M.last_r_res, M.last_a_flow)   # 恢复不重置健康

    if g is not None:

    # 世界侧执行（不因预后而放宽）
    mode = select_mode_from_belief(M.modes, b_s, lam)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)

    # 审计 + 证书 + 健康记忆
    M.vqa_iii.submit_async(b_s, b_h, stats, g, outcome)
    M.jres.emit(...)

## 4. 推导

**引理 23（单侧预后 ⇒ 安全单调）** 若 A_RESIL⊆A_BELIEF 且 λ_floor^RESIL≥λ_floor^BELIEF，则 RESIL 在最坏可信健康下的风险 ≤ BELIEF 在同一世界信念下的风险；健康名义且 RUL 下界充足时二者逐指令相同。证明：可行动集合求交、λ 取 max，二者对风险均单调。

**引理 24（RUL-LCB 触发的失效上界）** 若 RUL 分布经校准（ECE_RUL≤ε），触发用 LCB_q，则在校准域内 P(失效早于维护完成) ≤ (1−q)+ε；OOD 时该界不成立，必须退化为最保守维护。系：下界把乐观尾部从决策中结构性剔除，但**校准域是这份保证的全部前提**。

**引理 25（健康记忆 ⇒ 无故障遮蔽）** H_t 单调非减且恢复不清零、Resume 需 m_fail 后验≤θ_clear ⇒ 有限次恢复成功不降低后续维护触发概率下界。证明：恢复只更新任务态，不产生「健康变好」的似然，hazard 不可被稀释。

**引理 26（恢复阶梯终止性）** 索引严格单调、每级预算有限、失败只 i→i+1 ⇒ 至多 Σ_i(b_i+1)≤B 步到达吸收态，无同层死循环、无回跳；NPD 触发时步数 ≤ W+B。系：活性来自拓扑（DAG+有界重试），不依赖策略智能。

**引理 27（恢复 DoS 可用性上界）** 伪故障到达率 λ_f、阶梯占用 T_r、安全停占用 T_s ⇒ 可用性 ≥ 1−λ_f(π_r T_r+π_s T_s)，且由引理 26 占用有界。审计发现触发与外部扰动相关时升级对抗模式，但收紧不得降低任务安全。

**引理 28（诊断 VoI 可分解）** 在 A100′（给定 h 时诊断观测与任务观测条件独立）下，VoI(g)=VoI_s(g)+VoI_h(g)+I(s;h)。健康歧义大时选诊断动作；世界歧义大时自动退回 R69/R70 消歧。系：自检与追问共用一套 VoI 控制器，不需要第二套机制。

**定理 20（四层严格包含）** A99–A100′ 下，RESIL ≤ BELIEF ≤ FLUID ≤ R68（期望风险）；健康名义、RUL 充足、无恢复触发时四者逐指令相同；预后不确定/过期时退化为「按最坏健康收紧」的 BELIEF 特例。

**定理 21（恢复安全与无突变）** 每级 α_i 经定义 339 认证、Resume 需定义 335 证书、索引单调 ⇒ 恢复不把系统带入更差的健康可达集，级间切换控制连续（C-RAS-WM 前缀不变式），最终吸收到安全态或人工接管；失败/超时/投毒时 λ 单调不降地退回最保守。

**定理 22（阈值维护最优性）** 单调退化 + 周期窗口 + 线性成本 + 不可逆失效下，定义 333 的最优策略是阈值策略（阈值由 T_lead 与 δ 决定）；多部件边际收益递减 ⇒ 贪心 + RUL-LCB 达 (1−1/e) 近似。

## 8. 本轮最大风险

**一句话**：RESIL-RAS 的全部收益押在「健康状态可辨识、且 RUL 在尾部可信」上——而故障样本天然稀疏、非平稳，**恰好在最需要它的尾部最少**；一旦 RUL 系统性高估，预测性维护就退化为**预测性自满**，恢复阶梯又用「任务跑通了」制造高恢复成功率的假象，于是系统**越会恢复、积累的隐性损伤越多**。健康记忆能防止「忘记坏过」，却防不了「从未见过这种坏法」——**恢复指标越漂亮，真实健康可能越差**。
