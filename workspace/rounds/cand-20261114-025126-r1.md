# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互消歧」IP-253~263；本轮灵感：「用户共创」×「技能组合」）

> R69 把人类从「被融合的模态」升级成「被询问的证人」：面对多峰歧义，系统会看、会问、会触，用一次信息动作把一个可约的 epistemic 消解掉。但这条交互协议仍隐含一个**单次、无署名、用完即弃**的假设——人只是回答「这一次」的问题，答案不留下、不积累、不署上是谁教的。现实协作恰好相反：用户交付的不是一次回答，而是**可复用的能力**——一段示范、一条偏好、一次纠正、一个新技能。能力一旦可复用，系统的问题就从「这一帧该选哪个模态」变成「**这个技能是谁教的、能不能和别的技能拼、拼坏了算谁的**」。
>
> 本轮两个灵感正好对应这两个跃迁：
> - **用户共创**把「询问」升级成「授权」：用户成为技能库的共同作者，其贡献带有来源、可被问责、可被校准；系统不再是偶尔提问的执行器，而是承载多方知识的载体。
> - **技能组合**把「单个动作块」升级成「契约化的可组合模块」：技能不再是一团不透明的策略，而是带前置/后置/不变式/能力域/来源的**契约**；组合是契约的假设-保证链。
>
> 核心命题：**把技能制度化为带来源的契约，把共创制度化为带署名的证据，并显式引入第三类不确定性 U_comp（组合不确定性）——它既不是 R68 的噪声、也不是 R69 的「问一句就能消解的歧义」，而是技能之间相互作用产生的、任何单个作者都未曾验证的残余。只有当组合契约链闭合、且 U_comp 在预算内被认证或探针消解时才允许组合执行；否则退回到最大已认证子链或单技能，再退化为 R69/R68。** 命名 **MOSAIC-RAS**（Multi-Origin Skill Assembly with Interaction-aware Certification）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**这份能力是谁教的、它能和谁拼、拼坏时谁负责**」——不确定性不再只是刹车、提问，也可以是**一份被署名的契约、一条被认证的组合链、一次归到正确作者的纠正**。

## 0. 直觉与动机

**灵感 1（用户共创 → 人类从「证人」变成「作者」）**
直觉：R69 的「问」是一次性取证：得到一个回答、更新一次后验、然后丢弃。用户共创说的是另一件事：用户把自己的判断**沉淀成系统的一部分**——示范一段动作、标注一次偏好、纠正一个失败，甚至直接提交一个新技能。于是贡献不再是瞬时证据，而是**持久、可复用、可传播的知识**。这带来两个新问题：其一，贡献跨 episode 存活，一个错误会被反复调用（R69 的错误只影响一帧）；其二，贡献有作者，责任与信任必须落到人/来源上，不能像 R69 那样把所有回答加成一个匿名后验。

**灵感 2（技能组合 → 组合是新的风险发生地）**
直觉：一个技能单独安全，不代表和另一个技能拼起来安全。想想「加速通过」与「贴近观察」：前者假设前方足够空，后者为了看清会把机体压到障碍附近；单独各有安全包络，拼起来却可能在「既快又近」的联合状态里越界。**风险不是各技能风险的加和，而是它们相互作用的产物。** 组合不是免费的模块化红利，它制造了单个作者从未见过的联合行为。

**灵感 3（契约化 → 让组合可被推理，而非靠穷举测试）**
直觉：若技能只是黑箱策略，要保证 n 个技能的所有组合安全就得测试指数多条链——不可能。但若每个技能声明「我需要什么前置条件、保证什么后置条件、维持什么不变式、在哪个能力域内被验证过」，组合就能用**假设-保证（assume-guarantee）推理**逐边检查：上游保证是否蕴含下游假设、不变式是否沿接口保持。这把「组合安全」从测试问题变成**契约闭合问题**。契约不必完备（学习技能本就没有完备规格），但**不完备必须被显式计量**，而不是默认为零。

**灵感 4（三分 → 现有二分看不见组合）**
直觉：R69 的 U_ale 是模态内噪声、U_epi 是模态间歧义（问一句可约）。但组合残余既不在单个技能的模态内，也不在「选哪个模态」之间——它是**技能之间的关系**：契约缺口（上游保证没覆盖下游假设）、交互超出（联合行为偏离各技能边际的乘积）、覆盖缺口（组合轨迹跑到任何单个能力域之外）。更关键的是，**这份不确定性问人也没用**：用户可能只教了单个技能，并不知道两个技能拼起来会怎样。它必须靠**结构推理 + 定向探针**消解，而非 R69 的提问。

**灵感 5（共创的暗面 → 新的威胁模型与归责难题）**
直觉：一旦技能可被多方贡献、可被组合，攻击面与责任结构同时变化。可以提交一个**特洛伊技能**：单独测试完全正常，只在特定组合里作恶；可以伪造来源冒领高信任；可以多人共谋让「多源一致」失效；系统也可能因为「这是用户教的」而谄媚地过度信任。最阴险的是**责任缺口**：组合失败时没有任何单技能契约被违反——每个作者都能说「我的技能在它的假设下是对的」，于是没人负责、纠正回路永不触发。共创若不能归责，就会退化成一座没人能调试的技能仓库。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（MOSAIC-RAS 总览）** MOSAIC-RAS = (SKR, CCC, CUC, SCP, PCA, CCA, VQAuditor-M, RAS-WM§)。四不变式：
(i) 继承 R69 实时流零学习写操作（定义 276-i）、证据纪律（定义 293-iii）与 R68/R69 保守下界；
(ii) **契约纪律**：任何可执行技能必须携带机器可检查契约（Pre/Post/Inv/能力域/来源），无契约或匿名技能不得执行、更不得组合；
(iii) **组合闭合**：仅当组合的假设-保证链闭合、且 U_comp 在预算内被认证或探针消解时，才允许执行组合；否则退化为最大已认证子链或最高信任单技能；
(iv) **可归责**：每次执行与每次失败都记录来源图与反事实信用向量；非可归因失败必须单列为「接口级故障」，不得静默归零。

**定义 311（技能即契约）** 技能 S = (π_S, Pre_S, Post_S, Inv_S, C_S, ρ_S, θ_S, J_S)。π_S 为可执行策略（可为 R69 的 FMP 子策略）；Pre/Post ⊆ 𝒳×𝒞 为前置/后置条件；Inv_S ⊆ 𝒳 为安全不变式；C_S ⊆ 𝒳 为被验证的能力域；ρ_S 为来源图（作者集合 A_S、贡献类型、父技能）；θ_S 为来源条件化信任；J_S 为继承的 R68/R69 证书。**契约是技能的一等公民，策略只是契约的一侧。**

**定义 312（共创贡献与摄取）** 贡献 c = (type, content, a, x, τ)，type ∈ {demo, preference, correction, new_skill, constraint}，a 为作者，x 为上下文。摄取算子 ⊕ 将 c 转为：(a) 既有技能的**证据**（带来源的贝叶斯更新）；(b) 候选技能契约（若 type=new_skill）；(c) 对 Pre/Inv 的**约束精化**（若 type=constraint）。仅当契约合成通过安全过滤、且满足定义 323 的信任门时，候选技能才进入技能库。

**定义 313（来源条件化信任与反谄媚）** 信任 θ(a, κ) 按作者 a 与上下文类 κ 估计，来自已验证结果的可靠图与 ECE_a。技能信任取关键贡献者的最小值 θ_S = min_{a∈A_S^{critical}} θ(a, κ)（避免平均稀释）。**反谄媚门**：θ(a,κ) ≤ g(n_a^{indep})，n_a^{indep} 为独立验证过的贡献数；同一作者的自证、重复提交不计入独立源（与 R69 的 k-正交源纪律一致）。直觉：再受欢迎的作者，其信任也不能跑在独立证据前面。

**定义 314（组合与假设-保证链）** 组合 C = S_1 ∘ … ∘ S_n 连同接口边 E。把每个技能视为契约 (A_i, G_i)：A_i 为由上游保证与初始条件导出的**假设**，G_i ⊆ Post_i 为**保证**。组合契约闭合当且仅当：(i) 初态 x_0 ∈ Pre_1；(ii) 每条边 i→j 上 P(G_i ⇒ A_j) ≥ 1−δ；(iii) 每个接口处 ∩_i Inv_i 保持；(iv) 终态 ∈ Post_n。定义**契约缺口** Γ(C) = 1 − P(∧_{edges} G_i ⇒ A_j)，用于量化非语法可判的包含关系（学习契约只在能力域 C_S 内可信）。

**定义 315（组合不确定性 U_comp，第三类不确定性）** 将组合残余分解为三项：
- 契约缺口 Γ(C)（定义 314）；
- **交互超出** I_ex(C) = D_KL( P(ξ_{1:n} | C) ‖ ⊗_{i} P(ξ_i | S_i) )，即联合行为分布相对各技能边际乘积的偏离（总相关的归一化版本）；I_ex = 0 当且仅当技能在分布意义上不交互；
- **覆盖缺口** G_cov(C) = 1 − μ({traj(C) ∈ ∪_{i} C_{S_i} ∪ 已验证成对能力域})，μ 为轨迹测度。
U_comp = w_Γ·Γ + w_I·I_ex + w_G·G_cov（权重经 E303 校准）。**U_comp 与 U_ale、U_epi 正交，不可通过询问单个模态消解。**

**定义 316（组合兼容图与可达组合）** 建图 G_comp：节点为技能，边 (i,j) 存在当且仅当接口契约兼容且信任超阈值。可达组合 = 在 G_comp 中、深度 ≤ L、且状态流在当前任务下可实现的链。组合数量被契约剪枝，避免指数枚举；仅对可达链做按需认证（定义 317）。

**定义 317（惰性组合认证 SCP）** 规划时只认证当前候选链，不预先枚举全库。引入**证书代数**：子链证书可复用；组合证书 = combine(cert(i), cert(j))，combine 结合但不交换（顺序敏感）；缓存键为（链、接口、上下文类）。认证复杂度从 O(|G_comp|^L) 降到每个规划 O(L·cost(CCC))。

**定义 318（组合探针 PCA）** 当 U_comp 高且组合价值高时，分配一次**探针**：在数字孪生/影子模式/已认证微执行中做有界 rollout，估计 I_ex 与契约缺口。VoI_probe(C) = H(组合行为) − E_{y~probe}[H(组合行为|y)] − c_probe − λ_risk·risk(probe)。与 R69 不同，**探针的受访对象是世界/孪生，而非人**；孪生保真度不可信时探针作废（定义 322 的探针投毒）；单次探针只是似然，需与契约推理或第二次正交探针一致才可定案（继承定义 293-iii）。

**定义 319（保守组合退避 CF）** 若 U_comp > τ_comp、契约链不闭合、探针不可行/不可信、或任一关键来源信任低于 τ_trust：取组合的**最大已认证子链** C' ⊆ C（契约闭合且 U_comp ≤ τ_comp）；若无，执行最高信任的**单技能**；若连单技能都不满足，回到 R68 的纯保守停止。残余不确定性按 R69 定义 307 进入 λ_floor。**组合只在「有证书」时存在，否则不存在。**

**定义 320（反事实信用 CCA）** 对结果 y（任务效用或负风险）与技能联盟 N，Shapley 信用 φ_i = Σ_{T⊆N∖{i}} (|T|!(n−|T|−1)!/n!)·[v(T∪{i}) − v(T)]。大 n 用分层/采样 Shapley 或「固定接口、消融单技能」的契约级因果归因。信用经来源图 ρ 路由回作者，用于 (a) 审计，(b) 定向纠正，(c) 更新 θ。**信用只在与接口交互可分离时唯一可识别**；不可分离部分进入责任缺口（定义 321）。

**定义 321（责任缺口与非可归因失败）** 失败若满足「不存在任何单个技能的 Inv_i 被违反，但组合 Post_C 被违反」，称**非可归因失败**，责任缺口 R_gap = 1。此时对所有单技能，固定接口下的 Shapley 边际为零：逐技能重训无法修复。必须走**接口级修复**——新增/收紧接口不变式，或从兼容图中删除该边。这把「组合坏了算谁的」从伦理问题变成可操作的技术分类。

**定义 322（共创-组合威胁模型 ℰ_MOSAIC）** ℰ_co-create：特洛伊技能（隔离正常、特定组合作恶）、来源伪造、作者共谋（相关错误绕过 k 源）、谄媚过度信任、自证纠正、偏好漂移、契约遗漏（作者隐瞒前置条件）。ℰ_compose：组合奖励黑客、接口契约伪造、探针投毒（孪生被污染）。合并 ℰ_MOSAIC = ℰ_FLUID × ℰ_co-create × ℰ_compose。

**定义 323（信任不洗白与单调性）** 组合信任 θ(S_1∘…∘S_n) ≤ min_i θ(S_i)；组合证书可信度不高于最弱环；任一关键来源 θ < τ_trust ⇒ 组合证书无效。**推论：低信任技能无法借道高信任技能洗白。** 同时 U_comp ≥ 0，组合证书不能强于任何单项的保守下界。

**定义 324（共创审计与证书 J_MOSAIC）** J_MOSAIC = (J_FLUID, contract_chain_hash, provenance_graph, U_comp_before/after, Γ, I_ex, G_cov, probe_log_hash, credit_vector, R_gap, θ_min, mosaic_ver)。Valid ⇔ Valid(J_FLUID) ∧ 契约链闭合 ∧ (U_comp ≤ τ_comp ∨ 已走 CF) ∧ θ_min ≥ τ_trust ∧ 信用已记录 ∧ 无匿名技能 ∧ 非可归因失败未被静默忽略。

**定义 325（参与式责任审计 VQAuditor-M）** 在 R69 VQAuditor-I 上扩展：贡献是否被正确署名与记分、低信任技能是否被组合、非可归因失败是否被登记并路由到接口修复、特洛伊技能是否被探针/金丝雀捕获。结论回灌信任 θ 与兼容图 G_comp。共创包含「可申诉」，但申诉只能改变信用分配，**不能覆盖安全证书**。

**定义 326（退化边界）** n=1 且禁用共创摄取 ⇒ 逐指令等于 FLUID-RAS（R69）：单技能契约退化为 R69 证书，CF 退化为定义 307；再令 VoI ≤ 成本（定义 298）⇒ 逐指令等于 CALM-RAS（R68）。安全侧因契约闭合与 CF 而单调不弱于 R69。

## 2. 关键算法骨架

```python
# IP-264 SKR：技能库与契约（技能 = 策略 + 契约 + 来源 + 信任）
@dataclass
class Skill:
    pi: Policy                 # 可执行的 FMP 子策略
    Pre: Predicate; Post: Predicate; Inv: Predicate
    C: CompetenceRegion         # 已验证能力域
    provenance: ProvenanceGraph
    theta: dict                 # 来源条件化信任
    J: Certificate              # 继承 R68/R69

# IP-265 CCC：假设-保证链检查（边兼容 + 不变式保持）
def check_composition(chain, x0, ctx):
    if not chain[0].Pre(x0, ctx): return False, 1.0
    gamma = 0.0
    for a, b in zip(chain, chain[1:]):
        gap = 1.0 - prob_implies(a.Post, b.Pre, ctx)   # 学习契约的概率包含
        if gap > DELTA: return False, gap
        gamma = max(gamma, gap)
        if not preserves(a.Inv & b.Inv, a.Post, b.Pre, ctx):
            return False, 1.0
    return chain[-1].Post(x0, ctx), gamma

# IP-266 CUC：组合不确定性 = 契约缺口 + 交互超出 + 覆盖缺口
def compose_uncertainty(chain, ctx):
    gamma = check_composition(chain, ctx.x0, ctx)[1]
    i_ex  = interaction_excess(chain, ctx)      # 联合 vs 边际乘积（采样/解析）
    g_cov = 1 - coverage(chain_traj(chain),
                         union(chain[i].C for i in range(len(chain))))
    return W_GAMMA*gamma + W_I*i_ex + W_G*g_cov, (gamma, i_ex, g_cov)

# IP-268 PCA：组合探针（世界/孪生是受访者；VoI − 成本，孪生须可信）
def probe_if_worthwhile(chain, U_comp, twin):
    if not twin.reliable(): return None             # 探针投毒 → 作废
    best = None
    for p in probe_candidates(chain, U_comp):
        risk = twin.risk(p)
        if risk > EPS_PROBE or not budget.allow(p): continue
        voi   = entropy(chain) - expected_entropy_after(p, twin)
        score = voi - cost(p) - LAMBDA_RISK*risk
        if best is None or score > best.score: best = (p, score)
    return best if best and best.score > 0 else None

# IP-270 CCA：反事实信用（采样 Shapley，经来源图路由回作者）
def assign_credit(chain, outcome, samples=64):
    phi = sampled_shapley(chain, v=lambda T: value(T, outcome), m=samples)
    return route_to_authors(phi, [s.provenance for s in chain])

# IP-277 主闭环（继承 R69，仅在「组合」处插入 MOSAIC 层）
def MOSAIC_round(M, obs, task):
    z, o = M.mtm.forward(...); c, U_cal, _ = M.cof.step(...)
    # 1) 规划可达组合（契约剪枝），而非枚举全库
    cand  = M.scp.plan(task, M.skr, ctx=o)             # 深度 ≤ L，返回候选链
    chain = max(cand, key=lambda ch: expected_utility(ch, o))
    # 2) 组合不确定性 + 惰性认证
    U_comp, parts = M.cuc.compose_uncertainty(chain, ctx=o)
    ok, gamma     = M.ccc.check_composition(chain, o.x0, o)
    # 3) 有价值则探针（世界是受访者）；否则直接判定
    if ok and U_comp > TAU_COMP:
        p = M.pca.probe_if_worthwhile(chain, U_comp, M.twin)
        if p: U_comp = M.cuc.update_after_probe(U_comp, p, M.twin)
    # 4) 退避：组合不可信 → 最大已认证子链 → 单技能 → R68
    if (not ok) or (U_comp > TAU_COMP):
        chain = M.cf.max_certified_subchain(chain, TAU_COMP) \
                or M.cf.best_singleton(chain)
        ok = len(chain) > 0
    # 5) 执行组合；内层仍用 R69 的 λ_floor / C-RAS-WM 认证
    lam = max(M.efs.risk_scale(...),
              lam_floor(U_ale + U_epi_unresolved + (U_comp if not ok else 0.0)))
    A = M.ach.propose_chain(chain, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    # 6) 归责 + 证书 + 参与式审计
    phi = M.cca.assign_credit(chain, M.last_outcome)
    M.vqa_m.submit_async(chain, U_comp, parts, phi, R_gap=M.last_r_gap)
    return k, lam, chain, phi, (U_comp, parts)
```

## 3. 推导

**引理 19（组合严格放大风险）** 存在两个技能 S_1, S_2，各自在其能力域内风险 ≤ ε，但组合 C=S_1∘S_2 的风险 sup risk(C) > ε，且不能由 max_i risk(S_i) 或 Σ_i risk(S_i) 界定。构造：标量系统里，S_1「提速」在假设「距离 > d_0」下安全；S_2「贴近观察」在假设「速度 ≤ v_0」下安全；组合同时提速并贴近，进入 S_1 与 S_2 都未覆盖的联合区 (v > v_0 ∧ d < d_0)。故组合风险是**联合分布上的新事件**，不是边际的最大或线性函数。系：任何仅按单项风险做保守缩放的机制（含 R68 的 λ_floor）都无法覆盖 U_comp。

**引理 20（契约链的充分性）** 若每条边 P(G_i ⇒ A_{i+1}) ≥ 1−δ、各接口 Inv 保持、初态满足 Pre_1，则组合以概率 ≥ 1−nδ 满足 Post_n 且全程保持 ∧Inv_i。证明：对 n 条边用 union bound。注意这是**充分非必要**且**条件化于契约诚实**——契约遗漏不在保证范围内，这正是责任缺口的根源（定理 21）。

**引理 21（U_comp 的可探测性与样本复杂度）** 若 I_ex(C) ≥ ι，则在孪生上用长度 T 的探针可由 Pinsker 不等式把「存在交互」与「独立」以概率 ≥ 1−η 区分，所需 T = O(ι^{-2} log(1/η))。故高交互组合可被有限探针检出；I_ex 极小的组合无法在预算内被探针确认——此时应走 CF，而不是「探了等于没探」。

**引理 22（信任不洗白）** 由定义 323 组合信任取最小，任何组合的信任不超过最低信任组件；因此把低信任/特洛伊技能接到高信任技能之后，不能提升其可信度，也不能借组合证书绕过 τ_trust。

**定理 18（MOSAIC 严格包含 R69/R68）** 在契约诚实（A99）与能力域覆盖（A100）下，任意状态上 MOSAIC 的期望风险 ≤ R69；当 n=1、禁用共创、U_comp=0 时两者逐指令相同；再令 VoI ≤ 成本即逐指令等于 R68。证明要点：单技能时契约退化为 R69 证书、CF 与定义 307 相同；组合时只在契约闭合且 U_comp ≤ τ 时执行，否则退回 R69 可执行的子链，故风险不增。安全侧不让步，效率侧获得「组合复用」收益。

**定理 19（信用归责的一致性与收敛）** 采样 Shapley 以 O(1/√m) 收敛到真 Shapley；若接口交互可分离，则信用向量与真实作者贡献一致，按信用路由的纠正使被纠正贡献的重复错误率单调不增。若交互不可分离，则存在非可归因失败使所有单技能信用为零（与定理 21 一致），此时归责必须上移到接口。

**定理 20（特洛伊技能的组合认证必要性 / 隔离不可判定）** 存在技能对 (S_b, S_t)：对所有隔离测试分布 D_iso，两者行为 ε-不可区分（总变差 < ε），但存在一条可达组合 C 使二者在安全意义上显著不同。故任何只做「隔离测试 + 单技能证书」的认证器错误率下界 ≥ 1−ε。**结论：组合认证与定向探针不是可选项，而是由可组合性本身强制的。** 这解释了为什么 R69 的逐技能证据纪律不足以保障组合。

**定理 21（责任缺口的存在性与接口修复必要性）** 存在组合 C，其失败时所有单技能 Inv_i 均未被违反（故逐技能 Shapley 边际为零，逐技能重训无法改变结果），但通过新增/收紧接口不变式或删除边可消除该失败。故责任缺口是**结构性**的：不能由更努力的单技能验证消除，只能由接口级契约修订消除。系：共创系统的纠正回路必须包含「接口作者」角色，否则无人对组合失败负责。

```python
# IP-264/265 SKR + CCC：技能即契约；假设-保证链检查
def check_composition(chain, x0, ctx):
    if not chain[0].Pre(x0, ctx): return False, 1.0
    gamma = 0.0
    for a, b in zip(chain, chain[1:]):
        gap = 1.0 - prob_implies(a.Post, b.Pre, ctx)
        if gap > DELTA: return False, gap
        gamma = max(gamma, gap)
        if not preserves(a.Inv & b.Inv, a.Post, b.Pre, ctx): return False, 1.0
    return chain[-1].Post(x0, ctx), gamma

# IP-266 CUC：组合不确定性 = 契约缺口 + 交互超出 + 覆盖缺口
def compose_uncertainty(chain, ctx):
    gamma = check_composition(chain, ctx.x0, ctx)[1]
    i_ex  = interaction_excess(chain, ctx)
    g_cov = 1 - coverage(chain_traj(chain),
                         union(s.C for s in chain))
    return W_GAMMA*gamma + W_I*i_ex + W_G*g_cov, (gamma, i_ex, g_cov)

# IP-268 PCA：探针（世界/孪生是受访者；孪生不可信即作废）
def probe_if_worthwhile(chain, U_comp, twin):
    if not twin.reliable(): return None
    best = None
    for p in probe_candidates(chain, U_comp):
        risk = twin.risk(p)
        if risk > EPS_PROBE or not budget.allow(p): continue
        score = entropy(chain) - expected_entropy_after(p, twin) - cost(p) - LAMBDA*risk
        if best is None or score > best.score: best = (p, score)
    return best if best and best.score > 0 else None

# IP-270 CCA：采样 Shapley，经来源图路由回作者
def assign_credit(chain, outcome, samples=64):
    phi = sampled_shapley(chain, v=lambda T: value(T, outcome), m=samples)
    return route_to_authors(phi, [s.provenance for s in chain])

# IP-277 主闭环（继承 R69，仅在「组合」处插入 MOSAIC 层）
def MOSAIC_round(M, obs, task):
    z, o = M.mtm.forward(...); c, U_cal, _ = M.cof.step(...)
    cand  = M.scp.plan(task, M.skr, ctx=o)                 # 契约剪枝，深度 ≤ L
    chain = max(cand, key=lambda ch: expected_utility(ch, o))
    U_comp, parts = M.cuc.compose_uncertainty(chain, ctx=o)
    ok, gamma     = M.ccc.check_composition(chain, o.x0, o)
    if ok and U_comp > TAU_COMP:                           # 有价值才探，世界是受访者
        p = M.pca.probe_if_worthwhile(chain, U_comp, M.twin)
        if p: U_comp = M.cuc.update_after_probe(U_comp, p, M.twin)
    if (not ok) or (U_comp > TAU_COMP):                     # 退避链
        chain = M.cf.max_certified_subchain(chain, TAU_COMP) or M.cf.best_singleton(chain)
        ok = len(chain) > 0
    lam = max(M.efs.risk_scale(...),
              lam_floor(U_ale + U_epi_unresolved + (U_comp if not ok else 0.0)))
    k = M.c_ras_wm.certified_prefix(M.ach.propose_chain(chain, M.vista.H), ..., wm_preds)
    phi = M.cca.assign_credit(chain, M.last_outcome)        # 归责

```

## 4. 推导

**引理 19（组合严格放大风险）** 存在 S_1、S_2 单项风险 ≤ ε，但组合风险 > ε，且不能被 max_i 或 Σ_i 单项风险界定：S_1「提速」假设距离 > d₀，S_2「贴近观察」假设速度 ≤ v₀，组合进入两者都未覆盖的联合区 (v>v₀ ∧ d<d₀)。故组合风险是联合分布上的新事件，R68 的 λ_floor 等单项缩放无法覆盖。

**引理 20（契约链充分性）** 每边 `P(G_i⇒A_j)≥1−δ`、接口不变式保持、初态∈Pre₁ ⇒ 组合以概率 ≥1−nδ 满足 Post_n 且全程保持 ∧Inv_i（对 n 条边 union bound）。充分非必要，且条件化于契约诚实。

**引理 21（U_comp 可探测性与样本复杂度）** 若 I_ex ≥ ι，则长度 T 的孪生探针可由 Pinsker 以概率 ≥1−η 区分「存在交互 / 独立」，`T = O(ι^{-2} log(1/η))`；I_ex 极小时预算内不可确认，应走 CF。

**引理 22（信任不洗白）** 组合信任取最小 ⇒ 组合可信度不超过最低信任组件；低信任/特洛伊技能无法借高信任技能洗白或绕过 τ_trust。

**定理 18（MOSAIC 严格包含 R69/R68）** 契约诚实（A99）与能力域覆盖（A100）下，任意状态期望风险 ≤ R69；n=1、禁用共创、U_comp=0 时逐指令相同；再令 VoI≤成本即逐指令等于 R68。安全不让步，效率得组合复用收益。

**定理 19（信用归责一致性与收敛）** 采样 Shapley 以 O(1/√m) 收敛；接口交互可分离时信用与真实作者贡献一致，按信用路由的纠正使重复错误率单调不增；不可分离时单技能信用为零（见定理 21），归责上移到接口。

**定理 20（特洛伊技能的组合认证必要性 / 隔离不可判定）** 存在 (S_b, S_t)：所有隔离测试下 ε-不可区分，但某条可达组合下行为显著不同。故仅做隔离测试 + 单技能证书的认证器错误率下界 ≥1−ε——组合认证与定向探针是**被可组合性强制的**，不是可选项。

**定理 21（责任缺口存在性与接口修复必要性）** 存在组合 C，失败时所有单项 Inv_i 均未违反（逐技能 Shapley 边际为零，逐技能重训无法修复），但新增/收紧接口不变式或删边可消除失败。责任缺口是结构性的，必须设「接口作者」角色。

## 7. 本轮最大风险

**一句话**：整套方法把安全押在「学习到的契约是诚实且足够完整」上——**共创把作者数量乘以组合数量**，系统性制造每个作者都没写进契约的交互项；这些交互项一旦从证书里漏掉，MOSAIC 会为一条纸面闭合、现实越界的组合链盖章，而定理 21 保证这种失败无人可归责、纠正回路不触发，于是「共创」退化成一座越组合越危险、无人能调试的技能库。

**次级风险与缓解**：契约遗漏 → 显式计量 Γ、只在能力域 C_S 内信任契约、E301 审计；特洛伊技能隔离不可判定 → 组合认证 + 金丝雀探针（定理 20）、E308；作者共谋绕过 k 源 → 来源不洗白（定义 323）+ 独立验证数约束信任、E309；谄媚过度信任 → 反谄媚门 + E310；组合爆炸击穿实时预算 → 兼容图剪枝 + 惰性认证 + 证书代数、E304；探针投毒（孪生失真）→ 孪生保真门 + 探针作废 + 证据纪律。
