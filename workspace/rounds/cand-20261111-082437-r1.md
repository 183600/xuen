# 第 56 轮（承接第 55 轮 v32 GroundEdge-GenSim++++；新灵感循环第 1 轮；本轮灵感：「模块化设计」×「抓取」）

> 前 55 轮已把「执行-鲁棒-动作-证据」逐层证书化，但技能始终被当作**整块（monolithic）**对象：动作剖面 `α_S` 只描述它占用多大动作空间，检索证据只描述它在哪些场景可靠，却**无法描述它如何由更小的、可替换的部件拼成**，更无法回答抓取最核心的问题——**接触力能否闭合**。本轮用「模块化设计」重写「抓取」：把抓取拆成带类型端口的接触模块，使组合的第一性约束从「动作空间相交」升级为「接口相容 + 扳手锥力封闭」。核心矛盾：H22：整块技能的动作相容性看不见接触语义，组合前 Jaccard 很高、执行时因摩擦锥不足而滑脱；H23：抓取本是可复用、可替换的模块拼装，整块建模既阻碍跨物体迁移，也让失败无法局部修复。

## 0. 思考轨迹与直觉

**思考轨迹（可见）**
我先问：为什么抓取是这个体系里最刺眼的缺口？因为前 55 轮的"可行性"一路是**运动学/几何/证据**口径——动作能否覆盖、轨迹能否对齐、证据是否充分——却始终没有**力**。抓取恰恰是"几何上够得着、物理上抓不住"的高发区。再问："模块化设计"能带来什么别人没做过的东西？不是把技能分个层，而是给出**端口契约**这一工程基石：只要端口类型定义得足够强，模块就能被形式化地拼接、替换、复用，而组合的正确性可以在**接口层**被验证，而不是只能端到端试错。把这两点合起来，结论很自然：**抓取 = 接触模块的端口代数，力封闭 = 该代数的硬否决门**。下面五条灵感按"分解→拼装→验证→替换→协同"展开。

**灵感 1（模块化设计 → 抓取是可拼装的接触程序）**
直觉：工程模块化设计只有三件事——**标准端口、显式契约、可替换性**。抓取完全同构。"接近→预成形→接触→闭合→抬升→搬运"每一步都是模块，模块间传递的不是抽象"控制权"，而是**接触状态**：位姿、速度旋量、接触法向、可施加扳手锥、传感模态。端口定义清楚后，抓取就能像搭积木一样拼装、替换与复用。这把前几轮的"技能组合图"从**节点=整技能**细化为**节点=接触模块、边=端口匹配**。

**灵感 2（抓取 → 力封闭是模块组合不可绕过的硬约束）**
直觉：动作空间相容只说明"两个模块能接上"，不说明"接上之后能抓住"。抓取的本质是**用接触扳手锥抵抗任务扳手**：每个接触模块给出 `W_i`（摩擦锥 + 接触点力臂），组合给出 `W(A)=cone(∪W_i)`，真正的门槛是任务扳手 `w_T` 落在 `W(A)` 内部且留有余量。于是力封闭成为模块组合的**硬否决门**，动作相容性退化为必要非充分条件——这正好补上前几轮 `α_S` 完全看不见的维度。

**灵感 3（模块库与按端口检索 → 从"选技能"到"选装模块"）**
直觉：把模块库按 (物体可供性, 手部形态, 接触模态) 建索引。给定新物体，不重新学整段抓取，而是检索**端口可接**的模块序列/并行接触组，再在候选装配上做力封闭搜索。检索覆盖度直接决定装配的可靠域，正好复用第 55 轮 EIG/SRC/EAM：证据不足时显式判 `insufficient` 并触发 Isaac Sim 定向补证，而不是把"长得像"的模块硬拼。

**灵感 4（可重构末端 → 硬件模块与抓取模块的联合契约）**
直觉：模块化也不只发生在软件分层，还指**可换手指/指腹/吸盘的末端执行器**。硬件模块有自己的安装端口、力矩上限、传感带宽与磨损状态。抓取装配必须同时满足：软件端口匹配、硬件端口可安装、硬件能力包络覆盖所需扳手。这样"换一个指腹"不会悄悄破坏证书，而会触发联合可行性重算。

**灵感 5（失败即重组，而非仅重规划）**
直觉：前几轮的失败回传是"重剖分动作空间/重规划路径"。模块化视角给出更强的修复动作：**模块替换**（换接触模态/换指腹/换接近方向）与**接口重对齐**（重预成形、重接触）。边端一旦检测到滑移（实际扳手越出估计 `W`），回传的是"哪个端口/哪个模块失效"，云端在模块图中做局部重装配并增量更新证书，而不是全图重搜。

## 1. 形式化定义（增量：定义 128–134）

**定义 128（抓取模块与类型化端口）**
抓取模块 `M=(I_M,O_M,K_M,W_M,ρ_M,π_M)`：`I_M` 输入端口、`O_M` 输出端口、`K_M` 接触模态标签（贴合/包覆/捏取/吸附/钩挂）、`W_M⊆R^6` 扳手锥、`ρ_M` 鲁棒谱、`π_M` 出处。端口为七元组
`(p∈SE(3), ξ∈se(3), n∈S^2, W⊆R^6, μ∈[μ_lo,μ_hi], m, h)`，
即位姿、旋量、接触法向、可施加扳手、摩擦带、传感模态、硬件端口 id。

**定义 129（端口相容性与接口残差）**
`M_i ≻ M_j` 当且仅当：位姿残差 `||Δp||≤ε_p`、旋量连续 `||ξ_i-ξ_j||≤ε_ξ`、法向连续 `n_i·n_j ≥ cos ε_n`、摩擦带区间相交、传感模态握手成功、硬件端口可安装。接口残差
`δ_I(M_i,M_j) = max{ ||Δp||/ε_p, ||Δξ||/ε_ξ, ε_n/∠(n_i,n_j), 摩擦带间隙归一化, 握手失败 }`。
仅当 `δ_I ≤ Θ_I` 允许连接。`δ_I` 是"接得上"的量化，但不含"抓得住"。

**定义 130（模块装配图与并行接触）**
装配图 `G_M=(V,E,Π)`：`V` 模块实例，`E` 串行端口相容边，`Π` 可并行叠加的接触组（多指同时接触以抑制自由度）。抓取装配 `A=(V_A,E_A,Π_A)` 是满足端口契约的连通子图，且 `A` 的输出端口与任务端口匹配。

**定义 131（组合扳手锥与力封闭余量）**
接触 `i` 的扳手锥 `W_i = { [f;τ] : f∈FC(μ_i,n_i), τ=(p_i-p_o)×f }`，其中 `FC` 为摩擦锥。组合 `W(A)=cone(∪_{i∈A} W_i)`。给定任务扳手 `w_T`：
```
m_fc(A,w_T) = max{ γ≥0 : w_T + γ·B_1 ⊆ W(A) }
```
（`B_1` 单位球；对多面体锥可化为沿各面法向支撑函数的下确界 LP）。`A` 力封闭当且仅当 `m_fc ≥ m_min`；不足时返回最紧约束方向 `u* = argmin` 作为可解释根因。

**定义 132（模块化抓取证书）**
`MGC(A) = (A, W_cert, m_fc, δ_I, ρ_lcb, RAC, H_cert)`，其中 `W_cert` 含摩擦带与接触点不确定性、`H_cert` 为硬件证书。可部署条件：
```
m_fc ≥ m_min ∧ δ_I ≤ Θ_I ∧ RAC.status = certified ∧ H_cert = ok
```
关键：动作相容 `compat ≥ θ_a` 退为**先决过滤**，不再单独构成可行。

**定义 133（模块替换与增量重认证）**
替换算子 `sub(M→M')` 保持 `O_{M'}≻I_{succ}` 且 `I_{M'}≻O_{pred}`。增量重认证只重算受影响接触组的 `W` 与 `δ_I`。替换代价
`cost_sub = w_fc·Δm_fc + w_I·Δδ_I + w_ev·ΔCov`；若新余量跌破 `m_min` 则拒绝替换。

**定义 134（硬件-抓取联合可行性）**
硬件配置 `H={h_1..h_k}`（指腹/指节/吸盘等）。联合可行性要求：(i) 每个 `M` 的硬件端口 `h` 在 `H` 中已安装；(ii) 硬件力矩/速度/带宽包络覆盖 `W_cert` 需求；(iii) 磨损 `η_h` 使有效摩擦 `μ_eff` 落在证书带内。输出 `H_cert=(装配表, 包络余量, 磨损置信)`。

## 2. 关键算法 伪代码

### IP-128 GMD（Grasp Module Decomposition）
```python
def decompose_grasp(traj, contact_log, theta_seg):
    # 按接触相位切分：approach/preshape/contact/closure/lift/transport
    phases = segment_contact_phases(traj, contact_log, theta_seg)
    modules = []
    for ph in phases:
        M = GraspModule(
            I=extract_in_port(ph), O=extract_out_port(ph),
            K=classify_contact_mode(ph),
            W=build_wrench_cone(ph, contact_uncertainty(ph)),
            rho=robustness_spectrum(ph), pi=provenance(ph))
        modules.append(M)
    return Assembly(modules, chain_ports(modules))
```

### IP-129 MAM（Modular Assembly Matching）
```python
def match_assemblies(modules, task_port, eps, theta_a, m_min):
    G = build_port_graph(modules, eps)          # 端口相容图
    out = []
    for A in enumerate_connected_assemblies(G, out_port=task_port, depth_max=D):
        if action_compat(A) < theta_a: continue   # 先决过滤（必要不充分）
        if not port_contract_ok(A): continue
        W = compose_wrench_cone(A)
        m = force_closure_margin(W, task_port.w_T)
        if m >= m_min:                            # 力封闭硬门
            out.append((A, m))
    return sorted(out, key=lambda x: -x[1])
```

### IP-130 WCC（Wrench Closure Certificate）
```python
def wrench_certificate(A, I, kappa, alpha, m_min, theta_cov):
    E = retrieve_contact_evidence(A, I)
    if coverage(E, A.contact_subspace) < theta_cov:
        return ('insufficient', request_evidence(A))
    mu_lo = conformal_lower(evidence_friction(E), alpha)   # 摩擦下界
    W_rob = robust_cone(A, mu_lo, contact_uncertainty(E))  # 含点/向不确定性
    m = force_closure_margin(W_rob, task_wrench(A))
    if m < m_min:
        return ('reject', explain_tight_direction(W_rob, m))
    return ('certified', W_cert(W_rob, m, mu_lo, E))
```

### IP-131 MRR（Modular Repair & Reassembly）
```python
def repair_on_slip(A, slip, lib, theta_I, m_min):
    i = localize_failed_module(A, slip)         # 由越界扳手方向反推端口/模块
    cands = substitute_candidates(lib, replace=i, preserve_ports=True)
    cands = [A2 for A2 in cands if hardware_coupling(H, A2).status == 'ok']
    A2 = argmin(cands, key=lambda x: cost_sub(A, x))
    W2, m2, dI2 = incremental_recompute(A, A2)  # 只重算受影响接触组
    if m2 >= m_min and dI2 <= theta_I:
        return ('repaired', A2, MGC(A2, W2, m2, dI2, ...))
    return ('request_reassembly', explain(slip))
```

### IP-132 HMC（Hardware-Module Coupling）
```python
def hardware_coupling(H, A):
    for M in A.modules:
        h = H[M.port.h]
        if not mounted(h) or not envelope_covers(h, M.W):
            return ('reject', 'hardware', M)
        if wear_adjusted_friction(h) < M.W.mu_lo:
            return ('reject', 'wear', h)
    return ('ok', H_cert(H, A))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| GMD | O(|τ|·|K|) 切分 + 端口抽取 | O(|M|) | 相位切分完备、接触模态可判 |
| MAM | O(|M|²·|ports| + |A|·LP) | O(|M|²) | 端口相容 sound、力封闭剪枝 admissible |
| WCC | O((|A|·m)·LP(|A|·m)) | O(|A|·m) | 摩擦 conformal 下界、鲁棒锥 |
| MRR | O(|M|·LP) 增量 | O(|M|) | 替换保端口、`ε_inc` 有界 |
| HMC | O(|H|·|A|) | O(|H|) | 包络/磨损保守 |

**正确性定理（Modular Grasp Composition Soundness）**
承接第 55 轮 (A29)–(A32)；新增：
**(A33)** 接触模态 `K_M` 与扳手锥 `W_M` 在证据邻域内局部可交换，摩擦 conformal 下界有效；
**(A34)** 端口契约在认证域上对任务相关接触语义**充分**（否则组合不成立）；
**(A35)** 模块替换保持后继端口匹配，增量扳手锥与全局重算误差 `≤ ε_inc`；
**(A36)** 硬件包络与磨损估计保守且覆盖执行时域。
则对通过 `MGC` 的装配 `A`：
```
P(静态抵抗 w_T | MGC.certified) ≥ (1−β_cov)(1−α)(1−β_hw) − ε_inc
P(抓取成功 | MGC.certified)     ≥ (1−β_cov)(1−α)(1−β_hw) − ε_inc − β_slip
```
其中 `β_slip` 为未建模接触动力学（滑移、滚动、软指变形、传感延迟）造成且**不可被力封闭消除**的残余项。与第 55 轮相比：`compat ≥ θ_a` 从"可行性"降级为"先决过滤"，力封闭 `m_fc ≥ m_min` 成为新的硬门；代价是证书更强依赖 `A34` 端口语义充分性。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 端口契约欠定义导致"假相容" | 高 | 接触模态标签 + 扳手锥硬门 + 端口残差审计 |
| 摩擦锥/接触点估计偏差致高估余量 | 高 | conformal 摩擦下界 + 鲁棒锥 + 滑移绊线 |
| 软指/滚动等未建模动力学 | 高 | `β_slip` 显式入界 + 在线滑移辨识 + 保守 `m_min` |
| 模块库碎片化、组合爆炸 | 中 | 端口哈希索引 + 分层剪枝 + 模态去重 |
| 硬件磨损/装配误差漂移 | 中 | `H_cert` 时效 + 定期标定 + 保守包络 |
| 增量重认证与全局不一致 | 中 | `ε_inc` 入界 + 关键装配周期全量复算 |

## 6. 本轮最大风险

**一句话**：模块化抓取把组合从"动作空间相交"提升为"端口契约 + 扳手力封闭"双验证，但其 soundness 关键依赖**端口契约对接触语义的充分性**——一旦端口只编码位姿/旋量/摩擦锥而漏掉接触模态切换、软指变形与滚动，两个模块会"端口相容且刚性模型下力封闭、运行时却系统性滑脱"，从而把模块复用的收益变成负迁移；故必须以 **接触模态标签 + conformal 摩擦下界的力封闭硬门 + 滑移绊线** 三重护栏，宁可判定"端口不足/证据不足"，也绝不把"能拼上"当作"抓得住"。

# 第 56 轮产物 · 创新点清单 v33：GroundEdge-GenSim+++++（GMD×MAM×WCC×MRR×HMC×MGC×MTA×MPA）

> 承接第 55 轮产物 v32。本轮把"整块技能 + 检索证据"升级为"**可拼装、可替换、可力封闭验证**"的模块化抓取体系，新增八项算子：
> - **GMD（Grasp Module Decomposition）**：把抓取轨迹按接触相位拆成带类型端口的接触模块；
> - **MAM（Modular Assembly Matching）**：端口相容图上的装配搜索，以力封闭作硬剪枝；
> - **WCC（Wrench Closure Certificate）**：conformal 摩擦下界 + 鲁棒接触锥的力封闭证书；
> - **MRR（Modular Repair & Reassembly）**：滑移触发、按端口保持的局部模块替换与增量重认证；
> - **HMC（Hardware-Module Coupling）**：可重构末端（指腹/指节/吸盘）的硬件-抓取联合契约；
> - **MGC（Modular Grasp Certificate）**：`(A,W_cert,m_fc,δ_I,ρ_lcb,RAC,H_cert)` 联合证书；
> - **MTA（Modular Transfer Algebra）**：跨物体/跨形态的端口重定向 + 力封闭重认证；
> - **MPA（Modular Port-Aware Planning）**：只走已认证装配、显式传播 `insufficient` 的规划器。

| `δ_I` | 接口残差（归一化最大违反量） |
| `G_M=(V,E,Π)` | 模块装配图：串行边 + 并行接触组 |
| `A=(V_A,E_A,Π_A)` | 抓取装配 |
| `W(A)=cone(∪W_i)` | 组合扳手锥 |
| `m_fc(A,w_T)` | 力封闭余量（`w_T+γB_1⊆W(A)` 的最大 `γ`） |
| `μ_lo` | conformal 摩擦下界 |
| `W_cert` | 含接触点/法向不确定性的鲁棒扳手锥证书 |
| `MGC(A)` | 模块化抓取证书 |
| `H_cert` | 硬件端口/包络/磨损证书 |
| `cost_sub` | 模块替换代价 |
| `ε_inc` | 增量重认证与全局重算的误差上界 |

### IP-129 MAM
```python
def match_assemblies(modules, task_port, eps, theta_a, m_min):
    G = build_port_graph(modules, eps)                 # 端口相容图
    out = []
    for A in enumerate_connected_assemblies(G, task_port, depth_max=D):
        if action_compat(A) < theta_a: continue        # 先决过滤（必要不充分）
        if not port_contract_ok(A): continue
        W = compose_wrench_cone(A)
        m = force_closure_margin(W, task_port.w_T)
        if m >= m_min:                                 # 力封闭硬门
            out.append((A, m))
    return sorted(out, key=lambda x: -x[1])
```

### IP-130 WCC
```python
def wrench_certificate(A, I, kappa, alpha, m_min, theta_cov):
    E = retrieve_contact_evidence(A, I)
    if coverage(E, A.contact_subspace) < theta_cov:
        return ('insufficient', request_evidence(A))
    mu_lo = conformal_lower(evidence_friction(E), alpha)
    W_rob = robust_cone(A, mu_lo, contact_uncertainty(E))
    m = force_closure_margin(W_rob, task_wrench(A))
    if m < m_min:
        return ('reject', explain_tight_direction(W_rob, m))
    return ('certified', W_cert(W_rob, m, mu_lo, E))
```

### IP-131 MRR
```python
def repair_on_slip(A, slip, lib, H, theta_I, m_min):
    i = localize_failed_module(A, slip)                # 反推端口/模块
    cands = substitute_candidates(lib, replace=i, preserve_ports=True)
    cands = [A2 for A2 in cands if hardware_coupling(H, A2).status == 'ok']
    A2 = argmin(cands, key=lambda x: cost_sub(A, x))
    W2, m2, dI2 = incremental_recompute(A, A2)         # 只重算受影响接触组
    if m2 >= m_min and dI2 <= theta_I:
        return ('repaired', A2, MGC(A2, W2, m2, dI2))
    return ('request_reassembly', explain(slip))
```

def hardware_coupling(H, A):

### IP-133 MGC
```python
def modular_grasp_certificate(A, I, kappa, alpha, H, m_min, theta_I):
    hw = hardware_coupling(H, A)
    if hw.status != 'ok':
        return ('reject', hw)
    wc = wrench_certificate(A, I, kappa, alpha, m_min, theta_cov)
    if wc.status != 'certified':
        return (wc.status, wc)                        # insufficient 显式传播
    dI = interface_residual(A)
    if dI > theta_I:
        return ('reject', 'port_mismatch', dI)
    return ('certified', MGC(A, wc.W_cert, wc.m, dI, wc.rho_lcb, wc.RAC, hw.H_cert))
```

### IP-134 MTA
```python
def modular_transfer(A_src, object_dst, lib, theta_cov, m_min):
    A_map = retarget_ports(A_src, object_dst)         # 保接触模态，适配位姿/尺寸
    E = retrieve_contact_evidence(A_map, I)
    if coverage(E, A_map.contact_subspace) < theta_cov:
        return ('insufficient', request_evidence(A_map))
    # 关键：在新物体上重算 W，而不是把源证书做刚体变换
    Wc = wrench_certificate(A_map, I, kappa, alpha, m_min, theta_cov)
    if Wc.status != 'certified':
        return ('reject', Wc)
    return ('ok', MGC(A_map, Wc.W_cert, Wc.m, interface_residual(A_map), ...))
```

### IP-135 MPA
```python
def port_aware_plan(task_desc, G, I, budget):
    frontier = PriorityQueue([(0, 'root', [])])
    while frontier:
        cost, node, path = frontier.pop()
        if satisfies(node, task_desc):
            return ('ok', path)
        for nxt, port in G.successors(node):
            cert = nxt.cert
            if cert.status == 'insufficient' and budget > 0:
                Gen_Sim(query=cert.query, budget=adaptive); budget -= 1
                cert = re_certify(cert)
            if cert.status != 'certified':
                continue                              # 未认证装配不入路
            frontier.push((cost + cost_sub(nxt) + cost_align(nxt), nxt, path + [nxt]))
    return ('no_certified_assembly', collect_insufficient_reasons())
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| GMD | O(|τ|·|K| + |M|·|A|) | O(|M|) | 相位切分完备、模态可判 |
| MAM | O(|M|²·|ports| + |A|·LP) | O(|M|²+|E|) | 端口相容 sound、力封闭剪枝 admissible |
| WCC | O((|A|·m)·LP(|A|·m)) | O(|A|·m) | 摩擦 conformal 下界、鲁棒锥 |
| MRR | O(|M|·LP) 增量 | O(|M|) | 替换保端口、`ε_inc` 有界 |
| HMC | O(|H|·|A|) | O(|H|) | 包络/磨损保守 |
| MGC | O(|A|·LP + k log k) | O(|A|+k) | 六条件全过才认证 |
| MTA | O(|A|·LP + log|E|) | O(|A|+k) | 新物体重算力封闭、覆盖门槛 |
| MPA | O((|V| log|V|+|E|)·B_gen) | O(|V|+|E|) | 仅认证装配连通、`insufficient` 显式传播 |

**正确性定理（Modular Grasp Composition Soundness）**
假设第 55 轮 (A29)–(A32) 成立；新增
**(A33)** 接触模态 `K_M` 与扳手锥 `W_M` 在证据邻域内局部可交换、摩擦 conformal 下界有效；
**(A34)** 端口契约在认证域上对任务相关接触语义充分；
**(A35)** 模块替换保持后继端口匹配，增量与全局扳手锥误差 `≤ ε_inc`；
**(A36)** 硬件包络与磨损估计保守且覆盖执行时域。
则对 `MGC(A)=certified`：
```
P(静态抵抗 w_T) ≥ (1−β_cov)(1−α)(1−β_hw) − ε_inc
P(抓取成功)     ≥ (1−β_cov)(1−α)(1−β_hw) − ε_inc − β_slip
```
关键：`m_fc` 直接给出静态力封闭保证；`β_slip` 覆盖滑移/滚动/软指变形/传感延迟等**力封闭无法消除**的动力学残差。与 v32 相比，`compat ≥ θ_a` 从可行性条件降为先决过滤，力封闭成为硬门；代价是更强依赖 `A34` 端口语义充分性。

- `MRR` 的替换只在端口保持与硬件可行时允许，且 `ε_inc` 必须计入证书。

## 5. 本轮最大风险

**一句话**：模块化抓取把组合从"动作空间相交"提升为"端口契约 + 扳手力封闭"双验证，但其 soundness 关键依赖**端口契约对接触语义的充分性**——一旦端口只编码位姿/旋量/摩擦锥而漏掉接触模态切换、软指变形与滚动，两个模块会"端口相容且刚性模型下力封闭、运行时却系统性滑脱"，从而把模块复用的收益变成负迁移；故必须以 **接触模态标签 + conformal 摩擦下界的力封闭硬门 + 滑移绊线** 三重护栏，宁可判定"端口不足/证据不足"，也绝不把"能拼上"当作"抓得住"。
