# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「语音交互」×「动态避障」）

> R69 教会闭环「去问」：把不确定性拆成 aleatoric/epistemic，用流匹配给出多峰动作，用注视/探针/问句去主动消解。但 R69 的 `g_ask` 是一个被理想化的信道——**准瞬时、单向、可无限续期、且回答天然可信**。真实世界里，一个问题的答案要走完「说—听—懂—做」的往返，而动态障碍不会等你问完；更糟，机器人自己一开口，人和障碍的行为就已经变了。
>
> 本轮两个灵感把这层理想化打掉：
> - **语音交互**不是「文本问答的声学外壳」，而是一个**全双工、有往返时延、会重叠、会打断、且自身携带韵律不确定性**的物理信道；它既是传感器（听），也是执行器（说）。
> - **动态避障**给出一个天然的时间账本：每一步都存在**承诺截止线**（commitment horizon），过了这条线，再正确的答案也来不及执行。时间不是背景，时间是安全裕度本身。
>
> 核心命题：**把「交互」从「信息价值问题」升级为「时间契约问题」——一次交互只有当它的最坏往返时延能被剩余安全余量吸收、且始终有一条不依赖对方配合的预留退路兜底时才被允许；机器人自己的话语则是一个必须与计划一致、且绝不把安全押在对方服从上的控制动作。** 命名 **DUET-RAS**（Deadline-aware Utterance-negotiated Evasion and Trajectory），取「两支舞者必须在同一拍子上让行」之意。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我还来得及开口吗、我说的和做的一致吗**」——不确定性不只是一句提问，还是一个必须在截止线前兑现的时间契约。

## 0. 直觉与动机

**灵感 1（语音是全双工、有时延、会打断的信道 → R69 的 `g_ask` 是零时延幻觉）**
直觉：R69 把问句塞进动作块，仿佛答案在同一时刻到达。真实语音交互有一个不可压缩的往返：机器人 TTS 出声 → 人听觉与理解 → 人决定并动作 → 机器人 ASR 与 NLU，p99 常在数百毫秒到数秒。动态避障里，这段时间障碍已经移动了决定性的距离。所以 R69 的 `VoI(g) − c(g)` 漏掉了最大的一项成本：**等待期间损失的安全裕度 `c_time`**。一个在信息上极值钱的问句，可能在时间上根本不可兑现。这不是给 R69 打一个超时补丁，而是把「交互」和「控制」重新放回**共享同一个时间预算**的耦合优化里——它们不是先后两件事，而是抢同一份 time-to-commit。

**灵感 2（动态避障 → 承诺截止线）**
直觉：避障的关键不是「有没有更优轨迹」，而是「**还剩多久之后就不存在安全轨迹**」。定义承诺截止线 `t_commit(s)`：超过它，任何控制都躲不开（由 C-RAS-WM 的认证前缀与可达集给出）。交互只能花掉 `Δ_safe = t_commit − t − L_g^p99 − τ_m` 这段余量；余量为负时，问得再对也没用。由此得到一条硬判据：**交互不是被「社交成本」限制，而是被「时间预算」限制**。这把 R69 的软成本 argmax 变成带硬截止的可行性问题。

**灵感 3（语音是执行器，不只是传感器 → 说话会改变别人的轨迹）**
直觉：对行人说「我从你左边过」，对方常会主动让半步；喊一声「注意」能让人停下。话语是**控制动作**，它改变的是联合状态，而不只是机器人的信念。于是需要三样东西：(a) 一个预测「被搭话的人会怎么反应」的社会响应模型；(b) 一条诚实约束——**说出去的话必须和真正要执行的计划一致**（不能嘴上说停、脚下不停）；(c) 一条防御性铁律——**安全永远不能建立在对方服从之上**。机器人必须先算好一条「无论对方怎么反应都安全」的预留退路，再决定要不要开口；话语只能扩张可选项，不能替代退路。

**灵感 4（语音与运动学失败模式互补 → 用身体验证语言）**
直觉：语音在遮挡时仍可用（看不见但听得见），却在噪声、重放、语音克隆、超声波注入、旁人冒充时失效；视觉/运动学在噪声中稳健，却在遮挡时失效。两者正交。因此「说了让行」必须由「身体确实在让」来交叉验证；口型与声源方向必须对齐到同一个可见说话人，才能排除重放与不可听注入。这正是 R69「k 个正交证据源一致」纪律在**语音-身体**这一对上的落地：**一段话只有在身体作证时才算证据**。

**灵感 5（韵律与接地 → 回答本身也有不确定性，沉默不是同意）**
直觉：同一个「行」，犹豫的「呃……行吧」和干脆的「行」不是同一个证据；韵律（基频方差、能量、填充词、响应时延）携带置信度。更危险的是交互性本身：人可能没听见（无接地）、可能只是客套、可能被机器人逼着让路。**在截止线的压力下，系统最容易把「没有反对」读成「同意」**。所以本轮必须交付韵律置信折扣、接地超时、以及「沉默/客套默认不定案」的证据纪律。否则 R70 会把 R69 的「诚实的不知道」升级成「被时间逼出来的假共识」。

## 1. 形式化定义（增量：定义 310–327）

**定义 310（DUET-RAS 总览与四不变式）** `DUET-RAS = (VCG, CDIA, RRG, SRA, VBN, PGU, UPC, APM, RAS-WM‡)`。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **截止线-余量不变式**：任何交互须满足 `Δ_safe(t) ≥ 0`，且预留退路 `σ_safe` 在**所有**对方响应下安全；
(iii) **双向可信度**：机器人话语须话语-计划一致（UPC），人类回答须语音-身体一致（VBN）且接地；任一侧不可信，则该消息视为无证据；
(iv) **社会非胁迫**：话语不得要求人类承担超过 `ε_h` 的风险，不得以紧迫感诱导让行。

**定义 311（语音信道模型 VCG）** 入站 `y_in = ASR(mic(t))`，出站 `u = TTS(text)`。往返时延 `L_g = L_out(u) + L_react(h) + L_in(y)`，取 p99。信道全双工：机器人说话时可被打断（barge-in），打断优先级高于一切非安全动作。接地指示 `gr(t)∈{0,1}`（收到附和、应答或明确的动作响应）。语音不是文本：观测含韵律特征 `ρ`（F0 轨迹、能量、填充词率、停顿）。

**定义 312（承诺截止线与交互余量 CDIA）** 由 C-RAS-WM‡ 的认证前缀给出 `t_commit(s)`：最晚仍需做出不可撤销避让决策的时刻（等价地 `t + k_commit·Δt`）。交互余量
`Δ_safe(t) = t_commit(s) − t − L_g^p99 − τ_m`。
信息动作 `g` 可行 ⇔ `Δ_safe(t) ≥ 0` 且 `σ_safe` 已认证。

**定义 313（预留退路 RRG）** 在时刻 `t` 计算 `σ_safe(t)`，满足：对任意人类响应 `h`（服从、无视、反向、欺骗），执行 `σ_safe(t)` 的碰撞概率 ≤ `ε_safe`。交互只允许消耗「执行 `σ_safe` 不需要」的那部分余量；`σ_safe` 在交互期间持续可执行（anytime retreat）。

**定义 314（话语作为控制动作 SRA）** 话语 `u ∈ 𝒰` 经社会响应算子 `R_u(·|s_t, x_h)` 改变人类未来策略；联合转移 `P(s_{t+1}|s_t, a_t, u_t)`。话语的「控制收益」定义为它使安全集扩张的量，而非它提供的信息量。**非可地址主体（车、动物、无生命滚动体）不进入 `𝒰`。**

**定义 315（可地址性 addr）** `addr(x_h) = P(能感知 ∧ 能理解 ∧ 能响应)`。仅当 `addr ≥ τ_addr` 时允许语音协商；否则退回 R69/R68 纯避障。可地址性是语音层的作用域门控。

**定义 316（韵律置信 PGU）** 从 `ρ` 估计回答可靠度 `κ(y) ∈ [0,1]`（犹豫、填充词、超长停顿、弱能量 → `κ↓`）。答案以噪声信道并入后验：用温度 `α(κ)` 的似然 `P(y|M)^{α(κ)}` 更新模式后验；`κ→0` 时更新退化为恒等。

**定义 317（语音-身体一致性 VBN）** 令 `intent(y)` 为话语声明的意图，`kin(h)` 为身体运动学预测（轨迹、朝向、步态）。定义 `c_vb = 1[agreement(intent(y), kin(h)) ≥ τ_vb]`。语音与身体冲突 ⇒ 该回答不得作为证据（R69 证据纪律的语音实例）。

**定义 318（接地与超时）** 出站话语后若在 `T_g` 内无接地（无附和、无响应动作、无可见朝向改变），话语视为**未送达**，不得据此放松任何风险，并记一次「无效发声」进入审计。

**定义 319（话语-计划一致性 UPC）** 设机器人已承诺计划 `σ`、声称 `u`。要求 `u` 与 `σ` 的可观察行为一致（不说「我停」而继续前进），且不要求人类承担 `> ε_h` 的风险。`UPC(σ,u)=1`，否则 0；`UPC=0` 时禁止发声。

**定义 320（双向可信度与时间调整 VoI）**
`cred = c_robot(UPC) · c_human(c_vb · κ · gr)`；
`VoI_time(g) = VoI(g)·cred − c_social(g) − c_time(g)`，
其中 `c_time(g)` 为等待 `L_g` 期间安全裕度的期望损失（由可达集收缩度量）。仅当 `VoI_time > 0` 且 `Δ_safe ≥ 0` 才交互。**`cred=0 ⇒ VoI_time ≤ 0`，退化为不交互。**

**定义 321（声学投毒模型 APM / ℰ_voice）** 重放/语音克隆（TTS spoof）、超声波不可听指令注入、强噪声掩蔽导致 ASR 幻觉、旁观者冒充被协商主体、以紧迫语气实施社会工程。并入 AIC：`ℰ_DUET = ℰ_FLUID × ℰ_voice`。防御：声源方向须与可见口型对齐（provenance/liveness），回答须身体作证，协商主体绑定（addressee binding）。

**定义 322（证书 J_DUET）** `J_DUET = (J_FLUID, Δ_safe_p05, L_g_p99, cred, grounding_rate, c_vb_rate, UPC_hash, addr, barge_in_count, duet_ver)`。Valid ⇔ `Valid(J_FLUID) ∧ Δ_safe_p05 ≥ 0 ∧ UPC=1 ∧ APM 检测未触发`。

**定义 323（退化阶梯）** 当 `Δ_safe<0`、`addr<τ_addr`、未接地、`UPC=0`、VBN 冲突或 APM 告警时，DUET 输出**逐指令等于 R69 的「不交互」路径**；R69 再在 `VoI≤成本 / ECE 越界 / 缓变故障` 时逐指令等于 R68。三级严格包含：`R68 ⊂ R69 ⊂ DUET`。

**定义 324（安全集扩张与非依赖性）** 令 `𝒮_safe(t)` 为不依赖人类配合的安全状态集。DUET 仅允许 `σ_negotiated ∈ 𝒮_safe ⊕ Δ`，其中 `Δ` 由已接地的协商产生，且扩张量满足 `|Δ| ≤ |𝒮|·(gr·c_vb·UPC)`。**永不允许 `σ_negotiated` 的唯一安全依据是「对方会让」**。

**定义 325（时延-价值衰减）** `VoI_time` 关于 `Δ_safe` 单调不增：存在临界余量 `S*`，当 `Δ_safe < S*` 时对任意 `g` 有 `VoI_time(g) ≤ 0`。`S*` 由模态间距、到达时间差与响应时延分布共同决定。

**定义 326（节奏与长时程）** 单位时间发声 ≤ 1、同一意图重复抑制、交互疲劳与社交规范约束；交互日志用于下一轮的成本先验（继承 R69 定义 303）。

**定义 327（对 R69 时间成本的最小修正）** R69 的 `argmax_g[VoI−c]` 是 DUET 在 `L_g→0、cred→1、c_time→0` 时的极限；即 R69 =「零时延、完全可信语音」边界上的 DUET。

## 2. 关键算法骨架

```python
# IP-264 VCG：全双工语音信道（时延 p99 + 打断抢占）
class VoiceChannelGovernor:
    def p99_round_trip(self, u, humans):
        return self.L.out_p99(u) + max(self.L.react_p99(h) for h in humans) + self.L.in_p99()
    def speak_and_listen(self, u, deadline):
        self.tts(u)
        return self.asr.listen_until(min(deadline, self.t + T_G))
    def barge_in(self, mic):                        # 任何时刻可被打断
        return detect_interrupt(mic)                # 优先级 > 非安全动作

# IP-265 CDIA + IP-266 RRG：先算退路与余量，没有时间就不开口
def admissible(s, cwm, vcg, u):
    retreat = cwm.reserved_retreat(s)               # σ_safe：所有响应下安全
    if not cwm.certify(retreat): return False, None
    t_commit = cwm.commitment_horizon(s)            # C-RAS-WM‡ 认证前缀
    delta_safe = t_commit - s.t - vcg.p99_round_trip(u, s.humans) - TAU_M
    return (delta_safe >= 0), retreat

# IP-267 SRA + 定义 315：只有可地址主体才进入协商
def addressable(h): return h.addr >= TAU_ADDR

# IP-268 VBN + IP-269 PGU + 定义 318：接地、韵律、身体三者同时成立才算证据
def credible_answer(y, h, t0):
    gr    = y.grounded or (y.t - t0 <= T_G and y.backchannel)
    kappa = prosody_confidence(y.rho)
    c_vb  = agreement(intent(y), kinematics_predict(h, horizon=y.t - t0))
    return (gr and c_vb and kappa >= TAU_KAPPA), kappa, c_vb

# IP-270 UPC：话语-计划一致 + 不胁迫
def utterance_ok(u, sigma):
    return plan_consistent(u, sigma) and human_risk(u) <= EPS_H

# IP-271 TVoI：把「等待的时间」计入成本
def time_adjusted_voi(g, modes, s, vcg):
    cred = float(utterance_ok(g.text, s.sigma)) * s.cred_human
    return voi(modes, g) * cred - social_cost(g) - lost_margin_cost(g, s, vcg)

# IP-274 主闭环：先退路、再开口、再验证、最后非依赖地选方案
def DUET_RAS_round(M, obs):
    z, o = M.mtm.forward(obs); c, U_cal, _ = M.cof.step(o)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes = M.aud.decompose(M.fmp.sample(o, K), z)
    slow = M.fma.detect(o)                          # 继承 R69 第二意见
    # 1) 计算退路与余量；时间不够就没有候选
    ok, retreat = admissible(s, M.cwm, M.vcg, "candidate")
    cands = [g for g in M.mint.candidates(modes)
             if addressable(g.target) and utterance_ok(g.text, s.sigma)]
    g = max(cands, key=lambda g: time_adjusted_voi(g, modes, s, M.vcg), default=None)
    if (not ok) or g is None or time_adjusted_voi(g, modes, s, M.vcg) <= 0:
        return R69_round(M, obs)                    # 逐指令退化
    # 2) 开口并等；期间 retreat 持续可执行，超时/打断即放弃
    ok, retreat = admissible(s, M.cwm, M.vcg, g.text)
    y = M.vcg.speak_and_listen(g.text, deadline=s.t + max(0.0, delta_safe_of(s, M.vcg, g)))
    credible, kappa, c_vb = credible_answer(y, g.target, g.t0)
    # 3) 仅在双向可信 + 接地时更新；否则 U_epi 保持不变
    U_epi_after = M.pgu.update(modes, y, kappa) if credible else U_epi
    # 4) 安全：协商方案只是扩张；退路永远兜底（非依赖）
    sigma_neg = M.sra.plan(modes, y) if credible else None
    sigma = safer_of(sigma_neg, retreat)
    k = M.cwm.certified_prefix(sigma, s, wm_preds(sigma))
    lam = lam_floor(U_ale + (0.0 if credible else U_epi_after))
    # 5) 审计 + 证书
    M.vqa_d.submit_async(g, y, kappa, c_vb, delta_safe_of(s, M.vcg, g))
    return k, lam, sigma, (U_ale, U_epi_after)
```

## 3. 推导

**引理 19（时间成本主导性）** 设信息动作 `g` 的信息价值为 `V`，等待 `L_g` 期间安全裕度损失为 `c_time(L_g)`。若 `c_time` 关于 `L_g` 至少线性增长（可达集收缩速率 ≥ 相对接近速度），则存在 `L* = V/ḃ` 使 `L_g > L*` 时 `VoI_time<0`。系：**慢信道里「值钱的问题」也会变成「不值钱的问题」**——这解释了为何语音协商只对可及时响应的低速主体有效，对高速动态障碍几乎无效；此时正确动作不是「问得更好」，而是「直接退避」。

**引理 20（非依赖性安全）** 若策略仅在已接地且双向可信时采用 `σ_negotiated`，且 `σ_safe` 对所有响应安全，则对任意人类策略（含欺骗、无视、反向）风险 ≤ `max(risk(σ_safe), risk(σ_negotiated)|credible) = risk(σ_safe)`。即**协商不能提高最坏情况风险**。系：`σ_negotiated` 只允许在它同时被认证为不依赖对方的假设下使用。

**引理 21（语音-身体一致性的欺骗压缩）** 对重放/克隆/超声波注入，若攻击不改变说话者身体运动学，则 `c_vb=0` 以概率 ≥ `1−ε_cam` 被检出；对旁观者冒充，addressee binding 要求声源方向与可见口型对齐，误接受率 ≤ `ε_prov`。故语音欺骗的有效成功率被乘性压缩为 `δ_v·(ε_cam + ε_prov)`。

**引理 22（韵律折扣的信息上界）** 温度似然更新下，后验熵降 ≤ `α(κ)·(原始熵降)`；`κ=0` 时降为 0。系：**一个犹豫的回答最多只能消解它的置信度所允许的那部分 epistemic 不确定性**，这防止「被追问三次的含糊回答」被当成确证。

**定理 18（DUET 严格包含 R69）** 在 A99–A101 下，任意状态 `s`，DUET 的期望风险 ≤ R69；且当 `Δ_safe<0`、无地址、未接地、`UPC=0`、VBN 冲突或 APM 告警时两者逐指令相同。故 R69 是 DUET 在「`L_g→0` 且完全可信」边界上的退化；R68 再嵌套其内。安全侧不让步，效率侧获得安全集扩张。

## 6. 本轮最大风险

**一句话**：DUET 把「交互」变成一个带截止线的社会契约，而**在截止线压力下，系统最容易把「没被反对」误读为「被同意」**——机器人说了一句「我从你左边过」，对方没回头（未接地）、或只礼貌地「嗯」了一声（低 κ）、或身体其实正往左挪（`c_vb` 冲突），系统却可能因为 `Δ_safe` 正在变负而倾向采纳这条「看起来像同意」的证据；**于是开口本身制造了本不存在的让行，并把最后的安全裕度花在了这句没人真正回应的话上**。**说错，比不说更危险。**

**次级风险与缓解**：语音被重放/克隆/超声注入（声源-口型 provenance + VBN + 引理 21）；把安全押在对方服从上（RRG 预留退路 + 非依赖性铁律 + 引理 20）；高速障碍下仍硬要协商（CDIA 硬截止 + 自动退化 R68）；韵律误判导致过度自信（PGU 温度折扣 + ECE 门控）；话语与计划不一致（UPC + 审计回灌）。

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** 零学习写操作继承；**截止线-余量不变式**（`Δ_safe≥0` 且退路对所有响应安全）；**双向可信度**（UPC ∧ VBN ∧ 接地，否则视为无证据）；**社会非胁迫**（不得要求人类承担 > ε_h 风险）。

**定义 321–323（APM / 证书 / 退化阶梯）** ℰ_voice 含重放、克隆、超声注入、掩蔽、冒充、社会工程；`J_DUET` 并入时延/接地/一致性/话语哈希；任一安全条件不满足 ⇒ 逐指令退化 R69 ⇒（其内部）退化 R68。

class VoiceChannelGovernor:
    def p99_round_trip(self, u, humans):
        return self.L.out_p99(u) + max(self.L.react_p99(h) for h in humans) + self.L.in_p99()
    def speak_and_listen(self, u, deadline):
        self.tts(u)
        return self.asr.listen_until(min(deadline, self.t + T_G))
    def barge_in(self, mic):
        return detect_interrupt(mic)                # 优先级 > 非安全动作

# IP-265 CDIA + IP-266 RRG
def admissible(s, cwm, vcg, u):
    retreat = cwm.reserved_retreat(s)               # σ_safe：所有响应下安全
    if not cwm.certify(retreat): return False, None
    t_commit = cwm.commitment_horizon(s)
    delta_safe = t_commit - s.t - vcg.p99_round_trip(u, s.humans) - TAU_M
    return (delta_safe >= 0), retreat

# IP-267 SRA / IP-268 VBN / IP-269 PGU / 定义 318
def addressable(h): return h.addr >= TAU_ADDR

def credible_answer(y, h, t0):
    gr    = y.grounded or (y.t - t0 <= T_G and y.backchannel)
    kappa = prosody_confidence(y.rho)
    c_vb  = agreement(intent(y), kinematics_predict(h, horizon=y.t - t0))
    return (gr and c_vb and kappa >= TAU_KAPPA), kappa, c_vb

# IP-270 UPC
def utterance_ok(u, sigma):
    return plan_consistent(u, sigma) and human_risk(u) <= EPS_H

# IP-271 TVoI
def time_adjusted_voi(g, modes, s, vcg):
    cred = float(utterance_ok(g.text, s.sigma)) * s.cred_human
    return voi(modes, g) * cred - social_cost(g) - lost_margin_cost(g, s, vcg)

# IP-274 主闭环
def DUET_RAS_round(M, obs):
    z, o = M.mtm.forward(obs); c, U_cal, _ = M.cof.step(o)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes = M.aud.decompose(M.fmp.sample(o, K), z)
    slow = M.fma.detect(o)
    ok, retreat = admissible(s, M.cwm, M.vcg, "candidate")
    cands = [g for g in M.mint.candidates(modes)
             if addressable(g.target) and utterance_ok(g.text, s.sigma)]
    g = max(cands, key=lambda g: time_adjusted_voi(g, modes, s, M.vcg), default=None)
    if (not ok) or g is None or time_adjusted_voi(g, modes, s, M.vcg) <= 0:
        return R69_round(M, obs)                    # 逐指令退化
    ok, retreat = admissible(s, M.cwm, M.vcg, g.text)
    y = M.vcg.speak_and_listen(g.text, deadline=s.t + max(0.0, slack(s, M.vcg, g)))
    credible, kappa, c_vb = credible_answer(y, g.target, g.t0)
    U_epi_after = M.pgu.update(modes, y, kappa) if credible else U_epi
    sigma_neg = M.sra.plan(modes, y) if credible else None
    sigma = safer_of(sigma_neg, retreat)            # 非依赖：退路兜底
    k = M.cwm.certified_prefix(sigma, s, wm_preds(sigma))
    lam = lam_floor(U_ale + (0.0 if credible else U_epi_after))
    M.vqa_d.submit_async(g, y, kappa, c_vb, slack(s, M.vcg, g))
    return k, lam, sigma, (U_ale, U_epi_after)

## 4. 推导

**引理 19（时间成本主导性）** `c_time` 关于 `L_g` 至少线性增长（收缩速率 ≥ 相对接近速度），则存在 `L* = V/ḃ`，`L_g > L*` 时 `VoI_time<0`。系：慢信道里「值钱的问题」也会翻负——高速动态障碍应立即退避而非协商。

**引理 20（非依赖性安全）** 若仅在接地且双向可信时采用 `σ_negotiated`，且 `σ_safe` 对所有响应安全，则任意人类策略下风险 ≤ `risk(σ_safe)`。系：**协商不能提高最坏情况风险**。

**引理 21（欺骗压缩）** 重放/克隆/超声注入不改变说话者身体运动学 ⇒ `c_vb=0` 以概率 ≥ `1−ε_cam` 检出；冒充须声源方向与可见口型对齐，误接受 ≤ `ε_prov`。有效欺骗成功率 ≤ `δ_v·(ε_cam+ε_prov)`。

**引理 22（韵律折扣上界）** 温度似然下后验熵降 ≤ `α(κ)·(原始熵降)`，`κ=0` 时降为 0。系：含糊回答最多消解其置信度允许的部分。

**定理 18（DUET 严格包含 R69）** A99–A101 下任意状态风险 ≤ R69；当 `Δ_safe<0`、无地址、未接地、`UPC=0`、VBN 冲突或 APM 告警时逐指令相同。`R68 ⊂ R69 ⊂ DUET`；安全不让步，效率获安全集扩张。

**定理 19（开口的时机安全性）** 先认证 `σ_safe`、只花非退路余量、barge-in 即时抢占 ⇒ 控制连续无突变；交互失败/超时/被投毒时 `λ`、`k` 单调退化为 R69；换装不变式（R68 定理 15）保持。

## 7. 本轮最大风险

**一句话**：DUET 把交互变成一个带截止线的社会契约，而**在截止线压力下，系统最容易把「没被反对」误读为「被同意」**——对方没回头（未接地）、只礼貌「嗯」一声（低 κ）、或身体其实正往左挪（`c_vb` 冲突），系统却可能因 `Δ_safe` 正在变负而倾向采纳这条「看起来像同意」的证据；**开口本身制造了本不存在的让行，并把最后的安全裕度花在了这句没人真正回应的话上**。**说错，比不说更危险。**

**次级风险与缓解**：重放/克隆/超声注入（provenance + VBN + 引理 21）；把安全押在对方服从上（RRG + 非依赖铁律 + 引理 20）；高速障碍硬要协商（CDIA 硬截止 + 自动退化）；韵律误判致过度自信（PGU 温度折扣 + ECE 门控）；话语与计划不一致（UPC + 审计回灌）。
