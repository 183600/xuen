# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「因果推理」×「视觉编码器」）

> R69 把不确定性一分为二（aleatoric / epistemic），并让系统学会「问」。但 R69 有一个从未被审计的前提：**所有模态、所有似然、所有 VoI，都条件在一个视觉编码器给出的 z_t 上**。如果这个编码器学到的是「背景/光照/纹理 ↔ 动作」的虚假相关，那么流策略吐出的多峰分布就不是世界的歧义，而是**编码器的幻觉**；R69 会拿着这份幻觉去追问、去认证、去盖上「已消解」的章。R69 自陈的最大风险——「问错，比不问更危险」——的根因不在流匹配，而在**视觉条件的因果有效性**。
>
> 本轮两个灵感正好对症：
> - **视觉编码器**不是一个黑箱特征提取器，而是一个可以被结构化的**因果表征**：把 z 拆成任务因果因子 z_C 与 nuisance 因子 z_N；
> - **因果推理**给出判据：真模态应在 do(C) 下按机制可预测地响应、在 do(N) 下保持稳定；只随 nuisance 出现的模态是**幻影**，必须被隔离（quarantine），不得进入 VoI。
>
> 核心命题：**把 R69 的「相关模态」升级为「因果认证模态」——用多环境不变性训练因果视觉编码器，用 nuisance bank 做表征空间反事实，用干预稳定性给每个模态发证书；只有通过证书的模态才参与 CVoI 与交互，认证失败则逐级退化到 FLUID / CALM / 基础 RAS。** 命名 **CAVIA-RAS**（Causal-interventional Visual Ambiguity certification for Risk-Adaptive Systems）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我看到的，配不配让我去问**」——先认证「看」，再决定「问」，最后才允许「做」。

## 0. 直觉与动机

**灵感 1（视觉编码器是 R69 的隐变量，也是它的单点故障）**
直觉：R69 把 o_t 编码成 z_t，随后所有东西——流速度场、模态权重、行为似然、慢变故障第二意见——都条件在 z_t 上。可 z_t 从来没有被审计过。一个只在白天数据上训练的编码器，可能把「路灯亮」当成「有人」；一个靠背景纹理区分场景的编码器，可能把「换了一条街」读成「换了一个任务」。这时流模型输出的多个模态不是世界在犹豫，而是**表征在漏光**。R69 的 VoI 越精确，越会把这种漏光放大成一次自信的错误提问。关键转变：**不确定性不是从策略开始，而是从表征开始**；要认证 U_epi，先认证孕育 U_epi 的 z_t。

**灵感 2（因果推理 → 真模态对 nuisance 不敏感、对 cause 敏感）**
直觉：相关性的模态分布 p(ξ|o) 回答「在这样的像素下动作通常是什么」；因果的模态分布 p(ξ|do(C=c)) 回答「如果我把世界的那件事改掉，动作会怎样」。真正的歧义属于后者：行人可能左转也可能右转，这是**因果变量**（意图）的歧义；而「树影让路口看起来像有两个行人」只是 nuisance。因果推理给出一条可操作的判据：**对 nuisance 做干预，幻影模态应当消失；对 cause 做干预，真模态应当按机制可预测地移动**。这把「模态可信吗」从一个统计标定问题（R69 的 ECE）升级为一个**干预稳定性**问题；两者正交，不能互相替代。

**灵感 3（视觉编码器 → 多环境不变性把 z 拆成 z_C 与 z_N）**
直觉：因果表征学习的老办法是「多环境 + 不变性」：在白天/夜晚、晴/雨、不同街区等环境里，真正因果的特征其预测关系不变，nuisance 特征随环境漂移。训练一个 (Φ_C, Φ_N) 分裂编码器，加环境风险方差惩罚（IRM/ICP 式）和 HSIC 解耦，再配一个 nuisance bank（跨环境交换 z_N）与反事实解码器，就能在表征空间里做便宜的 do(N=n)——不需要真的把车开到雨里。于是「因果干预」从昂贵的物理实验，变成一个**可缓存的表征算子**；因果推理第一次能以毫秒级进入实时闭环。

**灵感 4（把主动交互升级为「有因果针对性的干预」）**
直觉：R69 的「看/问/触」是信息动作，但没问「这个动作干预了 SCM 的哪条边」。凑近看是干预观测通道 O，问一句是干预报告通道 R，摸一下是直接接触因果因子 C。因果视角下，最有价值的信息动作是**能阻断当前后门路径**的那个：如果模态权重被环境 E 混杂（C ← E → O），那么换一个让 E 与 O 条件独立的视角，比多问一句更能消歧。于是 R69 的 VoI 升级为 **CVoI（因果信息增益）**，MINT 升级为 **CI²A（因果干预信息动作）**：先找混杂边，再选能切断它的干预。

**灵感 5（因果本身也会错 → 必须有一条诚实的退化链）**
直觉：因果模型不是免死金牌。SCM 可能漏变量、nuisance bank 可能覆盖不到测试分布、多环境不变性在只有两个环境时并不可识别。若把「因果认证」当成新的绝对真理，就会把 R69 的「统计幻觉」升级成「因果幻觉」——更自信、更危险。所以本轮必须同时交付：编码器证书 CEC（环境风险方差、解耦度、干预重构误差、覆盖度）、模态证书 CMC（nuisance 稳定性 + 机制一致性）、因果不变性检验 CIV，以及一条**严格嵌套的退化链** CAVIA → FLUID → CALM → base。认证不可信时，宁可退回 R69 的相关模态，也不让一个戴因果徽章的黑箱驱动交互。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（CAVIA-RAS 总览）** CAVIA-RAS = (CVE, V-SCM, IMCE, NBank, CVoI, CI²A, CIV, FMA-C, CEC, RAS-WM†)。三不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；V-SCM、nuisance bank、编码器只在离线审计中更新；
(ii) **认证门控**：未经 CEC 认证的编码器、未经 CMC 认证的模态，不得驱动 CVoI、交互或动作选择；
(iii) **安全单调退化**：认证失败时 λ 与认证前缀只允许向更保守方向移动，逐级退化为 FLUID（R69）→ CALM（R68）→ base。

**定义 311（视觉结构因果模型 V-SCM）** M = (V, U, F)，V = {E, C, N, O, A, Y}：环境 E、任务因果因子 C、nuisance N、观测 O、动作 A、结果 Y；结构方程 O = f_O(C, N, E)，A = f_A(C, ε_A)，Y = f_Y(A, C, E)。假设 **A99**：因果充分性（给定 E 后 C 与 A 无未观测混杂）、Markov 与忠实性、环境间 nuisance 分布有重叠但不同。E 为域标签（白天/夜晚、晴/雨、场景 id），只在离线训练与审计可见；测试时 E 不可观测，故所有因果量必须写成对 E 的边缘化形式。

**定义 312（因果视觉编码器 CVE）** Φ = (Φ_C, Φ_N)，z_C = Φ_C(o) ∈ ℝ^{d_C}，z_N = Φ_N(o) ∈ ℝ^{d_N}；共享视觉骨干（如冻结 DINOv2 + 轻量适配器）分双头。离线目标：
`L_CVE = E[ℓ(Y, f_A(z_C))] + β·Var_e[R_e(f_A∘Φ_C)] + γ·HSIC(z_C, z_N) + δ·‖o − Dec(z_C, z_N)‖² + η·L_env-adv(z_C)`
其中 Var_e 为各环境经验风险方差（IRM/ICP 式不变性），HSIC 为解耦惩罚，L_env-adv 用梯度反转去掉 z_C 中可预测 E 的分量（环境对抗）。运行时 Φ 冻结。

**定义 313（nuisance bank 与反事实视觉）** 离线收集各环境 nuisance 表征 𝒩_bank = {z_N^{(e,i)}}_{e,i}，并训练条件解码器 Dec。表征空间干预：
`do(N=n): ô = Dec(z_C, n)`；`do(C=c): ô = Dec(c, z_N)`。
物理干预只在训练/实验中使用；运行时只允许表征空间反事实，且必须通过重构误差门（定义 321）。为保证 OOD 安全，采样 n 时只取 bank 中与当前 z_N 最近邻的 k_b 个（覆盖优先，不做远处外推）。

**定义 314（模态因果敏感性）** 对 R69 的模态 m_k（定义 296），定义
`S_N(m_k) = E_{n~𝒩_bank}[1 − IoU(supp m_k(o), supp m_k(ô_n))]`（nuisance 不稳定性）；
`S_C(m_k) = E_{c'~p(C)}[1 − Match(m_k(o), m_k(ô_{c'}) | SCM)]`（对因果干预的机制一致性）。
其中 ô_n、ô_{c'} 由定义 313 生成；Match 用 SCM 的 f_A 预测模态在动作空间的落点，再与生成原型比较。S_N 低说明模态不随 nuisance 漂移；S_C 高说明模态确实由 C 驱动。注意这不是「模态是否变化」，而是「变化方向是否符合因果机制」。

**定义 315（因果模态证书 CMC 与隔离区）** 模态 m_k 获证 iff
`CMC_k = 1[S_N(m_k) ≤ τ_N] · 1[S_C(m_k) ≥ τ_C] · 1[ID(Φ_C) ≥ τ_id]`。
未获证模态进入隔离区 Q，只监控、不参与决策。若认证模态集 M_cert = ∅，U_epi 视为未消解，走保守退化；**不回退到 R69 的相关模态**（因为此时已知相关模态不可信）。

**定义 316（因果信息增益 CVoI）** 只在 M_cert 上计算：
`CVoI(g) = H(M_cert | o) − E_{y~p(·|do(g),o)}[H(M_cert | do(g),o,y)]`。
do(g) 表示信息动作对 O、C 或报告 R 的干预（定义 317），不是被动条件。由于去掉 nuisance 分量，一般有 CVoI(g) ≤ VoI(g)；差额即混杂带来的表观增益。

**定义 317（因果干预信息动作 CI²A）** 信息动作按干预目标分类：g_O（换视角/补光/移动以切断 E→O 后门）、g_C（探针/接触以直接观测因果因子）、g_R（提问以获取报告）。选择
`g* = argmax_g [CVoI(g) − c(g)]`，s.t. risk(g) ≤ ε_int；
优先选择能阻断当前最大后门路径、且使认证模态后验熵下降最多的动作；若 max ≤ 0 不交互。R69 的 MINT 是「所有模态都视为因果、g 只做被动观测」的退化特例。

**定义 318（因果不变性检验 CIV）** 若 Φ_C 的因果主张成立，则对任意 do(C=c)，预测分布应满足 `p(A | do(C=c), e) = p(A | do(C=c))`。检验统计量
`T_CIV = sup_{c,e,e'} W_2(p(A|do(c),e), p(A|do(c),e'))`；
T_CIV > τ_CIV ⇒ 编码器因果主张失效，CEC 置零。运行时用缓存的 T_CIV 与在线小样本监控，不在每个控制周期重算。

**定义 319（反事实流似然 FMA-C）** 扩展 R69 定义 301：分别计算 a_score(o)、a_score(o_cal)、a_score(ô_n)、a_score(ô_c)。定义
`Δa_N = |a_score(o) − a_score(ô_n)|`，`Δa_C = |a_score(o) − a_score(ô_c)|`。
健康的因果策略应满足 Δa_N ↓、Δa_C ↑；若 Δa_N ↑ 而 r_res、Δa 均正常，则行为似然本身被 nuisance 污染，R69 的 FMA 第二意见不可信。这给 R69 的「行为自洽」补上「因果自洽」维度。

**定义 320（因果最坏情形风险缩放）** `λ_causal = max_{c ∈ 𝒞_plausible} risk(M_cert, do(C=c))`；最终 `λ = max(λ_FLUID, λ_causal)`，且仅当 CEC=1 时启用 λ_causal。任何情况下 λ 不因因果认证而低于 R69 的 λ；R70 的收益不是「更敢做」，而是「更少问错、更少选错」，安全侧不做任何让步。

**定义 321（因果编码器证书 CEC）** `CEC = 1[Var_e(R_e) ≤ τ_env] · 1[HSIC ≤ τ_disent] · 1[T_CIV ≤ τ_CIV] · 1[‖o − Dec(z_C,z_N)‖² ≤ τ_rec] · 1[coverage(𝒩_bank) ≥ κ]`。CEC=0 ⇒ 禁用 CVoI/CI²A/CMC，直接退化为 FLUID。coverage 用测试 z_N 到 bank 的核距离分位衡量，是「因果干预是否还在数据支撑内」的诚实标尺。

**定义 322（因果幻觉干扰集 ℰ_causal）** 包括：测试期 nuisance 漂移（背景/光照/天气改变）、因果因子缺失或反事实不可达、SCM 误设（漏混杂/后门未识别）、以改变 nuisance 伪造因果证据的对抗攻击、bank 覆盖盲区。`ℰ_CAVIA = ℰ_FLUID × ℰ_causal`。

**定义 323（因果审计 VQAuditor-X 与证书 J_CAVIA）** 审计新增：模态证书是否被正确发放、CVoI 是否被混杂污染、CIV 是否被绕过、干预日志是否可重放、bank 覆盖是否越界。`J_CAVIA = (J_FLUID, cec, mode_cert_ratio, civ_stat, counterfactual_consistency, bank_coverage, scm_version, intervention_log_hash)`。`Valid ⇔ Valid(J_FLUID) ∧ CEC ∧ mode_cert_ratio ≥ κ_cert`。

**定义 324（隔离区与证据纪律）** Q 中的模态不得进入 CVoI、不得作为交互候选、不得作为动作选择依据；只在审计与离线复盘中保留。任何「因果认证」结论必须由至少两个环境或两条干预路径一致支持（**A100：认证可信度**），单环境不变性不得单独定案；这与 R69 的「k 个正交证据源」纪律叠加，而非替代。

**定义 325（离线因果更新与预算）** SCM、nuisance bank、Φ 的更新只发生在离线审计阶段；运行时只读。因果发现预算与交互预算分离，避免「为了认证而频繁打扰世界」；bank 扩充必须在版本化数据上完成，并回放旧环境以防遗忘。

**定义 326（四级严格退化链）** `CAVIA --CEC失败--> FLUID --CVoI≤成本或ECE越界--> CALM --永不交互--> base`。每一级在前一级失效时逐指令等价或更保守；安全侧不做让步，效率收益仅来自「更少地问错」。

## 3. 推导

**引理 19（幻影模态的 VoI 虚高）** 设观测模态集为 M = M_cert ∪ M_spur，幻影模态总权重 ŵ_S，且与认证模态在轨迹空间可分。则 R69 的相关模态熵满足 `H(M) = H(B_S) + (1−ŵ_S)·H(M_cert)`，其中 `H(B_S) = −ŵ_S log ŵ_S − (1−ŵ_S) log(1−ŵ_S)`。一次交互只能消解一个因果模态，幻影分量带来的表观增益至多 H(B_S)，而随机选到幻影的概率为 ŵ_S，故至少浪费 ŵ_S·c(g) 的交互成本；当 ŵ_S 接近 1/2 时虚高最大。系：**模态越容易被 nuisance 复制，R69 越倾向于「问一个不存在的东西」**。

**引理 20（CMC 对幻影模态的拒绝率）** 在 A99–A100 且 nuisance bank 覆盖测试 nuisance 支撑下，若 m 仅由 nuisance 驱动，则 E[S_N(m)] ≥ s_spur > τ_N；若 m 由 C 驱动，则 E[S_N(m)] ≤ s_cause < τ_N。由 Hoeffding，K_N 次 bank 采样下误接收与误拒绝概率均 ≤ `exp(−2K_N·Δ_N²)`（Δ_N 为均值到阈值的最近距离，变量范围归一化）。取 K_N 足够大可使幻影通过率 ≤ δ_N。系：配合 R69 的 k-源证据纪律，幻影追问率从 ŵ_S 降到 δ_N 量级。

**引理 21（多环境不变性下的因果父节点可识别性）** 在 A99、至少两个环境的 nuisance 分布不同、且 f_A 忠实于 C 的条件下，最小化环境风险方差的不变预测器 Φ_C 只依赖对 Y 的因果父节点：nuisance 依赖项因跨环境风险方差不一致而被排除。可识别误差满足 `E‖Φ_C − Φ_C*‖ ≤ O(√Var_e(R_e) + ε_recon)`（A100 的定量版）。**边界**：该引理不声称恢复完整 C，只声称恢复「对动作/结果有因果作用的因子」——对本任务足够，因为模态认证只关心动作相关因子；若存在未观测混杂或环境数不足，可识别性不成立，CEC 必须置零。

**引理 22（因果干预的信息回收）** 设模态身份 M 与环境 E 存在混杂路径 E→C、E→O。对任意信息动作 g，相关增益与干预增益之差可分解为混杂项与选择项；当 g 切断 E→O 后门（或对 E 分层）且不引入新的对撞时，`CVoI(g) ≥ VoI(g) + I(M;E) − ε_est`。系：混杂越强（I(M;E) 越大），R69 越会系统性低估「换视角/补光」这类 g_O 的价值；CI²A 恰好补上这块被相关 VoI 漏掉的信息。

**定理 18（CAVIA 严格包含 FLUID）** 在 A99–A100 与 CEC 健全下，对任意状态 s，CAVIA 的期望风险 ≤ FLUID；当 CEC=0、CVoI(g*)≤c(g*)、或 M_cert=∅ 时，两者逐指令相同，或 CAVIA 更保守。故 FLUID 是 CAVIA 在「无条件信任相关模态」边界上的退化；CAVIA 不通过降低 λ 换取收益，而通过减少错误交互与错误模态选择获得收益。

**定理 19（因果交互的安全与无突变）** CI²A 的每个候选 g 先过 C-RAS-WM 前缀认证（继承定义 302），故物理风险 ≤ ε_int；g 只改变「选哪个认证模态」，不改变安全包络；CEC/CIV 失败时 λ 单调不降、认证前缀只缩不扩；R68 定理 15 的换装不变式保持 ⇒ 控制连续、无突变。

**定理 20（因果证书的幻影残留上界）** 在 A100 下，设先验幻影比例为 p_sp，误接收率 α ≤ δ_N，因果模态误拒率 β ≤ δ_R，则被 CMC 接收的模态中幻影的后验比例（FDR）满足
`FDR ≤ p_sp·α / [p_sp·α + (1−p_sp)(1−β)]`。
CEC 放行的编码器其因果不变性违反概率 ≤ δ_C。**当 SCM 误设或 bank 覆盖不足时该上界失效**——这正是本轮最大风险；coverage 项只能降低、不能消除它。

## 6. 本轮最大风险

**一句话**：CAVIA-RAS 的全部收益押在「视觉 SCM 与 nuisance bank 的因果主张可信」这一前提上——**若 SCM 误设（漏掉关键混杂）或 bank 覆盖不到测试分布，CMC 会以高置信度给幻影模态发「因果证书」，CEC 又无法在分布外识别自己的盲区；于是系统不是少问了，而是带着因果徽章、更自信地问错——「因果认证」把 R69 的统计幻觉洗成了更难质疑的因果幻觉。**

**次级风险与缓解**：
1. **多环境不足导致不可识别** → 明确 A99/A100 边界 + CEC 置零 + 退化为 FLUID，不宣称超出数据的因果结论；
2. **反事实解码器失真** → 重构误差门 + 只在 bank 近邻内做 do(N) + E307 反事实一致性；
3. **去混杂损害真模态** → E302 真歧义保持 + 认证模态为空时保守而非强行坍缩；
4. **认证开销击穿实时预算** → 仅歧义路径触发、bank 最近邻、K_N=K_C=2、缓存 CIV；
5. **因果对抗/投毒** → ℰ_causal 对抗训练 + 双环境/双路径证据纪律 + VQAuditor-X 可重放审计；
6. **因果模型版本漂移** → 离线版本化更新 + 回放旧环境 + 运行时只读，绝不边跑边学。

## 2. 形式化定义（要点版）

**定义 310（总览与三不变式）** CAVIA-RAS = (CVE, V-SCM, IMCE, NBank, CVoI, CI²A, CIV, FMA-C, CEC, RAS-WM†)；实时零学习写（因果结构仅离线更新）；认证门控（未过 CEC 的编码器、未过 CMC 的模态不得驱动决策）；安全单调退化（失败时只向更保守方向移动，逐级退回 FLUID→CALM→base）。

**定义 311（V-SCM）** V = {E,C,N,O,A,Y}，`O=f_O(C,N,E)`、`A=f_A(C,ε_A)`、`Y=f_Y(A,C,E)`。A99：因果充分性（给定 E 后 C 与 A 无未观测混杂）、Markov/忠实性、环境 nuisance 分布不同但有重叠。E 仅离线可见，测试时边缘化。

**定义 312（CVE）** `L_CVE = E[ℓ(Y,f_A(z_C))] + β·Var_e[R_e] + γ·HSIC(z_C,z_N) + δ·‖o−Dec(z_C,z_N)‖² + η·L_env-adv(z_C)`。共享冻结视觉骨干 + 双头；运行时冻结。

**定义 313（NBank 与反事实）** 离线建 `𝒩_bank`；运行时 `do(N=n): Dec(z_C,n)`、`do(C=c): Dec(c,z_N)`；n 只取当前 z_N 的近邻（k_b），避免 OOD 外推；反事实必须过重构误差门。

**定义 314–315（模态因果敏感性与 CMC）** `S_N = E_n[1−IoU(supp m_k(o), supp m_k(ô_n))]`，`S_C = E_c[Match(m_k(o), m_k(ô_c)|SCM)]`；`CMC_k = 1[S_N≤τ_N]·1[S_C≥τ_C]·1[ID(Φ_C)≥τ_id]`。未获证进 Q；`M_cert=∅` 时 U_epi 视为未消解，走保守退化，不回退相关模态。

**定义 316–317（CVoI 与 CI²A）** 只在 M_cert 上算 `CVoI(g) = H(M_cert|o) − E[H(M_cert|do(g),o,y)]`；信息动作按干预边分类 g_O/g_C/g_R，`g*=argmax[CVoI−c]` s.t. 安全与预算，优先切断最大后门路径。R69 的 MINT 是「全部模态视为因果、g 只做被动观测」的退化特例。

**定义 318–319（CIV 与 FMA-C）** `T_CIV = sup_{c,e,e'} W_2(p(A|do(c),e), p(A|do(c),e'))`，越界即 CEC=0；`Δa_N=|a_score(o)−a_score(ô_n)|`、`Δa_C=|a_score(o)−a_score(ô_c)|`，健康策略应 Δa_N↓、Δa_C↑。

**定义 320–321（因果风险与 CEC）** `λ_causal = max_c risk(M_cert, do(C=c))`；`λ = max(λ_FLUID, λ_causal)` 仅在 CEC=1 时启用，任何情况下 λ 不低于 R69；`CEC = 1[Var_e(R_e)≤τ_env]·1[HSIC≤τ_disent]·1[T_CIV≤τ_CIV]·1[recon≤τ_rec]·1[coverage≥κ]`，CEC=0 直接退回 FLUID。

**定义 322–323（干扰集与证书）** `ℰ_CAVIA = ℰ_FLUID × ℰ_causal`，新增 nuisance 漂移、SCM 误设、因果对抗、bank 覆盖盲区；`J_CAVIA = (J_FLUID, cec, mode_cert_ratio, civ_stat, counterfactual_consistency, bank_coverage, scm_version, intervention_log_hash)`，`Valid ⇔ Valid(J_FLUID) ∧ CEC ∧ mode_cert_ratio ≥ κ_cert`。

```python
    freeze_all()                                       # 运行时零学习写

# IP-266 IMCE：干预式模态认证
def certify_modes(modes, o, z_c, z_n, policy, bank, scm):
    cert, quarantine = [], []
    for m in modes:
        s_n = mean(1 - iou(support(m, o), support(m, policy.decode(z_c, n)))
                   for n in bank.nearest(z_n, K_N))     # do(N=n)
        s_c = mean(mech_match(m, policy.decode(c, z_n), scm)
                   for c in scm.sample_causal(K_C))     # do(C=c)
        ok = (s_n <= TAU_N) and (s_c >= TAU_C) and (id_score() >= TAU_ID)
        (cert if ok else quarantine).append(m)
    return cert, quarantine

# IP-268 CVoI：只在认证模态上算干预增益
def causal_voi(cert, g, o, bank):
    if not cert: return -inf
    return entropy(mode_weights(cert)) - expected_entropy_after(cert, g, o, bank)

# IP-275 主闭环
def CAVIA_RAS_round(M, obs):
    z_c, z_n = M.cve(obs)
    if not M.cec.check(z_c, z_n, obs):
        return FLUID_RAS_round(M.fluid, obs)            # 严格退回 R69
    samples = M.fmp.sample((z_c, z_n), K=M.adaptive_k(z_c, z_n))
    modes   = M.aud.decompose(samples)
    cert, Q = M.imce.certify(modes, obs, z_c, z_n, M.fmp, M.bank, M.scm)
    if not cert:
        return conservative_round(M, modes, Q)          # 不回退到相关模态
    g = M.ci2a.choose(cert, obs, M.budget)
    if g is not None:
        M.cia.update_belief(cert, M.cia.execute(g, do=M.target_of(g)))
    U_ale = sum(w[k] * trace(cov(cert[k])) for k in cert)
    U_epi = entropy(mode_weights(cert))
    lam = max(M.fluid.lam_floor(U_ale + U_epi), M.causal_risk(cert))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., M.vt.wm_preds)
    if M.civ.fail or M.fma_c.nuisance_dominant:
        lam = max(lam, M.fluid.lam)                     # 单调不降，回 R69 保守
    mode = select_mode(cert, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_x.submit(g, cert, Q, M.civ.stat, M.fma_c.metrics)
    return k, lam, mode, (U_ale, U_epi, Q)
```

## 4. 推导

**引理 19（幻影模态的 VoI 虚高）** M = M_cert ∪ M_spur，幻影总权重 ŵ_S，且轨迹空间可分，则 `H(M) = H(B_S) + (1−ŵ_S)H(M_cert)`，`H(B_S) = −ŵ_S log ŵ_S − (1−ŵ_S)log(1−ŵ_S)`。一次交互只能消解一个因果模态；幻影带来的表观增益至多 H(B_S)，随机选到幻影的概率为 ŵ_S，至少浪费 ŵ_S·c(g)。系：模态越容易被 nuisance 复制，R69 越倾向于问一个不存在的东西。

**引理 20（CMC 对幻影的拒绝率）** 在 A99–A100 且 bank 覆盖测试 nuisance 支撑下：nuisance 驱动模态的 E[S_N] ≥ s_spur > τ_N，因果模态的 E[S_N] ≤ s_cause < τ_N；K_N 次采样下误接收/误拒绝 ≤ `exp(−2K_N·Δ_N²)`。取 K_N 足够大可令幻影通过率 ≤ δ_N。系：配合 R69 的 k-源证据纪律，幻影追问率从 ŵ_S 降到 δ_N 量级。

**引理 21（多环境不变性的因果父节点可识别性）** 在 A99、≥2 个环境 nuisance 分布不同、f_A 忠实于 C 时，最小化环境风险方差的不变预测器只依赖对 Y 的因果父节点；可识别误差 `E‖Φ_C−Φ_C*‖ ≤ O(√Var_e(R_e)+ε_recon)`。**边界**：不声称恢复完整 C，只恢复动作相关因果因子；未观测混杂或环境数不足时可识别性不成立，CEC 必须置零。

**引理 22（因果干预的信息回收）** 设 E 混杂 C 与 O。当 g 切断 E→O 后门（或对 E 分层）且不引入新对撞时，`CVoI(g) ≥ VoI(g) + I(M;E) − ε_est`。系：混杂越强，R69 越会低估「换视角/补光」这类 g_O 的价值；CI²A 补上这块被相关 VoI 漏掉的信息。

**定理 18（CAVIA 严格包含 FLUID）** 在 A99–A100 与 CEC 健全下，CAVIA 的期望风险 ≤ FLUID；当 CEC=0、CVoI(g*)≤c(g*) 或 M_cert=∅ 时两者逐指令相同或 CAVIA 更保守。FLUID 是 CAVIA 在「无条件信任相关模态」边界上的退化；CAVIA 不靠降低 λ 换收益，而靠减少错误交互与错误模态选择。

**定理 19（因果交互安全与无突变）** CI²A 的 g 先过 C-RAS-WM 前缀认证，物理风险 ≤ ε_int；g 只改变「选哪个认证模态」，不改安全包络；CEC/CIV 失败时 λ 单调不降、前缀只缩不扩；R68 定理 15 的换装不变式保持 ⇒ 控制连续。

**定理 20（因果证书的幻影残留上界）** 在 A100 下，设先验幻影比例 p_sp、误接收 α≤δ_N、因果模态误拒 β≤δ_R，则 `FDR ≤ p_sp·α / [p_sp·α + (1−p_sp)(1−β)]`；CEC 放行的编码器其不变性违反概率 ≤ δ_C。SCM 误设或 bank 覆盖不足时上界失效——coverage 只能降低、不能消除。

## 7. 本轮最大风险

**一句话**：CAVIA-RAS 的全部收益押在「视觉 SCM 与 nuisance bank 的因果主张可信」这一前提上——**若 SCM 误设（漏掉关键混杂）或 bank 覆盖不到测试分布，CMC 会以高置信度给幻影模态发「因果证书」，CEC 又无法在分布外识别自己的盲区；系统于是不是少问了，而是带着因果徽章、更自信地问错——「因果认证」把 R69 的统计幻觉洗成了更难质疑的因果幻觉。**

**次级风险与缓解**：多环境不足导致不可识别（A99/A100 边界 + CEC 置零 + 退 FLUID）；反事实解码器失真（重构门 + bank 近邻 + E307）；去混杂损害真模态（E302 + 认证为空时保守而非强行坍缩）；认证开销击穿实时预算（仅歧义路径 + K_N=K_C=2 + 缓存 CIV）；因果对抗/投毒（ℰ_causal 对抗训练 + 双环境/双路径纪律 + VQAuditor-X 可重放）；因果模型版本漂移（离线版本化 + 回放旧环境 + 运行时只读）。
