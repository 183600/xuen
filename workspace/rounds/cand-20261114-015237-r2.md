# 第 70 轮（承接第 69 轮「FLUID-RAS 不确定性二分 × 主动交互」IP-253~263；本轮灵感：「手眼标定」×「无刷电机」）

> R69 把不确定性一分为二，并学会了向外求证：看不清就看、拿不准就问、质感不明就摸。但它默认了两件从未被检查的事——**你看的地方和你动的地方是同一个坐标系**（手眼标定），以及**你命令的力就是你实际给出的力**（无刷电机的换相与执行）。这两件事都会漂移，而且共享一个残酷结构：**只有在「足够丰富的运动」下才可观测**。AX=XB 需要非平行的多轴旋转才能定出传感器-执行器外参；无位置传感器的无刷电机在零速时反电动势为零、转子位置不可观测。于是「想知道自己的身体」天然要求「先动一动」；可「动」恰恰消耗安全裕度。
>
> 核心命题：**在 R69 的外部交互之外，补上一类「本体信息动作」——自激励（self-excitation）：用一次被安全认证、落在任务松弛窗口内的小幅运动，主动把手眼外参与电机执行参数从「不可观测」推成「可观测」，并用一条独立的「传感-运动一致性」通道把感知漂移与执行漂移分开。当激励无利可图、安全裕度不足、或本体已被认证时，逐指令退化为 FLUID-RAS / R68。** 命名 **SOMA-RAS**（Sensorimotor Observability via Motion Activation）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我的身体还是我以为的那个身体吗**」——不确定性不只是刹车、提问与注视，还可以是一次为了看清自己而做的、被严格约束的小动作。

## 0. 直觉与动机

**灵感 1（手眼标定 → 感知与动作之间有一条会漂移的缝）**
直觉：前几轮都隐含假设「观测 o 与动作 a 活在一个固定、共同的坐标系里」。真实系统里，相机到机械臂末端的外参 T_HE 会因热漂、装配松动、碰撞而缓慢变化；标定不是一次性常数，而是一个需要持续维护的状态。经典 AX=XB 告诉我们：只有当配对运动在旋转轴上「足够丰富」时，X 才可辨识；若机器人反复执行同一个任务，运动集合退化，某些方向上的外参误差会落进一个不可观测的子空间，既不产生残差、也不会被 R68 的标定观测器看见——**这正是 R68「缓变故障被标定吸收」的几何版本**。

**灵感 2（无刷电机 → 执行器也有「测量」，而且站着不动就测不到）**
直觉：无位置传感器的无刷电机（BLDC/PMSM）靠反电动势估转子位置，而反电动势 ∝ 转速：**零速时转子位置不可观测**，必须靠高频注入或先转起来。换相偏移 δ_c（编码器/转子磁极对齐）漂移后，命令转矩 τ_cmd 与实现转矩 τ_real 不再相等（表现为转矩纹波、效率下降）。也就是说，「动作实现」本身是一个带可观测性视界的估计量，而 R69 的 FMA 是在「动作被忠实执行」的假设下给动作轨迹打分的——执行漂移会被误记到感知或策略头上。

**灵感 3（两者其实是同一件事：相对标定是规范理论，激励是破缺规范对称）**
直觉：手眼外参是「眼系 ↔ 手系」的相对规范（gauge），换相偏移是「电角度命令 ↔ 转子磁角度」的相对规范。二者都可写成 AX=XB 形态的相对对齐；都有一条规范自由度——对应一个不可观测子空间（退化运动 / 零速）。**没有运动，这个规范就是真正的对称性，参数不可辨识；运动是打破规范对称、把相对相位锚定下来的唯一手段。**「以动求知」不是工程技巧，而是相对标定的本体论：可观测性不是一个静态属性，而是「你最近做过什么动作」的函数。

**灵感 4（以动求知 → 自激励是一种信息动作，且必须被「可观测性屏障」守住）**
直觉：R69 的信息动作是外向的（看/问/触）。这里加一个内向的：一次安全的小幅「探询性运动」，使手眼与执行参数的 Fisher 信息最大。但若系统总是回避激励，标定后验方差会像随机游走一样无界增长，最终不可恢复——这又是一次「沉默的失败」。所以要像控制安全那样控制**可辨识性**：维持最近激励信息矩阵的特征值在一个下限之上（κ_HE ≥ κ_min），把激励排进任务松弛窗口（低负载、远离障碍，用 R67 的 VISTA 预测）。这在控制论里有一个精确名字：**对偶控制（dual control）**——动作既要控制、又要学习；R69 学的是外部世界的模态，R70 学的是**自己的身体**。

**灵感 5（自激励是双刃剑 → 循环依赖与投毒）**
直觉：要安全地激励，你需要一个可信的身体模型；可身体模型恰恰是你要标定的东西——**循环依赖**。若标定已错，激励轨迹就会在错的坐标系里计算，可能越出安全壳；越界造成的扰动又让标定更错——「越动越错」。此外，激励过程可被外部污染：有人/某物在激励时推动了工具，制造出假的运动对；或伪造反电动势/编码器，把标定引向一个虚假的自信。所以 R70 必须同时交付：**标定无关的安全壳**（用眼观测的工作空间 + 出厂先验 provenance）、激励投毒检测、以及「单次激励不得定案」的证据纪律。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（SOMA-RAS 总览）** SOMA-RAS = (FLUID-RAS†, HEC, ARO, SEE, OBC, SRC, APG)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **可观测性屏障**：对当前任务依赖的校准边 E_task，最近激励信息矩阵的 κ ≥ κ_min，否则必须在安全松弛窗口内触发自激励；
(iii) **执行诚实性**：执行实现间隙 δ_a 必须被估计并传播，绝不假设为零；
(iv) **严格包含**：当激励 VoI ≤ 成本、安全松弛 < s_min、或本体已认证时，逐指令退化为 FLUID-RAS（得 R68 为再退化边界）。

**定义 311（传感器-执行器校准图）** 图 𝒢 = (𝒱, ℰ_cal)。节点为坐标系与执行器（眼、手、基座、各关节电机）；边 e ∈ ℰ_cal 为一个相对标定量（含外参 T_e、换相偏移 δ_c、电流零偏 b_i 等），每条边带四元组 (𝒪_e, γ_e, Σ_e, π_e)：可观测算子、随机游走漂移率、后验协方差、provenance（出厂/上次认证来源）。任务依赖子集 E_task ⊆ ℰ_cal；运行时须保证 E_task 的后验被认证（定义 326）。

**定义 312（手眼变换与 AX=XB 残差）** 手眼外参 X = T_HE ∈ SE(3)。对配对运动 (A_i 在手系, B_i 在眼系)：A_i X = X B_i，残差 r_HE,i = log(A_i X B_i^{-1} X^{-1})^∨ ∈ ℝ⁶。在线维护 (X̂, P_HE)。

**定义 313（激励信息矩阵与可观测性指数）** 把 r_HE 对 vec(X) 线性化得回归子 φ_i(A_i,B_i)；定义 J_PE = Σ_i φ_i φ_i^T。可观测性指数 κ_HE = λ_min(J_PE)。一段候选激励 ξ_exc 的信息增益 ΔJ(ξ_exc) = J_PE(追加后) − J_PE。κ_HE 就是「最近运动是否足以锚定相对规范」的标量度量。

**定义 314（规范零空间与退化盲区）** N_HE = ker(J_PE) 为未锚定的规范方向（例如纯平移、或所有旋转绕同一轴时的某个转动分量）。误差沿 N_HE 的分量**不产生任何 r_HE 残差**，却按漂移率 γ_e 随机游走：P_N(t+Δ) ⪰ P_N(t) + γ_HE² Δ。反复执行同一任务的机器人拥有一个持续存在的 N_HE；此即「沉默漂移」的几何定义。

**定义 315（无刷电机执行模型：换相偏移与执行实现间隙）** 面装永磁同步/无刷直流电机在 FOC 下：命令转矩 τ_cmd = k_t i_q^cmd；实现转矩 τ_real = k_t i_q cos(δ_c) + ripple(θ_rot, cogging)。换相偏移 δ_c 与电流零偏/增益 b_i 随温度与磨损漂移。定义**执行实现间隙** δ_a = τ_real − τ_cmd ∈ ℝ^{d_τ}，它是「策略以为发出的动作」与「真实发生的动作」之间的缝。

**定义 316（无位置传感器可观测视界）** 由反电动势估转子位置时，估计方差 σ_θ² ≈ σ_bemf² / (k_e ω)²；存在视界 ω_min 使得 |ω| < ω_min 时转子位置不可观测，零速时 δ_c 完全不可观测。恢复可观测性的合法动作是高频电流注入或受控转动——**执行器必须「动」才能知道自己朝哪**。

**定义 317（执行实现观测器 ARO）** 由电流 dq 分量、反电动势、编码器与指令运动联合估计 (δ_c, b_i)，输出 δ_a 及其协方差。关键：其可观测性同样受定义 316 视界约束，故 ARO 与 HEC 必须共享同一个「激励时钟」。

**定义 318（安全自激励设计 SEE）** 候选激励轨迹 ξ_exc ∈ 𝒜_exc（限时、限加速度、限力矩、且末尾回到安全集）。选择
ξ_exc* = argmax_{ξ} [ IG(Z; y(ξ)) − c_exc(ξ) ]，Z = (T_HE, δ_c, b_i)，
s.t. c_ras_wm.certify(ξ) ∧ h_safety(ξ) ≥ 0 ∧ h_obs(ξ) ≥ 0（定义 319）∧ |τ| ≤ τ_max。
目标偏好落在规范零空间 N_HE 的方向（D-最优 / 补秩），这正是「朝着自己看不见的地方动一动」。

**定义 319（可观测性屏障 OBC）** 定义可观测性屏障 h_obs = κ_HE − κ_min。要求激励策略使 {h_safety ≥ 0, h_obs ≥ 0} 为控制不变集：低于 κ_min 时，若安全松弛允许则安排激励，否则把不可观测的标定不确定性记为 U_cal_unobs 注入保守退避（定义 326）。这是「给可辨识性上的 CBF」——知识的控制障碍函数。

**定义 320（激励-安全对偶上界）** 在力矩上限 τ_max 与安全壳位移上限 s_max 下，单位时间的 Fisher 信息增量满足 ΔJ_PE ≤ c·(τ_max/I)²·Δt²·σ^{-2} 且累积位移 ≤ s_max。故把 κ 从 κ 提升到 κ_min 的最短再辨识时间 T_id ≥ f(κ_min − κ, τ_max, s_max)。系：**安全裕度越紧，允许的激励越弱，失明窗口越长**——「知道」要以安全裕度为货币付费。

**定义 321（传感-运动一致性残差 SRC）** 独立于策略似然的第二条通道：比较「眼观测到的手部运动（经当前 T̂_HE）」与「本体正运动学 + 对 δ_a 修正后的预测运动」：r_src = obs_hand − FK(q, a_real)。r_src 高而 r_res、FMA 低 ⇒ 手眼/执行漂移，而非感知噪声。它把 R69 的 FMA（策略似然）升级为「策略 + 运动学物理」的双重第二意见。

**定义 322（执行不确定性传播 APG）** 把 R69 的 U 再拆出执行项：U = U_perception ⊕ U_actuation ⊕ U_policy，其中 U_actuation 由 δ_a 的协方差与 ω 是否低于 ω_min 给出。δ_a 高时不得把偏差归咎于策略或流似然，而应走激励/最保守路径。

**定义 323（自激励审计 VQAuditor-X）** 审计激励决策：激励是否确有必要（κ 是否真的低于下限）、是否始终待在安全壳内、是否真的提升了 κ、标定是否只在 k 个正交来源一致后才更新、是否出现过度激励/磨损/时间浪费。结论回灌 SEE 的成本先验。

**定义 324（自激励投毒干扰集 ℰ_soma）** 退化运动盲区（漂移被隐藏）、激励期外力污染（制造假配对运动）、反电动势/编码器伪造、激励诱发的不稳定（共振、力矩饱和）、单次激励后的过度自信。并入 AIC：ℰ_SOMA = ℰ_FLUID × ℰ_cal × ℰ_act。

**定义 325（证书 J_SOMA）** J_SOMA = (J_FLUID, κ_HE, tr P_HE, δ_a_p95, excitation_log_hash, pe_floor_margin, realized_torque_p95, provenance_chain, soma_ver)。Valid ⇔ Valid(J_FLUID) ∧ E_task 的 κ ≥ κ_min ∧ 执行间隙已认证 ∧ k-来源证据纪律满足。

**定义 326（可观测性门控与两级退避扩展）** 若 E_task 已认证（κ ≥ κ_min，tr P_HE ≤ τ_P，δ_a ≤ τ_a）：沿用 R69 的 resolution bonus。若未认证且安全松弛充足：先自激励再重判。若未认证且无松弛 / 被投毒 / provenance 不可信：把不可观测标定不确定性视为当前不可解的 epistemic，令 λ = λ_floor(U_ale + U_epi + U_cal_unobs)（回到 R68 最保守）。⇒ FLUID-RAS 恰为「永不自我激励」边界，R68 再为其边界。

```python
class ActuationRealizationObserver:
    def update(self, i_dq, omega, theta, tau_cmd):

def design_excitation(N_null, budget, slack, torque_lim):

    return best if best and best.score > 0 else None          # 无利可图 → 不激励
```

## 3. 推导

**引理 19（规范零空间与退化盲区）** 设相对标定 X 的线性化回归矩阵为 J_PE。X 可辨识 ⇔ rank(J_PE) 满秩；等价地，运动集合须在至少两个非平行轴上产生旋转（手眼），或转速越过 ω_min（电机）。否则存在非平凡零空间 N = ker(J_PE)，误差沿 N 的分量是**纯规范**：不产生任何残差（r_HE ≈ 0，r_res ≈ 0），却按漂移率随机游走。故反复执行同一任务的系统会沿 N 沉默漂移；R69 的 FMA 之所以看不见它，是因为策略在**同一个错误坐标系**里自洽——动作似然在错的规范下依旧很高。

**引理 20（激励-安全对偶 / 信息-权限上界）** 在力矩上限 τ_max 与安全壳位移上限 s_max 下，单次激励可注入的 Fisher 信息受执行器权限约束：ΔJ_PE ≤ c·(τ_max/I)²·Δt²·σ^{-2}，可达位移 ≤ s_max。于是把 κ 抬到 κ_min 的最短再辨识时间 T_id ≥ f(κ_min − κ, τ_max, s_max)。系：**减少安全裕度（更贴边界、更省时间）会指数式拉长失明窗口**；因此激励应被调度到远未用满裕度的松弛窗口，而不是在临界态临时抱佛脚。

**引理 21（执行漂移与感知漂移的可分性）** 实现动作 a_real = a_cmd + δ_a。若 δ_a ≠ 0 而 T_HE 正确，则眼观测到的运动与正运动学预测出现 r_src ≠ 0；若 T_HE 有偏而 δ_a ≈ 0，则眼-手配对残差 r_HE ≠ 0，但 ARO 的电流/反电动势通道正常。两通道在低速时解耦条件不同（ARO 需 ω > ω_min，HEC 需足够旋转多样性），故联合可观测量 (r_HE, r_src, δ_a, ω) 可把执行漂移与感知漂移分离——这是 R69 引理 17 的「传感器/行为」对偶在「运动学/执行器」上的第三重镜像。

**引理 22（激励投毒下的假自信）** 若激励期运动对被外部扰动污染（概率 δ_e），单来源标定会收敛到一个偏差 X*，其偏差注入量为 δ_e·cond(J_PE)^{-1}；单次激励无法区分「真运动」与「被推动」。采用带 provenance 的 k 个正交来源（眼-手配对、本体运动学、独立的基座/外部锚点）一致纪律，且各来源污染相关 ρ<1，则假收敛率 ≤ δ_e·ρ^{k−1} + ε_σ。系：**一次激励只能提供似然，不能单独授予信任**。

**定理 18（SOMA 严格包含 FLUID-RAS 与 R68）** 在 A99–A101 下，SOMA 的两阶段策略（先判可观测性，再激励或保守）在任意状态 s 上的期望风险 ≤ FLUID-RAS；且当激励 VoI ≤ 成本、安全松弛 < s_min、或本体已认证（κ ≥ κ_min 等）时，两者**逐指令相同**（定义 326）。进一步，FLUID-RAS 在「永不外部交互」时退化为 R68。故：SOMA ⊃ FLUID-RAS ⊃ R68，安全侧逐层不让步，效率侧逐层获得 resolution bonus 与「恢复可观测性」的额外收益。

**定理 19（自激励安全与无突变）** 激励轨迹经 C-RAS-WM 前缀认证 + 力矩上限 + 安全壳 CBF + 可观测性屏障 OBC（定义 318–319）；激励被括起（bracketed）且末尾回到安全集；失败/超时/投毒时回退到激励前的已认证计划，λ 单调不降地退化为 R68；提交/换装不变式（R68 定理 15）保持 ⇒ 控制连续、无突变；且 OBC 在激励策略下为控制不变集——系统不会为了「看得清」而主动驶出安全区。

## 6. 本轮最大风险

**一句话**：自激励是一个「安全性取决于它所校准之标定」的动作——**循环依赖**：若手眼或换相已经错了，激励轨迹就在错的坐标系里被计算，可能越出安全壳，而越界扰动又让标定更错；更糟的是，反复自激励可被外力污染或伪造反电动势**投毒**，系统会把一个被「验证过」的错误身体模型信以为真，从而更大胆地动——**以动求知，也可能越动越错**。

**次级风险与缓解**：
1. **循环依赖（安全依赖待标定量）** → 只用「标定无关安全壳」（眼观测工作空间 + 出厂 provenance 引导 + 激励前已认证包络）做兜底，绝不在临界态激励；
2. **激励投毒/外力污染** → ℰ_soma 对抗 + k 个带 provenance 的正交来源一致纪律（引理 22）+ 单次激励不得定案；
3. **过度激励（磨损/时间/共振）** → SEE 成本项 + 激励预算 + 可观测性屏障只在必要时触发；
4. **低速执行不可观测** → 视界 ω_min 显式建模，低于视界时把 U_actuation 注入 λ_floor，绝不假装知道 δ_c；
5. **本体层拖垮实时预算** → HEC/ARO 增量更新 + SEE 离线预算 + 仅松弛窗口执行物理激励。

```python
    if g is not None: U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    U_body = 0.0 if self_ok else U_cal_unobs(kappa, trace(M.hec.P), delta_a)
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + (U_epi if g is None else 0.0) + U_body))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    if slow or M.poison_suspect:
        lam = max(lam, 0.8); k = min(k, k_cal_shrink(x_prime, U_cal))
    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_x.submit_async(xi_exc, kappa, delta_a, r_src)
    return k, lam, mode, (U_ale, U_epi, kappa, delta_a)
```

## 4. 推导

**引理 19（规范零空间与退化盲区）** X 可辨识 ⇔ rank(J_PE) 满秩（手眼需两轴以上非平行旋转；电机需 ω > ω_min）。否则 N=ker(J_PE) 非平凡，误差沿 N 为纯规范：`r_HE≈0`、`r_res≈0`，却按 γ 随机游走。反复执行同一任务的系统沿 N 沉默漂移；R69 的 FMA 看不见它，因为策略在同一错误规范下自洽，动作似然仍高。

**引理 20（激励-安全对偶上界）** 力矩上限 τ_max、安全壳位移 s_max 下，`ΔJ_PE ≤ c(τ_max/I)²Δt²σ^{-2}`，故 `T_id ≥ f(κ_min−κ,τ_max,s_max)`。系：安全裕度越紧，允许激励越弱、失明窗口越长；激励应排进松弛窗口（用 R67 VISTA 预测低负载/远障碍时段）。

**引理 21（执行漂移 vs 感知漂移可分）** `a_real=a_cmd+δ_a`。δ_a≠0 而 T_HE 正确 ⇒ `r_src≠0`；T_HE 偏而 δ_a≈0 ⇒ `r_HE≠0` 且 ARO 正常。联合量 `(r_HE, r_src, δ_a, ω)` 在各自可观测域内可分离二者——R69 引理 17 的第三重对偶镜像。

**引理 22（激励投毒下的假自信）** 运动对被污染概率 δ_e 时，单源标定收敛到偏差 X*，注入量 ∝ δ_e·cond(J_PE)⁻¹；带 provenance 的 k 个正交来源（眼-手、本体运动学、独立基座锚点）一致，污染相关 ρ<1，则假收敛率 ≤ `δ_e·ρ^{k−1}+ε_σ`。系：一次激励只给似然，不单独授予信任。

**定理 18（SOMA 严格包含 FLUID-RAS 与 R68）** A99–A101 下 SOMA 任意状态期望风险 ≤ FLUID-RAS；当激励 VoI ≤ 成本、安全松弛 < s_min、或本体已认证时逐指令相同。FLUID-RAS 在「永不外部交互」时退化为 R68。故 SOMA ⊃ FLUID-RAS ⊃ R68：安全不让步，效率逐层扩。

**定理 19（自激励安全与无突变）** 激励经 C-RAS-WM 前缀认证 + 力矩上限 + 安全壳 CBF + OBC（定义 318–319），被括起并回到安全集；失败/超时/投毒回退到激励前已认证计划，λ 单调不降；换装不变式（R68 定理 15）保持 ⇒ 控制连续、无突变；OBC 为控制不变集，系统不会为「看得清」驶出安全区。

## 7. 本轮最大风险

**一句话**：自激励是「安全性取决于它所校准之标定」的动作——**循环依赖**：若手眼/换相已错，激励轨迹就在错的坐标系里计算、可能越出安全壳，而越界扰动又让标定更错；外部还可污染激励或伪造反电动势**投毒**，使系统把一个被「验证过」的错误身体模型信以为真并更大胆地动——**以动求知，也可能越动越错**。

**次级风险与缓解**：安全依赖待标定量（标定无关安全壳 + 出厂 provenance 引导 + 激励前已认证包络，绝不在临界态激励）；激励投毒/外力污染（ℰ_soma 对抗 + k 个带 provenance 正交来源一致 + 单次激励不得定案）；过度激励磨损/共振（SEE 成本项 + 激励预算 + OBC 按需触发）；低速执行失明（显式 ω_min 视界，U_actuation 注入 λ_floor）；实时预算（增量 HEC/ARO + SEE 离线预算 + 仅松弛窗口物理激励）。
