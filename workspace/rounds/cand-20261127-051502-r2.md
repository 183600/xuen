## 1. 直觉与动机（两个灵感的碰撞，以及它们如何改写上一轮结论）

### 1.1 灵感 1：评测基准——「官方尺子的分辨率，比我们想象的粗得多」

**直觉**：上一轮把「得分点制」当成金矿，却忽略了一个更基本的问题：这把尺子本身有多精确？官方给每个任务 10 次、每类泛化只给 2 次。用 2 次伯努利去估计某任务在某一泛化轴上的成功率，标准误约 0.35——几乎等于抛硬币。也就是说，**官方榜能可靠区分的只有「总平均成功率」这一个聚合量，五条泛化轴的单独效应基本淹没在噪声里**。更关键的是排名是字典序：成功率是主指标，步骤分只在并列时起作用。上一轮 I5 把大量精力押在「得分点对齐」上，方向对，但权重必须下调——先把任务做完，再谈做得多漂亮。

**严谨定义**：设任务 i∈[32]、泛化轴 a∈{位置, 干扰物, 背景, 未见物品, 人为干扰}、重复 r∈{1,2}，episode e=(i,a,r)。成功 S_e∈{0,1}，步骤分 P_e∈[0,100]。官方主指标

  M_S = (1/32) Σ_i (1/10) Σ_{a,r} S_e = (1/320) Σ_e S_e，

破平指标 M_P = (1/32) Σ_i (1/10) Σ_{a,r} P_e。排名 = 对 (M_S, M_P, 提交时间) 的字典序。

在 S_e ~ Bernoulli(p) 的独立近似下，Var(M_S)=p(1−p)/320；取 p=0.3（沿用「榜首<30%」的上下文），SE≈0.026，单次官方评测对两个方案成功率差的 95% 可检测下界约 2.8×SE≈0.10（10 个百分点）。而单轴估计只有 64 次（32 任务 × 2），若要检测 10pp 的轴效应，按 80% 功效约需每组 330 次——**官方每轴预算比所需少约 5 倍**。这不是说官方基准不好，而是说：**必须自建一个高重复、可校准的代理基准，官方榜只用来做最终锚点**。

**推论（本轮最重要的重构）**：
1. **成功率先行**：所有创新的排序判据改为「预期成功率增量」，步骤分只作为 tie-break 优化；I5 从「得分点对齐」降级为「完成优先、步骤分次之」。
2. **五轴均衡增广**：既然 5 轴各 20%，不存在「主攻一轴」的性价比；I1 的增广预算应按 5 轴均分，而不是继续加码背景/干扰物。
3. **代理基准的分辨率必须高于官方**：代理基准要能在每轴给出 n≥100 的重复，才有资格指导模型选择；否则我们只是在噪声上做梯度下降。

### 1.2 灵感 2：点云配准——「演示不是轨迹，是物体坐标系里的一段程序」

**直觉**：上一轮 I9 用 2D VLM 嵌入做「检索最像的杯子怎么抓」，这只能给出软先验，给不出精确的抓取位姿。但数据里其实藏着更强的结构：每条演示的末端轨迹，本质上是在**物体坐标系**里的一段程序（先到把手，再合拢，再抬升）。如果我们能在评测时恢复物体的 6D 位姿，就能把这段程序通过一个 SE(3) 变换搬到当前场景——这不是「检索相似」，而是「精确重放一个换元后的程序」。头部相机是已校正立体对（F23），公制点云是拿得到的；**没有深度通道不等于没有几何**。

**严谨定义**：设当前观测的部分点云 P⊂R³（立体视差恢复），规范物体点云 Q（来自 CAD、演示首帧或离线重建）。配准求 (T,s)∈SE(3)×R_{>0}：

  (T*,s*) = argmin_{T,s} Σ_{p∈P} min_{q∈Q} ‖Tp − s q‖² + λ·point-to-plane + μ·双向 Chamfer，

对称物体（杯/碗/瓶）的位姿只在商空间 SE(3)/G 上可辨识，G 为连续 SO(2)（圆柱）或离散群（方块）；定义商度量 d(T₁,T₂)=min_{g∈G}‖T₁−T₂g‖_F。置信度用内点率 ρ=#{p: residual<τ}/|P|、残差与跨帧循环一致性门控。

**动作迁移**：设演示 d 中被操作物体位姿为 ξ_d^o(t)，当前为 ξ_c^o；物体相对末端轨迹 ξ_d^{e|o}(t)=(ξ_d^o)^{-1}ξ_d^e(t)。迁移为

  ξ_c^e(t) = ξ_c^o · ξ_d^{e|o}(t)。

对「物体 + 目标容器」共同定义的任务（挂杯到架、盘子放架），改用关系坐标系 ξ^{e|(o,τ)}，同时对齐物体与目标，避免只对上物体却对不上目标。该式在刚体假设下精确；对拉链、毛巾、网线、针管、液体等变形/关节/流体对象，**只迁移物体位姿，不迁移整段轨迹**，轨迹仍由策略生成——这是几何层的能力边界，必须写死。

**推论**：
1. **I9 从「2D 检索」升级为「3D 配准 + SE(3) 换元」**：检索只负责挑演示，配准负责给出精确的 ΔT；两者串联而非替代。
2. **点云配准同时是评测工具**：把「当前物体位姿 vs 目标位姿」的配准误差定义为几何进度，可自动、稠密、无需人工标注地给 L0/L1 消融打分——正好补上代理基准最缺的「廉价密集标签」。
3. **几何层是公共基础设施**：同一套 P、T、置信度同时服务 I9（迁移）、I11（评测）、I5（恢复里程碑），避免三套感知各建一遍。

### 1.3 统一：把「数据引擎」升级为「测量 × 几何」双基础设施

上一轮结论是「中期胜负手在数据引擎」。本轮修正为：数据引擎仍然是分数的来源，但**没有高分辨率的测量层，数据引擎的迭代是盲的；没有几何层，数据引擎造出来的增广/迁移无法精确落到物体坐标系**。三者关系：

- **I11（代理基准）** 回答「这次改动到底有没有用」——决定预算分配；
- **I10（几何接地）** 回答「物体在哪、演示怎么搬过来、进度怎么算」——决定迁移与评分；
- **I1/I2/I5（数据引擎）** 回答「训练分布怎么覆盖考纲」——决定分数上限。

一句话：**评测基准是方向盘，点云配准是坐标系，数据引擎是发动机；本轮先装方向盘和坐标系。**

## 0. 本轮两个定量结论（先看这个）

1. **官方榜的分辨率**：320 次 episode，5 轴 × 2 次/任务；主指标是总平均成功率，步骤分仅 tie-break。单轴 64 次的预算，对 10pp 轴效应约差 5 倍功效。→ 代理基准必须比官方更密，官方榜只做最终锚点。

## 1. 32 任务几何可辨识性分类（决定 I10/I9 的适用边界）

| 类别 | 任务（编号） | 配准可靠性 | 迁移方式 |

- **动机**：未见物品轴 2/10（20%），2D 检索给不出精确抓取位姿。

  1. **检索**：reset 期用 DINOv2/VLM 嵌入在「演示库」中检索 top-k 相似（物体类别 + 技能 + 关系坐标系）；

### I10 立体几何接地层（新）★★★★★
- **动机**：无深度通道（F23）但头部是已校正立体对；几何是 I9/I11 的共同地基。
- **组成**：
  1. **公制深度**：rectified stereo → disparity → Z=fB/d；半全局匹配（SGBM）或轻量学习匹配；
  2. **双通道自标定**：离线用 state_d435 + 立体视觉里程计估 (f,B,外参)；在线用「EE 作为标定靶」——夹爪尖端像素的视差 d 与已知 EE 深度 Z 满足 fB=dZ，多帧鲁棒回归；
  3. **外参**：训练集 state_d435 相对 torso 的变换 + 评测 waist 状态（lower_body 含 waist yaw/roll/pitch）推当前相机位姿；若头部与 torso 非刚性，用视觉里程计在线修；
  4. **点云处理**：桌面分割（RANSAC 平面）、物体实例分割（SAM/开放词汇检测）→ 物体点云；多视角融合（头 + 双腕，腕部单目用尺度先验）；
  5. **置信度**：内点率、残差、跨帧一致性、左右视差一致性；低于阈值输出 None。
- **输出**：每 episode 首帧 + 关键节点的物体点云、6D 位姿、尺度、置信度；reset 期一次，episode 内低频更新。
- **技术选型**：经典 SGBM + RANSAC/FPFH + trimmed ICP 优先（可解释、无训练）；学习配准（GeoTransformer/DCP）只在经典失败且数据充足时上；透明/反光用单目深度基础模型或腕部视角兜底。
- **资源**：SGBM CPU 可跑；配准 CPU/GPU 均可；1 人周工程 + 1 GPU 日验证。
- **风险**：透明/反光/细线/遮挡；标定漂移；延迟。缓解：置信门控 + 回退；标定一致性冒烟；异步低频。

### I11 排名感知代理基准（新）★★★★★
- **动机**：官方每轴 n=2，单轴不可测；需要高重复代理基准指导模型选择（P10）。
- **组成**：
  1. **评测卡**：每任务 5 轴 × 2 档 + 几何谓词 + 官方示例锚点；与 I1 的增广卡同源，但**训练/评测分离**（评测卡中的具体场景不进训练）；
  2. **高重复 in-silico 基准**：Isaac Lab（F14）或离线重放 + I10 几何进度；每轴 n≥100；无仿真对齐的任务用「离线扰动重放 + 动作一致性」代理；
  3. **层次贝叶斯标定**：logit p_{i,a}=μ+α_i+β_a+γ_{i,a}；用少量真机/单任务通道结果做后验锚定；输出 M_S 的后验与排名不确定性；
  4. **子集选择**：在候选 (任务, 轴, 剂量) 池中，用子模最大化/贝叶斯 D-最优选真机预算子集，目标 = 对官方排名的期望秩相关/决策信息增益；
  5. **反 Goodhart**：留出任务/轴、对抗验证（区分代理与官方分布）、预注册效应量、bootstrap 置信区间。
- **与 I8 差异**：I8 是「跑评测的流程」，I11 是「评测本身的统计设计」；二者共用注册表。
- **资源**：评测卡 32×10 分钟；in-silico 基准 1–2 人周；标定脚本 3 天。
- **风险**：代理与官方秩相关建立慢；仿真-真机 gap；评测卡泄漏进训练。缓解：先单任务通道标定 3–5 个任务；严格训练/评测分离；相关性 >0.6 才单独准入 L2（沿用 v1.1 判据）。

def transfer(demo, cur_obj_pose, cur_tgt_pose=None):
    # demo: {obj_pose_d, tgt_pose_d, ee_traj_d}
    if cur_tgt_pose is None:
        dT = cur_obj_pose @ inv(demo.obj_pose_d)
    else:
        # 关系坐标系：同时对齐物体与目标容器（挂杯/放盘）
        dT = relational_transform(
            (cur_obj_pose, cur_tgt_pose),
            (demo.obj_pose_d, demo.tgt_pose_d),
        )
    return [dT @ x for x in demo.ee_traj_d]

def safe_transfer(demo, obs, geom):
