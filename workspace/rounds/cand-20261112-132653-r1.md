# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC IP-153~160；灵感循环第 1 轮／全局第 61 轮；本轮灵感：「工具调用」×「对话管理」）

> 第 60 轮把「场景→意图→约束→阻抗→执行→EV-exec→场景更新」闭合成 SGEC。但这条链的「意图」仍是一次性的静态标签，而「执行原语」仍被当作安全链内部的函数。当系统开始由大模型/任务规划器以**工具调用**方式驱动、由**多轮对话**方式接受人类监督时，三个结构性缺口暴露出来：
> 1. **工具调用无契约**：EEIS/ERTC/CLEP 只校验阻抗参数，不校验「这个技能此刻是否可调用」。一个工具（抓取、推拉、下楼梯、充电对接）是否满足前置条件、后置结果能否被证据验证、失败是否有回退，都不在安全证书里——于是「参数安全的工具调用」仍可能语义上错误。
> 2. **对话管理无接地**：第 60 轮的 CIEC 把一句话映射成约束，却没有对话状态：没有代词消解、没有澄清、没有承诺记账、没有撤回、没有区分「陈述/感叹/命令/承诺」。一句「好烫」可能被误当「别碰」，一句「慢点」在三轮后是否仍有效也无从判断。
> 3. **行为归因无链路**：EV-exec 证明「机器人做了什么」，却不能回答「是哪句话、哪次对话状态、哪条工具契约授权了它」。一旦越权动作发生，无法回溯授权链，也无法在撤回时精确撤销受影响的下游调用。

## 0. 直觉与动机

**灵感 1（工具调用 → 工具调用契约 TCC）**
直觉：工具不是函数，而是**契约**。真实机器人里的「抓取」「推」「下楼梯」不是无副作用的纯函数，而是带前置条件（物体可见、夹爪空闲、位姿可达）、后置条件（物体在夹爪、力在容差内）、副作用（占用资源、改变场景）和失败模式（滑落、卡死）的动作。关键洞见：**把「工具调用」升格为一等安全制品**——为每个工具注册 `(Pre, Post, Effect, Risk, Cert, Fallback)`，工具规划变成「后置条件可推出下一前置条件」的契约组合。这样，大模型可以自由提议工具序列，但只有通过契约检查与证书准入的序列才能下发。

**灵感 2（对话管理 → 对话状态机 DSM）**
直觉：一句话不是意图标签，而是**对话状态机的一次转移**。对话管理要记住：已生效的约束、已许下的承诺、尚未回答的问题、用户已撤回的指令、以及指代对象（「它」「那个杯子」）。关键洞见：**安全约束只在显式、已接地的撤回下才可放松**；否则只能单调收紧（meet）。这样「慢点」不会因为下一轮闲聊而悄悄失效，也不会因为一次误分类而永久锁死。

**灵感 3（对话管理 → 言语行为接地 SAG）**
直觉：奥斯汀/塞尔的言语行为理论在机器人上非常实用。「好烫」是 expressive，只能更新信念；「别碰」是 directive，可以改约束；「我来扶着」是 commissive，产生人类承诺；「杯子在左边」是 assertive，只更新世界模型。关键洞见：**只有已接地的 directive/commissive 才有权限改写执行契约**。接地 = 解析置信度足够 ∧ 与当前任务相关 ∧ （涉及安全时）得到确认或证据。这从语义层面封死「感叹被当命令」「疑问被当授权」。

**灵感 4（工具调用 × 对话管理 → 澄清即工具 CAH）**
直觉：不确定时，最安全的「工具调用」不是动，而是**提问（ASK）或探测（PROBE）**。把 ask / probe / act 放进同一张期望风险表用 VOI 竞价：问一句的代价是回合时延与打扰，碰一下的代价是接触风险与节拍，直接做的代价是误执行。关键洞见：**提问本身也是执行动作，必须纳入安全预算与工具契约**；当安全集为空时，禁止「先做再问」，只允许受控探测。

**灵感 5（证据链 → 调用-对话归因 TCA × 对齐 DTA）**
直觉：每一次执行的工具调用都应能回答「谁授权、依据哪句话、契约是什么、证据在哪」。构建 utterance → dialogue state → tool call → EV-exec → outcome 的溯源图；并强制两条不变量：**无未授权之调用，无未兑现之承诺**。关键洞见：**对齐检查是一张可判定的安全网**——它不改善规划质量，但能在越权/漏做发生的瞬间把系统拉回可审计状态。

**灵感 6（合流 → 对话-工具契约闭环 DTCL + PCE+++++）**
直觉：第 60 轮 SERC 负责「场景-阻抗-执行」；本轮在其上叠加「对话-工具」层：`言语行为 → 对话状态 → 接地约束 → 工具契约 → EEIS/ERTC 编译 → 执行 → EV-exec → 溯源/对齐 → 状态更新`。预算从四维认知预算拓展为 **B_dialog / B_tool / B_scene / B_intent / B_ros / B_exec**；任一耗尽即触发对应的安全降级，但**任何降级都不得绕过契约与接地检查**（fail-closed）。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（工具调用契约 TCC）** 工具库 𝒯 中每个工具 τ 是一个六元组
`τ = (id, sig, Pre_τ, Post_τ, Eff_τ, (Risk_τ, Cert_τ, Fallback_τ))`。
- `Pre_τ(args, b)`：在信念 b 下调用前置条件；
- `Post_τ(args, e)`：执行证据 e 必须满足的后置条件；
- `Eff_τ`：副作用集合（资源占用、场景改变、权限消耗）；
- `Risk_τ ∈ {R0..R3}` 与所需最低证书等级 `Cert_min(Risk_τ)`；
- `Fallback_τ`：失败时的回退工具或安全停机。

一次调用 `a = (τ, args, auth, τ_deadline)`。定义：
- **可采纳** `Adm(a,b) ⇔ sig 匹配 ∧ b ⊨ Pre_τ(args) ∧ Cert_τ ≥ Cert_min(Risk_τ)`；
- **契约满足** `Sat(a,e) ⇔ Post_τ(args,e)`；
- **组合** `a₁;a₂` 可采纳当且仅当 `Post_{τ₁} ⇒ Pre_{τ₂}`（后置蕴含下一前置），且副作用不相斥。
工具计划 `π = a₁;…;aₙ` 合法当且仅当逐步可采纳且组合检查通过；任何 `¬Adm(a,b)` 却被执行的调用记为**越权调用**。

**定义 162（对话状态模型 DSM）** 对话状态
`s_t = (A_{0:t}, K_t, Π_t, Q_t, G_t, U_t)`，其中：
- `A_{0:t}`：言语行为历史；`K_t`：当前生效约束集（来自 CIEC/CST）；
- `Π_t`：机器人承诺集（commissive 产生的义务）；`Q_t`：未决澄清问题集；
- `G_t`：已接地事实与世界模型；`U_t`：对用户身份/可信度/不确定性的估计。
转移 `δ(s_t,u_t)=s_{t+1}`。约束更新规则：
```
K_{t+1} = K_t ⊓ ⟦u_t⟧     若 u_t 是已接地的 directive
K_{t+1} = K_t              若 u_t 未接地或是 assertive/expressive
K_{t+1} = K_t ⊖ c_id       仅当 u_t 是已接地且指名 c_id 的 revocation
```
其中 `⊓` 为收紧（meet），`⊖` 为按约束 id 的精确撤回。**除指名撤回外，约束只减不增（只紧不松）**。

**定义 163（言语行为接地 SAG）** 每条话语 `u` 解析为言语行为
`α(u) = (type, prop, force, conf)`，`type ∈ {directive, commissive, assertive, expressive, clarification, confirmation, revocation}`。
接地谓词：
`G(u,s) ⇔ conf ≥ θ_p ∧ relevant(u,s) ∧ (force ∈ {directive,commissive} ⇒ auth(u,s) ∨ confirm(u,s))`。
只有 `G(u,s)=1` 且 `type ∈ {directive,commissive,revocation}` 的行为可改写 `K/Π`；assertive 只更新 `G_t`；expressive 永不改写执行契约。安全关键指令若接地失败，必须进入 `Q_t` 澄清，而非猜测执行。

**定义 164（澄清-执行停策 CAH）** 给定状态 s、安全集 `K_safe(s)`、预算 `B_cd`，定义三种动作的期望价值：
```
VOI_ask  = E[风险下降 | 提问]   − cost_ask
VOI_probe= E[风险下降 | 探测]   − cost_probe − risk_probe
VOI_act  = E[风险下降 | 直接执行] − cost_act
```
停策：
```
若 K_safe(s)=∅: 只允许 PROBE（若 VOI_probe>0）或 ASK；禁止 ACT
否则若 Amb(s) ≥ θ_amb 且 VOI_ask ≥ max(VOI_act, VOI_probe): ASK
否则若 VOI_probe > VOI_act 且 Amb(s) ≥ θ_amb²: PROBE
否则: ACT（使用保守 K = argmin_{K∈K_safe} Risk）
```
不变式：**ASK 期间不产生任何运动；PROBE 必须本身是一个受证书约束的工具调用**。

**定义 165（调用-对话归因 TCA）** 溯源图 `G_prov = (V,E)`：
`V = A ∪ S ∪ Calls ∪ EV ∪ Outcomes`，`E` 含授权边（grounded act → call）、派生边（state → call）、证据边（call → EV-exec）、结果边（EV → outcome）。
- 授权集 `Auth(a) = {u ∈ A | G(u)=1 ∧ ⟦u⟧ ⇒ auth(a)} ∪ StandingPolicy(a)`；
- 责任归因 `φ(a)`：以风险泛函为价值函数、对 `Auth(a)` 与工具契约的联盟做 Shapley 边际贡献；
- 撤回传播：`revoke(u*)` 沿 `G_prov` 标记所有下游调用为 **tainted**，触发回退或安全停机，并只解冻不被其他授权覆盖的约束。

**定义 166（对话-工具对齐 DTA）** 对轨迹 `tr` 定义两条不变量：
```
(Auth)      ∀ a ∈ executed(tr): Auth(a) ≠ ∅
(Fulfill)   ∀ c ∈ Π: discharged(c) ∨ refused(c) 且在 deadline 前
```
越权集合 `O_call = {a | Auth(a)=∅}`，失约集合 `O_promise = {c | ¬discharged ∧ ¬refused}`。
`DTA_valid(tr) ⇔ O_call=∅ ∧ O_promise=∅ ∧ applied_K ⊆ promised_K`
（最后一项表示实际施加的约束不得比对话中承诺的更松）。

**定义 167（约束语义与单调收紧 CST）** 约束表达式文法由 `v_max, F_max, K_p, K_d, ε_traj` 的区间项与修饰词构成。解释函数 `⟦·⟧` 把短语映射到约束空间中的区间；修饰词构成紧度格 `(M, ⊑)`：
- 安全形容词单调：`轻/慢/柔` 只允许减小对应上界，`紧/用力` 只允许提高力但受 `F_safe` 截断；
- 否定按方向翻转（「别太用力」⇒ `F_max ≤ F_nom`）；
- 模糊量（「稍微」「一点」）展开为宽度 `δ` 的区间，而非点值；
- 组合取 meet `⊓`。
**保证**：任何未触发澄清的语义组合，其结果都落在「只收紧不放松」的安全锥内；若某修饰词方向本身歧义（无法判定收紧方向），必须降级为 `ASK`。

**定义 168（对话-工具预算 PCE+++++）** `B_cd = (B_dialog, B_tool, B_scene, B_intent, B_ros, B_exec)`，其中：
- `B_dialog = (turn_latency, clarification_count, context_window, grounding_calls)`；
- `B_tool = (availability, load, cert_budget, retry_budget)`；
- 其余沿用第 60 轮。
价值函数：
```
voi_cd(π) = VOI_meta_pessimistic(π)
            − cost_cog − cost_exec − cost_dialog − cost_tool
cost_dialog = λ_turn·Turn + λ_clar·Clarify + λ_ctx·Context
cost_tool   = λ_avail·Unavailable + λ_load·Load + λ_cert·CertDeficit
```
降级：`B_dialog` 耗尽 ⇒ 单轮脚本化确认模式（降低表达力但不放松约束）；`B_tool` 耗尽/工具不可用 ⇒ fail-closed 安全停机；任何降级**不得跳过 SAG 接地与 TCC 契约检查**。

### IP-161 TCC（工具调用契约）

```python
@dataclass
class ToolContract:
    name: str
    pre: Callable          # (belief, args) -> bool
    post: Callable         # (args, evidence) -> bool
    effect: Set[str]
    risk: str              # R0..R3
    cert_level: int
    fallback: Optional[str]

class ToolRegistry:
    def __init__(self):
        self.tools = {}
        self.required = {'R0': 0, 'R1': 1, 'R2': 2, 'R3': 3}

    def register(self, c: ToolContract):
        self.tools[c.name] = c

    def admissible(self, name, args, belief):
        c = self.tools[name]
        return (c.pre(belief, args)
                and c.cert_level >= self.required[c.risk]
                and getattr(belief, 'ros_graph_ok', True))

    def compose(self, plan):
        # 返回 (ok, obligations)：后置 ⇒ 下一前置
        obligations, prev_post = [], None
        for name, args in plan:
            c = self.tools[name]
            if prev_post is not None:
                obligations.append((prev_post, c.pre))
                if not implies(prev_post, c.pre):
                    return False, obligations
            prev_post = c.post
        return True, obligations

    def commit(self, name, args, belief, evidence=None):
        c = self.tools[name]
        if not self.admissible(name, args, belief):
            return REJECT
        if evidence is not None and not c.post(args, evidence):
            return c.fallback or SAFE_STOP
        return ACCEPT
```

### IP-162/163 DSM + SAG（对话状态与言语行为接地）

```python
class DialogueStateManager:
    def __init__(self):
        self.K = ConstraintSet.top()
        self.Pi, self.Q, self.G = [], [], {}
        self.turns = 0

    def step(self, utt, ctx):
        act = classify_speech_act(utt, ctx)   # type, prop, force, conf
        if not self.grounded(act, ctx):
            self.Q.append(clarification_for(act))
            return self.snapshot(), "ASK"

        if act.type == "directive":
            self.K = self.K.meet(interpret_constraint(act))  # 只收紧
        elif act.type == "commissive":
            self.Pi.append(Commitment(act.prop, deadline=ctx.deadline))
        elif act.type == "revocation":
            self.K = self.K.revoke(act.target_id)            # 精确撤回
        elif act.type == "assertive":
            self.G.update(act.prop)                          # 不碰执行
        elif act.type == "clarification":
            self.Q = [q for q in self.Q if q.id != act.target_id]
        self.turns += 1
        return self.snapshot(), "OK"

    def grounded(self, act, ctx):
        if act.conf < THETA_PARSE:
            return False
        if not relevant(act, ctx.task):
            return False
        if act.force in ("directive", "commissive"):
            return ctx.has_confirmation or ctx.has_evidence or act.conf >= THETA_SAFE
        return True
```

### IP-164 CAH（澄清/探测/执行停策）

```python
def clarification_halt_policy(state, K_safe, budget):
    amb = ambiguity(state)          # 由约束区间宽度与指代不确定性合成
    if K_safe.is_empty():
        if voi_probe(state) > 0 and budget.B_tool.ok():
            return "PROBE"
        return "ASK"

    v_ask, v_probe, v_act = (
        voi_ask(state), voi_probe(state), voi_act(state))
    if amb >= THETA_AMB and v_ask >= max(v_act, v_probe):
        return "ASK"
    if amb >= THETA_AMB2 and v_probe > v_act:
        return "PROBE"
    return "ACT"
```

### IP-165/166 TCA + DTA（归因与对齐）

```python
def build_provenance(trace):
    g = ProvenanceGraph()
    for state in trace.states:
        for call in state.calls:
            auth = [u for u in state.acts
                    if grounded(u) and entails(u, call.contract)]
            g.add_call(call, auth=auth, evidence=call.evidence)
    return g

def dta_valid(trace, applied_K, promised_K):
    orphan_calls = [c for c in trace.calls if not c.auth]
    orphan_promises = [c for c in trace.commitments
                       if not c.discharged and not c.refused]
    not_looser = applied_K.is_subset_of(promised_K)
    return not orphan_calls and not orphan_promises and not_looser

def revoke_and_propagate(g, target):
    for call in g.descendants(target):
        call.tainted = True
        trigger_fallback(call.contract.fallback)
    return g.retained_constraints()
```

### IP-168 PCE+++++（对话-工具预算）

```python
class DialogueToolBudget:
    def __init__(self, dialog=None, tool=None, base=None):
        self.B_dialog = dialog or DialogBudget()
        self.B_tool = tool or ToolBudget()
        self.B_base = base or CognitiveBudget()   # 第 60 轮四维预算

    def mode(self):
        if not self.B_tool.available():
            return "SAFE_STOP"                    # fail-closed
        if self.B_dialog.exhausted():
            return "SCRIPTED_CONFIRM"             # 单轮脚本化
        return "NORMAL"

    def charge(self, action):
        if action.kind == "clarify":
            self.B_dialog.clarification_count += 1
        elif action.kind == "tool_call":
            self.B_tool.load += action.estimated_load
            self.B_tool.retry_budget -= action.retry
```

### IP-DTCL（对话-工具契约闭环）

```python
def dialogue_tool_contract_loop(M, user_utt, delta_f_req):
    # 1) 对话状态与言语行为
    s, status = M.dsm.step(user_utt, M.ctx)
    if status == "ASK":
        return M, M.dsm.ask(), "AWAIT_USER"

    # 2) 约束语义 → 第 60 轮 CIEC/ERTC
    C_intent = interpret_constraint(s)
    M.ertc.lock_constraints(C_intent)

    # 3) 工具提案与契约检查
    plan = M.planner.propose(s)                    # 可能来自大模型
    ok, obligations = M.tool_registry.compose(plan)
    if not ok:
        return M, M.tool_registry.explain(obligations), "REPLAN"

    # 4) 澄清/探测/执行决策
    K_safe = M.eeis.compile_with_scene_prior(
        M.scene_model.get_scene_impedance_prior(), delta_f_req)
    decision = clarification_halt_policy(s, K_safe, M.budget)
    if decision in ("ASK", "PROBE"):
        return M, decision, decision

    # 5) 执行 + 证据（复用第 60 轮 SERC/CLEP/EPIR）
    M, fused, D_plus, EV_exec, cert = closed_loop_exec_probe(
        M, M.current_cp, delta_f_req, M.budget.B_base)

    # 6) 溯源 + 对齐 + 承诺结算
    g = build_provenance(M.trace)
    M.trace.commitments = settle(M.dsm.Pi, M.trace)
    if not dta_valid(M.trace, M.dsm.K, M.dsm.promised_K):
        M = revoke_and_propagate(g, target=find_violation(M.trace))
        return M, "DTA_VIOLATION", "SAFE_STOP"

    return M, (g, EV_exec, cert), "DONE"
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| TCC | O(\|𝒯\|) 单项检查；O(n) 计划组合 | O(\|𝒯\| + n) | 前置可证 + 后置可验；越权调用检出率 100% |
| DSM | O(1)/轮（+O(\|K\|) 约束更新） | O(\|A\|+\|Π\|+\|Q\|) | 除指名撤回外约束单调收紧 |
| SAG | O(1)/句（给定解析器） | O(1) | 仅已接地 directive/commissive 可改写契约 |
| CAH | O(1)（VOI 近似） | O(1) | ASK 无运动；`K_safe=∅` 禁止 ACT |
| TCA | O(V+E) 建图；O(samples·m) 近似 Shapley | O(V+E) | 授权链完整；撤回可传播 |
| DTA | O(\|tr\|) | O(\|tr\|) | `O_call=∅ ∧ O_promise=∅` 可判定 |
| CST | O(depth) | O(depth) | 语义组合只落在收紧锥内 |
| PCE+++++ | O(1) | O(1) | 任一预算耗尽即安全降级，且不跳过接地/契约 |

**正确性定理（DTCL）**：假设 A22–A71 成立，其中新增：
**(A66)** TCC：每个工具的 `Pre/Post` 是可靠的，证书等级与风险等级匹配；
**(A67)** DSM：除已接地指名撤回外，约束转移只做 meet；
**(A68)** SAG：言语行为分类器对安全关键指令的接地判定无假阳性（或假阳性被确认机制拦截）；
**(A69)** CAH：`VOI_ask/VOI_probe/VOI_act` 的估计误差有界；
**(A70)** TCA：溯源图对所有执行调用与承诺完整；
**(A71)** PCE+++++：各维预算单调消耗，降级策略不会绕过安全检查。
则：
1. **契约可靠性**：任一被执行且通过 `Post` 验证的工具计划，其语义后置条件成立；未通过 `Pre` 的调用不会被 `commit` 接受。
2. **授权可靠性**：若 `DTA_valid(tr)`，则不存在未接地的越权调用，也不存在未兑现且未拒绝的承诺；且实际约束不松于承诺约束。
3. **约束单调性**：在没有已接地指名撤回时，`K_{t+1} ⊑ K_t`，因此 `K_safe` 不会因对话噪声而意外放大。
4. **澄清安全性**：当 `Amb(s) ≥ θ_amb` 时执行 `ASK`，其期望风险不高于同状态下直接 `ACT`；`ASK` 期间系统保持零运动。
5. **降级安全性**：任一预算耗尽触发的脚本化/停机模式仍满足 (1)(2)。

### IP-161 TCC（工具调用契约）

```python
@dataclass
class ToolContract:
    name: str
    pre: Callable          # (belief, args) -> bool
    post: Callable         # (args, evidence) -> bool
    effect: Set[str]
    risk: str              # R0..R3
    cert_level: int
    fallback: Optional[str]

class ToolRegistry:
    def __init__(self):
        self.tools = {}
        self.required = {'R0': 0, 'R1': 1, 'R2': 2, 'R3': 3}

    def register(self, c: ToolContract):
        self.tools[c.name] = c

    def admissible(self, name, args, belief):
        c = self.tools[name]
        return (c.pre(belief, args)
                and c.cert_level >= self.required[c.risk]
                and getattr(belief, 'ros_graph_ok', True))

    def compose(self, plan):
        obligations, prev_post = [], None
        for name, args in plan:
            c = self.tools[name]
            if prev_post is not None:
                obligations.append((prev_post, c.pre))
                if not implies(prev_post, c.pre):
                    return False, obligations
            prev_post = c.post
        return True, obligations

    def commit(self, name, args, belief, evidence=None):
        c = self.tools[name]
        if not self.admissible(name, args, belief):
            return REJECT
        if evidence is not None and not c.post(args, evidence):
            return c.fallback or SAFE_STOP
        return ACCEPT
```

### IP-162/163 DSM + SAG（对话状态与言语行为接地）

```python
class DialogueStateManager:
    def __init__(self):
        self.K = ConstraintSet.top()
        self.Pi, self.Q, self.G = [], [], {}
        self.turns = 0

    def step(self, utt, ctx):
        act = classify_speech_act(utt, ctx)   # type, prop, force, conf
        if not self.grounded(act, ctx):
            self.Q.append(clarification_for(act))
            return self.snapshot(), "ASK"

        if act.type == "directive":
            self.K = self.K.meet(interpret_constraint(act))  # 只收紧
        elif act.type == "commissive":
            self.Pi.append(Commitment(act.prop, deadline=ctx.deadline))
        elif act.type == "revocation":
            self.K = self.K.revoke(act.target_id)            # 精确撤回
        elif act.type == "assertive":
            self.G.update(act.prop)                          # 不碰执行
        elif act.type == "clarification":
            self.Q = [q for q in self.Q if q.id != act.target_id]
        self.turns += 1
        return self.snapshot(), "OK"

    def grounded(self, act, ctx):
        if act.conf < THETA_PARSE:
            return False
        if not relevant(act, ctx.task):
            return False
        if act.force in ("directive", "commissive"):
            return ctx.has_confirmation or ctx.has_evidence or act.conf >= THETA_SAFE
        return True
```

```python
def clarification_halt_policy(state, K_safe, budget):
```

### IP-165/166 TCA + DTA（归因与对齐）

```python
def build_provenance(trace):
    g = ProvenanceGraph()
    for state in trace.states:
        for call in state.calls:
            auth = [u for u in state.acts
                    if grounded(u) and entails(u, call.contract)]
            g.add_call(call, auth=auth, evidence=call.evidence)
    return g

def dta_valid(trace, applied_K, promised_K):
    orphan_calls = [c for c in trace.calls if not c.auth]
    orphan_promises = [c for c in trace.commitments
                       if not c.discharged and not c.refused]
    not_looser = applied_K.is_subset_of(promised_K)
    return not orphan_calls and not orphan_promises and not_looser

def revoke_and_propagate(g, target):
    for call in g.descendants(target):
        call.tainted = True
        trigger_fallback(call.contract.fallback)
    return g.retained_constraints()
```

```python
def interpret_constraint(act):
    base = parse_intervals(act.prop)          # v_max,F_max,K_p,K_d,eps
    for mod in act.modifiers:
        base = base.meet(modifier_semantics(mod))
    if any(direction_ambiguous(m) for m in act.modifiers):
        raise NeedClarification(act)
    return base                              # 只可能更紧

def modifier_semantics(mod):
    table = {
        "slow":      Interval(v_max=(0, 0.5 * V_NOM)),
        "light":     Interval(F_max=(0, 0.8 * F_NOM)),
        "gentle":    Interval(K_p=(0, 0.7 * K_P_NOM), K_d=(1.2 * K_D_NOM, inf)),

        "not_too":   Interval(F_max=(0, F_NOM)),    # 否定按方向翻转
    }
    return table[mod]
```

```python
class DialogueToolBudget:
    def __init__(self, dialog=None, tool=None, base=None):
        self.B_dialog = dialog or DialogBudget()
        self.B_tool = tool or ToolBudget()
        self.B_base = base or CognitiveBudget()   # 第 60 轮四维预算

            return "SAFE_STOP"                    # fail-closed

            return "SCRIPTED_CONFIRM"             # 单轮脚本化
```

```python
def dialogue_tool_contract_loop(M, user_utt, delta_f_req):
    s, status = M.dsm.step(user_utt, M.ctx)
    if status == "ASK":
        return M, M.dsm.ask(), "AWAIT_USER"

    C_intent = interpret_constraint(s)
    M.ertc.lock_constraints(C_intent)

    plan = M.planner.propose(s)                # 可能来自大模型
    ok, obligations = M.tool_registry.compose(plan)
    if not ok:
        return M, M.tool_registry.explain(obligations), "REPLAN"

    K_safe = M.eeis.compile_with_scene_prior(
        M.scene_model.get_scene_impedance_prior(), delta_f_req)
    decision = clarification_halt_policy(s, K_safe, M.budget)
    if decision in ("ASK", "PROBE"):
        return M, decision, decision

    M, fused, D_plus, EV_exec, cert = closed_loop_exec_probe(
        M, M.current_cp, delta_f_req, M.budget.B_base)

    g = build_provenance(M.trace)
    M.trace.commitments = settle(M.dsm.Pi, M.trace)
    if not dta_valid(M.trace, M.dsm.K, M.dsm.promised_K):
        M = revoke_and_propagate(g, target=find_violation(M.trace))
        return M, "DTA_VIOLATION", "SAFE_STOP"

    return M, (g, EV_exec, cert), "DONE"
```
