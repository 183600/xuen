# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互的不确定性二分闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「机器人基础模型」×「场景理解」）

> R69 完成了两次漂亮的跃迁：把不确定性拆成 aleatoric / epistemic，又给系统装上了「开口问」的能力。但它有一个从未言明、也从未被检验的前提——**被问的世界，已经完整地活在我的表征 z_t 里**。U_ale 是「同一动作里的噪声」，U_epi 是「已表征出的几个模态中选哪个」；二者都**条件于**观测/表征 z_t。R69 从不问：**这个 z_t 里，是否根本就不存在任务所需的那个区别？**
>
> 机器人基础模型（RFM）恰恰是这个问题的高发地带。RFM 不是一只更清晰的眼镜，而是一个**在通用数据分布上做率失真优化的、有偏的压缩器**：它把比特优先分配给训练分布里高频、显眼的区别，悄悄丢掉罕见却致命的区别——脆弱性、温度、遮挡后的存在、可支撑性、材质对摩擦的影响。场景理解则是把这个压缩结果**解码成任务谓词**的过程。于是失败不再只是「我该选左还是右」，而是「我的本体里根本没有『左』和『右』这两个可区分的概念」。**对着盲点提问，得到的只是回声。**
>
> 本轮两个灵感正好各补一块：
> - **机器人基础模型**给出一个共享 trunk：同一个 z 同时喂养**语言头（声明式场景理解）**与**动作头（程序式场景理解）**。二者的裂口是一条不需要额外标注的审计通道；
> - **场景理解**告诉我们，任务谓词是**任务相关**且**视角相关**的：同一表征对「拿红杯」充分，对「拿不会碎的那个」可能完全不充分。因此「够不够用」必须对着任务、并在新的观测通道上被检验。
>
> 核心命题：**在 R69 的两轴不确定性（aleatoric / epistemic）之外，加入第三轴——表征充分性不确定 U_rep（我的场景表征是否保留了这个任务所需的区别）；把「问什么模态」升级为「先问我的表征漏掉了什么、漏掉的是否可获取、该沿哪个被丢掉的方向去激发新观测」；只有可获取且可负担时才修复表征，不可获取的亏空一律降格为 aleatoric 并退回 R68 保守。** 命名 **SCOPE-RAS**（Sufficiency-Certified Ontology Probing & Exploration for Risk-Adaptive Systems：任务充分性认证的场景本体探询闭环）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我看到的世界，是否包含这个任务所需的区别？若没有，我还能不能看见？**」——不确定性不只是噪声、也不只是歧义，还可能是一整块**从未进入过我表征的空白**。

## 0. 直觉与动机

**灵感 1（RFM 是有偏压缩器，不是更清楚的眼镜）**
直觉：预训练本质上是在通用任务分布下做率失真（rate–distortion）优化。比特是有限的，模型必然把分辨率花在「常见且显眼」的区别上：椅子 vs 桌子、红 vs 蓝、开 vs 关；而把「这把椅子能不能承重」「这块玻璃是否已裂」「被布盖住的物体是否仍在那儿」压到低比特甚至零比特。模型的自信不是场景的属性，而是**训练分布的回声**。场景理解因此是一个逆问题：从有损码 z 里恢复任务谓词。**关键不是模型错，而是它错得很稳定、很自信、且下游完全看不见自己丢了什么。**

**灵感 2（场景理解的「知道—做到」裂口是一条免费审计通道）**
直觉：RFM 通常共享 trunk：语言头能把场景说清楚（「杯子是空的」），动作头却按另一套隐含谓词行动（抓取轨迹预期了重量）。人可以「嘴上说一套、手上做一套」，模型也会。更一般地，语言头给出**声明式**场景理解，动作/几何/接触给出**程序式**场景理解；二者在真实场景下应当收敛，在表征不足或接地错误时会分叉。这个分叉不需要人工标注，是 RFM 结构自带的**第二意见**——R68 用残差、R69 用流似然，R70 用**说与做的差**。语义—几何版本同样成立：语言说「杯在桌上」，深度/支撑关系说「悬空」，二者矛盾即为表征可疑。

**灵感 3（第三轴是「前置」的，不是并列的）**
直觉：U_ale 与 U_epi 都默认「候选假设空间是对的」；U_rep 质疑的正是这个假设空间本身。若任务相关的属性 A 不由 z 的 σ-代数生成（A 不可从 z 测出），那么 R69 再怎么在「已表征的几个模态」之间做 VoI，对 A 的信息增益恒为零——**在错误的地图上找路，问得越多，走得越远**。所以三轴有严格的**层级**：先证表征够用（U_rep），再消歧（U_epi），最后才谈噪声（U_ale）。这也是本轮的理论姿态：**新层必须把旧层包含为「表征充分」的边界情形，而不是与之并列**。

**灵感 4（修复表征 ≠ 再多看一眼，而是沿被丢掉的方向激发新观测）**
直觉：如果缺陷方向 n 落在编码器 Φ 的零空间里，那么**同一个视角再看一百眼也没用**——该视角能提供的关于 n 的信息早已被榨干。要获取 n，必须改变**观测通道**：换视角/换尺度（去遮挡、提分辨率）、换模态（深度/触觉/音频/热）、做物理探针（推一下、抬一下以暴露质量与脆弱性）、发起接地问句（请求指认/示范）、或切换本体（换一个头/工具/提示词/坐标系）。这把 R69 的「看/问/触」从「消解已表征的模态」升级为「激发未表征的方向」。形式化后 VoI_rep(g) ≤ I(N_τ; y|g)：**不激发零空间方向的动作，信息增益严格为零**。

**灵感 5（双刃剑：自证、无限探询、诱导与对抗场景）**
直觉：一旦系统开始审计「我的表征够不够」，就出现四个新陷阱。其一，**自证陷阱**：用同一个 RFM 生成探针、再用它判分，等于让盲人给自己测视力——先验为零的方向上，缺陷率会恰好估计为 0。其二，**无限探询**：开放世界里 U_rep 永远可以「再确认一点」，若不设不可获取性判据与硬预算，系统会陷入分析瘫痪。其三，**诱导性共识**：机器人用带候选的问句「你是指红杯还是蓝杯？」去问，人类的顺从偏差会把机器人的本体强加给世界，制造出「已被验证」的假象。其四，**对抗场景**：镜面、贴图、假物体、语义伪装都能精准利用 RFM 先验。所以本轮必须同时交付：外部探针集（不共享被测模型先验）、不可获取性门、有限停止规则、接地纪律与诱导问题防护、对抗场景干扰集 ℰ_scene。否则 R70 只是给 R69 的「会提问的嘴」又配了一副「会自我催眠的眼睛」。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（SCOPE-RAS 总览与三不变式）** SCOPE-RAS = (TSP, DPC, DEF, RPE, RRC, ONA, SCM, NAG, SCG, SGB, RAS-WM§)。三不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i；探针分类器、语言头、动作头全部冻结）；
(ii) **探针外部性**：充分性证书所用的最小对探针集 𝒞_τ 必须**独立于被测 RFM** 生成（可控渲染/仿真/独立几何引擎/人类对照），否则证书无效；
(iii) **分层修复 + 硬预算 + 可停止**：决策顺序为「表征 → 歧义 → 噪声」；所有修复动作须过 C-RAS-WM 认证；总探询预算 B_rep 为硬约束；一旦判为不可获取即停止，不得以「再确认一下」为由延长。

**定义 311（任务相关谓词与任务等价）** 设场景 S 的谓词集 P = {p_1,…,p_m}（物体身份、位姿、尺度、关系、可供性、自由空间、材质/脆弱性/质量等）。任务 τ 诱导任务相关子集 P_τ ⊆ P 与容差 ε_τ。定义场景等价 s ~_τ s′ ⇔ 在 ε_τ 内最优决策/价值相同。场景理解对 τ 的任务就是**保真 ~_τ**：该分的分开，该同的同。

**定义 312（表征充分性与任务信息亏空）** 编码器 Φ: O → Z，z = Φ(o)。任务结果 Y。定义
D_τ = I(S; Y | τ) − I(Z; Y | τ) ≥ 0。
z 对 τ **充分** ⇔ D_τ ≤ ε_suff（等价地，贝叶斯风险差 R*(S) − R*(Z) ≤ ε_r）。注意 D_τ 是 **(表征, 任务) 对**的性质，不是模型单独的性质：同一 RFM 对「拿红杯」充分，对「拿不会碎的那个」可能完全不充分。

**定义 313（最小对探针集与双缺陷）** 外部生成 𝒞_τ = 𝒞_τ^+ ∪ 𝒞_τ^-：正对本应被区分（仅沿任务相关属性不同），负对本应保持不变（仅沿任务无关属性不同）。
- **崩塌率** δ_dis = P[z(s) ≈ z(s′) | (s,s′) ∈ 𝒞_τ^+]（假不变性：最危险）；
- **虚假区分率** δ_inv = P[π(z(s)) ≠ π(z(s′)) | (s,s′) ∈ 𝒞_τ^-]（假敏感性：多致保守，少致危险）。
证书阈值**非对称**：ε_d ≪ ε_i。U_rep 取风险加权对 (δ_dis, δ_inv)，而非简单标量。

**定义 314（声明—程序双通道场景理解 DPC）** 语言头 h_L: Z → Δ(P) 给声明式谓词；程序式谓词 h_π 由动作头/探针分类器/几何引擎反推（策略在候选谓词条件下的动作似然、支撑/接触一致性）。一致性 Ψ = 1 − E[1{h_L ≠ h_π}]，不一致集 ℐ。语义—几何特例：h_L 说「杯在桌上」而深度/支撑图说「悬空」即计入 ℐ。ℐ 是 RFM 自带的、无需标注的审计证据。

**定义 315（亏空子空间与可激发性）** 在 z 局部，任务相关方向由最优动作对场景属性的雅可比张成；落在 ker Φ 内的任务相关方向构成**亏空子空间** N_τ。修复动作 g 诱导观测通道 p(y|s,g)。定义**激发度** E(g) = I(N_τ; y | g)。称亏空**可获取** ⇔ 在传感器/动作包络内 max_g E(g) ≥ ε_e；否则为**不可获取**。

**定义 316（三轴不确定性分解与层级）** U_ale（模态内噪声，不可约）、U_epi（已表征模态间歧义，可约）、U_rep（表征充分性亏空，可修复或不可获取）。三者**不做简单加和**，而按任务门控的偏序处置：
U_rep > τ_rep（任务相关且超阈）⇒ 先修复表征；修复后或 U_rep ≤ τ_rep ⇒ 走 R69 处理 U_epi；残余一律并入 U_ale 兜底（定义 323）。op(U_rep) 由 δ_dis/δ_inv 与 D̂_τ 的校准估计给出。

**定义 317（表征修复动作空间）** 𝒜_rep = {g_view（视角/位姿改变）, g_scale（变焦/靠近/提分辨率）, g_mod（切深度/触觉/音频/热）, g_phys（推/抬/压以暴露质量、脆弱、摩擦）, g_ask（中性接地问句）, g_onto（换语言头/工具/提示词/坐标系/本体）}。g_phys 与 g_ask 继承 R69 的认证与证据纪律；g_view/g_mod 需满足运动学与时间预算；g_onto 必须声明切换后的表征版本并重新认证。

**定义 318（VoI_rep 控制器 RPE）** 
VoI_rep(g) = E_{y~p(·|g)}[D̂_τ(belief) − D̂_τ(belief|y)] ≤ E(g) = I(N_τ; y|g)。
选择 g* = argmax_g [VoI_rep(g) − c(g)]，s.t. 安全认证通过、B_rep 未越界、且 g 的输出仍落在 A_adm（继承 R69/R68 的安全包络）。若 max[VoI_rep − c] ≤ 0 ⇒ 不修复，转 NAG 或保守。**零激发动作（同视角重复看）在此式下自动零收益**，这是与 R69 MINT 的本质区别。

**定义 319（本体协商 ONA 与谓词采纳纪律）** 开放词汇谓词可由人类提议并通过 g_ask 引入。采纳规则：
(a) 至少两个正交证据源一致（声明 + 程序/几何/接触）；
(b) **诱导问题防护**：问句不得在提示中嵌入候选本体；若必须给候选，则候选集需平衡且随机化，否则回答降级为弱证据；
(c) 采纳后谓词进入 P_τ 并触发一次外部探针补测。防的是「机器人用自己的本体逼世界点头」。

**定义 320（充分性证书 SCM）** SC_τ(RFM; 𝒞_τ, ε) 有效 ⇔ δ_dis ≤ ε_d ∧ δ_inv ≤ ε_i ∧ 行为价值差 ≤ ε_b ∧ 探针集**外部生成** ∧ D̂_τ 的校准误差 ECE ≤ τ_ece ∧ 未过期（定义 326）。证书携带 probe_suite_hash 与 scope_ver，可被审计复现。

**定义 321（不可获取性判据 NAG 与停止规则）** 若 ∀g ∈ 包络内，E(g) < ε_e 或 c(g) > 剩余预算，则判亏空为**不可获取** U_rep^irr，签发不可获取证书并**停止探询**；该亏空按 aleatoric 处理（定义 323）。若仍有可获取方向但 VoI_rep ≤ c，同样停止。停止规则使「再确认一点」不能无限延长（定理 19）。

**定义 322（场景充分性校准门 SCG）** D̂_τ/δ_dis 的估计必须校准（可靠图 + ECE）。ECE > τ_ece ⇒ 禁用修复决策：若 R69 的模态校准仍有效则退回 FLUID-RAS，否则退回 R68 纯保守。**不可信的充分性估计既不能驱动修复，也不能为「已充分」背书。**

**定义 323（三级退避与 resolution bonus）** 
- SC 有效且 U_rep ≤ τ_rep：λ = λ_floor(U_ale)，并把 U_epi 交给 R69 消解（表征分辨率奖励）；
- 可修复且修复成功：以修复后的 z′ 重算 U_rep/U_epi/U_ale，λ 至少不弱于修复前；
- 不可获取 / 预算耗尽 / SCG 越界 / 修复失败：λ = λ_floor(U_ale + U_epi + U_rep^irr)，未消解的一切视同 aleatoric ⇒ 逐指令退化为 R68。
安全侧单调：任何路径的 λ 都不低于 R68 对应值。

**定义 324（对抗场景模型 ℰ_scene）** 针对 RFM 先验的攻击集：对抗贴图/光学错觉、镜面与透明体、假物体与空想性错视（pareidolia）、语义伪装（把危险物做得像常见安全物）、遮挡制造的存在性歧义、以及利用语言先验的「场景应当如此」幻觉。ℰ_SCOPE = ℰ_FLUID × ℰ_scene。

**定义 325（参与式审计 VQAuditor-S 与证书 J_SCOPE）** 审计对象新增：探针集是否独立、问句是否诱导、谓词是否单源采纳、零空间是否被系统性忽略、证书是否过期。J_SCOPE = (J_FLUID, δ_dis, δ_inv, E(g*), D̂_after, probe_suite_hash, SC_hash, staleness, scope_ver)。Valid ⇔ Valid(J_FLUID) ∧ SC 有效或已正确降级 ∧ 证据纪律满足 ∧ B_rep 未越界。

**定义 326（充分性时效与再认证）** 场景随时间变化，旧证书会失效。定义充分性半衰期 T_suff(τ, 场景动态) 与场景漂移监测（探针残差 CUSUM + WM 惊讶度）。当 staleness > T_suff 或漂移超阈 ⇒ SC 作废、必须再认证；「曾经充分」不等于「现在充分」。这把 R68 的「标定会漂」推进到「**表征本身会过期**」。

## 2. 关键算法骨架

```python
# IP-264 TSP：外部任务充分性探针集（独立于被测 RFM）
class SufficiencyProber:
    def __init__(self, renderer, task):               # renderer 不共享 RFM 先验
        self.pairs = build_minimal_pairs(renderer, task)   # +/- 最小对
    def collapse_rate(self, rfm):
        pos = [p for p in self.pairs if p.should_distinguish]
        return mean(cosine(rfm.encode(p.s1), rfm.encode(p.s2)) > TAU_COLLAPSE
                    for p in pos)

# IP-265 DPC：声明—程序（语义—几何）双通道一致性
def consistency(rfm, z):
    p_lang = rfm.lang_head(z)                         # 声明式谓词
    p_beh  = infer_from_policy(rfm, z)                # 程序式 / 几何 / 接触
    return agreement(p_lang, p_beh), p_lang - p_beh   # Ψ, 不一致集 I

# IP-266 DEF：用「原始可解码 vs 表征可解码」的差定位零空间方向
def deficiency_subspace(rfm, o, probes):
    f_raw = independent_features(o)                   # 深度/几何/独立引擎
    gap   = probe_accuracy(probes, f_raw) - probe_accuracy(probes, rfm.encode(o))
    return fisher_directions(clip(gap, 0))            # N_tau 的估计

# IP-267 RPE：只在能激发亏空方向的动作里选（同视角重复看 = 零收益）
def choose_repair(rfm, z, N_tau, budget):
    best = None
    for g in repair_candidates(N_tau):                # view/scale/mod/phys/ask/onto
        if not budget.allow(g): continue
        if not c_ras_wm.certify_info(g, z): continue
        excite = expected_info(N_tau, g)              # E(g)
        voi    = min(excite, est_deficit(z))          # VoI_rep <= E(g)
        score  = voi - cost(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None  # 无利可图 => NAG / 保守

# IP-268 ONA：接地问句 + 诱导防护 + 双源采纳
def negotiate(proposal, evidence, query):
    if is_leading(query): return 'weak'
    return 'adopt' if orthogonal_agree(evidence, k=2) else 'undecided'

# IP-269 RRC：执行修复并重编码（可能换模态/换本体/物理探针）
def repair(rfm, g, o):
    o_new = execute(g, o)                             # 看/移/触/问/换头
    return rfm.encode(o_new), expected_info_gain(g)

# IP-276 主闭环：先表征、再歧义、后噪声（严格包含 R69/R68）
def SCOPE_round(M, obs):
    z, o = M.rfm.encode(obs), obs
    # 0) 表征审计：外部探针 + 双通道 + 零空间定位
    d_hat, sc = M.scm.estimate(z, M.task, M.suf_suite)
    if not sc.valid:
        N_tau = M.def_.subspace(o, M.suf_suite.probes)
        g = M.rpe.choose_repair(M.rfm, z, N_tau, M.budget)
        if g is not None:
            z, _ = M.rrc.repair(M.rfm, g, o)
            d_hat = M.scm.reestimate(z, M.task)
        else:
            d_hat = M.nag.certify(z, M.budget)        # 可能标记 U_rep^irr
    # 1) 表征够用才进 R69；否则保守
    if d_hat <= TAU_REP and M.scg.ok():
        k, lam, mode, U = M.fluid.round(z)            # 继承 FLUID-RAS
    else:
        k, lam, mode, U = M.r68.round(z)              # 保守退避
        lam = max(lam, lam_floor(U_ale + U_epi + d_hat))
    # 2) 审计 + 证书（含探针集哈希与时效）
    M.vqa_s.submit_async(z, d_hat, sc, g, M.probe_log)
    return k, lam, mode, (d_hat, U)
```

## 3. 推导

**引理 19（充分性亏空的可测下界）** 设 A 为任务相关属性、Y 依赖 A，且 A 不由 σ(Z) 生成（不可从 z 测出）。则
D_τ = I(S;Y|τ) − I(Z;Y|τ) ≥ I(A;Y) − I(Z;Y) ≥ 0，
当 A 独立于 Z 时取等号下界 I(A;Y) > 0。对二值 A，H(A|Z)=H(A)，任务贝叶斯误差 ≥ h^{-1}(H(A|Z))；在平衡最小对上，崩塌率满足
R* ≥ δ_dis · r_min，
其中 r_min 为崩塌类内少数类的最低错误率。系：**表征崩塌不是无害的「模糊」，它直接给任务风险设了下界**；且该下界无法被 R69 的模态消歧触及（因为 A 根本不在被消歧的假设空间里）。

**引理 20（只有激发零空间方向才有信息）** 因 Y_g 经 z 与 N_τ 耦合，
VoI_rep(g) = I(N_τ; Y_g | Z) ≤ I(N_τ; y|g) = E(g)。
若 g 的观测通道在给定 z 后与 N_τ 条件独立（例如同一视角的重复采样、同一模态的再量化），则 E(g)=0 ⇒ VoI_rep(g)=0。系：**「同视角多看几眼」在数学上严格无收益**；修复必须改变通道（视角/尺度/模态/物理探针/本体）。若包络内 sup_g E(g) < ε_e，则亏空不可获取，应转 NAG 而非继续探询。

**引理 21（声明—程序不一致的判别力与诱导防护）** 设语言头与动作头在给定真实场景 S 下条件独立，则不一致集 ℐ 中任一谓词至少有一侧未接地（或双侧以相关方式未接地）；因此 Ψ 是 U_rep 的单调代理。对诱导性问句，人类顺从偏差使假共识率放大为 δ_c·ρ^{k−1} + ε_σ（ρ 为「人类顺从」与「机器人先验」的相关性，k 为正交证据源数）；中性问句使 ρ↓、ε_σ↓。系：**问句的形式本身会改变证据的可靠性**，这是 R69 证据纪律未覆盖的一层。

**定理 18（SCOPE 对 R69/R68 的分层严格包含）** 在 A99–A101 下：
(a) 若 SC 有效且 U_rep ≤ τ_rep，则 SCOPE 逐指令等价于 FLUID-RAS（不触发修复，λ 与动作完全相同）；
(b) 若存在 g 使 VoI_rep(g) > c(g) 且修复安全认证通过，则期望风险 ≤ FLUID-RAS，且严格更小当且仅当 D_τ > D_τ^irr；修复只更新对 N_τ 的信念，从不放松安全包络；
(c) 若亏空不可获取 / 预算耗尽 / SCG 越界 / 修复失败，则 λ = λ_floor(U_ale + U_epi + U_rep^irr) ≥ FLUID 的 λ_floor(U_ale + U_epi)，故风险 ≤ FLUID-RAS ≤ R68。
因此 R68 是「无表征审计、无交互」的角点，R69 是「表征充分」的边界；安全侧全程单调不让步。

**定理 19（修复收益上界与有限停止）** 信息增益对观测滤链是次模的，故期望边际 VoI_rep 随已获取观测单调不增；每次修复成本 c ≥ c_min > 0、预算 B_rep 有限，因此最优停止时间 T* ≤ B_rep/c_min，贪心策略的停止 regret 有界。且当 VoI_rep ≤ c + λ·ε_safety 时，修复被保守退避严格支配。期望风险下降满足
ΔR ≤ c · (D_τ − D_τ^irr) · (1 − e^{−VoI_rep})。
系：**有限预算 + 不可获取性判据 + 次模性共同排除了分析瘫痪**——「再确认一点」不是免费选项。

**定理 20（充分性的不可自证性）** 设探针集 𝒞_τ 由被测 RFM 自身的先验 π_Φ（或其解码器）生成。对任意 n ∈ ker Φ 且 π_Φ(n)=0 的方向，所有仅沿 n 不同的探针对在 π_Φ 下等概率，故 z(s)=z(s′) 几乎必然，δ_dis(n)=0。于是 U_rep 的估计**恰好在先验的零支撑上被系统性低估**，且低估量等于该零支撑的质量。故：
(i) 外部探针集（不变式 ii）不是工程偏好，而是**可辨识性的必要条件**；
(ii) 任何「自证式场景理解」要么暗中使用了外部探针，要么在最该报警处失明；
(iii) 残余风险是**结构性**的，不是可用更多数据消除的统计误差。
系：这是本轮最大风险的形式化根源，也是 SCOPE 把「外部性」写成不变式而非模块选项的原因。

## 6. 本轮最大风险

**一句话**：SCOPE 把「我的表征够不够用」的判决权，交给了由**同一个 RFM** 产出的探针、语言头与解码器——若探针集与 RFM 共享同一个先验盲区，δ_dis 会在最该报警的方向上恰好为 0（定理 20），系统于是用一张「已自证充分」的证书，为一个它根本看不见的区别背书；**这不是统计误差，而是结构性自盲：审计者无法用被审计者的眼睛看见自己的盲点。**

**次级风险与缓解**：
1. **分析瘫痪**（开放世界永远可再确认）→ 不可获取性判据 NAG + 硬预算 B_rep + 次模停止（定理 19）；
2. **诱导性共识**（用机器人本体逼世界点头）→ 中性问句 + 候选平衡 + 双源采纳（定义 319、引理 21）；
3. **对抗场景利用先验** → ℰ_scene 对抗训练 + 声明/几何双通道不一致检测（定义 324、E311）；
4. **物理修复动作越界** → g_phys 沿用 R69 认证与 R68 安全包络，修复只改信念不改包络（定理 18-b）；
5. **证书过期/表征漂移** → 时效半衰期 + CUSUM/WM 惊讶度触发再认证（定义 326、E314）。

## 2. 形式化定义（要点版）

**定义 310（总览与三不变式）** SCOPE-RAS 由 11 个组件构成；不变式：(i) 实时零学习写（继承 R68 定义 276-i）；(ii) **探针外部性**——𝒞_τ 必须独立于被测 RFM 生成，否则证书无效；(iii) **分层修复 + 硬预算 + 可停止**——表征→歧义→噪声，所有修复过 C-RAS-WM 认证，B_rep 硬约束，不可获取即停。

**定义 311–312（任务谓词与充分性亏空）** τ 诱导 P_τ 与 ~_τ；`D_τ = I(S;Y|τ) − I(Z;Y|τ) ≥ 0`，z 对 τ 充分 ⇔ D_τ ≤ ε_suff。D_τ 是 **(表征, 任务) 对**的性质：同一 RFM 对「拿红杯」充分，对「拿不会碎的那个」可能不充分。

**定义 313（双缺陷）** 正对崩塌率 `δ_dis = P[z(s)≈z(s') | 正对]`（最危险）；负对虚假区分率 `δ_inv = P[π(z(s))≠π(z(s')) | 负对]`（多致保守）。阈值非对称 ε_d ≪ ε_i。

**定义 314（DPC）** 语言头 h_L 给声明式谓词，动作/几何/接触反推程序式谓词 h_π；一致性 `Ψ = 1 − E[1{h_L≠h_π}]`，不一致集 ℐ。语义—几何特例：语言说「杯在桌上」而深度说「悬空」即入 ℐ。

**定义 315（亏空子空间与可获取性）** `N_τ = ker Φ 中的任务相关方向`；`E(g)=I(N_τ;y|g)`；`max_g E(g) ≥ ε_e` 为可获取，否则不可获取。

**定义 316（三轴与层级）** U_ale / U_epi / U_rep 不简单相加；`U_rep > τ_rep` ⇒ 先修复表征；修复后或 `U_rep ≤ τ_rep` ⇒ R69 处理 U_epi；其余并入 U_ale 兜底。

**定义 317–318（修复动作与 RPE）** `𝒜_rep = {视角, 尺度, 模态, 物理探针, 接地问句, 换本体}`；`g* = argmax[VoI_rep−c]`，`VoI_rep ≤ E(g)`，s.t. 安全认证 + B_rep。同视角重复看 E(g)=0 ⇒ 严格零收益。

**定义 319（ONA）** 开放词汇谓词需 (a) 两个正交源一致；(b) 诱导防护（问句不嵌候选，或候选平衡随机化）；(c) 采纳后触发外部补测。防「用机器人本体逼世界点头」。

**定义 320–322（SC / NAG / SCG）** SC 有效 ⇔ δ_dis≤ε_d ∧ δ_inv≤ε_i ∧ 价值差≤ε_b ∧ 探针外部 ∧ ECE≤τ_ece ∧ 未过期。NAG：包络内 `sup E(g)<ε_e` 或 `c(g)>预算` ⇒ 判 U_rep^irr 并停止。SCG：D̂_τ 的 ECE 越界 ⇒ 禁用修复，退回 R69（若其模态校准有效）或 R68。

**定义 323（三级退避）** 充分 ⇒ `λ=λ_floor(U_ale)` + R69 消歧（resolution bonus）；可修复且成功 ⇒ 用 z′ 重估，λ 不弱于修复前；不可获取/超预算/SCG 越界/失败 ⇒ `λ=λ_floor(U_ale+U_epi+U_rep^irr)`，逐指令退化 R68。λ 全程单调不低于 R68。

**定义 324–326（对抗 / 审计 / 时效）** `ℰ_SCOPE=ℰ_FLUID×ℰ_scene`（贴图、镜面、假物体、语义伪装、语言先验幻觉）；`J_SCOPE` 并入双缺陷、激发度、探针哈希、SC 哈希、staleness；充分性半衰期 `T_suff`，漂移/过期即再认证——「曾经充分」≠「现在充分」。

## 3. 关键算法伪代码

```python
# IP-264 TSP：外部任务充分性探针集（不共享被测 RFM 先验）
class SufficiencyProber:
    def __init__(self, renderer, task):
        self.pairs = build_minimal_pairs(renderer, task)   # +/- 最小对
    def collapse_rate(self, rfm):
        pos = [p for p in self.pairs if p.should_distinguish]
        return mean(cosine(rfm.encode(p.s1), rfm.encode(p.s2)) > TAU_COLLAPSE
                    for p in pos)

# IP-265 DPC：声明—程序（语义—几何）一致性
def consistency(rfm, z):
    p_lang = rfm.lang_head(z)
    p_beh  = infer_from_policy(rfm, z)                 # 动作/几何/接触
    return agreement(p_lang, p_beh), p_lang - p_beh    # Ψ, 不一致集 I

# IP-266 DEF：用「原始可解码 − 表征可解码」定位零空间
def deficiency_subspace(rfm, o, probes):
    f_raw = independent_features(o)                    # 深度/几何/独立引擎
    gap   = probe_accuracy(probes, f_raw) - probe_accuracy(probes, rfm.encode(o))
    return fisher_directions(clip(gap, 0))             # N_tau

# IP-267 RPE：只在能激发亏空方向的动作里选
def choose_repair(rfm, z, N_tau, budget):
    best = None
    for g in repair_candidates(N_tau):                 # view/scale/mod/phys/ask/onto
        if not budget.allow(g): continue
        if not c_ras_wm.certify_info(g, z): continue
        excite = expected_info(N_tau, g)               # E(g)
        score  = min(excite, est_deficit(z)) - cost(g) # VoI_rep <= E(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None   # 无利可图 => NAG / 保守

# IP-268 ONA：接地问句 + 诱导防护 + 双源采纳
def negotiate(proposal, evidence, query):
    if is_leading(query): return 'weak'
    return 'adopt' if orthogonal_agree(evidence, k=2) else 'undecided'

# IP-276 主闭环：先表征、再歧义、后噪声
def SCOPE_round(M, obs):
    z, o = M.rfm.encode(obs), obs
    d_hat, sc = M.scm.estimate(z, M.task, M.suf_suite)
    if not sc.valid:
        N_tau = M.def_.subspace(o, M.suf_suite.probes)
        g = M.rpe.choose_repair(M.rfm, z, N_tau, M.budget)
        if g is not None:
            z, _ = M.rrc.repair(M.rfm, g, o)
            d_hat = M.scm.reestimate(z, M.task)
        else:
            d_hat = M.nag.certify(z, M.budget)         # 可能标记 U_rep^irr
    if d_hat <= TAU_REP and M.scg.ok():
        k, lam, mode, U = M.fluid.round(z)             # 继承 FLUID-RAS
    else:
        k, lam, mode, U = M.r68.round(z)               # 保守退避
        lam = max(lam, lam_floor(U_ale + U_epi + d_hat))
    M.vqa_s.submit_async(z, d_hat, sc, g, M.probe_log)
    return k, lam, mode, (d_hat, U)
```

## 4. 推导

**引理 19（充分性亏空的可测下界）** A 为任务相关属性、Y 依赖 A 且 A 不由 σ(Z) 生成，则 `D_τ ≥ I(A;Y) − I(Z;Y) ≥ 0`；A⊥Z 时下界为 `I(A;Y)`。二值情形任务贝叶斯误差 ≥ `h⁻¹(H(A|Z))`；平衡最小对上有 `R* ≥ δ_dis·r_min`。系：**表征崩塌给任务风险设了下界，且该下界无法被 R69 的模态消歧触及**（A 不在被消歧的假设空间里）。

**引理 20（只有激发零空间方向才有信息）** `VoI_rep(g)=I(N_τ;Y_g|Z) ≤ I(N_τ;y|g)=E(g)`。若 g 的通道在给定 z 后与 N_τ 条件独立（同视角重复采样、同模态再量化），则 `E(g)=0`。系：**「同视角多看几眼」严格无收益**；若包络内 `sup E(g)<ε_e`，亏空不可获取，应转 NAG。

**引理 21（DPC 判别力与诱导防护）** h_L 与 h_π 在给定 S 下条件独立时，ℐ 中谓词至少一侧未接地，Ψ 是 U_rep 的单调代理。诱导问句的假共识率为 `δ_c·ρ^{k−1}+ε_σ`（ρ 为人类顺从与机器人先验的相关性，k 为正交源数）；中性问句使 ρ、ε_σ 下降。系：**问句形式本身改变证据可靠性**。

**定理 18（对 R69/R68 的分层严格包含）** A99–A101 下：(a) SC 有效且 `U_rep≤τ_rep` ⇒ 逐指令等价 FLUID-RAS；(b) 存在 `VoI_rep>c` 且认证通过 ⇒ 期望风险 ≤ FLUID，严格更小当且仅当 `D_τ>D_τ^irr`，且修复只改信念、不放松包络；(c) 不可获取/超预算/SCG 越界/失败 ⇒ `λ=λ_floor(U_ale+U_epi+U_rep^irr) ≥ FLUID 的 λ_floor(U_ale+U_epi)` ⇒ 风险 ≤ FLUID ≤ R68。R68=「无审计无交互」角点，R69=「表征充分」边界；安全单调不让步。

**定理 19（有限停止）** 信息增益对观测滤链次模 ⇒ 边际 VoI_rep 单调不增；`c≥c_min>0`、B_rep 有限 ⇒ 最优停止 `T* ≤ B_rep/c_min`，贪心 regret 有界；`VoI_rep ≤ c + λ·ε_safety` 时修复被保守退避严格支配。`ΔR ≤ c·(D_τ−D_τ^irr)(1−e^{−VoI_rep})`。系：**「再确认一点」不是免费选项**。

**定理 20（充分性的不可自证性）** 若 𝒞_τ 由被测 RFM 自身先验 π_Φ 生成，则对任意 `n∈ker Φ` 且 `π_Φ(n)=0`，仅沿 n 不同的探针对在 π_Φ 下等概率 ⇒ `z(s)=z(s')` 几乎必然 ⇒ `δ_dis(n)=0`。故 U_rep 估计**恰好在先验零支撑上被系统性低估**，低估量等于该零支撑质量。因此：(i) 外部探针是可辨识性必要条件，非工程偏好；(ii) 任何「自证式场景理解」要么暗中用了外部探针，要么在最该报警处失明；(iii) 残余风险是**结构性**的，不能靠更多数据消除。系：这是最大风险的形式化根源。

## 7. 本轮最大风险

**一句话**：SCOPE 把「我的表征够不够用」的判决权交给了由**同一个 RFM** 产出的探针、语言头与解码器——若探针集与 RFM 共享同一个先验盲区，`δ_dis` 会在最该报警的方向上恰好为 0（定理 20），系统于是用一张「已自证充分」的证书，为一个它根本看不见的区别背书；**这不是统计误差，而是结构性自盲：审计者无法用被审计者的眼睛看见自己的盲点。**

**次级风险与缓解**：分析瘫痪（NAG + B_rep + 次模停止，定理 19）；诱导性共识（中性问句 + 候选平衡 + 双源采纳，定义 319/引理 21）；对抗场景（ℰ_scene 对抗训练 + 双通道不一致，定义 324/E311）；物理修复越界（沿用 R69 认证与 R68 包络，定理 18-b）；证书过期（T_suff + CUSUM/WM 惊讶度再认证，定义 326/E314）。
