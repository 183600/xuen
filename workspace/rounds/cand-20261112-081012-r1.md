# 第 60 轮（承接第 59 轮「执行接地层」IP-145~151；灵感循环第 1 轮；本轮灵感：「LoRA」×「竞赛策略」）

> 第 59 轮把安全论证一路压到电流环、WCET 与阻抗参数，堵住了「执行器不是理想执行器」的抽象泄漏。但整条证据链仍踩在两个更高层的隐含前提上：**（i）系统只为「任务成功」优化，而 UniBot 的成败由名次/晋级规则决定——期望成功率最大化不一定是名次最优；（ii）系统一旦要适应新场景/新对手，就默认可以「全参数微调」，却从不审计「适应了多少、适应到了哪个子空间、这份适应本身会不会过拟合或被对手诱导」**。本轮两个灵感精准击中这两点：**LoRA** 把「适应」还原为**秩受限的低秩假设类**，秩 r 不再是一个实现细节，而是**可计量、可预算、可过期**的容量旋钮；**竞赛策略**把目标从「成功率」还原为**带失格硬约束的排序效用**——名次是随机的、规则是分阶段的、对手是非平稳且会针对你调整的。本轮核心命题：**「把策略适应降维成低秩子空间上的可证伪假设，把竞赛目标升维成带失格约束的排序博弈；用『秩预算 B_rank』作为探针/微调/解释/执行之外的第五种可分配资源，实现『只在能提升名次的子空间里适应，且适应得越少越安全』」**——从第 59 轮的**执行接地**推进到**竞赛接地（Competition-Grounded Strategy）**。

核心矛盾：

- **H38（策略过拟合·全秩适应在非平稳对手下最脆）**：竞赛中的对手分布随轮次、地图、其他队伍的军备竞赛而漂移。若每场都用全参数微调去拟合「上一个对手/上一张地图」，则适配器学到的是**对手的最近样本**而不是**可迁移的策略先验**；一旦对手换招，性能断崖。低秩假设类能限制过拟合，但秩太低会欠拟合、秩太高又会把噪声当策略——**秩本身必须由证据量 n 与泛化界共同决定，而不是手调超参**。
- **H39（效用错位·期望成功率 ≠ 名次）**：现有证据门优化的是 `P_safe` 与期望任务成功，但竞赛效用是**排序的、非线性的**：晋级赛只关心 `P(rank≤k)`，决赛关心冠军的凸收益，而「稳稳拿第 5」在晋级规则下可能毫无价值。与此同时，追名次会诱惑系统冒**失格风险**（超时、违规接触、安全事件）。因此需要一个**名次感知、风险预算随名次差动态调整**的控制器：落后时允许更高上行风险，领先时压缩方差，且**永远把失格概率作为硬约束**。
- **H40（对手推断的自指性·策略证据会被自己的适应污染）**：从对手行为反推其策略是一个证据问题，但**我们的适应会改变对手的最优反应**（performative prediction）：对手的「新行为」可能只是对我们新策略的回应，却被误读成对手的固有类型。若用被污染的证据去更新适配器，就会形成**自证预言**；更糟的是，对手可故意打出诱导性动作，让我们把秩预算花在错误的子空间上。
- **H41（安全子空间侵蚀·低秩更新不等于安全更新）**：LoRA 的更新虽然秩低，但仍可能恰好落在**安全关键方向**（力限幅、稳定性余量、速度上限）上；「参数少」不等于「影响小」。若无安全子空间投影与证书，一个 rank-4 的适配器就足以让上一轮辛苦建立的执行接地全部失效。

## 0. 直觉与动机

**灵感 1（LoRA → 低秩策略适配器 LRSA）**

直觉：把「策略」拆成两层——**共享的安全基座** `W0`（跨场景可迁移的运动/接触技能，永不轻动）与**竞赛专用的低秩策略增量** `ΔW=BA`（只调整「怎么打这一场」）。秩 r 是这条增量能表达的独立策略方向的个数，因此它天然是**容量**：r 越大越能拟合复杂对手，也越容易把对手的偶然动作记成规律。于是「适应多少」第一次变成一个**可被证据约束的标量**，而不是调参玄学。

严谨化的关键有三点。其一，**秩-证据匹配**：低秩矩阵类的复杂度约为 `O(r(d+k))`，用 Rademacher/一致收敛给出泛化间隙 `gap(r,n) ≤ c·sqrt(r(d+k)log(d+k)/n) + sqrt(log(1/δ)/2n)`；给定允许的策略泛化误差 `ε_strat` 与有效对局样本量 n，取 `r* = max{r : gap(r,n) ≤ ε_strat}`。样本少时自动退到低秩，样本多时才允许升秩——这把 LoRA 的 rank 与证据量**显式绑定**。
其二，**秩预算化**：`B_rank=(r_total,{r_c},r_used)` 与探针/微调/解释/执行预算并列，分配到「区域/对手簇/赛段」上；每提升一秩的边际名次收益递减，用背包/注水法分配，**耗尽即回退基座**。
其三，**安全保持投影**：把适配器更新投影到安全关键雅可比 `J_S` 的子空间之外，并要求信任域 `KL(π_θ‖π_θ0) ≤ ε_KL`；只有同时满足「秩够、泛化界够、安全子空间重叠小、校准集安全裕度不降」四条的适配器才允许上线，否则**宁可不适应（abstain）**。

**灵感 2（竞赛策略 → 名次效用与风险控制器 CARU + 对手推断 OSI）**

直觉：竞赛不是「把任务做完」，而是**在有限赛段里把分数换成名次**。因此目标函数应从 `E[success]` 换成 `E[φ(rank_H)]`（φ 可为「晋级指示」或「名次的对数效用」），并在其上加两层：**下行的 CVaR 惩罚**（避免为了搏冠军把整场打崩）与**失格硬约束**（`P(DQ) ≤ δ_dq`）。风险偏好不该是全局常数，而应由**当前名次差 × 剩余赛段价值**内生决定：落后时安全约束的影子价格下降（值得冒险），领先时上升（守成）。

同时，竞赛策略的另一半是**对手**。把对手策略压成低维类型 `z`，用逆规划/行为嵌入从可观测动作推断后验 `b_t(z)`，并用 CUSUM 检测换招。这里必须引入**表演性（performative）护栏**：只用滞后策略数据或随机化探针估计对手类型，避免把我们自己造成的行为当成对手的固有属性；一旦不可辨识或检测到换招，就**停止利用、重置对手先验、续约秩预算**。

**灵感 3（两灵感合流 → 竞赛接地闭环 CGSL）**

直觉：第 59 轮是「证据层 ↔ 执行层」的双向契约，本轮补上**目标层与策略层**：`竞赛规则/名次 → 风险预算 δ_f^(s) → 秩预算 B_rank → 低秩适配器 ΔW → 执行/接触 → 名次与证据`。适配器只能在「能提高名次且安全证书有效」的子空间里生长；执行结果与名次结果反过来审计适配器是否真的有用，并决定是否续约秩预算。于是**「适应」不再是无条件的能力展示，而是一次有成本、会过期、可被证伪的竞赛投资**。

## 1. 形式化定义（增量：定义 153–160）

**定义 153（低秩策略适配器 LRSA）** 基座策略 `π_θ0(a|s)=softmax(W0·φ(s))`，`W0∈ℝ^{d×k}`。秩 r 适配器 `ΔW=B·A`，`B∈ℝ^{d×r}`，`A∈ℝ^{r×k}`，`α` 为缩放。适配策略
```
π_{θ0,r}(a|s) = softmax((W0 + α·B·A)·φ(s))
```
假设类 `ℋ_r={ΔW | rank(ΔW)≤r, ‖ΔW‖_*≤Λ}`。容量 `C(r)=2r(d+k)`；以 1−δ 概率，对任意 `ΔW∈ℋ_r` 有泛化间隙
```
gap(r,n) ≤ 2·R_n(ℋ_r) + sqrt(log(1/δ)/(2n)),
R_n(ℋ_r) ≤ Λ·sqrt(2·C(r)·log(2(d+k))/n)
```
**秩-证据匹配原则**：给定策略证据有效样本量 `n_val` 与允许间隙 `ε_strat`，取
```
r*(n_val, ε_strat) = max{ r ≤ r_max : gap(r, n_val) ≤ ε_strat }
```
约束：适配器**只能作用于策略头/规划先验**，不得直接改写安全监视器、WCET 契约与电流环参数（这些属于第 59 轮 ERTC/EEIS 的硬约束域）。

**定义 154（秩预算 B_rank）** `B_rank=(r_total, {r_c}_{c∈𝒞}, r_used, epoch, n_val^c)`，`𝒞` 为区域/对手簇/赛段集合。第 c 项的边际名次收益 `μ_c(r)=U_c(r)−U_c(r−1)`（用留出对局估）。分配问题：
```
max_{r_c} Σ_c U_c(r_c)   s.t.  Σ_c r_c ≤ r_total,  0 ≤ r_c ≤ r_max
```
用边际收益/成本递减的贪心注水求解。`r_used` 单调消耗；**秩预算续约**只在两种情况发生：(i) 检测到策略 changepoint（新 epoch）；(ii) 留出验证显示旧适配器仍有效且新增样本使 `r*(n_val)` 增大。预算耗尽 ⇒ 冻结适配，回退基座策略。

**定义 155（竞赛效用与风险控制器 CARU）** 竞赛为有限期随机博弈 `G=(𝒮,𝒜,P,{u_i},H)`；我方名次 `rank_t = 1 + Σ_{j≠i} 1[s_j > s_i]`。竞赛效用
```
U_comp(π) = E[φ(rank_H)] − λ_var·CVaR_β(−φ(rank_H))
φ ∈ { 1[rank_H ≤ k]（晋级）,  log(1 + 1/rank_H)（名次弹性） }
```
策略选择为约束优化：
```
π* = argmax_{π∈Π(r,B_rank)} U_comp(π)
     s.t.  P(DQ) ≤ δ_dq,                 # 超时/违规/安全事件（硬约束）
           P(安全违例) ≤ δ_f^(s),        # 沿用第 59 轮执行接地安全界
           Cert_lora 有效
```
**名次自适应风险预算**：设 `δ_f^(s) = δ_f · w_s`，`Σ_s w_s ≤ 1`，`w_s ∝` 该赛段名次的边际价值；其最优解由安全约束的对偶变量 `λ_risk` 给出——落后时 `λ_risk` 小、允许更大上行风险，领先时 `λ_risk` 大、压缩方差。失格概率 `δ_dq` **永不参与权衡**（不可交换约束）。

**定义 156（安全保持适配器投影 SSG）** 安全约束 `g(θ,s) ≥ 0`（力限幅、稳定性余量、速度/加速度上限、接触几何）。在校准状态集上取安全关键雅可比 `J_S=∂g/∂θ`，其前 `r_s` 个左奇异向量张成安全关键子空间 `U_S`。投影算子 `P_⊥=I−U_S U_Sᵀ`，安全适配器 `ΔW_safe=P_⊥·B·A`。证书
```
Cert_lora = (r, r_used, ‖ΔW‖_*, ρ_safety, ε_KL, min_s g(θ0+ΔW_safe,s),
             gap(r,n_val), n_val, adapter_version, base_version, timestamp)
ρ_safety = ‖U_Sᵀ·ΔW_safe‖_F / (‖ΔW_safe‖_F + ε)
```
**上线判据（四门全过）**：`ρ_safety ≤ ρ_max` ∧ `min_s g(θ0+ΔW_safe,s) ≥ g_min` ∧ `KL(π_{θ0,r}‖π_θ0) ≤ ε_KL` ∧ `gap(r,n_val) ≤ ε_strat`；任一不过 ⇒ 适配器作废，回退基座，并记 `EV-strat.cert_ok=false`。

**定义 157（对手策略推断 OSI）** 对手类型 `z∈𝒵`，`dim(𝒵)=d_z`（低维策略嵌入）。用逆规划似然 `P(a_op|s,z)` 做贝叶斯更新得 `b_t(z)`：
```
b_{t+1}(z) ∝ b_t(z)·P(a_op,t | s_t, z)
```
**换招检测**：对数似然比 CUSUM `S_t=max(0,S_{t-1}+log[P(a_t|z_new)/P(a_t|z_old)]−ν)`，`S_t>h` ⇒ 判定 changepoint，重置先验并续约 `B_rank.epoch`。**表演性护栏**：似然只用滞后一步策略或随机化探针样本估计，并扣减表演性偏差 `B_perf`；若 Fisher 信息阵秩 `< d_z`（不可辨识）则保持均匀先验、**禁止对手利用**。输出
```
EV-opp = (b_t(z), H(b_t), S_t, identifiable, B_perf, τ_opp, harm_risk)
```
对手模型**只用于重排策略候选**，不得放宽任何证据门或安全约束。

**定义 158（策略证据 EV-strat 与 XMC++）** 
```
EV-strat = (adapter_version, r_used, gap(r,n_val), Cert_lora, ρ_safety,
            min_s g, KL, b_opp_entropy, changepoint_score, τ_strat,
            performative_flag, rank_gain_est, dq_risk)
```
模态集扩展 `ℳ++ = ℳ+ ∪ {strat}`。分歧 `D++(r) = D+(r) + w_strat·TV(lbl_strat, lbl_fused) + w_strat·|Q_μ_strat(0.99)−Q_μ_fused(0.99)|/μ_scale`。规则：(R1++) `D++>θ_D++` ⇒ 后验加宽并降低适配器置信；(R2++) EV-strat **仅作适配器门控与对账，不作 EV-xmodal/EV-exec/EV-human 替代佐证**；(R3++) `performative_flag ∨ changepoint` ⇒ `ρ_strat` 乘性降级，冻结对手利用；(R4++) `Cert_lora` 失效或 `rank_gain_est≤0` ⇒ 适配器回滚、秩预算冻结。

**定义 159（竞赛接地闭环算子 CGSL）** 单赛段算子：
```
CGSL(M, stage, B, rules):
 ① OSI:  b_opp, S_t, identifiable ← opponent_update(obs_op, lagged_policy)
 ② CARU: rank_gap, w_s, δ_f^(s), δ_dq ← competition_risk(stage, scoreboard, rules)
 ③ Rank: r* ← match(n_val, ε_strat); r_c ← allocate_rank(B_rank, marginal_rank_value)
        if B_rank exhausted: return BASE_FALLBACK
 ④ SSG:  ΔW ← train_low_rank(π_θ0, data, r*)
        ΔW_safe ← P_⊥·ΔW;  Cert_lora ← certify(ΔW_safe, r*, n_val)
        if ¬Cert_lora.valid: return BASE_FALLBACK
 ⑤ Play: 采用 PCE++++（五预算）执行探针/承诺/接触，风险预算 δ_f^(s)
 ⑥ Audit: 收集 EV-strat、EV-exec、名次结果；更新 U_c(r)、r_used
        if S_t>h ∨ performative_flag: renew_epoch(B_rank); freeze_exploit()
 ⑦ Return: (π_{θ0,r*}, Cert_lora, EV-strat, rank_outcome, dq_risk)
```
赛段调度：资格赛优先**保晋级**（低方差、低秩、少探针），决赛按名次差**逐级释放秩预算与风险预算**；任何时刻 `P(DQ)>δ_dq` 立即回退到「保名次基座策略」。

**定义 160（竞赛证书 J_comp 与部署界）** 
```
J_comp = (base_version, adapter_chain{ΔW_safe, Cert_lora, n_val},
          B_rank_log, b_opp_traj, EV_strat_log, CARU_decisions,
          rank_outcomes, changepoint_log, dq_risk_log)
```
部署界（对赛段取联合界）：
```
P(晋级 ∧ 安全) ≥ 1 − Σ_s [ δ_dq + δ_f^(s) + δ_strat(r*,n_val) + δ_opp
                          + δ_perf + δ_changepoint + δ_rank_alloc ]
                − P(基座回退失败) − P(规则理解错误未检出)
```
其中 `δ_strat=gap(r*,n_val)`，`δ_opp` 为对手模型误设，`δ_perf` 为表演性偏差，`δ_changepoint` 为换招漏检。

## 2. 关键算法伪代码

### IP-152 LRSA（低秩策略适配器与秩-证据匹配）

```python
class LowRankStrategyAdapter:
    def __init__(self, base_policy, r_max=16, eps_strat=0.02, delta=0.05):
        self.base = base_policy
        self.r_max, self.eps_strat, self.delta = r_max, eps_strat, delta

    def complexity(self, r, d, k):
        return 2 * r * (d + k)

    def generalization_gap(self, r, n):
        C = self.complexity(r, self.base.d, self.base.k)
        rademacher = self.base.weight_norm * math.sqrt(
            2 * C * math.log(2 * (self.base.d + self.base.k)) / max(n, 1))
        return 2 * rademacher + math.sqrt(math.log(1/self.delta) / (2*max(n,1)))

    def match_rank(self, n_val):
        feasible = [r for r in range(1, self.r_max+1)
                    if self.generalization_gap(r, n_val) <= self.eps_strat]
        return max(feasible) if feasible else 0   # 0 => 不适应

    def fit(self, data, r):
        if r == 0: return None
        B = init_zeros(self.base.d, r); A = init_small(r, self.base.k)
        for _ in range(self.steps):
            grad_B, grad_A = self._low_rank_grad(data, B, A)
            B -= self.lr * grad_B; A -= self.lr * grad_A
        return LowRankDelta(B, A, rank=r)
```

### IP-153 CARU（名次效用与风险控制器）

```python
def competition_risk(stage, scoreboard, rules, delta_f_total, delta_dq):
    rank = 1 + sum(1 for s in scoreboard.others if s > scoreboard.ours)
    gap = max(0, rules.advance_threshold - scoreboard.ours)
    # 赛段价值：越接近决赛/越落后，边际名次价值越高
    marginal_value = rules.stage_weight[stage] * (1 + gap / rules.score_scale)
    w = softmax({s: marginal_value[s] for s in rules.remaining_stages})
    return {
        'rank': rank,
        'delta_f_stage': delta_f_total * w[stage],
        'delta_dq': delta_dq,               # 硬约束，永不放宽
        'risk_appetite': marginal_value,     # 仅影响候选排序
    }

def select_strategy(candidates, U_comp, delta_dq, delta_f_stage):
    feasible = [c for c in candidates
                if c.dq_risk <= delta_dq and c.safety_risk <= delta_f_stage]
    if not feasible:
        return None                          # => 回退保名次基座
    return max(feasible, key=lambda c: U_comp(c))
```

### IP-155 OSI（对手推断+换招检测+表演性护栏）

```python
class OpponentInference:
    def __init__(self, z_dim=4, cusum_h=5.0, cusum_nu=0.5):
        self.b = np.ones(z_dim) / z_dim
        self.S = 0.0; self.h, self.nu = cusum_h, cusum_nu

    def update(self, a_op, s, lagged_policy=True, randomized=False):
        if not (lagged_policy or randomized):
            return self.b, self.S, True     # 表演性护栏：拒绝即时自指证据
        lik = np.array([self.likelihood(a_op, s, z) for z in range(len(self.b))])
        self.b = normalize(self.b * lik)
        old = self.likelihood(a_op, s, self.z_old)
        new = self.likelihood(a_op, s, self.z_new)
        self.S = max(0.0, self.S + math.log((new + 1e-9)/(old + 1e-9)) - self.nu)
        changed = self.S > self.h
        if changed: self.reset_prior(); self.S = 0.0
        identifiable = self.fisher_rank() >= len(self.b)
```

**正确性定理（Competition-Grounded Strategy Soundness, CGSS）** 假设 A22–A55（第 53–59 轮）成立；**(A56)** LRSA：基座策略固定，适配器只在策略头作用；留出验证样本从与竞赛同分布的对局中独立采样；泛化界 gap(r,n) 诚实。**(A57)** CARU：名次规则可形式化为 φ；失格事件可观测；`δ_dq` 硬约束由独立审计器执行。**(A58)** SSG：安全约束 g 在部署分布上可评估；`J_S` 的截断秩 `r_s` 覆盖安全关键方向；证书不可篡改。**(A59)** OSI：对手类型空间低维且可辨识（或不可辨识时被正确弃用）；换招检测漏检率 ≤δ_changepoint；表演性护栏拒绝即时自指证据。**(A60)** 秩预算单调、续约只在 changepoint 或留出验证通过时发生。则：

1. **低秩适应的泛化健全性**：以概率 ≥1−δ，`E[regret(π_{θ0,r})] ≤ empirical_regret + gap(r,n_val)`；取 `r≤r*(n_val,ε_strat)` 时策略泛化间隙 ≤ε_strat，且秩越高所需的 n_val 越大（秩-证据匹配）。
2. **安全保持性**：若 `Cert_lora` 有效，则 `ρ_safety≤ρ_max`、`min_s g≥g_min`、`KL≤ε_KL` 同时成立；适配器在部署分布上的安全违例概率相对基座不增（安全子空间外更新 + 信任域）。
3. **竞赛效用最优性**：在候选策略集上，CGSL 选出的策略是 `U_comp` 的 ε-最优解，且满足 `P(DQ)≤δ_dq`；落后时 `λ_risk` 下降、领先时上升，风险分配随名次差内生调整。

### IP-152 LRSA（低秩策略适配器）

```python
@dataclass
class LowRankDelta:
    B: np.ndarray        # d × r
    A: np.ndarray        # r × k
    rank: int
    alpha: float = 1.0
    def apply(self, W0):
        return W0 + self.alpha * (self.B @ self.A)

class LowRankStrategyAdapter:
    """只在策略头作用；不触碰安全监视器 / ERTC / EEIS 硬约束域。"""
    def __init__(self, base_policy, r_max=16, eps_strat=0.02, delta=0.05, weight_norm=1.0):
        self.base = base_policy
        self.r_max, self.eps_strat, self.delta = r_max, eps_strat, delta
        self.weight_norm = weight_norm

    def capacity(self, r):
        return 2 * r * (self.base.d + self.base.k)

    def generalization_gap(self, r, n):
        if r <= 0: return 0.0
        C = self.capacity(r)
        rad = self.weight_norm * math.sqrt(
            2 * C * math.log(2 * (self.base.d + self.base.k)) / max(n, 1))
        return 2 * rad + math.sqrt(math.log(1 / self.delta) / (2 * max(n, 1)))

    def match_rank(self, n_val):
        ok = [r for r in range(1, self.r_max + 1)
              if self.generalization_gap(r, n_val) <= self.eps_strat]
        if not ok:
            return 0                      # 证据不足以支撑任何适应 => abstain
        return max(ok)

    def fit(self, data, r, steps=200, lr=1e-2):
        B = np.zeros((self.base.d, r))
        A = np.random.normal(0, 0.01, (r, self.base.k))
        for _ in range(steps):
            gB, gA = self._grad(data, B, A)
            B -= lr * gB
            A -= lr * gA
        return LowRankDelta(B, A, r)
```

### IP-153 CARU（名次效用与风险控制器）

```python
@dataclass
class CompetitionRisk:
    rank: int
    delta_f_stage: float
    delta_dq: float
    risk_appetite: float

def competition_risk(stage, scoreboard, rules, delta_f_total, delta_dq):
    rank = 1 + sum(1 for s in scoreboard.others if s > scoreboard.ours)
    gap = max(0.0, rules.advance_threshold - scoreboard.ours)
    stage_value = {s: rules.stage_weight[s] * (1 + gap / rules.score_scale)
                   for s in rules.remaining_stages}
    z = np.array([stage_value[s] for s in rules.remaining_stages])
    w = np.exp(z - z.max()); w /= w.sum()
    return CompetitionRisk(
        rank=rank,
        delta_f_stage=delta_f_total * float(w[rules.remaining_stages.index(stage)]),
        delta_dq=delta_dq,                      # 硬约束，永不参与权衡
        risk_appetite=stage_value[stage],
        stage_weight=rules.stage_weight[stage],
    )

def rank_utility(rank_samples, phi, beta=0.05, lam_var=0.5):
    vals = np.array([phi(r) for r in rank_samples], dtype=float)
    var_tail = np.quantile(-vals, beta)         # CVaR 近似（β 分位尾部）
    return vals.mean() - lam_var * (-var_tail)

def phi_advance(rank, k):      return 1.0 if rank <= k else 0.0
def phi_elastic(rank):         return math.log1p(1.0 / max(rank, 1))

def select_strategy(candidates, risk):
    feasible = [c for c in candidates
                if c.dq_risk <= risk.delta_dq
                and c.safety_risk <= risk.delta_f_stage
                and c.cert_lora_valid]
    if not feasible:
        return None                              # => 回退保名次基座
    return max(feasible, key=lambda c: c.U_comp)
```

### IP-154 SSG（安全子空间投影与证书）

```python
@dataclass
class LoraCertificate:
    rank: int
    nuclear_norm: float
    rho_safety: float
    kl: float
    min_safety_margin: float
    gap: float
    n_val: int
    adapter_version: int
    base_version: int
    timestamp: float
    valid: bool

class StrategySubspaceGuard:
    def __init__(self, safety_constraints, calib_states, r_s=8,
                 rho_max=0.2, eps_kl=0.01, g_min=0.0):
        self.g = safety_constraints
        self.calib = calib_states
        self.r_s = r_s
        self.rho_max, self.eps_kl, self.g_min = rho_max, eps_kl, g_min
        J = self._jacobian(self.base_params, self.calib)   # n_cal × d
        _, _, Vt = np.linalg.svd(J, full_matrices=False)
        self.U_S = Vt[:r_s].T                              # d × r_s

    def project(self, delta: LowRankDelta):
        dW = delta.B @ delta.A
        dW_safe = dW - self.U_S @ (self.U_S.T @ dW)
        # 将投影结果重新因子化为秩不超过 r 的形式（SVD 截断）
        U, S, Vt = np.linalg.svd(dW_safe, full_matrices=False)
        r = delta.rank
        B = U[:, :r] * S[:r]
        A = Vt[:r, :]
        return LowRankDelta(B, A, r), dW, dW_safe

    def certify(self, delta_safe, dW, dW_safe, n_val, adapter_version, base_version):
        denom = np.linalg.norm(dW_safe) + 1e-12
        rho = np.linalg.norm(self.U_S.T @ dW_safe) / denom
        margins = [self.g(self.base_params + dW_safe, s) for s in self.calib]
        kl = kl_divergence(self.policy(self.base_params + dW_safe),
                           self.policy(self.base_params))
        gap = self.lrsa.generalization_gap(delta_safe.rank, n_val) \
              if hasattr(self, 'lrsa') else 0.0
        valid = (rho <= self.rho_max
                 and min(margins) >= self.g_min
                 and kl <= self.eps_kl
                 and gap <= self.eps_strat)
        return LoraCertificate(
            rank=delta_safe.rank, nuclear_norm=float(np.linalg.norm(dW_safe, 'nuc')),
            rho_safety=float(rho), kl=float(kl), min_safety_margin=float(min(margins)),
            gap=float(gap), n_val=n_val, adapter_version=adapter_version,
            base_version=base_version, timestamp=time.monotonic(), valid=valid)
```

### IP-155 OSI（对手推断 + CUSUM + 表演性护栏）

```python
class OpponentInference:
    def __init__(self, z_dim=4, h=5.0, nu=0.5):
        self.b = np.ones(z_dim) / z_dim
        self.S = 0.0
        self.h, self.nu = h, nu
        self.z_old, self.z_new = 0, z_dim - 1

    def fisher_rank(self):
        # 用当前后验加权的得分函数经验 Fisher 阵的秩
        F = sum(self.b[z] * np.outer(self.score(self.obs, z),
                                     self.score(self.obs, z))
                for z in range(len(self.b)))
        return np.linalg.matrix_rank(F, tol=1e-6)

    def update(self, a_op, s, lagged_policy=True, randomized=False):
        if not (lagged_policy or randomized):
            return self.b, self.S, True      # 表演性护栏：拒绝即时自指证据
        lik = np.array([self.likelihood(a_op, s, z) for z in range(len(self.b))])
        self.b = self.b * lik
        self.b /= self.b.sum() + 1e-12
        log_new = math.log(self.likelihood(a_op, s, self.z_new) + 1e-9)
        log_old = math.log(self.likelihood(a_op, s, self.z_old) + 1e-9)
        self.S = max(0.0, self.S + (log_new - log_old) - self.nu)
        changed = self.S > self.h
        if changed:
            self.b = np.ones_like(self.b) / len(self.b)
            self.S = 0.0
        identifiable = self.fisher_rank() >= len(self.b)
        performative_risk = (not identifiable) or changed
        return self.b, self.S, performative_risk
```

```python
class RankBudget:
    def __init__(self, r_total):
        self.r_total = r_total
        self.r_used = 0

    def exhausted(self):

    def allocate(self, marginal_value):
        # 贪心注水：每单位秩给边际名次收益最高者
        alloc = {}
        budget = self.r_total - self.r_used
        while budget > 0 and marginal_value:
            c = max(marginal_value, key=lambda k: marginal_value[k])
            step = 1 if marginal_value[c] > 0 else 0
            if step == 0: break
            alloc[c] = alloc.get(c, 0) + 1
            marginal_value[c] *= 0.8          # 边际收益递减

        self.r_used += sum(alloc.values())
        return alloc
    def renew_epoch(self):

        self.r_used = 0                       # 新 epoch 重新申请秩预算

def competition_grounded_loop(M, stage, rules, B):
    # ① OSI
```

```python
    modalities = ['vis', 'tap', 'prop', 'acou', 'exec', 'strat']
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| LRSA | 训练 O(n·r·(d+k))；秩匹配 O(r_max(d+k)) | O(r(d+k)) | 泛化界 gap(r,n) 可计算；秩-证据匹配 |
| CARU | O(\|候选\| log\|候选\|) | O(\|候选\|) | 名次效用单调、CVaR 下行界、失格硬约束 |
| SSG | 投影 O((d+k)²)；证书 O(n_cal·d) | O(d·r_s) | ρ_safety 有界、KL 信任域、安全裕度不降 |
| OSI | 更新 O(d_z·\|𝒵\|)；CUSUM O(1) | O(\|𝒵\|) | 换招漏检可控、不可辨识即弃用、表演性护栏 |
| CGSL | O(训练+SSG+一次 PCE++++) | 复用全栈 | 五预算单调、四门证书、失格即回退 |
| J_comp | O(1)/赛段追加 | O(赛段数) | 适配器链版本单增、证书可验证、失格风险可追溯 |

**正确性定理（Competition-Grounded Strategy Soundness, CGSS）** 假设 A22–A55（第 53–59 轮）成立；**(A56)** LRSA 泛化界诚实、适配器只作用策略头；**(A57)** CARU 名次规则可形式化、失格可观测且由独立审计器执行；**(A58)** SSG 的 `J_S` 截断秩覆盖安全关键方向、证书不可篡改；**(A59)** OSI 类型空间低维且不可辨识时被正确弃用、换招漏检 ≤δ_changepoint、表演性护栏拒绝即时自指证据；**(A60)** 秩预算单调、仅在 changepoint 或留出验证通过时续约。则：

1. **低秩泛化健全性**：以概率 ≥1−δ，策略泛化间隙 ≤ `empirical + gap(r,n_val)`；取 `r≤r*` 时 ≤ε_strat，且 `r*(n)` 随 n 单调不减。
2. **安全保持性**：`Cert_lora` 有效 ⇒ `ρ_safety≤ρ_max ∧ min_s g≥g_min ∧ KL≤ε_KL`；适配器对执行层安全约束的违例概率相对基座不增。
3. **竞赛效用最优性**：CGSL 在候选中给出 `U_comp` 的 ε-最优策略，且 `P(DQ)≤δ_dq`；`λ_risk` 随名次差（落后）下降、（领先）上升。
4. **单向性**：EV-opp/EV-strat 只能重排候选、加宽后验、触发回退；不能放宽证据门、不能减少探针、不能替代独立佐证；不可辨识或换招即冻结利用。
5. **终止性**：五预算 × 赛段有限 ⇒ 终止于 {适配、基座回退、保名次、停赛}。
6. **部署界**：
```
P(晋级 ∧ 安全) ≥ 1 − Σ_s [δ_dq + δ_f^(s) + δ_strat(r*,n_val) + δ_opp
                        + δ_perf + δ_changepoint + δ_rank_alloc]
                − P(基座回退失败) − P(规则理解错误未检出)
```
任何一项超界，**先牺牲名次，不牺牲失格约束**。
