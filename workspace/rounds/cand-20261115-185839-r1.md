# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧闭环」IP-253~263；灵感循环新循环第 1 轮；本轮灵感：「实时性」×「自主导航」）

> R69 让系统学会了「问」：把不确定性拆成 aleatoric/epistemic，用流匹配策略把歧义显式表示成多模态，用 VoI 决定看/问/触。但 R69 的世界是**没有钟的**——它的成本只由「次数、位移、社交」计量，唯独没有「时间」。它默认：采 K 个模态、聚好类、问出去、等回答，这一整套可以免费地、无限期地发生。对自主导航，这个假设是致命的：**答案到达时，问题已经变了**。
>
> 两个灵感各补一刀：
> - **实时性**不是「延迟低」，而是**及时性**：决策必须在死线前、以足够正确性、对**提交时刻的世界**仍然有效。它同时暴露了 R69 缺的两样东西——计算本身要花时间（计算期机器人仍在动、世界仍在变），以及不确定性不只随观测下降，还会随时间**回升**（观测老化）。
> - **自主导航**给出最强的信息动作：不是看/问/触，而是**运动本身**——探身看拐角、绕到遮挡物另一侧、减速观察到路口清空、靠边让别人先走。信息获取与位移**同构**；于是「获取信息」会消耗任务时间、改变自身状态，并**改写待解的问题**。
>
> 核心命题：**给 R69 的不确定性加上时间维。把静态歧义变成「有半衰期的歧义」；把 VoI 变成「死线感知的 t-VoI（过期即零）」；把信息动作变成占用时空的信息运动；并用「全程有效的兜底动作 MRC + 时空走廊 STC」把实时性从安全域里隔离出去——算不完只损失任务效率，不产生不安全状态。**
> 命名 **KAIROS-RAS**（Kairos-Aware Information-gathering, Real-time, Staleness-aware Risk-Adaptive System；Kairos=恰当时机）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我还来得及吗、问的还是同一个问题吗**」——实时性不是把系统变快，而是让系统知道**什么时候不该再想**。

## 0. 直觉与动机

**灵感 1（实时性 = 及时性，不是低延迟）**
直觉：一个 3ms 算完、但给出的是 200ms 前世界之答案的决策，比一个 10ms 算完、对当前世界有效的决策更危险。实时系统的经典区分在这里全都回来了：*response time*（算多快）、*deadline*（必须何时交）、*timeliness*（交出来的东西是否还对）。R69 的复杂度表只保证前者（P99 延迟 2.6ms），从未定义后者。把「及时」形式化为「在死线前提交 ∧ 对提交时刻的世界仍然有效」两个合取项，立刻发现：第二项 R69 根本没有机制去检查。

**灵感 2（自主导航里，信息动作就是运动）**
直觉：R69 的信息动作是注视/探针/问句，都是「原地不动地采集」。但开车或行走时，解除歧义最常用的手段是**改变 vantage point**：探头看被卡车挡住的斑马线、绕到岔路口看清路牌、减速让侧向来车先暴露意图、靠边停让后车先过。这些动作同时是**任务动作**和**观测动作**，它们占用时间、里程与安全裕度。于是「信息 vs 任务」不再是一个预算计数器，而是一条**时空轨迹的资源分配**问题；更麻烦的是：你为了看清 A 而移动，移动本身可能让你错过 B —— **获取信息会改变问题**。

**灵感 3（不确定性有双向时钟：观测下降、老化回升）**
直觉：R69 隐含假设 U 只会被观测**降低**。但导航中，自上次观测以来世界在动：行人可能已穿过、前车可能已变道、绿灯可能已转红。模态后验会**老化**，epistemic 随时间单调回升，速率由漂移率 ν 决定（半衰期 T₁/₂=ln2/ν）。这就产生 R69 完全没有的动力学：多采样的降熵收益，被采样所花时间内增长的不确定性部分抵消。存在一个**最优停止时刻** τ*：继续想/继续看不再划算，此刻最优决策是「立刻用现有信息做，并保持兜底」。这把 R69 的「自适应 K」从「不确定性驱动」升级为「不确定性 × 时间」驱动。

**灵感 4（问题漂移 / 时间混叠：正确的过期答案 = 错误答案）**
直觉：R69 的交互纪律只防「被投毒的回答」。但还有一类更隐蔽的失效：回答**本身正确**，只是它回答的是 `t_q` 时刻的问题，而决策在 `t_a=t_q+τ` 时刻才用得上。如果 τ 期间模态身份变了（行人已穿过、岔口已过、信号已变），那么把这个正确答案当作当前模态的证据，就是**用旧地图走新路**。必须加一道**时间一致性门（TCG）**：在问与答之间检验模态后验是否漂移超阈；漂移则标记 stale_answer，拒绝发放 resolution bonus。这把 R69 引理 18（空间/语义投毒上界）推广到时间维：**即使没有骗子，时间也会撒谎。**

**灵感 5（死线是新的安全边界：计算期也必须安全）**
直觉：R68/R69 的前缀认证（C-RAS-WM）假设「决策时刻选定动作 → 执行它」。但真实管线里，从开始算到最终动作下发之间有一段窗口 `[t, t+W_p99]`，机器人在这段时间里**仍在运动、世界仍在变化**。如果必须「算完才保证安全」，那么实时性失败就等价于安全失败。破解办法是**把安全与实时解耦**：在计算开始前先进入一条在整个 WCET 内都可行的**最小风险条件（MRC）**轨迹（减速/保持车道/靠边），并认证一条覆盖整个计算窗的**时空走廊（STC）**。这样无论计算在何时被中断、超时、崩溃，系统安全性都不劣于「全程执行 MRC」；实时性失败只退化为任务效率损失。这是本轮最重要的安全命题。

**灵感 6（时间域攻击面：假紧急）**
直觉：一旦「来得及」成为决策变量，对手就可以攻击它。制造紧迫（贴近尾随、突然切入、伪造「马上要撞」的感知）会把 W 压到接近 0，逼系统在低置信下抢答，或触发一次危险的急刹 MRC。**「假紧急」是一种新型社交工程/物理对抗：不是骗你相信错的东西，而是骗你没时间核实。** 因此 KAIROS 必须定义时间域干扰集 ℰ_time，并把「截止期权威」内部化（外部主体不得设置你的死线）。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（KAIROS-RAS 总览与四不变式）** KAIROS-RAS = (KTP, AAS, TVOI, SOS, IAM, STC, MRC, TCG, FMA-t, RAS-WM††)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **计算-安全耦合不变式**：任何被执行的动作必须在整个决策计算窗口 `[t, t+W_p99]` 内保持安全（由 MRC 兜底），即安全是「计算区间」的属性，不是「决策时刻」的属性；
(iii) **时间戳证据不变式**：任何用于定案的观测/回答必须携带可信时间戳与老化上界；年龄超过 τ_stale 的证据不得单独定案；
(iv) **时限包含不变式**：当 W→∞、漂移率 ν→0、计算时间→0 时，KAIROS 逐指令退化为 R69 的 FLUID-RAS（定义 325）。

**定义 311（时间化世界、漂移率与半衰期）** 模态身份过程 `M_t` 取值于有限集 ℳ，切换强度有界为 ν：`P(M_{t+Δ} ≠ M_t) ≤ 1 − e^{−νΔ}`（A99）。定义半衰期 `T_{1/2} = ln2/ν`、老化算子 `A_ν^Δ` 把信念 `b` 沿漂移核推演。假设 A100（老化界）：`H(M_{t+Δ}|o_t) ≥ H(M_t|o_t) + (1−e^{−νΔ})(H_max − H(M_t|o_t)) − ε_age`。即**不确定性不会自己消失，只会自己长大**。

**定义 312（截止期、控制周期与及时性）** 控制周期 `T_c`；任务/安全给出的最迟提交时刻 `t_deadline`；剩余预算 `W = t_deadline − t`。决策「及时」当且仅当 `t_submit ≤ t_deadline` 且 `valid_for_world(t_submit)`（由定义 319 的 TCG 判定）。定义 `P_miss = P(t_submit > t_deadline)` 与 `P_stale = P(提交的决策对提交时刻已失效)`。

**定义 313（计算预算、任意时间风险曲线与死线感知采样 AAS）** 采样预算 `B=(K,N)`，实际耗时 `T_calc(B)` 满足 P99 上界 `T99_calc(B)`（A101，单调增，可在线用历史分位估计）。任意时间性质：对任意预算 B，策略输出带风险上界 `ρ̂(B)` 的决策且 `ρ̂` 单调不增。死线感知选择 `K* = argmax_{K,N} [（ρ̂(B) − ρ̂(B_prev)）/（T99_calc(B) − T99_calc(B_prev)）]`，s.t. `T99_calc(B) ≤ W − W_MRC`。与 R69 定义 308 的关键差别：**K 不只由歧义大小决定，还由「还剩多少时间」决定**——歧义再大，没时间就不升 K，直接走 MRC/最保守。

**定义 314（时限感知信息价值 t-VoI）** R69：`VoI(g)=H(M|o) − E_y[H(M|o,y)]`。KAIROS 引入到达延迟 `τ(g,o)`（规划+执行+感知+推理+人类反应）与漂移：
`t-VoI(g) = E_{τ,y}[ 1{τ ≤ W} · 1{valid(τ)} · (H(M_t|o_t) − H(M_{t+τ}|o_t,y)) ] − c_time·E[τ]`。
第二项的熵是 `t+τ` 时刻的模态（问题漂移），不是查询时刻的模态。若 `τ > T_{1/2}`，即使答案正确，消解的也是「已过期的问题」，`t-VoI` 可为零甚至为负（为过期问题花掉了安全裕度与任务时间）。

**定义 315（信息动作即运动 IAM）** 信息动作从 R69 的瞬时原子 `g=(g_gaze,g_probe,g_ask)` 扩展为**轨迹级** `g_info ∈ 𝒢_info ⊂ 轨迹空间`，包含 `look_around`（探身/环视）、`detour_to_vantage`（绕行到视角点）、`slow_and_observe`（减速观察）、`yield_and_watch`（让行并观察）。它与任务动作共享 R69 的增广动作空间 `ξ=(a,g_info)`，但新增两类约束：时空安全（定义 316）与任务预算（信息绕行里程/时间）。**信息动作会改变状态，因此执行后必须重算模态后验**——这正是定义 319 存在的原因。

**定义 316（时空走廊安全 STC）** R68/R69 的认证在静态空间包络上做。KAIROS 要求认证覆盖「计算+执行」整窗的**时空管**：对 `t'∈[t, t+W_p99]` 预测动态障碍时空占用 `𝒪(t')` 与自身名义轨迹 `Γ(t')`，要求存在一条时空可行轨迹 `Γ_MRC` 使 `Γ_MRC(t') ∉ 𝒪(t')` 且满足动力学/舒适/规则约束。记 STC 证书为 `(Γ, [t,t+W_p99], 𝒪_bound, Γ_MRC)`。

**定义 317（最小风险条件 MRC 与计算期兜底）** 计算期间执行一个在整个 WCET 内保持安全的兜底动作 `u_MRC`（减速/保持车道/靠边/原地最小风险态）。要求：(a) `∀t'∈[t,t+W_p99]`，`u_MRC` 满足 STC；(b) 从 `u_MRC` 切换到最终决策满足 R68 定理 15 的换装不变式（控制连续、无突变）。**MRC 的存在性，是把「实时性」从「安全性」里剥离出来的关键。**

**定义 318（观测老化与最优停止 SOS）** 设上次定案/观测时刻 `t_o`，当前 `t`；老化后 `U_epi^age(t)` 由定义 311 给出；继续采集的瞬时降熵速率为 `r_s`，老化增熵速率为 `ν·h̄`（`h̄ = H_max − H`）。定义净收益
`J(τ) = r_s·τ·e^{−ντ} − c_time·τ − λ_risk·P_miss(τ)`。
最优停止 `τ* = argmax_τ J(τ)`，满足一阶条件 `r_s e^{−ντ*}(1−ντ*) = c_time + λ_risk·p'_miss(τ*)`。系：**ν 越大（世界越快）τ* 越小**——该快想快做；ν 越小（静态世界）τ* 越大——可以多想再问。

**定义 319（时间一致性门 TCG / 问题漂移检测）** 查询时刻 `t_q` 的模态后验 `w(t_q)`，答案到达时刻 `t_a` 用新观测重建的后验 `w(t_a)`。若 `TV(w(t_q), w(t_a)) > τ_drift`，或 `argmax` 身份改变且置信足够，则判 `stale_answer`：回答「答非所问」，**不发放 resolution bonus**，`U_epi` 保持未消解并走 R68 兜底。若信息动作本身改变了状态（定义 315），TCG 在运动前后各做一次检查。这是 R69 交互纪律的时间维补充：R69 防「被投毒的回答」，KAIROS 防「正确的过期回答」。

**定义 320（时限感知流似然 FMA-t 与延迟注入检测）** R69 的 `Δa=|a_score(o) − a_score(o_cal)|` 增加时间项：`D_t = |a_score(ξ|o_t) − a_score(ξ|o_{t−Δ})|/Δ`（行为自洽性的漂移率），与 `Δa`、老化年龄联合判据 `(r_res↓, Δa↑, D_t↑, age↑) ⇒ 缓变故障或延迟注入疑`。同时做时间戳一致性检验：`t_rx − t_stamp` 超过链路预算即判延迟注入/重放。

**定义 321（时钟与时间戳完整性）** 时间戳由可信单调时钟产生，接收时校验三条：非未来、非倒流、在链路预算内。任一失败 → 证据拒绝（不进入定案）。**截止期权威内部化**：`t_deadline` 只能由本体的安全/任务层设定，外部智能体或环境不得直接改写；外部压力只能改变感知到的风险，不能改变你的死线。

**定义 322（时间域干扰集 ℰ_time 与 AIC-KAIROS）** `ℰ_KAIROS = ℰ_FLUID × ℰ_time`，其中
`ℰ_time = {延迟注入, 观测重放（replay）, 时钟欺骗/时间源劫持, 计算耗尽的死线拖长 DoS, 假紧急诱导（用尾随/切入逼迫 W→0）}`。
「假紧急」是本轮特有的攻击面：不制造错误信念，而制造**没时间核实**；缓解见定义 317（MRC）+ 321（截止期权威）+ 324（时间余额下界）。

**定义 323（及时性证书 J_KAIROS）** `J_KAIROS = (J_FLUID, W_p99_margin, deadline_miss_rate, stale_answer_rate, mrc_activation_rate, t_voi_ratio, arrival_time_p95, clock_integrity, kairos_ver)`。`Valid ⇔ Valid(J_FLUID) ∧ P_miss ≤ δ_dl ∧ P_stale ≤ δ_stale ∧ clock_integrity ∧ MRC 覆盖整窗`。

**定义 324（衰减型风险缩放与时间余额）** R69：`λ = λ_floor(U_ale + 未消解 U_epi)`。KAIROS 让 U 带时间戳，并新增**时间余额项**：
`λ(t) = max( λ_floor(U_ale + U_epi^age(t)), λ_deadline(W) )`，其中
`λ_deadline(W) = 1 (W ≤ W_min)；exp(−(W−W_min)/τ_λ) (W > W_min)`。
即：时间越不够，风险缩放越保守；`W→0` 时强制 `λ→1`（只做 MRC）。这把「实时性」直接接进了 R68 的风险缩放主脉。

**定义 325（三层退化边界）** 当 `ν=0`（静态世界）、`W=∞`、`T_calc≈0` 时：`A_ν=Id`、`t-VoI→VoI`、`τ*→∞`、TCG 恒通过、`λ_deadline→0`，KAIROS 逐指令退化为 FLUID-RAS；再令 `VoI≤c`，退化为 CALM-RAS。三层严格嵌套，新层是旧层的边界泛化而非并列替代。

**定义 326（可抢占调度与中断语义）** 决策管线以**任意时间、可抢占**方式运行：在剩余时间 `W` 处强制中断，提交「当前最优决策 + MRC 切换指令」；调度为 deadline-monotonic，计算预算由 W 反推。任何时刻被中断都必须满足 `state(t') ≤_safe MRC(t')`。与 R69 定义 308 兼容：自适应 K 的选择受 W 约束（定义 313）。

## 2. 关键算法骨架

```python
# IP-264 KTP：时间化信念（时间戳 + 漂移老化）
class TemporalBelief:
    def __init__(self, nu, H_max, t0):
        self.nu, self.H_max, self.t_last = nu, H_max, t0
    def age(self, t):                                  # 定义 311 / A100
        dt = max(0.0, t - self.t_last)
        return mix(self.b, uniform(self.H_max), 1.0 - exp(-self.nu * dt))
    def accept(self, o, t_rx):                         # 定义 321
        assert o.t <= t_rx + EPS and o.t >= self.t_last - EPS
        assert (t_rx - o.t) <= LINK_BUDGET
        self.t_last = t_rx; return o

# IP-265 AAS：任意时间采样（死线感知 K，时间不够就不升 K）
def anytime_sample(fmp, o, W, W_mrc):
    K, best = 1, None
    while True:
        t99 = fmp.p99_time(K * fmp.N_step)             # A101
        if t99 > W - W_mrc:  break                     # 定义 313
        rho = fmp.anytime_risk(o, K)                   # 单调不增
        best = pick_pareto(best, (K, rho, t99))        # 风险/时间最优点
        if K >= K_MAX: break
        K *= 2
    return best.K, best.rho                           # 引理 21

# IP-266 TVOI + IP-267 SOS：t-VoI 与最优停止
def choose_timely_interaction(modes, o, t, W, nu, c_time):
    best = None
    for g in info_candidates(modes):                   # 含运动型信息动作
        tau = predict_delay(g, o)                      # 规划+执行+感知+推理
        if tau >= W: continue
        valid = exp(-nu * tau)                         # A102：答案时效概率
        voi_t = valid * (entropy(modes) - expected_entropy(modes, g, o)) \
                - c_time * tau                         # 定义 314
        if best is None or voi_t > best.voi_t:
            best = (g, voi_t, tau)
    return best if best and best.voi_t > 0 else None   # t-VoI<=0 → 不交互

def optimal_stop(r_s, nu, h_bar, c_time, p_miss):
    if r_s <= nu * h_bar:  return 0.0                  # 采不过老化 → 立刻做
    return solve(lambda tau: r_s*exp(-nu*tau)*(1-nu*tau)
                 - c_time - LAMBDA_RISK*deriv(p_miss, tau))  # 定义 318

# IP-268 IAM：信息动作即运动（绕行观察/减速/靠边）
def plan_info_motion(modes, o, goal, W):
    cands = [look_around(o), detour_to_vantage(o),
             slow_and_observe(o), yield_and_watch(o)]
    return [g for g in cands
            if stc.certify(g, o, W) and mission.budget_ok(g)]  # 定义 315-316

# IP-269 STC + IP-270 MRC：时空走廊 + 计算期兜底（先兜底，后思考）
def certify_and_hold(o, W_p99):
    tube = predict_spacetime_occupancy(o, W_p99)       # 动态障碍上界
    mrc  = min_risk_condition(o, tube)                 # 定义 317
    if not stc.feasible(mrc, tube):
        return None, tube                              # 无 MRC → 立即停车/降级
    return mrc, tube

# IP-271 TCG：问-答时间一致性门
def temporal_gate(w_q, w_a, tau, nu):
    if tau > T_HALF(nu):                 return 'stale'
    if total_variation(w_q, w_a) > TAU_DRIFT: return 'stale'
    return 'ok'

# IP-272 FMA-t：时限感知异常（缓变故障 / 延迟注入）
def flow_anomaly_t(policy, xi, o_now, o_prev, t_rx, t_stamp):
    da = abs(-policy.log_likelihood(xi, o_now)
             + policy.log_likelihood(xi, o_prev))
    dt = max(o_now.t - o_prev.t, EPS)
    drift = da / dt
    delay_attack = (t_rx - t_stamp) > LINK_BUDGET
    return DriftScore(da=da, d_t=drift, delay=delay_attack)  # 定义 320

# IP-276 KAIROS 主闭环（继承 R69，仅在时间/截止维插入）
def KAIROS_round(M, obs, t, t_deadline):
    W = t_deadline - t
    mrc, tube = certify_and_hold(obs, M.W_p99)         # 先兜底，后思考（定理 19）
    b = M.kbp.age(t)                                    # 时间化信念
    z, o = M.mtm.forward(obs), M.kbp.accept(obs, t)     # 时间戳完整性
    # 1) 时间余额不足 → 只做 MRC / R69 最保守
    if W <= M.W_min or mrc is None:
        return mrc, lam=1.0, reason='deadline_or_no_mrc'
    # 2) 任意时间、死线感知采样
    K, _ = M.aas.anytime_sample(M.fmp, o, W, M.W_mrc)
    modes, w = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    U_ale, U_epi = M.aud.split(modes, w)
    # 3) 时效优先的交互决策（含运动型信息动作）
    g = M.sos.choose_timely_interaction(modes, o, t, W, M.nu, M.c_time)
    if g is not None and M.iam.safe(g):
        ans = M.cia.execute(g, timeout=W)
        verdict = M.tcg.temporal_gate(w, M.cia.rebuild(ans), tau(ans), M.nu)
        if verdict == 'ok':
            U_epi = M.cia.update_belief(modes, ans)     # 发放 resolution bonus
        M.vqa_t.log(verdict, g, ans)
    # 4) 时间衰减风险缩放 + 漂移/延迟第二意见
    lam = M.krs.scale(U_ale, U_epi, W)                  # 定义 324
    fs = M.fma_t.flow_anomaly_t(M.fmp, M.last_action, o, M.last_obs, t, obs.t)
    if fs.delay or (fs.d_a > TAU_FMA and M.last_r_res < TAU_RES):
        lam = max(lam, 0.8)
        return mrc, lam, reason='drift_or_delay_attack'
    # 5) 选安全且证据一致的模态；可抢占提交
    mode = select_mode(modes, U_epi, lam)
    return M.sched.submit_or_preempt(mode, mrc, deadline=t_deadline)
```

## 3. 推导

**引理 19（老化-采样竞争引理）** 在 A99–A100 下，继续采集 τ 的净降熵为 `ΔH_net(τ) = (r_s − ν·h̄)·τ + o(τ)`，`h̄ = H_max − H(M|o)`。若 `r_s ≤ ν·h̄`，则 `τ*=0`：**采集的降熵速度赶不上世界变乱的速度，就该立刻做决定**。系：高漂移场景（人群、路口）应「快想快做」，低漂移场景（空旷高速）才值得「多想多问」。

**引理 20（t-VoI 的过期衰减上界）** 在 A99/A102 下，答案对 `t+τ` 问题仍有效的概率 `≤ e^{−ντ}`，故 `t-VoI(g) ≤ e^{−ντ}·VoI(g) − c_time·τ`。于是交互有利可图的必要条件是 `e^{−ντ}·VoI > c_time·τ`，给出临界延迟 `τ_c ≈ (1/ν)·ln(VoI/c_time)`。系：R69 的 `VoI` 恰是 `ν→0、c_time→0` 的极限；**在快变世界里，R69 的 resolution bonus 可能是一个被时间吃光的幻觉。**

**引理 21（死线约束下最优 K 的存在性）** 在 A101 下，若 `ρ̂(B)` 单调不增且边际收益递减，则受 `T99_calc(B) ≤ W − W_MRC` 约束的最优预算 `K*` 存在且唯一，可由一维搜索在 `O(log K_max)` 内求得。系：当 W 收缩时 `K*` 从 4 降到 1，再退化为「不采样、直接 MRC」——**不会「采样到死线」。**

**引理 22（时间一致性门的投毒推广）** 在 A99 下，模态真实切换但 TCG 未报警的概率 `P(TV < τ_drift | 切换) ≤ ε_tcg`，由 ν、观测信噪比与 τ_drift 决定。把 R69 引理 18 的错误采纳上界从「欺骗相关 ρ」扩展为「空间投毒 × 时间漂移」的联合上界 `δ_p·ρ^{k−1} + ε_tcg + ε_σ`。系：**时间漂移与语义投毒是同一类错误的两个来源，必须共用证据纪律。**

**定理 18（KAIROS 严格包含 FLUID-RAS / CALM-RAS）** 在 A99–A102 下：(a) 任意状态上的期望任务风险不高于 FLUID-RAS（只执行 `t-VoI>0` 的交互，且 λ 多了一个 `λ_deadline` 非负下界）；(b) 当 `ν=0、W=∞、T_calc≈0` 时两者**逐指令相同**（定义 325）；(c) 因此 R68⊂R69⊂R70 是严格嵌套，新层不引入需要独立信任的黑箱，只是给旧层补了时间坐标。安全侧不做让步，效率侧只在「来得及」时兑现 bonus。

**定理 19（时间-安全解耦定理）** 若在 `[t, t+W_p99]` 上存在 STC 可行的 MRC（定义 316–317），则无论计算管线在何处被中断/超时/崩溃，系统状态的安全性都不劣于「全程执行 MRC」；因此 **deadline miss 只造成任务效率损失（mission abort/slowdown），不产生不安全状态**。证明要点：安全性由 MRC 在整窗内保证，计算只决定「是否提前切换到更优动作」；换装不变式保证切换连续。这是本轮最重要的安全命题：实时性被隔离在效率域。

**定理 20（时间预算不可能三角）** 在 A101–A103 下，任何策略必须满足时间预算恒等式
`τ_gather + τ_calc + τ_react + τ_MRC ≤ W`，
且 `λ_deadline(W)` 与 `P_miss` 均为 `τ_gather+τ_calc` 的单调非减函数。因此在固定 W 下，「多看一眼/多想一步」与「留足反应与兜底时间」直接竞争，**不存在同时最大化（及时性、消解的信息量、安全裕度）的策略**；KAIROS 的设计点是：把安全裕度设为硬约束面，在此面上沿 `t-VoI/成本` 的 Pareto 前沿选点。系：追求「完美信息」在实时导航中是危险的，因为它必然吃掉 MRC 与反应时间。

## 6. 本轮最大风险

**一句话**：KAIROS 把「安全」押在 **MRC 在整个 P99 计算窗内都可行**、把「效率」押在 **漂移率 ν 与计算时间尾分布都估计准确** 上——一旦 ν 被低估（世界比模型变得快），系统就会把「正确的过期答案」当作时效答案自信执行；一旦 WCET 被低估或 MRC 不可行（拥挤人群、无安全靠边空间），定理 19 的「实时-安全解耦」就在最需要它的那一刻失效，**实时安全性并不比它对尾部分布的估计更可靠**。

**次级风险与缓解**：
1. **无 MRC 场景**（无处可停/不可减速）→ STC 不可行即进入「降低任务目标 + 最小暴露」模式，并显式上报不可保证（绝不假装安全）；
2. **漂移率 ν 误估** → 在线贝叶斯更新 ν + 保守上界 ν̄ + E314 压力测试，用 ν̄ 做 t-VoI 与 τ* 计算；
3. **假紧急攻击** → 截止期权威内部化（定义 321）+ W_min 下界 + 不因外部压力降低证据纪律；
4. **延迟注入/重放/时钟欺骗** → 时间戳三校验 + 单调时钟 + ℰ_time 对抗训练（定义 320–322）；
5. **信息运动诱发新风险** → IAM 全部过 STC/认证，绕行不越安全包络，失败即回 MRC（定理 19）；
6. **实时预算被 K 采样击穿** → 死线感知 K + 任意时间中断 + 绝不「采样到死线」（引理 21、定义 326）。

**定义 311–312（时间化世界与及时性）** 漂移 `P(M_{t+Δ}≠M_t) ≤ 1−e^{−νΔ}`；老化界 `H(M_{t+Δ}|o_t) ≥ H + (1−e^{−νΔ})(H_max−H) − ε_age`。及时 = 死线前提交 ∧ 对提交时刻世界仍有效；`P_miss`、`P_stale` 分别度量两种失败。

**定义 313（AAS）** `K*=argmax（边际风险降低/边际时间）`，s.t. `T99_calc(B) ≤ W−W_MRC`；时间不够时 K 从 4→1→0（直接 MRC）。与 R69 自适应 K 的区别：**歧义 × 时间**双门控。

**定义 314（t-VoI）** `t-VoI(g)=E[1{τ≤W}1{valid(τ)}(H(M_t|o_t)−H(M_{t+τ}|o_t,y))]−c_time·E[τ]`。第二项用 `t+τ` 时刻的模态，故 `t-VoI ≤ e^{−ντ}VoI − c_time·τ`；`τ>T_{1/2}` 时 bonus 可能变负。

**定义 315–317（IAM / STC / MRC）** 信息动作是轨迹 `g_info`（环视/绕行/减速/让行），会改变状态、占任务时间；STC 认证整窗时空管；MRC 是整窗可行的兜底动作，切换满足换装不变式。

**定义 318（SOS）** `J(τ)=r_s τ e^{−ντ} − c_time τ − λ_risk P_miss(τ)`；`τ*` 随 ν↑ 而↓；`r_s ≤ ν h̄` 时 `τ*=0`。

**定义 319（TCG）** `TV(w(t_q),w(t_a)) > τ_drift` 或身份翻转 → `stale_answer`，不发放 resolution bonus；信息运动前后各检一次。

**定义 320–321（FMA-t / 时钟）** 联合判据 `(r_res↓,Δa↑,D_t↑,age↑)` 判缓变故障/延迟注入；时间戳三校验（非未来/非倒流/链路预算内）；**截止期权威内部化**。

**定义 322（ℰ_time）** 延迟注入、重放、时钟欺骗、死线拖长 DoS、**假紧急**（逼 W→0）；并入 `ℰ_KAIROS=ℰ_FLUID×ℰ_time`。

**定义 323–324（证书与时间衰减 λ）** `J_KAIROS` 增 miss/stale/MRC/到达延迟/时钟完整性；`λ(t)=max(λ_floor(U_ale+U_epi^age), λ_deadline(W))`，`W→0 ⇒ λ→1`（只做 MRC）。

**定义 325–326（嵌套与中断）** R68⊂R69⊂R70 严格嵌套；管线任意时间可抢占，任意时刻中断都满足 `state(t')≤_safe MRC(t')`。

```python
# IP-264 KTP：时间化信念（时间戳 + 漂移老化）
class TemporalBelief:
    def age(self, t):                                   # 定义 311 / A100
        dt = max(0.0, t - self.t_last)
        return mix(self.b, uniform(self.H_max), 1 - exp(-self.nu*dt))
    def accept(self, o, t_rx):                          # 定义 321
        assert o.t <= t_rx + EPS and o.t >= self.t_last - EPS
        assert (t_rx - o.t) <= LINK_BUDGET
        self.t_last = t_rx; return o

# IP-265 AAS：死线感知采样（时间不够就不升 K）
def anytime_sample(fmp, o, W, W_mrc):
    K, best = 1, None
    while True:
        t99 = fmp.p99_time(K * fmp.N_step)              # A101
        if t99 > W - W_mrc: break                       # 定义 313
        best = pick_pareto(best, (K, fmp.anytime_risk(o, K), t99))
        if K >= K_MAX: break
        K *= 2
    return best.K                                       # 引理 21

# IP-266/267 TVOI+SOS：t-VoI 与最优停止
def choose_timely_interaction(modes, o, t, W, nu, c_time):
    best = None
    for g in info_candidates(modes):
        tau = predict_delay(g, o)
        if tau >= W: continue
        voi_t = exp(-nu*tau) * (entropy(modes) - expected_entropy(modes, g, o)) \
                - c_time*tau                            # 定义 314
        if best is None or voi_t > best[1]: best = (g, voi_t, tau)
    return best if best and best[1] > 0 else None       # t-VoI<=0 → 不交互

def optimal_stop(r_s, nu, h_bar, c_time, p_miss):
    if r_s <= nu*h_bar: return 0.0                      # 采不过老化 → 立刻做
    return solve(lambda t: r_s*exp(-nu*t)*(1-nu*t)
                 - c_time - LAMBDA_RISK*deriv(p_miss, t))  # 定义 318

# IP-268 IAM：信息动作即运动
def plan_info_motion(modes, o, goal, W):
    cands = [look_around(o), detour_to_vantage(o),
             slow_and_observe(o), yield_and_watch(o)]
    return [g for g in cands
            if stc.certify(g, o, W) and mission.budget_ok(g)]  # 定义 315-316

# IP-269/270 STC+MRC：先兜底，后思考
def certify_and_hold(o, W_p99):
    tube = predict_spacetime_occupancy(o, W_p99)
    mrc  = min_risk_condition(o, tube)
    if not stc.feasible(mrc, tube):
        return None, tube                               # 无 MRC → 立即降级/停车
    return mrc, tube                                    # 定义 317

# IP-271 TCG：问-答时间一致性门
def temporal_gate(w_q, w_a, tau, nu):
    if tau > ln2/nu:                     return 'stale'
    if total_variation(w_q, w_a) > TAU_DRIFT: return 'stale'
    return 'ok'
```

```python
# IP-276 主闭环（继承 R69，仅在时间/截止维插入）
def KAIROS_round(M, obs, t, t_deadline):
    W = t_deadline - t
    mrc, tube = certify_and_hold(obs, M.W_p99)          # 定理 19：先保安全
    M.kbp.age(t)
    z, o = M.mtm.forward(obs), M.kbp.accept(obs, t)     # 时间戳完整性
    if W <= M.W_min or mrc is None:
        return mrc, 1.0, 'deadline_or_no_mrc'           # 定义 324
    K = M.aas.anytime_sample(M.fmp, o, W, M.W_mrc)      # 定义 313
    modes, w = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    U_ale, U_epi = M.aud.split(modes, w)
    g = M.sos.choose_timely_interaction(modes, o, t, W, M.nu, M.c_time)
    if g is not None and M.iam.safe(g):                 # 信息运动过 STC
        ans = M.cia.execute(g, timeout=W)
        if M.tcg.temporal_gate(w, M.cia.rebuild(ans), tau(ans), M.nu) == 'ok':
            U_epi = M.cia.update_belief(modes, ans)     # 才发放 resolution bonus
        M.vqa_t.log(g, ans, W)
    lam = M.krs.scale(U_ale, U_epi, W)                  # 时间衰减 λ
    fs  = M.fma_t.flow_anomaly_t(M.fmp, M.last_action, o, M.last_obs, t, obs.t)
    if fs.delay or (fs.d_a > TAU_FMA and M.last_r_res < TAU_RES):
        return mrc, max(lam, 0.8), 'drift_or_delay_attack'
    mode = select_mode(modes, U_epi, lam)
    return M.sched.submit_or_preempt(mode, mrc, deadline=t_deadline)
```

## 4. 推导

**引理 19（老化-采样竞争）** 净降熵 `ΔH_net(τ)=(r_s−νh̄)τ+o(τ)`；`r_s≤νh̄ ⇒ τ*=0`。高漂移应快想快做，低漂移才值得多想多问。

**引理 20（t-VoI 过期衰减）** `t-VoI(g) ≤ e^{−ντ}VoI(g) − c_time τ`；临界延迟 `τ_c≈(1/ν)ln(VoI/c_time)`。R69 的 VoI 是 `ν→0,c_time→0` 的极限；快变世界里 resolution bonus 可能被时间吃光。

**引理 21（死线约束最优 K）** `ρ̂` 单调不增、边际收益递减 ⇒ 满足 `T99_calc(B)≤W−W_MRC` 的最优 `K*` 存在唯一，`O(log K_max)` 可求；W 收缩时 `K*:4→1→0`，不会「采样到死线」。

**引理 22（TCG 的投毒推广）** `P(TV<τ_drift|切换)≤ε_tcg`；错误采纳上界由 `δ_pρ^{k−1}+ε_σ` 推广为 `δ_pρ^{k−1}+ε_tcg+ε_σ`。时间漂移与语义投毒共用证据纪律。

**定理 18（严格包含）** 期望任务风险 ≤ FLUID-RAS；`ν=0,W=∞,T_calc≈0` 时**逐指令相同**；R68⊂R69⊂R70 严格嵌套，安全不让步，效率只在「来得及」时兑现。

**定理 19（时间-安全解耦）** 若整窗存在 STC 可行 MRC，则任意中断/超时/崩溃下安全性不劣于全程 MRC ⇒ **deadline miss 只损失任务效率，不产生不安全状态**。

**定理 20（时间预算不可能三角）** `τ_gather+τ_calc+τ_react+τ_MRC ≤ W`；`λ_deadline`、`P_miss` 随 `τ_gather+τ_calc` 单调非减 ⇒ 及时性/信息量/安全裕度不可同时最优；KAIROS 以安全为硬约束面，沿 `t-VoI/成本` Pareto 前沿选点。追求完美信息在实时导航中危险，因为它吃掉了 MRC 与反应时间。

## 7. 本轮最大风险

**一句话**：KAIROS 把安全押在「MRC 在整个 P99 计算窗内都可行」、把效率押在「漂移率 ν 与计算时间尾分布都估计准确」上——一旦 ν 被低估，系统就会把「正确的过期答案」当作时效答案自信执行；一旦 WCET 被低估或 MRC 不可行，定理 19 的解耦恰在最需要它时失效，**实时安全性并不比它对尾部分布的估计更可靠**。

**次级风险与缓解**：无 MRC 场景（进入最小暴露模式并显式上报不可保证）；ν 误估（在线贝叶斯 + 保守上界 ν̄ + E314）；假紧急（截止期权威内部化 + W_min 下界）；延迟/重放/时钟欺骗（时间戳三校验 + 单调时钟 + ℰ_time 对抗训练）；信息运动诱发新风险（全过 STC，失败即回 MRC）；预算击穿（死线感知 K + 可抢占中断，绝不采样到死线）。
