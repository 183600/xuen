# 第 10 轮（新灵感循环第 1 轮；本轮灵感：「LoRA」×「多视角视觉」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**把 v9 的「假设的安全」改成「可维护的安全」**。v9 自陈的最大风险是：块证书依赖「信任域内前向模型误差 ≤ β」，而 DA-ML 检测到的域偏移时刻恰恰是 β 最不可信的时刻。LoRA 与多视角视觉恰好提供两条正交的补救：前者把 β 从离线常数变成由**低秩适配器谱范数在线计算的账本**（模型侧上界）；后者用**冻结的经典多视几何**给出一个不经过学习模型的间隙下界（观测侧下界）。所有新增均为可选增强：适配器越预算、视角不足、标定失效 ⇒ 注入中立元，严格退回 v9。

## 0. 直觉与动机

**灵感 1（LoRA → 把「模型变了多少」变成可计算量）**
直觉：v9 的 β 是一个离线标定常数，默认「域内模型误差 ≤ β」。但 LoRA 式微调真正的危险不是「没学会」，而是**学会了却不告诉证书**：一个低秩更新可以在很小的参数改动下显著改变某类输入的预测。反过来说，低秩结构也给了我们一个抓手——若适配器写成 ΔW_ℓ = B_ℓA_ℓ，则它对隐藏层激活的改变被谱范数 ‖B_ℓA_ℓ‖₂ 控制；把每层谱范数相加，就得到整个前向模型预测变化的**可计算上界**。于是 β 不再是假设，而是 `β_eff(t) = β_0 + L_F·H_max·S(t)` 的运行时账本：适配器一旦越预算就回滚到零，v9 的信任域假设随之恢复。

更关键的是，适配器只有在**挣得自己的不确定性预算**时才值得启用。定义认证增益 Γ = 预测间隙的提升 − β_eff 的增加；Γ>0 才准入。这样 LoRA 不是「让模型更准」，而是「让安全余量在适配后仍然可证地不下降」。

**灵感 2（多视角视觉 → 用几何冗余绕开预测）**
直觉：单目检测的置信度与前向模型误差纠缠在一起——模型越不确定，越不知道「看不见」到底是没东西还是没看见。多视角提供的是另一种东西：**几何冗余**。一个空间体素如果在某个视角的深度射线之前，它就是确定的自由空间；多视角只是把自由空间 carve 得更大、更可靠。它不是预测，而是对世界的直接测量，因此可以完全绕开 F̂ 和 β。

由此得到**多视角自由空间证书（MVFSC）**：`F_t = ⋃_v {沿视线、在认证深度下界之前的体素}`，任何障碍物都只能落在 `F_t` 的补集里，故 `g_mv^lb = dist(机器人, W∖F_t)` 是真实间隙的一个**确定性下界**。它每帧可算，能把 v9 的 20 帧 DA 滑窗滞后压缩到 1 帧量级；单目时该通道失效，注入 max-格的下确界 −∞，退回 v9。

**灵感 3（二者相乘 → 证书格，而不是又一张证书）**
直觉：位置块证书与多视几何证书都是**间隙下界**，下界天然按 `max` 合成：`g^lb = max(g_pos^lb, g_mv^lb)`。max 的恒等元是 −∞，恰好表示「该通道缺席」，所以 v9 的中立元退化律 P11 可以原样复用。更妙的是，`max` 只能因为「某通道失效」而下降、不能凭空上升；只要每个被判 valid 的通道是 sound 的，双通道就不可能产生「证书空洞」。这把 v9 的单点预测安全，升级成**两条失效模式不同的安全证据**。

但必须警惕一个结构性陷阱：如果让 LoRA 去最小化多视角一致性残差，它就会把真实异常也当成「可解释的残差」抹平——**自适应吃掉了警报**。因此本轮把「证书通道不相交」提升为设计原则：几何证书只依赖冻结的经典几何与原始像素，适配器只改外观/语义分支，且梯度被投影到安全敏感子空间的正交补；这样适配器在数学上无法直接改变几何证书。

## 1. 研究问题（轮次升级版）

- **Q1（谱账本是否 sound 且够紧）**：在何种激活界与下游 Lipschitz 假设下，`β_eff = β_0 + L_F H_max Σ‖B_ℓA_ℓ‖₂` 是真实模型误差的可靠上界？运行时用幂迭代估计谱范数，如何给出可验证的误差余量？谱预算是否保守到让适配器失去意义（Γ 恒为负）？
- **Q2（自由空间证书的 soundness 与紧度）**：深度下界、外参误差、动态物体与遮挡如何进入 `F_t` 的构造，才能保证 `F_t ⊆ 真实自由空间`？在纹理缺失、反光、共视不足时，MVFSC 的下界会比 v9 单目证书更松还是更紧？多视角的「独立视角组」如何定义，才能避免共模失效？
- **Q3（抗「解释掉警报」）**：适配目标、几何证书与安全头之间需要何种正交性，才能保证 `∂g_mv^lb/∂θ ≡ 0` 且安全头的一阶变化为零？在非线性与分布外状态下，`‖J_safe Δθ‖ ≤ ε_hold` 的曲率余项如何界定？
- **Q4（退化与算力）**：适配器越预算、视角不足、标定漂移、几何通道与位置通道同时失效时，中立元注入是否严格等价于 v9 的对应退化级？新增计算能否守住 50Hz、p99 ≤ 20ms？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 认证低秩适配律（Certified Low-Rank Adaptation, CLA）**
适配器只允许作用在外观/语义分支，形式为 `ΔW_ℓ = B_ℓA_ℓ`，秩 `r_ℓ ≤ r_max`。维护谱账本 `S(π)=Σ_ℓ‖B_ℓA_ℓ‖₂`，并令 `β_eff^+(π)=β_0+L_F·H_max·S^+(π)`（`S^+` 为幂迭代的保守上界）。适配器准入需同时满足：(i) `β_eff^+ ≤ β_max`；(ii) 认证增益 `Γ(π)=[ĝ_min(π)−ĝ_min(0)]−[β_eff^+(π)−β_0] ≥ γ_min>0`；(iii) 安全正交约束（P15）。运行期每 `T_cert` 周期复核，越界即 `π←0` 回滚；回滚后的行为严格等于 v9 的冻结前向模型。

**P14 多视角自由空间证书律（Multi-View Free-Space Certificate, MVFSC）**
对每个视角只使用**认证深度下界** `d_v^-(u)`（真实首个表面距离 ≥ d_v^-），并扣除外参误差与掠射余量，构造自由空间并集 `F_t`。任何障碍物都不在 `F_t` 内，因此 `g_mv^lb=dist(p_t, W∖F_t)` 是真实间隙的确定性下界。证书 valid ⇔ 至少两个**独立视角组**健康、外参漂移 ≤ ε_ext、跨视角残差 CUSUM 未报警；失效时注入 `−∞`（max 的恒等元），绝不降级为「乐观的单目猜测」。动态物体通过膨胀未知体积与 `v_max^obs·K_eff·Δt` 时间余量处理。

**P15 证书格与通道不相交律（Certificate Lattice & Channel Disjointness, CLC）**
通道聚合算子 `⊔ = max`，中立元 `⊥ = −∞`；`g^lb = max_{i valid} g_i`。每个 valid 通道必须是 sound 的；失效通道只能从 max 中移除，不能替换为乐观值。安全谓词 `Safe_t ⇔ g^lb ≥ d_safe + d_brake(v_t)`；若 `g^lb=−∞`，立即进入 M₀ 硬检查与安全停驻。为防「自适应吃掉警报」，几何证书只依赖冻结的经典几何与原始像素（`∂g_mv^lb/∂θ≡0`），适配器梯度投影到安全敏感子空间的正交补，安全头冻结且满足 `‖J_safeΔθ‖≤ε_hold`。

## 3. 与基线的接口（如何退化）

- CLA 越预算 / 认证增益 ≤ 0 / 正交约束失败 ⇒ `π←0`，`β_eff=β_0`，等价 v9 冻结前向模型与位置块证书；
- MVFSC 失效（独立视角 < 2 / 标定漂移 / CUSUM 报警）⇒ `g_mv^lb←−∞`，`g^lb=g_pos^lb`，逐位等价 v9 单目证书；
- 位置块证书 AC 失效 ⇒ `K_eff←1`，逐步执行，等价 v8 决策粒度；
- 双通道同时失效 ⇒ `g^lb=−∞`，M₀ 硬检查 + 最近中止点安全停驻；不等待块边界；
- MW / ID / DA / SPR / Cal 失效 ⇒ 沿用 v9 的中立元五级链，最终退回 v7/v6。

## 4. 预期贡献

1. **认证低秩适配**：把 LoRA 的秩与谱范数变成安全预算，使 β 从离线假设升级为运行时账本；认证增益准则是「适配必须自付不确定性成本」的可操作判据。
2. **多视角自由空间证书**：用冻结经典几何给出与学习模型无关的间隙下界，单帧级响应补上 v9 的 20 帧 DA 滞后；`max`-格使双通道既可组合又可退化。
3. **通道不相交与抗解释掉警报**：形式化 `∂g_mv^lb/∂θ≡0`、安全子空间投影与 held-out 视角，给「适配器越强、证书越瞎」这一失效模式上锁。
4. **可维护的安全案例**：E571–E590 覆盖谱账本 soundness/紧度、认证增益、自由空间 soundness、标定漂移、动态遮挡、双通道等价、抗对抗适配、长跑与端到端；所有新增计算仍在 v9 的 20ms 预算内。

## 5. 本轮最大风险

**一句话**：LoRA 的谱账本只保证「相对基座模型的有界偏差」而不保证基座本身在陌生域正确，多视角几何又与基座共享标定、遮挡与同步链路——一旦这些共模环节同时漂移，两条证书会「有界地一起错」，而 max-格反而把这种一致错误当成更高的安全下界。

**新增定义 540（认证低秩适配器 Certified Low-Rank Adapter, CLA）**
适配器库 `Π={π_1,…,π_K}`，每个 `π` 由低秩对 `{(B_ℓ,A_ℓ)}_{ℓ∈L_app}`、秩预算 `r_max`、谱账本 `S(π)`、域标签与标定时间戳组成。前向计算 `W_ℓ(t)=W_ℓ^0+B_ℓA_ℓ`，其中 `W^0` 为冻结基座；几何分支、安全头与 v9 的所有证书模块**不在** `L_app` 中。`π=0` 表示无适配，行为严格等于 v9。适配器仅在 `T_adapt` 节拍切换，禁止在块内切换。

**新增定义 541（谱账本与有效 β Spectral Ledger & Effective Beta）**
设基座在信任域内的误差 `‖F̂_{θ₀}−F‖∞ ≤ β_0`；每层适配后的下游映射为 `L_ℓ`-Lipschitz，激活范数上界为 `H_ℓ`。定义
```
S(π)      = Σ_{ℓ∈L_app} ‖B_ℓA_ℓ‖₂
β_eff^+(π)= β_0 + L_F·H_max·S^+(π)
S^+(π)    = Σ_ℓ ŝ_ℓ·(1+ε_pi),   ŝ_ℓ = 幂迭代估计的 ‖B_ℓA_ℓ‖₂
```
其中 `L_F=max_ℓ L_ℓ`、`H_max=max_ℓ H_ℓ` 由标定集上的区间/激活统计给出。证书 valid ⇔ `β_eff^+ ≤ β_max`。运行期每 `T_cert=5` 周期（100ms）用热启动幂迭代复核；任何一层越界，在下一周期内 `π←0` 并记录 `rollback` 事件。这样 v9 的假设 `‖F̂−F‖∞≤β` 变成**由适配器预算维护的不变式**，而不是离线信念。

**新增定义 542（认证增益与适配准入 Certified Gain & Admission）**
对候选 `π`，在块级候选集上计算 `ĝ_min(π)`（前向模型预测的最小间隙）。定义
```
Γ(π) = [ĝ_min(π) − ĝ_min(0)] − [β_eff^+(π) − β_0]
```
准入条件（三者同时）：
1. `β_eff^+(π) ≤ β_max`；
2. `Γ(π) ≥ γ_min`（默认 `γ_min=0.01m`，约 5% 的 `d_safe`）；
3. 安全正交约束 `‖J_safe·Δθ(π)‖ ≤ ε_hold`（定义 547）。
任一失败即拒绝；若违规发生在激活后，回滚 `π←0`。**语义**：适配器必须用预测间隙的提升，偿付它带来的不确定性预算；不能偿付就不许上线。

**新增定义 543（多视角自由空间证书 MVFSC）**
设 `V_t` 为标定相机集合，视角 `v` 的位姿 `T_v`、外参误差上界 `δ_cal(v)`，深度图给出认证**下界** `d_v^-(u)`（真实首个表面距离 ≥ 该值；可由立体置信下界/结构光误差模型给出），动态掩膜 `ω_v(u)`。自由空间并集：
```
F_t = ⋃_{v∈V_t^ok} ⋃_{u: ω_v(u)=1}
      { c_v + s·R_v·û :
        0 ≤ s ≤ d_v^-(u) − δ_cal(v) − δ_grazing(v,u) }
```
其中 `δ_grazing` 为掠射角/深度不连续处的保守余量。间隙下界：
```
g_mv^lb(t) = dist(p_t, W ∖ F_t) − v_max^obs·K_eff·Δt
```
`W` 为工作空间；工作空间外与未 carve 的体积一律视为「未知/占用」，因此不会产生乐观下界。valid ⇔ (i) `d_ind(t) ≥ 2`（独立视角组，定义 545）；(ii) 外参监测通过；(iii) `ρ_mv(t) ≤ τ_ρ` 且 CUSUM 未报警；(iv) `F_t ≠ ∅`。失效时 `g_mv^lb←−∞`。单目时该通道从不 valid，系统退回 v9。

**新增定义 544（跨视角残差与单帧失效 Cross-View Residual & CUSUM）**
对每个健康视角 `v`，定义归一化残差
```
ρ_v(t) = max( 重投影残差_v(t)/σ_rep ,  自由空间冲突体素数_v(t)/N_conf )
ρ_mv(t)= max_{v∈V_t^ok} ρ_v(t)
C_t    = max(0, C_{t-1} + ρ_mv(t) − μ_0 − k)
```
若 `ρ_mv(t) > τ_ρ^gross` 或 `C_t > h`，判定视角失配：先移除残差最大的视角并重算；若独立视角组 <2，则 MVFSC 立即失效。`μ_0,k,h` 由标定集的 H0 分布按目标误报率确定（默认 `μ_0=0.5, k=0.25, h=4.0`）。CUSUM 的意义：对阶跃型几何失配，检测延迟为 `⌈h/δ⌉` 帧；当 `δ≥h` 时**1 帧**即报警，直接消除 v9 的 20 帧 DA 滑窗滞后（引理 91）。

**新增定义 545（独立视角组与视角健康 View Independence & Health）**
把相机按「共享安装刚性、共享标定链、共享曝光/同步链路、视场重叠 >90%」划入同一等价类；`d_ind(t)` 为健康等价类数。只有 `d_ind(t)≥2` 时 MVFSC 才 valid——两个共壳相机在标定漂移时会同向出错，不能算作两个独立证据。健康谓词 `health_v(t)` 由外参监测、镜头遮挡检测、时间戳新鲜度 `Δ_fresh≤ε_clock`、曝光饱和率共同决定。VIM 的输出同时写入日志与块证书，供离线复盘。

**新增定义 546（双证书格 Dual-Certificate Lattice, DCL）**
对通道 `i∈{pos,mv}`，令 `(g_i, valid_i)` 为下界与有效性。定义
```
g^lb(t) = max_{i: valid_i(t)=1} g_i(t),   若不存在 valid 通道则 = −∞
Safe_t  ⇔ g^lb(t) ≥ d_safe + d_brake(v_t)
```
`⊔=max` 满足交换/结合/幂等，`⊥=−∞` 为恒等元。关键性质：**从 max 中移除一个失效通道只会使 `g^lb` 不增，绝不会使它虚假升高**；因此单通道失效不可能制造「证书空洞」，只会让系统更保守（引理 90）。

**新增定义 547（证书正交适配 Certificate-Orthogonal Adaptation, COAL）**
在标定集上计算安全输出（M₀ 间隙、抓取有效位、SpatialCert 判据）对适配参数的 Jacobian `J_safe`。令 `S_safe=rowspace(J_safe)`、`P_safe` 为其正交投影。适配更新：
```
g ← ∇_θ L_adapt
g ← g − P_safe·g
θ ← θ − η·g
```
并硬校验 `‖J_safe·Δθ‖ ≤ ε_hold`（用区间传播或局部曲率上界）。`L_adapt` 只使用外观/语义损失与 held-out 视角上的**光度**一致性；`V_cert` 与 `V_train` 不相交，几何证书的残差 `ρ_mv` **不进入** `L_adapt`。几何分支完全不学习（冻结经典 MVS + 标定），故 `∂g_mv^lb/∂θ≡0`（引理 92）。若 `J_safe` 无法有界（安全头非光滑/不可微），COAL 关闭适配，`π=0` → v9。

**新增定义 548（双通道块证书与执行 Dual-Channel Chunk Certificate）**
v9 的块证书升级为
```
Ĉ_t = (g^lb, e^ub, β_eff^+(π_t), view_health_t, P_t)
```
`g^lb` 由定义 546 合成，`e^ub` 继承 v9 的用力上界，`P_t` 继承中止点集。`generate_chunk` 要求 `g^lb ≥ d_safe`、`e^ub≤τ_eff`、`P_t≠∅`；`midchunk_guard` 每周期重算 `g_mv^lb`（≤1.5ms）并与 `g_pos^lb` 取 max。若某通道失效导致 `g^lb` 跌破停车冗余，立即切换到 `≤k_exec` 的最大中止点 `p*`；若 `g^lb=−∞`，跳过 `p*` 直接执行 M₀ 硬检查与安全停驻。块仅在边界重规划，适配器切换也只在边界发生。

**新增定义 549（适配契约与秩预算 Adaptation Contract）**
在 v9 的 MW 契约表中新增三行：
```
κ_CLA  = (In: obs/domain_tag, Out: π,       D=0.2ms, Ŵ=0.2ms, v^⊥=0,   φ^elig=✓)
κ_MV   = (In: views/calib,     Out: g_mv^lb, D=2.0ms, Ŵ=1.5ms, v^⊥=−∞, φ^elig=✗)
κ_DCL  = (In: g_pos,g_mv,      Out: g^lb,    D=0.3ms, Ŵ=0.2ms, v^⊥=−∞, φ^elig=✗)
```
部署期静态校验 `Σ_m Ŵ_m ≤ 20ms` 与 EDF 可行性；秩 `r_a` 与适配层数 `|L_app|` 是契约的一部分，增大它们必须重新做谱账本认证。`κ_MV` 与 `κ_DCL` 的安全关键性使 `φ^elig=false`：ID 永不休眠它们。

# IP-357 CertifiedLoRAAdapter：认证低秩适配 + 谱账本
class CertifiedLoRAAdapter:
    def __init__(self, base, pairs, beta0, beta_max, LF, Hmax,
                 r_max=4, gamma_min=0.01, eps_pi=0.05,
                 T_cert=5, J_safe=None, eps_hold=1e-3):
        self.base, self.pairs = base, pairs          # [(B_l, A_l)] on L_app
        self.beta0, self.beta_max = beta0, beta_max
        self.LF, self.Hmax = LF, Hmax
        self.r_max, self.gamma_min, self.eps_pi = r_max, gamma_min, eps_pi
        self.T_cert, self.J_safe, self.eps_hold = T_cert, J_safe, eps_hold
        self.v = {l: zero_vec() for l in range(len(pairs))}   # 幂迭代热启动
        self.active = True

    def spectral_upper_bound(self):
        S_plus = 0.0
        for l, (B, A) in enumerate(self.pairs):      # ΔW = B A
            s_hat = power_iteration(B @ A, iters=3, init=self.v[l])
            self.v[l] = s_hat.vec
            S_plus += s_hat.value * (1.0 + self.eps_pi)
        return S_plus                                 # 保守上界 S^+

    def beta_eff(self):
        return self.beta0 + self.LF * self.Hmax * self.spectral_upper_bound()

    def certified_gain(self, g_hat_with, g_hat_without):
        return ((g_hat_with - g_hat_without)
                - (self.beta_eff() - self.beta0))

    def safety_orthogonal_ok(self, delta_theta):
        if self.J_safe is None:
            return False                              # 无法认证 ⇒ 禁用适配
        return norm(self.J_safe @ delta_theta) <= self.eps_hold

    def admit(self, candidate, g_hat_with, g_hat_without):
        if self.beta_eff(candidate) > self.beta_max:       # 预算
            return False
        if self.certified_gain(g_hat_with, g_hat_without) < self.gamma_min:
            return False                                    # 不偿付自己的预算
        if not self.safety_orthogonal_ok(candidate.delta_theta()):
            return False                                    # 安全正交
        return True

    def monitor(self, cycle_idx):
        if cycle_idx % self.T_cert == 0:
            if self.beta_eff() > self.beta_max:
                self.pairs = [(zeros_like(B), zeros_like(A))
                              for (B, A) in self.pairs]     # π ← 0
                self.active = False
                log_event('CLA_ROLLBACK', beta=self.beta_eff())
        return self.active


# IP-358 MultiViewFreeSpaceCertificate：冻结经典几何的自由空间下界
class MultiViewFreeSpaceCertificate:
    def __init__(self, delta_dep=0.02, delta_grazing=0.03,
                 tau_rho=1.0, mu0=0.5, k=0.25, h=4.0,
                 v_max_obs=1.0, dt=0.02):
        self.delta_dep, self.delta_grazing = delta_dep, delta_grazing
        self.tau_rho, self.mu0, self.k, self.h = tau_rho, mu0, k, h
        self.v_max_obs, self.dt = v_max_obs, dt
        self.cusum = 0.0

    def carve(self, views, depths, calib, dyn_mask, workspace):
        F = VoxelSet(workspace)
        for v in views:
            if not v.healthy or calib.drift(v) > calib.eps_ext:
                continue
            for u in depths[v].valid(dyn_mask[v]):
                d_lb = depths[v].lower_bound(u) - self.delta_dep
                s_max = d_lb - calib.error(v, u) - self.delta_grazing(v, u)
                if s_max > 0:
                    F.add_ray(v.center, v.R @ u, s_max)
        return F

    def consistency(self, views):
        rho = max(reprojection_residual(v, views) for v in views)
        if rho > self.tau_rho:                       # 瞬时毛刺
            return rho, True
        self.cusum = max(0.0, self.cusum + rho - self.mu0 - self.k)
        return rho, self.cusum > self.h

    def lower_bound(self, robot, F, workspace, K_eff):
        unknown = workspace.difference(F)
        return (distance(robot.position, unknown)
                - self.v_max_obs * K_eff * self.dt)


# IP-359 DualCertificateLattice：max-格 + 双通道守卫
class DualCertificateLattice:
    def __init__(self, d_safe, d_brake_fn):
        self.d_safe, self.d_brake = d_safe, d_brake_fn

    def combine(self, g_pos, pos_valid, g_mv, mv_valid):
        vals = []
        if pos_valid: vals.append(g_pos)
        if mv_valid:  vals.append(g_mv)
        return max(vals) if vals else float('-inf')   # ⊥ = −∞

    def midchunk_guard(self, chunk, k_exec, live, g_pos, pos_valid,
                       g_mv, mv_valid):
        g = self.combine(g_pos, pos_valid, g_mv, mv_valid)
        if g == float('-inf'):
            return ('hard_check', None)               # M₀ + 安全停驻
        margin = self.d_safe + self.d_brake(live.speed)
        if g < margin:
            return ('abort', chunk.nearest_abort(k_exec))
        return ('continue', k_exec + 1)

## 4. 推导

**引理 87（谱账本 soundness）**
设基座在信任域内满足 `‖F̂_{θ₀}−F‖∞ ≤ β_0`。对任一适配 `π`，若每层适配后下游映射为 `L_ℓ`-Lipschitz、该层激活范数 ≤ `H_ℓ`，则对信任域内所有输入
```
‖F̂_{θ₀+Δθ} − F‖∞ ≤ β_0 + Σ_ℓ L_ℓ·H_ℓ·‖B_ℓA_ℓ‖₂
                  ≤ β_0 + L_F·H_max·S(π) = β_eff(π).
```
证明：把 `F̂_{θ₀+Δθ}−F̂_{θ₀}` 按适配层望远镜展开。对第 `ℓ` 层，`ΔW_ℓ h = B_ℓ(A_ℓ h)`，故 `‖ΔW_ℓ h‖ ≤ ‖B_ℓA_ℓ‖₂‖h‖ ≤ ‖B_ℓA_ℓ‖₂H_ℓ`；下游映射 Lipschitz 常数 `L_ℓ` 把该扰动线性放大。对各层求和并三角不等式即得。用幂迭代上界 `S^+ ≥ S` 替换 `S`，结论仍成立。∎
**推论 87.1**：若 `β_eff^+ ≤ β_max`，则 v9 的信任域假设以 `β=β_max` 成立，v9 引理 82/83 可原样用于位置通道。

**引理 88（认证增益 ⇒ 适配不降低位置下界）**
若候选 `π` 通过定义 542 的准入，则
```
g_pos^lb(π) = ĝ_min(π) − β_eff^+(π)
             ≥ ĝ_min(0) − β_0 + γ_min
             = g_pos^lb(0) + γ_min.
```
证明：由 `Γ(π) = [ĝ_min(π)−ĝ_min(0)] − [β_eff^+(π)−β_0] ≥ γ_min` 移项即得。∎
因此适配只能**提高**位置通道的认证下界，绝不会用「更准的预测」偷偷吃掉安全余量；若提升不足以偿付 β 预算，候选被拒绝。

**引理 89（自由空间证书 soundness）**
若每个被使用的视角给出真实首个表面距离的下界 `d_v^-(u) ≤ d_v^true(u)`，外参误差满足 `‖T̂_v−T_v‖ ≤ δ_cal(v)`，且 `δ_grazing` 覆盖掠射/深度不连续处的几何误差，则定义 543 的 `F_t` 中每个点都位于真实自由空间；从而任何障碍物点 `o` 满足 `o∉F_t`，且
```
g_mv^lb(t) ≤ dist(p_t, Obstacles_t).
```
证明：对任意 `x=c_v+sR̂_vû` 且 `s ≤ d_v^-(u)−δ_cal−δ_grazing`，由三角不等式，`x` 到 `c_v` 的真实距离小于真实表面距离（外参与深度误差均被扣除），故 `x` 在表面之前，属于自由空间。于是 `F_t ⊆ Free_t`，取补集得 `Obstacles_t ⊆ W∖F_t`；距离函数单调性给出 `dist(p_t,W∖F_t) ≤ dist(p_t,Obstacles_t)`。再减去动态物体在 `K_eff·Δt` 内可移动的距离，仍是下界。∎

**引理 90（max-格无证书空洞）**
设每个通道的 valid 谓词 sound（valid ⇒ `g_i` 是真实间隙下界）。则对任意时刻，
```
g^lb(t) = max_{i: valid_i} g_i(t) ≤ dist(p_t, Obstacles_t).
```
并且把任一通道从 valid 改为 invalid，只会使 `g^lb` 不增；若全部 invalid，`g^lb=−∞`，系统进入 M₀ 硬检查。故单通道失效不可能把下界虚假抬高，不存在「一个通道坏了、另一个通道的乐观值顶上来」的空洞。证明：有限个真实下界的最大值仍是真实下界；从有限集合中删除元素，max 不增。∎
**注**：该引理的安全性依赖「valid 谓词 sound」；若某通道在标定漂移下仍被判 valid，则它的 `g_i` 不再是下界——这正是本轮最大风险的入口。

**引理 91（单帧几何失效检测）**
在 H0 下 `ρ_mv` 的均值为 `μ_0`；若发生阶跃失配使 `ρ_mv(t) ≥ μ_0+k+δ`，则 CUSUM 每帧至少增加 `δ`，故报警延迟 ≤ `⌈h/δ⌉` 帧；当 `δ≥h` 时延迟为 1 帧。对比 v9 的 DA 滑窗为 20 帧（`Δ_dom` 的 20 帧 EMA），对阶跃型几何异常，MVFSC 的失效检测快一个数量级。H0 下的误报率由 CUSUM 平均运行长度（ARL₀）控制，`h` 越大 ARL₀ 越长。证明：由 `C_t=max(0,C_{t-1}+ρ_t−μ_0−k)` 直接迭代；`ρ_t−μ_0−k ≥ δ` 时每步至少加 `δ`。∎

**引理 92（证书通道正交 / 抗「解释掉警报」）**
MVFSC 只依赖原始像素、冻结外参与经典几何，其参数集合与适配参数 `θ` 不相交，故
```
∂g_mv^lb/∂θ ≡ 0.
```
因此任何最小化 `L_adapt` 的更新（包括在训练视角上把 `ρ_mv` 压到零的对抗适配）都不会改变 `g_mv^lb`。COAL 进一步把梯度投影到 `rowspace(J_safe)` 的正交补，使安全头的一阶变化为零；在曲率界 `‖J_safeΔθ‖≤ε_hold` 下，安全输出的总变化 ≤ ε_hold。故适配器不能通过「解释掉异常」来抬升几何证书，也不能直接移动安全头。证明：链式法则给出 `∂g_mv^lb/∂θ=0`（函数不依赖 θ）；投影更新满足 `J_safe·g_proj=0`，故一阶项为零；非线性余项由 ε_hold 硬校验。∎

**引理 93（退化等价）**
对 v10 每个新增端口，注入定义 540–549 的中立元后，系统可观测行为与 v9 对应退化级逐位一致：
- `π←0` ⇒ `β_eff=β_0`，位置块证书 `(ĝ_min−β_0, P_t)` 与 v9 相同；
- `g_mv^lb←−∞` ⇒ `max(g_pos,−∞)=g_pos`，DCL 退化为 v9 的单证书；
- `d_ind<2` ⇒ MVFSC invalid，仅剩位置通道；
- 双通道 `−∞` ⇒ M₀ 硬检查，v9 引理 81 的入口判据；
- CLA/COAL/VIM 任一失效 ⇒ 对应中立元，不改变 v9 的 AC/MW/ID 状态机。
证明：逐端口代入定义 546 的 max-格恒等元与定义 540 的零适配，比较端口读数；调度顺序由 MW 保证不变，取值集合与 v9 相同。∎

## 8. 本轮最大风险

**一句话**：LoRA 的谱账本只保证「相对基座模型的有界偏差」而不保证基座本身在陌生域正确，多视角几何又与基座共享标定、遮挡与同步链路——一旦这些共模环节同时漂移，两条证书会「有界地一起错」，而 max-格反而把这种一致错误当成更高的安全下界。
