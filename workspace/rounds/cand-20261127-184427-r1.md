### 第 1 轮灵感驱动研究记录

**灵感词**：评测基准、主动交互

**直觉与动机**：
前几轮把 KEMPC 一路推进到 CADVS：证书链、视觉伺服、差分定位、多机一致性、时序熔断。但这套体系有一个尚未闭合的缺口——它不断**生产**证书，却没有任何系统化手段去**证伪**证书。第 3 轮已诚实承认最大风险是「证书通过但实则失效」的虚假安全感，而 R28 的缓解全是工程压缩（实时内核、零拷贝），并没有回答一个经验问题：**在真实分布偏移下，证书的假安全率到底是多少？** 没有度量，就没有改进的坐标。

「评测基准」正是这个坐标。但静态基准会被分布偏移和长尾场景绕过——测试集覆盖不到的状态，恰是证书最可能失效的状态。于是需要第二个灵感词「主动交互」：评测不应是离线一次性打分，而应是**系统主动去问、去探、去制造反例**的持续过程。

把两者接起来，得到本轮核心转向：
1. **评测基准 = 证伪仪器**：把「证书可信」从信念变成可测的统计量（假安全率 FSR、覆盖率、校准误差 ECE）。过去的指标（收敛加速 1.4×、违规率降到 60%）是点估计，缺少置信区间与反例分布，无法区分「真安全」与「没测到危险」。
2. **主动交互 = 实验设计策略**：系统用信息增益与价值（VOI）决定「下一步该探哪里、该问谁」，把被动消费证书变成主动获取证据。主动感知（换视点/曝光）、主动重定位、主动向操作员查询，都是在为证书补证据。
3. **二者形成闭环**：每一次主动探测既是一次控制动作，也是一条评测样本；评测结果反过来校准证书阈值。测试期与部署期的边界被打通，形成「在线自评测」。

一个反直觉的洞见：**最危险的证书不是「被拒绝」的证书，而是「从未被真正检验过」的证书**。被动系统只在自然分布里偶遇边界；主动系统则会为了降低对证书状态的不确定性，刻意走向边界——当然，这必须被元证书约束，否则「为了证明安全而变得不安全」。

**形式化目标（增量）**：
1. 定义证书评测基准 CEB = (𝒮, Φ, H, M)：场景分布 𝒮、故障注入算子 Φ、评估视界 H、指标集 M。
2. 定义核心指标：假安全率 FSR = P(证书通过 ∧ H 内实际违规 | 证书通过)；可靠性 Soundness = 1 − FSR；完整性 Compl = P(证书通过 | 实际安全)；校准误差 ECE。
3. 定义主动交互策略：a* = argmax_{a∈𝒜_probe} I(Θ; Z_a) / cost(a)，仅当 VOI = I(Θ;Z_a)/cost − τ > 0 且 a 落在元证书安全域内时执行；Θ 为证书有效性的隐状态。
4. 定义元证书 MCSE：探测动作本身须满足 P(瞬时违规 | a, M) ≤ ε 与探测预算 B_probe，并以累计风险预算上鞅约束整回合风险。
5. 定义自适应反例生成 AASG：基准侧以覆盖率与 FSR 下界为导向搜索难例，回灌 CEB（falsification）。
6. 实验假设：主动基准相对静态基准，在相同样本预算下将 FSR 估计方差降低 ≥ 50%；阈值再校准后 FSR 下降 ≥ 40%；探测引起的瞬时违规率 ≤ ε（默认 1%）。

**关键洞见**：评测基准回答「证书有多可信」，主动交互回答「为了知道它有多可信，下一步该做什么」——前者提供度量，后者提供实验设计；两者把「证书驱动控制」从开环认证变成闭环的、可证伪的科学实践。真正的安全不是「证书都通过」，而是「我们持续尝试推翻它，且知道推翻失败的概率上界」。

**本轮最大风险**：**主动交互与评测基准的合谋式退化（Goodhart + 探索风险）**——若基准奖励「找出失败」，系统会优化「通过基准」而非「真实安全」，基准一旦成为目标就不再是好的度量；更直接的是，为获取信息而执行的探测动作本身会消耗安全裕度、扰动系统，可能把机器人推入它正要验证的那类危险状态，形成「为了证明安全而变得不安全」的悖论，而元证书的违规概率估计本身也可能失准，导致「谁认证认证器」的无穷回退。

## 2. 关键算法骨架

### IP-478 Certificate Evaluation Benchmark (CEB)

```python
@dataclass
class CertificateEvaluationBenchmark:
    """CEB：场景分布 𝒮 + 故障注入 Φ + 视界 H + 指标 M 的可复现评测基准"""
    scenario_sampler: Callable[[int], Scenario]   # s ~ 𝒮（支持真实日志回放）
    fault_taxonomy: dict[str, FaultInjector]      # 光照/遮挡/丢包/时延/打滑/GNSS
    horizon: int = 200
    n_episodes: int = 2000
    violation_fn: Callable[[Trajectory], bool]    # 独立 ground truth，绝不复用证书

    def _inject(self, faults: list[str], t: int) -> dict:
        return {f: self.fault_taxonomy[f].sample(t) for f in faults}

    def run_episode(self, cert_policy, scenario: Scenario,
                    faults: list[str]) -> EpisodeResult:
        env = scenario.build()
        cert_passed = False
        violated = False
        confidences = []
        for t in range(self.horizon):
            obs = env.observe()
            out = cert_policy.step(obs)            # 返回 (u, cert_agg)
            if out.cert_agg.all_passed:
                cert_passed = True
                confidences.append(out.cert_agg.min_confidence)
            env.apply(self._inject(faults, t))
            env.step(out.u)
            if self.violation_fn(env.trajectory_so_far):
                violated = True
                break
        return EpisodeResult(cert_passed=cert_passed, violated=violated,
                             confidences=confidences)

    def evaluate(self, cert_policy, faults_per_ep: float = 1.0,
                 importance_weights: list[float] | None = None) -> BenchmarkReport:
        results, weights = [], []
        for i in range(self.n_episodes):
            s = self.scenario_sampler(i)
            faults = self._sample_faults(faults_per_ep)
            results.append(self.run_episode(cert_policy, s, faults))
            weights.append(1.0 if importance_weights is None
                           else importance_weights[i])
        return BenchmarkReport.from_episodes(results, weights)
```

```python
@dataclass
class BenchmarkReport:
    """指标集 M：FSR / Soundness / Completeness / ECE / Wilson 置信区间"""
    n_passed: int
    n_false_safe: int
    n_safe_passed: int
    n_safe_total: int
    confidences: list[float]
    outcomes: list[bool]           # 证书通过是否真的安全
    weights: list[float]

    @property
    def fsr(self) -> float:
        return self.n_false_safe / max(self.n_passed, 1)

    @property
    def soundness(self) -> float:
        return 1.0 - self.fsr

    @property
    def completeness(self) -> float:
        return self.n_safe_passed / max(self.n_safe_total, 1)

    @property
    def ece(self) -> float:
        return expected_calibration_error(self.confidences, self.outcomes, bins=10)

    def fsr_ci(self, z: float = 1.96) -> tuple[float, float]:
        """Wilson 区间：小样本/近 0 时比正态近似可靠"""
        return wilson_interval(self.n_false_safe, self.n_passed, z)
```

### IP-479 Active Certificate Interrogator (ACI)

```python
@dataclass
class ActiveCertificateInterrogator:
    """ACI：信息增益/VOI 驱动的主动探测（主动感知/重定位/问人）"""
    voI_threshold: float = 0.05
    probe_budget: int = 20
    candidate_probes: ProbeLibrary = field(default_factory=ProbeLibrary)

    def propose(self, state, cert_bundle) -> list[Probe]:
        probes = []
        if cert_bundle.uncertain('kc_vs_active'):
            probes += self.candidate_probes.perception(state)   # 换视点/曝光/变焦
        if cert_bundle.uncertain('kc_loc_valid'):
            probes += self.candidate_probes.recalibrate(state)  # 主动重定位/静止观测
        if cert_bundle.uncertain('kc_common_sense'):
            probes += self.candidate_probes.human_query(state)  # 主动向操作员提问
        return probes

    def information_gain(self, probe: Probe, belief: Belief) -> float:
        # I(Θ; Z_a) = H(Θ) − E_z[H(Θ | Z_a = z)]，Θ 为证书有效性隐状态
        return belief.entropy() - probe.expected_posterior_entropy(belief)

    def select(self, probes, belief, meta_cert) -> Probe | None:
        best, best_voi = None, -float('inf')
        for p in probes:
            if not meta_cert.admits(p):          # 元证书门控（IP-481）
                continue
            ig = self.information_gain(p, belief)
            voi = ig / max(p.cost, 1e-6)
            if voi > best_voi:
                best, best_voi = p, voi
        return best if best_voi > self.voI_threshold else None

    def interact(self, state, cert_bundle, belief, meta_cert) -> InteractionResult:
        chosen = self.select(self.propose(state, cert_bundle), belief, meta_cert)
        if chosen is None:
            return InteractionResult(kind='passive', evidence=None, probe=None)
        z = chosen.execute(state)                # 主动动作，可能耗时/有风险
        return InteractionResult(kind=chosen.kind, evidence=z, probe=chosen,
                                 posterior=belief.update(z))
```

### IP-480 Adaptive Adversarial Scenario Generator (AASG)

```python
@dataclass
class AdaptiveAdversarialScenarioGenerator:
    """AASG：覆盖率导向的反例搜索，最大化 FSR 下界；难例回灌 CEB"""
    fault_space: list[str]
    population: list[Scenario]
    mutation_rate: float = 0.1
    coverage_grid: CoverageGrid = field(default_factory=CoverageGrid)

    def score(self, s: Scenario, probe_fn) -> float:
        # 优先未覆盖区域 + 证书通过却真实违规（假安全反例）
        novelty = self.coverage_grid.novelty(s)
        r = probe_fn(s)
        return novelty + 2.0 * float(r.cert_passed and r.violated)

    def evolve(self, cert_policy, n_iter: int = 50) -> list[Scenario]:
        pop = self.population
        for _ in range(n_iter):
            scored = [(self.score(s, cert_policy.probe), s) for s in pop]
            scored.sort(key=lambda x: x[0], reverse=True)
            elites = [s for _, s in scored[:max(1, len(pop) // 4)]]
            pop = elites + [self._mutate(e) for e in elites for _ in range(3)]
        self.population = pop[:max(1, len(pop) // 4)]
        return self.population            # 难例回灌 CEB（带重要性权重）

    def importance_weight(self, s: Scenario) -> float:
        """反例分布 q(s) 下的样本，需 w = p(s)/q(s) 才能无偏估计原分布 FSR"""
        return self._base_density(s) / max(self._adversarial_density(s), 1e-9)
```

### IP-481 Meta-Certificate Safety Envelope (MCSE)

```python
@dataclass
class MetaCertificateSafetyEnvelope:
    """MCSE：探测动作的元证书。谁认证认证器——用已认证安全集 + 风险预算兜底"""
    eps: float = 0.01                 # 单步瞬时违规概率上界
    B_probe: int = 20                 # 每回合探测次数上限
    risk_budget: float = 0.05         # 回合累计风险预算 ρ_risk

    def __post_init__(self):
        self.spent = 0.0
        self.count = 0
        self.halted = False

    def admits(self, probe: Probe) -> bool:
        if self.halted or self.count >= self.B_probe:
            return False
        # 1) 探测动作必须落在 v29/CADVS 已认证安全集内（证书继承，非新假设）
        if not probe.within_certified_safe_set():
            return False
        # 2) 瞬时违规概率估计（来自离线标定的风险模型）
        p_viol = probe.estimated_violation_prob()
        if p_viol > self.eps:
            return False
        # 3) 累计风险预算（次可加，保守上界）
        if self.spent + p_viol > self.risk_budget:
            return False
        return True

    def commit(self, probe: Probe, observed_violation: bool):
        self.count += 1
        self.spent += probe.estimated_violation_prob()
        if observed_violation:
            self.halted = True            # 立即熔断，禁止继续探测
            self.spent = self.risk_budget
```

### IP-482 Benchmark-Certificate Co-Calibration (BCCC)

```python
@dataclass
class BenchmarkCertificateCoCalibration:
    """BCCC：用基准结果在线校准证书阈值；留出集门控防 Goodhart；漂移检测"""
    target_fsr: float = 0.02
    lr: float = 0.05
    drift_window: int = 200
    holdout_ratio: float = 0.3

    def update(self, report_train: BenchmarkReport,
               report_holdout: BenchmarkReport, thresholds: dict) -> dict:
        # 训练集与留出集调整方向相反 → 疑似过拟合基准，冻结阈值
        d_train = report_train.fsr - self.target_fsr
        d_hold = report_holdout.fsr - self.target_fsr
        if d_train * d_hold < 0:
            return thresholds
        for k in thresholds:
            thresholds[k] *= (1.0 + self.lr * d_train * self._sensitivity(k))
            thresholds[k] = self._clamp(k, thresholds[k])
        return thresholds

    def drift_detected(self, report_holdout: BenchmarkReport) -> bool:
        # 留出集 FSR 显著高于目标 → 分布漂移，触发重标定/告警而非继续调参
        return report_holdout.fsr > self.target_fsr * 2.0
```

### 主动基准闭环（单步）

```python
def active_benchmark_step(robot_state, sensor_data, belief, meta_cert) -> ControlOutput:
    """
    把「证书消费」改为「证书取证」：
    证书不确定时先做信息增益最大的安全探测，用新证据刷新证书，再决定动作。
    """
    cert_agg = get_cert_snapshot()
    if cert_agg.all_passed:
        return ControlOutput(cert_agg.u, path='certified', certs=cert_agg)

    # 证书不确定/未通过：主动获取证据（受 MCSE 门控）
    inter = ACI.interact(robot_state, cert_agg, belief, meta_cert)
    if inter.probe is not None:
        meta_cert.commit(inter.probe, observed_violation=inter.violated)
        cert_agg = get_cert_snapshot()        # 用新证据刷新证书链
        if cert_agg.all_passed:
            return ControlOutput(cert_agg.u, path=f'certified+{inter.kind}',
                                 certs=cert_agg)

    # 无安全且高价值探测 → 教师兜底，绝不裸探索
    return fallback_to_teacher(robot_state, sensor_data, reason='no_safe_probe')
```

## 3. 复杂度分析（增量更新）

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 | 实时性指标 |
|---|---|---|---|---|
| CEB 单回合 | O(H·(C_cert + C_env)) | O(H) | H=200 | 离线，非实时 |
| CEB 全量评测 | O(N_ep·H·C_cert) | O(N_ep) | N_ep=2000 | 单机 < 30min（并行可缩） |
| 指标计算 | O(N_ep·B_bin) | O(N_ep) | bins=10 | < 10ms |
| ACI 候选生成 | O(|𝒜_probe|) | O(|𝒜_probe|) | ≤ 12 候选 | < 1ms |
| ACI 信息增益 | O(|Θ|·|Z|·|𝒜_probe|) | O(|Θ|·|Z|) | |Θ|≤3, |Z|≤8 | < 2ms |
| AASG 每代 | O(P·(C_cert + C_cov)) | O(P) | P=64, 50 代 | 离线，分钟级 |
| MCSE 准入 | O(1) | O(1) | B_probe=20 | < 0.01ms |
| BCCC 更新 | O(|thresholds|) | O(1) | |thresholds|≤10 | < 0.1ms |
| **在线单步（含探测）** | **O(H_probe·C_probe)** | **O(|Θ|)** | 探测 ≤ 0.2s | **仅证书不确定时触发** |

**预算含义**：主动交互只在证书不确定时触发，正常认证路径零额外开销；探测动作有 B_probe 与风险预算双上限，最坏情况下回退教师路径（≤20ms，与 v30 一致）。

## 4. 正确性论证（增量更新）

### 引理 32（CEB 对 FSR 的 PAC 可估性）

**陈述**：设 CEB 从同一场景分布独立采样 N 条「证书通过」轨迹，经验假安全率 FSR̂ = (1/N)Σ 1[Viol_i ∧ CertPass_i] / P̂(CertPass)。则对任意 ε, δ ∈ (0,1)，当 N ≥ ln(2/δ)/(2ε²) 时，P(|FSR̂ − FSR| ≥ ε) ≤ δ。

**证明**：把「证书通过且真实违规」视为伯努利变量，独立同分布，由 Hoeffding 不等式直接得 P(|FSR̂ − FSR| ≥ ε) ≤ 2exp(−2Nε²) ≤ δ。若用 AASG 的重要性采样，须以 w_i = p(s_i)/q(s_i) 加权（自归一化 IS），估计量仍一致，方差由有效样本量 ESS 控制。∎

**工程含义**：FSR 不再是口号，而是带置信区间的可检验量。任何「证书更安全」的声明都必须报告 FSR̂ 与 Wilson/Hoeffding 区间，否则不可证伪。

### 引理 33（MCSE 门控下探测的 ε-安全性）

**陈述**：设每个被 MCSE 准入的探测动作 a 满足瞬时违规概率 P(Viol_a) ≤ ε，单回合最多 B_probe 次探测，累计风险预算 ρ_risk。则探测阶段至少发生一次违规的概率满足 P(∃违规) ≤ min(B_probe·ε, ρ_risk)。

**证明**：由联合界，P(∪_i Viol_i) ≤ Σ_i P(Viol_i) ≤ B_probe·ε。又由 MCSE.commit 的累计预算约束，Σ_i p_viol,i ≤ ρ_risk，且 p_viol,i ≥ P(Viol_i) 为保守上界，故 P(∃违规) ≤ Σ_i P(Viol_i) ≤ ρ_risk。任一探测观测到违规即 halted，后续预算归零。取二者最小。∎

**工程含义**：主动交互不是「拿安全换信息」，而是「在给定风险预算内买信息」。预算耗尽或任一违规即熔断，退回教师路径。

### 定理（主动基准的样本效率与安全性）

**陈述**：在 MCSE 成立（引理 33）的前提下，设 ACI 按 a* = argmax_a I(Θ;Z_a)/cost(a) 选探测，AASG 以覆盖率与假安全反例为导向生成样本。则：(i) 探测策略 ε-安全，即 Exec_AB ⊆ Exec_CADVS；(ii) 对给定样本预算，主动选择使 Θ 的后验熵期望下降不低于任意非自适应采样；(iii) 若 q 与 p 的密度比有界，AASG 加权后的 FSR 估计一致且方差随有效样本量下降。

**证明**：
- (i) 由 active_benchmark_step 逻辑：任何探测先过 meta_cert.admits（引理 33），失败或预算耗尽即 fallback_to_teacher；教师路径复用 CADVS 证书，故执行集不扩张。
- (ii) 互信息 I(Θ;Z_a) = H(Θ) − E[H(Θ|Z_a)] 正是后验熵的期望下降量；贪心最大化它在子模（submodular）条件下有 1−1/e 近似保证，且严格不劣于均匀/被动采样的期望熵下降。
- (iii) 自归一化重要性采样估计量一致性由 q(s)>0 ⇒ p(s)>0 与有界密度比保证；方差 ∝ (1/ESS)(1+Var(w))。∎

**诚实声明**：该定理只保证「探测不扩张执行集」与「信息效率」，**不保证** FSR 估计无偏——AASG 改变采样分布，若重要性权重估计错误则 FSR 有偏；MCSE 的 p_viol 来自离线标定，标定本身可能失准，此时「元证书」并不比被认证对象更可信。这正是「谁认证认证器」的递归缺口，只能靠独立留出集与人工审计缓解，无法在框架内彻底消除。

| R33 | **基准过拟合 / Goodhart 退化**（系统优化「通过基准」而非真实安全） | **极高** | 1) 训练/留出集方向一致性门控（BCCC）；2) 定期用 AASG 生成的新反例重测，禁止用同一分布调参与验收；3) 报告 FSR 置信区间与覆盖率，而非单一分数；4) 第三方盲测场景 | 基准与真实分布长期共演化时仍可能被「驯化」，需外部红队 |

## 6. 本轮最大风险（最终确认）

**一句话**：**评测基准与主动交互的合谋式退化**——当基准成为优化目标（Goodhart），系统会学会「通过评测」而非「真正安全」；而主动交互为获取证据必须消耗安全裕度、扰动系统，其自身的元证书又依赖可能失准的风险估计，于是「为了证明安全而变得不安全」与「谁认证认证器」的递归缺口叠加，构成本轮方案最深层、且无法在框架内部彻底消除的威胁。
