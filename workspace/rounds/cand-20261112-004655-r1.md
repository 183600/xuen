# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「实例分割」×「多语言支持」）

> 第 54 轮把技能组合从“能力匹配”推进到“动作-鲁棒性双证书”，并用动作空间剖面 α_S、组合图 G_S、云边映射 γ_ce 刻画组合可行性。但整条链路默认两个隐含前提：**（i）技能作用在“哪个实例”是已知且唯一的；（ii）任务描述的语言不影响语义解析。** 本轮用「实例分割」与「多语言支持」正面击穿这两个前提，提出 **接地区 𝔾**：实例条件动作剖面、实例别名风险、语言不变语义锚、跨语言指代接地，并论证接地是动作-鲁棒性金字塔的**前置地基**。

## 0. 直觉与动机

**灵感 1（实例分割 → 动作对象从“类别”细化到“实例”，暴露“实例别名”失败）**
直觉：第 54 轮的 `α_S(a)` 只回答“技能 S 能否执行动作 a”，却不回答“对哪一个物体执行”。实例分割给出逐实例掩码 `m∈M` 后，动作剖面应升级为 `α_S(a,m)`。真正危险的不是“看不见物体”，而是**两个实例视觉上几乎一样、可供性却不同**：满杯/空杯、把手被遮挡/未被遮挡、可抓/不可抓。定义**实例别名风险** `ρ_alias = sim_mask · div_aff`：掩码越像、动作可供性差异越大，越危险。这是独立于鲁棒性谱 ρ 的新失效模式——ρ 说“我能在扰动下稳定执行”，却不知道“我稳定地执行在了错误的杯子上”。

**灵感 2（多语言支持 → 语义接地漂移，而非翻译问题）**
直觉：任务描述 T 会以多语言到达。系统真正需要的不是“把中文翻成英文”，而是**语言不变的语义锚**：角色绑定（谁是施事/受事）、空间参照系（观察者中心 vs 物体中心）、否定辖域、量词与指代。同一任务在不同语言里可能解析出不同的动作序列或不同的目标实例（“左边的杯子”在镜像视角下指代相反）。定义语义框架空间 F 与接地映射 λ_ℓ，用框架距离 d_F 度量跨语言漂移，而不是用字符串相似度。

**灵感 3（两词交点 → 跨语言指代实例分割）**
直觉：两个灵感词的交点不是简单叠加，而是 **multilingual referring segmentation**：语言 ℓ 的指代表达（“左边那个红色的杯子”）必须落到实例掩码 m。接地管线 `g_ℓ = seg ∘ resolve_F ∘ λ_ℓ`。失败有三种正交来源：(a) `λ_ℓ` 解析出错误框架；(b) resolve 因实例别名选错 m；(c) seg 掩码本身有噪声。三者必须被同一张**接地证书 G_cert** 覆盖，而不是各自打补丁。

**灵感 4（接地是金字塔的地基，证书有前置序）**
直觉：第 54 轮的金字塔是“动作空间 𝔸 在鲁棒性 ρ 之上”。本轮在其下补一层 **接地区 𝔾**：`𝔾_0` 原始传感 → `𝔾_1` 实例掩码 → `𝔾_2` 语言语义框架 → `𝔾_3` 跨语言实例接地 → `𝔾_4` 接地证书。关键不是多一层，而是**证据有效性有前置序**：接地失败时，动作兼容与鲁棒性证书在语义上“真空成立”（vacuously valid），不能作为部署依据。于是部署判定从普通合取升级为**有依赖的合取**。

**灵感 5（跨语言技能迁移 → 语义漂移预算）**
直觉：第 54 轮的 JTC 只在动作-鲁棒性维度做迁移预算。跨语言迁移还需一条 **语义漂移预算** `d_F ≤ Θ_F` 与 **逐语言接地裕度** `margin_ℓ ≥ Θ_margin`。若技能在 ℓ1 验证、在 ℓ2 因参照系翻转导致目标实例改变，则动作证书再漂亮也是负迁移。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（实例条件动作剖面 IGAP）**
实例掩码集合 M（实例分割器输出），技能 S 的实例条件动作剖面 `α_S : A × M → [0,1]`。`α_S(a,m) ≥ θ_cov` 表示 S 可在实例 m 上执行 a。实例覆盖 `cover(S,A_T,m)=1 ⇔ ∀a∈A_T, α_S(a,m) ≥ θ_cov`。它细化定义 115：`max_m α_S(a,m)` 只表示“存在某实例可执行”，**不能**替代实例级检查。

**定义 122（实例别名风险）**
对 `m_i,m_j∈M`：
```
sim_mask(m_i,m_j) = IoU(m_i,m_j)
div_aff(m_i,m_j)  = (1/|A|) Σ_{a∈A} |α_S(a,m_i) - α_S(a,m_j)|
ρ_alias(m_i,m_j)  = sim_mask(m_i,m_j) · div_aff(m_i,m_j)
```
若 `ρ_alias > Θ_alias`，称 `(m_i,m_j)` 为**危险别名对**：视觉难分、动作语义不同。部署要求目标实例与所有其他实例 `ρ_alias ≤ Θ_alias`。

**定义 123（实例消歧证书 IDC）**
`I_cert = (m*, margin, part_ev, δ_i)`：
- `margin = 1 - max_{j≠*} sim_mask(m*,m_j)`：区分度；
- `part_ev`：部件级证据（关键点/部件掩码），用于在全局掩码高度相似时打破平局；
- `δ_i`：实例定位误差上界。
可部署条件：`margin ≥ Θ_margin ∧ δ_i ≤ Θ_i ∧ ∀j, ρ_alias(m*,m_j) ≤ Θ_alias`。

**定义 124（语言不变语义锚 LISA）**
语言集 L，语义框架空间 F，每语言接地映射 `λ_ℓ : T_ℓ → F`。对同一意图任务的多语言表述 `{T_ℓ}_{ℓ∈L}`，语言不变性要求
```
d_F(λ_ℓ(T_ℓ), λ_ℓ'(T_ℓ')) ≤ Θ_F   ∀ℓ,ℓ'
```
其中 `d_F` 综合**角色绑定、空间参照系、否定辖域、量词/指代**四项差异。**注意**：它不要求译文相同，而要求角色-参照系-辖域一致。

**定义 125（跨语言实例接地 CLIG）**
`g_ℓ = seg ∘ resolve_F ∘ λ_ℓ : T_ℓ → 2^M`，接地证书 `G_cert = (m*, I_cert, λ_ℓ, d_F, conf)`。可部署条件：`I_cert` 通过 ∧ `d_F ≤ Θ_F` ∧ `conf ≥ Θ_conf`。

**定义 126（接地-动作-鲁棒性联合证书 GAR-JC）**
`J* = (ρ, A_cert, I_cert, G_cert, γ_ce, δ_a, evidence)`，部署判定为**有依赖的合取**：
```
deployable(J*) = valid(G_cert) ∧ ( valid(G_cert) ⇒ ( valid(A_cert) ∧ (ρ ≥ ρ_min) ) )
```
若 `G_cert` 失败，则 `A_cert` 与 `ρ` 仅“真空有效”，不得作为部署证据。证书检查次序固定为 **接地 → 动作 → 鲁棒性**。

## 2. 关键算法 伪代码

### IP-121 IGS（Instance-Grounded Segmentation profile）

```python
def instance_action_profile(skill, A, instances, seg, probe):
    alpha = {}
    for m in instances:
        mask = seg.mask(m)
        for a in A:
            feas, conf = probe.query(skill, a, mask)
            alpha[(a, m.id)] = conf if feas else 0.0
    return alpha

def instance_cover(alpha, A_T, m_id, theta_cov=0.8):
    return all(alpha.get((a, m_id), 0.0) >= theta_cov for a in A_T)
```

### IP-122 IAD（Instance Aliasing Detection）

```python
def aliasing_pairs(alpha, instances, A, theta_alias):
    risky = []
    for i, mi in enumerate(instances):
        for mj in instances[i+1:]:
            sim = iou(mi.mask, mj.mask)
            div = sum(abs(alpha[(a,mi.id)] - alpha[(a,mj.id)]) for a in A) / len(A)
            r = sim * div
            if r > theta_alias:
                risky.append((mi.id, mj.id, r))
    return risky

def disambiguate(instances, alpha, frame, A, theta_margin, theta_alias):
    scored = [(m.id, affordance_score(alpha, m.id, frame, A)) for m in instances]
    m_star = max(scored, key=lambda x: x[1])[0]
    margin = 1.0 - max(iou(mask(m_star), mask(m.id))
                       for m in instances if m.id != m_star)
    risky = aliasing_pairs(alpha, instances, A, theta_alias)
    ok = margin >= theta_margin and all(m_star not in (i,j) for i,j,_ in risky)
    return m_star, margin, ok
```

### IP-123 LISA（Language-Invariant Semantic Anchor）

```python
def semantic_anchor(desc, lang, parser):
    frame = parser.to_frame(desc, lang)      # roles, ref-frame, scope, quantifiers
    return canonicalize(frame)               # language-neutral F

def lisa_consistency(frames, theta_F):
    d = max(frame_distance(frames[a], frames[b])
            for a, b in combinations(frames, 2))
    return (d <= theta_F), d
```

### IP-124 CLIG（Cross-Lingual Instance Grounding）

```python
def cross_lingual_ground(desc, lang, seg, resolver, A, theta_F, theta_margin):
    frame = semantic_anchor(desc, lang, resolver.parser)
    cands = resolver.candidates(frame, seg.instances)
    m_star, margin, ok_alias = disambiguate(cands, resolver.alpha, frame, A,
                                            theta_margin, THETA_ALIAS)
    d_F = frame_distance(frame, canonical_reference(frame))
    I_cert = InstanceCert(m_star, margin, resolver.parts(m_star),
                          delta_i=seg.localization_error(m_star))
    ok = ok_alias and I_cert.margin >= theta_margin \
         and I_cert.delta_i <= THETA_I and d_F <= theta_F
    return GroundingCert(m_star, I_cert, frame, d_F, ok)
```

### IP-125 GAR-JC（Grounding-Action-Robustness Joint Certificate）

```python
def gar_joint_certificate(skill_seq, desc, lang, seg, resolver,
                          gamma_ce, delta_a_budget, rho_min, theta_F):
    G = cross_lingual_ground(desc, lang, seg, resolver, A, theta_F, THETA_MARGIN)
    if not G.ok:
        return ('reject', 'grounding_fail', G)      # 前置失败：上层证书真空
    A_cert = joint_certificate(skill_seq, gamma_ce, delta_a_budget, rho_min)
    if A_cert.status != 'ok':
        return ('reject', 'action_fail', A_cert)
    return ('ok', GARCert(G, A_cert))               # 接地 → 动作 → 鲁棒性
```

### IP-126 CLTC（Cross-Lingual Transfer Certificate）

```python
def cross_lingual_transfer_certify(skill, frames, theta_F, theta_margin):
    d = max(frame_distance(frames[l1], frames[l2])
            for l1, l2 in combinations(frames, 2))
    if d > theta_F:
        return ('reject', 'semantic_drift', d)
    margins = {l: ground_margin(skill, l) for l in frames}
    if min(margins.values()) < theta_margin:
        return ('reject', 'grounding_margin', margins)
    return ('ok', CLTC(skill, d, margins))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| IGS | O(|M|·|A|·cost_probe) | O(|M|·|A|) | 逐实例剖面完备、探测可复现 |
| IAD | O(|M|²·|A|) | O(|M|²) | ρ_alias 阈值 sound、别名对无遗漏 |
| LISA | O(|L|²·cost_frame) | O(|L|·|F|) | 框架规范化单射、d_F 三角不等式 |
| CLIG | O(|T| + |M|·|A|) | O(|M|·|A|) | 接地证书 sound、margin 可验证 |
| GAR-JC | O(Σ 上述) | O(|M|·|A|+|F|) | 前置序正确、证书不可交换 |
| CLTC | O(|L|²·cost_frame) | O(|L|) | 漂移预算闭合、逐语言裕度下界 |

**正确性定理（Grounding-Aware Composition Soundness）**
承接第 54 轮 (A26)–(A28)；新增：
**(A29)** 实例分割器在部署域上 `mask IoU ≥ θ_seg` 且无系统性漏检；
**(A30)** 语义框架解析器对语言集 L 的接地误差有界，`d_F ≤ ε_F`；
**(A31)** 危险别名对检测 sound（不遗漏 `ρ_alias > Θ_alias`）。
则部署成功概率：
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a)
            - P(未检出别名) - P(d_F>Θ_F) - P(seg 漏检)
```
关键：**接地先验成立，动作与鲁棒性才有意义**；三项新扣减项分别对应实例、语言、分割三个正交风险源，且不可相互抵消。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 实例分割噪声/漏检 | 高 | 部件级证据 + 多视角融合 + 分割不确定性写入证书 |
| 低资源语言语义框架缺失 | 高 | 枢轴语言对齐 + 人工锚点 + 回退到受限语法 |
| 别名阈值 Θ_alias 任务相关 | 中 | 在线校准 + 按可供性分层设阈 |
| 接地证书增加云边延迟 | 中 | 边端轻量分割 + 云端框架校验异步流水 |
| 跨语言漂移难量化 | 高 | 平行语料 + 反事实指代测试集 + 参照系探针 |

## 6. 本轮最大风险

**一句话**：把「实例分割」与「多语言支持」引入为接地区 𝔾，使证据链从“语言 → 语义框架 → 实例 → 动作 → 鲁棒性”完整闭合，但其 soundness **同时依赖实例分割的逐实例完备性、语义框架规范化的跨语言单射性、以及别名阈值的任务无关校准**；一旦分割漏检隐藏了危险别名对，或低资源语言的参照系在规范化时被静默压平，系统会“自信且鲁棒地操作错误的实例”，且动作-鲁棒性证书全部真空成立而无法报警，故必须以 **部件级证据 + 平行语料框架校验 + 反事实指代红队** 三重护栏，宁可拒绝接地，也不把“看起来对齐”当作部署前提。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（IGAP×IAD×LISA×CLIG×GAR-JC×CLTC）

> 承接第 54 轮产物 v31。本轮在动作-协同层之下补 **接地区（Grounding）**，用「实例分割」×「多语言支持」打通“语言 → 语义框架 → 实例掩码 → 动作 → 鲁棒性”的完整证据链：
> - **IGAP（Instance-Grounded Action Profile）**：实例条件动作剖面 `α_S(a,m)`；
> - **IAD（Instance Aliasing Detection）**：实例别名风险 `ρ_alias = sim_mask · div_aff`；
> - **LISA（Language-Invariant Semantic Anchor）**：跨语言语义框架一致性与 `d_F`；
> - **CLIG（Cross-Lingual Instance Grounding）**：跨语言指代 → 实例掩码 + 接地证书；
> - **GAR-JC（Grounding-Action-Robustness Joint Certificate）**：有依赖的联合证书；
> - **CLTC（Cross-Lingual Transfer Certificate）**：跨语言技能迁移证书。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-115/118/120 以纳入接地维度。

    cands = resolver.candidates(frame, seg.instances)
    m_star, margin, ok_alias = disambiguate(cands, resolver.alpha, frame, A,
                                            theta_margin, THETA_ALIAS)
    d_F = frame_distance(frame, canonical_reference(frame))
    I_cert = InstanceCert(m_star, margin, resolver.parts(m_star),
                          delta_i=seg.localization_error(m_star))
    ok = ok_alias and I_cert.margin >= theta_margin \
         and I_cert.delta_i <= THETA_I and d_F <= theta_F
    return GroundingCert(m_star, I_cert, frame, d_F, ok)
```

### IP-125 GAR-JC

def gar_joint_certificate(skill_seq, desc, lang, seg, resolver,
                          gamma_ce, delta_a_budget, rho_min, theta_F):
    G = cross_lingual_ground(desc, lang, seg, resolver, A, theta_F, THETA_MARGIN)
    if not G.ok:
        return ('reject', 'grounding_fail', G)     # 前置失败：A/ρ 真空有效
    A_cert = joint_certificate(skill_seq, gamma_ce, delta_a_budget, rho_min)
    if A_cert.status != 'ok':
        return ('reject', 'action_fail', A_cert)
    return ('ok', GARCert(G, A_cert))              # 接地 → 动作 → 鲁棒性
```

### IP-126 CLTC

```python
def cross_lingual_transfer_certify(skill, frames, theta_F, theta_margin):
    d = max(frame_distance(frames[l1], frames[l2])
            for l1, l2 in combinations(frames, 2))
    if d > theta_F:
        return ('reject', 'semantic_drift', d)
    margins = {l: ground_margin(skill, l) for l in frames}
    if min(margins.values()) < theta_margin:
        return ('reject', 'grounding_margin', margins)
    return ('ok', CLTC(skill, d, margins))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| IGAP | O(|M|·|A|·cost_probe) | O(|M|·|A|) | 逐实例剖面完备，探测可复现 |
| IAD | O(|M|²·|A|) | O(|M|²) | ρ_alias sound，危险别名对无遗漏 |
| LISA | O(|L|²·cost_frame) | O(|L|·|F|) | 框架规范化单射，d_F 满足三角不等式 |
| CLIG | O(|T|+|M|·|A|) | O(|M|·|A|) | 接地证书 sound，margin 可验证 |
| GAR-JC | O(Σ 上述) | O(|M|·|A|+|F|) | 前置序正确，证书不可交换 |
| CLTC | O(|L|²·cost_frame) | O(|L|) | 漂移预算闭合，逐语言裕度下界 |

**正确性定理（Grounding-Aware Composition Soundness）**
假设第 54 轮 (A26)–(A28) 成立；新增 **(A29)** 实例分割在部署域上 `mask IoU≥θ_seg` 且无系统性漏检；**(A30)** 框架解析器对 L 的接地误差有界 `d_F≤ε_F`；**(A31)** 危险别名对检测 sound。
则：
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a)
            - P(未检出别名) - P(d_F>Θ_F) - P(seg 漏检)
```
关键：**接地先验成立，动作与鲁棒性才有意义**；三项新扣减项对应实例、语言、分割三个正交风险源，不可相互抵消。

## 5. 本轮最大风险

**一句话**：接地区 𝔾 让“语言 → 语义框架 → 实例 → 动作 → 鲁棒性”的证据链首次闭合，但其 soundness **同时依赖实例分割的逐实例完备性、语义框架规范化的跨语言单射性、以及别名阈值的任务无关校准**；一旦分割漏检隐藏危险别名对，或低资源语言的参照系在规范化时被静默压平，系统会“自信且鲁棒地操作错误实例”，且动作-鲁棒性证书全部真空成立而无法报警，故必须以 **部件级证据 + 平行语料框架校验 + 反事实指代红队** 三重护栏，宁可拒绝接地，也不把“看起来对齐”当作部署前提。
