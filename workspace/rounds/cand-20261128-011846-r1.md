### 第 5 轮灵感驱动研究记录

**灵感词**：视觉感知、故障诊断

**继承关系**：第 4 轮 CADVS-v4（IP-489~492）在 v3 五锚点（3DCF/MSRG/HICK/EEK/LTEM）之上追加价值锚 VACK（kc_val）与平衡锚 BCK（kc_bal），形成七硬门 kc_evidence_forged_v4 = kc_coverage ∧ kc_physics ∧ kc_human ∧ kc_ee ∧ kc_mem ∧ kc_val ∧ kc_bal，fail-closed；执行集 Exec_CADVS-v4 ⊆ Exec_CADVS-v3 ⊆ … ⊆ Exec_v29。本轮不推翻 v4，而是揭示 v4 隐含的两个「健全性假设」：(i) 把视觉感知当作可信 oracle——3DCF 只认证「空间是否被覆盖」，不认证「看到的类别/位姿/可抓取性是否可信」；(ii) 把传感器、执行器、模型当作永远健康——所有证书都默认证据源无故障。据此引入视觉证据锚 VECK（kc_vis）与故障诊断/健康锚 FDHK（kc_fault），并把证书从「裸命题」升级为「带出处与有效性上下文的判断」，形成 CADVS-v5（IP-493~496）。九硬门 kc_evidence_forged_v5 = kc_fault ∧ kc_vis ∧ (∧_{i=1..7} kc_i) @ V；逐时刻 Exec_CADVS-v5(t) ⊆ Exec_CADVS-v4(t)。

**直觉与动机**：

1. **视觉感知：从「看得见」到「看得准、看得可信」**。3DCF 的 Γ_3D 回答的是几何覆盖（相机能否看到该体素），但规则前件（物体类别、6D 位姿、抓取点、可通行区域、人部位姿）依赖的是**语义感知估计**。视觉感知有一整套独立失效模式：遮挡、逆光/低照、运动模糊、弱纹理/透明/反光、深度空洞、位姿多解、标定漂移、域漂移、对抗贴片。一个被覆盖的体素不等于一个可信的估计。引入视觉证据证书 VPC：对任务相关感知量做**保形预测**，得到预测集 C_α(x)（离散标签集或连续量的置信区域），要求 (a) 单例或直径 ≤ τ_m（精度），(b) 包含规则所假设的值（一致性），(c) 可见覆盖 vis_cov 足够、遮挡 occ_ratio 受限，(d) 标定版本一致且重投影/手眼漂移小，(e) 位于 ODD 内且 OOD/对抗分数低。硬门 kc_vis 全部满足才放行，否则 fail-closed 或转教师/主动视角。软因子 η_vis 取各归一化边际的最小值。关键：视觉不只是「被测对象」，它还能反向为故障诊断提供异常证据（视觉异常检测）——两词天然耦合。

2. **故障诊断：证书是「有条件的」，健康是那个未写出的条件**。v4 的每条证书都隐含「传感器没坏、执行器没退化、模型没漂、通信没延迟」。但偏置/漂移、编码器打滑、力矩输出衰减、力传感器卡死、接触模型失配、通信抖动都是**静默故障**：它们不改变证书里的布尔值，却让证书指向错误的世界。引入故障诊断证书 FDC：残差生成（解析冗余/奇偶空间、观测器/Kalman 新息、跨模态一致性、数据驱动重构误差）→ CUSUM/GLR/SPRT 检测 → 结构化残差签名隔离 → 退化模式分类（正常 / 可认证退化 / 安全停机）。硬门 kc_fault = 关键故障后验 p_f < τ_f ∧ 模式 ∈ M_certified ∧ 检测延迟 ≤ Δ。软因子 η_fault = 1 − max p_f。故障诊断不是「又一个锚点」，而是**关于证据的证据（meta-evidence）**：它决定其他锚点的证书此刻是否仍然成立。

3. **证书有效性演算：把「合取」升级为「带出处的可撤回判断」**。v4 的 CERTCALC 只有 ∧∨¬□，证书一旦为真就静态为真。但故障发生后，之前为真的证书必须**被追溯撤回**——这是 AI 中真值维护系统（TMS）/信念修正与数据库 provenance 的经典问题。把证书改写为判断 c @ V，V = (health, perception, calib_id, t) 为有效性上下文，π(c) 为出处（依赖的锚点/传感器）。定义故障失效算子 ⊘_F：若 π(c) ∩ F ≠ ∅ 则撤回 c（置 ⊥）。于是执行集变成时变集合 Exec_v5(t)，且逐点满足 Exec_v5(t) ⊆ Exec_v4(t)。这解释了 v4「单调收缩」在时间维度上的真正含义：不是一次性永久收缩，而是**随健康/感知上下文的每一次变化重新求交**。

**关键洞见**：v4 的七个锚点都是**一阶证据**（关于世界）；视觉感知与故障诊断是**二阶证据**（关于证据管线本身）。把它们当作两个并列合取项是不够的——正确做法是让它们**守护**其余锚点的证书：视觉证书给感知前件提供可信度，故障证书通过出处追溯撤回受污染的证据。因此 v5 的核心升级是「带出处、可失效、可重铸的证书维护」，而非「再加两道门」。九硬门 kc_evidence_forged_v5 = kc_fault ∧ kc_vis ∧ (∧_{i=1..7} kc_i) @ V，fail-closed；软评分 ECS_v5 = ECS_v4 · η_vis · η_fault。

**形式化目标（增量）**：
1. 定义视觉感知证书 VPC = (C_α, diam, vis_cov, occ_ratio, calib_id, odd_ok, s_ood, t)，硬门 kc_vis = (单例或 diam ≤ τ_m) ∧ (ŷ_rule ∈ C_α) ∧ vis_cov ≥ τ_v ∧ occ_ratio ≤ τ_o ∧ calib_ok ∧ odd_ok ∧ s_ood ≤ τ_ood，软因子 η_vis。
2. 定义故障诊断证书 FDC = (p_f, F_iso, mode, r_stats, T_detect, t)，硬门 kc_fault = (max_{f∈F_crit} p_f < τ_f) ∧ (mode ∈ M_certified) ∧ (T_detect ≤ Δ)，软因子 η_fault = 1 − max p_f。
3. 定义有效性上下文 V = (h, v, κ, t)、出处 π(c)、判断 c@V、失效算子 ⊘_F 与撤回/重铸规则。
4. 扩展证书演算 CERTVAL：证明有效集单调性 F₁ ⊆ F₂ ⟹ Valid(F₂) ⊆ Valid(F₁)；撤回是 fail-closed；重铸需新证据。
5. 定义视觉-故障耦合：视觉异常分数进入故障诊断，故障诊断条件化视觉可信度；给出不动点存在/收缩条件。
6. 定义故障感知可靠性定理：检测延迟 Δ、漏检 δ_fd、视觉假接受 δ_vis 下，接受无效证书的概率 ≤ δ_fd + δ_vis + P(T_detect > Δ)；给出安全窗口界。
7. 定义 EFA-v5 九硬门 + 有效性守护 + 撤回；ECS_v5 = ECS_v4 · η_vis · η_fault；逐时刻 Exec_v5(t) ⊆ Exec_v4(t)。

**本轮最大风险**：故障诊断的检测延迟与漏检，会在故障发生后的时间窗内让证书「看起来仍然有效」；更糟的是视觉感知的域漂移会同时污染故障诊断的视觉输入，使两个新锚点在同一扰动下**相关失效**，把 fail-closed 悄悄变成 fail-open。

### IP-493 VECK：视觉证据证书核（准入/视角切换时，异步 ~1–10 ms）

```python
@dataclass
class VisualEvidenceCertificateKernel:
    """VECK：任务相关视觉量的保形感知证书；kc_vis 硬门"""
    alpha_vis: float = 0.05
    tau_m: float = 0.02          # 连续量预测区域直径阈值（任务相关）
    tau_v: float = 0.80          # 可见覆盖下限
    tau_o: float = 0.20          # 遮挡比例上限
    tau_ood: float = 0.50        # OOD/对抗分数上限
    calib_scores: np.ndarray = None
    scorer: Any = None           # 任务相关感知模型（类别/位姿/抓取）
    density_ratio: Any = None    # 协变量漂移密度比

    def _nonconformity(self, x, y) -> float:
        return self.scorer.error(x, y)   # 位姿 ADD/ADD-S；类别 1-p_hat

    def conformal_set(self, x) -> PerceptionSet:
        n = len(self.calib_scores)
        k = int(np.ceil((n + 1) * (1.0 - self.alpha_vis)))
        q = np.sort(self.calib_scores)[min(k, n) - 1]
        return self.scorer.invert(x, q)  # 离散→标签集；连续→置信区域

    def evaluate(self, x, y_rule, calib_id, t_now) -> VPC:
        C = self.conformal_set(x)
        diam = C.diameter()
        vis_cov = self._visible_coverage(x)
        occ = self._occlusion_ratio(x)
        calib_ok = self._calibration_ok(x, calib_id)
        odd_ok, s_ood = self._odd_and_ood(x)
        return VPC(C=C, diam=diam, contains_rule=(y_rule in C),
                   vis_cov=vis_cov, occ_ratio=occ, calib_id=calib_id,
                   calib_ok=calib_ok, odd_ok=odd_ok, s_ood=s_ood, t=t_now)

    def kc_vis(self, vpc: VPC) -> bool:
        precise = (vpc.C.is_singleton() if vpc.C.discrete
                   else vpc.diam <= self.tau_m)
        return (precise and vpc.contains_rule
                and vpc.vis_cov >= self.tau_v
                and vpc.occ_ratio <= self.tau_o
                and vpc.calib_ok and vpc.odd_ok
                and vpc.s_ood <= self.tau_ood)

    def eta_vis(self, vpc: VPC) -> float:
        vals = [vpc.vis_cov,
                1.0 - vpc.occ_ratio,
                1.0 - min(vpc.diam / self.tau_m, 1.0),
                1.0 - min(vpc.s_ood / self.tau_ood, 1.0)]
        return float(np.clip(min(vals), 0.0, 1.0))

    def _visible_coverage(self, x) -> float: ...
    def _occlusion_ratio(self, x) -> float: ...
    def _calibration_ok(self, x, calib_id) -> bool: ...
    def _odd_and_ood(self, x) -> tuple[bool, float]: ...
```

### IP-494 FDHK：故障诊断与健康核（控制环内，残差 O(1)，检测 O(M)）

```python
@dataclass
class FaultDiagnosisHealthKernel:
    """FDHK：残差→CUSUM/GLR→结构化隔离→退化模式；kc_fault 硬门"""
    tau_f: float = 0.05
    delta_max: float = 0.05      # 最大允许检测延迟（s）
    cusum_k: float = 0.5
    cusum_h: float = 5.0
    signature: np.ndarray = None # S ∈ {0,1}^{m×M}
    critical: set = field(default_factory=set)

    def observe(self, q, qd, tau, sensors, t_now) -> FDC:
        r = self._residuals(q, qd, tau, sensors)      # 奇偶/观测器/跨模态
        g = self._cusum_update(r)                     # O(M)
        alarms = {f for f, gf in g.items() if gf > self.cusum_h}
        F_iso = self._isolate(alarms, self.signature) # 签名匹配
        p_f = self._posterior(r, F_iso)               # 贝叶斯/似然比
        mode = self._degradation_mode(p_f, F_iso)
        T_detect = t_now - self._onset_estimate(F_iso)
        return FDC(p_f=p_f, F_iso=F_iso, mode=mode, r_stats=r,
                   T_detect=T_detect, t=t_now)

    def kc_fault(self, fdc: FDC) -> bool:
        crit_p = max((fdc.p_f.get(f, 0.0) for f in self.critical), default=0.0)
        return (crit_p < self.tau_f
                and fdc.mode in ('normal', 'degraded_certified')
                and fdc.T_detect <= self.delta_max)

    def eta_fault(self, fdc: FDC) -> float:
        crit_p = max((fdc.p_f.get(f, 0.0) for f in self.critical), default=0.0)
        return float(np.clip(1.0 - crit_p, 0.0, 1.0))

    def _residuals(self, q, qd, tau, sensors) -> np.ndarray: ...
    def _cusum_update(self, r) -> dict: ...
    def _isolate(self, alarms, S) -> set: ...
    def _posterior(self, r, F_iso) -> dict: ...
    def _degradation_mode(self, p_f, F_iso) -> str: ...
    def _onset_estimate(self, F_iso) -> float: ...
```

### IP-495 CERTVAL：证书有效性演算与核心定理（离线理论，不在控制环）

```python
@dataclass(frozen=True)
class Judgement:
    cert: str
    V: ValidityContext           # (health, perception, calib_id, t)
    provenance: frozenset        # π(c) ⊆ anchors ∪ sensors

class CertValidityCalculus:
    """证书判断 c@V、出处 π、失效算子 ⊘_F、撤回/重铸"""

    @staticmethod
    def invalidate(c: Judgement, F: set) -> Judgement | None:
        # 出处与故障隔离集相交 → 撤回（返回 None 表示 ⊥），fail-closed
        return None if (c.provenance & F) else c

    @staticmethod
    def valid_set(certs, F):
        return {c for c in certs
                if CertValidityCalculus.invalidate(c, F) is not None}

    @staticmethod
    def reforge(c: Judgement, new_evidence: dict, V_new: ValidityContext):
        # 重铸必须由新证据支持，禁止无证据「复活」
        assert new_evidence.get('fresh', False)
        return Judgement(c.cert, V_new, c.provenance)
```

## 4. 正确性论证（增量更新）

### 引理 43（保形感知的覆盖-精度权衡）

**陈述**：设校准样本与部署样本在感知分布上可交换，非一致性分数 A_vis 满足标准保形构造，则对任意 α ∈ (0,1)，P(y_task ∈ C_α(x)) ≥ 1−α。若规则要求 ŷ_rule ∈ C_α(x) 且 C_α 为单例/直径 ≤ τ_m，则「基于错误或歧义感知的规则被接受」的概率 ≤ α + P(|C_α| > 1)（或 P(diam > τ_m)），由并集界给出。存在协变量漂移时，加权保形（密度比 ŵ ≤ w_max）将覆盖下界修正为 ≥ 1−α−O(w_max·TV)，且当 ŵ 无界时保证失效。

**证明**：split conformal 的标准可交换性论证给出边际覆盖；单例/直径事件与覆盖事件独立上界相加；加权版本由加权可交换性 + 密度比有界性推出。∎

**工程含义**：把「感知是否可信」变成一个**有分布无关保证的统计检验**，而非拍脑袋的置信度阈值；同时显式暴露「覆盖 ≠ 精度」——覆盖 95% 不代表单例，必须单独检查歧义率。

### 引理 44（故障检测延迟-误报权衡）

**陈述**：对幅度为 ν 的故障，CUSUM 取参考值 k < ν、阈值 h_th，则平均检测延迟 ARL_1 ≤ h_th/(ν−k) + 1；无故障平均运行长度 ARL_0 随 h_th 指数增长。对任意 Δ > 0，P(T_detect > Δ) ≤ E[T_detect]/Δ ≤ (h_th/(ν−k)+1)/Δ（Markov）。结构化签名的最小汉明距离 d_min 决定隔离歧义：若两个故障签名距离 < d_min，则隔离集必含二者，必须由人确认或保守停机。

**证明**：CUSUM 的 Lorden 最优性与随机游走漂移界给出 ARL_1；Markov 不等式给出延迟尾界；签名距离的编码论证给出隔离歧义。∎

**工程含义**：检测延迟不是 bug 而是**可量化的安全预算**；kc_fault 中的 T_detect ≤ Δ 把「故障已发生但尚未确认」的窗口显式纳入 fail-closed，而不是假装瞬时检测。

### 定理 v5（故障感知可靠性、有效集单调与逐点收缩）

**陈述**：在 (B1)~(B6)（继承 v2~v4）与新增假设 (B7) 感知校准/部署可交换（或加权可交换）、(B8) 故障残差模型与签名矩阵正确、(B9) 视觉与故障的耦合算子 Lipschitz 常数 L_T < 1 下：
(i) **有效集单调**：F₁ ⊆ F₂ ⟹ Valid(F₂) ⊆ Valid(F₁)；
(ii) **逐点收缩**：∀t，Exec_CADVS-v5(t) ⊆ Exec_CADVS-v4(t)；
(iii) **故障感知可靠性**：故障后接受无效证书的概率 P_failopen ≤ δ_fd + δ_vis + P(T_detect > Δ) + 1[ε_r>0]·P(撤回未完成)；
(iv) **撤回 fail-closed**：检测到 F 并进入 safe_stop 后，π(c)∩F≠∅ 的证书全部撤回，不再新增接受；
(v) **耦合不动点**：L_T < 1 时可靠度耦合存在唯一不动点；否则取保守 min 并 fail-closed。

**证明**：(i) 由引理/定理 5 的集合论证。(ii) v5 在 v4 每条路径上追加 kc_vis 与 kc_fault，并在更小的有效上下文 V 下求值七门，故只缩不涨。(iii) 失效只可能来自漏检（δ_fd）、视觉假接受（δ_vis）、检测延迟超窗（P(T_detect>Δ)）或撤回执行延迟；四者并集界。(iv) 由 ⊘_F 定义直接得。(v) 由 Banach 不动点定理；L_T ≥ 1 时不动点不保证，退回保守下界。∎

**诚实声明**：(B7) 保形保证依赖可交换性，而真实部署的视觉域漂移（光照/材质/新物体）恰好破坏它；加权保形只在密度比有界且支撑重叠时有效。(B8) 残差模型与签名矩阵本身可能标定错误，且某些故障（如缓慢磨损、软故障）幅度低于可检测下限。(B9) 视觉与故障常共享同一物理扰动源（如强光同时致盲相机并干扰视觉异常检测），L_T ≥ 1 的相关失效是**真实存在**的，此时 v5 只能退回保守 min + 人工确认，无法给出统计保证。因此 v5 是「可审计、可撤回」的工程强化，而非「绝对安全」的证明。
