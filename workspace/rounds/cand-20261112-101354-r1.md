# 第 58 轮（承接第 57 轮「元少样本×跨模态×个性化」IP-133~138；灵感循环第 4 轮；本轮灵感：「伦理审查」×「分布外泛化」）

> 第 57 轮把安全论证做成五层纵深，并在风险自陈里写下"坏先验普遍"：语料盲区会让元模型在 OOD 门外给出高度自信的错误后验。但这句话只点到症状——真正的病灶有两个，且互为镜像。**其一，OOD 门是"检测器"不是"泛化器"**：它只回答"像不像训练分布"，不回答"分布外应当相信什么"；被寄予厚望的共形保底是**边际交换性**保证，而交换性恰恰在分布偏移下失效——把"检测到 OOD、退回共形带"当作"OOD 下也安全"，是一个被藏起来的推理跳跃。**其二，整套统计证书是"自证"**：ε_meta、δ_ood、A37–A40 全部由提出方自行声明、自行检验、自行签发——审计者与被审计者是同一主体，证书在"谁有权说它成立"这一层是空的。本轮两个灵感各补一刀：**分布外泛化**告诉我们一个泛化主张究竟能是什么（可迁移的不变核 + 不可迁移的环境壳；移位条件保证，或干脆拒绝），**伦理审查**告诉我们谁有权做这个主张（前瞻注册、独立裁决、附加条件、持续复审、可撤销）。二者合流为 **"可审查的泛化"**：系统不再宣称"我泛化到 OOD"，只宣称"在经审查的管辖域内我有条件成立，域外一律拒绝"；不可约的归纳风险被**声明**出来，而不是伪装成一个概率项。

核心矛盾：
- **H29（检测 ≠ 泛化）**：OOD 门只给"是否在分布内"的判别，共形保底只在交换性下有效；二者拼起来推不出"分布外安全"，只是把"未知"换成了"看起来有保证的未知"。真正的 OOD 泛化需要一个**关于世界的不变机制主张**，而这是检测器给不出的。
- **H30（自证 vs 他证）**：A37 的"声明诚实"由谁核验？若由提出方核验，则任何 ε 都能被声明成想要的值；安全的最后一道门不是更小的 δ，而是**权力分离**——数据、主张、签发权必须由不同主体持有。
- **H31（泛化主张 vs 管辖通胀）**：若允许系统自行划定"我泛化到环境类 ℰ"，最省力的做法就是把 ℰ 划得足够大；拒绝算子于是沦为纸面防火墙。泛化的边界不能由被审查者定义，否则"可审查"只是把过度自信换了个更体面的名字。

## 0. 直觉与动机

**灵感 1（伦理审查 → 三权分立、前瞻注册、持续复审）**
直觉：IRB 的力量不在它用了更严的统计，而在它的**结构**：研究开始前注册方案（prospective registration），审查者与研究者分离（independence），可以附加条件、暂停、撤销（conditions & revocation），并要求不良事件上报与持续复审（continuing review）。把这四个结构搬到证书体系：把"泛化主张"升为一等公民并**先注册后部署**；把签发权从构建方手里拿走，交给一个**拿到全部原始日志、能自己生成对抗偏移、且其收益与部署量脱钩**的独立审查方；让许可带**期限与撤销**。证书不再是一份自评报告，而是一张**临时执照**。

**灵感 2（分布外泛化 → 泛化是有条件承诺，不是属性）**
直觉：一个模型"泛化好"不是一个数，而是一个三元组：**在哪个环境类 ℰ、允许哪种偏移族 𝒮、靠哪个可迁移机制**。只有**不变机制**（与材质无关的接触力学、几何一致性、守恒律）能跨环境迁移；颜色/纹理/季节这些**虚假相关**只是环境壳，换个分布就翻脸。所以必须把信念**泛化分账**：不变核 θ_inv 才配得到"可迁移"主张；环境壳 θ_shell 一律按未知 OOD 处理，只以先验范围进风险，永不点估计。可迁移性**只可证伪不可证明**——所以 EV-generalize 必须是一个可被不良事件收回的证据类。

**灵感 3（两词合流 → 可审查泛化：主张 × 管辖 × 拒绝）**
直觉：把灵感 1 的"执照"套在灵感 2 的"条件承诺"上——每张执照写明 `(ℰ_κ, 𝒮_κ, 不变核, 风险界, 期限)`；系统只能引用**当前有效**的执照做 OOD 承诺。关键不是把区间算得更宽，而是给"宽"配一条**管辖边界**：分布落在 𝒮_κ 内，用移位感知证书给条件保证；落在外面，返回的不是"很宽的区间"，而是**拒绝**（Refuse）。拒绝是这套体系里**唯一的非统计安全保证**——统计界再宽也活在某个分布假设里，只有"域外不承诺"由构造保证。

**灵感 4（诚实定理 → 不可约归纳风险 R_ind）**
直觉：第 57 轮的部署界把 OOD 贡献写成 `δ_ood·α_conf`，隐含了"检测器漏检后仍安全"。本轮把它拆成两项：**管辖内**有可界定的统计残差 R_stat；**管辖误判** `R_ind = P(自称在 ℰ_κ、实则在 ℰ_κ 外)` 是**不可约**的归纳风险——数据再多也消不掉，因为"这批数据代表整个世界"本身就是无法从数据内部证明的假设。审查、对抗偏移、证伪环境、持续监控只能**治理**它，不能**消除**它。诚实的定理必须承认这一项，而不是把它藏进一个乘积里。

**灵感 5（不可逆动作双保险 → 管辖 ∩ 证据 ∩ 监控）**
直觉：既然 R_ind 不可消除，安全的做法不是让统计更准，而是让**失效需要多个独立条件同时成立**。不可逆动作只在 `(审查域有效) ∩ (证据门通过) ∩ (持续审查未触发收缩)` 的交集内允许；要击穿，必须同时发生"管辖误判 ∧ 证据失效 ∧ 监控未及收缩"。管辖是机构保证，证据是统计保证，监控是时间保证——三种不同性质的保证，总比五层同源统计更像纵深。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（泛化主张登记 GCR）** 主张 `κ=(id, ℰ_κ, 𝒮_κ, f_κ, r_κ, α_κ, Inv_κ, W_κ, A_κ, exp_κ, cond_κ)`：ℰ_κ 为可判定的环境类（材质簇×坡度×季节×负载的可测子集）；𝒮_κ 为允许偏移族，取 `{Q:D_f(Q‖P_ref)≤ρ_κ}` 或参数化协变量偏移 `{Q:dQ/dP_ref≤w_max}`；f_κ 为被主张的**决策机制**（非整个系统）；Inv_κ⊆θ 为不变部件集；W_κ 为必须持续通过的证伪见证集；A_κ 为允许的动作责任域（L0/L1/L2 边界）；exp_κ 有效期；cond_κ 审查附加条件。有效性谓词 `Valid(κ,x,P_t,t) ⇔ Approved(κ) ∧ x∈ℰ_κ ∧ P_t∈𝒮_κ ∧ W_κ(t)全通过 ∧ t<exp_κ ∧ 无未结 AE ∧ cond_κ 成立`。**任何 OOD 承诺必须引用一个 Valid 的 κ**；无 κ 即无 OOD 主张。

**定义 140（独立审查算子 IRB）** 审查方 ℛ 获得完整 J_p、原始探针/同意/审计日志与不良事件流（I2），在**自生成且提出方不可见**的对抗偏移集 `𝒜_κ` 上评估：`Approve(κ) ⇔ min_{s∈𝒜_κ} PassRate(κ,s) ≥ 1−α_rev ∧ W_κ⊆𝒜_κ 被覆盖`。独立性公理：(I1) 审查方收益与部署量/上线速度脱钩；(I2) 全量原始数据可见，含提出方不想公开的 ρ 降级与 OOD 注册；(I3) 有权附加条件、设期限、暂停、撤销；(I4) 审查方自身受利益冲突账本与决策审计。**关键：对抗集由审查方生成（防"对着考题优化"），且审查方与提出方不共享训练语料（防共享盲区）。**

**定义 141（移位感知泛化证书 SCOPE）** 分区 θ=(θ_inv,θ_shell)：(a) 有界协变量偏移用加权共形 `C_w(x)`，保证 `P_test(Y∈C)≥1−α−½‖P_test−P_ref‖_TV`；(b) 一般 f-散度球 `𝒮_κ` 用鲁棒集 `C_𝒮(x)=argmin_C|C| s.t. inf_{Q∈𝒮_κ} Q(Y∈C|X=x)≥1−α`，可行条件 `ρ_κ≤ρ_max(α,n)`，否则空集。**越界即拒绝**：若 `D̂_f(P_t‖P_ref)>ρ_κ` 或 `ŵ>w_max` ⇒ 返回 `Refuse`，而非"更宽的区间"——严格区分"宽但有效"与"无主张"。C_𝒮 只作用于 θ_inv；θ_shell 以先验区间进 P_fail，永不点估计。

**定义 142（不变性见证 INV）** 训练环境 E_1..E_m、`f=h∘Φ`。Φ 在 𝒮_κ 上不变 ⇔ `∀e,e',y: ‖E_{P_e}[Φ(x)|y]−E_{P_e'}[Φ(x)|y]‖≤ε_inv`，且至少一对环境使 spurious 因子取值不同；证伪环境 `e_f∉{E_i}` 上退化 ≤δ_inv。`EV-generalize ⇔ m≥2 ∧ 不变检验过 ∧ e_f 过`。不变性**只可证伪不可证明** ⇒ EV-generalize 是可撤销证据类，被定义 143 的 AE1 收回。

**定义 143（持续审查与不良事件 CR）** 临时许可 `L=(κ,cond,exp,monitor)`。监控量：OOD 残差与分歧 D(r) 上的 e-value `A_t=Π e_i`；`A_t≥1/α_cr` ⇒ 不良事件。四类 AE：AE1 不变性破裂、AE2 偏移逃逸 `D̂_f>ρ_κ`、AE3 证据证伪、AE4 规模橡皮章。AE 触发**自动条件升级**（从 ℰ_κ 收缩失败子域、收紧证据门、强制 L2），随后 Δ_rev 内强制人工复审；自动机制**只收缩不扩张**。到期未续 ⇒ 许可失效。此即把第 57 轮"单向有界"从操作者层上移到**机构层**。

**定义 144（管辖与拒绝算子 JUR）** `Act(x,a)` 允许 ⇔ `∃κ: Valid(κ,x,P_t,t) ∧ a∈A_κ ∧ FSE(c)='ok'`；否则 `Refuse`（→ 绕行/L2/安全停），**与元后验置信无关**。`P(commit outside jurisdiction)=0` 由构造保证、非概率保证。不可逆动作额外要求 `x∈ℰ_κ ∩ 实证域`。

## 2. 关键算法伪代码（完整版见产物区）

```python
def jurisdiction(x, P_t, t, claims):                # IP-139/144
    return next((k for k in claims if valid(k, x, P_t, t)), None)

def review(kappa, Jp, raw, adv_gen):                # IP-140: 独立、前瞻
    adv = adv_gen.sample(kappa.S)                   # 审查方自生成，提出方不可见
    ok = min(pass_rate(kappa, s) for s in adv) >= 1 - alpha_rev
    return approve(kappa, cond=set_conditions(kappa)) if ok else reject(kappa)

def shift_pred(x, kappa, P_ref):                    # IP-141: 越界拒绝
    if shift_distance(P_t, P_ref) > kappa.rho:
        return Refuse()                             # 无主张，不是更宽的区间
    return robust_conformal(x, kappa.S, alpha=kappa.alpha, core=kappa.Inv)

def continuing_review(L, stream, t):                # IP-143: 只收缩不扩张
    if e_value(stream, t) >= 1 / alpha_cr:
        L.kappa = contract_domain(L.kappa, stream.anomaly)
        L.state = 'AE_escalated'                    # 强制 L2 + 收缩
    return L
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| GCR | O(\|claims\|) 查表 | O(\|claims\|) | 前瞻注册、只引用 Valid κ |
| IRB | O(\|𝒜_κ\|·C_eval) 离线 | O(\|𝒜_κ\|) | 独立性 I1–I4、对抗集保密 |
| SCOPE | O(d_φ)+O(N_cal) | O(N_cal) | 移位族内覆盖 ≥1−α、越界拒绝 |
| INV | O(m·C_inv) | O(m·d_Φ) | 至少一个 spurious 反转环境 |
| CR | O(1)/样本 | O(H_monitor) | 只收缩、AE 必触发复审 |
| JUR | O(1) | O(1) | 域外承诺数 = 0（构造） |

**正确性定理（Auditable Conditional Assurance, ACA 概要）**：在 A33–A40 上加 (A41) 主张注册完备、承诺只引用 Valid κ；(A42) 审查独立 I1–I4、对抗集与提出方语料非同源；(A43) SCOPE 在 𝒮_κ 内覆盖 ≥1−α_κ、越界返回 Refuse；(A44) CR 监控误报有界且 AE 必触发收缩。则：(i) **管辖内** `P(fail|Valid) ≤ r_κ+R_stat`；(ii) **管辖外** `P(commit)=0`（构造性，非统计）；(iii) 总风险 = `R_stat + R_ind`，其中 R_ind 为**不可约归纳风险**，只能被审查/监控/收缩治理；(iv) 不可逆动作失效需 `R_ind ∧ 证据门失效 ∧ 监控未及收缩` 同时成立。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 审查俘获 / 共享盲区 | 高 | 异构语料、外部红队、COI 账本、审查轮换、对抗集保密 |

| 持续审查误报致频繁收缩 | 中低 | e-value 序贯控制、滞后确认、复审仲裁 |

## 6. 本轮最大风险

**一句话**：本轮把"泛化"的担保从统计挪到了机构——若独立审查与被审查者共享同一语料与同一仿真器盲区，"审查通过"就立刻退化为给归纳风险盖合法印章的合规剧场，而管辖通胀会让拒绝防火墙在纸面上完备、在现实中失效；必须以异构语料红队、管辖边界由审查方批准、持续收缩与撤销权三重约束兜底，宁可拒绝一个"看起来能泛化"的世界，也不用制度权威为一处未知背书。

def valid(kappa, x, P_t, t, ae_log):
    return (kappa.approved
            and member(x, kappa.E)
            and in_shift_family(P_t, kappa.S, kappa.rho)
            and all(passes(w, t) for w in kappa.W)
            and t < kappa.exp

def require_claim(commit, x, P_t, t):

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| GCR | O(\|claims\|) 查表 | O(\|claims\|) | 前瞻注册、只引用 Valid κ（A41） |
| IRB | O(\|𝒜_κ\|·C_eval) 离线 | O(\|𝒜_κ\|) | 独立性 I1–I4、对抗集保密（A42） |
| SCOPE | O(d_φ)+O(N_cal) | O(N_cal) | 域内覆盖 ≥1−α、越界拒绝（A43） |
| INV | O(m·C_inv) | O(m·d_Φ) | 至少一个 spurious 反转环境、证伪环境 |
| CR | O(1)/样本 | O(H_monitor) | 只收缩、AE 必触发复审（A44） |
| JUR | O(1) | O(1) | 域外承诺数=0（构造） |
| PCE++ | PCE+ 加 O(\|CP\|·C_eval) | O(\|V\|+\|claims\|) | 域外先拒绝、域内照旧终止 |

**正确性定理（Auditable Conditional Assurance, ACA）**
假设 A22–A32、A33–A40 成立；**(A41)** 主张注册完备，承诺只引用 Valid κ；(**A42)** 审查独立 I1–I4，且对抗集 𝒜_κ 与提出方训练语料非同源；(**A43)** SCOPE 在 𝒮_κ 内覆盖 ≥1−α_κ，域外返回 Refuse 而非区间；(**A44)** CR 监控误报有界、AE 必触发收缩且自动机制只收缩不扩张。则：

1. **管辖内条件健全性**：`P(fail | Valid(κ)) ≤ r_κ + R_stat`，`R_stat = δ_f+ε_meta(k)+δ_probe+ε_h+δ_shift(κ)+δ_xm·1[L1]`。
2. **管辖外构造性安全**：`P(commit outside jurisdiction) = 0`——不依赖任何分布假设，纯由 JUR 门实现。
3. **风险分解（诚实性）**：`P(unsafe) = R_stat + R_ind`，其中 `R_ind = P(自称 x∈ℰ_κ 实则在 ℰ_κ 外)` 是**不可约归纳风险**；A41–A44 不消除它，只规定它必须被**声明**并受审查/监控/收缩治理。第 57 轮把这部分藏进 `δ_ood·α_conf`，本轮将其显式拆出。
4. **不可逆动作三重保险**：不可逆接触失效需 `R_ind 事件 ∧ 证据门失效 ∧ 监控未及收缩` 同时成立；任一守卫独立即可阻断。
5. **单调性（机构层）**：CR 与 IRB 只能缩域、加条件、缩短期限、撤销；不存在任何"自动扩域/放宽/加速"路径，个性化 auth 亦不能扩域。
6. **部署界**：

```
P_safe ≥ 1 − R_ind − Σ_cp R_stat(cp) − P(AE 未在 Δ_rev 内收缩)
（域外项由 JUR 构造性置零，不计入概率和）
```

关键：**域内给统计界、域外给构造性拒绝**——这才是对"未知分布"唯一诚实的回答；**R_ind 不可消、只可治**，因此把安全押在"审查与监控能否及时发现管辖误判"上，而不是押在"元模型恰好没漏检"上。

## 6. 本轮最大风险

**一句话**：本轮把"泛化"的担保从统计挪到了机构——若独立审查与被审查者共享同一语料、同一仿真器与同一盲区，"审查通过"就立刻退化为给归纳风险盖合法印章的合规剧场，而管辖通胀（把 ℰ_κ 声明得足够大以便放行）会让拒绝防火墙在纸面上完备、在现实中失效；必须以异构语料红队、管辖边界由审查方批准且附证伪见证、持续收缩与撤销权三重约束兜底，宁可拒绝一个"看起来能泛化"的世界，也不用制度权威为一处未知背书。
