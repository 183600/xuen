# 第 74 轮（承接第 73 轮「MODGAUGE-RAS 计量契约代数」IP-295~302；新灵感循环第 1 轮；本轮灵感：「关节驱动」×「人机交互」）

> R73 把「证据」做成了契约：MMS 模块三元组（契约/实现/证书）、CCA 串联-并联-否决组合代数、ΣREFLEX 通道化反作用预算、CPB 三条可证伪主张，并用 ECG 因果图（IP-302）把证据链显式化。它回答的是：**证据是否可信、能否在热替换下由组合规则保持安全性质**。
>
> 但整座大厦立在三个从未被自身审计的假设上：
> - **忠实执行假设**：控制域发出 `k`，系统默认 `k` 被关节忠实执行。可是关节驱动链（命令力矩 → 电流 → 电磁力矩 → 减速器输出 → 关节运动）本身是一条**会静默说谎的测量-执行通道**：电流-力矩常数随温度漂移、Stribeck 摩擦与静摩擦死区、谐波减速器扭转柔度与迟滞、传动回差、编码器量化、母线功率与电池压降、以及热降额。R73 的 `λ`、S2R-UQ 与停止距离全部建立在一个未被建模的执行器上。
> - **人是意图源而非被控对象假设**：R73 的 IRL 只把人类当意图隐变量 `z` 的来源。但在物理人机交互（pHRI）中，人的力**直接进入同一个力矩回路**；同一个力矩读数，在「无人接触 / 接近 / 交接 / 共享负载 / 约束 / 碰撞」下的物理含义完全不同。此时安全量不是避障距离，而是**接触力/功率传递与让位时延**。
> - **权威常量假设**：R73 的反作用是认知的——动作改变证据噪声。但动作也改变执行器本身：热积累降低力矩上限、磨损增大摩擦与回差、电池压降削减峰值功率、弹性储能改变响应。这是 **L5 执行权威反作用**：动作改变的是「未来还能不能执行安全动作」的**可行域**，而不只是噪声。传感器全对、证据全可信，证书仍可能不成立。
>
> 本轮两个灵感正好补上：
> - **关节驱动 → JAM（Joint Actuation Metrology）**：执行六分量不确定度（current / friction / elastic / backlash / encoder / thermal）+ **权威包络（authority envelope）**。核心概念区分：**不确定度是标量或分布，权威是集合或可行域**；把权威不足塞进 `λ` 当作方差，是把「**权威不足误读为不确定度大**」——R73 反复批判的「把 X 不确定度误读为 Y 不确定度」的同型新错误。一个机器人可以**对世界极其确定，却在物理上停不下来**。
> - **人机交互 → HCIM（Human-Coupling Impedance Metrology）**：耦合模式条件似然 `p(τ | s, h, w_h)` + 人类有界导纳/力-功率阈值/反应时延界 + **让位条件（yield condition）**。把人类从「意图源」升为「**共享执行通道的受限被控对象**」；人的反应时延是对机器人安全预算征收的一笔**死区税**。
> - 二者合流为 **CCA⁺**：新增 `COMP-AUTH`（执行链权威交）与 `COMP-YIELD`（人机共享权威的让位组合），并给出**权威组合单调性引理**——串联/否决/让位下权威只减；并联只有在**执行器独立性证书**通过时才允许 Minkowski 增大。这与 R73「并联不确定度只有在 conformal 审计通过后才允许缩窄」构成**精确对偶**。
> - **A-REFLEX**：ΣREFLEX 增加第五类通道 `a`（权威），预算 `Σ_t Σ_i c_auth^i ≤ B_auth`；**安全动作不免费**——急停、让位、反复避碰本身消耗未来执行安全动作的权威。这带来一个反直觉结论：**太多「看起来安全」的停车，可能耗尽之后真正保命所需的权威。**
>
> 核心命题：**不再问「证据是否可信」，而问「机器人是否拥有执行这份证据所要求的安全动作的权威——并且这份权威在人类共享执行通道时，是否仍可被计量、被组合、被否决？」** 把 MODGAUGE 上升为 **AUTH-GAUGE-RAS**（Actuation-uncertainty & Trust, Human-coupled GAUGE for RAS）——**执行权威计量学**。

## 0. 直觉与动机

**灵感 1（关节驱动 → 执行器是一个会「说谎」的证人）**
直觉：我们习惯把「命令了 20 N·m」当成事实。但真正到达环境的力矩是
`τ_d = k_t(T)·i + τ_g(q) − τ_f(q̇,τ) − τ_e(δ) ± quantization`，
右端每一项都有独立的物理机制与失效模式：
- `u_current`：电流采样噪声 + 力矩常数 `k_t(T)` 随绕组温度/磁饱和漂移；
- `u_friction`：Coulomb + Stribeck + 粘滞摩擦，且**静摩擦死区**让小幅命令力矩完全不产生运动（执行器「沉默」）；
- `u_elastic`：谐波减速器/串联弹性体的扭转柔度 `δ = τ/k_τ` 与迟滞，使输出角滞后于电机角；
- `u_backlash`：传动回差形成死区与相位滞后，换向瞬间尤其危险；
- `u_encoder`：编码器量化与差分测速噪声，低速时相对误差爆炸；
- `u_thermal`：绕组温升 `Ṫ = (i²R − h(T−T_amb))/C` 触发 `τ_max(T)` 降额、电阻变化、编码器对中热漂移。

与 R73 的深度六分量、接触四分量**完全同构**：它们都是「被动作与物理状态条件化的证据质量」。但 JAM 多出一个**类型不同的对象**：**权威包络 `A`**。它不是「力矩估计的方差」，而是「在控制时域内，这组关节**实际可达**的力矩-速度-加速度轨迹集合」（在热、功率、摩擦、回差约束下）。方差回答「我猜得准不准」，权威回答「我做不做得到」。把 `A` 压成 `σ` 再丢进 `λ`，等于用「不确定」冒充「不能」——系统可能自信地规划一个它根本执行不了的安全动作。

**灵感 2（人机交互 → 人类是被控对象，不是障碍物）**
直觉：把人类当障碍物，安全 = 保持距离；但真正的 pHRI 安全 = **接触力/功率低于身体部位阈值 + 能在人类反应之前让位**。人类是一个**有界导纳、有反应延迟、会主动施力、也会主动配合**的对象：
- 人的力 `w_h` 有上界 `F_max(h)`，接触功率 `P_c = w_c·ẋ` 有上界 `P_max(h)`（不同身体部位/接触面积不同）；
- 人有反应时延 `τ_h ∈ [τ_h,min, τ_h,max]`，`w_h(t)` 依赖机器人 `t−τ_h` 时刻的状态——这是一个**时滞微分约束**；
- 人的导纳 `Z_h` 未知但有界；共同收缩（co-contraction）会提高表观刚度；
- 人既能**帮助**（共享负载，减少机器人权威需求），也能**破坏**（突然倚靠、抓握、推搡，抢占权威）。

因此「人类」不是一个标签，而是一个**耦合模式隐变量** `h ∈ H`。同一力矩证据必须写成 `p(τ | s, h, w_h)`：在 `shared-load` 下，额外的力矩是协作；在 `collision` 下，同样的力矩是危险。这与 R73 的「材质条件深度似然」是同一招，但条件变量从「场景材质」换成了「**人机耦合模式**」。

**灵感 3（组合 → 权威代数与不确定度代数互为镜像）**
直觉：R73 的 CCA 有一条优美的单调性：串联不确定度只增；并联只有在 conformal 一致性审计通过、且跨模态相关性足够低时才允许缩窄；否决非补偿。执行权威的代数**恰好是它的镜像**：
- 串联（执行链 A∘B）：权威**取交** `A_out = A_A ∩ A_B`，只减不增（任一段做不到，整链做不到）；
- 否决：任一权威为空 ⇒ 整体否决（非补偿）；
- 让位（人机共享）：`A_out = A_robot ∩ (A_total ⊖ A_human,max)`，人类占用的权威从机器人可用权威中扣除，只减；
- 并联（冗余执行器，如双臂持物）：**只有在「执行器独立性证书」通过时**才允许 Minkowski 和 `A_A ⊕ A_B` 增大；共享母线功率、共享热通路、共享结构都会破坏独立性，此时退化为取交。
两套代数的对偶不是修辞，而是**设计原则**：证据侧的乐观（缩窄）需要审计，执行侧的乐观（增大）同样需要审计。**没有免费的认知，也没有免费的权威。**

**灵感 4（L5 执行权威反作用 → 安全动作会耗尽它自己所依赖的权威）**
直觉：R73 的反作用预算统计的是「信息成本」。可物理世界里，每一次急停、让位、避碰都在消耗执行器：热（`∫i²R dt`）、磨损（`∫|τ|dt`）、电池（`∫P dt`）、弹性储能。于是安全动作有一个**隐藏价格**：`c_auth(g) = E[ΔA | g]`。当 `A` 跌落到「让位集 `Y_safe`」以下时，机器人就**失去了执行最后防线动作的能力**。这解释了真实事故里一个反直觉的模式：系统在几十次「成功」的保守停车后，热降额让它在下一次真正需要急停时停不下来。安全证书必须包含**权威预算**，而不只是证据预算。

**灵感 5（人类信任/可读性 → 耦合证据本身要被审计）**
直觉：人的反应时延不是常数，它依赖机器人行为的**可读性/可预测性**。一个动作在物理上安全（力低于阈值），却可能因为不可预测而让人类反应更慢、更慌乱，从而在 `τ_h` 上放大风险。于是 `τ_h` 的界应当把「人类的预测不确定性」纳入：机器人行为越不可读，`τ_h,max` 越保守。这把 HRI 的「信任/可读性」从一个主观指标变成 `τ_safe` 约束里的一个**可审计上界**。

## 1. 形式化定义（增量：定义 383–399）

**定义 383（AUTH-GAUGE-RAS 总览与六不变式）** AUTH-GAUGE-RAS = (JAM, HCIM, CCA⁺, A-REFLEX, HCSC, CPB⁺, MODGAUGE†)。六不变式：
(i) **执行契约完整性**：每个关节/执行器模块必须实例化执行契约 AC（定义 385），无 AC 不入图；
(ii) **证据-权威类型分离**：不确定度 `u`（标量/分布）与权威 `A`（可行域/集合）是不同类型，**不可相加、不可互相折算**；权威只能用于否决与约束；
(iii) **权威组合单调性**：SER/VETO/YIELD 下权威非增；PAR 增大仅当独立性证书通过（引理 38）；
(iv) **人类耦合完备性**：每个物理交互动作必须声明支持的模式集 `H`、力/功率阈值、反应时延界，并通过 HCSC（定义 389）；
(v) **权威反作用预算与权威地板**：`Σ_t Σ_i c_auth^i ≤ B_auth`，且任何时刻 `A ⊇ Y_safe`，权威地板非补偿、不可交易；
(vi) **严格退化链**：`h = free ∧ A = ∞ ∧ JAM` 理想 ⇒ 逐指令等于 MODGAUGE ⇒ 再退化等于 R72/R71/R68；安全侧只增不减。

**定义 384（关节执行计量 JAM）** 对关节 `j`，观测量 `y_a = (τ_sensed, i_m, q, q̇, T, V_batt)`，条件似然 `p_act(τ_d | s, q, g, T)`，区间宽度由六分量合成：
`u_act² = u_current²(T, i_m) + u_friction²(q̇, τ) + u_elastic²(τ) + u_backlash²(q, q̇) + u_encoder²(q, q̇) + u_thermal²(T)`。
摩擦用 Stribeck 模型 `τ_f = τ_c sgn(q̇) + (τ_s − τ_c)e^{−|q̇|/q̇_s}sgn(q̇) + b q̇`，静摩擦死区 `|τ_cmd| < τ_s ⇒ q̇ = 0`。弹性 `δ = τ/k_τ + h_ela(τ)`（迟滞），回差为死区 `±b/2`。热模型 `Ṫ = (i²R − h(T−T_amb))/C`，`τ_max(T)` 单调降额。**每个分量独立追溯链 `τ_a,i`。**

**定义 385（执行契约 AC）** `AC = (EC†, J_type, A_out, T_model, τ_yield, H, W_auth, seal_ref_act)`：
- `J_type ∈ {rigid, SEA, QDD, harmonic, pneumatic, …}`：执行形态（供 MIC/形态迁移使用）；
- `A_out`：控制时域 `H_c` 上的权威包络（定义 386）；
- `T_model`：热/磨损/电池状态与界；
- `τ_yield: (g, h) → ℝ⁺`：让位时延函数；
- `H`：本模块支持的人类耦合模式集；
- `W_auth`：权威预算（焦耳/磨损量/电量等价）；
- `seal_ref_act`：SEAL-Actuator / SEAL-HRI 引用。

**定义 386（权威包络 A）** `A_j(g; H_c) = { (τ_j(t), q̇_j(t))_{t∈[0,H_c]} : |τ_j| ≤ τ̄_j(T_j), |q̇_j| ≤ q̇̄_j, P = Σ_j τ_j q̇_j ≤ P̄(V_batt, T), ∫ i_j²R dt ≤ E_th, τ_j ∈ [τ_lo, τ_hi] }`，经雅可比 `J^{-T}` 映射为末端力旋量集 `A_e`。要求 `A` 是**真实可达集的保守超集**（覆盖置信度 `1−β`，SEAL-Actuator 校准）。权限语义：`y ∉ A(g) ⇒ 动作 g 必须被否决`（不是「降权」，是硬约束）。

**定义 387（耦合模式与条件似然）** `H = {free, approach, contact-handover, shared-load, constraint, collision}`。模式后验 `b_t(h)` 由力矩/触觉/接近/视觉/语音在线推断；`p_act(τ | s, h, w_h)` 在 `h` 条件下把力矩分解为（任务负载，人类力，摩擦/动力学误差）。`h = unknown` ⇒ 取最保守包络。

**定义 388（人类导纳、力-功率界、反应时延）** 人类导纳 `Z_h ∈ 𝒵`（未知但有界）；接触力/功率阈值 `F_max(h)`, `P_max(h)`（按身体部位与接触面积，参考 ISO/TS 15066 准静态/动态准则）；反应时延 `τ_h ∈ [τ_h,min(h), τ_h,max(h)]`，`w_h(t)` 依赖机器人 `t−τ_h` 的状态。耦合动力学：
`M(q)q̈ + C(q,q̇)q̇ + g(q) = τ_d + Jᵀ(q)w_h + Jᵀ(q)w_c`。

**定义 389（让位条件 HCSC / Human-Coupled Safety Certificate）** 让位动作 `y ∈ {零力矩/反驱动, 导纳控制, 后退, 松开}`。`HCSC(g,h) := y ∈ A_eff(g; τ_h,max) ∧ τ_yield(g,h) + τ_h,max ≤ τ_safe(h) ∧ P_c ≤ P_max(h) ∧ F_c ≤ F_max(h)`。其中 `A_eff` 是在最坏人类力旋量下、持续 `τ_h,max` 的**鲁棒可达集**（死区税后的权威）。`τ_safe(h)` 由任务、身体部位、可读性上界共同决定。

**定义 390（CCA⁺ 组合代数）** 五个算子：
- **COMP-SER**（执行链串联）：`A_out = A_A ∩ A_B`；`u_out ≥ u_A + L_B u_A`；域取交、追溯合并、否决取并（继承 R73）。
- **COMP-PAR**（冗余执行器并联）：若 `Indep(A,B)`（不共享母线功率/热通路/结构、时间同步、无内耗）成立 ⇒ `A_out = A_A ⊕ A_B`（Minkowski 和，允许增大）；否则 `A_out = A_A ∩ A_B`（保守）。含人类时**禁用 Minkowski 增大**（人类可吸收/重定向），退化为 COMP-YIELD。
- **COMP-VETO**：`A_out = A_A ∩ A_B`；任一为空或 HCSC 失败 ⇒ 整体否决（非补偿）。
- **COMP-AUTH**（力传递链，如臂-手）：`A_out = ∩` 且摩擦/回差/柔度在链上叠加，`u` 按 SER 传播。
- **COMP-YIELD**（人机共享权威）：`A_out = A_robot ∩ (A_total ⊖ A_human,max)`，并要求阻抗匹配 `τ_yield ≤ τ_h,min`；否则不得进入该交互。

**定义 391（A-REFLEX 第五反作用层）** `c_auth^i(g) = E[ΔA^i | g]`，由热/磨损/电池/弹性四部分构成。预算 `Σ_t Σ_i c_auth^i ≤ B_auth`。稳态集 `A_safe = {a : A_{t+1}(a) ⊇ Y_safe ∧ margin_T ≥ m_T ∧ margin_V ≥ m_V}`。任一层越界 ⇒ 动作拒绝（非补偿）。与 ΣREFLEX 的 `ψ/z/c/v` 四层并行，构成第五通道 `a`。

**定义 392（执行感知安全包络）** `d_stop(g) = v·τ_delay + v²/(2a_max(A,T))`，其中 `a_max` 由当前权威、摩擦与热状态给出；安全包络 `E_auth = {g : d_stop(g) + v·τ_h,max ≤ clearance ∧ HCSC(g,h)}`。`τ_delay` 含控制域延迟、网络/调度延迟与 `τ_yield`。

**定义 393（执行威胁面 AIC-ACT）** `ℰ_act = {` 人类突袭（突然抓握/倚靠/推搡）、执行器故障（关节抱死、力矩常数漂移、编码器投毒）、热拒绝服务（诱导反复急停以降额）、力矩传感器欺骗、共同收缩陷阱 `}`。防线：JAM 与力矩传感/电流/编码器跨源一致性、单源不定案、权威降额、硬件权威地板。

**定义 394（CPB⁺ 主张 C4/C5/C6）**
- **C4（执行计量）** ← (JAM, A-REFLEX) ← MB4 ← AB4（六分量 vs 命令力矩当真值 vs 标量高斯执行噪声 vs 学习残差模型）← (力矩 NLL/ECE、停距误差、**假安全证书率**、假否决率)；
- **C5（人机耦合安全）** ← (HCIM, COMP-YIELD, HCSC) ← MB5 ← AB5（耦合模式条件 vs 人当障碍物 vs 人当噪声 vs 固定阻抗）← (峰值力/功率越界率、让位时延、任务时间、人类主观信任)；

非绑定组件 = 工程附件，不进核心认证路径。

**定义 395（模块级 E-IVG 扩展）** JAM 失效（区间超界/跨源不一致/热模型失配）⇒ **权威 stub**（该关节 `A = ∅`，一切依赖它的动作硬否决）；编码器故障 ⇒ 保守状态 stub + 降额权威；热限 ⇒ 降额权威（非零）；HCIM 失效 ⇒ 人类视为最大力扰动（收缩 `A`）；模式未知 ⇒ 取最保守 `h`。**无级联**：失效只能收缩本模态权威，不得污染其他模块的审计。

**定义 396（组合证书 J_ACT）** `J_ACT = J_MOD ⊗ J_AUTH ⊗ J_HRI`：`J_MOD` 为 R73 证据证书；`J_AUTH` 校验执行器标定、权威包络覆盖、热/摩擦/回差界；`J_HRI` 校验耦合模式校准、力/功率阈值适用性、反应时延界、HCSC 覆盖率。`Valid(J_ACT) ⇒ 证据有效 ∧ 权威可信 ∧ 人机耦合安全`。

**定义 397（复杂度结构上限扩展）** `|V_M| ≤ 24`、组合深度 ≤ 4（权威是**类型**而非新节点）、`|H| ≤ 6`、权威维数 ≤ 6（力旋量 6 维）、每关节热状态 ≤ 3、`H_c` 节点 ≤ 4。全部为 MReg 可审计图/类型性质。

**定义 398（可读性调节的反应时延界）** `τ_h,max(h) = τ_h,0(h) + κ·(1 − L(g))`，`L(g) ∈ [0,1]` 为行为可读性预测（预测人类对机器人下一步的置信度）；`L` 越低，`τ_safe` 越保守。这把「信任」变成 `τ_safe` 里的一个**可审计上界**，而非主观量表。

**定义 399（退化条件 A114–A116）** A114：JAM 六分量与热模型覆盖真实执行分布；A115：权威包络是真实可达集的保守超集（含摩擦/回差/热）；A116：人类力/功率/导纳/反应时延界在部署分布内成立。三条件同时成立时，定理 30–33 才严格成立。

class JointActuationMetrology:
    def update(self, q, qd, i_m, tau_sensed, T, v_batt):
        u_cur  = self.calib.current_unc(T, i_m)        # k_t(T) 漂移 + 采样噪声
        u_fric = self.fric.bound(qd, tau_sensed)        # Stribeck + 静摩擦死区
        u_ela  = self.elastic.bound(tau_sensed)         # 谐波/SEA 扭转柔度 + 迟滞
        u_back = self.backlash.bound(q, qd)             # 回差死区 + 相位滞后
        u_enc  = self.enc.quant_unc(q, qd)              # 量化 + 差分测速
        u_therm= self.thermal.derate_unc(T)             # 温升 -> 力矩降额
        lo, hi = interval(tau_sensed, u_cur, u_fric, u_ela, u_back, u_enc, u_therm)
        A      = self.auth.reachable(q, qd, lo, hi, T, v_batt)  # 可达集（zonotope）
        return ActEvidence(tau=(lo, hi), u=sqrt(u_cur**2+u_fric**2+u_ela**2+
                              u_back**2+u_enc**2+u_therm**2),
                           A=A, T=T, tau_max=self.thermal.tau_max(T),
                           tau=self.tchain.merge(self.trace))

def compose_plus(a, b, op, audit):
    if op == 'SER' or op == 'AUTH':          # 执行链：权威取交，只减不增
        return Ev(u=a.u + lip(b, a.u), A=a.A & b.A,
                  tau=a.tau.merge(b.tau), veto=a.veto | b.veto)
    if op == 'PAR':                          # 冗余执行：仅独立证书通过才允许增大
        if audit.independence_cert(a, b) and not audit.human_in_loop(a, b):
            A = minkowski(a.A, b.A)          # 需功率/热/结构不共享 + 同步
        else:
            A = a.A & b.A                    # 保守退化
        return Ev(u=a.u, A=A, tau=a.tau.merge(b.tau), veto=a.veto | b.veto)
    if op == 'VETO':                         # 非补偿
        if not a.A or not b.A or a.veto or b.veto:
            return Ev(valid=False, A=EMPTY, veto=a.veto | b.veto)
        return Ev(u=min(a.u, b.u), A=a.A & b.A)
    if op == 'YIELD':                        # 人机共享权威
        if not audit.impedance_match(a, b):  # tau_yield <= tau_h_min
            return Ev(valid=False, A=EMPTY, veto={'IMPEDANCE_MISMATCH'})
        A = a.A & subtract(a.A_total, b.F_max, b.P_max)   # 人类占用扣除
        return Ev(u=a.u, A=A, tau=a.tau.merge(b.tau), veto=a.veto)

# IP-306 A-REFLEX：第五层权威反作用预算（事件触发）
def authority_reflex(modules, g, state, budget):
    total, states2 = 0.0, {}
    for i, m in modules.items():
        chi = m.ac.chi_A(g)                              # 动作如何消耗权威
        c, s2 = m.authority_cost(state[i], chi)          # 热/磨损/电池/弹性
        if not (m.yield_set <= s2.A):                    # 权威地板：不可补偿
            return None, total
        if s2.margin_T < m.mT or s2.margin_V < m.mV:
            return None, total
        states2[i], total = s2, total + c
    if budget.spent + total > budget.B_auth:
        return None, total
    return states2, total

# IP-307 HCSC：让位安全证书与执行感知规划
def hcsc_check(g, act_ev, hum_ev, safety):
    if not contains(act_ev.A_eff(hum_ev.tau_h_max), safety.yield_maneuver):
        return False, 'NO_AUTHORITY'

    if hum_ev.F_hi > safety.F_max or hum_ev.P_hi > safety.P_max:
        return False, 'FORCE_POWER'
    return True, 'OK'

## 3. 推导

**引理 38（权威组合单调性：没有免费的权威）** 对 SER/AUTH：`A_out = A_A ∩ A_B ⊆ A_A, A_B`；VETO：`A_out ⊆` 任一输入；YIELD：`A_out = A_robot ∩ (A_total ⊖ A_h,max) ⊆ A_robot`。对 PAR：`A_out ⊆ A_A ⊕ A_B`，等号成立当且仅当 `Indep(A,B)`（功率/热/结构独立且同步）。⇒ 任何组合路径的权威不可能既超过输入证书的物理上限、又通过独立性审计。系：**权威代数是不确定度代数的镜像——证据侧缩窄要审计，执行侧增大也要审计。**

**引理 39（执行六分量的条件正交性）** 给定 `(q, q̇, T, 回差状态, 编码器状态, 摩擦区制)` 条件下，六分量由独立物理机制产生（电磁、接触摩擦、弹性变形、传动间隙、量化、热），条件近似不相关；遗漏任一 ⇒ 系统性低估区间宽度 ⇒ **假安全**。与 R73 引理 33 同型，但目标从「方差」变为「区间/可达集」。系：**JAM 不是「给力矩加个噪声」，而是把执行链升级为可审计的证据链。**

**引理 40（耦合模式可辨识与条件似然校准）** 若任意两种耦合模式 `h, h′` 的观测分布满足 `KL(p(·|h) ‖ p(·|h′)) ≥ δ > 0`，则后验 `b_t(h)` 以速率 `O(e^{−δt})` 收敛；用 SEAL-HRI 做 conformal 校准可控制模式误判的覆盖。若分离度不足（如 `shared-load` 与 `constraint` 在小力下难分），则 `h = unknown`，取最保守包络。系：**耦合模式必须被当作「材质」一样校准，不能靠工程直觉硬编码。**

**引理 41（让位时延的 Lipschitz 性与死区税）** 在 `A` 内，`τ_yield(g,h)` 对 `(g, τ_h)` Lipschitz；人类反应时延把有效权威收缩为 `A_eff(τ_h) ⊆ A`，且 `A_eff` 随 `τ_h` 单调收缩。⇒ 人类反应时延是对安全预算的**死区税**：`τ_yield + τ_h,max ≤ τ_safe`。系：**在人机共享通道里，「快」不是性能指标，而是安全约束。**

**引理 42（权威反作用的预算吸收与有限安全停车）** 对最大权威动作，热生成 `∫i²R dt ≥ ε_th > 0`，磨损 `∫|τ|dt ≥ ε_w > 0` ⇒ `c_auth(g) ≥ ε_a > 0`。在热模型 `Ṫ = (i²R − hΔT)/C` 下，存在有限 `N*` 使得连续 `N*` 次最大强度安全停车后 `A < Y_safe`。⇒ 权威预算是**有限资源**，且**被安全动作本身消耗**。系：**「安全动作」和「安全能力」不是同一件事；前者会耗尽后者。**

**引理 43（接触力/功率传递上界）** 在人类有界导纳 `Z_h ∈ 𝒵`、有界力 `‖w_h‖ ≤ F_h,max`、机器人权威 `A` 下，接触功率 `P_c = w_c·ẋ` 与接触力 `F_c` 有上界；由 `A_eff` 与 `τ_yield` 可得停止距离上界 `d_stop ≤ v τ_delay + v²/(2a_max(A,T))`。⇒ HCSC 的三项约束（力、功率、时延）可由 JAM+HCIM 的界**前验**检查，不需要事后重放。系：**一次性物理交互的安全必须事前证明——这继承并强化 R73 的「不可反事实」纪律。**

**定理 30（AUTH-GAUGE 严格包含）** 在 A114–A116 下：令 `h = free`（无人）、`A = ∞`（理想执行器、无热/功率限）、JAM 六分量为零，则 HCIM 平凡、A-REFLEX 恒等、COMP-YIELD 不用、HCSC 恒真，CCA⁺ 逐条退化为 CCA。由引理 38 与 R73 定理 27，AUTH-GAUGE 逐指令等于 MODGAUGE，再退化等于 R72/R71/R68。**安全单调不减；性能收益只在权威与人类模型成立时兑现。**

**定理 31（HCSC 有效性 ⇒ 人机耦合安全）** 若 `Valid(J_ACT)`：各模块证书有效、`J_AUTH` 证明 `A` 是真实可达集超集、`J_HRI` 证明人类力/功率/导纳/时延界成立，且每个被采纳动作满足 `HCSC`，则（相对执行模型与人类包络）接触力/功率越界概率 `≤ ε_h`，且机器人能在 `τ_safe` 内让位。**证明重量落在 A115（权威超集）与 A116（人类包络）在分布外仍成立**。

**定理 32（权威地板与零级联）** 任一执行器故障 ⇒ 权威 stub（`A = ∅`）或降额权威 ⇒ 依赖该关节的动作被硬否决；其余模块按定义 395 逐指令退化到低权威模式（冻结/后退/松开），人类侧 VETO 保留。⇒ 失效传染路径唯一（该执行通道缺失），无级联。系：**R73 的「零级联」从证据侧扩展到执行侧。**

**定理 33（执行器热替换与形态迁移）** 若 `impl′` 与 `impl` 满足同一 AC（J_type、A_out 类型、热模型界、`τ_yield` 结构、H、预算逐项相同）且 `cert′` 有效，则系统级性质（证据退化链、权威单调、HCSC、时序隔离）的证明只引用 AC 与组合校验，不引用实现内部 ⇒ 逐指令保持。认证成本 `O(系统) → O(模块)`。系：**MIC（形态无关契约）获得执行语义：换 SEA 为 QDD 只需重认证执行模块，不动主闭环。**

## 6. 本轮最大风险

**一句话**：AUTH-GAUGE 把安全的最后一道保证从「证据可信」转移到「**权威可证**」，而权威是**模型对物理能力的预测，模型又只能靠驱动同一批执行器来标定**——如果执行器退化以某种方式同时污染「能力」与「验证」（摩擦增大被误归因为负载、力矩常数漂移被误归因为人类施力、编码器偏置被误归因为弹性变形、人类无意倚靠让一个已失效的关节看起来仍能出力），那么系统会在**所有证据证书有效、所有权威包络自洽、所有 HCSC 通过**的情况下，为自己并不拥有的执行权威签发一张完美合规的证书：它不是「错误地认识世界」（R73 的风险），而是**正确地认识世界、却错误地相信自己的身体**，然后自信地停不下来。

次级风险与缓解：
1. **权威自证循环（性能即证明）** → 权威标定必须使用**环路外独立测量**（外部力台、扭矩传感器、热成像），并设**硬件权威地板**（机械限扭/离合/柔顺罩/保险丝），软件证书失效时硬件仍能兜底；SEAL-Actuator 由第三方执行。
2. **人类模型失配（导纳/反应时延分布外）** → 默认取最保守包络；在线估计 + 保守上界；`h=unknown` 时禁用共享负载模式；SEAL-HRI 覆盖身体部位与接触面积分层。
3. **摩擦/回差的激励依赖不可辨识** → 主动探针本身消耗权威（又一层循环）；探针预算独立于安全预算，且探针只在低风险态执行；不可辨识即取上界。
4. **权威过保守导致「冻结机器人」** → 权威地板之外允许**降级但有用**的模式（慢速、柔顺、有限行程）；报告任务吞吐而非只报安全，避免用安全证书掩盖不可用。
5. **ISO/TS 15066 阈值误用（身体部位/接触类型/准静态 vs 动态）** → 阈值作为显式契约字段（可审计），按场景绑定；错误绑定由 `J_HRI` 拒绝。
6. **热/磨损长尾与分布漂移** → 长时程实验 E409；权威预算随时间与工况自适应；硬件热保护不依赖软件。
7. **MBench 过拟合 / Goodhart** → MB4–MB6 预注册 + 固定种子 + 密封保持集 SEAL-MB；主张只认预注册指标；HRI 主观信任只作次要指标，不作安全证据。

## 2. 形式化定义（要点版）

**定义 383（总览与六不变式）** 执行契约完整性 / 证据-权威类型分离 / 权威组合单调性 / 人类耦合完备性 / 权威预算与权威地板 / 严格退化链。

**定义 384（JAM）** `p_act(τ_d|s,q,g,T)`；六分量各有独立追溯链；摩擦含 Stribeck 与静摩擦死区；弹性含谐波/SEA 柔度与迟滞；回差为死区；热模型给出 `τ_max(T)` 降额。

**定义 385（执行契约 AC）** 见符号表。核心：**权威 `A_out` 与让位时延 `τ_yield` 是契约字段**——「我能不能做、多快能让位」成为模块必须声明的接口信息。

**定义 386（权威包络）** 真实可达集的保守超集（覆盖 `1−β`）；`y ∉ A(g)` ⇒ 硬否决，而非降权。权威与不确定度是不同类型，禁止折算。

**定义 387（耦合模式与条件似然）** `H` 六模式；`b_t(h)` 在线推断；同力矩在 `shared-load` 下是协作、在 `collision` 下是危险；`h=unknown` 取最保守包络。

**定义 388（人类界）** 有界导纳、按身体部位/接触面积的力-功率阈值、反应时延区间；人力的时滞依赖 `w_h(t) = f(s(t−τ_h))`。

**定义 389（HCSC/让位条件）** 让位动作可达 ∧ 死区税 ∧ 力/功率阈值。安全 = 能在人类反应之前让位，而不只是保持距离。

**定义 390（CCA⁺）** SER/AUTH：权威取交；PAR：仅独立证书（功率/热/结构独立、同步、无内耗）通过且无人时允许 Minkowski 增大，否则取交；VETO：任一为空即否决；YIELD：`A_robot ∩ (A_total ⊖ A_human,max)` 且阻抗匹配 `τ_yield ≤ τ_h,min`。

**定义 391（A-REFLEX）** 第五反作用通道 `a`；成本 = 热/磨损/电池/弹性；预算 `B_auth`；权威地板非补偿；`A_safe` 稳态集。

**定义 392（执行感知安全包络）** `d_stop` 随权威与热降额变化；`E_auth` 含死区税；轨迹规划必须落在 `E_auth`。

**定义 393（AIC-ACT）** 五类执行威胁；防线：跨源一致性 + 单源不定案 + 权威降额 + 硬件权威地板。

**定义 394（CPB⁺）** C4←(JAM,A-REFLEX)←MB4←AB4；C5←(HCIM,COMP-YIELD,HCSC)←MB5←AB5；C6←(CCA⁺,独立性证书)←MB6←AB6。非绑定=工程附件。

**定义 395（模块级 E-IVG）** JAM 失效 ⇒ 权威 stub（`A=∅`，硬否决）；编码器故障 ⇒ 保守状态 + 降额权威；热限 ⇒ 降额权威；HCIM 失效 ⇒ 人类视为最大力扰动；模式未知 ⇒ 最保守 `h`。零级联。

**定义 396（J_ACT）** `J_ACT = J_MOD ⊗ J_AUTH ⊗ J_HRI`；Valid ⇒ 证据有效 ∧ 权威可信 ∧ 人机耦合安全。

**定义 397（结构上限）** `|V_M|≤24`、组合深度 ≤4、`|H|≤6`、权威维数 ≤6、每关节热状态 ≤3、`H_c` 节点 ≤4——MReg 可审计图/类型性质。

**定义 398（可读性调节）** `τ_h,max = τ_h,0 + κ(1−L(g))`；可读性越低，反应时延上界越大，`τ_safe` 越保守。

**定义 399（退化条件）** A114 执行模型表达力 / A115 权威包络超集 / A116 人类包络正确性。

class JointActuationMetrology:
    def update(self, q, qd, i_m, tau_sensed, T, v_batt):
        u_cur  = self.calib.current_unc(T, i_m)      # k_t(T) 漂移 + 采样噪声
        u_fric = self.fric.bound(qd, tau_sensed)      # Stribeck + 静摩擦死区
        u_ela  = self.elastic.bound(tau_sensed)       # 谐波/SEA 柔度 + 迟滞
        u_back = self.backlash.bound(q, qd)           # 回差死区
        u_enc  = self.enc.quant_unc(q, qd)            # 量化 + 差分测速
        u_therm= self.thermal.derate_unc(T)           # 热降额
        lo, hi = interval(tau_sensed, u_cur, u_fric, u_ela, u_back, u_enc, u_therm)
        A = self.auth.reachable(q, qd, lo, hi, T, v_batt)   # 可达集（zonotope）
        return ActEvidence(tau=(lo,hi), u=sqrt(u_cur**2+u_fric**2+u_ela**2+
                              u_back**2+u_enc**2+u_therm**2),

def compose_plus(a, b, op, audit):
    if op in ('SER', 'AUTH'):
        return Ev(u=a.u + lip(b, a.u), A=a.A & b.A,
                  tau=a.tau.merge(b.tau), veto=a.veto | b.veto)
    if op == 'PAR':
        if audit.independence_cert(a, b) and not audit.human_in_loop(a, b):
            A = minkowski(a.A, b.A)                  # 仅独立 + 无人时允许增大
        else:
            A = a.A & b.A                            # 保守退化
        return Ev(u=a.u, A=A, tau=a.tau.merge(b.tau), veto=a.veto | b.veto)
    if op == 'VETO':
        if not a.A or not b.A or a.veto or b.veto:
            return Ev(valid=False, A=EMPTY, veto=a.veto | b.veto)
        return Ev(u=min(a.u, b.u), A=a.A & b.A)
    if op == 'YIELD':
        if not audit.impedance_match(a, b):
            return Ev(valid=False, A=EMPTY, veto={'IMPEDANCE_MISMATCH'})
        A = a.A & subtract(a.A_total, b.F_max, b.P_max)
        return Ev(u=a.u, A=A, tau=a.tau.merge(b.tau), veto=a.veto)

# IP-306 A-REFLEX：第五层权威预算
def authority_reflex(modules, g, state, budget):
    total, states2 = 0.0, {}
    for i, m in modules.items():
        chi = m.ac.chi_A(g)
        c, s2 = m.authority_cost(state[i], chi)      # 热/磨损/电池/弹性
        if not (m.yield_set <= s2.A): return None, total     # 权威地板
        if s2.margin_T < m.mT or s2.margin_V < m.mV: return None, total
        states2[i], total = s2, total + c
    if budget.spent + total > budget.B_auth: return None, total
    return states2, total

def hcsc_check(g, act_ev, hum_ev, safety):

def AUTH_GAUGE_round(M, obs, audio, tac_frame, depth_img, joints, human):
    d_ev = M.dpe.update(depth_img, rgb, M.cam_state, M.motion, M.peers)
    t_ev = M.dmem.update(tac_frame, M.last_action)
    a_ev = M.jam.update(joints)
    h_ev = M.hcim.update(a_ev, human.tactile, human.prox, rgb, human.voice)
    if not a_ev.sound: a_ev = authority_stub(M.jam)
    if M.clock.due_metric():
        b_t = M.bse.step_full(..., d_ev=d_ev, t_ev=t_ev, a_ev=a_ev)
        cplx = M.cca_plus.compose(a_ev, h_ev, 'YIELD', M.audit)
        if not cplx.valid: return M.safe_stop(), False
        g = M.ervoi.choose(b_t, psi_hat, z_dist, t_ev.c_dist, M.budget, M.fmp, M.bse)
        if g:
            ok, why = hcsc_check(g, a_ev, h_ev, M.safety)
            if ok:
                s2, c = authority_reflex(M.mods, g, M.state, M.auth_budget)
                if s2 is not None: M.last_g, M.state = g, s2
            else:
                g = M.yield_policy(why)
        M.snapshot.write(b_t, a_ev, h_ev, cplx, M.state)
    snap = M.snapshot.read_latest()
    lam = embodied_risk_scale(snap.U_ale, snap.U_epi, snap.H_z,
                              max(snap.t_ev.u, snap.a_ev.u), M.risk_params)
    A = M.ach.propose_ctrl(..., pvop_bias=snap.pvop)
    k = M.c_ras_wm.certified_prefix(A, lam)
    if not contains(snap.cplx.A, k): return M.safe_stop(), False
    M.ctrl_out.publish(k, lam)
    return k, J_ACT(M.mreg, M.jam, M.hcim)

def actuator_fault_isolation(tau_sensed, i_m, q, qd, T):
    r = [residual_current(tau_sensed, i_m, T),
         residual_motion(q, qd, tau_sensed),
         residual_thermal(T, i_m)]
    if disagreements(r) >= 2: return 'FAULT', conservative_authority()

## 4. 推导要点

**引理 38（权威组合单调性）** SER/AUTH：`A_out ⊆` 各输入；VETO：`⊆` 任一；YIELD：`⊆ A_robot`；PAR：`A_out ⊆ A_A ⊕ A_B`，等号仅当独立证书成立。⇒ **没有免费的权威**；与 R73「没有免费的认知」互为镜像。

**引理 39（执行六分量条件正交性）** 给定执行状态，六机制条件近似独立；遗漏 ⇒ 区间系统性偏窄 ⇒ 假安全。

**引理 40（耦合模式可辨识）** 模式分布 KL 分离 `≥δ` ⇒ 后验收敛；分离不足 ⇒ `unknown` + 最保守包络；SEAL-HRI 控制误判覆盖。

**引理 41（死区税）** `τ_yield` 对 `(g,τ_h)` Lipschitz；`A_eff(τ_h)` 随 `τ_h` 单调收缩；`τ_yield+τ_h,max≤τ_safe` 为硬约束。

**引理 42（权威预算吸收）** `c_auth ≥ ε_a > 0`；热模型下存在有限 `N*` 次最大强度安全停车后 `A < Y_safe`。⇒ **安全动作有限，且被自身消耗。**

**引理 43（力/功率/停距上界）** 有界人类导纳 + 有界力 + 权威 ⇒ `F_c, P_c, d_stop` 上界；HCSC 可**前验**检查，无需事后重放。

**定理 30（严格包含）** `h=free ∧ A=∞ ∧ JAM` 理想 ⇒ 逐指令等于 MODGAUGE ⇒ R72/R71/R68；安全单调不减。

**定理 31（HCSC 有效性 ⇒ 人机耦合安全）** `Valid(J_ACT)` ⇒ 力/功率越界概率 `≤ ε_h`，且在 `τ_safe` 内可让位；证明重量在 A115/A116。

**定理 32（权威地板与零级联）** 执行器故障 ⇒ 权威 stub/降额 ⇒ 依赖动作硬否决；其余模块逐指令降级；人类侧 VETO 保留；无级联。

**定理 33（执行器热替换）** 同 AC + 有效 cert ⇒ 系统级性质逐指令保持；认证成本 `O(系统)→O(模块)`；MIC 获得执行语义。

## 7. 本轮最大风险

**一句话**：AUTH-GAUGE 把最后保证从「证据可信」转移到「**权威可证**」，而权威是模型对物理能力的预测、模型又只能靠驱动同一批执行器来标定——一旦退化同时污染「能力」与「验证」（摩擦增大被误归因为负载、力矩常数漂移被误归因为人类施力、编码器偏置被误归因为弹性、人类无意倚靠让失效关节看似仍能出力），系统就会在**证据证书全有效、权威包络自洽、HCSC 全通过**时为自己并不拥有的权威签发完美合规的证书：它不是错误地认识世界，而是**正确地认识世界、却错误地相信自己的身体**，然后自信地停不下来。

次级风险与缓解：
1. **权威自证循环** → 环路外独立测量 + **硬件权威地板**（机械限扭/离合/柔顺罩）+ 第三方 SEAL-Actuator。
2. **人类模型失配** → 默认最保守包络；`h=unknown` 禁用共享负载；SEAL-HRI 分层校准。
3. **摩擦/回差激励依赖** → 探针预算独立于安全预算；不可辨识即取上界。
4. **过保守冻结机器人** → 权威地板外允许降级有用模式（慢速/柔顺/有限行程）；报告吞吐。
5. **ISO/TS 15066 阈值误用** → 阈值作为显式可审计契约字段；`J_HRI` 拒绝错误绑定。
6. **热/磨损长尾漂移** → E409 长时程；自适应权威预算；硬件热保护独立于软件。
7. **MBench 过拟合/Goodhart** → MB4–MB6 预注册 + 密封保持集 + 三方复现；信任只作次要指标。
