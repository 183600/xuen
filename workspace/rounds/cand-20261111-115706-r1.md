# 第 55 轮（承接第 54 轮 v16+++ GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「多机协同」×「并发推理」）

> 第 54 轮把技能组合推进到动作空间剖面 `α_S`、组合图 `G_S`、云边映射 `γ_ce` 与联合证书 `J`。本轮处理两个新矛盾：**H22**：多个执行体（机器人或推理 worker）在同一共享动作空间上并发推进时，“各自正确”不等于“联合可行”；**H23**：并发推理的 K 个分支可以高度一致却共同错误，**共识不是正确性**。核心转向：从“单执行体的证书”升级为“**动作事务 + 所有权租约 + 独立证据**”的三重协同。

## 0. 直觉与动机

**灵感 1（先把“机”拆成执行体，统一物理机器与推理节点）**
直觉：多机协同的“机”在 UniBot 场景里至少有两层——物理机器人（G1 集群、双臂、多工位）与推理 worker（多 GPU、多模型副本、云端/边端）。二者共享同一个抽象：它们都在**并发地写一个共享工作区**。因此先定义执行体 `e ∈ E = R ∪ W`，协同的第一性不是“通信带宽”，而是“**对共享变量的写权**”。通信只是获取写权的手段。

**灵感 2（并发推理 = 动作级投机执行，而不是 token 级并行）**
直觉：传统 VLA 每个控制周期只做一次前向；并发推理同时展开 K 条动作假设（不同技能 token、不同 chunk 长度、不同采样温度），然后在**动作空间**而不是 token 空间做仲裁。关键是把一个动作块（action chunk）看成**可回滚的事务**，而不是不可逆命令：先投机提交一个短块，在回滚窗口内校验，失败就 abort。

**灵感 3（多机协同 = 共享动作空间上的事务并发控制）**
直觉：把每个执行体的短时计划看成对共享工作区 `X` 的事务：读集 `R_e`（物体位姿、占用栅格、他人意图），写集 `W_e`（抓取、放置、占用、交接）。两个事务冲突，当且仅当它们的写集在时间窗内重叠。用**所有权锁 + 租约**保证安全，用**乐观并发控制（OCC）**在非关键区保活力——这正是数据库的“隔离级别”思想迁移到物理动作空间。

**灵感 4（共识不是正确性：一致地错）**
直觉：K 个分支若共享同一个底座模型、同一份上下文、同一个仿真器，它们的误差是**相关**的。分支越多，方差越小、共识越“自信”，但共同偏差不变。形式化：共享偏差 `b` 下，共识误差下界约为 `||b|| - O(σ/√K_eff)`；当 `||b|| > ε_spec` 时，`K→∞` 只会让成功率趋近 0，而分支间一致性趋近 1。故必须引入**有效独立证据数 `K_eff`** 与外部校验，而不是盲目加分支。

**灵感 5（并发协同金字塔：在动作-鲁棒性双证书上再加一层）**
直觉：第 54 轮的金字塔是“鲁棒性 `ρ` × 动作空间 `A`”。本轮叠加并发协同层 `ℂ`：`ℂ_0` 物理互斥（碰撞/占用），`ℂ_1` 动作事务（读写集/提交），`ℂ_2` 所有权租约（单写者/失效接管），`ℂ_3` 并发推理共识（K 分支/证据独立性），`ℂ_4` 任务级协同（分工/交接）。跨层证书从 `J` 升级为 `J_E = ({J_e}, {S_e}, M, ρ^E)`。

## 1. 形式化定义（增量：定义 121–128）

**定义 121（执行体与共享动作空间）**
执行体集合 `E = R ∪ W`，`R` 为物理机器人，`W` 为推理 worker。共享状态 `X = (poses, occupancy, grasp_owner, intents)`。执行体 `e` 的局部动作空间 `A_e`，联合动作空间
`A^E_⊥ = {(a_e)_{e∈E} ∈ ∏_e A_e : ¬(a_i ⊥ a_j), i≠j}`，其中 `⊥` 为定义 123 的冲突关系。技能动作剖面 `α_e` 沿用定义 115。

**定义 122（动作事务）**
执行体 `e` 的动作事务 `T_e = (R_e, W_e, H_e, ξ_e)`：
- `R_e, W_e ⊆ X` 为读集与写集；`H_e` 为提交视野（未来控制步数）；
- `ξ_e = a_{t:t+H_e}` 为动作块；
- `commit(T_e)` 原子地在 `[t, t+H_e)` 内保留 `W_e`，`abort(T_e)` 释放保留并可回滚到上一个已提交块。
事务状态 `s(T_e) ∈ {speculating, committed, aborted}`。

**定义 123（冲突图与可串行化）**
两个事务冲突记 `T_i ⊥ T_j`，当且仅当
```
W_i ∩ (R_j ∪ W_j) ≠ ∅  ∨  W_j ∩ (R_i ∪ W_i) ≠ ∅
```
且提交视野重叠。冲突图 `G_conf = (V_T, E_conf)`，`(T_i,T_j) ∈ E_conf` 当 `T_i ⊥ T_j`，方向由全局提交序给出。已提交历史 `H` **冲突可串行化**当且仅当 `G_conf` 无环。物理干涉事件 `I` 定义为存在两个已提交事务在重叠视野内写同一变量。

**定义 124（并发投机与约束共识）**
K 个分支并行提出动作块 `ξ_b ~ π(· | o_t, s_b)`，权重 `w_b`。安全交集
`A_safe = ⋂_b A_core,b ∩ {a : α(a) ≥ θ_cov}`。共识动作
```
a* = argmin_{a ∈ A_safe} Σ_b w_b · d(a, ξ_b)
D  = Σ_b w_b · d(a*, ξ_b)
```
`d` 为 SE(3)/关节空间上的度量。投机证书 `S = (K, {ξ_b}, {w_b}, D, H, verifier)`。**有效独立证据数**
`K_eff = (Σ_b w_b)² / Σ_b w_b²`（Kish 有效样本量）。若分支共享偏差 `b`、独立噪声方差 `σ²`，则
```
E[||a* - a_true||] ≥ ||b|| - c·σ/√K_eff
```
即偏差给出不可由加分支消除的地板。

**定义 125（所有权与租约）**
所有权映射 `O : X_shared → E ∪ {⊥}`；租约 `L : X_shared → (owner, expiry)`。**安全不变式**：对任意 `x ∈ X_shared`，至多存在一个未过期租约。执行体只有在持有 `x` 的有效租约时才能写 `x`。租约可续租；到期后任何合格执行体可接管（takeover）。

**定义 126（并发协同证书）**
`M = (O, G_conf, C_cons, δ_sync, L)`：
- `O` 为所有权映射；`C_cons` 为共享目标共识（物体→目标、交接点、时序相位）；
- `G_conf` 为冲突图；`δ_sync` 为时钟偏移上界；
- `Valid(M) = 1` 当且仅当：(i) `G_conf` 无环；(ii) 任意 `x` 的租约互斥；(iii) `O` 在写集上单值；(iv) `δ_sync ≤ Θ_s`。

**定义 127（多执行体并发联合证书）**
```
J_E = ({J_e}_{e∈E}, {S_e}_{e∈E}, M, ρ^E, evidence)
```
可部署条件：
```
∀e: dom(J_e)=in ∧ D_e ≤ ε_spec ∧ K_eff,e ≥ κ_min
∧ Valid(M) ∧ σ_e ≤ τ_stale
```
其中 `J_e` 为第 54 轮联合证书，`σ_e` 为推理陈旧度，`ρ^E` 为定义 128 的并发鲁棒性谱。

**定义 128（并发退化谱与降级路由）**
`ρ^E : D → [0,1]`，维度 `D = {delay, loss, skew, failure, contention, staleness}`。降级路由 `δ_route`：若 `ρ^E(d) < ρ_min` 或 `Valid(M)=0`，则按 `E → E\{e} →` 单写者锁 `→` 单分支推理逐级退化。**优雅退化**要求
```
ρ^{E\{e}}(d) ≥ ρ^E(d) - Δ_fail
```
即失去一个执行体的性能跌落有上界。

## 2. 关键算法 伪代码

### IP-121 CSP（Concurrent Speculative Planner）

```python
def concurrent_speculate(obs, skills, K, eps_spec, kappa_min):
    branches = [async_run(worker_b, obs, skills[b % len(skills)])
                for b in range(K)]
    chunks = gather_with_deadline(branches, tau_stale)
    weights = [calibrated_weight(c, obs) for c in chunks]
    k_eff = (sum(weights)**2) / sum(w*w for w in weights)
    if k_eff < kappa_min:
        return ('reject', 'insufficient_independent_evidence', k_eff)
    a_star = constrained_geometric_median(chunks, weights, A_safe)
    D = sum(w * dist(a_star, c) for w, c in zip(weights, chunks))
    if D > eps_spec or not verifier(a_star, obs):
        return ('reject', 'consensus_or_verifier', D)
    return ('ok', SpecCert(K, chunks, weights, D, H, verifier))
```

### IP-122 ATC（Action Transaction Coordinator）

```python
def commit_transaction(T, O, L, G_conf):
    # 1) 只写自己持租约的变量；关键变量强制加锁
    for x in T.W:
        if is_critical(x) and not holds_valid_lease(L, T.e, x):
            if not try_acquire_lease(L, T.e, x, ttl=lease_ttl(x)):
                return ('abort', 'lock_busy', x)
    # 2) OCC 校验读集
    if any(version(x) != T.read_version[x] for x in T.R):
        release_new_leases(T); return ('abort', 'read_conflict')
    # 3) 全局序提交，避免环
    for x in sorted(T.W, key=object_rank):
        write_reservation(x, T.e, T.H)
    G_conf.add_transaction(T)
    if has_cycle(G_conf):
        rollback(T); G_conf.remove(T)
        return ('abort', 'serialization_cycle')
    return ('commit', T)
```

### IP-123 MLP（Multi-Executor Lease Planner）

```python
def coordinate(plan, E, X):
    O, L = assign_ownership(plan, X)          # 物体/区域→执行体
    C_cons = consensus_goals(plan, E)         # 交接点、目标位姿
    G_conf = build_conflict_graph(plan, O, L)
    for layer in topological_layers(G_conf):
        barrier_sync(E, skew=delta_sync)      # 每层同步一次
        for T in layer:
            ATC.commit_transaction(T, O, L, G_conf)
    return M = (O, G_conf, C_cons, delta_sync, L)
```

### IP-124 CJC（Concurrent Joint Certifier）

```python
def certify_joint(executors, plan):
    Js, Ss = [e.joint_cert for e in executors], [e.spec_cert for e in executors]
    M = plan.M
    if not Valid(M): return ('reject', 'coordination_invalid', M)
    if any(s.D > eps_spec for s in Ss):
        return ('reject', 'divergence', [s.D for s in Ss])
    if any(s.k_eff < kappa_min for s in Ss):
        return ('reject', 'correlated_evidence')
    rho = compose_concurrent_robustness(executors, plan)
    return ('ok', JointCertMulti(Js, Ss, M, rho, evidence=plan.log))
```

### IP-125 DRR（Degradation Router）

```python
def route(state):
    rho = state.rho_E
    if Valid(state.M) and rho['failure'] >= rho_min:
        return 'full'
    if state.delay > tau_sync or state.skew > Theta_s:
        return 'single_writer_lock'
    if state.k_eff < kappa_min or state.staleness > tau_stale:
        return 'single_branch'
    return 'n_minus_1'
```

### IP-126 CCF（Consensus-Constrained Fusion）

```python
def constrained_geometric_median(chunks, weights, A_safe):
    a = weighted_median(chunks, weights)
    for _ in range(max_iter):
        a = project_to_safe(a, A_safe)        # 投影到动作安全交集
        a = weiszfeld_update(a, chunks, weights)
        if converged(a): break
    return a
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| CSP | O(K·|A_chunk| + K·log K) | O(K·|A_chunk|) | `K_eff` 独立证据、验证器独立 |
| ATC | O(|W| log |X| + |E_conf|) | O(|T|+|E_conf|) | 租约互斥、读集版本一致 |
| MLP | O(|T|·|X| + |E_conf|) | O(|T|+|X|) | 拓扑层同步、全局序无环 |
| CJC | O(|E|·(|J|+|S|)) | O(|E|·|X|) | 联合证书 sound、退化谱单调 |
| DRR | O(|D|) | O(1) | 路由阈值与滞回 |

**命题 1（一致不等于正确 / Agreement–Correctness Gap）**
在定义 124 的共享偏差模型下，当 `K → ∞`，分支间离散度 `D/K → 0`（一致性趋于 1），但 `E[a*] → a_true + b`。若 `||b|| > ε_spec`，则成功率 `→ 0` 而一致性 `→ 1`。**因此分支数 K 不是正确性的有效变量，`K_eff` 与独立验证才是。**

**定理 1（租约安全性与通信延迟无关）**
若每个写变量都被一个未过期且互斥的租约覆盖，则无论通信延迟、丢包、时钟偏移如何，`G_conf` 中不会出现两个已提交事务写同一变量的边，物理干涉事件 `I` 不发生。安全性由单写者租约保证，**不依赖共识及时到达**。

**定理 2（有限租约下的活性）**
若每个待写变量至少有一个合格且存活的执行体，租约时长 `λ < ∞`，且接管规则公平，则每个未 abort 的事务在至多 `λ + τ_takeover` 内被提交或由新所有者重提；单执行体故障不导致永久停滞。**活性由“租约到期 + 接管”保证，而不是由乐观执行保证。**

**复合成功界**
假设第 54 轮 (A26)–(A28) 与 (A29) 分支校准、(A30) 租约单写者、(A31) 动态 Lipschitz 常数 `L`、(A32) 冲突图无环，则
```
P_success ≥ 1 - Σ_e (1-ρ_e(d)) - P(D>ε_spec) - P(K_eff<κ_min)
            - P(cycle) - L·τ_stale - P(lease_violation)
```
注意最后一项在定理 1 下为 0，这正是把“共识”换成“租约”的收益。

## 4. 实验设计与本轮机理仿真

| 实验 | 指标 | 目标 |
|---|---|---|
| E162 并发分支 K vs 成功率 | 成功率、分支一致性、P95 时延 | 揭示“一致但错”，验证 `K_eff` 门槛 |
| E163 多执行体冲突 | 干涉率、makespan、stall 率 | 租约零干涉，故障下 lease 可恢复 |
| E164 陈旧度 `σ` | 成功率 vs `σ`，有无速度补偿 | 给出 `τ_stale` 与 `L` 的标定方法 |
| E165 真机/多 worker 集成 | UniBot 任务成功率、干涉率、尾延迟 | 相对 v16+++ 提升 ≥ 10%，零物理干涉 |
| E166 降级路由 | 故障/断连下的保留率 | 优雅退化 `Δ_fail ≤ 8%` |

本轮先做**机理仿真**（非 G1 实机，纯 Python，固定随机种子，用于证伪而非刷榜）：

- **E162（K=1..16，共享偏差 b=0.35，噪声 σ=0.5，容差 0.25，2 万次）**：成功率 30.4% / 34.2% / 33.9% / 28.3% / 20.4%，分支一致性 100% / 51.9% / 19.7% / 4.3% / 0.2%。**K 增大后一致性单调上升，成功率反而下降**——共识收敛到共同偏差 `b`，与命题 1 一致。
- **E163（4 执行体、24 物体、300 次）**：无故障时 parallel / OCC / 硬租约的干涉率为 11.6% / 10.2% / 0%，makespan 为 13.15 / 13.17 / 12.06 步。加入“`t=3` 时 0 号执行体失效”后：parallel 15.86 步、干涉 7.0%；OCC 15.82 步、干涉 6.3%；**硬租约 100% 停滞**；**带 3 步租约的接管 15.77 步、干涉 0%**。这直接验证定理 1（安全）与定理 2（活性需租约到期）。
- **E164（速度 v~U[0,1.5]、容差 0.2、2 万次）**：陈旧度 `σ=0/1/2/4/8` 时，原始动作块成功率 100% / 13.1% / 6.4% / 3.4% / 1.6%；常速度补偿后 100% / 100% / 50.8% / 12.8% / 3.1%。说明 `τ_stale` 必须与动态 Lipschitz 常数联合标定，不能只看推理延迟。

> 这些是**机理级证据**，用于证明“共识≠正确、锁≠活性、陈旧≠可忽略”三件事；真机与 UniBot 榜单验证留待 E165/E166。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 分支共享偏差导致“一致地错” | 高 | `K_eff` 门槛 + 异构底座/不同观测 + 独立验证器 |
| 乐观提交在延迟下漏检冲突 | 高 | 关键变量强制租约 + 全局序提交 + 失败回滚 |
| 硬锁在单点故障下停滞 | 高 | 有限租约 + 公平接管 + 降级路由 |
| 陈旧动作块导致控制震荡 | 高 | `τ_stale` 标定 + 速度/世界模型补偿 + chunk 截断 |
| 租约续租风暴 / 活锁 | 中 | 指数退避 + 优先级 + 全局 object rank |
| 并发推理算力不可承受 | 中 | 分支剪枝 + 早停 + 云端批处理 + 边端只跑验证 |

## 6. 本轮最大风险

**一句话**：本轮把协同从“共识”改为“事务 + 租约 + 独立证据”，其 soundness 的真正支点是**租约的单写者不变式与 `K_eff` 的独立性**；一旦把并发分支的高一致性误当作高正确性、或在延迟/分区下让乐观提交绕过关键变量租约，系统就会以“零告警的一致”撞上不可逆的物理冲突（两只手同时抓同一物体），因此宁可牺牲部分并行度也要守住**关键变量硬锁 + 有限租约接管 + 独立验证**三条底线。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-MultiCon（CSP×ATC×MLP×CJC×DRR×CCF）

> 承接第 54 轮产物 v31。本轮在“动作空间剖面 + 组合图 + 云边协同 + 联合证书”之上，加入**多执行体并发协同层**：
> - **CSP（Concurrent Speculative Planner）**：动作级并发投机推理，K 分支 + 约束共识 + `K_eff` 门槛；
> - **ATC（Action Transaction Coordinator）**：把动作块建模为事务，租约锁 + OCC + 全局序提交；
> - **MLP（Multi-Executor Lease Planner）**：多机/多 worker 的所有权分配、冲突图与分层同步；
> - **CJC（Concurrent Joint Certifier）**：多执行体联合证书 `J_E`，同时校验 `ρ`、动作、共识与事务；
> - **DRR（Degradation Router）**：故障/延迟/陈旧下的逐级降级；
> - **CCF（Consensus-Constrained Fusion）**：安全交集上的加权几何中位数融合。
>
> IP 编号：IP-121~IP-126（6 个新增），升级 IP-117（CEC）、IP-118（AEC）、IP-120（JTC）以纳入并发维度。
> 核心负结果：**分支一致性不是正确性**；核心工程结论：**安全靠租约，活性靠租约到期，不靠共识及时到达**。

## 0. 核心 IP 设计

## 2. 关键算法 伪代码

### IP-121 CSP：动作级并发投机

```python
def concurrent_speculate(obs, skills, K, eps_spec, kappa_min, tau_stale):
    branches = [async_run(worker_b, obs, skills[b % len(skills)])
                for b in range(K)]
    chunks = gather_with_deadline(branches, tau_stale)   # 迟到分支丢弃
    weights = [calibrated_weight(c, obs) for c in chunks]
    k_eff = (sum(weights)**2) / sum(w*w for w in weights)
    if k_eff < kappa_min:
        return ('reject', 'insufficient_independent_evidence', k_eff)
    a_star = constrained_geometric_median(chunks, weights, A_safe(obs))
    D = sum(w * dist(a_star, c) for w, c in zip(weights, chunks))
    if D > eps_spec or not independent_verifier(a_star, obs):
        return ('reject', 'consensus_or_verifier', D)
    return ('ok', SpecCert(K, chunks, weights, D, H, k_eff))
```

### IP-122 ATC：动作事务提交

```python
def commit_transaction(T, O, L, G_conf):
    acquired = []
    for x in T.W:
        if is_critical(x) and not holds_valid_lease(L, T.e, x):
            if not try_acquire_lease(L, T.e, x, ttl=lease_ttl(x)):
                return ('abort', 'lock_busy', x)
            acquired.append(x)
    if any(version(x) != T.read_version[x] for x in T.R):
        release(L, acquired); return ('abort', 'read_conflict')
    for x in sorted(T.W, key=object_rank):       # 全局序，避免环
        write_reservation(x, T.e, T.H)
    G_conf.add_transaction(T)
    if has_cycle(G_conf):
        rollback(T); G_conf.remove(T); release(L, acquired)
        return ('abort', 'serialization_cycle')
    return ('commit', T)
```

### IP-123 MLP：多执行体租约规划

```python
def coordinate(plan, E, X, delta_sync):
    O, L = assign_ownership(plan, X)              # 物体/区域→执行体
    C_cons = consensus_goals(plan, E)             # 交接点/目标位姿/相位
    G_conf = build_conflict_graph(plan, O, L)
    for layer in topological_layers(G_conf):
        barrier_sync(E, skew=delta_sync)
        for T in layer:
            commit_transaction(T, O, L, G_conf)
    return M = (O, G_conf, C_cons, delta_sync, L)
```

### IP-124 CJC：并发联合证书

```python
def certify_joint(executors, plan, rho_min, eps_spec, kappa_min, tau_stale):
    Js = [e.joint_cert for e in executors]
    Ss = [e.spec_cert for e in executors]
    M  = plan.M
    if not Valid(M):                       # 无环 + 租约互斥 + 单值 + 同步
        return ('reject', 'coordination_invalid', M)
    if any(s.D > eps_spec for s in Ss):
        return ('reject', 'divergence', [s.D for s in Ss])
    if any(s.k_eff < kappa_min for s in Ss):
        return ('reject', 'correlated_evidence')
    if any(e.staleness > tau_stale for e in executors):
        return ('reject', 'stale_action')
    rho = compose_concurrent_robustness(executors, plan)
    if min(rho.values()) < rho_min:
        return ('reject', 'robustness_fail', rho)
    return ('ok', JointCertMulti(Js, Ss, M, rho, evidence=plan.log))
```

### IP-125 DRR：降级路由

```python
def route(state):
    if Valid(state.M) and state.rho_E['failure'] >= rho_min:
        return 'full'
    if state.delay > tau_sync or state.skew > Theta_s:
        return 'single_writer_lock'
```

### IP-126 CCF：约束共识融合

```python
def constrained_geometric_median(chunks, weights, A_safe):
    a = weighted_median(chunks, weights)
    for _ in range(max_iter):
        a = project_to_safe(a, A_safe)
        a = weiszfeld_update(a, chunks, weights)
        if converged(a): break
    return a
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CSP | O(K·|A_chunk| + K log K) | O(K·|A_chunk|) | `K_eff` 独立证据；验证器与模型解耦 |
| ATC | O(|W| log |X| + |E_conf|) | O(|T|+|E_conf|) | 租约互斥；读集版本；全局序无环 |
| MLP | O(|T|·|X| + |E_conf|) | O(|T|+|X|) | 拓扑层 barrier；所有权单值 |
| CJC | O(|E|·(|J|+|S|)) | O(|E|·|X|) | 四联证书 sound；退化谱单调 |
| DRR | O(|D|) | O(1) | 阈值 + 滞回，无震荡 |

**命题 1（Agreement–Correctness Gap）**
共享偏差 `b`、独立噪声 `σ` 下，`K→∞` 时分支一致性 `→1`，但 `E[a*]→a_true+b`；若 `||b||>ε_spec`，成功率 `→0`。故 **K 不是正确性的有效变量，`K_eff` 与独立验证才是**。

**定理 1（Lease Safety，延迟无关）**
若每个写变量均被未过期且互斥的租约覆盖，则任何通信延迟/丢包/时钟偏移下，两个已提交事务都不写同一变量，物理干涉 `I` 不发生。

**定理 2（Lease Liveness，故障可恢复）**
若每个待写变量至少有一个合格存活执行体、租约时长 `λ<∞`、接管公平，则未 abort 的事务在至多 `λ+τ_takeover` 内提交或被重提；单执行体故障不导致永久停滞。

**复合成功界**
在 (A26)–(A32) 下：
```
P_success ≥ 1 - Σ_e(1-ρ_e(d)) - P(D>ε_spec) - P(K_eff<κ_min)
            - P(cycle) - L·τ_stale - P(lease_violation)
```
定理 1 使 `P(lease_violation)=0`；代价是并行度下降，由 DRR 在非关键区恢复。

## 4. 本轮实验结果（机理仿真）

> **诚实声明**：以下为纯 Python 机理仿真（固定种子 20261111；非 G1 实机、非 UniBot 榜单）。目的不是 SOTA，而是证伪三个危险直觉：共识即正确、锁即安全、陈旧可忽略。

### E162 并发分支：一致性上升，成功率不升反降

设置：共享偏差 `b=0.35`、独立噪声 `σ=0.5`、容差 `0.25`、2 万次/组。

| K | 成功率 | 分支一致性 | 平均离散度 |
|---:|---:|---:|---:|
| 1 | 30.4% | 100% | 0.000 |
| 2 | 34.2% | 51.9% | 0.281 |
| 4 | 33.9% | 19.7% | 0.398 |
| 8 | 28.3% | 4.3% | 0.452 |
| 16 | 20.4% | 0.2% | 0.476 |

读法：`K` 增大使共识收敛到共同偏差 `b`（>容差），故**一致性趋 1、成功率趋 0**。这正是 `K_eff` 门槛与独立验证器存在的理由。

### E163 多执行体：租约零干涉，但硬锁在故障下停滞

设置：4 执行体、24 物体、随机工作量 {1,2,3}、每物体至少 2 个合格执行体、300 次/组。

无故障：

| 协议 | 干涉率 | makespan |
|---|---:|---:|
| parallel | 11.6% | 13.15 步 |
| OCC（延迟 0） | 10.2% | 13.17 步 |
| 硬租约 | **0%** | **12.06 步** |

`t=3` 时 0 号执行体失效：

| 协议 | 干涉率 | makespan | 停滞率 |
|---|---:|---:|---:|
| parallel | 7.0% | 15.86 步 | 0% |
| OCC（延迟 2） | 6.3% | 15.82 步 | 0% |
| 硬租约（无接管） | 0% | 300 步（上限） | **100%** |
| 租约 3 步 + 接管 | **0%** | 15.77 步 | 0% |

读法：**安全 = 租约单写者（定理 1）；活性 = 租约到期 + 接管（定理 2）**。只加锁不设租约，会把“零冲突”变成“零进展”。

### E164 陈旧动作块：延迟必须与动态 Lipschitz 联合标定

设置：速度 `v~U[0,1.5]`、容差 `0.2`、2 万次/组；`σ` 为观测陈旧步数。

| 陈旧度 σ | 原始动作块成功率 | 常速度补偿后 |
|---:|---:|---:|
| 0 | 100% | 100% |
| 1 | 13.1% | **100%** |
| 2 | 6.4% | **50.8%** |
| 4 | 3.4% | 12.8% |
| 8 | 1.6% | 3.1% |

读法：`τ_stale` 不能只按推理延迟设；必须满足 `L·τ_stale ≤ 容差`，否则并发推理的“快”会被陈旧动作的“错”吃掉。

## 6. 本轮最大风险

**一句话**：本轮把协同从“共识”改为“事务 + 租约 + 独立证据”，其 soundness 的真正支点是**租约单写者不变式与 `K_eff` 的独立性**；一旦把并发分支的高一致性误当作高正确性、或在延迟/分区下让乐观提交绕过关键变量租约，系统就会以“零告警的一致”撞上不可逆的物理冲突（两只手同时抓同一物体），因此宁可牺牲部分并行度也要守住**关键变量硬锁 + 有限租约接管 + 独立验证**三条底线。
