# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「用户测试」×「实时控制」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**人因可测 + 实时可证**。两个灵感各治 v9 的一笔债：**人因债**——ACMD 的"安全""可解释""降算力"全部是机器内部指标，从未有一名真人验证，"指标之声"从未被校准；**时序债**——MW 的逐周期硬截止把瞬时过载放大成"退化风暴"，而 AC 块生成一旦超时只能黯然退回 K=1、白白丢弃已算出的候选。必须用**人在环契约**与**(m,k)-弱硬实时**把"人"和"时间"升为一等公民，同时保持严格退化到 v9。

## 0. 直觉与动机

**灵感 1（用户测试 → 感知对齐证书与可测试性）**
直觉：MetricVoiceGauge 一路在"把指标说出来"，却从没有人验证这些话说到人耳里是否还有意义。用户测试不该是论文末尾一张 SUS 表，而应是**校准信号**：它回答"内部风险度量 g_int 与人感知风险 g_human 是否同序"。核心创新：**用户测试探针（UserTestHarness, UTH）+ 感知对齐证书（PerceptualAlignmentCertificate, PAC）**。关键安全设计：探针 φ^elig=false、WCET ≤0.1ms、只在块边界做带外采样，超时/失效注入"无探针"中立元（对控制与日志同时恒等）——观测不改变被观测，即 **P15 用户测试非侵入律**。附带产出：IP 清单里每条主张都配一份**可测试性契约**（指标、因子、样本量、随机化、预注册阈值），把"创新点"从叙事变成可证伪的实验单元。

但"测人"自带时间常数：接管延迟、注意力、信任都是分布而非标量，且重尾。于是用户测试的第二产物不是评分，而是**人在环契约（HumanContract, HCC）**：人作为一个可调度的实时模块，其截止期由实测反应分位数给出，其失效中立元是"让权给自主安全策略"。

**灵感 2（实时控制 → 弱硬实时与任意时间证书）**
直觉：v9 把"错过截止期"一律判为模块失效，这是**用二值化吃掉时序信息**——真实系统里"偶尔错过一次"往往无害，真正致命的是**成簇、相关**的错过。实时控制早就有更好的词：**弱硬实时 (m,k)-firm**——允许少量错过，但保证任意 k 个连续决策周期内至少 m 个按时。核心创新：**弱硬实时调度器（WeaklyHardScheduler, WHS）**：把退化从逐周期二元事件，变成**失配模式上的稳定性条件**（失配密度低于控制收缩裕度才安全，否则逐级退化）。配套**任意时间块证书（AnytimeCertificate）**：块生成被时间预算截断时，返回前缀子块的有效证书，而不是退回 K=1——利用证书的**前缀单调性**（少看几步只会更保守）。

灵感 2 的另一半是人的实时性：解释/请求确认若不能在人的**行动截止期**前到达，等于没解释。**解释预算调度器（ExplanationBudgetScheduler, EBS）**按 anytime 解释格出牌：最小时释立刻出，细化随剩余预算追加；预算耗尽则停在已出的最细层（永不空白）。

## 1. 研究问题（轮次升级版）

- **Q1（人因可测且非侵入）**：如何让在线用户测试在 50Hz 控制环里既收集到有统计效力的感知数据，又把探针效应 ε_probe 压到可忽略？PAC 在什么窗口/样本量下能同时拒绝"内部指标自嗨"与"被测者被探针带偏"？
- **Q2（人在环实时契约）**：如何定义 κ_h，使人的延迟/可靠性变异被与模块同一套中立元代数吸收，且接管-让权**无扰切换**（指令不跳变、安全不变式不破）？
- **Q3（弱硬实时稳定性）**：闭环在 (m,k)-firm 约束与零阶保持失配下，失配密度/簇长的可证稳定域是什么？任意时间截断是否严格保块证书有效，并在 K=1 时等价 v9？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 人在环契约律（Human-in-the-Loop Contract, HLC）**
人通道声明 κ_h=(In_h, Out_h, D_h(t), ρ_h(t), v_h^⊥, ℓ_h, ε_h)。D_h 取实测接管延迟的 1−δ 分位；ρ_h 为注意力/疲劳/校准的综合可靠性；v_h^⊥ = "让权自主安全策略"（等价 v9 全自主）；权限 a(t)∈[0,1] 连续混合、变化率受限 |ȧ|≤λ_a，接管时刻做**无扰投影**（自主目标 = 人最后安全指令在安全集上的投影）。人永远不能阻塞 φ^elig=false 的安全模块。

**P14 弱硬实时律（Weakly-Hard Real-Time, MK）**
每条关键决策链满足 (m,k)-firm：任意 k 个连续周期至少 m 个按时。失配模式 μ 落入控制亲和类 M(B_max, d_max)（簇长 ≤B_max、密度 ≤d_max）时闭环保持指数稳定；越类即触发下一级退化。调度仍为窗口内 EDF，硬安全模块保留逐周期硬截止。

**P15 用户测试非侵入律（Non-Intrusive User Testing, NUT）**
探针 φ^elig=false、Ŵ_probe≤0.1ms、只在块边界带外采样、无阻塞 I/O（lock-free 环形缓冲）；超时/失效注入"无探针"中立元（对控制/日志恒等）；条件分配仅在块边界、双盲、受试内平衡，且**绝不随机化安全模块**；探针效应 ε_probe 必须实测并 ≤ε_max。

## 3. 与基线的接口（如何退化）

- UTH/EBS 失效 ⇒ 无探针、无解释（中立元 ≡ 恒等），等价 v9；
- HCC 失效 / 人超时 / ρ_h<ρ_min ⇒ v_h^⊥ 让权自主，a 指数衰减到 0，等价 v9 全自主路径；
- WHS 失效 ⇒ 逐周期硬截止，等价 v9 的 MW；
- (m,k) 越界 ⇒ 依次触发 v9 五级退化链（AC→MW→ID→DA/SPR/Cal→v7）；
- 任意时间截断到 K=1 ⇒ 逐步执行，严格等价 v9 fallback。

## 4. 预期贡献

1. **人在环实时契约**：人作为带分布截止期的一等调度模块，接管-让权无扰，失效严格退化为 v9 全自主；
2. **弱硬实时稳定性**：(m,k)-firm 下零阶保持失配的显式稳定域（引理 88），把退化风暴换成"密度受控的错过"；
3. **任意时间块证书**：前缀单调性（引理 89）让块生成超时只缩时域、不丢有效性，直接修补 v9 最大风险的一半；
4. **可测试的感知对齐**：PAC + 可测试性契约，让"指标之声"第一次被真人校准，且探针非侵入有界（命题 90）。

## 5. 本轮最大风险

**一句话**：用户测试的样本永远少、人永远异质，D_h 与 ρ_h 在冷启动和分布外新用户上会系统性偏乐观——若系统在最需要接管的紧急时刻，依据一个被高估可靠性的人的分位数放弃自主权，那么"人在环契约"恰恰会把安全责任交给最不可靠的那个环节。

**新增定义 540（人在环契约 HumanContract）** 人通道声明 κ_h=(In_h, Out_h, D_h(t), ρ_h(t), v_h^⊥, ℓ_h, ε_h)。In_h={confirm, takeover, explain}×ctx；Out_h=U∪{⊥}；D_h 由定义 541 给出；ρ_h∈[0,1] 综合注意力/疲劳/校准；v_h^⊥ 为"让权自主安全策略"；ℓ_h 为解释载荷（定义 543）；ε_h 为信任校准容差。调度：人在环请求以 D_h 为截止期进入 MW，可抢占低优先级计算模块；但 M₀/SpatialCert/FaultCert 的硬截止绝对不可被抢占（优先级 ∞）。

**新增定义 541（接管延迟分布 TakeoverLatency）** 按用户 u 的经验分布 T_takeover ~ F_u。在对数空间估计以吸收重尾：ℓ=log T，以 EWMA 维护均值/方差，D_h(t)=min(D_task, exp(q_{1−δ}(ℓ)))。冷启动用群体先验 F_0；积累 n_min=5 次样本后才个性化。同时报告 q_0.95 与变异系数 CV，避免单点估计掩盖重尾。

**新增定义 542（权限混合与无扰切换 AuthorityBlending）** 目标权限 a*(t)=clip(σ(β_0+β_1 u+β_2 ρ_h+β_3 r), 0, 1)，其中 u 为紧迫度、r 为人就绪度；实际权限按速率限制演进：
```
a(t) = a(t−dt) + clip(a*(t) − a(t−dt), ±λ_a·dt, 0, 1)
```
人超时则 a ← a·e^{−Δt/τ_a} → 0（等价 v_h^⊥）。指令合成 u(t)=a·u_h^{proj}+(1−a)·u_auto；接管起点做无扰投影 u_h^{proj}=Proj_{U_safe}(u_h)，且把 u_auto 初始化为 u_h^{proj}，保证切换时刻指令连续（引理 87）。

**新增定义 543（任意时间解释格 ExplanationLattice）** 对请求类型 kind，E_kind=(E_0⊑E_1⊑…⊑E_L)，每层 E_i=(内容, WCET_i, info_i)，info 单调不减、WCET 单调不减。最小充分解释 E*=argmin_i{wcet_i : correct(human|E_i) ≥ θ_dec}（用用户测试标定）。预算 b=D_h−τ_now−τ_human(kind)；EBS 从 E_0 起按序渲染，仅当 WCET 落入剩余预算才升级；预算耗尽则停在已出的最细层。若连 E_0 都放不下 ⇒ 静默（≡ v9 无解释）。

**新增定义 544（感知对齐证书 PerceptualAlignmentCertificate, PAC）** 在窗口 W 内收集 n 组匹配的 (g_int, g_human)，g_human 为人对风险的 1–5 评分（来自双盲条件）。令 ρ_s 为 Spearman 相关、MAE 为归一化后的平均绝对偏差：
```
PAC 有效 ⇔ n ≥ n_min ∧ ρ_s 的 bootstrap 下界 ≥ ρ_min ∧ MAE ≤ ε_max
```
PAC 无效**只**触发指标层重校准（OTL/Cal 的阈值与权重），不得改动 φ^elig=false 的安全模块。

**新增定义 545（(m,k)-firm 弱硬实时 WeaklyHardConstraint）** 对关键决策链 c，任意 k 个连续决策周期内按时数 ≥ m。(m,k)=(k,k) 退化为硬实时；(1,k) 为最弱。记失配密度 d=1−m/k。窗口内 EDF，窗口外由 WHS 记账并审计。

**新增定义 546（失配模式与控制亲和类 MissPattern）** μ∈{0,1}^ℕ，1 表示失配。密度 d(μ)=limsup_n (1/n)Σ_{i≤n}μ_i；簇长 B(μ)=最长连续 1 段。控制亲和类 M(B_max,d_max)={μ : B(μ)≤B_max ∧ d(μ)≤d_max}。引理 88 给出该类的指数稳定条件；实测 μ 越类即触发 Level-2 退化。

**新增定义 547（任意时间块证书 AnytimeCertificate）** 块生成在时间预算 τ 下运行，任意时刻被截断返回 ζ^τ=(a^{1:K(τ)}, Ĉ(τ), P(τ))，其中 K(τ) 随 τ 单调不减，且证书对**该时域**有效：
```
g_min(K) = min_{k≤K} ĝ_k ≥ d_safe,   e_max(K) = max_{k≤K} ê_k ≤ τ_eff,   P(K) ≠ ∅（K=1 时豁免）
```
前缀性质：valid(K) ⇒ valid(K′) 对所有 K′≤K 成立；K=1 时严格等于 v9 的单步 fallback。

**新增定义 548（探针预算与非侵入界 ProbeBudget）** Ŵ_probe≤0.1ms；探针仅在块边界、带外、lock-free 环形缓冲中写入。探针效应 ε_probe := sup_{匹配回合} |J_with−J_without|/|J_without|，要求 ≤ε_max=0.02。条件分配仅在块边界、双盲、受试内平衡（counterbalanced）；安全模块永不参与随机化。

**新增定义 549（可测试性契约 TestabilityContract）** 每条主张 c 映射到 π_c=(claim, metric, factor levels, N, randomization, stopping rule, preregistered threshold)。论文/清单中任何性能或体验主张若不携带 π_c，视为不可采信——把"创新点提炼"升级为"创新点可证伪"。

## 3. 关键算法骨架

# IP-357 UserTestHarness：用户测试探针 + 感知对齐证书
class UserTestHarness:
    def __init__(self, cap=1024, wcet_ms=0.1, rho_min=0.6,
                 mae_max=0.5, n_min=30):
        self.ring = LockFreeRing(cap)          # 带外，无阻塞
        self.wcet, self.t0 = wcet_ms, now_ms()
        self.rho_min, self.mae_max, self.n_min = rho_min, mae_max, n_min
        self.window = deque(maxlen=200)        # (g_int, g_human, cond, blind)

    def probe_at_boundary(self, chunk_idx, g_int, cond):
        if now_ms() - self.t0 > self.wcet:     # 自身守约，超时即 v^⊥
            return
        self.ring.push(Probe(chunk_idx, g_int, cond, t=now_ms()))

    def ingest_rating(self, g_human, cond, blinded=True):
        p = self.ring.pop_matched(cond)
        if p is not None:
            self.window.append((p.g_int, g_human, cond, blinded))

    def pac(self):
        xs = [(g_int, g_h) for (g_int, g_h, _, _) in self.window]
        if len(xs) < self.n_min:
            return PAC(valid=False, reason='n_min')
        rho_s = spearman(xs); mae = mean_abs(normalize(xs))
        lo, _ = bootstrap_ci(rho_s, B=1000)
        ok = (lo >= self.rho_min) and (mae <= self.mae_max)
        return PAC(ok, rho_s, mae, len(xs), lo)


# IP-358 HumanContractChannel：人在环契约
class HumanContractChannel:
    def __init__(self, prior, n_min=5, delta=0.05,
                 lam_a=2.0, tau_a=0.4, rho_min=0.6):
        self.log_lat = deque(maxlen=100)       # 实测接管延迟（对数）
        self.prior, self.n_min, self.delta = prior, n_min, delta
        self.lam_a, self.tau_a, self.rho_min = lam_a, tau_a, rho_min
        self.a, self.pending = 1.0, None

    def deadline(self):
        if len(self.log_lat) < self.n_min:     # 冷启动：群体先验（定义 541）
            return quantile(self.prior, 1 - self.delta)
        return math.exp(quantile(self.log_lat, 1 - self.delta))

    def request(self, kind, ctx):              # confirm / takeover / explain
        if self.a < 0.05 or ctx.rho_h < self.rho_min:
            return 'defer'                     # 已让权/人不可靠 → v_h^⊥
        self.pending = Request(kind, t0=now_ms(), D_h=self.deadline())
        self.ebs.emit(kind, budget=self.pending.D_h - human_cost(kind))
        return 'pending'

    def poll(self, now):
        if self.pending is None:
            return None
        if now - self.pending.t0 <= self.pending.D_h:
            return None
        self.log_lat.append(math.log(max(1e-3, now - self.pending.t0)))
        self.a *= math.exp(-(now - self.pending.t0) / self.tau_a)
        self.pending = None
        return 'defer'                         # 超时 ⇒ 让权自主

    def blend(self, u_h, u_auto, dt, ctx):
        a_star = clip(sigmoid(ctx.beta @ [1, ctx.urgency,
                                          ctx.rho_h, ctx.readiness]), 0, 1)
        self.a = clip(self.a + clip(a_star - self.a,
                                    -self.lam_a*dt, self.lam_a*dt), 0, 1)
        up = self.bumpless_project(u_h or u_auto)   # 无扰投影（定义 542）
        if self.a >= 1.0 - 1e-9:
            u_auto = up
        return self.a * up + (1 - self.a) * u_auto


# IP-359 ExplanationBudgetScheduler：任意时间解释
class ExplanationBudgetScheduler:
    def __init__(self, lattice):               # lattice[kind] = [E_0..E_L]
        self.lattice, self.last = lattice, None

    def emit(self, kind, budget_ms):
        self.last, t0 = None, now_ms()
        for e in self.lattice[kind]:           # 粗 → 细
            if now_ms() - t0 + e.wcet > budget_ms:
                break
            self.last = e
            e.render_nonblocking()
        if self.last is None:                  # 连 E_0 都放不下 ⇒ 静默
            return None
        return self.last


# IP-360 WeaklyHardScheduler：弱硬实时（定义 545/546）
class WeaklyHardScheduler:
    def __init__(self, m, k, B_max, d_max):
        self.m, self.k, self.B_max, self.d_max = m, k, B_max, d_max
        self.hist = deque(maxlen=k)            # 1=按时, 0=失配
        self.burst, self.held = 0, None

    def record(self, met):
        self.hist.append(1 if met else 0)
        self.burst = self.burst + 1 if not met else 0

    def violated(self):
        if len(self.hist) < self.k:
            return False
        return (sum(self.hist) < self.m) or (self.burst > self.B_max)

    def run_chain(self, chain, ctx):
        try:
            out = chain(ctx)                   # 内部即 v9 MW 的 EDF
            self.record(True)
            self.held = out
            return out
        except DeadlineOverrun:
            self.record(False)
            if self.violated():
                self.escalate()                # Level-2：退回逐周期硬截止
            return self.held or safe_hold(ctx) # 零阶保持（ZOH）


# IP-361 AnytimeChunkCertifier：任意时间块证书（继承 IP-354）
class AnytimeChunkCertifier(ActionChunkCertifier):
    def generate_anytime(self, state, budget_ms, trust_ok):
        t0, best = now_ms(), None
        if not trust_ok:
            return self._single_step_fallback(state)      # ≡ v9
        for cand in self.policy.sample_sequences(state, self.K_max, n=256):
            elapsed = now_ms() - t0
            if elapsed > budget_ms:
                break
            K = max(1, int(self.K_max * (elapsed / budget_ms)))
            pred = self.F.rollout(state, cand)            # 只预测前缀
            cert = self._prefix_cert(pred, K)             # 定义 547
            pts = self._abort_points_prefix(state, cand, pred, K)
            if cert.valid and (pts or K == 1):
                c = Chunk(cand[:K], cert, pts)
                if best is None or c.score > best.score:
                    best = c
        return best or self._single_step_fallback(state)  # K=1 ≡ v9 fallback

## 4. 推导

**引理 87（人在环退化与无扰切换）** (i) 若人在 D_h 内未响应或 ρ_h<ρ_min，注入 v_h^⊥ 后 a→0，合成指令 u=u_auto^safe，与 v9 全自主路径逐位一致（v9 无人类通道，故"缺席"即其原行为）。(ii) 权限 a 连续且 |ȧ|≤λ_a；接管起点将 u_auto 初始化为 u_h 的安全投影 u_h^{proj}，故切换瞬间 u 连续（若 u_h∈U_safe 则 u_h^{proj}=u_h，严格无跳变），切换后 u 的导数被 λ_a·‖u_h^{proj}−u_auto‖ 界住。(iii) 人通道不得抢占 φ^elig=false 模块，安全不变式由 v8/v9 引理 80–84 传递。∎

**引理 88（(m,k) 失配下的指数稳定性）** 设 x_{k+1}=A x_k+B u_k，A 为 Schur 阵且有诱导范数 ‖A‖=λ<1；按时周期上安全控制器给 V(x_{k+1})≤λV(x_k)，失配周期上零阶保持给 V(x_{k+1})≤(1+c)V(x_k)+b。若失配模式 μ∈M(B_max,d_max) 且每个 k 窗口满足
```
ρ_eff := λ^m · (1+c)^{k−m} < 1     ⇔     d := (k−m)/k < −ln λ / (ln(1+c) − ln λ)
```
则每 k 步 V(t+jk) ≤ ρ_eff^j V(t) + b/(1−ρ_eff)，闭环几何衰减；B_max 只影响瞬态常数而不进入乘积（簇状失配不被逐步抵消，故需 B_max 上限而非仅密度）。证明：对窗口内各步界连乘，m 次收缩与至多 k−m 次扩张；簇长界保证扩张不集中于单个 Lyapunov 增量之外。∎

**引理 89（任意时间证书前缀单调与 v9 等价）** 对 K′≤K：g_min(K′)=min_{i≤K′}ĝ_i ≥ min_{i≤K}ĝ_i=g_min(K)；e_max(K′)≤e_max(K)；停车不变式的剩余轨迹 |traj_{p:K′}|≤|traj_{p:K}|，故 p 在 K 下可行则必在 K′ 下可行，P(K′)⊇P(K)∩{≤K′}。于是 valid(K)⇒valid(K′)：截断只缩短时域、绝不产无效块。K=1 时直接走 v9 `_single_step_fallback`，逐位等价。∎

**命题 90（探针非侵入界，条件性）** 探针仅在块边界带外运行，其进入控制环的唯一成本为 Ŵ_probe。则探针效应对主指标的影响被预算扰动界住：ε_probe ≤ (Ŵ_probe/B_dec)·κ_sens + ε_sample，其中 κ_sens 为闭环对决策预算占用的敏感度。取 Ŵ_probe≤0.1ms、B_dec=20ms 得 ε_probe ≤ 0.005·κ_sens+ε_sample；双盲块级分配消除条件分配偏置。此为上界命题，由 E572 实测检验。∎

**命题 91（解释及时性，条件性）** 若 D_h 取 q_{1−δ}(T_takeover) 且 EBS 在 D_h−τ_human 前完成 E*，则在分布平稳假设下 P(人在截止期前行动)≥1−δ；分布漂移时界退化为 ≥1−δ−TV(F_est,F_true)。故用户测试须同时报告 TV 估计与延迟分布拟合（E574）。∎

**命题 92（信任校准，条件性）** 记 e_trust=|trust−capability|。PAC 有效（g_int 忠实于人风险感知）且 HCC 以 ρ_h 限制权限时，过信任事件（真实能力 <c_min 却 a>0）的频率被 ρ_h 高估频率界住；在 ρ_h 由实测 D_h 与探针校准共同估计时，E[e_trust]≤ε_h+O(√(log N/N))。此为经验命题，由 E586 验证，不作为安全证明。∎
