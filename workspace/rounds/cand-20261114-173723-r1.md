# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「事件相机」×「视觉-语言-动作模型」）

> R69 把不确定性一分为二，用「流匹配策略 + 主动多模态交互」去消解 epistemic：会看、会问、会触。但它有一个自陈的死穴——**所有关于「发生了什么」的判断，都来自学习模型**：流策略的多模态分布可能幻觉出不存在的模态，VLA/LLM 的语言描述可能是「看起来很合理」的胡话。R69 的最大风险正是「问错比不问更危险」。换句话说，R69 会求证，但**它求证的对象和它用来求证的工具，是同一批可能撒谎的模型**。
>
> 本轮两个灵感补上一个「非模型」的锚点：
> - **事件相机**给出物理世界的**变化事实层**——它不预测、不生成、不学习，只记录「哪一像素在何时、以何极性变了」。微秒延迟、高动态范围、几乎不受运动模糊影响。它是第一个**不是模型观点**的通道。
> - **视觉-语言-动作模型（VLA）**给出**语义假设**——它能用语言把场景说清楚（「杯子在滑」「门是虚掩的」「这块表面是软的」），但慢（100ms+），且它的语言输出是**声明**而非证据。
>
> 核心命题：**先用事件「看」、再用 VLA「想」、最后才向人「问」。** 把 VLA 的语言声明降格为可被事件检验的物理假设；用事件相机当幻觉裁决者、计算触发器与陈旧检测器；把 R69 的交互梯度（问 > 触 > 看）重排为（**看 ≪ 触 < 问**），让绝大多数 epistemic 不确定性在零社交成本的「看」阶段消解。命名 **PULSE-RAS**（Physically-grounded Uncertainty-gated Language-verified Sensorimotor Engine）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我理解的场景，真的在按我以为的方式发生吗**」——在相信任何模型之前，先看世界有没有真的动。

## 0. 直觉与动机

**灵感 1（事件相机 → 变化是世界的「事实层」）**
直觉：帧相机的每个像素记录「此刻有多亮」，是绝对量的快照；事件相机的每个像素记录「此刻亮度变化是否超过阈值」，是变化的时间戳。前者要先推断才知道「动没动」，后者直接就是「动了的证据」。事件在数学上近似 ∂_t log I 的过阈采样：不是对世界的解释，而是世界变化的原始印记。R69 的所有不确定性都从学习对象算出来（流模态、VLA 语言），因此都能被「模型幻觉」污染；事件通道是唯一一条**不经过策略、不经过语言、不经过生成**的旁路。它把「我怀疑」变成「我看过」。

**灵感 2（VLA → 把语言当「待检验的物理假设」，而不是结论）**
直觉：VLA 的强项是**语义**——它能把视觉与语言对齐，说出「这是可形变物体」「杯子正在被推」。但它的语言输出是一个**声明（claim）**，声明可以为真也可以为假。R69 只把 LLM 用来解码问句，浪费了 VLA 最强的能力：**用语言提出可证伪的假设**。若把每句声明投影成「期望的视觉变更签名」（哪些区域该有事件、事件率多少、极性/时序如何），那么事件相机就是一个**即时证伪器**：说了会动却没有任何事件 ⇒ 幻觉；没料到会动却事件爆发 ⇒ 计划已陈旧。VLA 负责「可能是什么」，事件负责「到底是不是」。

**灵感 3（语义-时间互补 → 三时间尺度栈）**
直觉：VLA **语义强、时间慢**（100ms 级、一次性大前向）；事件反射**时间快、语义弱**（μs~ms，但只知道「这里变了」，不知道「变的是什么」）；R69 的流策略恰在中间（ms~10ms，有中等语义的动作分布）。三者不是替代关系，而是覆盖了**语义-时间平面的三个频段**。R70 把它们叠成一个栈：事件当「时钟」与「触发器」，流策略当「中间层动作生成」，VLA 当「慢层语义规划」。关键工程含义：**场景不变时不必思考**——事件无变化 ⇒ 复用旧计划 ⇒ VLA 不必每帧重跑，把 VLA 的算力从「常开」变成「按变化触发」。

**灵感 4（先看后问 → 重排交互梯度，直接给 R69 减负）**
直觉：R69 解决歧义靠「问」，但问有社交成本、有投毒风险、有延迟。而大量歧义其实是**时间性**的：物体在不在动？接触发生了没有？表面是不是刚性的？门是虚掩还是关着？——这些问题**看一会儿就有答案**，根本不需要问人。事件让「看」变得近乎免费且微秒级。于是交互梯度应重排为 **watch ≪ probe < ask**：先用事件观察（零社交成本、无投毒面），观察不够再物理探针，最后才问人。这同时降低 R69 的交互预算压力和它最大的攻击面（问得越少，被骗越少）。

**灵感 5（锚点也会被攻击 → 事件完整性必须自证）**
直觉：一旦系统把事件当「事实层」，就有了新的攻击面：激光注入可伪造事件（幻影变化），强光致盲/抑制可抹掉事件（隐形变化），重放可制造时间错位。若盲目相信事件，攻击者就能凭空捏造「世界变了」或「世界没变」。因此 R70 必须交付**事件通道完整性**：极性-亮度梯度物理一致性、时空密度合理性、与帧相机/R68 标定的互证。规则是：**事件通道不可信 ⇒ 事件证据作废 ⇒ 退化 R69**，而不是升级为虚假的自信。锚点必须能被检验，否则它就不是锚点。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（PULSE-RAS 总览）** PULSE-RAS = (EVS, LEG, ETC, SALT, ERX, EIG, RAS-WM‡)。三不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **物理变更通道独立且恒开**：事件反射 ERX 不经任何学习模型，延迟 τ_ev ≪ τ_VLA，始终在线，是最后一道物理防线；
(iii) **验证先于执行（VBA）**：任何以「需 grounding 的高风险语义声明」为前提的动作，必须在事件证据到位且接地通过后才可执行；证据未到 / 通道不可信 / 计划陈旧 ⇒ 不得执行，退化为 R69 保守（或仅 ERX）。

**定义 311（事件变更场 EVS）** 事件流 ℰ_{t−H:t} = {(u_i, t_i, p_i)}，u_i ∈ Ω 像素、p_i ∈ {+1,−1}。局部事件率 ρ(u,t) = Σ_i δ 核平滑；年龄场 A(u,t) = t − t_last(u)（最近一次事件到现在的时长）。变更显著性场 S(u,t) = 𝒩(ρ(u,t), A(u,t)) ∈ [0,1]^{|Ω|}，非学习、逐像素、随时间更新。S 高 = 该处正在变化；S 低且 A 大 = 该处静止。

**定义 312（事件触发认知 ETC）** 认知触发 T(t) = 1[∫_{Ω_crit} S(u,t) du ≥ θ_ev ∨ 出现新事件簇 ∨ 计划的期望变更支持区内出现事件]。仅当 T(t)=1 才唤醒 VLA 重规划；否则复用最近计划。θ_ev 由定义 326 自适应。ETC 是**计算门控**：把 VLA 从「每帧常开」改为「按世界变化触发」。

**定义 313（语义声明与变更签名）** VLA 输出结构化声明集 C = {(e_j, attr_j, pred_j, conf_j)}，e_j 实体、pred_j 时间谓词（「正在移动」「已经接触」「是刚性的」）。投影函数 Π 把每条声明映射为**期望变更签名** Sig(c) = (Ω_c, ρ_c, pol_c, τ_c)：应出现事件的区域、期望事件率、极性/时序模式、期望起始时刻。Π 把语言变成**可被事件检验的物理预测**。

**定义 314（语言-事件接地分 LEG）** G(c, ℰ) = hit(ℰ; Ω_c, ρ_c, pol_c) − λ_s·spurious(ℰ; Ω\Ω_c)。hit 为支持区内事件与签名的匹配度（率/极性/时序），spurious 为支持区外「应有解释却无声明」的事件密度（惩罚漏解释）。低 G 而高 conf ⇒ **接地失败 / 幻觉**。定义逐声明接地裕度 m_c = G(c) − τ_G。

**定义 315（幻影模态判据 EMV）** R69 的每个模态 m_k 预测未来观测的变化签名 Sig(m_k)（经世界模型/光流投影到图像域）。事件支持密度 e_k = ∫_{Ω_{m_k}} S du。若 ŵ_k 高而 e_k 长期低于噪声底（且在 A95 意义下可分）⇒ **幻影模态**。EMV = e_k / (ŵ_k + ε)。EMV 直接落刀 R69 的第一风险（「幻觉出不存在的模态」）。

**定义 316（陈旧度与陈旧检测 SALT）** VLA 在 t 出计划 π，推理延迟 T_VLA 后执行。决策相关事件集 ℰ_rel(π) = 落在 π 的期望变更支持区且幅度超过影响阈值的事件。若 [t, t+T_VLA] 内出现 ℰ_rel 事件 ⇒ 计划陈旧（世界在「思考期间」变了）。事件检测陈旧信号的延迟 τ_stale ≤ τ_ev + τ_reflex ≪ T_VLA。

**定义 317（事件反射 ERX）** 非学习的安全反射，直接作用于事件张量：looming（事件支持区扩张速率）、突发位移、碰撞前兆（视差/尺度扩张）。任一超阈 ⇒ 在 τ_ev 内触发保守动作/急停。它不依赖任何学习模型的正确性，也不经过 R69 的模式选择，是**与模型可信度解耦**的最后防线。

**定义 318（事件完整性 EIG）** 事件通道的攻击与检验：激光注入（伪造事件）、致盲/抑制（抹除事件）、重放（时间错位）、极性反转。一致性检验：(a) 事件极性与帧相机亮度梯度方向一致；(b) 事件时空密度符合场景动力学先验；(c) 与 R68 标定/R69 残差互证。任一项持续失配 ⇒ 通道 `compromised`，事件证据作废、退化 R69。

**定义 319（先看后问的交互梯度）** 信息动作成本 c(watch) ≪ c(probe) < c(ask)，其中 watch 由事件近乎零成本实现。R69 的 MINT（定义 298）成本函数替换为 c′(g) = c(g) + λ_g·1[g∈{probe,ask}]，VoI 计算不变。⇒ 同等 VoI 下优先在 watch 阶段消解；问句与探针调用率下降，R69 的交互预算与投毒面同时缩小。

**定义 320（三时间尺度调度）** τ_ev（~ms）< τ_flow（ms~10ms）< τ_VLA（100ms+）。调度器：ERX 恒开 → ETC 触发流策略 → 仅当 T(t)=1 或陈旧才调用 VLA → VLA 计划受 SALT 监控。任一层可因证据不足而拒绝交给下一层（验证先于执行）。

**定义 321（三通道异常）** 在 R69 的 (r_res, Δa) 之外加事件通道 e_score = −log p(ℰ | ξ, o)（事件对动作轨迹的似然），并定义变更间隙 e_gap = ‖Sig(ξ) − Ŝ‖（预测变更 vs 观测变更）。三通道 (r_res, Δa, e_gap) 中任意两路一致即提高置信，单路异常不单独定案（沿用 R69 证据纪律）。

**定义 322（声明审计 VQAuditor-E）** 审计对象新增：每条语言声明是否有事件支持、陈述与事件是否矛盾、事件通道是否被污染、反射是否被噪声误触发、陈旧是否被漏检。结论回灌 AuditBuf，成为 ETC 阈值与 MINT 成本先验。

**定义 323（威胁模型 AIC-PULSE）** ℰ_PULSE = ℰ_FLUID × ℰ_event（注入/致盲/重放/极性反转）× ℰ_stale（延迟诱导竞态：证明没到就执行）× ℰ_semantic（语言-视觉错位、诱导性描述）。

**定义 324（证书 J_PULSE）** J_PULSE = (J_FLUID, grounding_score_p5, ungrounded_high_risk_count, stale_flag, event_integrity, reflex_trigger_count, vla_calls_saved_ratio, latency_p99, pulse_ver)。Valid ⇔ Valid(J_FLUID) ∧ event_integrity=ok ∧ VBA 无违反 ∧ 审计无高危项。

**定义 325（降级单调）** 事件通道不可信 / 接地失败 / 计划陈旧 / 证据未到 ⇒ 行为退化为 R69（甚至仅 ERX 反射）。安全侧只在**物理变更证据支持**时放宽，**绝不因语义自信而放宽**。R69 是「事件通道关闭 / 永远信任模型」的退化边界。

# IP-264 EVS：事件变更场（非学习、恒开，直接在事件张量上算）
class EventSalienceField:
    def __init__(self, tau_age=5e-3, theta_ev=0.2):

## 3. 推导

**引理 19（事件触发的漏检/误触发界）** 在事件生成模型（|Δ log I| ≥ C 产生事件）下，区域 Ω 内一次幅度 ≥ C 的 log-亮度变化在积分窗内几乎必然产生至少一个事件；故触发对「≥C 变化」的漏检率上界为该变化落在阈值以下的比例。误触发率上界为背景噪声事件率 / θ_ev。⇒ ETC 的 ROC 由 C 与 θ_ev 显式给出，可调可证。系：阈值 C 是事件相机的「测量分辨率」——但作用在时间导数上，恰补 R68 只在绝对量上标定的短板。

**引理 20（LEG 的幻觉可分性）** 设 A99：真实声明与幻觉声明的事件支持密度相差裕度 Δ_ground > 0。则单条声明在 τ_G 处可分，误判率随 Δ_ground·√(观测窗长度) 指数下降。幻觉声明的事件支持 ≈ 噪声底，故 G ≈ −λ_s·spurious < τ_G；真实声明 G ≥ ρ_min > τ_G。系：**语言置信度不能替代事件证据**——高 conf 低 G 恰是幻觉的签名。前提是 EIG 成立（通道未污染）。

**引理 21（陈旧检测的反应延迟压缩）** 由定义 316–317，τ_stale ≤ τ_ev + τ_reflex。相对 VLA 重新规划延迟 T_VLA，有效反应时间压缩因子 = T_VLA / (τ_ev + τ_reflex)。在典型 T_VLA≈150ms、τ_ev+τ_reflex≈2ms 下约为 75×。条件：ℰ_rel 非空且事件完整性成立。⇒ **事件相机把慢 VLA 的有效反应速度提升两个数量级**，代价只是它无法理解语义（语义仍由 VLA/流策略提供）。

**定理 18（PULSE 严格包含 R69）** 在 A99 + 事件完整性成立下：若事件确认、接地通过、无陈旧，PULSE 执行与 R69 相同的动作（事件通道只「确认」，不改变选择）；若检出幻影模态 / 接地失败 / 计划陈旧 / 通道污染，PULSE 退化为 R69 保守（或仅 ERX），其动作属于 R69 的认证安全集。故 PULSE 的期望风险 ≤ R69，安全侧单调不降；且 R69 是「事件通道关闭」的退化边界。效率侧因 ETC 与交互梯度重排而提升。

**定理 19（事件触发的计算节省与守时）** VLA 调用次数 ≤ 基线（每帧一次）；场景静止（T(t)=0）时 VLA 不调用，控制延迟 ≈ τ_ev + τ_flow ≪ T_VLA。总计算量下降比例 ≈ 1 − E[T(t)]。且因 ERX 与 ETC 都在 VLA 之前，最坏控制时延不超过 τ_ev + τ_flow + 一次受预算约束的 VLA 调用。⇒ 实时性不退反进。

**定理 20（反射层安全下界与无突变）** ERX 非学习、事件延迟有界，故当事件完整时，其对突发变化的反应时延 ≤ τ_ev，可在物理停止距离内触发保守动作。ERX/ETC 只可能**收紧或中止** R69 的认证动作（定义 325 降级单调），绝不会放宽安全包络；R68/R69 的提交/换装不变式保持 ⇒ 控制连续、无突变。

## 6. 本轮最大风险

**一句话**：把事件当「事实层」的前提是**事件通道本身未被欺骗**——若攻击者能注入/抹除/重放事件，或事件噪声与标定误差把「没变」报成「变了」、把「变了」报成「没变」，那么 PULSE 的整个裁决逻辑就建立在被污染的锚点上：**它会把幻影模态当成真实、把真实变化判成幻觉，甚至用「物理证据」给一个错误结论盖章**——比 R69 的「模型幻觉」更危险，因为这次错误带着「我看过」的权威。

**次级风险与缓解**：
1. **事件通道被欺骗**（注入/致盲/重放/极性反转）→ EIG 三重一致性检验 + 与帧相机/R68 残差互证，判定 `compromised` 即证据作废、退化 R69；
2. **事件噪声/热像素误触发** → 自适应 θ_ev（定义 326）+ 去噪 + E310 噪声验证；
3. **LEG 投影依赖视觉/世界模型**（Π 可能错投影）→ 投影只用轻量几何/光流先验，且与 R69 的 Δa 双通道交叉验证（定义 321）；
4. **VBA 引入额外延迟**（验证未到不能动）→ ERX 快环兜底 + 验证与执行并行、仅高风险动作强制等待；
5. **语义自信压过事件证据**（VE 把自己说服）→ 硬规则：高 conf 低 G 一律判幻觉，语言永不能推翻事件（定义 325 降级单调）。

## 4. 推导

**引理 19（事件触发的漏检/误触发界）** 事件生成模型下，幅度 `≥C` 的 log-亮度变化几乎必然在积分窗内产生事件；漏检率上界为落在阈值以下的比例，误触发率上界为背景噪声事件率/`θ_ev`。⇒ ETC 的 ROC 由 `C,θ_ev` 显式给出。系：`C` 是作用在时间导数上的测量分辨率，补 R68 只在绝对量标定的短板。

**引理 20（LEG 的幻觉可分性）** A99（真实/幻觉声明事件支持差裕度 `Δ_ground>0`）下，`τ_G` 处可分，误判率随 `Δ_ground·√窗口` 指数下降；幻觉声明 `G≈−λ_s·spurious<τ_G`，真实声明 `G≥ρ_min>τ_G`。系：**语言置信不可替代事件证据**——高 conf 低 G 是幻觉签名；前提是 EIG 成立。

**引理 21（陈旧检测的反应延迟压缩）** `τ_stale≤τ_ev+τ_reflex`，相对 `T_VLA` 压缩因子 `T_VLA/(τ_ev+τ_reflex)`；典型 150ms/2ms ≈ 75×。⇒ 事件把慢 VLA 的有效反应速度提升两个数量级，语义仍由 VLA 提供。

**定理 18（PULSE 严格包含 R69）** A99 + 事件完整性下：确认/接地/非陈旧时与 R69 逐指令相同（事件只「确认」）；检出幻影/接地失败/陈旧/污染时退化为 R69 保守（或仅 ERX），动作属于 R69 认证安全集。故期望风险 ≤ R69，安全单调不降；R69 = 「事件通道关闭」退化边界；效率因 ETC 与交互梯度重排提升。

**定理 19（事件触发的计算节省与守时）** VLA 调用次数 ≤ 每帧一次；`T(t)=0` 时不调用，控制延迟 ≈ `τ_ev+τ_flow≪T_VLA`；计算下降比例 ≈ `1−E[T(t)]`，最坏时延受预算约束。⇒ 实时性不退反进。

**定理 20（反射层安全下界与无突变）** ERX 非学习、事件延迟有界，故 `≤τ_ev` 内可在物理停止距离内保守动作；ERX/ETC 只收紧或中止 R69 认证动作（降级单调），不放宽安全包络；R68/R69 提交/换装不变式保持 ⇒ 控制连续、无突变。

## 7. 本轮最大风险

**一句话**：把事件当「事实层」的前提是**事件通道本身未被欺骗**——若攻击者能注入/抹除/重放事件，或噪声与标定误差把「没变」报成「变了」、把「变了」报成「没变」，PULSE 的整个裁决逻辑就建立在被污染的锚点上：**它会把幻影模态当成真实、把真实变化判成幻觉，甚至用「物理证据」给一个错误结论盖章**——比 R69 的「模型幻觉」更危险，因为这次错误带着「我看过」的权威。

**次级风险与缓解**：事件通道被欺骗（EIG 三重一致性 + 帧相机/残差互证，`compromised` 即作废、退化 R69）；事件噪声/热像素误触发（自适应 `θ_ev` + 去噪 + E310）；LEG 投影依赖视觉/世界模型（轻量几何/光流先验 + 与 `Δa` 双通道交叉验证）；VBA 额外延迟（ERX 快环兜底 + 验证执行并行、仅高风险强制等待）；语义自信压过事件证据（硬规则：高 conf 低 G 判幻觉，语言永不推翻事件，降级单调）。
