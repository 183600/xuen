# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环续轮；本轮灵感：「真机评测」×「用户画像」）

> R69 给闭环装上了「嘴」——不确定性可以变成一次注视、一次探询、一句提问。但它默认了两件从未被检验的事：(1) **答案的价值可以在仿真里被标定**（分辨率红利 resolution bonus 由仿真 ECE 担保）；(2) **「k 个正交证据源」里的每个源，可信度是全局常数 δ_p**。本轮两个灵感恰好戳破这两条默认：
> - **真机评测**：分辨率红利是「借来的信任」——你用一个未被真机验证的信念，换取「可以更不保守」的许可；仿真里的 ECE 再漂亮，也担保不了 sim→real 的转移。
> - **用户画像**：R69 的「正交」在多数真实场景里是假的——同一个用户的笑容、语气、措辞由**同一个潜在意图**驱动，共因相关把 k 个源坍缩成 1 个；而可信度本身随用户、随疲劳、随对抗适应而漂移。
>
> 核心命题：**认知信用必须被抵押。** 每一单位「允许更不保守」（分辨率红利）和每一单位「相信某个回答」（证据采纳），都是一笔**认知信用贷**；它只能发放到**真机回执（real-machine receipt）**与**用户承保契约（per-user underwriting）**所担保的额度之内；无抵押即违约，违约即逐指令退回 R68 最保守档。命名 **BOND-RAS**（Backed-On-Non-simulated-Data：以非仿真数据为抵押的风险自适应闭环）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该问谁、还能问什么」，R70 问「**我凭什么相信我问到的答案、又凭什么相信自己真的变好了**」——不确定性不只是刹车和提问，它还是一本需要被真机回执不断对账的账本。

## 0. 直觉与动机

**灵感 1（真机评测 → 分辨率红利是借来的信用）**
直觉：R69 的 resolution bonus 说「歧义消解了就允许 λ 降到 λ_floor(U_ale)」。但这个「消解」是模型内部的信念。仿真里 ECE=0.03 不等于真机上 ECE=0.03。sim→real 的标定差 Δ_sim 不被任何仿真实验看见。于是 R69 的效率收益本质上是一笔**无担保贷款**：它用「我认为我确定」去换取「我更激进」。真机是唯一会强制清算的债权人。而且真机评测昂贵、危险、世界不可重置，所以它不是「跑几个 benchmark」，而是一个**稀缺、高风险、需预算的查询**——这恰好与 R69 的交互预算同构。

**灵感 2（用户画像 → 「正交证据」常常是共因假象）**
直觉：R69 证据纪律说「k 个正交源一致才定案」，隐含欺骗率 δ_p 是全局常数、源间相关 ρ<1。但现实里，一个人的表情、语气、用词往往由**同一个念头**驱动：嘴上说「没事」、脸上强笑、声音发紧，三者高度相关——它们是同一个人的一次社交伪装，不是三个独立证人。共因让 k_eff→1。更麻烦的是，可信度**因人而异、因疲劳与对抗适应而漂移**：新手 vs 专家、配合 vs 试探、第一天 vs 第七天。缺了用户画像，R69 会把「问一个人三次」误当成「问三个证人」。

**灵感 3（两者同构 → 统一成「认知信用账本」）**
直觉：真机回执担保的是「模型对世界的信念」，用户承保担保的是「人对模型的回答」。两者都是**信任的抵押品**，都满足同一条会计恒等式：**可发放的激进度 ≤ 已抵押的信任**。于是 R70 不必再造一个新闭环，只需在 R69 每个「发放许可」处插一道**承保/对账**环节：分辨率红利要有真机回执；跨源采纳要有 k_eff≥k_min 的用户画像校正；两者都没有 → 违约 → 逐指令退回 R68。这保持了 R69 的纪律「新层必须是旧层严格泛化」：BOND 在「回执齐全且用户可信」的极限处等于 R69，在「无回执/冷启动」处等于 R68——这是**双重边界的包含**，而非又一个并列黑箱。

**灵感 4（评估负债与反证优先）**
直觉：R63→R69 已经叠了七八层，每层都自证「严格包含前一层」，却没有一层在真机上被证伪过。这是**可证伪性赤字**：证书越堆越多，能被真机推翻的命题却越来越少。真机评测的正确姿态不是「确认我的收益」，而是「设计一个能把我的收益证伪的实验」——预注册反证条件、用 anytime-valid 序贯检验（因为真机是小样本且自适应分配），把「只跑过仿真」的声明记为**评估负债 D_e**，让它在部署高风险场景前必须被偿还。评估负债应与成功率并列，是一等指标。

**灵感 5（画像是一把双刃剑 → 冷启动惩罚的不公平）**
直觉：用户画像能提升安全，但它把「安全」变成一道**门槛**：数据稀少、行为 atypical、不被多数画像代表的用户，会长期停留在 CL_u≈0、λ 最高的保守档——冷启动与漂移惩罚是不均匀落下的。如果画像由多数人数据拟合、回执由受益方自证，那么这套信用体系会系统性地把自主权从少数人手里收回。**严谨的安全设计，可能以公平为代价**；本轮必须把它写进威胁模型与实验，而不是当作伦理脚注。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（BOND-RAS 总览）** BOND-RAS = (ECL, RMR, PUC, CBN, STV, CCR, RAS-WM††)。三不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **无抵押不授信**：任何相对 R68 的保守度下调（分辨率红利）、任何单源回答的采纳，都必须由当前（部署条件单元 × 用户簇）内有效的回执/承保抵押；
(iii) **可证伪性**：每一条被用于降低保守度的声明，都必须携带 provenance 标签与至少一个预注册、可能推翻它的实验；否则最高只能记为 `sim`，不得授信。

**定义 311（provenance 格）** 声明可信级别 L ∈ {`sim`, `replay`, `hw-single`, `hw-replicated(n)`, `hw-adversarial`}，偏序 `sim ≺ replay ≺ hw-single ≺ hw-replicated(n) ≺ hw-adversarial`。风险等级 ρ_claim 决定所需最低级别 L_min(ρ_claim)，授信不足即按无抵押处理。

**定义 312（真机回执 RMR）** 回执 r = (claim_id, cell, N, statistic, CI, log_hash, safety_envelope, operator_profile, hw_id, t, sig)。Valid(r) ⇔ 安全包络未被越过 ∧ 区间为 **anytime-valid**（可在任意停时读）∧ condition cell 与当前部署单元一致 ∧ 未过期。

**定义 313（部署条件单元）** 把部署划分为单元 cell = (task, environment, user_cluster, hw_config)。信用**逐单元有效**：单元 C1 的回执对 C2 给零授信。用户画像把 user_cluster 从「全体人类」细分到「可承保簇」。

**定义 314（认知信用与抵押率）** 对某声明所需信用额 b_req，已抵押额度 L_backed = f({Valid(r)})（多次回执按 anytime-valid 证据合并）。抵押率 κ = b_req / max(L_backed, ε)。κ ≤ 1 授信；κ > 1 **违约**。

**定义 315（抵押化分辨率红利 CBN）** 分辨率红利 b 只能发放 b_granted = min(b_req, L_backed)。λ = λ_floor(U_ale) − b_granted（且不低于 λ_floor(U_ale) − ε_b）；违约时 λ = λ_floor(U_ale + U_epi)（逐指令退回 R68）。⇒ λ_BOND ∈ [λ_R69, λ_R68]。

**定义 316（用户可靠性画像）** θ_u = (competence, honesty, consistency, interaction_cost, fatigue_curve, expressivity_baseline, adaptation_rate)。层级先验 p(θ_u)（簇→个体），后验由交互对账更新。画像只由**行为对账残差**估计，不采集外观/身份等敏感属性。

**定义 317（共因相关校正 CCR）** 证据源共享潜在意图 I_u 的因子模型，估计有效相关 ρ_eff；有效独立源数 k_eff = k / (1 + (k−1)ρ_eff)。证据纪律要求 k_eff ≥ k_min（而非 k ≥ k_min）；k_eff < k_min ⇒ 不得定案，U_epi 保持未消解。R69 的 k-一致是 ρ_eff=0 的退化特例。

**定义 318（用户承保与信用额度）** 用户信用额度 CL_u = g(posterior θ_u, 该单元有效回执)。**冷启动 CL_u=0**（禁止用该用户的回答换取分辨率红利）；承保后按簇分位数发放，并对少数簇设下限保护（见定义 326-公平约束）。

**定义 319（画像漂移与对抗适应 PDA）** 用户可适应系统（策略性）。对交互结果残差做序贯变化检测（CUSUM / e-value）；检出漂移 ⇒ 冻结 CL_u、该用户退回 R68、触发一次重新承保交互。

**定义 320（真机测试的 VoI 选择 STV）** 查询对象升级为「跑一次真机试验 h 以验证某声明/单元」：VoI(h) = 回执对抵押率与信用不确定性的期望缩减 − c_hw(h) − risk(h)。h* = argmax[VoI − c]；无正收益 ⇒ 不花硬件预算，声明保持 `sim` 且保守。**与 MINT 同构：真机是最贵的那次「提问」。**

**定义 321（评估负债 D_e 与反证账本）** 每条仅 `sim` provenance、却用于降低保守度的声明累积评估负债 D_e。高风险单元部署前须 D_e ≤ D_max；D_e 作为与成功率并列的一等指标上报。

**定义 322（评估安全包络与遮蔽试验）** 真机试验只在已认证包络内运行；对可能违反包络的声明不得直接试。采用 **shielded trial**：R68 核心安全层始终可否决，仅在「shield 介入」处离线反事实评估决策质量，实现近零风险数据采集。

**定义 323（反事实回放证书）** 用日志轨迹 + 重要性采样/数字孪生估计策略表现；仅当有效样本量 ≥ 阈值且支撑重叠校验通过，provenance 才能记为 `replay`，否则记 `replay-weak`（不给授信）。

**定义 324（anytime-valid 评估）** 采用 e-value/置信序列的序贯检验，使自适应分配与「偷看结果」不放大假阳性。这是 STV 自适应花费硬件预算的统计前提。

**定义 325（证书 J_BOND）** J_BOND = (J_FLUID, provenance_vec, receipts_hash, CL_u, k_eff, D_e, drift_flag, bond_ver)。Valid ⇔ Valid(J_FLUID) ∧ 全部发放红利满足 κ≤1 ∧ D_e ≤ D_max(cell) ∧ 回执未过期 ∧ CL_u 未冻结。

**定义 326（公平约束 FC）** 冷启动/漂移导致保守度上调时，必须满足：对不同 user_cluster 的**平均 λ 上调幅度之差** ≤ δ_fair（在控制任务难度与风险等级后），且少数簇的 CL 不得因样本量少于多数簇而被系统性压低；否则升级为「不公平违约」，须由审计与人工复核，禁止自动下调该类用户的自主权。

# IP-264 ECL：认知信用账本（核心：无抵押不授信）
class EpistemicCreditLedger:
    def __init__(self):
        self.receipts = {}                         # (claim_id, cell) -> [RMR...]

    def backed(self, claim_id, cell, now):
        rs = [r for r in self.receipts.get((claim_id, cell), [])
              if valid_receipt(r, cell, now)]      # anytime-valid CI + 安全包络 + 未过期
        return fuse_receipt_credit(rs)             # L_backed

    def collateral_ratio(self, b_req, claim_id, cell, now):
        return b_req / max(self.backed(claim_id, cell, now), EPS)

    def grant_bonus(self, b_req, ale, epi, claim_id, cell, now):
        if self.collateral_ratio(b_req, claim_id, cell, now) > 1.0:
            return lam_floor(ale + epi)            # 违约 -> 逐指令 R68
        b = min(b_req, self.backed(claim_id, cell, now))
        return max(lam_floor(ale) - b, lam_floor(ale) - EPS_B)

# IP-265 PUC：用户画像化承保 + CCR 共因校正
def user_credit(theta_post, cell_receipts, cold_start_k, cluster_floor):
    if theta_post.n < cold_start_k: return 0.0     # 冷启动 CL=0
    return max(quantile_credit(theta_post, cell_receipts), cluster_floor)

def effective_sources(source_evidence, theta_u):
    rho = estimate_common_cause(source_evidence, theta_u)   # 潜在意图因子模型
    k   = len(source_evidence)
    return k / (1.0 + (k - 1.0) * rho)             # k_eff：一个用户一场戏 -> 1

def update_belief_bond(modes, answer, theta_u, CL_u):
    if CL_u <= 0: return modes, FLAG_UNRESOLVED        # 冷启动不采纳
    k_eff = effective_sources(answer.sources, theta_u)
    if k_eff < K_MIN: return modes, FLAG_UNRESOLVED    # 共因坍缩，不得定案
    return bayes_update(modes, answer, discipline='k_eff_agree'), FLAG_OK

# IP-266 STV：真机测试的 VoI 选择（真机 = 最贵的查询）
def choose_hw_trial(claims, cell, ledger, hw_budget):
    best = None
    for h in trial_candidates(claims, cell):       # 由高 D_e / 高 κ 单元生成
        if not hw_budget.allow(h): continue
        voi   = expected_credit_reduction(ledger, h)   # 回执能缩多少信用不确定
        score = voi - cost_hw(h) - risk(h)
        if best is None or score > best.score: best = (h, score)
    return best if best and best.score > 0 else None   # 无正收益 -> 不测，保持保守

# IP-267 RMR：遮蔽真机试验 -> 签发回执
def run_shielded_trial(h, policy, shield):
    log = []
    for t in rollout(h, policy):
        veto = shield.veto(t)                      # R68 核心安全层，随时可否决
        log.append((t, veto))
        if veto: break                             # 零越包络：绝不为数据冒险
    stat, ci = anytime_valid_estimate(log, h.claim, h.cell)
    return issue_receipt(h, stat, ci, log_hash=hash(log))   # 记录 provenance

## 3. 推导

**引理 19（抵押化红利的安全支配）** 在 A99（回执 anytime-valid 且单元匹配）下，λ_BOND ≥ λ_R69 恒成立；当回执齐全 κ≤1 时取等；当 κ>1 或 CL_u=0 时 λ_BOND = λ_R68。故真机口径下 R(BOND) ≤ R(R69)，且 BOND 在无证据处逐指令复用 R68。要点：R69 的「严格包含 R68」本身是一条 sim 标定的命题；BOND 把这个包含从「模型信念」变成「受回执约束的分段函数」——只在被验证的分段里享受 R69，其余分段享受 R68。这是**双边界**，不是单边界。

**引理 20（共因校正的误采纳上界）** 设 k 个源共享潜在意图、两两相关 ρ，单源欺骗率 δ_p。朴素 k-一致（误视源独立）的错误采纳率仍近似 δ_p——它们是同一源的重复；经 CCR 得 k_eff = k/(1+(k−1)ρ)，错误率 ≤ δ_p·ρ^{k_eff−1} + ε_σ。系：**「问得更多」不等于「知道得更多」**；当 ρ→1（一个用户一场戏），k_eff→1，任何 k 都救不回来，唯一切实做法是换一个**真正独立的源**（另一个人/另一次真机试验），而不是把同一场戏再问几遍。

**引理 21（无抵押红利的违约成本）** 设 sim→real 标定差为 Δ_sim（未知，仅真机可界定），无抵押红利 b 引入的期望安全违规 ≥ b·Δ_sim − ε。要保证违规 ≤ ε，须 b ≤ 2ε/Δ_sim^upper；而 Δ_sim^upper 只能由真机回执收窄。系：**分辨率红利的定价权不在仿真**；评估负债不是流程装饰，而是安全预算的未偿部分。

**定理 18（BOND 的双边界包含与安全支配）** 在 A99–A101 下，按允许的激进度偏序 R68 ≼ BOND ≼ R69：(a) 回执齐全 ∧ 用户承保有效 ⇒ BOND ≡ R69 逐指令；(b) 无回执/冷启动/漂移/违约 ⇒ BOND ≡ R68 逐指令；(c) 当 Δ_sim>0 时，若 R69 存在未抵押红利，R69 的真机风险可严格大于 R68，而 BOND 因拒绝未抵押红利使 R(BOND) ≤ R(R68) + O(κ 越界的残余)，仅在回执有效性失效时成立。故 BOND 把「R69 对 R68 的包含」从一条未验证的仿真命题，升级为一条**由真机回执分段担保**的命题。

**定理 19（评估负债的序贯偿还）** 在 STV 按 VoI 分配、检验为 anytime-valid（定义 324）下，单元 c 的评估负债以概率 ≥1−α 在有限次真机试验内降至 D_max；期望试验数随「红利率—真机差距」的信噪比按 O(log(1/α)/Δ²) 缩放；无正 VoI 的单元不消耗硬件预算。系：**硬件预算应花在「信用最不确定、且最可能影响激进度」的单元上**，而非平均铺开。

**引理 22（可证伪性守门）** 任何声明，若未预注册「什么样的真机结果会推翻它」，则其 provenance 不得高于 `replay`，因而不得用于降低保守度（定义 311、310-iii）。系：把「可证伪」从科学美德变成**证书的准入条件**，从机制上防止「层数越多、越不可推翻」。

**引理 23（公平约束的必要性）** 若 CL_u 直接取后验分位数且不设簇下限，则样本量 n 较小的簇的 CL 期望随 n 下降，导致其 λ 上调幅度系统性偏大（族间差异 ∝ 1/√n）。定义 326 的 δ_fair 约束把「安全保守」与「样本量偏见」解耦：只有**证据不足**可以上调保守度，**群体样本量少**不可以。系：不写公平约束，用户画像会把统计上的小样本劣势固化为制度上的自主权劣势。

## 6. 本轮最大风险

**一句话**：BOND-RAS 把「要不要更激进、要不要相信这个回答」的定价权，交给了**回执的签发者**与**画像的拟合者**——若回执由受益方自证、画像由多数人数据拟合，这套信用体系就会退化为「带证书的自我认证」；更危险的是，它会把「安全」变成一道根据数据厚薄发放的门槛：数据稀少、行为 atypical、不被多数画像代表的用户将长期锁在 CL≈0、λ 最高的保守档，**冷启动与漂移惩罚变成制度化的区别对待**——最严谨的安全设计，可能以公平为代价。

**次级风险与缓解**：
1. **回执可被自证污染** → 回执需独立第三方/交叉实验室签发 + log_hash 可复算 + 定义 322 遮蔽试验；
2. **画像侵入隐私 / 编码偏见** → 定义 316 只用行为对账残差、定义 326 公平约束、E314 最小化与差分隐私；
3. **冷启动导致系统「安全但无用」** → STV 把硬件预算优先投向高 VoI 单元 + 簇下限 CL + E308 预算效率；
4. **anytime-valid 检验被自适应分配偷看击穿** → 定义 324 置信序列 + E310 名义水平校验；
5. **评估负债永不偿还、可证伪性赤字扩大** → 定义 321 把 D_e 设为一等指标并设部署门限，引理 22 把可证伪性写进准入。

## 2. 形式化定义（要点版）

**定义 310（总览与三不变式）** BOND-RAS；零学习写操作继承；**无抵押不授信**（红利/采纳须由当前 cell×用户簇的有效回执担保）；**可证伪性**（用于降低保守度的声明须带 provenance 与预注册反证实验，否则最高 `sim`、不得授信）。

**定义 311–313（provenance / 回执 / 单元）** provenance 偏序 `sim≺replay≺hw-single≺hw-replicated≺hw-adversarial`；回执 Valid ⇔ 安全包络不越 ∧ anytime-valid CI ∧ 单元匹配 ∧ 未过期；信用逐 cell 有效。

**定义 319（漂移）** 残差序贯检测（CUSUM/e-value），检出冻结 CL_u、回 R68、重新承保。

**定义 320–321（STV / 评估负债）** `h*=argmax[VoI−c_hw−risk]`，无正收益不测；仅 sim 却降保守度的声明累积 D_e，高风险部署前须 D_e≤D_max。

**定义 322–324（遮蔽试验 / 回放 / 序贯检验）** shielded trial 由 R68 核心层否决，零越包络；回放证书需 ESS 与支撑重叠校验；用 e-value/置信序列做 anytime-valid 检验。

**定义 325（J_BOND）** 并入 provenance、回执哈希、CL_u、k_eff、D_e、drift，任一不满足即 invalid。

**定义 326（公平约束 FC）** 控制难度后，族间平均 λ 上调幅度差 ≤ δ_fair；少数簇 CL 不得因样本量少被系统性压低；否则视为不公平违约，禁止自动下调该类用户自主权（须人工复核）。

class EpistemicCreditLedger:
    def backed(self, claim_id, cell, now):
        rs = [r for r in self.receipts.get((claim_id, cell), [])
              if valid_receipt(r, cell, now)]
        return fuse_receipt_credit(rs)                       # L_backed

    def grant_bonus(self, b_req, ale, epi, claim_id, cell, now):
        L = self.backed(claim_id, cell, now)
        if b_req / max(L, EPS) > 1.0:
            return lam_floor(ale + epi)                      # 违约 -> R68
        return max(lam_floor(ale) - min(b_req, L), lam_floor(ale) - EPS_B)

# IP-266/268 PUC + CCR：画像承保 + 共因校正
def user_credit(theta_post, receipts, cold_start_k, cluster_floor):
    if theta_post.n < cold_start_k: return 0.0           # 冷启动不授信
    return max(quantile_credit(theta_post, receipts), cluster_floor)

def update_belief_bond(modes, answer, theta_u, CL_u):
    if CL_u <= 0: return modes, FLAG_UNRESOLVED
    k_eff = len(answer.sources) / (1 + (len(answer.sources) - 1)
                                   * estimate_common_cause(answer.sources, theta_u))
    if k_eff < K_MIN: return modes, FLAG_UNRESOLVED      # 一个用户一场戏
    return bayes_update(modes, answer, discipline='k_eff_agree'), FLAG_OK

# IP-269 STV：真机是最贵的查询
def choose_hw_trial(claims, cell, ledger, hw_budget):
    best = None
    for h in trial_candidates(claims, cell):
        if not hw_budget.allow(h): continue
        score = expected_credit_reduction(ledger, h) - cost_hw(h) - risk(h)
        if best is None or score > best.score: best = (h, score)
    return best if best and best.score > 0 else None

## 4. 推导

**引理 19（抵押化红利的安全支配）** A99 下 λ_BOND ≥ λ_R69 恒成立；全抵押 κ≤1 时取等；κ>1 或 CL_u=0 时 λ_BOND=λ_R68。故真机口径 R(BOND) ≤ R(R69)，无证据处逐指令复用 R68。要点：R69 的「严格包含 R68」是 sim 标定命题；BOND 把它变成**受回执约束的分段函数**——双边界，非单边界。

**引理 20（共因校正的误采纳上界）** k 源共享潜在意图、两两相关 ρ、单源欺骗率 δ_p。朴素 k-一致（误视独立）错误率仍≈δ_p；CCR 得 `k_eff=k/(1+(k−1)ρ)`，错误率 ≤ `δ_p·ρ^{k_eff−1}+ε_σ`。系：**问得更多 ≠ 知道得更多**；ρ→1 时只能换真独立源（另一个人/另一次真机试验）。

**引理 21（无抵押红利的违约成本）** sim→real 标定差 Δ_sim 未知，仅真机可界定；无抵押红利 b 的期望违规 ≥ `b·Δ_sim − ε`。要保证违规 ≤ ε 须 `b ≤ 2ε/Δ_sim^upper`，而 Δ_sim^upper 只能靠真机回执收窄。系：**红利的定价权不在仿真**，评估负债是安全预算的未偿部分。

**引理 22（可证伪性守门）** 未预注册「何种真机结果会推翻它」的声明，provenance 不得高于 `replay`，故不得用于降低保守度。把可证伪性变成**证书准入条件**。

**引理 23（公平约束的必要性）** CL_u 取后验分位数而不设簇下限时，小样本簇的 CL 期望随 n 下降，λ 上调幅度族间差 ∝ 1/√n。定义 326 把「安全保守」与「样本量偏见」解耦：只有证据不足可上调保守度，群体样本少不可。

**定理 18（BOND 的双边界包含与安全支配）** A99–A101 下，按激进度偏序 R68 ≼ BOND ≼ R69：(a) 回执齐全 ∧ 承保有效 ⇒ BOND≡R69；(b) 无回执/冷启动/漂移/违约 ⇒ BOND≡R68；(c) Δ_sim>0 时，R69 若有未抵押红利，其真机风险可严格超 R68；BOND 因拒绝未抵押红利使 R(BOND) ≤ R(R68)+O(κ 越界残余)（仅当回执有效性失效）。故把「R69 对 R68 的包含」从仿真命题升级为**真机回执分段担保**的命题。

**定理 19（评估负债的序贯偿还）** STV 按 VoI 分配 + anytime-valid 检验下，单元 c 的 D_e 以概率 ≥1−α 在有限试验内降至 D_max，期望试验数随信噪比按 `O(log(1/α)/Δ²)` 缩放；无正 VoI 的单元不耗硬件预算。系：硬件预算花在「信用最不确定、且最影响激进度」的单元上。

## 7. 本轮最大风险

**一句话**：BOND-RAS 把「要不要更激进、要不要相信这个回答」的定价权交给了**回执的签发者**与**画像的拟合者**——若回执由受益方自证、画像由多数人数据拟合，这套信用体系会退化为「带证书的自我认证」；更危险的是，它把「安全」变成按数据厚薄发放的门槛，数据稀少/行为 atypical/不被多数画像代表的用户将长期锁在 CL≈0、λ 最高的保守档，**冷启动与漂移惩罚变成制度化的区别对待**——最严谨的安全设计，可能以公平为代价。

**次级风险与缓解**：回执自证污染（第三方/交叉实验室 + log_hash 可复算 + 遮蔽试验）；画像隐私与偏见（只用行为残差 + 公平约束 + 差分隐私 + E314）；冷启动「安全但无用」（STV 高 VoI 优先 + 簇下限 + E308）；自适应偷看击穿检验（anytime-valid 置信序列 + E310）；评估负债永不偿还（D_e 设为一等指标与部署门限 + 可证伪性准入）。
