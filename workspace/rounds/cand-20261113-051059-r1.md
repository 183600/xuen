# 第 65 轮（承接第 64 轮「GRIP 接触接地四层闭环」IP-204~213；灵感循环 II 第 4 轮；本轮灵感：「对话管理」×「力矩控制」）

> 第 64 轮用 F/T 与触觉把几何先验变成「可证伪」，但它自述的最大风险恰好否定了自己的地基：**当力觉本身有偏置/漂移/饱和、接触模型本身错误时，CGG 会把「传感器/模型错误」误判为「几何幻觉」，力觉从接地真值变成新的单点故障与物理伤害源（A83）**。本轮不再寻找「更真的通道」，而是更换认识论：**接触真值不是一次测量，而是一场对话**。对话管理提供「在不确定下如何澄清、确认、修复、建立共同基础」的理论；力矩控制提供这场对话唯一**力有界、可逆、物理上不可伪造**的「发音器官」。核心命题：
>
> **把「接地」从一次性判定升级为「澄清—确认—修复—承诺」的多轮过程；只有 grounded 之后才允许高力矩承诺，而力矩包络保证「提问」与「承诺」都不会越过物理安全边界。**

## 0. 直觉与动机

**灵感 1（对话管理 → 残差不是判决，而是误听信号：CDM）**
直觉：人类对话在噪声、歧义、口误下依然可靠，不是因为耳朵完美，而是会**追问、复述确认、修复**。第 64 轮 CGG 把接触残差 e_t 直接判为「几何错了」——相当于一听到不理解就断定对方说错。可在对话里，同一句「没听懂」至少有四种来源：对方说错（几何幻觉）、我听错（传感器偏置）、我的语法模型错（接触模型错）、对方换了话题（真实接触变化）。**Contact Dialogue Manager（CDM）** 维护「失配来源」的信念并选择下一个对话行为，而不是单方面降级几何。

**灵感 2（对话管理 → 信念跟踪与澄清价值：CDST + EVC）**
直觉：对话状态跟踪（DST）维护槽位信念；这里槽位是 φ=(μ,k,c,m,接触位置)、接触模型 M、传感器标定 θ_s。**关键且可严格证明的洞见**：第 64 轮 APP 用 D-最优最大化参数 Fisher 信息，但「在同一接触构型下更用力地压」只能提高 φ 的精度，**无法区分「传感器偏置」与「几何偏差」**——二者在单一构型下线性混淆（引理 7）。真正的澄清必须**换一种问法**：换接触点、换抓取、换姿态，使几何误差在力旋量上留下不同签名。于是用**澄清期望价值 EVC** 选择动作：E[假设熵下降] + λ·参数信息 − 风险 − 回合成本。

**灵感 3（对话管理 → 共同基础、修复与混合主动：GRD）**
直觉：对话的「共同基础（common ground）」不是「我说了」，而是「双方都确认了」。定义**接触共同基础 CG_t**：被 ≥k 个**独立**证据通道（腕部 F/T、关节力矩、触觉、几何视觉、人类确认）相互印证且无矛盾的假设集合。**承诺门**：仅当接地后才允许不可逆/高力矩动作。**修复协议**：接地失败时回滚到上个接地检查点，按 probe → confirm → handover 逐级升级。**打断（barge-in）**：滑移/力限/人类急停优先抢占当前回合。

**灵感 4（力矩控制 → 力矩是对话的发音器官：WBTQ + TSE）**
直觉：在位置控制里，力只是「副产物」；要对世界提出一个「力有界的问题」，必须进入力矩/阻抗层。把每个对话行为实现为**力矩程序**，带硬包络 (τ_max, F_max, τ̇_max, T_max)。**全身力矩 QP（WBTQ）** 在关节力矩限、摩擦锥、动力学可行性下分配多接触力矩。**力矩谱探针（chirp/dither）** 是「频域里的提问」：小幅、高信息、天然比大力按压安全。更关键：第 64 轮 FCS 校验的是**规划后预测的力**；力矩包络在**执行器指令层**约束，扭矩饱和是物理真实、不可被模型误差越过（引理 8）——这把「预测安全」升级为「指令安全」。此外，**关节力矩传感**可感知整条连杆上的接触，弥补第 64 轮触觉的 sim-to-real 缺口。

**灵感 5（三灵感合流 → DIAL-TC 与组件原位升级）**
闭环：任务目标 → CDM/CDST 维护 b_t(h,φ,M,θ_s) 并选对话行为 → WBTQ 把行为合成力矩程序 → TSE 投影到硬包络 → 执行一个回合 → 观测 F/T、触觉、关节力矩 → 更新信念 → 若失配：分类来源/澄清/修复；若接地：允许 commit → 进入下一回合。

组件升级：
- **CGG → CGG-D**：残差是证据，更新 b_t，而非直接判决；降级只是「未接地」的一种后果。
- **APP → CAPP**：从「参数最优」升级为「来源可判别 + 参数最优」。
- **FCS → TSE**：从预测力限升级为执行器层力矩/力双包络。
- **WCV-F → WCV-D / CSP-F → CSP-D**：搜索域与技能边以 b_t 为条件，不可逆边加承诺门。
- **AIC-F → AIC-D**：干扰集增「假设集外/复合故障」，并认证「不接地即不承诺」。
- **J_grip → J_dial**：证书增对话状态、失配后验、接地状态、承诺日志、包络版本、共同基础通道。

## 1. 形式化定义（增量：定义 217–231）

- **定义 217（DIAL-TC 闭环）**：DIAL-TC = (GRIP, CDST, CDM, TDA, WBTQ, TSE, GRD, J_dial)。定位：GRIP 的「对话化」升级。不变式：**语义流做信念更新/澄清决策/修复/承诺裁决；实时流只做力矩程序前向、包络投影、barge-in 与派发；任何不可逆承诺必须在接地门通过后发出**。
- **定义 218（接触对话状态）**：b_t(h, φ, M, θ_s) 为 h∈H（失配来源）、φ（物理参数）、M（接触模型）、θ_s（传感器标定）的联合信念。贝叶斯更新 b_t ∝ p(o_t | h, φ, M, θ_s, a_{t−1})·∫T(·|a_{t−1})b_{t−1}；对话熵 H_t = H(b_t) = −Σ∫ b log b。
- **定义 219（失配源假设集与生成模型）**：H = {h_geo, h_sens, h_model, h_contact}：
  - h_geo：e_t = J_{C,t}δC + η_t（随接触构型变化、与力大小弱相关）；
  - h_sens：e_t = b + η_t，b 在传感器系恒定（跨构型不变）；
  - h_model：e_t = δ_m(f_t, φ) + η_t（随接触力幅值增长）；
  - h_contact：e_t = Δ·1[t ≥ t_c] + η_t（突变/变点）。
  一般混合 e_t = J_{C,t}δC + b + δ_m(f_t,φ) + Δ·1[t≥t_c] + η_t。
- **定义 220（力矩对话行为 TDA）**：A = {probe_press, probe_rub, probe_chirp, probe_recontact, confirm, repair, commit, yield, abort}。每个 a = (π_a, E_a, rev_a, cost_a)：π_a 生成期望接触旋量/阻抗轨迹；E_a = (τ_max, F_max, τ̇_max, T_max) 为硬包络；rev_a ∈ {True, False} 是否可逆；cost_a 为时间+能量+风险。
- **定义 221（WBTQ 力矩程序合成）**：给定行为 a、状态 (q,q̇)、参数 φ 与阻抗 (K,D,f_ff)，
  τ*_{0:T} = argmin Σ_t ‖τ_t − τ_t^imp‖²_W + λ_τ‖τ_{t+1}−τ_t‖²
  s.t. τ_min ≤ τ_t ≤ τ_max，|τ_{t+1}−τ_t| ≤ Δτ_max，f_t^c ∈ K_μ，‖J(q_t)^{−T}τ_t‖ ≤ F_max，
  M(q)q̈ + C(q,q̇)q̇ + g(q) = τ + J(q)ᵀf_ext；
  τ_t^imp = M̂q̈_d + Ĉq̇ + ĝ + Jᵀ(K_t e_t + D_t ė_t + f_t^ff)。
- **定义 222（TSE 力矩安全包络）**：ρ_torque = min_j(τ_max,j−|τ_j|, Δτ_max,j−|Δτ_j|, F_max−‖J^{−T}τ‖, F_lim−F̂_contact)。派发前若 ρ_torque<0 则投影到可行域；在 Jacobian 相对误差 ≤δ_J、接触模型误差 ≤δ_F 下保证 ‖f_actual‖ ≤ F_max/(1−δ_J)+δ_F。撞击段另加法向速度限 v_n ≤ v_max 使冲量 m·v_n 有界。
- **定义 223（失配源判别统计 MSC）**：在 m 个接触构型上取残差 {e_c}。定义构型间散度 S_b = Σ_c‖e_c−ē‖²、与力幅相关 r_f = corr(‖e_c‖, ‖f_c‖)、变点统计 CUSUM。判别矩阵 D = [(J_{C,1}−J_{C,2})ᵀ, …, (J_{C,m−1}−J_{C,m})ᵀ]ᵀ。后验 p(h|{e_c}) ∝ p(h)p({e_c}|h)，其中对数似然分别用「构型相关」「常量偏置」「力幅相关」「变点」模板。
- **定义 224（CAPP 澄清策略 / EVC）**：a* = argmax_{a∈A_adm} E[ΔH(h|o,a) + λ_I·ΔIG(φ|o,a) − λ_R·CVaR_α(risk(a)) − λ_C·cost(a)]，其中 A_adm = {a: E_a ⊆ 当前安全包络 ∨ rev_a=True}。停止条件：H(b_t) ≤ ε_H、预算耗尽、或剩余动作均不可逆且未接地（转 handover）。
- **定义 225（接地判据 / 承诺门）**：Ground(b_t) ⇔ H(b_t) ≤ ε_H ∧ P(h_sens|b_t)+P(h_model|b_t) ≤ ε_s ∧ ρ_torque ≥ 0 ∧ |support(CG_t)| ≥ k。Commit(a) 允许 ⇔ Ground(b_t) ∧ (rev_a ∨ human_confirm ∨ CG_t 相互印证)。
- **定义 226（修复协议 GRD）**：维护检查点栈 {(t_i, b_{t_i}, robot_state_i)}。¬Ground 时回滚到最近接地检查点，按「配置多样化 probe → 已知构型 confirm → yield/handover」逐级升级；记录 repair_log（触发源、回滚步数、升级级数、结果）。
- **定义 227（轮次与打断）**：安全事件（滑移、力限、人类急停、包络越界）优先级最高，立即抢占当前回合并置 barge_in=True；被抢占行为标记 incomplete，下一回合先 repair。
- **定义 228（接触共同基础）**：CG_t = {h: 至少 k 个**独立**通道支持 h 且无通道反对}。通道 = {腕部 F/T, 关节力矩, 触觉阵列, 几何视觉, 人类确认}。独立性要求失败模式不相关（如触觉与关节力矩不共享同一标定源）；矛盾出现即从 CG_t 撤回 h（可废止）。
- **定义 229（对话 POMDP 目标）**：π_dm: b ↦ a 最大化 E[Σ_t (r_task − λ_R·risk_t − λ_C·turn_cost_t)]，风险用 CVaR_α 约束；与 OLP 的在线策略共用特征，π_dm 只在语义流更新。
- **定义 230（WCV-D / CSP-D / AIC-D）**：WCV-D 搜索域 ∩ 由 b_t 诱导的可行集（如 P(h_sens) 高时放宽 φ 球、收紧力）；CSP-D 对不可逆技能边附加 Ground(b_t) 前提；AIC-D 干扰集 ℰ_D = ℰ_F × {out_of_set_fault, compound_fault}，要求「未接地不承诺」在最坏干扰下仍成立。
- **定义 231（J_dial 证书）**：J_dial = (J_grip, dialogue_state_hash, mismatch_posterior, grounding_status, commit_log_hash, torque_envelope_ver, repair_log_hash, channel_support, cvar_dial)。Valid ⇔ Valid(J_grip) ∧ 每次 commit 时 Ground(b_t) ∧ ρ_torque ≥ 0 ∧ 包络版本与执行器限值一致 ∧ commit_log 与执行轨迹一致 ∧ 未接地时的不可逆动作计数为 0。

```python
# CDST + MSC：信念更新与失配源判别（语义流）
def update(b, a_prev, obs, configs):
    e = [obs.W[c] - predicted_wrench(configs[c], b) for c in configs]
    S_b = between_config_scatter(e)           # 构型间散度
    r_f = corr([norm(x) for x in e], [norm(f) for f in obs.f])
    cp  = cusum_changepoint(e)
    logp = {
        'h_geo':     loglik_geo(e, configs, b)      + log_large(S_b),
        'h_sens':    loglik_const_bias(e)           + log_small(S_b),
        'h_model':   loglik_force_scaled(e, r_f),
        'h_contact': loglik_changepoint(cp),
    }
    b.h = softmax({h: logp[h] + log(b.h_prev[h]) for h in H})
    b.phi = bayes_update_phi(b, obs, configs)
    return b

# CAPP：澄清感知的主动探测（语义流；非 D-最优）
def choose_act(b, acts, safe_env, budget):
    best, best_score = None, -inf
    for a in acts:
        if not admissible(a, safe_env, b):       # 不可逆且未接地 → 跳过
            continue
        dH   = expected_entropy_reduction(b, a)  # 假设判别信息
        dIG  = expected_param_info(b.phi, a)     # 参数 Fisher 信息
        risk = cvar_risk(a, b, alpha=0.95)
        score = dH + LAM_I*dIG - LAM_R*risk - LAM_C*a.cost
        if score > best_score:
            best, best_score = a, score
    return best if best_score > 0 else None

# WBTQ + TSE：力矩程序合成与硬包络投影（实时只做投影/派发）
def synth_and_dispatch(act, q, qd, phi, K, D, f_ff, env, J, delta_J, tau_prev):
    tau_imp = M_hat(q)@qdd_d + C_hat(q,qd)@qd + g_hat(q) \
              + J.T @ (K@e + D@ed + f_ff)
    tau = solve_torque_qp(tau_imp, q, qd, env, J, phi)   # 限幅/摩擦锥/动力学
    tau, rho = project_envelope(tau, tau_prev, env, J, delta_J)
    if rho < 0:
        return COMPLIANT_RETREAT, rho, True              # barge-in / 修复
    dispatch_torque(tau)
    return tau, rho, False
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 7（失配源可辨识性 / 两次构型的必要性）**：e_c = J_{C,c}u + b + η_c。单构型下 (u,b) 线性混淆，**无法区分传感器偏置与几何误差**；需存在 c,c′ 使 (J_{C,c}−J_{C,c′})u ≠ 0。故「多轮、换配置的对话」是**可辨识性的必要条件**，而非工程偏好；D-最优 APP 在单构型上对来源判别增益可为 0。
- **引理 8（力矩包络的指令级硬安全）**：若派发前投影使 ‖J^{−T}τ‖ ≤ F_max/(1−δ_J) 且 |τ|≤τ_max，则在刚体接触、Jacobian 相对误差 ≤δ_J 下 ‖f_actual‖ ≤ F_max；扭矩饱和是执行器物理硬限，模型误差无法越过它（区别于第 64 轮预测力检查）。撞击需另加 v_n 限。
- **定理 7（澄清回合数与信息增益）**：若判别矩阵满秩且每个可行动作满足 ΔH(a) ≥ IG_min，则期望接地回合数 ≤ ⌈(H_0−ε_H)/IG_min⌉+1；贪心 EVC 下 H_N ≤ H_0·exp(−cN)。纯 D-最优对 (h_sens, h_geo) 的 ΔH 可为 0，故不能接地。
- **定理 8（承诺安全）**：若仅 Ground 时 Commit 且 ρ_torque≥0，则 P[承诺动作造成违规或损伤] ≤ P(假接地) + α_geo + α_sensor + α_model + α_torque，其中 α_torque 由引理 8 界定。与第 64 轮定理 6 相比，新增「假接地」项——这正是本轮最大风险所在。
- **定理 9（DIAL-TC 端到端）**：Valid(J_dial) ⇒ 每次承诺均接地 ∧ GRIP 四层安全成立 ∧ 力矩包络硬界成立 ∧ 对话轨迹可审计；传感器故障 → h_sens 升 → yield/handover；集外故障 → 熵不降 → 永不 commit、安全 idle。
- **命题（辨识-控制耦合 / 双环回路）**：物体质量/惯量既是被估参数 φ，又进入 WBTQ 动力学补偿；估参期用保守惯量上界 Î ≥ I_true 并限加速度，可保证共估收敛（收缩条件 ‖ΔÎ‖/Î ≤ γ 且阻抗增益低于稳定裕度）。
- **实时性**：CDST/MSC/CAPP 只在语义流（回合级）；实时流仅 TSE 投影 <0.05ms、WBTQ 前向 <0.3ms、barge-in 检查 <0.05ms、派发 <0.1ms，叠加 GRIP 实时路径仍在 2ms 契约内（A92）。

## 5. 本轮最大风险

**一句话**：对话层的安全依赖两个隐藏前提——失配源假设集 H 是封闭可枚举的、且「澄清探针」本身安全可逆；一旦真实故障在集外（复合/新颖接触模型），或澄清力矩探针在易损物/人身上成了伤害动作，接地门就会给出**虚假的接地证明**，让系统带着「已澄清」的自信去做不可逆的高力矩承诺，**把对话管理变成一种更精致的过度自信**。

# 第 65 轮产物 · 创新点清单 v4：DIAL-TC（Dialogue-managed Torque Control：接触对话状态跟踪 × 失配源判别 × 澄清感知主动探测 × 力矩对话行为 × 全身力矩 QP × 力矩安全包络 × 接地修复纪律）

> 承接第 64 轮 IP-204~213（GRIP：CGG×MWS×FPE×APP×TSL×SLD×FCS×RSC-F×OLP-F×WCV-F×CSP-F×AIC-F×J_grip）。第 64 轮把力觉当作几何先验的接地真值，但其最大风险是**力觉自身故障被误判为几何幻觉，力觉从真值变成单点故障与物理伤害源**。本轮不换传感器，而换认识论：**真值不是一次测量，而是一场对话**。用对话管理做信念跟踪、来源判别、澄清、确认、修复与共同基础；用力矩控制做**力有界、可逆、执行器级不可伪造**的「提问/承诺」通道。实现 **「残差可归因、提问可判别、承诺需接地、力矩有硬界」**。
>
> IP 编号：IP-214~IP-224（共 11 个），均为第 64 轮组件的原位升级或挂载式新增。

## 2. 形式化定义（完整版）

**定义 217（DIAL-TC 闭环）** DIAL-TC 是 GRIP 的对话化升级：在第 64 轮「语义流 ∘ 实时流」骨架上挂载 CDST（信念跟踪）、MSC（失配源判别）、CAPP（澄清感知探测）、TDA/WBTQ（力矩对话行为与全身力矩 QP）、TSE（力矩安全包络）、GRD（接地与修复），并原位升级 CGG→CGG-D、WCV-F→WCV-D、CSP-F→CSP-D、AIC-F→AIC-D、J_grip→J_dial。不变式：**信念更新、来源判别、澄清决策、修复与承诺裁决只在语义流；实时流只做 TSE 投影、WBTQ 前向、barge-in 检查与派发，零学习写操作；任何不可逆承诺必须先通过 Ground(b_t)。**

**定义 218（接触对话状态）** 令 h∈H 为失配来源、φ 为物理参数、M 为接触模型、θ_s 为传感器标定。接触对话状态为联合信念
b_t(h,φ,M,θ_s) ∝ p(o_t | h,φ,M,θ_s,a_{t−1}) ∫ T(φ,M,θ_s | a_{t−1}) b_{t−1}(h,φ,M,θ_s) dφ dM dθ_s。
对话熵 H_t = −Σ_h∫∫∫ b_t log b_t。回合 t 由一个对话行为 a_{t−1} 与其观测 o_t 构成。定义「接地」需要 H_t 足够低且失配源后验足够确定（定义 225）。

**定义 219（失配源假设集与生成模型）** H = {h_geo, h_sens, h_model, h_contact}，其中
- h_geo：e_t = J_{C,t}δC + η_t。几何偏差 δC 经接触雅可比映射，**随接触构型变化**、与力大小弱相关；
- h_sens：e_t = b + η_t。传感器偏置 b 在传感器系恒定，**跨构型不变**；
- h_model：e_t = δ_m(f_t,φ) + η_t。接触模型误差随接触力幅值/方向变化，**与 ‖f_t‖ 相关**；
- h_contact：e_t = Δ·1[t≥t_c] + η_t。真实接触变化表现为**变点/突变**。
一般情形为四者叠加。判别即在后验 p(h|{e_c}) 上做推断（定义 223）。

**定义 220（力矩对话行为 TDA）** 对话行为集
A = {probe_press(d,v), probe_rub(u,v,f_n), probe_chirp(A_m,f_0,f_1,T), probe_recontact(c′,d), confirm(c₀,f_test), repair(k), commit(τ_des), yield(), abort()}。
每个 a = (π_a, E_a, rev_a, cost_a)：π_a 生成期望接触旋量/阻抗轨迹；E_a = (τ_max,F_max,τ̇_max,T_max) 为不可越过的硬包络；rev_a ∈ {True,False} 表示是否可逆；cost_a 为时间/能量/风险成本。**关键**：probe_recontact（换接触点）与 probe_chirp（小幅扫频）是「换一种问法」的物理实现，用于来源判别；probe_press 只在参数精度不足时使用。

**定义 221（WBTQ 力矩程序合成）** 给定行为 a、状态 (q,q̇)、参数估计 φ̂、阻抗 (K,D,f_ff)，求解
τ*_{0:T} = argmin_{τ_{0:T}} Σ_t ‖τ_t − τ_t^imp‖²_W + λ_τ Σ_t ‖τ_{t+1}−τ_t‖²
s.t. τ_min ≤ τ_t ≤ τ_max，|τ_{t+1}−τ_t| ≤ Δτ_max，
f_t^c ∈ K_{μ̂}(n_t)，‖J(q_t)^{−T}τ_t‖ ≤ F_max，
M(q)q̈ + C(q,q̇)q̇ + g(q) = τ + J(q)ᵀf_ext，
其中 τ_t^imp = M̂(q)q̈_d + Ĉ(q,q̇)q̇ + ĝ(q) + Jᵀ(K_t e_t + D_t ė_t + f_t^ff)。QP 在实时流只做一次前向/投影（热启动），完整轨迹在语义流合成。摩擦锥由 φ̂ 的 μ̂ 及其置信区间给出，取最坏 μ_lo。

**定义 222（TSE 力矩安全包络）** 逐关节/逐接触定义
ρ_torque = min_j (τ_max,j − |τ_j|, Δτ_max,j − |Δτ_j|, F_max − ‖J^{−T}τ‖, F_lim − F̂_contact,j)。
派发前若 ρ_torque < 0，将 τ 投影到可行域（比例缩放/二次投影），并置 `torque_clipped=True`。**指令级保证**：在刚体接触与 Jacobian 相对误差 ≤δ_J 下，若 ‖Ĵ^{−T}τ‖ ≤ F_max/(1−δ_J)，则真实接触力 ‖f‖ ≤ F_max；接触模型误差再贡献 δ_F。撞击段额外约束法向接近速度 v_n ≤ v_max，使冲量 ≤ m_eff·v_max 有界。与第 64 轮 FCS 的区别：FCS 校验**规划预测力**，TSE 约束**实际派发力矩**，扭矩饱和是执行器物理硬限。

**定义 223（MSC 失配源判别统计）** 在 m 个（通常 2–4 个）不同接触构型上采集残差 {e_c}：
- 构型间散度 S_b = Σ_c‖e_c − ē‖²；若 S_b 大且可由 (J_{C,c}−J̄)δĈ 解释 → h_geo；
- 若 S_b 小且 ē ≠ 0（常量偏置）→ h_sens；
- 力幅相关 r_f = corr(‖e_c‖, ‖f_c‖)；r_f 显著 → h_model；
- 残差序列的 CUSUM 变点显著 → h_contact。
判别矩阵 D = [(J_{C,1}−J_{C,2})ᵀ, …, (J_{C,m−1}−J_{C,m})ᵀ]ᵀ。后验
p(h|{e_c}) ∝ p(h) ∏_c p(e_c | h)，各 h 用上面对应模板的对数似然。输出 (p(h|·), 判别置信度, 建议下一构型 c_next)。

**定义 224（CAPP 澄清感知主动探测）** 可行动作集 A_adm = {a ∈ A : E_a ⊆ 当前 TSE 安全包络 ∨ rev_a = True}。选择
a* = argmax_{a∈A_adm} [ E(ΔH(h|o,a)) + λ_I·ΔIG(φ|o,a) − λ_R·CVaR_α(risk(a)) − λ_C·cost(a) ]。
其中 ΔH 为失配源假设的期望熵下降（判别信息），ΔIG 为参数 Fisher 信息增益，risk 含力/损伤/不可逆风险。停止：H(b_t) ≤ ε_H、预算耗尽、或无正收益可逆动作（转 handover）。**与第 64 轮 APP 的本质差异**：D-最优等价于只保留 λ_I 项，因而会选「同构型更大力按压」；CAPP 的 ΔH 项强制选「换构型」的重接触/扫频，才能判别来源（引理 7）。

**定义 225（接地判据与承诺门）** 定义接地
Ground(b_t) ⇔ H(b_t) ≤ ε_H ∧ P(h_sens|b_t) + P(h_model|b_t) ≤ ε_s ∧ ρ_torque ≥ 0 ∧ |support(CG_t)| ≥ k。
承诺门：Commit(a) 允许 ⇔ Ground(b_t) ∧ (rev_a ∨ human_confirm ∨ CG_t 对关键槽位相互印证)。对不可逆动作（抓取后抬升、插入、按压易损物），若未接地则强制替换为可逆 probe/confirm 或 yield。定义「假接地」为 Ground 成立但真值 h* 不在高后验集内。

**定义 226（GRD 修复协议）** 维护检查点栈 {(t_i, b_{t_i}, robot_state_i, last_grounded)}。当 Ground 失败或发生 barge-in：
1. 回滚到最近 `last_grounded` 检查点（力矩层用记录的 q,q̇,τ_prev 平滑接管，避免回滚冲击）；
2. 若失配源后验指向特定槽位，插入针对性 probe（如 h_sens → 空载标定动作；h_geo → 换接触点重接触）；
3. probe 后仍不接地 → confirm（在已知构型做低力复核）；
4. 仍失败 → yield/handover（人类确认或安全 idle）。
记录 repair_log = (trigger, posterior, rollback_steps, escalation_level, outcome)。

**定义 227（轮次与打断）** 回合由 (a_t, o_t) 定义。安全事件（滑移、力限、包络越界、人类急停）具有最高优先级，立即抢占当前回合并置 barge_in=True；被抢占行为标记 incomplete，下一回合先执行 repair。打断不修改 b_{t−1} 的历史，只在其上叠加 `preempted` 标记，保证审计可追溯。

**定义 228（接触共同基础）** CG_t = {h : 至少 k 个相互独立通道支持 h 且无通道反对}。通道 = {腕部 F/T, 关节力矩, 触觉阵列, 几何视觉, 人类确认}。独立性要求失败模式不相关（触觉与关节力矩若共享标定源则不能算独立）。矛盾出现即从 CG_t 撤回 h（可废止推理）。**CG_t 是承诺门的强证据，但不是充分证据**（防止相关故障同时污染多通道）。

**定义 229（对话 POMDP 目标）** 对话策略 π_dm: b ↦ a 最大化
E[Σ_t (r_task(b_t,a_t) − λ_R·risk(b_t,a_t) − λ_C·turn_cost(a_t))]，s.t. CVaR_α(总损伤) ≤ ζ。
π_dm 可用规则（EVC）或风险敏感 RL 训练；与 OLP 共享特征，仅语义流更新，实时流冻结。回合成本含时间与人类交互负担，避免「过度提问」。

**定义 230（WCV-D / CSP-D / AIC-D）** 
- WCV-D：搜索域 B(φ̂,r) ∩ 𝒢(g) ∩ K(μ̂) ∩ ℱ(f_lim) 的权重由 b_t 调节——P(h_sens) 高时放宽几何强约束、禁止依赖几何的激进收缩；P(h_geo) 高时收缩几何权重 λ_geo。
- CSP-D：层级 A* 的技能边附加 `Ground(b_t) ∨ rev_σ` 前提；不可逆技能边未接地则不建边，规划可插入 probe/recontact 元技能。
- AIC-D：干扰集 ℰ_D = ℰ_F × {out_of_set_fault, compound_fault}；认证要求在最坏干扰下「未接地 ⇒ 不可逆动作为 0」，并在 out-of-set 时后验熵不降到阈值以下（即无法假接地）。

**定义 231（J_dial 证书）** J_dial = (J_grip, dialogue_state_hash, mismatch_posterior, grounding_status, commit_log_hash, torque_envelope_ver, repair_log_hash, channel_support, cvar_dial)。
Valid(J_dial) ⇔ Valid(J_grip) ∧ 每次 commit 时 Ground(b_t) ∧ ρ_torque ≥ 0 ∧ torque_envelope_ver 与执行器限值/ISO 版本一致 ∧ commit_log 与执行轨迹一致 ∧ 未接地时不可逆动作计数 = 0 ∧ repair_log 完整。审计链：dialogue_state_hash 追溯信念，mismatch_posterior 追溯归因，commit_log_hash 追溯每次承诺的接地证据，repair_log_hash 追溯修复路径。

### IP-214/215 CDST + MSC（信念更新与失配源判别）

```python
class ContactDialogueStateTracker:
    """维护 b_t(h,phi,M,theta_s)，用构型多样化残差判别失配来源。语义流。"""
    def __init__(self, eps_H=0.2, eps_s=0.1):
        self.eps_H, self.eps_s = eps_H, eps_s
        self.b = init_belief()                      # 均匀 h，phi 用 GRIP 先验

    def update(self, b, a_prev, obs, configs):
        # obs: 每构型 W_meas、f、触觉；configs: 接触点/姿态
        e = [obs.W[c] - predicted_wrench(configs[c], b) for c in configs]
        S_b = sum(norm(x - mean(e))**2 for x in e)          # 构型间散度
        r_f = corr([norm(x) for x in e], [norm(f) for f in obs.f])
        cp  = cusum_changepoint(e)
        logp = {
            'h_geo':     gauss_loglik(e, Sigma_w) + log_large(S_b),
            'h_sens':    const_bias_loglik(e, Sigma_w) + log_small(S_b),
            'h_model':   force_scaled_loglik(e, r_f, Sigma_w),
            'h_contact': changepoint_loglik(cp, Sigma_w),
        }
        b.h = softmax({h: logp[h] + log(b.h_prev[h]) for h in H})
        b.phi = bayes_update_phi(b, e, configs)             # Fisher 融合
        b.H = entropy(b)
        b.groundable = (b.H <= self.eps_H) and \
                       (b.h['h_sens'] + b.h['h_model'] <= self.eps_s)
        return b
```

### IP-216 CAPP（澄清感知主动探测）

```python
class ClarificationAwareProber:
    def choose_act(self, b, acts, safe_env, budget):
        best, best_score = None, -np.inf
        for a in acts:
            if not admissible(a, safe_env, b):      # 不可逆且未接地 → 排除
                continue
            dH   = expected_entropy_reduction(b, a)      # 判别 h 的信息
            dIG  = expected_param_info(b.phi, a)         # 参数 Fisher 信息
            risk = cvar_risk(a, b, alpha=0.95)
            score = dH + LAM_I * dIG - LAM_R * risk - LAM_C * a.cost
            if score > best_score:
                best, best_score = a, score
        if best_score <= 0:
            return None                                   # 转 yield/handover
        return best

    def preferred_config(self, b):
        # h_sens vs h_geo 混淆时，优先能最大化构型差 J_{C,c}-J_{C,c'} 的动作
        if b.h['h_geo'] > 0 and b.h['h_sens'] > 0:
            return 'probe_recontact'
        if b.h['h_model'] > 0:
            return 'probe_chirp'                          # 力幅扫描
        return 'probe_press'
```

### IP-217/218 WBTQ（力矩程序合成）

```python
def wbtq_synthesize(act, q, qd, phi_hat, K, D, f_ff, env, mu_lo):
    qdd_d, x_d, xd_d = act.traj(q, qd)                  # 行为级期望轨迹
    e, ed = x_d - x_meas(q), xd_d - xd_meas(q, qd)
    tau_imp = (M_hat(q) @ qdd_d + C_hat(q, qd) @ qd + g_hat(q)
               + J(q).T @ (K @ e + D @ ed + f_ff))
    # 二次规划：关节限/力矩限/摩擦锥/接触力限/动力学可行性
    tau = solve_qp(H=W, f=-W @ tau_imp,
                   A_ineq=[I, -I, dI, -dI],
                   b_ineq=[env.tau_max, -env.tau_min,
                           env.dtau_max, env.dtau_max],
                   contact_cone=mu_lo, F_max=env.F_max)
    return tau
```

### IP-219 TSE（力矩安全包络与投影）

```python
def project_envelope(tau, tau_prev, env, J, delta_J):
    F_est = norm(pinv(J.T) @ tau)
    rho = min(env.tau_max - norm(tau, np.inf),
              env.dtau_max - norm(tau - tau_prev, np.inf),
              env.F_max / (1 - delta_J) - F_est,
              env.F_lim - F_est)
    if rho < 0:
        tau = scale_to_feasible(tau, env, J, delta_J)   # 投影到可行域
        rho = 0.0
    return tau, rho
```

### IP-220 GRD（接地、承诺与修复）

```python
def grounding_gate(b, cg, rho_torque):
    return (b.H <= EPS_H and b.h['h_sens'] + b.h['h_model'] <= EPS_S
            and rho_torque >= 0 and len(cg.support) >= K_CG)

def decide_act(b, goal, acts, cg, rho_torque):
    if grounding_gate(b, cg, rho_torque):
        return commit_or_continue(goal, b)              # 允许高力矩承诺
    a = capp.choose_act(b, acts, tse.safe_env, budget)
    return a if a is not None else yield_or_handover()

def repair(b, checkpoints, reason):
    cp = checkpoints.last_grounded()                     # 回滚到上次接地
    smooth_takeover(cp.robot_state)                      # 力矩平滑接管，避免冲击
    a = targeted_probe(reason.posterior)                 # 针对性澄清
    if still_ungrounded(run(a)):
        a = confirm_at_known_config()
    if still_ungrounded(run(a)):
        return handover()
    return b
```

### IP-224 DIAL-TC 闭环算子

```python
def DIAL_TC_round(M, goal, obs):
    # ———— 语义流（回合级）————
    M.b = M.cdst.update(M.b, M.last_act, obs, M.config_history)
    M.cg = update_common_ground(M.channels)              # F/T/关节力矩/触觉/视觉/人
    if not grounding_gate(M.b, M.cg, M.rho_torque):
        M.last_act = M.capp.choose_act(M.b, M.acts, M.tse.safe_env, M.budget)
        if M.last_act is None:
            M.last_act = yield_or_handover()
        M.checkpoint.push(M.b)
    else:
        M.last_act = commit_or_continue(goal, M.b)

    tau_prog = M.wbtq.synthesize(M.last_act, M.q, M.qd, M.phi_hat,
                                 M.K, M.D, M.f_ff, M.tse.env, M.mu_lo)

    # ———— 实时流（逐 tick）————
    for tau in tau_prog:
        tau_s, rho = M.tse.project(tau, M.tau_prev, M.tse.env, M.J, M.delta_J)
        if rho <= 0 and M.tse.clipped:
            M.barge_in = True
            M.last_act = yield_or_handover()
            break
        M.ertc.dispatch_torque(tau_s)
        M.tau_prev = tau_s
    obs = wait_contact_and_observe()

    J_dial = build_j_dial(
        M.j_grip, dialogue_state_hash=hash(M.b),
        mismatch_posterior=M.b.h, grounding_status=grounding_gate(M.b, M.cg, rho),
        commit_log_hash=hash(M.commit_log), torque_envelope_ver=M.tse.ver,
        repair_log_hash=hash(M.repair_log), channel_support=M.cg.support,
        cvar_dial=M.cvar)
    return M, J_dial
```

## 4. 推导

**引理 7（失配源可辨识性 / 两次构型的必要性）** 在 m 个接触构型上，残差线性化为
e_c = J_{C,c} u + b + η_c，c = 1,…,m，
其中 u 为几何偏差（由假定表面与真实表面之差经接触雅可比映射），b 为传感器偏置（传感器系常量），η_c~N(0,Σ_w)。堆叠得
E = J u + (1_m ⊗ I₆) b + η，J = [J_{C,1};…;J_{C,m}]。
(u,b) 可辨识当且仅当 col(J) ∩ span(1_m ⊗ I₆) = {0}。当 m=1 时，col(J)=col(J_{C,1})⊆ℝ⁶ 与 span(I₆)=ℝ⁶ 必然相交，任何 u 都可通过 b ← −J_{C,1}u 吸收，**单一构型永远无法区分几何误差与传感器偏置**。一般地，需要存在两构型 c,c′ 使 (J_{C,c}−J_{C,c′})u ≠ 0，即几何误差在不同构型下留下**不同签名**。这解释了为何「多轮、换配置的对话」是可辨识性的必要条件，而非工程偏好；第 64 轮 D-最优 APP 在同一构型上最大化参数 Fisher 信息，可令 ΔH(h_geo,h_sens)=0，对来源判别完全无效。∎

**引理 8（力矩包络的指令级硬安全）** 设接触处力矩映射 τ = Jᵀ f（多接触时按接触集堆叠）。派发前用估计 Ĵ 投影使 ‖Ĵ^{−T}τ‖ ≤ F_max/(1−δ_J)，并保证 τ 在关节力矩限内。设 Ĵ 的相对奇异值误差 ≤δ_J，则 ‖f‖ = ‖J^{−T}τ‖ ≤ (1/(1−δ_J))‖Ĵ^{−T}τ‖ ≤ F_max。与第 64 轮 FCS 的差别在于：FCS 约束的是**预测力** F̂ = Φ(τ_plan, φ̂)，φ̂ 错则约束失效；TSE 直接约束**实际派发力矩 τ**，而关节力矩上限 |τ|≤τ_max 是执行器的物理饱和，任何模型误差都无法让执行器输出超过它。剩余风险来自三处：Jacobian/接触集误差（δ_J、δ_F）、撞击冲量（另加 v_n ≤ v_max 使冲量 m_eff·v_max 有界）、以及环境反力（被动柔顺/阻抗降低刚度）。故 HardBound：\n‖f_actual‖ ≤ F_max + δ_F + m_eff·v_max/τ_c，其中 τ_c 为接触时间常数。∎

**定理 7（澄清回合数与信息增益）** 设 b_t 在 H 上，H_t=H(b_t)。若判别矩阵 D 满秩（引理 7 条件满足）且每个可行动作满足 E[ΔH(a)] ≥ IG_min > 0，则贪心 EVC 策略的期望接地回合数
E[N_ground] ≤ ⌈(H_0 − ε_H)/IG_min⌉ + 1，
且 H_N ≤ H_0·exp(−cN)（c>0，由贪心选择的正信息增益给出）。反之，若只允许单构型动作，则由引理 7，h_geo 与 h_sens 不可分，ΔH=0，H_t 不降到 ε_H 以下，**永远无法接地**，系统只能 yield/handover。这给出「对话轮数—可接地性」的定量刻画：接地能力由构型多样性而非单纯力大小决定。∎

**定理 8（承诺安全 / commitment safety）** 设对话策略只在 Ground(b_t) 且 ρ_torque ≥ 0 时执行 Commit。设「假接地」概率 P_false = P(Ground(b_t) ∧ h* ∉ 高后验集)，传感器/模型/几何的大偏差概率分别为 α_sensor、α_model、α_geo，力矩包络失效概率上界 α_torque（由引理 8）。则
P[承诺动作造成违规或损伤] ≤ P_false + α_geo + α_sensor + α_model + α_torque。
证明：承诺伤害只可能发生在「接地门误判」或「包络/接触模型失效」两类事件之一；前者概率 P_false，后者由 GRIP 定理 6 与引理 8 的联合界控制。与第 64 轮定理 6 相比，新增了 P_false 项——这正是对话层引入的新故障面：**接地门本身可能给出虚假证明**。∎

**定理 9（DIAL-TC 端到端）** 在 A88–A92 下：
1. **可归因**：多构型 MSC 以 ≥1−α_m 区分 H 中来源（引理 7）。
2. **可澄清**：EVC 策略在 O(log|H|/IG_min) 回合内使 H_t ≤ ε_H（定理 7）。
3. **可承诺**：Valid(J_dial) ⇒ 每次承诺均接地且 ρ_torque≥0；承诺伤害概率 ≤ P_false + α_geo+α_sensor+α_model+α_torque（定理 8）。
4. **优雅降级**：传感器故障 → h_sens 升 → 回滚标定/换通道/handover；LiDAR 幻觉 → h_geo 升 → 重接触澄清；两者同时或集外故障 → 熵不降 → 永不承诺、安全 idle。
5. **实时性**：TSE 投影 + WBTQ 前向 + barge-in ≤0.5ms，叠加 GRIP 实时路径 ≤2ms（A92）。
故 Valid(J_dial) ⇒ 接地 ∧ 四层安全 ∧ 力矩硬界 ∧ 轨迹可审计。∎

**命题（辨识—控制耦合 / 双环回路）** 物体质量 m 与惯量 I 同时出现在待估参数 φ 与 WBTQ 动力学补偿 M̂ 中。估参期若用 Î < I_true，力矩补偿不足会导致接触力预测偏低、包络看似安全；若 Î > I_true 则过度补偿、接触力偏高。取保守上界 Î ≥ I_true 并限制激励加速度 ‖q̈‖ ≤ a_max，可保证 ‖f_actual‖ ≤ F_max + m_eff·a_max 在界内；当 lift 探针逐步增大加速度时，m/I 的后验收缩使 Î→I_true，形成「估计—控制」收缩。稳定条件：阻抗刚度 K 低于由 Î 误差界决定的稳定裕度 K_max(γ)，其中 γ=‖ΔÎ‖/Î。这构成本轮的真实工程张力：**安全要求保守惯量，辨识要求激进激励**。∎

## 7. 已知风险

**一句话**：对话层的安全依赖两个隐藏前提——失配源假设集 H 是封闭可枚举的、且「澄清探针」本身安全可逆；一旦真实故障在集外（复合/新颖接触模型），或澄清力矩探针在易损物/人身上成了伤害动作，接地门就会给出**虚假的接地证明**，让系统带着「已澄清」的自信去做不可逆的高力矩承诺，**把对话管理变成一种更精致的过度自信**（A88 是隐藏核心假设）。

**次级风险与缓解**：
1. **假设集外故障（A88 失效）**：真实故障不属于 H，后验会把概率质量挤到最接近的错误 h 上，熵下降 → 假接地。缓解：加「残差不可解释度」检测——若最佳 h 的似然仍低于绝对阈值，则判 `out_of_set`、强制不接地；AIC-D 显式认证该行为。
2. **澄清探针本身有害**：probe_recontact 可能在易损物/人身上施加超限力矩。缓解：A_adm 只允许 E_a ⊆ 安全包络或可逆行为；接触人/易损物的探针改用 chirp 小幅或非接触通道（关节力矩空载/视觉）；人类确认优先。
3. **假接地（定理 8 的 P_false）**：多通道相关故障可同时污染 F/T 与关节力矩。缓解：CG_t 要求通道独立性；关键承诺加人类确认；对 commit 做对抗性抽样认证。
4. **力矩/辨识耦合（命题）**：保守惯量上界使接触力估计偏高/偏低，影响包络。缓解：lift 探针在线收敛 Î；阻抗增益低于 K_max(γ)；撞击段限速。
5. **过度提问（over-asking）**：EVC 若风险/成本权重不当会频繁澄清，拖慢任务、惹恼人类。缓解：回合成本 λ_C、信任预算、人类拒绝即降权；E240 直接度量。
6. **回合延迟与实时性**：多构型澄清拉长任务；实时流仍必须 ≤2ms。缓解：澄清在语义流异步；实时流只做 TSE/WBTQ 前向；barge-in 硬优先。
7. **标准/几何不匹配（继承第 64 轮）**：TSE 的 F_lim 仍依赖 ISO/TS 15066 与接触几何假设。缓解：取最保守限值 + 现场标定 + 力矩硬截断兜底。
8. **可废止推理的连锁回滚**：共同基础被推翻时可能大面积回滚、抖动。缓解：检查点分粒度、回滚只回退受影响槽位、加迟滞阈值避免反复。
