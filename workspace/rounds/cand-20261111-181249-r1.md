# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「可靠性」×「数据配比」）

> 第 54 轮把技能组合推进到「动作空间剖面 α_S + 组合图 SCOM + 云边闭环 CEC + 动作-鲁棒性联合证书 J」。但整套体系默认了一个未被审计的地基：**ρ、A_cert、J 都是在一份隐含的数据配方上标定出来的**。本轮把这个地基显式化为 **数据配比 m**，追问：当训练/标定/评测数据的比例改变时，第 54 轮那些可靠性断言还剩多少有效性？核心矛盾：H22（配比相对性）：可靠性不是技能的内禀属性，而是数据配比 m 的函数，脱离 m 的 ρ 只是“某一份配方上的快照”；H23（配比裂缝）：两个技能各自可靠，但其数据支撑在单纯形上不相交，组合后的联合配比落在支撑外，产生负迁移；H24（云边配比失配）：云端全局配比 m_c 与边端局部配比 m_e 不同，云端证书在边端可能已越出有效域。

## 0. 直觉与动机

**灵感 1（可靠性是配比的函数，不是模型的属性）**
直觉：同一套策略在“室内+白天+硬地板”数据上可靠，在“室外+逆光+湿滑地面”上可能崩溃；只报一个平均可靠性，相当于只报一道菜的平均营养却不管配方比例。更准确的对象是 **可靠性响应面** `R_S(d|m)`：维度 d 的可靠性是数据配比 m 的函数。锚点上的 ρ 只是响应面上的一个切片，证书必须同时声明它所在的配比邻域。

**灵感 2（数据配比是可控的实验设计变量，不是日志的副产品）**
直觉：配比不是只能被动观测的协变量。给定采集/标注预算 B，可以主动选择 `m ∈ Δ^{K-1}`，在“最坏情形可靠性”上做稳健设计。配比也有边际收益递减与相互干涉：某一来源从 10% 加到 20% 可能显著提升鲁棒性，从 50% 加到 60% 却几乎无益，甚至稀释其他维度。因此需要 **配比弹性** `e_{d,k}(m)=∂logit R_S(d|m)/∂log m_k`，用它识别“该往哪个数据源加预算”。

**灵感 3（配比坐标让分布移位变得可估计、可通信）**
直觉：在原始高维观测空间估计分布移位很难，但在 K 个来源/域上的配比单纯形里，移位可以用一个低维向量 `Δm` 表达。边端不必上传原始数据，只需回传 **配比指纹**（域分类器后验、特征充分统计量或 MMD 投影），云端即可判断 `m_e` 是否落在证书支撑内。这把“分布移位”从不可操作的口号变成可预算、可回滚的工程量。

**灵感 4（组合技能 = 组合配比，组合处会出现“配比裂缝”）**
直觉：两个技能单独可靠，不代表把它们串起来可靠。若 S1 的可靠性主要来自 A 域数据，S2 主要来自 B 域数据，而联合标定/部署落在 A、B 之间的混合区，联合可靠性可能低于两者的最小值。定义 **配比干涉** `I_ij(m)=max(0, min(R_i,R_j)-R_{i⊗j})`：正干涉意味着组合产生额外退化，不能用 `min(ρ)` 掩盖。组合图必须增加“配比相容”这条边条件。

**灵感 5（云边配比契约：证书只在支撑球内有效）**
直觉：云端用全局配比 m_c 训练与发证，边端实际配比 m_e 可能偏移。合理的契约不是“证书复制下发”，而是 `C_mix=(m_c, U_c, φ_e, Δ_m, feedback)`：云端只承诺在歧义球 `U(m_c,ε)` 与支撑 `M_S` 的交集内成立；边端用 `φ_e` 估计 `m̂_e`；若 `dist(m̂_e,m_c)>Δ_m` 或交集为空，则 **拒绝部署 / 触发补采 / 重加权**，而不是带着空证书上线。

**灵感 6（可靠性-数据金字塔 𝔻）**
直觉：在第 54 轮的动作协同层 `𝔸` 之下再插入数据层 `𝔻`：`𝔻_0` 原始来源与许可，`𝔻_1` 域配比，`𝔻_2` 配比移位，`𝔻_3` 任务/技能配比。跨层证书从 `(ρ,A_cert)` 升级为 `(ρ,A_cert,M_cert)`：动作决定“能不能做”，配比决定“凭什么说它可靠”。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（来源单元、数据配比与有效支撑）**
设 K 个来源/域单元 `D_1,...,D_K`（具身、场景、传感器、任务、人类介入等）。数据配比 `m ∈ Δ^{K-1}`，`m_k = n_k / Σ_j n_j`。技能 S 的有效配比 `m_S` 由其训练、标定与边端日志的样本比例给出。定义其 **有效支撑**
```
M_S = closure{ m ∈ Δ^{K-1} : cover_cal(S,m) ≥ θ_sup }
```
其中 `cover_cal` 表示该配比邻域内每个可靠性维度都有足够标定样本。`m ∉ M_S` 时称证书 **出支撑（out-of-support）**。

**定义 122（可靠性响应面与配比弹性）**
技能 S 的可靠性响应面为 `R_S : 𝔇_ρ × Δ^{K-1} → [0,1]`，`R_S(d|m)` 表示在配比 m 下维度 d 的可靠度。锚点可靠性 `ρ_S(d)=R_S(d|m_S^0)`。在 Aitchison 几何下定义 **配比弹性**
```
e_{d,k}(m) = ∂ logit R_S(d|m) / ∂ log m_k
```
`e_{d,k}>0` 表示增加来源 k 提升维度 d；`<0` 表示稀释或负迁移。以全变差 `TV(m,m')=½Σ_k|m_k-m'_k|` 作为证书使用的配比距离。

**定义 123（配比相对可靠性证书）**
```
M_cert = (m_anchor, M_S, L_m, ε_est, δ_m, evidence)
```
其语义为：对任意 `m ∈ M_S` 且 `TV(m,m_anchor) ≤ ε_est`，
```
|R_S(d|m) - R_S(d|m_anchor)| ≤ L_m · TV(m,m_anchor)   ∀ d
```
`L_m` 为响应面的配比 Lipschitz 常数（可由标定集或 GP 后验给出）。部署条件：
```
m̂_e ∈ M_S  ∧  L_m·(TV(m̂_e,m_anchor)+ε_est) ≤ δ_m  ∧  R_S^-(d|m̂_e,ε_est) ≥ ρ_min ∀d
```
其中 `R^-` 为定义 125 的歧义球下界。缺少任一条，`M_cert` 只是“锚点快照”，不得作为部署证据。

**定义 124（配比相容性与组合干涉）**
两技能 `S_i,S_j` 的配比相容性由三元组刻画：
```
Ω(S_i,S_j) = vol(M_{S_i} ∩ M_{S_j}) / vol(M_{S_i} ∪ M_{S_j})
D_m(S_i,S_j) = TV(m_{S_i}^0, m_{S_j}^0)
```
在联合配比 m 下的 **组合干涉**
```
I_ij(m) = max(0, min(R_{S_i}(d|m), R_{S_j}(d|m)) - R_{S_i⊗S_j}(d|m))
```
组合边可行当且仅当
```
Ω ≥ θ_Ω  ∧  D_m ≤ τ_m  ∧  I_ij(m) ≤ η  ∧  R_{S_i⊗S_j}(d|m) ≥ ρ_min ∀d
```
这把第 54 轮的 `compat(α)` 扩展为 **动作相容 × 配比相容 × 干涉可控** 的三重判定。

**定义 125（云边配比契约与歧义球）**
云边配比契约 `C_mix = (m_c, U_c, φ_e, Δ_m, feedback)`：
- `m_c` 云端锚点配比；`U_c = {m ∈ Δ^{K-1} : TV(m,m_c) ≤ ε_c} ∩ M_S` 为云端承诺的歧义球；
- `φ_e : 边端数据 → m̂_e` 为配比指纹估计器，只需上传低维充分统计量；
- `Δ_m` 为允许的配比失配预算，`feedback` 触发重加权/补采/拒绝。
**配比稳健下界**：
```
R_S^-(d|m0,ε) = inf_{m ∈ U(m0,ε) ∩ M_S} R_S(d|m)
```
若 `U(m0,ε) ∩ M_S = ∅`，定义 `R^- = -∞`（证书为空，必须拒绝）。

**定义 126（可靠性-数据联合证书与稳健配比设计）**
联合证书 `J⁺ = (J, M_cert, m̂_e, ε_est, δ_m, R^-)`：在第 54 轮 `J=(ρ,A_cert,γ_ce,δ_a)` 上叠加数据配比证据。仅当 `J` 的动作条件与 `M_cert` 的配比条件同时满足时，`dom_{J⁺}(T)=in`。给定采集/标注预算 B 与单位成本 `c(m)`，稳健配比设计目标为
```
m* = argmax_{m ∈ Δ^{K-1}, c(m) ≤ B}  min_{d ∈ 𝔇_ρ}  R_{S_set}^-(d|m, ε)
```
多技能时 `R_{S_set}` 取组合链在配比 m 与干涉上界 η 下的最坏可靠性。

## 2. 关键算法 伪代码

### IP-121 MRS（Mixture Response Surface）

```python
def fit_mixture_response(data_by_mix, dims, kernel='gp_ilr'):
    # data_by_mix: [(m, d, n_success, n_total)]
    X = [ilr_transform(m) for m,_,_,_ in data_by_mix]   # Aitchison 坐标
    surfaces = {}
    for d in dims:
        y = [logit(success/total) for _,dd,success,total in data_by_mix if dd==d]
        surfaces[d] = GPRegressor(kernel).fit(X, y)      # 均值 + 后验方差
    return surfaces

def mixture_lipschitz(surfaces, grid, eps=1e-3):
    # 在单纯形网格上估计 max |R(m)-R(m')| / TV(m,m')
    L = {d: max_local_ratio(s, grid, eps) for d, s in surfaces.items()}
    return max(L.values())

def active_mix_query(surfaces, budget, target_dims, cost):
    # 选择使最坏维度后验方差下降最多的配比
    best, best_gain = None, -1
    for m in simplex_candidates(resolution=0.05):
        if cost(m) > budget: continue
        gain = min_d(posterior_std(surfaces[d], m) for d in target_dims)
        if gain > best_gain: best, best_gain = m, gain
    return best
```

### IP-122 MRC（Mixture-Robust Certificate）

```python
def mixture_robust_certificate(skill, m_anchor, dims, eps_c, delta_m, rho_min):
    M_S = skill.mixture_support                    # 标定覆盖得到的支撑
    L_m = estimate_lipschitz(skill.surfaces, M_S)
    # 歧义球与支撑求交；空则直接拒绝
    U = intersect(TV_ball(m_anchor, eps_c), M_S)
    if U.is_empty():
        return ('reject', 'out_of_support', m_anchor)
    lower = {}
    for d in dims:
        lower[d] = min(skill.surfaces[d].lower_bound(m, beta=1.96) for m in U.sample())
    if min(lower.values()) < rho_min:
        return ('reject', 'robust_reliability_fail', lower)
    if L_m * (eps_c + skill.eps_est) > delta_m:
        return ('reject', 'mixture_budget_exceeded', L_m)
    return ('ok', MixtureCert(m_anchor, M_S, L_m, lower))
```

### IP-123 MDO（Mixture Design Optimization）

```python
def robust_mixture_design(skills, dims, budget, cost_fn, eps):
    m = uniform_mixture(len(dims_sources))
    for t in range(T):
        # Frank-Wolfe 方向：对最坏维度做内层对抗选择
        d_worst = argmin_d(robust_lower(skills, d, m, eps))
        s = frank_wolfe_direction(m, grad_worst(skills, d_worst, m))
        step = line_search(m, s, budget, cost_fn)
        m = project_simplex(m + step * s)
        if converged(m): break
    return m
```

### IP-124 MIA（Mixture Interference Audit）

```python
def mixture_interference(audit_pairs, dims, path_samples=8):
    report = {}
    for (S_i, S_j) in audit_pairs:
        inter = {}
        for d in dims:
            for m in interpolate(m_S_i, m_S_j, path_samples):
                r_min = min(R(S_i,d,m), R(S_j,d,m))
                r_comp = R(compose(S_i,S_j), d, m)
                inter[(d,m)] = max(0.0, r_min - r_comp)
        report[(S_i,S_j)] = InterferenceReport(
            Omega=overlap(M_S_i, M_S_j),
            D_m=TV(m_S_i, m_S_j),
            I=max(inter.values()))
    return report
```

### IP-125 CEM（Cloud-Edge Mixture feedback）

```python
def edge_fingerprint(edge_stream, domain_classifier):
    counts = domain_classifier.predict_proba_batch(edge_stream).mean(axis=0)
    m_hat = project_simplex(counts)
    return m_hat, sufficient_statistics(edge_stream)   # 低维、可隐私化

def cloud_mixture_gate(m_c, U_c, m_hat, eps_est, Delta_m):
    if TV(m_hat, m_c) <= Delta_m and m_hat in U_c:
        return ('accept', m_hat)
    if U_c.is_empty() or TV(m_hat, m_c) > 2 * Delta_m:
        return ('reject_reprofile', m_hat)              # 越界过远，重配比/补采
    return ('reweight_or_collect', importance_weights(m_hat, m_c))
```

### IP-126 RDC（Reliability-Data joint Certificate）

```python
def joint_reliability_data_cert(skill_seq, action_J, m_hat, eps_est, config):
    # 1) 动作维度沿用第 54 轮
    if action_J.status != 'ok': return ('reject','action_fail')
    # 2) 配比维度
    mix = mixture_robust_certificate(skill_seq, m_hat, config.dims,
                                     config.eps_c, config.delta_m, config.rho_min)
    if mix.status != 'ok': return ('reject', 'mixture_fail', mix.reason)
    # 3) 干涉维度
    inter = mixture_interference([(a,b) for a,b in pairs(skill_seq)], config.dims)
    if max(r.I for r in inter.values()) > config.eta:
        return ('reject','interference_fail', inter)
    # 4) 联合
    rho_joint = combine(mix.lower, action_J.rho, inter)
    if min(rho_joint.values()) < config.rho_min:
        return ('reject','joint_reliability_fail', rho_joint)
    return ('ok', ReliabilityDataCert(action_J, mix, rho_joint, m_hat))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| MRS | O(N·K + K³) | O(N·K) | 响应面可辨识、标定覆盖充分 |
| MRC | O(|𝔇_ρ|·|U|·K) | O(|𝔇_ρ|·|U|) | 支撑判定 sound、Lipschitz 上界 |
| MDO | O(T·(|U|·K + K·|S|)) | O(K·|S|) | 内层最坏情形可解、预算闭合 |
| MIA | O(|S|²·|𝔇_ρ|·K·P) | O(|S|²) | 干涉非负、路径覆盖锚点间 |
| CEM | O(K·B + K log K) | O(K) | 指纹无偏、失配门限单调 |
| RDC | O(|S|·|𝔇_ρ|·K) | O(|S|·|𝔇_ρ|) | 动作-配比-干涉三证合取 |

**正确性定理（Mixture-Relative Reliability Soundness）**
假设第 54 轮 (A26)–(A28) 成立，并新增：
**(A29)** 对每个 d，`R_S(d|·)` 在 `M_S` 上以 `L_m` 关于 TV 是 Lipschitz 的，且响应面后验有覆盖率 `1-β_m`；
**(A30)** 边端配比指纹误差 `TV(m_e,m̂_e) ≤ ε_est`，以概率 `1-β_e` 成立；
**(A31)** 在锚点间配比路径上，组合干涉 `I_ij(m) ≤ η`；
**(A32)** 云边契约的失配预算满足 `L_m(ε_c+ε_est) ≤ δ_m`，且 `m̂_e ∈ M_S` 经边端独立核验。
则对任意部署配比 `m_e` 与维度 d，
```
R_{S_i⊗S_j}(d|m_e) ≥ min(ρ_{S_i}(d), ρ_{S_j}(d)) - L_m·(TV(m̂_e,m_anchor)+ε_est) - η
```
且部署成功概率
```
P_success ≥ 1 - Σ_d (1-ρ_min(d)) - L_m·(ε_c+ε_est) - η - β_m - β_e - β_E
```
关键点：**锚点可靠性减去配比移位上界再减去干涉上界，才是可部署的下界**；当 `U∩M_S=∅` 时该下界不成立，证书必须为空。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 响应面在未采样配比处外推失真 | 高 | 只信支撑内证书 + GP 后验下界 + 主动补采 |
| 配比与数据量/质量混杂，`L_m` 被低估 | 高 | 分层标定 + 剂量-响应对照 + 留一来源验证 |
| 边端配比指纹有偏（域分类器偏置） | 高 | 多指纹交叉校验 + 保形预测 + 锚点重标定 |
| 干涉审计组合爆炸 | 中 | 只审邻接边 + Shapley 近似 + 分层剪枝 |
| 配比优化过拟合代理指标（Goodhart） | 高 | 最坏情形目标 + 留出配比红队 + 证书拒绝权 |
| 单纯形 K 过大导致支撑稀薄 | 中 | 来源合并/层级化 + 低维充分统计量 |

## 6. 本轮最大风险

**一句话**：把可靠性降格为数据配比的响应面，能把“这份 ρ 到底凭什么成立”变成可审计、可通信的证书，但响应面只在被采样过的单纯形区域可辨识，一旦优化器把配比推到支撑边缘、或 `L_m` 与边端指纹误差被低估，证书就会变成“纸面可靠、配比出界”的假安全，故必须以 **支撑内证书 + 后验下界 + 出支撑即拒绝** 为硬约束，宁可少发证，也不把未采样配比上的外推当作可靠性。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-ReliData（MRS×MRC×MDO×MIA×CEM×RDC）

> 承接第 54 轮产物 v31（v16+++ / GroundEdge-GenSim+++）。本轮在「动作空间 + 鲁棒性 + 云边协同」之上补上被默认掉的地基：**数据配比**。核心升级是把可靠性 `ρ` 从技能属性变为 **配比相对响应面** `R_S(d|m)`，并让每张证书携带其有效配比支撑 `M_S` 与移位预算 `δ_m`。
>
> - **MRS（Mixture Response Surface）**：拟合 `R_S(d|m)`，给出配比弹性与 Lipschitz 上界；
> - **MRC（Mixture-Robust Certificate）**：在歧义球 × 支撑交集上计算稳健可靠性下界；
> - **MDO（Mixture Design Optimization）**：预算约束下的最坏情形配比设计；
> - **MIA（Mixture Interference Audit）**：检测组合技能的配比干涉 `I_ij`；
> - **CEM（Cloud-Edge Mixture feedback）**：边端配比指纹回传 + 云端配比门控；

## 1. 符号体系增量（新增定义 121–126）

| 符号 | 含义 |
|---|---|
| `m ∈ Δ^{K-1}` | 数据配比：K 个来源/域单元上的比例向量 |
| `m_S` | 技能 S 的有效配比 |

## 2. 关键算法 伪代码

### IP-121 MRS

```python
def fit_mixture_response(data_by_mix, dims):
    X = [ilr_transform(m) for m,_,_,_ in data_by_mix]
    surfaces = {}
    for d in dims:
        y = [logit(s/n) for _,dd,s,n in data_by_mix if dd == d]
        surfaces[d] = GPRegressor(kernel='matern').fit(X, y)
    return surfaces

def mixture_elasticity(surface_d, m, h=1e-3):
    base = logit(surface_d.mean(m))
    return {k: (logit(surface_d.mean(perturb(m,k,+h)))
                - logit(surface_d.mean(perturb(m,k,-h)))) / (2*h)
            for k in range(len(m))}

def estimate_lipschitz(surfaces, M_S, grid):
    return max(max(abs(s(m) - s(m2)) / max(TV(m,m2), 1e-9)
                   for m in grid for m2 in neighbors(m, grid))
               for s in surfaces.values() if m in M_S)
```

### IP-122 MRC

```python
def mixture_robust_certificate(skill, m_anchor, dims, eps_c, delta_m, rho_min):
    M_S = skill.mixture_support
    U = intersect(TV_ball(m_anchor, eps_c), M_S)
    if U.is_empty():
        return ('reject', 'out_of_support')
    L_m = estimate_lipschitz(skill.surfaces, M_S, simplex_grid())
    lower = {d: min(skill.surfaces[d].lower_bound(m, beta=1.96)
                    for m in U.sample(n=256)) for d in dims}
    if min(lower.values()) < rho_min:
        return ('reject', 'robust_reliability_fail', lower)
    if L_m * (eps_c + skill.eps_est) > delta_m:
        return ('reject', 'mixture_budget_exceeded', L_m)
    return ('ok', MixtureCert(m_anchor, M_S, L_m, lower))
```

### IP-123 MDO

```python
def robust_mixture_design(skill_set, dims, budget, cost_fn, eps):
    m = uniform_mixture(K)
    for _ in range(T):
        d_worst = min(dims, key=lambda d: robust_lower(skill_set, d, m, eps))
        g = subgradient_worst(skill_set, d_worst, m, eps)
        s = frank_wolfe_direction(m, g)
        m = project_simplex(m + line_search(m, s, budget, cost_fn) * s)
    return m
```

### IP-124 MIA

```python
def mixture_interference(S_i, S_j, dims, path_n=8):
    I = {}
    for d in dims:
        for m in interpolate(m_S_i, m_S_j, path_n):
            I[(d,m)] = max(0.0, min(R(S_i,d,m), R(S_j,d,m))
                            - R(compose(S_i,S_j), d, m))
    return {'Omega': overlap(M_S_i, M_S_j),
            'D_m': TV(m_S_i, m_S_j),
            'I': max(I.values()) if I else 0.0}
```

def edge_fingerprint(stream, domain_clf):

def cloud_mixture_gate(m_c, U_c, m_hat, eps_est, Delta_m):
    if U_c.is_empty() or TV(m_hat, m_c) > 2*Delta_m:
        return ('reject_reprofile', m_hat)
    if TV(m_hat, m_c) <= Delta_m and m_hat in U_c:
        return ('accept', m_hat)
    return ('reweight_or_collect', importance_weights(m_hat, m_c))

### IP-126 RDC

```python
def joint_reliability_data_cert(skill_seq, action_J, m_hat, eps_est, cfg):
    if action_J.status != 'ok':
        return ('reject', 'action_fail')
    mix = mixture_robust_certificate(skill_seq, m_hat, cfg.dims,
                                     cfg.eps_c, cfg.delta_m, cfg.rho_min)
    if mix.status != 'ok':
        return ('reject', 'mixture_fail', mix.reason)
    inter = [mixture_interference(a, b, cfg.dims) for a, b in pairs(skill_seq)]
    if max(x['I'] for x in inter) > cfg.eta:
        return ('reject', 'interference_fail', inter)
    rho = {d: min(mix.lower[d],
                  action_J.rho[d]) - max(x['I'] for x in inter)
           for d in cfg.dims}
    if min(rho.values()) < cfg.rho_min:
        return ('reject', 'joint_fail', rho)
    return ('ok', ReliabilityDataCert(action_J, mix, rho, m_hat))
```

## 3. 推导与反例

### 3.1 为什么“锚点可靠性”会骗人（二域反例）

设 K=2，来源 A、B。两个技能在自然配比 `m=(0.8,0.2)` 上锚点可靠性几乎相同：

| 技能 | R_A | R_B | R(0.8,0.2) | R(0.2,0.8) | R(0,1) |
|---|---|---|---|---|---|
| S1 | 0.90 | 0.90 | 0.900 | 0.900 | 0.900 |
| S2 | 0.99 | 0.50 | 0.892 | 0.598 | 0.500 |

若只按锚点 `ρ≈0.9` 选择 S2，则在 B 主导的边端配比上，其可靠性跌到 0.5–0.6，而 S1 保持 0.9。**同样的 ρ，不同的配比敏感度**。因此第 54 轮的 `min(ρ)` 组合规则在配比移位下不 sound，必须改为 `min(R(d|m)) - I - L_m·TV`。

### 3.2 移位上界为何必须显式给 `L_m`

对 S2 取锚点 `m0=(0.8,0.2)`，若证书只声明 `R(m0)=0.892` 而配比移到 `m=(0.2,0.8)`，真实下降约 0.294。若标定集只覆盖 A 主导区域并低估 `L_m≈0.3`，则预测下界为 `0.892 - 0.3×0.6 = 0.712`，仍显著高于真实的 0.598。**低估 `L_m` 会制造假安全**，所以 `L_m` 必须由跨来源留一验证与后验上界给出，而不是由锚点附近局部差分外推。

### 3.3 组合干涉的路径判据

两个技能沿插值路径 `m(t)=(1-t)m_{S_i}+t m_{S_j}` 联合标定。若 `I_ij(m(t))` 在中间 `t∈(0.2,0.8)` 出现峰值，说明两侧各自可靠、中间区域退化，即“配比裂缝”。审计只需在路径上取 8–16 个点，即可把 `I_ij` 的上界纳入组合图边权。

## 4. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| MRS | O(N·K + K³) | O(N·K) | 响应面可辨识、标定覆盖充分 |
| MRC | O(|𝔇_ρ|·|U|·K) | O(|𝔇_ρ|·|U|) | 支撑判定 sound、`L_m` 上界 |
| MDO | O(T·(|U|·K + K·|S|)) | O(K·|S|) | 最坏情形可解、预算闭合 |
| MIA | O(|S|²·|𝔇_ρ|·K·P) | O(|S|²) | 干涉非负、路径覆盖锚点间 |
| CEM | O(K·B + K log K) | O(K) | 指纹无偏、失配门限单调 |
| RDC | O(|S|·|𝔇_ρ|·K) | O(|S|·|𝔇_ρ|) | 动作-配比-干涉三证合取 |

**正确性定理（Mixture-Relative Reliability Soundness）**
假设第 54 轮 (A26)–(A28) 成立，并新增：
**(A29)** `R_S(d|·)` 在 `M_S` 上以 `L_m` 关于 TV Lipschitz，后验覆盖率 `1-β_m`；
**(A30)** `TV(m_e,m̂_e) ≤ ε_est` 以概率 `1-β_e`；
**(A31)** 组合路径上 `I_ij(m) ≤ η`；
**(A32)** `L_m(ε_c+ε_est) ≤ δ_m` 且 `m̂_e ∈ M_S` 经独立核验。
则
```
R_{S_i⊗S_j}(d|m_e) ≥ min(ρ_{S_i}(d),ρ_{S_j}(d)) - L_m(TV(m̂_e,m_anchor)+ε_est) - η
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - L_m(ε_c+ε_est) - η - β_m - β_e - β_E
```
若 `U(m_anchor,ε_c) ∩ M_S = ∅`，则 `R^-=-∞`，证书为空，必须拒绝。**这三条（支撑内、后验下界、干涉上界）是本轮 soundness 的全部承重墙。**

## 7. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 响应面在未采样配比处外推失真 | 高 | 只信 `M_S` 内证书 + GP 后验下界 + 主动补采 |
| 配比与数据量/质量混杂，`L_m` 被低估 | 高 | 剂量-响应对照 + 分层标定 + 留一来源验证 |
| 边端指纹偏置（域分类器偏置） | 高 | 多指纹交叉校验 + 保形预测 + 锚点重标定 |
| 干涉审计组合爆炸 | 中 | 邻接边优先 + Shapley 近似 + 分层剪枝 |
| 配比优化过拟合代理指标（Goodhart） | 高 | 最坏情形目标 + 留出配比红队 + 证书拒绝权 |
| 单纯形 K 过大导致支撑稀薄 | 中 | 来源合并/层级化 + 低维充分统计量 |

## 8. 本轮最大风险

**一句话**：把可靠性降格为数据配比的响应面，能把“这份 ρ 到底凭什么成立”变成可审计、可通信的证书，但响应面只在被采样过的单纯形区域可辨识，一旦优化器把配比推到支撑边缘、或 `L_m` 与边端指纹误差被低估，证书就会变成“纸面可靠、配比出界”的假安全，故必须以 **支撑内证书 + 后验下界 + 出支撑即拒绝** 为硬约束，宁可少发证，也不把未采样配比上的外推当作可靠性。
