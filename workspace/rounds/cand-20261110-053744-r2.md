# 第 41 轮 · 双灵感落地 v8：多机证书合成 × 可认证视觉伺服交接 × 车队评测基准（四层架构 v6）

> 承接第 40 轮（v17：可认证流匹配执行 × 度量语义几何锚定 × 证书驱动课程引擎，四层架构 v5）。本轮灵感词「多机评测、视觉伺服」驱动设计聚焦于**证书体系两个此前被默认掉的边界**：空间上的「他者」与时间上的「闭环末端」。第 40 轮的证书是「单机、开环轨迹、单次评估」的；本轮把它推广为**可组合的多机 assume-guarantee 契约**，并用视觉伺服的经典收敛理论补齐「最后厘米」的闭环证明。

## 0. 直觉与动机

**灵感 1（多机评测 → 证书必须从「单元测试」升格为「集成测试」）**：第 40 轮的证书隐含假设「世界是静态的、其他机器人不存在」。真实车队里，其他机器人既不是静态障碍，也不是普通动态障碍，而是**各自带着不确定球与自身保证的证书持有者**。于是多机评测的真问题不是「每台机器人各自成功率多少」，而是「整个系统能否在任意时刻**同时**守住所有成员的证书」。这需要三样单机体系没有的东西：a) 一个**相对位姿不确定球 B_ij**，让机器人 i 只在信任域内采信 j 的保证（否则 j 的 h_min 对 i 毫无意义）；b) 一套 **assume-guarantee 合成规则**，把「i 的安全以 j 的保证为前提」变成可检查的契约，并用**小增益条件**排除「i 依赖 j、j 又依赖 i」的环形空转；c) 一个**跨具身迁移因子**——同一技能的证书搬到不同机型（连杆、执行器、相机）会退化，评测必须报告这种退化而不是假装没有。多机评测因此应当是可组合的、带迁移因子的，且报告**联合证书覆盖率**而非单机平均。

**灵感 2（视觉伺服 → 用经典定理补上「最后厘米」）**：v17 认证的是学习策略的**开环 ODE 轨迹**，但抓取、插入、交接这些末端阶段由视觉误差而非采样误差主导。视觉伺服给出一个远比全局 Lipschitz 界紧的局部定理：图像误差满足 ė = −λ L_s L̂_s⁺ e + 模型误差，在深度区间、标定误差、时延裕度内指数收敛；交互矩阵 L_s 精确刻画了「图像误差→相机速度」的耦合。三个直接收益：a) 终端控制器有了**局部且模型化**的证书，不再被整条轨迹的全局保守界拖累；b) 形成**交接契约**——流策略只需把误差送进伺服的认证吸引域，全局证书因此可以放松；c) 互观测视觉伺服（机器人看彼此的标定板/特征）天然给出相对位姿界，正好喂给多机合成。

**灵感 3（耦合 → 三者成环，证书从单机属性变成分布式不变量）**：多机需要「信任他者」的几何量，视觉互观测给出 B_ij；多机又是视觉伺服最严酷的测试场——遮挡、共享视野、特征竞争都会让可见性裕度变负。于是三者成环：视觉伺服提供**局部闭环与相对锚点** → 多机合成把这些锚点组成**联合证书** → 车队评测暴露联合证书失效的地带并回馈课程引擎（IP-50）。证书不再是一份单机文档，而是一个**可组合、可评测、可迁移的分布式不变量**。

## 1. 形式化定义

**定义 27（多机 assume-guarantee 证书契约）**：设车队有 N 个技能实例，第 i 个的契约 C_i^{AG} = (A_i, G_i)，其中保证 G_i ⊆ CertBundle_i（含流证书 CertFlow_i、度量语义类型 C_ms,i、有效域 ValidRegion_i、最小安全边际 m_i），假设 A_i 是对他者与环境的前提。干扰图 E 连接共享可达域的机器人对。定义**成对干扰屏障**
h_ij(x_i,x_j) = ‖p_i−p_j‖ − (r_i+r_j) − B_ij − B_i^self − B_j^self，
其中 B_ij 为相对位姿不确定球（定义 28），B_i^self 为自定位漂移球（第 40 轮 B_t）。
**合成算子 ⊗**：若 ∀i，A_i 被 {G_j}_{j∈N(i)} 满足，且每个环形依赖满足**小增益条件** ∏_{(i,j)∈cycle} γ_ij < 1（γ_ij 为 j 的保证扰动经干扰通道放大到 i 假设的增益），则联合执行满足 ⋀_i G_i，联合有效域
V_⊗ = ⋂_i V_i^{multi} ∩ ⋂_{(i,j)∈E} {h_ij ≥ 0}。
**定理（合成可靠性）**：若每个单机契约可靠、B_ij 以概率 1−δ 覆盖真实相对位姿、且所有环满足小增益，则联合证书以概率 ≥ 1−Nδ 成立。

**定义 28（互观测相对位姿界与信任域）**：机器人 i 观测 j 的标定板/语义特征得到量测 T̂_ij 及协方差；双向观测用协方差交叉（CI）融合：
Σ_ij^{-1} = ω Σ_i^{-1} + (1−ω) Σ_j^{-1}，ω∈[0,1]。
定义 B_ij(δ) 使 P(‖T̂_ij − T_ij‖ > B_ij) ≤ δ。**信任域** Trust_ij = {T : ‖T − T̂_ij‖ ≤ B_ij}。当相对位姿落在信任域外，i 不得采信 j 的保证，只能降级为保守避让（把 j 当作半径 B_ij 的未认证动态障碍）。

**定义 29（视觉伺服证书 CertVS）**：令特征误差 e = s − s*，交互矩阵 L_s(s,Z)，控制 v_c = −λ L̂_s⁺ e，闭环
ė = −λ L_s L̂_s⁺ e + δ(Z, calib, delay)。
**CertVS = {λ, α, E_basin, V_margin, τ_max, Z_interval, ρ_model}**：α 为认证收敛率，E_basin 为吸引域，V_margin 为特征点距图像边界的可见性裕度，τ_max 为时延裕度，Z_interval 为有效深度区间，ρ_model 为交互矩阵/标定相对误差上界。
**定理（指数收敛 + 可见性保持）**：若 e₀∈E_basin、Z∈Z_interval、标定误差 ≤ ρ_model、时延 τ<τ_max，则
‖e(t)‖ ≤ e^{−αt}‖e₀‖，α = λ(1−ρ_model) − L_δ τ/τ_max，
且 s(t)∈S_vis。τ_max 由相位裕度给出（λτ_max 约等于相位裕度/闭环带宽）。

**定义 30（视觉伺服交接与多机迁移评测）**：流策略终端误差界 ε_flow 由第 40 轮 CertFlow 给出，伺服吸引域半径 e_hand = sup{‖e‖ : e∈E_basin}。**交接可认证**当且仅当 ε_flow ≤ e_hand；切换后总误差满足
E_total ≤ max(ε_flow, e^{−α t_servo} e_switch) + ε_target，
收敛时间 t_servo = (1/α) ln(e_switch/ε_target)。
**跨具身迁移**：具身参数 θ（连杆/执行器/相机），迁移因子 L_emb 满足 |Δmargin| ≤ L_emb‖θ−θ₀‖；若 L_emb‖Δθ‖ > margin_budget 则必须重认证。**多机评测量**：
CC = E[1{∀i: x_i∈V_i^{multi} ∧ ∀(i,j): h_ij≥0 ∧ CertVS_i 有效}]（联合证书覆盖率），
IVR 为干扰违约率，Δ_succ 为跨具身成功率退化。评测采用配对种子、分层场景（交接链、共享走廊、协同装配）。

## 2. 三大产出设计

### 2.1 IP-51 FLEET-CERT-COMPOSITION（多机证书合成）
1. **契约发布与干扰图**：每个技能实例发布 (A_i,G_i,B_i^self)；按共享可达域建干扰图，只在强连通分量内检查小增益，避免全局枚举环。
2. **相对位姿界**：优先用 IP-52 互观测，退化时用 IP-49 共享地图/激光，必要时引入 UWB；CI 融合给 B_ij，并输出信任域。
3. **联合屏障**：h_ij 含双方漂移球与相对位姿球；分布式 QP（ADMM/共识）求解联合 CBF，非通信邻居用保守虚拟障碍替代。
4. **分布式有效域**：V_i^{multi} = ValidRegion_i ∩ ⋂_j Trust_ij；出域即降级并上报总线路由器。
5. **车队契约热更新**：任一机器人重颁证书 → 只沿干扰图局部传播（复用 IP-45 机制），避免全车队抖动。
6. **评测场景**：交接链（多机接力）、共享走廊（对向通行）、协同装配（共同持物）三类。

### 2.2 IP-52 VISUAL-SERVO-CERT-HANDOFF（可认证视觉伺服交接）
1. **伺服内核**：IBVS 为主、PBVS 为兜底；深度由 IP-49 激光/立体给出，交互矩阵在线辨识并给出 ρ_model。
2. **证书计算**：由 L_s 奇异值、深度区间、标定误差、时延估计 α、E_basin、V_margin、τ_max；任一项违约判不可认证。
3. **交接控制器**：在切换面 ‖e‖ = e_switch 处从认证流匹配切换到伺服；交接前显式核验 ε_flow ≤ e_hand，否则安全停或降速。
4. **证书修复**：当 IP-48 的 ODE 残差或 IP-49 漂移超过阈值时，伺服作为**闭环修复器**接管末端，把误差重新压回吸引域（RCA 的第五类触发）。
5. **互观测**：机器人互相追踪标定板/语义特征，给 B_ij；遮挡预测驱动特征重选（可见性感知的特征子集切换）。
6. **降级路径**：可见性裕度为负、深度越界或时延超 τ_max → 切 PBVS/保守位姿伺服或安全停。

### 2.3 IP-53 FLEET-EVAL-BENCH（多机评测基准与迁移证书）
1. **跨具身迁移**：估计 L_emb，对每类具身给出证书退化币值；超预算自动触发重认证。
2. **联合指标**：CC、IVR、交接链成功率、协同装配成功率、通信延迟分组。
3. **证书条件化课程**：把 IP-50 的采样从「单机证书赤字」扩展为「车队联合证书赤字」，优先采样联合有效域边缘与最容易产生遮挡/拥堵的配置。
4. **压力测试**：互观测遮挡、200ms 级通信延迟、相对位姿漂移、异构机型混编。
5. **部署闸门**：联合证书覆盖率或干扰违约率不达标的策略组合，禁止被 IP-45 总线路由。

## 5. 本轮最大风险

**一句话**：多机 assume-guarantee 与小增益虽然可靠，但每加一台机器人就乘入一个信任球与一对屏障，联合有效域 V_⊗ 随 N 快速收缩；一旦互观测遮挡使 B_ij 膨胀、视觉伺服的可见性裕度变负，整支车队的证书会退化为空集——故必须以 E73（联合覆盖率/合成保守性）与 E75（伺服紧致性/可见性）为本轮第一守门实验。

## 2. 关键算法

### IP-51 多机证书合成（伪代码）
```
def compose_fleet_contracts(agents, delta=0.01):
    G = interference_graph(agents, shared_reachability=True)
    B, trust = {}, {}
    for i in agents:
        for j in G.neighbors(i):
            B[i,j]     = mutual_pose_bound(i, j, delta)      # IP-52 互观测优先
            trust[i,j] = trust_region(B[i,j])
        A_i = all_within_trust(i, trust) and avoid_predicates(G.neighbors(i))
    for scc in strongly_connected_components(G):             # 只在 SCC 内查环
        for cycle in fundamental_cycles(scc):
            if prod(gamma[e] for e in cycle) >= 1.0:
                return INADMISSIBLE("cyclic_assumption_gain", cycle)
    V_joint = intersect([a.valid_region for a in agents] +
                        [{x: h_ij(x) >= 0} for (i,j) in G.edges])
    return FleetCert(A={A_i}, G={G_i}, B=B, trust=trust, V=V_joint)

def fleet_shared_cbf(agents, u_ref):
    # 每个机器人只与通信邻居交换状态；非邻居用保守虚拟障碍（半径 B_ij）
    constraints = []
    for (i,j) in comm_edges(agents):
        h = dist(p_i,p_j) - r_i - r_j - B[i,j] - B_self[i] - B_self[j]
        constraints.append(dh_dt(h, u_i, u_j) >= -alpha*h)
    return distributed_qp_admm(u_ref, constraints)           # 收敛后各自执行
```

```
def certify_visual_servo(L_s, Z_interval, calib_err, delay, lam):
    rho_model = calib_err + interaction_estimation_error(L_s)
    alpha     = lam*(1-rho_model) - delay_penalty(delay, L_s)
    if alpha <= 0: return INADMISSIBLE("no_contraction", alpha)
    tau_max   = phase_margin(L_s) / (lam * spectral_norm(L_s))
    e_basin   = basin_radius(L_s, Z_interval, visibility_margin)
    if delay >= tau_max: return INADMISSIBLE("delay_margin_exceeded", delay, tau_max)
    return CertVS(lam, alpha, e_basin, visibility_margin(L_s),
                  tau_max, Z_interval, rho_model)

def handoff_contract(flow_cert, servo_cert, eps_target):
    eps_flow = flow_cert.eps_ode + tracking_margin
    if eps_flow > servo_cert.e_basin:
        return INADMISSIBLE("handoff_gap", eps_flow, servo_cert.e_basin)
    e_switch = servo_cert.e_basin
    t_servo  = log(e_switch/eps_target) / servo_cert.alpha
    return Handoff(e_switch=e_switch, t_servo=t_servo, E_total=max(eps_flow, eps_target))

def servo_execute(x_hat, e, cert):
    if visibility_margin(e) < 0 or not in_interval(depth(x_hat), cert.Z_interval):
        return DEGRADE("visibility_or_depth")
    if measured_delay() >= cert.tau_max:
        return DEGRADE("delay")
    v_c = -cert.lam * pinv(interaction_matrix(e)) @ e      # IBVS
    return v_c                                            # PBVS 兜底见 degrade 分支
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 正确性保证 |
|---|---|---|
| 多机契约合成 | O(N+\|E\|+SCC 内环枚举)，稀疏图近线性 | **定理**：单机可靠 + 小增益<1 ⟹ 联合保证（概率≥1−Nδ） |
| 相对位姿 CI 融合 | 每对 O(d³)，d 为位姿维数 | CI 保守一致，B_ij 以 1−δ 覆盖 |
| 联合 CBF / ADMM | 每迭代 O(\|E_comm\|·d_u)，通常 <20 迭代 | h_ij≥0 且 Lipschitz ⟹ 真实间距安全 |
| 视觉伺服证书 | 交互矩阵 SVD O(k³)，k 为特征数 | **定理**：α>0 ⟹ ‖e(t)‖≤e^{−αt}‖e₀‖ 且可见性保持 |
| 交接判定 | O(1) | ε_flow≤e_hand ⟹ 复合误差界 max(ε_flow,ε_target) |
| 迁移因子估计 | O(#samples·d_θ) | 边际 Lipschitz 界，超预算即重认证 |
| 车队评测 | O(M·S·T·N·\|E\|) | 配对设计 + 配对置信区间；联合指标无偏 |

## 5. 风险与缓解

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 组合保守性爆炸：N 增大联合有效域指数收缩 | 高 | 只在强连通分量内验证小增益；分层合成（同构子车队先合）；仅对共享可达域建边；E73 第一守门 |
| 互观测遮挡/退化 → B_ij 膨胀、信任域塌缩 | 高 | 激光/UWB/里程计多模态兜底；CI 保守融合；出信任域降级为虚拟障碍；E73/E75 守门 |
| 视觉伺服可见性/深度/时延违约 → 吸引域失效 | 中 | 可见性感知特征重选 + PBVS 兜底 + 时延预算调度；E75 守门 |
| 交接 gap：流策略终端误差进不了吸引域 | 中 | 交接前显式核验 ε_flow≤e_hand；不满足则降速/安全停；由 IP-44 专门蒸馏交接面 |
| 跨具身迁移因子过松 → 迁移后悄悄失效 | 中 | L_emb 在线估计 + margin_budget 触发重认证；异构机型单独评测 |
| 车队评测组合空间爆炸 | 低 | 分层场景 + 配对种子 + 联合指标聚合，不做全组合枚举 |

## 6. 本轮最大风险

**一句话**：多机合成的正确性建立在「信任球不膨胀、伺服吸引域不塌缩」上——但每增加一台机器人就乘入一个 B_ij 与一对屏障，互观测遮挡又会同时放大 B_ij 并吃掉视觉伺服的可见性裕度，联合有效域 V_⊗ 可能随 N 指数收缩到空集，届时「可认证车队」将退化为「谁也不敢靠近谁的空证书」，故 E73 与 E75 是本轮成败判据。
