# 第 61 轮（承接第 60 轮「场景感知闭环」IP-153~160；灵感循环第 7 轮；本轮灵感：「数据质量」×「语义地图」）

> 第 60 轮把「执行层→证据层」升级为「认知驱动的场景-执行闭环」：SSM 用场景-阻抗先验提前收敛 K_safe，CIEC 把对话意图锁成实时约束，EPIR 用序列号+哈希保证 EV-exec 不因 ROS 丢包断裂，SERC 串起闭环，PCE++++ 增加认知预算。但**一个被默认成立的强假设**尚未被检验：
> 1. **场景先验被无条件信任**：SSM 的 π_scene(K|z) 与 scene_conf(z) 直接进入 EEIS 编译，却没有追问「这个场景信念是从什么质量的数据里学出来的」。若语义地图过期、缺失、错标，场景先验会把执行层「自信地」推向错误 K_safe——这才是第 60 轮最大风险的真正来源。
> 2. **语义地图没有质量元数据**：地图只存「这里是什么」，不存「我有多确定 / 多新 / 来自谁 / 和谁冲突」。没有质量维度，就无法区分「刚被多模态确认的桌沿」与「三个月前人工标注、从未复验的桌沿」。
> 3. **执行证据回写地图缺少质量闸门**：EV-exec 直接更新场景信念，一次误检就会污染地图；地图一旦被污染，下一轮场景先验又放大污染，形成「错误自举」。当前没有垃圾回收（降级为 unknown）机制。
> 4. **缺少主动补数据能力**：质量不足时，系统只能「回退通用先验」被动保守，不能主动决定「该去哪里看、看多久、问谁」以最小代价把质量补到可用阈值。

## 0. 直觉与动机

**灵感 1（语义地图 → 质量感知语义地图 QSM）**
直觉：语义地图不该是一张「标注好的图」，而应是一组**带质量护照的实体**。每个实体（桌面、楼梯口、充电桩、可抓取区）都随身携带六维质量向量：完整性（缺不缺边角）、准确性（标签对不对）、新鲜度（多久没复验）、一致性（多模态/多机是否冲突）、溯源可信度（谁标的、证据链是否可验）、分辨率（够不够接触级操作）。关键洞见：**质量不是标量，而是一组不可互相补偿的维度**——「很新但错标」和「很准但三个月没更新」是两种完全不同的危险；因此用格上的逐维支配关系判定可用性，关键维度低于地板值即一票否决。

**灵感 2（数据质量 → 质量感知场景先验 QSP）**
直觉：第 60 轮把场景识别转化为阻抗先验 π_scene(K|z)，但先验的「强度」应当由数据质量决定。质量高→均值贴近场景原型、协方差小；质量低→均值向通用先验收缩、协方差膨胀。关键洞见：**不确定不是把 K 改大或改小，而是把「可信 K 的椭球」放大，再做鲁棒安全编译**——低质量只会让鲁棒安全集变小（更保守），不会让系统「更自信地冒险」。

**灵感 3（数据质量 → 质量契约 DQC）**
直觉：质量没有绝对好坏，只有**相对用途**。同一张地图，导航认为「够用」，接触级操作可能认为「严重不足」。因此每个消费者（规划器、EEIS、CIEC）必须显式声明质量需求 q_req，地图查询返回 ADMIT / DEGRADE / REFUSE 三态。关键洞见：**把「地图够不够好」从隐性假设变成显式契约**，质量问题才能在执行前暴露，而不是在接触失败后追溯。

**灵感 4（语义地图 → 质量闸门回写 QMR + 垃圾回收）**
直觉：EV-exec 本身也是数据，也有质量。低质量证据不得写回地图；高质量证据按质量加权融合；过期且低质量实体必须**降级为 unknown**，而不是继续以旧标签「装懂」。关键洞见：**地图的可信度必须满足「无新证据只降不升」**，否则一次误检就能通过回写—先验—再回写形成错误自举。

**灵感 5（数据质量 → 主动质量采集 AQG）**
直觉：质量不足时，正确动作不是「一律保守」，而是计算「再观察 / 试探 / 问人 / 他机交叉验证」的信息价值（VOI）。关键洞见：**数据质量应成为可主动控制的状态变量**，用最小采集代价把质量补到契约阈值；补不上去才降级自主等级。

**灵感 6（两款灵感合流 → 质量有界闭环 SERC-Q）**
直觉：把「查地图→评质量→定自主等级→收缩先验→执行→质量闸门回写→质量更新」串成闭环。核心命题：**数据质量决定「认知先行」的上界**——地图质量越高，才允许越强的场景先验注入；质量下降必须在一个控制周期内触发自主等级降级。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（质量感知语义地图 QSM）** 质量感知语义地图 M⁺ = (E, R, Q, P, T, Λ)。其中：
- **实体与关系**：E 为语义实体（对象、表面、区域、可操作 affordance），R 为关系（邻接、支撑、可通过性、可抓取性）
- **质量映射**：Q: E∪R → [0,1]⁶，q(e) = (q_comp, q_acc, q_fresh, q_cons, q_prov, q_res) 分别表示完整性、准确性、新鲜度、一致性、溯源可信度、分辨率
- **溯源 DAG**：P(e) = (source_node, method, timestamp, parent_hashes)，记录实体由哪些观测/证据产生
- **有效期**：T(e) = [t_birth, t_last_seen]，新鲜度按实体挥发速度 τ_fresh(e) 指数衰减：q_fresh(e,t) = exp(−(t−t_last_seen(e))/τ_fresh(e))
- **有效质量**：q_eff(e,t) = (∏ᵢ qᵢ(e,t))^{1/6} · 𝟙[∀i: qᵢ(e,t) ≥ qᵢ^floor]
- **质量场**：区域 Ω 的质量为 q_eff(Ω,t) = min_{e∈Ω} q_eff(e,t)（区域安全由最弱实体决定）
有效质量的「关键维度地板」表达了一票否决：任一维度低于地板值，整体质量归零，禁止用其他维度补偿。

**定义 162（数据质量契约 DQC）** 契约 D = (consumer, q_req, C_crit, fallback, horizon)。其中：
- **质量需求** q_req ∈ [0,1]⁶，按消费者类型声明：规划器重 completeness/consistency；EEIS 重 accuracy/freshness/consistency；CIEC 重 provenance/consistency
- **质量格**：(Q, ⊑)，q ⊑ q′ ⇔ ∀i qᵢ ≤ q′ᵢ；q ⊒ q_req 表示逐维满足
- **一致性/支配**：若 q_eff ⊒ q_req，则 ADMIT；若仅关键维度 C_crit 满足而其余不足，则 DEGRADE（允许带膨胀先验执行）；若任一关键维度不满足，则 REFUSE（必须补数据或降级）
- **门控函数** G(D, q) ∈ {ADMIT, DEGRADE, REFUSE}
契约把「数据质量」从绝对评价转为相对用途判定，horizon 限定判定有效期，过期自动重新评估。

**定义 163（质量感知场景先验 QSP）** 给定场景 z、支撑该场景的实体质量 q = q_eff(E(z),t)，定义：
- **信任权重**：w(q) = q_eff(E(z),t) ∈ [0,1]
- **均值收缩**：μ_q(z) = w·μ_scene(z) + (1−w)·μ_general
- **协方差膨胀**：Σ_q(z) = Σ_scene(z) + (1−w)·Λ_inflate，Λ_inflate ≻ 0 为膨胀基
- **质量感知安全集**：
```
K_safe^Q(z,q) = { K ∈ K_safe_base :
                 ∀K′ ∈ Ell(μ_q(z), Σ_q(z), χ²_{1−α}):
                 cost_exec(K′, z) ≤ ε_safe }
```
其中 Ell 为置信椭球。q 越低 ⇒ 椭球越大 ⇒ 鲁棒安全集越小、越保守；q→0 时退化为通用先验 + 最大膨胀。该定义保证「先验注入强度」被数据质量连续调节，而不是二值开关。

**定义 164（质量校准置信度 SIC-Q）** 在第 60 轮 SIC 三元组上增加质量维：
- **质量校准场景置信度**：scene_conf^cal(z,t) = min(scene_conf(z), q_eff(E(z),t))，保证「对场景的相信程度不超过对数据的相信程度」
- **SIC-Q** = (scene_conf^cal(z), K_certainty(K|z,q), execution_feasibility(K|z), q_eff(E(z),t))
- **有效性判定**：SIC_Q_valid ⇔ scene_conf^cal ≥ τ_scene ∧ K_certainty ≥ τ_K ∧ execution_feasibility = true ∧ q_eff ⊒ q_req
- **校准误差约束**：要求质量估计器满足 ECE(q̂) ≤ δ_q；未通过校准的质量估计不得用于抬高自主等级

**定义 165（质量闸门地图回写 QMR）** 地图更新算子 QMR(M⁺, u, e)：设证据 u 的质量为 q_src，目标实体 e 的质量为 q_t。
- **准入门槛**：q_src ⊒ τ_update，且溯源无环（P(u) ∩ Descendants(e) = ∅），否则 REJECT
- **质量融合**（证据维度用 noisy-OR，溯源用最弱链）：
```
q_t'[comp/acc/cons/res] = 1 − (1 − q_t)(1 − q_src)
q_t'[fresh]             = 1.0
q_t'[prov]              = min(q_t[prov], q_src[prov])
```
- **冲突处理**：若 q_src 与 q_t 的标签冲突且 q_src < τ_conflict，则保留 q_t 并标记 conflict，不覆盖
- **垃圾回收**：若 q_eff(e,t) < τ_evict 或 age(e) > TTL(e)，把语义标签降级为 unknown，仅保留几何占据信息
- **回滚**：若后续执行证据否证该更新，可沿 P(e) 回滚到更新前版本

**定义 166（主动质量采集 AQG）** 当 DQC 返回 REFUSE/DEGRADE 时，在数据预算 B_data 下选择采集动作：
```
a* = argmax_{a∈A} VOI_data(a)
VOI_data(a) = E[U(q_{t+1}) − U(q_t) | a] − cost_data(a) − λ_risk·Risk(a)
```
其中 A = {重新观测区域, 触觉试探实体, 询问人类, 他机/多模态交叉验证}，U(q) 为「该质量可支撑的自主等级/任务成功率」效用。
- **停止规则**：q_eff ⊒ q_req 或 B_data 耗尽或 max_a VOI_data(a) ≤ 0
- **失败处理**：若预算耗尽仍未达标，确定性降级自主等级 α，禁止「不补数据也不降级」的僵局

**定义 167（质量有界自主 QBA）** 定义离散自主等级 α ∈ {3,2,1,0}：
- α=3：完整场景先验注入（QSP 原样进入 EEIS）
- α=2：膨胀先验注入（额外膨胀系数 ≥ 1.5）
- α=1：仅通用先验 + 基础速度/力约束
- α=0：第 59 轮纯执行接地层（不使用场景先验）
每级有质量需求 q_req(α)，且 q_req(3) ⊒ q_req(2) ⊒ q_req(1)。则
```
α*(q) = max { α ∈ {3,2,1,0} : q ⊒ q_req(α) }
```
α*(q) 对 q 逐维单调不减；新鲜度衰减导致 q 下降时，α* 在一个控制周期内单调不增。该定义把「认知先行」的许可边界显式化。

**定义 168（质量有界闭环 SERC-Q 与 PCE+++++）** 扩展第 60 轮 SERC 与预算：
```
B_cog' = (B_scene, B_intent, B_ros, B_exec, B_data)
B_data = (Observation_budget, Map_update_budget, Verification_budget, Freshness_horizon)
voi_q(π) = VOI_meta_pessimistic(π) − cost_cog(π) − cost_exec(π) − cost_data(π)
cost_data = λ_obs·Observation + λ_upd·Map_update + λ_ver·Verification
            + λ_stale·max(0, age − Freshness_horizon)
```
SERC-Q 算子：
```
① QSM.query(region) → (E, q_vec, q_eff, provenance)
② DQC.gate(q_eff, q_vec) → {ADMIT | DEGRADE | REFUSE}
③ QBA: α* ← select_autonomy(q_vec)
④ 若 REFUSE/DEGRADE: AQG(region, q_req, B_data) → 更新 q_vec；仍不足则 α* ↓
⑤ QSP: α*≥2 时 μ_q,Σ_q ← quality_aware_prior(q_eff)；否则通用先验
⑥ CIEC: 仅当意图数据质量 q_intent ⊒ q_req(CIEC∩) 时锁定约束
⑦ EEIS.compile_with_quality_prior(μ_q,Σ_q,δ_f_req) → K_safe^Q
⑧ Execute → EV-exec（携带 source_quality、provenance hash）
⑨ QMR: quality_gated_update(e, EV-exec, q_src)；quality_garbage_collect()
⑩ XMC++: 融合并更新场景-质量联合信念
⑪ Return (α*, K_safe^Q, EV-exec, q_eff, cert)
```

### IP-161 QSM（质量感知语义地图）

```python
Q_DIMS = ('completeness', 'accuracy', 'freshness',
          'consistency', 'provenance', 'resolution')

class QualityAwareSemanticMap:
    def __init__(self, freshness_tau=None, floors=None):
        self.entities = {}       # eid -> {'label', 'pose', 'attrs'}
        self.quality = {}        # eid -> np.ndarray(6)
        self.provenance = {}     # eid -> list[DAGNode]
        self.last_seen = {}      # eid -> timestamp
        self.tau_fresh = freshness_tau or {}
        self.floor = floors if floors is not None else np.full(6, 0.30)

    def effective_quality(self, eid, t):
        q = self.quality[eid].astype(float).copy()
        tau = self.tau_fresh.get(eid, 3600.0)
        q[2] = float(np.exp(-(t - self.last_seen[eid]) / tau))
        if np.any(q < self.floor):
            return 0.0
        return float(np.exp(np.mean(np.log(np.clip(q, 1e-6, 1.0)))))

    def quality_field(self, region, t):
        ids = self._entities_in(region)
        if not ids:
            return np.zeros(6), 0.0
        q_mat = np.stack([self._quality_with_freshness(e, t) for e in ids])
        q_vec = q_mat.min(axis=0)         # 区域由最弱实体决定
        q_eff = min(self.effective_quality(e, t) for e in ids)
        return q_vec, q_eff

    def query(self, region, t):
        return [{'eid': e, 'label': self.entities[e]['label'],
                 'q_vec': self._quality_with_freshness(e, t),
                 'q_eff': self.effective_quality(e, t),
                 'prov': self.provenance[e]} for e in self._entities_in(region)]
```

### IP-162 DQC + QBA（质量契约与质量有界自主）

```python
AUTONOMY_REQ = {
    3: np.array([0.85, 0.85, 0.80, 0.85, 0.80, 0.70]),
    2: np.array([0.65, 0.70, 0.60, 0.70, 0.60, 0.50]),
    1: np.array([0.40, 0.50, 0.30, 0.50, 0.40, 0.30]),
    0: np.zeros(6),
}

class DataQualityContract:
    def __init__(self, consumer, q_req, critical_dims, fallback='downgrade'):
        self.consumer = consumer
        self.q_req = np.asarray(q_req, dtype=float)
        self.critical = [Q_DIMS.index(d) for d in critical_dims]
        self.fallback = fallback

    def gate(self, q_vec):
        below = q_vec < self.q_req
        if not np.any(below):
            return 'ADMIT'
        if any(below[i] for i in self.critical):
            return 'REFUSE'
        return 'DEGRADE'

def select_autonomy(q_vec):
    for alpha in (3, 2, 1):
        if np.all(q_vec >= AUTONOMY_REQ[alpha]):
            return alpha
    return 0
```

### IP-163 QSP（质量感知场景先验）

```python
def quality_aware_scene_prior(mu_scene, Sigma_scene, mu_general,
                              q_eff, Lambda_inflate):
    w = float(np.clip(q_eff, 0.0, 1.0))
    mu_q = w * mu_scene + (1.0 - w) * mu_general
    Sigma_q = Sigma_scene + (1.0 - w) * Lambda_inflate
    return mu_q, Sigma_q

def compile_with_quality_prior(eeis, mu_q, Sigma_q, chi2_thr,
                               delta_f_req, inflate_extra=1.0):
    Sigma_q = Sigma_q * inflate_extra
    ellipsoid = eeis.ellipsoid(mu_q, Sigma_q, chi2_thr)
    robust_safe = eeis.robust_safe_set(ellipsoid, eps_safe=eeis.eps_safe)
    return robust_safe & eeis.safe_base(delta_f_req)
```

### IP-165 QMR（质量闸门回写与垃圾回收）

```python
def quality_gated_update(map_, eid, obs, q_src, prov_node, t,
                         tau_update=0.50, tau_conflict=0.60):
    if np.any(q_src < tau_update):
        return 'REJECT_LOW_QUALITY'
    if map_.provenance_reaches(eid, prov_node):
        return 'REJECT_CYCLE'
    if map_.label_conflict(eid, obs) and q_src[1] < tau_conflict:
        map_.mark_conflict(eid)
        return 'KEEP_CONFLICT'

    q_t = map_._quality_with_freshness(eid, t)
    fused = 1.0 - (1.0 - q_t) * (1.0 - q_src)   # noisy-OR 证据累积
    fused[2] = 1.0                               # freshness reset
    fused[4] = min(q_t[4], q_src[4])             # provenance 最弱链
    map_.quality[eid] = np.clip(fused, 0.0, 1.0)
    map_.last_seen[eid] = t
    map_.provenance[eid].append(prov_node)
    return 'ACCEPT'

def quality_garbage_collect(map_, t, tau_evict=0.25):
    for eid in list(map_.entities):
        if map_.effective_quality(eid, t) < tau_evict or map_.is_expired(eid, t):
            map_.entities[eid]['label'] = 'unknown'
            map_.drop_semantics(eid)   # 保留几何占据，删除不可信语义
```

### IP-166 AQG（主动质量采集）

```python
def active_quality_gather(map_, region, q_req, budget, t):
    while budget.remaining() > 0:
        q_vec, q_eff = map_.quality_field(region, t)
        if np.all(q_vec >= q_req):
            return map_, 'SATISFIED'
        best, best_voi = None, 0.0
        for action in budget.actions(region):
            q_next = map_.predict_quality(action, t)
            gain = budget.utility(q_next) - budget.utility(q_vec)
            voi = gain - budget.cost(action) - budget.risk_penalty(action)
            if voi > best_voi:
                best, best_voi = action, voi
        if best is None:
            break
        budget.spend(best)
        map_ = execute_acquisition(map_, best)
        t = clock()
    q_vec, _ = map_.quality_field(region, t)
    return map_, ('SATISFIED' if np.all(q_vec >= q_req) else 'DOWNGRADE')
```

```python
def quality_bounded_serc(M, region, intent, delta_f_req):

        if M.budget.data.remaining() > 0:
            M.map, q_status = active_quality_gather(
                M.map, region, M.dqc_eeis.q_req, M.budget.data, t)
        else:
            q_status = 'DOWNGRADE'
        q_vec, q_eff = M.map.quality_field(region, clock())
        alpha = select_autonomy(q_vec)
        if q_status == 'DOWNGRADE':
            alpha = max(0, alpha - 1)

    if alpha >= 2:
        mu_q, Sigma_q = quality_aware_scene_prior(
            M.mu_scene[region], M.Sigma_scene[region],
            M.mu_general, q_eff, M.Lambda_inflate)
        extra = 1.0 if alpha == 3 else 1.5
        K_prior = compile_with_quality_prior(
            M.eeis, mu_q, Sigma_q, M.chi2_thr,
            delta_f_req, inflate_extra=extra)
    else:
        K_prior = None   # α≤1: 通用先验/纯执行接地

    if intent is not None and M.dqc_intent.gate(M.intent_quality) != 'REFUSE':
        M.intent_ctrl.receive_intent(intent)

    M, fused, D_plus, EV_exec, cert = closed_loop_exec_probe(
        M, M.current_cp, delta_f_req, M.budget, K_prior)

    epir_msg = M.epir.append(EV_exec.__dict__)
    status = quality_gated_update(
        M.map, region, EV_exec, EV_exec.source_quality,
        prov_node=epir_msg.hash, t=clock())
    M.map = quality_garbage_collect(M.map, clock())
    M, fused, D_plus = xmodal_fuse_plus(
        M, region, M.inf_latest, epir_msg)

    return M, fused, D_plus, {
        'alpha': alpha, 'q_eff': q_eff, 'gate': gate,
        'map_update': status, 'K_safe': K_prior}
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| QSM | O(d·|E|) 查询 / O(d) 单实体更新 | O(|E|·(d+|P|)) | 六维质量 + 关键维度地板，区域取最弱实体 |
| DQC | O(d) 门控 | O(d) | ADMIT/DEGRADE/REFUSE 三态，关键维度一票否决 |
| QSP | O(d²) 协方差膨胀 + O(d³) 椭球/鲁棒集 | O(d²) | q→0 退化通用先验；q 降低 ⇒ 鲁棒安全集单调收缩 |
| SIC-Q | O(d) | O(d) | 置信度不超过数据可信度，ECE ≤ δ_q |
| QMR | O(|P|) 溯源检查 / O(|E|) 垃圾回收 | O(|E|·|P|) | 低质量拒绝、无环、无新证据只降不升 |
| AQG | O(|A|) 单步 VOI | O(|A|) | B_data 内达标或确定性降级，无死锁 |
| QBA | O(#levels) = O(1) | O(1) | α*(q) 对 q 单调，质量下降一周期内降级 |
| SERC-Q | O(闭环 + 质量评估) | 复用 | 自主等级不超过数据质量许可上界 |

**正确性定理（DQ-SGEC）**：假设 A66–A70 成立：
- **(A66) 质量校准**：质量估计器满足 ECE(q̂) ≤ δ_q；无新证据时 q_fresh 单调不增，且整体质量不会自发上升。
- **(A67) 先验收缩**：QSP 对 q 连续，q→0 时 π_q 收敛到通用先验；q ⊑ q′ ⇒ K_safe^Q(q) ⊆ K_safe^Q(q′)（质量越低，鲁棒安全集越小）。
- **(A68) 契约健全**：若 q_eff ⊒ q_req 且消费者误差模型正确，则消费者决策风险 ≤ ε_req。
- **(A69) 回写无环**：溯源 DAG 无环；q_src ⊒ τ_update 才允许更新；质量融合满足单调上界且不产生循环证据。
- **(A70) 自主包络**：q_req(α) 随 α 单调增强；α*(q) 对 q 单调不减；新鲜度衰减可在一个控制周期内触发降级。

则：
1. **质量有界自主**：任意时刻 α*(q_t) 是数据质量允许的最大自主等级；SERC-Q 不注入超出 q_req(α*) 的场景先验，因此「认知先行」始终被数据质量上界约束。
2. **不自信地错**：若 q 不满足 EEIS 契约，QSP 膨胀或 α≤1，K_safe^Q 只会更保守；结合第 60 轮 K_safe_base，安全派发概率下界为 1−ε_req。
3. **地图不被污染自举**：低于 τ_update 的证据不能提高实体质量；垃圾回收把过期/低质量语义降级为 unknown；错误无法通过「回写→先验→再回写」跨轮放大。
4. **闭环活性**：AQG 在 B_data 内要么把质量补到 q_req，要么在预算耗尽时确定性降级 α；不存在「既不补数据也不降级」的僵局。

## 5. 本轮最大风险

**一句话**：如果「数据质量」本身被系统性高估（地图看起来又新又全，实则过期或错标），QBA 会把自主等级错误抬高、QSP 会注入过强先验，让第 60 轮的「场景误判→错误 K_safe」以更隐蔽的方式复现；因此必须以「来源溯源不可伪造 + 冗余交叉验证 + 执行证据反证 + 无新证据质量只降不升」为硬护栏，并默认「质量高估比质量低估更危险」。

### IP-161 QSM（质量感知语义地图）

```python
Q_DIMS = ('completeness', 'accuracy', 'freshness',
          'consistency', 'provenance', 'resolution')

class QualityAwareSemanticMap:
    def __init__(self, freshness_tau=None, floors=None):
        self.entities = {}       # eid -> {'label', 'pose', 'attrs'}
        self.quality = {}        # eid -> np.ndarray(6)
        self.provenance = {}     # eid -> list[DAGNode]
        self.last_seen = {}      # eid -> timestamp
        self.tau_fresh = freshness_tau or {}
        self.floor = floors if floors is not None else np.full(6, 0.30)

    def effective_quality(self, eid, t):
        q = self.quality[eid].astype(float).copy()
        tau = self.tau_fresh.get(eid, 3600.0)
        q[2] = float(np.exp(-(t - self.last_seen[eid]) / tau))
        if np.any(q < self.floor):
            return 0.0
        return float(np.exp(np.mean(np.log(np.clip(q, 1e-6, 1.0)))))

    def quality_field(self, region, t):
        ids = self._entities_in(region)
        if not ids:
            return np.zeros(6), 0.0
        q_mat = np.stack([self._quality_with_freshness(e, t) for e in ids])
        q_vec = q_mat.min(axis=0)         # 区域由最弱实体决定
        q_eff = min(self.effective_quality(e, t) for e in ids)
        return q_vec, q_eff

    def query(self, region, t):
        return [{'eid': e, 'label': self.entities[e]['label'],
                 'q_vec': self._quality_with_freshness(e, t),
                 'q_eff': self.effective_quality(e, t),
                 'prov': self.provenance[e]} for e in self._entities_in(region)]
```

```python
AUTONOMY_REQ = {
    3: np.array([0.85, 0.85, 0.80, 0.85, 0.80, 0.70]),
    2: np.array([0.65, 0.70, 0.60, 0.70, 0.60, 0.50]),

class DataQualityContract:
    def __init__(self, consumer, q_req, critical_dims, fallback='downgrade'):
        self.consumer = consumer
        self.q_req = np.asarray(q_req, dtype=float)
        self.critical = [Q_DIMS.index(d) for d in critical_dims]
        self.fallback = fallback

    def gate(self, q_vec):
        below = q_vec < self.q_req
        if not np.any(below):
            return 'ADMIT'
        if any(below[i] for i in self.critical):
            return 'REFUSE'
        return 'DEGRADE'

def select_autonomy(q_vec):
    for alpha in (3, 2, 1):
        if np.all(q_vec >= AUTONOMY_REQ[alpha]):
            return alpha
    return 0
```

### IP-163 QSP（质量感知场景先验）

```python
def quality_aware_scene_prior(mu_scene, Sigma_scene, mu_general,
                              q_eff, Lambda_inflate):
    w = float(np.clip(q_eff, 0.0, 1.0))
    mu_q = w * mu_scene + (1.0 - w) * mu_general
    Sigma_q = Sigma_scene + (1.0 - w) * Lambda_inflate
    return mu_q, Sigma_q

def compile_with_quality_prior(eeis, mu_q, Sigma_q, chi2_thr,
                               delta_f_req, inflate_extra=1.0):
    Sigma_q = Sigma_q * inflate_extra
    ellipsoid = eeis.ellipsoid(mu_q, Sigma_q, chi2_thr)
    robust_safe = eeis.robust_safe_set(ellipsoid, eps_safe=eeis.eps_safe)
    return robust_safe & eeis.safe_base(delta_f_req)
```

### IP-165 QMR（质量闸门回写与垃圾回收）

```python
def quality_gated_update(map_, eid, obs, q_src, prov_node, t,
                         tau_update=0.50, tau_conflict=0.60):
    if np.any(q_src < tau_update):
        return 'REJECT_LOW_QUALITY'
    if map_.provenance_reaches(eid, prov_node):
        return 'REJECT_CYCLE'
    if map_.label_conflict(eid, obs) and q_src[1] < tau_conflict:
        map_.mark_conflict(eid)
        return 'KEEP_CONFLICT'

    q_t = map_._quality_with_freshness(eid, t)
    fused = 1.0 - (1.0 - q_t) * (1.0 - q_src)   # noisy-OR 证据累积
    fused[2] = 1.0                               # freshness reset
    fused[4] = min(q_t[4], q_src[4])             # provenance 最弱链
    map_.quality[eid] = np.clip(fused, 0.0, 1.0)
    map_.last_seen[eid] = t
    map_.provenance[eid].append(prov_node)
    return 'ACCEPT'

def quality_garbage_collect(map_, t, tau_evict=0.25):
    for eid in list(map_.entities):
        if map_.effective_quality(eid, t) < tau_evict or map_.is_expired(eid, t):
            map_.entities[eid]['label'] = 'unknown'
            map_.drop_semantics(eid)   # 保留几何占据，删除不可信语义
```

### IP-166 AQG（主动质量采集）

```python
def active_quality_gather(map_, region, q_req, budget, t):
    while budget.remaining() > 0:
        q_vec, q_eff = map_.quality_field(region, t)
        if np.all(q_vec >= q_req):
            return map_, 'SATISFIED'
        best, best_voi = None, 0.0
        for action in budget.actions(region):
            q_next = map_.predict_quality(action, t)
            gain = budget.utility(q_next) - budget.utility(q_vec)
            voi = gain - budget.cost(action) - budget.risk_penalty(action)
            if voi > best_voi:
                best, best_voi = action, voi
        if best is None:
            break
        budget.spend(best)
        map_ = execute_acquisition(map_, best)
        t = clock()
    q_vec, _ = map_.quality_field(region, t)
    return map_, ('SATISFIED' if np.all(q_vec >= q_req) else 'DOWNGRADE')
```

### IP-168 PCE+++++（数据预算与 VOI）

```python
class DataBudget:
    def __init__(self, obs_ops=20, update_ops=100, verify_ops=10,
                 freshness_horizon=3600):
        self.obs_ops = obs_ops
        self.update_ops = update_ops
        self.verify_ops = verify_ops
        self.freshness_horizon = freshness_horizon

    def remaining(self):
        return min(self.obs_ops, self.verify_ops)

    def spend(self, action):
        self.obs_ops -= action.obs_cost
        self.verify_ops -= action.verify_cost

def voi_quality(voi_meta, cost_cog, cost_exec, cost_data):
    return voi_meta - cost_cog - cost_exec - cost_data

def cost_data(obs, upd, ver, age, freshness_horizon,
              lam_obs=0.1, lam_upd=0.05, lam_ver=0.2, lam_stale=0.3):
    return (lam_obs * obs + lam_upd * upd + lam_ver * ver +
            lam_stale * max(0.0, age - freshness_horizon))
```

| QSP | O(d²)+O(d³) | O(d²) | q→0 退化通用先验；q 降低 ⇒ 鲁棒安全集单调收缩 |
| SIC-Q | O(d) | O(d) | 置信度 ≤ 数据可信度 |
| QMR | O(|P|)/O(|E|) | O(|E|·|P|) | 低质量拒绝、无环、无新证据只降不升 |
| AQG | O(|A|) | O(|A|) | B_data 内达标或确定性降级 |
| QBA | O(1) | O(1) | α*(q) 对 q 单调 |
| SERC-Q | O(闭环+质量评估) | 复用 | 自主等级不超过质量许可上界 |

**正确性定理（DQ-SGEC）**：若 A66–A70 成立（质量校准 ECE≤δ_q；QSP 单调收缩；DQC 风险有界；QMR 无环且低质量拒绝；QBA 包络单调），则：
1. **质量有界自主**：α*(q_t) 为数据质量允许的最大自主等级，SERC-Q 不注入超出 q_req(α*) 的先验。
2. **不自信地错**：q 不满足契约时先验膨胀或 α≤1，K_safe^Q 只会更保守，安全派发概率 ≥ 1−ε_req。
3. **地图不被污染自举**：低质量证据不能抬高实体质量，过期语义降级 unknown，错误无法跨轮放大。
4. **闭环活性**：AQG 在 B_data 内要么补足质量，要么确定性降级，无僵局。

## 4. 实验设计 E192–E196

| 实验 | 指标 | 目标 |
|---|---|---|
| E192 QSM/DQC | 质量校准 ECE；门控误接受/误拒绝 | ECE ≤ 0.05；误接受 ≤ 1%；误拒绝 ≤ 5% |
| E193 QSP | 低质量错误 K_safe 派发率；高质量额外保守代价 | 错误派发 → 0；额外保守 ≤ 15% |
| E194 QMR | 错误 EV-exec 注入后污染率；回滚正确率 | 污染 ≤ 1%；回滚 ≥ 99% |
| E195 AQG/QBA | 自主等级正确率；质量恢复率；采集开销 | ≥ 90%；≥ 85%；≤ 1.3× |
| E196 端到端 | vs 第 60 轮：过期/缺失/错标下成功率、安全违规、证据链完整性 | 安全违规 −60%；中等质量成功率 ≥ 85%；链完整性 ≥ 99.9% |

**消融**：①第 60 轮 SERC（质量无关）；②QSM+DQC 无 QSP（只报警不收缩）；③QSM+QSP 无 QMR（回写不设闸门）；④完整 DQ-SGEC。重点监控「错误自举率」与「低质量自信失败率」。

## 5. 本轮最大风险

**一句话**：若「数据质量」自身被系统性高估（地图看似又新又全，实则过期或错标），QBA 会错误抬高自主等级、QSP 会注入过强先验，使第 60 轮的「场景误判→错误 K_safe」以更隐蔽的方式复现；必须以「溯源不可伪造 + 冗余交叉验证 + 执行证据反证 + 无新证据质量只降不升」为硬护栏，并默认「质量高估比质量低估更危险」。
