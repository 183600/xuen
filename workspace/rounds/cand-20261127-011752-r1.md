灵感驱动研究循环·第 1 轮（新循环）；本轮灵感：「三维感知」×「动力学」

> **基线**：第 3 轮产出 MetricVoiceGauge-NCD-HUTDH-v23+IP-436–439（云边同步 CESC / 少样本 FSVC / 知产 IPAM / HPC-E+ 四证门），其上承 v22 的 HDL/ACSC/DCSC/HPC-E/CFC++、v21 的 SDC/CAC/DCL/GIC、v20 的 PCA/CTS/CFC/HPC/CFCtrl，以及 v19 的 DCM/OGCC/CCV/DRS/OGC 与 v17 的 CLP/S2C/HCG/PSV/APS/AMC。
> **本轮纪律**：不推倒 v23，CESC/FSVC/IPAM/HPC-E+ 与 v22/v21/v20/v19/v17 全部保留。本轮只做一件事：**把"二维框 + 准静态快照"的语义证据与负信息，升级为"三维体素占据场 + 时空动力学租约"的证书体系**——用射线雕刻给出**不依赖语义召回 κ_c** 的几何负信息，用可达管与时间租约把自由空间从"状态"改写为"有期限的租约"，从结构上封堵 v21/v22 遗留的"合规缺席幻觉"，并把"快照安全"升级为"时空管安全"。

## 0. 直觉与动机

**灵感 1（三维感知 → 从"框 + Hull"到"体素占据场 + 射线雕刻的负信息"）**
直觉：v21 的 SDC 把检测框膨胀成 CertBox，CAC 用 2D 覆盖图加召回下界 κ_c 来"赎回"自由空间。但两者本质上都是 2D/语义的：CertBox 是投影框，Cov_t 是平面覆盖，而"这里没人"的结论完全押在检测器召回率上——这正是 v23 遗留的最大风险。三维感知给出一个**完全不同源的证据**：深度射线本身携带几何负信息。一条深度射线若在 `d_r^-` 之前没有返回，那么这段空间在几何上就是空的（free-space carving），它与"检测器有没有认出人"无关。把场景表示为体素占据场 `O_t: V_ρ → {F, O, U}`，每个体素的状态由多模态射线的雕刻/命中证据决定，就把 SDC（正证据）与 CAC（负证据）统一进同一个**三维证据场**：Occupied 只能被命中/检测增补，Free 只能被满足雕刻法定条件的射线"赎回"，Unknown 永远保守。关键反直觉点：**解决"缺席幻觉"的正确方式不是把 κ_c 估得更准，而是换一个不依赖语义召回的负信息源**——几何射线雕刻的失效模式（透明/镜面/吸光）与语义漏检（儿童/蹲姿/逆光）是**解耦**的，二者构成独立冗余。副产品：体素级证据天然支持跨机器人按 (voxel, 状态) 去重融合，比 NMS 的 IoU 等价类更严格。

**灵感 2（动力学 → 自由空间不是"状态"而是"租约"，证书必须时空化）**
直觉：现有证书都是**快照**：t 时刻 Free 的体素，t+Δ 可能被一个 1.5 m/s 的人占据。把自由空间当成静态属性，是"准静态假设"的隐藏漏洞——尤其当机器人在共享区做长时规划时。动力学要求我们回答的不是"现在空不空"，而是"**在我到达之前它还能空多久**"。于是引入两个动力学对象：(a) **障碍可达集** `R_obs(t+Δ) = B(p + vΔ, ½ a_max Δ²)`（有界加速度下的最坏可达球），并可用 conformal 轨迹预测给出 ≥1-α 覆盖的预测集；(b) **机器人制动动力学** `d_stop(v) = v²/(2 a_brake) + v·t_react`。自由空间证书因此带一个**时间租约 τ_lease**：只有当"机器人能在 τ_lease 内到达并制动"与"最坏障碍在 τ_lease 内到不了"同时成立时，该自由体素才可被依赖。关键反直觉点：**"更保守"不等于"更慢"**——给自由空间加时间租约反而能释放更多活性，因为静态方案为了安全只能把整片区域长期标为"可能有人"，而时空管允许在租约窗口内精确地使用它。动力学还把 v22 的臂能量/整机动力学统一进来：执行不仅要能量可行，还要落在**时空安全管**内。

**两者如何统一**
统一为 **v23 之上的"时空体积"层**：STOC（体素占据证书）回答"空间上那里是什么"，CFSC（认证射线雕刻）回答"凭什么说那里是空的且不依赖语义召回"，DRT（动力学可达管）与 TLFS（时间租约）回答"这份空在时间上还能信多久"，DACBF（动力学 CBF 执行过滤器）保证执行轨迹始终落在被认证的时空管内。共享状态 `ζ_ce` 扩展为 **`ζ_st = ζ_ce ∪ (O_t, V_ρ, Carve_t, R_obs, τ_lease, Tube(π), φ_cbf)`**。统一准入门 **`HPC-ST = HPC-E+ ∧ STOC ∧ DRT`**：几何/规范/能量（v23）∧ 体积证据（STOC）∧ 时空管（DRT）。任一失效退回 v23 的静态保守，再退 v22/v21。

## 2. 设计原则（在 P41–P42 基础上新增 P43–P46）

**P43 三维证据单调律（Volumetric Evidence Monotonicity）**
场景表示为体素占据场 `O_t: V_ρ → {F, O, U}`。`O` 只能被命中/检测增补；`F` 只能被满足雕刻法定条件的射线"赎回"；`U` 永远保守、绝不当自由。障碍集合 `Obs_t = {v : O_t(v)=O} ∪ inflate(∂F, ρ)`；任何失效（深度缺失/标定漂移/模态掉线）使体素从 F 退回 U、O 只增不减。跨时刻的松弛只能走 `O → U → F`，**绝不 O → F 直跳**。SDC 的 CertBox 与 CAC 的 Cov_t 均成为该场的投影视图，单调性在三维层面统一。

**P44 几何负信息律（Geometric Negative Information）**
自由体素的认证只依赖几何射线：`v ∈ F_t ⟺ |{r : v ∈ FreeCarve(r)}| ≥ k_carve ∧ |modalities(v)| ≥ 2 ∧ 跨模态一致`，其中 `FreeCarve(r) = {x : 0 ≤ |x| ≤ d_r^-}`。其失效概率由传感器漏返回/深度误差模型给出，**不含 κ_c**；透明/镜面/吸光风险由模态多样性、主动探测与 U 回退承担，而非语义召回假设。

**P45 时空证书律（Space-Time Certificate）**
每张自由证书携带租约 `τ_lease(v) = min(τ_sensor(v), τ_kin(v))`，`τ_kin` 由机器人制动距离与障碍最坏可达集联合导出。证书仅在 `[t, t+τ_lease)` 内有效；过期即退回 U 并触发重规划。证书是四维对象 `Cert(v, [t, t+τ])`，不是三维快照。

**P46 动力学执行过滤律（Dynamics-Aware Execution Filter）**
执行必须落在被认证时空管 `Tube(π) = {(x,t) : O_t(x) ≠ O ∧ 距 U/O 边界 ≥ m_dyn}` 内；离散 CBF-QP 过滤器在每步把名义控制投影到安全集 `h(x) ≥ 0`。过滤器只收缩执行集：`Exec_v24 = Exec_v23 ∩ Fil_stoc ∩ Fil_drt ⊆ Exec_v23`。

## 3. 与基线的接口（如何退化）

- STOC 失效（体素场不可信）⇒ 退回 v23 的 2D CertBox/Cov_t 语义视图 ⇒ 等价 v23；
- CFSC 失效（深度不可用/模态不足）⇒ 所有体素置 U ⇒ 全域保守 ⇒ 比 v23 更保守，子集；
- DRT 失效（预测不可信）⇒ 租约取 0、退回静态人距上限 ⇒ 子集；
- TLFS 过期 ⇒ 单步保守重规划，不回滚证书链；
- DACBF 失效 ⇒ 退回 v22 的静态安全过滤器 ⇒ 子集；
- 全部失效 ⇒ 完全回退 v23 ⇒ `Exec_v24 ⊆ Exec_v23 ⊆ ... ⊆ Exec_v18`。
- **安全继承**：STOC 只增 O、CFSC 只赎回有几何证据的 F、租约只缩不扩、CBF 只收缩；任意失效都向更保守方向退化。

## 4. 预期贡献

1. **体积化感知证书 STOC**：把 SDC/CAC 统一为三维体素证据场，给出"O 只增、F 有偿赎回、U 吸收"的单调系统；
2. **几何负信息**：首次让"这里没人"的结论**不依赖语义检测召回 κ_c**，而依赖可监控的几何雕刻失效模型，并与语义通道解耦冗余——结构性封堵缺席幻觉；
3. **时空证书与时间租约**：把自由空间从状态升级为带 TTL 的租约，给出 τ_lease 的动力学导出与失效安全；

## 5. 本轮最大风险

**一句话**：时空管的全部保证押在"几何雕刻失效模式与语义漏检解耦"与"障碍加速度有界且预测误差可交换"两个假设上；一旦出现透明/吸光表面（几何与语义同时失效）叠加一个超界猛冲的个体（conformal 尾部事件），两个独立冗余会同时破缺，机器人将在一张形式上完备的时空证书下撞上去——即"多冗余的联合尾部幻觉"。

## 1. 关键算法骨架（在 IP-436–439 骨架上扩展）

```python
# ============================================================
# IP-440 Space-Time Occupancy Certificate (STOC) — 体素占据场
# ============================================================
F, O, U = "F", "O", "U"

@dataclass
class DepthRay:
    origin: np.ndarray
    direction: np.ndarray          # 单位向量
    d_minus: float                 # 认证下界：此距离内无返回 ⇒ 几何空
    d_plus: float                  # 命中上界
    modality: str                  # 'lidar' / 'stereo' / 'tof' / 'radar'
    t: float

class VoxelOccupancyField:
    def __init__(self, rho=0.05, k_carve=3, min_modalities=2, tau_occ=0.5):
        self.rho = rho
        self.k_carve = k_carve
        self.min_modalities = min_modalities
        self.tau_occ = tau_occ
        self.state: dict[Voxel, str] = {}
        self.free_ev = defaultdict(lambda: defaultdict(int))  # v -> {modality: count}
        self.occ_ev = defaultdict(int)
        self.occ_t = {}
        self.last_carve_t = {}

    def integrate(self, rays: list[DepthRay]):
        for r in rays:
            self._carve(r)
            self._hit(r)

    def _carve(self, r: DepthRay):
        for v in voxels_along(r.origin, r.direction, r.d_minus, self.rho):
            self.free_ev[v][r.modality] += 1
            self.last_carve_t[v] = r.t
            if self.state.get(v, U) == O:
                continue                       # O 不能被同一快照内的雕刻放宽
            ev = self.free_ev[v]
            if sum(ev.values()) >= self.k_carve and len(ev) >= self.min_modalities:
                self.state[v] = F              # 仅雕刻法定票可赎回自由

    def _hit(self, r: DepthRay):
        for v in voxels_between(r.origin, r.direction, r.d_minus, r.d_plus, self.rho):
            self.occ_ev[v] += 1
            self.occ_t[v] = r.t
            self.state[v] = O                  # 命中/检测只增占据

    def decay_dynamic(self, t: float):
        # 动态占据过期：O → U（绝不 O → F），需重新雕刻才可回 F
        for v, t_occ in list(self.occ_t.items()):
            if t - t_occ > self.tau_occ and self.state.get(v) == O:
                self.state[v] = U
                self.occ_ev[v] = 0
                self.free_ev[v].clear()

    def invalidate(self, region):
        for v in region:
            if self.state.get(v) == F:
                self.state[v] = U              # 失效只向保守退化

    def free_voxels(self): return {v for v, s in self.state.items() if s == F}
    def occ_voxels(self):  return {v for v, s in self.state.items() if s == O}


# ============================================================
# IP-441 Certified Free-space Carving (CFSC) — 几何负信息界
# ============================================================
class CertifiedCarver:
    def __init__(self, kappa_geo=1e-3):
        self.kappa_geo = kappa_geo            # per-ray 漏返回界，与 κ_c 无关

    def false_free_bound(self, n_voxels: int, k_carve: int) -> float:
        # 单个体素被 k 条独立射线同时漏返回的概率 ≤ κ_geo^k；
        # 全场 union bound：δ_carve ≤ |V| · κ_geo^k
        return min(1.0, n_voxels * (self.kappa_geo ** k_carve))

    def quorum_ok(self, ev: dict[str, int], k_carve: int, min_modalities: int) -> bool:
        return sum(ev.values()) >= k_carve and len(ev) >= min_modalities


# ============================================================
# IP-442 Dynamic Reachability Tube (DRT) — 动力学可达管
# ============================================================
class DynamicReachabilityTube:
    def __init__(self, a_max=2.0, a_brake=1.5, t_react=0.1, dt=0.05, m_dyn=0.10):
        self.a_max, self.a_brake, self.t_react = a_max, a_brake, t_react
        self.dt, self.m_dyn = dt, m_dyn

    def reachable(self, p, v, horizon):
        out = []
        for k in range(int(horizon / self.dt) + 1):
            tau = k * self.dt
            out.append((p + v * tau, 0.5 * self.a_max * tau * tau))
        return out

    def stopping_distance(self, v_rob: float) -> float:
        return v_rob ** 2 / (2 * self.a_brake) + v_rob * self.t_react

    def tube_ok(self, plan, occ: VoxelOccupancyField, obs_states, t, horizon) -> bool:
        for tau in np.arange(0, horizon, self.dt):
            x = plan.pose(tau)
            if occ.state.get(to_voxel(x), U) == O:
                return False
            for p, v in obs_states:
                for c, rad in self.reachable(p, v, horizon):
                    if np.linalg.norm(x - c) <= rad + self.m_dyn:
                        return False
            if self.stopping_distance(plan.speed(tau)) > plan.clearance(occ, tau):
                return False
        return True


# ============================================================
# IP-443 Temporal Lease Freshness (TLFS) — 时间租约
# ============================================================
class TemporalLeaseManager:
    def __init__(self, tau_sensor=0.2, m_dyn=0.10, eps=1e-3):
        self.tau_sensor, self.m_dyn, self.eps = tau_sensor, m_dyn, eps

    def lease(self, v, t, robot, obs_states, occ, drt: DynamicReachabilityTube) -> float:
        lo, hi = 0.0, self.tau_sensor
        if not self._safe_at(v, t, robot, obs_states, occ, drt, lo):
            return 0.0                         # 连瞬时都不安全 ⇒ 立即 U
        while hi - lo > self.eps:
            mid = 0.5 * (lo + hi)
            if self._safe_at(v, t, robot, obs_states, occ, drt, mid):
                lo = mid
            else:
                hi = mid
        return lo

    def _safe_at(self, v, t, robot, obs_states, occ, drt, tau) -> bool:
        x_v = voxel_center(v)
        d_stop = drt.stopping_distance(robot.speed)
        for p, vel in obs_states:
            c = p + vel * tau
            rad = 0.5 * drt.a_max * tau * tau
            if np.linalg.norm(x_v - c) <= rad + drt.m_dyn:
                return False
        return d_stop + drt.m_dyn <= clearance_to_boundary(x_v, occ)


# ============================================================
# IP-444 Dynamics-Aware CBF Filter (DACBF) — 执行过滤
# ============================================================
class DynamicsAwareCBFFilter:
    def __init__(self, alpha=1.0, dt=0.02):
        self.alpha, self.dt = alpha, dt

    def filter(self, u_nom, x, h, grad_h, f, g, energy_constraints):
        # 离散 CBF-QP:
        #   min ||u - u_nom||^2
        #   s.t. h(x + dt(f + g u)) >= (1 - alpha*dt) h(x)
        #        + PGEV 能量约束 + 关节/速度箱约束
        from scipy.optimize import minimize
        obj = lambda u: float(np.sum((u - u_nom) ** 2))
        cons = [
            {'type': 'ineq',
             'fun': lambda u: h(x + self.dt * (f + g @ u)) - (1 - self.alpha * self.dt) * h(x)},
            *energy_constraints,
        ]
        res = minimize(obj, u_nom, constraints=cons, method='SLSQP')
        return res.x if res.success else None   # None ⇒ 不可行 ⇒ SafeStop


# ============================================================
# IP-445 HPC-ST Gate — 时空三证一体准入门
# ============================================================
@dataclass
class HPCST:
    hpce_plus: 'HPCEPlus'
    stoc: VoxelOccupancyField
    carver: CertifiedCarver
    drt: DynamicReachabilityTube
    lease_mgr: TemporalLeaseManager
    cbf: DynamicsAwareCBFFilter

    def admits(self, plan, x, v, z, E_res, margin_req, modules,
               t, robot, obs_states, horizon) -> bool:
        # 1. v23 四证门：几何/规范/负信息/能量/云边/少样本/知产
        if not self.hpce_plus.admits(plan, x, v, z, E_res, margin_req, modules):
            return False
        # 2. 当前体积证据：计划扫过的体素不得为 O
        if not self._stoc_ok(plan, t):
            return False
        # 3. 时空管：未来 H 内不与障碍可达集相交，且租约覆盖
        if not self.drt.tube_ok(plan, self.stoc, obs_states, t, horizon):
            return False
        for vox in plan.voxels(t):
            if self.stoc.state.get(vox, U) == F:
                if self.lease_mgr.lease(vox, t, robot, obs_states, self.stoc, self.drt) <= 0:
                    return False
        # 4. 执行可行性：CBF-QP 有解
        if self.cbf.filter(plan.u_nom, x, plan.h, plan.grad_h, plan.f, plan.g,
                           plan.energy_constraints) is None:
            return False
        return True

    def _stoc_ok(self, plan, t) -> bool:
        return all(self.stoc.state.get(vx, U) != O for vx in plan.voxels(t))


# ============================================================
# IP-446 CFC-4D — 时空体素共识（在 CFC+++ 上扩展）
# ============================================================
class CertificateFederatedConsensus4D(CFCPlusPlusHierarchical):
    def consensus_round(self, t, horizon):
        base = super().consensus_round()
        out = {}
        for key, val in base.items():
            tracks = self._tracks_over(key, t, horizon)
            temporal_ok = all(self._track_consistent(tr) for tr in tracks)
            voxel_dedup_ok = self._dedup_by_voxel(tracks)   # 同 (voxel,state,t) 只计一票
            out[key] = val if (temporal_ok and voxel_dedup_ok) else "CI"
        return out

    def _track_consistent(self, tr) -> bool:
        # 同一轨迹相邻时刻不得出现 F→O 的"瞬移式"矛盾（需有过渡 U 或高加速度解释）
        return all(not (a.state == F and b.state == O and
                        np.linalg.norm(a.pos - b.pos) > self.a_max * (b.t - a.t) ** 2)
                   for a, b in zip(tr, tr[1:]))


# ============================================================
# 端到端流水线：感知 → 体积证书 → 时空管 → CBF → 准入
# ============================================================
class SpaceTimeCertificatePipeline(PerceptionComplianceEnergyPipeline):
    def __init__(self, config: dict):
        super().__init__(config)
        self.stoc = VoxelOccupancyField(config.get('rho', 0.05))
        self.carver = CertifiedCarver(config.get('kappa_geo', 1e-3))
        self.drt = DynamicReachabilityTube(config['a_max'], config['a_brake'],
                                           config['t_react'])
        self.lease = TemporalLeaseManager(config.get('tau_sensor', 0.2))
        self.cbf = DynamicsAwareCBFFilter()
        self.hpc_st = HPCST(self.hpc_e_plus, self.stoc, self.carver,
                            self.drt, self.lease, self.cbf)

    def step(self, sensor_data: dict, cloud_update: Optional[dict] = None):
        # 1. 三维证据整合（异步、可增量）
        self.stoc.integrate(sensor_data['rays'])
        self.stoc.decay_dynamic(sensor_data['t'])

        # 2. v23 原有流水线（云边/少样本/知产/语义-规范/能量）
        admitted, info = super().step(sensor_data, cloud_update)
        if not admitted:
            return False, info

        # 3. 时空三证准入
        plan = info['plan']
        ok = self.hpc_st.admits(
            plan, sensor_data['x'], sensor_data['v'], sensor_data['z'],
            sensor_data['E_res'], sensor_data['margin_req'],
            self._modules_in_plan(plan), sensor_data['t'],
            sensor_data['robot'], sensor_data['obs_states'],
            sensor_data['horizon'])
        info['free_bound'] = self.carver.false_free_bound(
            len(self.stoc.free_voxels()), self.stoc.k_carve)
        info['n_free'] = len(self.stoc.free_voxels())
        info['n_occ'] = len(self.stoc.occ_voxels())
        return ok, info
```

## 2. 复杂度分析

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 |
|---|---|---|---|
| STOC 射线整合 | O(Σ_r L_r/ρ)，稀疏哈希均摊 O(雕刻体素数) | O(\|V_occupied ∪ V_free\|) | ρ=0.05 m, k_carve=3 |
| CFSC 法定/界 | O(1) 每体素均摊；界计算 O(1) | O(\|V\|) | κ_geo=1e-3 |
| DRT 时空管 | O((H/dt)·(\|obs\|+1)) | O(H/dt) | H=2 s, dt=0.05 s |
| TLFS 租约 | O(log(1/ε)·(\|obs\|+1)) 二分 | O(1) | ε=1e-3, τ_sensor=0.2 s |
| DACBF QP | O(n³)，n = dof+约束 ≤ 20 | O(n²) | 50Hz 下 <1 ms |
| CFC-4D 共识 | O(N·M·L·T) | O(N·M·T) | T = 时间窗内快照数 |
| 端到端单步 | O(\|rays\|·L/ρ + \|det\|·d + n³) | O(\|V\| + \|D_calib\|) | P99 <20 ms |

**实时性保证**：体素场用稀疏哈希/八叉树增量更新，只重算被新射线触碰的体素；DRT/TLFS/CBF 均在计划生成后一次计算，CBF-QP 变量维数小（≤20），满足 50Hz 控制环。体素整合与租约计算可下沉到 10Hz 感知线程，控制路径只做 O(1) 状态查询。

## 3. 正确性论证

### 引理 1（几何负信息界，不依赖 κ_c）
**陈述**：若体素 v 被 `k = k_carve` 条相互独立的射线认证自由，且每条射线对真实占据体素的漏返回概率 ≤ κ_geo，则 `P(v 实占却被认证自由) ≤ κ_geo^{k}`；全场 `δ_carve ≤ |V_ρ| · κ_geo^{k}`。该界**不含语义检测召回 κ_c**。

**证明**：
1. 真实占据体素若被某条射线穿过，则该射线以概率 ≥1-κ_geo 返回命中，不进入 `FreeCarve(r)`。
2. 体素被认证自由，当且仅当所有 k 条雕刻射线都未命中；独立性给出 `P ≤ κ_geo^{k}`。
3. 对全场 |V_ρ| 个体素取 union bound 得上界。整个推导只涉及深度射线的漏返回模型，与检测器类别召回无关。∎

### 引理 2（时间租约的动力学安全）
**陈述**：设 `τ_lease(v) ≤ τ*`，其中 τ* 是满足 `d_stop(v_rob(t)) + max_obs reach(τ*) + m_dyn ≤ dist(v, ∂(O∪U))` 的最大时长；若所有障碍加速度满足 `‖a‖ ≤ a_max`，则对任意 `t' ∈ [t, t+τ_lease]`，依赖 v 为自由所规划的执行段在该窗口内无碰撞。

**证明**：
1. 最坏可达球 `B(p+vτ, ½a_maxτ²)` 按三角不等式支配任何满足加速度界的真实轨迹，故真实障碍在 τ 内必在球内。
2. 机器人制动距离 `d_stop` 给出从当前速度到静止的最短所需距离；条件保证机器人在到达 v 的边界前已能停住。
3. 两者相加仍小于到 O/U 边界的距离，故即便障碍从边界以最大加速度逼近，接触也不会在租约窗口内发生。∎

### 引理 3（单调执行链）
**陈述**：`Exec_v24 = Exec_v23 ∩ Fil_stoc ∩ Fil_drt ⊆ Exec_v23 ⊆ ... ⊆ Exec_v18` 恒成立。

**证明**：
- `Fil_stoc` 与 `Fil_drt` 都是合取谓词，只删除计划、不新增计划；
- STOC 失效 → 全 U（保守）；CFSC 失效 → 全 U；DRT/TLFS 失效 → 租约 0；DACBF 不可行 → SafeStop；
- 每种失效都映射到 v23 或更保守的执行子集，故交集只会缩小。∎

### 引理 4（体素单调与动态过期不产生假自由）
**陈述**：跨时刻状态迁移只允许 `O→U`、`U→F`（经雕刻法定）与 `F→U`（失效），不存在 `O→F` 直跳；因此动态占据过期不会直接制造自由空间。

**证明**：`decay_dynamic` 只把 O 置 U 并清空证据；`_carve` 在 `state==O` 时直接 continue；`F` 仅由法定票生成。任何 F 都必先经过 U 且获得新的几何证据。∎

### 定理（HPC-ST 时空准入门可靠性）
**陈述**：`HPCST.admits(π)=True` ⟹ π 同时满足：(1) v23 的几何/规范/负信息/能量/云边/少样本/知产条件；(2) 当前体积证据无 O 冲突，且误判自由概率 ≤ δ_carve；(3) 未来 H 内落在障碍最坏可达管之外且租约覆盖；(4) 存在满足 CBF 与能量约束的控制。且 `Exec_v24 ⊆ Exec_v23`。

**证明**：由 `HPCST.admits` 的四个连言条件，配合引理 1（体积证据界）、引理 2（租约安全）、引理 3（单调链）直接可得。必要性由任一条件缺失即拒证；充分性由四条件同时成立保证时空管与统计界闭环。∎
