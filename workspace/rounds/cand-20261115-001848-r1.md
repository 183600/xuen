# 第 3 轮（灵感循环第 3 轮；本轮灵感：「力控」×「电池管理」）

> **基线继承**：第 2 轮 **ToolGauge**（IP-315–320；定义 416–431；引理 46–50；实验 E426–440），
> 其下继承 LeanGauge（IP-310–314）与 MODGAUGE 五不变式。
> 本轮纪律：**在 ToolGauge 之上沿两条新轴升级，而不是推倒重来**——
> 把「非接触外感受计量」升级为「接触力控计量」，把「一次性校准热替换」升级为
> 「计量资产的健康管理（会老化、需估计、需均衡、需热管理）」。
> 所有旧模块、五不变式与退化链保留；本轮新增的力与老化只**门控与调度**，不进入数值真值通道。

## 双轴映射（升级而非重写）

| 灵感词 | 第 2 轮对象 | 升级为 | 一句话动机 |
|---|---|---|---|
| 力控（阻抗/导纳、混合位-力、接触态） | IP-316 T₀ 工具库：只会「看、照、敲、热」，机器人是外部观察者 | **C-Box + FRI**：接触是一等计量对象，力旋量是可编程探针 | 质量、质心、惯量、摩擦锥、接触刚度、间隙、预紧力**只在施加受控力时显形**；力/力矩还是与视觉物理独立的内感受通道 |
| 电池管理（EKF-SoC、RLS-SoH、SoP、均衡、热失控） | IP-318 AP-Cal + 定义 428 P-Quarantine：修好即永久有效，只在事后断路 | **MHM**：校准资产是「会老化的电池组」，需持续估计、预测、均衡与热隔离 | 传感器漂移、磨损、温漂会让已修复契约随时间退化；「一次性热替换」没有寿命概念，P-Quarantine 只在污染发生后才反应 |

**核心命题**：把 ToolGauge 的「契约化工具调用 + 摊销校准 + 交叉验证热替换」升级为
「**接触力控探测 + 计量健康管理（SoC/SoH/SoP）+ 最弱单元均衡 + 寿命感知退化**」：
力控只为**可辨识且安全**的接触参数生成物理激励；数值真值仍由计量层独占；
BMS 式健康管理只做门控、调度与熔断，不进入数值通道。

**合成链：MODGAUGE ⊃ LeanGauge ⊃ ToolGauge ⊃ ForceGauge**（后者是能力最强的**可选**增强层）。

**不变式保持声明**：
- MODGAUGE 五不变式（契约完整性、组合单调性、反作用通道完备、主张绑定、严格退化链）全部保留；
- **严格退化链延长**：ForceGauge 失效（力包络不可满足 / 接触不可辨识 / SoH 或 SoP 不达标）⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE；
- **新增「有界作用力不变式」**：任何探测的峰值力/总冲量/接触压强不得超过预注册物理包络；无包络的未知物体 ⇒ 只允许零力探测（退回 ToolGauge）。这是本轮对第 2 轮「零副作用」安全姿态的**明确降级与补偿**。

## 0. 直觉与动机

### 灵感 1（力控 → 接触是一等计量对象，力是可编程的探针）

直觉：ToolGauge 的工具库 T₀ 全是「看、照、敲、热」——本质上是把机器人当成一个**外部观察者**，
用非接触或准静态外感受测量世界。但装配、插拔、拧紧、抓取这些接触丰富任务里，最有价值的物理量
（质量、质心、转动惯量、摩擦锥、接触刚度、间隙、预紧力）**根本不会在「看」里出现**，它们只在
**施加受控力**时才显形。力控（阻抗/导纳、混合位置-力控制）恰好提供「把力变成可编程探针」的语言：
选择矩阵 S 把任务空间切成力控子空间与位置控子空间，导纳参数把「柔顺」变成可设计的动力学，
接触态（自由/滑移/粘滞/冲击/分离）是接触力学的隐含标签。

映射到 MODGAUGE：盲区不再只是「格子 (d,m,i) 没验证过」，而是
「**接触态空间里某个 (位姿 × 力旋量 × 接触模式) 区域没有被验证过**」。力/力矩回执带来两类全新证据：
(a) **内感受通道**，与视觉/IR 等外感受通道在物理上独立——正好补上第 2 轮「独立回执交叉验证」
最缺的**独立性来源**（此前只能靠 cross.modal 模拟独立）；(b) **动力学一致性约束**
（摩擦锥、牛顿-欧拉、能量守恒），把「观测是否有效」从签名层推进到物理层。
代价是：**探测从「零副作用」变成「有界但真实的作用力」**，安全论证必须整体重写。

### 灵感 2（电池管理 → 校准资产不是一次性事件，而是会老化的电池组）

直觉：ToolGauge 把每次修复当成「修好即永久有效」的热替换；P-Quarantine 只在事后发现相关性污染。
但真实系统里，传感器漂移、机械磨损、温漂、先验过期会让已修复的契约**随时间退化**——
第 2 轮完全没有「寿命」概念。BMS 的整套方法论正是为此而生：
状态测不到就**估计**（EKF 估 SoC），参数会变就**辨识**（RLS 估内阻/容量），
容量会衰减就**建模**（SoH），能力受限就**限功率**（SoP），单体不一致就**均衡**（balancing），
会热失控就**热管理**（隔离/熔断）。

映射：把每个校准契约 / 子图 / 盲区簇视作一节「**计量单元 (metrology cell)**」：
- **SoC_al ≈ 可信覆盖度**（还「存」着多少可信校准，类比荷电状态）；
- **SoH_al ≈ 契约有效容量**（老化后最多还能达到多少覆盖，类比健康度）；
- **SoP_al ≈ 还能安全施加的探测功率**（力上限 / 预算 / 访问频次，类比峰值功率能力）；
- **R_int ≈ 信息阻抗**（单位方差缩减所需代价，随老化与温度上升）；
- **均衡 ≈ 跨盲区预算/先验调度**，使组内「最弱单元」不拖垮整体覆盖；
- **热失控 ≈ 相关性污染连锁**（正是第 2 轮最大风险），用组级热管理隔离。

第 2 轮的「热替换」于是升级为「**带衰减的资产 + 持续健康估计 + 主动维护**」：
不是修完就不管，而是预测它何时会坏、在坏之前按计划补测、并在组级别做最弱单元感知的预算均衡。

### 合流点

力控提供「高信息密度但高风险」的探测动作；BMS 提供「风险/寿命感知的资产管理」。
两者合起来，把第 2 轮「在给定预算下修盲区」升级为
「**在力安全包络与资产寿命约束下，最大化最弱单元的长期可信度**」。
并且两者互补地解决同一个老问题：第 2 轮的「独立回执」靠 cross.modal 合成，独立性存疑；
力/力矩是**物理上真独立**的第二模态，且其「老化」正好可用 BMS 的观测-估计框架在线跟踪。

## 1. 形式化定义（增量：定义 432–447）

**定义 432（接触态与力旋量空间）** 接触态 c ∈ 𝒞 = {free, sliding, sticking, impact, separating}。
接触力旋量 w = (f, τ) ∈ ℝ⁶，在接触坐标系分解为法向 f_n ≥ 0 与切向 f_t ∈ ℝ²。
力控探测在混合控制下执行：选择矩阵 S = diag(s₁…s₆)，s_i ∈ {0,1}，range(S) 为力控子空间，
range(I−S) 为位置控子空间；导纳律 M_d ẍ + D_d ẋ + K_d x = f_ext − f_d。

**定义 433（接触扩展的探测程序）** Π_s^F = ((t₁,a₁,c₁^target),…,(t_L,a_L,c_L^target))，L ≤ L_max；
每个调用声明目标接触态 c^target 与力控模式 (S, f_d, 导纳参数)。
TCV-F 在 TCV 四查之上再加三查：① c^target 在预注册接触态转移图内可达；
② 力包络 f_d ⊕ 跟踪误差 ≤ f_env(obj)；③ 激励秩 ρ(Π) ≥ κ_id（定义 435）。

**定义 434（力回执与物理合法性）** r^F = (t, args, w_meas, c_meas, x_meas, sig, ts, seq)。
physical_valid(r^F) ⇔
① 摩擦锥 |f_t| ≤ μ̂·f_n + ε_μ；
② 单边接触 f_n ≥ −ε_n；
③ 牛顿-欧拉残差 ‖Y(q,q̇,q̈)θ̂ − w_meas‖ ≤ ε_NE；
④ 能量账 ∫ f·v dt ∈ [−E_diss, E_inj,max]；
⑤ 力包络 f_n ∈ [f_min,f_max]、‖τ‖ ≤ τ_max、‖ḟ‖ ≤ j_max。
任一不满足 ⇒ 回执作废，且**触发接触态重估**（不是静默丢弃——这是与第 2 轮定义 417 的差别）。

**定义 435（接触参数可辨识性与激励秩）** 惯性/接触参数 θ = (m, mc, I, μ, k_c, b_c) 由回归
Y(q,q̇,q̈)θ = w 辨识。程序 Π 的激励矩阵 Φ(Π) = σ_w⁻² Σ_k Y_kᵀY_k，激励秩 ρ(Π) = λ_min(Φ)。
可辨识条件 ρ(Π) ≥ κ_id。**被动观测（无力激励）下 ρ≈0 的「不可辨识盲区」，只有力控激励才能推入可辨识域**——
这形式化了「力探针为什么能看见看不见的东西」。

**定义 436（计量单元与健康状态向量）** 每个校准契约字段/子图/盲区簇 j 是一节计量单元，
健康状态 x_j = (SoC_j, SoH_j, R_j, T_j)：SoC_j∈[0,1] 可信覆盖度；SoH_j∈[0,1] 有效容量比；
R_j ≥ R_min 信息阻抗；T_j∈[0,1] 与邻居的相关性污染度（「温度」）。

**定义 437（等效电路式校准模型 ECM-Cal）** 单元 j 的「端电压」（可观测可信度）：
V_j = OCV_j(SoC_j) − R_j·i_j − V_RC,j，
其中 OCV_j(·) 由物理先验/MP-Φ 给出（单调、Lipschitz），i_j 为漂移/证据消耗「电流」，
V_RC 为一阶 RC 瞬态 dV_RC/dt = −V_RC/(R_pC_p) + i_j/C_p。
校准既会「放电」（漂移侵蚀），也会「充电」（补测/交叉验证增益）。

**定义 438（SoC 的 EKF 估计）** 状态 x=(SoC, V_RC)，离散化 (A,B,C)；观测 z = V_meas
（由 V 阶段交叉验证残差换算的等价置信度）。标准 EKF 预测/更新；
「库仑计数」对应 SoC⁻ = SoC − η⁻¹ Σ i_j Δt；在可观性与有界非线性下误差协方差有界（引理 53）。

**定义 439（SoH 与容量衰减，RLS 辨识）** 容量衰减 C_eff(t) = C_nom·(1 − α·N_cycle − β·t)，
内阻增长 R(t) = R₀(1 + γ·N_cycle + δ·t)。Θ=(α,β,γ,δ) 由带遗忘因子 λ_f 的 RLS 在线辨识：
Θ̂ ← Θ̂ + Pφ(y−φᵀΘ̂)/(λ_f+φᵀPφ)，P ← (P − PφφᵀP/(λ_f+φᵀPφ))/λ_f。
SoH = C_eff/C_nom；SoH < h_min ⇒ 该单元「报废」，触发主动维护或退化。

**定义 440（SoP 与探测功率包络）** SoP_j = max P s.t. ΔV_j(P) ≥ ΔV_min ∧ P ≤ P_force_env ∧ T_j ≤ T_trip。
即可用探测力/预算由「可信度不跌穿下限」「不超力包络」「不超热阈值」三者联合决定；
SoP 直接门控 T-Box 的增益注 β_t（只有 SoP 内的调用才计为可行）。

**定义 441（计量均衡 MBal）** 给定单元集合 {j} 的 SoC_j 与总预算 B，分配 b_j 使
max min_j (SoC_j + g_j(b_j))，g_j 为凹边际收益，约束 Σb_j ≤ B、b_j ≥ 0。
max-min 凹规划用注水法求唯一最优；**最弱单元决定系统级可信度**。

**定义 442（相关性热失控与隔离屏障）** T_j 由单元 j 与「共享先验/共享传感器」邻居的残差相关系数估计。
正反馈：T_j↑ ⇒ R_j↑ ⇒ SoC_j↓ ⇒ 更多补测 ⇒ 更多共享先验 ⇒ T_j↑。
熔断：T_j ≥ T_trip 或 dT_j/dt ≥ τ_heat ⇒ 该**连通分量整体**隔离（不只是单单元 P-Quarantine），
强制改用不共享先验的独立通道回执；无法独立 ⇒ 整组降级到 LeanGauge。
这是对第 2 轮「跨盲区强相关」风险的**组级热管理**。

**定义 443（主动维护探测 AMP）** 按日历老化与循环老化预测，在 SoC 跌破维护阈值前安排补测：
t* = argmin_t [E[维护成本] + E[故障成本 | SoC(t)]]。维护分 calendar（时间驱动全量校验）
与 cycle（探测次数驱动定向补测）。

**定义 444（有界作用力不变式 SFE）** 任何接触探测须满足峰值力 ≤ f_env(obj)、总冲量 ≤ J_env(obj)、
接触压强 ≤ p_env(obj)；包络来自预注册材质先验或 VLA 材质假设的**保守下界**。
无包络 ⇒ f_env = 0（只允许零力探测）。

**定义 445（寿命感知退化链）** SoH_j < h_min 或 SoP_j < p_min 或 SFE 不可满足 ⇒ 该单元退化
ForceGauge→ToolGauge→LeanGauge→MODGAUGE。退化单调（不自动升级），重新升级须通过完整 V 阶段。

**定义 446（健康账本与风险预算）** HL = {x_j, Θ̂_j, 维护记录}；
系统级风险预算 R_sys = Σ_j w_j(1 − SoC_j·SoH_j)；每次探测须 ΔR_sys ≤ 0 或由预算显式支付。

**定义 447（继承与编号约定）** 未重定义者沿用 416–431；
令 𝒞={free}、T₀^F=∅、MHM 恒等 ⇒ ForceGauge ≡ ToolGauge。

## 2. 推导（引理 51–56）

**引理 51（力控探测的接触安全界）** 设力跟踪误差 e_f 关于包络边界亚高斯（参数 b_f），f_env ≤ f_yield/S_f，则
P(f_peak > f_yield) ≤ exp(−(f_yield−f_env)²/2b_f²)；冲量用 Chebyshev：P(J > J_yield) ≤ b_J²/(J_yield−J_env)²。
**系**：SFE 只保证「有界作用力」，**不保证「零副作用」**——这是本轮相对第 2 轮安全姿态的根本变化。
证明思路：力跟踪误差分解为模型误差 + 控制误差，分别用亚高斯与有界项控制；再用 union bound 覆盖冲量。

**引理 52（接触参数可辨识性界）** 在 ρ(Π) ≥ κ_id 与有界噪声 ‖ε‖ ≤ ε_w 下，‖θ̂−θ‖ ≤ ε_w/√ρ(Π)；
信息增益 Ĝ_t^F = ½ log det(I + Φ_t/σ²) 随激励秩单调增。
**推论 52.1**：被动不可辨识盲区（ρ≈0）在力控激励下获得有限误差界——「力探针」是可辨识性的开关。
证明思路：最小二乘误差界由 λ_min 控制；信息增益用高斯通道容量公式，Φ 的特征值越大增益越大。

**引理 53（SoC EKF 收敛界）** 若 (A,C) 一致可观、f,h 为 Lipschitz（L_f,L_h），则存在 P̄ 使后验协方差 ≼ P̄，
且 E‖x̂−x‖² ≤ tr(P̄)/(1−γ)（压缩因子 γ<1）。库仑计数漂移被交叉验证观测持续校正。
证明思路：标准 EKF 有界性（协方差一致有界 + 可观测性 ⇒ 指数遗忘初始误差）。

**引理 54（均衡的最弱单元最优性）** 对凹边际收益 g_j，max-min 注水解唯一最优，且所有未饱和单元边际收益相等（KKT）。
**系**：系统级可信度 = 最弱单元 SoC，故均衡严格优于平均分配（除非所有单元同质）。

**引理 55（热隔离的有效性）** 若相关性污染在隔离后不跨连通分量传播，则隔离分量的 P-Quarantine 不传染健康分量；
组级降级只在熔断分量内发生。对照：无隔离时相关 ρ 沿共享先验链按 ρ^d 传播。

**引理 56（健康管理不破坏不变式与实时性）** MHM/MBal/热管理全在异步修复路径；
50Hz 路径只有 O(1) 的 SoC 门控（读缓存），EKF/RLS 异步；退化链单调 ⇒ 五不变式与硬实时保持。

## 3. 本轮最大风险

**一句话**：力控探测把第 2 轮的「零副作用」安全姿态永久打破——**作用力本身**可能损坏未知/易碎物体；
而 BMS 式健康指标（SoC/SoH 看起来正常）会对「包络模型失配」产生**健康幻觉**，
使系统在物理破坏真正发生前没有任何告警，甚至以「资产健康」为理由批准更大的探测力。

**次级风险与缓解**：
1. **力包络模型错误**（摩擦/刚度/质量估计偏差）→ 保守下界 + PROBING 显式态 + 力矩硬限 + 无包络即零力（定义 444）；
2. **健康幻觉**（SoC/SoH 掩盖模型失配）→ 定义 426 解析门槛 + 独立力通道交叉验证 + E444/E451 证伪；
3. **相关性沿共享先验扩散** → 连通分量级热隔离（定义 442）+ 独立传感器回执；
4. **SoH/SoP 估计被对抗操纵**（伪造老化/回执）→ 签名 + seq + 物理合法性五查（定义 434）；
5. **均衡饥饿**（强势单元长期挤占预算）→ max-min 硬约束 + 最弱单元优先维护；

## 2. 形式化定义（要点）

**定义 432（接触态/力旋量）** 接触态 c∈𝒞；混合控制选择矩阵 S 分力控/位控子空间；导纳律 M_dẍ+D_dẋ+K_dx=f_ext−f_d。
**定义 433（TCV-F 三查）** 在 schema/前置/预算/循环之上加：接触态可达、力包络满足、激励秩达标。
**定义 434（力回执五查）** 摩擦锥、单边接触、牛顿-欧拉残差、能量账、力包络；失败触发接触态重估。
**定义 435（可辨识性）** 回归 Yθ=w，ρ(Π)=λ_min(σ_w⁻²ΣYᵀY)≥κ_id；被动不可辨识盲区靠力激励打开。
**定义 436–440（MHM）** 计量单元 x=(SoC,SoH,R,T)；ECM-Cal 端电压 V=OCV(SoC)−R·i−V_RC；
EKF 估 SoC；RLS 辨识 Θ 得 SoH；SoP 联合力包络/热阈值/可信度下限门控探测功率。
**定义 441（均衡）** max min_j(SoC_j+g_j(b_j)) s.t. Σb_j≤B；注水法唯一最优。
**定义 442（热失控）** T_j 由共享先验邻居残差相关估计；正反馈 + 连通分量级隔离熔断。
**定义 443（主动维护）** t*=argmin E[维护]+E[故障|SoC(t)]；calendar/cycle 两类维护。
**定义 444（SFE）** 峰值力/冲量/压强 ≤ 预注册包络；无包络 ⇒ 零力探测。
**定义 445（寿命退化链）** SoH/SoP/SFE 任一不达标 ⇒ 单调退化到 ToolGauge→LeanGauge→MODGAUGE。
**定义 446（健康账本）** R_sys=Σw_j(1−SoC_j·SoH_j)；探测须不增总风险或显式付费。
**定义 447（退化约定）** 𝒞={free}、T₀^F=∅、MHM 恒等 ⇒ ForceGauge ≡ ToolGauge。

# IP-321 C-Box：接触态扩展的盲区与力探针选择
class CBox:
    def blind_spots(self, R):
        # 盲区 = (pose, wrench-bin, contact-mode) 未验证区域
        return [(s, w_bin, c) for s in R.unverified()
                for c in reachable_modes(s) for w_bin in wrench_bins(s)]

    def contact_hypotheses(self, s, R_cell):
        hs = self.lbox.propose(s, R_cell)                  # 继承 IP-315（白名单数值输入）
        hs = [h for h in hs if contact_consistent(h, R_cell)]  # 摩擦锥/接触态指纹
        return hs or ["UNKNOWN"]

# IP-322 FRI：力回执物理合法性（五查）
def physical_valid(r, theta_hat, env):
    f_n, f_t, tau = decompose(r.w, r.frame)
    return (norm(f_t) <= theta_hat.mu * f_n + EPS_MU        # ① 摩擦锥
            and f_n >= -EPS_N                               # ② 单边
            and norm(regressor(r.q) @ theta_hat - r.w) <= EPS_NE  # ③ N-E
            and -env.E_diss <= r.energy <= env.E_inj_max    # ④ 能量账
            and env.f_min <= f_n <= env.f_max               # ⑤ 力包络
            and norm(tau) <= env.tau_max and norm(r.fdot) <= env.j_max)

def accept_force_receipt(r, theta_hat, env):
    if not verify_sig(r) or not seq_monotone(r): return None
    if not physical_valid(r, theta_hat, env):
        schedule_contact_reestimate(r)   # 不静默丢弃：触发接触态重估
        return None
    return r

# IP-323 MHM：ECM-Cal + EKF-SoC + RLS-SoH + SoP
class MHM:
    def __init__(self, n_cells):
        self.x   = [{"SoC": 1.0, "V_RC": 0.0} for _ in range(n_cells)]  # EKF 状态
        self.P   = [np.eye(2) for _ in range(n_cells)]
        self.Theta = [np.zeros(4) for _ in range(n_cells)]             # RLS 参数
        self.RlsP  = [1e3 * np.eye(4) for _ in range(n_cells)]

    def ekf_predict(self, j, i_j, dt):
        A, B, C = ecm_discretize(self.Theta[j], dt)
        self.x[j] = A @ self.x[j] + B * i_j
        self.P[j] = A @ self.P[j] @ A.T + Q_proc
        return C @ self.x[j]

    def ekf_update(self, j, z):
        C = ecm_observe(self.Theta[j])
        S = C @ self.P[j] @ C.T + R_meas
        K = self.P[j] @ C.T / S
        self.x[j] = self.x[j] + K * (z - C @ self.x[j])
        self.P[j] = (np.eye(2) - K @ C) @ self.P[j]

    def rls_update(self, j, phi, y, lam_f=0.98):
        P, th = self.RlsP[j], self.Theta[j]
        K = P @ phi / (lam_f + phi @ P @ phi)
        th += K * (y - phi @ th)
        P = (P - np.outer(K, phi @ P)) / lam_f
        self.Theta[j] = th; self.RlsP[j] = P

    def state_of_health(self, j):
        alpha, beta, gamma, delta = self.Theta[j]
        C_eff = 1.0 - alpha * n_cycles(j) - beta * calendar_age(j)
        R_grow = 1.0 + gamma * n_cycles(j) + delta * calendar_age(j)
        return max(0.0, C_eff), R_grow

    def state_of_power(self, j, env, dv_min, t_trip):
        return max_power(self.x[j]["SoC"], self.state_of_health(j),
                         dv_min, env.f_max, self.T[j], t_trip)

# IP-324 MBal：max-min 注水均衡
def balance_cells(cells, budget):
    # g_j 凹 ⇒ 二分注水水位 mu，使 Σ_j b_j(mu) = budget
    lo, hi = 0.0, max(c.SoC for c in cells) + budget
    for _ in range(64):
        mu = 0.5 * (lo + hi)
        used = sum(max(0.0, inv_marginal(c, mu)) for c in cells)
        (lo, hi) = (mu, hi) if used < budget else (lo, mu)
    return {c.id: max(0.0, inv_marginal(c, mu)) for c in cells}

# IP-325 TTB：相关性热屏障（连通分量级熔断）
class ThermalBarrier:
    def update_temp(self, cells, residuals):
        for comp in connected_components(self.share_graph):      # 共享先验/传感器
            rho = est_corr(residuals[comp])
            for j in comp:
                self.T[j] = ema(self.T[j], rho)
                if self.T[j] >= self.T_trip or dT(self.T[j]) >= self.tau_heat:
                    self.isolate(comp)                            # 整分量隔离
                    break

    def isolate(self, comp):
        for j in comp:
            cells[j].force_independent_channel = True
            if not independent_receipts_available(j):
                cells[j].degrade_to(LeanGauge)                    # 无独立通道 ⇒ 整组降级

# IP-326 ForceGauge 主闭环（在 ToolGauge-6C 之上插入接触与健康门控）
def forcegauge_6c(M, s):
    H  = M.cbox.contact_hypotheses(s, M.dbox.R[s])                 # 接触态假设
    if H == ["UNKNOWN"]: return M.toolgauge_6c(s)                 # 退化链第 1 级
    prog = M.tbox.select(H, M.tools_F, M.tcvF, M.budget_left(s))  # 带 TCV-F
    if not M.sfe.admissible(prog, M.env, H):                      # 无包络/超包络
        return M.toolgauge_6c(s)                                  # 退回零力探测
    prog = M.mbal.allocate(M.cell(s), prog, M.budget_left(s))     # 均衡后预算
    receiptsF = M.tcvF.execute(prog, M.env)                       # PROBING 力控态
    receiptsF = [r for r in receiptsF
                 if accept_force_receipt(r, M.theta_hat(s), M.env)]
    if not M.identifiable(receiptsF): return M.toolgauge_6c(s)    # ρ<κ_id ⇒ 退化
    mu, Sig = M.apcal.calibrate(receiptsF, H, s)                  # 继承 IP-318
    if not M.apcal.cross_validate(mu, Sig, M.cross_receipt(s)):
        return M.toolgauge_6c(s)
    new_ec = M.apcal.update_contract(M.dpe, mu, Sig, s)
    if not contract_regression(new_ec): return M.toolgauge_6c(s)
    M.mreg.hot_replace(M.dpe, new_ec)
    M.mhm.ekf_predict(s, drift_current(s), dt=M.dt)               # 健康状态更新
    M.mhm.ekf_update(s, confidence_from(new_ec))
    M.mhm.rls_update(s, aging_regressor(s), observed_aging(s))
    M.thermal.update_temp(M.cells, M.recent_residuals())
    M.hl.record(s, M.mhm.x[s], M.mhm.Theta[s])                    # 健康账本
    return True

## 4. 推导（引理 51–56）

**引理 51（力控安全界）** f_env ≤ f_yield/S_f、力误差亚高斯 b_f ⇒ P(f_peak>f_yield) ≤ exp(−(f_yield−f_env)²/2b_f²)；
冲量 Chebyshev 界。系：SFE 只给「有界作用力」，不给「零副作用」。
**引理 52（可辨识性界）** ρ(Π)≥κ_id ⇒ ‖θ̂−θ‖ ≤ ε_w/√ρ(Π)；Ĝ_t^F=½logdet(I+Φ_t/σ²)。推论 52.1：力激励是可辨识性开关。
**引理 53（EKF 有界性）** (A,C) 一致可观 + Lipschitz ⇒ 后验协方差 ≼ P̄，E‖x̂−x‖² ≤ tr(P̄)/(1−γ)。
**引理 54（均衡最优性）** 凹 g_j 的 max-min 注水解唯一且 KKT 边际相等；系统可信度 = 最弱单元。
**引理 55（热隔离有效性）** 隔离后污染不跨连通分量；无隔离时按 ρ^d 沿共享先验链传播。
**引理 56（不变式与实时性）** MHM/MBal/TTB 全异步；50Hz 仅 O(1) SoC 门控；退化单调 ⇒ 五不变式与硬实时保持。

## 8. 本轮最大风险

**一句话**：力控探测把「零副作用」安全姿态永久打破——**作用力本身**可能损坏未知/易碎物体，
而 BMS 式健康指标（SoC/SoH 看起来正常）会对「包络模型失配」产生**健康幻觉**，
使系统在物理破坏真正发生前没有任何告警，甚至以「资产健康」为理由批准更大的探测力。

以 E441/E450/E451 证伪、以 SFE（定义 444）+ 无包络零力 + 力矩硬限 + TTB（定义 442）四重兜底。
