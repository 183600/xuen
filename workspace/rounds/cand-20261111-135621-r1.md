# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「模型蒸馏」×「低成本方案」）

> 第 54 轮把技能组合从“能力匹配”提升为「动作-鲁棒性双证书」`J=(ρ, A_cert, γ_ce, δ_a)`，代价是证书生成与组合规划高度依赖云端重教师：组合图 A*、结构化仿真、鲁棒性谱计算。本轮追问一个工程上更尖锐的问题：**能否用蒸馏把这套重证书压成边端可承受的轻证书，同时不把 soundness 一起蒸馏掉？** 核心矛盾：**H22**：证书蒸馏存在“相变点”——压缩率越过某个阈值后，学生证书不再保守，开始对可靠包络之外的动作与任务过度签发；**H23**：低成本不是“压缩率最大化”，而是 **风险-成本约束下的选择性签发与可靠弃权**（abstention），把不可承担的风险显式升级给云端，而不是静默地赌学生模型没出错。

## 0. 直觉与动机

**灵感 1（证书蒸馏 → 蒸馏的不是模型，而是“可保守外推的判定域”）**
直觉：普通模型蒸馏把教师输出 `f_T(x)` 拟合成学生输出 `f_S(x)`；但安全证书蒸馏的目标函数不是逐点拟合，而是 **保持判定方向**。学生只要在包络 `Ω_D` 内比教师更悲观（`ρ̂ ≤ ρ`、`Â_core ⊆ A_core`、`δ̂_a ≥ δ_a`），就永不产生“虚假安全”；风险来自 `Ω_D` 的误画，而不是来自拟合误差本身。于是蒸馏产物必须显式携带 **可靠包络 `Ω_D`** 与 **弃权位**，而不是一个裸的压缩网络。

**灵感 2（风险可控蒸馏 → 用 conformal 把“学生何时可信”变成可统计的阈值）**
直觉：与其相信学生证书的绝对数值，不如只相信它的 **排序 / 非一致性分数**。在标定集上选一个签发阈值 `λ_τ`，使“学生签发但实际失败”的比例被 `R_max` 控制、且弃权率 ≤ α。这把“低成本”从压缩率问题，转成 **覆盖率-风险曲线** 上的受约束选择：宁可少签发 15%，也不签发一次错误证书。

**灵感 3（成本账本 → 维度级预算分配，而不是全局一刀切）**
直觉：鲁棒性谱的各维度 `d` 与动作子集 `a` 的安全价值并不相等。低成本方案应像投资组合：给每个维度/动作分配 `b_d` 比特与算力，使 **单位成本的边际成功率增益** 最大。由此得到 `cost(J)=c_b·bytes+c_l·latency+c_f·flops+c_e·energy` 的账本，以及“成本-可靠”Pareto 前沿；决策依据是 `GCR=ΔP_success/Δcost`，而不是参数量的绝对值。

**灵感 4（蒸馏级联 → 廉价验证器只许否决、不许越过教师批准）**
直觉：边端不需要一次算全证书。先用极小验证器 `V_0` 做“绊线”：它可以说“可疑/拒绝”，但 **不允许**在教师未批准的区域内说“通过”（单调否决）。可疑样本逐级升级 `V_1→...→V_k=教师/仿真`。期望成本是级联命中率的函数，安全则靠 `accept_i ⊆ accept_{i+1}` 的结构约束兜底。这与第 54 轮 Explain 回传天然衔接：低层否决触发的是“升级”，不是“重规划”。

**灵感 5（节俭证书金字塔 → 在 𝕃 与 𝔸 之上加一层 𝔻）**
直觉：第 53 轮有鲁棒性层 `𝕃`，第 54 轮有动作-协同层 `𝔸`。本轮叠加 **蒸馏/成本层 `𝔻`**：`𝔻_0` 教师判定域，`𝔻_1` 学生证书+包络，`𝔻_2` 级联验证器，`𝔻_3` 弃权/升级通道。跨层传递的不是“更小的证书”，而是 **带包络与成本账本的证书**：`(J, Ω_D, λ_τ, ledger, abstain)`。低成本因此是一个 **可解释、可审计的降级策略**，而非黑箱压缩。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（证书蒸馏与可靠包络）**
教师联合证书 `J=(ρ,A_cert,γ_ce,δ_a)`（第 54 轮定义 120）。蒸馏算子 `D` 生成学生证书
`Ĵ = D(J) = (ρ̂, Â_cert, γ̂_ce, δ̂_a, Ω_D)`，其中 `Ω_D ⊆ 𝔗 × 𝔇` 为 **可靠包络**（任务×维度域）。称 `D` 在 `Ω_D` 上 **ε-可靠且保守**，当且仅当 `∀(T,d)∈Ω_D`：
```
Â_core(T) ⊆ A_core(T),   ρ̂_d(T) ≤ ρ_d(T),   δ̂_a(T) ≥ δ_a(T),   max_d(ρ_d-ρ̂_d) ≤ ε_ρ
```
且 `cover(Â_core, A_T)` 的判定与教师一致。`(T,d) ∉ Ω_D` 时学生 **必须弃权**（`abstain=1`）。保守性保证学生不会“虚假安全”；`ε_ρ` 只计入覆盖率与成本，不直接侵蚀 soundness。

**定义 122（风险-覆盖曲线与风险可控蒸馏）**
对签发阈值 `λ`，覆盖 `C(λ)=P(Ĵ 签发)`，风险 `R(λ)=P(fail | Ĵ 签发)`。风险可控蒸馏求解：
```
min_{Ĵ,λ}  cost(Ĵ)   s.t.   R(λ) ≤ R_max,  C(λ) ≥ C_min
```
用 split-conformal：在标定集上取非一致性分数 `s(x)` 的分位数作为 `λ_τ`，使弃权率 `1-C(λ_τ) ≤ α`；则在可交换假设下 `R_test ≤ R_cal + gap` 以至少 `1-α` 的概率成立。

**定义 123（证书成本账本）**
`cost(J) = c_b·bytes(J) + c_l·lat(J) + c_f·flops(J) + c_e·energy(J)`。
维度级预算 `b_d` 满足 `Σ_d b_d ≤ B`；蒸馏收益比 `GCR(J→Ĵ) = ΔP_success / Δcost`。决策规则：在 Pareto 前沿上选 `GCR` 最大且 `R ≤ R_max` 的点。

**定义 124（蒸馏级联与单调否决）**
级联 `V_0, V_1, ..., V_k`（`V_k` 为教师/结构化仿真），每级输出 `accept/reject/abstain`。**单调否决约束**：
```
accept(V_i) ⊆ accept(V_{i+1}),   reject(V_i) ∩ accept(V_k) = ∅
```
期望成本 `E[cost] = Σ_i P(reach_i)·c_i + P(escalate)·c_teacher`。任何最终 `accept` 要么经过 `V_k`，要么落在 `Ω_D` 内。

**定义 125（组合路由器蒸馏）**
教师组合图 `G_S` 上 A* 产生的带证书路径集 `Paths_cert(G_S)`。学生路由器 `π̂: x ↦ path`，一致性集
`Cons(π̂) = {x | π̂(x) ∈ Paths_cert(G_S)}`。在 `Cons(π̂)` 之外强制 `abstain` 或回退到云端搜索；训练损失含路径可行性惩罚 `L_feas`。

**定义 126（节俭联合证书 FJC）**
`J_λ = (Ĵ, Ω_D, λ_τ, ledger, abstain)`。部署判定：
```
deploy(T)=1 ⟺ (T∈Ω_D) ∧ (λ≥λ_τ) ∧ (Â_core ⊆ A_T) ∧ (δ̂_a<Θ_a) ∧ (ledger.cost ≤ B)
```
否则进入级联或升级云端；**弃权不是失败，而是显式降级**。

## 2. 关键算法 伪代码

### IP-121 CDN（Certificate Distillation with eNvelope）

```python
def distil_certificate(J_teacher, student, calib_tasks, eps_rho):
    envelope = []
    for x in calib_tasks:
        rho_hat = student.rho(x)
        A_hat   = student.action_core(x)
        d_hat   = student.delta_a(x)
        conservative = (A_hat <= J_teacher.A_core[x]
                        and all(rho_hat[d] <= J_teacher.rho[x][d] for d in rho_hat)
                        and d_hat >= J_teacher.delta_a[x])
        gap = max(J_teacher.rho[x][d] - rho_hat[d] for d in rho_hat)
        if conservative and gap <= eps_rho:
            envelope.append(x)
        else:
            expand_teacher_queries(x)     # 主动补样，重训学生
    return StudentCert(student, envelope=frozenset(envelope), eps_rho=eps_rho)
```

### IP-122 RCK（Risk-Controlled calibration）

```python
def calibrate_lambda(scores, fails, R_max, alpha):
    order = sorted(range(len(scores)), key=lambda i: scores[i])
    for lam in sorted(set(scores), reverse=True):
        sel = [i for i in order if scores[i] <= lam]
        cover = len(sel) / len(scores)
        risk  = sum(fails[i] for i in sel) / max(1, len(sel))
        if risk <= R_max and (1 - cover) <= alpha:
            return lam
    return None   # 全弃权：宁可不用，不可错发
```

### IP-123 DCS（Distillation Cascade with monotone veto）

```python
def cascade_verify(x, verifiers, teacher, budget):
    for i, V in enumerate(verifiers):
        out = V(x)                       # 'accept' | 'reject' | 'abstain'
        if out == 'reject':
            return ('reject', f'veto@{i}')
        if out == 'accept' and V.certified(x):
            if not teacher.is_within_envelope(x):
                return ('reject', f'veto@{i}:out_of_envelope')
            return ('accept', i)
    if budget.remaining() >= teacher.cost(x):
        return teacher(x)                # 升级到重教师
    return ('abstain', 'budget_exhausted')
```

### IP-124 CRD（Composition Router Distillation）

```python
def distil_router(G_S, demo_tasks, student):
    feasible = set(paths_with_cert(G_S))
    for x in demo_tasks:
        p = a_star(G_S, task=x)
        if p is None:
            continue
        student.fit(x, p, loss=path_ce(p) + lambda_f * infeasible_penalty(p, feasible))
    return Router(student, cons_set=feasible)
```

### IP-125 FJC + IP-126 CLB（Cost Ledger Budgeting）

```python
def budget_allocate(dims, B, marginal_value, unit_cost):
    b = {d: 0 for d in dims}
    while sum(b.values()) < B:
        d = max(dims, key=lambda k: marginal_value(k, b[k] + 1) / unit_cost(k))
        if marginal_value(d, b[d] + 1) <= 0:
            break
        b[d] += 1
    return b

def frugal_certificate(J, student, calib, B, R_max, alpha):
    J_hat = distil_certificate(J, student, calib, eps_rho=EPS)
    lam   = calibrate_lambda(scores(J_hat, calib), fails(J_hat, calib), R_max, alpha)
    if lam is None:
        return FJC(J_hat, envelope=frozenset(), lam=None, ledger=None, abstain=True)
    ledger = cost_ledger(J_hat, lam)
    if ledger.cost > B:
        b = budget_allocate(J_hat.dims, B, marginal_success_gain, unit_cost)
        J_hat = prorate_dimensions(J_hat, b)      # 维度级剪枝，保留核心动作
    return FJC(J_hat, J_hat.envelope, lam, ledger, abstain=False)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| CDN | O(|calib|·|𝔇| + Q·|A|) | O(|calib|·|𝔇|) | 包络保守、gap 可测 |
| RCK | O(n log n) | O(n) | 可交换性、阈值覆盖 |
| DCS | O(Σ_i P(reach_i)·c_i) | O(|V|) | 单调否决、升级完备 |
| CRD | O(|demo|·(|E| log |V|)) | O(|Path|) | 可行性集合闭环 |
| CLB/FJC | O(|𝔇|·B) | O(|𝔇|) | 预算闭合、GCR 单调 |

**正确性定理（Risk-Controlled Frugal Certification Soundness）**
假设 **(A29)** 第 54 轮教师证书 `J` 在其判定域上 sound；**(A30)** 蒸馏在 `Ω_D` 上 ε-可靠且保守（定义 121）；**(A31)** 标定集与测试可交换，conformal 阈值 `λ_τ` 使弃权率 ≤ α；**(A32)** 级联满足单调否决（定义 124）；**(A33)** 路由器在 `Cons(π̂)` 外强制弃权。则对测试任务 `T`：
```
P(T 被签发且失败) ≤ [Σ_d(1-ρ_min(d)) + β_E + P(δ_a>Θ_a)] · (1-α) + α + ε_ρ
```
即：**低成本只来自“少签发/早升级”，不来自放宽教师 soundness**；一旦学生证书保守且包络正确，蒸馏本身不引入新的不安全点。期望成本满足
`E[cost] ≤ c_teacher·P(escalate) + Σ_i c_i·P(reach_i) ≤ B`。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 包络 `Ω_D` 外推失效 → 学生过度签发 | 高 | 主动补样 + OOD 检测 + 包络外强弃权 |
| conformal 可交换性被边端分布漂移破坏 | 高 | 在线重标定 + 分布漂移报警 + 回退教师 |
| 保守投影导致覆盖率崩塌（弃权风暴） | 高 | 分层阈值 + 核心动作保底 + 预算再分配 |
| 级联教师调用成本反噬 | 中 | 升级预算 + 缓存 + 早停 |
| 路由器把不可行路径记忆成可行 | 高 | 可行性集合硬约束 + 反例回放 + 路径证书复核 |
| 蒸馏后证书难以审计 | 中 | 成本账本 + 包络快照 + 证据链留存 |

## 6. 本轮最大风险

**一句话**：证书蒸馏把云端重证书压成边端轻证书，其低成本完全建立在“学生保守 + 包络正确 + 弃权可信”三件事同时成立之上；一旦边端分布漂移使 `Ω_D` 失效而 conformal 校准仍按旧分布签发，学生证书会从“可审计的降级”退化成“过度自信的虚假安全”，届时唯一的护栏是 **包络外强制弃权 + 在线漂移报警 + 升级教师的成本预算**——宁可多升级，绝不把压缩率当作安全裕度。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-FrugalCert（CDN×RCK×DCS×CRD×FJC×CLB）

> 承接第 54 轮产物 v31（GroundEdge-GenSim+++）。本轮在「动作-鲁棒性双证书」`J` 之上，增加 **证书蒸馏、风险可控签发、级联验证、组合路由器蒸馏、节俭证书、成本预算分配** 六个算子，把云端重证书体系压成边端可承受、可审计、可弃权的低成本方案：
> - **CDN（Certificate Distillation with eNvelope）**：`Ĵ = D(J)`，携带可靠包络 `Ω_D` 与保守性约束；
> - **RCK（Risk-Controlled calibration）**：conformal 阈值 `λ_τ`，把“学生何时可信”变成风险-覆盖约束；
> - **DCS（Distillation Cascade with monotone veto）**：廉价验证器只许否决、不许越级批准；
> - **CRD（Composition Router Distillation）**：教师 A* 路径蒸馏为边端路由器，`Cons(π̂)` 外弃权；
> - **FJC（Frugal Joint Certificate）**：`J_λ=(Ĵ,Ω_D,λ_τ,ledger,abstain)`，弃权即显式降级；
> - **CLB（Cost Ledger Budgeting）**：维度级预算 `b_d` 与 `GCR` 贪心分配。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-115/116/118/120 以携带包络与成本账本。

```python
        sel = [i for i in order if scores[i] <= lam]
        cover = len(sel) / len(scores)
        risk  = sum(fails[i] for i in sel) / max(1, len(sel))
        if risk <= R_max and (1 - cover) <= alpha:
            return lam
    return None
```

### IP-123 DCS

```python
def cascade_verify(x, verifiers, teacher, budget):
    for i, V in enumerate(verifiers):
        out = V(x)
        if out == 'reject':
            return ('reject', f'veto@{i}')
        if out == 'accept' and V.certified(x):
            if not teacher.is_within_envelope(x):
                return ('reject', f'veto@{i}:out_of_envelope')
            return ('accept', i)
    if budget.remaining() >= teacher.cost(x):
        return teacher(x)
    return ('abstain', 'budget_exhausted')
```

### IP-124 CRD

```python
def distil_router(G_S, demo_tasks, student):
    feasible = set(paths_with_cert(G_S))
    for x in demo_tasks:
        p = a_star(G_S, task=x)
        if p is None:
            continue
        student.fit(x, p, loss=path_ce(p) + lambda_f * infeasible_penalty(p, feasible))
    return Router(student, cons_set=feasible)
```

### IP-125 FJC + IP-126 CLB

```python
def budget_allocate(dims, B, marginal_value, unit_cost):
    b = {d: 0 for d in dims}
    while sum(b.values()) < B:
        d = max(dims, key=lambda k: marginal_value(k, b[k] + 1) / unit_cost(k))
        if marginal_value(d, b[d] + 1) <= 0:
            break
        b[d] += 1
    return b

def frugal_certificate(J, student, calib, B, R_max, alpha):
    J_hat = distil_certificate(J, student, calib, eps_rho=EPS)
    lam   = calibrate_lambda(scores(J_hat, calib), fails(J_hat, calib), R_max, alpha)
    if lam is None:
        return FJC(J_hat, envelope=frozenset(), lam=None, ledger=None, abstain=True)
    ledger = cost_ledger(J_hat, lam)
    if ledger.cost > B:
        b = budget_allocate(J_hat.dims, B, marginal_success_gain, unit_cost)
        J_hat = prorate_dimensions(J_hat, b)
    return FJC(J_hat, J_hat.envelope, lam, ledger, abstain=False)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CDN | O(|calib|·|𝔇| + Q·|A|) | O(|calib|·|𝔇|) | 包络内保守、gap 可测 |
| RCK | O(n log n) | O(n) | 可交换性、风险覆盖 |
| DCS | O(Σ_i P(reach_i)·c_i) | O(|V|) | 单调否决、升级完备 |
| CRD | O(|demo|·|E| log |V|) | O(|Path|) | 路径可行性硬约束 |
| CLB/FJC | O(|𝔇|·B) | O(|𝔇|) | 预算闭合、`GCR` 单调 |

**正确性定理（Risk-Controlled Frugal Certification Soundness）**
假设第 54 轮教师 `J` 在其判定域上 sound（A29）；**(A30)** 蒸馏在 `Ω_D` 上 ε-可靠且保守；**(A31)** 标定集与测试可交换，`λ_τ` 使弃权率 ≤ α；**(A32)** 级联单调否决；**(A33)** 路由器在 `Cons(π̂)` 外弃权。则
```
P(签发 ∧ 失败) ≤ [Σ_d(1-ρ_min(d)) + β_E + P(δ_a>Θ_a)]·(1-α) + α + ε_ρ
E[cost] ≤ c_teacher·P(escalate) + Σ_i c_i·P(reach_i) ≤ B
```
核心结论：**低成本只来自“少签发/早升级”，不来自放宽教师 soundness**；保守性约束使蒸馏不引入新的不安全点，`α` 是显式买来的“弃权保费”。

## 7. 本轮最大风险

**一句话**：证书蒸馏把云端重证书压成边端轻证书，其低成本完全建立在“学生保守 + 包络正确 + 弃权可信”三件事同时成立之上；一旦边端分布漂移使 `Ω_D` 失效而 conformal 校准仍按旧分布签发，学生证书会从“可审计的降级”退化成“过度自信的虚假安全”，届时唯一的护栏是 **包络外强制弃权 + 在线漂移报警 + 升级教师的成本预算**——宁可多升级，绝不把压缩率当作安全裕度。
