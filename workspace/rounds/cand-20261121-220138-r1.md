# 第 1 轮（新灵感循环第 1 轮；基线 v20；本轮灵感：「视觉编码器」×「步态规划」）

> **基线**：v20 产出 MetricVoiceGauge-NCD-HUTDH-v20 + IP-420–424（感知层：PCA/CTS/CFC/HPC/CFCtrl；定义 767–820；引理 151–156；实验 E751–E770）。
> 本轮纪律：**编码是带误差界的压缩，步态是带合同的接触序列**。不推倒 v20：v17 的 CLP/S2C/HCG/PSV/APS/AMC、v19 的 DCM/OGCC/CCV/DRS/OGC、v20 的 PCA/CTS/CFC/HPC/CFCtrl 全部保留。本轮只做一件事：**把视觉编码器的可证误差球，沿步态接触合同传播成足端/CoM 的鲁棒安全裕度，使“看见地形→迈出这一步”成为可审计的证书链**。

## 0. 直觉与动机

### 灵感 1（视觉编码器 → 编码不是“看懂世界”，而是“给出可传播的误差界”）
直觉：视觉编码器通常被当作一个“把图像压成 latent”的黑箱：训练时追求精度/泛化，部署时把输出当地形真值。但机器人踩下去的从来不是 latent，而是真实地面的高度、坡度、摩擦与可变形性。编码器在分布内的平均误差再小，也不能回答“这一步的最坏误差是多少”；而步态规划恰恰只关心最坏情况：脚掌落点偏 2cm、坡面被低估 5°、台阶被平滑成斜坡，都会让一个“看起来可行”的步态在接触瞬间失稳。更反直觉的是：**一个精度稍低但带紧致误差界的编码器，比一个精度更高但误差尾部未知的编码器更安全**。核心创新：**证书化视觉编码器（Certified Visual Encoder, CVE）** 与 **地形信念证书（Terrain Belief Certificate, TBC）**。CVE 不只输出高度图，还输出三样东西：certified Lipschitz 界 `L_F`、共形预测区间 `[h^-, h^+]`、以及 OOD 分数；TBC 把局部观测、位姿不确定度、量化/压缩误差融合成世界系区间地形 `B_T`。关键反直觉点：**编码器的目标不是“消除不确定性”，而是“把不确定性变成可传播、可求交、可拒绝的区间”**——区间只会随观测求交而收缩，遇到不一致或分布外就冻结，而不是用先验“补全”。

### 灵感 2（步态规划 → 步态不是轨迹，而是一串带合同的可恢复接触）
直觉：步态规划通常输出一条 CoM 轨迹 + 一串落脚点，然后用 MPC/WBC 跟踪。但步态真正的风险不在“轨迹是否平滑”，而在**接触是否成立**：抬脚时支撑多边形缩小、落脚时地面高度未知、单支撑期 CoM 是否仍在捕获域、打滑后能否恢复。把这些都塞进一个代价函数，等于把安全寄托在权重调参上。核心创新：**步态合同代数（Gait Contract Algebra, GCA）** 与 **鲁棒步态证书（Robust Gait Certificate, RGC）**。把每个步态相位 `k` 写成一个合同 `G_k = (Pre_k, Inv_k, Post_k, Fail_k, Res_k, TTL_k)`：`Pre` 管“支撑多边形 + 目标足端可踏 + 地形信念新鲜”，`Inv` 管“CoM/ZMP 在支撑域内、摩擦锥内、关节限位内”，`Post` 管“接触建立 + 信念细化”，`Fail` 管“打滑/超时/OOD”，`Res` 管“恢复时必须回到的已认证相位”。相位只能按类型规则组合：`Post_k ⇒ Pre_{k+1}` 才允许拼接；恢复只能跳到预先认证过的相位，不能现场发明。关键反直觉点：**步态的“动态性”不是安全的反面；没有接触合同的动态步态才是**——合同把动态步态限制在“每一步都可证”的范围内，而不是靠更柔顺的控制器兜底。

### 灵感 3（两者统一 → 视觉-步态耦合证书：误差球 × 敏感度 ≤ 裕度预算）
直觉：视觉误差与步态安全之间不是“感知准了就安全”的线性关系，而是一个**敏感度放大**关系：地形高度误差 `e_T` 经过步态规划器的敏感度 `S_g` 放大成 CoM/ZMP 偏差，再与支撑裕度 `m` 比较。真正该问的是：`S_g · e_T ≤ m − b` 是否成立？如果编码器误差界很紧但步态对地形极其敏感（大步长、高 CoM、单支撑期长），仍然不安全；反过来，步态很保守但编码器误差界很松，也会把可执行域压到零。核心创新：**视觉-步态耦合证书（Visual-Gait Coupling Certificate, VGCC）**。VGCC 把 `B_T`、步态 `g`、敏感度 `S_g`、v20 碰撞证书统一成一个可审计对象 `C_g = (g, B_T, S_g, M_vg, witness, merkle_root, τ_gait)`，其中 `M_vg = min_k {m_zmp^rob, m_fric^rob, m_foot^rob, m_reach^rob}`，每个鲁棒裕度都是“标称裕度 − S_g·e_T − buffer”。统一状态 `ζ_vg = (B_T, g, contracts, S_g, margins, τ_vis, τ_gait, mode_vg)`。统一接口：**VGCC 通过 ∧ v20 证书覆盖 ⇒ g ∈ Exec_v21；否则冻结步态并回退 v20 的保守静态步态**。关键反直觉点：**安全不是“编码器更准”或“步态更稳”的单独属性，而是“误差球 × 敏感度”落在“裕度预算”内的联合属性**；任何一边单独优化都可能把另一边推向失效。

### 三者如何统一
v20 回答“给定感知快照，身体/末端在参数 θ 下是否零碰撞”（`Exec_v20`）；v21 回答“给定带证书的地形信念与步态合同，这条步态在真实地形上是否仍保有足端/CoM 裕度”（`Exec_v21`）。CVE/TBC 是感知侧（误差界→地形信念），GCA/RGC 是步态侧（接触合同→鲁棒裕度），VGCC 是耦合侧（误差球×敏感度→裕度预算），EFDC 是时序侧（新鲜度/OOD→冻结回退）。四者不是补丁，而是“编码—信念—合同—耦合—回退”的闭环：**CVE 回答“这个 latent 的误差界是多少”，TBC 回答“世界系地形区间是什么”，GCA 回答“这条步态的每个接触是否可组合”，RGC 回答“最坏地形下裕度还剩多少”，VGCC 回答“误差球是否吃掉了裕度预算”**。

## 1. 研究问题（轮次升级版）

- **Q1（编码误差界的紧致性与有效性）**：如何同时得到 certified Lipschitz 界 `L_F` 与共形区间 `q_{1-α}`，并让二者组合后的 `e_T` 既 sound 又不至于把步态压死？量化/压缩/曝光变化如何进入 `e_T`？世界系融合时位姿误差如何膨胀？多帧求交在非可交换地形上何时会“越交越错”？

- **Q2（步态合同的组合与恢复）**：`Pre/Inv/Post/Fail/Res/TTL` 如何定义才能让单支撑/双支撑/腾空相的拼接保安全？`Post_k ⇒ Pre_{k+1}` 在接触残差、信念细化、CoM 捕获域下如何机械检查？打滑/超时后的恢复为什么只能跳到已认证相位？“重试”在什么条件下是幂等的，什么条件下是证书化活锁？

- **Q3（耦合敏感度的可证性）**：`S_g` 如何计算/认证？用 LIPM 解析界、区间可达性、还是对认证仿真器做有限差分？如何避免 `S_g` 过松导致全部拒绝，或过紧导致漏判？裕度预算 `m − b` 如何在感知误差与控制跟踪误差之间分配？`S_g·e_T ≤ m−b` 的判定如何在 200Hz 控制环内完成？

- **Q4（视觉与步态的时序协调）**：视觉 10–30Hz、步态控制 200–1000Hz，`τ_vis` 与 `τ_gait` 如何对齐？单支撑期只有 0.2–0.4s，视觉延迟/丢帧如何被“信念保持 + 冻结 + 已认证恢复”覆盖？OOD 或信念不一致时，如何在不破坏平衡的前提下 fail-closed？回退 v20 静态步态是否需要预先认证的“过渡相位”？

## 2. 设计原则（在 P31–P33 基础上新增 P37–P39）

**P37 编码误差可传播律（Encoder Error Propagation Law）**
视觉编码器不得输出“裸 latent”。每个地形输出必须携带 `(L_F, q_{1-α}, e_quant, τ_vis, ood_score)`，并满足 `e_T = q_{1-α} + (L_F + L_T)·δ_img + e_quant + L_pose·δ_pose`，其中 `L_T` 是地形的物理 Lipschitz 先验（最大坡度界），`L_pose` 是位姿误差到世界系高度的放大系数。**地形信念 `B_T = (T^-, T^+, e_T, coverage, τ_vis, ood)` 只能在世界系求交收缩；求交为空、OOD 超阈、或 `e_T > r_max` 时必须冻结，不得用先验/插值扩张区间**。任何“点估计地形”一律视为无证书。

**P38 接触合同组合律（Contact Contract Composition Law）**
每个步态相位 `k` 携带合同 `G_k = (Pre_k, Inv_k, Post_k, Fail_k, Res_k, TTL_k)`。组合只在类型规则成立时允许：`Post_k ⇒ Pre_{k+1}`（含接触残差与信念细化）；`Res_k` 必须包含下一相位所需的支撑/CoM 状态；`Fail_k` 必须触发**预先认证的恢复相位** `Recovery_k`，不得现场重规划；`TTL_k` 超时必须进入双支撑或冻结。**合同只能组合、排序、重试已认证的相位，不能放宽任何 `Inv`；没有 v20 碰撞见证的相位不得进入 `Exec_v21`**。

**P39 视觉-步态耦合保守律（Visual-Gait Coupling Conservatism Law）**
对每条步态 `g` 与地形信念 `B_T`，定义耦合裕度 `M_vg(g, B_T) = min_k { m_zmp^rob, m_fric^rob, m_foot^rob, m_reach^rob }`，其中 `m^rob = m^nom − S_g·e_T − b`，`S_g` 必须是**认证过的**敏感度上界。**只有 `M_vg ≥ 0` 且 v20 碰撞证书覆盖该步态时，`g` 才进入 `Exec_v21`**。`S_g` 不得用未认证的经验值；`e_T` 不得用均值/中位数；`b` 必须覆盖跟踪误差、接触柔顺与执行器延迟。任何一项不可证，一律 fail-closed 回退 v20 静态步态。

## 3. 与基线的接口（如何退化）

- CVE 失效（无 Lipschitz 界/共形区间/编码器故障）⇒ 地形信念无效 ⇒ 冻结步态，回退 v20 静态保守步态 ⇒ 等价 v20；
- TBC 失效（位姿丢失/多帧不一致/世界系不可融合）⇒ 只用单帧保守区间，且 `e_T` 放大 ⇒ 等价 v20（更保守）；
- GCA 失效（合同缺失/组合不可判定）⇒ 只执行 v20 单相位静态步态 ⇒ 等价 v20；
- RGC 失效（`S_g` 不可证/裕度不可计算）⇒ 拒绝所有动态步态 ⇒ 等价 v20 静态步态；
- VGCC 失效（耦合检查不可用）⇒ 只接受 v20 已认证步态 ⇒ 等价 v20；
- EFDC 失效（时钟/新鲜度不可用）⇒ 冻结当前步态并进入双支撑 ⇒ 等价 v20；
- 六者全失效 ⇒ 完全退回 v20 的 PCA/CTS/CFC/HPC/CFCtrl + 静态步态；
- **安全继承**：CVE/TBC 只提供保守区间、GCA 只组合已认证相位、RGC 只在最坏地形上判定、VGCC 只做交集、EFDC 只冻结/回退；任意失效都使可执行集收缩，`Exec_v21 ⊆ Exec_v20` 由引理 162 保证。

## 4. 预期贡献

1. **证书化视觉编码器**：首次把“视觉编码器输出”从点估计 latent 改写为“Lipschitz 界 + 共形区间 + OOD 分数”的可传播地形信念，使感知误差第一次能以区间形式进入步态规划，而不是被下游当噪声平均掉；
2. **步态合同代数**：把步态从“轨迹 + 落脚点”升级为“相位合同 + 类型规则 + 认证恢复”，给出单支撑/双支撑/腾空相的保安全组合条件，并把“打滑/超时/分布外”变成一等失败边；
3. **视觉-步态耦合证书**：提出 `误差球 × 敏感度 ≤ 裕度预算` 的联合安全判据，给出 `S_g` 的认证方法与 `M_vg` 的保守计算，使“看见地形”与“迈出这一步”之间第一次有可审计的定量桥梁；
4. **时序退化闭环**：用 EFDC 把视觉新鲜度、OOD、信念不一致与步态相位绑定，给出“冻结—双支撑—已认证恢复—v20 回退”的时序协议，使低频视觉与高频步态控制安全解耦；
5. **安全继承链**：`Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18`，v21 的增益不是扩大可执行集，而是在 v20 已认证的包络内，用局部可证地形替换全局最坏地形，从而在**不增加碰撞/失稳风险**的前提下挑选更合适的动态步态。

## 5. 本轮最大风险

**一句话**：视觉编码器的证书（共形覆盖率与 Lipschitz 界）只在标定分布与像素扰动下成立；一旦遇到分布外地形（玻璃、草地、可变形地面）或语义漂移，真实误差可能落在区间之外，而 Lipschitz 界只约束像素扰动、不约束语义分布漂移，于是“证书通过、步态迈出、脚底打滑”——**证书在分布外从硬约束退化为纸面约束**。

## 1. 关键算法骨架

```python
# IP-425 Certified Visual Encoder (CVE)
@dataclass
class TerrainBelief:
    T_minus: np.ndarray      # 世界系高度下界
    T_plus: np.ndarray       # 世界系高度上界
    e_T: float               # 最大半宽
    coverage: float          # 共形覆盖率 1-alpha
    ood_score: float
    tau_vis: float           # 时间戳
    valid: bool = True
    frame: str = "world"

class CertifiedVisualEncoder:
    def __init__(self, encoder, decoder, L_F, q_conformal, L_T, L_pose,
                 e_quant, alpha=0.05, tau_ood=0.8, r_max=0.05):
        self.encoder = encoder
        self.decoder = decoder
        self.L_F = L_F                  # CROWN/IBP 认证的端到端 Lipschitz 界
        self.q = q_conformal            # 留出集上的共形分位数
        self.L_T = L_T                  # 地形物理 Lipschitz 先验
        self.L_pose = L_pose            # 位姿误差放大系数
        self.e_quant = e_quant          # 量化/压缩残差
        self.alpha = alpha
        self.tau_ood = tau_ood
        self.r_max = r_max

    def certify(self, image, delta_img, delta_pose, now):
        z = self.encoder(image)
        h_pred = self.decoder(z)

        # 1. 误差预算：共形 + 像素扰动 + 地形先验 + 量化 + 位姿
        e_T = (self.q
               + (self.L_F + self.L_T) * delta_img
               + self.e_quant
               + self.L_pose * delta_pose)

        # 2. OOD：latent Mahalanobis / energy score
        ood = self.ood_score(z, image)

        # 3. 保守区间（世界系）
        T_minus = h_pred - e_T
        T_plus = h_pred + e_T

        valid = (ood <= self.tau_ood) and (e_T <= self.r_max)
        return TerrainBelief(T_minus, T_plus, e_T, 1.0 - self.alpha,
                             ood, now, valid=valid)

    def fuse(self, beliefs):
        """世界系求交：区间只能收缩；空交集视为观测不一致。"""
        if not beliefs:
            return None, "NO_BELIEF"
        T_minus = np.maximum.reduce([b.T_minus for b in beliefs])
        T_plus = np.minimum.reduce([b.T_plus for b in beliefs])
        if np.any(T_minus > T_plus):
            return None, "INCONSISTENT"
        e_T = float(np.max((T_plus - T_minus) / 2.0))
        return TerrainBelief(
            T_minus, T_plus, e_T,
            coverage=min(b.coverage for b in beliefs),
            ood_score=max(b.ood_score for b in beliefs),
            tau_vis=max(b.tau_vis for b in beliefs),
        ), "OK"


# IP-426 Terrain Belief Certificate (TBC)
class TerrainBeliefCertificate:
    def __init__(self, s_max=0.6, h_max=0.08, rho_max=0.03):
        self.s_max = s_max          # 最大可踏坡度
        self.h_max = h_max          # 最大可踏台阶
        self.rho_max = rho_max      # 最大粗糙度

    def traversable(self, belief, x, foot_radius):
        """在足端圆盘上取区间最坏坡度/台阶/粗糙度。"""
        patch = belief.patch(x, foot_radius)
        slope_hi = patch.slope_upper()      # 由 T^-, T^+ 端点计算
        step_hi = patch.step_height_upper()
        rough_hi = patch.roughness_upper()
        return (slope_hi <= self.s_max
                and step_hi <= self.h_max
                and rough_hi <= self.rho_max)

    def foothold_set(self, belief, workspace, grid=0.02):
        """在 workspace 内网格采样，返回所有可踏足端。"""
        candidates = []
        for x in workspace.grid(grid):
            if self.traversable(belief, x, workspace.foot_radius):
                candidates.append(x)
        return candidates


# IP-427 Gait Contract Algebra (GCA)
@dataclass
class PhaseContract:
    k: int
    pre: Callable[[State, TerrainBelief], bool]
    inv: Callable[[State, TerrainBelief], bool]
    post: Callable[[State, TerrainBelief], bool]
    fail: Callable[[State, TerrainBelief], bool]
    res: Set[str]
    pre_state_keys: Set[str]
    ttl: float
    recovery: Optional[int]      # 预先认证的恢复相位 id

class GaitContractAlgebra:
    def compose(self, phases, beliefs):
        for k in range(len(phases) - 1):
            a, b = phases[k], phases[k + 1]

            # 1. 合同衔接：Post_k 必须蕴含 Pre_{k+1}
            if not self.implies(a.post, b.pre):
                return None, f"POST_PRE_BREAK@{k}"

            # 2. 残差状态必须覆盖下一相位所需状态
            if not a.res.issuperset(b.pre_state_keys):
                return None, f"RES_MISMATCH@{k}"

            # 3. 信念细化：下一相位不得使用更宽的区间
            if not self.refines(beliefs[k + 1], beliefs[k]):
                return None, f"BELIEF_EXPANDED@{k}"

            # 4. 恢复必须已认证
            if a.recovery is not None and not self.is_certified(a.recovery):
                return None, f"UNCERTIFIED_RECOVERY@{k}"

        return phases, "OK"

    def refines(self, b_new, b_old):
        return (np.all(b_new.T_minus >= b_old.T_minus)
                and np.all(b_new.T_plus <= b_old.T_plus))

    def is_certified(self, phase_id):
        return phase_id in self.certified_recovery_ids


# IP-428 Robust Gait Certificate (RGC)
class RobustGaitCertifier:
    def __init__(self, v20_cert, tbc, buffer=None, r_max=0.05):
        self.v20 = v20_cert
        self.tbc = tbc
        self.b = buffer or dict(b_zmp=0.01, b_fric=0.05,
                                b_foot=0.005, b_reach=0.01)
        self.r_max = r_max

    def certify(self, gait, belief, S_g, now):
        if not belief.valid:
            return None, "PERCEPTION_INVALID"
        if belief.e_T > self.r_max:
            return None, "TERRAIN_UNCERTAINTY_TOO_LARGE"

        worst = dict(zmp=float("inf"), fric=float("inf"),
                     foot=float("inf"), reach=float("inf"))

        for phase in gait.phases:
            # 足端可踏性：在区间最坏值下检查
            for p in phase.footholds:
                if not self.tbc.traversable(belief, p, gait.foot_radius):
                    return None, f"UNSAFE_FOOTHOLD@{phase.k}"

            # 鲁棒裕度 = 标称裕度 - 敏感度*误差 - 缓冲
            worst["zmp"] = min(
                worst["zmp"],
                phase.m_zmp_nom - S_g * belief.e_T - self.b["b_zmp"])
            worst["fric"] = min(
                worst["fric"],
                phase.m_fric_nom - self.b["b_fric"])
            worst["foot"] = min(
                worst["foot"],
                phase.m_foot_nom - belief.e_T - self.b["b_foot"])
            worst["reach"] = min(
                worst["reach"],
                phase.m_reach_nom - S_g * belief.e_T - self.b["b_reach"])

        M_vg = min(worst.values())
        if M_vg < 0:
            return None, f"MARGIN_NEGATIVE:{M_vg:.4f}"

        # v20 碰撞证书必须覆盖整条步态（身体/末端）
        if not self.v20.covers(gait):
            return None, "V20_NOT_COVERED"

        return GaitCertificate(
            gait=gait, belief=belief, S_g=S_g, M_vg=M_vg,
            witness=self.witness(gait, belief),
            merkle_root=self.merkle(gait, belief),
            tau_gait=now,
        ), "OK"


# IP-429 Visual-Gait Coupling Certificate (VGCC)
class CertifiedSensitivityEstimator:
    """S_g 的认证上界：LIPM 解析界 + 区间可达性，取最大。"""
    def __init__(self, z_min=0.5, step_span=0.4):
        self.z_min = z_min
        self.step_span = step_span

    def certify(self, gait):
        T = max(p.duration for p in gait.phases)
        omega = math.sqrt(9.81 / self.z_min)

        # LIPM: xi(T)=p+(xi0-p)e^{omega T}
        # d xi / d p = 1-e^{omega T}; 高度扰动同时改变 omega
        lipm_bound = ((math.exp(omega * T) - 1.0)
                      + T * math.exp(omega * T)
                      * self.step_span * omega / (2.0 * self.z_min))

        # 区间可达性：对认证仿真器做区间传播
        reach_bound = self.interval_reachability_bound(gait)
        S_g = max(lipm_bound, reach_bound)
        return S_g, "OK"

    def interval_reachability_bound(self, gait):
        # 沿相位做区间积分，返回 ||d(CoM,ZMP)/d h|| 的上界
        return interval_reachability(gait.phases,
                                     state_dim=gait.state_dim,
                                     terrain_dim=gait.terrain_dim)


class VisualGaitCouplingCertificate:
    def __init__(self, rgc, sensitivity_estimator, budget_allocator):
        self.rgc = rgc
        self.sens = sensitivity_estimator
        self.budget = budget_allocator

    def verify(self, gait, belief, now):
        if belief is None or not belief.valid:
            return None, "PERCEPTION_INVALID"

        # 1. 认证敏感度上界
        S_g, status = self.sens.certify(gait)
        if status != "OK":
            return None, "SENSITIVITY_UNCERTIFIED"

        # 2. 裕度预算：感知误差不得吃掉全部标称裕度
        if S_g * belief.e_T > self.budget(gait):
            return None, "MARGIN_BUDGET_EXCEEDED"

        # 3. 鲁棒步态证书（含 v20 碰撞见证）
        cert, status = self.rgc.certify(gait, belief, S_g, now)
        if status != "OK":
            return None, status
        return cert, "OK"


# IP-430 Encoder-Gait Freshness & Degradation Controller (EGDC)
class EncoderGaitFreshnessController:
    def __init__(self, v20, ttl_vis=0.1, tau_ood=0.8):
        self.v20 = v20
        self.ttl_vis = ttl_vis
        self.tau_ood = tau_ood

    def check(self, belief, gait, now):
        if belief is None or not belief.valid:
            return "V20_STATIC"
        if now - belief.tau_vis > self.ttl_vis:
            return "FREEZE_TO_DOUBLE_SUPPORT"
        if belief.ood_score > self.tau_ood:
            return "V20_STATIC"
        if self.inconsistent(belief):
            return "FREEZE_TO_DOUBLE_SUPPORT"
        return "OK"

    def degrade(self, gait, mode):
        if mode == "OK":
            return gait
        if mode == "FREEZE_TO_DOUBLE_SUPPORT":
            # 只允许已认证的过渡相位，随后回退 v20
            return self.certified_transition(gait)
        if mode == "V20_STATIC":
            return self.v20.static_gait()
        raise ValueError(mode)

    def inconsistent(self, belief):
        return np.any(belief.T_minus > belief.T_plus)
```

## 2. 推导（引理 157–163）

**引理 157（编码误差可传播性）**
设端到端地形预测 `F = D_ψ∘E_φ` 在图像球 `B_∞(I, δ_img)` 上满足 `||F(I+δ) − F(I)||_∞ ≤ L_F||δ||_∞`；地形真值满足物理 Lipschitz 先验 `|h*(I+δ) − h*(I)| ≤ L_T||δ||_∞`；共形区间在标定分布上满足 `Pr[h*(I) ∈ [h_pred(I)−q, h_pred(I)+q]] ≥ 1−α`。则对 `I' = I+δ`，有
`h*(I') ∈ [h_pred(I') − e_T, h_pred(I') + e_T]`，至少以 `1−α` 概率成立，其中 `e_T = q + (L_F+L_T)δ_img + e_quant + L_pose·δ_pose`。
证明：三角不等式分解
`|h*(I')−h_pred(I')| ≤ |h*(I')−h*(I)| + |h*(I)−h_pred(I)| + |h_pred(I)−h_pred(I')|`，
三项分别由物理先验、共形覆盖、Lipschitz 界控制；量化与位姿项同理叠加。∎

**引理 158（地形信念求交单调性）**
对同一世界系点 `x` 的两个独立观测 `B_1, B_2`，若各自以 `1−α_i` 覆盖 `h*(x)`，则 `B_1 ∩ B_2` 以至少 `1−(α_1+α_2)` 覆盖；若交集为空，则在假设成立时不可能，必须触发不一致告警。世界系融合前须按位姿不确定度膨胀 `e_pose = L_pose·δ_pose`，否则交集可能被虚假收缩。∎

**引理 159（步态合同组合）**
若每个相位 `k` 在其时域内满足 `Inv_k`，且对每个相邻对 `Post_k ⇒ Pre_{k+1}`（在残差 `Res_k` 与信念细化下），则整条步态在 `∪_k [t_k, t_{k+1}]` 上满足所有 `Inv`。
证明：对 `k` 归纳。基础相位由合同直接成立；归纳步由 `Post_k` 提供 `Pre_{k+1}` 所需状态与信念，且 `beliefs[k+1] ⊆ beliefs[k]`，故 `Inv_{k+1}` 成立。∎

**引理 160（鲁棒裕度支配）**
若每个裕度函数 `m_k(g; h)` 对 `h` 在 `B_T` 上单调（或 Lipschitz 且最坏值在区间端点取到），则 `m_k^rob = min_{h∈B_T} m_k(g;h)` 满足：对任意真实 `h* ∈ B_T`，`m_k(g;h*) ≥ m_k^rob`。因此 `M_vg = min_k m_k^rob ≥ 0` 蕴含真实地形下所有裕度非负。∎

**引理 161（视觉-步态耦合可靠性）**
若 `belief.valid`、`e_T ≤ r_max`、`S_g` 为认证上界、`M_vg ≥ 0`、且 v20 碰撞证书覆盖 `g`，则执行 `g` 在真实地形上以至少 `1−α` 概率满足足端可踏、ZMP/摩擦/可达裕度非负；若 OOD 或信念不一致，EGDC 在 `TTL` 内冻结并回退，不执行任何未认证相位。∎

**引理 162（v21 安全继承）**
`Exec_v21 = {g ∈ Exec_v20 : VGCC(g, B_T) = CERT}`，故 `Exec_v21 ⊆ Exec_v20`；CVE/TBC/GCA/RGC/VGCC 的任意失效均使 `VGCC` 返回拒绝或触发 EGDC 回退 v20 静态步态，故 `Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18`。∎

**引理 163（恢复相位的幂等性）**
若恢复相位 `Recovery_k` 满足 `Pre_recovery ⊆ Post_k^{-1}(Res_k)`，且其 `Inv` 在双支撑下成立，则从 `Fail_k` 进入恢复不会引入新的未认证状态。重试仅在 `Fail_k ⊆ Pre_k` 且存在复位见证把世界状态与资源恢复到 `Pre_k` 时幂等；否则为重试型活锁，必须禁止。∎

## 6. 已知风险与失效模式

1. **共形覆盖的可交换性假设失效**：共形区间只在标定与测试可交换时保证边际覆盖；地形分布漂移（草地→玻璃）会破坏该假设，区间可能系统性偏窄。缓解：分层共形（按地形类别）、在线覆盖率监控、OOD 触发保守膨胀。
2. **Lipschitz 界过松或过紧**：CROWN/IBP 在深网络上可能给出很松的界，导致 `e_T` 过大而全拒绝；若认证过程有误（如漏掉归一化层），又会过紧而漏判。缓解：分段/局部 Lipschitz、随机平滑对照、认证器自检。
3. **`S_g` 低估**：解析 LIPM 界忽略了接触柔顺、关节弹性、时延，可能低估真实敏感度。缓解：区间可达性与解析界取最大、对认证仿真器做有限差分上界、加保守乘子。
4. **位姿误差导致虚假收缩**：多帧求交若未正确膨胀 `L_pose·δ_pose`，会把同一地形的不同观测交成空集或过窄区间。缓解：显式位姿协方差传播、按帧独立膨胀、空集只告警不收缩。
5. **相位边界的时间离散化**：`Post_k ⇒ Pre_{k+1}` 在连续时间成立，但控制是离散的；边界抖动可能造成“合同成立但实际越界”。缓解：在相位边界加时间膨胀 `Δt`，用最坏采样点检查。
6. **可变形地形不在高度场模型内**：草地、沙地、软垫的“高度”不能刻画承载能力，`Trav` 可能把软地判为可踏。缓解：增加可变形性/承载通道、对软地强制降速或拒绝。
7. **视觉延迟与单支撑期不匹配**：单支撑期仅 0.2–0.4s，30Hz 视觉的一帧延迟就可能让落脚点基于过期地形。缓解：TTL 冻结、双支撑过渡、预测式信念外推（仅外推区间，不外推点估计）。
8. **审计开销**：每步态 Merkle 证明与日志可能影响 200Hz 控制环。缓解：异步落盘、增量 Merkle、只对相位边界做证明。

## 7. 本轮最大风险

**一句话**：共形覆盖率在分布外失效、Lipschitz 界只约束像素扰动而不约束语义漂移、`S_g` 又只对认证模型内的动力学成立；三者叠加会让“证书通过、步态迈出、脚底打滑”——**v21 的证书在分布外从硬约束退化为纸面约束**。
