# 第 1 轮（新灵感循环 R1；本轮灵感：「任务规划」×「桌面操作」）
> **继承基线**：第 8 轮 MetricVoiceGauge-DA-SPR-Cal（定义 493–531；引理 77–81；实验 E531–E550）。
> 本轮纪律：**计划即假设 + 指标即签证 + 桌面即约束域**。任务规划把「当前动作的风险」升级为「整段计划的风险预算」；桌面操作把「自由空间导航」升级为「杂乱小工作域的几何承诺」。二者合流于一条原则：**规划器只提出计划，指标梯为计划签发证书，桌面几何为每个操作背书；证书不足时单调重规划或弃权，绝不通过放松安全阈值来让计划“变得可行”**。所有新模块均为可选增强，任一失效 ⇒ 退回 v8。

## 0. 直觉与动机

**灵感 1（任务规划 → 计划是有时间结构的假设）**
直觉：v8 的指标梯是“近视”的：它只对当前动作 s_t 打分。但桌面任务是长程、顺序、带前置条件的——“先移开挡路的杯子，再抓取目标，再放入抽屉”。若只在每一步做局部判断，就会出现两种典型失败：①每一步都安全，整段计划却不可行（例如先抓了底座，导致后面的抽屉打不开）；②前面贪快，后面无解（例如把目标压在一堆书下面）。任务规划提供的不是“更聪明的动作选择”，而是一个**可被指标系统审计的未来结构**：计划树的每个节点都带前置条件、效果、资源与不可逆性。于是把计划看成一条**关于未来的假设**，指标梯的职责是签发“未来可行性证书”，而不是事后追认。核心概念：**计划条件化指标梯（Plan-Conditioned Metric Ladder, PCML）** 与 **前瞻风险预算（Horizon Risk Budget, HRB）**。

**灵感 2（桌面操作 → 小工作域里的几何承诺）**
直觉：桌面操作的主要失败不是“撞到墙”，而是“碰倒旁边的杯子”“夹爪进不去”“物体被压在不稳定的堆叠下”“人手突然伸进来”。这些约束发生在几十厘米的工作域内，具有强几何性与拓扑性：可达性、间隙、支撑、遮挡、抓取仿射、堆叠依赖。导航安全距离的尺度在这里不适用，必须换成**交互包络（interaction envelope）**。核心概念：**桌面交互包络证书（Desktop Interaction Envelope Certificate, DIEC）**：它不回答“路径是否无碰”，而回答“这个操作在可达、间隙、支撑、可见、抓取五个维度上是否都还有几何余量”。

**合流（计划-证书-单调重规划）**
直觉：完整闭环应为：语言/任务 → 规划器提出计划树 π → 计划-指标编译器把符号前置/效果编译成度量义务 → 桌面几何为每个操作签发 DIEC → 前瞻风险预算评估整段计划 → 计划证书 → 执行 → 计划-执行一致性监控 → 若偏离则**单调重规划**（只能收紧，不能放松）→ 仍不可行则弃权/求助。关键不是让规划器“更会规划”，而是让系统在**计划不可行时也可证明地不执行**。

## 1. 研究问题（R1 升级版）

- **Q1（计划编译可靠性）**：符号前置/效果如何无遗漏地编译成可监控的度量义务，使“义务满足”蕴含“执行安全”？在什么受限谓词片段上该蕴含关系可证？
- **Q2（前瞻风险）**：如何在有限算力（≤2ms/周期、H≤8）下评估整段计划风险，并保证证书对计划任意前缀仍然成立（前缀单调）？
- **Q3（桌面几何）**：可达、间隙、支撑、遮挡、抓取五类约束如何统一为可比较的证书，且阈值与 v8 的 M₀/M₁ 同物理尺度？
- **Q4（单调重规划）**：当某步证书失败时，如何重规划而不放松安全约束，并保证终止性/可判定性？

## 2. 设计原则（P16–P21）

**P16 计划即假设（Plan as Hypothesis, PaH）**
规划器输出是候选计划树 π，不是执行授权；任何多步计划必须持有有效的计划证书 C_plan 才能进入执行；单步可逆动作可走 v8 的反应式路径。

**P17 前瞻指标（Lookahead Metric, LM）**
指标不再只评估当前步，而在计划时域 H 上评估：单步风险 ρ(s_k,a_k) ∈ [0,1] 经折扣累积为 R_H，并对**所有前缀** h ≤ H 检查预算，保证任意中途停止点都安全。

**P18 桌面交互包络（Desktop Interaction Envelope, DIE）**
接触操作必须同时满足：可达性余量 r_reach、间隙余量 c_clear、支撑稳定余量 s_sup、可见性 v_vis、抓取仿射余量 g_grasp 五项；任一不足即证书无效，不得执行。

**P19 单调重规划（Monotone Replanning, MR）**
重规划 π' 必须满足 `SafetyObl(π') ⊇ SafetyObl(π)|≥k` 且安全类阈值只紧不松；找不到这样的 π' 时输出弃权，而不是放松阈值“凑”一个可行计划。

**P20 不可逆承诺门（Irreversibility Commitment Gate, ICG）**
Tier-3（切割、倾倒、近人递送、可能夹手的抽屉/门操作）除计划证书外，还要求全时域证书与（封闭世界 ∨ 人类显式确认），且不破坏堆叠依赖。

**P21 计划-执行一致性（Plan-Execution Consistency, PEC）**
在线比较预测效果 e_pred 与观测效果 e_obs；偏差超阈值即撤销计划证书、触发重认证或单调重规划，绝不带着失效证书继续执行。

## 3. 与基线的接口（如何退化）

- 规划器失效 ⇒ 退回 v8 的反应式单步指标（H=1，无计划证书）；
- 计划-指标编译器失效 ⇒ 计划证书恒无效，禁止一切多步计划，仅允许单步可逆动作；
- 桌面几何证书失效 ⇒ 所有桌面接触操作降为 Tier-3（需人类确认），或只允许自由空间动作；
- 前瞻风险模块失效 ⇒ H=1，等价 v8 的近视风险；
- 单调重规划失效 ⇒ 证书失败即安全停机，不自动重规划；
- 计划-执行监控失效 ⇒ 按“计划已失效”处理，保守停机；
- 全部失效 ⇒ 完整退回 MetricVoiceGauge-DA-SPR-Cal v8，再按 v8 四级链继续退化。

## 4. 预期贡献

1. **计划条件化指标梯 + 计划证书**：把指标系统从“当前动作打分器”升级为“未来计划签证器”，并明确其可靠性只覆盖受限可验证谓词片段；
2. **前瞻风险预算**：给出前缀单调的风险评估，使任意中途停止点都在预算内；
3. **桌面交互包络证书**：把可达/间隙/支撑/遮挡/抓取统一为与 M₀/M₁ 同尺度的五维几何余量；
4. **单调重规划与不可逆承诺门**：重规划只能收紧安全约束，不可逆动作需要全时域证据；
5. **实时隔离**：计划证书与几何证书在异步线程生成，50Hz 主环只读快照；
6. 完整实验矩阵 **E551–E570** 覆盖计划编译、前瞻风险、桌面几何、堆叠、重规划、退化与实机。

## 5. 本轮最大风险

**一句话**：计划证书与桌面几何证书都建立在“符号因果模型正确、几何观测准确”之上；一旦规划器给出语义正确但因果模型错误的长程计划（例如忽略质量、摩擦、堆叠耦合或柔性物体形变），单调重规划只能在错误模型内部收紧，无法发现“计划本身错了”，系统可能以高置信度、零间隙违规地执行一个物理上必然失败甚至危险的动作。

**新增定义 532（桌面工作域观测 DesktopWorkspaceObservation）**
```
O_t = ( P_t, I_t^RGBD, {T_t^v, K^v}_{v=1}^V, {o_j}_{j=1}^N, H_t, n_sup )
o_j = ( pose_j ∈ SE(3), cov_j ∈ ℝ⁶ˣ⁶, bbox_j, mask_j, cls_j, m̂_j )
```
`P_t` 为工作域点云（桌面局部坐标系），`H_t` 为人手/人体关键点集合，`n_sup` 为支撑面法向。**接触操作要求 `cov_j` 与 `H_t` 可读**；缺失时不得签发 Tier-2/3 证书，走 Level-3。

**新增定义 533（符号计划树 SymbolicPlanTree）**
```
π = (a_1, ..., a_n),   a_i = (op_i, θ_i, tier_i, pre_i, eff_i, τ_i^dl)
pre_i, eff_i ⊆ L_obl 的原子谓词及其否定
```
`op_i` 为参数化操作原语（move, reach, grasp, lift, place, open, close, pour, handover…）；`tier_i ∈ {0,1,2,3}` 复用 v8 影响层级；`τ_i^dl` 为该步的相对截止时间。计划树允许顺序/分支，执行前线性化为带守卫的动作序列。

**新增定义 534（度量义务 MetricObligation）**
```
o = (kind, target, scope, θ, step)
kind ∈ {REACH, CLEAR, SUPPORT, VISIBLE, GRASP, TEMPORAL}
scope ∈ {PRE, DURING, POST}
```
编译器 `Compile: (pre_i, eff_i, O_t) → 2^{Obl}` 只接受 `L_obl` 片段：每个谓词必须能映射到定义 538–544 的可测量量。**不可映射的谓词 ⇒ 编译失败 ⇒ 计划证书无效（fail-closed），而不是静默忽略**。这是“计划证书只对受限片段可靠”的诚实边界。

**新增定义 535（计划条件化指标梯 PlanMetricLadder）**
```
M_plan(s, π) = 1 ⇔ ∀ o ∈ O(π): check(o, s, scope) = 1
δ_plan: 任一 scope ∈ {DURING, POST} 的义务违背 ⇒ 直接触发 M₀ 硬约束（保持/急停）
```
`M_plan` 与 `M_desk` 到 `M₀` 的退化映射均为“直接触发 M₀ 硬约束检查”；未启用规划时两层不产生额外约束，但也不产生任何多步执行授权。

**新增定义 536（前瞻风险预算 HorizonRiskBudget）**
```
R_H(π,s) = Σ_{k=0}^{H-1} γ^k · ρ(s_k, a_k),   γ ∈ (0,1]
peak_H(π,s) = max_{0≤k<H} ρ(s_k, a_k)
```
前缀单调证书要求：
```
budget_ok(π) ⇔ ∀ h ≤ H: R_h ≤ h · b̄ ∧ peak_h ≤ ρ_max
```
其中 `b̄` 为单位步风险预算均值，`ρ_max` 为单步硬上限。**对每个前缀都检查**，保证计划在任何中途停止点都在预算内；只检查全长会留下“前几步超支、后面用低风险摊平”的漏洞。

**新增定义 537（计划证书 PlanCertificate）**
```
C_plan = (π, O(π), R_H, peak_H, H, age, compile_ok, valid)
valid ⇔ compile_ok ∧ M_plan(s,π) ∧ budget_ok(π) ∧ age ≤ τ_age
```
证书随计划版本号发布；执行器在每一步开始前检查 `version` 与 `age`，过期或版本不匹配即拒绝执行。

**新增定义 538（桌面交互包络 DesktopInteractionEnvelope）**
```
E(x) = ( r_reach(x), c_clear(x), s_sup(x), v_vis(x), g_grasp(x) )
DIEC.valid(x, tier) ⇔ r_reach ≥ τ_reach ∧ c_clear ≥ τ_clear(tier)
                    ∧ s_sup ≥ τ_sup(tier) ∧ v_vis ≥ τ_vis
                    ∧ g_grasp ≥ τ_grasp(tier)
```
五个分量均归一化到“余量/阈值”或 `[0,1]`，便于与 v8 的 `M₀/M₁` 同尺度比较：`c_clear` 以米计、`r_reach` 以关节/任务空间余量计、`s_sup` 为无量纲稳定裕度。

**新增定义 539（可达性包络 ReachabilityEnvelope）**
```
r_reach(x) = max_{q: FK(q)=x} min( margin_joint(q), margin_self(q), margin_track )
margin_joint(q) = min_j min( q_j − q_j^min, q_j^max − q_j )
```
若无逆解或自碰撞余量 ≤ 0，则 `r_reach = 0`。`margin_track` 预留跟踪误差，保证“规划可达”不等于“执行可达”。

**新增定义 540（间隙包络 ClearanceEnvelope）**
```
c_clear(x) = min_{y ∈ Obstacles_t} ||x − y|| − r_eff
r_eff = r_gripper + 3σ_track + ε_control
```
运动过程用扫掠体（swept volume）检查，取整段轨迹上的最小值。`τ_clear(tier)` 默认 Tier-1 = 2cm、Tier-2 = 1cm、Tier-3 = 1.5cm 且要求人类确认。

**新增定义 541（支撑稳定性 SupportStability）**
```
P_sup(o) = 支撑多边形（支撑面与物体接触点的凸包）
s_sup(o) = dist( proj_{P_sup}(CoM(o)), ∂P_sup ) / h_CoM(o)
```
静态稳定要求 `CoM` 投影落在 `P_sup` 内部且 `s_sup ≥ τ_sup`。含加速度的准静态操作需满足 `s_sup ≥ a_max/g + τ_sup`；动态搬运时 `a_max` 由轨迹规划给出。

**新增定义 542（堆叠支撑图 StackSupportGraph）**
```
G_sup = (V_objects, E_sup),   (i,j) ∈ E_sup ⇔ i 直接支撑 j
descendants(i) = 沿 E_sup 从 i 可达的物体集合
Remove(i) safe ⇔ ∀ j ∈ descendants(i): j 已被持握或已移除
safe_removal_order = G_sup 的逆拓扑序
```
“先抽下面的书”会破坏上层支撑，是桌面任务最常见的隐性不可逆错误；支撑图把这种依赖显式化。

**新增定义 543（抓取仿射证书 GraspAffordanceCertificate）**
```
GAC = (grasp_type, approach_dir, force_closure_margin, friction_margin)
g_grasp = min( force_closure_margin/τ_fc, friction_margin/τ_fr, align(approach_dir, n_surface) )
```
`align = 1 − |approach_dir · n_surface| / cos(τ_appr)`（接近方向越偏离表面法向越差）。未知物体几何 ⇒ `g_grasp = 0`。

**新增定义 544（可见性与遮挡 VisibilityScore）**
```
v_vis(x) = (1/V) Σ_v 1[ ray(x → cam_v) 无遮挡 ] · max(0, n_x · d_{x→v})
```
`n_x` 为抓取点/表面法向，`d` 为单位方向。可见性不足会导致抓取点定位漂移，故 `v_vis` 同时约束几何精度与抓取成功率。

**新增定义 545（计划-执行一致性 PlanExecutionConsistency）**
```
d_exec(k) = || e_pred(a_k) − e_obs(a_k) ||_W
consistent(k) ⇔ d_exec(k) ≤ τ_exec
```
`e_pred` 来自规划器的效果模型，`e_obs` 来自执行后感知。偏差超阈值时撤销 `C_plan`，触发重认证或单调重规划。用滑动窗口区分随机噪声（aleatoric，窗口内均值≈0）与模型错误（epistemic，窗口内持续偏置）。

**新增定义 546（单调重规划 MonotoneReplanning）**
```
π' = MRP(π, k, s)
s.t. SafeObl(π') ⊇ SafeObl(π)|_{≥k}
     θ'(o) ≤ θ(o)                  # 安全类义务阈值只收紧
     depth(π') ≤ depth_max ∧ cost(π') ≤ budget
```
若不存在满足上述约束的 `π'`，输出 `ABSTAIN`，由 v8 的恢复/求助接口处理。单调锥把“为了让计划可行而放松安全”这一退化路径从设计上排除。

**新增定义 547（不可逆承诺门 IrreversibilityCommitmentGate）**
```
gate(a) = 1 ⇔ tier(a) ≤ 2
            ∨ ( C_plan.valid ∧ full_horizon_cert ∧ (closed_world ∨ human_confirm)
                ∧ ¬destabilizes_dependents(a) )
```
Tier-3 示例：切割、倾倒、近人递送、可能夹手的抽屉/门操作。授权通过不等于绕过硬约束，v8 的 `M₀/M₁` 检查在所有 Tier 上仍强制执行。

**新增定义 548（桌面风险 DesktopRisk）**
```
risk_PLAN = λ_pH·(R_H/(H·b̄)) + λ_pp·(peak_H/ρ_max)
          + λ_pc·1[compile_fail] + λ_px·1[d_exec > τ_exec]
risk_DESK = λ_r·(1 − r_reach/τ_reach)_+ + λ_c·(1 − c_clear/τ_clear)_+
          + λ_s·(1 − s_sup/τ_sup)_+ + λ_v·(1 − v_vis/τ_vis)_+
          + λ_g·(1 − g_grasp/τ_grasp)_+
```
两项均非负、有界：`risk_PLAN ∈ [0, λ_pH+λ_pp+λ_pc+λ_px]`，`risk_DESK ∈ [0, λ_r+λ_c+λ_s+λ_v+λ_g]`。

**新增定义 549（七维风险向量 SevenDimRiskVector）**
```
risk(s) = [ risk_SEN, risk_SEM, risk_EFF, risk_PERF, risk_SLAM, risk_PLAN, risk_DESK ]^T ∈ ℝ⁷
```
前五维继承 v8；MetaWeight 与情感重权模块同步扩展到 7 维，`Ṽ` 新增两个低权重分量（默认 0.1、0.1），避免计划/桌面风险被情感调节压过。

**新增定义 550（八层指标梯 EightLayerMetricLadder）**
```
M = (M₀, M₁, M₂, M₃, M_dom, M_SLAM, M_plan, M_desk)
M_plan: c_plan = 1[C_plan.valid]
M_desk: c_desk = 1[DIEC.valid ∧ SSC.valid ∧ SSA.safe ∧ GAC.valid]
```
未启用规划/桌面增强时两层不产生额外约束，但也不产生任何多步或接触执行授权。

**新增定义 551（桌面空间证书 DesktopSpatialCert）**
```
DSC = ( SpatialCert_v8, C_plan, DIEC, SSC, SSA.safe_removal_order,
        gate_result, risk_PLAN, risk_DESK, t_stamp, plan_version )
```
`DSC` 随动作发布到 ROS/日志，支持事后审计：每个桌面动作都能追溯到“计划哪一步、义务是否满足、五维几何余量是多少、为什么授权”。

**新增定义 552（系统标识 SystemIdentity）**

```
Φ_TP-DM = (M 八层, risk 七维, 计划证书, DIEC, 单调重规划, 不可逆门)
```

## 2. 形式化定义（要点）

**定义 532（桌面观测）** 接触操作必须有物体位姿协方差与人手轨迹；缺失即降级。

**定义 533（计划树）** 计划是候选假设，不是执行授权；动作节点带影响层级与截止时间。

**定义 534（度量义务）** 仅编译 `L_obl` 片段；不可编译即失败，不做“尽力而为”的近似。

**定义 535（M_plan）** 义务在 PRE/DURING/POST 三个作用域分别检查；DURING/POST 违背直接触发 M₀。

**定义 536（HRB）** 对每个前缀检查预算与峰值，保证任意停止点安全。

**定义 537（计划证书）** 编译、义务、预算、龄期四者合取；版本号参与执行前校验。

**定义 538（DIEC）** 五维几何余量合取；阈值与影响层级挂钩。

**定义 539–544（五维几何）** 可达、间隙、支撑、堆叠、抓取、可见性各自可独立测量，便于定位失败来源。

**定义 545（执行一致性）** 偏差超阈值即撤销证书；区分噪声与模型错误。

**定义 546（单调重规划）** 安全义务超集 + 阈值只紧不松；无解即弃权。

**定义 547（不可逆门）** Tier-3 需全时域证书 + 封闭世界/人类确认 + 不破坏依赖。

**定义 548–550（风险与八层）** 风险非负有界；七维与 v8 的 softmax 接口兼容；八层指标梯保持退化链。

**定义 551–552（证书与标识）** DSC 可审计；v9 与 v8 的接口边界明确。

```python
class Tier(IntEnum):

class PlanProposer:
    """计划提案器：HTN/PDDL 或 LLM 生成候选计划；只提案，不授权。"""
    def __init__(self, planner, max_depth=8):
        self.planner = planner
        self.max_depth = max_depth

    def propose(self, task, obs):
        plans = self.planner.solve(task, obs, max_depth=self.max_depth)
        return [self._linearize(p) for p in plans]

    def _linearize(self, plan_tree):
        # 顺序/分支展开为带守卫的动作序列；省略展开细节
        return plan_tree


class PlanMetricCompiler:
    """把 pre/eff 编译成可测量义务；仅接受 L_obl 片段。"""
    SUPPORTED = {'REACH','CLEAR','SUPPORT','VISIBLE','GRASP','TEMPORAL'}

    def compile(self, plan, obs):
        obligations, ok = [], True
        for i, a in enumerate(plan):
            for pred in a.pre:
                ob = self._to_obligation(pred, a, obs, step=i, scope='PRE')
                if ob is None:
                    ok = False        # 不可映射 => 编译失败（fail-closed）
                    continue
                obligations.append(ob)
            for pred in a.eff:
                ob = self._to_obligation(pred, a, obs, step=i, scope='POST')
                if ob is not None:
                    obligations.append(ob)
            # 接触类动作追加 DURING 义务
            if a.op in ('grasp','lift','place','open','close','pour'):
                obligations.append(Obligation('CLEAR', a.params.get('x'),
                                              'DURING', obs.tau_clear(a.tier), i))
        return obligations, ok

    def _to_obligation(self, pred, action, obs, step, scope):
        # 只实现受限片段：图示映射，未识别谓词返回 None
        table = {
            'reachable': 'REACH', 'clear': 'CLEAR', 'stable': 'SUPPORT',
            'visible': 'VISIBLE', 'graspable': 'GRASP',
        }
        kind = table.get(pred.name)
        if kind is None or kind not in self.SUPPORTED:
            return None
        return Obligation(kind, action.params.get('x'), scope,
                          obs.threshold(kind, action.tier), step)

class HorizonRiskBudget:
    def __init__(self, gamma=0.9, b_bar=0.35, rho_max=0.8):
        self.gamma, self.b_bar, self.rho_max = gamma, b_bar, rho_max

    def evaluate(self, plan, risk_fn, state, H=None):
        H = H or len(plan)
        R = 0.0
        peak = 0.0
        prefix_ok = True
        for k in range(H):
            rho = float(np.clip(risk_fn(state, plan[k]), 0.0, 1.0))
            R += (self.gamma ** k) * rho
            peak = max(peak, rho)
            # 每个前缀都要满足预算与峰值约束
            if R > (k + 1) * self.b_bar or peak > self.rho_max:
                prefix_ok = False
                break
        return R, peak, prefix_ok

class DesktopInteractionEnvelope:
    def __init__(self, ik_solver, tau_reach=0.10, tau_clear={1:0.02,2:0.01,3:0.015},
                 tau_sup=0.15, tau_vis=0.3, tau_grasp=0.5):
        self.ik = ik_solver
        self.tau_reach, self.tau_clear = tau_reach, tau_clear
        self.tau_sup, self.tau_vis, self.tau_grasp = tau_sup, tau_vis, tau_grasp

    def reachability(self, x, q_seed):
        sol = self.ik.solve(x, q_seed)
        if sol is None:
            return 0.0
        margin_joint = float(np.min(np.minimum(sol.q - sol.q_min, sol.q_max - sol.q)))
        margin_self = self.ik.self_collision_margin(sol.q)
        margin_track = self.ik.tracking_margin(sol.q)
        return max(0.0, min(margin_joint, margin_self, margin_track))

    def clearance(self, x, obstacles, r_gripper, sigma_track, eps_control):
        r_eff = r_gripper + 3 * sigma_track + eps_control
        d = min(np.linalg.norm(x - y) for y in obstacles) if obstacles else np.inf
        return d - r_eff

    def support_stability(self, obj):
        P = self._support_polygon(obj)
        c = self._com_projection(obj)
        if not self._inside(c, P):
            return 0.0
        return self._dist_to_boundary(c, P) / max(obj.h_com, 1e-6)

    def visibility(self, x, normal, cameras):
        scores = []
        for cam in cameras:
            d = cam.pos - x
            dist = np.linalg.norm(d)
            if dist < 1e-6 or self._occluded(x, cam.pos):
                scores.append(0.0)
            else:
                scores.append(max(0.0, float(np.dot(normal, d / dist))))
        return float(np.mean(scores)) if scores else 0.0

    def evaluate(self, x, obj, tier, q_seed):
        r = self.reachability(x, q_seed)
        c = self.clearance(x, obj.obstacles, obj.r_gripper,
                           obj.sigma_track, obj.eps_control)
        s = self.support_stability(obj)
        v = self.visibility(x, obj.normal, obj.cameras)
        g = obj.grasp_margin(x)
        valid = (r >= self.tau_reach and c >= self.tau_clear[tier]
                 and s >= self.tau_sup and v >= self.tau_vis
                 and g >= self.tau_grasp)
        return {'r': r, 'c': c, 's': s, 'v': v, 'g': g}, valid


class StackSupportAnalyzer:
    def __init__(self):
        self.g_sup = {}

    def build(self, objects):
        self.g_sup = {o.id: set() for o in objects}
        for o in objects:
            for p in objects:
                if p.id != o.id and self._supports(p, o):
                    self.g_sup[p.id].add(o.id)

    def descendants(self, oid):
        seen, stack = set(), [oid]
        while stack:
            cur = stack.pop()
            for ch in self.g_sup.get(cur, ()):
                if ch not in seen:
                    seen.add(ch); stack.append(ch)
        return seen

    def safe_removal_order(self):
        # 逆拓扑序：先移除不被任何人支撑的“叶子”
        indeg = {v: 0 for v in self.g_sup}
        for u, chs in self.g_sup.items():
            for v in chs:
                indeg[v] += 1
        order, ready = [], [v for v, d in indeg.items() if d == 0]
        while ready:
            v = ready.pop()
            order.append(v)
            for u, chs in self.g_sup.items():
                if v in chs:
                    indeg[v] -= 1  # 简化示意；实际按出边更新
        return order

    def remove_safe(self, oid, held):
        return all(j in held for j in self.descendants(oid))


class GraspAffordanceCertificate:
    def __init__(self, tau_fc=0.3, tau_fr=0.2, tau_appr=np.deg2rad(30)):
        self.tau_fc, self.tau_fr, self.tau_appr = tau_fc, tau_fr, tau_appr

    def evaluate(self, obj, x, approach_dir):
        fc = obj.force_closure_margin(x)
        fr = obj.friction_margin(x)
        n = obj.normal
        align = 1.0 - abs(float(np.dot(approach_dir, n))) / max(np.cos(self.tau_appr), 1e-6)
        g = min(fc / self.tau_fc, fr / self.tau_fr, max(0.0, align))
        return float(np.clip(g, 0.0, 1.0)), g >= 1.0

class PlanExecutionMonitor:
    def __init__(self, tau_exec=0.15, window=5):
        self.tau_exec, self.window = tau_exec, window
        self.hist = []

    def update(self, e_pred, e_obs):
        d = float(np.linalg.norm(np.asarray(e_pred) - np.asarray(e_obs)))
        self.hist.append(d)
        self.hist = self.hist[-self.window:]
        bias = float(np.mean(self.hist))
        return {'d': d, 'consistent': d <= self.tau_exec,
                'epistemic': bias > self.tau_exec}


class MonotoneReplanner:
    def __init__(self, planner, depth_max=8):
        self.planner, self.depth_max = planner, depth_max

    def replan(self, plan, failed_step, state, current_obligations):
        candidates = self.planner.solve_from(state, failed_step, self.depth_max)
        for cand in candidates:
            if not self._safety_superset(cand, current_obligations, failed_step):
                continue
            if not self._thresholds_only_tighter(cand, current_obligations):
                continue
            return cand
        return None                    # 无解 => ABSTAIN，不放松阈值

    def _safety_superset(self, cand, old, k):
        return self._safe_set(cand) >= {o for o in old if o.step >= k and o.scope != 'PRE'}

    def _thresholds_only_tighter(self, cand, old):
        old_by_key = {(o.kind, o.target): o.theta for o in old}
        for o in cand:
            key = (o.kind, o.target)
            if key in old_by_key and o.theta > old_by_key[key]:
                return False
        return True

    def _safe_set(self, plan):
        return {o for o in plan.obligations if o.scope != 'PRE'}


class IrreversibilityCommitmentGate:
    def __init__(self, closed_world=False):
        self.closed_world = closed_world

    def authorize(self, action, cert, full_horizon_ok, human_confirm, destabilizes):
        if action.tier <= Tier.REVERSIBLE:
            return True
        return (cert['valid'] and full_horizon_ok
                and (self.closed_world or human_confirm)
                and not destabilizes)

class AsyncPlanCertPipeline:
    def __init__(self, proposer, compiler, hrb, certifier, geometry, tau_age=0.20):
        self.proposer, self.compiler, self.hrb = proposer, compiler, hrb
        self.certifier, self.geometry = certifier, geometry
        self.tau_age = tau_age
        self.snapshot = None

    def producer_tick(self, task, obs, risk_fn, now):
        for plan in self.proposer.propose(task, obs):
            obligations, ok = self.compiler.compile(plan, obs)
            budget = self.hrb.evaluate(plan, risk_fn, obs.state)
            cert = self.certifier.issue(plan, obligations, ok, budget, now)
            if cert['valid']:
                geo = self.geometry.evaluate(plan[0].params.get('x'),
                                             obs.objects[0], plan[0].tier,
                                             obs.q_seed)
                self.snapshot = {'cert': cert, 'geo': geo, 'stamp': now}
                return
        self.snapshot = None

    def consumer_read(self, now):
        s = self.snapshot
        if s is None or now - s['stamp'] > self.tau_age:
            return None                # 过期 => fail-closed
        return s

    r_desk = _risk_desk(geo[0])
    risk7 = np.r_[base_risk5, r_plan, r_desk]
    risk7[0] = max(risk7[0], r_plan + r_desk)       # 只收紧安全层
    w_prime = M.reward_decomposer.w_7d(risk7)

    # 5. 继承 v8 主流程（八层 M，M_plan/M_desk 已注入）
    result = M.metricvoicegauge_round_8(
        M, s, obs, task, risk_override=risk7, w_override=w_prime)

    # 6. 执行后一致性检查；偏差 => 撤销证书 / 单调重规划
    obs_effect = M.env.observe_effect()
    if monitor is not None:
        st = monitor.update(step.params.get('expected_effect'), obs_effect)
        if not st['consistent']:
            cand = replanner.replan(cert['plan'], 0, s, cert['obligations']) \
                if replanner is not None else None
            if cand is None:
                return M.abstain_or_ask(s)
            cert = plan_pipe.certifier.issue(
                cand, cand.obligations, True,
                plan_pipe.hrb.evaluate(cand, M.risk_fn, s), now)
    return result


def _risk_plan(cert):
    return 0.5 * (cert['R'] / max(cert['H'], 1)) + 0.5 * cert['peak']


def _risk_desk(geo):
    return float(np.clip(1.0 - max(geo['c'] / 0.01, 0.0), 0.0, 1.0))
```

> 集成备注：计划证书与桌面几何的生产者必须运行在独立线程/GPU 流；若硬件只能跑 5Hz，则把 `τ_age` 调到 200ms，并把 Tier-2 降为需人类确认。`w_7d` 是 v8 MetaWeight 的 7 维扩展；若情感模块未升级，新增分量使用低权重默认值（0.1、0.1），避免情感调节压过计划/几何证据。`M.abstain_or_ask` 由 v8 的恢复计划接口提供；不可用时返回预认证安全停机。

## 4. 推导

**引理 82（受限片段义务编译可靠性）** 设 `L_obl` 中每个谓词 `p` 对应检查函数 `g_p`，且 `g_p` 关于测量误差是 `L`-Lipschitz 的，测量误差上界为 `ε`。若编译后的义务在带余量 `θ_p ≥ Lε` 下通过，则真实谓词 `p` 成立。证明：`|g_p(x̂) − g_p(x)| ≤ L‖x̂−x‖ ≤ Lε`；`g_p(x̂) ≥ θ_p ≥ Lε` 蕴含 `g_p(x) ≥ 0`。**边界**：该引理只覆盖 `L_obl` 片段；一般 PDDL 谓词（如“干净”“可用”）不可测量，编译器必须拒绝，不能用本引理为任意计划背书。

**引理 83（前瞻预算的前缀单调性）** 因 `ρ ≥ 0, γ > 0`，`R_h` 关于 `h` 单调不减。定义 536 对每个前缀 `h ≤ H` 检查 `R_h ≤ h·b̄` 且 `peak_h ≤ ρ_max`，故若 `budget_ok(π)` 成立，则对任意 `h* ≤ H` 截断的计划 `π[:h*]` 也满足预算与峰值约束。因此执行器可在任意中途停止点安全退出，不会因“前面超支、后面摊平”而遗漏风险。

**引理 84（间隙安全界）** 设跟踪误差为零均值、各轴标准差 `σ_track` 的高斯噪声，控制误差有界 `‖e_ctrl‖ ≤ ε_control`，且 `c_clear ≥ τ_clear = 3σ_track + ε_control`。则单轴违反间隙的概率 ≤ `2Q(3) ≈ 0.0027`；联合到最近障碍点后由 Bonferroni 给出 `P(collision) ≤ N_obs·2Q(3)`。该界依赖高斯与独立假设；非高斯/相关的感知误差下应改用经验分位数或更保守的 `r_eff`。

**引理 85（支撑稳定条件）** 准静态下，若 `CoM` 投影严格落在支撑多边形 `P_sup` 内且稳定裕度 `s_sup ≥ τ_sup`，物体不会绕支撑边翻倒。含加速度 `a` 时，惯性力等效于把 `CoM` 投影平移 `a/g`，故要求 `s_sup ≥ ‖a_max‖/g + τ_sup`。该条件是静态/准静态充分条件，不覆盖碰撞、滑动与柔性形变。

**引理 86（堆叠移除顺序安全）** 若按 `G_sup` 的逆拓扑序移除物体，则在移除 `i` 时，`descendants(i)` 中所有物体要么已被移除、要么已被持握；由定义 542，`Remove(i)` 不会使任何仍依赖 `i` 的物体失去支撑。归纳可证整段移除序列不产生非预期坍塌。边界：该结论假设支撑图准确且持握可靠；感知漏检或抓取滑脱会破坏前提。

**引理 87（单调重规划的安全性）** 设 `π' = MRP(π,k,s)`。由定义 546，`SafeObl(π') ⊇ SafeObl(π)|≥k` 且安全类阈值只紧不松。因此任何在 `π'` 下通过证书的动作，也必然满足 `π` 在第 `k` 步之后原有的安全义务；重规划不会引入相对于 `π` 的新的安全放松。**注意**：该引理只保证“不放松”，不保证“存在可行解”；无解时系统必须弃权。

**引理 88（执行一致性检测的保守性）** 若 `d_exec > τ_exec` 且 `τ_exec ≥ 2ε_noise`（`ε_noise` 为观测噪声上界），则观测到的偏差不能完全由噪声解释，存在模型失配的证据。撤销证书并触发重认证只可能收紧安全约束（定义 546/547），故该触发是保守的；其代价是误报（把噪声判为模型错误）导致的重规划开销，而非安全风险。

**引理 89（不可逆门可靠性）** 若 `gate(a)=1` 且 `tier(a)=3`，由定义 547 必有 `C_plan.valid ∧ full_horizon_cert ∧ (closed_world ∨ human_confirm) ∧ ¬destabilizes_dependents(a)`。任一条件不满足则 `gate(a)=0`。故 Tier-3 动作不可能在缺少全时域证据或人类确认时执行。

**引理 90（退化正交性）** 接口正交：PP 只写计划树；PMC 只写义务与编译状态；HRB 只写风险预算；DIE/SSC/SSA/GAC 只写几何余量与移除序；MRP 只写新计划；ICG 只写授权；PEM 只写一致性状态与撤销信号。任一模块失效时其输出被替换为保守值（无计划 / 编译失败 / 最大风险 / 零余量 / 拒绝 / 不一致），不改变其他模块的输入语义。故任意组合的退化行为可由各 Level 组合确定，无级联副作用。

**定理 91（桌面操作授权定理）** 对任意在 v9 中被授权执行的桌面动作 `a`，在授权时刻必满足：
(i) `C_plan.valid`（编译成功、义务满足、前缀预算成立、未过期）；
(ii) 若 `a` 为接触/多步动作，`DIEC.valid`（五维几何余量均达标）；
(iii) 若 `tier(a)=3`，不可逆门通过（全时域证书 ∧（封闭世界 ∨ 人类确认）∧ 不破坏依赖）；
(iv) v8 的 `M₀/M₁` 硬约束检查仍强制执行。
因此，系统不会在计划不可行、几何余量不足或缺少不可逆授权时执行桌面操作；不确定时的策略是“单调重规划/弃权/求助”，而不是“放松阈值凑可行”。证明：由定义 537/538/547 的合取条件与引理 86–89；任一条件不满足即拒绝执行。**注意**：定理只保证程序性证书与几何余量，不保证物理真值；残余风险是“模型正确、证书通过，但真实因果/摩擦/形变与模型不符”。

**引理 92（计算复杂度与实时隔离）** 设计划长度 `n ≤ 8`、义务数 `|O| ≤ c·n`、候选物体数 `N ≤ 64`、视角数 `V ≤ 4`。编译为 `O(n·|L_obl|)`；HRB 为 `O(H)`；DIEC 五维中可达性 `O(IK)`、间隙用空间哈希近似 `O(N)`、支撑/堆叠 `O(N²)` 建图后可缓存、可见性 `O(V)`。总增量在 CPU 上 ≤ 1.5ms，可放在异步线程；主环 50Hz 只读快照 `O(1)`。生产者超时导致 `age > τ_age` 时消费者按无证书处理，进入 Level-1/2 退化，不阻塞主环。

## 8. 本轮最大风险

**一句话**：计划证书与桌面几何证书都建立在“符号因果模型正确、几何观测准确”之上；一旦规划器给出语义正确但因果模型错误的长程计划（例如忽略质量、摩擦、堆叠耦合或柔性物体形变），单调重规划只能在错误模型内部收紧，无法发现“计划本身错了”，系统可能以高置信度、零间隙违规地执行一个物理上必然失败甚至危险的动作。
