# 第 41 轮 · 双灵感落地 v18：对象级空间记忆 × 验证-即-行动闭环（Δ-Plane 四账本，四层架构 v6）

> 承接第 40 轮（v17：热预算治理 × 步数感知规划 × 学习-TO 混合轨迹，四层架构 v5）。本轮灵感词「迭代验证 / SLAM」。初看这两个词像是「再加两个模块」——SLAM 是导航的事、迭代验证是训练的事，与桌面操作何干？但把 v17 的每一条 P0 假设摊开看，它们戳中的是**同一个被默认掉的变量：物体位姿是已知且静止的**。IP-50 的「最后一毫米」建立在精确目标位姿上；IP-49 的图世界模型把物体位置当先验；IP-33 的 CBF 把障碍包络当确定集；IP-48 把重试记为步数浪费却从不问重试的根因。**v18 的主轴：把「对象级空间记忆（SLAM）」与「可校准的验证残差（迭代验证）」合成一个闭环，让 v17 的精度、规划、安全都建立在一个会被持续更新、且有统计保证的空间信念上；Δ-Plane 从三账本扩为四账本（新增认知预算 U_map）。**

## 0. 联网核实（先事实后推理；检索口径 2026-11-10，来源链接见产物区 §5）

- **事实 F67（对象级语义 SLAM 已工程化，2025–2026）**：OpenGS-SLAM（arXiv 2503.01646，ICRA 2025）以 3D Gaussian Splatting 做开放集稠密语义 SLAM，支持开放词汇、对象级场景理解，语义渲染约 10× 加速、存储约 2× 降低；Go-SLAM（IROS 2025，DOI 10.1109/IROS60139.2025.11246048）把 grounded object segmentation 与开放词汇查询接入 3DGS-SLAM，为每个物体分配唯一 ID；DOGL-SLAM（IEEE RA-L 已接收）做动态环境下的对象级 SLAM（联合高斯-地标跟踪 + 分层动态滤除）；HAMMER（arXiv 2501.14147，RA-L 2025）以服务器架构从多机器人异步流构建公制-语义高斯地图。**含义：多视角、对象级、含动态物体的语义建图已可作「空间记忆」的现成底座，不再是研究原型。**
- **事实 F68（主动对象建图与抓取，2021–2026）**：Object SLAM-Based Active Mapping and Robotic Grasping（3DV 2021）用对象驱动的探索策略降低目标位姿不确定性以服务抓取/放置；POp-GS（CVPR 2025）给出 3DGS 下基于 P-optimality 的信息增益/下一最佳视角（NBV）公式；Motion-Uncertainty-Aware NBV（RSS 2026）与基于互信息的分层主动语义 SLAM（Sci Rep 2026）显示：**「多走一步去看清」的收益可被量化，且是保持跟踪鲁棒性的必要手段。**
- **事实 F69（运行时失败预测可用仅成功数据校准，NeurIPS 2025）**：FIPER（arXiv 2510.09459）用「策略嵌入空间的随机网络蒸馏 OOD 分数 + 动作 chunk 熵」双指标，经 conformal prediction 仅用少量成功轨迹校准阈值，触发需两指标同时越界；实验显示其区分真失败与良性 OOD 更准、告警更早。**含义：验证阈值不必依赖失败数据或手调，可做分布无关校准。**
- **事实 F70（闭环/主动失败检测与人为干扰，CVPR 2025 / 2024）**：Code-as-Monitor（CVPR 2025）用约束感知的视觉编程同时做反应式（失败后检测）与主动式（可预见失败前拦截）检测，可与开环策略组成闭环，处理「人手移走物体」；KnowLoop（arXiv 2406.00430）用不确定性做闭环 LLM 规划的失败检测，并给出「开环成功率 70–80%，引入人为干扰后跌至 0%」的证据。**含义：验证必须进闭环；「检测」本身是 v17 缺失的一等环节。**
- **事实 F71（conformal 进控制回路有前提，NeurIPS 2025）**：Conformal Prediction in The Loop 用反馈式 CP 构造障碍位置的预测区域以实现概率无碰撞 TO，并明确指出：交互/自适应场景破坏可交换性（exchangeability）假设，需对抗鲁棒 CP 或迭代更新来维持保证。**含义：把验证阈值当固定常数是错的，必须分场景桶/反馈校准。**
- **事实 F72（诚实缺口 A39–A42，2026-11-10）**：F60 仅声明四路相机以 JPEG 传输，**未核实是否有深度图、相机内参/外参标定、任务物体 CAD/尺寸**；也未核实 SLAM/验证与策略推理共用同一后端时的算力预算；「迭代验证」的额外开销必须计入 Δ-Plane。以上是 v18 成立与否的前提，不能当既成事实。

## 1. 研究者直觉（先直觉与动机，后形式化）

**直觉 1（SLAM 不是导航，是「操作的空间记忆」）**。桌面操作不需要城市尺度 SLAM，但需要一个**活的、物体级、带协方差的桌子模型**。G1 有 4 路相机 + 可动 base/pivot；官方语言指令整段不变（F60），说明对象在一 episode 内相对固定，但人为干扰会移动它们。v17 的 IP-36 语义图本质是「一次性快照」——物体一被移走或遮挡，图世界模型与 TO 包络立刻过期，而 v17 没有任何机制知道自己过期了。对象级 SLAM（F67）恰好补三样：物体位姿随时间的演化与协方差、未观测/被遮挡物体的信念传播、以及「移动相机去重观测」的主动能力（F68）。这把 v17 从「开环的世界模型」变成「闭环的世界信念」。

**直觉 2（验证不是新模块，是一个可校准的残差）**。v17 已有 IP-24 失败监测、IP-28v2 CTC 进度、IP-30 VLM 判别、IP-46 证书——四个各自手调阈值的验证器。它们的问题是：没有共同度量、没有统计保证、误报/漏报无法归因。迭代验证的正解是定义一个**统一的预测-观测残差** `z_k`（在空间记忆坐标系里表达），用 conformal 只在成功轨迹上校准阈值 `τ_α`（F69），于是「何时重规划」从拍脑袋变成「`z_k > τ_α`」的分布无关判据。这是把验证从工程技巧升格为**可证伪的统计程序**，也让 v17 的四个验证器有了共同的「本币」。

**直觉 3（迭代验证的经济学：几何便宜、采样昂贵）**。生成式策略的 best-of-k 验证很贵（每候选一次前向）。但空间一致性检查几乎免费：给定命令 chunk 与地图，预测 EE 与物体位姿，下一帧观测即可算残差。因此正确顺序是「**先用几何残差剪枝/判定，几何有歧义才调 VLM 或策略重采样**」。这正好落在 v17 的 Δ-Plane 预算框架里——验证不是无成本的正确性，而是一种要记账的算力；几何验证是「低成本高覆盖」的第一道闸。

**直觉 4（U_map 作为第四本账：认知预算）**。v17 的三账本（热/时延/步数）都是物理成本；本轮加入认知成本——位姿不确定性 `U_map`（协方差迹或任务相关方向方差）。它与其他账本同构：可以「花步数买确定性」（主动 NBV），也可以「用确定性省步数」（不用反复试错）。关键耦合：`U_map` 高 → TO 的精度目标不可信 → 应**增大安全裕度而非硬追精度**；`U_map` 高且任务高价值 → 值得花 1–2 步做 NBV。这条把 L1 记忆、L3 规划/TO、L3 安全用同一本账串起来。

**直觉 5（修剪：v18 只买两样东西）**。规则 51 要求每轮剪。对照本赛道现实（单一 G1 本体、桌面序列任务），IP-42 跨本体运动预训练与 IP-44 三阶段渐进蒸馏是典型的「能力展示型」——G1 是唯一本体，跨本体表征对本榜单边际得分极低；蒸馏收益可被官方/开源 VLA 基座 + LoRA 覆盖。本轮把这两项降 P2，兑换给 IP-51/IP-52 两个真正补 v17 短板的 P0。

## 2. 灵感词 → 落地线（新增 + 重构 + 修剪登记）

- 「**SLAM**」→ **IP-51 SPATIAL-MEMORY-SLAM（SMS，P0 新增）**：对象级语义 SLAM（多视角 6D 位姿 + 数据关联 + 因子图后端 + 鲁棒核）+ 未观测物体信念 + 动态/静态判别与重关联 + 主动 NBV（信息增益/步数成本）+ 位姿协方差输出（喂 IP-49/50/53）+ 手眼/外参在线标定。定位是「操作的空间记忆」，不是导航。
- 「**迭代验证**」→ **IP-52 VALIDATE-OR-ACT（IVL，P0 新增）**：预测-观测残差 `z_k`（EE 跟踪 / 物体一致性 / 任务进度 / 语义歧义）+ conformal 阈值 `τ_α`（仅成功轨迹校准）+ 四类归因（干扰/执行失败/感知失败/规划错）+ 验证预算调度（几何优先、VLM 仅歧义时）+ 残差驱动软重规划/重观测。把 v17 的四个验证器收束为一本「验证账」。
- 「**交叉**」→ **IP-53 CONFORMAL-GEOMETRIC-GUARD（P1 新增）**：按位姿误差的 conformal 分位膨胀物体包络与 CBF 裕度，使「概率无碰撞」（P(collision)≤α）与 TO/CBF 直接对接；把 U_map 翻译成安全裕度。
- 升级：**IP-36**（静态语义图 → 活的对象信念、含协方差与遮挡信念）、**IP-49**（规划读 U_map，NBV 作为可交易动作进入 E_score）、**IP-50**（TO 的终端/避障裕度由协方差决定）、**IP-48**（三账本 → 四账本，新增 U_map）、**IP-24/28v2**（统一到验证残差）、**IP-33**（CBF 包络按 conformal 分位膨胀）、**IP-38**（恢复含 re-localization）、**IP-25**（SLO 纳入 SLAM/验证时延）。
- 修剪登记：**IP-42 CROSS-EMBODIMENT-MOTION → P2 挂起**（单一 G1 本体，跨本体预训练边际得分低）；**IP-44 PROGRESSIVE-CURRICULUM-DISTILL → P2 挂起**（由基座 + LoRA 覆盖，三阶段蒸馏算力/数据门槛高）。

## 3. 形式化直觉（严格版见产物区 §3）

**定义 29（空间记忆 `M_t`）**：`M_t = (G_t, {X_i, Σ_i, c_i, b_i}, T_base(t))`，其中 `G_t` 为因子图/位姿图，`X_i∈SE(3)` 为任务相关物体位姿，`Σ_i` 为其边缘协方差，`c_i` 为语义类别/属性，`b_i` 为未观测或被遮挡物体的信念（高斯混合或粒子）。更新为鲁棒 MAP：`M_t = argmax ∏ φ_odom(T_base) · ∏ φ_kin(T_EE|q) · ∏ φ_obj(X_i|z_i,T_base) · ∏ φ_prior(X_i)`，用 switchable constraints/鲁棒核抑制动态物体与误关联。

**定义 30（验证残差与 conformal 阈值）**：在第 `k` 个 chunk 边界，`r_k = g(m̂_{k+1}, m_{k+1})`，分量含（i）EE 跟踪残差、（ii）任务相关物体一致性（未操作为 0、被操作与期望位移差）、（iii）任务进度残差（CTC）、（iv）语义残差（仅几何歧义时）；`z_k = ||r_k||_{Σ_r^{-1}}` 为白化范数。阈值 `τ_α` 由成功轨迹残差的经验 `(1−α)` 分位得到（F69）；在可交换性成立时 `P(z_test ≤ τ_α) ≥ 1−α`。**闭环破坏可交换性（F71）→ 按场景桶重校准 + 反馈式 CP。**

**定义 31（验证-即-行动 / 迭代精化）**：策略每步在「执行下一 chunk」与「先做 NBV 重观测」间选择：`a* = argmax_a E[ΔScore] − λ_c·Cost(a)`，其中 NBV 的收益 = 预期位姿方差下降转化为的 TO 精度提升与失败率下降，成本 = 步数 + 时延 + 热。迭代终止条件：`z_k ≤ τ_α` 且 `tr(Σ_target) ≤ ε_pose`，或认知/物理预算耗尽。收敛性由「协方差单调收缩 + 预算上界」保证（无预算上界时可能不终止，故必须记账）。

**定义 32（不确定性感知安全裕度）**：对物体包络 `𝒪_i`，取位姿误差的 conformal 分位 `q_{1−α}`，膨胀为 `𝒪_i^α = 𝒪_i ⊕ Ball(q_{1−α})`；TO/CBF 在该膨胀包络上求解，从而 `P(collision) ≤ α`（在 CP 有效性前提下）。这是把 U_map 直接翻译成安全约束的桥。

## 4. 关键决断

1. **记忆化**：把 SLAM 从导航工具重定义为「操作的空间记忆 + 验证的度量基准」；v17 的语义图升级为带协方差的活信念。
2. **验证统计化**：验证阈值由 conformal 在成功数据上校准，不依赖失败数据与手调；几何优先、语义后置，验证开销计入账本。
3. **认知预算化**：U_map 成为第四本账；NBV 是「用步数买确定性」的显式交易，进入 E_score。
4. **不确定性进安全**：位姿协方差经 conformal 膨胀进 TO 约束与 CBF 裕度，使「精度」与「安全」共享同一不确定性来源。
5. **修剪两项**：IP-42、IP-44 降 P2，兑换复杂度给 IP-51/IP-52。

## 5. 本轮最大风险（一句话）

**若相机无深度、无内外参标定、任务物体无 CAD（A39–A41），单目对象位姿误差可能接近甚至大于 v17 的 TO 想赢的那 5mm，则「验证残差」建立在噪声之上、主动 NBV 也可能只是在错误地图上花步数；必须以 E73（位姿精度）/E74（干扰恢复）/E75（conformal 校准）三重守门，任一失败即退化为「2.5D 桌面假设 + 保守裕度」的 v17.5，而不是把闭环自我指涉地越拧越紧。**

# 第 41 轮产物 · 创新点清单 v18：对象级空间记忆 × 验证-即-行动闭环（Δ-Plane 四账本，四层架构 v6）

> 承接 v17（第 40 轮）。本轮灵感词「迭代验证 / SLAM」经联网核实（口径 2026-11-10）后指向 v17 的同一个隐藏假设：**物体位姿已知且静止**。v18 新增 **2 项核心 IP（IP-51 对象级空间记忆 / IP-52 验证-即-行动）+ 1 项 P1 安全桥（IP-53 conformal 几何守护）+ Δ-Plane 第四账本 U_map（认知预算）**，升级 8 项协作 IP（IP-24/25/28v2/33/36/38/48/49/50），**修剪 2 项 v17 能力展示型设计（IP-42 跨本体运动、IP-44 三阶段蒸馏 → P2）**。主轴从「单位物理成本的得分效率」推进到「物理成本 + 认知成本的联合调度」。

## 0. 结论

- **Δ-Plane v2（本轮总纲）**：在 H_gpu / Ĥ_motor / S_used / L_p99 之外新增 **U_map（位姿不确定性/认知预算）**；四账本共同调度 v16/v17 的服务总线、证书、规划、TO 与安全。
- **IP-51 SPATIAL-MEMORY-SLAM（P0 新增）**：对象级语义 SLAM（多视角 6D 位姿 + 鲁棒因子图 + 动态判别 + 重关联）+ 未观测物体信念 + 主动 NBV + 协方差输出；把 v17 的静态语义图升级为「活的桌面记忆」。
- **IP-52 VALIDATE-OR-ACT（P0 新增）**：统一预测-观测残差 `z_k` + conformal 阈值 `τ_α`（仅成功轨迹校准）+ 四类失败归因 + 几何优先的验证预算；把 v17 的四个手调验证器收束为一本「验证账」，并直接驱动软重规划/重观测。
- **IP-53 CONFORMAL-GEOMETRIC-GUARD（P1 新增）**：按位姿误差的 conformal 分位膨胀物体包络与 CBF 裕度，使概率无碰撞（P≤α）与 TO/CBF 对接。
- **修剪（规则 51）**：IP-42 跨本体运动→P2（单一 G1 本体，边际得分低）；IP-44 三阶段渐进蒸馏→P2（基座 + LoRA 覆盖）。
- **关键耦合**：SLAM 提供「便宜且统一的验证基准」→ 迭代验证可负担；验证检测到干扰 → 少走无效步；主动 NBV 花步数买确定性 → 提升 TO 精度、减少下游重试；U_map 高 → 放大安全裕度而非硬追精度。
- 通道诚实：相机无深度/内外参/物体 CAD 未核实（A39–A41）；SLAM 与策略共存的算力预算未核实（A42）；conformal 可交换性在闭环下会破（F71），需分桶/反馈校准。
- 行动项：A16–A38 延续；**A39–A44 新增**（深度/内参外参、物体 CAD、同后端算力、conformal 分桶、NBV 步数上限、外参在线标定）。

## 1. 事实卡（新增 F67–F72，检索日期 2026-11-10）

- **F67（对象级语义 SLAM）**：OpenGS-SLAM（arXiv 2503.01646，ICRA 2025）3DGS 开放集稠密语义 SLAM、对象级、语义渲染约 10× 加速；Go-SLAM（IROS 2025，DOI 10.1109/IROS60139.2025.11246048）grounded object segmentation + 开放词汇查询 + 每物体唯一 ID；DOGL-SLAM（RA-L 已接收）动态环境对象级 SLAM（联合高斯-地标跟踪 + 分层动态滤除）；HAMMER（arXiv 2501.14147，RA-L 2025）服务器式多机器人异步流公制-语义高斯地图。
- **F68（主动对象建图/抓取）**：Object SLAM-Based Active Mapping and Robotic Grasping（3DV 2021）对象驱动探索降位姿不确定性以利抓取；POp-GS（CVPR 2025）3DGS 下 P-optimality 信息增益/NBV；Motion-Uncertainty-Aware NBV（RSS 2026）；互信息分层主动语义视觉 SLAM（Sci Rep 2026）。
- **F69（运行时失败预测，NeurIPS 2025）**：FIPER（arXiv 2510.09459）RND OOD + action-chunk entropy，conformal 仅用成功轨迹校准，无需失败数据；区分真失败与良性 OOD，告警更早更准。
- **F70（闭环/主动失败检测）**：Code-as-Monitor（CVPR 2025）约束感知反应式+主动式失败检测，可与开环策略组成闭环，处理人手移物；KnowLoop（arXiv 2406.00430）不确定性失败检测用于闭环 LLM 规划，给出「开环 70–80% → 人为干扰下 0%」证据。
- **F71（conformal 进回路）**：Conformal Prediction in The Loop（NeurIPS 2025）反馈式 CP 构造障碍预测区域做概率无碰撞 TO；明确交互/自适应破坏可交换性，需对抗鲁棒 CP 或迭代更新。
- **F72（缺口 A39–A42）**：F60 仅声明四路相机 JPEG，未核实深度、内外参标定、物体 CAD；未核实 SLAM/验证与策略推理同后端算力；验证开销必须入 Δ-Plane。

### 3.2 IP-51 SPATIAL-MEMORY-SLAM（对象级空间记忆，完整设计）

**IP 卡片（六字段）**：
- **动机**：v17 的 IP-36 语义图是静态快照，IP-50 的精度目标与 IP-33 的障碍包络都假设它正确；F70 证明人为干扰下开环成功率可跌至 0%。F67 证明对象级语义 SLAM 已可工程化，F68 证明主动建图对抓取位姿精度有量测收益。
- **与现有方案差异**：导航 SLAM 追求全局轨迹一致性；本任务只要「任务相关物体的局部高精度 + 变更检测」。故不建全场景稠密图，而建**对象级稀疏因子图**（只保留任务相关物体、桌面平面、机器人 base/EE 节点），并显式维护「未观测信念」与「动态/静态」标签。与 IP-36 的分工：IP-36 管语义类型/关系，IP-51 管位姿、协方差与时间演化。
- **技术可行性**：前段用开放词汇检测/分割（SAM/CLIP）+ 模型基 6D 位姿（FoundationPose 类）或 3DGS 跟踪；后段因子图增量求解（iSAM2 类）；单次更新目标 <5ms；主动 NBV 用 P-optimality 信息增益（F68），候选视图由 base/pivot/臂的离散可达位姿给出。
- **所需资源**：数据=每机一次手眼/外参标定（E73）；算力=前段可复用策略的视觉骨干（省算力），后端稀疏图 CPU 毫秒级；接口=F60 的 4 相机 + 本体关节/EE + pivot，零接口改造。
- **落地步骤**：① E73 标定与位姿精度基线；② 前端接入 + 任务相关物体注册；③ 因子图后端 + 动态判别/重关联；④ 未观测信念与遮挡处理；⑤ 主动 NBV 接入 IP-49 E_score；⑥ E74 干扰恢复验收。
- **风险**：单目尺度/深度缺失（A39）→ 多视角三角化 + 桌面平面先验 + 物体尺寸先验；SLAM 与策略抢算力（A42）→ 关键帧化 + 仅任务物体 + 与 IP-48 共调度；外参漂移 → 在线标定 + 置信包络。

**符号表**：

| 符号 | 含义 | 来源 |
|---|---|---|
| `X_i∈SE(3)` | 物体 i 的位姿 | 前端观测 + 后端 MAP |
| `Σ_i` | 位姿边缘协方差 | 因子图边缘化 |
| `b_i` | 未观测/遮挡信念 | 高斯混合/粒子，含桌面接触先验 |
| `T_base(t), T_EE(t)` | base / EE 位姿 | 里程计 + 正运动学 |
| `c_i` | 语义类别/属性 | IP-36 类型系统 |
| `z_i` | 观测（分割掩码/关键点/深度若有） | 4 相机 |

**算法（对象级因子图更新）**：
```
输入：多视角观测 z, 本体 q/EE/pivot, 上一时刻 M_{t-1}
1. 前端：检测/分割 → 与 M_{t-1} 数据关联（语义+几何+外观描述子）
2. 动态判别：若关联物体残差 > κ 且无法由机器人自身运动解释 → 标记 dynamic
3. 后端：MAP = argmax Σ 鲁棒核(里程计) + 核(正运动学) + 核(物体相对观测) + 先验(桌面/重力)
4. 边缘化得 Σ_i；遮挡/丢失物体沿信念 b_i 传播并膨胀 Σ_i
5. 若 tr(Σ_target) > ε_pose：调用 NBV 候选生成（IP-53 前）
6. 输出 X_i, Σ_i, b_i, 变更标志(relocalize?)
```

**正确性论证**：P51（一致性）——在观测无偏、鲁棒核排除外点前提下，因子图 MAP 是最大后验估计，协方差反映真实不确定性；P52（变更检测）——动态物体残差期望显著大于静态外点阈值，重关联后地图自洽；P53（NBV 单调收益）——在 P-optimality 下新增视角不增大后验协方差（信息矩阵半正定叠加），故重观测不会使目标位姿更不确定。

### 3.3 IP-52 VALIDATE-OR-ACT（验证-即-行动，完整设计）

**IP 卡片（六字段）**：
- **动机**：v17 的 IP-24/28v2/30/46 是四个孤立验证器，阈值手调、无统计保证、无法归因；F69 证明可用仅成功数据做 conformal 校准；F71 提醒闭环会破坏可交换性。
- **与现有方案差异**：FIPER 只做「失败告警」，Code-as-Monitor 做「约束检测」，二者都不把验证与**空间记忆**绑定、也不把验证成本纳入资源调度。本设计把验证定义为空间坐标系中的预测-观测残差，并让它同时驱动（a）提交前几何剪枝、（b）执行后失败归因、（c）地图更新与重规划、（d）可选的 NBV 重观测。
- **技术可行性**：残差各分量均在既有模块中有来源（IP-28v2 进度、IP-30 判别、IP-50 跟踪模型、IP-51 位姿）；conformal 校准离线一次性完成，在线只做阈值比较 O(1)。
- **所需资源**：数据=成功轨迹残差分布（自采，按 5 场景分桶）；算力=几何残差毫秒级，VLM 仅歧义时调用；接口=每次 `get_action` 的观测即天然的 chunk 边界验证点。
- **落地步骤**：① 定义残差与白化；② 成功轨迹采集 + conformal 校准；③ 四类归因规则；④ 接入软重规划/重观测；⑤ E75 校准验收 + E74 干扰恢复。
- **风险**：可交换性破坏（F71）→ 分场景桶 + 反馈式 CP + 周期性重校准；误报伤步数 → α 可调 + 「连续 k 次越界才触发」；归因误判 → 先做保守动作（重观测）再做激进动作（改策略）。

**符号表**：`r_k=(r_EE, r_obj, r_prog, r_sem)`；`Σ_r` 残差协方差；`z_k=||r_k||_{Σ_r^{-1}}`；`τ_α` conformal 阈值；`Cause∈{DISTURB, EXEC_FAIL, PERCEPT_FAIL, PLAN_ERR}`；`B_verify` 验证预算（算力/时延）。

**算法**：
```
每次 get_action（即一个 chunk 边界）：
1. 先验证上一 chunk 的预测结果：
   r_EE   = ||x_EE^obs − x_EE^pred||_{Σ_track}
   r_obj  = 任务相关物体位姿增量 − 期望增量（未被操作则期望 0）
   r_prog = CTC 进度偏差；r_sem 仅当几何歧义
   z = 白化范数(r)
2. 若 z ≤ τ_α：地图融合，继续
   若 z > τ_α（且连续 k 次）：四类归因
     - DISTURB      → IP-51 重关联/重定位 → IP-49 软重规划
     - EXEC_FAIL    → 失败记忆升级策略（不原地重试）
     - PERCEPT_FAIL → 请求 NBV 重观测（IP-51）
     - PLAN_ERR     → 图世界模型修复，必要时 LLM
3. 提交前（新 chunk）：
   a. 几何验证候选（碰撞/可达/在膨胀包络内）→ 剪枝
   b. 若仍有多个候选或几何歧义 → 预算内 best-of-k + VLM
4. 记录 B_verify 到 IP-48（计入 L_p99 / U_map）
```

**正确性论证**：P54（校准有效性）——可交换性成立时 `P(z_test≤τ_α)≥1−α`（CP 定理）；P55（归因可分离）——四类残差在任务相关方向上正交性/可分性假设下，可用决策树/似然比实现可控误分；P56（验证不伤成功率）——几何验证只会剔除被膨胀包络判定为碰撞/不可达的候选，最优候选仍保留，故成功率不降（最坏退化为原策略）。

### 3.4 IP-53 CONFORMAL-GEOMETRIC-GUARD（P1，安全桥）

**要点**：对每个物体包络 `𝒪_i`，用 E73 的位姿误差残差做 conformal 校准，得 `q_{1−α}`，膨胀为 `𝒪_i^α=𝒪_i⊕Ball(q_{1−α})`；IP-50 的避障约束与 IP-33 的 CBF 均在该膨胀包络上求解。**与现有 CBF 差异**：v17 用固定裕度，本设计让裕度随估计不确定性与场景桶自适应，且给出 `P(collision)≤α` 的有限样本保证（F71 前提下）。**风险**：CP 有效性依赖标定与测试同分布，跨场景需分桶；膨胀过大会降低可达空间，需以 α 与成功率做 Pareto 扫描（E77）。

### 3.6 训练/服务伪代码（v18 增量版）

```python
# ===== 离线：标定 + conformal 校准（IP-51/52 依赖）=====
def calibrate(robot_if, success_trajs):
    extr = estimate_hand_eye_and_cameras(robot_if)        # E73；失败→2.5D 桌面假设
    residuals = [residual_components(traj, map) for traj in success_trajs]
    z = [whitened_norm(r) for r in residuals]
    tau = {bucket: empirical_quantile(z_bucket, 1 - alpha)
           for bucket, z_bucket in bucketize(z, dims=[scenario]).items()}
    return extr, tau                                       # 分桶阈值（F71 破可交换性）

# ===== 运行期：记忆 → 验证 → 规划 → TO（每个 get_action 调用）=====
def act_v18(obs, state):
    # A. 账本更新（四本）
    M = state.slam.update(obs)                             # IP-51
    ledger = update_ledger(H_gpu=telemetry(), H_motor=heat_proxy(state),
                           S_used=state.steps, L=L_ewma, U=M.uncertainty())
    knobs = governor(ledger)                               # 含 B_verify

    # B. 先验证上一个 chunk（IP-52）
    if state.prev_chunk is not None:
        z, cause = validate_post(state.prev_chunk, M, state.prev_plan, tau=state.tau)
        if z > state.tau[state.scenario]:
            if cause == "DISTURB":     M.relocalize(); state.need_plan = True
            elif cause == "EXEC_FAIL": state.failure_memory.upgrade()
            elif cause == "PERCEPT":   M = request_nbv(M, state)   # 重观测
            else:                      state.need_plan = True

    # C. 主规划 / 软重规划
    if state.need_plan:
        state.plan = step_efficient_planner(obs.language, M, state.p_s, state.W,
                                            state.failure_memory, scenario=state.scenario,
                                            budget=knobs, U=ledger.U_map)

    # D. 认知预算交易：位姿不确定时，先花步数买确定性
    if M.uncertainty(state.plan.target) > state.eps_pose:
        nbv = M.next_best_view(state.plan.target, budget=knobs)
        if planner_accepts_nbv(nbv, state.plan, ledger):   # E[ΔScore] > 步数成本
            return M, nbv.command                            # 本步执行 NBV

    # E. 中层 → TO 精修（裕度由协方差决定，IP-50/53）
    task = midlevel(state.plan, M, budget=knobs)
    warm = stream_policy_head(state.plan.skill, obs)
    refined = hybrid_to(task, warm, envelopes=M.inflated_envelopes(alpha),
                        f_track=state.f_track, weights=(w_E, knobs.hot, w_P))
    if refined is None: refined = warm

    # F. 提交前几何验证（IP-52）
    refined = geometric_validate(refined, M, envelopes=M.inflated_envelopes(alpha))
    if refined is None:
        M = request_nbv(M, state); return M, hold()
    chunk = refined.next_chunk(knobs.T_a_eff)
    if not guard.cbf_check(chunk, margins=state.conformal_q):   # IP-53 + IP-33
        chunk = resample_or_fallback(state, r=2)

    state.prev_chunk, state.prev_plan = chunk, state.plan
    return M, adapt(chunk, control_space=state.control_space)
```

## 6. 清单迭代规则（继承 27–51 + 本轮新增 52–55）

- 继承规则 27–51（通道诚实/映射验证/SLO/fail-safe/灵感-现实校验/单模型合规/步骤分双解释/稠密监督/方法论遗产/元数据重照亮/语言口径分离/摊销/验证器分级/灵感词落地/层级联合规划/跨本体运动/流式韵律/渐进蒸馏/服务化/证书化/组合代数/热预算/期望得分/学习-TO/修剪优先）。
- **52（新增）：空间记忆一等公民原则**——任务相关物体的位姿、协方差与遮挡信念必须作为在线状态维护；任何依赖物体位姿的模块（规划/TO/CBF）必须读取该记忆的即时版本与不确定性，禁止默认「静止且已知」。
- **53（新增）：验证即统计程序原则**——验证阈值必须由成功轨迹的 conformal 分位校准（可交换性成立时），闭环下按场景桶/反馈式重校准；验证必须给出四类归因并驱动不同恢复动作；验证开销计入账本。
- **54（新增）：认知预算原则**——U_map 与热/时延/步数同为账本；主动 NBV 是「花步数买确定性」的显式交易，必须进入 E_score，且每 episode 有上限；高不确定性优先放大安全裕度而非硬追精度。
- **55（新增）：修剪优先原则（续）**——每轮至少降级 ≥2 项能力展示型设计（本轮 IP-42/IP-44），新增 P0 必须对应明确的失效模式与可证伪实验（E73–E78），否则不得入 P0。

**本轮最大风险一句话**：单目位姿若无法在无深度/无 CAD 下达到毫米级（A39–A41），验证残差与主动 NBV 都会在噪声上自我强化——「记忆-验证-精度」闭环可能退化为不可验证的循环论证；以 E73/E74/E75 三重守门，失败即退 v17.5（3-DoF 桌面假设 + 保守裕度），绝不在错误地图上越拧越紧。

**当前最值得押注**：**IP-52 VALIDATE-OR-ACT**——它把 v17 四个各自为政的验证器收束为一本可校准的「验证账」，复用现成的空间记忆与跟踪模型，几乎零接口成本，且能被 E75（conformal 校准）与 E74（干扰恢复）两个小实验快速证实/证伪；即便 IP-51 的位姿精度不达标，几何前验证与四类归因仍可独立生效，是「低风险、可回退、直击人为干扰与泛化失败」的一手。
