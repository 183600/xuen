# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧」IP-253~263；灵感循环第 3 轮；本轮灵感：「云边协同」×「多模态大模型」）

> R69 把不确定性劈成 aleatoric / epistemic，并让系统学会「问」。但它默认「被问的人/模型」是同一个身体里、低延迟、可信、且与边缘策略相互独立的。现实里，能真正看懂复杂场景的那个**多模态大模型**不在车上/机器人上——它在云里：更慢（80–800ms vs 2.6ms 环路）、会断线、会悄悄换版本、和边缘策略共享训练血统（因此**错误相关**）、还可能被提示注入或后端投毒。R69 的「k 个正交证据源」在云边场景下会被一个假象骗过：**边缘与云「都同意」不是因为都对，而是因为它们一起错（共享盲区）**。
>
> 本轮的两个灵感正好把这层「外部大脑」纳进来，同时不让它坐进驾驶座：
> - **云边协同**给出一个**延迟、间歇、版本化、部分对抗**的 oracle 抽象——云的输出只能是「证据」，不能是「指令」；
> - **多模态大模型**给出边缘做不到的高容量语义先验（意图、物体身份、任务目标），恰好补上「慢歧义」这一 R69 的 MINT 解不动的部分。
>
> 核心命题：**把云当作一个「慢、会走神、可能撒谎、且与边缘同源」的 oracle；边缘主环是它的全函数（云掉线 = 恒等），云只能「否决（加保守）」或「在认证包络内确认（加分辨率）」，永远不能把安全地板压到边缘单独决策之下。** 命名 **NIMBUS-RAS**（Networked Intermittent Multimodal Belief Update with Safety）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我该信它几分、它的答案到我手里还值钱吗**」——云边协同的第一性问题是**信任的时变折扣**，不是带宽。

## 0. 直觉与动机

**灵感 1（异构算力 → 歧义天然分时）**
直觉：R69 的信息动作（注视/探针）是毫秒级的近身消歧；但有一类歧义根本近身问不出来——「那是一把椅子还是一个人」「他挥手是打招呼还是求救」「任务目标是先卸货还是先充电」。这些是语义级、时间尺度以秒计的**慢歧义**。让边缘的 2.6ms 闭环去背一个 MLLM，既超时又超算力；而云端正好有算力。**歧义的时间尺度，决定它该在边还是在云解。** 这把 R69 的「值不值得问」升级成「**该问谁、答案来不来得及**」。

**灵感 2（延迟 → 答案会过期）**
直觉：云端答案 300ms 后才回来。若这 300ms 内模式身份已经变了（车已经越过岔口、人已经放下手），再正确的旧答案也是垃圾。所以云答案的价值必须乘以一个**时间相干因子** P(M_{t+δ}=M_t)；快歧义（τ_c 小）即使 ambiguity 很大也不该上云——不是算不起，是**答案到得太晚**。这给出一条可执行的判据：**上云的是慢歧义，不是大歧义**。

**灵感 3（同源 → 共识可能是共谋式错觉）**
直觉：R69 用「k 个正交源一致」把单次交互的投毒上界压到 δ_p·ρ^{k−1}。但当边缘流策略是从云端 MLLM 蒸馏而来、或二者吃同一批数据时，它们的错误高度相关（ρ_ec→1）——「边缘说 A、云也说 A」根本不是两个独立证人，而是**一个证人照了镜子**。把相关性当独立，会让后验置信度系统性虚高，「已验证」的章盖在一个共享盲区上。所以云票必须按 **1−ρ_ec** 打折；而 ρ_ec 只能靠**有地面真值的锚定探针**才可辨识。

**灵感 4（版本漂移 → 又一个「被标定吸收的故障」）**
直觉：R68 的慢变故障能被标定吸收，R69 用行为似然补了一刀。现在云端模型会静默升级（v→v+1），它的校准、拒答倾向、甚至「幻觉率」都会变——而边缘看不见。这正是 R68 那个「故障被解释掉」的结构在云侧重演：**漂移被「云端一直很自信」解释掉了**。对策同构：固定版本指纹 + 锚定探针上的序贯漂移检测（CUSUM/SPRT）+ 越界即降权。R70 问的就是「**谁来看住看门人**」。

**灵感 5（带宽与隐私 → 别把眼睛寄上去）**
直觉：上云的不该是原始多模态流（带宽 + 隐私 + 被中间人重放），而是一个**歧义描述子**：几个模态原型 + 权重 + 一条问句。它既是语义通信的充分统计量，也是隐私投影后的残渣。代价是信息天花板：描述子里没有的东西，云再怎么问也答不出来（garbage-in）。所以**隐私预算直接封顶分辨率红利**——这是一个可证明的取舍，而不是工程妥协。

**灵感 6（学习闭环 → 让云当老师，但不许它碰实时权重）**
直觉：R69 抱怨系统「永远不会学」。云可以标注、可以教，但 R68 的铁律「实时流零学习写操作」不能破。于是让云的标注进**影子蒸馏缓冲**，经离线晋升门（回放 + 安全回归 + 校准 + 溯源）才准更新边缘权重。这样既关上了学习环，又不给投毒/漂移任何直接改写实时策略的通道。**云可以改变边缘明天怎么想，但不能改变边缘这一毫秒怎么动。**

## 1. 形式化定义（增量：定义 310–322）

**定义 310（NIMBUS-RAS 总览）** NIMBUS-RAS = (CED, SCV, SSC, ACW, ANCHOR, VPB, RSG, SDB, CEB, RAS-WM††)。四不变式：
(i) 实时流零学习写操作（继承 R68 定义 276-i，SDB 不得直写实时权重）；
(ii) **边缘全函数**：任意时刻 t 的控制输出是边缘本地状态的函数，云缺失/超时/乱序 = 恒等映射（退化 R69）；
(iii) **云不直接致动**：云输出只能进入证据 → 信念 → λ → 认证前缀链，永不可作为动作提案绕过 C-RAS-WM；
(iv) **非对称信任**：云可自由「加保守」（抬高 U），只可在认证包络内「减保守」（κ-折扣的分辨率红利）。

**定义 311（云边时延与陈旧模型）** 查询在 t 发出，答案在 t+δ 到达，δ = δ_net + δ_infer + δ_queue，δ ≥ δ_min，且可能丢失（丢弃率 p_drop）或乱序。边缘在 [t, t+δ) 内必须独立安全运行；答案只对 t+δ 之后的状态有效。

**定义 312（时间相干与歧义分时）** 模式身份过程 M_t。定义相干时间 τ_c = ∫_0^∞ P(M_{t+s}=M_t) ds 的估计（由边缘 FMP 的模态持续期统计）。称歧义为**慢歧义**若 τ_c ≥ δ_p99，否则为**快歧义**。快歧义只允许 R69 的近身信息动作；慢歧义才允许上云。

**定义 313（陈旧校正 VoI，SCV）** 对候选云端查询 q（携带描述子 d 与问句），
SCV(q) = P(M_{t+δ}=M_t | o_t) · VoI(q) − c_comm(d) − c_social(q) − c_stale(δ)，
其中 c_stale(δ) = c_0·(1 − e^{−δ/τ_c}) 为过期惩罚。仅当 SCV(q) > 0 且 τ_c ≥ δ_p99 时允许上云。SCV 取代 R69 的 VoI 作为云侧调度分数。

**定义 314（语义充分统计通道 SSC 与隐私投影）** 描述子 d = (ξ̄_{1:K̂}, ŵ_{1:K̂}, ℰ_disc, q) ∈ 𝒟，ℰ_disc 为判别性残差子集（定义 300）。要求 d 满足隐私投影：I(d; raw_o) ≤ I_max（由差分隐私/信息瓶颈实现），且 |d| ≤ B_max（带宽）。**信息天花板引理**：云侧可获得的互信息 I(M; answer | d) ≤ I(d; M) ≤ I_max，故分辨率红利被隐私预算封顶。

**定义 315（相关证据模型）** 边缘证据 E_e 与云证据 E_c 的错误指示变量相关 ρ_ec ∈ [0,1]（共享训练血统/数据/提示模板）。有效独立证据数 k_eff = 1 + (k−1)(1−ρ_ec)，或等价地用精度加权：I_tot = I_e + w_c·I_c，w_c = (1−ρ_ec)/(1+ρ_ec)。ρ_ec=1 ⇒ 云票权重为 0（照镜子不算证人）。

**定义 316（锚定探针集 ANCHOR 与可辨识性）** 维护一组有地面真值/可交叉验证的探针 𝒫 = {(o_i, M_i)}，覆盖易/难/陷阱三档。周期性（或每次版本变更后）向边缘与云同时注入，得混淆矩阵 C_e, C_c 与联合错误率，估 ρ_ec 与各自 ECE。**可辨识性命题**：仅凭「二者一致」无法区分「同对」与「同错」；必须有至少一档 𝒫_hard（真值已知且历史上易错）才能把 ρ_ec 与准确率同时辨识。探针即「量尺」，其可信度是全部安全论证的前提。

**定义 317（版本钉扎与漂移检测 VPB）** 每个云答案携带 v = (model_hash, prompt_hash, decode_cfg, probe_set_ver, ts, nonce) 并签名。边缘对探针响应序列做 CUSUM/SPRT 漂移检测：若对数似然比累计越界，判云行为变更，κ←0 直到 RSG 重新认证。签名+时间戳+nonce 同时抵御重放。

**定义 318（回归安全门 RSG）** 版本晋升需通过：(i) 𝒫 上 ECE ≤ τ_ece^c；(ii) 与「上一已知良好版本」在稳定子集上的一致率 ≥ τ_stable；(iii) 𝒫_hard 上无显著退化（序贯检验）；(iv) 与边缘在 𝒫 上的误差相关 ρ_ec 未升至 τ_ρ 以上。任一失败 ⇒ 云降级为不可信，κ=0，行为退回 R69。降级是**单调、可审计、无需重训边缘**的。

**定义 319（影子蒸馏缓冲 SDB 与晋升证书）** 云标注 (d, answer, v, conf) 进入 SDB，不写实时权重。离线晋升（周期或算力空闲）需：回放安全回归、校准 ECE、探针无退化、溯源≥2 个去相关来源或人工审计。晋升生成证书 J_promo = (weights_hash_before/after, reg_suite_ver, ece, probe_delta, provenance)。实时环从不等待晋升。

**定义 320（认证升级包络 CEB）** 定义信任折扣 κ = κ(SCV, k_eff, ECE_c, drift, ρ_ec) ∈ [0,1]，对所有分量单调：SCV↑、k_eff↑、ECE_c↓、drift=0、ρ_ec↓ ⇒ κ↑。云可消解的不确定性上限为 ΔU ≤ κ·U_epi。于是
λ_final = max( λ_floor(U_ale + (1−κ_eff)·U_epi_unresolved), λ_edge_alone )，
其中 λ_edge_alone 是 R69 在同一状态下的 λ。**非对称性**：若云判「更危险」，允许 λ ↑（无上限）；若云判「更安全」，λ 只能降到 λ_edge_alone，不更低。κ=0 ⇒ 逐指令等于 R69。

**定义 321（威胁模型 AIC-NIMBUS）** ℰ_NIMBUS = ℰ_FLUID × ℰ_comm × ℰ_oracle × ℰ_privacy，其中 ℰ_comm = {丢包, 乱序, 重放, 中间人}, ℰ_oracle = {后端投毒, 静默漂移, 场景文字提示注入, 共谋欺骗}, ℰ_privacy = {描述子反演, 侧信道泄漏}。每个 threat 绑定一个检测器与一个降权规则。

**定义 322（证书 J_NIMBUS 与主闭环）** J_NIMBUS = (J_FLUID, δ_p99, τ_c, SCV, I(d;raw)≤I_max, k_eff, ρ_ec, cloud_ver_hash, drift_stat, κ, J_promo?, nimbus_ver)。Valid ⇔ Valid(J_FLUID) ∧ δ_p99 已估 ∧ 隐私/带宽未越界 ∧ 云版本钉扎 ∧ κ 与探针一致。

## 2. 关键算法骨架

```python
# IP-264 CED：云边调度（边缘全函数；云只进证据链，非阻塞）
class CloudEdgeDispatcher:
    def step(self, o_t, modes, w, z):
        self.belief = self.aud.decompose(modes, z)       # R69 边缘信念
        # 快歧义：只走 R69 近身交互，永不上云
        if self.tau_c(o_t) < self.delta_p99:
            return self.r69_path(o_t, modes)
        # 慢歧义：估 SCV，决定是否上云
        q = self.ssc.build(modes, w, o_t)                # 描述子 + 问句
        if self.scv(q, o_t) <= 0 or not self.budget.allow(q):
            return self.r69_path(o_t, modes)
        self.pending.append((q, self.clock.now()))
        return self.r69_path(o_t, modes)                 # 不等云，继续跑

    def on_answer(self, ans):                            # 异步到达；可能过期/被拒
        q, t_sent = self.pending.pop(ans.corr_id)
        if not self.vpb.verify(ans.sig, ans.ver, ans.nonce):
            return self.degrade(ans)                     # 签名/重放失败
        if self.clock.now() - t_sent > self.tau_c:
            return self.degrade(ans)                     # 答案已过期
        k_eff = self.acw.effective_sources(ans, q)       # 相关性折扣
        kappa = self.ceb.kappa(ans.scv, k_eff, ans.ece,
                               self.vpb.drift, self.acw.rho)
        self.belief.apply(ans, weight=kappa)             # 只动信念，不动指令
        return kappa
```

# IP-265 SCV / IP-266 SSC / IP-267 ACW / IP-269 VPB
def scv(q, tau_c, delta, voi, c):
    return math.exp(-delta / tau_c) * voi - c.comm - c.social - c.stale(delta)

def ssc_build(modes, w, o, Imax, Bmax):                  # 只发充分统计量，不发原图
    d = (mode_prototypes(modes), w,
         discriminative_residuals(modes), make_question(modes))
    assert mutual_info_upper(d, o) <= Imax and size(d) <= Bmax
    return d

def effective_sources(ans, q, rho_hat):                  # 云与边缘不再算两票
    w_c = (1.0 - rho_hat) / (1.0 + rho_hat)
    return 1.0 + w_c * ans.independence_class

def vpb_check(ans, probes):                              # 版本钉扎 + CUSUM 漂移
    if not verify_sig(ans.sig, ans.ver, ans.nonce):
        return False
    stat = cusum_update(probes.error_loglik_ratio(ans.ver))
    return stat < H_DRIFT

# IP-270 RSG：版本晋升/降级
def regression_gate(cand_ver, probes, last_good):
    ok = (ece(cand_ver, probes) <= TAU_ECE_C
          and agree(cand_ver, last_good, probes.stable) >= TAU_STABLE
          and not regress(cand_ver, probes.hard)
          and rho(cand_ver, EDGE, probes) < TAU_RHO)
    return ok        # False ⇒ κ=0，云降级，行为退回 R69

# IP-275 主闭环（R69 之上加一层；云不在实时路径）
def NIMBUS_round(M, obs):
    k, lam_edge, mode, (Ua, Ue) = M.fluid.round(obs)      # 完整 R69 一步
    kappa = M.ced.step_async(obs, mode, Ue)               # 非阻塞；可能返回 0
    Ue_resolved = (1.0 - kappa) * Ue
    lam = max(lam_floor(Ua + Ue_resolved), lam_edge)      # 非对称：不低于边缘
    M.sdb.offer(M.ced.last_answer)                        # 影子缓冲，不写实时权重
    M.jnimbus.submit(lam_edge, lam, kappa, M.ced.stats)
    return k, lam, mode

## 3. 推导

**引理 19（陈旧折扣与分时判据）** 设 M_t 平稳、相干时间 τ_c，δ 为往返时延。则云答案对当前模式的期望信息增益 ≤ e^{−δ/τ_c}·VoI(q)。故当 τ_c < δ_p99 时，任何云查询的期望增益 < 成本；**快歧义上云严格劣于边缘近身交互**。系：上云应条件在「慢歧义」，而非「大歧义」。

**引理 20（相关折扣与伪验证率）** 若边缘/云错误相关 ρ_ec，却按独立源计票，则「k 源一致」的后验错误率被低估为 δ_p·ρ^{k−1}；真实值 ≥ δ_p·(ρ + (1−ρ)ρ_ec)^{k−1}。当 ρ_ec→1，折扣后有效票数→1，所谓「已验证」退化为单源。**只有 ANCHOR 的 𝒫_hard 能同时辨识准确率与 ρ_ec**；无锚定时，「一致」不提供任何独立信息。

**引理 21（隐私-分辨率天花板）** 因 I(M; answer|d) ≤ I(d; M) ≤ I_max，CEB 可解锁的 ΔU ≤ κ·U_epi，其中 κ 的上界是 I_max 的单调函数。故隐私/带宽预算不仅限制通信，**直接封顶效率红利**：想更少保守，就得允许更多（安全审计下的）信息上云——这是一个可量化、可审计的取舍。

**定理 18（非对称信任与 R69 严格包含）** 在定义 320 的规则下，对任意状态：λ_final ≥ λ_edge_alone；且当 SCV≤0、κ=0（丢包/过期/漂移/ECE 越界/ρ_ec 越界/隐私越界）时，轨迹与 R69 **逐指令相同**。若 κ>0 且 ANCHOR/RSG 假设成立，则期望风险 ≤ R69。故 NIMBUS 是 R69 在「云不可用/不可信」边界上的退化：安全侧不让步，效率侧获**受隐私预算封顶、受探针校准**的分辨率红利。

**定理 19（漂移的有界暴露）** CUSUM 在探针上的平均检测延迟 ≤ h(Δ_drift, α, β)；在检出前，κ 对漂移的敏感度有界，故最坏超额风险 ≤ g(κ_max, Δ_drift, 探针频率)。**这是有界漏洞，不是零漏洞**：漂移检测的强度与探针频率成正比，与「不打扰部署」成反比——必须显式写入证书。

**定理 20（离线晋升不破坏实时安全）** SDB 不写实时权重，故实时不变式 (i) 恒成立；晋升门（定义 319）保证新权重在冻结场景集与探针上满足同一 J_FLUID 证书，故晋升前后实时安全语义不变。云可改变边缘「明天怎么想」，不能改变「这一毫秒怎么动」。

## 4. 复杂度分析

| 组件 | 时间 | 空间/带宽 | 正确性保证 |
|---|---|---|---|
| CED 调度（边缘侧，非阻塞） | < 0.05ms | O(1) | 定义 310/313；全函数 |
| SCV 计算 | < 0.02ms | O(1) | 引理 19 |

# IP-264 CED：非阻塞调度，云只进证据链
class CloudEdgeDispatcher:
    def step(self, o_t, modes, w, z):
        belief = self.aud.decompose(modes, z)
        if self.tau_c(o_t) < self.delta_p99:             # 快歧义 → 永不上云
            return self.r69_path(o_t, modes)
        q = self.ssc.build(modes, w, o_t)                # 充分统计量描述子
        if self.scv(q, o_t) <= 0 or not self.budget.allow(q):
            return self.r69_path(o_t, modes)             # 无利可图 → R69
        self.pending.append((q, self.clock.now()))
        return self.r69_path(o_t, modes)                 # 不等云

    def on_answer(self, ans):
        q, t_sent = self.pending.pop(ans.corr_id)
        if not self.vpb.verify(ans.sig, ans.ver, ans.nonce):
            return self.degrade(ans)                     # 重放/伪造
        if self.clock.now() - t_sent > self.tau_c:
            return self.degrade(ans)                     # 过期
        k_eff = self.acw.effective_sources(ans, q)       # (1-ρ)/(1+ρ)
        kappa = self.ceb.kappa(ans.scv, k_eff, ans.ece,
                               self.vpb.drift, self.acw.rho)
        self.belief.apply(ans, weight=kappa)             # 只动信念
        return kappa

# IP-265/266/267/269 组合
def scv(voi, tau_c, delta, c):
    return math.exp(-delta / tau_c) * voi - c.comm - c.social - c.stale(delta)

def ssc_build(modes, w, o, Imax, Bmax):
    d = (mode_prototypes(modes), w,
         discriminative_residuals(modes), make_question(modes))
    assert mutual_info_upper(d, o) <= Imax and size(d) <= Bmax
    return d

def effective_sources(ans, rho):
    return 1.0 + (1.0 - rho) / (1.0 + rho) * ans.independence_class

def vpb_check(ans, probes):
    return (verify_sig(ans.sig, ans.ver, ans.nonce)
            and cusum_update(probes.error_llr(ans.ver)) < H_DRIFT)

# IP-270 RSG：晋升/降级
def regression_gate(cand, probes, last_good):
    return (ece(cand, probes) <= TAU_ECE_C
            and agree(cand, last_good, probes.stable) >= TAU_STABLE
            and not regress(cand, probes.hard)
            and rho(cand, EDGE, probes) < TAU_RHO)

# IP-275 主闭环：R69 一步 + 非阻塞云证据
def NIMBUS_round(M, obs):
    k, lam_edge, mode, (Ua, Ue) = M.fluid.round(obs)
    kappa = M.ced.step_async(obs, mode, Ue)              # 可能立即返回 0
    lam = max(lam_floor(Ua + (1.0 - kappa) * Ue), lam_edge)
    M.sdb.offer(M.ced.last_answer)                        # 不写实时权重
    M.jnimbus.submit(lam_edge, lam, kappa, M.ced.stats)
    return k, lam, mode

## 4. 推导

**引理 19（陈旧折扣与分时判据）** 云答案对当前模式的期望增益 ≤ `e^{−δ/τ_c}·VoI(q)`；`τ_c < δ_p99` 时云查询期望增益 < 成本。系：上云应条件在「慢歧义」而非「大歧义」。

**引理 20（相关折扣与伪验证率）** 按独立源计票时「k 源一致」错误率被低估为 `δ_p·ρ^{k−1}`；真实下界 ≥ `δ_p·(ρ+(1−ρ)ρ_ec)^{k−1}`。ρ_ec→1 时有效票数→1，「已验证」退化为单源。只有 `𝒫_hard` 能同时辨识准确率与 ρ_ec。

**引理 21（隐私-分辨率天花板）** `I(M;ans|d) ≤ I(d;M) ≤ I_max` ⇒ `ΔU ≤ κ·U_epi` 且 κ 上界是 I_max 的单调函数。隐私/带宽预算直接封顶效率红利，取舍可量化、可审计。

**定理 18（非对称信任与 R69 严格包含）** 任意状态下 `λ_final ≥ λ_edge_alone`；当 SCV≤0、κ=0（丢包/过期/漂移/ECE 越界/ρ_ec 越界/隐私越界）时与 R69 **逐指令相同**；κ>0 且 ANCHOR/RSG 成立时期望风险 ≤ R69。R69 = 「云不可用」边界，安全不让步。

**定理 19（漂移的有界暴露）** CUSUM 平均检测延迟 ≤ `h(Δ_drift, α, β)`；检出前最坏超额风险 ≤ `g(κ_max, Δ_drift, 探针频率)`。**有界漏洞而非零漏洞**，检测强度与探针频率成正比、与部署打扰成反比，须写入证书。

**定理 20（离线晋升不破坏实时安全）** SDB 不写实时权重 ⇒ 不变式 (i) 恒成立；晋升门保证新权重在冻结场景与探针上满足同一 J_FLUID ⇒ 实时安全语义不变。云可改变边缘「明天怎么想」，不能改变「这一毫秒怎么动」。
