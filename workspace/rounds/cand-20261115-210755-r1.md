# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「机械臂抓取」×「模块化设计」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**抓取证书化 + 模块装配代数 + 组合式安全**。两个灵感各治 v9 的一笔债：**抓取债**——块证书里的 γ̂_grasp 只是一个未建模的布尔，恰好掩盖了接触过程最危险的连续量；**结构债**——MW 只把契约声明化，模块仍是固定单体，无组合定理、无热插拔、无任务级装配。共同纪律：抓取或装配任一环节失效 ⇒ 注入中立元，逐位退回 v9（引理 91），而非行为漂移。

## 0. 直觉与动机

**灵感 1（机械臂抓取 → 抓取证书与滑移预算）**
直觉：v9 把"抓取成功"压成一个布尔 γ̂_grasp，像把婚姻压成"已婚"——它丢掉了真正决定成败的连续量：还剩多少力闭合余量、接触是否已进入微滑、位姿误差吃掉了多少裕度。抓取不是某一帧的状态，而是一段**带证书的接触过程**：接近、预抓、闭合、抬升、搬运、释放各有不同风险，不能用同一阈值。核心创新：**抓取证书器（GraspCertifier, GC）**，输出区间证书 Ĝ=(q_FC, s_slip, c_cont, e_pose)，按六相给阈值；并用**滑移能量预算** E_slip=∫[f_t−μ_s f_n]_+·|v_t|dt 做早期预警——在真正跌落之前减速或重抓。它把 v9 块证书里的布尔 γ̂_grasp 升级为带 β_g 余量的区间，使"块内抓取失败"不再是一个无法被块证书表达的漏洞。

**灵感 2（模块化设计 → 模块装配代数与组合证书）**
直觉：前九轮不断往一个单体里堆模块，已 14+ 个 IP；每加一个都要重新论证全局安全——这是"手工整体论"的税。模块化不是把代码拆文件，而是让**接口成为一等公民**：每个模块是带类型端口、契约、rely-guarantee 证书和退化态射的黑盒；系统是一次**类型化装配**，组合安全由接口上的 assume-guarantee 闭合推出，而非每次重证全局。核心创新：**模块化量表套件（ModularGaugeKit, MK）**：模块七元组 + 装配图 + 模块库 + 热插拔协议。抓取与模块化在此交汇：**夹爪本身是一个可热插拔模块**，它的语义接口正是抓取证书模式——换夹爪＝换模块＋证书迁移。

**灵感 1×2 的交汇**
GC 给接触层提供"细粒度、相依赖"的证书，MK 给结构层提供"可组合、可替换"的骨架。二者共同把 v9 的"单一整体证书"分解为"接口证书 + 组合规则"：抓取失败在接触层被 GC 捕获并触发重抓，结构变更在装配层被类型系统拦截并在热插拔协议下无损迁移。

## 1. 研究问题（轮次升级版）

- **Q1（抓取证书可靠性）**：如何用可观测的力/触觉/位姿量构造保守抓取证书，使「证书成立 ⇒ 相内不滑落」在传感器与模型误差内成立？抓取证书如何与动作块证书联合，使块内抓取失败被重抓取中止点吸收而不破坏 v9 停车不变式？
- **Q2（组合证书）**：在什么接口类型与 rely-guarantee 闭合条件（无环或良基秩）下，逐模块证书的装配可推出系统级不变量？共享状态与接触耦合如何被静态检查或运行时监控捕获？
- **Q3（热插拔安全）**：quiescence + 证书迁移协议能否保证替换窗口内系统行为始终落在 v9 中立元退化格点内（无不变式空洞）？替换延迟是否受 200ms 块边界上界约束？

## 2. 设计原则（在 P7–P12 基础上新增 P13–P15）

**P13 抓取证书律（Grasp-Certificate, GC）**
抓取输出不是布尔，而是区间证书 Ĝ=(q_FC, s_slip, c_cont, e_pose)。每相 φ_g 有独立阈值；证书成立 ⇔ 各分量的保守端点均越过阈值。搬运期维护滑移能量预算 E_slip(t)≤E_max，越过 ρE_max（ρ<1）即早期减速/重抓。**禁止点估计抓取**：任何抓取判定必须使用带 β_g 的区间端点。

**P14 模块装配律（Modular Assembly, MK）**
每模块是七元组 μ=(I,O,κ,f,δ,Σ,meta)：类型化端口、v9 契约、计算映射、退化态射 δ(o)=o⊕v^⊥（幂等）、rely-guarantee 证书接口、元数据。系统是类型化装配图 G=(V,E,ρ,γ)；合法装配要求每条绑定的端口兼容（单位/量程/速率/容差/新鲜度）且每个环含至少一个延迟寄存器（v9 的 CVC 闭环正是一个延迟环）。

**P15 组合证书闭合律（Assume-Guarantee Closure, AGC）**
组合安全不是「所有模块都安全」的合取，而是「每模块在邻居保证下安全 + 邻居确实提供该保证」的闭包。绑定 i→j 要求 G_i ⇒ R_j；依赖图在去掉延迟边后须无环，或存在良基秩 r:V→ℕ（R_m 只依赖秩更小者的 G）。闭合通过才签发系统配置证书。

## 3. 与基线的接口（如何退化）

- GC 失效（无力/触觉或证书超差）⇒ γ̂_grasp 退回 v9 布尔阈值 + 保守限速，等价 v9 抓取语义；
- HSC 失效 ⇒ 配置冻结、禁止热插拔，等价 v9 静态部署；
- AGC 失效 ⇒ 放弃 rely-guarantee 组合，回退 v9 的手工集成与全局重证；
- MK 失效 ⇒ 固定单体装配，等价 v9 硬接线；
- AC 失效 ⇒ K_eff ← 1，逐步执行，等价 v9 Level-1；
- MW 失效 ⇒ 切换 v8 手写网关，等价 v9 Level-2；
- ID 失效 ⇒ 全模块 active，等价 v9 Level-3；
- v8 的 DA/SPR/Cal 任一失效 ⇒ 中立元注入，等价 v7；
- 全部失效 ⇒ 完整退回 v6。

## 4. 预期贡献

1. **抓取证书**：把抓取从布尔升级为相依赖区间证书，配滑移能量预算与重抓取中止点，使接触层失败可被块级安全框架吸收；
2. **模块装配代数**：七元组模块 + 类型化装配图 + 模块库，把"加模块=改全局证明"变为"装配一次、按接口证书闭合"；
3. **组合证书**：rely-guarantee 闭合条件与良基秩，明确"何时逐模块证书能推出系统级不变量"，并给出反例条件；
4. **热插拔不变量**：quiescence + 证书迁移 + 回滚，使运行期替换模块不产生不变式空洞；
5. **夹爪模块接口**：机械/电气/语义三层标准，使平行夹爪、吸附、灵巧手可带各自抓取证书热插拔；E571–E590 覆盖上述全部主张。

## 5. 本轮最大风险

**一句话**：抓取证书与模块组合证书都建立在「接口契约能覆盖耦合」的假设上，而接触力恰恰是穿透所有接口的隐性共享状态——各模块证书皆真时，组合仍可能因未建模的接触耦合（滑移改变物体位姿 → 抓取位姿证书、SLAM 风险与下一步重抓同时失真）而失效；即「证书是局部的，而接触是全局的」。

**新增定义 540（类型化端口 TypedPort）** 端口 τ=(name,unit,[lo,hi],rate,tol,fresh)，分别表示单位、量程、更新速率、容差与最大新鲜度。绑定 b: μ_i.out→μ_j.in 合法（记 τ_out⊑τ_in）当且仅当：
```
units_convertible(unit_out, unit_in)
∧ [lo_out,hi_out] ⊆ [lo_in,hi_in] ∧ rate_out ≥ rate_in
∧ tol_out ≤ tol_in ∧ fresh_out ≤ fresh_in
```
`⊑` 是预序而非全序；仅当两侧可换算到同一基准单位时才比较量程。该定义把"接线能跑"从运行期崩溃前移为部署期类型错误。

**新增定义 541（模块七元组 Module）** μ=(I,O,κ,f,δ,Σ,meta)：
- I,O：输入/输出类型化端口集；
- κ：v9 定义 535 的契约（截止期、WCET、中立元、优先级、蒸馏资格）；
- f：纯计算映射（不得直接读写其他模块内部状态）；
- δ:O→O 为退化态射，δ(o)=o⊕v^⊥，要求 **幂等** δ∘δ=δ、**保持中立元** δ(v^⊥)=v^⊥，且 δ(o) 落在 v9 退化格点内（引理 91 的可组合版本）；
- Σ=(R_m,G_m,S_m) 为 rely-guarantee 证书接口；
- meta=(version,priority,resource,provenance) 用于装配、审计与配置版本化。
"纯计算 + 端口"是模块化能成立的前提：跨模块共享状态必须显式化为端口或延迟边，否则组合证书无对象可谈。

**新增定义 542（类型化装配图 Configuration）** G=(V,E,ρ,γ)：V⊆模块集，E⊆{(μ_i.out, μ_j.in, d?)}，ρ∈V 为根，γ 为系统安全规范。**良型（well-typed）** ⇔ 每条绑定满足定义 540，且每个有向环至少含一条延迟边 d（单位延迟寄存器）。v9 的 CVC 闭环是带延迟的反馈环，故不违反无环直觉；延迟边的语义是 `x(t)=y(t−1)`。⟦G⟧ 定义为在延迟边处插入单位延迟后的同步组合。

**新增定义 543（Rely-Guarantee 证书与闭合）** 每模块声明 Σ_m=(R_m,G_m,S_m)：R_m 是对输入与环境（含接触扰动）的假设，G_m 是对输出（含共享可观测）的承诺，S_m 是内部不变量。对绑定 i→j 要求 **G_i ⇒ R_j**。令依赖图 D 有边 m→n 当 R_m 提及 G_n；**闭合条件**为 D 去掉延迟边后无环，或存在良基秩 r 使每条非延迟依赖 n→m 满足 r(n)<r(m)。闭合是组合证书可签发（定义 547）的充分条件；不闭合时只能做运行时监控（降级到 Level-3）。

**新增定义 544（抓取证书 GraspCertificate）** 由接触力/触觉/位姿估计构造：
```
q_FC   = min_{‖w‖=1} max_{f∈FC} w^T G_c f          # 力闭合余量，>0 即闭合
s_slip = min_i (μ_s f_{n,i} − ‖f_{t,i}‖)/f_{n,i}   # 归一化摩擦余量
c_cont = Σ_i area(patch_i)                          # 有效接触量
e_pose = ‖log(T_obj^{-1} T_grasp_target)‖           # 抓取位姿误差
```
考虑传感器/模型误差界 β_g，证书取保守区间 q_lo=q̂_FC−β_g，s_lo=ŝ_slip−β_g，e_hi=ê_pose+β_g。相 φ 内证书成立 ⇔
```
q_lo ≥ q_min(φ) ∧ s_lo ≥ s_min(φ) ∧ c_cont ≥ c_min(φ) ∧ e_hi ≤ e_max(φ)
```
阈值随相收紧（例：APPROACH 宽、CLOSE/LIFT 最严、RELEASE 最松）。**抓取判定只允许使用区间端点，禁止点估计**——这是 v9 布尔 γ̂_grasp 的严格加强。

**新增定义 545（滑移能量预算 SlipEnergyBudget）**
```
E_slip(t) = ∫_{t0}^{t} max(0, f_t(τ) − μ_s f_n(τ)) · ‖v_t(τ)‖ dτ
```
其中 f_t、f_n、v_t 为切向力、法向力、切向相对速度。搬运期要求 E_slip(t) ≤ E_max；越过 ρE_max（默认 ρ=0.8）即触发早期减速或重抓，而非等力锥真正破裂。E_slip 在成功重抓并重新签发抓取证书后清零；未重抓前单调不减，故"预警—重抓"存在有限触发时界。

**新增定义 546（抓取相机与重抓取中止点 GraspPhaseFSM）** φ_g∈{APPROACH, PRE_GRASP, CLOSE, LIFT, TRANSPORT, RELEASE}。相迁移由定义 544 的相判据 + 几何就绪谓词守卫；搬运期额外守卫 E_slip<ρE_max。重抓取中止点集
```
P_t^g = { p ∈ P_t : (可安全停驻) ∨ (存在从第 p 步末可执行的重抓取位姿) }
```
中块滑移告警时取 p*_g=max{p∈P_t^g : p≤k_exec}；P_t^g 为空则退回 v9 的安全停驻（引理 88）。与 v9 的中止点集 P_t 是包含关系，故不扩大不可退区域。

**新增定义 547（装配证书 ConfigurationCertificate）** 对良型装配图 G，若 (i) ∀m∈V，Σ_m 在其 R_m 下成立；(ii) ∀(i→j)∈E，G_i⇒R_j；(iii) 定义 543 的闭合条件成立，则签发
```
Cert(G) = ( ⋀_{m∈V} S_m , ⋀_{m∈V} G_m , r 的秩见证 )
```
并记 ⟦G⟧⊨γ。配置证书是可吊销的：任一绑定失效、成员版本变更或秩见证失效即吊销，触发 Level-3/Level-4 退化。证书只承诺到接口可观测层，不承诺模块内部实现——这是模块化的边界，也是最大风险所在。

**新增定义 548（热插拔协议 HotSwap）** 替换 Swap(μ_old→μ_new) 分六步：
1. **quiescence**：等到块边界并确认 μ_old 无在途输出；若 200ms 内未到边界，`deadline_guard` 强制注入 δ_old；
2. **中立注入**：δ_old 将 μ_old 输出置 v^⊥（等价 v9 退化级，引理 83）；
3. **接口检查**：新端口满足定义 540，证书模式版本兼容；
4. **证书迁移**：邻居 G ⇒ R_new，且 S_new 在共享可观测上不弱于 S_old（S_old⇒S_new）；
5. **重签发**：用定义 547 重签配置证书；失败则回滚；
6. **提交**：激活 μ_new，旧模块进入 frozen（保留回滚路径）。
替换窗口内系统行为始终 ∈ v9 退化格点（引理 90）；延迟上界 = 一个块周期（≤200ms）+ 装配检查（≤20ms）。

**新增定义 549（夹爪模块接口 GripperModuleInterface）** 三层接口：
- 机械层 M_g=(payload, aperture, DOF, compliance, max_tip_force)；
- 电气层 E_g=(bus, power, control_rate, feedback_rate)；
- 语义层 S_g=(sensing_channels, Ĝ_schema, slip_model_params, π_g)。
**证书投影** π_g：若缺少触觉/六维力，则用更大的 β_g、更低的 q_min/s_min 与限速 v_g 生成保守证书；若连力估计都没有，则 GC 退化为 v9 布尔阈值。该接口使平行夹爪、真空吸附、灵巧手成为**可热插拔的同类模块**——换夹爪不是换硬件，而是换一个带自证语义的模块。

**定义 493（六层指标层级）** 继承 v9：M=(M₀,M₁,M₂,M₃,M_dom,M_SLAM) 不变；抓取证书作为 M₀ 的接触层子证书接入，不新增顶层，避免破坏层级语义。

**定义 521（DA-OTL）** 继承 v9 不变；τᵢ(t) 的块级替代逻辑不变。
**升级定义 533（块证书，v10）** Ĉ_t=(ĝ_min, ê_max, Ĝ_t, Ê_slip^pred)：
```
块有效 ⇔ ĝ_min≥d_safe ∧ ê_max≤τ_eff ∧ (Ĝ_t 在整个 K 内相判据成立) ∧ Ê_slip^pred≤ρE_max
```

class Port:

            and inp.lo <= out.lo and out.hi <= inp.hi

class GraspCertifier:
    def __init__(self, beta_g=0.02, E_max=1.0, rho=0.8, gmi=None):
        self.beta_g, self.E_max, self.rho = beta_g, E_max, rho
        self.gmi = gmi                    # 定义 549：夹爪语义接口（可缺省）
        self.E_slip = 0.0
        if gmi is not None:               # 证书投影：无触觉则放大 β_g、限速
            self.beta_g = gmi.projected_beta(beta_g)
            self.v_cap = gmi.speed_cap
        else:
            self.v_cap = None

    def certify(self, obs, phase) -> GraspCert:
        q = force_closure_margin(obs.contacts)          # 标准力闭合余量
        s = friction_margin(obs.fn, obs.ft, obs.mu_s)   # 归一化摩擦锥余量
        c = obs.contact_area
        e = pose_error(obs.T_obj, obs.T_grasp)
        return GraspCert(q_lo=q - self.beta_g, s_lo=s - self.beta_g,
                         c=c, e_hi=e + self.beta_g)

    def phase_valid(self, g: GraspCert, phase) -> bool:
        th = PHASE_TH[phase]
        return (g.q_lo >= th['q'] and g.s_lo >= th['s']
                and g.c >= th['c'] and g.e_hi <= th['e'])

    def update_slip(self, obs, dt) -> float:            # 定义 545
        excess = max(0.0, obs.ft - obs.mu_s * obs.fn)
        self.E_slip += excess * abs(obs.vt) * dt
        return self.E_slip

    def re_grasp_abort(self, chunk, k_exec, obs):
        if self.E_slip < self.rho * self.E_max:
            return None
        pts = [p for p in chunk.re_grasp_points if p <= k_exec]   # 定义 546
        return max(pts) if pts else chunk.safe_stop_point(k_exec)


# ---------- IP-360 HotSwapController：热插拔协议 ----------
def hot_swap(old: Module, new: Module, graph, ctx) -> bool:
    wait_next_chunk_boundary(max_ms=200)               # (1) quiescence
    inject_neutral(old)                                # (2) δ_old，引理 83
    if not all_bindings_compatible(new, graph, ctx):   # (3) 类型检查
        activate(old); return False
    if not cert_migration_ok(old, new, graph, ctx):    # (4) G_neighbors⇒R_new
        activate(old); return False
    cert = assemble(modules_of(graph, replacing=old, by=new),
                    bindings_of(graph), spec_of(graph), delay_of(graph))
    if not cert:                                       # (5) 重签发失败
        activate(old); return False                    #     回滚
    activate(new); return True                         # (6) commit

## 4. 推导

**引理 87（抓取证书保守性）** 设每个认证量的估计误差有界：|q̂−q|≤β_g、|ŝ−s|≤β_g、|ê−e|≤β_g。若定义 544 的相判据在保守端点上成立（q_lo≥q_min, s_lo≥s_min, c≥c_min, e_hi≤e_max），则真实量满足 q≥q_min、s≥s_min、c≥c_min、e≤e_max。证明：由 q≥q̂−β_g=q_lo 及单调性直接得；s、e 同理。于是相内准静态摩擦模型下摩擦力始终留有正余量 s>0，不会进入持续滑移。∎

**引理 88（抓取-块联合安全）** 在 v9 引理 82 的块证书可靠性与引理 87 的抓取证书保守性下，若块起点相判据成立，且在执行到任一几何中止点前 E_slip(t)<ρE_max，则物体要么以正摩擦余量保持到块末，要么在 E_slip 达到 E_max 之前触发重抓取或 v9 安全停驻。证明：若真实滑移出现，则 f_t−μ_s f_n>0 且 ‖v_t‖>0，E_slip 严格增；E_slip<ρE_max 保证尚有可测预算，越过 ρE_max 的时刻可被定义 545 的积分监控在有限步内检出（步长 Δt，最小超载与速度给出发应时界）。检出后定义 546 选 p*_g≤k_exec；若 P_t^g 为空，退回 v9 引理 82 的安全停驻。两条路径都先于 E_max 耗尽，故不静默跌落。∎

**引理 89（装配证书可靠性 / Assume-Guarantee Soundness）** 若 (i) G 良型；(ii) 每模块在 R_m 成立时满足 (G_m,S_m)；(iii) 每条绑定 G_i⇒R_j；(iv) 依赖图去延迟边后无环或存在良基秩 r，则 ⟦G⟧ 满足 ⋀_m S_m 与 γ。证明：对 r 归纳（延迟边另行对离散时间归纳）。最小秩模块的 R_m 只提及环境与延迟输入，由 (ii) 与其 G 得 S_m；对模块 m，其每个非延迟前驱 n 有 r(n)<r(m)，由归纳假设 G_n 同时刻成立，结合 (iii) 得 R_m，再由 (ii) 得 G_m,S_m。延迟边 x(t)=y(t−1) 在时间归纳的基例由初始状态证书给出，归纳步由上一时刻的 G 给出。所有模块合取得 ⋀S_m；γ 由接口可观测投影得。∎

**引理 90（热插拔不变量）** 定义 548 的 Swap 在替换窗口内保持配置不变量：步骤 (1)(2) 将旧模块输出置为 v^⊥，由 v9 引理 83 该行为等价于 v9 退化级，故 quiescence 期行为 ∈ v9 退化格点；步骤 (3)(4) 保证新模块端口与证书兼容，步骤 (5) 重签后由引理 89 恢复系统不变量；任一步失败回滚到 δ_old，故不变量从不跌破 v9。延迟上界：quiescence≤一个块周期（≤200ms）+ 装配检查（≤20ms）；若 200ms 内未达块边界，deadline_guard 在 200ms 处强制注入 v^⊥ 并执行替换，故有硬上界。∎

**引理 91（v10 退化链严格等价）** 对退化链九级逐项：GC 失效 ⇒ 抓取判定退化为 v9 布尔 γ̂_grasp + 限速，而 v9 块证书正是用该布尔，故逐位等价 v9；HSC 失效 ⇒ 配置冻结，等价 v9 静态部署；AGC 失效 ⇒ 放弃 RG 合取、回到 v9 手工集成与全局重证，行为集 = v9；MK 失效 ⇒ 固定单体装配，等价 v9 硬接线；GMI 缺省 ⇒ 定义 549 的证书投影退化为更大 β_g 的保守证书，完全无传感时退化为 v9 布尔；其余 AC/MW/ID/DA/SPR/Cal 按 v9 引理 83 继续退化。因此 v10 任一新增失效 ⇒ 精确退回 v9，全失效 ⇒ v6。∎

**引理 92（组合证书不可组合的反例边界）** 存在良型装配图 G 与逐模块证书均成立、但绑定级 G_i⇒R_j 不成立的实例，使 ⟦G⟧ 违反 γ。构造：抓取模块承诺"位姿误差≤e_max 当物体静止"，规划模块假设"物体位姿不被接触改变"；单模块各自成立，但滑移使物体位姿改变，规划模块的 R 被违反而 G_i 未覆盖该情况。故组合证书必须显式包含接触引起的共享状态变化，不能只做端口类型匹配。∎

## 8. 本轮最大风险

**一句话**：抓取证书与模块组合证书都建立在「接口契约能覆盖耦合」的假设上，而接触力恰恰是穿透所有接口的隐性共享状态——各模块证书皆真时，组合仍可能因未建模的接触耦合（滑移改变物体位姿 → 抓取位姿证书、SLAM 风险与下一步重抓同时失真）而失效；即「证书是局部的，而接触是全局的」。
