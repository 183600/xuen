# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配不确定性二分闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「动作分块」×「技术路线图」）

> R69 让系统学会了「问」，但它对两个时间尺度都还很天真：
> 1. **动作尺度**：动作块长度 H 是固定的，且被当成不可分的整体承诺——要么整块执行、要么整块丢弃。可真实世界的信息不是均匀到达的：块的前 3 步也许有充分证据，后 12 步只是外推。把整块都执行，等于把「还能改主意」的权利一次性花光；把整块都丢弃，则永远停在第一步，抖动、复合误差、算力全回来了。
> 2. **能力尺度**：只要模块通过一次证书，就默认它此后一直可信。可 R68/R69 的证书是**状态证书**，不是**版本证书**；它回答「这一轮安不安全」，不回答「这个新模块该不该上线、上线后多久该回滚」。
>
> 两个灵感正好各补一个尺度：
> - **动作分块**告诉我们，承诺长度本身是一个可优化的决策变量（chunk length / commitment horizon / replanning gate / temporal ensembling），而且跨块拼接有独立的安全性——跨模态平均会把两条都可行的走廊平均成中间那堵墙；
> - **技术路线图**告诉我们，能力演进需要里程碑、依赖、就绪等级（TRL/RRL）、门控（go/no-go）与回滚，而不是「一次认证，永久信任」。
>
> 核心命题：**把「承诺」提升为一等公民，并在两个时间尺度上用同一套数学处理它——动作尺度上选择「承诺多长」（自适应分块 + 可信前缀 + 同模态拼接），能力尺度上选择「承诺哪个版本」（就绪等级 + 晋升门控 + 回滚）。两者共享同一骨架：在不确定下选择承诺长度，用里程碑门控决定前进/保持/回滚。** 命名 **ROAD-RAS**（Roadmap-gated Adaptive-Duration chunked commitment）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我承诺到哪一步为止、以及我凭什么相信自己已经到了这一步**」——不确定性不只是刹车和提问，也可以是「只走一半就停下来看」。

## 0. 直觉与动机

**灵感 1（动作分块 → 承诺长度是被 R69 浪费掉的自由度）**
直觉：R69 的流策略一次生成 H 步的块，但闭环里 `k` 只是「认证前缀」，与不确定性无关。于是出现两种坏情况：块很长而证据很短，系统被迫执行未验证的尾巴；块很短而任务很长，系统每步重采样，抖动和复合误差像没分块一样。人的做法是「走到有把握的边界就停」——不是每步都犹豫，也不是闭眼走完。把「承诺前缀长度 k_c」显式化，它同时由三件事约束：安全认证前缀 k_wm、不确定性可信前缀 k_u、以及重规划成本的折中最优 k*。分块从「固定 H 的一次性承诺」变成「长度自适应的滚动承诺」。

**灵感 2（分块 → 跨块拼接是一个独立的失败模式）**
直觉：一旦滚动重规划，就有重叠块如何拼接的问题。ACT 式 temporal ensembling 对单峰动作很有效，但在 R69 的多模态策略上会出事：两个块分别落在「绕左」和「绕右」两个模态，对它们做加权平均，得到的不是第三个合法模态，而是**两条走廊中间那堵墙**。分块不是免费的：它把「选错模态」从一次性错误，变成逐块拼接时的连续性错误与非法插值。因此拼接必须同模态、C¹ 连续、模态切换要显式门控，绝不能跨模态平均。

**灵感 3（路线图 → 证书是状态的，不是版本的）**
直觉：R68/R69 的 J_CALM/J_FLUID 是**运行时健康证**：它证明「这一轮观测下的动作在包络内」，但不证明「这个新版本比其他版本更值得上线」。技术路线图的核心不是「现在好不好」，而是「下一步敢不敢走、走错了退得回来吗」。于是需要一个**版本维度的证据链**：就绪等级、晋升门控、影子/灰度测试、回滚时间上界。证书回答「安不安全」，路线图回答「该不该发布」。

**灵感 4（两个尺度同构 → 一个骨架，两个实例）**
直觉：动作分块与能力路线图在数学上是同一件事——都是在不确定下选择「承诺长度」：太长则失去反应性，太短则失去连贯性；都需要一个门控决定「继续 / 中断 / 回退」。动作尺度：chunk ↔ commitment horizon ↔ replanning gate ↔ mode switch；能力尺度：版本 ↔ readiness level ↔ promotion gate ↔ rollback。把它们写成同一个 option/semi-MDP 语言，就能共用终止函数、共用证据纪律、共用审计。这正好回应 R69 的告诫——新层不能是并列的又一个黑箱。

**灵感 5（路线图是双刃剑 → 自我认证与路线图债务）**
直觉：门控的证据由系统自己产生（影子测试、证书、审计日志），这就有 Goodhart 风险：模块可以「考自己出的题」。更隐蔽的是**技术债务的路线图版**——为了上线把证据缺口记成「以后补」，缺口随服役时间累积成「路线图债务」。债务越大，就绪等级越名不副实；而一旦出事再回滚，回滚本身也需要证据（旧版本还在吗、状态可迁移吗）。所以本轮必须同时交付：晋升的反事实论证、证书 TTL（过期即降级）、债务预算、以及「回滚可用性」作为晋升的必要条件。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（ROAD-RAS 总览）** ROAD-RAS = (FLUID-RAS, ADC, CCH, MCS, CRG, RML, RGP, RRB, CGR, RRA)。四不变式：
(i) **实时只读**：继承 R68 定义 276-i，并扩展为「实时环内不做任何晋升或回滚写操作」；
(ii) **承诺单调**：surprise 只能缩短承诺前缀，不得在无新证据时延长；
(iii) **同模态拼接**：跨块拼接必须同模态且 C¹ 连续；模态切换需显式门控与重新认证；禁止跨模态平均；
(iv) **分级晋升**：不得跳级，任一级失败即停在当前级；回滚路径必须预先验证可用。

**定义 311（可变长动作块 / 选项）** 动作块 C = (ξ_{t:t+H}, m, k_c)，其中 ξ 为 R69 定义 294 的增广动作，m 为模态身份，H 为规划长度，承诺前缀 k_c ∈ [1,H] 为「在下次重规划前不可撤销执行的步数」；后缀 (k_c,H] 为「已规划但可修订」。三元组 (ξ,m,k_c) 构成一个 option（semi-MDP），终止函数见定义 314。

**定义 312（块可信前缀 CCH）** 沿块逐步累积不确定性 u_i = U_ale^{(i)} + γ·U_epi_res^{(i)}（R69 定义 297，γ 为未消解惩罚），并定义不可逆度 I(k) = (1/ε_recov)·max_{i≤k} risk(ξ_i) + η·(k/H)。则
k_u = max{ k ≤ H : Σ_{i≤k} u_i ≤ κ(k) ∧ I(k) ≤ 1 }，
k_c = min(H, k*, k_u, k_wm)，其中 k* 为定义 319 的折中最优，k_wm 为 C-RAS-WM 认证前缀。κ(k) 随 k 递增（越靠后可用的修正机会越多），故 k_u 不是简单平均，而是「可挽救预算」。

**定义 313（同模态拼接 MCS）** 相邻块 C=(ξ,m,k_c)、C'=(ξ',m',k'_c) 的重叠区为 [t_o,t_o+ℓ)。若 m=m'，拼接 ξ_new 为在模态 m 内、满足边界一阶导一致（C¹）的最小曲率插值；若 m≠m'，允许两种动作：(a) 维持旧块并触发 R69 交互（VoI>成本时）；(b) 显式模态切换事件，需 mode_conf≥τ_switch 且切换后前缀重新认证。**禁止** ξ_new = (1−α)ξ + αξ' 形式的跨模态凸组合。定义拼接不连续度 D_s = ‖ξ̇_new(t_o) − ξ̇_old(t_o)‖。

**定义 314（重规划门控 CRG）** 选项终止函数 β(z_t, progress, surprise, r_res) = 1 当且仅当任一条件成立：progress ≥ k_c；surprise(Δa) > τ_fma；r_res > τ_res；mode_changed(z_t,m)；安全触发。β=1 时终止当前承诺、重新规划；否则继续执行已承诺前缀。

**定义 315（就绪等级 RML）** 每个能力模块 M 有就绪等级 RRL(M) ∈ {R0 shadow（只记录不执行）, R1 canary（低风险子集/影子执行）, R2 gated（受门控默认关闭，条件启用）, R3 default（默认启用）}。等级是**证据函数**而非配置项：RRL = max{ l : E_l(M) ⊨ G_l }，E_l 为该级要求的证据集。

**定义 316（晋升门控 RGP）** 从 l 晋升到 l+1 当且仅当：证书有效且未过期（TTL）；影子/灰度不一致率 ≤ δ_l（置信上界）；对抗集（含 ℰ_ROAD）通过率 ≥ π_l；回滚在 τ_rb 内可验证完成；新增路线图债务不越预算。晋升须附**反事实安全论证**：「若新模块错误，旧模块仍能在 τ_rb 内接管且不变式不破」。

**定义 317（回滚 RRB）** 回滚 = 预加载旧版本检查点 + 原子版本指针切换 + 证书链与审计哈希保留。触发集：实时 surprise 持续越界、债务超限、证书过期、审计发现证据缺陷。回滚有硬上界 τ_rb，且不得破坏 R68 换装不变式（定理 15）。

**定义 318（承诺-就绪耦合 CGR）** 模块允许的最大规划/承诺长度受就绪等级约束：H_max(M) = H_0·ρ^{(R3−RRL(M))}，ρ<1；即越不成熟的模块，越不允许做长承诺。这把「模块可信度」直接翻译成「动作承诺长度」，避免用未验证模块去做长时程开环。

**定义 319（承诺长度折中）** 设重规划抖动代价 ∝ a/k，陈旧承诺代价 ∝ b·k（b 由漂移率与信息到达率决定），则期望代价 J(k)=a/k+b·k，最优 k* = √(a/b)。k* 与 k_u、k_wm 取 min 得 k_c，实现「该长则长、证据不足则短」。

**定义 320（路线图债务）** RD(M) = Σ_gap (证据缺口严重度 × 服役时间 × 暴露度)，按模块与等级加权。债务预算 RD(M) ≤ D_max；超限即触发降级或回滚。债务是「先上线后补证据」的显式价格，使就绪等级不至于是空头支票。

**定义 321（路线图审计 RRA）** 审计对象：晋升反事实是否成立、证据来源与新鲜度、证书 TTL、比分是否被污染、回滚演练是否真做过、债务是否如实记账。结论回灌 AuditBuf，成为下一轮晋升的先验。

**定义 322（AIC-ROAD 干扰集）** ℰ_ROAD = ℰ_FLUID × ℰ_chunk × ℰ_roadmap；
ℰ_chunk = 拼接攻击（在块边界注入跳变）、时长操纵（诱导过短/过长承诺）、边界利用（专挑块尾失效）、模态切换欺骗；
ℰ_roadmap = 晋升证据投毒（伪造影子测试）、过期证书重放、影子模式规避（识别出影子期则表现良好）、灰度污染（canary 集合被攻击者控制）。

**定义 323（证书 J_ROAD）** J_ROAD = (J_FLUID, k_c, H, D_s_p95, RRL, promotion_hash, rollback_ready, RD, cert_ttl)。Valid ⇔ Valid(J_FLUID) ∧ D_s_p95 ≤ τ_s ∧ k_c ≤ min(k_u,k_wm) ∧ RRL 与证据一致 ∧ 证书未过期。

**定义 324（分级晋升的检出复合）** 设第 l 级对有害回归的检出概率为 p_l，各级条件独立，则 L 级串联的漏检概率为 ∏_{l=1}^L (1−p_l)；配合回滚成功率 p_r，有害版本在 τ_rb 后仍活跃的概率上界为 ∏(1−p_l) + (1−p_r)。分级门控的价值即「把一次检测变成多次独立检测」。

**定义 325（承诺安全包络）** 已承诺前缀的风险上界 R(k_c) ≤ ε_int；重规划只在 β=1 时发生且只缩短承诺，故任意时刻实际执行轨迹都是某个已认证 plan 的前缀 ⇒ 安全包络不被承诺长度放大。

**定义 326（ROAD 严格包含 FLUID）** 当 H 固定、k_c=H、CRG 恒不终止、所有模块 R3、关闭晋升/回滚时，ROAD-RAS 逐指令退化为 FLUID-RAS。故 FLUID 是 ROAD 在「固定承诺 + 全模块成熟」边界上的特例；安全侧不弱于 FLUID。

## 2. 关键算法骨架

```python
# IP-264 ADC：自适应时长分块（承诺长度是一等决策变量）
class AdaptiveChunkPolicy:
    def __init__(self, trunk, fmp, duration_head, cch, wm):
        self.trunk, self.fmp = trunk, fmp            # 复用 R69 FMP（流匹配多模态）
        self.duration_head, self.cch, self.wm = duration_head, cch, wm

    def plan(self, o_t, H_max):
        z = self.trunk(o_t)
        H = min(H_max, int(self.duration_head(z)))   # 规划长度档位（非承诺）
        samples = self.fmp.sample(o_t, K=self.K(z))
        modes = cluster_trajectories(samples)
        m = select_mode(modes, lam=1.0)              # 先取最可能模态
        k_u = self.cch.credibility_horizon(modes, m, z, H)
        k_wm = self.wm.certified_prefix(m.a[:H])
        k_star = int(sqrt(a_jitter / b_stale))       # 定义 319 折中
        k_c = max(1, min(H, k_star, k_u, k_wm))      # 只承诺证据支撑的前缀
        return Chunk(xi=m.a[:H], mode=m, k_commit=k_c, H=H)

# IP-265 CCH：可信前缀 = 可挽救预算 + 不可逆度
def credibility_horizon(modes, m, z, H):
    k_u = 0
    for k in range(1, H + 1):
        u  = sum(u_ale(m, i) + GAMMA * u_epi_res(m, i, z) for i in range(1, k + 1))
        ir = irreversibility(m, k)                       # 消耗的ε_recov 比例
        if u <= kappa(k) and ir <= 1.0:
            k_u = k                                       # 单调：可继续则继续
        else:
            break
    return k_u

# IP-266 MCS：同模态拼接；跨模态禁止平均
def stitch(prev, new):
    if prev.mode.id == new.mode.id:
        return c1_min_curvature_merge(prev.xi, new.xi, boundary='derivative')
    if mode_conf(new) > TAU_SWITCH and certified_switch(prev.mode, new.mode):
        return explicit_mode_switch(prev, new)            # 记切换事件，重认证前缀
    return prev                                           # 保守：维持旧块，触发 R69 交互
    # 绝不返回 (prev.xi + new.xi) / 2：跨模态平均可能落到非流形/障碍内

# IP-267 CRG：选项终止函数（何时中断承诺）
def should_replan(chunk, z_t, progress, surprise, r_res):
    return (progress >= chunk.k_commit
            or surprise > TAU_FMA
            or r_res > TAU_RES
            or mode_changed(z_t, chunk.mode)
            or not safety_ok(z_t))

# IP-268/269/270 RML+RGP+RRB：离线路线图 tick（实时环不写）
def roadmap_tick(M, evidence_buf):
    for mod in M.modules:
        if stale_certificate(mod) or roadmap_debt(mod) > D_MAX:
            M.rrb.rollback(mod, reason='stale/debt')      # 先降级，后补证据
            continue
        if ready_evidence(mod) and gate(mod, mod.rrl + 1, evidence_buf):
            M.rgp.promote(mod, mod.rrl + 1)               # 逐级晋升，不跳级

def gate(module, level, evidence):
    return (valid_certificate(module, level) and not expired(module)
            and shadow_disagreement(module) <= DELTA[level]
            and adversarial_pass(module, E_ROAD) >= PASS[level]
            and rollback_verified(module) <= TAU_RB
            and roadmap_debt(module) + new_debt(level) <= D_MAX)

# IP-275 主闭环：FLUID 的风险缩放 + ROAD 的承诺调度
def ROAD_RAS_round(M, obs):
    H_max = M.cgr.h_max_of(M.fmp.rrl)                     # 定义 318：未成熟模块不许长承诺
    chunk = M.adc.plan(obs, H_max)
    exec_prefix(chunk.xi[:chunk.k_commit],
                lam=M.fluid.lam, cert=M.j_road)           # R69 两级保守退避照旧
    if M.crg.should_replan(chunk, obs, progress, M.surprise, M.last_r_res):
        new = M.adc.plan(obs, H_max)
        chunk = M.mcs.stitch(chunk, new)                  # 同模态 C¹，或显式切换
    M.rra.log(chunk, M.fmp.rrl, M.j_road)                 # 只读审计，离线晋升
    return chunk
```

## 3. 推导

**引理 19（承诺长度折中）** 设单位任务长度内重规划抖动代价为 a/k、陈旧承诺代价为 b·k（b>0 反映漂移率与信息到达率），则期望代价 J(k)=a/k+b·k 在 k*=√(a/b) 处最小，且 J(k*) = 2√(ab)。系：**信息到达越快、漂移越大（b↑），越应短承诺；重采样越贵/越抖（a↑），越应长承诺**——固定 H 只在 a/b 恰好恒定于该场景时最优，故自适应分块严格优于固定分块。

**引理 20（跨模态平均不安全）** 设模态 m₁、m₂ 的原型 ξ₁、ξ₂ 都满足安全约束集 𝒮（𝒮 非凸，如两条绕障走廊），则存在 α∈(0,1) 使 ξ̄=(1−α)ξ₁+αξ₂ ∉ 𝒮；且当流形非凸时，ξ̄ 的策略密度低于两端模态。故 temporal ensembling 式平均在多模态策略上可能同时「违反约束」与「落在低密度区」；MCS 的同模态约束不是保守偏好，而是安全必要条件。

**引理 21（承诺安全）** 若 k_c ≤ k_wm 且 k_c 在执行前确定，surprise 只能触发 β=1 提前终止（缩短而非延长承诺），则实际执行轨迹是已认证 plan 的前缀；每次重规划重新认证 ⇒ 任意时刻风险 ≤ ε_int。承诺长度不放大安全包络（定义 325）。

**定理 18（ROAD 严格包含 FLUID）** 在 R69 的 A95–A98 与本轮 A99（分级检测条件独立）下，ROAD 任意状态期望风险 ≤ FLUID；当 k_c=H、CRG 恒不终止、全模块 R3 时两者逐指令相同（定义 326）。故 R69 是 ROAD 在「固定承诺 + 全成熟」边界上的退化：安全不让步，效率侧获得自适应承诺与版本纪律。

**定理 19（分级晋升安全上界）** 设 L 级晋升门控对有害回归的逐级检出概率为 p₁..p_L，回滚成功率 p_r、回滚时限 τ_rb；则有害版本在 τ_rb 后仍活跃的概率 ≤ ∏_{l=1}^L (1−p_l) + (1−p_r)。系：**多级门控把漏检概率做成乘积**——这是「路线图」相对「一次性证书」的定量收益；且 RD≤D_max 把「先上线后补证据」的暴露时间纳入同一上界。

## 6. 本轮最大风险

**一句话**：ROAD-RAS 把「还能改主意」的能力交给了两个**自证的估计器**——块可信前缀依赖 R69 的模态/不确定性估计，晋升门控依赖系统自己产出的影子测试与证书；一旦估值器**自信地错**，自适应分块会把一次本可在中途纠正的误判锁成一段不可撤销的轨迹，路线图再给这个错误版本盖上一枚「已就绪」的章，于是**分块把可纠正错误变成不可纠正轨迹，路线图把一次性错误变成制度化错误**——错误不再是偶然的，而是有证书、有版本、可复现的。

**次级风险与缓解**：
1. **跨模态平均**（撞进两条走廊中间）→ 定义 313 禁止凸组合 + 引理 20 + E303；
2. **承诺过长/过短被操纵** → CCH 双约束（不确定 + 不可逆）+ CRG 终止 + 承诺单调（定义 310-ii）；
3. **自我认证 Goodhart** → 证书 TTL + 债务预算 + 审计反事实 + 外部留出集（E307/E310）；
4. **回滚不可用** → 回滚演练作为晋升必要条件 + τ_rb 硬上界（定义 316–317、定理 19）；
5. **未成熟模块做长时程开环** → CGR 就绪-长度耦合（定义 318）+ E311，越不成熟承诺越短。

# IP-264 ADC：自适应时长分块
class AdaptiveChunkPolicy:
    def plan(self, o_t, H_max):
        z = self.trunk(o_t)
        H = min(H_max, int(self.duration_head(z)))          # 规划长度
        modes = cluster_trajectories(self.fmp.sample(o_t, K=self.K(z)))
        m = select_mode(modes, lam=1.0)
        k_u  = self.cch.credibility_horizon(modes, m, z, H)
        k_wm = self.wm.certified_prefix(m.a[:H])
        k_c  = max(1, min(H, int(sqrt(A_JITTER / B_STALE)), k_u, k_wm))
        return Chunk(xi=m.a[:H], mode=m, k_commit=k_c, H=H)

# IP-265 CCH：可信前缀 = 可挽救预算 + 不可逆度
def credibility_horizon(modes, m, z, H):
    k_u = 0
    for k in range(1, H + 1):
        u  = sum(u_ale(m, i) + GAMMA * u_epi_res(m, i, z) for i in range(1, k + 1))
        if u <= kappa(k) and irreversibility(m, k) <= 1.0: k_u = k
        else: break
    return k_u

# IP-266 MCS：同模态拼接；跨模态禁止平均
def stitch(prev, new):
    if prev.mode.id == new.mode.id:
        return c1_min_curvature_merge(prev.xi, new.xi, boundary='derivative')
    if mode_conf(new) > TAU_SWITCH and certified_switch(prev.mode, new.mode):
        return explicit_mode_switch(prev, new)              # 记事件、重认证前缀
    return prev                                             # 维持旧块，触发 R69 交互

# IP-267 CRG：选项终止函数
def should_replan(chunk, z_t, progress, surprise, r_res):
    return (progress >= chunk.k_commit or surprise > TAU_FMA or r_res > TAU_RES
            or mode_changed(z_t, chunk.mode) or not safety_ok(z_t))

# IP-268/269/270：路线图离线 tick（实时环只读）
def roadmap_tick(M, evidence_buf):
    for mod in M.modules:
        if stale_certificate(mod) or roadmap_debt(mod) > D_MAX:
            M.rrb.rollback(mod, reason='stale/debt'); continue
        if ready_evidence(mod) and gate(mod, mod.rrl + 1, evidence_buf):
            M.rgp.promote(mod, mod.rrl + 1)

def gate(module, level, evidence):
    return (valid_certificate(module, level) and not expired(module)
            and shadow_disagreement(module) <= DELTA[level]
            and adversarial_pass(module, E_ROAD) >= PASS[level]
            and rollback_verified(module) <= TAU_RB
            and roadmap_debt(module) + new_debt(level) <= D_MAX)

# IP-275 主闭环
def ROAD_RAS_round(M, obs):
    H_max = M.cgr.h_max_of(M.fmp.rrl)                       # 定义 318
    chunk = M.adc.plan(obs, H_max)
    exec_prefix(chunk.xi[:chunk.k_commit], lam=M.fluid.lam, cert=M.j_road)
    if M.crg.should_replan(chunk, obs, progress, M.surprise, M.last_r_res):
        chunk = M.mcs.stitch(chunk, M.adc.plan(obs, H_max))  # 同模态 C¹ / 显式切换
    M.rra.log(chunk, M.fmp.rrl, M.j_road)                    # 只读审计
    return chunk

## 4. 推导

**引理 19（承诺长度折中）** `J(k)=a/k+bk` ⇒ `k*=√(a/b)`，`J(k*)=2√(ab)`。信息到达快/漂移大（b↑）应短承诺；重采样贵/抖（a↑）应长承诺。固定 H 仅在 a/b 恒定场景最优，故自适应分块严格更优。

**引理 20（跨模态平均不安全）** 若两模态原型 ξ₁、ξ₂ 均满足非凸安全集 𝒮（两条绕障走廊），则存在 α 使 `ξ̄=(1−α)ξ₁+αξ₂∉𝒮`，且 ξ̄ 处于低密度区。故 temporal ensembling 式平均同时造成违规与似然塌陷；同模态约束是安全必要条件。

**引理 21（承诺安全）** `k_c≤k_wm`，surprise 只触发提前终止（缩短），则实执行轨迹恒为已认证 plan 前缀，风险 ≤ ε_int，承诺长度不放大安全包络。

**定理 18（ROAD 严格包含 FLUID）** A95–A99 下，ROAD 期望风险 ≤ FLUID；当 `k_c=H`、CRG 恒不终止、全模块 R3 时逐指令相同。R69 是 ROAD 的边界退化。

**定理 19（分级晋升安全上界）** 逐级检出 p_l、回滚成功 p_r、时限 τ_rb 下，有害版本 τ_rb 后仍活跃概率 ≤ `∏_{l=1}^L(1−p_l)+(1−p_r)`。多级门控把漏检做成乘积；债务预算 D_max 把「先上线后补证据」的暴露纳入同一上界。

**本轮在路线图中的位置**：M5 是第一次「工程化收敛」里程碑——把前四轮的**状态能力**转成**可发布、可回滚、可审计的版本能力**。交付顺序（deployment roadmap）：MCS（安全前置）→ CCH/CRG（效率）→ RML/RGP/RRB（发布纪律）→ CGR/RRA（耦合与审计）；每一级都遵循 R0 shadow → R1 canary → R2 gated → R3 default，未过门控不进入实时环。

**当前模块 RRL 建议**：sim 上 ADC/CCH/MCS 可先到 R2；CRG 到 R2；RML/RGP/RRB 属离线，R1；CGR 因直接改承诺长度，必须等 E302+E303 双达标才 R2。任何模块 `RD>D_max` 或 `cert_ttl` 过期即回退一级，优先于性能收益。

## 8. 本轮最大风险

**一句话**：ROAD-RAS 把「还能改主意」的能力交给两个自证的估计器——块可信前缀依赖 R69 的模态/不确定性估计，晋升门控依赖系统自己产出的影子测试与证书；一旦估值器**自信地错**，自适应分块会把一次本可中途纠正的误判锁成不可撤销的轨迹，路线图再为这个错误版本盖上「已就绪」的章，于是**分块把可纠正错误变成不可纠正轨迹，路线图把一次性错误变成制度化错误**。

**次级风险与缓解**：跨模态平均撞墙（定义 313 + 引理 20 + E303）；承诺时长被操纵（CCH 双约束 + CRG + 承诺单调）；自我认证 Goodhart（TTL + 债务预算 + 反事实审计 + 外部留出集）；回滚不可用（回滚演练作晋升必要条件 + τ_rb）；未成熟模块长时程开环（CGR 就绪-长度耦合 + E311）。
