# 第 55 轮（承接第 54 轮 v16++ GroundEdge-GenSim+++ / 产物 v31；新灵感循环第 2 轮；本轮灵感：「状态估计」×「模型预测控制」）

> 第 54 轮把技能组合提升为动作-鲁棒性双证书（ACS/SCOM/CEC/AEC/JTC）。但这套证书隐含两个未言明的假设：**状态是真值**、**证书是瞬时的**。本轮用 **状态估计** 与 **模型预测控制** 拆开这两个假设。核心矛盾：H22：鲁棒性谱 `ρ(d)` 默认在真值状态 `x` 上评估，而部署只有带不确定性的信念 `b=(x̂,Σ)`，估计误差是证书未建模的隐藏扰动通道，约束边界一旦穿过信任域，证书就在真值上悄悄失效；H23：证书是"当前时刻有效"的快照，而任务需要沿时间保持，MPC 的有限时域预测能给出前瞻证书，但模型失配与估计漂移会沿 horizon 累积，使证书"过期"。

## 0. 直觉与动机

**灵感 1（状态估计 → 证书必须条件化在信念上，而非真值上）**
直觉：机器人从不拥有真实状态，只拥有信念 `b_t=(x̂_t,Σ_t)`。一个在 `x̂` 上成立的鲁棒性证书，在真实状态 `x∈B_ε(x̂)` 上可能失效，尤其当约束边界穿过信任域时。因此把证书改写为 **估计条件化鲁棒性** `ρ(d|b)=inf_{x∈B_ε(x̂)} ρ(d|x)`：证书不再是"点"的性质，而是"信任域最坏情况"的性质。估计误差从此成为与动作、扰动并列的第一类不确定性来源。

**灵感 2（可观测性 → 鲁棒性的"可知性"边界）**
直觉：不是所有方向的鲁棒性都能被估计出来。若某状态方向的可观测性 Gramian `O_t` 特征值太小，`Σ` 在该方向被拉长，信任域退化为细长椭球，最坏情况鲁棒性崩塌。于是引入 **可观测性缺口 `O-gap`**：任务若要求在该方向上动作，则无论控制器多强，证书都不可声明。这把"能不能估准"从精度指标升级为部署前的硬否决项。

**灵感 3（MPC → 证书的时间维度与"证书 horizon"）**
直觉：MPC 用滚动时域预测把当前控制与未来约束连起来。把同样思想搬到证书上：沿预测时域 `τ=0..H` 传播信念，得到 **预测鲁棒性序列** `ρ_τ(d|b_τ)`，其下确界给出前瞻证书；超过某个 **证书 horizon `H_cert`** 后预测不再可信，证书作废。证书从"瞬时快照"变成"时空带"，并带一个 **衰减率 `λ_cert`** 指示需要多频繁地重估/重规划。

**灵感 4（Tube MPC → 递归可行性作为自维持证书）**
直觉：普通证书是"检查一次"；Tube MPC 的扰动不变管 `Z` 与终端不变集 `X_f` 让可行性在时间上自我保持：若 `t` 时刻可行且 `w∈W`，则 `t+1` 仍可行。于是 **递归可行性盾 RFS** 把证书从"一次性证明"变成"闭环维持"：每一步都预测下一步是否仍在证书集内，若将越界则提前否决并 fallback。这是 MPC 对证书体系最本质的贡献——证书可以被"控制"着不失效。

**灵感 5（估计-预测对偶 → 四路归因与时空联合证书）**
直觉：估计看过去（可观测性），MPC 看未来（可控性），二者是对偶。失败时到底怪谁？用 **信念条件化解释 BCE** 做四路归因：估计误差（NEES 超限）/模型失配（预测残差大）/动作不可行（`a∉α_S`）/扰动越界（`w∉W`）。归因结果经第 54 轮反向解释信道回传云端，决定是改估计器、改模型、还是改动作剖面。最终形成 **时空联合证书 STC**：同时携带空间（动作/信任域）与时间（horizon/衰减）两个维度。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（信念与信任域）**
信念 `b_t=(x̂_t,Σ_t)`，信任域 `B_ε(x̂_t)={x | (x-x̂_t)^T Σ_t^{-1}(x-x̂_t) ≤ ε²}`。估计器 **一致** 当且仅当 `E[NEES_t]=n` 且 `P(x_t∉B_ε(x̂_t)) ≤ δ_est`，其中 `NEES_t=(x_t-x̂_t)^T Σ_t^{-1}(x_t-x̂_t)`。可观测性 Gramian `O_t`，方向 `v` 上的估计底噪 `ε_floor(v)=ε·sqrt(v^T Σ_t v)`。

**定义 122（估计条件化鲁棒性与可观测性缺口）**
估计条件化鲁棒性 `ρ(d|b) = inf_{x∈B_ε(x̂)} ρ(d|x)`。证书 `Cert(d,b)` 成立当且仅当 `ρ(d|b) ≥ ρ_min(d)`。
**可观测性缺口** `O-gap(b)={v | λ_min(O_t,v)<λ_obs}`；若任务所需动作方向 `A_T` 与 `O-gap` 相交，则 `Cert=⊥`（不可声明，而非低置信）。

**定义 123（预测鲁棒性与证书 horizon）**
预测模型 `f̂`，扰动集 `W`，信念传播 `b_{τ+1}=propagate(b_τ,u_τ,W)`。预测鲁棒性 `ρ_H(d|b)=min_{0≤τ≤H} ρ(d|b_τ)`。**证书 horizon** `H_cert(b)=max{H | ρ_H(d|b)≥ρ_min(d) ∀d}`，**证书衰减率** `λ_cert = -d/dτ log ρ_τ(d|b)|_{τ=H_cert}`。

**定义 124（递归可行性与证书保持）**
终端集 `X_f` 控制不变，管 `Z` 扰动不变，约束按 `Z` 收紧。若 `b_0` 可行且 `w_t∈W`，则 `b_{t+1}` 可行。**证书保持**：`Cert(b_t) ∧ RFS(b_t)=ok ⇒ Cert(b_{t+1})`，即证书由闭环而非单次检查维持。

**定义 125（时空联合证书）**
`J_st = (ρ(d|b), Σ, ε, H_cert, λ_cert, Z, O-gap, A_cert, γ_ce, evidence)`。可部署条件：
```
ρ(d|b) ≥ ρ_min(d) ∀d  ∧  H_cert ≥ H_task  ∧  O-gap(b) ∩ A_T = ∅  ∧  δ_a < Θ_a
```
其中 `A_cert,γ_ce,δ_a` 承接第 54 轮动作层，`ρ` 承接第 53 轮鲁棒性层。

**定义 126（信念条件化解释 BCE）**
`BCE(failure) → r ∈ {estimation_error, model_mismatch, action_infeasible, disturbance_ood, unknown}`，按 `NEES`、预测残差、`a∉α_S`、`w∉W` 依次判定，并输出反事实证据（"若真值=x 则本可成功"）。四路互斥，作为反向解释信道的归因载荷。

## 2. 关键算法 伪代码

### IP-121 SEB（State-Estimation-aware Bound）

```python
def belief_certificate(skill, belief, dims, eps, lambda_obs):
    xhat, Sigma = belief
    B = trust_region_samples(xhat, Sigma, eps)          # 椭球边界采样
    rho_b = {d: min(robustness(skill, x, d) for x in B) for d in dims}
    O = observability_gramian(skill, belief)
    o_gap = [v for v in eigvecs(O) if eigval(O, v) < lambda_obs]
    if any(required_direction(v, dims) for v in o_gap):
        return ('reject', 'observability_gap', o_gap)
    return ('ok', BeliefCert(rho_b, B, o_gap, Sigma))
```

### IP-122 MPC-Cert（Model-Predictive Certificate）

```python
def mpc_certificate(skill, belief, model, H, W, rho_min, eps):
    b, rho_min_h, H_cert = belief, float('inf'), 0
    for tau in range(H):
        b = propagate_belief(b, model, W)
        c = belief_certificate(skill, b, dims, eps, lambda_obs)
        if c.status != 'ok' or min(c.rho.values()) < rho_min:
            break
        rho_min_h = min(rho_min_h, min(c.rho.values()))
        H_cert = tau + 1
    lam = decay_rate(rho_min_h, H_cert)
    return MPCert(rho_min_h, H_cert, lam, tube=Z)
```

### IP-123 RFS（Recursive Feasibility Shield）

```python
def recursive_feasibility_shield(belief, plan, model, W, Xf, rho_min):
    if not feasible(belief, plan, Xf):
        return ('fallback', safe_stop(belief))
    b_next = propagate_belief(belief, model, W)
    c = belief_certificate(plan.skill, b_next, dims, eps, lambda_obs)
    if c.status != 'ok' or min(c.rho.values()) < rho_min:
        return ('veto', 'certificate_would_violate', b_next, c)
    return ('ok', plan)
```

### IP-124 OPC（Observability-Predictability Coupling）

```python
def estimation_prediction_coupling(K, belief, model, H):
    K_se = {}
    for (d1, d2), k in K.items():
        K_se[(d1, d2)] = k * obs_weight(d1, belief) * pred_weight(d2, model, H)
    return K_se
```

### IP-125 BCE（Belief-Conditioned Explanation）

```python
def belief_conditioned_explain(failure, belief, model, W):
    if nees(failure, belief) > chi2_thresh:        return 'estimation_error'
    if prediction_residual(failure, model) > r:    return 'model_mismatch'
    if failure.action not in failure.skill.alpha:  return 'action_infeasible'
    if failure.disturbance not in W:               return 'disturbance_ood'
    return 'unknown'
```

### IP-126 STC（Spatio-Temporal Certificate）

```python
def spatio_temporal_certificate(skill_seq, belief, model, H_task, W):
    J = joint_certificate(skill_seq, gamma_ce, delta_a_budget, rho_min)  # 第54轮
    if J.status != 'ok':
        return ('reject', 'action_layer', J)
    mc = mpc_certificate(skill_seq[0], belief, model, H_task, W, rho_min, eps)
    if mc.H_cert < H_task:
        return ('reject', 'horizon_short', mc.H_cert)
    return ('ok', STC(J, mc, BCE_channel=True))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| SEB | O(|B|·|𝔇| + n²) | O(|B|+|𝔇|) | 信任域采样覆盖 ≥ 95%、NEES 一致 |
| MPC-Cert | O(H·|B|·|𝔇|) | O(H·|B|) | 传播误差有界、horizon 截断 |
| RFS | O(|B|·|𝔇|) 每步 | O(|B|) | 递归可行性、盾无漏检 |
| OPC | O(|K|) | O(|K|) | 权重单调、耦合非负 |
| BCE | O(1) | O(1) | 四路互斥、证据可追溯 |
| STC | O(H·|B|·|𝔇| + |S|·|A|) | O(H·|B|+|A|) | 空间-时间预算闭合 |

**正确性定理（Belief-Time Certificate Soundness）**
假设 (A22)–(A28) 承接第 54 轮；**(A29)** 估计器一致，`P(x_t∉B_ε(x̂_t))≤δ_est` 且 NEES 检验通过；**(A30)** 预测误差在 `H_cert` 内满足 `||x_true(τ)-x̂_pred(τ)||≤Δ_pred(τ)`，且 `Δ_pred(H_cert)≤Δ_max`；**(A31)** `w_t∈W` 有界；**(A32)** RFS 在控制周期 `τ_ctrl` 内完成检查。则：
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a)
              - δ_est - P(Δ_pred(H_cert)>Δ_max) - P(RFS miss)
```
关键：**信任域包含真值**、**预测误差在 horizon 内有界**、**递归可行性由盾维持**。任一项破缺都会使证书从"保守"退化为"乐观"。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 估计器过度自信、`Σ` 虚假收缩 | 高 | NEES 在线监测 + 协方差膨胀 + 红队状态扰动 |
| MPC 模型失配沿 horizon 累积 | 高 | 证书 horizon 截断 + 在线模型校准 + 残差监控 |
| RFS 频繁触发导致任务停滞 | 中 | 分层 fallback + 保守恢复策略 + 死锁检测 |
| 可观测性缺口误判 | 中 | 多传感器融合 + 主动感知 + 缺口回退 |
| 时空证书计算开销 | 中 | 增量信念传播 + 边缘加速 + 采样缓存 |
| 估计-预测归因混淆 | 高 | 受控消融 + 反事实仿真 + 证据交叉验证 |

## 6. 本轮最大风险

**一句话**：状态估计与 MPC 把证书从静态空间扩展到信念-时间维度，但其 soundness **双重依赖估计器一致性（`Σ` 不收缩到虚假自信）与预测模型在证书 horizon 内的误差有界**；一旦估计器过度自信或模型失配沿 horizon 累积，信任域将不包含真值、预测证书将系统性乐观，递归可行性盾反而会在错误信念上"安全地"驶向不可恢复区，故必须以 **NEES 在线监测 + 协方差膨胀 + 证书 horizon 截断 + 保守 fallback** 四重护栏，宁可频繁重估，绝不把"自以为知道的状态"当作真值。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（SEB×MPC-Cert×RFS×OPC×BCE×STC）

> 承接第 54 轮产物 v31。本轮在动作-鲁棒性双证书体系之上，加入 **状态估计条件化、模型预测证书、递归可行性盾** 三大算子：
> - **SEB（State-Estimation-aware Bound）**：把鲁棒性证书条件化到信念信任域 `B_ε(x̂)`，并否决可观测性缺口方向；
> - **MPC-Cert（Model-Predictive Certificate）**：沿预测时域给出前瞻证书、证书 horizon `H_cert` 与衰减率 `λ_cert`；
> - **RFS（Recursive Feasibility Shield）**：用递归可行性在闭环中自维持证书；
> - **OPC（Observability-Predictability Coupling）**：把第 53 轮耦合矩阵 `K` 扩展为估计-预测耦合 `K_se`；
> - **BCE（Belief-Conditioned Explanation）**：失败四路归因，接入第 54 轮反向解释信道；
> - **STC（Spatio-Temporal Certificate）**：空间（动作/信任域）× 时间（horizon/衰减）联合证书。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-115/117/118/120 以纳入信念与时间维度。

```python
    mc = mpc_certificate(skill_seq[0], belief, model, H_task, W, rho_min, eps)
    if mc.H_cert < H_task:
        return ('reject', 'horizon_short', mc.H_cert)
    return ('ok', STC(J, mc, BCE_channel=True))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SEB | O(|B|·|𝔇| + n²) | O(|B|+|𝔇|) | 信任域采样覆盖 ≥ 95%、NEES 一致 |
| MPC-Cert | O(H·|B|·|𝔇|) | O(H·|B|) | 传播误差有界、horizon 截断 |
| RFS | O(|B|·|𝔇|) 每步 | O(|B|) | 递归可行性、盾无漏检 |
| OPC | O(|K|) | O(|K|) | 权重单调、耦合非负 |
| BCE | O(1) | O(1) | 四路互斥、证据可追溯 |
| STC | O(H·|B|·|𝔇| + |S|·|A|) | O(H·|B|+|A|) | 空间-时间预算闭合 |

**正确性定理（Belief-Time Certificate Soundness）**
假设第 54 轮 (A22)–(A28) 成立；**(A29)** 估计器一致，`P(x_t∉B_ε(x̂_t))≤δ_est` 且 NEES 检验通过；**(A30)** 预测误差在 `H_cert` 内满足 `||x_true(τ)-x̂_pred(τ)||≤Δ_pred(τ)`，且 `Δ_pred(H_cert)≤Δ_max`；**(A31)** `w_t∈W` 有界；**(A32)** RFS 在控制周期 `τ_ctrl` 内完成检查。则部署成功概率：
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a)
              - δ_est - P(Δ_pred(H_cert)>Δ_max) - P(RFS miss)
```
关键：**信任域包含真值**、**预测误差在 horizon 内有界**、**递归可行性由盾维持**。任一项破缺，证书都会从"保守"退化为"乐观"。

## 5. 本轮最大风险

**一句话**：状态估计与 MPC 把证书从静态空间扩展到信念-时间维度，但其 soundness **双重依赖估计器一致性（`Σ` 不收缩到虚假自信）与预测模型在证书 horizon 内的误差有界**；一旦估计器过度自信或模型失配沿 horizon 累积，信任域将不包含真值、预测证书将系统性乐观，递归可行性盾反而会在错误信念上"安全地"驶向不可恢复区，故必须以 **NEES 在线监测 + 协方差膨胀 + 证书 horizon 截断 + 保守 fallback** 四重护栏，宁可频繁重估，绝不把"自以为知道的状态"当作真值。
