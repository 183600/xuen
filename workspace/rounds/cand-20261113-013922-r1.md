# 第 63 轮（承接第 62 轮「ROSE 鲁棒在线场景进化闭环」IP-183~192；灵感循环 II 第 2 轮；本轮灵感：「激光雷达」×「通用操作」×「抗干扰」）

> 第 62 轮构建了 ROSE：OLP 带遗憾界的在线投影、WCV+RSC 偏差驱动的 CVaR 球兜底、SBR+SHC 遗憾驱动的场景银行、Shield 对话安全屏蔽、OCB 对抗老虎机预算。但第 62 轮自述的最大风险暴露了**三个感知-几何-执行层面的根基性短板**：
> 1. **USR/MEL 缺乏 3D 几何先验**：语义表征 x 仅融合视觉 V、触觉 T、本体 P、语言 L，缺失**稠密 3D 点云几何**——接触面法向、曲率、空间拓扑对阻抗编译（EEIS/MSPF）与物理推断（MEL）至关重要，若无 LiDAR 级几何，WCV 球心 φ̂ 与半径 r 的初始化均受限于「盲人摸象」。
> 2. **动作空间仍是「原子阻抗」而非「通用技能」**：DMS/ERTC 直接输出 K_safe 与约束 c，未抽象出**可组合、可迁移、带前后置条件的技能原语**（reach, grasp, push, insert, hand-over 等）——「通用操作」要求策略在技能层面推理与组合，而非在阻抗参数层面拟合。
> 3. **抗干扰仅止于「参数不确定球」**：RSC/WCV 只处理物理参数 φ 的系统性偏差（A72），未覆盖**传感器噪声（LiDAR 杂波/多径）、执行器扰动（关节摩擦突变/电流尖峰）、对抗性感知攻击（遮挡/欺骗点云）、分布外几何（新物体拓扑）**——第 62 轮的 ρ_rob 在这些扰动下可能虚高，证书 J_rose 失效。

## 0. 直觉与动机

**灵感 1（激光雷达 → LSF：LiDAR-Semantic Fusion 稠密几何语义融合）**
直觉：第 61/62 轮的 USR 统一语义表征 x ∈ ℝ^256 只融合 RGB+触觉+本体+语言。**关键缺口**：稠密 3D 几何（点云/深度/法向/曲率/接触面拓扑）是阻抗编译与物理推断的「几何先验」。LiDAR 点云 P_cloud 经体素化/下采样 → 几何编码器 E_geo → 几何嵌入 g ∈ ℝ^d_g，再通过**跨模态注意力**与现有 USR 分支融合：x' = CrossAttn([x; g])。几何嵌入 g 同时喂入 MEL 作为 φ̂ 的几何正则项（接触面法向约束摩擦锥、曲率约束刚度上界），喂入 WCV 作为球心 φ̂ 的几何初始化——**几何不再是事后解释，而是先验约束**。

**灵感 2（通用操作 → USL：Universal Skill Library 通用技能库 + CSP 技能组合规划）**
直觉：第 62 轮 DMS→Shield→ERTC 仍在「阻抗参数/约束」层面操作。**关键洞见**：把「操作」提升为**带前后置条件的技能原语**库 USL = {σ_i}，每技能 σ = (name, pre: ℒ_pre, eff: ℒ_eff, π_σ: 𝒳→𝒦×𝒞, cost, 𝒫_feas)。DMS/RL 不再直接输出 K/c，而是输出**技能序列** τ = [σ_1, ..., σ_H] 与参数绑定 θ_i；CSP (Constraint Satisfaction Planning) 在 USL 上搜索可行序列，再由 ERTC 逐技能展开为阻抗轨迹——「通用操作」被形式化为**技能层面的组合规划 + 参数层面的鲁棒展开**，技能库可跨任务迁移、跨本体复用。

**灵感 3（抗干扰 → DIR：Disturbance-Invariant Representation 干扰不变表征 + AIC 抗干扰认证器）**
直觉：第 62 轮的鲁棒性仅针对「物理参数 φ 的不确定球」（A72）。**关键补全**：显式建模**四类干扰**并学习不变表征：① 传感器噪声 η_sens（LiDAR 杂波、RGB 光照突变）；② 执行器扰动 η_act（关节摩擦突变、电流尖峰、通讯延迟抖动）；③ 对抗感知 η_adv（遮挡、欺骗点云、纹理攻击）；④ 几何分布外 η_ood（新物体拓扑、未见材质）。**DIR 目标**：学习编码器 E_dir 使得 Z = E_dir(O) 对干扰类不变——I(Z; η | task) ≈ 0，同时保持任务相关信息 I(Z; task) 最大。实现：多源对比学习（干扰增强视图 vs 干净视图）+ 因果干预正则（do(η) 不改变 Z 的任务预测头输出）。**AIC 认证器**：对组合技能 τ，计算最坏干扰下的鲁棒裕度 ρ_dir = min_{η∈ℰ} margin(τ, η)，其中 ℰ 为干扰集（由 DIR 校准的经验分布支撑），输出证书 J_dir 并入 J_rose。

**灵感 4（三灵感合流 → LIRO：LiDAR-Invariant Robust Operations 闭环）**
三者咬合：LSF 提供**几何先验**修正 φ̂_0 与 r_0（WCV 球更紧、更准）；USL 提供**技能抽象**使 DMS/RL 在语义层面规划、ERTC 在参数层面鲁棒展开；DIR+AIC 提供**干扰免疫**保证 ρ_dir 覆盖传感/执行/对抗/分布外四类扰动。闭环：LiDAR 几何 → LSF 融合 → USR/MEL 更准 → WCV 球更小 → 技能参数更激进 → USL 组合成功率↑；执行残差 + 干扰标注 → DIR 在线对比更新 → AIC 重新认证 → J_rose 扩展 ρ_dir。**第 62 轮 ROSE 是「参数层面的在线鲁棒进化」，LIRO 是「几何-技能-干扰三层联合的通用鲁棒操作闭环」**。

**灵感 5（ROSE 组件的原位升级）**
- **OLP → OLP-Geo**：投影头输入扩为 x' = CrossAttn([x; g])，h(x') 含几何特征，遗憾界 G̃ 增加 L_g·‖g‖ 项但几何先验使 ℓ̃_t 更平滑、收敛更快。
- **WCV → WCV-Geo**：球心 φ̂_0 由几何推断初始化（接触面法向→摩擦锥、曲率→刚度先验），半径 r_0 几何感知收缩；CVaR 优化在几何约束下搜索最坏 φ。
- **SBR → SSB (Spatial Scenario Bank)**：场景签名增入**点云指纹** fp_cloud = SimHash(体素化法向直方图)，Mine/Mut 在几何空间变异（拓扑扰动、局部形变、接触面翻转）。
- **Shield → Shield-Skill**：约束投影升级为**技能前置条件投影**——RL 提案的技能参数 θ 先过 pre-condition 投影再入 CSP，再由 ERTC 展开。
- **OCB → OCB-Skill**：臂空间扩为 {USL 技能模式} × {MEL 模式} × {对齐开关}，EXP3 在技能粒度上调度预算。

- **定义 188（CSP 技能组合规划）**：给定目标 G（由 DMS 意图解析），搜索 τ = [σ_1, ..., σ_H] 使得 pre_σ1 当前满足、eff_σi ⊨ pre_σ{i+1}、eff_σH ⊨ G、Σ cost ≤ budget、∀i π_σi ∈ 𝒫_feas(φ̂, r)。求解器：层级 A* + 技能级松弛（将 pre/eff 软化为代价），实时路径仅展开首技能 π_σ1。
- **定义 189（DIR 干扰不变表征）**：E_dir: 𝒪 → ℤ，ℤ = ℤ_task ⊕ ℤ_nuisance。对比损失 ℒ_con = -log exp(sim(z_i, z_i^+)/τ) / Σ_j exp(sim(z_i, z_j)/τ)，正样本 z_i^+ = E_dir(aug_dir(O_i))（干扰增强：LiDAR dropout/噪声注入/遮挡/对抗扰动），负样本为其他 batch 样本。因果正则 ℒ_causal = ‖∂ŷ/∂η‖²（η 为干扰参数，ŷ 为任务预测头输出）。总损失 ℒ_dir = ℒ_con + λ_causal·ℒ_causal；语义流低频更新，实时路径仅前向。
- **定义 190（AIC 抗干扰认证器）**：干扰集 ℰ = {η: ‖η‖_∞ ≤ ε_sens} × {η: ‖η‖_∞ ≤ ε_act} × AdvBall(ε_adv) × OODBall(ε_ood)；四类半径由 DIR 校准的经验分布分位数给出。ρ_dir(τ) = min_{η∈ℰ} min_{t∈[0,H]} margin(π_σt(·; η), φ̂, r)；采样近似 n_cert=64。J_dir = (ρ_dir, ℰ_spec, cert_hash)。
- **定义 191（SSB 空间场景银行）**：扩展 SBR：scene_sig = (V_sig, T_sig, fp_cloud, φ_sig, dyn_annot)；fp_cloud = SimHash(voxel_normal_hist(P_cloud, 32³))。Mine 优先匹配 fp_cloud；Mut 增加几何变异 {拓扑扰动(欧拉特征数±1), 局部形变(自由形式变形 FFD), 接触面翻转(法向反向)}。

## 2. 关键算法骨架（完整伪代码见产物区）

```python
# LSF：LiDAR 几何编码 + 跨模态融合
g = E_geo(voxelize(P_cloud));  x' = CrossAttn(x, g, g)
# USL + CSP：技能库检索 + 组合规划（语义流）
τ, θ_bind = csp_plan(USL, goal, x', φ̂, r)  # 仅语义流
# 实时流：仅展开首技能
K_seq = π_σ1(x', θ_bind[0]);  K_safe, ρ_rob = wcv_geo_compile(K_seq, φ̂, r)
# DIR：干扰不变表征（语义流对比更新）
z = E_dir(O);  ℒ_dir = contrastive(z, Aug_dir(O)) + λ_causal·‖∂ŷ/∂η‖²
# AIC：抗干扰认证
ρ_dir = min_{η∈ℰ} margin(τ, η);  J_liro = (J_rose, ρ_dir, ...)
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 3（几何先验收缩球半径）**：设 GeoInit 使 ‖φ* − φ̂_0‖ ≤ δ_geo < δ_bias（纯 MEL 估计偏差），则 RSC 稳态 r_∞ ≤ δ_geo + o(1) < δ_bias + o(1)——**几何先验直接压缩 WCV 球，鲁棒裕度 ρ_rob 同步增大**。
- **引理 4（DIR 不变性界）**：若 ℒ_causal 使 ‖∂ŷ/∂η‖ ≤ ε_causal 且对比损失使 I(Z_nuisance; η) ≤ ε_info，则对任意 η∈ℰ，任务预测漂移 ‖ŷ(O+η) − ŷ(O)‖ ≤ L_ŷ·(ε_causal + √ε_info)——**干扰对任务头的影响被显式压缩**。
- **定理 2（技能层面鲁棒遗憾界）**：将 OLP-Geo 的参数 W 视为技能参数 θ 的线性化修正，CSP 选择的技能序列 τ 在 USL 上诱导损失 ℓ̃_t^skill(θ)。因 USL 覆盖任务相关子空间（A81），有效维度 d_eff ≪ d_us，遗憾界改进为 **R_T^skill ≤ D_skill·G̃_skill·√T**，其中 G̃_skill ≤ G̃_geo / √κ（κ 为技能抽象压缩比）。
- **定理 3（AIC 认证有效性）**：若 ℰ 由 DIR 校准分位数覆盖 P[η* ∈ ℰ] ≥ 1−α_dir，且 margin 单调，则 ρ_dir ≥ 0 ⇒ 对真实干扰 η* 技能序列安全概率 ≥ 1−α_dir——**四类干扰被统一认证框架覆盖**。
- **实时性**：实时路径新增仅 LSF 前向（<0.2ms）、DIR 前向（<0.1ms）、π_σ1 展开（<0.3ms），总计 ≤ 1ms 契约内（A75 继承）。

## 2. 形式化定义（完整版）

**定义 201（GLIDE 闭环）** GLIDE 是 LIRO 的「深度相机几何 × 步态-操作联合 × 低成本全链路」升级：在第 63 轮「语义流 ∘ 实时流」骨架上，**替换** LSF→DGF、DIR→DIR-Depth、AIC→AIC-Depth、SSB→SSB-Depth、WCV-Geo→WCV-Depth、OLP-Geo→OLP-Depth、Shield-Skill→Shield-Mixed、OCB-Skill→OCB-Mixed，**新增** GL、USL-Mixed、CSP-Mixed、LCA。不变式：**核心接口（x', g, τ, θ, φ̂, r, J）完全兼容**，仅内核替换与参数扩展；**全部学习/规划/认证只发生在语义流与低频线程；实时路径（1–10kHz）只做 DGF/DIR-Depth 前向、OLP-Depth 前向 + Shrink、WCV-Depth 编译、π_σ1 全身展开派发**——几何/混合技能/干扰/成本四层在时序上隔离。

**定义 202（DGF 深度几何融合）** 输入：深度图 D、RGB 图 I、内参 K、外参 T_cw。管线：
1. **可微几何解析**：`N, K_curv, U = DiffGeometry(D, I, K)`——平面拟合（RANSAC 可微近似）或 TSDF 融合（稀疏体素），输出法向图、曲率图、不确定性图（U 基于视差一致性代价 + 纹理梯度 + 多路径检测置信度）。
2. **轻量 2.5D 编码器**：`E_geo^d = MobileNetV3_Small(输入通道=7: N×3 + K_curv + U + I_gray)`，骨干冻结（ImageNet 预训练 + 深度几何自监督掩码重建），双头输出 `g_mean ∈ ℝ^{128}`、`Σ_g_diag ∈ ℝ^{128}`（对角协方差，经 softplus 保证正定），**INT8 量化部署**。
3. **跨模态融合**：`x' = CrossAttn_QKV(x, g_mean, g_mean)`，同定义 186。
**实时前向 < 5ms (Orin Nano CPU / 树莓派 5 NEON)**。无 LiDAR 时 DGF 退化为零几何嵌入（g_mean=0, Σ_g=diag(σ_max²)），系统优雅降级为纯视触觉模式。

**定义 203（GL 步态原语库）** GL = {σ_gait_i}_{i=1}^{15}，核心步态：`{trot, pace, bound, gallop, walk, crawl, climb_stairs, step_over, dynamic_transition, turn_in_place, lateral_shift, diagonal, pronk, hop, fallback}`。每步态原语 σ_gait = (name, pre_gait, eff_gait, π_gait, cost, 𝒫_feas_gait)：
- `pre_gait(φ, x')`：一阶逻辑谓词，例 `pre_trot ≡ (v_cmd ∈ [0.2, 1.5]) ∧ (terrain_rough ≤ 0.05) ∧ (ZMP_margin ≥ 0.02) ∧ (base_height ∈ [0.25, 0.45]) ∧ (momentum_feasible)`；
- `eff_gait(φ, x')`：例 `eff_trot ≡ (base_vel ≈ v_cmd) ∧ (contact_pattern = trot) ∧ (momentum_bounded) ∧ (energy_rate ≤ E_max)`；
- `π_gait(x'; θ_gait)`：步态策略，轻量 MLP（2 层，隐藏 128），输入 x' 输出 `{足端关键帧 p_foot(t) ∈ ℝ^{4×3×M}, 基座阻抗 K_base(t) ∈ ℝ^{6×6×M}, 接触序列 C(t) ∈ {0,1}^{4×M}}`；θ_gait 可被 OLP-Depth 微调；
- `cost`：加权和（能耗/稳定性裕度/速度偏离/切换平滑度）；
- `𝒫_feas_gait(φ̂, r, Σ_g)`：鲁棒可行集，采样 φ∈B(φ̂,r) + 基座状态，验证全身动力学约束（动量守恒、ZMP、接触力锥、关节限位、自碰撞）。

**定义 204（USL-Mixed 混合技能库）** USL-Mixed = USL ∪ GL，N_total ≈ 65。统一接口 σ = (name, pre, eff, π_σ, cost, 𝒫_feas)。pre/eff 统一谓词语言：操作技能 pre 含接触力锥/摩擦锥/进近方向；步态技能 pre 含 ZMP/动量/接触序列/地形粗糙度。技能图节点全互联，边权含切换代价（操作↔步态切换代价 > 操作↔操作/步态↔步态）。

**定义 205（CSP-Mixed 混合技能组合规划）** 给定目标 G = (G_nav, G_manip)（导航目标 + 操作目标），搜索混合技能序列 τ = [σ_1, ..., σ_H] ⊂ USL-Mixed 与参数绑定 θ_bind：
- 硬约束：pre_σ1(x', φ̂, r, Σ_g) 成立；∀i < H, eff_σi ⊨ pre_σ{i+1}；eff_σH ⊨ G；
- **全身动力学一致性**：∀i, π_σi(·; θ_i) 满足 **快速近似检查**（< 1ms/技能）：
  - 质心动量投影：`h_com = J_com(q)·v`，期望动量变化 `Δh_des` 在可实现锥内；
  - ZMP 线性化：`zmp = p_com − (h_com/g)·v_com`，要求 `zmp ∈ support_polygon ⊕ margin`；
  - 接触力锥线性化：`f_contact ∈ friction_cone ⊕ regularization`；
  - 关节限位/速度/加速度限位；
- 软约束：Σ_i cost(σ_i, θ_i) + skill_switch_penalty·切换数 ≤ budget；
- 鲁棒可行：∀i, π_σi ∈ 𝒫_feas^mixed(φ̂, r, Σ_g)（定义 218）。
求解器：**层级 A* 在混合图上** —— 高层搜索技能序列（启发式 = 剩余导航距离/最大速度 + 操作子任务数），低层参数优化（L-BFGS，pre/eff/ZMP/动量/接触力锥软化为 hinge 代价）。**实时路径仅展开首混合技能 π_σ1**（并行输出足端轨迹 + 基座阻抗 + 臂阻抗），后续技能在后续语义流步重规划。

**定义 206（DIR-Depth 深度感知干扰不变表征）** 编码器 `E_dir^d: 𝒪^d → ℤ`，输入 `𝒪^d = (D, I, T, P, L)`，输出 `ℤ = ℤ_task ⊕ ℤ_nuisance`（各 64 维）。训练损失同定义 189，`Aug_dir^d` 在定义 199 基础上增加 6 类深度退化增强：
1. **视差量化噪声**：`D + QuantNoise(Δ_disp)`，Δ_disp 基于焦距/基线/深度量化公式；
2. **多路径伪影**：`D ⊕ MultipathGhost(ratio=0.1)`，在高反射率区域注入虚假深度峰值；
3. **运动模糊核**：`D * MotionBlurKernel(σ=2px)`，模拟高速运动下深度图模糊；
4. **遮挡深度洞**：`D ⊙ OcclusionMask(depth_hole_ratio=0.3)` + `GaussianFill(σ=0.5m)`；
5. **强光饱和**：`I ⊙ SaturationMask(ratio=0.2)` + `D ⊙ DepthDropout(ratio=0.4)`；
6. **透明/镜面深度缺失**：`D ⊙ TransparentMask(material_class)` + `GaussianFill(σ=0.5m)`。
对比损失 `ℒ_con^d`、因果正则 `ℒ_causal^d = ‖∂ŷ/∂η_depth‖²_F`（η_depth 含上述 6 类参数）。总损失 `ℒ_dir^d = ℒ_con^d + λ_causal·ℒ_causal^d`，λ_causal=1.0。**语义流每 10 步更新（batch=32），实时路径仅前向 < 0.1ms**。

**定义 207（AIC-Depth 深度感知抗干扰认证器）** 干扰集 `ℰ^d = ℰ × ℰ_depth`：
- `ℰ_depth = {η_depth: ‖η_depth‖_∞ ≤ ε_depth} ∪ {η_hole: hole_ratio ≤ ε_hole} ∪ {η_transparent: material ∈ 𝒞_transparent}`。
- ε_depth, ε_hole 由 DIR-Depth 经验分位数校准（95 分位数），𝒞_transparent 由视觉材质分类头给出。
- `ρ_dir^d(τ) = min_{η∈ℰ^d} min_{t=1..H} margin(π_σt(·; η), φ̂, r, Σ_g)`，采样近似 n_cert=64（ℰ 16 + ℰ_depth 48，深度退化权重更高）。
- **新增深度不确定性裕度项**：`depth_uncert_margin = min_t ‖∂margin/∂Σ_g‖_F · ‖Σ_g‖_F`，量化 Σ_g 对安全裕度的敏感度。
- `J_dir^d = (ρ_dir^d, ℰ^d_spec, cert_hash, depth_uncert_margin)`。

**定义 208（SSB-Depth 深度场景银行）** `scene_sig^d = (V_sig, T_sig, fp_cloud, depth_fp, φ_sig, dyn_annot)`：
- `depth_fp = SimHash(voxel_normal_hist(D) ⊕ hist(U, bins=16))`，法向直方图（32³×8）⊕ 不确定性直方图（16 bins），共 80 位指纹。
- `Mine(EV_exec, anchor)`：优先匹配 `depth_fp`（汉明距离 < 10）；若无匹配且有险情，创建新场景。
- `Mut(s)`：继承 SBR 变异 + **深度退化变异**：噪声注入（U 膨胀）、洞洞生成（depth_fp 局部翻转）、材质翻转（透明↔不透明）。

**定义 209（LCA 低成本适配器）** LCA = {mode_sensor, mode_compute, mode_calib} 三维编译期开关，**运行时零开销**：
- `mode_sensor ∈ {LiDAR, Stereo_Dual, Stereo_Quad, ToF_Single, ToF_Dual}` → 选择 DGF 管线参数（基线/焦距/帧率/曝光）、E_geo^d 输入通道数、Aug_dir^d 增强强度。
- `mode_compute ∈ {Server_GPU, Edge_NPU, Edge_CPU}` → 触发量化感知训练（FP32/INT8/INT4）、算子融合（Conv+BN+ReLU、MatMul+Add）、线程亲和（大核/小核分流）、流水线并行（语义流 4 线程：感知/规划/学习/认证）。
- `mode_calib ∈ {Factory, Self_Supervised}` → 自监督联合标定损失：`ℒ_calib = ‖D_proj(T) − D_obs‖² + ‖T_contact(P) − T_tactile‖² + ‖P_kin(q) − P_obs‖²`，无需标定板，开箱即用收敛 < 5min。
部署时一次性配置，**证书 J_glide 增加 `cost_tier` 字段标识档位**。

**定义 210（WCV-Depth 深度感知鲁棒编译）** 球心 `φ̂_0 = GeoInit(g_mean)`（定义 216）；初始半径 `r_0 = r_base·γ_geo(g_mean, Σ_g)`，`γ_geo = γ_base·(1 + α_uncert·‖Σ_g‖_F)`（α_uncert=0.5，经验校准）。几何约束集**软化为机会约束**：`𝒢_chance(g) = {φ: P[n(φ) ≈ n_cloud | g_mean, Σ_g] ≥ 1−δ_geo ∧ P[κ(φ) ≤ κ_max(g) | g_mean, Σ_g] ≥ 1−δ_geo}`，δ_geo=0.05。搜索域 `B(φ̂_0, r_0) ∩ 𝒢_chance`，采样验证概率约束（n_worst=8，每样本从 N(g_mean, Σ_g) 采样 10 次检查约束满足率）。输出 `K_safe, ρ_rob, geo_conflict_chance`。若机会约束冲突率 > 50%，回退硬约束 `𝒢(g_mean)` 并报警 `geo_conflict_chance=True`。

**定义 211（OLP-Depth 深度感知在线投影）** 投影头输入 `x'` 不变，但 `h: ℝ^{384} → ℝ^m` 增加不确定性随机特征维度（输入拼接 `vec(Σ_g_diag)`）。`K_W(x') = Π_0(x') + h(x')ᵀW`。梯度上界 `G̃_depth = G̃_geo + G·L_uncert·‖Σ_g‖_F`，其中 `L_uncert = sup ‖∂h/∂Σ_g‖`。在线更新同 OLP-Geo。

**定义 212（Shield-Mixed 混合技能前置条件屏蔽）** RL/CSP 提案的混合技能参数 θ：`θ* = argmin_{θ'∈Θ_pre^mixed} ‖θ'−θ‖₂`，其中 `Θ_pre^mixed = {θ: pre_σ(θ, φ̂, r) ∧ ZMP_in_polygon(θ) ∧ momentum_feasible(θ) ∧ contact_force_cone(θ)}`。ZMP/动量/接触力键谓词均可线性化为二次约束，投影为**小规模 SQP**（顺序二次规划，< 8ms，语义流侧）。若 `‖θ*−θ‖_∞ > δ_mixed`（δ_mixed=0.15），降级 `ask_clarify_mixed(σ, violated_preds)`。

**定义 213（OCB-Mixed 混合技能粒度预算老虎机）** 臂空间 = `{USL-Mixed模式} × {MEL模式} × {align} × {cost_tier}`：
- USL-Mixed模式 = `{full_seq, single_skill, gait_only, manipulation_only, mixed_parallel, cached_seq, frozen}`（7 种）；
- MEL模式 = `{full, distill, cached, frozen}`（4 种）；
- align = `{on, off}`（2 种）；
- cost_tier = `{high, mid, low}`（3 种）；
原始 168 臂，**聚合为 K=32**（按计算量/功耗聚类）。每语义步 EXP3 采样臂 a_t，奖励 `r_t = progress_t − κ·(compute_cost_t + power_cost_t + skill_switch_penalty·𝟙[σ_t ≠ σ_{t-1}])`，归一化 [0,1]。重要性加权更新。**硬降级规则**：EXP3 选择的臂不得突破当前 `cost_tier` 允许的最高模式（PCE+++++ 继承）。

```python
class DepthGeometryFusion:
    """深度图 + RGB → 可微几何解析 → 轻量 2.5D 编码器 → g=(g_mean, Σ_g) → CrossAttn 融合。实时前向 < 5ms。"""
    def __init__(self, d_us=256, d_g=128, d_out=384, mode_sensor='Stereo_Dual'):
        self.mode_sensor = mode_sensor
        self.diff_geo = DifferentiableGeometry(mode_sensor)   # 可微平面/TSDF + 不确定性
        self.E_geo = QuantizedMobileNetV3Small(in_ch=7, out_dim=d_g*2, quant_mode='INT8')  # 双头
        self.cross_attn = CrossAttention(d_us, d_g, d_out, heads=4)
        self.g_cache = None

    def update_geometry(self, D, I, K, T_cw):
        # 1. 可微几何解析
        N, K_curv, U = self.diff_geo(D, I, K)          # (H,W,3), (H,W), (H,W)
        # 2. 编码器输入拼接
        feat = torch.cat([N, K_curv.unsqueeze(-1), U.unsqueeze(-1), I.mean(-1, keepdim=True)], dim=-1)  # (H,W,7)
        feat = feat.permute(2,0,1).unsqueeze(0)         # (1,7,H,W)
        # 3. 编码器前向（冻结骨干，仅双头可微）
        g_mean, sigma_diag = self.E_geo(feat)           # (1,d_g), (1,d_g)
        sigma_diag = F.softplus(sigma_diag) + 1e-6      # 正定
        Sigma_g = torch.diag_embed(sigma_diag.squeeze(0))  # (d_g,d_g) 对角
        self.g_cache = (g_mean.squeeze(0), Sigma_g)

    def fuse(self, x):
        if self.g_cache is None:
            g_mean = torch.zeros(self.d_g, device=x.device)
            Sigma_g = torch.eye(self.d_g, device=x.device) * 1.0  # 最大不确定性
        else:
            g_mean, Sigma_g = self.g_cache
        x_prime = self.cross_attn(x.unsqueeze(0), g_mean.unsqueeze(0), g_mean.unsqueeze(0))
        return x_prime.squeeze(0), g_mean, Sigma_g
```

```python
class CSPMixedPlanner:
    """层级 A* 在混合图上 + 全身动力学一致性检查 + 参数优化。语义流 < 80ms。"""
    def __init__(self, mixed_lib: MixedSkillLibrary, max_horizon=6):
        self.lib, self.max_horizon = mixed_lib, max_horizon

    def plan(self, goal_nav, goal_manip, x_prime, phi_hat, r, Sigma_g, base_state, budget=150.0):
        goal = CompositeGoal(goal_nav, goal_manip)
        feasible = self.lib.get_feasible(phi_hat, r, Sigma_g, x_prime, base_state)
        # 高层 A* 搜索混合技能序列
        start = ('start', [], 0.0, base_state)
        open_set = [start]
        while open_set:
            curr, seq, cost, b_state = heapq.heappop(open_set)
            if goal.holds(seq, phi_hat, x_prime, b_state):
                theta_bind = self._optimize_params(seq, x_prime, phi_hat, r, Sigma_g, base_state)
                return seq, theta_bind
            if len(seq) >= self.max_horizon: continue
            for next_name in self.lib.skill_graph.successors(curr):
                next_skill = self.lib.skills[next_name]
                if next_skill not in feasible: continue
                edge_cost = self.lib.skill_graph[curr][next_name]['weight']
                new_cost = cost + next_skill.cost + edge_cost
                if new_cost > budget: continue
                # 快速动力学一致性检查
                if not self._quick_dynamics_check(next_skill, b_state, phi_hat, r, Sigma_g):
                    continue
                new_b_state = predict_base_state(b_state, next_skill, phi_hat)
                heapq.heappush(open_set, (next_name, seq + [next_skill], new_cost, new_b_state))
        return [self.lib.skills['safe_idle']], [None]

    def _quick_dynamics_check(self, skill, base_state, phi_hat, r, Sigma_g) -> bool:
        # < 1ms 快速检查：ZMP 线性化 + 动量锥 + 接触力锥线性化
        for _ in range(8):
            phi = sample_ball(phi_hat, r)
            b_s = sample_base_state(base_state, Sigma_g)
            if skill.is_gait:
                p_foot, K_base, C_seq = skill.policy(x_prime_dummy)
            else:
                p_foot, K_base, C_seq = base_state.nominal_gait, skill.policy(x_prime_dummy), base_state.C_seq
            if not zmp_in_polygon_linearized(p_foot, K_base, C_seq, phi, b_s): return False
            if not momentum_feasible(p_foot, K_base, C_seq, phi, b_s): return False
            if not contact_force_cone_linearized(p_foot, K_base, C_seq, phi): return False
        return True

    def _optimize_params(self, seq, x_prime, phi_hat, r, Sigma_g, base_state):
        def loss(theta_list):
            total = 0.0
            b_s = base_state
            for i, (skill, theta) in enumerate(zip(seq, theta_list)):
                if skill.is_gait:
                    p_foot, K_base, C_seq = skill(x_prime, theta)
                else:
                    K_seq, c_seq = skill(x_prime, theta)
                    p_foot, K_base, C_seq = b_s.nominal_gait, K_seq, c_seq
                total += skill.cost
                # 前置条件软约束
                if i == 0:
                    total += hinge(skill.pre.violation(phi_hat, x_prime, b_s))
                else:
                    total += hinge(seq[i-1].eff.violation(skill.pre, phi_hat, x_prime, b_s))
                # 后置条件软约束
                total += hinge(skill.eff.violation(phi_hat, x_prime, b_s))
                # 全身动力学软约束
                total += hinge(zmp_violation(p_foot, K_base, C_seq, phi_hat, b_s))
                total += hinge(momentum_violation(p_foot, K_base, C_seq, phi_hat, b_s))
                total += hinge(contact_force_violation(p_foot, K_base, C_seq, phi_hat))
                # 鲁棒裕度软约束
                total += hinge(-min_margin_mixed(p_foot, K_base, C_seq, phi_hat, r, Sigma_g))
                b_s = predict_base_state(b_s, skill, phi_hat)
            return total
        return lbfgs_optimize(loss, init=[s.default_theta for s in seq])
```

### IP-207 DIR-Depth（深度感知干扰不变表征）

```python
class DepthDisturbanceInvariantRepresentation:
    """E_dir^d: (D,I,T,P,L) → ℤ_task ⊕ ℤ_nuisance。深度退化增强 + 因果正则。"""
    def __init__(self, d_obs=512+640*480//4, d_z=128, tau=0.1, lambda_causal=1.0):
        self.encoder = QuantizedMLP(d_obs, [256, 256], d_z, quant_mode='INT8')
        self.head_task = QuantizedMLP(d_z//2, [64], 6, quant_mode='INT8')
        self.tau, self.lambda_causal = tau, lambda_causal
        self.aug = DepthDisturbanceAugmenter()

    def forward(self, O_depth):
        z = self.encoder(O_depth)
        return z[:d_z//2], z[d_z//2:]

    def contrastive_loss(self, batch_O):
        z_task = []; z_task_pos = []
        for O in batch_O:
            z_t, _ = self.forward(O)
            z_task.append(z_t)
            O_aug = self.aug(O)
            z_t_pos, _ = self.forward(O_aug)
            z_task_pos.append(z_t_pos)
        z_task = torch.stack(z_task); z_task_pos = torch.stack(z_task_pos)
        sim = torch.mm(z_task, z_task_pos.t()) / self.tau
        labels = torch.arange(len(batch_O), device=z_task.device)
        return F.cross_entropy(sim, labels)

    def causal_regularizer(self, batch_O):
        reg = 0.0
        for O in batch_O:
            z_t, _ = self.forward(O)
            y = self.head_task(z_t)
            for eta_name in ['lidar_dropout', 'lidar_noise', 'adv_pgd', 'occlusion', 'actuator_disturb',
                             'disp_quant', 'multipath', 'motion_blur', 'depth_hole', 'saturation', 'transparent']:
                O_pert = self.aug.perturb_single(O, eta_name, eps=1e-3)
                z_t_pert, _ = self.forward(O_pert)
                y_pert = self.head_task(z_t_pert)
                reg += torch.norm(y_pert - y) ** 2
        return reg / len(batch_O)

    def update(self, batch_O):
        loss = self.contrastive_loss(batch_O) + self.lambda_causal * self.causal_regularizer(batch_O)
        loss.backward()
        return loss.item()
```

```python
class DepthAntiInterferenceCertifier:
    """采样认证 ρ_dir^d = min_{η∈ℰ^d} min_t margin(τ, η)，含 depth_uncert_margin。"""
    def __init__(self, n_cert=64):
        self.n_cert = n_cert
        self.eps = {'sens': 0.05, 'act': 0.1, 'adv': 0.05, 'ood': 0.3,
                    'depth': 0.15, 'hole': 0.4, 'transparent': 1.0}

    def calibrate_eps(self, dir_module: DepthDisturbanceInvariantRepresentation, history_O):
        # 标准干扰分位数
        sens_mags, act_mags = [], []
        for O in history_O:
            sens_mags.append(estimate_lidar_noise(O.D))
            act_mags.append(estimate_actuator_disturbance(O.P))
        self.eps['sens'] = np.percentile(sens_mags, 95)
        self.eps['act'] = np.percentile(act_mags, 95)
        # 深度退化分位数
        depth_mags, hole_ratios = [], []
        for O in history_O:
            depth_mags.append(estimate_depth_noise(O.D, O.U))
            hole_ratios.append(O.U.mean())  # 不确定性图均值近似洞比例
        self.eps['depth'] = np.percentile(depth_mags, 95)
        self.eps['hole'] = np.percentile(hole_ratios, 95)

    def certify(self, tau, theta_bind, x_prime, phi_hat, r, Sigma_g):
        min_margin = float('inf')
        worst_eta = None
        for _ in range(self.n_cert):
            eta = self._sample_disturbance()
            margin_t = []
            for skill, theta in zip(tau, theta_bind):
                if skill.is_gait:
                    p_foot, K_base, C_seq = skill(x_prime, theta)
                else:
                    K_seq, c_seq = skill(x_prime, theta)
                    p_foot, K_base, C_seq = base_state.nominal, K_seq, c_seq
                O_pert = apply_disturbance_depth(x_prime, eta)
                margin_t.append(min_margin_under_pert_mixed(p_foot, K_base, C_seq, phi_hat, r, O_pert))
            m = min(margin_t)
            if m < min_margin:
                min_margin = m
                worst_eta = eta
        # 深度不确定性裕度项
        depth_uncert_margin = self._compute_depth_uncert_margin(tau, theta_bind, x_prime, phi_hat, r, Sigma_g)
        return min_margin, worst_eta, self.eps.copy(), depth_uncert_margin

    def _compute_depth_uncert_margin(self, tau, theta_bind, x_prime, phi_hat, r, Sigma_g):
        # 有限差分估计 ∂margin/∂Σ_g
        margin_base = float('inf')
        for skill, theta in zip(tau, theta_bind):
            if skill.is_gait:
                p_foot, K_base, C_seq = skill(x_prime, theta)
            else:
                K_seq, c_seq = skill(x_prime, theta)
                p_foot, K_base, C_seq = base_state.nominal, K_seq, c_seq
            margin_base = min(margin_base, min_margin(p_foot, K_base, C_seq, phi_hat, r))
        # 扰动 Σ_g
        Sigma_g_pert = Sigma_g + torch.eye(Sigma_g.shape[0]) * 1e-3
        margin_pert = float('inf')
        for skill, theta in zip(tau, theta_bind):
            if skill.is_gait:
                p_foot, K_base, C_seq = skill(x_prime, theta)
            else:
                K_seq, c_seq = skill(x_prime, theta)
                p_foot, K_base, C_seq = base_state.nominal, K_seq, c_seq
            margin_pert = min(margin_pert, min_margin(p_foot, K_base, C_seq, phi_hat, r, Sigma_g_pert))
        return (margin_pert - margin_base) / 1e-3 * torch.norm(Sigma_g, 'fro')

    def _sample_disturbance(self):
        return {
            'sens': sample_lidar_disturbance(self.eps['sens']),
            'act': sample_actuator_disturbance(self.eps['act']),
            'adv': sample_adversarial(self.eps['adv']),
            'ood': sample_ood_geometry(self.eps['ood']),
            'depth': sample_depth_noise(self.eps['depth']),
            'hole': sample_depth_hole(self.eps['hole']),
            'transparent': sample_transparent_material(self.eps['transparent'])
        }
```

```python
def wcv_depth_compile(olp, x_prime, eeis, phi_hat, r, g_mean, Sigma_g,
                      eps=0.05, n_worst=8, delta_geo=0.05, alpha_uncert=0.5):
    # 1. 几何初始化球心
    if phi_hat is None:
        phi_hat = geo_init_depth(g_mean)  # GeoInit(g_mean)
        r = r_base * (1 + alpha_uncert * torch.norm(Sigma_g, 'fro').item())
    # 2. 机会约束集 𝒢_chance
    G_chance = geo_chance_constraint_set(g_mean, Sigma_g, delta_geo)  # 概率约束
    # 3. 候选采样在 B∩𝒢_chance 内
    candidates = []
    for i in range(n_worst):
        phi_cand = sample_ball_intersect_chance(phi_hat, r, G_chance, Sigma_g)
        K = olp.project(x_prime)
        K_c = eeis.compile_with_phys_constraint(K, phi_cand)
        margin = safety_margin(K_c, phi_cand)
        loss_i = execution_loss_estimate(K_c, phi_cand)
        candidates.append((phi_cand, K_c, margin, loss_i))
    # 4. CVaR 尾部收缩
    candidates.sort(key=lambda z: z[3], reverse=True)
    tail = candidates[:max(1, int(eps * n_worst))]
    K_safe = intersect_shrink([K_c for _, K_c, _, _ in tail])
    rho_rob = min(margin for _, _, margin, _ in tail)
    cvar = np.mean([loss_i for _, _, _, loss_i in tail])
    # 5. 冲突率检查
    conflict_rate = sum(1 for _, _, _, _ in candidates if not chance_satisfied(_, G_chance)) / n_worst
    geo_conflict_chance = (conflict_rate > 0.5)
    return K_safe, rho_rob, cvar, geo_conflict_chance
```

### IP-212 OLP-Depth（深度感知在线投影）

```python
class DepthEnhancedOLP(OnlineLearningProjector):
    def __init__(self, Pi0, d_us_prime=384, m=128, d_out=6, D=1.0, r_max=0.5):
        super().__init__(Pi0, d_us_prime, m, d_out, D, r_max)
        # h 输入拼接 [x'; vec(Σ_g_diag)]，不确定性随机特征
        self.h = FrozenRandomFeatures(d_us_prime + 128, m, seed=42)
        self.G_tilde_depth = None

    def project(self, x_prime, Sigma_g_diag):
        h_input = torch.cat([x_prime, Sigma_g_diag], dim=-1)
        return self.Pi0(h_input) + self.h(h_input).T @ self.W

    def online_step(self, x_prime, Sigma_g_diag, grad_l):
        if self.G_tilde_depth is None:
            L_h = np.max(np.linalg.norm(self.h(torch.cat([x_prime, Sigma_g_diag]))))
            L_uncert = 0.5  # 经验上界
            G = 10.0
            self.G_tilde_depth = G * (L_h + L_uncert * np.linalg.norm(Sigma_g_diag)) * (1 + KAPPA_PHI * self.r_max)
        return super().online_step(torch.cat([x_prime, Sigma_g_diag]), grad_l)
```

```python
class MixedSkillBudgetBandit:
    MODES = [
        (usl, mel, align, tier)
        for usl in ('full_seq', 'single_skill', 'gait_only', 'manipulation_only', 'mixed_parallel', 'cached_seq', 'frozen')
        for mel in ('full', 'distill', 'cached', 'frozen')
        for align in ('on', 'off')
        for tier in ('high', 'mid', 'low')
    ]  # 168 原始，聚类为 32

    def __init__(self, K=32, eta=0.3):
        self.w = np.ones(K) / K; self.eta = eta; self.K = K
        self.prev_mode = None
        self.cluster_map = self._build_cluster_map()  # 168 -> 32

    def _build_cluster_map(self):
        # 按计算量/功耗聚类，每簇选代表臂
        clusters = {}
        for i, mode in enumerate(self.MODES):
            key = (mode[0], mode[3])  # (USL模式, cost_tier) 粗聚类
            if key not in clusters: clusters[key] = []
            clusters[key].append(i)
        cluster_map = {}
        for key, indices in clusters.items():
            rep = indices[0]
            for idx in indices: cluster_map[idx] = rep
        return cluster_map

    def choose(self):
        return self.MODES[np.random.choice(self.K, p=self.w)]

    def update(self, arm_idx, compute_cost, power_cost, progress, usl_mode):
        skill_switch = 1.0 if (self.prev_mode and usl_mode != self.prev_mode[0]) else 0.0
        reward = np.clip(progress - KAPPA_OCB * (compute_cost + power_cost + SKILL_SWITCH_PENALTY * skill_switch), 0, 1)
        clustered_idx = self.cluster_map.get(arm_idx, arm_idx)
        r_hat = reward / max(self.w[clustered_idx], 1e-6) / self.K
        self.w[clustered_idx] *= np.exp(self.eta * r_hat / self.K)
        self.w /= self.w.sum()
        self.prev_mode = (usl_mode, arm_idx)

    def clipped_arm(self, arm, hard_rule):
        return hard_rule.dominates(arm) if hard_rule else arm
```

## 4. 推导

**引理 5（深度不确定性显式量化球半径）** 设 DGF 输出 Σ_g 满足 ‖Σ_g‖_F ≤ σ_max(g_mean)（经验校准，σ_max 随深度质量单调递减），且 γ_geo = γ_base·(1+α_uncert·‖Σ_g‖_F)，α_uncert=0.5。RSC 更新 r_{t+1} = (1−β_c)r_t + β_c e_t，稳态 r_∞^d = E[e_t]。因 e_t 由 φ* − φ̂_0 驱动，且 φ̂_0 = GeoInit(g_mean)，有 E[e_t] ≤ ‖J_φ⁺‖·(‖φ* − GeoInit(g_mean)‖ + α_uncert·‖Σ_g‖_F) + noise。设 LiDAR 基线 r_∞^LiDAR = ‖J_φ⁺‖·δ_geo + o(1)，则 **r_∞^d ≤ r_∞^LiDAR·(1 + α_uncert·σ_max/δ_geo)**——深度不确定性被显式量化为球半径膨胀系数，证书不虚高。∎

**引理 6（混合技能图联合可行性）** 若 CSP-Mixed 搜索到序列 τ，且 ∀i π_σi ∈ 𝒫_feas^mixed(φ̂, r, Σ_g)，则由定义 218，∀φ∈B(φ̂,r)，∀基座状态采样，π_σi(·;φ) 满足 ERTC ∧ pre_σi ∧ ρ_rob ≥ 0 ∧ ZMP_in_poly ∧ momentum_feas ∧ contact_force_cone ∧ joint_limits。由于 CSP-Mixed 高层搜索保证 pre/eff 链条蕴含，低层参数优化将 ZMP/动量/接触力锥软化为 hinge 代价并收敛，存在参数绑定 θ_bind 使得全身轨迹满足所有约束。**步态与操作在技能层面联合保证动力学一致性**。∎

**引理 7（DIR-Depth 深度退化不变性界）** 设 ℒ_causal^d 使 ‖∂ŷ/∂η_depth‖_F ≤ ε_causal_depth，对比损失使 I(Z_nuisance; η_depth) ≤ ε_info_depth。对任意深度退化干扰 η_depth∈ℰ_depth，由数据处理不等式及 Pinsker 不等式，任务预测漂移 ‖ŷ(O+η_depth) − ŷ(O)‖ ≤ L_ŷ·W_1(P_{Z|O+η_depth}, P_{Z|O}) ≤ L_ŷ·(ε_causal_depth + √(2ε_info_depth))。**深度退化模式被显式纳入不变性学习**。∎

**定理 4（混合技能层面鲁棒遗憾界）** OLP-Depth 在混合技能参数空间（维度 d_mixed = d_op + d_gait ≈ 256 + 64 = 320）上运行 OGD。因 USL-Mixed 覆盖任务相关子空间（任务流形内在维度 d_task^mixed ≪ d_mixed），有效维度 d_eff^mixed = rank(J_θW) ≤ d_task^mixed。梯度上界 G̃_depth = G̃_geo + G·L_uncert·σ_max。标准 OGD 分析给出 **R_T^mixed ≤ D_mixed·G̃_depth·√T**，其中 D_mixed 为混合技能参数空间直径。**步态原语抽象进一步压缩有效维度**（d_task^mixed < d_task^op_only），遗憾常数改进。∎

**定理 5（AIC-Depth 认证有效性含深度不确定性）** 设 ℰ^d 覆盖 P[η* ∈ ℰ^d] ≥ 1−α_dir（α_dir=0.05），且 depth_uncert_margin ≥ −δ_uncert（δ_uncert=0.05）。margin(τ, η) 对 η 单调。采样近似 n_cert=64 时，Hoeffding 给出置信度 > 99%。若 ρ_dir^d ≥ 0 且 depth_uncert_margin ≥ −δ_uncert，则对真实干扰 η* 混合技能序列安全概率 ≥ 1−α_dir−δ_cert。**深度相机退化模式被统一认证框架覆盖**。∎

2. **步态-操作联合动力学一致性**：∃全身轨迹满足动量/ZMP/接触力锥/关节限位 —— 混合技能图联合保证（引理 6）。
3. **深度退化免疫可认证**：P[τ 在真实 η* 下安全] ≥ 1−α_dir−δ_cert —— 四类干扰+深度退化统一认证（定理 5）。
4. **混合技能层面遗憾改进**：R_T^mixed ≤ D_mixed·G̃_depth·√T，G̃_depth ≤ G̃_geo + G·L_uncert·σ_max —— 技能抽象降维+不确定性感知（定理 4）。
5. **低成本部署实时性**：边缘端语义流 < 100ms，实时流 < 10ms，模型 < 50MB INT8 —— 全链路降本契约（命题）。
6. **端到端安全组合**：Valid(J_glide) ⇔ 几何有效 ∧ 混合技能可行 ∧ 干扰认证通过 ∧ 部署档位有效 ∧ LIRO 证书有效 —— 四层安全证书链式组合。

## 7. 已知风险

**一句话**：若深度相机在**强光直射透明/镜面物体 + 高速运动模糊**复合极端工况下产生**大面积相干错误深度（而非随机噪声）**，DGF 的不确定性估计 Σ_g 会**系统性低估**（视差一致性高但几何错误），导致 WCV-Depth 球半径**欠膨胀**、CSP-Mixed 在**错误几何先验**上规划动态步态、DIR-Depth 在**错误干净视图**上对比学习——**深度不确定性量化从「显式保守」反变为「隐式乐观」**，这是本轮低成本几何替代论证共同依赖的单点假设（A83）。

**次级风险与缓解**：
1. **步态原语库覆盖不全**：长尾地形/动态障碍无对应步态 → CSP-Mixed 回退 gait_only + 在线步态发现（从演示/RL 挖掘新步态加入 GL，lineage 记录）。
2. **DIR-Depth 灾难性遗忘**：在线对比更新破坏已学不变性 → 经验回放缓冲区（保留 15% 干净+退化样本）+ EWC 正则（Fisher 对角，λ=0.1）。
3. **AIC-Depth 采样漏判极端深度退化**：n_cert=64 可能漏掉组合极端 → 自适应增采（ρ_dir^d 接近 0 或 depth_uncert_margin < 0 时 n_cert→256）+ 区间算术形式化边界验证。
4. **CSP-Mixed 实时性抖动**：复杂混合规划超时 → anytime A*（随时返回当前最佳）+ 硬性时间预算（50ms）超时回退 safe_idle + gait_only。
5. **深度相机完全失效降级**：DGF 失效时 g_mean=0, Σ_g=diag(σ_max²)，系统优雅降级为纯视触觉+本体模式（J_glide 标记 depth_degraded=True），保留步态原语库用于纯导航。
6. **自监督标定收敛失败**：弱纹理/纯旋转运动下标定不可观 → 添加主动标定行为（主动摆动末端激发触觉/本体），或回退出厂标定先验。
7. **INT8 量化精度崩塌**：极端分布外输入导致量化误差放大 → 关键路径（WCV-Depth、Shield-Mixed）保留 FP16 回退，证书标记 quant_degraded=True。
