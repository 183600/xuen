# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「手眼标定」×「多轮对话」）

> 第 54 轮把云边映射 `γ_ce` 写成给定的 Lipschitz 可逆映射，并假设 `δ_a` 可直接度量。本轮指出这是最脆弱的一环：`γ_ce` 在真实系统中是**未知外参**，只能由动作-观测对应关系标定出来，且标定存在**规范自由度（gauge）与可辨识性**问题；其语义层面的歧义（坐标系、工具、单位、时序）只能靠**多轮澄清对话**消解。核心矛盾：H22：动作激励不足时 `γ_ce` 不可辨识，残差小但解不唯一，`δ_a` 给出虚假可信；H23：标定外参会随机械磨损/重装漂移，跨轮复用旧证书等于复用过期外参，而多轮对话中的误听会污染标定观测并让误差逐轮累积。

## 0. 直觉与动机

**灵感 1（γ_ce 不是给定映射，而是手眼外参 X）**
直觉：手眼标定求解 `A X = X B`：`A_i` 是云端发出的相对动作，`B_i` 是边端观测到的相对动作，`X = γ_ce` 是两套动作坐标之间的未知外参。第 54 轮把 `X` 当作已知，等于**跳过了标定**。正确做法是把 `X` 当作待估量，证书里携带的是 `X̂` 及其协方差 `Σ_X`，而不是一个无误差的映射符号。`δ_a` 应由 `Σ_X` 诱导的置信椭球给出，而非拍脑袋阈值。

**灵感 2（可辨识性优先于残差小 → 激励秩是证书的前置条件）**
直觉：手眼标定的经典失败模式是「残差很小但解不唯一」——纯平移激励、或所有旋转轴共线时，绕轴旋转分量不可辨识。对应本框架：若技能只在低维动作子空间（低 `rank(A_i)`）里做标定，`compat` 与 `δ_a` 都好看，但 `γ_ce` 在未激励方向上完全自由。因此必须定义**激励秩 `ρ_ex(E)`** 与最小奇异值门槛，作为签发证书的硬前置条件；可辨识性从“数值细节”升格为“第一性约束”。

**灵感 3（语义规范自由度的多轮对话消解）**
直觉：即使数值 `X` 精确，仍有语义 gauge：云端说的“左手”对应边端哪个夹爪？`m` 还是 `mm`？时间戳用谁的主时钟？这些无法由 `AX=XB` 唯一确定，只能通过**多轮对话澄清**（“你指的是左腕还是左夹爪？”）。把语义歧义建模为假设集 `H_t`，每轮提问把 `H_t` 收缩；证书要求 `|H_t|=1`（或 Hamming 直径为零），即语义规范被钉死。

**灵感 4（标定-对话双环 → 数值协方差与语义熵同时收敛才可签发）**
直觉：系统有两个耦合闭环：**数值环**用更多/更优激励动作降低 `Σ_X`；**语义环**用澄清问题降低 `Ent(H)`。二者共享有限的交互预算（动作预算与用户耐心）。多轮标定策略 `π` 在每一轮选择“做一次标定动作”还是“问一个澄清问题”，目标是在预算内同时把 `tr(Σ_X)` 与 `Ent(H)` 压到阈值以下；任一未收敛则拒绝签发联合证书。

**灵感 5（时变证书与污染轮次的鲁棒修复）**
直觉：外参随磨损/温漂缓慢变化 `X_{t+1}=X_t exp(η)`，所以证书必须有**纪元 `e` 与半衰期 `T_half`**，过期即失效、必须重标定，不能无限复用。同时多轮对话会误听，把错误对应 `(A_i,B_i)` 注入标定；用一致性残差 `r_i=||log(X̂^{-1}A_iX̂B_i^{-1})||` 做鲁棒加权（Huber/GNC），高残差轮次不是简单丢弃，而是**触发重新提问/重新演示**（DCR），因为丢弃会损失激励、造成偏差。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（云边外参标定方程）**
云边外参 `X = γ_ce ∈ SE(d)`（`d=6` 为刚体位姿维度）。第 `i` 次交互给出对应 `(A_i, B_i)`，满足
```
A_i X = X B_i + E_i ,   B_i = edge_obs_i , A_i = cloud_cmd_i
```
其中 `E_i` 为观测噪声。标定即由 `{(A_i,B_i)}` 估计 `X̂` 及其协方差 `Σ_X`。

**定义 122（激励秩与可辨识性）**
对激励集 `E={(A_i,B_i)}_{i=1..T}`，定义激励算子 `𝒜(E): se(d) → se(d)^T`，`𝒜(E)ξ = (log(B_i^{-1} exp(ξ) B_i))_{i=1..T}`（对 `X` 的李代数扰动）。称 `E` 为 **ρ_ex-可辨识**，若
```
rank(𝒜(E)) = d  ∧  σ_min(𝒜(E)) ≥ σ_0 > 0
```
其中 `σ_min` 为最小奇异值，`σ_0` 为激励门槛。仅当 `ρ_ex(E)=d` 时 `X̂` 在规范等价类内唯一；否则存在不可观子空间 `ker(𝒜)`，其方向上的 `δ_a` 无界。

**定义 123（标定-对话信念状态）**
第 `t` 轮信念 `b_t = (X̂_t, Σ_t, H_t, Q_t, e_t)`：
- `X̂_t ∈ SE(d)`：外参估计；
- `Σ_t ∈ ℝ^{d×d}`：估值协方差（在 `X̂_t` 切空间）；
- `H_t`：语义假设集（坐标系/工具/单位/主时钟的组合），`Ent(H_t)` 为其熵；
- `Q_t`：已提问集合（避免重复提问）；
- `e_t`：标定纪元编号。
信念转移 `b_{t+1}=τ(b_t, o_t)`，`o_t` 为本轮观测（标定动作结果或用户澄清回答）。

**定义 124（多轮标定策略与停止条件）**
策略 `π: b_t → u_t ∈ {probe(a), ask(q)}`，`probe` 选一个标定动作、`ask` 选一个澄清问题。单轮收益
```
G(u_t) = λ_Σ·Δlogdet(Σ_t) + λ_H·(Ent(H_t) - Ent(H_{t+1})) - c_a·cost(a) - c_q·cost(q)
```
停止条件（签发前置）：
```
tr(Σ_t) ≤ Θ_Σ  ∧  Ent(H_t) ≤ ε_H  ∧  ρ_ex(E_t) = d  ∧  (t - e_t) ≤ T_half
```

**定义 125（时变联合证书与新鲜度）**
联合证书 `J_t = (ρ, A_cert, X̂_t, Σ_t, H_t, e_t, T_half, D_t, evidence)`，其中 `D_t` 为漂移上界。`J_t` 在 `t` 时刻**有效**当且仅当
```
(t - e_t) ≤ T_half  ∧  tr(Σ_t + Var(D_t)) ≤ Θ_X  ∧  |H_t| = 1
```
漂移模型 `X_{t+1}=X_t exp(η_t)`，`η_t ~ 𝒩(0,Q_drift)`；超过 `Θ_X` 触发强制重标定并使旧证书作废。

**定义 126（对话一致性残差与污染轮次）**
对第 `i` 轮观测定义一致性残差
```
r_i = || log( X̂^{-1} A_i X̂ B_i^{-1} ) ||
```
鲁棒权重 `w_i = ψ(r_i/σ)/ (r_i/σ)`（Huber/GNC）。若 `r_i > τ_r ∧ w_i < w_min`，判为**污染轮次**，不直接丢弃，而是标记为待修复并触发一次针对性 `ask`/`probe`（DCR）。污染率上界记 `κ`。

## 2. 关键算法 伪代码

### IP-121 HEC（Hand-Eye Extrinsic Calibration of γ_ce）

```python
def hand_eye_calibrate(pairs, sigma2, sigma0):
    # pairs: [(A_i, B_i)]，A_i 云端相对动作，B_i 边端相对动作
    for A, B in pairs:
        assert A.shape == B.shape
    X_hat = solve_ax_xb_dual_quaternion(pairs)   # 初值
    J = build_excitation(pairs)                  # 激励算子矩阵
    rank = matrix_rank(J)
    smin = smallest_singular_value(J)
    if rank < 6 or smin < sigma0:
        return ('unidentifiable', rank, smin, ker_basis(J))
    # 高斯-牛顿 + 协方差传播
    X_hat, Sigma = gauss_newton_se3(X_hat, pairs, sigma2)
    return ('ok', X_hat, Sigma, rank, smin)
```

### IP-122 AEX（Active Excitation under Action Budget）

```python
def active_excitation(X_hat, Sigma, candidates, budget, sigma2):
    E, chosen = [], []
    for _ in range(budget):
        best, best_gain = None, -inf
        for a in candidates:
            J_new = build_excitation(E + [predict_pair(a, X_hat)])
            gain = logdet(Sigma) - logdet(inv(inv(Sigma) + J_new.T @ J_new / sigma2))
            if gain > best_gain and rank(J_new) >= rank_of(E):
                best, best_gain = a, gain
        if best is None: break
        chosen.append(best); E.append(predict_pair(best, X_hat))
    return chosen
```

### IP-123 MTC（Multi-Turn Calibration Dialogue）

```python
def multi_turn_calibrate(b0, env, budget_a, budget_q, Theta_Sigma, eps_H):
    b = b0
    while not stop_ok(b, Theta_Sigma, eps_H):
        # 数值环 vs 语义环：按边际信息增益/成本比较
        u_num = best_probe(b, env.candidates)
        u_sem = best_question(b, env.questions)
        u = argmax([u_num, u_sem], key=lambda x: gain(x, b))
        o = env.execute(u)                      # 动作结果或用户回答
        if u.is_probe and residual(o, b) > tau_r:
            o = env.repair(u)                   # DCR：重新演示/重问
        b = bayes_update(b, u, o)               # X̂,Σ,H,Q,e
        b = robust_reweight(b)                  # IP-125
    return ('ok', cert_from_belief(b))
```

### IP-124 TCC（Time-aware Certificate Custody）

```python
def cert_valid(J, now):
    if now - J.epoch > J.T_half: return False, 'stale'
    Sigma_drift = propagate_drift(J.Sigma, now - J.epoch, Q_drift)
    if trace(Sigma_drift) > Theta_X: return False, 'drift_budget'
    if semantic_diameter(J.H) > 0: return False, 'gauge_ambiguous'
    return True, 'ok'
```

### IP-125 DCR（Dialogue-Consistency Repair）

```python
def robust_reweight(b, tau_r=3.0, w_min=0.1):
    rs = [residual(p, b) for p in b.pairs]
    ws = [huber_weight(r / b.sigma) for r in rs]
    b.pairs = [p for p, w in zip(b.pairs, ws) if w >= w_min]
    b.contaminated = [(p, r) for p, r, w in zip(b.pairs, rs, ws) if w < w_min]
    if b.contaminated:
        b.pending_repair.extend(b.contaminated)
    b = reestimate(b)          # 只在 w>=w_min 的观测上重估 X̂,Σ
    return b
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| HEC | O(T·d³)（SVD/求解）+ O(T·d²)（协方差） | O(T·d) | 激励秩满、σ_min 达标、噪声零均值 |
| AEX | O(B·|C|·d³)（贪心 D-optimal） | O(|C|·d) | 动作候选覆盖不可观子空间 |
| MTC | O(T_turn·(d³+|H|·|Q|)) | O(d²+|H|+|Q|) | 双环同时收敛、提问不重复 |
| TCC | O(d²)（漂移传播）/ O(1) 检查 | O(d²) | 漂移模型上界成立、纪元单调 |
| DCR | O(T·d²) | O(T·d) | 污染率 κ < 1/2、残差可分 |

**正确性定理（Calibrated Cloud-Edge Composition Soundness）**
承接第 54 轮 (A26)–(A28)；新增
**(A29)** 标定残差零均值且次高斯，方差 `σ²`；
**(A30)** 激励集 `E_t` 满足 `rank(𝒜(E_t))=d` 且 `σ_min(𝒜(E_t)) ≥ σ_0`；**(A31)** 签发前语义规范已定：`|H_t|=1`；**(A32)** 污染率 `κ<1/2` 且鲁棒估计一致。
则
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a)
             - 2·exp(-c·T·σ_0²/σ²) - P(Ent(H_t)>ε_H) - P(drift_t>D_max)
```
其中 `tr(Σ_t) ≲ d·σ²/(T·σ_0²)` 给出标定项，第二项来自语义歧义，第三项来自外参漂移。关键：**可辨识性（激励秩）是签发前提，语义 gauge 必须由对话钉死，证书必须带纪元与新鲜度**。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 激励动作占用任务预算，挤占鲁棒性/性能 | 高 | 把标定动作并入任务动作（in-task calibration）+ 预算联合优化 |
| 协方差低估导致虚假自信 | 高 | 区间/鲁棒协方差 + 留出验证 + 共形预测校准 |
| 语义歧义无法收敛（用户不配合） | 高 | 默认规范锚点 + 拒答即拒绝签发，不猜 |
| 外参漂移快于重标定周期 | 中 | 在线漂移监测 + 触发式重标定 + 半衰期保守设定 |
| 多轮误听污染导致误差累积 | 中 | DCR 鲁棒重估 + 重新演示 + 污染率上界监控 |
| 规范自由度（gauge）未固定导致解漂移 | 高 | 显式 gauge 固定（选主坐标系）+ 对话确认 |

## 6. 本轮最大风险

**一句话**：把 `γ_ce` 从“给定映射”还原为“待标定手眼外参”并以多轮对话消解语义 gauge，理论上补齐了第 54 轮最脆弱的假设，但整条 soundness 同时押注于**激励秩可观测、协方差被正确估计、语义歧义终将收敛**；一旦动作预算迫使激勵退化、或 `Σ_X` 被低估、或对话迟迟不收敛，系统会因“残差小而自信地解出不唯一的外参”而签发自洽但外部错误的证书，故必须以 **可辨识性硬闸门 + 保守协方差/共形校准 + 未收敛即拒签** 三重护栏，宁可延迟部署，绝不把“数值闭环良好”误当作“外参真实正确”。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（HEC×AEX×MTC×TCC×DCR×UAC）

> 承接第 54 轮产物 v31。本轮把云边映射 `γ_ce` 从“给定 Lipschitz 可逆映射”还原为**待标定的手眼外参**，并用**多轮对话**消解语义规范自由度，新增六个算子：
> - **HEC（Hand-Eye Extrinsic Calibration）**：以 `A X = X B` 标定 `γ_ce`，输出 `X̂` 与协方差 `Σ_X`；
> - **AEX（Active Excitation）**：在动作预算下做 D-optimal 激励选择，保证可辨识性；
> - **MTC（Multi-Turn Calibration Dialogue）**：数值协方差环 + 语义假设集环的双环多轮收敛；
> - **TCC（Time-aware Certificate Custody）**：证书纪元/半衰期/漂移预算的时效管控；
> - **DCR（Dialogue-Consistency Repair）**：基于一致性残差的鲁棒重估与“重问/重演示”修复；
> - **UAC（Uncertainty-Aware Certificate）**：由 `Σ_X` 诱导置信椭球的 `δ_a`，让证书携带不确定性。

## 2. 关键算法 伪代码

### IP-121 HEC

```python
def hand_eye_calibrate(pairs, sigma2, sigma0, dim=6):
    X_hat = solve_ax_xb_dual_quaternion(pairs)
    J = build_excitation(pairs)                # se(6) -> se(6)^T
    rank, smin = matrix_rank(J), smallest_singular_value(J)
    if rank < dim or smin < sigma0:
        return ('unidentifiable', rank, smin, ker_basis(J))
    X_hat, Sigma = gauss_newton_se3(X_hat, pairs, sigma2)
    return ('ok', X_hat, Sigma, rank, smin)

def uncertainty_delta(Sigma, chi2):
    # 置信椭球 -> 最坏方向动作对齐误差
    return sqrt(chi2 * largest_eigenvalue(Sigma))
```

### IP-122 AEX

```python
def active_excitation(X_hat, Sigma, candidates, budget, sigma2, dim=6):
    E, chosen = [], []
    for _ in range(budget):
        best, best_gain = None, -inf
        for a in candidates:
            J_new = build_excitation(E + [predict_pair(a, X_hat)])
            if matrix_rank(J_new) < dim:
                continue                       # 仍不可辨识则不奖励
            gain = logdet(Sigma) - logdet(inv(inv(Sigma) + J_new.T @ J_new / sigma2))
            if gain > best_gain:
                best, best_gain = a, gain
        if best is None:
            break
        chosen.append(best)
        E.append(predict_pair(best, X_hat))
    return chosen
```

### IP-123 MTC

```python
def multi_turn_calibrate(b0, env, budget_a, budget_q, Theta_Sigma, eps_H):
    b = b0
    while not (trace(b.Sigma) <= Theta_Sigma and entropy(b.H) <= eps_H):
        if budget_a <= 0 and budget_q <= 0:
            return ('reject', 'budget_exhausted', b)
        u_num = best_probe(b, env.candidates)
        u_sem = best_question(b, env.questions - b.Q)
        u = argmax([u_num, u_sem], key=lambda x: expected_gain(x, b))
        o = env.execute(u)
        if u.is_probe and residual(o, b) > 3.0 * b.sigma:
            o = env.repair(u)                  # DCR
        b = bayes_update(b, u, o)
        b = robust_reweight(b)                 # IP-125
    if not identifiably_excited(b.pairs) or semantic_diameter(b.H) > 0:
        return ('reject', 'not_identifiable_or_gauge_open', b)
    return ('ok', cert_from_belief(b))
```

### IP-125 DCR

```python
def robust_reweight(b, tau_r=3.0, w_min=0.1):
    rs = [residual(p, b) for p in b.pairs]
    ws = [huber_weight(r / b.sigma) for r in rs]
    keep = [(p, w) for p, r, w in zip(b.pairs, rs, ws) if w >= w_min]
    b.pending_repair = [(p, r) for p, r, w in zip(b.pairs, rs, ws) if w < w_min]
    b.pairs = [p for p, _ in keep]
    b = reestimate(b, weights=[w for _, w in keep])
    return b
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| HEC | O(T·d³) | O(T·d) | 激励秩 = d，σ_min ≥ σ_0，协方差一致 |
| AEX | O(B·|C|·d³) | O(|C|·d) | 补充不可观方向，D-optimal 单调增益 |
| MTC | O(T_turn·(d³+|H|·|Q|)) | O(d²+|H|+|Q|) | 双环同时收敛，未收敛即拒签 |
| TCC | O(d²) 传播 / O(1) 检查 | O(d²) | 漂移上界与纪元单调性 |
| DCR | O(T·d²) | O(T·d) | 污染率 κ<1/2，鲁棒估计一致 |
| UAC | O(d³)（特征分解） | O(d²) | δ_a 由 Σ 诱导，预算闭合 |

**正确性定理（Calibrated Cloud-Edge Composition Soundness）**
承接第 54 轮 (A26)–(A28)；新增 **(A29)** 标定残差零均值次高斯（方差 `σ²`）；**(A30)** 激励集 `E_t` 满足 `rank(𝒜(E_t))=d`、`σ_min≥σ_0`；**(A31)** 签发前语义规范已定（`|H_t|=1`）；**(A32)** 污染率 `κ<1/2` 且鲁棒估计一致。则
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a)
             - 2·exp(-c·T·σ_0²/σ²) - P(Ent(H_t)>ε_H) - P(drift_t>D_max)
```
且 `tr(Σ_t) ≲ d·σ²/(T·σ_0²)`。三条硬前提：**激励秩满（可辨识）**、**语义 gauge 已钉死**、**证书未过新鲜期**；任一不满足则拒绝部署，而不是把“残差小”当成“映射正确”。

## 5. 本轮最大风险

**一句话**：把 `γ_ce` 还原为待标定手眼外参并以多轮对话消解语义 gauge，理论上补齐了第 54 轮最脆弱的假设，但整条 soundness 同时押注于**激励秩可观测、协方差被正确估计、语义歧义终将收敛**；一旦动作预算迫使激励退化、或 `Σ_X` 被低估、或对话迟迟不收敛，系统会因“残差小而自信地解出不唯一的外参”而签发自洽但外部错误的证书，故必须以 **可辨识性硬闸门 + 保守协方差/共形校准 + 未收敛即拒签** 三重护栏，宁可延迟部署，绝不把“数值闭环良好”误当作“外参真实正确”。
