# 第 44 轮（新循环第 4 轮）· Curriculum-Cert × Embodied-FM-Shield：用「证书课程」管住具身大模型的开放世界，用「并发课程」驯服 v20 的并发风险（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 自陈最大风险是「共形只保边际覆盖 + 多用户契约求交为空」，但它仍压着两个更强的单点假设：**(H3) 能力集合 A 与场景分布是封闭且有界的**——课程只用于离线训练调度，在线扩张靠一次性三重闸门；**(H4) 语义层只是一个"可靠解析器"**——具身大模型（VLA/LLM）的输出被默认能可靠映射到既有证书。本轮灵感词「课程学习」「具身智能大模型」精确击中这两个假设：**课程学习**把"扩张"从一次性闸门升级为**带前置证明依赖的单调课程**（每次只加一节可单独认证的 lesson，条件覆盖按层天然成立）；**具身智能大模型**把语义层从"解析器"降级为**不可信提案者**，其开放世界输出必须经证书解释器落到某个 active lesson 才能执行。二者耦合处（lesson 之间的缝隙 + 大模型在缝隙处的开放世界新颖性）是本轮真正的新问题。

## 0. 直觉与动机

**灵感 1（课程学习 → 把"认证扩张"改造成"证书课程"）**：v20 的扩张是一个开关：三重闸门过了就整体放宽，过不了就全部退回。直觉上这是"要么全学、要么不学"，既脆弱又无法解释"到底学会了哪一块"。课程学习的核心直觉——**先易后难、每步只跨一个"最近发展区"、学过的不许遗忘**——恰好是认证扩张缺失的结构：把能力空间切成一节节 lesson，每节自带区域 D_j、证书 C_j、前置课 Pre_j 与测评；只有前置课 active 且本节测评（含逐层条件覆盖）通过，才把它**单调**并入在线包络 E_t。好处有三：**(a)** 条件覆盖不再靠"边际共形"事后补救，而是每节 lesson 的准入条件（按构造分层）；**(b)** 失败只回退一节及其后继（DAG 级联），而不是全链路熔断；**(c)** "灾难性遗忘"变成可审计的回归套件——证书漂移即级联降级。

**灵感 2（具身智能大模型 → 从"可验证策略"退为"不可信提案者"）**：VLA/LLM 的价值是开放世界泛化与自然语言接口，代价是黑箱、幻觉、动作空间开放。直接把它当策略去静态验证不现实；正确直觉是**把它关进"提案—解释—准入"的笼子**：大模型只负责产出 token 序列，证书解释器 T 把 token 编译成（符号动作 â, 声称的 lesson ℓ̂, 义务集 O），只有 â 落在某 active lesson 的允许集、且义务被守卫/租约清偿，才允许执行。任何"无法归课"的输出即 **out-of-curriculum 新颖性**，一律路由到预认证的保守技能库 Σ_safe 或离线队列，绝不放行。这样**无论基础模型多错，闭环 sound 性只依赖解释器与 lesson 证书**。

**灵感 3（耦合 → 并发本身也是课程，且课程就是调度）**：v20 的并发风险是"一上来就开满并发，契约求交容易空"。课程的直觉正好给出药方：**把并发等级 c 本身作为课程变量单调爬坡**（c=1→C_max），每级 c 都带自己的 rely-guarantee 不变式 I_c 与交错 fuzz；只有 level c−1 稳定后才准入 level c。于是"高并发可用性崩塌"被转化为"是否允许晋级"的局部决策；HI 模式则退到"当前负载下仍成立的最大 c"。同时 lesson 有难度与算力成本，课程顺序即投机分支的调度顺序——**课程、并发、调度三者统一为同一张偏序**。

**耦合升级**：CLC（证书课程引擎）负责 lesson DAG、单调准入与遗忘级联；FMCI（基础模型证书解释器/具身盾）负责把开放世界提案编译为可判定的准入问题；CXC（课程-并发耦合器）负责并发等级爬坡与课程感知调度。四层架构由 v8 的"人格契约层 + 并发证书层"升级为 v9 的"**人格契约层 + 并发证书层 + 开放世界课程层**"。

## 1. 形式化定义（增量：定义 44–49）

**定义 44（课时与课程）**：课时 L_j = (D_j, φ_j, A_j, C_j, Pre_j, α_j, b_j)：D_j ⊆ O×I 为任务/指令分布区域，φ_j 为入口谓词，A_j ⊆ A 为该课允许动作集，C_j 为在 D_j 上 sound 的证书（受控不变集/守卫），Pre_j ⊆ L 为前置课，α_j 为误覆盖目标，b_j 为测评预算。课程 G=(L,≺) 为以 Pre 为边的 DAG。**活跃前沿** A_t ⊆ L 是已准入集合。**在线能力包络** E_t = ⋃_{j∈A_t} (C_j ∩ D_j)。**命题（并集 sound）**：若每节 j∈A_t 的 C_j 在 D_j 上 sound，且执行时在 D_j 内只使用 A_j 并承诺 j 的策略（存在不离开 C_j 的驻留策略），则 E_t 在 D_t=⋃D_j 上 sound。**推论**：单调准入不破坏既有 sound 性；真正的新风险只在 **lesson 缝隙**（见定义 45）。

**定义 45（单调准入、缝隙与遗忘级联）**：准入 promote(L_j) 在 t 时刻成立，当且仅当
(1) Pre_j ⊆ A_t 且其租约新鲜；
(2) 在 D_j 的留出集上条件覆盖 ≥ 1−α_j 且零违例；
(3) 影子运行 T_shadow 零违例；
(4) 信任/算力预算可支付 b_j。
**缝隙与交接证书**：若离开 lesson j 的策略将进入 D_k，必须在 D_j∩D_k 上持有**交接证书** H_{j→k}，证明切换瞬间 E_t 的不变式保持；无交接证书的相邻课时禁止直接换策。**遗忘级联**：任何课时回归失败或被检测到证书漂移，则 demote(L_j) 并递归 demote 其全部后继；降级只收缩 E_t，恒 sound。**命题（无灾难性遗忘可审计）**：维护每课回归套件 R_j，漂移检测触发级联降级，则包络内每条结论始终有"当前仍被测评支持"的出处。

**定义 46（基础模型证书解释器与开放世界边界）**：具身基础模型 π_FM: (o, 指令, 记忆) → token 序列 y。解释器 T: y → (â, ℓ̂, O)，其中 â 为符号动作、ℓ̂ 为声称课时、O 为义务（如"须在 D_ℓ 内""须满足接触力上限"）。**准入判据**：提案可执行当且仅当存在 active lesson ℓ 使 ℓ̂=ℓ、â∈A_ℓ、当前状态∈D_ℓ、且 O 被守卫∧租约清偿。**out-of-curriculum** 定义为：ℓ̂=⊥，或 â∉A_ℓ（∀ℓ∈A_t），或当前状态已在 E_t 之外。此时**禁止放行**，只能路由到预认证保守技能库 Σ_safe 或离线认证队列。**新颖率** ν = out-of-curriculum 提案占比。**定理（基础模型无关的 sound 性）**：若解释器对已准入提案的判定 sound、Σ_safe sound，则闭环 sound 性与 π_FM 的对错无关——基础模型只影响可用性与新颖率，不影响安全性。

**定义 47（并发课程）**：并发等级 c∈{1..C_max}，每级声明证书不变式 I_c 与 rely/guarantee 接口，且 Pre(c)=c−1。**晋级判据**：I_{c−1} 在 T_stable 内零破坏 + 宽度 ≤c 的交错 fuzz 零破坏 + 线性一致性审计通过，才允许 c→c+1。运行时实际并发度 k_t ≤ c_t（投机分支 b≤c_t），HI 模式取"当前负载下仍成立的最大 c"。**命题（晋级保 sound）**：若每级 I_c 按定义 40 成立、且晋级只增并发不放松阈值，则任意可达并发等级下的执行保持 I_{c_t}；高并发契约空集被前移到"是否晋级"的离线决策，不再在运行时突发。

**定义 48（人格课程与渐进披露）**：对用户 u，个性化疗程是 Π_u 的单调增长序列 Π_u^{(1)} ⊆ Π_u^{(2)} ⊆ …，第 m 步只在 **persona 分层（Mondrian）** 的该层条件覆盖 ≥1−α 且信任预算 τ_u 可支付时准入；每步把 v20 的"边际共形扩张"改为"单层 lesson 扩张"。**命题**：逐层准入使**条件覆盖成为准入条件本身**，而非事后统计——直接对冲 v20 的边际覆盖风险；代价是个性化收敛变慢（用可用性换可证明性）。

**定义 49（课时难度、最近发展区与证书后悔）**：课时难度 d_j = 达到覆盖 1−α_j 所需期望测评预算（或固定预算下的覆盖缺口）。**最近发展区** ZPD = {j : d_lo ≤ d_j ≤ d_hi}：太易无包络增量、太难覆盖失败。课程排序目标：在 DAG 约束下最小化**证书后悔** Regret = ∫(E_t^oracle − E_t^cur)dt + λ·∫ unsafe_exposure dt。**推论**：课程学习在此不是"训练技巧"，而是**在证明预算约束下最大化可验证能力包络**的调度问题。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 CERTIFIED-LESSON-CURRICULUM（证书课程引擎 CLC）
1. **课时编译**：把技能/场景/指令切分为带 D_j、A_j、Pre_j、α_j 的课时，自动生成前置 DAG 与回归套件 R_j。
2. **单调准入 + 遗忘级联**：按定义 45 逐课准入；漂移/回归失败递归降级；全程审计"出处"。
3. **缝隙与交接证书**：识别 D_j∩D_k，生成 H_{j→k}；无交接证书禁止换策（堵住课程缝隙）。
4. **课程排序**：按难度/ZPD/证书后悔排序，兼顾前置约束与算力预算。

### 2.2 IP-61 FOUNDATION-MODEL-CERT-INTERPRETER（基础模型证书解释器 / 具身盾 FMCI）
1. **提案—解释—准入三段式**：π_FM 只提案；T 编译为 (â,ℓ̂,O)；准入器按定义 46 判定。
2. **开放世界新颖性路由**：out-of-curriculum 一律走 Σ_safe 或离线队列，禁止"猜测放行"。
3. **指令→契约的反射性检查**：自然语言指令到形式契约的编译须可回译验证；歧义时产出澄清集而非默认解释。
4. **能力包络看板**：实时输出 ν、包络增长、被拒提案归因，供课程引擎选下一课。

### 2.3 IP-62 CURRICULUM-CONCURRENCY-COUPLER（课程-并发耦合器 CXC）
1. **并发爬坡**：按定义 47 单调晋级，维护每级 I_c 与 fuzz 证据；HI 模式选最大可行 c。
2. **课程感知投机调度**：投机分支顺序=课程难度序；b 受当前 c_t 与关键级约束。
3. **课程-负载联合过载策略**：过载时先砍"非前置、低关键"课时与投机，保前置安全课与监控预算。
4. **晋级/降级与依赖传播**：并发晋级失败只回退一级；课时降级同步收紧 c 的上界。

## 5. 本轮最大风险

**一句话**：课程学习把分布切成一个个 lesson 后，**lesson 之间的缝隙与切换（seam/handover）天然无人持证**，而具身大模型最丰富的开放世界提案恰恰涌现在这些边界——一旦把 out-of-curriculum 误判为"已覆盖"，就会形成 v20 平坦认证都未曾有过的**静默失效带**；因此 E95（缝隙）与 E96（新颖性判定）必须设为红线，并默认回退到"最小课程 + 保守技能库 + 串行监控"。

## 2. 关键算法（伪代码）

### IP-60 CLC：课时编译、单调准入与遗忘级联
```
def build_curriculum(skills, scenarios, alpha):
    lessons = [Lesson(D=region(s), A=actions(s), alpha=alpha[s], Pre=prereq(s))
               for s in scenarios]
    G = DAG(lessons, edges=lambda L: L.Pre)
    for L in topo(G):
        L.C = certify_lesson(L.D, L.A)          # 离线证书（含逐层条件覆盖测评）
    return G

def admit_lesson(G, L, A_t, lease_table, budget):
    if not all(p in A_t and lease_fresh(lease_table[p]) for p in L.Pre):
        return Reject("prereq")
    if not conditional_coverage_ok(L.D, L.C, 1 - L.alpha):   # 分层条件覆盖
        return Reject("coverage")
    if shadow_violations(L) > 0 or budget < L.b:
        return Reject("shadow_or_budget")
    for H in handovers(G, L, A_t):              # 缝隙必须持交接证
        if not H.valid_on(intersect(L.D, D(H.to))):
            return Reject("seam", missing=H)
    return Promote(L)                            # 单调并入 E_t

def demote_cascade(G, L, A_t):
    A_t.discard(L)
    for child in descendants(G, L):
        A_t.discard(child)                       # 遗忘级联：只收缩，恒 sound
    return A_t
```

### IP-61 FMCI：基础模型盾与开放世界准入
```
def interpret_and_admit(y, o, A_t, C_global, persona, lease, t):
    a_hat, l_hat, O = T(y, o)                   # token -> 符号动作/课时/义务
    if l_hat not in A_t:
        return Fallback(S_safe, "out_of_curriculum")
    L = A_t[l_hat]
    if a_hat not in L.A or o not in L.D:
        return Fallback(S_safe, "out_of_domain")
    if not all(discharge(ob, L, C_global, persona, lease, t) for ob in O):
        return Reject("obligation_unsatisfied")
    return Admit(a_hat, L)                       # 基础模型对错不影响 sound

def reflexive_instruction_compile(instruction):
    contracts = compile_C(instruction)
    if not roundtrip_equiv(instruction, contracts):   # 回译不等价 => 有歧义
        return Clarify(ambiguity_set(instruction))    # 不猜测放行
    return contracts
```

### IP-62 CXC：并发爬坡与课程感知调度
```
def concurrency_step(c, evidence):
    if c >= C_max:
        return c
    if invariant_holds(I[c], evidence) and fuzz_ok(width=c+1) and audit_linearizable():
        return c + 1                              # 单调晋级，晋级只增并发不放松阈值
    return c

def curriculum_aware_schedule(lessons, c_t, overload, kappa):
    order = topo_sort_by(lessons, key=difficulty) # 先易后难（ZPD 内优先）
    b = min(c_t, branch_budget(kappa))            # 投机受并发课程上界
    if overload:                                  # HI：只保前置安全课 + 安全预算
        order = [L for L in order
                 if L.is_prerequisite and L.kappa >= K_GEOMETRY]
        reserve_budget(SAFETY_MONITOR, B_safe)
    return pack(order, b, affinity=True)
```

```
def lesson_guard(e, x, lesson, lease, t, seam):

                 lease.m - lease.lam * (t - lease.tau),

def certify_open_world_proposal(a_hat, lesson, budget_us):
```

### IP-57 升级：人格课程（逐层准入）
```
def persona_curriculum_step(u, Pi_u_seq, tau_u, alpha):
    for step, Pi in enumerate(Pi_u_seq):
        # 每步是该 persona 分层内的一节 lesson
        if conditional_coverage_ok(stratum=u, target=1 - alpha) \
           and tau_u >= cost(Pi) and shadow_ok(Pi):
            promote_step(u, step)
            tau_u -= cost(Pi)
        else:
            break                                 # 不跳步，不到期不扩张
    return Pi_u_current(u), tau_u
```

## 6. 本轮最大风险

**一句话**：课程学习把分布切成一个个 lesson 后，**lesson 之间的缝隙与切换（seam/handover）天然无人持证**，而具身大模型最丰富的开放世界提案恰恰涌现在这些边界——一旦把 out-of-curriculum 误判为"已覆盖"，就会形成 v20 平坦认证都未曾有过的**静默失效带**；因此 E95（缝隙）与 E96（新颖性判定）必须设为红线，并默认回退到"最小课程 + 保守技能库 + 串行监控"。
