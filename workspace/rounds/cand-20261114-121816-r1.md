# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「对比实验」×「嵌入式系统」）

> R69 把不确定性拆成 aleatoric 与 epistemic，并用「流匹配多模态策略 + 主动交互」去消解后者。但它只回答了「不确定性多重、能不能问」，没有回答两个更硬的问题：**（1）这份不确定性到底来自哪一环？** 是感知把「笑」读错了、是标定把观测拉偏了、是策略本身多峰、还是被交互对象投毒了？R69 对所有 epistemic 一律「去问」，可若病因是标定漂移，问一百句也问不出来；若病因是感知噪声，问也只是把 aleatoric 当 epistemic 白花预算。**（2）我凭什么相信「问出来的答案」和「算出来的模态」是真的？** R69 自陈的最大风险正是：全部收益押在模态分布可信上，问错比不问更危险。
>
> 本轮两个灵感给出同一把钥匙的两面：
> - **对比实验**把「观察」升级为「干预」。R69 的 K 次采样是看（observation），只能得到相关；控制变量、只改一个因子再重放，才是干预（intervention），才能得到因果。它把「不确定性有多大」变成「不确定性来自哪个因子」——一个可以被归因的向量，而不是一个标量。
> - **嵌入式系统**不是「把大模型塞进小盒子」的工程妥协，而是**对比实验合法性的前提**。受控实验要求「除一个变量外全都相同」；GPU 上的异步归约、原子竞争、autotune 让两次「相同」的重放本就不同，观测差被非确定性噪声污染。定点算术 + 确定性调度 + 固定种子给出位精确复现，才让配对差值可归因。同时，硬实时与有限 slack 迫使实验成为**稀缺的可调度资源**，而定点量化本身又引入「确定性但有偏」的新混淆项，必须再用一条对照通道去测。
>
> 核心命题：**R69 沿「性质轴」把 U 分成 (U_ale, U_epi)；本轮沿「来源轴」再用运行期受控对比实验估计归因向量 α（perception / calibration / policy / interaction / quant），并用 α 选择正确的响应；只有在孪生保真、slack 充足、证据纪律满足时才采信归因，否则逐指令退化为 R69。** 命名 **CONTRAST-RAS**（Comparative ON-device Twin Replay for Attribution and Safe Transition）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**到底是哪一环错了，以及我凭什么相信这个结论**」——不确定性不只是刹车踏板或一句提问，也可以是一场被精心控制、可复现、可审计的对比实验。

## 0. 直觉与动机

**灵感 1（对比实验 → 从「不确定性有多大」到「不确定性来自哪一环」）**
直觉：R69 把不确定性按**性质**分成 aleatoric / epistemic，却没有按**来源**分。两个同为 epistemic 的不确定性可能有完全不同的病因：感知歧义（该看）、标定漂移（该重标定）、策略多峰（该问或该探索）、交互投毒（该不信）。R69 的响应永远是「问」，这在病因不是「信息缺失」时是南辕北辙。对比实验的核心动作是**控制变量**：固定其余一切，只改一个因子，重放、比较、看观测泛函是否变化。它把「不确定」这个形容词变成「哪个模块该负责」这个名词。这正是因果推断里 observation 与 intervention 的分野：R69 的 K 次采样是看，看到的是相关；本轮的单因子重放是干预，干预才给因果。

**灵感 2（嵌入式系统 → 确定性是对比实验的「合法前提」，不是部署的让步）**
直觉：普通科学实验有可复现性危机——不可复现的证据不算证据。GPU 上的深度学习栈天生不可复现：异步归约顺序不定、原子操作竞争、cuDNN autotune 选核、浮点融合、抢占式调度。两次「除一个变量外全同」的运行本就不同，配对差值是「因子效应 + 非确定性噪声」的混合物，归因被污染。嵌入式系统的定点算术、确定性调度、固定种子、关中断/无 DMA 竞争，给出**位精确重放**，于是配对差值中的混淆项从「不可控方差」压缩到可界定的量化偏差与孪生残差。**在这套框架里，嵌入式不是把模型变小的妥协，而是让因果归因这件事在物理上成立的认识论仪器。** 反过来，硬实时与有限 slack 又把实验变成稀缺资源：不是想跑就跑，而是要在不抢占安全路径的前提下排队、估值、丢弃。

**灵感 3（孪生/双世界 → 实验绝不扰动安全路径）**
直觉：运行期做实验最危险的是「实验本身把系统搞坏」。解法是双世界：主路径照常、结果先落地保证安全底线；孪生路径只读输入快照、在 slack 窗口里重放，绝不回写主状态、绝不共享可变内存、绝不改变主路径 WCET。这是 R69「交互动作也要过安全认证」的更进一步：连「做实验」这个认知动作也要过资源与隔离认证。但双世界带来一个必须自证的前提——**孪生必须忠实于主路径**。因此每次归因前先做「零假设实验」：不改任何因子，重放两次，差值必须为零（硬件上为 ≤ τ_null）。零差值不成立，说明存在隐藏非确定性（中断抖动、缓存、时钟漂移），孪生不可信，全部对比作废。

**灵感 4（稀缺预算 → 用信息价值调度实验，而不是穷举）**
直觉：可做的对比实验是组合爆炸的：因子、因子取值、时序、模态对……但每周期只有极短的 slack。不能全做，也不该全做——很多对比对当前的不确定性毫无判别力。于是引入实验价值 VoE（value-of-experiment）：每毫秒 slack 期望降低多少归因熵。按 VoE 降序装包进 slack，放不下的直接丢弃、绝不抢占主路径。这与 R69 的 VoI 是一对：**VoI 决定「值不值得干预世界」，VoE 决定「值不值得干预我自己的认知」**。前者花的是交互预算，后者花的是计算 slack，两者都不能超支。

**灵感 5（对比实验是双刃剑 → 归因 p-hacking 与实验投毒）**
直觉：一旦系统能「做实验」，就有了新的自欺渠道。最阴险的不是实验失败，而是**实验成功得太容易**：不断换因子、换取值、换观测泛函，直到某个对比「显著」，然后宣布找到了病因——这是把确认偏误自动化，即机器学习版的 p-hacking。n 次自适应未登记实验里至少一次假阳性的概率是 1−(1−α)^n，随 n 趋近于 1。外部攻击者还可以**投毒对比通道**：制造让孪生虚假发散的噪声（假归因）、或让孪生虚假一致（掩盖真故障）、或利用定点量化制造「确定性但系统性偏移」的结果。所以本轮必须同时交付：预注册与 α-spending、零假设对照、留出确认、实验完整性哈希链、以及「单次对比永不定案」。否则 R70 不是进步，而是给 R69 装了一台会自我印证的伪科学机器。

## 1. 形式化定义（增量：定义 310–322）

**定义 310（CONTRAST-RAS 总览与四不变式）** CONTRAST-RAS = (DTE, SFA, NEX, VES, QCR, PRE, ACR, EIC, RAS-WM‡)。四不变式：
(i) **实验非干涉**：对比实验仅在主路径 slack 窗口内、在隔离孪生上执行，绝不改变主路径的可达状态、WCET 与截止期（继承 R69 定义 293-i）；
(ii) **孪生保真**：任何归因前必须通过零假设实验（Δ_null ≤ τ_null），否则孪生不可信、全部对比作废；
(iii) **预注册与多对照**：假设与对照设计须在执行前登记，单次对比不得定案，需 ≥ k 个独立对照一致（对抗 p-hacking）；
(iv) **严格包含**：实验基础设施任一环节失效（孪生失真 / slack 不足 / 被投毒 / 结论不显著）⇒ 逐指令退化为 R69，R69 再按原规则退化为 R68。

**定义 311（确定性孪生执行 DTE）** 主路径 π_main 与孪生路径 π_twin 共享同一观测快照 o 与同一确定性契约 𝔇：(a) 定点算术（int8/int16 + 固定 scale，舍入规则确定）；(b) 确定性调度与固定种子；(c) 无异步归约、无原子竞争、无 autotune。对任意输入与种子，replay_𝔇(o; seed) 位精确可复现。孪生只读主路径的输入快照与已提交状态，不回写、不改变主时钟。

**定义 312（受控对比算子 SFA）** 因子集合 ℱ = {perception, calibration, policy, interaction, quant}，每个因子 f 有取值域。单因子对比定义
Δ(e) = 𝒪(π_twin[f ← f′](o)) − 𝒪(π_twin[f](o))，
其中除 f 外所有输入、种子、时序、内存布局保持不变；观测泛函 𝒪 可取模态身份、动作块、风险分或任务结果。灵敏度矩阵 S_{ij} = ∂𝒪_i/∂f_j 由一族对比估计。

**定义 313（来源归因）** 归因向量 α ∈ Δ^{|ℱ|}（单纯形），α_f 为「本次不确定性期望可归因于因子 f」的后验质量。给定对比集 {Δ(e)}、灵敏度矩阵 S 与先验，α = softmax(Bayes(S, Δ; prior))；归因熵 H_attr = −Σ_f α_f log α_f。R69 沿性质轴得 (U_ale, U_epi)，本轮沿来源轴得 α；二者构成二维分解 (U_ale, U_epi) × α，性质决定「要不要收紧/询问」，来源决定「收紧谁、询问谁、重标定谁」。

**定义 314（零假设实验 NEX）** 不改变任何因子，以同一输入、同一种子重放两次：Δ_null = |𝒪(π_twin(o; seed)) − 𝒪(π_twin(o; seed))|，理论上恒为 0；真实硬件上以多次重放的经验分布度量，要求 P(Δ_null > τ_null) ≤ δ_null。越界 ⇒ 检测到隐藏非确定性（中断抖动、缓存、DMA 竞争、时钟漂移），孪生作废、归因禁用。

**定义 315（实验价值调度 VES）** 单次实验 e 的代价为最坏执行时间 WCET(e) 与内存；价值 VoE(e) = E[H_attr(before) − H_attr(after) | e] / WCET(e)。在每个控制周期的 slack 预算 B_slack 与截止期内，选实验队列最大化 Σ VoE，s.t. Σ WCET(e) ≤ B_slack，且实验不得抢占主路径、不得跨周期泄漏。无正收益或放不下 ⇒ 不实验。

**定义 316（预注册与抗 p-hacking 纪律 PRE）** 执行前登记 (假设 H, 因子 f, 对照 f′, 观测泛函 𝒪, 停止规则)；采用序贯检验的 α-spending 把总 I 类错误控制在 α 以内；至少一次留出确认（held-out confirmation）或 k 个独立对照一致；严禁「实验到显著为止」。证据强度以 log-likelihood ratio 累积，而非单次 p 值。

**定义 317（量化偏差对照通道 QCR）** 定点量化引入确定性但系统性的偏差 q。用参考浮点路径或抖动（dither）路径与定点路径做配对对比，一致估计 q̂ 及其置信区间；q̂ 非零时归因置信按 |q̂| 折减，且**不得把 q̂ 当作 0**——否则归因会系统性偏向 quant 因子或掩盖真实因子。

**定义 318（归因驱动的响应选择 ACR）** 由 α 与 H_attr 选响应：perception → 注视/靠近（R69 MINT）；calibration → 重标定（R68 COF）；policy → 探索或问询（R69 MINT/CIA）；interaction → 降低交互信任或禁用交互（R69 MCG 的下游版）；quant → 放宽安全裕度并记录；H_attr 过高或无法归因 → R69 纯保守兜底。可执行响应集合是 R69 的**严格超集**。

**定义 319（实验完整性链 EIC）** 每次对比登记 (seed, 因子, 输入哈希, WCET, 结果) 并串成哈希链；种子在执行前承诺（commit-reveal），链尾写入证书。任何篡改使链不连续 ⇒ 该批实验作废。EIC 让「我做过哪些实验、是否事后改过停止规则」可被第三方审计。

**定义 320（证书 J_CONTRAST）** J_CONTRAST = (J_FLUID, null_error, H_attr_before/after, attribution_map_hash, wcet_slack_used, p_hacking_guard_ok, experiment_chain_tail, contrast_ver)。Valid ⇔ Valid(J_FLUID) ∧ 孪生保真 ∧ 证据纪律满足 ∧ slack 未越界 ∧ 链完整。

**定义 321（三级回退与严格包含链）** 若实验可用且归因显著：λ 与响应由 α 决定（可获得低于 R69 的保守度，但永不下探安全界）；若孪生失真 / slack 不足 / 被投毒 / 不显著：逐指令退化为 R69；R69 再在 ECE 越界、VoI≤成本等情形退化为 R68。⇒ **R68 ⊂ R69 ⊂ R70**，安全侧单调不弱，效率侧逐层获得 bonus。

**定义 322（自适应实验深度与析因设计）** 默认只做 1 组单因子对比；仅当归因不显著（H_attr > τ_H）且 slack 有余时，加深到 2–3 因子的 2×2 析因设计（同时估计主效应与交互效应）。深度由 VES 预算决定，并保证 P99 WCET 不被击穿；深度提升本身须预注册，不得因「想看更多」而无限加深。

## 2. 关键算法骨架

```python
# IP-264 DTE：确定性孪生执行（定点 + 固定种子 + 隔离，只读快照）
class DeterministicTwin:
    def __init__(self, main_pipeline, fixed_point_spec, budget):
        self.main, self.fp, self.budget = main_pipeline, fixed_point_spec, budget

    def replay(self, o_snapshot, factor_override=None, seed=0):
        # 除 factor_override 外一切相同；deterministic_scope 关闭中断抖动/异步归约
        with deterministic_scope(self.fp, seed, no_shared_write=True):
            return self.main.run(o_snapshot, override=factor_override)

# IP-265 SFA：单因子受控对比 + 灵敏度矩阵 → 归因
def contrast(twin, o, factors, obs_fn):
    base = obs_fn(twin.replay(o))
    return {f: obs_fn(twin.replay(o, factor_override={f: perturb(f)})) - base
            for f in factors}                       # 只变一个因子

def attribute(deltas, S, prior):
    alpha = softmax(bayes_update(prior, S, deltas))  # 来源轴 α
    return alpha, entropy(alpha)                     # (α, H_attr)

# IP-266 NEX：零假设实验（孪生保真门；不过则全部归因作废）
def twin_is_faithful(twin, o, obs_fn, n=8):
    diffs = [abs(obs_fn(twin.replay(o, seed=s))
                 - obs_fn(twin.replay(o, seed=s))) for s in range(n)]
    return percentile(diffs, 99) <= TAU_NULL

# IP-267 VES：slack 内的实验价值调度（不抢占主路径）
def schedule_experiments(queue, slack_ms):
    chosen, used = [], 0.0
    for e in sorted(queue, key=lambda e: e.voe, reverse=True):
        if used + e.wcet <= slack_ms and e.voe > 0:
            chosen.append(e); used += e.wcet
    return chosen, used                              # 放不下就丢弃，绝不抢占

# IP-269 PRE：预注册 + 序贯 α-spending + 留出确认
def preregistered_test(e, alpha_left):
    e.register(hypothesis=e.h, factor=e.f, obs=e.obs, stop_rule=e.rule)  # 执行前承诺
    return sequential_test(e.result, alpha_left)     # 抗「实验到显著为止」

# IP-268 QCR：量化偏差通道（确定性但有偏，不可当 0）
def quant_bias(twin, o, obs_fn):
    return (obs_fn(twin.replay(o, factor_override={'quant': 'float_ref'}))
            - obs_fn(twin.replay(o, factor_override={'quant': 'fixed'})))

# IP-270 ACR：归因驱动的响应（严格超集于 R69）
def respond(alpha, H_attr, M):
    if H_attr > TAU_H:       return M.fluid.fallback()      # 归因不了 → R69
    src = argmax(alpha)
    return {
        'perception':  M.fluid.mint_ask,
        'calibration': M.cof.recalibrate,
        'policy':      M.fluid.explore_or_ask,
        'interaction': M.fluid.disable_interaction,
        'quant':       M.safety.widen_margin,
    }.get(src, M.fluid.fallback)()

# IP-274 主闭环
def CONTRAST_RAS_round(M, obs):
    k, lam, st = M.fluid.round(obs)                  # 先跑 R69，保证安全底线
    if not M.nex.twin_is_faithful(M.twin, obs, M.obs_fn):
        return k, lam, st                            # 孪生不可信 → 直接用 R69
    queue = M.ves.build(M.twin, obs, M.factors, M.budget.slack())
    deltas, spent = {}, 0.0
    for e in M.ves.schedule(queue, M.budget.slack())[0]:
        if not M.pre.admit(e):            continue   # 预注册/α-spending 不过
        deltas.update(M.sfa.contrast(M.twin, obs, [e.factor], M.obs_fn))
        spent += e.wcet
    alpha, H_attr = M.sfa.attribute(deltas, M.sens_matrix, M.prior)
    q = M.qcr.quant_bias(M.twin, obs, M.obs_fn)      # 量化混淆项
    alpha = M.sfa.debias(alpha, q)                   # 按 |q| 折减置信
    resp = M.acr.respond(alpha, H_attr, M)           # 响应超集于 R69
    M.eic.append(spent, alpha, deltas)
    return resp
```

## 3. 推导

**引理 19（确定性对比的可归因性）** 在 DTE 位精确复现与 NEX「P(Δ_null ≤ τ_null) ≥ 1−δ」下，单因子对比 Δ(e) 对因子 f 因果效应的估计偏差 ≤ q + τ_null，即 E[Δ|f] = effect(f) ± (q + τ_null)。对照非确定性 GPU 路径：其重放方差 σ_nd 会把因子效应完全混入观测差，偏差为 σ_nd 量级。系：**对比实验的合法性与硬件确定性成正比**——这正是把嵌入式系统当作认识论工具的严格理由，而非工程借口。

**引理 20（非干涉与 WCET 隔离）** 若孪生仅在 slack 窗口执行、与主路径无共享可变状态、且 WCET(twin) ≤ B_slack，则由最坏执行时间可加性与隔离域，主路径 WCET 与截止期错失概率不变。故任意多次对比实验都不降低安全侧性能；实验的代价只体现为「未被利用的 slack」的机会成本。

**引理 21（p-hacking 放大与纪律上界）** 若自适应跑 n 次未登记实验、任一 p<α 即定案，则至少一次假归因的概率为 1−(1−α)^n，随 n 单调趋近 1；采用预注册 + α-spending + 留出确认后，总假归因率 ≤ α。系：**没有预注册的「对比实验」只是把确认偏误自动化**——系统会为自己既有的病因假设不断生产「证据」。

**引理 22（量化偏差的可辨识与不可忽略性）** 定点偏差 q 是确定性的，故可被参考路径的配对对比一致估计 q̂（QCR）；但当 q ≠ 0 时若被当作 0，归因会系统性偏向 quant 因子或掩盖真实因子。因此必须显式建模 q̂ 并按 |q̂| 折减置信——确定性不等于无偏。

**定理 18（CONTRAST 严格包含 R69）** 当孪生保真、slack 充足、归因显著时，CONTRAST 的期望风险 ≤ R69；当孪生失真 / slack 不足 / 被投毒 / 归因不显著时，二者逐指令相同（定义 321）。故 R70 是 R69 在「试验基础设施可用」边界上的严格泛化：安全侧不让步，效率侧仅在可验证的条件下获得归因 bonus。

**定理 19（归因收敛与响应效率）** 若灵敏度矩阵 S 满秩、对比覆盖全部因子且满足 PRE，则 H_attr 随独立对比数 k 指数下降；选错响应的期望损失（相对 oracle 响应）≤ C_max·e^{−c·k}。系：多做几个正交对照买来的是响应正确率的指数提升——但前提是对照真正独立且未被投毒（否则见引理 21、23）。

**引理 23（实验投毒的归因偏移上界）** 若对比通道被投毒、使某因子观测差被额外偏移 δ_p，则归因向量的 L1 偏移 ≤ κ·δ_p（κ 为灵敏度矩阵条件数）；条件数越大，系统对投毒越敏感。故需 EIC（完整性）+ NEX（保真）+ 多对照（去相关），三者共同把 κ·δ_p 压回安全阈内。

## 6. 本轮最大风险

**一句话**：CONTRAST-RAS 的全部归因结论都押在「孪生是主路径的忠实确定性模型」这一前提上——**一旦存在隐藏非确定性（中断抖动、缓存、DMA 竞争、时钟漂移）或孪生与主路径悄悄分叉，受控实验里就会混入一个未经控制的第二变量；此时实验并非「失败」，而是产生一个看上去干净、实际上被污染、且因「做过对照实验」而更被系统信任的错误病因——实验做得越严谨，错得越自信**。

**次级风险与缓解**：
1. **归因 p-hacking（不断换因子直到显著）** → 定义 316 预注册 + α-spending + 留出确认 + 引理 21 上界；
2. **实验投毒/虚假发散/虚假一致** → EIC 哈希链 + NEX + 多独立对照 + 引理 23 偏移界；
3. **量化偏差被当成 0** → QCR 参考通道 + debias + 引理 22；
4. **实验击穿实时预算** → VES 严格装包 + slack 硬上限 + 「放不下即丢弃」+ 引理 20；
5. **归因显著但响应映射错误**（α 对、动作错）→ ACR 是 R69 的严格超集，无法映射即回退，且响应本身仍过 C-RAS-WM 认证。

## 3. 关键算法伪代码

```python
# IP-264 DTE：确定性只读孪生（位精确重放）
class DeterministicTwin:
    def replay(self, o_snapshot, factor_override=None, seed=0):
        with deterministic_scope(self.fp, seed, no_shared_write=True):
            return self.main.run(o_snapshot, override=factor_override)

# IP-265 SFA：单因子对比 + 归因
def contrast(twin, o, factors, obs_fn):
    base = obs_fn(twin.replay(o))
    return {f: obs_fn(twin.replay(o, factor_override={f: perturb(f)})) - base
            for f in factors}

def attribute(deltas, S, prior):
    alpha = softmax(bayes_update(prior, S, deltas))
    return alpha, entropy(alpha)                     # (α, H_attr)

# IP-266 NEX：零假设实验（孪生保真门）
def twin_is_faithful(twin, o, obs_fn, n=8):
    diffs = [abs(obs_fn(twin.replay(o, seed=s)) - obs_fn(twin.replay(o, seed=s)))
             for s in range(n)]
    return percentile(diffs, 99) <= TAU_NULL

# IP-267 VES：slack 内实验装包（不抢占主路径）
def schedule_experiments(queue, slack_ms):
    chosen, used = [], 0.0
    for e in sorted(queue, key=lambda e: e.voe, reverse=True):
        if used + e.wcet <= slack_ms and e.voe > 0:
            chosen.append(e); used += e.wcet
    return chosen, used

# IP-269 PRE：预注册 + α-spending
def preregistered_test(e, alpha_left):
    e.register(hypothesis=e.h, factor=e.f, obs=e.obs, stop_rule=e.rule)
    return sequential_test(e.result, alpha_left)

# IP-268 QCR：量化偏差（确定性但有偏）
def quant_bias(twin, o, obs_fn):
    return (obs_fn(twin.replay(o, factor_override={'quant': 'float_ref'}))
            - obs_fn(twin.replay(o, factor_override={'quant': 'fixed'})))

# IP-270 ACR：归因驱动响应（严格超集于 R69）
def respond(alpha, H_attr, M):
    if H_attr > TAU_H: return M.fluid.fallback()
    src = argmax(alpha)
    return {'perception': M.fluid.mint_ask, 'calibration': M.cof.recalibrate,
            'policy': M.fluid.explore_or_ask, 'interaction': M.fluid.disable_interaction,
            'quant': M.safety.widen_margin}.get(src, M.fluid.fallback)()

# IP-274 主闭环
def CONTRAST_RAS_round(M, obs):
    k, lam, st = M.fluid.round(obs)                  # 先跑 R69，安全底线
    if not M.nex.twin_is_faithful(M.twin, obs, M.obs_fn):
        return k, lam, st
    queue = M.ves.build(M.twin, obs, M.factors, M.budget.slack())
    deltas, spent = {}, 0.0
    for e in M.ves.schedule(queue, M.budget.slack())[0]:
        if not M.pre.admit(e): continue
        deltas.update(M.sfa.contrast(M.twin, obs, [e.factor], M.obs_fn)); spent += e.wcet
    alpha, H_attr = M.sfa.attribute(deltas, M.sens_matrix, M.prior)
    alpha = M.sfa.debias(alpha, M.qcr.quant_bias(M.twin, obs, M.obs_fn))
    resp = M.acr.respond(alpha, H_attr, M)
    M.eic.append(spent, alpha, deltas)
    return resp
```

## 4. 推导

**引理 19（确定性对比的可归因性）** DTE 位精确 + NEX（`P(Δ_null≤τ_null)≥1−δ`）下，`E[Δ|f] = effect(f) ± (q + τ_null)`；非确定性 GPU 路径的偏差为 σ_nd 量级。系：对比实验的合法性与硬件确定性成正比——嵌入式是对比实验的认识论前提。

**引理 20（非干涉与 WCET 隔离）** 孪生仅用 slack、无共享可变状态、`WCET(twin)≤B_slack` ⇒ 主路径 WCET 与截止期错失概率不变；实验只消耗 slack 机会成本。

**引理 21（p-hacking 放大与纪律上界）** n 次未登记自适应实验至少一次假阳性 `1−(1−α)^n → 1`；预注册 + α-spending + 留出确认后总假归因率 ≤ α。系：无预注册的对比实验是把确认偏误自动化。

**引理 22（量化偏差可辨识且不可忽略）** 确定性偏差 q 可由参考路径配对一致估计 q̂；但 q 被当作 0 时归因系统性偏向 quant 或掩盖真因子，故须显式建模并按 |q̂| 折减置信。

**引理 23（实验投毒的归因偏移上界）** 对比通道被额外偏移 δ_p 时，归因向量 L1 偏移 ≤ κ·δ_p（κ 为灵敏度矩阵条件数）；EIC + NEX + 多对照共同压回安全阈。

**定理 18（CONTRAST 严格包含 R69）** 孪生保真、slack 充足、归因显著时期望风险 ≤ R69；孪生失真/slack 不足/投毒/不显著时逐指令相同（定义 321）。R68 ⊂ R69 ⊂ R70，安全侧单调不弱。

**定理 19（归因收敛与响应效率）** `S` 满秩、对比覆盖全因子且满足 PRE 时，`H_attr` 随独立对比数指数下降，误响应期望损失 ≤ `C_max·e^{−c·k}`。系：多做正交对照买来响应正确率的指数提升，但前提是对照独立未投毒。

## 7. 本轮最大风险

**一句话**：CONTRAST-RAS 的全部归因押在「孪生是主路径的忠实确定性模型」上——**一旦存在隐藏非确定性（中断抖动、缓存、DMA 竞争、时钟漂移）或孪生悄悄分叉，受控实验就会混入一个未受控的第二变量；实验不是失败，而是给出一个看上去干净、实则被污染、且因「做过对照」而更被系统信任的错误病因——实验越严谨，错得越自信**。

**次级风险与缓解**：归因 p-hacking（预注册 + α-spending + 留出确认 + 引理 21）；实验投毒（EIC + NEX + 多对照 + 引理 23）；量化偏差被当 0（QCR + debias + 引理 22）；击穿实时预算（VES 装包 + slack 硬上限 + 放不下即丢弃 + 引理 20）；归因对但响应错（ACR 严格超集 + 无法映射即回退 + 响应过 C-RAS-WM 认证）。
