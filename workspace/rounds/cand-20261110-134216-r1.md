# 第 44 轮（新循环第 1 轮） · Instruct-Cert × Traj-Cert：把「语言指令」与「轨迹优化」纳入端到端可验证闭环（四层架构 v9）

> 承接第 43 轮 v8（Persona-Cert × Concurrent-Cert）。v8 解决了「谁（persona）」与「何时（并发/新鲜度）」，却把最上游、最日常的两个环节当作标称黑箱：**(H1) 语言指令被一次性解析成一个目标/代价**——歧义、欠指定、指代与常识缺口被悄悄抹平，机器人可能对「错误的规格」给出完美证书；**(H2) 轨迹优化被当作纯数值求解**——语言条件代价、STL/时序规约与连续时间执行之间的离散化缝隙没有任何 soundness 论证。本轮灵感词「语言指令」「轨迹优化」精确命中这两个假设：前者要求把「语言→形式规约」本身当作带统计覆盖保证的接地过程；后者要求把「优化出的离散轨迹→连续执行」的不确定性纳入证书。二者耦合处是本轮真正的新问题：**歧义集越大越安全但越保守/越不可行，歧义集越小越灵活但可能静默偏离真实意图**——这正是「语义 soundness 预算」与「轨迹可行性」的张力。若说 v8 管的是「谁 × 何时」，v9 管的是「意 × 行」。

## 0. 直觉与动机

**灵感 1（语言指令 → 「先承认歧义，再谈安全」）**：人类说「把那个红色的盒子放到桌子左边、别碰倒杯子」，其中「那个」「左边」「别碰倒」都依赖场景与常识。把它硬解析成一条 STL 公式，等价于**在没有任何覆盖保证的情况下押注一个 φ\***。正确姿态是：语言接地不是一个点，而是一个**带权规约集合** Ĝ^α(l)，它由共形预测保证「真实意图 φ\* 以 ≥1−α 的概率落在集合内」。安全不能建立在「解析正确」这个未证假设上，而应建立在「即使解析错，也有风险上界」上。一句话：**先承认歧义，再谈安全；歧义不是 bug，是可被度量与预算化的量**。

**灵感 2（轨迹优化 → 「证书必须覆盖连续时间，而不只是采样点」）**：轨迹优化器输出的是 t_0..t_N 的离散航点，控制器真正执行的是连续曲线。若只在采样点验证 STL 鲁棒度与 CBF 裕度，采样点之间可能已经越界。于是引入**轨迹管**：用动力学 Lipschitz 常数与加速度界算出相邻采样点之间的最大偏离 Δ(h)，只要离散鲁棒度 ρ_φ(ξ) ≥ Δ(h)、CBF 裕度 ≥ Δ(h)，连续执行就被证书覆盖。**轨迹优化不是求一条线，而是求一条带半径的管**；采样越密，管越细，保守性越低——这把「算力」变成可交易的「保守性」。

**灵感 3（耦合 → 「澄清也是一种受控动作」）**：当歧义集导致风险无法压到 β 以内、或目标不可行时，系统不该静默放行（不安全），也不该静默停机（不可用），而应**主动澄清**（「您说的是左边那个红盒，还是右边那个？」）。澄清不是免费对话：它消耗用户耐心（persona 契约里的交互预算），且等待期间机器人必须停在已认证的安全集内——因此澄清本身要有一条**受证的等待轨迹**，提问本身也是轨迹优化/实验设计问题（最大化信息增益）。

**耦合升级**：LIC（指令证书引擎）把自然语言编译成「歧义规约集 + 共形覆盖 + 风险预算 + 澄清策略」；TOC（轨迹优化证书器）在规约集上做鲁棒 STL 优化，并用轨迹管把离散解提升为连续时间证书；ILV（指令-轨迹验证器）在仿真里做释义不变性、反事实指令 fuzz、歧义覆盖与冲突检测，把反例回灌 CKB 与 SCV。四层架构由 v8 的「仿真-检索-边缘 + 人格 + 并发」升级为 v9 的「… + 指令证书层 + 轨迹证书层」，形成 **意（语言）→ 规约（证书）→ 行（轨迹管）→ 验（反事实）** 的闭环。

## 1. 形式化定义（增量：定义 44–49）

**定义 44（语言指令的歧义接地集与共形覆盖证书）**：设指令 l∈L，形式规约 φ∈Φ（STL/LTL 模板族，可含时序与安全谓词），接地分布 g(φ|l)。在校准集 D_cal={(l_i, φ\*_i)} 上定义非一致性分数 s(l,φ)（如语义嵌入距离 + 规约规范渲染距离）。共形 p 值 p_l(φ) = (1 + Σ_i 1[s(l_i,φ\*_i) ≥ s(l,φ)])/(n+1)。**歧义接地集** Ĝ^α(l) = {φ∈Φ_l : p_l(φ) > α}。在可交换性下 P(φ\*∈Ĝ^α(l)) ≥ 1−α。定义**语义分辨率** R(l)=|Ĝ^α(l)| 与歧义熵 H(Ĝ^α)。按动词类/场景类做 Mondrian 分层校准，避免「全局覆盖合格、单类覆盖崩坏」。**注**：Φ 取有限模板族，使 |Ĝ^α| 可枚举、可审计。

**定义 45（指令风险预算与端到端语言-轨迹 soundness 预算）**：对选定子集 S⊆Ĝ^α(l)，定义**指令风险** r(S)=P(φ\*∉S|l)。默认取 S=Ĝ^α 时由共形保证 r(S)≤α；若为提升可行性而删去部分非硬规约，则用留出校准集上的置信上界 r̂(S)+√(log(1/η)/(2n)) 作为 r(S) 的保守估计。**受证轨迹** ξ 需同时满足：(i) 安全 ξ⊨C_global，安全违例概率 ≤ δ；(ii) 指令 ∀φ∈S，ρ_φ(ξ) ≥ 0（STL 鲁棒度）；(iii) 风险 r(S) ≤ β。**组合引理**：P(ξ 违反真实意图 φ\*) ≤ r(S)+δ ≤ β+δ。**不可交易集** Φ_hard(l)⊆Φ_l（由安全本体识别，如「不得进入/不得接触/不得靠近边缘」）永远保留在 S 中，不参与风险交易。**推论**：语言接地误差与轨迹安全误差被显式分离、再加总，任何一环都不能被另一环的「高置信」掩盖。

**定义 46（澄清作为受控信息获取动作）**：设对 Φ 的信念 b（由 g 与对话历史更新），查询空间 Q（是/否、指认、排序、示范），观测 o∼O(·|q,φ\*)。**信息增益** IG(q)=H(b)−E_o[H(b′)]。**澄清策略** π(b)=argmax_{q∈Q_ans(Π_u)} IG(q)−λ_u·cost(q)，其中 Q_ans(Π_u) 受人格契约 Π_u（确认粒度、交互预算、语言能力）约束。**澄清证书**：至多 k 次查询后，要么得到 r(S)≤β 的可行 S，要么安全停机；且等待期间的「驻留轨迹」本身须由 TOC 出具安全证书（**安全澄清**：提问不得让机器人暴露于未认证状态）。

**定义 47（语言-轨迹语义 Lipschitz 鲁棒性）**：定义语义距离 d_L(l,l′)（嵌入距离 + 蕴含方向性）。令 ξ\*(l) 为受证最优轨迹。**释义不变性**：∀l′∈P(l)（保义改写集），dist(ξ\*(l),ξ\*(l′)) ≤ ε_inv。**语义可分性**：∀l′∈N(l)（否定/换位/量词等改义集），dist(ξ\*(l),ξ\*(l′)) ≥ ε_sep，或系统必须触发澄清/安全停机。二者合称**语义对比证书**：既防「换个说法就乱动」（过敏感），也防「不同意思却同一动作」（指令坍缩）。

**定义 48（连续时间轨迹管证书）**：轨迹优化输出采样步长 h 的离散轨迹 ξ。设加速度界 a_max、动力学 Lipschitz 常数 L_f、数值误差 ε_num，定义**管半径** Δ(h)=½·a_max·h²+L_f·h·ε_num。连续执行状态满足 dist(x(t), ξ(t)) ≤ Δ(h)。**管证书**：若 ∀φ∈S，ρ_φ(ξ) ≥ Δ(h)，且 CBF 裕度 ≥ Δ(h)，则连续执行同时满足指令规约与安全约束。**命题**：Δ(h)→0（h→0），故保守性可由采样率连续交易；管半径是空间版的「租约衰减 λ」，与定义 41 的时间版衰减同构。

**定义 49（多指令合取与最小让步证书）**：给定指令 l_1..l_m 及其子集 S_i、风险预算 β_i，**合取可行性**要求存在 ξ 使 ∀i、∀φ∈∪_i S_i 有 ρ_φ(ξ)≥0 且 Σ_i r(S_i) ≤ β_total。若不可行（含硬规约直接矛盾，如「向左」∧「向右」），输出**最小让步集**：选择代价最小的放松序列（删一条非硬规约 / 放宽一个 β_i / 请求仲裁），交用户或操作员确认；**绝不静默丢弃任一指令**。**命题**：若让步仅删除非硬规约且总风险仍 ≤β_total，则合取证书保持 sound。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 INSTRUCTION-CERT-ENGINE（指令证书引擎 LIC）
1. **规约族生成**：LLM/VLM 把 l 解析为有限 STL/LTL 模板族 Φ_l（含时序、空间关系、否定、量词），并做指代消解（「那个/那里」→ 感知实体）。
2. **共形接地**：按动词类/场景类做 Mondrian 分层校准，输出 Ĝ^α(l) 与逐规约 p 值、语义分辨率、歧义熵。
3. **风险预算选择**：在 S⊆Ĝ^α 上最小化估计任务代价 + λ|S|，约束 r(S)≤β；硬安全规约 Φ_hard 永不移除；默认回退 S=Ĝ^α（最大覆盖、最保守）。
4. **澄清策略**：风险不可达或不可行时，在 persona 交互预算内最大化信息增益地提问；k 次后仍不达标则安全停机。
5. **证书输出**：向 TOC 交付 (S, r(S), β, 覆盖保证, Φ_hard, 澄清历史)，全程可审计。

### 2.2 IP-61 TRAJECTORY-CERT-OPTIMIZER（轨迹优化证书器 TOC）
1. **鲁棒 STL 轨迹优化**：min J(ξ) s.t. min_{φ∈S} ρ_φ(ξ) ≥ Δ(h)、CBF 约束、动力学可行；用可微 STL 鲁棒度梯度求解，失败则采样/搜索回退。
2. **风险分配**：把 β 在规约间与时间轴上分配（Bonferroni/自适应），保证每条规约的鲁棒裕度覆盖其分配风险。
3. **连续时间管证书**：由 a_max、L_f、h 算 Δ(h)，按管膨胀障碍与 CBF 裕度（只收紧、不放松），把离散解提升为连续执行证书。
4. **证书化输出**：轨迹 + (ρ_min, CBF 裕度, Δ(h), 租约 ℓ)；不可行则返回 Infeasible + 最小让步候选给 LIC。
5. **安全优先的代价整形**：语言条件代价项只允许在**已受证轨迹集合内**做排序（tie-breaking），绝不进入或放松安全约束。

### 2.3 IP-62 INSTRUCTION-TRAJECTORY-VALIDATOR（指令-轨迹验证器 ILV）
1. **释义不变性测试**：LLM 生成保义改写 P(l)，测轨迹偏离 ≤ε_inv 且规约仍被满足，估计语义 Lipschitz 常数。
2. **反事实/对抗指令 fuzz**：最小改义编辑（否定、空间关系互换、量词替换），检查轨迹可分性 ≥ε_sep、无不安全执行、检出「指令坍缩」。
3. **歧义覆盖测试**：按动词/场景测条件覆盖；注入分布漂移（新环境/新物体），检验覆盖失效检测。
4. **澄清质量评估**：用带隐变量 φ\* 的模拟用户，测到达 β 所需查询数、成功率、用户负担，以及澄清期间是否发生安全违例。
5. **多指令冲突**：合成冲突/并发指令，验证冲突检出率、最小让步命中率、零静默丢弃。

## 5. 本轮最大风险

**一句话**：共形接地只保证在**校准指令分布**上的（分层）边际覆盖，遇到分布外改写或对抗语言可能静默失配；更危险的是「风险预算」会把一条听起来像偏好、实为安全关键的语言约束当成可交易成本删掉——因此必须把 Φ_hard 设为不可交易集，并将 E95/E96/E99 设为红线实验，默认回退到「全集鲁棒 + 受证澄清 + 安全停机」这条永不放行错误规格的底线。

## 2. 关键算法（伪代码）

### IP-60 LIC：共形接地、风险预算与澄清
```
def ground_instruction(l, scene, alpha, persona):
    cands = llm_parse_to_specs(l, scene)        # 有限 STL 模板族 Phi_l
    cands = ground_deixis(cands, scene)         # "那个/那里" -> 感知实体
    cat   = instruction_category(l)             # 动词类/场景类，Mondrian 分层
    q     = quantile(calib[cat], 1 - alpha)     # 分层秩统计阈值
    scores = {phi: nonconformity(l, phi) for phi in cands}
    Ghat  = [phi for phi in cands if scores[phi] <= q]
    pvals = {phi: conformal_pvalue(scores[phi], calib[cat]) for phi in cands}
    return Ghat, pvals, R=len(Ghat), H=entropy(pvals)

def select_spec_subset(Ghat, beta, task_ctx):
    S = set(Ghat)                               # 默认全集：覆盖最大、最保守
    for phi in sorted(Ghat, key=criticality):   # 先尝试删低关键
        if phi in SAFE_NONTRADABLE(task_ctx):   # 硬安全规约不可交易
            continue
        cand = S - {phi}
        if risk_upper(cand) <= beta and feasible_gain(cand, task_ctx) > 0:
            S = cand
    return S, risk_upper(S)

def clarify_if_needed(S, beta, persona, scene):
    if risk_upper(S) <= beta and feasible(S, scene):
        return None
    # 受证驻留：等待期轨迹必须已认证，提问不得暴露于未认证状态
    parking = certified_parking_trajectory(scene)
    q = argmax(q for q in Q_answerable(persona)
               if IG(q) - lambda_u * cost(q))
    return Clarify(q, parking)                  # k 次后仍不达标 -> safe_stop
```

### IP-61 TOC：鲁棒 STL 优化、风险分配与轨迹管
```
def certified_traj_opt(S, C_global, x0, goal, h):
    # 1) 连续时间管半径（只收紧、不放松）
    Delta = 0.5 * a_max * h**2 + L_f * h * eps_num
    C_safe = inflate(C_global, Delta)           # 障碍/CBF 裕度按管膨胀
    # 2) 多规约鲁棒 STL 优化，鲁棒裕度必须覆盖管半径
    xi = solve_min_cost(
            objective = J_task(xi),
            constraints = [min_phi rho_phi(xi) >= Delta,
                           CBF(xi) in C_safe,
                           dynamics(xi, x0, goal)])
    if xi is None:
        return Infeasible(minimal_concession(S))  # 交回 LIC 协商/澄清
    return CertifiedTrajectory(
        xi, rho_min=min_phi rho_phi(xi),
        cbf_margin=cbf_margin(xi), tube=Delta,
        lease=acquire_lease('toc', x0, theta, K_GEOMETRY))

def risk_allocate(beta, S):
    # 规约间/时间轴风险分配；硬规约不分配风险（必须 0 违例）
    soft = [phi for phi in S if phi not in SAFE_NONTRADABLE]
    return {phi: beta / max(1, len(soft)) for phi in soft}

def shape_cost_language(xi_set, l):
    # 语言只影响“已受证集合内”的排序，绝不进入/放松安全约束
    return argmin(xi in xi_set, key=lambda xi: J_task(xi) + lambda_l*lang_cost(xi,l))
```

### IP-62 ILV：释义、反事实、覆盖与冲突
```
def validate_instruction_trajectory(l, xi, Ghat, alpha):
    # 释义不变性：换说法不应乱动
    P = paraphrase(l)
    dev = max(dist(xi, traj(lp)) for lp in P)
    assert dev <= eps_inv
    # 改义可分性：否定/换位/量词必须改变动作，否则触发澄清或停机
    N = contrastive_edits(l)
    sep = min(dist(xi, traj(ln)) for ln in N)
    assert sep >= eps_sep or triggered_clarify_or_stop()
    # 条件覆盖与漂移
    cov = conditional_coverage(Ghat, instruction_category(l))
    assert cov >= 1 - alpha - tol, "coverage failure -> tau/trust fallback"
    return Certificate(dev, sep, cov)

def compose_instructions(instructions):
    S_all = union(S_i for each) ; risk = sum(r(S_i))
    if infeasible(S_all) or risk > beta_total:
        # 硬规约矛盾（如“向左”∧“向右”）-> 必须澄清/仲裁
        return minimal_concession(instructions)   # 绝不静默丢弃
    return S_all, risk

def conflict_and_collapse_audit(log):
    return detect(silent_drop(log), instruction_collapse(log),
                  coverage_drift(log), unsafe_during_clarify(log))
```

### IP-51/52/53 升级：规约与鲁棒度感知的守卫栈
```
def car_transition_guard(e, x, cert_obj, persona, lease, S, t):
    theta   = cert_obj.alpha_e[e] * cert_obj.theta_sim[e]
    m_lookup = cert_lookup_L0(x).m_lo[e]
    m_lease  = lease.m - lease.lam * (t - lease.tau)
    m_cap    = persona_cap[e](persona)
    rho_ok   = min_phi rho_phi(x, e) >= Delta(h)      # STL 鲁棒度覆盖管
    risk_ok  = risk_upper(S) <= beta                  # 指令风险预算
    return (min(m_lookup, m_lease, m_cap) >= theta
            and lease_valid(lease, theta, t) and rho_ok and risk_ok)

def certify_light_v4(x, guards, persona, S, budget_us, criticality):
    b = cert_lookup_spec(x, S); lease = acquire_lease('lcs', x, theta, criticality)
    U = undecided_guards(b, guards)
    if not U and lease_valid(lease, theta, monotonic_now()):
        return b, lease, -1
    if budget_us < 110 or criticality < K_GEOMETRY:
        return downgrade_monotone(b), lease, -1
    status, margin = monitor_step_INT8(quantize_obs(x))
    b.m_lo = min(b.m_lo, margin)
    rho = stl_robustness_monitor(x, S)                 # 在线鲁棒度
    return (b, lease, 0) if not U and rho >= Delta(h) else (downgrade_monotone(b), lease, 0)
```

| E98 澄清效率 | 到 β 查询数；成功率；用户等待；澄清期违例 | ≤2 次；≥95%；<5s；0 起 |
| E99 释义/对抗鲁棒 | 保义偏离；改义可分性；对抗不安全率；坍缩检出率 | ≤ε_inv；≥ε_sep；0；≥95% |
| E100 歧义-保守前沿 | 成功率 vs |S|；对单规格/全集基线 Pareto；同风险提升 | ≥10pp |
| E101 多指令冲突 | 冲突检出；最小让步命中；静默丢弃；仲裁时延 | 100%；≥90%；0；<2s |

回退：E95 覆盖失效 → 收缩闭集模板 + 强制澄清；E96 不达标 → β→0 全集最保守 + 安全停机；E97 管不 sound → 提高采样率/降速；E98 澄清过贵 → 仅高置信指令，否则停机；E99 坍缩 → 冻结指令集/白名单；E100 无收益 → 默认全集鲁棒；E101 冲突 → 单一活跃指令仲裁排队；任何红线失败 → 全链路熔断回退 v20。

## 6. 本轮最大风险

**一句话**：共形接地只保证在**校准指令分布**上的（分层）边际覆盖，遇到分布外改写或对抗语言可能静默失配；更危险的是「风险预算」会把一条听起来像偏好、实为安全关键的语言约束当成可交易成本删掉——因此必须把 Φ_hard 设为不可交易集，并将 E95/E96/E99 设为红线实验，默认回退到「全集鲁棒 + 受证澄清 + 安全停机」这条永不放行错误规格的底线。
