# 第 14 轮（本轮灵感：「视觉定位」×「6D位姿估计」）

> **基线**：第 13 轮 MetricVoiceGauge-NCD-HUTD（定义 583–594；引理 113–121；实验 E627–E646）。
> 本轮纪律：**先证观测，再证动作；感知歧义只能被感知消除，不能被算力消除；位姿证书只在任务商上成立**。不推倒 v13：v13 的 AIO/RTIC、CPD/DGC、DDL、RTCR 与 v12 的 USG/TGC/BAA/GAGP/UC、v11 的 HAS/HCC/HATD/HDT、v10 的 NGE/DSL/CC/CWM/CAE/NCP、v9 的 AC/MW/ID、v8 的 DA/SPR/Cal 及九不变式全部保留。四个新端口——HALO/ALC（别名感知定位）、TPC/SQG（任务投影 6D 位姿证书与对称门）、FGC（帧图证书）、PACR（感知感知路由器）——一律以**中立元**接入，失效即严格退回 v13（引理 129），再沿 v13 退化链退回 v12/v11/v10/v9/v8/v7/v6。本轮只做三件事：把“位姿输入”改写为“带别名状态的可信集”、把“6D 位姿误差”改写为“任务投影误差 + 可商对称性”、把 v13 的一维时限阶梯扩成“时间 × 感知”的二维授权格。

## 0. 直觉与动机

### 灵感 1（视觉定位 → 可信集、别名证书与“负证据”）

v13 的实时层默认“位姿由上游视觉给出”，然后把毫秒、蒸馏间隙和安全余量都建在这个位姿上。问题在于：**视觉定位的错误不是高斯尾巴，而是多模态假确定性**。重复房间、对称走廊、相同家具、动态遮挡和 kidnapped robot 都会让后验出现多个任务上完全不同的模态；此时一个点估计加协方差会把“我在两个完全不同的地方”压成一个看似很小的椭圆。更糟的是，增加特征、增加匹配、增加计算，往往会让错误模态的绝对置信度更高——**证据越多，错得越自信**。

所以本轮第一个反直觉点：定位证书不能只证明“我对当前模态有多确定”，还必须证明“**没有另一个任务上不同的模态被漏掉**”。前者是正证据，后者是负证据。我们要求证书同时携带可信集 `C_loc`、任务可分间隙 `Δ_loc`（第一名与第二名的对数似然差）和别名状态；只报点估计、或只报边缘协方差的输入，在 v14 中一律不可作为自主授权依据。

第二个反直觉点：并非所有定位歧义都危险。若两个模态对应的动作、接触效果与安全谓词完全相同，则它们在**任务商**上是同一个点，歧义是良性的。真正要拒绝的是“任务可分但观测不可分”的别名。于是我们把安全条件从“单模态”放宽为“**任务等价类内单模态**”，既避免无谓的活动性损失，又不在薄边界上放行。

### 灵感 2（6D 位姿估计 → 任务投影证书与对称门）

6D 位姿的通常指标是 ADD/ADD-S 或平均旋转误差，但这些指标与操作安全并不对齐：抓一个圆柱时绕轴旋转可能无关紧要，抓一个带手柄的杯子时同样的绕轴旋转却是致命的；放置任务关心的是接触面法向和落点，而不是物体背面某个点的误差。平均误差可以在大量容易样本上很好看，却在一条极薄的接触边界上把“不可抓”判成“可抓”。

因此 6D 位姿证书不能是一个各向同性的 `SE(3)` 球，而应是**任务投影误差**下的可信包络：只约束对该技能的安全谓词、接触效果和值函数真正有影响的自由度。关键创新是**对称商门（SQG）**：只有当技能的安全谓词与接触效果在某个对称子群 `G_τ` 下不变时，才允许把该子群商掉；若任务对某个对称方向敏感，则 `G_τ={e}`，宁可多要样本、多要余量，也不把错误朝向藏进商里。对称性在这里不是免费的先验，而是**必须由任务证书背书的许可证**。

第三个反直觉点：对称性估计本身也可能错。把物体误判为“连续旋转对称”会让一个完全错误的姿态在商度量下误差为零；因此我们要求对称类也进入校准与支撑条件，且任何未被任务不变性验证的商都视为无效。商的收益是样本效率与紧致性，代价是必须证明“商掉的自由度确实不影响任务”。

### 灵感 3（融合 → 帧图证书与“时间 × 感知”二维授权格）

实际控制用的不是“地图系位姿”或“物体系位姿”中的任何一个，而是复合变换 `T^{ee}_{obj}=T^{ee}_{base}T^{base}_{map}T^{map}_{obj}`。地图定位误差与 6D 位姿误差可能来自同一批视觉特征、同一张地图、同一次标定漂移，因而**共享共同模态**；把两者的边缘覆盖相乘，等于偷偷假设独立，最坏情况下会严重高估联合覆盖。更隐蔽的是误差可能“碰巧抵消”：地图把物体估计偏左、位姿把它估计偏右，复合后看起来正确；但安全不能建立在偶然抵消上，除非抵消本身被留出集认证。于是本轮第三个组件是**帧图证书（FGC）**：在帧图上做联合校准或共同模态膨胀，明确禁止“边缘相乘 + 假设独立”。

最后，v13 的授权阶梯只有“时间”一个轴：时间越紧，沿学生阶梯向更保守的档位塌缩。感知歧义引入了第二个轴：**感知档位**。算力再多也不能把“两个任务不同的地方”变成“一个地方”，因为算力没有获得新观测；只有主动感知（换视角、重定位、必要时用接触探测）才能提高感知档位。于是 v14 把授权做成二维格 `Acc_{i,j}`：`i` 是 v13 的时间/蒸馏档，`j` 是感知证书档；两个方向都单调，任一方向失效都只能向更保守方向塌缩。路由器 PACR 的职责不是“用更多算力硬解歧义”，而是判断**这一帧的毫秒应该花在更高的学生档，还是花在买一个能提高感知档的新观测**；当两者都不划算时，执行认证回退或 `a_ask`。

### 三者如何统一

v13 是“语义层 + 实时实现层”：它回答“在给定位姿与毫秒预算下，哪些动作被允许、能安全实现多少”。v14 在它前面插入一个**信念层**：回答“哪些位姿/物体位姿集合是可信的，因而 v13 的授权在整个可信集上还剩下多少”。形式化地，v14 的执行集是

```
Exec_v14 = ⋂_{ξ∈C_t} Exec_v13(ξ)  ∩  FGC 有效  ∩  v13 四预算约束
```

其中 `ξ=(g,θ)` 同时包含机器人定位与物体 6D 位姿。HALO 给出 `C_loc` 与别名状态，TPC 给出任务投影位姿包络，FGC 给出复合变换的联合证书，PACR 在二维格上选档并在必要时选择主动感知。四者只做“缩小可信集/收紧授权/选择实现”的事，绝不新增 v13 未允许的动作。**HALO 回答“我在哪里、还有没有另一个我”，TPC 回答“这个物体在任务相关的意义上在哪里”，FGC 回答“这些‘哪里’复合后还可信吗”，PACR 回答“这一帧的值不值得花时间去看清楚”**。

## 1. 研究问题（轮次升级版）

- **Q1（定位证书的可证语义）**：如何定义“任务上单模态”的可信集，使别名排除既可证又不至于把良性歧义全部判死？负证据间隙 `Δ_loc` 在重复结构、动态遮挡、地图陈旧时如何校准？被动观测无法区分两个观测等价地点时，证书应如何显式降级为 `AMBIG` 而不是给出假确定？
- **Q2（6D 位姿证书与对称商）**：如何定义任务投影误差，使证书恰好覆盖接触安全真正敏感的自由度？对称子群 `G_τ` 的可商条件如何与 v13 的接触/谐波证书对齐？对称类误判、遮挡、透明/反光物体下，共形覆盖如何分层校准而不被尾部击穿？
- **Q3（帧图与二维路由）**：边缘证书在共享视觉特征/共同标定漂移下如何合成联合证书？共同模态膨胀 `κ` 如何校准而不退化为无穷保守？二维格上“时间档”和“感知档”的边际收益如何比较，主动感知的值信息（VoI）如何扣除其运动风险与时间成本？
- **Q4（与 v13 的兼容与活性）**：HALO/TPC/FGC 是否可能被学生模型绕过，或在 DGC 已经保守的情况下叠加出过度假拒绝？二维塌缩到 `(0,0)` 时是否会清空可行集、导致频繁 `a_ask`？新增证书能否守住 50Hz/p99≤22ms，并严格退回 v13？

## 2. 设计原则（在 P22–P24 基础上新增 P25–P28）

**P25 观测先证律（Certify Observation Before Action）**
任何用于自主授权的位姿输入必须携带感知证书：可信集、覆盖概率、任务直径、别名/多模态状态、支撑域与可复现证据。点估计、单边缘协方差、无支撑外推的位姿一律不可作为授权依据；无证书时只能走 v13 已有的回退、`a_ask` 或认证的主动感知。

**P26 任务商最小律（Minimal Task Quotient）**
只有在技能的安全谓词、接触效果签名与值函数对该变换不变时，才允许商掉相应的定位别名或物体对称自由度；不确定时取最小群 `{e}`。不得用“平均误差小”“对称物体通常如此”之类的先验替代任务不变性证明；不得把未被认证的误差抵消当作收益。

**P27 感知—算力不可替代律（Perception Cannot Be Bought by Compute）**
同一观测下的认知歧义不能靠增加枚举、增加学生档或增加谐波推演来消除；算力只能细化“每个模态内部”的授权，不能消除“模态之间”的任务可分性。感知档位的提升必须来自新观测或新动作；二维格必须对时间与感知分别单调，任一轴失效只允许沿该轴向更保守方向塌缩。

**P28 共同模式不独立律（Common-Mode Non-Independence）**
帧图各边的误差可能共享地图、特征、标定与时序潜因子；禁止把边缘覆盖概率直接相乘当作联合覆盖。联合证书必须来自联合校准，或对共同模态做显式的保守膨胀 `κ`；任何“误差会抵消”的假设都必须有留出集上的覆盖证据，否则按最坏相加处理。

## 3. 与基线的接口（如何退化）

- HALO 失效 ⇒ 直接使用 v13 的定位输入 `ĝ_v13`（`C_loc={ĝ_v13}`，无别名检查），**等价 v13 定位路径**；
- TPC 失效 ⇒ 直接使用 v13 的 6D 位姿输入 `θ̂_v13`（`ρ=0, G_τ={e}`，无任务投影/对称商），**等价 v13 位姿路径**；
- FGC 失效 ⇒ 使用 v13 既有的变换链与误差处理，不做联合校准/共同模态膨胀，**等价 v13 帧处理**；
- PACR 失效 ⇒ 由 v13 的 RTCR/静态调度器按固定顺序选档，感知证书仅作事后否决，**等价 v13 调度路径**；
- 四者全失效 ⇒ MetricVoiceGauge-NCD-HUTD v13，再沿 v13 退化链退回 v12/v11/v10/v9/v8/v7/v6；
- **安全继承**：HALO 只缩小可信集、TPC 只收紧位姿包络、FGC 只收紧复合变换、PACR 只在二维格中选档；四端口均不能新增授权或放宽 v13 的任何阈值，`Exec_v14⊆Exec_v13` 由引理 128 保证。

## 4. 预期贡献

1. **别名感知的定位证书**：把视觉定位从“点估计 + 协方差”改写为“可信集 + 负证据间隙 + 任务等价类”，解决重复结构下“越匹配越自信地错”的结构性问题，并给出被动观测不可区分时的显式降级语义；
2. **任务投影 6D 位姿证书**：把 6D 误差从各向同性 `SE(3)` 球改写为任务投影包络，用对称商门把“可商的对称性”与“任务敏感的对称性”分开，避免平均指标掩盖薄接触边界错误；
3. **帧图联合证书**：显式处理地图/基座/物体/夹爪之间的共同模态与误差抵消，给出不依赖独立假设的复合覆盖界，填补“边缘证书无法直接合成”的空白；
4. **时间 × 感知二维授权格与主动消歧**：把 v13 的一维时限阶梯扩展为二维单调退化格，证明算力不能替代感知，并给出以毫秒和运动风险计价的 VoI 路由；E647–E666 覆盖覆盖性、别名压力、对称反例、帧图合成、二维塌缩与端到端消融。

## 5. 本轮最大风险

**一句话**：HALO/TPC/FGC 的可靠性都以“地图与物体模型仍然有效、部署分布落在校准支撑内、且任务不变性判断正确”为前提；当场景同时发生地图漂移、强遮挡与对称类误判时，三个证书会相互“背书”出一个任务上错误却处处显示为已认证的位姿，而二维格会把这种认知错误表现为“按时、在授权子集内、却抓错了物体/方向”的安全决定。

| ALC=(C_loc,ĝ*,Δ_loc,α_loc,α_amb,supp_loc) | 别名感知定位证书；`Δ_loc` 为任务可分负证据间隙 |
| TPC_τ=(P̂,E_τ,ρ_τ,G_τ,α_pose,supp_pose) | 任务投影 6D 位姿证书；`E_τ` 为任务投影包络 |
| G_τ | 允许商掉的对称子群（经 SQG 验证任务不变性；不确定时 `{e}`） |
| FGC=(T̂,C_comp,δ_F,κ,supp_F) | 帧图联合证书；`κ` 为共同模态膨胀 |
| Acc^rob(C_t) | 鲁棒授权集 `⋂_{ξ∈C_t} Exec_v13(ξ)` |
| Acc_{i,j}(C_t) | 二维授权格：时间档 `i`、感知档 `j` |
| j*(PC_t) | 感知档：满足质量级别 `j` 的最大档 |
| ζ_vp=(B_time,B_safe,B_infer,B_obs,i*,j*,C_t,PC_t,mode,drift,VoI) | v14 路由共享状态 |
| B_transfer,B_distill,B_obs | 迁移、蒸馏、观测/校准预算；与 v13 的 `B_time` 一并不可挪用 |
| U,V(PC),VoI(u) | 主动感知动作集、证书价值、单位时间值信息 |
| P^rt | v13 的实时安全回退集（定义 590），v14 沿用并要求主动动作也在其中 |

**定义 595（任务观测商 Task Observation Quotient）** 记技能族 `τ` 的候选动作集为 `A_τ`。对 `ξ,ξ'∈Ξ`，定义
```
ξ ~_τ ξ'  ⇔  ∀a∈A_τ :
    Cert_{v13}(ξ,a) = Cert_{v13}(ξ',a)
    Eff_{v13}(ξ,a)  = Eff_{v13}(ξ',a)          # 接触扳手类/运动锥/效果签名
    |value(a|ξ) − value(a|ξ')| ≤ ε_v
```
其中 `Cert_{v13}` 是 v13 的四重证书合取（物理/接触/谐波/规范 + gap），`Eff_{v13}` 是 v13 的效果签名。商空间 `Ξ_τ = Ξ/~_τ`；**任务可分模态**是 `Ξ_τ` 中不同的等价类。若两个位姿只在任务不敏感的自由度上不同，则它们属于同一任务类，视觉歧义是良性的；若属于不同任务类，则是必须排除或显式降级的别名。任务伪度量
```
d_τ(ξ,ξ') = min_{g∈G_τ} d_task(ξ, g·ξ')
```
只度量任务真正敏感的自由度，`G_τ` 由定义 598 的 SQG 许可证决定。

**定义 596（感知证书 Perception Certificate）**
```
PC_t = ( C_t, α_p, d_max, M_t, supp_t, Ĉ_t )
```
有效当且仅当：
1. **覆盖**：在校准与部署可交换、部署落在 `supp_t` 内的条件下，`P(ξ_t∈C_t) ≥ 1−α_p`；
2. **任务直径**：`sup_{ξ,ξ'∈C_t} d_τ(ξ,ξ') ≤ d_max`；
3. **模态图**：`M_t: C_t→{UNI, AMBIG}`；`UNI` 表示 `C_t` 至多与一个任务可分模态相交；`AMBIG` 必须列出所有相交的任务类，且下游只允许鲁棒交集动作；
4. **支撑**：`supp_t` 是地图区域/物体类/遮挡层的显式集合；`ξ∉supp_t` 时证书无效，不得外推；
5. **可复现证据**：`Ĉ_t` 含定位假设分数、几何内点数、对称类、帧图残差等审计记录；证据不可复现的证书视为无效。
`PC_t` 是 HALO/TPC/FGC 的公共上位结构；三个模块分别给出它的定位、位姿与帧图特化。

**定义 597（别名感知定位证书 Aliasing-Aware Localization Certificate）**
```
ALC_t = ( C_loc, ĝ*, Δ_loc, α_loc, α_amb, supp_loc )
```
其中 `Δ_loc` 是**任务可分负证据间隙**：若第一名模态为 `[ĝ*]_τ`，则
```
Δ_loc = log p_(1) − log p_(2)
```
`p_(1),p_(2)` 为按任务类聚合后的前两名后验质量（同一任务类内的多峰先合并）。`ALC` 有效当且仅当：
1. `P(g_t∈C_loc) ≥ 1−α_loc`；
2. **别名排除**：`P(∃ 任务可分模态 [g']_τ≠[ĝ*]_τ 且 Δ(g',ĝ*)<τ_amb) ≤ α_amb`；若不成立，必须令 `M_t=AMBIG`，不得输出单模态证书；
3. `C_loc` 可为非高斯并集；其任务直径满足 `sup d_τ ≤ d_loc,max`；
4. `supp_loc` 为地图中具有足够视觉签名的可观测区域；重复结构区、动态遮挡区、地图未覆盖区必须显式降级；
5. **被动不可区分语义**：若两个地点在传感器模型下被动观测等价，任何被动证书都无法区分；此时只能 `AMBIG` 或走主动消歧（定义 603），不得用更高匹配分数伪造确定性。
关键点：证书盯的是**任务可分模态之间的间隙**，不是绝对匹配置信度；增加特征可能同时抬高两个模态，若间隙不增，证书不应变强。

**定义 598（任务投影 6D 位姿证书 Task-Projected Pose Certificate）**
```
TPC_τ = ( P̂, E_τ, ρ_τ, G_τ, α_pose, supp_pose )
E_τ = { θ : d_τ(θ,P̂) ≤ ρ_τ }
```
有效当且仅当：
1. **覆盖**：按物体类、对称类、遮挡层/透明层/反光层分层校准后，`P(θ_t∈E_τ) ≥ 1−α_pose`；
2. **任务投影**：`d_τ` 只包含该技能 `τ` 的接触安全敏感自由度；`E_τ` 可为并集，若并集跨任务可分模态则标 `AMBIG`；
3. **对称商门（SQG）**：`G_τ` 必须满足
```
∀g∈G_τ, ∀a∈A_τ :
    Cert_{v13}(ξ 以 θ←gθ, a) = Cert_{v13}(ξ 以 θ, a)
    Eff_{v13}(ξ 以 θ←gθ, a) = Eff_{v13}(ξ 以 θ, a)
    value(a|ξ 以 θ←gθ) = value(a|ξ 以 θ)
```
不满足时 `G_τ={e}`；若对称类本身不确定，取已验证不变子群与 `{e}` 的交（默认 `{e}`），**不确定即不商**；
4. **分层支撑**：`supp_pose` 记录物体实例/类别、可见面比例、材质层；重遮挡、透明、强反光、未见过实例必须单独校准或降级；
5. **紧致性义务**：`ρ_τ` 不得超过任务允许的最大位姿余量 `ρ_max(τ)`；超出时不是“更安全”，而是“不可执行”，必须走主动视角/回退。
对称性不是免费先验：只有当任务对某个方向**确实不敏感**时，商掉它才是可靠的；否则商会把错误朝向藏起来。

**定义 599（帧图证书 Frame-Graph Certificate）** 构造函数图
```
G_F = ( V, E ),  V = {map, base, obj, ee}
T^{ee}_{obj} = T^{ee}_{base} · T^{base}_{map} · T^{map}_{obj}
```
每条边 `e` 携带边缘证书 `(T̂_e, ρ_e, δ_e, supp_e)`。复合证书
```
FGC = ( T̂, C_comp, δ_F, κ, supp_F )
C_comp = { T : d_SE3(T, T̂) ≤ ρ_comp },   ρ_comp = Σ_e ρ_e + κ
```
有效当且仅当：
1. **联合覆盖**：`P(T^{ee}_{obj} ∈ C_comp) ≥ 1−δ_F`；
2. **共同模态膨胀**：`κ ≥ 0` 由留出集上 `| d_SE3(T_comp,T̂_comp) − Σ_e d_SE3(T_e,T̂_e) |` 的保守上分位校准；`κ` 必须覆盖共享地图/特征/标定漂移造成的共同模态，**不得用独立性假设把 `κ` 置零**；
3. **边缘有效**：所有 `(T̂_e,ρ_e,δ_e)` 在各自支撑内有效；任一边失效则 FGC 无效；
4. **环路一致**：若存在运动学/触觉/二次视觉的帧图环路 `T^{ee}_{obj,loop}`，要求 `d_SE3(T̂, T^{ee}_{obj,loop}) ≤ ρ_F`；否则标 `INCONSISTENT`，不得用其中一个“看起来更好”的变换覆盖另一个；
5. **禁止未认证抵消**：允许 `T_comp` 误差小于各边误差之和，但只有在留出集上认证了抵消模式后才可缩小 `C_comp`；否则一律按最坏相加。
特别地，边缘覆盖概率**不能**直接相乘：`P(∩E_e) ≥ max(0,1−Σδ_e)` 是最坏下界，任何优于该下界的声明都需要联合校准证据。

**定义 600（鲁棒授权 Robust Authorization）**
```
Acc^rob(C_t) = ⋂_{ξ∈C_t} Exec_v13(ξ)
value^rob(a|C_t) = min_{ξ∈C_t} value(a|ξ)
```
`Acc^rob(C_t)` 是“对整个可信集都安全”的动作集合；若为空，则不存在可自主执行的动作，只能 `a_ask`、认证回退或主动感知。注意：这是**全称量化**而非期望；歧义状态下允许的动作会变小，这是歧义的正确价格。若 `C_t` 标 `AMBIG`，`Acc^rob` 自然退化为各任务类授权的交集，禁止只对最可能模态优化。

**定义 601（时间 × 感知二维授权格 Two-Axis Authorization Lattice）** 设时间档 `i=0..m`（v13 的学生/教师阶梯），感知档 `j=0..k`（证书质量级别，`j` 越大覆盖越强、任务直径越小、别名概率越低）。定义
```
Acc_{i,j}(C_t) = { a : ∀ξ∈C_t, a∈Acc^{v13}_{i}(ξ) }  ∩  { PC_t 满足级别 j }
Acc_{i,j} ⊆ Acc_{i+1,j},    Acc_{i,j} ⊆ Acc_{i,j+1},    Acc_{i,j} ⊆ Exec_v13
```
`j=0` 表示无有效感知证书（只允许回退/`a_ask`）；`j=k` 表示最强的联合感知证书。时间档 `i` 增加依赖更多计算，感知档 `j` 增加依赖更多/更好的观测与校准；二者是不同货币。
```
j*(PC_t) = max{ j : PC_t 满足级别 j }
i*(B,PC_t) = max{ i : w_i ≤ B_time − B_safe − B_percept , Acc_{i,j*(PC_t)}(C_t) ≠ ∅ }
```
若不存在非空 `(i,j)`，只能主动感知或回退；不得用更大的 `i` 假装提高了 `j`。

**定义 602（感知感知路由器 PACR 的状态与策略）**
```
ζ_vp = ( B_time, B_safe, B_infer, B_obs,
         i*, j*, C_t, PC_t, mode, drift, VoI )
mode ∈ {track, relocalize, active-disambiguate,
        multi-hypothesis-safe, teacher-only, fallback}
```
选择规则：
1. `PC_t` 为 `UNI` 且 `Acc_{i*,j*}≠∅` ⇒ `track` 或 `speculate-verify`；
2. `PC_t` 为 `AMBIG` 但 `Acc_{i*,j*}≠∅` ⇒ `multi-hypothesis-safe`，只执行 `value^rob` 最优的鲁棒动作；
3. `PC_t` 为 `AMBIG` 且存在高 VoI 的安全主动动作 ⇒ `active-disambiguate`；
4. 地图/物体模型失效、漂移或 `PC_t` 超出支撑 ⇒ `relocalize` 或 `fallback`；
5. 只能教师完成 ⇒ `teacher-only`（仍受 v13 anytime 与 RTIC 约束）。
执行策略
```
π_vp(x;B,PC_t) = argmax_{a∈Acc_{i*,j*}(C_t)} value^rob(a|C_t)
```
且要求对所有 `ξ∈C_t`，`π_vp(x;B,PC_t)∈Exec_v13(ξ)`；若 `Acc_{i*,j*}=∅`，`π_vp∈P^rt` 或 `a_ask`。

**定义 603（主动感知与值信息 Active Perception / VoI）** 主动动作集 `U` 包含换视角、重定位、移动基座、接触探测等。`u∈U` 可行当且仅当
```
u ∈ P^rt ,   w(u) ≤ B_percept ,   P(safe(u)) ≥ 1−α_act
```
其值信息定义为
```
VoI(u) = ( E_{z∼p(·|u)}[ V(PC_{t+1}) ] − V(PC_t) )
         / ( w(u) + λ_r·risk(u) + λ_m·motion(u) )
V(PC) = max_{a∈Acc^rob(C)} value^rob(a|C)   （空集时为 0）
```
仅当 `VoI(u) ≥ ν_min` 时执行主动消歧；若 `VoI<0` 或没有安全主动动作，回退优于“为了看清而冒险”。值函数 Lipschitz 为 `L_V` 时，`E[V(PC')−V(PC)] ≤ L_V·I(ξ;z|u)`：主动感知的收益受互信息上界约束，不能被算力凭空创造。

**定义 604（四预算不可挪用 Four-Budget Non-Fungibility）** 在 v13 定义 593 的基础上增加观测/校准预算 `B_obs`：
```
B_total = B_transfer + B_distill + B_obs
B_time  = B_safe + B_infer
B_infer = B_pose + B_rest
B_percept ⊆ B_pose
```
`B_transfer` 是迁移间隙预算，`B_distill` 是蒸馏间隙预算，`B_obs` 是感知校准与主动观测容量（覆盖 `α_p`、`d_max`、别名支撑），`B_percept` 是在线感知时间片。四者不得互相冲抵：地图漂移不能用蒸馏预算买单，感知歧义不能用算力档位买单，主动观测不能挪用安全切片 `B_safe`。任一预算耗尽时，唯一允许的动作是更保守档位、`a_ask` 或认证回退。

**定义 605（感知执行策略与语义保持）** v14 的执行集为
```
Exec_v14 = { a : a ∈ Acc_{i*(B),j*(PC)}(C_t)
                 ∧ FGC 有效
                 ∧ v13 物理/接触/谐波/规范/gap 证书有效
                 ∧ U_gap + U_dis + U_obs ≤ B_total
                 ∧ P^rt ≠ ∅ }
```
其中 `U_obs` 是感知证书的误差上界（定位/位姿/帧图联合）。要求 `Exec_v14 ⊆ Exec_v13`，且 `π_vp` 在所有 `ξ∈C_t` 上都是 v13 语义下的合法动作。HALO/TPC/FGC 只在**上游缩小可信集**；PACR 只在**下游选择实现**；没有任何端口能放宽 v13 阈值。

**定义 606（中立元表 v14 扩展）**

| 新组件 | v^⊥ | 等价退化点 |
|---|---|---|
| HALO/ALC | `C_loc={ĝ_v13}`，无别名检查，`Δ_loc=∞`，直接用 v13 定位输入 | Level-4（v13 定位路径） |
| TPC/SQG | `P̂=θ̂_v13`，`ρ≡0`，`G_τ={e}`，任务投影退化为恒等，无新增限制 | Level-3（v13 位姿路径） |
| FGC | 使用 v13 既有变换链，无联合校准/`κ`，不做环路检查 | Level-2（v13 帧处理） |
| PACR | v13 的 RTCR/静态调度顺序，感知证书仅事后否决，不做二维选档/主动消歧 | Level-1（v13 调度路径） |

中立元是**相对等价**：它复现 v13 的行为（包括 v13 对位姿输入的信任），不宣称绝对安全；若要绝对安全，必须四个端口都激活并保持证书有效。

## 2. 形式化升级（要点）

**升级定义 582/592（选择目标）** 在 v13 的 `−λ_time·E[latency]−λ_ask·E[false_reject]` 之外增加 `−λ_obs·U_obs` 与感知约束：
```
max_g E[Progress(g)]
    − λ_risk·(U_gap+U_dis+U_obs)
    − λ_time·E[latency(g)] − λ_ask·E[false_reject(g)]
s.t. v11/v12/v13 证书全部有效；FGC 有效；P^rt≠∅
     Acc_{i,j}(g)⊆Exec_v13；U_gap+U_dis+U_obs≤B_total
```
感知误差与迁移/蒸馏误差并列进入同一风险项，但预算账户保持分离。

**升级定义 571/583（技能与随时算子）** v13 的 HAS/HCC/HATD/HDT、AIO/RTIC、CPD/DGC、DDL、RTCR 原样保留；HALO/TPC/FGC 只改写这些模块的**位姿输入**与**可信集**，不改变技能语义、绑定、效果签名或前后置条件。AIO 的 anytime 阶段可以在 `C_t` 上做鲁棒扩张：每个新阶段加入的动作必须对所有 `ξ∈C_t` 仍然被 v13 认证。

**升级定义 579/590（中止点与回退）** v13 的 `P^rt` 保留，并要求：
```
P^rt(C_t) ≠ ∅  ⇔  ∃π_f∈Exec_v13 : ∀ξ∈C_t, π_f 在 ξ 下安全且可在本帧完成
```
若 `C_t` 为 `AMBIG` 且鲁棒回退集为空，则必须 `a_ask`；不得挑一个“最可能模态”的回退。

**升级定义 531（软硬约束衔接）** v13 的物理/接触/谐波/规范硬检查不变；“定位别名未排除”“位姿包络超 `ρ_max`”“帧图不一致”“观测预算耗尽”进入**执行门**（不可自主执行），不是物理硬违规。物理硬违规的定义由 v13 保持。

**升级定义 580（中立元）** 见定义 606；四个中立元注入后调用序列与 v13 逐位一致。

```python
# IP-375 HALO：多假设定位 + 负证据间隙 + 可信集
class HypothesisAwareLocalizationOperator:
    def __init__(self, map_model, sensor_model, alpha_loc=0.05,
                 alpha_amb=0.05, tau_amb=0.0, support=None):
        self.M, self.Z = map_model, sensor_model
        self.alpha_loc, self.alpha_amb = alpha_loc, alpha_amb
        self.tau_amb, self.support = tau_amb, support

    def hypotheses(self, obs, prior):
        # 返回按任务类聚合后的前 K 个模态；同任务类内的峰先合并
        modes = self.M.match(obs, prior)
        return self.M.merge_by_task_class(modes)

    def certify(self, obs, prior):
        modes = self.hypotheses(obs, prior)
        assert modes, "no hypothesis: must relocalize/ask"
        best = modes[0]
        C_loc = conformal_credible_set(
            self.M, obs, prior, alpha=self.alpha_loc)
        if len(modes) == 1:
            delta = float("inf")
            ambiguous = False
        else:
            delta = log(modes[0].mass) - log(modes[1].mass)
            ambiguous = (delta < self.tau_amb) or (best.task_class != modes[1].task_class)
        if not self.support.contains(obs):
            return ALC(C_loc, best.pose, delta, self.alpha_loc,
                       self.alpha_amb, support=False), "AMBIG"
        if ambiguous and delta < self.tau_amb:
            return ALC(C_loc, best.pose, delta, self.alpha_loc,
                       self.alpha_amb, support=True), "AMBIG"
        # 两名模态任务等价时允许合并；任务不同则必须 AMBIG
        return ALC(C_loc, best.pose, delta, self.alpha_loc,
                   self.alpha_amb, support=True), "UNI"


# IP-376 TPC：任务投影包络 + 对称商门（不确定即不商）
class TaskProjectedPoseCertifier:
    def __init__(self, pose_model, task_metric, alpha_pose=0.05,
                 calib_by_class=None):
        self.P = pose_model
        self.d_tau = task_metric
        self.alpha_pose = alpha_pose
        self.calib = calib_by_class or {}

    def admissible_symmetry(self, theta_hat, obj, skill):
        # 只保留在 skill 的安全谓词/效果/值函数下不变的子群
        G = self.P.symmetry_group(obj, theta_hat)
        G_ok = {g for g in G
                if skill_invariant_under(skill, g, obj)}
        return G_ok or {identity()}

    def certify(self, obs, obj, skill, occlusion=None):

            self.calib[(obj.cls, occlusion_layer(occlusion))],

class FrameGraphCertificate:
    def __init__(self, edges, kappa_calib, delta_F=0.05, rho_F=None):
        self.edges, self.kappa, self.delta_F = edges, kappa_calib, delta_F
        self.rho_F = rho_F

    def compose(self):
        T_hat = identity()
        rho_sum = 0.0
        for e in self.edges:
            T_hat = T_hat @ e.T_hat
            rho_sum += e.rho
        assert self.kappa >= 0.0

                return FGC(T_hat, C_comp, self.delta_F,
                           self.kappa, support=True), "INCONSISTENT"
        return FGC(T_hat, C_comp, self.delta_F,
                   self.kappa, support=True), "UNI"
```

## 4. 推导

**引理 122（鲁棒授权的可靠性与值下界）** 若 `PC_t` 覆盖真实状态的概率 ≥1−α_p，且 `a∈Acc^rob(C_t)`，则 `P(a 在真实状态下安全) ≥ 1−α_p`；并且对任意 `a`，`value^rob(a|C_t) ≤ E[value(a|ξ_t)]`。若 `Acc^rob(C_t)=∅`，则不存在可自主执行的动作。证明：`a∈Acc^rob` 意味着对所有 `ξ∈C_t` 都有 `Cert_{v13}(ξ,a)=1`；以 ≥1−α_p 的概率 `ξ_t∈C_t`，故安全。值下界由逐点最小值定义直接得到；空集时全称命题无可用动作。∎ 推论：**歧义的代价是授权收缩，而不是用期望值赌一把**；把 `Acc^rob` 换成“最可能模态的授权”会立即丢失覆盖保证。

**引理 123（ALC 的覆盖、别名排除与被动不可区分下界）** 在校准与部署可交换、部署落在 `supp_loc` 内、且任务类聚合正确的条件下，定义 597 的 `C_loc` 满足 `P(g_t∈C_loc)≥1−α_loc`；以 `Δ_loc` 的保守分位为阈值时，
```
P(存在未声明的任务可分别名) ≤ α_amb ,
```
否则证书必须返回 `AMBIG`。进一步，若两个地点在传感器模型下**被动观测等价**（对所有被动观测 `z`，`p(z|g_1)=p(z|g_2)`，且二者任务可分），则任何不改变观测分布的被动策略都无法以优于 1/2 的联合错误率区分它们；因此单模态被动证书不存在，只有主动动作（改变 `p(z|g,u)`）或 `AMBIG`/`a_ask` 是可靠的。证明：覆盖由分裂共形给出；别名排除对 `Δ_loc` 做单侧共形校准；不可区分性由假设检验的 Le Cam 两点下界：在两个完全相同的分布下，任何检验的假确定率与漏检率之和 ≥1。∎ 推论：**“匹配分数高”不是确定性，“与第二名的任务可分间隙大”才是**；重复房间中增加特征可能同时抬高两个模态，间隙不增则证书不应变强。

**引理 124（对称商门的可靠性与过度商反例）** 若 `G_τ` 满足定义 598 的任务不变性，则 `d_τ` 是良定义的任务伪度量，商空间上的共形分数与 `G_τ` 的选取无关，`TPC_τ` 的覆盖可转移到 `Ξ_τ`，且 `E_τ` 在任务意义上不丢失安全信息。若存在 `g∈G_τ` 与 `a∈A_τ` 使 `Cert_{v13}(θ,a)≠Cert_{v13}(gθ,a)`，则把 `g` 商掉会产生**过度商**：存在 `θ` 使 `d_τ(θ,gθ)=0` 但任务误差 `d_task(θ,gθ)>0`，于是证书可在任务上错误的方向上放行。证明：不变性条件下，`Cert`/`Eff`/`value` 在 `G_τ` 轨道上为常数，故商映射是证书的纤维化，覆盖与分数不变；反例由定义直接构造：取一个只在 `g` 方向上敏感的技能（如带手柄杯子的绕轴朝向），令 `θ` 与 `gθ` 在商下同点但手柄方向不同。∎ 推论：**对称性只有在任务不变时才可商；不确定时取 `{e}`**。商的收益是样本效率与紧致性，不是免费的安全裕度。

**引理 125（帧图复合的共同模态界与不可乘性）** 在左不变 `SE(3)` 度量下，复合映射是 1-Lipschitz 的，因此
```
d_SE3(T_comp,T̂_comp) ≤ Σ_e d_SE3(T_e,T̂_e) ,
P(T_comp∈C_comp) ≥ 1 − Σ_e δ_e   （由并集界）
```
若各边误差共享潜因子 `z`（共同地图/特征/标定），写 `e_e=b_e z+η_e`，则最坏复合误差含 `Σ_e|b_e|·ρ_z` 项；`κ` 必须覆盖该项及交叉项。**边缘覆盖不能相乘**：由 Fréchet–Hoeffding，`P(∩E_e) ≥ max(0,1−Σδ_e)`，在没有联合依赖证据时不能声称更好；用 `∏(1−δ_e)` 或 RSS 会低估共同模态下的联合误差。误差抵消可使 `T_comp` 误差小于 `Σρ_e`，但只有留出集认证的抵消模式才可用来收紧 `C_comp`；否则按最坏相加。证明：三角不等式与复合 Lipschitz；并集界；共同模态展开；反例取两条边共享同一标定偏移、方向相反使复合“看起来正确”，但在另一留出子集上同向叠加使复合越界。∎ 推论：**帧图证书必须联合校准；边缘证书相乘是未声明的独立性假设，不能作为安全依据**。

**引理 126（二维格的单调退化与算力—感知不可替代）** 对定义 601 的格：
1. `Acc_{i,j}⊆Acc_{i+1,j}` 且 `Acc_{i,j}⊆Acc_{i,j+1}`；
2. 期望鲁棒价值 `v_{i,j}=E[max_{a∈Acc_{i,j}} value^rob(a)]` 关于 `i,j` 单调不减；
3. **不可替代性**：固定观测 `x` 后，`C_t` 不变；若存在两个任务可分模态 `ξ_1,ξ_2∈C_t` 使 `Acc^{v13}_i(ξ_1)∩Acc^{v13}_i(ξ_2)=∅`，则对所有 `i` 都有 `Acc_{i,j}=∅`。增加时间档 `i` 只能在每个模态内部细化授权，不能删除另一个模态；只有新观测/主动动作改变 `C_t`（从而提高 `j`）或改变模态集合，才能使交集重新非空；
4. 双轴退化满足
```
v_{m,k} − v_{i,j}
 = Σ_{i'=i}^{m-1}(v_{i'+1,j}−v_{i',j})
 + Σ_{j'=j}^{k-1}(v_{m,j'+1}−v_{m,j'})
```
取期望并按 `{B<w_{i'+1}+B_safe}`、`{PC 不满足级别 j'+1}` 放缩，得到与 v13 引理 115 同构的退化界（含一个二维交互项）。
证明：(1)(2) 由格的定义与嵌套；(3) 由全称交集：`Acc_{i,j}⊆Acc^{v13}_i(ξ_1)∩Acc^{v13}_i(ξ_2)=∅`，对所有 `i` 成立；(4) 伸缩求和。∎ 推论：**“再看久一点”不能替代“换个地方看”**；时间与感知是两种货币，二维塌缩必须分别计价。

**引理 127（主动感知的安全与 VoI 界）** 若主动动作 `u` 不在 `P^rt` 中，则它不可执行；若 `u` 可行且 `VoI(u)≥ν_min`，则执行 `u` 的一步期望鲁棒价值增益不小于其时间/风险成本；若 `VoI(u)<0`，回退（或 `a_ask`）的一步价值不低于执行 `u`。在值函数 `L_V`-Lipschitz 下，
```
E[V(PC_{t+1})−V(PC_t) | u] ≤ L_V · I(ξ; z | u) ,
```
故主动感知的收益受互信息上界约束，不能通过增加内部计算伪造。证明：可行性由 `P^rt` 给出；VoI 定义为收益/成本比，`ν_min` 为预注册阈值；Lipschitz 界由信息不等式（`|E[f]−f(E)|` 型）给出。∎ 推论：**若歧义只能通过进入不安全区域才能消除，则安全系统必须 `AMBIG`/`a_ask`，不能“为了看清而冒险”**。

**引理 128（安全继承与不可绕过）** 在定义 605 下，`Exec_v14⊆Exec_v13`。证明：`Acc_{i,j}(C_t)⊆⋂_{ξ∈C_t}Acc^{v13}_i(ξ)⊆Exec_v13(ξ)` 对每个 `ξ` 成立；FGC 只增加对 `T^{ee}_{obj}` 的约束；HALO/TPC 只缩小 `C_t`/`E_τ`；PACR 只在上述集合中选档；主动动作要求 `u∈P^rt`；`U_obs` 只进入预算约束。故任一被执行动作在真实状态属于 v13 执行集。∎ 因此 v13 引理 117/118 与 v11/v12 的安全继承在 v14 上继续成立。

**引理 129（中立元退化等价 v13）** 将定义 606 的四个中立元注入 HALO/TPC/FGC/PACR 端口，则：HALO 退化为 v13 定位输入，TPC 退化为 v13 位姿输入（`ρ=0`、`G_τ={e}`），FGC 退化为 v13 变换链，PACR 退化为 v13 RTCR/静态调度；二维格中 `j*` 取最高档（中立元不增加限制），`Acc_{i,j*}=Acc^{v13}_i`。主闭环调用序列与 v13 逐位一致，再沿 v13 链退回 v12/v11/v10/v9/v8/v7/v6。证明：逐端口代入定义 606，并用定义 595–605 的边界条件核对；四端口互不相交且中立元不改变 v13 任何证书检查。∎ 注意：这是**相对等价**，不保证 v13 在绝对意义上的位姿安全；v13 的位姿信任假设被原样继承。

**引理 130（预算守恒与在线复杂度 v14）** 新增在线成本上界：HALO 多假设维护与证书查表 ≤0.25ms（全局重定位按 `B_percept` 低频执行）；TPC 对称轨道投影 + 共形查表 ≤0.15ms；FGC 四节点复合 + 环路检查 ≤0.05ms；PACR 二维选档 O(log m·log k) ≤0.05ms；合并证书与鲁棒交集 ≤0.1ms。证书层合计 ≤0.6ms；视觉前端与 6D 位姿网络沿用 v13 输入（不在本轮新增推理），若启用主动重定位/额外视角则从 `B_percept` 支出并多速率执行。决策侧典型 ≤10.6ms，p99 仍 ≤22ms，50Hz 保持。证明：逐项代入复杂度表并做静态 EDF 校验 `ΣŴ≤B_dec`；安全切片 `B_safe` 硬预留；主动感知受 `B_percept` 与 `P^rt` 双重约束，不侵占关键路径。∎

## 8. 已知风险与失效模式

1. **地图陈旧/漂移（证书的绝对前提失效）**：ALC 与 FGC 都以地图有效为前提；地图漂移时，正确的视觉匹配会把机器人定位到错误的旧结构上。缓解：地图健康检查、时序变化检测、运动学/触觉环路、地图外区域强制 `AMBIG`/重定位、把 `B_obs` 用于在线地图维护。
2. **过度商对称性（把错误朝向藏起来）**：把任务敏感的对称自由度误判为可商，会让 TPC 在商度量下完美覆盖、在任务上完全错误。缓解：SQG 硬门、任务不变性单元测试、对称类回归集、不确定即 `{e}`、部署前 100% 商审计。
3. **共同模态导致的联合低估**：边缘证书各自覆盖良好，但共享标定/地图/特征使复合误差同向叠加；`κ` 校准不充分时会低估。缓解：联合校准、留出集按场景分层、最坏相加兜底、环路一致性检查。
4. **主动感知本身引入风险**：为了消歧而移动/触碰可能进入不安全区域或触发动态障碍。缓解：`u∈P^rt` 硬约束、VoI 计入运动风险、只在安全切片内移动、失败即 `a_ask`。
5. **假歧义导致活动性塌缩**：过度保守的 `α_amb/ρ_τ` 或分层校准不足会把常见场景大量标为 `AMBIG`。缓解：任务商合并良性多峰、按场景分层校准、显式假拒绝预算、增加常见档/主动视角。
6. **对称类/材质分布外**：透明、反光、重遮挡、未见过的对称物体使共形覆盖在尾部失效。缓解：材质/遮挡分层、主动采样、EVT 尾部修正、缩小宣称支撑、必要时拒绝自主执行。
7. **证书层自身超预算**：多假设维护、鲁棒交集与环路检查在高峰期叠加，可能侵蚀 v13 的 22ms 预算。缓解：证书查表化、多速率执行、`B_safe` 硬预留、watchdog 强制回退。
8. **学生/蒸馏绕过感知证书**：若 CPD 学生直接读取原始位姿而绕过 `C_t`，会出现“蒸馏自洽但感知错误”的旁路。缓解：在 DGC/RTCR 入口强制 `Acc_{i,j}(C_t)` 交集、拒绝点估计输入、审计所有授权路径、对抗测试 E656/E658。

## 9. 本轮最大风险

**一句话**：HALO/TPC/FGC 的可靠性都以“地图与物体模型仍然有效、部署分布落在校准支撑内、且任务不变性判断正确”为前提；当场景同时发生地图漂移、强遮挡与对称类误判时，三个证书会相互“背书”出一个任务上错误却处处显示为已认证的位姿，而二维格会把这种认知错误表现为“按时、在授权子集内、却抓错了物体/方向”的安全决定。
