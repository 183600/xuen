### 第 6 轮灵感驱动研究记录（CADVS-v6：可证演示的混合步态 DCHG）

**灵感词**：步态规划、演示方案

**继承关系**：第 5 轮 CADVS-v5（IP-493~496）确立「认证的生成式执行」（CGE）：七硬门 fail-closed 不增（覆盖/物理/人因/末点/记忆/价值/平衡）、条件流匹配提议 π_θ^FM、LMEM-v2 记忆固化、FAMK 情感非对称调制、执行集嵌套 Exec_CADVS-v5 ⊆ Exec_CADVS-v4 ⊆ … ⊆ Exec_v29。本轮不推翻 v5，而是补 v5 的三个结构性短板：(a) **证书对象是「连续轨迹的点谓词」**，而腿式运动是**混合系统**——离散接触时序（哪只脚、何时触地/离地）是组合对象，逐点 ZMP/摩擦锥成立并不能推出整段调度可行（重心转移时间、落脚可达性、切换冲量、摆动净空都可能失败）；(b) v5 的「执行」缺少**程序层对象**：一场演示是带时间预算、验收标准与回退的技能序列，轨迹级证书不能自动组合成演示级保证；(c) v5 的最大风险 R57（固化自指博弈）仍缺**外生真值**，「演示」恰好提供了天然的外部通道——可复现、可验收的见证。两个灵感词统一为主题「**可证演示的混合步态**」（Demonstrable Certified Hybrid Gait, DCHG），形成 CADVS-v6（IP-497~500）。本轮自律：**硬门仍为七个**（正面回应 R52 锚点维护负债）；新增能力只走三条非侵入路径：**混合化**（把接触时序纳入 kc_balance/kc_physics 的时序合取）、**程序化**（演示计划作为离线/监督层守卫）、**外生化**（见证与声明包络作为离线治理，不改在线谓词）。执行集嵌套升级为 Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ … ⊆ Exec_v29。

**直觉与动机**：

1. **步态规划 → 把「接触时序」提升为一等公民的证书对象，把逐点证书升级为逐段证书**。v5 的 x=(pose,wrench) 是连续量；但双足/四足的运动由**接触调度** σ=((φ_1,[t_0,t_1)),…,(φ_m,[t_{m-1},t_m))) 支配，φ∈{LS,RS,DS,FL}，每相有接触集 C(φ)。一个处处 ZMP 在支撑多边形内的轨迹，仍可能因为「下一落脚点不在可达集」「重心转移来不及」「切换冲量超限」「摆动腿擦地」而摔倒——这些是**时序/切换**性质，点谓词看不见。引入**混合证书** G(x,σ)=∧_j phase_cert_j ∧ ∧_j guard_cert_j：phase_cert_j 把 kc_balance/kc_physics 细化到相 j（ZMP/摩擦锥/净空），guard_cert_j 是新内容——切换后状态必须落在下一相的 **viability kernel** V_{φ_{j+1}}（可捕获域/捕获点），且冲量 ‖J_j‖≤J_max、落脚点 ∈ Reach(φ_j)、净空 h_swing≥h_min。**定理 9（混合证书组合）**：若每相的安全集 S_j 在该相流下前向不变，则只需检查「每相初始状态 ∈ S_j」与「每次切换守卫带裕度成立」即可推出整段调度成立（对相数归纳），从而把连续监测降为**离散检查点**，在线成本不升反降。**定理 10（调度细化保持嵌套）**：G 是既有门的合取细化（不新增门），故 Exec_v6 ⊆ Exec_v5。规划：接触调度搜索 = 在 (相位,状态) 图上的 A*/MCTS，节点带证书剪枝，启发式取捕获点到可捕获域的距离（可采纳），超预算或全灭则 fail-closed 回退最保守的站立/双支撑恢复步态。

2. **演示方案 → 把「演示」从一次表演升级为「可复现、可验收、有声明包络的证书程序」**。演示 P=((skill_i,params_i,t_i,budget_i,fallback_i))。**演示证书** DemoCert(P) 四项合取：(i) 每个技能的 pre/post 证书（复用七门）；(ii) **时间可行性** Σbudget_i≤T_demo（含切换开销）；(iii) **回退完备性**——每个已枚举失败模式都有到 SAFE/安全停机的有证回退路径；(iv) **可复现性**——给定种子/参数，结局在容差内可重放。**定理 11（演示可靠性/不静默失败）**：若 DemoCert(P) 成立、执行留在声明包络 E 内、且监测对不安全偏离可检测，则任何违例都在到达不安全状态前触发回退；失败要么被回退吸收、要么被显式报告，**不会静默通过**。**声明包络** E 是关键：证书只在 E 内有效，E 外 fail-closed 暂停/回退——把 R53 的 OOD「过度声明」变成可审计的包络违约，而不是一句免责声明。

3. **演示作为外部真值 → 用「见证 + 包络契约」打破 R57 自指**。v5 固化训练集是「自己铸证 ∧ 人工抽检」，仍是自指。v6 要求每个进入固化的片段携带**独立见证** w（物理结局真值、人工签核、异源传感器/独立求解器重放），且见证必须与证书通道**非同源（非共模）**。**定理 12（见证约束下的博弈界）**：若见证与证书条件独立、验收假接受率 ≤ α，则博弈片段进入固化的概率 ≤ α/片段，n 片段累计 ≤ 1−(1−α)^n；**若两通道共模则无保证**（诚实边界）。同时把演示方案作为**契约**：承诺的包络 E 与验收测试 A 写进契约，证书强度以演示覆盖为界，「未见证区」保守回退——这把「演示很漂亮」与「证书很强」两件事分开，杜绝用演示视频替代证书。

**关键洞见**：v5 回答「提议任意、记忆反哺、情感调制下证书边界如何不变」；v6 回答「**当被认证对象本身是混合的（离散接触时序）、当安全承诺要以可复现演示的形式对外声明、当固化闭环需要外生真值时，如何让证书代数从『点谓词』扩展到『段』与『程序』，同时不新增硬门**」。七门 kc_evidence_forged_v5 原样复用；新增只有：(i) 混合证书 G（对 kc_balance/kc_physics 的时序合取，只紧不松）；(ii) 演示程序证书 DemoCert（程序层守卫 + 声明包络 + 回退完备）；(iii) 见证约束（离线治理，不改在线谓词）。Exec_CADVS-v6 = {x∈Exec_v5 : G(x,σ(x))=1 ∧ InvokedByCertifiedPlan(x)} ⊆ Exec_v5。

**形式化目标（增量）**：
1. 接触调度 σ=((φ_j,[t_{j-1},t_j)))，φ∈{LS,RS,DS,FL}；接触集 C(φ)；混合流 ẋ=f_{φ}(x,u)，切换 x^+=R_j(x^-)。
2. 混合证书 G(x,σ)=∧_j phase_cert_j(x,φ_j) ∧ ∧_j guard_cert_j；guard_cert_j：x(t_j^+)∈V_{φ_{j+1}}、‖J_j‖≤J_max、p_j∈Reach(φ_j)、h_swing≥h_min。
3. 定理 9（混合证书组合/前向不变）、定理 10（调度细化保持嵌套）、定理 11（演示可靠性/不静默失败）、定理 12（见证约束博弈界）、定理 13（包络违约 fail-closed）。
4. DemoCert(P)=pre/post ∧ temporal ∧ fallback_total ∧ reproducible；E 为声明包络，E 外暂停/回退。
5. EFA-v6：七门 + G 合取 + DemoCert 守卫；ECS_v6=ECS_v5·η_gait·η_demo。
6. Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ … ⊆ Exec_v29。

**本轮最大风险**：**混合证书的组合误差放大**——定理 9 依赖每相安全集 S_j 在真实动力学下前向不变，而 S_j 由 LIPM/线性化接触近似、冲量模型与 viability kernel 数值解给出；打滑、多接触、柔性、未建模外力会让 S_j 在实机上不再不变，误差又沿 m 次切换被放大，而离散检查点恰好落在误差最大处之外——证书在模型内自洽、在真实接触上失真。

## 2. 关键算法骨架

### IP-497 HCSC：混合接触调度证书核（离线/异步规划；在线仅检查点）

```python
@dataclass
class HybridContactScheduleKernel:
    """HCSC：把接触调度 σ 作为一等证书对象。
    定理 9：相内前向不变 + 切换守卫 ⇒ 整段调度成立；连续监测降为离散检查点。
    定理 10：G 是既有门的合取细化 ⇒ Exec_v6 ⊆ Exec_v5（不新增门）。"""
    phi_set: tuple = ('LS', 'RS', 'DS', 'FL')
    V: dict = None                # V_φ：离线数值求解的 viability kernel（近似）
    L_V: float = 0.8              # kernel 边界 Lipschitz 常数（离线标定）
    eps_V: float = 0.02           # kernel 近似 Hausdorff 误差上界
    J_max: float = 0.35           # 切换冲量上限（按硬件标定）
    h_min: float = 0.04           # 摆动净空下限（m）

    def plan_schedule(self, x0, terrain, horizon: int, budget: int):
        """A*/MCTS 在 (相位,状态) 图上搜索；h = dist(x, V_φ)（可采纳）；
        节点扩展前先过 guard_cert 剪枝；超预算/全灭 → None（调用方 fail-closed）"""
        frontier = [(self._h(x0, 'DS'), 0, x0, 'DS', [])]
        while frontier and budget > 0:
            _, g, x, phi, seq = heappop(frontier)
            if g >= horizon:
                return ContactSchedule(seq)
            for phi_next in self._legal_next(phi, terrain, x):
                x_plus = self._reset(x, phi_next)
                if not self.guard_cert(x, phi_next):   # 证书剪枝
                    continue
                heappush(frontier, (g + 1 + self._h(x_plus, phi_next),
                                    g + 1, x_plus, phi_next, seq + [(phi_next, x_plus)]))
            budget -= 1
        return None                                  # fail-closed：回退保守步态

    def phase_cert(self, x, phi):
        """把 kc_balance/kc_physics 细化到相位：ZMP∈Conv(C(phi)) ∧ 摩擦锥 ∧ 净空。
        复用 VACK/BCK 的 wrench 证书字段，避免重复物理求解"""
        return (zmp_in_support(x, phi)
                and friction_cone_ok(x, phi)
                and swing_clearance(x, phi) >= self.h_min)

    def guard_cert(self, x_minus, phi_next) -> bool:
        """切换守卫；引理 45：带裕度检查可吸收 kernel 近似误差"""
        x_plus = self._reset(x_minus, phi_next)
        margin = self._V_margin(x_plus, phi_next)    # 到 V_φ 边界的距离
        return (margin >= self.L_V * self.eps_V
                and impulse_norm(x_minus) <= self.J_max
                and self._foothold(x_minus, phi_next) in Reach(phi_next)
                and swing_clearance(x_minus, phi_next) >= self.h_min)

    def compose(self, sigma, x) -> bool:
        """定理 9：只检查每相初始状态与每次切换（O(m)），不连续扫全轨迹"""
        for j, (phi_j, t_j) in enumerate(sigma.phases):
            if j == 0 and not self.phase_cert(x(t_j), phi_j):
                return False
            if j > 0 and not self.guard_cert(x(t_j - 1e-6), phi_j):
                return False
        return True

    def conservative_gait(self):
        """全灭/超预算回退：站立或双支撑微步（恒有证）"""
        return STAND_RECOVERY_GAIT
```

### IP-498 DPC：演示计划编译器与包络契约（离线编译；在线监督）

```python
@dataclass
class DemonstrationPlanCompiler:
    """DPC：演示 = 有证技能序列程序；DemoCert 四合一。
    定理 11：DemoCert ∧ 留在 E 内 ∧ 偏离可检测 ⇒ 不静默失败。
    定理 13：E 外一律 fail-closed（暂停/回退），不对外声明。"""
    envelope_cal: Any             # 包络标定器（离线，含 ε_E 不确定度）

    def compile(self, demo_spec, E, T_demo) -> DemoPlan:
        steps = []
        for skill in demo_spec.skills:
            steps.append(SkillStep(
                skill=skill,
                pre=self._certify_pre(skill),         # 复用七门
                post=self._certify_post(skill),       # 复用七门
                budget=skill.budget + SWITCH_OVERHEAD,
                fb=self._fallback_for(skill)))        # 已枚举失败模式 → SAFE
        return DemoPlan(steps=steps, E=E, T_demo=T_demo)

    def demo_cert(self, P: DemoPlan) -> bool:
        return (all(s.pre and s.post for s in P.steps)
                and sum(s.budget for s in P.steps) <= P.T_demo
                and self._fallback_total(P)           # 回退完备
                and self._reproducible(P))            # 种子/参数可重放

    def _fallback_total(self, P) -> bool:
        """∀ 已枚举失败模式 f：fb(f) 为有证路径且终止于 SAFE/安全停机。
        未枚举模式由『安全停机』兜底，但覆盖率作为审计指标上报（诚实边界）"""
        return all(self._fb_terminates_safe(s) for s in P.steps)

    def guard(self, P: DemoPlan, x, t) -> str:
        if not in_envelope(x, P.E, eps=self.envelope_cal.eps_E):
            return 'ENVELOPE_VIOLATION'               # fail-closed
        if not self._fallback_available(P, t):
            return 'FALLBACK_UNAVAILABLE'
        return 'OK'
```

### IP-499 WDL：见证演示账本（离线治理，打破 R57 自指）

```python
@dataclass
class WitnessedDemonstrationLedger:
    """WDL：每个进入固化的片段必须携带与证书通道非同源的见证。
    定理 12：见证独立 + 假接受 ≤ α ⇒ 博弈片段入固化概率 ≤ α/片段。
    诚实边界：共模见证无保证。"""
    provenance_db: Any            # 传感器/求解器/标定 provenance 图

    def record(self, episode, w: Witness) -> None:
        self._append(episode.id, w)

    def independent(self, w: Witness, cert_channel) -> bool:
        """非同源：不同传感器族 ∨ 独立求解器重放 ∨ 人工物理签核；
        同一标定/同一数据管线不算独立"""
        return not self.provenance_db.common_ancestor(w.src, cert_channel)

    def admit(self, ep) -> bool:
        """固化准入：铸证 ∧ 结局成功 ∧ 见证存在 ∧ 见证独立 ∧ 包络内 ∧ 人工抽检"""
        return (ep.forged and ep.outcome_ok and ep.witness is not None
                and self.independent(ep.witness, ep.cert_channel)
                and ep.envelope_ok and ep.human_audit)

    def gaming_rate_bound(self, alpha: float, n: int) -> float:
        return 1.0 - (1.0 - alpha) ** n            # 定理 12 累计界
```

### IP-500 EFA-v6：七硬门 + 混合证书 + 演示守卫

```python
@dataclass
class EvidenceForgingAssemblerV6:
    """EFA-v6：七门逐字继承 v5；追加 G 合取与 DemoCert 守卫。
    门集合不变，新增只收紧 ⇒ Exec_v6 ⊆ Exec_v5"""
    hcsc: HybridContactScheduleKernel
    dpc: DemonstrationPlanCompiler
    wdl: WitnessedDemonstrationLedger
    v5: EvidenceForgingAssemblerV5

    def select(self, x0_state, t_now, rule_id, context, plan: DemoPlan):
        # 第 0 层：演示/包络守卫（程序层，fail-closed）
        g = self.dpc.guard(plan, x0_state, t_now)
        if g != 'OK':
            return False, None, g                      # ENVELOPE/FALLBACK 拒绝
        # 第 1 层：v5 七门选证（逐字不变）
        ok, x, code = self.v5.select(x0_state, t_now, rule_id, context)
        if not ok:
            return ok, x, code
        # 第 2 层：混合步态证书（调度规划 + 组合检查）
        sigma = self.hcsc.plan_schedule(x, context.terrain, context.horizon, context.budget)
        if sigma is None or not self.hcsc.compose(sigma, x):
            return True, self.hcsc.conservative_gait(), 'FORGED_CONSERVATIVE_GAIT'
        return True, x, 'FORGED_DCHG'

    def ecs_v6(self, x, sigma, n_flow, s_emo, plan) -> float:
        m_G = min_margin(sigma, x)                     # 调度最小裕度
        eta_gait = sigmoid(m_G - B_GAIT)
        eta_demo = 1.0 - LAMBDA_DEMO * plan.risk_score
        return self.v5.ecs_v5(x, n_flow, s_emo) * eta_gait * eta_demo
```

## 4. 正确性论证（增量更新）

### 引理 45（viability kernel 近似裕度）

**陈述**：设近似 kernel V̂_φ 与真实 V_φ 的 Hausdorff 距离 ≤ e_V，V_φ 边界关于状态 L_V-Lipschitz。若守卫用「到 V̂_φ 的裕度 ≥ L_V·e_V」判定，则通过近似守卫 ⇒ 状态属于真实 V_φ。**证明**：Hausdorff 界 + Lipschitz 裕度三角不等式。∎

**诚实边界**：e_V 的标定只在标定分布内有效；分布外 kernel 误差无界，是定理 9 的主要威胁。

### 引理 46（调度搜索可采纳性与完备性）

**陈述**：若启发式 h(x,φ)=dist(x,V_φ) 不高估到目标的最小切换数（可采纳），则 A* 在扩展预算内返回的调度为最小相数调度；若在 horizon 内无可行调度，则返回 None（fail-closed），不会返回未过 guard 的伪调度。**证明**：A* 可采纳性 + guard 剪枝只删除不可行扩展。∎

### 引理 47（组合误差放大）

**陈述**：设每相模型误差 ε_m、流映射 Lipschitz 常数 L，则跨 m 次切换的终态偏差 ≤ Σ_{j=0}^{m-1} L^{m-j} ε_m。若 L<1（收缩相）有界；若 L≥1（临界/发散相，如推挤下的支撑相），偏差随 m 指数增长。∎

**工程含义**：这正是本轮最大风险的形式化来源——组合定理的结论强度被每相模型误差与 L 放大，而检查点无法看到相内累积。

### 定理 v6（执行集嵌套与混合/演示/见证，总装）

**陈述**：在 v5 假设 (B1)~(B7) 及新增 (B8) V_φ 近似误差 ≤ e_V 且守卫带 L_V·e_V 裕度、(B9) 见证与证书条件独立、(B10) 演示偏离可检测 下：
(i) Exec_CADVS-v6 ⊆ Exec_CADVS-v5（严格：G 与 DemoCert 非恒真）⊆ … ⊆ Exec_v29；
(ii) 混合组合：相内前向不变 + 切换守卫 ⇒ 整段调度成立，检查点 O(m) 充分（定理 9）；
(iii) 演示可靠性：DemoCert ∧ 留在 E ∧ 可检测 ⇒ 不静默失败（定理 11）；
(iv) 见证博弈界：独立见证 ⇒ 入固化概率 ≤ α/片段、累计 ≤ 1−(1−α)^n（定理 12）；
(v) 包络 fail-closed：E 外一律拒绝，声明不越界（定理 13）；
(vi) 七锚完备性保持（定理 10）。

**证明**：(i) 由 G 与 DemoCert 均为合取细化（定理 10）；(ii)(iii)(iv)(v) 分别由定理 9、11、12、13；(vi) 由不新增门。∎

**诚实声明**：(B8) kernel 与冲量模型在打滑/多接触/柔性下误差无界，引理 47 的放大可能使组合结论在实机上失效；(B9) 共模见证使定理 12 失效，且共模常伪装成「外部真值」；(B10) 不可检测偏离无保证；(iv) 加性价值假设 (B4) 继承自 v4，未解决。

## 7. 本轮最大风险（最终确认）

**一句话**：**混合证书的组合误差放大**——定理 9 依赖每相安全集 S_j 在真实动力学下前向不变，而 S_j 由 LIPM/线性化接触近似、冲量模型与 viability kernel 数值解给出；打滑、多接触、柔性、未建模外力会让 S_j 在实机上不再不变，误差又沿 m 次切换被放大（引理 47），而离散检查点恰好落在误差最大处之外——证书在模型内自洽、在真实接触上失真。
