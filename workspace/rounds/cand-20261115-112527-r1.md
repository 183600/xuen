# 第 5 轮（研究线累计；本轮灵感：「移动操作」×「本体感知」）

> **基线**：第 4 轮 InstructGauge-WR（IP-328–333；定义 448–467；引理 59–62；实验 E457–E472）。第 3 轮 InstructGauge 的五不变式与 CVC 闭环、第 2 轮 ToolGauge、第 1 轮 LeanGauge / MODGAUGE 全部继续继承。
> **本轮纪律**：**增量升级 + 严格退化**。移动底盘是「可变的参考系」，本体感知是「第二条独立证据通道」；任一环节不可用都必须逐级退回 WR v4 → InstructGauge v3 → ToolGauge，并且退回时要把结果显式标成「固定基座 / 单通道」，而不是静默等价。

## 0. 直觉与动机

**灵感 1（移动操作：参考系从“免费”变成“要维护的资源”）**
固定基座时代，世界坐标系几乎是免费的：相机、腕部、末端之间的标定近似静态，基座不动意味着“上一刻的证书”天然可以搬到下一刻。移动底盘打破了这个前提。基座位姿有里程计漂移，轮子会打滑，底盘受非完整约束（差速/阿克曼不能横移），上下坡与越障改变稳定性裕度，可达域随基座位置动态变化，机械臂的反作用力还会反过来扰动底盘。更关键的是：**一个块的 K 步执行期间，参考系本身在动**。于是第 3 轮说的“证据陈旧窗口 = K 步”在移动操作里升级为“K 步 × 参考系漂移”：不是证据变旧，而是证据所依附的坐标系也变旧了。移动还带来一个正面机会——**move-to-see**：与其在原地猜盲区，不如把底盘挪到一个能看见的位置；但移动本身会制造新的盲区、消耗时间、并可能把系统带进不可逆的狭窄通道。

**灵感 2（本体感知：唯一与自身运动因果绑定、且不受光照/遮挡影响的通道）**
本体感知包括关节编码器、关节力矩、IMU、轮速里程计。它的价值不是“多一个传感器”，而是**一个可用于解释和否决外部证据的自模型**。它至少能做三件事：(i) **自运动预测**——由关节角与基座位姿前向计算腕部相机/末端的预期位姿，从而把外部残差里“自己动的部分”减掉；(ii) **身体图式一致性**——用自模型预测下一时刻的本体读数，残差可暴露滑移、意外接触、负载突变、执行器退化；(iii) **稳定性裕度**——由质心、支撑多边形、坡度给出倾覆/失稳的连续度量。它不受反光、遮挡、光照突变影响，恰好与腕部相机互补。但它有两个致命弱点：**积分漂移**与**系统偏差（标定/零偏）**，而且它“看起来很可信”，容易被当成真值。

**灵感 3（两者耦合：真正的新失败模式是“归因错误”，不是“看不见”）**
移动操作里最危险的错误不是单路传感器坏掉，而是**把世界的变化误判为自己在动，或把自己在动误判为世界在变**。前者造成假阳性截断（明明只是底盘在动，却触发约束违背），后者造成假阴性（把基座滑移、手眼标定漂移、轮子打滑吃进容差，导致接地悄悄失效）。此外，自然语言指令通常隐含一个参考系（“货架左边”“沿墙走”）：如果接地绑定在移动基座坐标上，基座一转，指令就悄悄旋转了。因此本轮的结构不是“加两个模块”，而是四根支柱：**自运动解耦**（把残差分成可解释/不可解释两部分）、**双通道否决**（外部证书与本体证书不可解释即不可信）、**参考系锚定**（指令与证书绑定到稳定世界锚点，并监控基座不确定度）、**移动不可逆屏障**（改变可达域/稳定性/退路的底盘动作强制 K=1 并留回溯检查点）。

## 1. 研究问题（本轮要回答什么）

- **Q1（归因）**：本体感知能否把外部残差分解为“自运动可解释部分”与“世界变化部分”，从而同时压低假阳性截断与假阴性漏检？分解误差如何进入漂移界？
- **Q2（移动结构）**：非完整约束、稳定性裕度、动态可达性如何进入“前缀封闭分块”？哪些底盘动作应被判定为不可逆并强制 K=1？参考系漂移如何并入块长上界？
- **Q3（双通道）**：两条证据链在什么条件下可以互相否决？当两路共享时钟/标定/模型时，“独立性”失效，如何检测共模并退化到保守上界？

## 2. 四条设计原则（正式化见产物区定义 468–481）

**P1 自运动解耦（Ego-Motion Factorization）**
任何外部残差先经本体前向模型解释；只有“本体无法解释”的部分才计入违规。形式化方向：把外部残差 `e` 分成 `e_self`（本体预测的自运动残差）与 `e_world`（剩余世界残差），仅当 `||e_world|| > ε_world` 才触发截断/修正。这条原则同时抑制两类错误：不会把纯基座运动误判为违规，也不会让本体预测把真实世界变化吞掉。

**P2 双通道否决（Two-Channel Veto，三值逻辑）**
外部 `SpatialCert` 与本体 `SelfCert` 必须同时可判定为通过；任一通道 FAIL 或 **UNKNOWN** 都降级为 K=1。这里刻意采用“不可解释即不可信”的 fail-closed 三值逻辑，而不是简单多数投票：另一路“看起来正常”不能覆盖一路的不可解释。因为移动场景中单路正常恰恰可能是共模错误的表现。

**P3 参考系锚定（Frame Anchoring）**
指令接地与空间证书都绑定到稳定的世界锚点（地标、已知物体、预注册坐标系），而不是移动基座坐标；同时维护基座位姿不确定椭球 `U_t` 与手眼标定的在线自校准。当 `U_t` 超出包络或锚点不可重观测时，证书作废并先重锚定，再允许分块执行。

**P4 移动不可逆屏障（Locomotion Irreversibility Barrier）**
把底盘动作按可逆性分级：开阔地小幅移动可逆；进入窄通道、越障、超出坡度/摩擦包络、离开定位覆盖、逼近倾覆边界属于不可逆或条件不可逆。不可逆动作强制 K=1，并在执行前保存回溯检查点；跨不可逆过渡必须由独立回执交叉验证后才允许继续。

## 3. 与基线的接口（如何严格退化）

| 失效/缺失环节 | 退化动作 | 退化为 |
|---|---|---|
| 无本体感知或时间戳失配超界 | `e_self := 0`，`SelfCert := ⊤` | WR v4 单通道 |
| 底盘静止（`v_base = 0`） | 里程计项与基座不确定度项消失 | WR v4 |
| 里程计/本体漂移超界 | 禁用自运动解释，改用保守外部残差 | WR v4（更保守阈值） |
| 锚点不可重观测且 U 超界 | 暂停分块，先重锚定 | 暂停-重规划 |
| 移动不可逆屏障触发 | 强制 K=1 + 检查点 | 逐步执行 |
| 本体与外感知均不可用 | 逐级回退 | InstructGauge v3 → ToolGauge |

**核心退化等式**：`v_base = 0 ∧ 无本体 ⇒ e_self = 0 ∧ SelfCert = ⊤ ∧ WBAS = KinematicAdmissibleSet ∧ B_total = B_vis + B_arm·K`，即算法逐项化为 WR v4（产物区引理 69）。这是本轮“增量而非推翻”的可检查证据。

## 4. 预期贡献

1. 一个**自运动解耦**的外部残差口径，把移动带来的参考系漂移从“噪声”变成“可解释项”，并用同一机制同时抑制假阳性截断与假阴性漏检；
2. 一个**双通道三值否决 + 参考系锚定**的证书组合，为移动操作提供不依赖单一路径的安全证据，并显式建模“共享标定/时钟导致的共模失效”；
3. 一个**全身可采纳集 + 移动不可逆屏障**，把非完整约束、稳定性裕度与动态可达性纳入前缀封闭分块，使“移动”不再游离于分块安全之外；
4. 一条可证伪路径 E473–E488：覆盖自运动解耦、滑移检测、共模注入、锚点传递、全身前缀封闭、不可逆屏障、块长上界、move-to-see 收益、退化等价与 50Hz 时序保全。

## 5. 本轮最大风险

**一句话**：本体感知的漂移与系统偏差会被“自运动解耦”吸收成看似合理的解释项，而共享时钟/标定又会让两路证据产生**看起来自洽的共模错误**——此时“双通道交叉验证”给出的是虚假的安全感，真实的基座滑移或手眼失配反而被解释成世界变化。

## 2. 形式化定义（要点）

**定义 468（本体感知状态与同步）**
`π_t = (q_t, q̇_t, τ_t, a_t^imu, v_t^wheel, t)`。设各通道时间戳为 `t_i`，则
```
skew(π_t) = max_i |t_i - t|
aligned(π_t) ⇔ skew(π_t) ≤ δ_sync
```
若 `¬aligned`，`π_t := ⊥`（UNKNOWN），下游一律按 fail-closed 处理。

**定义 469（本体前向模型）**
```
T̂_prop(t) = T_base(t) · FK(q_t)
```
其中 `T_base(t)` 由轮速里程计积分、IMU 航向/重力方向校正得到；`FK` 为机械臂正运动学。相机安装外参 `X_cam→ee` 由 IP-338 在线维护。

**定义 470（自运动解耦）**
给定实测 `M(t)`、外部期望 `E(t)`、本体预测 `P(t)=T̂_prop(t)`，定义
```
e_self(t)  = log( E(t)⁻¹ · P(t) )
e_world(t) = log( P(t)⁻¹ · M(t) )
```
一阶复合下 `log(E⁻¹M) ≈ e_self + e_world`。**只有** `||e_world(t)||_{Σ} > ε_world` 才触发截断/修正；并定义可解释比例
```
η(t) = ||e_self(t)|| / (||e_self(t)|| + ||e_world(t)|| + δ)
```
`η` 进入证书，供审计“这次判据到底是被本体解释掉了，还是被世界残差触发的”。

**定义 471（本体一致性证书 SelfCert）**
```
s_t        = || π_t - M_self(a_{t-1}, π_{t-1}) ||_W
s_slip(t)  = || v_wheel(t) - v_imu(t) ||
τ_res(t)   = τ_meas(t) - τ_model(q_t, q̇_t, q̈_t)
h_stab(t)  = min_{e∈支撑边} dist(CoM_proj, e)
```
```
SelfCert(C) = (s̄, E_slip, E_τ, h_min, F_fault, score)
SelfCert.OK ⇔ s̄ ≤ ε_body ∧ E_slip = ∅ ∧ h_min ≥ h_stab^min ∧ F_fault = ∅
```
其中 `M_self` 可为解析刚体模型，也可为学习模型；学习模型必须给出校准后的残差阈值。

**定义 472（双通道三值证书合取）**
```
Cert_OK(C) = SpatialCert.is_consistent ∧ SelfCert.OK ∧ Anchor.OK
```
取值 `{PASS, FAIL, UNKNOWN}`：全 PASS 才 PASS；任一 FAIL 即 FAIL；其余为 UNKNOWN。**UNKNOWN ⇒ K=1**。此定义刻意不采用多数投票。

**定义 473（全身可采纳集 WBAS）**
```
WBAS(s) = { (δq, δξ) :
    IK(q+δq, ξ+δξ) 在关节限位内
  ∧ A(ξ)·ξ̇ = 0                       (非完整约束)
  ∧ collision_free(q+δq, ξ+δξ)
  ∧ h_stab(ξ+δξ) ≥ h_stab^min
  ∧ reachable(q+δq, ξ+δξ)
  ∧ U_t ⊆ U_max }
```
前缀封闭：`∀ j ≤ K, (δq, δξ)_{1:j} ∈ WBAS(s)`。与 v4 的 `KinematicAdmissibleSet` 相比，多了基座三自由度、非完整约束与稳定性/定位包络。

**定义 474（参考系锚定与不确定度）**
设世界锚点集合 `A = {a*}`，基座位姿估计 `ξ̂` 与协方差 `Σ_ξ`：
```
U_t = { ξ : (ξ-ξ̂)ᵀ Σ_ξ⁻¹ (ξ-ξ̂) ≤ χ² }
```
锚定证书有效当且仅当 `tr(Σ_ξ) ≤ σ_max` 且锚点可重观测。跨坐标系传递误差界
```
ε_transfer = ε_a + diam(U_t) + ε_calib
```
当 `ε_transfer > ε_vis` 时，v4 的空间证书不得直接用于基座坐标。

**定义 475（移动不可逆屏障）**
```
κ: A_move → {R, C, I}
```
`R`：开阔地小幅移动，存在可执行的逆向动作；`C`：条件可逆（依赖坡度/摩擦/载荷）；`I`：进入窄通道、越障、超出坡度包络、离开定位覆盖、逼近倾覆边界。规则：
```
κ(a)=I ⇒ K=1 ∧ checkpoint = (ξ, q, a*, digest(certs))
κ(a)=C ∧ ¬conditions_hold ⇒ 按 I 处理
```
检查点之前的证书摘要不可被后续覆盖。

**定义 476（含基座运动的漂移界与块长上界）**
```
B_total(K) = B_vis + B_arm·K + L_base·v_max·K·dt
           + λ·tr(Σ_ξ(K)) + B_sync
K_max = max{ K ∈ ℕ : B_total(K) ≤ B_max }
```
`B_vis` 为视觉/深度噪声界，`B_arm` 为单步机械臂漂移，`L_base` 为基座运动对腕部位姿的 Lipschitz 系数，`tr(Σ_ξ(K))` 为里程计随机游走，`B_sync = L_base·v_max·δ_sync` 为时间失配项。若 `K_max < 1`，必须停止分块并重锚定，而不是偷偷把阈值放宽。

**定义 477（Move-to-See 视点收益）**
```
VOI_move(v) = E[IG(v)] - c_move(v) - λ_s·risk_stab(v) - λ_i·1[κ(v)=I]
```
仅当 `v ∈ WBAS(s) ∧ VOI_move(v) > 0 ∧ SelfCert.OK` 才允许把移动作为探测动作。`IG` 为对盲区不确定度的期望信息增益。

**定义 478（双通道独立性与共模检验）**
假设 `e_world ⟂ s | state`。在滑动窗口内计算
```
ρ_cm = |corr(e_world, s)|
```
若 `ρ_cm > ρ_max`，独立性假设作废（共享时钟、共享标定、共享模型都会导致共模），此时漏检界只能取并集上界
```
P_miss ≤ min(P_miss^Spatial, P_miss^Self)
```
并置位 `CM-DEGRADED`，后续按保守路径执行。

**定义 479（时间同步与延迟补偿）**
`δ_sync` 为允许的最大通道失配；`t_meas` 与 `t_apply` 之间的控制延迟计入 `B_sync`。任何“用未来帧补过去帧”的对齐都必须在证书中记录外推量，禁止无标记外推。

**定义 480（锚点相对指令接地）**
```
Γ_anchor(ℓ) = argmin_{g ∈ G_anchor} d(φ(ℓ), φ(g))
              s.t. frame(g) ∈ A_stable
```
指令槽位携带 `anchor_id`；若锚点丢失或不可重观测，`Γ_anchor(ℓ) = ⊥`，退回默认目标 `ι₀`（与 v3 的能力闭包一致）。

**定义 481（证书新鲜度与失效传播）**
```
fresh(t) = 1[t - t_cert ≤ T_fresh] ∧ 1[tr(Σ_ξ(t)) ≤ σ_max] ∧ Anchor.reobservable()
```
`¬fresh` ⇒ `Cert_OK = UNKNOWN` ⇒ K=1。失效沿 `SpatialCert → AnchorCalib → SelfCert` 单向传播，不允许下游证书“修复”上游的 UNKNOWN。

```python
class ProprioStream:
    def __init__(self, joint_topic, torque_topic, imu_topic, odom_topic):
        self.joint_topic = joint_topic
        self.torque_topic = torque_topic
        self.imu_topic = imu_topic
        self.odom_topic = odom_topic
        self.buffer = deque(maxlen=512)

    def aligned(self, t):
        pi = self._nearest_with_interp(t)
        if pi is None or pi.skew > self.delta_sync:
            return None                      # UNKNOWN，而不是猜一个值
        return pi

class EgoMotionDecomposer:
    def __init__(self, fk, base_integrator):
        self.fk = fk
        self.base = base_integrator

    def predict(self, pi):
        T_base = self.base.pose(pi)          # 轮速 + IMU 校正
        return T_base @ self.fk(pi.q) @ self.X_cam_to_ee

    def decompose(self, E, P, M):
        e_self = se3_log(E.inv() @ P)
        e_world = se3_log(P.inv() @ M)
        eta = norm(e_self) / (norm(e_self) + norm(e_world) + 1e-9)
        return e_self, e_world, eta

class SelfCertGenerator:
    def __init__(self, self_model, weight, eps_body):
        self.model = self_model
        self.W = weight
        self.eps_body = eps_body

    def step(self, pi_prev, a_prev, pi):
        pred = self.model.predict(a_prev, pi_prev)
        s = (pi.vec() - pred).norm(self.W)
        slip = abs(pi.v_wheel - pi.v_imu)
        tau_res = pi.tau - self.model.torque(pi.q, pi.qd, a_prev)
        return s, slip, tau_res

    def certificate(self, C, pis):
        s_bar = mean([self.step(*row)[0] for row in pis])
        slips = [t for t, row in enumerate(pis) if self.step(*row)[1] > self.eps_slip]
        h_min = min([row.h_stab for row in pis], default=+inf)
        faults = [t for t, row in enumerate(pis) if row.fault]
        ok = (s_bar <= self.eps_body and not slips
              and h_min >= self.h_stab_min and not faults)
        return SelfCert(s_bar, slips, h_min, faults, ok)

class WholeBodyLoop:
    def prefix_ok(self, C, state, pi):
        for i, (dq, dxi) in enumerate(C.actions):
            if not self.nonholonomic_ok(state.xi, dxi):
                return False, i
            if not self.stability_ok(state.xi + dxi, pi):
                return False, i
            if not self.reachable(state.q + dq, state.xi + dxi):
                return False, i
            if self.collision.check(state.q + dq, state.xi + dxi):
                return False, i
            state = self.step(state, dq, dxi)
        return True, len(C.actions)

class AnchorCalib:
    def ground(self, ell, scene, ontology, anchors):
        if ell is None:
            return self.default_iota
        g = self.resolve_anchor(ell, anchors)
        if g is None or not self.reobservable(g):
            return None                       # ⊥，退回默认目标
        return self.bind_to_anchor(g)

    def update_handeye(self, pi_seq):
        # 用已知关节运动构造 AX = XB，在线求相机外参
        self.X_cam_to_ee = solve_ax_xb(pi_seq, self.cam_poses)

    def needs_reanchor(self):
        return trace(self.Sigma) > self.sigma_max or not self.anchor_ok
```

```python
def propriogauge_m(M, s, ell=None):
    # 0. 本体流：失配就是 UNKNOWN，绝不外推成“正常”
    pi = M.proprio.aligned(M.env.time())
    if pi is None:
        return instructgauge_wr(M, s, ell)        # 退化：单通道 WR v4

    # 1. 锚点相对接地 + 手眼自校准
    M.anchor.update_handeye(M.proprio.recent(0.5))
    iota = M.anchor.ground(ell, M.scene, M.ontology, M.anchors)
    if iota is None:
        iota = M.default_iota

    # 2. 假设与分块规划（块长已含基座运动项）
    H = M.lbox.hypothesize(s, M.dbox.R[s], iota)
    K_max = M.drift.k_max(M.state, pi)            # 定义 476
    if K_max < 1:
        M.anchor.reanchor(M.wristcam)
        return None, None, []
    C = M.iac.plan_chunk(iota, H, M.tools, min(M.budget_left(s), K_max),
                         M.drift.bound(M.state, pi))

    # 3. 全身前缀封闭 + 移动不可逆屏障
    ok, j = M.wbas.prefix_ok(C, M.state, pi)      # IP-337
    if not ok:
        C = M.iac.plan_chunk(iota, H, M.tools, 1, M.drift.bound(M.state, pi))
    C = M.mbar.enforce(C, pi)                     # IP-339：I 级 ⇒ K=1 + checkpoint

    # 4. 提交前双通道检查
    self_ok, self_cert = M.selfcert.certificate(C, M.proprio.span(C))
    if not (M.wristcam.spatial_pre(C) and self_ok):
        return fallback_v4(M, s, ell, reason="dual_channel_pre")

    # 5. 执行：每步做自运动解耦 + 三值否决
    for t, a in enumerate(C.actions):
        pi_t = M.proprio.aligned(M.env.time())
        if pi_t is None:
            C = C.truncate(t)
            break
        P = M.decomp.predict(pi_t)
        e_self, e_world, eta = M.decomp.decompose(
            M.wristcam.expected(C, t), P, M.wristcam.latest())
        sp_ok = not (norm(e_world, M.sigma) > M.eps_world)
        se_ok, _ = M.selfcert.step(C.prev_state(t), a, pi_t)
        verdict = three_valued_and(sp_ok, se_ok, M.anchor.fresh())
        if verdict != "PASS":                     # FAIL 或 UNKNOWN ⇒ fail-closed
            C = C.truncate(t)
            break
        M.env.apply(a)

    # 6. 证书 + 锚定更新 + 主张绑定
    M.anchor.update(M.wristcam, M.proprio.span(C))
    spatial_cert = generate_spatial_cert(C, M.wristcam.tf_seq(C), M.epsilon_vis)
    final_self = M.selfcert.certificate(C, M.proprio.span(C))
    cert = CertBundle(spatial_cert, final_self, M.anchor.cert())
    receipts = M.tcv.get_receipts()
    return C, cert, bind_claims(C, iota, receipts)
```

## 4. 推导

**引理 63（自运动解耦的假阳性抑制与可检测性）**
设真实运动纯为自运动，且本体预测误差 `||e_world|| = ||log(P⁻¹M)|| ≤ ε_p`。则世界残差不超过 `ε_p`；当 `ε_world ≥ ε_p` 时不会触发截断，即消除了“把基座运动误判为约束违背”的假阳性。反之，若真实世界残差 `||e_world*|| > ε_world + ε_p`，则由三角不等式必被检测。证明要点：`se(3)` 局部双不变度量下 `log(E⁻¹M) = log((E⁻¹P)(P⁻¹M))`，故两侧残差可加，误差被 `ε_p` 吸收，扣掉本体项后世界项仍超阈。

**引理 64（双通道漏检界与共模条件）**
在条件独立 `e_world ⟂ s | state` 下，双通道联合漏检概率满足 `P_miss ≤ P_miss^Spatial · P_miss^Self`。若 `ρ_cm > ρ_max`（共享时钟/标定/模型），乘积界失效，只剩并集界 `P_miss ≤ min(P_miss^Spatial, P_miss^Self)`。又因 UNKNOWN 触发 K=1，有效漏检还受 `P(UNKNOWN)` 制约：系统以退化为代价换取“不可解释即不可信”。证明：条件独立给出联合分布可分解；相关时 Cauchy–Schwarz 只给并集界；三值逻辑把 UNKNOWN 归入保守分支。

**引理 65（参考系锚定的证书传递）**
若锚定误差 `ε_a`、基座不确定椭球直径 `diam(U_t)`、手眼标定误差 `ε_calib`，则世界坐标下的空间证书传到基座坐标的误差不超过 `ε_transfer = ε_a + diam(U_t) + ε_calib`。当 `ε_transfer ≤ ε_vis` 时，v4 的 `SpatialCert` 可安全用于移动基座；否则必须重锚定或扩大阈值（显式记录），不能默认传递。

**引理 66（全身前缀封闭的保持）**
若 `WBAS(s)` 对 `(δq, δξ)` 前缀封闭，且稳定性裕度沿可采纳前缀单调不增、其 1-Lipschitz 常数被 `L_s` 界定，则任意可采纳块的前缀仍可采纳；截断到第 `j` 步不会破坏非完整约束与碰撞约束。证明：前缀封闭由定义直接给出；稳定性由 Lipschitz 界沿前缀累积，若整块满足 `h_stab ≥ h_min`，前缀裕度只会更大。

**引理 67（移动不可逆屏障的安全性）**
在 I 级底盘动作处强制 K=1 并在执行前保存检查点，则每次决策至多执行一个不可逆底盘动作；不可逆位移不随块长 K 累积，最坏情况被压到单动作效应。若要求独立回执交叉验证后才继续，则恢复也必须以检查点为基准。证明：对 I 级动作 `K=1` 使“决策—执行”原子化为单步；检查点保存 `(ξ, q, a*, digest)`，后续任何恢复只能回到该状态。

**引理 68（块长上界的存在性与保守性）**
对 `v_max > 0`，`B_total(K)` 关于 `K` 单调不减（`B_arm·K`、`L_base·v_max·K·dt` 线性增长，`tr(Σ_ξ(K))` 非减），故 `K_max = max{K: B_total(K) ≤ B_max}` 唯一且可由二分求得。若 `K_max < 1`，不存在安全分块，必须停止/重锚定。显式上界：
```
K_max ≤ (B_max - B_vis - B_sync) / (B_arm + L_base·v_max·dt + λ·Δtr)
```
这给出“移动越快、块必须越短”的可证伪预测。

**引理 69（严格退化等价）**
当 `v_base = 0` 且本体感知不可用时：`e_self = 0`，`SelfCert = ⊤`，`WBAS = KinematicAdmissibleSet`，`B_total = B_vis + B_arm·K`，`Cert_OK = SpatialCert.is_consistent`。逐项代入即得 ProprioGauge-M ≡ InstructGauge-WR（v4）。同理关闭底盘即回到 WR；WR 失效即回到 InstructGauge v3；再失效回到 ToolGauge。退化链无隐藏依赖。

## 8. 本轮最大风险

**一句话**：本体感知的漂移与系统偏差会被“自运动解耦”吸收成看似合理的解释项，而共享时钟/手眼标定又会让两路证据产生**看起来自洽的共模错误**——此时双通道给出的不是独立验证，而是虚假的安全感；最危险的场景是基座缓慢滑移被稳定地解释为“世界在变”，从而在 K 步分块里静默累积接地误差。
