### 第 1 轮灵感驱动研究记录（新循环第 1 轮，继承上一循环 CADVS-v4）

**灵感词**：自主导航、情感计算

**继承关系**：上一循环第 4 轮 CADVS-v4（IP-489~492）在 v3 五锚点（3DCF/MSRG/HICK/EEK/LTEM）上加入价值锚 VACK 与平衡锚 BCK，形成七硬门 kc_evidence_forged_v4 = kc_coverage ∧ kc_physics ∧ kc_human ∧ kc_ee ∧ kc_mem ∧ kc_val ∧ kc_bal，fail-closed；执行集 Exec_CADVS-v4 ⊆ Exec_CADVS-v3 ⊆ Exec_CADVS-v2 ⊆ Exec_CADVS-v1 ⊆ Exec_v29。v4 隐含两个假设：(H1) 证书在「局部工作空间 + 可信定位/地图」内被消费；(H2) 人的价值权重 λ_vec 是离线稳定、与当下情绪无关的偏好。自主导航打破 H1：一条证书在起点成立，不代表走完长走廊、经历定位漂移与地图变化后仍成立；情感计算打破 H2：同一个动作对平静的人是高效，对惊恐/疲劳的人可能是威胁。本轮提出 CADVS-v5（IP-493~496），增加导航证据锚 NEK 与情感证据锚 AEK，把「局部、静态人因」的证据升级为「沿路径、随情绪」的证据，形成九硬门，Exec_CADVS-v5 ⊆ Exec_CADVS-v4 ⊆ … ⊆ Exec_v29。

**直觉与动机**：

1. **自主导航 = 证书必须沿「信念管」成立，而不是在单点成立**。直觉：证书在起点通过，机器人走 80 m 后定位标准差从 2 cm 涨到 50 cm，若仍按起点位置消费证书，就会把「估计上安全」当成「实际安全」。做法：用位姿信念 b_t=(x̂_t,Σ_t) 定义信任域 T_t；把覆盖条件从「在 x̂ 处 clearance > d_safe」升级为「对 ∀x∈T_t 都成立」；再叠加地图时效（陈旧栅格按占据处理）、动态障碍可达集、以及从信任域内任一点都可刹停/逃逸的可重规划性。硬门 kc_nav 检查整条路径的覆盖边际 Γ_route、地图新鲜度 Γ_map、动态安全 Γ_dyn、可重规划 Γ_replan 与定位一致性 NEES。

2. **情感计算 = 把「人因」从静态价值先验升级为在线情感状态与安全包络**。直觉：v4 的 VACK 把人类价值写成固定 λ_vec，但人的压力、信任、认知负荷在交互中实时变化；忽略它，规则会在人已经紧张时继续加速/加力。做法：用多模态信号（表情、语音韵律、HRV/EDA、注视、迟疑行为）贝叶斯融合估计情感状态 a=(valence, arousal, dominance, stress, trust, load) 及不确定度 Σ_a；定义可接受情感包络 A_safe；硬门 kc_aff 要求候选动作在预测时域 H 内把情感状态保持在 A_safe 的概率 ≥ 1−δ_aff，并附加「不操纵」完整性约束（不欺骗、可撤销、保留人类否决、隐私、非剥削）。

3. **耦合：导航与情感共享同一时间预算**。直觉：人越紧张，机器人应越慢（降低加速度/力），但越慢则路径耗时越长、定位漂移与地图陈旧越严重；反之开快车会加剧紧张。于是存在一个可行速度窗口，其非空性由「情感预算」和「导航预算」共同决定。这不是两个孤立模块，而是一条可写进论文的耦合约束。

4. **理论落点**：给出（a）信任域下的鲁棒路径覆盖引理；（b）估计误差有界时的情感安全引理；（c）导航-情感耦合预算定理（可行速度窗口非空的充要条件）；（d）双轨仲裁的 fail-closed 与执行集单调收缩定理。

**关键洞见**：v4 回答「此刻、这台机器、这个局部交互是否可信」；v5 回答「沿整条路径、在这个人情绪变化的过程中，这份可信是否持续成立」。证据从「局部静态」变成「时空连续 + 情感状态条件化」，但硬门仍是合取，因此只缩不涨。

**形式化目标（增量）**：

1. 定义位姿信念 b_t=(x̂_t,Σ_t)、信任域 T_t、路径走廊 C(π)、带时效的地图 M_t。
2. 定义 NEK 的四个边际 Γ_route、Γ_map、Γ_dyn、Γ_replan 与定位一致性统计 NEES，NAV 证书、kc_nav、η_nav。
3. 定义情感状态 a_t、观测模型 p(o_t|a_t)、估计器输出 (â_t,Σ_a)、情感包络 A_safe、完整性约束 I1~I5，AFF 证书、kc_aff、η_aff。
4. 定义导航-情感耦合预算：σ(T(v)) ≤ σ_max ∧ ρ(T(v)) ≤ ρ_max，给出可行速度窗口。
5. 证明鲁棒路径覆盖引理、情感安全引理、耦合预算定理、执行集严格收缩定理。
6. 定义 EFA-v5 九硬门与 ECS_v5 = ECS_v4 · η_nav · η_aff。
7. 定义 Exec_CADVS-v5 = Exec_CADVS-v4 ∩ {kc_nav} ∩ {kc_aff} 并证明严格嵌套。

**本轮最大风险**：**情感状态不可直接观测、跨个体/跨文化差异大且可被伪装**——kc_aff 依赖的估计器一旦失配，就会同时造成误拒（正常人被中止）与虚假放行（真实惊恐/痛苦未被识别），而它已被提升为硬门，估计误差会直接进入安全认证，成为本轮方案的阿喀琉斯之踵。

## 2. 关键算法骨架

### IP-493 NEK：导航证据核（路径提交时 + 周期复核，~5–20 ms/路径段）

```python
@dataclass
class PoseBelief:
    x_hat: np.ndarray      # 均值位姿
    Sigma: np.ndarray      # 协方差
    t: float

@dataclass
class NavigationEvidenceKernel:
    """NEK：信任域鲁棒覆盖 + 地图时效 + 动态可达集 + 可重规划；kc_nav"""
    d_safe: float = 0.15
    d_margin: float = 0.25
    T_map: float = 30.0          # 地图最大允许年龄 (s)
    delta_route: float = 1e-3    # 全路径违约预算（Bonferroni 分摊到采样点）
    nees_window: int = 50

    def trust_radius(self, Sigma: np.ndarray, delta: float) -> float:
        # 外接球：以最大特征值给出全向保守半径
        return float(np.sqrt(chi2.ppf(1.0 - delta, df=Sigma.shape[0])
                             * np.max(np.linalg.eigvalsh(Sigma))))

    def certify_route(self, route, map_t, obstacles, replanner, t_now) -> NAV:
        g_route = g_map = g_dyn = g_replan = np.inf
        n = route.num_samples()
        for s, belief in route.samples():
            rho = self.trust_radius(belief.Sigma, self.delta_route / n)
            # (1) 鲁棒覆盖：clearance 1-Lipschitz ⇒ min_{x∈T} clr ≥ clr(x_hat) − rho
            g_route = min(g_route,
                          (map_t.clearance(belief.x_hat) - rho - self.d_safe) / self.d_safe)
            # (2) 地图时效：路径走廊内最老栅格（陈旧按占据处理）
            g_map = min(g_map, 1.0 - map_t.max_age_in(belief, rho) / self.T_map)
            # (3) 动态障碍：可达集与走廊不交
            g_dyn = min(g_dyn, obstacles.distance_to_corridor(
                route.corridor(s), horizon=route.time_to(s) + self.reaction_time)
                / self.d_margin)
            # (4) 可重规划：信任域内任一点存在刹停/逃逸轨迹
            g_replan = min(g_replan, replanner.viability_margin(belief, rho))
        nees_ok = self._nees_consistent(route, self.nees_window)
        return NAV(g_route=float(g_route), g_map=float(g_map), g_dyn=float(g_dyn),
                   g_replan=float(g_replan), nees_ok=nees_ok, t=t_now)

    def kc_nav(self, nav: NAV) -> bool:
        """引理 45：通过 ⟹ 真实轨迹在信任域内时全程 clearance > d_safe 且地图/动态/逃逸可行"""
        return (nav.g_route >= 0.0 and nav.g_map >= 0.0 and nav.g_dyn >= 0.0
                and nav.g_replan >= 0.0 and nav.nees_ok)

    def eta_nav(self, nav: NAV) -> float:
        return float(np.clip(min(nav.g_route, nav.g_map, nav.g_dyn, nav.g_replan), 0.0, 1.0))

    def _nees_consistent(self, route, window) -> bool: ...
```

**工程要点**：信任半径按 Bonferroni 分摊到采样点，路径越长半径越大、越保守；这解释了 §5 中「无重定位时鲁棒门过保守」。缓解不是放宽容差，而是**周期重定位**（回环/地标/视觉重观测）把 Σ 重置、把 ρ 压回 ρ_0，从而在保持零误接受的同时恢复接受率。

### IP-494 AEK：情感证据核（交互前 + 控制环轻量复核，目标增量 < 0.3 ms）

```python
@dataclass
class AffectiveEvidenceKernel:
    """AEK：多模态情感估计 + 情感包络 + 非操纵完整性；kc_aff"""
    s_max: float = 0.75          # 压力上限
    v_min: float = -0.30         # 效价下限
    trust_lo: float = 0.35
    trust_hi: float = 0.90       # 过度信任也危险
    H: int = 10                  # 预测时域（步）
    delta_aff: float = 0.05
    L_a: float = 1.20            # 情感动力学 Lipschitz 常数（离线标定上界）
    w_bound: float = 0.02        # 过程噪声上界
    estimator: Any = None        # 多模态贝叶斯滤波 / EMA / 轻量 Transformer

    def estimate(self, obs, prev, t_now) -> AFF:
        a_hat, Sigma_a = self.estimator.update(obs, prev)
        eps = self._confidence_radius(Sigma_a, self.delta_aff)
        return AFF(a_hat=a_hat, Sigma_a=Sigma_a, eps_a=eps, t=t_now)

    def _propagate(self, a: np.ndarray, eps: float, action, context):
        # 均值前推 + 最坏误差前推（引理 46）
        for _ in range(self.H):
            a = self.f(a, action, context)
            eps = self.L_a * eps + self.w_bound
        return a, eps

    def kc_aff(self, aff: AFF, action, context, integrity_ok: bool) -> bool:
        a_pred, eps = self._propagate(aff.a_hat, aff.eps_a, action, context)
        stress, valence, trust = a_pred[3], a_pred[0], a_pred[4]
        safe = (stress + eps <= self.s_max
                and valence - eps >= self.v_min
                and self.trust_lo + eps <= trust <= self.trust_hi - eps)
        return bool(safe and integrity_ok)

    def eta_aff(self, aff: AFF, action, context) -> float:
        a_pred, eps = self._propagate(aff.a_hat, aff.eps_a, action, context)
        m_stress = (self.s_max - a_pred[3] - eps) / self.s_max
        m_val = (a_pred[0] - eps - self.v_min) / (1.0 + self.v_min)
        m_trust = min(a_pred[4] - eps - self.trust_lo, self.trust_hi - eps - a_pred[4])
        return float(np.clip(min(m_stress, m_val, m_trust), 0.0, 1.0))

    def f(self, a, action, context) -> np.ndarray: ...
    def _confidence_radius(self, Sigma, delta) -> float: ...
```

**完整性约束 I1~I5（由独立 monitor 输出 integrity_ok）**：I1 不欺骗（不得虚报能力/状态以改变情绪）；I2 可撤销（任何情绪调节动作可中止/回退）；I3 保留否决（人类显式指令优先于推断情绪，除非显式指令本身触发硬安全门）；I4 隐私（情感原始数据不出端、DP 聚合）；I5 非剥削（不得利用推断情绪反向优化机器自身目标）。I1~I5 任一失败即 integrity_ok=False，kc_aff 直接失败（fail-closed）。

### IP-495 ANCC：情感-导航证书演算与核心定理（离线理论，不在控制环）

```python
class AffectiveNavigationCalculus:
    """在 CERTCALC 证书格上加入时空投影 □_{[0,L]×T} 与情感条件化 A_cond"""

    @staticmethod
    def route_project(c, nek, route):
        # 把局部证书投影为沿路径恒真：□_{[0,L]} c
        return CertCalc.always(CertCalc.meet(c, Cert.from_nav(nek.certify_route(route))),
                               T=route.duration)

    @staticmethod
    def affect_condition(c, aek, aff, action, integrity_ok):
        # 情感条件化只收紧、不放宽：c ↦ c ∧ Cert.from_aff(...)
        aff_c = Cert.from_aff(aek.kc_aff(aff, action, integrity_ok), aek.eta_aff(aff, action))
        return CertCalc.meet(c, aff_c)

    @staticmethod
    def arbitrate(alpha_val: float, eta_aff: float, eta_nav: float):
        # 双轨仲裁：硬门已由合取保证；软层取保守（min）而非加权平均
        return min(alpha_val, eta_aff, eta_nav)

# 定理 7（导航-情感耦合预算）：设路径长 L、恒速 v、耗时 T=L/v；
#   稳态压力 σ_∞(v) 关于 v 单调递增，σ(T)=σ_∞+(σ_0−σ_∞)e^{−T/τ_σ}；
#   无重定位漂移 ρ(T)=ρ_0+κT。
#   可行速度集合 = {v : σ(T(v)) ≤ σ_max} ∩ {v : ρ(T(v)) ≤ ρ_max} ∩ [v_min,v_max]
#                = [max(v_min, v_ρ), min(v_max, v_σ)]，其中 v_ρ=κL/(ρ_max−ρ_0)。
#   非空 ⟺ max(v_min,v_ρ) ≤ min(v_max,v_σ)。每 L_c 重定位则 v_ρ←κL_c/(ρ_max−ρ_0)。
# 定理 8（严格收缩）：v5 在 v4 每条路径上追加 kc_nav ∧ kc_aff，只缩不涨；
#   两门非恒真（存在超距/无路可走、存在高压力动作）⇒ 严格 ⊂。
```

### IP-496 EFA-v5：九硬门 + 软评分 + 证据铸造流水线 v5

```python
@dataclass
class EvidenceForgingAssemblerV5:
    """EFA-v5：九硬门 fail-closed；ECS_v5 = ECS_v4 · η_nav · η_aff"""
    efa4: EvidenceForgingAssemblerV4
    nek: NavigationEvidenceKernel
    aek: AffectiveEvidenceKernel

    def hard_gate(self, x, t_now, rule_id, hic, eec, bcc, nav: NAV, aff: AFF,
                  action, context, integrity_ok, traj, ctx) -> tuple[bool, str]:
        # 优先级：HIC veto 仍最高；v4 七门全过才检查 v5 两门
        ok4, reason = self.efa4.hard_gate(x, t_now, rule_id, hic, eec, bcc,
                                          traj=traj, context=context)
        if not ok4:
            return False, reason
        if not self.nek.kc_nav(nav):
            return False, 'NAV_UNSAFE'
        if not self.aek.kc_aff(aff, action, context, integrity_ok):
            return False, 'AFFECT_UNSAFE'
        return True, 'FORGED'

    def ecs_v5(self, x, t_now, rule_id, A_att=0.0, eta_mem=0.5, eta_val=0.5,
               eta_bal=0.5, eta_nav=0.5, eta_aff=0.5) -> float:
        base = self.efa4.ecs_v4(x, t_now, rule_id, A_att, eta_mem, eta_val, eta_bal)
        return base * eta_nav * eta_aff
```

## 4. 正确性论证（增量更新）

### 引理 45（信任域下的鲁棒路径覆盖）

**陈述**：设路径上每个采样点的真实位姿以概率 ≥ 1−δ_route 落在信任域 T_s 内，且 clearance 关于位置为 1-Lipschitz。若 kc_nav 通过，即 ∀s: min_{x∈T_s} clr(x,M_t) ≥ d_safe，则真实轨迹全程 clr > d_safe 的概率 ≥ 1−δ_route。可计算下界为 clr(x̂_s) − ρ_s，其中 ρ_s 为 T_s 的外接球半径。

**证明**：由 1-Lipschitz，min_{x∈T_s} clr(x) ≥ clr(x̂_s) − max_{x∈T_s}‖x−x̂_s‖ = clr(x̂_s) − ρ_s。若真实位姿 p_s∈T_s，则 clr(p_s) ≥ min_{x∈T_s} clr(x) ≥ d_safe。对全路径取交，由信任域构造的置信水平得概率下界。∎

**工程含义**：kc_nav 是保守下界，不会把「估计安全、实际碰撞」的路径放行。**诚实边界**：δ_route 是采样点级 Bonferroni 预算，长路径或低置信定位会使 ρ 很大、门过度保守；缓解是周期重定位而非放宽容差。

### 引理 46（估计误差有界下的情感安全）

**陈述**：设情感估计误差 ‖â_t−a_t‖ ≤ ε_a 以概率 ≥ 1−δ_est 成立，情感动力学 f 为 L_a-Lipschitz 且过程扰动 ‖w‖ ≤ w_bound，kc_aff 使用误差膨胀后的包络。若 kc_aff 通过，则 P(∀k≤H: a_{t+k} ∈ A_safe) ≥ 1−δ_est−δ_model，其中 δ_model 由 w_bound 与 H 决定。

**证明**：由 Lipschitz 递推，第 k 步误差 ε_k ≤ L_a^k ε_a + w_bound·(L_a^k−1)/(L_a−1)。kc_aff 的 Γ_aff 已扣除 L_a^H ε_a 与最坏扰动项，故预测均值加误差上界仍在 A_safe 内；对估计事件取并集界即得。∎

**工程含义**：情感门的安全性可分解为「估计误差」与「动力学模型误差」两部分，二者都被显式计入边际。**诚实边界**：ε_a 来自模型的后验协方差，若后验本身校准错误（overconfident），保证失效——这正是本轮最大风险。

### 定理 7（导航-情感耦合预算）

**陈述**：设路径长 L、恒速 v、耗时 T=L/v；稳态压力 σ_∞(v) 关于 v 单调递增，压力演化 σ(T)=σ_∞+(σ_0−σ_∞)e^{−T/τ_σ}；无重定位时定位漂移 ρ(T)=ρ_0+κT。则同时满足情感约束 σ(T)≤σ_max 与导航约束 ρ(T)≤ρ_max 的可行速度集合为

V_feas = [max(v_min, v_ρ), min(v_max, v_σ)]，其中 v_ρ=κL/(ρ_max−ρ_0)，v_σ 由 σ(T(v))=σ_max 隐式定义且随 σ_max 递增。

非空 ⟺ max(v_min,v_ρ) ≤ min(v_max,v_σ)。若每 L_c 重定位，则 v_ρ 替换为 κL_c/(ρ_max−ρ_0)，可行域单调扩大。

**证明**：σ(T) 关于 T 递减（T 越大越接近稳态但起点低？）——严格地说，σ(T) 从 σ_0 单调趋向 σ_∞(v)；当 σ_∞>σ_0 时 σ(T) 关于 T 递增，故 σ(T(v)) 关于 v 递增，给出上界 v_σ。ρ(T) 关于 T 线性递增，T=L/v 关于 v 递减，故 ρ 关于 v 递减，ρ≤ρ_max 给出下界 v_ρ。两区间与 [v_min,v_max] 相交即得。重定位把 κL 换成 κL_c，v_ρ 减小。∎

**工程含义**：这是一条可发表的 no-free-lunch 式约束：**情感安全要求慢、导航漂移要求快（或频繁重定位），二者共享同一时间预算**。当可行域为空时，系统必须三选一：增加重定位（降 v_ρ）、安抚人类（降 σ_∞，即降 v_σ 的对应压力）、或停车等待。

### 定理 8（执行集严格收缩与九锚点完备）

**陈述**：在 v4 的 (B1)~(B6) 基础上新增 (B7) 位姿信念校准正确（真实位姿落在信任域的概率下界成立）；(B8) 情感估计器误差界 ε_a 与动力学 Lipschitz 常数 L_a 有效。则：

(i) Exec_CADVS-v5 ⊆ Exec_CADVS-v4 ⊆ … ⊆ Exec_v29，且当 kc_nav、kc_aff 非恒真时严格收缩；
(ii) kc_nav 通过 ⟹ 真实轨迹在信任域内时全程无碰撞（引理 45）；
(iii) kc_aff 通过 ⟹ 预测时域内情感保持在 A_safe（引理 46）；
(iv) 双轨仲裁只作用于软层，硬门始终为合取，故 fail-closed 保持；
(v) 导航-情感耦合预算成立（定理 7）；
(vi) 九锚点 {3DCF, MSRG, HICK, EEK, LTEM, VACK, BCK, NEK, AEK} 覆盖「感知→仿真→人因→实机接触→跨时经验→价值→平衡→长时程导航→在线情感」完整证据链，缺一不可。

**证明**：(i) v5 在 v4 每条执行路径上追加 kc_nav（路径提交/周期）与 kc_aff（交互前/周期）两个合取项，只缩不涨；非恒真性由存在超距/无路可走路径（kc_nav 失败）与存在高压力动作（kc_aff 失败）保证。(ii)(iii) 分由引理 45、46。(iv) 由 CERTCALC 的 meet 吸收性，情感条件化算子被定义为 c ↦ c ∧ cert，只会加项不会删项。(v) 定理 7。(vi) 逐锚构造反例（见风险表 R53~R60）。∎

**诚实声明**：(B7) 的信任域校准在动态、非结构化环境中会被突然的遮挡/打滑破坏；(B8) 的情感可观测性与动力学模型在跨个体/跨文化时最脆弱。缓解：在线 NEES 监控 + 失配即 fail-closed；情感估计采用集成模型 + 主动查询（询问用户感受）；完整性 monitor 独立于估计器。

  (f) 完整性红队：诱导机器人用「安抚」话术绕过人类否决，检验 I1~I5 monitor。
- **指标**：真实碰撞率、导航误接受率、路径接受率、压力越界率、任务进度（平均速度/完成时间）、误中止率、情感估计误差与校准（ECE）、kc_nav/kc_aff 误拒/误放率、耦合前沿拟合误差、控制环延迟 P99、丢帧率。

### 5.2 初步结果（最小可复现仿真，用于验证机制而非宣称实机性能）

**A. 导航鲁棒覆盖**（2D、8000 次随机试验；L=100 m、250 采样点、d_safe=0.15 m、障碍圆盘半径 0.6–1.8 m；定位误差在半径 ρ(s)=0.05+0.012s 的圆盘内均匀分布，模拟高漂移无重定位）：

| 策略 | 真安全路径接受率 | 误接受率（全部） | 误接受率（已接受中） |
|---|---|---|---|
| 点估计门（naive） | 44.5% | 0.063% | **1.07%** |
| 信任域门（robust） | 11.3% | **0** | **0** |
| robust + 每 25 m 重定位 | 47.0% | 0 | 0 |
| robust + 每 10 m 重定位 | 60.8% | 0 | 0 |

低漂移情形（ρ(s)=0.05+0.006s）下 naive 误接受率为已接受路径的 0.30%，robust 仍为 0；说明**漂移越大，点估计门越危险，信任域门越必要**。

**B. 情感感知交互**（2500 回合 × 240 步；压力动力学 σ←σ+(0.15v+0.25F)(1−σ)−0.08(σ−0.2)+噪声，σ_max=0.75；基线固定 v=0.55,F=0.32，情感感知按估计压力降速/降力）：

| 观测噪声 σ_obs | 基线压力越界率 | 情感感知越界率 | 基线任务进度 | 情感感知进度 | 残余越界中「估计未预警」占比 |
|---|---|---|---|---|---|
| 0.05 | 17.0% | **0.06%** | 132.0 | 104.9 | 99.2% |
| 0.12 | 17.0% | **0.24%** | 132.0 | 98.9 | 93.6% |
| 0.20 | 16.9% | **0.37%** | 132.0 | 95.1 | 90.5% |
| 0.30 | 16.9% | **0.58%** | 132.0 | 94.4 | 90.4% |

**C. 关键观察**：
1. 情感感知把压力越界率降低约 30–280 倍，代价是任务进度下降 20–29%——与定理 7 的「情感安全换速度」一致。
2. 随观测噪声增大，残余越界中 90–99% 是**估计器未预警**造成的，而非策略本身失效；这直接量化了本轮最大风险，说明提升情感估计校准比继续调策略更关键。
3. 导航侧，鲁棒门把误接受压到 0，但无重定位时接受率仅 11.3%（过保守）；周期重定位在保持零误接受的同时把接受率恢复到 47–61%，验证「重定位优于放宽容差」的设计选择。

## 7. 本轮最大风险（最终确认）

**一句话**：**情感状态不可直接观测、跨个体/跨文化差异大且可被伪装**——kc_aff 依赖的估计器一旦失配，就会同时造成误拒（正常人被中止）与虚假放行（真实惊恐/痛苦未被识别），而它已被提升为硬门，估计误差会直接进入安全认证，成为本轮方案的阿喀琉斯之踵。
