# 第 2 轮 · GEM：把最后 5 厘米交给三维语义地图与 MPC

> 检索/复核日期：2026-10-24（UTC）。赛事身份不变：用户所指是宇树科技的 **UniBot 世界挑战赛**（unibot.unitree.com），G1 + Dex1、32 项桌面任务、通才单模型赛道、选手自部署 + 官方远程真机 API 评测。本轮是当前灵感循环的第 2 轮，承接状态文件里的第 7 轮 PILOT。三个灵感词是「三维感知」「最优控制」「语义地图」。我先用它们去撞本轮核实到的官方事实，结果撞出一个必须修正上一轮假设的结论：**排行榜先按平均成功率排序，步骤分只在成功率相同时作 tie-break（[S5] 1.2）**。因此，上一轮“终局放置占约 40% 步骤分”的主论据要降级；真正的主论据是——**终局放置/插入是 32/32 任务的成功闸门，而成功率是唯一主排序键**。在这个规则下，最值得押注的不是再训一个更大的 VLA，而是给现有 VLA 加一层**任务级 3D 语义地图 + 不确定性感知 MPC + 可验证谓词**的测试时“几何-控制外骨骼”：把最后一公里从开环动作块变成闭环最优控制，并且不引入第二个任务模型。

## 0. 本轮先核实：六个会改变判断的事实

### 0.1 排名规则：成功率优先，步骤分只是 tie-break

英文手册 1.2 写得很清楚：实时榜单按 32 个任务的**总平均成功率**排序；成功率相同才看总平均步骤分；仍相同则更早提交者靠前（[S5]）。中文手册同文（[S6]）。官网首页写“按平均成功率与步骤分综合排序”，是模糊表述；以手册为准。

这条修正很重要：

```text
旧假设（第 7 轮）：排名 = 成功率与步骤分综合排序
新事实（本轮）  ：排名 = 平均成功率 ＞ 平均步骤分（仅 tie-break）
```

于是上一轮“终局放置占 39.8% 步骤分、所以是最大单项”的算术仍然成立，但它不再是主目标；**主目标是“整条 episode 是否成功”，终局步是 32/32 任务的闸门**。这反而让“失败检测 + 重试/修复”的价值更高：在 180 秒预算内，一次失败后的恢复可以把 0 变成 1，而步骤分只在并列时才有用。

### 0.2 官方榜与运行记录仍是占位，`<30%` 只能当先验

本轮 2026-10-24 23:06 UTC 实测：`leaderboard.html` 与 `runs.html` 仍是「即将发布 / Coming Soon」（[S2][S3]）；`leaderboard_data.json` 直连返回风控 HTML，无法复核。上一轮抓到的 8 模型占位表头部成功率 29.7%，是 `gen_leaderboard.py` 脚本生成的占位数据，不可当真实排名。用户所说“榜首不到 30%”与这个占位头部一致，但**本轮无法从官方渠道证实**，只能作为“待验证先验”。

如果真实头部也低于 30%，它说明的不是“大家语义理解差”，而是**执行可靠性在 OOD 下普遍不过关**：位置/背景/干扰物/未见物品/人为干扰五个轴里，模型都能大致看懂任务，但最后几厘米的放置、插入、闭合、恢复经常失败。这正好是显式三维几何与闭环控制的主场。

### 0.3 数据集已经把“做 3D”的门槛降得很低

本轮重新拉取 HangCup 的 `meta/info.json`（[S14]）：

- 1,043 episodes / 194,564 frames / 30fps；32 个数据集 lastModified 均为 **2026-10-14**（[S12][S13]）。
- 四路视频：`head_stereo_left/right`、`wrist_left/right`，480×640。
- **`camera_params` 直接给了标定**：头部双目左右内参、畸变、双目 R/T（基线 58.25 mm，fx≈282.4 px，rectified=true）；左右腕部彩色/IR 内参、IR1–IR2 基线 18.05 mm。
- 状态里不只有双臂和夹爪，还有 `state_torso`、`state_d435`、`waist_state_joint`、EE 位姿的 base/torso 两套坐标（[S14]）。
- 官方 WLA 的数据规范明确了 base 系：x 前、y 左、z 上；EE 动作是相对当前 EE 的 SE(3) 变换；状态是 60 维统一向量（[S19]）。

这意味着：**33k 演示不只是“动作轨迹”，而是带机器人运动学与相机标定的多视角 3D 记录**。用它们离线构建“任务级 3D 语义地图先验”是可行的，而且不需要新传感器、不需要额外采集。

但要把边界说清楚：数据集有头部双目的内参和基线，**没有直接给出“头部相机到 base”的外参**；`state_d435`/`state_torso` 给了运动学线索，头部相机到 torso、腕部相机到 EE 的安装外参需要离线手眼标定。推理接口只暴露 `lower_body`（含 waist yaw/roll/pitch）和 EE base 位姿，不暴露 `state_d435`/`state_torso`；因此测试时要靠 waist FK + 离线标定的安装外参，把相机放到 base 系里。这是一个必须做的工程步骤，也是主要风险之一。

### 0.4 提交接口 v2 对“3D + MPC”是友好的，但有几个坑

本轮重读 `unibot_submission` README（[S16]，v2 提交 2026-08-21，[S17]）：

- 观测四路 RGB：`cam_left_high`、`cam_right_high`、`cam_left_wrist`、`cam_right_wrist`；双臂关节/EE base 位姿、夹爪、`lower_body[15]`（最后 3 维是 waist yaw/roll/pitch）、`observation.language` 单字符串。
- 动作空间二选一：`joint` 或 `ee`；`action_chunk_size` 自定；`obs_delta_indices` 决定传哪些键、每键堆叠几帧；`image_resize` 自定。
- **N 台评测机器人，要求从 8765 起连续 N 个端口**；每端口独立完成交互，状态必须隔离（[S16] 5）。
- 官方会记录每步延迟与动作统计规律，并可能把延迟稳定性/动作异常作为结果可信度的一部分（[S16] 6）。

两个坑：

1. **相机键名和数据集不一致**：数据集是 `head_stereo_left/right`、`wrist_left/right`，接口是 `cam_left_high/right_high`、`cam_left_wrist/right_wrist`。必须按“角色”映射，不能按字符串硬编码。
2. **接口没有相机内参/外参**：数据集有，测试时没有。要么假设评测机与数据集同型（需向官方确认），要么在测试时做自标定/在线校正；否则 3D 目标的尺度会偏。这个未知项必须写进风险表。

### 0.5 公开可见的“头部做法”：全量 LoRA 已经商品化，差异化不在“再训一个 VLA”

官方基座：UnifoLM-WLA-1.0-Base，6B，约 2,500 小时真机数据、64 个任务，官方描述强调“interaction-centric world modeling”和“spatial perception”（[S18][S20]）。它大概率是很多队的起点。

公开的参赛侧配方：`ezhoureal/lingbot-vla-v2-unibot-lora` 把 LingBot-VLA 2.0（6.3B：Qwen3-VL-4B + Qwen2 action expert/MoE）在 **UniBot 全量 33,276 episodes** 上 LoRA rank 64、10K steps、单张 RTX 4090 训练，合并成单个 full-model checkpoint；joint 控制，臂/夹爪/waist/base 的相对 delta（[S21]）。这不是排行榜证据，但它说明：**“拿一个 6B VLA + 全量数据 + LoRA”已经是低成本、可复制的基线**；验证 loss 0.085 也不等于真机成功率。

四个官方 fork（Terry1504、hausmanj、khanhthanhdev、caiyueliang）目前都还是模板 README，没有公开的头部方案。因此“头部怎么做”无法从公开材料直接核实；能确定的是：**数据规模与基座权重正在商品化，真正稀缺的是测试时的几何状态、接触控制与恢复能力**。这也是本轮把研究火力从“再训一个 VLA”转向“测试时外骨骼”的原因。

### 0.6 规则里的硬约束与未读到的部分

已核实（[S5][S6]）：

- 只能提交**一个模型**完成全部 32 个任务；不得按任务混用多个模型；架构不限（World Model、VLA 都可）。
- 每个任务 **10 次独立运行**，5 类泛化各 2 次；单次真机最长 **180 秒**，超时算失败。
- 不计分的单任务测试通道存在，但不进榜。
- 数据资源：每队可获得 32 个任务的全部真机数据。

未核实/需邮件确认：

- 外部数据、自采数据、第三方预训练权重是否允许；
- 辅助感知模型（SAM/DepthAnything/FoundationPose 等）是否算“第二个模型”；
- 评测机相机内参/外参是否与数据集一致；
- N 的准确数量、每端口延迟上限、调试槽可用次数。

这些未知项直接影响 3D 方案的合规边界，默认按最保守方式设计：**最小合规版只用官方数据 + 单个 VLA + 确定性几何/控制代码，不引入第二个学习模型**。

## 1. 三个灵感词，各自钉到官方事实上

### 1.1 三维感知：头部双目做“米级地图”，腕部 RGB 做“厘米级伺服”

先把物理误差算清楚。头部双目基线 b≈58.25 mm，fx≈282.4 px；视差误差 σ_d 取 0.5 px 时：

```text
σ_z ≈ z² / (fx · b) · σ_d
z=0.3m → 2.7 mm
z=0.5m → 7.6 mm
z=0.7m → 14.9 mm
```

桌面任务的工作距离大约 0.4–0.7 m，所以头部双目的深度误差是 **5–15 mm 量级**：足够做“物体在哪个槽位、容器在哪、自由空间在哪”的米级/厘米级地图，**不够做插头的毫米级对孔**。这决定了正确的分工：

- **头部双目 + 机器人运动学**：构建任务级 3D 语义地图、估计容器/槽位/自由空间、给 MPC 提供粗目标与碰撞约束。
- **腕部 RGB**：最后 3–5 cm 的 2D 视觉伺服、对孔/对边/对槽的细对齐、接触前后的视觉校验。
- **不要依赖腕部 IR**：数据集标定里有腕部 IR 内参，但推理接口只给 RGB；IR 图像不在观测目录里。腕部单目深度若被允许可作为增强，否则老老实实做 2D 伺服。

这条“粗 3D + 细 2D”的混合路线，比“全靠 3D”更符合 G1 的传感器现实，也比“全靠 2D”更能抗遮挡和背景变化。

### 1.2 最优控制：不是扭矩级 MPC，而是 EE 空间的重规划外骨骼

接口给的是 EE 位姿动作块，不是扭矩；所以我们做的是**任务空间滚动时域 MPC**：

- 状态：EE 位置/姿态/速度/角速度；模型用双积分器/运动学模型；
- 控制：EE 加速度（或速度）序列；
- 约束：工作空间、速度/加速度/加加速度上限、与地图 ESDF 的碰撞距离、放置/插入的姿态约束、支撑/接触约束；
- 代价：到 3D 目标的位置/姿态误差 + 速度/加速度平滑 + 碰撞罚 + 目标协方差（不确定性）；
- 求解：小规模 QP/SCP，horizon 10–15 步（0.33–0.5 s），CPU 上 5–20 ms；输出前若干步作为 action chunk，下一次 `get_action` 再重规划。

这不是上一轮砍掉的“运行时全物理仿真/MPC”。上一轮砍的是依赖全物理仿真的重型 MPC；本轮引入的是**只依赖任务空间运动学 + 地图 ESDF 的轻量 MPC**，不解刚体接触动力学，接触段用“接触代理 + 柔顺步进”处理。两者在工程复杂度上差一个量级。

接触代理是接口约束下的关键发明：观测里没有力/力矩，但每一步都有**实际 EE 位姿**。把“上一条命令的 EE 位姿”和“当前实际 EE 位姿”的差（位置 + 姿态）当作接触/受阻信号：

```text
c_t = ||p_cmd − p_act|| / σ_p + ||Log(R_cmdᵀ R_act)|| / σ_R
```

自由空间 c_t 应很小；插入/放置受阻时 c_t 上升。超过阈值就切柔顺模式：降增益、沿插入轴小步走、横向用腕部视觉纠偏；连续 N 步没有沿轴进展就退回 5 mm、重新对中；再失败就重抓。没有力传感器也能做出“感知受阻”的闭环。

### 1.3 语义地图：不是 SLAM 地图，是“任务级 3D 语义先验 + 可验证谓词”

这里的“语义地图”不是给导航用的占据栅格，而是**每个任务一张、从演示中提取的对象中心 3D 图**：

- 节点：目标物、容器、支撑面、槽位、干扰物、人手；
- 边：on / in / aligned / inserted / occludes / articulated / supports；
- 属性：类别、可操作 affordance、6D 位姿 + 协方差、开合/满空状态、所属评分步骤；
- 槽位：支撑面上的候选放置区域，带释放位姿分布、接近方向、容差。

离线用 33k 演示构建这张图的**先验分布**（不是单张固定布局）：同一任务的不同演示给出物体/容器的位姿分布、放置模式、接近锥、失败恢复片段。在线用当前观测做**配准 + 实例更新**：可见物体用双目/分割/6D 位姿更新，被遮挡物体保留先验并放大协方差；容器/桌面提供全局锚点，把先验变换到当前场景。

这张图同时干三件事：

1. **给 VLA 提供显式目标**：槽位/锚点/6D 位姿，替代纯 2D overlay；
2. **给 MPC 提供约束**：ESDF、支撑面、接近方向、插入轴；
3. **给评分步骤提供真值**：`on/in/stacked/inserted/closed` 这些谓词直接在图上算，完成/未完成不再靠黑箱；人把叠好的碗拿走、把拉链拉开，图上的谓词翻转，立刻触发恢复。

这就是“语义地图”在 UniBot 里的正确用法：**它不是另一个大模型，而是一张可检查、可更新、可验证的任务状态图**。

## 2. 本轮主判断：从“2D 锚点 + 位姿统计”升级到“3D 语义地图 + MPC 外骨骼”

### 2.1 上一轮 PILOT 的方向对，但几何核心太弱

PILOT 的三件事是对的：评分步骤图（SSG）、放置位姿迁移（OPT）、落点闭环（SVL）。但它有三个结构性弱点：

- **2D 锚点视角依赖**：背景一换、遮挡一来，锚点就漂；容器 6D 位姿从单视角估计很脆。
- **K 条演示的位姿统计假设容器可观测**：容器被挡住时没有目标；K 条也不足以覆盖位置/未见物品的分布。
- **SVL 是启发式循环，不是控制律**：没有碰撞/支撑/姿态约束，没有接触推理，遇到插头/网线/试管这类接触丰富任务只能靠碰运气。

本轮的升级不是推倒重来，而是把几何核心换掉：

| 上一轮 | 本轮 | 关系 |
|---|---|---|
| PGL 2D 锚点阶梯 | 3D 任务地图 → 2D 投影 → 6D 位姿 | 升级；2D 保留为回退 |
| OPT K 条演示位姿统计 | 全量演示的任务地图先验 + 在线配准 | 升级；K 条统计保留为 baseline |
| SVL 启发式 settle | MPC + 接触代理 + 谓词校验 | 升级；settle 保留为最后一步 |
| SSG 学习谓词头 | 地图上的几何谓词 + 学习兜底 | 升级；SSG 仍是骨架 |
| ICR 检索条件化 | 降为可选动作先验 | 降级；不再当状态估计 |

### 2.2 成功率优先，让“终局闸门 + 重试”比上一轮更值钱

上一轮的杠杆算术是“终局放置 +Δ ⇒ 全局 +Δ×q”。在成功率优先的规则下，这个逻辑更强：

```text
成功率 = P(整条 episode 所有步骤完成)
终局步 = 32/32 任务的最后闸门
一次失败后的重试/修复 = 把 0 变成 1
步骤分 = 只在成功率并列时决定名次
```

所以本轮把预算从“提高步骤分”进一步移到“**确保整条成功**”：

- 终局放置/插入/闭合的成功率；
- 失败检测的准确率（知道自己没成功）；
- 180 秒内的重试/修复成功率；
- 人为干扰后的恢复成功率。

这四件事正好是 3D 地图 + MPC + 谓词验证的组合拳。

### 2.3 为什么是“跨五轴”的杠杆

五个泛化轴（位置/干扰物/背景/未见物品/人为干扰）里，模型都要做最后那一下放置/插入；也都要在失败后恢复。3D 地图是对象中心的，不依赖背景像素；配准把先验拉到当前位置，不依赖训练布局；ESDF 把干扰物变成碰撞约束；谓词把人为干扰变成状态翻转。**它不是某一个轴的补丁，而是五个轴共用的执行层**。

对比“再补一个轴”：

| 改进 | 作用范围 | 对平均成功率的增益 |
|---|---|---|
| 单轴 +Δ | 该轴 1/5 权重 | ≈ Δ/5 |
| 终局执行 +Δ | 全部轴 × 全部任务 | ≈ Δ×q（q≈0.5–0.7） |

差距仍是 2.5–3.5 倍。区别是：上一轮用“2D 锚点 + 位姿统计”去吃这个杠杆，本轮用“3D 地图 + MPC”去吃，后者的上限更高，因为它直接解决米级/厘米级状态与接触。

### 2.4 证据链：3D/地图/控制三件事都有 2026 年的硬结果

- **POT-VLA**（G1，2026-07）：持久 3D 对象 token + 几何谓词验证，把 GR00T-N1.7 基线从 39/80 提到 71/80；最大增益在“需要维持 3D 关系”的任务（[S23]）。这直接证明“持久 3D 对象状态 + 可验证谓词”在 G1 上有效。
- **VistaVLA**（2026-07）：3D Gaussian 几何-语义 token，真实任务 +22.8%，OOD +30.0%（[S24]）。
- **3DS-VLA**（2025/2026）：3D 空间关键点/affordance，多任务/多 embodiment 泛化（[S25]）。
- **DepthVLA**（2025）：深度专家，Simpler WidowX 74.8% vs π0 58.8%（[S26]）。
- **LingBot-VLA**（2026）：去掉深度后，干净环境掉 3.76 个百分点、随机化环境掉 8.58 个百分点（[S22]）——**OOD 越强，3D 越值钱**。
- **AnySlot**（2026）：显式视觉槽位目标优于 VLM 坐标回归，零样本槽位放置（[S27]）。
- **ActivePose / SE(3)-PoseFlow**（2025–2026）：用位姿不确定性驱动 next-best-view，主动消除 6D 歧义（[S28][S29]）。
- **ChronoGraph / 3DSG survey**（2026）：4D 功能场景图、3D 场景图的开放挑战，明确指出“图应更显式地作为规划器的记忆”（[S30][S31]）。
- **VLMPC**（2024/2025）：VLM + MPC 的分层操作，MPC 负责约束与前瞻（[S32]）。
- **VLA-Corrector**（2026）：阶段感知的可观测状态 + 闭环恢复，说明“知道自己走到哪一步”是恢复的前提（[S33]）。
- **AHEAD**（2026）：冻结 VLA + latent 世界模型做动态物体拦截，说明“测试时外骨骼”可以不重训 VLA（[S34]）。

这条证据链的共同结论：**3D/地图/控制不是玄学，单项都有硬增益；缺的是把它们组合成一个低延迟、可验证、能恢复的测试时系统**。而这正好是比赛最需要的。

### 2.5 与最接近的工作的差异

最接近的是 POT-VLA（[S23]）：它也维护持久 3D 对象记录，也做几何谓词验证，也在 G1 上验证。差异：

- POT-VLA 把 3D 记录变成 token 注入 action expert，需要训练/集成；GEM 把它做成**外部地图 + MPC**，最小版本不重训 VLA，可以直接套在 WLA/LingBot/π0.5 上。
- POT-VLA 的验证主要用于“判断动作是否达成关系”；GEM 的地图还用于**目标选择、碰撞约束、接触代理、恢复触发**，是控制回路的一部分。
- POT-VLA 的对象记录来自 RGB-D；GEM 的地图先验来自**33k 演示的离线任务图**，在线只做配准/更新，因此对遮挡和位置变化更稳。

另一条接近的路线是把 3D 场景图作为模仿学习的显式记忆：它把图喂给 diffusion policy；GEM 不训练新 policy，而是把图喂给 MPC 和谓词。两者可以叠加，但 GEM 的更轻、更适合单模型/自部署约束。

## 2. 评分算术：为什么终局执行仍是第一杠杆

### 2.1 成功率优先，让“整条成功”比“部分分”更值钱

```text
成功率 = P(所有步骤完成)                  # 0/1，终局失败整条归零
步骤分 = Σ 步骤权重 × P(该步完成)          # 只在成功率并列时 tie-break
排名   = 平均成功率 ＞ 平均步骤分 ＞ 提交时间
```

因此，任何能提高“整条 episode 成功率”的改动，优先级都高于“让已成功的 episode 步骤分更高”。终局放置/插入/闭合是 32/32 任务的最后闸门；失败检测与重试把 0 变成 1；这两件事的边际收益最高。

### 2.2 终局闸门与部分分诊断

终局步骤权重合计 39.8%，但它的真正价值是**闸门**：终局失败，前面所有步骤分都白拿。部分分仍有诊断价值：

- 若某任务的步骤分高、成功率低，说明失败集中在后段（终局或倒数第二步）。
- 若步骤分也低，说明抓取/接近阶段就有问题。
- 这两类失败需要不同策略：前者用地图/MPC/谓词，后者用抓取/感知/恢复。

### 2.3 跨轴杠杆

五个泛化轴（位置/干扰物/背景/未见物品/人为干扰）里，模型都要做最后那一下放置/插入；也都要在失败后恢复。3D 地图是对象中心的，不依赖背景像素；配准把先验拉到当前位置，不依赖训练布局；ESDF 把干扰物变成碰撞约束；谓词把人为干扰变成状态翻转。**它不是某一个轴的补丁，而是五个轴共用的执行层**。

| 改进 | 作用范围 | 平均成功率增益 |
|---|---|---|
| 单轴 +Δ | 该轴 1/5 权重 | ≈ Δ/5 |
| 终局执行 +Δ | 全部轴 × 全部任务 | ≈ Δ×q（q≈0.5–0.7） |

差距约 2.5–3.5 倍。上一轮用“2D 锚点 + 位姿统计”吃这个杠杆；本轮用“3D 地图 + MPC”吃，后者的上限更高，因为它直接解决米级/厘米级状态与接触。

### 2.4 时间预算

- 演示中位数约 6–10s/任务；官方限时 **180s**。
- 每个终局放置点允许 1–2 次重试 + 0.5s 级 settle 校验。
- 长程任务（T16/T17/T31，4–5 步）需要重试上限（建议 ≤2 次/task）。
- 恢复预算建议占全局 20–30%，不要把所有时间花在第一次尝试的“完美轨迹”上。

### 2.5 预算分配建议

```text
3D 地图 + 配准（TMP/CFR/SPD）        25%
MPC + 接触代理（UMPC/CPA/ECA）       25%
谓词 + 恢复（MDO/BRP/CDR）           20%
VLA 基线 + overlay（GPR/MVI）        15%
工程/部署/统计（INT/SMA/PSB）        15%
```

### 3.1 总览

一句话：**SSG 给步骤，地图给状态，VLA 给语义先验，MPC 给精确执行，谓词给成功判定。**

### 3.2 离线：任务级 3D 语义地图先验（TMP）

不是给导航用的 SLAM 地图，而是**每个任务一张、从演示中提取的对象中心 3D 图**：

- **节点**：目标物、容器、支撑面、槽位、干扰物、人手。
- **边**：`on / in / aligned / inserted / occludes / articulated / supports`。
- **属性**：类别、affordance、6D 位姿 + 协方差、开合/满空状态、所属评分步骤。
- **槽位**：支撑面上的候选放置区域，带释放位姿分布、接近方向、容差。
- **ESDF**：由演示点云 + 当前场景点云融合的欧氏符号距离场，给 MPC 做碰撞约束。

离线构建步骤：

1. 解析 33k episodes，提取四路视频、状态、EE 位姿、camera_params。
2. 手眼标定：`T_T^H`、`T_E^W`；若 `state_d435` 就是头部相机状态，则直接用它做监督；否则用固定安装 CAD + 多视角 bundle adjustment 标定。
3. 多视角重建 + 对象跟踪：双目 SGBM/RAFT-Stereo 深度 → 点云；SAM2/颜色形状分割 → 对象掩码；FoundationPose/ICP → 6D 位姿；跟踪得到轨迹。
4. 规范系对齐：桌面平面 → 任务系 F；容器 6D 位姿 → 容器系 C；把释放位姿写成 `H_i = T_C^{-1} T_E(t_release)`。
5. 聚类：对每个任务/步骤的 `H_i` 做 GMM/核密度，得到均值、协方差、模态、95% 分位容差 `τ_task`。
6. 构建图：对象/容器/槽位节点 + 关系边 + 接近锥 + ESDF。
7. 验证：重投影 <5px、桌面平面 <5mm、对象位姿 <1cm、释放位姿在演示分布内；不达标不入库。

产物：`maps/<task>.npz`（节点/边/槽位/GMM/ESDF/接近锥/谓词模板），单任务 <50MB，总计 <2GB。

防过拟合：地图只存对象/容器的**相对位姿与槽位分布**，不存绝对场景坐标或背景纹理；在线必须配准后才使用，避免把演示布局背下来。

### 3.3 在线：配准、不确定性与地图更新（CFR）

在线每 `get_action` 或每 3–5 步：

1. 头部双目 → 点云；腕部 RGB → 局部细节。
2. 粗配准：桌面平面 + 容器检测 → RANSAC/Umeyama 求 `T_B^F`；用语言/属性做语义关联（Hungarian）。
3. 精配准：分割对象/容器的 point-to-plane ICP；鲁棒核（Cauchy）抗遮挡/干扰。
4. 地图变换：`M_t = T_B^F · M_prior`；可见节点用观测更新，遮挡节点保留先验并放大协方差。
5. 变化检测：与上一帧地图比较，检测物体消失/移动/新增；人为干扰触发步骤回退。
6. 不确定性：`Σ_target = J_T Σ_F J_T^T + Σ_H + Σ_calib`；若 Mahalanobis 距离超阈值，触发主动重观测或降速。

关键设计：**离线重感知，在线轻几何**。离线可以用 SAM/FoundationPose 等重型模型建图；在线只用经典分割/ICP/平面拟合 + 单 VLA，避免“第二个学习模型”的合规风险，也降低延迟。

### 3.4 地图→VLA 的单模型接口（MVI）

不改变提交接口、不增加第二个模型：

- 把地图的 3D 目标/槽位/插入轴投影到头/腕图像，渲染成十字、朝向箭头、容差圈、插入轴线。
- 训练时用演示真实目标做同样的渲染 → 同分布 overlay；推理时用地图预测做渲染。
- VLA 仍是“语言 + 4 视图 → 动作 chunk”，只是图像里多了几何提示。
- 地图同时给 MPC 提供目标/约束；MPC 的输出可以与 VLA chunk 融合（见 3.5）。

这样既保留单模型，又把 3D 信息注入 VLA，不需要改网络结构或加 token。

### 3.5 不确定性感知任务空间 MPC（UMPC）

不是扭矩级 MPC，而是 EE 空间的重规划外骨骼：

- 状态：EE 位置/姿态/速度/角速度；模型用双积分器/运动学模型。
- 控制：EE 加速度（或速度）序列。
- 约束：工作空间、速度/加速度/加加速度上限、与 ESDF 的碰撞距离、放置/插入姿态约束、支撑/接触约束。
- 代价：到 3D 目标的位置/姿态误差 + 速度/加速度平滑 + 碰撞罚 + 目标协方差（不确定性）。
- 求解：小规模 QP/SCP，horizon 10–15 步（0.33–0.5s），CPU 上 5–20ms；输出前若干步作为 action chunk，下一次 `get_action` 再重规划。
- 融合：`a_final = α a_VLA + (1-α) a_MPC`，α 由目标不确定性/接触状态决定；自由空间 α 高，接近/接触 α 低。
- 动作空间：建议统一用 `ee`；若底座用 `joint`，MPC 的 EE 轨迹需经 G1 IK 转 joint，并做关节限位/奇异点检查。
- 时间对齐：VLA chunk 与 MPC 轨迹重采样到 30Hz；自由段以 VLA 为主，接近/接触段 MPC 权重升高，避免用几何控制破坏语义先验。

这不是上一轮砍掉的“运行时全物理仿真/MPC”。上一轮砍的是依赖全物理仿真的重型 MPC；本轮引入的是**只依赖任务空间运动学 + 地图 ESDF 的轻量 MPC**，不解刚体接触动力学，接触段用“接触代理 + 柔顺步进”处理。两者在工程复杂度上差一个量级。

### 3.6 接触代理（CPA）：没有力传感器也能感知受阻

观测里没有力/力矩，但每一步都有**实际 EE 位姿**。把“上一条命令的 EE 位姿”和“当前实际 EE 位姿”的差当作接触/受阻信号：

```text
f_hat_t = K_hat (p_cmd,t-1 - p_act,t) + D_hat (v_cmd,t-1 - v_act,t)
c_t     = ||f_hat_t|| / f_scale + λ ||Log(R_cmd^T R_act)||
```

自由空间 `c_t` 应很小；插入/放置受阻时 `c_t` 上升。超过阈值就切柔顺模式：

- 降增益、沿插入轴小步走；
- 横向用腕部视觉纠偏；
- 连续 N 步没有沿轴进展 → 退回 5mm、重新对中；
- 再失败 → 重抓。

`K_hat`、`D_hat` 用插入类演示标定；阈值按任务分桶（插头/网线/试管/针管各一组）。

### 3.7 地图谓词与恢复（MDO）

谓词不是黑箱分类，而是地图上的几何/关系判定：

- `on(A,B)`：A 的投影在 B 的支撑多边形内，高度在容差内，稳定 0.5s。
- `in(A,C)`：A 的中心在 C 的内腔（按 A 半径腐蚀），低于容器边缘，未被遮挡。
- `stacked(A,B)`：`on(A,B)` + 水平中心距 < 半径和 − margin + 姿态对齐 < θ。
- `inserted(P,S)`：插头尖端到插座中心 < ε_xy，插入深度在 [d_min,d_max]，轴向对齐 < θ，稳定。
- `closed(Z)`：拉链/盒盖的几何状态；拉链用 2D 线/缝检测 + VLA 谓词头兜底。
- `aligned(A)`：姿态误差到规范系 < θ。

每个谓词带置信度与滞回阈值（enter/exit 不同），避免抖动。谓词从 1→0 时：

1. 检测变化（物体被拿走/移动/拉开）；
2. 回退步骤 `s_t ← s_{t-1}`；
3. 重新配准/更新地图；
4. 重试/重抓/换接近方向；
5. 若物体已移出工作空间，标记不可恢复，避免浪费时间。

## 4. 数学与算法

### 4.1 坐标与标定

定义：

- `B`：机器人 base；`T`：torso；`H`：头部相机；`W`：腕部相机；`E`：EE；`F`：任务/桌面系；`C`：容器系；`O`：对象系。
- `T_B^T(q_waist)`：waist FK；`T_B^E`：接口给的 EE base 位姿；`T_T^H`、`T_E^W`：离线手眼标定。
- 头部相机到 base：`T_B^H = T_B^T · T_T^H`。
- 腕部相机到 base：`T_B^W = T_B^E · T_E^W`。

标定误差预算：

| 项 | 目标 | 方法 |
|---|---:|---|
| 相机重投影 | <5px | 棋盘/AprilTag + bundle adjustment |
| 桌面平面 | <5mm | RANSAC 平面 + 多帧平均 |
| EE 回放 | <2cm | 演示重放 + 视觉对齐 |
| 对象 6D 位姿 | <1cm | FoundationPose/ICP + 多视角一致性 |
| 释放位姿 | <τ_task | 演示分布 95% 分位 |

注意：数据集有 `camera_params`，但没有直接的头部外参；`state_d435` 是否等于头部相机状态需实测。若不等，必须用固定安装 CAD + 多视角优化；这是本项目最大的工程风险之一。

### 4.2 地图表示

```text
M = (V, E, S, D)
V = {v_i = (class, pose μ_i, cov Σ_i, extent, affordance, state)}
E = {(i,j,relation)}  relation ∈ {on,in,aligned,inserted,occludes,supports}
S = {slot_k = (support, pose distribution, approach cone, tolerance)}
D = ESDF(voxel grid)
```

- 体素：5–10mm；截断 5cm；ESDF 用快速扫描/欧氏距离变换。
- 对象位姿：SE(3) 均值/协方差；旋转用四元数或 SO(3) 局部切空间。
- 槽位：GMM 或核密度；每个模态带接近方向与容差。
- 动态物体（人手）：单独层，不写入静态 ESDF；用运动分割剔除。

### 4.3 先验构建

对每个任务/步骤：

```text
H_i = (T_B^C_i)^{-1} · T_B^E_i(t_release)
```

- 位置：`μ_p = median_i(H_i.p)`，`Σ_p = robust covariance`。
- 姿态：四元数弦均值/局部切空间高斯；`Σ_R` 用角速度协方差。
- 多模态：GMM（BIC 选峰数）；每个模态对应一种放置方式/槽位。
- 容差：`τ_task = 95th percentile_i ||H_i - μ||_Σ`；用于谓词阈值与 MPC 目标权重。
- 接近锥：从释放位姿反推最后 5cm 的速度方向，聚类得到 `approach cone`。

### 4.4 在线配准

粗配准：

```text
min_{R,t} Σ_j ρ(||R x_j + t - y_j||)
```

- 对应点：桌面/容器/对象的关键点或分割质心；RANSAC 剔除外点；`ρ` 用 Cauchy/Huber。
- 语义关联：语言/属性/几何代价的 Hungarian 匹配；不匹配的节点保留先验并放大协方差。

精配准：

```text
min_{T} Σ_j ||n_j^T (T x_j - y_j)||² + λ ||T - T_0||²
```

- point-to-plane ICP；`T_0` 为粗配准；多尺度（2cm→5mm）。
- 收敛判据：RMSE <5mm 或 20 次迭代；失败则回退到粗配准 + 先验。

### 4.5 不确定性传播

```text
Σ_target = J_T Σ_F J_T^T + Σ_H + Σ_calib
```

- `J_T`：目标位姿对配准变换的雅可比；`Σ_F`：配准协方差（ICP Hessian 逆）；`Σ_H`：先验释放位姿协方差；`Σ_calib`：标定误差。
- 门控：`(x - μ)^T Σ_target^{-1} (x - μ) ≤ χ²_{0.95}(6)`；超阈值 → 降速/重观测/回退 2D 锚点。
- MPC 权重：`W_p = Σ_p^{-1}`，`W_R = Σ_R^{-1}`；不确定性大时自动降增益、加平滑。

### 4.6 MPC 公式

离散动力学（每轴双积分器；姿态用 SO(3) 指数映射）：

```text
p_{k+1} = p_k + dt v_k + 0.5 dt² a_k
v_{k+1} = v_k + dt a_k
R_{k+1} = R_k Exp(dt ω_k)
ω_{k+1} = ω_k + dt α_k
```

代价：

```text
J = Σ_{k=0}^{N-1} [
      ||p_k - p*||²_{W_p}
    + ||Log(R_k^T R*)||²_{W_R}
    + λ_v ||v_k||²
    + λ_a ||a_k||²
    + λ_j ||a_k - a_{k-1}||²
    + λ_c max(0, d_min - d(x_k))²
    + λ_s ρ_s(x_k)
    ] + terminal cost
```

约束：

```text
p_k ∈ Workspace
d(x_k) ≥ d_min
|v_k| ≤ v_max, |a_k| ≤ a_max, |a_k - a_{k-1}| ≤ j_max
angle(R_k, R*) ≤ θ_cone          # 接近/插入锥
z_k ≥ table_height + margin      # 支撑
```

求解：

- SCP/iLQR：动力学线性，碰撞约束线性化；每步 2–3 次 QP 迭代；warm start。
- Horizon 10–15（0.33–0.5s @30Hz）；输出前 3–5 步；下一次重规划。
- 超时/不可行 → min-jerk 回退；`p99 <20ms`（单核），否则降 horizon。

不确定性感知：

```text
chance constraint: d(x_k) - κ sqrt(n^T Σ_x n) ≥ d_min
```

- `κ` 由风险等级定；目标协方差大时，`κ` 增大、速度上限降低。
- 目标不确定性极高 → 不执行 MPC，先主动重观测。

### 4.7 接触代理

```text
f_hat_t = K_hat (p_cmd,t-1 - p_act,t) + D_hat (v_cmd,t-1 - v_act,t)
c_t     = ||f_hat_t|| / f_scale + λ ||Log(R_cmd^T R_act)||
```

模式：

| 条件 | 模式 | 动作 |
|---|---|---|
| `c_t < c1` | 自由 | 正常 MPC |
| `c1 ≤ c_t < c2` | 接近 | 降速、对准轴、腕部视觉 |
| `c_t ≥ c2` | 接触 | 柔顺：`v_cmd = v_nom + K_a (f_des - f_hat)`，限制横向力 |
| 沿轴无进展 N 步 | 受阻 | 退回 5mm、重新对中、重试 |
| 连续失败 | 重抓 | 开爪、退离、重新抓取 |

`f_des` 沿插入轴；`K_a` 为柔顺增益；`f_scale` 用演示接触段的 95% 分位标定。

### 4.8 谓词定义

设 `proj_xy`、`support_polygon`、`rim`、`axis`、`tip`、`socket` 由地图给出。

```text
on(A,B) := proj_xy(p_A) ∈ erode(support_polygon(B), r_A)
           ∧ z_A - z_B ∈ [h_min, h_max]
           ∧ ||v_A|| < ε_v
           ∧ stable(T=0.5s)

in(A,C) := p_A ∈ erode(interior(C), r_A)
           ∧ z_A < rim_z(C) - margin
           ∧ visible(A)

stacked(A,B) := on(A,B)
                ∧ ||proj_xy(p_A) - proj_xy(p_B)|| < r_A + r_B - margin
                ∧ angle(R_A, R_B) < θ_stack

inserted(P,S) := ||tip(P) - center(S)||_xy < ε_xy
                 ∧ depth(P,S) ∈ [d_min, d_max]
                 ∧ angle(axis(P), axis(S)) < θ_insert
                 ∧ stable(T=0.3s)

closed(Z) := geometric gap/line state
             ∨ predicate_head(Z)   # 拉链/布料兜底

aligned(A) := angle(R_A, R_canonical) < θ_align
```

滞回：`enter` 阈值比 `exit` 更严；连续 3 帧满足才置 1，连续 3 帧不满足才置 0。

### 4.9 恢复状态机

```text
MONITOR ── predicate 1→0 / no-progress ──► DIAGNOSE
DIAGNOSE ── target lost ──► RELOCALIZE ──► REPLAN
DIAGNOSE ── contact stuck ──► BACKOFF ──► REALIGN ──► RETRY
DIAGNOSE ── grasp lost ──► REGRASP ──► RETRY
DIAGNOSE ── object removed ──► UNRECOVERABLE (省时间)
REPLAN/RETRY ── success ──► MONITOR
```

预算：

- 每步超时 = 演示中位时长 × 3 + 2s；全局 180s。
- 重试 ≤2 次/普通任务，≤1 次/长程任务；恢复预算 ≤30%。
- 每次恢复记录原因/动作/结果，供离线诊断。

## 7. 评测协议

### 7.1 离线（每天）

| 指标 | 目标 | 数据 |
|---|---:|---|
| 相机重投影 | <5px | 标定集 |
| 桌面平面 | <5mm | 演示/真机 |
| 对象 6D 位姿 | <1cm | 标注集 |
| 释放位姿在 τ 内 | ≥80% | held-out 演示 |
| 配准 RMSE | <5mm | 回放 |
| MPC 跟踪误差 | <VLA chunk | 回放 |
| 接触 F1 | >0.7 | 插入任务 |
| 谓词 F1 | >0.85 | 步骤标注 |

### 7.2 本地（每周）

- 回放/运动学仿真：用记录的观测 + 地图 + MPC 重放，不改场景；验证感知/控制，不验证接触物理。
- 真机小规模（若有 G1）：8 任务 × 5 试次；只看失败模式，不做模型选择。
- 失败挖掘：按 P1–P8 分类，统计每类占比；优先修最贵的。

### 7.3 平台（版本门）

- 不计分单任务调试槽（[S35]，上轮核实；本轮未复抓）。
- 任务选择：T27（叠碗=放置门控）、T10（插排=插入力控）、T19（拉链=闭合终局）。
- 判定：终局步成功率 ≥ +10pp 且无回归才允许进计分跑；每个大版本最多 1 槽。
- 计分跑：W7 中期、W8 终期；若只允许 1 次，则 W8 唯一一次。
- 提交前 4h soak：N 端口并发、状态隔离、健康检查、延迟 p99。

### 7.4 统计：320 trials 能证明什么，不能证明什么

- 计分 trials：32 任务 × 10 次 = **320**；每任务 10 次，5 类泛化各 2 次。
- 单臂成功率标准误（p≈0.3）：`SE = sqrt(0.3×0.7/320) = 2.56pp`；95% CI 约 ±5.0pp。
- 两独立臂差值：`SE_diff = sqrt(2×0.21/320) = 3.62pp`；80% power 只能检测约 **10pp** 的差异。
- 配对设计（同任务/同场景/同种子）：若不一致率 10–20%，`SE_diff ≈ 1.8–2.5pp`；80% power 可检测 **5–7pp**。
- 每任务 10 次，单任务成功率 SE 约 14.5pp（p=0.3）；任务异质性主导，必须用分层/层次模型。

结论：

1. **不要用非配对 320 trials 宣称 +3pp**；那在统计上不可区分。
2. 调试槽/本地实验要做**配对 A/B**（同场景、同初始状态、同种子），否则会误判。
3. 最终评估用 task-level bootstrap + 层次 Beta-Binomial；报告 95% CI，不只看点估计。
4. 若真实头部 <30%，+5pp 已经是很大的相对提升（约 17% 相对增益），但需要配对证据支撑。

### 9.1 四个主押注的详细说明

#### I1 TMP：任务级 3D 语义地图先验

- **动机**：33k 演示带相机标定与机器人状态；终局执行是 32/32 任务的成功闸门；纯 2D 锚点视角依赖强。
- **差异**：不是 SLAM，不是 3DGS，不是场景重建；是“对象/容器/槽位/释放位姿”的任务级图先验，在线只做配准/更新。
- **可行性**：数据字段齐；离线重感知；在线轻几何；单任务 <50MB。
- **资源**：8×H100 7–10 天；或 1×4090 3–5 天做 8 任务抽样。
- **步骤**：标定 → 重建 → 规范系 → 释放位姿 → GMM/ESDF → 质量门。
- **风险**：透明/布料/小件深度失效 → 分桶回退 2D/检索；容器不可见 → 先验+协方差。
- **证伪**：若 8 任务离线释放位姿在 τ 内 <70%，先修标定/分割，不进入在线。

#### I2 UMPC：不确定性感知任务空间 MPC

- **动机**：VLA 输出 chunk 开环执行 0.5s 后误差累积；放置/插入需要碰撞/姿态/支撑约束。
- **差异**：只依赖 EE 运动学 + ESDF，不解接触动力学；协方差加权；与 VLA chunk 融合。
- **可行性**：小规模 QP/SCP，CPU 5–20ms；有成熟工具（OSQP/qpOASES/Crocoddyl）。
- **资源**：1 核 CPU；无新数据。
- **步骤**：公式 → 回放验证 → 碰撞单元测试 → 真机调试。
- **风险**：模型误差/求解超时 → min-jerk 回退；接触段交给 CPA。
- **证伪**：若 MPC 跟踪误差大于 VLA chunk，或 p99 >100ms，关掉 MPC。

#### I3 CPA：接触代理

- **动机**：观测无力/力矩；插头/网线/试管/针管需要“受阻”感知；纯位置控制会硬撞。
- **差异**：用命令-实际 EE 跟踪误差构造力代理；无需额外传感器；按任务标定阈值。
- **可行性**：接口有实际 EE 位姿；演示有插入段；阈值可扫描。
- **资源**：无新数据；离线标定。
- **步骤**：提取插入段 → 拟合 K/D → 阈值 → 模式机 → 插入测试。
- **风险**：跟踪误差受控制器/延迟影响 → 归一化+双阈值；误判 → 腕部视觉校验。
- **证伪**：若接触 F1 <0.7，插入任务回退纯视觉伺服。

#### I4 MDO：地图谓词+恢复

- **动机**：成功=全步骤；模型经常“以为完成”；human 轴会撤销步骤。
- **差异**：谓词在地图上算，可解释/可验证；滞回+状态机；恢复预算。
- **可行性**：几何谓词对刚体任务足够；拉链/布料用 VLA 谓词头兜底。
- **资源**：无新数据；规则+阈值。
- **步骤**：谓词 → 滞回 → 状态机 → 预算 → 调试。
- **风险**：谓词噪声/抖动 → 多帧确认；透明物体 → 2D/学习兜底。
- **证伪**：若谓词 F1 <0.8，先修感知/阈值，不进入恢复。

### 9.2 已砍/降级清单

- **砍**：全 32 任务高保真孪生；3DGS 作为核心；每任务 LoRA/模型合并；自由仿真数据/仿真 RL；运行时全物理仿真/MPC；WMA-0 进主路径。
- **降级**：ICR 检索 → 可选动作先验；L2L → 可选外部数据；TCLB → 离线相对比较；FLEET → 工程检查单。
- **保留**：SSG、NRB、GPR-VLA/WLA、TLE/ACP/GF、AH-TP、Endurance Governor、Compliance Compiler。

## 10. 风险与合规

| 风险 | 概率 | 影响 | 缓解 | 停止条件 |
|---|---|---|---|---|
| 测试机内参与数据集不一致 | 中 | 高 | 邮件确认；桌面/已知物体自标定；腕部 2D 伺服兜底 | 重投影 >5px → 关 3D 目标 |
| 头部/腕部外参标定误差 | 中 | 高 | `state_d435`/`state_torso`/EE 手眼；多视角一致性 | 配准 >1cm → 只用地图像素锚点 |
| 透明/布料深度失效 | 高 | 中 | 分桶：3D 只做刚体/不透明；透明/布料回退 2D/相位/检索 | 该任务 3D 误差 >2cm → 退出 3D |
| 接触代理误判 | 中 | 中 | 双阈值+腕部视觉；插入任务专项标定 | F1 <0.7 → 纯视觉伺服 |
| MPC 求解超时 | 中 | 中 | 小 horizon、warm start、CPU、QP；超时回退 min-jerk | p99 >100ms → 降 horizon/关 MPC |
| 单模型合规（辅助感知） | 中 | 高 | 最小版只用确定性几何；离线重感知/在线轻几何；披露 | 官方认定违规 → 去学习感知 |
| 外部数据违规 | 低 | 高 | 默认只用官方数据；L2L 默认 OFF | 官方禁止 → L2L 转赛后 |
| 成功率方差大（320 trials） | 高 | 中 | 配对场景/种子；task bootstrap；层次模型 | CI 跨 0 → 不上线 |
| N 端口/状态隔离 | 中 | 高 | 每端口独立地图/MPC；共享 VLA 后端；健康检查 | soak 失败 → 不提交 |
| 物体被 human 移出工作空间 | 低 | 高 | 变化检测→标记不可恢复→省时间；不硬追 | 不可达 → 放弃该次 |
