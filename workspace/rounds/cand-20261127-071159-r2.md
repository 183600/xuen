### 第 2 轮灵感驱动研究记录

**灵感词**：鲁棒性、多传感器融合

**直觉与动机**：
v25 的七证链（USMC+SMC+RMC+MCC）本质是「名义点」上的布尔断言：给定一组观测与模型参数，证书要么通过要么拒绝，却没有回答两个更基本的问题——(a) 当观测噪声、模型误差、执行偏差甚至对抗扰动落在某个球内时，证书是否仍然成立？(b) 当 LiDAR/相机/IMU/力矩/触觉/GNSS 多源证据彼此冲突、退化或被 Byzantine 欺骗时，融合出的状态是否仍可被信任？受「鲁棒性」启发，证书应从布尔值升级为「量化半径」：证书不仅声明 π 可行，还声明以 π 为中心、半径 r(π) 的扰动球整体可行，而 r(π) 由裕度 m(π) 与证书函数的 Lipschitz 常数 L_C 决定。受「多传感器融合」启发，融合应从加权平均升级为「可证冗余」：协方差交叉保证保守性、几何中位数保证 breakdown point、跨模态一致性保证不被单一模态欺骗、融合后 conformal/ACI 保证覆盖。核心洞见：**鲁棒性把证书从「点」扩张为「球」，多传感器融合把证据从「单源」去风险为「可证冗余」；两者相乘即「证据鲁棒 ⇒ 状态可信 ⇒ 证书鲁棒」的闭环，任何一环的假设被违反都必须触发可证明的降级。**

**形式化目标**：
1. 定义鲁棒性证书（RBC）：扰动集 Δ = {δ : d(π, π∘δ) ≤ ε_Δ}，证书裕度 m(π) = -max_j g_j(π)；若各约束 g_j 为 L_j-Lipschitz，则 m 为 L = max_j L_j Lipschitz，鲁棒可行性要求 m(π) ≥ L·ε_Δ，可证鲁棒半径 r(π) = m(π)/L，并要求 r(π) ≥ r_min 与 ℙ_δ(C(π+δ)=1) ≥ 1-α_rob（ACI 长程覆盖）。
2. 定义多传感器融合证书（MSFC）：协方差交叉保守性 P_f ⪰ (Σ_s ω_s P_s^{-1})^{-1}（Loewner 序）；NEES/NIS 落入 χ² 区间；几何中位数 breakdown point ≥ 1/2 且 S ≥ 2f+1；跨模态 Hausdorff/重投影 ≤ ε_cross、时间同步 ≤ τ_sync；Fisher 信息 λ_min ≥ λ_0 保证可观测；融合输出经 ACI 覆盖 ≥ 1-α_fuse。
3. 定义鲁棒-融合耦合证书（RFCC）：不确定性预算 ε_Δ ≥ e_fuse + ε_model + ε_exec（有界）/ ε_Δ² ≥ Σ ε_·²（随机），融合误差上界 e_fuse = sqrt(χ²_{n,1-α_fuse}·λ_max(P_f)) 进入预算，要求 r(π) ≥ ε_Δ 且预算不超支。
4. 构建九证准入门 RMS-USC v26：SRC-USC ∪ RBC ∪ MSFC ∪ RFCC，Exec_v26 = Exec_v25 ∩ Fil_rob ∩ Fil_fuse ⊆ Exec_v25。
5. 证明融合冲突/传感器失效/Byzantine 欺骗/扰动超界下的单调退化链与降级策略。

```python
# ============================================================
# IP-448 Robustness Certificate (RBC) — 鲁棒性证书
# ============================================================
@dataclass
class RobustnessCertificate:
    """把 v25 的布尔证书升级为「扰动球内处处成立」的半径证书"""
    margin_fn: Callable[[Any], float]      # π -> m(π) = -max_j g_j(π)
    lipschitz: 'LipschitzBundle'           # 各约束 L_j 的认证上界
    delta_set: 'PerturbationSet'           # Δ, 半径 ε_Δ
    r_min: float = 0.02                    # 最小可证鲁棒半径
    alpha_rob: float = 0.05                # 概率鲁棒风险
    gamma_aci: float = 0.01                # ACI 步长
    scenario_n: int = 2000                 # scenario 瞬时兜底样本数

    def verify_lipschitz_margin(self, pi) -> bool:
        """m(π) ≥ L_C·ε_Δ  =>  ∀δ∈Δ: g_j(π+δ)≤0（引理 13）"""
        m = self.margin_fn(pi)
        L = self.lipschitz.max(pi)
        return m >= L * self.delta_set.radius

    def robust_radius(self, pi) -> float:
        """可证鲁棒半径 r(π)=m(π)/L_C（Lipschitz 下界推出的最大安全球）"""
        m = self.margin_fn(pi)
        L = max(self.lipschitz.max(pi), 1e-9)
        return max(m, 0.0) / L

    def verify_radius(self, pi) -> bool:
        return self.robust_radius(pi) >= self.r_min

    def verify_scenario(self, pi, sampler) -> bool:
        """场景法瞬时兜底：对 ε_Δ 球内的 Δ 采样，失败比例不得超过 α_rob"""
        fails = 0
        for _ in range(self.scenario_n):
            delta = sampler.sample_in_ball(self.delta_set.radius)
            fails += int(self.margin_fn(pi + delta) < 0)
        return fails <= int(self.alpha_rob * self.scenario_n)

    def verify_probabilistic(self, pi, sampler) -> bool:
        """ACI：以 C(π+δ_t)=0 为误差，长程覆盖率趋于 1-α_rob（引理 14）"""
        alpha_t, errs = self.alpha_rob, []
        for delta in sampler.stream(pi):
            err = int(self.margin_fn(pi + delta) < 0)
            errs.append(err)
            alpha_t += self.gamma_aci * (self.alpha_rob - err)
            alpha_t = min(max(alpha_t, 1e-3), 1.0 - 1e-3)
        return (sum(errs) / max(len(errs), 1)) <= self.alpha_rob + self.gamma_aci

    def verify_cvar(self, pi, sampler, beta: float = 0.1) -> bool:
        """尾部风险：最坏 β 分位的约束违反量 CVaR ≤ 0（离散采样近似）"""
        losses = sorted(self.margin_fn(pi + sampler.sample_in_ball(
            self.delta_set.radius)) for _ in range(self.scenario_n))
        k = max(int(beta * len(losses)), 1)
        tail = losses[:k]
        return sum(tail) / len(tail) >= 0.0

    def verify_all(self, pi, sampler) -> bool:
        return (self.verify_lipschitz_margin(pi)
                and self.verify_radius(pi)
                and self.verify_scenario(pi, sampler)
                and self.verify_probabilistic(pi, sampler))

# IP-449 Multi-Sensor Fusion Certificate (MSFC) — 多传感器融合证书
# ============================================================
@dataclass
class MultiSensorFusionCertificate:
    """保守融合 + 卡方一致性 + Byzantine breakdown + 跨模态 + 可观测 + 覆盖"""
    sensors: list['SensorSpec']
    z: dict[str, Tensor]                   # 模态 -> 观测（含时间戳 t）
    x_f: Tensor                            # 融合状态
    P_f: Tensor                            # 融合协方差
    P_s: dict[str, Tensor]                 # 各模态协方差
    weights: dict[str, float]              # Σω_s=1
    alpha_chi2: float = 0.05               # NEES 卡方风险
    max_byzantine: int = 1                 # 允许的 Byzantine 模态数 f
    eps_cross: float = 0.03                # 跨模态几何容差 (m)
    tau_sync: float = 0.01                 # 时间同步容差 (s)
    lambda_min_fim: float = 1e-3           # 可观测性阈值
    alpha_fuse: float = 0.05               # 融合覆盖风险

    def verify_conservativeness(self) -> bool:
        """P_f ⪰ P_CI = (Σ_s ω_s P_s^{-1})^{-1}（Loewner 序，引理 15）"""
        P_ci_inv = sum(self.weights[s] * torch.linalg.inv(self.P_s[s])
                       for s in self.weights)
        P_ci = torch.linalg.inv(P_ci_inv)
        return bool(torch.linalg.eigvalsh(self.P_f - P_ci).min() >= -1e-9)

    def verify_nees(self, errors: list[Tensor]) -> bool:
        """NEES 均值落入 χ²_n(α/2, 1-α/2)/N 区间；偏离即不一致"""
        n = self.x_f.numel()
        lo, hi = chi2_interval(n, self.alpha_chi2)
        nees = [float(e @ torch.linalg.solve(self.P_f, e)) for e in errors]
        mean = sum(nees) / max(len(nees), 1)
        return lo / n <= mean <= hi / n

    def verify_byzantine(self) -> bool:
        """几何中位数 breakdown=1/2；要求 S ≥ 2f+1 且残差在界内"""
        S = len(self.sensors)
        if S < 2 * self.max_byzantine + 1:
            return False
        ests = torch.stack([self._local_estimate(s) for s in self.sensors])
        w = torch.tensor([self.weights[s] for s in self.sensors])
        gm = geometric_median(ests, w)
        resid = torch.norm(ests - gm, dim=1)
        return bool(resid.max() <= self._byz_residual_bound())

    def verify_cross_modal(self) -> bool:
        """重叠模态：时间同步 ≤ τ_sync 且几何/重投影一致 ≤ ε_cross"""
        for a, b in self._overlap_pairs():
            if abs(float(self.z[a].t) - float(self.z[b].t)) > self.tau_sync:
                return False
            if hausdorff_distance_of_modalities(self.z[a], self.z[b]) > self.eps_cross:
                return False
        return True

    def verify_observability(self, jacobians: dict[str, Tensor]) -> bool:
        """F = Σ_s J_sᵀ R_s^{-1} J_s，λ_min(F) ≥ λ_0 且满秩"""
        F = sum(j.T @ torch.linalg.inv(self.P_s[s]) @ j
                for s, j in jacobians.items())
        evals = torch.linalg.eigvalsh(F)
        return bool(evals.min() >= self.lambda_min_fim
                    and torch.linalg.matrix_rank(F) == self.x_f.numel())

    def verify_fusion_conformal(self, aci: 'ACICalibrator') -> bool:
        """融合后的非一致性分数必须重新校准；ACI 处理漂移/非交换序列"""
        return aci.long_run_coverage() >= 1.0 - self.alpha_fuse

    def certified_error_bound(self) -> float:
        """e_fuse = sqrt(χ²_{n,1-α_fuse}·λ_max(P_f))，进入 RFCC 预算"""
        n = self.x_f.numel()
        hi = chi2_interval(n, self.alpha_fuse)[1]
        return float(torch.sqrt(hi * torch.linalg.eigvalsh(self.P_f).max()))

    def verify_all(self, errors, jacobians, aci) -> bool:
        return (self.verify_conservativeness()
                and self.verify_nees(errors)
                and self.verify_byzantine()
                and self.verify_cross_modal()
                and self.verify_observability(jacobians)
                and self.verify_fusion_conformal(aci))

    def _local_estimate(self, s: str) -> Tensor:
        return h_apply(self.sensors[s].model, self.z[s])

    def _byz_residual_bound(self) -> float:
        # 由 Weiszfeld 收敛半径 + 局部协方差给出；f 越大界越松
        return float(3.0 * self.certified_error_bound())

    def _overlap_pairs(self):
        return [(a.m, b.m) for a in self.sensors for b in self.sensors
                if a.m < b.m and a.fov.overlaps(b.fov)]

# IP-450 Robust-Fusion Coupled Certificate (RFCC) — 鲁棒-融合耦合预算
# ============================================================
@dataclass
class RobustFusionCoupledCertificate:
    """把融合误差、模型误差、执行误差并入鲁棒扰动预算，失败即分级降级"""
    rbc: RobustnessCertificate
    msfc: MultiSensorFusionCertificate
    eps_model: float = 0.01
    eps_exec: float = 0.01
    eps_fuse_alloc: float = 0.01
    eps_delta_alloc: float = 0.05          # 总预算，必须 ≥ rbc.delta_set.radius

    def verify_budget(self) -> bool:
        """有界：ε_Δ ≥ e_fuse+ε_model+ε_exec；随机：ε_Δ² ≥ Σε²（保守取加和）"""
        e_fuse = self.msfc.certified_error_bound()
        need = e_fuse + self.eps_model + self.eps_exec
        return (need <= self.rbc.delta_set.radius
                and e_fuse <= self.eps_fuse_alloc
                and self.rbc.delta_set.radius <= self.eps_delta_alloc)

    def verify_coupled_radius(self, pi) -> bool:
        """控制裕度必须覆盖总预算：r(π) ≥ ε_Δ（引理 16）"""
        return self.rbc.robust_radius(pi) >= self.rbc.delta_set.radius

    def conflict_mode(self, conflict_score: float) -> str:
        """冲突分级，返回降级模式；reject 由上层拒绝"""
        eps = self.rbc.delta_set.radius
        if conflict_score <= eps:
            return 'full'
        if self.msfc.verify_byzantine() and conflict_score <= 2.0 * eps:
            return 'trusted_subset'            # 剔除冲突模态，仍在 breakdown 内
        if conflict_score <= 4.0 * eps:
            return 'single_source_conservative'  # 退最可信单模态 + 协方差膨胀
        return 'reject'

    def verify_all(self, pi, conflict_score) -> bool:
        return (self.verify_budget()
                and self.verify_coupled_radius(pi)
                and self.conflict_mode(conflict_score) != 'reject')

# IP-451 RMS-USC 鲁棒-多传感器融合统一准入门 v26
# ============================================================
@dataclass
class RobustMultiSensorUnifiedCertificate:
    src_usc: 'SemanticReconfigCoordUnifiedCertificate'  # v25 七证
    rbc: RobustnessCertificate
    msfc: MultiSensorFusionCertificate
    rfcc: RobustFusionCoupledCertificate

    def admits(self, multi_plan, fused_data, pi, sampler,
               errors, jacobians, aci, conflict_score) -> tuple[bool, str]:
        # 1. v25 七证（语义-重构-协同，先保证名义计划合法）
        if not self.src_usc.admits(
                multi_plan, fused_data,
                gt_entities=fused_data.get('gt_entities'),
                queries=fused_data.get('queries'),
                retrieved=fused_data.get('retrieved')):
            return False, 'src_usc_reject'
        # 2. 融合证书（证据层）：保守性/一致性/breakdown/跨模态/可观测/覆盖
        if not self.msfc.verify_all(errors, jacobians, aci):
            return False, 'msfc_reject'
        # 3. 耦合证书（预算层）：融合误差必须被鲁棒半径吸收
        if not self.rfcc.verify_all(pi, conflict_score):
            return False, 'rfcc_reject'
        # 4. 鲁棒证书（证书层）：扰动球内处处成立 + 概率覆盖
        if not self.rbc.verify_all(pi, sampler):
            return False, 'rbc_reject'
        return True, 'admitted'

        fused, conflict = self._robust_fuse(multi_sensor_data)
        self.aci.update(int(not fused['consistent']))
        # 2) 由融合状态构造鲁棒证书输入 π 与扰动采样器
        pi = self._plan_from_fused(fused)
        sampler = self._perturbation_sampler(fused)
        # 3) 九证准入
        admitted, reason = self.rms_usc.admits(
            multi_plan=self._plan_from_fused(fused),
            fused_data=multi_sensor_data, pi=pi, sampler=sampler,
            errors=fused['errors'], jacobians=fused['jacobians'],
            aci=self.aci, conflict_score=conflict)
        if not admitted:
            # 4) 按冲突模式降级；仍失败则退回 Exec_v25 保守单源
            mode = self.rms_usc.rfcc.conflict_mode(conflict)
            return False, {'reason': reason, 'degrade_mode': mode,
                           'fallback': 'Exec_v25_single_source_conservative'}
        return True, {'fused': fused, 'robust_radius': self.rms_usc.rbc.robust_radius(pi),
                      'conflict': conflict, 'aci_coverage': self.aci.long_run_coverage()}

    def _robust_fuse(self, data: dict) -> tuple[dict, float]:
        ests = [self._local_estimate(s, data) for s in data['sensors']]
        # NIS 门限剔除离群模态（保留 ≥ 2f+1）
        keep = self._nis_gate(ests, data)
        ests, covs = ests[keep], [data['P_s'][s] for s in keep]
        w = self._adaptive_weights(covs)
        x_f, P_f = covariance_intersection([e.x for e in ests], covs, w)
        conflict = self._cross_modal_conflict(ests)
        return ({'x': x_f, 'P': P_f, 'errors': [e.x - x_f for e in ests],
                 'jacobians': data['jacobians'], 'consistent': conflict <= data['eps_cross']},
                conflict)


# ---------------- 辅助函数 ----------------
def geometric_median(points: Tensor, weights: Tensor,
                     iters: int = 100, tol: float = 1e-6) -> Tensor:
    """Weiszfeld 迭代；breakdown point = 1/2（任意维）"""
    y = (points * weights[:, None]).sum(0) / weights.sum()
    for _ in range(iters):
        d = torch.norm(points - y, dim=1).clamp_min(1e-9)
        w = weights / d
        y_new = (points * w[:, None]).sum(0) / w.sum()
        if torch.norm(y_new - y) < tol:
            return y_new
        y = y_new
    return y

def covariance_intersection(estimates, covs, weights) -> tuple[Tensor, Tensor]:
    """P_CI^{-1} = Σ ω_s P_s^{-1}; x_CI = P_CI Σ ω_s P_s^{-1} x_s（相关性未知保守）"""
    P_inv = sum(w * torch.linalg.inv(P) for w, P in zip(weights, covs))
    P = torch.linalg.inv(P_inv)
    x = P @ sum(w * torch.linalg.solve(P, x_s)
                for w, x_s, P in zip(weights, estimates, covs))
    return x, P

def chi2_interval(n: int, alpha: float) -> tuple[float, float]:
    from scipy.stats import chi2
    return (chi2.ppf(alpha / 2.0, n), chi2.ppf(1.0 - alpha / 2.0, n))


class ACICalibrator:
    """Gibbs & Candès (2021) 自适应 conformal：非交换/漂移下的长程覆盖"""
    def __init__(self, alpha: float, gamma: float = 0.01):
        self.alpha, self.gamma, self.alpha_t = alpha, gamma, alpha
        self.errs: list[int] = []

    def update(self, err: int) -> None:
        self.errs.append(err)
        self.alpha_t += self.gamma * (self.alpha - err)
        self.alpha_t = min(max(self.alpha_t, 1e-3), 1.0 - 1e-3)

    def long_run_coverage(self) -> float:
        return 1.0 - sum(self.errs) / max(len(self.errs), 1)
```

## 3. 正确性论证（增量）

### 引理 13（Lipschitz 鲁棒裕度的可靠性）
**陈述**：设 \(g_j:\Pi\to\mathbb{R}\) 关于度量 \(d\) 为 \(L_j\)-Lipschitz，\(m(\pi)=-\max_j g_j(\pi)\)，\(L=\max_j L_j\)。若 \(m(\pi)\ge L\,\varepsilon_\Delta\)，则对所有 \(d(\pi,\pi')\le\varepsilon_\Delta\) 有 \(g_j(\pi')\le 0\)（即 \(\pi'\) 仍满足全部 v25 证书）。

**证明**：对任意 \(j\)，由 Lipschitz 性 \(g_j(\pi')\le g_j(\pi)+L_j d(\pi,\pi')\le g_j(\pi)+L_j\varepsilon_\Delta\)。因 \(g_j(\pi)\le -m(\pi)\)，故 \(g_j(\pi')\le -m(\pi)+L_j\varepsilon_\Delta\le -L\varepsilon_\Delta+L_j\varepsilon_\Delta\le 0\)。取 \(j\) 任意，结论成立。可证半径取 \(r(\pi)=m(\pi)/L\) 时，半径 \(r\) 的球整体可行；由于用的是上界 \(L\ge L_j\)，该半径是保守下界，真实可行半径只会更大。∎

### 引理 14（ACI 在任意扰动序列下的长程鲁棒覆盖）
**陈述**：令 \(err_t=\mathbf{1}[C(\pi+\delta_t)=0]\in[0,1]\)，按 \(\alpha_{t+1}=\alpha_t+\gamma(\alpha_{rob}-err_t)\) 更新。则对任意（可对抗、非交换）扰动序列，
\[
\left|\frac{1}{T}\sum_{t=1}^{T}err_t-\alpha_{rob}\right|\le\frac{\alpha_1+\gamma}{\gamma T}.
\]
**证明**：对更新式求和并望远镜消去 \(\alpha_t\)，得 \(\alpha_{T+1}=\alpha_1+\gamma T\alpha_{rob}-\gamma\sum err_t\)；由 \(\alpha_{T+1}\in(0,1)\) 夹逼即得界。故长程覆盖率趋于 \(1-\alpha_{rob}\)（Gibbs & Candès, 2021）。**注意**：该保证是长程/边际的，不提供逐时刻覆盖，故算法同时保留 scenario 瞬时兜底与 Lipschitz 硬裕度。∎

### 引理 15（MSFC 的保守-一致-冗余三重保证）
**陈述**：若 \(P_f\succeq P_{CI}=(\sum_s\omega_sP_s^{-1})^{-1}\)、NEES 均值落在 \(\chi^2_n\) 区间、\(S\ge2f+1\) 且几何中位数残差有界、跨模态与可观测性条件成立，则融合误差满足 \(\|x_f-x\|\le e_{fuse}\) 的概率至少 \(1-\alpha_{fuse}\)。

**证明**：
1. **CI 保守性**：当各局部协方差 \(P_s\) 一致（\(P_s\succeq\mathbb{E}[(x_s-x)(x_s-x)^\top]\)）而互相关未知时，协方差交叉给出 \(P_{true}\preceq P_{CI}\)（Loewner 序）；故 \(P_f\succeq P_{CI}\succeq P_{true}\)，融合协方差不乐观。
2. **卡方一致性**：高斯近似下 NEES \(\sim\chi^2_n\)；均值落区间说明 \(P_f\) 未低估误差。
3. **Breakdown**：几何中位数的 breakdown point 为 \(1/2\)，在 \(S\ge2f+1\)（\(f<S/2\)）时，至多 \(f\) 个被篡改模态不能把聚合点拖出有界邻域；Weiszfeld 残差界给出该邻域半径。
4. **可观测/跨模态**：\(\lambda_{\min}(F)\ge\lambda_0\) 保证不可观方向有先验界，跨模态 \(d_H\le\varepsilon_{cross}\) 与 \(\tau_{sync}\) 排除单模态系统性欺骗。
5. 合并 1–4，由 \(P_f\) 的最大特征值与 \(\chi^2_{n,1-\alpha_{fuse}}\) 分位得 \(\|x_f-x\|^2\le\chi^2_{n,1-\alpha_{fuse}}\lambda_{\max}(P_f)\)，即 \(e_{fuse}\)。∎

### 引理 16（RFCC 预算分解与耦合半径）
**陈述**：若 \(e_{fuse}\le\varepsilon_{fuse}\)、模型误差 \(\le\varepsilon_{model}\)、执行误差 \(\le\varepsilon_{exec}\) 且 \(\varepsilon_{fuse}+\varepsilon_{model}+\varepsilon_{exec}\le\varepsilon_\Delta\)，并且 \(r(\pi)\ge\varepsilon_\Delta\)，则计划在融合不确定性下仍满足引理 13 的鲁棒证书。

**证明**：由三角不等式，实际总扰动 \(d\le e_{fuse}+\varepsilon_{model}+\varepsilon_{exec}\le\varepsilon_\Delta\)，落在 RBC 扰动球内；再由引理 13，\(m(\pi)\ge L\varepsilon_\Delta\iff r(\pi)\ge\varepsilon_\Delta\) 保证球内处处可行。随机误差情形用方差可加 \(\varepsilon_\Delta^2\ge e_{fuse}^2+\varepsilon_{model}^2+\varepsilon_{exec}^2\) 更紧，但有界情形必须用 Minkowski 和（加和）才是 sound。冲突分级在 \(conflict\le2\varepsilon_\Delta\) 时退回 breakdown 内的可信子集，其融合误差界按剔除后子集重算，预算约束仍成立。∎

### 引理 17（九证单调退化链 v26）
**陈述**：\(\mathrm{Exec}_{v26}\subseteq\mathrm{Exec}_{v25}\subseteq\cdots\subseteq\mathrm{Exec}_{v18}\) 在任意单点/组合故障下恒成立。

**证明**：由定义 \(\mathrm{Exec}_{v26}=\mathrm{Exec}_{v25}\cap Fil_{fuse}\cap Fil_{rob}\)，集合交必为子集。三条退化路径均只收紧集合、不放松：
- **融合冲突/Byzantine 超限** → MSFC=false（或 RFCC 判 reject）→ 先降 `trusted_subset`（剔除模态后仍要求 MSFC），再降 `single_source_conservative`（单源 + 协方差膨胀，$e_{fuse}$ 变大），最坏退回 v25 的保守单源计划；每一步都是原集合的子集。
- **鲁棒半径不足/扰动超界** → RBC=false → 收缩运行包络（降速/降力/降工作空间）直至 \(r(\pi)\ge\varepsilon_\Delta\)，或退回 v25 名义计划的降额版本（更保守，故为子集）。
- **预算超支** → RFCC=false → 重新分配感知/控制风险预算，或降级到可信子集；仍不满足则退回 v25。
- 组合故障取交集，单调性由交运算保持。∎

### 定理（RMS-USC 九证准入门完备性）
**陈述**：对任意多机计划 \(\Pi\)，\(\mathrm{RMS\text{-}USC}.\mathrm{admits}(\Pi)=\mathrm{True}\) 当且仅当 \(\Pi\) 同时满足 v25 的十项条件，以及
(11) **鲁棒性**：\(m(\pi)\ge L_C\varepsilon_\Delta\)、\(r(\pi)\ge r_{min}\)、scenario 失败率 \(\le\alpha_{rob}\)、ACI 长程覆盖 \(\ge1-\alpha_{rob}\)；
(12) **融合可信**：CI 保守 \(P_f\succeq P_{CI}\)、NEES 一致、\(S\ge2f+1\) 且 breakdown 有界、跨模态 \(d_H\le\varepsilon_{cross}\) 与 \(\tau_{sync}\)、FIM 可观测、融合覆盖 \(\ge1-\alpha_{fuse}\)；
(13) **耦合预算**：\(e_{fuse}+\varepsilon_{model}+\varepsilon_{exec}\le\varepsilon_\Delta\)、\(r(\pi)\ge\varepsilon_\Delta\)、冲突模式 \(\ne\) reject。

**证明**：充分性由 `admits` 的四个连言分支（src_usc / msfc / rfcc / rbc）与引理 13–16 直接得到；必要性为任一分支为假即拒证，对应一类未被缓解的风险。引理 17 给出退化链，保证降级不会绕过 v25 的安全基线，构成「证据鲁棒 → 状态可信 → 证书鲁棒」的完整闭环。∎

## 6. 本轮最大风险（最终确认）

**一句话**：**鲁棒证书的扰动集 Δ 与 Lipschitz 常数 L_C 是整套认证的「元假设」——一旦 L_C 被估低、实际 Byzantine 模态数超过 f、或攻击者同步污染多模态并制造「伪一致」，RBC/MSFC/RFCC 就会把「伪鲁棒」误判为「真鲁棒」，使 RMS-USC 在融合证据已被污染、证书裕度实际为负时仍错误准入；即认证器自身假设的失效，比任何单点传感器故障都更根本，也更难被同一套证书链捕获。**
