# 第 68 轮（承接第 67 轮「LENS 轻量视觉编码器」IP-234~243；灵感循环第 2 轮；本轮灵感：「行为树」×「步骤分」）

> 第 67 轮 LENS 回答的是「**看多细**」：在安全相关子空间上压缩视觉前端，并让算力随风险自适应。但它默认下游执行仍然是**扁平动作块 + 认证前缀 k***：一条线性计划，一个全局风险缩放 λ_risk，一次降级。这个假设在长程、多阶段、需要反应式恢复的任务里站不住：VISTA 的 k* 只能表达「这次走几步」，不能表达「如果这一步失败，退到哪条已验证的备用分支」；RAS 的 λ_risk 只能全局收紧/放宽，不能表达「只修某一棵子树」。
>
> 本轮把「扁平前缀 + 全局缩放」升级为「**步骤分认证的行为树**」：
>
> **行为树是安全证书的代数，步骤分是每个节点上的局部证书与部分信用（partial credit）。**
>
> 由此得到 **SCBT：Step-Certified Behavior Tree（步骤分认证行为树）**。它不是把 VISTA/RAS/LENS 换成行为树，而是给它们补上缺失的**组合层**：Sequence 把步骤分聚合成「最弱环」证书，Fallback 把「已验证的备选」变成可执行的恢复语义，Decorator 把重试/超时变成带预算的证书变换，步骤级故障归因则把「哪一层坏了」细化为「**哪一步坏了、该换哪棵子树**」。一句话：**认证前缀是线性证书，SCBT 要的是树形证书。**

## 0. 直觉与动机

**灵感 1（行为树不是流程图，而是可执行策略的代数）**
直觉：行为树的 Sequence / Fallback / Parallel / Decorator 正好对应证书代数的四种基本运算：
- Sequence `→`：所有子步骤都要成功 ⇒ 安全性是 `min`（最弱环），对应合取；
- Fallback `?`：按优先级尝试备选 ⇒ 只在**已验证的分支**里选，对应「带守卫的析取」；
- Parallel `⇉`：并发子任务 ⇒ 合取 + 资源预算；
- Decorator（Retry/Timeout/Guard）：不改变局部安全性，只改变**暴露时间**与**不确定度**。

更关键的是，行为树是**反应式**的：每个 tick 都可以重新选择分支。这恰好匹配 VISTA 的实时控制环——恢复不需要重规划整条计划，只需要在一次 tick 里换一棵已验证的子树。行为树因此不是可视化工具，而是「**在执行中可重写的证书结构**」。

**灵感 2（步骤分 = 局部证书 + 部分信用）**
直觉：「步骤分」在人类评分里指解题的中间步骤也能拿分；在机器学习里它就是 process reward / dense credit。把两者合起来：每个树节点 `n` 维护一个步骤分 `S_n ∈ [0,1]`，表示「从这一步继续，安全地完成任务」的**校准概率**。它的三个好处是：
1. **稠密**：不必等终局失败才发现问题，单步分数下滑即可触发检查；
2. **可比较**：Fallback 的多个分支可以直接按 `S_i` 排序，而不是靠手写优先级；
3. **可部分归因**：某一步「有进展但风险升高」仍能拿中间分，从而区分「完全走错」与「方向对但代价高」。

但步骤分是**估计量**，所以必须校准、必须带置信度、必须在不可信时 fail-closed——否则它会把「看起来不错」变成「被证书放行」。

**灵感 3（故障归因从「哪一层」到「哪一步」）**
直觉：第 65 轮 VISTA 的残差签名 `ρ` 回答「几何 / 传感器 / 模型哪一层坏了」，第 66 轮 RAS 增加「情绪」维度，第 67 轮 LENS 增加「压缩是否失效」。但控制层仍然只知道「这个 chunk 有问题」。若把 `ρ` 条件到树节点上，就能得到 `P(n | ρ)`：是**抓取条件**错了、**接近动作**抖了，还是**放置步骤**的视觉残差超了。归因粒度从 chunk 细化到 node，恢复动作也就能从「全局降级」变成「只替换失败子树」。这是本轮相对前三轮最本质的增量：**把恢复从标量动作升级为结构动作。**

**灵感 4（认证前沿取代认证前缀）**
直觉：VISTA 的 `k*` 是「沿一条线性计划能安全走多远」；SCBT 的对应物是**认证前沿（certified frontier）**：从根沿当前激活分支走到叶子的那条路径上，所有节点的证书都成立的最大深度 `h*`，再加上 Fallback 的分支选择 `i*`。于是 `k*_SCBT = (h*, i*)`。线性前缀是它的特例（一棵只有 Sequence 的树）。这个推广使「安全」与「结构」正交：深度可以因风险而收缩，分支可以因步骤分而切换，两者都由同一套代数约束。

**灵感 5（与 LENS/RAS 的风险双螺旋）**
直觉：LENS 在风险升高时**向上加算力**（看更细），SCBT 则在风险升高时**向下收计划**（走更短、更多用已验证 fallback）。这两者不是矛盾，而是同一风险信号的两个正交响应：**垂直方向增加感知分辨率，水平方向减少暴露步数**。把 `g_t`（LENS 通道组）与 `h_t`（SCBT 前沿深度）联立，得到一个二维的「风险—算力—步数」调度面。这也是对第 67 轮 RAC 的自然补全：只调度算力而不调度计划长度，等于只调了半个控制器。

**灵感 6（失败安全：树手术必须是单调的）**
直觉：在线改树很危险。SCBT 的原则是：**任何手术只能让证书变强，不能变弱**。允许的手术只有 `{retry, prune, switch-to-certified, tighten, safe-stop}`，且每次都要过「术后最弱环 margin 不下降」的检查；若没有可用的安全手术，就执行 `safe-stop`，而不是继续尝试。这继承并强化了 LENS 的 fail-closed：LENS 在感知上「看不见就退回大模型」，SCBT 在控制上「修不好就停」。

## 1. 形式化定义（增量：定义 259–272）

- **定义 259（SCBT 总览）**：`SCBT = (BT, SSG, SCA, SFA, CFR, BTS, J_SCBT)`。定位：VISTA/RAS/LENS 之上的「结构化执行与恢复层」。不变式：(i) 步骤分校准、证书代数参数、手术宏库只在语义流离线构建；(ii) 实时流只做 tick、查表打分、CUSUM、按宏库做手术，零学习写操作；(iii) 所有在线修改满足安全单调性，否则 safe-stop。
- **定义 260（行为树语法与 tick 语义）**：节点类型 `N = {Action, Condition, Sequence, Fallback, Parallel, Retry, Timeout, Guard}`。`tick(n, o_t) ∈ {Success, Failure, Running}`；Running 返回续延（无记忆/有记忆两种语义）。激活路径 `P_t = (n_0 → n_1 → … → n_h)` 是本次 tick 实际经过的节点序列；`leaves(P_t)` 为实际派发的动作叶子。要求所有 Fallback 使用「有记忆 + 迟滞」语义，禁止无记忆 fallback 的抖振。
- **定义 261（步骤分）**：对节点 `n` 与历史 `H_t(n)`，步骤分
  `S_n(t) = P( safe_success(τ_n) | H_t(n) ) ∈ [0,1]`，
  即「从该节点继续，最终安全完成任务」的校准概率。同时记录 `s_n = (p_n, q_n, c_n)`：进度、风险、置信度；标量化 `S_n = σ(α p_n − β q_n + γ c_n)`，`σ` 单调。`S_n` 既是局部证书，也是部分信用。
- **定义 262（η-校准步骤分）**：称 `S` 是 η-校准的，若在标定分布上
  1. 可靠性误差 `ECE(S) = Σ_b |B_b|/N · |acc(B_b) − conf(B_b)| ≤ η`；
  2. 适当评分 `Brier(S) = E[(S − Y)²] ≤ η² + Var(Y)`；
  3. 单调一致性：若节点 `m` 是 `n` 的后代，则 `S_n ≤ S_m + ε_mono`（父节点不应比其必经子步骤更乐观）。
  仅当 `η ≤ η_max` 且 `ε_mono ≤ ε_mono^max` 时，步骤分可用于证书聚合。
- **定义 263（SSG 步骤分生成器）**：`S_n(t) = h_θ( φ(ρ_n, π_n, Δ_n, c_n) )`，其中 `ρ_n` 是 VISTA 残差签名在子树 `τ_n` 上的投影、`π_n` 是 RAS 情绪分布、`Δ_n` 是相对上一步的进度增量、`c_n` 是置信特征；`h_θ` 对进度单调增、对风险单调减、对不确定度单调减。在线只做前向推理与查表，不更新参数。
- **定义 264（步骤证书代数 SCA）**：每个节点携带证书 `C_n = (m_n, u_n)`，`m_n` 为安全裕度（到安全边界的归一化距离），`u_n` 为不确定半径。组合算子：
  - **Sequence**：`m = min_i m_i`，`u = ⊕_i u_i := sqrt(Σ_i u_i²)`；
  - **Fallback（带守卫）**：令武装集 `A(n) = {i : Guard_i(o_t) = true}`，要求 `∀i∈A: C_i` 有效；`m = min_{i∈A} m_i`，执行分支 `i* = argmax_{i∈A} S_i`；`A=∅ ⇒ Failure`；
  - **Parallel**：`m = min_i m_i`，约束资源 `Σ_i c_i ≤ C`；
  - **Retry^k**：`m` 不变，`u ← u/√k_eff` 仅当 SFA 判定故障为瞬态；**Timeout^τ**：`m` 不变，仅截断暴露时间；
  - **Guard**：`m` 不变，但把「守卫条件本身可靠」作为独立证书项 `u_guard` 计入 `u`。
  关键点：Fallback 的证书对**所有武装分支**取 min（保守），但对**执行分支**按步骤分取 max（性能）；安全与性能因此解耦。
- **定义 265（认证前沿 CFR）**：给定激活路径与分支选择，认证前沿
  `F_t = (n_1, …, n_h), m(F) = min_{n∈F} m_n, S(F) = min_{n∈F} S_n`（最弱环）。
  `k*_SCBT = (h*, i*) = argmax_{(h,i)} h`，满足 `m(F_h) ≥ 0`、`S(F_h) ≥ τ_frontier`、`time(F_h) ≤ B`；`h*` 是「沿已验证分支能安全暴露的最大步数」，`i*` 是分支选择。扁平 `k*_VISTA` 是只有 Sequence 时的特例。
- **定义 266（步骤级故障归因 SFA）**：对树节点集合 `N`，
  `P(n | ρ) ∝ p(ρ | n) · P(n)`，
  其中 `p(ρ|n)` 由 VISTA 签名在子树 `τ_n` 上的条件分布给出。输出 `(n*, H*, post)`：最可能的故障节点、故障类别、后验。若后验熵 `> τ_amb`，输出**故障簇**（一组相邻节点）而非单点，并把簇交给 BTS 做保守手术。
- **定义 267（步骤分变点检测）**：对每个节点维护 CUSUM
  `g_n(t) = max(0, g_n(t−1) + (μ_0 − S_n(t)) − k)`，
  `g_n(t) > h` 时报警。设 `H_0` 下 `S_n` 均值 `μ_0`、`H_1` 下均值下降 `δ`，则误报的 ARL `≥ e^{h}`（近似），检测延迟 `≤ h/(δ−k) + 1`（`k<δ`）。报警触发 SFA 与 BTS，而不是直接降级。
- **定义 268（行为树手术 BTS）**：允许的宏操作
  `O = {retry(n,k), prune(n), switch(n→m), tighten(n,λ), insert_safe_stop(n)}`。
  手术 `T' = op(T, n)` 可采纳，当且仅当：(i) `T'` 语法有效；(ii) `m(F') ≥ max(m(F), m_min)`；(iii) 若 `op = switch`，则目标分支 `m` 必须已在武装集中通过证书；(iv) 手术次数与时间有上界。定义安全偏序 `T' ⊒_safe T` 为「所有前沿裕度不减」。**不可采纳 ⇒ safe-stop**。
- **定义 269（AIC-BT 干扰集）**：`ℰ_BT = ℰ_LENS × ℰ_struct × ℰ_score`。其中
  `ℰ_struct = {条件误判, 陈旧节点记忆, Decorator 活锁, 树投毒, 叶子缺失}`；
  `ℰ_score = {步骤分失准, 步骤分投毒/奖励黑客, 分布漂移, 共因退化}`。
  共因项 `ℰ_common_bt` 捕获「同一光照事件同时降低 LENS 特征与步骤分」的耦合，并要求 SFA 区分「真故障」与「评分器故障」。
- **定义 270（J_SCBT 证书）**：
  `J_SCBT = (J_LENS, tree_hash, F_t, {S_n}, sfa_posterior, calib_version, cusum_state)`；
  `Valid(J_SCBT) ⇔ Valid(J_LENS) ∧ m(F) ≥ 0 ∧ η_S ≤ η_max ∧ tree_hash ∈ approved ∧ (无未处置报警)`。
- **定义 271（风险自适应行为树调度）**：给定 `λ_risk(t)` 与 LENS 的 `g_t`，选择前沿深度
  `h_t = clamp( h_min + ⌊λ_risk(t)·(h_max − h_min)⌋ , h_min, h_max )`，
  即**风险越高（λ_risk 越低）→ 暴露越短**；同时在 `A(n)` 内按 `S_i` 选分支。与 LENS 的 `g_t`（风险越高、算力越高）构成「垂直加密 / 水平收缩」的对偶。
- **定义 272（部分信用势与安全早停）**：令 `Φ_n = E[剩余安全回报 | n]`，步骤信用 `κ_n = Φ_n − Φ_parent`。当 `S_n < τ_abort` 且剩余回报上界 `UB(Φ_n) < V_min` 时，执行 fallback 或 `safe-stop`。该规则把「继续硬做」的期望损失限制在校准误差与势函数 Lipschitz 常数之内。

# SSG：步骤分（在线只前向）
class StepScoreGenerator:
    def __init__(self, mu0=0.8, cusum_k=0.1, cusum_h=1.5):
        self.mu0, self.k, self.h = mu0, cusum_k, cusum_h
        self.g = defaultdict(float)

    def score(self, node, rho, pi, delta_progress, conf):
        feat = encode_step_features(rho, pi, delta_progress, conf)
        S = self.calibrated_head(feat)          # 定义 262，∈[0,1]
        self.g[node.id] = max(0.0, self.g[node.id]
                              + (self.mu0 - S) - self.k)
        return S, self.g[node.id] > self.h


# SCA：证书代数（递归求值，同时返回执行分支）
def eval_cert(node, obs, ssg):
    if node.type == 'Action':
        m = safety_margin(node, obs)             # VISTA 局部证书
        S, alarm = ssg.score(node, obs.rho, obs.pi,
                             obs.delta_progress, obs.conf)
        return Cert(m=m, u=node.u_model, score=S, alarm=alarm), node
    if node.type == 'Sequence':
        certs = [eval_cert(c, obs, ssg) for c in node.children]
        m = min(c.m for c, _ in certs)
        u = sqrt(sum(c.u**2 for c, _ in certs))

def certified_frontier(tree, obs, ssg, lam_risk, budget):
    path = tree.active_path(obs)
    F, m_F = [], +inf
    for n in path:
        cert, _ = eval_cert(n, obs, ssg)

def recover(tree, rho, obs, ssg):

    if not alarms and max(post.values()) < TAU_ATTR:

## 3. 推导

**引理 14（证书代数的误差不放大）** `min` 与 `max` 关于无穷范数是 1-Lipschitz；若每个叶子的裕度误差 `≤ ε_m`、步骤分误差 `≤ ε_S`，则任意组合节点的 `|m̂ − m| ≤ ε_m`、`|Ŝ − S| ≤ ε_S`。不确定度按 `sqrt(Σ u_i²)` 聚合，等价于独立子高斯变量的联合界；当子节点误差相关时，用 `u_parent ≤ Σ u_i` 的更保守界。**因此组合只聚合误差、不创造误差**——但也不消除局部误差（见定理 18 的风险）。
*证明*：`|min_i a_i − min_i b_i| ≤ max_i |a_i − b_i|`；`max` 同理；平方和开方由独立性和方差可加性给出。

**引理 15（CUSUM 的误报/延迟界）** 在 `H_0` 下若 `S_n` 独立同分布、均值 `μ_0`，则 ARL `≥ e^{h}`（Wald 近似）；在 `H_1` 下均值下降 `δ > k`，期望检测延迟 `≤ h/(δ−k) + 1`。故步骤分崩塌会在有界时间内被发现，暴露时间有上界。
*证明*：CUSUM 的鞅构造 + Wald 方程 / 随机游走越界期望。

**定理 15（SCBT 的组合安全性）** 若 (i) 每个被执行的武装叶子都有 `m ≥ 0`；(ii) Guard 条件由独立监视器给出且可靠度 `≥ 1−α_g`；(iii) 局部裕度误差 `≤ ε_m`；则对任意执行前沿 `F`，有 `m(F) ≥ −ε_m`，且执行未认证分支的概率 `≤ α_tree + α_g + δ_cusum`。进一步，**Fallback 完备性**：只要存在一个已认证的武装分支，CFR 会在树的深度 `d` 内返回它；若不存在，则返回 safe-stop 而非继续执行。
*证明思路*：对定义 264 的 `min` 组合做归纳；Fallback 的武装集要求所有分支通过证书，故选择任一分支都安全；完备性由有限树上的 DFS + 认证剪枝保证。

**定理 16（校准步骤分的早停遗憾界）** 若步骤分 `η`-校准、势函数 `Φ` 关于 `S` 是 `L`-Lipschitz，则早停/切换策略相对全知 oracle 的期望遗憾
`Regret(T) ≤ 2η·H + L·ε_mono·H + O(√(log(1/δ)/T))`，
以概率 `≥ 1−δ`。其中 `H` 为最大步数。直觉：校准误差是「错误继续/错误中止」的唯一系统性来源；稠密步骤分把终局才可见的 `O(√H)` 方差摊薄为逐步的 `O(ηH)`。
*证明思路*：把遗憾分解为「每步的校准偏差项」与「停止时间的鞅项」；前者由 η-校准界定，后者由 Azuma/Hoeffding 给出。

**定理 17（步骤级归因的信息优势）** 节点划分 `σ(node)` 细于 chunk 划分 `σ(chunk)`，即 `σ(chunk) ⊆ σ(node)`。由数据处理不等式，
`I(n*; fault) ≥ I(chunk; fault)`；
等号成立当且仅当故障效应在每个 chunk 内恒定。因此步骤级归因不会损失信息；当一个 chunk 内含多个易错步骤时严格更优，定位误差的期望随树分辨率提高而下降。
*证明*：`n* → chunk` 是确定映射，故 `fault → n* → chunk` 构成马尔可夫链；数据处理不等式给出结论。

**定理 18（手术的 fail-closed 单调性）** 在定义 268 的安全偏序下，每个可采纳手术 `T' ⊒_safe T`，即所有前沿裕度不减；若不存在可采纳手术，`safe-stop` 的裕度最大。因此在线恢复循环**永远不会降低已认证的安全性**，代价只是可能牺牲性能（保守）。但注意：这条定理只保证「相对于当前的局部证书」不降级，**不保证局部证书本身正确**。
*证明*：定义 268 的采纳条件直接给出；safe-stop 将所有动作替换为已验证的停止动作，其裕度按构造 `≥ m_min`。

## 6. 本轮最大风险

**一句话**：SCBT 的组合证书只能传播**局部**步骤分与裕度的误差，无法验证行为树结构本身（尤其条件节点与边）是否语义正确——一旦步骤分被分布漂移/投毒校准错误，或一个 Guard 条件被写反，系统会自信地执行一棵「每个局部都合格、整体却错误」的子树，而 `min/max` 代数会把这种错误整合成一张看似合法的证书，形成比 LENS 更隐蔽的「**组合性幻觉（compositional hallucination）**」。

**次级风险与缓解**：
1. **步骤分失准/奖励黑客**：用独立校准集 + 保守下置信界 `S_n^LCB`，证书只用 LCB；连续 N 步校准漂移则吊销 `calib_version`。
2. **树结构错误**：对 Guard 条件做运行时双向监视（条件成立/不成立各测一次），并把「条件节点」纳入 AIC-BT；关键任务用形式化静态检查（BT 的 LTL 语义）。
3. **Fallback 抖振/活锁**：有记忆语义 + 迟滞 + 最小驻留时间；每棵子树的重入次数有界。
4. **手术组合爆炸**：只允许预编译宏库（O(常数) 个操作），并限制每轮最多一次手术。
5. **共因失效**：LENS 与 SSG 共享同一光照/遮挡事件时，二者同时退化——用与视觉解耦的时序/本体感知信号做交叉校验。
6. **CUSUM 延迟 vs 误报**：对高危节点用更小的 `h`、对低频节点用更大的 `h`，并按故障类别分层设置。

ECE(S) = Σ_b |B_b|/N · |acc(B_b) − conf(B_b)| ≤ η
Brier(S) = E[(S − Y)²] ≤ η² + Var(Y)
S_n ≤ S_m + ε_mono   (m 为 n 的后代)

仅当 `η ≤ η_max ∧ ε_mono ≤ ε_mono^max` 时可用于证书聚合。

**定义 264（步骤证书代数 SCA）**
```
Sequence:   m = min_i m_i,  u = sqrt(Σ_i u_i²)
Fallback:   A = {i : Guard_i(o_t)=true}
            m = min_{i∈A} m_i,  i* = argmax_{i∈A} S_i
Parallel:   m = min_i m_i  s.t.  Σ_i c_i ≤ C
Retry^k:    m 不变, u ← u/√k_eff  (仅瞬态故障)
Timeout^τ:  m 不变, 截断暴露时间
Guard:      u ← sqrt(u² + u_guard²)

Fallback 对武装集取 min（安全），对执行分支取 max（性能）。

    F, m_F = certified_frontier(
        M.scbt.tree, obs, M.ssg, M.last_lambda_risk)

    if any(M.ssg.g[n.id] > M.ssg.h for n in F):
        M.scbt.tree = recover(M.scbt.tree, rho, obs, M.ssg)

    k_scbt = M.cfr.prefix(F, m_F)
    joint_post, _ = M.efs.synthesize(rho, face_gate)
    lam = M.efs.risk_scale(joint_post)

    tau_cmd = M.vista.pi_sigma.prefix_dispatch(F[:k_scbt]) * lam
    tau_cmd = M.ers.shaping(tau_cmd, face_gate)

    J = build_j_scbt(M.vista.J, M.lens.J, M.scbt.tree,
                     F, M.ssg, k_scbt, m_F)
    if not valid_j_scbt(J, M.eta_max):
        return safe_stop(M.scbt.tree)

    M.last_lambda_risk = lam
    return k_scbt, lam, F, J
```

## 4. 推导

**引理 14（证书代数误差不放大）** `min/max` 关于无穷范数 1-Lipschitz；若叶子 `|m̂−m| ≤ ε_m`、`|Ŝ−S| ≤ ε_S`，则任意组合节点同样满足。不确定度按 `u = sqrt(Σu_i²)` 聚合（独立子高斯联合界）；相关时用 `u ≤ Σu_i`。组合只聚合误差、不创造误差，也不消除局部误差。
*证明*：`|min_i a_i − min_i b_i| ≤ max_i |a_i−b_i|`；`max` 同理；方差可加。

**引理 15（CUSUM 界）** `H_0` 下 ARL `≥ e^h`（Wald 近似）；`H_1` 下均值下降 `δ>k` 时，期望延迟 `≤ h/(δ−k)+1`。
*证明*：CUSUM 鞅构造 + Wald 方程。

**定理 15（SCBT 组合安全性）** 若 (i) 每个执行武装叶子 `m ≥ 0`；(ii) Guard 由独立监视器给出、可靠度 `≥1−α_g`；(iii) 局部裕度误差 `≤ε_m`，则
```
m(F) ≥ −ε_m
P(执行未认证分支) ≤ α_tree + α_g + δ_cusum
```
且 Fallback 完备：只要存在已认证武装分支，CFR 在深度 `d` 内返回它；否则 safe-stop。
*证明思路*：对定义 264 的 `min` 结构归纳；武装集全认证 ⇒ 任一分支安全；完备性由有限树 DFS + 认证剪枝。

**定理 16（校准步骤分的早停遗憾）** 若 `S` 为 η-校准、`Φ` 关于 `S` 为 `L`-Lipschitz，则
```
Regret(T) ≤ 2η·H + L·ε_mono·H + O(√(log(1/δ)/T))
```
以概率 `≥1−δ`。
*证明思路*：遗憾 = 每步校准偏差项 + 停止时间鞅项；前者由 η-校准，后者由 Azuma/Hoeffding。

**定理 17（步骤级归因信息优势）** `σ(chunk) ⊆ σ(node)`，故
```
I(n*; fault) ≥ I(chunk; fault)
```
等号当且仅当故障效应在每个 chunk 内恒定。一个 chunk 含多个易错步骤时严格更优。
*证明*：`n* → chunk` 为确定映射，构成马尔可夫链，用数据处理不等式。

**定理 18（手术 fail-closed 单调性）** 在 `⊒_safe` 下每个可采纳手术满足 `T' ⊒_safe T`（所有前沿裕度不减）；无可采纳手术时 `safe-stop` 裕度最大。故在线恢复循环永不降低已认证安全性，代价是可能牺牲性能。**但该定理只保证相对当前局部证书不降级，不保证局部证书本身正确。**
*证明*：定义 268 的采纳条件直接给出；safe-stop 将所有动作替换为已验证停止动作。

## 7. 本轮最大风险

**一句话**：SCBT 的组合证书只能传播局部步骤分与裕度的误差，无法验证行为树结构本身（尤其条件节点与边）是否语义正确——一旦步骤分被分布漂移/投毒校准错误，或一个 Guard 条件被写反，系统会自信地执行一棵「局部全合格、整体却错误」的子树，而 `min/max` 代数会把这种错误整合成看似合法的证书，形成比 LENS 更隐蔽的「组合性幻觉（compositional hallucination）」。

**次级风险与缓解**：
1. **步骤分失准/奖励黑客** → 独立校准集 + 保守下置信界 `S_n^LCB`；漂移时吊销 `calib_version`；
2. **树结构错误** → Guard 运行时双向监视 + 条件节点纳入 AIC-BT + 关键任务 LTL 静态检查；
3. **Fallback 抖振/活锁** → 有记忆语义 + 迟滞 + 最小驻留时间 + 重入次数上界；
4. **手术组合爆炸** → 仅预编译宏库，每轮最多一次手术；
5. **共因失效** → 与视觉解耦的时序/本体感知交叉校验；
6. **CUSUM 延迟 vs 误报** → 按节点风险分层设置 `h`，高危节点更快报警。
