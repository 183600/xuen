# 第 61 轮（承接第 60 轮「场景感知闭环」IP-153~160；灵感循环第 1 轮；本轮灵感：「多轮对话」×「场景落地」）

> 第 60 轮建立了 SSM×CIEC×EPIR×SERC×PCE++++，把「场景→阻抗先验、意图→实时约束、EV-exec→防丢证据链」串成闭环。但**落地视角**下仍有三个根问题：
> 1. **认知是单轮的**：CIEC 把一句话 `intent` 一次性查表映射为 `C_intent`，无法处理真实对话中的**相对调整**（「再轻一点」）、**指代**（「像刚才那样」「那个位置」）、**澄清**（「你是指夹爪还是底座？」）与**非单调覆盖**（后一句可以推翻前一句）。约束没有版本、不能回溯、不能谈判。
> 2. **场景是封闭集的**：SSM 的 10 个场景 + Kalman 后验在实验室成立，但真实落地是**开放集长尾**；`unknown` 被强行吸附到最近邻，是**安全先验错配**的最危险来源，而不是安全的兜底。
> 3. **落地缺一个判据**：第 60 轮只有「适应成功率 ≥ 80%」这类离线指标，缺少把**对话中达成的约束**与**执行证据**对账的一致性证书，也缺少**场景覆盖率**的统计保证——「场景落地」仍停留在假设层面。

## 0. 直觉与动机

**灵感 1（多轮对话 → 约束状态机 MCSM）**
直觉：约束不是一个值，而是一份**会演化、可回溯的契约**。人这一轮说「慢点」，下一轮说「但别太软」，再下一轮说「刚才那个力度就行」。因此约束需要一个**带版本的对话状态**：每一句只产生一个**约束补丁 ΔC**，叠加在 `C_t` 上；`C_t` 可回滚到任意历史版本，且**永远先与安全地板 S_hard 求交**。关键洞见：**对话只能收紧或平移安全域内的约束，永远不能突破安全地板**——把「人说了算」限定为「安全域内人说了算」。

**灵感 2（多轮对话 → 约束谈判协议 CNP）**
直觉：当人的要求与物理可行域冲突（「完全别用力」但必须接触），单轮系统只有两种坏结局——硬执行（危险）或静默失败（用户困惑）。多轮对话的真正价值是**回价**：机器人回一句「做不到完全不接触，K_p=0.6、接触力 ≤0.8F_nom 可以吗？」。把「意图约束」升级为**有界轮数的双向谈判**：人提议、机器人验证可行性并给反提议、人接受/拒绝/修改。关键洞见：**可行性检查必须发生在执行之前**，谈判是把「执行期失败」提前到「对话期解决」。

**灵感 3（场景落地 → 开放集场景识别 OSSR）**
直觉：部署到现场，第一件事是承认「我不认识这个场景」。把封闭集分类换成**开放集 + 证据不确定性**：已知场景给信念 `b_k`，其余给**无知度 u**；当 `u` 高或特征距离远时判为 `unknown`，此时**不允许套用任何具体场景先验**，而用**不确定性膨胀**的保守阻抗域。承认未知后，再主动做**短探针（probe）**采集数据，登记为新场景 `z_new`。关键洞见：**「unknown」不是分类失败，而是一个安全的、可学习的一等状态**。

**灵感 4（对话接地记忆 CGM + 落地就绪证书 DRC）**
直觉：多轮对话之所以能「像刚才那样」，是因为有**对话-执行接地记忆**：记住「哪句话 → 哪个区域 → 哪个约束 → 执行结果」。用这段记忆做指代消解，也用它做**说-做一致性检测**（约定 K_p=0.6，实测 0.85 就报警）。再往上，把多个场景、多轮谈判、多次执行汇总成一张**落地就绪证书**：场景覆盖率、约束符合率、未知率、谈判成功率、证据链完整性，各自带统计下界。关键洞见：**落地不是一个二元状态，而是一个可签发、可审计的证书**。

**灵感 5（五灵感合流 → 对话驱动的场景落地闭环 DGSL；预算升级 PCE+++++）**
直觉：多轮对话把 `OSSR 的 unknown` 变成探针任务，把 `CNP 的反提议` 变成可执行约束，把 `CGM` 变成指代与对账依据，把 `DRC` 变成毕业判据；执行证据再回流，更新场景信念与记忆。闭环为：**对话→约束契约→可行性/谈判→开放集场景→执行→EV-exec→说做对账→记忆/证书→下一轮对话**。预算相应升级出 `B_dlg`（轮数/澄清/谈判/记忆）。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（多轮约束状态机 MCSM）** 对话约束状态 `D_t = (C_t, Π_t, R_t, h_t, V_t)`：
- **约束盒**：`C_t = ∏_i [l_i, u_i]`（各参数维度的区间盒，如 v_max/F_max/K_p/K_d/ε_traj/region）
- **安全地板**：`S_hard` 为不可被对话放松的硬盒；**不变式**：`∀t, C_t ⊆ S_hard`
- **指代绑定**：`Π_t : ref → (entity, turn_id)`，指代消解结果
- **待澄清集**：`R_t`，歧义未消的槽位
- **历史窗口**：`h_t = (u_1..u_t)` 的摘要
- **版本栈**：`V_t = [C_0, C_1, ..., C_t]`，支持回滚 `rollback(τ)`

状态转移 `D_{t+1} = δ(D_t, u_t)`，其中补丁语义：
```
patch(u_t) = {(field_i, op, value_i)}         # op ∈ {set, inc, mul, clamp}
C̃_{t+1} = apply(C_t, patch(u_t))              # 逐字段 last-writer-wins（非单调）
C_{t+1} = C̃_{t+1} ⊓ S_hard                    # 强制与安全地板求交（不变式）
```
**对话安全性引理**：只要 `S_hard` 固定且 `⊓` 为交，则任意多轮、任意顺序的补丁都满足 `C_t ⊆ S_hard`。

**定义 162（指代与相对调整解析 RA）** 解析函数 `ρ(u_t, D_t, M_g) → (target, ΔC, amb)`：
- **相对调整**：`"再轻一点" ⇒ K_p ← K_p·(1−ε)`，`"比刚才慢"` 以接地记忆 `M_g` 中最近一次约束为基准
- **指代消解**：`"那个位置" ⇒ Π_t[ref]`，用嵌入检索 + 时间衰减 `sim·λ^{t−t_ref}` 选实体
- **歧义度**：`amb(u_t) = 1 − max_k softmax_k`；若 `amb > τ_amb`，置入 `R_t` 并生成澄清问句
- **澄清优先**：存在 `R_t ≠ ∅` 时，禁止对相关槽位执行补丁（宁停勿错）

**定义 163（约束谈判协议 CNP）** 有界交替博弈 `(H, O, N_neg, U_O)`：
```
t=0: 人提出 C_H
loop t = 1..N_neg:
    if feasible(C_H, K_safe, B_exec): O.commit(C_H); return ACCEPT
    C_O = argmax_{C ∈ Feas} U_O(C; C_H)
          s.t.  C ⊆ S_hard  ∧  dist(C, C_H) ≤ ρ_concession(t)
    H ∈ {accept(C_O), reject, modify(C_H')}
if 未收敛: return C_cons = EEIS.compile_conservative(...)
```
- **可行域**：`Feas = {C | C ∩ K_safe^scene ≠ ∅ ∧ cost(C) ≤ B_exec}`
- **机器人效用**：`U_O(C; C_H) = −dist(C, C_H) − λ_risk·risk(C)`
- **让步界**：`ρ_concession(t)` 单调不减，保证反提议逐步靠近请求
- **安全不变式**：反提议恒满足 `C_O ⊆ S_hard`（谈判也不能越安全地板）

**定义 164（开放集场景识别 OSSR）** 证据分类头输出 Dirichlet `Dir(α)`：
- **信念/无知**：`b_k = α_k / S`，`u = K / S`，`S = Σα_k`
- **已知判定**：`known ⟺ max_k b_k ≥ τ_b ∧ u ≤ τ_u ∧ d_ood(x) ≤ τ_d`
- **未知处理**：`unknown` 时**禁用具体先验**，用膨胀域 `K_safe^unk = K_safe^base ⊖ u·Σ_infl`（⊖ 表示按 u 收缩可行域）
- **新场景登记**：探针数据 `D_probe` 经贝叶斯回归得 `π_new = N(μ_new, Σ_new)`，并令 `Σ_new ← Σ_new + u·Σ_infl` 后再登记
- **单调安全**：`u` 越大 ⇒ 可行域越小 ⇒ 越保守（可证）

**定义 165（对话接地记忆 CGM）** `M_g = {(e_i, d_i, C_i, region_i, outcome_i)}`：
- **检索**：`retrieve(q) = argmax_i sim(e_q, e_i)·λ^{t−t_i}`，用于「像上次那样」的指代
- **说做对账**：`conform(i) = [ dist(C_i^agreed, C_i^exec) ≤ ε_conf ]`，其中 `C^exec` 从 EV-exec 反演
- **漂移告警**：连续 `W_drift` 次 `conform = false` ⇒ 触发「约定失效」，回到 CNP 重谈

**定义 166（场景落地就绪证书 DRC）** `DRC = (cov, conf, nov, neg, chain)`，各分量带统计下界：
- `cov`：场景覆盖率，对场景分布的经验覆盖用 Clopper–Pearson 下界
- `conf`：约束符合率 `Pr(conform)`
- `nov`：未知/新登记率（用于暴露长尾风险）
- `neg`：谈判成功率与平均轮数
- `chain`：EPIR 证据链完整性
- **签发条件**：`LB(cov) ≥ θ_cov ∧ LB(conf) ≥ θ_conf ∧ LB(chain) ≥ θ_chain`（`LB` 为置信下界）

**定义 167（对话感知预算 B_dlg 与 PCE+++++）** `B_dlg = (B_turn, B_clarify, B_negotiate, B_memory)`：
- 轮数耗尽 ⇒ 锁定当前可行 `C_t` 并停止接受新补丁
- 澄清耗尽 ⇒ 对歧义槽位取保守默认（不猜）
- 谈判耗尽 ⇒ 返回 `C_cons` 并记录未达成项
- 记忆耗尽 ⇒ 只保留最近 `W_mem` 条接地对，禁用「像上次那样」的跨会话指代
- 总 VOI：`voi_dlg = voi_cog − λ_turn·TurnCost − λ_clar·ClarifyCost − λ_neg·NegotiateCost`

**定义 168（对话驱动场景落地闭环 DGSL）** 算子 `DGSL(M, u_t, scene_obs)`：
```
① MCSM: (C_t, Π_t, R_t) ← δ(D_{t−1}, u_t)          # 补丁 + 安全地板求交
② RA:   若 R_t ≠ ∅ → 生成澄清问句并返回（宁停勿错）
③ OSSR: (z, b, u) ← observe(scene_obs)
④ 若 unknown → 发起短探针 → 登记 π_new（Σ 膨胀）→ 得 K_safe^scene
⑤ CNP:  if ¬feasible(C_t) → negotiate(C_t, K_safe^scene) → C*
⑥ Exec: K_safe ← EEIS.compile(C*, K_safe^scene)；dispatch
⑦ EV-exec ← execute(); EPIR.append(EV-exec)
⑧ CGM:  append(utterance, C*, region, outcome)；conform 检测
⑨ DRC:  更新 cov/conf/nov/neg/chain；若漂移 → 回到 ⑤ 重谈
⑩ Return: (C*, EV-exec, DRC, R_t, M_g)
```

## 2. 关键算法伪代码

### IP-161 MCSM（多轮约束状态机）

```python
class MultiTurnConstraintStateMachine:
    def __init__(self, safety_floor):
        self.S_hard = safety_floor          # 不可放松
        self.C = safety_floor.copy()
        self.stack = [self.C.copy()]
        self.bindings, self.pending = {}, []
        self.protected = {'safety', 'region_hard'}

    def update(self, utterance, memory):
        patch, amb, refs = self._parse(utterance, memory)
        if amb > TAU_AMB:
            self.pending.append(utterance)
            return self.C, self._clarify(utterance)      # 宁停勿错
        C_new = self.C.copy()
        for f, op, v in patch:
            if f in self.protected:
                continue                                  # 保护字段不可被对话改写
            C_new[f] = apply_op(C_new[f], op, v)          # set/inc/mul/clamp
        C_new = C_new.intersect(self.S_hard)              # 不变式：C ⊆ S_hard
        self.C = C_new
        self.stack.append(C_new.copy())
        self.bindings.update(refs)
        return self.C, None

    def rollback(self, tau):
        self.C = self.stack[tau].copy()
        self.stack = self.stack[:tau + 1]
```

### IP-163 CNP（约束谈判）

```python
class ConstraintNegotiator:
    def negotiate(self, C_H, k_safe, exec_budget, max_neg=4):
        for t in range(1, max_neg + 1):
            if feasible(C_H, k_safe, exec_budget):
                return C_H, 'ACCEPT'
            C_O = self._best_counter(C_H, k_safe, rho=self._concession(t))
            if C_O is None:
                break
            resp = self._ask_human(C_O)          # accept / reject / modify
            if resp == 'accept':
                return C_O, 'AGREED'
            if resp != 'modify':
                break
            C_H = resp.new_request
        return EEIS.compile_conservative(k_safe), 'FALLBACK'

    def _best_counter(self, C_H, k_safe, rho):
        cand = [C for C in sample_box(C_H, rho) if C.subset_of(self.S_hard)]
        cand = [C for C in cand if feasible(C, k_safe, B_exec)]
        return max(cand, key=lambda C: -dist(C, C_H) - LAMBDA_RISK * risk(C),
                   default=None)
```

### IP-164 OSSR（开放集场景识别）

```python
class OpenSetSceneRecognizer:
    def observe(self, x):
        alpha = self.evidence_head(x)
        S = alpha.sum(); b = alpha / S; u = self.K / S
        d = self.ood_distance(x)
        if max(b) >= TAU_B and u <= TAU_U and d <= TAU_D:
            return self.labels[argmax(b)], b, u, False       # known
        return 'unknown', b, u, True

    def register_novel(self, probe_data, u):
        mu, Sigma = self.bayes_regress(probe_data)
        Sigma = Sigma + u * SIGMA_INFL                     # 不确定性膨胀
        self.priors[len(self.priors)] = Gaussian(mu, Sigma)

    def safe_domain(self, z, u):
        base = self.base_domain()
        return base.shrink(u) if z == 'unknown' else base & self.priors[z].ci()
```

### IP-166 DRC（落地就绪证书）

```python
def issue_deployment_readiness(records, alpha=0.05):
    n = len(records)
    cov_lb = clopper_pearson_lo(sum(r.covered for r in records), n, alpha)
    conf_lb = clopper_pearson_lo(sum(r.conform for r in records), n, alpha)
    chain_lb = clopper_pearson_lo(sum(r.chain_ok for r in records), n, alpha)
    return DeploymentReadiness(
        cov=cov_lb, conf=conf_lb, nov=mean(r.is_novel for r in records),
        neg=mean(r.negotiated for r in records), chain=chain_lb,
        valid=(cov_lb >= THETA_COV and conf_lb >= THETA_CONF
               and chain_lb >= THETA_CHAIN))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| MCSM | O(\|patch\|) / 轮 | O(T·d) 版本栈 | 安全地板不变式：`C_t ⊆ S_hard` 恒成立 |
| RA | O(\|M_g\|·d) 检索 | O(W_mem·d) | 歧义 `amb>τ_amb` ⇒ 强制澄清 |
| CNP | O(N_neg·S_sample) | O(1) | `< N_neg` 轮收敛或安全回退 |
| OSSR | O(K) 前向 | O(K + N_probe) | `u↑ ⇒ 可行域↓`（单调保守） |
| DRC | O(n) | O(1) | Clopper–Pearson 置信下界 |

**正确性定理（DGSL）**：设 A66–A70 成立——**(A66)** `S_hard` 固定且 `⊓` 为交；**(A67)** 相对调整算子在紧致域内；**(A68)** `U_O` 连续、`ρ_concession` 单调不减且 `Feas` 非空紧致；**(A69)** 证据头校准（`b+u=1`）；**(A70)** 对账容差 `ε_conf` 覆盖传感器噪声。则：
1. **对话安全**：任意轮数、任意覆盖顺序，恒有 `C_t ⊆ S_hard`；人无法通过对话突破安全地板。
2. **谈判终止与安全**：若 `Feas ≠ ∅`，CNP 在 `N_neg` 轮内达成 `ACCEPT/AGREED`；否则返回安全 `C_cons`，且所有反提议 `⊆ S_hard`。
3. **开放集安全单调性**：`unknown` 状态与更高 `u` 只会缩小可行域，`K_safe^unk` 覆盖真实可行域的概率 ≥ `1−α`。
4. **证书可审计**：`DRC` 各分量为置信下界，签发条件给出覆盖率/符合率的统计保证。

## 5. 本轮最大风险

**一句话**：若开放集把长尾场景误登记为已知、或接地记忆把「像上次那样」锚定到错误的历史回合，机器人会**自信地执行一份在错误语境下"谈定"的约束**——对话共识并不等于物理安全，因此必须让 `S_hard` 安全地板、`unknown` 保守膨胀、说做对账漂移告警三者**独立于对话**地兜底。

## 2. 关键算法伪代码

### IP-161 MCSM（多轮约束状态机）

```python
class MultiTurnConstraintStateMachine:
    def __init__(self, safety_floor):
        self.S_hard = safety_floor
        self.C = safety_floor.copy()
        self.stack = [self.C.copy()]
        self.bindings, self.pending = {}, []
        self.protected = {'safety', 'region_hard'}

    def update(self, utterance, memory):
        patch, amb, refs = self._parse(utterance, memory)
        if amb > TAU_AMB:
            self.pending.append(utterance)
            return self.C, self._clarify(utterance)      # 宁停勿错
        C_new = self.C.copy()
        for f, op, v in patch:
            if f in self.protected:
                continue                                  # 保护字段对话不可改写
            C_new[f] = apply_op(C_new[f], op, v)
        C_new = C_new.intersect(self.S_hard)              # 不变式
        self.C, self.stack = C_new, self.stack + [C_new.copy()]
        self.bindings.update(refs)
        return self.C, None

    def rollback(self, tau):
        self.C, self.stack = self.stack[tau].copy(), self.stack[:tau + 1]
```

### IP-163 CNP（约束谈判）

```python
class ConstraintNegotiator:
    def negotiate(self, C_H, k_safe, exec_budget, max_neg=4):
        for t in range(1, max_neg + 1):
            if feasible(C_H, k_safe, exec_budget):
                return C_H, 'ACCEPT'
            C_O = self._best_counter(C_H, k_safe, rho=self._concession(t))
            if C_O is None:
                break
            resp = self._ask_human(C_O)                  # accept/reject/modify
            if resp == 'accept':
                return C_O, 'AGREED'
            if resp != 'modify':
                break
            C_H = resp.new_request
        return EEIS.compile_conservative(k_safe), 'FALLBACK'

    def _best_counter(self, C_H, k_safe, rho):
        cand = [C for C in sample_box(C_H, rho) if C.subset_of(self.S_hard)]
        cand = [C for C in cand if feasible(C, k_safe, B_exec)]
        return max(cand, key=lambda C: -dist(C, C_H) - LAMBDA_RISK * risk(C),
                   default=None)
```

### IP-164 OSSR（开放集场景识别）

```python
class OpenSetSceneRecognizer:
    def observe(self, x):
        alpha = self.evidence_head(x)
        S = alpha.sum(); b = alpha / S; u = self.K / S
        d = self.ood_distance(x)
        known = max(b) >= TAU_B and u <= TAU_U and d <= TAU_D
        return (self.labels[argmax(b)] if known else 'unknown'), b, u, not known

    def register_novel(self, probe_data, u):
        mu, Sigma = self.bayes_regress(probe_data)
        self.priors[len(self.priors)] = Gaussian(mu, Sigma + u * SIGMA_INFL)

    def safe_domain(self, z, u):
        base = self.base_domain()
        return base.shrink(u) if z == 'unknown' else base & self.priors[z].ci()
```

### IP-165 CGM（对话接地记忆与对账）

```python
class ConversationalGroundingMemory:
    def append(self, utterance, C_agreed, region, EV_exec):
        self.items.append(Grounding(
            emb=embed(utterance + region), C_agreed=C_agreed,
            C_exec=invert_from(EV_exec), region=region,
            conform=dist(C_agreed, invert_from(EV_exec)) <= EPS_CONF,
            t=now()))

    def resolve(self, ref, lam=0.95):
        return max(self.items, key=lambda g: sim(embed(ref), g.emb)
                   * lam ** (now() - g.t))

    def detect_drift(self, window=3):
        return sum(not g.conform for g in self.items[-window:]) >= window
```

### IP-168 DGSL（对话驱动场景落地闭环）

```python
def dialogue_grounded_scene_landing(M, utterance, scene_obs):
    C, clarify = M.mcsm.update(utterance, M.memory)
    if clarify is not None:                       # 歧义 → 先问，不执行
        return M, clarify, None
    z, b, u, unknown = M.ossr.observe(scene_obs)
    if unknown:                                   # 承认未知 → 探针 → 登记
        probe = M.run_probe()
        M.ossr.register_novel(probe, u)
    K_safe = M.ossr.safe_domain(z, u)
    if not feasible(C, K_safe, M.budget.exec):
        C, status = M.negotiator.negotiate(C, K_safe, M.budget.exec)
    K = M.eeis.compile(C, K_safe)
    EV = M.execute(K)
    M.epir.append(EV)
    M.memory.append(utterance, C, M.region, EV)
    if M.memory.detect_drift():
        M.mcsm.pending.append('DRIFT_RENEGOTIATE')
    drc = issue_deployment_readiness(M.records)
    return M, None, (C, EV, drc)
```

### IP-166 DRC（落地就绪证书）

```python
def issue_deployment_readiness(records, alpha=0.05):
    n = len(records)
    lb = lambda s: clopper_pearson_lo(s, n, alpha)
    cov, conf = lb(sum(r.covered for r in records)), lb(sum(r.conform for r in records))
    chain = lb(sum(r.chain_ok for r in records))
    return DeploymentReadiness(
        cov=cov, conf=conf, chain=chain,
        nov=mean(r.is_novel for r in records),
        neg=mean(r.negotiated for r in records),
        valid=(cov >= THETA_COV and conf >= THETA_CONF and chain >= THETA_CHAIN))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性 |
|---|---|---|---|
| MCSM | O(\|patch\|)/轮 | O(T·d) | `C_t ⊆ S_hard` 恒成立 |
| RA | O(\|M_g\|·d) | O(W_mem·d) | 歧义超阈强制澄清 |
| CNP | O(N_neg·S_sample) | O(1) | `<N_neg` 收敛或安全回退 |
| OSSR | O(K) | O(K+N_probe) | `u↑ ⇒ Feas↓` 单调保守 |
| DRC | O(n) | O(1) | Clopper–Pearson 下界 |

**正确性定理（DGSL）**：若 A66–A70 成立（固定安全地板；相对调整紧致；`U_O` 连续、`ρ` 单调、`Feas` 非空紧致；证据头校准 `b+u=1`；对账容差覆盖噪声），则：
1. 对话安全：任意轮数/覆盖顺序，`C_t ⊆ S_hard`；人无法靠对话突破安全地板。
2. 谈判终止：`Feas≠∅` 时 `N_neg` 轮内达成，否则返回安全 `C_cons`，且反提议恒 `⊆ S_hard`。
3. 开放集安全：`unknown`/高 `u` 只缩小可行域，`K_safe^unk` 覆盖真实可行域概率 ≥ `1−α`。
4. 证书可审计：`DRC` 分量均为置信下界，签发条件给出统计保证。

## 6. 本轮最大风险

**一句话**：若开放集把长尾场景误登记为已知、或接地记忆把「像上次那样」锚定到错误的历史回合，机器人会**自信地执行一份在错误语境下"谈定"的约束**——对话共识并不等于物理安全，必须让 `S_hard` 安全地板、`unknown` 保守膨胀、说做对账漂移告警三者**独立于对话**地兜底。
