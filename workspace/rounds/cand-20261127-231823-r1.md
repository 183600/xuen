## 1. 直觉与动机（两个灵感的碰撞）

**灵感 1（阻抗控制 → 机器人没有力传感器，但它的跟踪误差就是力传感器）**
直觉：位置/阻抗控制的机器人顶住物体时，实际位姿会落后于指令位姿；在准静态下，外部接触力近似正比于这个残差（F ≈ K·Δx）。比赛接口恰好同时给了「我们下发的目标」（action）和「机器人实测位姿」（下一次 observation）——于是**控制器的跟踪误差泄漏了接触力**。我们改不了评测端低层控制器的刚度 K（那是黑箱），但可以改**参考轨迹**：自由段高刚度精确跟踪，接触段沿估计的接触法向低刚度退让，切向仍保持跟踪——这就是「参考整形导纳」：不能换弹簧，但可以移动弹簧的锚点。夹爪还有独立通道：指令闭合而实测开口停滞，|gripper_action − gripper_state| 即夹持接触/滑移信号。核心反直觉点：**在没有力传感器的比赛里，力控的正确入口不是加传感器，而是利用位置控制器的误差。**

**灵感 2（微调 → 阻抗不是外挂模块，而是可以从示教里学出来的标签）**
直觉：示教数据里同时有目标 action 与实测 state（F21/F22），所以每个时间步都能免费算出「残差—速度—曲率—夹爪残差」特征，进而得到一条**示教阻抗曲线**：人在接触前减速、接触时退让、需要插入时反而加力顶住。把这条曲线作为辅助监督去微调 action expert（F11：frozen-VLM + LoRA，单卡 24GB），策略学到的就不只是「去哪」，还有「在哪该让、在哪该顶」。微调的真实风险是遗忘：接触段重加权会把自由空间能力磨掉，所以必须配 replay + 对基座的蒸馏正则。核心反直觉点：**阻抗控制不只是推理期的滤波器，它首先是一个可以从示教中自监督出来的训练目标；而「柔顺」不等于「一直软」——示教里该硬的地方必须学硬。**

**统一（一个闭环）**：I10 用隐式力估计在推理期做各向异性导纳；I11 用同一批残差标签离线微调出「预测性柔顺头」。I10 给 I11 供标签，I11 让 I10 从「事后反应」变「事前预判」。数据飞轮：示教 → 隐式力/柔顺标签 → 阻抗感知微调 → 预测性导纳 → 执行产生新残差 → 校准 K̂。两者都不加传感器、不改单模型、不碰在线学习。

## 3. 研究问题（Q9–Q11，Q1–Q8 保留）

- **Q9（隐式力可辨识性）**：action−state 残差在 joint / ee 两种 control_space 下，哪一种更接近真实接触力？在含积分或高刚度控制器下残差是否仍单调？gripper 残差能否独立检测夹持/滑移？标定实验的最小协议是什么？
- **Q10（阻抗标签的可迁移性）**：从示教提取的柔顺曲线能否跨任务/跨物体迁移？预测头能否在残差出现前从视觉预判接触（提前 1–3 步）？「该硬」的接触能否被正确学回？

## 0. 创新点清单（每点：动机 / 与现有方案差异 / 技术可行性 / 所需资源 / 落地步骤 / 风险）

### I10 无传感器隐式力觉 + 各向异性导纳护盾（新） ★★★★★

- **动机**：P4 无触觉；6–8 个接触类任务（PlugCharger、PlugInEthernet、DisconnectEthernet、ZipUp、Unlock、PourOutMedicine、SyringeWaterTransfer、StackBowls/StoreCups）的失败多发生在「顶太硬 / 没顶住 / 夹滑」。现有 I3 只做视觉几何伺服，无法感知接触力的大小与方向。
- **核心定义（隐式力）**：设 t 步下发目标为 a_t（ee 位姿或关节角），实测为 s_t。低层控制器近似为 PD/阻抗律 `τ = K(a−s) + D(ȧ−ṡ) + τ_ext`；准静态接触时 `τ_ext ≈ −K r_t`，故**外部力代理** `F̂_t = K̂ r_t`（ee 空间取平移 + 旋转 log 残差；关节空间取逐关节残差）。K̂ 不可直接观测，用单任务通道标定：已知载荷/弹簧/电子秤下拟合 `F = K̂ r`；未标定前只用归一化残差做相对门控，不做绝对力断言。夹爪另设 `g_t = gripper_action − gripper_state`，`|g_t|` 大且持续 → 夹持接触/滑移。
- **导纳护盾（参考整形）**：策略给出期望轨迹 `x_pol,t`；我们不直接下发，而是解一阶导纳：
  `x_ref,t = x_ref,t−1 + α(s_t)(x_pol,t − x_ref,t−1) + β(s_t) · Π_n̂ F̂_t / k_soft`
  其中 `s_t∈[0,1]` 为 I11 预测的柔顺度；`n̂_t = F̂_t/||F̂_t||` 为接触法向；`Π_n̂ = n̂n̂ᵀ` 只沿法向退让，切向保持高刚度。`α(s)` 随 s 减小（柔顺时慢跟踪），`β(s)` 为退让增益；对 `||x_ref,t−x_ref,t−1||`、`||x_ref,t−x_obs,t||` 设安全上限。自由段 s≈0 → `x_ref≈x_pol`（精确跟踪）；接触段 s≈1 → 法向低刚度、切向高刚度（各向异性）。
- **与现有方案差异**：I3 用视觉关键点做几何伺服，无力量级；直接 SFT 队伍没有接触反馈；纯柔顺（一直软）会牺牲插入所需的顶力。本点用**控制器误差**做力代理，并只在该让的方向让（PR6）。
- **技术可行性**：中-高。推理开销 <1ms（逐帧残差 + 3×3 投影 + 限幅）；无需新传感器；`ee` 模式直接得笛卡尔残差；`joint` 模式得逐关节力矩代理但需 Jacobian 映射（作为消融）。
- **所需资源**：无额外 GPU；标定 1–2 小时单任务通道；工程 1 人周。
- **落地步骤**：①在 3 个接触任务上采集「已知载荷—残差」标定点，拟合 K̂ 与单调性；②实现残差/夹爪残差估计器；③实现各向异性导纳 + 安全包络（离线回放验证不越界）；④与 I3 仲裁：视觉接近段用 I3，接触段用力觉导纳；⑤单任务通道 A/B（接触成功率、超力/卡死次数、节拍）。
- **风险**：低层控制器含积分 → 稳态残差趋零，力估计失效（缓解：用残差导数 + 速度失配，标定 R²<0.5 即降级）；K̂ 随位形/负载漂移（缓解：分任务/分位形标定，只做相对门控）；该硬的接触被误判为「该让」（缓解：柔顺度由示教标签学习，不是「接触=软」；加最小顶力约束）；模块化边界需书面确认（**I10' 降级**：导纳仅训练期辅助，推理纯端到端）。

### I11 阻抗感知微调：IfD 标签 + 接触课程 + 抗遗忘（新） ★★★★★

- **动机**：F11 官方支持 frozen-VLM/LoRA 单卡微调；但默认 SFT 把接触段与自由段一视同仁，策略学不到「何时该让/该顶」（P9/P10）。
- **示教阻抗提取（Impedance from Demonstration, IfD）**：对每条示教逐帧计算特征 `φ_t = [||r_t||, ||v_t||, ||a_t||, κ_t, |g_t|]`（残差、速度、加速度、曲率、夹爪残差），用变化点/两状态 HMM 或轻量分类器得到伪标签：接触概率 `p_t`、柔顺度 `s_t`、以及「该硬」概率 `h_t`（高残差 + 低速度 + 目标持续推进）。**关键**：标签不是「接触=柔顺」，而是示教实际表现的阻抗策略；若 action 语义为 next-state（残差≈0），退化为纯运动学标签（速度/曲率/夹爪），仍可用。
- **微调目标**：在 flow-matching 损失上加四项：
  `L = L_flow + λ_f·L_force + λ_s·L_compliance + λ_c·mean(s_t·L_flow,t) + λ_r·L_replay`
  - `L_force/L_compliance`：动作专家隐状态接小 MLP，回归 `f_t=||r_t||` 与 `s_t/h_t`（辅助头；推理时输出导纳门控）；
  - 接触重加权：`s_t` 高的帧 flow loss 加权（课程式从 1.0 渐增到 1+λ）；
  - `L_replay`：在 32 任务标称 replay 上对冻结基座做动作蒸馏/KL，防遗忘；
  - 仅 LoRA（action expert + DiT，rank 16–32），VLM 冻结（F11）。
- **与现有方案差异**：普通 LoRA SFT 只拟合动作；本点用免费隐式力标签做多任务/课程微调，产出「预测性柔顺头」，让 I10 从反应式变预判式；并用 replay 蒸馏显式管理接触增益 vs 自由空间遗忘。
- **技术可行性**：中-高。标签纯离线；辅助头 <1M 参数；单卡 24GB LoRA 可跑；预测头推理 <1ms。
- **所需资源**：1×24GB GPU；标签计算 1 GPU 日（110 语料可选）；微调 1–2 GPU 日/轮；1 人周工程。
- **落地步骤**：①标签提取 + 可视化抽检（接触段是否落在减速/高残差区）；②3 个接触任务试点；③辅助头 + 接触课程 LoRA；④L0：接触预测 AUC、柔顺度误差、自由空间 Δprog；⑤单任务通道 A/B：接触成功率 vs 自由空间遗忘。
- **风险**：标签语义失效（action=next-state）→ 退化为运动学标签；接触重加权过拟合 → replay + 早停 + 低 rank；预测头看不到接触（遮挡/腕相机）→ 多视角 + 残差后验融合；LoRA 容量不足 → 两阶段（先通才后阻抗）或只对 DiT 加 rank。

```python
def implicit_force(prev_action, obs, K_hat, D_hat, prev_r, dt):
    # ee 模式：prev_action 为我们上一步下发的 ee 目标
    x_cmd = prev_action["ee_pose"]              # (6,) xyz + rpy
    x_obs = obs["observation.state.ee_pose"]    # (6,)
    r = x_cmd - x_obs
    r_dot = (r - prev_r) / dt
    F_hat = K_hat * r[:3] + D_hat * r_dot[:3]   # 平移力代理
    n_hat = F_hat / (np.linalg.norm(F_hat) + 1e-6)
    g = prev_action["gripper"] - obs["gripper"] # 夹持接触/滑移通道
    return F_hat, n_hat, g, r

def admittance_guard(x_pol, x_ref_prev, F_hat, n_hat, s, dt, cfg):
    Pi_n = np.outer(n_hat, n_hat)
    alpha = 1.0 / (1.0 + cfg.tau(s) / dt)       # s↑ -> 慢跟踪
    dx = alpha * (x_pol[:3] - x_ref_prev[:3])
    dx += cfg.beta(s) * (Pi_n @ F_hat) / cfg.k_soft   # 仅法向退让
    dx = clip_norm(dx, cfg.v_max(s) * dt)       # 速度/步长安全包络
    x_ref = x_ref_prev.copy()
    x_ref[:3] += dx
    x_ref[3:] = slerp_toward(x_ref_prev[3:], x_pol[3:], alpha)
    return clamp_workspace(x_ref, cfg)
```

### 1.2 示教阻抗标签（I11）

```python
def impedance_labels(ep, dt):
    r   = ep.action - ep.state                  # (T,D) 目标 - 实测
    v   = finite_diff(ep.state, dt)
    acc = finite_diff(v, dt)
    kappa = curvature(ep.state)
    g   = ep.action_gripper - ep.state_gripper
    phi = stack([norm(r), norm(v), norm(acc), kappa, abs(g)])
    contact = hmm_two_state(phi)                # 软 p_t
    s = sigmoid(w1 @ normalize(phi))            # 柔顺度
    h = sigmoid(w2 @ normalize(phi))            # 「该硬」概率
    return contact, s, h                        # 若 action=next-state：r≈0，退化到 v/acc/g
```
