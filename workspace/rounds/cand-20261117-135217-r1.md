# 第 12 轮（新灵感循环第 3 轮；本轮灵感：「Gazebo」×「流匹配策略」）
> **基线**：第 11 轮 MetricVoiceGauge-NCD-H（定义 554–561；引理 96–103；实验 E589–E606）。
> 本轮纪律：**双引擎取证 + 少步生成式候选 + 证书投影 + 软件在环回归**。不推倒 v11：HAS/HCC/HATD/HDT 与 NGE/DSL/CC/CWM/CAE/NCP、九不变式全部保留；四个新组件一律以**中立元**接入，失效即严格退回 v11（引理 102 升级版），再沿 v11 十三级链退回 v10/v9/v8/v7/v6。本轮只做三件事：把"枚举候选"换成"少步流匹配生成"、把"终端过滤"升级为"沿生成轨迹的证书投影"、让 v11 引理 100 里那个未测量的 ε_struct 第一次可以被第二个独立仿真器**测量**。

## 0. 直觉与动机

### 灵感 1（流匹配策略 → 少步生成可行技能段）

直觉：v11 的 NCP/HATD 在 5Hz 规划时是"采样 32 条候选 → 逐条证书过滤 → 选一条"。这像在草垛里捞针：多模态接触（抓/推/滑）容易被单峰采样器平均掉；长尾场景下 32 条可能一条都不过证书；每次规划都要付 32 次 rollout 的钱。流匹配（Flow Matching，Lipman et al. 2022；Rectified Flow，Liu et al. 2022）换了一个问题：不学"动作的概率密度"，而学一条从噪声到数据的**速度场** v_θ(x,t)，用 1–4 步 ODE 积分就能把先验样本推到目标分布；训练是 simulation-free 的条件回归，不需要扩散那种几十步去噪。把它条件在 c=(任务图 g, 谐波状态 ζ_h, 证书上下文 β) 上，就能直接生成多模态、且"像数据"的技能段。核心创新：**流匹配技能策略（FlowMatchingSkillPolicy, FMSP）**——把候选段生成重写成条件 rectified flow 的少步积分，NFE∈{1,2,4}。直觉：不是"学会在候选堆里挑"，而是"学会一支箭从噪声射向可行动作"。

### 灵感 2（Gazebo → 独立见证器与软件在环试验场）

直觉：v11 只有一个 Isaac Sim 孪生 HDT，引理 100 的 ε_struct 是"写在公式里但没有测量方法的常数"；风险章节也承认柔轮变形场、齿隙、润滑脂流变学难以完美仿真。Gazebo 是开源、ROS 2 原生、插件化、可确定性重放的物理仿真器，其接触/摩擦求解器与 Isaac 不同源。它不该被当成"另一个 Isaac"来堆算力，而应当被当成**独立见证器**：同一条动作、同一初始状态，在两套引擎里成对 rollout，分歧 δ_gz 是结构误差的可观测量；在"轨迹度量满足三角不等式 + Gazebo 已用实机数据标定到误差 ε_G + 部署输入被搜索分布覆盖"三个前提下，有 ε_struct ≤ δ_gz + ε_G。Gazebo 还能把整套 NGE/CWM/HATD/HCC/FMSP 作为 ROS 2 节点跑在软件在环（SIL）里，做确定性重放与故障注入，把纸面的"退化链"变成可回归的测试。核心创新：**跨引擎分歧估计器（GazeboCrossSimDiscrepancy, GCSD）** 与 **SIL 重放/故障注入试验场（SILReplayHarness, SRFI）**。

### 灵感 3（两者相乘：沿生成轨迹的证书投影）

直觉：流匹配保证"像数据"，不保证"一定安全"。只在终端做拒绝采样，会遇到"生成得漂亮但全被四重证书拒绝"的悬崖；把证书硬塞进训练损失，又可能把流拉扁、丢掉多模态。核心创新：**证书投影流（CertifiedFlowProjection, CFP）**——在 ODE 每一步用证书裕度函数 h(x;c) 的梯度做切线锥投影（CBF 式），使 h 沿轨迹按指数下界衰减；终端再做有限步修复/精确拒绝，且**终端验收必须过真实 HCC/CC，不信可微代理**。训练侧加"屏障正则化"，让速度场本身贴近可行流形，投影只做安全网而不做拐杖。直觉：不是给箭绑绳子，而是把护栏修在箭的必经之路上。

### 三者如何统一

把 v12 的规划写成**双引擎取证下的少步生成式合规分解**：FMSP 在 (g,ζ_h) 条件下用 2 步流生成候选段；CFP 沿积分轨迹投影并终端修复，保证每个候选落在四重证书交集内；GCSD 用 Gazebo 成对 rollout 给出 δ_gz，自适应校准证书余量 β，并在 δ_gz 突增时触发重新分解；SRFI 在 Gazebo 里以确定性重放注入故障，验证每个退化级别确实落到 v11 的对应契约。四者共享条件 c=(g,ζ_h,β,ε_G)：**流回答"候选从哪来"，投影回答"候选怎么一定安全"，Gazebo 回答"我们凭什么相信模型"，SIL 回答"坏了会不会按契约退化"**。

## 1. 从直觉到严谨定义（本轮最小骨架）

**定义 A（流匹配技能策略 FMSP）** 设技能段空间 Ξ=ℝ^{H×d}×ℳ，条件 c=(g,ζ_h,e,β)。取 OT 条件路径 ξ_t=(1−t)ξ_0+tξ_1，ξ_0∼N(0,I)，ξ_1∼q(·|c)，目标速度 u_t=ξ_1−ξ_0。训练
```
L_FM(θ)=E‖v_θ(ξ_t,t|c)−(ξ_1−ξ_0)‖²
        + λ_m·L_CE(模式头) + λ_b·E[(max(0,−(∇h·v_θ+αh)))²]
```
采样为 NFE 步 Euler：ξ_{k+1}=ξ_k+(1/NFE)·v_θ(ξ_k,k/NFE|c)，默认 NFE=2、上界 4。FMSP 只提议候选，不判定安全。

**定义 B（证书裕度屏障与投影流 CFP）** 令 m_j 为四重证书的归一化裕度，h(ξ;c)=min_j m_j，S_c={h≥0}。投影算子
```
Π(v)=v,                                  若 ∇h·v+αh≥0，
     v−((∇h·v+αh)/‖∇h‖²)∇h,            否则。
```
沿 ξ̇=Π(v_θ) 积分，每步后做有限步梯度修复；终端仅当 h(ξ_1)≥ε_cert **且真实 HCC/CC/物理/规范证书全过**时接受，否则拒绝；连续拒绝超 R 次回退 v11 NCP。可得连续时间 h(ξ(t))≥h(ξ_0)e^{−αt}，离散时间差 O(Δ)。

**定义 C（Gazebo 跨引擎分歧 GCSD）** 对同一输入在同一时刻、同一种子下成对 rollout：
```
δ_gz(s,a)=d(M_I(s,a),M_G(s,a)),    δ̄_gz=E[δ_gz]，
a*∈argmax_{a∈A_cov}δ_gz(s,a)        （主动分歧搜索，CEM/贝叶斯优化）
ε_struct ≤ sup δ_gz + ε_G
β_disc=κ(Q_{1−q}(δ_gz)+ε_G),   β_total=β_id+β_disc+ε_cert
```
其中 ε_G 为 Gazebo 相对实机的标定误差上界。δ_gz 突增或 β_total 清空可行段 ⇒ 重分解 / a_ask。

**定义 D（SIL 重放与故障注入 SRFI）** Replay 用 Gazebo 固定步长 + 种子化传感器 + ROS 2 全栈记录/重放；故障目录 F 用覆盖阵列组合；对退化级别 ℓ 做 n_ℓ 次试验，失败 x_ℓ 次，Clopper–Pearson 上界 p_u(x_ℓ,n_ℓ,α)≤δ_SIL 时记 Ĉ_SIL,ℓ=true。它是统计证据，不是证明，且不得用于放宽 β。

**定义 E（v12 退化契约）** 四个中立元：FMSP⊥=v11 的 32 候选 NCP；CFP⊥=终端精确证书拒绝（超时回退 NCP）；GCSD⊥=δ_gz≡0、β=β_v11；SRFI⊥=Ĉ_SIL vacuous true。四端口互不相交，全失效 ⇒ 严格 v11，再沿 v11 十三级链退回 v10/v9/v8/v7/v6。v12 新增 L0–L4，其中 L3 是"安全保留但延迟上界变差"的唯一性能退化级。

## 2. 研究问题（轮次升级版）

- **Q1（少步生成的保真度）**：在接触模式多模态、任务图长尾的分布上，NFE∈{1,2,4} 的条件 rectified flow 能否覆盖 q(ξ|c) 的主要模态？少步离散化误差与任务成功率之间是否存在可证的折衷？reflow 在接触突变处会不会把多模态"拉直"成单峰？
- **Q2（投影的安全—最优性折衷）**：CFP 在连续/离散时间下能否严格保证 h≥0？投影带来的"可行但次优"端点畸变有多大有界？终端拒绝率的可接受上界、以及回退 v11 NCP 的触发条件怎么定，才能既不悬崖又不把安全网当拐杖？
- **Q3（跨引擎上界的有效性）**：当 Gazebo 与 Isaac 结构不同源、但可能共享同一套错误的谐波/接触假设时，δ_gz 在什么条件下才是 ε_struct 的有效上界？common-mode（相关）结构误差如何检测/证伪？主动分歧搜索能否把"未覆盖输入"变成"已测量输入"，其覆盖假设如何审计？
- **Q4（SIL 证据与 v11 兼容）**：SRFI 能否在有限样本下给出可审计的统计 SIL 证书？SIL 通过显然不等于实机安全，如何把它与 v11 的四重证书、v12 的十六级退化链拼成一张不矛盾的证据表？四个新组件的失效是否都落到 v11 的明确退化点？

## 3. 设计原则（在 P16–P18 基础上新增 P19–P21）

**P19 生成可证律（Generative Certifiability）**
任何生成候选必须携带证书才能进入 NCP 评分；生成器不能绕过证书。流的 NFE 预算固定（默认 2，最大 4），超预算或连续拒绝超限即回退 v11 的 32 候选采样。生成质量可以下降，证书门槛不许下降。

**P20 双引擎可观测律（Cross-Engine Observability）**
结构误差必须由至少两个结构不同源的模型测量；单引擎的高置信不是证据。GCSD 必须同时报告 δ_gz、ε_G 与输入覆盖假设；"两引擎一致"不能替代"与真实一致"。common-mode 风险必须显式标注为不可由 δ_gz 消去的残余项，禁止把它藏进固定余量。

**P21 退化可回归律（Degradation Regression）**
每个中立元与退化级别必须有确定性 SIL 测试；测试通过是证书的一部分，不是可选的 QA。若某级退化没有可复现测试，则该级不得对外声明"已契约化"。

## 4. 与基线的接口（如何退化）

- **FMSP 失效** ⇒ 回退 v11 NCP 的 32 候选采样 + 证书过滤，**等价 v11 规划路径**；
- **CFP 失效** ⇒ 保留流生成，但改为终端精确拒绝采样（超过 R 次回退 NCP）；安全不降、延迟上界变差，**等价 v11 安全语义**；
- **GCSD 失效** ⇒ δ_gz≡0、β 回退 v11 的固定余量，失去独立见证，**等价 v11 证据路径**；
- **SRFI 失效** ⇒ SIL 证书取 vacuous true，仅保留离线测试，**不改变在线行为**；
- 四者全失效 ⇒ MetricVoiceGauge-NCD-H v11，再沿 v11 十三级链退回 v10/v9/v8/v7/v6；
- **安全继承**：CFP 只能投影/删除候选，FMSP 只能生成候选，GCSD 只能放大余量/触发重分解，SRFI 只能增加测试；新模块不能绕过任何 v11 已适用的证书（引理 110）。CFP 的终端验收必须回到真实 HCC/CC，不能只信可微代理。

## 5. 预期贡献

1. **流匹配技能策略（FMSP）**：用条件 rectified flow 的 1–4 步积分替代 32 候选枚举，保留多模态、降低规划 rollout 成本，并给出 NFE—保真度的显式折衷；
2. **证书投影流（CFP）**：把"安全"从事后过滤变成沿生成轨迹的 CBF 式投影，给出连续时间不变性、离散时间误差界、终端拒绝率界与投影畸变界；提出"屏障正则化流匹配"让投影只做安全网；
3. **跨引擎分歧估计器（GCSD）**：首次把 v11 引理 100 的 ε_struct 从"未测量常数"变成可测量量 δ_gz+ε_G，并用主动分歧搜索与分位数余量把"模型不可信"转化为"可行域自适应"；
4. **SIL 重放与故障注入（SRFI）**：把 v12 的十六级退化链变成确定性可重放、覆盖阵列驱动、可统计认证的软件在环证据；
5. **E607–E626** 覆盖生成质量、投影安全、跨引擎上界、SIL 回归、消融、端到端与 WCET。

## 6. 本轮最大风险

**一句话**：当 Gazebo 与 Isaac 共享同一套错误的谐波/接触结构假设时，δ_gz 会很小，系统把"跨引擎一致"误当成"接近真实"，从而收窄 β、放大可行域，实机上却在共同未建模的柔轮屈服/微滑模式上失效——即**自信地跨引擎一致却共同错误**。

# 第 12 轮产物 · 创新点清单 v12：**MetricVoiceGauge-NCD-HF**（Metric Voice Gauge with Norm Grounding, Contact Dexterity, Causal Attribution, Harmonic Compliance & Flow-Matching Cross-Engine Grounding）

> 背景：第 11 轮 MetricVoiceGauge-NCD-H（定义 554–561；引理 96–103；实验 E589–E606），其基线为第 10 轮 MetricVoiceGauge-NCD。
> 本轮灵感：「Gazebo」×「流匹配策略」
> **继承纪律**：MetricVoiceGauge 九不变式全部保留；v11 的 HAS/HCC/HATD/HDT 与 v10 的 NGE/DSL/CC/CWM/CAE/NCP、v9 的 AC/MW/ID、v8 的 DA/SPR/Cal 原样保留。四个新组件均为**可选增强**：任一不可用 ⇒ 注入中立元，严格等价退回 v11（引理 111），再沿 v11 十三级链退回 v10/v9/v8/v7/v6。

### 0.1 退化链声明（v12 契约化十六级，L0–L15）

- **L0**：FMSP + CFP + GCSD + SRFI 全激活 → MetricVoiceGauge-NCD-HF；
- **L1**：SRFI 失效 ⇒ SIL 证书 vacuous true，仅离线测试；在线行为不变，**等价 v12 去 SIL 证据**；
- **L2**：GCSD 失效 ⇒ δ_gz≡0、β 回退 v11 固定余量；失去独立见证，**等价 v11 证据路径**；
- **L3**：CFP 失效 ⇒ 保留流生成，改终端精确拒绝采样（超 R 次回退 NCP）；安全语义不变、延迟上界变差；
- **L4**：FMSP 失效 ⇒ v11 NCP 32 候选采样 + HATD，**等价 v11 Level-0**；
- **L5**：HDT 失效 ⇒ v11 Level-1（CWM 定值谐波模型、HATD 启发式分解）；
- **L6**：HATD 失效 ⇒ v11 Level-2（v10 NCP 直接采样，HCC 在线拦截）；
- **L7**：HAS/HCC 失效 ⇒ v11 Level-3（谐波中立元，θ_flex≡0、k_h≡∞）；
- **L8**：CWM/CAE 失效 ⇒ v11 Level-4（v9 黑箱 F̂ + 相关消融）；
- **L9**：DSL/CC 失效 ⇒ v11 Level-5（v9 低维原语 + γ_grasp）；
- **L10**：NGE 失效 ⇒ v11 Level-6（allow-all 规范中立元）；
- **L11**：AC 失效 ⇒ v11 Level-7（K_eff←1，逐步执行）；
- **L12**：MW 失效 ⇒ v11 Level-8（v8 手写网关）；
- **L13**：ID 失效 ⇒ v11 Level-9（归因冻结）；
- **L14**：v8 的 DA/SPR/Cal 任一失效 ⇒ v11 Level-10（等价 v7）；
- **L15**：全失效 ⇒ 完整退回 v7，再退回 v6。

L0–L4 作用于**互不相交的端口**（候选生成端口、证书投影端口、跨引擎取证端口、SIL 回归端口），其失效组合可交换至调度顺序；因此任意子集失效都落到 v11 的一个明确退化点，不存在"半失效"的灰色行为。L3 是唯一的"安全保留但性能退化"级别，明确标注为 v11 安全语义的超集实现。

## 1. 符号体系增量（定义 562–571）

| 符号 | 含义 |
|---|---|
| ξ ∈ ℝ^{H×d} × ℳ | 技能段表示：连续参数矩阵 + 接触模式序列 |
| c = (g, ζ_h, e, β) | 流条件：任务图、谐波状态、环境估计、证书余量上下文 |
| q(ξ\|c) | 通过 v11 四重证书的可行段数据分布 |
| ξ_t, u_t | 概率路径与目标速度场；OT 路径 ξ_t=(1−t)ξ_0+tξ_1，u_t=ξ_1−ξ_0 |
| v_θ(ξ,t\|c) | FMSP 学到的连续速度场 |
| NFE | 生成时的函数求值步数（默认 2，上界 4） |
| h(ξ;c) | 证书裕度屏障：四重证书归一化裕度的最小值（实现用 smooth-min） |
| S_c = {ξ : h(ξ;c) ≥ 0} | 四重证书可行集 |
| Π(v) | 切线锥证书投影算子（CBF-QP 形式） |
| α, g | 屏障衰减率与边界梯度下界 |
| ε_cert | 可微证书代理的标定误差上界 |
| δ_gz(s,a) | Gazebo 与 Isaac 在同一输入上的轨迹分歧 |
| ε_G | Gazebo 孪生相对实机的标定误差上界 |
| ε_struct | Isaac HDT 相对实机的结构误差上界 |
| β_disc, β_total | 分歧感知余量、总证书余量 |
| F, Ĉ_SIL,ℓ | 故障目录、退化级别 ℓ 的统计 SIL 证书 |
| ζ_f = (ξ,t,v_θ,c) | 流状态（生成期使用，不进入 v11 的 ζ_h） |

**定义 562（流匹配技能策略 Flow-Matching Skill Policy）** 设技能段空间 Ξ=ℝ^{H×d}×ℳ，条件空间 𝒞。对连续分量取 OT 条件路径
```
ξ_t = (1−t)ξ_0 + tξ_1,   ξ_0∼N(0,I),  ξ_1∼q(·|c),  t∼U[0,1],
u_t(ξ_t|ξ_1) = ξ_1 − ξ_0.
```
训练目标
```
L_FM(θ) = E‖v_θ(ξ_t,t|c) − (ξ_1−ξ_0)‖²
        + λ_m L_CE(p_θ^m(m|ξ_t,t,c), m_1)                 (离散模式头)
        + λ_b E[(max(0, −(∇_ξ h·v_θ + α h)))²]            (屏障正则项)
```
采样用 NFE 步显式 Euler：
```
ξ_{k+1} = ξ_k + (1/NFE)·v_θ(ξ_k, k/NFE | c),   ξ_0∼N(0,I).
```
可用 reflow 以生成对 (ξ_0,ξ_1^gen) 拉直路径以降 NFE。离散模式由 CTMC 流或温度 softmax 生成，解码时按证书掩码屏蔽不可行模式。**FMSP 只负责提议候选，不负责判定安全。**

**定义 563（证书裕度屏障）** 对候选 ξ，记四重证书值 Ĉ(ξ;c)=(Ĉ_h,Ĉ_contact,Ĉ_safety,Ĉ_norm)，各分量归一化裕度
```
m_j(ξ;c) = (limit_j − value_j(ξ;c)) / scale_j,   j∈{θ,τ,θ̇,E,f,s,n,…}
h(ξ;c) = min_j m_j(ξ;c)            （实现用 smooth-min h_τ）
S_c = {ξ : h(ξ;c) ≥ 0}.
```
h 的梯度由可微证书代理 Ĉ_φ（定义 571）给出；代理标定误差 ε_cert 计入 m_j 的余量。**CFP 只用 h 做投影；终端验收必须回到真实 HCC/CC。**

**定义 564（证书投影流 Certified Flow Projection）** 给定 v=v_θ(ξ,t|c) 与 h=h(ξ;c)，定义投影速度场
```
Π(v) = v,                                   若 ∇h·v + α·h ≥ 0,
       v − ((∇h·v + α·h)/‖∇h‖²)·∇h,        否则。
```
生成 ODE 为 ξ̇=Π(v_θ)，离散实现：
```
ξ_{k+1} = ξ_k + Δ·Π(v_θ(ξ_k, t_k|c)),   Δ=1/NFE
if h(ξ_{k+1}) < 0:  ξ_{k+1} ← ξ_{k+1} + η∇h     （最多 r 步修复）
if 仍 h < 0:        拒绝并重采样；重采样 > R 次 ⇒ 回退 v11 NCP
```
终端：仅当 h(ξ_1)≥ε_cert **且**真实 HCC/CC/物理/规范证书全部通过时接受；否则拒绝。连续/离散安全性与终端拒绝界见引理 105–107。

**定义 565（Gazebo 跨引擎分歧 Cross-Sim Discrepancy）** 设 M_I 为 v11 的 Isaac HDT，M_G 为 Gazebo 孪生（同输入接口；接触/摩擦/谐波结构不同源）。对成对输入 (s,a,θ_h) 在同一时刻、同一种子下 rollout，取轨迹度量 d：
```
δ_gz(s,a) = d(M_I(s,a), M_G(s,a)),     δ̄_gz = E[δ_gz]
a* ∈ argmax_{a∈A_cov} δ_gz(s,a)        （CEM/贝叶斯优化；A_cov 为覆盖约束输入集）
```
结构误差上界（引理 108）：ε_struct = sup‖M_I−R‖_d ≤ sup δ_gz + ε_G，其中 ε_G=sup‖M_G−R‖_d 由 Gazebo 的实机标定残差给出。分歧感知余量：
```
β_disc  = κ·(Q_{1−q}(δ_gz) + ε_G)
β_total = β_id + β_disc + ε_cert
```
κ 为证书值对轨迹 sup-范数的 Lipschitz 常数，Q 取高分位覆盖长尾。若 δ_gz 滑动上升率超阈值，或 β_total 使可行段为空，触发 HATD 重分解 / a_ask。

**定义 566（SIL 重放与故障注入试验场）** SRFI=(Replay,F,Cert_SIL)：
- **Replay**：Gazebo 固定步长 + 种子化传感器 + ROS 2 全栈节点，记录 (s_t,a_t,seed) 并可确定性重放；
- **F**：故障目录 {传感器丢帧、时间戳抖动、执行器饱和、k_h 漂移、摩擦突变、丢包、时钟偏斜、接触异常}；用覆盖阵列构造 F×退化级别的组合测试；
- **Cert_SIL**：对每个退化级别 ℓ，n_ℓ 次试验记录契约失败数 x_ℓ（契约 = "落到 v11 对应中立元" 或 "安全中止"）；Clopper–Pearson 上界 p_u(x_ℓ,n_ℓ,α)≤δ_SIL 时记 Ĉ_SIL,ℓ=true。
SIL 证书是**统计证据**，不是证明；必须与四重证书分开记账，且不得用于放宽 β。

# IP-367 FlowMatchingSkillPolicy
class FlowMatchingSkillPolicy:
    def __init__(self, v_theta, mode_head, decoder, nfe=2, nfe_max=4):
        self.v = v_theta                    # v(ξ,t|c) -> ℝ^{H×d}
        self.mode_head = mode_head          # 离散模式 CTMC/温度头
        self.decoder = decoder
        self.nfe, self.nfe_max = nfe, nfe_max

    def integrate(self, xi0, cond, nfe=None):
        nfe = min(nfe or self.nfe, self.nfe_max)
        xi, dt = xi0, 1.0 / nfe
        for k in range(nfe):
            xi = xi + dt * self.v(xi, k * dt, cond)
        modes = self.mode_head.decode(self.decoder(xi), cond)
        return self.decoder.assemble(xi, modes)   # ξ = (continuous, mode_seq)

    def train_step(self, q_batch, cond, barrier_grad):
        # OT-CFM + 模式 CE + 屏障正则（定义 562）
        xi0, xi1 = sample_prior(q_batch.shape), q_batch
        t = uniform(0, 1, (len(q_batch), 1, 1))
        xi_t = (1 - t) * xi0 + t * xi1
        target = xi1 - xi0
        v = self.v(xi_t, t, cond)
        loss = mse(v, target)
        loss += self.mode_head.ce_loss(xi_t, t, cond, q_batch.modes)
        g = barrier_grad(xi_t, cond)            # ∇h
        viol = relu(-(g * v).sum() - ALPHA * barrier(xi_t, cond))
        loss += LAMBDA_B * (viol ** 2).mean()
        return loss


# IP-368 CertifiedFlowProjection
class CertifiedFlowProjection:
    def __init__(self, beta, alpha=1.0, repair_steps=3, max_retry=8):
        self.beta, self.alpha = beta, alpha
        self.r, self.R = repair_steps, max_retry

    def project_step(self, xi, v, cond):
        h, g = self.barrier_and_grad(xi, cond)
        dot = (g * v).sum()
        if dot + self.alpha * h >= 0:
            return v
        return v - ((dot + self.alpha * h) / (g * g).sum().clamp_min(1e-8)) * g

    def generate_from_xi(self, fmsp, xi, cond):
        # 单个流样本：投影积分 + 有限步修复 + 终端精确验收
        for k in range(fmsp.nfe):
            v = fmsp.v(xi, k / fmsp.nfe, cond)
            xi = xi + (1.0 / fmsp.nfe) * self.project_step(xi, v, cond)
            for _ in range(self.r):
                h, g = self.barrier_and_grad(xi, cond)
                if h >= 0: break
                xi = xi + ETA * g
        h, _ = self.barrier_and_grad(xi, cond)
        if h >= EPS_CERT:
            cand = fmsp.decode(xi, cond)
            if exact_certificates_pass(cand):          # 真实 HCC/CC/物理/规范
                return cand
        return None                                     # 外层重采样或回退 L4


# IP-369 GazeboCrossSimDiscrepancy
class GazeboCrossSimDiscrepancy:
    def __init__(self, isaac_hdt, gazebo_twin, metric, kappa, quantile=0.95):
        self.isaac, self.gz, self.d = isaac_hdt, gazebo_twin, metric
        self.kappa, self.q = kappa, quantile
        self.delta_window = deque(maxlen=64)

    def measure(self, state, action_batch):
        d = []
        for a in action_batch:
            y_i = self.isaac.rollout(state, a)
            y_g = self.gz.rollout_same_seed(state, a)
            d.append(self.d(y_i, y_g))
        self.delta_window.extend(d)
        return np.array(d)

    def active_search(self, state, n_iter=32):
        # CEM 在覆盖约束输入集上最大化 δ_gz（找"最不放心"的输入）
        dist = initialize_search_distribution(state)
        for _ in range(n_iter):
            a = dist.sample(64)
            score = self.measure(state, a)
            dist.update(a[np.argsort(score)[-8:]])
        return dist.mean()

    def adaptive_margin(self, beta_id, eps_G, eps_cert):
        q = np.quantile(self.delta_window, self.q) if self.delta_window else 0.0
        beta_disc = self.kappa * (q + eps_G)
        return beta_id + beta_disc + eps_cert, q + eps_G

    def uncertainty(self, delta_gz, eps_G):
        q = np.quantile(delta_gz, self.q) if len(delta_gz) else 0.0
        return self.kappa * (q + eps_G)

## 4. 推导

**引理 104（条件流匹配训练一致性）** 设 q(·|c) 绝对连续、v_θ 与 u_t 平方可积。则条件 CFM 目标
```
L_CFM(θ)=E_{t,ξ_0,ξ_1}‖v_θ(ξ_t,t|c)−(ξ_1−ξ_0)‖²
```
与以真实边缘速度场 u_t(ξ)=E[ξ_1−ξ_0|ξ_t=ξ] 定义的（不可解）FM 目标具有相同的 θ-梯度（相差与 θ 无关的常数）。证明：展开平方，对 ξ_1|ξ_t 取条件期望，交叉项化为 2⟨v_θ,u_t⟩−2‖v_θ‖² 的期望；两目标的差只含 E‖u_t‖²−E‖ξ_1−ξ_0‖²，与 θ 无关。∎（Lipman et al. 2022）

**引理 105（CFP 连续时间安全性）** 设 h∈C¹、h(ξ_0)>0、在边界层 {h≤η} 上 ‖∇h‖≥g>0、v_θ 有界、α>0。则沿 ξ̇=Π(v_θ) 有
```
h(ξ(t)) ≥ h(ξ_0)·e^{−αt} > 0,  ∀t∈[0,1].
```
证明：若 ∇h·v+αh≥0，则 Π(v)=v，故 ḣ=∇h·v≥−αh；否则 Π(v)=v−((∇h·v+αh)/‖∇h‖²)∇h，故 ḣ=∇h·v−(∇h·v+αh)=−αh。两种情形均有 ḣ≥−αh，由 Grönwall 得结论。∎

**引理 106（CFP 离散时间与终端安全）** 在引理 105 条件下再加 ∇h 为 L-Lipschitz、‖v_θ‖≤V。以步长 Δ=1/NFE 做显式 Euler，则存在 C=C(L,V,α,g) 使
```
h(ξ_k) ≥ h(ξ_0)e^{−αt_k} − CΔ.
```
若 Δ≤h(ξ_0)/(2C)，则所有中间点 h>0。终端仅接受 h(ξ_1)≥ε_cert 且真实证书通过者，故接受样本必满足真实四重证书。设终端拒绝概率为 η<1，则期望重采样次数 ≤1/(1−η)，最坏延迟 ≤(R+1)·NFE·τ_step；R 次仍失败则回退 v11 NCP，安全性由 v11 保证。证明：Euler 局部截断误差 O(Δ²)、Lipschitz 传播给出一致界；终端验收是精确判定，不依赖代理。∎

**引理 107（投影—最优性折衷）** 记无投影流终点为 ξ_1^u、投影流终点为 ξ_1^p，g=inf‖∇h‖>0。则
```
‖ξ_1^p − ξ_1^u‖ ≤ (1/g)·∫_0^1 [−(∇h·v_θ+αh)]_+ dt + O(Δ).
```
特别地，若无投影流全程满足 CBF 条件 ∇h·v_θ+αh≥0，则投影从不激活，畸变为 0。证明：投影仅在 [−(∇h·v+αh)]_+>0 时激活，此时速度修正范数为 [−(∇h·v+αh)]_+/‖∇h‖ ≤ [−(∇h·v+αh)]_+/g；对时间积分并用 Euler 误差项即得。∎

**引理 108（跨引擎结构误差上界）** 设 d 为满足三角不等式的轨迹伪度量，M_I、M_G、R 在相同输入与相同初始条件下比较。则
```
ε_struct = sup‖M_I−R‖_d ≤ sup δ_gz + ε_G,   ε_G = sup‖M_G−R‖_d.
```
若部署输入分布 D_real 不在主动搜索覆盖分布 D_search 的支撑内，则需加上分布偏移项 2·sup_{A}|P_{D_real}(A)−P_{D_search}(A)|（或相应的 Wasserstein 项）。证明：对每个输入，‖M_I−R‖≤‖M_I−M_G‖+‖M_G−R‖，取上确界即得；分布偏移由测度差的定义直接得到。∎

**引理 109（分歧感知余量可靠性）** 设证书标量 y（如 max θ_flex）对轨迹满足 |y(M_I)−y(R)|≤κ‖M_I−R‖_d。则
```
y(R) ≤ y(M_I) + κ(δ_gz+ε_G) ≤ ŷ + β_id + κ(δ_gz+ε_G)
```
当 β_disc≥κ(Q_{1−q}(δ_gz)+ε_G) 且使用分位数覆盖长尾时，HCC 在结构误差下仍保守有效。证明：Lipschitz 性 + 引理 108 + 估计误差 β_id 的三角分解。∎

**引理 110（v12 安全继承）** 记 E_v12 为 v12 接受的可执行段集合，E_v11(β_total) 为 v11 在余量 β_total 下的可执行集。则
```
E_v12 ⊆ E_v11(β_total).
```
CFP 只能投影或删除候选，FMSP 只能提议候选，GCSD 只能增大 β 或触发重分解，SRFI 只能增加测试；终端接受必须通过真实 v11 四重证书。由于 β_total≥β_v11，E_v11(β_total)⊆E_v11(β_v11)，故 v11 安全性继承。证明：逐模块检查其输出的集合包含关系；投影与拒绝都是交/子集操作，余量增大使可行集单调收缩。∎

**引理 111（中立元退化等价 v11）** 将定义 567 的四个中立元分别注入 FMSP/CFP/GCSD/SRFI 端口，则生成、投影、余量、SIL 行为逐位退化为 v11：FMSP⊥ 即 NCP 采样器；CFP⊥ 即 v11 的终端证书过滤（超时回退 NCP）；GCSD⊥ 使 β=β_v11；SRFI⊥ 不改变在线路径。四端口互不相交，逐端口代入即得 v11 程序；再由 v11 引理 102 继续退回 v10/v9/v8/v7/v6。∎

**引理 112（预算守恒 v12）** 新增在线成本上界：FMSP NFE=2、批量 8，GPU ≤0.6ms / CPU ≤0.8ms；CFP 投影+修复 ≤0.2ms；GCSD 异步 10Hz、摊销 ≤0.3ms；SRFI 离线/非实时窗口，在线 0ms。相对 v11 的 32 候选 NCP 采样，FMSP 批量生成节省 ≥0.5ms。总决策 p99 仍 ≤22ms，50Hz 保持。证明：逐项代入复杂度表并做静态 EDF 校验 ΣŴ_m≤B_dec；CWM 因候选数从 32 降至 8，评分成本同步下降。∎

**引理 113（SIL 统计证书）** 对退化级别 ℓ 做 n 次独立重放，失败 x 次，取 Clopper–Pearson 单侧上界 p_u(x,n,α)。若 p_u(x,n,α)≤δ_SIL，则以置信度 1−α 有契约失败概率 ≤δ_SIL。零失败时样本复杂度 n≥ln(1/α)/δ_SIL（近似）。证明：二项分布尾概率与 Clopper–Pearson 区间定义；零失败时 (1−δ)^n≥1−α 解出 n。∎（注：独立性依赖故障采样与种子管理，见风险 7。）

## 8. 已知风险与失效模式

1. **Common-mode 结构误差（首要风险）**：Gazebo 与 Isaac 若共享同一套错误的谐波/接触假设，δ_gz 会小，ε_G 又被低估，于是 β 收缩、可行域放大。缓解：至少一个模型用结构不同的接触/滞回模型；用实机残差直接标定 ε_G；在证据表里把"δ_gz 小"与"接近真实"分开陈述；保留 fixed 冗余余量作为下限。
2. **流的多模态塌缩**：少步 reflow 可能把抓/推/滑多模态拉成单峰，长尾模式消失。缓解：NFE 自适应、模式头独立训练、条件注入、按模式分层评估 E607。
3. **投影导致"安全但无用"**：强投影把终点推离任务目标，终端拒绝率上升。缓解：屏障正则训练让流先接近可行、α 调度、投影畸变上界监控（E611）、必要时放宽非关键余量。
4. **可微证书代理误差**：Ĉ_φ 与真实 HCC 的偏差会让投影方向错。缓解：终端必须用真实证书验收；代理只用于梯度；ε_cert 计入 β；分区间校准。
5. **NFE 延迟在 GPU 争用下失控**：批量生成与 CWM/HDT 抢 GPU。缓解：NFE 上限、CPU 快路径、批量上限、离线缓存流先验、E626 背压测试。
6. **SIL 不等于现实**：Gazebo 的接触/摩擦/执行器模型仍是近似，SIL 通过不蕴含实机安全。缓解：SIL 证书只作回归证据；实机小样本校准 ε_G；把 SIL 与实机差异纳入 ε_struct。
7. **统计 SIL 证书的误置信**：非独立试验、故障目录不完整、多重比较、分布偏移都会让 p_u 偏乐观。缓解：种子/场景去相关、覆盖阵列设计、Bonferroni 校正、报告故障目录覆盖率与未覆盖域。

## 9. 本轮最大风险

**一句话**：当 Gazebo 与 Isaac 共享同一套错误的谐波/接触结构假设时，δ_gz 会很小，系统把"跨引擎一致"误当成"接近真实"，从而收窄 β、放大可行域，实机上却在共同未建模的柔轮屈服/微滑模式上失效——即**自信地跨引擎一致却共同错误**。
