# 第 61 轮（承接第 60 轮「场景感知闭环」IP-153~160；灵感循环第 7 轮；本轮灵感：「激光雷达」×「实时推理」）

> 第 60 轮的 SGEC 把「场景→意图→约束→阻抗→执行→EV-exec→场景更新」闭了起来：SSM 让场景变成阻抗先验、CIEC 让意图锁定约束、EPIR 让证据抵抗 ROS 丢包。但它仍是**「接触之后才认识场景」的闭环**：SSM 的场景后验主要来自力/位遥测，必须先碰一下才知道是桌面还是地毯；CIEC 的 τ_response 只约束「意图→约束」，却没有任何机制保证「感知→约束」按时到达。于是三个新局限浮现：
> 1. **感知的时序鸿沟**：LiDAR 能在接触前给出几何，但点云推理是**可变时延**的（帧率、体素密度、模型宽度都影响延迟）。若推理在 `t_commit` 之后才完成，EEIS 编译所用的先验已经过期；第 60 轮完全没有「推理结果时间戳」这一概念。
> 2. **几何-阻抗的语义鸿沟**：LiDAR 只测几何与反射强度，不测柔性/摩擦/刚度。把粗糙度 `σ_h`、坡度 `θ_s`、强度 `Ī` 直接当作阻抗是**类别错误**；必须显式建模「几何描述子 → 阻抗先验分布」的映射，并保留其**不确定性与弃权能力**，否则就是把「看得见」误当成「摸得准」。
> 3. **证据的几何断链**：EPIR 只校验「序号-哈希-因果顺序」，不校验「执行的阻抗是否与当时看到的几何一致」。若 LiDAR 被遮挡/欺骗、或场景在扫描后被人改变，EV-exec 仍然「合规」，但合规的对象已经换了——证据链缺失**几何见证**。

## 0. 直觉与动机

**灵感 1（激光雷达 → 接触前的阻抗影子 LGIM）**
直觉：LiDAR 不是「测量刚度」，而是测量**接触将要发生的几何舞台**：接触点的法向决定力方向、局部曲率决定接触斑大小、粗糙度决定微观接触点数量、坡度决定切向负载、强度与纹理谱是材料的弱代理。关键洞见：把点云局部 patch 变成几何描述子 `g`，再经**几何→阻抗映射** `T_geo` 得到阻抗先验分布 `π_geo(K|g)`；它只提供**先验**，接触力遥测仍作为似然做后验修正——第 60 轮 SSM 从「后验的唯一来源」降级为「后验的一个证据源」，LiDAR 先验补上了接触前的那半段。

**灵感 2（实时推理 → 推理是一份「随时可终止的契约」ASI）**
直觉：传统调用把推理当作原子函数 `y = f(x)`；实时场景里它更像**会随时间变好的答案** `Q(t)`。可用渐进体素（粗→细）与模型宽度（窄→宽）组织成层级推理，质量随时间是**单调不降**的；给定截止期 `d` 与置信目标 `γ`，最优策略是阈值早退：当边际信息增益/单位时间低于成本，或下一层会越过截止期，就停。关键洞见：**推理必须在任何时刻都能被抢占并返回一个合法的、校准过的答案**，而不是「要么延迟、要么无解」。

**灵感 3（运动中的激光雷达 → 预见你将要触碰的地方 STLA×MDCA）**
直觉：机器人不是静止的；一帧 LiDAR 内的每个点是在不同时刻采到的，自车运动会让点云**运动畸变**（deskew）。更重要的是，我们关心的不是「现在在哪里」，而是 `Δ` 秒后**将要接触的那个点**。因而要沿自车/机械臂轨迹把未来接触点投影到本地几何地图，对那一小块 patch 做预见推理。关键洞见：**不确定性必须随预见时域增长**——`Σ_geo(Δ) = Σ_K(g) + Δ·Q_Δ`，预见越远越保守，且超过 `Δ_max` 就弃权。

**灵感 4（时延 → 陈旧度是物理量 PEC）**
直觉：一个 200ms 前的场景先验，在会移动、会被人改动的世界里，**严格等价于**一个方差更大的先验。这不是工程补丁，而是 Kalman 预测步：`Σ_eff = Σ_geo + Q_process·Δ_stale`。关键洞见：把「新鲜度」写进执行契约——执行提交屏障 `t_commit` 只接受 `t_commit - t_inf ≤ Δ_fresh` 的推理；否则要么等（若有时间余量），要么走保守分支，绝不允许「用过期先验 + 高置信度」提交。

**灵感 5（激光雷达作为见证 + 认知预算扩展 LGW×PCE+++++）**
直觉：把接触点局部几何 `(scan_hash, g_c, ICP_residual, t_scan)` 写进 EV-exec，形成**几何见证**；云端复算 `T_geo(g_c)` 并与实际执行的 `K_exec` 比对，就能发现「几何说不该这么硬、执行却这么硬」的异常——这既是遮挡/欺骗检测，也是「扫描后场景被改」的检测。同时第 60 轮的四维认知预算要再加三维修正：`B_geo`（扫描率/点数/patch 半径）、`B_infer`（推理算力/延迟分位/模型宽度）、`B_tempo`（新鲜度窗口/截止期余量）。

**灵感 6（合流 → GLIDE：几何-时延感知的推理驱动执行）**
直觉：把上述五点合为 **GLIDE（Geometry-Latency-aware Inference-Driven Execution）**：
`LiDAR 扫描 → 运动去畸变 → anytime 预见推理 → 陈旧度膨胀 → EEIS 编译 → 执行 → 几何见证 → 场景/预算更新`。
它把第 60 轮的「场景先验」从**接触后的事后归因**升级为**接触前的可弃权预测**；把「证据链」从「序号连续」升级为「序号连续 + 几何一致」。核心纪律：**预见只能在安全边界内收窄先验，永远不能覆盖接触遥测的否决权**。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（LiDAR-几何-阻抗映射 LGIM）** 给定接触点 `x_c` 邻域半径 `r` 的局部点云 patch `P_c`，几何描述子
`g = (n̂, κ, σ_h, θ_s, Ī, ρ, φ_occ)`
其中 `n̂` 为主法向，`κ` 为局部平均曲率，`σ_h` 为对拟合平面的残差标准差（粗糙度），`θ_s` 为坡角，`Ī` 为归一化反射强度，`ρ` 为点密度，`φ_occ` 为 patch 遮挡率。映射算子
`T_geo = (T_μ, T_Σ) : g ↦ (μ_K(g), Σ_K(g))`，
先验 `π_geo(K|g) = N(K; μ_K(g), Σ_K(g))`。

物理接地（避免「几何=刚度」的类别错误）：对半径 `R` 的球形末端，接触刚度近似 Hertz 关系 `K_c = 2E*a`，接触半径 `a = (3FR_eff/(4E*))^{1/3}`，`1/R_eff = 1/R + κ`。LiDAR 只能给出 `κ`（进而 `R_eff`）与材料类别弱代理 `(Ī, 纹理谱)`，无法直接观测有效模量 `E*`；因此 `T_μ` 输出的是**在标定分布下的条件期望** `E[K_c | g, F_nom]`，`T_Σ` 吸收 `E*` 的不可观测性。三条结构约束：
- **单调性**：`∂μ_K/∂Ī ≥ 0`（高反射/金属倾向更刚），`∂Σ_K/∂σ_h ≥ 0`，`∂Σ_K/∂φ_occ ≥ 0`，`∂Σ_K/∂ρ ≤ 0`。
- **共形校准**：在标定集 `D_cal = {(g_i, K_i^probe)}` 上用 split-conformal 得到区间 `CI_{1-α}(g)`，保证 `P(K_true ∈ CI_{1-α}(g)) ≥ 1-α`。
- **弃权**：若 `ρ < ρ_min` 或 `φ_occ > φ_max`，`T_geo` 返回 `⊥`，明确「无几何先验」，回退到第 60 轮 SSM 的反应式路径。

**定义 162（运动去畸变与接触斑对齐 MDCA）** 一帧扫描内每个点 `p_i` 的采样时刻为 `t_i ∈ [t_s, t_e]`，自车/臂体位姿轨迹为 `T_ego(t)`。去畸变
`p_i' = T_ego(t_ref)·T_ego(t_i)^{-1}·p_i`，`t_ref = t_e`。
接触斑对齐：`P_c = {p_i' : ||p_i' − x_c|| ≤ r}`。扫描有效性判定
`valid_scan = (ρ ≥ ρ_min) ∧ (φ_occ ≤ φ_max) ∧ (t_ref − t_s ≤ Δ_scan_max) ∧ (r_deskew ≤ ε_deskew)`，
其中 `r_deskew` 为去畸变残差。`valid_scan = false` 时 LGIM 必须弃权——**宁可不给先验，也不给错的先验**。

**定义 163（随时推理 ASI：Anytime Scene Inference）** 推理契约 `c_inf = (d_inf, γ_target, b_inf)`：截止期、置信目标、算子预算。层级 `l = 1..m`，体素尺寸 `v_l` 递减、模型宽度 `w_l` 递增。第 `l` 层产出后验 `π^(l)`、熵 `H^(l)`、耗时 `t_l`。Anytime 性质：
- **质量单调**：`H^(l+1) ≤ H^(l)`；
- **时间单调**：`t_1 < t_2 < … < t_m`；
- **可抢占**：任一时刻停止都返回合法后验。

早退规则
`l* = min{ l : H^(l) ≤ H_target  ∨  t_l + E[Δt_{l+1}] > d_inf }`。
输出 `(ẑ, γ̂ = 1 − H^(l*)/log N, t_inf, H^(l*), abstain)`。若 `l=1` 都赶不上 `d_inf`，返回 `abstain` 并置 `γ̂ = 1/N`（等价于均匀先验），禁止伪造置信度。

**定义 164（时空预见 STLA）** 当前时刻 `t`、规划给出的接触时刻 `t_c = t + Δ`、预期接触点轨迹 `x_c(t_c)`。预见推理
`z_{t_c} = argmax_z P(z | O_{t−k:t}, T_ego, x_c(t_c))`，
实现上把 `x_c(t_c)` 投影进本地几何地图、取 patch 后跑 `T_geo`。预见不确定度
`Σ_geo(Δ) = Σ_K(g) + Δ·Q_Δ + σ_model²(Δ)·I`，
`Q_Δ` 为场景变化率（人搬动物体/遮挡变化）的过程噪声上界，`σ_model²(Δ)` 为预测误差随预见时域的增长项。若 `Δ > Δ_max` 或 `valid_scan = false`，弃权。

**定义 165（感知-执行时间契约 PEC）** 推理完成时刻 `t_inf`、执行提交时刻 `t_commit`，陈旧度 `Δ_stale = t_commit − t_inf`（要求 `≥ 0`，否则该推理对本次提交无效）。**陈旧度膨胀**按 Kalman 预测步：
`Σ_eff = Σ_geo(Δ) + Q_stale·Δ_stale`，
`Q_stale` 为场景先验的漂移率对角阵。有效安全集
`K_safe^PEC = {K : (K − μ_K)^T Σ_eff^{-1} (K − μ_K) ≤ χ²_{1-α}} ∩ K_safe_base`。
**截止期可行度** `ρ_deadline = P(τ_infer ≤ Δ_available)`（由离线 profiler 的延迟分布得到）；若 `ρ_deadline < θ_d`，强制使用 `K_safe_base` 并置 `STALE`。**提交屏障**：仅当 `Δ_stale ≤ Δ_fresh` 时允许用几何先验收窄，否则只能等或保守执行。

**定义 166（激光雷达几何见证 LGW）** 扩展执行证据
`EV-exec' = EV-exec ∪ W_geo`，`W_geo = (t_scan, x_c, g_c, scan_hash, ICP_residual, T_ego_hash, Σ_eff)`。
云端复算一致性
`c_geo = exp( − ½ (K_exec − μ_K(g_c))^T Σ_eff^{-1} (K_exec − μ_K(g_c)) )`，
并校验 `ICP_residual ≤ ε_icp`、`scan_hash` 可复现。若 `c_geo < θ_geo` 或哈希/残差失配，标记 `GEOMETRIC_MISMATCH`：可能是遮挡、欺骗、或「扫描后场景被改」。于是 EPIR 的连续性从**溯源连续**升级为**溯源 + 几何双连续**。

**定义 167（GLIDE 闭环）** 算子 `GLIDE(M, intent, Δ, delta_f_req)`：
```
① LiDAR: O_t ← scan();  r_deskew ← MDCA.deskew(O_t, T_ego)
② STLA: x_c ← project(plan(t+Δ)); P_c ← patch(x_c, r); g ← descriptor(P_c)
③ LGIM: if valid_scan: π_geo ← T_geo(g) else π_geo ← ⊥
④ ASI:  (ẑ, γ̂, t_inf) ← anytime_infer(P_c, c_inf)
⑤ PEC:  Δ_stale ← t_commit − t_inf; Σ_eff ← inflate(Σ_geo, Δ_stale)
        K_safe^PEC ← compile(π_geo, Σ_eff, delta_f_req) if ρ_deadline ≥ θ_d else K_safe_base
⑥ CIEC: C_intent ← ϕ(intent); ERTC.lock_constraints(C_intent)   # 第 60 轮
⑦ Execute: telemetry ← wait_contact(); K_exec ← dispatched
⑧ LGW:  W_geo ← build_witness(O_t, g, K_exec, Σ_eff); EV-exec' ← EV-exec ∪ W_geo
⑨ EPIR: S_shadow.append(EV-exec'); S_sync.push()                 # 第 60 轮
⑩ XMC++/SSM: 更新场景-意图-执行信念（接触似然 veto 几何先验）
⑪ Return: (ẑ, γ̂, K_safe^PEC, EV-exec', W_geo, DGS.status)
```
纪律：`π_geo` 只可**收窄** `K_safe_base`，接触遥测的后验可**否决** `π_geo`；任一阶段弃权即回退第 60 轮 SERC。

**定义 168（DGS 三元组与 PCE+++++ 预算）** 前瞻派发必须同时满足
`DGS = (ρ_deadline ≥ θ_d, γ̂ ≥ γ_min, SIC_valid)`。
预算 `B_cog' = (B_geo, B_infer, B_tempo, B_scene, B_intent, B_ros, B_exec)`：
- `B_geo`：`(scan_rate, points_per_frame, patch_radius)`；
- `B_infer`：`(ops, latency_p99, model_width)`；
- `B_tempo`：`(freshness_window, deadline_slack)`；
- 其余复用第 60 轮 `B_scene/B_intent/B_ros/B_exec`。

降级映射：
- `B_geo` 耗尽 → 降低扫描率/缩小 patch，LGIM 弃权；
- `B_infer` 耗尽 → 固定 `l=1` 的粗推理，`γ̂` 下调；
- `B_tempo` 耗尽（`Δ_stale > Δ_fresh`）→ 禁用几何先验，回退反应式 SSM；
- `B_scene/B_intent/B_ros/B_exec` 耗尽 → 沿用第 60 轮策略。

```python
class LiDARGeometryImpedanceMapper:
    def __init__(self, r=0.05, rho_min=20, phi_max=0.6, alpha=0.1):
        self.r, self.rho_min, self.phi_max = r, rho_min, phi_max
        self.alpha = alpha
        self.calibrator = SplitConformal(alpha=alpha)  # 共形校准

    def descriptor(self, patch_pts):
        if len(patch_pts) == 0:
            return None
        n_hat, kappa, sigma_h = fit_local_surface(patch_pts)
        intensity = normalized_mean_intensity(patch_pts)
        rho = len(patch_pts) / (np.pi * self.r ** 2)
        phi_occ = occlusion_ratio(patch_pts, self.r)
        theta_s = slope_from_normal(n_hat)
        return dict(n=n_hat, kappa=kappa, sigma_h=sigma_h, I=intensity,
                    rho=rho, phi_occ=phi_occ, theta_s=theta_s)

    def map_to_prior(self, g, F_nom=5.0):
        if g is None or g['rho'] < self.rho_min or g['phi_occ'] > self.phi_max:
            return None  # 明确弃权，禁止返回伪先验
        R_eff = 1.0 / (1.0 / TIP_RADIUS + g['kappa'])
        mu_K = self._predict_mean(g, F_nom, R_eff)   # 标定分布条件期望
        Sigma_K = self._predict_cov(g)               # 含 E* 不可观测性
        lo, hi = self.calibrator.interval(g)          # 共形区间
        Sigma_K = np.maximum(Sigma_K, conformal_to_cov(lo, hi))
        return Distribution(mean=mu_K, cov=Sigma_K, abstain=False)


class MotionDeskewAlignment:
    def __init__(self, eps_deskew=1e-3, delta_scan_max=0.1):
        self.eps, self.dmax = eps_deskew, delta_scan_max

    def deskew(self, points, ego_traj, t_ref):
        out = []
        for p, t_i in points:
            T_rel = ego_traj.at(t_ref) @ inv(ego_traj.at(t_i))
            out.append(T_rel.apply(p))
        residual = reprojection_residual(out)
        return out, residual

    def valid(self, g, residual):
        return (g['rho'] >= self.rho_min and g['phi_occ'] <= self.phi_max
                and residual <= self.eps)
```

### IP-163 ASI（随时推理 + 截止期早退 + 校准）

```python
class AnytimeSceneInference:
    def __init__(self, levels, deadline, gamma_target):
        self.levels = levels  # [(voxel, width), ...] 粗 -> 细
        self.d_inf, self.gamma_target = deadline, gamma_target

    def infer(self, patch, t_start):
        best = None
        for l, (voxel, width) in enumerate(self.levels):
            t_now = time.time() - t_start
            est_next = self.profile[voxel]['p99']
            if best is not None and t_now + est_next > self.d_inf:
                break  # 下一层必超期 -> 就地早退
            posterior = scene_net(patch, voxel=voxel, width=width)
            entropy = -np.sum(posterior * np.log(posterior + 1e-9))
            best = (posterior, entropy, time.time() - t_start)
            if entropy <= self.entropy_target:
                break
        if best is None:
            return Abstain(reason='deadline_at_level0', t_inf=time.time() - t_start)
        posterior, entropy, t_inf = best
        z_hat = int(np.argmax(posterior))
        gamma = 1.0 - entropy / np.log(len(posterior))
        return Result(z=z_hat, gamma=gamma, t_inf=t_inf,
                      entropy=entropy, abstain=(gamma < self.gamma_target))
```

### IP-165 PEC（陈旧度膨胀 + 提交屏障）

```python
class PerceptionExecutionContract:
    def __init__(self, delta_fresh=0.15, theta_d=0.95, Q_stale=diag_q()):
        self.d_fresh, self.theta_d, self.Q_stale = delta_fresh, theta_d, Q_stale
        self.latency_dist = load_latency_profile()

    def feasible(self, delta_available):
        return self.latency_dist.cdf(delta_available) >= self.theta_d

    def effective_cov(self, Sigma_geo, delta_stale):
        return Sigma_geo + self.Q_stale * max(0.0, delta_stale)

    def gate(self, result, t_commit, delta_available, K_safe_base):
        if result.abstain or not self.feasible(delta_available):
            return K_safe_base, 'STALE'
        delta_stale = t_commit - result.t_inf
        if delta_stale > self.d_fresh:
            return K_safe_base, 'STALE'
        Sigma_eff = self.effective_cov(result.Sigma_geo, delta_stale)
        return compile_eeis(result.prior, Sigma_eff), 'FRESH'
```

```python
def verify_geometric_witness(W, mapper, theta_geo=0.7, eps_icp=1e-3):
    if W['ICP_residual'] > eps_icp:
        return False, 'ICP_MISMATCH'
```

| PEC | O(d²) 协方差膨胀 | O(d²) | 陈旧先验方差单调不减 |
| LGW | O(1) 构建 + O(N_patch) 验证 | O(1) | 几何一致性可复算 |

**正确性定理（GLIDE）**：假设 A66–A72 成立：
- **(A66) LGIM 共形有效性**：`P(K_true ∈ CI_{1-α}(g)) ≥ 1−α`（标定分布同分布时）。
- **(A67) MDCA 有界畸变**：`r_deskew ≤ ε_deskew`，无效扫描必弃权。
- **(A68) ASI 契约**：任意抢占点返回合法后验；`t_inf ≤ d_inf` 或显式 `abstain`。
- **(A69) STLA 覆盖**：预见误差落在 `Σ_geo(Δ)` 的 `1−α` 椭球内。
- **(A70) PEC 传播**：`Σ_eff = Σ_geo + Q_stale·Δ_stale` 为陈旧先验的合法上界。
- **(A71) LGW 绑定**：`scan_hash + ICP_residual + T_ego_hash` 唯一绑定见证与扫描。
- **(A72) 预算单调**：`B_cog'` 各维单调消耗，耗尽即触发既定降级。

则：
1. **前瞻不降安全**：若 DGS 成立，`K_safe^PEC ⊆ K_safe_base` 且 `K_safe^PEC` 以概率 `≥ 1−α` 包含真安全集；前瞻派发的安全裕度不低于第 60 轮 SERC。
2. **时间完整性**：任何提交满足 `Δ_stale ≤ Δ_fresh`；过期推理要么等待、要么被 `STALE` 拦截，绝不进入 EEIS。
3. **几何证据连续性**：`EV-exec'` 同时满足 EPIR 的溯源连续与 LGW 的几何一致；遮挡/欺骗/场景改动以 `GEOMETRIC_MISMATCH` 显式暴露。
4. **优雅降级**：任一 `B_cog'` 维度耗尽或任一组件弃权，均回退第 60 轮 SERC，性能不劣于反应式基线。

### IP-161 RMR（可恢复性流形）

```python
class RecoverabilityManifold:
    def __init__(self, critic, unc_model, goal_set, kappa=2.0, tau_rec=0.02):
        self.V, self.unc = critic, unc_model        # V_rec(x), sigma(x)
        self.G, self.kappa, self.tau_rec = goal_set, kappa, tau_rec
        self.rho_safe, self.rho_commit = 0.35, 0.15

    def margin(self, x, z_terrain=None, p_intent=None):
        ctx = (z_terrain, p_intent)
        v = self.V(x, ctx)
        sigma = self.unc(x, ctx)                     # ensemble variance
        v_lcb = v - self.kappa * sigma               # lower-confidence bound
        return v_lcb - self.tau_rec, v, v_lcb, sigma

    def status(self, x, z_terrain=None, p_intent=None):
        rho, *_ = self.margin(x, z_terrain, p_intent)
        if rho > self.rho_safe:   return 'NOMINAL'
        if rho > self.rho_commit: return 'MARGINAL'
        return 'COMMITTED'
```

### IP-162 TPC（跌倒预测证书）

```python
class TipoverPredictor:
    def __init__(self, z_com=0.8, tau_react=0.25, delta=0.05):
        self.omega = math.sqrt(9.81 / z_com)
        self.tau_react, self.delta = tau_react, delta

    def predict(self, x, support_polygon, sigma_contact):
        c, cdot = com_position(x), com_velocity(x)
        xi = c + cdot / self.omega                   # DCM
        d = signed_dist_to_polygon(xi, support_polygon)
        tau = self._time_to_fall(d, cdot, sigma_contact)
        p = 1.0 / (1.0 + math.exp(-(self.tau_react - tau) / 0.08))
        tau_lcb = tau - self._ttf_quantile(sigma_contact, self.delta)
        p_ucb = min(1.0, p + self.delta)
        alert = ('red' if (tau_lcb < self.tau_react and p_ucb >= 0.85)
                 else 'amber' if tau_lcb < 2 * self.tau_react else 'green')
        return PredictionCertificate(tau_lcb, p_ucb, self.delta, alert)
```
