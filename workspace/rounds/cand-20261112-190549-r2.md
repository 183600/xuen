# 第 61 轮（承接第 60 轮 SGEC「场景感知闭环」IP-153~160；灵感循环第 7 轮；本轮灵感：「传感器融合」×「论文发表」）

> 第 60 轮把「执行层→证据层」升级为「认知驱动的场景-执行闭环」：SSM 场景-阻抗先验、CIEC 意图约束锁定、EPIR 因果隔离、SERC 闭环、PCE++++ 认知预算。但**三个更根本的局限**仍未解决：
> 1. **融合是"假融合"**：SSM 的 Kalman 更新用了一个自构造的观测矩阵 `H = _observation_matrix(features)`，隐含假设所有模态**同源时钟、同步到达、互不相关、无外点**。而真实的多传感器（RGB-D、IMU、触觉阵列、六维力、轮速）是**异步、带时延、时钟漂移、相关性未知、含离群点**的——这正是「传感器融合」灵感击中之处。第 60 轮的"融合"没有时间对齐、没有鲁棒核、没有未知相关处理，一旦传感器错位，「场景先验」会把错误传给 K_safe。
> 2. **证据链只有"什么"，没有"谁"**：EPIR 保证了 EV-exec 的 seq/hash 因果顺序，却**不记录每条融合信念是由哪些测量、以多大权重贡献的**。于是出了问题只能知道"错了"，无法回答"是哪个传感器、哪一帧、把它拉偏的"——**不可反事实重放，即不可消融**。
> 3. **不可发表**：E187–E191 只有目标值（≥85%、≥80%、99.9%），**没有基线、没有消融、没有统计检验、没有可复现产物**。「论文发表」灵感在此发难：这些是"声称"不是"证据"，无法通过同行评议的门槛。SGEC 的整座塔在可证伪性上是悬空的。

## 0. 直觉与动机

**灵感 1（传感器融合 → 时序对齐因子图融合 TAF）**
直觉：融合的第一性对象不是某个 `t` 时刻的点估计 `x_t`，而是**一条时间一致的信念轨迹 B(t)**。每个测量不该只是一个数，而应是 `(value, source_time, delay, clock_domain, provenance)`。真正的融合 = 把异步测量**重投影到同一参考时钟**，用因子图在"关键帧信念"之间做 IMU 预积分连接，用鲁棒核（Huber/Cauchy）抵抗外点，用**协方差交叉（CI）**处理"我不知道两个模态是否相关"的情形。关键洞见：**时间是一等公民**——先对齐时间，再谈融合；未对齐的融合，其置信度是虚假的。

**灵感 2（传感器融合 × 论文发表 → "融合溯源即消融" FP）**
直觉：审稿人问的消融（"去掉传感器 i 会怎样？"）和工程上问的溯源（"是哪个传感器把信念拉偏了？"）**是同一个问题**。定义融合溯源为**留一影响（leave-one-out influence）**：`w_i ∝ D(fuse(全部), fuse(去掉 i))`。于是系统在运行时顺手就产出了消融清单：溯源向量越集中，说明该信念越依赖单模态（脆弱）；越分散，说明融合冗余（鲁棒）。关键洞见：**可复现性不是事后补的实验，而是融合算子内建的副产物**。

**灵感 3（论文发表 → 发表级证据协议 PGEP）**
直觉：把每个"创新点"从一句口号变成**可证伪的 claim 元组** `C = (H, M, B, A, S, R)`：假设、指标、基线、消融、统计检验、可复现产物。再配两张证书——**可证伪证书 J_fal**（字段齐全 + 统计功效达标）与**可复现证书 J_rep**（产物哈希、环境、种子、脚本、期望置信区间）。关键洞见：**先用"能否被证伪"筛掉一半想法，再花算力做实验**——这是研究效率的最大杠杆。

**灵感 4（三灵感合流 → 发表级融合证据闭环 PFE）**
直觉：TAF 产出**时间一致信念 + 溯源向量**；FP 把溯源转成**反事实消融**；EPIR 的证据账本升格为 **EPL 融合溯源账本**（记录 belief_id、贡献测量、权重、哈希），支持任意时刻**重放**；PGEP 给每条闭环结论签发 J_fal/J_rep。闭环变为：**对齐→融合→溯源→消融→签发→更新**。这让第 60 轮的"认知先行"第一次具备了**同行可检验性**。

**灵感 5（PCE+++++ → 发表预算 B_pub）**
直觉：算力预算之外还需**"证据预算"**：B_seed（随机种子数/统计功效）、B_abl（消融覆盖度）、B_repro（复现产物完整度）、B_stat（显著性检验次数/多重比较校正）。若 B_stat 耗尽⇒降低 claim 强度（从"优于"降为"可比"）；若 B_abl 不足⇒禁止声称因果；若 B_repro 不足⇒结论标记 `UNPUBLISHABLE` 而非 `REJECTED`（区分"未验证"与"被否定"）。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（时序对齐因子图融合 TAF）** 测量 `m = (id, s, v, t_src, τ_d, c, σ, ρ, π)`，其中 s 为传感器，v 为观测值，t_src 为源时戳，τ_d 为传输时延，c 为时钟域，σ 为噪声尺度，ρ 为鲁棒核，π 为溯源标签。TAF 算子：

```
B(t) = TAF({m_i}, prior) =
  argmax_{x_{0:K}}  Σ_f ρ_f( ||r_f(x)||_{Σ_f} )          # 因子图最大后验
  s.t.  t_i ← A_c(t_i; δ_clk)                             # 时钟域重投影，|skew| ≤ δ_clk
        x_{k} = x_{k-1} ⊗ Δx_IMU(k-1,k)                   # IMU 预积分连接关键帧
```

- **时间对齐算子** A_c：把各时钟域时戳映射到参考时钟，`t_ref = t_src + τ_d + ε_clk`，`|ε_clk| ≤ δ_clk`；超出 δ_clk 的测量**降权或丢弃**（不可信时刻）。
- **鲁棒核** ρ_f ∈ {Huber(δ), Cauchy(γ)}：`ρ_H(r)=½r² if |r|≤δ else δ(|r|−½δ)`，抑制外点。
- **未知相关融合**：当两模态相关性未知时用协方差交叉 `CI(μ₁,Σ₁,μ₂,Σ₂,ω)`，`Σ_CI⁻¹ = ωΣ₁⁻¹+(1−ω)Σ₂⁻¹`，ω∈[0,1]，**一致性保证**：`Σ_CI ⪰ Σ_true`（不保守地假设独立）。
- **输出**：信念轨迹 `B(t)=(μ(t), Σ(t), NEES(t))`，并做**一致性检验** `NEES(t) ∈ [χ²_{n,α/2}, χ²_{n,1−α/2}]`。

**定义 162（融合溯源 FP）** 给定融合算子 TAF、先验与测量集 M，溯源向量 `w(M) ∈ Δ^{|M|}`：

```
w_i = D( TAF(M), TAF(M \ {m_i}) ) / Σ_j D( TAF(M), TAF(M \ {m_j}) )
D(·,·) = ½( μ_a−μ_b )ᵀ (Σ_a+Σ_b)⁻¹ ( μ_a−μ_b ) + ½ tr( Σ_a⁻¹Σ_b + Σ_b⁻¹Σ_a − 2I )
```

- **反事实重放算子** `Replay(belief_id, drop_set)`：从 EPL 取回该信念的贡献测量集，删掉 drop_set 后重算 TAF，得到反事实信念。
- **溯源集中度** `H(w) = −Σ w_i log w_i`（熵）：低熵⇒单模态主导（脆弱，触发"融合冗余不足"告警）；高熵⇒多模态共识（鲁棒）。
- **因果贡献**：若 `w_i ≥ τ_attr` 且 `Replay` 在该传感器被移除后信念越出 1-α 置信椭球，则称"该传感器对此信念具因果贡献"。

**定义 163（发表级证据协议 PGEP）** 一条 claim：

```
C = (H, M, B, A, S, R)
H: 可证伪假设（"X 在分布 D 上使指标 M 改善"）
M: 指标与目标值；B: 基线（必须 ≥1 个强基线 + 1 个消融）
A: 消融集（由 FP 溯源自动生成，覆盖 Fa=1−H(w) 的 top-k）
S: 统计检验（配对 Wilcoxon / bootstrap CI + 多重比较校正 Holm）
R: 可复现产物（代码/配置/种子/环境 lock/期望 CI）
```

- **可证伪谓词** `Falsifiable(C) = 1[∀字段非空] ∧ [Power(C.S) ≥ 1−β] ∧ [基线非平凡]`。
- **可证伪证书** `J_fal = (Falsifiable, 反例构造器, 失效判据)`：必须给出"什么观测会推翻 H"。
- **证据强度** `Strength(C) = min(统计显著性, 消融覆盖, 复现完整度)`——取木桶短板，不取平均。

**定义 164（融合升级 XMC+++）** 在第 60 轮 XMC+ 上叠加 TAF 与 FP：

```
(M, B(t), p) = XMC+++(M, region, inf, EV-exec, {m_i})
  ① {m_i} ← time_align({m_i}; δ_clk)          # TAF 时间对齐
  ② B(t) ← TAF({m_i}, prior=B_prev(t))         # 轨迹融合（鲁棒核 + CI）
  ③ reject if NEES(t) ∉ χ² 区间 → 触发"融合不一致"降级
  ④ p ← FP({m_i}, TAF)                         # 溯源向量
  ⑤ D⁺ ← divergence(B(t), B_prev)
```

**定义 165（发表级融合闭环 SERC+）** 在 SERC 上增加溯源与签发：

```
① TAF: B(t) ← time_align+factor-graph fuse(telemetry, B_prev)
② FP: p ← leave-one-out influence; 低熵告警
③ SERC 原流程：scene → intent → K_safe → execute → EV-exec
④ EPL: ledger.append(belief_id, {m_i}, p, t, hash)
⑤ PGEP: C ← claim(K_safe 收益); J_fal ← falsify(C); J_rep ← reproduce(C, Replay)
⑥ if ¬Falsifiable ∨ B_pub 不足: 结论标记 UNPUBLISHABLE，不得进入 claim 表
⑦ Return (B(t), p, EV-exec, J_fal, J_rep, ledger.status)
```

**定义 166（发表预算 PCE+++++）** `B_pub = (B_seed, B_abl, B_stat, B_repro)`：

- `B_seed`：独立种子数与目标统计功效（power ≥ 0.8）
- `B_abl`：可执行的消融条数上限（由 FP 生成候选，按 |w_i| 排序）
- `B_stat`：显著性检验次数预算（多重比较校正后的检验配额）
- `B_repro`：复现产物完整度（代码/配置/数据哈希/环境 lock）
- **降级规则**：`B_stat` 耗尽 ⇒ claim 强度降级为"可比"；`B_abl` 不足 ⇒ 禁止声称因果，只报相关；`B_repro` 不足 ⇒ `UNPUBLISHABLE`；`B_seed` 不足 ⇒ 只报点估计，不报置信区间。

**定义 167（可复现证书 J_rep）** `J_rep = (artifact_hash, env_lock, seeds, run_script, expected_CI, tolerance)`；校验：

```
Reproducible(J_rep) = hash_match ∧ env_match ∧ |θ_repro − θ_orig| ≤ tolerance ∀θ ∈ expected_CI
```

**定义 168（融合溯源证据账本 EPL）** 只追加账本 `L`，每条记录：

```
e = (belief_id, t_ref, {m_i.id}, w, NEES, hash(prev_e), hash(content))
```

支持 `Replay(e, drop_set)` 与**链式校验** `hash(prev_e)`（既保因果顺序，又保可重放）。EPIR（定义 155）退化为 EPL 的"传输子层"：seq/hash 保证到达，EPL 保证**可解释与可消融**。

### IP-161 TAF（时序对齐因子图融合）

```python
class TemporalAlignmentFusion:
    def __init__(self, ref_clock, delta_clk=0.02, robust='huber', delta=1.0):
        self.ref = ref_clock
        self.delta_clk = delta_clk
        self.kernel = robust
        self.delta = delta
        self.history = deque(maxlen=200)

    def time_align(self, measurements):
        aligned = []
        for m in measurements:
            t_ref = m.t_src + m.tau_d
            skew = abs(t_ref - self.ref.now())
            if skew > self.delta_clk:
                continue                      # 时刻不可信，丢弃
            aligned.append(replace(m, t_ref=t_ref, weight=1.0 - skew/self.delta_clk))
        return sorted(aligned, key=lambda x: x.t_ref)

    def robust_rho(self, r):
        if self.kernel == 'huber':
            a = abs(r)
            return 0.5*r*r if a <= self.delta else self.delta*(a - 0.5*self.delta)
        return 0.5*self.delta**2 * math.log1p((r/self.delta)**2)   # Cauchy

    def fuse(self, prior, measurements):
        # 因子图：IMU 预积分连接关键帧 + 各模态鲁棒观测因子
        graph = FactorGraph()
        graph.add_prior(prior.mu, prior.Sigma)
        for m in measurements:
            graph.add_factor(m.model, m.value, m.Sigma,
                             rho=self.robust_rho, weight=m.weight)
        return graph.solve()                  # Gauss-Newton / iSAM2

    def fuse_with_ci(self, mu1, S1, mu2, S2, omega=0.5):
        S_ci = np.linalg.inv(omega*np.linalg.inv(S1) + (1-omega)*np.linalg.inv(S2))
        mu_ci = S_ci @ (omega*np.linalg.inv(S1)@mu1 + (1-omega)*np.linalg.inv(S2)@mu2)
        return mu_ci, S_ci

    def consistency_check(self, B, n_dim, alpha=0.05):
        lo, hi = chi2.ppf(alpha/2, n_dim), chi2.ppf(1-alpha/2, n_dim)
        return lo <= B.NEES <= hi
```

### IP-162 FP（融合溯源 = 内建消融）

```python
def provenance_vector(fuse_fn, prior, measurements):
    full = fuse_fn(prior, measurements)
    infl = {}
    for i, m in enumerate(measurements):
        rest = measurements[:i] + measurements[i+1:]
        if not rest:
            infl[m.id] = 1.0
            continue
        cand = fuse_fn(prior, rest)
        infl[m.id] = bhattacharyya_div(full.mu, full.Sigma, cand.mu, cand.Sigma)
    tot = sum(infl.values()) or 1.0
    return {k: v/tot for k, v in infl.items()}

def provenance_entropy(w):
    return -sum(p*math.log(p + 1e-12) for p in w.values())

def counterfactual_replay(ledger, belief_id, drop_ids):
    e = ledger.get(belief_id)
    ms = [m for m in e.measurements if m.id not in drop_ids]
    return TemporalAlignmentFusion(e.ref_clock).fuse(e.prior, ms)
```

### IP-163 PGEP（发表级证据协议）

```python
@dataclass
class Claim:
    hypothesis: str
    metric: str
    baseline: list
    ablation: list
    statistic: str
    repro: dict

def falsifiable(c: Claim, required_power=0.8) -> bool:
    fields_ok = all([c.hypothesis, c.metric, c.baseline, c.ablation, c.statistic, c.repro])
    power_ok = c.repro.get('power', 0.0) >= required_power
    nontrivial = any(b not in ('none', 'random', 'no_op') for b in c.baseline)
    return fields_ok and power_ok and nontrivial

def strength(c: Claim, run) -> float:
    p = run.p_value
    abl = len(run.ablations_done) / max(1, len(c.ablation))
    rep = 1.0 if reproducible(run.repro) else 0.0
    return min(float(p < 0.05), abl, rep)            # 木桶短板

def strength_curve(claims, alpha=0.05):
    # Holm 多重比较校正后再判定
    ordered = sorted(claims, key=lambda c: c.run.p_value)
    m = len(ordered)
    return [c for i, c in enumerate(ordered) if c.run.p_value <= alpha/(m - i)]
```

```python
def xmodal_fuse_plus_plus(M, region, inf, ev_exec, measurements, prior):
    taf = TemporalAlignmentFusion(M.ref_clock)
    ms = taf.time_align(measurements)
    B = taf.fuse(prior, ms)
    if not taf.consistency_check(B, n_dim=prior.dim):

    M.D_plus = divergence(B.mu, prior.mu)
    return M, B, M.D_plus, p
```

### IP-166 PCE+++++（发表预算）

```python
class PublicationBudget:
    def __init__(self, seeds=5, ablations=20, stat_tests=30, repro=1.0):
        self.B_seed, self.B_abl = seeds, ablations
        self.B_stat, self.B_repro = stat_tests, repro
        self.used = dict(seed=0, abl=0, stat=0)

    def claim_grade(self):
        if self.B_repro < 0.9:            return 'UNPUBLISHABLE'
        if self.used['stat'] >= self.B_stat: return 'COMPARABLE_ONLY'
        if self.used['abl'] < 3:          return 'CORRELATION_ONLY'
        return 'PUBLISHABLE'

    def power(self, effect, sigma, n):
        return 1 - norm.cdf(norm.ppf(0.975) - effect/(sigma/math.sqrt(n)))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| TAF | O((n+k)³) 因子图求解/关键帧；增量 iSAM2 O(n) | O(n + K) | NEES 落入 χ² 区间 ≥ 95%；外点下 RMSE ≤ 1.2× 理想 |
| FP | O(|M|) 次融合（可缓存/并行） | O(|M|) | 溯源向量 Σw=1；反事实重放与真实消融一致 ≥ 99% |
| PGEP | O(#claims·log #claims) 校正 | O(#claims) | falsifiable/strength 判定可复现；多重比较 FWER ≤ α |
| XMC+++ | 复用 TAF | 复用 | 融合不一致必触发降级 |
| SERC+ | O(闭环)+O(账本追加) | O(ledger) | EPL 链式校验；UNPUBLISHABLE 不进入 claim 表 |

**正确性定理（PFEC）**：假设 A61–A68 成立——**(A66)** TAF 的时钟偏差有界 `|ε_clk| ≤ δ_clk`、鲁棒核满足 `ρ(r) ≥ 0` 且次线性增长，则因子图 MAP 解一致（NEES 检验通过）；**(A67)** FP 的留一影响是融合算子的可微近似，反事实重放与真实重跑在容差内一致；**(A68)** PGEP 的字段完备且统计功效达标，Holm 校正控制 FWER ≤ α。则：

1. **时序一致性**：`B(t)` 在 δ_clk 内对齐，未对齐测量的权重随 skew 单调下降 ⇒ 融合不被"错时"证据污染。
2. **融合可解释性**：任一信念可分解为溯源向量 `w`，低熵触发冗余告警 ⇒ 单点传感器故障不外溢为"高置信错误"。
3. **可证伪性**：`Falsifiable(C)=1` 且 `J_fal` 给出反例构造器 ⇒ 每条结论都可被观测推翻。
4. **可复现性**：EPL + J_rep 使任意信念可 `Replay`，`Reproducible(J_rep)=1` ⇒ 结论可被第三方重放。
5. **预算安全**：`B_pub` 任一维耗尽 ⇒ 结论强度降级而非伪造显著性。

## 4. 实验设计 E192–E196

## 5. 本轮最大风险

**一句话**：若把"溯源一致性 ≥ 99%"和"可证伪率 100%"当成系统真实的安全保证，而 TAF 的时钟对齐在分布式 ROS 环境下被 NTP 跳变击穿（δ_clk 假设失效），那么我们会用一个**看起来可发表、实则时间基准已错位**的融合结论去锁 K_safe——"论文级严谨"反而放大了"错时证据被高置信采纳"的抽象泄漏；必须以"时钟域单调性校验 + 未对齐测量一律降权 + NEES 越界即降级 + UNPUBLISHABLE 与 REJECTED 严格区分"四道闸门，保证可发表性永远从属于时序正确性。

### IP-161 TAF（时序对齐因子图融合）

```python
class TemporalAlignmentFusion:
    def __init__(self, ref_clock, delta_clk=0.02, robust='huber', delta=1.0):
        self.ref, self.delta_clk = ref_clock, delta_clk
        self.kernel, self.delta = robust, delta
        self.history = deque(maxlen=200)

    def time_align(self, measurements):
        aligned = []
        for m in measurements:
            t_ref = m.t_src + m.tau_d
            skew = abs(t_ref - self.ref.now())
            if skew > self.delta_clk:
                continue                        # 时刻不可信：丢弃
            aligned.append(replace(m, t_ref=t_ref,
                                   weight=1.0 - skew/self.delta_clk))
        return sorted(aligned, key=lambda x: x.t_ref)

    def robust_rho(self, r):
        if self.kernel == 'huber':
            a = abs(r)
            return 0.5*r*r if a <= self.delta else self.delta*(a - 0.5*self.delta)
        return 0.5*self.delta**2 * math.log1p((r/self.delta)**2)

    def fuse(self, prior, measurements):
        graph = FactorGraph()
        graph.add_prior(prior.mu, prior.Sigma)
        for m in measurements:
            graph.add_factor(m.model, m.value, m.Sigma,
                             rho=self.robust_rho, weight=m.weight)
        return graph.solve()                    # Gauss-Newton / iSAM2 增量

    def fuse_with_ci(self, mu1, S1, mu2, S2, omega=0.5):
        S = np.linalg.inv(omega*np.linalg.inv(S1) + (1-omega)*np.linalg.inv(S2))
        mu = S @ (omega*np.linalg.inv(S1)@mu1 + (1-omega)*np.linalg.inv(S2)@mu2)
        return mu, S

    def consistency_check(self, B, n_dim, alpha=0.05):
        lo, hi = chi2.ppf(alpha/2, n_dim), chi2.ppf(1-alpha/2, n_dim)
        return lo <= B.NEES <= hi
```

```python
def provenance_vector(fuse_fn, prior, measurements):
    full = fuse_fn(prior, measurements)
    infl = {}
    for i, m in enumerate(measurements):
        rest = measurements[:i] + measurements[i+1:]
        infl[m.id] = 1.0 if not rest else \
            bhattacharyya_div(full.mu, full.Sigma, *(lambda c: (c.mu, c.Sigma))(
                fuse_fn(prior, rest)))
    tot = sum(infl.values()) or 1.0
    return {k: v/tot for k, v in infl.items()}

def provenance_entropy(w):
    return -sum(p*math.log(p + 1e-12) for p in w.values())

def counterfactual_replay(ledger, belief_id, drop_ids):
    e = ledger.get(belief_id)
    ms = [m for m in e.measurements if m.id not in drop_ids]
    return TemporalAlignmentFusion(e.ref_clock).fuse(e.prior, ms)
```

```python
@dataclass
class Claim:
    hypothesis: str; metric: str; baseline: list
    ablation: list; statistic: str; repro: dict

def falsifiable(c, required_power=0.8):
    fields_ok = all([c.hypothesis, c.metric, c.baseline,
                     c.ablation, c.statistic, c.repro])
    power_ok = c.repro.get('power', 0.0) >= required_power
    nontrivial = any(b not in ('none', 'random', 'no_op') for b in c.baseline)
    return fields_ok and power_ok and nontrivial

def strength(c, run):
    return min(float(run.p_value < 0.05),
               len(run.ablations_done)/max(1, len(c.ablation)),
               1.0 if reproducible(run.repro) else 0.0)

def holm_significant(claims, alpha=0.05):
    ordered = sorted(claims, key=lambda c: c.run.p_value)
    m = len(ordered)
    return [c for i, c in enumerate(ordered) if c.run.p_value <= alpha/(m - i)]
```

```python
class PublicationBudget:
    def __init__(self, seeds=5, ablations=20, stat_tests=30, repro=1.0):
        self.B_seed, self.B_abl = seeds, ablations
        self.B_stat, self.B_repro = stat_tests, repro
        self.used = dict(seed=0, abl=0, stat=0)

    def claim_grade(self):
        if self.B_repro < 0.9:               return 'UNPUBLISHABLE'
        if self.used['stat'] >= self.B_stat: return 'COMPARABLE_ONLY'
        if self.used['abl'] < 3:             return 'CORRELATION_ONLY'
        return 'PUBLISHABLE'

    def power(self, effect, sigma, n):
        return 1 - norm.cdf(norm.ppf(0.975) - effect/(sigma/math.sqrt(n)))
```
