# 第 67 轮（承接第 66 轮「RAS 情绪驱动闭环」IP-224~233；新灵感循环第 1 轮；本轮灵感：「实例分割」×「知识图谱」）

> 第 66 轮 RAS 把 VISTA 的「故障闭环」升级为「意图闭环」：用面部表情捕获风险态度，用风险缩放决定「控制多少」。但 RAS 仍带着两个隐蔽的扁平化：
> 1. **对象盲（object-blind）**：它只知道「几何/力/模型/情绪」这些抽象故障类，不知道故障发生在**哪个对象**上——杯子滑落和刀具滑落得到同一个 `H_geo` 后验，却对应完全不同的处置；
> 2. **记忆盲（memoryless）**：每个回合都从同一组固定先验 ℋ×E 重新开始，不会把「上次杯子在桌沿滑落」这类对象-关系经验带入下一次，也无法审计「这条先验从哪来」。
>
> 本轮灵感恰好补上这两块：**实例分割**给出对象身份、掩码与跨帧绑定，回答「坏在谁身上」；**知识图谱**给出对象-关系-因果的符号先验与可版本化记忆，回答「经由什么关系坏、以前是否坏过」。二者合流，使故障归因从「标签分类」变成「图上的路径推断」。

## 0. 直觉与动机

**灵感 1（实例分割 → 对象身份与「绑定问题」）**
直觉：VISTA/RAS 的感知都是一张「整图特征」，故障签名 ρ 是对整幅残差的一个统计量。这在多物体场景里会犯**绑定错误**：桌沿的杯子与手中的刀发生遮挡时，残差属于哪个对象是不确定的。实例分割恰恰解决机器视觉里最古老的「绑定问题（binding problem）」——它把像素划分成**带持久 ID 的对象令牌** `o_i = (id_i, m_i, c_i)`。故障一旦挂到对象上，「几何故障」就细化为「杯子相对于桌面的支撑关系失效」，风险缩放也就能只作用于**相关对象**，而不是整条控制指令一刀切。

**灵感 2（知识图谱 → 关系先验与可审计记忆）**
直觉：实例分割告诉我们「有杯子、有桌子、有杯子在桌上」，但**「在桌上」意味着什么、坏了会怎样**，单靠分割给不出。知识图谱把这些常识写成三元组与公理：`cup --supported_by--> table`、`grasp(hand, cup) → 需要 cup 在 hand 的抓取域内`。于是故障不再是「某特征超阈值」，而是「某条本应成立的关系被违反」。更重要的是，图谱是**外部、可版本化、可审计**的记忆：第 66 轮 RAS 的风险是情绪先验不可解释，而图谱的每条先验都能追溯到出处（provenance）。这为「跨回合不遗忘地积累故障经验」提供了不依赖权重更新的路径。

**灵感 3（反事实图干预 → 从相关到因果）**
直觉：仅凭观测到的图异常，无法区分「杯子滑落导致桌面湿」与「桌面湿导致反光误检」。知识图谱允许做 `do` 干预：在图上删掉/替换一条关系边（如「移除支撑关系」），前向推演预测观测量变化，变化越大，该边越可能是**根因路径**上的因果边。这把 VISTA 的「残差归因」升级为「结构化反事实归因」，也为主动探针提供了可解释的候选集合。

**灵感 4（三灵感合流 → KAIROS：对象-关系可归因闭环）**
闭环在 RAS 的「ERG→EFS→C-RAS→ERS」骨架上换装并新增对象/图两层：
1. **OEG Object-Entity Gateway**：实例分割 + 跟踪 + 图谱接地，输出持久对象令牌与场景图 `G_t`；
2. **SGB Scene-Graph Builder / Aligner**：把对象令牌接地图谱实体，检查公理满足度，计算图异常分 `A(G_t)`；
3. **GFA Graph Fault Attribution**：用图谱路径枚举生成假设 `ℓ`，每条路径携带「故障类型 + 对象 ID」，替换 RAS 的固定 7 类扁平假设；
4. **CGI Counterfactual Graph Intervention**：对高不确定路径做 `do` 干预重评分，抑制相关≠因果；
5. **KGM Knowledge-Graph Memory**：把确认过的故障路径写成带 provenance 与版本的三元组，仅在语义流检索/写入；
6. **OAR Object-Action Re-commitment**：动作块按对象条件化，对象绑定变化时只重承诺受影响的块后缀；
7. **C-KAIROS Certified prefix**：认证前缀必须同时满足 RAS 风险、对象身份保持、图谱一致性三条约束；
8. **GRS Graph Risk Scaling**：`λ_KAIROS = λ_RAS · (1 - κ·A_norm)`，图异常越强越保守。

**灵感 5（对第 66 轮各组件的精确升级）**
- **EFS → GFA**：假设集 `ℋ_RAS = ℋ × E` 变为「图上长度 ≤ L 的路径集合」，后验从乘积分量变为路径似然；
- **C-RAS → C-KAIROS**：`k* = min(k_RAS, k_obj, k_graph, m_kairos)`，新增对象身份证书与图一致性证书；
- **FAS → CGI-FAS**：当路径后验弥散时，不是采集更多情绪探针，而是做**图上反事实干预**；
- **AIC-RAS → AIC-KG**：干扰集新增 `ℰ_seg`（掩码错误/实例漏检）、`ℰ_bind`（ID 交换）、`ℰ_kg`（图谱过时/缺失/错误边）与共因 `ℰ_common_kg`（分割错误 → 图接地错误 → 归因错误）；
- **J_RAS → J_KAIROS**：证书增 `object_id_hash`、`scene_graph_hash`、`path_posterior`、`kg_version`、`kg_consistency`、`memory_provenance`。

**核心命题（本轮落点）**
> **把「意图感知闭环」升级为「对象-关系可归因闭环」：实例分割给出对象身份（who/what），知识图谱给出关系与因果记忆（why/before），二者把故障假设从固定标签集合升级为图上的路径集合，从而回答「坏在谁身上、经由什么关系、有无历史先例」。**

## 1. 形式化定义（增量：定义 245–260）

- **定义 245（KAIROS 总览）**：`KAIROS = (OEG, SGB, GFA, CGI, KGM, OAR, C-KAIROS, GRS, ERG, ERS)`。定位：RAS 的「意图闭环」升级为「对象-关系可归因闭环」。不变式：对象令牌、场景图、路径后验、图记忆的写操作只在语义流；实时流只做实例掩码残差、身份匹配、图约束早停，零学习写操作。
- **定义 246（实例对象观测量）**：实例分割器 `f_seg` 把图像映射为 `S_t = {(m_i, c_i, s_i)}_{i=1}^{N_t}`，其中 `m_i ∈ {0,1}^{H×W}` 为掩码、`c_i` 为类别、`s_i ∈ [0,1]` 为置信度。对象令牌为 `o_i = (id_i, m_i, c_i, s_i, b_i, e_i)`，`b_i` 为包围盒、`e_i ∈ ℝ^{d_e}` 为重识别外观嵌入。
- **定义 247（对象身份保持）**：跨帧匹配用匈牙利算法在代价 `C_ij = 1 - IoU(m_i^{t-1}, m_j^t) - η·cos(e_i^{t-1}, e_j^t)` 上求最优匹配。身份裕度 `ι(t) = 1 - max_{i≠j} IoU(m_i^{t-1}, m_j^t)`；若 `ι(t) < τ_id` 则标记 `id_swap_risk = True`。
- **定义 248（场景图）**：`G_t = (V_t, E_t)`，`V_t = O_t ∪ {a_t} ∪ {env}`，`a_t` 为主体（机器人/人），`env` 为环境；`E_t ⊆ V_t × R × V_t` 为带权关系边，`R = {supported_by, contain, grasp, near, part_of, ...}`，边权 `w_e ∈ [0,1]`。
- **定义 249（图谱接地）**：接地映射 `φ: V_t → C` 把对象类别映射到知识图谱概念，`ψ: R → P` 把关系映射到谓词。接地后的图记为 `G_t^K = (φ(V_t), ψ(E_t))`。
- **定义 250（图约束满足度）**：知识图谱公理集 `A = {a_k}`（如 `cup(x) → ∃y supported_by(x,y)`）。满足度 `Γ(G_t) = exp(-Σ_k λ_k·viol_k(G_t)) ∈ (0,1]`，`viol_k` 为第 k 条公理被违反的程度（0 表示满足）。
- **定义 251（图异常分）**：相对图谱预测图 `Ĝ_t` 的异常分 `A(G_t) = α_e·d_edit(G_t, Ĝ_t) + α_Γ·(1-Γ(G_t))`，归一化到 `[0,1]`。`A > τ_graph` 表示图级异常。
- **定义 252（路径故障假设）**：故障假设是从异常节点 `v_0` 到根因节点 `v_L` 的路径 `ℓ = v_0 --r_1--> v_1 ... --> v_L`，长度为 `L ≤ L_max`。其标签 `h_ℓ = (fault_type(v_L), id(v_0))`，即**同时携带故障类型与对象身份**。假设集 `ℋ_t = TopK_paths(G_t, v_0, L_max)`。
- **定义 253（路径后验）**：`P(ℓ | ρ, G_t, K) ∝ p(ρ | ℓ)·exp(-A(G_t | ℓ))·P(ℓ | K)·M(ℓ)`，其中 `P(ℓ|K)` 为图谱路径先验（边权连乘），`M(ℓ)` 为图记忆先验（定义 257）。归一化在 TopK 路径上完成。
- **定义 254（反事实图干预）**：对候选边 `e` 做干预 `do(G_t \ {e})`，前向推演得预测观测 `ŷ_{-e}`，因果强度 `C_e = D(y_obs, ŷ_{-e})`。路径 `ℓ` 的反事实分数 `C_ℓ = Σ_{e∈ℓ} C_e`；当路径后验熵 `H(ℓ) > τ_entropy` 时用 `C_ℓ` 重排序。
- **定义 255（对象身份证书）**：认证前缀 `k` 满足对象身份保持，当且仅当 `∀s≤k: ι(s) ≥ τ_id` 且 `∀s≤k: |V_s| = |V_{s}^{pred}|`。记最大可行前缀为 `k_obj`。
- **定义 256（C-KAIROS 认证前缀）**：`k*KAIROS = min(k_RAS, k_obj, k_graph, m_kairos)`，其中 `k_graph = max{k: ∀s≤k, Γ(G_s) ≥ τ_consistency}`，`m_kairos = min(m_RAS, m_obj)`。
- **定义 257（图记忆 KGM）**：记忆为带权三元组集合 `M = {(s, p, o, n, ω, prov, ver)}`，`n` 为观测次数、`ω` 为确认后验、`prov` 为来源（回合号/实验号）、`ver` 为图谱版本。检索 `M(ℓ) = max_{τ∈M, τ⊨ℓ} ω·exp(-λ_T·age(τ))`。写入仅发生在语义流，采用版本化追加（不删旧版本）。
- **定义 258（对象条件动作块）**：动作块 `A_t = {(a_j, o_{ι(j)})}`，每个原子动作绑定一个对象令牌。若在时刻 s 对象绑定发生变化（`ι(s) < τ_id` 或 ID 集合改变），则从 s 起重承诺块后缀 `A_t[s:]`。
- **定义 259（图风险缩放）**：`λ_KAIROS = clip(λ_RAS·(1 - κ·A_norm(G_t)), 0.5, 1.2)`，`κ` 为标定参数。图异常越强，`λ` 越保守（越小）。
- **定义 260（J_KAIROS 证书）**：`J_KAIROS = (J_RAS, object_id_hash, scene_graph_hash, path_posterior, kg_version, kg_consistency, memory_provenance)`。Valid ⇔ `Valid(J_RAS) ∧ k_obj ≥ 1 ∧ Γ(G_t) ≥ τ_consistency ∧ kg_version 可追溯`。

## 2. 关键算法骨架

```python
class ObjectEntityGateway:
    def observe(self, img, prev_objects):
        segs = instance_segmentation(img)          # {(mask, class, score)}
        objects = []
        for seg in segs:
            emb = reid_embedding(img, seg.mask)
            objects.append(Object(mask=seg.mask, cls=seg.cls,
                                  score=seg.score, emb=emb,
                                  id=None, bbox=bbox(seg.mask)))
        matched, unmatched = hungarian_match(prev_objects, objects,
                                             tau_id=self.tau_id)
        for obj, prev in matched:
            obj.id = prev.id
            obj.id_swap_risk = (mask_iou(prev.mask, obj.mask) < self.tau_id)
        for obj in unmatched:
            obj.id = self.new_id()
        return objects

class SceneGraphBuilder:
    def build(self, objects, kg):
        V = objects + [AGENT, ENV]
        E = []
        for u, v in candidate_pairs(V):
            for r in kg.predicates_for(u.cls, v.cls):
                w = relation_scorer(u, v, r)
                if w > self.tau_edge:
                    E.append(Edge(u, r, v, w))
        G = SceneGraph(V, E)
        G.consistency = kg.axiom_satisfaction(G)   # Γ(G)
        G.anomaly = self.anomaly_score(G, kg.predict(G))
        return G

class GraphFaultAttribution:
    def attribute(self, rho, G, kg, memory, tau_entropy=0.7):
        v0 = G.most_anomalous_node()
        paths = kg.enumerate_paths(v0, G, L_max=self.L_max)
        post = {}
        for ell in paths:
            lik = self.p_rho(rho, ell) * exp(-G.anomaly_given(ell))
            prior = kg.path_prior(ell) * memory.retrieve(ell)
            post[ell] = lik * prior
        post = normalize(post)
        if entropy(post) > tau_entropy:            # 后验弥散 → 反事实干预
            for ell in post:
                post[ell] *= exp(self.counterfactual_score(ell, G, kg))
            post = normalize(post)
        return post

class KnowledgeGraphMemory:
    def retrieve(self, path):
        return max((t.omega * exp(-self.lam_T * t.age)
                    for t in self.triples if t.entails(path)), default=1e-3)

    def commit(self, path, post, provenance):
        if post[path] >= self.tau_commit:
            self.triples.append(Triple.from_path(
                path, omega=post[path], prov=provenance,
                ver=self.kg.version))              # 语义流、版本化追加

def KAIROS_round(M, obs):
    V, T, P, L, P_cloud, W, tactile, img, depth, flow = obs
    M.lsf.update_geometry(P_cloud)
    x_prime = M.lsf.fuse(M.usr.fuse(V, T, P, L))
    y_vis = M.f_vis(img, depth, flow)

    objects = M.oeg.observe(img, M.prev_objects)   # 实例分割 + 身份
    G = M.sgb.build(objects, M.kg)                 # 场景图 + 接地
    face_gate = M.er.recognize(img)                # 沿用 RAS 情绪通道

    A = M.vista.ach.propose(x_prime, H=M.vista.H)
    rho = M.vista.fir.signature(M.vista.stage.split(M.vista.residual_log))
    path_post = M.gfa.attribute(rho, G, M.kg, M.kgm)

    k_ras = M.csc_ras.certified_prefix_ras(A, path_post, M.m_ras, M.alpha_chunk)
    k_obj = M.csc.certified_prefix_object(A, G, M.tau_id)
    k_graph = M.csc.certified_prefix_graph(A, G, M.tau_consistency)
    k_star = min(k_ras, k_obj, k_graph, M.m_kairos)

    lam = M.efs.risk_scale(path_post)              # 沿用 RAS
    lam = clip(lam * (1 - M.kappa * G.anomaly_norm), 0.5, 1.2)

    tau_cmd = M.vista.pi_sigma.prefix_dispatch(A[:k_star])
    tau_cmd = M.ers.shaping(tau_cmd * lam, path_post)

    if G.anomaly > M.tau_graph:                    # 对象条件重承诺
        A = M.oar.recommit(A, k_star, G)
    return k_star, lam, path_post, G, face_gate
```

## 3. 推导

**引理 11（对象身份保持下界）** 设相邻帧掩码 IoU 的下界为 `ι_min`，重识别嵌入的类间余弦间隔为 `δ_e`。若 `ι_min + η·δ_e > τ_id`，则匈牙利匹配的对象绑定错误率 `P_swap ≤ exp(-2N(ι_min+ηδ_e-τ_id)^2)`（Hoeffding 界）。即身份裕度越大，绑定错误呈指数下降。

**引理 12（反事实可识别性）** 若对路径 `ℓ` 上的每条边都有有效干预且前向模型在干预下可微，则 `C_ℓ` 在 Markov 等价类内唯一确定根因节点；当图含未观测混杂边 `v_0 ← u → v_L` 时，仅凭 `C_ℓ` 无法区分 `v_0` 与 `u`，需记忆先验 `M(ℓ)` 打破对称。

**定理 11（KAIROS 端到端安全）** 在 A87–A91 与定义 247–256 下，KAIROS 输出的控制指令 `τ_cmd` 满足：
1. `P(|τ_cmd - τ*| > ε) ≤ α_chunk + δ_fi + α_emotion + α_obj + α_graph`；
2. 若 `k_obj ≥ 1` 且 `Γ(G_t) ≥ τ_consistency`，则执行过程不发生对象绑定交换（ID swap）；
3. `A(G_t) = 0 ⇒ λ_KAIROS = λ_RAS`，图无异常时不引入额外保守性。

**定理 12（图记忆的保守扩展性）** 若新增三元组 `τ` 对既有观测的似然支持为零（`p(ρ_old | τ) = 0`），则 `P(ℓ | ρ_old, M ∪ {τ}) = P(ℓ | ρ_old, M)`。即版本化追加的记忆不会改写旧回合的归因结论，避免 Continual Learning 中典型的灾难性遗忘；若 `p(ρ_old|τ) > 0`，则需保留旧版本 `ver` 以便审计回溯。

| E260 长尾与过时图谱 | 新对象/新关系/错误边下的鲁棒性 | 拒答率可控、误归因 < 10% |

## 6. 本轮最大风险

**一句话**：KAIROS 把「对象身份稳定」与「知识图谱完备」当作两条硬前提，但真实长尾场景里既会出现分割失败导致的**对象错绑**，也会出现图谱未覆盖的新对象/新关系——此时图路径推断会以高置信度把故障归因到错误节点，并用对象级证书「认证」一个错误对象，比 RAS 的扁平先验更危险，因为它是**精确地错**。

**次级风险与缓解**：
1. **图谱封闭世界假设**：对未接地对象保留 `UNKNOWN` 节点并禁止其参与证书（`k_graph` 对 UNKNOWN 强制降级），避免用错边；
2. **分割遮挡**：多帧掩码融合 + 事件相机边缘补全，`ι < τ_id` 时冻结对象级动作；
3. **图谱过时**：`kg_version` 与 `provenance` 全程入证书，支持回滚；错误边只在语义流修正；
4. **路径爆炸**：`L_max ≤ 4` + 边权剪枝 + TopK，把路径数控制在 O(10)；
5. **图记忆污染**：只在 `post ≥ τ_commit` 且多回合一致时写入，避免单次误检固化。

```python
# IP-234 OEG
class ObjectEntityGateway:
    def observe(self, img, prev_objects):
        segs = instance_segmentation(img)
        objects = [Object(mask=s.mask, cls=s.cls, score=s.score,
                          emb=reid_embedding(img, s.mask),
                          id=None, bbox=bbox(s.mask)) for s in segs]
        matched, unmatched = hungarian_match(prev_objects, objects,
                                             tau_id=self.tau_id)
        for obj, prev in matched:
            obj.id = prev.id
            obj.id_swap_risk = mask_iou(prev.mask, obj.mask) < self.tau_id
        for obj in unmatched:
            obj.id = self.new_id()
        return objects

# IP-235 SGB
class SceneGraphBuilder:
    def build(self, objects, kg):
        V = objects + [AGENT, ENV]
        E = [Edge(u, r, v, w)
             for u, v in candidate_pairs(V)
             for r in kg.predicates_for(u.cls, v.cls)
             for w in [relation_scorer(u, v, r)] if w > self.tau_edge]
        G = SceneGraph(V, E)
        G.consistency = kg.axiom_satisfaction(G)      # Γ(G)
        G.anomaly = self.anomaly_score(G, kg.predict(G))
        return G

# IP-236/237 GFA + CGI
class GraphFaultAttribution:
    def attribute(self, rho, G, kg, memory, tau_entropy=0.7):
        v0 = G.most_anomalous_node()
        paths = kg.enumerate_paths(v0, G, L_max=self.L_max)
        post = {ell: self.p_rho(rho, ell)
                     * exp(-G.anomaly_given(ell))
                     * kg.path_prior(ell) * memory.retrieve(ell)
                for ell in paths}
        post = normalize(post)
        if entropy(post) > tau_entropy:
            post = normalize({ell: p * exp(self.counterfactual_score(ell, G, kg))
                              for ell, p in post.items()})
        return post

# IP-238 KGM
class KnowledgeGraphMemory:
    def retrieve(self, path):
        return max((t.omega * exp(-self.lam_T * t.age)
                    for t in self.triples if t.entails(path)), default=1e-3)

    def commit(self, path, post, provenance):
        if post[path] >= self.tau_commit:
            self.triples.append(Triple.from_path(
                path, omega=post[path], prov=provenance, ver=self.kg.version))

# IP-239 OAR
def object_recommit(A, k_star, G):
    if G.binding_changed_from(k_star):
        s = G.first_binding_change()
        return A[:s] + repropose(A[s:], G)
    return A

# IP-240/242 KAIROS 闭环
def KAIROS_round(M, obs):
    V, T, P, L, P_cloud, W, tactile, img, depth, flow = obs
    M.lsf.update_geometry(P_cloud)
    x_prime = M.lsf.fuse(M.usr.fuse(V, T, P, L))
    y_vis = M.f_vis(img, depth, flow)

    objects = M.oeg.observe(img, M.prev_objects)
    G = M.sgb.build(objects, M.kg)
    face_gate = M.er.recognize(img)

    A = M.vista.ach.propose(x_prime, H=M.vista.H)
    rho = M.vista.fir.signature(M.vista.stage.split(M.vista.residual_log))
    path_post = M.gfa.attribute(rho, G, M.kg, M.kgm)

    k_ras = M.csc_ras.certified_prefix_ras(A, path_post, M.m_ras, M.alpha_chunk)
    k_obj = M.csc.certified_prefix_object(A, G, M.tau_id)
    k_graph = M.csc.certified_prefix_graph(A, G, M.tau_consistency)
    k_star = min(k_ras, k_obj, k_graph, M.m_kairos)

    lam = clip(M.efs.risk_scale(path_post)
               * (1 - M.kappa * G.anomaly_norm), 0.5, 1.2)

    tau_cmd = M.vista.pi_sigma.prefix_dispatch(A[:k_star])
    tau_cmd = M.ers.shaping(tau_cmd * lam, path_post)
    A = object_recommit(A, k_star, G)
    return k_star, lam, path_post, G, face_gate
```

## 4. 推导

**引理 11（对象身份保持下界）** 设相邻帧掩码 IoU 下界 `ι_min`、ReID 类间余弦间隔 `δ_e`。若 `ι_min+η·δ_e>τ_id`，则绑定错误率
```
P_swap ≤ exp(-2N(ι_min + ηδ_e - τ_id)²)
```
即身份裕度越大，绑定错误指数衰减。

**引理 12（反事实可识别性）** 若路径 `ℓ` 上每条边都有有效干预且前向模型在干预下可微，则 `C_ℓ` 在 Markov 等价类内唯一确定根因节点；若存在未观测混杂边 `v_0←u→v_L`，仅凭 `C_ℓ` 无法区分 `v_0` 与 `u`，需记忆先验 `M(ℓ)` 打破对称。

**定理 11（KAIROS 端到端安全）** 在 A87–A91 与定义 247–256 下：
1. `P(|τ_cmd-τ*|>ε) ≤ α_chunk + δ_fi + α_emotion + α_obj + α_graph`；
2. 若 `k_obj≥1 ∧ Γ(G_t)≥τ_consistency`，执行过程不发生对象绑定交换（ID swap）；
3. `A(G_t)=0 ⇒ λ_KAIROS=λ_RAS`，图无异常时不引入额外保守性。

**定理 12（图记忆的保守扩展性）** 若新增三元组 `τ` 对既有观测的似然支持为零（`p(ρ_old|τ)=0`），则
```
P(ℓ|ρ_old, M∪{τ}) = P(ℓ|ρ_old, M)
```
即版本化追加不会改写旧回合归因结论，避免灾难性遗忘；若 `p(ρ_old|τ)>0`，保留旧版本 `ver` 以支持审计回溯。
