# 第 1 轮（新灵感循环；技术基线 v8；本轮灵感：「分布外泛化」×「排行榜」）

> **基线**：第 8 轮 MetricVoiceGauge-DA-SPR-Cal v8（定义 493–531；引理 77–81；实验 E531–E550）。
> **本轮纪律**：OOD 泛化回答「证书在没见过的分布上还算不算数」；排行榜回答「在多方竞争与反复提交下，排名还算不算数」。二者共享同一个敌人：**对评估分布的过拟合**。新增模块一律为可选增强，任一失效逐级退回 v8。

## 0. 直觉与动机

**灵感 1（分布外泛化 → 从「域偏移告警」升级为「泛化证书」）**
直觉：v8 的 DA-ML 只测到「输入离参考域远」，然后凭经验收紧阈值；这既没有统计保证，也分不清「新奇但安全」与「危险偏移」。OOD 泛化给出的不是又一个距离，而是**可校准的弃权/告警**：用保形 p 值控制误报率，用最差组风险/分布鲁棒优化替代平均风险，用泛化上界决定证书能否签发。换句话说，v8 关心「像不像训练分布」，本轮关心「在不像训练分布时，我的安全声明还成立吗」。

进一步，把泛化拆成四个尺度：
- **域级**（v8 已有）：`Δ_dom(t)`，MMD 测整体漂移；
- **样本级**（本轮新增）：`p_OOD(t)`，保形 p 值测单帧是否离群；
- **组级**（本轮新增）：`R_DRO(θ)`，最差环境/最差任务组的风险；
- **评估级**（本轮新增）：排行榜排名区间与 Goodhart 差距。
前三个尺度回答「部署时是否安全」，第四个尺度回答「对外宣称的领先是否真实」。四者共用同一套证据链。

**灵感 2（排行榜 → 把排名当作带噪声的统计量，而非真值）**
直觉：排行榜是典型的多重比较 + 自适应复用 + Goodhart 场：同一批任务被反复用来调参，公开榜分数会系统性地高于隐藏/OOD 分数。若把榜单名次直接当能力，系统会优化「榜」而不是「事」。本轮把排行榜形式化为**任务抽样下的随机排序**：用配对 bootstrap 给排名区间，用隐藏任务与 OOD 任务测「榜单-现实差」，用 e-value 校正反复提交带来的选择偏差，并定义**排名稳定性**——在分布扰动下名次不翻转的半径。

**合流点（1+1>2）：排行榜本身就是一次 OOD 测试**
对排行榜过拟合，本质上就是 OOD 泛化失败：系统在公开任务分布 `P_pub` 上排名很高，却在隐藏任务 `P_hid` 或 OOD 任务 `P_ood` 上排名下滑。于是可以设计一个闭环：
1. **OOD 闸门**决定「何时可以收紧」——只有统计显著的离群才允许触发额外保守化，避免 v8 的「退化风暴」；
2. **DRO 阈值**决定「收紧到哪里」——按最差组风险而非平均风险校准，保证陌生组不被平均掉；
3. **泛化证书**决定「能不能宣称安全」——用置信上界而非点估计；
4. **排行榜证书**决定「能不能宣称领先」——用排名区间、稳定性半径与 Goodhart 守卫，而不是裸名次。

## 1. 研究问题（本次会话第 1 轮）

- **Q1（样本级 OOD 闸门）**：如何把 OOD 检测从经验阈值变成有误报率上界的闸门，并与 v8 的域级 `Δ_dom` 正交组合，避免「感知抖动 → 频繁收紧 → 退化风暴」？
- **Q2（组级鲁棒校准）**：如何在有限样本、未知组结构下，给指标阈值一个最差组/分布鲁棒的校准，并给出可计算的置信上界？
- **Q3（评估级排名证书）**：如何把排行榜名次从点估计升级为带置信度、抗选择偏差、抗 Goodhart 的证书，并定义「OOD 下名次不翻转」的稳定性半径？
- **Q4（退化与实时性）**：四个新模块如何与 v8 的 OTL / DA-ML / SPR / Calib-FI 正交组合，任一失效平滑回退，且不破坏 50Hz？

## 2. 设计原则（在 P7–P9 基础上升级为 P10–P13）

**P10 保形 OOD 闸门（Conformal OOD Gate, COG）**
在冻结特征空间上定义非一致性分数 `a(z)`，用参考集 `Z_ref` 校准保形 p 值：
```
a(z) = (1/k) · Σ_{j∈kNN(z; Z_ref)} ||z − z_j||₂
p(z) = (1 + Σ_{j=1}^{n} 1[a(z_j) ≥ a(z)]) / (n + 1)
g(z) = 1[p(z) ≤ α]
```
`g=1` 表示「在显著性水平 α 下，当前样本显著离群」。OOD 闸门只允许 OTL 追加收紧项，不允许放宽任何安全阈值；无显著证据的「可疑」不触发退化。

**P11 分布鲁棒阈值（Distributionally Robust Threshold, DRT）**
不再用平均风险校准 `τᵢ`，而是在环境/任务组的 χ² 不确定集 `U_ρ` 上取最差风险：
```
R_DRO(θ) = sup_{Q∈U_ρ} E_Q[ℓ_θ]
```
用 Hoeffding 最差组上界 + 不确定集半径项得到可计算上界，再反解阈值。`ρ→0` 时退化为 v8 的平均校准；`ρ` 越大越保守但越抗未知组。

**P12 排行榜排名证书（Leaderboard Rank Certificate, LRC）**
把排行榜视为「任务抽样 → 系统得分 → 排序」的随机过程。按任务做配对 bootstrap，得到每个系统名次的 `1−α` 区间 `[r_lo, r_hi]`；同时定义 OOD 扰动下的**排名稳定性半径** `Δ_stab`：
```
Δ_stab(a) = max_{P'∈U_ρ^LB} |r_{P'}(a) − r_{P_pub}(a)|
```
只有 `r_hi(a) ≤ k` 且 `Δ_stab(a) ≤ s_max` 时才签发「前 k 名」证书。

**P13 反 Goodhart 守卫与任意时刻有效选择校正（Goodhart Guard, GG）**
定义公开榜与隐藏/OOD 榜的差距：
```
G = S_pub − max(S_hid, S_ood)
S_eff = S_pub − λ_G · max(0, G) − λ_D · log(1 + m)
```
其中 `m` 为自适应提交次数。用 e-value 控制「反复提交后宣称提升」的族错误率：在零假设「无真实提升」下，`E_m` 是上鞅，Ville 不等式给出 `P(∃m: E_m ≥ 1/α) ≤ α`。公开榜只用于展示，不进入控制回路；证书只在 Goodhart 差距不显著且 e-value 支持时才声明领先。

## 3. 与基线的接口（如何退化）

- **COG 失效** ⇒ `g ≡ 0`，OOD 收紧项消失，退回 v8 的 DA-ML/OTL 路径；
- **DRT 失效** ⇒ `τᵢ` 退回 v8 的 DA-OTL 阈值（仅域偏移 + 性能趋势）；
- **GenCert/选择风险模块失效** ⇒ 控制回路不变，所有安全主张降级为 exploratory，不签发泛化证书；
- **LRC/RSA/GG/FTS 失效** ⇒ 排行榜只报点估计名次并标注 `unverified`，控制回路完全不受影响（排行榜在离线评估面，不在 50Hz 主环）；
- **全部失效** ⇒ 逐位等价 MetricVoiceGauge-DA-SPR-Cal v8，再退回 v7。

关键顺序：**先 v8 OTL/DA-ML，再 OOD 闸门，再 DRO 收紧，最后 clip**。所有新增项对 M₀/M₁ 只增不减（`μᵢ, κᵢ ≥ 0`），因此组合只会更保守，不会放宽安全。

## 4. 预期贡献

1. **四尺度泛化框架**：把域级 MMD、样本级保形 p 值、组级 DRO 风险、评估级排名证书统一到同一证据链；
2. **保形 OOD 闸门 + DRO 阈值的双层统计保证**：前者控制误报率，后者控制最差组风险，二者都与 v8 正交；
3. **排行榜排名证书**：排名区间、OOD 稳定性半径、Goodhart 差距、任意时刻有效 e-value 的形式化与算法；
4. 完整的 **感知-指标-动作-评估** 闭环：E551–E575 覆盖 OOD 检测、DRO 校准、排名有效性、抗过拟合、退化与实时性。

## 5. 本轮最大风险

**一句话**：如果 OOD 校准集与排行榜任务共享同一批数据/分布，那么 OOD 闸门与排名证书会互相自我确认——系统在榜上名次稳定、证书齐全，却在真正的新分布上同时失去告警与排名有效性；这是「评估泄漏」而非「算法失效」，也最难被常规消融发现。

# 第 1 轮产物 · 创新点清单 v9：**MetricVoiceGauge-ODR-LC**（Out-of-Distribution-robust, Distributionally-robust Leaderboard Certification）

> 背景：第 8 轮 MetricVoiceGauge-DA-SPR-Cal v8（定义 493–531；引理 77–81；实验 E531–E550）。
> 本轮灵感：「分布外泛化」×「排行榜」
> **继承纪律**：v8 的九不变式（CVC-闭环、SpatialCert、RT-CVC、FaultCert、PrimitiveGraph、严格退化链、OTL、GCT、ER）与 DA-ML / SPR / OnlineCalib-FI 三级退化链全部保留。COG / SRC / DRT / GenCert / LRC / RSA / GG / FTS 一律为**可选增强**：任一不可用 ⇒ 逐级退回 v8。

**新增定义 532（OOD 非一致性分数与保形 p 值 ConformalOODScore）**
给定冻结编码器 `φ: O → ℝ^d` 与参考特征集 `Z_ref = {z_j}_{j=1}^n`，定义：
```
a(z) = (1/k) · Σ_{j ∈ kNN(z; Z_ref)} ||z − z_j||₂
p(z) = (1 + Σ_{j=1}^{n} 1[a(z_j) ≥ a(z)]) / (n + 1)
g(z) = 1[p(z) ≤ α]
```
参考分数 `a(z_j)` 用留一法计算，避免自匹配导致 p 值偏大。若测试样本与参考集可交换，则 `P(p(z) ≤ α) ≤ α`。在协变量偏移下，使用加权保形版本或把 `p` 解释为「新颖度分数」而非精确 p 值；这一点在引理 82 中显式声明。

**新增定义 533（选择风险与覆盖率 SelectiveRisk）**
```
Cov(g)  = E[g(z)]
R_sel(g) = E[ℓ(z)·g(z)] / max(E[g(z)], ε_cov)
```
约束：`Cov(g) ≥ c_min` 且 `R_sel(g) ≤ ε_sel`。前者防止闸门长期关闭导致任务不可用，后者保证「只在有把握时接受」的选择风险可控。

**新增定义 534（分布鲁棒风险 DistributionallyRobustRisk）**
设环境/任务组 `e=1..E`，`P_e` 为第 e 组分布，`λ ∈ Δ_E` 为混合权重，定义 χ² 不确定集：
```
U_ρ = { Q = Σ_e λ_e P_e : Σ_e (λ_e − 1/E)² / (1/E) ≤ 2ρ }
R_DRO(θ) = sup_{Q ∈ U_ρ} E_Q[ℓ_θ(z)]
```
`ρ=0` 时 `U_ρ` 退化为各组等权混合；`ρ` 越大，允许的组间重加权越极端，校准越保守。

**新增定义 535（DRO 阈值校准 DROThreshold）**
对每层 `i` 与候选阈值 `τ`，令 `θ_τ` 为「阈值取 τ 时的策略参数」，定义有限样本上界：
```
R̂_DRO^+(θ) = max_e [ R̂_e(θ) + sqrt( log(2E/δ) / (2 n_e) ) ] + L_ℓ · sqrt(2ρ)
τ_i^DR = inf { τ : R̂_DRO^+(θ_τ) ≤ ε_i }
```
`R̂_e` 为第 e 组经验风险，`n_e` 为该组样本数。由于 `R̂_DRO^+` 对 `ρ` 与 `1/n_e` 单调不降，`τ_i^DR` 对 `ρ` 单调不降（更保守）。

**新增定义 536（泛化证书 GeneralizationCertificate）**
对主张 `C = (指标, 上界 ε_C)`，在 n 个样本、假设类 `F_C` 上定义：
```
U_C = R̂_C + sqrt( log(2/δ) / (2n) ) + 2 R_n(F_C)
      + β_shift · W₁(P_test, P_ref) + γ_OOD · g·(1−p)
```
`GenCert(C)` 有效当且仅当：
```
U_C ≤ ε_C   ∧   Cov ≥ c_min   ∧   b_OOD ≥ b_min
```
其中 `b_OOD` 为预注册 OOD 测试组的通过率。`U_C` 的三项分别对应「采样误差、模型复杂度、分布偏移」；第三项使证书在陌生域自动变厚（更保守），而不是盲目沿用同分布上界。

**新增定义 537（排行榜随机排序 StochasticLeaderboard）**
任务 `t=1..T` 从任务分布 `P_T` 抽取，系统 `a=1..S` 的得分矩阵为 `X_{a,t}`。定义：
```
μ_a(P) = E_{t~P}[ X_{a,t} ]
r_P(a) = 1 + Σ_{b≠a} 1[ μ_b(P) > μ_a(P) ]
```
公开榜用 `P_pub` 的经验均值代替 `μ_a(P_pub)`。名次 `r_P(a)` 是随机变量，不是系统能力的真值；把它当点估计是排行榜误用的根源。

**新增定义 538（排名区间与稳定性半径 RankInterval & StabilityRadius）**
对任务做配对 bootstrap（同一次重采样同时作用于所有系统，保留任务难度相关性）：
```
第 b 次重采样得到 r_b(a)，b=1..B
[r_lo(a), r_hi(a)] = [ Q_{α/2}({r_b(a)}), Q_{1−α/2}({r_b(a)}) ]
```
定义两个 OOD 稳定性量：
```
Inv(P,Q) = 2 / (S(S−1)) · Σ_{a<b} 1[ (r_P(a)−r_P(b)) · (r_Q(a)−r_Q(b)) < 0 ]
Δ_stab(a) = max_{P' ∈ U_ρ^LB} | r_{P'}(a) − r_{P_pub}(a) |
```
其中 `U_ρ^LB` 是以 `P_pub` 为中心、向 `P_ood` 方向混合的排行榜不确定集。认证「前 k 名」需 `r_hi(a) ≤ k`；认证「排名稳定」需 `Inv(P_pub,P_ood) ≤ inv_max` 且 `Δ_stab(a) ≤ s_max`。

**新增定义 539（Goodhart 差距与去膨胀分数 GoodhartGap）**
```
G      = S_pub − max(S_hid, S_ood)
S_eff  = S_pub − λ_G · max(0, G) − λ_D · log(1 + m)
```
`G>0` 表示公开榜分数高于隐藏/OOD 榜，是「对榜单过拟合」的直接信号。`S_eff` 对差距和提交次数同时惩罚，避免「多刷几次就领先」。`S_pub,S_hid,S_ood` 必须是同一指标、同一归一化尺度。

**新增定义 540（任意时刻有效 e 值 AnytimeValidEValue）**
设第 j 次提交相对基线的提升 `Δ_j ∈ [0,1]`，零假设 `H₀: E[Δ_j] ≤ δ₀`，取 `λ_e ∈ [0,1)`：
```
E_m = Π_{j=1}^{m} ( 1 + λ_e (Δ_j − δ₀) )
```
在 `H₀` 下 `E_m` 是非负上鞅，故由 Ville 不等式：
```
P( ∃m : E_m ≥ 1/α ) ≤ α
```
这允许「边看榜边提交、看到显著就停」而不膨胀族错误率；普通固定样本 t 检验做不到这一点。

**新增定义 541（排行榜证书 LeaderboardCertificate）**
```
LBC = ( C, [r_lo,r_hi], Δ_stab, G, S_eff, U_C, Cov, R_sel, E_m, H_ev, T_valid )
```
`LBC` 有效当且仅当以下条件同时成立：
1. `GenCert(C).valid = true`；
2. `r_hi(a) ≤ k`（若主张前 k 名）；
3. `Δ_stab(a) ≤ s_max` 且 `Inv(P_pub,P_ood) ≤ inv_max`；
4. `G ≤ g_max`；
5. `E_m ≥ 1/α`（若主张「显著优于基线」；只报告名次时此条可豁免，但不得写「显著」）；
6. 证据链哈希 `H_ev` 可重放且与预注册一致。

**新增定义 542（OOD 排名反转率 OODRankInversion）**
```
Inv_rate = Inv(P_pub, P_ood)
```
用于回答「换个分布，名次会不会翻车」。`Inv_rate=0` 表示所有系统对排序完全一致；`Inv_rate=1` 表示完全反转。排行榜证书把 `Inv_rate` 作为一等信息披露，而不是只报一个名次。

**新增定义 543（证书失效与漂移触发 CertificateInvalidation）**
`LBC` 在以下任一条件发生时立即失效并降级为 exploratory：
```
参考特征集哈希变化
∨ OOD 报警率落在 [α−ε_α, α+ε_α] 之外
∨ 排名区间宽度 > w_max
∨ U_C > ε_C
∨ Goodhart 差距的单侧置信下界 > g_max
∨ 证据链哈希不匹配
```
失效不是「删除证书」，而是把证书状态改为 `stale`，并触发一次离线重校准；控制回路仍按当前最保守阈值运行。

## 2. 形式化定义（要点）

**定义 493（指标层级闭合 MetricLadder，升级版）** 在 v8 六层基础上增加 `M_OOD`，得到七层 `M=(M₀,M₁,M₂,M₃,M_dom,M_SLAM,M_OOD)`。`M_OOD` 监控 `p_OOD < τ_p`、`R_sel < ε_sel`、`Cov ≥ c_min`，并具备到 M₀ 的退化映射 `δ_OOD`：任一 OOD 条件违背 ⇒ 直接触发 M₀ 硬约束检查。

**定义 494（语音指令类型化 VoiceCommandTyping）** 保留自 v8，不因排行榜评估而改变；排行榜只评估「任务完成与安全」，不进入语音指令解析路径。

**定义 495（奖励可逆向性 RewardDecomposer，升级版）** 风险向量扩展为 6 维：
```
risk(s) = [risk_SEN, risk_SEM, risk_EFF, risk_PERF, risk_SLAM, risk_OOD]
risk_OOD(s) = g_t · (1 − p_t)
```
`risk_OOD` 只在显著离群时非零，避免把「新奇」误判为「危险」。`w'_i(s)=softmax(α·risk_i(s)+β·emo(s)·Ṽ_i)`，`i=0..5`。

**定义 496（软证书 SoftCert，升级版）**
```
δ_trigger = { σ < τ_safe
              ∧ γ_grasp valid
              ∧ Δ_dom < τ_dom
              ∧ risk_SLAM < τ_SLAM
              ∧ risk_OOD < τ_OOD }
```
五个条件同一物理尺度（违背概率上界或风险上界），任一触发 ⇒ 退化到 M₀。`τ_OOD` 由 `α` 与 `c_min` 共同决定，不单独拍脑袋。

**定义 497（MetaWeight 动态调节，升级版）** `w_i(s)=softmax(α·risk(s))_i`，`i=0..5`；风险向量的第 6 维只在 OOD 闸门开启时参与 softmax，闸门关闭时该项为 0，等价 v8 的 5 维。

**定义 521（在线阈值调节 DA-OTL，组合版）**
```
τ_i(t) = clip( τ_i^v8(t) + κ_i·Δ_dom(t) + μ_i·g_t·(1−p_t) + Δ_i^DRO(t), ε_min,i, ε_max,i )
```
其中 `τ_i^v8(t)` 为 v8 的 DA-OTL 输出；`Δ_i^DRO(t) ≥ 0` 为 DRO 收紧增量；`μ_i` 对 M₀/M₁ 取大值，对 M₂/M₃ 取小值。所有新增项非负，保证「只会更保守」。

**定义 526（域偏移量 DomainShift）** 保留自 v8：`Δ_dom(t)=MMD²(φ(s_{t−W+1:t}), φ(s_ref))`。本轮明确其角色是**域级**泛化信号，与样本级 `p_OOD`、组级 `R_DRO` 并列，而不是替代它们。

**定义 527（SLAM 风险分量）** 保留自 v8，`risk_SLAM` 仍是风险向量第 5 维。

**定义 528（标定偏移与一致性图）** 保留自 v8；标定故障会通过 `κ_i` 收紧与传感器降权进入同一阈值链。

**定义 529（域自适应阈值调节）** 保留自 v8，作为本轮的「域级」基线项。

**定义 530（标定故障隔离）** 保留自 v8；本轮不改变其「降权而非硬屏蔽」的语义。

**定义 531（六层软硬约束无缝衔接）** 升级为七层版本：`δ_trigger` 增加 `risk_OOD < τ_OOD`；其余条件与 v8 相同。任一软层违背 → 必经 M₀，无「软通过硬失」空洞。

**新增定义 532–543** 见第 1 节；其中 532–536 属于「部署时泛化」，537–543 属于「评估时泛化」。两组的共同接口是 `H_ev`：排行榜证书引用的参考集、任务集、编码器版本必须与 OOD 校准一致，否则证书直接失效（见定义 543）。

from __future__ import annotations
import numpy as np


class ConformalOODGate:
    """样本级 OOD 闸门：kNN 非一致性 + 保形 p 值 + H 步迟滞。"""

    def __init__(self, encoder, ref_obs, alpha=0.05, k=10, H=3, eps_cov=1e-6):
        self.phi = encoder
        self.phi.eval()
        self.alpha = alpha
        self.k = k
        self.H = H
        self.eps_cov = eps_cov
        self.ref = self._embed(ref_obs)
        self.ref_scores = np.array([self._loo_score(i) for i in range(len(self.ref))])
        self._counter = 0
        self._last_gate = 0

    def _embed(self, obs):
        import torch
        with torch.no_grad():
            z = self.phi(obs)
        return z.flatten(1).cpu().numpy()

    def _score(self, z):
        d = np.linalg.norm(self.ref - z, axis=1)
        return np.partition(d, self.k)[:self.k].mean()

    def _loo_score(self, i):
        d = np.linalg.norm(self.ref - self.ref[i], axis=1)
        d[i] = np.inf
        return np.partition(d, self.k)[:self.k].mean()

    def p_value(self, obs):
        z = self._embed(obs)[0]
        s = self._score(z)
        return (1.0 + np.sum(self.ref_scores >= s)) / (len(self.ref_scores) + 1.0)

    def gate(self, obs):
        p = self.p_value(obs)
        self._counter = self._counter + 1 if p <= self.alpha else 0
        g = int(self._counter >= self.H)
        self._last_gate = g
        return float(p), g


class DistributionallyRobustThreshold:
    """组级 DRO：χ² 不确定集 + 最差组 Hoeffding 上界。"""

    def __init__(self, base_tau, eps_min, eps_max, rho=0.1, delta=0.05, lipschitz=1.0):
        self.base_tau = dict(base_tau)
        self.eps_min = dict(eps_min)
        self.eps_max = dict(eps_max)
        self.rho = rho
        self.delta = delta
        self.lipschitz = lipschitz

    def radius_penalty(self):
        return self.lipschitz * np.sqrt(2.0 * self.rho)

    def worst_group_upper(self, losses_by_env):
        E = max(len(losses_by_env), 1)
        vals = []
        for losses in losses_by_env.values():
            n = max(len(losses), 1)
            mean = float(np.mean(losses))
            vals.append(mean + np.sqrt(np.log(2.0 * E / self.delta) / (2.0 * n)))
        return max(vals) + self.radius_penalty()

    def update(self, losses_by_layer, delta_dom, kappa):
        tau = {}
        for i, losses_by_env in losses_by_layer.items():
            risk_ub = self.worst_group_upper(losses_by_env)
            tau[i] = float(np.clip(
                self.base_tau[i] + kappa[i] * delta_dom + risk_ub,
                self.eps_min[i], self.eps_max[i],
            ))
        return tau


class GeneralizationCertificate:
    """评估级证书：把采样误差、复杂度、分布偏移、OOD 惩罚分开记账。"""

    def __init__(self, delta=0.05, beta_shift=1.0, gamma_ood=0.5):
        self.delta = delta
        self.beta_shift = beta_shift
        self.gamma_ood = gamma_ood

    def upper_bound(self, empirical_risk, n, rademacher, wasserstein, ood_penalty):
        hoeffding = np.sqrt(np.log(2.0 / self.delta) / (2.0 * max(n, 1)))
        return (empirical_risk + hoeffding + 2.0 * rademacher
                + self.beta_shift * wasserstein + self.gamma_ood * ood_penalty)

    def issue(self, claim, empirical_risk, n, rademacher, wasserstein,
              ood_penalty, coverage, c_min, ood_battery_pass, b_min):
        U = self.upper_bound(empirical_risk, n, rademacher, wasserstein, ood_penalty)
        valid = (U <= claim["epsilon"]) and (coverage >= c_min) and (ood_battery_pass >= b_min)
        return {"claim": claim, "U_C": float(U), "valid": bool(valid),
                "coverage": float(coverage), "ood_battery_pass": float(ood_battery_pass)}


class LeaderboardRankCertifier:
    """评估级排名：按任务配对 bootstrap，保留任务难度相关性。"""

    def __init__(self, alpha=0.05, B=2000, seed=2026):
        self.alpha = alpha
        self.B = B
        self.seed = seed

    def certify(self, score_matrix, names):
        X = np.asarray(score_matrix, dtype=float)
        S, T = X.shape
        rng = np.random.default_rng(self.seed)
        ranks = np.zeros((self.B, S), dtype=int)
        for b in range(self.B):
            idx = rng.integers(0, T, size=T)
            means = X[:, idx].mean(axis=1)
            order = np.argsort(-means, kind="stable")
            r = np.empty(S, dtype=int)
            r[order] = np.arange(1, S + 1)
            ranks[b] = r
        lo = np.quantile(ranks, self.alpha / 2.0, axis=0)
        hi = np.quantile(ranks, 1.0 - self.alpha / 2.0, axis=0)
        return {
            names[i]: {"r_lo": float(lo[i]), "r_hi": float(hi[i]),
                       "r_hat": float(ranks[:, i].mean())}
            for i in range(S)
        }


class RankStabilityAnalyzer:
    """OOD 扰动下的排名反转率与稳定性半径。"""

    def __init__(self, n_grid=21):
        self.n_grid = n_grid

    @staticmethod
    def _rank(scores):
        order = np.argsort(-np.asarray(scores), kind="stable")
        r = np.empty(len(order), dtype=int)
        r[order] = np.arange(1, len(order) + 1)
        return r

    @staticmethod
    def _inversion(rp, ro):
        S = len(rp)
        inv = 0
        pairs = 0
        for a in range(S):
            for b in range(a + 1, S):
                pairs += 1
                if (rp[a] - rp[b]) * (ro[a] - ro[b]) < 0:
                    inv += 1
        return inv / max(pairs, 1)

    def inversion_rate(self, pub_scores, ood_scores):
        return self._inversion(self._rank(pub_scores), self._rank(ood_scores))

    def stability_radius(self, pub_scores, ood_scores, s_max=0.1, rho=0.2):
        pub = np.asarray(pub_scores, dtype=float)
        ood = np.asarray(ood_scores, dtype=float)
        r0 = self._rank(pub)
        best = 0.0
        for w in np.linspace(0.0, rho, self.n_grid):
            mix = (1.0 - w) * pub + w * ood
            if self._inversion(r0, self._rank(mix)) <= s_max:
                best = float(w)
            else:
                break
        return best


class GoodhartGuard:
    """反 Goodhart：公开-隐藏-OOD 差距 + e-value 选择校正。"""

    def __init__(self, lambda_G=0.5, lambda_D=0.1, g_max=0.02,
                 alpha=0.05, lam=0.5, delta0=0.0):
        self.lambda_G = lambda_G
        self.lambda_D = lambda_D
        self.g_max = g_max
        self.alpha = alpha
        self.lam = lam
        self.delta0 = delta0
        self.e_value = 1.0
        self.m = 0

    def update(self, s_pub, s_hid, s_ood, delta_j):
        self.m += 1
        gap = float(s_pub) - max(float(s_hid), float(s_ood))
        factor = 1.0 + self.lam * (float(delta_j) - self.delta0)
        self.e_value *= max(factor, 1e-12)
        s_eff = (float(s_pub) - self.lambda_G * max(0.0, gap)
                 - self.lambda_D * np.log1p(self.m))
        return {
            "G": gap,
            "S_eff": float(s_eff),
            "E_m": float(self.e_value),
            "gap_ok": gap <= self.g_max,
            "improvement_significant": self.e_value >= 1.0 / self.alpha,
        }


def build_leaderboard_certificate(claim, score_matrix, names, hidden_scores,
                                  ood_scores, gen_cert, rank_cert, rsa, gg,
                                  empirical_risk, n, rademacher, wasserstein,
                                  ood_penalty, coverage, c_min, ood_battery_pass,
                                  b_min):
    """离线评估入口：不进入 50Hz 控制路径。"""
    ci = rank_cert.certify(score_matrix, names)
    pub = np.asarray(score_matrix, dtype=float).mean(axis=1)
    inv = rsa.inversion_rate(pub, ood_scores)
    stab = rsa.stability_radius(pub, ood_scores, s_max=claim.get("s_max", 0.1))
    gg_out = gg.update(pub[0], hidden_scores[0], ood_scores[0], claim["delta"])
    gen = gen_cert.issue(claim, empirical_risk, n, rademacher, wasserstein,
                         ood_penalty, coverage, c_min,
                         ood_battery_pass, b_min)
    valid = (gen["valid"] and ci[names[0]]["r_hi"] <= claim["k"]
             and stab >= claim.get("s_min", 0.1)
             and inv <= claim.get("inv_max", 0.1)
             and gg_out["gap_ok"])
    if claim.get("superiority", False):
        valid = valid and gg_out["improvement_significant"]
    return {"LBC_valid": bool(valid), "rank": ci[names[0]],
            "Delta_stab": float(stab), "Inv_rate": float(inv),
            "Goodhart": gg_out, "GenCert": gen,
            "H_ev": claim.get("H_ev"), "alpha": rank_cert.alpha}


def metricvoicegauge_round_1(M, s, obs, audio_stream=None, ell=None,
                             ood_gate=None, dro=None):
    """50Hz 主路径：v8 核心 + OOD 闸门 + DRO 收紧；排行榜证书离线。"""
    p_ood, g_ood = (1.0, 0)
    if ood_gate is not None:
        p_ood, g_ood = ood_gate.gate(obs)

    tau_v8 = M.metric_ladder.da_otl_thresholds()  # v8 DA-OTL 输出
    if g_ood and dro is not None:
        tau = dro.update(M.layer_losses(), M.delta_dom, M.kappa)
    else:
        tau = tau_v8

    risk_ood = float(g_ood) * (1.0 - float(p_ood))
    risk_6d = np.array([*M.reward_decomposer._compute_risk(M.env.state), risk_ood])

    C, spatial_cert, claims, metrics, rewards = M.metricvoicegauge_round_8(
        M, s, obs, audio_stream, ell=ell,
        tau_override=tau, risk_override=risk_6d,
    )
    claims = list(claims) + [{
        "claim": "risk_OOD_bounded",
        "p_ood": float(p_ood),
        "g_ood": int(g_ood),
        "tau": float(tau.get(6, np.inf)),
    }]
    return C, spatial_cert, claims, metrics, rewards

## 4. 推导

**引理 82（保形闸门的误报与退化风暴上界）**
在参考样本与测试样本可交换的假设下，由定义 532 的保形构造，`P(p(z) ≤ α) ≤ α`。若闸门要求连续 `H` 帧显著才置 `g=1`，则任意长度 `T` 的窗口内，虚假开闸次数的期望不超过 `αT/H`（把每次「连续 H 帧全显著」视为一个超几何尾事件，或用 e-value 版本得到 anytime 界）。因此 v8 中「感知抖动 → 每帧收紧 → 退化风暴」的期望频率被显式压到 `α/H` 量级；代价是真实 OOD 的检测延迟最多增加 `H−1` 帧。若分布偏移破坏可交换性，则 `p` 只作为新颖度分数，界退化为启发式；此时必须依赖 DRO 的组级上界，而不能只靠 COG。

**引理 83（DRO 阈值的保守性）**
设损失 `ℓ ∈ [0,1]`，各组样本独立，`n_e` 为第 e 组样本数。由 Hoeffding 不等式与对 `E` 个组的 union bound，以概率至少 `1−δ`，对所有 e 同时有：
```
R_e(θ) ≤ R̂_e(θ) + sqrt( log(2E/δ) / (2 n_e) )
```
又对任意 `Q∈U_ρ`，由 χ² 变分表示，存在与 `Q` 对应的重加权，使得
```
E_Q[ℓ] ≤ max_e E_{P_e}[ℓ] + L_ℓ · sqrt(2ρ)
```
两式相加即得 `R_DRO(θ) ≤ R̂_DRO^+(θ)`。因此用 `R̂_DRO^+` 反解的 `τ_i^DR` 是真实最差组风险的保守上界；`ρ→0` 时半径项消失，退化为 v8 的最差组（近似平均）校准。`R̂_DRO^+` 对 `ρ` 单调不降，故阈值只会随不确定集变大而变严或不变。

**引理 84（排名区间的覆盖性）**
把任务得分视为 iid 抽样，系统均值为 `μ_a`，名次 `r` 是均值的连续泛函（在无并列的连续分布下）。任务级配对 bootstrap 对均值向量一致，连续映射定理给出名次分布的 bootstrap 一致性；percentile 区间 `[r_lo,r_hi]` 的渐近覆盖率为 `1−α`。有限样本下，用 `B≥2000` 并报告区间宽度；若宽度 `> w_max`，定义 543 直接使证书失效，而不是假装精确。若任务分布非平稳（OOD），bootstrap 只覆盖 `P_pub` 内的抽样不确定性，必须叠加定义 538 的 `Δ_stab` 才完整。

**引理 85（Goodhart 差距的检验性质）**
若 `P_pub = P_hid = P_ood` 且各榜使用同一指标，则 `E[G] = E[S_pub] − E[max(S_hid,S_ood)] ≤ 0`。以 `G` 的单侧 bootstrap 置信下界做检验：若下界 `>0`，则在显著性水平 α 下拒绝「三榜同分布」。这只能说明「公开榜与隐藏/OOD 榜存在系统差异」，不能单独证明差异来自过拟合；因此 LBC 把它与 e-value、任务轮换记录、证据链哈希一起使用，形成多证据判定，而不是单指标定罪。

**引理 86（任意时刻有效选择校正）**
在零假设 `H₀: E[Δ_j] ≤ δ₀` 下，`E[1+λ_e(Δ_j−δ₀)] = 1+λ_e(E[Δ_j]−δ₀) ≤ 1`。由于 `λ_e∈[0,1)` 且 `Δ_j∈[0,1]`，每个因子非负，故 `E_m` 是非负上鞅。由 Ville 不等式，`P(∃m: E_m ≥ 1/α) ≤ α`。这保证「边看榜边调参边提交」的任意停止策略不会把虚假提升的族错误率抬高到 α 以上；代价是 e-value 对真实提升的检测功效低于固定样本检验，需要更多提交或更强的真实效应。

**引理 87（选择风险分解）**
若 `Cov = E[g] ≥ c_min`，则
```
R_sel = E[ℓ·g] / E[g] ≤ E[ℓ] / c_min = R / c_min
```
因此只要基础风险 `R ≤ ε` 且覆盖率不低于 `c_min`，选择风险就被 `ε/c_min` 控制。这条引理解释了为什么 `M_OOD` 必须同时监控覆盖率和选择风险：只压选择风险会让闸门趋向于「全部弃权」，只压覆盖率会让闸门形同虚设。

**引理 88（组合退化无安全空洞）**
设 v8 阈值为 `τ^v8`，本轮阈值为 `τ^new = clip(τ^v8 + κΔ_dom + μ g(1−p) + Δ^DRO, ε_min, ε_max)`。对 M₀/M₁，`κ,μ≥0`、`Δ_dom≥0`、`g(1−p)≥0`、`Δ^DRO≥0`，故 `τ^new ≥ τ^v8`，即本轮只可能更早触发 M₀ 硬检查。若 COG 失效，`g≡0`；若 DRT 失效，`Δ^DRO≡0`；两者同时失效时 `τ^new = clip(τ^v8)`，逐位等价 v8。LRC/RSA/GG/FTS 只写评估命名空间，不写控制命名空间，故其失效不改变控制行为。由此任意子集失效都对应一个明确的 v8 子路径，无级联副作用。

## 8. 本轮最大风险

**一句话**：如果 OOD 参考集与排行榜任务共享同一批数据/分布（评估泄漏），那么 OOD 闸门与排名证书会互相自我确认——系统在榜上名次稳定、证书齐全，却在真正的新分布上同时失去告警与排名有效性；这是「评估泄漏」而非「算法失效」，也最难被常规消融发现。
