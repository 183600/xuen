# 第 55 轮（承接第 54 轮 v16++ GroundEdge-GenSim+++；灵感循环第 1 轮；本轮灵感：「模型蒸馏」×「场景驱动创新」）

> 第 54 轮把技能组合推进为「动作空间剖面 ACS + 组合图 SCOM + 云边协同 CEC + 联合证书 AEC/JTC」。本轮把「云端大教师 → 边端小学生」的知识转移纳入同一证书体系，并用「场景」同时充当蒸馏的采样算子与验收算子。核心矛盾：**H22**：教师技能的动作剖面 `α^T` 与鲁棒谱 `ρ^T` 不能通过普通 KD 无损传递，学生常「答案对但动作覆盖窄、鲁棒性塌陷」；**H23**：以 i.i.d. 数据蒸馏优化的是平均场景，而长尾部署场景恰是学生失真最严重处，平均指标会掩盖系统性失效。

## 0. 直觉与动机

**灵感 1（蒸馏的不是答案，而是动作-鲁棒性证书）**
直觉：普通蒸馏对齐的是输出分布 `p(y|x)`；但第 54 轮的技能本质是三元组 `(α_S, ρ_S, J_S)`。因此蒸馏目标应是——学生**覆盖教师的动作核心区 `A_core^T`、在维度谱上不塌陷、并能签发可验证证书**。答案一致只是必要条件，不是充分条件。若只对齐输出，学生可以在训练集上 99% 一致，却在 `A_core^T` 的边缘动作上完全不可达，这种「证书不保持的蒸馏」在边端部署时是隐形的。→ **证书保持蒸馏 CPD**。

**灵感 2（场景驱动：场景是采样算子，也是验收算子）**
直觉：与其在全体数据上均匀蒸馏，不如按部署场景分布 `p_Z` 重新加权，把有限算力花在真实会遇到的场景与长尾。更进一步，场景不只决定「蒸馏什么」，还决定「何时算蒸馏成功」：验收必须在场景采样上做，而不是在训练集上。这把蒸馏从「离线精度最大化」变成「场景条件成功率最大化」。→ **场景驱动蒸馏 SDD**。

**灵感 3（可蒸馏性剖面与蒸馏组合）**
直觉：并非所有云端技能都值得蒸馏到边端。动作空间越紧凑、场景越集中、教师越冗余的技能，可蒸馏性越高；反之应保留云端或走 hybrid。于是把第 54 轮的组合图 `G_S` 扩展为「云 C / 边 E / 混合 H」的**路由组合 DPR**，在边端预算 `B_e`（参数量、延迟、内存）下做带证书的多选背包，而不是「能蒸尽蒸」。

**灵感 4（场景创生闭环：用失败解释生成新场景）**
直觉：场景驱动创新不是被动采样，而是把边端 `Explain` 的失败根因当作变异算子，生成「物理合法但教师没覆盖好」的新场景 `z'`，再回炉蒸馏。创新由此变成可度量的：新场景带来的成功增益 `Δ`，就是场景驱动创新的价值。但必须防「为新颖而生成不可行场景」的伪创新——变异场景必须先过物理可行性阀。→ **SGI + 保真阀**。

**灵感 5（金字塔叠加场景-蒸馏层 𝔻）**
直觉：在 `𝕃`（鲁棒性）与 `𝔸`（动作空间）之上叠加 `𝔻`：`𝔻_0` 数据/场景分布，`𝔻_1` 蒸馏目标，`𝔻_2` 师生间隙，`𝔻_3` 证书保持与路由。跨层证书必须同时携带 `ρ`、`A_cert` 与蒸馏间隙 `G`，否则「教师能做的学生也能做」只是一句口号。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（场景模式与场景分布）**
场景 `z = (T_z, c_z, δ_z, κ_z)`，其中 `T_z` 为任务、`c_z` 为上下文、`δ_z` 为扰动、`κ_z` 为物理/安全约束。场景空间 `Z`，部署分布 `p_Z`，经验场景集 `Z_n ~ p_Z`。部署覆盖率 `cov_Z(Π) = P_{z~p_Z}[z ∈ dom(Π)]`；长尾集 `Z_tail = {z : p_Z(z) ≤ ε_tail}`。

**定义 122（师生技能对与蒸馏间隙）**
师生技能对 `(S^T, S^s)`，蒸馏间隙 `G = (D_fid, Δα, Δρ, Δ_cert)`：
- 场景一致率 `D_fid = E_{z~p_Z}[ 1(y^T(z)=y^s(z)) ]`；
- 动作覆盖损失 `Δα = max_{a∈A_core^T} max(0, α^T(a) - α^s(a))`；
- 鲁棒性损失 `Δρ(d) = max(0, ρ^T(d) - ρ^s(d))`，`∀d ∈ 𝔇_ρ`；
- 证书损失 `Δ_cert = 1[ J^s ⊭ J^T on dom(J^T) ∩ dom(J^s) ]`。

**定义 123（证书保持蒸馏 CPD）**
称学生 `S^s` 对教师 `S^T` 是 **CP-sound** 的，当且仅当存在阈值 `(θ_fid, ε_a, ε_ρ)` 使
```
D_fid ≥ θ_fid ∧ Δα ≤ ε_a ∧ Δρ(d) ≤ ε_ρ ∀d ∧ Δ_cert = 0 ∧ dom(J^T) ⊆ dom(J^s)
```
直观：学生不仅「答得像」，而且「动作盖得住、鲁棒不塌、证书能签」。

**定义 124（场景驱动蒸馏目标）**
场景重加权课程 `q_Z(z) ∝ p_Z(z)^{1-β} · novel(z)^{β} · hard(z)^{γ}`，其中 `novel` 为相对训练场景的新颖度、`hard` 为教师在场景上的不确定度。蒸馏目标：
```
L_SDD = E_{z~q_Z}[ ℓ_task(S^s;z) ]
      + λ_kd · E_{z~q_Z}[ KL(p^T(·|z) ‖ p^s(·|z)) ]
      + λ_a · L_α(α^s, α^T) + λ_ρ · L_ρ(ρ^s, ρ^T) + λ_c · L_cert(J^s, J^T)
```
`β,γ` 由场景覆盖率与长尾占比控制：`β→0` 退化为纯部署分布蒸馏，`β→1` 退化为纯新颖性探索。

**定义 125（场景创生算子与创新分）**
基于 Explain 的变异算子 `M: Z × E → 2^Z`，输入失败场景与其根因 `e`，输出候选变异场景。合法性 `valid(z') = 1[κ_{z'} 可满足]`。场景创新分：
```
I(z') = novelty(z') · valid(z') · transfer(z'; S^s)
```
仅当 `valid(z') ≥ θ_v` 且 `transfer(z') > 0` 才允许进入蒸馏回炉，防止不可行或纯对抗的伪创新。

**定义 126（蒸馏部署组合与可蒸馏性）**
对每个技能 `S` 选择路由 `r(S) ∈ {C, E, H}`（云端保留 / 边端蒸馏 / 混合）。组合 `Π = {(S, r(S))}` 受约束：
```
Σ_{r(S)∈{E,H}} cost_edge(S) ≤ B_e,   cov_Z(Π) ≥ θ_cov,   每条边端技能 CP-sound
```
可蒸馏性 `distill(S) = g( α 紧凑度, 场景集中度, 教师冗余度, 鲁棒谱平坦度 )`，用于背包排序而非硬阈值。

## 2. 关键算法 伪代码

### IP-121 SDD（Scenario-Driven Distillation）

```python
def scenario_weighted_sampler(z_pool, p_Z, novel, hard, beta, gamma):
    w = {z: (p_Z(z) ** (1-beta)) * (novel(z) ** beta) * (hard(z) ** gamma)
         for z in z_pool}
    total = sum(w.values())
    return {z: w[z] / total for z in z_pool}

def scenario_driven_distill(teacher, student, z_pool, steps):
    for step in range(steps):
        q = scenario_weighted_sampler(z_pool, pZ, novelty, hardness, beta, gamma)
        batch = sample(z_pool, q, n_batch)
        loss = task_loss(student, batch) \
             + lam_kd * kd_loss(student, teacher, batch) \
             + lam_a * action_loss(student.alpha, teacher.alpha, batch) \
             + lam_r * robust_loss(student.rho, teacher.rho) \
             + lam_c * cert_loss(student.cert, teacher.cert)
        student.update(loss)
    return student
```

### IP-122 CPD（Certificate-Preserving Distillation check）

```python
def cpd_check(student, teacher, pZ, theta_fid, eps_a, eps_rho):
    D_fid = scenario_agreement(student, teacher, pZ)
    delta_alpha = max(0.0, max(teacher.alpha[a] - student.alpha[a]
                             for a in teacher.A_core))
    delta_rho = {d: max(0.0, teacher.rho[d] - student.rho[d])
                 for d in teacher.rho}
    if D_fid < theta_fid: return ('reject', 'fidelity', D_fid)
    if delta_alpha > eps_a: return ('reject', 'action_gap', delta_alpha)
    if any(v > eps_rho for v in delta_rho.values()):
        return ('reject', 'robust_gap', delta_rho)
    if not cert_implies(student.cert, teacher.cert):
        return ('reject', 'cert_not_preserved')
    return ('ok', G(D_fid, delta_alpha, delta_rho, 0.0))
```

### IP-123 SGI（Scenario Generation & Innovation）

```python
def scenario_innovate(explain_events, pZ, theta_v, budget):
    candidates = []
    for (z, e) in explain_events:
        for z2 in mutate(z, e):              # 围绕失败根因做受约束变异
            if validity(z2) < theta_v:       # 物理/安全阀
                continue
            score = novelty(z2) * validity(z2) * transfer_estimate(z2)
            if score > 0:
                candidates.append((score, z2))
    return topk(candidates, budget)
```

### IP-124 DPR（Distillation Portfolio Router）

```python
def distill_portfolio(skills, B_e, theta_cov):
    items = []
    for S in skills:
        for r in ('E', 'H'):
            cost = edge_cost(S, r)
            gain = expected_scenario_gain(S, r) * distillability(S)
            items.append((S, r, gain, cost))
    selected = multi_choice_knapsack(items, B_e)   # 每技能至多选一个 r
    Pi = selected + [(S, 'C') for S in skills if S not in selected]
    if scenario_coverage(Pi) < theta_cov:
        return ('reject', 'coverage', Pi)
    if not all(cpd_check(S, S.teacher, pZ, ...) == 'ok'
               for (S, r) in Pi if r in ('E', 'H')):
        return ('reject', 'cp_unsound', Pi)
    return ('ok', Pi)
```

### IP-125 SGA（Scenario Gap Auditor）

```python
def scenario_gap_audit(pZ_deploy, q_train, Z_grid):
    gap = {}
    for z in Z_grid:
        gap[z] = max(0.0, pZ_deploy(z) - q_train(z))
    mass = sum(gap.values())
    hot = sorted(gap.items(), key=lambda kv: -kv[1])[:k]
    return ('ok', mass, hot)   # 回灌给 SDD 的 q_Z 与 SGI 的 novelty
```

### IP-126 SJC（Scenario-Joint Certificate）

```python
def scenario_joint_certificate(S, Pi, G_dist, cov_Z):
    if S.routing == 'E' and not cpd_check(S, S.teacher, pZ, ...) == 'ok':
        return ('reject', 'distill_gap')
    if cov_Z < theta_cov:
        return ('reject', 'scenario_coverage')
    J_D = JointCert(
        rho   = compose_robustness_chain(S, K),
        A_cert= (S.A_core, buffer_zone(S.A_core, S.delta_a)),
        gamma_ce = S.gamma_ce,
        G     = G_dist,
        cov_Z = cov_Z,
        routing = Pi[S],
    )
    return ('ok', J_D)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| SDD | `O(N_scen·|A|·|π|)`/epoch | `O(|A| + N_scen)` | 场景权重归一、长尾不丢 |
| CPD | `O(|A_core| + |𝔇_ρ| + N_val)` | `O(|A|)` | 间隙四元组完备、证书蕴含可判 |
| SGI | `O(|E|·|M|·|Z|)` | `O(|Z|)` | 变异合法、创新分可估 |
| DPR | `O(|S|·|R|·B_e)`（背包 DP） | `O(|S|·B_e)` | 预算闭合、覆盖率约束 |
| SGA | `O(|Z_grid| log|Z_grid|)` | `O(|Z_grid|)` | 部署分布可采样、gap 非负 |
| SJC | `O(|S|·(|A|+|𝔇_ρ|))` | `O(|A|)` | 联合证书 sound、路由一致 |

**正确性定理（Scenario-Conditioned Distillation Soundness）**
假设第 54 轮 `(A26)–(A28)` 成立；**(A29)** 部署场景支撑被训练场景覆盖，协变量偏移为 `d_TV(p_Z, q_train) ≤ Δ_Z`；**(A30)** 在场景集上一致偏差满足 PAC 界（`n` 个样本、置信 `1-δ`）；**(A31)** 场景变异合法率 `valid ≥ θ_v`，非法变异不进入蒸馏。则对任意 `z ~ p_Z`，以概率 `≥ 1-δ`：
```
P(success | z) ≥ 1 - (1 - D_fid) - Σ_d Δρ(d) - P(Δα > ε_a)
                   - Δ_Z - sqrt( (log|Z| + log(1/δ)) / (2n) )
```
关键：**证书保持把「平均精度蒸馏」改成「场景条件可部署性」**；场景偏移项 `Δ_Z` 是新的、不可省的代价。

## 4. 实验设计 E162–E166

| 实验 | 指标 | 目标 |
|---|---|---|
| E162 蒸馏间隙随场景数 | `D_fid`、`Δα`、`Δρ` vs `n` | `D_fid ≥ 0.95`，`Δα ≤ 0.05` |
| E163 证书保持率 | CP-sound 比例 vs `λ` 权重 | CP-sound ≥ 90%，虚假 sound ≤ 2% |

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 场景分布设定错误（`p_Z` 偏差） | 高 | 多源场景采样 + SGA 持续审计 + 保守覆盖阈值 |
| 把平均一致误当证书保持 | 高 | CPD 四元组硬门禁 + 虚假 sound 红队测试 |
| 教师-学生容量差导致长尾塌陷 | 高 | 长尾重加权 + 混合路由 H + 教师残差蒸馏 |
| 变异场景不可行/纯对抗 | 中 | 合法性阀 + `transfer>0` + 人工抽检 |
| 背包组合爆炸 | 中 | 可蒸馏性排序 + 分层预算 + 贪心上界剪枝 |
| 蒸馏导致技能同质化/负迁移 | 中 | 路由多样性约束 + 负迁移绊线 + 回滚 |

## 6. 本轮最大风险

**一句话**：场景驱动蒸馏把「平均对齐」升级为「场景条件证书保持」，但其 soundness **同时依赖部署场景分布 `p_Z` 的可观测性、师生间隙 `G` 的无偏估计、以及变异场景的物理合法性**；一旦 `p_Z` 被错设或 SGA 采样不足，学生会在「自认为覆盖」的场景上签发虚假证书，并在真实长尾处系统性失效——故必须以 **多源场景审计 + CPD 硬门禁 + 非法场景一票否决** 三重护栏，宁可少蒸一个技能，也绝不把「场景自洽」当成「部署为真」。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-SceneDistill（SDD×CPD×SGI×DPR×SGA×SJC）

> 承接第 54 轮产物 v31（GroundEdge-GenSim+++）。本轮在「动作空间 + 云边协同 + 联合证书」之上，增加 **场景驱动的模型蒸馏** 层：
> - **SDD（Scenario-Driven Distillation）**：把场景分布作为蒸馏采样算子，长尾/新颖/困难场景重加权；
> - **CPD（Certificate-Preserving Distillation）**：用四元间隙 `G=(D_fid,Δα,Δρ,Δ_cert)` 判定学生是否保持教师证书；
> - **SGI（Scenario Generation & Innovation）**：用 Explain 根因变异场景，创新分 `I(z)` 可度量；
> - **DPR（Distillation Portfolio Router）**：在边端预算下做 `C/E/H` 路由的多选背包；
> - **SGA（Scenario Gap Auditor）**：审计训练场景与部署场景的 gap 并回灌；
> - **SJC（Scenario-Joint Certificate）**：把蒸馏间隙、场景覆盖率与路由并入联合证书。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-115/117/118/120 以纳入场景-蒸馏维度。

```python
def scenario_weighted_sampler(z_pool, p_Z, novel, hard, beta, gamma):
    w = {z: (p_Z(z) ** (1-beta)) * (novel(z) ** beta) * (hard(z) ** gamma)
         for z in z_pool}
    total = sum(w.values())
    return {z: w[z] / total for z in z_pool}

def scenario_driven_distill(teacher, student, z_pool, pZ, steps):
    for _ in range(steps):
        q = scenario_weighted_sampler(z_pool, pZ, novelty, hardness, beta, gamma)
        batch = sample(z_pool, q, n_batch)
        loss = task_loss(student, batch) \
             + lam_kd * kd_loss(student, teacher, batch) \
             + lam_a  * action_loss(student.alpha, teacher.alpha, batch) \
             + lam_r  * robust_loss(student.rho, teacher.rho) \
             + lam_c  * cert_loss(student.cert, teacher.cert)
        student.update(loss)
    return student
```

### IP-122 CPD

```python
def cpd_check(student, teacher, pZ, theta_fid, eps_a, eps_rho):
    D_fid = scenario_agreement(student, teacher, pZ)
    delta_alpha = max(0.0, max(teacher.alpha[a] - student.alpha[a]
                             for a in teacher.A_core))
    delta_rho = {d: max(0.0, teacher.rho[d] - student.rho[d])
                 for d in teacher.rho}
    if D_fid < theta_fid:                       return ('reject', 'fidelity', D_fid)
    if delta_alpha > eps_a:                     return ('reject', 'action_gap', delta_alpha)
    if any(v > eps_rho for v in delta_rho.values()):
        return ('reject', 'robust_gap', delta_rho)
    if not cert_implies(student.cert, teacher.cert):
        return ('reject', 'cert_not_preserved')
    return ('ok', G(D_fid, delta_alpha, delta_rho, 0.0))
```

```python
def scenario_innovate(explain_events, pZ, theta_v, budget):
    candidates = []
    for (z, e) in explain_events:
        for z2 in mutate(z, e):
            if validity(z2) < theta_v:          # 物理/安全阀：一票否决
                continue
            score = novelty(z2) * validity(z2) * transfer_estimate(z2)
            if score > 0:
                candidates.append((score, z2))
    return topk(candidates, budget)
```

```python
def distill_portfolio(skills, B_e, theta_cov, pZ):
    items = []
    for S in skills:
        for r in ('E', 'H'):
            items.append((S, r,
                          expected_scenario_gain(S, r) * distillability(S),
                          edge_cost(S, r)))
    selected = multi_choice_knapsack(items, B_e)       # 每技能至多一个 r
    Pi = selected + [(S, 'C') for S in skills if S not in selected]
    if scenario_coverage(Pi) < theta_cov:
        return ('reject', 'coverage', Pi)
    for (S, r) in Pi:
        if r in ('E', 'H') and cpd_check(S, S.teacher, pZ, ...)[0] != 'ok':
            return ('reject', 'cp_unsound', S)
    return ('ok', Pi)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SDD | `O(N_scen·|A|·|π|)`/epoch | `O(|A|+N_scen)` | 权重归一、长尾不丢 |
| CPD | `O(|A_core|+|𝔇_ρ|+N_val)` | `O(|A|)` | 四元组完备、证书蕴含可判 |
| SGI | `O(|E|·|M|·|Z|)` | `O(|Z|)` | 变异合法、创新分可估 |
| DPR | `O(|S|·|R|·B_e)` | `O(|S|·B_e)` | 预算闭合、覆盖约束、CP 硬门禁 |
| SGA | `O(|Z_grid| log|Z_grid|)` | `O(|Z_grid|)` | 部署分布可采样、gap 非负 |
| SJC | `O(|S|·(|A|+|𝔇_ρ|))` | `O(|A|)` | 联合证书 sound、路由一致 |

**正确性定理（Scenario-Conditioned Distillation Soundness）**
假设第 54 轮 `(A26)–(A28)` 成立；**(A29)** `d_TV(p_Z, q_train) ≤ Δ_Z`；**(A30)** 场景集上一致偏差满足 PAC 界（`n` 样本、置信 `1-δ`）；**(A31)** 变异合法率 `valid ≥ θ_v`，非法变异不入蒸馏。则对任意 `z ~ p_Z`，以概率 `≥ 1-δ`：
```
P(success | z) ≥ 1 - (1 - D_fid) - Σ_d Δρ(d) - P(Δα > ε_a)
                   - Δ_Z - sqrt( (log|Z| + log(1/δ)) / (2n) )
```
要点：**证书保持蒸馏**把目标从「平均精度」改为「场景条件可部署性」；`Δ_Z` 为协变量偏移的不可省代价，必须由 SGA 显式审计。

## 6. 本轮最大风险

**一句话**：场景驱动蒸馏把「平均对齐」升级为「场景条件证书保持」，但其 soundness **同时依赖部署场景分布 `p_Z` 的可观测性、师生间隙 `G` 的无偏估计、以及变异场景的物理合法性**；一旦 `p_Z` 被错设或 SGA 采样不足，学生会在「自认为覆盖」的场景上签发虚假证书，并在真实长尾处系统性失效——故必须以 **多源场景审计 + CPD 硬门禁 + 非法场景一票否决** 三重护栏，宁可少蒸一个技能，也绝不把「场景自洽」当成「部署为真」。
