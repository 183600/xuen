# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 4 轮；本轮灵感：「因果推理」×「安全性」）

> 第 57 轮把安全的赌注从"模型置信"换到"证据质量"，又用元先验、跨模态对账、个性化信任三层把它撑住；但它有三条从未被点破的隐含假设：**(a) 证据都是观测**——地图由保守策略自己走出来，探针虽然在物理上是干预，却被当作普通观测去更新后验，于是"从未失败"可能只是"从未在困难条件下试过"，选择偏差让关联不可外推到反事实；**(b) 一致即独立**——跨模态一致被当作独立佐证，但一致完全可能来自共同原因（同一物理欺骗同时通过视觉与触探的共享通道），统计不相关不等于因果 d-分离；**(c) 归责靠启发式**——事后证伪只是"发现谁错了就给谁乘性降权"，既可能冤枉真正正确的模态，也可能放过真正的因果元凶。本轮两个灵感各补一刀：**因果推理**把探针重新理解为干预、把先验的可迁移性换成跨环境不变性、把跨模态独立换成 d-分离、把归责换成反事实责任；**安全性**把安全从"对世界的断言"改写为"对干预集合的断言 + 未辨识即保守"。核心命题由"证据说可信"升级为 **"干预可识别、机制可迁移、共因可分离、责任可归因的因果安全"**。

核心矛盾：
- **H29（观测 vs 干预）**：安全需要回答"如果我这样落脚会怎样"，而历史证据是"我上次那样落脚没出事"；后者被部署策略的选择偏差污染，前者只有在探针被当作 `do(·)` 时才可能被识别——把观测当因果，等于用幸存者样本给不可逆接触背书。
- **H30（因果模型 vs 无模型安全）**：因果推断要求 DAG 正确、无未观测混杂；而前 57 轮的全部努力恰恰是"不把安全押在模型上"。因果层把赌注从"先验质量"移到"因果结构正确性"——一个自信而错误的 SCM 会产出看起来严谨、实则建立在错误干预模型上的安全证书。
- **H31（一致 vs 共因）**：第 57 轮 EV-xmodal 把跨模态一致当独立证据；但两个模态可以因共享共同原因而同向，伪一致会以"双保险"的形式把单点错误放大成"独立复现"。独立性必须是因果的，不是统计的。

## 0. 直觉与动机

**灵感 1（因果推理 → 探针即干预，证据分两层）**
直觉：前 57 轮把探针当成"多看了世界一眼"，但探针真正的身份是**机器人亲手做的实验**。实验和观察的区别就是因果推断的全部：观测受部署策略选择偏差（只在看起来安全处落脚）与共同原因污染，干预则在设计上无混杂。所以先把证据分成 O-证据（到访/被动观测，需倾向加权/后门调整才能用）与 I-证据（探针= `do(·)`，可直接识别干预分布）。规则很硬：**只有 I-证据（或其部分识别界）才有资格签发"若采取 u 则安全"的干预性声明**；O-证据只能更新关联信念，不能进入不可逆承诺的必要因果前提。这一刀把第 57 轮"探针次数 k_probes"从预算问题变成**可识别性问题**。

**灵感 2（因果推理 → 不变性即可迁移性，TIP 替代摊销先验的质量赌注）**
直觉：第 57 轮的元先验从全体区域史摊销，看似省样本，实则把"湿季的湿滑""轻载下的稳定"这类环境特异关联也一起摊销了——换到旱季或重载，先验就成了系统性偏差源，而且它错得很自信。因果不变性给出一个可证伪的准入条件：**只有跨环境保持不变的条件机制才允许跨区摊销**（不变因果预测/不变风险最小化）。不变性是"可运输性"的证书，也是先验的照妖镜：不变性检验一失败，该模块立刻被踢出摊销集合、退回共形带。第 57 轮 OOD 门查的是"输入像不像训练分布"，TIP 查的是"机制是不是跨环境不变"——前者防新输入，后者防伪相关。

**灵感 3（因果推理 → 因果对账，d-分离替代统计独立）**
直觉：两个模态"都说是干的"可以有两种解释：真相是干的（真一致），或有一个共同原因同时骗过它们（伪一致）。第 57 轮只看到"同侧"，看不到背后的图。因果对账问的是图上的问题：在干预上下文与融合信念给定时，两个模态是否 **d-分离**？若存在未阻断的后门路径（共享共同原因），则它们的一致至多算一次观测，不产生独立性增益，并触发共因告警。这把 EV-xmodal 从"一致性证据"升级为"**因果独立性证据**"——只有 d-分离下的同侧才能顶替一次佐证。

**灵感 4（因果推理 → 反事实归责，替代启发式降权）**
直觉：出事之后第 57 轮的做法是"哪个模态的预测与实测相反就降哪个"，这在共因场景下会冤枉人、也会放过元凶。因果归责问的是反事实：**若没有这条证据（或这个模态/这次标注），结果会不会不同？**——用 SCM 上的 `E[Y_{do(¬E_s)} − Y]` 或 Shapley 分摊给每条证据源，并诚实标注识别状态（identified / bounded / unidentifiable）。只有被判为因果责任且方向为正的源才降 ρ；不可识别时不指控单一源，而是整体降档并把区域标为"因果未辨识"。归责从启发式变成可审计、可解释、可申诉的因果推理。

**灵感 5（安全性 → 因果安全包络 + 干预型 VOI）**
直觉：安全不是"我相信世界是安全的"，而是"我承诺采取的所有干预都不会把人/机带进坏集合"：`Safe(π) ⇔ ∀do(u)∈𝒰_adm, P(Y∈Y_bad|do(u),b_r) ≤ δ_f`。于是探询的价值也应改写成对**当前承诺动作的因果效应**的信息增益（iVOI），探针优先选择能切断后门路径、识别效应符号的干预（在安全上限内小范围随机化步态/载荷/接触力），而不是把同一模态问五遍。不可识别的效应只给部分识别界，承诺按**最坏上界**判定；若坏结果到可干预变量的因果路径根本不可识别，则该区域按 OOD 保守处理——禁止不可逆承诺，只能观测/绕行/协商。探针即实验、实验即识别、识别才承诺、不识别就保守。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（因果表面模型 CSM 与证据分层）** 对每区域 r 维护部分可识别结构因果模型 𝒢_r=(V,E,F,P_U)，V={地材 m、湿度 w、坡度 s、步态 g、接触力 f_c、载荷 ℓ、滑移/沉陷 y、…}，U 为未观测混杂（含部署策略的选择偏差）。机器人只保留：(i) 与观测+干预数据一致的 DAG 等价类 `[𝒢_r]`（CPDAG/PAG，不假装知道唯一 DAG）；(ii) 可识别的干预分布 `P(y|do(g),do(f_c),do(ℓ),ctx)`；(iii) 不可识别效应的部分识别界 `[L_r,U_r]`（自然界/Manski 界）。证据分层：**O-证据**（到访、被动观测；受策略倾向 π(a|x) 混杂，须 IPW/后门调整，仅更新关联信念）；**I-证据**（探针 = 干预；设计上无混杂，可直接识别干预分布）。硬规则：只有 I-证据或其部分识别界可签发干预性安全声明；O-证据不得进入不可逆承诺的必要因果前提。

**定义 140（可迁移不变先验 TIP）** 元环境集 ℰ={e_1,…,e_N}（区域/季节/载荷档），候选机制模块 {f_k}。不变集 `I* = {k : ∀e,e'∈ℰ, Δ(f_k;e,e') ≤ Δ_inv}`（Δ 为同条件机制分布差，ICP/IRM 检验）。摊销先验 q_φ 只允许覆盖 I*；环境特异模块不进跨区摊销，只能在本环境内用或退共形带。不变性证书 `(N_inv, α_inv, Δ_inv, 留出环境结果)`；新区域 z_r 的环境签名若不在覆盖内，相关模块自动失效。TIP 与第 57 轮 OOD 门互补：OOD 门防"没见过的新输入"，TIP 防"见过但不可运输的伪机制"。

**定义 141（因果跨模态对账 CXR）** 模态 m 观测变量 X_m⊆V，可存在共同原因 C（如真实地材状态）与模态特异噪声。EV-xmodal（修正 R2）要求：在干预上下文与融合后验给定时，`m ⊥ m' | (do-ctx, b_r)` 在等价类 `[𝒢_r]` 中**对所有一致 DAG 成立**（m-Markov 等价类下 d-分离），而非仅观测数据中统计不相关。伪一致判据：若不存在该 d-分离，则 m 与 m' 的同侧至多计一次观测，不产生独立性增益，并置共因告警位。分歧度拆为 `D(r)=D_stat(r)+D_c(r)`（统计分歧 + 因果共因分量）。ρ_m 按后门调整后的因果效应校准；只有 CFA 判为因果责任时才降级。

**定义 142（反事实失败归责 CFA）** verdict v（事后实测/失败）到达时，在 𝒢_r 上计算证据源 s（模态/元先验/人工标注/步态选择/载荷假设）的反事实责任 `Resp(s)=E[Y_{do(¬E_s)}−Y]`，或以 Shapley 值 φ_s 在源集合上分摊，并输出识别状态 `id(s)∈{identified,bounded,unidentifiable}`。仅当 `id(s)≠unidentifiable` 且责任方向为正才触发 ρ_m 降级与历史证据回溯；若核心路径不可识别，则不指控单一源，改整体降档并把区域标为 `cause_unidentified`。审计记 `(v, φ_s, id(s), 反事实轨迹)`，供人审与个性化信任 cal 评分使用。

**定义 143（干预型 VOI 与主动因果探询 iVOI/ACP）** 探针价值按"对当前承诺动作因果效应的信息增益"计：`iVOI(π)=E_{Y~P(·|do(a),b_r)}[Δrisk(commit)] − cost(π)`。探针选择偏好能切断后门路径或识别效应符号的干预（在安全上限 F_abs 内对步态/载荷/接触力做小范围随机化），而非重复同模态观测。每个因果探针必须声明 `identifiability∈{identified,partial,none}`；`none` 的探针不得用于签发因果声明。每检查点预算 `k_probe+k_cons+k_causal` 终止。

**定义 144（因果安全包络 CSE 与证书 J_c）** 安全规范定义在干预集上：`Safe(π) ⇔ ∀do(u)∈𝒰_adm, P(Y∈Y_bad|do(u),b_r) ≤ δ_f`。承诺 ⇔ 已识别因果效应（或部分识别最坏上界 U_r）满足 Safe ∧ 证据门过。`J_c=(J_p,[𝒢_r],I*,d-sep 结果,识别状态,部分识别界,反事实归责审计,未知因果标志)`。**未知因果规则**：若坏结果到可干预变量的因果路径不可识别，则该区域按 OOD 保守处理——禁不可逆承诺，只允许观测/绕行/L2 协商。因果护盾把标称指令投影到 Safe 干预集；投影失败即安全停。

## 2. 关键算法伪代码（完整版见产物区）

```python
def csm_update(G_r, ev):
    if ev.kind == 'I':                       # 探针 = do(·)：无混杂
        G_r.add_interventional(ev.do, ev.y)
    else:                                    # 到访/观测：策略混杂
        G_r.add_observational(ev, pi=propensity(ev, policy))  # IPW/后门
    return minimal_equivalence_class(G_r)    # CPDAG/PAG，不假装唯一 DAG

def interventional_effect(G_r, do_u, b_r):
    if identifiable(G_r, do_u):
        return ('identified', estimate(G_r, do_u, b_r))
    return ('bounded', partial_bounds(G_r, do_u))   # 最坏界 [L,U]

def transportable_prior(envs, modules):
    return {k for k in modules if invariance_violation(k, envs) <= Delta_inv}

def counterfactual_blame(G_r, verdict, sources):
    return {s: (cf_resp(G_r, verdict, s), identifiability(G_r, s)) for s in sources}
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| CSM | O(\|V\|²)/更新；等价类朴素 O(\|V\|³) | O(\|V\|²) | 干预/观测分层、倾向加权诚实 |
| TIP | O(N·\|模块\|·m) 检验 | O(\|ℰ\|·\|模块\|) | 不变性检验功效、Δ_inv 声明 |
| CXR | O(\|ℳ\|²·\|V\|²)/区域 | O(\|V\|·\|ℳ\|) | d-分离保守、共因不误判 |
| CFA | O(反事实查询数·\|V\|) | O(\|源\|·\|V\|) | 识别状态诚实、不可识别不指控 |
| iVOI | O(\|候选\|·(查询+估计)) | O(\|V\|) | identifiability 前置、预算终止 |
| CSE | O(\|𝒰_adm\|·估计) | O(\|𝒰_adm\|+J_c) | 未辨识即保守、部分界取上界 |

**正确性定理（Causal-Safe Soundness, CSS 概要）**：在 A37–A40 上加 (A41) CSM 充分性——声明的 U 之外未观测混杂的敏感性不超过 Γ（Rosenbaum/E-value），等价类内所有 DAG 的干预估计与声明一致且部分识别界有效；(A42) 不变性诚实——I* 的检验水平、Δ_inv、留出环境结果如实披露；(A43) d-分离可靠性——等价类不遗漏反事实共因，伪一致不计独立；(A44) 归责识别状态诚实。则：(i) **干预性健全**：承诺失效 ≤ δ_f + 部分识别上界间隙，O-证据路径另计策略混杂敏感度 Γ；(ii) **交互单调性保持**：因果层只能经"更准的干预信念"或"更保守的动作"（取部分界上界、未辨识即禁不可逆、未知因果走 OOD 保守）影响系统，无升险路径；(iii) **优雅降级**：当 𝒢_r 不可用或不变性检验失败，系统退化为第 57 轮的证据门（差距以显式回退项计入，而非隐藏）；(iv) iVOI 在 `k_probe+k_cons+k_causal` 内终止于 {承诺, 绕行, L2 协商, 安全停}。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| DAG 误设/未观测混杂 → 虚假因果自信 | 高 | 部分识别取最坏界 + 敏感性分析 Γ 披露 + 探针随机化造无混杂数据 + 未辨识禁不可逆 |
| 不变性检验功效不足（环境数太少）→ 伪机制被误判为不变 | 高 | N_inv 门槛 + 留出环境 + Δ_inv 声明 + 检验失败即退共形带 |
| d-分离依赖正确 DAG，等价类下检不出共因 → 伪一致 | 中高 | 未判 d-分离一律视为不独立（保守默认）+ 共因告警 + 仅 L1 |
| 因果发现在线开销/时延进入控制回路 | 中 | 有限候选 DAG + 等价类缓存 + 可回退第 57 轮路径 |
| 反事实归责不可识别 → 归责失准 | 中 | 不可识别不指控单一源，整体降档 + 审计可申诉 |
| 因果层给人"已控混杂"的错觉 | 高 | 安全论证中 I-证据与 O-证据分列，Γ 与部分界显式进部署界 |

## 6. 本轮最大风险

**一句话**：本轮用因果推理把"坏先验"换成"错误因果图"——一旦 SCM 误设（漏掉关键共同原因或未观测混杂）且不变性检验又因环境稀少而没抓住它，系统会产出**看起来最严谨、实则建立在错误干预模型上的安全证书**，而反事实归责与 iVOI 会让这套错误图自我强化；必须以部分识别最坏界、不变性证伪、d-分离保守默认、未辨识即禁不可逆四重护栏，把因果证书降格为"可证伪的必要证据"而非"充分授权"。

## 2. 关键算法伪代码

### IP-139 CSM（因果表面模型与证据分层）

```python
def csm_update(G_r, ev, policy):
    if ev.kind == 'I':                        # 探针 = do(·)：设计上无混杂
        G_r.add_interventional(ev.do, ev.y)
    else:                                     # 到访/被动观测：策略选择混杂
        G_r.add_observational(ev, pi=propensity(ev, policy))  # IPW/后门调整
    return minimal_equivalence_class(G_r)     # 只保留 CPDAG/PAG

def interventional_effect(G_r, do_u, b_r):
    if identifiable(G_r, do_u):
        return ('identified', estimate(G_r, do_u, b_r))
    return ('bounded', partial_bounds(G_r, do_u))           # 最坏界 [L,U]

def o_evidence_usable(G_r, ev):
    return ('assoc_only', backdoor_adjusted(ev, G_r))       # 不得签因果声明
```

### IP-140 TIP（可迁移不变先验）

```python
def transportable_prior(envs, modules, delta_inv):
    I_star = set()
    for k, f in modules.items():
        viol = max(mech_gap(f, e, e2) for e in envs for e2 in envs)
        if viol <= delta_inv and holdout_ok(f, envs):
            I_star.add(k)
    return I_star                              # 仅不变模块进入摊销

def tip_infer(M, r, obs, meta):
    inf = meta.q_phi(obs, z=ctx(r), modules=meta.I_star)
    if not meta.env_covered(ctx(r)):           # 环境签名未覆盖
        return Inf(cls='FALLBACK', belt=conformal_belt(...))
    return inf
```

### IP-142 CFA（反事实失败归责）

def counterfactual_blame(G_r, verdict, sources):
    out = {}
    for s in sources:
        r = cf_resp(G_r, verdict, s)           # E[Y_{do(not E_s)} - Y]
        out[s] = (r, identifiability(G_r, s))  # identified/bounded/unidentifiable

def apply_blame(M, blame, audit):
    if all(id_ == 'unidentifiable' for _, id_ in blame.values()):
        M.flag(M.region, 'cause_unidentified'); downgrade_all(M.region)
    for s, (r, id_) in blame.items():
        if id_ != 'unidentifiable' and r > 0:
            M.rho[s] = max(rho_min, M.rho[s] * gamma_down)
    audit.log(blame); return M

### IP-143 iVOI（干预型 VOI 与主动因果探询）

```python
def ivoi_probe(cp, G_r, b_r, F_abs, budget):
    cands = [p for p in probes(cp) if F_abs.safe(p)]
    cands = [p for p in cands if p.identifiability != 'none']
    if not cands or budget.k_causal <= 0: return None
    p = argmax(cands, key=lambda q: ivoi(q, G_r, b_r) - cost(q))
    return p if ivoi(p, G_r, b_r) >= theta_ivoi else None
```

### IP-144 CSE（因果安全包络 + 因果护盾）

```python
def causal_safety_gate(u, b_r, G_r, delta_f):
    st, val = interventional_effect(G_r, do_u=u, b_r=b_r)
    if st == 'none':
        return ('reject', 'cause_unidentified')          # 未辨识即保守
    bound = val if st == 'identified' else val[1]        # 取部分界上界
    if bound > delta_f:
        return ('reject', 'not_safe_interventionally')
    return ('ok', Jc(G_r, u, st, val, ...))

def causal_shield(u_nom, G_r, b_r, delta_f):
    if causal_safety_gate(u_nom, b_r, G_r, delta_f)[0] == 'ok':
        return u_nom
    safe = project_to_safe_set(u_nom, lambda u: causal_safety_gate(u, b_r, G_r, delta_f))
    return safe if safe is not None else safe_brake(u_nom)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CSM | O(\|V\|²)/更新；等价类 O(\|V\|³) | O(\|V\|²) | O/I 分层、倾向加权诚实（A41/A44） |
| TIP | O(N·\|模块\|·m) | O(\|ℰ\|·\|模块\|) | 不变性与留出披露（A42） |
| CXR | O(\|ℳ\|²·\|V\|²) | O(\|V\|·\|ℳ\|) | d-分离保守、共因不误判（A43） |
| CFA | O(查询数·\|V\|) | O(\|源\|·\|V\|) | 识别状态诚实、不可识别不指控 |
| iVOI | O(\|候选\|·(查询+估计)) | O(\|V\|) | identifiability 前置、k_causal 终止 |
| CSE | O(\|𝒰_adm\|·估计) | O(\|𝒰_adm\|+J_c) | 未辨识即保守、部分界取上界 |

**正确性定理（Causal-Safe Soundness, CSS）**
假设 A22–A32（第 53–55 轮）、A33–A36（第 56 轮）、A37–A40（第 57 轮）成立；**(A41)** CSM 充分性：声明的 U 之外未观测混杂的敏感性 ≤Γ，等价类内所有 DAG 的干预估计与声明一致，部分识别界有效（不窄于真值）；**(A42)** 不变性诚实：I* 的检验水平、Δ_inv 与留出环境结果如实披露；**(A43)** d-分离可靠性：等价类不遗漏反事实共因，伪一致不计独立证据；**(A44)** 归责识别状态诚实。则：

1. **干预性健全性**：承诺失效 ≤ δ_f + U_r−L_r（部分识别间隙）；O-证据路径另计策略混杂敏感度 Γ；未辨识路径被"禁不可逆 + OOD 保守"截断。
2. **交互单调性保持**：因果层只能经 (a) 更准的干预信念或 (b) 更保守的动作（取部分界上界、未辨识禁不可逆、未知因果走 OOD 保守、共因→不独立）影响系统，不存在升险路径。
3. **优雅降级**：𝒢_r 不可用或不变性检验失败时，显式退化为第 57 轮证据门，差距以回退项计入部署界而非隐藏。
4. **终止性**：iVOI 在 `k_probe+k_cons+k_causal` 内终止于 {承诺, 绕行, L2 协商, 安全停}。
5. **部署界**：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1])
             − P(混杂敏感度 > Γ) − P(不变模块误判)
             − P(伪一致漏检) − P(因果未辨识未触发保守)
```

关键：**探针即实验**（I-证据与 O-证据分层，只有干预能签因果声明）；**不变性即可迁移性**（先验从"全体摊销"收紧为"不变才摊销"）；**独立即 d-分离**（一致必须经得起共因检验）；**归责即反事实**（只有因果责任才降权）；**安全即干预集**（部分界取最坏、未辨识即保守）。五个机制全部经"更准的干预信念或更保守的动作"两个安全通道起作用，并与第 57 轮形成可回退的纵深。

## 6. 本轮最大风险

**一句话**：本轮用因果推理把"坏先验"换成"错误因果图"——一旦 SCM 误设（漏掉关键共同原因或未观测混杂）且不变性检验又因环境稀少而没抓住它，系统会产出**看起来最严谨、实则建立在错误干预模型上的安全证书**，而反事实归责与 iVOI 会让这套错误图自我强化；必须以部分识别最坏界、不变性证伪、d-分离保守默认、未辨识即禁不可逆四重护栏，把因果证书降格为"可证伪的必要证据"而非"充分授权"。
