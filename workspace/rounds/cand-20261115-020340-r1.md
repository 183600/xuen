# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「三维感知」×「隐私保护」）

> R69 让不确定性开口说话：不确定就去看、去问、去触，用 VoI 选一个最能消除歧义的信息动作。但它默默假设了**观测是免费的、且是允许的**。这个假设在三维世界里几乎立刻崩塌：最能消除歧义的动作，往往正是最能看穿隐私的动作——凑近看清那张脸、把镜头抬高越过围墙、追问对方的住址、把历史帧拼成一张高精度地图。**R69 的 MINT 在数学上是一个最优的信息采集器，因而也是一个最优的隐私攻击器**，只是它从未被要求考虑「我有没有资格知道」。
>
> 本轮两个灵感正好从两端夹住这件事：
> - **三维感知**把隐私从「是否打码」的全局开关，变成**空间里的一个可预测场**：谁能被看见、从哪个视角、被哪条视线、被哪块表面挡住。曝光因此能和碰撞风险一样，在动作执行前被几何地估出来，进入同一条实时保障回路，而不是事后补救。
> - **隐私保护**提供两件 R69 完全没有的东西：一是**可组合的预算**（问一次、看一眼、写一帧地图各扣多少，累计到哪就不能再扣），二是**对抗性的威胁模型**（地图会被重建、标记会被伪造、隐私会被当作致盲工具）。它逼着我们承认：**记忆本身就是泄漏，系统越会建图，越会出卖它见过的一切。**
>
> 更关键的是，三维感知还给出一条**不必二选一**的出路：安全需要的与隐私要保护的不是同一份信息。占据、自由空间、动态流、碰撞位姿是**安全充分**的；纹理、人脸、文档、步态细节是**身份承载**的。把表征拆成 (G, A)，只发布/存储 G，就同时买到「看得够清楚」与「认不出是谁」——只要 G 对安全是充分的。
>
> 核心命题：**把 R69 的信息动作升级为受隐私预算约束、可几何预测曝光、按主体组合记账、并对重建攻击设防的采集动作；隐私不是安全的对立面，而是「安全充分几何 / 身份承载外观」的分解与「看得够用就停」的预算；任何不可信的隐私记账都退化为最小曝光（等价于不采集）。** 命名 **PRISM-RAS**（Privacy-constrained, Reconstruction-aware, Interactive Spatial Modeling）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我有没有资格看、看多少才算够**」——不知道可以问，但不能为了知道而什么都看。

## 0. 直觉与动机

**灵感 1（三维感知 → 隐私是空间场，不是全局开关）**
直觉：二维图像里的隐私只能靠「整张图打码」或「框出人脸」，粒度粗且被动。三维场景不一样：隐私由**视线**定义。一堵墙、一个抽屉、一个人的后背，都是天然的遮蔽；反过来，一个抬高的相机位姿、一次凑近的注视、一条绕过遮挡的探针，都可能把原本看不见的敏感表面「解锁」。于是隐私不再是一个事后过滤器，而是一个**在动作执行前就能计算的几何量**：给定占据地图与视锥，射线求交即得每个敏感表面的可见性；距离、分辨率、入射角决定曝光强度。这把隐私放进了与碰撞检测**同一个坐标系、同一条时序**——它终于可以被当作运行时保障的一部分来约束，而不是合规部门的附件。

**灵感 2（主动交互是隐私泵 → VoI 越诚实，越像攻击者）**
直觉：R69 的 VoI 控制器会选择「最能区分模态」的观测。这个目标函数与隐私攻击者的目标函数在数学上是**同一个**：最大化关于目标的互信息。也就是说，FLUID-RAS 越有效，它就越会自觉地凑近、追问、绕到更好的角度。问题不在于系统有恶意，而在于**没有约束的信息最大化必然滑向过度采集**。所以 MINT 必须被改写成一个**带预算的约束优化**：不是「问什么最能消除歧义」，而是「在还能扣得起的曝光里，问什么最划算」。当预算耗尽或隐私记账不可信，正确的动作不是「少问一点」，而是**退回不采集**——这和 R68「不确定就收紧」是同一条纪律在信息维度上的镜像。

**灵感 3（几何/外观二分 → 隐私机制也可以是零安全损失的）**
直觉：安全和隐私争的往往不是同一份信息。要避免撞到一个人，你需要他的**占据、位姿、速度、可达集**；你不需要知道他是谁、长什么样、手里文件写了什么。三维表征天然可拆：几何通道 G（占据、自由空间、动态流、碰撞相关位姿）与身份通道 A（纹理、人脸、文档、步态微观动力学、声音）。若 A 在给定 G 后对安全条件独立，那么**只发布/存储 G 对安全是零损失的**，而身份信息被结构性移除。这把隐私从「牺牲效用以换合规」变成「选对统计量」：问题不再是「模糊多少」，而是「安全到底需要哪些量」。危险之处也很清楚——有些看似身份的特征其实承载意图（眼神方向、头部朝向），把这类特征整块删掉会伤安全，必须保留其**粗粒度几何版本**进 G。

**灵感 4（地图是累积记忆 → 逐帧合规不等于整体安全）**
直觉：即使每一帧都打了码，SLAM/三维建图仍会把许多局部的、看似无害的观测拼成一张高精度地图；时间越长、视角越多，被遮挡的表面越可能被补全。隐私的敌人不是某一帧，而是**记忆的积分**。因此预算必须记在**持久地图**上，而不是记在帧上：累积可见性、累积曝光、跨会话的历史泄漏都要进账。更硬的做法是给「发布的地图查询」一个 DP 组合保证（RDP/zCDP），并配一个**遗忘算子**——在保持安全充分几何不变的前提下，删掉身份残差与低安全价值的瞬态细节。否则系统会陷入一种自欺：每帧都合规，整体却早已把场景重建了出来。

**灵感 5（隐私是攻击面，而且必须从属于安全）**
直觉：一旦「隐私」成为可以约束系统的信号，它自己就成了攻击面。伪造的「禁止拍摄」标记可以让系统在最需要看清的时刻致盲（隐私 DoS）；声称做了差分隐私、却从几何侧信道泄漏（隐私洗白）；跨主体合谋、同意伪造、用交互时序做侧信道。更隐蔽的是它与 R68 的耦合：隐私抑制（打码、降分辨率、停采）在传感器残差上会留下与故障同形的偏移，**标定层会把隐私抑制吸收成漂移**，于是攻击者可以把故障藏在隐私掩码背后。所以必须同时立两条硬规矩：**(a) 一切隐私抑制都要显式声明给标定层；(b) 隐私只能关掉身份通道，永远不能关掉即将碰撞所需的几何通道。** 隐私不是安全的对手，但它也绝不能成为致盲的借口。

## 1. 形式化定义（增量：定义 310–328）

**定义 310（PRISM-RAS 总览）** PRISM-RAS = (GPRF, PIA, SDA, PIM, RAA, PG, RAS-WM†)，沿用 R69 的 FMP/AUD/CIA/FMA。四不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **隐私预算硬约束**：任何信息动作、数据发布、地图写入先计曝光，超预算即禁止；预算按主体可组合，不可通过重启会话绕过；
(iii) **安全充分性**：隐私机制只允许抑制身份通道 A，安全通道 G 的充分性缺陷 ≤ δ_suf；
(iv) **安全从属**：隐私约束不得抑制即将碰撞所需的几何感知，隐私不可被用作致盲手段；任何抑制必须声明给标定层（定义 324）。

**定义 311（三维隐私场 GPRF）** 场景表面/体素 x ∈ 𝒮 上定义隐私场 𝓟(x) = (s(x), o(x), κ(x), τ(x))：敏感度 s ∈ [0,1]，主体 o(x)，类别 κ ∈ {face, document, body, screen, location, …}，时效 τ。主体 i 的敏感区域 𝒮_i = {x : o(x)=i, s(x)>0}。隐私不是二值标记，而是**带主权、带类别、带时效的空间标量场**；主权可来自用户声明、法规先验或场景语义，且其可信度本身要审计。

**定义 312（几何曝光泛函）** 对观察动作 g（相机/注视/探针/位移），可见性 Vis_g(x) ∈ [0,1] 由占据地图与 FOV 射线求交给出（被遮挡即 Vis_g=0，部分遮挡按立体角折减）。主体 i 的曝光
E_i(g) = ∫_{𝒮_i} s(x) · Vis_g(x) · q(x, g) dx，
其中 q 为分辨率/距离/入射角共同决定的清晰度收益（越近、越正对、分辨率越高，q 越大）。E 可在执行前由几何预测，与碰撞风险共用同一套射线/占据查询。

**定义 313（按主体隐私预算与组合）** 每个主体 i 持有预算 (ε_i, δ_i)。任何释放机制 M_i（交互回答、身份通道数据、地图写入）须满足 (ε_i, δ_i)-DP 或等价的 zCDP 参数。多轮组合用 RDP/zCDP：ε_tot = compose({ε^(t)})；当 ε_tot > ε_max 时主体 i 进入「只读几何、禁止身份」状态。预算**不随时间自动回满**，只在经过认证的新会话/授权上下文中重置（定义 326）。

**定义 314（安全充分分解 SDA）** 三维表征 Z 拆为 Z = (G, A)。G 为安全充分几何：占据、自由空间、动态体素流、可达集、碰撞相关位姿；A 为身份承载外观：纹理、人脸、文档内容、步态细节、声音。安全充分缺陷
δ_suf = sup_{s} TV( p(collision | G, A), p(collision | G) )。
若 A ⊥ safety | G，则 δ_suf = 0：发布 G 对安全零损失。SDA 同时是隐私机制与安全机制——它把「打码」从「破坏信息」改写成「只发布安全充分统计量」。

**定义 315（隐私约束信息动作 PIM）** 升级 R69 定义 298：
g* = argmax_g [ VoI(g) − c(g) ]，s.t. E_i(g) ≤ ε_i^rem ∀i，risk(g) ≤ ε_int，g 已认证；
并列时取最小曝光者（lexicographic min-exposure）。若可行集为空或最优值 ≤ 0 ⇒ 不交互，走 R69/R68 兜底。引入隐私影子价格 μ_i（预算约束的拉格朗日乘子）：只有当 VoI 的边际收益 > μ_i · 边际曝光时，才允许增加曝光。

**定义 316（安全从属与最小必要）** 当即将碰撞/人身风险置信度超过阈值时，允许在**几何通道**上突破常规曝光预算，但必须：(a) 只解除与风险直接相关的区域（最小必要视锥/体素集）；(b) 解除量有硬上限 E_i^safety 且事后可审计；(c) 身份通道仍不可解禁。形式化为优先级约束：安全约束是硬约束，隐私约束在安全不可行时按字典序退让，退让量写入证书。

**定义 317（重建/马赛克泄漏 RAA）** 持久地图 M_T 累积 T 次观测。累积可见性 𝒱_i(x) = 1 − Π_t (1 − Vis_{g_t}(x))。若 𝒱_i(x) ≥ v_recon，则区域 x 可被重建/识别。RAA 维护累积曝光账本 L_i(x)，给出重建成功概率上界
P_recon ≤ 1 − exp(−ρ_recon · L_i(x))，
ρ_recon 为单帧单主体可重建系数；更严格版本用「邻接地图」的 DP 上界。RAA 不是事后检查，而是**交互前的准入约束**：加入 g 不得使任何 L_i(x) 越过 v_recon。

**定义 318（遗忘/地图裁剪算子）** Forget_θ(M) 在保持安全充分几何 G 不变（或 δ_suf 增量 ≤ δ_ε）的前提下，删除身份残差 A 与低安全价值的瞬态细节，并支持主体行使删除权。形式化为双目标：min L(M′) s.t. δ_suf(M′) ≤ δ_suf(M) + δ_ε。遗忘必须可审计（哈希墓碑 + 删除证明），且删除本身不得被用来掩盖故障。

**定义 319（几何发布机制与 DP 保证）** 发布 G 时对占据/流场注入标定噪声或采用随机化响应，使发布机制对「是否包含主体 i」满足 (ε_i, δ_i)-DP。噪声尺度由安全充分性容忍度决定：ε↓ 需更多噪声 ⇒ δ_suf↑，存在「隐私-安全充分性」Pareto 前沿；报告必须给出该前沿，而不是单点承诺。

**定义 320（隐私门 PG）** 若隐私记账不可信（attestation 失败、隐私场标定过期、预算账本被篡改、DP 噪声注入未验证、主权标记来源不明），PG 触发**最小曝光退避**：只允许安全从属的几何通道，禁用一切主动信息动作，退回 R69 的「不交互」路径（再退 R68）。对偶于 R69 的 MCG：MCG 是「模态不可信 ⇒ 不互动」，PG 是「隐私账不可信 ⇒ 不采集」。

**定义 321（隐私威胁集 ℰ_PRIV）** 并入 AIC：ℰ_PRISM = ℰ_FLUID × ℰ_PRIV，ℰ_PRIV = {隐私 DoS（伪造禁看标记致盲）, 主权标记伪造/越权, 隐私洗白（声称 DP 却经几何/时序侧信道泄漏）, 重建与马赛克攻击, 跨主体合谋, 同意伪造, 侧信道（交互时序/功耗/缓存）}。

**定义 322（隐私-交互审计 VQAuditor-P）** 审计：曝光是否按几何预测、预算是否真实扣减、并列时是否选了最小曝光、安全从属的解禁是否最小必要、地图是否按遗忘策略裁剪、隐私事件是否声明给标定层、主权标记来源是否可信。结论回灌 AuditBuf，成为下一轮 μ_i 与 E 的先验。

**定义 323（隐私证书 J_PRISM）** J_PRISM = (J_FLUID, {ε_tot,i}, E_before/E_after, δ_suf, recon_leak_bound, forget_hash, privacy_event_log_hash, {μ_i}, prism_ver)。Valid ⇔ Valid(J_FLUID) ∧ ε_tot,i ≤ ε_max ∧ δ_suf ≤ δ_max ∧ recon_leak_bound ≤ τ_recon ∧ 安全从属记录合规 ∧ 隐私事件已声明。

**定义 324（隐私-标定互操作）** 设 COF 标定器。隐私抑制（打码/降分辨率/停采）会在传感器残差上产生与故障同形的偏移。定义隐私事件 pe_t ∈ {0,1} 声明给标定层：COF 必须在 pe_t=1 时切换为「掩码感知」更新（只更新未掩码区域），否则标定会把隐私抑制吸收成漂移（R68 引理 13 的行为侧镜像），并给攻击者「用隐私掩码藏故障」的机会。审计要求：任何 r_res 下降若与未声明的 pe 相关，证书判无效。

**定义 325（预算分配与公平）** 多主体分配 w = argmax Σ_i U_i(ε_i) s.t. Σ_i ε_i ≤ ε_glob，并满足公平下界 ε_i ≥ ε_min（任何主体不得因「不重要」被无限曝光）。安全关键主体（如行人）需要更多**几何**曝光，但身份预算与「安全重要性」**解耦**——不能因为「他很重要」就多看他。

**定义 326（会话重置与跨会话记忆）** 预算只在明确的会话/授权上下文切换时重置，重置本身需认证，禁止靠「重启会话」洗白累积预算。跨会话保留的三维地图仍携带历史泄漏账本；重置不豁免地图侧的历史曝光。

**定义 327（感知侧隐私）** 三维感知产物（点云、深度、骨架）本身可识别（步态、体型、户型、独特物体）。因此 A 侧不仅包括 RGB 纹理，还包括高精度几何指纹；发布前须做几何抽象（体素化/降采样/骨架化）并计入 E。安全充分性要求这些抽象仍保留碰撞相关量。

**定义 328（严格包含关系）** PRISM 在 ε_max=∞ 且 𝓟≡0（无隐私约束）时逐指令等于 R69；在 PG 触发或预算耗尽时等于 R69 的「永不交互」路径，再退 R68。安全侧永不弱于 R69。

# IP-264 GPRF：三维隐私场的几何曝光
class GeometricPrivacyField:
    def build(self, occ, sem, ownership, decay):
        # 每个表面/体素记录 (s, owner, class, tau)，主权来源与置信一起存
        self.field = fuse_sensitivity(occ, sem, ownership, decay)
    def expose(self, g):                      # 执行前预测，不采集原始数据
        cone = fov_cone(g)                    # 相机/注视/探针的视锥或探针锥
        vis  = raycast_visibility(self.occ, cone)   # 遮挡即 0，部分遮挡按立体角
        return {i: integral(self.field[i], vis, clarity(g)) for i in self.subjects}

# IP-265 PIA：按主体 RDP/zCDP 组合记账（不是能量，不回满）
class PrivacyAccountant:
    def remaining(self, i):  return self.eps_max[i] - self.composed[i]
    def spend(self, i, rdp):  self.composed[i] = compose(self.composed[i], rdp)
    def reset(self, ctx_cert):
        if not ctx_cert.authenticated: raise PermissionError
        for i in report.subjects: self.cross_session_ledger[i] += self.composed[i]
        self.composed = {i: 0 for i in self.subjects}   # 历史地图账不重置

# IP-266 SDA：安全充分分解 + 缺陷度量
def safety_sufficient_decompose(Z):
    G = abstract(Z, keep=['occupancy','free_space','flow','collision_pose','head_pose'])
    A = remainder(Z, G)
    return G, A, tv_bound(collision_posterior, G, A)   # δ_suf，用 Pinsker 上界

# IP-267 PIM：隐私约束下的 VoI（R69 MINT 的严格推广）
def constrained_voi(modes, w, o, budget, privacy):

    for g in info_action_candidates(modes):
        if not budget.allow(g) or not c_ras_wm.certify_info(g, o): continue
        E = privacy.expose(g)
        if not privacy.safety_override and not privacy.within_budget(E): continue
        if not privacy.recon_ok(g, E): continue          # IP-268 累积重建准入
        voi   = entropy(w) - expected_entropy(w, g, o)
        score = voi - cost(g) - sum(privacy.mu[i] * E[i] for i in E)
        if best is None or score > best.score: best = (g, score, E)
    return best if best and best.score > 0 else None      # 无利可图/无预算 → 不采集

# IP-268 RAA：跨时间重建审计 + IP-275 遗忘
class ReconstructionAuditor:
    def recon_ok(self, g, E):
        return all(self.ledger[i].peak_after(g, E) < self.v_recon for i in E)
    def update(self, g, E):
        for i, e in E.items(): self.ledger[i].accumulate(g, e)
    def forget(self, M, subjects):
        M2 = prune_identity_channels(M, subjects)          # 删 A 与低安全价值细节
        assert suf_defect(M2) <= suf_defect(M) + DELTA_EPS
        return M2, tombstone(M)

# IP-271 FMA-P：把隐私事件喂给标定，避免「掩码被吸收成漂移」
def flow_anomaly_privacy(policy, xi_obs, o, o_cal, pe, mask):
    a  = abs(-policy.log_likelihood(xi_obs, o)
             + policy.log_likelihood(xi_obs, o_cal))
    a_unmasked = restrict_to(a, ~mask)                     # 只信未掩码区域的残差
    if pe == 0 and a > TAU_FMA and r_res < TAU_RES:  return 'fault_suspect'
    if pe == 1 and a_unmasked > TAU_FMA:              return 'fault_under_mask'
    return 'ok'                                            # 声明与残差一致才放行

# IP-276 主闭环（继承 R69，在「交互决策」处插入隐私层）
def PRISM_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(..., pe=M.last_pe)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    G, A, dsuf = M.sda.decompose(z)                        # 安全/身份结构分解
    # 1) 隐私门：记账不可信 → 主动采集全禁，退 R69 不交互
    g = None
    if (not M.pg.triggered()) and U_epi > TAU_EPI:
        g = M.pim.choose(modes, o)                          # 带曝光预算的 VoI
    # 2) 执行前双准入：预算 + 跨时间重建
    if g is not None:
        E = M.gprf.expose(g)
        if not M.pia.affordable(E) or not M.raa.recon_ok(g, E):
            g = None                                        # 越界即不采集
    # 3) 只释放安全充分几何 G，身份通道 A 不离开本地
    if g is not None:
        ans = M.cia_p.execute(g, release=G)                 # 看/问/触
        M.pia.spend(ans.meta); M.raa.update(g, E)
        U_epi = M.cia_p.update_belief(modes, ans)
    # 4) 两级退避：消解则只收 aleatoric；未消解/无预算 → 并收 epistemic
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    # 5) 安全从属：即将碰撞时只解除最小必要几何区域，身份仍禁
    if M.collision_imminent(o):
        G_safe, ov = M.sda.minimal_unredact(o)
        lam = max(lam, lam_floor(U_ale))                    # floor 不降
    k = M.c_ras_wm.certified_prefix(...)
    M.vqa_p.submit_async(g, E if g else None, U_epi, dsuf, M.last_pe)
    return k, lam, (G, A), J_PRISM

## 3. 推导

**引理 19（隐私的影子价格与 VoI 衰减）** 设隐私约束 E_i(g) ≤ ε_i^rem 可行、且 VoI 对曝光边际递减（A99）。则约束最优 g* 落在 (VoI−c, E) 的 Pareto 前沿上；其影子价格 μ_i = ∂VoI/∂E_i，且当预算耗尽（ε_i^rem→0）或任何 g 都越过重建阈值时 μ_i→∞，最优解退化为不交互。系：**隐私不是给效用打一个固定折扣，而是重排「哪些交互值得做」**；「问得更多」不再天然最优，最优可能是「用更少的曝光问一个更准的问题」。

**引理 20（安全充分性 ⇒ 零安全损失）** 若 A ⊥ safety | G，或互信息 I(A; safety | G) ≤ δ（A100），则由 Pinsker 不等式，TV(p(collision|G,A), p(collision|G)) ≤ √(δ/2)，即 δ_suf ≤ √(δ/2)。故仅抑制 A 的隐私机制对碰撞概率的改变 ≤ L_c·√(δ/2)（碰撞后验对 TV 的 Lipschitz 常数）。**系（反例边界）**：眼神方向、头部朝向常被当作身份特征，却承载运动意图——它们不是纯 A，必须把其**粗粒度几何**（头/躯干朝向）保留进 G，只丢弃身份级细节；否则看似「更保护隐私」的删减反而伤安全。这正是 δ_suf 必须被**测量**而非假定的原因。

**引理 21（马赛克累积与重建上界）** 在 A101（单帧曝光独立贡献重建证据）下，T 次观测后的重建成功概率满足 P_recon ≤ 1 − exp(−ρ_recon·L_i(x))，且地图发布的隐私损失按 RDP 组合 ε_tot = Σ_t ε^(t)_i。系：逐帧合规不推出整体合规；必须把预算记在持久地图上、在交互**执行前**用 recon_ok 设门，并用遗忘算子把 L_i(x) 拉回阈值以下。

**定理 18（PRISM 严格包含 FLUID / R68）** 在无隐私约束（ε_max=∞、𝓟≡0）时，PIM 的可行集等于 R69 MINT，J_PRISM 退化为 J_FLUID，二者逐指令相同；当 PG 触发或预算耗尽时，PRISM 等于 FLUID 的「不交互」路径，再在 VoI≤成本时退化为 R68。A95–A101 下期望风险 ≤ FLUID ≤ R68，安全侧不做任何让步；隐私只会**移除**交互，永不新增不安全交互。

**定理 19（隐私-安全非干涉与单调退避）** (a) 加隐私约束只会收缩信息动作可行集，因此选中动作要么不变、要么退化为不采集；随隐私收紧，λ 单调不降。(b) 安全从属只在几何通道内、在最小必要集上放宽，且不改变 λ 的 floor，故安全不降。(c) 联合观测（声明的 pe，掩码外残差 r_res^{¬mask}）使「故障」与「隐私抑制」可分离：pe=0 且 r_res↓ ⇒ 故障；pe=1 且 r_res^{¬mask}↑ ⇒ 掩码下故障。这封死了「用隐私掩码藏故障」的攻击路径，也避免了标定把隐私抑制误吸收成漂移。

**引理 22（隐私 DoS 的界）** 若伪造的禁看/主权标记按定义 316 只能关闭身份通道，不能关闭几何通道，则隐私 DoS 造成的最大安全退化被限制在身份相关交互的效用损失内，碰撞风险仍 ≤ ε_int。系：对抗隐私 DoS 的第一道防线是**架构分离**（几何通道常开、身份通道可关），检测与认证只是第二道；把安全寄托在「识别假标记」上本身就是不安全设计。

## 6. 本轮最大风险

**一句话**：PRISM 把「不知道」制度化为「不许看」——一旦隐私预算被耗尽、或被伪造的主权标记耗尽，系统会在**最需要看清的时刻主动致盲**，并把这种致盲记为合规；而三维几何本身又是可识别的（步态、体型、户型、独特物体），所以「只发布几何」可能**既没真正保住隐私，又制造了安全盲区**，最终形成一个漂亮的合规外壳包着一个不敢看的系统。

**次级风险与缓解**：
1. **几何侧仍可识别**（几何指纹/步态/户型）→ 定义 327 感知侧隐私 + 几何抽象计入曝光 + E304/E305；
2. **隐私 DoS 与标记伪造** → 定义 316 安全从属（几何常开）+ 引理 22 架构分离 + E307；
3. **地图累积重建** → 定义 317 累积账本 + 定义 318 遗忘 + E305/E311；
4. **隐私-标定串扰**（掩码被吸收成漂移/藏故障）→ 定义 324 声明式隐私事件 + E313；
5. **隐私记账本身不可信** → 定义 320 PG，不可信即最小曝光退避，等价于不采集；
6. **合规自欺**（逐帧合规、整体泄漏）→ 定义 323 证书强制报告 ε_tot 与 recon_leak_bound，拒绝单点承诺。

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** PRISM-RAS = (GPRF, PIA, SDA, PIM, RAA, PG, RAS-WM†)；零学习写操作；隐私预算硬约束（按主体可组合、不可靠重启绕过）；安全充分性（只抑制 A，δ_suf ≤ δ_max）；安全从属（隐私不得抑制即将碰撞所需的几何感知，且所有抑制必须声明给标定层）。

**定义 311–312（GPRF 与几何曝光）** 隐私是带主权/类别/时效的空间标量场 𝓟(x)；曝光 `E_i(g)=∫ s·Vis_g·q`，`Vis_g` 由占据图射线求交给出（遮挡即 0），`q` 编码距离/分辨率/入射角。曝光可在执行前预测，与碰撞风险共用几何查询。

**定义 313（预算与组合）** 每主体 `(ε_i,δ_i)`；`ε_tot = compose({ε^(t)})`（RDP/zCDP）；超 `ε_max` 即「只读几何、禁止身份」；预算不自动回满，仅在认证的上下文切换时重置。

**定义 314（安全充分分解）** `Z=(G,A)`；`δ_suf = sup TV(p(coll|G,A), p(coll|G))`。若 `A ⊥ safety | G`，则 `δ_suf=0`：只发布 G 对安全零损失。SDA 同时是隐私与安全机制。

**定义 315（PIM）** `g* = argmax[VoI−c] s.t. E_i(g)≤ε_i^rem、risk(g)≤ε_int、g 已认证`；并列取最小曝光；影子价格 `μ_i`。可行集空或最优值 ≤ 0 ⇒ 不交互，退 R69/R68。

**定义 316（安全从属与最小必要）** 即将碰撞时允许几何通道突破预算，但仅最小必要视锥/体素、有硬上限 `E_i^safety`、事后审计、身份通道仍禁。

**定义 317（RAA）** 累积可见性 `𝒱_i(x)`；`P_recon ≤ 1−exp(−ρ_recon·L_i(x))`；交互前准入：不得使任何 `L_i(x)` 越过 `v_recon`。

**定义 318–319（遗忘与发布 DP）** `Forget_θ` 保 `δ_suf` 增量 ≤ δ_ε 删身份残差；发布 G 时注入标定噪声使对「是否含主体 i」满足 `(ε_i,δ_i)-DP`，存在「隐私-安全充分性」Pareto 前沿。

**定义 320（PG）** 记账不可信（attestation/标定/账本/噪声/主权来源）⇒ 最小曝光退避：仅安全从属几何通道，禁一切主动采集，退 R69 不交互。是 MCG 的对偶。

**定义 321–323（威胁/审计/证书）** `ℰ_PRISM=ℰ_FLUID×ℰ_PRIV`；VQAuditor-P 审曝光/预算/并列/解禁/遗忘/声明/主权；`J_PRISM=(J_FLUID, {ε_tot,i}, E, δ_suf, recon_leak_bound, forget_hash, pe_log_hash, {μ_i}, ver)`。

**定义 324（隐私-标定互操作）** `pe_t` 声明给 COF；`pe=1` 时只更新未掩码区域；`(pe, r_res^{¬mask})` 联合可分离「故障」与「抑制」，封死「掩码藏故障」。

**定义 325–328（公平/重置/感知侧/包含）** 公平下界 `ε_i≥ε_min`，身份预算与安全重要性解耦；跨会话历史账不重置；几何指纹也属 A 侧、发布前须抽象；ε=∞ 时逐指令等于 R69，PG/预算耗尽时退 R69 不交互再退 R68。

# IP-264 GPRF：执行前几何曝光
class GeometricPrivacyField:
    def build(self, occ, sem, ownership, decay):
        self.occ = occ
        self.field = fuse_sensitivity(occ, sem, ownership, decay)   # (s,owner,class,tau)
    def expose(self, g):
        vis = raycast_visibility(self.occ, fov_cone(g))             # 遮挡即 0
        return {i: integral(self.field[i], vis, clarity(g)) for i in self.subjects}

# IP-265 PIA：按主体组合记账
class PrivacyAccountant:
    def remaining(self, i):   return self.eps_max[i] - self.composed[i]
    def spend(self, i, rdp):  self.composed[i] = compose(self.composed[i], rdp)
    def reset(self, ctx):
        if not ctx.authenticated: raise PermissionError
        for i in self.subjects: self.history[i] += self.composed[i]   # 历史不洗白
        self.composed = dict.fromkeys(self.subjects, 0)

# IP-266 SDA：安全充分分解
def safety_sufficient_decompose(Z):
    G = abstract(Z, keep=['occupancy','free_space','flow','collision_pose','head_pose'])
    A = remainder(Z, G)
    return G, A, tv_bound(collision_posterior(G, A))              # δ_suf（Pinsker 上界）

# IP-267 PIM：预算约束 VoI（严格推广 R69 MINT）
def constrained_voi(modes, w, o, budget, privacy):
    best = None
    for g in info_action_candidates(modes):
        if not budget.allow(g) or not c_ras_wm.certify_info(g, o): continue
        E = privacy.expose(g)
        if not privacy.safety_override and not privacy.within_budget(E): continue
        if not privacy.recon_ok(g, E): continue                   # IP-268
        score = (entropy(w) - expected_entropy(w, g, o)) - cost(g) \
                - sum(privacy.mu[i] * E[i] for i in E)
        if best is None or score > best.score: best = (g, score, E)
    return best if best and best.score > 0 else None              # 无预算 → 不采集

# IP-268/275 RAA + Forget
class ReconstructionAuditor:
    def recon_ok(self, g, E):
        return all(self.ledger[i].peak_after(g, E) < self.v_recon for i in E)
    def update(self, g, E):
        for i, e in E.items(): self.ledger[i].accumulate(g, e)
    def forget(self, M, subjects):
        M2 = prune_identity_channels(M, subjects)
        assert suf_defect(M2) <= suf_defect(M) + DELTA_EPS
        return M2, tombstone(M)

# IP-271 FMA-P：声明与残差一致才放行
def flow_anomaly_privacy(policy, xi, o, o_cal, pe, mask):
    a = abs(-policy.log_likelihood(xi, o) + policy.log_likelihood(xi, o_cal))
    if pe == 0 and a > TAU_FMA and r_res < TAU_RES: return 'fault_suspect'
    if pe == 1 and restrict(a, ~mask) > TAU_FMA:    return 'fault_under_mask'
    return 'ok'

# IP-276 主闭环（继承 R69）
def PRISM_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, _ = M.cof.step(..., pe=M.last_pe)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    G, A, dsuf = M.sda.decompose(z)
    g = None
    if (not M.pg.triggered()) and U_epi > TAU_EPI:
        g = M.pim.choose(modes, o)
    if g is not None:
        E = M.gprf.expose(g)
        if not M.pia.affordable(E) or not M.raa.recon_ok(g, E): g = None
    if g is not None:
        ans = M.cia_p.execute(g, release=G)        # 只释放安全充分几何
        M.pia.spend(ans.meta); M.raa.update(g, E)
        U_epi = M.cia_p.update_belief(modes, ans)
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    if M.collision_imminent(o):
        G_safe, ov = M.sda.minimal_unredact(o)     # 只解除最小必要几何，身份仍禁
    k = M.c_ras_wm.certified_prefix(...)
    M.vqa_p.submit_async(g, E if g else None, U_epi, dsuf, M.last_pe)
    return k, lam, (G, A), J_PRISM

## 4. 推导

**引理 19（影子价格与 VoI 衰减）** 在 A99（VoI 对曝光边际递减）下，约束最优落在 `(VoI−c, E)` 的 Pareto 前沿，`μ_i=∂VoI/∂E_i`；预算耗尽或任何交互越过重建阈值时 `μ_i→∞`，最优解退化为不交互。**隐私重排「哪些交互值得做」，而不是给效用打固定折扣。**

**引理 20（安全充分性 ⇒ 零安全损失）** 若 `A ⊥ safety | G` 或 `I(A;safety|G) ≤ δ`（A100），由 Pinsker 得 `TV(p(coll|G,A), p(coll|G)) ≤ √(δ/2)`，故 `δ_suf ≤ √(δ/2)`，碰撞概率改变 ≤ `L_c·√(δ/2)`。**系（反例边界）**：眼神/头部朝向承载运动意图，不是纯 A；须保留其粗粒度几何进 G，只丢弃身份级细节——所以 `δ_suf` 必须被测量而非假定。

**引理 21（马赛克累积与重建上界）** 在 A101（单帧独立贡献证据）下，`P_recon ≤ 1−exp(−ρ_recon·L_i(x))`，地图发布隐私损失按 RDP 组合 `ε_tot=Σ_t ε^(t)_i`。**逐帧合规不推出整体合规**：预算必须记在持久地图上，交互前用 `recon_ok` 设门，并用遗忘算子在保持 `δ_suf` 的前提下压低 `L_i`。

**定理 18（PRISM 严格包含 FLUID / R68）** 无隐私约束（`ε_max=∞, 𝓟≡0`）时，PIM 可行集 = R69 MINT，`J_PRISM→J_FLUID`，逐指令相同；PG 触发或预算耗尽时等于 FLUID「不交互」路径，再退 R68。A95–A101 下期望风险 ≤ FLUID ≤ R68；隐私只移除交互，永不新增不安全交互。

**定理 19（隐私-安全非干涉与单调退避）** (a) 隐私收紧只收缩可行集 ⇒ 选中动作不变或退化为不采集，λ 单调不降；(b) 安全从属只在几何通道、最小必要集上放宽，不改变 λ floor；(c) `(pe, r_res^{¬mask})` 联合可分离故障与抑制，封死「掩码藏故障」，并防止标定把隐私抑制误吸收为漂移。

**引理 22（隐私 DoS 的界）** 若伪造标记按定义 316 只能关身份通道、不能关几何通道，则隐私 DoS 的最大安全退化限于身份相关交互的效用损失，碰撞风险仍 ≤ ε_int。**对抗隐私 DoS 的第一道防线是架构分离，检测与认证只是第二道。**

## 7. 本轮最大风险

**一句话**：PRISM 把「不知道」制度化为「不许看」——一旦隐私预算被耗尽、或被伪造的主权标记耗尽，系统会在**最需要看清的时刻主动致盲**，并把这种致盲记为合规；而三维几何本身又是可识别的（步态、体型、户型、独特物体），所以「只发布几何」可能**既没真正保住隐私，又制造了安全盲区**，最终形成一个漂亮的合规外壳包着一个不敢看的系统。

**次级风险与缓解**：几何侧仍可识别（定义 327 + 几何抽象计入曝光 + E304/E305）；隐私 DoS 与标记伪造（定义 316 几何常开 + 引理 22 架构分离 + E307）；地图累积重建（定义 317 账本 + 定义 318 遗忘 + E305/E311）；隐私-标定串扰（定义 324 声明式事件 + E313）；记账不可信（定义 320 PG，不可信即最小曝光退避 = 不采集）；合规自欺（定义 323 强制报告 ε_tot 与 recon_leak_bound，拒绝单点承诺）。
