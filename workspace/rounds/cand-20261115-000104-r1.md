## 映射（升级而非重写）

| 灵感词 | ToolGauge 中的隐含假设 | 升级为 | 一句话动机 |
|---|---|---|---|
| 技能组合 | 每个盲区从零规划一条扁平程序 Π_s | **S-Box + STC**：技能库 + 组合代数 + 类型/资源校验 | 已修好的相似盲区不应从零再来；组合必须有类型、资源与能力域契约 |

| 合成 | 6C 是一条开环 episode 链 | **EndurGauge**：技能组合驱动的续航感知闭环 | 把“修得快”升级为“在任务寿命内以可认证的方式持续修” |

**核心命题**：把 ToolGauge 的「语义假设 → 契约化工具调用 → 摊销校准 → 交叉验证后局部热替换」
升级为「**可复用技能组合 → 组合类型/资源校验 → 续航感知调度 → 精度自适应执行 → 账本复盘与技能进化**」：
VLA 从“程序规划器”降格为“**技能组合器**”，只能拼接预注册且通过 STC 的技能；
数值真值仍由计量层独占；能量、热、磨损与证书时效第一次成为**与数值契约同等级的一等约束**。

**不变式保持声明**：
- MODGAUGE 五不变式（契约完整性、组合单调性、反作用通道完备、主张绑定、严格退化链）全部保留；
- 技能组合只改变“选择与编排”，不进入数值通道；任何技能体最终仍展开为 MTC 工具调用；
- **严格退化链延长**：EndurGauge 失效（能量不足 / 技能无法通过 STC / 能力域外 / 热或磨损超限）
  ⇒ 退回 ToolGauge 扁平程序 ⇒ 再失效退回 LeanGauge 纯数值探测 ⇒ 最后退回 MODGAUGE；
- **能量保留不变式**：SoC 低于安全储备时，系统宁可不修，也不得把能量花到非安全关键探测上。

## 0. 直觉与动机

### 灵感 1（技能组合 → 从“一次性程序”到“可验证的技能代数”）

直觉：ToolGauge 的 Π_s 是一条为单个盲区临时拼出来的扁平工具序列，验证完即丢弃；
但真实计量修复充满重复母题：镜面反射盲区几乎总是“光照扫描 + IR 补测 + 立体基线”，
遮挡盲区几乎总是“换视角 + 双目 + 跨通道互检”。如果每次都从零规划、从零验证、从零校准，
那么第 100 个盲区学不到前 99 个盲区的任何“动作经验”。技能组合的启示是：
**把已验证的动作片段沉淀为技能，用类型系统保证拼接合法，用资源代数保证拼接可负担，用能力域保证拼接可迁移。**

这不是把 VLA 变强，恰恰相反：VLA 从“自由规划器”降为“**技能组合器**”——
它只能在预注册技能库上选择组合算子，组合结果必须通过 STC（Skill Type Checker）。
这既放大了复用红利，又把 ToolGauge 已经建立的四层攻击面（schema / 物理前置 / 签名回执 / SNC）
扩展到组合层：攻击者还要伪造合法的组合类型与资源画像。

但组合不是免费的，它引入三类新失效：
1. **接口错配**：前一个技能的后置回执不满足后一个技能的前置；
2. **物理互扰**：PAR 并行时两个技能共享执行器、工作空间、光谱或热预算；
3. **能力域外推**：技能在源盲区验证过，不代表在语义邻近但分布不同的目标盲区仍可靠。
因此必须把“组合”从启发式提升为带证书的代数。

### 灵感 2（续航能力 → 能量与“认知续航”的双重预算）

直觉：长时运行的具身系统不是“每修一个盲区都电无限”。修复动作要耗电、发热、磨损执行器；
更隐蔽的是，**校准本身会过期**：温度漂移、材料老化、负载变化会让昨天通过 V 阶段交叉验证的证书今天失效。
所以“续航能力”应拆成两条轴：

- **能量续航（energy endurance）**：SoC、热余量、磨损余量、充电窗口；它把所有盲区的修复预算耦合在一起——
  今天在一个低价值盲区上多花 20 J，可能让明天一个安全关键盲区无电可修；
- **认知续航（epistemic endurance）**：证书年龄、漂移率、再验证截止期；它让“修好”不再是永久状态，
  而是一个带 TTL 的租约。长时系统的目标不是“修得最多”，而是“在任务寿命内让可认证覆盖率始终高于下限”。

ToolGauge 的 TB-Contract 是这一框架的**单 episode 退化特例**：令能量无约束、证书 TTL 为无穷、只修一个盲区即可。
EndurGauge 则把它升级为跨盲区、跨时间、带再充电与再验证的长期契约。

### 灵感 3（合成 → EndurGauge：每焦耳的可认证覆盖率）

直觉闭环：

```
D-Box 发现盲区 s
   ↓
S-Box：从技能库组合出候选 ω/Π_s（复用 + 迁移）
   ↓
STC：类型 / 前置蕴含 / 非干扰 / 循环上限 / 能力域 / 资源余量 六查
   ↓
E-Sched：在 (SoC, 热, 磨损, 证书年龄) 约束下选“每焦耳价值”最高的技能与精度模式
   ↓
6C 执行（ToolGauge 原样；数值真值仍由计量层独占）
   ↓
续航账本：记录预测/实际能量、热、磨损、证书刷新
   ↓
技能生命周期：晋升 / 降级 / 退休；证书到期前触发再验证
```

核心命题一句话：**把“单次修复的信息增益”升级为“任务寿命内每焦耳的可认证覆盖率”，
并让技能复用与能量约束在同一套契约里被审计。**

## 1. 形式化定义（增量：定义 432–444）

**定义 432（计量技能 Skill）** 技能 ω = (n_ω, X_ω, Y_ω, G_ω, B_ω, Φ_ω, ρ_ω, C_ω, κ_ω)：
- X_ω / Y_ω：类型化输入/输出（状态、回执、假设集）；
- G_ω：前置守卫（含物理包络与执行时刻快照谓词）；Φ_ω：后置保证（回执属性 + 语义一致性）；
- B_ω：技能体，或为一条 MTC 工具程序，或为对技能库的合法组合；
- ρ_ω = (μ_E, σ_E, μ_Θ, σ_Θ, μ_V, σ_V, μ_T, σ_T)：能量、热负荷、磨损、时间画像（均值+不确定度）；
- C_ω = (D_ω, η_ω, n_ω^val)：能力域（盲区语义描述 + 回执分布半径）、分布半径、已验证次数；
- κ_ω：技能证书（验证记录、最大实测资源、已知失败模式、版本号）。
语义：ω 是部分函数，仅在 G_ω 成立且目标盲区 s ∈ D_ω 时定义。

**定义 433（技能组合代数）** 技能库 Ω 在下列算子下取最小闭包 Ω*，每个算子带硬性侧条件：
- **SEQ(ω₁,ω₂)**：要求 Φ₁ ⇒ G₂（后置蕴含前置），回执按 Y₁→X₂ 线程化；
  ρ = ρ₁ ⊕ ρ₂（能量/热/磨损相加，方差按独立性相加；时间相加）；
- **PAR(ω₁,ω₂)**：要求 NI(ω₁,ω₂)——执行器集合、工作空间、光谱带、共享状态无写-写冲突，
  且 G₁∧G₂ 在双方并发执行下保持；ρ_E = ρ_E1+ρ_E2，ρ_Θ = ρ_Θ1+ρ_Θ2，ρ_T = max(ρ_T1,ρ_T2)；
- **BRANCH(g,ω₁,ω₂)**：g 为有界时延可测谓词；ρ ≤ max(ρ₁,ρ₂) + ρ_g；Φ = (g∧Φ₁)∨(¬g∧Φ₂)；
- **LOOP_n(ω)**：要求循环不变式 I：G_ω ⇒ I，且 I 在每轮后保持；n ≤ n_max；ρ = n·ρ_ω；
- **FALLBACK(ω₁,ω₂)**：ω₁ 后置失败时执行 ω₂；ρ ≤ ρ₁ + p_fail·ρ₂；Φ = Φ₁∨Φ₂。
**组合语义**：组合只允许在 Ω* 上递归定义；任何叶子仍必须是预注册 MTC 工具，禁止在组合层引入新物理原语。

**定义 434（技能类型系统 STC）** 类型判断 Γ; Δ ⊢ Π : (X, Y, ρ, Φ)，其中 Δ 为剩余资源上下文。
STC 逐项检查：① 接口类型匹配；② 前置守卫蕴含（含跨调用时的不变式保持，修复“只在快照检查一次”的缺陷）；
③ PAR 非干扰；④ LOOP 上限与不变式；⑤ 目标盲区 s ∈ C_ω 的能力域；⑥ 资源可行性
`ρ_pred + z_{1−δ}·σ_ρ + |Π|·ε_ρ ≤ Δ`（ε_ρ 为资源画像校准误差）。
任一失败 ⇒ 拒绝执行；VLA 可重试组合或退回 ToolGauge 扁平程序，**不得带病执行**。
STC 是 TCV 的严格推广：TCV 等价于深度为 1 的 STC。

**定义 435（续航契约 E-Contract）** EC = (E_mission, C_batt, P_max, Θ_max, V_max, ℋ, s_min, s_res, δ, TTL, recharge)：
任务总能量、电池容量、功率上限、热上限、磨损上限、任务时域、可认证覆盖率下限、安全能量储备、
置信水平、证书最大允许年龄、充电窗口。ToolGauge 的 TB-Contract 是 ℋ=单 episode、TTL=∞、
仅保留单盲区 B_tools 的退化特例。

**定义 436（续航状态与认知时效）** 系统状态 e_t = (SoC_t, Θ_t, V_t, t_rem, a_t=(a_s))，
其中 a_s 为盲区 s 的证书年龄。能量/热/磨损动力学取保守一阶模型：
```
SoC_{t+1} = min(C_batt, SoC_t − E_t + R_t)
Θ_{t+1}   = Θ_t + α·E_t − β·(Θ_t − Θ_env)
V_{t+1}   = V_t + γ·Σ_acts
```
认知时效：若漂移率为 ρ_drift，则证书年龄 a_s 下的覆盖率下界为 `1−α−ρ_drift·a_s−η′`；
再验证截止期 `d_s = t + TTL_s(δ) − a_s`，其中 TTL_s(δ) 是使上述下界不低于 1−α−δ 的最大年龄。
定义安全状态集 `S_safe = {SoC ≥ s_res, Θ ≤ Θ_max, V ≤ V_max, a_s ≤ TTL_s(δ) ∀s}`。

**定义 437（续航感知价值与 E-Sched）** 对动作 a=(s,ω,mode)（mode 见定义 439），定义每焦耳价值
```
Q(a,e) = crit(s)·ΔH(s,ω,mode) / c_eq(a)
c_eq(a) = E_a + κ_Θ·Θ_a + κ_V·V_a + κ_T·T_a
```
其中 crit(s) 为安全关键度，ΔH 为预期可认证不确定度下降，c_eq 为能量等价代价。
E-Sched 在任务时域上求解
```
max_π  E[ Σ_t crit(s_t)·ΔH_t ]   s.t.  Σ_t c_eq,t ≤ E_mission − s_res,
       a_s(t) ≤ TTL_s(δ),  SoC_t ≥ s_res,  Θ_t ≤ Θ_max,  V_t ≤ V_max
```
在线实现用能量影子价格 λ_E：仅当 `Q(a,e) ≥ λ_E` 且不违反储备/截止期才执行；
λ_E 由对偶次梯度更新。截止期用 EDF 守卫，储备用准入控制守卫。

**定义 438（技能能力域与迁移）** 对源盲区 s₀（ω 已验证）与目标 s，定义语义距离
d_C(s,s₀)（材质/光照/几何描述子的 Wasserstein 距离）与回执分布 TV 距离 η_C(s,s₀)。
复用允许 iff `d_C ≤ d_max ∧ η_C ≤ η_C^max`；迁移覆盖下界
`cov_target ≥ cov_source − L·η_C(s,s₀)`。
超出能力域 ⇒ 必须执行 n_adapt 条“适应探测”（由引理 53 给出）后才能复用，否则 STC 拒绝。
技能组合的整体覆盖 `Cov(Ω*) = P_{s~D_blind}(∃Π∈Ω*: s∈D_Π)` 作为技能库的核心指标。

**定义 439（精度模式与能量-精度 Pareto）** 每个技能 ω 有模式集 M_ω，每模式 m 给出
(ρ_ω(m), σ_obs(m), ΔH(m))。定义 Pareto 前沿
`P_ω = {m : ∄m′, ρ(m′)≤ρ(m) ∧ σ_obs(m′)≤σ_obs(m)，且至少一者严格}`。
E-Sched 只在前沿上选模式；低电量时自动沿 Pareto 前沿向低功耗端移动，实现**精度自适应退化**。

**定义 440（续航证书 Stamina Certificate）** 对策略 π 与时域 ℋ，SC(π,ℋ) 断言
`P(∀t≤ℋ: e_t ∈ S_safe ∧ Cov_cert(t) ≥ s_min) ≥ 1−δ`。
充分条件：
(C1) 每条技能的资源画像有校准误差界 ε_ρ；
(C2) 准入控制保证每次执行后 SoC 不低于 s_res；
(C3) 再验证总利用率 `U = Σ_s c_eq(renew_s)/TTL_s ≤ 1` 且 EDF 可调度；
(C4) 漂移模型在置信 1−δ/2 下成立。
四条同时成立时，证书由储备不变式 + 联合界 + Hoeffding 集中给出（引理 55）。
**证书不是装饰**：任一条件被证伪，系统必须显式撤销证书并降级，不得静默保留。

**定义 441（续航账本 Endurance Ledger）** 账本 L 为不可变、带签名的事件序列，
每条记录 `(ω, args, mode, ρ_pred, ρ_actual, e_t, receipts, outcome, ts)`。
用途：① 在线校准资源画像；② 检测能量漂移、热累积、磨损加速；③ 归因每个盲区的累计能耗；
④ 支持事故复盘与技能晋升/退休审计。账本与 ToolGauge 的工具回执共享 `seq` 单调性。

**定义 442（能量保留与退化链）** 保留策略：`SoC < s_res + margin` ⇒ 仅允许安全关键动作；
`SoC < s_res` ⇒ 停止一切探测，进入被动维持；`Θ > Θ_max` ⇒ 强制冷却；
`V > V_max` ⇒ 退休高磨损技能。退化链固定为
**EndurGauge（S-Box+E-Box）→ ToolGauge（扁平 TCV）→ LeanGauge（纯数值）→ MODGAUGE**。
若 `E_mission < E_req + s_res`，契约不可满足：必须显式重谈任务或下调 s_min，**严禁静默违约**（能量破产显式化）。

**定义 443（技能生命周期）** 候选技能经 ① STC 类型检查、② N_val 次校准盲区验证、
③ 资源画像 ECE ≤ ε_ρ、④ 安全评审，才可晋升入 Ω 并获得版本号。
出现能力域衰减、失败率上升或单位收益磨损成本上升 ⇒ 退休并保留审计记录。
技能体只能由预注册原语组合，晋升需签名账本证据 ⇒ 攻击者无法用环境文本/二维码直接注入技能。

**定义 444（继承与编号约定）** 未被本轮重定义的第 1/2 轮记号（R、s、λ、γ、M_ver、N_bl、EC、MReg、
MTC/TCV、L-Box、AP-Cal、P-Quarantine、TB-Contract 等）沿用定义 398–431。
EndurGauge 以 ToolGauge 为退化特例：Ω = 原始工具集（组合深度 1）、能量无约束、ℋ=单 episode、TTL=∞、证书恒新鲜
⇒ EndurGauge ≡ ToolGauge。

## 2. 关键算法骨架

```python
# IP-321 S-Box：技能库与组合代数
@dataclass
class Skill:
    name: str
    iface: tuple[TypeSpec, TypeSpec]
    pre:   Callable[[State], bool]           # G_ω
    body:  Union[ToolProgram, "Composition"]
    post:  Callable[[State, Receipts], bool] # Φ_ω
    rho:   ResourceProfile                   # (mu,var) for E/heat/wear/time
    comp:  Competence                        # D_ω, η_ω, n_val
    cert:  SkillCert                         # 版本、失败模式、最大实测资源

class SkillAlgebra:
    def SEQ(self, a, b):
        require(implies(a.post, b.pre))
        return Composition("SEQ", (a, b), rho=a.rho + b.rho, post=b.post)
    def PAR(self, a, b):
        require(non_interfering(a, b))       # 执行器/空间/光谱/共享状态
        return Composition("PAR", (a, b), rho=sum_energy_heat(a.rho, b.rho, time="max"))
    def BRANCH(self, g, a, b):
        require(measurable(g) and bounded_latency(g))
        return Composition("BRANCH", (g, a, b), rho=max(a.rho, b.rho) + g.rho)
    def LOOP(self, a, invariant, n_max):
        require(preserves(a, invariant))
        return Composition("LOOP", (a,), rho=n_max * a.rho, invariant=invariant)
    def FALLBACK(self, a, b):
        return Composition("FALLBACK", (a, b), rho=a.rho + a.p_fail * b.rho)

# IP-322 STC：组合类型/资源/能力域校验
class STC:
    def verify(self, pi, target, estate, budget):
        for node in topo(pi):                          # ① 接口
            if not type_match(node): return False, "iface"
            if not entails(node.pre, node.post_prev):  # ② 前置蕴含 + 不变式
                return False, "guard"
            if not non_interfering(node):              # ③ PAR 非干扰
                return False, "interference"
        if not bounded_loops(pi): return False, "loop" # ④ 循环上限
        if not in_competence(pi, target): return False, "competence"  # ⑤ 能力域
        if not resource_ok(pi, estate, budget): return False, "resource" # ⑥ 资源余量
        return True, "ok"

# IP-323 E-Box：续航状态、价值与调度
class EBox:
    def value(self, s, skill, mode, e):
        dH = expected_certified_gain(s, skill, mode, e)
        ceq = energy_equiv(skill.rho(mode))
        return self.crit(s) * dH / ceq

    def schedule(self, blind_spots, library, e):
        feasible = [a for s in blind_spots for a in candidates(s, library)
                    if self.reserve_ok(a, e) and self.deadline_ok(a, e)]
        ranked = sorted(feasible, key=lambda a: -self.value(*a, e))
        for a in ranked:
            if self.value(*a, e) >= self.lambda_E:      # 能量影子价格
                return a
        return None

# IP-324 StaminaCert：续航证书与账本
class StaminaCert:
    def issue(self, pi, horizon, e0, ledger):
        E_req = ledger.expected_cost(pi, horizon) + e0.s_res \
                + z(self.delta) * ledger.std_cost(pi, horizon)
        if e0.SoC < E_req: return None                  # 显式能量破产
        if not self.edf_feasible(pi, horizon): return None
        return Certificate(s_min=pi.s_min, s_res=e0.s_res,
                           ttl=pi.ttl, assumptions=pi.assumptions)

# IP-325 EndurGauge 主闭环
def endurgauge_round(M, obs, audio, tac, depth, det):
    for s in M.dbox.detect_blind_spot():
        e = M.ebox.state()
        if not M.ebox.safe(e):                          # 定义 442：先保命
            M.degrade(reason="energy_or_thermal")
            break
        pi = M.sbox.compose_for(s)                      # 技能组合（复用）
        ok, why = M.stc.verify(pi, s, e, M.budget_left(s))
        if not ok:
            pi = M.toolgauge.flat_program(s)            # 退化：ToolGauge
        a = M.ebox.schedule([s], M.sbox.library, e)
        if a is None:
            M.enqueue_renewal(s); continue              # 无划算动作：排再验证
        receipts = M.tcv.execute(pi.body, M.env)        # 6C 原样；PROBING 态
        M.apcal.calibrate_and_verify(receipts, pi, s)   # ToolGauge V 阶段
        M.ledger.record(pi, receipts, e)                # 定义 441
        M.sbox.update_competence(pi, receipts, s)       # 能力域在线修正
        M.staminacert.refresh(pi, M.ledger)             # 证书续租
    return MODGAUGE_round(M, obs, audio, tac, depth, det)   # 主控不变
```

## 3. 推导

**引理 51（组合的契约保持）** 若组合树 Π 的每个叶子技能在其能力域内满足自身契约，且定义 433 的全部侧条件成立，
则 Π 满足派生契约 (X,Y,ρ,Φ)；任何执行失败都被限制在失败子树内，并由 FALLBACK/退化链处理；
组合不产生叶子副作用并集之外的物理副作用。
证明：对派生树结构归纳。SEQ 由 Φ₁⇒G₂ 传递后置；PAR 由 NI 保证无写-写竞争与并发守卫保持；
LOOP 由不变式保证每轮可重启；FALLBACK 只扩大后置析取。副作用由叶子并集递归给出。

**引理 52（资源代数与保守上界）** 设资源画像经账本校准、误差为 ε_ρ，则对任意组合 Π，
实际资源消耗以概率 ≥ 1−δ 不超过
```
ρ_actual(Π) ≤ ρ_pred(Π) + z_{1−δ}·σ_ρ(Π) + |Π|·ε_ρ。
```
故 STC 的资源余量检查是**保守充分**的；能量可行性检查通过 ⇒ 不会在计划内击穿储备。
证明：对 SEQ/LOOP 用可加性与 Hoeffding；PAR 的非干扰保证能量/热/磨损可加、时间取 max；BRANCH 取 max 加评估开销。

**引理 53（技能迁移的覆盖退化）** 若目标 s 与源 s₀ 满足 TV ≤ η_C，且源技能在 s₀ 上共形覆盖为 1−α，
则迁移到 s 的覆盖至少为 `1−α−2η_C`（分布传输 + 三角不等式）。
若 η_C > η_C^max，则需至少 `n_adapt ≥ 2·log(1/δ)/η_C²` 条适应探测，把有效分布半径压回阈值；
否则 STC 拒绝复用。**系**：技能复用不是免费午餐，其收益必须扣除“能力域外推税”。

**引理 54（续航调度的近优性与稳定性）** 在资源约束可分、到达过程平稳且充放电可行的条件下，
能量影子价格策略相对离线 LP 的后悔为 `O(√ℋ)`，且 SoC 队列稳定、不击穿储备；
若截止期总利用率 U ≤ 1，EDF 对再验证截止期可行；若 U > 1，则不存在任何策略能同时满足全部 TTL，
必须显式下调 s_min 或缩短 ℋ（契约不可满足性检测）。
证明：Lyapunov 漂移加惩罚 + 对偶次梯度 + EDF 最优性。

**引理 55（续航证书的可靠性）** 在 C1–C4 成立且漂移模型置信 1−δ/2 下，
`P(∀t≤ℋ: e_t ∈ S_safe ∧ Cov_cert(t) ≥ s_min) ≥ 1−δ`，
所需能量满足 `E_mission ≥ E[Σc_eq] + s_res + z_{1−δ/2}·sd(Σc_eq)`。
证明：储备准入控制给出 SoC 不变式；每步资源集中给出能量上界；漂移模型给出覆盖率下界；三项联合界。
**系**：若账本检测到漂移率显著高于假设，证书立即失效并触发降级——证书是可证伪的，不是一次性盖章。

**引理 56（退化链与五不变式保持）** S-Box/E-Box 只作用于“选择、编排、资源分配”，
不改变任何数值契约的语义；STC 拒绝非预注册原语，技能叶子仍展开为 MTC；语言主张仍绑定有效回执；
U 阶段仍是唯一写入 EC 的路径。故 MODGAUGE 五不变式保持，且能量不足时按固定顺序剥离可选层，
不会出现“越降级越危险”的反向退化。新增失败模式“能量破产”由定义 442 显式处理。

## 6. 本轮最大风险（一句话）

**一句话**：EndurGauge 的组合安全与续航证书都建立在“技能资源/副作用可加且互不干扰、漂移模型与到达过程可校准”

7. **调度短视** → 能量影子价格 + 长期覆盖率目标 + 离线 LP 上界对照。

## 2. 形式化定义（要点）

**定义 432（技能）** `ω = (n, X, Y, G, B, Φ, ρ, C, κ)`；语义为部分函数，仅在 `G` 成立且目标 `s∈D_ω` 时定义；叶子仍为预注册 MTC 工具。
**定义 433（组合代数）** 五算子带硬侧条件：SEQ 要求 `Φ₁⇒G₂`；PAR 要求非干扰 NI；BRANCH 要求 g 可测有界；LOOP 要求不变式与 `n≤n_max`；FALLBACK 以后置析取扩大成功率。资源按代数合成（能量/热/磨损相加，时间按算子取和或 max）。
**定义 434（STC）** `Γ;Δ ⊢ Π : (X,Y,ρ,Φ)` 六查：接口类型、守卫蕴含与跨调用不变式、PAR 非干扰、循环上限、能力域、资源余量 `ρ_pred+zσ_ρ+|Π|ε_ρ ≤ Δ`。失败即拒绝执行，允许重试组合或退回扁平程序。
**定义 435（E-Contract）** 能量、热、磨损、时域、覆盖率下限、安全储备、置信度、TTL、充电窗口；TB-Contract 是 `ℋ=1, TTL=∞` 的退化物。
**定义 436（续航状态与时效）** 一阶能量/热/磨损动力学；证书年龄 `a_s` 与漂移率 `ρ_drift` 给出覆盖率下界；安全集 `S_safe = {SoC≥s_res, Θ≤Θ_max, V≤V_max, a_s≤TTL_s}`。
**定义 437（E-Sched）** `Q = crit(s)·ΔH / c_eq`，`c_eq = E+κ_ΘΘ+κ_VV+κ_TT`；在能量、截止期、热、磨损约束下最大化长期价值；在线用影子价格 `λ_E` 与 EDF/储备守卫。
**定义 438（能力域与迁移）** 语义距离 `d_C` 与回执分布 TV `η_C`；复用 iff `d_C≤d_max ∧ η_C≤η_C^max`；迁移覆盖 `cov_target ≥ cov_source − L·η_C`；否则强制 `n_adapt ≥ 2log(1/δ)/η_C²` 条适应探测。
**定义 439（精度模式）** 每技能有 `(ρ(m), σ_obs(m), ΔH(m))`；只在 Pareto 前沿上选模式，低电量沿前沿降精度。
**定义 440（续航证书）** `P(∀t≤ℋ: e_t∈S_safe ∧ Cov_cert(t)≥s_min) ≥ 1−δ`；充分条件 C1–C4：资源误差界、储备准入、再验证利用率 `U≤1` 且 EDF 可行、漂移模型成立。证书可被账本证伪，证伪即撤销并降级。
**定义 441（续航账本）** 不可变、签名的事件 `(ω,args,mode,ρ_pred,ρ_actual,e_t,receipts,outcome,ts)`；用于在线校准、漂移检测、能耗归因与技能晋升审计。
**定义 442（能量保留与退化链）** 保留策略 + 固定退化顺序；`E_mission < E_req+s_res` 时显式“能量破产”，必须重谈或下调 `s_min`，禁止静默违约。
**定义 443（技能生命周期）** 晋升需 STC + `N_val` 验证 + 资源 ECE ≤ ε_ρ + 安全评审；能力衰减/失败率/磨损成本上升则退休；只允许预注册原语组合，防技能库污染。
**定义 444（继承）** 旧记号沿用定义 398–431；EndurGauge 在“Ω=原始工具、能量无约束、ℋ=1、TTL=∞”时退化为 ToolGauge。

## 3. 关键算法骨架

```python
# IP-321 S-Box：技能组合
class SkillAlgebra:
    def SEQ(self, a, b):      require(implies(a.post, b.pre));  return Comp("SEQ", a, b, rho=a.rho+b.rho)
    def PAR(self, a, b):      require(non_interfering(a, b));    return Comp("PAR", a, b, rho=sum_eh(a.rho,b.rho,time="max"))
    def BRANCH(self, g, a, b): require(bounded(g));              return Comp("BRANCH", g, a, b, rho=max(a.rho,b.rho)+g.rho)
    def LOOP(self, a, inv, n): require(preserves(a, inv));       return Comp("LOOP", a, inv, n, rho=n*a.rho)
    def FALLBACK(self, a, b): return Comp("FALLBACK", a, b, rho=a.rho + a.p_fail*b.rho)

# IP-322 STC：六查
class STC:
    def verify(self, pi, target, estate, budget):
        checks = [type_ok(pi), guard_ok(pi), non_interfering(pi),
                  loop_ok(pi), in_competence(pi, target),
                  resource_ok(pi, estate, budget)]
        return all(checks), first_failure(checks)

# IP-323/324 E-Box：续航调度
class EBox:
    def value(self, s, skill, mode, e):
        return self.crit(s) * expected_certified_gain(s, skill, mode, e) \
               / energy_equiv(skill.rho(mode))
    def schedule(self, spots, library, e):
        cand = [a for s in spots for a in candidates(s, library)
                if self.reserve_ok(a, e) and self.deadline_ok(a, e)]
        a = max(cand, key=lambda a: self.value(*a, e))
        return a if self.value(*a, e) >= self.lambda_E else None   # 影子价格闸门

# IP-325 StaminaCert：证书签发与续租
class StaminaCert:
    def issue(self, pi, horizon, e0, ledger):
        E_req = ledger.expected_cost(pi, horizon) + e0.s_res \
                + z(self.delta) * ledger.std_cost(pi, horizon)
        if e0.SoC < E_req or not self.edf_feasible(pi, horizon):
            return None                                    # 显式能量破产/截止期不可行
        return Certificate(s_min=pi.s_min, s_res=e0.s_res, ttl=pi.ttl)

# IP-326 SkillLife：晋升/退休
class SkillLife:
    def promote(self, cand, ledger):
        if all([stc_ok(cand), cand.comp.n_val >= N_val,
                resource_ece(cand, ledger) <= EPS_RHO, safety_review(cand)]):
            return self.library.add(cand, version=self.next_version())
    def retire(self, skill, ledger):
        if competence_decayed(skill) or failure_rate(skill) > F_MAX \
           or wear_cost(skill) > W_COST_MAX:
            self.library.deprecate(skill, evidence=ledger.slice(skill))

# IP-327 EndurGauge 主闭环
def endurgauge_round(M, obs, audio, tac, depth, det):
    for s in M.dbox.detect_blind_spot():
        e = M.ebox.state()
        if not M.ebox.safe(e):                              # 先保命：能量/热/磨损
            M.degrade(reason="energy_or_thermal"); break
        pi = M.sbox.compose_for(s)                          # 复用技能组合
        ok, why = M.stc.verify(pi, s, e, M.budget_left(s))
        if not ok: pi = M.toolgauge.flat_program(s)         # 退化到 ToolGauge
        a = M.ebox.schedule([s], M.sbox.library, e)
        if a is None: M.enqueue_renewal(s); continue
        receipts = M.tcv.execute(pi.body, M.env)            # 6C 原样
        M.apcal.calibrate_and_verify(receipts, pi, s)       # V 阶段
        M.ledger.record(pi, receipts, e)                    # 定义 441
        M.sbox.update_competence(pi, receipts, s)           # 能力域修正
        M.staminacert.refresh(pi, M.ledger)                 # TTL 续租
    return MODGAUGE_round(M, obs, audio, tac, depth, det)   # 主控不变
```

## 4. 推导

**引理 51（组合契约保持）** 叶子契约成立 + 五算子侧条件 ⇒ 组合树满足派生契约；失败被限制在失败子树，由 FALLBACK/退化链处理；无叶子并集之外的副作用。证明：结构归纳。
**引理 52（资源代数上界）** 校准误差 ε_ρ 下，`ρ_actual(Π) ≤ ρ_pred(Π)+z_{1−δ}σ_ρ(Π)+|Π|ε_ρ`；故 STC 资源检查保守充分，能量可行性不击穿储备。证明：SEQ/LOOP 可加 + Hoeffding，PAR 非干扰，BRANCH 取 max。
**引理 53（迁移覆盖退化）** `TV≤η_C` 时 `cov_target ≥ 1−α−2η_C`；超出阈值需 `n_adapt ≥ 2log(1/δ)/η_C²` 条适应探测。**系**：技能复用收益必须扣除“能力域外推税”。
**引理 54（续航调度近优性）** 平稳可分资源下，影子价格策略相对离线 LP 的后悔 `O(√ℋ)`，SoC 稳定不击穿储备；`U≤1` 时 EDF 对再验证截止期可行，`U>1` 时必须重谈 `s_min` 或 `ℋ`。证明：Lyapunov 漂移加惩罚 + 对偶 + EDF 最优性。
**引理 55（续航证书可靠性）** C1–C4 且漂移模型置信 1−δ/2 ⇒ `P(∀t≤ℋ: e_t∈S_safe ∧ Cov≥s_min) ≥ 1−δ`，所需能量 `E_mission ≥ E[Σc_eq]+s_res+z_{1−δ/2}sd(Σc_eq)`。证明：储备不变式 + 资源集中 + 漂移下界 + 联合界。**系**：账本检出漂移率偏高 ⇒ 证书立即失效并降级。
**引理 56（退化链与五不变式保持）** S-Box/E-Box 只改选择/编排/资源分配，不改数值契约语义；STC 拒绝非预注册原语；U 仍是唯一写入 EC 的路径；能量不足时按固定顺序剥离可选层 ⇒ 五不变式与严格退化链保持，新增“能量破产”显式处理。

## 5. 复杂度分析

| 组件 | 域 | 时间 | 空间 | 正确性锚 |
|---|---|---|---|---|
| S-Box 组合检索 | 异步事件 | O(\|Ω\|·d_C) < 3ms | O(\|Ω\|) | 定义 432/438 |
| STC 六查 | 异步 | O(\|Π\|·(\|T₀\|+log\|Ω\|)) < 10ms | O(\|Π\|) | 定义 434、引理 51/52 |
| E-Sched 单事件 | 异步 | O(K·\|M\|·log K) < 5ms | O(K·\|M\|) | 定义 437、引理 54 |

**相对 ToolGauge 的关键改进**：单次修复不一定更快，但第 N 个盲区的**边际规划/验证成本随技能库增长而下降**；
能量从“单盲区硬预算”升级为“跨盲区可调度、可储备、可充电”的长期资源；证书从“一次性通过”升级为“带 TTL 的租约”。
**总增开销**：50Hz 路径 ≤ 0.1ms/周期（账本可异步）；稀疏事件 < 40ms；技能生命周期可离线。

## 8. 本轮最大风险

**一句话**：EndurGauge 的组合安全与续航证书都建立在“技能资源/副作用可加且互不干扰、漂移模型与到达过程可校准”
这一强假设上；真实系统的热-机械-磨损耦合、技能间隐性资源共享与漂移突变会让证书系统性乐观，
于是系统可能在“已被认证”的错觉中把能量花在错误的技能组合上，直到一次跨技能的相关失效与能量破产同时发生。
