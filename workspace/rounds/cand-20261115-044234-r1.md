# 第 4 轮（灵感循环第 4 轮；本轮灵感：「论文创新点」×「ROS」）

> **基线**：第 3 轮 InstructGauge（IP-321–327；定义 432–447；引理 51–58；实验 E441–E456）。第 2 轮 ToolGauge、第 1 轮 LeanGauge / MODGAUGE 骨架继续继承不变。
> 本轮纪律：**运行时落地 + 可证伪前置**。两个新灵感各沿一条轴升级 InstructGauge：ROS 把「证据契约」编译到分布式运行时的物理语义上；「论文创新点」把「主张」升级为可消融分离、可重放兑现的账本条目。任一环节不可用都必须能一键退回。

## 0. 直觉与动机

**灵感 1（ROS → 把「证据新鲜度」从算法假设变成运行时强制）**
直觉：前三轮一直把 CVC 的漂移界 `δ_c`、块长 `K`、回执时效当作「算法内部的数」。但在真机上，这些量其实由消息中间件决定：ROS 2 的 QoS 政策（reliability / durability / deadline / lifespan / liveliness / history）直接回答四个物理问题——一条回执**最晚多久会到**、**会不会静默丢**、**节点重启后还在不在**、**对端死了多久才被发现**。也就是说，第 3 轮的「证据陈旧窗口 K」在 ROS 里有一个可测量的对应物：`deadline` 与 `lifespan` 的较小者。正确做法不是让算法「假设」中间件可靠，而是把每个安全相关证据契约**编译成一组 QoS 政策并做可判定检查**：例如「BEST_EFFORT 回执去喂不可逆屏障」必须在部署前被类型系统拒绝，而不是靠运行时撞运气。ROS 的 lifecycle node 还顺带给了「只在块静默点热替换」一个现成实现：先 configure 一个 inactive 影子节点，在静默点 activate，再 deactivate 旧的——热替换从「口头约定」变成「状态机迁移」。

**灵感 2（论文创新点 → 把「贡献」定义为可消融分离的命题，而不是叙述）**
直觉：研究循环最危险的不是做不出东西，而是把「我做了 A 和 B」写成「A、B 各有创新」，审稿人只需问一句「去掉 A 会怎样」就穿帮。一个真正的创新点应满足三条可检验条件：(i) 相对一个**明确否定基线** b 有方向性效应；(ii) 存在**最小消融集** `A_min`，去掉它效应就消失；(iii) 有**预先注册的判别实验**把效应量与置信区间钉死。把这三条写成记录，「创新点」就从修辞变成账本条目；而且能机械地防重复计数——两条主张若共享同一判别实验、且 `A_min` 互相嵌套，它们就不是两条独立创新，而是同一条被拆卖（salami-slicing）。

**灵感 3（两者耦合 → 账本条目必须能被运行时证据兑现）**
直觉：ROS 回答「证据从哪来、多新、能否重放」，账本回答「贡献由哪条证据支撑」。耦合点是**证据可重放性**：若一条创新点声称「QoS 编译消除了越界动作」，它必须能在一次 rosbag2 回放中逐条复现，否则只是日志里的一句话。因此本轮把第 3 轮的 NCB（主张-回执绑定）再升一级为**三级绑定**：贡献条目 ↔ 判别实验 ↔ 可回放回执；任一级缺失，条目降级为「未验证主张」，不进论文创新点清单。

## 1. 研究问题（本轮要回答什么）

- **Q1（运行时契约）**：能否把证据契约编译为 ROS 2 QoS + lifecycle 政策，并在**部署前**判定「该配置在语义上不可能支撑某类安全决策」？
- **Q2（严格收紧）**：QoS 引入的新鲜度上界是否只会**收紧**第 3 轮的块长 `K`、绝不放大？信息缺失时是否严格退化？
- **Q3（贡献核算）**：「论文创新点」能否操作化为可消融分离、可重放兑现的账本条目，并机械地杜绝重复计数与「整体即创新」的偷换？

## 2. 三条设计原则（雏形，正式化见产物区定义 448–464）

**P1 QoS 即证据契约的物理语义（QoS-as-Evidence）**
每条逻辑证据契约 `κ = (类型, 时效下界, 有效期, 关键度, 持久化要求)` 编译为一个 QoS profile `θ`；可采纳谓词 `Adm(κ, θ)` 是**可判定**的，且在部署前运行。核心红线：任何进入不可逆屏障判定或 CVC 安全否决的回执，其 `reliability` 必须是 `RELIABLE`；审计用回执必须有 `TRANSIENT_LOCAL` 或外部持久化。允许丢弃的传感器流才可 `BEST_EFFORT`，且**永远不得**参与安全否决。

**P2 生命周期即热替换（Lifecycle-as-Swap）**
新契约版本以 **inactive 影子节点**形态进入图：`configure` 完成、输出被门控；仅在 `q_quiesce`（第 3 轮定义 439）执行 `activate(new) → deactivate(old) → cleanup(old)`。激活失败则旧节点保持 active，迁移原子回滚。热替换不再是「约定」，而是状态机上的可验证迁移序列。

**P3 可消融分离的创新点（Ablation-Separated Contribution）**
创新点 `γ = (主张 c, 基线 b, 效应 Δ, 最小消融集 A_min, 判别实验 E_f, 新颖性类 ψ)`。计数规则：`γ` 计入独立创新当且仅当 `Disc(γ)`（消融后效应在预注册 CI 下消失）成立且 `A_min ≠ ∅`。共享同一 `E_f` 且 `A_min` 互相嵌套的条目合并为一条。由此「创新点数量」是一个**保守下界**：账本只会少计，绝不多计。

## 3. 与基线的接口（如何退化）

- QoS 信息不可得 / `Adm` 无法判定 ⇒ 退回第 3 轮纯逻辑契约，`K ≤ K_MAX(ι)`；ROS 层隐藏。
- `fresh(θ) < Δt_exec`（连一步都撑不住）⇒ 强制 `K=1`，等价 ToolGauge 逐步执行。
- lifecycle 迁移失败 / 影子节点不可用 ⇒ 禁止热替换，冻结旧契约（安全优先）。
- 时钟非仿真 / 回放不可用 ⇒ 账本条目降级为「未验证」，不删除但不可计入创新点。
- 所有新组件失效 ⇒ 逐级回退 InstructGauge → ToolGauge → LeanGauge → MODGAUGE 原样。

## 4. 预期贡献

1. 一个 **QoS-证据契约编译器**：把安全相关证据的时效/持久化/活性要求变成部署前可判定的准入条件，堵住「中间件静默丢包导致安全否决失效」这一类隐蔽漏洞；
2. 一个**只收紧不放大**的分块-QoS 适配层：`K ≤ min(K_MAX(ι), K_MAX^QoS)`，并在新鲜度不足时优雅退化为 `K=1`；
3. 一个**影子生命周期热替换**协议：把「静默点热替换」从假设变成可回滚的状态机迁移；
4. 一个 **Contribution Ledger**：把「论文创新点」形式化为可消融分离记录，配判别实验矩阵与可重放审计，机械防止重复计数；
5. 一条可证伪路径：E457–E472 覆盖 QoS 准入、块长收紧、影子迁移、确定性回放、账本非重复、时钟偏斜、跨发行版语义一致与人类评审一致性。

## 5. 本轮最大风险

**一句话**：QoS 契约与贡献账本会共同制造一种「已经工程化、已经量化」的严谨错觉——QoS 可能静默丢弃关键回执而账本仍给出漂亮的消融数字，于是论文创新点沦为**账本伪影**（bookkeeping artifact），真正的残余风险是「运行时证据是否真的被兑现」而不是记录是否整齐。

## 2. 形式化定义（要点）

**定义 448（ROS 2 图与 QoS profile）** `θ = (rel ∈ {RELIABLE, BEST_EFFORT}, dur ∈ {VOLATILE, TRANSIENT_LOCAL}, hist ∈ {KEEP_LAST(d), KEEP_ALL}, deadline, life, live)`。图 `G` 上的每条边绑定一个 `θ`；同一逻辑通道的 writer/reader 必须 QoS 兼容（reader 要求不得强于 writer 提供，否则 DDS 不匹配）。

**定义 449（逻辑证据契约 κ）** 对每类回执（感知、探测、回执、校准、审计）定义 `κ`。`crit ∈ {advisory, safety, barrier}`；`persist ∈ {none, session, durable}`。契约不关心实现，只声明「这条证据在被用于何种决策前必须满足什么时效与留存」。

**定义 450（QoS-契约编译 QCC 与可采纳性 Adm）** `QCC: κ → θ`，规则：
- `crit=barrier ∨ safety` ⇒ `rel=RELIABLE`；`crit=barrier` ⇒ 额外要求独立通道交叉验证。
- `τ_fresh` ⇒ `deadline ≤ τ_fresh` 且 `life ≤ τ_fresh`。
- `τ_valid` ⇒ `life ≤ τ_valid`（过期回执不得再被 CVC 使用）。
- 时间集成窗口 `m` ⇒ `hist.depth ≥ m`（KEEP_LAST）或 `KEEP_ALL`。
- `crit≥safety` ⇒ `live ≤ 2·Δt`（对端停摆须在下一 CVC 前被察觉）。
- `persist=durable` ⇒ 外部 rosbag2/存储；`session` ⇒ `TRANSIENT_LOCAL`。
`Adm(κ,θ)` 逐条检查；任一违反 ⇒ 编译失败（**部署前拒绝**，而非运行时告警）。特别地：`crit=barrier ∧ rel=BEST_EFFORT ⇒ ⊥`。

**定义 451（有效新鲜度）** `fresh(θ) = min(deadline, life) − margin(J,ρ)`，其中 `J` 为传输抖动上界、`margin` 随时钟漂移率 `ρ` 线性增长。这是**可被 CVC 使用的证据年龄上界**；若 `fresh(θ) ≤ 0` 则契约不可用。

**定义 452（QoS 收紧块长）** `K_MAX^QoS(θ) = ⌊(fresh(θ) − J_exec) / Δt_exec⌋`，`Δt_exec` 为单步执行周期。运行时约束 `K ≤ min(K_MAX(ι), K_MAX^QoS(θ))`。注：这是**交集式收紧**，因此引入 QoS 只能让块更短，不可能更长。

**定义 453（生命周期影子激活 Λ）** 新版本节点以 `unconfigured → inactive` 存在，输出经 gate 丢弃（不发布或 remap 到死 topic）。迁移仅在 `q_quiesce`：`activate(new)` 成功后 `deactivate(old) → cleanup(old)`；若 `activate` 失败或超时，`deactivate(new)` 并保留 old。任何时刻恰有一个 active 契约版本。

**定义 454（契约版本钉扎）** 每条在途块 `C` 记录其 `pin(v_κ)`；CVC 用 pin 的版本复核，绝不在块中途切换契约语义。版本号在 `ReviewBundle` 中可见，保证审计可复现。

**定义 455（贡献记录 γ）** `γ=(c,b,Δ,A_min,E_f,ψ)`：`c` 为可判定命题（含指标与方向），`b` 为明确否定基线（消融基线，不是「无系统」），`Δ` 为预注册效应量，`A_min` 为实现该效应所需的最小组件集（`A_min ⊆ {IP…}`），`E_f` 为判别实验 id，`ψ ∈ {机制, 系统, 方法, 观察}` 为创新类型。

**定义 456（判别实验 Disc）** 设 `E_f` 在「完整系统」与「完整系统去掉 A_min」两种配置下各跑预注册次数，指标为 `μ`。`Disc(γ) ⟺ |μ(full) − μ(full∖A_min)| > δ_min ∧ CI_pre 不含 0 ∧ 方向与 c 一致`。若 `A_min=∅`，`Disc` 恒假（没有可移除之物，就不是创新）。

**定义 457（贡献等价与去重）** `γ₁ ~_γ γ₂ ⟺ E_{f,1}=E_{f,2} ∧ (A_{min,1} ⊆ A_{min,2} ∨ A_{min,2} ⊆ A_{min,1})`。等价类内只保留 `A_min` 最小者。注意这是**保守**去重：真正独立但恰好共享一个实验的两条贡献会被并成一条（少计，不多计）。

**定义 458（独立创新计数）** `Indep(Γ) = |{ [γ]_{~_γ} : Disc(γ)=⊤ }|`。论文创新点清单输出的是商集代表，而非原始记录数；每个代表附 `E_f` 与 `A_min`。

**定义 459（回放可兑现 Replay）** 在 `use_sim_time=true`、单线程确定性 executor、所有随机源（VLA 采样、校准抽样）种子已记录、所有输入 topic 以 `RELIABLE` 且历史充足录制的条件下，回放决策序列哈希 `h(τ)` 与原运行相等。`Replay(γ)=⊤` 当且仅当支撑 `γ` 的全部回执在回放中逐条复现。

**定义 460（三级绑定 LedgerBind）** `LedgerBind(γ) = (γ, E_f 的执行记录, {receipt_id})`。仅当 `Disc(γ) ∧ Replay(γ)` 时 `γ` 进入「已验证创新点」；仅有 `Disc` 无回放 ⇒ 「统计成立但不可复现」；仅有意向 ⇒ 「未验证主张」。

**定义 461（QoS 降级算子 ↓_QoS）** 当观测到丢包率超阈、`deadline` 连续 miss 或 `liveliness` 丢租约：`↓_QoS: (K,m) → (1,1)`，停止时间集成，回退最近已验证单步；若 `crit=barrier` 则同时挂起不可逆动作直到独立回执到达。降级是**单向安全**的：只降低能力，不降低安全约束。

**定义 462（时钟域与保守新鲜度）** 在 `/clock` 仿真域中 `fresh` 用仿真时间计算；跨域（wall↔sim）时取 `skew` 上界并从 `fresh` 中扣除，确保「宁可认为证据更旧」。

**定义 463（贡献-实验矩阵）** `M_claim×exp[i,j]=1` 表示 `E_f=j` 支撑 `γ=i`。要求每个实验列至少被一个贡献引用，每个贡献行至少有一个实验；空列是「做了没写」，空行是「写了没做」，均须在 `ReviewBundle` 中显式说明。

**定义 464（审稿可复核包 ReviewBundle）** `(G 拓扑与 QoS, 契约版本 pin, 贡献账本 Γ, M_claim×exp, 回放哈希, 预注册协议)`，使第三方能仅凭此包复核每条创新点而不接触原始机器人。

## 3. 关键算法骨架

```python
# IP-328 QCC：逻辑契约 → QoS，部署前准入
def compile_qos(kappa):
    theta = QoS(reliability=RELIABLE if kappa.crit in ("safety", "barrier")
                         else BEST_EFFORT,
                durability=TRANSIENT_LOCAL if kappa.persist != "none"
                           else VOLATILE,
                history=KEEP_LAST(max(kappa.m, 1)),
                deadline=kappa.tau_fresh,
                lifespan=min(kappa.tau_fresh, kappa.tau_valid),
                liveliness=AUTOMATIC if kappa.crit != "advisory" else None,
                lease=min(2 * DT, kappa.tau_fresh))
    return theta if Adm(kappa, theta) else None      # None ⇒ 部署前拒绝

def Adm(kappa, theta):
    if kappa.crit == "barrier" and theta.rel != RELIABLE:   return False
    if theta.deadline > kappa.tau_fresh:                    return False
    if theta.lifespan > kappa.tau_valid:                    return False
    if kappa.crit != "advisory" and theta.lease > 2 * DT:   return False
    if kappa.m > theta.history_depth:                        return False
    if kappa.persist == "durable" and not theta.external_store: return False
    return True

# IP-329 QFA：QoS 收紧块长（只收紧）
def chunk_len_qos(iota, theta, drift_bound):
    k_logical = chunk_len_instruct(iota, drift_bound)       # 第 3 轮 K_MAX(ι)
    fresh = min(theta.deadline, theta.lifespan) - margin(J, rho)
    if fresh <= 0: return 1                                  # 连一步都撑不住
    k_qos = floor((fresh - J_exec) / DT_EXEC)
    return max(1, min(k_logical, k_qos))                     # 交集收紧

# IP-330 LCS：影子生命周期热替换
def hot_swap(nodes, old_id, new_contract, boundary):
    if not is_quiescent(boundary):          return "deferred"
    new = nodes.configure(inactive_copy(old_id, new_contract))
    if not wait_configured(new, timeout=T_conf): return "rollback_kept_old"
    if not nodes.activate(new):             return "rollback_kept_old"
    nodes.deactivate(old_id); nodes.cleanup(old_id)
    return "swapped"                                      # 恰一个 active 版本

# IP-331 CL：贡献账本与去重
def ledger_commit(gamma, runs):
    if not gamma.A_min:                         return classify(gamma, "not_a_contribution")
    if not Disc(gamma, runs, alpha=PRE_ALPHA):  return classify(gamma, "rejected")
    for g in ledger:
        if equivalent(gamma, g):                 # 共享实验 + 嵌套消融
            keep_minimal(g, gamma); return classify(gamma, "merged")
    if not Replay(gamma, runs):                  return classify(gamma, "unreplicated")
    ledger.add(gamma); return classify(gamma, "verified")

# IP-332 RRA：确定性回放
def replay_audit(bag, seeds, params):
    with sim_time("/clock"), deterministic_executor(single_thread=True):
        replayed = run_pipeline(bag, seeds=seeds, params=params)
    return hash_decision_sequence(replayed) == hash_decision_sequence(bag.original)

# IP-333 ROSGauge-8C
def rosgauge_8c(M, s, ell):
    kappa = M.contracts.for_region(s)
    theta = M.qcc.compile_qos(kappa)
    if theta is None: return M.instructgauge_7c(M, s, ell)   # 部署前拒绝 ⇒ 退化
    iota  = M.nlib.ground(ell, M.scene, M.ontology)[0] or M.default_iota
    H     = M.lbox.hypothesize(s, M.dbox.R[s], iota)
    K     = M.qfa.chunk_len_qos(iota, theta, M.drift_bound(s))
    C     = M.iac.plan_chunk(iota, H, M.tools, M.budget_left(s), M.drift_bound(s), K)
    if crosses_irreversible(C, I_IRR): C = truncate_at_barrier(C, I_IRR)
    cert  = M.cvc.commit(C, M.env, iota)
    if not M.rra.replayable(cert): return stub_and_red(s, "unreplayable")
    mu, Sig = M.apcal.calibrate(cert.receipts, H, s)
    if not M.apcal.cross_validate(mu, Sig, M.cross_receipt(s)):
        return stub_and_red(s, "cross_failed")
    M.lcs.hot_swap(M.nodes, M.active_id, new_contract(mu, Sig), cert.boundary)
    M.ledger.commit_from_run(s, cert)
    return True
```

## 4. 推导

**引理 59（QoS 可采纳性 ⇒ 证据年龄可靠）** 若 `Adm(κ,θ)` 成立，且回执经该 `θ` 通道送达，则任一被 CVC 接受的回执年龄 `≤ fresh(θ)`；若 `crit=barrier`，其可靠性不为 BEST_EFFORT。故 CVC 的 `drift ≤ δ_c` 检查不会因中间件静默丢弃/过期而被「幸运通过」。
*证明骨架*：DDS 语义给 `deadline`（writer 周期内必发）与 `lifespan`（样本超过即失效）上界，`TRANSIENT_LOCAL` 给 late-joiner 历史；`RELIABLE` 排除静默丢包。取 `min(deadline,lifespan)` 再减去抖动与时钟偏斜余量即得年龄上界。`Adm` 逐条保证这些前提。BEST_EFFORT 可能丢包，故对 barrier 直接判不采纳。

**引理 60（QoS 只收紧块长且严格退化）** 对任意可用 `θ`，`K ≤ min(K_MAX(ι), K_MAX^QoS(θ)) ≤ K_MAX(ι)`；若 `θ` 不可得或 `fresh(θ)≤0`，取 `K=1` 或退回第 3 轮 `K_MAX(ι)`。即引入 ROS 层**不能**让块比第 3 轮更长。
*证明*：`K_MAX^QoS=⌊(fresh−J_exec)/Δt_exec⌋` 只依赖 `θ`；运行时取交集，故上界单调不增。退化分支按定义 452 与第 3 轮定义 440 直接得到。

**引理 61（影子生命周期迁移的观测等价与回滚）** 若迁移只在 `q_quiesce` 发生、inactive 影子输出被 gate 丢弃、且 `activate` 成功后才 `deactivate(old)`，则未涉及子图看到的输入消息序列与迁移前逐条相同；`activate` 失败时旧节点保持 active，系统状态与迁移前等价。
*证明骨架*：`q_quiesce`（第 3 轮定义 439）保证无在途块、无待处理不可逆动作，故不存在「半新半旧」的块；gate 保证影子在 inactive 期间不贡献输出；迁移序列是状态机上的有限链，失败分支停在原状态。回到第 3 轮引理 57 与第 1 轮子图逐指令等价。

**引理 62（账本不重复计数）** 按 `~_γ` 取商后，`Indep(Γ) ≤ |{E_f}|`，且任意两条被计数的贡献要么判别实验不同，要么 `A_min` 非嵌套；因此账本**绝不会高估**独立创新数，只可能低估（共享实验的独立贡献被合并）。
*证明*：`~_γ` 由 `(E_f, A_min 嵌套)` 定义，商集每个元素对应唯一的「实验 + 最小消融」对；`Indep` 只数 `Disc` 成立的类。注入到实验 id 即得 `≤ |{E_f}|`；合并规则只会减少计数，故为上界保守。

**引理 63（贡献可重放性）** 在 `use_sim_time`、确定性单线程 executor、随机种子与参数全部记录、输入 topic `RELIABLE` 且历史充足的条件下，回放决策序列哈希与原运行一致；因此 `Replay(γ)=⊤` 可作为 `γ` 的独立证据。
*证明骨架*：管道中非确定源仅来自时钟、调度与随机采样三类；三者分别被 `/clock`、单线程确定性调度与显式种子消除；消息无损由 `RELIABLE` 与足够 history 保证。哈希对决策序列敏感，故一致即逐条可复现。

**引理 64（无免费创新）** 若 `A_min=∅`，则 `Disc(γ)=⊥`，`γ` 不计入 `Indep`。因此「整个系统相对空基线更好」不能被称为一个创新点；创新必须可归因到至少一个可移除组件。
*证明*：`Disc` 比较 `full` 与 `full∖A_min`；`A_min=∅` 时两配置相同，差值恒为 0，不满足 `>δ_min`。由定义 458 不计入。

## 8. 本轮最大风险

**一句话**：QoS 契约与贡献账本共同制造「已工程化、已量化」的严谨错觉——中间件可能静默丢弃关键回执而账本仍产出漂亮的消融数字，使论文创新点沦为账本伪影；真正的残余风险是运行时证据能否被兑现，而非记录是否整齐。
