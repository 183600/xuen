# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC IP-153~160；灵感循环第 7 轮；本轮灵感：「场景泛化」×「情感计算」）

> 第 60 轮把「场景」从物理障碍升级为阻抗先验 π_scene(K|z)，并用 CIEC/EPIR/SERC 把认知、意图、证据串成闭环。但**三个根本局限**仍暴露：
> 1. **场景泛化被闭集化**：Z_scene 固定为 10 个标签，`unknown` 只能回退 π_general。真实场景是**连续因子的组合**（粗糙度×坡度×摩擦×柔顺性×杂乱度），未见场景大多是「已见因子的新组合」，闭集分类把可泛化问题误当成拒识问题。
> 2. **情感是缺失的风险观测**：CIEC 只处理显式语言意图（「慢点」「轻触」），而人在陌生/危险场景中的**压力、犹豫、信任、紧张**是连续、高带宽、先于语言出现的风险信号；第 60 轮把它们全部丢弃，导致「场景风险」只能由几何/力估计。
> 3. **泛化与交互解耦**：OOD 场景恰恰是人最焦虑、机器人行为最影响信任的场景；第 60 轮把「场景不确定性」和「人的状态」当作两条独立支路，既浪费了「情感作为跨场景风险探针」的价值，也无法防止「机器人越讨好用户、安全裕度越小」的情感谄媚。

## 0. 直觉与动机

**灵感 1（场景泛化 → 组合场景因子 CSF）**
直觉：场景不是「桌子/楼梯/湿地」这些标签，而是若干近正交因子的笛卡尔积：f=(粗糙度 ρ, 坡度 θ, 摩擦 μ, 柔顺性 κ, 杂乱度 c, 尺度 s)。见过「光滑-高摩擦-平地」和「粗糙-低摩擦-斜坡」后，面对「粗糙-高摩擦-斜坡」这个**从未见过的组合**，人仍能预测其阻抗。关键洞见：**泛化 = 因子空间中的结构化插值，而非类别间的最近邻**；把 K(f) 约束为「低秩 + 稀疏可加 + 少量交互」结构，可直接得到与支撑集距离 d(f,S_obs) 相关的泛化误差上界，并把 `unknown` 从一个类别变成一个**可度量的支撑距离**。

**灵感 2（情感计算 → 情感状态推断 AFI）**
直觉：人的情感是可观测的连续状态 a=(效价 v, 唤醒 ar, 压力 σ, 信任 τ, 犹豫 h)，通过语音韵律、面部动作单元、心率变异性 HRV、皮电 EDA、响应时延、握持力等线索外显。关键洞见：**情感是「潜在风险」的跨场景不变观测**——同一句「没事」在桌面上和在湿滑楼梯上代表的风险不同，但「声线发紧 + 犹豫 + 心率升高」在两个场景中都指向「我不确定、可能危险」。因此 affect 可以作为一种**免费的 OOD 风险探针**，在几何看不出来（透明、黑面、薄布覆盖）时提供独立证据。

**灵感 3（情感 → 约束 ACR）**
直觉：显式意图是离散、低带宽、事后才到的；情感是连续、高带宽、先于语言的。把 a 映射为「情感安全裕度」：压力↑/犹豫↑ ⇒ K_d↑、v_max↓、F_max↓、柔顺性↑。关键洞见：**情感只能收紧、不能放宽安全约束（one-sided safety）**。否则会出现「情感谄媚」：机器人为了让用户「看起来满意」而压缩安全裕度。ACR 用单调、有界、带迟滞的调节律，保证安全底线与 affect 解耦。

**灵感 4（泛化 × 情感互证 ARX）**
直觉：场景新颖度 d(f,S_obs) 与情感异常 e_t 是潜在风险 r 的两个**条件近似独立**证据。两者同高 ⇒ 保守 + 请求确认；新颖度高但情感平静 ⇒ 仍保守但主动探针；新颖度低但情感异常 ⇒ 可能是「几何看不见的隐藏风险」（反光/透明/湿滑/既往创伤）⇒ 探针 + 收紧；两者都低 ⇒ 正常执行。关键洞见：**冲突本身是信号**——它同时覆盖 LiDAR/视觉域偏移与真实场景异常，并把「人机互证」变成可计算的风险后验。

**灵感 5（合流 → 情感感知场景泛化闭环 ASGL 与 PCE-GA）**
直觉：CSF 把场景变成因子 → CGP 给出有覆盖保证的阻抗集合 → AFI 推断情感 → ARX 融合两类风险 → ACR 单调收紧约束 → EEIS 编译 → 执行 → EV-exec 回写因子模型和情感校准。闭环为：**因子编码→支撑距离→保形集→情感推断→互证→约束收紧→执行→证据→模型更新**。PCE-GA 在四维认知预算上增加 B_gen（泛化/保形/OOD 检测算力）与 B_aff（情感推断/隐私保护/调节开销），任一耗尽即降级：B_gen 耗尽 ⇒ 放弃组合外推、改用保守保形集；B_aff 耗尽 ⇒ 情感通道关闭、回退显式意图 + 基础安全裕度。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（组合场景因子 CSF）** 场景从类别改写为因子：
- **因子空间** F ⊂ R^d，f = (ρ_rough, θ_slope, μ_fric, κ_comp, c_clutter, s_scale)。
- **编码/解码**：E_scene：(P_t, telemetry_{1:t}) → f_t；D_scene：f ↦ π_scene(K|f)。
- **结构化阻抗模型**：K(f) = K₀ + Σ_j A_j φ_j(f_j) + Σ_{(j,k)∈E} B_{jk} ψ_{jk}(f_j,f_k)，其中 rank(A_j) ≤ r、|E| ≤ m、φ/ψ 为有界基函数；可加项承载主效应，交互项承载组合效应。
- **支撑集与新颖度**：S_obs = {f₁,...,f_n}，d(f,S_obs) = min_i ||f − f_i||_{Σ_f^{-1}}。
- **泛化界**：以概率 ≥ 1−δ，sup_{f∈F} ||K(f) − K̂(f)|| ≤ C·sqrt((r·d + m·log d)/n) + L·d(f,S_obs)。即「组合外推误差」由结构复杂度与支撑距离共同决定。

**定义 162（保形泛化预测 CGP）** 给阻抗集合以有限样本覆盖保证：
- **非一致性分数**：s(f,K) = ||K − μ̂(f)||_{Σ̂(f)^{-1}}。
- **保形集**：C_α(f) = {K : s(f,K) ≤ q_{1−α}·(1 + λ_d·d(f,S_obs))}，q_{1−α} 为校准集 D_cal 上 s 的 (1−α) 分位。
- **加权覆盖**：以 w_i(f) = exp(−d(f,f_i)/τ) 做局部加权保形，P(K* ∈ C_α(f)) ≥ 1 − α − ε_shift，ε_shift 随有效样本量下降；越远离支撑集，集合越大、越保守。
- **安全域收缩**：K_safe := C_α(f) ∩ K_safe_base；保形集只收缩、不扩张 EEIS 的基础安全域。

**定义 163（情感状态推断 AFI）** 情感作为跨场景风险观测：
- **潜在状态**：a_t = (v, ar, σ_stress, τ_trust, h_hesitation) ∈ [0,1]⁵。
- **观测**：o_t = (prosody, AU, HRV, EDA, response_latency, grip_force, utterance)。
- **后验**：P(a_t|o_{1:t}) 由多模态时序融合（Deep Kalman / HMM）给出，输出均值 â_t 与协方差 Σ_a,t。
- **情感异常**：e_t = (â_t − a_ref)ᵀ Σ_a^{-1} (â_t − a_ref)，a_ref 为当前场景的平静参考；或用平静流形上的负对数似然。
- **跨场景不变性假设 A66**：P(r | a, scene) = P(r | a)，r 为潜在风险。这是「情感可作跨场景风险探针」的理论前提，必须在实验中用域泛化检验，而非默认成立。

**定义 164（情感约束调节 ACR）** 情感到执行约束的单侧映射：
- **单侧安全**：ψ_aff：A × K → K，K′ = ψ_aff(a,K)，恒要求 K′ ⊆ K（只收紧、绝不放宽）。
- **调节律**：ΔK(a) = η·g(a)，g 关于 σ、ar、h 单调不减，0 ≤ ΔK ≤ ΔK_max；K′ = K ⊖ ΔK（降低 K_p、v_max、F_max，提升 K_d 与柔顺性）。
- **迟滞与平滑**：da/dt = (a_raw − a)/T_aff，并设死区 [a_lo, a_hi]，防止情感抖动导致阻抗抖振。
- **信任校准**：τ_trust 只改变「是否解释、是否请求确认、是否切换交互策略」，**不改变安全裕度的方向**；低信任不能成为放宽或收紧的借口。

**定义 165（泛化-情感互证 ARX）** 两类独立风险证据的联合后验：
- P(r | d, e_t) ∝ P(d | r)·P(e_t | r)·P(r)，用逻辑模型 logit r = b₀ + b_d·log(1+d) + b_e·e_t + b_de·log(1+d)·e_t。
- **决策表**：
  - (d↑, e↑)：保守 + 请求人类确认；
  - (d↑, e↓)：保守 + 主动探针（轻触/多视角）；
  - (d↓, e↑)：疑似隐藏风险 → 探针 + 收紧；
  - (d↓, e↓)：正常执行。
- **跨场景校准**：用多场景的 (a, r) 对估计不变的 P(r|a)，以 L_inv = Σ_scene ||P_s(r|a) − P(r|a)||² 作域泛化正则。

**定义 166（情感感知场景泛化闭环 ASGL）** 算子 ASGL(M, obs, intent)：
```
① CSF: f ← E_scene(P_t, telemetry); d ← d(f, S_obs)
② CGP: C_α(f) ← conformal_predict(f, d)
③ AFI: (â, Σ_a, e) ← affect_infer(o_{1:t})
④ ARX: (r, mode) ← joint_risk(d, e); mode ∈ {normal, probe, confirm, tighten}
⑤ CIEC: 若存在显式意图，C_intent ← φ(intent)，ERTC.lock_constraints(C_intent)
⑥ EEIS: K_base ← compile(delta_f_req, fused, ξ_exec, Z_env, C_α(f))
⑦ ACR: K ← ψ_aff(â, K_base)，断言 K ⊆ K_base
⑧ Dispatch: send_impedance_params(K.best, Cert_eeis)
⑨ Execute: telemetry ← wait_contact()
⑩ EV-exec: 记录 (f, d, â, e, K, r, telemetry)，EPIR.append(EV-exec)
⑪ Update: CSF.update(f, K_obs)；AFI.calibrate(â, risk_obs=EV-exec.risk)
⑫ Return: (K, EV-exec, Cert_eeis, mode, d, e)
```

**定义 167（PCE-GA 六维认知预算）** B_ga = (B_scene, B_intent, B_ros, B_exec, B_gen, B_aff)。其中：
- **B_gen** = (Conformal_calibration_ops, OOD_detection_ops, Support_estimation_ops)
- **B_aff** = (Affect_inference_ops, Privacy_budget, Regulation_ops, Affect_latency_budget)

**PCE-GA VOI 扩展**：
```
voi_ga(π) = VOI_meta_pessimistic(π) − cost_cog(π) − cost_gen(π) − cost_aff(π) − cost_exec(π)
cost_gen = λ_cal·ConformalCost + λ_ood·OODCost + λ_sup·SupportCost
```

若 B_gen < θ_gen：放弃组合外推，改用离支撑集最近的保守保形集；若 B_aff < θ_aff：关闭情感通道，回退显式意图 + K_floor；若 B_exec 耗尽：沿用第 60 轮降级；若 B_ros 异常：本地闭环。

**定义 168（情感安全包络 ESE 与反谄媚护栏）** 给「情感调节」加硬边界：
- **硬安全下限**：K_floor = EEIS.compile_conservative(·)，与 affect 完全无关；任何时刻 K ⊇ K_floor。
- **允许集**：A_allow(r,a) = {K : K ⊆ K_max(r) 且 K ⊇ K_floor}。
- **反谄媚约束**：对任意策略更新 π，若其仅因「用户表现出正向情感」而降低安全裕度，则拒绝：形式化为 ψ_aff(a,K) ⊆ K，且 margin(K) ≥ margin(K_floor)。
- **情感隐私**：原始语音/面部/生理信号不出端；只上传可证伪的标量 e_t、a 的聚合统计与对应风险，且可被用户审计与删除。

### IP-161 CSF（组合场景因子）

```python
class CompositionalSceneFactorization:
    def __init__(self, d=6, rank=2, max_interactions=4):
        self.factors = ['rough', 'slope', 'friction',
                        'compliance', 'clutter', 'scale']
        self.rank, self.max_interactions = rank, max_interactions
        self.K0 = np.zeros((6, 6))
        self.W_add = {j: np.zeros((6, 6)) for j in range(d)}
        self.W_int = {}
        self.Sigma_f = np.eye(d)
        self.support = []

    def encode(self, lidar_patch, telemetry):
        f = self.encoder(lidar_patch, telemetry)
        return np.clip(f, 0.0, 1.0)

    def support_distance(self, f):
        if not self.support:
            return float('inf')
        d = [np.sqrt((f - g) @ np.linalg.inv(self.Sigma_f) @ (f - g))
             for g in self.support]
        return float(min(d))

    def predict(self, f):
        K = self.K0.copy()
        for j, val in enumerate(f):
            K += self.W_add[j] @ self.basis[j](val)
        for (j, k), B in self.W_int.items():
            K += B @ (self.basis[j](f[j]) * self.basis[k](f[k]))
        return K

    def update(self, f, K_obs, weight):
        self.support.append(f)
        for j in range(len(f)):
            self._ridge_update(self.W_add[j], self.basis[j](f[j]), K_obs, weight)
        for (j, k) in self._active_interactions(f):
            self._ridge_update(self.W_int.setdefault((j, k), 0.0),
                               self.basis[j](f[j]) * self.basis[k](f[k]),
                               K_obs, weight)
```

### IP-162 CGP（保形泛化预测）

```python
class ConformalGeneralizationPredictor:
    def __init__(self, alpha=0.1, tau=0.5, lam_d=1.0):
        self.alpha, self.tau, self.lam_d = alpha, tau, lam_d
        self.cal = []          # [(f, K, score)]
        self.q = None

    def fit(self, D_cal):
        for f, K in D_cal:
            self.cal.append((f, K, self._score(f, K)))
        self.q = np.quantile([s for _, _, s in self.cal], 1 - self.alpha)

    def _score(self, f, K):
        mu = self.model.predict(f)
        return float(np.linalg.norm(
            np.linalg.solve(self.model.cov(f), K - mu)))

    def predict_set(self, f):
        d = self.model.support_distance(f)
        radius = self.q * (1 + self.lam_d * d)
        mu = self.model.predict(f)
        return {'center': mu, 'radius': radius, 'novelty': d}

    def weighted_coverage_bound(self, f):
        w = np.array([np.exp(-self.model.support_distance(g) / self.tau)
                      for g, _, _ in self.cal])
        n_eff = w.sum() ** 2 / max((w ** 2).sum(), 1e-9)
        return 1 - self.alpha - 1 / np.sqrt(max(n_eff, 1))
```

### IP-163 AFI（情感状态推断）

```python
class AffectiveStateInference:
    def __init__(self, dim=5, calm_ref=None):
        self.dim = dim
        self.fusion = DeepKalman(dim=dim)
        self.calm_ref = calm_ref or np.zeros(dim)
        self.calm_cov = np.eye(dim) * 0.1

    def update(self, obs):
        self.fusion.predict()
        self.fusion.update(obs)                  # prosody/AU/HRV/EDA/...
        a_hat, Sigma_a = self.fusion.posterior()
        e = float((a_hat - self.calm_ref) @ np.linalg.inv(
            Sigma_a + self.calm_cov) @ (a_hat - self.calm_ref))
        return a_hat, Sigma_a, e

    def cross_scene_invariance_loss(self, pairs_by_scene):
        losses = []
        for scene, pairs in pairs_by_scene.items():
            p = self.risk_given_affect(pairs)
            losses.append(np.sum((p - self.global_risk_given_affect(pairs)) ** 2))
        return float(np.sum(losses))
```

### IP-164 ACR（情感约束调节，单侧安全）

```python
class AffectiveConstraintRegulator:
    def __init__(self, eta=0.3, dK_max=0.4, T_aff=1.5):
        self.eta, self.dK_max, self.T_aff = eta, dK_max, T_aff
        self.a_smooth = None

    def regulate(self, K, a_hat, dt):
        if self.a_smooth is None:
            self.a_smooth = a_hat.copy()
        self.a_smooth += (a_hat - self.a_smooth) * dt / self.T_aff
        g = self.deadzone(max(self.a_smooth[1],   # arousal
                              self.a_smooth[2],   # stress
                              self.a_smooth[4]))  # hesitation
        dK = min(self.dK_max, self.eta * g)
        K2 = self.tighten(K, dK)                  # K_p↓, v_max↓, F_max↓, K_d↑
        assert self.subset(K2, K), 'ACR violated one-sided safety'
        return K2

    def subset(self, K2, K):
        return (K2.K_p <= K.K_p and K2.v_max <= K.v_max
                and K2.F_max <= K.F_max and K2.K_d >= K.K_d)
```

### IP-165 ARX（泛化-情感互证）

```python
def joint_risk(d, e, model):
    z = (model.b0 + model.bd * np.log1p(d)
         + model.be * e + model.bde * np.log1p(d) * e)
    return 1.0 / (1.0 + np.exp(-z))

def arx_decide(f, e, model, tau_d=1.0, tau_e=2.0):
    d = model.csf.support_distance(f)
    r = joint_risk(d, e, model)
    if d > tau_d and e > tau_e:
        return r, 'conservative_confirm'
    if d > tau_d and e <= tau_e:
        return r, 'conservative_probe'
    if d <= tau_d and e > tau_e:
        return r, 'tighten_probe'      # 几何看不见的隐藏风险
    return r, 'normal_execute'
```

### IP-166 ASGL（情感感知场景泛化闭环）

```python
def affective_scene_generalization_loop(M, obs, explicit_intent):
    f = M.csf.encode(obs.lidar_patch, obs.telemetry)
    d = M.csf.support_distance(f)
    C = M.cgp.predict_set(f)

    a_hat, Sigma_a, e = M.afi.update(obs.affect)
    r, mode = arx_decide(f, e, M.arx_model)

    if explicit_intent:
        M.ciec.receive_intent(explicit_intent)

    K_base = M.eeis.compile(obs.delta_f_req, M.fused, M.xi_exec,
                            M.Z_env, conformal_set=C)
    K = M.acr.regulate(K_base, a_hat, obs.dt)
    assert M.acr.subset(K, K_base)

    cert = M.eeis.certify(K)
    dispatch_impedance_params(K.best, cert)
    telemetry = wait_contact()

    EV = build_exec_evidence(telemetry, K, cert, d, a_hat, e, r, mode)
    M.epir.append(EV)

    M.csf.update(f, telemetry.K_obs, weight=1.0 / (1.0 + d))
    M.afi.calibrate(a_hat, risk_obs=EV.risk)
    return M, K, EV, mode, d, e
```

### IP-167 PCE-GA（六维认知预算）

```python
class PCEGA:
    def __init__(self):
        self.B_gen = GenBudget(cal_ops=100, ood_ops=50, support_ops=200)
        self.B_aff = AffectBudget(infer_ops=1000, privacy=1.0, reg_ops=500)

    def voi(self, pi, ctx):
        return (voi_meta_pessimistic(pi)
                - cost_cog(pi) - self.cost_gen(pi) - self.cost_aff(pi)
                - cost_exec(pi))

    def cost_gen(self, pi):
        return (0.1 * pi.conformal_ops + 0.05 * pi.ood_ops
                + 0.02 * pi.support_ops)

    def cost_aff(self, pi):
        return (0.2 * pi.affect_ops + 0.3 * pi.privacy_cost
                + 0.1 * pi.reg_ops)

    def fallback(self, pi):
```

```python
class CompositionalSceneFactorization:
    def __init__(self, d=6, rank=2, max_interactions=4):
        self.factors = ['rough', 'slope', 'friction',
                        'compliance', 'clutter', 'scale']
        self.rank, self.max_interactions = rank, max_interactions
        self.K0 = np.zeros((6, 6))
        self.W_add = {j: np.zeros((6, 6)) for j in range(d)}
        self.W_int = {}
        self.Sigma_f = np.eye(d)
        self.support = []

    def encode(self, lidar_patch, telemetry):
        return np.clip(self.encoder(lidar_patch, telemetry), 0.0, 1.0)

    def support_distance(self, f):
        if not self.support:
            return float('inf')
        inv = np.linalg.inv(self.Sigma_f)
        return float(min(np.sqrt((f - g) @ inv @ (f - g))
                         for g in self.support))

    def predict(self, f):
        K = self.K0.copy()
        for j, val in enumerate(f):
            K += self.W_add[j] @ self.basis[j](val)
        for (j, k), B in self.W_int.items():
            K += B @ (self.basis[j](f[j]) * self.basis[k](f[k]))
        return K

    def update(self, f, K_obs, weight):
        self.support.append(f)
        for j in range(len(f)):
            self._ridge_update(self.W_add[j], self.basis[j](f[j]),
                               K_obs, weight)
        for (j, k) in self._active_interactions(f):
            self._ridge_update(self.W_int.setdefault((j, k), 0.0),
                               self.basis[j](f[j]) * self.basis[k](f[k]),
                               K_obs, weight)
```

### IP-162 CGP（保形泛化预测）

```python
class ConformalGeneralizationPredictor:
    def __init__(self, alpha=0.1, tau=0.5, lam_d=1.0):
        self.alpha, self.tau, self.lam_d = alpha, tau, lam_d
        self.cal = []
        self.q = None

    def fit(self, D_cal):
        for f, K in D_cal:
            self.cal.append((f, K, self._score(f, K)))
        self.q = np.quantile([s for _, _, s in self.cal], 1 - self.alpha)

    def _score(self, f, K):
        mu = self.model.predict(f)
        return float(np.linalg.norm(
            np.linalg.solve(self.model.cov(f), K - mu)))

    def predict_set(self, f):
        d = self.model.support_distance(f)
        radius = self.q * (1 + self.lam_d * d)
        return {'center': self.model.predict(f),
                'radius': radius, 'novelty': d}

    def weighted_coverage_bound(self, f):
        w = np.array([np.exp(-self.model.support_distance(g) / self.tau)
                      for g, _, _ in self.cal])
        n_eff = w.sum() ** 2 / max((w ** 2).sum(), 1e-9)
        return 1 - self.alpha - 1 / np.sqrt(max(n_eff, 1))
```

### IP-164 ACR（情感约束调节，单侧安全）

```python
class AffectiveConstraintRegulator:
    def __init__(self, eta=0.3, dK_max=0.4, T_aff=1.5):
        self.eta, self.dK_max, self.T_aff = eta, dK_max, T_aff
        self.a_smooth = None

    def regulate(self, K, a_hat, dt):
        if self.a_smooth is None:
            self.a_smooth = a_hat.copy()
        self.a_smooth += (a_hat - self.a_smooth) * dt / self.T_aff
        g = self.deadzone(max(self.a_smooth[1],   # arousal
                              self.a_smooth[2],   # stress
                              self.a_smooth[4]))  # hesitation
        dK = min(self.dK_max, self.eta * g)
        K2 = self.tighten(K, dK)                  # K_p↓, v_max↓, F_max↓, K_d↑
        assert self.subset(K2, K), 'ACR violated one-sided safety'
        return K2

    def subset(self, K2, K):
        return (K2.K_p <= K.K_p and K2.v_max <= K.v_max
                and K2.F_max <= K.F_max and K2.K_d >= K.K_d)
```

### IP-165 ARX（泛化-情感互证）

```python
def joint_risk(d, e, model):
    z = (model.b0 + model.bd * np.log1p(d)
         + model.be * e + model.bde * np.log1p(d) * e)
    return 1.0 / (1.0 + np.exp(-z))

def arx_decide(f, e, model, tau_d=1.0, tau_e=2.0):
    d = model.csf.support_distance(f)
    r = joint_risk(d, e, model)
    if d > tau_d and e > tau_e:
        return r, 'conservative_confirm'
    if d > tau_d and e <= tau_e:
        return r, 'conservative_probe'
    if d <= tau_d and e > tau_e:
        return r, 'tighten_probe'      # 几何看不见的隐藏风险
    return r, 'normal_execute'
```

```python
class EmotionalSafetyEnvelope:
    def __init__(self, eeis):

        if not self.subset(self.K_floor, K):
            return False                 # 击穿硬安全下限，拒绝
```
