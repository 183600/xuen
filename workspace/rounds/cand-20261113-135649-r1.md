# 第 68 轮（承接第 67 轮「SimRAS 仿真增强风险自适应闭环」IP-233~242；灵感循环第 1 轮；本轮灵感：「视觉语言动作模型」×「意图识别」）

> 第 67 轮 SimRAS 把闭环从「在线反应」升级为「离线预演 + 世界模型滚动 + 视觉问答审计」。但它仍未回答一个更基本的问题：**这些风险是为“谁”的“什么目标”服务的？** 情绪是症状，故障是状态，而意图才是原因。SimRAS 的风险标量 λ_risk 把所有意图压成一个数，于是当用户真正想要的东西与系统假设不同时，越精确的仿真反而越危险。
>
> 本轮核心命题：**把「风险闭环」升级为「语义意图闭环」：用视觉-语言-动作模型（VLA）把指令、场景与动作块嵌入同一语义空间，用意图识别在行为轨迹上维护意图后验，构建「意图可验证、意图可澄清、意图可认证」的闭环——CIVIC（Certified Intent-Verified Instruction Closure）。**
>
> CIVIC 追问的不是「风险多大」，而是「**这是谁想要的、系统是否真的理解、理解错了会怎样**」。

## 0. 直觉与动机

**灵感 1（VLA → 动作的“可命名性”）**
直觉：传统动作分块 `A_t` 只是一串向量，无法与“把杯子递给我”这样的语言对齐。VLA 的关键创新不是“模型更大”，而是**动作被语言命名了**：同一个策略在输出动作 token 的同时，也输出与指令共享潜空间的语言 token。于是“这段动作是否符合那个意图”第一次可以被计算，而不是靠人事后判断。

**灵感 2（意图识别 → 隐藏目标的后验，而非标签）**
直觉：工程里的意图识别常被做成分类器（pick / place / handover）。但真实意图是**关于未来目标的信念分布**，会随观察不断收缩或漂移。把意图从 one-hot 标签升级为 `P(I | l, o_{0:t}, a_{0:t})`，才能量化“系统此刻到底有多确定”，也才能把“不确定”本身作为安全约束。

**灵感 3（二者合流 → 意图是故障与风险之间的缺失变量）**
直觉：SimRAS 的 `H_emotion` 与 `H_fault` 都默认“意图已给定”。但若意图错，情绪再准、仿真再真也无意义——系统是在为错误的目标做正确的风险评估。意图应当被显式建模为**先于故障的根变量**：`I → (π, H, A)`。把 `I` 加入联合后验，风险标量才第一次具备语义（“对谁、为了什么而安全”）。

**灵感 4（意图鲁棒认证 → 从期望安全到可信集安全）**
直觉：安全的定义不该是“在意图后验的均值下安全”，而应是“**对后验可信集里的每一个意图都安全**”。这是 worst-case / CVaR 式的安全，天然抵御“平均意义上安全、却对真实意图致命”的放行。它与 SimRAS 的 `k_wm` 前瞻认证正交：前者管“未来会不会坏”，CIVIC 管“坏了是不是因为理解错了”。

**灵感 5（主动澄清 → 把 FAS 从“探针”升级为“提问”）**
直觉：情绪探针只能观察，意图不确定时最有效的手段是**问一句**或**做一个最小演示**。把澄清动作形式化为“最大化意图互信息 / 最小化打扰成本”的规划，闭环就从“被动感知”变成了“主动协商”。这也是 VLA 的独特优势：它既能生成动作，也能生成问题。

**灵感 6（合流 → CIVIC 六层结构）**
CIVIC 沿用 SimRAS 的时序骨架，但在每个环节注入语义意图：
1. **VLG（VLA Language Grounder）**：把指令 `l`、视觉 `o_t`、动作块 `A_t` 编码到共享潜空间，产出动作的“语言化” `v(A)`；
2. **IPG（Intent Posterior Generator）**：在 `(l, o, a, π)` 上维护意图后验 `P(I|·)`；
3. **IGV（Intent Grounding Verifier）**：用 `KL(P_I || P_I^VLA)` 检测“语言说一套、动作做一套”；
4. **IBS（Intent Barrier Shield）**：在意图可信集上做 worst-case 安全投影，得到 `k_CIV`；
5. **AID（Active Intent Disambiguator）**：意图熵过高时，规划最小成本的澄清动作；
6. **CIV（Certified Intent-verified prefix）+ 证书**：输出意图条件化、可审计的认证前缀。

## 1. 形式化定义（增量：定义 276–295）

- **定义 276（CIVIC 总览）**：`CIVIC = (VLG, IPG, IGV, IBS, AID, CIV, J_CIVIC)`。定位：把 SimRAS 的「风险闭环」升级为「语义意图闭环」。不变式：VLA 重推理离线/蒸馏；实时流只做意图后验更新、接地残差计算、安全屏障投影与早停；任何在线环节零学习写操作。
- **定义 277（意图假设集）**：`ℐ = {i_1, ..., i_n} ∪ {i_⊥}`，每个意图 `i = (g_i, C_i, φ_i)` 由目标 `g_i`、约束集 `C_i`（如“不要碰玻璃”“左手递”）与成功谓词 `φ_i` 构成；`i_⊥` 为开集“未知/不支持意图”。
- **定义 278（语言-视觉-动作共享潜空间）**：编码器 `E_L, E_V, E_A` 把 `(l, o_t, A_t)` 映射为 `(z_l, z_v, z_a) ∈ ℝ^d`。对齐损失 `L_align = -log σ(⟨z_l, z_a⟩/τ) + ...`，使“语义相近的意图”在潜空间邻近。
- **定义 279（VLA 策略与动作语言化）**：`A_t = π_VLA(l, o_t, z_t)`；动作解码器给出语言化描述 `v(A_t) = Dec_A(z_a)`。`v(A)` 是可被人审计的短句，而不是隐藏向量。
- **定义 280（意图后验）**：`P(I | l, o_{0:t}, a_{0:t}, π_{0:t}) ∝ P(I) · P(l|I) · ∏_s P(o_s|I) P(a_s|I) P(π_s|I)`。各项由对比似然给出，避免对高维观测直接建模。
- **定义 281（意图熵与可信集）**：`H_I(t) = -∑_i P(i|·) log P(i|·)`；可信集 `ℐ_α(t)` 是质量不小于 `1-α_int` 的最小意图集合（按后验降序取）。
- **定义 282（VLA-意图接地残差）**：`g_t = KL(P_I(·|l, o, a) || P_I^VLA(·|A_t))`，其中 `P_I^VLA` 由“动作语言化 `v(A)` 与意图描述 `d_i` 的匹配”诱导。`g_t > τ_ground` 判为“说做不一致”。
- **定义 283（意图条件安全裕度）**：对动作块 `A` 与意图 `i`，`m(A|i) = min_{s≤k} ρ_safe(s|i)`，其中 `ρ_safe(s|i)` 同时含几何/力/模型约束与意图约束 `C_i`（例如“递”要求末端朝向人、“放”要求速度趋零）。
- **定义 284（意图鲁棒认证前缀）**：`k_CIV = max{k ≤ m_civ : ∀i ∈ ℐ_α(t), m(A_{1:k}|i) ≥ 0 ∧ g_t ≤ τ_ground}`；CVaR 变体把 `∀i` 换成“后验最差 `α_int` 分位”。
- **定义 285（意图风险缩放，单调收紧）**：`λ_intent(t) = exp(-β_H·H_I(t) - β_g·g_t) ∈ (0, 1]`。与第 66 轮情绪缩放不同，**意图不确定只能收紧、永不放宽**——这是对上一轮“误判放行”风险的直接结构性修补。
- **定义 286（主动意图澄清）**：澄清动作集 `𝒜_clar = {ask(q), demo(d), wait, handover_probe}`；选择 `a* = argmax_{a} IG(I; a) / (c(a) + λ_r·risk(a))`，约束 `risk(a) ≤ ρ_max`，其中 `IG` 为意图互信息增益。
- **定义 287（澄清问题生成）**：`q = VLA_query(l, ℐ_α(t))`，但受限生成于**有限模板文法** `𝒬`（如“你是要 A 还是 B？”“要我停在 C 吗？”），以保证问题可认证、不可被任意提示注入。
- **定义 288（意图条件故障联合后验）**：`P(I, H, E | ·) = P(I|·) · P(H, E | I, ρ, face)`。这把“意图错”与“传感器故障”解耦：同一异常既可能是 `H_geo`，也可能是 `I` 选错。
- **定义 289（意图漂移）**：`d_intent(t) = JS(P_I(t) || P_I(t-T))`；`d_intent > τ_drift` 触发重锚定并请求重新指令，而不静默跟随。
- **定义 290（AIC-CIVIC 攻击与共因集）**：`ℰ_CIVIC = ℰ_SimRAS × ℰ_intent × ℰ_vla`，其中 `ℰ_intent = {指令歧义, 意图漂移, 欺骗性示范, 多主体意图冲突}`，`ℰ_vla = {动作 token 幻觉, 语言捷径, 分布外组合, 提示注入}`；共因 `ℰ_common_intent` 捕获“指令被污染 → 动作与意图后验同时偏移”。
- **定义 291（J_CIVIC 证书）**：`J_CIVIC = (J_SimRAS, intent_posterior_hash, credible_set_hash, g_t, k_CIV, vla_version, clarification_log, attack_set_ver)`。`Valid ⇔ Valid(J_SimRAS) ∧ g_t ≤ τ_ground ∧ k_CIV ≥ k_min ∧ (H_I ≤ H_max ∨ ∃ clarification_log)`。
- **定义 292（开集意图处理）**：若 `P(i_⊥) > τ_unknown`，则不允许越过 `k_0`（最小安全前缀），转入安全停机或请求重新示范，绝不把未知意图硬归入已知类。
- **定义 293（意图协商协议）**：`propose → confirm/reject → execute`，最多 `R_max` 轮；确认结果写入 `clarification_log`，成为证书的一部分与后续先验。
- **定义 294（意图条件可达集）**：`Reach_i(k) = {s_k : ∃ a_{0:k-1} 使 φ_i 可在 k 步内达成且始终满足 C_i}`；`φ_i ∉ Reach_i(k)` 时，该意图被判为“本块内不可兑现”，需提前澄清而不是盲目执行。
- **定义 295（部署不变式）**：实时环路 = IPG 轻量更新 + IGV 残差 + IBS 投影 + AID 触发判定，总增量 <1.5ms；VLA 全量推理与离线标定在语义流/离线侧完成；`clarification` 异步阻塞于“执行前”而绝不打断已认证前缀。

## 2. 关键算法骨架

```python
class IntentPosteriorGenerator:            # IPG
    def __init__(self, intents, tau_drift=0.25):
        self.intents, self.tau_drift = intents, tau_drift
        self.log_post = {i: math.log(1/len(intents)) for i in intents}

    def update(self, l, obs, acts, emos):
        for i in self.intents:
            ll = (self.p_lang(l, i) + self.p_obs(obs, i)
                  + self.p_act(acts, i) + self.p_emo(emos, i))
            self.log_post[i] += ll
        self.log_post = normalize_log(self.log_post)
        return self.posterior()

    def posterior(self):
        return {i: math.exp(v) for i, v in self.log_post.items()}


class VLALanguageGrounder:                 # VLG
    def __init__(self, vla, tau=0.07):
        self.vla, self.tau = vla, tau

    def ground(self, l, obs_t, A_t):
        z_l, z_v = self.vla.encode_lang(l), self.vla.encode_vis(obs_t)
        z_a = self.vla.encode_action(A_t)
        v_A = self.vla.verbalize(z_a)                 # 可审计短句
        p_vla = self.match_intents(v_A)               # 动作隐含的意图分布
        align = cosine(z_l, z_a)                       # 语言-动作一致性
        return {'p_vla': p_vla, 'verbal': v_A, 'align': align}


class IntentGroundingVerifier:             # IGV
    def __init__(self, tau_ground=0.35):
        self.tau_ground = tau_ground

    def residual(self, p_intent, p_vla):
        return kl_div(p_intent, p_vla)

    def verify(self, p_intent, p_vla):
        g = self.residual(p_intent, p_vla)
        return {'g': g, 'ok': g <= self.tau_ground}


class IntentBarrierShield:                 # IBS
    def __init__(self, alpha_int=0.1, k_min=2):
        self.alpha_int, self.k_min = alpha_int, k_min

    def credible_set(self, p_intent):
        items = sorted(p_intent.items(), key=lambda kv: -kv[1])
        out, mass = [], 0.0
        for i, p in items:
            out.append(i); mass += p
            if mass >= 1 - self.alpha_int:
                break
        return out

    def certified_prefix(self, A, p_intent, g, safety_margin):
        credible = self.credible_set(p_intent)
        if g > self.tau_ground:
            return 0                          # 说做不一致 → 不认证
        k_best = 0
        for k in range(1, len(A) + 1):
            if all(safety_margin(A[:k], i) >= 0 for i in credible):
                k_best = k
            else:
                break
        return k_best


class ActiveIntentDisambiguator:           # AID
    def __init__(self, tau_entropy=0.8, rho_max=0.2, r_max=3):
        self.tau_entropy, self.rho_max, self.r_max = tau_entropy, rho_max, r_max

    def should_clarify(self, p_intent, g):
        return entropy(p_intent) > self.tau_entropy or g > self.tau_ground

    def plan(self, l, p_intent, context):
        best, best_score = None, -1.0
        for a in self.candidate_actions(l, p_intent):     # ask/demo/wait/probe
            if self.risk(a) > self.rho_max:
                continue
            score = self.info_gain(a, p_intent) / (self.cost(a) + 1e-3)
            if score > best_score:
                best, best_score = a, score
        return best

    def question(self, l, p_intent):
        top2 = top_k(p_intent, 2)
        return constrained_generate(                       # 有限模板文法
            self.vla, l, top2, grammar=self.q_grammar)


def CIVIC_round(M, obs):
    l, V, T, P, L, P_cloud, W, tactile, img, depth, flow, emos = obs

    # 0) 原有 SimRAS 前向（略）
    M.lsf.update_geometry(P_cloud)
    x_prime = M.lsf.fuse(M.usr.fuse(V, T, P, L))

    # 1) IPG：意图后验
    p_intent = M.ipg.update(l, x_prime, M.act_log, emos)

    # 2) VLG + IGV：动作语言化与接地残差
    A = M.vista.ach.propose(x_prime, H=M.vista.H)
    grounding = M.vlg.ground(l, x_prime, A)
    g = M.igv.residual(p_intent, grounding['p_vla'])

    # 3) 开集/漂移守卫
    if p_intent.get('i_bot', 0) > M.tau_unknown:
        return 0, 1.0, p_intent, 'unknown_intent'
    if M.drift(p_intent) > M.tau_drift:
        p_intent = M.ipg.reanchor(l)

    # 4) AID：必要时先澄清，再执行
    if M.aid.should_clarify(p_intent, g):
        a = M.aid.plan(l, p_intent, x_prime)
        if a is not None and a.kind in ('ask', 'demo'):
            obs_new = M.execute_clarification(a)          # 阻塞于执行前
            p_intent = M.ipg.update(l, *obs_new, emos)
            A = M.vista.ach.propose(x_prime, H=M.vista.H)
            grounding = M.vlg.ground(l, x_prime, A)
            g = M.igv.residual(p_intent, grounding['p_vla'])

    # 5) IBS：意图可信集上的鲁棒认证前缀
    k_civ = M.ibs.certified_prefix(A, p_intent, g, M.safety_margin_intent)
    k = min(k_civ, M.simras_prefix(A, p_intent))

    # 6) 单调收紧的风险缩放
    lambda_intent = math.exp(-M.beta_H * entropy(p_intent) - M.beta_g * g)
    tau_cmd = M.vista.pi_sigma.prefix_dispatch(A[:k]) * lambda_intent

    cert = J_CIVIC(M.j_simras, hash(p_intent), hash(M.ibs.credible_set(p_intent)),
                   g, k, M.vla.version, M.clarification_log, M.aic_version)
    return k, lambda_intent, p_intent, cert
```

## 3. 推导

**引理 13（意图后验收缩）** 设观测在给定 `I` 下条件独立，且每次观测使期望对数损失至少下降 `ι > 0`。则 `H_I(t) ≤ H_I(0) - t·ι`，且当 `t ≥ H_I(0)/ι` 时后验熵不超过 0。直觉：持续观察必然收敛，除非出现 `d_intent > τ_drift` 的漂移（此时后验被重锚，收缩重新开始）。

**引理 14（接地残差对 VLA 误差的界）** 若 VLA 诱导的意图分布在真实意图上的总变差为 `ε_VLA`，且似然密度比有界 `B`，则 `g_t = KL(P_I || P_I^VLA) ≤ B·ε_VLA`。因此 `τ_ground` 可被标定为 `B·ε_VLA` 的可检测倍数：VLA 越差，阈值越应保守。

**定理 14（意图鲁棒安全）** 若 `J_CIVIC` 有效，则对可信集 `ℐ_α(t)` 中任意意图，
`P(unsafe) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_vqa + α_intent + α_open`；
且因 `λ_intent ∈ (0,1]`，意图不确定性**只收紧不放松**，故不存在“因意图误判而放行”的通道。

**定理 15（主动澄清的收敛与成本）** 若每次澄清的意图互信息增益 `IG ≥ IG_min`，则把意图熵降到 `ε` 所需澄清次数 `N ≤ ⌈log(1/ε)/IG_min⌉`，总打扰成本 `≤ N·c_max`。主动澄清相对被动观察，期望样本复杂度从 `O(1/ι)` 降到 `O(log(1/ε)/IG_min)`。

**定理 16（说做不一致的可检测性）** 在 `ℰ_intent` 下若指令与动作的语义散度至少 `Δ`，则 `T` 帧内 IGV 检出概率 `≥ 1 - exp(-T·Δ²/(2B²))`（Hoeffding + Pinsker）。恶意提示注入若改变动作 token 却未改变语言 token，必被残差捕获。

## 6. 本轮最大风险

**一句话**：CIVIC 把「意图」当作可从语言与动作中可靠辨识的潜变量，但真实场景中语言本身歧义、可被提示注入，VLA 又会用流畅的“动作语言化”为错误意图背书——于是最危险的不是识别错，而是**系统对错误意图过度自信（意图过自信）**：接地残差与后验熵同时偏低，IBS 便在一个错误但看似可信的意图集合上给出认证前缀，把“理解错了”伪装成“理解对了”——这是本轮全部理论依赖的核心假设：**意图可由有限观测辨识，且 VLA 的语义接地残差是可靠的分布外信号。**

## 2. 形式化定义（完整版）

**定义 276（CIVIC 总览）** CIVIC 是 SimRAS 的「语义意图」升级层：
```
CIVIC = (VLG, IPG, IGV, IBS, AID, CIV, J_CIVIC)
```
不变式：VLA 全量推理与离线标定在语义流/离线侧；实时流只做意图后验更新、接地残差、屏障投影与澄清触发，增量 <1.5ms；零在线学习写操作。

**定义 277（意图假设集）** `ℐ = {i_1,...,i_n} ∪ {i_⊥}`，`i = (g_i, C_i, φ_i)`。`i_⊥` 表示“未知/不支持意图”，必须被显式拒绝而非硬归入已知类。

**定义 278（共享潜空间）** `E_L, E_V, E_A` 把 `(l, o_t, A_t)` 映射为 `(z_l, z_v, z_a)`。对齐目标：
```
L_align = -log σ(⟨z_l,z_a⟩/τ) - log σ(⟨z_l,z_v⟩/τ) + 正则项
```

**定义 279（VLA 策略与动作语言化）** `A_t = π_VLA(l, o_t, z_t)`，`v(A_t) = Dec_A(z_a)`。`v(A)` 必须是可审计短句，不允许不可读的隐藏 token 直接进入证书。

**定义 280（意图后验）**
```
P(I∣l,o_{0:t},a_{0:t},π_{0:t}) ∝ P(I)·P(l∣I)·∏_s P(o_s∣I)P(a_s∣I)P(π_s∣I)
```
各似然由对比模型给出，避免对高维观测直接建模。

**定义 281（意图熵与可信集）**
```
H_I(t) = -∑_i P(i∣·) log P(i∣·)
ℐ_α(t) = 质量 ≥ 1-α_int 的最小意图集合（按后验降序）
```

**定义 282（接地残差）** `g_t = KL(P_I(·∣l,o,a) ‖ P_I^VLA(·∣A_t))`，`P_I^VLA` 由 `v(A)` 与意图描述 `d_i` 的匹配诱导。`g_t > τ_ground` 判为“说做不一致”。

**定义 283（意图条件安全裕度）**
```
m(A∣i) = min_{s≤k} ρ_safe(s∣i)
```
`ρ_safe` 同时包含几何/力/模型约束与意图约束 `C_i`（如“递”要求末端朝向人，“放”要求速度趋零）。

**定义 284（意图鲁棒认证前缀）**
```
k_CIV = max{ k ≤ m_civ : ∀i∈ℐ_α(t), m(A_{1:k}∣i) ≥ 0 ∧ g_t ≤ τ_ground }
```
CVaR 变体把 `∀i` 替换为“后验最差 `α_int` 分位”。

**定义 285（意图风险缩放，单调收紧）**
```
λ_intent(t) = exp(-β_H·H_I(t) - β_g·g_t) ∈ (0,1]
```
与情绪缩放不同，意图不确定只能收紧，**不存在放松通道**。

**定义 286（主动澄清）** `𝒜_clar = {ask(q), demo(d), wait, handover_probe}`，
```
a* = argmax_a IG(I;a) / (c(a) + λ_r·risk(a)),  s.t. risk(a) ≤ ρ_max
```

**定义 287（澄清问题生成）** `q = VLA_query(l, ℐ_α(t))`，受限生成于有限模板文法 `𝒬`；禁止自由文本进入执行链，防止提示注入。

**定义 288（意图条件故障联合后验）**
```
P(I,H,E∣·) = P(I∣·)·P(H,E∣I,ρ,face)
```
把“意图错”与“传感器故障”解耦。

**定义 289（意图漂移）** `d_intent(t) = JS(P_I(t)‖P_I(t-T))`；`> τ_drift` 触发重锚定并请求重新指令。

**定义 290（AIC-CIVIC 攻击与共因集）**
```
ℰ_CIVIC = ℰ_SimRAS × ℰ_intent × ℰ_vla
ℰ_intent = {指令歧义, 意图漂移, 欺骗性示范, 多主体意图冲突}
ℰ_vla = {动作token幻觉, 语言捷径, 分布外组合, 提示注入}
```
共因 `ℰ_common_intent` 捕获“指令被污染 → 动作与意图后验同时偏移”。

**定义 291（J_CIVIC 证书）**
```
J_CIVIC = (J_SimRAS, intent_posterior_hash, credible_set_hash, g_t, k_CIV,
           vla_version, clarification_log, attack_set_ver)
Valid ⇔ Valid(J_SimRAS) ∧ g_t ≤ τ_ground ∧ k_CIV ≥ k_min
        ∧ (H_I ≤ H_max ∨ ∃ clarification_log)
```

**定义 292（开集意图处理）** 若 `P(i_⊥) > τ_unknown`，不允许越过 `k_0`，转入安全停机或请求重新示范。

**定义 293（意图协商协议）** `propose → confirm/reject → execute`，最多 `R_max` 轮；确认结果写入 `clarification_log`，成为证书与后续先验的一部分。

**定义 294（意图条件可达集）** `Reach_i(k) = {s_k : ∃ a_{0:k-1} 使 φ_i 在 k 步内可达且始终满足 C_i}`。若 `φ_i ∉ Reach_i(k)`，该意图被列为“本块不可兑现”，必须提前澄清。

**定义 295（部署不变式）** 实时环路 = IPG 轻量更新 + IGV 残差 + IBS 投影 + AID 触发，增量 <1.5ms；VLA 全量推理与离线标定在语义流/离线侧；澄清发生在“执行前”，绝不打断已认证前缀。

```python
# IP-244 IPG：意图后验生成器
class IntentPosteriorGenerator:
    def __init__(self, intents, tau_drift=0.25):
        self.intents, self.tau_drift = intents, tau_drift
        self.log_post = {i: math.log(1.0/len(intents)) for i in intents}

    def update(self, l, obs, acts, emos):
        for i in self.intents:
            ll = (self.p_lang(l, i) + self.p_obs(obs, i)
                  + self.p_act(acts, i) + self.p_emo(emos, i))
            self.log_post[i] += ll
        self.log_post = normalize_log(self.log_post)
        return {i: math.exp(v) for i, v in self.log_post.items()}

    def entropy(self, p):
        return -sum(v * math.log(v + 1e-12) for v in p.values())

    def drifted(self, p_t, p_prev):
        return js_div(p_t, p_prev) > self.tau_drift


# IP-245 VLG：动作语言化
class VLALanguageGrounder:
    def __init__(self, vla, tau=0.07):
        self.vla, self.tau = vla, tau

    def ground(self, l, obs_t, A_t):
        z_l, z_v = self.vla.encode_lang(l), self.vla.encode_vis(obs_t)
        z_a = self.vla.encode_action(A_t)
        return {
            'z': (z_l, z_v, z_a),
            'verbal': self.vla.verbalize(z_a),        # 可审计短句
            'p_vla': self.match_intents(self.vla.verbalize(z_a)),
            'align': cosine(z_l, z_a),
        }


# IP-246 IGV：接地验证
class IntentGroundingVerifier:

        self.tau_ground = tau_ground

    def verify(self, p_intent, p_vla):

        return {'g': g, 'ok': g <= self.tau_ground}


# IP-247 IBS：意图鲁棒屏障
class IntentBarrierShield:
    def __init__(self, alpha_int=0.1, k_min=2, tau_ground=0.35):
        self.alpha_int, self.k_min, self.tau_ground = alpha_int, k_min, tau_ground

    def credible_set(self, p_intent):
        out, mass = [], 0.0
        for i, p in sorted(p_intent.items(), key=lambda kv: -kv[1]):
            out.append(i); mass += p
            if mass >= 1 - self.alpha_int:
                break
        return out

    def certified_prefix(self, A, p_intent, g, safety_margin):
        if g > self.tau_ground:
            return 0
        credible = self.credible_set(p_intent)
        k_best = 0
        for k in range(1, len(A) + 1):
            if all(safety_margin(A[:k], i) >= 0 for i in credible):
                k_best = k
            else:
                break
        return k_best


# IP-248 AID：主动澄清
class ActiveIntentDisambiguator:
    def __init__(self, vla, tau_entropy=0.8, rho_max=0.2, r_max=3, q_grammar=None):
        self.vla, self.tau_entropy = vla, tau_entropy
        self.rho_max, self.r_max = rho_max, r_max
        self.q_grammar = q_grammar

    def should_clarify(self, p_intent, g):
        return entropy(p_intent) > self.tau_entropy or g > self.tau_ground

    def plan(self, l, p_intent, ctx):
        best, best_score = None, -1.0
        for a in self.candidates(l, p_intent, ctx):
            if self.risk(a) > self.rho_max:
                continue
            score = self.info_gain(a, p_intent) / (self.cost(a) + 1e-3)
            if score > best_score:
                best, best_score = a, score
        return best

    def question(self, l, p_intent):
        top2 = top_k(p_intent, 2)
        return constrained_generate(self.vla, l, top2, grammar=self.q_grammar)

def CIVIC_round(M, obs):
    l, V, T, P, L, P_cloud, W, tactile, img, depth, flow, emos = obs
    M.lsf.update_geometry(P_cloud)
    x_prime = M.lsf.fuse(M.usr.fuse(V, T, P, L))

    # 1) 意图后验
    p_intent = M.ipg.update(l, x_prime, M.act_log, emos)

    # 2) 动作块 + 语言化 + 接地残差
    A = M.vista.ach.propose(x_prime, H=M.vista.H)
    grounding = M.vlg.ground(l, x_prime, A)
    g = M.igv.verify(p_intent, grounding['p_vla'])['g']

    # 3) 开集与漂移守卫
    if p_intent.get('i_bot', 0.0) > M.tau_unknown:
        return 0, 1.0, p_intent, 'unknown_intent'
    if M.ipg.drifted(p_intent, M.prev_intent):
        p_intent = M.ipg.reanchor(l)

    # 4) 主动澄清（执行前）
    if M.aid.should_clarify(p_intent, g):

        if a is not None and a.kind in ('ask', 'demo'):

            p_intent = M.ipg.update(l, *M.execute_clarification(a), emos)
            A = M.vista.ach.propose(x_prime, H=M.vista.H)
            g = M.igv.verify(p_intent, M.vlg.ground(l, x_prime, A)['p_vla'])['g']

    # 5) 意图鲁棒认证前缀
    k_civ = M.ibs.certified_prefix(A, p_intent, g, M.safety_margin_intent)

    # 6) 单调收紧
    lam = math.exp(-M.beta_H * entropy(p_intent) - M.beta_g * g)
    tau_cmd = M.vista.pi_sigma.prefix_dispatch(A[:k]) * lam

    cert = J_CIVIC(M.j_simras, hash(p_intent),
                   hash(M.ibs.credible_set(p_intent)), g, k,
```

## 4. 推导

**引理 13（意图后验收缩）** 设观测在给定 `I` 下条件独立，且每次观测使期望对数损失至少下降 `ι > 0`。则
```
H_I(t) ≤ H_I(0) - t·ι
```
当 `t ≥ H_I(0)/ι` 时后验熵不超过 `0`。若出现 `d_intent > τ_drift`，后验被重锚，收缩重新开始。

**引理 14（接地残差对 VLA 误差的界）** 若 VLA 诱导分布相对真实意图的总变差为 `ε_VLA`，且似然密度比有界 `B`，则
```
g_t = KL(P_I ‖ P_I^VLA) ≤ B·ε_VLA
```
故 `τ_ground` 应标定为 `B·ε_VLA` 的可检测倍数；VLA 越差，阈值越保守。

**定理 14（意图鲁棒安全）** 若 `J_CIVIC` 有效，则对可信集 `ℐ_α(t)` 中任意意图，
```
P(unsafe) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_vqa + α_intent + α_open
```
且 `λ_intent ∈ (0,1]`，意图不确定性只收紧不放松，**不存在“因意图误判而放行”的通道**。

**定理 15（主动澄清的收敛与成本）** 若每次澄清的意图互信息增益 `IG ≥ IG_min`，则把意图熵降到 `ε` 所需澄清次数
```
N ≤ ⌈log(1/ε)/IG_min⌉
```
总打扰成本 `≤ N·c_max`；相对被动观察，样本复杂度由 `O(1/ι)` 降至 `O(log(1/ε)/IG_min)`。

**定理 16（说做不一致的可检测性）** 在 `ℰ_intent` 下若指令与动作的语义散度至少 `Δ`，则 `T` 帧内 IGV 检出概率
```
P(detect) ≥ 1 - exp(-T·Δ²/(2B²))
```
（Hoeffding + Pinsker）。提示注入若改变动作 token 却不改变语言 token，必被残差捕获。

## 7. 本轮最大风险

**一句话**：CIVIC 把「意图」当作可从语言与动作中可靠辨识的潜变量，但真实场景中语言本身歧义、可被提示注入，VLA 又会用流畅的“动作语言化”为错误意图背书——于是最危险的不是识别错，而是**系统对错误意图过度自信（意图过自信）**：接地残差与后验熵同时偏低，IBS 便在一个错误但看似可信的意图集合上给出认证前缀，把“理解错了”伪装成“理解对了”——这是本轮全部理论依赖的核心假设：**意图可由有限观测辨识，且 VLA 的语义接地残差是可靠的分布外信号。**
