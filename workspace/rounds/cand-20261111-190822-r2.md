# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「流匹配策略」×「末端位姿」）

> 第 54 轮把技能从能力黑箱压成动作空间占用 α_S，并给出云边动作-鲁棒性联合证书 J。本轮追问两个更「第一性」的问题：技能的动作**不是均匀占满一个区域**，而是由生成式策略以**流匹配**形式给出的一条连续速度场——真正该被认证的是**动作分布的高密度核**而非硬占用；而任务成败最终落在**末端位姿**上，SE(3) 是比「动作空间」更接近物理保真度的不变量。核心矛盾：H22：硬占用 α_S 会高估兼容性（把"可执行但极不可能"的动作当作可组合），导致 SCOM 假阳性；H23：云端在 SE(3) 位姿层规划、边端在关节动作层执行，但 IK 提升在位姿奇异处**多值且病态**，位姿层证书无法直接下传到动作层。

## 0. 直觉与动机

**灵感 1（流匹配策略 → 动作占用从「集合」升级为「密度 + 速度场」）**
直觉：第 54 轮的 `α_S(a)∈{0,1}` 只回答"能不能做"，但流匹配策略 `π_S` 实际定义了一个速度场 `v_S(a,t|o)`，把噪声 `a_0∼N(0,I)` 经 ODE `da/dt=v_S` 输运到动作分布 `p_S(a)`。于是"技能真正可靠的区域"不是支撑集，而是**高密度核** `Core_θ(S)={a: log p_S(a) ≥ log θ_den}`。一个动作即便可执行（`α_S=1`），若落在低密度尾部，也极可能在分布外扰动下崩掉。这把技能兼容性从"集合交"提升为"密度比"。

**灵感 2（末端位姿 → 把证书锚定到可测量的 SE(3) 管）**
直觉：无论云端多聪明，任务成功最终体现为末端位姿 `ξ(t)=(p,R)∈SE(3)` 是否贴合期望轨迹 `ξ_T(t)`。因此证书的最终判据应是**位姿管**：`sup_t d_SE3(ξ(t),ξ_T(t)) ≤ ε`。位姿管是**物理可解释**的（厘米 + 度），可直接向用户/裁判承诺，也能反向约束动作分布核的大小。

**灵感 3（位姿连续组合 → 流的速度场边界匹配，而非动作集合交）**
直觉：两段技能拼接，不是"动作空间有交集就行"，而是**速度场在边界处连续**：`||v_i(a,T_i) - v_j(a,0)|| ≤ δ_v`，同时末端位姿在拼接点对齐 `d_SE3(ξ_i(T_i), ξ_j(0)) ≤ ε_b`。流匹配的确定性 ODE 让"拼接"成为重参数化时间 + 边界速度匹配，比 54 轮的 Jaccard 兼容更贴合真实执行。

**灵感 4（位姿提升歧义 → IK 多值性是云边下传的真正断点）**
直觉：云端在位姿层说"到 ξ*"，边端要解 `IK(ξ*)=q`；但 IK 在奇异附近多解、且条件数 `κ_J=σ_max(J)/σ_min(J)` 爆炸，微小的位姿误差会被放大成巨大的关节跳变。于是位姿证书 `ε` 必须与雅可比条件 `κ_J` 联动：`||δq|| ≤ κ_J·||δξ||`。这解释了 54 轮 `γ_ce` 为何在极限动作处失效——它漏掉了 `SE(3)→关节` 的提升算子。

**灵感 5（流-位姿金字塔）**
直觉：在第 54 轮动作层 `𝔸` 之上叠加 **流-位姿层 `𝔽`**：`𝔽_0` 噪声先验，`𝔽_1` 速度场与密度，`𝔽_2` SE(3) 位姿流形，`𝔽_3` 任务位姿轨迹。证书沿层传递时同时携带 `(log p_S, ε, κ_J, ρ)`，形成**密度-位姿-鲁棒性三证书**。

## 1. 形式化定义（增量：定义 121–128）

**定义 121（流匹配策略）**
技能 S 的策略写成速度场 `v_S: ℝ^d × [0,1] × O → ℝ^d`。采样：`a(0)∼p_0=N(0,I)`，`da/dt=v_S(a,t|o)`，`a_S = φ_S(a(0))`。由连续性方程，pushforward 密度满足
```
log p_S(a) = log p_0(φ_S^{-1}(a)) - ∫_0^1 ∇·v_S(a(t),t) dt
```

**定义 122（高密度动作核与密度比兼容）**
`Core_θ(S)={a: log p_S(a) ≥ log θ_den}`。技能 i,j 的密度比兼容度
```
r_ij = ∫_{Core(S_i)∩Core(S_j)} min(p_i,p_j) da / ∫_{Core(S_i)∪Core(S_j)} max(p_i,p_j) da
```
组合可行需 `r_ij ≥ θ_r`（替代 54 轮的 Jaccard `compat`）。

**定义 123（SE(3) 位姿管）**
`d_SE3(ξ_1,ξ_2)=||p_1-p_2||_2 + λ_R·arccos((tr(R_1^T R_2)-1)/2)`。位姿管 `Tube(ξ_T,ε)={ξ: d_SE3(ξ(t),ξ_T(t))≤ε ∀t}`。正运动学 `FK(q)=ξ`。

**定义 124（位姿连续组合）**
`S_i⊗S_j` 位姿连续当且仅当
```
d_SE3(FK(a_i(T_i)),FK(a_j(0))) ≤ ε_b ∧ ||v_i(a_i(T_i),T_i)-v_j(a_j(0),0)|| ≤ δ_v
```

**定义 125（位姿提升歧义证书）**
提升 `IK: SE(3)→𝒬` 在局部唯一当 `κ_J(q)=σ_max(J(q))/σ_min(J(q)) ≤ κ_max`，且 `||δq|| ≤ κ_J ||δξ||`。提升一致域 `Lift_in={ξ: κ_J(IK(ξ)) ≤ κ_max}`。

**定义 126（流-位姿联合证书）**
`F=(log p_S, ε, κ_J, ρ, evidence)`；可部署当
```
∀a∈plan: log p_S(a)≥log θ_den ∧ ε≤ε_max ∧ sup_{Tube} κ_J≤κ_max ∧ ρ≥ρ_min
```

**定义 127（流-位姿对齐成本）**
`cost_fp(S_i,S_j)=w_p(1-r_ij)+w_ε·ε_b/ε_max+w_κ·log(κ_J/κ_max)+w_ρ(1-ρ_comp)`。

**定义 128（流-位姿金字塔）**
`𝔽=(𝔽_0,…,𝔽_3)`，跨层证书 `Cert_𝔽=(log p_S, ε, κ_J, ρ, Explain)`；层间传递要求密度单调不增、位姿管嵌套、`κ_J` 单调。

## 2. 关键算法 伪代码

### IP-121 FAD（Flow Action Density）

```python
def flow_log_density(policy, a, n_steps=32):
    dt = -1.0 / n_steps
    logp = 0.0
    for k in reversed(range(n_steps)):
        t = (k + 0.5) / n_steps
        v = policy.velocity(a, t)
        logp -= policy.divergence(a, t) * dt   # Hutchinson / 解析散度
        a = a + v * dt
    return logp + log_gaussian(a)              # 回到 p_0
```

### IP-122 PTC（Pose Tube Certificate）

```python
def pose_tube_cert(a_traj, xi_target, fk, eps_max):
    errs = [se3_dist(fk(a), xi) for a, xi in zip(a_traj, xi_target)]
    eps = max(errs)
    return ('ok', eps) if eps <= eps_max else ('reject', 'pose_tube', eps)
```

### IP-123 PCC（Pose-Continuous Composition）

```python
def pose_continuous_compose(si, sj, eps_b, delta_v):
    if se3_dist(fk(si.end_action()), fk(sj.start_action())) > eps_b:
        return ('reject', 'pose_gap')
    if norm(si.velocity_end() - sj.velocity_start()) > delta_v:
        return ('reject', 'velocity_jump')
    return ('ok', stitch_flow(si, sj))         # 时间重参数化后拼接
```

### IP-124 PLA（Pose-Lift Ambiguity）

```python
def lift_certificate(xi_tube, ik, jac, kappa_max):
    qs = [ik(xi) for xi in xi_tube]
    if not branch_consistent(qs):              # 追踪同一 IK 分支
        return ('reject', 'multivalued_lift')
    kappa = max(cond(jac(q)) for q in qs)
    return ('ok', kappa) if kappa <= kappa_max else ('reject', 'near_singular', kappa)
```

### IP-125 FPC（Flow-Pose Joint Certificate）

```python
def flow_pose_cert(plan, policy, fk, ik, jac, b):
    a_traj = policy.rollout(plan)              # 确定性 ODE 采样
    if min(flow_log_density(policy, a) for a in a_traj) < log(b.theta_den):
        return ('reject', 'out_of_distribution')
    st, eps = pose_tube_cert(a_traj, plan.xi_target, fk, b.eps_max)
    if st != 'ok':
        return (st, eps)
    st, kappa = lift_certificate(plan.xi_target, ik, jac, b.kappa_max)
    if st != 'ok':
        return (st, kappa)
    if min(plan.rho.values()) < b.rho_min:
        return ('reject', 'robustness_fail', plan.rho)
    return ('ok', FPC(min_logp=..., eps=eps, kappa=kappa, rho=plan.rho))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| FAD | O(n_steps·d·b) | O(d) | 散度估计无偏、ODE 稳定 |
| PTC | O(|T|·d_fk) | O(|T|) | FK 精确、SE(3) 度量一致 |
| PCC | O(|T|·d_fk + d) | O(1) | 边界速度 Lipschitz |
| PLA | O(|Tube|·d_ik + d³) | O(|Tube|) | 分支一致、κ_J 门限 sound |
| FPC | O(n_steps·d + |T|·d_fk + |Tube|·d_ik) | O(|T|+|Tube|) | 四约束联合 sound |

**正确性定理（Flow-Pose Certificate Soundness）**
假设承接 (A26)–(A28)；新增 **(A29)** `v_S` 在采样区间 `L_v`-Lipschitz；**(A30)** 密度估计校准误差 ≤ `δ_den`、ODE 积分误差 ≤ `δ_ode`；**(A31)** 位姿管上 `κ_J ≤ κ_max` 且 `FK` 精确。则
```
P( sup_t d_SE3(ξ(t),ξ_T(t)) ≤ ε )
  ≥ 1 - δ_den - δ_ode - δ_lift - Σ_d (1 - ρ_min(d))
```
其中 `δ_lift = P(κ_J > κ_max ∨ IK 多值跳变)`。关键：**密度核限定分布内**，**位姿管给出物理可测承诺**，**κ_J 保证位姿证书能无放大地下传到关节**。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 流密度校准失真 | 高 | 条件流匹配解析速度 + held-out ECE + 保形预测放缩 θ_den |
| SE(3) 线性化误差累积 | 高 | 右不变误差 + 分段管 + 角速度上界 |
| 长时 ODE 积分漂移 | 中 | Lipschitz 界 + 自适应步长 + 中途锚点重投影 |
| IK 分支跳变 | 高 | 分支一致性跟踪 + κ_J 门限 + 关节连续性约束 |
| 云边坡姿时间对齐 | 中 | 统一 SE(3) 时间戳 + 速度前馈 |

## 6. 本轮最大风险

**一句话**：流匹配策略把证书从「动作可执行」推进到「动作高密度核 + SE(3) 位姿管」，形式上漂亮，但其 soundness **同时压在两个各自可信、却从未联合验证的近似上——流模型的似然校准与 SE(3) 位姿管的线性化/提升一致性**；一旦密度估计把分布外动作误判为高密度核、或位姿管在奇异附近因 IK 病态而实际越界，两张各自"通过"的证书会叠加成一个系统性伪装的"已认证位姿，而真实末端早已出管，故必须以**保形密度校准 + κ_J 全程门限 + 位姿管实测超界绊线**三重护栏，宁可缩小认证域，绝不把「流密度漂亮」当成「位姿一定在管内」。

```

  ≥ 1 - δ_den - δ_ode - δ_lift - Σ_d (1 - ρ_min(d))
```
其中 `δ_lift = P(κ_J > κ_max ∨ IK 多值跳变)`。关键：**密度核限定分布内**，**位姿管给出物理可测承诺**，**κ_J 保证位姿证书无放大下传到关节**。

## 5. 本轮最大风险

**一句话**：流匹配策略把证书从「动作可执行」推进到「动作高密度核 + SE(3) 位姿管」，形式上漂亮，但其 soundness **同时压在两个各自可信、却从未联合验证的近似上——流模型的似然校准与 SE(3) 位姿管的线性化/提升一致性**；一旦密度估计把分布外动作误判为高密度核、或位姿管在奇异附近因 IK 病态而实际越界，两张各自"通过"的证书会叠加成一个系统性伪装的"已认证位姿，而真实末端早已出管，故必须以**保形密度校准 + κ_J 全程门限 + 位姿管实测超界绊线**三重护栏，宁可缩小认证域，绝不把「流密度漂亮」当成「位姿一定在管内」。
