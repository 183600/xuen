>
> **把「创新点」从组件清单降维为「可消融、可分离、可反驳」的因果声明；把「比赛」从堆功能升级为预算与对抗基线约束下的证据组合优化。** 一条创新点只有在「去掉它会掉分（信用）、它与别的点不共线（独立）、先验完备基线解释不了它（新颖）、最强反论文打不死它（稳健）」四条同时成立时才进入叙事；一个赛道只有在「分差确实由我们的机制中介、而非算力/调参/数据混杂」时才值得投入。

## 0. 直觉与动机

**灵感 1（创新点提炼 → 创新不是一个数量，而是一组可分离的因果声明）**
直觉：前 65 轮积累了 223 个 IP，但"创新点数量"是虚荣指标。评审或评委不会逐条验证 223 件事，他们只检验 2–3 条决定性声明。若声明 A 与声明 B 永远一起开关、一起涨分，它们只是一个创新点（**共线**）；若去掉某组件分数不掉，它只是实现细节（**无信用**）；若一个"先验完备基线"——把已发表的所有相关机制都装进去、并用同等算力与调参预算训练——也能达到同等效果，那就不是新颖性（**被先验解释**）；若一个更强的反论文（counter-paper）能复现甚至超过我们，那这条声明就不该写进标题（**被反驳**）。因此，提炼不是删减文字，而是**做一组能把这些声明彼此分开的干预**。这与第 65 轮"故障不可辨识"是同一个数学结构：把"故障幅度 θ"换成"声明信用 γ"，把"CGG 二选一"换成"223 条声明里选最小可分离基"。

**灵感 2（比赛策略 → 比赛是带预算的主动实验选择，而不是功能展示）**
直觉：比赛本质上是第 65 轮 AFA 的元层版本。AFA 问"做哪个探针最能分清谁坏了"；比赛问"做哪个实验/报哪条赛道最能判定我们的声明是否成立"。正确的策略不是把所有功能都报一遍，而是选择**每单位算力能最大程度降低声明不确定性**的实验；避开"分差主要来自算力/调参/数据、而非我们的机制"的赛道（**混杂**）；避开"决定性指标正好是我们的共享弱点"的赛道（**策略级共因**，透明/反光会同时骗过我们的视觉与对手的视觉）；不要用公开榜单反复调参（**赢家诅咒**）。

**灵感 3（合流 → 提炼与比赛是同一个集合选择问题）**
直觉：提炼是在声明集 C 上选一个子集 S；比赛是在实验/赛道集 E 上选一个子集。两者共享同一目标：在预算 B 下最大化"可辩护证据覆盖"，并满足独立性、新颖性、反驳稳健性、共失效上界。这个目标函数是**单调次模**的，所以贪心有 1−1/e 级别的近似保证——这意味着"不用赌，按边际证据/成本贪心买"就是接近最优的比赛策略。叙事证书 J_candor 正是研究与比赛之间的接口：它告诉比赛方"哪几条声明要守、要买哪些实验去守"。

**灵感 4（反论文 → 研究版的对抗认证）**
直觉：与其问"我们的方法好不好"，不如问"**最强的反论文会怎么写我们**"。对每条声明构造四类反论文：(i) 最近先验 + 同等预算；(ii) "只是更多数据/算力"的暴力基线；(iii) 同一机制去掉我们的关键 twist；(iv) 把我们的机制用在不该用的分布上。若声明在 minimax 意义下仍有正裕度，才保留；否则合并、降级为"工程细节"，或直接删掉。这是第 65 轮 DIR/AIC 对抗干扰集在"研究声明"上的镜像。

**灵感 5（叙事熵 → 好故事既集中又不单点）**
直觉：好的提炼会让信用集中在少数几条声明上（叙事熵低、故事清晰），但**不能低到只有一条**——单条声明被反论文打掉，整个故事就崩了。因此需要两个指标：叙事熵 H_narr 与蒸馏比 δ_dist，并要求"有效声明数 ≥2（允许时）"或显式标注单点风险。最终产出的不是一段漂亮话，而是一份**可审计的证书**：每句话都挂着一条声明、一个消融、一个先验基线、一个反驳裕度、一笔预算。

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（声明、组件与声明集）**：组件 N={1,…,n}（每个 IP/机制）；声明 c_i=(m_i,B_i,y_i,D_i,ψ_i)，含机制、比较基线族、指标、评价分布、**可测伪证器** ψ_i。C={c_i}。区分"组件"（实现）与"声明"（可证伪命题）：多个组件可支撑一条声明，一个组件也可拆成多条声明；**进入叙事的单位是声明，不是组件**。
- **定义 234（声明信用与 Shapley 归因）**：v(S)=E_{x∼D}[Y(do(components=S))]；Shapley 信用 γ_i=Σ_{S⊆N\{i}} |S|!(n−|S|−1)!/n!·[v(S∪{i})−v(S)]，满足效率性 Σ_i γ_i=v(N)−v(∅)。声明被"信用认证"⇔ γ_i 的 bootstrap 置信区间排除 0 且归一化信用 γ_i/Σ_j|γ_j|≥τ_c。
- **定义 235（声明签名与可分离性）**：对基准 j，边际效应 M_{ji}=E[Y_j|do(c_i=1)]−E[Y_j|do(c_i=0)]（其余置于默认）。声明签名矩阵 M∈ℝ^{m×n}，可分离性 κ_claim=λ_min(MᵀΣ_Y⁻¹M)/λ_max(·)。若 rank(M)<|C| 或 κ_claim<κ_min，则存在**共线声明**：它们不能被分别信用归因，必须合并为一个复合声明。**两个总是一起动的创新，只是一个创新。**
- **定义 236（先验完备基线与新颖残差）**：用先验池 P 构造 b_pa：装入所有已发表的相关机制，并在同等数据/算力/调参预算下训练。新颖残差 ν_i=γ_i(ours)−γ_i(b_pa)（同一基准、同一协议）。再做**机制中介检验**：若把先验机制 m_p 加回我们的消融版本能恢复 ≥1−ε_med 的性能，则我们的增益被 m_p 解释，不算新颖。新颖认证⇔ ν_i≥τ_n 且无先验机制中介过半。
- **定义 237（反论文与反驳裕度）**：反论文集 B⁻(c_i) 含四类：最近先验同预算、暴力数据/算力基线、去掉关键 twist 的同机制、错分布移植。反驳裕度 μ_i(b)=E[Y_ours−Y_b | c_i 的决定性指标与分布]；反驳风险 R_i=P(min_{b∈B⁻} μ_i(b)≤0)。声明"反驳硬化"⇔ 对 ‖B⁻‖ 的 CVaR 与 bootstrap 下界仍满足 min_b μ_i(b)>0 且 R_i≤α_ref。用 minimax 而非均值，防止"平均赢、关键赛道输"。
- **定义 238（可提炼声明基 S*）**：选 S⊆C 使：(i) 每条 i∈S 同时通过信用/独立/新颖/反驳四认证；(ii) S 覆盖所有可辩护效应——未被选中的可辩护声明要么信用可忽略，要么与 S 中某条近共线（合并无损）；(iii) 证据成本 Σ_{i∈S} cost_i≤C_story。目标 V(S)=Σ_f w_f[1−∏_{i∈S}(1−cover_{if})]−λ|S|，其中 f 为待解释的可辩护效应。S* 是"最小可分离见证集"，与测试覆盖/集合覆盖同构，NP-hard，贪心有 log/1−1/e 近似。
- **定义 239（赛道、基线与锦标赛状态）**：赛道 t∈T，评分规则 s_t，对手/基线集，公开/私有划分，剩余算力与截止时间。比赛状态 State=(T, leaderboard, B, deadline)。
- **定义 240（判别性赛道与机制中介）**：赛道 t 上的分差 Δ_t=perf(ours)−perf(best baseline)。声明 c_i 在 t 上**有判别性** ⇔ 消融机制 m_i 能移除 ≥ρ_med 的 Δ_t，且数据/算力/调参被匹配；定义 discrim_t(c_i)=被中介的分差比例。只报"分差由我们机制中介"的赛道，避免把算力优势误读成创新优势。
- **定义 241（证据组合与预算）**：实验 e∈E（消融、基线、赛道提交、压力测试），成本 c_e，覆盖概率 p_{ie}=P(e 能判定声明 i 生死)。预算 B。选 E 最大化 f(E)=Σ_i w_i[1−∏_{e∈E}(1−p_{ie})]。f 单调次模；"判定生死"包括证真与证伪——两者都降低决策不确定性。
- **定义 242（策略级共失效守卫）**：在赛道/实验上建共失效图：若同一分布偏移（透明、反光、光照、硬件、数据偏置）会同时压低两者，则连边。策略共失效风险 = max_{失效源} 暴露预算占比，约束 ≤ρ_share。这是第 65 轮共因故障在策略层的镜像。
- **定义 243（叙事熵与蒸馏比）**：信用份额 p_i=γ_i/Σγ，H_narr=−Σ p_i log p_i，有效声明数 exp(H_narr)；蒸馏比 δ_dist=|S*|/n_components，解释信用比 =Σ_{i∈S*}γ_i/Σ_all γ_i。好故事：|S*| 小、解释信用高、无冗余、每条反驳硬化；但若 max_i p_i 过高，必须显式标注单点风险。
- **定义 244（CANDOR 策略）**：给定 State 与声明基 S*，选 (E,allocation) 最大化期望最终效用 U=E[rank/accept]−λ_risk·共失效风险−λ_cost·成本，s.t. 预算与覆盖约束。用场景采样 + 贪心求解；不确定性高时退化为"先买判别性最强的 2 个实验"。
- **定义 245（J_candor 证书）**：J_candor=(claim_basis, credit_CI, signature_condition, novelty_residual, refutation_margin, cover_map, budget_ledger, cofailure_max, holdout_tracks, narrative_entropy, dist_ratio, version)。Valid ⇔ 每条选中声明四认证通过 ∧ 覆盖可辩护效应≥ρ_cov ∧ 预算未超 ∧ 共失效≤ρ_share ∧ 至少一条留出赛道未动 ∧ 每条声明有伪证器与责任人。
- **定义 246（CANDOR 双环算子）**：**声明环（离线、昂贵）**：[组件登记→定义声明与伪证器→Shapley 消融→签名矩阵→先验完备基线→反论文红队→提炼 S*→J_candor]；**比赛环（在线、有预算）**：[State 读入→判别赛道筛选→证据组合贪心→提交/监控→共失效守卫→预算重分配→留出赛道复核]。不变式：**无四认证不进入叙事；无边际覆盖不分配预算；离线红队与在线比赛分离，在线不写声明。**
- **定义 247（评审注意力预算与声明排序）**：评审最多检查 L 条声明；按可辩护性排序，价值 = 前 L 条存活概率之和。若 |S*|>L，优先合并近共线声明或删除最低反驳裕度者，而不是把 223 条都塞进附录。
- **定义 248（CANDOR 不变式）**：(a) 叙事只含通过四认证的声明；(b) 每条声明有唯一伪证器与可执行消融；(c) 比赛预算按边际覆盖/成本分配；(d) 至少保留一条未触碰的留出赛道；(e) 任何赛道分差不得由未匹配的算力/数据混杂解释；(f) 共失效暴露有上界；(g) 离线声明环与在线比赛环严格分离。

## 2. 关键算法骨架

```python
# 1) 声明信用：对每条声明做 Shapley 消融（语义/离线环）
gamma = shapley_credit(value_fn, C, n_perm=256)         # 置换采样，CI 可 bootstrap
credited = {i for i in C if ci_lo(gamma, i) > 0
            and gamma[i] / sum_abs(gamma) >= TAU_C}

# 2) 可分离性：签名矩阵秩 / 共线检测
M = signature_matrix(C, benchmarks)                      # M[j,i] = 边际效应
S = maximal_independent_subspace(M, kappa_min=KAPPA_MIN) # 共线声明合并

# 3) 新颖与反驳：先验完备基线 + 反论文红队
nu = novelty_residual(gamma, b_pa, mediation_tol=EPS_MED)
mu = refutation_margin(ours, counter_papers(C), cvar=0.2)
hardened = {i: nu[i] >= TAU_N and mu_lo[i] > 0 and refute_risk[i] <= ALPHA_REF}

# 4) 提炼：最小可分离声明基（次模覆盖 + 简洁惩罚）
S_star = distil(S, credited & hardened, cover, costs, budget=C_STORY, lam=LAMBDA)
cert = build_j_candor(S_star, gamma, M, nu, mu)

# 5) 比赛：判别赛道 + 预算证据组合 + 共失效守卫
tracks = arena.select(T, S_star, require_mediation=True, matched_budget=True)
E = portfolio.greedy(tracks, S_star, costs, cover, budget=B,
                     cofailure_max=RHO_SHARE, holdout=1)
for e in E:                                  # 在线只做实验与监控
    submit_or_run(e); monitor(e, S_star)
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（声明信用可辨识）**：在可独立干预（A94）与无混杂（A95）下，Shapley 信用 γ_i 可由置换采样无偏估计；若两声明从未被独立开关（共线），则只有其和可辨识，单独信用不可辨识——这正是"两个创新其实是一个"的形式化。
- **引理 10（最小声明基 = 签名矩阵的秩）**：可观测效应全部落在 M 的列空间；最小独立声明数 = rank(M)。任何 r=rank(M) 的基都能精确解释全部可观测效应，共线列不增加新效应。故提炼的下界由秩给出，而不是由"感觉重要"给出。
- **定理 9（CANDOR 审计有效性）**：若 Valid(J_candor)，则每条选中声明都有非零干预信用、无共线重复、先验完备基线残差、正的反驳下界、覆盖映射与预算账本。证书保证的是**内部可审计**，不是外部为真；外部有效性必须由留出赛道复核。
- **定理 10（预算组合近最优）**：覆盖函数 f(E) 单调次模；基数约束下贪心 ≥(1−1/e)f(OPT)；背包约束下密度贪心 ≥(1−1/e)/2，带部分枚举可到 (1−1/e)。故"按边际证据/成本贪心买实验"是近最优比赛策略。
- **命题 11（排行榜选择偏差）**：K 个候选配置的公开分带 iid 噪声 N(0,σ²) 时，取最大值会把期望虚高约 σ√(2 ln K)；以概率 ≥1−δ 虚高不超过 σ√(2 ln(K/δ))。故必须留出赛道并报告收缩估计，否则"调参调出来的冠军"会在私有榜崩塌。

# 第 66 轮产物 · 创新点清单 v4：CANDOR（Claim-level Attribution, Novelty Distillation & Opportunity Ranking：声明级归因 × 创新提炼 × 比赛证据组合策略）

> 承接第 65 轮 IP-214~223（VISTA：VPG×ACH×FIR×VCV×VSP/AFA×CSC×RSC-V×WCV-V×CSP-V×AIC-V×J_vista）。第 65 轮把"几何可证伪"升级为"故障可归因"，但其最大风险是**归因依赖有限假设集与失效独立性**：未知复合故障会被强行归入最近假设，系统因"已经归因"而更自信地执行。本轮不追加第 6 个模态，也不再加新组件，而是换一个层级提问：
>
> **223 个 IP 里，到底有几条是能被消融独立证明、能被先验完备基线区分、能被最强反论文打不死的"创新声明"？比赛预算又该押在哪几条上？**
>
> 本轮实现 **「创新可分离、叙事可审计、预算按证据买」**：把创新点从"组件清单"降维为"可消融、可分离、可反驳"的因果声明；把比赛从"堆功能"升级为预算与对抗基线约束下的证据组合优化。核心新增为 **CANDOR 双环**：离线**声明环**做信用/独立/新颖/反驳四认证并提炼最小声明基；在线**比赛环**按"边际证据/成本"贪心买实验，并用共失效守卫与留出赛道防止赢家诅咒。
>
> IP 编号：IP-224~IP-233（共 10 个），全部为第 65 轮之上的元层新增或原位挂载。

## 2. 形式化定义（完整版）

**定义 233（声明、组件与声明集）** 组件集 N={1,…,n} 表示可开关的机制/IP；声明 c_i=(m_i,B_i,y_i,D_i,ψ_i)，其中 m_i 为机制陈述，B_i 为比较基线族，y_i 为指标，D_i 为评价分布，ψ_i 为**可测伪证器**（一个能在有限实验内判定真/假的谓词）。C={c_i} 为声明集。关键区分：组件是"实现"，声明是"可证伪命题"；多个组件可支撑一条声明，一个组件也可拆成多条声明。**进入叙事与比赛的计数单位是声明，不是组件。**

**定义 234（声明信用与 Shapley 归因）** 对 S⊆N，定义干预价值 v(S)=E_{x∼D}[Y(do(components=S))]。声明 i 的 Shapley 信用
γ_i = Σ_{S⊆N\{i}} |S|!(n−|S|−1)!/n! · [v(S∪{i})−v(S)]，
满足效率性 Σ_{i∈N} γ_i = v(N)−v(∅)。用置换采样估计 γ̂_i，并以 bootstrap 给置信区间。**信用认证**：CI 下界 >0 且归一化信用 γ_i/Σ_j|γ_j| ≥ τ_c。若无法对某组件做独立干预（A94 失效），则只能报告信用区间而非点估计。

**定义 235（声明签名与可分离性）** 对基准 j=1,…,m，边际效应
M_{ji}=E[Y_j | do(c_i=1)] − E[Y_j | do(c_i=0)]（其余声明置于默认）。
M 的第 i 列为声明 i 的"效应签名"。可分离裕度
κ_claim = λ_min(MᵀΣ_Y⁻¹M) / λ_max(MᵀΣ_Y⁻¹M)。
若 rank(M)<|C| 或 κ_claim<κ_min，则存在**共线声明**：它们在任何基准上同向同比例移动，无法被分别信用归因。此时必须合并为复合声明 c_{ij}，或删除冗余者。**判据：两个总是一起动的创新，只是一个创新。**

**定义 236（先验完备基线与新颖残差）** 给定先验池 P（所有已发表的相关机制），构造**先验完备基线** b_pa：装入 P 中每个机制（允许组合），并在同等训练数据、同等调参预算、同等算力下训练。新颖残差
ν_i = γ_i(ours) − γ_i(b_pa)，
在同一基准、同一协议、同一随机种子集上计算。再做**机制中介检验**：对每个先验机制 m_p，把 m_p 加回"去掉 c_i 的消融版本"，若性能恢复比例 ≥1−ε_med，则我们的增益被 m_p 解释，c_i 不算新颖。**新颖认证**：ν_i≥τ_n 且不存在中介过半的先验机制。注意：新颖性不是"引用更少"，而是"在把先验都装进去的强基线面前，仍有无法被解释的残差"。

**定义 237（反论文与反驳裕度）** 对声明 c_i 构造四类反论文：
1. 最近先验 + 同等预算；
2. 暴力基线（更多数据/更大模型/更长训练）；
3. 同一机制去掉关键 twist；
4. 把我们的机制移植到不该用的分布。
记 B⁻(c_i) 为反论文集。反驳裕度 μ_i(b)=E[Y_ours−Y_b | c_i 的决定性指标与分布]；反驳风险 R_i=P(min_{b∈B⁻} μ_i(b)≤0)。**反驳硬化**：对 B⁻ 的 CVaR_β 与 bootstrap 下界仍满足 min_b μ_i(b)>0，且 R_i≤α_ref。采用 minimax 而非均值，防止"平均赢、决定性赛道输"。

**定义 238（可提炼声明基 S*）** 选 S⊆C 使：
(i) ∀i∈S 同时通过信用（定义 234）、独立（定义 235）、新颖（定义 236）、反驳（定义 237）四认证；
(ii) S **覆盖**所有可辩护效应：未被选中的可辩护声明，要么信用可忽略（γ_i<τ_c），要么与 S 中某条近共线（合并后不损失可观测效应）；
(iii) 证据成本 Σ_{i∈S} cost_i ≤ C_story。
目标函数
V(S)=Σ_f w_f [1−∏_{i∈S}(1−cover_{if})] − λ|S|，
其中 f 跑遍待解释的可辩护效应。S* 是**最小可分离见证集**，与测试覆盖/集合覆盖同构（NP-hard）；贪心有对数/1−1/e 级近似。λ 控制"简洁 vs 覆盖"的权衡；L（定义 247）进一步截断。

**定义 239（赛道、基线与锦标赛状态）** 赛道 t∈T，评分规则 s_t，对手/基线集，公开/私有数据划分，剩余算力 B 与截止时间。比赛状态 State=(T, leaderboard, B, deadline)。赛道有不同"决定性指标"：有的看成功率，有的看安全违规，有的看样本效率；同一套声明在不同赛道上的可判别性不同。

**定义 240（判别性赛道与机制中介）** 赛道 t 上分差 Δ_t=perf(ours)−perf(best baseline)。声明 c_i 在 t 上**有判别性** ⇔ 消融机制 m_i 能移除 ≥ρ_med 的 Δ_t，且数据/算力/调参预算被匹配。定义 discrim_t(c_i)=被 m_i 中介的分差比例。**只报判别性高的赛道**，避免把"算力更多/调参更狠"误读成"创新更强"。若 discrim_t(c_i)<ρ_med，则该赛道对 c_i 不可判别，不能作为声明的证据。

**定义 241（证据组合与预算）** 实验 e∈E（消融、基线复现、赛道提交、压力测试、红队评审），成本 c_e（算力/时间/金钱），覆盖概率 p_{ie}=P(e 能判定声明 i 的生死)。预算 B。选择 E 最大化
f(E)=Σ_i w_i [1−∏_{e∈E}(1−p_{ie})]，
s.t. Σ_{e∈E} c_e ≤ B。f 是单调次模的（加权覆盖）。注意"判定生死"既包括证真也包括证伪：两者都降低决策不确定性，因此失败的实验也有信息价值。

**定义 242（策略级共失效守卫）** 在赛道/实验上建共失效图 G_cf：若同一分布偏移（透明、镜面、反光、光照、遮挡、硬件老化、数据偏置）会同时压低两者，则连边。策略共失效风险
CF(E) = max_{失效源 s} (Σ_{e∈E_s} c_e) / B，
其中 E_s 为受 s 影响的实验。约束 CF(E)≤ρ_share。这是第 65 轮共因故障在策略层的镜像：不要求"没有共因"，只要求"不要把全部预算压在同一个共因上"。

**定义 243（叙事熵与蒸馏比）** 信用份额 p_i=γ_i/Σ_j γ_j，叙事熵 H_narr=−Σ_i p_i log p_i，有效声明数 N_eff=exp(H_narr)。蒸馏比 δ_dist=|S*|/n_components，解释信用比 E_credit=Σ_{i∈S*}γ_i/Σ_all γ_i。好故事的标准：|S*| 小、E_credit 高、无冗余、每条反驳硬化。若 max_i p_i 过高（单条声明承载大部分信用），必须显式标注**单点风险**，并在比赛中优先为它买反论文实验。

**定义 244（CANDOR 策略）** 给定 State 与声明基 S*，选 (E, allocation) 最大化期望最终效用
U = E[rank/accept] − λ_risk·CF(E) − λ_cost·Σ c_e，
s.t. 预算、覆盖（f(E)≥ρ_cov·f_max）、共失效（CF≤ρ_share）、留出（至少一条赛道不参与调参）约束。用场景采样（对"声明是否真实""对手强度""分布漂移"采样）+ 贪心求解；不确定性高时退化为"先买判别性最强的 2 个实验，再重估"。

**定义 245（J_candor 证书）**
J_candor=(claim_basis, credit_CI, signature_condition, novelty_residual, refutation_margin, cover_map, budget_ledger, cofailure_max, holdout_tracks, narrative_entropy, dist_ratio, version)。
验证规则：
Valid(J_candor) ⇔
∀i∈S*：credit_CI_i>0 ∧ ν_i≥τ_n ∧ μ_i^lo>0 ∧ R_i≤α_ref
∧ κ_claim(S*)≥κ_min
∧ 覆盖可辩护效应≥ρ_cov
∧ Σ_{i∈S*} cost_i≤C_story ∧ 比赛预算≤B
∧ CF(E)≤ρ_share
∧ 至少一条留出赛道未参与任何调参
∧ 每条声明有伪证器 ψ_i 与责任人。
证书新增审计链：**为什么是这几条声明（claim_basis）、每条声明的反论文是谁（refutation_margin）、比赛预算花在哪（budget_ledger）、哪些赛道被留出（holdout_tracks）。**

**定义 246（CANDOR 双环算子）**
- **声明环（离线，昂贵，可失败）**：[组件登记 → 定义声明与伪证器 → Shapley 消融 → 签名矩阵与共线合并 → 先验完备基线 → 反论文红队 → 提炼 S* → 构建 J_candor]。
- **比赛环（在线，有预算）**：[State 读入 → 判别赛道筛选 → 证据组合贪心 → 提交/运行 → 监控与共失效守卫 → 预算重分配 → 留出赛道复核 → 证书更新]。
不变式：**无四认证不进入叙事；无边际覆盖不分配预算；离线红队与在线比赛严格分离，在线不写声明、不改伪证器。**

**定义 247（评审注意力预算与声明排序）** 评审/评委最多检查 L 条声明。按可辩护性（min 反驳裕度 × 新颖残差）排序，价值 = 前 L 条存活概率之和。若 |S*|>L，优先合并近共线声明或删除最低反驳裕度者，而不是把 223 条都塞进附录。**注意力是比算力更稀缺的预算。**

**定义 248（CANDOR 不变式）** (a) 叙事只含通过四认证的声明；(b) 每条声明有唯一伪证器与可执行消融；(c) 比赛预算按边际覆盖/成本分配；(d) 至少保留一条未触碰的留出赛道；(e) 任何赛道分差不得由未匹配的算力/数据混杂解释；(f) 共失效暴露有上界；(g) 离线声明环与在线比赛环严格分离。A94–A98 为这些不变式的假设基础：
- **A94（可独立干预）**：每条声明的机制可被独立开关，且不连带改变算力/数据/调参预算。
- **A95（无混杂）**：消融与基线在训练数据、调参预算、算力上匹配；否则只报告中介下界。
- **A96（先验池近似完备）**：P 覆盖最强已发表机制；否则 ν_i 只是新颖性的上界（真实新颖性可能更小）。
- **A97（反论文可实现）**：B⁻ 可被实现并调到可比预算；否则反驳裕度是乐观上界。
- **A98（赛道可迁移）**：公开/私有划分可交换；至少一条留出赛道用于最终复核。

### IP-224 CCC（Shapley 声明信用）

```python
class ClaimCredit:
    """对声明集做置换采样 Shapley；只认可能独立干预的声明。"""
    def __init__(self, value_fn, n_perm=256, tau_c=0.05):
        self.v, self.n_perm, self.tau_c = value_fn, n_perm, tau_c

    def estimate(self, claims):
        n = len(claims)
        samples = {i: [] for i in claims}
        for _ in range(self.n_perm):
            perm = np.random.permutation(claims)
            S, prev = set(), self.v(set())
            for i in perm:
                S.add(i)
                cur = self.v(S)
                samples[i].append(cur - prev)
                prev = cur
        gamma = {i: float(np.mean(samples[i])) for i in claims}
        ci = {i: bootstrap_ci(samples[i], alpha=0.05) for i in claims}
        total = sum(abs(g) for g in gamma.values()) + 1e-12
        credited = {i for i in claims
                    if ci[i][0] > 0 and gamma[i] / total >= self.tau_c}
        return gamma, ci, credited

    def identifiable(self, claims, interventions):
        # 若两声明在所有可行干预下同开同关，则只有其和可辨识
        return independent_columns(interventions, claims)
```

### IP-225/226/227 可分离、新颖、反驳

```python
def claim_signature_matrix(claims, benchmarks, value_fn, default):
    M = np.zeros((len(benchmarks), len(claims)))
    for j, b in enumerate(benchmarks):
        for i, c in enumerate(claims):
            M[j, i] = (evaluate(b, value_fn, active={c}, fixed=default)
                       - evaluate(b, value_fn, active=set(), fixed=default))
    return M

def separability(M, sigma_y, kappa_min=1e-2):
    J = M.T @ np.linalg.inv(sigma_y) @ M
    eig = np.linalg.eigvalsh(J)
    kappa = eig.min() / max(eig.max(), 1e-12)
    rank = int(np.sum(eig > 1e-9 * eig.max()))
    return {'kappa': float(kappa), 'rank': rank,
            'collinear': rank < M.shape[1] or kappa < kappa_min}

def novelty_residual(gamma, b_pa, claims, eps_med=0.2):
    nu = {}
    for i in claims:
        gain_ours = gamma[i]
        gain_pa = b_pa.marginal(i)                 # 同预算、同数据
        nu[i] = gain_ours - gain_pa
        # 机制中介：加回先验机制能否恢复消融后的性能
        if b_pa.mediates(i, tol=eps_med):
            nu[i] = min(nu[i], 0.0)
    return nu

COUNTER_PAPERS = {
    'nearest_prior': lambda c: build_nearest_prior(c, matched_budget=True),
    'brute_force':   lambda c: build_brute_force(c, more_data=4, more_compute=4),
    'no_twist':      lambda c: build_same_mechanism(c, drop_twist=True),
    'wrong_dist':    lambda c: build_misapplied(c, shift='ood'),
}

def refutation_margin(ours, claims, alpha_ref=0.05, cvar_beta=0.2):
    mu, risk = {}, {}
    for c in claims:
        margins = [ours.score(c) - b.score(c) for b in
                   (factory(c) for factory in COUNTER_PAPERS.values())]
        margins = np.asarray(margins)
        mu[c] = float(np.quantile(margins, cvar_beta))   # 最坏尾部
        risk[c] = float(np.mean(margins <= 0))
    return mu, risk
```

### IP-228 DISTIL（提炼声明基）

```python
class Distiller:
    def __init__(self, cover, costs, weights, lam=0.1, rho_cov=0.9):
        self.cover, self.costs, self.w = cover, costs, weights
        self.lam, self.rho_cov = lam, rho_cov

    def value(self, S, effects):
        return sum(self.w[f] * (1 - np.prod([1 - self.cover[i].get(f, 0)
                                             for i in S]))
                   for f in effects)

    def select(self, eligible, effects, budget, L=None):
        S, spent = [], 0.0
        while True:
            best, best_gain = None, 0.0
            for i in eligible:
                if i in S or spent + self.costs[i] > budget:
                    continue
                gain = (self.value(S + [i], effects) - self.value(S, effects)
                        - self.lam) / self.costs[i]          # 边际/成本
                if gain > best_gain:
                    best, best_gain = i, gain
            if best is None or best_gain <= 0:
                break
            S.append(best); spent += self.costs[best]
            if L and len(S) >= L:
                break
        return S, spent
```

### IP-229/230/231 ARENA + PORT + COFAIL

```python
class TrackSelector:
    def __init__(self, rho_med=0.5, matched=True):
        self.rho_med, self.matched = rho_med, matched

    def select(self, tracks, claims):
        keep = []
        for t in tracks:
            if self.matched and not t.budget_matched():
                continue
            disc = {c: t.mediated_fraction(c) for c in claims}
            if max(disc.values(), default=0) >= self.rho_med:
                keep.append((t, disc))
        return keep


class EvidencePortfolio:
    def __init__(self, costs, cover, weights, rho_share=0.5):
        self.costs, self.p, self.w = costs, cover, weights
        self.rho_share = rho_share

    def coverage(self, E, claims):
        return sum(self.w[i] * (1 - np.prod([1 - self.p[e][i] for e in E]))
                   for i in claims)

    def greedy(self, candidates, claims, budget, cofail):
        E, spent = [], 0.0
        while True:
            best, best_gain = None, 0.0
            for e in candidates:
                if e in E or spent + self.costs[e] > budget:
                    continue
                if cofail.exposure(E + [e]) > self.rho_share:
                    continue                                  # 策略级共因守卫
                gain = (self.coverage(E + [e], claims)
                        - self.coverage(E, claims)) / self.costs[e]
                if gain > best_gain:
                    best, best_gain = e, gain
            if best is None or best_gain <= 0:
                break
            E.append(best); spent += self.costs[best]
        return E, spent


class CoFailureGuard:
    def __init__(self, budget, sources):
        self.budget, self.sources = budget, sources   # sources[e] = set(失效源)

    def exposure(self, E):
        worst = 0.0
        for s in set().union(*[self.sources[e] for e in E]) if E else set():
            worst = max(worst, sum(self.budget[e] for e in E
                                   if s in self.sources[e]))
        return worst / max(sum(self.budget.values()), 1e-12)
```

def CANDOR_round(claim_registry, benchmarks, prior_pool, tracks, budget):
    # ———— 声明环（离线，昂贵）————
    cc = ClaimCredit(claim_registry.value_fn)

    sep = separability(M, claim_registry.sigma_y, KAPPA_MIN)
    claims = merge_collinear(claim_registry.claims, M) if sep['collinear'] \
             else claim_registry.claims

    b_pa = build_prior_art_complete(prior_pool, matched_budget=True)
    nu = novelty_residual(gamma, b_pa, claims, EPS_MED)
    mu, risk = refutation_margin(claim_registry.ours, claims, ALPHA_REF)

    eligible = {c for c in credited
                if c in claims and nu[c] >= TAU_N
                and mu[c] > 0 and risk[c] <= ALPHA_REF}
    effects = defensible_effects(claim_registry, eligible)
    S_star, story_cost = Distiller(claim_registry.cover,
                                   claim_registry.costs,
                                   claim_registry.weights).select(
        eligible, effects, C_STORY, L=L_REVIEW)
    J = build_j_candor(S_star, gamma, ci, M, nu, mu, risk,
                       story_cost, version=CANDOR_VERSION)

    # ———— 比赛环（在线，有预算）————
    arena = TrackSelector(rho_med=RHO_MED).select(tracks, S_star)
    cofail = CoFailureGuard(budget.costs, budget.sources)
    E, spent = EvidencePortfolio(budget.costs, budget.cover,
                                 budget.weights).greedy(
        [e for t, _ in arena for e in t.experiments],
        S_star, budget.total, cofail)
    holdout = reserve_holdout(tracks, E)          # 至少一条不参与调参

## 4. 推导

**引理 9（声明信用可辨识）** 设 v(S)∈[0,V_max]，A94（可独立干预）与 A95（无混杂）成立。置换采样估计量 γ̂_i 无偏，且 T 次置换下由 Hoeffding 不等式
P(|γ̂_i−γ_i|≥ε) ≤ 2 exp(−T ε² / (2 V_max²))。
若两声明 i,j 在所有可行干预中同开同关（无干预能将它们分离），则观测只依赖 v 在商格上的取值，只有 γ_i+γ_j 可辨识；此时 rank(M)<|C|，κ_claim=0。这正是"两个创新其实是一个"的形式化。∎

**引理 10（最小声明基 = 签名矩阵的秩）** 可观测效应 y=E[Y|do(·)] 落在 M 的列空间 col(M) 中。若 rank(M)=r，则存在 r 条独立声明的签名构成 col(M) 的基，能精确解释全部可观测效应；任何额外声明的签名是这 r 条的线性组合，不增加新效应（只可能重新分配信用）。故最小独立声明数下界为 r，且 r 可达到。实践中用数值秩（特征值阈值）与 κ_claim 共同判定共线。∎

**定理 9（CANDOR 审计有效性）** 若 Valid(J_candor)，则由定义 245：每条 i∈S* 有非零干预信用（CI>0）、新颖残差 ν_i≥τ_n（先验完备基线无法解释）、反驳下界 μ_i^lo>0（四类反论文的尾部仍打不死）、且 S* 满足 κ_claim≥κ_min（无共线重复）、覆盖≥ρ_cov、预算与共失效有界。因此对任意审计者，**证书内部自洽且可复核**：每条叙事声明都能追溯到一次消融、一个先验基线、一个反论文、一笔预算。注意：该定理只保证"内部可审计"，不保证"外部为真"；外部有效性必须由 A98 的留出赛道复核，二者不可互相替代。∎

**定理 10（预算组合近最优）** 定义 241 的 f(E)=Σ_i w_i[1−∏_{e∈E}(1−p_{ie})] 是单调次模的（加权覆盖函数）。在基数约束 |E|≤K 下，标准贪心达到 (1−1/e)f(OPT)。在背包约束 Σc_e≤B 下，按 f 增量/成本比的密度贪心达到至少 (1−1/e)/2·f(OPT)，带部分枚举的变体可达 (1−1/e)。因此"按边际证据/成本买实验"是近最优的比赛策略；在共失效约束下，贪心只需在每步过滤违反 CF≤ρ_share 的候选，仍保持次模性（可行域是下闭的），近似比不变。∎

**命题 11（排行榜选择偏差）** 设 K 个候选配置的公开分 Y_k=θ_k+ε_k，ε_k iid N(0,σ²)，真实 θ_k 相近。则 max_k Y_k 的期望超过真实最优约 σ√(2 ln K)（Gaussian 极值近似）；由联合界，以概率 ≥1−δ 有 max_k ε_k ≤ σ√(2 ln(K/δ))。故仅按公开榜选配置会把"噪声赢家"当成创新；必须留出赛道并用收缩估计（如 James–Stein/层次贝叶斯）报告私有榜预期。比赛环因此把 holdout 设为硬约束（定义 248d）。∎

**命题 12（叙事压缩不损失可观测效应）** 若 S* 覆盖 col(M) 的一组基且每条被删声明与 S* 中某条近共线（|corr|≥1−ε），则删除这些声明后，任何基准上的可观测效应变化 ≤ε·‖M‖；即"少讲几条"不改变可观测结论，只降低冗余。反之，若删除的声明与 S* 不正交且非近共线，则存在某基准 j 使效应不可由 S* 解释——这正是"不能为了简洁而丢掉真正的创新"。∎

## 7. 已知风险

**一句话**：CANDOR 的最大风险是把"消融可分离"误当成"现实可分离"——一旦组件不可独立干预（A94 失效）、先验完备基线被欠调（A96/A95 失效）、或赛道指标被算力/数据混杂（A95/A98 失效），证书会产出**内部自洽却外部错误**的创新叙事，并把比赛预算押在一条其实站不住的声明上；这比"没有提炼"更危险，因为它给了一个看似严谨的背书。

**次级风险与缓解**：
1. **先验池不完备**：我们可能漏掉最强的已发表机制，导致 ν_i 虚高；缓解：A96 只把 ν_i 当上界，持续扩充 P，并请外部红队补先验。
2. **反论文欠调**：反论文若被弱实现，反驳裕度会虚高；缓解：A97 要求同预算调参、外部复现、报告实现成本；对每类反论文保留"最强版本"。
3. **Shapley 成本爆炸**：n 大时全因子不可行；缓解：置换采样 + 方差自适应停止 + 只对候选声明做精确估计；共线合并先行降维。
4. **声明与组件多对多**：一条声明可能由多组件支撑，Shapley 在组件层会低估/高估；缓解：在**声明层**定义开关（定义 233），组件只作为实现的嵌套因子。
5. **赛道混杂无法完全匹配**：真实比赛难以给对手同等算力；缓解：用机制中介比例而非绝对分差做证据，discrim<ρ_med 的赛道只作展示不作声明。
6. **留出赛道泄漏**：团队可能无意中用私有信息调参；缓解：留出赛道由独立人员保管、只跑一次、结果写入 J_candor。
7. **叙事过压缩**：为追求简洁删掉真正的次要创新；缓解：λ 与 L 可调，保留"合并而非删除"的选项，并记录被合并声明的信用。
8. **评审代理偏差**：E245 的 LLM 评审可能偏好长文；缓解：人类专家双盲 + 结构化评分 + 只看声明与证据链。

**本轮结论**：CANDOR 不产生新的机器人能力，而是给前 65 轮的能力**做减法并上证据**：用 Shapley 信用、签名矩阵秩、先验完备基线、反论文红队，把 223 个 IP 压成少数几条可审计的声明；再用次模证据组合与共失效守卫，把比赛预算买到最能判定这些声明的地方。**如果一条创新点不能被消融、不能被先验区分、不能被反论文检验，那它就不该出现在标题里。**
