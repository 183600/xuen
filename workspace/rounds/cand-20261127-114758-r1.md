### 第 4 轮灵感驱动研究记录（承接第 3 轮）

**灵感词**：6D位姿估计、数据配比

**直觉与动机**：

前几轮把 KEMPC/KT-MPC 推到了「证书驱动 + 可解释 + 跨任务迁移 + 自适应权重」的形态，但整套证书体系默认了两个从未被审视的前提：

1. **状态是已知的**。KT-MPC 直接以 x0 求解，KC 的前置/后置条件在「真实状态」上求值。现实中双足机器人拿到的是带协方差的 6D 位姿估计 T̂（足端相对地形、躯干相对世界，乃至 loco-manipulation 中被操作物）。位姿误差会把「支撑多边形」「足底接触点」「质心投影」这类几何前提整体平移/旋转，证书可能是在「错误的世界」上签发的——这是证书的**感知支撑域**问题。

2. **知识是被充分数据支撑的**。常识规则 c_i 的适用性与阈值来自数据，但没人约束训练/验证数据的「配比」w（地形 × 负载 × 速度 × 仿真/实机）。若 w 偏向常见平地，稀有湿滑/重载域上规则可能从未被验证，却在平均指标上表现良好——这是证书的**数据支撑域**问题。

把两者放在一起看：**6D 位姿估计给出证书在 SE(3) 上的空间支撑域（带不确定椭球），数据配比给出证书在任务分布上的统计支撑域（带覆盖下界）**。一个可信的证书必须同时声明「我在哪些位姿上成立」和「我在哪些数据域上被验证过」。这自然引出「双支撑域证书」：位姿鲁棒化把约束按不确定半径做 Minkowski 腐蚀，数据配比则决定覆盖下界如何随样本分配变化。

**关键洞见**：位姿不确定性与数据配比不是两个独立补丁，而是同一个「支撑域收缩」现象的两个坐标轴。位姿椭球半径 r_α 越大，鲁棒可行域越小；数据越向易测域倾斜，稀有域覆盖越低。二者可统一进一个**风险预算恒等式**：

    R_total ≤ α_pose + δ_data + (1 - C_lb(w))

传感器精度买 α，样本量与配比买 δ 和 C_lb。更关键的是，在 DKW 型覆盖界下，最大化覆盖下界的最优配比是 **w* ∝ p_t^{2/3}**——对稀有域做「温和超采样」。这正好从数学上解释了为什么「按目标分布原样配比」反而不是最优，以及为什么朴素地最大化平均覆盖会导致数据配比坍缩（全部押到易测域）。

**形式化目标（增量）**：
1. 定义位姿条件化 KC：P_i(T,x), Q_i(T,x_H)，给出 SE(3) 不确定椭球 E_α 与鲁棒证书裕度 ρ_i = m_i(T̂) - L_i·r_α。
2. 定义数据配比覆盖证书 DMCC：C_lb(w) = Σ_d p_t(d)·Ĉ_d - Σ_d p_t(d)·sqrt(ln(2D/δ)/(2N w_d))，并要求 supp(p_t) ⊆ supp(w)。
3. 推导固定样本预算下的最优配比 w* ∝ p_t^{2/3}，并给出下界 w_min 约束下的 KKT 修正 w_d = max(w_min, c·p_d^{2/3})。
4. 定义 PMR-MPC 与 SDCG：把 ρ_i > 0 与 C_lb ≥ 1-ε_cov 作为准入门条件，得到风险预算 R_total ≤ α + δ + (1-C_lb)。
5. 实验验证：位姿噪声增大时 PUKC 的误准入率应显著低于名义证书；配比从 p_t 改为 p_t^{2/3} 时，稀有域覆盖下界应提升而平均覆盖基本不降。

**本轮最大风险**：**位姿估计的系统性偏差与目标分布误设会让风险预算的两项同时失效**——若 6D 位姿估计存在未被协方差捕获的偏置，或部署期真实任务分布 p_t 偏离离线假设，则「α 置信椭球」根本不包含真值、「C_lb」是在错误的分布上算出的，证书会在错误的世界与错误的分布上自证安全，且因各项指标仍显示「达标」而极难在线察觉。

### IP-467 Pose-Uncertainty-Aware Knowledge Certificate (PUKC)

```python
from dataclasses import dataclass, field
from typing import Callable
import numpy as np
from scipy.stats import chi2

@dataclass
class PoseUncertaintyAwareKnowledgeCertificate:
    """PUKC：位姿条件化常识证书，带 SE(3) 鲁棒裕度"""
    name: str
    precond_pose: Callable       # P(T, x) -> float，返回有符号裕度（>=0 成立）
    postcond_pose: Callable      # Q(T, x_H) -> float，返回有符号裕度
    H: int = 10
    lip_const: float = 1.0       # L_i：裕度对 d_SE(3) 的 Lipschitz 常数
    sigma: float = 1.0           # 继承 IEKC 的激活显著性
    is_active: bool = True

    def pose_radius(self, Sigma: np.ndarray, alpha: float = 0.05) -> float:
        """E_α ⊆ 测地球 B(T̂, r_α) 的保守半径"""
        chi2_q = chi2.ppf(1.0 - alpha, df=6)
        lam_max = float(np.linalg.eigvalsh(Sigma)[-1])
        return float(np.sqrt(chi2_q * max(lam_max, 0.0)))

    def robust_margin(self, T_hat: np.ndarray, Sigma: np.ndarray,
                      x0: np.ndarray, traj: np.ndarray,
                      alpha: float = 0.05) -> tuple[float, float]:
        """返回 (ρ_i, r_α)。ρ_i = m_i(T̂) - L_i·r_α，负值表示位姿鲁棒意义下不可用"""
        r_alpha = self.pose_radius(Sigma, alpha)
        # 有符号裕度取前置与后置的较小者（保守）
        m = min(self.precond_pose(T_hat, x0),
                self.postcond_pose(T_hat, traj[min(len(traj) - 1, self.H - 1)]))
        rho = m - self.lip_const * r_alpha
        return rho, r_alpha

    def robustly_holds(self, T_hat, Sigma, x0, traj, alpha=0.05) -> bool:
        return self.robust_margin(T_hat, Sigma, x0, traj, alpha)[0] > 0.0

# ---- 具体实例：位姿不确定下的支撑多边形（Steiner 腐蚀） ----
def support_polygon_margin(T_hat, x, r_alpha, area_min=200.0):
    """足端位姿估计 -> 支撑多边形；按不确定半径做一阶 Minkowski 腐蚀"""
    S = compute_support_polygon(T_hat)          # 由双足接触点/足底多边形得到
    A = polygon_area(S)                          # cm^2
    P = polygon_perimeter(S)                     # cm
    A_robust = max(0.0, A - P * r_alpha)         # 一阶腐蚀；二阶项 O(r_alpha^2)
    return A_robust - area_min                   # 有符号裕度（cm^2）
```

> 说明：`support_polygon_margin` 的输入单位若为 cm，则 `lip_const` 取 `P`（周长），量纲为 cm²/cm；一般情形把 `L_i` 视为「裕度/位姿距离」的经验 Lipschitz 上界即可。

### IP-468 Data-Mixture Coverage Certificate (DMCC)

```python
@dataclass
class DataMixtureCoverageCertificate:
    """DMCC：给定数据配比 w，给出目标分布 p_t 上的覆盖下界"""
    domains: list[str]
    target_dist: dict[str, float]          # p_t
    delta: float = 0.05                    # DKW 置信度
    min_domain_mass: float = 0.02          # w_min
    n_total: int = 1000                    # 样本预算 N
    empirical_cov: dict[str, float] = field(default_factory=dict)  # Ĉ_d

    def coverage_lower_bound(self, w: dict[str, float]) -> float:
        """C_lb(w) = Σ_d p_t(d)Ĉ_d - Σ_d p_t(d)sqrt(ln(2D/δ)/(2N w_d))"""
        D = len(self.domains)
        log_term = np.log(2.0 * D / self.delta)
        mean = 0.0
        penalty = 0.0
        for d in self.domains:
            p = float(self.target_dist.get(d, 0.0))
            if p <= 0.0:
                continue
            wd = float(w.get(d, 0.0))
            if wd <= 0.0:
                return -np.inf            # 目标域无数据，无法认证
            nd = self.n_total * wd
            mean += p * float(self.empirical_cov.get(d, 0.0))
            penalty += p * np.sqrt(log_term / (2.0 * nd))
        return mean - penalty

    def optimal_mixture(self) -> dict[str, float]:
        """固定 N 下的覆盖最优配比：w* ∝ p_t^{2/3}，再投影到 {w>=w_min}"""
        raw = {d: float(self.target_dist.get(d, 0.0)) ** (2.0 / 3.0)
               for d in self.domains}
        if sum(raw.values()) <= 0.0:
            return {d: 1.0 / len(self.domains) for d in self.domains}
        # KKT：w_d = max(w_min, c * p_d^{2/3})，c 由 Σ w_d = 1 确定
        w = dict(raw)
        lo = self.min_domain_mass
        # 二分 c 使 sum(max(lo, c*raw_d)) = 1
        c_lo, c_hi = 1e-9, 1e9
        for _ in range(80):
            c = 0.5 * (c_lo + c_hi)
            s = sum(max(lo, c * v) for v in raw.values())
            if s > 1.0:
                c_hi = c
            else:
                c_lo = c
        c = 0.5 * (c_lo + c_hi)
        w = {d: max(lo, c * raw[d]) for d in self.domains}
        z = sum(w.values())
        return {d: v / z for d, v in w.items()}

    def maximin_mixture(self) -> dict[str, float]:
        """替代目标：抬高覆盖最差域（注水），牺牲少量平均覆盖换取稀有域安全"""
        w = {d: max(self.min_domain_mass, 1.0 / len(self.domains))
             for d in self.domains}
        # 迭代：把平均配比中「覆盖缺口最大」域的 w_d 上调，其余按比例下调
        for _ in range(50):
            deficits = {d: 1.0 - self.empirical_cov.get(d, 0.0) for d in self.domains}
            worst = max(deficits, key=deficits.get)
            w[worst] = min(1.0, w[worst] + 0.01)
            rest = [d for d in self.domains if d != worst]
            s_rest = sum(w[d] for d in rest)
            if s_rest > 0:
                for d in rest:
                    w[d] *= (1.0 - w[worst]) / s_rest
        z = sum(w.values())
        return {d: v / z for d, v in w.items()}
```

### IP-469 Pose-Mixture Robust MPC (PMR-MPC)

```python
class PoseMixtureRobustMPC(KnowledgeTransilientMPC):
    """PMR-MPC：在 KT-MPC 上增加位姿鲁棒激活与覆盖缺口附加代价"""

    def __init__(self, *args, dmcc: DataMixtureCoverageCertificate,
                 pose_provider: Callable, alpha: float = 0.05,
                 coverage_weight: float = 5.0, **kwargs):
        super().__init__(*args, **kwargs)
        self.dmcc = dmcc
        self.pose_provider = pose_provider
        self.alpha = alpha
        self.coverage_weight = coverage_weight

    def robust_active_set(self, T_hat, Sigma, x0, traj):
        active = []
        for kc in self.kc_list:
            if not isinstance(kc, PoseUncertaintyAwareKnowledgeCertificate):
                continue
            rho, r_alpha = kc.robust_margin(T_hat, Sigma, x0, traj, self.alpha)
            if rho > 0.0:
                active.append((kc, rho))
        return active

    def coverage_risk(self, w):
        clb = self.dmcc.coverage_lower_bound(w)
        return max(0.0, 1.0 - clb)

    def solve(self, x0, sensor_data, w):
        T_hat, Sigma = self.pose_provider(sensor_data)
        # 名义 KT-MPC 求初解，得到名义轨迹
        u0, kc0, dcc0, exp0 = super().solve(x0)
        traj0 = self._simulate_trajectory(x0, u0)

        # 位姿鲁棒过滤：只有 ρ_i>0 的规则才允许「授予安全」
        active = self.robust_active_set(T_hat, Sigma, x0, traj0)
        active_names = {kc.name for kc, _ in active}

        # 覆盖缺口 -> 保守化附加代价（覆盖越低，越压低速度/收紧支撑要求）
        delta_cov = self.coverage_risk(w)
        speed_scale = max(0.2, 1.0 - delta_cov)
        cost_extra = self.coverage_weight * delta_cov

        # 用鲁棒激活集重算知识惩罚；不可用规则不参与「授予安全」，但保留违规告警
        penalty = 0.0
        for kc in self.kc_list:
            if kc.name in active_names:
                rho = dict((k.name, r) for k, r in active)[kc.name]
                penalty += self.weights.get('knowledge', 10.0) * kc.sigma * max(0.0, -rho)
            else:
                penalty += self.weights.get('knowledge', 10.0) * kc.sigma  # 视为未认证，保守计罚

        return {
            "u": u0, "kc": kc0, "dcc": dcc0, "explanation": exp0,
            "robust_active": active_names, "delta_cov": delta_cov,
            "speed_scale": speed_scale, "cost_extra": cost_extra,
            "robust_penalty": penalty,
        }
```

### IP-470 Active Data-Mixture Scheduler (ADMS)

```python
class ActiveDataMixtureScheduler:
    """ADMS：主动选择下一批数据采集/验证的域配比"""

    def propose(self, dmcc: DataMixtureCoverageCertificate,
                objective: str = "coverage") -> dict:
        if objective == "coverage":
            w = dmcc.optimal_mixture()
        elif objective == "maximin":
            w = dmcc.maximin_mixture()
        else:
            raise ValueError(objective)
        clb = dmcc.coverage_lower_bound(w)
        # 每域建议采集量：n_d = N·w_d
        plan = {d: int(round(dmcc.n_total * w[d])) for d in dmcc.domains}
        return {"w": w, "n_d": plan, "predicted_C_lb": clb,
                "delta_cov": max(0.0, 1.0 - clb)}

    def update_empirical(self, dmcc, domain: str, successes: int, n: int):
        """增量更新经验覆盖（可用 Beta 后验均值替代）"""
        old = dmcc.empirical_cov.get(domain, 0.0)
        old_n = max(1, dmcc.n_total // max(1, len(dmcc.domains)))
        dmcc.empirical_cov[domain] = (old * old_n + successes) / (old_n + n)
```

### IP-471 Support-Domain Certification Gate (SDCG)

```python
@dataclass
class SupportDomainCertificationGate:
    """SDCG：KTCG ∪ PUKC ∪ DMCC 的联合准入门"""
    inner: 'KnowledgeTransilientCertificationGate'
    dmcc: DataMixtureCoverageCertificate
    pose_provider: Callable
    alpha: float = 0.05
    eps_cov: float = 0.10
    risk_budget: float = 0.20
    current_w: dict = None
    last_risk: float = float("inf")

    def admits(self, robot_plan, sensor_data: dict) -> bool:
        T_hat, Sigma = self.pose_provider(sensor_data)

        # 1. 继承 KTCG 九证
        if not self.inner.admits(robot_plan, sensor_data):
            return False

        # 2. Fil_pose：所有激活 PUKC 必须位姿鲁棒成立
        traj = robot_plan.nominal_traj
        for kc in self.inner.kc_list:
            if not isinstance(kc, PoseUncertaintyAwareKnowledgeCertificate):
                continue
            if kc.is_active and not kc.robustly_holds(
                    T_hat, Sigma, robot_plan.init_state, traj, self.alpha):
                return False

        # 3. Fil_coverage：目标分布覆盖下界达标
        w = self.current_w or self.dmcc.optimal_mixture()
        clb = self.dmcc.coverage_lower_bound(w)
        if clb < 1.0 - self.eps_cov:
            return False

        # 4. 风险预算：α(位姿越界) + δ(采样) + δ_cov(覆盖缺口)
        delta_cov = max(0.0, 1.0 - clb)
        self.last_risk = self.alpha + self.dmcc.delta + delta_cov
        return self.last_risk <= self.risk_budget
```

## 3. 关键推导

### 引理 26（位姿鲁棒裕度与椭球包含）

**陈述**：设规则 i 的有符号裕度 m_i(T) 关于 d_SE(3) 满足 L_i-Lipschitz，即 |m_i(T)-m_i(T')| ≤ L_i·d_SE(3)(T,T')。令 r_α = sqrt(χ²_{6,1-α}·λ_max(Σ))，则对任意 T ∈ E_α 有 m_i(T) ≥ m_i(T̂) - L_i·r_α。因此若 ρ_i := m_i(T̂) - L_i·r_α > 0，则规则 i 在整条椭球 E_α 上成立。

**证明**：由 E_α 的定义，‖log(T̂⁻¹T)‖²_{Σ⁻¹} ≤ χ²_{6,1-α}。因 ‖v‖_{Σ⁻¹} ≥ ‖v‖₂/sqrt(λ_max(Σ))，故 d_SE(3)(T̂,T) = ‖log(T̂⁻¹T)‖₂ ≤ sqrt(χ²_{6,1-α}·λ_max(Σ)) = r_α，即 E_α ⊆ B(T̂,r_α)。再由 Lipschitz 性，m_i(T) ≥ m_i(T̂) - L_i·d_SE(3)(T̂,T) ≥ m_i(T̂) - L_i·r_α = ρ_i > 0。∎

**支撑多边形特例**：对凸多边形 S，其平行体/腐蚀的面积满足 Steiner 公式 A(S ⊖ B_r) = A(S) - P(S)·r + O(r²)。故一阶鲁棒面积为 A_robust ≈ A - P·r_α，对应的鲁棒裕度为 A - P·r_α - 200（cm²）。这也解释了为何周长越大的支撑多边形对位姿误差越敏感。

### 引理 27（数据配比覆盖下界）

**陈述**：对每个域 d 采集 n_d = N·w_d 个 iid 样本，经验覆盖为 Ĉ_d。则对任意 δ ∈ (0,1)，以概率 ≥ 1-δ，对所有 d 同时有

    C_d ≥ Ĉ_d - sqrt(ln(2D/δ)/(2 n_d)).

于是目标分布 p_t 上的覆盖 C_t = Σ_d p_t(d)·C_d 满足

    C_t ≥ C_lb(w) := Σ_d p_t(d)·Ĉ_d - Σ_d p_t(d)·sqrt(ln(2D/δ)/(2 N w_d)),

前提是 w_d > 0 对所有 p_t(d) > 0 的域成立（即 supp(p_t) ⊆ supp(w)）。

**证明**：单域 DKW 不等式给出 P(sup_x|Ĉ_d(x)-C_d(x)| > ε) ≤ 2e^{-2n_d ε²}。对 D 个域做并集界，取每域失败概率 δ/D，令 ε_d = sqrt(ln(2D/δ)/(2n_d))，则「对所有 d，|Ĉ_d-C_d| ≤ ε_d」的概率 ≥ 1-δ。再用 p_t(d) 加权求和即得下界。若某目标域 w_d=0，则无样本、下界不可计算，故返回 -∞。∎

### 定理（固定预算下的最优数据配比）

**陈述**：固定样本预算 N，令 n_d = N·w_d，把经验覆盖 Ĉ_d 视为与 w 无关的 plug-in 估计，则最大化 C_lb(w) 等价于

    min_w  Σ_d p_d · w_d^{-1/2}   s.t.  Σ_d w_d = 1,  w_d ≥ w_min,

其无下界约束解为 **w_d* ∝ p_d^{2/3}**；带下界 w_min 时的解为 w_d* = max(w_min, c·p_d^{2/3})，常数 c 由 Σ_d w_d* = 1 唯一确定。

**证明**：C_lb(w) 中第一项 Σ p_d Ĉ_d 与 w 无关，第二项的惩罚为 sqrt(ln(2D/δ)/(2N))·Σ_d p_d w_d^{-1/2}。故只需最小化 f(w)=Σ_d p_d w_d^{-1/2}。f 在 w_d>0 上严格凸（f'' = (3/4)p_d w_d^{-5/2} > 0），等式约束下 KKT 条件为

    -1/2·p_d·w_d^{-3/2} + λ = 0  ⟹  w_d = (p_d/(2λ))^{2/3} ∝ p_d^{2/3}.

带 w_d ≥ w_min 时，KKT 互补松弛给出 w_d = max(w_min, c·p_d^{2/3})，c 由归一化约束确定（等价于把点 p^{2/3} 投影到带上界的概率单纯形，可用注水/二分求解）。∎

**推论（温和超采样）**：w_d*/p_d ∝ p_d^{-1/3}。因指数 -1/3 < 0，越稀有的域（p_d 越小）获得的**相对**采样比例越高。这与「按目标分布原样配比」直觉相反，正是避免稀有域覆盖为 0 的数学依据。

### 定理（SDCG 的风险预算）

**陈述**：设在执行步 k，事件 E1 = {T ∈ E_α}（概率 ≥ 1-α），E2 = {覆盖下界 C_lb(w) 成立}（概率 ≥ 1-δ）。若 SDCG 准入，即所有激活 PUKC 满足 ρ_i > 0 且 C_lb ≥ 1-ε_cov，则在 E1 ∩ E2 上：(a) 所有激活常识规则在 E_α 上鲁棒成立；(b) 目标分布下未认证质量 ≤ δ_cov = 1-C_lb。于是单步「位姿失效或落入未认证域」的概率上界为

    R_total ≤ α + δ + (1 - C_lb(w)).

**证明**：(a) 由引理 26，ρ_i>0 蕴含 E_α 内规则成立。(b) 由引理 27，C_t ≥ C_lb，未认证质量 1-C_t ≤ 1-C_lb = δ_cov。失败只可能来自三个互斥来源：位姿落在 E_α 外（≤α）、覆盖界失效（≤δ）、样本落入未认证域（≤δ_cov）。由并集界得 R_total ≤ α+δ+δ_cov。∎

**工程含义**：这是可调的「三旋钮」风险预算——提高传感器精度/融合降低 α，增加样本量 N 或改用 w* 降低 δ 与 δ_cov；若三者之和仍超预算，SDCG 应拒绝并降级到保守步态，而非放行。

### 引理 28（准入门单调收缩）

**陈述**：SDCG 的可行执行集满足 Exec_v29 ⊆ Exec_v28 ⊆ Exec_v27，且当 Σ→0（无位姿不确定）且 w 使 C_lb→1 时，Exec_v29 → Exec_v28。

**证明**：SDCG 在 KTCG 的九项合取之上再与 Fil_pose、Fil_coverage 两个谓词取合取，故执行集只会收缩。极限情形下 r_α→0 使 ρ_i→m_i(T̂)，覆盖下界→1 使 Fil_coverage 恒真，两过滤器退化为恒真，故收缩消失。∎

## 4. 复杂度分析（增量）

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 |
|---|---|---|---|

**E1（位姿鲁棒性）**：在支撑多边形/足底接触几何上注入 6D 位姿噪声，扫描 σ_pos ∈ {0,5,10,20}mm、σ_rot ∈ {0,0.1,0.5}°，比较名义证书与 PUKC（α=0.05）的**误准入率**（证书判安全但真值下违规）。预期：名义证书在 20mm/0.5° 时误准入显著上升，PUKC 被 α 约束在 ~5%。

## 7. 本轮最大风险（最终确认）

**一句话**：**位姿估计的系统性偏差与目标分布误设会让风险预算的两项同时失效**——若 6D 位姿估计存在协方差未捕获的偏置，或部署期真实 p_t 偏离离线假设，则 α 置信椭球根本不包含真值、C_lb 是在错误分布上计算的，证书会在错误的世界与错误的分布上自证安全，而平均指标仍显示「达标」，是当前方案最隐蔽的安全隐患。
