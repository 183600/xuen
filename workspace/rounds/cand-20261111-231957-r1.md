# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；新一轮灵感循环第 1 轮；本轮灵感：「具身智能」×「开源软件」）

> 第 54 轮把技能组合从"能力匹配"升级为"动作-鲁棒性双证书"，但仍默认技能库是**封闭、可信、单一版本**的。本轮借「开源软件」的供应链视角，直面开放具身智能的真实形态：技能由异构贡献者提交、多版本共存、多 fork 分化、彼此依赖，证书会随版本漂移而失效。核心矛盾：**H22**：开源式复用缺少**行为语义**上的版本契约，接口/API 兼容不等于动作空间兼容；**H23**：可复现构建与签名只能证明"产物没变、来源可追"，不能证明"换一个身体仍然安全"，来源可信 ≠ 物理有效。

## 0. 直觉与动机

**灵感 1（技能 = 开源包，组合 = 依赖解析）**
直觉：一个技能应像 pip/npm 包一样携带 manifest：名称、版本、动作空间声明 `α_S`、鲁棒性谱 `ρ_S`、依赖 `deps`、适用 embodiment 约束、能力权限、来源哈希与证据附件。于是"两个技能能否组合"不必等到运行时试错，而可以在**安装期**由依赖解析判定。开源生态几十年的老问题——依赖地狱、钻石冲突、锁文件、供应链投毒——会原样迁移到具身技能上。

**灵感 2（行为语义版本 BSemVer：接口兼容 ≠ 行为兼容）**
直觉：开源 semver 只约束 API；技能的"API"却是动作空间占用与鲁棒性。一个 PATCH 完全可以不改任何函数签名，却悄悄缩小 `A_core` 或降低 `ρ`，使下游组合的联合证书 `J` 失效——这就是**行为供应链投毒**。因此版本号升级规则必须建立在**行为差异**上：PATCH 只允许 `α` 在 `δ_a` 内不动且 `ρ` 不降；MINOR 只允许动作覆盖扩张；一旦收缩核心动作集或降低鲁棒性，必须 bump 到 MAJOR 并强制下游复认证。

**灵感 3（依赖解析带动作约束：版本兼容但动作不相交）**
直觉：普通包管理器只需满足版本区间；技能还要同时满足**动作空间交集、embodiment 约束、能力权限**。于是出现一种新型钻石冲突：版本区间可满足，但选中的两个版本动作空间不相交。解析器要在三重可行域里找解，并输出**锁文件 + 联合证书**，让一次通过验证的组合可以被复现。

**灵感 4（E-SBOM：物料清单 + 出生证明 + 分区证据）**
直觉：开源供应链安全依赖 SBOM 与构建证明。具身技能同样需要绑定模型权重、训练与仿真数据、仿真器版本与参数、传感器标定、评测 embodiment 列表和审阅签名，用 Merkle 树做成 attestation。但必须加一条限定：**哈希只保证"是同一个东西"，不保证"在另一个身体上有效"**。所以 E-SBOM 必须按 embodiment 分区携带证据，而不是只给一份全局签名。

**灵感 5（车队 = 开源 CI 的 runner 池）**
直觉：开源项目靠 CI 在每个 PR 上回归。具身生态的 CI runner 就是真实/仿真机器人车队：新版本必须在 N 个 embodiment fork 上跑行为回归，通过统计门禁才允许 merge。这把"社区评审"变成"车队证据"，代价是机器人小时与 embodiment 多样性。若车队同质化，就会得到具身版的 "works on my machine" green build 幻觉。

## 1. 形式化定义（增量：定义 121–128）

**定义 121（具身技能清单 ESM）**
技能清单 `M_S = (name, ver, α_S, ρ_S, C_S, deps, E_S, R_S, h_S, sig)`：
- `α_S, ρ_S` 为第 54 轮的动作剖面与鲁棒性谱；
- `C_S ⊆ Emb` 为声明适用的 embodiment 集合；
- `deps = {(name, range)}` 为依赖及版本区间；
- `E_S` 为证据摘要（见定义 124）；
- `R_S ⊆ 𝔄` 为允许调用的动作/能力集合；
- `h_S` 为产物 Merkle 根，`sig` 为贡献者与审阅者签名。

**定义 122（行为差异与行为语义版本）**
`Δ_b(S@v, S@v') = (Δα, Δρ, ΔA_core, ΔR)`，其中 `Δα = dist(α^{v'}, α^{v})`、`Δρ` 为逐维差、`ΔA_core = A_core(v) \ A_core(v')`、`ΔR` 为权限对称差。升级规则：

```
patch:  A_core(v') = A_core(v) ∧ ρ(v') ⪰ ρ(v) ∧ Δα ≤ δ_a ∧ ΔR = ∅
minor:  A_core(v') ⊇ A_core(v) ∧ ρ(v') ⪰ ρ(v) ∧ ΔR = ∅   （允许覆盖扩张）
major:  其余（收缩 A_core、ρ 任一维下降、动作语义/权限变更）
```

其中 `⪰` 为逐维不小于。Bump 规则把版本号从"字符串约定"变成**可判定的行为契约**：`major` 必须触发所有下游依赖者的证书复验。

**定义 123（具身依赖图与解析）**
具身依赖图 `G_dep = (P, D)`，`P` 为候选包版本集合，`D` 为依赖边。解析 `r : P → Versions` 可行当且仅当：

```
∀ (p,p') ∈ deps:  r(p') ∈ range(p,p')
∀ S_i,S_j ∈ composition_closure(r):  compat(S_i,S_j) ≥ θ_a
⋂_{S ∈ r} C_S ≠ ∅
ρ_comp(d) ≥ ρ_min  ∀ d
R_comp ⊆ R_root（定义 126 的安全继承）
```

输出锁文件 `L = (r, J, {att_S})`；不可行时输出**冲突核** `K_conflict`（导致冲突的最小包/约束子集），供社区定位。

**定义 124（E-SBOM 来源证明）**
`att(S) = Sign_{sk}( Merkle(h_W, h_D, h_Sim, h_Cal, {h(ev_e)}_{e∈C_S}) )`，其中 `h_W/h_D/h_Sim/h_Cal` 分别为权重、数据、仿真器配置、标定哈希；`ev : C_S → Evidence` 是**按 embodiment 分区**的证据映射。验证要求：签名有效、Merkle 根一致、且部署 embodiment `e` 必须落在 `dom(ev)` 内，否则证明"来源可信"但**不授予部署许可**。

**定义 125（Fork 与证书迁移）**
fork 映射 `φ : Emb → Emb'` 诱导动作映射 `φ_* : A → A'`。第 54 轮联合证书 `J` 可迁移当且仅当：

```
φ_*(A_core) ⊆ A' ∧ ρ'_{φ(d)} ≥ ρ_min ∀d ∧ drift(φ, A_core) ≤ δ_a
```

否则必须**复认证**。迁移证书带 TTL：`J' = (φ_*(J), drift, ttl)`，过期自动失效，防止 fork 漂移无限累积。

**定义 126（能力权限与安全 Copyleft）**
每个技能声明权限集 `R_S ⊆ 𝔄`。组合时 `R_comp = ⋃ R_child ⊆ R_parent`；此外安全约束继承（安全 copyleft）：若 `S` 依赖安全认证技能 `S_safe`，则 `S` 必须继承 `S_safe` 的安全约束集，不能用"重写实现"规避。许可兼容谓词记为 `license_compat(S_i,S_j) ∈ {ok, conflict}`。

**定义 127（开放技能 CI 证据与合并门禁）**
车队证据 `E_CI = {(e_i, n_i, k_i)}`，`n_i` 为第 `i` 个 embodiment 层测试次数、`k_i` 通过次数。合并门禁：

```
∀ stratum i:  WilsonLCB(k_i, n_i) ≥ 1 - ε
∀ stratum i:  regress(candidate, i) ≤ Δ_reg
∃ holdout stratum:  LCB ≥ 1 - ε 且不在候选训练/调参可见集
证书迁移条件（定义 125）全部成立
```

只有同时满足才 `merge`，否则 `reject` 并返回失败分层。

**定义 128（开放供应链下的部署可靠性下界）**
在清单可信（A29）、attestation 不可伪造（A30）、解析有界完备（A31）、CI 分层抽样（A32）下：

```
P_success ≥ 1 - [ Σ_d(1-ρ_min(d)) + β_res + β_drift + β_ci + β_att ]
```

其中 `β_res` 为解析不完备/动作兼容误判的概率，`β_drift` 为 fork 证书漂移超预算的概率，`β_ci` 为统计门禁误差，`β_att` 为来源证明失效概率。**关键**：`β_att` 与 `β_drift` 是封闭生态中不存在的两项，开放性的代价必须显式记账。

## 2. 关键算法 伪代码

### IP-121 BVD（Behavior Version Diff）

```python
def behavior_diff(S_old, S_new, delta_a, sampler):
    a_old = sampler.estimate_profile(S_old)      # 分层采样，带置信区间
    a_new = sampler.estimate_profile(S_new)
    d_alpha = max_abs(a_old, a_new)
    shrink = S_old.A_core - S_new.A_core
    rho_drop = {d: S_old.rho[d] - S_new.rho[d]
                for d in S_old.rho if S_new.rho[d] < S_old.rho[d] - EPS}
    rights_change = S_new.R ^ S_old.R
    if shrink or rho_drop or rights_change:
        return ('major', shrink, rho_drop, rights_change)
    if a_new.covers(a_old) and d_alpha > delta_a:
        return ('minor', d_alpha)
    if d_alpha <= delta_a:
        return ('patch', d_alpha)
    return ('invalid', 'non-monotone action change')   # 必须拆成新包名
```

### IP-122 EDR（Embodied Dependency Resolution）

```python
def resolve(P, dep_constraints, theta_a, rho_min, budget):
    domains = {p: versions_satisfying(p, dep_constraints) for p in P}
    best = None
    def dfs(assign):
        nonlocal best
        if len(assign) == len(P):
            if action_compat_all(assign, theta_a) and rights_ok(assign) \
               and embodiment_ok(assign):
                J = build_joint_cert(assign, rho_min)
                if J.ok:
                    best = (dict(assign), J)
                    return True
            return False
        p = most_constrained(domains, assign)
        for v in order_by_evidence(domains[p]):
            assign[p] = v
            if propagate(p, v, domains) and dfs(assign):
                return True
            del assign[p]
        return False
    if dfs({}):
        return ('ok', Lockfile(best[0], best[1], attestations(best[0])))
    return ('conflict', minimal_conflict_core(P, domains))
```

### IP-123 ESBOM（Provenance Attestation）

```python
def build_attestation(S, embodiment_set, signer):
    ev = {e: run_evidence_suite(S, e) for e in embodiment_set}
    leaves = [h(S.weights), h(S.data), h(S.sim_cfg), h(S.calib)] \
             + [h(ev[e]) for e in sorted(ev)]
    root = merkle_root(leaves)
    return sign(root, signer.sk), ev

def verify_attestation(S, att, deployed_embodiment):
    if not verify_sig(att.root, att.sig) or att.root != recompute_root(S):
        return ('reject', 'provenance_mismatch')
    if deployed_embodiment not in att.ev:
        return ('reject', 'no_evidence_for_embodiment')
    return ('ok', att.ev[deployed_embodiment])
```

### IP-124 OSCF（Open Skill Continuous Integration）

```python
def merge_gate(candidate, strata, holdout, eps, regress_budget):
    ev = fleet_test(candidate, strata | {holdout})
    for e, (n, k) in ev.items():
        if wilson_lcb(k, n) < 1 - eps:
            return ('reject', 'stratum_under_power', e)
        if e != holdout and regress(candidate, e) > regress_budget:
            return ('reject', 'behavioral_regression', e)
    if wilson_lcb(*ev[holdout]) < 1 - eps:
        return ('reject', 'holdout_fail', holdout)
    return ('accept', ev)
```

### IP-125 FCT（Fork Certificate Transfer）

```python
def transfer_certificate(J, phi, delta_a, rho_min, ttl):
    A_core_prime = phi_star(J.A_cert.A_core, phi)
    drift = max_action_drift(phi, J.A_cert.A_core)
    if drift > delta_a or not subset(A_core_prime, phi.alpha):
        return ('recertify', 'action_domain_broken', drift)
    rho_prime = phi_star_spectrum(J.rho, phi) - coupling_penalty(phi)
    if any(rho_prime[d] < rho_min for d in rho_prime):
        return ('recertify', 'robustness_broken', rho_prime)
    return ('ok', JointCertFork(phi, J, drift, rho_prime, expiry=now + ttl))
```

### IP-126 CRG（Capability Rights Guard）

```python
def rights_check(child, parent):
    if not child.R <= parent.R:
        return ('conflict', 'permission_escalation', child.R - parent.R)
    if not license_compat(child.license, parent.license):
        return ('conflict', 'license_incompatible')
    for s in child.safety_inherited:
        if s not in parent.safety_inherited:
            return ('conflict', 'safety_copyleft_violation', s)
    return ('ok',)
```

### IP-127 SCD（Supply-chain Drift Sentinel）

```python
def drift_sentinel(deployed, manifest, probe, delta_a, eps):
    obs = probe.profile(deployed)          # 运行时独立探针，不只信 manifest
    if max_abs(obs.alpha, manifest.alpha) > delta_a:
        return quarantine(deployed, 'behavioral_drift')
    if any(obs.rho[d] < manifest.rho[d] - eps for d in manifest.rho):
        return quarantine(deployed, 'robustness_drift')
    return ('ok',)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| BVD | O(|𝒜|·T_probe + |deps|) | O(|𝒜|) | 分层采样覆盖、δ_a 校准 |
| EDR | 最坏 O(exp(|P|))，剪枝后近线性 | O(|P|·|V|) | 冲突核最小性（有界域） |
| ESBOM | O(|C_S|·T_ev + |M| log|M|) | O(|C_S|·|E|) | 哈希抗碰撞、分区证据完备 |
| OSCF | O(|Strata|·N_test) | O(|Strata|) | Wilson 下界、holdout 隔离 |
| FCT | O(|A_core| + |𝔇_ρ|) | O(|A_core|) | φ 动作包含、TTL 强制 |
| SCD | O(|𝒜|)/次 | O(|𝒜|) | 探针不可被技能观测或规避 |

**正确性定理（Open-Supply-Chain Deployment Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** 清单 `M_S` 在其声明的 `C_S` 上经校准可信；**(A30)** attestation 签名不可伪造且 Merkle 绑定无碰撞；**(A31)** 解析域有界、动作兼容判定 sound；**(A32)** CI 车队按部署分布分层抽样且 holdout 不泄漏。则对锁文件 `L` 通过门禁后部署到同分布 embodiment `e`，有定义 128 的下界。相较第 54 轮封闭假设，开放生态额外引入 `β_att + β_drift` 两项——**这正是"开源复用"必须支付、且不能藏在签名背后的代价**。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 行为版本契约不可判定/采样不足 | 高 | 分层主动采样 + 红队动作探索 + 近似判定显式标注置信 |
| 供应链投毒 / 抢注同名包 | 高 | 命名注册表 + 审阅 quorum + E-SBOM + SCD 运行时哨兵 |
| CI 车队同质化导致 green build 幻觉 | 高 | embodiment 分层配额 + 永久 holdout + 多样性审计 |
| Fork 漂移使证书"腐化" | 中 | 证书 TTL + 漂移触发复认证 + 迁移预算 |
| 安全 copyleft 导致生态分裂 | 中 | 能力/许可格 + 兼容性检查器 + 渐进继承 |
| 证据体积爆炸 | 中 | Merkle 剪枝 + 证据摘要 + 按需展开 |

## 6. 本轮最大风险

**一句话**：把技能组合前移到"开源包 + 行为版本 + 依赖解析 + 车队 CI"能系统化开放具身智能的复用，但**开源软件的可信假设在具身上并不成立**——签名与可复现只证明"来源与同一性"，不证明"跨 embodiment 的物理安全"；一旦社区把"CI 绿 + 哈希通过"误当成部署许可，行为版本契约就会被同质化车队与 fork 漂移系统性绕过，形成规模化的具身负迁移，故必须以 **embodiment 分层证据 + 行为版本门禁 + 证书 TTL/复认证** 为护栏，宁可拒绝合并，也不把"可复现"当成"可部署"。

# 第 55 轮产物 · 创新点清单 v32：OASIS（Open Embodied Skill supply-chain Integrity System）

> 承接第 54 轮产物 v31（GroundEdge-GenSim+++）。本轮把"封闭可信技能库"扩展为**开放具身技能生态**，新增七个子系统：
> - **ESM（Embodied Skill Manifest）**：技能的开源包清单；
> - **BVD（Behavior Version Diff）**：行为语义版本判定；
> - **EDR（Embodied Dependency Resolution）**：带动作空间约束的依赖解析；
> - **ESBOM（Embodied SBOM Attestation）**：按 embodiment 分区的来源证明；
> - **OSCF（Open Skill Continuous Integration）**：机器人车队 CI 合并门禁；
> - **FCT（Fork Certificate Transfer）**：fork 证书迁移与 TTL；
> - **SCD（Supply-chain Drift Sentinel）**：运行时行为漂移哨兵。
>
> IP 编号：IP-121~IP-127（共 7 个新增）；升级 IP-115/116/118/120 以纳入版本、来源与迁移语义。

## 2. 关键算法 伪代码

### IP-121 ESM / IP-122 BVD

```python
class Manifest:
    name: str; ver: SemVer
    alpha: Profile; rho: Spectrum
    embodiments: set[Emb]; deps: list[DepRange]
    rights: set[Action]; safety_inherited: set[SafetyId]
    merkle_root: bytes; sig: Signature; evidence: dict[Emb, Evidence]

def behavior_diff(S_old, S_new, delta_a, sampler):
    a_old, a_new = sampler.estimate(S_old), sampler.estimate(S_new)
    shrink = S_old.A_core - S_new.A_core
    rho_drop = {d for d in S_old.rho if S_new.rho[d] < S_old.rho[d] - EPS}
    rights_change = S_new.R ^ S_old.R
    if shrink or rho_drop or rights_change:
        return ('major', shrink, rho_drop, rights_change)
    if a_new.covers(a_old):
        return ('minor', max_abs(a_old, a_new))
    if max_abs(a_old, a_new) <= delta_a:
        return ('patch', max_abs(a_old, a_new))
    return ('invalid', 'non-monotone')

def bump(ver, kind):
    return {'major': ver.major+1 | 0.0.0,
            'minor': ver.major | ver.minor+1 | 0,
            'patch': ver.major | ver.minor | ver.patch+1}[kind]
```

### IP-123 EDR

```python
def resolve(P, constraints, theta_a, rho_min, budget):
    domains = {p: versions_satisfying(p, constraints) for p in P}
    def dfs(assign):
        if len(assign) == len(P):
            if not action_compat_all(assign, theta_a): return False
            if not embodiment_ok(assign): return False
            if not rights_ok(assign): return False
            J = build_joint_cert(assign, rho_min)
            return (assign, J) if J.ok else False
        p = most_constrained(domains, assign)
        for v in order_by_evidence(domains[p]):
            assign[p] = v
            if propagate(p, v, domains) and (res := dfs(assign)):
                return res
            del assign[p]
        return False
    res = dfs({})
    if res: return ('ok', Lockfile(res[0], res[1], attest_all(res[0])))
    return ('conflict', minimal_conflict_core(P, domains))
```

### IP-124 ESBOM

```python
def attest(S, embodiments, signer):
    ev = {e: run_evidence_suite(S, e) for e in embodiments}
    root = merkle_root([h(S.weights), h(S.data), h(S.sim_cfg), h(S.calib)]
                       + [h(ev[e]) for e in sorted(ev)])
    return Attestation(root=root, sig=sign(root, signer.sk), ev=ev)

def verify_attestation(S, att, e_deploy):
    if not verify_sig(att.root, att.sig) or att.root != recompute_root(S):
        return ('reject', 'provenance_mismatch')
    if e_deploy not in att.ev:
        return ('reject', 'no_evidence_for_embodiment')   # 来源可信但不可部署
    return ('ok', att.ev[e_deploy])
```

### IP-125 OSCF

```python
def merge_gate(candidate, strata, holdout, eps, regress_budget):
    ev = fleet_test(candidate, strata | {holdout})
    for e, (n, k) in ev.items():
        if wilson_lcb(k, n) < 1 - eps:
            return ('reject', 'under_power', e)
        if e != holdout and regress(candidate, e) > regress_budget:
            return ('reject', 'behavioral_regression', e)
    if wilson_lcb(*ev[holdout]) < 1 - eps:
        return ('reject', 'holdout_fail', holdout)
    return ('accept', ev, lockfile_with(candidate, ev))
```

### IP-126 FCT

```python
def transfer(J, phi, delta_a, rho_min, ttl):
    core_p = phi_star(J.A_cert.A_core, phi)
    drift = max_action_drift(phi, J.A_cert.A_core)
    if drift > delta_a or not subset(core_p, phi.alpha):
        return ('recertify', 'action_domain_broken', drift)
    rho_p = phi_star_spectrum(J.rho, phi) - coupling_penalty(phi)
    if any(rho_p[d] < rho_min for d in rho_p):
        return ('recertify', 'robustness_broken', rho_p)
    return ('ok', ForkCert(phi, J, drift, rho_p, expiry=now + ttl))
```

### IP-127 SCD

```python
def sentinel(deployed, manifest, probe, delta_a, eps):
    obs = probe.profile(deployed)
    if max_abs(obs.alpha, manifest.alpha) > delta_a:
        return quarantine(deployed, 'behavioral_drift')
    if any(obs.rho[d] < manifest.rho[d] - eps for d in manifest.rho):
        return quarantine(deployed, 'robustness_drift')
    return ('ok',)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| ESM/BVD | O(|𝒜|·T_probe + |deps|) | O(|𝒜|) | 分层采样置信标注、行为序单调 |
| EDR | 最坏 O(exp(|P|))，剪枝近线性 | O(|P|·|V|) | 有界域下冲突核完备 |
| ESBOM | O(|C_S|·T_ev + |M| log|M|) | O(|C_S|·|E|) | 哈希抗碰撞、分区证据覆盖 `C_S` |
| OSCF | O(|Strata|·N_test) | O(|Strata|) | Wilson 下界 sound、holdout 隔离 |
| FCT | O(|A_core| + |𝔇_ρ|) | O(|A_core|) | φ 动作包含、TTL 到期失效 |
| SCD | O(|𝒜|)/次 | O(|𝒜|) | 独立探针、不可被技能规避 |

**正确性定理（Open-Supply-Chain Deployment Soundness）**
假设第 54 轮 (A26)–(A28) 成立，并新增 **(A29)** 清单在 `C_S` 上校准可信；**(A30)** attestation 不可伪造且 Merkle 绑定无碰撞；**(A31)** 解析域有界、动作兼容判定 sound；**(A32)** CI 车队按部署分布分层抽样、holdout 不泄漏。则对通过门禁的锁文件 `L` 部署到同分布 embodiment：

```
P_success ≥ 1 - [ Σ_d(1-ρ_min(d)) + β_res + β_drift + β_ci + β_att ]
```

与第 54 轮相比，开放生态新增 `β_att`（来源证明失效/越界部署）与 `β_drift`（fork 证书漂移）两项。**结论：开放复用的收益必须大于这两项新增风险，否则应退回封闭验证。**

## 6. 本轮最大风险

**一句话**：OASIS 把技能复用前移为"清单 + 行为版本 + 依赖解析 + 分区来源证明 + 车队 CI"，能显著提升开放生态的可组合性，但其可信性仍**建立在开源软件式假设之上**——签名、哈希与 CI 绿只覆盖"来源、同一性与车队内分布"，不覆盖"未声明 embodiment 与 fork 漂移下的物理安全"；一旦生态把门禁当作安全证书，就会以规模化、可复现的方式把负迁移部署到真实身体上，故必须以 **embodiment 分区证据 + 永久 holdout + 证书 TTL/复认证 + 运行时 SCD** 为不可省护栏。
