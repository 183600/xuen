# 第 5 轮（灵感循环第 1 轮；本轮灵感：「视觉定位」×「双臂协作」）

> **基线**：第 4 轮 InstructGauge-WR（IP-328–333；定义 448–467；引理 59–62；实验 E457–E467）。InstructGauge → ToolGauge → LeanGauge → MODGAUGE 的严格退化链继续继承不变。
> 本轮纪律：**增量升级 + 严格退化**。视觉定位沿「世界锚与可定位性」轴增强 WR，双臂协作沿「相对位姿与闭链」轴增强 WR；二者都是可选增强，任一环节不可用都必须能一键退回单臂 WR，再退回 InstructGauge v3。

## 0. 直觉与动机

**灵感 1（视觉定位：从「位姿真值」改为「可定位性证书」）**
直觉：传统 VIO/SLAM 输出一个位姿和一个协方差，工程上很容易把它当成近似真值。但在对称零件、重复纹理、弱纹理和动态遮挡下，视觉重投影优化在最弱方向上是病态的：位姿会**高置信度地错**。对双臂插装来说，安全需要的不是平均误差小，而是**最弱方向也有界**。所以正确的接口不是 `T_map←cam`，而是 `LocCert = (T̂, Σ, λ_min, ρ_inlier, A)`：只有 λ_min 足够大、内点率足够高、且不存在多峰别名解 `A` 时，视觉位姿才被允许进入安全闭环；否则退回局部里程计并把块长压到 1。

**灵感 2（双臂协作：相对位姿是主变量，共模误差既会抵消也会藏起来）**
直觉：交接、双手装配、协同搬运的硬约束几乎都写在**相对位姿与闭链**上，而不是两臂各自的世界绝对位姿。若两臂锚在同一张地图，共同的定位漂移 G 在 `T_{B_L←B_R}` 中精确抵消——这既是双臂的优势，也是陷阱：相对位姿证书对共模错误**完全失明**。对「插进固定夹具、对准世界参考」的任务，共模误差恰恰致命。因此必须把误差显式分解为**共模 G + 差分 D**，并为世界参考任务强制一条独立的世界锚边（夹具/标定板/固定相机）做审计。

**灵感 3（耦合：遮挡恰好发生在最需要定位的交接时刻）**
直觉：双臂协作时一臂经常挡住另一臂的相机；而交接/首次接触又是最接近不可逆、最需要精度的一刻。若此时视觉定位掉线，系统还用一个长块开环执行，就会同时出现「看不到、停不下、验不了」。解法不是提高相机帧率，而是结构性冗余：**遮挡感知的锚切换**（换可见相机/换参考系）、**闭链可采纳集**（两臂动作联合校验）、**交接屏障**（跨交接强制 K=1 + 双回执 + 相对位姿证书）。

## 1. 研究问题（本轮要回答什么）

- **Q1（不可信定位下如何安全用）**：当视觉定位可能「高置信度错误」时，什么样的证书能保证进入闭环的位姿至少不会把最弱方向的误差带进接触？
- **Q2（相对位姿能保证什么）**：双臂相对位姿证书能保证差分误差有界，但无法约束共模误差；如何用锚图与世界锚审计把「相对正确、整体错误」这一失效模式显式暴露？
- **Q3（遮挡-交接耦合）**：当遮挡掉线恰好落在交接窗口，能否用锚切换 + 闭链约束 + 交接屏障把风险压回单步，而不是靠更长块硬扛？

## 2. 三条设计原则（正式化见产物区定义 468–482）

**P1 证书化定位（Certified, not trusted）**
视觉位姿只有在 `LCert` 有效时才可作为世界锚；证书包含可定位性 `λ_min`、内点率、别名解计数与协方差迹上界。证书失效时，不得用「协方差看起来不大」来蒙混——退化到局部里程计/单臂相对定位，并把 K 压到 1。形式化方向：`LCert(·) = valid ⇒ λ_min ≥ λ0 ∧ |A| = 1`。

**P2 共模/差分分解 + 世界锚审计（Gauge Split & Audit）**
把双臂世界位姿写成 `T^{W←B_i} = G · T̂^{W←B_i}`，相对位姿与 G 无关；因此相对位姿证书只对差分误差负责。世界参考任务额外要求锚图中存在含固定夹具（F）的环，审计共模残差 `r_cycle^{F}`。没有世界锚边时，系统只能声明「相对安全」，不能声明「世界安全」。

**P3 遮挡感知锚切换 + 交接屏障（Occlusion-Aware Handover Barrier）**
在每个决策边界估计各相机的可见性/可定位性，切换到 `max min λ` 的可见锚；若最优仍低于阈值，则强制 K=1 并降速。跨交接/首次接触设置屏障：必须同时满足 `RPC.valid`、两臂 `LCert`、最小间隙与双回执，且 K=1。该原则把「语义-时间放大」压回「单步可验证」。

## 3. 与基线的接口（如何退化）

- 视觉定位不可用 / `LCert` 失效 ⇒ 关闭世界锚，改用关节编码器 + 轮式/IMU 里程计（相对定位），等价于单臂 InstructGauge-WR 的 TF 路径；
- 仅单臂可用 ⇒ 退化为单臂 WR（无闭链、无交接屏障）；
- 锚图无世界环 / 夹具不可见 ⇒ 只声明相对安全，世界参考任务拒绝执行或转人工；
- 锚图审计超时 ⇒ 本块 K=1；闭链不可采纳 ⇒ 拆成两次单臂可采纳动作；
- 所有增强失效 ⇒ InstructGauge v3 ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE。

## 4. 预期贡献

1. 一个**可定位性证书**口径，把视觉定位从「信任协方差」升级为「显式拒绝病态方向」，并给出 λ_min → 误差界的可检查链；
2. 一个**共模/差分分解与锚图审计**框架，把双臂「相对完美、整体偏移」这一最隐蔽的失效模式变成可检测的环残差；
3. 一个**遮挡感知锚切换 + 交接屏障**执行器，把最危险的交接窗口强制压回 K=1、双回执、双证书；
4. 一条完整可证伪路径：E468–E483 覆盖可定位性校准、共模抵消、锚审计、差分放大、遮挡切换、别名假置信、闭链误差、sim→real、消融、退化等价与 50Hz 时序。

## 5. 本轮最大风险

**一句话**：共模抵消会把「整体锚错」伪装成「相对完美」——两臂彼此一致、相对位姿证书全绿，却一起对准了错误的世界参考；若夹具/标定板本身也由同一视觉链路定位，世界锚审计会与错误共模相关，残余风险集中在「共享锚的集体错觉」，而不是单臂定位精度。

## 2. 形式化定义（要点）

**定义 468（视觉定位测量与可定位性）** 设时刻 `t` 的视觉定位解为
```
T̂_t = argmin_{T∈SE(3)} Σ_k ρ( ||π(T^{-1} p_k) - u_k||²_{Ω_k} )
Λ_t  = J^T Ω J,          λ_t = λ_min(Λ_t)
ρ_t  = n_inlier / n,     A_t = { T : cost(T) ≤ cost(T̂_t) + τ_amb }
```
定义测量 `LocEst_t = (T̂_t, Σ_t, λ_t, ρ_t, A_t)`。`λ_t` 刻画最弱可观测方向；`A_t` 刻画别名多解。

**定义 469（可定位性证书）**
```
LCert(LocEst) = 1  ⇔  λ ≥ λ0 ∧ ρ ≥ ρ0 ∧ |A| = 1 ∧ tr(Σ) ≤ σ0²
valid_pose(LocEst) = T̂  若 LCert=1；否则 ⊥
```
证书是**门**而不是精度分数：它只回答「该位姿是否允许进入安全闭环」。

**定义 470（共模/差分分解）** 存在 `G ∈ SE(3)` 使
```
T^{W←B_L} = G · T̂^{W←B_L},      T^{W←B_R} = G · T̂^{W←B_R}
T^{B_L←B_R} = (T̂^{W←B_L})^{-1} · T̂^{W←B_R}
```
最后一个等号说明相对位姿与 `G` 无关。记 `D_L = T̂^{-1}T`、`D_R = T̂^{-1}T`，则相对误差只依赖 `D_L^{-1}D_R`。

**定义 471（相对协方差与共模投影）** 令 `ξ = (ξ_L, ξ_R) ~ N(0, Σ_pair)`，其中 `Σ_pair` 的交叉项来自共享地图/共享特征。取
```
ξ_rel = J ξ,     J = [ -Ad_{T^{B_R←B_L}},  I ]
Σ_rel = J Σ_pair J^T
```
共模方向 `ξ_L = ξ_R` 落在 `J` 的零空间，故 `Σ_rel` 对共模误差不敏感——这正是定义 475 审计要补的洞。

**定义 472（相对位姿证书 RPC）**
```
RPC = (T̂_rel, Σ_rel, κ, valid)
valid ⇔ sup_{δ ∈ E_κ(Σ_rel)} c_task(T̂_rel · Exp(δ)) ≤ 0
```
其中 `c_task` 为任务符号间隙（≤0 表示可行），`E_κ(Σ)` 为 κ-σ 椭球。等价的可检查形式：
```
d_SE3(T̂_rel, ∂A_task) ≥ κ · sqrt(λ_max(Σ_rel))
```

**定义 473（双臂闭链可采纳集）**
```
BAdm(s) = { (a_L, a_R) :
    a_L ∈ KinematicAdmissibleSet_L(s)  ∧
    a_R ∈ KinematicAdmissibleSet_R(s)  ∧
    e_chain(a_L, a_R, s) ≤ ε_chain     ∧
    clearance(a_L, a_R) ≥ d_min        ∧
    ||w_int|| ≤ w_max }
```
`e_chain = ||log( T̂_rel^{-1} · FK_L(a_L,s)^{-1} · FK_R(a_R,s) · T^{ee_L←ee_R} )||`。

**定义 474（锚图）** `AG = (V,E,{(T̂_e,Σ_e)}_{e∈E})`，`V = {W, F, B_L, B_R}`，边为带协方差的观测或运动学变换。定义
```
world_anchored(AG) = 1  ⇔  F 与 W 连通 且 环空间含 F 的独立环秩 ≥ 1
```

**定义 475（锚图共模审计）** 对含 `F` 的环 `γ = (e_1,…,e_k)`，
```
r_γ = || log( Π_{i=1..k} T_e_i^{s_i} ) ||_{Σ_γ} ,   s_i ∈ {+1,-1}
CMAudit(AG) = 1  ⇔  ∀γ ∋ F :  r_γ ≤ τ_anchor
```
关键条件：`F` 的观测必须**独立于共享视觉地图**（接触探针、激光跟踪、独立标定板），否则审计与共模误差相关，见风险节。

**定义 476（遮挡感知定位调度）** 设相机 `i` 的可见性 `v_i(t)∈{0,1}`、可定位性 `λ_i(t)`。每个决策边界选
```
S*(t) = argmax_{S ⊆ Sensors, |S| ≤ 1 per arm}  min_{i∈S} v_i(t)·λ_i(t)
```
若 `min_{i∈S*} λ_i < λ0`，输出 `(K=1, v ≤ v_safe, request_view)`；否则允许 `K = K_max(λ_S*)`。

**定义 477（交接屏障）**
```
HB(s) = RPC.valid ∧ LCert_L.valid ∧ LCert_R.valid
        ∧ clearance ≥ d_min ∧ dual_receipt_ready
```
`HB(s)=1` 时强制 `K_L=K_R=1`，且每一步都要求两臂 `joint_pre` 同时成立。

**定义 478（双臂 CVC 证书）**
```
BCert(C) = ( id, K_L, K_R, RPC, e_chain_max, clearance_min,
             r_F, receipts_L, receipts_R, anchor_valid )
valid ⇔ RPC.valid ∧ e_chain_max ≤ ε_chain ∧ clearance_min ≥ d_min
        ∧ anchor_valid ∧ receipts 完整
```

**定义 479（安全可执行块）**
```
SafeChunk(C,s) = PrefixClosed(C) ∧ BCert(C).valid
                 ∧ ( HB(s) ⇒ K_L=K_R=1 )
                 ∧ ( ¬HB(s) ⇒ K ≤ K_max(λ_min) )
K_max(λ) = clip( floor(c · λ/λ0), 1, K0 )
```
可定位性越低，允许的块越短；这是「证据陈旧窗口 ≤ 可定位性预算」的直接实现。

**定义 480（接触误差预算）**
```
e_contact ≤ e_loc_diff + e_kin + e_ctrl + [world task] · e_anchor
```
`e_loc_diff = κ_c · sqrt(λ_max(Σ_rel))`，`κ_c = 1 + ||p_contact||/ρ` 为接触点杠杆；`e_anchor` 为共模审计残差上界。世界参考任务必须计入 `e_anchor`，纯相对任务可置零。

**定义 481（退化算子）** 记 `D_V` 关闭视觉世界锚、`D_B` 关闭双臂闭链、`D_A` 关闭锚审计。则
```
D_V(VisLocGauge-DA) = 单臂 InstructGauge-WR（相对定位路径）
D_B(VisLocGauge-DA) = 单臂 InstructGauge-WR（无闭链）
D_V ∘ D_B ∘ D_A(VisLocGauge-DA) = InstructGauge-WR
```

**定义 482（主闭环）** `VisLocGauge-DA = M ∘ HB ∘ BAdm ∘ AnchorAudit ∘ RPC ∘ LocCert ∘ WRC-ROS-7C`，其中 `M` 为模态选择器（根据可用组件选择退化路径），见图与伪代码。

## 3. 关键算法骨架

```python
# IP-334 LocCert-Perception
class LocCertifier:
    def __init__(self, lambda0, rho0, sigma0_sq, tau_amb):
        self.lambda0, self.rho0 = lambda0, rho0
        self.sigma0_sq, self.tau_amb = sigma0_sq, tau_amb

    def certify(self, loc_est):
        """loc_est: T_hat, Sigma, Lambda, rho, cost_fn, hypotheses"""
        lam = smallest_eigenvalue(loc_est.Lambda)
        amb = [T for T in loc_est.hypotheses
               if loc_est.cost(T) <= loc_est.cost(loc_est.T_hat) + self.tau_amb]
        ok = (lam >= self.lambda0 and
              loc_est.rho >= self.rho0 and
              len(amb) == 1 and
              trace(loc_est.Sigma) <= self.sigma0_sq)
        return LocCert(valid=ok, lam=lam, ambiguity=amb,
                       T=loc_est.T_hat if ok else None)

# IP-335 Gauge-Split
def gauge_split(loc_L, loc_R, Sigma_pair):
    """把两臂世界位姿拆成 G 与相对位姿，并传播相对协方差"""
    T_rel = inv(loc_L.T) @ loc_R.T
    J = np.vstack([-adjoint(T_rel), np.eye(6)])
    Sigma_rel = J @ Sigma_pair @ J.T
    return T_rel, Sigma_rel

def relative_pose_cert(T_rel, Sigma_rel, task_region, kappa):
    margin = signed_distance_se3(T_rel, task_region)
    radius = kappa * np.sqrt(np.max(np.linalg.eigvalsh(Sigma_rel)))
    return RPC(T=T_rel, Sigma=Sigma_rel, kappa=kappa, valid=(margin >= radius))

# IP-336 AnchorGraph-Audit
def anchor_audit(AG, tau_anchor):
    cycles = cycle_basis(AG.edges)
    world_cycles = [c for c in cycles if AG.F in vertices(c)]
    if not world_cycles:
        return CmAudit(world_anchored=False, residual=inf)
    residuals = [hadamard_residual(AG, c) for c in world_cycles]
    return CmAudit(world_anchored=True,
                   residual=max(residuals),
                   valid=max(residuals) <= tau_anchor)

# IP-337 DualArm-ClosedChain
def bimanual_admissible_pair(kloop, s, a_L, a_R):
    if not (kloop.admissible(a_L, side='L', s=s) and
            kloop.admissible(a_R, side='R', s=s)):
        return False
    chain = inv(est_rel(s)) @ inv(fk('L', a_L, s)) @ fk('R', a_R, s) @ T_ee
    if norm(log_se3(chain)) > EPS_CHAIN:
        return False
    if clearance(fk('L', a_L, s), fk('R', a_R, s)) < D_MIN:
        return False
    if norm(internal_wrench(a_L, a_R, s)) > W_MAX:
        return False
    return True

# IP-338 Occlusion-Aware-Anchoring
def occlusion_schedule(sensors, t, lambda0, K0):
    visible = [i for i in sensors if i.visible(t)]
    if not visible:
        return Schedule(K=1, speed='safe', request_view=True)
    best = max(visible, key=lambda i: i.localizability(t))
    if best.localizability(t) < lambda0:
        return Schedule(K=1, speed='safe', request_view=True)
    K = int(np.clip(np.floor(C_GAIN * best.localizability(t) / lambda0), 1, K0))
    return Schedule(anchor=best, K=K, speed='normal')

# IP-339 Handover-Barrier
def handover_barrier(rpc, lcert_L, lcert_R, clearance, receipts):
    return (rpc.valid and lcert_L.valid and lcert_R.valid and
            clearance >= D_MIN and receipts.dual_ready)

# IP-340 VisLocGauge-DA 主闭环
def vislocgauge_da(M, s, task):
    # 1) 视觉定位 + 证书
    loc_L, loc_R = M.vloc.locate(s)
    cert_L, cert_R = M.loccert.certify(loc_L), M.loccert.certify(loc_R)

    # 2) 任一位姿不可信 ⇒ 关闭世界锚，退化到单臂 WR 相对路径
    if not (cert_L.valid and cert_R.valid):
        return instructgauge_wr(M, s, task)

    # 3) 共模/差分分解与相对位姿证书
    T_rel, Sigma_rel = gauge_split(loc_L, loc_R, M.vloc.pair_covariance())
    rpc = relative_pose_cert(T_rel, Sigma_rel, task.region, M.kappa)

    # 4) 锚图审计：世界参考任务必须有独立世界锚
    audit = anchor_audit(M.ag, M.tau_anchor)
    if task.world_referenced and not (audit.world_anchored and audit.valid):
        return Refuse("world-anchor-unverified")

    # 5) 闭链可采纳规划
    C = M.iac.plan_bimanual(task.iota, M.budget(s), M.drift_bound(s))
    if not all(bimanual_admissible_pair(M.kloop, s, aL, aR)
               for aL, aR in C.pairs):
        C = M.iac.split_single_arm(task.iota)   # 退化为两次单臂动作

    # 6) 交接屏障 + 遮挡感知块长
    sched = occlusion_schedule(M.sensors, M.env.time(), M.lambda0, M.K0)
    HB = handover_barrier(rpc, cert_L, cert_R, C.clearance_min, M.receipts)
    if HB or sched.K == 1:
        C = C.truncate_to(1)
        K_eff = 1
    else:
        K_eff = min(C.K, sched.K)

    # 7) 执行：逐步联合前置 + 实时证书复核；任一失败即截断到最后安全前缀
    executed = 0
    for t in range(K_eff):
        if not (M.cvc.joint_pre(C.pair[t].L) and M.cvc.joint_pre(C.pair[t].R)):
            break
        if HB and not still_grounded(task.iota, M.env):
            break
        M.env.apply(C.pair[t])
        executed = t + 1

    # 8) 生成 BCert 并发布；主张绑定
    bcert = make_bcert(C, executed, rpc, audit, M.receipts)
    M.ros_cvc.publish_bcert(bcert)
    claims = bind_claims(C, task.iota, M.receipts, bcert)
    return C[:executed], bcert, claims
```

## 4. 推导

**引理 63（共模不变性）** 对任意 `G ∈ SE(3)`，若两臂世界位姿同时左乘 `G`，则 `T^{B_L←B_R}` 严格不变；因此 `RPC` 对 `G` 不敏感。证明：`(G T̂_L)^{-1}(G T̂_R) = T̂_L^{-1} G^{-1} G T̂_R = T̂_L^{-1} T̂_R`。

**引理 64（共模不可观测性）** 仅含两臂相对位姿观测的证书，对共模误差 `G` 的检验功效为 0：存在任意大的 `G` 使所有相对位姿证书保持 `valid`。证明：由引理 63，`RPC` 的输入在 `G` 作用下不变，故其输出不变；取 `G` 为任意大平移即可。

**引理 65（差分误差的接触点放大）** 设相对位姿误差为 `ξ=(ω,v)∈se(3)`，接触点相对基座坐标 `p_c`，则接触点误差满足
```
||e_c|| ≤ ||v|| + ||ω||·||p_c|| ≤ (1 + ||p_c||/ρ) ||ξ||_ρ = κ_c ||ξ||_ρ
```
其中 `ρ` 为旋转误差的归一化长度。证明：刚体变换作用于点的误差为 `e_c = v + ω × p_c`，取范数并用三角不等式与 `||ω×p_c|| ≤ ||ω|| ||p_c||` 即得。

**引理 66（可定位性门的保守可靠性）** 若 `λ_min(Λ) < λ0`，则存在单位方向 `δ` 使重投影代价在 `δ` 上的二阶增量 `< λ0 ||δ||²`；当该增量低于测量噪声尺度时，任何仅基于该测量的证书都无法保证任务容差。证明：沿最小特征向量方向扰动，二次型取 `λ_min`；代价变化被噪声淹没时，位姿在 `δ` 方向不可辨识。

**引理 67（世界锚的可观测性）** 若锚图中存在一条观测 `T^{W←F}` 且该观测独立于共享视觉地图，则共模 `G` 在含 `F` 的环残差中可观测：
```
r_γ ≥ ||log G||_{Σ_γ} - ||log N_γ||_{Σ_γ}
```
其中 `N_γ` 为独立观测与运动学噪声的复合。证明：环闭合要求 `G` 与独立观测一致；将 `G` 左作用于两臂位姿后，环残差中只剩 `G` 与独立噪声，三角不等式给出下界。

**引理 68（遮挡调度不退化）** 若存在可见相机 `i` 使 `λ_i ≥ λ0`，则 `S*` 选择该相机且 `K≥1`；若不存在，则 `K=1`、降速路径与单步 CVC 等价（无开环块，故无块内证据陈旧）。证明：`S*` 按 `min λ` 最大化，故可见良态相机必被选中；`λ<λ0` 时定义 479 强制 `K=1`，退化为逐步执行。

**引理 69（交接屏障的组合安全性）** 若 `HB(s)=1` 且执行器每步通过两臂 `joint_pre`，则任何闭链接触发生时都满足 `RPC.valid`、两臂 `LCert.valid`、最小间隙与双回执；且块长被强制为 1，因此不存在「块内已执行但未复核」的接触。证明：`HB` 是接触步的前置合取项；`K=1` 使每一步都成为决策边界，归纳可得。

**引理 70（误差预算可组合）** 接触误差满足定义 480 的加法上界，且 `e_anchor` 仅在世界参考任务中非零；纯相对任务可安全地忽略共模项。证明：各误差源在各自切空间线性化后相加；引理 63 说明纯相对任务的接触残差与 `G` 无关，故 `e_anchor` 项消失。

**引理 71（严格退化等价）** 关闭 `LocCert/RPC/AnchorAudit/BAdm/遮挡调度/交接屏障` 后，`VisLocGauge-DA` 的轨迹与 `InstructGauge-WR` 逐字相同。证明：每个增强都以定义 481 的算子形式包在 WR 外层；关闭算子即恒等映射，主闭环退化为 `WRC-ROS-7C` 的原始调用。

## 8. 本轮最大风险

**一句话**：共模抵消会把「整体锚错」伪装成「相对完美」——两臂相对位姿证书全绿、闭链残差为零，却因共享同一张错误地图而一起偏离世界参考；若夹具/标定板也由同一视觉链路定位，世界锚审计与错误共模相关，系统会在「自洽的集体错觉」中通过所有检查。缓解只能依靠**独立于该视觉链路的物理锚**（接触探针、激光跟踪、机械限位）或对世界参考任务强制人工确认，但这会牺牲双臂协作的自主性与节拍。
