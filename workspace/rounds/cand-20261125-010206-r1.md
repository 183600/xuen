灵感驱动研究循环·本轮灵感：「遥操作」×「状态机」（承 MetricVoiceGauge-NCD-HUTDH-v22 + IP-431–435）

> **基线**：v22 产出 HDL/ACSC/DCSC/HPC-E/CFC++（IP-431–435），其上承 v21 语义-规范层 SDC/CAC/DCL/GIC/HPC+/CFC+、v20 联邦感知证书 PCA/CTS/CFC/HPC/CFCtrl、v19 证书体系 DCM/OGCC/CCV/DRS/OGC、v17 感知链 CLP/S2C/HCG/PSV/APS/AMC。
> 本轮纪律：**遥操作命令是不可信、带时延、越权可达的外部意图提议；状态机是承载"安全即不变式"的可验证监督器**。不推倒 v22：HPC-E、EVC、PGEV、HDL、ACSC、DCSC、CFC++ 全部保留。本轮只做一件事：**在 v22 的物理接地-能量证书之上加一层"监督-准入"层，把执行从"逐步检查证书"升级为"状态机不变式 + 命令盾"，并把遥操作作为受盾的外部通道接进来，顺手封堵 v22 的最大风险（跨层退化振荡与配空间能耗过度保守导致的活性坍缩）**。

## 0. 直觉与动机

**灵感 1（遥操作 → 命令是不可信的、带时延的外部意图）**
直觉：v22 默认执行由本地自主规划器产生，但真实部署里大量动作来自远端操作员——他可能看到的是 100–300ms 前的世界，可能在打游戏式的误操作，网络还会抖动。把遥操作当成"多了一条控制输入"是致命的：它其实是**一条绕开本地规划器、却必须经过同一张安全证书的越权通道**。三件 v22 缺失的东西由此补上：**命令年龄**（t−t_stamp，迟到的命令基于陈旧世界）、**时延锥**（往返延迟期间动态障碍会移动，证书必须对整个时延窗鲁棒）、**权威互斥**（人机同时下令的交接窗口是双重指令危险区）。核心创新：**遥操作准入证书 (Teleoperation Admission Certificate, TAC)**——每条遥操作命令携带时间戳与来源签名，作为"提议"进入与自主计划相同的 HPC-E 门；超龄命令直接拒绝并回落保持态。关键反直觉点：**遥操作的正确接法不是"把人的指令直接给执行器"，而是"把人当成一个会犯错、会迟到、可能被冒充的提议者"——安全来自盾，不来自人的可靠**。副产品：双边力反馈的**无源性**恰好可以复用 v22 的 PGEV 能量账本——用虚拟能量罐把"操作员通道注入/抽取的能量"与真实电池 E_res 分账管理，从而在时延下保持闭环无源与真实可制动。

**灵感 2（状态机 → 安全即状态不变式，而非逐步检查）**
直觉：v21/v22 的 APS/TTL/降级逻辑是"散落的事件 + 超时 + 口头优先级"，无法证明不振荡，也无法审计"为什么现在允许这件事"。状态机把它收拢成一个**显式、确定、全定义的层次状态图 (statechart)**：每个状态携带一张**已认证的执行包络 E_s**（E_s 已经过 HPC-E 证明 ⊆ Exec_v22），迁移由**守卫 g** 触发且必须满足"降级包络 ⊆ 原包络"或"升级重新认证"。核心创新：**认证监督状态机 (Certified Supervisory State Machine, CSSM)**。安全从"每一步都要重新验一遍证书"退化为"只验状态不变式 + 迁移守卫"——控制环只做 O(1) 状态查询与包络隶属判断。关键反直觉点：**给出一个良基秩函数 ρ 后，"不会无限振荡"是可以被证明的，而不是靠调参**：所有降级迁移严格减小 ρ，所有升级迁移必须满足驻留时间 T_dwell 与稳定谓词，于是状态轨迹在有限步内稳定。这把 v22 第 9.5 节的风险（层级退化振荡）从"经验担心"变成"可证伪命题"。

**两者如何统一（盾 + 监督器）**
遥操作提供**外部提议**，状态机提供**准入裁决**。统一为 **命令盾 (Metric Shield, MS)**：无论命令来自自主规划器还是远端操作员，都先投影到当前监督状态 s 的认证包络 E_s 上，再进入执行；不可投影则保持/降级。共享状态 ζ_pgev 扩展为 **ζ_op = ζ_pgev ∪ (α_auth, C_buf, B_pass, s, ρ, dwell)**。统一准入门 **HPC-T = (HPC-E, TAC, SSMC-invariant, PET≥0)**。安全继承闭合：`Exec_v23 = ⋃_{s 可达} E_s ∩ (命令年龄 ≤ τ_cmd) ∩ (B_pass ≥ 0) ⊆ Exec_v22`。CFC++ 的层级一致性检查被状态机不变式收紧为更硬的"包络包含"检查。

## 1. 研究问题（轮次升级版）

- **Q12（时延下的命令认证）**：如何为带年龄 a=t−t_stamp 的遥操作命令定义证书有效期——是在时延锥上做鲁棒膨胀（保守但简单），还是"增量命令 + 零阶保持 + 每次重新认证"（活性好但须保证保持态本身安全）？二者在什么条件下等价？如何用 DICC 给出"命令在 [t, t+a] 内仍安全"的可审计充分条件？

- **Q13（无源性与真实能量分账）**：虚拟能量罐 B_pass 与真实储备 E_res 如何**分账**而不互相冒充？双边遥操作注入能量时，如何保证"无源性成立"∧"真实 fallback 能耗可支付"的联合不变式 `E_res ≥ E_fallback + E_arm + E_reach_safe + E_margin` 在最坏时延下仍成立？

- **Q14（监督状态机的可验证性）**：如何构造层次状态图使（i）迁移全定义且确定，（ii）良基秩 ρ 严格下降于降级、驻留约束于升级，（iii）每个状态的 E_s ⊆ Exec_v22 可由机器复核？状态空间如何随 HDL/DCL 规则数增长而可控（符号化/偏序归约）？

- **Q15（权威交接）**：人机权威交接的原子性如何保证（避免双指令窗口）？接管 (takeover) 的时延与操作员的"我已接管"信念如何对齐——若操作员以为已接管而机器人仍在自主，或反之，状态机如何用可审计的握手协议消解？

## 2. 设计原则（在 P34–P37/P41–P42 基础上新增 P43–P45）

**P43 遥操作命令受盾律（Teleop-as-Untrusted-Proposal / Shield Law）**
令遥操作命令 c 带 `(t_stamp, src, payload)`。执行前必须 `age(c) = t − t_stamp ≤ τ_cmd` 且 `π(c) ∈ E_s`（π 把命令解释为计划/速度增量）。超龄或不可投影（∉ E_s）→ 拒绝并返回"保持/降级"，**绝不直接执行**。自主命令与遥操作命令走**同一**盾：`admit(c) = [age≤τ_cmd] ∧ [π(c) ∈ E_s] ∧ [B_pass(c) ≥ 0]`。时延锥鲁棒化：E_s 以最坏时延 d_max 对动态障碍做膨胀，或采用增量+重认证；二者取保守并集。故遥操作的引入不扩域：`Exec_v23 ⊆ Exec_v22`。

**P44 监督状态机良基律（Well-Founded Supervisory Degradation）**
层次状态图 M = (S, s0, →, E, ρ, T_dwell)。每状态 s 携认证包络 `E_s ⊆ Exec_v22`。迁移 c→s' 仅在守卫 g 成立时发生，且须满足其一：(a) **降级**：`E_{s'} ⊆ E_s` 且 `ρ(s') < ρ(s)`；(b) **升级**：`E_{s'}` 在当前世界重新认证通过 ∧ 已驻留 ≥ T_dwell(s') ∧ 稳定谓词 stable(s')。迁移关系**全定义且确定**（每个 (s, 输入事件) 有唯一后继；无定义时默认 → SAFE_STOP）。故任意状态轨迹的危险度 ρ 单调有界，且在"证据事件有限/世界平稳"下有限步进入吸收集；`∀s 可达, E_s ⊆ Exec_v22`。

**P45 时延-无源性分账律（Delay–Passivity Budget Separation）**
设虚拟无源罐 `B_pass(t) ≥ 0` 记录操作员通道净注入能量，真实储备 E_res(t) 记录电池可支付能量。二者**独立记账、联合约束**：`admit(c) ⇒ (B_pass' ≥ 0) ∧ (E_res ≥ E_fallback + E_arm + E_reach_safe + E_margin)`。禁止把 B_pass 的盈余"兑现"为 E_res 的透支，也禁止用 E_res 的盈余放宽无源性要求。时延下用波变量/scattering 变换使通道无源；能量罐只约束**命令权威**，不代表物理续航。联合不变式每步转移后重查，任一不满足 → 降级到 SAFE_STOP。

## 3. 与基线的接口（如何退化）

- TAC 失效（时钟/签名/年龄不可信）⇒ 拒绝一切遥操作命令，仅自主执行且走 v22 门 ⇒ 等价 v22（更保守）；
- CSSM 失效（状态机崩溃或验证失败）⇒ 进入 **SAFE_STOP 吸收态**（共享区停机 + 非共享区静态人距上限）⇒ `Exec_v23 ⊆ Exec_v22`；
- PET 失效（能量罐读数不可信）⇒ 双边力反馈降为单向监督式遥操作（只发目标不发力），命令仍受盾 ⇒ 子集；
- 时延突增超过 d_max ⇒ 时延锥失效 ⇒ 拒绝新命令 + 保持最后认证的减速/让位 ⇒ 子集；
- 权威握手失败 ⇒ 默认保持当前权威（不接受隐式接管）并告警 ⇒ 子集；
- 全部失效 ⇒ 完全回退 v22 ⇒ `Exec_v23 ⊆ Exec_v22 ⊆ Exec_v21 ⊆ Exec_v20`；
- **安全继承**：盾只收缩不扩张（P43），状态机降级只缩包络（P44），双预算只加约束（P45）；任意失效向更保守退化。控制环 O(1) 查询 s 与 E_s 隶属；状态迁移、命令年龄、双预算余额进入 APS 新鲜度阶梯与审计链。

## 4. 预期贡献

1. **遥操作受盾律**：首次把遥操作命令严格建模为"不可信、带年龄、越权可达的提议"，并证明其经同一证书盾后不扩张执行域；
2. **认证监督状态机**：把"安全"从逐步检查升级为"状态不变式 + 迁移守卫"，用良基秩函数**证明**不振荡，取代调参式优先级；
3. **时延-无源性分账**：虚拟能量罐与真实能量储备**分账联合约束**，在时延下同时保持闭环无源与真实可制动，避免"无源但刹车没电"；
4. **权威交接协议**：给出原子化人机权威交接与默认保持当前权威的消解规则，封堵双指令窗口；
5. **封堵 v22 最大风险**：良基秩 + T_dwell 驻留把"跨层退化振荡"变为可证伪命题，包络包含检查替代口头层级优先级；
6. **HPC-T 统一门**：`Exec_v23 ⊆ Exec_v22` 闭环，控制环保持 O(1)。

## 5. 本轮最大风险

**一句话**：虚拟无源罐 B_pass 与真实储备 E_res 若在工程实现中被"合并成一个能量数"，状态机会在无源性检查全绿时批准一条物理上无法完成延迟制动的遥操作命令——即"无源但没电"的合规灾难。

## 2. 关键算法骨架（伪代码）

```python
@dataclass
class TeleopCommand:
    t_stamp: float          # 本地单调时钟戳
    src: str                # operator_id + 签名
    payload: dict           # velocity_delta / waypoint / gripper / force
    def age(self, now):
        return now - self.t_stamp

class TeleoperationAdmissionCertificate:          # IP-436
    def __init__(self, tau_cmd, shield, tank):
        self.tau_cmd = tau_cmd; self.shield = shield; self.tank = tank

    def admit(self, c, now, s, E_s, world):
        if not self._signature_ok(c):
            return Reject("BAD_SIGNATURE")
        if c.age(now) > self.tau_cmd:
            return Reject("STALE")                 # 超龄：拒，回落保持
        pi = self._interpret(c)                    # π(c)
        if not self.shield.contains(pi, E_s, world):   # 时延锥已在 E_s 内膨胀
            return Reject("OUT_OF_ENVELOPE")
        if not self.tank.can_commit(c, dt=0.0):     # 无源罐非负 + 分账联合约束
            return Reject("PASSIVITY_OR_ENERGY")
        return Admit(pi)

class CertifiedSupervisoryStateMachine:            # IP-437
    def __init__(self, states, s0, rank, dwell):
        self.states = states; self.s = s0
        self.rank = rank; self.dwell = dwell
        self.dwell_timer = {k: 0.0 for k in states}

    def delta(self, s, event):                          # 全定义、确定
        nxt = self._transition_table(s, event)
        return nxt if nxt is not None else "SAFE_STOP"

    def step(self, event, now, world, certifier):
        s = self.s
        nxt = self.delta(s, event)
        if not self.states[nxt].guard(s, event, world, certifier):
            return s                                     # 守卫失败：保持
        if self.rank[nxt] < self.rank[s]:                # 降级：静态保证 E_nxt ⊆ E_s
            assert self.states[nxt].envelope <= self.states[s].envelope
        else:                                            # 升级：驻留 + 稳定 + 新证据
            if self.dwell_timer[nxt] < self.dwell[nxt]:
                return s
            if not certifier.stable(nxt, world):
                return s
            if not certifier.fresh_evidence(nxt):
                return s
        self.s = nxt
        return nxt

class PassivityEnergyTank:                          # IP-438
    def __init__(self, B0, B_max, E_res_fn, E_fallback, E_arm, E_reach_safe, E_margin):
        self.B = B0; self.B_max = B_max; self.E_res = E_res_fn
        self.E_fallback = E_fallback; self.E_arm = E_arm
        self.E_reach_safe = E_reach_safe; self.E_margin = E_margin

    def _channel_energy(self, cmd, dt):                # 波变量：注入(+) / 抽取(-)
        return self._wave_transform(cmd, T_s=0.05, dt=dt)

    def can_commit(self, cmd, dt):
        B_new = self.B + self._channel_energy(cmd, dt)
        if not (0.0 <= B_new <= self.B_max):           # 无源罐自身非负且不爆炸
            return False
        # 分账联合约束：绝不把 B_pass 盈余当作物理续航
        if self.E_res() < (self.E_fallback + self.E_arm
                           + self.E_reach_safe + self.E_margin):
            return False
        return True

    def commit(self, cmd, dt):
        if not self.can_commit(cmd, dt):
            return False
        self.B += self._channel_energy(cmd, dt)
        return True

class AuthorityHandover:                             # IP-439
    def __init__(self):
        self.authority = "AUTONOMOUS"; self.pending = None; self.epoch = 0

    def request(self, who, ts):
        if self.pending is not None:                   # 已有未决交接：拒绝并发
            return Reject("HANDOVER_IN_PROGRESS")
        self.pending = {"who": who, "ts": ts, "phase": "REQUEST"}
        return Ack("WAIT_RELEASE")

    def release(self, current):
        if self.pending and self.pending["phase"] == "REQUEST":
            self.pending["phase"] = "RELEASED"
            return Ack("GRANT_PENDING")
        return Reject("NO_PENDING")

    def grant(self):
        if self.pending and self.pending["phase"] == "RELEASED":
            self.authority = self.pending["who"]; self.pending = None
            self.epoch += 1                            # 原子切换 + 审计纪元年增
            return Ack("GRANTED")
        return Reject("NOT_RELEASED")

class MetricShield:                                  # IP-440
    tau_cmd = 0.30
    def contains(self, pi, E_s, world):
        return self._subset(pi, E_s) and self._world_consistent(pi, world)

    def admit(self, cmd_or_plan, s, E_s, world, now, is_teleop):
        if is_teleop:
            if cmd_or_plan.age(now) > self.tau_cmd:
                return Reject("STALE")
            pi = self._interpret(cmd_or_plan)
        else:
            pi = cmd_or_plan
        if not self.contains(pi, E_s, world):
            return Reject("OUT_OF_ENVELOPE")           # 保持 / 由 CSSM 降级
        return Admit(pi)
```

## 3. 形式化结果（引理 / 定理与证明梗概）

**引理 169（盾不扩域，Shield Non-Expansion）**
对任意来源（自主 / 遥操作）的被准入计划 π，存在可达状态 s 使 `π ∈ E_s`，而静态验证保证 `E_s ⊆ Exec_v22`。故 `Exec_v23 ⊆ Exec_v22`。
*证明*：由 P43，admit 当且仅当 π∈E_s 且 E_s 是 P44 静态认证过的包络；对 s 归纳，初始 E_s0 ⊆ Exec_v22，降级 E_{s'}⊆E_s，升级重认证后仍 ⊆ Exec_v22。∎

**引理 170（时延鲁棒安全，Delay-Robust Safety）**
若 E_s 已按最坏时延 d_max 对动态障碍做可达集膨胀，则任何在 t 时刻被准入的命令，在 [t, t+d_max] 内的执行都不会破坏 v22 的几何/能量证书。
*证明*：膨胀后的 E_s 覆盖了延迟窗内障碍的所有可达位置，π∈E_s 即 π 对该超集安全；命令年龄门确保不会执行窗口之外的解释。∎
*注*：若采用"增量 + 零阶保持 + 每步重认证"路径，则安全性由逐步重认证直接给出，但需额外证明"保持态本身安全"（保持 = 零速度，属于 E_s 的常驻子集）。

**定理 171（无 Zeno 振荡，No Zeno Chattering）**
在 P44 下，任意有限时间区间内的状态迁移次数有界：每次降级使 ρ 严格下降，ρ ≥ 0，故降级至多 ρ(s0) 次；任意两次降级之间，每次升级需驻留 ≥ T_dwell 且需一次"新证据事件"，故升级次数受证据事件数上界约束。特别地，在证据事件有限或世界平稳的假设下，轨迹在有限步内进入吸收集。
*证明*：降级次数 ≤ ρ(s0)（良基 + 严格下降）。两次降级之间的升级序列每次消耗 T_dwell 时间或消耗一个不可再生/需新证据的升级配额，有限区间内不能无限次。SAFE_STOP 为吸收态。∎

**定理 172（双预算联合不变式，Joint Budget Invariant）**
若每步 commit 均通过 `can_commit`，则恒有 `B_pass ≥ 0 ∧ E_res ≥ E_fallback + E_arm + E_reach_safe + E_margin`；且 B_pass 的更新不写入 E_res，E_res 的更新不写入 B_pass（分账）。
*证明*：can_commit 同时检查两个不等式，任一失败即不提交（命令被拒或降级）；更新式在实现上分离两个变量。归纳得联合不变式。∎

**推论 173（v22 风险消解）**
v22 第 9.5 节的"层级退化振荡 / 配空间能耗过度保守"被定理 171（振荡有界）+ P43/P44 的包络包含检查（保守性只有单向）转为可证伪命题：振荡次数可上界，保守性不会因层间来回切换而累积放大到活性归零（每次降级单调收紧且良基有限）。

## 4. 实验设计

|---|---|---|---|---|
| E1 | 时延下安全性/活性 | 注入 0/100/300/500ms + 抖动；动态障碍 | 证书冲突数、命令接受率、平均速度 | 500ms 内 0 认证冲突；接受率随时延单调降但不为 0（保持/让位） |
| E2 | 恶意/误操作操作员 | 随机危险命令 + 越界速度 + 冒充签名 | 盾拒绝率、碰撞率、拒绝原因分布 | 认证碰撞 = 0；STALE/BAD_SIG/OUT_OF_ENVELOPE 分类清晰 |
| E3 | 振荡抑制 | 证书临界值来回扰动；对比 v22 TTL 基线 | 状态迁移/秒、SAFE_STOP 触发数 | 迁移/秒有界且显著低于基线；无 Zeno |

**消融**：去掉 TAC（直通遥操作）→ E2 预期出现认证域外碰撞；去掉 CSSM（回退 v22 TTL）→ E3 迁移/秒显著上升；合并 B_pass 与 E_res → E4 预期出现联合违反。

**度量采集**：每步记录 `(t, s, ρ(s), age(c), B_pass, E_res, admitted, reason)`，写入 APS 审计链；对 `Exec_v23 ⊆ Exec_v22` 做在线隶属抽查（随机采样计划，验证 ⊆ 关系）。

## 5. 与 v22 各模块的挂接点

- **TAC ← HPC-E**：`shield.contains` 内部调用 HPC-E 验证几何/规范/负信息/能量/差距；TAC 只加"命令年龄 + 来源"两维。
- **PET ← EVC/PGEV**：`E_res`、`E_fallback`、`E_arm`、`E_reach_safe`、`E_margin` 全部复用 IP-431/434 的既有量，PET 只新增 B_pass 并加联合不等式。
- **CSSM ← HDL/DCL/GIC**：HDL 的三层过滤器链编译为状态机的"模式层"；DCL 的 F/O/P 规则映射为迁移守卫；GIC 的意图状态映射为 OPERATIONAL 内的子模式与升级证据。
- **AHC ← APS**：交接握手事件携带时间戳进入 APS 新鲜度阶梯，过期握手视为失败并保持原权威。
- **MS ← CFC++**：盾的 `_world_consistent` 复用 CFC++ 的层级一致性结果；状态机包络包含检查取代其口头层级优先级。

## 6. 本轮最大风险

**一句话**：虚拟无源罐 B_pass 与真实储备 E_res 若在工程实现中被"合并成一个能量数"，状态机会在无源性检查全绿时批准一条物理上无法完成延迟制动的遥操作命令——即"无源但没电"的合规灾难。
