# 第 1 轮（灵感循环第 1 轮；本轮灵感：「强化学习」×「失败恢复」）

> 承接当前保留的 LeanGauge（IP-310~314，定义 398–415）。LeanGauge 已经能把「需求盲区」找出来，并用可预测自助下注 + 少样本贝叶斯校准就地修复契约。但它仍留下三个未被定义的地方：
> 1. **探测策略是手写的**：什么时候探、探哪个盲区、探几次、何时放弃，全由阈值 γ、τ_n 和预算常数决定，没有从失败中学习；
> 2. **失败没有恢复语义**：4CV 只有「成功修复」和「降级/stub」两个出口，缺少一条**可认证的返回路径**——系统知道怎么坏，却不知道怎样保证在有限时间内回到已认证状态；
> 3. **契约更新没有来源追踪**：一次被污染或过期的探测样本可以直接改写 EC，误差沿下游组合传播，而系统无法只撤回「受污染的那一支」。
>
> 本轮把「强化学习」与「失败恢复」放在一起，不是「用 RL 调参」，而是提出一个更强的命题：**探测是一个在恢复核内进行的、带风险预算的序贯实验设计问题；失败不是终止事件，而是一个必须携带「恢复证书」与「认知回滚证书」的状态转移。** 设计 **RESILE**（Recoverable Shielded Interactive Learning with Epistemic rollback，可恢复·屏蔽式·交互学习与认知回滚），IP-315~321；定义 416–431；实验 E419–E432。理论姿态：RESILE 是 LeanGauge 的**保守扩展**——当恢复包络覆盖全状态且无失败时，RESILE 退化为 LeanGauge 的 4CV；任何时刻，安全由快盾（毫秒级恢复控制器）兜底，学习只发生在慢环，且只能选择恢复核内的动作。

## 0. 直觉与动机

### 灵感 1（强化学习 → 探测不是阈值规则，而是「信息—风险」的序贯交易）

直觉：LeanGauge 的 I-Box 像一个只会在固定价格买入的投资者：只要 λ(a) ≥ γ 就采样，采到 N_bl 够数就停。它没有回答三个真正的序贯问题：
- **先探哪个盲区**？不同盲区的情报价值不同，有的探一次能把整个等价类的不确定度压低，有的探十次仍在噪声里；
- **何时停**？继续探测的边际信息增益可能已经低于它占用的风险预算和恢复成本；
- **何时放弃修复、改为回滚或降级**？继续校准一个已经被证明不可校准的模块，比直接回滚更危险。

这三个问题天然是一个**带约束的马尔可夫决策过程（CMDP）**：状态里包含物理状态、契约状态、证据图和剩余风险预算；动作里包含任务动作、探测动作、修复动作、回滚动作和停机动作；目标是最大化「单位风险的信息增益/覆盖增益」，约束是「不可恢复失败概率 ≤ α」和「恢复时延 ≤ τ_rec」。关键不是把 RL 当成黑箱，而是把**恢复能力写进可行动作集**：RL 只能在「即使这一步失败也能在 τ_rec 内回到已认证集」的状态里探索。这样，RL 的探索就不再是「拿系统赌明天」，而是「在安全气囊展开范围内试错」。

### 灵感 2（失败恢复 → 恢复必须是「物理 + 认知」双回滚）

直觉：传统故障恢复只回滚机器人位姿、关节、任务栈。但 LeanGauge 的失败有一半是**认知的**：一个过期或被投毒的探测样本写进了契约，系统即使退回安全位姿，仍会带着「这个材质已经校准过」的错误信念再次执行同一个危险动作。**物理回滚救的是身体，认知回滚救的是判断。**

因此我们引入**契约溯源 DAG（CP-DAG）**：每一条 u 字段、χ_R、D、τ_merge、每一条输运边、每一个校准样本都是图上的节点，边表示「由谁推出谁」。当一次探测或失败证伪了某个节点，系统不是全量重置，而是计算它的**后代闭包**，做一次「最小失效切割」：只撤回依赖于被证伪证据的那一支，并在原位置留下**负见证**（¬c），防止从同一个污染源再次推出同一结论。回滚的代价用**爆炸半径**计量；回滚的正确性用**回滚证书**保证：回滚后不存在任何有效主张依赖被证伪节点，且 R73 的五不变式仍逐条成立。

这把「失败恢复」从「重启/降级」升级为「可证明的局部认知修复」：系统可以只忘记错的那一部分，而不忘记全部。

### 灵感 3（失败即数据 → 用恢复轨迹做 hindsight relabeling）

直觉：安全系统里失败样本极其昂贵，但它们恰恰是最有信息量的。LeanGauge 把失败当作「未通过」，丢掉了；RESILE 把每一次失败拆成两段数据：
- **前段**（失败前）是「哪里容易坏」的风险样本，用来更新风险模型和恢复契约的边界；
- **后段**（恢复过程）是「怎样从坏状态回去」的恢复轨迹，用 hindsight relabeling 把「到达安全集」重标为子目标，直接训练恢复策略 π_rec。

更进一步，把「失败前最后一个安全状态」重标为子目标，把「差一点失败」的 near-miss 也纳入训练。这就是 **Recovery Hindsight Relabeling（RHR）**：失败不再是负样本，而是**恢复策略的正样本 + 风险模型的正样本**。它让稀缺的失败数据同时服务于「避免失败」和「失败后恢复」两个目标。

### 灵感 4（安全 RL 的教训 → 快盾慢学，学习永远在恢复核内）

直觉：端到端 RL 在安全关键系统里最危险的模式，是「策略更新」和「安全约束」共享同一个时间尺度：一次梯度更新可能让策略在下一个控制周期做出不可恢复的动作。RESILE 采用**双时间尺度 + 屏蔽**：
- **快环（≥1 kHz）**：恢复盾 R-Shield 只做一件事——检查候选动作的下一步是否仍在恢复核 K_rec 内；若否，用已认证的恢复控制器 π_rec 替换，或直接拒绝。
- **中环（50 Hz）**：LeanGauge 的 D-Box/I-Box/BP-Cal 继续做计量探测与局部校准。
- **慢环（分钟级）**：失败条件策略 π_θ 用离线/保守 RL 更新；它只能向快环**建议**动作，不能绕过盾。

安全性因此有了清晰的归属：快环负责「不出不可恢复的事」，慢环负责「越来越会选值得探的事」。学习可以失败，但失败只能发生在恢复核内。

## 1. 形式化定义（增量：定义 416–431）

**定义 416（失败增强的计量状态）** 在 LeanGauge 状态上增加契约与证据维度：
x_t = (p_t, q_t, o_t, C_t, G_t, b_t, m_t)
- p_t,q_t,o_t：机器人、关节、物体/环境状态；
- C_t：当前有效计量契约集合（EC 及其组合）；
- G_t：契约溯源 DAG（定义 421）；
- b_t：剩余风险预算（力/温/时延/样本数）；
- m_t：当前恢复裕度（与定义 419 的 h_rec 相关）。

**定义 417（失败分类）** 失败事件 F 分为四类：
- F_meas：测量失败（丢帧、饱和、σ_obs 不可信）；
- F_contract：契约失败（观测落在声明域外，或后验与声明冲突）；
- F_recover：恢复失败（π_rec 未在 τ_rec 内回到 S_cert）；
- F_evidence：证据失败（过期、投毒、来源不可信）。
前三类是「世界/系统」的失败，第四类是「信念」的失败；RESILE 要求每一类都有独立的检测器和恢复动作。

**定义 418（可恢复关系与不可恢复集）** 对转移 (x,a,x′)，若存在恢复策略 π_rec 使 x′ 在 τ_rec 内以概率 ≥1−β 回到已认证集 S_cert，且消耗风险 ≤ b_rec，则称该转移**可恢复**，记 Rec(x,a,x′)=1。不可恢复集
X_unrec = {x′ : ¬∃π_rec 满足上述条件}。
注意：失败 ≠ 不可恢复。RESILE 允许进入 X_fail = X \ S_cert，但禁止进入 X_unrec。

**定义 419（恢复契约 RC）** 恢复契约
RC = (S_cert, E_rec, π_rec, h_rec, τ_rec, b_rec, κ)
其中：
- S_cert ⊆ X：已认证安全集（物理安全 + 契约有效）；
- E_rec ⊇ S_cert：恢复包络，允许探索的最大状态集；
- π_rec：恢复控制器；
- h_rec: E_rec → ℝ≥0：恢复屏障函数，h_rec(x)=0 ⇔ x∈∂S_cert，h_rec 越大表示离安全越远；
- τ_rec：最大恢复时延；b_rec：单次恢复风险预算；κ∈(0,1)：收缩率。
RC 有效 ⇔ 对任意 x∈E_rec\S_cert，在 π_rec 下
h_rec(x_{t+1}) ≤ (1−κ) h_rec(x_t)，且 h_rec(x_0) ≤ h_max ⇒ ∃k≤⌈log(h_max/ε)/κ⌉，h_rec(x_k) ≤ ε。
（实际用区间/SoS/学习式屏障 + Lipschitz 界验证，见引理 46。）

**定义 420（恢复核与恢复盾）** 恢复核
K_rec = {x∈E_rec : h_rec(x) ≤ h_max ∧ b_t ≥ β_rec(h_rec(x))}。
恢复盾是一个安全投影算子：
Shield(x,a) = a，若 x′ = f(x,a) ∈ K_rec；
Shield(x,a) = π_rec(x)，否则。
盾不仅「裁剪动作」，还会**替换为恢复动作**；因此它同时是过滤器和兜底控制器。

**定义 421（契约溯源 DAG）** CP-DAG G = (V_G, E_G, λ_G, τ_G, σ_G)：
- 节点 v∈V_G 是主张/证据单元：u 字段、χ_R、D、τ_merge、校准样本、输运边、组合证书；
- 有向边 (u→v) 表示 v 的推导依赖 u；
- λ_G(v) 是来源类型（先验/测量/输运/组合/负见证）；
- τ_G(v) 是时间戳；σ_G(v) 是置信/可靠度。
G 必须无环；任何新契约声明必须携带其在 G 中的证明子树。

**定义 422（认知回滚算子）** 当节点 c 被证伪（探测冲突、失败回执、过期、投毒检测），定义后代闭包
Desc(c) = {v : c ⇝ v in G}，
回滚集 RB(c) = {c} ∪ Desc(c)。
认知回滚 ERoll(c)：
1. 将所有 v∈RB(c) 标记为 INVALID，并从有效契约集 C_t 中撤下；
2. 从最近的检查点恢复这些节点的非污染版本（若无则标记 UNKNOWN）；
3. 在 G 中插入负见证节点 ¬c，并禁止任何从 c 重新推导的边；
4. 触发受影响子图的重新验证（只重验 RB(c) 的边界）。
与全量重置不同，ERoll(c) 只触及 RB(c)；其大小称为**爆炸半径** blast(c)=|RB(c)|。

**定义 423（回滚证书）** 回滚证书 RCert(c) = (RB(c), cut, checkpoint, revalidate, invariants) 满足：
- **切割性**：RB(c) 是后代闭包，cut 覆盖所有从 c 到有效节点的路径；
- **新鲜性**：回滚后所有有效节点的 τ_G 晚于证伪时刻；
- **不变量**：回滚后的契约集合满足 R73 的契约完整性、组合单调性、反作用通道完备、主张绑定、严格退化链；
- **可重放**：revalidate 只依赖非 INVALID 节点，且能在 τ_rev 内完成。
RCert 有效 ⇔ 上述四项全部成立。

**定义 424（失败条件 CMDP）** RESILE 的决策问题：
max_π E_π[ Σ_t γ^t ( I_t − λ_c c_t − λ_r r_t ) ]
s.t. E_π[ Σ_t c_t ] ≤ B_total，
     P(∃t: x_t∈X_unrec) ≤ α，
     P(τ_rec > τ_max) ≤ β。
其中 I_t 是信息增益（定义 425），c_t 是可恢复风险成本，r_t 是恢复/回滚成本。

**定义 425（信息—风险收益）** 对契约参数 u 与探测动作 a：
I(a|x) = H(u | D_t) − E_{o~P(·|x,a)}[ H(u | D_t ∪ {(a,o)}) ]。
在 GP 后验下有闭式近似：I(a) = ½ log(1 + σ_prior²(a)/σ_noise²(a))。
定义单位风险信息收益
IRR(a|x) = I(a|x) / (c_t(a) + ε)。
慢环策略以 IRR 为奖励信号；它学的是「怎样用最少的可恢复风险买最多的契约信息」。

**定义 426（恢复 hindsight relabeling）** 给定失败轨迹 τ = (x_0,a_0,…,x_T)，其中 x_T∈X_fail，恢复段 ρ = (x_T,…,x_{T+k}∈S_cert)。RHR 生成：
- 恢复样本：(x_T, a_rec, x_{T+1}) → 目标 S_cert；
- 子目标样本：把 x_{T−1}（最后一个安全状态）重标为目标；
- near-miss 样本：若 h_rec(x_T) < m_near，则以权重 w_near 加入风险模型；
- 反事实样本：把失败动作 a_{T−1} 替换为 π_rec 的建议动作，生成「如果当时恢复」的对照。
RHR 不改变真实奖励，只改变「以什么为目标」；其正确性依赖目标重标后的回报等价性（标准 HER 结论）。

**定义 427（失败恢复契约 FR-Contract）** FR-Contract = (F_detect, RC, ERoll, τ_rec, τ_rev, B_rec, escalation)。
- F_detect：四类失败的检测器；
- RC：恢复契约；
- ERoll：认知回滚；
- τ_rec/τ_rev：物理/认知恢复时延上界；
- B_rec：恢复预算；
- escalation：若恢复失败或回滚后不变量不成立，升级到系统级降级（R68 样式）。
FR-Contract 是 IV-Contract 的严格扩展：IV-Contract 管「探测迭代不超时」，FR-Contract 管「探测失败也可回」。

**定义 428（双时间尺度屏蔽闭环）** RESILE 运行三层：
- 快环（≥1 kHz）：Shield + π_rec + 契约有效性快速检查；
- 中环（50 Hz）：D-Box/I-Box/BP-Cal + ERoll 触发；
- 慢环（分钟）：失败条件策略 π_θ 的离线/保守更新。
约束：慢环的任何输出必须经过快环 Shield；快环不接受慢环的在线梯度。

**定义 429（可恢复覆盖率与恢复感知遗憾）** 可恢复覆盖率
C_rec(T) = μ({s∈S_blind : n_verify(s)≥τ_n ∧ EC_s 有效 ∧ s 的探测路径在 K_rec 内})，
其中 μ 为按风险加权的子空间测度。恢复感知遗憾
Reg(T) = C_rec^* − C_rec(T)。
目标不是「探遍所有盲区」，而是「在恢复核内探到单位风险最有价值的盲区」。

**定义 430（失败记忆与 near-miss 账本）** 失败记忆 FM = {(x,a,F_type,h_rec,recovery_outcome,provenance)}；near-miss 账本记录 h_rec 接近阈值但未失败的事件。FM 同时用于：训练 π_rec、校准风险模型、更新恢复包络 E_rec、触发 FR-Contract 的 escalation 阈值。

**定义 431（RESILE 总览）** RESILE = (LeanGauge, RC, R-Shield, CP-DAG, ERoll, FC-Probe, RHR, FM)。其闭环为 **5CV**：Detect（D-Box）、Correct（I-Box）、Verify（BP-Cal）、Update（热替换）、**Recover（ERoll + π_rec）**。5CV 在 4CV 的每个出口都增加一个「可恢复性检查」；任何出口不满足 RCert/RC 时，不得返回主循环。

```python
        samples = collect(o)
        if enough(samples):
            new_ec = BPCal.calibrate(samples, s)
            if CONTRACT_VALID(new_ec):
                M.mreg.hot_replace(M.dpe, new_ec)
                dag.attach(new_ec, provenance=samples)
    return MODGAUGE_round(M, obs)
```

## 3. 推导

**引理 46（恢复盾的不变性）** 若 RC 有效（h_rec 在 π_rec 下 κ-收缩，π_rec 可在 τ_rec 内回到 S_cert，b_rec 足够），且 x_0∈K_rec，则对任意策略选择的 a，Shield(x_t,a) 使 x_{t+1}∈K_rec ∪ S_cert；且任何进入 X_fail 的转移都在 ⌈log(h_max/ε)/κ⌉ 步内回到 S_cert。证明：对 h_rec 归纳；若 a 安全则由 K_rec 定义直接成立；若 a 不安全则 Shield 替换为 π_rec，由收缩性 h_rec(x_{t+1}) ≤ (1−κ)h_rec(x_t)，几何收敛到 0；预算约束由 b_rec 保证。

**定理 47（屏蔽下的不可恢复失败界）** 在精确模型下，P(∃t: x_t∈X_unrec | Shield, x_0∈K_rec) = 0。在模型误差 ε_m 与 h_rec 的 Lipschitz 常数 L_h 下，
P(∃t: x_t∈X_unrec) ≤ α_model + exp(−2 B_total² / (T·c_max²))，
其中 α_model ≤ L_h ε_m / h_max 是屏障验证误差导致的边界穿透概率。证明：盾把系统限制在 K_rec 的 ε_m-邻域内；只有模型误差把「名义安全」翻译成「实际不安全」时才可能穿透；再用 Hoeffding 控制预算随机性。

**定理 48（认知回滚的可靠性）** 若 CP-DAG 无环、RB(c) 是后代闭包、且回滚后所有有效节点的来源不含 c，则 ERoll(c) 后不存在任何有效契约声明依赖被证伪节点；且 R73 五不变式保持。证明：对 G 做拓扑归纳。切割性保证所有 c→v 路径被切断；新鲜性保证不复活旧污染；五不变式对「删除节点 + 边界重验」单调保持（组合单调性只允许结论变保守，不会变乐观）。

**引理 49（恢复感知遗憾）** 在恢复核内，探测问题等价于带预算的贝叶斯实验设计。若每次探测的信息增益 ≤ I_max，风险成本 ≥ c_min，且策略采用 Thompson sampling/IRR 贪心，则
Reg(T) ≤ O( sqrt(|S_blind| · I_max · T) ) + O( |S_blind| · τ_rec / Δ_min )，
第二项是恢复事件造成的覆盖延迟。证明：标准贝叶斯遗憾分解 + 恢复时间占用的有效探测轮数折算。

**引理 50（对 LeanGauge 的保守扩展）** 当 E_rec = X、h_rec≡0、无失败时，RESILE 的 5CV 退化为 LeanGauge 的 4CV，且所有 LeanGauge 保证（定义 398–415、引理 42–45）逐条成立。证明：Shield 恒等、ERoll 空操作、FC-Probe 在 γ 阈值下与 I-Box 同分布；5CV 的 Recover 阶段为空。

**引理 51（RHR 的数据效率）** 对目标重标后的恢复样本，其回报与真实恢复目标等价；因此在失败样本数 N_f 下，π_rec 的恢复成功率估计的方差按 O(1/N_f) 下降，而不是按 O(1/N_success) 下降。证明：标准 HER 的目标重标等价性 + 失败段与恢复段的条件独立分解。

## 6. 本轮最大风险

**一句话**：RESILE 把安全外包给「恢复契约」——如果 h_rec / π_rec 是在错误动力学模型下验证的（打滑、卡死、传感器说谎），或者对抗者专门攻击恢复包络的边界，那么盾牌会把真正不可恢复的状态误判为可恢复，而 RL 恰恰会被「单位风险信息增益」引导到恢复包络边界去探测，系统于是以「持有恢复证书」的姿态进入不可恢复区；这比 LeanGauge 的「自信地组合错误世界」更危险，因为它多了一层「自信地认为自己能回来」。

次级风险与缓解：
1. **恢复模型失配** → RC 用区间/SoS + Lipschitz 保守验证；在线监测 h_rec 残差，超界即缩小 E_rec；
2. **恢复包络边界攻击** → 在 E_rec 内保留安全裕度 m_rec，禁止贴着边界探测；对边界附近的探测加随机化和多重见证；
3. **CP-DAG 爆炸** → 限制每个契约节点的祖先集大小；对高频更新做增量检查点；爆炸半径超阈值时退化为子图级重建；
4. **离线 RL 分布外** → 只在 K_rec 内在线微调；用保守 Q（CQL）和不确定性惩罚；策略输出必须经过 Shield；
5. **回滚后反复失败** → FR-Contract 的 escalation：同一节点回滚 ≥N 次 ⇒ 标记为不可修复，转人工/降级；
6. **RHR 目标重标偏差** → 只在恢复段做重标，保持真实动力学；对反事实样本加重要性权重；
7. **快环计算抖动** → Shield 的 h_rec 用查表/多项式近似，最坏情况有 WCET 证书；超时即进入预认证的保守恢复动作。

## 2. 形式化定义（要点）

**定义 416（失败增强状态）** `x_t = (p_t,q_t,o_t,C_t,G_t,b_t,m_t)`：物理状态、有效契约集、溯源 DAG、剩余风险预算、恢复裕度。

**定义 417（失败分类）** `F = F_meas ∪ F_contract ∪ F_recover ∪ F_evidence`。前三是物理/系统失败，第四是信念失败；每类有独立检测器与恢复动作。

**定义 418（可恢复关系）** `Rec(x,a,x′)=1` 当且仅当存在 `π_rec` 使 `x′` 在 `τ_rec` 内以概率 `≥1−β` 回到 `S_cert` 且风险 `≤b_rec`。`X_unrec = {x′ : ¬∃π_rec}`。失败 ≠ 不可恢复：允许进入 `X_fail = X \ S_cert`，禁止进入 `X_unrec`。

**定义 419（恢复契约）** `RC = (S_cert,E_rec,π_rec,h_rec,τ_rec,b_rec,κ)`，有效条件：
```
∀x∈E_rec\S_cert:  h_rec(x_{t+1}) ≤ (1−κ) h_rec(x_t)
h_rec(x_0) ≤ h_max  ⇒  ∃k ≤ ⌈log(h_max/ε)/κ⌉, h_rec(x_k) ≤ ε
```

**定义 420（恢复核与恢复盾）**
```
K_rec = {x∈E_rec : h_rec(x) ≤ h_max ∧ b_t ≥ β_rec(h_rec(x))}
Shield(x,a) = a         若 f(x,a) ∈ K_rec
            = π_rec(x)  否则
```
盾同时是过滤器与兜底控制器。

**定义 421（CP-DAG）** `G=(V_G,E_G,λ_G,τ_G,σ_G)`，节点为 u 字段/χ_R/D/τ_merge/样本/输运边/组合证书，边为推导依赖；必须无环；新契约声明必须携带证明子树。

**定义 422（认知回滚）** 对被证伪节点 c：`RB(c) = {c} ∪ Desc(c)`。ERoll(c)：标 INVALID → 检查点恢复 → 插入负见证 `¬c` → 只重验 RB(c) 边界。

**定义 423（回滚证书）** `RCert = (RB,cut,checkpoint,revalidate,invariants)`，要求切割性、新鲜性、R73 五不变式、可重放。

**定义 424（失败条件 CMDP）**
```
max_π E[Σ γ^t (I_t − λ_c c_t − λ_r r_t)]
s.t. E[Σ c_t] ≤ B_total
     P(∃t: x_t∈X_unrec) ≤ α
     P(τ_rec > τ_max) ≤ β
```

**定义 425（信息—风险收益）** `I(a|x)=H(u|D_t)−E[H(u|D_t∪{(a,o)})]`，GP 近似 `I(a)≈½log(1+σ_prior²/σ_noise²)`；`IRR=I/(c+ε)`。

**定义 426（RHR）** 失败轨迹重标为：恢复样本（目标 S_cert）、子目标样本（最后安全状态）、near-miss 风险样本、反事实恢复对照。

**定义 427（FR-Contract）** `(F_detect,RC,ERoll,τ_rec,τ_rev,B_rec,escalation)`；是 IV-Contract 的严格扩展，管「探测失败也可回」。

**定义 428（双时间尺度闭环）** 快环 ≥1kHz（Shield/π_rec/契约快检）；中环 50Hz（D-Box/I-Box/BP-Cal/ERoll）；慢环分钟级（FC-Probe 离线/保守更新）。慢环输出必须过盾，快环不接受在线梯度。

**定义 429（可恢复覆盖率）** `C_rec(T)=μ({s∈S_blind: n_verify≥τ_n ∧ EC_s 有效 ∧ 探测路径∈K_rec})`；`Reg(T)=C_rec^*−C_rec(T)`。

**定义 430（失败记忆）** `FM={(x,a,F_type,h_rec,recovery_outcome,provenance)}` + near-miss 账本；用于训练 π_rec、校准风险模型、更新 E_rec、触发 escalation。

**定义 431（RESILE 总览）** `RESILE=(LeanGauge,RC,R-Shield,CP-DAG,ERoll,FC-Probe,RHR,FM)`；闭环为 **5CV**：Detect→Correct→Verify→Update→Recover。任何出口不满足 RCert/RC 时不得返回主循环。

## 4. 推导

**引理 46（恢复盾不变性）** 若 RC 有效且 `x_0∈K_rec`，则 Shield 使 `x_{t+1}∈K_rec∪S_cert`；任何进入 `X_fail` 的转移都在 `⌈log(h_max/ε)/κ⌉` 步内回到 `S_cert`。

**定理 47（不可恢复失败界）** 精确模型下 `P(∃t:x_t∈X_unrec | Shield)=0`；模型误差 `ε_m` 与 Lipschitz `L_h` 下，`P≤α_model+exp(−2B_total²/(T·c_max²))`，`α_model≤L_h ε_m/h_max`。

**定理 48（认知回滚可靠性）** 若 CP-DAG 无环、RB(c) 为后代闭包、回滚后有效节点来源不含 c，则不存在有效声明依赖被证伪节点，且 R73 五不变式保持。

**引理 49（恢复感知遗憾）** 恢复核内探测等价于带预算贝叶斯实验设计；`Reg(T) ≤ O(√(|S_blind|·I_max·T)) + O(|S_blind|·τ_rec/Δ_min)`。

**引理 50（对 LeanGauge 的保守扩展）** 当 `E_rec=X`、`h_rec≡0`、无失败时，5CV 退化为 4CV，LeanGauge 定义 398–415 与引理 42–45 逐条成立。

**引理 51（RHR 数据效率）** 目标重标后的恢复样本与真实恢复目标等价；恢复成功率估计方差按 `O(1/N_f)` 下降，而非 `O(1/N_success)`。

## 7. 本轮最大风险

**一句话**：RESILE 把安全外包给「恢复契约」——如果 `h_rec` / `π_rec` 是在错误动力学模型下验证的（打滑、卡死、传感器说谎），或者对抗者专门攻击恢复包络边界，盾牌会把真正不可恢复的状态误判为可恢复，而 RL 又会被「单位风险信息增益」引导到包络边界去探测，系统于是以「持有恢复证书」的姿态进入不可恢复区；这比 LeanGauge 的「自信地组合错误世界」更危险，因为它多了一层「自信地认为自己能回来」。

缓解：RC 用区间/SoS + Lipschitz 保守验证并在线监测 `h_rec` 残差；保留边界安全裕度 `m_rec`；CP-DAG 限制祖先集并对高频更新做增量检查点；RL 只在 `K_rec` 内微调且输出必须过盾；同一节点回滚 ≥N 次即标记不可修复并升级降级；Shield 的 `h_rec` 用查表/多项式近似并给出 WCET 证书。
