# 第 44 轮（灵感驱动循环第 2 轮）· Pose-Cert × Transfer-Cert：把「位姿估计」与「跨任务泛化」纳入可验证证书闭环（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 自陈最大风险是「共形边际覆盖被欺骗 + 多用户契约求交为空」，但它仍压着两个更底层、也更致命的单点假设：**(H3) 位姿/状态被视为精确已知的锚点**——v20 的每一条几何证书、每一个守卫 margin 都是 `x` 的函数，可 `x` 来自 LIO/学习式位姿估计，会漂、会滞后、会重尾、会在动态场景里短暂发散；**(H4) 证书被默认「按任务重造」或「检索即可跨任务复用」**——仿真-检索飞轮为每个任务生成证书，CKB 检索又把它们跨任务、跨本体、跨场景复用，却从未给「迁移」本身一个风险上界。本轮灵感词「位姿估计」「跨任务泛化」精确命中这两个假设：**位姿估计**迫使我们把 `x` 从「已知量」降级为「带覆盖保证的置信集」，让每张证书先扣掉位姿不确定性；**跨任务泛化**迫使我们把「迁移」从经验直觉升级为「带任务距离的证书迁移许可」，距离超预算就拒绝迁移、回到重认证。二者耦合处是本轮真正的新问题：**位姿误差分布本身是任务条件的，所以证书迁移必须同时迁移位姿误差模型，否则会在任务切换的瞬间静默失效。**

## 0. 直觉与动机

**灵感 1（位姿估计 → 「位姿不是噪声，是证书的扣款」）**：直觉上，工程师会说「位姿有 1cm 误差，把安全距离留大一点就行」。这句话只在误差有界、且证书对位姿 Lipschitz 时才成立；而真实位姿估计器给的是一个点估计 + 协方差，协方差既不保证覆盖，也不告诉你误差重尾到什么程度，更不保证跨场景可交换。正确做法是把位姿估计输出升级为**位姿证书**：一个置信集 X̂_t^β，满足 P(x_t∈X̂_t^β) ≥ 1−β，再配一条漂移界。于是一切证书先做「鲁棒化」：m̲ = m(x̂) − L_m·ρ。由此得到一个反直觉但重要的结论：**位姿估计精度不是感知指标，而是安全杠杆**——ρ 每降一点，可用动作集就合法扩大一点；把算力花在「让守卫 margin 最紧的那个方向」上，是比均匀提升感知更划算的主动感知。一句话：**点估计是承诺，置信集才是凭证；证书只能消费凭证。**

**灵感 2（跨任务泛化 → 「迁移不是免费的直觉，是带距离的扣款」）**：直觉上，「这个抓取策略在导航任务里也差不多能用」是一个危险的类比。证书只对「它被认证的那个任务分布」负责；跨任务复用必须回答：目标任务与源任务到底差多远？证书对任务差异有多敏感？因此把任务嵌入一个度量空间，定义任务距离 δ，并要求证书对任务是 L_c-Lipschitz 的；迁移后的有效 margin 是 m_{s→t} = m_s − L_c·δ̂。若剩余预算 (m_s−θ) 不够付这笔「距离扣款」，就拒绝迁移（负迁移拒绝），回到重认证。更进一步，跨任务泛化可以被严格重述为**任务空间的覆盖/量化问题**：给定任务族的覆盖数 N(ε)，只要为每个 ε-网中心认证一张证书，任何距中心 ≤ε 的任务都能以 L_c·ε 的损失复用。一句话：**泛化不是「模型见过很多任务」，而是「任务空间被证书覆盖到多细」。**

**灵感 3（耦合 → 位姿是任务无关的公共分母，也是迁移的公共风险项）**：位姿/状态是几何证书跨任务共享的唯一公共接口：导航、抓取、全身操作都在同一个 `m(x)` 上做判断。但位姿误差的分布是**任务条件**的——快速运动、动态遮挡、低纹理、不同传感器配置都会改变它。因此跨任务迁移证书时，必须同时迁移「位姿误差模型」：要么在目标任务上证明条件覆盖仍 ≥1−β，要么支付一个位姿迁移 gap，要么用少量目标样本做 few-shot 重校准。否则会出现最隐蔽的失效：**证书本身迁移成功，但它赖以成立的位姿覆盖在目标任务上已经失效**。一句话：**证书迁移可以打折，位姿覆盖不能打折；两者必须同时持证，否则就是双重迁移的静默漏洞。**

**耦合升级**：PoCE（位姿证书引擎）把多源位姿估计编译成带覆盖保证的置信集、位姿租约与鲁棒 margin；TCE（迁移证书引擎）把 CKB 检索升级为带任务距离的迁移许可与负迁移拒绝；PTV（位姿-迁移验证器）在仿真里枚举任务族、位姿退化与任务切换，把反例回灌 CKB/SCV。四层架构由 v8 的「人格 + 并发证书层」升级为 v9 的「人格 + 并发 + 位姿证书层 + 迁移许可层」。

## 1. 形式化定义（增量：定义 44–49）

**定义 44（位姿证书与覆盖-锐度代数）**：位姿估计器输出点估计 x̂_t 与置信集 X̂_t^β ⊆ X（X 可为 SE(3) 或状态流形），要求在标定分布下 P(x_t∈X̂_t^β) ≥ 1−β。位姿证书 P_t=(x̂_t, X̂_t^β, ρ_t, β, τ_t, λ_p, regime)，其中 ρ_t=sup_{x∈X̂_t^β} d(x,x̂_t) 为半径，τ_t 为测量时刻，λ_p 为位姿漂移率，regime∈{static,slow,fast,dynamic,degenerate}。采用按 regime/task 分层的 split-conformal：非一致性分数取测地距离 s_t=d(x_t,x̂_t)，阈值取分层经验分位。**覆盖-锐度代数**：两个独立证书 X̂_A, X̂_B 满足 P(x∈X̂_A)≥1−β_A、P(x∈X̂_B)≥1−β_B，则 (i) 并集覆盖 P(x∈X̂_A∪X̂_B)≥1−min(β_A,β_B)，但半径取 max；(ii) 交集覆盖 P(x∈X̂_A∩X̂_B)≥1−β_A−β_B（union bound），半径取 min。**推论**：并集适合「宁大勿漏」，交集适合「双估计器一致时才收紧」；交集在 β_A+β_B≥1 时无保证，必须失败关闭。**漂移**：位姿租约声明 d(x_t,x_τ)≤v_max(t−τ)+ε_drift，用于定义 45 的时间扣款。

**定义 45（位姿鲁棒证书与位姿杠杆）**：设证书泛函 m:X→R 对位姿 d 是 L_m-Lipschitz 的。**位姿鲁棒边际** m̲(X̂_t)=m(x̂_t)−L_m·ρ_t。**守卫判据**：m̲(X̂_t)−λ·(t−τ_t) ≥ θ 且位姿租约未过期。**命题（不静默高估）**：若 x_t∈X̂_t^β、L_m 在其定义域上有效，则 m(x_t) ≥ m̲(X̂_t)；故以 m̲ 做守卫只会保守、绝不放大真实 margin。**位姿杠杆**：∂(可用动作集)/∂ρ_t ≈ −L_m·(∂m/∂a)^{-1}，即位姿半径是可交易的安全资源；定义**感知-证书价值** VoIC(方向)=L_m·Δρ(方向)，仅当该方向使守卫由「紧」转「松」时值得投入算力（证书驱动的主动位姿估计）。**失败关闭**：若覆盖监控拒绝（见定义 48）或 ρ_t 超阈值，则 m̲ 退回先验保守半径或直接安全保持。

**定义 46（任务度量与迁移证书）**：任务 T=(f_T, O_T, G_T, D_T, E_T, S_T)，分别为动力学/观测/目标/状态分布/本体/传感器-位姿体制。以公共特征映射 ψ 把任务诱导的状态-动作占用测度 μ_T 嵌入度量空间，定义任务距离 δ(T_s,T_t)=W_1(ψ_#μ_{T_s}, ψ_#μ_{T_t})（或 TV/MMD，需给上置信界）。称证书 C_s=(m_s,L_c,domain_s) 对任务 L_c-Lipschitz，若在公共状态集上 |m_s(x)−m_t(x)| ≤ L_c·δ(T_s,T_t)。**迁移证书** m_{s→t}(x̂)=m_s(x̂)−L_c·δ̂−L_m·ρ_t^{(t)}−λΔ。**迁移许可** L=(src,tgt,δ̂,δ_UCB,L_c,expiry,hash)，仅在 δ̂_UCB ≤ δ_max=(m_s−θ−L_m ρ_t−λΔ)/L_c 时签发。**定理（迁移 sound 性）**：若 (i) C_s 在 T_s 上 sound，(ii) δ(T_s,T_t)≤δ̂_UCB，(iii) x_t∈X̂_t^β，(iv) L_c/L_m 有效，则 m_{s→t}(x_t) 是 T_t 上真实 margin 的下界，误用概率 ≤ β+γ（γ 为 δ̂_UCB 的估计失效概率）。**证明**：三角不等式 m_t(x_t) ≥ m_s(x_t)−L_cδ ≥ m_s(x̂)−L_cδ−L_mρ = m_{s→t}；事件「x_t∉X̂」与「δ>δ̂」取并集即得 β+γ。

**定义 47（迁移代数、负迁移拒绝与任务覆盖）**：迁移可组合但距离可加：δ(T_1,T_3)≤δ(T_1,T_2)+δ(T_2,T_3)，故每次迁移消耗预算 b←b−L_cδ̂，b≤0 即拒绝；迁移深度受 b 与 δ̂ 的累计误差约束，禁止「借道任务洗白证书」。**负迁移拒绝**：若 δ̂_LCB>δ_max（用下置信界而非点估计做拒绝更保守），或目标任务 manifest 缺位姿体制，则拒绝迁移并触发 few-shot 重认证。**任务族覆盖**：若任务族 F 在 d_T 下可被 ε-网 {T_i} 覆盖（覆盖数 N(ε)），且每个中心有证书，则任意 T∈F 可迁移，损失 ≤L_cε；因此「跨任务泛化」的样本复杂度 ≈N(ε)·(每中心标定成本)，证书的 Lipschitz 常数决定所需分辨率。**证书粗化**：迁移前把任务特定部分剥离，只保留不变量核（几何/动力学不变量），粗化本身也计入 L_c。

**定义 48（任务条件位姿覆盖与双重迁移）**：边际覆盖 P(x∈X̂)≥1−β 不蕴含任务条件覆盖 P(x∈X̂|T)≥1−β。定义**位姿迁移 gap** g_pose(T_s,T_t)=sup_{A⊆X}|Cov_s(A)−Cov_t(A)|（或按 regime 的 TV）。**双重迁移证书** C_{s→t}^{joint}=(C_s,L,P_t) 仅在 (i) 任务许可 L 有效、(ii) 目标位姿条件覆盖经 Mondrian 校准或 few-shot 重校准 ≥1−β 时成立。**命题（边际覆盖陷阱）**：存在任务族使边际覆盖 =1−β 而某一稀有任务条件覆盖 =0，故跨任务迁移若只查边际覆盖，可在不违反任何「全局指标」的情况下静默失效。**回退**：g_pose 超阈值 → 只用目标任务的少量样本重校准；仍不达标 → 位姿退回保守先验并禁止迁移。

**定义 49（多任务执行时刻证书与任务切换租约）**：执行时刻活跃任务集 A(t) 可切换。执行者同时持有位姿证书 P_t、各活跃任务的迁移证书与租约，定义 C_act(t)=X̂_t^β ∩ ⋂_{T∈A(t)} C_{T} ∩ LeaseSet(t) ∩ PersonaSet。仅当 C_act(t)≠∅ 且 min margin ≥θ 时才致动；否则安全保持。**任务切换租约**：从 T_old 切到 T_new 时，旧证书仅在 grace 窗口内有效，且必须满足 (i) 切换守卫——T_new 的位姿条件覆盖与迁移许可已签发；(ii) 两任务距离 δ(T_old,T_new) 已计入；(iii) 切换瞬间的 margin 不做「先透支后恢复」。**定理（多任务 sound 性）**：若每个活跃任务的位姿覆盖与迁移许可成立、切换守卫通过、且租约未过期，则任意切换点及切换后保持 sound；任一条件失败即安全保持。**注**：把位姿租约与迁移许可放进 IP-58 租约表后，v20 的并发结论自动继承：低关键任务只能读不能写位姿/迁移许可，非干扰条件不变。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 POSE-CERT-ENGINE（位姿证书引擎 PoCE）
1. **多估计器融合**：几何 LIO 与学习式位姿并行，各自输出置信集，按定义 44 的覆盖-锐度代数选择并集（保覆盖）或交集（双一致时收紧）；估计器分歧超阈值即判「degenerate/失配」，失败关闭。
2. **共形位姿标定**：按 regime 与任务簇做 Mondrian split-conformal，输出 ρ、β、漂移率；带覆盖率监控与重校准触发（分布漂移/重尾/новый场景）。
3. **位姿租约与鲁棒 margin**：签发 (x̂,ρ,β,τ,λ_p,regime)，向 IP-51/IP-49 输出 m̲=m(x̂)−L_mρ；位姿租约进入 IP-58 租约表。
4. **证书驱动主动感知**：用 VoIC=L_m·Δρ 给感知算力排序，只在使守卫由紧转松的方向加算力；过载时先保「证书相关」感知，砍非关键语义。

### 2.2 IP-61 TRANSFER-CERT-ENGINE（迁移证书引擎 TCE）
1. **任务嵌入与距离**：从任务 manifest（本体、目标、场景、传感器/位姿体制、动力学参数）构造 ψ(T)，估计 δ̂ 及其置信界 δ̂_UCB/δ̂_LCB（Wasserstein/TV/MMD，bootstrap）。
2. **迁移许可签发**：按定义 46 算 δ_max，签发/拒绝迁移许可；许可带源任务、目标、L_c、δ̂、到期与哈希，进入 CKB 检索路径。
3. **负迁移拒绝与 few-shot 重认证**：δ̂_LCB>δ_max 或位姿体制不匹配即拒绝；边界附近用少量目标样本做「证书重标定 + 覆盖重校准」后重签。
4. **任务族覆盖与粗化**：维护 ε-网与每中心证书，给出任务族覆盖报告；迁移前做证书粗化，只保留不变量核并计入 L_c。

### 2.3 IP-62 POSE-TRANSFER-VALIDATOR（位姿-迁移验证器 PTV）
1. **位姿压力注入**：运动模糊、动态遮挡、低纹理、传感器退化、kidnapping、仿真-现实 gap；学习式估计器的重尾/相关误差。
2. **任务族基准**：导航/抓取/移动操作/人机交互 × 本体与传感器配置变化；跨任务迁移矩阵。
3. **双重迁移审计**：条件覆盖、迁移 gap、δ 估计校准、负迁移拒绝率；任务切换瞬间的证书复用审计。
4. **联合压力测试**：位姿退化 × 任务切换 × 并发交错 × 人格切换，把反例回灌 SCV/CKB，并检验回退路径。

**一句话**：位姿证书的覆盖失效与任务距离的置信界低估，会在「任务切换 × 位姿分布突变」的同一瞬间叠加——证书本身迁移成功，但它赖以成立的位姿覆盖已在目标任务上失效，从而把 v20 的「可见的保守」偷换成「不可见的越界」；因此 E96（不静默高估）与 E99/E101（负迁移与条件覆盖）必须设为红线，并默认回退到「点估计 + 逐任务重认证 + 位姿不确定时直接安全保持」这条永不跨任务、也永不依赖位姿覆盖的底线。

## 2. 关键算法（伪代码）

### IP-60 PoCE：位姿证书、融合与鲁棒化
```
def calibrate_pose_cert(estimator, calib_set, alpha, regime):
    # split-conformal：分数 = 测地距离，按 regime/task 分层维护各自分位
    scores = [geodesic(estimator.predict(z), x_gt) for (z, x_gt) in calib_set]
    q = empirical_quantile(scores, 1 - alpha)      # 秩统计阈值
    return PoseCalib(radius=q, alpha=alpha, regime=regime)

def pose_certificate(estimators, obs, calibs, alpha):
    cands = [PoseCert(e.predict(obs), calibs[e.id], ts=now(),
                      lam_p=e.drift_rate(obs)) for e in estimators]
    if disagree(cands) > tau_disagree:            # 估计器分歧 => degenerate
        return PoseCert.safe_hold(reason="degenerate")
    # 默认并集保覆盖；仅当两估计器独立且 beta 和 < 1 才可交集收紧
    if independent(cands) and sum(c.alpha for c in cands) < 1:
        return intersect_certs(cands)             # 半径 min，覆盖 ≥1-Σβ
    return union_certs(cands)                     # 半径 max，覆盖 ≥1-minβ

def robust_margin(cert_func, pose_cert, theta, t):
    # 位姿扣款 + 时间扣款；只输出下界
    m_pose = cert_func.m(pose_cert.x_hat) - cert_func.L_m * pose_cert.rho
    m_eff  = m_pose - pose_cert.lam_p * (t - pose_cert.tau)
    return m_eff

def value_of_info(pose_cert, guards):
    # 只给使某个守卫由紧转松的感知方向排序
    return {g: guards[g].L_m * expected_radius_reduction(g) for g in guards}

def pose_active_perception(pose_cert, guards, budget):
    plan = []
    for g, voic in sorted(value_of_info(pose_cert, guards).items(),
                          key=lambda kv: -kv[1]):
        if guards[g].near_binding() and budget.can_spend(g.cost):
            plan.append(g); budget.spend(g.cost)
    return plan
```

### IP-61 TCE：任务距离、迁移许可与负迁移拒绝
```
def task_distance(task_s, task_t, samples):
    # 公共特征 psi 上的占用测度 W1；bootstrap 给上下置信界
    d_hat, lo, hi = wasserstein_ci(psi(task_s), psi(task_t), samples)
    return TaskDistance(point=d_hat, lcb=lo, ucb=hi)

def issue_transfer_license(C_s, dist, pose_cert_t, theta, lam_dt):
    b = C_s.m - theta - C_s.L_m * pose_cert_t.rho - lam_dt
    d_max = b / C_s.L_c
    if dist.lcb > d_max:                    # 用下界做拒绝，保守
        return License.REFUSE(reason="negative_transfer", d_max=d_max)
    if dist.ucb > d_max:
        return License.PROVISIONAL(d_max=d_max)   # 需 few-shot 重认证
    return License(src=C_s.src, tgt=dist.tgt, d_hat=dist.point,
                   ucb=dist.ucb, L_c=C_s.L_c, expiry=now()+TTL)

def transferred_margin(C_s, lic, pose_cert_t, t, theta):
    if lic is REFUSE or not lic.valid(t):
        return None                         # 不得使用
    m = C_s.m - C_s.L_c * lic.ucb - C_s.L_m * pose_cert_t.rho \
        - pose_cert_t.lam_p * (t - pose_cert_t.tau)
    return m if m >= theta else None        # 预算不足即停用

def few_shot_recertify(C_s, target, n_samples, alpha):
    # 边界附近：仅用目标任务少量样本重标定证书 + 位姿条件覆盖
    calib = collect(target, n_samples)
    C_t = recalibrate_certificate(C_s, calib)          # 保持不变量核
    P_t = calibrate_pose_cert(target.pose_estimator, calib, alpha,
                              regime=target.regime)     # 条件覆盖
    return C_t, P_t, coverage_test(P_t, target, alpha)
```

def audit_double_transfer(C_s, target, lic, pose_cert, n_episodes):
    # 1) 任务层：实跑目标任务的违例率与 margin 损失
    losses, viol = [], 0
    for ep in sample_tasks(target, n_episodes):
        if transferred_margin(C_s, lic, pose_cert, ep.t, THETA) is None:
            continue
        losses.append(ep.true_margin - transferred_margin(...))
        viol += int(ep.violates)
    # 2) 位姿层：任务条件覆盖（不是边际覆盖）
    cov = conditional_coverage(pose_cert, target, alpha)
    # 3) 结论：任一不达标即撤销许可并回灌
    ok = (viol == 0 and max(losses) <= lic.predicted_loss
          and cov >= 1 - alpha)
    if not ok:
        revoke(lic); feed_back(CKB, target, pose_cert, losses, cov)
    return AuditResult(ok=ok, viol=viol, cov=cov)

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性保证 |
|---|---|---|---|
| IP-60 位姿标定 | 离线 O(N_calib log N_calib) | 分层分数表 O(N_calib) | 可交换性/分层下覆盖 ≥1−β；漂移用租约扣款 |
| IP-60 多估计器融合 | O(#estimators) | 每估计器 O(1) | 并集覆盖 ≥1−minβ；交集覆盖 ≥1−Σβ（Σβ<1） |
| IP-60 鲁棒 margin | O(1)+O(d) | O(1) | m̲≤真实 margin（Lipschitz + 覆盖）→ 只保守不高估 |
| IP-60 主动感知 | O(#guards log #guards) | 计划 O(#guards) | 只重排算力，不改变阈值/不放宽证书 |
| IP-61 任务距离 | O(N log N) 采样 + W1 求解 | 样本 O(N) | δ 的 UCB/LCB 用于签发/拒绝；点估计不直接用于 sound 结论 |
| IP-61 迁移许可 | O(1) 计算 + O(1) 存储 | 每许可 O(1) | δ_UCB≤δ_max 才签发 → 迁移 margin 为下界 |

| IP-61 任务族覆盖 | 离线 O(N(ε)·标定) | ε-网 O(N(ε)) | 覆盖数决定跨任务泛化的分辨率与样本复杂度 |
| IP-62 双重迁移审计 | O(n_episodes·T_ep) 离线 | 轨迹 O(T_ep) | 同时检任务层违例与位姿条件覆盖，任一失败撤销许可 |
| IP-49 位姿鲁棒几何 | O(原有几何) + O(1) | 同 X̂ 表示 | 所有几何 margin 统一扣 L_mρ |
| IP-51 CAR v9 | O(\|E\|) 比较 | 同 L0+租约 | 任一源无效（含迁移 None）即拒绝，无静默回退 |
| IP-58 租约表 | O(log k) | O(k) | 位姿/迁移租约与 v20 租约同构，过期即停用 |

**关键定理（迁移 + 位姿联合 sound 性，重述定义 46）**：若源证书在 T_s 上 sound、δ(T_s,T_t)≤δ_UCB、x_t∈X̂_t^β、且 L_c/L_m 有效，则 m_{s→t}(x_t)=m_s(x̂)−L_cδ_UCB−L_mρ−λΔ 是目标任务真实 margin 的下界，误用概率 ≤β+γ。**证明**：m_t(x_t) ≥ m_s(x_t)−L_cδ ≥ m_s(x̂)−L_cδ_UCB−L_mρ；对「位姿覆盖失效」与「δ 估计失效」取并集即得 β+γ。**推论**：v20 的所有并发/人格结论在本轮自动保持，因为位姿与迁移许可只是新增的**只读约束源**，只会收缩守卫可行域，不会放松任何既有阈值。

| E99 负迁移拒绝 | δ>δ_max 时拒绝率；误接受的不 sound 迁移；迁移深度越界 | ≥99%；0；0 |

| E101 条件覆盖/双重迁移 | 每任务条件覆盖率；最差任务；双重迁移违例；位姿迁移 gap | ≥1−β；≥1−β；0；<10% |
| E102 长时程多任务部署 | 100h 不安全事件；任务切换次数；许可过期/续签；位姿漂移事件 | 0 起；1000 次；100%；全检出 |

回退：E95/E97 位姿覆盖不达标 → 关闭学习式位姿、退回保守先验半径并必要时安全保持；E96 鲁棒 margin 仍被高估 → 增大 L_m 保守系数、缩短位姿租约；E98/E99 迁移不可靠 → 关闭跨任务复用、逐任务重认证；E100 无效率收益 → 放弃迁移、只保留同任务内复用；E101 条件覆盖不足 → 纯收缩到单任务 + 目标样本重校准；任何红线失败 → 全链路熔断回退 v20。

## 5. 风险与缓解（增量）

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 位姿证书只保边际覆盖，任务条件覆盖在稀有任务上失效 | 高 | E95/E101 红线；Mondrian 按 regime/task 分层；任务切换前强制条件覆盖复核；失败即安全保持 |
| 任务距离 δ 被低估（占用测度采样偏差/高维），迁移许可误签 | 高 | E98/E99 红线；用 δ_UCB 签发、δ_LCB 拒绝；bootstrap/MMD 双估计；边界走 few-shot |
| 学习式位姿误差重尾且相关，共形可交换性被破坏 | 高 | 按 regime 分层 + 漂移租约；重尾场景用保守分位；E96 对抗测试；覆盖监控触发重校准 |
| 「证书迁移成功但位姿覆盖失效」的双重迁移静默漏洞 | 高 | 定义 48 联合证书；E101 专项；任何一层失败即撤销许可并回灌 |
| 任务切换瞬间复用旧证书，恰好跨越位姿分布突变 | 高 | 任务切换租约 + grace 窗口内重验；切换守卫要求新任务位姿条件覆盖已签发 |
| 迁移链式复用导致 δ 累计误差被稀释/洗白 | 中-高 | 迁移预算 b 与三角不等式；限制迁移深度；每跳重签许可并记录源 ID |
| 位姿主动感知挤占安全监控算力 | 中 | VoIC 只重排非关键感知；HI 模式硬隔离安全监控与位姿证书预算 |
| 任务嵌入/距离估计本身成为新单点（估计器偏差） | 中 | 距离估计器与证书解耦；用多个距离族取最保守 UCB；离线审计 |

## 6. 本轮最大风险

**一句话**：位姿证书的覆盖失效与任务距离的置信界低估，会在「任务切换 × 位姿分布突变」的同一瞬间叠加——证书本身迁移成功，但它赖以成立的位姿覆盖已在目标任务上失效，从而把 v20 的「可见的保守」偷换成「不可见的越界」；因此 E96（不静默高估）与 E99/E101（负迁移与条件覆盖）必须设为红线，并默认回退到「点估计 + 逐任务重认证 + 位姿不确定时直接安全保持」这条永不跨任务、也永不依赖位姿覆盖的底线。
