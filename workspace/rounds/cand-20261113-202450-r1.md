# 第 69 轮（承接第 68 轮「CALM-RAS」IP-243~252；灵感循环新循环第 2 轮；本轮灵感：「原型验证」×「关节驱动」）

> R68 CALM-RAS 把标定升为一等公民，但其自陈风险恰恰是这套范式无法自洽的原罪：**标定是自指的**——用同一批传感器去估计"这批传感器是否可信"，慢故障只要落进标定带宽，就会被当作漂移"标好"，越标定越隐形。根因不是滤波器不够好，而是**信息不足**：被动观测只给出 c 与 φ 叠加后的一个投影，单凭它，任何算法都无法把"传感器歪了"与"传感器坏了"分开（不可辨识）。
>
> 本轮两块灵感恰好补上两样东西：**原型验证**给出一个外部的、非自指的参考真值（计量锚 / 故障原型流形 / 硬件在环验证），**关节驱动**给出一个可以主动施加的、物理独立的激励与观测通道（本体感知 + 持续激励）。核心命题：
>
> **可辨识性先于标定：只有当主动关节激励使漂移 c 与故障 φ 在信息几何上可分（κ_id ≥ κ_min）时，才允许把残差吸收为标定；不可辨识时一律按故障保守处理——PROVE-RAS（Prototype-Referenced Online Validation & Excitation）。**
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「**我凭什么相信这个『准』不是把故障标进去了**」——把标定从"能解释就吸收"降级为"可辨识才吸收"。

## 0. 直觉与动机

**灵感 1（原型验证 → 破自指：需要一个外部真值锚）**
R68 的 COF 像一个只照镜子的人：它只能看见"当前读数与历史读数的不一致"，而慢故障与慢漂移在镜子里长得一模一样。计量学早就解决过这个问题——任何可信测量都必须溯源到一个**外部参考件**（量块、标准电阻、校准球）。给闭环放一个物理可溯源的原型参考件（几何、质量、刚度、反射率已知），周期性去"碰一下"，就得到一条不依赖被检验传感器的真值链：参考件读数与标定预测一致、而普通观测仍在偏，是真漂移；参考件本身也偏、且偏离方向与某个故障原型流形同向，则故障已经把"参考与传感器"一起污染（共模），必须升级为故障而非继续标定。原型的第二层含义是**故障原型（fault prototype）**：把已知故障模式（零偏、增益、回差、摩擦、编码器卡死）表示为参数流形，残差轨迹向哪个流形漂移，比"残差是否超阈值"更早、更可分。

**灵感 2（关节驱动 → 主动制造可辨识性，而非被动等它出现）**
R68 只在"静态段"被动等待信息，但静止段恰恰最不可辨识：所有力都应为零，零偏与真实负载无法区分。机器人真正的优势是它**能自己动**：让关节在安全包络内做一组设计好的微小激励（变构型、变负载、变速度、轻触参考件），同一参数在不同工况下留下不同指纹——零偏是加性的（与负载无关），摩擦/回差是负载-速度依赖的，外参漂移是几何依赖的。激励把"一个方程解两个未知数"变成"一组方程超定求解"，这是**可辨识性（identifiability）**的来源，不是算法能凭空创造的。关节驱动同时提供第二重独立观测：指令力矩 vs 实测关节力矩 vs 实际加速度的一致性残差 r_drv，是一条不经过视觉、不经过世界模型的物理通道，可独立校验 R67 的 WM 漂移。

**灵感 3（两者合流 → 一条更根本的安全不变式）**
R68 的不变式是"标定速率受限"（物理防线），它只能防"快故障被吸收"，防不住"慢故障被吸收"。R69 升级为"**可辨识性受限**"（信息防线），直接回答"这条残差到底该记在 c 账上还是 φ 账上"。于是得到新纪律：
> **可辨识才标定，不可辨识即按故障（identifiable-or-fault）。**
它与 R68 的"不确定即收紧"同构，但更根本：R68 管"标定结果可不可信"，R69 管"标定这个动作该不该发生"。

**灵感 4（原型验证的第三种含义 → 部署前的物理验证关）**
R68 的 CAC 五关全在回放/离线数据上做，仍可能过拟合到 Sim2Real 缝隙。R69 增加第六关：候选适配器/标定更新必须先在真机上跑一段**硬件在环（HIL）原型验证协议**（安全激励 + 参考件比对 + 故障注入 canary），通过才允许原子换装。这把"原型验证"从研发阶段的一次性活动，变成部署环路里的一个可审计关卡。

**灵感 5（对 R66/R67/R68 风险的对症下药）**
- R68 原罪（慢故障被标定吸收）：IID + IIE 把"能解释就吸收"改为"可辨识才吸收"；FPB 用原型流形几何检出孵化中故障；PRA 打破自指；
- R67 黑箱（WM 漂移误放宽）：r_drv 提供不经过神经网络的物理地线，做**异源**校验（区别于 R68 引理 15 的同源共模抵消）；刚体动力学漂移本身可独立诊断；
- R66 欺骗（假笑/僵硬表情）：把情绪判断挂到"行为-驱动"一致性上——真实情绪表达往往伴随可测的动作/顺应性响应，可通过轻推测顺应性，但这只是弱证据，不宣称解决；主要贡献是给"行为上下文"一个不可轻易伪造的物理基座；
- R65 H_sensor：故障原型库给 H_sensor 一个参数化、可解释的表示，替代纯后验赌。

## 1. 形式化定义（增量：定义 293–309）

**定义 293（PROVE-RAS 总览）** PROVE-RAS = (PRA, JDE, IID, IIE, FPB, PVG, CALM-RAS†)。三条新不变式：
(i) **外部锚不变式**：任何 c 更新必须伴随一次年龄 < T_ref 的参考件测量，锚过期即冻结标定；
(ii) **可辨识性不变式**：IIE 仅沿可辨识子空间更新 c；不可辨识方向不吸收、只抬升 U；
(iii) **激励安全不变式**：任何激励 ξ ∈ Ξ_safe，且执行期间任务安全裕度不下降（λ 冻结在激励前值以上）。

**定义 294（原型参考锚 PRA）** 参考件 R* 具有可溯源真值 g*（几何尺寸、质量、刚度、表面反射率等）。测量模型 y_ref = h_ref(c, φ) + n_ref，n_ref ~ 𝒩(0, R_ref)。锚的计量不确定性 u_ref = tr(Σ_ref) 沿溯源链传播；锚年龄 a_ref = t − t_last_ref。锚新鲜 ⇔ a_ref ≤ T_ref ∧ u_ref ≤ ū_ref。参考件可被机械臂主动触碰/扫描（见 JDE），不要求一直可见。

**定义 295（增广参数状态）** x_t = (c_t, φ_t) ∈ ℝ^{d_c + d_φ}。c 为 R68 的 12 维标定慢变量；φ 为故障参数（力零偏 b_F^fault ∈ ℝ³、通道增益 g ∈ ℝ^M、回差 β ∈ ℝ^J、摩擦 f_v/f_c ∈ ℝ^{2J}、失效掩码等）。c 的动力学慢（τ_thermal ≈ 10³ s），φ 可更慢（老化）或更快（冲击）；二者在观测上可叠加，故单帧不可分——这是 R68 盲点的形式化。

**定义 296（关节驱动观测）** 关节级本体感知 o_jd = (q, q̇, q̈, τ_cmd, τ_meas, i_m)。刚体动力学 τ_meas = M(q)q̈ + C(q,q̇)q̇ + g(q) + F(q,q̇) + τ_ext。关节驱动残差 r_drv = τ_cmd − τ̂_meas（τ̂ 由辨识模型给出）；指令-响应一致性 r_resp = q̈_meas − q̈_pred(τ_cmd)。r_drv 与视觉/WM 完全异构，构成独立校验通道。

**定义 297（关节驱动激励与持续激励条件）** 激励策略 ξ 在窗口 [t, t+T_e] 内对关节施加设计轨迹（构型扫掠、负载阶跃、速度扫描、轻触参考件），生成回归矩阵 Φ_e = [∂h/∂c, ∂h/∂φ]。**持续激励（PE）条件**：λ_min(Φ_eᵀ Φ_e / T_e) ≥ γ_pe > 0。安全激励集 Ξ_safe = {ξ : 关节力矩/速度/接触力在安全包络内，且任务可中断性 ≥ 阈值}。

**定义 298（可辨识性裕度）** 局部线性化下 Fisher 信息 I = Φ_eᵀ R⁻¹ Φ_e，按 c/φ 分块 I = [[I_cc, I_cφ], [I_φc, I_φφ]]。**可辨识性裕度** κ_id = λ_min(D_φ^{−1/2} S_φ D_φ^{−1/2})，其中 S_φ = I_φφ − I_φc I_cc⁻¹ I_cφ 为 φ 的 Schur 补，D_φ 为 φ 的先验尺度归一化。κ_id ≥ κ_min ⇔ 该激励窗口内 c 与 φ 局部可辨识（分离误差有 CRB 上界）；κ_id < κ_min ⇔ 不可辨识，任何估计器都无法在窗口内可靠分离（信息论下界）。**关键：κ_id 是激励 ξ 的函数，不是算法的函数。**

**定义 299（可辨识门控估计器 IIE）** 用投影卡尔曼/子空间 EKF 替代 COF 的无约束更新：c 的更新做投影 P_id，仅保留与不可辨识方向正交的分量——ĉ ← ĉ + P_id K(y − h(ĉ))，P_id = I − U_0 U_0ᵀ，U_0 为 I_cc 中与 φ 混淆的小特征值方向。沿不可辨识方向：不更新 c，令 Σ_c 沿 U_0 膨胀（U ↑），并把该方向能量转记入 φ 的故障证据。**语义：不知道记谁账上的量，就不入 c 账。**

**定义 300（故障原型库 FPB）** 每个故障模式 k 对应参数流形 M_k = {g_k(ψ) : ψ ∈ Ψ_k}（零偏=仿射子空间、增益=乘法子空间、回差=滞环带、摩擦=非线性曲面、失效=坐标子空间）；漂移流形 M_c = {c : ‖c‖ ≤ c_max}。原型距离 d_k(r) = dist(r, M_k)；用残差轨迹的切向速度：若 dr/dt 向 M_k 的切向投影占优、且到 M_c 的测地距离增速为正，则判**孵化中故障（incipient）**。原型验证 = 用已知故障样本离线校准 M_k 的覆盖半径 ρ_k，新观测须落在某 M_k 的 ρ_k 内才认领，否则记"未知"而非硬分。

**定义 301（原型验证关 PVG）** 在 CAC 五关后追加第六关：
6. **物理原型验证**：候选 M′ 在真机上执行 Ξ_safe 内的 HIL 协议（时长 T_pvg，含参考件比对与注入 canary），要求 (a) 参考件预测误差 ≤ ε_ref；(b) 故障检出率与金标回放差异 ≤ 1%；(c) 全程安全裕度 ≥ λ_min 且无急停；(d) 激励后系统辨识参数漂移 ≤ ε_drift（防"验证动作本身把系统磨损了"）。任一不过 → 拒绝并记入 ℰ_pvg。

**定义 302（锚溯源链与新鲜度）** 溯源链 R* → 出厂计量 → SI 单位；u_ref 按 GUM 传播；锚过期/超不确定 ⇒ 标定冻结且 λ_floor 抬升。参考件被遮挡/移出工作区 ⇒ 触发"锚缺失"降级，禁止吸收残差。

**定义 303（主动保守纪律）** λ_floor(u_ref, κ_id, U) = max(0.6, 0.8·1[κ_id < κ_min ∨ a_ref > T_ref ∨ U > τ_cal])。统一收编 R66（face_unobservable）、R67（wm_drift）、R68（U > τ_cal），并新增"不可辨识/锚失效"两个触发源。语义：**信息不足与测量不可信同级，都只导向收紧。**

**定义 304（激励调度）** ξ* = argmax_{ξ∈Ξ_safe} E[ΔI(ξ)] s.t. task_risk(ξ) ≤ r_budget, interruptibility ≥ 1−δ。即在安全与任务预算内最大化信息增益；无可行激励时 κ_id 保持低，系统按定义 303 保守。

**定义 305（扩展残差）** r_t = (r_geo, r_sync, r_zero, r_emo, r_wm, **r_drv, r_ref, r_proto**)：新增关节驱动一致性、参考件残差、原型距离向量。r_drv 独立校验 WM（定义 309）。

**定义 306（AIC-PROVE 干扰集）** ℰ_PROVE = ℰ_CALM × ℰ_anchor × ℰ_excite × ℰ_ident；ℰ_anchor = {锚欺骗（仿制参考件/遮挡）、锚松动、共模热污染}；ℰ_excite = {激励诱发磨损、激励被任务拒绝、激励观察者效应}；ℰ_ident = {可辨识性饥饿、错误原型覆盖、激励下故障伪装}。

**定义 307（J_PROVE 证书）** J_PROVE = (J_CALM, anchor_id, a_ref, u_ref, κ_id, excitation_log_hash, proto_dist_vec, pvg_verdict)。Valid ⇔ Valid(J_CALM) ∧ a_ref ≤ T_ref ∧ κ_id ≥ κ_min（用于标定吸收）∧ pvg_verdict = PASS。

**定义 308（管线）** 离线：设计参考件与溯源链 → 采集已知故障训练原型流形 M_k → 辨识名义模型。在线：例行任务中穿插参考件触碰与微型激励 → IIE 门控更新 → FPB 孵化检测 → 影子适配器 → PVG 物理验证 → 原子换装。

**定义 309（关节驱动校验 WM）** 用关节动力学模型给出物理预测 ŝ_jd；WM 预测 ŝ_wm 与 ŝ_jd 的差异若超过由 r_drv 不确定性给出的阈值，则判 wm_drift。因 r_drv 不经过视觉/神经网络，可作为 WM 黑箱的"物理地线"；这是**异源**校验，与 R68 引理 15 的同源共模抵消互补。

```python
# IP-253 PRA：原型参考锚（外部真值 + 溯源 + 新鲜度）
class PrototypeReferenceAnchor:
    def __init__(self, g_star, trace, T_ref, u_bar):
        self.g_star, self.T_ref, self.u_bar = g_star, T_ref, u_bar
        self.t_last, self.S_ref = -np.inf, trace.initial_cov()
        self.id = trace.anchor_id

    def measure(self, obs):                    # 触碰/扫描参考件
        self.t_last = obs.t
        y = self.sensor_model(obs, self.g_star)
        self.S_ref = self.propagate(self.S_ref)
        return y, self.R_ref

    def fresh(self, t):
        a = t - self.t_last
        return a <= self.T_ref and np.trace(self.S_ref) <= self.u_bar


# IP-254 JDE：关节驱动激励（安全包络内的信息最大化）
class JointDriveExcitation:
    def plan(self, task, safety, budget):
        cands = self.maneuvers(safety.envelope)     # 构型/负载/速度/触锚
        ok = [x for x in cands
              if safety.task_risk(x) <= budget
              and safety.interruptibility(x) >= 1 - self.delta]
        return max(ok, key=self.expected_info_gain, default=None)

    def pe_ok(self, xi_log):
        Phi = self.regressor(xi_log)
        return np.linalg.eigvalsh(Phi.T @ Phi / len(xi_log))[0] >= self.gamma_pe


# IP-255/256 IID + IIE：可辨识性判别 + 门控更新
class IdentifiabilityGatedEstimator:
    def step(self, y, H, R, xi_log, anchor_ok):
        I = self.fisher(H, R, xi_log)               # Phi^T R^-1 Phi
        Icc, Icp, Ipp = I[:12,:12], I[:12,12:], I[12:,12:]
        S = Ipp - Icp.T @ pinv(Icc) @ Icp           # phi 的 Schur 补
        kappa = self.normalized_min_eig(S)
        if (not anchor_ok) or kappa < self.K_MIN:
            self.freeze_c()                         # 不可辨识 → 不入 c 账
            self.inflate_confounded(I)              # U↑，转记故障证据
            return self.c, self.S, kappa, 'UNIDENTIFIABLE->FAULT'
        P = self.identifiable_projector(I)          # 仅可辨识方向
        self.c = self.c + P @ self.K @ (y - self.h(self.c))
        self.S = self.cov_update(I)
        return self.c, self.S, kappa, 'ABSORB'


# IP-257 FPB：故障原型流形 + 孵化检测
class FaultPrototypeBank:
    def classify(self, r_hist):
        d = {k: dist(r_hist, M_k) / rho_k
             for k, (M_k, rho_k) in self.manifolds.items()}
        k_best = min(d, key=d.get)
        if d[k_best] > 1.0:
            return 'UNKNOWN', d[k_best], False     # 覆盖外不硬分
        incipient = self.tangent_vel_toward(r_hist, M_k) > self.v_inc \
                    and self.geodesic_to(M_c).deriv > 0
        return k_best, d[k_best], incipient


# IP-258 PVG：第六关（硬件在环物理原型验证）
class PrototypeValidationGate:
    def run(self, cand, env):
        xi = env.excitation.plan(env.task, env.safety, env.budget)
        if xi is None: return False, {'reason': 'no_safe_excitation'}
        log = env.execute(xi)                       # 真机 HIL，含触锚与 canary
        verdict = {
            'ref_error': ref_error(log) <= self.EPS_REF,
            'parity':    abs(detect_rate(log) - self.gold_rate) <= 0.01,
            'safety':    env.safety.min_margin(log) >= self.LAM_MIN,
            'no_wear':   drift_after(log) <= self.EPS_DRIFT,
        }
        return all(verdict.values()), verdict


# IP-262 主闭环：PROVE-RAS round
def PROVE_RAS_round(M, obs, task):
    # 0) 锚新鲜度（外部真值前置）
    anchor_ok = M.pra.fresh(M.t)
    if not anchor_ok:
        M.pra.measure(obs)                          # 尝试补一次参考测量
        anchor_ok = M.pra.fresh(M.t)

    # 1) MTM 一次前向（继承 R68 CALM）
    z, o = M.mtm.forward(obs_pack, M.a_prev, M.scene_ctx)

    # 2) 机会式关节激励 + 本体感知（信息制造）
    xi = M.jde.plan(task, M.safety, M.info_budget)
    xi_log = M.jde.execute(xi, M.env) if xi else None
    o_jd = M.jd_sense(obs)                          # q, qdot, tau_cmd, tau_meas

    # 3) IID：Fisher/Schur 可辨识性裕度
    kappa = M.iid.margin(o, o_jd, xi_log)

    # 4) IIE：可辨识才标定（不可辨识即按故障）
    c, U, kappa, verdict = M.iie.step(
        residuals(o, o_jd), M.H, M.R, xi_log, anchor_ok)

    # 5) FPB：原型流形 / 孵化检测
    r_hist = M.residual_log.push(residuals(o, o_jd))
    proto, d_proto, incipient = M.fpb.classify(r_hist)

    # 6) CFA/EFS 继承：条件于 c，并叠加原型与可辨识证据
    joint_post = M.cfa(o['pi'], c, U, proto, incipient)

    # 7) r_drv 异源校验 WM（R67 物理地线）
    wm_drift = (kl_div(o['pi'], M.mtm.rollout(z, M.ach.propose_actions(...), 1)[0]['pi'])
                > M.tau_wm) or M.wm_cross_check(o_jd, z)

    # 8) 认证前缀 + 风险缩放（新增锚/可辨识下限）
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), joint_post, ...)
    if U > M.tau_cal or kappa < M.K_MIN or not anchor_ok:
        k = min(k, M.k_cal_shrink(kappa))
    lam = max(M.efs.risk_scale(joint_post),
              M.lam_floor(anchor_ok, kappa, U))     # 定义 303
    tau = M.pi_sigma.prefix_dispatch(A[:k]) * lam

    # 9) 影子学习 → PVG 物理原型验证 → 原子换装
    if M.cac.due():
        if M.pvg.run(M.shadow, M.env)[0]:
            M.cac.commit(M.shadow)
        else:
            M.cac.reject('pvg')
    return k, lam, joint_post, (c, U, kappa, proto)
```

## 3. 推导

**引理 16（可辨识性分离界）** 在局部线性化与持续激励裕度 κ_id 下，对慢漂移 H_c 与慢故障 H_φ 两个假设，参数分离度 δ = ‖c − φ‖ / σ，Neyman–Pearson 误差指数满足 Pe ≤ exp(−T_e·κ_id·δ² / 2)（忽略常数）。当 κ_id = 0 时两假设在窗口上**观测等价**，任何检验的 Pe ≥ 1/2。结论：**R68 的慢故障盲区不是阈值问题，而是 κ_id = 0 的信息不可辨识；R69 用激励把 κ_id 抬到 κ_min 以上。**

**引理 17（慢故障的几何可检性）** R68 引理 13 只覆盖 ω_f ≥ 3ω_cal。对 ω_f < ω_cal，若故障原型流形与漂移流形分离 δ_sep > 0 且激励信息率 ι > 0，则检测延迟 T_det ≤ δ_sep / ι + O(1/ι)；即慢故障以"延迟"换"可检"，而非像 R68 那样被直接吸收。系：**频谱不可分 ≠ 参数不可分**，原型流形分离度是慢故障的"几何指纹"。

**引理 18（激励-安全-可辨识三角）** 信息增益 ΔI(ξ) 关于激励幅度/工况多样性单调不减，任务风险 task_risk(ξ) 亦单调不减；在安全包络 Ξ_safe 下可达 κ_id^max = max_{ξ∈Ξ_safe} κ_id(ξ)。若 κ_id^max < κ_min，则任何调度都无法获得可辨识性，系统只能永久保守（定义 303）——**这是设计约束而非算法缺陷：此时必须改进参考件/工况设计，而非加大滤波增益。** 另需扣除激励的观察者效应：激励本身改变 φ（磨损），故净收益 = ΔI − c_wear·dφ/dn（定义 301-d）。

**定理 16（PROVE-RAS 端到端风险一致性）** 在 A87–A94 与 A95–A98（锚可溯源、激励 PE、原型覆盖、激励安全）下：
1. P(|τ_cmd − τ*| > ε) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_vqa + α_cal + **α_id + α_anchor + α_pvg**；
2. **慢故障被吸收概率** P(absorb φ | ω_f < ω_cal) ≤ P(κ_id < κ_min) + exp(−T_e·κ_id·δ²/2)——R68 的"越标定越隐形"被拆成"不可辨识则拒绝吸收（转保守）"+"可辨识则指数级可分"两项，原罪被**有界化**，而非假装消除；
3. κ_id < κ_min ∨ a_ref > T_ref ⇒ λ_risk ≥ 0.8 ∧ 冻结 c ∧ k 收缩——信息不足永远导向收缩；
4. PVG 通过后上线，有害适配器上线概率 ≤ (1 − r_pvg)(1 − r_canary)·p_h。

**定理 17（PVG 的 Sim2Real 收敛）** 若候选适配器在真机 HIL 协议上失败概率为 q，则 n 次独立 canary 用例的漏检概率 ≤ (1 − r_pvg)ⁿ；且 HIL 协议覆盖 Ξ_safe 的关键工况，使"回放通过但真机失败"的条件概率 ≤ ε_s2r。提交窗口内 λ 与 k 冻结、回滚路径同构 ⇒ 换装无控制突变。

## 6. 本轮最大风险

**一句话**：PROVE-RAS 把安全押在"主动激励足以制造可辨识性"上，但激励同时受安全包络与任务占用的双重挤压——在长期人机共处或高精度任务里激励预算可能趋近于零，κ_id 长期低于阈值，系统将退化为"永久保守 + 冻结标定"的僵化机器人，**可辨识性饥饿（identifiability starvation）是这套方案的原罪：为了不掉进"标定吸收故障"的坑，它可能选择"永远不标定"。**

**次级风险与缓解**：
1. **锚单点失效**：外部真值只有参考件一条链 → 溯源链 + 物理不可克隆特征 + 多锚冗余 + 锚缺失即冻结；
2. **原型覆盖不全**：新故障可能落在所有 M_k 的 ρ_k 之外 → 判 UNKNOWN 并触发保守，绝不硬分；
3. **观察者效应**：激励诱发磨损，估计动作改变被估对象 → 净收益扣减 + ε_drift 约束 + 激励预算上限；
4. **PVG 误拒拖慢适应** → 分级 PVG（轻量例检 + 周期全检）+ 误拒率监控；
5. **激励本身的安全**：运动/接触在有人场景可能危险 → Ξ_safe 硬约束、任务可中断性前置、λ 冻结；
6. **κ_id 估计偏差**：线性化/噪声模型错误导致"假可辨识" → 保守先验 + 后验残差检验 + 原型交叉验证。

## 3. 关键算法伪代码

```python
# IP-253 PRA：参考锚（外部真值 + 溯源 + 新鲜度）
class PrototypeReferenceAnchor:
    def measure(self, obs):
        self.t_last = obs.t
        self.S_ref = self.propagate(self.S_ref)
        return self.sensor_model(obs, self.g_star), self.R_ref
    def fresh(self, t):
        return (t - self.t_last <= self.T_ref) and (np.trace(self.S_ref) <= self.u_bar)

# IP-254 JDE：安全包络内信息最大化的关节激励
class JointDriveExcitation:
    def plan(self, task, safety, budget):
        ok = [x for x in self.maneuvers(safety.envelope)
              if safety.task_risk(x) <= budget
              and safety.interruptibility(x) >= 1 - self.delta]
        return max(ok, key=self.expected_info_gain, default=None)
    def pe_ok(self, log):
        Phi = self.regressor(log)
        return np.linalg.eigvalsh(Phi.T @ Phi / len(log))[0] >= self.gamma_pe

# IP-255/256 IID + IIE：可辨识性判别 + 门控更新
class IdentifiabilityGatedEstimator:
    def step(self, y, H, R, xi_log, anchor_ok):
        I = self.fisher(H, R, xi_log)
        Icc, Icp, Ipp = I[:12,:12], I[:12,12:], I[12:,12:]
        kappa = self.normalized_min_eig(Ipp - Icp.T @ pinv(Icc) @ Icp)
        if (not anchor_ok) or kappa < self.K_MIN:
            self.freeze_c(); self.inflate_confounded(I)
            return self.c, self.S, kappa, 'UNIDENTIFIABLE->FAULT'
        P = self.identifiable_projector(I)
        self.c = self.c + P @ self.K @ (y - self.h(self.c))
        return self.c, self.cov_update(I), kappa, 'ABSORB'

# IP-257 FPB：故障原型流形 + 孵化检测
class FaultPrototypeBank:
    def classify(self, r_hist):
        d = {k: dist(r_hist, M_k) / rho_k for k, (M_k, rho_k) in self.manifolds.items()}
        k_best = min(d, key=d.get)
        if d[k_best] > 1.0: return 'UNKNOWN', d[k_best], False
        incipient = (self.tangent_vel_toward(r_hist, M_k) > self.v_inc
                     and self.geodesic_to(M_c).deriv > 0)
        return k_best, d[k_best], incipient

# IP-258 PVG：第六关（真机 HIL 物理原型验证）
class PrototypeValidationGate:
    def run(self, cand, env):
        xi = env.excitation.plan(env.task, env.safety, env.budget)
        if xi is None: return False, {'reason': 'no_safe_excitation'}
        log = env.execute(xi)
        v = {'ref_error': ref_error(log) <= self.EPS_REF,
             'parity':    abs(detect_rate(log) - self.gold_rate) <= 0.01,
             'safety':    env.safety.min_margin(log) >= self.LAM_MIN,
             'no_wear':   drift_after(log) <= self.EPS_DRIFT}
        return all(v.values()), v

# IP-262 主闭环
def PROVE_RAS_round(M, obs, task):
    anchor_ok = M.pra.fresh(M.t) or (M.pra.measure(obs) and M.pra.fresh(M.t))
    z, o = M.mtm.forward(obs_pack, M.a_prev, M.scene_ctx)          # 1) 继承 CALM
    xi = M.jde.plan(task, M.safety, M.info_budget)                 # 2) 制造信息
    xi_log = M.jde.execute(xi, M.env) if xi else None
    o_jd = M.jd_sense(obs)
    kappa = M.iid.margin(o, o_jd, xi_log)                          # 3) 可辨识裕度
    c, U, kappa, verdict = M.iie.step(                             # 4) 门控标定
        residuals(o, o_jd), M.H, M.R, xi_log, anchor_ok)
    proto, d_proto, incipient = M.fpb.classify(                    # 5) 原型/孵化
        M.residual_log.push(residuals(o, o_jd)))
    joint_post = M.cfa(o['pi'], c, U, proto, incipient)            # 6) 继承 CFA
    wm_drift = (kl_div(o['pi'], M.mtm.rollout(z, M.ach.propose_actions(...), 1)[0]['pi'])
                > M.tau_wm) or M.wm_cross_check(o_jd, z)           # 7) r_drv 异源校验
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), joint_post, ...)
    if U > M.tau_cal or kappa < M.K_MIN or not anchor_ok:
        k = min(k, M.k_cal_shrink(kappa))
    lam = max(M.efs.risk_scale(joint_post), M.lam_floor(anchor_ok, kappa, U))
    tau = M.pi_sigma.prefix_dispatch(A[:k]) * lam                  # 8) 风险缩放
    if M.cac.due():                                                # 9) PVG + 换装
        M.cac.commit(M.shadow) if M.pvg.run(M.shadow, M.env)[0] else M.cac.reject('pvg')
    return k, lam, joint_post, (c, U, kappa, proto)
```

## 4. 推导

**引理 16（可辨识性分离界）** 局部线性化 + PE 裕度 κ_id 下，慢漂移 H_c 与慢故障 H_φ 的参数分离度 δ = ‖c − φ‖/σ，Neyman–Pearson 误差 Pe ≤ exp(−T_e·κ_id·δ²/2)；κ_id = 0 ⇒ 两假设观测等价，Pe ≥ 1/2。**R68 的盲区是 κ_id = 0 的信息不可辨识，不是阈值问题**；R69 用激励把 κ_id 抬过 κ_min。

**引理 17（慢故障的几何可检性）** 对 ω_f < ω_cal（R68 引理 13 覆盖不到），若原型流形分离 δ_sep > 0 且激励信息率 ι > 0，则 T_det ≤ δ_sep/ι + O(1/ι)。慢故障以"延迟"换"可检"，而非被吸收。系：频谱不可分 ≠ 参数不可分。

**引理 18（激励-安全-可辨识三角）** ΔI(ξ) 与 task_risk(ξ) 均随激励幅度/多样性单调不减；κ_id^max = max_{ξ∈Ξ_safe} κ_id(ξ)。若 κ_id^max < κ_min，任何调度都无法可辨识，系统只能永久保守——这是设计约束，须改进参考件/工况，而非加大滤波增益。净收益须扣除观察者效应 c_wear·dφ/dn。

**定理 16（端到端风险一致性）** A87–A98 下：
1. `P(|τ_cmd − τ*| > ε) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_vqa + α_cal + α_id + α_anchor + α_pvg`；
2. `P(absorb φ | ω_f < ω_cal) ≤ P(κ_id < κ_min) + exp(−T_e κ_id δ²/2)`——R68 原罪被有界化：不可辨识则拒绝吸收（转保守），可辨识则指数级可分；
3. `κ_id < κ_min ∨ a_ref > T_ref ⇒ λ ≥ 0.8 ∧ 冻结 c ∧ k 收缩`；
4. 有害适配器上线概率 ≤ `(1 − r_pvg)(1 − r_canary)·p_h`。

**定理 17（PVG 的 Sim2Real 收敛）** 真机失败概率 q，n 次 canary 漏检 ≤ `(1 − r_pvg)ⁿ`；HIL 覆盖 Ξ_safe 关键工况使"回放过、真机败"条件概率 ≤ ε_s2r；提交窗口冻结 λ/k、回滚同构 ⇒ 无控制突变。

## 7. 本轮最大风险

**一句话**：PROVE-RAS 把安全押在"主动激励足以制造可辨识性"上，但激励同时受安全包络与任务占用的双重挤压——在长期人机共处或高精度任务里激励预算可能趋近于零，κ_id 长期低于阈值，系统将退化为"永久保守 + 冻结标定"的僵化机器人，**可辨识性饥饿是这套方案的原罪：为了不掉进"标定吸收故障"的坑，它可能选择"永远不标定"。**

**次级风险与缓解**：锚单点失效（溯源链 + 物理不可克隆 + 多锚冗余 + 缺失即冻结）；原型覆盖不全（判 UNKNOWN 并保守，绝不硬分）；观察者效应（净收益扣减 + ε_drift + 激励预算上限）；PVG 误拒拖慢适应（分级 PVG + 误拒监控）；激励安全（Ξ_safe 硬约束 + 可中断性前置 + λ 冻结）；κ_id 假可辨识（保守先验 + 后验残差检验 + 原型交叉验证）。
