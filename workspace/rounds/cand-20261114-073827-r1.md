# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；灵感循环第 1 轮；本轮灵感：「人机协作」×「场景理解」）

> R69 把 R68 的标量不确定性一分为二：aleatoric 沿用「不确定就收紧」的铁律，epistemic 交给「流匹配多模态策略 + 主动多模态交互」去消解；并用流似然（FMA）当标定不可吸收的第二意见。它确实回答了「我该向谁求证、还能问什么」。
>
> 但 R69 自陈的最大风险暴露了一个更深的认识论漏洞：**它把交互建模成「机器向一个可信度已知的 oracle 提问」，把模态当作「关于动作的假设」，把人类回答当作「关于动作的标签」。** 于是一旦模态权重未校准（幻觉出幻影模态、或坍缩掉真模态），VoI 就在错误信念上计算，系统会自信地追问一个幻影、或把人类一个误导性回答盖上「已验证」的章——「问错，比不问更危险」。
>
> 这个漏洞的根在于：真实的人机协作不是「审问」，而是**两个智能体在一个共享场景上建立共同基础（common ground）**。歧义常常不是「动作多峰」，而是「我们说的是不是同一个东西」（指称歧义）；可信度也不是全局常数 δ_p，而是随语境、随对方是否看得到同一场景而变的双向信任；人类也不只是被问者，而是能主动纠正、解释、拒绝的协作者。
>
> 本轮两个灵感正好补上两块缺失：
> - **场景理解**给出一个结构化的、可指认、可编辑、带溯源的共享场景图（SSG），把「动作模态」重新锚定到「场景指称」——幻影模态接不到任何实体，就地被拦截；
> - **人机协作**给出混合主动协议（MIP）与双向信任——机器可主动展示它的场景解释让人审查，人可主动纠正场景，双方共同决定谁在什么事实上拥有权威。
>
> 核心命题：**把 R69 的「审问式交互」升级为「共享场景上的共同基础构建」；指称歧义交给场景接地（看/指/核），意图歧义交给人类权威（问偏好），并用可证伪解释、证据因果独立性与双向信任，防止「共同基础变成共同幻觉」。** 命名 **SHARE-RAS**（Shared scene understanding & Human-AI Reciprocal Engagement for Risk-Adaptive Systems）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我们说的是同一个世界吗**」——不确定性不只是刹车，也不只是一句提问，还可能是双方对场景指称的一次错位。

## 0. 直觉与动机

**灵感 1（人机协作 → 从「审问」到「共同基础」）**
直觉：R69 的交互是一问一答的单向信道，隐含假设「答案即真值」。但人类协作里，「我不确定」常常表现为「我们说的是不是同一个东西」，解决靠的是把双方的场景表征对齐（joint attention、pointing、共同注视）。Clark & Brennan 意义下的共同基础不是「我知道答案」，而是「我们都知道彼此知道」。这把交互目标从「降低动作熵」改成「把一组命题加入共同基础 CG」——目标变了，证据结构也变了：需要**相互确认**与**来源可追溯**，而不只是单次采信。

**灵感 2（场景理解 → 歧义的根在指称，不在动作）**
直觉：R69 把 U_epi 完全归因于「动作多峰」。但一个绕左/绕右的分歧，可能只是因为机器把「左边的门」和人类说的「左边那扇」指成了不同实体；一旦指称对齐，动作根本没有歧义。反过来，指称清楚但意图不清（要不要打扰那个人）是另一类问题，只有人类能回答。故 U_epi 应拆成 U_ref（可被场景接地消解）与 U_int（必须由人类权威裁决）。R69 把两者混进 H_mode，导致**该自己看的去问人、该问人的去自己猜**——这是比采信错更隐蔽的系统性错配。

**灵感 3（共同基础 → R69 是「已接地、单次问答」的退化边界）**
直觉：若共同基础已建立、人类被当作可信 oracle、交互只允许一次问答，则 SHARE 退化为 FLUID，再退化为 R68。理论姿态延续 R69：**新层必须是旧层的严格泛化而非并列替代**，安全侧永不让步，否则每加一层就多一个需要独立信任的黑箱。

**灵感 4（解释作为接地探针 → 正面回应 R69 最大风险）**
直觉：R69 无法区分「模态是幻影」还是「人类在误导」，因为它只看答案，不看答案所依附的指称。让机器先展示它的场景子图 G_k（「我认为是 A 杯，因为它在你左手边且是唯一满的」），人类的纠正就落在**具体节点/边**上——是实体错了（指称错位）还是因果错了（意图/常识错）。**可证伪的解释把「是/否」答案升级为「错在哪」的结构化编辑**：幻影模态无法接地到任何 SSG 实体，接地失败即被拦截。这直接攻击「问错比不问更危险」。

**灵感 5（协作是双刃剑 → 共同基础可以联合错误）**
直觉：解释既是解药也是毒药。人类会**锚定**（anchoring）在机器的解释上，于是一个错误解释会诱导人类确认一个错误场景；若双方共享同一传感器/同一先验，错误相关，那么「双方一致」不等于「正确」——只是把错误社会性地封存成「已接地」。R69 的「k 个正交证据一致」在这里失效，因为**解释破坏了证据的独立性**。故本轮必须交付：证据因果独立性检验、异议保留、反事实证伪、以及「接地但存疑」的状态，绝不让共识抹平残余不确定性。

## 1. 形式化定义（增量：定义 310–322）

**定义 310（SHARE-RAS 总览）** SHARE-RAS = (SSG, RG, MIP, EXP, BTC, SWM-S, RAA, MGD, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **无接地不行动**：任何执行动作必须映射到一组 SSG 节点，其接地状态 ≥ g_min 且来源因果独立；
(iii) **协作预算与权威规则**：交互预算继承 R69；感知事实可由机器自接地，偏好/意图事实须人类权威，物理安全权威归 RAS-WM‡（人类越权可覆盖但留痕）；
(iv) **异议保留**：接地证书必须保留冲突证据，不得把残余不确定性压到 aleatoric floor 以下。

**定义 311（共享场景图 SSG）** 版本化类型图 SSG = (V, E, A, Π, τ)：V 为实体节点（身份、位姿、属性），E 为空间/语义/因果关系边，A 为可供性，Π 为逐节点/边的来源与置信，τ 为版本。每节点有 owner ∈ {human, machine, joint} 与接地状态。SSG 是共同指称基底，双方读写皆带 provenance。

**定义 312（共同基础与接地状态）** 命题 p 关于 SSG，grounded(p) ⇔ 两方都有证据相信「双方都相信 p」（到二阶互知）。机器维护带不确定性的 \hat{CG}。p 的接地证书 = (证据源, 独立性类, 确认, 异议, 版本)。

**定义 313（指称/意图歧义分解）** U_epi = U_ref + U_int + U_x：U_ref 为模态所指 SSG 实体/关系的分配歧义（可由机器感知+接地动作消解）；U_int 为指称确定后目标/偏好的歧义（只能由人类权威裁决）；U_x 为交叉项。R69 的 H_mode 是三者未拆的混合。

**定义 314（混合主动协议 MIP）** 动作集 {propose, request_grounding, explain, correct, defer, interrupt, accept, reject}，双方均可发起；每次发起带理由与截止期。终止于 CG 覆盖所需命题集或预算耗尽。主动分 I(a) = 联合风险的期望下降 / 成本。

**定义 315（解释作为接地探针）** 对模态 m_k，解释 E(m_k) = (G_k ⊆ SSG, 因果链, 反事实)。人类编辑 Δ_h ∈ {confirm, 改节点, 改边, 否定蕴含}。解释价值 VoI_E = I(M; Δ_h | E, o)。反事实**可证伪**当且仅当存在可观测 y 能推翻 m_k；证伪度低于阈值则解释不得作为证据。

**定义 316（双向信任标定）** T = (T_{m→h}, T_{h→m})。T_{m→h}(context) = P(人类回答正确 | 问题类型, 感知可达性, 历史)，**随语境变，非全局 δ_p**；T_{h→m} 由解释保真度更新（机器所述 G_k/因果链是否预测了它的行为）。R69 的 δ_p 是「语境恒定」特例。

**定义 317（场景条件共享世界模型 SWM-S）** 动力学/预测以 SSG 为条件，附物理与可供性一致性约束；动作必须在接地场景中可行，不一致即接地告警。

**定义 318（角色与权限仲裁 RAA）** 逐事实授权：感知事实→机器可自接地（除非歧义）；规范/意图事实→人类权威；安全包络→RAS-WM‡ + 人类覆盖。权限冲突按最小权限+审计解决，绝不静默。

**定义 319（误接地检测 MGD）** 检测指称漂移：双方用同一措辞指不同 SSG 节点。信号：同语言指称映射到分叉节点 ID、交叉核对探针不一致、SSG 版本分叉、反事实不一致。检出即冻结动作，先做接地修复。

**定义 320（共识收敛与联合幻觉上界）** 设人机证据误差相关为 ρ_c。在 k 个**因果独立**来源下，P(已接地但错误) ≤ f(δ_p, ρ_c, k)，但 ρ_c→1 时该界不随 k→0；故**独立性而非一致次数才是约束瓶颈**。

**定义 321（证书 J_SHARE）** J_SHARE = (J_FLUID, SSG_version, grounding_coverage, independence_class, dissent_hash, trust_matrix_snapshot, explanation_fidelity, joint_delusion_risk, share_ver)。Valid ⇔ Valid(J_FLUID) ∧ grounding_coverage ≥ g_min ∧ independence_class ≥ c_min ∧ 无未决 MGD ∧ 异议已保留。

**定义 322（两级退避的协作扩展）** 若预算内未建立 CG，或 MGD 未决，或独立性不足，或权威冲突 → 退化为 R69（FLUID，g=None）；若信任 ECE 越界 → 退化为 R68 纯保守。安全侧：SHARE ⊆ FLUID ⊆ R68。

## 2. 关键算法骨架

```python
# IP-264 SSG：共享场景图（双方读写皆带 provenance，版本化）
class SharedSceneGraph:
    def upsert(self, node, provenance, owner): ...
    def refer(self, phrase, context):            # 语言指称 -> 候选节点集
        return self._resolve(phrase, context)
    def ground(self, props):                     # 生成接地证书
        return GroundCert(props, self._independence_class(), self._dissent())
    def actionable(self, node):                  # 无可接地节点则不可行动
        return node.ground_status >= G_MIN and node.provenance.independent()

# IP-265 RG：指称 / 意图歧义分解（R69 单一 H_mode 的纠正）
def split_ref_intent(modes, ssg):
    U_ref = referential_entropy(modes, ssg)       # 模态所指实体的分歧
    U_int = intent_entropy(modes, ssg)            # 同一指称下目的的分歧
    return U_ref, U_int, cross_term(U_ref, U_int)

# IP-267 EXP：可证伪解释作为接地探针
def explain(modes, ssg):
    out = []
    for m in modes:
        G = supporting_subgraph(m, ssg)           # 支撑该模态的 SSG 子图
        cf = minimal_counterfactual(m, ssg)       # 要让该模态消失需改哪个节点/边
        out.append((m, G, cf, falsifiability(m, cf)))
    return [e for e in out if e.falsifiability > TAU_FALS]   # 不可证伪的不作证据

# IP-266 MIP + IP-268 BTC：混合主动 + 双向信任
def collaborate(M, E, U_int):
    dh = M.mip.request_grounding(E)               # 人类 confirm / edit / reject
    M.ssg.apply_edit(dh, provenance='human')
    M.btc.update(human_edit=dh, explanation=E)    # 机器更新对人类可靠性的语境估计
    return dh

# IP-271 MGD：指称漂移检测（同词不同物）
def drift(ssg):
    return any(len({n.id for n in ssg.refer(ph)}) > 1 for ph in ssg.shared_phrases())

# IP-274 SHARE-RAS 主闭环（继承 R69，替换不确定性处置层）
def SHARE_RAS_round(M, obs):
    z, o = M.mtm.forward(obs); c, U_cal, thr = M.cof.step(...)
    M.ssg.update_from_perception(o, provenance='machine')
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    U_ref, U_int, _ = M.rg.split_ref_intent(modes, M.ssg)
    # 1) 指称歧义：机器先自接地（看/指/探），能省一次社交打扰
    if U_ref > TAU_REF:
        g = M.mint.choose_grounding(modes, U_ref, M.ssg, M.budget)
        if g is not None:
            M.cia.execute(g); M.ssg.update_from_perception(...)
            U_ref = M.rg.residual_ref(modes, M.ssg)
    # 2) 意图歧义：只有人类权威能裁决；用可证伪解释换取结构化纠正
    E = None
    if U_int > TAU_INT and M.mip.allow():
        E  = M.exp.explain(modes, M.ssg)
        dh = M.mip.request_grounding(E)           # 人 confirm/edit/reject
        M.ssg.apply_edit(dh, provenance='human')
        M.btc.update(dh, E)
        if M.mgd.drift(M.ssg):                    # 同词不同物 -> 先修复再谈
            M.mgd.repair(); U_int = M.rg.residual_int(modes, M.ssg)
    # 3) 联合幻觉护栏：低独立证据不得消解不确定性，异议不得抹除
    if M.ssg.independence_class() < C_MIN:
        U_int = M.rg.unresolved(U_int)
    # 4) 第二意见 + 风险缩放（沿用 R69 两级退避）
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o, o_calibrated)
    slow  = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    grounded = M.ssg.grounded_all(modes)
    U_floor  = U_ale + (0.0 if grounded else (U_ref + U_int))
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    if slow: lam = max(lam, 0.8)
    A = M.ach.propose(x_prime, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    # 5) 只选「接地可行」的模态执行
    mode = select_mode_grounded(modes, M.ssg, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    # 6) 参与式审计（新增 SSG 版本、解释、人类编辑）
    M.vqa_i.submit_async(M.ssg.version, E, dh, U_ref, U_int)
    return k, lam, mode, (U_ale, U_ref, U_int)
```

## 3. 推导

**引理 19（接地剪除幻影模态）** 幻影模态 m_phantom 的指称集为空——不存在接地状态 ≥ g_min 且来源独立的 SSG 实体与之对应。故 select_mode_grounded 不会选中它；R69 的「追问幻影」被指称接地就地拦截，误追问率 ≤ 1 − grounding_recall。**这是对 R69 最大风险的直接回应：先接地，再提问。**

**引理 20（指称/意图通道分离的必要性）** 若把 U_epi 按「信息存在于何处」拆分，则 U_ref 的最优消解动作是机器感知（信息在场景里），U_int 的最优消解动作是人类权威（信息只在偏好里）。交叉消解至少多付 Δcost，且 U_int 中不可由几何观测约化的部分形成不可约误差。故 R69 的单一 H_mode 通道存在**系统性错配**：它既会浪费社交打扰去问机器本可看清的事，也会用几何去猜机器永远猜不到的偏好。

**引理 21（解释的锚定对偶）** 解释使人类纠正率上升 Δc，同时把人与机器的误差相关从 ρ_0 抬到 ρ_0 + a·Δc（a 为锚定系数）。解释净价值 ∝ Δc·(1−ρ) − a·Δc·ρ，存在最优解释强度；超过后「共同基础」变「共同幻觉」。系：解释必须**可证伪**且**保真**，否则会制造相关性而非法消解不确定性。

**定理 18（SHARE 严格包含 FLUID/R68）** 在 A99–A101（SSG 可接地、信任可标定、MIP 终止）下，SHARE 任意状态期望风险 ≤ FLUID ≤ R68；当 SSG 已完全接地、信任取常数、MIP 只允许单次问答时，SHARE 逐指令退化为 FLUID；再当 VoI ≤ 成本时退化为 R68。安全侧不让步，效率侧获得「共同基础红利」。

**定理 19（无接地不行动 → 安全与连续）** 每条被执行的动作都可追溯到一个接地节点集并经过 C-RAS-WM 认证；接地失败 / MGD / 权威冲突 / 独立性不足时，λ 单调不降地退化到 R69/R68；提交/换装不变式（R69 定理 17）保持 ⇒ 控制连续、无突变，协作不扩大安全包络。

**定理 20（共识不是真理 / 联合幻觉界）** 当证据相关 ρ_c → 1 时，无论一致次数 k 多大，P(已接地但错误) 不趋于 0；只有提高因果独立性（ρ_c ↓）或引入外部真值探针才能降低。故「一致」只有在独立性约束下才可作证据——R69 的 k-一致纪律必须补上独立性前提，否则「问到一个可验证的一致」也可能是一个被共同编造的一致。

## 4. 推导

**引理 19（接地剪除幻影模态）** 幻影模态指称集为空（无接地≥g_min 且独立的 SSG 实体对应），`select_mode_grounded` 必不选中；误追问率 ≤ `1 − grounding_recall`。**先接地，再提问**——直接回应 R69 最大风险。

**引理 20（通道分离必要性）** U_ref 信息在场景、U_int 信息在偏好；交叉消解多付 `Δcost` 且 U_int 的几何不可约部分形成不可约误差。R69 单一 H_mode 通道存在系统性错配。

**引理 21（解释锚定对偶）** 纠正率升 Δc，误差相关升到 `ρ_0+a·Δc`；解释净价值 `∝ Δc(1−ρ) − a·Δc·ρ`，存在最优解释强度，超过即「共同基础变共同幻觉」。系：解释须可证伪且保真。

**定理 18（严格包含）** A99–A101 下 SHARE 期望风险 ≤ FLUID ≤ R68；完全接地+常数信任+单次问答时逐指令退化为 FLUID，VoI≤成本时再退化为 R68。安全不让步，效率获共同基础红利。

**定理 19（无接地不行动）** 动作可追溯至接地节点集并经 C-RAS-WM 认证；接地失败/MGD/权威冲突/独立性不足时 λ 单调不降退化；换装不变式保持 ⇒ 连续无突变。

**定理 20（共识不是真理）** ρ_c→1 时 P(已接地但错误) 不随 k→0 降低；只有提高独立性或引入外部真值探针能降。R69 的 k-一致纪律必须补独立性前提。
