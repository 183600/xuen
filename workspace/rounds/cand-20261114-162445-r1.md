## 0. 直觉与动机

**灵感 1（双臂 = 闭链，闭链 = 一条共享观测通道）**
直觉：单手抓杯子时，手和杯子是两个刚体，靠接触约束；双手同抓一个刚性物体时，两条臂 + 物体构成一个**运动学闭环**。闭环意味着两臂的位姿不能独立任取——它们被同一个物体「焊」在一起。物理上这叫约束（constraint），认识论上这是一条**强制的信息通道**：一条臂对世界的判断会通过物体、以力的形式传导到另一条臂。单臂系统里「两个假设是否一致」只能靠概率比较；双臂系统里它**必须**被物理解释掉，解释不掉的残差就是可观测的分歧。这是本轮第一个核心直觉：**闭链把「模型不一致」变成了「物理上必须消解的力」。**

**灵感 2（内部力 = 免费的触觉探询）**
直觉：抓握力可分解为两部分——一部分推动物体（外部力），一部分两臂互相对顶、净效果为零（内部力）。标准抓取理论里内部力只用来防滑，是「浪费」；但在本轮视角下它是宝贝：当两臂对物体位姿有分歧，系统会**下意识地互相较劲**——各自按自己的预测去「扶正」物体，分歧就变成挤压。于是内部力不是噪声，而是**一次零成本、连续、实时的触觉提问**：「你到底以为它在哪？」这与 R69 的主动探询同源，但探询者就是伙伴本身，无需外呼、无需社交成本。**分歧越大，内耗越高**——这是一个几乎无法被传感器标定吸收的物理信号。

**灵感 3（共识的致命前提：误差必须去相关）**
直觉：R69 用「k 个正交源一致」防投毒，隐含假设各源独立。可如果两个源是同一台相机训练出来的两个头、或共享同一份外参偏差，它们的一致**不携带任何独立信息**——只是同一个错误被复述了两遍。双世界模型同理：两臂若共用一个标定、一份先验、一种视角，则「两臂都认为物体在 X」等价于「一条臂认为物体在 X」。所以本轮的核心度量不是「一致性」，而是**误差的认知相关 ρ_epi**：一致性只有在 ρ_epi 低时才是证据。n_eff = 2/(1+ρ_epi) ∈ [1,2]，两臂完全相关时退化成一条臂。这把「多数表决」升级为「有效独立源计数」。

**灵感 4（去相关是一种可以主动执行的动作）**
直觉：既然相关性和几何有关，就可以**用动作去打破它**：让物体绕某轴转一下，两臂的视角、力臂、遮挡关系就变了，共同盲区被拆开；沿只有一条臂看得见的轴平移，强迫两条臂的世界模型暴露差异。这不是随机抖动，而是 R69 信息动作的**双人版**：选一对关节动作，使「两臂误差的差分可观测性」最大化。VoI 要乘上 (1−ρ)：**只被一条臂看到的信息才值钱，被两臂同时看到的信息可能一文不值**。

**灵感 5（角色是一个必须被估计的全局隐变量）**
直觉：双人搬桌子，必须有人主导方向、有人跟随；两人都主导就会拧，两人都跟随就会飘。双臂同理，**lead/follower 角色是全局隐变量**，而且两条臂可能对「谁是主导」判断不一致——这是比位姿分歧更高一层、更难被内部力暴露的认知失败（两臂都以为自己在跟随，结果没人负责）。R66 问「人机之间谁控制」，R70 把它下沉为「**机器人内部，哪条臂说了算**」，并把角色冲突做成一个独立的可观测/可审计量。

**灵感 6（共识坍缩：靠松手达成的「一致」）**
直觉：本文最想提前堵住的一个漏洞。既然低内部力 = 高共识，那么系统会不会学会**把内部力降下来就等于达成共识**？会。最省力的降内耗方式是**松开、变软、互相让步**——物体于是滑落。这是一种**退化解**：用降低任务完整性换取表面的模型一致。人类合作里这叫「和稀泥」，机器人里这叫**共识坍缩（consensus collapse）**：两臂都变得顺从、内耗归零、然后一起丢东西。所以共识度量必须与任务完整性指标**成对出现**，绝不能单独优化内部力。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（DUET-RAS 总览）** DUET-RAS = (SWM^L, SWM^R, CCE, ROL, ABP, IWP, RAS-WM‡)。三不变式：
(i) **实时零学习写操作**（继承 R69 定义 293-i / R68 定义 276-i）；
(ii) **耦合诚实性**：任何共识声明必须附一条**独立**证据通道；共享偏置通道（ρ_epi 高）按 n_eff 降权，不得被当作第二个投票；
(iii) **完整性非退化**：共识度量永远与任务完整性度量成对评估，**只靠降低内部力带来的共识一律无效**（反共识坍缩）。

**定义 311（双臂耦合世界模型 SWM-Bi）** 两条臂各自维护局部世界模型 f^i_θ: o^i_t ↦ z^i_t（i∈{L,R}），预测本臂末端、物体位姿与接触。闭链约束 C(q_L, q_R, s_obj)=0（刚性抓取的相对位姿/接触约束），**闭链残差** r_chain = C(q_L,q_R,ŝ_obj)。共享物体状态 ŝ_obj 由两臂预测融合，但融合权重受定义 313 的独立源计数约束。

**定义 312（内部力观测 IWP）** 抓取映射 G 给出物体净力 w_obj = G f + w_ext，f=[f_L;f_R]。内部力 f_int=(I−G⁺G)f 位于 G 的零空间，对物体运动无净贡献。定义 **内部力势** IWP = ‖f_int − f_int^min(grasp)‖ / σ_f，其中 f_int^min 为防滑所需最小内耗、σ_f 为力噪声尺度。IWP 是「两臂世界模型分歧」的物理读出（引理 19）。

**定义 313（认知相关 ρ_epi 与有效独立源 n_eff）** ρ_epi = 在**共享输入扰动**下两臂世界模型残差 r^L、r^R 的相关系数（用共同激励的标定片段估计）。定义有效独立源计数 n_eff = 2/(1+ρ_epi) ∈ [1,2]。ρ_epi→1 ⇒ n_eff→1（两臂等价于一条臂，共识无信息）；ρ_epi→0 ⇒ n_eff→2。

**定义 314（共识证据 CCE）** 共识对数几率 log-odds_cons = n_eff · κ · a（a 为归一化一致度、κ 为单源可靠度）。**关键**：一致度 a 必须用 n_eff 折扣；两臂高一致但高相关 ⇒ 证据量按一条臂计。CCE 输出「可信共识 / 弱共识 / 无共识」三档。

**定义 315（角色隐变量 ROL）** 角色 r_t ∈ {L-lead, R-lead, symmetric, none}，由刚度/力分配与预测权威估计。定义**角色冲突** role_conflict = 1 − 两臂对 r_t 后验的一致性（TV 距离）。角色冲突是独立于位姿分歧的一类认知失败：两臂都以为对方主导 ⇒ 无人负责。

**定义 316（主动去相关探询 ABP）** 联合信息动作 g_bi ∈ 𝒜_info^bi 改变耦合几何（绕轴转动、错位平移、改变抓取点/刚度），目标是最大化**差分可观测性**（两臂雅可比/视角之差对候选模态的判别力），而非最大化总信息量。ABP 受 R69 交互预算 + 定义 302 认证约束（双人动作也要过 C-RAS-WM）。

**定义 317（去相关感知 VoI）** VoI_ind(g) = (1 − ρ̂_epi(g)) · [H(M|o) − E_{y~p(·|g)}H(M|o,y)]。即：**只有落到独立通道上的信息才计入价值**。g 若被两臂以相同方式观测（ρ̂≈1），则 VoI_ind≈0，不值得做。ABP 选 g* = argmax_g [VoI_ind(g) − c(g)]。

**定义 318（完整性门 IG）** 任务完整性 I = I_grip ∧ I_slip ∧ I_obj（抓取质量、滑移裕度、物体位姿置信）。**共识被采纳的必要条件**：I ≥ I_min。IG 与 CCE 联合决定是否采信共识（反定义 326 的退化解）。

**定义 319（共识坍缩检测 CCD）** 若内部力下降（IWP↓）同时完整性下降（I↓）或外部任务残差上升，则判为共识坍缩。标记后**冻结**共识证据、退回 R69 单臂保守，并记录「以松手换一致」的负样本进审计缓冲。

**定义 320（共模失败检测 CMFD）** 两臂一致、IWP 低、但**外部独立通道**（腕部相机/外部力/物体位姿外部观测）与两臂共同判断冲突，则判为共模失败。CMFD 是 R69 流似然第二意见（定义 301）在「伙伴也会一起错」场景下的推广：需要一条**不经过两臂共识**的第三方通道来打破平局。

**定义 321（非对称权威分配 ASA）** 依据 ROL 与 CCE 在 [0,1] 上分配刚度/权威 α：主导臂 α→1，跟随臂 α→0，symmetric 时 α=0.5。分配变化必须经过认证前缀的**无扰切换**（定理 20），不得瞬时跳变。

**定义 322（共享世界模型更新纪律 SWU）** 共享 latent 只在两种情况下更新：(a) 来自独立通道的新观测；(b) 经定义 314 认证的可信共识。实时环内**禁止**用单臂残差直接写共享 latent（继承零学习写操作）。

**定义 323（威胁模型 ℰ_DUET）** ℰ_DUET = ℰ_FLUID × ℰ_common × ℰ_grasp × ℰ_role，其中 ℰ_common：**对两臂同时可见的共同偏置注入**（外参、共享先验、同源对抗扰动）；ℰ_grasp：抓取/力通道欺骗；ℰ_role：角色劫持（诱导两臂争主导或同时退让）。

**定义 324（证书 J_DUET）** J_DUET = (J_FLUID, ρ_epi, n_eff, role_conflict, integrity_margin, consensus_collapse_flag, chain_residual_p95, duet_ver)。Valid ⇔ Valid(J_FLUID) ∧ ρ_epi ≤ τ_ρ ∧ I ≥ I_min ∧ ¬collapse ∧ role_conflict ≤ τ_role。

**定义 325（两级退避，含双臂 Resolution Bonus）** 若共识可信（CCE=可信 ∧ I≥I_min ∧ ρ_epi≤τ_ρ ∧ 无共模）：可启用双臂 resolution bonus（更快、更稳、更紧的协同），λ 与散度按「已消解」处理；否则**把两臂视作一条臂**、承担全部 U，逐指令退化为 R69/R68 单臂保守。⇒ DUET 在不可信边界上严格等于 FLUID-RAS。

**定义 326（时序耦合与异步一致性）** 两臂控制率/延迟不同，消息延迟 τ_d，一致性地平线 H_c：超过 H_c 的共识按时效折扣 e^{−τ_d/H_c} 降权；陈旧共识不得驱动权威切换。保证异步双臂仍满足 P99 实时与无突变。

# IP-264 SWM-Bi：双臂耦合世界模型（每臂局部 latent + 闭链残差）
class BiWorldModel:
    def __init__(self, wm_L, wm_R, chain):
        self.wmL, self.wmR, self.chain = wm_L, wm_R, chain

    def forward(self, oL, oR, qL, qR):
        zL, zR   = self.wmL(oL), self.wmR(oR)          # 局部世界模型（复用 R68 trunk）
        s_obj    = fuse_object(zL, zR, self.rho_epi)    # 融合权重受独立源计数约束
        r_chain  = self.chain.residual(qL, qR, s_obj)   # 闭链残差
        return zL, zR, s_obj, r_chain

# IP-265 CCE：认知相关估计 + 有效独立源折价
def consensus_evidence(zL, zR, rL, rR):
    rho  = estimate_rho_epi(rL, rR)                     # 共同激励片段估计
    n_eff = 2.0 / (1.0 + rho)                           # rho->1 退化为单臂
    agree = normalized_agreement(zL, zR)
    log_odds = n_eff * KAPPA * agree
    return classify(log_odds), n_eff, rho               # 可信/弱/无

# IP-266 ROL：角色估计与冲突监测
def role_estimate(alpha, post_L, post_R):
    r = argmax_role(stiffness_force_signature(alpha))
    conflict = total_variation(post_L[r], post_R[r])    # 两臂对"谁主导"的一致性
    return r, conflict

# IP-267/268 ABP + IWP：内部力作为免费探针；按去相关价值选动作
def abp_choose(modes, rho, budget):
    best = None
    for g in bimanual_info_actions():                   # 转动物体 / 错位 / 改抓取
        if not budget.allow(g) or not c_ras_wm.certify_info(g): continue
        voi = (1.0 - rho_hat(g)) * info_gain(modes, g)  # 只计独立通道信息
        score = voi - cost(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None

def internal_wrench_anomaly(f, G, grasp):
    f_int = (np.eye(len(f)) - np.linalg.pinv(G) @ G) @ f   # 零空间内部力
    return norm(f_int - f_int_min(grasp)) / sigma_f        # IWP

# IP-269/270 完整性门 + 共识坍缩检测
def accept_consensus(cc, I, iwp_prev, iwp_now, task_err):
    if cc != 'trusted' or I < I_MIN:              return False
    if iwp_now < iwp_prev and (I < I_prev or task_err > err_prev):
        flag_consensus_collapse(); return False    # 以松手换一致 -> 拒绝
    return True

# IP-271 CMFD：外部独立通道打破两臂共谋
def common_mode_fail(s_obj_consensus, o_ext):
    return disagree(s_obj_consensus, external_estimate(o_ext))  # 不经两臂共识

# IP-275 主闭环（继承 R69，仅在"谁是证据源"处插入 DUET 层）
def DUET_RAS_round(M, oL, oR, qL, qR):
    zL, zR, s_obj, r_chain = M.swm.forward(oL, oR, qL, qR)
    cc, n_eff, rho = M.cce.consensus_evidence(zL, zR, M.rL, M.rR)
    I = M.ig.integrity(zL, zR, s_obj)
    iwp = M.iwp.internal_wrench_anomaly(M.last_f, M.G, M.grasp)
    # 1) 共识坍缩 / 共模失败优先检测（先证伪，再采信）
    collapse = M.ccd.detect(iwp, M.iwp_prev, I, M.I_prev, M.task_err)
    cmf      = M.cmfd.common_mode_fail(s_obj, M.ext_obs)
    # 2) 共识不可信 -> 视作单臂，完整继承 R69/R68
    trustworthy = (cc == 'trusted') and (not collapse) and (not cmf) \
                  and (I >= M.I_MIN) and (rho <= M.TAU_RHO) \
                  and (M.rol.conflict <= M.TAU_ROLE)
    if not trustworthy:
        return M.fluid.round_single(zL, oL)          # 逐指令退化为 R69（定义 325）
    # 3) 可信：主动去相关探询（仅当歧义高）
    if M.epi > M.TAU_EPI:
        g = M.abp.choose(M.modes, rho, M.budget)
        if g is not None:
            s_obj = M.abp.execute_and_update(g)
    # 4) 角色 -> 非对称权威（无扰切换，定理 20）
    r, conf = M.rol.estimate(M.alpha, M.postL, M.postR)
    M.asa.allocate(r, alpha=smooth_transition(M.alpha, r))
    # 5) 双臂 resolution bonus：更紧更快的协同执行
    A = M.coord.propose(s_obj, r)
    k = M.c_ras_wm.certified_prefix(A, ...)
    mode = select_mode(M.modes, M.epi, lam=lam_floor(M.ale))
    # 6) 共享 latent 只在独立通道/可信共识时更新（定义 322）
    M.swu.update(s_obj, independent=(not cmf), trusted=(cc == 'trusted'))
    M.vqa.submit_async(r, cc, rho, iwp, collapse, cmf)
    return k, mode, (r, cc, n_eff)

## 3. 推导

**引理 19（内部力是分歧的单调读出）** 设两臂对物体位姿的预测差为 δ = ŝ_obj^L − ŝ_obj^R，其沿闭链约束零空间的分量为 P_null δ。在接触刚度 K_g 下，为同时满足各自预测而产生的额外内部力满足 ‖f_int − f_int^min‖ = ‖K_g P_null δ‖ + O(‖δ‖²)。故 IWP 是「两臂世界模型在约束零空间上的相对分歧」的单调函数。系：**内部力是一条零成本、连续的触觉探询**；但它只度量**差分**分歧，对**共同**偏差（P_null δ=0）完全失明——这正是共模失败的物理根源。

**引理 20（相关误差下的证据折价）** 若两臂残差 r^L、r^R 的相关系数为 ρ，则其线性融合相对单一最优臂的方差增益为 G(ρ) = 2/(1+ρ) − 1 = (1−ρ)/(1+ρ)。故有效独立源 n_eff = 2/(1+ρ)：ρ=0 时两票，ρ=1 时一票，ρ→−1 时两票且最优。**推论**：任何把「两臂一致」当无条件两个独立证据的融合都会高估置信；高 ρ 下的一致只是回声。

**引理 21（去相关探询的收益）** 对差分可观测性 Do(g)（两臂雅可比/视角之差对候选模态的 Fisher 信息）满足 ρ̂_epi(g) ≈ ρ_0 · e^{−c·Do(g)}。则去相关后的有效证据增益 ∝ (1 − ρ̂_epi(g))·ΔH，且最优 g* 使 Do(g) 最大而非使总信息最大。系：**被两臂以相同方式看到的信息价值≈0；探询的价值在于制造「只有一条臂看得见」的差分**。

**定理 18（DUET 严格包含 FLUID-RAS / R68）** 在 A99–A102 下，DUET 的两级策略（先证伪共识，再采信）在任意状态的期望风险 ≤ FLUID-RAS 单臂策略；当 ρ_epi>τ_ρ、I<I_min、检测到共识坍缩或共模失败时，两者**逐指令相同**（定义 325）。故 R69/R68 是 DUET 在「共识不可信」边界上的退化：安全侧不做让步，可信侧获得双臂 resolution bonus。

**定理 19（反共识坍缩）** 完整性门 IG（定义 318）与任务残差耦合（定义 319）共同保证：被采纳的共识集合不包含「内部力下降且完整性下降」的退化解。形式地，若 IWP→0 由增大服从度（降低刚度）实现，则 I 单调下降，IG 拒绝该共识；故 **「靠松手达成一致」在系统内不可达**。系：共识度量不可被单目标优化为松弛。

**定理 20（角色切换与异步下的无突变）** 权威 α 经平滑过渡 + 认证前缀约束（定义 321、326），且陈旧共识按 e^{−τ_d/H_c} 降权，则角色切换与异步延迟下控制输入连续（Lipschitz），提交/换装不变式（R68 定理 15）保持 ⇒ 无突变、P99 实时预算不被击穿。

## 4. 推导

**引理 19（内部力是分歧的单调读出）** 设两臂物体位姿预测差 `δ=ŝ^L−ŝ^R`，沿闭链零空间分量 `P_null δ`；接触刚度 `K_g` 下额外内部力满足 `‖f_int−f_int^min‖=‖K_g P_null δ‖+O(‖δ‖²)`。故 IWP 单调反映**差分**分歧；对共同偏差（`P_null δ=0`）完全失明——这是共模失败的物理根源。

**引理 20（相关误差的证据折价）** 相关 ρ 的两臂残差线性融合的方差增益 `G(ρ)=(1−ρ)/(1+ρ)`，故 `n_eff=2/(1+ρ)`：ρ=0 两票、ρ=1 一票、ρ→−1 两票且最优。推论：高 ρ 下的「两臂一致」只是回声，无条件当两票必高估置信。

**引理 21（去相关探询收益）** 差分可观测性 `Do(g)` 下 `ρ̂_epi(g)≈ρ_0 e^{−c·Do(g)}`，可消解增益 `∝(1−ρ̂_epi(g))·ΔH`，最优 g* 使 Do(g) 最大而非总信息最大。系：被两臂同看的信息价值≈0，探询价值在于制造「只有一条臂看得见」的差分。

**定理 18（DUET 严格包含 FLUID/R68）** A99–A102 下 DUET 期望风险 ≤ FLUID 单臂；当 `ρ_epi>τ_ρ ∨ I<I_min ∨ collapse ∨ cmf` 时两者逐指令相同。R69/R68 = 「共识不可信」边界；安全不让步，可信侧获双臂 resolution bonus。

**定理 19（反共识坍缩）** 完整性门与任务残差耦合保证被采纳共识不含「内部力↓ 且完整性↓」的退化解：若 IWP→0 由降刚度实现，则 I 单调下降被 IG 拒绝 ⇒「靠松手达成一致」在系统内不可达。

**定理 20（角色切换与异步无突变）** 权威 α 经平滑过渡 + 认证前缀，陈旧共识按 `e^{−τ_d/H_c}` 降权，则角色切换/异步延迟下控制连续（Lipschitz），提交/换装不变式（R68 定理 15）保持 ⇒ 无突变、P99 守时。

## 7. 本轮最大风险

**一句话**：DUET-RAS 的全部协同收益押在「两臂误差可被去相关」这一前提上——**若两臂共享同一标定/先验/视角（ρ_epi→1），它们会冷静地一致错下去；内部力只读差分分歧、对共同偏差完全失明，系统可能在低内耗、丝滑、看似完美协调的动作里把共同错误执行到底，甚至用「松手变软」把内耗压到零伪装成共识——共谋证实的错误，比各自犯错更危险。**

**次级风险与缓解**：共识坍缩（IG + CCD，定理 19 证明退化解不可达）；共模失败（CMFD 外部独立通道 + SWU 更新纪律）；角色冲突/争主导（ROL + ASA 无扰切换，定理 20）；异步陈旧共识（`e^{−τ_d/H_c}` 降权 + 定义 326）；去相关探询越界（沿用定义 302 认证与 R69 交互预算）。
