# 第 43 轮（新循环第 3 轮） · SEM-CERT-MAP：把语义地图变成「证书证据账本」，把数据采集变成「证书不确定性驱动的主动实验」（四层架构 v8）

> 承接第 42 轮 v19（SCV × CKB × ECR）。第 42 轮的最大风险是「仿真偏差累积 + 检索幻觉」：证书 soundness 依赖 D_sim 覆盖 D_real、KB 模板与当前任务相似，这两件事都是离线一次性判断，运行时并不知道「我哪里还没有证据」。本轮灵感词「语义地图」「数据采集」给出互补视角：**语义地图不只是导航结构，它天然是一张空间索引的「证据账本」**——每个语义实体/区域都可挂载证书、支撑数据、有效期与不确定度；**数据采集也不应被动喂数据，而应由证书系统反向驱动**——哪里证书最不确定、最接近守卫阈值、最影响决策，就去哪里采集。二者合起来把第 42 轮的「离线验证→部署」改造成「在线证据生产→证书维护」的持续过程：地图回答「证书从哪来、到哪去、何时失效」，采集回答「下一步补哪块证据」。

## 0. 直觉与动机

**灵感 1（语义地图 → 证书的空间证据场，而不是一张更漂亮的地图）**：现有 L1 已经产出度量语义图 C_ms，但它主要服务 LIO、规划与语义查询，证书仍然是「全局的、无位置的」对象。直觉上，人类工程师给机器人做安全认证时，脑子里想的不是一纸全局证书，而是一张「经验地图」：这条走廊测过一万次，那块反光玻璃从没测过；这个抽屉拉过，那个抽屉只见过没碰过。语义地图恰好提供了这种**可寻址的抽象单元**（物体、房间、通道、affordance 边），把「证书」从全局标量拆成**按语义实体/区域索引的证据字段**：每个节点记录边际下界、可信区间、有效期、支撑数据、来源（仿真/实机/人工）。这样，证书不再是「要么全信、要么全不信」，而是「在哪些语义上下文里、基于哪些数据、还能信多久」。

**灵感 2（数据采集 → 证书信息增益驱动的主动实验）**：数据采集的朴素做法是「多跑、多采、均匀覆盖」，但在证书体系里，数据的价值极不均匀：**守卫阈值附近的样本最值钱**，因为它直接决定安全/不安全的判定；远离阈值的样本再多也只是重复确认。更进一步，采集动作本身有风险与成本：不能为了验证「前方是否安全」就直接把机器人开进未认证区域。于是采集应被建模成一个**带安全护盾的约束主动学习/bandit 问题**：候选动作 = 视角变化、被动观察、短距离探针、前沿一步扩展；目标 = 单位风险/成本下的证书信息增益最大；约束 = 采集轨迹必须落在已认证区域或「一步前沿」内。这既提高数据效率，也避免「用不安全的方式验证安全」的悖论。

**灵感 3（证据溯源 + grounded RAG → 让证书可审计、可撤销、可拒绝合并）**：第 42 轮的 RAG 幻觉本质是「检索到了相似模板，但没有检查它是否被当前场景的证据支持」。语义地图给出**空间与语义的落地条件**（模板适用域必须与当前地图上下文相交），证据账本给出**数据层面的落地条件**（模板的支撑数据必须与当前证据重叠且仍然有效）。每条证书 = 一个 claim，claim 必须带 provenance DAG：它依赖哪些采集 episode、哪版模型、哪次标定。若某批数据后来被判定有偏（传感器标定漂移、仿真参数错误），沿依赖闭包**保守撤销**所有下游证书，并把受影响地图区域重新标为「待采集」。这把「数据采集」提升为「证据生产与证据责任」，也为第 42 轮的两条新失效链提供运行时闸门。

**耦合**：语义地图回答「在哪里、关于什么」；数据采集回答「下一步测什么」；证据账本回答「凭什么信、何时撤回」；CKB/grounded RAG 回答「能复用哪段已验证经验」。四者形成 **Map→Acquire→Prove→Reuse→Map** 的证据飞轮，与第 42 轮的 Sim→RAG→Edge→Sim 飞轮正交叠加：前者管「空间证据覆盖」，后者管「模型/模板进化」。

## 1. 形式化定义（增量：定义 38–43）

**定义 38（语义地图与证书证据场）**：时刻 t 的语义地图 M_t = (V_t, E_t^topo, E_t^sem, A_t)，其中 V_t 为语义实体/区域节点，E_t^topo 为拓扑邻接，E_t^sem 为 affordance/交互语义边，A_t 为节点属性。对每个 v ∈ V_t，证据属性
e_t(v) = (m_lo(v), m_hi(v), θ(v), p_safe(v), τ(v), P(v), H(v))
分别表示证书边际的 (1−δ) 可信下界、上界、守卫阈值、安全后验、有效期、provenance 集合、以及证书哈希集合。地图本身带几何误差场 ε_map(v)（来自 LIO 协方差与回环残差）。称 E_t = {e_t(v)}_{v∈V_t} 为**证书证据场**。

**定义 39（证书判定不确定度与临界集）**：对守卫谓词 G_v = 1[m(v) ≥ θ(v)]，令 p_v = P(G_v = safe | D_t)，二元熵 H_v = −p_v log p_v − (1−p_v) log(1−p_v)；令边际可信区间宽度 W_v = m_hi(v) − m_lo(v)。定义**证书不确定度** U_cert(v) = H_v + λ_W·W_v，**决策临界集** V_crit = {v : |m_lo(v) − θ(v)| ≤ ε_θ ∨ H_v ≥ H_min}。直觉：U_cert 高的地方不是「地图画得不准」，而是「证书判不准」；V_crit 是采集预算应该优先投的空间。

**定义 40（证书信息增益）**：对候选采集动作 a（视角/探针/前沿扩展），观测 O_a ∼ p(· | M_t, a)。定义
IG_cert(a) = Σ_{v∈V_crit} I(G_v ; O_a | D_t)
即所有临界节点守卫判定与本次观测的互信息之和（可用局部线性观测模型的一步 Fisher 信息近似）。它衡量「这次采集能让多少个临界判定从模糊变确定」，而不是「能多看到多少平方米」。

**定义 41（风险-成本约束的主动采集策略）**：a* = argmax_{a∈A_adm} IG_cert(a) / (C(a) + λ_R·R(a))，subject to R(a) ≤ R_budget, coverage(a) ≥ c_min。其中 C(a) 为时间/能量/通信成本，R(a) 为采集动作的碰撞/失稳/进入未认证区的风险。**安全护盾**定义可行动集 A_adm = {a : path(a) ⊆ C_cert(M_t) ∪ Frontier_δ(M_t)}，即只允许在已认证区域或「距已认证边界不超过 δ 的一步前沿」内采集；对未认证区域只允许被动观察（远距视角、长焦、声呐/雷达扫），不允许物理探入。另设强制探索配额：每 N 次采集至少有一次落在「长期未访问且语义新颖度高」的区域，以对抗第 5 节的自证循环。

**定义 42（证据溯源账本 EPL 与证书撤销）**：EPL 是有向无环图，数据节点 d_i 记录（传感器、时间、标定版本、采样设计、模型版本、质量门），证书节点 c_j 记录（模板、支撑证据集合 supp(c_j)、推导规则、覆盖地图区域）。依赖闭包 dep(c_j) = 从 c_j 反向可达的全部数据节点。**撤销算子**：若 d_i 被判无效（标定漂移、数据污染、分布外、仿真参数错误），则对所有 d_i ∈ dep(c_j) 的证书置为 Unverified，并把其覆盖区域加入 V_crit 触发再采集。**证据充分性**：证书可采信需同时满足 (i) 所有依赖有效；(ii) 覆盖临界区域的采样设计达到覆盖度 ≥ 1−η 且有效样本量 ≥ n_min；(iii) 采样分层覆盖证书敏感度热力图的各分位。**命题（保守撤销）**：若依赖有效且推导规则 sound，则证书 sound；撤销只可能多撤、不可能漏撤。

**定义 43（地图条件证书迁移与失效）**：若 v 与 u 由语义路径 π 相连，路径上地图误差为 ε_map(π)、语义边 e 的证书敏感度 Lipschitz 常数为 L_e、语义距离为 d_sem(e)，则
m_lo(u) ≥ m_lo(v) − L_m·ε_map(π) − Σ_{e∈π} L_e·d_sem(e)。
当地图更新使某区域几何/语义变化超过 ε_reval 时，所有满足 d_map(u, changed) ≤ r_reval 的证书立即过期，其中 r_reval 由上式反解出的「证书有效半径」。**命题（迁移 soundness）**：若上述不等式右端仍 ≥ θ(u) 且所有依赖有效，则迁移后的证书 sound；否则必须重新采集/重颁。

## 2. 四大产出设计（增量 IP-57/58/59 + 升级 IP-49/50/51/54/55/45/47）

### 2.1 IP-57 CERT-EVIDENCE-MAP（CEM，证书证据地图）
1. **三层地图结构**：几何层（点云/网格/位姿图，沿用 LIO）、语义层（对象/房间/affordance，沿用 CTC/VLM）、证据层（新增 e_t(v)）。三层共享节点 ID，证据层可独立版本化与回滚。
2. **证据字段更新**：新 episode 先做数据关联（位姿+语义+时间），再按 Bayes 更新 p_safe、按 conformal/区间方法更新 (m_lo, m_hi)，按地图回环误差更新 ε_map；τ 取「数据保质期」与「地图有效期」的较小者。
3. **临界性热力图**：把 U_cert、|m_lo−θ|、语义边敏感度 L_e 聚合成空间热力图，供 IP-58 选点、IP-54 定向补仿真、人类审计可视化。
4. **地图更新触发的证书失效**：回环/重定位/语义标签翻转/物体移动 → 计算 r_reval → 批量置 τ=now；失效区域进入采集队列，而不是直接沿用旧证书。

### 2.2 IP-58 CERT-GUIDED-ACQUISITION（CGA，证书引导采集）
1. **采集动作库**：被动视角（云台/变焦/多传感器）、主动短探针（轻触/推拉/开门）、前沿一步扩展、请求人类示范/人工标注、请求云端仿真补充（把「采集」扩展到仿真与人类两种数据源）。
2. **信息增益估计**：对 V_crit 用局部线性观测模型估计 IG；对语义不确定（VLM 标签熵）与证书不确定分别加权，避免「只采集自己想看的」。
3. **安全护盾与阶梯扩展**：A_adm 限制在已认证区/一步前沿；未认证区只用被动观测；每次扩展前用当前证据场给出保守 CBF margin，扩展后立即重证再前进。
4. **风险-成本调度**：用约束 bandit / 滚动时域 POMDP 求解；硬约束 R ≤ R_budget；强制探索配额 + 冷却期，防止在同一个高价值点反复采样。
5. **采集契约**：每次采集输出可审计的 (目标临界节点、预期信息增益、实际信息增益、风险、成本、数据去向)，用于 E88/E94 的因果归因。

### 2.3 IP-59 EVIDENCE-PROVENANCE-LEDGER（EPL，证据溯源账本）
1. **数据血缘**：每个 episode 记录传感器 ID、标定哈希、时间同步误差、采样设计、模型版本、质量门结果；不可变追加（append-only），哈希链防篡改。
2. **依赖追踪与撤销**：证书 → 模板/推导 → 数据 episode 的反向可达；撤销沿闭包传播；撤销是保守的（宁多勿漏），并记录撤销原因与影响面。
3. **证据充分性审计**：覆盖度、有效样本量、分层覆盖、分布外检测；不达标证书不得进入 CAR 的可用集，只能触发采集或人工确认。
4. **联邦/多机共享**：多机器人共享证据账本时按 provenance 去重、按硬件/标定分组；跨机迁移必须重新检查地图条件迁移界与标定一致性。

## 3. 四层架构 v8

```
L1: TRI-FUSE(INT8) + IP-49 LIO → 几何层 + 语义层 + ε_map + B_t

L2: CTC + VLM + IP-35 仲裁 → 对象/affordance/证书谓词 + 语义置信
    → IP-58 CGA 采集提议（语义不确定 + 证书不确定）
L3: IP-51 CAR(带 τ 与 provenance 的守卫) ← IP-56 ECR(L0/L1 查表与 INT8 监控)
    → IP-47 乘积模板组合 → IP-39 规划(CBF margin=证据场 m_lo)
    → IP-45 总线(证据事件 + 采集心跳) → IP-48 认证流匹配 + IP-43 韵律调度
    → IP-53 CMC(看门狗=L1 INT8)
L4: IP-55 CKB(grounded RAG + 证据重叠门) ← IP-54 SCV(证据缺口定向仿真)
    ← IP-59 EPL(溯源/撤销/充分性审计) ← IP-58 CGA(主动采集)
    → IP-50 课程(采集-课程联合) → RCA 重颁证书(含地图区域+有效期+provenance)
运行期：证书查询 → τ 过期/V_crit/地图失效 → CGA 生成采集任务 → 新数据入 EPL
        → 证据场更新 → 证书重颁或撤销 → 热更新下发
```

## 4. 实验设计（E87–E94 硬门槛，承接 E79–E86）

| E91 溯源撤销 | 注入有偏/污染数据后的撤销召回/精确率；残留可信孤证 | 召回 ≥ 99%；精确 ≥ 90%；0 个 |

| E94 自证循环/盲区审计 | 对抗 holdout 发现的隐藏不安全区；强制探索命中率 | 盲区 < 5%；探索命中 ≥ 1/20 |

回退：E87 校准失败 → 放大可信区间并降级为经验区间；E88 无增益 → 退回「不确定度+网格」采集；E89 迁移失效 → 只在完全匹配的语义节点间迁移并加大 r_reval；E90 门太严 → 人工确认通道；E91 撤销过/欠 → 冻结账本版本并人工审计；E92 无改善 → 回退第 42 轮 α_e；E94 出现自证 → 提高强制探索比例并引入外部审计机器人/人工巡检验证。

## 5. 本轮最大风险

**一句话**：最大风险是「证据自证循环」——语义地图、证书引擎与采集策略共享同一套 VLM/LIO/仿真模型与同一批数据，主动采集会优先涌向模型最自信、最容易得分的地方，形成「越采集越自信、越自信越少探索」的回音室，证书覆盖率看似上升而真实盲区被系统性掩盖；因此 E94（自证/盲区审计）与 E91（溯源撤销）必须作为红线，配合独立审计集、强制探索配额与证据账本冻结回滚。

# 第 43 轮产物 · 创新点清单 v20：SEM-CERT-MAP 证据飞轮（CEM × CGA × EPL）× 地图条件证书（四层架构 v8）

> 承接第 42 轮产物 v19。本轮增量插入 IP-57/58/59，升级 IP-49/50/51/54/55/45/47；不推倒任何既有层级。核心是把 v19 的「仿真→知识→边缘」飞轮，补齐为「空间证据覆盖」与「模型/模板进化」双飞轮：地图负责定位证据缺口，采集负责生产证据，账本负责审计与撤销，CKB 负责复用已验证经验。

## 0. 核心 IP 设计

## 2. 关键算法（伪代码）

### IP-57 CEM：证据场更新与地图条件迁移
```
def update_evidence_field(M_t, episodes, cert_engine, delta=1e-3):
    for obs in episodes:
        v = associate(M_t, obs)              # 位姿 + 语义 + 时序关联
        M_t.geo[v], M_t.sem[v] = fuse(M_t.geo[v], M_t.sem[v], obs)
        D_v = M_t.evidence[v].data + obs
        m_lo, m_hi = cert_engine.credible_margin(D_v, delta)
        p_safe = cert_engine.posterior_safe(D_v)
        M_t.evidence[v] = Evidence(
            m_lo=m_lo, m_hi=m_hi, theta=M_t.evidence[v].theta,
            p_safe=p_safe, H=binary_entropy(p_safe),
            tau=min(data_expiry(D_v), map_validity(v)),
            prov=union(obs.prov, M_t.evidence[v].prov),
            cert_hash=union(obs.cert_hash, M_t.evidence[v].cert_hash),
            critical=(abs(m_lo - M_t.evidence[v].theta) <= eps_theta
                      or binary_entropy(p_safe) >= H_min))
    return M_t

def map_conditioned_transfer(M_t, v, u, path, L_m):
    decay = sum(L_e[e] * d_sem[e] for e in path.E_sem) + L_m * eps_map(path)
    return M_t.evidence[v].m_lo - decay

def invalidate_on_map_update(M_t, changed_region, eps_reval):
    V_inv = []
    for u in M_t.V:
        if d_map(u, changed_region) <= solve_reval_radius(eps_reval):
            M_t.evidence[u].tau = now()      # 立即过期 -> 进入采集队列
            M_t.evidence[u].critical = True
            V_inv.append(u)
    return V_inv
```

### IP-58 CGA：证书引导的主动采集
```
def select_acquisition(M_t, actions, budget, lam, beta):
    V_crit = [v for v in M_t.V if M_t.evidence[v].critical]
    best, best_score = None, -inf
    for a in actions:
        if not safety_shield(a, M_t):        # 只允许已认证区/一步前沿
            continue
        if risk_estimate(a, M_t) > budget.R_max:
            continue
        IG = expected_info_gain(a, V_crit, M_t)
        cost = cost_estimate(a, M_t)
        risk = risk_estimate(a, M_t)
        score = IG / (cost + lam * risk)
        score *= (1.0 + beta * novelty_bonus(a, M_t))   # 强制探索
        if score > best_score:
            best, best_score = a, score
    return best

def expected_info_gain(a, V_crit, M_t):
    IG = 0.0
    for v in V_crit:
        J = margin_jacobian(v, a)            # d m / d observation
        Sigma_o = observation_cov(a, v)
        prior = M_t.evidence[v].posterior_var
        IG += 0.5 * log(1.0 + J.T @ inv(Sigma_o) @ J * prior)
    return IG

def safety_shield(a, M_t, delta_frontier=0.5):
    return path_inside(a, M_t.certified_region, delta_frontier)

def gap_directed_scv(M_t, V_crit, sim_budget):
    gaps = estimate_sim_real_gap(M_t, V_crit)   # 逐区域 W_1/残差热力图
    regions = topk(gaps, k=sim_budget)
    return [simulate_region(r, M_t) for r in regions]
```

### IP-59 EPL：溯源、撤销与可采信
```
def record_certificate(EPL, cert, data_episodes, derivation):
    node = CertNode(id=hash(cert), cert=cert,
                    dep=[d.id for d in data_episodes],
                    derivation=derivation, status='valid')
    EPL.add(node)
    return node

def revoke_episode(EPL, M_t, ep_id, reason):
    seeds = [n for n in EPL.nodes if ep_id in n.dep]
    affected = reverse_reachable(EPL, seeds)     # 依赖该 episode 的证书闭包
    for n in affected:
        n.status = 'unverified'
        n.revoke_reason = reason
        for v in n.cert.covered_vertices:
            M_t.evidence[v].tau = now()          # 证据场同步失效
            M_t.evidence[v].critical = True
    return affected

def admissible(cert, EPL, coverage_req=0.95, n_min=30):
    return (all(EPL.get(d).status == 'valid' for d in cert.dep)
            and cert.evidence_coverage >= coverage_req
            and cert.effective_n >= n_min
            and stratified_coverage(cert.sampling) >= coverage_req)
```

### IP-55 升级：grounded RAG（拒绝无证据合并）
```
def grounded_rag_retrieve(phi, psi, M_t, KB, EPL, k=10):
    cand = KB.retrieve(phi, psi, k=k)
    kept = []
    for c in cand:
        if not map_context_compatible(c, M_t):   # 模板适用域与地图上下文相交
            continue
        if not evidence_overlap(c.evidence, M_t.evidence):
            continue
        if not admissible(c, EPL):
            continue
        kept.append(c)
    return rerank(kept)[:5]

def grounded_merge(cands, M_t):
    # 只在共同证据支持的地图子集上合并；其余区域进入 Delta 待采集
    common = intersect_regions([c.applicable_region for c in cands])
    C = merge_templates([c.C for c in cands])
    Delta = M_t.V_crit - common
    return C, Delta
```

def car_transition_guard(e, x, cert_obj, M_t, EPL, now):
    v = locate(M_t, x)
    ev = M_t.evidence[v]
    if ev.tau <= now:                       # 证据过期
        return False, 'trig_evidence_expired'
    if not admissible(cert_obj, EPL):       # provenance 失效
        return False, 'trig_provenance_revoked'
    theta_real = cert_obj.alpha_e[e] * cert_obj.theta_sim[e]
    return ev.m_lo >= theta_real, 'ok'

def lcs_v3(x, guards, M_t, budget_us=200):
    b = cert_lookup_L0(x)                   # T-1: 5us
    ev = M_t.evidence[locate(M_t, x)]
    if ev.tau <= now or ev.critical:
        return downgrade_monotone(ev), 'need_acquire'
    U = undecided_guards(ev, guards)
    if not U:
        return ev, -1                       # T-1 决策等价
    if budget_us < 110:

    status, margin = monitor_step_INT8(quantize_obs(x))

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性保证 |
|---|---|---|---|
| IP-57 证据场更新 | O(|episodes|·(d + log|V|)) | 每节点常数元组，O(|V|) | 可信区间覆盖率 ≥ 1−δ ⟹ U_cert 校准（E87） |
| IP-57 地图条件迁移 | O(|π|) 路径长度 | O(1) | 迁移不等式成立且依赖有效 ⟹ 迁移 sound；否则触发重颁 |
| IP-57 地图失效 | O(|V|) 或空间索引 O(log|V|+k) | O(|V_inv|) | r_reval 由 ε_reval 反解 ⟹ 不漏掉受影响区域（保守） |
| IP-58 采集选择 | O(|A|·|V_crit|·d_o) / 步 | O(|A|+|V_crit|) | 安全护盾保证采集动作在认证区/一步前沿 |
| IP-58 信息增益 | O(|V_crit|·d_o^2) | O(d_o^2) | 局部线性+高斯近似下 Fisher 信息是一步 IG 的下界近似 |
| IP-59 撤销传播 | O(|EPL|+|dep|) | O(|dep|) | 反向可达闭包 ⟹ 保守撤销，宁多勿漏 |

| 端到端运行期 | 证书查询 O(log N)+证据检查 O(1) | 证据场 O(|V|) | τ 过期/撤销即降级，绝不沿用失效证书 |

## 6. 本轮最大风险

**一句话**：最大风险是「证据自证循环」——语义地图、证书引擎与采集策略共享同一套 VLM/LIO/仿真模型与同一批数据，主动采集会优先涌向模型最自信、最容易得分的地方，形成「越采集越自信、越自信越少探索」的回音室，证书覆盖率看似上升而真实盲区被系统性掩盖；因此 E94（自证/盲区审计）与 E91（溯源撤销）必须作为红线，配合独立审计集、强制探索配额与证据账本冻结回滚。
