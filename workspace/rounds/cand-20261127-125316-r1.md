### 第 4 轮灵感驱动研究记录（新循环第 1 轮，承接 v28/KTCG）

**灵感词**：桌面操作、用户体验

**直觉与动机**：

前几轮把双足机器人从「会走、会站、会切换」推进到「常识可解释、跨任务可迁移、权重可自适应」的 KTCG 九证门。但这些证书都在回答同一个问题：**机器人自身是否安全**。桌面操作把机器人放进一个**人机共享的物理工作空间**——桌沿、桌面高度、坐着的人手、待递的水杯——安全不再只是机器人状态的函数，而是（机器人, 人, 物体）三元组的联合函数。与此同时，「用户体验」提醒我们：操作员面对的也是一个共享空间——**认知工作空间**。证书再完备，如果解释延迟 2 秒、一次弹出 30 条规则、或把罕见但致命的关键规则折叠进「更多」，操作员就会要么过载、要么盲信。

于是本轮的核心直觉是：

> 桌面是物理共享工作空间，界面是认知共享工作空间；两者都需要「契约 + 前向不变性」，而不只是「过滤器」。

1. **桌面操作 → 共享工作空间契约（SWC）**：桌沿、桌面高度、人手位置构成时变安全集 S(t)。它不是对单个状态的静态检查，而是要求存在控制律使 S **前向不变**。用控制障碍函数（CBF）把「不碰桌、不碰人、放得稳」写成 b_j(s) ≥ 0 与 ḃ_j + α_j(b_j) ≥ 0，从而把「证书」从终点检查升级为沿轨迹的连续保证。

2. **用户体验 → 可度量的交互证书（UXC）**：把「好用」拆成四个可测不变量：解释延迟 τ_exp、认知负载 C_load、信任校准误差 E_trust、干预率 R_int。关键修正：干预率**不是越低越好**——过低是「自满」，过高是「不信任/过载」，因此用**健康区间** [r_lo, r_hi] 而非单边阈值；同时要求解释具备可行动性 A_action（能映射到具体控制/参数调整的比例）。

3. **二者的张力 → 透明性保护门（TPCG）**：当 UX 指标（尤其 C_load 上限）与安全透明性冲突时，绝不能为「界面清爽」而隐藏关键规则。定义「必须呈现集」C_crit：若 |C_crit| > C_cap，门必须**拒绝或升级人工**，而不是静默折叠。这把「用户体验」从「讨好用户」纠正为「在不损害用户知情权的前提下降低负担」。

**关键洞见**：桌面操作给出「空间上的共享」，用户体验给出「注意力上的共享」。二者共享同一结构——**共享资源 + 契约 + 前向不变性**。物理上用 CBF 保证人不被碰，认知上用 C_crit 保证关键信息不被吞。这样 v29 不只更安全，还更「可被人类正确监督」：安全集收缩与信任校准同时被约束，避免「证书齐全但人看不懂」的假安全。

**形式化目标（增量）**：
1. 定义 TOC（桌面操作证书）：TOC = (W_t, δ_clear, d_safe, GraspPred, StablePred)，对 (机器人, 人, 物体) 联合状态判定。
2. 定义 SWC：安全集 S = {s : b_j(s) ≥ 0, j=1..m}，并要求控制律满足 CBF 条件 ḃ_j + α_j(b_j) ≥ 0（离散形式 b_{k+1} ≥ (1 − α_j·Δt)·b_k）。
3. 定义 UXC：UXC = (τ_exp ≤ τ_max) ∧ (C_load ≤ C_cap) ∧ (E_trust ≤ ε) ∧ (R_int ∈ [r_lo, r_hi]) ∧ (A_action ≥ a_min)。
4. 定义 TPCG：KTCG ∪ TOC ∪ SWC ∪ UXC，且满足「关键规则必须呈现」约束；Exec_v29 = Exec_v28 ∩ Fil_table ∩ Fil_human ∩ Fil_ux ⊆ Exec_v28。
5. 证明/度量：(a) CBF 条件下 S 前向不变；(b) UXC 只收缩执行集，故安全性单调保持；(c) 桌面递物任务上，v29 相对 v28 桌面/人手碰撞降为 0、任务成功率 ≥ 90%，同时信任校准误差下降 ≥ 40%，干预率落入健康区间而非趋零。

**本轮最大风险**：**为满足 UX 指标（延迟/认知负载）而抑制关键规则呈现，会制造「透明性—安全性冲突」——证书齐全、界面流畅，却让操作员在不知情中过度信任，形成比信息过载更隐蔽的「静默降级」；而这种降级恰恰在 v29 的所有安全证书上显示为「通过」。**

### IP-467 Tabletop Operation Certificate (TOC)

```python
@dataclass
class TabletopOperationCertificate:
    """TOC：桌面操作证书，对（机器人, 人, 物体）联合状态判定"""
    table_height: float                 # 桌面高度 h_t
    workspace: tuple                    # ((x_lo,x_hi),(y_lo,y_hi),(z_lo,z_hi))
    clearance_margin: float = 0.05      # δ_clear
    human_safe_dist: float = 0.30       # d_safe
    grasp_library: dict = field(default_factory=dict)  # {obj_id: GraspModel}
    stability_margin: float = 0.02
    lip_margin: float = 0.03            # 桌沿水平禁入带

    def fk(self, x_r: Tensor) -> Tensor:
        """正运动学：机器人状态 -> 末端执行器位置"""
        return self._forward_kinematics(x_r)

    def barrier_table(self, s) -> float:
        """桌面/桌沿障碍：z 间隙与水平禁入带的联合最小值"""
        e = self.fk(s.x_r)
        b_z = e[2] - self.table_height - self.clearance_margin
        b_lip = self._horizontal_margin(e, self.lip_margin)
        return min(b_z, b_lip)

    def barrier_human(self, s) -> float:
        """人机间距障碍：末端到人手（含预测不确定性球）的距离"""
        e = self.fk(s.x_r)
        return float(torch.norm(e - s.x_h)) - (self.human_safe_dist + s.x_h_radius)

    def barrier_bounds(self, s) -> float:
        """工作空间盒约束"""
        e = self.fk(s.x_r)
        return self._box_margin(e, self.workspace)

    def barriers(self, s) -> list[float]:
        return [self.barrier_table(s), self.barrier_human(s), self.barrier_bounds(s)]

    def grasp_ok(self, s) -> bool:
        g = self.grasp_library.get(s.target_obj.id)
        return g is not None and g.success_prob >= 0.80

    def stability_ok(self, s) -> bool:
        """放置后物体质心投影须落在支撑多边形内（含 margin）"""
        return s.target_obj.com_proj_in_support(self.stability_margin)

    def check(self, s) -> 'TOCReport':
        b = self.barriers(s)
        return TOCReport(
            clearance=min(b),
            grasp_ok=self.grasp_ok(s),
            stable_ok=self.stability_ok(s),
            admits=(min(b) >= 0.0 and self.grasp_ok(s) and self.stability_ok(s)),
        )

@dataclass
class TOCReport:
    clearance: float
    grasp_ok: bool
    stable_ok: bool
    admits: bool
```

### IP-468 User Experience Certificate (UXC)

```python
@dataclass
class UserExperienceCertificate:
    """UXC：把「好用」形式化为可测不变量，输出 UXReport"""
    tau_max: float = 0.10                       # 解释延迟上限（s）
    load_cap: int = 5                           # C_cap 认知负载预算
    trust_eps: float = 0.10                     # 信任校准误差上限
    intervention_band: tuple = (0.02, 0.20)     # [r_lo, r_hi] 健康干预区间
    actionability_min: float = 0.60             # 可行动性下限

    def evaluate(self, ux: 'UXState') -> 'UXReport':
        checks = {
            "latency":       ux.tau_exp <= self.tau_max,
            "cognitive":     ux.c_load <= self.load_cap,
            "trust_calib":   abs(ux.trust_est - ux.reliability_est) <= self.trust_eps,
            "intervention":  self.intervention_band[0] <= ux.r_int <= self.intervention_band[1],
            "actionability": ux.a_action >= self.actionability_min,
        }
        reasons = [k for k, ok in checks.items() if not ok]
        return UXReport(
            checks=checks,
            admits=all(checks.values()),
            reasons=reasons,
            suggested_action=self._suggest(reasons),
        )

    def _suggest(self, reasons: list[str]) -> str:
        if "cognitive" in reasons:
            return "reduce_noncritical_rules_or_escalate"  # 绝不隐藏关键规则
        if "latency" in reasons:
            return "switch_to_async_explanation"
        if "intervention" in reasons and "trust_calib" in reasons:
            return "recalibrate_trust_or_request_human_check"
        return "none"

@dataclass
class UXState:
    tau_exp: float
    c_load: int
    trust_est: float
    reliability_est: float
    r_int: float
    a_action: float

@dataclass
class UXReport:
    checks: dict
    admits: bool
    reasons: list[str]
    suggested_action: str
```

### IP-469 Shared-Workspace Contract (SWC)

```python
@dataclass
class SharedWorkspaceContract:
    """SWC：联合安全集的前向不变契约（CBF 离散条件）"""
    barriers: list[Callable]      # b_j(s)，须可微
    alphas: list[Callable]        # class-K α_j
    dt: float

    def safe_margin(self, s) -> float:
        return min(b(s) for b in self.barriers)

    def cbf_residual(self, s, s_next, j: int) -> float:
        """离散 CBF 残差：b_{k+1} - (1 - α_j·dt)·b_k ≥ 0"""
        b_now = self.barriers[j](s)
        b_next = self.barriers[j](s_next)
        return b_next - (1.0 - self.alphas[j](b_now) * self.dt) * b_now

    def check_trajectory(self, traj: list) -> bool:
        for k in range(len(traj) - 1):
            for j in range(len(self.barriers)):
                if self.cbf_residual(traj[k], traj[k + 1], j) < -1e-6:
                    return False
        return True
```

### IP-470 Tabletop-Human Experience MPC (THE-MPC)

```python
@dataclass
class TabletopHumanExperienceMPC:
    """THE-MPC：KEMPC ∪ TOC ∪ SWC ∪ UXC，QP 中显式加入 CBF 约束"""
    dynamics: Callable
    horizon: int = 20
    dt: float = 0.01
    weights: dict = field(default_factory=dict)
    toc: TabletopOperationCertificate = None
    swc: SharedWorkspaceContract = None
    uxc: UserExperienceCertificate = None
    ux_state: UXState = None
    slack_var: bool = True

    def solve(self, s0) -> tuple:
        import cvxpy as cp
        N, n_x, n_u = self.horizon, len(s0.x_r), self._control_dim()
        X = cp.Variable((N + 1, n_x))
        U = cp.Variable((N, n_u))
        s = cp.Variable(N) if self.slack_var else None

        cost, constraints = 0.0, [X[0] == s0.x_r]
        for k in range(N):
            constraints.append(X[k + 1] == self.dynamics(X[k], U[k]))
            # 经验/控制成本
            cost += cp.quad_form(U[k], self.weights.get("control", 0.01) * cp.eye(n_u))
            # 知识惩罚（沿用 KT-MPC）
            cost += self._knowledge_penalty(X[k + 1])
            # SWC 的 CBF 离散约束（TOC 的 barrier 即 SWC 的 barrier）
            for j, b in enumerate(self.swc.barriers):
                b_now = b(s0 if k == 0 else X[k])
                b_next = b(X[k + 1])
                constraints.append(
                    b_next - (1.0 - self.swc.alphas[j](b_now) * self.dt) * b_now >= 0
                )
            # 软约束（仅在 CBF 不可行时放宽，且必须记录事件）
            if s is not None:
                cost += self.weights.get("slack", 100.0) * s[k]
                constraints.append(s[k] >= 0)

        prob = cp.Problem(cp.Minimize(cost), constraints)
        try:
            prob.solve(solver="OSQP", warm_start=True)
            if prob.status != "optimal":
                return self._cbf_aware_fallback(s0)
            return U.value[0], self._toc_report(s0, X.value), self._ux_report()
        except Exception:
            return self._cbf_aware_fallback(s0)

    def _knowledge_penalty(self, x) -> float:
        return 0.0  # 复用 IP-465.compute_knowledge_penalty 的实现

    def _toc_report(self, s0, traj) -> TOCReport:
        worst = None
        for k in range(len(traj)):
            s = self._joint_state(s0, traj[k])
            r = self.toc.check(s)
            worst = r if worst is None or r.clearance < worst.clearance else worst
        return worst

    def _ux_report(self) -> UXReport:
        return self.uxc.evaluate(self.ux_state)

    def _cbf_aware_fallback(self, s0) -> tuple:
        """CBF-QP 不可行：退化为「最小间隙方向」的保守控制，并上报事件"""
        u = self._repulsive_safe_control(s0)
        self._log_event("cbf_infeasible", s0)
        return u, self._toc_report(s0, [s0.x_r]), self._ux_report()

    def _control_dim(self) -> int:
        return 6
```

### IP-471 Transparency-Preserving Cert Gate (TPCG)

```python
@dataclass
class TransparencyPreservingCertGate:
    """TPCG：KTCG ∪ TOC ∪ SWC ∪ UXC，且关键规则不可被静默隐藏"""
    ktcg: 'KnowledgeTransilientCertificationGate'
    toc: TabletopOperationCertificate
    swc: SharedWorkspaceContract
    uxc: UserExperienceCertificate
    scheduler: 'UXAwareExplanationScheduler'
    theta_crit: float = 0.80

    def admits(self, plan, sensor_data: dict) -> bool:
        # 1-9：继承 KTCG 九证
        if not self.ktcg.admits(plan, sensor_data):
            return False

        # 10：桌面/人机/物体联合安全（TOC）
        joint_traj = plan.predicted_joint_traj
        for s in joint_traj:
            if not self.toc.check(s).admits:
                return False

        # 11：共享工作空间前向不变（SWC）
        if not self.swc.check_trajectory(joint_traj):
            return False

        # 12：透明性保护 + UX（先定「呈现集」，再评估 UX）
        surfaced = self.scheduler.surface(plan.active_rules, self.uxc.load_cap)
        if surfaced is None:
            # |C_crit| > C_cap：不得折叠关键规则，升级人工
            return self._escalate(plan, reason="critical_rules_exceed_load_cap")

        ux = self.uxc.evaluate(plan.ux_state)
        if not ux.admits:
            # 若仅因负载超限，可通过降级非关键规则而非隐藏关键规则解决
            return self._degrade_noncritical_or_escalate(plan, ux)

        return True

    def _escalate(self, plan, reason: str) -> bool:
        self._log(plan, event="escalate", reason=reason)
        return False  # 交回人类决策，绝不静默通过

    def _degrade_noncritical_or_escalate(self, plan, ux: UXReport) -> bool:
        if "cognitive" in ux.reasons:
            return self._escalate(plan, reason="cognitive_overload")
        if "latency" in ux.reasons:
            self.scheduler.set_async(True)
            return self.uxc.evaluate(plan.ux_state).admits
        return self._escalate(plan, reason="ux_gate")
```

### IP-472 UX-Aware Explanation Scheduler (UXES)

```python
class UXAwareExplanationScheduler:
    """UXES：异步解释 + 关键规则优先 + 陈旧度上界"""
    def __init__(self, theta_crit: float = 0.80, max_staleness: float = 0.30):
        self.theta_crit = theta_crit
        self.max_staleness = max_staleness
        self.async_mode = False

    def surface(self, rules: list, cap: int) -> list | None:
        """返回要呈现的规则集；若关键规则数超过 cap 返回 None（必须升级）"""
        crit = [r for r in rules if r.criticality >= self.theta_crit]
        if len(crit) > cap:
            return None
        others = sorted(
            (r for r in rules if r.criticality < self.theta_crit),
            key=lambda r: r.criticality, reverse=True,
        )
        return crit + others[: max(0, cap - len(crit))]

    def set_async(self, enabled: bool):
        self.async_mode = enabled

    def staleness_ok(self, age: float) -> bool:
        return age <= self.max_staleness
```

## 3. 复杂度分析（增量更新）

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 |
|---|---|---|---|
| TOC 联合检查 | O(H·(n_link + m + n_obj)) | O(m) | H≤20，n_link≤20，m≤3 个 barrier，n_obj≤5 |
| SWC 轨迹验证 | O(H·m·n_x) | O(H·n_x) | m≤3，离散 CBF 每步一次 barrier 评估 |
| UXC 评估 | O(N_rule log N_rule) | O(N_rule) | N_rule≤50，排序为主 |
| UXES 调度 | O(N_rule log N_rule) | O(C_cap) | 关键规则数通常 ≤3，C_cap=5 |
| THE-MPC 求解 | O(N·n_x³ + N·m·n_x²) | O(N·n_x + N·m) | 相比 KT-MPC 增加 m 条 CBF 约束，开销约 +8% |
| TPCG 总体 | O(N·n_x³ + H·(n_link+m) + N_rule log N_rule) | O(N·n_x + N_rule) | 关键路径仍为 QP 求解 |

**实时性**：N=20, n_x=12, n_u=6 时 THE-MPC 典型求解 6–18 ms；TOC/SWC 检查 <1 ms；UXC+UXES <1 ms；异步解释在非关键周期生成，关键路径额外开销 <1 ms，满足 50 Hz 控制周期。CBF 不可行时的回退控制 <2 ms。

## 4. 正确性论证（增量更新）

### 引理 26（TOC 的 CBF 前向不变性）

**陈述**：设 b_j(s) 连续可微，若控制律在每步满足离散 CBF 条件 b_j(s_{k+1}) ≥ (1 − α_j·Δt)·b_j(s_k) 且 α_j·Δt ∈ (0,1]，则从 b_j(s_0) ≥ 0 出发，恒有 b_j(s_k) ≥ 0。

**证明**：由条件递推得 b_j(s_k) ≥ (1 − α_j·Δt)^k · b_j(s_0)。因 α_j·Δt ∈ (0,1]，底数非负，故 b_j(s_k) ≥ 0 对所有 k 成立。若初始 b_j(s_0) > 0，则 b_j 只会以几何速率衰减而不会穿越 0。∎

### 引理 27（执行集单调收缩与安全性保持）

**陈述**：TPCG 的准入集 Exec_v29 = Exec_v28 ∩ {π : TOC(π) ∧ SWC(π) ∧ UXC(π)} ⊆ Exec_v28。因此 v28 的任何安全不变量在 v29 下仍成立。

**证明**：TPCG.admits 的第一步即调用 ktcg.admits，故 admits_v29(π) ⟹ admits_v28(π)。集合交运算只会删除元素，不会新增，故 Exec_v29 ⊆ Exec_v28。安全不变量是执行集的超集性质，收缩执行集不破坏之。∎

### 引理 28（透明性完备性：关键规则不被静默隐藏）

**陈述**：对任意规则集 R 与预算 C_cap，UXES.surface(R, C_cap) 要么返回一个包含 C_crit(R) 的集合，要么返回 None（触发升级）。因此不存在「关键规则被折叠且门仍通过」的执行路径。

**证明**：分两种情况。若 |C_crit(R)| ≤ C_cap，surface 先取全部 C_crit，再用剩余预算填充非关键规则，返回值必含 C_crit。若 |C_crit(R)| > C_cap，surface 直接返回 None，TPCG.admits 走 _escalate 分支返回 False，不产生准入。两种情况下均无静默隐藏。∎

### 引理 29（解释延迟预算的可行性）

**陈述**：若解释生成异步执行，且关键路径满足 τ_solve + τ_cert ≤ τ_max − τ_slack，同时解释陈旧度 age ≤ max_staleness，则 UXC 的延迟分项可在不牺牲控制频率的前提下达标。

**证明**：关键路径延迟 τ_crit = τ_solve + τ_cert，不包含 τ_explain。异步解释的 τ_exp 由调度器在空闲周期填充，只要 age ≤ max_staleness 即满足「信息仍然有效」的约束。将 τ_explain 移出关键路径后，τ_crit 的上界即所需条件。∎

### 定理（TPCG 的安全—透明联合保证）

**陈述**：对任意计划 Π，若 TPCG.admits(Π) = True，则 Π 同时满足：
1. KTCG 的九项安全/知识证书；
2. TOC 的桌面间隙、人机间距、抓取可行性与放置稳定性；
3. SWC 的联合安全集前向不变；
4. UXC 的延迟、负载、信任校准、干预率、可行动性全部达标；
5. **不存在被静默隐藏的关键规则**（透明性完备）。

**证明**：由 admits 的合取结构逐项调用（1–4）；第 5 项由引理 28 保证：surface 返回 None 时门走升级分支，不会准入。因此所有准入路径都满足五项。∎

## 5. 实验设计（桌面操作 + 用户体验）

**平台**：MuJoCo 双足机器人 + 桌面（高 0.75 m）+ 坐姿人体模型（可动上肢）+ 物体（杯/盘/布）。对照与消融：

| 组别 | 配置 | 目的 |
|---|---|---|
| B0 | v28（KT-MPC/KTCG） | 基线：无桌面/人机/UX 约束 |
| B1 | v29 去掉 UXC（只加 TOC+SWC） | 隔离「物理共享空间」收益 |
| B2 | v29 去掉「关键规则必须呈现」 | **暴露静默降级/自满陷阱** |
| B3 | v29 完整 TPCG | 完整方案 |

**任务**：① 桌上取杯；② 向坐姿人类递物；③ 擦桌（长程接触）。每任务 100 次随机初始位姿，共 300 次。

**指标**：桌面/桌沿穿透率、人机最小间距违例率、抓取成功率、放置后 1 s 物体稳定率、任务成功率、τ_exp（p50/p95）、NASA-TLX（C_load 校准）、E_trust、R_int、A_action。

**预期结果**：
- B0 → B1：桌面/人手碰撞显著下降，任务成功率略降（更保守）；验证 SWC 前向不变有效。
- B1 → B3：碰撞保持为 0，任务成功率回升（UX 减少无效干预），E_trust 下降 ≥40%，R_int 落入 [r_lo, r_hi]。
- **B2 vs B3（关键对照）**：B2 的 C_load 更低、R_int 更低、界面更「顺滑」，但未检测到的失败率更高、E_trust 更大——直接量化「静默降级」风险。B3 的 C_load 略高但 E_trust 显著更低，证明透明性保护的必要性。
- 延迟：B3 的 τ_exp p95 < 100 ms（异步），控制周期保持 50 Hz。

**统计**：配对 bootstrap 置信区间；对 E_trust 与未检测失败率做相关分析，验证「界面顺滑 ↔ 过度信任」的耦合。

## 7. 本轮最大风险（最终确认）

**一句话**：**为满足 UX 指标（延迟/认知负载）而抑制关键规则呈现，会制造「透明性—安全性冲突」——证书齐全、界面流畅，却让操作员在不知情中过度信任，形成比信息过载更隐蔽的「静默降级」；而这种降级恰恰在 v29 的所有安全证书上显示为「通过」，因此必须用 C_crit 硬约束与未检测失败率来对抗，而不能只优化延迟与负载数字。**
