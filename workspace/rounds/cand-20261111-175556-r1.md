# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感驱动研究循环第 2 轮；本轮灵感：「跌倒恢复」×「演示数据」）

> 第 54 轮已把技能组合从“能力匹配”推进为“动作空间剖面 + 云边联合证书”。本轮不再继续堆叠动作维度，而是换一个更苛刻的检验场：**跌倒恢复**。核心判断是：跌倒恢复不是一段“站起来”的轨迹模仿，而是一个**可恢复性核（recoverability kernel）的穿越与回归问题**；而**演示数据不是轨迹燃料，而是这个核边界的稀疏、带偏采样**。由此产生三个核心矛盾：H22：正常演示集中在可恢复性核内部，边界与核外样本稀缺，导致“演示上很成功、真实近跌倒时虚假安全”；H23：恢复动作包含冲击阶段，成功但冲击超预算的演示不能作为可部署证据；H24：云端聚合演示得到的核与边端本体/地面/负载下的真实核存在偏移，恢复证书会在边界处失效。

## 0. 直觉与动机

**灵感 1（跌倒恢复 = 可恢复性核的穿越，而非单技能）**
直觉：与其问“哪个技能能站起来”，不如问“当前状态还在不在可恢复域内”。定义可恢复性核 `K_ε`：从状态 `x` 出发，存在某个策略在时间窗 `T` 内回到直立安全集 `U` 并保持 `T_hold` 的概率至少 `1-ε`。所谓“跌倒”，就是状态轨迹穿出 `K_ε` 的事件；恢复技能的作用不是复制演示动作，而是把状态重新推回 `K_ε` 并增加恢复裕度。这样，跌倒检测、恢复规划、证书判定共享同一个几何对象：核及其边界 `∂K_ε`。

**灵感 2（演示数据 = 边界采样器，而非轨迹复制器）**
直觉：普通行为克隆假设演示状态近似独立同分布，但恢复场景恰恰相反：正常演示大量落在核内部，那里恢复容易、信息量低；真正高信息量的样本在 `∂K_ε` 附近，尤其是“近跌倒但救回来了”和“跌倒了但恢复失败”的负演示。于是提出**边界加权演示**：样本权重随到 `∂K_ε` 的距离指数上升，并给近跌倒/失败样本额外权重。进一步，**体积覆盖率不是充分统计量，边界覆盖率才是**：一个在核内部到处都有演示、但边界完全空白的模型，可以在演示集上接近满分，却在真实跌倒前兆处任意犯错。

**灵感 3（恢复动作包络 = 跌倒前缓冲 + 冲击缓冲 + 跌倒后起身）**
直觉：第 54 轮的动作剖面 `α_S` 只描述“技能能否执行某个动作”，但跌倒恢复天然分三段：跌倒前保护（收臂、屈膝、降低质心）、冲击阶段（缓冲、避免头部/关节受冲击）、跌倒后起身（翻身、撑地、回到站立）。恢复动作包络 `E_R=(A_pre,A_buf,A_post)` 把这三段显式分开，并把**冲击预算** `J_R` 作为与成功率并列的硬约束。一个“成功站起来但砸坏关节”的演示不是正样本，而是需要被证书拒绝的负资产。

**灵感 4（演示-反事实互证 = 防止“幸运的成功”)**
直觉：演示只告诉我们“这个动作做成了”，却没告诉我们“换一个动作是否也能做成、甚至更稳”。在低数据、高风险的恢复场景里，成功可能来自初始条件的幸运，而不是动作的因果有效性。于是对边界附近的演示做**反事实回放**：在仿真中替换为局部动作，比较恢复价值；若演示动作与局部最优动作的差距过大，则说明演示存在混杂，不能直接用于核估计与策略蒸馏。这把“演示数据质量”从数据清洗问题提升为**可证书化的因果一致性问题**。

**灵感 5（云边恢复层级 = 云端先验 + 边端核校准 + 独立反射层）**
直觉：云端可以用跨机器人、跨场景的演示估计一个较平滑的核先验 `K_c` 与恢复技能图 `G_R`；边端必须用本体感受器与局部近跌倒数据校准 `K_e`。两者在边界处最容易分歧，因此证书不能只看“云端认为可恢复”，还要看**边端核的局部裕度**。更关键的是：跌倒发生前后的几十毫秒内，不能把安全寄托在学习策略上，必须有一个不依赖演示数据的**保护反射层** `π_reflex`（收臂、屈膝、柔顺、撑地保护）。云边契约的顺序应是：先反射保命，再核判定，最后恢复规划。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（可恢复性核与跌倒事件）**
状态空间 `X`，直立安全集 `U ⊆ X`，恢复时间窗 `T`，保持时间 `T_hold`，策略类 `Π`。可恢复性核
```
K_ε = { x∈X | sup_{π∈Π} P( ∃t∈[0,T]: x_t∈U ∧ ∀s∈[t,t+T_hold]: x_s∈U | x_0=x, π ) ≥ 1-ε }
```
跌倒时刻 `τ_f = inf{ t | x_t ∉ K_ε }`。恢复成功当且仅当 `τ_f` 之后在 `T` 内回到 `U` 并保持 `T_hold`。对有符号边界距离 `m_K(x)`，`x` 在核内时 `m_K(x)=dist(x,∂K_ε)>0`，核外为负；`m_K` 同时充当**恢复裕度**。

**定义 122（恢复动作包络与恢复鲁棒性）**
恢复技能 `R` 的动作包络 `E_R=(A_pre,A_buf,A_post)`，分别对应跌倒前保护、冲击缓冲、跌倒后起身三个阶段。阶段条件动作剖面 `α_R(a|φ)∈[0,1]`，`φ∈{pre,buf,post}`。恢复鲁棒性 `ρ_R(d)=P(Recover | 扰动 d)`，冲击成本
```
J_R = E[ ∫_0^{τ_rec} ||F_contact(t)|| dt ]
```
恢复证书必须同时满足 `ρ_R(d) ≥ ρ_min` 与 `J_R ≤ J_max`，不允许用高冲击换取成功率。

**定义 123（演示数据的边界支持测度）**
演示集 `D={(x_i,a_i,x_i',ℓ_i)}`，标签 `ℓ_i∈{nominal,near_fall,fall,recover,fail_recover}`。边界权重
```
w_i = exp(-|m_{K_est}(x_i)|/σ) · (1 + λ_n·1[ℓ_i∈{near_fall,fall,fail_recover}])
```
加权经验测度 `μ_D^w = Σ_i w_i δ_{x_i} / Σ_i w_i`，有效样本数 `N_eff=(Σw_i)^2/Σw_i^2`。体积覆盖与边界覆盖分别为
```
cov_D^V(S)  = ∫_S p_D^w(x) dx / vol(S)
cov_D^∂K    = ∫_{tube(∂K_est,δ)} p_D^w(x) dx / vol(tube(∂K_est,δ))
```
其中 `p_D^w` 为 `μ_D^w` 的核密度估计。**边界覆盖是本轮的一等公民，体积覆盖只作辅助诊断。**

**定义 124（演示-反事实一致性）**
恢复价值 `Q_R(x,a)`，局部动作集 `A_loc(x)`。演示动作的反事实遗憾
```
Δ_cf(D) = E_{x~μ_D^w}[ max(0, max_{a'∈A_loc(x)} Q_R(x,a') - Q_R(x,a_demo)) ]
```
若 `Δ_cf(D) ≤ δ_cf`，则称演示在恢复意义下**反事实一致**；否则该演示只能作为“成功案例”而不能作为“因果证据”。

**定义 125（恢复证书）**
```
R_cert = (K_est, m_min, cov_D^∂K, ρ_R, τ_rec, J_R, Δ_cf, evidence)
```
可部署条件：`x_0∈K_est`，`m_K(x_0) ≥ δ_K`，`cov_D^∂K ≥ θ_b`，`ρ_R(d) ≥ ρ_min ∀d`，`τ_rec ≤ τ_max`，`J_R ≤ J_max`，`Δ_cf ≤ δ_cf`。任一条件失败都返回可解释的拒因，而不是降级为“试试看”。

**定义 126（云边恢复契约）**
```
C_rec = (K_c, K_e, G_R, R_cert, π_reflex, Explain_loop, fallback_rule)
```
- `K_c`：云端跨场景演示估计的核先验；`K_e`：边端本地校准核；
- `G_R`：恢复技能图，节点含 `{upright, near_fall, fallen, get_up, recover}`，边含恢复转换与冲击成本；
- `π_reflex`：不依赖学习策略的毫秒级保护反射；
- `fallback_rule`：若 `x∉K_e`、`m_K(x)<δ_K` 或 `τ_f` 已触发，则先执行 `π_reflex`，再决定是否进入学习型恢复；
- `Explain_loop`：把边端失败片段以脱敏负演示回传云端，驱动 `K_c` 重估与恢复技能图修补。

## 2. 关键算法 伪代码

### IP-121 RKN（Recoverability Kernel Network）

```python
def estimate_recoverability_kernel(D_pos, D_neg, K_prior, sigma, alpha):
    X = states(D_pos) + states(D_neg)
    y = [1]*len(D_pos) + [0]*len(D_neg)
    lab = labels(D_pos) + labels(D_neg)
    w = [boundary_weight(x, K_prior, sigma, l) for x, l in zip(X, lab)]
    clf = WeightedClassifier().fit(X, y, sample_weight=w)

    # 物理先验 + 加权 conformal 校准，给出假安全率上界
    scores = nonconformity_scores(clf, X, y)
    q = weighted_quantile(scores, 1 - alpha/n_eff_correction(w))
    return ConformalKernel(clf, q, K_prior)

def boundary_weight(x, K_prior, sigma, label):
    d = abs(signed_distance(x, K_prior))
    w = exp(-d / sigma)
    if label in ('near_fall', 'fall', 'fail_recover'):
        w *= (1 + lambda_neg)
    return w
```

### IP-122 BWD（Boundary-Weighted Demonstrations）

```python
def active_boundary_query(K_est, D, budget, value_fn):
    candidates = sample_near_boundary(K_est, delta_b)
    acquisition = []
    for x in candidates:
        u = kernel_uncertainty(K_est, x)       # 边界附近应最大
        v = value_fn(x)                        # 下游任务/跌倒代价
        c = query_cost(x)
        acquisition.append((u * v / c, x))
    return top_k(acquisition, budget)

def reweight_demonstrations(D, K_est, sigma):
    for (x, a, x2, lab) in D:
        D.w[x] = boundary_weight(x, K_est, sigma, lab)
    return normalize_weights(D)
```

### IP-123 RAE（Recovery Action Envelope）

```python
def recovery_envelope(skill, phases=('pre', 'buf', 'post')):
    E_R, profile = {}, {}
    for phi in phases:
        A_phi = skill.phase_action_space(phi)
        for a in A_phi:
            profile[(phi, a)] = skill.occupancy(phi, a)   # α_R(a|φ)
        E_R[phi] = A_phi
    J = estimate_impact_cost(skill, E_R)                   # 冲击预算
    return RecoveryEnvelope(E_R, profile, J)
```

### IP-124 FDC（Fall-Demonstration Contrastive Certificate）

```python
def counterfactual_consistency(D_boundary, Q_R, sim, delta_cf):
    gaps = []
    for (x, a_demo, _, lab) in D_boundary:
        q_demo = Q_R(x, a_demo)
        q_best = max(Q_R(x, a2) for a2 in local_actions(x))
        gaps.append(max(0.0, q_best - q_demo))
    delta = weighted_mean(gaps, D_boundary.w)
    if delta > delta_cf:
        return ('reject', 'causal_confounding', delta)
    return ('ok', delta)
```

### IP-125 RRC（Recovery Routing Certificate）

```python
def recovery_route(x_f, G_R, K_est, R_cert):
    start = fall_mode(x_f, K_est)          # near_fall / fallen / impact
    goal = 'upright'
    path, cost = a_star(
        G_R, start=start, goal=goal,
        cost=lambda e: e.time + w_j * e.impact + w_m * max(0, delta_K - e.margin),
        constraint=lambda e: e.impact <= R_cert.J_max and e.margin >= delta_K
    )
    if path is None:
        return ('reject', 'no_safe_route')
    return ('ok', path, cost)
```

### IP-126 CERC（Cloud-Edge Recovery Contract）

```python
def cloud_edge_recover(x, K_c, K_e, G_R, R_cert, pi_reflex):
    # 1) 毫秒级反射层永远先于学习策略
    if x not in K_e or margin(K_e, x) < delta_K:
        return ('reflex', pi_reflex(x))

    # 2) 云边核在边界处分歧过大，拒绝并按解释回传
    if kernel_disagreement(K_c, K_e, x) > Delta_K:
        exp = explain_kernel_gap(K_e, x)
        return ('recalibrate', exp)

    # 3) 恢复证书逐项检查
    if not deployable(R_cert, x):
        return ('reject', certificate_violations(R_cert, x))

    # 4) 搜索低冲击、高裕度恢复路径
    path = recovery_route(x, G_R, K_e, R_cert)
    if path[0] != 'ok':
        return ('reflex_and_replan', pi_reflex(x), path)
    return ('recover', path)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| RKN | `O(n log n)` 建近邻 + `O(n)` conformal | `O(n)` | 加权可交换性、假安全率可校准 |
| BWD | `O(n·d)` 权重 + `O(b·d)` 主动查询 | `O(n)` | 边界覆盖非零、权重二阶矩有限 |
| RAE | `O(|A_pre|+|A_buf|+|A_post|)` | `O(|A|)` | 三阶段动作不相交、冲击可测 |
| FDC | `O(n_b·m·T)` 反事实回放 | `O(n_b)` | 仿真保真度、局部动作覆盖 |
| RRC | `O(|V| log |V| + |E|)` | `O(|V|+|E|)` | 路径满足冲击与裕度约束 |
| CERC | `O(d + τ_loop)` | `O(|V|+|E|)` | 反射层独立、核分歧可检测 |

**命题 1（体积覆盖不是恢复充分的）**
设恢复成功概率 `η(x)` 在边界 `∂K_ε` 附近 `L`-Lipschitz。若演示在核内部体积覆盖很高、但在 `∂K_ε` 的 `δ`-管状邻域覆盖为零，则存在两个与演示一致、但在边界处恢复判定相反的可恢复性核；因此任何仅由体积覆盖给出的误差界都不能控制近跌倒处的假安全率。**推论：恢复演示采集应以 `cov_D^∂K` 为优化目标，而不是以状态空间均匀覆盖为目标。**

**定理（恢复部署的保守下界）**
假设第 54 轮 (A26)–(A28) 成立，并新增：**(A29)** 加权 conformal 给出 `P(x∈K_est \ K) ≤ α_fs`；**(A30)** `cov_D^∂K ≥ θ_b` 且演示反事实遗憾 `Δ_cf(D) ≤ δ_cf`；**(A31)** 恢复回放中仿真与真实的 TV 距离 ≤ `β_sim`。则对通过 `R_cert` 的恢复：
```
P_success ≥ 1 - α_fs - β_sim - δ_cf - Σ_d(1-ρ_R(d)) - P(τ_rec > τ_max)
```
该下界不追求紧致，只用于**保守否决**：任何一项无法估计时，证书应直接拒绝，而不是用经验成功率替代。

## 6. 本轮最大风险

**一句话**：边界加权演示与可恢复性核把跌倒恢复从“事后模仿”变成“边界上的可验证决策”，但最大风险是演示分布对跌倒前兆的系统性缺失使 `K_est` 在 `∂K` 外产生虚假安全区，边端直到进入不可逆域才触发恢复；必须以物理可行性先验、加权 conformal、负演示/反事实互证与独立反射层四重护栏，宁可误触发保护，绝不把演示支持不到的边界当作可恢复。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（RKN×BWD×RAE×FDC×RRC×CERC）

> 承接第 54 轮产物 v31。本轮把“跌倒恢复”作为检验动作空间与云边证书的极端场景，把“演示数据”从行为克隆燃料重新定义为**可恢复性核边界的带偏采样**。新增六个算子：
> - **RKN（Recoverability Kernel Network）**：边界加权 + 加权 conformal 的可恢复性核估计；
> - **BWD（Boundary-Weighted Demonstrations）**：以边界覆盖为目标的演示重加权与主动采集；
> - **RAE（Recovery Action Envelope）**：跌倒前/冲击/起身三阶段动作包络与冲击预算；
> - **FDC（Fall-Demonstration Contrastive Certificate）**：演示动作的反事实一致性证书；
> - **RRC（Recovery Routing Certificate）**：跌倒模式到直立模式的安全路径搜索；

## 2. 关键算法 伪代码

### IP-121 RKN

```python
def estimate_recoverability_kernel(D_pos, D_neg, K_prior, sigma, alpha):
    X = states(D_pos) + states(D_neg)
    y = [1] * len(D_pos) + [0] * len(D_neg)
    lab = labels(D_pos) + labels(D_neg)
    w = [boundary_weight(x, K_prior, sigma, l) for x, l in zip(X, lab)]

    clf = WeightedClassifier().fit(X, y, sample_weight=w)
    scores = nonconformity_scores(clf, X, y)
    q = weighted_quantile(scores, 1 - alpha / n_eff_correction(w))
    return ConformalKernel(clf, q, K_prior)

def boundary_weight(x, K_prior, sigma, label):
    d = abs(signed_distance(x, K_prior))
    w = exp(-d / sigma)
    if label in ('near_fall', 'fall', 'fail_recover'):
        w *= (1 + lambda_neg)
    return w

def deployable_margin(K_est, x, delta_K):
    return inside(K_est, x) and signed_distance(x, K_est) >= delta_K
```

### IP-122 BWD

```python
def active_boundary_query(K_est, D, budget, value_fn):
    candidates = sample_near_boundary(K_est, delta_b)
    scored = []
    for x in candidates:
        u = kernel_uncertainty(K_est, x)     # 边界附近最大
        v = value_fn(x)                      # 跌倒代价 / 任务价值
        scored.append((u * v / query_cost(x), x))
    return top_k(scored, budget)

def reweight_demonstrations(D, K_est, sigma):
    for (x, a, x2, lab) in D:
        D.w[x] = boundary_weight(x, K_est, sigma, lab)
    D.N_eff = (sum(D.w.values()) ** 2) / sum(w * w for w in D.w.values())
    return normalize_weights(D)
```

### IP-123 RAE

```python
def recovery_envelope(skill, phases=('pre', 'buf', 'post')):
    E_R, profile = {}, {}
    for phi in phases:
        A_phi = skill.phase_action_space(phi)
        for a in A_phi:
            profile[(phi, a)] = skill.occupancy(phi, a)
        E_R[phi] = A_phi
    J = estimate_impact_cost(skill, E_R)
    return RecoveryEnvelope(E_R, profile, J)

def recovery_skill_ok(R, rho_min, J_max):
    return (min(R.rho.values()) >= rho_min) and (R.J_R <= J_max)
```

### IP-124 FDC

```python
def counterfactual_consistency(D_boundary, Q_R, simulator, delta_cf):
    gaps = []
    for (x, a_demo, _, lab) in D_boundary:
        q_demo = Q_R(x, a_demo)
        q_best = max(Q_R(x, a2) for a2 in local_actions(x))
        gaps.append(max(0.0, q_best - q_demo))
    delta = weighted_mean(gaps, D_boundary.w)
    if delta > delta_cf:
        return ('reject', 'causal_confounding', delta)
    return ('ok', delta)
```

### IP-125 RRC

```python
def recovery_route(x_f, G_R, K_est, R_cert):
    start = fall_mode(x_f, K_est)          # near_fall / fallen / impact
    path, cost = a_star(
        G_R, start=start, goal='upright',
        cost=lambda e: e.time + w_j * e.impact + w_m * max(0, delta_K - e.margin),
        constraint=lambda e: e.impact <= R_cert.J_max and e.margin >= delta_K
    )
    if path is None:
        return ('reject', 'no_safe_route')
    return ('ok', path, cost)
```

### IP-126 CERC

```python
def cloud_edge_recover(x, K_c, K_e, G_R, R_cert, pi_reflex):
    if x not in K_e or margin(K_e, x) < delta_K:
        return ('reflex', pi_reflex(x))

    if kernel_disagreement(K_c, K_e, x) > Delta_K:
        return ('recalibrate', explain_kernel_gap(K_e, x))

    violations = certificate_violations(R_cert, x)
    if violations:
        return ('reject', violations)

    path = recovery_route(x, G_R, K_e, R_cert)
    if path[0] != 'ok':
        return ('reflex_and_replan', pi_reflex(x), path)
    return ('recover', path)

def explain_kernel_gap(K_e, x):
    # 至少返回：边界符号、最近边界方向、触发核分歧的传感器通道
    return Explanation(sign=margin_sign(K_e, x),
                       normal=boundary_normal(K_e, x),
                       channels=top_sensitivity_channels(K_e, x))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| RKN | `O(n log n + n)` | `O(n)` | 加权 conformal 假安全率 ≤ α_fs |
| BWD | `O(n·d + b·d)` | `O(n)` | 边界覆盖非零、`N_eff` 可诊断 |
| RAE | `O(|A_pre|+|A_buf|+|A_post|)` | `O(|A|)` | 三阶段正交、冲击可测 |
| FDC | `O(n_b·m·T)` | `O(n_b)` | 局部动作覆盖、仿真保真 |
| RRC | `O(|V| log |V| + |E|)` | `O(|V|+|E|)` | 路径满足冲击/裕度硬约束 |
| CERC | `O(d + τ_loop)` | `O(|V|+|E|)` | 反射层独立、核分歧可解释 |

**命题（边界覆盖优先于体积覆盖）**
恢复成功概率在 `∂K_ε` 附近变化最快；若演示在 `∂K_ε` 的 `δ`-管状邻域覆盖为零，则仅凭核内部的高体积覆盖无法约束边界处的分类误差，存在与演示集一致、但在近跌倒状态判定相反的核。因此演示采集的优化目标应为 `max cov_D^∂K s.t. 演示预算`，而不是均匀覆盖状态空间。

**定理（恢复部署的保守下界）**
假设 (A26)–(A28) 成立，并新增：**(A29)** 加权 conformal 给出 `P(x∈K_est\K) ≤ α_fs`；**(A30)** `cov_D^∂K≥θ_b` 且 `Δ_cf≤δ_cf`；**(A31)** 恢复回放仿真-真实 TV 距离 ≤ `β_sim`。则通过 `R_cert` 的恢复满足
```
P_success ≥ 1 - α_fs - β_sim - δ_cf - Σ_d(1-ρ_R(d)) - P(τ_rec > τ_max)
```
该下界用于**保守否决**：任一项不可估计时证书拒绝，而非以经验成功率替代。

**报告规范**：必须同时报告“平均恢复成功率”和“边界假安全率 / 冲击超预算率”。只报告前者会把“在容易样本上很稳、在近跌倒处失效”的方案误判为成功。

## 6. 本轮最大风险

**一句话**：边界加权演示与可恢复性核把跌倒恢复从“事后模仿”变成“边界上的可验证决策”，但最大风险是演示分布对跌倒前兆的系统性缺失使 `K_est` 在 `∂K` 外产生虚假安全区，边端直到进入不可逆域才触发恢复；必须以物理可行性先验、加权 conformal、负演示/反事实互证与独立反射层四重护栏，宁可误触发保护，绝不把演示支持不到的边界当作可恢复。
