# 第 70 轮（承接第 69 轮「FLUID-RAS 不确定性二分与主动多模态交互」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「低成本方案」×「三维感知」）

> R69 把不确定性一分为二，并教会闭环「问」：aleatoric 收紧、epistemic 用看/问/触去消解。但 R69 默认了两件从未写进证书的事：**（a）几何感知是可信且几乎免费的输入；（b）多个证据源是正交独立的。** 一旦把系统搬到低成本 3D 硬件上，两条同时失效——深度稀疏、单目尺度不可辨、ToF 多路径、结构光在强光下失效、纹理缺失区三角化发散；更糟的是，这些失败**按场景材质与结构成片出现**，于是「多个便宜传感器一致」很可能只是它们共享了同一个盲区。
>
> 本轮两个灵感各补一块：
> - **低成本方案**不是「降级」，而是**换约束**：感知从被动输入变成主动采购，最便宜的信息动作往往不是「问人」，而是「动一下视角」；每一焦耳、每一毫秒、每一块钱都要与它买到的任务风险下降对账。
> - **三维感知**把 R69 的标量不确定性**空间化**：不确定住在具体区域（深度协方差、覆盖空洞、尺度/位姿漂移、遮挡、重复结构），而只有「下游策略对它敏感」的区域才值得花钱看。同时，便宜传感器的物理失效模式是**可预测、可几何自检**的——低成本不等于低严谨。
>
> 核心命题：**把 R69 的「动作模态上的不确定性」投影为三维空间中的「风险加权几何不确定性场」，并按全成本（能量/时延/算力/社交/风险）对每一次消除动作计价；同时把「证据正交」从假设降级为必须逐场景层认证的结论。** 命名 **FRUGAL-RAS**（Flow-conditioned, Risk-weighted, Uncertainty-Gated, Active Lookaround）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**下一焦耳/下一块钱该花在哪块几何上，以及这些便宜的独立证据是不是真的独立**」——省下来的成本如果买到的是一致性幻觉，那比不省更危险。

## 0. 直觉与动机

**灵感 1（低成本方案 → 从「重建得更好」到「只买会改变决策的那块几何」）**
直觉：贵的 3D 传感器用钱买掉了「视角规划」这件事——稠密、可靠、几乎无洞，策略可以被动消费。便宜的传感器把这个负担还给系统：有洞、有偏、有尺度歧义，于是**看哪里、从哪看、要不要再动一步**重新成为动作。设计目标随之改变：不是最大化重建质量，而是最大化「每单位全成本买到的任务风险下降」。这与 R69 的 VoI 同源，但计价对象从「模态熵」变成「任务风险」，计价单位从「信息」变成「钱/焦耳/毫秒/社交打扰」。

**灵感 2（三维感知 → 不确定性有空间地址，风险有权重）**
直觉：R69 的 U_epi 是一个动作模态分布上的标量；但真实歧义在空间里是**分区的**：桌面上的杯子深度很准，玻璃门后的椅子既没覆盖又尺度可疑，远处重复纹理的柱子位姿漂移。把每个区域的几何不确定性写下来还不够，必须再乘一个「下游策略对该区域几何误差的敏感度」：同样 2cm 的深度误差，在薄障碍物碰撞边界上致命，在远处墙面上无关紧要。于是 VoI 从标量变成一个**风险加权空间场** ρ(r)=w_task(r)·U_geo(r)，主动感知变成在这个场上做「哪里值得买」的拍卖。

**灵感 3（便宜 ≠ 盲目 → 失效模式是物理可预测的）**
直觉：昂贵系统靠冗余掩盖失效；便宜系统的失效恰恰**有清晰的物理成因**：镜面/透明表面使 ToF 多路径与结构光散斑失效，无纹理区使立体匹配退化，重复结构使三角化产生幽灵平面，强光淹没红外。既然成因可知，就能在**没有真值**时自检：多视角重投影一致性、跨物理原理（飞行时间 vs 三角化 vs 运动视差）的深度分歧、平面/重力/已知尺寸先验。低成本系统的正确姿态不是「相信它」，而是「**精确地知道自己在哪里瞎**」。

**灵感 4（最便宜的信息动作是动一下，不是问一句）**
直觉：R69 的信息动作里，问人的社交成本被低估了；而几何歧义有一个几乎免费的解法——**运动视差**。换一个视角，遮挡解除、三角化基线变长、尺度从运动中获得约束。对几何歧义，动一下通常严格优于问一句：人不擅长给米制尺度，也容易被问烦。于是本轮把动作按成本分层：复用已有视角 < 认证过的微运动 < 主动照明/投影 < 换传感器 < 问人。**问人只保留给语义/规范歧义，或任何可达视角都几何不可观测的情形。** 这直接回应 R69 的交互疲劳风险（E297）。

**灵感 5（便宜的独立证据可能共谋 → 独立性必须被认证，而不是被假设）**
直觉：R69 的证据纪律是「k 个正交证据源一致才定案」。但低成本 3D 的「多源」经常不独立：同一批相机共享标定误差，所有深度原理在玻璃上一起错，重复结构让所有三角化一起产生同一个幽灵面。此时 k 个源一致不是证据，而是**共模偏差的放大**。鲁棒统计早就警告过：相关误差不会被多数投票消掉。所以本轮必须把「正交」从一个默认假设，降级为一个**逐场景层（材质/几何/光照/运动）可测量的证书**；认证不了独立，就必须去做「打破该层」的动作（换视角、换物理原理、主动探测），或退回 R69 的纯保守。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（FRUGAL-RAS 总览与四不变式）** FRUGAL-RAS = (L3B, GUC, RWV, MAG, CIC, AEG, FMA3, RAS-WM†)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **空间证据纪律**：任何进入控制/安全包络的几何断言必须携带「认证不确定包络 + 来源溯源」；未认证的 3D 点不得定义安全边界；
(iii) **全成本硬预算**：每个感知/交互动作按 (能量、时延、算力、社交、风险) 全成本计价，单位回合预算 B 硬约束；边际成本超过其风险加权 VoI 的动作不得执行；
(iv) **条件独立**：多源一致只有在该场景层被 CIC 认证为误差去相关时才计为正交证据；否则标记为 consensus_suspect，不得单独收缩安全包络。

**定义 311（低成本分层三维信念 L3B）** 对区域 r，维护
`b(r) = (μ_r, Σ_r, o_r, P_r, p_r, τ_r)`，
其中 μ_r 为几何均值（TSDF / Gaussian splat 局部面元），Σ_r 为深度/尺度/位姿联合协方差，o_r ∈ [0,1] 为可观测度（多视角覆盖与基线），P_r 为来源集（传感器、视角、时间戳、标定版本），p_r 为 R69 语义/身份后验，τ_r 为逐源信任。更新只在认证源上做贝叶斯融合；来自 consensus_suspect 层的观测只进影子缓存，不进 b(r)。

**定义 312（几何不确定性分解）** `U_geo(r) = U_scale + U_pose(r) + U_depth(r) + U_cov(r) + U_sem(r)`：
- U_scale：全局米制规范（单目规范自由度）；
- U_pose：里程计漂移在 r 处的投影；
- U_depth：由视差/飞行时间/散斑物理模型给出的局部深度方差；
- U_cov：未观测/被遮挡/超出量程造成的覆盖空洞；
- U_sem：R69 的身份/属性歧义映射到该区域的语义分量。
并区分「可由运动/换视角约化」与「在当前预算内不可约」两部分（对应 R69 的 U_epi / U_ale 在几何侧的镜像）。

**定义 313（风险加权空间不确定性场 GUC）** `ρ(r) = w_task(r) · U_geo(r)`，其中 `w_task(r) = ∂ E[R_task] / ∂ ε_geo(r)` 是下游策略在该区域的任务风险敏感度，可用流策略对几何扰动的有限差分或碰撞/约束裕度的雅可比估计。ρ 是主动感知的「标价场」：它回答的不是「哪里最不确定」，而是「**哪里最不确定且最要命**」。

**定义 314（风险加权三维 VoI，RWV）** 对感知/视角动作 v：
`RV-VoI(v) = E[ΔR_task | v] − λ_c c(v)`，
其中 `E[ΔR_task|v] ≈ Σ_r ρ(r) · P(v 观测到 r 且约化其不确定性)`。选 `v* = argmax RV-VoI`，s.t. 动作过 C-RAS-WM 认证且不越预算。注意：熵最大化的经典 next-best-view 只是 ρ 均匀时的特例；当 w_task 非均匀时，经典 NBV 会去看「最花但最无关」的墙。

**定义 315（低成本动作分层与运动占优）** 信息动作按全成本排序：
`reuse(已有视角) ≺ micro-motion(认证微运动/运动视差) ≺ active-sense(主动照明/投影/换物理原理) ≺ sensor-switch ≺ ask(问人)`。
当目标歧义是**几何性**的（身份已定、只需更准的位姿/深度/尺度），且 `c_move < c_ask` 且运动段通过安全认证，则运动视差**支配**提问（引理 20）。提问只保留给：语义/规范歧义、几何在任何可达视角下不可观测、或 CIC 要求打破场景层的情形。

**定义 316（米制锚图 MAG 与尺度可观测性）** 维护稀疏锚点图：地面/重力、已知尺寸物体或标定板、轮速/IMU 预积分、结构平行/正交先验。尺度可观测 Gramian
`G_scale = Σ_a J_aᵀ Ω_a⁻¹ J_a`；
`rank(G_scale)` 与条件数给出尺度是否可辨。若退化（纯旋转、零基线、无锚点），**尺度视为未消解 epistemic，必须靠运动/锚点解决，绝不允许靠问人解决**，且禁止一切依赖绝对尺度的安全断言。

**定义 317（共模独立证书 CIC）** 将场景-动作划分为层 z（材质、几何类别、光照、运动、距离档）。对每层估计跨源误差相关 `ρ_cm(z)`（由残差历史 + 失效模式预测器 + 探测激励得到），定义有效独立度
`k_eff(z) = k / (1 + (k−1) ρ_cm(z))`。
仅当 `ρ_cm(z) ≤ τ_cm`（或 `k_eff ≥ k_min`）时，该层内的一致才被计为正交证据；否则进入定义 319。

**定义 318（共模不可约引理的形式化用途）** 把源误差分解为 `e_i = e_cm + e_i^⊥`，`Var(e_cm)=ρ_cm σ²`。任何对称融合规则在 k 源一致后，独立分量按 1/√k 降，但**共模分量不降**。因此 `E[融合后误差] ≥ √ρ_cm σ − O(σ/√k)`。这条不变量是 CIC 存在的理由：k 再大也买不回被共享的盲区。

**定义 319（共识可疑与破层动作）** 若多源一致但 `ρ_cm(z)` 高（典型：镜面、玻璃、无纹理、重复结构），标记 `consensus_suspect`，**禁止**据此收缩 AEG 包络。系统必须选择「破层」动作：改变视角/基线、切换物理原理（ToF ↔ 立体 ↔ 运动视差）、主动照明/偏振/投影、或材质探针；破层后仍不可分，则退回 R69 的 `λ_floor(U_ale+U_epi)` 纯保守。

**定义 320（宽松成本模型）** `c(g) = α_e E + α_t T + α_c C_comp + α_s S_social + α_r R_risk`，所有项由部署预算归一化；`B` 为单位回合硬预算。RWV 在 `Σ c(g) ≤ B` 的背包约束下求解；任何单步 `c(g) > B_remaining` 直接不可行，退化到已有视角/保守。

**定义 321（随时安全包络 AEG）** 安全包络 `E_t = {x : P_occ(x) > p_safe}` 按认证几何界向外膨胀 `b(U_geo)`；仅当 CIC 认证的独立证据到达时才允许收缩，且收缩必须留下重放证书。单调性：无认证新证据时 `E_{t+1} ⊆ E_t` 的逆不成立——包络只允许「有证据地缩、无证据地胀」。这与 R68 的 λ_floor、R69 的两级退避串联，保证安全侧永不弱于前者。

**定义 322（FMA-3D 三通道第二意见）** 在 R69 的 (r_res, Δa) 之外增加几何一致性通道 `g_res`：多视角重投影误差、跨物理原理深度分歧、平面/重力结构残差。判别模式扩展为：
- `r_res↓, Δa↑`：行为-标定失配（R69 缓变故障）；
- `g_res↑, r_res↓`：几何层被标定/融合吸收（便宜深度源共模漂移）；
- `Δa↑, g_res↑, r_res↓`：条件编码与几何同时偏离，最高优先级。
**注意**：Δa 与 g_res 都条件于同一观测 o，可能共享同一条件误差，故二者不自动正交，必须过 CIC；这一点写入证书，避免「第二意见」变成「同一个错的两次复述」。

**定义 323（FRUGAL 证书 J_FRUGAL）**
`J_FRUGAL = (J_FLUID, l3b_ver, envelope_bound_p95, scale_rank, scale_cond, rho_cm_used, k_eff_min, consensus_suspect, cost_spent/B, g_res_p95, frugal_ver)`。
Valid ⇔ `Valid(J_FLUID)` ∧ 尺度可观测性满足（或所有尺度相关断言已禁用）∧ 使用到的每个证据层 `k_eff ≥ k_min`（否则 consensus_suspect 且已走保守）∧ 成本未越界 ∧ AEG 单调性证书成立。

**定义 324（随时成本调度器）** 分层 anytime 调度：第 0 层免费复用已有视角；第 1 层认证微运动；第 2 层主动感知；第 3 层问人；第 4 层保守退避。只有当上一层的最优 `RV-VoI ≤ 0` 或预算耗尽时才进入下一层。该结构保证：任何时刻中断都能给出「当前层内最优且安全」的动作，P99 时延可证。

**定义 325（与 FLUID/R68 的严格退化边界）** 当 (a) 所有区域 `U_geo=0` 且 CIC 认证独立，或 (b) 预算 B=0，或 (c) 尺度不可观测且无锚点，或 (d) 所有证据层 `ρ_cm > τ_cm`，FRUGAL 必须逐指令退化为 R69 FLUID（并进一步在 VoI≤成本时退化为 R68）。退化路径上安全参数只增不减。

**定义 326（参与式审计 VQAuditor-F）** 新增审计对象：每个几何断言是否携带溯源与包络；每个「独立证据」是否真的过了 CIC；共识可疑是否被恰当上报；破层动作是否安全；成本账是否与证书一致；问题是否被用来解决本可动一下解决的几何歧义（提问浪费审计）。结论回灌 AuditBuf，成为下一轮成本先验与 ρ_cm 先验。

## 2. 关键算法骨架

```python
# IP-264 L3B：低成本分层三维信念（只在认证源上融合）
class Layered3DBelief:
    def fuse(self, obs, provenance, cic):
        for r in obs.regions:
            if cic.stratum_suspect(r, provenance):
                self.shadow[r].append(obs)          # 影子缓存，不进安全信念
            else:
                self.b[r] = bayes_fuse(self.b[r], obs, provenance)

    def geo_uncertainty(self, r):
        return (self.u_scale + self.u_pose(r) + self.u_depth(r)
                + self.u_cov(r) + self.u_sem(r))

# IP-265 GUC：风险加权空间不确定性场（任务敏感度 × 几何不确定性）
def risk_field(belief, policy, task):
    rho = {}
    for r in belief.regions:
        w = task.risk_sensitivity(r, policy)        # 碰撞/约束裕度的雅可比
        rho[r] = w * belief.geo_uncertainty(r)
    return rho

# IP-266 RWV：风险加权三维 VoI + 成本最优视角
def choose_view(rho, candidates, budget, c_ras_wm, cost):
    best = None
    for v in candidates:                            # reuse < motion < sense < ask
        if not budget.allows(v) or not c_ras_wm.certify(v): continue
        gain = sum(rho[r] * prob_observe_and_resolve(v, r) for r in rho)
        score = gain - lambda_c * cost(v)
        if best is None or score > best.score: best = (v, score)
    return best if best and best.score > 0 else None

# IP-267 MAG：尺度可观测性证书
def scale_certificate(anchors, motion):
    G = sum(J(a).T @ inv(Omega(a)) @ J(a) for a in anchors)
    rank, cond = matrix_rank(G), condition_number(G)
    observable = rank >= 2 and cond < KAPPA_MAX and not degenerate(motion)
    return observable, rank, cond              # 不可观测 ⇒ 禁止绝对尺度断言

# IP-268 CIC：共模独立证书（逐场景层）
def independence_certificate(residuals, strata, failure_pred):
    for z in strata:
        rho_cm = estimate_correlation(residuals[z]) + failure_pred.correlation(z)
        k_eff = k / (1 + (k - 1) * rho_cm)
        certify[z] = (rho_cm <= TAU_CM and k_eff >= K_MIN)
    return certify

# IP-270 FMA-3D：几何一致性第二意见（与 Δa 共享条件，需过 CIC）
def fma3(policy, belief, xi_obs, o, o_cal):
    delta_a = abs(-policy.log_likelihood(xi_obs, o)
                  + policy.log_likelihood(xi_obs, o_cal))
    g_res = (multi_view_reproj_residual(belief)
             + cross_physics_depth_disagreement(belief)
             + structural_prior_residual(belief))
    return delta_a, g_res

# IP-274 主闭环（继承 R69，仅在不确定性处置处插入 FRUGAL 层）
def FRUGAL_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    M.l3b.fuse(obs, obs.provenance, M.cic)                 # 认证源才进信念
    scale_ok, rank, cond = M.mag.scale_certificate(...)
    rho = M.guc.risk_field(M.l3b, M.fmp, M.task)          # 风险加权空间场
    # 1) 几何歧义优先用「动一下」消解（运动视差支配提问）
    v = M.rwv.choose_view(rho, M.candidates(o), M.budget, M.c_ras_wm, M.cost)
    if v is not None and v.kind != 'ask':
        M.execute_certified(v); obs = M.resense(v)
        M.l3b.fuse(obs, obs.provenance, M.cic)
    # 2) 语义/规范歧义才回到 R69 的交互；几何不可观测时禁止问尺度
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, M.adaptive_K(z)), z, M.fmp.mode_head)
    g = M.mint.choose_interaction(modes, o, M.budget) if U_epi > TAU_EPI else None
    if g is not None and not M.cic.stratum_suspect_for(g, obs):
        answer = M.cia.execute(g); U_epi = M.cia.update_belief(modes, answer)
    # 3) 三通道第二意见（标定不可吸收 + 几何一致）
    da, g_res = M.fma3.flow_and_geometry(M.fmp, M.l3b, M.last_action, o, o_calibrated)
    line3 = (g_res > TAU_G) and (M.last_r_res < TAU_RES)    # 几何被吸收
    # 4) 安全包络：只允许有证据地缩、无证据地胀
    env = M.aeg.update(M.l3b, M.cic, inflation=M.envelope_inflation())
    # 5) 风险缩放：未消解 epistemic 仍走 R69 两级退避
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    if line3 or not scale_ok:
        lam = max(lam, 0.8); k = min(k, k_cal_shrink(...))   # 回 R68 最保守
    # 6) 选择模态、认证前缀、审计
    mode = select_mode(modes, U_epi, lam)
    k = M.c_ras_wm.certified_prefix(mode.a[:k], env, ...)
    M.vqa_f.submit_async(v, g, rho, da, g_res, M.budget.ledger)
    return k, lam, mode, (U_ale, U_epi)
```

## 3. 推导

**引理 19（风险加权信息增益下界）** 设任务风险对区域几何误差满足 Lipschitz（A99：`|R_task(ε) − R_task(ε')| ≤ L_r ‖ε_r − ε'_r‖`），且区域间误差可加。则对任意感知动作 v，
`E[ΔR_task|v] ≥ Σ_r w_task(r) · E[Δ U_geo(r)|v] − L_r·高階项`。
即 RV-VoI 是真实任务风险下降的一阶下界；系：**当 w_task 非均匀时，熵最大化 NBV 一般不是最优**——它把预算花在「最不确定但无关」的区域。

**引理 20（几何歧义下运动占优）** 设歧义为纯几何（身份后验已定），存在认证可达视角使目标区域可观测度从 o 升到 o'（o' > o），且 `c_move < c_ask`。则 `RV-VoI(move) − RV-VoI(ask) ≥ (w_task·ΔU_geo(move) − w_task·ΔU_geo(ask)) − (c_move − c_ask) > 0` 当几何收益不低于语义收益。系：低成本 3D 闭环的提问频率应随「运动可用性」单调下降，直接缓解 R69 的交互疲劳（E297 的镜像）。

**引理 21（共模不可约）** 在定义 318 的分解下，任何 k 源对称融合的残余误差满足 `E‖e_fused‖ ≥ √ρ_cm σ − C σ/√k`。因此当 `ρ_cm > τ_cm` 时，增加源数不能把误差压到安全阈值以下；必须「破层」（改变物理原理/视角/材质激励）才能降低 ρ_cm。系：CIC 不是可选优化，而是低成本多源系统安全性的必要条件。

**定理 18（FRUGAL 严格包含 FLUID 与 R68）** 在 A99 与 R69 的 A95–A98 下，FRUGAL 的 anytime 分层策略在任意状态的期望风险 ≤ FLUID；当定义 325 的任一退化条件成立时，两者逐指令相同；再叠加 `VoI≤c` 时退化到 R68。安全侧：AEG 的「无证据只胀不缩」与 λ 单调不降保证包络不弱于前代。效率侧：运动视差替代提问、风险加权 NBV 替代熵 NBV，分别节省社交成本与感知成本。

**定理 19（随时安全与无突变）** 分层调度在任意中断点返回当前层最优且经 C-RAS-WM 认证的动作；AEG 的膨胀方向与 λ_floor 的单调性共同保证控制连续、安全包络不突缩；换装/提交不变式（R68 定理 15）保持。⇒ 低成本降级只降低效率，不降低安全下界。

## 6. 本轮最大风险

**一句话**：FRUGAL-RAS 的全部便宜都建立在「便宜的独立证据真的独立」这一前提上——**若低成本 3D 源在玻璃、镜面、无纹理或重复结构上一起失败，而 CIC 又没能在该场景层识别出共模相关，那么 k 源一致会把同一个盲区认证成「已验证的几何」，系统会据此收缩安全包络并自信地少看/不问，于是省钱直接买来一个更安静的撞墙方式**。

**次级风险与缓解**：
1. **风险敏感度 w_task 估错**（把无关区域当致命/反之）→ 用碰撞/约束裕度雅可比 + 保守上界，E302 消融；
2. **运动本身不安全或超时**（换视角诱发碰撞/时间窗过期）→ 微运动必须过 C-RAS-WM 认证（定理 19）；
3. **CIC 的 ρ_cm 需要数据/先验，冷启动不可靠** → 分层先验 + 主动探测激励 + 默认保守（未认证即 consensus_suspect）；
4. **L3B 表示漂移**（TSDF/splat 长期融合累积偏置）→ 溯源证书 + 增量重放 + E311；
5. **把几何可解的问题拿去问人**（提问浪费/社交成本）→ 定义 315 分层 + VQAuditor-F 提问浪费审计；
6. **尺度不可观测时仍做绝对断言** → MAG 证书硬门控（定义 317），不可观测即禁用相关安全断言。

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** 零学习写操作继承；空间证据纪律（几何断言必须带认证包络 + 溯源）；全成本硬预算；条件独立（只有 CIC 认证层内的一致才算正交证据）。

**定义 315（动作分层与运动占优）** `reuse ≺ micro-motion ≺ active-sense ≺ sensor-switch ≺ ask`；几何歧义且运动认证时，运动支配提问；提问只给语义/规范歧义或几何不可观测。

**定义 316–317（MAG 与尺度可观测）** 地面/重力/已知尺寸/轮速 IMU 作米制锚；`rank(G_scale)` 与条件数决定尺度是否可辨；不可辨即禁用绝对尺度断言，且绝不允许靠问人解决尺度。

**定义 318–319（CIC 与共识可疑）** 逐层估计 `ρ_cm`、`k_eff`；一致仅当 `ρ_cm≤τ_cm` 才计入证据；否则标记 consensus_suspect，禁止据此缩包络，必须做破层动作（换视角/换物理原理/主动激励）或退回 R69 保守。

**定义 320–321（成本与 AEG）** 全成本模型 + 背包硬预算；安全包络「有证据才缩、无证据只胀」，与 λ_floor 串联，保证安全侧单调。

**定义 326（VQAuditor-F）** 审计几何溯源、CIC 认证、共识可疑、破层安全、成本账一致性、以及「本可动一下却去问人」的提问浪费。

## 3. 关键算法伪代码

```python
# IP-264 L3B：只在认证源上融合；可疑层进影子缓存
class Layered3DBelief:
    def fuse(self, obs, prov, cic):
        for r in obs.regions:
            if cic.stratum_suspect(r, prov): self.shadow[r].append(obs)
            else: self.b[r] = bayes_fuse(self.b[r], obs, prov)

# IP-265 GUC：风险加权空间不确定性场
def risk_field(belief, policy, task):
    return {r: task.risk_sensitivity(r, policy) * belief.geo_uncertainty(r)
            for r in belief.regions}

# IP-266 RWV：风险加权三维 VoI，运动优先
def choose_view(rho, candidates, budget, c_ras_wm, cost):
    best = None
    for v in candidates:                          # reuse < motion < sense < ask
        if not budget.allows(v) or not c_ras_wm.certify(v): continue
        gain = sum(rho[r] * prob_observe_and_resolve(v, r) for r in rho)
        score = gain - lambda_c * cost(v)
        if best is None or score > best.score: best = (v, score)
    return best if best and best.score > 0 else None

# IP-267 MAG：尺度可观测性硬门控
def scale_certificate(anchors, motion):
    G = sum(J(a).T @ inv(Omega(a)) @ J(a) for a in anchors)
    ok = matrix_rank(G) >= 2 and condition_number(G) < KAPPA_MAX and not degenerate(motion)
    return ok, matrix_rank(G), condition_number(G)

# IP-268 CIC：共模独立证书
def independence_certificate(residuals, strata, failure_pred):
    out = {}
    for z in strata:
        rho_cm = estimate_correlation(residuals[z]) + failure_pred.correlation(z)
        out[z] = (rho_cm <= TAU_CM and k / (1 + (k-1)*rho_cm) >= K_MIN)
    return out

# IP-270 FMA-3D：行为 + 几何双通道（共享条件，须过 CIC）
def fma3(policy, belief, xi, o, o_cal):
    da = abs(-policy.log_likelihood(xi, o) + policy.log_likelihood(xi, o_cal))
    g  = (multi_view_reproj_residual(belief)
          + cross_physics_depth_disagreement(belief)
          + structural_prior_residual(belief))
    return da, g

# IP-274 主闭环：R69 + FRUGAL 层
def FRUGAL_RAS_round(M, obs):
    z, o = M.mtm.forward(...); M.cof.step(...)
    M.l3b.fuse(obs, obs.provenance, M.cic)
    scale_ok, _, _ = M.mag.scale_certificate(...)
    rho = M.guc.risk_field(M.l3b, M.fmp, M.task)
    v = M.rwv.choose_view(rho, M.candidates(o), M.budget, M.c_ras_wm, M.cost)
    if v is not None and v.kind != 'ask':
        M.execute_certified(v); M.l3b.fuse(M.resense(v), obs.provenance, M.cic)
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, M.adaptive_K(z)), z, M.fmp.mode_head)
    g = M.mint.choose_interaction(modes, o, M.budget) if U_epi > TAU_EPI else None
    if g is not None and not M.cic.stratum_suspect_for(g, obs):
        U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    da, g_res = M.fma3.flow_and_geometry(M.fmp, M.l3b, M.last_action, o, o_calibrated)
    line3 = (g_res > TAU_G) and (M.last_r_res < TAU_RES)
    env = M.aeg.update(M.l3b, M.cic, M.envelope_inflation())
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    if line3 or not scale_ok: lam = max(lam, 0.8); k = min(k, k_cal_shrink(...))
    mode = select_mode(modes, U_epi, lam)
    k = M.c_ras_wm.certified_prefix(mode.a[:k], env, ...)
    M.vqa_f.submit_async(v, g, rho, da, g_res, M.budget.ledger)
    return k, lam, mode, (U_ale, U_epi)
```

## 4. 推导

**引理 19（风险加权信息增益下界）** 在 A99（任务风险对区域几何误差 Lipschitz）与区域误差可加下，`E[ΔR_task|v] ≥ Σ_r w_task(r)·E[ΔU_geo(r)|v] − 高阶项`。系：w_task 非均匀时，熵最大化 NBV 一般次优。

**引理 20（几何歧义下运动占优）** 纯几何歧义、存在认证可达视角提升可观测度、且 `c_move<c_ask` 时，运动视差的 RV-VoI 严格高于提问。系：提问频率随运动可用性单调下降，缓解交互疲劳。

**引理 21（共模不可约）** 源误差 `e_i=e_cm+e_i^⊥`，`Var(e_cm)=ρ_cm σ²`。任意对称融合后 `E‖e_fused‖ ≥ √ρ_cm σ − Cσ/√k`；故 `ρ_cm>τ_cm` 时增加源数不能达标，必须破层（换物理原理/视角/主动激励）。系：CIC 是低成本多源系统的安全必要条件，不是可选优化。

**定理 18（严格包含 FLUID 与 R68）** A99 + R69 的 A95–A98 下，FRUGAL 任意状态期望风险 ≤ FLUID；定义 325 任一退化条件成立时逐指令相同；叠加 `VoI≤c` 退化为 R68。AEG「无证据只胀不缩」与 λ 单调不降保证安全包络不弱于前代。

**定理 19（随时安全与无突变）** anytime 分层在任意中断点返回当前层最优且经 C-RAS-WM 认证的动作；AEG 膨胀方向与 λ_floor 单调性保证包络不突缩；R68 定理 15 的换装/提交不变式保持 ⇒ 控制连续、无突变。低成本只降效率，不降安全下界。

## 7. 本轮最大风险

**一句话**：FRUGAL-RAS 的全部便宜都押在「便宜的独立证据真的独立」上——**若低成本 3D 源在玻璃、镜面、无纹理或重复结构上一起失败，而 CIC 未能在该场景层识别出共模相关，k 源一致就会把同一个盲区认证成「已验证的几何」，系统据此收缩安全包络并自信地少看/不问——省钱最终买来的是一种更安静的撞墙方式**。

**次级风险与缓解**：w_task 估错（碰撞/约束裕度雅可比 + 保守上界 + E302）；运动不安全/超时（C-RAS-WM 认证 + 定理 19）；CIC 冷启动不可靠（分层先验 + 主动探测 + 未认证即 consensus_suspect）；L3B 长期漂移（溯源证书 + 增量重放 + E311）；把几何可解题拿去问人（定义 315 分层 + VQAuditor-F 提问浪费审计）；尺度不可观测仍做绝对断言（MAG 硬门控）。
