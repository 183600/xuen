# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC IP-153~160；灵感循环第 7 轮；本轮灵感：「物体泛化」×「地形适应」）

> 第 60 轮把「场景」升级为可预测的阻抗先验 π_scene(K|z)，实现了「先认知后执行」的离散场景适应。但**两个结构性缺口**尚未解决：
> 1. **物体泛化鸿沟**：Z_scene 是固定 N 类的枚举集，π_scene(K|z) 每类一张表。真实世界物体是**开放集**——没见过的杯子、软硬未知的桌面、从未标注的容器，都不在表内；一旦 o ∉ O_seen，只能回退通用先验，第 60 轮建立的场景优势瞬间归零。泛化能力被「闭集完备假设」卡死。
> 2. **地形离散跳变**：κ_scene 只能检测「从 z_old 切换到 z_new」的跳变，但地形是**沿路径连续变化的场**（坡度 θ、摩擦 μ、柔顺性 c、粗糙度 r 渐变），不存在明确切换点。离散分类器在过渡带输出模糊后验，使 K_safe 在过渡区振荡，缺失**连续地形适应**与**接触前预调**。
> 3. **更本质的耦合**：物体与地形是联合作用的——同一只杯子在光面桌面与地毯上的阻抗先验不同；第 60 轮的单一场景标签无法表达「新物体 × 新地形」的**交叉泛化**。

## 0. 直觉与动机

**灵感 1（物体泛化 → 物体阻抗指纹 OIF）**
直觉：泛化不是「认出新类别」，而是**在物理属性空间里插值**。杯子、工具、容器千差万别，却共享同一套物理属性：质量 m、表面摩擦 μ_s、柔顺性 c、几何重心 g、纹理粗糙度 ρ。只要把物体编码进这个属性空间，未见过的物体就不再是「类别外」，而是「属性空间中的一个新点」——其阻抗先验可由邻近已见对象核回归得到。关键洞见：**把「类别泛化」降维成「属性泛化」，泛化能力来自属性空间的连续性（Lipschitz），而不是分类器的闭集完备性。**

**灵感 2（地形适应 → 连续地形场 CTF）**
直觉：地形不是离散标签，而是沿路径定义的连续场 τ(x) = (θ, μ, c, r)。机器人每走一步都在「采样」这个场：滑移率、力导数突变、姿态偏差都是地形的观测。用 GP 对本体感受残差做回归，得到 τ̂(x) 与认知不确定度 σ_τ²(x)。关键洞见：**地形适应要「向前看一步」——用 ∇τ̂(x) 预测前方地形变化，在接触前调整 K，而不是接触后被动补偿。** 但预测必须被 passivity 约束，否则「预测性阻抗」会注入能量导致失稳。

**灵感 3（物体-地形联合先验 OTJP）**
直觉：K 的先验应同时条件于物体与地形，但没有足够数据覆盖所有组合。用**可加分解** π(K|o,τ) ≈ N(μ_o + μ_τ + μ_int, Σ_o + Σ_τ + Σ_int)：物体主效应、地形主效应各自可学，交互项只在少量跨域数据上学习；未见组合 (o*, τ*) 由两个主效应相加得到，这是结构化的「交叉泛化」。关键洞见：**加性结构把 O(|O|·|T|) 的组合泛化降为 O(|O|+|T|) 的因子泛化，代价是承认交互项可能缺失——用保守上界兜底。**

**灵感 4（OOD 门控 + 泛化证书 Cert_gen）**
直觉：泛化一定会外推，外推一定会错。与其假装不会错，不如显式度量「离已知多远」：属性距离 d_a、地形后验方差 σ_τ²、阻抗偏移 K_shift、耗散裕度 passivity_margin。只有四项都落在安全域内才允许「认知先行」，否则退回第 60 轮的保守通用先验。关键洞见：**泛化能力必须配一张「泛化证书」，把「我能外推多远」变成可审计的量，而不是隐式的乐观。**

**灵感 5（GTAL 闭环 + PCE+++++）**
直觉：闭环为 物体→属性→地形→联合先验→EEIS/ERTC 编译→执行→残差→更新属性/地形→写回记忆。预算在第 60 轮 B_cog 基础上新增 B_gen（属性探测、元更新、记忆容量）与 B_terrain（GP 推断、前视计算、残差采样）；任一耗尽即退化为「通用先验」或「无前视」，绝不透支执行安全。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（物体阻抗指纹 OIF，Object Impedance Fingerprint）** 指纹 F(o) = (a(o), z_o, μ_K, Σ_K)。其中：
- **可解释属性向量**：a(o) = (m, μ_s, c, g, ρ) ∈ A ⊂ R⁵（质量、表面摩擦、柔顺性、几何重心、纹理粗糙度），由视觉/触觉/几何描述子估计。
- **隐编码**：z_o = ψ(o) ∈ Z ⊂ R^d，捕捉难以显式建模的残余（涂层、内部结构、装配刚度）。
- **属性-阻抗映射**：g = (g_μ, g_Σ)，π_obj(K|o) = N(K; g_μ(a(o), z_o), g_Σ(a(o), z_o))。
- **互补性**：a(o) 提供可解释外推坐标，z_o 提供残余拟合能力；二者缺一不可。

**定义 162（属性空间泛化 OG-Transfer）** 给定已见对象集 O_s = {(o_i, K_i)}，属性距离 d_a(o,o') = ‖a(o) − a(o')‖_Λ（加权 Mahalanobis 距离，Λ 为属性尺度矩阵）。对未见对象 o*：
```
w_i = k_h(d_a(o*, o_i)) · k_z(‖z_{o*} − z_{o_i}‖)
μ_K(o*) = Σ_i w_i K_i / Σ_i w_i
K̂(o*) = μ_K(o*) + Δ_meta(o*)                    # Δ_meta 为元学习残差修正
d_a(o*, O_s) = min_i d_a(o*, o_i)
```
**泛化界**：‖K(o*) − K̂(o*)‖ ≤ L_g · d_a(o*, O_s) + ε_meta，其中 L_g 为 g 对 a 的 Lipschitz 常数。据此定义**泛化半径** R_gen = min{ d : L_g·d + ε_meta ≤ δ_K }。泛化不是无限的，而是**被属性距离显式限界**。

**定义 163（连续地形场 CTF，Continuous Terrain Field）** 地形场 τ(x) = (θ(x), μ(x), c(x), r(x)) ∈ T，x = (x, y) 为平面坐标。观测模型：
```
y_t = h(τ(x_t)) + η_t
y_t = (slip_t, ‖Ḟ_t‖, ‖e_pose_t‖, t_contact_settle)   # 本体感受残差
τ̂(x) = m(x) + k(x,X)[K_XX + σ_n²I]^{-1}(Y − m(X))      # GP 后验均值
σ_τ²(x) = k(x,x) − k(x,X)[K_XX + σ_n²I]^{-1}k(X,x)     # 认知不确定度
```
地形变化率 ∇τ̂(x) = ∂τ̂/∂x 用于前视预测 τ̂(x + Δx)；σ_τ²(x) 大表示「未采样区域，不可轻信」。

**定义 164（地形自适应阻抗 TAI，Terrain-Adaptive Impedance）** 自适应律：
```
K_terrain(x) = K_base + ΔK(τ̂(x), ∇τ̂(x); α)
ΔK_lead = α · J_τ · ∇τ̂(x) · Δx                # 前视项：把前方地形变化转为阻抗预调
```
**无源约束**：阻抗更新不得注入能量。存在能量函数 V(e, ė) 使
```
V̇ ≤ −eᵀD e + P_in,   D = K_d − ½ Ḣ ≻ 0,   P_in ≤ 0
```
于是 K_terrain 投影到无源集 K_passive：若 λ_min(D) < ε_pass，则补正 K_d ← K_d + (ε_pass − λ_min)I。稳定性结论：若 τ̂、∇τ̂ 有界，则「机器人 + 阻抗 + 自适应律」闭环一致最终有界（UUB）。

**定义 165（物体-地形联合先验 OTJP，Object-Terrain Joint Prior）**
```
π(K|o, τ) = N( μ_o(z_o, a) + μ_τ(τ̂(x)) + μ_int(z_o, τ̂(x)),
                Σ_o + Σ_τ + Σ_int )
```
- μ_o：物体主效应；μ_τ：地形主效应；μ_int：交互项，仅用少量跨域数据学习。
- 若跨域数据不足：令 μ_int = 0，Σ_int = Σ_int^max（保守膨胀）。
- **因子泛化**：未见组合 (o*, τ*) 的先验由两个主效应相加给出；交互缺失的误差由 Σ_int^max 显式兜底，绝不隐式乐观。

**定义 166（泛化-地形自适应闭环 GTAL）** 算子 GTAL(M, o, x, delta_f_req)：
```
① OIF   : a(o), z_o ← ψ(o)
② CTF   : τ̂(x), σ_τ²(x), ∇τ̂(x) ← GP.update(residual_history)
③ OTJP  : π(K|o,τ) ← compose(μ_o, μ_τ, μ_int; Σ_o, Σ_τ, Σ_int)
④ GenGate: if d_a(o*,O_s) > R_gen or σ_τ²(x) > R_τ:
               π ← π_general                     # 退回第 60 轮通用先验
⑤ TAI   : K_adapt ← project_passive(K_base + ΔK_lead)
⑥ Compile: K_safe ← EEIS.compile_with_prior(π, K_adapt, delta_f_req)
⑦ Cert  : Cert_gen ← build_cert(d_a, σ_τ², K_shift, passivity_margin)
⑧ Lock  : ERTC.lock_constraints(K_safe.constraints)
⑨ Execute: telemetry, EV-exec ← closed_loop_exec_probe(...)
⑩ Update: CTF.update(x, residual); OIF.update(o, EV-exec); OTJP.update(...)
⑪ Memory: memory_writeback(z_o, τ̂, K_safe, EV-exec)
⑫ Return: (K_safe, Cert_gen, EV-exec, D⁺, τ̂, σ_τ²)
```

**定义 167（泛化证书 Cert_gen）** Cert_gen = (d_a, σ_τ², K_shift, passivity_margin, valid)。其中：
- **属性外推距离** d_a = d_a(o*, O_s)；
- **地形认知方差** σ_τ² = σ_τ²(x)；
- **阻抗偏移** K_shift = ‖K_safe − μ_prior‖_{Σ_prior^{-1}}（Mahalanobis 偏移）；
- **耗散裕度** passivity_margin = λ_min(K_d − ½Ḣ)。
```
valid = (d_a ≤ R_gen) ∧ (σ_τ² ≤ R_τ) ∧ (K_shift ≤ ΔK_max) ∧ (passivity_margin ≥ ε_pass)
```
valid = false → 降级：优先退回 π_general，仍不满足则 K_conservative；若 K_conservative = ∅ 则 DEGRADE_EXEC。**证书是「认知先行」与「执行安全」之间的硬闸门。**

**定义 168（泛化-地形预算 PCE+++++）** 在 B_cog = (B_scene, B_intent, B_ros, B_exec) 基础上扩展：
```
B_gen     = (Property_probe_budget, Meta_update_rate, Memory_capacity)
B_terrain = (GP_update_freq, Lookahead_horizon, Residual_sampling)
voi_gen(π) = VOI_meta_pessimistic(π) − cost_gen − cost_terrain − cost_cog − cost_exec
cost_gen     = λ_probe·Probe_cost + λ_meta·Meta_update_cost + λ_mem·Memory_cost
cost_terrain = λ_gp·GP_update_cost + λ_lead·Lookahead_cost + λ_res·Residual_cost
```
备用策略：B_gen 耗尽 ⇒ 冻结属性外推，使用最近邻对象先验；B_terrain 耗尽 ⇒ 关闭前视仅做被动适应；B_ros 异常 ⇒ 本地闭环；B_exec 耗尽 ⇒ 第 60 轮原有降级。

### IP-161 OIF（物体阻抗指纹）

```python
class ObjectImpedanceFingerprint:
    def __init__(self, attr_dim=5, latent_dim=8):
        self.encoder = ObjectEncoder(latent_dim)
        self.g_mu = PropertyToImpedanceMean()
        self.g_sigma = PropertyToImpedanceCov()
        self.Lambda = np.eye(attr_dim)

    def extract_properties(self, obj):
        return np.array([obj.mass, obj.friction, obj.compliance,
                         obj.geometry_centroid, obj.texture_roughness])

    def encode(self, obj):
        a = self.extract_properties(obj)
        z = self.encoder(obj.rgbd, obj.tactile, a)
        mu = self.g_mu(a, z)
        sigma = self.g_sigma(a, z)
        return ObjectFingerprint(a=a, z=z, mu=mu, sigma=sigma)

    def property_distance(self, f1, f2):
        d = f1.a - f2.a
        return float(np.sqrt(d @ self.Lambda @ d))
```

### IP-162 OG-Transfer（属性空间泛化）

```python
class PropertySpaceGeneralizer:
    def __init__(self, seen_fps, seen_K, L_g=0.8, eps_meta=0.05, k=5):
        self.seen, self.K = seen_fps, seen_K
        self.L_g, self.eps_meta, self.k = L_g, eps_meta, k
        self.meta_corrector = ResidualMetaLearner()

    def predict(self, fp_star):
        dists = np.array([fp_star.property_distance(o) for o in self.seen])
        idx = np.argsort(dists)[:self.k]
        w = np.array([np.exp(-dists[i] / max(np.median(dists), 1e-6)) for i in idx])
        mu = np.tensordot(w / w.sum(), self.K[idx], axes=(0, 0))
        mu = mu + self.meta_corrector(fp_star)
        d_min = float(dists.min())
        bound = self.L_g * d_min + self.eps_meta      # 泛化误差上界
        return mu, float(d_min), bound

    def generalization_radius(self, delta_K):
        return max(0.0, (delta_K - self.eps_meta) / self.L_g)
```

### IP-163 CTF（连续地形场）

```python
class TerrainFieldEstimator:
    def __init__(self, lengthscale=0.2, noise=0.05):
        self.X, self.Y = [], []
        self.gp = GaussianProcess(kernel=RBF(lengthscale), noise=noise)

    def residual_observation(self, telemetry):
        slip = (telemetry.v_cmd - telemetry.v_actual) / max(abs(telemetry.v_cmd), 1e-6)
        dF = np.linalg.norm(np.gradient(telemetry.force))
        e_pose = np.linalg.norm(telemetry.attitude_error)
        return np.array([slip, dF, e_pose, telemetry.contact_settle])

    def update(self, x, telemetry):
        self.X.append(np.asarray(x))
        self.Y.append(self.residual_observation(telemetry))
        self.gp.fit(np.asarray(self.X), np.asarray(self.Y))

    def query(self, x, lookahead=0.1):
        tau_hat = self.gp.predict(x)
        sigma2 = float(self.gp.predict_var(x))
        grad = self.gp.gradient(x)
        direction = grad / max(np.linalg.norm(grad), 1e-6)
        tau_lead = self.gp.predict(np.asarray(x) + lookahead * direction)
        return tau_hat, sigma2, grad, tau_lead
```

### IP-164 TAI（地形自适应阻抗 + 无源投影）

```python
class TerrainAdaptiveImpedance:
    def __init__(self, K_base, alpha=0.3, eps_pass=0.05):
        self.K_base, self.alpha, self.eps_pass = K_base, alpha, eps_pass

    def adapt(self, tau_hat, grad, tau_lead):
        dK = self.alpha * (tau_lead - tau_hat)          # 前视项
        K = self.K_base + self.J_tau(tau_hat) @ dK
        return self.project_passive(K)

    def project_passive(self, K):
        D = K.Kd - 0.5 * K.Hdot
        lam = float(np.linalg.eigvalsh(D).min())
        if lam < self.eps_pass:
            K.Kd = K.Kd + (self.eps_pass - lam) * np.eye(len(K.Kd))
        return K
```

### IP-165 OTJP（物体-地形联合先验）

```python
class ObjectTerrainJointPrior:
    def __init__(self, mu_o, mu_tau, Sigma_o, Sigma_tau, Sigma_int_max):
        self.mu_o, self.mu_tau = mu_o, mu_tau
        self.Sigma_o, self.Sigma_tau = Sigma_o, Sigma_tau
        self.Sigma_int_max = Sigma_int_max
        self.has_cross_data = False

    def compose(self, fp_star, tau_hat):
        mu_int = self.interaction_model(fp_star.z, tau_hat) if self.has_cross_data else 0.0
        sigma_int = self.Sigma_int if self.has_cross_data else self.Sigma_int_max
        return GaussianPrior(mu=self.mu_o + self.mu_tau + mu_int,
                             Sigma=self.Sigma_o + self.Sigma_tau + sigma_int)
```

def generalization_terrain_adaptive_loop(M, obj, x, delta_f_req):
    fp = M.oif.encode(obj)
    tau_hat, sigma2, grad, tau_lead = M.ctf.query(x, M.budget.lookahead)

    mu_pred, d_a, bound = M.generalizer.predict(fp)
    prior = M.otjp.compose(fp, tau_hat)

    if d_a > M.R_gen or sigma2 > M.R_tau:            # OOD 门控

    K_adapt = M.tai.adapt(tau_hat, grad, tau_lead)
    K_safe = M.eeis.compile_with_prior(prior, K_adapt, delta_f_req)

    cert = build_cert_gen(d_a, sigma2, K_safe, prior, K_adapt)
    if not cert.valid:
        K_safe = M.eeis.compile_conservative(delta_f_req)

    M, fused, D_plus, EV_exec = closed_loop_exec_probe(

    M.ctf.update(x, EV_exec.telemetry)
    M.oif.update(obj, EV_exec)
    M.otjp.update(fp, tau_hat, EV_exec)
    M.memory.writeback(fp.z, tau_hat, K_safe, EV_exec)
    return M, K_safe, cert, EV_exec, D_plus

### IP-167 Cert_gen（泛化证书）

```python
def build_cert_gen(d_a, sigma2, K_safe, prior, K_adapt,
                   R_gen, R_tau, Delta_max, eps_pass):
    K_shift = mahalanobis(K_safe, prior.mu, np.linalg.inv(prior.Sigma + 1e-6*np.eye(len(prior.mu))))
    margin = float(np.linalg.eigvalsh(K_adapt.Kd - 0.5*K_adapt.Hdot).min())
    valid = (d_a <= R_gen and sigma2 <= R_tau
             and K_shift <= Delta_max and margin >= eps_pass)
    return CertGen(d_a=d_a, sigma_tau2=sigma2, K_shift=K_shift,
                   passivity_margin=margin, valid=valid)
```

### IP-168 PCE+++++（泛化-地形预算）

```python
class GeneralizationTerrainBudget:
    def __init__(self, gen_ops=80, gp_updates=100, lookahead=2, cog_budget=None):
        self.B_gen_ops, self.B_gp_updates = gen_ops, gp_updates
        self.lookahead = lookahead
        self.cog = cog_budget or CognitiveBudget()
        self.ops_gen = self.ops_gp = 0

    def mode(self):
        if self.ops_gen >= self.B_gen_ops:
            return 'nearest_neighbor_prior'
        if self.ops_gp >= self.B_gp_updates:
            return 'no_lookahead'
        return 'normal'

    def charge(self, action):
        if action.type == 'property_probe':
            self.ops_gen += 1
        elif action.type == 'gp_update':
            self.ops_gp += 1
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| OIF | O(d_attr + d_latent) / 编码 | O(d_attr + d_latent) | 属性估计误差 ≤ δ_a；Lipschitz 界成立 |
| OG-Transfer | O(k·d_attr) / 查询 | O(|O_s|) | 泛化误差 ≤ L_g·d_a + ε_meta |
| CTF | O(n³) 拟合 / O(n²) 查询 | O(n + n_hist) | GP 后验方差校准；覆盖率 ≈ 1−α |
| TAI | O(d²) 投影 | O(d²) | 无源裕度 ≥ ε_pass；闭环 UUB |
| OTJP | O(d²) 组合 | O(d²) | 因子泛化误差由 Σ_int^max 兜底 |
| GTAL | O(闭环) | 复用 + 记忆 | 泛化成功率 ≥ 75%；ΔECE ≥ 15% |

**正确性定理（GA-TA）** 假设 A22–A70 成立；新增 **(A66)** OIF 属性-阻抗映射 g 对属性 a 满足 Lipschitz 常数 L_g；**(A67)** GP 超参校准，σ_τ² 为 calibrated epistemic variance；**(A68)** TAI 投影保证 D = K_d − ½Ḣ ⪰ ε_pass I；**(A69)** OOD 门控在 d_a > R_gen 或 σ_τ² > R_τ 时必回退 π_general；**(A70)** B_gen/B_terrain 单调消耗，任一耗尽即触发对应安全策略。则：

1. **物体泛化界**：对任意未见对象 o*，‖K(o*) − K̂(o*)‖ ≤ L_g·d_a(o*,O_s) + ε_meta；当 d_a ≤ R_gen 时误差 ≤ δ_K。泛化能力被属性距离显式限界，而非依赖闭集完整性。
2. **地形适应有界性**：若采样覆盖连通，则 σ_τ²(x) 随观测收缩，τ̂(x) → τ(x)；在 A68 下地形自适应闭环一致最终有界。

### IP-161 OIF（物体阻抗指纹）

```python
class ObjectImpedanceFingerprint:
    def __init__(self, attr_dim=5, latent_dim=8):
        self.encoder = ObjectEncoder(latent_dim)
        self.g_mu = PropertyToImpedanceMean()
        self.g_sigma = PropertyToImpedanceCov()
        self.Lambda = np.eye(attr_dim)

    def extract_properties(self, obj):
        return np.array([obj.mass, obj.friction, obj.compliance,
                         obj.geometry_centroid, obj.texture_roughness])

    def encode(self, obj):
        a = self.extract_properties(obj)
        z = self.encoder(obj.rgbd, obj.tactile, a)
        return ObjectFingerprint(a=a, z=z, mu=self.g_mu(a, z), sigma=self.g_sigma(a, z))

    def property_distance(self, f1, f2):
        d = f1.a - f2.a
        return float(np.sqrt(d @ self.Lambda @ d))
```

### IP-162 OG-Transfer（属性空间泛化 + 显式误差界）

```python
class PropertySpaceGeneralizer:
    def __init__(self, seen_fps, seen_K, L_g=0.8, eps_meta=0.05, k=5):
        self.seen, self.K = seen_fps, seen_K
        self.L_g, self.eps_meta, self.k = L_g, eps_meta, k
        self.meta_corrector = ResidualMetaLearner()

    def predict(self, fp_star):
        dists = np.array([fp_star.property_distance(o) for o in self.seen])
        idx = np.argsort(dists)[:self.k]
        w = np.array([np.exp(-dists[i] / max(np.median(dists), 1e-6)) for i in idx])
        mu = np.tensordot(w / w.sum(), self.K[idx], axes=(0, 0)) + self.meta_corrector(fp_star)
        d_min = float(dists.min())
        return mu, d_min, self.L_g * d_min + self.eps_meta
```

### IP-163 CTF（连续地形场）

```python
class TerrainFieldEstimator:
    def __init__(self, lengthscale=0.2, noise=0.05):
        self.X, self.Y = [], []
        self.gp = GaussianProcess(kernel=RBF(lengthscale), noise=noise)

    def residual_observation(self, telemetry):
        slip = (telemetry.v_cmd - telemetry.v_actual) / max(abs(telemetry.v_cmd), 1e-6)
        dF = np.linalg.norm(np.gradient(telemetry.force))
        e_pose = np.linalg.norm(telemetry.attitude_error)
        return np.array([slip, dF, e_pose, telemetry.contact_settle])

    def update(self, x, telemetry):
        self.X.append(np.asarray(x))
        self.Y.append(self.residual_observation(telemetry))
        self.gp.fit(np.asarray(self.X), np.asarray(self.Y))

    def query(self, x, lookahead=0.1):
        tau_hat = self.gp.predict(x)
        sigma2 = float(self.gp.predict_var(x))
        grad = self.gp.gradient(x)
        n = grad / max(np.linalg.norm(grad), 1e-6)
        tau_lead = self.gp.predict(np.asarray(x) + lookahead * n)
        return tau_hat, sigma2, grad, tau_lead
```

### IP-164 TAI（地形自适应阻抗 + 无源投影）

```python
class TerrainAdaptiveImpedance:
    def __init__(self, K_base, alpha=0.3, eps_pass=0.05):
        self.K_base, self.alpha, self.eps_pass = K_base, alpha, eps_pass

    def adapt(self, tau_hat, grad, tau_lead):
        dK = self.alpha * (tau_lead - tau_hat)
        return self.project_passive(self.K_base + self.J_tau(tau_hat) @ dK)

    def project_passive(self, K):
        lam = float(np.linalg.eigvalsh(K.Kd - 0.5 * K.Hdot).min())
        if lam < self.eps_pass:
            K.Kd = K.Kd + (self.eps_pass - lam) * np.eye(len(K.Kd))
        return K
```

### IP-167 Cert_gen（泛化证书）

def build_cert_gen(d_a, sigma2, K_safe, prior, K_adapt,
                   R_gen, R_tau, Delta_max, eps_pass):
    K_shift = mahalanobis(K_safe, prior.mu,
                          np.linalg.inv(prior.Sigma + 1e-6*np.eye(len(prior.mu))))
    margin = float(np.linalg.eigvalsh(K_adapt.Kd - 0.5*K_adapt.Hdot).min())
    valid = (d_a <= R_gen and sigma2 <= R_tau
             and K_shift <= Delta_max and margin >= eps_pass)
