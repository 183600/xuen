# 第 1 轮（新灵感循环 R1；本轮灵感：「多视角视觉」×「开放词汇」）
> **继承基线**：第 8 轮 MetricVoiceGauge-DA-SPR-Cal（定义 493–531；引理 77–81；实验 E531–E550）。
> 本轮纪律：**语义提案 + 几何签证 + 分层授权**。多视角视觉把「感知主张」升级为「可验证的 3D 证书」；开放词汇把「指令词表」升级为「语言提案空间」。二者合流于一条原则：**开放词汇只负责提出候选，多视角几何负责签发证书，影响层级决定是否授权执行**。所有新模块均为可选增强，任一失效 ⇒ 退回 v8。

## 0. 直觉与动机

**灵感 1（多视角视觉 → 几何签证）**
直觉：v8 的指标梯把观测 s_t 当作既定事实，但「画面里有一个杯子」只是一条单视角主张，不是几何事实。多视角提供独立的第二意见：同一个 3D 点若能在 ≥2 个视角中被一致观测，就应满足极线约束、低重投影残差、足够视差与掩码一致性；否则它可能只是纹理幻觉、遮挡误判或检测器伪阳性。于是可以定义**多视角接地证书（MVGC）**：不是「检测到了什么」，而是「这个 3D 主张在几何上可被多少视角、以多小的残差共同见证」。

**灵感 2（开放词汇 → 语义提案而非语义权威）**
直觉：真实用户不会只使用训练集里的封闭词表；「把那个带蓝色条纹的马克杯递给我」要求开放词汇。开放词汇检测器（如 Grounding DINO / OWLv2）能以文本为查询、零样本地提出候选，但它有三个致命弱点：① 幻觉标签；② 无校准置信度；③ 分布外词会静默映射到最近邻。若直接把开放词汇标签写进 M₀/M₁，等于把不可信的自然语言当成硬约束。正确姿态是**不对称信任**：开放词汇只生成提案与标签集，几何与校准负责降低不确定性，影响层级负责决定权限。

**合流（提案-签证-授权）**
直觉：一个安全的闭环应是：语言/语音 → 开放词汇提案 → 跨视角关联 → 三角化与证书 → 共形标签集 → 影响分层授权 → 指标梯/动作。关键不是让开放词汇「更准」，而是让系统在**不准时也可证明地不行动**。由此得到本轮核心概念：**认证式弃权（certified abstention）**——当几何证书不通过或标签集不唯一时，系统不是猜一个最近邻标签，而是明确弃权、请求用户确认或退回封闭词表。

## 1. 研究问题（R1 升级版）

- **Q1（几何证书）**：如何定义多视角接地证书，使错误 3D 主张被拒绝的概率随视角数/视差单调下降，且证书阈值与现有 M₀/M₁ 的物理尺度对齐？
- **Q2（校准开放词汇）**：如何在开放词表上给出具有有限样本覆盖保证的标签集，并检测「未见词」而不静默映射到最近邻？
- **Q3（安全授权）**：如何把已认证的语义提案映射到指标层，使开放词汇的不确定性只能收紧、不能放松安全约束，且不可逆动作必须经过更强授权？
- **Q4（实时性）**：开放词汇模型计算量大，如何在不破坏 v8 的 50Hz WCET 前提下，把感知证书以快照方式供主环读取？

## 2. 设计原则（P10–P15）

**P10 开放词汇只提案（Open-Vocab as Proposal, not Authority）**
开放词汇输出只写入「候选标签集 L」与「候选 3D 假设 h」，不得直接写入任何 M₀/M₁ 判据；所有语义谓词必须经过几何证书与授权器。

**P11 多视角几何签证（Multi-View Geometric Visa, MVGV）**
一个 3D 主张只有满足：可见视角数 n_vis ≥ 2、重投影残差 ε_rep ≤ τ_rep、视差 ρ_par ≥ τ_par、跨视角掩码一致性 κ_IoU ≥ τ_iou、三角化协方差 trace(Σ_X) ≤ τ_cov，才签发证书。

**P12 语义-几何双证书（Dual Certificate）**
语义侧证书是共形标签集 C_α(q,o)（覆盖率 ≥ 1−α），几何侧证书是 MVGC；二者同时通过才允许进入 M₂/M₃。单一证书只能支持信息性查询（Tier-0/1）。

**P13 影响分层授权（Impact-Tiered Authorization, ITA）**
按动作不可逆性与人机距离分四级：Tier-0 信息、Tier-1 可逆轻动作、Tier-2 可逆操作、Tier-3 不可逆/高风险。Tier-2 要求双证书；Tier-3 额外要求标签属于封闭词表或人类显式确认。

**P14 认证式弃权（Certified Abstention）**
当 |C_α| ≠ 1、证书过期、或几何证书不通过时，系统输出「弃权」而非最近邻猜测；弃权率作为一等指标进入实验与预注册。

**P15 异步感知、快照读取（Async Perception, Snapshot Read）**
开放词汇提案与几何证书在独立感知线程以 10–20Hz 运行；主环 50Hz 只读取带时间戳的不可变证书快照。快照过期 ⇒ 视为无效（fail-closed），不阻塞主环。

## 3. 与基线的接口（如何退化）

- 开放词汇/共形模块失效 ⇒ 仅允许封闭词表标签；未见词一律弃权，已知词等价于 v8 的 VoiceCommandTyping；
- 多视角几何/证书失效 ⇒ 禁止 Tier-2/3 操作，仅保留 Tier-0/1 信息性使用；等价于 v8 的感知能力但语义不外扩；
- 影响授权器失效 ⇒ fail-closed：所有开放词汇触发的动作需人类确认；
- 异步流水线失效（证书过期）⇒ 主环按「无证书」处理，安全层只收紧；
- 全部失效 ⇒ 完整退回 MetricVoiceGauge-DA-SPR-Cal v8，再按 v8 四级链继续退化。

## 4. 预期贡献

1. **提案-签证-授权**三段式架构：为开放词汇具身智能体提供「不准时可证明地不行动」的安全范式；
2. **多视角接地证书**：把跨视角重投影、视差、覆盖与协方差统一为可比较的 3D 主张证书，并给出伪阳性抑制界；
3. **共形开放词汇**：有限样本覆盖的标签集 + 未见词检测 + 认证式弃权，替代不可校准的 softmax 置信度；
4. **影响分层授权与安全单调耦合**：开放词汇不确定性只能收紧安全层，不可逆动作需更强证据；
5. **实时隔离**：异步证书流水线把开放词汇的算力开销挡在 50Hz 主环之外。

## 5. 本轮最大风险

**一句话**：多视角几何只能证明「那里确实有一个 3D 物体」，不能证明「它就是你语义上想要的那个东西」——几何一致但语义错误的接地（例如把刀具认成勺子）仍可能通过双证书并授权 Tier-2 操作；若共形校准在分布外失效且影响分层对「可逆」估计过于乐观，系统会以很高置信度执行语义错误但几何正确的动作。

## 1. 符号体系增量（定义 541–552）

**定义 541（对象原型记忆 ObjectPrototypeMemory）** 维护有限容量对象原型集合：
```
D_mem = { (z_i, y_i, c_i, n_i, τ_i) }_{i=1..n},  n ≤ N_max = 512
y_i = (成功次数) / n_i,  n_i ≥ n_min = 5 才具备校准资格
```
写入策略：新观测先按距离阈值 0.15 归并到最近原型，否则新增；淘汰策略为“最近最少使用 + 覆盖价值最低”（优先淘汰 n_i < n_min 或距离簇中心最近的冗余原型）。嵌入 φ 冻结，记忆只增删样本、不更新权重。

**定义 542（原型新颖度 PrototypeNovelty）**
```
ρ(o) = (1/k) Σ_{j=1}^{k} d_(j)(z_o, D_mem),  k = 3
```
其中 d_(j) 为到原型集合的第 j 小欧氏距离；空记忆时 ρ=2（最大距离上界）。

**定义 543（跨物体泛化证书 COGC）** 加权 conformal 性能下界：
```
ŷ(z) = k(z,Z)ᵀ (K + λI)^{-1} y,      K_ij = exp(−γ‖z_i−z_j‖²)
s_i  = |y_i − ŷ_{−i}(z_i)|
q_α  = inf{ q : (Σ_{i:s_i≤q} w_i + w_∞) / (Σ_i w_i + w_∞) ≥ 1−α },  w_∞ = max_i w_i
C_α(z) = [ max(0, ŷ(z) − q_α), min(1, ŷ(z) + q_α) ]
```
Tibshirani 修正项 w_∞ 保证测试点自身权重不导致分位数退化。

**定义 544（泛化风险分量 GeneralizationRisk）**
```
risk_GEN(o) = max( clip(1 − L_α(z_o), 0, 1),  λ_ρ · ρ(o)/2 ),  λ_ρ = 0.5
```
第一项是“证书下界离目标成功率还差多少”，第二项是“新颖度硬下限”，防止极端 OOD 物体因局部残差偶然偏小而拿到过窄区间。

**定义 545（对象条件阈值先验 OCTP）**
```
τ_i^{(0)}(o) = clip( τ_i^base + δ_max · tanh(h_ψ(z_o)_i), ε_min,i, ε_max,i ),  δ_max = 0.15
```
h_ψ 在元任务 T_c = {物体类别 c 的 support/query 划分} 上做 MAML：内环用 OTL 在 support 上走 3 步，外环最小化 query 上的收敛步数与 M₀ 违背数之和。

**定义 546（安全门控 TTA SG-TTA）** 适配器 Δ 的接受判据：
```
G(Δ) = accept  ⟺  Ĉov_{P_probe}(φ⊕Δ) ≥ 1 − α − ε_cov
                  ∧  M₀.decide(s_t; φ⊕Δ) = M₀.decide(s_t; φ)
                  ∧  ρ(φ⊕Δ) ≤ ρ(φ) + ε_drift
```
更新频率 ≤ 1Hz，异步执行；拒绝则回滚到 checkpoint。

**定义 547（对象可抓性重加权 OAR）** 把对象属性注入奖励权重：
```
w'_i(s,o) = softmax( α·risk_i(s,o) + β·emo(s)·Ṽ_i + γ·g_i(z_o) )_{i=0..5}
g(z_o) = MLP_g(z_o) − mean(MLP_g(z_o))          # 零均值，避免全局权重漂移
```
g 在成对偏好数据上训练（脆弱→安全，重物→效率+慢速），γ=0.3。

**定义 548（七层指标闭合 MetricLadder-v9）** M 增加 M_gen 层，监控 `risk_GEN < τ_gen`，并具备退化映射 δ_gen：任一 M_gen 违背直接触发 M₀ 硬约束检查。

**定义 549（六维风险向量与对象条件奖励）** risk(s,o) ∈ ℝ⁶，w'(s,o) 按定义 547 计算；v8 的 5 维是其子向量（risk_GEN≡0 时严格等价）。

**定义 550（系统标识）**
```
Φ_COG = {τ^(0) object-conditional + τ adaptative+domain,
         risk 6-dim + GEN, φ frozen + gated-TTA, calib online}
Φ_v8  = {τ adaptative+domain, risk 5-dim + SLAM, φ fixed, calib online}
```

**定义 551（泛化退化映射 δ_gen）** δ_gen 定义为：若 risk_GEN ≥ τ_gen，则跳过 M₁–M_SLAM 的软通过路径，直接进入 M₀ 硬约束检查，并把 τ_gen 与 τ_safe 置于同一“风险上界”物理尺度。

**定义 552（证书有效性监控 CVM）** 滑窗经验覆盖率：
```
Ĉov_t = (1/W) Σ_{j=t−W+1}^{t} 1[ y_j ∈ C_α(z_j) ],  W = 30
若 Ĉov_t < 1−α−ε_cov 连续 K=3 个窗口 ⇒ frozen := True, risk_GEN := 1
```
同时以 PIT 直方图 KS 检验做第二探测器；`frozen=True` 时冻结 OPE 写入与 SG-TTA，并进入保守抓取模式。

## 2. 形式化定义（要点）

**定义 541** 对象原型记忆：冻结嵌入 + 有限容量 + 留一校准资格；嵌入不做在线更新，避免“表征漂移污染历史证书”。

**定义 542** 新颖度取 k=3 均值而非单最近邻，降低单个离群原型的诱导偏差。

**定义 543** COGC 采用加权 conformal 而非普通 conformal，权重来自 M_dom，显式处理 v8 已建模的环境域偏移。

**定义 544** risk_GEN 是证书下界缺口与新颖度下界的 max；前者负责“已知范围内的悲观估计”，后者负责“已知范围外的兜底”。

**定义 545** OCTP 仅输出 τ 初值，不参与任何硬判据；元训练目标含 M₀ 违背惩罚，保证先验不牺牲安全。

**定义 546** SG-TTA 的双门控中，“硬决策不变”是不可协商项：即使覆盖率提升，只要改变当前 M₀ 判定就拒绝。

**定义 547** OAR 与 v8 定义 524 完全兼容：g≡0 时退化为 v8 的情感重加权。

**定义 548–551** 七层闭合与 δ_gen 保证“泛化层没有绕过 M₀ 的旁路”，与 v8 引理 81 的“无空洞”论证同构。

**定义 552** CVM 是唯一有权把 risk_GEN 强制置 1 的模块；它是 fail-safe，不依赖任何学习组件。

## 3. 关键算法骨架

```python
# IP-353 ObjectPrototypeEncoder：对象原型记忆（冻结基础模型）
class ObjectPrototypeEncoder:
    def __init__(self, backbone, dim=384, n_min=5, N_max=512, device='cuda'):
        self.phi = backbone                    # 冻结 DINOv2 ViT-S/14
        self.phi.eval()
        for p in self.phi.parameters():
            p.requires_grad = False
        self.dim, self.n_min, self.N_max = dim, n_min, N_max
        self.device = device
        self.Z = np.zeros((0, dim), dtype=np.float32)
        self.y = np.zeros((0,), dtype=np.float32)
        self.n = np.zeros((0,), dtype=np.int32)
        self.cat, self.last_used = [], np.zeros((0,), dtype=np.int64)
        self.t = 0

    @torch.no_grad()
    def embed(self, object_crop):
        f = self.phi(object_crop.to(self.device)).flatten(1)
        z = torch.nn.functional.normalize(f, dim=-1)
        return z.cpu().numpy().astype(np.float32)

    def novelty(self, z, k=3):
        if len(self.Z) == 0:
            return 2.0
        d = np.linalg.norm(self.Z - z[None, :], axis=1)
        kk = min(k, len(d))
        return float(np.mean(np.partition(d, kk - 1)[:kk]))

    def add_trial(self, z, success, category, merge_eps=0.15):
        if len(self.Z):
            d = np.linalg.norm(self.Z - z[None, :], axis=1)
            j = int(np.argmin(d))
            if d[j] < merge_eps:
                self.y[j] = (self.y[j] * self.n[j] + success) / (self.n[j] + 1)
                self.n[j] += 1
                self.last_used[j] = self.t; self.t += 1
                return j
        self.Z = np.vstack([self.Z, z[None, :]])
        self.y = np.append(self.y, float(success))
        self.n = np.append(self.n, 1)
        self.cat.append(category)
        self.last_used = np.append(self.last_used, self.t); self.t += 1
        self._evict()
        return len(self.Z) - 1

    def _evict(self):
        while len(self.Z) > self.N_max:
            eligible = np.where(self.n >= self.n_min)[0]
            pool = eligible if len(eligible) else np.arange(len(self.Z))
            j = pool[np.argmin(self.last_used[pool])]
            keep = np.ones(len(self.Z), dtype=bool); keep[j] = False
            self.Z, self.y, self.n = self.Z[keep], self.y[keep], self.n[keep]
            self.last_used = self.last_used[keep]
            self.cat = [c for i, c in enumerate(self.cat) if keep[i]]

    def snapshot(self):
        return self.Z, self.y, self.n


# IP-354 CrossObjectGeneralizationCertificate：加权 conformal 证书
class CrossObjectGeneralizationCertificate:
    def __init__(self, alpha=0.1, lam=0.01, gamma=1.0, lambda_rho=0.5):
        self.alpha, self.lam, self.gamma = alpha, lam, gamma
        self.lambda_rho = lambda_rho

    def _K(self, A, B):
        d2 = ((A[:, None, :] - B[None, :, :]) ** 2).sum(-1)
        return np.exp(-self.gamma * d2)

    def fit(self, Z, y, n, weights=None):
        self.Z, self.y, self.n = Z, y, n
        self.w = np.ones(len(Z)) if weights is None else np.asarray(weights)
        K = self._K(Z, Z) + self.lam * np.eye(len(Z))
        self.K_inv = np.linalg.inv(K)
        H = K @ self.K_inv
        loo = (H @ y - np.diag(H) * y) / np.clip(1.0 - np.diag(H), 1e-6, None)
        self.s = np.abs(y - loo)

    def interval(self, z, rho):
        k = self._K(z[None, :], self.Z)[0]
        mu = float(k @ self.K_inv @ self.y)
        order = np.argsort(self.s / self.w)
        s_sorted = (self.s / self.w)[order]
        w_sorted = self.w[order]
        w_inf = float(np.max(self.w))
        cw = np.cumsum(w_sorted) / (w_sorted.sum() + w_inf)
        idx = min(int(np.searchsorted(cw, 1.0 - self.alpha)), len(s_sorted) - 1)
        q = float(s_sorted[idx])
        L = max(0.0, mu - q); U = min(1.0, mu + q)
        risk_conf = float(np.clip(1.0 - L, 0.0, 1.0))
        risk_gen = max(risk_conf, self.lambda_rho * rho / 2.0)
        return L, U, float(np.clip(risk_gen, 0.0, 1.0)), q


# IP-355 ObjectConditionalThresholdPrior：元学习阈值先验
class ObjectConditionalThresholdPrior:
    def __init__(self, dim=384, hidden=128, n_layers=7, delta_max=0.15):
        self.delta_max = delta_max
        self.net = torch.nn.Sequential(
            torch.nn.Linear(dim, hidden), torch.nn.GELU(),
            torch.nn.Linear(hidden, n_layers), torch.nn.Tanh())

    def prior(self, z, base, eps_min, eps_max):
        with torch.no_grad():
            h = self.net(torch.as_tensor(z, dtype=torch.float32)).numpy()
        return np.clip(base + self.delta_max * h, eps_min, eps_max)


# IP-356 SafetyGatedTestTimeAdaptation：双门控 TTA
class SafetyGatedTestTimeAdaptation:
    def __init__(self, model, cert, probe, eps_cov=0.03, eps_drift=0.05,
                 max_rate_hz=1.0):
        self.model, self.cert, self.probe = model, cert, probe
        self.eps_cov, self.eps_drift = eps_cov, eps_drift
        self.period = 1.0 / max_rate_hz
        self.checkpoint = copy.deepcopy(model.state_dict())
        self.last_update = -1e9
        self.accepted = self.rejected = 0

    def _coverage(self):
        hits = [int(self.cert.interval(z, rho)[0] <= y <= self.cert.interval(z, rho)[1])
                for z, y, rho in self.probe]
        return float(np.mean(hits))

    def gate(self, candidate_state, state_t, now):
        if now - self.last_update < self.period:
            return False
        old_state = copy.deepcopy(self.model.state_dict())
        self.model.load_state_dict(candidate_state, strict=False)
        cov = self._coverage()
        hard_same = self.model.m0_decision(state_t) == \
                    self._m0_with(old_state, state_t)
        if cov >= 1.0 - self.cert.alpha - self.eps_cov and hard_same:
            self.checkpoint = copy.deepcopy(self.model.state_dict())
            self.last_update, self.accepted = now, self.accepted + 1
            return True
        self.model.load_state_dict(old_state)
        self.rejected += 1
        return False

    def _m0_with(self, state_dict, state_t):
        saved = copy.deepcopy(self.model.state_dict())
        self.model.load_state_dict(state_dict)
        d = self.model.m0_decision(state_t)
        self.model.load_state_dict(saved)
        return d

    def rollback(self):
        self.model.load_state_dict(self.checkpoint)


# IP-357 ConformalValidityMonitor：证书有效性监控（fail-safe）
class ConformalValidityMonitor:
    def __init__(self, alpha=0.1, W=30, K=3, eps_cov=0.03):
        self.alpha, self.W, self.K, self.eps_cov = alpha, W, K, eps_cov
        self.hits = collections.deque(maxlen=W)
        self.bad_windows, self.frozen = 0, False

    def update(self, covered: bool):
        self.hits.append(1 if covered else 0)
        if len(self.hits) == self.W:
            cov = sum(self.hits) / self.W
            self.bad_windows = self.bad_windows + 1 if cov < 1 - self.alpha - self.eps_cov else 0
            if self.bad_windows >= self.K:
                self.frozen = True
        return self.frozen


# IP-358/359/361 主闭环片段：MetricVoiceGauge-COG
def metricvoicegauge_cog(M, s, obs, object_crop, category,
                         audio_stream=None, ell=None,
                         ope=None, cogc=None, octp=None, sg_tta=None,
                         cvm=None, oar=None, online_learner=None,
                         domain_adapter=None, slam_risk=None, calib_fi=None):
    # --- 0. 感知侧（摊销 ≤2ms；嵌入仅新物体首次计算，异步缓存）---
    if ope is not None:
        z_o = ope.embed(object_crop)
        rho = ope.novelty(z_o)
    else:
        z_o, rho = geometry_features(object_crop), 0.0

    # --- 1. 跨物体泛化证书 ---
    if cogc is not None and ope is not None:
        L, U, risk_gen, q = cogc.interval(z_o, rho)
    else:
        L, U, risk_gen, q = 0.0, 1.0, 0.0, 0.0

    # --- 2. 证书有效性监控（唯一 fail-safe 权限）---
    if cvm is not None:
        cvm.update(covered=True)          # 实际实现用上一物体真实结果回填
        if cvm.frozen:
            risk_gen = 1.0               # 宁可不泛化，不可伪造泛化

    # --- 3. 对象条件阈值先验 → OTL ---
    base = M.metric_ladder.thresholds
    tau0 = octp.prior(z_o, base, M.eps_min, M.eps_max) if octp is not None else base
    if online_learner is not None:
        online_learner.reset_to(tau0)
        if domain_adapter is not None:
            online_learner.update_domain_shift(domain_adapter.compute_domain_shift())
        tau_current = online_learner.update_all(M.metric_ladder.compute_metrics(len(M.inflight) > 0))
    else:
        tau_current = base

    # --- 4. 继承 v8：DA-ML / SPR / Calib-FI / GCT / ER ---
    risk_5d = assemble_risk_5d(M, slam_state, calib_fi)          # v8 路径
    risk_6d = np.array([*risk_5d, risk_gen])                     # 第 6 维
    g = oar.bias(z_o) if oar is not None else np.zeros(6)
    emo = extract_emotion(audio_stream) if audio_stream is not None else 0.0
    w_prime = softmax(alpha * risk_6d + beta * emo * V + gamma * g)

    # --- 5. 软硬约束：δ_gen 无旁路 ---
    soft_ok = (risk_6d[0] < tau_current[0] and risk_6d[1] < tau_current[1]
               and risk_gen < tau_current[6] and M.spatial_cert(s))
    C = M.decide(s, tau_current, w_prime) if soft_ok else M.hard_only(s, tau_current)

    # --- 6. 异步回写：结果 → 原型记忆 / 证书重拟合 / CVM ---
    def on_outcome(success):
        if ope is not None:
            ope.add_trial(z_o, success, category)
            Z, y, nn = ope.snapshot()
            cogc.fit(Z, y, nn, weights=M.mdm.likelihood_ratio())
        if cvm is not None:
            cvm.update(covered=(L <= float(success) <= U))

    M.register_outcome_hook(on_outcome)
    return C, risk_6d, w_prime, (L, U), tau_current
```

## 4. 推导

**引理 82（加权 conformal 覆盖）** 设 (A1) 校准物体与测试物体来自同一超总体；(A2) 密度比 r(z)=p_test(z)/p_ref(z) 已知且有界，w_i=r(z_i)；(A3) 加权可交换性成立。则
```
P( y* ∈ C_α(z*) ) ≥ 1 − α − δ_w,   δ_w ≤ ½·E| r̂(z)/r(z) − 1 |
```
证明要点：加权 conformal（Tibshirani et al.）在精确权重下给出 1−α；权重估计误差经三角不等式转化为加权经验 CDF 的一致误差 δ_w。**推论**：M_dom 估计的域漂移越大，r̂ 越不准，δ_w 越大，覆盖越不可信——这正是 CVM 存在的理由。

**引理 83（新颖度—风险单调性）** 设核岭预测 ŷ 关于 z 满足 L-Lipschitz，(A4) 残差离散度随到最近原型的距离非减。则 q_α 关于 ρ 非减，L_α=ŷ−q_α 关于 ρ 非增，故 risk_GEN^conf=1−L_α 关于 ρ 非减；再与 λ_ρ·ρ/2 取 max 后仍非减。结论：越新奇的物体 → risk_GEN 越高 → τ 越紧、速度越低、越倾向保守抓取。A4 为经验假设，由 E553 检验；若违反，CVM 的覆盖率监控会先报警。

**引理 84（元先验收缩加速）** 设 OTL 更新为仿射压缩 `|τ_{t+1}−τ*| ≤ γ|τ_t−τ*| + b`，0<γ<1。则
```
|τ_t−τ*| ≤ γ^t e₀ + b/(1−γ),   e₀ = |τ₀−τ*|
t*(ε) = max(0, ⌈ ln((ε − b/(1−γ))/e₀) / ln γ ⌉)
```
若 OCTP 使 e₀' < e₀，则 t*(ε) 严格下降。当元训练把类别平均 e₀' 压到 `(ε−b/(1−γ))·γ³` 以下时，E[t*] ≤ 3，直接回答 Q2。注意：先验只改 e₀，不改 γ 与 b，故不改变 OTL 的稳定性条件。

**引理 85（SG-TTA 无伤害）** 定义认证风险 R_t = 1 − Ĉov_{P_probe}(φ_t)。门控只接受 R_{t+1} ≤ R_t 且 M₀ 判定不变的更新；拒绝则回滚 checkpoint。故沿接受序列 R_t 单调非增，被拒更新使 R_t 不变，归纳得 max_t R_t ≤ R_0。有限探针 m=64 下，覆盖估计误差由 Hoeffding 界控制：`P(|Ĉov−Cov| ≥ ε_cov) ≤ 2exp(−2mε_cov²)`。**边界**：这保证的是探针风险不升，不是总体风险不升；总体保证需探针与部署分布可交换（引理 82）。因此 SG-TTA 必须与 CVM 同时开启。

**引理 86（证书失效可检测）** 若真实覆盖降到 1−α−2ε_cov 以下，则 W=30 窗口经验覆盖以 Hoeffding 集中到真实值；在混合系数有界的弱相依假设下，连续 K=3 个坏窗口的检测概率趋于 1，检测延迟 ≤ K·W = 90 个物体。检测触发后 risk_GEN:=1，系统进入保守模式，故“证书失效”不会直接转化为“安全失效”。误报率由 ε_cov 控制（E569 量化）。

**引理 87（五级退化正确性）** 各模块写集正交：OPE 只写 D_mem；COGC 只读 D_mem/M_dom 并写 risk_GEN；OCTP 只写 τ⁽⁰⁾；SG-TTA 只写 φ checkpoint；OAR 只写 g；CVM 只写 frozen 标志。因此任一子集失效都精确映射到声明退化级别，互不级联。又由定义 551，δ_gen 直达 M₀ 且所有学习模块的写集都不含 M₀ 判据，故任意退化下 M₀ 硬安全不变。全失效时 risk_GEN≡0、φ 冻结、τ⁽⁰⁾=默认，系统逐字退回 v8。

## 8. 本轮最大风险

**一句话**：conformal 证书的全部保证都建立在“原型与测试物体可交换”之上，而跨物体泛化场景本质上是非交换的；一旦 CVM 检测延迟或元先验把 τ_gen 放得过松，系统会拿着一个统计上漂亮、却系统性过窄的下界，把真正危险的新物体认证为可抓取——最大风险不是不会泛化，而是**用错误的泛化证书为鲁莽背书**。
