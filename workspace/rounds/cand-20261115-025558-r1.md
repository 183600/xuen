# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「仿真到现实迁移」×「实时控制」）

> R69 让系统学会「问」，但它的两种自信都来自仿真：一是「我知道哪种不确定该问」（aleatoric / epistemic 的切分在仿真里校准），二是「我总来得及问」（P99 < 2.6ms 是在标称算力、零延迟、无争用下测的）。「仿真到现实迁移」与「实时控制」恰好从两处同时拆台：
> - 真实世界的观测、动力学、接触与延迟把仿真里的模态分布、流似然基线和通道切分整体推移，R69 的「模态权重可信、该问谁可信」不再自动成立；
> - 真实控制器有硬截止与抖动，信息动作（看 / 问 / 触）本身耗时，答案可能在决策之后才到；「先问再走」在毫秒世界里可能变成「问到一半撞上」。
>
> 核心命题：**把 R69 的两个点假设——「分布匹配」与「算力/延迟为零」——替换为两个可认证的包络：迁移包络 PTE（仿真信念在哪些区域仍有条件保证）与计算包络 CE（在硬截止内能算什么、必须放弃什么）；交互只在两包络与通道校准的交集内被授权，且证据价值必须按「到达时刻」贴现；一旦出包络或来不及，就沿退化阶梯单调回落到非学习的、WCET 有界的几何安全控制器。** 命名 **PACE-RAS**（Policy Assurance under Compute-and-transfer Envelopes：计算-迁移双包络下的实时可信闭环）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我在仿真里学会的自信，到了真实的毫秒里还作数吗？如果来不及问，我还安全吗**」。

## 0. 直觉与动机

**灵感 1（仿真到现实迁移 → 迁过去的不是策略，而是「信念的适用域」）**
直觉：常规 sim2real 想把策略搬过去；但对 R69 这种会「问」的系统，真正要搬的是**判断**：哪些不确定是噪声（别问）、哪些是歧义（该问）、问了信谁。这些判断全部由仿真数据和仿真校准塑造。真实世界一旦离开仿真覆盖，模态权重、`U_ale / U_epi` 切分、流似然基线会同时失真，而且**失真的方向不一定保守**：可能把真实歧义误判成噪声（该问不问，硬闯），也可能把噪声误判成歧义（反复追问一个幻影）。所以 R70 不主张「零样本迁移策略」，而主张**给仿真信念配一张适用域许可证（PTE）**：在证区内，R69 的结论有条件有效；出证区，结论作废，而不是打折。没有真实锚点的区域，默认**不授权**——这是本轮的诚实姿态。

**灵感 2（实时控制 → 证据是有到达时刻的，晚到的证据约等于噪声）**
直觉：R69 的 VoI 是一个静态期望信息增益，隐含假设「答案立刻可用」。实时闭环里，信息动作要花时间：注视要停留、探针要接触、问句要等人回答；控制周期有硬截止 `D`。一个在 `D` 之后才到的答案，对当前动作价值为零；强行并入还会把一个「针对旧状态」的答案当成新证据，制造**时序错配**。所以 R70 把 VoI 改成**时间价值 T-VoI**：只有能在决策时刻前完成「采集 + 传输 + 融合」的证据才计价；晚到的证据进入**隔离区**，只能作为下一次决策的先验候选，且必须与当前观测重新对齐后才可解封。

**灵感 3（实时控制 × 仿真到现实 → 延迟本身就是一种域差，而且最容易被仿真抹掉）**
直觉：仿真通常假设零计算延迟、固定控制周期、理想执行器；真实系统有 WCET、抖动、丢帧、执行器延迟和算力争用（热降频、其他进程）。这类**时序域差（temporal domain gap）**不会出现在状态分布里，却会直接改变闭环稳定性：同一个动作晚 20ms 执行，可能从「让行」变成「抢行」。它也不会被只随机化物理参数的域随机化覆盖。因此 R70 把**时序增广**作为一等公民：状态里显式包含各通道年龄与在途动作，安全集用**延迟增广 CBF / 不变集**在 worst-case 延迟下计算；学习策略必须在**任意抢占点**都能吐出一个经认证的动作（anytime），而不是「算完才安全」。

**灵感 4（两个包络的交集 → 交互是受限资源，不是无条件能力）**
直觉：R69 的交互层是一个开关（VoI > 成本就问）。R70 里它变成一种**受许可的资源**：交互只在「迁移包络内 ∧ 计算包络内 ∧ 通道校准可信」的三重交集里被授权；交集随状态、算力、抖动、证据年龄动态收缩。授权区外不是「少问一点」，而是**不允许学习组件主导**，必须沿退化阶梯下降。这样 R69 不是被否定，而是变成 PACE 在「包络无限大、延迟为零、漂移为零」边界上的精确退化。

**灵感 5（漂移 vs 证据 → 实时不确定性的「节律」）**
直觉：sim2real 的本质是「现实以多快的速度让仿真信念过期」，real-time 的本质是「我以多快的速度能在截止前买到证据」。这两者之比，就是系统能不能「跟上」世界。定义 **epistemic drift rate `ρ_drift`**（1/s）与 **certified evidence rate `ρ_evi`**（nats/s），令视界内漂移造成的不确定性增量为 `ΔH_drift(D) = H·(e^{ρ_drift·D}−1)`，并要求 **tempo 条件**：`ΔH_drift(D) ≤ ρ_evi·(D−τ_ctl) + B`。满足，则「边做边问」可行；不满足，任何调度要么超时、要么让 `U_epi` 悬空——此时唯一诚实的动作是降级保守。这把 R69 的「值不值得问」升级为「**来不来得及问**」。

**灵感 6（迁移与实时互相掩护 → 需要新的对抗面）**
直觉：两个包络都可能被骗：用域随机化「覆盖」了真实却覆盖错方向；用时间戳伪造 / 延迟注入让「新鲜证据」其实是重放；用算力争用制造 deadline miss，迫使系统降级到更笨的控制器。最危险的是**两者合谋**：让系统误以为「在包络内、来来得及」，从而在错误的先验上自信行动。所以 PACE 必须把「时序攻击 + 迁移对抗样本 + 陈旧证据重放」纳入一等威胁模型，并让证书同时覆盖两个包络。

**灵感 7（预算有限 → 真实锚点应该花在「最可能来不及」的地方）**
直觉：PTE 的许可证需要真实数据来发，而真实数据昂贵。均匀采集或按地图熵采集都不对；应该按 **tempo 边际收益**分配：优先那些 `ρ_drift` 高、后果大、又恰好处在 PTE 边界上的 regime——也就是最可能把系统从「来得及问」推成「来不及」的地方。这把「仿真到现实迁移」从一次性工程，变成一项可持续的**保真度预算**。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（PACE-RAS 总览）** PACE-RAS = (PTE, CTC, T-VoI, SEQ, ETC, DOT, DR-CBF, DGL, FBA, VQAuditor-RT, RAS-WM‡)。四不变式：
(i) **硬截止不变式**：控制关键路径 WCET ≤ D；交互与精化是可选工作，只能使用 slack；每个抢占点必须产出经认证动作；
(ii) **包络授权不变式**：学习组件只在 PTE ∧ CE ∧ CTC 三重交集内主导，出包络必须沿 DGL 单调降落；
(iii) **证据时序不变式**：只有能在决策时刻前到达并完成时序对齐的证据才可参与当前决策，晚到者进隔离区；
(iv) **严格包含**：零延迟、零抖动、零漂移、无限包络时逐指令退化为 R69；再叠加 VoI ≤ 成本时退化为 R68。

**定义 311（时序增广状态）** `s_t = (x_t, u_{t−L:t−1}, τ_t)`，其中 `u` 为在途动作，`τ_t = (τ_sen, τ_est, τ_map, τ_ans)` 为各通道年龄。转移含延迟：`x_{t+1} = f_d(s_t, u_t)`；年龄随拍更新 `τ_{t+1} = (τ_t + Δt) ⊙ (1 − 更新指示)`。**控制读到的是带年龄的估计，而不是「当前真值」。**

**定义 312（计算包络 CE 与可选工作图）** `CE = (D, WCET(·), J_δ, G_opt)`。`G_opt` 为可选工作 DAG：节点是计算阶段（trunk、flow step、聚类、VoI 枚举、FMA），边是依赖，每节点带 `(wcet, quality-level, output-cert)`。调度器在剩余 slack 内选一个**前缀闭包**执行，保证任意时刻可停在认证检查点。

**定义 313（anytime 流策略 AFP）** 对 R69 流策略，允许在 `N` 步内任意 `n` 步后截断：`ξ^{(n)} = x_0 + Σ_{i<n} Δs·v_θ(x_{s_i}, s_i | z)`。截断残差 `ε_trunc(n) ≤ (1−s_n)·V_max`，质量等级 `ℓ(n)` 单调。**关键**：`ξ^{(n)}` 必须仍过 C-RAS-WM 认证；不过则本检查点输出 L3 安全动作。任何时刻的输出都带 **deadline stamp**（有效期至 `t+D`）。

**定义 314（迁移包络 PTE）** 按 regime `r`（接触 / 自由 / 高速 / 遮挡 / 湿滑 / 重载 …）维护仿真支撑集 `S_r` 与**条件迁移风险上界** `R_r(α)`：在 regime-conditional real-anchor 上，`P(real regret ≤ R_r) ≥ 1−α`。迁移分 `t(x) = 1[x ∈ S_r ∧ R_r ≤ R_max ∧ license 未过期]`。`PTE = {(S_r, R_r, anchor_hash, sim_seed_hash, expiry)}`。**出 PTE ⇒ 仿真导出的模态权重 / 似然 / 通道切分一律「未授权」**（不是打折）。没有 real-anchor 的 regime 默认未授权。

**定义 315（通道迁移校准 CTC）** R69 的分解 `𝒟_sim : (U_ale, U_epi)` 本身是仿真产物。真实锚点上用**可执行干预**（真的凑近看 / 真的问 / 真的触）得到通道真值标签，构造混淆矩阵 `C_sim→real` 与 epistemic share `π = U_epi/(U_ale+U_epi)`，用 conformal 给出 **`π_LCB`** 与 `U_ale` 的上界，并算 channel-ECE。交互授权要求 `π_LCB ≥ τ_π` 且 `channel-ECE ≤ τ_ch`。**这是对 R69「问错比不问更危险」的迁移版正面回应**：不让一个在仿真里学会的切分，在真实里决定问不问。

**定义 316（时间价值 VoI，T-VoI）** 对信息动作 `g`，令 `τ_g` 为采集 + 传输 + 融合的总时延，`D_dec` 为决策截止：
`T-VoI(g) = E[ΔH(M|y_g)·1{τ_g+τ_fuse ≤ D_dec}] − c(g) − λ_t·τ_g`。
只有「赶得上」的那部分信息增益计价；错过截止的增益记为 0（其价值递延到未来决策，不折现进当前）。等价地，用 `τ_g` 的分布做截断期望，而不是用点估计。

**定义 317（过期证据隔离区 SEQ）** 晚于 `D_dec` 到达的答案写入 `SEQ : (payload, t_arrive, t_valid, provenance, hash)`。解封条件：与当前观测的重对齐检验通过（似然比 `> τ_re`）且未被 `ℰ_PACE` 标记；否则丢弃并审计。**禁止把旧答案直接并入当前后验。**

**定义 318（tempo 条件 / 不确定性节律）** 令 `H_t = H(V_t) = H(U_epi(s_t))`，漂移上界为指数增长 `H_{t+1} ≤ e^{ρ_drift·Δt}·H_t`，故视界内漂移增量 `ΔH_drift(D) = H_t·(e^{ρ_drift^UCB·D} − 1)`；证据率 `ρ_evi`（nats/s，取 CTC 认证后的**下界**），保守兜底抵扣 `B`（nats）。tempo 可行 ⇔
`ΔH_drift(D_dec) ≤ ρ_evi^LCB·(D_dec − τ_ctl) + B`。
可行 ⇒ 存在不超时且期望 `U_epi` 不增的交互调度；不可行 ⇒ 不授权交互，走 DGL。注意两边都用**保守界**：漂移取上界、证据取下界，否则「可行」只是自欺。

**定义 319（抢占检查点与认证等级）** 流水线检查点 `c_0..c_m`，每点有 `(输出, wcet, ℓ, cert)`。调度器选满足剩余 slack 的最高 `ℓ` 前缀闭包；`c_0` 必为 L3 安全动作（保底）。认证输出携带有效期与包络版本号，过期即失效。

**定义 320（退化阶梯 DGL）** L0：PACE 全量（PTE ∧ CE ∧ CTC ∧ tempo）→ 交互 + 流；L1：tempo 失败 → R69 禁交互（= R68 保守）；L2：CTC 失败 → R68 + 延迟增广安全集；L3：PTE 失败 / 截止 miss / 抖动越界 → 非学习几何安全控制器（WCET 有界）。单调性：`SafeSet(L_{k+1}) ⊆ SafeSet(L_k)`；下降立即、恢复需重新认证 + dwell time（防抖）。

**定义 321（延迟增广鲁棒不变集 DR-CBF）** 用 worst-case 延迟 `L_max` 与抖动 `J_δ` 构造增广状态 `(x, u_{t−L:t})` 的 CBF `h_d`，约束 `h_d(s_{t+1}) ≥ (1−γ)h_d(s_t)`。执行器实际延迟超界 ⇒ 立即降 L3。

**定义 322（抖动感知风险预算）** `λ_t = λ_floor(U)·(1 + κ·max(0, Ĵ_t − J_δ)/J_δ)`；抖动越界同时触发 DGL 下降。安全侧只增不减。

**定义 323（证书 J_PACE）** `J_PACE = (J_FLUID, PTE_version, pte_coverage, pte_gap_bound, wcet_p99, deadline_miss_rate, jitter_p99, tempo_margin, π_LCB, channel_ECE, seq_count, dgl_level, sim_seed_hash, pace_ver)`。Valid ⇔ `J_FLUID` 有效 ∧ 截止满足 ∧ 包络未越界（或已按 DGL 降级并重签）。

**定义 324（对抗集 ℰ_PACE）** `ℰ_PACE = ℰ_FLUID × ℰ_time × ℰ_transfer × ℰ_stale`，其中 `ℰ_time`：延迟注入 / 时间戳伪造 / 算力争用 / 丢帧；`ℰ_transfer`：利用已知仿真偏差的定向 OOD、域随机化盲区、锚点污染；`ℰ_stale`：旧答案重放、跨 episode 证据偷渡；以及「时序-迁移合谋」（让系统误判包络内且来得及）。

**定义 325（实时参与式审计 VQAuditor-RT）** 审计截止 miss、SEQ 使用、包络越界、DGL 切换与切换理由、T-VoI 估计误差、许可证过期；结论回灌调度器与 FBA 预算分配。

**定义 326（保真度预算分配 FBA）** 真实校准预算按「tempo 边际收益」分配：`argmax_r (P(tempo fail | r)·consequence(r)·Δinfo_per_anchor(r)) / cost(r)`，优先 `ρ_drift` 高、后果大、且靠近 PTE 边界的 regime，而不是均匀覆盖或全图熵。

## 2. 关键算法骨架

```python
# IP-264 PTE：迁移包络（regime-conditional conformal + 许可证过期）
class TransferEnvelope:
    def __init__(self, regimes, alpha):
        self.S, self.R, self.alpha = regimes, {}, alpha
    def certify(self, x, regime):
        if regime not in self.S: return False, INF
        lic = self.S[regime]
        in_support = lic.contains(x)
        ok = in_support and lic.R <= R_MAX and not lic.expired()
        return ok, lic.R                      # 无锚点/过期 => 未授权

# IP-265 CTC：通道迁移校准（π 的下置信界）
def channel_transfer_gate(sim_decomp, real_anchors, alpha):
    C = confusion(sim_decomp.labels(real_anchors), real_anchors.true_channel)
    pi_lcb = conformal_lcb(C, alpha)          # epistemic share 下界
    ece    = channel_ece(C)
    return (pi_lcb >= TAU_PI and ece <= TAU_CH), pi_lcb, ece

# IP-266 AFP：anytime 流采样（任意检查点可停，永不返回未认证动作）
def anytime_sample(policy, z, o_t, deadline, slack):
    x, n, cert = randn(1, D), 0, geo_safety_action(o_t)   # c0 保底
    while n < N_MAX and time_left() > WCET_STEP:
        x = x + (1.0/N_MAX) * policy.v(x, n/N_MAX, z)
        n += 1
        cand = policy.decode(x)
        if c_ras_wm.certify(cand, o_t):
            cert = (cand, quality_level(n), stamp(now, deadline))
        if time_left() <= RESERVE_FOR_FUSE: break
    return cert

# IP-267 T-VoI：只有赶得上的信息才计价
def tvoi(g, modes, w, D_dec):
    tau = latency_model(g) + fuse_latency()          # 用分布，不用点估计
    if tau.p01 > D_dec: return -INF                  # 晚到 = 对当前决策零价值
    dH = entropy(w) - expected_entropy(w, g)
    return dH * P_arrive_before(tau, D_dec) - cost(g) - LAMBDA_T * tau.mean

# IP-268 SEQ：过期证据隔离与重对齐
def admit_evidence(seq, ans, o_now):
    if ans.t_arrive <= DEADLINE and realign_lr(ans, o_now) > TAU_RE:
        return ans.payload                          # 当前决策可用
    seq.push(ans)                                   # 只递延，不污染当前后验
    return None

# IP-269 ETC：tempo 条件（保守界；漂移是视界内累积量）
def tempo_feasible(U_epi, drift_amount, rho_evi_lcb, D_dec, tau_ctl, B):
    # drift_amount = H(U_epi) * (exp(rho_drift_ucb * D_dec) - 1)
    return drift_amount <= rho_evi_lcb * (D_dec - tau_ctl) + B

# IP-270 DOT：deadline 反向调度（mandatory 先锁，optional 用价值密度填 slack）
def schedule(ce, t_rem, nodes):
    plan = [MANDATORY_PATH]                         # trunk + 认证 + DR-CBF
    slack = t_rem - wcet(MANDATORY_PATH)
    for node in knapsack_by_value_density(nodes, slack):
        if wcet(node) <= slack:
            plan.append(node); slack -= wcet(node)
    return plan                                     # 任意前缀闭包都可执行

# IP-271 DR-CBF：延迟增广不变集
def delay_robust_cbf(x, u_hist, lam, L_max, J_delta):
    h = augmented_barrier(x, u_hist, L_max + J_delta)
    return qp_certified_prefix(h, lam)              # 不可行 => 返回 None

# IP-277 主闭环：先保命，再求信息，最后精化（reverse-deadline）
def PACE_RAS_round(M, s_t, D):
    x, u_hist, tau = s_t
    safe = M.geo_safety.solve(x, u_hist, tau)       # c0：L3，WCET 有界
    out  = (safe, L3, stamp(now, D))
    # 1) 迁移包络：仿真信念是否被授权
    ok_pte, gap = M.pte.certify(x, M.regime(x))
    if not ok_pte:
        M.audit.log('pte_out', gap); M.dgl = L3
        return M.dgl, out
    # 2) 通道迁移校准：R69 的切分在真实还成立吗
    ok_ctc, pi_lcb, ece = M.ctc.check()
    # 3) anytime 前向 + 分解（考完即用，不阻塞）
    z    = M.trunk(x, u_hist, tau)
    cand = M.afp.anytime_sample(M.fmp, z, x, now + D, M.sched.slack())
    U_ale, U_epi, modes = M.aud.decompose([cand], z)
    # 4) tempo + T-VoI：来不及问就不问
    if ok_ctc and tempo_feasible(U_epi, M.rho_drift.drift_amount(x, D), M.rho_evi.lcb(), D, M.tau_ctl, M.B):
        g = M.mint.choose(modes, D, scorer=tvoi)    # 只枚举赶得上的 g
        if g is not None:
            ans = M.cia.execute_with_deadline(g, D)
            y   = M.seq.admit(ans, x)               # 晚到则隔离
            if y is not None: U_epi = M.cia.update(modes, y)
    # 5) 风险缩放 + 延迟增广认证
    lam = max(M.efs.risk_scale(), lam_floor(U_ale + unresolved(U_epi)))
    lam = M.jitter.budget(lam, M.jitter.p99)
    k   = M.dr_cbf.certified_prefix(cand, u_hist, x, lam)
    if k is None:
        M.dgl = degrade(M.dgl, reason=JITTER); return M.dgl, out
    # 6) 证书 + 实时审计
    J = M.cert.sign(J_FLUID=..., pte=(ok_pte, gap), ctc=(pi_lcb, ece),
                    wcet=M.wcet.p99, miss=M.deadline_miss,
                    tempo=M.tempo_margin, dgl=M.dgl)
    M.vqa_rt.submit_async(J, M.seq.summary())
    return M.dgl, (cand[:k], lam, stamp(now, D), J)
```

## 3. 推导

**引理 19（anytime 质量-时间单调界）** 设速度场有界 `‖v_θ‖ ≤ V_max`、`L`-Lipschitz。在 `s_n` 截断的 rectified flow 样本与真实目标分布间的 `W_1` 距离 `≤ (1−s_n)·V_max`；每多一步，该上界单调不增。又因每个检查点都过 C-RAS-WM 认证，**截止 miss 只会把输出从「更优」降为「L3 保底」，不会从「安全」变成「不安全」**。系：实时性以「质量」而非「安全性」为代价，这是 anytime 契约的全部价值。

**引理 20（晚到证据的时序偏差与隔离必要性）** 若在 `s_{t−Δ}` 产生的答案被当成 `s_t` 的证据直接融合，则其后验偏差满足 `KL(p_t ‖ p_late) ≥ c·ρ_drift·Δ`（`c` 为模态转移常数）。因此「晚到即用」会在漂移越大、延迟越大时越危险；SEQ 的重对齐检验把可接受延迟限制在 `Δ ≤ τ_re/(c·ρ_drift)`。系：**实时系统里，证据的价值必须带时间戳，否则它就是伪装成信息的噪声。**

**引理 21（CTC 保守门控）** 在可交换 real-anchor 上，用 conformal `π_LCB` 门控交互，则「在通道不可信时仍追问」的概率 `≤ α`；通道迁移导致的漏问（把真歧义判成噪声）由混淆矩阵 `C` 上界给出，其代价只是效率，不是安全。故 CTC 门控是**安全单调**的：它只会减少交互，不会扩大安全集。

**引理 22（延迟增广不变集在抖动下的前向不变性）** 若实际执行延迟 `≤ L_max`、抖动 `≤ J_δ`，且 DR-CBF 使用增广状态与最坏延迟，则 `h_d ≥ 0` 前向不变。若实测抖动越界，立即降 L3，而 L3 按构造满足不变性；故任意时刻安全集不被扩大。

**定理 18（tempo 可行性）** 在 CE 与 tempo 条件下（漂移用 UCB、证据用 LCB），存在一个在线调度，使所有控制关键工作在 `D` 前完成，且被授权的交互在 `D_dec` 前完成采集 + 融合的概率 `≥ 1−α`，同时期望 `U_epi` 不增。若 tempo 条件不成立，则 CE 内不存在这样的调度：任何方案要么超时，要么让 `U_epi` 悬空；此时 DGL 保证安全。证明要点：可选工作 EDF + 检查点闭包 + 对 slack 的价值密度背包；漂移-证据不等式保证「买入的证据 ≥ 漂移吃掉的部分」。

**定理 19（PACE 对 R69 / R68 的严格包含）** 当延迟 = 0、抖动 = 0、`ρ_drift = 0`、PTE 全覆盖且许可证永不过期时，tempo 恒可行、T-VoI 退化为 R69 的静态 VoI、SEQ 恒空、DGL 恒为 L0，**PACE 逐指令等于 R69**；再叠加 `VoI ≤ 成本`，逐指令等于 R68。沿 DGL 向下，安全集单调收缩、恢复需重新认证，故任意状态期望风险 `≤ R69`；只有「包络内且来得及」时才有严格效率增益。系：**新层不引入新的信任黑箱，而是给旧层加了一张可撤销的许可证。**

**定理 20（截止满足与无突变）** 若 `WCET(控制关键路径) ≤ D` 且每个抢占点都产出认证动作，则不存在 deadline miss；DGL 的下降立即、恢复带 dwell，切换只发生在检查点且新旧输出均安全，故控制连续、无抖振（no chattering）。结合引理 22，得「实时 + 安全」的联合保证。

## 6. 本轮最大风险

**一句话**：PACE 的整个授权逻辑押在 `ρ_drift^UCB`——「现实以多快速度让仿真信念过期」——这一个量上；而它恰恰是离开仿真后最难知道、最容易被域随机化和短锚点低估的量，**你用来判断自己来不来得及的钟，本身可能是错的**：一旦它偏快（低估漂移），tempo 条件会误判「来得及」，系统就会在错误的先验上自信地追问、把陈旧证据当成新鲜证据融合，最后在截止前被现实追上。

**次级风险与缓解**：
1. **PTE 过窄导致永久保守**（效率收益清零）→ FBA 按 tempo 边际收益投放锚点 + 许可证分级 + E303/E314 监控；
2. **anytime 粗动作虽安全但动态很差**（抖动/顿挫）→ 质量等级门控 + 每检查点 C-RAS-WM 认证 + E302；
3. **CTC 需要真实干预，成本高且涉及社交** → 只用低成本微干预锚点 + 复用 R69 的交互预算 + E304；
4. **调度在算力争用/热降频下失效** → WCET 预算含争用裕度 + 抖动越界即降 L3 + E313；
5. **时序-迁移合谋攻击** → `ℰ_PACE` 联合对抗训练 + 证书双包络联签 + E312。

```python
# IP-264 PTE：无锚点/过期 => 未授权
def pte_certify(pte, x, regime):
    if regime not in pte.S: return False, INF
    lic = pte.S[regime]
    return (lic.contains(x) and lic.R <= R_MAX and not lic.expired()), lic.R

# IP-265 CTC：通道迁移门控（信不过就不问）
def ctc_gate(sim_decomp, anchors, alpha):
    C = confusion(sim_decomp.labels(anchors), anchors.true_channel)
    pi_lcb, ece = conformal_lcb(C, alpha), channel_ece(C)
    return (pi_lcb >= TAU_PI and ece <= TAU_CH), pi_lcb, ece

# IP-266 AFP：anytime，永不返回未认证动作
def anytime_sample(policy, z, o_t, deadline):
    x, n, cert = randn(1, D), 0, geo_safety_action(o_t)   # c0 保底
    while n < N_MAX and time_left() > WCET_STEP:
        x = x + (1.0/N_MAX) * policy.v(x, n/N_MAX, z); n += 1
        if c_ras_wm.certify(policy.decode(x), o_t):
            cert = (policy.decode(x), quality(n), stamp(now, deadline))
        if time_left() <= RESERVE_FOR_FUSE: break
    return cert

# IP-267 T-VoI：用到达时间分布，不用点估计
def tvoi(g, modes, w, D_dec):
    tau = latency_model(g) + fuse_latency()
    if tau.p01 > D_dec: return -INF
    return (entropy(w) - expected_entropy(w, g)) * P_arrive(tau, D_dec) \
           - cost(g) - LAMBDA_T * tau.mean

# IP-268 SEQ：晚到只递延，不污染当前后验
def admit(seq, ans, o_now):
    if ans.t_arrive <= DEADLINE and realign_lr(ans, o_now) > TAU_RE:
        return ans.payload
    seq.push(ans); return None

# IP-269 ETC：tempo（漂移取 UCB、证据取 LCB）
def tempo_ok(U_epi, drift_amount, rho_evi_lcb, D_dec, tau_ctl, B):
    return drift_amount <= rho_evi_lcb * (D_dec - tau_ctl) + B

# IP-270 DOT：reverse-deadline，mandatory 先锁，optional 填 slack
def schedule(ce, t_rem, nodes):
    plan, slack = [MANDATORY_PATH], t_rem - wcet(MANDATORY_PATH)
    for nd in knapsack_by_value_density(nodes, slack):
        if wcet(nd) <= slack: plan.append(nd); slack -= wcet(nd)
    return plan

# IP-271 DR-CBF：延迟增广不变集；不可行 => None
def dr_cbf(x, u_hist, lam, L_max, J_delta):
    h = augmented_barrier(x, u_hist, L_max + J_delta)
    return qp_certified_prefix(h, lam)

# IP-277 主闭环：先保命，再求信息，最后精化
def PACE_RAS_round(M, s_t, D):
    x, u_hist, tau = s_t
    safe = M.geo_safety.solve(x, u_hist, tau)
    out  = (safe, L3, stamp(now, D))                    # c0
    ok_pte, gap = M.pte.certify(x, M.regime(x))
    if not ok_pte:
        M.audit('pte_out', gap); M.dgl = L3; return M.dgl, out
    ok_ctc, pi_lcb, ece = M.ctc.check()
    z    = M.trunk(x, u_hist, tau)
    cand = M.afp.anytime_sample(M.fmp, z, x, now + D)
    U_ale, U_epi, modes = M.aud.decompose([cand], z)
    if ok_ctc and tempo_ok(U_epi, M.rho_drift.drift_amount(x, D),
                           M.rho_evi.lcb(), D, M.tau_ctl, M.B):
        g = M.mint.choose(modes, D, scorer=tvoi)
        if g is not None:
            ans = M.cia.execute_with_deadline(g, D)
            y   = M.seq.admit(ans, x)
            if y is not None: U_epi = M.cia.update(modes, y)
    lam = max(M.efs.risk_scale(), lam_floor(U_ale + unresolved(U_epi)))
    lam = M.jitter.budget(lam, M.jitter.p99)
    k   = M.dr_cbf.certified_prefix(cand, u_hist, x, lam)
    if k is None: M.dgl = degrade(M.dgl, JITTER); return M.dgl, out
    J = M.cert.sign(J_FLUID=..., pte=(ok_pte, gap), ctc=(pi_lcb, ece),
                    wcet=M.wcet.p99, miss=M.deadline_miss,
                    tempo=M.tempo_margin, dgl=M.dgl)
    M.vqa_rt.submit_async(J, M.seq.summary())
    return M.dgl, (cand[:k], lam, stamp(now, D), J)
```

## 4. 推导

**引理 19（anytime 质量-时间单调界）** 速度场 `‖v_θ‖ ≤ V_max` 且 `L`-Lipschitz 时，在 `s_n` 截断的 rectified flow 与目标分布的 `W_1 ≤ (1−s_n)V_max`，且随步数单调不增；每个检查点过 C-RAS-WM，故 deadline miss 只把输出从「更优」降为「L3 保底」，不会从安全变成不安全。系：实时性以质量为代价，不以安全性为代价。

**引理 20（晚到证据的时序偏差）** 在 `s_{t−Δ}` 产生、于 `s_t` 直接融合的答案造成 `KL(p_t ‖ p_late) ≥ c·ρ_drift·Δ`；漂移与延迟越大越危险。SEQ 的重对齐把可接受延迟限制为 `Δ ≤ τ_re/(c·ρ_drift)`。系：实时系统里，没有时间戳的证据就是伪装成信息的噪声。

**引理 21（CTC 保守门控）** 可交换 real-anchor 上，`π_LCB` 门控使「通道不可信仍追问」的概率 ≤ α；漏问只损效率不损安全，故 CTC 门控安全单调。

**引理 22（DR-CBF 前向不变）** 实际延迟 ≤ `L_max`、抖动 ≤ `J_δ` 时，延迟增广 CBF 保证 `h_d ≥ 0` 前向不变；越界即降 L3，L3 按构造满足不变性，故安全集永不被扩大。

**定理 18（tempo 可行性）** 在 CE 与 tempo 条件下（漂移 UCB、证据 LCB），存在在线调度使所有控制关键工作在 `D` 前完成，被授权的交互在 `D_dec` 前完成采集+融合的概率 ≥ 1−α，且期望 `U_epi` 不增；若 tempo 不成立，则 CE 内无此调度，任何方案要么超时要么让 `U_epi` 悬空，DGL 保证安全。证明：可选工作 EDF + 检查点闭包 + slack 价值密度背包；漂移-证据不等式保证「买到的 ≥ 漂移吃掉的」。

**定理 19（严格包含 R69/R68）** 零延迟、零抖动、`ρ_drift=0`、PTE 全覆盖且永不过期时，tempo 恒可行、T-VoI 退化为静态 VoI、SEQ 恒空、DGL 恒 L0，PACE 逐指令等于 R69；再叠 `VoI ≤ 成本` 等于 R68。沿 DGL 向下安全集单调收缩、恢复需重认证，故任意状态期望风险 ≤ R69，只有「包络内且来得及」才有严格效率增益。系：新层不引入新的信任黑箱，只给旧层加一张可撤销的许可证。

**定理 20（截止满足与无突变）** `WCET(关键路径) ≤ D` 且每个抢占点产出认证动作 ⇒ 无 deadline miss；DGL 下降立即、恢复带 dwell，切换只发生在检查点且新旧输出均安全 ⇒ 控制连续、无抖振。结合引理 22 得「实时 + 安全」联合保证。

### 6.1 解析预实验（非实测，用于标定验收阈值）

取初始模态熵 `H = 2.0 nats`、`D_dec = 50ms`、`τ_ctl = 2.2ms`、认证证据率 `ρ_evi^LCB = 40 nats/s`、兜底抵扣 `B = 0.2 nats`，则证据容量 `= 40×0.0478 + 0.2 ≈ 2.11 nats`。

- 慢漂移 `ρ_drift = 1/s`：`ΔH_drift = 2(e^{0.05}−1) ≈ 0.10 nats`，tempo margin `≈ +2.01 nats`，授权交互；
- 临界漂移：解 `2(e^{0.05ρ}−1) = 2.11` 得 `ρ* ≈ 14.4/s`；
- 快漂移 `ρ_drift = 40/s`：`ΔH_drift ≈ 12.8 nats`，margin `≈ −10.7 nats`，必须不授权交互并降 L1。

结论：在 50ms 视界、单次查询约 0.8 nats/20ms 的设定下，**系统能容忍的仿真信念漂移率约为 14/s**；超过它，「先问再走」在数学上不再可行。这个数应作为 E305 的核心扫描点。

## 7. 本轮最大风险

**一句话**：PACE 的整个授权逻辑押在 `ρ_drift^UCB`——「现实以多快速度让仿真信念过期」——这一个量上；而它恰恰是离开仿真后最难知道、最容易被域随机化和短锚点低估的量，**你用来判断自己来不来得及的钟，本身可能是错的**：一旦它低估漂移，tempo 条件会误判「来得及」，系统就会在错误的先验上自信地追问、把陈旧证据当成新鲜证据融合，最后在截止前被现实追上。

**次级风险与缓解**：
1. PTE 过窄导致永久保守（效率收益清零）→ FBA 按 tempo 边际收益投放锚点 + 许可证分级 + E303/E314；
2. anytime 粗动作虽安全但动态差（顿挫）→ 质量等级门控 + 每检查点认证 + E302；
3. CTC 需真实干预、成本与社交代价高 → 只用低成本微干预锚点 + 复用 R69 交互预算 + E304；
4. 调度在算力争用/热降频下失效 → WCET 含争用裕度 + 抖动越界即降 L3 + E313；
5. 时序-迁移合谋攻击 → `ℰ_PACE` 联合对抗训练 + 证书双包络联签 + E312。
