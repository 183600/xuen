# 第 10 轮（新灵感循环第 1 轮；本轮灵感：「深度学习」×「边缘计算」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**深度证书 + 边界卸载**。两个灵感分别治理 v9 的两笔债：**标定债**（冻结 F̂ + 全局手调 β=0.02，把前向误差当成平稳同分布，证书只有经验置信、没有覆盖保证）与**空间债**（50Hz 算力只能在机内硬挤，p99 已贴 20ms，更强的世界模型无处安放）。深度学习负责把"β"升级为可分解、可校准、可检验的证书；边缘计算负责把"算力"升级为空间上可伸缩、但不进入安全闭环的资源。两者都必须服从 v9 的中立元退化链：边缘失效 / 共形失效 ⇒ 注入 v^⊥ 或回退 v9 固定 β，严格等价 v9，而非行为漂移。

## 0. 直觉与动机

### 灵感 1（深度学习 → 从"冻结黑盒 + 手调 β"到"有覆盖保证的深度证书"）
直觉：v9 的 ActionChunkCertifier 用一个冻结 LSTM-MPC 代理 F̂ 和**一个全局常数 β** 给整块动作上保险。这在工程上很省事，却在认识论上很脆弱：β 是离线标定的单点，隐含"误差在信任域内平稳且同分布"；一旦场景、光照、负载变化，β 要么过保守（算力/成功率白丢），要么过乐观（安全债）。深度学习真正能给的，不是"更大的网络"，而是**可分解、可校准、可检验的不确定性**：深度集成给出认知不确定性（epistemic），异方差输出头给出偶然不确定性（aleatoric），共形预测再把二者变成**有限样本覆盖保证** q̂_{1−α}。核心创新：**共形深度证书器（ConformalDeepCertifier, CDC）**——把 F̂ 升级为深度集成，把标量 β 升级为按上下文桶条件化的共形分位数；证书写成 ĝ_min = μ̂_min − q̂_c − β_lin。关键纪律：覆盖保证只在"桶内可交换 ∧ 桶样本 ≥ n_min ∧ 交换性检验通过"时生效，否则退回 v9 的 β；证书是概率性的，但 v9 的停车不变式仍是确定性的最后防线。两者分工明确：**共形负责"少留余量"，停车守卫负责"错了也能停"**。

### 灵感 2（边缘计算 → 安全边界本地化 + 建议型重计算卸载）
直觉：边缘计算真正的价值不是"把模型搬出去"，而是把算力变成**空间上可伸缩的资源**。但网络有长尾延迟、会断、会被重放/欺骗，而 50Hz 的实时控制等不起一个"可能 80ms 才到"的块。因此正确的问题不是"哪些模块可以卸载"，而是"**哪些模块永远不许卸载，剩余模块如何卸载才不改变安全论证**"。核心创新：**安全分区卸载器（SafetyPartitionedOffload, SPO）**：沿数据依赖图取安全关键汇点的**传递闭包**作为本地安全闭包 L（M₀ 硬检查、SpatialCert、FaultCert、AC 中块守卫与证书校验、MW 自身、停车不变式），只把结果被**守卫端口**读取的建议型模块 E 卸载（大世界模型候选块采样、语义 grounding、长程规划、边缘训练）。E 的结果必须携带**时敏契约**（截止期、输入状态哈希、时间戳）并通过**推测一致性包络**才允许进入本地；否则注入 v^⊥，等价 v9 本地执行。上行只传特征/嵌入（原始音频与图像不出机），并用**单侧 DP** 把隐私成本转化为"更保守的证书"，而不是安全债。50Hz 主环从不阻塞等待边缘。

### 灵感 3（二者耦合 → 边缘训练、联邦共形校准、端侧保守蒸馏）
直觉：深度证书需要大量校准数据，边缘恰好能聚合机队；但联邦数据非 IID，恰好破坏共形预测的交换性假设——这是"用边缘帮共形"的最大陷阱。核心创新：**联邦共形校准器（FederatedConformalCalibrator, FCC）+ 保守蒸馏学生（ConservativeDistilledStudent, CDS）**：边缘只聚合校准残差的分位数草图（单侧加噪），本地永远保留自己的校准集与在线覆盖率监控；端侧学生证书必须**逐点 ≤** 教师证书（保守蒸馏），部署前通过认证回归测试；否则拒绝学生、退回 v9。这样"边缘"只提升效率与覆盖，不承担安全责任。

## 1. 研究问题（轮次升级版）

- **Q1（深度证书的覆盖边界）**：共形保证在域偏移 / 非 IID 下何时失效？上下文桶 + 自适应共形推断（ACI）能否把"边际保证"升级为"长期条件覆盖"，且失效可在线检测并保守回退？深度集成的不确定性分解是否真的比标量 β 更紧而不更险？
- **Q2（卸载的时序非干扰）**：如何把网络抖动、断连、陈旧结果、重放/欺骗统一代数化为"中立元"，使任意边缘轨迹下 50Hz 安全闭环的守卫判定与本地执行一致？安全分区边界能否由数据依赖闭包形式化审计，而非人工标注？
- **Q3（联邦校准与安全责任）**：非 IID 下联邦共形校准能否只改善效率、绝不削弱本地覆盖？保守蒸馏能否把教师的覆盖保证传递给端侧学生，而不把安全责任转移到边缘？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 安全边界本地律（Safety-Partitioned Locality, SPO）**
安全闭包 L 定义为所有安全关键汇点沿数据依赖图的反向传递闭包；L 内模块及其守卫永远在机内执行。边缘模块 E 只能通过**守卫端口**写入，且写入必须同时满足时敏契约与推测一致性包络；任一条件不满足即注入 v^⊥。任何边缘结果的进入都不得绕过 L 的实时守卫与停车不变式。

**P14 共形深度证书律（Conformal Deep Certificate, CDC）**
块证书余量不再是一个全局常数，而是上下文桶 c 上的单侧共形分位数 q̂_c：ĝ_min = min_k μ̂_g − q̂_c^g − β_lin，ê_max = max_k μ̂_e + q̂_c^e + β_lin。q̂_c 仅在桶内可交换性检验通过、样本量 ≥ n_min 时启用；否则逐级回退到父桶、全局桶，最终回退 v9 的固定 β。q̂_c 另受自适应共形推断（ACI）在线修正，并硬性截断于 β_max = v9 的最坏情形余量。

**P15 保守蒸馏律（Conservative Distillation, CDS）**
端侧学生 g_ψ 的证书必须在验证域 D_val 上逐点不高于教师证书：cert_s(x) ≤ cert_t(x)。违反者拒绝部署；域外输入一律回退 v9 冻结 F̂ + β。蒸馏只允许"把更紧的证书搬到端侧"，不允许"把更松的证书搬到端侧"。

## 3. 与 v9 的接口（如何退化）

- 边缘结果超时 / 陈旧 / 状态哈希不符 / 一致性包络拒绝 ⇒ E 端口注入 v^⊥，本地 v9 路径继续；
- 边缘断连 / 隐私预算耗尽 ⇒ 全部 E 端口 v^⊥，等价 v9 本地执行；
- 共形桶样本不足 / 交换性检验失败 / 覆盖率跌破门槛 ⇒ q̂_c 逐级回退至 v9 固定 β，再不行 K_eff ← 1；
- 蒸馏认证回归失败 ⇒ 拒绝学生，回退 v9 冻结 F̂ + β；
- CDC / SPO / FCC 任一失效 ⇒ 严格退回 v9 MetricVoiceGauge-ACMD；
- v9 的 AC/MW/ID 失效 ⇒ 按 v9 五级链退回 v8 / v7 / v6。

## 4. 预期贡献

1. **两层安全论证**：共形覆盖（概率层）+ v9 停车不变式（确定层）首次被显式分工，证书可以更紧，但安全性永远由本地实时守卫兜底；
2. **安全分区卸载**：用数据依赖闭包定义"永不出机"的安全闭包，用守卫端口 + 时敏契约 + 一致性包络把网络时序不确定性代数化为中立元，给出时序非干扰引理；
3. **联邦共形校准 + 保守蒸馏**：机队数据提升证书质量与算力效率，但安全责任不转移；单侧 DP 使隐私只花效率、不花安全；
4. **预算-安全-隐私三角**：E571–E592 覆盖共形覆盖、非 IID、网络长尾、断连等价、蒸馏回归、隐私预算、对抗边缘与端到端任务。

## 5. 本轮最大风险

**一句话**：边缘卸载把安全论证从"模型误差"扩展为"模型误差 × 网络时序 × 分区正确性"，而分区边界与共形交换性都依赖可能出错的人工/统计判断——一旦某个实际影响安全闭包的模块被误判为可卸载，或边缘教师与本地学生共享同一失效模式，一致性包络（两边都错）就无法发现，网络延迟会被"合法地"注入安全环路。

**新增定义 540（深度集成世界模型 DeepEnsembleWorldModel, DEW）** 前向世界模型由 M=5 个独立训练的成员组成，每个成员输出指标均值 f_i(x) 与异方差尺度 s_i(x)>0（x=(state, a^{1:K})）：
```
μ̂(x) = (1/M) Σ_i f_i(x)
σ̂²_epi(x) = (1/M) Σ_i (f_i(x) − μ̂(x))²
σ̂²_ale(x) = (1/M) Σ_i s_i(x)²
```
训练目标为异方差负对数似然 + 安全加权项（M₀ 间隙与 effort 样本权重 ×5）；部署后**冻结**，安全路径上不做在线梯度更新（在线只允许 Bucket 路由、ACI 与选择，不允许改权重）。σ̂ 只用于桶路由、主动采样与分布漂移报警，**不直接进入安全证书**，避免与共形 q̂ 重复计数。

**新增定义 541（共形块证书 ConformalChunkCertificate, CCC）** 在上下文桶 c 内取单侧非一致性分数
```
r_i = max_{k≤K} ( μ̂_g(x_i,k) − g_true(x_i,k) )        # 前缀最坏：一次覆盖整块所有 k
q̂_c = Quantile_{⌈(n_c+1)(1−α)⌉/n_c}( {r_i}_{i=1..n_c} )
```
证书为
```
ĝ_min = min_{k≤K} μ̂_g(s,a^{1:k}) − q̂_c^g − β_lin
ê_max = max_{k≤K} μ̂_e(s,a^{1:k}) + q̂_c^e + β_lin
```
其中 β_lin 是几何/线性化余量（不可由学习吸收）。有效条件：n_c ≥ n_min、交换性检验通过、⌈(n_c+1)(1−α)⌉ ≤ n_c、且 q̂_c ≤ β_max；否则逐级回退父桶 → 全局桶 → v9 固定 β（β_max 取 v9 经验误差上界 ×1.2）。证书结构里保留 (c, n_c, cov_c) 以便离线审计与逐位复现。

**新增定义 542（上下文条件共形校准 ContextConditionalConformal, C4）** 桶 c=(scene_class, bin(Δ_dom), bin(risk_SLAM))，bin 取 {低,中,高}；每个桶独立做 Mondrian 共形。交换性检验：把桶内标定集对半切，一半拟合 q̂、另一半算经验覆盖；若 |cov_holdout − (1−α)| > δ_ex 或残差分布 KS 检验 p<0.01，则判该桶**不可交换**，整桶失效并回退父桶。冷启动桶（n_c<n_min）不发证书，直接 v9 固定 β。该定义把"域偏移导致共形失效"变成**可检测、可回退**的状态，而不是静默乐观。

**新增定义 543（安全分区与本地闭包 SafetyPartition, SP）** 在模块数据依赖图 G=(V,E_dep) 上定义安全关键汇点
```
S = { M₀硬检查, SpatialCert, FaultCert, AC中块守卫, AC证书校验, MW调度器, 停车不变式检查 }
L = { v ∈ V | v 在 G 中可反向到达某个 s ∈ S }        # 反向传递闭包
E = V \ L,  约束：E 到 S 的每条路径都必须经过一个守卫端口 g
```
守卫端口 g 对 E 结果的写入谓词为 A(·)（定义 545）∧ 时敏契约（定义 544）。等价地：**任何能影响安全变量的模块都在 L，永不出机**；边缘最长只能影响"建议"，不能影响"守卫看到的世界"。部署期用静态数据流 + CBMC 断言 `无 E→S 的未守卫路径`。

**新增定义 544（时敏卸载契约 TimedOffloadContract, TOC）** 边缘模块 m 声明
```
κ^E_m = (In, Out, D_m, Ŵ_m^edge, v^⊥, D_edge, ε_p, δ_state)
```
请求携带状态哈希 h_t 与时间戳 t_s；结果在本地被接受当且仅当：
```
(i)  Δt_age = t_recv − t_s ≤ D_edge                     # 未过期
(ii) h(result) = h_t  ∧  drift(state_now, state_at_t_s) ≤ δ_state   # 状态未漂移
(iii) 该次调用消耗的隐私预算累计 ε_total ≤ ε_max
(iv) 一致性包络 A(ζ_edge, ζ_loc) = true
```
任一不满足即返回 v^⊥ = 本地推测结果 ζ_loc。注意 (ii)：块是在状态 s_t 上生成的，若回程期间状态漂移超过 δ_state，即使动作序列本身合法，也不再对应当前状态，必须作废；这条把"陈旧但格式正确"的网络结果也归入中立元。

**新增定义 545（推测一致性包络 SpeculativeConsistencyEnvelope, SCE）** 本地永远并行运行一个廉价推测器（v9 固定 β 的 chunker 或端侧学生），产出 ζ_loc；边缘结果 ζ_edge 仅在
```
A = [ ĝ_min(ζ_edge) ≥ ĝ_min(ζ_loc) ] ∧ [ ê_max(ζ_edge) ≤ ê_max(ζ_loc) ]
    ∧ [ γ̂_grasp(ζ_edge) ⪰ γ̂_grasp(ζ_loc) ] ∧ [ P(ζ_edge) ≠ ∅ ]
    ∧ [ 首步动作通过本地实时守卫 ]
```
时替换本地块。**δ_consistency 取 0**：边缘只能在"证书不更差"时胜出，因此边缘永远不能把本地安全性拉低；它赢得的是更长块长、更高任务得分与更好中止点密度，而不是更松的证书。若边缘多数次无法胜出，SPO 自动降低该模块的卸载优先级（E560 的效率统计）。

**新增定义 546（保守蒸馏学生 ConservativeDistilledStudent, CDS）** 端侧学生 g_ψ 以教师集成/证书为目标，损失
```
L(ψ) = L_task + λ·E_x[ max(0, cert_s(x) − cert_t(x)) ] + μ·CoveragePenalty
```
训练后做**认证回归**：在验证域 D_val 上逐点检查 cert_s(x) ≤ cert_t(x)+tol，且学生覆盖率 ≥ 1−α−ε_cov，且学生 WCET ≤ Ŵ_s；任一失败则把学生 q̂ 抬升 δ_violation 后重测，仍失败则拒绝部署、回退 v9。域外输入（桶无效或分布漂移超阈）直接走 v9 路径，不使用学生证书。

**新增定义 547（联邦共形校准 FederatedConformalCalibrator, FCC）** 机器人 i 在本地计算残差分位数草图（直方图或 GK sketch），只上传**单侧噪声**后的分位数
```
q̃_i = q̂_i + Lap⁺(Δq/ε_i)          # 只向上加噪，保证 q̃_i ≥ q̂_i
q̂_global = WeightedQuantile( {(q̃_i, n_i)} )
q̂_i* = max( q̂_i, q̂_global + δ_prior )
```
边缘从不接收原始数据、图像或音频，只接收 `(模块, 桶, 分位数, 样本数)`。由于最终取 max，全局先验只能让本地证书更保守、不能更乐观；非 IID 的代价被限制在效率（q̂ 偏大），而不是安全（覆盖被削弱）。

**新增定义 548（本地覆盖监控与自适应共形 LocalCoverageMonitor, LCM/ACI）** 滑动窗口 W=500 块，在线记录 err_t = 1{g_t < ĝ_min,t}；按自适应共形推断更新
```
q̂_{t+1} = clip( q̂_t + γ_t (α − err_t), 0, β_max )
```
γ_t = γ₀/(1+t/T_γ) 为递减步长。该更新在分数有界时给出长期平均覆盖 ≥ 1−α 的保证，**不要求交换性**，因此可兜住 C4 的桶失效与真实域跳变；代价是偏移期间瞬时覆盖可能低于 1−α。为安全起见，偏移检测（σ̂_epi 突增或 KS 漂移）触发**立即加性抬升** q̂ ← min(β_max, q̂ + δ_jump)，指数回退只在连续 H_safe 个窗口盈余后进行。若 q̂ 连续 H_max 个窗口贴住 β_max，判共形失效（Level-3），K_eff ← 1。

**新增定义 549（边缘账本与隐私账户 EdgeLedger）** 每次卸载记录 `(module, bucket, h_t, t_s, Δt_age, q̂_used, accept/reject, reason, ε_spent)`，形成可复现审计链。账本触发两类自动降级：(i) ε_total > ε_max ⇒ 关闭所有 E（Level-2）；(ii) 某 E 模块的"被接受但随后被本地守卫中止"比率连续超阈 ⇒ 判该模块建议不可信，永久回退该模块到 v9（Level-2），并进入离线复盘。**安全相关性由审计日志证明，而不是由部署者口头声明。**

**升级定义 539（有效块长，v10）** 当边缘块被接受、证书有效且 `Δ_dom < τ_dom/2` 时，允许 `K_eff = min(K_max^edge, K_edge)`，其中 `K_max^edge = 2·K_max`；否则严格使用 v9 公式。边缘一旦缺席，K_eff **立即**回退到 v9 值（不等块边界），防止"用边缘算力换来的长块"在断连后继续执行。

# IP-357 ConformalDeepCertifier：共形深度证书器
class ConformalDeepCertifier:
    def __init__(self, ensemble, calib_store, alpha=0.01, n_min=200,
                 beta_lin=0.005, beta_max=0.02, delta_ex=0.03):
        self.F, self.calib = ensemble, calib_store
        self.alpha, self.n_min = alpha, n_min
        self.beta_lin, self.beta_max, self.delta_ex = beta_lin, beta_max, delta_ex

    def bucket(self, delta_dom, risk_slam, scene):
        return (scene, bin3(delta_dom), bin3(risk_slam))

    def quantile(self, c):
        b = self.calib.get(c)
        if b is None or b.n < self.n_min:
            return None                                   # 冷启动 → v9 固定 β
        q = empirical_quantile(b.residuals, 1 - self.alpha)
        if q is None or q > self.beta_max:
            return None                                   # 过于保守 → 退回 v9
        if abs(holdout_coverage(b) - (1 - self.alpha)) > self.delta_ex:
            return None                                   # 交换性检验失败
        return q

    def certify(self, state, actions):
        mu, epi, ale = self.F.predict(state, actions)     # 定义 540
        c = self.bucket(state.delta_dom, state.risk_slam, state.scene)
        q = self.quantile(c)
        if q is None:
            return v9_fixed_certificate(state, actions, beta=self.beta_max)
        g_min = mu.g_min - q.g - self.beta_lin           # 定义 541
        e_max = mu.e_max + q.e + self.beta_lin
        if g_min < state.d_safe or e_max > state.tau_eff:
            return None                                   # 证书不通过，拒绝候选
        return Cert(g_min, e_max, q, c, self.calib[(c)].n)


# IP-358 SafetyPartitionedOffload：安全分区卸载器（非阻塞）
class SafetyPartitionedOffload:
    LOCAL = {'M0', 'SpatialCert', 'FaultCert', 'AC_GUARD', 'CERT_CHECK', 'MW', 'STOP_INV'}
    EDGE   = {'BIG_WORLD_MODEL_CHUNKER', 'SEMANTIC_GROUNDING', 'LONG_HORIZON_PLAN'}

    def __init__(self, client, local_speculator, ledger, eps_max=8.0):
        self.client, self.local = client, local_speculator
        self.ledger, self.eps_max = ledger, eps_max

    def submit(self, module, features, state, contract):
        assert module in self.EDGE and module not in self.LOCAL
        h = state_hash(state)
        payload = dp_features(features, contract.eps_p)      # 原始数据不出机
        return self.client.send_async(module, payload, h,
                                      t_s=now(), deadline=contract.D_edge)

    def poll(self, future, local_chunk, state, contract):
        r = future.try_get()                                  # 绝不阻塞
        if r is None:
            return local_chunk, 'pending'                     # 本周期用本地块
        if now() - r.t_s > contract.D_edge:
            return local_chunk, 'stale'                       # 定义 544(i)
        if r.state_hash != state_hash(state) or \
           state_drift(state, r.state_at_s) > contract.delta_state:
            return local_chunk, 'state_drift'                 # 定义 544(ii)
        if not self.ledger.can_spend(contract.eps_p):
            return local_chunk, 'privacy_budget'
        if not consistency_envelope(r.chunk, local_chunk):    # 定义 545
            return local_chunk, 'envelope_reject'
        return r.chunk, 'accepted'

class FederatedConformalCalibrator:
    def aggregate(self, sketches):                            # {(q_i, n_i)}
        noisy = [(q + lap_positive(delta_q / eps_i), n)
                 for q, n, eps_i in sketches]                 # 单侧 DP，只会更保守
        return weighted_quantile(noisy)

    def local_merge(self, q_local, q_global, delta_prior=0.002):
        return max(q_local, q_global + delta_prior)           # 定义 547

## 4. 推导

**引理 87（共形块证书的有限样本覆盖）** 固定桶 c 与块长 K，设标定样本与测试样本在桶内可交换，非一致性分数取前缀最坏残差 r_i=max_{k≤K}(μ̂_g−g_true)。则对 q̂_c=Quantile_{⌈(n+1)(1−α)⌉/n}，有
```
P( g_k ≥ ĝ_min  ∀k≤K ) ≥ 1 − α
```
证明：前缀最坏分数把"整块所有 k 同时覆盖"化为单变量单侧覆盖；标准共形分位数给出 P(r_new ≤ q̂_c) ≥ 1−α，而 r_new ≤ q̂_c ⇔ ∀k: μ̂_g,k−g_k ≤ q̂_c ⇔ g_k ≥ μ̂_g,k−q̂_c ≥ ĝ_min。有限样本修正 ⌈(n+1)(1−α)⌉ 处理 n 较小时的分位数偏置。∎ 注意该保证是**边际的**（对桶内随机测试点），不是逐状态条件保证；这正是需要 C4 分桶、ACI 与确定性停车守卫三层兜底的原因。

**引理 88（安全分区非干扰）** 在定义 543 的分区下，任意边缘轨迹（包括延迟、丢包、重放、伪造）都不改变安全闭包 L 的本地守卫判定序列，除非边缘建议通过守卫端口 A 且 cert_edge ≥ cert_loc。证明：安全变量只被 L 中模块写入；E 的输出只能到达守卫端口，而端口谓词 A 要求 cert_edge 分量不劣于本地推测块、P(ζ_edge)≠∅、且首步通过本地实时守卫。即便边缘结果伪造了"更好的证书"，本地守卫仍在每个控制周期用**实时观测**重算停车不变式；一旦破坏，立即切换到重新验证过的中止点或紧急制动。于是边缘能影响的只有"选哪个候选块"，不能影响"候选是否被本地守卫接受/中止"，故安全判定与边缘无关。∎

**引理 89（边缘失效 ≡ v9）** 当所有 E 端口取 v^⊥=ζ_loc 且 CDC 回退 v9 固定 β 时，MetricVoiceGauge-DECO 的数据流与判定序列与 v9 MetricVoiceGauge-ACMD 相同：本地模块集合不变、K_eff 使用 v9 公式、中块守卫与停车不变式不变、ID/MW 契约不变。因此安全相关变量逐位等价；日志仅多出边缘账本的空记录。∎

**引理 90（保守蒸馏的保证传递）** 若在验证域 D_val 上 cert_s(x) ≤ cert_t(x)，且学生与教师使用同一守卫与中止点规则，则学生接受的动作块集合 ⊆ 教师接受的动作块集合。于是对任意 x∈D_val，P(g ≥ cert_s) ≥ P(g ≥ cert_t) ≥ 1−α；教师覆盖保证被传递给学生而不放大风险。域外输入不使用学生证书（回退 v9），故该传递无需假设全局可交换。∎

**引理 91（联邦校准的局部有效性）** 定义 547 的本地合并为 q̂_i*=max(q̂_i, q̂_global+δ_prior) ≥ q̂_i；证书 ĝ_min 关于 q̂ 单调不增，故合并只会让证书更保守。单侧 DP 噪声 Lap⁺ 非负，进一步只增大 q̃_i。因此 q̂_i* 的本地覆盖不劣于纯本地 q̂_i；非 IID 与隐私噪声的代价只体现为 q̂ 变大（效率下降），不会削弱本地覆盖率。∎

**引理 92（ACI 长期覆盖与自愈收敛）** 在残差有界且步长 γ_t 满足标准递减条件时，定义 548 的更新给出长期平均覆盖 ≥1−α−o(1)；q̂ 被硬截断在 [0,β_max]，故不会无限增长。偏移检测触发加性抬升、回退仅在连续盈余后缓慢进行，形成非对称滞回，故 q̂ 不会在阈值附近高频振荡；若 q̂ 贴住 β_max 超过 H_max 个窗口，则系统宣告共形失效并按定义 539 令 K_eff=1。∎

**引理 93（时敏卸载的 50Hz 守恒）** SPO 的 `submit` 异步、`poll` 只做 O(1) 的 `try_get` 与哈希/包络比较；主环从不阻塞等待网络。被接受的边缘块只在块边界替换本地块，且替换后仍由本地守卫逐周期检查。因此每周期的本地最坏执行时间与 v9 相同（感知 ≤2ms + 决策 ≤20ms），网络延迟/抖动不改变周期长度；超时即 `pending/stale` 并继续用本地块。故 50Hz 守恒与网络无关。∎

## 8. 本轮最大风险

**一句话**：边缘卸载把安全论证从"模型误差"扩展为"模型误差 × 网络时序 × 分区正确性"，而分区边界与共形交换性都依赖可能出错的人工/统计判断——一旦某个实际影响安全闭包的模块被误判为可卸载，或边缘教师与本地学生共享同一失效模式，一致性包络（两边都错）就无法发现，网络延迟会被"合法地"注入安全环路。
