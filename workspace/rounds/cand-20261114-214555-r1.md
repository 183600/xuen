# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「论文发表」×「检索增强生成」）

> R69 让系统学会了「问」：把不确定性拆成 aleatoric/epistemic，用流匹配采样得到有形状的歧义，再用注视、探针、问句这些信息动作去消解。但 R69 有一个被忽略的前提——**每一次回答都是即时消费、用完即弃的**。系统不会积累「上次在类似情境里，这个笑容意味着紧张」这类知识；它每一轮都在重新发现、重新提问；k 源一致性只在当次有效，事后无法复查；一个被验证过的错误也无法被撤销。更危险的是，R69 已经承认：问错比不问更危险。可如果系统连「上次问过、上次答过、上次错在哪」都不记得，它就注定要把同一个错误反复问出来。
>
> 本轮两个灵感恰好补上「时间维度」与「外部记忆」：
> - **检索增强生成（RAG）**给出「先查再答」的范式——把知识放在模型之外，可检索、可更新、可引用；
> - **论文发表**给出让外部知识**可信**的社会-认识论机制——出处（provenance）、同行复现（peer replication）、引用（citation）、预印本与正式发表的分级，以及最关键的**撤稿（retraction）**。
>
> 核心命题：**epistemic 不确定性的消解有两个基质——「脑内」（策略采样 + 即时交互）与「脑外」（积累的知识库/文献层）。R69 只用前者；R70 增加一个可版本化、可溯源、靠独立复现获得权威、可撤稿的知识层：先检索、再交互、最后保守。** 命名 **PEER-RAS**（Publication-grounded Epistemic Evidence Retrieval for Risk-adaptive Systems；PEER 同时呼应 peer review）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我们已经知道了什么，我们记住的东西还可信吗**」——记忆不是免费的；记得错，比不知道更危险。

## 0. 直觉与动机

**灵感 1（RAG → 先查后问：很多歧义去年就解决过）**
直觉：R69 每当 U_epi 超过阈值就去「问」，默认知识只能现取。但一个长期运行的具身系统会反复遇到结构相似的情境：同一个人的某类表情、同一种材质反光、同一类岔路。把这些已解决的歧义沉淀为可检索的主张，系统就能在**花掉一次物理/社交交互之前**先把它查出来。检索是「零物理成本的信息动作」：它不转身、不伸手、不打扰人，只读记忆。这把 R69 的「问一次」扩展成「先查、查不到再问」。但要小心：查到的可能不是当下的情形（不适配）、可能过期、可能是被人塞进来的假文献。

**灵感 2（论文发表 → 出处与撤稿：让「已验证」可被推翻）**
直觉：R69 的「k 个正交源一致」是在当次交互内完成的，事后没有任何持久记录，也没有撤销机制。论文发表给了三样东西：(a) **provenance**——每个断言写明谁、何时、在什么条件下、用什么方法得到；(b) **versioning/conflict**——同一命题可有多个版本与相互矛盾的结论，用引用关系组织；(c) **retraction**——被证伪的主张会被撤稿，且依赖它的后续工作要被标红。映射到闭环：每个交互回答不再直接进策略，而是登记为「主张」；一个误导性回答即使当次骗过了证据纪律，也会在后续复现失败时被撤稿，并回溯标记曾依赖它的决策与证书。这正是对 R69 最大风险（「把误导性回答盖上已验证的章」）的制度性回应——**不是保证永不误信，而是保证误信可被发现、可被追责、可被撤回**。

**灵感 3（同行评审/复现 → 权威是挣来的，不是声称的）**
直觉：RAG 最大的幻觉来源是「检索到什么就信什么」。论文发表的解药是**复现**：一个结论被独立研究者在不同情境下重复得到，才配得上高权威。于是知识库里的每条主张有一个**权威分**，它只能通过**独立**复现（来源独立、情境多样、无共同祖先）增长；单次、单源、自我引用都不能升权。检索时，权威分决定它能在多大程度上改写模态后验。没有这一层，知识库就是一台「自信放大器」。

**灵感 4（引用 → 决策的证据链可审计、可局部定位）**
直觉：R69 的参与式审计是整体性的、事后的。引用（citation）把审计变成「查参考文献」：每个动作与证书记录它引用了哪些主张；一旦某条主张被撤稿，反查引用图就能精确列出所有受影响的动作/证书/部署，而不必重跑全系统。这把「可解释」从一句口号变成一张可机器核验的**依赖图**。

**灵感 5（发表制度也是攻击面 → 知识库投毒与引用洗白）**
直觉：现实学界有掠夺性期刊、引用卡特尔、造假论文；知识库同样会有：注入假主张、用互相引用虚增权威（citation laundering）、投喂过期知识、针对特定查询做投毒。**一旦系统「记得」，攻击就从「骗它一次」升级为「让它长期相信一个错误」，而且这种错误会压制它去问本该问的问题**。所以 R70 必须同时交付：知识库门控（新鲜度/适配性/来源信誉）、引用洗白防护（权威只认独立根）、撤稿传播、以及「预印本只能影响问什么、不能给予效率奖励」的两级权威。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（PEER-RAS 总览）** PEER-RAS = (CLM, RAG-G, REV, RTP, TIP, KBG, CIT, ALG, RAS-WM†)。继承 R69 的三条不变式（定义 293-i/ii/iii），并新增三条：
(iv) **先查后问（lookup-first，条件性）**：零物理成本的检索先于物理/社交交互被评估；但若检索的尾部风险（陈旧/投毒）高于交互，则顺序反转（引理 21）；
(v) **出处完备（provenance-completeness）**：任何进入后验的主张必须有可核验的出处与引用链，否则视同不存在；
(vi) **权威单调（authority-monotonicity）**：权威只能由独立复现增加，不得由自我引用、单源或同源多跳引用升权；唯一能让权威下降的合法操作是撤稿/污染检测。

**定义 311（主张 Claim）** 一条主张 c = (φ_c, C_app, src_c, t_c, E_c, ver_c, τ_c)。其中 φ_c: 𝒪→Δ(ℳ) 是该主张对模态的后验映射（「观察到这类证据时，模态为 m 的似然」），C_app ⊆ 情境空间是适用条件（光照、距离、对象身份、版本等），src_c 为出处元组（来源、方法、时间），t_c 为采集时刻，E_c 为支持证据链（观测或子主张集合），ver_c 为版本，τ_c ∈ {preprint, reviewed, retracted} 为发表状态。

**定义 312（知识库与引用图 KB）** 知识库 𝒦 = (C, E_cite, Index)。引用图 G_KB = (C, E_cite)，边 c→c′ 表示 c 的成立依赖 c′（派生/引用）。Index 为对 (φ_c, C_app) 的向量索引，支持近似近邻检索。图允许冲突：同一情境可有多条相互矛盾的主张并存，由权威与证据仲裁，而非静默平均。

**定义 313（检索增广 RAG-G）** 由当前观测与歧义模态构造查询 q_ret = Q(z_t, {m_k}, {ξ̄_k})。检索 top-N 主张，经 KBG 门控（定义 316）后得可用集 𝒦_ok。检索先验用对数意见池（log-opinion pool）融合：
log p_ret(M|o) = Σ_{c∈𝒦_ok} a_eff(c,o)·log φ_c(M)，
其中 a_eff(c,o) = auth(c)·fresh(c)·κ(c,o) 为有效权威，κ 为适用性核。最终后验
p(M|o,𝒦) ∝ p_flow(M|o)·exp(Σ_c a_eff(c,o)·log φ_c(M))。
若 𝒦_ok=∅，则 p_ret 均匀，p(M|o,𝒦)=p_flow(M|o)——严格退化为 R69。

**定义 314（复现权威 REV）** 权威 auth(c) ∈ [0,1] 是对「c 为真」的后验信念，由独立复现证据更新：
auth(c) = σ(β_0 + β_1·n_indep(c) + β_2·div_ctx(c) − β_3·taint(c))，
其中 n_indep 为来源两两独立的复现次数，div_ctx 为复现情境多样性（情境两两距离 ≥ δ_ctx 的对数），taint 为撤稿/污染传播量。两级门槛：τ_c=preprint ⇒ auth ≤ a_pre；τ_c=reviewed ⇔ auth ≥ a_rev ∧ n_indep ≥ k_rev。只有 reviewed 主张可给予 resolution bonus（定义 323）。

**定义 315（引用洗白防护 ALG）** 权威增量只来自「独立根」：对任一复现证据，沿 G_KB 反向追溯其证据根集合 Roots(e)；仅当 |Roots(e) \ Roots(c)| ≥ 1 且与已有证据根两两不交时计为独立。互为引用的团（clique）只算一个根，故自我引用无法把 auth 抬过单源上限 a_single。检测到高密度互引子图（环路比 > ρ_cycle）时标记为疑似引用卡特尔，冻结其升权并转元审计。

**定义 316（知识库门 KBG：适配性、新鲜度、来源门）** 主张 c 可用（c∈𝒦_ok）当且仅当：
(i) 适配：κ(c,o) = exp(−d_ctx(C_app, ctx(o))²/2σ_app²) ≥ κ_min；
(ii) 新鲜：fresh(c) = exp(−(t_now−t_c)/τ_fresh)·1[drift_test(c) passes]；
(iii) 来源信誉 ρ(src_c) ≥ ρ_min，且 c 不在相对策略训练分布的 OOD 区域；
(iv) τ_c ≠ retracted。
任一不满足 ⇒ c 视同不存在，不进入定义 313 的融合。

**定义 317（撤稿与溯源 RTP）** 撤稿事件 retract(c) 令 τ_c=retracted、auth(c)←0。沿反向引用边传播：任何直接或间接依赖 c 的主张 d 获得 taint(d) += w(c→d)，若累计 taint(d) 超过阈值 τ_taint 则 d 降级为 preprint 或失效。任何引用了被污染主张的动作/证书被标记 provisional 并进入复审队列。撤销是**单调保守**的：只可能移除权威、增加不确定性，不会凭空增加信任。

**定义 318（三选一信息策略 TIP）** 在状态 o 下可选的获取信息方式为 r（检索，成本 c_r、尾部风险 r_ret）、g（物理/社交交互，成本 c_g、风险 r_int）、∅（直接保守）。定义
J(r)=VoI(r)−c_r−ρ·r_ret，J(g)=VoI(g)−c_g−ρ·r_int，J(∅)=0。
若 J(r) ≥ max(J(g),0) 且 r_ret ≤ r_int：先检索；若检索后 H_mode 降到阈值以下且来源为 reviewed，则直接采纳（resolution bonus）；否则继续在 g 上求 max(J(g),0)。若 max(J(r),J(g)) ≤ 0：不交互，走 R69/R68 兜底。lookup-first 是「当 r_ret ≤ r_int 时」的排序结论，不是无条件公理（引理 21）。

**定义 319（检索-交互协同）** 检索不仅回答「是什么」，还可回答「该问什么」：若某高权威主张指向与当前流模态冲突的模态，则把它转成一次**针对性复现交互**（问句 q 由冲突对生成），其 VoI 用冲突后验熵计算。于是「查」与「问」不是竞争而是级联：查缩小假设集，问验证被检索主张。

**定义 320（引用审计 CIT）** 每个动作 a、证书 J、以及风险缩放决策记录引用集 R(·) ⊆ 𝒦。审计 = 核验引用：逐条检查 κ/新鲜/权威/撤稿状态；发现引用已失效则证书降级。证书含 citation_root_hash，可离线重放引用图做局部复核，无需重跑整个闭环。

**定义 321（知识库威胁 ℰ_PEER）** ℰ_KB = {假主张注入（KB poisoning）、引用洗白（citation laundering/cartel）、陈旧知识（分布漂移后仍被检索）、查询定向投毒（retrieval collusion）、自动生成的幻觉主张}。总威胁集 ℰ_PEER = ℰ_FLUID × ℰ_KB（R69 的交互投毒与 R70 的知识库投毒可叠加）。

**定义 322（证书 J_PEER）** J_PEER = (J_FLUID, auth_used, retrieval_ratio, retraction_flags, freshness_min, citation_root_hash, kb_ver)。Valid ⇔ Valid(J_FLUID) ∧ 所有引用主张过 KBG 门 ∧ 无 retracted 引用 ∧（若使用 resolution bonus）引用主张均 reviewed。retrieval_ratio 与权威分位数一并入证。

**定义 323（两级权威与 resolution bonus）** resolution bonus 的授予需同时满足：引用主张均为 reviewed、ECE ≤ τ_ece、无 retraction 标记、检索后验熵下降超过 ΔH_min。**preprint 主张只能改变「问什么」（提示候选交互），绝不能授予 bonus、不能降低 λ**。若知识库整体不可信（引用洗白/高污染率），KBG 全拒 ⇒ 退化为 R69；若 R69 的 ECE 门也越界，则退化为 R68。

**定义 324（权威的时间衰减与再验证）** auth_eff 含时间衰减；当一条高被引主张的 fresh(c) 跌破 τ_fresh 时，触发一次「再验证」交互（定义 319），其成本记入预算。知识不是一次发表的静态事实，而是需要定期复现的活的结论。

**定义 325（严格包含与退化链）** 当 𝒦=∅、或 KBG 全拒、或所有候选 J≤0 时，PEER-RAS 与 FLUID-RAS 逐指令相同；当 FLUID 再退化（VoI≤成本/ECE 越界）时与 R68 相同。故 R70 ⊇ R69 ⊇ R68，安全侧逐级不让步。

# IP-264 CLM：主张登记与版本（交互回答不即时消费，先入账）
class ClaimLedger:
    def register(self, phi, cond, src, evidence, tier="preprint"):
        c = Claim(phi=phi, C_app=cond, src=src, t=now(), E=evidence,
                  ver=self.next_version(), tau=tier)
        self.kb.add(c); self.index.add(c)          # 追加写，不覆盖
        return c

    def revise(self, c, new_evidence, tier=None):
        # 只增加证据/版本，不静默改写；冲突并存而非平均
        c2 = c.with_evidence(new_evidence, tau=tier or c.tau)
        self.kb.add(c2); self.kb.add_edge(c2, c)   # 版本继承引用边
        return c2

# IP-265 RAG-G：检索增广后验（先查）
def retrieve_ground(z, modes, o, kb):
    q    = query(z, modes)
    cand = kb.index.search(q, N=32)
    ok   = [c for c in cand if kb_gate(c, o)]       # 定义 316
    if not ok:
        return None, []                             # 退化 R69
    logp = sum(auth_eff(c, o) * log(c.phi(o)) for c in ok)
    return softmax(logp), ok

def fuse(p_flow, p_ret, ok):
    return renormalize(p_flow * exp(log(p_ret + eps))) if ok else p_flow

# IP-266 REV + IP-273 ALG：复现权威与引用洗白防护
def update_authority(c, repl, kb):
    roots_new = kb.roots(repl) - kb.roots(c)
    if not independent(roots_new, kb.roots(c)): return   # 同源不计
    if any(cycle(c, r) for r in roots_new):      return   # 互引不计
    c.n_indep += 1; c.div_ctx = diversity(repl)
    c.auth = sigmoid(b0 + b1*c.n_indep + b2*c.div_ctx - b3*c.taint)
    c.tau  = "reviewed" if (c.auth >= A_REV and c.n_indep >= K_REV) else "preprint"

# IP-267 RTP：撤稿传播（单调保守）
def retract(c, kb):
    c.tau, c.auth = "retracted", 0.0
    for d in kb.reverse_reach(c):                 # 依赖 c 的主张
        d.taint += kb.edge_w(c, d)
        if d.taint >= TAU_TAINT:
            d.tau = "preprint"; d.auth *= (1 - d.taint)
    mark_dependent_certificates_provisional(c)    # 引用审计的局部失效

# IP-268 TIP：三选一（先查后问，条件性）
def plan_info(o, modes, p_flow, kb, budget):
    p_ret, ok = retrieve_ground(z, modes, o, kb) if budget.allow_retrieval() else (None, [])
    J_r = voi(p_flow, p_ret) - C_R - RHO*ret_tail_risk(ok) if ok else -inf
    best_g, J_g = choose_interaction(modes, p_flow, o, budget)   # R69 的 MINT
    if J_r >= max(J_g, 0) and ret_tail_risk(ok) <= int_risk(best_g):
        p_post = fuse(p_flow, p_ret, ok)
        if reviewed(ok) and entropy(p_post) < TAU_H and ece_ok():
            return ("adopt", ok, p_post)          # resolution bonus（仅 reviewed）
        return ("ask", best_g, p_post)            # 检索缩小假设集后针对性交互
    if J_g > 0: return ("ask", best_g, p_flow)
    return ("conservative", None, p_flow)         # 退化 R69/R68

    M.cit.record(mode, used_claims=used)           # 引用入账，供撤稿溯源
    M.vqa_i.submit_async(g, ans, U_epi, U_epi_after, a_hat)
    return k, lam, mode, (U_ale, U_epi_after)
```

## 3. 推导

**引理 19（带信任折扣的检索增益）** 设可用主张的有效权威 a_eff = auth·fresh·κ。若其判断与真实模态一致的概率为 a_eff，不一致时误导损失为 L_mis，检索使模态后验熵下降 ΔH，则相较不检索，期望任务误差变化 ≤ −c·Δ_min·a_eff·(1−e^{−ΔH}) + (1−a_eff)·L_mis。故检索净收益 > 0 当且仅当 a_eff > L_mis / (L_mis + c·Δ_min·(1−e^{−ΔH}))。系：**这给出 KBG 门与 TIP 采纳阈值的理论依据——低权威/低适配的主张即使「相关」也不该进入后验**；歧义越可分（Δ_min 大）、主张越权威，检索越值钱。

**引理 20（复现权威的污染上界）** 设每条独立复现被伪造的概率 ≤ δ_f，且每条计入的证据至少新增一个不相交的证据根，则一条假主张达到 reviewed 的概率 ≤ δ_f^{k_rev} + ε_root。引用卡特尔的所有成员共享同一根集合，最多贡献 1 次独立复现，故不能降低该界。系：**「权威」防的不是单次撒谎，而是「用数量伪装成独立」**。

**引理 21（先查后问的条件最优性）** 比较 J(r)=VoI(r)−c_r−ρ·r_ret 与 J(g)。若 c_r<c_g 且 r_ret≤r_int，则先检索不劣于先交互（检索可按结果决定是否仍需交互，信息不浪费）；反之若 r_ret>r_int（知识库高度可疑），先交互反而更安全。故 lookup-first 是**条件排序**而非公理——这正是 KBG 门控必须先于调度的原因。

**定理 18（PEER 严格包含 FLUID/R69）** 在 A95–A99（R69 假设 + 知识库独立复现假设）下：
(i) 当 𝒦=∅ 或 𝒦_ok=∅，p_ret 均匀，PEER 与 FLUID 逐指令相同；
(ii) 当存在 reviewed 且门控通过的主张，resolution bonus 使 λ 只在 U_ale 上收缩，期望风险 ≤ FLUID；
(iii) preprint 主张不得授予 bonus、只影响交互选择，故不引入新的放松通道。
因此 PEER 的安全侧不弱于 R69，效率侧获得「查得到就不问」的收益。

**定理 19（撤稿的无突变与单调保守）** 撤稿只在审计周期内把 auth 置零并沿引用图传播 taint；由此 U_epi 单调不减，λ 通过速率限制斜坡 ρ_λ 单调不降，且其渐近值不超过 R69 的保守值（R69 本身就是「无知识」的边界）。故撤稿不引发超出 R68/R69 包络的控制突变，提交/换装不变式（R69 定理 17）保持。

## 6. 本轮最大风险

**一句话**：PEER-RAS 的全部效率收益押在「知识库的权威分 ≈ 真实性」这一前提上——**若权威可被引用洗白/复现造假抬升，或知识在分布漂移后静默过期，检索就会用一个「自信的错误先验」替代 R69 那种「诚实的不知道」，并且这种错误会压制系统去问本该问的问题、持续自我强化**；于是 R69 的「问错」升级为「记得错」，而且更难发现、更难清除——**记得错，比不知道更危险**。

**次级风险与缓解**：
1. **知识库投毒/检索共谋** → KBG 来源门 + ALG 独立根约束 + 引理 20 上界 + ℰ_PEER 对抗训练；
2. **陈旧知识与分布漂移** → 时间衰减 + drift_test + 定义 324 再验证交互；
3. **检索确认偏差（不再提问）** → preprint 不得授予 bonus + 冲突必须转针对性复现交互 + E311/E313；
4. **provenance 膨胀/延迟** → 异步登记与索引、引用集压缩、只对 reviewed 主张做完整链校验；
5. **隐私与同意**（把人脸/行为回答长期入库）→ 主张默认去标识化、适用条件化存储、可删除权与租户隔离；
6. **版本增殖与一致性** → 追加写 + 版本引用边 + 冲突并存加仲裁，禁止静默覆盖。

## 2. 形式化定义（要点版）

**定义 310（总览与六不变式）** 继承 R69 三不变式，新增：lookup-first（条件性）、provenance-completeness（无出处即不存在）、authority-monotonicity（权威只由独立复现增长、只由撤稿下降）。

**定义 311–312（主张与知识库）** 主张 `c` 携带后验映射、适用条件、出处、时间、证据链、版本、发表状态；知识库是允许冲突并存的引用图 + 向量索引，冲突由权威仲裁而非静默平均。

**定义 313（RAG-G）** 查询 `q_ret=Q(z_t,{m_k},{ξ̄_k})`，门控后取 `𝒦_ok`，`log p_ret=Σ a_eff·log φ_c`，`p(M|o,𝒦)∝p_flow·exp(Σ a_eff·log φ_c)`；`𝒦_ok=∅` 时退化为 R69。

**定义 314–315（REV/ALG）** `auth=σ(β0+β1·n_indep+β2·div_ctx−β3·taint)`；权威增量只认独立证据根，互引团只算一根，环路比超限冻结升权；`reviewed ⇔ auth≥a_rev ∧ n_indep≥k_rev`。

**定义 316（KBG 门）** 适配 `κ≥κ_min`、新鲜 `fresh`、来源信誉 `ρ≥ρ_min`、非 OOD、非 retracted；任一不过即视同不存在。

**定义 317（RTP 撤稿）** `retract(c)` 置 auth=0，沿反向引用传播 taint，超阈值降级；依赖证书标 provisional；撤销单调保守。

**定义 318–319（TIP/协同）** `J(r)=VoI(r)−c_r−ρr_ret`，`J(g)=VoI(g)−c_g−ρr_int`；`J(r)≥max(J(g),0)` 且 `r_ret≤r_int` 时先查；检索可把冲突转成针对性复现交互，查与问成级联。

**定义 320–322（CIT/威胁/证书）** 动作/证书记录引用集并含 `citation_root_hash`；`ℰ_PEER=ℰ_FLUID×ℰ_KB`；`J_PEER` 并入权威、检索比、撤稿标记、新鲜度、kb 版本。

**定义 323–325（两级权威/时间衰减/退化链）** 仅 reviewed + 门控通过 + ECE 合格可授予 resolution bonus；preprint 只能影响「问什么」；权威随时间衰减并触发再验证；`R70 ⊇ R69 ⊇ R68`，安全逐级不让步。

```

## 4. 推导

**引理 19（带信任折扣的检索增益）** 有效权威 `a_eff=auth·fresh·κ`，检索使后验熵降 ΔH，则期望任务误差变化 ≤ `−c·Δ_min·a_eff·(1−e^{−ΔH}) + (1−a_eff)·L_mis`。故净收益 >0 当且仅当 `a_eff > L_mis/(L_mis + c·Δ_min(1−e^{−ΔH}))`。系：KBG 门与采纳阈值的理论依据——低权威/低适配即「相关」也不该进后验；越可分越权威，检索越值钱。

**引理 20（复现权威的污染上界）** 每条独立复现伪造概率 ≤ δ_f、每步至少新增一个不相交证据根时，假主张达到 reviewed 的概率 ≤ `δ_f^{k_rev}+ε_root`；引用卡特尔共享同一根集，最多算 1 次独立复现。系：权威防的是「用数量伪装独立」。

**引理 21（先查后问的条件最优性）** 若 `c_r<c_g` 且 `r_ret≤r_int`，先检索不劣于先交互；若 `r_ret>r_int`（知识库高度可疑），先交互更安全。故 lookup-first 是条件排序，KBG 门必须先于调度。

**定理 18（PEER 严格包含 FLUID/R69）** A95–A99 下：空 KB/门控全拒 ⇒ 逐指令等于 FLUID；reviewed 主张通过门控 ⇒ resolution bonus 仅在 U_ale 上收缩，期望风险 ≤ FLUID；preprint 不授予 bonus、只影响交互选择 ⇒ 不引入放松通道。安全不弱于 R69，效率获「查得到就不问」。

**定理 19（撤稿的无突变与单调保守）** 撤稿在审计周期内置零并沿引用图传播 taint；U_epi 单调不减，λ 经速率限制斜坡单调不降，渐近不超过 R69 保守值（R69 即「无知识」边界）；故无超出 R68/R69 包络的突变，提交/换装不变式保持。

## 7. 本轮最大风险

**一句话**：PEER-RAS 的全部效率收益押在「知识库的权威分 ≈ 真实性」这一前提上——**若权威可被引用洗白/复现造假抬升，或知识在分布漂移后静默过期，检索就会用一个「自信的错误先验」替代 R69 那种「诚实的不知道」，并且这种错误会压制系统去问本该问的问题、持续自我强化**；于是 R69 的「问错」升级为「记得错」，而且更难发现、更难清除——**记得错，比不知道更危险**。

**次级风险与缓解**：知识库投毒/检索共谋（KBG 来源门 + ALG 独立根 + 引理 20 + ℰ_PEER 对抗训练）；陈旧知识/漂移（时间衰减 + drift_test + 再验证交互）；检索确认偏差（preprint 不授予 bonus + 冲突转复现 + E311/E313）；provenance 膨胀/延迟（异步登记、引用集压缩、仅 reviewed 全链校验）；隐私与同意（去标识化、条件化存储、删除权、租户隔离）；版本增殖（追加写 + 冲突并存仲裁，禁止静默覆盖）。
