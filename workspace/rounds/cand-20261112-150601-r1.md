# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC IP-153~160；灵感循环第 1 轮〔新循环〕；本轮灵感：「跨任务泛化」×「创新点」）

> 第 60 轮把执行层升级为「认知驱动的场景-执行闭环」：SSM 场景语义建模、CIEC 认知意图约束、EPIR 执行感知隔离区、SERC 场景闭环、SIC 三元校验、CESC 联合决策。但把它放到「跨任务」尺度上，三个更根本的局限立刻暴露：
> 1. **泛化只是「内插」而非「跨任务」**：SSM 的 10 个场景、CIEC 的 5 个意图都是**封闭集合**，场景先验靠离线标定查表。遇到「玻璃桌面 / 冰面 / 超轻负载」或「再稳一点 / 稍微向右」这类新任务时，只能回退通用先验，前 60 轮学到的结构**一次性失效**。根因是：任务嵌入空间没有**度量**、没有**流形**、没有**距离**，系统无法回答「新任务离已知任务多远」。
> 2. **证书是「实例级」而非「任务族级」**：J_exec（第 59 轮）与 SIC（第 60 轮）只对**一次具体执行**背书。换物体、换表面，证书即作废。系统能说「这次安全」，不能说「这类任务在半径 r 内都安全」——跨任务泛化因此**没有可携带的安全语义**。
> 3. **创新点本身未被审计**：60 轮、160 条定义、191 个实验，主体是**机制叠加**；每轮都声称「ΔECE ≥ 20%」，却缺少一个可证伪的核心科学命题与机制级消融。若「创新点」不被定义成**能被实验杀死的命题**，它就退化为「又加了一个模块」。

## 0. 直觉与动机

**灵感 1（跨任务泛化 → 可迁移阻抗流形 TIM）**
直觉：不同任务不是孤立的点，而是共享同一个**低维物理交互流形**上的不同位置。桌面的「刚性 + 微振」、楼梯的「斜坡 + 抖动」、湿滑地面的「低摩擦 + 滑移风险」，本质是同一组物理自由度（刚度、阻尼、摩擦、柔顺）的不同组合。因此阻抗参数不该按任务**查表**，而应是流形上的**光滑场 Φ: e ↦ K**。跨任务泛化的本质 = 在新任务嵌入 e\* 处，用最近锚点做**带 Lipschitz 界的流形插值**：离锚点越远，可用安全裕度必须按距离**按比例打折**。

**灵感 2（跨任务泛化 → 组合任务代数 CTA）**
直觉：真正的新任务往往是**已知原语的组合**——「湿滑地面 + 轻触」= 低摩擦 ⊕ 低力限；「楼梯 + 负重」= 斜坡 ⊕ 高 K_d。若每个原语携带可组合的契约，则未见任务的阻抗先验可由原语**零样本合成**。关键洞见：组合不是免费的——原语之间存在**交互残差 R_comp**（湿滑 × 加速会放大滑移），必须显式建模并作为泛化裕度的**扣减项**；否则「组合泛化」会变成「组合幻觉」。

**灵感 3（跨任务泛化 → 可迁移执行契约 TEC + 泛化证书 GEC）**
直觉：把第 59/60 轮的「单次执行证书」升维成「任务族证书」。TEC 声明某片嵌入区域 F 内的所有任务共享一个**参数化契约**；GEC 给出**泛化半径 r\*** 与**安全概率 1−α**。核心是一条兑换关系：**泛化距离用安全裕度支付**，m\* = min_i m_i − L·r\*。若 m\* < m_min，正确行为不是「勉强执行」，而是**拒绝泛化、转探索或降级**。

**灵感 4（创新点 → 泛化安全定理 GST + 新颖度检测 TND）**
直觉：真正的创新点应给出**可证伪的定量预言**。本轮的可证伪命题是：*若阻抗场是 L-Lipschitz、锚点覆盖半径为 r、每个锚点有裕度 m，则半径 r 内任意新任务的执行失效率 ≤ α 当且仅当 L·r ≤ m*。这条「泛化-安全兑换律」把跨任务泛化从工程直觉变成**可测量、可反驳**的科学假设。TND 负责判定「新任务在多远处」，区分内插 / 外推 / 分布外三种 regime，并直接决定用 TEC、TIM+CTA 还是拒绝。

**灵感 5（创新点 → 创新点审计 NOA + 元预算 PCE+++++）**
直觉：为防止本轮又变成机制叠加，引入**创新点审计协议**：每个创新点必须写成三元组（可证伪命题 C，最强基线 B，机制消融 A），并报告**新颖度增量 Δ_novel**；同时**预注册杀死实验**（什么结果会推翻它）。配套把第 60 轮四维预算扩成五维元预算 B_meta = (B_gen, B_transfer, B_anchor, B_cog)：B_gen 管探索新任务、B_transfer 管验证迁移、B_anchor 管锚点增长与淘汰。**没有预算的泛化是失控，没有审计的创新是叙事。**

## 1. 形式化定义（增量：定义 161–168）

**定义 161（可迁移阻抗流形 TIM）** 阻抗流形 M = (E, K, Φ, d_E, A)。其中：
- **任务嵌入空间** E ⊂ R^d：任务 τ 由三部分融合嵌入 e(τ) = ψ(lang(τ), obs(τ), meta(τ))，分别为语言指令、场景观测指纹、本体/负载元信息；
- **阻抗空间** K ⊂ R^p：K = (K_p, K_d, F_max, v_max, ε_traj)；
- **阻抗场** Φ: E → P(K)，Φ(e) = N(K; μ(e), Σ(e))，把任务嵌入映到阻抗先验分布；
- **度量** d_E：由监督对比/三元组学习的任务距离（同类任务近、跨物理机制远）；
- **锚点集** A = {(e_i, m_i, π_i)}：已由实测证书背书的“已知安全任务”，m_i 为安全裕度；
- **Lipschitz 性**：∀e, e′，W₂(Φ(e), Φ(e′)) ≤ L·d_E(e, e′)；
- **迁移算子** T_k(e\*) = Σ_{i∈N_k(e\*)} w_i Φ(e_i)，w_i ∝ exp(−d_E(e\*,e_i)²/2σ²)；
- **泛化半径** r\*(e\*) = min_i d_E(e\*, e_i)（到最近锚点的距离）。

**定义 162（组合任务代数 CTA）** 原语库 P = {(p_j, C_j)}，C_j 为原语契约；合成算子 {⊕_∥（并发/叠加）, ⊕_→（时序）, ⊖（抑制）}，任务 τ = Compose(p_{j₁},…,p_{j_k}; ops)。合成规则：
- **契约合成**：C_{A⊕B} = C_A ⊗ C_B ⊕ R_comp(A,B)，R_comp 为**交互残差**；
- **前验合成**：π(K|τ) = normalize(π_{j₁} ⊛ … ⊛ π_{j_k})（先验卷积）；
- **不可组合判定**：若 R_comp > R_max 或 Pre_A ∩ Pre_B = ∅，则 NotComposable(τ)，禁止零样本合成。

**定义 163（可迁移执行契约 TEC）** TEC = (F, C_F, T, r, α)。其中 F ⊂ E 为连通的**任务族**；C_F = (K_safe^F, F_max^F, v_max^F, ε^F) 为族内共享的参数化契约；T 为迁移算子；r 为被覆盖的泛化半径。语义：∀τ ∈ F，若 d_E(e(τ), A_F) ≤ r，则 C_F 对 τ 成立的概率 ≥ 1−α。

**定义 164（泛化执行证书 GEC）** GEC(e\*) = (r\*, L_cert, m\*, α, regime)。其中：
- m\* = min_{i∈N_k(e\*)} m_i − L_cert·r\*（**泛化安全裕度**）；
- L_cert 由**保形校准（conformal）**给出：L_cert = Quantile_{1−α}( |K̂−K_true| / d_E )，在独立校准任务集上统计；
- **判定**：SAFE ⇔ m\* ≥ m_min；MARGINAL ⇔ 0 ≤ m\* < m_min（收窄执行域）；UNSAFE ⇔ m\* < 0（拒绝泛化 → 探索/降级）。

**定义 165（任务新颖度检测 TND）** 新颖度 ν(τ) = max(ν_geo, ν_sem)，其中：
- ν_geo = d_E(e\*, A)/r_max ⊕ ρ_local(e\*) ⊕ e_rec(e\*)，融合「到锚点距离 / 局部密度 / 重构误差」；
- ν_sem = 意图在语义原语空间的最近距离（如「再稳一点」是否落在已知意图锥内）；
- **regime 判定**：ν ≤ ν_in ⇒ InDist（查 TEC）；ν_in < ν ≤ ν_out ⇒ Extrapolate（TIM+CTA+GEC）；ν > ν_out ⇒ OutOfDist（拒绝迁移，走 B_gen 探索）。

**定义 166（泛化迁移闭环 TGCL）** 把 SERC 从「场景-执行」扩展为「任务-迁移-执行」闭环：
```
① Embed:    e* ← ψ(lang, obs, meta)
② Novelty:  ν ← TND(e*); regime ← classify(ν)
③ ID:       C_F ← TEC.lookup(e*); GEC ← certify(e*, C_F)
④ EXTRA:    Φ̂(e*) ← TIM.transfer(e*); GEC ← certify(e*)
            if GEC.m* < m_min: C_τ ← CTA.compose(primitives; R_comp)
            if NotComposable: regime ← OutOfDist
⑤ OOD:      Φ̂ ← π_general; 触发 B_gen 探索；否则 return SAFE_REFUSE
⑥ Compile:  K_safe ← EEIS.compile(δ_f_req, Φ̂, C_intent)   # 复用第 60 轮
⑦ Execute:  SERC 第 60 轮闭环；得到 EV-exec 与实测裕度 m_obs
⑧ Admit:    if m_obs ≥ m_min ∧ GEC valid: A ← A ∪ {(e*, m_obs, Φ̂)}
            else: A_quarantine ← A_quarantine ∪ {(e*, m_obs)}   # 隔离，不污染锚点
⑨ Recal:    L_cert ← conformal_update(residuals)               # 在线保形
⑩ Return:   (K_safe, GEC, regime, ν, A.status)
```

**定义 167（元预算 PCE+++++）** B_meta = (B_gen, B_transfer, B_anchor, B_cog)。其中：
- **B_gen**：分布外任务的探索接触次数 / 探索算力；
- **B_transfer**：验证一次迁移所需的最少实测接触数 / 校准样本数；
- **B_anchor**：锚点内存与刷新频率（容量上界）；
- **B_cog** = (B_scene, B_intent, B_ros, B_exec)（第 60 轮原有四维）。
策略：B_gen 耗尽 ⇒ 拒绝 OOD 任务、回退通用契约；B_transfer 耗尽 ⇒ 只用 ID 区 TEC、禁用外推；B_anchor 耗尽 ⇒ **覆盖感知淘汰**（优先删冗余锚点、保留高覆盖锚点）；任 B_cog 耗尽 ⇒ 第 60 轮既有降级。

**定义 168（创新点审计 NOA）** 一个创新点 I 可采纳，当且仅当它可写成四元组 I = (C, B, A, Δ_novel)，且满足：
- **C（Claim）**：带度量与阈值的可证伪命题（例：GST 的失效率 ≤ α）；
- **B（Baseline）**：第 60 轮最强方法 + 朴素迁移基线（查表/均值/微调）；
- **A（Ablation）**：留一组件消融，去掉该组件后 C 必须**显著失效**；
- **Δ_novel**：在「机制 / 保证 / 测量」三轴上相对最近先行工作的最小分离度；
- **Kill criterion**：预注册一个**能杀死 C 的实验**（如 held-out 失效率 > 2α 即判定证伪）。

### IP-161 TIM（可迁移阻抗流形）

```python
class TransferableImpedanceManifold:
    def __init__(self, embed_dim=32, sigma=0.6, k=3):
        self.A = []                 # anchors: (e, margin, phi_mean, phi_cov)
        self.d_E = LearnedMetric(embed_dim)   # contrastive / triplet
        self.sigma, self.k = sigma, k
        self.L_cert = None

    def embed(self, lang, obs, meta):
        return self.d_E.encode(lang, obs, meta)

    def transfer(self, e_star):
        if not self.A:
            return None, float('inf')
        d = [self.d_E.dist(e_star, a.e) for a in self.A]
        idx = sorted(range(len(d)), key=lambda i: d[i])[:self.k]
        w = np.exp(-np.array([d[i] for i in idx])**2 / (2*self.sigma**2))
        w = w / max(w.sum(), 1e-12)
        mu = sum(wi * self.A[i].phi_mean for wi, i in zip(w, idx))
        r_star = min(d)                       # 到最近锚点的距离
        return mu, r_star

    def certify(self, e_star, margin_min):
        mu, r_star = self.transfer(e_star)
        m_anchor = min(a.margin for a in self._nearest(e_star))
        m_star = m_anchor - self.L_cert * r_star
        return GeneralizedExecutionCertificate(r_star, self.L_cert,
                                               m_star, alpha=self.alpha)
```

### IP-162 CTA（组合任务代数）

```python
class CompositionalTaskAlgebra:
    def __init__(self, primitives, R_max=0.15):
        self.P = primitives              # {name: (contract, prior)}
        self.R_max = R_max

    def compose(self, names, ops):
        C, pi = self.P[names[0]]
        for name, op in zip(names[1:], ops):
            C_b, pi_b = self.P[name]
            R = self._interaction_residual(C, C_b, op)   # 湿滑×加速 等
            if R > self.R_max or not self._precompatible(C, C_b):
                return None, NotComposable(name, R)
            C = contract_compose(C, C_b, op).deduct(R)
            pi = prior_convolve(pi, pi_b)
        return C, pi
```

### IP-163 TEC / GEC（族级契约与泛化证书）

```python
class GeneralizedExecutionCertificate:
    def __init__(self, r_star, L_cert, m_star, alpha):
        self.r_star, self.L_cert = r_star, L_cert
        self.m_star, self.alpha = m_star, alpha

    def regime(self, m_min):
        if self.m_star >= m_min:  return 'SAFE'
        if self.m_star >= 0:      return 'MARGINAL'
        return 'UNSAFE'

def certify(e_star, anchors, alpha, margin_min, residuals):
    L_cert = np.quantile(residuals, 1 - alpha)      # 保形上界
    r_star = min(anchors.dist(e_star))
    m_anchor = min(anchors.margin_near(e_star))
    return GeneralizedExecutionCertificate(r_star, L_cert,
                                           m_anchor - L_cert * r_star, alpha)
```

### IP-164 TND（任务新颖度检测）

```python
class TaskNoveltyDetector:
    def __init__(self, A, r_max, nu_in=0.6, nu_out=1.0):
        self.A, self.r_max = A, r_max
        self.nu_in, self.nu_out = nu_in, nu_out

    def score(self, e_star, intent):
        d = min(self.A.dist(e_star))
        rho = self._local_density(e_star)          # 锚点局部密度
        rec = self._reconstruction_error(e_star)   # 自编码重构
        nu_geo = max(d / self.r_max, 1 - rho, rec)
        nu_sem = self._intent_distance(intent)
        return max(nu_geo, nu_sem)

    def classify(self, nu):
        if nu <= self.nu_in:    return 'InDist'
        if nu <= self.nu_out:   return 'Extrapolate'
        return 'OutOfDist'
```

```python
def transfer_generalization_loop(M, task, delta_f_req):
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| TIM | O(A·d) 查询 / O(A²d) 度量学习 | O(A·(d+p)) | 迁移误差 ≤ L_cert·r\*（保形 1−α） |
| CTA | O(k·|P|) 组合 | O(|P| + k) | 合成契约有效 ⇔ R_comp ≤ R_max |
| TEC/GEC | O(A) 查证 | O(1) | m\* ≥ m_min ⇒ SAFE，失效率 ≤ α |
| TND | O(A·d) | O(A) | OOD 拒绝率 ≥ 1−β，误拒 ≤ γ |
| TGCL | O(单闭环) | 复用第 60 轮 | 锚点只增“已验证”点，覆盖半径单调不增 |
| PCE+++++ | O(预算检查) | O(1) | 任一预算耗尽即触发对应安全策略 |

**泛化安全定理（GST）**：
假设 A22–A68 成立，且 **(A66)** 阻抗场 Φ 是 L-Lipschitz（W₂ 意义）；**(A67)** 保形校准集与测试任务同分布，L_cert 为 1−α 分位上界；**(A68)** 锚点证书的实测裕度为 m_i 且覆盖半径为 r\*。则对任意满足 d_E(e\*, A) ≤ r\* 的新任务 e\*：

1. **迁移误差界**：P( |K̂(e\*) − K_true(e\*)| > L_cert·r\* ) ≤ α；
2. **安全兑换律**：GEC 裕度 m\* = min_i m_i − L_cert·r\*；当 m\* ≥ m_min 时，执行失效率 ≤ α；
3. **组合守恒**：若 τ = A⊕B 且 R_comp ≤ min(m_A, m_B)，则 composite 的裕度 ≥ min(m_A, m_B) − R_comp；
4. **锚点增长单调性**：在“只接纳实测 m_obs ≥ m_min 的锚点”门控下，覆盖半径 r_max 单调不增，故泛化误差上界单调不增（直到 B_anchor 容量上限）。

*证明要点*：由 Lipschitz 性，Φ(e\*) 与最近锚点 Φ(e_i) 的 W₂ 距离 ≤ L·d_E(e\*,e_i) ≤ L·r\*；迁移算子误差可分解为「流形逼近误差 + 插值偏差 + 标签噪声」，其中后两项被保形残差分位 L_cert·r\* 统一吸收，故 1 成立。将误差上界代入锚点安全球 m_i，得 m\* 表达式，2 成立。3 由契约合成的次可加性与 R_comp 扣减直接得到。4 由接纳门控保证新锚点不降低任何已覆盖点的证书，且覆盖半径取 min 故不增。∎

**推论（泛化覆盖率-风险前沿）**：对给定风险 α，可认证覆盖率为 Cov(α) = P_{τ∼D}[ d_E(e(τ), A) ≤ m_min / L_cert ]。α 越小 ⇒ L_cert 越大 ⇒ 认证半径越小 ⇒ 覆盖率越低。这给出一个**可测量的前沿**，而非单一精度数字——它正是本轮希望被实验检验的核心。

### IP-161 TIM（可迁移阻抗流形）

```python
class TransferableImpedanceManifold:
    def __init__(self, embed_dim=32, sigma=0.6, k=3, alpha=0.05):
        self.A = []                        # (e, margin, phi_mean, phi_cov)
        self.d_E = LearnedMetric(embed_dim) # contrastive / triplet
        self.sigma, self.k, self.alpha = sigma, k, alpha
        self.L_cert = None

    def embed(self, lang, obs, meta):
        return self.d_E.encode(lang, obs, meta)

    def transfer(self, e_star):
        if not self.A:
            return None, float('inf')
        d = np.array([self.d_E.dist(e_star, a.e) for a in self.A])
        idx = np.argsort(d)[:self.k]
        w = np.exp(-d[idx]**2 / (2 * self.sigma**2))
        w = w / max(w.sum(), 1e-12)
        mu = sum(wi * self.A[i].phi_mean for wi, i in zip(w, idx))
        return mu, float(d[idx[0]])          # (迁移先验, 泛化半径 r*)

    def certify(self, e_star, m_min):
        mu, r_star = self.transfer(e_star)
        near = np.argsort([self.d_E.dist(e_star, a.e) for a in self.A])[:self.k]
        m_anchor = min(self.A[i].margin for i in near)
        m_star = m_anchor - self.L_cert * r_star
        return GeneralizedExecutionCertificate(r_star, self.L_cert, m_star, self.alpha)
```

```python
class CompositionalTaskAlgebra:
    def __init__(self, primitives, R_max=0.15):
        self.P = primitives                  # {name: (contract, prior)}
        self.R_max = R_max

    def compose(self, names, ops):
        C, pi = self.P[names[0]]
        for name, op in zip(names[1:], ops):
            C_b, pi_b = self.P[name]
            R = self._interaction_residual(C, C_b, op)
            if R > self.R_max or not self._precompatible(C, C_b):
                return None, NotComposable(name, R)
            C = contract_compose(C, C_b, op).deduct(R)
            pi = prior_convolve(pi, pi_b)
        return C, pi

        # 例：湿滑(低μ) × 加速(高v) → 滑移残差随 v/μ 增大
```

### IP-163/164 TEC / GEC（族级契约与泛化证书）

```python
class GeneralizedExecutionCertificate:
    def __init__(self, r_star, L_cert, m_star, alpha):
        self.r_star, self.L_cert = r_star, L_cert
        self.m_star, self.alpha = m_star, alpha

    def regime(self, m_min):
        if self.m_star >= m_min:  return 'SAFE'
        if self.m_star >= 0:      return 'MARGINAL'
        return 'UNSAFE'

def certify(e_star, anchors, alpha, margin_min, residuals):
    L_cert = np.quantile(residuals, 1 - alpha)     # 保形上界
    d = [anchors.dist(e_star, a.e) for a in anchors]
    i = int(np.argmin(d))
    r_star = float(d[i])
    m_star = anchors[i].margin - L_cert * r_star
    return GeneralizedExecutionCertificate(r_star, L_cert, m_star, alpha)
```

### IP-165 TND（任务新颖度检测）

```python
class TaskNoveltyDetector:
    def __init__(self, A, r_max, nu_in=0.6, nu_out=1.0):
        self.A, self.r_max = A, r_max
        self.nu_in, self.nu_out = nu_in, nu_out

    def score(self, e_star, intent):
        d = min(self.A.dist(e_star))
        rho = self._local_density(e_star)
        rec = self._reconstruction_error(e_star)
        nu_geo = max(d / self.r_max, 1 - rho, rec)
        nu_sem = self._intent_distance(intent)
        return max(nu_geo, nu_sem)

    def classify(self, nu):
        if nu <= self.nu_in:   return 'InDist'
        if nu <= self.nu_out:  return 'Extrapolate'
        return 'OutOfDist'
```

## 4. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性 |
|---|---|---|---|
| TIM | O(A·d) 查询 / O(A²d) 学习 | O(A(d+p)) | 迁移误差 ≤ L_cert·r\*（保形 1−α） |
| CTA | O(k·|P|) | O(|P|+k) | 合成有效 ⇔ R_comp ≤ R_max |
| TEC/GEC | O(A) 查证 | O(1) | m\* ≥ m_min ⇒ 失效率 ≤ α |
| TND | O(A·d) | O(A) | OOD 漏拒 ≤ 1% |
| TGCL | O(单闭环) | 复用第 60 轮 | 门控下覆盖半径单调不增 |
| PCE+++++ | O(1) | O(1) | 任一预算耗尽即降级 |

**泛化安全定理（GST）**：若 (A66) Φ 是 L-Lipschitz；(A67) 保形校准集与测试同分布、L_cert 为 1−α 上界；(A68) 锚点证书裕度 m_i、覆盖半径 r\*，则对 d_E(e\*,A) ≤ r\* 的新任务：
1. P(|K̂−K_true| > L_cert·r\*) ≤ α；
2. m\* = min_i m_i − L_cert·r\*；m\* ≥ m_min ⇒ 失效率 ≤ α；
3. 组合裕度 ≥ min(m_A,m_B) − R_comp；
4. 门控接纳下覆盖半径与泛化误差上界单调不增。

*证明要点*：Lipschitz 给出 Φ(e\*) 与最近锚点的 W₂ 距离 ≤ L·r\*；迁移误差 = 流形逼近 + 插值偏差 + 标签噪声，后两项由保形残差分位吸收（1）；把误差上界代入锚点安全球得 m\*（2）；契约合成的次可加性与 R_comp 扣减给出（3）；接纳门控保证新锚点不降低已覆盖点证书且 r_max 取 min，不增（4）。∎

**推论（风险-覆盖率前沿）**：Cov(α) = P_{τ∼D}[ d_E(e(τ),A) ≤ m_min / L_cert ]。α↓ ⇒ L_cert↑ ⇒ 认证半径↓ ⇒ 覆盖率↓。本轮要报告的正是这条**前沿曲线**，而非单一“精度”数字。

| E196 端到端 vs 第 60 轮 | 迁移时间、ΔECE、违反次数、锚点增长 | 时间 −40%；ΔECE ≥ 20%；违反不增 |
| E197 消融 + NOA | 去 TIM/CTA/GEC/门控；注入 5% 坏锚点 | 去组件后 C 显著失效；坏锚点下违反 ≤ 基线+2% |

**本轮快速原型（合成校准，非真机；仅验证 GST 的可证伪性与量级）**
设置：二维合成阻抗场 Φ(e)=1+0.6sin(1.5e₁)+0.4e₂−0.2e₁e₂（真值 L_true≈1.52），40 锚点、k=3 高斯核、m=0.45、保形 α=5%。

| 指标 | 结果 |
|---|---|
| L_cert（1−α 分位） / 中位数 | **1.42 / 0.33**（残差重尾，必须用保形分位而非最大斜率） |
| 迁移平均误差 vs 通用先验 | **0.135 vs 0.631**（−78.6%） |
| 安全率 vs 通用先验 | **96.2% vs 32.8%** |
| 认证半径 m/L_cert | **0.316** |
| α=5% 可认证覆盖率 | **47.2%** |
| 认证半径内实测违反率 | **0%** |
| 误差界成立率（目标 ≥95%） | **96.6%** |
| 锚点 4→37 的误差 | **0.434 → 0.144**（−66.8%，单调改善） |
| OOD 检测 AUROC | **0.989**（但 OOD 最小距 0.41 与 InDist p95=0.75 重叠 ⇒ 需按任务风险设阈） |
| 注入 5% 坏锚点：无门控 vs 有门控+隔离 | 违反 **6.2% vs 3.4%**（回到基线） |

> 原型只验证**机制与量级**，不替代 E192–E197 的主实验。它的意义是给出一个可被真机数据反驳的定量预言：`L_cert·r* ≤ m_min ⇔ 失效率 ≤ α`。若真机上该预言系统性失败，则 GST 被证伪，本轮创新点应被否决（这正是 NOA 的 kill criterion）。

## 6. 本轮最大风险

**一句话**：若保形校准集本身来自**有偏或已漂移的任务分布**，L_cert 会把错误的分布包装成严谨的证书——GST 数学上成立、现实中却认证了一个不存在的任务族；必须以**在线保形重校准 + 锚点隔离区 + OOD 拒绝**三重机制，让证书随实测证据收缩，而不是随叙事扩张。
