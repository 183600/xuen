# 第 55 轮（承接第 54 轮 v16+++ GroundEdge-GenSim+++；新灵感循环第 1 轮；本轮灵感：「人形机器人」×「用户共创」）

> 第 54 轮已把技能组合约束到动作空间剖面与云边动作映射。本轮换一个更靠前的问题：当技能不是工程师预定义，而是由**非专家用户共创**，执行体又是**高自由度人形机器人**时，证书体系是否还成立？核心矛盾：**H22（语义-具身鸿沟）**：用户共创在语义层可表达，但在人形整身动作流形上不可实现，组合前看似合理、执行时因平衡/接触/关节约束整体失效；**H23（证书的多数暴政）**：共创群体偏好异质，单一 `ρ_min` 证书等价于用平均用户代表所有人，会系统性牺牲少数用户。

## 0. 直觉与动机

**灵感 1（人形机器人 = 具身语法，而不是放大的机械臂）**
直觉：人形机器人的难点不是自由度更多，而是**动作之间存在整身耦合**：迈步改变支撑多边形，支撑多边形改变可施加力矩，力矩又限制手臂负载。因此用户共创不应从「画轨迹」开始，而应从**语义原语组合**开始，由系统把人形约束作为编译器的一部分。把用户可写空间记为语义语法 `L(G)`，把物理可实现集合记为整身流形 `A_h`，二者一般不重合，其距离就是**语义-具身鸿沟** `g(π)`。共创的第一职责不是满足用户，而是**尽早、可解释地暴露这个鸿沟**。

**灵感 2（共创契约 = 三方责任的可验证划分）**
直觉：一次共创不是「用户提需求、系统照做」，而是一份三方契约：用户承诺意图与偏好，云端承诺组合计划，边端承诺具身安全与实时性。契约必须能回答三个问题：**这是谁提出的？在哪个偏好集合下被验证？在哪一机型/哪一身体状态下可执行？** 缺一项，共创产物就不能进入共享库。

**灵感 3（用户不是一个人，而是一个偏好分布）**
直觉：把用户偏好建模为单纯形上的权重 `w_u`，共创群体 `U` 诱导一个**偏好多面体** `P_U = conv{w_u}`（更准确地，由成对比较约束定义的置信多面体）。证书不应在某一个 `w` 上成立，而应在整个 `P_U` 上成立：`∀w∈P_U, w·f(S) ≥ b(w)`。这把「用户满意度」从平均值改写为**最差用户的下界**，即 no-user-left-behind。

**灵感 4（溯源先于合并）**
直觉：群体共创的真正瓶颈不是生成技能，而是**合并技能**。两个用户各自「正确」的技能，合在一起可能前提矛盾、效果冲突。因此每个贡献都要有签名溯源 DAG，合并前先做作者证书校验与语义冲突检测；否则共享库会被「影子贡献」和局部最优技能污染。

**灵感 5（互塑闭环需要收敛判据）**
直觉：系统部署的技能会改变用户偏好，用户偏好又改变系统更新方向。这是一个双向动力系统。必须给出不动点与收缩条件，并度量**能动性损失**（agency loss）：技能库的可接受多样性是否被认证机制收窄。否则「用户共创」会退化为「共创剧场」。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（用户偏好画像与偏好多面体）**
设技能 `S` 的特征向量 `f(S) = (f_1,...,f_k) ∈ R^k`，其中前若干维为鲁棒性谱 `ρ_d(S)`，其余为负时延、能耗、动作自然度、社会可接受度等。用户 `u` 的偏好权重 `w_u ∈ Δ^{k-1}`。由成对比较 `S_i ≻_u S_j` 得到线性约束 `(f(S_i)-f(S_j))·w ≥ 0`，连同 `w∈Δ`、`w ≥ 0` 构成
```
P_U = { w ∈ Δ^{k-1} : A_U w ≤ c_U },
```
称 `P_U` 为**偏好多面体**；`P_U` 以至少 `1-α` 的覆盖概率包含群体真实偏好。群体效用定义为最差情形
```
U_U(S) = min_{w∈P_U} w·f(S).
```
另定义个体理性下界 `b(w)`（例如 `w·f(S) ≥ b(w)` 表示该偏好下可接受）。

**定义 122（具身动作语法与可实现流形）**
人形身体图 `B=(V_j,E_l)`，原语集合 `Π = {reach, grasp, step, lean, turn, whole_body_gesture, ...}`。语法 `G` 生成语义程序 `π ∈ L(G)`。形态可行约束
```
M = { 平衡(CoM ∈ 支撑多边形), 关节/力矩限位, 自碰撞, 接触可行性 }.
```
实现算子 `R_M : L(G) → 2^{A_h} ∪ {⊥}` 返回所有可实现整身轨迹；**语义-具身鸿沟**
```
g(π) = inf_{a ∈ R_M(π)} d(π, a),   若 R_M(π)=∅ 则 g(π)=∞.
```
若存在 `π'` 使 `g(π') ≤ ε` 且 `π'` 与 `π` 语义距离最小，称 `π` 为 **ε-可修复**，`π'` 为最近修复。

**定义 123（共创契约）**
共创契约
```
C_cc = (u, π, R_M(π), P_U, J, Prov)
```
包含四项义务：`O1` 意图忠实（`π` 忠实于用户语义选择）；`O2` 云端计划在粗动作空间 `A_c` 上可行；`O3` 边端在 `A_e` 上满足安全不变式与鲁棒性下界；`O4` 群体公平（对 `P_U` 成立）。契约以用户签名、系统证明与边端证据三元组封存。

**定义 124（偏好条件化联合证书）**
```
J_U = (J, P_U, f, b, δ_pref)
```
在定义 120 的联合证书 `J` 之上增加偏好维度。`J_U` 可接受当且仅当：
```
(1) Safe(S) = 1;                    # 硬安全不变式
(2) g(π) ≤ ε;                        # 具身可实现
(3) ∀w ∈ P_U : w·f(S) ≥ b(w);        # 群体偏好一致
(4) Prov 完整且签名可验证.            # 溯源完整
```
定义证书余量 `σ_U(S) = min_{w∈P_U} (w·f(S)-b(w))`，要求 `σ_U ≥ δ_pref`。由于目标对 `w` 线性，条件 (3) 等价于检查 `P_U` 的顶点（或解一个线性规划），这是可判定性的关键。

**定义 125（共创溯源图与作者证书）**
溯源图 `Prov = (V_p, E_p)` 是 DAG：节点为贡献（用户演示、偏好陈述、修复建议、验证证据），边为派生关系。每个节点携带作者 `id`、证据哈希与签名。技能库合并算子 `⊔`；冲突谓词 `Conf(S_i,S_j)` 表示存在 `w∈P_U` 使两者前提/效果矛盾。**作者证书**成立当且仅当每个已部署技能到其签名用户意图存在一条合法路径，且所有边证据可复放。

**定义 126（互塑算子与不动点）**
技能库 `L` 与偏好状态 `P` 的互塑动力学
```
F : (L,P) → L,   G : (L,P) → P,
(L_{t+1}, P_{t+1}) = (F(L_t,P_t), G(L_t,P_t)).
```
不动点 `(L*,P*)` 满足 `F(L*,P*)=L*`、`G(L*,P*)=P*`。若在度量 `d` 下 `Lip(F)·Lip(G) < 1`，则迭代局部收缩。**能动性损失**
```
Agency(L) = 1 - diversity(L) / diversity(L_0),
```
其中 `diversity` 为技能库在被认证前提下的语义覆盖体积。

## 2. 关键算法 伪代码

### IP-121 UPP（User Preference Profiling）

```python
def profile_user(user, pair_bank, eps=0.02, budget=40):
    P = simplex_polytope(k)
    for t in range(budget):
        (i, j) = argmax_information_gain(pair_bank, P)
        y = user.compare(i, j)
        half = (f[i] - f[j]) if y else (f[j] - f[i])
        P = P.intersect({w: dot(half, w) >= 0})
        if polytope_width(P) <= eps:
            break
    return P, coverage_bound(P, t)
```

### IP-122 EAR（Embodiment-Aware Realization）

```python
def realize(pi, body, M, eps):
    if not grammar_parse(pi, body):
        return Infeasible('syntax', explain_parse(pi))
    traj = whole_body_optimize(pi, body, M)
    if traj.feasible:
        return Realization(traj, gap=traj.residual)
    pi_near, d = nearest_repair(pi, body, M)
    if d <= eps:
        return Repaired(pi_near, gap=d,
                        explain=explain_violations(traj.violations))
    return Infeasible('embodiment', explain_violations(traj.violations))
```

### IP-123 CCV（Co-creation Contract Verification）

```python
def verify_contract(u, pi, P_U, J, b, eps, delta_pref):
    R = realize(pi, u.body, M, eps)
    if isinstance(R, Infeasible):
        return Reject('embodiment', R.explain)
    if not safe_invariant(R.traj):
        return Reject('safety', R.traj.violations)
    vertices = vertices_of(P_U)
    slack = min(dot(w, f_of(R)) - b(w) for w in vertices)
    if slack < delta_pref:
        w_bad = argmin_w(vertices, lambda w: dot(w, f_of(R)) - b(w))
        return Reject('preference', slack, w_bad)
    if not provenance_complete(J.Prov, pi):
        return Reject('provenance')
    return Accept(J_U=JointCertU(J, P_U, f_of(R), b, slack, R))
```

### IP-124 PCM（Preference-Conditioned Merge）

```python
def cohort_merge(lib, S, Prov, P_U):
    if not provenance_complete(Prov, S):
        return Quarantine('provenance', S)
    conflicts = [T for T in lib if Conf(S, T, P_U)]
    if conflicts:
        return Quarantine('conflict', S, explain_conflict(S, conflicts))
    dominated = [T for T in lib if dominates_under(S, T, P_U)]
    return (lib - set(dominated)) | {S}

def dominates_under(S, T, P_U):
    return all(dot(w, f[S]) >= dot(w, f[T])
               for w in vertices_of(P_U))
```

### IP-125 CPL（Co-creation Provenance Ledger）

```python
def append(Prov, entry, parents, signer):
    h = H(entry, sorted(parents))
    node = Node(h, entry, signer.sign(h), parents)
    Prov.add(node)
    return h

def audit(Prov, S):
    return all(verify_sig(n) and parents_ok(Prov, n)
               for n in ancestors(Prov, S))
```

### IP-126 MSL（Mutual Shaping Loop）

```python
def mutual_shaping(L, P, F, G, beta=0.5, eps=1e-3, T=50):
    hist = []
    for t in range(T):
        L2 = F(L, P)
        P2 = (1 - beta) * P + beta * G(L2, P)
        hist.append((L2, P2))
        if metric(L2, P2, L, P) < eps:
            return FixedPoint(L2, P2, agency=agency_loss(L2, L0))
        if oscillates(hist, window=4):
            return Rollback('oscillation', last_stable(hist))
        L, P = L2, P2
    return BudgetExceeded('no_fixed_point', hist[-1])
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| UPP | O(B·LP(k,\|P_U\|)) | O(\|P_U\|) | 约束保持凸性、覆盖界可算 |
| EAR | O(T_opt·\|M\|) | O(\|A_h\|) | 整身约束完备、修复语义保真 |
| CCV | O(\|V_{P_U}\|·k + T_opt) | O(\|V_{P_U}\|) | LP 顶点等价、安全不变式 sound |
| PCM | O(\|L\|·\|V_{P_U}\|·k) | O(\|L\|) | 冲突谓词 sound、Pareto 保持 |
| CPL | O(\|Prov\|) | O(\|Prov\|) | 签名链完整、证据可复放 |
| MSL | O(T·(\|L\|+\|P\|)) | O(T) | 收缩条件、振荡检测 |

**正确性定理（Cohort-Robust Co-creation Soundness）**
假设第 54 轮 (A26)–(A28) 成立，并新增：**(A29)** 真实群体偏好 `{w_u}` 以概率 `≥1-α` 落在 `P_U` 内；**(A30)** `Safe` 与 `R_M` 相对于真实执行误差为 `β_E`，且 `g(π)≤ε`；**(A31)** 溯源完整且合并无冲突的概率 `≥1-β_P`；**(A32)** 互塑迭代处于收缩域或已回滚到最近稳定点。则对每个用户 `u∈U`，以概率 `≥1-α-β_E-β_P`：
```
P(success_u) ≥ 1 - max_{w∈P_U} Σ_d w_d (1-ρ_d(S)) - β_E,
U_u(S) = w_u·f(S) ≥ b(w_u).
```
证明要点：由 (A29)，`w_u∈P_U`；由定义 124 条件 (3)，`min_{w∈P_U} w·f(S) ≥ b(w)`，故个体 `w_u·f(S) ≥ b(w_u)`；失败概率由 `ρ` 的加权失败质量与具身/执行误差 `β_E` 上界控制；溯源性由 (A31) 排除未验证贡献。**关键**：证书不是对平均用户成立，而是对偏好多面体一致成立。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 偏好启发负担导致用户敷衍 | 高 | 主动成对选择 + 少量默认锚点 + 可跳过 |
| 偏好多面体维数高、顶点爆炸 | 中 | 低维特征投影 + LP 对偶直接求 `σ_U` |
| 整身运动优化慢，无法实时共创 | 高 | 分层缓存 + 热启动 + 降级为可行性筛选 |
| 溯源被游戏或密钥泄露 | 高 | 硬件签名 + 证据哈希 + 抽查复放 |
| 互塑导致操纵/共创剧场 | 高 | 能动性预算 + 反事实推荐 + 外部审计 |
| 人形安全不变式不完备 | 极高 | 硬约束优先 + 仿真红队 + 物理急停兜底 |

## 6. 本轮最大风险

**一句话**：把人形具身约束与群体偏好写进共创契约，能把「用户共创」从主观满意度提升为可验证的 cohort-robust 证书，但其 soundness **同时依赖整身安全约束的完备性、偏好多面体的覆盖概率、以及互塑闭环的收缩性**；一旦安全不变式漏项或 `P_U` 严重欠采样，系统会以「已认证」的名义把语义上悦人、具身上危险或只服务多数人的技能规模化部署，故必须以**硬安全优先 + 覆盖校准 + 能动性预算**三重护栏，宁可拒绝共创，也不把「认证通过」当作具身安全的替代品。

def verify_contract(u, pi, P_U, J, b, eps, delta_pref):
    R = realize(pi, u.body, M, eps)

        return Reject('preference', slack, w_bad)       # 违反 O4
    if not audit(J.Prov, pi):
        return Reject('provenance')                     # 违反溯源
    return Accept(J_U=JointCertU(
        J=J, P_U=P_U, f=f_of(R), b=b,
        slack=slack, realization=R))

### IP-124 PCM：群体 Pareto 合并

```python
def cohort_merge(lib, S, Prov, P_U):
    if not audit(Prov, S):
        return Quarantine('provenance', S)
    conflicts = [T for T in lib if Conf(S, T, P_U)]
    if conflicts:
        return Quarantine('conflict', S,
                          explain_conflict(S, conflicts, P_U))
    dominated = {T for T in lib
                 if dominates_under(S, T, P_U)
                 and not dominates_under(T, S, P_U)}
    return (lib - dominated) | {S}

def dominates_under(S, T, P_U):
    # 群体 Pareto：对全部可信偏好不劣，且至少一个严格优
    le = all(dot(w, f[S]) >= dot(w, f[T]) for w in vertices_of(P_U))
    lt = any(dot(w, f[S]) >  dot(w, f[T]) for w in vertices_of(P_U))
    return le and lt
```

### IP-126 MSL：互塑闭环

```python
def mutual_shaping(L, P, F, G, beta=0.5, eps=1e-3, T=50, L0=None):
    L0 = L0 or L
    hist = []
    for t in range(T):
        L2 = F(L, P)                       # 部署/退役/合并
        P2 = (1 - beta) * P + beta * G(L2, P)   # 用户偏好滞后更新
        hist.append((L2, P2))
        if metric(L2, P2, L, P) < eps:
            return FixedPoint(L2, P2,
                              agency=1 - diversity(L2) / diversity(L0))
        if oscillates(hist, window=4):
            return Rollback('oscillation', last_stable(hist))
        L, P = L2, P2
    return BudgetExceeded('no_fixed_point', hist[-1])
```

## 3. 推导：顶点等价、公平下界与失败概率

**推导 1（LP 顶点等价）**
条件 (3) 为 `∀w∈P_U: w·f(S) ≥ b(w)`。若 `b(w)` 线性（如 `b(w)=w·b_0`），则 `w·(f(S)-b_0) ≥ 0` 在凸多面体上成立，当且仅当在所有顶点成立；一般 `b` 若为凹函数，则 `w·f(S)-b(w)` 为凸函数，其在凸紧集上的最小值可能在内部，需直接解凸规划。故实现中优先用 LP/凸规划而非盲目顶点枚举。

**推导 2（最差用户与 Pareto 保持）**
若 `w_u∈P_U` 且 `min_{w∈P_U} w·f(S) ≥ b(w)` 成立，则 `w_u·f(S) ≥ b(w_u)`，即每个用户都不低于其个体理性下界。合并时移除被群体 Pareto 支配的旧技能不会降低任何 `w∈P_U` 的效用，因此 `cohort_merge` 在 `P_U` 上单调不降。

**推导 3（失败概率上界）**
将失败质量按偏好权重聚合：`P(fail) ≤ max_{w∈P_U} Σ_d w_d (1-ρ_d(S)) + β_E`。若 `b(w)` 对每个 `w_d>0` 强制 `ρ_d ≥ ρ_min`，则退化为第 54 轮的逐维界 `Σ_d(1-ρ_min(d))`，保持向后兼容。

**正确性定理（Cohort-Robust Co-creation Soundness）**
在 (A26)–(A28) 与 (A29)–(A32) 下，对每个 `u∈U`，以概率 `≥1-α-β_E-β_P`：
```
P(success_u) ≥ 1 - max_{w∈P_U} Σ_d w_d(1-ρ_d(S)) - β_E,
w_u·f(S) ≥ b(w_u).
```
证：`w_u∈P_U`（A29）；定义 124 条件 (3) 给出个体理性；失败概率由加权失败质量与执行误差控制；溯源（A31）排除未审计贡献；互塑收缩（A32）保证部署态不漂出证书域。

## 6. 本轮最大风险

**一句话**：把人形具身约束与群体偏好写进共创契约，能把「用户共创」从主观满意度提升为可验证的 cohort-robust 证书，但其 soundness **同时依赖整身安全约束的完备性、偏好多面体的覆盖概率、以及互塑闭环的收缩性**；一旦安全不变式漏项或 `P_U` 严重欠采样，系统会以「已认证」的名义把语义上悦人、具身上危险或只服务多数人的技能规模化部署，故必须以**硬安全优先 + 覆盖校准 + 能动性预算**三重护栏，宁可拒绝共创，也不把「认证通过」当作具身安全的替代品。
