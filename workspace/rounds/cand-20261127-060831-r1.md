### 第 2 轮灵感驱动研究记录（承接 IP-447 / Exec_v25）

**灵感词**：迁移学习、长期记忆

**直觉与动机**：
现有 SRC-USC（v25）把安全证书做成「一次性、从零验证」的证明：每遇到新机器人、新任务、新环境，SMC/RMC/MCC/USMC 都要重新采集校准集、重跑 conformal 校准与动力学残差检查。这在长期部署中造成三重浪费：(i) 同一类结构/语义/协同经验被反复重新证明；(ii) 少样本新任务因校准集不足而无法达到 1-α，导致 Exec_v25 近乎空集；(iii) 失败见证（witness）随会话结束而丢失，系统无法从历史失效中学习。

受「迁移学习」启发：证书本身应可作为可迁移对象——源域证书在满足可证分布差异界 Γ_trans 时，可经加权 conformal / 差异修正迁移到目标域，且迁移后的覆盖率下界仍可计算；当差异过大时应主动「拒迁」而非硬迁（负迁移防护）。受「长期记忆」启发：应建立持久化的「证书记忆」LTCM，把 (上下文键 κ, 证书 C, 有效期, 衰减率, 失败见证 W, 溯源证明) 作为一等公民存储、检索、整合与遗忘；记忆不是绕过验证的后门，而是把「已验证的证明」缓存为可快速复核的证明对象。

核心洞见：**迁移是把证书从源域「搬运」到目标域并支付可计算的覆盖税 Γ_trans；长期记忆是把证书从过去「搬运」到现在并支付可计算的新鲜度税 λ·Δt；两者共同把安全验证从「每次重证」变为「带税复用」，而单调退化链保证税一旦付不起就退回从零验证（Exec_v25）。**

**形式化目标**：
1. 定义迁移证书（TC / IP-448）：源域证书 C_s 在差异界 Γ_trans 下迁移为目标域 C_t，满足 ℙ_{𝒟_t}(Y∈C_t(X)) ≥ 1 - α_s - Γ_trans；仅当 α_s + Γ_trans ≤ α_max 且通过负迁移留出检验时准入。
2. 定义长期记忆证书（LMC / IP-449）：记忆条目 m=(κ,C,[t^-,t^+],λ,W,v)，检索返回的证书必须通过「上下文包含 + 新鲜度 + 溯源完整 + 高风险佐证」四重复核；遗忘只删除、不新增证明，故记忆保持 soundness 单调。
3. 定义迁移-记忆统一准入门（TM-USC / IP-450）：Exec_v26 = Exec_v25 ∩ Fil_trans ∩ Fil_mem ⊆ Exec_v25；记忆命中只替代「重算上下文证书」，不替代「计划级义务复核」，迁移失败/记忆过期一律回退 v25 从零验证。
4. 证明迁移覆盖守恒引理、记忆健全性引理与 v26 单调退化链。
5. 给出「带税复用」的摊销样本复杂度：记忆命中 O(1) 复核，迁移 O(n_t) 校准，从零 O(n_calib)，且安全预算不因复用而扩大。

**关键风险预告**：迁移差异界若低估真实分布漂移，或记忆中的陈旧证书被过度信任，系统会在「证明仍有效」的错觉下复用一个已越界的证书。

## 0. 新增核心模块（在 IP-447 / Exec_v25 基础上扩展）

| 编号 | 名称 | 类型 | 关键改进（相对 SRC-USC v25） |
|---|---|---|---|
| IP-448 | Transferable Certificate Adapter (TCA) | 迁移证书 | 源域证书在可证差异界 Γ_trans 下迁移到目标域；加权 conformal 支付覆盖税 α_eff = α_s + Γ_trans；负迁移留出检验；Γ_trans 超预算即「拒迁」回退从零校准 |
| IP-449 | Long-Term Certificate Memory (LTCM) | 长期记忆证书 | 持久化条目 (κ,C,[t^-,t^+],λ,W,v)；ANN 检索 + 上下文包含 + 新鲜度衰减 + Merkle 溯源 + 高风险 k-of-n 佐证；整合只加强不削弱，失败见证有保留配额 |
| IP-450 | Transfer-Memory Unified Certificate (TM-USC) | 迁移-记忆统一准入门 | 记忆→迁移→新鲜校准三级回退；只复用「上下文级证书」，计划级义务（结构/力控/语义几何/重构/协同）每次重算；Exec_v26 = Exec_v25 ∩ Fil_trans ∩ Fil_mem ⊆ Exec_v25 |

**定位澄清**：迁移与记忆不是放宽安全约束，而是降低「证明 Exec_v25 成员资格」的样本与计算成本。Exec_v25 取语义定义——存在合法证书使十项谓词成立；TCA/LTCM 只是用源域数据或历史数据更快地构造该证书。因此 v26 不会把任何不安全计划拉进执行集，只会把「需要重证」变为「带税复用」。

```python
# ============================================================
# IP-448 Transferable Certificate Adapter (TCA) — 迁移证书适配器
# ============================================================
@dataclass
class TransferableCertificateAdapter:
    """把源域上下文证书在可证差异界内迁移到目标域，并显式支付覆盖税"""
    source_cert: 'ContextCertificate'
    source_domain: 'DomainDescriptor'       # (P_s, T_s, n_s, δ_s)
    target_domain: 'DomainDescriptor'       # (P_t, T_t, n_t, δ_t)
    discrepancy: 'DiscrepancyEstimator'     # TV/MMD/HΔH 上界估计器
    density_ratio: 'DensityRatioEstimator'  # w(x) ≈ dP_t/dP_s
    alpha_max: float = 0.05
    delta_trans: float = 0.03               # 允许的最大覆盖税
    guard_margin: float = 0.01
    min_ess: float = 30.0

    def transfer_gap_bound(self) -> float:
        """Γ_trans = TV 上界 + 两侧有限样本项 + 密度比估计误差（全部取上界）"""
        d_tv = self.discrepancy.upper_bound_tv(
            self.source_domain, self.target_domain)
        n_s = max(self.source_domain.n_calib, 1)
        n_t = max(self.target_domain.n_unlabeled, 1)
        delta = min(self.source_domain.delta, self.target_domain.delta)
        fs = math.sqrt(math.log(2.0 / delta) / (2.0 * n_s))
        ft = math.sqrt(math.log(2.0 / delta) / (2.0 * n_t))
        err_w = self.density_ratio.estimation_error()
        return min(1.0, d_tv + fs + ft + err_w)

    def transport(self, target_calib: Optional[Tensor]) -> Optional['ContextCertificate']:
        """返回目标域证书；覆盖税超预算、有效样本不足或密度比病态时返回 None（拒迁）"""
        gamma = self.transfer_gap_bound()
        if gamma > self.delta_trans:
            return None
        alpha_eff = self.source_cert.alpha + gamma
        if alpha_eff > self.alpha_max:
            return None

        w, ess = None, float(self.source_domain.n_calib)
        if target_calib is not None:
            w = self.density_ratio.weights(target_calib)
            if (w <= 0).any() or not torch.isfinite(w).all():
                return None
            ess = (w.sum() ** 2 / (w ** 2).sum()).item()
            if ess < self.min_ess:              # 密度比退化，迁移不可信
                return None
            alpha_eff += math.sqrt(
                math.log(2.0 / self.target_domain.delta) / (2.0 * ess))

        if alpha_eff > self.alpha_max:
            return None

        cert = self.source_cert.reweight(w, alpha=alpha_eff)
        cert.provenance = self._provenance(gamma, w)
        cert.transfer_meta = {
            'gamma': gamma, 'alpha_eff': alpha_eff, 'ess': ess,
            'source_task': self.source_domain.task_id,
            'target_task': self.target_domain.task_id,
        }
        return cert

    def verify_negative_transfer_guard(self, transferred: 'ContextCertificate',
                                       target_val: Tensor,
                                       scratch: Optional['ContextCertificate'] = None) -> bool:
        """留出集上迁移风险不得显著劣于从零基线；无基线时用源域经验风险"""
        r_t = empirical_risk(transferred, target_val)
        r_s = (empirical_risk(scratch, target_val)
               if scratch is not None else self.source_cert.empirical_risk())
        return r_t <= r_s + self.guard_margin

    def verify_all(self, target_calib: Optional[Tensor], target_val: Tensor,
                   scratch: Optional['ContextCertificate'] = None
                   ) -> Optional['ContextCertificate']:
        cert = self.transport(target_calib)
        if cert is None:
            return None
        if not self.verify_negative_transfer_guard(cert, target_val, scratch):
            return None
        return cert


# ============================================================
# IP-449 Long-Term Certificate Memory (LTCM) — 长期证书记忆
# ============================================================
@dataclass
class CertificateMemoryEntry:
    """只缓存上下文级证书（校准器/结构参数界/先验），绝不缓存计划级义务"""
    key: 'ContextKey'
    cert: 'ContextCertificate'
    t_from: float
    t_until: float
    half_life: float
    witnesses: list['FailureWitness']
    residuals: Tensor
    provenance: 'MerkleProof'
    version: int
    risk_class: str = 'normal'          # normal / high
    corroborations: int = 1

    def confidence(self, now: float) -> float:
        return 0.5 ** ((now - self.t_from) / max(self.half_life, 1e-9))


@dataclass
class LongTermCertificateMemory:
    entries: dict['ContextKey', list[CertificateMemoryEntry]]
    index: 'ANNIndex'                   # HNSW / IVF-PQ
    theta_mem: float = 0.6
    max_entries: int = 100000
    min_witness_quota: int = 64         # 稀有失败见证的永久保留下限
    corroboration_k: int = 2            # 高风险条目写入/使用所需佐证数
    fresh_budget: int = 100             # 每 N 次准入强制一次从零验证

    # ---------- 读：检索 + 四重复核 ----------
    def retrieve(self, key: 'ContextKey', now: float
                 ) -> Optional[CertificateMemoryEntry]:
        best = None
        for e in self.index.search(key.embedding, k=8):
            if now > e.t_until:                         # (i) 有效期
                continue
            if e.confidence(now) < self.theta_mem:      # (ii) 新鲜度
                continue
            if not context_contains(e.key, key):        # (iii) 上下文包含
                continue
            if not self._verify_provenance(e):          # (iv) 溯源完整
                continue
            if e.risk_class == 'high' and e.corroborations < self.corroboration_k:
                continue
            if best is None or e.confidence(now) > best.confidence(now):
                best = e
        return best

    def verify_soundness(self, key: 'ContextKey', now: float,
                         cert_checker: 'ContextCertificateChecker') -> bool:
        e = self.retrieve(key, now)
        if e is None:
            return False
        return cert_checker.revalidate_context(e.cert, key)

    # ---------- 写：近邻合并 + 配额 ----------
    def write(self, entry: CertificateMemoryEntry) -> None:
        merged = self._merge_near_duplicates(entry)
        self.entries.setdefault(merged.key, []).append(merged)
        self.index.add(merged.key.embedding, merged)
        self._enforce_quota()

    # ---------- 整合：只加强、不削弱 ----------
    def consolidate(self, now: float) -> None:
        for key in list(self.entries.keys()):
            self.entries[key] = self._merge_entries(self.entries[key])
        self._forget(now)              # 只删除低置信非关键条目
        self._retain_witnesses()       # 失败见证按严重度保底

    def _merge_entries(self, entries: list[CertificateMemoryEntry]
                       ) -> list[CertificateMemoryEntry]:
        if len(entries) <= 1:
            return entries
        merged, used = [], [False] * len(entries)
        for i, e in enumerate(entries):
            if used[i]:
                continue
            cluster = [e]
            used[i] = True
            for j in range(i + 1, len(entries)):
                if used[j]:
                    continue
                if (context_contains(e.key, entries[j].key) or
                        context_contains(entries[j].key, e.key)):
                    cluster.append(entries[j])
                    used[j] = True
            if len(cluster) == 1:
                merged.append(e)
            else:
                # 关键：有效域取交、alpha 取最大、见证取并集 —— 合并只会更保守
                merged.append(CertificateMemoryEntry(
                    key=_intersect_keys([c.key for c in cluster]),
                    cert=_conservative_join([c.cert for c in cluster]),
                    t_from=max(c.t_from for c in cluster),
                    t_until=min(c.t_until for c in cluster),
                    half_life=min(c.half_life for c in cluster),
                    witnesses=[w for c in cluster for w in c.witnesses],
                    residuals=torch.cat([c.residuals for c in cluster]),
                    provenance=_merge_provenance([c.provenance for c in cluster]),
                    version=max(c.version for c in cluster),
                    risk_class=('high' if any(c.risk_class == 'high'
                                              for c in cluster) else 'normal'),
                    corroborations=sum(c.corroborations for c in cluster),
                ))
        return merged

    def _forget(self, now: float) -> None:
        for key in list(self.entries.keys()):
            kept = []
            for e in self.entries[key]:
                critical = any(w.severity >= 'high' for w in e.witnesses)
                if critical or e.confidence(now) >= self.theta_mem:
                    kept.append(e)
                else:
                    self.index.remove(e.key.embedding, e)
            self.entries[key] = kept

    def _retain_witnesses(self) -> None:
        # 按严重度排序，保证高严重度见证总量不低于 min_witness_quota
        all_w = [(e, w) for es in self.entries.values() for e in es
                 for w in e.witnesses]
        all_w.sort(key=lambda x: _severity_rank(x[1].severity), reverse=True)
        if len(all_w) < self.min_witness_quota:
            self.witness_archive.extend(w for _, w in all_w)

    def _enforce_quota(self) -> None:
        if len(self.entries) <= self.max_entries:
            return
        flat = [(e, k) for k, es in self.entries.items() for e in es]
        flat.sort(key=lambda x: x[0].confidence(self._now()))
        for e, k in flat[:len(self.entries) - self.max_entries]:
            if any(w.severity >= 'high' for w in e.witnesses):
                continue
            self.entries[k].remove(e)
            self.index.remove(e.key.embedding, e)


# ============================================================
# IP-450 Transfer-Memory Unified Certificate (TM-USC)
# ============================================================
@dataclass
class TransferMemoryUnifiedCertificate:
    src_usc: 'SemanticReconfigCoordUnifiedCertificate'
    tca: TransferableCertificateAdapter
    ltcm: LongTermCertificateMemory
    fresh_calibrator: 'ConformalCalibrator'
    _since_fresh: int = 0

    def admits(self, plan: 'MultiRobotPlan', ctx: 'ContextDescriptor',
               now: float, sensor_data: dict,
               gt_entities: Optional[list] = None,
               queries: Optional[list[str]] = None,
               retrieved: Optional[list[list]] = None) -> bool:
        # 1) 上下文级证书：记忆 → 迁移 → 新鲜校准（三级回退）
        ctx_cert = None
        entry = self.ltcm.retrieve(ctx.key, now)
        if entry is not None and self.ltcm.verify_soundness(
                ctx.key, now, self.src_usc.smc):
            ctx_cert = entry.cert

        if ctx_cert is None:
            ctx_cert = self.tca.verify_all(
                ctx.target_calib, ctx.target_val,
                scratch=self._scratch_if_available(ctx))

        if ctx_cert is None:
            ctx_cert = self.fresh_calibrator.calibrate(
                ctx.target_calib, alpha=self.src_usc.smc.alpha)
            if ctx_cert is None:
                return False

        # 2) 计划级义务永远重算：结构/力控/轻量化/语义几何/重构/协同
        #    记忆与迁移只替换上下文证书，不替换任何计划相关谓词
        ok = self.src_usc.admits(
            plan, sensor_data, gt_entities, queries, retrieved,
            context_cert=ctx_cert)

        # 3) 仅通过后写入记忆；并执行新鲜度预算，防止长期「自信漂移」
        if ok:
            self.ltcm.write(CertificateMemoryEntry(
                key=ctx.key, cert=ctx_cert,
                t_from=now, t_until=now + ctx.horizon,
                half_life=ctx.half_life,
                witnesses=ctx.witnesses, residuals=ctx.residuals,
                provenance=ctx_cert.provenance, version=ctx.version,
                risk_class=plan.risk_class))
            self._since_fresh += 1
            if self._since_fresh >= self.ltcm.fresh_budget:
                self.ltcm.invalidate_all()     # 下一轮强制从零验证
                self._since_fresh = 0
        return ok

    def _scratch_if_available(self, ctx: 'ContextDescriptor'):
        if ctx.scratch_budget_ok:
            return self.fresh_calibrator.calibrate(
                ctx.target_calib, alpha=self.src_usc.smc.alpha)
        return None

# 端到端集成：在 v25 多机流水线中插入 TM-USC
# ============================================================
class TransferMemoryPerceptionComplianceEnergyPipeline:
    def __init__(self, config: dict):
        self.v25 = config['v25_pipeline']       # 复用 SRC-USC 流水线
        self.tm_usc = TransferMemoryUnifiedCertificate(
            src_usc=self.v25.src_usc,
            tca=TransferableCertificateAdapter(
                source_cert=config['source_cert'],
                source_domain=config['source_domain'],
                target_domain=config['target_domain'],
                discrepancy=config['discrepancy'],
                density_ratio=config['density_ratio'],
                alpha_max=config['alpha_max'],
                delta_trans=config['delta_trans'],
            ),
            ltcm=LongTermCertificateMemory(
                entries={}, index=config['ann_index'],
                theta_mem=config['theta_mem'],
                min_witness_quota=config['min_witness_quota'],
                corroboration_k=config['corroboration_k'],

            ),

        self.ipam.register_module("tca", ["IP-448"],

        self.ipam.register_module("ltcm", ["IP-449"],
            ["certificate_memory", "provenance", "witness_retention",

        self.ipam.register_module("tm_usc", ["IP-450"],
            ["three_level_fallback", "context_only_cache",

            'admitted': admitted,
            'memory_hit': self.tm_usc.ltcm.retrieve(ctx.key, now) is not None,
            'transfer_gap': self.tm_usc.tca.transfer_gap_bound(),
            'ctx_cert_source': self.tm_usc._last_source,
        }
```

## 2. 复杂度分析（增量）

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 |
|---|---|---|---|
| TCA 差异界估计（MMD/RFF） | O((n_s+n_t)·r·d) | O(r·d) | r≤512 随机特征, d≤256 |
| TCA 加权 conformal | O(n_t log n_t + n_t d) | O(n_t) 权重 | n_t≤500 |
| TCA 证书重加权 | O(n_s·d) | O(n_s) 校准残差 | n_s≤2000 |
| LTCM ANN 检索 | O(log |M| · d) 期望 | O(|M|·d) 索引 | |M|≤10⁵, d≤256 |
| LTCM 上下文复核 | O(d + |W|) | O(|W|) 见证 | |W|≤64 |
| LTCM 近邻合并 | O(k·d + |W|) | O(k) 邻域 | k≤8 |
| LTCM 整合/遗忘 | O(|M| log |M|) | O(|M|) | 触发频率≤1/100 步 |
| 计划级义务重算 | 同 v25（不增加） | 同 v25 | 每步必做 |
| 端到端摊销准入 | p_m·O(log|M|d) + (1-p_m)[p_t·O(n_t log n_t) + (1-p_t)·O(n_calib)] | 同 v25 + O(|M|d) | 平稳环境 p_m→1 |

**实时性保证**：记忆命中路径只增加一次 ANN 查询与一次上下文复核，P99 目标 <5ms；迁移路径只在目标域校准集上做加权 conformal，P99 目标 <30ms；新鲜校准路径即 v25。计划级义务（含 MCC O(N²T)）始终重算，故最坏情况不劣于 v25。

## 3. 正确性论证（增量）

### 引理 13（迁移覆盖守恒）
**陈述**：设源证书 C_s 在 𝒟_s 上满足 ℙ_{𝒟_s}(Y∈C_s(X)) ≥ 1-α_s，且 Γ_trans 是 TV(P_s,P_t)、两侧有限样本项与密度比估计误差之和的上界。则迁移证书 C_t 在 𝒟_t 上满足
ℙ_{𝒟_t}(Y∈C_t(X)) ≥ 1 - α_s - Γ_trans。
若 α_s + Γ_trans ≤ α_max，则 C_t 是 α_max 合法证书。

**证明**：TV 定义给出对任意可测集 A，|P_t(A)-P_s(A)| ≤ TV(P_s,P_t)。取 A={Y∈C_s(X)}，得 P_t(A) ≥ P_s(A)-TV ≥ 1-α_s-TV。加权 conformal 用 w 重加权后把 TV 项收紧为密度比估计误差 ε_w；两侧有限样本项由 Hoeffding/DKW 给出。由三角不等式合并 d_tv+fs+ft+ε_w 即 Γ_trans。负迁移 guard 是经验必要条件，不参与覆盖下界证明，只用于过滤「界虽小但经验风险反而变差」的迁移。∎

### 引理 14（记忆健全性与遗忘单调性）
**陈述**：若 LTCM 的 `retrieve` 强制 (i) 有效期、(ii) 新鲜度、(iii) 上下文包含、(iv) 溯源完整、(v) 高风险 k-of-n 佐证，且 `consolidate` 只执行「删除低置信非关键条目」或「合并为有效期交集、α 取最大、见证并集」的操作，则对任意时刻 t 与上下文 κ，记忆检索得到的证书在 κ 上的有效性不弱于写入时的有效性；记忆演化不会新增任何未经验证的证书。

**证明**：删除操作只能缩小可检索集合。合并操作中有效期取交集使有效域单调缩小，α 取最大使覆盖承诺单调不增，见证取并集使负记忆单调增，三者均为保守变换。检索条件 (iii) 防止跨域误用，(iv)(v) 防止伪造与单点投毒。因此记忆只可能「少用/更保守地用」，不可能「多用/更激进地用」。∎

### 引理 15（v26 单调退化链）
**陈述**：Exec_v26 ⊆ Exec_v25^sem，且任意失效路径回退到 v25 从零验证。

**证明**：TM-USC 的唯一准入出口是 `src_usc.admits(..., context_cert=ctx_cert)`。ctx_cert 来自记忆、迁移、新鲜校准三者之一，均需满足 α_eff ≤ α_max 与 provenance/guard 约束。计划级义务（USMC 结构/力控/轻量化、SMC 几何、RMC 动力学、MCC 协同）每次重算，不复用任何计划相关缓存。故通过 TM-USC 的计划必满足 v25 的十项语义谓词，即 π ∈ Exec_v25^sem。若记忆过期/迁移税超预算/负迁移 guard 失败/新鲜校准失败，则 ctx_cert 为 None 或直接拒绝，不会绕过 v25。∎

### 定理（TM-USC 的带税复用安全-样本效率定理）
**陈述**：对任意计划 π，`TM-USC.admits(π)=True` 当且仅当 π 满足 v25 十项谓词，且其上下文证书由以下之一建立：(a) 新鲜校准；(b) 通过引理 14 复核的记忆条目；(c) 通过引理 13 覆盖税与负迁移 guard 的迁移证书。三者覆盖率均 ≥ 1-α_max，provenance 完整。进一步，若记忆命中率为 p_m、迁移成功率为 p_t，则每次准入的期望目标域标注数为
(1-p_m)[(1-p_t)·n_calib + p_t·n_t] + O(1)，
在平稳环境下 p_m→1 时退化为 O(1)。

**证明**：必要性由 `admits` 的分支结构直接得到；充分性由引理 13/14 的覆盖率与健全性，加上计划级义务重算得到。样本复杂度由三级回退的期望展开得到，O(1) 项为记忆复核与索引查询。新鲜度预算 `fresh_budget` 保证 p_m 不会退化为 1 的「永久自证」，每 N 次至少一次从零校准，从而给漂移检测提供锚点。∎

## 6. 本轮最大风险（最终确认）
