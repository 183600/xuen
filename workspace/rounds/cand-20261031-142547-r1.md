# 第 13 轮（新灵感循环第 1 轮）· CO-ADAPT：把人为干扰从「异常」升级为「带信用分配的社会反馈」

> 检索/复核日期：**2026-10-31（UTC）**。赛事身份不变：宇树 **UniBot 世界挑战赛**（unibot.unitree.com），G1 + Dex1，32 项桌面任务，通才单模型赛道，选手自部署 + 官方远程真机 API。本轮按用户指令记为「情感计算主题循环第 1 轮」，研究线承接第 10 轮 **FACT-VLA**、第 11 轮 **GEO-RESIDUAL**、第 12 轮 **CHUNK-SERVO**。三个灵感词是「情感计算」「人机协作」「桌面操作」。本轮不推倒 CHUNK-SERVO 的「30 步规划 + 5 步伺服」，而是补它把人类干预当成「异常」时丢掉的三样东西：**时机、对象、意图**。

## 0. 先给结论：20% 的人为干扰不是 64 次随机噪声，而是 64 次「社会评价」

第 12 轮把最后 3 厘米从开环变成 5 步闭环，方向是对的。但它在 human 轴上仍然沿用了一个隐含假设：**人类干预是一个需要被检测、然后被恢复的二值异常**。YIELD、CO-HASM、TENDER 已经把「检测→让行→恢复」做得相当细，但它们回答的都是同一个问题：**人插手之后怎么办**。

本轮问一个更上游的问题：

> **人为什么插手？他评价的是我哪一步？我能不能让他不必插手？**

三个判断：

1. **人为干扰占 20%（每任务 2/10，共 64/320 trials），是唯一没有官方训练数据的泛化轴。** 位置、干扰物、背景、未见物品都能在 33k 干净演示里找到近似；人手进入工作区、移动物体、撤销步骤，在演示里几乎没有。这个结构性缺口没有被第 12 轮的伺服解决，因为伺服解决的是「我的手偏了」，不是「人为什么推我」。
2. **人类干预不是随机噪声，而是一次带对象和时机的评价。** 人移动杯子，可能是纠正抓取点；人拿走插头，可能是接管；人把物体推近，可能是协助；人反复阻挡，可能是测试。把这四类都压成「edit_score 超阈值」，就会用同一种让行动作回应四种不同意图——该接受协助时回滚，该让行时重规划，该等待时松爪。
3. **情感计算在桌面操作里的正确定义，不是读表情，而是「评价—归因—调节」闭环。** 人类评价机器人的行为，机器人把评价归因到自己的某个决策，再调节下一次行为。眼下的 API 没有音频、没有面部特写、没有生理信号，但有四路 RGB、有 30Hz 本体、有可枚举的评分步骤——这恰好够做**行为层的情感计算**：从人手轨迹、物体位移、干预时机推断评价，而不是从脸上推断情绪。

所以本轮的押注是 **CO-ADAPT**（Co-Adaptive POMDP for Tabletop Co-presence）：

> 在 CHUNK-SERVO 的 5 步执行块上，维护一个五类人类意图的贝叶斯信念；用「干预时刻 × 干预对象 × 动作历史」做信用分配，定位被评价的那个决策；用人-物-夹爪三方接触的视觉柔顺处理物理耦合；用关键决策点的「意图前导」动作降低非必要干预。VLA 仍是唯一学习模型，新增的全部是贝叶斯信念更新、确定性响应原语和规则状态机。

一句话：**第 12 轮把最后 3 厘米闭环了；本轮把「人」从外生扰动变成可归因、可适应的反馈信号。**

三个可验证创新点：

1. **SA-Belief（Social Appraisal Belief）**：把人类干预从二值事件变成五类意图的后验信念（协助/纠正/接管/测试/路过），用任务阶段、人手轨迹、物体位移更新；用代价敏感决策替代固定让行。
2. **CTA（Credit-Timed Attribution）**：干预发生后，用「干预对象与历史动作目标的因果相关度 × 时间核」定位被纠正的决策索引 `k*`，只回滚到 `k*`，而不是整题重来；这是把 HRI 里的「纠正时机」问题做成一个可计算的信用分配。
3. **VAC + Intent Preamble（三方接触视觉柔顺 + 意图前导）**：人手接触机器人正在操作的物体时，从手-物相对运动推断「接管/协助/拿走」，输出松爪、保持或让行；在接近、换向、抓取前插入 0.2–0.4s 的可读动作，让人类能预测机器人意图。

三个灵感词怎么落到方案里：

| 灵感词 | 落到哪里 | 不做什么 |
|---|---|---|
| **情感计算** | 把「评价（appraisal）—归因（attribution）—调节（regulation）」做成 SA-Belief + CTA；内部状态用可观测行为估计，不读表情、不做语音情绪 | 不做人脸/语音情感识别；不引入第二个人类行为大模型；不声称能读心 |
| **人机协作** | 五类意图对应五组响应（接受协助/纠正目标/让行/保持等待/继续）；三方接触时机器人主动松爪或降增益 | 不做对话/确认（API 无输出通道）；不把「协作」做成新任务；不假设人类一定配合 |
| **桌面操作** | 工作空间小、人手频繁进入、任务步骤可枚举，正好支持「按对象归因」和「按步骤回滚」；用头双目看手，用腕部看接触 | 不做全身人机共处；不做多人场景；不做需要力/触觉的三方力控 |

本轮明确不声称的三件事：

- **不声称能识别人类情绪。** 我们说的一直是「意图/评价」，不是「愤怒/焦虑/满意」。
- **不声称人类评测者一定受机器人动作影响。** 「可读动作降低非必要干预」是假设 H1，必须用真人用户研究或单任务通道验证；不成立时，方案退化为 CTA + VAC 的「响应质量」收益。
- **不声称五类意图是完备的。** 用 `UNKNOWN` 类兜底，后验低于阈值时回退到第 12 轮的编辑检测与让行。

## 2. 诊断：为什么「让行」还不够

把一次人类干预拆成四个信息层：

```text
t_int - Δ: 人手开始朝工作区移动      ← 前兆（可预测）
t_int:     人手接触/移动物体          ← 事件（可检测）
t_int + δ: 人完成动作、离开            ← 结果（可观测）
t_int + 1: 机器人才决定怎么恢复        ← 响应（当前方案）
```

第 12 轮与已有让行方案的信息损失：

| 方案 | 检测 | 意图 | 对象 | 时机/归因 | 物理耦合 | 减少干预 |
|---|---|---|---|---|---|---|
| CHUNK-SERVO 编辑检测 | edit_score | 无（二值） | 无 | 无 | 无 | 无 |
| YIELD | 人手/运动 | 5 类恢复意图（测试时推断） | 粗 | 无 | 无 | 无 |
| CO-HASM | 人区状态机 | 脚本先验 | 步骤级 | 最小回滚到最早失效步骤 | 无 | 无 |
| TENDER | 残差分诊 | 5 类（调整/撤销/接管/路过/观察） | 粗 | 无 | 无力柔顺（环境接触） | 可读让行（局部） |
| **CO-ADAPT** | 前兆 + 事件 | 5 类 + UNKNOWN，贝叶斯信念 | 对象级 | **credit assignment 到决策 k\*** | **人-物-夹爪三方** | **意图前导 + 可读动作** |

四个具体缺口：

1. **时机损失**：检测到人手才让，已经晚了 200–300ms（一个 chunk + 检测窗口）。人手进入工作区的速度通常是 0.3–1.0 m/s；300ms 就是 9–30cm。对 5cm 的杯口/网口，这已经是碰撞距离。
2. **对象损失**：只知道「场景变了」，不知道人动的是「目标杯」还是「旁边的干扰杯」。回滚粒度只能到评分步骤，不能到「哪一个抓取决策」。
3. **意图损失**：把「协助」当「干扰」会回滚掉别人刚帮你摆好的物体；把「纠正」当「接管」会僵持；把「测试」当「碰撞」会过度让行，浪费时间。
4. **物理耦合损失**：人手扶着杯子时，夹爪继续按原轨迹走会对抗；没有力传感器，唯一安全的策略是「看到手-物接触就松/降增益/让」，而不是「用力顶住」。

## 3. 方法：CO-ADAPT

### 3.1 总架构

在 CHUNK-SERVO 的每端口 `PolicyService` 里加一个 **Social Appraisal Loop**，与 VLA 规划、视觉伺服并列，不阻塞主循环：

```text
obs_t (4×RGB + EE/gripper/lower_body)
  │
  ├─→ VLA plan (30 steps, async) ──────────────┐
  │                                            │
  ├─→ Human observer (head stereo)             │
  │     hand 3D track, object displacement     │
  │     contact flag, TTC                      │
  │          │                                 │
  │          ▼                                 │
  │     SA-Belief b_t(g) ──→ response policy ──┤
  │          │                    │            │
  │          │                    ├─ CONTINUE / SLOW / YIELD / HOLD
  │          │                    ├─ RELEASE / ROLLBACK / REPLAN
  │          │                    └─ INTENT_PREAMBLE
  │          ▼                                 │
  │     CTA: k* = argmax corr(obj, action_k)·κ(t_int−t_k)
  │          │                                 │
  │          ▼                                 │
  │     update goal / rollback to k*           │
  │                                            ▼
  └──────────────────────────────→ servo 5-step chunk → API
```

四条不变量：

- VLA 仍是唯一学习模型；人手检测用确定性几何（运动 + 双目深度 + 肤色/轮廓作为弱先验），不用第二个网络。
- 所有响应都必须返回形状合法的 5 步 chunk；任何异常回退到 CHUNK-SERVO 的保守动作。
- 人类不可观测时（手不在视野、遮挡、头相机没看到），SA-Belief 退化为均匀先验，只保留 edit_score 触发。
- 响应延迟预算 ≤30ms/次（CPU），不挤占伺服与 VLA。

### 3.2 SA-Belief：五类社会评价的贝叶斯信念

隐藏变量：

```text
g ∈ G = { ASSIST, CORRECT, TAKE_OVER, TEST, PASS_BY, UNKNOWN }
```

| 意图 | 行为签名（视觉可观测） | 期望响应 |
|---|---|---|
| ASSIST | 手把物体推向机器人/摆正/递近；物体朝机器人可达域移动 | 接受新状态，继续，不惩罚 |
| CORRECT | 手移动目标物体到新位置/姿态；或把已放置物体挪开 | 更新 `T_base_target`，从当前步骤重试 |
| TAKE_OVER | 手持续握住物体并把它带离工作区；夹爪仍闭合 | 松爪、退回安全位、等待 |
| TEST | 手反复阻挡/快速进出，但不真正改变物体状态 | 保持安全、减速、不追手 |
| PASS_BY | 手穿过工作区但不接触任务物体 | 减速让行，随后恢复 |
| UNKNOWN | 证据不足/遮挡/与以上都不符 | 回退第 12 轮编辑检测 |

信念更新（每 chunk 一次）：

```math
b_{t+1}(g) \;\propto\; b_t(g)\; P(o_{t+1}\mid g, a_t)\; P(g\mid s_t)
```

- `P(g|s_t)`：任务阶段先验。例如「接近目标」阶段更可能是 CORRECT/PASS_BY；「已抓取」阶段更可能是 TAKE_OVER/ASSIST。
- `P(o|g,a)`：手工设计的行为似然，用四个特征：
  1. 手到任务物体的最小距离 `d_ho`；
  2. 手到机器人 EE 的最小距离 `d_hr`；
  3. 物体位移方向与「机器人可达域」的夹角 `θ_assist`；
  4. 手-物接触持续时间 `τ_c`。
- 不做端到端学习；所有参数用离线合成干预 + 少量自采真人数据校准（校准表，不是模型）。

决策：在响应集 `R` 上做一步贝叶斯风险最小化：

```math
r^* = \arg\min_{r\in R} \sum_{g\in G} b_t(g)\, C(r,g)
```

代价矩阵 `C(r,g)` 由「任务损失 + 安全损失 + 时间损失」组成，见产物区 §6。

### 3.3 前兆预测：在接触之前让

从头部双目跟踪人手 3D 位置 `h_t` 与速度 `v_t`；用等速 + 不确定性膨胀预测未来 `H_p=0.5s` 的占据：

```math
\hat h_{t+\tau} = h_t + v_t\tau,\qquad
\sigma_h(\tau) = \sigma_0 + \alpha\tau
```

计算人手预测管与机器人未来扫掠体积 `R_{t:t+H_p}` 的最小距离 `d_min`，以及到冲突的时间 `TTC`：

```math
P_{\mathrm{int}} = \sigma\!\left(w_0 + \frac{w_1}{TTC+\epsilon} + w_2(1-d_{\min}/d_0) + w_3(1-\pi_t)\right)
```

- `P_int > θ_yield`：提前减速/让行；
- `P_int > θ_preamble` 且尚未接触：插入意图前导（朝向目标、夹爪预成型、短暂停顿），让人类看懂机器人要去哪；
- `TTC < 0.2s`：进入 VAC 保护模式（降速、松爪待命）。

注意：`P_int` 是「人类将进入冲突区」的概率，不是「人类有敌意」的概率。我们不做情绪归因。

### 3.4 CTA：干预的信用分配

人类干预是对机器人**过去某个决策**的延迟评价。设动作历史窗口：

```text
H_t = {(a_k, z_k, t_k)}_{k=t-K}^{t}
```

其中 `z_k` 是该动作作用的物体/目标（由动作 + 场景图得到），`t_k` 是时刻。干预事件在 `t_int` 发生，干预对象为 `z_int`（被移动/被拿走的物体）。

信用分配：

```math
k^* = \arg\max_{k\in H_t} \underbrace{\mathrm{corr}(z_k, z_{\mathrm{int}})}_{\text{对象相关度}}\cdot
\underbrace{\exp\!\left(-\frac{(t_{\mathrm{int}}-t_k)^2}{2\sigma_t^2}\right)}_{\text{时间核}}\cdot
\underbrace{\rho_k}_{\text{动作可纠正性}}
```

- `corr(z_k,z_int)`：同一物体=1，同一受器/同一评分步骤=0.5，其他=0。
- 时间核：人类通常纠正最近 0.5–3s 的决策；`σ_t` 由离线数据校准。
- `ρ_k`：若该动作已经不可撤销（物体已放下、夹爪已松开），降低权重。

得到 `k*` 后的四种处理：

1. **目标被移动**：更新 `T_base_target`，从 `k*` 对应的步骤重试，不回滚更早的成功步骤。
2. **步骤被撤销**：回滚完成栈到 `k*` 之前，重做。
3. **物体被拿走**：标记 `z_int` 丢失，请求 VLA 重规划替代方案；若无替代，fail gracefully。
4. **协助**：接受新状态，更新目标，继续；不触发回滚。

这就是「最小因果回滚」：回滚粒度不是整题，也不是固定评分步骤，而是**被评价的那个决策**。

### 3.5 VAC：人-物-夹爪三方接触的视觉柔顺

API 没有力/触觉，但有三样东西：腕部 RGB、头双目、夹爪开合命令。用它们做**视觉柔顺**：

```text
if 人手与机器人正在操作的物体接触:
    if 手-物相对速度指向「拿走」:
        RELEASE（松爪，退回安全位）
    elif 手-物接触但物体稳定:
        HOLD_SOFT（保持夹持，降低伺服增益与速度）
    elif 手把物体推向机器人:
        ACCEPT_ASSIST（更新目标，继续）
else:
    normal servo
```

关键：**机器人不主动对抗**。检测到接触就降低法向增益/速度，宁可掉一次抓取，也不要把物体夹坏或撞手。这是「安全优先于成功率」的局部取舍，但在 human 轴上是正确的：一次碰撞可能让人更不信任、后续干预更多。

### 3.6 Intent Preamble：可读性作为干预的「上游税率」

在三个关键决策点插入 0.2–0.4s 的可读动作：

1. **接近目标前 5–8cm**：夹爪朝向目标、减速、短暂停顿；
2. **换向/换臂前**：先抬升 1–2cm，再转向；
3. **抓取前**：夹爪预成型（张开到目标宽度）并保持 0.2s。

这不是「表演情绪」，而是**让人类能预测机器人意图**，从而减少「以为它要撞/要拿错」的非必要干预。它是假设 H1 的操作化：如果人类评测者会看机器人动作，前导应该降低干预率；如果评测是固定脚本，前导无效但不至于伤任务（代价是每次 0.2–0.4s，最多 2–3 次）。

### 3.7 响应策略：从「让行」到「按意图响应」

| 后验最大类 | 默认响应 | 备选 | 安全约束 |
|---|---|---|---|
| ASSIST | ACCEPT_ASSIST | CONTINUE | 确认物体稳定后再加速 |
| CORRECT | UPDATE_GOAL + RETRY(k*) | REPLAN | 先停，避免追着手走 |
| TAKE_OVER | RELEASE + HOLD | YIELD | 松爪前确认物体有支撑 |
| TEST | SLOW + HOLD | YIELD | 不追手、不对抗 |
| PASS_BY | SLOW | YIELD | 人手离开后恢复原 chunk |
| UNKNOWN | 第 12 轮 edit recovery | YIELD | 保守优先 |

## 4. 与第 12 轮的关系：保留、升级、剪枝

**保留**：

- 30 步 VLA 规划 + 5 步伺服执行（CHUNK-SERVO）；

### 1.2 观测与派生特征

原始观测（A 级，沿用第 12 轮）：

```text
images:  cam_left_high, cam_right_high, cam_left_wrist, cam_right_wrist  (480×640 RGB)
state:   left/right arm joint [7], left/right EE pose [6] (xyz+rpy, base),
         left/right gripper [1], lower_body [15], language str
```

派生特征（确定性几何，无学习权重）：

1. **人手 3D 轨迹**：头部双目视差 + 运动分割 + 肤色/轮廓弱先验；输出 `h_t` 与置信度 `c_h`。
2. **物体位移**：头双目 ROI 的稀疏光流 / 局部点云配准；输出 `Δz_t` 与置信度 `c_z`。
3. **手-物接触**：腕部 RGB 中手部掩码与物体掩码的 IoU + 头双目距离阈值；输出 `contact ∈ {0,1}` 与 `c_c`。
4. **手-机器人距离**：`d_hr = ||h_t - ee_t||`。
5. **机器人扫掠体积**：由当前 5 步 chunk 的 EE 轨迹 + 夹爪包围盒膨胀得到。
6. **任务阶段**：第 11/12 轮的相位估计 + 评分步骤谓词；输出 `s_t` 与 `π_t`。

所有派生特征都带置信度；置信度低于阈值时，对应似然退化为均匀分布。

### 1.3 人类在环 POMDP

完整系统是一个部分可观测随机博弈：

```math
\mathcal{M} = (\mathcal{X}, \mathcal{A}, \mathcal{O}, T, Z, R, \gamma),
\quad x_t = (q_t, \xi_t, g_t, h_t)
```

- `q_t`：机器人状态（关节、EE、夹爪）；
- `ξ_t`：桌面物体/受器状态；
- `g_t`：人类意图；
- `h_t`：人手状态。

观测 `o_t` 由 §1.2 给出；动作 `a_t` 是 5 步 EE chunk；奖励：

```math
R_t = \Delta \pi_t - \lambda_c \,\mathbb{1}[g_t \neq \mathrm{ASSIST}]\cdot c_{\mathrm{int}}
      - \lambda_s \,\mathbb{1}[\mathrm{collision}] - \lambda_t \,\Delta t
```

其中 `c_int` 是干预造成的任务代价（回滚/重试/时间），`λ` 是权重。目标是：

```math
\max_{\pi}\; \mathbb{E}\left[\sum_t \gamma^t R_t\right].
```

完整求解不可行（连续状态、未知人类策略、在线预算 <30ms）。本报告做三个近似：

1. **状态分解**：机器人/物体状态由 CHUNK-SERVO 的几何模块给出，视为条件独立于 `g`；只对 `g` 维护信念。
2. **信念近似**：离散贝叶斯，`|G|=6`。
3. **响应近似**：一步（myopic）贝叶斯风险最小化，不做长时域规划。

这三个近似对应 §11 的假设 A1–A5。

## 2. SA-Belief：社会评价信念

### 2.1 意图定义与行为签名

| 意图 | 定义 | 可观测签名 | 机器人期望响应 |
|---|---|---|---|
| `ASSIST` | 人帮助机器人完成任务（推近、摆正、递物、扶稳） | 物体朝机器人可达域移动；手-物接触后物体更接近目标位姿；人手不遮挡夹爪路径 | 接受新状态，继续，不回滚 |
| `CORRECT` | 人纠正机器人的目标/轨迹（移动目标、挪开已放物体、转正受器） | 目标物体被移动/旋转；干预对象与当前 `z_t` 一致；人离开后物体停在新位姿 | 更新 `T_base_target`，从 `k*` 重试 |
| `TAKE_OVER` | 人接管当前子任务（拿走物体、自己操作） | 手持续握持物体并带离工作区；夹爪仍闭合；物体速度与人手一致 | 松爪、退回安全位、等待 |
| `TEST` | 人测试机器人的安全性/鲁棒性（反复阻挡、快速进出） | 手反复进出但不改变物体状态；接触时间短；物体位移小 | 减速、保持安全、不追手 |
| `PASS_BY` | 人只是路过共享工作区 | 手轨迹穿过但不接触任务物体；`d_ho` 始终大于阈值 | 减速让行，随后恢复 |
| `UNKNOWN` | 证据不足/遮挡/与以上都不符 | 置信度低或特征冲突 | 回退第 12 轮 edit recovery |

**重要边界**：这些是「意图/评价」，不是「情绪」。我们不推断人是否生气、焦虑或满意；我们只推断「这次干预想达到什么」。

### 2.2 先验

阶段先验 `P(g|s_t)` 用一个小表表示（每任务一列，离线标定，非学习模型）：

```text
例：接近目标阶段   ASSIST .10  CORRECT .30  TAKE_OVER .10  TEST .10  PASS_BY .35  UNKNOWN .05
    已抓取/搬运    ASSIST .15  CORRECT .25  TAKE_OVER .30  TEST .10  PASS_BY .15  UNKNOWN .05
    放置/插入      ASSIST .20  CORRECT .35  TAKE_OVER .15  TEST .10  PASS_BY .15  UNKNOWN .05
```

先验来自：任务语义（是否易被协助/纠正）+ 官方 `human_*_note` 的类型先验（B 级）+ 少量自采真人数据。没有真人数据时用均匀先验 + 任务阶段修正。

### 2.3 似然

用四个手工特征 `φ(o) = (d_ho, d_hr, θ_assist, τ_c)`，每类意图一个参数化的似然：

```math
P(o\mid g,a) = \prod_{j=1}^{4} p_j(\phi_j(o)\mid g)\,\cdot\,\mathbb{1}[\text{feature valid}]
```

具体形式（全部是可解释的指数族/高斯/伯努利，参数离线校准）：

| 特征 | `ASSIST` | `CORRECT` | `TAKE_OVER` | `TEST` | `PASS_BY` |
|---|---|---|---|---|---|
| `d_ho`（手-物距离） | 小 | 小 | 很小 | 中 | 大 |
| `d_hr`（手-EE 距离） | 中 | 中 | 小 | 小 | 大 |
| `θ_assist`（物体位移朝机器人可达域） | 小（朝向） | 中 | 大 | — | — |
| `τ_c`（接触时长） | 中 | 短-中 | 长 | 短且反复 | ≈0 |

实现上用**对数线性模型**而非高斯混合，避免参数爆炸：

```math
\log P(o\mid g,a) = \sum_{j=1}^{4} w_{g,j}\,\phi_j(o) + b_g
```

权重 `w` 由离线数据用最大似然/网格搜索校准；这是统计表，不是神经网络。

### 2.4 信念更新

每 chunk 边界更新一次：

```math
b_{t+1}(g) =
\frac{b_t(g)\,P(o_{t+1}\mid g,a_t)\,P(g\mid s_{t+1})}
{\sum_{g'\in G} b_t(g')\,P(o_{t+1}\mid g',a_t)\,P(g'\mid s_{t+1})}
```

数值稳定：log-sum-exp；每步做 Laplace 平滑 `+ε`，避免零概率锁死。

**证据门控**：若 `c_h < c_min`（人手检测置信度低）或 `c_z < c_min`（物体位移不可靠），则本次不更新，保持 `b_t`，并把 `UNKNOWN` 的质量抬高：

```math
b_{t+1} \leftarrow (1-\eta)\,b_t + \eta\,\delta_{\mathrm{UNKNOWN}},\quad \eta = 0.5
```

### 2.5 决策

```math
r^* = \arg\min_{r\in R}\;\sum_{g\in G} b_t(g)\,C(r,g)
```

代价矩阵见 §8。若 `max_g b_t(g) < θ_b`（默认 0.55），强制 `r = HOLD` 或回退第 12 轮 edit recovery；不赌低置信度的意图。

## 3. 前兆预测：在接触之前让

### 3.1 人手运动模型

头部双目给出人手 3D 轨迹 `h_{1:t}`。用等速模型 + 不确定性膨胀：

```math
\hat h_{t+\tau} = h_t + v_t\tau,\qquad
\Sigma_h(\tau) = \Sigma_0 + \tau^2\,\Sigma_v
```

`Σ_0` 是检测噪声，`Σ_v` 是速度估计协方差。预测时域 `H_p = 0.5s`（约 15 帧）。

### 3.2 冲突度量

机器人未来扫掠体积 `R_{t:t+H_p}` 由当前 chunk 的 5 步 EE 轨迹 + 夹爪包围盒膨胀得到。人手预测管 `Ĥ_{t+\tau}` 是中心 `ĥ`、协方差 `Σ_h` 的椭球。定义：

```math
d_{\min} = \min_{\tau\in[0,H_p]} \mathrm{dist}\!\left(\hat H_{t+\tau},\, R_{t+\tau}\right)
```

```math
TTC = \min\{\tau : \hat H_{t+\tau}\cap R_{t+\tau}\neq\emptyset\}
```

若 `d_min > d_0`（默认 15cm）或人手速度远离工作区，则 `P_int ≈ 0`，不触发。

### 3.3 干预风险

```math
P_{\mathrm{int}} = \operatorname{sig}\!\left(
w_0 + \frac{w_1}{TTC+\epsilon}
+ w_2\left(1-\frac{d_{\min}}{d_0}\right)
+ w_3(1-\pi_t)
+ w_4\,\mathbb{1}[\text{gripper closed}]
\right)
```

- `w` 用离线合成/自采数据校准；默认先验 `w_1 > 0` 最大，因为 TTC 是最直接的前兆。
- `gripper closed` 增加风险：人更可能担心机器人拿着东西撞。
- `P_int` 是「人类将进入冲突区」的概率，不是「人类有敌意」的概率。

### 3.4 三档触发

```text
P_int < θ_1 (0.35):            正常执行
θ_1 ≤ P_int < θ_2 (0.65):      意图前导 + 减速 30%
P_int ≥ θ_2 或 TTC < 0.25s:    让行/保持 + VAC 保护模式
```

触发后进入「社会模式」，至少持续 `T_hold = 0.3s`，避免抖动式切换。

## 4. CTA：干预的信用分配

### 4.1 问题

人类在 `t_int` 时刻干预，但他评价的可能是 `t_int - 0.3s` 的抓取点，也可能是 `t_int - 3s` 的目标选择。若一律回滚「上一步」或「最早失效步骤」，就会：

- 回滚太近：没改到真正的错误决策，人再次干预；
- 回滚太远：破坏已经成功的前置步骤，浪费时间。

### 4.2 动作历史

维护长度 `K`（默认 30 个 chunk ≈5s）的环形缓冲：

```text
H_t = {(a_k, z_k, t_k, ρ_k)}_{k=t-K}^{t}
```

- `z_k`：该动作作用的物体/受器（由动作目标 + 场景图匹配）；
- `ρ_k ∈ [0,1]`：可纠正性。若 `k` 之后物体已被放置/夹爪已松开/已进入不可逆接触，`ρ_k` 降低。

### 4.3 归因分数

干预对象 `z_int`（被移动/被拿走/被接触的物体）由物体位移检测给出。定义：

```math
\mathrm{score}(k) =
\underbrace{\mathrm{corr}(z_k,z_{\mathrm{int}})}_{\in\{0,0.5,1\}}
\cdot
\underbrace{\exp\!\left(-\frac{(t_{\mathrm{int}}-t_k)^2}{2\sigma_t^2}\right)}_{\text{时间核}}
\cdot
\underbrace{\rho_k}_{\text{可纠正性}}
```

```math
k^* = \arg\max_{k\in H_t}\mathrm{score}(k)
```

- `corr`：同一物体=1；同一受器或同一评分步骤=0.5；其他=0。
- `σ_t`：离线校准；先验 1.0s（人通常纠正最近 1–2 个决策）。
- 若最大分数低于 `θ_k`（默认 0.2），不归因，回退到评分步骤级回滚。

### 4.4 四种处理

| 场景 | 判定 | 动作 |
|---|---|---|
| 目标被移动 | `z_int` 是当前目标/受器，物体停在新位姿 | 更新 `T_base_target`；从 `k*` 对应步骤重试；不回滚更早成功步骤 |
| 步骤被撤销 | 已放置物体被挪回/拉链被拉开/瓶盖被拧回 | 完成栈回滚到 `k*` 之前；重做该步骤 |
| 物体被拿走 | `z_int` 离开工作区且未返回 | 标记丢失；请求 VLA 重规划替代方案；无替代则 fail gracefully |
| 协助 | `g=ASSIST` 且物体朝有利位姿移动 | 接受新状态；更新目标；**不回滚** |

「最小因果回滚」的形式化：

```math
\mathrm{rollback}(k^*) = \{s \mid s \text{ 依赖 } k^* \text{ 之后的动作}\}
```

只重做受影响的后继步骤；若步骤依赖图是 DAG，且 `k*` 之前的状态未被干预改变，则之前步骤保持有效（命题 3）。

### 4.5 与 CHUNK-SERVO 的接口

CTA 不直接改 VLA 权重，只改三样东西：

1. `goal`：`T_base_target` / 目标图；
2. `plan_idx`：从哪个 plan 索引重试；
3. `completion_stack`：哪些评分步骤已完成。

这三样都在第 11/12 轮的运行时状态里，不需要新模型。

## 5. VAC：人-物-夹爪三方视觉柔顺

### 5.1 为什么需要

API 没有力/触觉。当人手接触机器人正在操作的物体时，继续按原轨迹走会：

- 对抗人手，可能夹坏物体；
- 让人误以为机器人要抢，增加后续干预；
- 在透明/易碎物体上造成不可逆损坏。

### 5.2 接触检测

用三个信号做与门/或门：

```text
contact_score = w1 * IoU(hand_mask, object_mask)
              + w2 * proximity(head_stereo hand, object)
              + w3 * co-motion(hand_velocity, object_velocity)
```

- `IoU` 来自腕部 RGB 的手/物掩码（运动 + 颜色 + 深度）；
- `proximity` 来自头双目 3D 距离；
- `co-motion` 是手与物体速度的相关性。
- `contact_score > θ_c` 触发 VAC；置信度低时不触发（避免误松爪）。

### 5.3 三种柔顺模式

```text
if contact_score > θ_c:
    if 手-物相对速度指向「离开工作区」 and gripper closed:
        RELEASE_SOFT: 松爪 + 手臂后退 1–2cm + 速度上限 0.1 m/s
    elif 物体稳定 and 手在扶稳:
        HOLD_SOFT: 保持夹持；伺服增益 ×0.3；速度 ×0.5
    elif 手把物体推向机器人:
        ACCEPT_ASSIST: 保持夹持；更新目标；速度 ×0.7
    else:
        HOLD_SOFT
else:
    normal servo
```

### 5.4 安全约束

- 松爪前检查支撑：若物体下方无支撑面/桌面，优先 `HOLD_SOFT` 而不是 `RELEASE`，避免掉落。
- 后退方向必须避开人手：用头双目估计人手占据，选择切向后退。
- 所有模式都受速度/加速度上限约束；VAC 不增加任何力，只降低增益/速度。
- 最大 VAC 持续 `T_vac_max = 3s`；超时后回退到安全 hold 并请求重规划。

### 5.5 与「无力柔顺」的区别

TENDER 的无力柔顺处理的是机器人-环境接触（顶住就退）。VAC 处理的是人-机器人-物体三方接触，目标不是「完成接触」，而是「不与人对抗、不损坏物体」。两者可以叠加：环境接触用导纳，人-物接触用 VAC，优先级 VAC > 环境导纳。

## 6. 意图前导：可读性作为干预的上游税率

### 6.1 动机

人类干预有时不是因为机器人做错了，而是因为**看不懂机器人要做什么**：以为它要撞、要拿错、要重复。如果机器人在关键决策点给出可读的动作线索，人类可能选择观察而不是干预。这是 legibility 文献的核心假设，也是本轮的 H1。

### 6.2 三个前导原语

| 原语 | 触发 | 动作 | 时长 |
|---|---|---|---|
| `PRE_APPROACH` | 距离目标 5–8cm | 夹爪朝向目标；减速 30%；停顿 0.2s | 0.2–0.3s |
| `PRE_TURN` | 换向/换臂前 | 先抬升 1–2cm；再转向 | 0.2–0.4s |
| `PRE_GRASP` | 抓取前 | 夹爪预成型到目标宽度；保持 0.2s | 0.2s |

### 6.3 约束

- 每个任务最多 3 次前导；累计 ≤1.0s。
- 只在 `P_int > θ_1` 或人类在视野内时启用；无人时关闭（省时间）。
- 前导不改变 VLA 的语义意图，只改速度/朝向/夹爪时序；结束时平滑回到原 chunk。
- 前导是假设 H1 的开关；G12 不通过就关闭，不影响 CTA/VAC。

## 7. 响应策略与代价矩阵

### 7.1 响应集

```text
R = {CONTINUE, SLOW, YIELD, HOLD, RELEASE, ROLLBACK, REPLAN, ABORT}
```

| 响应 | 含义 | 实现 |
|---|---|---|
| `CONTINUE` | 继续当前 chunk | 原样 |
| `SLOW` | 减速 | 时间缩放 0.5–0.7 |
| `YIELD` | 退回安全位/让出通道 | 预计算的安全构型 + 切向后退 |
| `HOLD` | 原地保持 | 速度 0，夹爪保持 |
| `RELEASE` | 松爪 | 夹爪张开 + 后退 |
| `ROLLBACK` | 回滚到 `k*` | 重放完成栈 + 重规划 |
| `REPLAN` | 请求 VLA 新 plan | 异步，旧 plan 继续安全执行 |
| `ABORT` | 放弃当前任务 | 安全 hold，等待 reset |

### 7.2 代价矩阵

代价是「任务损失 + 安全损失 + 时间损失」：

```math
C(r,g) = \alpha\, L_{\mathrm{task}}(r,g)
       + \beta\, L_{\mathrm{safe}}(r,g)
       + \gamma\, L_{\mathrm{time}}(r)
```

先验矩阵（行=响应，列=意图；数值为相对代价，待离线校准）：

| | ASSIST | CORRECT | TAKE_OVER | TEST | PASS_BY | UNKNOWN |
|---|---:|---:|---:|---:|---:|---:|
| CONTINUE | 0.1 | 3.0 | 3.0 | 2.0 | 0.5 | 2.0 |
| SLOW | 0.3 | 2.0 | 2.0 | 0.5 | 0.2 | 1.0 |
| YIELD | 1.5 | 1.0 | 0.5 | 0.3 | 0.3 | 0.5 |
| HOLD | 1.0 | 0.8 | 0.5 | 0.4 | 0.6 | 0.4 |
| RELEASE | 3.0 | 2.0 | 0.5 | 1.0 | 3.0 | 1.0 |
| ROLLBACK | 3.0 | 0.5 | 3.0 | 2.0 | 3.0 | 2.0 |
| REPLAN | 2.0 | 0.8 | 2.0 | 2.0 | 2.0 | 1.5 |
| ABORT | 5.0 | 5.0 | 5.0 | 4.0 | 5.0 | 4.0 |

设计原则：

- `TAKE_OVER` 下 `RELEASE`/`YIELD` 最便宜；
- `CORRECT` 下 `ROLLBACK`/`REPLAN` 最便宜；
- `ASSIST` 下 `CONTINUE` 最便宜；
- `TEST` 下 `SLOW`/`YIELD` 最便宜；
- `PASS_BY` 下 `SLOW` 最便宜；
- `UNKNOWN` 下 `HOLD`/`YIELD` 最便宜（保守）。

矩阵不是拍脑袋的最终值：离线用合成/自采数据做逆优化或网格搜索，最小化「响应后任务失败率 + 时间」；但即使先验矩阵也能保证「不确定时保守」。

### 7.3 安全覆盖

贝叶斯风险最小化可能选出「任务最优但不安全」的响应。加一层硬约束：

```text
if collision_risk > θ_safe:  强制 YIELD/HOLD，覆盖 r*
if human_hand_in_sweep:      强制 SLOW/HOLD
if object_unsupported:       禁止 RELEASE
if retries > max:            强制 ABORT
```

安全覆盖优先于代价最优；这是「min 操作」，不是学习。

## 8. 算法伪代码

### 8.1 主循环

```python
class CoAdaptPolicy:
    def get_action(self, obs):
        self.tick(obs)
        feats = self.human_observer.update(obs)   # hand, objects, contact, confidence

        # 1) belief update (chunk boundary)
        if feats.valid:
            self.belief.update(feats, phase=self.phase)
        else:
            self.belief.degrade_to_unknown(eta=0.5)

        # 2) precursor / risk
        risk = self.predictor.risk(feats, self.plan, self.plan_idx)
        self.social_mode = risk.p_int >= THETA_1

        # 3) base chunk from CHUNK-SERVO
        a_ff = self.chunk_servo.next_chunk(obs)

        # 4) response selection (if human present)
        if feats.human_visible or self.social_mode:
            r = self.select_response(self.belief, risk)
            a_cmd = self.apply_response(r, a_ff, feats)
        else:
            a_cmd = a_ff

        # 5) optional intent preamble
        if self.preamble.enabled and self.preamble.should_fire(obs, risk):
            a_cmd = self.preamble.apply(a_cmd)

        # 6) intervention attribution (event-triggered)
        if self.edit_detector.fired(obs):
            k_star = self.cta.attribute(self.history, self.edit_detector.object)
            self.handle_intervention(k_star, self.belief, obs)

        # 7) safety override + valid action
        a_cmd = self.safety.override(a_cmd, feats, self.plan)
        return self.adapter.to_api(a_cmd, obs, self.token)
```

### 8.2 信念更新

```python
def update(self, feats, phase):
    prior = self.phase_prior[phase]                  # P(g|s)
    log_post = np.log(self.b + EPS) + np.log(prior + EPS)
    for g in G:
        log_post[g] += self.log_likelihood(feats, g)
    self.b = softmax(log_post)
    if self.b[UNKNOWN] > 0.6:
        self.b = 0.7 * self.b + 0.3 * onehot(UNKNOWN)
```

### 8.3 信用分配

```python
def attribute(self, history, z_int, t_int):
    best, best_score = None, -1.0
    for (a_k, z_k, t_k, rho_k) in history:
        s = corr(z_k, z_int) * exp(-(t_int - t_k)**2 / (2 * SIGMA_T**2)) * rho_k
        if s > best_score:
            best, best_score = k, s
    if best_score < THETA_K:
        return None          # fall back to score-step rollback
    return best
```

### 8.4 响应选择

```python
def select_response(self, b, risk):
    if risk.collision > THETA_SAFE:
        return YIELD if not risk.hand_on_object else HOLD
    costs = [sum(b[g] * C[r][g] for g in G) for r in R]
    r = R[argmin(costs)]
    if max(b.values()) < THETA_B:
        r = HOLD
    return r
```

### 8.5 三方柔顺

```python
def vac(self, feats, a_ff):
    if feats.contact_score < THETA_C:
        return a_ff
    if feats.relative_velocity_away and feats.gripper_closed:
        if feats.object_supported:
            return self.release_soft(a_ff)
        return self.hold_soft(a_ff)
    if feats.hand_stabilizing:
        return self.hold_soft(a_ff)
    if feats.hand_pushing_toward_robot:
        return self.accept_assist(a_ff)
    return self.hold_soft(a_ff)
```

### 8.6 干预处理

```python
def handle_intervention(self, k_star, belief, obs):
    g_hat = argmax(belief)
    if g_hat == ASSIST:
        self.goal.update_from(obs)          # accept, no rollback
        return
    if g_hat == TAKE_OVER:
        self.request_hold(); return
    if k_star is None:
        self.rollback_to_score_step(); return
    if self.object_moved(obs):
        self.goal.update_from(obs)
        self.replay_from(k_star)
    elif self.step_undone(obs):
        self.completion_stack.rollback_to(k_star)
        self.replay_from(k_star)
    elif self.object_gone(obs):
        self.request_replan(reason="object_missing")
```

## 10. 正确性论证

以下命题都是**条件性**的；假设见 §10.6。

### 10.1 命题 1（信念一致性）

**若**人类意图 `g` 在窗口内固定，**若**观测在给定 `g` 下条件独立同分布，**若**似然可辨识（不同 `g` 的观测分布不同），**若**先验在 `G` 上全正，**则**贝叶斯更新产生的后验 `b_t` 以概率 1 收敛到 `δ_{g}`。

**证明要点**：`b_t(g)` 是 `P(g|o_{1:t})`。在固定 `g` 下，`log b_t(g) - log b_t(g')` 是似然比的和；由大数定律，它除以 `t` 收敛到 `E_g[log(p(o|g)/p(o|g'))] = KL(p_g || p_{g'}) > 0`（可辨识性）。因此 `b_t(g) → 1`，其余 →0。这是标准的贝叶斯一致性；离散有限 `G` 下无需额外正则。∎

**实践含义**：信念会收敛，但需要「同一意图持续若干 chunk」。若人类意图在几帧内切换（TEST 类），信念会滞后；这是我们把 `TEST` 的代价设计成「保守响应」而不是「快速分类」的原因。

### 10.2 命题 2（信用分配的唯一性）

**若**干预只针对单一动作 `k*`，**若** `score(k*) > score(k)` 对所有 `k ≠ k*` 成立，**则** `argmax_k score(k) = {k*}`，且唯一。

**证明**：直接由严格最大值得出；`score` 是有限集上的实值函数。∎

**实践含义**：唯一性依赖「单一被评价动作」假设。若人类同时纠正多个决策（例如先移动目标再拿走物体），`score` 可能多峰；此时取 top-2 并检查谓词一致性，或回退评分步骤级回滚。这是 §14 的风险。

### 10.3 命题 3（最小回滚的步骤安全性）

**若**评分步骤依赖图 `D` 是 DAG，**若** `k*` 之前的所有完成步骤的状态没有被干预改变，**若**回滚集合 `R(k*) = {s : s 在 D 中依赖 k* 之后的动作}`，**则**回滚并重做 `R(k*)` 后，`k*` 之前的完成步骤仍然有效。

**证明**：`R(k*)` 只包含依赖 `k*` 之后动作的步骤；由 DAG 的无环性，这些步骤的后继不会反过来影响 `k*` 之前的状态。`k*` 之前的状态未被干预改变，故其谓词仍成立。∎

**实践含义**：这是「最小因果回滚」的正确性依据，但它依赖「依赖图」和「状态未被改变」两个条件。若人类移动了 `k*` 之前的物体（例如把已经摆好的杯子挪走），则必须扩大回滚集合；CTA 用物体位移检测来发现这种情况。

### 10.4 命题 4（一步贝叶斯风险最优）

**给定**信念 `b` 和代价矩阵 `C`，**若**响应集 `R` 有限，**则** `r* = argmin_r Σ_g b(g) C(r,g)` 最小化期望代价。

**证明**：期望代价是 `b` 的线性函数；有限集上的逐点最小化即全局最小。∎

**实践含义**：这是 myopic 最优，不是长时域最优。我们接受这个近似，因为完整 POMDP 求解在 30ms 预算内不可行；而且人类意图的短期平稳性让 myopic 不至于太差。

### 10.5 命题 5（VAC 不增加主动对抗）

**若**VAC 只降低伺服增益/速度、或在松爪时减小夹爪闭合量，**则**机器人不会主动增加对物体的法向力。

**证明**：法向力（在位置控制下）由轨迹对抗产生；降低增益/速度减少轨迹对抗，松爪减少夹持力。VAC 不增加任何增益或闭合量。∎

**边界**：这不是「不碰撞」的保证。没有力/触觉，机器人无法知道人手施加了多大力；VAC 只能保证「不主动对抗」，不能保证「不被动碰撞」。这是已知风险，必须在真机实验中用限速/限幅兜底。

### 10.6 假设清单

| 假设 | 内容 | 违反时的后果 | 检测方式 |
|---|---|---|---|
| A1 | 人类意图在 0.5–2s 窗口内分段常数 | 信念滞后/振荡 | 后验熵监控 |
| A2 | 似然排序正确（不必校准到概率） | 响应次优 | G8 macro-F1 |
| A3 | 干预对象可被视觉定位 | CTA 归因错误 | G9 top-1 |
| A4 | 动作历史窗口覆盖被评价决策 | `k*` 不在窗口内 | 扩大 K / 检测 |
| A5 | 步骤依赖图可近似为 DAG | 回滚破坏前置步骤 | 谓词检查 |
| A6 | 人类评测者会看机器人动作（H1） | 前导无效 | G12 |

## 11. 实验设计

### 11.1 离线：合成干预与归因

**数据**：33k 成功演示（32 任务）。对每个任务取 50–100 条轨迹，在关键帧注入五类合成干预：

| 意图 | 合成方式 |
|---|---|
| ASSIST | 把目标物体朝机器人 EE 推近 3–8cm / 摆正 5–15° |
| CORRECT | 把目标物体移动到新位姿 / 把已放置物体挪开 |
| TAKE_OVER | 把人手模型放到物体上并带离工作区 |
| TEST | 人手快速进出，不改变物体状态 |
| PASS_BY | 人手轨迹穿过工作区但不接触任务物体 |

同时记录真实标签 `(g, z_int, k*)`。合成到真实有域差，所以只用它做**排序/消融**，不用它预测真机绝对成功率。

**指标**：

- SA-Belief：macro-F1、UNKNOWN 召回、后验熵；
- CTA：top-1/top-2 命中率、与固定「回滚上一步」的差值；
- 前兆：TTC 误差、precision/recall；
- 响应：期望代价 vs oracle（已知 `g` 时的最优响应）。

**门**：G8 macro-F1 ≥0.70；G9 top-1 ≥70%、top-2 ≥85%。

### 11.2 仿真：人类策略与闭环

**平台**：MuJoCo / IsaacLab + G1 URDF + 简化人手臂（胶囊体 + 逆运动学）。

**人类策略**（三种，覆盖不同假设）：

1. **脚本化**：按固定时刻/固定对象干预（最坏情况，H1 不成立）；
2. **反应式**：当机器人进入「看起来要失败」的状态时干预（依赖机器人行为，H1 部分成立）；
3. **信任式**：维护对机器人的信任，信任低时更频繁干预；机器人可读动作提高信任（H1 成立）。

**指标**：

- 任务成功率、干预率、恢复时间、任务时间、碰撞率；
- 与 CHUNK-SERVO（无 CO-ADAPT）配对比较；
- 消融：SA-Belief vs 二值检测；CTA vs 固定回滚；VAC on/off；前导 on/off。

**门**：G10 TTC 误差 ≤150ms；仿真中 VAC 碰撞率下降 ≥50%；脚本化人类下不回归。

### 11.3 真机：单任务通道

**任务**（5 个，覆盖不同接触类型）：

| 任务 | 为什么选 |
|---|---|
| T01 HangCup | 挂/孔对齐，人手容易移动杯架 |
| T26 PlugInEthernet | 插入，人手容易移动网口/线 |
| T19 ZipUp | 拉链，人手容易拉开已拉好的部分 |
| T27 StackBowls | 叠碗，人手容易拿走/移动碗 |
| T16 FoldTowel | 变形任务，防回归（伺服/VAC 不应伤害它） |

**协议**：

- 每任务 10 次 A/B（CO-ADAPT off/on），同一初始条件，尽量配对；
- 由同一位实验者按五类意图脚本干预；脚本随机化顺序；
- 记录成功、步骤分、耗时、p99 延迟、干预次数、恢复次数、碰撞/掉落；
- 统计：配对差值 + bootstrap 95% CI；5 次/任务只能看方向，不能看显著性。

**门**：G11 ≥3/5 任务 +10pp；非 human 轴不回归 >5pp；VAC 无夹坏/撞手。

### 11.4 真人用户研究（辅助，验证 H1）

- 招募 8–12 名非专家；
- 两种条件：前导 on/off；顺序随机；
- 任务：HangCup / StackBowls；
- 指标：非必要干预率（主）、任务时间、信任问卷、NASA-TLX、可读性评分；
- 门：G12 非必要干预率下降 ≥20%，任务时间增加 ≤10%。

这不是竞赛评分的直接证据，但它是 H1 的唯一可证伪来源。

### 11.5 消融矩阵

| 消融 | 比较 | 预期 |
|---|---|---|
| 信念 | 五类 SA-Belief vs 二值 edit | 五类降低误响应 |
| 归因 | CTA vs 固定上一步回滚 | CTA 减少重复干预 |
| 柔顺 | VAC on/off | VAC 降低掉落/碰撞 |
| 前导 | on/off | 仅在 H1 成立时降低干预 |
| 意图先验 | 阶段先验 vs 均匀 | 阶段先验加速收敛 |
| 安全覆盖 | on/off | 覆盖降低最坏情况 |

### 11.6 统计与可复现

- 所有真机 A/B 用配对设计；报告差值、95% bootstrap CI、原始计数；
- 320 trials 的全局 SE ≈2.4pp；单任务 10 次 A/B 的 SE 更大，只能看方向；
- 离线合成数据按 session/物体/背景分组划分，相邻帧不跨 split；
- 代码/配置/随机种子固定；合成干预脚本公开。

## 14. 风险与合规

### 14.1 单模型合规

| 模式 | 做法 | 风险 | 建议 |
|---|---|---|---|
| C1 纯确定性 | SA-Belief/CTA/VAC 全是几何+贝叶斯+规则 | 最低 | 主推 |
| C2 校准表 | 似然/代价参数用离线数据校准，但是统计表不是网络 | 低 | 允许；提交材料写明 |
| C3 同 checkpoint 特征 | 若需更强人手/物体特征，用 VLA 同一 checkpoint 的 encoder | 低–中 | 仅在 C1 不足时 |

禁止：独立的人手检测网络、人类意图分类网络、第二个策略模型。人手检测用运动+双目+颜色先验；意图用离散贝叶斯。

### 14.2 风险表

| 风险 | 影响 | 缓解 |
|---|---|---|
| H1 不成立（固定脚本） | 前导收益消失 | 前导可关；主收益押 CTA/VAC；G12 决定是否启用 |
| 人手检测失败/遮挡 | 信念退化、漏检 | 头双目+腕部+本体兜底；置信度低回退 edit |
| 意图误分类 | 错响应（该让不让/该继续却回滚） | UNKNOWN + 代价敏感 + 置信度阈值 |
| CTA 归因错误 | 回滚错步骤 | top-2 校验 + 谓词检查 + 不可逆动作降权 |
| 过度让行 | 时间涨、成功率降 | 让行预算（≤2 次/任务，≤2s/次）；超预算继续 |
| VAC 松爪掉落 | 物体损坏/失败 | 支撑检查；优先 HOLD_SOFT；限速 |
| 无力度量 | 无法保证不碰撞 | 限速/限幅；VAC 只保证不主动对抗 |
| 单模型解释 | 被判第二个模型 | C1/C2；可审计；提前邮件确认 |
| 延迟 | 响应慢于人手 | 前兆预测 + 5 步块；最坏 hold |
| 评测噪声 | 假阳性 | 配对 A/B + bootstrap + 重复 |
| 合成数据域差 | 离线指标虚高 | 只用于排序/消融；真机 A/B 为准 |
| 人类研究偏差 | H1 结论不稳 | 随机顺序、双条件、预注册指标 |

### 14.3 安全与伦理

- 机器人不主动接触人手；VAC 只后退/松爪/降速。
- 松爪前检查支撑，避免掉落。
- 最大速度/加速度/力（开环）限制；VAC 时长上限。
- 人类研究知情同意、可随时停止；不采集人脸/语音。
- 不声称「情感识别」；文档中统一用「意图/评价」表述。
