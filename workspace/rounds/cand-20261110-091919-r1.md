# 第 43 轮（新循环第 3 轮） · Plan-Cert-Swarm：把「证书飞轮」升级为「任务规划→群体执行」的可组合认证网络（四层架构 v8）

> 承接第 42 轮 v19（SCV × CKB × ECR）。第 42 轮自陈最大风险是「仿真偏差累积 + 检索幻觉」——证书可能在「自信满满」中静默失效。更根本的局限是：42 轮的证书只覆盖**单机的控制层转移**，它能证明「这一步动作安全」，却不能证明「这串任务能完成」「一群机器人能协同完成」。本轮灵感词「任务规划」「群体智能」正好补这两个缺口：**任务规划**把证书从「单步守卫」提升到「携带证明的计划树」——每个子任务节点自带局部证书与 assume-guarantee 契约，整棵计划树的正确性由契约合成保证，失败时按子树做证书引导的修复；**群体智能**有双重用法——其一是**被认证的对象**（多机任务分配、编队、覆盖、共识），其二是**合成算法本身**（数字蚁群在证书空间并行搜索、以 CKB 为信息素场做 stigmergic 协同）。于是飞轮从 Sim→RAG→Edge→Sim 扩展为 **Plan→Contract→Edge→Swarm→Repair→Plan** 的闭环。

## 0. 直觉与动机

**灵感 1（任务规划 → 携带证明的计划树 PCP）**：当前 CAR 的守卫是「状态级」的：给定 x，判 margin ≥ θ。但用户真正要的是「把东西搬到 B 并回来」，这是一棵 HTN 计划树。直觉是让计划里的每个节点像软件里「带证明的函数」——`action + 前置条件 + 局部证书 + 后置契约`；父节点只依赖子节点的**契约**，不依赖其内部实现（信息隐藏）。这样一条计划的安全性可以**分而治之**地证明：局部证书通过（单元测试）+ 接口契约匹配（guarantee ⊨ assume）→ 整体正确。计划失败时也不必全部重算：证书告诉我们哪棵子树违约，只重规划该子树。这把 42 轮的「转移表」升级成「契约化计划 DAG」。

**灵感 2（群体智能 → 群体证书与契约）**：单机证书相加 ≠ 群体安全。两机各自「离障碍 ≥0.5m」仍可能互撞；各自「通信正常」仍可能因共识延迟失步。直觉：群体安全是**耦合不变量**（如两两距离 ≥ d_safe），必须用**成对/子集契约**显式声明耦合，再用「仲裁者」或「共识阈值」合成。引入 **quorum certificate**：N 个 agent 中至少 q 个独立验证同一不变量，才能把群体证书升格为「已证」；这样对 k 个拜占庭/失联 agent 仍 sound。同时按需**分层**：编队外层只需「队形保持」的粗契约，内层才展开到两两 barrier——越靠近物理接触，契约越细。

**灵感 3（群体智能作为搜索算法 → 数字蚁群证书搜索）**：42 轮的 CEGAR 是单线程冷启动。直觉是把「找可行证书」变成蚁群觅食——大量轻量搜索代理（采样器/局部证明器）并行在证书模板空间游走，找到反例就往 CKB 的「信息素场」里沉积（哪条模板、哪组阈值更常成功），后续代理按信息素 + 启发式（几何敏感度、L_m 大小、差集大小）概率选路；差集 Δ 上的 CEGAR 只作为「局部精修」。信息素挥发保证不会锁死在旧模板，又天然复用 42 轮 KB 的检索与反例。

**耦合升级**：计划树负责「做什么、谁来做、按什么顺序」；契约代数负责「每个子任务交给谁时需要什么假设、产出什么保证」；群体运行时负责「多机并发执行与耦合不变量」；证书搜索负责「找不到证书时怎么群体式地找」。执行期任一节点违约 → 契约重协商 → 计划子树修复 → 新证书入 CKB → 信息素更新。42 轮的**单机资产**（L0 表、INT8 监控器、CKB）全部保留，本轮只在它上面加「计划」「群体」两层。

## 1. 形式化定义（增量：定义 38–44）

**定义 38（携带证明的计划 DAG，PCP）**：计划 P=(V,E)，节点 v=(a_v, φ_v, ψ_v, C_v, κ_v)，a_v 为符号动作（HTN 方法/原子技能），φ_v 前置条件，ψ_v 后置条件，C_v 局部证书（来自 42 轮 L0/L1 或 SMT/区间证明），κ_v=(A_v,G_v) 为假设-保证契约。**合成正确性**：若 (i) ∀v，C_v 在其有效域内成立；(ii) ∀(u,v)∈E，G_u ⊨ A_v；(iii) 根节点 G_root ⊨ 全局规约 Ψ，则 P 在 Ψ 下 sound。契约顺序合成记 ⊗：G_{u⊗v}=G_v∘G_u。

**定义 39（时间/资源证书）**：给每个节点绑定时间窗 [est_v,lft_v] 与资源向量 r_v（能耗、算力、带宽）。计划可行需满足 ∀(u,v)∈E, lft_u+dur_u≤lft_v；∀t, Σ_{v active at t} r_v ≤ R_cap。用区间代数 + 差分约束（负环检测）在 O(|V|·|E|) 内核验，输出「调度证书」与各节点 slack。

**定义 40（契约代数与精化序）**：契约 κ=(A,G)，组合 κ1⊗κ2=(A1∪A2,G1∘G2)；精化 κ1 ⊑ κ2 当且仅当 A2 ⊇ A1 且 G1 ⊇ G2（更强假设 + 更弱保证 = 更易满足）。群体合成用**仲裁算子** ⊔：把 N 个单机契约合成为群体契约，显式携带耦合项（相对位置、共享资源、通信假设）。**命题**：⊗ 与 ⊔ 对 ⊑ 单调，故证书可在不破坏 soundness 的前提下被保守替换（gluing）。

**定义 41（群体不变量与 quorum 证书）**：设联合状态 X=(x_1,…,x_N)，群体不变量 Φ(X)（如 ∀i<j ‖p_i−p_j‖≥d_safe ∧ 队形误差≤e_form）。**成对 barrier**：B_ij(x_i,x_j)≥0 且 Ḃ_ij+λB_ij≥0 ⟹ 任意时刻不越界。**quorum 证书** QC(Φ)=(签名集 S,|S|≥q)：S 中每个 agent 独立运行本地验证器并对 Φ 的同一版本摘要签名；q=⌈(N+k+1)/2⌉ 可容忍 k 个拜占庭。Φ 成立当且仅当存在 QC(Φ) 且契约闭合。

**定义 42（群体任务分配证书）**：分配 A:T→2^{Agents}，满足能力 cap(a,t)、容量 Σ_t load(a,t)≤C_a、makespan(A)≤M。证书=(可行性证明, 分配不变量, 重分配触发条件)。拍卖给出 O(|T|log|A|) 近似证书（对偶 gap≤ε）；共识给出分布式一致分配，证书附带「视图编号」防脑裂。

**定义 43（群体证书搜索 SCS，信息素场）**：搜索空间 = 证书模板参数 θ（守卫阈值、L_m、T_hold、档位 j*）。信息素 τ: 模板网格→R≥0 存于 CKB；代理 k 以 P(θ|τ) ∝ τ(θ)^α·η(θ)^β 选模板（η=启发式：敏感度低、差集小、复用度高），找到改进解则沉积 Δτ ∝ 1/|Δ|；每轮 τ←(1−ρ)τ+沉积。**命题**：在有限模板集上，带挥发的 MMAS 型更新以概率 1 收敛到局部最优可行证书；差集精修保证最终仍是 sound 证书而非近似。

**定义 44（证书引导的计划修复）**：运行时节点 v* 违约。修复算子 R：取违约子树边界契约 (A_in,G_out) → 在 CKB 检索同契约模板 → 局部重规划子树 → 校验 (i) 新子树 G ⊨ A_in？(ii) 兄弟节点假设仍满足？→ 若否，上升一层重协商契约。**定理**：每次 R 只改最小违约子树，且新契约满足 A_new ⊇ A_old、G_new ⊆ G_old，故修复保持全局 soundness；修复代价 ∝ 子树规模而非整树。

## 2. 四大产出设计（增量 IP-57/58/59 + 升级 IP-51/54/55/56/47/50/45）

### 2.1 IP-57 PLAN-CERT-COMPILER（计划证书编译器 PCC）
1. **HTN → PCP 编译**：把 HTN 方法展开成计划 DAG；每个原子技能查 42 轮 L0 证书表得到局部 C_v，并把 L0 表的「有效域」转成契约 (A_v,G_v)。
2. **契约合成检查**：边 u→v 上验证 G_u ⊨ A_v；用 SMT（前置/后置）与区间分析（连续量）混合求解；失败点即「契约裂缝」，回传计划器做接口适配。
3. **时间/资源证书**：差分约束 + 资源累积剖面（resource profile），输出调度证书与 slack 分布。
4. **冲突前置化**：把潜在多机资源冲突（同一区域、同一充电桩、共享通道）编译成显式耦合契约，交给 IP-58。

### 2.2 IP-58 SWARM-CONTRACT-RUNTIME（群体契约运行时 SCR）
1. **成对 barrier 层**：每个 agent 广播 (位置, 速度, 契约摘要, 视图号)，本地计算 B_ij 与 Ḃ_ij；仅当所有可见邻居满足才放行。
2. **quorum 证书层**：对群体不变量 Φ 的版本摘要做阈值签名聚合；q 由 N 与容错 k 决定；视图号防脑裂。
3. **分布式任务分配**：拍卖（边缘仲裁）或共识（去中心）；分配证书随任务下发，负载超限触发重分配。
4. **分层降级**：通信退化时，从「全局 Φ + quorum」退化为「局部成对 barrier + 队形保持」；再退化为「单机 SafeStop + 让出通道」——降级链每级都带证书，避免 42 轮式「可用性崩塌」。

### 2.3 IP-59 STIGMERGIC-CERT-SEARCH（群体证书搜索 SCS）
1. **信息素场**：CKB 里为每类模板维护 τ 表（任务指纹聚类 × 参数网格），支持 HNSW 近邻 + 局部 τ 查询。
2. **并行搜索代理**：每个代理 = 采样器 + 局部 CEGAR + 轻量证明器；代理间不直接通信，只通过 τ 间接协作（stigmergy）。
3. **挥发与多样性**：ρ 控制遗忘速率；给「久未被选中但历史成功率高」的模板加探索奖励，防早熟收敛。
4. **反例共享**：任一代理找到的反例即时入 KB Ξ，其他代理通过 τ 与 Ξ 双重引导避坑。

## 3. 四层架构 v8

```
L1: TRI-FUSE(INT8) + IP-49 LIO → 单机状态证书 + 成对 barrier 输入
L2: CTC + VLM + IP-35 仲裁 → 语义/几何残差 → 任务指纹 φ + 环境指纹 ψ
L3: IP-57 PCC(HTN→PCP, 契约合成, 时间/资源证书) ⇄ IP-51 CAR(计划节点模式)
    → IP-58 SCR(成对 barrier + quorum + 分配证书 + 分层降级)
    → IP-47 双层组合(计划 DAG × 群体契约) → IP-39 规划(CBF) → IP-45 总线
L4: IP-59 SCS(数字蚁群 + 信息素场) ⇄ IP-55 CKB(契约索引 + τ) ⇄ IP-54 SCV(多机并行仿真)
    → IP-50 课程(计划复杂度×群体规模) → RCA 重颁证书(含计划/群体证书)
运行期：本地 barrier(μs) + quorum 签名(ms) + 偏移监控 → 契约重协商 → 子树修复 → 信息素更新
```

## 5. 本轮最大风险

**一句话**：计划层与群体层把「一个证书」变成「一张契约网」，新失效链是**契约裂缝的静默传播**与**quorum 相关失效**——若 G_u ⊨ A_v 的检查因抽象过粗而漏判、或群体成员因共享同一传感器/同一仿真偏差而「伪独立」地签出同一错误证书，则整棵树会带着一致同意的错误结论运行；因此 E87（契约裂缝检出）与 E90（伪独立/拜占庭）必须作为红线实验，任一不达标即熔断回退到 42 轮单机证书。

## 1. 符号体系（增量：定义 38–44 符号）

| 符号 | 含义 | 定义 |
|---|---|---|
| P=(V,E), v=(a_v,φ_v,ψ_v,C_v,κ_v) | 携带证明的计划 DAG | 动作 + 前置/后置 + 局部证书 + 契约 |
| κ=(A,G) | assume-guarantee 契约 | A 为需满足的假设，G 为对外保证 |
| κ1⊗κ2=(A1∪A2, G1∘G2) | 契约顺序合成 | 后置保证传递为下一个前置假设 |
| κ1 ⊑ κ2 | 精化序 | A2⊇A1 ∧ G1⊇G2（更强假设、更弱保证） |
| ⊔ | 群体仲裁算子 | 合成 N 个单机契约并显式携带耦合项 |
| Φ(X) | 群体不变量 | 如两两距离 ≥d_safe 且队形误差 ≤e_form |
| B_ij, Ḃ_ij+λB_ij≥0 | 成对 barrier 证书 | 保证 i,j 不越界 |
| QC(Φ)=(S,\|S\|≥q) | quorum 证书 | q=⌈(N+k+1)/2⌉，容忍 k 个拜占庭 |
| A:T→2^{Agents} | 群体任务分配 | 满足能力/容量/makespan 约束 |
| τ: 模板网格→R≥0 | 信息素场 | 存于 CKB，SCS 共享记忆 |
| R(P,v*) | 计划修复算子 | 边界契约检索 + 最小子树重规划 |

## 2. 关键算法（伪代码）

### IP-57 PCC：HTN 编译为 PCP 并检查契约
```
def compile_plan(htn, task, env, cert_table):
    P = htn.expand(task)                       # HTN -> 计划 DAG
    for v in P.V:
        v.C = cert_table.lookup(v.a, v.pre)     # IP-56 L0 局部证书
        v.kappa = certificate_to_contract(v.C)  # (A_v, G_v)
    cracks = []
    for (u, v) in P.E:
        if not entails(P.node[u].kappa.G, P.node[v].kappa.A):
            cracks.append((u, v))               # 契约裂缝
    if cracks:
        return NEEDS_ADAPTER(cracks)            # 回传计划器做接口适配
    sched = temporal_resource_cert(P, R_cap)
    if not sched.sat:
        return UNSCHEDULABLE(sched.peak, sched.diff_constraints)
    return PCP(P, contracts=[v.kappa for v in P.V], schedule=sched)

def temporal_resource_cert(P, R_cap):
    # 时间：差分约束 lft_u + dur_u <= lft_v，负环即不可行
    if has_negative_cycle([(u, v, P.node[u].dur) for (u, v) in P.E]):
        return Cert(False, reason='temporal_cycle')
    # 资源：事件点扫描，峰值不得超过容量
    events = build_resource_profile(P)          # 按 est/lft 生成 +r/-r 事件
    peak = sweep_max(events)
    return Cert(peak <= R_cap, peak=peak, slack=compute_slack(P))
```

### IP-58 SCR：成对 barrier + quorum + 分配
```
def swarm_step(agents, Phi_ver, k, tau_q):
    # 1) 物理耦合层：任何可见邻居的成对 barrier 失效即本地保持
    for i in agents:
        for j in visible_neighbors(i):
            if not barrier_hold(i.x, j.x, d_safe):
                i.hold(); return 'LOCAL_HOLD'
    # 2) 群体共识层：收集对同一版本摘要的签名
    sigs = gather_signatures(Phi_ver, timeout=tau_q)
    q = ceil((len(agents) + k + 1) / 2)
    if len(sigs) >= q and verify_quorum(sigs, Phi_ver):
        commit(Phi_ver)
        return 'QUORUM_OK'
    # 3) 分层降级
    return degrade_to_local_barrier()

def auction_allocate(tasks, agents, C):
    # 按紧迫度降序，拍卖价 = 代价 + 负载影子价（对偶界）
    A, load = {}, {a: 0 for a in agents}
    for t in sorted(tasks, key=urgency, reverse=True):
        for cost, a in sorted((travel_cost(a, t), a) for a in agents):
            if load[a] + cost <= C[a]:
                A[t] = a; load[a] += cost; break
        else:
            return INFEASIBLE(t)               # 无可行 agent -> 触发重分配
    return A, dual_gap(A, load)

def consensus_allocate(tasks, agents, view_id):
    # 带视图号的一致性分配；视图落后方拒绝合并，防脑裂
    proposal = local_proposal(tasks, agents)
    return raft_like_commit(proposal, view_id)
```

### IP-59 SCS：数字蚁群证书搜索
```
def scs_search(KB, template_space, swarm_size, tmax, alpha=1, beta=2, rho=0.1):
    tau = KB.pheromone                     # 初始由 42 轮历史成功率初始化
    best = None
    for t in range(tmax):
        for agent in range(swarm_size):
            theta = sample_by_pheromone(tau, template_space, alpha, beta)
            C = verify_local(theta)        # 局部采样/证明，廉价筛选
            if C.feasible:
                if best is None or C.gap < best.gap:
                    best = C
                    deposit(tau, theta, 1.0 / max(1, len(C.Delta)))
            else:
                KB.add_counterexample(C.cex)   # 反例共享，其他代理避坑
        tau = (1 - rho) * tau              # 挥发防早熟
        tau = normalize(tau)
    # 最终只在差集上做精确 CEGAR，保证 soundness 而非近似
    return assemble(best, cegar_refine(best.Delta, budget=300))
```

### IP-51/57 升级：证书引导的计划修复
```
def repair_plan(P, failed_v, KB):
    sub = P.subtree(failed_v)                    # 最小违约子树
    A_in, G_out = boundary_contract(sub)        # 子树入/出口契约
    for cand in KB.retrieve_by_contract(A_in, G_out):
        P_new = instantiate(cand, sub.scope)
        if not entails(P_new.G, A_in):
            continue
        if not siblings_assumptions_hold(P, failed_v, P_new):
            continue
        # 新契约更强或相等，保证全局 soundness 单调
        if contract_le(P_new.kappa, sub.kappa):
            return replace_subtree(P, failed_v, P_new)
    return escalate_contract(P, failed_v)       # 上升一层重协商
```

## 5. 风险与缓解（增量）

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 契约裂缝静默传播：G_u ⊨ A_v 抽象过粗漏判，错误沿计划树上行 | 高 | E87 红线；契约检查同时用 SMT + 区间双引擎交叉验证；每层保留具体反例；编译期裂缝必须显式修复不得跳过 |
| quorum 伪独立：成员共享同一传感器/仿真偏差，签出同一错误证书 | 高 | E90 红线；签名权重按硬件/传感器/固件版本去相关；引入异构见证源（不同仿真配置、不同物理标定）；对 q 做相关性惩罚 |
| 群体状态空间爆炸：N 机成对契约 O(N^2) 导致编译不可行 | 中 | 分层抽象：先队形/拓扑粗契约，再按接触邻域展开；空间哈希只保留邻近对；同构群体用对称性约简 |
| 信息素早熟：SCS 锁死在旧模板，错过更优证书 | 中 | 挥发 ρ + 探索奖励 + 多起点；每轮保留 ε 比例随机代理；最终差集精修不依赖信息素 |
| 通信退化降级链抖动：反复在 quorum 与局部 barrier 间切换 | 中 | 滞回阈值 + 冷却期；视图号只增不减；降级状态写入证书版本，恢复需重新达成 quorum |
| 计划修复震荡：子树修复后与兄弟契约冲突，反复重协商 | 中 | 契约精化单调（只允许更强假设/更弱保证）；修复预算与次数上限；超限上升一层并锁定版本 |
| 分配证书与执行偏移：实际耗时超出 dur_v | 低-中 | 分配证书携带 slack 裕度；超时触发重分配而非硬失败；E91 监控对偶 gap |

## 6. 本轮最大风险

**一句话**：计划层与群体层把「一个证书」变成「一张契约网」，新失效链是**契约裂缝的静默传播**与**quorum 相关失效**——若 G_u ⊨ A_v 的检查因抽象过粗而漏判、或群体成员因共享同一传感器/同一仿真偏差而「伪独立」地签出同一错误证书，则整棵树会带着一致同意的错误结论运行；因此 E87（契约裂缝检出）与 E90（伪独立/拜占庭）必须作为红线实验，任一不达标即熔断回退到 42 轮单机证书。
