# 第 5 轮（灵感循环第 5 轮；本轮灵感：「热管理」×「真实世界泛化」）

> **基线**：第 4 轮 InstructGauge-WR（IP-328–333；定义 448–467；引理 59–62；实验 E457–E472）。第 3 轮 InstructGauge 五不变式、CVC 闭环，第 2 轮 ToolGauge，第 1 轮 LeanGauge / MODGAUGE 全部继承不变。
> 本轮纪律：仍是**增量升级 + 严格退化**。热管理与真实世界泛化各沿一条轴加深，且任一增强失效都能逐级退回 InstructGauge-WR。

## 0. 直觉与动机

**灵感 1（热管理：一个被忽视的慢变量，正在偷偷改写「可行域」）**
机械臂在真实世界里不是理想刚体：电机铜损、减速器摩擦、连续大扭矩都会把关节温度推高，而驱动器为了自保护会按温度**降额**（torque / velocity derating）。这意味着同一个动作 `a` 在冷机和热机下的物理可行性不同；第 4 轮的 `KinematicAdmissibleSet` 若把温度当常数，就会在长班次、高占空比下**系统性高估能力**。关键直觉是：热是**慢变量**（时间常数几十秒到几分钟），远慢于 50Hz 控制，也慢于一个动作块；因此它可被单独估计、预测与外层调度，而不破坏内环实时性。更重要的是，热不是纯噪声，而是有物理模型的**可预测状态**——这让「提前降额」成为可能，而不是等驱动器保护触发后被动停机。

**灵感 2（真实世界泛化：不要把「泛化」当口号，要把它压缩成一个可监控的包络）**
真实世界泛化最容易被误用：训练分布一换，任何离线证书都可能失效。严谨的做法不是宣称「我们的方法能泛化」，而是把部署条件显式参数化为一个**热包络 `E_θ`**（环境温度、占空比、负载、散热条件），并只在包络内给出条件化保证；一旦在线监测发现 `θ` 或残差越出包络，证书立即作废并退回保守策略。热恰好是真实世界漂移中**可测量、可建模、且与安全强相关**的一条主轴，因此它是把「泛化」从空话变成可证伪命题的最佳切口。我们明确声明：本轮只认证热轴上的泛化，不认证光照、材质、磨损等未建模轴。

**灵感 3（两者耦合：热同时破坏能力、证据与可交换性）**
热管理不是加一个温度阈值那么简单，它同时在三处动手：

1. **能力**：温度升高 ⇒ 可采纳动作集收缩（TKAS），语言 / 规划不能越权；
2. **证据**：温度升高 ⇒ 腕部相机与 TF 标定漂移（镜头 / 连杆热膨胀），第 4 轮的 `SpatialCert` 阈值必须随温度膨胀，否则会「错误地认为一致」；
3. **统计**：冷机与热机的残差分布不同，全局共形校准的可交换性被热区层打破，覆盖率会在热端坍塌。

所以正确解法是「**一条时间尺度脊柱 + 三张证书**」：用热观测器做慢外层，用 TKAS 管能力、用热标定证书管证据、用热区层共形管统计，最后用一张**热泛化证书**把三者组合成一个可检查的失败概率上界。

## 1. 研究问题（本轮要回答什么）

- **Q1（能力）**：如何把温度相关的降额严格嵌入可采纳集，使得「估计不确定」也不会导致越界，同时尽量少损失能力？
- **Q2（证据）**：热漂移如何定量地进入 `SpatialCert` / TF 验证，何时必须重新标定或退回无腕相机路径？
- **Q3（统计）**：热区层破坏可交换性后，如何仍然给出**逐区层**覆盖保证，并在样本不足时安全回退？
- **Q4（泛化）**：能否把「真实世界泛化」表述为「在热包络 `E_θ` 内的条件化失败概率上界」，并在线检测包络失效？

## 2. 四条设计原则（雏形，正式化见产物区定义 468–483）

**P1 热能力闭包（Thermal Capability Closure）**
`A_T(s,θ) ⊆ A(s)`，且对 `θ` 单调不增。规划一律使用温度上置信界 `θ_ub = θ̂ + k_σ σ`，保证「估计越不确定越保守」，绝不因热估计误差而扩权。这是第 3 轮 capability closure 在热轴上的直接推广：语言与规划只能缩小、不能扩大物理可行域。

**P2 热预算分块（Thermal-Budgeted Chunking）**
块长 `K* = min(K_drift, K_thermal, K_irr)`，其中 `K_thermal` 由热模型预测的峰值温度不超过 `θ_budget` 决定。热头寸（thermal headroom）是和时间、证据并列的第三种预算；冷机允许更长块以提高吞吐，热机自动缩块以留出散热余量。

**P3 热漂移证据膨胀（Thermal Evidence Inflation）**
标定参数漂移满足 Lipschitz / 滞后界 `δ_cal(θ, θ̇)`，则 `SpatialCert` 的阈值按 `ε_vis(θ) = ε_vis⁰ + L_proj · δ_cal` 膨胀；膨胀超过 `τ_cal` 就重标定，重标定失败就退回纯关节编码器路径。核心是「宁可把一致性判得更严，也不让热漂移伪装成一致」。

**P4 热区层共形 + 包络绊线（Regime-Stratified Conformal + Envelope Tripwire）**
按热区层 `r` 分别校准；样本不足按「联合层 → 热层 → 全局」逐级回退；在线监测越出 `E_θ` 或区层置信度低时，证书作废并切换保守策略。这把「泛化」从一次性离线声明变成**带绊线的运行时承诺**。

## 3. 与基线的接口（如何退化）

- 热传感器缺失 ⇒ 用电流 / 力矩积分做代理温度，仍按上置信界保守降额；代理也缺失 ⇒ 静态最坏热包络。
- 热模型缺失 ⇒ 高负载动作强制 `K_thermal = 1`，等价于逐步执行。
- 热漂移证书失效 ⇒ 关闭腕部相机，退化为第 4 轮 CVC 单帧漂移检测。
- 热区层样本不足 ⇒ 联合层回退到热层，再回退到全局共形。
- 热包络绊线触发 ⇒ 退回保守静态降额 + 全局共形。
- 所有热增强失效 ⇒ InstructGauge-WR；其失效 ⇒ InstructGauge v3 ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE。

## 4. 预期贡献

1. 把热降额形式化为**单调可采纳集**，并证明「用温度上界规划」在估计误差下仍然安全——能力闭包的热版本；
2. 给出热漂移进入 `SpatialCert` 的**可证膨胀界**，把「热导致视觉证书失真」从经验问题变成可检查条件；
3. 提出**热区层共形校准**与三级回退，修复热端覆盖率坍塌；
4. 把真实世界泛化重述为「热包络内的条件失败概率上界 + 在线绊线」，给出一条可证伪、可部署的泛化口径；
5. 一条完整实验路径 E473–E490，覆盖观测、降额、分块、漂移、覆盖、长时程、跨环境与退化等价。

## 5. 本轮最大风险

**一句话**：热泛化证书的效力完全取决于「热包络 `E_θ` 覆盖真实部署」这一假设，而环境温湿度、负载谱与机械磨损的耦合可能在包络之外制造未建模的热漂移，导致证书在看似正常的在线监测下给出虚假保证。

> 背景：第 4 轮 InstructGauge-WR（IP-328–333；定义 448–467；引理 59–62；实验 E457–E472）。

### 0.1 定位与边界（先把「泛化」说清楚）

本轮**不**声称解决任意真实世界分布漂移。我们只做一件更窄、但可检查的事：把热状态当作真实世界漂移中**可测、可建模、与安全强相关**的一条主轴，并把「泛化」重述为

> 在声明的热包络 `E_θ` 内，执行动作违反热约束、使用失效标定、或结果落在预测区间外的联合概率有一个可计算上界；一旦在线监测发现越出 `E_θ`，证书作废并退回保守策略。

这与「全局共形 + 无条件泛化」的常见叙事有本质区别：后者在热端会静默失效，前者把失效条件显式化、可监控、可回退。热轴之外的光照、材质、磨损漂移不在本轮证书范围内，需由后续轮次的对应传感器轴补上。

## 2. 形式化定义（要点）

**定义 468（热状态与集总 RC 动力学）** 对关节 `i`：

```
θ_{t+1,i} = θ_{t,i} + (Δt / C_i) · [ Q_gen,i(a_t, θ_t) − λ_i (θ_{t,i} − θ_amb) ]
Q_gen,i(a,θ) = |τ_i(a,θ) · ω_i(a)| + R_i · i_i(a,θ)² + μ_i · |ω_i(a)|
```

其中 `R_i i_i²` 为铜损，`μ_i|ω_i|` 为摩擦热。物理约束 `θ_{t,i} ∈ [θ_min, θ_critical,i]`；`θ_critical` 为不可长期越过的临界温度。

**定义 469（热观测器与上置信界）** 给定测量 `y_t`（热电偶、驱动器温度寄存器或电流积分代理），后验

```
θ̂_t = E[θ_t | y_{0:t}],   Σ_t = Cov[θ_t | y_{0:t}]
θ_ub,i = θ̂_{t,i} + k_σ · sqrt(Σ_{t,ii})
```

称观测器以 `1−δ_est` 置信度覆盖真值，若 `P(θ_t ≤ θ_ub) ≥ 1−δ_est`（逐分量）。无温度传感器时，用 `Q_gen` 的积分做代理观测，并把 `δ_est` 上调；无代理时令 `θ_ub = θ_max^static`。

**定义 470（热区层划分）** 令 `load_t` 为最近窗口的平均力矩占额定比。用分位数把 `(θ_max, load)` 划成有限区层 `R = {r_1,…,r_m}`（例如 cold/nominal/hot/critical × low/high）。区层映射 `ρ: (θ,load) ↦ R` 在边界处带滞回，避免 50Hz 抖动导致区层频繁切换。定义区层误判率 `η = P(ρ̂ ≠ ρ)`。

**定义 471（热-运动可采纳集 TKAS）**

```
A_T(s,θ) = { a ∈ A(s) :
    τ_req(a,s) ≤ τ_max(θ)
  ∧ ω_req(a,s) ≤ ω_max(θ)
  ∧ T_1(θ,a) ≤ θ_safe
  ∧ IK 与碰撞检测通过 }
```

其中 `T_1(θ,a)` 为定义 468 的单步预测温度，`θ_safe ≤ θ_critical − m_safe`。由构造 `A_T(s,θ) ⊆ A(s)`；第 4 轮的 `KinematicAdmissibleSet` 是 `θ` 固定时的特例。

**定义 472（热降额函数）** 取单调不增的降额因子

```
d_τ(θ) = clip( (θ_crit^motor − θ) / (θ_crit^motor − θ_rated), 0, 1 )
d_ω(θ) = clip( (θ_crit^motor − θ) / (θ_crit^motor − θ_rated), 0, 1 )^{1/2}
τ_max(θ) = τ_rated · d_τ(θ),   ω_max(θ) = ω_rated · d_ω(θ)
```

具体指数可由电机热试验标定；关键是 `d_τ,d_ω` 对 `θ` 单调不增，下面的单调性引理只依赖这一点。

**定义 473（热指数与热头寸）** 单动作热指数 `h(a,s,θ) = T_1(θ,a) − θ`；块热指数 `H(C,θ) = max_{k≤|C|} T_k(θ, C_{1:k})`。热头寸 `B_θ = θ_budget − θ_ub`，其中 `θ_budget ≤ θ_safe` 是规划预算（通常留出 `m_safe`）。

**定义 474（热预算块长）**

```
K_thermal(θ_ub, C) = max { k ∈ {0,…,|C|} : H(C_{1:k}, θ_ub) ≤ θ_budget }
```

若连第一步都超预算，`K_thermal = 0`，表示必须先冷却再规划。

**定义 475（有效块长）**

```
K* = min( K_drift, K_thermal, K_irr, K_cap )
```

`K_drift` 来自第 3 轮的证据陈旧界，`K_irr` 来自第 3 轮不可逆屏障，`K_cap` 是规划器的构造上界。`K*=0` ⇒ 不执行，进入冷却 / 等待。

**定义 476（热标定漂移界）** 设常温标定参数为 `c(θ₀)`。对腕部相机外参 / 内参与 TF 链路，假设存在可标定的界

```
δ_cal(θ, θ̇) = L_+^heat · [θ − θ₀]_+ + L_+^cool · [θ₀ − θ]_+ + L_h · |θ̇| + ε_c
```

加热与冷却使用不同系数以容纳滞回；`ε_c` 为重复标定噪声。该界是建模假设，必须由 E476 的标定实验验证，而不是先验真理。

**定义 477（热标定证书 CalCert_T）**

```
CalCert_T = ( θ_lo, θ_hi, δ_cal, ε_vis(θ), valid, t_recal )
ε_vis(θ) = ε_vis⁰ + L_proj · δ_cal(θ, θ̇)
valid ⇔ δ_cal ≤ τ_cal ∧ θ ∈ [θ_lo, θ_hi]
```

`L_proj` 是残差对相机/TF 标定参数的 Lipschitz 常数，可由离线扰动实验估计。`valid = false` 时，腕部相机只能提供低权重证据，或直接关闭并退回第 4 轮的纯 CVC 路径。

**定义 478（热区层共形预测）** 对每个区层 `r`（可选再按指令层 `ℓ` 细分），在校准集 `D_{r,ℓ}` 上计算非一致性分数 `s_i = |y_i − μ̂(x_i)|`，取

```
q_{r,ℓ} = Quantile_{⌈(n_{r,ℓ}+1)(1−α)⌉ / n_{r,ℓ}}( {s_i}_{i∈D_{r,ℓ}} )
C_{r,ℓ}(x) = [ μ̂(x) − q_{r,ℓ}, μ̂(x) + q_{r,ℓ} ]
```

**三级回退**：若 `n_{r,ℓ} < n_min`，用 `D_r`；若 `n_r < n_min`，用 `D_global`。这保证样本不足时不会产生空区间或未定义分位数。

**定义 479（区层漂移与覆盖缺口）** 对区层 `r`，令

```
κ_r = sup_{A} | P_r^deploy(A) − P_r^cal(A) |        （总变差）
κ   = max_r κ_r + η/(1−η)
```

若区层内可交换，`κ_r = 0`；若仅有近似可交换，`κ_r` 是覆盖率的直接扣减项；`η/(1−η)` 吸收区层分类器误判。

**定义 480（热泛化包络）**

```
E_θ = ( θ_amb ∈ [θ_amb^lo, θ_amb^hi],
        duty ∈ [0, d_max],
        payload ∈ [m_lo, m_hi],
        cooling ∈ C_set,
        |θ̇| ≤ v_max )
Θ(E_θ) = { 满足定义 468 且参数落在 E_θ、θ_t ∈ [θ_min, θ_critical] 的所有热轨迹 }
p_out = P( 部署热轨迹 ∉ Θ(E_θ) )
```

包络是证书的**适用范围**，不是对真实世界的全称声明。

**定义 481（热泛化证书 TGC）**

```
TGC = ( E_θ, {CalCert_T}, {q_{r,ℓ}}, κ, δ_est, α )
```

若以下条件成立：
1. `∀θ ∈ Θ(E_θ)`，规划使用 `A_T(s,θ_ub)` 且 `θ_ub` 以 `1−δ_est` 覆盖真值；
2. `∀θ ∈ Θ(E_θ)`，`CalCert_T.valid = true`；
3. `∀r,ℓ`，区层共形以 `1−α−κ` 覆盖；

则称 TGC 在包络 `E_θ` 上有效，并给出联合失败界

```
F(E_θ) ≤ p_out + δ_est + κ + α
```

`F` 是「热约束违背 ∨ 标定失效 ∨ 结果出区间」的并集概率上界。**这是一个条件化保证**：`p_out` 必须由在线绊线估计或保守设定，不能默认为 0。

**定义 482（热屏障）** 定义

```
B_θ(a,s) = 1  ⇔  h(a,s,θ_ub) > β · B_θ  ∨  T_1(θ_ub,a) > θ_critical − m_safe
```

若 `B_θ(a,s)=1`，强制 `K*=1`，并要求在下一块前收到「冷却回执」`θ̂ ≤ θ_cool`。直观：热虽最终可散，但若恢复时间超过本 episode 剩余时间，则在本 episode 内等价于**不可逆**——这是第 3 轮不可逆屏障在时间维度上的推广。

**定义 483（退化映射 D）**

```
D(¬sensor)      = 电流积分代理 + 上调 δ_est
D(¬proxy)       = θ_ub := θ_max^static
D(¬thermal-model) = K_thermal := 1（高负载动作）
D(¬CalCert_T)   = 关闭腕部相机，退回 CVC 单帧漂移
D(¬strata)      = 全局共形 q_global
D(¬envelope)    = 静态保守降额
D(全关闭)        = InstructGauge-WR
```

```python
# IP-334 ThermoObserver：10Hz 慢外层，不进入 50Hz 内环
class ThermoObserver:
    def __init__(self, n_joints, C_th, lam, dt=0.1, k_sigma=2.0):
        self.n = n_joints
        self.C = np.asarray(C_th); self.lam = np.asarray(lam)
        self.dt = dt; self.k_sigma = k_sigma
        self.theta_hat = np.full(n_joints, ambient_default())
        self.Sigma = np.eye(n_joints) * sigma0**2
        self.partition = ThermalPartition(hysteresis=0.5)

    def _heat(self, tau, omega, current, theta):
        return (np.abs(tau * omega) + R * current**2
                + mu * np.abs(omega))

    def update(self, tau, omega, current, ambient, dt):
        Q = self._heat(tau, omega, current, self.theta_hat)
        A = np.diag(1.0 - self.lam * dt / self.C)
        b = (self.lam * dt / self.C) * ambient + (dt / self.C) * Q
        self.theta_hat = A @ self.theta_hat + b
        self.Sigma = A @ self.Sigma @ A.T + Q_proc(dt)
        y = read_temperature_sensor()          # 可能为 None
        if y is not None:
            H = np.eye(self.n)
            K = self.Sigma @ H.T @ np.linalg.inv(H @ self.Sigma @ H.T + R_meas)
            self.theta_hat = self.theta_hat + K @ (y - H @ self.theta_hat)
            self.Sigma = (np.eye(self.n) - K @ H) @ self.Sigma

    def estimate(self):
        sigma = np.sqrt(np.diag(self.Sigma))
        return self.theta_hat, sigma

    def regime(self, load):
        return self.partition.bin(self.theta_hat, load)

# IP-335 TKAS
class ThermoKinematicSet:
    def __init__(self, limits, thermal_model):
        self.limits = limits; self.model = thermal_model

    def admissible(self, action, state, theta_ub):
        if self.limits.tau(action, state) > self.limits.tau_max(theta_ub):
            return False
        if self.limits.omega(action, state) > self.limits.omega_max(theta_ub):
            return False
        if self.model.step(theta_ub, action) > self.limits.theta_safe:
            return False
        return self.limits.ik_and_collision_ok(action, state)

    def filter(self, chunk, state, theta_ub):
        return [a for a in chunk.actions
                if self.admissible(a, state, theta_ub)]

# IP-336 TBP
class ThermalBudgetPlanner:
    def __init__(self, model, theta_budget):
        self.model = model; self.theta_budget = theta_budget

    def max_chunk(self, chunk, theta_ub):
        theta = theta_ub.copy(); k = 0
        for a in chunk.actions:
            theta = self.model.step(theta, a)
            if np.any(theta > self.theta_budget):
                break
            k += 1
        return k

# IP-337 ThermoCalCert
class ThermoCalCert:
    def __init__(self, L_heat, L_cool, L_h, eps_c, L_proj,
                 eps0, tau_cal, theta0):
        self.L_heat = L_heat; self.L_cool = L_cool; self.L_h = L_h
        self.eps_c = eps_c; self.L_proj = L_proj; self.eps0 = eps0
        self.tau_cal = tau_cal; self.theta0 = theta0

    def certify(self, theta_hat, theta_dot):
        d = (self.L_heat * max(theta_hat - self.theta0, 0)
             + self.L_cool * max(self.theta0 - theta_hat, 0)
             + self.L_h * abs(theta_dot) + self.eps_c)
        eps_vis = self.eps0 + self.L_proj * d
        valid = d <= self.tau_cal
        return CalCert(theta_hat, d, eps_vis, valid)

# IP-338 RSCC：Mondrian 共形 + 三级回退
class RegimeStratifiedConformal:
    def __init__(self, alpha, n_min, scores):
        self.alpha = alpha; self.n_min = n_min; self.scores = scores

    def quantile(self, regime, layer=None):
        for key in [(regime, layer), (regime, None), (None, None)]:
            s = self.scores.get(key, [])
            if len(s) >= self.n_min:
                return conformal_quantile(s, self.alpha)
        raise InsufficientCalibration

# IP-339 TGC：组合证书 + 在线绊线
class ThermalGeneralizationCert:
    def __init__(self, envelope, cal_cert, rscc, kappa, delta_est, alpha):
        self.E = envelope; self.cal = cal_cert; self.rscc = rscc
        self.kappa = kappa; self.delta_est = delta_est; self.alpha = alpha

    def inside_envelope(self, theta_hat, theta_dot, load):
        return self.E.contains(theta_hat, theta_dot, load)

    def make(self, chunk, theta_ub, cal_cert, q):
        return TGC(E=self.E, theta_ub=theta_ub,
                   cal=cal_cert, q=q,
                   failure_bound=(self.E.p_out + self.delta_est
                                  + self.kappa + self.alpha))

# IP-340 ThermoGauge-GR 主闭环
def thermogauge_gr(M, s, ell=None):
    # 1. 热慢环（10Hz，异步；50Hz 主路径只读缓存）
    theta_hat, sigma = M.tse.estimate()
    theta_ub = theta_hat + M.k_sigma * sigma
    regime = M.tse.regime(M.load())
    theta_dot = M.tse.theta_dot()

    # 2. 包络绊线：越界即作废证书，退回保守路径
    if not M.tgc.inside_envelope(theta_hat, theta_dot, M.load()):
        return M.instructgauge_wr(s, ell)
    if M.tgc.regime_confidence(regime) < M.eta_min:
        return M.instructgauge_wr(s, ell)

    # 3. 热标定证书：决定腕部相机是否可用、ε_vis 是否膨胀
    cal = M.tcc.certify(theta_hat, theta_dot)
    if cal.valid:
        M.wristcam.enable()
        eps_vis = cal.eps_vis
    else:
        M.wristcam.disable()          # 退化为 CVC 单帧漂移
        eps_vis = M.eps0_static

    # 4. 规划（语言接地与假设生成沿用第 3/4 轮）
    iota = M.nlib.ground(ell, M.scene, M.ontology) if ell else M.default_iota
    H = M.lbox.hypothesize(s, M.dbox.R[s], iota)
    C = M.iac.plan_chunk(iota, H, M.tools,
                         M.budget_left(s), M.drift_bound(s),
                         theta_ub=theta_ub)     # 新增可选参数

    # 5. TKAS 过滤：热降额 + IK/碰撞 + 预测温度
    C = C.retain(M.tkas.filter(C, M.env.state(), theta_ub))

    # 6. 热预算与不可逆屏障共同定块长
    k_thermal = M.tbp.max_chunk(C, theta_ub)
    k_irr = M.irr.max_chunk(C)               # 第 3 轮不可逆屏障
    k = min(len(C.actions), k_thermal, k_irr)
    C = C.truncate(k)
    if k == 0:
        return M.cool_until(theta_hat, theta_cool=M.theta_cool)

    # 7. 热屏障：跨临界/高热动作绝不分块
    if any(M.tbarrier.trigger(a, M.env.state(), theta_ub) for a in C.actions):
        C = C.truncate(1)

    # 8. 执行（沿用第 4 轮 joint-pre + SpatialCert + ROS 发布）
    spatial_violations = []
    for t, action in enumerate(C.actions):
        if not M.cvc.joint_pre(action) or not still_grounded(iota, M.env):
            break
        if not M.tkas.admissible(action, M.env.state(), theta_ub):
            C = C.truncate(t); break
        M.env.apply(action)
        tf = M.wristcam.latest_tf() if M.wristcam.enabled else None
        if tf is not None and not M.ros_cvc.verify_tf_consistency(tf, C.psi_post):
            spatial_violations.append(t)
            if len(spatial_violations) > M.violation_threshold:
                C = C.truncate(t); break

    # 9. 生成热标定 / 时空 / 泛化证书
    spatial_cert = generate_spatial_cert(C, M.wristcam.tf_seq(), eps_vis)
    q = M.rscc.quantile(regime, iota.layer if iota else None)
    tgc = M.tgc.make(C, theta_ub, cal, q)

    # 10. ROS 声明式发布（向后兼容第 4 轮消息）
    M.ros_cvc.publish_cvc(C.id, len(C.actions), C.actions,
                          C.pre_conditions, C.post_conditions,
                          [spatial_cert])
    M.ros_cvc.publish_thermal(tgc)          # 新消息，旧订阅者可忽略
    M.ros_cvc.broadcast_block_tf(C.id, C.final_state)

    receipts = M.tcv.get_receipts()
    claims = bind_claims(C, iota, receipts)
    return C, spatial_cert, tgc, claims
```

## 4. 推导

**引理 63（热能力单调性与上界保守性）** 若 `θ₁ ≤ θ₂`（逐分量），则 `A_T(s,θ₂) ⊆ A_T(s,θ₁)`。进一步，若真实温度满足 `θ_t ≤ θ_ub`，则在 `A_T(s,θ_ub)` 内选出的任何动作对真实状态仍可行。

*证明*：由定义 472，`d_τ,d_ω` 对 `θ` 单调不增，故 `τ_max(θ₂) ≤ τ_max(θ₁)`、`ω_max(θ₂) ≤ ω_max(θ₁)`；由定义 468，`T_1(θ,a)` 对 `θ` 单调不减，故 `T_1(θ₂,a) ≤ θ_safe ⇒ T_1(θ₁,a) ≤ θ_safe`。三个约束的可行域随 `θ` 单调收缩，逐分量取大只会更严。若 `θ_ub` 以 `1−δ_est` 覆盖真值，则由单调性，`A_T(s,θ_ub)` 中的动作对真值也可行，安全性以 `1−δ_est` 成立。∎

*注*：这条引理是「不确定就保守」的正式依据；它把热估计误差从安全论证中剥离出来——估计越差，`σ` 越大，`θ_ub` 越高，可行集越小。

**引理 64（热预算分块不越界）** 设每步热模型误差有界 `|T_1^true(θ,a) − T_1^model(θ,a)| ≤ e_m`，且 `K* = min(K_drift,K_thermal,K_irr)` 满足

```
H(C_{1:K*}, θ_ub) + K* · e_m ≤ θ_budget
```

则执行该块期间真实温度不超过 `θ_budget`。若 `θ_budget ≤ θ_critical − m_safe`，则未触及临界温度。

*证明*：对步数 `k` 归纳。基础步 `k=0`，`θ_0^true ≤ θ_ub`。设 `θ_k^true ≤ θ_k^model + k e_m`，则

```
θ_{k+1}^true ≤ T_1^true(θ_k^true, a_k)
            ≤ T_1^model(θ_k^true, a_k) + e_m
            ≤ T_1^model(θ_k^model + k e_m, a_k) + e_m
            ≤ T_1^model(θ_k^model, a_k) + (k+1) e_m        （单调性）
```

最后一步用到 `T_1^model` 对 `θ` 的单调性。归纳得 `θ_{K*}^true ≤ H(C_{1:K*}, θ_ub) + K* e_m ≤ θ_budget`。∎

**引理 65（热漂移下 SpatialCert 的可靠性）** 设标定参数漂移满足 `||c(θ) − c(θ₀)|| ≤ δ_cal(θ)`，残差对标定参数的 Lipschitz 常数为 `L_proj`。若使用膨胀阈值 `ε_vis(θ) = ε_vis⁰ + L_proj δ_cal`，则：

1. 任何被该阈值判为「不一致」的帧，在真实标定下也至少以 `ε_vis⁰` 的残差偏离；
2. 任何真实残差 `> ε_vis⁰` 的帧不会被误判为一致。

*证明*：记名义残差 `r_nom`、真实残差 `r_true`。由 Lipschitz 性，

```
|r_true − r_nom| ≤ L_proj ||c(θ) − c(θ₀)|| ≤ L_proj δ_cal
```

故 `r_true ≥ r_nom − L_proj δ_cal`、`r_true ≤ r_nom + L_proj δ_cal`。若 `r_nom > ε_vis⁰ + L_proj δ_cal`，则 `r_true > ε_vis⁰`，得 (1)。若 `r_true > ε_vis⁰`，则 `r_nom ≥ r_true − L_proj δ_cal > ε_vis⁰ − L_proj δ_cal`；要保证被判不一致需 `r_nom > ε_vis⁰ + L_proj δ_cal`，因此 (2) 需要单边条件 `r_true > ε_vis⁰ + 2 L_proj δ_cal` 才能由名义阈值可靠捕获。工程上把 `ε_vis(θ)` 取 `ε_vis⁰ + 2 L_proj δ_cal` 即得双侧保守；本轮的实现采用这一更严的 `2×` 版本。∎

*注*：这条引理只保证「在 `δ_cal` 界成立时」的可靠性；若热漂移超出建模的 Lipschitz 界（例如滞回非单调），证书会失效。因此 `δ_cal` 的在线验证（E476）是证书的前置条件，而不是可选项。

**引理 66（热区层覆盖）** 若在每个热区层 `r` 内，校准分数与部署分数可交换，则 `P(Y ∈ C_r(X) | R=r) ≥ 1−α`。若仅近似可交换且 `TV(P_r^deploy, P_r^cal) ≤ κ_r`，则覆盖率至少 `1−α−κ_r`。若区层分类器有误判概率 `η`，则总体覆盖率至少 `1−α−κ−η/(1−η)`，其中 `κ = max_r κ_r`。

*证明*：第一句是 Mondrian 共形预测的标准结论（在每个区层内独立应用分裂共形）。第二句由总变差耦合：任取事件 `A`，`|P_r^deploy(A) − P_r^cal(A)| ≤ κ_r`，把校准集上的 `1−α` 覆盖下界平移到部署分布。第三句：分类正确时按 `r` 校准，分类错误时退化为任意区层，其覆盖率下界为 `0`；用全概率公式与 `η/(1−η)` 的几何级数放大即得。∎

*推论*：全局共形在热端的覆盖率可低至 `1−α−κ_hot`，而分层校准把缺口局部化到热层；代价是冷层样本被部分闲置，这正是「覆盖率—样本效率」的显式交换。

**引理 67（TGC 组合失败界）** 若 `TGC = (E_θ,{CalCert_T},{q_{r,ℓ}},κ,δ_est,α)` 成立，且部署中 `P(θ ∉ Θ(E_θ)) ≤ p_out`，则「执行动作违反热约束 ∨ 使用失效标定 ∨ 真实结果落在预测区间外」的总概率不超过

```
F ≤ p_out + δ_est + κ + α
```

*证明*：定义四个失败事件：`A_out`（热轨迹越出包络）、`A_est`（`θ_ub` 未覆盖真值）、`A_shift`（区层漂移超过 `κ`）、`A_conf`（共形区间未覆盖）。由定义 480，`P(A_out) ≤ p_out`；由定义 469，`P(A_est) ≤ δ_est`；由引理 66，`P(A_conf | ¬A_shift) ≤ α`，故 `P(A_conf) ≤ α + κ`；热约束违背由引理 63 归入 `A_out ∪ A_est`，标定失效由引理 65 归入 `A_out ∪ A_est`。对四个事件取并集界即得。∎

*注*：`F` 是**条件化**上界，不是对任意真实世界分布的无条件保证。`p_out` 若被低估，证书会给出虚假保证；因此定义 480 要求在线绊线与保守的 `p_out` 设定。

**引理 68（退化等价性）** 退化映射 `D` 满足：

1. 关闭热观测器（`σ→∞` 或使用静态 `θ_max`）⇒ `A_T(s,θ_ub)=A_T(s,θ_max)`，规划退回第 4 轮 `KinematicAdmissibleSet` 的保守子集；
2. 关闭热模型 ⇒ `K_thermal=1`，块执行退回逐步；
3. 关闭热标定证书 ⇒ 腕部相机失效，退化为 CVC 单帧漂移检测；
4. 关闭热区层 ⇒ 全局共形，退回第 3 轮校准口径；
5. 全部关闭 ⇒ 主循环与 InstructGauge-WR 逐步同构。

*证明*：逐项令增强算子的参数取恒等元：`σ=∞` 使 `θ_ub=θ_max`，`K_thermal=1` 使 `K*=1`，`CalCert_T.valid=false` 使腕部相机旁路，`|R|=1` 使 `q_{r,ℓ}=q_global`，`E_θ` 取全空间使绊线恒不触发。此时主循环的每个热 guard 退化为恒真，剩余路径正是第 4 轮 WRC-ROS-7C 闭环；继续关闭第 4 轮组件即回到 InstructGauge v3 / ToolGauge。∎

|---|---|---|
| P1 | 全局共形在热区层的覆盖率会跌到 `1−α` 以下（α=0.10 时 <0.80）；RSCC 维持 ≥0.88 | 「热区层破坏可交换性」夸大了，热分层不必要 |
| P2 | 静态降额要么在高占空比下出现 >5% 热越界，要么损失 >30% 能力；TKAS+`θ_ub` 做到 0 越界且能力损失 <15% | 热降额对能力的影响可以忽略，本轮动机不成立 |
| P3 | 名义 `ε_vis` 在 30 分钟高负载后漏检 >20% 的真实标定违背；膨胀版捕获 ≥95% | 热漂移对腕部相机可忽略，IP-337 冗余 |
| P4 | 热预算分块把峰值温度越界事件降到 0，同时保留 ≥90% 冷机吞吐 | 热预算与吞吐不可兼得，分块收益被高估 |
| P5 | 包络越界可在临界温度前 ≥2 s 被绊线检出 | 热慢变量假设失效，在线绊线来不及 |
| P6 | 无热屏障时，高负载长块每 100 episode 至少 1 次临界事件；有屏障为 0 | 热屏障过度保守，严重损伤吞吐 |

## 6. 复杂度分析

| 组件 | 域 | 时间 | 空间 | 正确性锚 |
|---|---|---|---|---|
| ThermoObserver | 热慢环 | `O(n)` / 10Hz 更新 | `O(n²)` | 定义 468–469 |
| TKAS | 规划 | `O(|A|·n)` 每动作 | `O(|A|)` | 定义 471–472 |
| TBP | 规划 | `O(K·n)` | `O(n)` | 定义 473–474 |
| ThermoCalCert | 证据 | `O(1)` | `O(1)` | 定义 476–477 |
| RSCC | 统计 | `O(1)` 查询 + 离线 `O(n_r log n_r)` | `O(n_r)` | 定义 478–479 |
| TGC | 集成 | `O(1)` | `O(1)` | 定义 480–481 |
| 主闭环热 guard | 50Hz 主路径 | 只读缓存，`<0.05 ms` | 不变 | 继承第 4 轮引理 50 |

关键时序结论：热观测在 10Hz 慢环完成，50Hz 主路径只做缓存读取与常数时间比较；热模型、共形分位数、包络判定全部离线/低频，故不破坏第 4 轮的 50Hz 时序保全。

## 9. 本轮最大风险

**一句话**：ThermoGauge-GR 的最大风险不是热模型不准，而是**证书的包络假设 `E_θ` 与真实部署不匹配**——一旦环境温湿度、负载谱或机械磨损把机器人推到包络之外，在线绊线只能保证「退回保守」，却无法追回此前已执行的热漂移动作所造成的标定污染或关节热损伤，即证书的「条件化」边界可能被部署现实悄悄越过。
