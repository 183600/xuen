# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「谐波减速器」×「意图理解」）

> R69 把不确定性一分为二（aleatoric / epistemic），把 epistemic 全部交给「主动交互 + VoI」。这建立在两个未言明的前提上：(a) 一切可约的 epistemic 都靠「问」消解；(b) 问来的回答是对**固定意图**的被动观测，不会反过来改变意图。本轮两个灵感同时击穿这两点。
>
> - **谐波减速器**：一个高精度传动，其误差既不是随机噪声，也不是「该去问谁」的歧义——它是**相位锁定、路径依赖（迟滞）、并缓慢疲劳退化**的确定性畸变。它靠**按相位索引的前馈补偿表**消除，靠**单调累积的损伤变量**追踪退化；这两者都不是 R68 的「刹车」，也不是 R69 的「提问」。
> - **意图理解**：意图是隐变量，但人**表达出来的意图**是隐意图经过一层「传动」后的畸变——被语境/习惯（结构化）、被交互历史（迟滞/锚定）、被**你自己的提问**（干预）所改变。于是「问」是因果模型里的 do(g)，回答是**处理效应而非独立证据**。
>
> 核心命题：**R69 的二分太粗——必须补上第三通道「结构化 epistemic」（相位锁定、可学习、应补偿而非提问或减速），并把交互从「提问以观测」升级为「干预以识别」：用意图传输模型把设计内的柔顺与设计外的退化分开，用单调损伤锚做标定不可吸收的见证，用迟滞死区与软预载承诺把「幻影追问」从源头减掉。** 命名 **HARMONIC-RAS**（Harmonic-structured uncertainty, Accumulative-damage anchor, Residual phase-locking, Model-based intent transmission, Observational-vs-interventional evidence, Near-zero-backlash commitment, Intent-in-the-loop, Calibration-immutable wear）。
>
> 一句话定位：R66 问「谁控制」，R67「未来怎样」，R68「我的测量还准吗」，R69「我该向谁求证」，R70 问「**我求证的那个东西是稳定的意图吗，还是我在测量自己的提问；这层畸变是可建模的传动，还是正在累积的损伤**」。

## 0. 直觉与动机

**灵感 1（谐波减速器 → 不确定性的第三种结构：相位锁定的系统性误差）**
直觉：谐波减速器的传动误差大部分是**确定的**——它是波发生器转角 θ_w 的周期函数（再叠加柔轮自身转频），可以傅里叶分解、做成查找表，一次学、长期补。它既不是噪声（不是不可约，学得出来），也不是歧义（不需要问齿轮「你在第几齿」——量相位、查表即可）。控制上没人会给减速器「减速求稳」，也没人会向它「提问」，正确做法是**前馈补偿**。
迁移：机器人里大量系统性不确定是**锁定在某个可测参考相位**上的（步态相位、关节角、任务相位、热/老化时间）。R68 把它们当噪声去收紧 λ，R69 把它们当歧义去算 VoI——都不对。它们应走**第三条通道**：学一个相位索引的误差模型并前馈补偿。这是本轮第一根支柱。

**灵感 2（柔轮弹性 → 设计内的柔顺 vs 设计外的退化）**
直觉：柔轮被**故意设计成会弹性变形**的——它的形变是预期内、可建模的；而疲劳裂纹是设计外的、单调累积的。同一个传感器信号「它变形了」，既可能是正常柔顺，也可能是退化。R68/R69 把所有「超出预期」一律并入保守，把「正常柔顺」和「正在坏掉」混为一谈。
迁移：**意图表达本来就会随语境/历史合理漂移（设计内柔顺，建模即可）；而「传输模型本身在漂移」才是退化（故障）**。标定可以拟合当下的柔顺，却无法撤销已经累积的疲劳。于是需要一个**单调、不可被标定清零**的退化状态来区分二者（灵感 3、定义 315）。

**灵感 3（迟滞/空回 → 意图表达有死区与路径依赖；别对噪声问问题）**
直觉：谐波减速器有迟滞环——输出依赖加载方向的**历史**，死区内小幅输入不产生输出。控制器若把死区内每个微小变化都当成新指令，就会抖振（chatter）。
迁移：意图表达是迟滞的：行为的小幅波动落在死区内，只有**越过回滞带**才是真实意图改变。R69 对每次模态波动都算 VoI，等于对噪声问问题——不仅浪费预算，还会诱发**交互疲劳**、追一个幻影模态（正是 R69 自陈的头号风险）。用迟滞感知的**意图变化检测器**做门控：死区内不问，只有真正出带且持续才问。这从**源头**压掉幻影追问，而不是事后靠审计拦截。

**灵感 4（波发生器 → 结构化激励而非开放提问）**
直觉：波发生器给柔轮施加一个**已知、受控的椭圆波**来产生形变；系统辨识也是注入已知激励、读响应。开放提问是「无设计的激励」，回答里混着诱导、锚定、社交压力，无法辨识。
迁移：把探询改成**结构化微干预**——一个已知、安全、低幅度的「二选一/正交小提议/受控手势」，其**设计好的变化**能识别响应函数对意图的局部斜率，从而把「诱导偏差」和「真实意图」分开。这既是探询，也是**对意图传输的在线系统辨识**。

**灵感 5（意图理解 → 交互是干预，回答是处理效应）**
直觉：因果语言里，「问」是 do(g)。回答 y = f(m, g, context) 依赖 g：一个诱导性问题会在 m 不变时改变 y 的分布。R69 把回答当对 m 的独立证据，并用「k 个正交源一致」聚合；但**若所有提问共享同一个诱导偏差，它们就是相关的错误源，k-一致性会静默失效**——恰好是 R69 的投毒风险。
迁移：意图推断必须是**干预式**的：估计 p(m | do(g), y, ψ)，响应模型 ψ 含顺从度、锚定/诱导偏差、策略性（甚至欺骗性）回答。交互证据只有满足 (i) ψ 被辨识（来自随机化微干预的秩条件）且 (ii) 诱导偏差有界时，才可准入。这把 R69 的「稳健聚合」升级为「因果可识别」。

**灵感 6（分布式啮合 → 精度来自多处弱接触的载荷分担）**
直觉：谐波减速器靠约 30% 齿同时啮合、弹性预载实现近零背隙与高精度——**精度来自分散接触的载荷分担，而非刚性单点**。
迁移：意图承诺应是**软预载**的：维持一个由多条弱而多样的证据支撑的连续后验，只有后验越过回滞带并持续才承诺。单源投毒只能改变其载荷份额，翻不动输出；切换平滑无抖振。这是 R69「k-正交一致」的力学版与连续版。

**灵感 7（对偶通道升级 → 正面回应 R69 最大风险）**
直觉：R69 怕「问错比不问更危险」——问一个幻影、把误导回答盖上「已验证」。本轮有三重正面回应：(i) 用相位锁定模型**先减掉**本不该问的系统误差；(ii) 用迟滞死区**不问**噪声级波动；(iii) 用因果辨识把回答降级为「通过准入才可用的处理效应」。R69 的 Δa 只看「点残差」，本轮再加一个**单调累积的损伤见证 ẇ**，标定连它的一阶导都抹不掉。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（HARMONIC-RAS 总览）** HARMONIC-RAS = (ITM, SUD, SCD, HCD, CDA, SMI, ICI, SPC, RAS-WM‡)。五不变式：
(i) **实时流零学习写**（继承 R68 定义 276-i / R69 定义 293-i）；
(ii) **标定不可逆的单调损伤态**：CDA 状态 w 只增不减，标定（COF）不得修改 w（定义 315）；
(iii) **单通道处置、不得重复计数**：U_ale→λ floor、U_epi-amb→VoI 交互、U_epi-struct→前馈补偿（定义 313）；
(iv) **干预式证据纪律**：交互证据须通过「响应模型可辨识 + 诱导偏差有界」双检（定义 318），否则降级为观测证据；
(v) **补偿有界**：结构化补偿受信任域约束，拟合残差超阈即退回 R69（定义 316、322）。

**定义 311（意图传输模型 ITM）** 隐意图 m ∈ ℳ；表达行为/回答 y。设
y = T_ψ(m, φ, h, w) + ε，T_ψ = T_nom(m) + T_struct(φ) + T_hyst(m, h) + T_deg(w)，
其中 φ 为可测参考相位，h 为交互历史（迟滞状态），w 为累积损伤，ψ 为传输参数；T_nom 名义映射，T_struct 相位锁定系统误差，T_hyst 迟滞算子，T_deg 退化漂移，ε 为噪声。

**定义 312（相位参考与结构化误差）** 参考相位 φ_t 可测（步态/任务/关节相位）。结构化误差 e_struct(φ) = T_struct(φ) 是周期或光滑函数，可傅里叶/查找表表示。定义结构化 epistemic 分量 U_epi-struct = Var[y − T̂_struct(φ) | 单模态]，即**拟合后残差**。它既非不可约（可学），也非多模态歧义（单模态），故走补偿通道。

**定义 313（三通道不确定性分解）** 升级定义 297：U_ale = Σ_k ŵ_k tr(Σ_k)（模态内噪声）；U_epi-amb = H_mode·g(Δ_min)（模态间歧义）；U_epi-struct = Var[y − T̂_struct(φ)|单模态]（相位锁定系统残差）。三者语义不同、**不简单相加**，分别进入 λ floor / VoI / 前馈补偿三条处置通道（定义 307、316）。

**定义 314（迟滞意图变化检测 HCD）** 用 Bouc–Wen / Preisach 型迟滞算子 ℋ_B（死区宽 B）刻画意图表达：设 Δ 为后验充分统计量的变化，仅当 |Δ| > B 且持续 τ_hold 才判为真实意图变化；死区内波动视为测量噪声，**不触发 VoI**。B 由每位用户/语境的迟滞环在线标定。

**定义 315（累积损伤锚 CDA）** 单调不减状态 w_t：w_t − w_{t−1} = γ·D(e_t, φ_t) ≥ 0，D 为损伤增量（如**相对冻结名义模型**的预测误差、交互应力代理）。**w 永不被 COF 标定重置或回退**。它提供标定不可吸收的见证：标定能把当下的残差 r_res 抹到 0，却不能使 w 下降。故障嫌疑当 w 越过磨损阈值，或其**速率 ẇ** 异常。

**定义 316（结构化补偿通道 SCD）** 离线/在线学习 e_struct(φ)（傅里叶表或小网络），对策略条件与风险缩放施加**前馈校正**，把系统分量从 U 中扣除 → 不靠交互就获得 resolution bonus。补偿受信任域 ‖校正‖ ≤ ε_comp 约束；若拟合残差 > τ_struct，则禁用补偿、退回 R69（定义 322）。

**定义 317（结构化微干预 SMI / 波发生器式探询）** 不用开放问句，而选**有设计的干预** δ（受控二选一、正交小提议、受控手势），使响应能识别 T_ψ 对 m 的局部斜率，从而把诱导偏差与真实意图分离。δ 在试验间随机化/平衡以实现辨识；安全性同 R69 定义 302（过 C-RAS-WM 前缀认证）。

**定义 318（因果意图推断 ICI）** 用干预后验 p(m | do(g), y, ψ)。响应模型 ψ 含顺从度 κ、诱导/锚定偏差 β_lead、策略性回答 s。**准入条件**：(i) ψ 可辨识（来自随机化微干预的秩条件 rank ≥ dim m）；(ii) 实测诱导偏差界 |β_lead| ≤ τ_lead。任一不满足 ⇒ 该证据仅作观测证据，不得单独消解模态（退回 R69 k-一致 + 保守）。

**定义 319（软预载承诺 SPC）** 维持后验 p(m|·)；仅当某模态 p_max > 1−δ 且持续 τ_hold 才承诺；否则保持软预载（分布式啮合）并继续累积证据。切换因此平滑无抖振（无背隙式突变），单源投毒无法把 p 翻过回滞带。

**定义 320（载荷分担证据）** 证据流集合 ℰ；每条流权重上限 w_max，承诺用载荷分担聚合；毒化一条流对聚合的改变 ≤ 其载荷份额。这是「精度来自分散接触」的形式化，也是 R69 证据纪律的连续力学版。

**定义 321（结构-退化分离对偶）** 升级定义 309：联合模式 (r_res, Δa, ẇ) 可分离三类——**真慢漂移**（r_res 可升、ẇ 平）、**设计内柔顺**（r_res 平、ẇ 平）、**被标定吸收的隐性退化**（r_res↓ 而 ẇ↑）。单调 w 是标定无法吸收的判别量。

**定义 322（传输校准门 TCG）** 计算 ITM 拟合残差；残差 > τ_trans ⇒ 传输模型本身不可信 ⇒ 关闭补偿与干预式证据，退回 R69 保守（与 R69 MCG 同构，但发生在传输层而非模态层）。

**定义 323（迟滞感知交互预算 HIB）** 升级定义 293-ii / R69 预算：预算按**回滞带出带次数**计，而非按每次波动计；交互疲劳成本随交互率上升，设最小干预间隔；保证 24h 长时程稳定。

**定义 324（证书 J_HARMONIC）** J_HARMONIC = (J_FLUID, U_epi_struct, struct_fit_residual, w_damage, w_rate, leading_bias_bound, identification_rank, hysteresis_B, spc_margin, harmonic_ver)。Valid ⇔ Valid(J_FLUID) ∧ 拟合残差达标 ∧ CDA 单调 ∧ 可辨识 ∧ 非诱导。

**定义 325（安全集成）** 所有干预（开放问句与结构化微干预）过 C-RAS-WM 前缀认证（R69 定义 302）；结构化补偿受信任域约束；模态切换经 SPC 满足平滑性（R69 定理 17 / R68 定理 15），控制连续无突变。

**定义 326（退化与三级严格包含）** 令 U_epi-struct := 0 并关闭补偿 ⇒ 逐指令退化为 FLUID-RAS（R69）；再令 VoI ≤ 成本或关闭交互 ⇒ 退化为 R68。故 HARMONIC-RAS ⊋ FLUID-RAS ⊋ R68 三级包含，安全侧逐级不让步。

```python
# IP-264 ITM：意图传输模型（名义 + 相位锁定 + 迟滞 + 退化），复用 R69 的 z_t / 证据流
class IntentTransmissionModel:
    def __init__(self, nom, struct_table, hyst, deg, phase_est):
        self.nom, self.struct = nom, struct_table      # e_struct(phi)
        self.hyst, self.deg     = hyst, deg            # h(m,h) / d(w)
        self.phase              = phase_est

    def predict(self, m, h):
        phi = self.phase.estimate()                    # 可测参考相位
        return (self.nom(m) + self.struct(phi)
                + self.hyst.step(m, h) + self.deg(self.w))

    def residual(self, y, m, h):
        return y - self.predict(m, h)

# IP-265 SUD：三通道分解（在 R69 decompose 之上加 struct 残差）
def decompose3(samples, y, itm, m_hat, h):
    U_ale, U_epi_amb, modes = r69_decompose(samples)
    fit = itm.struct.fit_residual(itm.phase)           # 相位锁定可解释部分
    U_struct = var(itm.residual(y, m_hat, h))          # 单模态下系统残差
    return U_ale, U_epi_amb, U_struct, modes, fit

# IP-266 SCD：相位前馈补偿（受信任域约束；拟合残差超阈即禁用）
def structured_compensate(itm, o, z, trust):
    phi = itm.phase.estimate()
    corr = itm.struct(phi)
    if norm(corr) > trust.eps_comp or itm.struct.fit_residual > TAU_STRUCT:
        return None                                    # 不回退：交给 R69 通道
    return { 'z': z - corr.encode(z), 'phi': phi, 'corr': corr }

# IP-267 HCD：迟滞死区门控（真正出带且持续才触发交互）
def intent_changed(posterior, hyst, stats, h):
    stat = sufficiency(posterior)                       # 充分统计量
    if abs(stat - hyst.last) <= hyst.B:                 # 死区内：噪声，不问
        return False
    return persistence_exceeded(stats, hyst.B, hyst.tau_hold)

# IP-268 CDA：单调损伤锚（相对冻结名义模型；标定不可重置）
def damage_update(w_prev, y, itm_nominal, phi):
    D = squared_error(y, itm_nominal.predict_frozen(phi))
    return w_prev + GAMMA * D                           # 只增不减，COF 无权修改

# IP-269 SMI：结构化微干预（波发生器式：已知激励以识别局部斜率）
def choose_micro_intervention(modes, w, budget):
    cands = balanced_designs(modes)                     # 正交/二选一/受控手势
    for d in cands:
        if not budget.allow(d) or not c_ras_wm.certify_info(d, o): continue
        gain = expected_slope_information(w, d)         # 设计矩阵的信息增益
        if gain > 0 and leading_bound(d) <= TAU_LEAD:
            return d
    return None

# IP-270 ICI：因果意图推断（辨识 + 诱导偏差双检）
def causal_intent_update(posterior, do_g, y, psi):
    if not psi.identified() or psi.leading_bound() > TAU_LEAD:
        return observational_update(posterior, y), 'downgraded'
    return bayes_do(posterior, do_g, y, psi), 'admitted'

# IP-271 SPC：软预载承诺（回滞带 + 持续期；无背隙式抖振）
def soft_preload_select(posterior, hyst):
    m = argmax(posterior)
    if posterior[m] > 1 - DELTA and hyst.held(m) > hyst.tau_hold:
        return commit(m)
    return soft_preload(posterior)                      # 继续分布载荷、累积证据

# IP-274 主闭环（继承 R69；仅在分解与交互处置处插入 HARMONIC 层）
def HARMONIC_RAS_round(M, obs):
    z, o = M.mtm.forward(...)
    c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_amb, U_struct, modes, fit = M.sud.decompose3(samples, M.last_y, M.itm, M.m_hat, M.h)
    # 1) 结构化补偿：能建模的不要问、也不要一味减速
    sc = M.scd.structured_compensate(M.itm, o, z, M.trust)
    if sc is not None:
        z, U_struct = sc['z'], 0.0
    # 2) 单调损伤见证（标定不可吸收）
    M.w = M.cda.damage_update(M.w, M.last_y, M.itm.nom, M.itm.phase.estimate())
    hidden_deg = (M.w_rate() > TAU_WRATE) and (M.last_r_res < TAU_RES)
    # 3) 迟滞门控：只在真正意图改变时考虑交互
    need = M.hcd.intent_changed(M.posterior, M.hyst, M.stats, M.h) and (U_amb > TAU_EPI)
    g, kind = None, None
    if need and M.budget.allow_band_exit():
        g = M.smi.choose_micro_intervention(modes, M.posterior, M.budget)   # 优先结构化
        kind = 'smi' if g is not None else 'ask'
        if g is None:
            g = M.mint.choose_interaction(modes, M.posterior, o, M.budget)
    if g is not None:
        ans = M.cia.execute(g)
        M.posterior, status = M.ici.causal_intent_update(M.posterior, g, ans, M.psi)
    # 4) 风险缩放：噪声 + 未消解歧义进 λ；结构化分量已被前馈扣除
    U_floor = U_ale + (U_amb if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    if hidden_deg:
        lam = max(lam, 0.8); k = min(k, k_cal_shrink(x_prime, U_cal))        # 回 R69 最保守
    # 5) 软预载承诺，平滑切换
    mode = M.spc.soft_preload_select(M.posterior, M.hyst)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    # 6) 审计 + 证书
    M.vqa_i.submit_async(g, kind, status, U_struct, M.w, M.psi.leading_bound())
    return k, lam, mode, (U_ale, U_amb, U_struct, M.w)
```

## 3. 推导

**引理 19（相位锁定误差的可补偿性与增益界）** 设 e_struct(φ) 关于 φ 为 L-Lipschitz，相位估计误差 |φ̂−φ| ≤ δφ，拟合残差 sup|e−ê| ≤ ρ_s。则前馈补偿后的残余系统误差 ≤ L·δφ + ρ_s；相较不补偿，期望任务风险下降 ≥ c·(Var[e_struct] − (L·δφ+ρ_s)²) 的正部。**系**：补偿收益正比于「可解释方差」减去「相位估计不可靠度」；若相位不可测（δφ 无界），补偿必须关闭（退回 R69）——这解释并约束了定义 316 的信任域。

**引理 20（迟滞死区抑制无效交互的最优带宽）** 设意图表达的小幅波动 ~ N(0, σ_n²)，真实意图变化幅度 Δ_s，死区宽 B。则被死区挡掉的伪交互比例 = P(|波动| ≤ B)，而真实变化被漏检的概率 = P(Δ_s + 波动 ∈ 带内)。存在最优 B* 使「交互后悔」= 伪交互成本·P(伪) + 漏检成本·P(漏) 最小，且 B* 随 σ_n/Δ_s 增大。**系**：当 Δ_s 小（模糊不可分）时 B* 使系统**不问**——与 R69 引理 16 的「不可分就别问」在机制层一致，但这里是靠死区而非靠 Δ_min。

**引理 21（交互证据的因果准入条件）** 设回答 y = T(m, g) + β_lead·g + ε。若响应模型未辨识或 |β_lead| 未知，则仅凭观测交互得到的后验 p(m|y,g) 与真实干预后验 p(m|do(g),y) 相差一个由 β_lead 线性平移的偏置。故错误模态采纳率的下界 ≥ β_lead/(Δ_min + β_lead)（两模态时）；当 Δ_min 小、β_lead 大时，**任何提问都无助于定案**。**系**：定义 318 的双检不是保守冗余，而是把 R69 的「k 个独立源」修正为「k 个可辨识、非诱导的源」——否则 k 再大也只是同一个偏差的复制。

**定理 18（三级严格包含与安全单调）** 在 A99–A102 下，HARMONIC-RAS 在任意状态的期望风险 ≤ FLUID-RAS ≤ R68；且当 U_epi-struct=0/补偿关闭、VoI ≤ 成本、ECE 越界、hidden_deg 成立时逐指令相同。三级退化边界明确，安全侧永不弱于前代。

**定理 19（单调损伤锚的不可吸收性）** 设 w 定义为相对**冻结名义模型**的预测误差累积，标定算子 C 只作用于在线残差 r_res 与在线模型参数，不改变冻结模型、且 w 只增。则对任意标定 C，隐性退化都会使 ẇ>0，而 r_res 可被 C 压到 ≈0；故 (r_res↓, ẇ↑) 是标定无法消除的联合见证（定义 321）。相较 R69 的 Δa（点残差），ẇ 是**积分量**，连一阶导都抹不掉。

**定理 20（软预载切换的无抖振与投毒鲁棒）** SPC 在回滞带 B>0、持续期 τ_hold 下，模态切换频率有界（无 chatter）；单源投毒对载荷分担聚合的改变 ≤ 其权重份额 w_max，故翻不过回滞带，除非投毒份额 > 1−δ。**系**：R69 把「精度来自 k 源一致」当离散投票，本轮把它变成连续载荷分担——精度来自**分散的弱接触**，单点失效不致命。

## 6. 本轮最大风险

**一句话**：HARMONIC-RAS 用「结构化误差可补偿 + 回答可去偏」换取效率，但整套机制押在**参考相位可观测、传输结构可辨识**上；一旦相位不可测、或**真实意图变化在统计上长得像相位锁定误差**，补偿就会把真实变化当作传输误差**减掉**，因果去偏也会把真实信号当作诱导偏差**抹平**——系统从 R69 的「问错」升级为「**自信地看不见变化**」（phantom stability），而这比问错更难被审计发现，因为它留下的残差和损伤锚都看起来「正常」。

**次级风险与缓解**：
1. **相位的不可观测性** → 引理 19 的 δφ 界 + 定义 316 信任域：相位不可测即关闭补偿、退回 R69；E301/E310 显式检验。
2. **补偿吞掉真实意图变化** → 定义 314 迟滞门控与定义 321 的 ẇ 分离；补偿只扣「单模态内的相位锁定残差」，不跨模态扣。
3. **因果模型不可辨识却假装可辨识** → 定义 318 的秩条件 + 随机化微干预；秩不足即降级为观测证据（引理 21）。
4. **损伤锚被设计漏洞清零** → 定理 19 要求 w 定义在**冻结名义模型**上、且 COF 无权写 w；代码层审计（E304/E313）。
5. **结构化微干预本身越界或诱发操纵** → 定义 317/325 过 C-RAS-WM + 平衡设计 + E306/E312。
6. **退化边界被新层悄悄破坏** → 定理 18 + E308 的逐指令一致性回归测试。

**定义 321（结构-退化分离对偶）** 联合模式 `(r_res, Δa, ẇ)` 分离真漂移（r_res↑、ẇ平）/设计内柔顺（r_res平、ẇ平）/被标定吸收的隐性退化（r_res↓、ẇ↑）。

**定义 324–326（证书/安全/包含）** `J_HARMONIC` 并入 struct 残差、w/ẇ、诱导界、辨识秩、B；干预过 C-RAS-WM、补偿受信任域、切换经 SPC 平滑；令 `U_epi-struct=0` 并关补偿退 FLUID，再关交互退 R68 ⇒ 三级严格包含。

## 3. 关键算法伪代码

```python
# IP-264 ITM：意图传输模型（名义 + 相位锁定 + 迟滞 + 退化）
class IntentTransmissionModel:
    def predict(self, m, h):
        phi = self.phase.estimate()
        return (self.nom(m) + self.struct(phi)
                + self.hyst.step(m, h) + self.deg(self.w))
    def residual(self, y, m, h): return y - self.predict(m, h)

# IP-265 SUD：三通道分解
def decompose3(samples, y, itm, m_hat, h):
    U_ale, U_amb, modes = r69_decompose(samples)
    U_struct = var(itm.residual(y, m_hat, h))            # 单模态下系统残差
    return U_ale, U_amb, U_struct, modes, itm.struct.fit_residual

# IP-266 SCD：相位前馈补偿（信任域；坏拟合即禁用）
def structured_compensate(itm, z, trust):
    corr = itm.struct(itm.phase.estimate())
    if norm(corr) > trust.eps or itm.struct.fit_residual > TAU_STRUCT: return None
    return z - corr.encode(z), corr

# IP-267 HCD：迟滞死区门控（死区内不问）
def intent_changed(posterior, hyst, stats):
    if abs(sufficiency(posterior) - hyst.last) <= hyst.B: return False
    return persistence_exceeded(stats, hyst.B, hyst.tau_hold)

# IP-268 CDA：单调损伤锚（冻结名义模型；标定不可重置）
def damage_update(w, y, nom_frozen, phi):
    return w + GAMMA * squared_error(y, nom_frozen.predict(phi))   # 只增

# IP-269 SMI：结构化微干预（波发生器式已知激励）
def choose_micro_intervention(modes, w, budget):
    for d in balanced_designs(modes):
        if not budget.allow(d) or not c_ras_wm.certify_info(d, o): continue
        if leading_bound(d) > TAU_LEAD: continue
        if expected_slope_information(w, d) > 0: return d
    return None

# IP-270 ICI：因果意图更新（辨识 + 诱导偏差双检）
def causal_intent_update(post, do_g, y, psi):
    if not psi.identified() or psi.leading_bound() > TAU_LEAD:
        return observational_update(post, y), 'downgraded'
    return bayes_do(post, do_g, y, psi), 'admitted'

# IP-271 SPC：软预载承诺（回滞带 + 持续期）
def soft_preload_select(post, hyst):
    m = argmax(post)
    if post[m] > 1 - DELTA and hyst.held(m) > hyst.tau_hold: return commit(m)
    return soft_preload(post)                            # 继续累积、平滑

# IP-274 主闭环（继承 R69）
def HARMONIC_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_amb, U_struct, modes, fit = M.sud.decompose3(samples, M.last_y, M.itm, M.m_hat, M.h)
    sc = M.scd.structured_compensate(M.itm, z, M.trust)
    if sc is not None: z, U_struct = sc[0], 0.0
    M.w = M.cda.damage_update(M.w, M.last_y, M.itm.nom, M.itm.phase.estimate())
    hidden = (M.w_rate() > TAU_WRATE) and (M.last_r_res < TAU_RES)     # 标定不可吸收
    need = M.hcd.intent_changed(M.posterior, M.hyst, M.stats) and U_amb > TAU_EPI
    g = None
    if need and M.budget.allow_band_exit():
        g = M.smi.choose_micro_intervention(modes, M.posterior, M.budget)
        if g is None: g = M.mint.choose_interaction(modes, M.posterior, o, M.budget)
    status = 'none'
    if g is not None:
        M.posterior, status = M.ici.causal_intent_update(M.posterior, g, M.cia.execute(g), M.psi)
    U_floor = U_ale + (U_amb if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    if hidden: lam = max(lam, 0.8); k = min(k, k_cal_shrink(x_prime, U_cal))
    mode = M.spc.soft_preload_select(M.posterior, M.hyst)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_i.submit_async(g, status, U_struct, M.w, M.psi.leading_bound())
    return k, lam, mode, (U_ale, U_amb, U_struct, M.w)
```

## 4. 推导

**引理 19（相位锁定误差补偿增益界）** `e_struct` 关于 φ 为 L-Lipschitz，相位误差 ≤ δφ、拟合残差 ≤ ρ_s ⇒ 补偿后系统误差 ≤ `L·δφ+ρ_s`，风险下降 ≥ `c·(Var[e_struct]−(L·δφ+ρ_s)²)_+`。系：相位不可测 ⇒ 必须关补偿、退回 R69（对应定义 316 信任域）。

**引理 20（迟滞死区的最优带宽）** 波动 ~ `N(0,σ_n²)`、真实变化 `Δ_s`、死区 `B`：伪交互比例 `P(|·|≤B)`，漏检 `P(Δ_s+·∈带内)`；存在 `B*` 最小化交互后悔，且 `B*` 随 `σ_n/Δ_s` 增大。系：`Δ_s` 小（模糊不可分）时死区使系统**不问**，与 R69 引理 16 机制一致但更强（不依赖 Δ_min）。

**引理 21（因果准入条件）** `y=T(m,g)+β_lead·g+ε`；若 ψ 未辨识或 `β_lead` 未知，观测后验与干预后验相差 `β_lead` 线性平移，两模态错误采纳率下界 ≥ `β_lead/(Δ_min+β_lead)`。系：定义 318 双检把 R69 的「k 独立源」修正为「k 可辨识且非诱导的源」。

**定理 18（三级严格包含与安全单调）** A99–A102 下 `Risk(HARMONIC) ≤ Risk(FLUID) ≤ Risk(R68)`；当 `U_epi-struct=0`/补偿关闭、`VoI≤成本`、ECE 越界、`hidden` 成立时逐指令相同。

**定理 19（损伤锚不可吸收）** w 定义在**冻结名义模型**上、只增、COF 不可写；则隐性退化使 `ẇ>0` 而 `r_res` 可被压到 ≈0 ⇒ `(r_res↓, ẇ↑)` 为标定不可消除见证；相较 R69 的点残差 Δa，`ẇ` 是积分量，连一阶导都抹不掉。

**定理 20（软预载无抖振与投毒鲁棒）** `B>0`、持续 `τ_hold` ⇒ 切换频率有界（无 chatter）；单源投毒对载荷分担聚合改变 ≤ `w_max`，翻不过回滞带，除非份额 > `1−δ`。

## 7. 本轮最大风险

**一句话**：HARMONIC-RAS 用「结构化误差可补偿 + 回答可去偏」换效率，但押在**相位可观测、传输结构可辨识**上；一旦相位不可测、或**真实意图变化长得像相位锁定误差**，补偿会把真实变化当传输误差减掉、因果去偏会把真实信号当诱导偏差抹平——系统从 R69 的「问错」升级为「**自信地看不见变化**」（phantom stability），且残差与损伤锚都看似正常，比问错更难被审计发现。

**次级风险与缓解**：相位不可观测（引理 19 的 δφ 界 + 定义 316 信任域，E301/E310）；补偿吞掉真实变化（定义 314 迟滞门控 + 定义 321 的 ẇ 分离，只扣单模态内相位残差）；因果模型伪辨识（定义 318 秩条件 + 随机化微干预，秩不足即降级）；损伤锚被漏洞清零（定理 19 冻结名义模型 + COF 无权写 w，E304/E313）；微干预越界或操纵（定义 317/325 + 平衡设计，E306/E312）；退化边界被破坏（定理 18 + E308 逐指令回归）。
