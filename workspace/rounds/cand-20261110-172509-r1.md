# 第 44 轮（新循环第 4 轮） · Generalization-Cert × Usability-Cert：把「跨物体泛化」与「可用性评估」纳入证书的二维前沿（四层架构 v9）

> 承接第 43 轮 v8（Persona-Cert × Concurrent-Cert）。v8 自陈最大风险是「共形只保边际覆盖 + 多用户契约空集」，但它仍压着两个更深的未言明假设：**(H1) 证书的「有效域」被默认为已测物体/已测场景的集合**——安全性只在 E87–E94 的测试物体上被验证为 sound，而真实部署会连续遇到新物体、新组合；跨物体时「视觉相似 ≠ 动力学相似」，泛化可能是**静默的分布外失效**。**(H2) 「可用性」被偷换成 Nominal 占比/无违例率**——从未真正测量人类可用性（任务成功、干预负担、信任校准、认知负荷），而均值会掩盖「可用性悬崖」。本轮灵感词「跨物体泛化」「可用性评估」精确命中这两个假设：**跨物体泛化**把证书从「点」升级为「带有效域与泛化半径的集合」；**可用性评估**把目标从「只求 sound」升级为「在一个可认证的物体等价类 × 人格上，联合保证 sound 且 usable」。二者耦合处是本轮真正的新问题：**泛化半径越宽 → 可用性越高但迁移证书越易失真；越窄 → 越 sound 但可用性崩塌**，因此必须显式给出「安全–泛化–可用性」三维前沿，而不是单点声明。

## 0. 直觉与动机

**灵感 1（跨物体泛化 → 证书不是点，是带半径的「有效域」）**：直觉上，把「杯子」上标定好的抓取/碰撞证书搬到「马克杯/纸杯/塑料杯」时，如果只看外观相似就默认成立，那是把**视觉等价**误当成**动力学等价**——质量、摩擦、可变形性、可供性都可能不同。因此证书必须携带**有效域 D_c 与泛化半径 ρ(c)**：只在物体表示空间中距离 ≤ ρ 的等价类内 sound，超出则必须重新认证。迁移不是「复制证书」，而是「用 Lipschitz/加权共形给出迁移后的边际退化界 Δm = L_m·γ(ρ)」，当退化后被侵蚀到阈值以下就拒绝迁移。

**灵感 2（可用性评估 → 从「没有违例」到「人能不能用」）**：直觉上，一个「永不违例」的系统可以永远停机——它绝对 sound，但零可用。可用性评估（Nielsen 任务成功率/时间/错误率、SUS、NASA-TLX 认知负荷、信任校准）要求我们量化：任务成功率、回退率、干预负担、达时、信任校准误差、认知负荷。并加两条：**(a) 条件可用性**——按物体等价类 × persona 评估**最坏情况**而非均值；**(b) 可用性下界 u_min**——任何回退阶梯的每一级都必须 u ≥ u_min，否则升级人工，绝不「静默降级到不可用」。

**灵感 3（耦合 → 安全–泛化–可用性三维前沿与认证运营曲线）**：保守性 λ、泛化半径 ρ、可用性 U 构成一条可测绘的**认证运营曲线（certificate operating curve）**：每提高一档保守性，违例率下降但可用性下降；每放宽 ρ，可用性上升但迁移风险上升。因此本轮不追求「单点最优」，而是输出 **Pareto 前沿 + 选定工作点 + 可审计的回退阶梯**，并把「跨物体 × persona 的不可用矩阵」作为一等公民。耦合升级：OEC 把物体编译成带有效域的迁移证书；UEE 在等价类 × 人格上评估最坏可用性；OGV 用跨物体/组合 fuzz 测绘前沿并回灌 CKB/SCV。

## 1. 形式化定义（增量：定义 44–49）

**定义 44（物体因子表示与任务条件等价类）**：物体 o 经 VLM+3D 编码为因子表示 φ(o)=(g, a, d, s)（几何、可供性、动力学、语义），任务 τ 下的度量 d_φ^τ 由任务相关因子加权。等价类 [o]_δ^τ = {o' : d_φ^τ(φ(o),φ(o')) ≤ δ}。**注**：跨物体泛化只在 [o]_δ^τ 内被允许；语义相似不作为等价依据。

**定义 45（泛化证书与有效域）**：证书 c=(pred_c, θ_c, D_c, ρ(c), γ_c, L_m)，其中 D_c = [o_c]_ρ(c) 为有效域（可并多球），γ_c:[0,ρ]→R≥0 为动力学–表示失真上界：∀o'∈D_c，|d(o')−d(o_c)| ≤ γ_c(ρ)。**迁移边界理**：若监测量的 Lipschitz 常数为 L_m，则 o' 上的边际下界 m(o') ≥ m(o_c) − L_m·γ_c(ρ)。**推论**：当 m(o_c) − L_m·γ_c(ρ) ≥ θ_c 时迁移 sound；否则 c 在 o' 上不可用，必须降级或重认证。

**定义 46（泛化间隙与分布无关迁移风险）**：在物体层用加权共形（对象类分层 + 协变量偏移权重）构造迁移风险上界 R_gen(δ) = P_{o'~O_novel}(o'∉D_c ∨ violation | o'∈D_c)。**泛化间隙** Gap_gen = 经验域内违例率 − 证书声明的违例率；要求 |Gap_gen| ≤ ε_gen 且拒绝率 P(o'∉D_c) ≤ β。**关键**：这不是像素 OOD，而是「动态失真 + 可供性误配」的条件风险。

**定义 47（可用性向量与条件下界）**：可用性 U=(SR 任务成功率, FR 回退率, IB 干预负担, TTG 达时超限率, TCE 信任校准误差, CL 认知负荷)。**条件可用性** U_{[o]_δ^τ, u} 是该等价类 × persona 上的最坏值（分位数/最坏场景），而非均值。**可用性可行域**：U ≥ u_min（逐分量），u_min 由任务 × 风险等级给出。**可用性悬崖**：一致 δ 小区间内 U 的断崖式下降点，必须被 OGV 显式测绘。

**定义 48（认证运营曲线与三维前沿）**：给定保守性旋钮 λ（租约衰减/阈值上浮/ρ 收缩），得到点 (Violation(λ), Gap_gen(λ), U(λ))。**认证运营曲线**是 λ 的参数曲线；**可行工作点**集 W = {λ : Violation=0 ∧ |Gap_gen|≤ε_gen ∧ U≥u_min}。**命题**：若 W≠∅，可选最可用点运行；若 W=∅，必须回到「逐物体重认证」或「人工接管」，禁止在不可行区运行。

**定义 49（可认证迁移阶梯与联合保证）**：回退阶梯 L_0 ≻ L_1 ≻ … ≻ L_k，能力单调递减、每级携带可用性下界 U_i 与有效域 D_i。**阶梯契约**：∀i，若物体 o'∈D_i 且 U_i ≥ u_min 则允许在 L_i 运行；若不存在这样的 i，则升级人工。**联合保证定理**：若 (a) 每级证书在 D_i 内 sound（定义 45），(b) 每级 U_i 由条件可用性下界给出（定义 47），(c) 阶梯切换只降能力、不改安全谓词，则在 D_i 上的运行同时满足 sound 与 usable；切换点处 sound 保持（复用定义 42 只删不增）。**与人格耦合**：若对象–人格对 (o',u) 的可用性矩阵项 < u_min，则触发协商而非静默运行。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 OBJECT-EQUIVALENCE-CERTIFICATE ENGINE（跨物体泛化证书引擎 OEC）
1. **因子化物体表示**：φ(o)=(g,a,d,s)，VLM 可供性 + 3D 几何 + 动力学先验；任务条件度量 d_φ^τ。
2. **有效域与泛化半径**：证书携带 D_c、ρ(c)、γ_c、L_m；迁移前做边界理检查，不满足即拒绝迁移。
3. **加权共形迁移证书**：对象类分层 + 协变量偏移权重，输出 R_gen 上界与拒绝率 β。
4. **证书索引**：CKB 指纹增物体等价类 + 可供性签名；检索返回「证书 + 有效域」，域外拒答。

### 2.2 IP-61 USABILITY-EVALUATION ENGINE（可用性评估引擎 UEE）
1. **可用性仪器**：任务成功率/回退率/干预负担/达时/信任校准/NASA-TLX；自动日志 + 人因量表双通道。
2. **条件可用性估计**：按 [o]_δ^τ × persona 分层估计最坏值；报告可用性下界与悬崖点，禁止只报均值。
3. **可用性预算**：u_min 逐任务定义；回退阶梯每级必须带 U_i，低于 u_min 即升级人工。
4. **认证运营曲线**：扫描保守性 λ，输出 (Violation, Gap_gen, U) 前沿与选定工作点，交认证/运营审计。

### 2.3 IP-62 OBJECT-GENERALIZATION-VALIDATOR（跨物体泛化验证器 OGV）
1. **跨物体/组合采样**：新物体、物体–物体组合、可供性歧义、对抗性材质/质量扰动。
2. **泛化前沿测绘**：ρ 扫描 → 违例率/拒绝率/可用性；定位可用性悬崖与最小安全半径。
3. **可用性回归**：分布漂移下任务成功率/干预负担回归，检出版本退化。
4. **双回路反例回灌**：违例 → CKB 扩等价类/记失效域；可用性悬崖 → SCV 课程加物体变体。

## 4. 实验设计（E95–E102 硬门槛，承接 E87–E94）

| 实验 | 指标 | 门槛 |
|---|---|---|

回退：E95/E96 迁移失真 → 关闭跨物体迁移，逐物体重认证；E97 漂移检测不达标 → 强制短周期全量重认证；E98 可用性测量不可信 → 只用人因真值、停用自动 U；E99 无可行工作点 → 收缩任务域或提升人工接管；E100/E101 可用性崩塌 → 收窄等价类 + 单一保守档；任何红线失败 → 全链路熔断回退 v8。

## 5. 本轮最大风险

**一句话**：物体等价类由视觉/可供性表示空间定义，但声明的失真上界 γ_c(ρ) 未必真能界住动力学差异（看起来像、质量/摩擦/可变形性不同），一旦 γ_c 被低估，迁移证书会在域内静默失真；再叠加可用性只在有限物体样本上估计，会同时制造「域内假 sound + 假 usable」——因此 E95/E96 必须用真实物体变体验证动力学失真界并设为红线，默认回退是「逐物体重认证 + 串行安全监控」。

| W | 可行工作点集 | Violation=0 ∧ \|Gap_gen\|≤ε ∧ U≥u_min |
| L_0≻…≻L_k | 迁移阶梯 | 能力单调递减、每级带 U_i 与 D_i |

### IP-60 OEC：因子化、有效域与迁移证书
```
def factorize_object(o):
    g = geometry_3d(o); a = vlm_affordance(o)
    d = dynamics_prior(o); s = vlm_semantic(o)
    return Phi(g, a, d, s)

def equivalence_class(phi_o, task, delta):
    # 任务条件度量；语义相似不作为等价依据（定义 44）
    return Ball(center=phi_o, radius=delta, metric=task_metric(task))

def transfer_certificate(cert, o_new, rho, L_m):
    if not in_domain(o_new, cert.D_c):
        return NoTransfer("outside_domain")           # 域外拒答，不静默迁移
    gamma = cert.gamma(rho)                            # 动力学-表示失真上界
    m_new = cert.m - L_m * gamma                       # 迁移边界理，定义 45
    if m_new < cert.theta:
        return NoTransfer("margin_eroded")             # 边界理击穿，拒绝
    return cert.with_margin(m_new).with_domain(ball(o_new, rho))

def weighted_conformal_transfer(scores, weights, alpha):
    # 对象类分层 + 协变量偏移权重（定义 46）
    q = weighted_quantile(scores, 1 - alpha, weights)
    return RiskBound(alpha=alpha, q=q, reject_rate=estimate_reject(weights))
```

### IP-61 UEE：可用性向量、条件下界与运营曲线
```
def usability_vector(trace, human_study):
    return U(success_rate(trace), fallback_rate(trace),
             intervention_burden(trace), time_to_goal_over(trace),
             trust_calibration_error(human_study),
             cognitive_load(human_study))

def conditional_usability(traces, obj_class, persona, q=0.05):
    sel = [t for t in traces
           if t.obj_class == obj_class and t.persona == persona]
    return worst_quantile(U_from(sel), q)   # 最坏值，不报均值（定义 47）

def usability_ok(U, u_min):
    return all(U[k] >= u_min[k] for k in U) # 逐分量红线

def certificate_operating_curve(sweep_lambda, certs, objs):
    pts = []
    for lam in sweep_lambda:
        viol, gap, U = evaluate(certs, objs, lam)
        pts.append((lam, viol, gap, U))
    W = [p for p in pts if p.viol == 0
         and abs(p.gap) <= eps_gen and usability_ok(p.U, u_min)]
    return pareto_front(pts), (choose_max_usability(W) if W else None)
    # W 为空 => 不许运行，退回逐物体重认证/人工接管（定义 48）
```

### IP-51/58 升级：泛化感知的守卫与租约
```
def car_transition_guard_v9(e, x, cert, persona, lease, obj_shift, rho, t):
    theta = cert.alpha_e[e] * cert.theta_sim[e]
    m_lookup   = cert_lookup_L0(x).m_lo[e]
    m_lease    = lease.m - lease.lam * (t - lease.tau)
    m_persona  = persona_cap[e](persona)

    in_domain  = obj_shift <= rho
    return (in_domain and lease_valid(lease, theta, t)
            and min(m_lookup, m_lease, m_persona, m_transfer) >= theta)

def lease_with_generalization(task, x, rho, obj_shift):
```

## 5. 风险与缓解（增量）

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| γ_c(ρ) 低估动力学差异，域内迁移静默失真（视觉像≠动力学像） | 高 | E95/E96 红线；用真实物体变体校准 γ_c；域外一律拒答；默认逐物体重认证 |
| 可用性只在有限物体样本估计，均值乐观掩盖悬崖 | 高 | E98 构念效度；条件最坏分位；悬崖显式测绘；只用可信指标下结论 |
| 加权共形在协变量偏移下权重估计错误，R_gen 上界失效 | 高 | E96 红线；权重敏感性分析；偏移过大即拒绝迁移 |
| 等价类过宽导致假泛化，过窄导致可用性崩塌 | 中-高 | 运营曲线选工作点；ρ 自适应；W 空则回退重认证/人工 |
| 「可用性」指标彼此冲突（快 vs 稳 vs 少干预） | 中 | 多目标 Pareto；逐任务 u_min；不把可用性压成单一分数 |
| 迁移阶梯切换瞬间能力断崖，用户困惑/信任崩塌 | 中 | 每级 U_i 校验；切换提示与可解释；低于 u_min 直接升级人工 |
| 物体指纹/可供性签名索引错误，张冠李戴证书 | 中 | 契约哈希绑定物体类+硬件版本；部署前全量物体回归 |

## 6. 本轮最大风险

**一句话**：物体等价类由视觉/可供性表示空间定义，但声明的失真上界 γ_c(ρ) 未必真能界住动力学差异（看起来像、质量/摩擦/可变形性不同），一旦 γ_c 被低估，迁移证书会在域内静默失真；再叠加可用性只在有限物体样本上估计，会同时制造「域内假 sound + 假 usable」——因此 E95/E96 必须用真实物体变体验证动力学失真界并设为红线，默认回退是「逐物体重认证 + 串行安全监控」。
