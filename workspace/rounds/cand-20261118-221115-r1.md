# 第 2 轮（UniBot 线；本轮灵感：「可靠性」×「大语言模型」）

> **基线与编号**：第 1 轮 UniBot-SAGE v1（IP-01…IP-08；定义 U1–U12；引理 L1–L7；实验 E601–E618）继续有效，本轮**深化与修剪，不推倒重来**。新增 IP-09…IP-13、定义 U13–U24、引理 L8–L14、实验 E619–E636。
> **本轮转向**：第 1 轮把「抓取」做成隐变量、把「技能」做成路由、把「地形」做成推理期适配；本轮把这三件事收到一个更硬的问题上——**在只有有限真机试次、且评测分布被故意偏移的赛制里，怎样让「成功」是可重复、可校准、可审计的，而不是一次幸运的均值？** 一句话：**从「提高平均成功率」转向「提高成功率的下置信界与排名稳定性」，并让大语言模型只做「规格编译器 / 失败解释器」，不进入 100 ms 控制回路。**
> **情报复核（2026-11-18）**：官网首页与榜单页仍显示「即将发布 / Coming Soon」，`leaderboard_data.json` 仍是 teaser 占位表；32 任务 / 32,000 episodes / 169 h / 5 类泛化场景 / 单模型通才赛道均未变。失败检测方向在 2026 年快速升温：Foresight（arXiv 2606.23085）用动作条件世界模型隐变量 + 函数型 conformal 做长程失败检测；SAFECAST（2608.04246）用对比集增强隐状态探针与校准以对抗部署偏移；VLA-Tug（2611.08425）用轻量 latent probe + Learn-then-Test 给出 FPR/漏检界并预测失败模式；Hide-and-Seek（2605.30834）用粗监督做时序失败定位；NTU 2026 提出时间感知指标 AUTC；NVIDIA 2026 用世界模型不确定性监测双臂失败。**共同空白**：这些工作大多停在「检测 / 报警」，没有把检测变成**带风险预算的干预**，也没有在「单模型、单 API、有限试次、故意 OOD」的赛制里讨论**干预的净收益与合规性**。本轮填这个空白。

## 0. 一句话直觉

> **排行榜上的「29.7%」不是你的能力，而是一次带噪抽样；可靠性不是「再准一点」，而是「知道自己什么时候不可信，并且只在有把握时动手」。**

第 1 轮的 T1（终态成功是唯一货币）与 T3（断点在最后一环）仍然成立，但本轮补上第三条：**T4 计分器本身是低分辨率的**。在每任务试次 `n` 有限时，32 任务平均成功率的抽样标准差约为 `sqrt(mean_t p_t(1−p_t)/n)/sqrt(32)`；当 `n=10` 时约 2.4 个百分点——与第 1 名和第 2 名的差距（1.2 个百分点）同量级。因此：
- 追求「+1 分」的微调很可能只是在拟合噪声；
- 真正值得追求的是**能被有限试次分辨的 +3～5 分**，以及**把灾难性尾部失败（整条 episode 空抓 / 卡死 / 超时）压下去**；
- 任何「失败后重试 / 换抓法 / 改原语」的干预，都必须先证明它在**假阳性成本**下仍是正收益。

## 1. 直觉解释（先直觉，后定义；严格定义见产物区 §3）

### 1.1 灵感 1 ·「可靠性」：不是把均值做高，而是把下置信界做高

第一性原理：竞赛榜单是一个**估计量**，不是真值。它由「32 个任务 × 每任务 n 次 bernoulli 试次」构成，排名是对这个估计量排序。可靠性至少有三层，且常被混为一谈：

1. **统计可靠性**：同样的策略再跑一遍，排名会不会翻？——用 bootstrap / 二项重采样直接量化。
2. **校准可靠性**：模型说「我抓住了 / 我快失败了」时，这个置信度是否与真实频率一致？——用可靠性图、conformal、Learn-then-Test 量化。
3. **干预可靠性**：检测到异常后动手，是救回还是把可救的失败变成硬失败？——用不对称成本下的净收益量化。

第 1 轮的 IP-02 已经触及第 3 层，但只给了「高精度、低召回」的定性准则；本轮把它变成**可计算的风险预算**。

**本轮先做了两个便宜的机制检查（不是榜单证据，见产物区 §7）**：

- **排名稳定性**：把 teaser 的 8×32 成功率表当作结构，按每任务 `n` 次二项重采样。`n=10` 时，`P(第一名仍第一)=0.494`、`P(完整排名不变)=0.011`、平均名次漂移 1.03 位；`n=30` 时也只有 `0.640 / 0.052 / 0.63`。也就是说，**在 10–30 次/任务的真实预算下，榜首与第二名的 1.2 分差距基本不可分辨**。
- **朴素残差监测的假阳性**：在 12 个任务、30 条**真实成功演示**上，用「指令末端位置 vs 下一帧观测末端位置」的跟踪残差 + 双侧 CUSUM。全局中位数/MAD 归一化下，`h=4…12` 的**假阳性率均为 96.7%**；残差 z 分数的 99 分位中位数高达 8.55。含义很直接：**成功轨迹本身就充满大残差（加速、接触、换向），不做相位条件化的残差监测器会把几乎每条成功轨迹判成失败。** 这不是「再调一个阈值」能解决的，必须换信号（学习到的 latent probe）或换校准（分相位、conformal、ACI）。

这两个结果把本轮的立场钉死：**可靠性层不是免费的；一个未校准的可靠性层会让系统比没有它更差。**

### 1.2 灵感 2 ·「大语言模型」：让 LLM 写「规格与解释」，不让它写「电机指令」

第一性原理：LLM 在本题里的优势不是反应速度，而是**把自然语言任务编译成可检查的结构**；劣势是延迟、非平稳、幻觉与不可审计。官方接口的 per-step 预算与「动作统计规律性 / 可信度」审核，决定了**不可能让 LLM 每步参与控制**。因此正确的分工是：

- **离线（允许慢、允许贵）**：LLM 把 32 条语言指令编译成**类型化的接触模式自动机（CMA）**——状态是 reach / grasp / lift / transport / align / insert / place / release，边是带几何谓词的 guard，另加 recovery 边；LLM 同时从指令生成 **OOD 对比集**（背景 / 干扰物 / 未见物品 / 位置 / 人为遮挡）与失败模式解释，用于训练和校准小监测器。
- **在线（必须在 100 ms 内）**：只跑**蒸馏后的小验证器 / 小解释器**；LLM 最多作为一个**异步旁路**，以 1–2 Hz 或事件触发给出「子目标 / 风险提示」，且必须带时间戳、置信度和「过期即忽略」的硬规则。
- **红线**：LLM 的输出只能是**低维、可拒收、可回退**的调制信号（子目标 token、风险 token、恢复原语编号），不能直接生成关节动作；所有规格在提交前冻结，不读取评测侧信息。

一句话：**LLM 是「赛前教练 + 赛后复盘」，不是「场上运动员」。**

### 1.3 合成：给策略套一层「可靠性契约」

把三件事合成一个**外骨骼式**的可靠性层，包在第 1 轮的三层栈外面：

**规格层（LLM 离线编译）→ 监测层（小模型 + 相位条件化 + conformal）→ 干预层（带风险预算的重试 / 恢复 / 放弃）→ 路由层（按下置信界选专家）→ 审计层（bootstrap 排名区间、延迟平稳性、动作熵）**。

关键设计选择：

- **契约而非补丁**：每一层都必须能**单独关闭并精确退回基线**（第 1 轮的退化链 Level-0…Level-4 继续有效）；关闭后行为不是「差不多」，而是**逐位等价于基线分支**。
- **先证明再启用**：任何干预只有在「净收益的下置信界 > 0」时才启用；否则只记录、不动手。
- **LLM 规格可审计**：CMA 的每条 guard / recovery 边都能追溯到语言指令与公开数据统计；冻结后哈希上链（本地审计日志），防止「读题即硬编码」的质疑。
- **可靠性指标进入优化目标**：训练/选型时同时看均值、下置信界与 CVaR；不再用单一均值选 checkpoint。

## 2. 本轮研究问题（Q6–Q10）

- **Q6（排行榜的可分辨性）**：在真实试次预算下，32 任务平均成功率能把多小的真实差距分辨出来？给定 `n`，最小可检测差（MDD）是多少？我们应当把资源押在「+1 分」还是「+3～5 分 + 尾部」？
- **Q7（失败监测的可校准性）**：在只有 1 维夹爪、4 路 RGB、无触觉/力觉的接口下，能否用「相位条件化残差 + 学习到的 latent probe + 分相位 conformal」把假阳性压到 ≤5%，同时把检测延迟压到 ≤0.3 s？朴素残差监测的 96.7% 假阳性是信号问题还是校准问题？
- **Q8（LLM 规格编译的收益与合规）**：LLM 把指令编译成 CMA 后，guard 的精确率/召回率能否支撑「早停 + 恢复」？这算不算「按任务硬编码」？最严格的合规形态（只用语言 + 公开数据、提交前冻结、可一键关闭）还剩多少收益？
- **Q9（风险感知路由）**：把第 1 轮 IP-01 的「按均值选专家」改成「按下置信界 / CVaR 选专家」，在有限试次下能否提高排名稳定性？均值的代价是多少？
- **Q10（异步 LLM 监督的边界）**：LLM 旁路以 1–2 Hz 运行时，过期/拒收/幻觉对 p99 延迟与成功率的影响能否被硬界住？它带来的收益是否值得这份工程复杂度？

## 3. 设计原则（在第 1 轮 P1–P6 上追加）

- **P7 可靠性是契约，不是补丁**：每个可靠性组件必须有「关闭后逐位退回基线」的开关与可复现实验；没有退化路径的组件不允许上线。
- **P8 LLM 离线化**：LLM 只出现在训练前（规格编译、对比集生成、失败归因）与异步旁路（低频子目标/风险提示）；在线主回路不允许调用 LLM。
- **P9 无校准不干预**：任何重试 / 换抓 / 改原语，必须通过「净收益下置信界 > 0」的门槛；否则只记录。
- **P10 优化可分辨量**：不做小于当前 MDD 的指标追逐；以「排名稳定性 + CVaR + 尾部失败率」为选型目标。
- **P11 可审计优先**：延迟、动作统计、规格来源、校准曲线、bootstrap 排名区间都要能一键导出；可信度审核本身当作一个可优化的验收项。

## 4. 与第 1 轮的关系、MVP 与退化链

**保留不动**：IP-06（代理评测 / 六因子）、IP-02（抓握确认）、IP-03（chunk 缝合与延迟）仍是机制正确性的地基；IP-01（技能路由）继续作为最大红利的候选，但选型准则改为 P10。
**本轮新做的 MVP**：IP-09（Conformal Reliability Gate）+ IP-10（LLM Spec Compiler，离线）+ IP-13（Reliability Audit / Rank-Stability Bench）。理由：IP-09 直接回答 Q7 并把第 1 轮 IP-02 的「保守介入」变成可计算的风险预算；IP-10 把「LLM」用在它真正擅长且合规的地方；IP-13 让前两者有可信的标尺，且能在没有真机时段时持续迭代。
**暂缓**：IP-11（异步 LLM 监督）与 IP-12（风险感知路由）作为 P1，等 IP-09/IP-13 打通、且真机 A/B 显示监测器可用后再上；IP-05/IP-07 维持第 1 轮的 P1/P2 判断。

**退化链（新增层级，接在第 1 轮 Level-4 之后）**：
- Level-5：conformal 校准集不足 / 交换性检验失败 ⇒ 关闭 IP-09 的干预，只保留记录（回到第 1 轮的「不干预」基线）；
- Level-6：LLM 规格编译失败 / guard 置信度低 ⇒ 丢弃 CMA，回退到策略自身的隐式相位（IP-02 的相位分类器）；
- Level-7：异步 LLM 旁路超时 / 消息过期 ⇒ 丢弃调制，逐位退回无调制策略；
- Level-8：审计层异常（导出失败 / 延迟抖动超界）⇒ 关闭所有非必要组件，提交最小可信基线。

## 5. 预期贡献（本轮可验收）

1. **把「排行榜可靠性」变成可计算的设计输入**：给出 32 任务平均成功率的抽样标准差、MDD、排名稳定性曲线，明确「多大的改进才值得做」。
2. **给出一个可校准、带风险预算的失败干预框架**（IP-09）：不是又一个检测器，而是「检测 → 干预 → 净收益证明」的闭环，并诚实报告朴素残差监测 96.7% 假阳性的负结果。
3. **把 LLM 用在可审计的位置**（IP-10）：任务 → CMA 规格编译 + 对比集生成 + 失败归因；在线不调用 LLM，符合单模型/单 API/延迟/可信度约束。
4. **风险感知的技能路由**（IP-12）：把第 1 轮的 +4.26 oracle 上界，改写成有限试次下的下置信界选型问题，给出均值—尾部权衡。
5. **一套可导出的可信度审计**（IP-13）：bootstrap 排名区间、校准曲线、延迟平稳性、动作熵、规格来源哈希，直接对齐官方「延迟与动作规律性」的可信度口径。

## 6. 本轮最大风险

**一句话**：整条可靠性层建立在「校准集与评测分布可交换」的假设上，而 UniBot 的 5 类泛化场景恰恰是**为打破这个假设而设计的**；一旦交换性失效，conformal 的假阳性保证会静默失效，系统可能一边自信地报告「已校准」，一边在未见物品/人为干扰上把可救的失败判成不可救，而排行榜只奖励均值、不奖励「诚实的不确定性」，于是我们可能得到一个审计上很漂亮、分数上却更低的系统。

## 7. 下一轮迭代计划（深化与修剪，不推倒重来）

- **立即执行**：把 IP-09 的监测器从「手写残差」升级为「VLA 隐状态探针 + 相位条件化 + 分相位 conformal/ACI」；用 SAFECAST 式对比集做 OOD 校准；把 E621 的 96.7% 假阳性作为必须打败的负基线。
- **并行执行**：IP-10 先在 6 个最难的插入/旋转任务上编译 CMA，人工抽检 guard；若 guard 精确率 <90%，缩小到「只编译 recovery 边」，不碰主流程。
- **修剪预案**：若 IP-09 在真机 A/B 上的净收益下置信界 ≤0，则**彻底关闭干预**，只保留 IP-13 的审计与 IP-10 的离线规格（它们不影响在线成功率）；若 IP-12 的均值损失 >1 分且排名稳定性没有提升，则退回 IP-01 的均值路由。
- **保留项**：IP-06、IP-02、IP-03、IP-13 不砍；IP-09 的「监测-记录」形态永远保留（即使不干预，它也是代理评测的标签源）。

# 第 2 轮产物 · 创新点清单 v2（UniBot 线）：**UniBot-SAGE-RELY**

> **RELY = Reliability-Enforced Layer for Embodied policies**（可靠性外骨骼）。
> **基线**：第 1 轮 UniBot-SAGE v1（IP-01…IP-08；U1–U12；L1–L7；E601–E618）继续有效；本轮新增 **IP-09…IP-13**、定义 **U13–U24**、引理 **L8–L14**、实验 **E619–E636**。
> **数据来源纪律**：榜单数字仍来自 `unibot.unitree.com/leaderboard_data.json`（teaser / 占位表，`generated_from=gen_leaderboard.py`，官方尚未正式发布），检索日期 2026-11-17/18；凡引用皆标注 "teaser"。本轮新增的两个实验均为**结构敏感性分析 / 检测器表征**，明确标注 **synthetic mechanism check, NOT benchmark evidence**。
> **本轮一句话**：**给策略套一层可关闭、可校准、可审计的可靠性契约——LLM 只在离线编译规格与解释失败，在线只跑小监测器；所有干预必须先证明净收益的下置信界 > 0。**

## 0. 本轮结论摘要

| 结论 | 证据 | 设计后果 |
|---|---|---|
| 排行榜是低分辨率估计量 | teaser 结构重采样：`n=10` 时 `P(榜首仍榜首)=0.494`、`P(完整排名不变)=0.011`、平均名次漂移 1.03；`n=30` 时 `0.640 / 0.052 / 0.63` | 放弃 +1 分微调；目标改为「可分辨的 +3～5 分 + 尾部失败率」 |
| 32 任务平均的抽样噪声不可忽略 | `n=10` 时均值标准差 ≈2.40 pp；`n=30` ≈1.38 pp；`n=100` ≈0.76 pp | 任何 A/B 必须报告 bootstrap 区间与 MDD，否则结论不可信 |
| 朴素残差监测不可用 | 30 条真实成功演示上，EE 跟踪残差 CUSUM 假阳性 **96.7%**（`h=4…12`），z 的 99 分位中位数 **8.55** | 失败监测必须「学习到的 latent probe + 相位条件化 + 分相位 conformal/ACI」，不能靠手写阈值 |
| LLM 的正确位置是离线规格编译器 | 在线预算 35–70 ms、官方审核动作规律性；LLM 延迟与幻觉不可控 | 在线主回路禁用 LLM；LLM 只做 CMA 编译、对比集生成、失败归因 |
| 干预必须带风险预算 | 净收益 `Δ=q·ρ·p_det−(1−q)·c·p_fa−overhead`；朴素监测的 `p_fa≈0.967` 使 Δ<0 | 先证明 `LCB(Δ)>0`，否则只记录不干预 |
| 可靠性层必须可逐位回退 | 第 1 轮 Level-0…4 + 本轮 Level-5…8 | 每个组件都有「关闭 = 精确退回基线」的开关 |

**本轮路线**：`规格层（LLM 离线） → 监测层（小模型 + 分相位校准） → 干预层（风险预算） → 路由层（下置信界） → 审计层（排名稳定性 / 可信度）`，外挂在第 1 轮的三层栈之外。

## 2. 新增创新点详述

### IP-09 · Conformal Reliability Gate（CRG，P0）

- **动机**：2026 年的失败检测工作（Foresight、SAFECAST、VLA-Tug、Hide-and-Seek）已经证明「隐状态探针 + conformal」可以在长程操作中检测失败；但它们的目标是**报警**，不是**在不对称成本下决定是否干预**。UniBot 的评分只奖励终态成功，而干预的代价不对称：漏判会把可救失败变成硬失败，误判会把成功轨迹打断。
- **与现有方案的差异**：①把检测器输出变成**分相位的 conformal p 值**，在每个相位（reach/grasp/transport/align/insert/place/release）分别校准假阳性；②用 **ACI（Adaptive Conformal Inference）** 在 episode 内更新阈值，抵抗 5 类泛化场景造成的分布偏移；③把「是否干预」写成**带风险预算的决策**，要求净收益下置信界 >0；④提供「只记录不干预」的默认安全形态。
- **技术可行性**：中–高。信号全部可得：VLA 隐状态（若允许读内部）、4 路 RGB、EE 跟踪残差、1 维夹爪、相位分类器（IP-02/U3）。检测器可用 ResNet18/ViT-S 级小网络或探针；校准集来自官方数据的成功/失败回放 + SAFECAST 式对比集。
- **所需资源**：数据 = 官方 32 数据集 + 自建对比集；算力 = 单卡数小时训练探针 + 校准；接口 = 纯策略内部逻辑，不新增字段。
- **落地步骤**：
  1. 用第 1 轮 IP-06 的阶段标签，把每条轨迹切成 7 个相位；
  2. 训练相位条件化的失败分数 `s_t`（latent probe + residual + grip + phase）；
  3. 在每个相位上用成功校准集构造 conformal 阈值；用 ACI 做在线更新；
  4. 定义干预动作集合并估计其成本 `c` 与救回率 `ρ`；
  5. 用 `LCB(Δ)>0` 决定是否启用；默认只记录；
  6. 在 6 个最难任务上做真机 A/B（E629）。
- **风险**：①交换性失效（5 类 OOD 正是为此设计）⇒ ACI + 对比集校准 + 显式报告「校准失效」；②探针过拟合 teaser/训练任务 ⇒ 按任务留一 + 背景留一验证；③干预延迟（检测到动手已晚）⇒ 只在「还有救」的相位启用，超时直接放弃。

### IP-10 · LLM Spec Compiler（LSC，P0）

- **动机**：LLM 的直接控制不可用（延迟、幻觉、不可审计），但它在**把语言变成结构**上远强于小模型。UniBot 的 32 条指令 + 官方数据统计，足以让 LLM 离线生成一份可检查的「接触模式自动机」，把第 1 轮隐式的阶段先验变成显式的 guard。
- **与现有方案的差异**：现有 VLA 大多把语言当全局条件向量；我们把语言编译成**带 guard 的状态机**，用于（a）早停：guard 不满足时不再盲目执行 chunk；（b）恢复：失败时选择 recovery 边；（c）解释：把 episode 失败归因到具体 guard。LLM 只在离线运行，在线执行的是冻结的小解释器。
- **技术可行性**：中。难点不是生成，而是**验证 guard 的可观测性**：guard 只能用观测里有的量（RGB、EE 位姿、夹爪、语言），不能假设深度/力/触觉。LLM 生成的 guard 必须通过「在官方数据上可计算 + 与阶段标签一致」的双重检查。
- **所需资源**：数据 = 官方 32 数据集；算力 = 离线 LLM 调用（每任务数十次）+ 人工抽检；接口 = 无。
- **落地步骤**：
  1. 为 32 任务写统一 prompt：输入指令 + 数据 schema + 阶段统计，输出 CMA（状态、guard、recovery 边）；
  2. 在官方数据上回放 CMA，计算 guard 的精确率/召回率；
  3. 人工抽检 10%，只保留精确率 ≥90% 的 guard；
  4. 冻结规格并计算哈希，写入审计日志；
  5. 在线只跑解释器；低置信 guard 直接放行（不阻塞策略）；
  6. 合规审查：确认「规格由语言 + 公开数据生成、提交前冻结、可一键关闭」不构成按任务硬编码。
- **风险**：①LLM 幻觉出不存在的物体/关系 ⇒ guard 必须绑定观测键 + 数据统计；②规格泄漏评测信息 ⇒ 只用公开数据与语言，禁止读评测侧；③规格过细 = 硬编码 ⇒ 限制 guard 数量（每任务 ≤6 条）并做「留任务」泛化测试；④LLM 成本 ⇒ 缓存 + 只对难任务编译。

### IP-11 · Asynchronous LLM Supervisor（ALS，P1）

- **动机**：有些语义判断（「这是不是目标物体」「当前子目标是否已完成」）小模型弱、LLM 强，但 LLM 太慢。解法是把 LLM 放到**旁路**，用低频/事件触发的方式给出可拒收的提示，主回路永远不被它阻塞。
- **与现有方案的差异**：常见做法是「LLM 规划器 + 底层策略」的同步调用，延迟不可控；我们把 LLM 变成**带时间戳的建议者**，策略只在「消息新鲜 + 置信度高 + 与当前相位一致」时采纳，且影响被 FiLM 范数约束。
- **技术可行性**：中。工程上是一个 sidecar 进程 + 有界队列；难点是**过期语义**与**一致性**（LLM 的提示可能落后于场景）。
- **所需资源**：算力 = 1 张卡或外部 API（若允许）；接口 = 无新增字段；延迟预算 = 主回路不变。
- **落地步骤**：
  1. 定义消息 `m=(subgoal, confidence, timestamp, spec_hash)`；
  2. 策略端只接受 `age≤τ_max` 且 `confidence≥c_min` 的消息；
  3. 用 FiLM/LoRA 施加有界调制；`‖Δ‖≤ρ`；
  4. 关闭旁路时逐位退回无调制基线；
  5. 压测：LLM 超时/崩溃/返回垃圾时，主回路 p99 不变。
- **风险**：①LLM 延迟尖峰 ⇒ 旁路隔离 + 过期丢弃；②提示与场景不一致 ⇒ 置信度门控 + 相位一致性检查；③合规（外部 API）⇒ 只允许本地模型或赛前允许的服务。

### IP-12 · Risk-Controlled Skill Routing（RCSR，P1）

- **动机**：第 1 轮 IP-01 用 oracle 路由给出 +4.26 分上界，但那是「已知每个任务谁最强」的上界；在有限试次下，按均值选专家会系统性地高估「偶然表现好」的专家。可靠性视角要求按**下置信界**选。
- **与现有方案的差异**：把路由从 `argmax_k mean(R_k)` 改成 `argmax_k LCB_β(R_k)`；若所有专家的 LCB 都低于通用专家，则回退通用专家。目标从「最大化均值」改为「最大化均值 − λ·尾部风险」，并报告排名稳定性。
- **技术可行性**：高（统计层改动，工程小）。
- **所需资源**：数据 = 代理评测的 per-task 结果；算力 = 小；接口 = 无。
- **落地步骤**：①估计每个专家在每个任务上的成功率与方差（bootstrap）；②计算 LCB；③设置回退规则；④在代理评测上比较 mean-routing vs LCB-routing 的均值、CVaR、排名稳定性；⑤真机验证。
- **风险**：①LCB 过保守 ⇒ 总是回退通用专家，失去路由红利；②任务样本太少 ⇒ 用层级贝叶斯收缩；③与 IP-01 的合规形态冲突 ⇒ 仍保持单 checkpoint。

### IP-13 · Reliability Audit & Rank-Stability Bench（RASB，P0）

- **动机**：没有可信的标尺，所有「提升」都可能是噪声。本轮的两个实验已经证明：在 10–30 次/任务的预算下，1 分级别的差异基本不可分辨；朴素残差监测的假阳性高达 96.7%。因此必须把「测量」本身做成基础设施。
- **与现有方案的差异**：常见做法只报均值；我们报**区间 + MDD + 排名稳定性 + 校准曲线 + 延迟平稳性 + 动作熵**，并把这些作为选型门槛。
- **技术可行性**：高（统计 + 工程）。
- **所需资源**：计算 = 极小；数据 = 已有实验输出；接口 = 无。
- **落地步骤**：①bootstrap 每个任务的 per-episode 结果；②计算平均成功率的 BCa 区间与 MDD；③bootstrap 模型排名，报告 `P(rank=k)`；④导出校准曲线（可靠性图）与 ECE；⑤导出延迟 p50/p99 的滑动窗口平稳性检验；⑥把报告接入每次 A/B。
- **风险**：①bootstrap 假设 episode 可交换 ⇒ 按任务分层重采样；②小样本区间过宽 ⇒ 明确报告「不可分辨」；③审计本身增加工程时间 ⇒ 脚本化、默认开启。

## 3. 符号与定义（U13–U24，接 U1–U12）

| 符号 | 含义 |
|---|---|
| `R(π)` | 策略在 32 任务上的平均成功率估计量 |
| `n` | 每任务每模型的评测试次 |
| `MDD_{1−β}` | 给定 `n`、显著性 `α`、功效 `1−β` 下的最小可检测差 |
| `s_t` | 失败分数（越大越可能失败） |
| `q_{p,α}` | 相位 `p` 的 conformal 阈值（显著性 `α`） |
| `π_int` | 干预策略（重试 / 换抓 / 恢复原语 / 放弃） |
| `Δ` | 干预的期望净成功率变化 |
| `ρ` | 检测到失败后干预的救回概率 |
| `c` | 误干预成功轨迹的期望损失（占一次成功的比例） |
| `A=(S,s_0,G,δ,R)` | 接触模式自动机（CMA） |
| `m_t` | 异步 LLM 监督消息 `(subgoal, confidence, timestamp, spec_hash)` |
| `LCB_β(·)` | 置信水平 `β` 下的下置信界 |
| `CVaR_α` | 成功率分布的下尾条件期望 |
| `AUDIT` | 审计报告（区间 / MDD / 校准 / 延迟 / 熵） |

**定义 U13（平均成功率估计量）** `R̂(π) = (1/32) Σ_{j=1}^{32} (1/n) Σ_{i=1}^{n} 1[success_{j,i}]`；其抽样方差近似 `Var(R̂) ≈ (1/32²) Σ_j p_j(1−p_j)/n`（任务内独立、任务间不假设同分布）。

**定义 U14（最小可检测差）** `MDD = (z_{1−α/2}+z_{1−β}) · sqrt(Σ_j [p_j(1−p_j)+p'_j(1−p'_j)]/n) / 32`，用于两模型配对比较（忽略任务间协方差时是保守上界）。

**定义 U15（排名稳定性）** `Stab(n) = P_{bootstrap}(rank(π_i; R̂^{(b)}) = rank(π_i; R̂) ∀i)`；辅以 `P(top1 correct)` 与平均名次漂移。

**定义 U16（相位条件化失败分数）** `s_t = f_θ(z_t^{latent}, r_t^{EE}, g_t, z_phase)`，其中 `r_t^{EE}=‖a_t^{pos}−s_{t+1}^{pos}‖`，`g_t` 为夹爪开合，`z_phase` 由 U3 给出。

**定义 U17（分相位 conformal 阈值）** 对相位 `p` 的成功校准集 `C_p`，`q_{p,α} = Quantile_{1−α}({max_t s_t^{(c)} : c∈C_p})`；在线当 `s_t > q_{p,α}` 时报警。

**定义 U18（ACI 更新）** `q_{p,t+1} = q_{p,t} + γ(α − err_t)`，`err_t=1[s_t>q_{p,t}]`，`γ>0`；用于抵抗分布偏移。

**定义 U19（干预净收益）** `Δ = q·ρ·p_det − (1−q)·c·p_fa − overhead`，其中 `q` 为基线失败率，`p_det` 为真失败上的检测率，`p_fa` 为成功轨迹上的假阳性率。

**定义 U20（CMA 规格）** `A=(S,s_0,G,δ,R)`：`S` 为接触模式（reach/grasp/lift/transport/align/insert/place/release），`G` 为 guard 集合（`g: O→{0,1}`，只能用可观测键），`δ: S×G→S` 为转移，`R: S×G→Π∪{retry,abort}` 为恢复边。

**定义 U21（规格编译）** `A = LLM(ℓ, D_pub)`，`ℓ` 为语言指令，`D_pub` 为公开数据统计；`A` 在提交前冻结并哈希，运行时不允许再调用 LLM。

**定义 U22（异步监督消息）** `m_t=(u_t,c_t,τ_t,h)`，`u_t` 为子目标/风险 token，`c_t∈[0,1]` 为置信度，`τ_t` 为时间戳，`h` 为规格哈希；策略仅接受 `now−τ_t≤τ_max`、`c_t≥c_min`、`h` 匹配的消息。

**定义 U23（有界调制）** 异步消息只通过 `FiLM` 或 `LoRA` 进入策略，且 `‖Δθ‖≤ρ`；若消息被拒收/过期，调制置零。

**定义 U24（风险感知路由）** `k* = argmax_k LCB_β(R_k | task)`；若 `max_k LCB_β(R_k) < LCB_β(R_gen)`，则选通用专家 `k=gen`。

## 4. 关键算法骨架

```python
# ===== IP-09：分相位 conformal + ACI + 风险预算干预 =====
class ConformalReliabilityGate:
    def __init__(self, detector, alpha=0.05, gamma=0.01, tau_max=9):
        self.det = detector
        self.alpha, self.gamma, self.tau_max = alpha, gamma, tau_max
        self.q = {p: 1.0 for p in PHASES}       # 初始保守：不报警
        self.err = {p: [] for p in PHASES}
        self.n_retry = 0

    def calibrate(self, success_rollouts):
        """U17：每个相位用成功轨迹的最大分数定阈值（split conformal）。"""
        for p in PHASES:
            scores = [max(self.det.score(o, p) for o in ep) for ep in success_rollouts[p]]
            self.q[p] = np.quantile(scores, 1 - self.alpha)

    def update(self, p, s_t):
        """U18：ACI，在线把长期假阳性拉回 alpha。"""
        err = float(s_t > self.q[p])
        self.q[p] += self.gamma * (self.alpha - err)
        self.q[p] = float(np.clip(self.q[p], 0.0, 1.0))

    def step(self, obs, phase, session):
        s = self.det.score(obs, phase)                 # U16
        self.update(phase, s)
        alarm = s > self.q[phase]
        if not alarm or phase not in INTERVENABLE:
            return None
        if session.n_retry >= self.tau_max:            # U6 上限
            return ABORT
        # U19：只有 LCB(Δ)>0 才动手（离线估计 Δ 的区间）
        if self.lcb_delta(phase) <= 0:
            session.log_only(phase, s)
            return None
        session.n_retry += 1
        return self.choose_intervention(obs, phase)    # 重抓/换抓/恢复原语

# ===== IP-10：LLM 离线编译 CMA，在线只跑解释器 =====
def compile_spec(instruction, public_stats, llm):
    """U21：只允许语言 + 公开数据；输出后立即冻结。"""
    raw = llm(SPEC_PROMPT.format(instruction=instruction, stats=public_stats))
    A = parse_cma(raw)
    assert only_observable_guards(A)                   # 观测键白名单
    assert len(A.guards) <= 6                          # 防过拟合
    return freeze_and_hash(A)

class CMAInterpreter:
    def __init__(self, A): self.A = A; self.state = A.s0
    def guard(self, g, obs): return eval_guard(g, obs)
    def step(self, obs):
        for g in self.A.guards[self.state]:
            if self.guard(g, obs):
                nxt = self.A.delta[self.state][g]
                rec = self.A.recovery.get((self.state, g))
                self.state = nxt
                return rec                            # None 表示正常推进
        return None

# ===== IP-11：异步 LLM 旁路（1–2 Hz / 事件触发） =====
class AsyncSupervisor:
    def __init__(self, llm, tau_max=1.0, c_min=0.7, rho=0.1):
        self.llm, self.tau_max, self.c_min, self.rho = llm, tau_max, c_min, rho
        self.latest = None
    def offer(self, obs, spec_hash):
        m = self.llm(SUPERVISOR_PROMPT, obs)           # sidecar，绝不阻塞主回路
        self.latest = (m, time.time(), spec_hash)
    def modulation(self, now, phase, spec_hash):
        if self.latest is None: return None
        m, ts, h = self.latest
        if now - ts > self.tau_max or m.confidence < self.c_min or h != spec_hash:
            return None                                # U22：过期/低置信/哈希不符 ⇒ 忽略
        return bounded_film(m.subgoal, phase, rho=self.rho)  # U23

# ===== IP-12：下置信界路由 =====
def route(expert_stats, task, beta=0.9, gen="generalist"):
    """U24：用 LCB 选专家；全部低于通用专家则回退。"""
    lcb = {k: lower_confidence_bound(v[task], beta) for k, v in expert_stats.items()}
    best = max(lcb, key=lcb.get)
    if lcb[best] < lcb[gen]:
        return gen
    return best

# ===== IP-13：排名稳定性审计 =====
def rank_stability(per_task_success, B=20000, n=10, seed=0):
    rng = np.random.default_rng(seed)
    p = np.asarray(per_task_success) / 100.0          # [models, tasks]
    obs = p.mean(axis=1); obs_rank = rankdesc(obs)
    exact = top1 = 0; shifts = []
    for _ in range(B):
        x = rng.binomial(n, p) / n
        s = x.mean(axis=1); r = rankdesc(s)
        exact += int(np.array_equal(r, obs_rank))
        top1 += int(r[0] == obs_rank[0])
        shifts.append(np.abs(r - obs_rank).mean())
    return {"p_exact": exact / B, "p_top1": top1 / B, "mean_shift": np.mean(shifts)}
```

## 5. 推导（引理 L8–L14）

**引理 L8（conformal 干预的假阳性控制）** 若校准集与部署样本可交换，且分数 `s_t` 的构造与标签无关，则对任意成功 rollout，`P(∃t: s_t > q_{p,α}) ≤ α`（split conformal 的秩论证）。因此「报警」的假阳性可按相位独立控制在 `α`。**推论**：若 5 类 OOD 破坏交换性，该界不再成立；必须用 ACI 或分域校准，并显式报告失效。

**引理 L9（不对称成本下的干预门槛）** 记基线失败率 `q`、救回率 `ρ`、检测率 `p_det`、假阳性率 `p_fa`、误干预损失 `c`、开销 `o`。干预的期望净变化 `Δ=qρp_det−(1−q)c p_fa−o`。仅当 `LCB(Δ)>0` 时启用干预，则在置信水平 `β` 下不会降低成功率。**推论**：当 `p_fa≈0.967`（本轮实测）时，即使 `p_det=1, ρ=0.5, q=0.7`，也有 `Δ≈0.35−0.29c−o`；取 `c≥1` 即转负 ⇒ 朴素监测必须被 veto。

**引理 L10（LLM 规格编译的合规条件）** 若 CMA 满足：(a) guard 只使用观测白名单中的键；(b) 规格仅由语言与公开数据生成；(c) 提交前冻结且哈希可审计；(d) 每任务 guard 数 ≤K 且留任务泛化测试通过；则它不构成「按任务读取评测侧信息的硬编码」，而是「语言条件的通用规格」。违反任一条，则退回 IP-02 的隐式相位。

**引理 L11（异步监督的有界影响）** 若调制只通过 `‖Δθ‖≤ρ` 的 FiLM/LoRA 进入，且消息过期/低置信/哈希不符时置零，则对任意输入 `o`，`‖π_ALS(o)−π_base(o)‖ ≤ L·ρ`（`L` 为调制层 Lipschitz 常数）；关闭旁路时输出逐位等于基线。因此异步 LLM 的幻觉/延迟不会破坏主回路的安全性。

**引理 L12（风险感知路由的 Pareto 条件）** 若 `LCB_β(R_k)` 是 `R_k` 的 `β` 下界，则选 `argmax_k LCB_β(R_k)` 等价于在置信水平 `β` 下最大化最坏情况成功率。相比均值路由，它可能牺牲均值，但换来确定性；当且仅当 `mean(R_{k*}) ≥ mean(R_{mean}) − ε` 且 `CVaR_α(R_{k*}) ≥ CVaR_α(R_{mean})` 时，风险路由才优于均值路由（Pareto 条件）。

**引理 L13（排名稳定性的样本量）** 对两模型平均成功率之差 `Δ`，在每任务 `n` 次、任务间独立近似下，`SE(Δ)=sqrt(Σ_j [p_j(1−p_j)+p'_j(1−p'_j)]/n)/32`；达到功效 `1−β` 需 `n ≥ (z_{1−α/2}+z_{1−β})² Σ_j[p_j(1−p_j)+p'_j(1−p'_j)]/(32Δ)²`。代入 teaser 的 `Δ=1.2pp`、`p≈0.25`：`n=10` 时 `SE≈3.57pp`，`MDD≈10.0pp`；`n=1000` 时 `SE≈0.36pp`，`MDD≈1.0pp`。⇒ **10–30 次/任务无法分辨榜首与第二；不要把 +1 分当真实信号。**

**引理 L14（相位条件化的必要性）** 若成功轨迹的残差分布在不同相位下方差不同（`σ_p²` 随相位变化），则用全局阈值 `q` 会在高方差相位产生 `P(s>q|success)` 远超名义 `α` 的假阳性；只有按相位分别校准才能把每个相位的假阳性控制到 `α`。本轮实测的全局 CUSUM 假阳性 96.7% 即为该引理的反例证据。

#### E620 · 朴素残差监测的假阳性（负结果）

- **数据**：`exp/unibot_states/*.npz`，12 个任务、30 条真实成功演示（episode×hand），30 Hz。
- **信号**：`r_t = ‖a_t^{pos} − s_{t+1}^{pos}‖`（指令末端位置 vs 下一帧观测末端位置），用 episode 前段的 median/MAD 归一化，双侧 CUSUM（`k=1`，`h∈{4,6,8,10,12}`）。
- **脚本 / 结果**：`exp/reliability_failure_probe.py` → `exp/reliability_failure_probe.json`。
- **结果**：全局归一化下，`h=4…12` 的**假阳性率均为 96.7%**；残差 z 的 99 分位中位数 **8.55**、90 分位 **18.4**。分任务看，12 个任务中 11 个的假阳性率为 100%（HangCup 为 50%）。改用滚动窗口归一化或「只在夹爪闭合时监测」也没有改善（仍为 93–100%）。
- **解释**：成功轨迹本身就包含加速、接触、换向造成的大残差；**不是阈值没调好，而是信号/校准的建模不对**。这直接否定「手写残差 + 固定阈值」的可靠性方案，支持 IP-09 的「学习到的 latent probe + 分相位 conformal/ACI」。
- **重要警告**：该实验只含成功演示，扰动是合成的；它测量的是**检测器的假阳性**，不是真机成功率。

## 11. 本轮最值得押注的创新点（一句话）

**押注 IP-09（Conformal Reliability Gate）+ IP-10（LLM Spec Compiler）的组合：前者把 2026 年最热的「失败检测」从报警推进到「带风险预算的干预」，后者把 LLM 放在唯一合规且真正有增益的位置（离线规格编译），两者都不依赖一个更大的 VLA，却直接命中「排行榜是低分辨率估计量 + 最后一环失败不可恢复」这两个结构性事实。**

## 12. 本轮最大风险（一句话）

**整条可靠性层依赖「校准集与评测分布可交换」，而 UniBot 的 5 类泛化场景正是为打破它而设计；一旦交换性失效，conformal 的假阳性保证会静默失效，而排行榜只奖励均值，我们可能得到一个审计漂亮、分数却更低的系统。**
