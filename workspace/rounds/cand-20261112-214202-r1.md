# 第 62 轮（承接第 61 轮「具身语义进化闭环」IP-173~182；灵感循环第 1 轮；本轮灵感：「模型预测控制」×「上下文理解」）

> 第 61 轮 ESEC 用 USR 统一了场景/意图/阻抗/证据的表征，用 MEL 做零样本物理推断，用 DMS 做多轮对话，用 SRT-Dual 解耦语义流与实时流，用 PCE+++++ 做六维预算。但它留下四个核心局限：
> 1. **语义锚点是「当前点」而非「未来轨迹」**：实时流只消费最新锚点做一步式阻抗编译（`K_safe ← Π(anchor_latest)`），本质是**短视/反应式控制**——没有对未来 H 步的场景演化、接触力演化、任务阶段演化做预测。阻抗参数只在「此刻正确」，不在「未来安全」。
> 2. **上下文被压成一个向量**：USR 把 scene/intent/evidence 压到 ℝ^d_us，但「上下文理解」真正需要的是**结构化、多时间尺度、带信念的隐状态**（任务阶段、物理属性、用户意图、环境动态、社会情境），且要能被持续跟踪、更新、消歧。单向量既不可解释，也无法表达「我不确定现在是哪个任务阶段」。
> 3. **不确定性没有进入决策**：MEL 输出 `U_epistemic/U_aleatoric`，PCE 只拿它做预算分配与降级，**没有把不确定性写进优化目标与约束**——没有机会约束、没有鲁棒裕度、更没有「用动作主动降低不确定性」的对偶控制。
> 4. **模型误差会欺骗优化**：一旦引入预测模型做 MPC，学习动力学/接触模型的误差会被优化器主动利用（model exploitation），产生「预测很自信、接触很危险」的失败；第 61 轮没有预测误差的分布无关校准，也没有 MPC 层的安全护盾。

## 0. 直觉与动机

**灵感 1（模型预测控制 → 分层预测式阻抗控制 HMPC）**
直觉：第 61 轮的 `K_safe` 是「当前状态 → 当前阻抗」的静态映射，而真实接触操作是**一段有时序的力-位-阻抗轨迹**（接近→接触→加载→保持→卸载）。MPC 的核心不是「再解一次优化」，而是**在有限时域上滚动优化一条满足约束的轨迹**。但接触丰富操作无法承受单层大 MPC：非线性强、时域长、频率高。关键洞见：做**分层双速率 MPC**——语义层慢（10~50Hz，MPPI/CEM，输出参考管 X_ref、U_ref 与终端集），接触层快（0.5~1kHz，线性化接触 QP，5~20 步，warm-start，<1ms）。语义层决定「往哪走、什么阻抗区间」，接触层决定「这一毫秒怎么发力」。

**灵感 2（上下文理解 → 结构化多尺度上下文信念 CBS）**
直觉：第 61 轮把上下文压成 `scene_emb + intent_emb` 的一个点，无法表达「多峰、会切换、跨尺度」的真实上下文。关键洞见：引入**结构化上下文空间** `Z_ctx = Z_task × Z_phys × Z_intent × Z_env × Z_social`，并维护**分层信念** `b_t = (b^micro, b^meso, b^macro)`：micro（接触/即时，毫秒~几十毫秒）、meso（子任务，0.2~1s）、macro（会话/任务，秒~分钟）。用 MEL 的摊销编码器提供提议分布 `q_φ(z|o,ℓ,h)`，用粒子滤波保留多峰，用递归贝叶斯做持续跟踪。上下文从「一次快照」变成「一条可更新、可校准、可解释的信念轨迹」。

**灵感 3（两灵感合流 → 上下文条件 MPC，CC-MPC）**
直觉：MPC 的性能几乎完全由「预测模型 + 代价 + 约束」决定，而这三者都应被上下文调制：`f_θ(x,u,z_ctx)`、`c(x,u,z_ctx)`、`G(z_ctx)`。关键洞见：**上下文不是 MPC 的输入特征，而是 MPC 的「问题定义」**——同一台机器人，面对「易碎杯」与「稳固箱」，动力学相同但代价权重、力上限、终端集完全不同。把 `b_t` 映射为 `(w(z), G(z))`，MPC 就从「一个控制器」变成「一族由上下文索引的控制器」。

**灵感 4（不确定性 → 对偶控制与主动上下文探测 DCP）**
直觉：第 61 轮把不确定性当作「要降级的坏消息」，但不确定性其实是「可以被动作改变的资源」。关键洞见：在 MPC 目标中加入信息增益项 `-λ_info·I(z_ctx; y_{0:H} | u_{0:H}, b_t)`，当 `VOI_ctx > cost_probe` 时，规划一个**安全的探测动作**（轻触测刚度、移视线降场景歧义、向 DMS 发澄清问句、微探索动作）。这是 POMDP 的对偶控制思想：控制既「利用」上下文，也「认识」上下文。它把「上下文理解」从被动感知升级为闭环中的主动决策变量。

**灵感 5（安全 → 保形安全护盾 CSS）**
直觉：学习模型进入优化环后，优化器会主动寻找模型误差最大的方向。关键洞见：必须用**分布无关的保形预测**给出动力学误差区间 `C_α(x,u)`，据此收紧约束；再用**鲁棒控制不变集（RCIS）+ 安全滤波器**把 MPC 名义解投影回安全集：`u_safe = argmin‖u-u_mpc‖ s.t. x_{k+1} ∈ RCIS`。护盾频繁触发即判为「模型不可信」，自动回退到第 61 轮 SRT-Dual 的保守编译。

**灵感 6（预算 → PCE++++++ 八元预算与 VOI 竞争）**
直觉：第 61 轮的六元预算没有「预测成本」与「上下文维护成本」。关键洞见：扩展为 **`B_cog8 = (B_scene, B_intent, B_ros, B_exec, B_mel, B_usr, B_mpc, B_ctx)`**，并让 VOI 在「多规划一步（plan_longer）」「多理解一点（probe_context）」「精炼信念（refine_belief）」「直接执行（execute）」之间竞争分配——这是「预测」与「理解」两种认知投资的显式权衡。

## 1. 形式化定义（增量：定义 173–184）

**定义 173（结构化上下文空间 Z_ctx）** 上下文不是单一向量，而是因子化空间：
```
Z_ctx = Z_task × Z_phys × Z_intent × Z_env × Z_social
  Z_task   : 任务阶段/子目标（层级离散：approach→contact→load→hold→release）
  Z_phys   : 物理属性 (μ_fric, k_stiff, η_damp, σ_brittle) ∈ ℝ⁴
  Z_intent : 用户意图分布 Δ(I)（与第 61 轮 b_intent 对齐）
  Z_env    : 环境动态（地形、障碍、人类接近度、光照/遮挡）
  Z_social : 社会情境（协作/竞争、规范、人际距离）
```
- **上下文编码器**：`E_ctx: Z_ctx → ℝ^d_us`，与第 61 轮 USR 共享 `d_us=256`，保证上下文嵌入可直接参与 USR 对齐。
- **因子分解假设**：`p(z_ctx)=p(z_task)p(z_phys)p(z_intent|z_task)p(z_env)p(z_social)`，允许各因子以不同频率更新（见定义 174）。

**定义 174（多时间尺度上下文信念 CBS）** 信念 `b_t(z_ctx)` 分解为三层：
```
b_t = (b_t^micro, b_t^meso, b_t^macro)
  micro : 接触模式/瞬时力/局部几何，更新 ~10-100Hz
  meso  : 子任务阶段/物体属性，更新 ~0.2-1Hz
  macro : 会话意图/任务目标/社会情境，更新 ~0.01-0.1Hz
```
递归贝叶斯更新（每层独立转移核，macro 条件 meso 条件 micro）：
```
b_t^τ(z) ∝ p(o_t, ℓ_t | z) · ∫ p_τ(z | z') · b_{t-1}^τ(z') dz'
p_τ(z|z') = (1-ε_τ)·δ_{z'→z}^{τ} + ε_τ·p_0(z)     # 慢层 ε 小（粘滞），快层 ε 大（灵敏）
```
- **摊销提议**：MEL 编码器给出 `q_φ(z | o_t, ℓ_t, h_t)`，粒子滤波用其作为提议分布，保留多峰（如「轻放 0.6 / 稳住 0.4」）。
- **耦合约束**：`b^macro` 通过条件先验约束 `b^meso` 的转移，`b^meso` 通过阶段先验约束 `b^micro` 的接触模式。
- **校准目标**：期望校准误差 `ECE(b) ≤ 0.05`，用温度缩放/分位数校准离线标定。

**定义 175（上下文条件动力学 CCDM）** 预测模型被上下文索引：
```
x_{k+1} = f_θ(x_k, u_k, z_ctx) + w_k,     w_k ~ N(0, Σ(z_ctx))
x = (q, q̇, f_ext, contact_mode)           # 机器人状态 + 接触状态
u = (K_p, K_d, F_ref) 或 τ                 # 阻抗/力/力矩指令
z_ctx ~ b_t                                # 从上下文信念采样
```
- **结构先验**：`f_θ = f_rigid(q,q̇,u) + f_compliant(f_ext, z_phys; θ)`，刚体部分解析已知，柔性接触部分学习，降低对数据的依赖。
- **认知不确定性**：`N_e` 个模型集成，`U_ep(x,u,z) = Var_ensemble[f]`。
- **偶然不确定性**：异方差头 `Σ_ale(x,u,z)`。
- **与 MEL 一致性**：`z_phys ≡ φ_phys`，即第 61 轮 MEL 的物理属性推断直接作为 CCDM 的上下文因子，避免双重估计。

**定义 176（分层模型预测控制 HMPC）** 两个速率层，共享上下文信念：
```
语义层 SemanticMPC（10-50Hz，H_s = 20-50 步）：
  状态： (b_t, task_state, memory_context)
  决策： 子任务/路点/阻抗区间参考 → 参考管 (X_ref, U_ref, X_term)
  目标： task_progress + context_consistency - effort
  求解： MPPI / CEM（非凸、高维、可并行采样）

接触层 ContactMPC（0.5-1kHz，H_c = 5-20 步）：
  状态： (q, q̇, f_ext)
  决策： (K_p, K_d, F_ref) 或 τ
  目标： tracking + effort + safety + smoothness
  求解： 在当前工作点线性化接触动力学 → 小规模 QP，warm-start，<1ms
```
统一优化形式（在信念上取期望）：
```
min_{u_{0:H-1}}  E_{z~b_t, w}[ Σ_{k=0}^{H-1} c(x_k,u_k,z) + c_term(x_H) ]
s.t.  x_{k+1} = f_θ(x_k,u_k,z) + w_k
      Pr( g_i(x_k,u_k,z) ≤ 0 ) ≥ 1 - δ_i ,  ∀k      # 机会约束
      u_k ∈ U(z)                                     # 上下文相关可容许集
      x_H ∈ X_term(z)                                # 上下文相关终端不变集
```
- **层间接口**：语义层下发参考管与终端集；接触层回传可行性标志、跟踪误差、护盾触发；不可行时语义层**回溯重规划**（hierarchical feedback）。

**定义 177（语义-上下文代价/约束编译器 SCC）** 把信念映射为 MPC 的问题定义：
```
w(z) = (w_task, w_effort, w_safe, w_ctx, w_info) = MLP_w(E_ctx(z))
c(x,u,z) = w_task·c_task + w_effort·c_effort + w_safe·c_safety
         + w_ctx·‖E_ctx(z) - E_ctx(z_ref)‖² + w_info·c_info
G(z) = { g_i(x,u) ≤ 0 }   # 上下文相关裕度
  易碎 (σ_brittle ↑)  ⇒ F_max ← F_max·0.5, 力裕度 +20%
  有人 (z_social.human ↑) ⇒ 距离裕度 +50%, 速度上限 ↓
  协作 (z_social.collab)  ⇒ 柔顺性代价 ↑（允许人类主导）
```
- **权重学习**：从人类偏好/演示中用逆最优控制（IOC）学习 `w(z)`，但**规则安全约束 G(z) 永远硬优先**（第 61 轮 A68 的延续）。
- **可解释性**：每个权重可追溯到上下文因子，避免「黑箱调参」。

**定义 178（对偶控制与主动上下文探测 DCP）** 在目标中加入信息价值：
```
J_dcp = E_{z~b_t}[ Σ c(x_k,u_k,z) ] - λ_info · I(z_ctx ; y_{0:H} | u_{0:H}, b_t)
Î(z;y) ≈ H(b_t) - E_{y}[ H(b_t | y) ]                  # 熵减近似
       ≈ Var_ensemble[f] 或 粒子预测分歧度              # 可计算代理
```
- **触发条件**：`VOI_ctx(a_probe) > cost_probe + risk_probe`，其中 `VOI_ctx = Î·λ_info`。
- **探测动作集**：`{probing_contact(轻触测刚度), gaze_shift(降低场景歧义), clarify_question(经 DMS 询问), micro_explore(小幅度安全探索)}`。
- **安全约束**：探测动作必须落在**鲁棒安全集**内，禁止以接触丢失/力超限为代价换取信息。
- **与 POMDP 的关系**：这是 belief-space planning 的双效控制（dual effect：控制既改变状态也改变信息）。

**定义 179（时序上下文记忆 TCM）** 三层记忆，补足第 61 轮固定长度 `H_diag` 与证据缓冲：
```
M = (M_work, M_epi, M_sem)
  M_work : 当前信念 b_t、最近证据、待确认约束（继承第 61 轮）
  M_epi  : {(E_ctx(z), u, outcome, timestamp)}，ANN 索引，支持跨 episode 检索
  M_sem  : 物体/场景原型、物理属性先验、交互技能库
```
- **检索**：`R_k = ANN_topk(E_ctx(z_t), M_epi, k)`，检索结果条件化 CCDM 与代价：`f_θ(x,u,z,R_k)`。
- **少样本适配**：检索到的相似 episode 作为「上下文内示例」，实现不更新参数的 in-context 适配。
- **可审计**：每条检索记录 provenance（时间戳、episode id、相似度），写入证书。

**定义 180（保形安全护盾 CSS）** 分布无关的预测校准 + 安全投影：
```
保形预测：用校准集构造 C_α(x,u)，使 Pr( f(x,u) ∈ C_α(x,u) ) ≥ 1-α
约束收紧：g_i^tight(x,u) = g_i(x,u) + max_{e∈C_α} ‖e‖   （区间可达性）
鲁棒不变集：RCIS = 最大控制不变集（zonotope/interval 可达性计算）
安全滤波：u_safe = argmin_u ‖u - u_mpc‖²  s.t.  x_{k+1} ∈ RCIS, u ∈ U(z)
```
- **护盾触发率**：`r_shield = 触发次数 / 总步数`；若 `r_shield > θ_shield`，判定模型不可信，回退第 61 轮保守编译。
- **不改变安全语义**：护盾只做「最小扰动投影」，不重写任务目标。

**定义 181（上下文-预测联合证书 J_ctx_pred）** 扩展第 61 轮 `J_sem_exec`：
```
J_ctx_pred = ( J_sem_exec,
               ECE(b_t),                 # 上下文信念校准误差
               δ_pred,                   # 保形预测误差上界
               mpc_recursive_feasible,   # 递归可行性
               r_shield,                 # 护盾触发率
               t_solver,                 # MPC 求解时间
               memory_provenance )       # 记忆检索溯源
Valid(J_ctx_pred) ⇔ Valid(J_sem_exec) ∧ ECE ≤ ε_ece ∧ δ_pred ≤ δ_max
                    ∧ mpc_recursive_feasible ∧ r_shield ≤ θ_shield ∧ t_solver ≤ τ_mpc
```

**定义 182（八元认知-预测预算 B_cog8 与 PCE++++++）**
```
B_cog8 = (B_scene, B_intent, B_ros, B_exec, B_mel, B_usr, B_mpc, B_ctx)
B_mpc  = (H_s, H_c, QP_iters, M_scenarios, t_solver_budget, warm_start_hit)
B_ctx  = (belief_dim, N_particles, memory_k, update_freq, info_gain_thresh)
cost_cog8 = cost_cog5 + λ_mpc·(t_solver/τ_mpc + M_scenarios/M_max)
                      + λ_ctx·(N_particles/N_max + memory_k/k_max + update_freq/f_max)
```
- **VOI 竞争分配**：`a* = argmax_{a∈{plan_longer, probe_context, refine_belief, execute}} VOI(a) - cost(a)`。
- **降级链**：`B_mpc` 耗尽 → 缩短时域 `H_s→H_c→1`（退化为第 61 轮一步式）；`B_ctx` 耗尽 → 冻结信念，使用 MAP 点估计；`B_usr` 耗尽 → 冻结投影头。
- **安全不降级**：任何预算耗尽只降低「预测/理解」能力，**不降低安全约束与护盾**。

**定义 183（上下文感知预测闭环 CAMP-ESEC）** 统一第 61 轮 ESEC 与本轮：
```
CAMP-ESEC(M, o_t, ℓ_t, delta_f_req):
  # ── 语义层（异步，10-50Hz）──
  b_t ← CBS.update(b_{t-1}, o_t, ℓ_t, M_work)            # 定义 174
  R_k ← TCM.retrieve(E_ctx(b_t), M_epi, k)               # 定义 179
  (X_ref, U_ref, X_term) ← SemanticMPC(b_t, R_k)         # 定义 176
  # ── 实时层（同步，0.5-1kHz）──
  z_ctx ← b_t.sample()                                   # 或 MAP + 场景采样
  (w(z), G(z)) ← SCC(b_t)                                # 定义 177
  u_nom ← ContactMPC(x_t, X_ref, U_ref, w(z), G(z), f_θ(·,z,R_k))   # 定义 175/176
  if DCP.should_probe(b_t): u_nom ← DCP.plan_probe(u_nom, b_t)      # 定义 178
  u_safe ← CSS.filter(u_nom, x_t, C_α, RCIS)             # 定义 180
  dispatch(u_safe)
  EV_exec ← wait_contact(); M_work.push(E_evidence(EV_exec))
  M.J_ctx_pred ← build_cert(EV_exec, b_t, CSS.stats, t_solver)      # 定义 181
  return M, u_safe, EV_exec, M.J_ctx_pred
```

**定义 184（上下文偏移鲁棒性 COR）** 形式化「上下文突然变了」：
```
偏移检测：CUSUM / 似然比 作用于预测残差 r_t = ‖x_t - f_θ(x_{t-1},u_{t-1},z)‖
检测延迟：Pr(τ_detect ≤ τ_max) ≥ 1-β
响应：   b_t ← b_t.expand(τ_shift)  # 增大方差，提升快层 ε
         R_k ← TCM.retrieve_shift(history)  # 检索历史相似偏移
         触发 DCP 主动探测
安全保证：偏移检测到适配完成期间，护盾保持激活，禁止高风险动作
```
- **K-shot 适配**：偏移后 K 次交互内完成信念再收敛（目标 K ≤ 5）。

## 2. 本轮最大风险

```python
class ContextBeliefState:
    def __init__(self, n_particles=256, d_us=256, ece_target=0.05):
        self.n_particles = n_particles
        self.particles = {                 # 分层粒子集
            'micro': ParticleSet(n_particles, dim=16),
            'meso':  ParticleSet(n_particles, dim=32),
            'macro': ParticleSet(n_particles, dim=24),
        }
        self.eps = {'micro': 0.20, 'meso': 0.05, 'macro': 0.01}  # 快层灵敏、慢层粘滞
        self.encoder = ContextEncoder(d_us)  # E_ctx
        self.calibrator = TemperatureCalibrator(ece_target)

    def update(self, o_t, l_t, h_t, mel_proposal):
        # 1) MEL 摊销提议 q_phi(z|o,l,h)
        q = mel_proposal                      # dict of factorized proposals
        # 2) 分层递归贝叶斯：propose → reweight → resample
        for tau, ps in self.particles.items():
            ps.propose(q[tau], eps=self.eps[tau])     # 混合转移核
            ps.reweight(likelihood(o_t, l_t, tau))
            if ps.ess() < 0.5 * self.n_particles:
                ps.systematic_resample()
        # 3) 层间耦合：macro 条件 meso，meso 条件 micro
        self.particles['meso'].condition_on(self.particles['macro'].map())
        self.particles['micro'].condition_on(self.particles['meso'].map())
        # 4) 温度校准（离线标定，在线只查表）
        self.calibrator.apply(self.particles)
        return self

    def sample(self, n=1):
        idx = np.random.choice(self.n_particles, n, p=self.weights())
        return self.particles['meso'].state[idx]

    def map(self):
        return {tau: ps.map() for tau, ps in self.particles.items()}

    def entropy(self, tau='meso'):
        return self.particles[tau].entropy()

    def expand(self, factor=1.5):
        for ps in self.particles.values():
            ps.cov *= factor                   # 上下文偏移时扩方差

    def ece(self, holdout):
        return self.calibrator.ece(holdout)
```

    def __init__(self, n_ensemble=5):
        self.models = [ContactDynamicsNet() for _ in range(n_ensemble)]
        self.rigid = RigidBodyModel()          # 解析刚体部分

class HierarchicalMPC:
    def __init__(self, dyn, budget):
        self.dyn = dyn
        self.budget = budget

            samples = cem_update(samples, costs, elite_ratio=0.1)

        return X_ref, U_ref, X_term

                            warm_start=self.budget.last_u_seq)
        return u_seq

class DualController:
    def __init__(self, dyn, dms, safety_set):
        self.dyn = dyn
        self.dms = dms
        self.safety_set = safety_set
        self.lambda_info = 0.3

                                            - a.cost - a.risk)

class ConformalSafetyShield:
    def __init__(self, dyn, rcis, alpha=0.05, theta_shield=0.05):
        self.dyn = dyn
        self.rcis = rcis                 # 预计算鲁棒控制不变集
        self.alpha = alpha
        self.theta_shield = theta_shield
        self.activations = 0
        self.steps = 0

    def filter(self, u_nom, x_t, z_ctx):
        self.steps += 1
        C = self.dyn.conformal_set(x_t, u_nom, z_ctx, self.alpha)
        x_next_lo, x_next_hi = interval_reach(x_t, u_nom, C)
        if (x_next_lo, x_next_hi) ⊆ self.rcis:
            return u_nom, False
        # 最小扰动投影：找最近的、使下一步落入 RCIS 的 u
        u_safe = project_onto_safe(x_t, u_nom, self.rcis, C)
        self.activations += 1
        return u_safe, True

    def trigger_rate(self):
        return self.activations / max(self.steps, 1)

    def should_fallback(self):
        # 频繁触发 ⇒ 模型不可信 ⇒ 回退第 61 轮保守编译
        return self.trigger_rate() > self.theta_shield

**正确性定理（CAMP-ESEC-Complete）**：
假设第 61 轮 A61–A70，及 **(A71)** CBS：上下文信念校准良好（ECE ≤ ε_ece），且分层转移核满足 `ε_τ`-混合；**(A72)** CCDM：学习动力学误差满足保形界 `Pr(f ∈ C_α) ≥ 1-α`，且刚体部分解析精确；**(A73)** HMPC：接触层 QP 在收紧约束下递归可行，终端集 `X_term` 为控制不变集；**(A74)** CSS：安全滤波器保持 `x_t ∈ RCIS ⇒ x_{t+1} ∈ RCIS`；**(A75)** DCP：探测动作集 `A_probe ⊆ A_safe`（不破坏安全不变性）；**(A76)** PCE++++++：八元预算单调消耗，降级链只影响预测时域/信念精度，不影响 `G(z)` 与 RCIS。

则：
1. **上下文可跟踪**：在上下文无突变时，`b_t` 以概率 1-β 收敛到真实上下文邻域；突变时检测延迟 ≤ τ_detect。
2. **预测可行性**：在 A72+A73 下，HMPC 每一步递归可行，且机会约束以概率 ≥ 1-δ 满足。
3. **闭环安全**：在 A74+A75 下，若初始状态 ∈ RCIS，则闭环轨迹始终 ∈ RCIS，护盾触发率超过 θ_shield 时回退保守控制。
4. **预测优于反应**：在上下文条件代价下，HMPC 的期望代价不高于第 61 轮一步式基线（在相同约束集上），且当上下文预测准确时严格更优。
5. **理解可行动**：当 `VOI_ctx > cost_probe` 时，DCP 的信息增益 ≥ 0，且探测不降低安全不变性。
6. **预算安全**：任一预算耗尽只降低预测/理解能力，不违反 ERTC 实时契约与安全约束。

## 5. 本轮最大风险

**一句话**：学习动力学在接触丰富工况下被 MPC 主动利用、上下文信念在多峰/突变时误收敛、或对偶探测动作本身引入不安全接触，都会让「预测越自信、理解越具体、失效越灾难」——必须以「保形预测误差界 + 鲁棒不变集安全滤波 + CUSUM 偏移检测 + 探测动作安全集约束 + 护盾触发率硬阈值回退」构成预测-理解的双重安全护栏，确保「预测先行、理解在后」永不跨越「执行安全」红线。
