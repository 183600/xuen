# 第 55 轮（承接第 54 轮 v16+++ GroundEdge-GenSim；灵感循环第 6 轮；本轮灵感：「手眼标定」×「语音交互」）

> 第 54 轮把技能组合推进到动作空间剖面 α_S、组合图 G_S、云边映射 γ_ce 与联合证书 J。但 J 有一个未被审计的前提：**γ_ce 与任务动作序列 A_T 都被当成“给定量”**。本轮用「手眼标定」补上前者——任何跨空间映射都必须由带噪成对约束估计，并附带可观测性与协方差；用「语音交互」补上后者——A_T 是语音意图的后验分布，且可通过主动澄清降低歧义。核心矛盾：H22：标定在运动/语料退化时不可辨识，却仍输出高置信 γ_ce，使证书“假精确”；H23：语音歧义与 ASR/执行时延使意图–动作在时空上错配，空间对齐正确也仍系统性失败。

## 0. 直觉与动机

**灵感 1（手眼标定 → 把“映射”从假设升级为“带可观测性证书的估计量”）**
直觉：经典手眼标定解 `A_k X = X B_k`，X 为相机—末端变换。真正决定成败的不是解方程，而是三件事：**运动是否激励了足够多非平行旋转轴（可观测性）**、**测量噪声如何传播为 X 的协方差 Σ_X**、**标定是否随时间漂移**。把第 54 轮的 γ_ce 也当作一个待标定变换：云端粗动作 A_c 与边端细动作 A_e 是两套“坐标架”，必须用成对执行记录拟合 γ_ce，并输出 `(γ_ce, Σ_γ, σ_min, 有效期)`；`σ_min` 过小即判“不可辨识”，不得签发部署证书。这样，第 54 轮的 Lipschitz 假设就从“信仰”变成“可检验命题”。

**灵感 2（语音交互 → A_T 是后验分布，不是字符串；歧义可主动压低）**
直觉：语音指令 `u` 先经 ASR 得到 n-best，再经语义解析与场景接地得到动作目标集合 `{A_T^m, p_m}`。因此 `cover(S, A_T)=1` 这种布尔判定是错的，应改为 **鲁棒覆盖概率** `P_{A_T∼p}(cover(S,A_T)=1) ≥ 1-ε`。当意图熵 `H(L)` 高（指代不明、约束缺失）时，不应赌一个解释，而应发起 **主动澄清查询**（“是左边的红色杯还是右边的？”）。澄清在数学上就是一次 **信息增益最大的主动标定实验**，与第 54 轮的主动剖面采样同构，只是被标定的是“语言—动作”映射而非动作剖面。

**灵感 3（时空标定 → 手眼标定的时间偏移问题就是语音的 ASR 延迟问题）**
直觉：带未知时间偏移的手眼标定相当于求 `A(t)X = X B(t+Δ)`。语音交互里，用户说“停”的时刻、ASR 出字时刻、控制器执行时刻各不相同；若 Δ 未标定，空间上完美的 γ_ce 也会让机器人“晚半拍”抓空或撞上。因此需要 **时空联合标定 `(T, Δ, α)`**（变换、偏移、时钟偏斜），并像手眼一样用事件流互相关/对应残差估计 Δ，给出 `Δ ± 3σ_t` 的时序证书。

**灵感 4（主动澄清 = 主动标定 → 把对话建模为实验设计）**
直觉：澄清问句不是自然语言技巧，而是一个 **查询 q**，其价值是期望信息增益 `IG(q)=H(L)-E[H(L|answer)]` 除以交互成本。只允许有限查询模板集 Q（指代消解、约束确认、目标复核），在预算内选 `D-optimal` 查询，直到 `H(L)<H_stop`。这把“语音交互”接入第 54 轮的 Explain 回传闭环：失败解释可反向生成澄清问句，使“解释—澄清—重标定”形成同一控制环。

**灵感 5（证书金字塔新增标定层 ℂ）**
直觉：在鲁棒性层与动作协同层之下，必须有更底层的地基 **ℂ（Calibration）**：`ℂ_0` 传感器/时钟基准，`ℂ_1` 手眼与多传感器外参，`ℂ_2` 跨模态空间映射 γ_ce，`ℂ_3` 语言—动作接地与时间偏移。上层任何证书的误差预算都必须向下扣除 `ℂ` 层的不确定性与漂移，否则就是空中楼阁。于是形成 **标定层 → 动作层 → 鲁棒性层 → 任务层** 的四层误差预算传递。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（跨模态标定问题 CMC）**
给定两个坐标架/表示空间 `F_i, F_j`，成对相对观测 `{(A_k, B_k)}_{k=1..n}`（`A_k∈SE(3)` 作用于 F_i，`B_k∈SE(3)` 作用于 F_j），标定即求 `T_ij` 使 `A_k T_ij = T_ij B_k + ε_k`。手眼标定是 `F_i=`末端、`F_j=`相机的特例；云边映射是 `F_i=A_c`、`F_j=A_e` 的（近似）特例；语言—动作标定则把 `T_ij` 推广为仿射/嵌入映射 `Φ: L→A_T`。标定结果记为三元组 `Cal=(T_ij, Σ_T, o)`，`o` 为可观测性指标。

**定义 122（可观测性与标定协方差）**
把 `A_k X = X B_k` 线性化为 `M x = 0`，`M` 由旋转/平移块堆叠。**可观测性** `o = σ_min(M) / σ_max(M)`；当 `o < o_min`（旋转轴共线、运动退化、语料单一）时称标定 **不可辨识**。标定协方差一阶近似 `Σ_T ≈ σ_ε² (MᵀM)^{+}`，误差椭球半径 `r_T(δ)=sqrt(χ²_{dim}(1-δ)·λ_max(Σ_T))`。仅当 `o ≥ o_min` 且 `r_T(δ) ≤ r_budget(δ)` 时可签发证书。

**定义 123（语音意图后验与接地）**
语音 `u` 的意图后验为 `p(L|u) ∝ Σ_m p(u|h_m) p(h_m) · 1[g(h_m)=L]`，其中 h 为 ASR/语义假设，`g` 为接地函数（指代、空间关系、约束）。任务目标分布 `p(A_T|u)=Σ_L p(A_T|L)p(L|u)`。**意图熵** `H(L|u)=-Σ p log p`。**鲁棒覆盖** `RC(S,u,ε)=1` 当且仅当 `P_{A_T∼p}(cover(S,A_T)=1) ≥ 1-ε`。

**定义 124（主动澄清查询）**
查询模板集 `Q={q_1..q_m}`（指代/约束/目标/风险确认），查询 `q` 的回答 `a_q` 使后验更新为 `p(L|u,a_q)`。查询价值 `V(q)=IG(q)/cost(q)`，`IG(q)=H(L|u)-E_{a_q}[H(L|u,a_q)]`。**澄清策略** `π_C` 在预算 `B_q` 内最大化 `Σ V(q)`，停机条件 `H(L|u,a) ≤ H_stop` 或预算耗尽；耗尽仍未收敛则回退到保守安全动作 `a_safe`。

**定义 125（时空标定与一致性窗口）**
事件流 `E_x={(t_k^x, e_k)}`、`E_y={(t_k^y, e_k)}`。时空标定估计 `(Δ, α)` 使 `t_k^y ≈ α·t_k^x + Δ`，`α` 为时钟偏斜。时序证书 `(Δ̂, Σ_t)`，残差 `res_t = max_k |t_k^y-(α̂ t_k^x+Δ̂)|`。**时空一致性**要求 `res_t ≤ w_align` 且 `r_t(δ)=3sqrt(λ_max(Σ_t)) ≤ w_budget`。空间证书与时序证书必须同时有效，才允许执行。

**定义 126（标定感知联合证书 CAC）**
在定义 120 的 `J=(ρ,A_cert,γ_ce,δ_a,evidence)` 上扩展为
`J_C=(ρ, A_cert, γ_ce, Σ_γ, o_γ, Δ̂, Σ_t, p(A_T|u), Φ_L, evidence)`。
**部署判据**：`dom(T)=in` 且 `o_γ≥o_min` 且 `r_γ(δ)+δ_a ≤ Θ_a` 且 `r_t(δ)≤w_budget` 且 `RC(S,u,ε)=1` 且证书未过期。误差预算递归（组合 k 个技能）：
`δ_total ≤ Σ_{i=1..k}(δ_a^i + r_γ^i) + drift(T, t_exp) + r_t(δ)`。

## 2. 关键算法 伪代码

### IP-121 CMC（Cross-Modal Calibration）

```python
def cross_modal_calibrate(pairs, sigma_eps, o_min, r_budget):
    # pairs: [(A_k, B_k)] 相对运动；AX = XB
    M = build_kronecker_system(pairs)          # 4n x 16, null-space 求 X
    U, S, Vt = svd(M)
    x = Vt[-1]
    X = reshape_4x4(x); X = project_to_SE3(X)
    o = S[-1] / S[0]                           # 可观测性
    Sigma = sigma_eps**2 * pinv(M.T @ M)
    r = chi2_radius(Sigma)
    if o < o_min:
        return ('unobservable', o, suggest_exciting_motions(pairs))
    if r > r_budget:
        return ('uncertain', r, 'collect_more_or_better_excitation')
    return ('ok', Cal(X, Sigma, o))
```

### IP-122 VIG（Voice Intent Grounding）

```python
def voice_intent_posterior(u, scene, asr, parser):
    hyps = asr.nbest(u, N=10)                  # [(text, p_asr)]
    post = {}
    for text, p_asr in hyps:
        for L, p_sem in parser(text, scene):
            post[L] = post.get(L, 0.0) + p_asr * p_sem
    post = normalize(post)
    H = entropy(post)
    A_T_dist = {L: ground_to_action(L, scene) for L in post}
    return post, A_T_dist, H

def robust_cover(skill, u, eps):
    post, A_T_dist, H = voice_intent_posterior(u, scene, asr, parser)
    p_ok = sum(p for L,p in post.items() if cover_check(skill.alpha, A_T_dist[L]))
    return p_ok >= 1 - eps, p_ok, H
```

### IP-123 ACD（Active Clarification Dialogue）

```python
def clarify(u, Q, budget, H_stop):
    post, _, H = voice_intent_posterior(u, scene, asr, parser)
    asked = []
    while H > H_stop and budget > 0:
        q, ig = max(((q, expected_info_gain(q, post)) for q in Q - set(asked)),
                    key=lambda z: z[1] / cost(z[0]))
        a = ask_user(q); asked.append(q)
        post = bayes_update(post, q, a); H = entropy(post)
        budget -= cost(q)
    if H > H_stop:
        return ('fallback_safe', a_safe, post, H)
    return ('resolved', argmax(post), post, H)
```

### IP-124 TAC（Temporal Alignment Calibration）

```python
def temporal_calibrate(E_x, E_y, w_align):
    # 事件级对应 + 鲁棒回归 t_y = alpha * t_x + Delta
    corr = match_events(E_x, E_y)              # 同名事件/运动-语音锚点
    (alpha, Delta), inliers = robust_fit(corr) # RANSAC/Huber
    Sigma_t = cov_from_inliers(inliers) * residual_scale
    res_t = max(abs(t_y - (alpha*t_x + Delta)) for t_x,t_y in inliers)
    if res_t > w_align or chi2_radius(Sigma_t) > w_align:
        return ('time_misaligned', res_t, Sigma_t)
    return ('ok', Delta, alpha, Sigma_t, res_t)
```

### IP-125 CAC（Calibration-aware Certificate）

```python
def calibration_aware_certificate(skill_seq, cal_space, cal_time, intent_post,
                                  budgets, t_exp):
    if cal_space.o < o_min or not valid(cal_space, t_exp):
        return ('reject', 'calibration_invalid', cal_space)
    if cal_time is None or cal_time.res_t > w_align:
        return ('reject', 'time_misaligned', cal_time)
    delta = sum(s.delta_a for s in skill_seq)
    delta += sum(chi2_radius(s.cal.Sigma) for s in skill_seq)
    delta += drift_bound(cal_space, t_exp) + chi2_radius(cal_time.Sigma_t)
    if delta > budgets.delta_a:
        return ('reject', 'budget_exceeded', delta)
    if not robust_cover_chain(skill_seq, intent_post, budgets.eps):
        return ('reject', 'intent_ambiguous', entropy(intent_post))
    return ('ok', CertJ_C(skill_seq, cal_space, cal_time, intent_post, delta))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| CMC | O(n·d³)（SVD 主导） | O(n·d²) | `o≥o_min`、协方差一阶有效 |
| VIG | O(N·|L|·|scene|) | O(|L|) | ASR n-best 召回、接地校准 |
| ACD | O(B_q·|Q|·|L|) | O(|Q|·|L|) | 信息增益估计无偏、预算闭合 |
| TAC | O(n log n + n) | O(n) | 事件对应正确、时钟模型线性 |
| CAC | O(|S|·(|A|+|L|)) | O(|A|+|L|) | 预算递归 sound、证书未过期 |

**正确性定理（Calibrated Cross-Modal Deployment Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** 成对观测由结构化仿真/真实执行生成，`σ_ε` 有界且独立；**(A30)** 语音后验经过温度/共形校准，`p(A_T|u)` 的可靠性有下界；**(A31)** 时钟偏斜在证书有效期内近似线性，漂移率有界；**(A32)** 主动澄清的回答模型 `p(a|L)` 已知且查询成本可测。则
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(o_γ<o_min)
            - P(r_γ+δ_a>Θ_a) - P(res_t>w_align) - P(intent_err)
```
关键：**可观测性先于精度**，**时间对齐先于空间对齐**，**意图后验先于动作承诺**。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|

## 6. 本轮最大风险

**一句话**：把手眼标定与语音交互引入后，证书链第一次拥有了“误差从何而来”的地基，但整条链的 soundness **同时押注于标定可观测性与意图后验的可靠性**；一旦运动退化导致 Σ_γ 被低估、或 ASR/接地过度自信使 p(A_T|u) 尖锐却错误，系统会以极高的形式置信度执行系统性错位动作，故必须以 **`σ_min` 硬门控 + 后验共形校准 + 证书 TTL/漂移监控** 三重护栏，宁可拒绝部署，也绝不把“可观测性不足下的伪精确标定”当作地基。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim*（CMC×VIG×ACD×TAC×CAC）

> 承接第 54 轮产物 v31。本轮不再新增“更高层能力”，而是**向下补地基**：把第 54 轮当作给定量的 `γ_ce` 与 `A_T` 改为 **可标定、可观测、带时间戳的估计量**。五个新算子：
> - **CMC（Cross-Modal Calibration）**：手眼标定的泛化，输出 `(T, Σ_T, o)` 三件套；
> - **VIG（Voice Intent Grounding）**：语音 → 意图后验 `p(A_T|u)` 与鲁棒覆盖；
> - **ACD（Active Clarification Dialogue）**：把澄清建模为信息增益最大的主动标定查询；
> - **TAC（Temporal Alignment Calibration）**：估计 `(Δ, α)`，签发时序证书；
> - **CAC（Calibration-aware Certificate）**：将标定/时序/意图不确定性注入第 54 轮联合证书 J。
>
> IP 编号：IP-121~IP-125（共 5 个新增），升级 IP-115/117/118 以接入标定层 ℂ。

```python
            post[L] = post.get(L, 0.0) + p_asr * p_sem
    post = calibrate_posterior(normalize(post))     # 温度/共形校准
    A_T_dist = {L: ground_to_action(L, scene) for L in post}
    return post, A_T_dist, entropy(post)

def robust_cover(skill, u, eps):
    post, A_T_dist, H = voice_intent_posterior(u, scene, asr, parser)
    p_ok = sum(p for L,p in post.items()
               if cover_check(skill.alpha, A_T_dist[L]))
    return p_ok >= 1 - eps, p_ok, H
```

### IP-123 ACD

```python
def clarify(u, Q, budget, H_stop):
    post, _, H = voice_intent_posterior(u, scene, asr, parser)
    asked = set()
    while H > H_stop and budget > 0:
        q, ig = max(((q, expected_info_gain(q, post))
                     for q in Q - asked),
                    key=lambda z: z[1] / cost(z[0]))
        a = ask_user(q); asked.add(q)
        post = bayes_update(post, q, a); H = entropy(post)
        budget -= cost(q)
    if H > H_stop:
        return ('fallback_safe', a_safe, post, H)
    return ('resolved', argmax(post), post, H)
```

### IP-124 TAC

```python
def temporal_calibrate(E_x, E_y, w_align):
    corr = match_events(E_x, E_y)                 # 语音事件 ↔ 动作事件锚点
    (alpha, Delta), inliers = robust_fit(corr)    # Huber / RANSAC
    Sigma_t = cov_from_inliers(inliers) * residual_scale
    res_t = max(abs(t_y - (alpha*t_x + Delta)) for t_x,t_y in inliers)
    if res_t > w_align or chi2_radius(Sigma_t) > w_align:
        return ('time_misaligned', res_t, Sigma_t)
    return ('ok', Delta, alpha, Sigma_t, res_t)
```

### IP-125 CAC

```python
def calibration_aware_certificate(skill_seq, cal_space, cal_time,
                                  intent_post, budgets, t_exp):
    if cal_space.o < o_min or not valid(cal_space, t_exp):
        return ('reject', 'calibration_invalid', cal_space)
    if cal_time is None or cal_time.res_t > w_align:
        return ('reject', 'time_misaligned', cal_time)
    delta = sum(s.delta_a + chi2_radius(s.cal.Sigma) for s in skill_seq)
    delta += drift_bound(cal_space, t_exp) + chi2_radius(cal_time.Sigma_t)
    if delta > budgets.delta_a:
        return ('reject', 'budget_exceeded', delta)
    if not robust_cover_chain(skill_seq, intent_post, budgets.eps):
        return ('reject', 'intent_ambiguous', entropy(intent_post))
    return ('ok', CertJ_C(skill_seq, cal_space, cal_time,
                          intent_post, delta))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CMC | O(n·d³) | O(n·d²) | `o≥o_min`；协方差一阶传播有效 |
| VIG | O(N·|L|·|scene|) | O(|L|) | n-best 召回；后验经共形校准 |
| ACD | O(B_q·|Q|·|L|) | O(|Q|·|L|) | 信息增益近似无偏；预算闭合 |
| TAC | O(n log n) | O(n) | 事件对应 + 线性时钟模型 |
| CAC | O(|S|·(|A|+|L|)) | O(|A|+|L|) | 误差预算递归 sound；TTL 门控 |

**正确性定理（Calibrated Cross-Modal Deployment Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** 成对观测 `σ_ε` 有界独立；**(A30)** 语音后验经校准且可靠性有下界；**(A31)** 时钟偏斜在 TTL 内近似线性；**(A32)** 澄清回答模型与查询成本已知。则
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(o_γ<o_min)
            - P(r_γ+δ_a>Θ_a) - P(res_t>w_align) - P(intent_err)
```
关键：**可观测性先于精度**；**时间对齐先于空间对齐**；**意图后验先于动作承诺**。

## 5. 本轮最大风险

**一句话**：把手眼标定与语音交互引入后，证书链第一次拥有了“误差从何而来”的地基，但整条链的 soundness **同时押注于标定可观测性与意图后验的可靠性**；一旦运动退化导致 Σ_γ 被低估、或 ASR/接地过度自信使 p(A_T|u) 尖锐却错误，系统会以极高的形式置信度执行系统性错位动作，故必须以 **`σ_min` 硬门控 + 后验共形校准 + 证书 TTL/漂移监控** 三重护栏，宁可拒绝部署，也绝不把“可观测性不足下的伪精确标定”当作地基。
