# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「排行榜」×「对比实验」）

> 第 54 轮把技能组合提升为动作剖面 + 云边协同 + 动作-鲁棒性联合证书。但所有证书最终都要被「比较」：谁更好、该部署谁、该信谁。本轮以「排行榜」与「对比实验」为透镜，指出排行榜本质是对高维对比实验的一次**有损压缩**，而压缩过程系统性地丢弃了**可比性前提**与**不确定性**。核心矛盾：H24：排行榜把带支撑域的偏序压成标量全序，制造"不可比系统间的虚假冠军"；H25：对比实验的统计显著 ≠ 证书可兑现，多重比较与选择偏差让排行榜冠军成为 winner's curse 的产物。

## 0. 直觉与动机

**灵感 1（排行榜 = 对比实验的有损压缩算子）**
直觉：真实的对比实验不是一个分数，而是一个带不确定性的**配对对比矩阵** `M`：每个元素是系统 i 与 j 在公共支撑域上的配对效应及置信区间。排行榜 `r` 只是 `M` 的一个标量投影。压缩会丢三样东西：**可比性**（哪些对根本不该比）、**序信息**（原本的偏序被强行全序化）、**不确定性**（CI 被抹成点估计）。所以问题不是"排行榜准不准"，而是"这张榜在哪些对上是**可兑现**的"。定义压缩损失 `L_rank = λ_c·CompViol + λ_o·RankInv + λ_u·UncCollapse`。

**灵感 2（可比性作为第一性约束 → 三值对比）**
直觉：两个系统可比，前提是它们的证书支撑域有足够重叠、动作剖面/数据覆盖对齐、评测协议一致；否则它们的分数差是"苹果比橘子"。于是比较关系从二值 `{≻,≺}` 升级为三值 `{≻,≺,⊥}`（`⊥` = incomparable）。排行榜因此从全序退化为**偏序（区间序/Pareto 序）**。**"拒绝排名"是一种正确输出**，而不是能力不足。

**灵感 3（稳健排名 → 抗抖动与置信名次）**
直觉：排行榜对随机种子、指标权重、样本量极其敏感（"排行榜抖动"）。用配对 bootstrap / 置信序列估计 top-k 成员稳定性与 Kendall τ 的下界，只在**稳定区**发布名次；不稳定区标"并列/未决"。名次不再是一个数字，而是一个带置信集的区间 `[r_lo, r_hi]`。这把第 53 轮的"鲁棒性谱"思想搬到评测侧：**评测结论本身也要有鲁棒性谱**。

**灵感 4（对比实验的预注册与配对设计 → 可比性可判定）**
直觉：可信的对比实验 = 预注册 + 配对设计（共同随机数、配对种子）+ 公共支撑采样 + 多重比较校正。把这些固化成 **对比实验证书 `C_cmp`**，使"这次比较是否合法"可被第三方审计。没有 `C_cmp` 的榜单条目视为"未认证"，不进正式榜。这把"对比实验"从一次性动作变成**可复用的判定对象**。

**灵感 5（反 Goodhart → 选择分数与认证分数分离）**
直觉：一旦排行榜成为优化目标，参赛者会过拟合榜单（benchmark overfitting / leaderboard gaming）。缓解不是"造更严的榜"，而是**分离两套分数**：认证分数（公开、带支撑域、带 CI）与选择分数（私有、用于内部采集）。并持续监测训练榜与留出榜的排名一致性 gap；gap 突增即判定榜单被污染并冻结审计。

**灵感 6（金字塔扩展）**
在第 54 轮的鲁棒性层 `𝕃` 与动作-协同层 `𝔸` 之上，再叠 **可比性-竞赛层 `ℂ`**：`ℂ_0` 原始实验记录，`ℂ_1` 配对对比矩阵 `M`，`ℂ_2` 可比性判定（三值），`ℂ_3` 证书化偏序排行榜。跨层证书从 `(ρ,A_cert,J)` 升级为 `(ρ,A_cert,J,C_cmp,rank_cert)`。

## 1. 形式化定义（增量：定义 127–132）

**定义 127（配对对比矩阵）**
系统集合 `𝒮={S_1,...,S_n}`，任务/场景支撑 `Ω`。对每对 `(i,j)` 在公共支撑 `Ω_ij = dom(C_i) ∩ dom(C_j)` 上做配对实验，配对效应
```
d_ij = (1/(|T|·|Σ|)) Σ_{t∈T} Σ_{s∈Σ} (s_i(t,s) - s_j(t,s)),   CI_ij(α) = bootstrap(diffs, α)
```
`M = {(i,j, d_ij, CI_ij, |Ω_ij|)}`。配对使用共同随机数（common random numbers），以消除环境噪声差。

**定义 128（评测可比性）**
可比核
```
compat_eval(i,j) = fit_D(Ω_ij) · align(α_i, α_j) · proto_match(i,j)
```
其中 `fit_D` 为证书支撑覆盖（承接第 54 轮定义 122），`align` 为动作剖面一致性，`proto_match∈{0,1}` 为评测协议一致。`S_i` 与 `S_j` **可比** 当且仅当 `compat_eval(i,j) ≥ θ_cmp ∧ |Ω_ij| ≥ N_min`。

**定义 129（证书化偏序排行榜）**
三值关系：
```
S_i ≻_C S_j  iff  compat_eval(i,j) ≥ θ_cmp ∧ LCB(d_ij) > ε_margin
S_i ≺_C S_j  iff  compat_eval(i,j) ≥ θ_cmp ∧ UCB(d_ij) < -ε_margin
否则           S_i ⊥_C S_j
```
排行榜输出偏序 `(𝒮, ≻_C)` 及每对证据，而非单一全序。

**定义 130（排行榜压缩损失 / 可兑现排名）**
给定"真"配对矩阵 `M` 与发布榜 `r`：
```
L_rank = λ_c·CompViol + λ_o·RankInv + λ_u·UncCollapse
CompViol = |{发布为可比但对不可比}| / |pairs|
RankInv  = |{可比对上与 LCB 序不一致}| / |comparable pairs|
UncCollapse = 1 - (发布 CI 宽度 / 真实 CI 宽度)
```
一个排行榜"可兑现"当且仅当 `L_rank ≤ L_max`。

**定义 131（排名稳定性）**
对 `M` 做 `B` 次配对 bootstrap 得排名集合 `{r_b}`：
```
stability@k = P(top-k 成员集不变) ≈ (1/B) Σ_b 1[top_k(r_b) = top_k(r_ref)]
τ_lo = Kendall τ 的 α 下界
```
仅当 `stability@k ≥ θ_s` 时 top-k 可发布，否则该区标记"并列/未决"。

**定义 132（对比实验证书与联合排名证书）**
```
C_cmp = (Ω_ij, compat_eval, paired_design, multiplicity, effect_CI, prereg_hash)
J''   = (J', C_cmp, rank_cert),  rank_cert = (≻_C, stability, incomparability_mass)
```
发布条件：`C_cmp 有效 ∧ stability@k ≥ θ_s ∧ incomparability_mass ≤ M_max`。任一不满足则拒绝发布名次（可发布"不可比/未决"结论）。

## 2. 关键算法 伪代码

### IP-121 PCE（Paired Comparison Experiment）

```python
def paired_comparison(systems, tasks, seeds, alpha, theta_fit, N_min):
    M = {}
    for i, j in combinations(systems, 2):
        omega = intersect_domains(cert[i].domain, cert[j].domain)
        if fit(omega) < theta_fit or len(omega) < N_min:
            M[(i,j)] = Incomparable(reason='support_gap'); continue
        diffs = []
        for t in tasks:
            for s in seeds:                      # 配对种子 + 共同随机数
                diffs.append(run_paired(i, j, t, s, common_random=True))
        d, ci = mean(diffs), bootstrap_ci(diffs, alpha)
        M[(i,j)] = PairedEffect(d, ci, omega, paired=True)
    return holm_bonferroni(M, alpha)             # 多重比较校正
```

### IP-122 CRA（Comparability-Aware Ranking）

```python
def comparability_aware_ranking(M, theta_cmp, eps_margin):
    rel = {}
    for (i,j), e in M.items():
        if isinstance(e, Incomparable) or compat_eval(i,j) < theta_cmp:
            rel[(i,j)] = '⊥'; continue
        if e.ci.low > eps_margin:      rel[(i,j)] = '≻'
        elif e.ci.high < -eps_margin:  rel[(i,j)] = '≺'
        else:                          rel[(i,j)] = '⊥'   # 统计不可分
    return transitive_closure_partial_order(rel)
```

### IP-123 LSC（Leaderboard Stability Certificate）

```python
def rank_stability(M, B=1000, k=3, alpha=0.05):
    tops, taus = [], []
    for _ in range(B):
        Mb = paired_bootstrap(M)
        r  = comparability_aware_ranking(Mb, theta_cmp, eps_margin)
        tops.append(set(top_k(r, k))); taus.append(kendall_tau(r, r_ref))
    return Stability(top_k_invariance=frac_equal(tops),
                     tau_lower=quantile(taus, alpha),
                     unstable=[s for s in systems if membership_entropy(s) > H_max])
```

### IP-124 GOD（Goodhart / Overfitting Detector）

```python
def goodhart_monitor(train_board, heldout_board, gap_baseline, delta_gap):
    gap = 1 - kendall_tau(rank(train_board), rank(heldout_board))
    if abs(gap - gap_baseline) > delta_gap or heldout_rank_collapse(heldout_board):
        return ('contaminated', freeze_board(), audit_lineage())
    return ('ok', gap)
```

### IP-125 CLC（Certificate Leaderboard Compiler）

```python
def compile_leaderboard(systems, certs, tasks, seeds, alpha):
    M  = paired_comparison(systems, tasks, seeds, alpha, theta_fit, N_min)
    rel = comparability_aware_ranking(M, theta_cmp, eps_margin)
    st = rank_stability(M, B, k)
    published = {}
    for s in systems:
        if certs[s].C_cmp is None: continue       # 未认证不进正式榜
        published[s] = RankInterval(st.interval(s), domain=certs[s].domain,
                                    comparable_to=rel.neighbors(s))
    return CertificateLeaderboard(published,
                                  incomparability_mass=rel.incomparable_fraction,
                                  stable_region=st.stable)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| PCE | O(n²·|T|·|Σ|·C_run) | O(n²) | 公共支撑采样、配对/共同随机数、FWER 控制 |
| CRA | O(n²) + 传递闭包 O(n³/word) | O(n²) | 三值关系 sound、可比性优先于显著性 |
| LSC | O(B·(n² + n log n)) | O(n²) | bootstrap 一致、top-k 不变率可估 |
| GOD | O(n log n) 每窗口 | O(n) | 留出榜独立、rank gap 可检 |
| CLC | O(n² + B·n²) | O(n²) | 偏序编译、不可比质量显式披露 |

**正确性定理（Comparability-Aware Ranking Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** 配对实验在公共支撑上采样且使用共同随机数；**(A30)** 多重比较校正在族水平控制 `FWER ≤ α`；**(A31)** bootstrap 排名稳定性估计一致。
则对任一发布结论：
```
P(发布 S_i≻_C S_j 但真实不优) ≤ α
Regret(部署决策 | 榜) ≤ incomparability_mass + (1 - stability@k)
```
关键：**先判可比，再判显著，最后判稳定**；三者缺一不得发布名次。排行榜因此不是"谁第一"，而是"在哪些可比对上、以多大置信、谁不差于谁"。

## 4. 实验设计 E162–E166

| 实验 | 指标 | 目标 |
|---|---|---|
| E162 排行榜抖动 | `stability@3`、`τ_lo` | 稳定区 `≥0.90`，显式报告不稳定区大小 |
| E163 可比性判定 | 假可比率 / 假不可比率 | 假可比 `≤5%`，假不可比 `≤10%` |
| E164 多重比较校正 | 经验 FWER / FDR | FWER `≤ α`；对比 naive vs Holm/BH |
| E165 榜单过拟合检测 | 检测器 AUROC、rank gap | AUROC `≥0.85`，gap 阈值可迁移 |
| E166 偏序榜 vs 标量榜 | 部署决策 regret、漂移下成功率 | regret 降低 `≥10%`，并披露 incomparability_mass |

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| θ_cmp 过严导致榜单退化为空 | 高 | 显式 incomparability 预算 + 分层可比域 + 报告"未决" |
| θ_cmp 过松重新引入虚假全序 | 高 | 支撑覆盖硬门槛 + 红队构造不可比对 |
| 证书 Goodhart（针对榜口径过拟合） | 高 | 预注册 + 留出支撑 + 选择/认证分数分离 |
| bootstrap 低估排名不确定性 | 中 | 块 bootstrap + 置信序列 + 多种子复核 |
| 多重比较校正过度保守 | 中 | BH 控制 FDR + 预注册主指标分层 |

## 6. 本轮最大风险

**一句话**：证书化偏序排行榜的诚实性可能以可用性为代价——`θ_cmp` 过严会让绝大多数系统对判为 incomparable、榜单退化为空，`θ_cmp` 过松则重新引入虚假全序；更隐蔽的是，一旦该榜成为优化目标，参赛者会针对"证书支撑域 + 稳定性口径"过拟合（证书 Goodhart），故必须以 **预注册 + 留出支撑 + incomparability 预算显式披露 + 选择/认证分数分离** 四重护栏，宁可发布"未决/不可比"，也不发布一个看似精确、实则不可兑现的冠军。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（PCE×CRA×LSC×GOD×CLC×JRC）

> 承接第 54 轮产物 v31。本轮在动作-鲁棒性双证书体系之上，增加 **对比实验可判定化、排行榜证书化、排名稳健化、反 Goodhart** 四大算子：
> - **PCE（Paired Comparison Experiment）**：公共支撑上的配对对比矩阵 `M` + 对比实验证书 `C_cmp`；
> - **CRA（Comparability-Aware Ranking）**：三值偏序排行榜 `{≻,≺,⊥}`，可比性优先于显著性；
> - **LSC（Leaderboard Stability Certificate）**：top-k 稳定性与 Kendall τ 下界，只发布稳定区名次；
> - **GOD（Goodhart / Overfitting Detector）**：训练榜/留出榜 rank gap 监测，识别榜单污染；
> - **CLC（Certificate Leaderboard Compiler）**：把系统 + 证书编译成带支撑域与置信区间的偏序榜；
> - **JRC（Joint Ranking Certificate）**：将 `C_cmp` 与 `rank_cert` 并入联合证书 `J''`。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-118/120 以纳入可比性与排名证据。

|---|---|---|---|
| PCE | O(n²·|T|·|Σ|·C_run) | O(n²) | 公共支撑采样、配对/共同随机数、FWER ≤ α |
| CRA | O(n² + n³/word) | O(n²) | 三值关系 sound，可比性优先于显著性 |
| LSC | O(B·(n²+n log n)) | O(n²) | bootstrap 一致，top-k 不变率可估 |
| GOD | O(n log n)/窗口 | O(n) | 留出榜独立，rank gap 可检 |
| CLC | O(n² + B·n²) | O(n²) | 偏序编译，不可比质量显式披露 |
| JRC | O(n² + |𝔇_ρ|) | O(n²) | 联合证书 sound，预算闭合 |

**正确性定理（Comparability-Aware Ranking Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** 配对实验在公共支撑上采样且使用共同随机数；**(A30)** 多重比较校正在族水平控制 `FWER ≤ α`；**(A31)** bootstrap 排名稳定性估计一致。
则：
```
P(发布 S_i≻_C S_j 但真实不优) ≤ α
Regret(部署决策 | 榜) ≤ incomparability_mass + (1 - stability@k)
```
关键：**先判可比，再判显著，最后判稳定**；任一环节失败则发布"不可比/未决"，而非强行给名次。

## 5. 本轮最大风险

**一句话**：证书化偏序排行榜的诚实性可能以可用性为代价——`θ_cmp` 过严会让绝大多数系统对判为 incomparable、榜单退化为空，`θ_cmp` 过松则重新引入虚假全序；更隐蔽的是，一旦该榜成为优化目标，参赛者会针对"证书支撑域 + 稳定性口径"过拟合（证书 Goodhart），故必须以 **预注册 + 留出支撑 + incomparability 预算显式披露 + 选择/认证分数分离** 四重护栏，宁可发布"未决/不可比"，也不发布一个看似精确、实则不可兑现的冠军。
