# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「社会规范理解」×「消融实验」）

> R69 给了系统一张嘴（看 / 问 / 触），并用 `VoI − c` 决定何时开口；但它把「社会成本」压成一个标量 `c(g)`，把「规范」降格成「价钱」。真实世界里规范不是价钱，是**语法**：有些动作不是「贵」，而是**不该做**（不能盯着陌生人看、不能未经允许触碰、不能在众目睽睽下追问隐私）；有些动作不是「可选」，而是**必须做**（先致意、先让行、先说明意图）。更麻烦的是，规范会**污染证据本身**：一句冒犯的问话得到的不是答案，而是敷衍、顺从或拒绝——R69 的证据纪律再严，也拦不住「礼貌偏差」这种良性投毒。
>
> 本轮两个灵感恰好补两块缺失：
> - **社会规范理解**把交互从「值不值得问」升级为「**允不允许问、以什么方式问、问了对方会不会说真话**」——规范是道义约束（许可 / 义务 / 禁止），不是效用项；
> - **消融实验**则是一次方法论清算：R66–R69 连加四层，每轮只做「关掉本层看掉多少」的单因子消融（OFAT），而组件高度门控耦合（MCG 门控 MINT、FMA 决定是否问、规范层能整体关闭交互）。OFAT 会把「被别的层借来的功劳」记到本层头上，也会因辛普森悖论把「只对多数群体有效」误判成全局有效。
>
> 核心命题：**规范是交互策略的一等约束——可推断、多元、且会改变答案可信度；而任何组件（包括本轮新增的规范层）的正当性，必须由「规范分层的、交互感知的消融 / 归因」来证明，而不是由单因子掉点来宣称。** 命名 **NORM-RAS**（Norm-Governed, Obligation-aware, Relational Multimodal Risk-Adaptive System），配套消融协议 **N-SAID**（Norm-Stratified Ablation & Interaction Decomposition）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我有没有资格问，以及我凭什么相信这个答案**」——礼貌不是软性约束，而是交互证据链的第一道真实性检查。

## 0. 直觉与动机

**灵感 1（规范不是标量成本，而是道义语法）**
直觉：R69 的 `c(g)` 隐含「只要够值，什么都能问」。但规范是 deontic 的：`P`（许可）/`O`（义务）/`F`（禁止）三类模态不可与效用作等价交换。一个禁止动作的信息价值再高也不能执行（禁止的代价不是高，是 ∞）；一个义务动作即使亏本也必须做（先表明身份、先让行、先说明意图）。把 `F` 折进 `c(g)` 会让优化器在「收益足够大」时越界；把 `O` 折进 `c(g)` 会让它在「赶时间」时失礼。因此规范必须是**可行域约束**（定义 313），而不是目标函数里的一个可调惩罚项。

**灵感 2（规范是关系的、多元的、可推断的）**
直觉：同一句「你还好吗」，对朋友是关心，对陌生人是冒犯；同一束注视，对孩子是保护，对成人是凝视。规范依赖上下文 `κ = (角色, 关系, 场所, 紧迫度, 文化, 在场观众)`。系统不能持有一张全局规范表，必须对 `N | o, κ` 做**概率推断**，并承认规范本身多元且有争议（不同群体对同一动作的许可度不同）。这直接决定：**不确定时不能假装确定**，而应收缩到「普遍许可核」。

**灵感 3（规范会污染证据：礼貌是一种良性投毒）**
直觉：本轮最关键的耦合。R69 的投毒模型假设「人会撒谎」；但更常见的是**人不会撒谎，只是不愿说、不敢说、或顺着你说**：冒犯性提问 → 拒绝回答（删失）；诱导性提问 → 顺从性回答（social desirability bias）；权力不对等 → 对方说「你决定就好」。这些不是恶意攻击，却同样让「已验证」的章盖在假答案上。因此规范违反同时抬高成本并降低答案可信度 `trust(g)`。R69 把「问错」视为投毒；R70 进一步指出**不合规地问，问到的多半不是真话**——所以规范层首先是**证据质量层**，其次才是礼貌层。

**灵感 4（消融：层数越多，单因子归因越不可信）**
直觉：R66–R69 的消融都是 OFAT（一次只关一个模块）。但本栈的模块是**门控耦合**的：没有 AUD 的模态分解，MINT 没有候选；没有 MCG，MINT 可能在不可信模态上乱问；没有 FMA，slow-fault 分支会改变是否允许交互；没有 NORM，交互可能被规范层整体关闭。OFAT 下「关掉 MINT」看似掉点，其实掉的是「MINT + AUD 的联合能力」，而「单独 MINT」的边际可能接近 0——**功劳被错记，缺陷被掩盖**。正确做法是因子设计 + Shapley / 交互指数归因，显式估计 `I(S)` 交互项。

**灵感 5（规范分层消融：礼貌可能只是对多数人的礼貌）**
直觉：规范层天然按群体不同。一个规范模型可以在**总体**指标上变好，却在少数 / 非典型语境上让系统「过度礼貌 → 减少求证 → 更差服务」。池化消融会因辛普森悖论给出正的边际贡献。故本轮的方法论承诺是：**消融必须按规范群体分层报告**，并要求组件不得以牺牲某群体为代价换取总体收益（公平掩蔽指数 FMI，定义 321）。

## 1. 形式化定义（增量：定义 310–323）

**定义 310（NORM-RAS 总览）** NORM-RAS = (NMI, NDC, RIU, NEB, NTG, N-SAID, RAS-WM‡)。五不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **交互预算硬约束**（继承 R69 定义 293-ii）；
(iii) **证据纪律**（继承 R69 定义 293-iii）；
(iv) **规范安全**：任何信息动作须在道义可行域内（定义 313）；规范后验不确定 / 冲突时只允许**普遍许可核** `𝒜_info^univ`，否则不交互；
(v) **可消融问责**：任何组件（含 NMI / NDC / NTG 自身）须在 N-SAID 下报告规范分层、含交互项的边际贡献（定义 319–322），否则不得计入收益。

**定义 311（规范本体与道义算子）** 上下文 `κ = (role, relation, place, urgency, culture, audience)`。规范条目 `n = (op, c, cond, strength, source)`，其中 `op ∈ {P, O, F}`（许可 / 义务 / 禁止），`c ∈ 𝒞` 为动作类（gaze / probe / ask 的子类），`cond` 为触发条件，`strength ∈ [0,1]` 为规范强度（可违反的软规范强度低，硬规范接近 1），`source` 为来源（法律 / 组织 / 习俗 / 个人偏好）。上下文相关规范集 `N_κ ⊆ 2^{条目}`；`P / O / F` 作用在**动作类**而非单条轨迹，避免对连续动作逐点枚举。

**定义 312（规范推断 NMI）** 规范后验 `q(N | o, κ) ∝ p(o | N) · p(N | κ)`，由三条证据融合：离线规范先验 `p(N | κ)`、现场线索（他人反应、场合标识、既往互动）、以及（可选）一次显式的**元询问**「我可以……吗？」。输出不是点估计，而是 `q` 及支持集 `Supp_τ = {N : q(N) ≥ τ_N}`。元询问本身受定义 313 约束（不能以追问隐私的方式询问是否可问）。

**定义 313（道义可行域 NDC）** 给定 `q` 与容差 `(δ_F, δ_O)`，
`𝒜_info^adm = { g ∈ 𝒜_info : max_{N ∈ Supp_τ} Pr(F(g) | N) ≤ δ_F  ∧  max_{N ∈ Supp_τ} Pr(¬O_done(g) | N) ≤ δ_O }`。
若 `𝒜_info^adm = ∅`，只保留**普遍许可核** `𝒜_info^univ ⊆ 𝒜_info^adm`（例如符合公共规范的注视与等待；不含探针、不含隐私问句）。若连 `𝒜_info^univ` 都不可证，则不交互。

**定义 314（规范敏感信息效用 RIU）** `VoI_norm(g) = trust(g) · VoI(g) − c_norm(g)`，其中 `VoI(g)` 继承 R69 定义 298，`trust(g) = 1 − β · viol(g)` 为答案真实度折扣（`viol ∈ [0,1]` 为规范违反度，`β` 为顺从偏差系数），`c_norm(g) = c_phys(g) + c_rel(g)`（物理 + 关系成本）。`g ∉ 𝒜_info^adm ⇒ VoI_norm(g) = −∞`。选择 `g* = argmax VoI_norm`；若 `VoI_norm(g*) ≤ 0` 则不交互，退 FLUID 保守分支。

**定义 315（规范条件证据模型 NEB）** 回答 `y` 的似然建模为
`p(y | g, M, N) = (1 − δ_c(g)) · p_true(y | M) + δ_c(g) · p_comply(y | g, M)`，
其中 `δ_c(g) = β · viol(g)` 为顺从 / 讨好混合权重，`p_comply` 倾向于复述提问者暗示的模态。拒绝 / 沉默 `y = ⊥` 视为**删失观测**，用删失似然 `Pr(⊥ | g, M, N)` 进入后验，而非当作缺失随机丢弃。R69 的「k 个正交证据源一致」纪律升级为：**先扣除顺从分量，再要求一致**。

**定义 316（规范多元与群体分层）** 规范群体 `G`（按文化 / 角色 / 脆弱性划分），每群有自己的 `q_g` 与可行域 `𝒜_g^adm`。策略不得只优化群体加权平均；要求逐群最差约束 `∀g : VoI_norm^g(g*) ≥ 0 ∨ 不交互`，并将逐群结果交审计（定义 321）。规范冲突时给 Pareto 报告，不做单一标量化。

**定义 317（规范威胁治理 NTG）** 禁止：以诱导性措辞获取答案、超时长凝视、越力 / 越位探针、借「询问许可」套取隐私、以提问实施社交工程。NTG 对候选 `g` 做**规范红队检查**，任一触发 ⇒ `g` 作废。与 R69 的 `ℰ_poison` 合并为 `ℰ_NORM = ℰ_poison × ℰ_norm-cue`（伪造规范线索：假制服、假权威、假紧急）。

**定义 318（规范记忆与版本）** 规范先验只在离线 / 审计窗口更新（继承零实时写操作）；实时只读 `p(N | κ)` 的版本化快照。规范漂移以「版本差」度量，旧策略在新版本下的越界率纳入审计，不回写实时环。

**定义 319（消融因子与响应）** 因子向量 `x ∈ {0,1}^k`，`k = |{FMP, AUD, MINT, CIA, FMA, MCG, NMI, NDC, NTG}| = 9`；响应向量 `f(x) = (R_task, R_norm, success, ECE, latency, per-group metrics)`。允许分数因子设计（resolution ≥ V）控制成本；关键交互用全因子补齐。

**定义 320（交互感知归因）** Möbius 交互指数 `I(S) = Σ_{T ⊆ S} (−1)^{|S|−|T|} f(T)`；Shapley 值 `φ_i = Σ_{S ∌ i} [|S|!(k−|S|−1)!/k!] · [f(S ∪ {i}) − f(S)]`。**OFAT 边际** `Δ_i^OFAT = f({i}) − f(∅)`。三者关系：`φ_i` 与 `Δ_i^OFAT` 仅在所有 `|S| ≥ 2` 的 `I(S) = 0`（可加）时相等；否则 `Δ_i^OFAT` 系统性遗漏含 `i` 的高阶交互项。

**定义 321（规范分层消融与公平掩蔽指数）** 对每群 `g` 估计 `φ_i^g`。池化 `φ_i = Σ_g π_g φ_i^g`。**公平掩蔽指数** `FMI_i = max_g φ_i^g − min_g φ_i^g`。组件 `i` 通过当且仅当：`φ_i ≥ τ_φ`（有真实贡献）∧ `min_g φ_i^g ≥ −τ_h`（不显著伤害任何群）∧ `FMI_i ≤ τ_f`（效应不随群体剧烈翻转）。

**定义 322（消融证书 J_ABLATE）** `J_ABLATE = (design_matrix, I(S)_{|S|≥2}, φ_i, φ_i^g, FMI_i, CIs, prereg_hash)`。Valid ⇔ 设计已预注册 ∧ 交互项已报告 ∧ 逐群 CI 已给出 ∧ 未通过组件已被移除或标注。

**定义 323（三级退避与证书 J_NORM）** 层级：**NORM**（规范可证、`g ∈ 𝒜_info^adm`、`trust` 高）→ **FLUID-min**（仅 `𝒜_info^univ` 的被动信息动作，复用 R69 保守缩放）→ **R68**（不交互）。`J_NORM = (J_FLUID, norm_posterior_hash, deontic_admissible_set_hash, trust_score, viol_rate_p95, ablation_cert, norm_ver)`。Valid ⇔ `Valid(J_FLUID) ∧ viol_rate ≤ δ_F ∧ J_ABLATE.Valid`。

# IP-264 NMI：规范后验推断（离线先验 + 现场线索 + 可选元询问）
def infer_norms(o, kappa, prior_snapshot):
    q = bayes(prior_snapshot[kappa], cues(o))          # 支持集 Supp_tau
    return q, support_set(q, tau_N)

# IP-265 NDC：道义可行域（禁止=硬约束；不确定→普遍许可核）
def admissible_info_set(q, delta_F, delta_O):
    adm = [g for g in INFO_ACTIONS
           if worst_case_forbid(q, g) <= delta_F
           and worst_case_omit_obligation(q, g) <= delta_O]
    return adm if adm else UNIVERSAL_PERMISSIBLE_CORE   # 可能为空

# IP-266 RIU：规范敏感 VoI（含答案真实度折扣）
def choose_interaction_norm(modes, o, q, budget):
    adm = admissible_info_set(q, DELTA_F, DELTA_O)
    best = None
    for g in [g for g in info_action_candidates(modes) if g in adm]:
        if not budget.allow(g) or not nt_g.check(g, o): continue
        voi = trust(g, q) * voi_plain(g, modes, o) - c_phys(g) - c_rel(g, q)
        if best is None or voi > best.voi: best = (g, voi)
    return best if best and best.voi > 0 else None      # ≤0 → FLUID 保守分支

# IP-267 NEB：顺从偏差 + 拒绝删失 的规范条件证据
def update_belief_norm(modes, g, y, q):
    if y == REFUSAL:
        return censor_update(modes, p_refuse(g, modes, q))   # 删失，不是缺失
    w = beta * violation(g, q)
    post_true    = bayes_update(modes, y, source='true')
    return (1 - w) * post_true + w * bayes_update(modes, y, source='comply')

# IP-269 N-SAID：因子设计 + Shapley + Möbius 交互（离线）
def n_said(factors, f, groups, design):
    runs = design.expand(factors)                        # 分数/全因子
    responses = {x: f(x) for x in runs}
    I = {S: mobius(responses, S) for S in powerset(factors) if len(S) >= 2}
    phi = {i: shapley(responses, i) for i in factors}
    phi_g = {g: {i: shapley(responses, i, subset=g) for i in factors}
             for g in groups}
    fmi = {i: max(phi_g[g][i] for g in groups)
              - min(phi_g[g][i] for g in groups) for i in factors}
    return I, phi, phi_g, fmi

# IP-272 主闭环（三级退避）
def NORM_RAS_round(M, obs):
    z, o = M.mtm.forward(obs); c, U_cal, thr = M.cof.step(o)
    q, supp = M.nmi.infer(o, kappa=obs.context)
    adm     = M.ndc.admissible(q)
    # R69 的歧义与第二意见仍然保留
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)

    # 规范门控：不可证 → 只允许普遍许可核；再不行 → 不交互

## 3. 推导

**引理 19（规范违反的证据折扣上界）** 设信息动作 `g` 的规范违反度为 `v = viol(g)`，顺从偏差系数 `β`，则其期望信息增益满足
`VoI_norm(g) ≤ (1 − βv) · VoI_plain(g) − c_norm(g)`。
证明要点：`y` 以权重 `βv` 来自 `p_comply`，而 `p_comply` 由提问的暗示决定、对真实模态 `M` 的条件互信息至多为 0，故混合后 `I(M; y | g) ≤ (1 − βv)·I_plain(M; y | g)`；再减成本即得。系：**存在合规替代 `g'` 使 `(1−βv)VoI(g) < VoI(g')` 时，冒犯地多问不如礼貌地少问**——高名义 VoI 可被 `βv` 抵消。

**引理 20（规范不确定性 → 可行域单调收缩）** 若支持集扩大 `Supp_τ ⊆ Supp'_τ`，则 `𝒜_info^adm(Supp') ⊆ 𝒜_info^adm(Supp)`；当 `Supp_τ` 覆盖全部规范假设时，`𝒜_info^adm → 𝒜_info^univ`。因此交互率随规范后验熵单调不增，而规范违反概率始终被 `δ_F` 上界约束。系：**越不确定越像 R68**——不确定性不是靠「更谨慎地问」，而是靠「更少地问且只做普遍许可的动作」。

**引理 21（OFAT 的交互偏差）** 设门控结构使 MINT 仅在 AUD 开启时有效。则 `Δ_MINT^OFAT = f({MINT}) − f(∅) = 0`，而
`φ_MINT = ½[f({AUD,MINT}) − f({AUD})] > 0`（若 MINT 在 AUD 条件下有贡献）。
一般地，`Δ_i^OFAT` 等于 `φ_i` 减去所有含 `i`、`|S| ≥ 2` 的 Möbius 交互项之加权和；故 **OFAT 仅在系统可加（`I(S)=0`）时无偏**。系：任何「关掉本层掉多少」的主张，必须附带交互项 `I(S)` 报告，否则不可采信。

**引理 22（规范分层的辛普森反转）** 存在群体分布 `π_g` 与组件效应，使池化 `φ_i = Σ_g π_g φ_i^g > 0`，而存在群体 `g` 使 `φ_i^g < 0`。此时总体消融通过、分层消融否决。`FMI_i = max_g φ_i^g − min_g φ_i^g` 可检出该反转；要求 `min_g φ_i^g ≥ −τ_h` 才能防止「以少数群体换总体收益」。

**定理 18（NORM 是 FLUID 的道义约束扩展）** 在 A99（规范条件证据模型、`β` 有界）下：
(i) NORM 的任一交互动作均在 `𝒜_info^adm` 内，故 `R_norm(NORM) ≤ R_norm(FLUID)`；
(ii) 当 FLUID 选中的动作**已合规**且 `trust = 1`、`c_norm = c` 时，`VoI_norm` 与 R69 的 `VoI − c` 同序，NORM 与 FLUID **逐指令相同**；
(iii) 当 FLUID 的动作被禁止时，NORM 的复合风险严格更低（禁止项为硬约束）；
(iv) 但 NORM 的**纯任务风险**可能高于 FLUID——这是为合规付出的显式代价，必须与 `R_norm` 一同报告，不得只报成功率。
故 R69 是 NORM 在「规范完全宽松且答案无顺从偏差」边界上的退化。

**定理 19（可消融识别的充分条件）** 若设计覆盖因子交互闭包的全因子（或足够高分辨率的分数因子 + 补齐），则 `φ_i`、`I(S)` 可识别；且 `Δ_i^OFAT = φ_i` 当且仅当所有含 `i` 的 `|S| ≥ 2` 交互项为零。于是「OFAT 通过」可作为「可加系统」的充分证据，但在本栈的门控耦合下不成立，**必须报告交互项与分层效应**。系：N-SAID 的证书（定义 322）把「消融」从修辞变成可复现的归因证据。

## 6. 本轮最大风险

**一句话**：NORM-RAS 的最大风险是**规范推断并不中立**——它可能把「多数群体的规范」当成「普遍规范」，从而以「合规」之名系统性地对少数 / 非典型语境**减少求证**（过度礼貌 = 不作为），而聚合消融因辛普森悖论仍显示正收益，最终让系统**礼貌、自信、且恰好对最需要帮助的人最没用**。

**次级风险与缓解**：
1. **规范过度推断（假禁止 → 瘫痪）** → 只在 `Support_τ` 上取最坏情况 + 保留普遍许可核，宁可少问不可乱问，但保证不退化为完全不作为；
2. **规范欠推断（失礼 / 冒犯）** → NTG 红队 + `δ_F` 硬约束 + 人类研究 E315；
3. **元询问本身越界（借许可套隐私）** → 元询问也进 `𝒜_info` 与 NDC，递归受同一约束；
4. **顺从偏差估计错误** → E303 标定 `β`，`trust` 折扣保守取上界，`β` 越界即退 FLUID；
5. **消融结论被耦合欺骗** → 强制报告 `I(S)` 与逐群 `φ_i^g`，`J_ABLATE` 未通过不得计入收益；
6. **规范版本漂移** → 只读快照 + 离线版本化 + 越界率审计（定义 318）。

## 4. 推导

**引理 19（规范违反的证据折扣）** `v = viol(g)`、顺从系数 `β`，则 `VoI_norm(g) ≤ (1−βv)·VoI_plain(g) − c_norm(g)`。因 `p_comply` 由提问暗示决定、对真实模态 `M` 的条件互信息至多为 0，混合后信息量按 `(1−βv)` 折损。系：**高名义 VoI 可被 `βv` 抵消——冒犯地多问不如礼貌地少问。**

**引理 20（规范不确定性 → 可行域单调收缩）** `Supp_τ ⊆ Supp'_τ ⇒ 𝒜^adm(Supp') ⊆ 𝒜^adm(Supp)`；覆盖全假设时 `𝒜^adm → 𝒜_info^univ`。故交互率随规范后验熵单调不增，违规概率始终 `≤ δ_F`。系：**越不确定越像 R68——少问，且只做普遍许可的动作。**

**引理 21（OFAT 的交互偏差）** 门控使 MINT 依赖 AUD 时，`Δ_MINT^OFAT = f({MINT})−f(∅) = 0`，而 `φ_MINT = ½[f({AUD,MINT})−f({AUD})] > 0`。一般地 `Δ_i^OFAT` 遗漏所有含 `i` 的高阶 Möbius 项；**OFAT 仅在 `I(S)=0`（可加）时无偏**。系：任何消融主张须附带 `I(S)`，否则不可采信。

**引理 22（规范分层的辛普森反转）** 存在 `π_g` 与效应使池化 `φ_i = Σ π_g φ_i^g > 0` 但某群 `φ_i^g < 0`。`FMI_i` 可检出；要求 `min_g φ_i^g ≥ −τ_h` 防止以少数群体换总体收益。

**定理 18（NORM 是 FLUID 的道义约束扩展）** A99 下：(i) NORM 的交互均在 `𝒜_info^adm` 内 ⇒ `R_norm(NORM) ≤ R_norm(FLUID)`；(ii) 若 FLUID 动作已合规且 `trust=1`、`c_norm=c`，二者逐指令相同；(iii) FLUID 动作被禁止时 NORM 复合风险严格更低；(iv) 但 NORM 的**纯任务风险**可能更高——这是合规的显式代价，必须与 `R_norm` 同时报告。R69 = 「规范全宽松 + 无顺从偏差」边界。

**定理 19（可消融识别）** 覆盖交互闭包的全 / 高分辨率分数因子设计下，`φ_i`、`I(S)` 可识别；`Δ_i^OFAT = φ_i` 当且仅当所有含 `i` 的 `|S|≥2` 交互项为零。故本栈必须报告交互项与分层效应；N-SAID 证书把消融从修辞变为可复现归因。

## 7. 本轮最大风险

**一句话**：NORM-RAS 的最大风险是**规范推断并不中立**——它可能把「多数群体的规范」当成「普遍规范」，以「合规」之名对少数 / 非典型语境系统性**减少求证**（过度礼貌 = 不作为），而聚合消融因辛普森悖论仍显示正收益，最终让系统**礼貌、自信、且恰好对最需要帮助的人最没用**。

**次级风险与缓解**：规范过度推断（取支持集最坏情况 + 保留普遍许可核，避免瘫痪）；规范欠推断（NTG + `δ_F` + 人类研究）；元询问越界（递归进 NDC）；顺从偏差估计错误（`β` 标定 + 保守上界，越界退 FLUID）；消融被耦合欺骗（强制 `I(S)` + 逐群 `φ_i^g`，`J_ABLATE` 未过不计收益）；规范漂移（只读快照 + 离线版本化 + 越界审计）。
