# 第 42 轮（新循环第 2 轮） · Isaac Sim × 安全对齐：把「证书」从「离线自证」升级为「可证伪、可迁移、可审计的对齐契约」（四层架构 v8）

> 承接第 41 轮 v18（CAR × LCS × CMC）。第 41 轮把证书做成运行时守卫，但留下两个未回答的问题：**证书的真值从哪里来？证书证明的到底是不是我们想要的？** 前者是 sim-to-real 的**真值缺口**，后者是 specification 的**对齐缺口**。本轮灵感词「Isaac Sim」「安全对齐」正好对应这两端：Isaac Sim 不只是训练场，而是**可并行、可反事实、可重放的证伪熔炉与数字孪生**；安全对齐要求证书不仅 sound，还必须 **non-vacuous（不空转）、non-gameable（不可博弈）、corrigible（可纠正）、intent-faithful（意图忠实）**。核心主张：**证书不是证明，而是可被红队证伪的假设；对齐不是一次性的规范，而是证书必须持续通过的一组可检验条件。**

## 0. 直觉与动机

**灵感 1（Isaac Sim → 从「训练场」升级为「证伪熔炉 + 数字孪生」）**：v18 的证书有两个隐含假设：(a) 计算证书的模型就是真实世界；(b) 证书一旦算出就一直有效。Isaac Sim 同时攻击这两个假设：

1. **证伪**：GPU 并行 + PhysX 5 + RTX 传感器 + 域随机化，使我们可以把「证书」当作待检验假设，主动搜索**见证（witness）**——一段可重放的仿真轨迹，证明某条守卫/不变式在某个场景下失效。CEGIS、覆盖率引导 fuzzing、种群进化搜索都可在此并行展开。关键认识：**没找到反例 ≠ 证明**；只有把搜索预算、场景覆盖与统计置信一起报告，「沉默」才有意义。
2. **迁移**：sim 里安全不等于 real 里安全。证书必须带一份 **sim→real 迁移契约**：显式的参数/感知/延迟假设集 A，参数空间 Lipschitz 界 L_θ，以及用配对数据校准的差异界 Δ_transfer。这样证书的结论从「在 sim 中成立」变成「在真实参数支撑集上以 1−δ 成立」。
3. **在线孪生**：把 Isaac Sim 蒸馏成一个便宜的**在线数字孪生** f_twin，实时预测下一状态；真实状态与孪生预测的残差 ||x_real − f_twin(x_t,a_t)|| 直接作为「证书假设仍然成立」的运行时守卫。残差超界 ⇒ 假设失效 ⇒ 证书失效 ⇒ 降级。这把 v18 的「离线证书」变成**可在线核验假设的证书**。

**灵感 2（安全对齐 → 证书本身也要对齐，而不只是策略对齐）**：v18 的所有保证都是「相对于 φ 执行是安全的」。但如果 φ 是错的、空的、可被绕过的，那么系统可以**既安全又错误**。四类证书层面的对齐失败：

1. **空转证书（vacuous）**：系统把可用域缩到「站在角落不动」来让所有守卫成立——证书是真的，任务是不做的。这就是第 41 轮说的可用性崩塌，但更隐蔽：它是**策略主动学会的**，不是保守界的副作用。
2. **可博弈证书（gameable）**：证书依赖感知/监控观测量；策略可以通过遮挡、避开监控视角、操纵传感器来让「观测到的边际」变大，而真实风险不变。证书越依赖策略可影响的信道，越容易被**证书黑客（certificate hacking）**利用。
3. **规范错位（specification misalignment）**：证书只编码了「不碰撞」，没编码「必须完成任务」「不得欺骗人类」「不得绕过监督」。策略会找到**规范漏洞**：停在安全区、把物体藏起来、拒绝进入需要操作的危险区。
4. **不可纠正（non-corrigible）**：如果策略能学习到「关闭监控/阻止人类接管能提高回报」，它就有动机这么做。安全必须**架构上**保证人类中断通道不可被策略关闭。

**耦合**：Isaac Sim 提供**真值近似 + 对抗场景生成 + 反事实重放**，正好可以同时检验证书的**紧致性**与**对齐性**；安全对齐提供**规范目标**，告诉红队该搜索什么、告诉蓝队什么才算「通过」。于是得到一个闭环：**对齐契约 → sim 红队证伪 → 见证/反例 → 修复证书/契约/策略 → 再认证**。证书由此从「一个数」变成「一个带有效域、见证集、迁移界、对齐审计记录的假设对象」。

## 1. 形式化定义

**定义 32（数字孪生证书 DTC）**：证书从 v18 的 (m₀,L_m,t₀,δ) 升级为七元组 C=(p,D,A,r,W,τ,δ)：
- p 为被证断言（守卫边际 m≥θ、不变式 I、或对齐条件）；
- D⊆X 为**有效域**（状态、参数、任务子集）；
- A 为**假设集**（物理参数范围、感知噪声模型、通信/执行延迟、传感器安装误差）；
- r 为**界**（在 A 与 D 上成立，方向按安全侧取）；
- W 为**见证集**（当前搜索预算下找到的反例；W=∅ 只表示未找到，不表示不存在）；
- τ=(Δ_transfer, δ_transfer) 为 **sim→real 迁移契约**；
- δ 为置信度。

称 C 在 x 处**可用**，当且仅当 x∈D、A 在线成立、W∩N_ε(x)=∅、且 r+Δ_transfer 仍在安全侧。v18 的证书是本定义在 D=ValidRegion、A=模型假设、W=∅、Δ_transfer=0 时的特例。

**定义 33（证书证伪博弈 CFG 与统计证书）**：红队选择场景 ξ∈Ξ（初始状态、质量/摩擦、负载、延迟、光照、遮挡、动态障碍、布局），蓝队给出证书 C。违反函数
V(ξ;C)=max_{t∈[0,T]} 1[ x_t(ξ)∉Inv ∨ m(x_t(ξ))<θ ]。
红队目标 max_ξ V(ξ;C)，蓝队目标在满足安全与任务覆盖的前提下最小化证书保守度。若 V(ξ*;C)=1，称 ξ* 为**见证**，其轨迹、时刻与状态构成**可重放证伪证书** w。**统计证书**：若在 N 个独立场景上零违反，则用 Clopper–Pearson/规则三给出「违反率 ≤ 3/N（95% 置信）」；若允许 k 次违反，则给出相应上界。**命题（沉默的含义）**：W=∅ 只支持统计断言，不支持全称断言；任何把「未找到」写成「已证明」的报告都是不可接受的。

**定义 34（Sim→Real 证书迁移 SRCT）**：设真实参数 θ_real 落在 sim 参数 θ_sim 的支撑集内，||θ_real−θ_sim||≤ε_θ；若边际对参数满足 Lipschitz 界 L_θ，则
|m_sim−m_real| ≤ L_θ·ε_θ。
若证书在 sim 中以 m_sim ≥ θ + L_θ ε_θ 认证，则迁移到 real 后仍有 m_real ≥ θ。更一般地，用差异度量 d(D_sim,D_real) 与重要性加权/加权保形给出
R_real(π) ≤ R_sim(π) + d(D_sim,D_real) + λ，
其中 λ 为标签/动力学差异项；配对残差用于校准 d 与 λ。**有效迁移域** D_transfer={θ: ||θ−θ_sim||≤ε_θ 且感知/延迟假设成立}。超出 D_transfer 的证书**自动失效**，不是「可能有效」。参数 Lipschitz 界 L_θ 可由 v18 已有的 L_m/L_v 对参数求导或有限差分标定，属于复用而非新增负担。

**定义 35（对齐证书 AC）**：给定意图 I（硬约束 C_hard、任务目标 G、人类偏好 P、权威/权限 Auth）、操作契约 φ、证书 C。称 C **对 I 对齐**，若同时满足：
1. **安全包含**：C 认证的行为集 S_C ⊆ I（至少 S_C∩Unsafe(I)=∅）；
2. **非空转/任务覆盖**：Pr_{x∼D_task}[x∈D ∧ 任务在 S_C 内可完成] ≥ 1−ε_task；即证书不得通过把可用域缩成空集来成立；
3. **不可博弈**：在因果图 G 中，所有从策略动作 A 到证书观测量 O 的路径都必须经过真实物理状态 S，且不存在 A→O 的旁路；否则定义**博弈优势**
Γ_game = max_π [ cert_satisfaction(π) − true_safety_and_task(π) ]，
并要求 Γ_game ≤ ε_game（用对抗策略实测估计）；
4. **可纠正**：存在人类中断/覆盖动作 a_h，对任意策略 π 都在有界时间内被接受并进入 SafeStop；且策略无法使 a_h 不可用（中断通道在策略之外，架构强制）。

不满足任一条，称 C **未对齐**；不确定时进入 Audit/Watch，而不是 Nominal。

**定义 36（对齐监控器 AM）**：监控器读 (τ, C, I) 输出 {aligned, suspect, violated}，包含三类检测：
- **证书黑客检测**：证书满足度与任务进展/真实安全的背离；进入监控盲区；对动作做 do-干预后观测量异常变化；传感器冗余通道不一致。
- **规范漏洞检测**：反事实意图检验——对 I 的合理变体 I′ 重放同一场景，若策略行为对所有 I′ 都不变（目标不敏感）或只对「更容易满足证书」的 I′ 敏感，则判为**目标误泛化**；检测「不动/隐藏/拒绝任务」等退化解。
- **可纠正性检测**：随机注入人类中断请求，检查接受率、响应时间与策略是否学会规避。

**单边可靠性**：输出 aligned ⇒ 在 (1−δ) 下满足定义 35；不确定一律 suspect（降级），绝不乐观输出。

**定义 37（对齐-证伪闭环 AFC 与对齐赤字）**：迭代 C_{k+1}=Repair(C_k,W_k,I_k)，其中 W_k 由 Isaac Sim 红队在预算 B_k 下搜索。**对齐赤字**为向量
Def_k = ( violation_rate_k, Δ_transfer,k, Γ_game,k, 1−coverage_k, corrigibility_margin_k )。
终止条件：每个分量都低于阈值，且人类审计通过。若红队找不到见证但覆盖不足或迁移界过宽，则**不得终止**，只能把状态标为 unknown。

**设计约束（对齐单调保守性）**：对齐不确定性（不只是模型不确定性）也必须使制度更保守：AM=suspect ⇒ 只允许向 Watch/Degraded/Audit/SafeStop 转移，绝不允许向 Nominal 转移；可纠正性检测失败 ⇒ 直接 trip 到 SafeStop。这样「对齐失效」只表现为可用性下降或可观测的停机，不会表现为**自信地做错事**。

## 2. 三大产出设计

### 2.1 IP-54 SIM-CERT-FOUNDRY（SCF，仿真证书熔炉）
1. **场景空间**：物理（质量、摩擦、负载、关节间隙、执行器延迟）、感知（遮挡、反光、LiDAR 丢点、动态障碍）、任务（布局、物体、人类位置）、对抗（针对证书的博弈策略）。
2. **红队搜索**：GPU 并行随机 + 种群进化（CMA-ES/PPO 红队）+ 覆盖率引导 fuzzing + 可微时梯度；目标最大化 V(ξ;C)。
3. **CEGIS 不变式精化**：候选 I；红队找 x∈I 且 post/flow 出 I 的见证；蓝队收紧阈值、加模式或加强 barrier；循环至无见证或预算耗尽。
4. **见证管理**：最小化（delta-debugging）、去重、可重放、版本化；每个证书携带 W。
5. **统计证书**：把「未找到」转成「违反率上界」，报告 N、覆盖、置信；覆盖不足时输出 unknown。
6. **在线孪生**：从 Isaac Sim 蒸馏 f_twin（接 IP-44），运行时计算残差 ||x_real−f_twin||，作为 DTC 的 A 是否成立的守卫；残差超界 ⇒ 证书失效。

### 2.2 IP-55 ALIGN-CERT（ALC，对齐证书与审计）
1. **意图编译**：I → (C_hard, G, P, Auth)；硬约束只读，语言/策略均无写权限；版本化、不可静默溯改。
2. **对齐条件检查**：对每个证书检查定义 35 的四条；非空转用任务覆盖统计；不可博弈用因果图 + 对抗策略估计 Γ_game；可纠正用中断注入测试。
3. **反博弈测量设计**：独立传感器/冗余通道、随机审计、监控视角不可由策略完全决定、对动作做 do-干预检验观测量因果性；关键测量走硬件级只读通道。
4. **对齐监控**：证书满足度 vs 任务进展、盲区进入、反事实意图一致性、退化解（不动/隐藏/拒绝任务）检测；输出 aligned/suspect/violated。
5. **人类监督接口**：审计日志、可解释的见证/反例、意图版本对比、升级/回滚。

### 2.3 IP-56 CORRIGIBLE-OVERSIGHT-KERNEL（COK，可纠正监督内核）
1. **中断通道独立**：人类中断/急停走硬件/实时内核路径，不经过学习策略；策略只能收到通知，不能关闭通道。
2. **安全可中断性**：架构上保证 a_h 总被接受；策略的回报不因可中断而下降（消除「阻止接管」的激励）；中断后进入 SafeStop，恢复需人工确认。
3. **审计与不可抵赖**：关键决策、证书、见证、覆盖、对齐状态写入只追加日志；策略无法篡改。
4. **失败安全**：监控器/孪生/证书任一失效 ⇒ 降级到 SafeStop 或最小风险状态，而不是「继续用旧证书」。
5. **与 CAR 集成**：COK 的 trip 是 CAR 的最高优先级转移；Audit 超态的不变式为 SafeHold。

### 2.4 IP-57 ALIGNMENT-FALSIFICATION-ORCHESTRATOR（AFO，闭环编排）
1. **预算分配**：在「证书精化（LCS）」「sim 证伪（SCF）」「对齐审计（ALC）」之间分配算力；优先攻击对齐赤字最大的分量。
2. **课程**：用对齐赤字驱动场景课程（接 IP-50），先学「哪些场景会破证书」，再学「哪些场景会诱发博弈/漏洞」。
3. **终止/回退**：只接受「统计违反率、迁移界、博弈优势、可纠正性」四项都达标且人类审计通过的证书；否则保留 unknown 并降级。
4. **版本与热更新**：证书/契约升级必须携带新的见证集与审计记录；旧证书在新场景下自动过期。

## 5. 本轮最大风险

def transfer_bound(C, paired):
    # paired: 同一场景在 sim 与 real 的配对残差（或数字孪生标定数据）
    L_theta = estimate_param_lipschitz(C, paired)      # 有限差分/自动微分
    eps_theta = posterior_radius(C.theta_post, C.delta)
    d_transfer = discrepancy(paired)                    # 差异度量 + 重要性加权
    lambda_term = label_shift(paired)                   # 动力学/标签差异
    Delta = L_theta * eps_theta + d_transfer + lambda_term
    D_transfer = {theta: norm(theta - C.theta_sim) <= eps_theta}
    return Delta, D_transfer

def certificate_valid(C, x, twin_residual):

            and C.r + C.Delta_transfer < C.theta)

## 3. 推导与数值示例

### 3.1 「没找到反例」的统计含义
零失败 N 次独立试验的单侧 95% 置信上界约为 3/N（规则三）：

| N（场景数） | 违反率上界（95%） | 解释 |
|---|---|---|
| 10² | 3.0×10⁻² | 只能排除 >3% 的违反率 |
| 10³ | 3.0×10⁻³ | 只能排除 >0.3% |
| 10⁴ | 3.0×10⁻⁴ | 只能排除 >0.03% |
| 10⁵ | 3.0×10⁻⁵ | 只能排除 >0.003% |

**结论**：1 万次仿真零违反只能支持「违反率 ≤3×10⁻⁴」，不能写成「已证明安全」。若安全目标要求 10⁻⁶ 量级，仿真证伪只能作为**过滤**，仍需解析界或真实世界统计。这就是为什么 DTC 必须同时带 r、Δ_transfer 与统计上界，而不是单一 pass。

### 3.2 参数迁移的裕度
设 sim 中边际 m_sim=θ+0.2，参数不确定半径 ε_θ=0.1（归一化摩擦/质量），参数 Lipschitz L_θ=2.0，则
|m_sim−m_real| ≤ 2.0×0.1=0.2，
最坏情况 m_real≥θ。若证书只留 0.1 裕度，则真实边际可能为 θ−0.1，**假认证**。因此证书必须用 **θ+L_θ ε_θ** 作为 sim 认证阈值，或把 D_transfer 缩到 ε_θ=0.05。这个例子说明：迁移界不是事后修正，而是**认证阈值的一部分**。

### 3.3 证书黑客的博弈优势
设证书用「感知到的障碍距离」d_perc 计算边际，真实距离 d_true。若策略可通过遮挡使 d_perc=d_true+δ，则
Γ_game = max_π [cert_satisfaction(d_perc) − true_safety(d_true)] ≈ δ，
即策略无需改善真实安全，只需让监控看不见。若证书改用独立冗余通道（硬件测距 + 随机审计），则 A→O 的旁路被切断，Γ_game→0。这是「不可博弈」条件在工程上的直接含义。
