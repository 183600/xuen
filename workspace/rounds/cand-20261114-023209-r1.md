# 第 71 轮（承接第 70 轮「BELIEF-RAS」IP-264~274；灵感循环新循环第 1 轮；本轮灵感：「腕部相机」×「ROS2」）

> R70 把闭环从「动作模态信念」推到「世界信念 b_t(s)」，问出「我现在信什么」。但它默认了三件从未被检验的事：测量来自**固定、已标定、同步、集中**的传感器组——相机装在头上、外参是常量、所有消息共用一个时钟、估计器一次事务式完成更新。真实机器人不是这样：**腕部相机**装在手眼链末端，看哪里由手臂动作决定，外参本身会漂；**ROS2** 把系统拆成一张异步节点图，时钟有偏、TF 有延迟、QoS 会降级、消息会迟到甚至静默丢失。于是 R70 的 b_t 建立在一个**并不存在的理想测量装置**上。
>
> 本轮不是再加一个模块，而是**把「测量装置」从常量升级为状态**：手眼外参 X 与时钟偏斜 θ 都进入信念；并且**把「传感器的位置」从外生参数升级为可决定动作**——腕部相机要看得更清，必须动，而动会改任务、改风险、也改标定。
>
> 核心命题：**具身信念 = 对世界 × 对测量装置 × 对证据能否按时到达 的联合信念；看得更清不是免费的，它是一次与任务共享同一手臂的动作。** 命名 **HORUS-RAS**（Hand-eye Observability & ROS2-Unified Spatial-temporal uncertainty reduction，手眼可观测与 ROS2 统一时空不确定性消解）。
>
> 一句话定位：R69 问「向谁求证」，R70 问「我现在信什么」，R71 问「**我的眼睛装在哪、它此刻看到的还算数吗、为了看清它值不值得动**」。

## 0. 直觉与动机

**灵感 1（腕部相机 → 观测是具身的，不是旁观的）**
直觉：头顶相机像「旁观者」，位置固定，看得到就看得到。腕部相机像「手电筒绑在手上」：它离物体近、分辨率高、能绕过遮挡，但视野窄、会被自己的手挡住、运动一快就糊；更重要的是，**它看向哪里由手臂决定**。这意味着「获取一个观测」不是被动等待，而是执行一个与抓取/装配共享执行器、共享安全包络、共享时间的动作。R69 的「看/问/触」把注视当成便宜的信息动作，R71 必须承认：**腕部视角的信息是有运动成本的，且运动本身会改变被观测的世界**。
第二层更隐蔽：腕部相机的坐标系是 `T_base_hand(q)·T_hand_cam`。手臂运动学误差会同时污染「相机看到的东西」和「本体感觉认为手在哪」。所以腕部视觉与本体感觉不是两个独立证人，而是**共用同一条运动链的串谋证人**——它们会一起错，并且错得像彼此印证。

**灵感 2（ROS2 → 观测是分布式的、带时间戳的、会迟到的）**
直觉：单进程估计器里，`observe(o)` 是一个原子操作；ROS2 里，观测是一次跨节点的、可能乱序、可能降 QoS、可能丢包、且必须做 TF 变换的事件。`stamp` 来自传感器时钟，`frame_id` 需要查 TF 树，`qos` 决定会不会丢，`executor` 决定回调何时被调度。于是「我有没有看到」之外，多出一个 R70 从未建模的问题：**「我在决策截止前，能不能拿到足够新、且能对齐到同一时空坐标的那份证据」**。这不是传感器的 aleatoric 噪声，也不是状态本身的 epistemic 歧义，而是**交付层面的 epistemic**：证据存在但没按时到，等价于此刻不知道。
把这一点讲透：R70 的 H[b_t] 假设所有已发布观测都已融合。真实系统里必须区分 `H[s | 已到达证据]` 与 `H[s | 截止前将到达的证据]`；后者才是决策该用的量。一个 30Hz 的腕部相机，若 TF 查询超时 20ms，它在这 20ms 内对安全决策的贡献应视为零，而不是「上一次的值」。

**灵感 3（R70 的三个隐含假设 → 三类新不确定性）**
直觉：把假设逐条推翻，就得到本轮的三根支柱。

| R70 隐含假设 | 现实（腕部相机 / ROS2） | 新不确定性 | 新控制手段 |
|---|---|---|---|
| 传感器位置固定、外参已知 | 手眼外参随热漂/碰撞漂移，且只有运动才可观测 | 空间标定 epistemic `H[ω_t(X)]` | 激发感知标定（XCR） |
| 观测与本体感觉独立 | 腕部视觉与本体感觉共享运动链误差 | 相关证据导致的过度自信 | 证据去相关（EDC） |
| 观测同步、集中、按时到达 | 分布式节点、时钟偏斜、TF 延迟、QoS 降级 | 交付 epistemic `H[V_t]` | 截止感知 VoI（DAU/MINT‡） |

**灵感 4（对 R70 的姿态 → 仍然是严格包含，不是另起黑箱）**
直觉：R70 是本轮在「外参已知、时钟同步、无丢包、腕部相机对任务无额外信息」边界上的退化。新层必须每一层可单独关闭：关掉腕部视角→回到固定多相机 BELIEF；冻结外参→回到 R70 BSE；忽略交付时间→回到同步更新。**安全侧只允许因新增不确定性而更保守，不允许因新增传感器而更自信**（除非证据通过去相关与校准门）。

**灵感 5（双刃剑 → 看得更多，可能更自信地错）**
直觉：加一个近距离相机通常被默认为「信息更多 = 更好」。但如果它的误差与已有证据强相关，朴素融合会把同一个错误数两遍，后验方差被低估，系统在**实际更错**的时候**表现得更有把握**。更糟的是「为了看清而移动」可能把物体碰倒、把已完成的装配扰动、或在不可逆承诺前浪费掉最后的时间窗。因此本轮必须同时交付：相关性感知融合、视角动作的安全认证、交付截止纪律、以及「移动去看」与「先做后看」的显式取舍。否则 R71 只是给 R70 装了一只**会附和偏见的眼睛**。

## 1. 形式化定义（增量：定义 331–340）

**定义 331（HORUS-RAS 总览与五不变式）** HORUS-RAS = (HEB, WCM, EVG, XCR, TSC, DAU, EDC, BSE‡, MINT‡, FMA‡, DGC, RAS-Baselines v2, Proto-Val v2, RAS-WM‡)。五不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **无未经时空认证的证据**：任何进入信念的观测必须通过 TSC（时间戳可校正、frame 可解析、QoS 契约满足、年龄未过期），否则只能进入「拒收日志」，不得静默丢弃；
(iii) **无重复计数的证据**：腕部视觉与本体感觉融合前必须过 EDC，`k_eff ≥ 2` 才可用于承诺级决策；
(iv) **视角动作安全**：任何「为了看而移动」的轨迹必须过 C-RAS-WM‡、保持 R70 承诺账本相容、且不得使任务进入更差的可达集；
(v) **严格退化**：外参已知 + 时钟同步 + 无损交付 + 腕部无独立信息 ⇒ 逐指令退化为 BELIEF-RAS。

**定义 332（ROS2 观测契约）** 一条观测消息 `m = (stamp_src, stamp_recv, frame_id, node_id, seq, qos, payload, provenance)`。`m` 可被信念采纳当且仅当：`frame_id` 能在有界时间内解析到 `base` frame；`stamp_src` 经时钟模型 θ 校正后与 `stamp_recv` 一致；QoS 满足订阅端要求（reliable/best-effort、depth、deadline）；校正年龄 `age(m) ≤ validity(frame)`；`seq` 未回退。契约把「数据」升级为「带时空坐标与投递保证的证词」。

**定义 333（腕部相机观测模型 WCM）** `o^w_t = Π(K, T_base_hand(q_t)·X·X_obj) + ε_vis(v,s) + ε_blur(q̇_t) + ε_kin(q_t)`，其中 `X ≜ T_hand_cam`，可见性掩码 `M_vis(v,s)` 编码 FoV 与自遮挡，模糊 `σ_blur ∝ ‖q̇‖`，`ε_kin` 来自关节/连杆误差。关键：`Cov(ε_vis, ε_prop) = Σ_wp ≠ 0`，因为视觉与本体感觉共享 `q` 的误差；WCM 必须显式携带这个交叉协方差，而不是默认块对角。

**定义 334（手眼信念 HEB）** 外参 `X ∈ SE(3)` 为随机变量，先验来自离线标定，漂移模型 `X_{t+1} = X_t · exp(η_t + η_thermal(T))`。`ω_t(X) = p(X | 观测序列)`；`U_cal^sp = H[ω_t]`（空间标定 epistemic）。HEB 与 R70 的 BSE 共享证据，但更新的是「测量装置」而非「世界」。

**定义 335（手眼可观测性与激发）** 对单一静态视角，手眼外参存在规范自由度（沿视线/关节轴的平移与旋转不可分），Fisher 信息阵 `FIM(X; 单视角)` 秩亏。定义激发分数 `ε_exc(v_{1:k}) = λ_min(FIM(X; v_{1:k}))`。**运动是手眼自标定的必要条件，不是可选优化**：静止的腕部相机只能看世界，不能校准自己。

**定义 336（证据去相关 EDC）** 给定证据源协方差与交叉相关 `ρ_ij`，定义有效独立源数 `k_eff = (Σ_i w_i)² / (Σ_i Σ_j w_i w_j ρ_ij)`。融合使用完整协方差（含 `Σ_wp`），不用块对角近似。`k_eff < 2` 的单一运动链证据只能作为「似然提示」，不得单独满足 R69 的 `k 正交证据`纪律。去相关动作包括：换一个误差主方向不同的视角、引入外部标记、等待独立节点（如头部相机/力传感器）。

**定义 337（时空一致性 TSC）** 把每条消息对齐到 `base` frame：以 `stamp_src` 在 TF 树中有界查询变换；用因子图在线估计时钟偏斜 θ（含跳变检测）；输出采纳集 `A_t` 与拒收原因标签 `{stale, out-of-order, frame-alias, qos-mismatch, clock-jump, tf-missing}`。TSC 是「测量装置的免疫系统」：它不判断世界，只判断证词是否合法。

**定义 338（交付感知不确定性 DAU）** 令 `I_t(D)` 为决策截止 D 前实际可到达的证据集（随机）。`U_epi^eff = E_{I_t(D)}[H[s | I_t(D)]]`；对消息投递概率 `p_deliver` 与延迟分布做蒙特卡洛，得到截断上界。`H[V_t]` 表示「证据能否按时到达」本身的熵。它既不是 `U_ale` 也不是 R70 的 `U_epi`，而是**第三条不确定性通道**，单独进入退避（定义见产物区）。

**定义 339（具身视角 VoI / EVG）** 视角动作 `v = (q_target, dwell, focus) ∈ V_safe`，成本 `c(v) = c_time + c_energy + c_risk + c_task_loss`，任务是 `Δs_task(v)`。`VoI_view(v) = H[b_t] − E_{o^w~p(·|v)}[H[b_{t+1}(o^w)]]`，且只计算**会改变动作选择**的那部分不确定性（决策相关投影）。净收益 `score(v) = VoI_view(v) + λ_cal·IG(X;v) − c(v)`；`score ≤ 0` 则不移动，退回 R70 保守。

**定义 340（严格包含边界）** 当 `ω_t = δ(X_0)`（外参确定）、`θ = 0`、交付无损同步、且腕部视角对 `s` 的互信息为 0 时，HORUS 的每一步信念更新与动作选择与 BELIEF-RAS 逐指令相同；再关闭 BSE 得 FLUID；再关闭交互得 CALM（R68）。安全侧层层不让步。

## 2. 关键机制（直观看它们如何咬合）

1. **HEB + WCM**：把外参当状态，腕部观测的边缘似然要对 `ω_t(X)` 积分。这样「相机装歪了」不会被误判成「世界变了」。
2. **XCR**：主动选择一段安全的、有转动激励的短运动，让手眼外参从秩亏变得可观测；它同时可以服务于任务（例如把手臂移到预抓取位），因此标定不是额外开销，而是「顺路的激励」。
3. **EDC**：在融合前检查腕部与本体感觉的相关性；相关性高时降权、或把「换视角」作为一个去相关动作。这是本轮对「看得更多可能更错」的正面回应。
4. **TSC + DAU**：把「按时到达」纳入不确定性；迟到证据不是零信息，而是**过期信息**；过期信息不得进入承诺前提。MINT‡ 的候选信息动作因此包含「等一条消息/触发一次重传/换一个更快的节点」。
5. **DGC + 生命周期降级**：ROS2 节点各自出证，聚合为系统级证书；任一关键节点失证、QoS 违约、TF 缺失即进入降级模式，绝不静默升级置信。

## 3. 本轮最大风险

**一句话**：HORUS 的全部增益押在「手眼外参可在线观测、且腕部证据与本体感觉可被正确去相关」——**若运动激励不足（外参不可观）或相关性估计错误（把串谋证人当独立证人），系统会在真正更错的时候显得更自信；而「移动去看」又可能与任务共享手臂、在不可逆承诺前浪费最后的时间窗**。看得更多，可能是更自信地错。

# 第 71 轮产物 · 创新点清单 v1：HORUS-RAS（Hand-eye Observability & ROS2-Unified Spatial-temporal uncertainty reduction：把世界信念升级为「世界 × 测量装置 × 证据交付」的联合信念；HEB×WCM×EVG×XCR×TSC×DAU×EDC×BELIEF-RAS‡）

> 承接第 70 轮 IP-264~274（BELIEF-RAS）。R70 用显式世界后验 b_t(s) 统一了 epistemic/aleatoric，并交付基线协议与原型验收。但它把**测量装置**当成了常量：外参已知、时钟同步、观测集中且按时到达。本轮用两个灵感逐条推翻这三个假设：**腕部相机**证明观测是具身的（视角即动作、外参即状态、视觉与本体感觉共享误差）；**ROS2** 证明观测是分布式且带时间的（时钟偏斜、TF 延迟、QoS 降级、消息迟到/丢失）。
>
> 本轮交付一个**联合信念**与四件可独立开关的机制：
> - **HEB/WCM/XCR**：外参 X 与时钟 θ 进入信念，腕部观测边缘化 `ω_t(X)`；用激发感知的运动让手眼可观测，用视角一致性检测漂移。
> - **TSC/DAU**：每条 ROS2 消息必须通过时空契约；把「截止前能否拿到证据」显式计入不确定性。
> - **EDC**：融合前估计腕部与本体感觉的相关性，防止「同一错误数两遍」。
> - **EVG/MINT‡**：把「移动去看」作为与任务共享手臂的联合动作，按净信息收益与安全/承诺约束决策。
>
> 核心命题：**在分布式具身系统里，安全的关键不是「多一个相机」，而是「知道这只眼睛装在哪、它的证词什么时候还算数、以及为了看清它值不值得动」。** IP 编号 IP-275~290（16 个），定义 341–356。

## 2. 形式化定义（增量：定义 341–356）

**定义 341（腕部增强 BSE‡）** 联合状态 `x_t = (s_t, X_t, θ_t)`。预测：`s` 沿用 R70 的语义马尔可夫 × 连续过程，`X` 随机游走 + 热漂，`θ` 线性漂移 + 跳变。更新：只融合 `m ∈ A_t`，似然为
`p(m|x) = p_flow(ξ|o,s,X) · p_ans(y|g,s) · p_cal(r|s) · p_qos(m)`，
其中 `p_qos` 编码 QoS 违约/丢包下的降权。腕部观测按 `p(o^w|s)=∫ p(o^w|s,X) ω_t(X) dX` 边缘化。实现：语义离散 `M≤20` 精确、连续粒子 `N≤500`、`X` 用 SE(3) 误差状态 EKF 或小粒子集（`N_X≤32`）。

**定义 342（WCM-V 视角一致性）** 同一物体/标记由两个视角 `v_i,v_j` 观测，预测位置差 `d_ij(X) = ‖proj_{v_i}(X·p) − proj_{v_j}(X·p)‖`。若 `d_ij` 随视角系统性变化而世界静止，则判 `X` 漂移；若两视角一致但都偏离触觉/力证据，则判 `s` 变化或视觉偏差。这是把 R70 的「模态对互信息」升级为「视角对互检」。

**定义 343（TSC 时空一致性）** 采纳条件：
`Admit(m) ⇔ Resolvable(frame_id, stamp_src, ≤τ_tf) ∧ |stamp_src + θ̂ − stamp_recv| ≤ τ_clk ∧ QoS_ok ∧ age ≤ validity ∧ seq_ok ∧ ¬Alias(frame_id)`。
时钟因子图节点为 `(node, t)`，边为接收-发送差与已知硬件同步脉冲；跳变检测 `|Δθ| > τ_jump` 触发重估并把跨跳变的消息标记为 stale。拒收必须写入 `R_t` 并进入证书，**禁止静默丢弃**。

**定义 344（DAU 交付感知不确定性）** `I_t(D)` 为截止 D 前到达且通过 TSC 的证据随机集。`U_epi^eff = Σ_{I} p(I|history, D) H[s|I]`；用投递概率 `p_deliver` 与延迟分布 MC（`N≤64`）。若 `U_epi^eff > U_epi^now + δ`，说明「现在能做但等不到证据」，应提前决策或改走保守通道。`U_del = H[V_t]` 与 `U_epi` 语义不同，不做简单加和。

**定义 345（EDC 证据去相关）** 设证据 `(w_i, Σ_i)` 与交叉协方差 `Σ_ij`，融合用 `Σ_full`（非块对角）。`k_eff = (Σw)²/(ΣΣ w_i w_j ρ_ij)`。承诺级决策要求 `k_eff ≥ κ_eff`（默认 1.7）。相关过高时允许的去相关动作：换视角、引入外部标记、等待独立节点、增加触觉/力证据。`k_eff` 进入证书。

**定义 346（EVG 具身视角增益）** `V_safe` 为满足运动学、碰撞、承诺账本与时间预算的视角动作集。`VoI_view(v) = H[b_t] − E[H[b_{t+1}]]`，投影到「会改变 argmax 动作」的子空间。`score(v) = VoI_view(v) + λ_cal·IG(X;v) + λ_task·E[Δprogress] − c(v)`。`score ≤ 0 ⇒ 不动`（严格退回 R70）。

**定义 347（XCR 激发感知标定）** 选 `v_{1:k}` 最大化 `λ_min(FIM(X;v_{1:k}))`，约束：每步在安全包络内、可恢复、不打断不可逆承诺、总时长 ≤ `T_cal`。允许「顺路激励」：把标定运动嵌入预抓取/退让/复位轨迹。输出更新的 `ω_t(X)` 与可观测性报告。

**定义 348（MINT‡ 截止感知联合 VoI）** 候选信息动作族 `G = {view, gaze, probe, ask, wait, retransmit}`。`VoI_eff(g) = p_deliver(g,D_g)·VoI(g) − c(g)`，`g* = argmax s.t. 安全/预算/承诺相容`；`max VoI_eff ≤ 0 ⇒ 不交互`。`D_g` 由其所服务的最早不可逆承诺决定（借用 R70/TELOS 的 resolve-early）。

**定义 349（FMA‡ 视角条件流似然异常）** `a_score = −log ∫∫ p_θ(ξ|o,s,X) b_t(s) ω_t(X) ds dX`；`Δa = |a(o,X̂) − a(o,X_cal)|`。新增「视角一致性残差」`r_view = min_X Σ d_ij(X)²`；三元组 `(r_res↓, Δa↑, r_view↑)` 判别「标定吸收的缓变故障」与「手眼漂移」。

**定义 350（DGC 分布式图证书）** 每个关键 ROS2 节点 `n` 发 `C_n = (node_id, pkg_ver, inputs_hash, outputs_hash, latency_p99, qos_profile, clock_domain)`；构建哈希链 `digest(J_HORUS)`。证书要求：关键节点全覆盖、TF 树连通、QoS 契约满足、`R_t` 可解释、无未认证节点结果进入承诺前提。

**定义 351（LC-DEG 生命周期降级）** 状态机 `Active → No-Wrist → No-TF → Safe-Stop`，由副作用的不可逆性决定降级方向。降级只允许降低置信/增加保守：`No-Wrist` 退固定相机 BELIEF；`No-TF` 禁用跨帧融合、退单帧/本体感觉保守；`Safe-Stop` 继承 R70 定义 343 的优雅交接。禁止从降级态静默恢复到高置信（需重新认证）。

**定义 352（AIC-DIST 干扰集）** `ℰ_DIST = ℰ_BELIEF × ℰ_wrist × ℰ_ros`：
- `ℰ_wrist`：手眼漂移、自遮挡、镜面/透明、运动模糊、标定板遮挡、视角劫持；
- `ℰ_ros`：时钟跳变/回拨、TF 陈旧/别名/环、QoS 由 reliable 降 best-effort、乱序、消息丢失、节点崩溃/重启、时间戳伪造；
- `ℰ_corr`：故意制造与本体感觉相关的腕部证据以诱导过度自信。

**定义 353（J_HORUS 证书）** `J_HORUS = (J_BELIEF, ECE_handeye, |θ̂|_95, reject_rate, k_eff_min, deadline_miss_rate, view_voi_ratio, dgc_digest, horus_ver)`。`Valid ⇔ Valid(J_BELIEF) ∧ ECE_handeye ≤ τ_he ∧ |θ̂|_95 ≤ τ_θ ∧ reject_rate ≤ τ_rej ∧ k_eff_min ≥ κ_eff ∧ deadline_miss_rate ≤ τ_dm ∧ DGC 覆盖完整`。

**定义 354（三级退避增强）** `λ = λ_floor(U_ale + α·U_epi^eff + β·U_cal^sp + γ·U_del)`：
- 若证据消解且 EDC 通过：`α=0`（resolution bonus）；
- 若 `ECE_handeye > τ_he` 或 `k_eff < κ_eff`：`β` 取上界并禁用视角增益（不拿不可信外参换效率）；
- 若 `deadline_miss_rate` 超阈：`γ` 取上界，退回「早决策/保守」。
保证 HORUS 的 λ 在任一拒绝条件下逐指令 ≥ R70 的 λ。

**定义 355（严格包含链）** 在 `ω_t=δ(X_0)`、`θ=0`、无损同步、腕部互信息为 0 的边界：`HORUS ≡ BELIEF`；关闭 BSE：`BELIEF ≡ FLUID`；关闭交互：`FLUID ≡ CALM(R68)`。每一级新增量都可单独拒绝，拒绝时单调回退。

**定义 356（RAS-Baselines v2 协议）** 6 基线：BELIEF-RAS、Wrist-Only（固定外参朴素融合）、Head-Only、Sync-Only（忽略交付）、No-EDC、No-View（不看只做）。固定：ROS2 bag 回放 + 注入时钟/TF/QoS 故障；5 种子；配对 Wilcoxon `p<0.01` + Bonferroni；报告模板强制包含 `k_eff`、`reject_rate`、`deadline_miss`、`ECE_handeye`。Proto-Val v2 三环境：Isaac Sim + Gazebo/ROS2 + 真机（UR/Franka + 腕部 RealSense）。

# IP-282 BSE‡：联合信念（世界 s / 手眼 X / 时钟 θ）
class JointBeliefFilter:
    def __init__(self, bse, heb, clock, tsc, edc, N_X=32):
        self.bse, self.heb, self.clock = bse, heb, clock
        self.tsc, self.edc, self.N_X = tsc, edc, N_X

    def step(self, b_prev, w_prev, msgs, last_act):
        # 1) TSC：校正时钟、解析 TF、按契约准入
        A, R = self.tsc.admit(msgs, self.clock.theta)
        # 2) 预测（s / X / θ 各自转移）
        b_pred = self.bse.predict(b_prev, last_act)
        w_pred = self.heb.predict(w_prev)                 # 随机游走 + 热漂
        # 3) HE 更新与视角一致性
        w_t = self.heb.update(w_pred, A)
        r_view = self.heb.view_consistency(A, w_t)
        # 4) EDC：估计相关，计算 k_eff，必要时降权
        k_eff = self.edc.effective_sources(A, w_t)
        A_fused = self.edc.reweight(A, k_eff)
        # 5) 世界更新：腕部观测对 X 边缘化
        b_t = self.bse.update(b_pred, A_fused, w_t)
        return b_t, w_t, (A, R, k_eff, r_view)


# IP-283/284 EVG + MINT‡：先看/先做/先问/先等
def choose_information_action(b_t, w_t, fmp, budget, cw):
    best = None
    for g in candidates(b_t, w_t):          # view / gaze / probe / ask / wait / retransmit
        if not budget.allow(g) or not cw.certify_info(g, b_t, w_t):
            continue
        if g.kind == "view" and not cw.viewpoint_safe(g.v, b_t):
            continue                          # 运动共享手臂：必须过认证
        voi   = voI_view_or_state(b_t, w_t, g, fmp)     # 决策相关投影
        p     = deliver_prob(g, b_t)                     # DAU
        cost  = c_time(g)+c_energy(g)+c_risk(g)+c_task_loss(g)
        score = p * voi + g.lam_cal * expected_handeye_gain(w_t, g) - cost
        if best is None or score > best.score:
            best = (g, score)
    return best if best and best.score > 0 else None


# IP-285 FMA‡：边缘化 (s, X)，并做视角互检
def flow_anomaly_horus(fmp, xi_obs, o, o_cal, b_t, w_t, A):
    a_o   = -fmp.log_likelihood_joint(xi_obs, o, b_t, w_t, N_is=32, N_X=32)
    a_cal = -fmp.log_likelihood_joint(xi_obs, o_cal, b_t, w_t, N_is=32, N_X=32)
    r_view = view_consistency_residual(A, w_t)
    return abs(a_o - a_cal), r_view

## 4. 推导

**引理 23（手眼可观测性的运动必要条件）** 设腕部相机在固定关节角 `q` 下观测静态场景，外参 `X` 的 Fisher 信息阵为 `FIM_q(X)`。由于沿关节旋转轴的平移与绕视线的旋转不改变成像，`FIM_q` 至少有一个零特征方向；故 `rank(FIM_q) < dim(X)`，单静态视角无法唯一确定 `X`。若 `k` 个视角的旋转轴张成三维，则 `FIM(X;v_{1:k})` 满秩。系：**静止的腕部相机不能自标定；「看」只有在动的时候才对 X 有信息**，这是 XCR 存在的理由。

**引理 24（相关证据的过度自信膨胀）** 设真实联合协方差含交叉项 `Σ_wp = ρ·σ_wσ_p`，朴素融合按 `Σ_wp=0`，则后验方差 `σ_naive² = σ_w²σ_p²/(σ_w²+σ_p²)`，真实后验方差为 `σ_true² = σ_w²σ_p²(1−ρ²)/(σ_w²+σ_p²−2ρσ_wσ_p)`。当 `ρ>0` 时 `σ_naive² < σ_true²`，且比值随 `ρ→1` 发散。故**未去相关的腕部证据会把置信度虚抬**；`k_eff` 给出可操作的检测量。系：R69 的「k 正交源一致」纪律在具身系统中必须替换为「k_eff 有效源一致」。

**引理 25（交付感知 VoI 的截止折扣）** 若信息动作 `g` 的收益在截止 `D_g` 后兑现则价值为 0，投递概率 `p`，则 `E[VoI_eff] = p·VoI(g) − c(g)`。对同一歧义，若其服务的最早不可逆承诺越早（`D_g` 越小），则 `p` 越小、`VoI_eff` 越低，因此应**对不可逆动作 resolve-early、对可逆动作 trial-and-error**。系：这解释了为什么「等一条会迟到的消息」在不可逆步骤前等价于「不知道」。

**引理 26（视角增益与运动成本的阈值结构）** 设歧义度 `A` 与遮挡度 `O` 使 `VoI_view` 单调增，运动成本 `c(v)` 随位移/速度单调增，则存在阈值 `A*`（依赖 `O`、任务余量 `m_task`）使 `score(v)>0` 当且仅当 `A>A*`。当 `m_task→0`（任务已无容错余量）时 `c_task_loss→∞`，阈值 `A*→∞`，即**任务越紧越不该为了看而移动**。系：EVG 天然给出「先做后看 vs 先看后做」的切换面。

**定理 20（HORUS 严格包含 BELIEF）** 在 `ω_t=δ(X_0)`、`θ=0`、`A_t=I_t`（无损同步）、且 `I(o^w;s | o_other)=0` 时，HORUS 的联合滤波退化为 R70 的 `b_t(s)`，EDC 的 `k_eff` 等于 R70 的证据源数，EVG 的视角候选收益为 0，故其信念更新与动作选择与 BELIEF-RAS **逐指令相同**。在任一拒绝条件（`ECE_handeye` 越界、`k_eff<κ`、`deadline_miss` 超阈）下，定义 354 的 λ 不低于 R70 的 λ。故 `Risk(HORUS) ≤ Risk(BELIEF)` 且安全侧不让步，效率收益只在证据合法时兑现。

**定理 21（时空准入的认证可靠性）** 若所有进入信念的消息满足定义 343 的 `Admit`，且拒收消息全部进入 `R_t` 与证书，则：(i) 不存在使用 `age>validity` 的证据；(ii) 跨时钟跳变的证据被隔离；(iii) 生命周期降级只会降低置信。因此在证书 `Valid` 的轨迹上，后验不会因「迟到/错帧/错 QoS 的证据」而出现非因果的置信跃升。

**定理 22（鲁棒性上界）** 设 `δ_p` 为相关证据被误当独立源的概率，`k_eff` 估计误差 `ε_k`，则在 EDC 生效且 `k_eff≥κ_eff` 下，过度自信的后验方差低估量 ≤ `f(ρ_max, ε_k)`（引理 24 的界）；若 `ρ` 不可估，则系统按定义 354 令 `β` 取上界，退化为 R70 保守。故 **EDC 失效不导致安全性下降，只导致效率回退**。

## 7. 本轮最大风险

**一句话**：HORUS 的收益完全依赖两个可估计性前提——**手眼外参可被足够运动激励到可观测，且腕部证据与本体感觉的相关结构可被正确估计**；若运动预算不足或任务不允许激励，`ω_t(X)` 会停留在错误先验，视角增益会自信地基于错误外参；若相关性被低估，系统会把同一运动链误差数两遍，在真正更错时显得更自信——**移动去看，可能既没看清，又错过了做对的窗口**。

**次级风险与缓解**：
1. **视角动作不安全/扰动任务** → EVG 只接受 `V_safe` 且过 C-RAS-WM‡；任务余量小时阈值自动升高（引理 26）；
2. **时钟/TF 故障导致错误融合** → TSC 准入 + 拒收日志 + 生命周期降级（定理 21）；
3. **ROS2 实时预算被新增组件击穿** → 常规主环 <5.2ms，视角规划异步；DAU/EDC 全部有硬上限；
4. **相关证据欺骗（ℰ_corr）** → `k_eff` 纪律 + 换视角去相关 + DGC 归因；EDC 失效只回退效率不降安全（定理 22）；
5. **手眼标定与 R68 标定层重复/冲突** → 明确分工：R68 管传感器残差，HEB 管空间外参，二者独立证书、联合判据（定义 349 三元组）。
