# 第 58 轮（承接第 57 轮「少样本元推断×跨模态对账×个性化有界信任」IP-133~138；灵感循环第 1 轮；本轮灵感：「SLAM」×「Isaac Sim」）

> 第 57 轮把安全的赌注从"模型置信"一路推到"证据质量"，用元先验摊销、共形保底、跨模态对账与单向信任机层层兜住；它自陈的最大风险是"坏先验普遍"——元模型在语料盲区之外自信地错。但第 57 轮仍默认了两件从未被正面检验的事：**(i) 证据所栖身的空间坐标系是稳定的、外生的、与证书无关的**——所有区域信念、裕度、承诺都写在 SLAM 地图的坐标系里，仿佛这个坐标系不会漂、不会被一次错误回环整体改写；**(ii) 被仿真验证过等于被现实验证过**——在 Isaac Sim 里跑一万个 episode 得到的成功率被当作一万份证据，仿佛这 10000 个样本彼此独立。**SLAM** 让坐标系变成一个联合估计、会漂移、会被感知别名欺骗、一次回环即可全局改写的活对象；**Isaac Sim** 让"廉价的大规模证据"成为可能，但这些 episode 共享同一个孪生构建、同一套物理与渲染参数、同一个 reality gap——它们相对于"现实"的有效样本量不是 10000，而约等于 1。本轮把两个灵感统一为一个更锋利的问题：**看似海量的证据，可能共享同一个单点故障。** 命题从"证据说可信"推进为 **"先证共同源、再谈证据量：位姿可证、地图可溯、别名可辨、孪生可限、仿真只可否证"**。核心贡献是把第 57 轮"同一模态重复五遍只是把同一个错误问五遍"推广为一条可计算的原则——**相关证据不是证据**。

核心矛盾：
- **H32（坐标系共模 vs 区域独立）**：第 56~57 轮的区域证据失效率按区域取 union bound，隐含假设各区域失效近似独立；但所有区域都继承同一个位姿图估计，一次全局漂移、一次失锁重定位、一次错误回环会让大量区域证书同时失效。**共模失效不是"多一个风险项"，而是让 union bound 本身失效。**
- **H33（回环修订 vs 旧证书长寿）**：回环闭合不是局部更新，而是一次全局改判；它会把过去"已证明安全"的区域整体平移。若旧证书不随地图版本回溯失效，就会出现第 56 轮"坏证据长寿"的地图版：**证书在坐标系已经改写后仍以"仍然有效"的名义放行。** 更危险的是假回环——一次错误地点同一，可污染整张地图。
- **H34（仿真丰度 vs 现实鸿沟）**：Isaac Sim 能以极低成本生成海量反事实场景，但所有 episode 共享同一孪生构建与同一套物理/渲染/传感模型；它们相对于现实是高度相关的。把仿真成功率当作独立证据，等于把"同一个 reality gap 问了一万遍"；若再用它减少真实探针，就是**仿真证据洗白**。

## 0. 直觉与动机

**灵感 1（SLAM → 坐标系本身是证据的一部分）**
直觉：地图不是背景板，而是所有证据的坐标系。位姿协方差不会只停留在定位模块里，它会顺着"障碍物距离/台阶高度/落脚点裕度"一路传播进每一次承诺；坐标系偏了 5cm，标称 4cm 的裕度就已经是负的。因此安全门必须先问"我在哪个坐标系里证明的"，再问"这个区域安不安全"。**先证坐标系，再证区域。**

**灵感 2（SLAM → 地图是版本化账本，回环是全局改判）**
直觉：地图元素应像证据一样带出处、观测史、独立支撑、回环支撑、新鲜度与别名风险；回环闭合应像第 57 轮的模型更新一样过隔离区——先算漂移修正场，再算**失效集**：哪些证书的裕度依赖了被平移超过容差的位姿。被命中的证书立即挂起、重探或保守加宽，而不是静默续期。**回环不是一次局部更新，而是一次全局改判；改判必须回溯。**

**灵感 3（SLAM → 别名与假回环是"全局共谋"）**
直觉：单模态的假阳性只是一次错误观测；一次错误回环却能把两个不同地点焊死，随后所有经过该区域的定位与地图都会自洽地错。这是第 57 轮跨模态共谋的 SLAM 版，而且爆炸半径更大。对策不是"再多跑几遍回环检测"（同一个外观特征会重复骗你），而是：别名风险高时**禁止合并**、只保留软假设；用独立模态与几何一致性做身份证据；主动派一次**身份探针**去区分；单次回环永远不能单独授权不可逆接触。

**灵感 4（Isaac Sim → 孪生是张需要标定和保质期的地图）**
直觉：数字孪生不是现实的副本，而是一张由 USD 资产、物理参数、传感器模型、渲染参数与域随机化分布共同定义的"仿真地图"。它只在**有效域**内可信，会随真实世界改造而漂移，也会因资产版本更新而改变行为。因此孪生需要自己的出处、有效域、reality gap 分解（物理/渲染/传感/执行/分布）、真实锚标定，以及与真实 SLAM 地图的配准残差。**孪生与地图必须互相注册；配准发散就是世界变了的证据。**

**灵感 5（Isaac Sim → 仿真买效率，不买安全）**
直觉：仿真的价值不该被浪费在"证明安全"上，而应被用在它最擅长的地方——**廉价地证伪**。在有效孪生里构造最坏情形，若能稳定复现失败，就有资格投否决票、触发真实探针或绕行；若仿真通过，则**不产生任何授权学分**，只能用来给真实探针排序。原因很硬：仿真成功只给出 `R_real ≤ R_sim + g(𝒯)`，只要 reality gap 上界 g 不够小，这个式子就永远无法单独证明安全；而 10000 个共享同一孪生的 episode 的有效样本量约等于 1。**仿真只可否证，不可背书。**

**灵感 6（两灵感合流 → 共同源证据记账 ECS）**
直觉：SLAM 的位姿图和 Isaac Sim 的孪生构建都是**共同源**：它们让大量看似独立的证据共享同一个隐藏误差。把证据误差写成单因子模型 `ε_i = a_i u + ε_i^⊥`，则独立样本量不是个数 n，而是 `n_eff = n²/1ᵀR1 = n/(1+(n−1)ρ̄)`。当 ρ→1 时 n_eff→1：一万个仿真 episode、二十个共享同一坐标系漂移的区域、三个共享同一纹理的"独立"模态，都会瞬间坍缩成一份证据。于是第 57 轮的"独立性要求"升级为可计算的**共同源隔离**：**任何声称 k 份独立支撑的证据，必须报出共同源图与 n_eff；共同源未隔离，证据学分按 n_eff 折扣。** 本轮把"一切判定器走隔离"推进为"**共同源走隔离**"。

## 1. 形式化定义（增量：定义 139–145）

**定义 139（共同源证据记账 ECS）** 每条证据 e 携带出处向量 π(e)（位姿图版本、地图版本、标定 ID、模型哈希、孪生构建、会话、操作者、传感器）。共同源图 𝒢 的边 (e,e′) 带耦合强度 κ(e,e′)∈[0,1]。证据误差单因子分解 ε_i=Σ_λ a_{iλ}u_λ+ε_i^⊥，相关系数矩阵 R（R_ii=1）。**有效样本量** `n_eff(E)=n²/(1ᵀR1)=n/(1+(n−1)ρ̄)`；**共同源类** C_λ={e:a_{eλ}≠0}；**爆炸半径** B_λ=Σ_{e∈C_λ}a_{eλ}。规则：(E1) 任何要求 k 份独立支撑的证据门（EV-xmodal、EV-map-loop、EV-sim⁺ 等）必须满足 n_eff(E)≥k 且共同源类数≥k，否则按 n_eff 折扣；(E2) 安全界对共同源类取 union bound，而不是对单条证据取 union bound；(E3) 共同源未声明或声明不完整 ⇒ 该证据不得进入授权路径。

**定义 140（空间记忆账本 SML）** 地图 𝓜=(𝒱,ℰ,ℳ,ver)，每个地图元素 m 携带 `(几何/语义分布, 出处 π_m, 观测史 H_m, 独立支撑 n_eff(m), 回环支撑 L_m, 位姿协方差 Σ_m, 新鲜度 age_m, 别名风险 a_m, 版本 ver_m, 依赖证书 Dep(m))`。修订算子 `Rev(𝓜,ℓ)` 对回环 ℓ 做位姿图优化，得到漂移修正场 δ_T(x) 与**回溯失效集** `Inv(ε)={J∈Dep(𝓜): shift_J(δ_T)>ε_J}`，其中 ε_J 是证书 J 的位姿容差。修订后 𝓜 版本递增；Inv 中所有证书立即挂起，重探/加宽/重证完成前不得承诺。无完整出处或 n_eff<2 的地图元素不得支撑 EV-visit/EV-margin。

**定义 141（坐标系/位姿证书 FPC）** 位姿估计 (x̂,Σ,g,A)，g 为规范自由度（全局平移/旋转/尺度），A 为外部锚。坐标系证书 `J_F=(frame_id,x̂,Σ,g,A,一致性统计,漂移率,有效期)`。一致性统计包括回环残差 χ²、NEES、里程计-外部传感器分歧、跨会话配准残差、重定位似然。**位姿膨胀裕度**：真实裕度 `m^true ≥ m−L_r‖δξ‖`，证书裕度 `m^cert=m−L_r q_{1−δ_F}(‖δξ‖)`；`m^cert<θ_K` ⇒ 降档/重定位，不得承诺。**共模门**：`P_frame_fail=P(‖δξ‖>ε_pose ∨ 规范漂移>ε_g ∨ 失锁/重定位失败 ∨ 别名合并)`，一旦失效，所有区域证书同时挂起。

**定义 142（别名感知回环修订 ALR）** 回环候选 (i,j) 带 `(匹配分 s_ij, 别名风险 a_ij=P(i≠j|匹配), 独立支撑 E_ij, 几何残差 r_ij)`。规则：(A1) a_ij>θ_alias 或 n_eff(E_ij)<2 ⇒ **禁止合并**，只记软假设边并派身份探针（预算 k_id）；(A2) 回环是全局修订，必须过修订门：身份证据 ∧ 几何残差 ∧ 爆炸半径 `B_ij=|Dep(i)∪Dep(j)|` ∧ `p_false·B_ij≤ε_alias`；(A3) 单次回环不得单独授权不可逆接触，也不得单独把某区域从"需探"升级为"可承诺"；(A4) 假回环被事后证伪 ⇒ 撤回合并、回滚地图版本、重基所有受影响证书。

**定义 143（数字孪生保真契约 DFC）** 孪生 𝒯=(USD 世界, 物理参数 θ_p, 传感模型 θ_s, 渲染参数 θ_r, 域随机化 D_rand)。**有效域** D_𝒯；**reality gap 分解** `g(𝒯)=(g_p,g_s,g_r,g_a,g_d)`；真实锚集 A_real 上成对实验给出 gap 上界 ĝ 与覆盖 1−α_twin。**孪生-地图配准** `T_{𝒯→𝓜}` 的残差与**世界发散度** `Δ_div`（真实世界已改而孪生未改）。有效谓词 `Valid(𝒯,s)=s∈D_𝒯 ∧ gap_covered(s) ∧ registration_residual≤ε_reg ∧ Δ_div≤θ_div ∧ ver_𝒯 已登记`。孪生更新也必须过隔离与影子验证；**孪生漂移与地图修订同等对待**。

**定义 144（仿真即证伪 S2F）** 仿真证据分两类：**EV-sim⁻**（在有效孪生内、通过伪影过滤后稳定复现的失败）只可**否决**：阻断承诺、触发定向真实探针或绕行；**EV-sim⁺**（仿真通过）**不产生授权学分**，只能用于真实探针排序/提出待检验假设，不得减少真实探针预算、不得替代任何真实证据、不得进入不可逆接触的必要证据集。**证伪证书** `J_fals=(场景, 有效域证明, 伪影过滤, 失败裕度)`；不可迁移的伪影失败不计为证伪。

**定义 145（空间-孪生联合探-诺-演 PCE-S）** 每个检查点：①**帧门**（J_F 有效？）；失效 ⇒ 重定位/加锚，挂起承诺；②**图门**（地图版本是否晚于证书？元素是否新鲜/有出处/别名风险低？）⇒ 否则身份/变化探针；③**孪生证伪**（有效孪生内构造最坏情形；有 J_fals ⇒ 否决并定向探针/绕行；sim⁺ 只排序探针）；④第 57 轮元推断与跨模态对账；⑤证据门 + 承诺；⑥任一地图修订 ⇒ 对 Inv 重基后才允许下一次承诺。预算 `E_total=E_motion+E_probe+E_id+E_reloc+E_twin`，终止于 `k_probes+k_cons+k_id+k_reloc`。

## 2. 关键算法伪代码（完整版见产物区）

```python
def effective_sample_size(E):                       # IP-139
    R = correlation_matrix(E, provenance_graph)
    return len(E)**2 / sum(R)                        # 1^T R 1

def frame_gate(J_F, margins):                        # IP-141
    if J_F.invalid or J_F.drift_rate * J_F.horizon > J_F.eps_pose:
        return 'suspend_relocalize'                  # 共模失效：全部挂起
    for r, m in margins.items():
        if m - J_F.L[r] * J_F.q_pose < theta_K:
            return 'downgrade', r                    # 位姿膨胀裕度不足
    return 'ok'

def loop_closure_gate(cand, M):                      # IP-142
    if cand.alias_risk > theta_alias or n_eff(cand.supports) < 2:
        return 'soft_hypothesis', identity_probe(cand)
    B = len(Dep(cand.i) | Dep(cand.j))
    if cand.p_false * B > eps_alias:
        return 'soft_hypothesis', identity_probe(cand)
    return 'accept_revision', map_revise(M, cand)   # 全局改判 → Inv 回溯

def twin_rehearse(T, s, M):                          # IP-143/144
    if not twin_valid(T, s, M): return []            # 无效孪生不给任何证据
    fails = adversarial_rollouts(T, s, k=k_sim)
    return [f for f in fails if relevant(f, T) and not known_artifact(f)]
                                                    # 只返回可证伪失败
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| ECS | O(\|E\|²) 建 R；O(\|E\|²) 求 n_eff | O(\|E\|²) | 出处图完整、共同源不漏报 |
| SML | O(pose-graph) + O(\|Dep\|·\|Inv\|) | O(\|𝒱\|+\|ℰ\|+\|Dep\|) | 失效集完备、版本单调 |
| FPC | O(\|margins\|) | O(1)+O(Σ) | 协方差校准、漂移检测漏检≤δ_F |
| ALR | O(\|cand\|·\|E\|²) | O(\|ℰ_loop\|) | 别名风险校准、爆炸半径门 |
| DFC | O(\|D_𝒯\|) 校验；O(k_sim) 回放 | O(孪生静态) | 有效域诚实、配准/发散检测 |
| S2F | O(k_sim·T_rollout) | O(k_sim) | 只否决不背书、伪影过滤 |
| PCE-S | O(\|CP\|·(k_p+k_c+k_id+k_reloc+k_sim)) | O(\|V\|+\|σ\|+\|𝒯\|) | 帧门先行、修订后重基、终止 |

**正确性定理（Common-Source Soundness, CSS 概要）**：在 A37–A40（第 57 轮）之上加 **(A41)** 坐标系证书健全：位姿误差超界/失锁/规范漂移的漏检率 ≤δ_F，协方差校准诚实；**(A42)** 地图修订健全：出处与依赖完备，回环假合并率受爆炸半径门约束，失效集 Inv 不漏证书；**(A43)** 孪生保真：有效域内 gap 上界覆盖 ≥1−α_twin，配准发散漏检 ≤δ_div；**(A44)** 仿真非对称：EV-sim⁺ 零授权学分、EV-sim⁻ 仅否决，仿真不入不可逆必要证据集；**(A45)** 共同源记账诚实：出处图不漏边、n_eff 用于一切独立性声明。则：

(i) **共模健全性**：`P_safe ≥ 1 − δ_F − Σ_r P_region_fail|F − δ_alias·1[loop] − δ_div·1[twin] − …`；关键差别是位姿共模项只出现一次，不再被区域 union bound 重复放大。

(ii) **证据学分健全性**：任何要求 k 份独立支撑的证据门，在 n_eff(E)<k 时必拒；EV-sim⁺ 贡献 0，故"同一个孪生/同一张位姿图问 n 遍"无法满足 k 支撑要求。

(iii) **回溯健全性**：任一地图修订后，Inv 中证书在下一次承诺前必然被挂起/重基，故不存在"坐标系已改而证书仍生效"的路径。

(iv) **交互单调性**：FPC/SML/ALR/DFC/S2F 只能经"信念更宽（位姿膨胀、地图集员）、动作更慢/更保守（挂起、降档、绕行）或否决"影响系统；sim⁺ 只改探针顺序，不改探针预算与授权；不存在升险路径。

(v) **终止性**：每检查点探针数有界，PCE-S 在 `k_probes+k_cons+k_id+k_reloc` 内终止于 {承诺, 绕行, L2 协商, 安全停}。

def correlation_matrix(E, G):
    # 由出处图构造单因子载荷；共享因子越多，相关越接近 1
    R = identity(len(E))
    for lam, cls in G.common_classes.items():
        for e in cls:
            for e2 in cls:
                if e != e2:
                    R[e][e2] = max(R[e][e2], G.kappa(e, e2))
    return R

def effective_sample_size(E, G):
    R = correlation_matrix(E, G)
    return len(E) ** 2 / sum(R)                 # n^2 / (1^T R 1)

def evidence_credit(E, k_required, G, requires_independence=True):
    if requires_independence and len(G.common_classes_covered(E)) < k_required:
        return False, 'common_source_not_isolated'
    ne = effective_sample_size(E, G)
    ok = (ne >= k_required) if requires_independence else True
    return ok, ne                            # 学分按 ne 折扣，绝不用 |E| 冒充

## 3. 关键推导与定量界

### 3.1 有效样本量：为什么"问了很多遍"不等于"很多证据"

把 n 条证据的误差写成单因子模型 `ε_i=a_i u+ε_i^⊥`，相关矩阵 R。均值的方差为 `(σ²/n²)1ᵀR1`。定义 n_eff 使 `σ²/n_eff=(σ²/n²)1ᵀR1`，得

```
n_eff = n² / (1ᵀR1) = n / (1 + (n−1)ρ̄).
```

若 `ρ̄=0`，n_eff=n；若 `ρ̄→1`，n_eff→1。即使 n=10000，只要 `ρ̄=0.9`，n_eff≈1.11；`ρ̄=0.99`，n_eff≈1.01。Isaac Sim 的 episode 共享同一孪生构建与同一 reality gap，正是 `ρ̄→1` 的情形；十个共享同一位姿图漂移的区域也是同一情形。**证据门的独立性学分必须用 n_eff，而不是计数。**

### 3.2 位姿膨胀裕度：坐标系误差如何吃掉区域裕度

设区域 r 的标称裕度为 m_r，裕度对位姿的 Lipschitz 常数为 L_r（例如"到障碍物距离"对平移的敏感度、台阶高度对俯仰/滚转的敏感度）。真实裕度满足

```
m_r^true ≥ m_r − L_r‖δξ‖.
```

以坐标系证书的 `q_{1−δ_F}(‖δξ‖)` 代入，得到可用于承诺的证书裕度

```
m_r^cert = m_r − L_r q_{1−δ_F}(‖δξ‖).
```

只有当 `m_r^cert ≥ θ_K` 才允许承诺；否则降档/重定位/重探。关键点：**位姿误差不是区域独立的额外噪声，而是所有区域共享的平移项**；把它逐区域独立处理会低估共模风险，把它只放在定位模块里则会让下游证书"看起来仍然安全"。

### 3.3 回环假合并与爆炸半径

回环候选的单次假合并概率 `p_false` 由别名风险与独立支撑给出。要求独立支撑 `n_eff(E_ij)≥2` 且几何残差过门后，仍有 `p_false`。一次假合并影响的地图/证书数为爆炸半径 B_ij。采用修订门的约束

```
p_false · B_ij ≤ ε_alias
```

才接受全局修订；否则只保留软假设并派身份探针。若单模态假阳性率为 p₁，三份真正独立支撑把假合并压到约 `p₁³`；但如果三份支撑共享同一纹理/同一外观源，则 `n_eff≈1`，假合并率仍约 `p₁`——**"多模态"只有在共同源隔离后才是多模态。**

### 3.4 孪生迁移界与"只否决不背书"的非对称性

在有效域 `s∈D_𝒯` 内，若 reality gap 的校准上界为 `g(𝒯)`，则

```
R_real(s) ≤ R_sim(s) + g(𝒯).
```

要仅凭仿真证明 `R_real≤δ_f`，需要 `R_sim+g≤δ_f`，即 gap 上界必须极小；而 `g` 本身通常比 `δ_f` 大一个量级。更根本的是，k_sim 个 episode 相对现实共享同一孪生，`n_eff≈1`，所以 `R_sim` 的置信区间不会随 k_sim 正常收缩。于是仿真**不能**提供正向安全学分。反过来，若在有效孪生内稳定复现失败，把它当作否决票是保守的：即使孪生偏悲观，最坏也只是损失活性（多探/绕行），不会放行危险。**这就是"仿真只可否证"的严格理由：否证方向是保守的，背书方向不是。**

### 3.5 共模部署界（示意）

对检查点取界，但把共享位姿项提到外层，只计一次：

```
P_safe ≥ 1 − δ_F − Σ_cp (δ_region|F + δ_alias·1[loop] + δ_div·1[twin])
             − P(护盾失败) − P(τ_int ∧ 安全停失效).
```

与第 57 轮相比，关键变化不是多了一个 δ_F，而是**位姿共模项不再被区域 union bound 重复计价**；同时 EV-sim⁺ 不出现在任何正向项中。

## 4. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| ECS | O(N²) 建 R；O(N²) 求 n_eff；增量 O(N·Δ) | O(N²) | 出处图完整、共同源不漏报（A45） |
| SML | O(pose-graph)+O(Dep·Inv) | O(𝒱+ℰ+Dep) | 失效集完备、版本单调（A42） |
| FPC | O(margins) 每检查点 | O(1)+O(Σ_pose) | 协方差校准、漏检≤δ_F（A41） |
| ALR | O(cand·N²) | O(ℰ_loop) | 别名风险校准、爆炸半径门（A42） |
| DFC | O(D_𝒯) 校验；O(k_sim) 回放 | O(孪生静态) | 有效域诚实、配准/发散检测（A43） |
| S2F | O(k_sim·T_rollout) | O(k_sim) | 只否决不背书、伪影过滤（A44） |
| PCE-S | O(CP·(k_p+k_c+k_id+k_reloc+k_sim)) | O(V+σ+𝒯) | 帧门先行、修订后重基、终止 |

**正确性定理（Common-Source Soundness, CSS）**
假设 A37–A40（第 57 轮）成立；**(A41)** 坐标系证书健全：位姿误差超界/失锁/规范漂移的漏检率 ≤δ_F，协方差校准诚实；**(A42)** 地图修订健全：出处与依赖完备，回环假合并率受爆炸半径门约束，失效集 Inv 不漏证书；**(A43)** 孪生保真：有效域内 gap 上界覆盖 ≥1−α_twin，配准/世界发散漏检 ≤δ_div；**(A44)** 仿真非对称：EV-sim⁺ 零授权学分、EV-sim⁻ 仅否决，仿真不入不可逆必要证据集；**(A45)** 共同源记账诚实：出处图不漏边、n_eff 用于一切独立性声明。则：

1. **共模承诺健全性**：`P_safe ≥ 1 − δ_F − Σ_cp(δ_region|F + δ_alias·1[loop] + δ_div·1[twin]) − P(护盾失败) − P(τ_int ∧ τ_mm 超时 ∧ 安全停失效)`；位姿共模项只出现一次。
2. **证据学分健全性**：任何要求 k 份独立支撑的证据门，在 `n_eff(E)<k` 时必拒；`EV-sim⁺` 贡献 0；因此"同一个孪生/同一张位姿图问 n 遍"无法满足 k 支撑要求。
3. **回溯健全性**：任一地图修订后，Inv 中证书在下一次承诺前必然被挂起/重基；不存在"坐标系已改而证书仍生效"的路径。
4. **交互单调性**：FPC/SML/ALR/DFC/S2F 只能经 (a) 信念更宽（位姿膨胀、地图集员、保守加宽）或 (b) 动作更慢/更保守（挂起、降档、绕行、否决）影响系统；sim⁺ 只改探针顺序，不改预算与授权；不存在升险路径。
5. **终止性**：每检查点 `k_probes+k_cons+k_id+k_reloc` 有界，PCE-S 终止于 {承诺, 绕行, L2 协商, 安全停}。

**关键**：**共同源给丰度、n_eff 给真相**（证据量不再被相关样本欺骗）；**位姿给坐标系、膨胀裕度给安全**（共模误差不再被区域 union bound 稀释）；**回环给修订、Inv 给回溯**（地图改判必须追责到证书）；**孪生给效率、证伪给边界**（仿真买探针顺序，不买安全学分）。

## 7. 本轮最大风险

**一句话**：本轮最大风险不是某一次 SLAM 漂移或某一次孪生失真，而是**共同源清单本身错了或回溯不完整**——一旦把共享同一位姿图/同一孪生构建的证据误记为独立证据，或在回环修订后漏掉某张依赖旧位姿的证书，系统就会把"同一个错误问了很多遍"记成"很多独立证据"，在一次全局漂移中集体给出假安全；必须以出处图强制声明、n_eff 折扣、回环修订门与失效集完备性审计四重护栏，宁可让系统又慢又保守，也不让它集体自信地错。
