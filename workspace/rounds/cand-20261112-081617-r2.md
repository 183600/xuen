# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 2 轮；本轮灵感：「在线学习」×「结构优化」）

> 第 57 轮用「元先验 + 共形保底 + 跨模态对账 + 单向有界信任」把证据承诺做成少样本可校准、跨模态可对账、个性化有界的体系，但它的风险自陈暴露了一个更深的结构性缺陷：**整个证据机器是"冻结"的**。**(a)** 元语料在部署前固化，部署中真正产生的、能补上盲区的数据只被"事后证伪回溯"用来**降权**（越错越保守），却从不被用来**学习**（越错越聪明）——于是"坏先验普遍"只能被共形带兜住，系统能变谨慎、不能变准；一旦世界非平稳（季节、磨损、新材质入场），冻结先验会同时失去效率与校准。**(b)** 更根本的是**结构**：区域怎么分、证据类有哪几种、门拓扑怎么连、探针/检查点怎么排，全部是第 53~57 轮手设并"证明一次、终身沿用"的；但正确性定理是对**固定结构**证的，结构一变，定理的前提就没了——而部署数据恰好最有资格告诉我们"哪些格子该细分、哪些证据义务是冗余的、哪些门该加一道"。本轮两个灵感正是要打开这两把锁：**在线学习**把部署流变成"带证人的延迟标签"学习闭环，**结构优化**把静态证据架构变成一个**只允许单向精化**的安全格；二者的合流原则只有一条——**学习只能改变信念，不能放宽门；结构只能在精化方向在线演化，粗化必须进离线和隔离区**。
>
> 关键不是"让系统会学习、会自我改进"，而是设计一个**学习与改进不得越权**的制度：在线更新必须由事后证人或独立模态签发"学习许可"（延迟标签、验证倾向、影子模型晋升），结构编辑必须携带可机械检查的精化证据（J_s），漂移检测必须能在学到错误世界前冻结并回滚。第 57 轮把"一切判定器走隔离"；本轮推广为 **"一切学习器与一切结构编辑都走隔离，且只被允许往保守方向在线演化"**。

核心矛盾：
- **H29（在线学习 vs 可证伪性）**：系统越从自身经验在线学习，失败越可能被学成自洽的"习惯"——用自己产生的证据训练自己，等于把"问同一个问题"推广成"反复强化同一个错误"；真实标签延迟、稀疏、甚至由同一物理机制签发，使信用分配在时间上不可辨识；而非平稳性又意味着历史不保证未来（无遗憾 vs 安全的经典冲突）。
- **H30（结构优化 vs 证明可移植性）**：正确性定理定义在固定结构上（固定分区、固定证据类、固定门拓扑、固定估计器层级）。局部安全的编辑不必组合成全局安全的结构；优化压力会去找门的"合法旁路"（Goodhart）——**优化的对象正是"什么叫证据"，于是优化本身可以优化掉安全**。
- **H31（双时间尺度 vs 统计有效性）**：参数在线更新是快回路（每次接触），结构编辑应是慢回路（每会话/每批）。若快回路跑在慢回路前面，结构就被"过时统计"优化；若慢回路改动后不重置快回路的统计，历史证据会在新结构下被错误地当作同分布样本复用。

## 0. 直觉与动机

**灵感 1（在线学习 → 带证人的延迟标签学习，VOL-D）**
直觉：把第 57 轮冻结的元语料想象成"考前做过的题"，部署才是"真正的考试"。在线学习的第一反应是"边考边学"，但机器人不能边撞边学——不可逆接触的标签只在**事后**到达，且由与探针不完全独立的物理过程签发。于是改成"**带证人的延迟标签学习**"：每条样本先入缓冲，只有拿到**事后实测或独立模态的核实**（证人）才获得学习许可；按已知/可估的核实倾向做逆概率加权，避免"只学被核实的简单样本"；更新步长是**安全参数**（越不确定/漂移越可疑，步长越小直至冻结）；新模型先在**影子模式**跑，必须在核实留出集上"更准且不回退安全"才晋升，否则丢弃并保留检查点回滚。学习率的制度含义是：**学习可以让我更准，但不能让我更敢赌。**

**灵感 2（结构优化 → 结构精化格，SRL）**
直觉：第 57 轮的结构是"建筑师一次画好的图纸"，部署期才发现有的房间太大（同格内材质差异大）、有的门是摆设（某证据类从不改变判决）、有的承重墙必须保留。结构优化若直接做"增删改"搜索，等于允许系统把承重墙也优化掉。改用**格上的单调优化**：把证据架构 S=(Π 分区, Ω 证据义务映射, G 门拓扑, T 探针/检查点拓扑, H 估计器层级) 定义偏序 ⪰；只允许**精化**在线发生（细分格子、增加义务、加严阈值、增设护栏、细分层级/保留部分汇聚），**粗化**（合并、删除义务、放宽阈值、删护栏）一律视为"拆墙"，只能进离线隔离区、需回归证据与影子部署。效率收益不是来自"少要证据"，而是来自"把证据花在真正异构的格子上"——但细分会让每格样本变少，故精化必须携带**校准保持**见证（部分汇聚/分层先验或补充探针使 k\*(w\*) 仍成立），否则不许由细分换取效率。这就是"结构优化的目标不是更松，而是更省"。

**灵感 3（双时间尺度 → 冻结-回滚-再精化的体制机）**
直觉：快慢两个回路必须解耦。参数快回路每步更新；结构慢回路在会话边界、由漂移检测与回归证书共同放行，且每次编辑**冻结**受影响的在线统计（版本隔离），使旧证据不会被新结构"偷用"。漂移检测器是一个在线 e-process/CUSUM：一旦报警，立刻冻结学习、加宽共形带、把结构回滚到最后一个 J_s 认证版本、提高探针预算；恢复后在**留存核实集**上重新校准才解冻。双时间尺度（a_n/b_n→0）给出收敛，冻结/回滚给出安全——**会学习，但学会的东西必须先证明自己不会让我们更敢赌。**

**灵感 4（安全通道不变性 → 新证据类 EV-online 的准入与禁入）**
直觉：在线学习若真有用，就该能省探针；但"省探针"天然是"变大胆"。解决办法是把收益包装成一个**新证据类**并给它苛刻的准入：EV-online 必须（i）标签已核实、（ii）证据生成时的模型版本被冻结、与标签来源不构成自证、（iii）漂移状态为已认证平稳、（iv）仅可作为 L1 佐证、**永不进入不可逆接触必要证据集**（沿用第 57 轮对 EV-xmodal 的隔离思想）。这样在线学习只经由"信念更准（含加宽）"和"动作更保守"两个安全通道起作用，符合并强化交互单调性：**它能把效率挣回来，却不能把风险卖出去。**

## 1. 形式化定义（增量：定义 139–144）

**定义 139（带延迟证人的在线学习 VOL-D）** 流 {(o_t,y_t,Δ_t)}，Δ_t≤Δ_max；标签以概率 q_v 被独立核实（倾向 e_t 已知或可估），核实误差 ≤ε_v。只对已核实集 V_T 更新：φ_{t+1}=Proj_{Θ_safe}(φ_t−η_t w_t ∇ℓ_t(φ_t))，w_t=1/e_t，η_t≤η_max(uncertainty_t,drift_t)（越可疑越小，DRIFT 时 η=0）。每会话更新预算 B_upd。影子学习器 φ^s 仅在核实留出集 H_v 上同时满足「对数损失显著更低（e-value>1/α_prom）」∧「ECE 不劣化 >ε_cal」∧「安全回归集零新增假承诺」时晋升；否则回滚到最近检查点。声明**自适应遗憾契约**：∀区间 I⊆[T]，Reg_I ≤ O(√(|I|·V_I))，V_I=Σ_{t∈I}‖θ_t*−θ_{t−1}*‖ 为漂移变差。

**定义 140（结构精化格 SRL）** 结构 S=(Π,Ω,G,T,H)：区域分区/证据义务映射/门拓扑/探针-检查点拓扑/估计器层级。精化序 S'⪰S 当且仅当 (R1) ∀c'∈Π' ∃c∈Π: c'⊆c；(R2) Ω'(c')⊇Ω(c)（义务不删）；(R3) G 的护栏是 G' 的子图（护栏不删）；(R4) 阈值不放松（δ_f'≤δ_f、θ_K'≥θ_K、α_conf'≤α_conf）；(R5) H' 是对 H 的细分且兄弟格保留部分汇聚。在线编辑算子仅允许 {split, add_obligation, strengthen, add_guard, split_hierarchy}；其逆为**粗化**。**校准保持精化（CPR）**：精化后每子格或满足 k\*(w\*)（补探针），或经部分汇聚/分层先验使 ECE 不劣于父格 +ε_cal；不满足 CPR 的精化不得记入效率收益。

**定义 141（安全结构优化 SOR 与编辑证书 J_s）** 候选精化集 𝒞(S) 由数据触发（D(r) 高→split；某类失败集中→add_obligation；某护栏从不改变判决→候选"中性化"但须等价证明；探针冗余→split_hierarchy）。优化目标 max_{S'∈𝒞(S), S'⪰S_floor} E(S')（E=期望探针数×时延），约束 J_s(S→S')=1。J_s=(S_ver_old,S_ver_new,精化见证 π_witness,CPR 见证,回放回归结果,漂移统计,回滚指针,等价证明[若中性])。**全局安全地板 S_floor 永不可粗化**（安全通道不变性 A43）。粗化只在离线隔离区、经影子部署与回放回归后才可入版。

**定义 142（漂移检测与体制切换 DDT）** 在已核实残差 r_t=|ŷ_t−y_t| 上运行 e-process/CUSUM：E_t=Π_{s≤t}(1+λ(r_s−μ_0))，报警 ⇔ E_t>1/α_drift（Ville 界给 FAR≤α_drift）；变点后检测时延 ≤ D_max=log(1/α_drift)/KL(μ_1‖μ_0)（w.h.p.）。报警 ⇒ {η←0, α_conf←α_conf^+, 结构回滚至最后 J_s 版本, k_probes←k_probes^+}；恢复需在留存核实集上重校（ECE≤ε_meta 且回归零新增假承诺）后解除。未检出漂移期间的参数位移由变差预算 V_T 上界。

**定义 143（双时间尺度在线-结构演化算子 OSE）** 参数步长 a_n、结构步长 b_n，满足 a_n/b_n→0、Σa_n=Σb_n=∞、Σa_n²+Σb_n²<∞。每 B 个会话块尝试一次结构精化；每会话在线编辑 ≤Δ_S；DRIFT 期间结构冻结。收敛目标：快回路在冻结结构上收敛到 Θ_safe 内不动点，慢回路在有限格高/势函数下降下停在极大可认证精化元；因编辑速率有界且格高有限，排除无限抖动。

**定义 144（在线-结构证据门 OSG 与证书 J_o）** 证据类扩为六类：EV-probe\*/EV-visit/EV-margin/EV-xmodal（限 L1）/EV-human/**EV-online**。EV-online 合法当且仅当：(i) 标签已核实（事后实测或独立模态）；(ii) 证据生成时模型版本冻结且与标签来源非自证；(iii) drift_state=CERTIFIED_STATIONARY；(iv) 仅作 L1 佐证，不可替代不可逆接触必要证据；(v) 所在格满足 Ω 义务。不可逆接触必要证据集仍为 {EV-probe\*∨EV-margin}∪佐证。J_o=(S_ver,J_s 链,φ_t/版本,promotion_log,drift_log,replay_log,label_provenance)，继承 J_p 全检；JCPS 输出追加 (φ_t,S_ver,J_s,drift_state,replay_log)。

## 2. 关键算法伪代码（完整版见产物区）

```python
def vol_d_update(phi, buf, drift, meta):            # IP-139：只学被证人签发的样本
    for (o, y, e) in buf.verified():                # 未核实样本永不进入更新
        w = 1.0 / propensity(e)                     # 逆倾向纠正，避免只学简单样本
        phi = project(phi - eta(phi, drift) * w * grad_loss(phi, o, y), Theta_safe)
        buf.consume(); 
    return phi

def try_promote(shadow, inc, H_v):                  # 影子晋升：更准 ∧ 不更险
    if improves_loss(shadow, inc, H_v, alpha_prom) and \
       not worse_calibration(shadow, inc, H_v, eps_cal) and \
       safety_regression(shadow).new_false_commits == 0:
        return shadow, 'promoted'
    return inc, 'rolled_back'                        # 保留检查点，绝不原地覆盖

def structural_edit(S, cand):                       # IP-140/141：只走精化方向
    if not refines(cand, S) or not cpr_holds(cand):  # 更粗/更碎而不可校准 → 拒绝
        return S, 'reject'
    if not regression(safety_replay(cand)).passes:   # 回放旧险情不得新增假承诺
        return S, 'reject'
    return cand, Js(S, cand)                         # 生成编辑证书，记入链
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| VOL-D | O(d_φ)/核实样本；缓冲 O(batch) | O(B_lab+\|H_v\|) | 延迟核实诚实、倾向可估、影子晋升 |
| SRL | O(\|Π\|+\|Ω\|+\|G\|)/编辑 | O(结构日志) | 精化见证机械可检、S_floor 不变 |
| SOR | O(\|𝒞\|·\|H_replay\|) | O(\|𝒞\|) | 仅精化在线、粗化离线隔离 |
| DDT | O(1)/核实残差 | O(window) | FAR≤α_drift、时延≤D_max |
| OSE | 双时间尺度 | O(版本链) | a_n/b_n→0、编辑速率有界、格高有限 |
| OSG | O(\|σ\|) | O(\|σ\|) | EV-online 限 L1、须核实+冻结+平稳 |

**正确性定理（OSS，Online-Structural Soundness 概要）**：在 A37–A40 上新增 (A41) 核实诚实（时延 ≤Δ_max、误差 ≤ε_v、核实倾向 e∈[q_min,1] 且与标签独立/可估）；(A42) 漂移检测 FAR≤α_drift、时延≤D_max、未检出漂移的变差 ≤V_T；(A43) 结构编辑只走 J_s 精化或离线粗化，S_floor 不变；(A44) 双时间尺度条件与 EV-online 冻结/版本隔离成立。则：(i) 在线学习只增加 ≤ε_v+O(√(V_T/(q_min·T)))+α_drift 的失效率，且不改变门的下界；(ii) 任何被接受的精化使承诺集合收缩（P_fail 不增，误差 ≤ε_reg），粗化仅经隔离回归后重新取证；(iii) OSE 在有限格高下停机于极大可认证精化元，无编辑抖动；(iv) 交互单调性保持——学习与结构编辑只能经"信念更准（含加宽）"或"动作更保守"两个通道起作用。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 自证反馈环（用自己证据训练自己） | 高 | 仅核实标签 + 独立模态证人 + 版本冻结 + 影子/回滚 |
| 漂移漏检或迟检 → 学到过时世界 | 高 | e-process 检测 + 冻结/加宽/回滚 + 变差预算 + 保守默认 |
| 结构优化 Goodhart（优化掉安全） | 高 | 精化格 + J_s + S_floor 不可粗化 + 粗化离线隔离 |

| 双时间尺度抖动/结构震荡 | 中 | a_n/b_n→0 + 编辑速率上限 + 有限格高/势函数 |
| 证书与回放开销 | 中低 | 增量哈希 + 代表性回放子集 + 预算封顶 |

## 6. 本轮最大风险

**一句话**：本轮让系统"自己改自己的证据结构"，最大的风险是**自指闭环**——在线学习器用结构 S 产生的证据训练，结构优化器又用在线学习器在 S 下的统计去改 S，于是"局部可认证的精化"可能在无人察觉处组合成全局更弱的门（细分碎裂样本、粗化借道中性编辑、漂移被新结构掩盖），而每一张局部证书都还是真的；必须以"粗化永不上线、EV-online 永不进不可逆必要集、S_floor 不可变、漂移即刻冻结回滚"四条硬不变量把自指环钉死。

### IP-139 VOL-D（带延迟证人的在线学习）

```python
def vol_d_step(phi, buf, drift, meta, session):
    if drift.state != 'STATIONARY' or session.updates >= B_upd:
        return phi, 'frozen'
    for (o, y, e, t) in buf.pop_verified(now):        # 无核实标签 → 留在缓冲
        if not label_verified(y): continue
        w = 1.0 / max(propensity(e), Q_MIN)           # 逆倾向：别只学简单样本
        eta = min(ETA_MAX, eta_base * uncertainty(phi, o)
                            * drift_shrink(drift))     # 越可疑步长越小
        g = grad_loss(phi, o, y)
        phi = project_theta_safe(phi - eta * w * g)    # 投影到安全可行域
        session.updates += 1
    return phi, 'updated'

def shadow_promote(phi, shadow, H_v, alpha_prom, eps_cal):
    if e_value(shadow, phi, H_v) > 1.0 / alpha_prom \
       and calibration_drop(shadow, phi, H_v) <= eps_cal \
       and safety_regression(shadow).new_false_commits == 0:
        return shadow, certify(phi_old=phi, phi_new=shadow, H_v=H_v)
    return phi, rollback_to_last_checkpoint(phi)       # 原模型永不原地覆盖
```

### IP-140 SRL（结构精化格：只拆不改承重墙）

```python
def refines(S2, S1):
    return (all(any(c2 <= c1 for c1 in S1.Pi) for c2 in S2.Pi)       # R1 更细分
            and all(S2.Omega(c2) >= S1.Omega(parent(c2, S1)) for c2 in S2.Pi)  # R2 义务不删
            and subgraph(S1.G_guards, S2.G_guards)                   # R3 护栏不删
            and S2.delta_f <= S1.delta_f and S2.theta_K >= S1.theta_K
            and S2.alpha_conf <= S1.alpha_conf                       # R4 阈值不松
            and hierarchy_refines(S2.H, S1.H))                       # R5 层级细分+兄弟汇聚

def cpr_holds(S2, S1, data):
    for c2 in S2.Pi:                                  # 细分后每格要么够样本
        if cell_samples(c2, data) < k_star(c2, data.w_target):
            if not partial_pooling_ok(c2, S2.H, S1, eps_cal):  # 要么部分汇聚
                return False                          # 否则不许用细分换效率
    return True

def apply_edit(S, cand):
    if not refines(cand, S) or not cpr_holds(cand, S, replay_data):
        return S, ('reject', 'not_certified_refinement')
    if not regression(safety_replay(cand)).passes:    # 旧险情回放不得新增假承诺
        return S, ('reject', 'regression_failed')
    if edit_budget_exhausted(S.session, DELTA_S):
        return S, ('reject', 'edit_rate')
    return cand, Js(S_ver_old=hash(S), S_ver_new=hash(cand),
                    witness=refinement_witness(S, cand),
                    cpr=cpr_witness(cand), replay=regression_log,
                    drift=drift.state, rollback=hash(S))
```

### IP-141 SOR（安全结构优化：在格内买效率）

```python
def structure_optimize(S, data, S_floor):
    if drift.state != 'STATIONARY' or not session_boundary():
        return S, None                                # 慢回路：漂移期/会话中不动结构
    candidates = []
    for c in S.Pi:                                    # 数据触发的精化候选
        if disagreement(c, data) > theta_D: candidates.append(('split', c))
        if failure_concentrated(c, data):  candidates.append(('add_obligation', c))
        if probe_redundant(c, data):       candidates.append(('split_hierarchy', c))
        if guard_never_binds(c, data):     candidates.append(('neutralize_guard', c))
    best, best_gain = S, 0.0
    for cand in candidates:
        S2 = build(cand, S)
        if not (S2 >= S_floor) or not refines(S2, S): continue
        if not cpr_holds(S2, S, data): continue
        gain = E(S2) - E(best)                        # 只按“更省”计分，不按“更松”
        if gain > best_gain and apply_edit(S, S2)[1] not in ('reject',):
            best, best_gain = S2, gain
    return best, Js_chain_delta(S, best)              # 未找到安全精化则原样返回

def offline_coarsen(S2, S, quarantine):               # 粗化永不上线，只进隔离区
    if not quarantine.shadow_deploy(S2).passes_all_regressions():
        return S, ('reject', 'coarsen_not_certified')
    return promote_after_quarantine(S2), Js(S, S2, mode='offline_coarsen')
```

### IP-142 DDT（漂移检测与体制切换）

```python
def drift_update(E, r_t, lam, mu0, alpha_drift):
    E = E * (1.0 + lam * (r_t - mu0))                 # e-process，非负鞅
    if E > 1.0 / alpha_drift:                         # Ville: P(误报) <= alpha_drift
        return E, 'DRIFT'
    return E, 'STATIONARY'

def on_drift(S, phi, M):
    freeze_learning()                                 # η←0
    M.alpha_conf = inflate(M.alpha_conf)              # 共形带加宽
    S = rollback_to_last_certified(S)                 # 回滚到最后一个 J_s 版本
    M.k_probes = increase(M.k_probes)                 # 探针预算上调
    return S, phi, M

def recover(S, phi, H_holdout, eps_meta):
    if recalibrated(phi, H_holdout) <= eps_meta and \
       safety_regression(phi).new_false_commits == 0:
        return unfreeze(phi)                          # 只有重校通过才解冻
    return phi, 'stay_frozen'
```

### IP-143 OSE（双时间尺度在线-结构演化）

```python
def online_structural_evolution(phi, S, stream, meta):
    n = 0
    while True:
        o, y, dt, e = stream.next()
        drift.update(o, y, dt, e)
        if drift.state == 'DRIFT':
            S, phi, M = on_drift(S, phi, M); continue
        phi = vol_d_step(phi, buffer, drift, meta, session)   # 快回路 a_n
        if n % B == 0 and session_boundary():                 # 慢回路 b_n
            S_new, js = structure_optimize(S, replay_data, S_floor)
            if js is not None:
                freeze_stats(S_new)                           # 新结构不偷用旧统计
                S = S_new
        n += 1
        if step_sizes(a_n, b_n) violates_two_timescale(): break
    return phi, S
```

### IP-144 OSG（在线-结构证据门 + 证书 J_o）

```python
def osg_evidence_gate(c, M, S, persona, ood_reg, drift):
    if   c.ev == 'EV-probe*':
        ok = (c.inf.cls == 'ID' and c.inf.ece_k <= eps_meta(c.k)) or \
             (c.inf.cls == 'OOD' and c.region in ood_reg.certified)
    elif c.ev == 'EV-xmodal':
        ok = c.level == 'L1' and c.indep_declared and D(c.region) <= theta_D
    elif c.ev == 'EV-online':
        ok = (c.label_verified and c.model_version_frozen
              and not self_confirming(c.label_source, c.evidence_source)
              and drift.state == 'CERTIFIED_STATIONARY'
              and c.level == 'L1')                        # 永不进入不可逆必要集
    elif c.ev == 'EV-human':
        ok = persona[c.op].auth >= 'A1' and \
             c.corrob >= quarantine_exit(persona[c.op].auth)
    elif c.ev in ('EV-visit', 'EV-margin'):
        ok = round57_checks(c, M)
    else:
        return ('reject', 'no_evidence_class', c)
    if not ok: return ('reject', 'evidence_insufficient', c)
    if c.irreversible and c.ev in ('EV-xmodal', 'EV-online'):
        return ('reject', 'online_or_xmodal_on_irreversible', c)   # 硬禁令
    return ('ok', c)

def online_structural_certificate(sched, S, phi, logs):
    for c in contacts(sched):
        if osg_evidence_gate(c, M, S, persona_of(c), ood_reg, drift)[0] != 'ok':
            return ('reject', c)
    if not structure_floor_intact(S, S_floor):        return ('reject', 'S_floor')
    if S.ver != last_js_chain_head(S):                return ('reject', 'structure_unaudited')
    return ('ok', Jo(S_ver=hash(S), js_chain=S.js_log, phi=phi.version,
                     promotion_log=logs.promotion, drift_log=logs.drift,
                     replay_log=logs.replay, provenance=logs.label_prov))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| VOL-D | O(d_φ)/核实样本；缓冲 O(batch) | O(B_lab+\|H_v\|) | 逆倾向无偏、影子晋升、回滚（A41） |
| SRL | O(\|Π\|+\|Ω\|+\|G\|)/编辑 | O(结构日志) | 精化见证机械可检、S_floor 不变（A43） |
| SOR | O(\|𝒞\|·\|H_replay\|) | O(\|𝒞\|) | 在线只精化、粗化离线隔离（A43） |
| DDT | O(1)/核实残差 | O(window) | FAR≤α_drift、时延≤D_max（A42） |
| OSE | 双时间尺度 a_n/b_n→0 | O(版本链) | 编辑速率有界、有限格高停机（A44） |
| OSG/FSE+ | O(\|σ\|) | O(\|σ\|) | EV-online 限 L1、须核实+冻结+平稳 |

**正确性定理（Online-Structural Soundness, OSS）**
假设 A22–A40 成立；**(A41)** 核实诚实：标签核实时延 ≤Δ_max、核实误差 ≤ε_v、核实倾向 e_t∈[q_min,1] 且与标签独立或可估（否则改用保守上界）；未核实样本永不参与更新。**(A42)** 漂移检测：e-process 误报率 ≤α_drift，变点后检测时延 ≤D_max=log(1/α_drift)/KL(μ_1‖μ_0)，未检出漂移期间参数位移变差 ≤V_T。**(A43)** 结构编辑：在线只接受 J_s 认证的精化（含 CPR），粗化仅在离线隔离区经影子部署与回放回归后入版，全局安全地板 S_floor 不变。**(A44)** 双时间尺度：a_n/b_n→0、Σa_n=Σb_n=∞、Σ(a_n²+b_n²)<∞，EV-online 证据在生成时刻版本冻结、与标签来源非自证。则：

1. **在线学习健全性**：相对第 57 轮冻结先验，在线更新只增加失效率
   `Δ_online ≤ ε_v + δ_online(V_T, q_min) + α_drift`，其中 `δ_online = O(√(V_T/(q_min·T))) + ε_cal`；影子晋升的 e-value 保证错误晋升概率 ≤α_prom。
2. **结构单调性**：若 S' 是 J_s 认证精化（S'⪰S），则任一通过 S' 门的接触也通过 S 门（承诺集合收缩，P_fail 不增，误差 ≤ε_reg）；CPR 保证细分不因样本碎裂而破坏校准；S_floor 不变保证最坏情况下界不弱于第 57 轮。
3. **双时间尺度收敛**：固定结构上快回路收敛到 Θ_safe 内不动点；慢回路在有限格高与势函数 E 有上界下停于极大可认证精化元；DRIFT 期冻结与 Δ_S 编辑上限排除无限抖动。
4. **部署界**（对检查点与结构版本取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1]
                   + δ_online·1[EV-online])
             − Σ_{k edits} (ε_reg + ε_v) − P(𝓜 陈旧未检出) − P(漂移漏检) − P(粗化隔离失败)
```

关键：**在线学习只把"冻结先验"换成"被证人约束的活先验"**，收益走 EV-online（限 L1），风险不进入不可逆层；**结构优化只在精化格里买效率**（更省而非更松），粗化必须离线隔离；**漂移即冻结回滚**，学习/结构都不得在不确定时继续；四条硬不变量（粗化不上线、EV-online 不进不可逆必要集、S_floor 不变、漂移冻结）钉死自指环。

## 6. 本轮最大风险

**一句话**：本轮让系统"自己改自己的证据结构"，最大的风险是**自指闭环**——在线学习器用结构 S 产生的证据训练，结构优化器又用学习器在 S 下的统计去改 S，于是"局部可认证的精化"可能在无人察觉处组合成全局更弱的门（细分碎裂样本、粗化借道中性编辑、漂移被新结构掩盖），而每一张局部证书都还是真的；必须以"粗化永不上线、EV-online 永不进不可逆必要集、S_floor 不可变、漂移即刻冻结回滚"四条硬不变量把自指环钉死。
