## 1. 两个灵感的第一性原理

### 灵感 1 ·「三维感知」→ 把状态层从「2D 框 + 未知深度」升级为「米制几何 + 协方差」

**直觉解释**：第 3 轮的 SceneState 已经会「盯住目标」，但它对目标的描述本质仍是图像平面上的——知道目标在画面哪一块，却不知道离我多远、多大、朝向如何。立体相机 + 已公开标定把这件事从「像素问题」变成「米制几何问题」：深度可由视差直接算，深度误差可由几何直接传播成协方差，抓取点可以在点云法向上采样，而不是在 2D 框里猜。

**严谨定义**（本轮新增 U19/U20，见产物区）：
- **测量模型**：校正后的头立体满足 `d = fB/Z + n_d`，`n_d~N(0,σ_d²)`，故 `Z=fB/d`、`σ_Z = Z²σ_d/(fB)`；横向 `σ_X ≈ Zσ_u/f`。因此 3D 协方差**强各向异性**：深度误差随 `Z²` 增长，横向随 `Z` 线性增长（L14）。
- **6D 物体位姿**：开词汇掩码 → 掩码点云 → 拟合位姿 `(t,R)` 与 `Σ∈R^{6×6}`；对称物体需对称感知；无 CAD 的未见物体退化为「点 + 法向 + 几何供抓性」，正好补上第 3 轮 IP-14 的「抓取点几何失配」。
- **一个关键事实**：评测只下发腕部**彩色**（IR 立体未在观测目录），所以腕部是单目、尺度不可观；它的尺度必须由头立体、手眼关系和已知几何锚定。**头立体是唯一米制锚点，腕部是相对/伺服线索**。
- **在线自标定**：相机→基座外参评测时并不下发，但头视野里能看到夹爪，而 EE 位姿（base 系）是下发的——用「夹爪在视野中的 3D 点 + 已知 EE 位姿」做 PnP，即可在线估计外参并监控残差。这把「依赖未知外参」变成「可自检的自标定」。

**策略含义**：第 3 轮把「该信什么」交给状态层；本轮给状态层装上**带正确单位的尺子**。断言（U17）的 Σ 从「拍脑袋」变成「几何传播 + 系统误差膨胀」，抓取从「2D 外观相似」变成「3D 几何供抓」。

### 灵感 2 ·「自主导航」→ 导航在操作域的三层转译：基座去哪、眼睛去哪、手走哪条路

**直觉解释**：操作任务里的「导航」不是从 A 房间走到 B 房间，而是三件同构的事：①**基座去哪**才能让目标进入可操作区（可达性/重定位）；②**眼睛去哪**才能把位姿不确定性降下来（主动视角/next-best-view）；③**手走哪条路**才能在构型空间里绕开障碍、完成插入（全局规划）。前两件都是「用移动换可操作性或信息」，因此都必须过步数账。

**严谨定义**（本轮新增 U21/U22）：
- **可达性场与可操作度**：对基座位姿 `b` 与目标点 `p`，定义可达性 `r(b,p)∈[0,1]`（IK 可行 + 关节限位 + 无碰撞）与可操作度 `w(b,p)=√det(JJᵀ)`；基座选择 `b* = argmax_b w(b,p)`，约束 `r(b,p)=1`。
- **主动视角的信息增益**：高斯先验 `x~N(μ,Σ)`，视角 `a` 的测量信息阵 `J_a=HᵀR⁻¹H`，后验 `Σ'⁻¹=Σ⁻¹+J_a`，互信息 `I(a)=½logdet(I+ΣJ_a)`；仅当期望成功率增益 `Δp·S` 超过移动成本 `λ·c_move(a)` 才移动（L15）。
- **基座重定位的盈亏平衡**：设好基座下完成任务期望步数 `T`、移动成本 `c_b`、坏基座一次失败浪费 `s_fail`、不动成功率 `p0`，则「先移动」优于「先试」⇔ `c_b < ((1-p0)/p0)·s_fail`（L16）。直觉：可达性越差（p0 越小），越应早移动；p0→1 时几乎不该动。
- **全局-局部分层**：全局在 EE/基座构型空间用 RRT-Connect + 捷径化生成路标序列（碰撞来自 3D 点云地图），局部仍用第 2–3 轮的 WaypointServo；插入/退出用「退让-接近」两段路径。

### 灵感 3 ·「合流」→ 感知即导航，导航即测量

3D 不确定度既是感知的目标，也是导航的收益/代价——二者是同一笔账。第 3 轮 P12「交互即测量」升级为 **P15「移动即测量」**：基座移动与视角移动和探测动作一样，必须在期望步数账上为正才允许上线。于是「最后一厘米」第一次有了可分配的预算：0.5 m 处 σ_d=0.25 px 时深度标准差≈3.8 mm，容差预算可在「感知」与「伺服」之间显式切分，而不是全部压给控制器。

## 2. 研究问题（新增 Q13–Q15，接第 1–3 轮 Q1–Q12）

- **Q13（立体深度的可用域与校准）**：在挑战 32 项的表距（约 0.3–1.0 m）与纹理/反光条件下，头立体 + 几何协方差能否把 U17 到点断言校准到 `[α/2, 2α]`？远距/低纹理/镜面的退化边界在哪？（E634/E641）
- **Q14（3D 抓取与未见物体）**：点云几何供抓性相对 2D 外观相似度，在 DiverseManip 与新语料物体留出上能提升多少？6D 位姿在对称/无 CAD 物体上的误差能否支撑抓取？（E635/E636）
- **Q15（移动的盈亏平衡）**：基座重定位与 NBV 在步骤分约束下何时净收益为正（L15/L16）？公开数据/合成扰动上验证的触发规则能否迁移到评测？（E637/E638）

## 3. 设计原则（新增 P13–P15，接第 1–3 轮 P1–P12）

- **P13（几何优先）**：凡能用米制几何表达的，不用外观相似度；抓取候选按几何供抓性排序，外观只作消歧。
- **P14（协方差诚实）**：所有 3D 量必须带「几何传播的随机项 + 未建模系统误差的膨胀项」；不得用点估计冒充确定量，也不得把系统误差当随机误差喂进卡方门限。
- **P15（移动即测量）**：基座移动与视角移动和探测同账（L15/L16）；预期收益不抵步数成本时不许移动；账算不平的移动只许离线分析。

## 4. 清单处置（深化 / 修剪 / 新增）

- **深化**：IP-13（2D 检测→3D 测量前端 + 在线自标定 + 各向异性协方差）；IP-14（2D 抓取→点云供抓；2D 滑移→腕部锚定 3D 微位移）；IP-05→ReachNav3D（可达性场 + 基座重定位 + NBV + 全局规划）；IP-09（3D 路标 + 全局-局部分层，伺服不变）；IP-06（新增 3D 指标：深度误差/位姿误差/可达覆盖/校准残差）；IP-12（110 数据集 + schema 统一器 + 相机命名鲁棒性）；IP-03（基座动作的延迟整形与 chunk 对齐）。

## 5. 本轮最大风险

**标定/外参漂移（3D 比 2D 更自信地错）**：本轮全部收益建立在「内参已知 + 相机-基座外参可自标定 + 时间同步」上。一旦外参或时延有系统偏差，卡方门限会把**系统误差误判为随机误差**，让系统在错误坐标系里「高置信地失败」——这比第 3 轮的地图毒化更隐蔽，因为 3D 的自信度更高。对冲：①夹爪入视野的在线手眼自标定 + 残差监控；②协方差膨胀项 `Σ_sys` 由残差在线估计（P14）；③残差超阈退化 2D（Level-1.7）；④断言尽量用 EE 相对量闭合，降低对绝对外参的依赖。次要风险：远距/反光/低纹理造成深度空洞；评测相机名 `cam_*_high` 与数据 `head_stereo_*` 不一致、`cam_right_high` 未下发导致「以为有立体其实没有」；基座运动吃步骤分；NBV 过度主动。

> **一句话最大风险**：本轮真正怕的不是「看不到 3D」，而是「3D 坐标系错了还自以为很准」——标定与协方差诚实度决定成败。

## 3. 新增 IP 详述

### IP-16 · Metric3D 立体深度 + 6D 位姿 + 在线自标定（P0，新）

- **动机**：第 3 轮 IP-13 的测量是「开词汇 2D 检测 + 匈牙利/EKF」，协方差是手调的；而官方 `meta/info.json` 直接给出头立体内参、畸变、`R`、`T`（基线 58.26 mm、`rectified:true`）。这意味着深度与协方差可由几何解析得到，不必训练深度网络，也不必逐任务调阈值。
- **与现有方案差异**：teaser 榜（待复核假设）与 v3 状态层都在 2D/隐式 3D；本方案把「目标在哪、多大、朝向、抓哪」全部放进米制 3D，并让 U17 卡方断言的 Σ 有物理来源（L14）。组件全部现成件（SGBM/RAFT-Stereo、SAM/GroundingDINO、点云拟合、PnP），无新策略模型。
- **技术可行性**：高。头立体已校正，`fB≈16.45 px·m`；0.5 m 处视差≈32.9 px，`σ_d=0.25 px` 时 `σ_Z≈3.8 mm`。风险在远距（`σ_Z∝Z²`）、低纹理、镜面。
- **关键工程点**：
  1. **立体是 opt-in**：评测 `obs_delta_indices` 只下发被声明的键，example 只声明 `cam_left_high`；必须显式声明 `cam_right_high` 并在握手校验右目存在，否则「以为有立体其实没有」。
  2. **命名/单位不一致**：评测键 `cam_left_high/right_high`，数据键 `head_stereo_left/right`；头 `T` 为 mm、腕外参为 m。统一器必须显式换算并做左右目一致性检查。
  3. **在线自标定**：相机→基座外参不在观测内，但头视野可见夹爪、且 EE 位姿（base）下发；用夹爪 3D 点 + EE 位姿 PnP 估 `T_base←cam`，残差超阈即 Level-1.7。
- **落地步骤**：①读入 `camera_params`，做左右目校正与单位归一；②视差 + 视差置信（左右一致性 + 唯一性）；③掩码点云 → 6D 位姿 + Σ；④夹爪入视野自标定 + 残差监控；⑤把 `(x̂,Σ)` 接 IP-13/U17；⑥深度空洞/低纹理触发事件重估（E634/E641）。
- **风险**：远距/反光/低纹理深度空洞；外参/时延系统误差（见 §10）；评测右目未下发；对称物体位姿多解。

### IP-17 · ReachNav3D 可达性/基座重定位/NBV/全局规划（P1，新）

- **动机**：接口含 `action.pivot[7]`（vx,vy,angle_z,…,height），富 schema 还含 `action.base_command`（vx,vy,angle_z,height）与 `state_d435`/`state_torso`——**基座/身高是可动的**。挑战中存在书架、传送带、货架等可能超出单一基座位姿可达范围的任务；位置泛化轴也会把目标放到远处。因此「基座去哪」是真实决策，而非装饰。
- **差异**：v3 的 IP-05 只是 2D 可达性；本轮把它升级为「3D 可达性场 + 可操作度 + 信息增益」的统一决策，并与 P15 的步数账绑定。NBV 与基座移动共享同一套代价/收益，避免「为了看得更清楚而乱走」。
- **技术可行性**：中高。可达性用 IK + 关节限位 + 点云碰撞；NBV 用高斯互信息的线性化近似；全局规划用 RRT-Connect + 捷径化。风险在评测是否真正执行 pivot、以及基座运动带来的延迟/抖动。
- **落地步骤**：①从 URDF + 标定建可达性/可操作度场；②目标 3D 点 → 基座位姿选择（`argmax w` s.t. 可达）；③L16 触发规则决定「先移动」还是「先试」；④NBV 在「高不确定 + 高失败代价」相位白名单内启用（L15）；⑤全局路标序列交 IP-09 局部伺服；⑥`action.pivot` 的 chunk 对齐与延迟整形（IP-03）。
- **风险**：pivot 未真正生效 / 评测不允许移动（Q15 接口前提）；基座运动吃步骤分；NBV 过度主动；可达性模型与真机偏差。

## 5. 符号与定义（新增 U19–U22；U1–U18 沿用第 1–3 轮）

- **定义 U19（立体深度测量与协方差）**：校正后 `d=fB/Z+n_d`，`n_d~N(0,σ_d²)`；`Z=fB/d`，`σ_Z=Z²σ_d/(fB)`，`σ_X≈Zσ_u/f`。相机系 3D 协方差 `Σ_cam≈diag((Zσ_u/f)²,(Zσ_v/f)²,(Z²σ_d/(fB))²)`，强各向异性。
- **定义 U20（6D 物体位姿状态）**：`x_T=(t∈R³,R∈SO(3))`，协方差 `Σ_T∈R^{6×6}`；由掩码点云拟合，对称物体按对称群商化；无 CAD 时退化为「质心 + 主法向 + 尺度」，供抓用点云对跖采样。
- **定义 U21（可达性场与可操作度）**：`r(b,p)∈[0,1]` 为基座位姿 `b` 下点 `p` 的 IK 可行且无碰撞程度；`w(b,p)=√det(JJᵀ)`；可达集 `R_b={p:r(b,p)=1}`；基座选择 `b*=argmax_b w(b,p)` s.t. `r=1`。
- **定义 U22（主动视角信息增益）**：先验 `N(μ,Σ)`，视角 `a` 的测量信息阵 `J_a=HᵀR⁻¹H`，互信息 `I(a)=½logdet(I+ΣJ_a)`；决策 `a*=argmax_a [Δp(I(a))·S − λ·c_move(a)]`，仅当括号内 >0 才移动。

```python
# ===== IP-16: 立体深度 + 几何协方差（单位统一后）=====
def stereo_measure(obs, calib, sigma_d=0.25):
    L = rectify(obs.head_left, calib)          # camera_params: rectified=True
    R = rectify(obs.head_right, calib)
    d, conf = disparity(L, R)                  # SGBM / RAFT-Stereo, subpixel
    ok = (d > D_MIN) & (conf > CONF_MIN)
    Z = calib.fB / d[ok]                       # fB ≈ 16.45 px*m
    sZ = Z**2 * sigma_d / calib.fB             # L14: 深度不确定度
    pts = backproject(Z, calib)                # camera frame
    return pts, sZ, ok
```

```python
# ===== IP-16: 掩码点云 -> 6D 位姿 + 诚实协方差 =====
def object_state(obs, mask, calib, dossier):
    pts, sZ, ok = stereo_measure(obs, calib)
    P = pts[ok & mask[ok]]
    T, Sigma = fit_pose(P, model=dossier.primitive, symmetry=dossier.sym)
    Sigma = Sigma + Sigma_sys(est_residual=calib.residual)   # P14: 系统误差膨胀
    return T, Sigma
```

```python
# ===== IP-13/U17: 各向异性 3D 卡方到点断言 =====
def assert_3d(wp, state):
    e = state.t - wp.goal_t                       # 米制误差
    d2 = e.T @ inv(state.Sigma_xyz) @ e           # Sigma 含深度/横向各向异性
    if d2 <= chi2_ppf(3, ALPHA):       return True
    if d2 >  chi2_ppf(3, ALPHA_FAIL):  return False   # 交介入
    return None                                       # 不确定区（滞回）
```

```python
# ===== IP-17: 基座重定位（L16 触发 + 可操作度选择）=====
def maybe_reposition(target, state, base_grid, arm, stats):
    p0 = stats.reach_prob(state.base, target)         # 不动成功率
    if p0 >= P0_HIGH: return state.base               # 几乎必成，别动
    if stats.c_base >= ((1 - p0) / max(p0, EPS)) * stats.s_fail:
        return state.base                             # L16: 移动不划算
    best = None
    for b in base_grid:
        q = arm.ik(b, target)
        if q is None: continue
        score = arm.manipulability(q) - LAMBDA_V * stats.view_cost(b, target)
        best = max(best, (score, b), key=lambda t: t[0])
    return best[1] if best else state.base
```

```python
# ===== IP-17: NBV（L15 盈亏平衡）=====
def next_best_view(state, views):
    best = None
    for a in views:
        J  = expected_info(a, state)                  # H^T R^-1 H
        ig = 0.5 * logdet(np.eye(state.dim) + state.Sigma @ J)
        dp = success_gain(state.Sigma, ig)            # Δp 代理
        score = dp * SCORE - LAMBDA_M * step_cost(a)
        best = max(best, (score, a), key=lambda t: t[0])
    return best[1] if best and best[0] > 0 else None  # 账不平就不动
```

## 7. 推导（新增引理 L14–L16；L1–L13 沿用第 1–3 轮）

**引理 L14（立体深度的不确定度传播与可用半径）** 校正立体下 `d=fB/Z+n_d`，`n_d~N(0,σ_d²)`。由 `∂Z/∂d=−Z²/(fB)` 得 `σ_Z=Z²σ_d/(fB)`；横向 `σ_X≈Zσ_u/f`。故深度/横向误差比 `σ_Z/σ_X=Zσ_d/(Bσ_u)`：在 `Z=0.5 m, σ_d=σ_u=0.25 px, B=58.26 mm` 时约 **8.6×**，`Z=1 m` 时约 **17×**——**3D 协方差强各向异性，各向同性阈值必然错**。若要求 `σ_Z≤τ/3`，则可用半径 `Z_max=√(τ fB/(3σ_d))`：`τ=1 cm, σ_d=0.25 px` 时 `Z_max≈0.47 m`；`σ_d=0.1 px` 时 `≈0.74 m`。⇒ 头立体在近距可支撑毫米级断言，远距必须降级为粗定位或靠腕部/先验锚定。∎

**引理 L15（主动视角的信息增益与盈亏平衡）** 先验 `x~N(μ,Σ)`，视角 `a` 的测量 `z=Hx+v, v~N(0,R)`，后验信息 `Σ'⁻¹=Σ⁻¹+J`，`J=HᵀR⁻¹H`，互信息 `I(a)=½logdet(I+ΣJ)`。若成功率 `p(e)` 关于期望误差 `e=tr(Σ')` 局部线性 `p(e)−p(e')≈κ(e−e')`，则期望分增益 `Δ≈κ(trΣ−trΣ')·S`。故 NBV 值得做 ⇔ `Δ>λ·c_move(a)`。一维特例：`σ'²=σ²σ_m²/(σ²+σ_m²)`，`I=½log(1+σ²/σ_m²)`——**先验不确定度不显著大于测量噪声时，信息增益趋零，移动纯属浪费**。∎

**引理 L16（基座重定位的盈亏平衡）** 设好基座下完成任务期望步数 `T`（已含重试）、移动成本 `c_b`、坏基座一次失败浪费 `s_fail`、不动成功率 `p0`。先移动成本 `C_m=c_b+T`；先试成本 `C_t=p0·T+(1−p0)(s_fail+c_b+T)`。`C_m<C_t ⇔ c_b<((1−p0)/p0)·s_fail`。⇒ `p0≤0.5` 时阈值 ≥`s_fail`：**只要移动比一次失败尝试便宜，就应先移动**；`p0→1` 时几乎不该动。该式直接作为 IP-17 的重定位触发器。∎

## 12. 本轮最值得押注的创新点（一句话）

**押注 IP-16（Metric3D 立体深度 + 6D 位姿 + 在线自标定）**：官方已把 32 项任务、4 路相机、头立体内参与基线（58.26 mm、rectified）全部公开，立体又可在 `obs_delta_indices` 主动声明——这是把第 3 轮「2D 状态层」升级为「米制 3D 状态层」的**零新数据、零新策略模型**窗口；它向下让 U17 断言从「拍脑袋阈值」变成「设计参数 α」，向上为 IP-17 的基座重定位与 NBV 提供可信的 3D 几何与协方差。真正的护城河不是「有深度」，而是**坐标系与协方差的诚实度**（自标定 + Σ_sys + 超阈退化），这恰是「一周抄不走」的工程细节。

> **一句话最大风险**：3D 坐标系一旦标错，系统会比 2D 时代更自信地失败——自标定与协方差诚实度是本轮唯一不能省的环节。
