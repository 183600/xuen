# 第 44 轮（新循环第 4 轮） · Intent-Cert × Foundation-Proposer：把「意图理解」与「具身智能大模型」纳入证书闭环（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 已把「用户」与「并发」纳入闭环，但它仍压着两个未言明的假设：**(H3) 意图是封闭假设类上的统计集合**——共形集 Ĥ_u^α 假定意图可参数化为固定标签、可交换采样；**(H4) 「语义→形式化」这一步可信**——默认把自然语言/多模态指令编译成目标规格不会出错，且可以用同一个大模型既做理解又做校验。本轮两个灵感词精确命中：**「意图理解」**迫使我们从「预测标签」转向「开放世界溯因 + 歧义可执行化」；**「具身智能大模型」**迫使我们把大模型从「被信任的决策者」降级为「不被信任的提议器」，再用独立证书层补上语义接地。二者耦合处是本轮真正的硬问题：**语义自证循环**（模型证明自己理解对了）与**表达力-可验证性权衡**（可判定语法装不下开放意图）。

## 0. 直觉与动机

**灵感 1（意图理解 → 理解不是一个标签，而是「可执行集合 + 知道何时不知道」）**：人类说「把那个拿过来」，「那个」可能指杯子也可能指盘子，「拿过来」可以是递到手上也可以是放到桌上。传统做法让 VLM 输出一个最可能的意图再执行，这在开放世界里等于把**歧义风险**静默转成**动作风险**。我们改为输出**意图假设集** Ĝ_t（任务意图 × 运动意图），只执行对**整个集合**都安全的动作；当集合内意图导致动作分叉时，把「澄清」提升为一等动作；当期限迫使不能问时，执行**最小承诺动作**（对所有意图都安全、且不对任何意图作不可逆承诺）。一句话：**理解 = 把不确定性压缩成可执行证书，而不是压成一个标签。**

**灵感 2（具身智能大模型 → 从「信任模型」到「信任接口」）**：具身大模型（VLA/LLM）真正强的是**提议**——它能在开放世界里想到人想不到的目标分解与操作序列；真正弱的是**可证明性**——语义输出不可审计、会幻觉、会被提示注入。因此本轮做角色分离：**M 只负责提议（propose），V 独立负责认证（certify），选择器只接受 V=1 的候选**。由定义 49 的分离定理，安全性只由 V 决定，**换更大的模型只买覆盖率、不买风险**。这把「要不要用大模型」从安全争论降级为性能/成本问题。

**灵感 3（耦合 → 语义接地证书与自证循环）**：要让「提议-认证」成立，必须解决语义落地：自然语言 u 被编译成 CIG 公式 g，凭什么信？我们要求 **SGC（语义接地证书）**：双向蕴含测试 + 风险控制预测集（RCPS）给出语义误译的概率上界，且**验证器不得与提议器同源**。否则就是「用同一个模型证明自己理解对了」的语义循环，证书会空洞化。这是本轮最容易被审稿人击中的点，也是 E95 红线的由来。

**意图的分层**：意图不是单层的。**任务意图**（做什么：抓杯/递物/避让）来自大模型语义，落在可判定文法 CIG；**运动意图**（怎么动：人下一步轨迹/让行方向）来自轨迹预测，落在共形轨迹集。二者相乘得到 Ĝ_t = Ĝ_task × Ĝ_motion，安全证书必须同时量化两层歧义。

**耦合升级**：ICC（意图证书编译器）把开放指令编译成带 SGC 的意图集；PCA（提议-认证-澄清运行时）用独立认证器做 EXEC/CLARIFY/COMMIT 三分，并给意图签发租约；IAV（意图对抗验证器）用开放世界 fuzz、语义注入、自证循环审计与漂移压力测试回灌 CKB/SCV。四层架构由 v8 的「人格契约层 + 并发证书层」升级为 v9 的「人格契约层 + 并发证书层 + 意图证书层」。

## 1. 形式化定义（增量：定义 44–50）

**定义 44（意图语义域与可认证意图文法 CIG）**：意图 g=(g_task, g_motion)，其中任务意图 g_task=(φ, H, S, ≺)：φ 为有界时域度量时序逻辑（bounded MTL）公式，H/S 为硬/软约束（安全、资源、规范），≺ 为偏好序；运动意图 g_motion 为人类轨迹/让行方向的分布。**可认证意图文法** CIG 是一个可判定片段：谓词有限、时域有界、组合封闭（∧/∨/有界 U），其满足性可在 O(|g|·2^{|P|}) 内判定。观测 o_{1:t} 下，**意图假设集** Ĝ_t = {g ∈ CIG × G_motion : compatible(g, o_{1:t})}。**开放世界投影**：g ∉ CIG 时置 ⊥，禁止静默近似，必须转澄清或人工。**表达力-可验证性权衡命题**：CIG 越接近自然语言，判定复杂度越高；因此把「开放」留给提议器，把「可判定」留给证书，二者通过投影与澄清桥接。

**定义 45（语义接地证书 SGC）**：自然语言/多模态指令 u 经形式化器 f_θ 得到 g=f_θ(u)。语义损失 ℓ_sem(g,g*)∈[0,1] 以目标满足轨迹的编辑距离定义。在校准集 {(u_i,g_i*)} 上用风险控制预测集（RCPS / learn-then-test）求阈值 λ̂，使 P(ℓ_sem(f_θ(u),g*) ≤ λ̂) ≥ 1−α 以 ≥1−β 置信成立。**双向蕴含测试** T(u,g)=(u⊨g, g⊨u)；仅当 T=pass 且 ℓ_sem≤λ̂ 时 SGC 有效，否则 **abstain**。**独立性要求**：签发 SGC 的验证器 V_sem 必须与提议器 M 非同源（规则、小模型或人类金标）；若 M 自证，SGC 空洞，定义 49 的分离定理失效。

**定义 46（意图条件化证书与三分可执行性）**：动作 a 对意图集 Ĝ 的**鲁棒安全** Safe(a,Ĝ) := ∀g∈Ĝ，执行 a 的轨迹满足 g 的硬约束 H_g 与全局安全 H_0；**核心达成** Achieve(a,Ĝ_c) 针对核心子集 Ĝ_c⊆Ĝ（置信度 ≥ρ）。决策三分：
(1) **EXEC**：∃a 使 Safe(a,Ĝ) ∧ Achieve(a,Ĝ_c)；
(2) **CLARIFY**：∃查询 q 使澄清前沿收益 V(q) 超阈值且 q 本身安全（定义 48）；
(3) **COMMIT**：期限迫使时选**最小承诺动作** a_lc：Safe(a_lc,Ĝ) 但不对任何 g 作不可逆承诺。
**不可逆闸门**：不可逆动作仅在 |Ĝ|=1、SGC 有效且人类 consent（联动 IP-57 的 Π_u）时允许。**命题**：若 V 对每个 g∈Ĝ sound，则 Safe(a,Ĝ) 对真实意图 g*∈Ĝ 成立；因此三分决策的超集越保守，soundness 越强、完备性越低。

**定义 47（意图租约与漂移衰减）**：意图租约 ℓ_I=(Ĝ, τ, μ, δ, κ_I)：τ 为理解时刻，μ 为漂移衰减率，δ 为漂移阈值，κ_I 为关键级。漂移统计 d_t = D(预测人动作分布, 观测动作) + 语义嵌入位移。**有效判据**：d_t≤δ 且 t−τ≤TTL_I；过期意图不得支撑不可逆动作。**非可交换性**：漂移破坏共形可交换假设，故用 ACI 在线校准 + 变点检测维持覆盖；μ 由上下文波动率（场景熵、用户切换率）估出。**命题**：若漂移上界 d_t≤δ 且 δ 内所有意图共享同一安全核 H_0，则租约有效期内 Safe 结论 sound；否则必须重理解或降级为最小承诺。

**定义 48（澄清前沿与极小极大信息增益）**：查询 q 把 Ĝ 划分为答案单元 {Ĝ_1..Ĝ_m}，**澄清前沿** F(q) 即该划分。在 credal 集 𝒫(Ĝ) 上定义价值 V(q)=min_{P∈𝒫} E_P[ΔRegret(Ĝ | answer)]（对抗最坏分布），并约束 (a) 执行 q 不引入新的不安全状态，(b) 交互成本 c(q)≤B_clarify。选 q* = argmax V(q) s.t. 约束；若 max V(q) < V_min 则不提问，转 COMMIT 或协商。**推论**：澄清把「猜意图」的风险转换为「有界交互成本」，且在 credal 最坏情形下仍不降低安全性。

**定义 49（提议-认证分离定理）**：设提议器 M: o ↦ {(g_j,a_j,conf_j)}（可含任意幻觉/对抗），独立认证器 V 返回 sound∈{0,1}，选择器 Sel 仅从 {V=1} 中选。则对任意 M，unsafe(Sel(M))=0，只要 V sound 且 Sel 不旁路 V；且完备性 |{V=1}| 随 M 增强单调不降。**推论**：换更大的具身大模型只买覆盖率、不买风险；安全性由 V 而非 M 决定。**前提**：V 的语义部分不得调用 M，否则回到定义 45 的循环。

**定义 50（多用户语义合并与冲突格）**：多用户意图集 {Ĝ_u} 与人格契约 {Π_u} 的合并 ⊔ 需检测三类冲突：资源冲突、目标冲突、规范冲突。合并结果要么是可行的联合意图集，要么触发**最小让步 + 优先级 + 澄清**；CIG 不可满足时禁止静默取交集为空。**命题**：若冲突检测在 CIG 内可判定，则多用户并发下「空集静默放行」为 0，把 v20 的 E93 从契约层扩展到语义层。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 INTENT-CERT-COMPILER（意图证书编译器 ICC）
1. **集合语义解析**：NL/多模态指令 → CIG 的**集合**语义，保留歧义、不强行消歧；OOG 检测置 ⊥ 并路由澄清/人工。
2. **语义接地证书 SGC**：双向蕴含 + 属性测试 + RCPS 风险控制；强制独立验证器（规则/小模型/人类金标），禁止同一大模型自证。
3. **意图指纹**：Ĝ 的结构哈希 + 语义嵌入写入 CKB，支持检索、回归与「张冠李戴」检测。
4. **anytime 细化**：固定观测下随算力增加输出嵌套细化 Ĝ^{(k+1)}⊆Ĝ^{(k)}（保持 sound）；推理被中断时返回当前集合，保证任意时刻可用。

### 2.2 IP-61 PROPOSE-CERTIFY-ASK（提议-认证-澄清运行时 PCA）
1. **提议器适配层**：VLA/LLM 产生多样候选（goal + plan + 置信度），只作为 proposal，不进入守卫。
2. **独立认证器**：CIG 模型检查 + 几何证书 + 人格契约 + 意图租约，返回 certified / uncertified / abstain。
3. **三分决策**：EXEC / CLARIFY / COMMIT；CLARIFY 用定义 48 选查询，COMMIT 用最小承诺动作 + 协商。
4. **意图租约表 + 漂移监控**：ACI 在线校准 + 变点检测；过期意图触发重理解或单调降级。
5. **不可逆闸门与多用户合并**：不可逆动作需 singleton 意图 + SGC 有效 + consent；多用户按定义 50 做语义冲突消解。

### 2.3 IP-62 INTENT-ADVERSARIAL-VALIDATOR（意图对抗与漂移验证器 IAV）
1. **开放世界意图 fuzz**：CIG 边界、OOG、复合目标、时序陷阱、指代歧义。
2. **语义幻觉/提示注入**：场景文字注入、对话注入、gaslighting、矛盾指令。
3. **自证循环审计**：检测 proposer/verifier 同源，独立金标回归，证书空洞化检测。
4. **漂移与多用户**：意图切换、快速用户切换、长时程漂移、跨用户语义冲突。
5. **Sim 三角评测**：Isaac Sim 注入人类意图噪声/延迟/中断，测 safety–completeness–clarification 三角曲线。

## 5. 本轮最大风险

**一句话**：语义接地证书的**自证循环**与 CIG 的**表达力瓶颈**是同一枚硬币的两面——验证器若与提议器同源，证书空洞；可判定语法若太小，系统退化成脆弱命令解析器并丢掉具身大模型的全部开放世界价值，因此 E95（独立金标 + 自证差距）与 E97（OOG 拒识）必须设为红线，默认回退到「白名单命令式 + 每步人工确认 + 最小承诺」这条永不失 sound 的底线。

## 2. 关键算法（伪代码）

### IP-60 ICC：集合语义解析、SGC 与 anytime 细化
```
def compile_intent(u, M, V_sem, calib, G_motion):
    proposals = M.propose_intents(u)          # 集合语义，允许歧义/多解
    out = []
    for g_task in proposals:
        if not in_CIG(g_task):
            out.append(OOG(g_task))           # 不静默近似，转澄清/人工
            continue
        sgc = semantic_grounding_cert(u, g_task, V_sem, calib)
        if sgc.valid:                         # 双向蕴含 + RCPS 风险阈值
            out.append(Certified(g_task, sgc))
        else:
            out.append(Abstain(g_task, sgc.reason))
    G_task = IntentSet(out)
    return product(G_task, G_motion)          # Ĝ_t = Ĝ_task × Ĝ_motion

def semantic_grounding_cert(u, g, V_sem, calib):
    # 独立性：V_sem 与提议器 M 非同源；禁止 M 自证
    if not V_sem.bidirectional_entailment(u, g):     # u⊨g 且 g⊨u
        return SGC(valid=False, reason='entail')
    lam = calib.rcps_threshold(alpha, beta)          # learn-then-test
    l = V_sem.semantic_loss(u, g)
    return SGC(valid=(l <= lam), lam=lam, loss=l)

def refine_anytime(u, k_budget, extra_evidence):
    G = compile_intent_initial(u)
    for k in range(k_budget):                 # 固定观测，算力单调
        G = restrict(G, extra_evidence(u, k)) # 只收缩，保持 sound
    return G                                  # 中断即返回当前 sound 集合
```

### IP-61 PCA：独立认证、三分决策、意图租约与不可逆闸门
```
def pca_step(o, G, persona, deadline, M):
    proposals = M.propose(o, G)               # 任意多、任意幻觉均可
    certified = []
    for g, a, conf in proposals:
        if g not in G:                        # 意图集之外的提议直接丢弃
            continue
        if not certifier.sound(o, g, a, persona):   # 独立 V：CIG 模型检查
            continue                                 # + 几何 + 人格契约
        certified.append((g, a, conf))
    if any(achieves_core(a, G.core) for _, a, _ in certified):
        a = best(certified)
        if is_irreversible(a):
            return EXEC(a) if irreversible_gate(a, G, persona) else CLARIFY(best_query(G))
        return EXEC(a)
    q = argmax_clarification(G, persona, deadline)   # 定义 48
    if q is not None and value(q) >= V_min:
        return CLARIFY(q)
    return COMMIT(least_commitment_safe(o, G, persona))

def irreversible_gate(a, G, persona):
    return len(G) == 1 and G.sgc.valid and human_consent(persona)

def intent_lease(G, t, context):
    mu = drift_rate(context)                  # 场景熵 + 用户切换率
    return Lease_I(G, tau=t, mu=mu, delta=delta_t, kappa=K_INTENT)

def intent_valid(lease, t):
    return (t - lease.tau <= TTL_I) and (drift_stat(lease, t) <= lease.delta)
# 过期 -> 重新理解；若不允许重理解 -> 仅允许最小承诺动作

def argmax_clarification(G, persona, deadline):
    best, best_v = None, V_min
    for q in generate_queries(G, persona, deadline):
        if not safe_to_ask(q, G):             # 提问不得引入不安全状态
            continue
        if cost(q) > B_clarify:
            continue
        v = minimax_value(q, credal_set(G))   # 定义 48 的 V(q)
        if v > best_v:
            best, best_v = q, v
    return best
```

### IP-50/57/58 升级：多用户语义合并与漂移联动
```
def merge_intents(intents, personas):
    # 三类冲突：资源 / 目标 / 规范
    if not CIG_sat(conjunction(intents)):
        return negotiate(minimal_concession(intents, personas))
    merged = conjunction(intents)
    if has_resource_conflict(merged) or has_norm_conflict(merged):
        return negotiate(minimal_concession(intents, personas))
    return merged                             # 空集绝不静默放行

def certify_with_intent_lease(o, g, a, persona, lease, t):
    if not intent_valid(lease, t):
        return False                          # 陈旧意图不得支撑不可逆动作
    if g not in lease.G:
        return False
    return certifier.sound(o, g, a, persona)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性保证 |
|---|---|---|---|
| IP-60 集合语义解析 | O(|u|·|CIG|) 解析 | 意图集 O(|Ĝ|) | 保留歧义；OOG 置 ⊥ 不静默近似 |
| IP-60 SGC | 校准 O(1) 查表；验证 O(|g|) | 校准表 O(N) | RCPS ⟹ 语义风险 ≤α（置信 1−β）；独立性防自证 |
| IP-60 anytime 细化 | 每次迭代 O(|Ĝ|) | 当前集合 O(|Ĝ|) | 固定观测下单调收缩 ⟹ 任意中断点 sound |
| IP-61 独立认证 | O(b·(|g|·2^{|P|}+T_geo)) | 候选 O(b) | 只接受 V=1 ⟹ 输出 sound（定义 49） |
| IP-61 三分决策 | O(b·|Ĝ|) 判定 | O(|Ĝ|) | Safe 量化整个 Ĝ ⟹ 对真实意图 sound |
| IP-61 澄清选择 | O(|Q|·|Ĝ|·log|Ĝ|) | 前沿 O(|Ĝ|) | 极小极大收益 + 安全约束 ⟹ 不降低安全 |
| IP-61 意图租约 | O(1) 判据 + O(d) 漂移 | 每租约 O(1) | δ 内共享安全核 ⟹ 租约期内 sound |
| IP-61 不可逆闸门 | O(1) | O(1) | singleton + SGC + consent ⟹ 不可逆动作可审计 |
| IP-62 意图 fuzz | O(#场景 × T_sim) 离线 | 轨迹 O(N) | 覆盖 CIG 边界/OOG ⟹ 语义反例可检出 |
| IP-62 自证循环审计 | O(N_prop·N_ver) | 日志 O(N) | 同源检测 + 独立金标 ⟹ 证书空洞化可检出 |
| IP-62 漂移检测 | O(N log N) | 窗口 O(N) | 变点 + ACI ⟹ 漂移后可恢复覆盖 |

**分离定理的工程含义**：安全性 = f(认证器 V)，覆盖率 = g(提议器 M)。因此认证器必须走最保守、最高关键级的实现（INT8 固定阈值、规则可审计），而提议器可以随竞赛/部署自由升级 VLA/LLM。模型升级只影响 E96 的认证执行覆盖率与 E100 的覆盖增益，不影响 E95/E96 的违例红线。

## 6. 本轮最大风险

**一句话**：语义接地证书的**自证循环**与 CIG 的**表达力瓶颈**是同一枚硬币的两面——验证器若与提议器同源，证书空洞；可判定语法若太小，系统退化成脆弱命令解析器并丢掉具身大模型的全部开放世界价值，因此 E95（独立金标 + 自证差距）与 E97（OOG 拒识）必须设为红线，默认回退到「白名单命令式 + 每步人工确认 + 最小承诺」这条永不失 sound 的底线。
