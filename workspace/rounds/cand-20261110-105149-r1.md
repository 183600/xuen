# 第 43 轮（新循环第 3 轮） · 证书即专利：以语义地图为权利要求索引，把「检索相似」升级为「证明覆盖」（Claim-Cert Portfolio v1，四层架构 v8）

> 承接第 42 轮 v19（SCV × CKB × ECR 的 Sim-Cert-RAG 飞轮）。第 42 轮自陈最大风险是「仿真偏差累积 + 检索幻觉」——证书会在自信满满中静默失效。本轮两个灵感词恰好各补一刀：**专利布局**给出一种被法律工业打磨过的「边界思维」——专利保护的不是一个点，而是一组**权利要求（claims）**：独立权利要求划大边界、从属权利要求做条件细化、优先权日决定新颖性、自由实施（FTO）检查组合是否踩到别人的权利要求。把它搬到证书上，就是把「一张证书」升级为「一组带作用域、带优先权、带依赖关系的权利要求」，让「相似」不再等于「适用」。**语义地图**则提供权利要求赖以锚定的坐标系——证书不应只声明「在某个度量状态附近安全」，而应声明「在语义实体 `门/货架/桌沿` 的某种交互模式下安全」；语义地图正是这种「在哪、对什么、以何种模式」的索引，也是跨环境复用与跨机器人迁移的公共底座。二者合一，核心主张是：**把第 42 轮「检索到相似模板就合并」的启发式，替换为「只有在语义作用域上证明包含、且无权利要求冲突时才复用」的可判定流程**，从机制上掐死检索幻觉。

## 0. 直觉与动机

**灵感 1（专利布局 → 证书的「权利要求边界」与「自由实施」）**：第 42 轮的 CKB 把证书当「模板」做 Top-k 相似度合并，隐患是**相似 ≠ 适用**：厨房台面抓杯子的证书，可能因嵌入相近被误用到玻璃茶几上，而二者的摩擦与易碎约束天差地别。专利布局的直觉是：模板不该只带「参数」，必须带**权利要求结构**。具体映射为四件事：**(a) 独立/从属**——核心安全不变式是独立权利要求（任何复用都必须满足），工况相关的细化约束是从属权利要求（只在特定语义模式下激活）；**(b) 优先权与新颖性**——每条证书带「验证时间戳 + 环境指纹」，复用前先做**现有技术检索（prior-art search）**，已有更强权利要求覆盖就不必重验，过期证书自动降为「现有技术」而非继续生效；**(c) 自由实施（FTO）**——多个证书组合用于新任务时，必须证明接口区被覆盖、且不存在两条权利要求对同一区域给出相反裁决（权利要求冲突）；**(d) 布局优化**——不是无脑多验，而是在「覆盖率 vs 验证成本 vs 冲突风险」上做组合优化，避免「专利丛林」把所有边界都占满、反而让系统处处触发保守降级。

**灵感 2（语义地图 → 权利要求的「作用域索引」与「迁移基座」）**：第 42 轮的证书作用域仍是度量状态空间里的盒子，换一个房间、换一种家具，盒子就失效，只能从头验证——这是「冷启动」与「Sim-to-Real 偏差」共同的根。语义地图的直觉是：把状态投影到**语义状态** s = (实体 v, 交互模式 g)，证书的作用域写成 S_c ⊆ V×G×X。这样：**(a) 作用域可解释、可审核**——「对抽屉、在 `拉` 模式下、相对位姿 ±5cm 内安全」比一个高维盒子更接近人类的验证直觉；**(b) 复用可迁移**——同一类语义实体（不同房间的两扇门）共享权利要求，只需对新实体的**语义等价性**做轻量确认，而非全量重验；**(c) 幻觉可拦截**——检索只在「语义实体类型相同且作用域包含可被证明」的候选里发生，嵌入相似度仅用于排序，不用于判定适用；**(d) 偏差可定位**——当实机与仿真在同一语义实体上的边际分布出现系统性差异，偏差被归因到具体实体/模式，直接喂给 IP-54 的域随机化去补那一块，而不是笼统地重跑全域。

**灵感 3（耦合：语义地图既是索引，也是「权利要求驱动」的主动建图目标）**：第 42 轮的语义地图是被动产物（SLAM/VLM 建完就用）。本轮让它反过来被证书驱动：运行时只在**空白区（white space）**与**权利要求边界附近**加密建图/验证——因为只有这些地方的语义不确定性会真正改变「覆盖/不覆盖」的裁决。这形成一个更省的新闭环：**权利要求指出哪里没被证明 → 语义地图去把那块建清楚 → 仿真/实机只验那一块 → 补进组合**。比第 42 轮「全域域随机化」便宜一个量级。

**与 v19 的关系**：SCV 负责「造证据」，CKB 负责「存证据」，ECR 负责「用证据」；本轮插入的是**证据的「法律结构层」**——SCM 给证据上语义坐标，CPP 给证据上权利要求与组合规则，CAE 在运行时判定「侵权（进入未覆盖区）/冲突」。飞轮不变，但每一次检索都从「像不像」变成「证不证得了包含」。

## 1. 形式化定义（增量：定义 38–43）

**定义 38（语义地图与语义状态投影）**：语义地图 M = (V, E, R, Λ)，V 为语义实体集（地点/物体/可交互部位），E ⊆ V×V 为拓扑关系，R: V → 2^X 为实体在度量空间的足迹，Λ 为语义描述子（类别、可供性、材质/易碎性标签）。**语义状态投影** π_M: X → S_sem = V × G，G 为交互模式集（如 `接近/抓取/推/拉/放置`）。π_M 多对一：每个语义状态 s=(v,g) 对应度量纤维 F_s ⊆ R_v。要求投影误差有界：∀x, x' ∈ F_s，‖x−x'‖ ≤ δ_fiber(s)，δ_fiber 由 IP-49 的定位/漂移界 B_t 给出。

**定义 39（证书权利要求 claim）**：一条证书被重写为 c = (I_c, F_c, S_c, p_c, D_c, Π_c)：I_c 为**独立权利要求**（无条件必须成立的安全不变式集，如「与任何实体保持 ≥ d_min」）；F_c 为**从属权利要求**（带激活条件的不变式族，如 `if 实体.易碎 then 接触力 ≤ f_glass`）；S_c ⊆ S_sem × X 为**作用域**；p_c = (t_c, ψ_c, hash_M) 为**优先权**（验证时刻、环境指纹、地图版本）；D_c 为依赖的父权利要求集；Π_c 为证据包（仿真/实机证据、置信度、验证器版本）。**sound 定义**：c 在其作用域内 sound，当且仅当 ∀(s,x)∈S_c，I_c(x) 成立且 F_c 中所有被激活的细化约束成立，置信度 ≥ 1−δ_c。

**定义 40（权利要求代数：包含、冲突、组合、自由实施）**：
- **包含/新颖性**：c₁ ⊑ c₂（c₂ 蕴含 c₁）当且仅当 S_{c₁} ⊆ S_{c₂} 且 I_{c₂} ⇒ I_{c₁}，且两证据的验证器版本兼容。若新任务需求 S_req ⊆ S_c 且 c 有效，则**无需重新验证**，直接复用（现有技术）。
- **冲突**：c₁ ⊥ c₂ 当且仅当 S_{c₁}∩S_{c₂} ≠ ∅ 且存在 (s,x) 使二者给出的安全裁决不一致（一条声明安全，另一条的从属约束判为不安全）超过容差 ε_verdict。冲突不可靠「取 max 保守」静默掩盖，必须显式记录并收缩作用域。
- **组合**：c₁⊗c₂ 在接口契约（共享状态变量/坐标系/语义实体）兼容时有定义，作用域取 S_{c₁}×S_{c₂} 的乘积并交，组合 sound 当且仅当接口被覆盖且 c₁⊥c₂（无冲突）。
- **自由实施 FTO**：任务作用域 S_m 被组合 P 覆盖，当且仅当 S_m ⊆ ⋃_{c∈P} S_c 且 S_m 上无冲突；否则 **空白区** W(P, S_m) = S_m \ ⋃_{c∈P} S_c 非空，运行时必须降级或 SafeStop。

**定义 41（证书专利组合与布局优化）**：组合 P ⊆ 𝒞，覆盖率 Cov(P) = Pr_{m∼D_mission}[π(m) ∈ ⋃_{c∈P} S_c]，验证成本 W(P)=Σ_{c∈P} w_c，冲突图 H 以冲突关系连边。**布局问题**：max_{P} Cov(P) − λW(P) s.t. P 在 H 中独立（无冲突）、依赖闭包成立。该问题含最大覆盖为特例，NP-hard；无冲突时贪心达 1−1/e，有冲突时用冲突感知局部搜索。**「专利丛林」判据**：若 |P| 增长而 Cov 边际 < η_marg 且冲突边数上升，则判定布局过密，触发剪枝（合并从属、删除冗余独立权利要求）。

**定义 42（优先权新鲜度与语义迁移有效性）**：c 在 (t, ψ, M) 下有效，当且仅当 t−t_c ≤ A（年龄阈值）、W₁(ψ, ψ_c) ≤ ε_ψ（环境指纹偏移）、且 M 与 hash_M 的语义对齐误差 ≤ δ_fiber。过期或被语义漂移击穿的 c **不删除**，转入「现有技术档案」并标记失效原因（专利的「失效/被无效」），供布局优化与审计追溯。

**定义 43（运行时侵权与空白区判定）**：给定 x，s=π_M(x)。若存在有效 c 使 (s,x)∈S_c 且无冲突 → 取最保守的 active 裁决正常执行；若 mission 要求该 s 被覆盖而 ⋃S_c 未覆盖 → **空白区侵权（white-space violation）**；若多条 active 权利要求冲突 → **权利要求冲突**。**命题（无反例静默失效）**：若所有 c 均 sound、包含判定 exact、且投影误差 ≤ δ_fiber，则运行时「无空白区 ∧ 无冲突」蕴含执行状态处于已证明安全域内；因此任何未证明的安全执行都会被显式拦截为降级/SafeStop，而非静默通过。

**成本模型 v3**：COT₃ = C_layout（组合优化/现有技术检索，离线摊销） + Σ_{c∈P} w_c·1[re-verify on expiry] + C_runtime（权利要求匹配 + 投影，≈20μs） + C_mapping（仅空白区/边界主动建图）。相比 v19 的全域域随机化，C_mapping 从 O(|X|) 降为 O(boundary ∪ white-space)。

## 2. 四大产出设计（增量 IP-57/58/59 + 升级 IP-54/55/56/51/52/49/47/45）

### 2.1 IP-57 SEM-CLAIM-MAP（SCM，语义权利要求地图）
1. **语义锚定与投影**：把每条历史证书的度量作用域经 M 投影为语义作用域 S_c；对每个 (v,g) 记录度量纤维 F_s 与 δ_fiber，作为后续「包含证明」的几何依据。
2. **独立/从属拆分**：用不变式依赖图把 I_c 与 F_c 分开；从属约束带激活谓词（实体标签、模式、外部条件），使复用只激活相关部分，避免「整包保守」。
3. **语义等价判定**：新实体 v' 与已验实体 v 是否可复用，判据是 Λ 等价 + 纤维几何相似 + 材质/易碎等安全相关标签一致，而不是嵌入余弦。
4. **索引结构**：以 (实体类型, 交互模式) 为一级键、以拓扑邻接为二级键建倒排 + 局部 KD 树，支持「同模式跨实例」的快速候选召回。

### 2.2 IP-58 CERT-PATENT-PORTFOLIO（CPP，证书专利组合引擎）
1. **现有技术检索**：新任务 → 需求作用域 S_req → 在 SCM 中找可证明包含的 c；命中则复用并做新鲜度检查，不命中则进入差集补全（复用第 42 轮 RAG 的差集流程，但差集现在是**语义空白区**）。
2. **冲突检测与作用域收缩**：候选合并前做两两冲突检测（共享区裁决不一致），冲突时优先保留优先权更高/证据更强的一条，另一条收缩到无冲突子域或标记为「待裁决」。
3. **布局优化**：在候选证书集上跑冲突感知贪心最大覆盖（成本含仿真预算），输出组合与其覆盖率-成本曲线；对「专利丛林」触发剪枝。
4. **版本与优先权链**：每条证书维护 (t_c, ψ_c, hash_M, 父证书)，漂移/重验产生新版本并自动把旧版转入现有技术档案，保证审计可回放。

### 2.3 IP-59 CLAIM-RUNTIME（CAE，权利要求运行时）
1. **语义投影 + 权利要求匹配**：每拍把状态投影为 s，查 active 权利要求，做「覆盖/空白区/冲突」三态判定，延迟目标 < 20μs（比第 42 轮 L0 查表多一次语义键查找）。
2. **分级失效而非整体 SafeStop**：空白区在 mission 不敏感区 → 降级（限速/回退）；在敏感区 → SafeStop；权利要求冲突 → 取最保守并上报飞轮。
3. **权利要求驱动主动建图**：只对空白区与权利要求边界（覆盖率梯度大处）分配建图/验证预算，输出「下一步该建/该验哪里」。
4. **证据回传**：运行时命中空白区/冲突的轨迹切片，带语义标签回灌 IP-54，作为有针对性的域随机化与反例种子。

## 3. 四层架构 v8

```
L1: TRI-FUSE(INT8) + IP-49 LIO → 度量语义地图 M=(V,E,R,Λ) + 漂移界 B_t + δ_fiber(实体级)
L2: CTC + VLM + IP-35 仲裁 → 任务语义作用域 S_req=(实体类型,模式,约束) + 任务指纹 φ
L3: IP-51 CAR ← IP-59 CAE 权利要求运行时(覆盖/空白区/冲突三态)
    → IP-47 组合(接口契约 + FTO 检查) → IP-39 规划(CBF margin 来自 active claim)
    → IP-48 认证流匹配 + IP-43 韵律 → IP-53 CMC(看门狗)
L4: IP-57 SCM(语义锚定 + 独立/从属拆分 + 包含证明)
    → IP-58 CPP(现有技术检索 + 冲突检测 + 布局优化 + 优先权链)
    ↔ IP-54 SCV(定向仿真: 空白区/边界采样, 反例按语义归因)
    → IP-50 课程 / IP-44 蒸馏 → RCA 重颁证书(带权利要求与优先权) → 契约热更新
运行期: 语义投影(~5μs) + 权利要求匹配(~15μs) → 三态裁决
        → 空白区触发 IP-59 主动建图 / 冲突触发飞轮 / 过期触发定向重验
```

## 5. 本轮最大风险

**一句话**：把证书重写为「权利要求 + 语义作用域」引入了一个新的**证明责任转移**风险——系统安全不再依赖「边际够大」这一连续量，而依赖「作用域包含关系正确」这一离散判定，一旦语义地图投影/实体等价判定出错（把玻璃茶几误判为厨房台面的同类实体），错误会被「证明通过」的形式合法化并在组合中扩散，因此 E87/E88 必须作为红线，包含判定不可证时宁可全量重验也不许相似复用。

### IP-57 SCM：语义锚定与权利要求构建
```
def build_semantic_claim_map(M, CKB):
    SCM = {}
    for c in CKB.certificates:
        # 1) 语义锚定：度量作用域投影到实体/模式
        anchors = []
        for v in M.V:
            if measure_overlap(c.scope_metric, M.R[v]) > 0:
                for g in modes_supported(M, v, c):
                    fib = M.fiber(v, g)          # F_(v,g)
                    anchors.append((v, g, fib, fiber_diam(fib)))
        S_c = {(v, g) for (v, g, fib, d) in anchors} × c.scope_metric
        # 2) 独立/从属拆分（依不变式依赖图）
        I_c, F_c = split_independent_dependent(c.invariants)
        # 3) 语义等价签名：安全相关标签必须一致，嵌入只做排序
        eq_sig = semantic_signature(M, anchors)   # 类别/可供性/材质/易碎/摩擦等级
        SCM[c.id] = Claim(id=c.id, I=I_c, F=F_c, S=S_c,
                          priority=(c.t_verified, c.env_hash, hash(M)),
                          deps=c.dependencies, proof=c.proof,
                          eq_sig=eq_sig, delta_fiber=anchors)
    return SCM

def semantic_signature(M, anchors):
    return {(M.Lambda[v].category, M.Lambda[v].affordance,
             M.Lambda[v].material_class, M.Lambda[v].fragility,
             M.Lambda[v].friction_class) for (v, g, _, _) in anchors}

def semantic_equivalent(v_new, v_old, tol=1):
    # 安全相关标签逐项相等；仅几何/纹理等非安全属性允许 tol 内差异
    a, b = M.Lambda[v_new], M.Lambda[v_old]
    return (a.category == b.category and a.affordance == b.affordance
            and a.fragility == b.fragility and a.friction_class == b.friction_class)
```

### IP-58 CPP：现有技术检索、冲突检测与布局优化

def prior_art_search(S_req, SCM, mission):
    # 关键：先证明作用域包含，再谈复用；相似度只用于排序
    hits = []
    for c in SCM.claims:
        if semantic_overlap(c.S, S_req) == 0:
            continue
        if not scope_inclusion_provable(c.S, S_req):   # 离散判定 + δ_fiber 裕度
            continue
        if not claim_valid_now(c, mission.env_psi, mission.t, mission.M):
            continue
        hits.append(c)
    return max(hits, key=lambda c: (c.priority.time, c.proof.strength), default=None)

def conflict(c1, c2, eps_verdict=1e-3):
    inter = scope_intersect(c1.S, c2.S)
    if is_empty(inter):
        return False
    # 在相交区采样，检查两条权利要求的裁决是否相反
    for (s, x) in sample_scope(inter, n=64):
        if abs(verdict(c1, x) - verdict(c2, x)) > eps_verdict:
            return True
    return False

def merge_claims(cands, S_req):
    P = []
    for c in sorted(cands, key=lambda c: c.priority.time, reverse=True):
        conflict_set = [p for p in P if conflict(c, p)]
        if conflict_set:
            c = restrict_scope(c, conflict_set)     # 收缩到无冲突子域
            if c is None:
                continue                            # 无法收缩 → 归档待裁决
        P.append(c)
    covered = union_scope([c.S for c in P])
    white = S_req - covered
    return P, white

def optimize_portfolio(candidates, D_mission, budget, conflict_graph, lam=1.0):
    # 冲突感知贪心最大覆盖；无冲突时 1-1/e 近似
    P, cov, spent = [], empty_scope(), 0.0
    while spent < budget:
        best, best_gain = None, 0.0
        for c in candidates:
            if c in P or any(conflict(c, p) for p in P):
                continue
            if not deps_satisfied(c, P):
                continue
            gain = (D_mission.mass(c.S - cov) - lam * c.verify_cost) / c.verify_cost
            if gain > best_gain:
                best, best_gain = c, gain
        if best is None or best_gain <= 0:
            break
        P.append(best); cov = cov | best.S; spent += best.verify_cost
    # 专利丛林判据：边际覆盖率过低且冲突边上升 → 剪枝
    if marginal_coverage(P, D_mission) < ETA_MARG and conflict_edges(P) > 0:
        P = prune_redundant(P)          # 合并从属、删冗余独立权利要求
    return P, cov

def claim_valid_now(c, psi_now, t_now, M_now):
    fresh = (t_now - c.priority.time) <= HORIZON_A
    env_ok = wasserstein1(psi_now, c.priority.env) <= EPS_PSI
    map_ok = semantic_align_error(M_now, c.priority.map_hash) <= DELTA_FIBER
    return fresh and env_ok and map_ok

def expire_claims(SCM, psi_now, t_now, M_now):
    for c in SCM.claims:
        if not claim_valid_now(c, psi_now, t_now, M_now):
            archive_as_prior_art(c, reason=invalid_reason(c))
            schedule_targeted_reverify(c)   # 只重验受影响语义作用域

def claim_runtime(x, M, P, mission):
    s = M.project(x)                       # (v, g) + 度量残余
    active = [c for c in P if covers(c, s, x) and claim_valid_now(c, mission.env_psi, mission.t, M)]
    if conflict_any(active):
        return SAFE_STOP, 'claim_conflict'
    if not active:
        if mission.requires_coverage(s):
            return SAFE_STOP, 'white_space'
        return DEGRADED, 'out_of_scope'    # 非敏感区：限速/回退，不整体停车
    # 多条非冲突权利要求取最保守裁决
    return most_conservative(active), 'covered'

def claim_driven_mapping(plan, P, M, budget):
    # 只为「空白区 + 权利要求边界」分配建图/验证预算
    frontier = []
    for v in M.V:
        if near_claim_boundary(v, P, radius=R_B):
            frontier.append((v, coverage_gradient(v, P) * risk_weight(v)))
        elif in_white_space(v, P, plan):
            frontier.append((v, WHITE_SPACE_PRIORITY))
    frontier.sort(key=lambda z: z[1], reverse=True)
    return allocate_mapping(frontier, budget)

def targeted_sim_sampling(P, S_req, white, M, N):
    # 定向域随机化：空白区 + 边界 + 已知冲突实体

    seeds += [x for x in prior_conflict_seeds(M)]      # 历史冲突实体的反例种子
    return run_batch_sim(seeds, domain_randomize(target_entities(M, seeds)))
