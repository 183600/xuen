# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「参数高效微调」×「故障诊断」）

> 第 54 轮把技能组合推进到「动作空间剖面 α_S + 组合图 G_S + 云边映射 γ_ce + 联合证书 J」。本轮换一个更底层的视角：**边端模型靠什么被诊断、靠什么被修复**。核心矛盾：H22：真实故障的根因高维且分散，但边端真正「可操作」的修复方向往往低维；诊断若不能把故障投影到低秩可修复子空间，就会出现「诊断对了、修不了」或「修了但修坏别的」。H23：参数高效微调（PEFT）的低秩结构既是修复手段，也是天然的低维诊断信道；但适配器子空间与历史技能相互干扰，修复新故障可能静默破坏旧能力，使「诊断-修复」闭环产生负迁移。

## 0. 直觉与动机

**灵感 1（适配器即故障可定位子空间 → 把「修」变成「在低维坐标系里定位」）**
直觉：边端模型不整体重训，而是 `W = W0 + ΔW`，`ΔW = B A`，`B∈ℝ^{d×r}, A∈ℝ^{r×k}`，`r ≪ min(d,k)`。`B` 的列空间 `𝒜_W = span(B)` 就是模型的「可修复子空间」。故障诊断不再问「哪个神经元坏了」，而问「故障方向在 `𝒜_W` 上的坐标是什么」。这把高维黑箱诊断降维成低维坐标估计，且坐标天然对应可执行的修复参数——**诊断空间与修复空间第一次重合**。

**灵感 2（故障指纹 → 用适配器激活/低秩梯度做通信友好的签名）**
直觉：边端不需要回传原始轨迹或全模型梯度。故障指纹 `σ(τ)` 取故障轨迹 `τ` 上的适配器梯度低秩压缩（或适配器激活的池化），维度只有 `O(r)` 量级。云端据此诊断，边端只上传 `σ(τ)`。PEFT 结构因此成为**诊断的压缩信道**：参数高效不仅省训练，还省通信与隐私暴露。这与第 54 轮 `Explain_loop` 的反向解释信道天然互补——`Explain` 给语义根因，`σ` 给可修复坐标。

**灵感 3（故障模式基 FMB → 从「逐个修」到「稀疏组合修」）**
直觉：历史上大量故障的指纹往往共享少数方向。学习一组正交的**故障模式基** `U = {u_1,…,u_m}`，新故障指纹满足 `σ ≈ U α` 且 `‖α‖_0 ≤ k_s`。诊断变成**稀疏编码**：用 OMP/LASSO 求 `α`，支撑集 `supp(α)` 就是「哪几种已知故障模式在复合」。于是修复也能组合：`ΔW_r = Σ_{i∈supp} α_i · Repair(u_i)`。诊断可解释（命中了哪几种模式）、修复可复用、且支持「复合故障」。

**灵感 4（诊断-修复证书 DRC + 适配器正交约束 → 「修好了且没修坏别的」可判定）**
直觉：低秩修复最危险的不是修不好，而是**修一个坏一片**（灾难性遗忘）。因此修复补丁必须携带证书 `J_rep = (F, R, r, ΔW_r, ρ_after, Δρ_retain, evidence)`：在故障集 `F` 上鲁棒性谱恢复到 `ρ_min` 以上，在保留集 `R` 上退化不超过 `ε_forget`。用适配器干扰 `I(ΔW_i,ΔW_j) = ‖ΔW_iᵀΔW_j‖_F / (‖ΔW_i‖_F‖ΔW_j‖_F)` 度量子空间夹角，修复前做正交投影 `ΔW_r ← ΔW_r − P_{𝒜_j}ΔW_r`，把干扰压到 `θ_I` 以下。这把「负迁移」变成一个有界的、可验证的量。

**灵感 5（云边诊断-修复闭环 → 参数即信道、证书即契约）**
直觉：边端做**定位**（算 `σ`、判 `supp`），云端做**组合修复**（查 `U`、合成 `ΔW_r`、出证书），边端做**安装与验证**（带 rollback 锚点）。契约 `C_dr = (σ_e, α_e, U_c, ΔW_r, J_rep, B_diag)` 规定：上行指纹 ≤ `B_diag`，下行补丁 rank ≤ `r`，往返 ≤ `τ_dr`。若诊断残差 `‖σ − Uα‖ > τ_resid`，系统必须**弃权（abstain）**而不是硬修——这是本轮最重要的安全阀。它把第 54 轮「云规划-边校验-反向解释-重剖分」闭环下沉到参数层。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（低秩适配子空间）**
基础权重 `W0 ∈ ℝ^{d×k}`，适配器 `ΔW = B A`，`B ∈ ℝ^{d×r}`，`A ∈ ℝ^{r×k}`，秩 `r ≪ min(d,k)`。定义**可修复子空间** `𝒜_W = span(B) ⊆ ℝ^d`（列空间）与输入侧 `𝒜_W^{in} = span(Aᵀ) ⊆ ℝ^k`。技能 `S` 的参数载体为三元组 `(W0, B, A)`，其修复预算为 `rank(ΔW) ≤ r`。

**定义 122（故障指纹）**
对故障轨迹 `τ = {(o_t,a_t,r_t)}` 与诊断损失 `ℓ`，故障指纹
```
σ(τ) = LowRank_r( ∇_{ΔW} ℓ(τ) )   或   σ(τ) = Pool(activations_𝒜(τ))
```
要求 `dim(σ) = O(r)` 且与模型规模无关。**诊断映射** `D: τ ↦ (supp(σ), α)`，其中 `supp` 为命中的故障模式集合，`α` 为对应系数。**诊断残差** `r_diag(τ) = ‖σ(τ) − U α‖₂`。

**定义 123（故障模式基 FMB）**
正交基 `U = [u_1,…,u_m] ∈ ℝ^{dim(σ)×m}`，`UᵀU = I`。任意故障方向近似 `σ ≈ U α`，`‖α‖_0 ≤ k_s`。**非相干性** `μ(U) = max_{i≠j} |u_iᵀu_j|`。诊断目标：
```
α* = argmin_α ½‖σ − Uα‖₂² + λ‖α‖₁ ,   supp = {i : |α*_i| > θ_α}
```
若 `r_diag(τ) > τ_resid`，判定为 **OOD / 不可修**，系统弃权。

**定义 124（诊断-修复证书 DRC）**
`J_rep = (F, R, r, ΔW_r, ρ_after, Δρ_retain, r_diag, evidence)`：
- `F` 为已诊断故障集，`R` 为需保留的技能/任务集；
- `ΔW_r = B_r A_r`，`rank ≤ r`；
- `ρ_after(f) = ρ_{W0+ΔW_r}(f)`，`∀f∈F: ρ_after(f) ≥ ρ_min`；
- `Δρ_retain(s) = ρ_{W0+ΔW_r}(s) − ρ_{W0}(s)`，`∀s∈R: Δρ_retain(s) ≥ −ε_forget`；
- `evidence` 至少含诊断残差、故障探针与保留集回归结果。
若 `r_diag ≤ τ_resid` 且上述两条约束成立，则修复**可部署**；否则 `reject` 或 `abstain`。

**定义 125（适配器干扰与遗忘界）**
干扰 `I(ΔW_i,ΔW_j) = ‖ΔW_iᵀΔW_j‖_F / (‖ΔW_i‖_F ‖ΔW_j‖_F)`。在正交化修复 `ΔW_r ⟂ 𝒜_j` 下，保留集退化满足
```
Δρ_retain(j) ≥ − c_I · I(ΔW_r, ΔW_j) · ‖ΔW_r‖_F
```
即干扰越小，遗忘上界越紧。正交修复约束：`max_j I(ΔW_r,ΔW_j) ≤ θ_I`。

**定义 126（云边诊断-修复契约）**
`C_dr = (σ_e, α_e, U_c, ΔW_r, J_rep, B_diag, τ_dr, anchor)`：
- `σ_e` 边端故障指纹，`‖σ_e‖_bytes ≤ B_diag`；
- `α_e, supp_e` 边端诊断结果；
- `U_c` 云端共享故障模式基；
- `ΔW_r` 云端合成修复补丁（`rank ≤ r`）；
- `J_rep` 修复证书；
- `τ_dr` 往返延迟上界，`anchor` 为可回滚的最后良好适配器。
契约成立当且仅当 `r_diag ≤ τ_resid ∧ J_rep.accept ∧ ‖ΔW_r‖_bytes ≤ B_patch ∧ latency ≤ τ_dr`。

## 2. 关键算法 伪代码

### IP-121 FSL（Fault Signature Localization）

```python
def fault_signature(traj, model, adapter, loss_fn, r):
    # 仅对适配器参数求低秩梯度，不触碰全模型
    gB, gA = grad_adapter(loss_fn, model, adapter, traj)
    # 组合低秩因子并压缩为 O(r) 维指纹
    sigma = lowrank_compress(outer_sum(gB, gA), rank=r)
    return sigma, {"residual_probe": heldout_probe(traj)}
```

### IP-122 FMB（Fault Mode Basis）

```python
def learn_fault_basis(signatures, m, k_s):
    # 字典学习 + 稀疏约束，得到共享故障方向
    U = dictionary_learn(signatures, n_atoms=m, sparsity=k_s)
    U = orthonormalize(U)
    mu = max_abs_offdiag(U.T @ U)
    assert mu <= 0.5 / (2*k_s - 1)   # 非相干性足以支撑精确支撑恢复
    return U
```

### IP-123 SDR（Sparse Diagnosis & Repair）

```python
def diagnose_and_repair(sigma, U, model, W0, r, tau_resid, theta_alpha):
    alpha = omp(sigma, U, sparsity=k_s)
    r_diag = norm(sigma - U @ alpha)
    if r_diag > tau_resid:
        return ("abstain", "ood_fault", r_diag)   # 安全阀：不硬修
    supp = [i for i,a in enumerate(alpha) if abs(a) > theta_alpha]
    fault_dir = U[:, supp] @ alpha[supp]
    B_r, A_r = fit_lowrank_repair(fault_dir, model, W0, rank=r)
    return ("ok", supp, alpha, (B_r, A_r), r_diag)
```

### IP-124 DRC（Diagnosis-Repair Certificate）

```python
def repair_certificate(F, R, W0, dW_r, rho_min, eps_forget, r_diag, tau_resid):
    if r_diag > tau_resid:
        return ("abstain", "low_confidence")
    rho_after = {f: spectrum(W0 + dW_r, f) for f in F}
    if any(v < rho_min for v in rho_after.values()):
        return ("reject", "fault_not_repaired", rho_after)
    delta_retain = {s: spectrum(W0 + dW_r, s) - baseline[s] for s in R}
    if any(v < -eps_forget for v in delta_retain.values()):
        return ("reject", "forgetting", delta_retain)
    return ("accept", DRC(F, R, rank(dW_r), dW_r, rho_after, delta_retain, r_diag))
```

### IP-125 AIR（Adapter Interference Regularization）

```python
def orthogonal_repair(dW_new, adapters, theta_I):
    for dW_j in adapters:
        if interference(dW_new, dW_j) > theta_I:
            # 投影到现有适配器子空间的正交补
            dW_new = dW_new - project(dW_new, subspace(dW_j))
    return dW_new
```

### IP-126 CEDR（Cloud-Edge Diagnosis-Repair）

```python
def cloud_edge_diagnose_repair(edge, cloud, tau_resid, theta_I):
    sigma_e = edge.fault_signature()
    if bytesize(sigma_e) > cloud.B_diag:
        sigma_e = top_r_quantize(sigma_e, cloud.B_diag)   # 信道预算
    alpha, supp, r_diag = cloud.sparse_diagnose(sigma_e, cloud.U)
    if r_diag > tau_resid:
        return ("abstain", "request_more_evidence", r_diag)
    dW_r = cloud.compose_repair(supp, alpha)
    dW_r = orthogonal_repair(dW_r, cloud.adapters, theta_I)
    cert = repair_certificate(cloud.F, cloud.R, cloud.W0, dW_r, r_diag=r_diag)
    if cert[0] != "accept":
        return cert
    edge.install(dW_r, anchor=cloud.last_good)      # 带回滚锚点
    ok = edge.verify(cert, probes=cloud.F + cloud.R)
    if not ok:
        edge.rollback(cloud.last_good)              # 静默失败即回滚
    return ("ok", cert) if ok else ("rolled_back", cert)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| FSL | O(r·|τ| + d·k·r) | O(r)（指纹） | 低秩梯度近似、探针完备 |
| FMB | 离线 O(N·m·k_s)（摊销） | O(dim(σ)·m) | 非相干性 μ 有界 |
| SDR | O(m·dim(σ)·k_s)（OMP） | O(m) | 支撑恢复条件、残差门控 |
| DRC | O((|F|+|R|)·C_ρ) | O(|F|+|R|) | 谱评估可靠、遗忘界 sound |
| CEDR | O(B_diag + r·d·k) | O(r·d + r·k) | 往返 ≤ τ_dr、回滚可用 |

**正确性定理（Parameter-Efficient Diagnosis-Repair Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** 故障方向落在秩 `r` 的适配器子空间内，且 `FMB` 非相干性 `μ < 1/(2k_s−1)`；**(A30)** 正交化修复下遗忘界 `Δρ_retain ≥ −c_I θ_I`；**(A31)** 诊断残差门控 `r_diag ≤ τ_resid` 时支撑恢复精确。
则修复部署成功率：
```
P_success ≥ 1 − P(supp 恢复错误) − P(Δρ_retain < −ε_forget) − P(ρ_after < ρ_min | supp 正确) − P(r_diag > τ_resid)
```
关键：**诊断与修复共享同一低秩坐标系**，**稀疏支撑恢复可判定**，**遗忘被正交干扰界约束**，**OOD 故障必须弃权而非硬修**。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 故障不在低秩可修子空间（OOD/系统性故障） | 高 | 残差门控 + 弃权 + 不可修判定，绝不硬修 |
| 稀疏诊断强制输出错误支撑 | 高 | 非相干性约束 + 重构残差 + 多探针一致性 |
| 修复补丁过拟合已诊断故障 | 高 | 留出故障探针 + 保留集回归 + 证书否决 |
| 适配器相互干扰导致静默遗忘 | 高 | 正交投影 `θ_I` + 遗忘上界 + 回滚锚点 |
| FMB 字典漂移/过期 | 中 | 在线字典更新 + 版本化 `U_c` + 漂移检测 |
| 边端指纹被量化截断失真 | 中 | 自适应码率 + 残差补偿 + 云端请求补证 |

## 6. 本轮最大风险

**一句话**：把故障诊断与修复同时压进「低秩适配子空间 + 稀疏故障模式基」使云边诊断-修复变得参数高效且可证书化，但其 soundness **根本依赖「故障方向可低秩稀疏表示」这一强假设**；一旦遇到传感器漂移、机械磨损、分布外等系统性故障，OMP 仍会强行给出一个自信的稀疏支撑，云端据此合成看似合理的错误补丁——「自信误诊 + 貌似合理修复」可能通过局部探针却在真实边端静默负迁移，比不修更危险，故必须以 **重构残差弃权 + 留出探针 + 正交干扰界 + 回滚锚点** 四重护栏，宁可判定「不可修」，也绝不把低秩可表示性当成故障可修复性的充分条件。

### IP-123 SDR

```python
def diagnose_and_repair(sigma, U, model, W0, r, tau_resid, theta_alpha):
    alpha = omp(sigma, U, sparsity=k_s)
    r_diag = norm(sigma - U @ alpha)
    if r_diag > tau_resid:
        return ("abstain", "ood_fault", r_diag)          # 安全阀
    supp = [i for i,a in enumerate(alpha) if abs(a) > theta_alpha]
    fault_dir = U[:, supp] @ alpha[supp]
    B_r, A_r = fit_lowrank_repair(fault_dir, model, W0, rank=r)
    return ("ok", supp, alpha, (B_r, A_r), r_diag)
```

### IP-124 DRC

```python
def repair_certificate(F, R, W0, dW_r, rho_min, eps_forget, r_diag, tau_resid):
    if r_diag > tau_resid:
        return ("abstain", "low_confidence")
    rho_after = {f: spectrum(W0 + dW_r, f) for f in F}
    if any(v < rho_min for v in rho_after.values()):
        return ("reject", "fault_not_repaired", rho_after)
    delta_retain = {s: spectrum(W0 + dW_r, s) - baseline[s] for s in R}
    if any(v < -eps_forget for v in delta_retain.values()):
        return ("reject", "forgetting", delta_retain)
    return ("accept", DRC(F, R, rank(dW_r), dW_r, rho_after, delta_retain, r_diag))
```

### IP-125 AIR

```python
def orthogonal_repair(dW_new, adapters, theta_I):
    for dW_j in adapters:
        if interference(dW_new, dW_j) > theta_I:
            dW_new = dW_new - project(dW_new, subspace(dW_j))
    return dW_new
```

### IP-126 CEDR

```python
def cloud_edge_diagnose_repair(edge, cloud, tau_resid, theta_I):
    sigma_e = edge.fault_signature()
    if bytesize(sigma_e) > cloud.B_diag:
        sigma_e = top_r_quantize(sigma_e, cloud.B_diag)
    alpha, supp, r_diag = cloud.sparse_diagnose(sigma_e, cloud.U)
    if r_diag > tau_resid:
        return ("abstain", "request_more_evidence", r_diag)
    dW_r = cloud.compose_repair(supp, alpha)
    dW_r = orthogonal_repair(dW_r, cloud.adapters, theta_I)
    cert = repair_certificate(cloud.F, cloud.R, cloud.W0, dW_r, r_diag=r_diag)
    if cert[0] != "accept":
        return cert
    edge.install(dW_r, anchor=cloud.last_good)
    ok = edge.verify(cert, probes=cloud.F + cloud.R)
    if not ok:
        edge.rollback(cloud.last_good)
    return ("ok", cert) if ok else ("rolled_back", cert)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| FSL | O(r·|τ| + d·k·r) | O(r) | 低秩梯度近似、探针完备 |
| FMB | 离线 O(N·m·k_s) 摊销 | O(dim(σ)·m) | 非相干性 μ 有界 |
| SDR | O(m·dim(σ)·k_s) | O(m) | 支撑恢复 + 残差门控 |
| DRC | O((|F|+|R|)·C_ρ) | O(|F|+|R|) | 谱评估可靠、遗忘界 sound |
| CEDR | O(B_diag + r·d·k) | O(r·d + r·k) | 往返 ≤ τ_dr、回滚可用 |

**正确性定理（Parameter-Efficient Diagnosis-Repair Soundness）**
假设第 54 轮 (A26)-(A28) 成立；**(A29)** 故障方向落在秩 `r` 适配器子空间，FMB 非相干性 `μ < 1/(2k_s−1)`；**(A30)** 正交化修复遗忘界 `Δρ_retain ≥ −c_I θ_I`；**(A31)** `r_diag ≤ τ_resid` 时支撑恢复精确。则：
```
P_success ≥ 1 − P(supp 错误) − P(Δρ_retain < −ε_forget)
              − P(ρ_after < ρ_min | supp 正确) − P(r_diag > τ_resid)
```
关键：**诊断与修复共享低秩坐标系**，**稀疏支撑可判定**，**遗忘受正交干扰界约束**，**OOD 必须弃权**。

## 5. 本轮最大风险

**一句话**：把故障诊断与修复同时压进「低秩适配子空间 + 稀疏故障模式基」使云边诊断-修复变得参数高效且可证书化，但其 soundness **根本依赖「故障方向可低秩稀疏表示」这一强假设**；一旦遇到传感器漂移、机械磨损、分布外等系统性故障，OMP 仍会强行给出一个自信的稀疏支撑，云端据此合成看似合理的错误补丁——「自信误诊 + 貌似合理修复」可能通过局部探针却在真实边端静默负迁移，比不修更危险，故必须以 **重构残差弃权 + 留出探针 + 正交干扰界 + 回滚锚点** 四重护栏，宁可判定「不可修」，也绝不把低秩可表示性当成故障可修复性的充分条件。
