# 第 66 轮（承接第 65 轮「VISTA 视觉知情安全时序归因」IP-214~223；灵感循环第 2 轮；本轮灵感：「演示方案」×「安全交互」）

> 第 65 轮用「视觉前瞻 × 动作分块」把 GRIP 的「几何可证伪」升级成「故障可归因」，其自述的最大风险说到了根子上：**VISTA 的归因能力依赖两个隐藏假设——故障属于有限假设集 ℋ，且视觉与几何的失效相互独立（A88）；真实故障常是未知类型的组合，透明/镜面/对抗 patch 又会让视觉与几何共享同一个分布外失效源，此时 FIR 会把未知复合故障强行归入最近假设、只膨胀错误的球，系统反而因为「已经归因」而更自信地继续执行。** 本轮不往 ℋ 里再塞第 7 个假设，也不换模态，而是换一个提问方式：第 65 轮问「**是谁坏了、该膨胀哪个球**」，PROVE 问「**当我们根本不知道是谁坏了时，凭什么还敢说自己安全；这个『敢』能不能被外人复查、被随时撤回**」。本轮核心命题是：
>
> **把「安全」从系统内部的故障后验，外化成可执行、可复查、可撤销的演示证据：用「演示方案」把未知故障的发现变成受控、可逆、随时有效的实验序列；用「安全交互」把「不可逆性」升格为一等资源来记账，任何演示、探针、甚至向人求助，都必须先扣可逆性预算。**

## 0. 直觉与动机

**灵感 1（演示方案 → 演示不是训练数据，而是"可执行证明"）**
直觉：模仿学习（LfD/ACT/扩散策略）把演示当数据，追求"学得像"；但对安全而言，一个演示最珍贵的属性不是它多像专家，而是它是一次**受控实验**——有人在某个上下文里做了某个动作，我们看到了过程，而且（通常）没把东西弄坏。于是把每条演示升级成"带证明的演示"（proof-carrying demonstration）：它自带**前提 context φ**、**不变量 I**（力限/无滑移/工作空间）、**见证 w**（时间戳化的感知与证书）、**撤销计划 R**（从任意前缀退回原状）、**来源 σ**（谁、何时、什么标定版本）。这样"演示过"就变成一条**可复查的证据**，而不是一段不可审计的轨迹。更进一步：**违反不变量的"负演示"比正演示更值钱**——它是一条反例，直接证伪一条安全断言；"演示方案"的真义就是**如何把正、负演示编排成一套反证组合**。

**灵感 2（演示方案 → 未知故障不可枚举，但"可以被证据界定"）**
直觉：VISTA 的困境是 ℋ 有限。你永远无法把所有未知故障列完，所以"归因正确"这条路在开放世界里必然漏。但换一个目标就可解：不要求**发现**未知故障，而要求**约束自己敢声称的安全程度**。维护一个开放式新颖度分数 s(x)（状态/签名到演示分布的偏离），把演示集当作 conformal 标定集得到 p 值，再用 e-process 累积"财富"E_t；一旦 E_t 越过 1/α_ow，就判"分布外/未知故障"并安全降级。同时用**随时有效的置信上界** Û_t 去估计"部署中新颖质量 π_novel"：只有当 Û_t≤ε 时才允许在证书上写"未知故障质量 ≤ ε"。这不是"我能发现一切"，而是"**我只敢在证据允许的范围内说自己安全**"。必须诚实：这套保证是相对于**演示分布**的；演示被人挑选，就可能把保证买偏——这是本轮的头号软肋。

**灵感 3（安全交互 → 可逆性是一等资源，而不是事后补丁）**
直觉：安全交互不是"永不失败"，而是"失败也能退"。把**可逆性**做成一种会消耗、会恢复的资本：状态 s 下执行动作 a 有承诺成本 c(a)，执行撤销可回收 ρ(a)，预算 B_{t+1}=B_t−c(a_t)+ρ(a_t)；只要 B_t≥B_min，交互就是可退的。用 CVaR 而不是期望来刻画撤销代价（因为安全关心尾部），于是"不可逆"就是 κ=∞。这一把尺子同时量住了力限、滑移裕度、VISTA 的不可逆视界 m、以及人机交接——它们都只是在花同一种钱。提问方式从"这个力多大"变成"**我还剩多少可以反悔**"。

**灵感 4（安全交互 → 把"问人"当成最后一种探针）**
直觉：VISTA 的 AFA 用物理探针分故障，但易损物体上物理探针本身就是伤害源。人示范是一种**非接触探针**：让懂的人做一遍给我看。但"问人"不能是开放式打扰，必须是**契约**：声明上下文 φ_req、要检验的断言 claim、要求维持的不变量 I_req、愿意支付的预算 B_req 与时限 T_req；人可以接受、还价、拒绝。机器人先验证演示是否真的满足契约，再决定信不信。这是"安全交互"在**权限层**的版本：不是机械臂别撞人，而是**请求本身也别越界**——机器人绝不要求人做一件连它自己都不敢做的动作。

**灵感 5（合流 → PROVE：Proof-carrying Reversible Open-world Verification via Expert demonstrations）**
闭环：PCD（带证明演示）→ RIB（可逆性预算账本）→ OWM（开放世界监控：新颖度 + e-process + 随时有效界）→ DFP（反证演示组合）→ DRC（演示请求契约，人机安全交互）→ DVL（验证与来源账本，防事后挑选）→ RAC（可逆动作屏蔽）→ CSC-R（可逆感知认证前缀）→ AFA-D（预算化主动归因）→ J_prove（带证明、可撤回的安全证书）。第 65 轮是"在有限 ℋ 内把故障分开"，PROVE 处理"**ℋ 之外**"：不保证归因对，只保证**错也留痕、错也能退、错也不被过度自信地宣称安全**。一句话定位：**从"归因正确"到"错误可审计、可逆转、可撤回"**。

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（PROVE 闭环）**：PROVE = (VISTA, PCD, RIB, OWM, DFP, DRC, DVL, RAC, CSC-R, AFA-D, J_prove)。定位：VISTA 的"开放式证据 + 可逆交互"升级。不变式：**演示采集、验证、归因与证书构建只在语义流与离线审计；实时流只做可逆投影、预算扣减、早停与派发，零学习写操作。**
- **定义 234（带证明演示 PCD）**：d=(φ_d, π_d, I_d, w_d, R_d, σ_d)。φ_d 为上下文/前提，π_d 为示范动作序列（可为负演示），I_d 为不变量谓词，w_d 为见证轨迹，R_d 为每条前缀的撤销计划，σ_d 为不可伪造来源（人/策略/时间/标定版本）。演示的价值不止"像专家"，更在"可复查地证明/证伪某条断言"。
- **定义 235（演示有效性 Valid_demo）**：Valid_demo(d) ⇔ φ_d 在起点成立 ∧ w_d 与来源标定 σ_d 在 conformal 界内一致 ∧（I_d(w_d)=真 ∨ 显式标注为负演示）∧ R_d 对每条前缀可执行 ∧ σ_d 验签通过。负演示是有效证据，但只进"反证集"，不得进"正证据集"。
- **定义 236（可逆性模型与预算）**：状态 s、动作 a 的撤销代价 κ_α(s,a)=CVaR_α[最优撤销计划 R 的代价]，无撤销计划则 κ_α=∞。可逆性预算 B_{t+1}=B_t−c(a_t)+ρ(a_t)，B_0 初始、B_min 保留。动作 r-可逆 ⇔ κ_α(s,a)≤r。预算是一个**风险测度**（CVaR），不是计数。
- **定义 237（安全交互谓词）**：SafeInteract(τ) ⇔ ∀t: B_t≥B_min ∧ a_t∈A_r(s_t)，A_r(s)={a:κ_α(s,a)≤r}。可逆视界 m_rev(s)=max{k:Σ_{i<k}c_worst(a_i)≤B_t−B_min}。VISTA 的 m 是 κ 取 0/∞ 指示函数时的特例。
- **定义 238（演示方案与选择协议）**：演示方案 S=(Strata, π_sam, n, prereg_hash)：分层划分、采样策略、预算、部署前提交的哈希。演示集 D~S。可审计 ⇔ hash(S) 与账本一致 ∧ 每条演示的分层归属一致。覆盖 Cov(S) 为"达到最小演示数的部署分层比例"。
- **定义 239（开放式新颖度与 conformal p 值）**：新颖度 s(x)（演示状态距离、签名马氏距离、或视觉/力残差嵌入的 OOD 分数）。标定集 D_cal 上 p_t=(1+#{i:s_i≥s_t})/(n_cal+1)。可交换性下 p_t 超均匀。
- **定义 240（e-process 与随时有效的未知故障界）**：e 值 e_t=κ p_t^{κ−1}（κ∈(0,1)），财富 E_t=∏e_i。Ville 不等式给出 P(∃t:E_t≥1/α_ow)≤α_ow，越过即判"分布外/未知故障"。另用随时有效上界 Û_t（Hoeffding/Bernstein + 并集界 α_t=6α/(π²t²)）估计部署新颖质量 π_novel；只有 Û_t≤ε 才允许证书声称"未知故障质量≤ε"。**E_t 负责"何时警觉"，Û_t 负责"敢说自己多安全"，二者职责分离。**
- **定义 241（反证演示组合与价值）**：组合 P⊆D。覆盖价值 V(P)（被覆盖分层数，次模）、证据价值 W(P)=log E_{|P|}、成本 K(P)=Σκ(d)+λ_tT(d)。VoD(P)=V(P)+λ_wW(P)−λ_BK(P)；在 SafeInteract(P) 下最大化。覆盖部分用贪心获 1−1/e，证据部分用局部搜索。
- **定义 242（演示请求契约 DRC）**：q=(φ_req, claim, I_req, B_req, T_req)。可受理 ⇔ I_req⊆I_certified(机器人自身可认证包络) ∧ B_req≤B_t−B_min ∧ claim 对准一个真实缺口（Û_t>ε 或归因熵高）。人响应 r∈{accept(d), counter(q'), refuse}。accept 后交 DVL 验证；refuse 则 safe_idle。
- **定义 243（演示验证与来源账本 DVL）**：只追加的 Merkle 账本，记录演示哈希、来源、方案哈希。有效 ⇔ 相对 prereg 无事后删除/重排 ∧ 来源验签 ∧ 每条 Valid_demo。可检测**事后挑选**与重放，但检测不了**预先就带偏**的方案（见风险）。
- **定义 244（可逆动作屏蔽 RAC）**：π_σ^rev=Π_{A_r(s)}π_σ(a)；A_r(s)=∅ 时输出 safe_stop 并发起 DRC。屏蔽是"最后一道可逆闸门"，不是性能优化。
- **定义 245（可逆感知认证前缀 CSC-R）**：k*=min(k_csc, k_rev)，k_rev=max{k:Σ_{i<k}c_worst(a_i)≤B_t−B_min}。Valid 要求 k*≥1；块承诺风险同时受 VISTA 的 α_chunk 与本轮 α_rev 约束。
- **定义 246（预算化主动归因 AFA-D）**：a*=argmax_{a∈A∪{ask_human}} [I(ℋ∪{U};ρ(a)|ρ_{1:2}) − λ_Bκ(a) − λ_tT(a)]，s.t. SafeInteract、f_n≤f_safe；`ask_human` 仅当 DRC 可受理。新增未知故障汇假设 U，但**只用于检测与降级，绝不强行归因到 U**。

## 2. 关键算法骨架

```python
# OWM：新颖度 → e-process（何时警觉）+ 随时有效界（敢说多安全）
p_t = conformal_p(novelty(x_t), calib_scores)      # 超均匀
E_t = E_prev * (kappa * p_t ** (kappa - 1))        # 财富累积
flag = E_t >= 1.0 / alpha_ow                       # 分布外/未知故障
U_hat = anytime_ucb(novelty_hits, t, alpha)        # 新颖质量 UCB
certifiable = (U_hat <= eps) and not flag

# RIB + RAC：先问"还能不能退"，再问"做不做"
a_rev = project_to_reversible(a, A_r(s))           # 空集 → safe_stop + DRC
B_next = B_t - c(a_rev) + rho(a_rev)
assert B_next >= B_min                             # 安全交互谓词

# DRC：请求演示而不是硬探
q = contract(query_claim(post, U_hat), I_req=I_certified,
             B_req=min(B_t - B_min, kappa_probe), T_req=T_max)
if admissible(q) and voa_ask_human(post, q) > voa_best_probe:
    d = request_human_demo(q)                       # 人可 accept/counter/refuse
    if d and Valid_demo(d): dvl.append(d)
    else: return safe_idle()

# CSC-R + J_prove
k_star = min(csc.certified_prefix(A, post, m, alpha_chunk),
             max_reversible_prefix(A, B_t - B_min))
return build_j_prove(J_vista, dvl.root, E_t, U_hat, B_t, k_star, ...)
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（负演示可判定且有用）**：Valid_demo 可由见证与撤销计划判定；负演示只进反证集，却能把"某断言在 φ_d 上成立"直接证伪。因此演示的价值不是"正样本数量"，而是**正/负证据对断言空间的覆盖**。
- **引理 10（随时有效的新颖质量界）**：固定预注册标定集下，尾事件 π_novel 的经验上界 Û_t 满足 P(∃t:π_novel>Û_t)≤α_ow（并集界 + Hoeffding/Bernstein）。故 Û_t≤ε 是"未知故障质量≤ε"的有限样本、随时有效证书。
- **引理 11（预算充分性）**：若所有执行动作落在 A_r 且累计最坏承诺成本≤B_0−B_min，则每条前缀都存在 CVaR_α 撤销计划、成功概率≥1−α，交互不会越过不可逆边界（CVaR 的次可加性 + 预算归纳）。
- **命题（组合次模性）**：覆盖价值次模，贪心达 1−1/e；证据价值 log-wealth 非次模，退化为"覆盖贪心 + 证据局部搜索"。
- **定理 9（PROVE 开放世界安全/虚假保证界）**：在 A94–A98 下，若 Valid(J_prove)，则要么 flag_t 触发安全降级，要么新颖质量≤ε；后者与 VISTA 定理 7 合并，得"质量>ε 的未知故障活跃而证书称安全"的概率≤α_ow+α_vis+δ_fi+α_rev。**这把 A88 的"故障可枚举"弱化成"故障的新颖质量可被 ε 界定"。**
- **定理 10（可逆交互的近安全）**：若所有动作过 RAC 且前缀由 CSC-R 截断，则交互满足 B_min-安全、每条前缀以≥1−α 可撤销，块承诺风险≤α_chunk+α_ow+α_rev；VISTA 的 m 是本定理在 κ∈{0,∞} 下的退化。
- **实时性**：新颖度采样（<0.1ms）、e-process/UCB 更新（<0.02ms）、RAC 投影（<0.1ms）、预算扣减（<0.01ms），其余同 VISTA，目标 ≤2.7ms（A98 修订契约）。

## 5. 本轮最大风险

**一句话**：PROVE 的全部开放世界保证都建立在 A94——"演示方案在部署前预注册、且部署与演示在分层内可交换"——之上；但**演示是人挑选的**，预注册只能防事后篡改，防不了**事先就带偏的演示方案**（只演示容易的、避开易损与透明场景），此时 `Û_t≤ε` 会成为一张"用偏样本买来的安全证明"，系统因为"演示通过了、财富没报警"而获得**虚假保证**，比 VISTA 的"错误归因"更危险，因为它把不确定性包装成了可审计的确定性。

## 2. 形式化定义（完整版）

**定义 233（PROVE 闭环）** PROVE 是 VISTA 的"开放式证据 + 可逆交互"升级：在 VISTA 的"语义流 ∘ 实时流"骨架上挂载 PCD（带证明演示）、RIB（可逆性预算）、OWM（开放世界监控）、DFP（反证演示组合）、DRC（演示请求契约）、DVL（验证与来源账本），并原位升级 Shield/OCB→RAC、CSC→CSC-R、AFA→AFA-D、J_vista→J_prove。不变式：**演示采集、验证、归因、组合选择与证书构建只发生在语义流与离线审计；实时路径只做新颖度采样、预算扣减、可逆投影、早停与派发，零学习写操作。**

**定义 234（带证明演示 PCD）** 一条演示
d=(φ_d, π_d, I_d, w_d, R_d, σ_d)，
其中 φ_d 为上下文/前提（物体、几何、任务、技能），π_d∈ℝ^{T×d_a} 为示范动作序列，I_d 为不变量谓词（|f_n|≤f_lim、无滑移、工作空间、接触力单调等），w_d 为时间戳化的感知/证书见证，R_d 为从 π_d 每条前缀出发的撤销计划，σ_d 为不可伪造来源（示范者、策略版本、相机/力传感器标定版本、时间）。若 I_d(w_d)=真称**正演示**，否则称**负演示**。负演示同样是有效证据：它证伪"断言在该 φ_d 上成立"，但不得进入正证据集。

**定义 235（演示有效性）**
Valid_demo(d) ⇔ φ_d 在起点成立
∧ w_d 与 σ_d 的标定在 conformal 界内一致
∧ (I_d(w_d)=真 ∨ 标注为负演示)
∧ (∀前缀 p≼π_d: R_d(p) 可执行且 κ_α≤r)
∧ σ_d 验签通过。
**关键区分**：一条违反 I_d 的轨迹是"有效负演示"而不是"无效数据"；只有见证与来源不可信、或撤销计划缺失，才是真正无效。这样演示库不会因为"人也会失败"而丢弃最有价值的信息。

**定义 236（可逆性模型与预算）** 对状态 s、动作 a，令
κ_α(s,a)=CVaR_α[ C(R) ]，
C(R) 为最优撤销计划 R 的总代价（时间/能量/位移/对物体的二次损伤），无可行撤销则 κ_α=∞。可逆性预算
B_{t+1}=B_t−c(a_t)+ρ(a_t), B_0=B_init,
其中 c(a) 为承诺成本（进入不可逆区域的程度），ρ(a) 为执行撤销后的回收。动作 r-可逆 ⇔ κ_α(s,a)≤r。**预算用 CVaR 而非期望**，因为安全关心最坏尾部的可撤销性；这也与 WCV 的 CVaR 尾部采样在语言上统一。

**定义 237（安全交互谓词）** 轨迹 τ=(a_0,…,a_{T−1}) 安全 ⇔
∀t: B_t≥B_min ∧ a_t∈A_r(s_t), A_r(s)={a:κ_α(s,a)≤r}。
可逆视界
m_rev(s)=max{k:Σ_{i<k}c_worst(a_i)≤B_t−B_min}。
当 κ_α 取 0/∞ 指示函数时，m_rev 退化为 VISTA 的不可逆视界 m；当取力/滑移裕度时，退化为 FCS/SLD 的约束。**因此"安全交互"不是新增一层约束，而是把已有各层的"不可逆"统一标价。**

**定义 238（演示方案与选择协议）** 演示方案
S=(Strata, π_sam, n, prereg_hash)，
Strata 为部署上下文的一组预注册分层（物体类别×易损度×透明/反光×接触类型×负载区间），π_sam 为分层内采样策略，n 为演示预算。演示集 D~S。方案可审计 ⇔ hash(S) 与 DVL 记录一致 ∧ 每条 d 的分层归属可由 φ_d 复算。覆盖率
Cov(S)=|{分层 j : n_j≥n_min}| / |Strata|。
**预注册的意义**：它把"事后挑好看的演示"排除，但**排除不了"一开始就只挑好做的分层"**——这是本轮无法用工程手段消除的残余风险。

**定义 239（开放式新颖度与 conformal p 值）** 新颖度
s(x)=‖ψ(x)−μ_demo‖²_{Σ_demo⁻¹} 或 OOD 头输出，
ψ 为任务观测量/视觉-力残差嵌入的拼接，μ_demo、Σ_demo 由演示集估计。用独立标定集 D_cal（不得与用于拟合 ψ 的演示重叠），conformal p 值
p_t=(1+#{i∈D_cal : s_i≥s_t})/(n_cal+1)。
在可交换性下 p_t 超均匀。**若演示与部署不可交换（选择偏差/漂移），p_t 的超均匀性被破坏，后续所有保证失效**——此即 A94。

**定义 240（e-process 与随时有效的未知故障界）** 取 κ∈(0,1)，e 值
e_t=κ·p_t^{κ−1}，
财富 E_t=∏_{i≤t}e_i。在 H0（无分布外/无未知故障）下 {E_t} 为非负超鞅，Ville 不等式给出
P(∃t:E_t≥1/α_ow)≤α_ow。
故 `flag_t=1[E_t≥1/α_ow]` 是一个 I 类错误受控的**随时有效告警器**。另一方面，为了"敢声称安全"，用尾事件 Z_t=1[s(x_t)>q_demo(1−β)] 估计新颖质量 π_novel=P[Z=1]，并用带并集界 α_t=6α/(π²t²) 的 Hoeffding/经验 Bernstein 给出随时有效上界 Û_t：
P(∃t:π_novel>Û_t)≤α_ow。
**职责分离**：E_t 决定"何时警觉"，Û_t 决定"证书上敢写多安全"；二者都不假装能发现具体故障类型。

**定义 241（反证演示组合与价值）** 对组合 P⊆D，定义
V(P)= 覆盖分层数（次模），
W(P)=log E_{|P|}（证据财富），
K(P)=Σ_{d∈P}κ_α(d)+λ_t T(d)。
组合价值 VoD(P)=V(P)+λ_w W(P)−λ_B K(P)。选
P*=argmax_{P⊆D, SafeInteract(P)} VoD(P)。
覆盖项用贪心（1−1/e），证据项非次模，用"贪心初始化 + 局部交换"；|P| 通常 ≤ 数十，可承受。

**定义 242（演示请求契约 DRC）** 当 `flag_t=1` 或归因熵高而物理探针不安全时，生成契约
q=(φ_req, claim, I_req, B_req, T_req)，
claim 为待检验断言（如"透明杯在 2N 下的接触斑位置"），I_req 为要求示范者维持的不变量，B_req 为愿意支付的可逆预算，T_req 为时限。可受理 ⇔
I_req⊆I_certified(机器人自身可认证包络) ∧ B_req≤B_t−B_min ∧ claim 对准真实缺口。
人响应 r∈{accept(d), counter(q'), refuse}。accept 后 d 交 DVL 验证；counter 需重新做可受理检查；refuse 则 safe_idle + 保守降级。**"安全交互"在此处的含义是：请求本身不得越界，机器人不要求人替它承担它自己不敢承担的风险。**

**定义 243（演示验证与来源账本 DVL）** DVL 是只追加 Merkle 账本，叶子为
h(d)=H(φ_d,π_d,I_d,h(w_d),h(R_d),σ_d)，
并记录 prereg_hash 与分层标签。有效 ⇔ 相对 prereg 无删除/重排/插入 ∧ σ_d 验签 ∧ 每条 Valid_demo。由于账本只追加，**事后挑选**（删掉失败演示）与**重放**（同一演示冒充新证据）可被检测；但预注册阶段就缺失的分层、或系统性地只演示容易场景，账本本身无法识别——它记录的是"你说要做什么、做了什么"，不是"你该做什么"。

**定义 244（可逆动作屏蔽 RAC）** 在 Shield/OCB 之后加可逆闸门：
π_σ^rev(s)=Π_{A_r(s)}(π_σ(s))。
若 A_r(s)=∅，输出 safe_stop，并触发 DRC 询问"这种情形该怎么退"。RAC 不是性能优化，而是**最后一道可逆闸门**：它宁可不动，也不进入没有撤销计划的动作。

**定义 245（可逆感知认证前缀 CSC-R）** 对块 A_t 与执行前缀 k：
k_rev=max{k:Σ_{i<k}c_worst(a_i)≤B_t−B_min}，
k*=min(k_csc(A_t,post,m,α_chunk), k_rev)。
要求 k*≥1；若 k*=0，则不发块，改走 safe_stop + DRC。单块越界预算合并为
α_block=α_chunk+α_rev+α_ow+δ_fi+α_vis。
**长预测、短执行（VISTA 定理 8）在这里被预算化**：短的不只是"不可逆视界 m"，而是"预算允许你反悔到哪儿"。

**定义 246（预算化主动归因 AFA-D）** 探针集 A={press,rub,tap,lift,visual_probe,null_test,ask_human}。选
a*=argmax_{a∈A} [ I(ℋ∪{U};ρ_{1:3}(a)|ρ_{1:2}) − λ_Bκ_α(a) − λ_tT(a) ]，
s.t. SafeInteract、f_n≤f_safe(φ̂,f̂_vis)、形变≤ε_strain。
`ask_human` 仅在 DRC 可受理且其期望信息增益/预算比优于所有物理探针时选用。**U 是汇假设**：当 E_t 报警而所有已知假设都不匹配时，把证据指向 U 并触发降级/问人，但**绝不输出"故障类型 = U"**，避免把未知强行命名。

**定义 247（J_prove 证书）**
J_prove=(J_vista, demo_ledger_root, Valid_demo_all, E_t, Û_t, α_ow, ε, B_t, B_min, k_rev, contract_hashes, prereg_hash, provenance_ver)。
验证规则：
Valid(J_prove) ⇔ Valid(J_vista)
∧ Valid_demo_all
∧ (flag_t ∨ Û_t≤ε)
∧ B_t≥B_min
∧ k*≥1 ∧ 块签名与执行前缀一致
∧ prereg_hash 与 DVL 根一致 ∧ provenance_ver 为当前版本
∧ 所有 ask_human 均有契约与响应记录。
审计链在 VISTA 的"为何膨胀这个球 / 为何只执行 k* 步 / 视觉是否可用"之外，新增三问：**凭什么信（demo_ledger + Û_t）、谁演示的（provenance）、还能不能退（B_t + R_d）**。

### IP-224/235 PCD 与演示有效性

```python
class ProofCarryingDemo:
    """正演示支持断言，负演示证伪断言；二者都必须可撤销、可验签。"""
    def __init__(self, phi, pi, invariant, witness, reversal, source):
        self.phi, self.pi, self.I = phi, pi, invariant
        self.w, self.R, self.sigma = witness, reversal, source
        self.polarity = +1 if invariant(witness) else -1   # 负演示不丢弃

    def valid(self, conformity_bound):
        if not self.phi.holds_at_start:
            return False
        if not witness_consistent(self.w, self.sigma, conformity_bound):
            return False
        for prefix in prefixes(self.pi):
            if not self.R.exists(prefix) or self.R.cvar(prefix) > R_MAX:
                return False
        return verify_signature(self.sigma)

    def evidence_for(self, claim):
        return (+1, self) if (self.polarity > 0 and claim == self.I) else \
               (-1, self) if (self.polarity < 0 and claim == self.I) else None
```

### IP-225/230 RIB + RAC（可逆性预算与屏蔽）

```python
class ReversibilityBudget:
    def __init__(self, B_init, B_min, alpha=0.05):
        self.B, self.B_min, self.alpha = B_init, B_min, alpha

    def admissible(self, s, a):
        return self.B - self.c_worst(s, a) >= self.B_min

    def commit(self, s, a):
        if not self.admissible(s, a):
            return False
        self.B -= self.c_worst(s, a)        # 承诺
        return True

    def undo(self, s, a):
        self.B = min(self.B_max, self.B + self.rho(s, a))   # 撤销回收
        return True

    def c_worst(self, s, a):
        return cvar(self.alpha, reversal_cost_samples(s, a))


def reversible_shield(policy, s, rib):
    candidates = [a for a in policy.support(s) if rib.admissible(s, a)]
    if not candidates:
        return SafeStop(), RequestDemoContract(context=s)   # 问人，不乱动
    return argmax(candidates, key=lambda a: policy.logprob(a))
```

### IP-226 OWM（开放世界监控）

```python
class OpenWorldMonitor:
    """E_t 负责警觉，Û_t 负责敢说多安全。"""
    def __init__(self, calib_scores, alpha_ow, eps, kappa=0.5):
        self.calib = np.sort(calib_scores)
        self.alpha_ow, self.eps, self.kappa = alpha_ow, eps, kappa
        self.E, self.t = 1.0, 0

    def conformal_p(self, score):
        n = len(self.calib)
        return (1 + np.sum(self.calib >= score)) / (n + 1)

    def update(self, score):
        self.t += 1
        p = self.conformal_p(score)
        self.E *= self.kappa * p ** (self.kappa - 1.0)   # e 值乘积
        flag = self.E >= 1.0 / self.alpha_ow              # Ville
        U_hat = self._anytime_ucb(self.t)                 # 新颖质量 UCB
        return {'flag': flag, 'wealth': self.E,
                'U_hat': U_hat, 'certifiable': (U_hat <= self.eps) and not flag}

    def _anytime_ucb(self, t):
        alpha_t = 6.0 * self.alpha_ow / (np.pi ** 2 * max(t, 1) ** 2)
        return hoeffding_upper(self.hits, t, alpha_t)     # 随时有效
```

### IP-227 DFP（反证演示组合）

```python
def select_portfolio(demos, strata, rib, lam=(1.0, 1.0, 1.0), budget=None):
    """覆盖贪心 + 证据局部交换；始终在 SafeInteract 下。"""
    P = greedy_cover(demos, strata)                      # 1 - 1/e
    improved = True
    while improved:
        improved = False
        for d_in in list(P):
            for d_out in demos:
                if d_out in P:
                    continue
                Q = (P - {d_in}) | {d_out}
                if rib.safe_for(Q) and vod(Q, lam) > vod(P, lam) + EPS:
                    P, improved = Q, True
                    break
            if improved:
                break
    return P
```

def certified_prefix_reversible(A, post, m, alpha_chunk, rib):

## 4. 推导

**引理 9（负演示可判定且不可替代）** Valid_demo 的定义只依赖前提可判定、见证与来源一致、撤销计划存在三件事；I_d(w_d) 的取值不参与有效性判定，只决定极性。于是负演示是有效证据。设断言空间 𝒞 被 φ 分层；一条负演示在 φ_d 上执行了不满足 I 的轨迹，则任何"∀x∈φ_d: I(x)"形式的断言被直接证伪。正演示只能增加支持度，不能排除反例；因此**在有限演示预算下，负演示对断言空间的收缩率不低于正演示**（对每个被证伪断言，正演示至多提高置信度，负演示直接删除该断言）。∎

**引理 10（随时有效的新颖质量上界）** 固定预注册标定集 D_cal，尾事件 Z_t=1[s(x_t)>q_demo(1−β)]。对任意 t，Hoeffding 不等式给出
P(π̂_t−π_novel≥√(log(1/α_t)/(2t)))≤α_t。
取 α_t=6α_ow/(π²t²)，由 Σ_t α_t=α_ow 与并集界，
P(∃t:π_novel>Û_t)≤α_ow。
故当 Û_t≤ε 时，以置信 1−α_ow 有 π_novel≤ε。注意：该界只对**固定的、预注册的**演示/标定分布成立；若演示方案随部署反馈被在线修改，标定集与检验集不再可交换，此界失效。∎

**引理 11（可逆预算充分性）** 设执行动作 a_0,…,a_{T−1} 均满足 a_t∈A_r(s_t) 且 Σ_t c_worst(a_t)≤B_0−B_min。对任意前缀 p，由预算递推 B_{|p|}=B_0−Σ_{t<|p|}c+Σρ≥B_min。对每条 a_t，由 r-可逆性存在撤销计划 R_t 使 CVaR_α[C(R_t)]≤r；CVaR 具有次可加性与单调性，故拼接撤销计划 R_{p}=R_{|p|−1}∘…∘R_0 满足
CVaR_α[C(R_p)]≤Σ_t CVaR_α[C(R_t)]≤Σ_t c_worst(a_t)≤B_0−B_min。
即从任意前缀都可退回起点、且尾部代价不超过预算；成功概率由每步撤销成功率与 α 控制。故交互不越过不可逆边界。∎

**引理 12（覆盖次模、证据非次模）** 覆盖价值 V(P)=|∪_{d∈P} strata(d)| 是覆盖函数的复合，标准次模；贪心达到 1−1/e。W(P)=log E_{|P|} 一般非次模，且 E_t 是乘性累积，故整体 VoD 不保证次模；算法用"覆盖贪心 + 局部交换"，其最优性退化为局部最优，但每一步都经 SafeInteract 过滤，安全性不受最优性影响。∎

**定理 9（PROVE 开放世界安全 / 虚假保证界）** 在
- A94（演示方案部署前预注册，分层内演示与部署可交换）、
- A95（撤销代价 CVaR 模型标定误差有界）、
- A96（见证与运行证据在 conformal 界内一致）、
- A97（人机契约被遵守，人示范满足 I_req）、
- A98（实时预算 ≤2.7ms，零学习写）
下，若 Valid(J_prove)，则：
1. 要么 flag_t=1，系统已进入安全降级/问人，不宣称安全；
2. 要么 Û_t≤ε，即部署新颖质量≤ε（置信 1−α_ow）；
3. 在情形 2 下，与 VISTA 定理 7 合并，"新颖质量>ε 的未知故障活跃而证书仍称安全"的概率
   P(false assurance)≤α_ow+α_vis+δ_fi+α_rev。
**意义**：A88 的"故障必须可枚举"被替换为"故障的新颖质量可被 ε 界定"。这不是消除有限假设集的缺陷，而是把它变成一个**可量化、可审计、可拒绝**的残余项；当证据不足以支撑 ε 时，证书合法地拒绝签发。∎

**定理 10（可逆交互的近安全）** 若所有动作经 RAC 投影、前缀经 CSC-R 截断，则由引理 11，交互满足 B_min-安全且每条前缀以≥1−α_rev 可撤销；由 CSC 的 α_chunk、OWM 的 α_ow、VISTA 的 δ_fi/α_vis，单块风险
P[越界或不可撤销]≤α_chunk+α_rev+α_ow+δ_fi+α_vis。
VISTA 定理 8 的 m 是本定理在 κ∈{0,∞} 时的退化：此时 k_rev=m。故"长预测、短执行"升级为"**长预测、可逆执行**"：短的不只是不可逆视界，而是预算允许反悔的范围。∎

**命题（相对 VISTA 的保守性下降）** VISTA 在归因模糊时对所有球联合膨胀。PROVE 先看 Û_t：若 Û_t≤ε（新颖不显著），保持 VISTA 的紧球；仅在 flag_t 或 Û_t>ε 时才降级/问人。设部署中"模糊但新颖不显著"的比例为 q，则 PROVE 的联合膨胀次数相对 VISTA 下降约 q，且不增加假阴性——因为下降发生在证据支持"无未知故障"的分层内。反之当演示方案带偏时，该命题不成立（见风险）。∎

## 7. 已知风险

**一句话**：PROVE 的全部开放世界保证都建立在 A94——"演示方案部署前预注册、且部署与演示在分层内可交换"——之上；但**演示是人挑选的**，预注册只能防事后篡改，防不了**事先就带偏的方案**（只演示容易的、避开易损与透明场景），此时 `Û_t≤ε` 会成为一张"用偏样本买来的安全证明"，系统因"演示通过、财富没报警"而获得**虚假保证**，比 VISTA 的"错误归因"更危险，因为它把不确定性包装成了可审计的确定性。

**次级风险与缓解**：

1. **预注册偏差（头号，无法根治）**：分层本身由人设计，可能漏掉真实部署分层。缓解：把 Strata 的完备性当作独立审计项；报告"未覆盖分层"而非只报覆盖率；对 Û_t 做敏感性分析（ε-曲线）；显式拒绝在覆盖不足时签发证书。
2. **可交换性被在线更新破坏**：为补覆盖而在线加演示，会污染标定集。缓解：固定标定集 + 新演示进"证据集"但不进"标定集"，或用 learn-then-test 的分裂；任何标定集变更都使旧证书失效并要求重签。
3. **撤销代价模型本身错误**：κ_α 由仿真/标定估计，真实撤销可能更难（粘附、塑性、重力）。缓解：κ 用上置信界而非点估计；RAC 对 κ 的不确定做最坏化；κ 超界即视为不可逆。
4. **"问人"引入新的不安全**：人可能做出危险示范、或拒绝导致任务失败。缓解：I_req⊆I_certified、B_req 受限、示范先验证后使用、拒绝即 safe_idle；契约不含"必须完成"的强制项。
5. **负演示被滥用**：把噪声/传感器故障误记为负演示，会错误删除有效断言。缓解：负演示也必须通过见证一致性与来源验签；对同一断言要求多条独立负演示才删除。
6. **E_t/Û_t 的统计假设脆弱**：非平稳部署使 conformal/UCB 名义覆盖失真。缓解：滑动窗标定 + 漂移检测 + 分段重签；漂移时主动把 Û_t 抬到 1（拒绝签发）。
7. **Merkle 账本只保证"记录未被改"，不保证"记录该有都有"**：缺失层与遗漏演示无法被账本发现。缓解：与外部审计/第三方演示集交叉；把"应演示清单"也纳入 prereg。
8. **实时预算**：新颖度嵌入 + RAC + 预算 逼近 2.7ms；缓解：嵌入降维/查表、RAC 早筛、把 OWM 的 UCB 更新按块而非按步、世界模型全留语义流。

**与第 65 轮的边界**：VISTA 回答"在 ℋ 内谁坏了、膨胀哪个球、执行到哪一步"；PROVE 不改进 ℋ 内的归因，而是回答"当 ℋ 不够时，我们凭什么还敢说自己安全、这个说法能不能被外人复查、能不能随时撤回"。**前者是归因学，后者是证据学与可逆性经济学。**
