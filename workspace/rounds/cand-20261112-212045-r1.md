# 第 62 轮（承接第 61 轮「具身语义进化闭环」IP-173~182；灵感循环第 8 轮；本轮灵感：「视觉编码器」×「多模态融合」）

> 第 61 轮构建了 ESEC：USR 统一语义表征、MEL 多模态具身大模型、DMS 多轮对话、SRT-Dual 语义-实时双流、PCE+++++ 六维预算。但**四个感知层局限**仍待突破：
> 1. **视觉编码器是「互联网视觉」而非「具身视觉」**：MEL 的 Enc_v 是冻结 ViT-L/14 + LoRA，编码的是外观与语义类别，而非接触几何、表面法向、可变形性、摩擦相关纹理。对操作任务，真正决定阻抗先验的是**几何-物理线索**，冻结 ViT 对这些线索缺乏 3D/接触/时序归纳偏置。
> 2. **多模态融合是「静态拼接 + 单次注意力」**：CrossAttention([v,t,p,l]) 隐含假设模态同步、同可靠性、无缺失。真实系统中视觉 ~30Hz、触觉/本体 ~1kHz、语言事件驱动，且各模态可靠性随遮挡、光照、接触阶段剧烈变化——静态融合会把不可靠模态的噪声平权注入，甚至被单一模态主导。
> 3. **视觉是被动的、全分辨率的**：固定分辨率、全图 token，既浪费实时预算，又不会主动寻找任务相关信息（遮挡时不会换视角、加光源）。感知与决策解耦，缺乏「看哪里」的主动闭环。
> 4. **跨模态幻觉缺乏特征级守卫**：VLM 可能「自信地看错」（把空杯说成满杯、把反光当液体），而第 61 轮只在 USR 语义层做事后对账（XMC+++），缺少**特征级、物理级的在线一致性校验与冲突证据**。

## 0. 直觉与动机

**灵感 1（视觉编码器 → 接触感知几何编码器 CAVE）**
直觉：MEL 的视觉编码器把一张图压成一个「语义类」向量，但机械臂需要的不是「这是杯子」，而是「杯口边缘在哪里、表面法向朝哪、这块区域会不会滑、能不能捏」。构建 **接触感知视觉编码器（CAVE, Contact-Aware Vision Encoder）**：在冻结 ViT 的每一层用深度/法向做 FiLM 调制，注入几何归纳偏置；增加短时运动 token 捕捉位移与形变；增加多尺度 ROI token（接触候选区用更细 patch）；用触觉接触标签监督一个接触热图头。关键洞见：**视觉编码器的输出不再只是 scene_emb，而是「几何 token 集 + 接触先验 C_hat + 纹理可供性嵌入 e_tex」**，直接为阻抗先验提供物理约束。

**灵感 2（视觉编码器 × 多模态融合 → 视觉-触觉对比对齐 VTCA）**
直觉：视觉看到的「接触区外观」与触觉感到的「接触动力学」本应是同一物理事件的两个投影。用对比学习把 CAVE 的接触区嵌入 e_v^c 与触觉编码 e_t 拉到同一子空间：同一材质/接触对为正样本，不同接触阶段为负样本。关键洞见：**VTCA 是视觉编码器与融合器的「接口协议」**——只有视觉嵌入与触觉嵌入可比，后续融合才有物理意义；它也是零样本摩擦/刚度推断的跨模态监督来源。

**灵感 3（多模态融合 → 可靠性路由融合 RRF）**
直觉：融合的核心不是「怎么拼」，而是「信谁、信多少」。构建 **可靠性路由融合（RRF, Reliability-Routed Fusion）**：对每个模态估计可靠性 ρ_m = σ(wᵀ[conf_m, freshness_m, ood_m, snr_m])；用时间戳差 Δτ_m 做异步对齐与延迟补偿；用门控 g_m = softmax_m(log ρ_m − λ_τ Δτ_m) 抑制不可靠/过期模态；在 token 级用 MoME 路由选择 top-k 模态专家；训练时做模态 dropout，推理时缺失模态映射到可学习的 null embedding。关键洞见：**融合权重是「可靠性 × 新鲜度」的函数，而非固定学习到的常数**——这让系统在遮挡/断触觉/语言缺失时优雅退化。

**灵感 4（多模态融合 → 模态冲突与缺失处理 MCH）**
直觉：模态冲突（视觉说「硬的」，触觉说「软的」）不应被平均，平均会造出一个「谁也不像」的幻觉特征。构建 **模态冲突处理（MCH, Modality Conflict Handling）**：计算模态对分歧度 D_conf，超过阈值时产生显式 conflict token，降低相关模态可靠性，并把冲突证据写入 USR 证据缓冲，触发三种消解动作之一——主动复看（AFP）、对话澄清（DMS）、保守扩展（EEIS）。关键洞见：**冲突是信息而非噪声**：它是最有价值的「该重新感知了」信号。

**灵感 5（视觉编码器 × 多模态融合 → 主动注视 + 语义令牌剪枝 + 七维预算）**
直觉：既然融合能判断「谁不可靠」，视觉就不该被动全分辨率。用 **主动注视感知（AFP）** 以「对 USR 物理属性的期望信息增益」为奖励选择下一视角/变焦/ROI；用 **语义引导令牌剪枝（STP）** 依据 intent_emb、接触先验、新颖度保留 top-k token 并合并冗余 token；把视觉/融合开销纳入 **七维认知-感知预算 B_cog7 = (B_scene, B_intent, B_ros, B_exec, B_mel, B_usr, B_perc)**，其中 B_perc = (B_vis_tokens, B_fuse_routes, B_gaze, B_conf_resolve)。关键洞见：**感知不是免费的**——主动看、融合路由、冲突消解都要花预算，预算耗尽时按「关主动→冻结注视→激进剪枝→退化为静态可靠性加权融合」降级，但安全永不降级。

## 1. 形式化定义（增量：定义 173–184）

**定义 173（接触感知视觉编码器 CAVE）** CAVE = (Enc_rgb, Enc_geo, Enc_motion, Fuse_tok, Head_contact, Head_tex)。其中：
- **输入**：RGB 图像 V ∈ ℝ^{H×W×3}、深度 D ∈ ℝ^{H×W}、表面法向 N ∈ ℝ^{H×W×3}、短时帧栈 V_{t-k:t}
- **几何编码器**：Enc_geo: (D, N) → Z_geo ∈ ℝ^{N_g×d_g}，以 FiLM 注入 ViT 各层：h_l ← (1+γ_l(Z_geo))·LN(h_l) + β_l(Z_geo)
- **运动编码器**：Enc_motion: V_{t-k:t} → Z_mot ∈ ℝ^{N_m×d}，由帧差/光流/轨迹 token 构成
- **多尺度令牌**：全局 patch-14 token Z_glob；接触候选 ROI 用 patch-7 细粒度 token Z_roi
- **令牌融合**：Z_v = Fuse_tok(Z_glob, Z_geo, Z_mot, Z_roi) ∈ ℝ^{N_v×d_v}
- **接触热图头**：Head_contact: Z_v → Ĉ ∈ [0,1]^{⌈H/14⌉×⌈W/14⌉}，以触觉接触标签监督
- **纹理可供性头**：Head_tex: Z_v → e_tex ∈ ℝ^{d_tac}，与触觉嵌入同维，供 VTCA 对齐
- **输出**：视觉证据包 E_vis = (Z_v, Ĉ, e_tex, N_roi)，其中 N_roi 为接触区几何法向

**定义 174（视觉-触觉对比对齐 VTCA）** 令接触区视觉嵌入 e_v^c = Pool_{Ĉ>τ_c}(Z_v)，触觉嵌入 e_t = Enc_t(T)。对齐损失：
```
ℒ_vt = -log( exp(sim(e_v^c, e_t^+) / τ_t) / Σ_j exp(sim(e_v^c, e_t^j) / τ_t) )
     + λ_phys · ‖φ_phys^v - φ_phys^t‖²_Σ
```
- 正样本：同一接触事件（同材质、同接触阶段）的视觉-触觉对
- 负样本：不同接触阶段 / 不同材质
- **物理一致性项**：视觉与触觉各自推断的 φ_phys 应一致，作为跨模态物理监督
- **对齐质量**：δ_vt = E[1 - sim(e_v^c, e_t^+)]，要求接触区 δ_vt ≤ 0.15

**定义 175（可靠性路由融合 RRF）** RRF = (Est_rel, Align_t, Gate, Router, NullEmb)。给定各模态 token 集 Z_m（m ∈ {v,t,p,l}）、时间戳 τ_m、原始置信度 conf_m：
- **可靠性估计**：ρ_m = σ(wᵀ[conf_m, freshness_m, ood_m, snr_m])，freshness_m = exp(-(t−τ_m)/τ_m^max)
- **异步对齐**：Δτ_m = |τ_m − τ_ref|；用轻量时间规整 T_warp 对齐到参考时刻
- **门控**：g_m = softmax_m( log ρ_m − λ_τ·Δτ_m )，且 Σ_m g_m = 1
- **门控交叉注意力**：Z_fused = Σ_m g_m · Attn(Q, K_m, V_m)
- **Token 级路由（MoME）**：每个融合 token 经 router 选 top-k 模态专家，缓解「单模态主导全局」
- **缺失模态**：g_m → 0，并以可学习 null embedding e_∅^m 占位；训练时以概率 p_m 随机 dropout 模态
- **退化保证**：若所有 ρ_m 低于 ρ_min，返回 conflict token 并触发 MCH，而非强行融合

**定义 176（模态冲突与缺失处理 MCH）** MCH = (D_conf, z_conf, Resolve)。其中：
- **分歧度**：D_conf(m,m') = 1 − cos(Proj_m(Z_m), Proj_m'(Z_m'))，在共享子空间计算
- **冲突 token**：若 max_{m,m'} D_conf > τ_conf，产生 z_conf ∈ ℝ^{d_fused}（不参与平均，单独送入 MEL 融合器）
- **冲突证据**：E_conf = (m, m', D_conf, τ, Ĉ, ρ) 写入 USR.evidence_buffer，供 XMC+++ 与审计使用
- **消解动作**（按优先级）：① 主动复看（AFP 重观测）→ ② 对话澄清（DMS.ask_clarify）→ ③ 保守扩展（EEIS 向安全区收缩）→ ④ 等待（wait）
- **缺失语义**：缺失 ≠ 冲突；缺失时使用 null embedding 并降低该模态先验权重，不产生冲突证据

**定义 177（主动注视感知 AFP）** AFP = (B, A_gaze, O, T, R_ig)。其中：
- **信念**：b = (scene_emb, φ_phys, Σ_phys, U_ep)，其中 Σ_phys 为物理属性后验协方差
- **注视动作**：a = (pan, tilt, zoom, ROI, illumination, wrist_cam_pose)
- **期望信息增益**：IG(a) ≈ ½ log det(I + Σ_phys^{−1} J_aᵀ Σ_o^{−1} J_a)，J_a 为观测雅可比，Σ_o 为观测噪声
- **奖励**：R_ig(a) = IG(a) − λ_t·t(a) − λ_e·energy(a) − λ_r·risk(a)
- **下一最佳视角**：a* = argmax_{a∈A_safe} R_ig(a)，A_safe 由 ERTC 约束（相机运动不得引发超限力/速度）
- **令牌分配**：N_v(a) ∝ 信息密度，且 Σ_a N_v(a) ≤ B_vis_tokens

**定义 178（语义引导令牌剪枝 STP）** 令任务查询 q = W_q·intent_emb。token 重要性：
```
s_i = λ_1⟨q, k_i⟩ + λ_2·Ĉ_i + λ_3·novelty_i + λ_4·U_ep·uncertainty_i
```
- **保留集**：S = top-k(s_i)，k = clip(round(B_vis_tokens / d_v), k_min, N_v)
- **合并**：被丢弃 token 经二分软匹配合并进保留 token（token merging）
- **重构误差界**：‖Z_v − Z_v^pruned‖_F ≤ ε_tok(B_vis_tokens)，随预算单调下降
- **安全例外**：Ĉ_i > τ_c 的接触区 token 永不剪枝（硬保护）

**定义 179（跨模态一致性守卫 CMG）** CMG = (D_phys, D_feat, H_score, Guard)。其中：
- **物理分歧**：D_phys = ‖φ_phys^v − φ_phys^t‖_Σ + ‖φ_phys^v − φ_phys^p‖_Σ
- **特征分歧**：D_feat = 1 − cos(P_s f_v, P_s f_t)，P_s 为共享子空间投影
- **幻觉分数**：H_score = σ(α·D_phys + β·D_feat + γ·U_ep − δ·contact_evidence)
- **守卫规则**：若 H_score > τ_h，将视觉证据标记为 `unverified`；`unverified` 的视觉 φ_phys 不得直接设 K_p，只能作为 EEIS 的「软先验」并经保守收缩
- **触发**：H_score > τ_h ⇒ 优先 AFP 重观测；若连续 2 次仍高 ⇒ DMS 澄清

**定义 180（七维认知-感知预算 B_cog7 与 PCE++++++）** B_cog7 = (B_scene, B_intent, B_ros, B_exec, B_mel, B_usr, B_perc)。其中：
- **B_perc** = (B_vis_tokens, B_fuse_routes, B_gaze, B_conf_resolve)
- **感知成本**：
```
cost_perc = λ_vis·(tokens_used / B_vis_tokens)
          + λ_fuse·(routes_used / B_fuse_routes)
          + λ_gaze·(gaze_count / B_gaze)
          + λ_conf·(conflicts_resolved / B_conf_resolve)
```
- **VOI 扩展**：voi_cog7 = VOI_meta − cost_mel − cost_usr − cost_perc − cost_exec
- **降级链（安全不降级）**：
  1. B_gaze 耗尽 ⇒ 关闭 AFP，固定注视，沿用上一 ROI
  2. B_vis_tokens 耗尽 ⇒ STP 激进剪枝（k → k_min），但接触区硬保护
  3. B_fuse_routes 耗尽 ⇒ 关闭 MoME token 级路由，退化为静态可靠性加权融合
  4. B_conf_resolve 耗尽 ⇒ 冲突时直接保守扩展（不再主动复看/对话），并标记 `degraded_perception`

**定义 181（视觉-物理先验融合 VPF）** 将 CAVE/RRF/CMG 的输出融合进第 61 轮 MSPF：
```
φ_phys^fused = Σ_m w_m φ_phys^m,  w_m = ρ_m / (U_m + ε),  m ∈ {v,t,p}
约束（几何感知）：
  K_p ∈ [k_min(Ĉ, N_roi), k_max(Ĉ, N_roi)]
  K_d ∈ [η_min(φ_phys^fused), η_max(φ_phys^fused)]
  F_max ≤ μ_fric^fused · N_normal · safety_margin
若 H_score > τ_h：w_v ← w_v · 0.3（视觉降权），并向区间内侧收缩 20%
K_safe^vpf = EEIS.compile_with_mel_prior(δ_f, φ_phys^fused, U_ep, U_al)
```

**定义 182（感知-融合联合证书 PFC）** 扩展第 61 轮 J_sem_exec：
```
PFC = (J_sem_exec,
       D_conf_max,             # 本周期最大模态分歧
       H_score,                # 幻觉分数
       tokens_used,            # 视觉 token 用量 / 预算
       gaze_trace_hash,        # 注视轨迹哈希（可审计）
       fusion_route_hash,      # 融合路由哈希
       ρ = (ρ_v, ρ_t, ρ_p, ρ_l))
验证规则：
Valid(PFC) ⇔ Valid(J_sem_exec)
            ∧ D_conf_max ≤ τ_conf
            ∧ H_score ≤ τ_h
            ∧ tokens_used ≤ B_vis_tokens
            ∧ anchor_fresh
```

**定义 183（感知-视觉-融合闭环 PVF-ESEC）** 升级第 61 轮 ESEC，将感知前端纳入闭环：
```
PVF-ESEC(M, obs, L, δ_f_req):
  # —— 感知流（异步，~10-30Hz）——
  b ← (M.scene_emb, M.phys_prior, M.Σ_phys, M.U_ep)
  if budget.can_gaze():  a_gaze ← AFP.next_best_view(b)
  V, D, N, T ← active_capture(a_gaze)
  E_vis ← CAVE.encode(V, D, N, T)                    # Z_v, Ĉ, e_tex
  Z_v ← STP.prune(E_vis.Z_v, intent_emb=M.intent_emb, Ĉ, B_vis_tokens)
  Z_fused, ρ ← RRF.fuse({Z_v, Z_t, Z_p, Z_l}, {τ_m})
  D_conf, z_conf ← MCH.detect(Z_v, Z_t, Z_p)
  φ_phys^v ← MEL.dec_phys(Z_fused)
  H_score ← CMG.guard(φ_phys^v, φ_phys^t, φ_phys^p, U_ep, contact_evidence)
  if H_score > τ_h or D_conf > τ_conf:
      a_diag ← MCH.resolve(D_conf, H_score)           # 复看 / 澄清 / 保守
  φ_phys^fused ← VPF.fuse(φ_phys^v, φ_phys^t, φ_phys^p, ρ, H_score)
  M.phys_prior ← φ_phys^fused
  M.anchor ← USR.commit(M.scene_emb, M.intent_emb, φ_phys^fused, M.U_ep)

  # —— 实时流（同步，~1-10kHz）——
  anchor ← USR.read_latest()
  K_safe ← EEIS.compile_with_mel_prior(δ_f, φ_phys^fused, U_ep, U_al)  # 含 VPF 约束
  dispatch(K_safe)
  EV_exec ← wait_contact()
  M.evidence_emb ← E_evidence(EV_exec)
  USR.evidence_buffer.push((M.evidence_emb, E_conf))
  M.PFC ← build_pfc(EV_exec, D_conf, H_score, tokens_used, gaze_trace, route_hash, ρ)
  return M, K_safe, EV_exec, M.PFC
```

**定义 184（PVF-Complete 正确性定理）** 假设 A61–A70 及：
**(A71)** CAVE：几何 FiLM 注入满足 Lipschitz 连续，接触热图头校准良好（ECE ≤ 0.05）。
**(A72)** VTCA：接触区视觉-触觉对齐 gap δ_vt ≤ 0.15。
**(A73)** RRF：可靠性估计器校准（ECE ≤ 0.05），且对可靠模态的门控 g_m 有下界 g_min > 0。
**(A74)** AFP：信息增益估计有界且近似无偏，A_safe 由 ERTC 硬约束。
**(A75)** STP：剪枝重构误差 ≤ ε_tok(B_vis_tokens)，接触区 token 硬保护。
**(A76)** CMG：幻觉检测 FPR ≤ α、FNR ≤ β。

则：
1. **感知-控制安全一致性**：若 Valid(PFC)，则 K_safe 的物理约束来自 `verified` 的 φ_phys^fused；`unverified` 视觉证据至多贡献 0.3 权重且经保守收缩。
2. **缺失模态鲁棒性**：任一模态缺失时，融合性能退化 ≤ f(ρ_m)，且不产生伪冲突。
3. **主动感知效率**：在信息增益估计无偏下，AFP 的单位成本期望信息增益不低于固定注视策略。
4. **实时性**：STP 将视觉 token 数从 N_v 降至 k，语义流延迟随 k 线性下降；B_vis_tokens 耗尽时硬保护接触区，安全不降级。
5. **幻觉抑制**：在 A76 下，未经验证的视觉物理属性直接设 K_p 的概率 ≤ β，且被 PFC 验证规则拒绝。

### IP-183 CAVE（接触感知视觉编码器）

```python
class ContactAwareVisionEncoder:
    def __init__(self, d_v=768, d_g=256, n_roi=64, patch=14):
        self.vit = FrozenViT(patch=patch, lora=True)      # 冻结骨干 + LoRA
        self.enc_geo = GeometryEncoder(d_g)                # (D, N) -> Z_geo
        self.enc_motion = MotionEncoder(d_v)               # 帧差/光流
        self.film = [FiLM(d_g, d_v) for _ in range(self.vit.depth)]
        self.head_contact = ContactHead(d_v, out=1)
        self.head_tex = TextureAffordanceHead(d_v, d_tac=256)
        self.roi_pool = ROIPooler(patch=7)

    def encode(self, V, D, N, frames):
        Z_geo = self.enc_geo(D, N)                         # [N_g, d_g]
        Z_mot = self.enc_motion(frames)                    # [N_m, d_v]
        h = self.vit.patch_embed(V)                        # 全局 patch-14
        for l, blk in enumerate(self.vit.blocks):
            h = self.film[l](h, Z_geo)                     # FiLM 注入几何
            h = blk(h)
        Z_glob = self.vit.norm(h)
        C_hat = self.head_contact(Z_glob)                  # 接触热图
        roi = self._contact_rois(C_hat, topk=self.n_roi)
        Z_roi = self.roi_pool(V, roi, patch=7)             # 细粒度接触区 token
        Z_v = self.fuse_tokens(Z_glob, Z_geo, Z_mot, Z_roi)
        e_tex = self.head_tex(Z_v)
        return VisualEvidence(Z_v, C_hat, e_tex, N_roi=N[roi])
```

### IP-184 RRF（可靠性路由融合）

```python
class ReliabilityRoutedFusion:
    def __init__(self, d=512, n_mod=4, topk=2, p_drop=0.1, tau_max=0.2):
        self.rel_head = ReliabilityHead(n_mod)             # -> rho
        self.gate = nn.Linear(n_mod * 3, n_mod)
        self.cross_attn = nn.MultiheadAttention(d, 8)
        self.router = MoMERouter(d, n_experts=n_mod, topk=topk)
        self.null_emb = nn.Parameter(torch.zeros(n_mod, d))
        self.tau_max = tau_max
        self.p_drop = p_drop

    def fuse(self, token_sets, timestamps, t_ref):
        # token_sets: {m: [N_m, d]}, timestamps: {m: float}
        feats, rho = [], {}
        for m, Z in token_sets.items():
            dt = abs(timestamps[m] - t_ref)
            fresh = math.exp(-dt / self.tau_max)
            conf = self._confidence(Z)
            ood = self._ood_score(Z)
            snr = self._snr(Z)
            rho[m] = torch.sigmoid(self.rel_head(
                torch.tensor([conf, fresh, ood, snr])))
            feats.append(self._time_warp(Z, dt))
        # 训练期模态 dropout；推理期缺失模态用 null embedding
        present = [m for m in token_sets if not self._missing(m)]
        if not present:
            return self._conflict_token(), rho
        r = torch.stack([rho[m] for m in present])
        gate = torch.softmax(torch.log(r + 1e-6)
                             - 0.5 * torch.tensor(
                                 [abs(timestamps[m] - t_ref) for m in present]), 0)
        Q = feats[0]
        fused = torch.zeros_like(Q)
        for g, m, Z in zip(gate, present, feats):
            fused += g * self.cross_attn(Q, Z, Z)[0]
        fused = self.router(fused)                         # token 级模态专家
        return fused, rho
```

### IP-185 MCH（模态冲突与缺失处理）

```python
class ModalityConflictHandler:
    def __init__(self, tau_conf=0.35, tau_c=0.5):
        self.tau_conf = tau_conf
        self.tau_c = tau_c
        self.proj = {m: nn.Linear(d_m, 256) for m in ['v','t','p']}

    def detect(self, Z_v, Z_t, Z_p):
        z = {'v': self.proj['v'](Z_v.mean(0)),
             't': self.proj['t'](Z_t.mean(0)),
             'p': self.proj['p'](Z_p.mean(0))}
        D_conf, worst = 0.0, None
        for a, b in [('v','t'), ('v','p'), ('t','p')]:
            d = 1 - F.cosine_similarity(z[a], z[b], dim=0)
            if d > D_conf:
                D_conf, worst = d, (a, b)
        z_conf = self._conflict_token(z, worst) if D_conf > self.tau_conf else None
        return D_conf, z_conf

    def resolve(self, D_conf, H_score, ertc_safe=True):
        if H_score > 0.7 or D_conf > self.tau_conf:
            return DialogueAction('ask_clarify',
                question='视觉与触觉证据冲突，是否重新观察/切换保守模式？')
        return DialogueAction('wait')
```

### IP-187 STP（语义引导令牌剪枝）

```python
class SemanticTokenPruner:
    def __init__(self, k_min=16, tau_contact=0.5):
        self.k_min = k_min
        self.tau_contact = tau_contact

    def prune(self, Z_v, intent_emb, C_hat, B_vis_tokens):
        N = Z_v.shape[0]
        k = max(self.k_min, min(N, int(B_vis_tokens / Z_v.shape[1])))
        q = self.W_q(intent_emb)
        attn = (Z_v @ q) / math.sqrt(Z_v.shape[1])
        novelty = 1 - F.cosine_similarity(
            Z_v, Z_v.mean(0, keepdim=True), dim=-1)
        s = 0.5 * attn + 0.3 * C_hat.flatten()[:N] \
            + 0.1 * novelty + 0.1 * self.U_ep
        # 接触区硬保护：无论分数多低都保留
        protected = (C_hat.flatten()[:N] > self.tau_contact)
        keep = torch.topk(s, k).indices
        keep = torch.unique(torch.cat([keep, protected.nonzero().flatten()]))
        drop = torch.tensor([i for i in range(N) if i not in keep])
        Z_pruned = self.token_merge(Z_v, keep, drop)       # 二分软匹配合并
        return Z_pruned
```

### IP-188 CMG（跨模态一致性守卫）

```python
class CrossModalGuard:
    def __init__(self, tau_h=0.6, alpha=0.4, beta=0.3, gamma=0.2, delta=0.3):
        self.tau_h = tau_h
        self.a, self.b, self.g, self.d = alpha, beta, gamma, delta

    def guard(self, phi_v, phi_t, phi_p, U_ep, contact_evidence):
        D_phys = self._mahalanobis(phi_v, phi_t) + \
                 self._mahalanobis(phi_v, phi_p)
        D_feat = 1 - F.cosine_similarity(self.P_s(phi_v),
                                         self.P_s(phi_t), dim=0)
        H = torch.sigmoid(self.a * D_phys + self.b * D_feat
                          + self.g * U_ep - self.d * contact_evidence)
        verified = H <= self.tau_h
        return H.item(), verified
```

```python
            self.perc_degraded = True

        self.fuse_used += n
        if self.fuse_used >= self.B_fuse_routes:
            self.perc_degraded = True

    def spend_conf(self):

        if self.conf_used >= self.B_conf_resolve:
            self.perc_degraded = True

                + 0.2 * self.fuse_used / self.B_fuse_routes
                + 0.2 * self.gaze_used / self.B_gaze
                + 0.3 * self.conf_used / self.B_conf_resolve)

        return (self.voi_meta_pessimistic(action)
                - self.cost_mel(action) - self.cost_usr(action)
                - self.cost_perc() - self.cost_exec(action))
```

```python
    def encode(self, V, D, N, frames):
        Z_geo = self.enc_geo(D, N)
        Z_mot = self.enc_motion(frames)
        h = self.vit.patch_embed(V)
        for l, blk in enumerate(self.vit.blocks):
            h = self.film[l](h, Z_geo)      # FiLM 注入几何归纳偏置
            h = blk(h)
        Z_glob = self.vit.norm(h)
        C_hat = self.head_contact(Z_glob)
        roi = self._contact_rois(C_hat, topk=self.n_roi)
        Z_roi = self.roi_pool(V, roi, patch=7)
        Z_v = self.fuse_tokens(Z_glob, Z_geo, Z_mot, Z_roi)
        e_tex = self.head_tex(Z_v)
        return VisualEvidence(Z_v, C_hat, e_tex, N_roi=N[roi])
```

### IP-184 VTCA（视觉-触觉对比对齐）

```python
def vtca_loss(e_v_contact, e_t_pos, e_t_negs, phi_v, phi_t, tau=0.07, lam=0.5):
    pos = F.cosine_similarity(e_v_contact, e_t_pos, dim=-1) / tau
    neg = torch.stack([F.cosine_similarity(e_v_contact, e, dim=-1) / tau
                       for e in e_t_negs])
    l_align = -torch.log(torch.exp(pos) /
                         (torch.exp(pos) + torch.exp(neg).sum(0)))
    l_phys = F.mse_loss(phi_v, phi_t)
    return l_align.mean() + lam * l_phys
```

### IP-185 RRF（可靠性路由融合）

```python
class ReliabilityRoutedFusion:
    def __init__(self, d=512, n_mod=4, topk=2, tau_max=0.2):
        self.rel_head = ReliabilityHead(n_mod)
        self.cross_attn = nn.MultiheadAttention(d, 8)
        self.router = MoMERouter(d, n_experts=n_mod, topk=topk)
        self.null_emb = nn.Parameter(torch.zeros(n_mod, d))
        self.tau_max = tau_max

    def fuse(self, token_sets, timestamps, t_ref):
        feats, rho = [], {}
        for m, Z in token_sets.items():
            dt = abs(timestamps[m] - t_ref)
            fresh = math.exp(-dt / self.tau_max)
            rho[m] = torch.sigmoid(self.rel_head(torch.tensor([
                self._confidence(Z), fresh,
                self._ood_score(Z), self._snr(Z)])))
            feats.append(self._time_warp(Z, dt))
        present = [m for m in token_sets if not self._missing(m)]
        if not present:
            return self._conflict_token(), rho
        r = torch.stack([rho[m] for m in present])
        gate = torch.softmax(torch.log(r + 1e-6)
                             - 0.5 * torch.tensor(
                                 [abs(timestamps[m] - t_ref) for m in present]), 0)
        Q = feats[0]
        fused = torch.zeros_like(Q)
        for g, Z in zip(gate, feats):
            fused += g * self.cross_attn(Q, Z, Z)[0]
        return self.router(fused), rho
```

### IP-186 MCH（模态冲突与缺失处理）

```python
class ModalityConflictHandler:
    def __init__(self, tau_conf=0.35):
        self.tau_conf = tau_conf
        self.proj = {m: nn.Linear(d_m, 256) for m in ['v', 't', 'p']}

    def detect(self, Z_v, Z_t, Z_p):
        z = {'v': self.proj['v'](Z_v.mean(0)),
             't': self.proj['t'](Z_t.mean(0)),
             'p': self.proj['p'](Z_p.mean(0))}
        D_conf, worst = 0.0, None
        for a, b in [('v','t'), ('v','p'), ('t','p')]:
            d = 1 - F.cosine_similarity(z[a], z[b], dim=0)
            if d > D_conf:
                D_conf, worst = d, (a, b)
        z_conf = self._conflict_token(z, worst) if D_conf > self.tau_conf else None
        return D_conf, z_conf

    def resolve(self, D_conf, H_score):
        if H_score > 0.7 or D_conf > self.tau_conf:
            return DialogueAction('ask_clarify',
                question='视觉与触觉证据冲突，是否重新观察/切换保守模式？')
        return DialogueAction('wait')
```

```python
class ActiveFoveatedPerception:

        self.ertc = ertc

    def next_best_view(self, belief):

        for a in self.action_space:

                torch.eye(len(belief.phi)) +
                belief.Sigma_inv @ J.T @ self.Sigma_o_inv(a) @ J)

            if r > best_r:

        return best
```

### IP-188 STP（语义引导令牌剪枝）

```python
class SemanticTokenPruner:
    def __init__(self, k_min=16, tau_contact=0.5):
        self.k_min = k_min
        self.tau_contact = tau_contact

    def prune(self, Z_v, intent_emb, C_hat, B_vis_tokens):
        N = Z_v.shape[0]
        k = max(self.k_min, min(N, int(B_vis_tokens / Z_v.shape[1])))
        q = self.W_q(intent_emb)
        attn = (Z_v @ q) / math.sqrt(Z_v.shape[1])
        novelty = 1 - F.cosine_similarity(
            Z_v, Z_v.mean(0, keepdim=True), dim=-1)
        s = 0.5 * attn + 0.3 * C_hat.flatten()[:N] \
            + 0.1 * novelty + 0.1 * self.U_ep
        protected = (C_hat.flatten()[:N] > self.tau_contact)
        keep = torch.topk(s, k).indices
        keep = torch.unique(torch.cat([keep, protected.nonzero().flatten()]))
        drop = torch.tensor([i for i in range(N) if i not in keep])
        return self.token_merge(Z_v, keep, drop)   # 接触区硬保护，零剪枝
```

### IP-189 CMG（跨模态一致性守卫）

```python
class CrossModalGuard:
    def __init__(self, tau_h=0.6, alpha=0.4, beta=0.3, gamma=0.2, delta=0.3):
        self.tau_h, self.a, self.b, self.g, self.d = \
            tau_h, alpha, beta, gamma, delta

    def guard(self, phi_v, phi_t, phi_p, U_ep, contact_evidence):
        D_phys = self._mahalanobis(phi_v, phi_t) + \
                 self._mahalanobis(phi_v, phi_p)
        D_feat = 1 - F.cosine_similarity(self.P_s(phi_v),
                                         self.P_s(phi_t), dim=0)
        H = torch.sigmoid(self.a * D_phys + self.b * D_feat
                          + self.g * U_ep - self.d * contact_evidence)
        return H.item(), H.item() <= self.tau_h
```

```python
class CognitivePerceptionBudget:

                + 0.3 * self.conf_used / self.B_conf_resolve)
```

```python
class VisionPhysicsFusion:
    def __init__(self, eps=1e-6, tau_h=0.6):
        self.eps, self.tau_h = eps, tau_h

    def fuse(self, phi_v, phi_t, phi_p, rho, H_score):
        w = {m: rho[m] / (U[m] + self.eps)
             for m, U in [('v', phi_v.u), ('t', phi_t.u), ('p', phi_p.u)]}
        if H_score > self.tau_h:
            w['v'] *= 0.3                     # 未验证视觉降权
        total = sum(w.values())
        phi = sum(w[m] * phi[m] for m in w) / total
        if H_score > self.tau_h:
            phi = self._shrink_to_interior(phi, 0.2)   # 向区间内侧收缩 20%
        return phi
```

2. **缺失模态鲁棒性**：任一模态缺失时性能退化 ≤ f(ρ_m)，且不产生伪冲突。
3. **主动感知效率**：单位成本期望信息增益不低于固定注视基线。

5. **幻觉抑制**：A76 下未验证视觉直设 K_p 的概率 ≤ β，并被 PFC 拒绝。
