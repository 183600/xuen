# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「开源软件」×「步态规划」）

> R69 让闭环学会了「问」：把不确定性拆成 aleatoric / epistemic，前者收紧、后者交给流匹配多模态 + 主动交互消解。但它把两个信任问题留在了暗处：
> 1. **谁认证认证者？** R69 的全部收益押在「流模型的模态分布可信」上，而可信与否只由一条 MCG（ECE 门）判定——这是**单一证人**。rectified flow 在有限数据上幻觉出幻影模态时，ECE 未必能发现；系统会自信地追问一个幻影，或给一个误导性回答盖上「已验证」的章。
> 2. **何时必须停止追问？** R69 的交互是「VoI − 成本 > 0 就问」，没有时间纪律。幻影模态可以无限消耗 query，epistemic 不确定可以让系统永远停在岔口——「诚实的犹豫」退化为「瘫痪」。
>
> 本轮两个灵感各补一个洞，而且补的是同一个哲学：
> - **开源软件**的机制从来不是「相信维护者」，而是**可 fork、可重建、可溯源**：你不必信任单一作者，只要能从源码重建、与签名上游对齐、必要时 fork。→ 把「单一 MCG 证人」升级为「多个独立重导出的一致（forkable verification）」+「认知供应链 BBOM」+「运行时栈证明」。
> - **步态规划**的机制从来不是「先消除地形不确定再走」，而是**接触调度**：把还没验证的假设放在**摆动腿**上（provisional、可撤、有恢复立足点），到**支撑相**才让它承重；不清楚就先 toe-tap 探一下，探错就收腿。→ 把「不确定性」从「必须消解的量」升级为「可以被调度、被携带、被限时承诺的负载」。
>
> 核心命题：**不确定性不是必须在行动前清零的标量，而是可以按时序调度、且只在可复现验证后才允许承重的负载。** 未验证的 epistemic 只能待在 swing（可携带、可撤回、有退路），只有通过独立 fork 一致 + BBOM 溯源 + PROV 的信念才能升为 stance（load-bearing）。三条新纪律——**可复现性门、接触承诺期限、可逆探针**——共同把 R69 的「问」变成「有纪律、有退路、有时间盒的问」。
>
> 命名 **FORGE-RAS**（Forkable Observable Reproducible Gait-scheduled Epistemic Risk-Adaptive System）：像开源一样可重建/可 fork，像步态一样按接触相位承诺。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**这份答案能被独立重建吗？在落步之前，我最多能带着多少没验证的假设走**」。

## 0. 直觉与动机

**灵感 1（开源软件 → 信任来自可重建，不来自权威）**
直觉：R69 用 ECE 给模态权重发一张合格证，但 ECE 本身是一个数字，由单条标定管线算出；若这条管线有 bug、被替换、或与模型共享同一数据盲区，合格证就是同义反复。开源软件的教训恰好相反：可信度来自**任何人都能从制品重建出相同结果**（reproducible build），来自**每个依赖都有 SBOM 与签名**（provenance），来自**不满意可以 fork**。把它搬到认知层：模态后验不应由单一 MCG 宣判，而应由 **n 个相互独立的重导出（不同种子、独立 head、独立标定管线、第三方构建）** 给出的分布是否一致来判定。R69 的 MCG 只是 n=1 的退化。

**灵感 2（步态规划 → 未验证的信念只能待在摆动腿）**
直觉：双足/四足行走从不先确认整片地形再迈步——它把「这块地可能不稳」这个未验证假设放在**摆动腿**上，摆动相是 provisional 的、可撤回的；只有**触地（contact）**才把假设变成承重事实。若触地发现滑，就靠**恢复步（recovery step）**把重量交给已验证的立足点。这给出 R69 缺失的时序结构：epistemic 不确定不是「要么消解、要么保守」的二选一，而是**在 swing 携带、到 deadline 必须 commit 或 recover**。于是「带着不确定性继续走」第一次有了可算的安全界（恢复立足点的可达域 vs 落点不确定椭球）。

**灵感 3（接触调度 = 交互预算的硬时间盒）**
直觉：R69 的交互预算是一个「软成本」c(g)，VoI 略有盈余就问，幻影模态可以一直问下去。步态规划说：**摆动相本身有时间**。交互只能发生在 swing 窗口内；到 commit deadline（由 capture point / 支撑多边形决定）必须落子。这把「问不问」从无界优化变成**有界调度**：每个未消解模式最多占一个 swing 窗口，phantom 最多被问一次，之后要么被 commit（带恢复步兜底）要么被 drop。交互疲劳与「岔口瘫痪」同时被结构性消除，而不是靠调参。

**灵感 4（可逆探针 → 只有能撤回的观测才配承重）**
直觉：R69 的信息动作（注视 / 探针 / 问句）只要求过 C-RAS-WM 认证，却没要求**可撤回**。步态里的 toe-tap / 轻踏是典型可逆探针：探的时候重量还在后腿，探错直接收腿，不改变安全包络。把它形式化：一个信息动作只有在同一接触相位内存在 **abort**、且 abort 后状态回到探针前的安全包络内，才允许把观测用来提升假设的支撑状态；不可逆交互（例如已经向人类开口承诺、已经踏入无法收回的区域）只能提供似然，不能 load-bearing。这把 R69 的「交互安全」从「动作本身不越界」升级为「观测的使用权必须可撤回」。

**灵感 5（供应链即攻击面 → 新威胁模型）**
直觉：一旦信任来自「依赖 + 重建 + 签名」，攻击面就从「传感器被偏置」扩展到「认知供应链被投毒」：**域名抢注式伪模式**（一个看起来像真模态的幻影混进候选）、**废弃依赖**（标定过期却仍被引用）、**依赖混淆**（在高信任层注入伪模式，诱导系统优先采纳）、**后门**（隐蔽共谋欺骗）、**假 fork / 镜像**（共享同一盲区的「独立」重建，让 n_eff 虚高）、**fork 分歧 DoS**（故意制造分歧迫使系统永远保守）。R69 的 ℰ_poison 只覆盖「人撒谎」，本轮必须把 ℰ 升级为供应链威胁模型 ℰ_supply，否则「可复现」会变成「同一个错误的共识」。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（FORGE-RAS 总览）** FORGE-RAS = (ESC, FORK, GAIT, PATCH, PROV, RAS-WM‡)。四不变式：
(i) 实时流零学习写操作（继承 R68 定义 276-i）；
(ii) **可溯源承重**：任何进入 VoI / λ / commit 的信念必须携带 BBOM，且依赖信任层级 ≥ 该用途所需层级；无 BBOM 的信念只能进 swing，不得 load-bearing；
(iii) **可复现性门**：信念升 stance 需 Div(F) ≤ τ_div 且 n_eff ≥ n_min；单 fork 退化为 R69 的 ECE 门；
(iv) **接触时序硬约束**：未消解 epistemic 只可在 swing 携带，到 commit deadline 必须 commit 或 recovery；不得无限追问。

**定义 311（认知供应链与信念物料清单）** 认知依赖 D = {d_i} 构成 DAG；每个 d_i = (artifact, ver, hash, signer, τ_i, attestation)。信念 b 的 BBOM(b) = 其依赖闭包；信任层级 τ(b) = min_{d∈BBOM(b)} τ(d)（最弱链），再按可复现性加 bonus。层级格：τ_0 unverified < τ_1 self-signed < τ_2 single third-party < τ_3 reproducible-2 < τ_4 reproducible-k < τ_5 formally certified。用途所需层级 τ_req：swing 可 τ≥τ_1，stance / commit 必须 τ≥τ_3。

**定义 312（可 fork 验证 FORK）** 对模态后验 p(M|o)，fork 集 F={f_1..f_n} 为独立重导出（不同采样种子 / 独立 trunk head / 独立标定管线 / 第三方工具链重建）。分歧 Div(F) = max_{i≠j}[ TV(ŵ^{(i)}, ŵ^{(j)}) + λ_W·W_2(ξ̄^{(i)}, ξ̄^{(j)}) ]。接受条件 Div(F) ≤ τ_div ∧ 每个 fork 的 BBOM 均 attested。n=1 ⇒ Div≡0 ⇒ 严格退化为 R69 的 MCG（ECE 单门）。

**定义 313（有效 fork 数与幻影残差）** n_eff = n / (1 + (n−1)·ρ̄)，ρ̄ 为 fork 间错误相关（共享数据 / 同源换皮时 ρ̄→1）。幻影模式被 n_eff 个 fork 同时误报且一致接受的概率 ≤ δ_ph·ρ̄^{n_eff−1} + ε_div。⇒ 只有**真独立**的 fork 才降幻影；假 fork 不提供任何保证。

**定义 314（步态相位与接触调度）** 相位 φ_t ∈ G（步态图节点：walk / trot / bound / transition）。假设集 ℋ 按支撑状态 σ(h) ∈ {swing, stance} 划分；接触事件 e_k=(h,φ_k) 把 h 从 swing 提升到 stance。U_swing = Σ_{h∈swing} ŵ_h trΣ_h + 未消解 epistemic(swing)；U_loaded = 同式对 stance。不变式：U_loaded 中的 epistemic 分量必须已通过定义 310-iii。

**定义 315（可承载不确定性与恢复立足点）** 恢复立足点 ρ_rec(s) = 从 s 出发、在 τ_react 内可执行且已认证的安全动作（可退回的支撑）。允许携带 U_swing 的条件：∃ρ_rec(s)，且其可达域覆盖摆动腿落点的不确定椭球（定义 316 的 margin 条件）。⇒ 携带不确定性的许可由「退路是否覆盖落点」决定，而非由 U_epi 标量决定。

**定义 316（可逆探针原理）** 信息动作 g 是 reversible probe ⇔ 存在 abort(g) 使 (a) 在同一接触相位内撤回；(b) risk(abort) ≤ ε_abort；(c) abort 后状态回到 g 前的安全包络（相位内 rollback）。只有 reversible probe 的观测可提升假设支撑状态；不可逆交互只提供 likelihood，不改变 σ(h)。R69 的 g 无 (a)(c)，本轮加强。

**定义 317（承诺期限与步态调度 VoI）** 每个假设有 commit deadline φ_dl(h)（由 capture point / 支撑多边形给出）。在 swing 窗口内选 g* = argmax_g [(VoI(g) − c(g)) / Δφ(g)] s.t. φ_t + dur(g) ≤ φ_dl(h) 且 g 过认证。到 φ_dl 仍有 U_swing：要么按当前后验 commit 一个 mode（进入 stance，须满足 certified margin），要么执行 recovery step（回到 R69 保守）。⇒ phantom / 未消解模式最多消耗一个 swing 窗口，追问次数有硬上界。

**定义 318（信念补丁纪律 PATCH）** 人类 / 第三方回答视为 patch p：须过 CI（≥k 个正交证据源测试 + 签名 + BBOM 完整）才 land 进 belief repo；未过则 quarantine 并记录 blame（来源、时间、被哪些证据否定）。单源 patch 只能作为 likelihood，不得 land。这是 R69 证据纪律的「可溯源、可回滚、可追责」版本。

**定义 319（运行时认知栈证明 PROV）** 启动时与每 T_att 秒校验本地 flow 模型 / 标定 / 解码器 / 证据源的 hash+签名与已发布 manifest 一致（measured boot / reproducible build）。不一致 ⇒ quarantine 该依赖、禁用相关 mode、降级到 R69 纯保守。直接防「标定层被悄悄替换」与依赖混淆。

**定义 320（供应链威胁模型 ℰ_supply）** 域名抢注式伪模式、废弃依赖（stale calibration / 过期 hash）、依赖混淆（高信任层注入伪模式）、后门（隐蔽共谋）、假 fork / 镜像（ρ̄→1 虚高 n_eff）、fork 分歧 DoS（制造分歧逼保守）。ℰ_FORGE = ℰ_FLUID × ℰ_supply。

**定义 321（参与式审计 VQAuditor-F）** 审计对象新增：BBOM 完整性、fork 独立性（真独立还是同源换皮）、commit 是否在 deadline 前、recovery foothold 是否真可达、patch CI 是否被绕过、PROV 是否周期执行。结论回灌 AuditBuf，更新 ρ̄ 与 τ_req 先验。继承 VQAuditor-I。

**定义 322（证书 J_FORGE）** J_FORGE = (J_FLUID, bbom_root_hash, n_eff, div_max, gait_phase_at_commit, swing_budget_used, recovery_margin, patch_ci_pass, prov_attest_age, forge_ver)。Valid ⇔ Valid(J_FLUID) ∧ Div ≤ τ_div ∧ n_eff ≥ n_min ∧ 所有 stance 假设 BBOM attested ∧ PROV 新鲜（age ≤ T_att）∧ commit 在 deadline 前。

**定义 323（两级 commit 退避，含 fork / gait bonus）** 若 fork 一致且探针可逆：可用较小保守 margin（fork bonus，不弱于 R69 的 resolution bonus）；否则（单 fork / 分歧 / 不可逆探针 / PROV 失败）：退化为 R69 保守，并在 deadline 前 recovery。⇒ R69 = 「单 fork + 无 swing + 单源 patch + 无 PROV」边界。

**定义 324（步态图自适应）** 步态节点按支撑多边形 / β 置信档组织，低置信 → 更稳步态（更大支撑多边形、更低速度），高置信 → 更动态步态。这给「只收紧 λ」加了第二个旋钮：不只减速，还可**换更稳的步态**。λ 与 gait 联合选择：argmin 期望风险 s.t. 时延预算。

**定义 325（时序默认值与失效）** 默认 T_att=1s、swing window=1 个步态周期、commit deadline 由 capture point / 支撑多边形给；任一超时、PROV 失败、或 recovery foothold 不可达 ⇒ 立即 recovery step，禁止 commit。

# IP-264 ESC：认知供应链与 BBOM
class EpistemicSupplyChain:
    def bbom(self, belief_id):                     # 依赖闭包（缓存）
        return self.dag.closure(belief_id)
    def trust(self, belief_id):                    # 最弱链 + 可复现 bonus
        deps = self.bbom(belief_id)
        return min(d.tau for d in deps) + self.repro_bonus(deps)
    def attested(self, belief_id, tau_req):        # 定义 311 / 319
        return self.trust(belief_id) >= tau_req and self.prov.fresh(belief_id)

# IP-265 FORK：独立重导出的一致门
def fork_verify(policy, o, forks, tau_div):
    posts = [f.posterior(o) for f in forks]        # 不同 seed / head / 管线 / 工具链
    div   = max(divergence(a, b) for a, b in pairs(posts))
    n_eff = len(forks) / (1 + (len(forks)-1) * rho_bar(forks))
    ok    = (div <= tau_div) and all(f.attested for f in forks)
    return ok, div, n_eff, merge(posts)            # n=1 时退化为 ECE 门

# IP-266 GAIT：接触调度、承诺期限、可逆探针
def gait_step(hypotheses, z, phi, budget):
    swing = [h for h in hypotheses if h.sigma == 'swing']
    for h in swing:
        if phi >= h.deadline:                      # 到期限
            if h.trust >= TAU_STANCE and has_margin(h):
                h.commit()                         # 升 stance（须 certified）
            else:
                return recovery_step(h)            # 退回安全立足点
    g = best_probe(swing, z, phi, budget)          # 只在可逆时可用
    if g and phi + g.dur <= g.host.deadline and g.reversible:
        obs = g.execute(); g.host.update(obs)
    elif phi >= any(swing_deadline):               # 无探针可逆 → 按后验承诺
        commit_best_or_recover(swing)
    return None

# IP-267 PROV：运行时认知栈证明
def prov_check(manifest, local, age, T_att):
    if age > T_att: quarantine_all(); return 'stale'
    bad = [k for k in manifest if local.hash(k) != manifest.hash(k)]
    if bad:
        for k in bad: quarantine(k)                # 禁用相关 mode
        return 'degraded'
    return 'ok'

# IP-268 PATCH：信念补丁 CI
def land_patch(patch, belief, evidence_sources):
    passed = [s.test(patch) for s in evidence_sources]   # 正交证据
    if patch.signed and patch.bbom_complete and sum(passed) >= K_ORTH:
        belief.land(patch); return 'landed'
    belief.quarantine(patch, blame=patch.source); return 'rejected'

# IP-275 主闭环（继承 R69，插入 FORGE 层）
def FORGE_RAS_round(M, obs, phi):
    z, o = M.mtm.forward(...); c, U_cal, _ = M.cof.step(...)
    # 0) 运行时证明：认知栈是否可信
    if M.prov.check(...) != 'ok':
        return r69_conservative(M, o, lam_floor(U_cal))     # 纯 R69 兜底
    # 1) 多 fork 重导出 + 一致性门（替代单 ECE）
    ok, div, n_eff, post = fork_verify(M.fmp, o, M.forks, TAU_DIV)
    U_ale, U_epi, modes = decompose(post)
    # 2) 按支撑状态分流不确定性：swing 可携带，stance 须承重
    U_swing, U_loaded = split_by_support(modes)
    # 3) 步态调度：可逆探针 / 承诺期限 / 恢复步
    if U_epi > TAU_EPI and phi + M.probe_dur <= min_deadline(modes):
        g = M.gait.best_probe(modes, z, phi, M.budget, must_be_reversible=True)
        if g: post = M.gait.execute_probe(g, post)
    action = M.gait.commit_or_recover(post, phi)   # 到期限或超预算
    # 4) 升 stance 前再核 BBOM / 信任层级
    if not all(M.esc.attested(m.id, TAU_STANCE) for m in action.stance_modes):
        action = r69_conservative(M, o, lam_floor(U_loaded + U_swing))
    # 5) 保守侧仍按 R69 两级退避 + fork / gait bonus
    lam = max(M.efs.risk_scale(...), lam_floor(U_loaded + residual_epi))
    k   = M.c_ras_wm.certified_prefix(action.a, ..., wm_preds)
    # 6) 审计 + 证书
    M.vqa_f.submit_async(M.esc, div, n_eff, phi, action)
    return k, lam, action, (U_loaded, U_swing, ok, n_eff)

## 3. 推导

**引理 19（fork 一致压制幻影）** 设幻影模式在真信念中权重为 0，单 fork 因采样 / 拟合噪声误报概率 δ_ph。n_eff 个（错误相关 ρ̄）独立 fork 同时误报且被一致性门接受的概率 ≤ δ_ph·ρ̄^{n_eff−1}+ε_div。要点：可复现性门把「信任单个 ECE」换成「信任独立重建的一致」；且增益严格依赖独立性——同源换皮 ρ̄→1 时无增益（对应开源中假 fork / 镜像不提供审计价值）。这是 R69 引理 18（投毒上界）在**模型自身**上的镜像。

**引理 20（摆动不确定性与恢复裕度）** 若 U_swing 的落点椭球被 ρ_rec(s) 的可达域覆盖，则在 commit deadline 前执行 recovery step 的失败概率 ≤ ε_rec，且 ε_rec 随 recovery margin 单调下降。要点：携带未消解 epistemic 继续移动的风险由**恢复裕度**而非 U_epi 标量界定。这把 R69 的「必须先消解再做」放宽为「可带着走，但必须留退路」，且安全界可算。

**引理 21（有界追问）** 每个未消解 / 幻影模式最多占用一个 swing 窗口（定义 317）；N 个步态周期内交互次数 ≤ ⌈N·swing_ratio⌉，每个模式最多被追问一次后被 commit 或 drop。要点：交互从「软成本」变「硬时序」，R69 的无限追问 / 交互疲劳被结构性消除，而非靠调参。

**定理 18（FORGE 严格包含 R69）** 取 n=1、gait graph 单 stance 相（无 swing）、patch 单源、PROV 关闭时，FORGE 每条决策与 R69 逐指令相同；一般情形下 FORGE 的安全约束是 R69 的加强（更多门 + 时序硬约束 + 可撤回性），效率侧获得 fork bonus 与 gait bonus。故 R69 = FORGE 的「单 fork / 无摆动 / 单源」边界。

**定理 19（时序-证据联合无突变）** commit / recover / probe-abort 均在同一接触相位内过 C-RAS-WM‡ 认证；recovery step 是预认证动作；λ 沿 gait phase 单调不降；故控制连续、无突变（继承 R68 定理 15、R69 定理 17）。

**定理 20（供应链完整性）** 在 PROV 每 T_att 周期执行且 manifest 签名的前提下，被篡改依赖在 ≤ T_att 内被发现并隔离（概率 1）；依赖混淆需伪造签名（假设不可行）；假 fork 被 VQAuditor-F 的独立性检验降权（ρ̄↑ ⇒ n_eff↓）；fork 分歧 DoS 只能触发 fail-safe 降级，不能触发危险动作。

## 6. 本轮最大风险

**一句话**：FORGE-RAS 的全部安全增益押在「fork 真独立、provenance 真可信」上——**若多个 fork 共享同一数据盲区 / 同源换皮（ρ̄→1），或签名根被攻破，那么「可复现的一致」就退化为「同一个错误的共识」，系统会以虚高的 n_eff 把共享幻觉升为 stance、把误导性 patch 盖上「已通过 CI」的章；假开源比单一诚实证人更危险，因为它批量制造虚假保证。**

**次级风险与缓解**：
1. **recovery foothold 名义可达、实际不可达**（地形/动力学突变）→ 定义 315 可达域核验 + 定义 325 超时即 recover + E304；
2. **fork 成本击穿实时预算** → 缓存 + n=1 默认路径 + 仅 stance 候选升 n，E313 给拐点；
3. **PATCH CI 被社交工程绕过**（诱导性 patch 通过单源测试）→ k 正交 + 签名 + blame 链 + E314；
4. **步态图切换本身引发瞬态** → 换装不变式 + C-RAS-WM‡ 前缀认证 + 定理 19；
5. **PROV 与实时性冲突**（每周期校验过重）→ 摊还 + 增量 hash + 只校验进入 stance 的依赖子图。

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** FORGE-RAS = (ESC, FORK, GAIT, PATCH, PROV, RAS-WM‡)；零学习写操作继承；可溯源承重（无 BBOM 只能 swing）；可复现性门（Div ≤ τ_div ∧ n_eff ≥ n_min）；接触时序硬约束（swing 携带、deadline 必须 commit / recover）。

# IP-264 ESC：认知供应链与 BBOM
class EpistemicSupplyChain:
    def bbom(self, b):        return self.dag.closure(b)
    def trust(self, b):       return min(d.tau for d in self.bbom(b)) + self.repro_bonus(b)
    def attested(self, b, t): return self.trust(b) >= t and self.prov.fresh(b)

# IP-265 FORK：独立重导出的一致门
def fork_verify(policy, o, forks, tau_div):
    posts = [f.posterior(o) for f in forks]
    div   = max(divergence(a, b) for a, b in pairs(posts))
    n_eff = len(forks) / (1 + (len(forks)-1)*rho_bar(forks))
    return (div <= tau_div) and all(f.attested for f in forks), div, n_eff, merge(posts)

# IP-266/IP-271 GAIT：接触调度 + 步态调度 VoI
def gait_step(hypotheses, z, phi, budget):
    swing = [h for h in hypotheses if h.sigma == 'swing']
    for h in swing:
        if phi >= h.deadline:
            return h.commit() if (h.trust >= TAU_STANCE and has_margin(h)) else recovery_step(h)
    g = best_probe(swing, z, phi, budget, must_be_reversible=True)   # IP-269
    if g and phi + g.dur <= g.host.deadline: g.host.update(g.execute())
    elif phi >= any(h.deadline for h in swing): commit_best_or_recover(swing)
    return None

# IP-267 PROV：运行时认知栈证明
def prov_check(manifest, local, age, T_att):
    if age > T_att: quarantine_all(); return 'stale'
    bad = [k for k in manifest if local.hash(k) != manifest.hash(k)]
    for k in bad: quarantine(k)
    return 'degraded' if bad else 'ok'

# IP-268 PATCH：信念补丁 CI
def land_patch(patch, belief, sources):
    passed = [s.test(patch) for s in sources]
    if patch.signed and patch.bbom_complete and sum(passed) >= K_ORTH:
        belief.land(patch); return 'landed'
    belief.quarantine(patch, blame=patch.source); return 'rejected'

# IP-275 主闭环（继承 R69，插入 FORGE 层）
def FORGE_RAS_round(M, obs, phi):

        action = r69_conservative(M, obs, lam_floor(U_loaded + U_swing))  # 4) 溯源门

## 4. 推导

**引理 19（fork 一致压制幻影）** 幻影在真信念权重 0、单 fork 误报 δ_ph；n_eff 个（错误相关 ρ̄）独立 fork 同时误报且被接受的概率 ≤ `δ_ph·ρ̄^{n_eff−1}+ε_div`。系：增益严格依赖独立性——假 fork / 镜像 ρ̄→1 无增益；这是 R69 引理 18 在模型自身上的镜像。

**引理 20（摆动不确定性与恢复裕度）** 若 U_swing 落点椭球被 `ρ_rec(s)` 可达域覆盖，则 deadline 前 recovery 失败概率 ≤ ε_rec 且随 margin 单调下降。系：携带未消解 epistemic 的风险由恢复裕度而非 U_epi 标量界定，安全界可算。

**引理 21（有界追问）** 每个未消解 / 幻影模式最多占一个 swing 窗口；N 周期内交互次数 ≤ `⌈N·swing_ratio⌉`，每模式最多追问一次后被 commit / drop。系：交互从软成本变硬时序，消除无限追问与交互疲劳。

**定理 18（FORGE 严格包含 R69）** n=1、单 stance 相、单源 patch、PROV 关闭时逐指令同 R69；一般情形安全约束是 R69 的加强（更多门 + 时序 + 可撤回性），效率侧获 fork / gait bonus。R69 = 「单 fork / 无摆动 / 单源」边界。

**定理 19（时序-证据联合无突变）** commit / recover / probe-abort 均在同相位过 C-RAS-WM‡；recovery 为预认证动作；λ 沿 gait phase 单调不降 ⇒ 控制连续、无突变（继承 R68 定理 15、R69 定理 17）。

**定理 20（供应链完整性）** PROV 每 T_att 执行且 manifest 签名 ⇒ 篡改依赖 ≤ T_att 内隔离（概率 1）；依赖混淆需伪造签名（假设不可行）；假 fork 被独立性检验降权；fork 分歧 DoS 只能 fail-safe 降级。

## 7. 本轮最大风险

**一句话**：FORGE-RAS 的全部安全增益押在「fork 真独立、provenance 真可信」上——**若多个 fork 共享同一数据盲区 / 同源换皮（ρ̄→1），或签名根被攻破，则「可复现的一致」退化为「同一个错误的共识」，系统会以虚高的 n_eff 把共享幻觉升为 stance、把误导性 patch 盖上「已通过 CI」的章；假开源比单一诚实证人更危险，因为它批量制造虚假保证。**

**次级风险与缓解**：recovery foothold 名义可达实际不可达（定义 315 可达域核验 + 定义 325 超时 recover + E304）；fork 成本击穿实时预算（缓存 + n=1 默认 + 仅 stance 候选升 n，E313）；PATCH CI 被社交工程绕过（k 正交 + 签名 + blame + E314）；步态图切换引发瞬态（换装不变式 + C-RAS-WM‡ + 定理 19）；PROV 与实时性冲突（摊还 + 增量 hash + 只校验进入 stance 的依赖子图）。
