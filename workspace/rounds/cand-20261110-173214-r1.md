# 第 48 轮（灵感循环第 1 轮；承接第 47 轮产物 v24 与第 46 轮想法 v11；本轮灵感：手势识别 × 容错控制） · Gesture-Fault-Tolerant-Cert：意图通道故障诊断-重构与“优雅降级”联合证书（四层架构 v12）

> 承接 v11/v24 Compliance-Actuation-Cert。v11 把安全从位姿扩展到力-位-能-热，并用驱动租约 ℓ_a 处理执行器退化；但其隐含假设 H6 是：**意图通道（语音/上下文/记忆/接触预测）可信、彼此独立，且任何异常都应直接 fail-closed**。现实中 UniBot 的人机交互大量依赖手势：指向递物、招手靠近、张手停止。手势既是空间指代（deictic grounding）最自然的通道，也是噪声最大、最易被遮挡/视角/光照/快速运动破坏的通道。容错控制（FTC）恰好给出正确框架：安全不应只是“检测到异常就停机”，而应是“检测-隔离-重构-优雅降级”，并在有界故障集下仍保持安全不变量。两个灵感词精确命中 H6：**手势识别**引入一个高方差、可被模仿欺骗、却不可替代的意图/安全通道；**容错控制**要求把意图通道当成可能故障的传感器，通过解析冗余与重构维持证书 soundness。新问题：**当手势、语音、上下文、记忆甚至执行器同时出现部分故障时，如何签发一个在故障集 F 下仍有界成立、且能从 nominal→reconfigured→safe-hold→e-stop 优雅降级的联合证书，而不是让单个通道故障把整套系统硬停机或静默带病运行。**

## 0. 直觉与动机

**灵感 1（手势识别 → 空间指代证书，而非又一个语音通道）**
直觉：语音能说“把那个给我”，却说不清“那个”在哪；手势能直接指向。手势因此同时提供两类价值：**deictic（指代）**——把手部关键点反投影成工作空间中的指代锥，与深度图/分割求交得到候选物体集；**symbolic（符号）**——张手、摆手、交叉臂等离散安全命令，延迟远低于语音 ASR+NLU。但手势的可靠性高度条件化：遮挡、背光、视角偏斜、快速运动导致的运动模糊、不同用户的做手势习惯，都会让识别置信与真实正确率错位。因此手势输出不能是一个标签，而应是一张**手势意图证书** G_t=(Î_t, C_t, ρ_g, H_g, τ_g)：意图候选集、指代锥、校准可靠度、熵与有效期。

**灵感 2（容错控制 → 从“fail-closed”到“检测-隔离-重构-优雅降级”）**
直觉：v11 的租约体系对执行器退化做了级联失效，但仍是“事件触发式停机”。FTC 的核心不是停机，而是**在故障发生后仍维持可证明的安全与尽可能多的功能**。它要求三件事：(a) 故障检测与隔离（FDI）——用跨模态解析冗余（手势↔语音↔上下文↔接触力↔执行器残差）发现卡死、偏置、增益损失、尖峰、分布外、延迟；(b) 主动重构——丢弃/降权故障通道、重融合、缩小任务域、降低刚度 K_d；(c) 被动兜底——对未被及时检测的有界故障，用鲁棒不变集保证仍处于安全域。手势在这里既是**被监控的故障源**，也是**重构后可用的冗余源**。

**灵感 3（手势作为容错控制的安全后备通道——但必须独立且可校准）**
直觉：当语音链路故障或操作者双手正忙时，一个“张手/交叉臂”手势可以作为**补充的紧急停止/保持通道**。但它只有在满足两个条件时才可托付安全：一是走**独立快速路径**（不经过意图识别主链、不被 VAD/CPD/MVR 否决、优先级最高）；二是其**召回率被独立校准**而非借用意图识别的置信。否则会出现两种灾难：漏检（该停没停）或误触（频繁误停导致可用性崩溃、操作者绕过安全机制）。

**耦合升级（v12）**：在 v11 的 CAE 层之上新增 **Gesture-Fault-Tolerant Envelope（GFTE）层**。IP-72 GIC 输出手势意图证书并把指代锥接到深度/分割；IP-73 FDI-R 做跨模态残差检测、隔离与通道健康度维护；IP-74 SGO 提供独立、可校准、最高优先级的安全手势覆盖通道。四层 v12：根信任层在 ℓ_p/ℓ_e/ℓ_a 之外增加**意图冗余条件**（至少一条独立健康通道）与安全覆盖通道；L1 几何层把指代锥并入 P_t 与 R_t^F 的候选域；L2 上下文层融合手势/语音/记忆并输出通道健康；L3 CAR 守卫从二值 fail-closed 升级为四级状态机；L4 DCL 采集故障注入与误识别样本。

## 1. 形式化定义（增量：定义 69–73）

**定义 69（手势意图证书）**
设手势观测 x^g_t 为手部关键点序列，识别映射 R_g: x^g_t → (Î_t, â_t, ρ_g, H_g)，其中 Î_t⊆I 为意图候选集，â_t 为手部锚点与指向方向。指代锥
C_t(â_t,d_t)={p : angle(p−â_t, d_t) ≤ θ_g}，
候选物体集 O_t = Objects ∩ C_t。证书
G_t=(Î_t, C_t, O_t, ρ_g, H_g, τ_g)，
其中 ρ_g 由分层共形校准（按遮挡度、视角、运动速度、用户分层）。**手势 soundness**：
P(intent*∈Î_t ∧ object*∈O_t | x^g_t, quality) ≥ 1−α_g。
**歧义判据**：若 |O_t|>1 且 H_g>H_amb，则 G_t 标记为 ambiguous，不得单独驱动高风险动作。

**定义 70（意图通道故障模型与残差）**
通道集合 K={gesture, voice, context, contact, memory, actuation}。每通道故障模式集 F_k={none, stuck, bias, gain-loss, spike, out-of-distribution, latency}。跨模态残差
r_{k,k'}=D(Î_k, Î_{k'})（意图一致性，如集合距离/KL），
r_k^{kin}=landmark 运动学可行性误差，
r_k^{tmp}=时序预测残差，
r_k^{self}=通道自一致残差。
检测统计量用 CUSUM/EWMA 累积：Λ_k(t)=max(0, Λ_k(t−1)+r_k(t)−ν_k)。健康度 h_k=1−σ(Λ_k−λ_k)，隔离由残差签名（stuck→时序方差≈0；bias→恒定偏移；gain-loss→幅度缩放；spike→单帧跳变；OOD→特征马氏距离）判定。**有界故障假设**：任一时刻活动故障通道数 |F_active| ≤ f。

**定义 71（容错联合证书与优雅降级状态机）**
联合证书
J_t^FT=(P_t, R_t^F, G_t, ℓ_p, ℓ_e, ℓ_a, H_t^K, m_t, K_d, mode_t)，
mode_t∈M={M0 nominal, M1 reconfigured, M2 safe-hold, M3 e-stop}。**容错 soundness**：若 (i) ℓ_p,ℓ_e,ℓ_a 有效，(ii) 存在至少一条与故障通道独立的健康意图通道 h_k≥h_min，(iii) 安全覆盖通道在线，则
P(X_t∈P_t ∧ F_t∈R_t^F ∧ intent*∈Î_t | F_active, mode_t) ≥ 1−α。
**降级约束**：M0→M3 的转移在任意模式下必须可在 T_stop 内到达；M1→M0 必须先通过一次完整重认证，禁止“带病自愈”直接回 nominal；M2 冻结笛卡尔运动、保持低刚度 K_d⪯K_hold 且力证书持续有效。

**定义 72（重构策略与容错不变量）**
策略
π_re(H_t^K, {r_k}, x_t, leases) → (mode_t, w_k, K_d, m_t)，
其中 w_k 为通道融合权重。求解
max E[TaskGain(mode,w,K_d) − λ_s·Risk_s − λ_f·Cost_reconfig]
s.t. J_t^FT 可签发，且对任意 |F'|≤f 的故障集满足容错不变量：
(mode_t∈{M2,M3}) ∨ (P_t 非空 ∧ R_t^F 非空 ∧ 至少一条独立健康意图通道)。
即：要么仍有可证明的证书，要么已进入优雅安全态，不存在“静默继续但证书已空”的第三态。

**定义 73（安全手势覆盖证书）**
设计安全手势集 S_stop 与独立检测器 D_s（结构上不共享意图识别主链）。覆盖证书
O_t=(s_t, π_stop, L_stop)，
要求
P(detect | s∈S_stop) ≥ 1−β_miss，E[false trigger / hour] ≤ β_fa，端到端延迟 ≤ L_stop。
**优先级公理**：O_t 的优先级严格高于所有任务命令与所有记忆/语音/接触先验；任何模块不得否决 O_t；硬件急停为最终权威，O_t 只是**补充**通道，不可作为唯一停止手段。

## 2. 三大新增产出与既有 IP 升级

**IP-72 GIC（Gesture Intent Certifier）**
- 时序手势识别：关键点序列 + 轻量时序模型，输出意图候选集与熵
- 指代接地：手部锚点/指向 → 指代锥 → 与深度图/分割求交 → 候选物体集
- 分层共形可靠度 ρ_g：按遮挡、视角、速度、用户分布校准
- 歧义处理：多物体或高熵时禁止单独驱动高风险动作，转多模态确认

**IP-73 FDI-R（Fault Detection, Isolation & Reconfiguration）**
- 跨模态解析冗余：手势/语音/上下文/接触/执行器残差交叉验证
- 故障检测与隔离：CUSUM/EWMA + 残差签名，维护通道健康度 H_t^K
- 主动重构：通道降权/剔除、任务域收缩、K_d 下降、模态切换
- 被动兜底：有界故障下的鲁棒不变集，覆盖未及时检测的故障

**IP-74 SGO（Safety Gesture Override）**
- 独立快速路径：不经过意图识别主链，专用停止手势分类器
- 独立校准的召回/误触率与延迟上界，作为安全案例的一部分
- 最高优先级覆盖：可打断任何任务、队列与重构决策
- 与硬件急停的仲裁关系：HW E-stop 为最终权威，SGO 仅补充

**既有 IP 升级**
IP-67 VAD：语音与手势联合意图分布，输入通道健康度；手势可补足指代槽位。
IP-68 SAB：指令-姿态-力绑定加入 G_t 的 Î_t/O_t；覆盖手势触发时强制进入 Q_safe 或安全态。
IP-69 JAL：执行器故障模式接入 FDI-R，ℓ_a 退化作为故障证据之一参与隔离。
IP-70 CAC：证书签发条件加入 mode_t；M1 下按降权后的 K_d 与通道集重算力半径。
IP-71 CPD：接触类型先验融合手势（递物/指认/推挡），高熵时强制低刚度。
IP-51 CAR：由二值 fail-closed 升级为四级状态机与容错不变量守卫。
IP-62 CCA：新增手势欺骗/模仿、遮挡、卡死、偏置、增益损失、延迟注入红队。
IP-61 DCL：采集手势误识别、故障注入、覆盖手势漏检/误触样本。
IP-63 ECPS：手势出现与指代需求改变模态调度（如需深度做指代接地）。
IP-66 MVR：记忆键加入通道健康与故障标签，故障期禁止复用相关记忆。

## 3. 算法骨架

GFTE 每控制周期：
1. 读手势关键点、语音、上下文、接触、执行器状态与三张租约
2. GIC 计算 Î_t、C_t、O_t、ρ_g、H_g；歧义则标记
3. SGO 走独立快速路径检测停止手势（先于一切任务命令）
4. FDI-R 计算跨模态残差，更新 H_t^K，隔离故障通道
5. 若检测到停止覆盖 → 直接进入 M2/M3
6. π_re 依据健康度与故障集选择 mode、融合权重、K_d、m_t
7. 若冗余前提不满足 → M2 safe-hold，而非静默继续
8. 在所选 mode 下由 PSE/CAC 签发 J_t^FT，CAR 按不变量守卫后执行
9. 故障与误识别样本回灌 DCL；M1→M0 需完整重认证

## 4. 本轮最大风险

**一句话**：把手势同时当作“需要被容错的故障源”和“可托付的安全覆盖通道”，会在同一物理通道上叠加相互矛盾的要求——为提高停止召回而放宽阈值会推高误触、破坏可用性并诱导操作者绕过安全机制，为降低误触而收紧阈值又会漏检真正的紧急停止；若 SGO 的召回率未被独立校准且硬件急停被弱化为非权威，容错架构反而制造出一个新的单点失效。

# 第 48 轮产物 · 创新点清单 v25：GFTE（GIC × FDI-R × SGO）× 手势识别-容错控制联合证书

## 2. 关键算法 伪代码

### IP-72 GIC
```
def gesture_certify(frames, depth, segmenter, calib, theta_g=25*deg):
    lm   = landmark_net(frames)                 # 21 pts/hand, temporal
    probs= intent_head(lm)                      # Î_t over intent set
    q    = quality_features(lm, frames)         # occlusion/view/speed/blur
    rho_g= calib.reliability(probs, q)          # 分层共形
    H    = entropy(probs)
    anchor, dir = deictic_head(lm)              # hand anchor + pointing ray
    cone = pointing_cone(anchor, dir, theta_g)
    objects = raycast(cone, depth, segmenter)   # candidate objects
    cert = GestureCert(intents=topk(probs), cone=cone, objects=objects,
                       rho=rho_g, H=H, expires=now()+tau_g)
    if len(objects) > 1 and H > H_amb:
        cert.ambiguous = True                   # 禁止单独驱动高风险动作
    return cert
```

```
def residuals(g, voice, ctx, contact, mem, act):
    return {
      'gesture_voice':  set_dist(g.intents, voice.intents),
      'gesture_ctx':    context_consistency(g.intents, ctx),

def fdi(res, state, thr):
    health, faults = {}, []
    for k, r in res.items():
        state[k] = max(0.0, state[k].lam + r - state[k].nu)   # CUSUM
        if state[k].lam > thr[k]:
            faults.append((k, isolate_by_signature(state[k], r)))
        health[k] = 1.0 - sigmoid(state[k].lam - thr[k])
    return health, faults

def iso_signature(hist):
    if var(hist) < eps:              return 'stuck'
    if abs(mean(diff(hist))) < eps:  return 'bias'
    if ratio(hist) < 1:              return 'gain-loss'
    if spike_rate(hist) > thr:       return 'spike'
    if mahalanobis(hist) > thr:      return 'ood'
    return 'latency'
```

### 重构策略 π_re 与容错不变量守卫
```
def reconfigure(health, faults, x, leases, override):
    if override is not None and override.p >= theta_stop:
        return Mode.E_STOP if emergency(override) else Mode.SAFE_HOLD
    trusted = [k for k in INTENT_K
               if health[k] >= h_min and not faulty(k, faults)]
    if len(trusted) == 0:
        return Mode.SAFE_HOLD                    # 优雅降级而非静默继续
    if any(f in ('stuck','bias','gain-loss') for f in faults):
        return Mode.RECONFIGURED with weights(trusted)
    if not all(leases[k].valid() for k in (P, E, A)):
        return Mode.SAFE_HOLD
    return Mode.NOMINAL

def car_guard_ft(cert, mode, health, override, T_stop):
    # 容错不变量：要么证书非空，要么已进入安全态
    if override is not None:
        return enter_safe(mode, within=T_stop)
    if mode in (M2, M3):
        return ok
    redundancy = any(health[k] >= h_min for k in INDEPENDENT_INTENT)
    if cert is None or not redundancy:
        return enter_safe(M2, within=T_stop)
    return ok
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| GIC 手势证书 | O(T·L) 时序前向 + O(|O|) 锥求交 | O(T·L) | ρ_g 分层共形 ⇒ 手势 soundness ≥1−α_g；歧义标记禁止单独高危动作 |
| FDI-R 残差/隔离 | O(|K|²·d) 每周期 | O(|K|·W) | 有界故障 |F|≤f 下，CUSUM 检测延迟可界；残差签名隔离可辨识故障模式 |
| SGO 覆盖 | O(1) 专用分类器 | O(1) | 独立校准：召回 ≥1−β_miss、误触 ≤β_fa/h、延迟 ≤L_stop |
| π_re + 守卫 | O(|K| + n_j³) | O(|Q|) | 容错不变量 ⇒ 无“证书已空仍继续”的第三态；M1→M0 需重认证 |

**正确性定理（GFTE）**：设有界故障假设 |F_active|≤f 成立，三张租约 ℓ_p/ℓ_e/ℓ_a 在 [t,t+τ] 有效，且存在至少一条与故障通道独立的健康意图通道 h_k≥h_min，安全覆盖检测器满足覆盖证书 O_t。则系统在 [t,t+τ] 内满足：或 J_t^FT 可签发且 P(X∈P)≥1−α、F∈R_t^F、intent*∈Î_t；或 mode_t∈{M2,M3} 且在 T_stop 内可达。若检测到 s∈S_stop，则无论任务/记忆/语音状态如何，系统在 L_stop+L_stop_margin 内进入 M2/M3。**关键**：证书 soundness 不再只依赖租约，而显式依赖“独立健康意图通道”这一冗余前提；冗余丧失被定义为进入安全态，而非继续执行。

## 4. 实验设计 E121–E126

| 实验 | 指标 | 门槛 |
|---|---|---|
| E121 手势意图与指代接地 | 意图准确率、指代锥物体命中率、歧义校准覆盖率 | 准确率 ≥95%；命中率 ≥90%；覆盖率 ≥1−α_g（α_g=0.05） |
| E122 手势可靠度校准 | ECE、可靠度-正确率一致性、OOD 检测 | ECE ≤0.05；OOD AUROC ≥0.9 |
| E123 FDI 检测与隔离 | 检测延迟、隔离 F1、误报率 | 延迟 ≤150ms；隔离 F1 ≥0.9；误报 ≤1/h |
| E124 单/多故障重构安全 | 注入 stuck/bias/gain-loss/spike/latency；证书非空率、误入 M2 率、不安全转移 | 不安全转移 0 次；误降级 ≤5%；|F|≤2 下仍满足不变量 |
| E125 安全手势覆盖 | 召回率、误触率、端到端延迟 | 召回 ≥99.9%；误触 ≤1/h；延迟 ≤100ms |
| E126 100h 故障+手势闭环 | 不安全事件、可用性、任务成功率、覆盖漏检 | 不安全事件 0；可用性 ≥90%；成功率 ≥90%；漏检 0 |

**回退策略**：E121 指代命中 <85% → 强制多模态确认并禁用纯手势高风险动作；E122 ECE >0.08 → 扩大 ρ_g 并降低手势权重；E123 隔离 F1 <0.8 → 回退保守通道剔除（无法隔离则整体降级）；E124 出现不安全转移 → 收紧 f 假设并强制 M2 优先；E125 召回 <99% → 停用手势覆盖作为安全通道，硬件急停必须独立保留；E126 任一漏检或误触超阈 → 灰度回收 SGO、仅保留符号命令。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 手势覆盖漏检（该停没停） | 高 | 独立校准召回、专用分类器、硬件急停始终权威、定期演练 |
| 手势覆盖误触导致频繁误停 | 高 | 独立误触率预算、双手势确认、误触率纳入安全案例 |
| 指代锥多物体歧义导致选错对象 | 高 | 歧义标记禁行、深度/分割确认、语音补槽、二次确认 |
| 跨模态残差把“用户改主意”误判为通道故障 | 中 | 残差加时序迟滞、区分意图变化与故障、人因确认 |
| 故障隔离错误（误剔除健康通道） | 中 | 残差签名多证据、隔离后仍保留被动鲁棒兜底 |
| M1→M0 过早重认证导致带病自愈 | 中 | 强制完整重认证与驻留时间、健康度滞回 |
| 记忆复用故障期历史参数 | 中 | 记忆键含健康/故障标签，故障期直接屏蔽相关记忆 |

## 6. 本轮最大风险

**一句话**：把“手势识别”同时置于故障源与安全覆盖通道两个角色，使同一通道承担相互冲突的阈值要求——放宽以提高停止召回会抬高误触、摧毁可用性并诱发绕过，收紧以抑制误触又会漏检真实急停；若 SGO 的召回/误触与延迟未被独立校准、且硬件急停的最终权威被弱化，则这套容错架构会亲手制造一个新的单点失效。
