# 第 55 轮（承接第 54 轮 v16++ GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「分布外泛化」×「创新点」）

> 第 54 轮把技能从“能力标签”细化为动作空间占用 `α_S`，并以 ACS/SCOM/CEC/AEC/JTC 建立动作-鲁棒性双证书。但整套体系隐含一个未言明的前提：所有证书 `ρ、A_cert、J` 都是在标定分布 `D_in` 上采集的。本轮追问：当任务、环境、本体或执行器发生分布漂移，这些证书还剩多少效力？核心矛盾：H22 现有证书的 soundness 只在 `D_in` 邻域成立，OOD 下会“sound 地给出错误保证”；H23 OOD 风险无法被鲁棒性谱吸收，因为支撑外行为不可插值；H24 若只再叠一个指标，本轮的“创新点”将退化为 DRO/Conformal 的重命名。

## 0. 直觉与动机

**灵感 1（OOD 不是“数据变了”，而是“动作支撑逃逸”）**
直觉：`α_S` 的支撑集 `supp_α(S) = {a | α_S(a) ≥ θ_cov}` 是技能“真正会做”的动作区域。分布外失败的根因往往不是密度变化，而是测试任务的动作落到了 `supp_α` 之外——技能在支撑内插值、在支撑外编造。于是任意移位可分解为 **in-support 重加权 + out-of-support 逃逸**：
`D_ood = (1-β_esc)·D_ood^{in} + β_esc·D_ood^{out}`。
前者可由第 54 轮的 `ρ` 吸收，后者只能拒识/降级。这把抽象的 OOD 变成可测的几何量 `β_esc`。

**灵感 2（证书要携带“有效域”，而不只是一个数）**
直觉：`ρ=0.9` 这句话没有意义，除非同时说明“在哪个域上成立”。故证书应从标量/向量升级为 **带域对象** `C = (g, 𝓓_C, b_C, π_fb)`：`g` 是保证，`𝓓_C` 是有效域，`b_C` 是域边界裕度，`π_fb` 是域外回退策略。部署第一步不是执行，而是判定目标是否落在 `𝓓_C`；落在域外时证书不是“失效”，而是“触发 fallback”，从而保留部分保证。这把“证书”从静态断言变成可执行契约。

**灵感 3（证书迁移：把 `D_in` 的保证搬到 `D_ood`）**
直觉：若能找到 `D_in→D_ood` 的传输映射 `T` 且技能对 `T` Lipschitz，则 `ρ` 可按 `L·W_1` 衰减后迁移。迁移成功 = 证书可搬运；迁移失败 = 必须重标定。这把 OOD 泛化从“祈祷泛化”变成“搬运 + 记账”，每一份削弱都显式计入迁移损失 `Δ_trans`。

**灵感 4（分布鲁棒组合：组合图上的最坏情况边权）**
直觉：第 54 轮 `G_S` 的边权是在 `D_in` 上估的。OOD 下应把边权替换为移位球内的最坏情况成本 `cost_wc(e) = sup_{D'∈B_ε(D_in)} E_{D'}[cost_align]`；只有最坏路径仍可部署，组合才真正 OOD-safe。这把动作兼容性从“平均可行”升级为“鲁棒可行”。

**灵感 5（“创新点”本身要被形式化：三元组判据）**
直觉：本项目已积累 120+ IP，最大危险不是想法不够，而是新瓶装旧酒。故引入创新点判据：一个创新点必须同时给出 (O) 新对象、(I) 新不变量、(F) 可证伪预测，并能与最近邻基线（IRM / DRO / Conformal / Domain Randomization）在 F 上区分。本轮主张的创新点是 **“动作支撑 OOD 证书 + 证书迁移”**：
- O：带有效域证书 `C=(g,𝓓_C,b_C,π_fb)` 与支撑逃逸率 `β_esc`；
- I：不变量“支撑内保证可迁移、支撑外保证必拒识”，即 `(a∈𝓓_C ⇒ g) ∧ (a∉𝓓_C ⇒ π_fb 满足 g_fb)`；
- F：若移除有效域判定（退化为纯 `ρ`），OOD 成功率应显著下降且置信区间不重叠；若真实移位是“支撑保持但语义反转”，则 `β_esc≈0` 而迁移界仍给出错误保证（此为本轮预设的证伪点）。

## 1. 形式化定义（增量：定义 121–128）

**定义 121（任务分布族与移位球）**
`D_in` 为标定分布，`𝓟` 为允许分布族，Wasserstein-1 移位球 `B_ε(D_in) = {D'∈𝓟 | W_1(D',D_in) ≤ ε}`。真实 OOD 分布 `D_ood` **可以不在球内**（A29 明确允许球外移位，这是后续 soundness 必须显式处理的漏洞来源）。

**定义 122（动作支撑与支撑逃逸分解）**
`supp_α(S) = {a∈A | α_S(a) ≥ θ_cov}`；支撑逃逸率 `β_esc(S,D) = P_{a~D}[a ∉ supp_α(S)]`。分解 `D = (1-β_esc)·D^{in} + β_esc·D^{out}`，其中 `D^{in}` 为条件化后的支撑内分布；in-support 移位 `d_in(D,D_in) = W_1(D^{in}, D_in^{in})`。

**定义 123（带有效域证书 CVD）**
证书 `C = (g, 𝓓_C, b_C, π_fb)`：
- `g` 为保证（如 `ρ` 下界或 `J` 联合证书）；
- `𝓓_C ⊆ A × Φ` 为有效域（动作 × 上下文）；
- `b_C ≥ 0` 为域边界裕度，`dist(∂𝓓_C, target) ≥ b_C` 才算“域内”；
- `π_fb` 为域外回退策略。
**soundness**：`(a,φ)∈𝓓_C ⇒ g`；`(a,φ)∉𝓓_C ⇒ π_fb` 必须满足安全下界 `g_fb`。证书不得在域外对 `g` 作任何承诺。

**定义 124（证书迁移算子）**
`T_{in→ood}: C_in ↦ C_ood`，由动作传输映射 `T_A:A→A` 与上下文映射 `T_Φ:Φ→Φ` 诱导，迁移损失
`Δ_trans = L_A·d_in + L_Φ·||T_Φ - id|| + Λ_int`，
其中 `Λ_int` 为不可迁移的语义断层项（本体/执行器改变导致含义漂移）。若 `Δ_trans > Θ_trans`，或 `𝓓_C ∩ supp(T_A(D_ood)) = ∅`，则**迁移拒绝**，证书不得搬用。

**定义 125（OOD 泛化风险界）**
```
R_ood(C) ≤ R_in(C) + L_A·W_1(D_in, D_ood) + β_esc·R_max + Λ_int + P(δ_a > Θ_a)
```
其中 `P(δ_a>Θ_a)` 承接第 54 轮动作对齐项。关键结构性结论：**`β_esc` 项不可能被鲁棒性谱 `ρ` 吸收**，只能由拒识/回退项 `π_fb` 承担；否则界为空（vacuous）。

**定义 126（分布鲁棒技能组合图）**
`G_S^DRO = (V,E, cost_wc)`，边权 `cost_wc(e) = sup_{D'∈B_ε(D_in)} E_{a~D'}[cost_align(e,a)]`。路径可部署当且仅当 `max_e cost_wc(e) ≤ B_task` 且 `β_esc(S_path, D_ood) ≤ β_max`。

**定义 127（创新点三元组）**
创新点 `I = (O, I_inv, F)`：`O` 为新对象，`I_inv` 为跨分布成立的可判定不变量，`F` 为可证伪预测。称 `I` 为真创新当且仅当存在基线集合 `𝔅`，使 `F` 对 `I` 与每个 `b∈𝔅` 给出**可区分**的预测（在给定实验分辨率下置信区间不重叠）。

**定义 128（拒识-回退策略）**
`π_fb: (a,φ) ↦ {degrade, abstain, handover}`，安全要求 `P(fail | π_fb) ≤ 1-ρ_fb` 且 `handover` 延迟 `≤ τ_loop`。回退本身也是被证书化的，不允许“无保证地降级”。

## 2. 关键算法 伪代码

### IP-121 SED（Support-Escape Decomposition）

```python
def support_escape(alpha, D_target, theta_cov=0.8):
    inside, outside = [], []
    for a, w in D_target.samples():          # (action, weight)
        (inside if alpha.get(a,0.0) >= theta_cov else outside).append((a,w))
    beta = sum(w for _,w in outside)
    D_in_cond  = normalize(inside)
    D_out_cond = normalize(outside)
    d_in = wasserstein1(D_in_cond, D_in.support_restricted(alpha))
    return EscapeReport(beta_esc=beta, d_in=d_in,
                        D_in_cond=D_in_cond, D_out_cond=D_out_cond)
```

### IP-122 CVD（Certificate with Validity Domain）

```python
def make_certificate(skill, rho, domain, margin, fallback):
    # domain 由 alpha + 上下文内核给出：{(a,phi) | alpha>=theta and k(phi)>=theta_phi}
    return Certificate(g=rho, domain=domain, boundary_margin=margin,
                       fallback=fallback)

def certificate_check(cert, a, phi):
    if cert.domain.contains(a, phi) and cert.boundary_dist(a,phi) >= cert.b_C:
        return ('apply', cert.g)
    return ('fallback', cert.fallback.decide(a, phi))
```

### IP-123 CTR（Certificate Transport）

```python
def transport_certificate(cert_in, T_A, T_Phi, D_ood, L_A, L_Phi, Theta_trans):
    d_in = cert_in.domain.in_support_shift(D_ood)
    Delta = L_A*d_in + L_Phi*norm(T_Phi - identity) + semantic_gap(cert_in, D_ood)
    mapped_support = T_A.supp(D_ood)
    if Delta > Theta_trans or cert_in.domain.is_disjoint(mapped_support):
        return ('reject', Delta)
    rho_ood = {d: max(0.0, cert_in.g[d] - Delta) for d in cert_in.g}
    domain_ood = map_domain(cert_in.domain, T_A, T_Phi, shrink=Delta)
    return ('ok', make_certificate(cert_in, rho_ood, domain_ood,
                                   cert_in.b_C - Delta, cert_in.fallback))
```

### IP-124 DRC（Distribution-Robust Composition）

```python
def dro_compose(G, shift_radius, eps, B_task, beta_max, D_ood):
    G_wc = G.copy()
    for e in G.edges:
        G_wc[e].cost = worst_case_cost(e, shift_radius)   # sup over B_eps(D_in)
    path = minmax_path(G_wc, goal)                        # 最小化最大边成本
    esc = support_escape(compose_alpha(path), D_ood)
    if max(G_wc[e].cost for e in path) > B_task or esc.beta_esc > beta_max:
        return ('reject', path, esc)
    return ('ok', path, esc)
```

### IP-125 NVT（Novelty Test）

```python
def novelty_test(claim, baselines, experiment):
    O, I_inv, F = claim
    results = {}
    for b in [claim] + baselines:
        results[b.name] = experiment.run(b)     # 返回 F 的观测 + CI
    claim_ci = results[claim.name].ci
    if any(overlaps(claim_ci, results[b.name].ci) for b in baselines):
        return ('not_distinguishable', results)
    if not experiment.falsifier_hit(claim):
        return ('not_falsifiable', results)
    return ('pass', results)
```

### IP-126 FBP（Fallback Policy）

```python
def fallback_plan(esc, cert, budget):
    if esc.beta_esc <= budget.beta_ok and not esc.D_out_cond:
        return ('degrade', cert.g)
    if esc.beta_esc <= budget.beta_max:
        return ('handover', {'latency': budget.tau_loop,
                             'safe_rho': cert.fallback_rho})
    return ('abstain', {'reason': 'support_escape'})
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| SED | O(\|D_target\|·\|A\|) | O(\|D_target\|) | 支撑判定阈值 sound、条件化无偏 |
| CVD | O(\|𝓓_C\|) 查询 | O(\|𝓓_C\|+\|Φ\|) | 域成员判定保守、边界裕度单调 |
| CTR | O(\|A\|+\|Φ\|) | O(\|A\|+\|Φ\|) | Lipschitz 常数可验、语义断层项非负 |
| DRC | O(\|E\|·\|B_ε\| + \|V\|log\|V\|) | O(\|V\|+\|E\|) | 最坏情况上界 sound、min-max 路径最优 |
| NVT | O(\|𝔅\|·T_exp) | O(\|𝔅\|) | 证伪器预注册、CI 口径一致 |

**正确性定理（Support-Aware OOD Soundness）**
假设第 54 轮 (A26)–(A28) 成立；新增 **(A29)** 真实 `D_ood` 可位于 `B_ε(D_in)` 之外，但 `β_esc` 可估；**(A30)** 传输映射 `T_A` 在 `supp_α` 上 Lipschitz，`L_A<∞` 且由留出集校准；**(A31)** 语义断层 `Λ_int` 有可计算上界；**(A32)** 回退策略 `π_fb` 的安全下界 `g_fb` 经独立评测。则对任意 `D_ood ∈ 𝓟`：
```
P(success | C_ood) ≥ 1 - [R_in(C_in) + L_A·W_1 + β_esc·R_max + Λ_int + P(δ_a>Θ_a) + P(fail|π_fb)·β_esc]
```
且若 `Δ_trans > Θ_trans` 或支撑不交，则 `C_ood` **不得**被颁发，系统只能走 `π_fb`。**核心不变量**：证书在 `𝓓_C` 内的承诺与迁移误差单调挂钩；`𝓓_C` 外的承诺一律为空，绝不外推。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 支撑保持但语义反转的移位（`β_esc≈0`） | 高 | 语义探针 + 反事实动作对 + `Λ_int` 强制非零惩罚 |
| `T_A` Lipschitz 常数跨域失真 | 高 | 分域校准 + 保守上界 + 迁移拒绝闸门 |
| `β_esc` 估计依赖 `D_ood` 采样 | 高 | 分层重要性采样 + 主动 OOD 探测 + 对抗任务生成 |
| 最坏情况边权导致组合过保守 | 中 | 分层 `ε` 网格 + 风险预算自适应 |
| “创新点”被审稿人判为 DRO+Conformal 重命名 | 高 | 预注册 NVT、明确不变量与证伪点、消融有效域判定 |

## 6. 本轮最大风险

**一句话**：把 OOD 泛化等同于“动作支撑逃逸”是本轮全部 soundness 的地基，但一旦真实移位是**支撑保持而语义反转**（support-preserving semantic shift）——例如同一动作在不同本体上含义相反——`β_esc≈0` 会让迁移界自信地给出“可迁移”的错误保证；更糟的是，若不做有效的基线区分，本轮所谓创新点可能只是 DRO 与 Conformal 的重新包装，因此必须以 **语义断层项 `Λ_int` + 预注册证伪实验 E166** 把这条最危险的失败模式钉死，宁可拒绝迁移，也不颁发一张“域内为真、域外为假”的漂亮证书。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-OOD-Cert（SED×CVD×CTR×DRC×NVT×FBP）

> 承接第 54 轮产物 v31。上一轮把技能做成“动作空间占用 + 动作-鲁棒性双证书”，但所有保证都默认在标定分布 `D_in` 上成立。本轮把 **分布外泛化** 从经验愿望升级为可判定命题，并用 **创新点三元组** 对新增贡献做自我审计：
> - **SED（Support-Escape Decomposition）**：把任意移位拆成“支撑内重加权 + 支撑外逃逸”；
> - **CVD（Certificate with Validity Domain）**：证书携带有效域与回退策略，域外不外推；
> - **CTR（Certificate Transport）**：把 `D_in` 的保证按 Lipschitz/传输误差搬运到 `D_ood`，搬不动就拒绝；
> - **DRC（Distribution-Robust Composition）**：技能组合图边权换成移位球内最坏情况成本；
> - **NVT（Novelty Test）**：用 (O,I,F) 三元组与 IRM/DRO/Conformal/Domain Randomization 做可证伪区分；
> - **FBP（Fallback Policy）**：域外拒识/降级/移交也被证书化。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-115/118/120 以纳入有效域与迁移误差。

```python
    for a, w in D_target.samples():
        (inside if alpha.get(a,0.0) >= theta_cov else outside).append((a,w))
    beta = sum(w for _,w in outside)
    D_in_cond  = normalize(inside)
    D_out_cond = normalize(outside)
    d_in = wasserstein1(D_in_cond, D_in.support_restricted(alpha))
    return EscapeReport(beta_esc=beta, d_in=d_in,
                        D_in_cond=D_in_cond, D_out_cond=D_out_cond)
```

```python
def transport_certificate(cert_in, T_A, T_Phi, D_ood,
                          L_A, L_Phi, Theta_trans):
    d_in = cert_in.domain.in_support_shift(D_ood)
    Delta = (L_A*d_in
             + L_Phi*norm(T_Phi - identity)
             + semantic_gap(cert_in, D_ood))
    mapped_support = T_A.supp(D_ood)
    if Delta > Theta_trans or cert_in.domain.is_disjoint(mapped_support):
        return ('reject', Delta)
    rho_ood = {k: max(0.0, cert_in.g[k] - Delta) for k in cert_in.g}
    domain_ood = map_domain(cert_in.domain, T_A, T_Phi, shrink=Delta)

                                   cert_in.b_C - Delta, cert_in.fallback))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SED | O(\|D_target\|·\|A\|) | O(\|D_target\|) | 支撑判定与条件化无偏，`β_esc` 可估 |
| CVD | O(\|𝓓_C\|) 查询 | O(\|𝓓_C\|+\|Φ\|) | 域成员判定保守，边界裕度单调 |
| CTR | O(\|A\|+\|Φ\|) | O(\|A\|+\|Φ\|) | Lipschitz 可验，`Λ_int≥0`，超预算必拒 |
| DRC | O(\|E\|·\|B_ε\|+\|V\|log\|V\|) | O(\|V\|+\|E\|) | 最坏情况上界 sound，min-max 路径最优 |
| NVT | O(\|𝔅\|·T_exp) | O(\|𝔅\|) | 证伪器预注册，CI 口径一致 |

**正确性定理（Support-Aware OOD Soundness）**
假设第 54 轮 (A26)–(A28) 成立；新增 **(A29)** 真实 `D_ood` 可位于 `B_ε(D_in)` 外但 `β_esc` 可估；**(A30)** `T_A` 在 `supp_α` 上 Lipschitz 且由留出集校准；**(A31)** 语义断层 `Λ_int` 有可计算上界；**(A32)** `π_fb` 的安全下界 `g_fb` 经独立评测。则对任意 `D_ood∈𝓟`：
```
P(success | C_ood) ≥ 1 - [R_in(C_in) + L_A·W_1 + β_esc·R_max
                         + Λ_int + P(δ_a>Θ_a) + P(fail|π_fb)·β_esc]
```
且当 `Δ_trans > Θ_trans` 或 `𝓓_C ∩ supp(T_A(D_ood)) = ∅` 时，`C_ood` 不得颁发，系统只能执行 `π_fb`。**不变量**：证书承诺随迁移误差单调衰减，域外承诺恒为空。

**创新点定位（NVT 自查）**

| 维度 | 本方案 OOD-Cert | IRM | DRO | Conformal | Domain Rand. |
|---|---|---|---|---|---|
| 新对象 O | 带域证书 `C=(g,𝓓_C,b_C,π_fb)` + `β_esc` | 不变风险惩罚项 | 最坏分布损失 | 预测集/覆盖率 | 随机化训练分布 |
| 新不变量 I | 域内可迁移、域外必拒识 | 环境不变预测器存在 | 球内最坏风险有界 | 边际覆盖率 | 无（经验） |
| 可证伪预测 F | 去掉 `𝓓_C` 判定 OOD 成功率显著下降；语义移位触发拒迁 | 跨环境误差差 | 球外失效 | 分布无关覆盖 | 支撑外无保证 |

> 结论：本轮的真创新锚点是 **“把 OOD 泛化转化为动作支撑逃逸 + 证书迁移”**，DRO 只提供最坏情况边权工具，Conformal 只提供覆盖率口径；本方案的可判定不变量（域外承诺为空 + 迁移拒绝闸门）是二者都不具备的。
