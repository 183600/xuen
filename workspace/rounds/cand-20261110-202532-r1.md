# 第 47 轮（承接第 46 轮 v23；本轮灵感：本体感知 × 通信延迟） · Proprio-Delay：本体感知锚定的时间一致性证书与端到端延迟预算（架构 v11）

> 承接第 46 轮 v23 Memory-Safety-Voice。v23 用记忆检索、语音意图、能量租约、姿态证书构成全局决策 Π，但仍隐含 H5：所有子系统共享同一时刻、零延迟同步的“now”。真实 UniBot 栈中相机、VLM、ECPS、语音、CAR、执行器分布在不同进程/板卡，消息从 t_sense 到 t_exec 存在 20–200ms 延迟与时钟偏移；v23 的 P_t、ℓ_e、B(v,P) 都是在旧快照上算出的。两个灵感词精确命中 H5：**本体感知**是唯一本地、高频、低延迟的自身运动测量，可把“上一刻的外部感知”推进到“执行时刻”；**通信延迟**迫使每张证书变成带时效的时间索引证书，并需要端到端延迟预算。三者耦合的新问题：**当用本体感知跨越延迟盲区时，接触/打滑/标定偏差会让外推误差快速累积，而时钟偏移又会低估数据年龄——证书看似新鲜、实际已静默过期，并级联至安全谓词**。

## 0. 直觉与动机

**灵感 1（本体感知 → 有界时域的时间锚）**
直觉：闭眼走两步。外部视觉描述“世界在 t_sense 时的样子”，本体感知描述“我从那以后如何运动”，两者复合才能得到执行时刻的自身状态。但闭眼越久，漂移越大，所以本体感知只能提供**有界时域**的外推，跨不过去就必须重感知。

**灵感 2（通信延迟 → 证书的保质期与 deadline 调度）**
直觉：没有时间戳的证书等于谎言。延迟把几何不确定性转化为时间不确定性：同一半径的证书，100ms 后可能已不覆盖真实状态。因此每张证书都要有有效期 H_c，并用实时系统的 EDF 思路把端到端预算分配到传感/推理/通信/执行各段。

**灵感 3（耦合 → 速度作为时间缓冲）**
直觉：走得慢，状态移动得少，证书就能“活”得更久。于是延迟预算、限速、证书半径三者可以联合调节：v_cmd≤r_tol/a_act。但接触/打滑会破坏外推区间，一旦漂移界失效，降速也不再安全，必须收缩时域或 fail-closed。

**架构升级**：在 v23 五链路之上补上“时间”维度。根信任层增加**统一时基与延迟台账**；L1 几何层由本体感知输出时间索引状态区间；L2 记忆/语音检索以 (age, clock epoch) 为键；L3 CAR 守卫增加年龄与时域判据；L4 DCL 采集带延迟标签的样本用于标定漂移界。

## 1. 形式化定义（增量：定义 59–63）

**定义 59（统一时基与延迟台账）**
每条消息 i 记录 τ_i=(t_i^sense, t_i^pub, t_i^recv, t_i^exec)，本地单调钟有界偏移 |δ(t)|≤ε_clk。数据年龄 a_i(t)=t−t_i^sense。延迟台账
L={ (i, t_i^sense, t_i^recv, d_i, a_i) }，
其中 d_i 为该证书的软截止期。**新鲜判据**：a_i(t)≤H_i 且 |δ(t)|≤ε_clk，否则证书作废。

**定义 60（本体感知状态传播与漂移界）**
本体状态 s_t=(q, q̇, τ, p, R, v, ω)，由关节编码器/力矩 + IMU 得到。外推 x̂_t=Φ(s_{t0}, u_{t0:t})，区间误差
e_prop(a)=e_0+L_p·a+½L_a·a²，
L_p 由未建模动态与接触决定，L_a 由 jerk 界决定；接触/打滑检测 c_t=1 时令 L_p←k_c·L_p（k_c>1）。输出区间 I_prop=[x̂−e_prop, x̂+e_prop]。

**定义 61（时间索引姿态证书）**
P_{t|t0}=Ball(x̂_{t|t0}, r_ω(m)+ρ(a))，
ρ(a)=L_φ·rad(P_{t0})+v_max·a+½a_max·a²+e_prop(a)+ε_clk·v_max。
**时间索引 soundness**：若 a≤H_c 且 I_prop 覆盖真实相对运动，则
P(X_t∈P_{t|t0} | ω_t,m_t) ≥ 1−α_p。
证书时域 H_c=max{a : ρ(a)≤r_max−r_ω}。

**定义 62（端到端延迟预算）**
把总预算 D_e2e 分解为传感 D_s、推理 D_i、调度 D_p、通信 D_n、执行 D_a，ΣD≤D_e2e；用到达-服务曲线给各段上界。证书必须在截止期 d_c=t0+H_c 前到达执行器。调度采用 EDF，截止期为 d_c；若 d_c 不可达则触发降速/重感知/fail-closed。

**定义 63（延迟感知联合证书与时间绑定）**
联合证书 J_t=(P_{t|t0}, ℓ_p, ℓ_e(a_e), m_t, a_max, d_act)。时间绑定
B(v_t,P_{t|t0},ω)=P(g(v)∈g(P_{t|t0})|a≤H_v)，
其中 g(·) 把语音意图与姿态盒映射到机械臂锚点集合。**可行执行判据**：
a_voice≤H_v, a_pose≤H_p, a_energy≤H_e, d_act≤min(H_p,H_v,H_e), B≥θ_safe；
否则重校验、入安全队列或 fail-closed。速度-时域耦合 v_cmd≤r_tol/a_act。

## 2. 新增 IP 与既有升级

**IP-69 PROPRIO-ANCHOR（PA）**
- 1kHz 本体缓冲、时间戳插值与区间传播
- 接触/打滑检测（力矩突变、足端/轮端滑移、IMU 冲击）
- 漂移界在线标定：视觉残差回灌更新 L_p
- 输出 x̂_{t|t0}、I_prop、外推时域 H_prop

**IP-70 DELAY-LEDGER（DL）**
- 每消息打点，(t_sense,t_pub,t_recv,t_exec) 全链路追踪
- 时钟偏移保守估计与突变检测
- 逐 topic 年龄直方图/p99 与软截止期
- EDF + 预算分配，输出陈旧告警与降级信号

**IP-71 TEMPORAL-BINDER（TB）**
- 在执行时刻预测状态上计算安全绑定 B
- 年龄/时域/时钟三重守卫
- 速度-时域耦合限速
- 与安全队列协同：按剩余时域重排、超时撤回

**既有 IP 升级**
IP-60 PSE：签发时间索引证书 P_{t|t0}，同时返回 H_c 与 age
IP-63 ECPS：能量租约带年龄；电池遥测陈旧时按最坏放电外推，模态预热预留 d_act
IP-66 MVR：记忆键加入 (age, clock epoch)，命中后必须用当前延迟预算重验，不直接复用
IP-67 VAD：语音意图携带 ASR/NLU 延迟，t_exec 处重校验，过期则二次确认
IP-68 SAB：B 改为 B(v,P_{t_exec|t0})，安全队列按截止期管理
IP-51 CAR：守卫加入 a≤H 与 |δ|≤ε_clk
IP-61 DCL：采集延迟标签与接触标签样本，用于标定 L_p 与 p99
IP-62 CCA：新增延迟注入、时钟阶跃/漂移、乱序重放、接触打滑红队
IP-45 总线：proprio/state-interval、timestamp、delay-ledger、staleness、clock-sync 话题

## 3. 算法骨架

```
def proprio_propagate(s0, t0, t_exec, imu, contact, Lp0, La, e0):
    a = max(0.0, t_exec - t0)
    s_hat = integrate(s0, imu[t0:t_exec])
    Lp = Lp0 * (K_CONTACT if contact else 1.0)
    e = e0 + Lp*a + 0.5*La*a*a
    return s_hat, e

def time_indexed_cert(c0, t_exec, imu, contact, eps_clk, vmax, amax, rmax):
    a = t_exec - c0.t_sense
    s_hat, e_prop = proprio_propagate(c0.s, c0.t_sense, t_exec,
                                      imu, contact, Lp0, La, e0)
    rho = c0.r0 + L_PHI*c0.rad0 + vmax*a + 0.5*amax*a*a + e_prop + eps_clk*vmax
    if rho > rmax:
        return None
    return Cert(center=s_hat, radius=rho, t_exec=t_exec, age=a)
```

```
def temporal_dispatch(v, c0, lease, ledger, now):
    d_act = ledger.p99('actuator')
    t_exec = now + d_act
    if ledger.age(v, t_exec) > H_VOICE:
        return 'revalidate_voice'
    if ledger.age(lease, t_exec) > H_ENERGY:
        lease = lease.worst_case_refresh()
    c1 = time_indexed_cert(c0, t_exec, ledger.imu, ledger.contact,
                           ledger.eps_clk, ledger.vmax, ledger.amax, R_MAX)
    if c1 is None or ledger.clock_violated():
        return 'fail_closed'
    B = safety_bind(v, c1, ledger.omega)
    if B < THETA_SAFE:
        push(Q_safe, (v, deadline=t_exec + H_VOICE))
        return 'queued'
    v_cmd = min(ledger.v_limit, (R_MAX - c1.radius) / max(d_act, 1e-3))
    return ('act', c1, v_cmd)
```

## 4. 本轮最大风险

**一句话**：用本体感知跨越通信延迟盲区时，最大的风险是接触/打滑使漂移界悄然失效、而时钟偏移又低估数据年龄，导致时间索引证书“看起来新鲜”但已不覆盖真实位姿；必须在接触感知时放大误差界、保守估计时钟偏移，并在时域边界默认重感知或 fail-closed。

## 2. 关键算法伪代码

### IP-70 延迟台账与时钟界
```
def stamp(payload, t_sense):
    return Msg(payload=payload, t_sense=t_sense,
               t_pub=monotonic(), t_recv=monotonic())

def age(msg, t_exec):
    return t_exec - msg.t_sense

def clock_bound(samples):
    # samples: [(t1,t2,t3,t4)] 双向时间戳
    # NTP 下界：|offset| <= ((t2-t1)-(t3-t4))/2
    return max(abs(((t2 - t1) - (t3 - t4)) / 2.0)
               for t1, t2, t3, t4 in samples)

def edf_push(ledger, cert, deadline):
    ledger.push(deadline, cert)
    if ledger.p99('actuator') > ledger.budget_act(D_e2e):
        return 'degrade'   # 降速 / 重感知 / fail-closed
    return 'ok'
```

```
    a = t_exec - c0.t_sense
    s_hat, e_prop = propagate_interval(c0.s, c0.t_sense, t_exec,

def temporal_global_decision(v, c_t, B_t, c0, lease, M, ledger, now):
    d_act = ledger.p99('actuator')
    t_exec = now + d_act
    # 1) 记忆检索先做时基校验
    mem, dist = memory_lookup(v, c_t, B_t, M, epoch=ledger.clock_epoch)
    if mem is not None and age(mem, t_exec) <= H_MEM:
        cand, mode = mem.m, 'memory'
    else:
        cand, mode = mvr_schedule(c_t, B_t, v, M, calib, S_phi)[0], 'realtime'
    # 2) 语音意图时效
    if age(v, t_exec) > H_VOICE:
        return 'revalidate_voice'
    # 3) 能量租约时效
    if age(lease, t_exec) > H_ENERGY:
        lease = lease.worst_case_refresh()
    # 4) 时间索引姿态证书
    c1 = time_indexed_cert(c0, t_exec, ledger.imu, ledger.contact,
                           ledger.eps_clk, ledger.vmax, ledger.amax, R_MAX)
    if c1 is None or ledger.clock_violated():
        return 'fail_closed'
    # 5) 执行时刻安全绑定
    B_prob = safety_bind(v, c1, ledger.omega)
    if B_prob < THETA_SAFE:
        push(Q_safe, (v, deadline=t_exec + H_VOICE))
        return 'queued'
    v_cmd = min(ledger.v_limit, (R_MAX - c1.radius) / max(d_act, 1e-3))
    return ('act', cand, c1, v_cmd, mode)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| PA 区间传播 | O(N)（增量可 O(1)） | O(N) | 接触放大后区间仍覆盖真实相对运动 |
| DL 打点/年龄 | 插入 O(log N)，查询 O(1) | O(N) | 年龄上界与截止期可审计 |
| TB 时间证书 | O(N) | O(1) | a≤H 且 I_prop 覆盖 ⇒ 1−α soundness |
| 全局时间决策 | O(Q+N) | O(Q) | 任一超时/时钟违约 ⇒ fail-closed |

正确性定理：设 |δ(t)|≤ε_clk，所有消息年龄不超过各自时域，且本体区间 I_prop 以概率 ≥1−α_p 覆盖真实相对运动。则对任意执行时刻 t_exec，真实状态 X(t_exec)∈P_{t_exec|t0} 以概率 ≥1−α_p。时间绑定器仅在 B≥θ_safe 且三张证书年龄均在时域内时下发动作，因此 v23 的联合 soundness 在非零延迟下仍成立；任一时域违约即 fail-closed，不会静默执行过期证书。证明要点：外推误差用三角不等式累加，ρ(a) 对 a 单调递增，时钟偏移上界并入半径。

## 4. 实验设计 E115–E121

| 实验 | 指标 | 门槛 |
|---|---|---|
| E115 时钟同步 | 偏移估计误差、年龄误差 | 偏移误差 ≤1ms；年龄误差 ≤5ms |
| E116 本体外推漂移 | 20/50/100ms 位置误差、区间覆盖率 | 100ms 误差 ≤3cm；覆盖率 ≥99% |
| E117 延迟注入 | 0–300ms 下证书违例率 | 阈值内违例 0 起 |
| E118 陈旧检测 | 过期证书检出率、误报率 | 检出 ≥99.9%；误报 ≤1% |
| E119 速度-时域权衡 | 吞吐量、最大安全速度 | 吞吐下降 ≤20% |
| E120 接触/打滑 | 漂移界触发率、恢复时间 | 触发 ≥95%；恢复 ≤200ms |
| E121 100h 闭环 | 安全违例、p99 延迟、降速次数 | 0 违例；p99≤预算；降速 ≤5% |

回退策略：E115 时钟误差超界 → 提高 ε_clk 并默认限速；E116 漂移超界 → 缩短 H_prop、提高重感知频率；E117 出现违例 → 关闭本体长时域外推，仅在 a≤a_safe 内使用；E120 接触检测漏检 → 保守把 k_c 调大并触发 fail-closed。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 时钟偏移/阶跃低估年龄 | 高 | 单调钟 + 保守 ε_clk + PTP；偏移突变直接 fail-closed |
| 接触/打滑使漂移界失效 | 高 | 接触检测放大 L_p，视觉残差在线标定，超界重感知 |
| 本体外推过长 | 中 | H_prop 硬上限；超时禁止继续信任外推 |
| 延迟台账估计偏低 | 中 | 使用 p99 + 安全裕度；EDF 预留执行段预算 |
| 记忆复用忽略时基 | 中 | 记忆键含 age/epoch，复用前重验 |
| 限速损伤任务吞吐 | 低 | 任务层速度预算，优先保安全再优化效率 |

## 6. 本轮最大风险

**一句话**：最大的风险是本体漂移界与时钟偏移同时失守，使通信延迟被“隐藏”而不是被“消除”——旧证书在执行时刻已经过期却被判为新鲜；因此必须把接触/打滑、时钟突变、时域边界都作为硬失效条件，宁可降速、重感知或 fail-closed。
