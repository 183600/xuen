## 1. 两个灵感的第一性原理

### 灵感 1 ·「多模态大模型」→ 缺的不是更聪明的策略，是「语义状态」

**直觉**：第 3 轮的状态层是**几何**的——在哪、目标是谁、卡没卡。但真实失败常是**语义**的：「我以为还在接近，其实已经抓住了」（相位错）、「我在该拉的地方推」（可供性错）、「抓的是盖子不是杯子」（角色错）、「该重抓却在对齐」（恢复策略错）。几何给不了这些标签，多模态大模型（MLLM）能给。但 MLLM 慢、贵、会幻觉；2026 的 Guardian 结果显示其失败检测误差 **68–93% 属感知而非推理**。所以正确用法不是把 MLLM 塞进快环，而是**语义先验，不是证据**：事件触发、缓存、经**异质**（几何/运动学/本体感受）门控后才允许影响慢环。

**严谨定义**：语义状态 U19、跨模态门控 U20；门控精度放大 L14；陈旧预算 L16。

- **语义只作先验（P13）**：MLLM 产出 `phase / role / affordance / failure-hypothesis`，写入 IP-13 的场景图，不直接产生动作、不直接改伺服。
- **门控必须异质**：用第二个 MLLM 自证会共享同一感知误差（Guardian 的教训），门控要用几何/运动学/夹爪标量这类**不同模态**的残差。
- **慢环优先**：语义只改先验、候选排序、介入选择，不改高频伺服；超 TTL 即失效。

### 灵感 2 ·「真机评测」→ 真机是唯一标尺，所以要把它当「仪器」而非「次数」

**直觉**：真机评测是唯一 ground truth，但稀缺、昂贵、有噪声。2026 的外部工作已把「世界模型/VLM 当评测器」推到聚合相关很高（RoboWorld r=0.989；Veo 能排对序但绝对值偏低；R2S-Eval 做真到仿校准）。但**聚合相关掩盖按单元格的系统偏差**：代理可能在「遮挡下插入」「未见可变形物体」上系统性错，却因平均分高而显得可信。挑战按成功率 + 步骤分计分（F1），榜单将含任务级粒度（F5）——这要求我们按**单元格（六因子 × 五轴）**给出**校准证书**，并用主动实验设计花真机预算。

**严谨定义**：校准证书 U21、主动真机预算 U22；样本复杂度下界 L15。

- **评测即仪器（P14）**：未认证单元格报「未知」不报「零」；证书带 TTL；代理分数不得跨出证书覆盖范围做决策。
- **主动预算**：真机时段花在「缺证书且决策敏感」的单元格，而非均匀多跑（L15 证明全认证预算不够，选择是强制的）。
- **读数自动化**：用 MLLM 离线失败归因（IP-18）把真机回放灌进矩阵，降低人工，但带 judge certificate（与人类 κ）。

**策略含义**：第 3 轮把「现在在哪、目标是谁、卡没卡」交给几何状态层；本轮把「现在处于哪个语义阶段、该怎么恢复」交给**语义层**（IP-16），把「我们到底该信代理多少分」交给**评测仪器层**（IP-17/18）。两者共用一条纪律：**MLLM 只在慢环、只作先验、必须被异质量门控或人类锚定**——这既是技术选择，也是防止「评测闭环自证」的护城河。

## 2. 研究问题（新增 Q13–Q16，接第 1–3 轮 Q1–Q12）

- **Q13（语义状态的门控收益）**：事件触发 + 几何门控的 MLLM 语义状态，能否在**不增加 ACTION REJECTED、不超延迟预算**的前提下，改善几何状态层之上的相位/角色/恢复判断（门控后精度 ≥0.9 @ 召回 ≥0.6）？（E634/E637）
- **Q14（MLLM 失败归因的可信度）**：MLLM 离线把真机 episode 归因到六因子 × 五轴矩阵，与人类标注的一致性（κ）能到多少？对「伪成功/自纠正」类世界模型假阳性是否稳健？（E635）
- **Q15（真机预算的主动分配）**：固定真机预算下，按单元格「主动校准」相比「均匀多跑」，能否显著提高认证覆盖率、降低决策后悔？未认证单元格「诚实报未知」的代价是否可接受？（E636）
- **Q16（语义陈旧与延迟）**：语义标注的 TTL 如何设定？陈旧标注进入闭环的致害是否低于门槛？异步语义能否满足 U12 延迟预算？（E637）

## 3. 设计原则（新增 P13–P15，接第 1–3 轮 P1–P12）

- **P13（语义只作先验，不作证据）**：MLLM 输出只能改变先验/候选/慢环，不能直接触发不可逆动作；进入快环必须通过**异质**跨模态门控（几何/运动学/本体感受），不得用同族 MLLM 自证。
- **P14（评测即仪器，须带证书）**：任何代理评测数字在未被校准证书覆盖的单元格上不得用于决策；未认证单元格一律报「未知」而非「零」；证书带 TTL；真机预算按信息价值主动分配。
- **P15（陈旧即无效）**：语义标注带 TTL，超过 `T_sem` 自动失效，不得进入闭环；异步语义只作慢环先验并带指数衰减权重。

## 5. 本轮最大风险

**评测闭环自证（judge–proxy–state 三者共谋）**：若同一个 MLLM 家族既产生语义先验（IP-16）、又标注真机失败（IP-18）、又参与代理评分（IP-17），误差会**相关**——代理恰好在「这个 MLLM 懂的单元格」上显得校准良好，证书变成自我确认，制造出比无校准更危险的**假信任**。对冲：①门控用异质几何模态；②留出一个从不参与前两者的 judge 模型做锚；③人类抽检做绝对锚点；④伪成功/自纠正对抗探针（dWorldEval 类）。次要风险：MLLM 感知误差主导（只作先验 + 证据帧 + 几何门控）、真机预算不足致 CI 过宽（诚实报未知 + 主动分配 + 证书 TTL）、语义延迟/成本（事件触发 + 缓存 + 异步）。

（一句话）最大风险：**评测闭环自证——当语义、标注、评分共用同一模型时，校准证书会自我确认，把「未知」伪装成「可信」。**

## 3. 新增 IP 详述

### IP-17 · EvalInstrument 单元格校准证书 + 主动真机预算（P0，新）

- **动机**：真机评测是唯一 ground truth 但稀缺；2026 的外部工作（RoboWorld r=0.989、Veo 排序一致、R2S-Eval 真到仿校准）把聚合相关推得很高，却**普遍不报按单元格的系统偏差**。挑战按成功率 + 步骤分计分（F1）、榜单将含任务级粒度（F5），一个平均分高的代理完全可能在「遮挡下插入」「未见可变形物体」上系统性错。把代理当「仪器」而非「分数」，是让 IP-06 的结论可决策的唯一严谨方式。
- **与现有方案差异**：不造新评测器，而是给已有代理（IP-06）与外部世界模型加一层**计量学**：每单元格输出 `(n, bias, CI, valid)`；未认证报「未知」；真机预算按信息价值主动分配（L15 证明全认证预算必然不够，选择是强制的）。
- **技术可行性**：高。核心是统计（偏差/CI/TTL）+ 少量真机时段；IP-18 降低人工读数成本。
- **资源**：真机时段 B（稀缺、需预约）；IP-06 的 6×5 矩阵提供单元格定义；IP-18 提供批量读数。
- **落地步骤**：①单元格定义（6 因子 × 5 轴）；②证书 schema 与认证规则（`CI ≤ ε` 且 `n ≥ n_min`）；③主动分配（贪心最大化「认证覆盖 × 决策权重」，每单元格保留最小 n）；④对接 IP-06 代理与世界模型读数；⑤证书 TTL 与漂移重认证；⑥E636。
- **风险**：预算不足致 CI 过宽（→ 诚实报「未知」，不硬下结论）；分布漂移（→ 证书 TTL）；**与 IP-16/18 共用 MLLM 致自证（见 §10 头号风险）**。

### IP-16 · SemanticState 语义先验层（P1，新）

- **动机**：IP-13 的几何状态回答不了「在哪个语义阶段、该用哪种抓法、这是不是误判、该换什么策略」。这些是语义量，MLLM 是现成来源；但 Guardian(2026) 显示其失败检测误差 68–93% 属感知而非推理，故只能作先验、必须异质门控。
- **与现有方案差异**：不换端到端 VLA 大脑、不把 MLLM 放快环；只做低频/事件触发的语义标注，写入 IP-13 图，门控后才影响慢环。门控是几何/运动学/夹爪残差，而非第二个 MLLM。
- **技术可行性**：中高。推理服务可自部署；事件触发把调用压到每 episode O(10) 次；缓存 + TTL 控成本。
- **资源**：一个 VLM 推理服务（单卡或 API）；无训练。
- **落地步骤**：①语义 schema（phase / role / affordance / failure-hypothesis + 置信 c + 时间戳 τ）；②触发条件（断言不确定区、复读检测命中、大光流、新干扰物）；③异质门控（角色掩码 vs 跟踪目标；phase vs 路标索引/夹爪状态；affordance vs 几何供抓性）；④TTL 与异步队列；⑤接入 IP-02 介入选择 / IP-15 干扰分类 / IP-04 特征；⑥E634/E637。
- **风险**：幻觉过门（头号风险）；延迟与成本；感知误差主导（→ 证据帧 + 几何门控 + 只作先验）。

### IP-18 · FailureJudge MLLM 失败归因（P1，新，并入 IP-06 标注器）

- **动机**：六因子 × 五轴矩阵的标注是真机评测的瓶颈；真机回放量大、人工贵。MLLM 可离线把 episode 归因到因子与轴，把 IP-17 的读数成本压下来。
- **与现有方案差异**：离线、非闭环、带 **judge certificate**（与人类 κ）；对「伪成功 / 自纠正」做对抗探针（dWorldEval 指出的世界模型把失败「修」成假阳性问题）。
- **技术可行性**：中。FAER / Guardian / RoboFailRing 显示 VLM 失败归因可行但感知误差大 → 用「证据帧 + 结构化 rubric + 多帧」；只做候选归因 + 人工抽检。
- **资源**：真机回放（官方 runs 页开放后可用，F5）；人标约 100 条做 κ 校准；MLLM 推理。
- **落地步骤**：①六因子 rubric 与证据帧选择协议；②人标 100 条做 κ；③对抗集（伪成功/自纠正/遮挡误判）；④批量归因 → 矩阵 → 供 IP-17；⑤E635。
- **风险**：感知误差主导（→ 只做候选 + 抽检）；κ 不达标则降级为「检索辅助」，不自动灌矩阵；与 IP-16/17 共用模型致自证。

## 5. 符号与定义（新增 U19–U22；U1–U18 沿用第 1–3 轮）

- **定义 U19（语义状态）**：`S = {(φ, r, A, h, c, τ)}`，φ=任务阶段标签，r=目标/物体角色，A=可供性候选集，h=失败假设，c=置信，τ=生成时间戳；由 MLLM oracle 在事件触发时产生，写入场景图 `M`；语义是**标注性**而非度量性，不参与几何断言。
- **定义 U20（跨模态门控）**：`G : (S, M_geo) → {accept, quarantine, reject}`。`accept` ⇔ 语义声明与几何/运动学/夹爪状态一致（如角色 r 的掩码与跟踪目标在门内、phase φ 与路标索引和夹爪状态相容）；`reject` ⇔ 矛盾；`quarantine` ⇔ 不可验证。仅 `accept` 可影响快环；`quarantine` 仅供慢环/离线。
- **定义 U21（校准证书）**：对矩阵单元格 `(f,a)`，`C_{f,a} = (n, b̂, CI, v)`，`b̂` 为代理与真机的偏差（或秩不一致度），`CI` 为置信区间，`v=1` ⇔ `CI 宽度 ≤ ε 且 n ≥ n_min`。决策规则：代理分数仅在 `v=1` 的单元格可用于决策，其余报「未知」；证书带 TTL。
- **定义 U22（主动真机预算）**：给定预算 `B`（真机 episode 数）与单元格权重 `w_{f,a}`（决策敏感度），选 `{n_{f,a}}` 使 `Σ n_{f,a} ≤ B` 且最大化 `Σ w_{f,a}·1[C_{f,a}.v=1]`（或最小化期望决策后悔）；每单元格保留最小 `n_min` 以保 CI 可估。

## 6. 关键算法骨架（新增片段；主体沿第 1–3 轮 `UniBotSAGEPolicy`）

```python
# ===== IP-16: 语义先验层（低频 + 事件触发 + 异质门控 + TTL）=====
class SemanticState:
    def __init__(self, oracle, ttl):
        self.oracle, self.ttl = oracle, ttl
        self.claims = []                     # U19 标注列表

    def maybe_update(self, obs, scene, trigger):
        if not trigger:                      # 触发: 断言不确定区/复读/大光流/新干扰物
            return
        raw = self.oracle.annotate(obs, scene)          # 异步、慢、可失败
        self.claims = [self.gate(c, scene) for c in raw]

    def gate(self, c, scene):                # U20: 异质门控（几何/运动学/夹爪）
        if contradicts_geometry(c, scene):   # 角色与跟踪目标不符 / phase 与路标矛盾
            return c._replace(status="reject")
        if not verifiable_geometrically(c, scene):
            return c._replace(status="quarantine")
        return c._replace(status="accept")

    def prior(self, now):                    # P13/P15: 只给慢环，且未过期
        return [c for c in self.claims
                if c.status == "accept" and now - c.tau <= self.ttl]
```

```python
# ===== IP-17: 校准证书 + 主动真机预算（U21/U22）=====
def certificate(cell, real, proxy, eps, n_min, z):
    n = len(cell.samples)
    b = mean(proxy - real)
    ci = z * std(proxy - real) / sqrt(max(n, 1))
    return Cert(n=n, bias=b, ci=ci, valid=(n >= n_min and ci <= eps))

def allocate(B, cells, weights, n_min):
    alloc = {c: n_min for c in cells}        # 每单元格保底（CI 可估）
    left = B - sum(alloc.values())
    if left <= 0:
        return alloc                         # 预算不足: 只保底, 其余报「未知」
    while left > 0:                          # 贪心最大化边际认证权重/成本
        c = max(cells, key=lambda c: weights[c] * marginal_gain(c, alloc[c]))
        alloc[c] += 1
        left -= 1
    return alloc
```

## 7. 推导（新增引理 L14–L16；L1–L13 沿用第 1–3 轮）

**引理 L14（异质门控的精度放大）** 设语义声明正确的先验概率为 `p`；门控对正确声明通过率 `γ`，对错误声明误放率 `β`。则进入快环的声明精度 `p' = γp / (γp + β(1−p))`，召回 `r' = γp`。于是 `p' > p ⇔ β < γ`（误放率低于通过率）；门控把精度放大到 `p'`，代价是召回降为 `γp`。若门控为**异质几何量**（与 MLLM 感知误差不共享），`β` 可压到很小，`p'≈1`；若门控用同族 MLLM 自证，`β` 与 `(1−p)` 正相关，增益消失甚至为负。⇒ 门控必须异质；这解释了 Guardian 型「感知误差主导」为何不能靠再问一次模型解决。∎

**引理 L15（校准证书的样本复杂度下界与选择的强制性）** 在单元格内以方差 `σ²` 估计偏差至 `±δ`、置信 `1−γ`，正态近似下需 `n_min = ⌈z²_{1−γ/2}·σ²/δ²⌉` 个真机 episode。`M` 个单元格全认证需 `B ≥ M·n_min`。取 `δ=0.1, σ=0.3, γ=0.05`（`z≈1.96`）得 `n_min≈35`；`M=30`（6×5）需 `≈1050` 集。若真机预算 `B≪1050`，则认证覆盖 `≤ B/n_min ≪ M`——**全认证不可行，选择认证是强制的，而非优化**。在权重 `w_{f,a}` 下最大化认证覆盖是预算化最大覆盖问题，贪心达 `(1−1/e)` 近似（目标子模时）。⇒ IP-17 的主动分配不是锦上添花，而是预算约束下的唯一严谨解。∎

**引理 L16（语义陈旧预算）** 设环境状态每步转移概率 `λ`、步长 `Δt`；标注龄 `k` 步后仍新鲜的概率为 `e^{−λkΔt}`。给定可接受陈旧概率 `p_s`，有效期 `T_sem = −ln(1−p_s)/λ`（时间单位），等价最大步数 `k_max = −ln(1−p_s)/(λΔt)`。若 oracle 延迟 `τ_m > T_sem`，标注**到达即过期**，不得进快环，只能作慢环先验并带指数衰减权重 `e^{−λ·age}`。⇒ 语义层必须异步 + 带 TTL；延迟超过 TTL 时唯一正确动作是丢弃而非等待。∎
