# 第 48 轮（承接第 47 轮产物 v24；本轮灵感：力觉传感 × 具身智能大模型） · Contact-Cert-Shield：接触门控触觉证书与具身大模型动作块认证盾（六层架构 v12）

> 承接第 47 轮 v11 Servo-Traj-Cert 与产物 v24，以及 v23 Memory-Safety-Voice、v10 Energy-Context-Depth。三者把“感知可信”依次推进到逐帧姿态证书、轨迹级证书管、能量-上下文-深度联合调度、记忆-语音-绑定闭环，但它们共享两个此前从未被审视、却更强的隐含假设：**H7：操作在自由空间完成，接触只是任务的终点而非需要被在线认证的过程**；**H8：动作生成器本身可被分解为白盒控制器输出，证书只需守卫感知**。在 UniBot 的真实抓取、插入、擦拭、递接任务里，这两条同时崩塌：**力觉传感**表明，抓没抓住、滑没滑、处于何种接触模式，这些关键状态在视觉里根本不可观测，只能靠接触门控的触觉/力（1kHz）在线判定，而触觉证书只在接触态有定义、且受 sim-to-real 摩擦系数漂移影响；**具身智能大模型**（VLA）给出的却是一个低频、开环、不可认证的动作块或接触意图，它可能幻觉出“已经夹住”或“对象还在桌上”。二者耦合出新的核心问题：**如何把证书链从自由空间感知延伸到接触丰富操作，用一个高频接触证书去门控/否决一个低频不可认证的大模型动作块，并保证自由空间↔接触切换（冲击、丢接触、滑移）在证书失效之前被拦截。**

## 0. 直觉与动机

**灵感 1（力觉传感 → 接触门控的触觉证书）**
直觉：触觉不是另一个相机。它只在“贴上”之后才有意义，而且是局部、高频、事件驱动的：接触建立、滑移萌生、接触破断都发生在毫秒级。抓取稳不稳，取决于接触力是否落在摩擦锥内、内力是否足够、切向/法向比是否逼近滑动边界——这些量在图像里看不见。因此“感知可信”必须再增加一类**只在接触态有效**的证书 C^ft，并携带自己的租约 ℓ_ft（标定版本、摩擦系数下界 μ_lo、传感器饱和界与 sim-to-real 间隙）。
定义化（见定义 64）：C^ft=(c, λ_slip, μ_lo, σ_ft, δ_sim, ℓ_ft)，sound ⇔ 接触持续 ∧ 摩擦锥裕度 λ_slip≥λ_min ∧ 力闭合/内力可行 ∧ 未饱和 ∧ δ_sim≤δ_sim,max ∧ ℓ_ft 有效；κ_ct=0 时 C^ft 无定义（不是“有效”）。

**灵感 2（具身智能大模型 → 动作块认证盾 / simplex）**
直觉：VLA 不产生“控制器”，它产生“意图 + 开环动作块”。它的价值是语义先验（抓哪个、怎么抓、下一步做什么），它的危险是它不可认证：高延迟、分布漂移、会把未接触当成已接触。正确用法不是让大模型直接驱动执行器，而是把它当成 simplex 架构里的“高性能但不可信控制器”：动作块必须先被编译成一串**分阶段、每阶段有对应证书类型**的候选计划（approach→handover→grasp/force→retreat），任一阶段无法认证就整块否决，回退到经认证的安全原语。
定义化（见定义 66）：compile(P)=(φ_i, τ(φ_i), guard_i)，可执行 ⇔ 每一阶段的证书都能签发为 sound。

**灵感 3（耦合 → 切换区与事件中断）**
直觉：最危险的不是自由空间，也不是稳定接触，而是二者之间的切换：接近时位姿/深度被夹爪遮挡，接触瞬间触觉又处在瞬态。必须为切换单独设证书（定义 65）：接近伺服证书须 sound 到接触预测时刻，法向速度受冲击上界约束，接触必须在检测窗内被触觉确认。更重要的是，接触事件（onset/slip/break）比证书续签循环快一个数量级，必须用 1kHz 事件触发器（定义 67）**抢占**正在执行的大模型动作块并强制重签；否则力 CBF 与证书的前向不变性会在检测延迟内被破坏。
定义化（见定义 67）：事件中断的容忍延迟 τ_evt≤ε_f/L_f，ε_f 为力安全裕度、L_f 为力变化率上界。

**耦合升级（v11 → v12 六层）**：在 v11 五层之上新增 **L6 接触-力觉-认证盾层**。根信任层新增触觉租约 ℓ_ft 与冲击-能量预算；L5 伺服-轨迹证书层把轨迹管终点接到 handover 证书，禁止把接触后阶段纳入自由空间管；L6 由 FTC 签发接触证书、HOC 守卫切换、VCS 把 VLA 动作块编译为证书计划、CET 做 1kHz 事件抢占、XMC 做视觉-触觉-本体一致性校验。CAR 守卫升级为“活跃证书集合的合取，任一失效即 fail-closed”；DCL 采集接触失败（滑移、丢接触、冲击超限、阶段误分类）；ECPS 能量租约加入保力功耗 P_hold(f) 与冲击能量。MVR/VAD/SAB 分别以接触结果、接触意图、力安全绑定接入。

## 1. 形式化定义（增量：定义 64–69）

**定义 64（接触门控触觉证书 C^ft）**
设接触标志 κ_ct∈{0,1}，六维力/力矩 w=(f,τ)，法向 f_n、切向 f_t。摩擦锥裕度
λ_slip = 1 − ‖f_t‖ / (μ_lo·f_n)。
C^ft=(c, λ_slip, μ_lo, σ_ft, δ_sim, ℓ_ft)，c∈{free, contact, slip, break}。
**触觉 soundness**：C^ft sound ⇔ κ_ct=1 ∧ λ_slip≥λ_min ∧ f_n∈[F_min,F_max] ∧ force_closure_feasible(w,G) ∧ 未饱和 ∧ δ_sim≤δ_sim,max ∧ ℓ_ft 有效。κ_ct=0 时 C^ft 无定义，任何依赖它的阶段必须降级。

**定义 65（自由空间-接触切换证书 C^h）**
接近阶段预测接触时刻 t_c 与预接触位姿不确定度 σ_pre。法向接近速度 v_n，环境接触刚度 k_env，反射减速度 a_ref，检测延迟 δ_det。冲击上界
F_impact ≤ k_env·(v_n·δ_det + v_n²/(2a_ref))。
**切换 soundness**：C^h sound ⇔ C^vs 在 [t,t_c] sound ∧ σ_pre≤σ_pre,max ∧ v_n≤v_n,max ∧ F_impact≤F_impact,max ∧ 存在 δ_on>0 使接触在 [t_c−δ_on, t_c+δ_on] 内被触觉确认。切换区间内的触觉瞬态只能作为“已接触”证据，不得当作稳定抓取证据。

**定义 66（大模型动作块证书编译与认证盾）**
VLA 提案 P=(intent, a_{t:t+H}, conf)。分解为阶段序列 φ_1..φ_k∈{approach, handover, grasp, force, retreat}，每阶段映射到证书类型 τ(φ)∈{C^vs, C^h, C^ft, C^f(cbf)}。定义
compile(P) = (φ_i, τ(φ_i), guard_i)，
guard_i 为该阶段的运行时监控（轨迹管、冲击界、力 CBF）。**可执行性**：P 可执行 ⇔ 所有阶段证书均可签发 sound 且 conf≥conf_min。**认证盾** S(P,x) 是运行时执行器，满足：(a) soundness：被执行动作始终落在活跃证书的安全集内；(b) 最小侵入：compile(P) 成功时按原计划执行，仅在证书违例时改写；(c) fail-closed：无认证计划且无安全原语时停机。

**定义 67（接触事件触发与中断延迟）**
1kHz 接触分类器输出事件 E∈{onset, slip, break, ∅}。设力变化率上界 L_f、力安全裕度 ε_f，定义容忍延迟预算
τ_evt = ε_f / L_f。
**事件中断 soundness**：若事件在 t_e 检出且 t_e−t_true≤τ_evt，则在 τ_evt 内抢占并切到力安全反射（降切向/增法向/释放），系统仍处于力安全集 S_f={f: F_min≤f_n≤F_max, ‖f_t‖≤μ_lo f_n−ε_m}。

**定义 68（接触阶段能量-力租约）**
接触阶段功率由保力项主导：P_hold(f)=p_0+k_t·‖f‖（阻抗/力控保持力矩）。接触租约
ℓ_c=(B_t, P_hold, E_impact,max, τ_c, B_min)。
**可行性**：B_t−∫_t^{t+H}(P_idle+P_hold(f(τ)))dτ≥E_min 且冲击能量 ∫f_n·v_n dt≤E_impact,max。能量紧张时被迫降低内力，直接压缩 C^ft 的 λ_slip 裕度——能量与抓取稳定是显式对偶。

**定义 69（触觉-视觉-本体一致性证书）**
由位姿证书 P_t 与对象模型预测接触点 p̂∈B(p_v,r_v)，触觉测得接触点 p_ft 带界 σ_ft。定义残差
r_xmc = ‖p_ft − p̂‖。
**一致性判据**：若 r_xmc≤r_v+σ_ft+ε_m，则视觉与触觉不矛盾；若 r_xmc>r_v+σ_ft+ε_m，则在 P_t 覆盖成立的条件下至少有一个前提为假（错对象/位姿越界/触觉故障），签发一致性告警并 fail-closed。XMC 把“两路都不能单独保证”转化为“两者冲突即为可用告警”。

## 2. 新增产出与既有 IP 升级

**IP-72 FTC（Force/Tactile Certificate）**
- 接触态分类（free/contact/slip/break）与摩擦锥裕度 λ_slip
- 力闭合/内力可行性与法向力 CBF 边界
- 传感器饱和、标定版本、μ_lo 与 sim-to-real 间隙租约
- 滑移前兆（切向高频振动、切向/法向比趋势）预测

**IP-73 HOC（Handover Certificate）**
- 预接触位姿不确定度与接触时刻预测
- 冲击速度/冲量预算与反射减速度可行性
- 接触确认窗 δ_on 与瞬态隔离
- 与 IP-69 伺服证书、IP-70 轨迹管终点对接

**IP-74 VCS（VLA Certificate Shield）**
- 意图/动作块→阶段分解器（含阶段类型分类与置信）
- 每阶段证书类型绑定与运行时 guard 编译
- simplex 回退：不可认证→认证安全原语；无原语→停机
- 最小侵入执行与逐阶段重签

**IP-75 CET（Contact Event Trigger）**
- 1kHz 事件分类与抢占
- slip 反射：力安全控制（降切向/增法向/释放）
- 事件→传播→重签的延迟计量与预算校验

**IP-76 XMC（Cross-Modal Consistency）**
- 视觉预测接触点 vs 触觉实测接触点残差校验
- 错对象/位姿越界/触觉故障的联合告警
- 冲突时 fail-closed，并生成 DCL 采集样本

**既有 IP 升级**
IP-69 SVC：增加接近段终点→handover 接口，σ_pre 由深度/位姿证书给出
IP-70 TRT：轨迹管在 handover 处终止，禁止把接触后阶段纳入自由空间管
IP-71 OATO：阶段化轨迹优化，接触阶段改用接触动力学与力预算
IP-63 ECPS：加入 P_hold(f) 与冲击能量预算；深度收益与触觉收益联合评估
IP-66 MVR：记忆键加入接触结果（grasp/slip/impact）与 μ_lo
IP-67 VAD：语音目标→接触意图（抓/推/递），需求分布落到接触阶段
IP-68 SAB：绑定检查加入接触力安全与阶段类型一致性
IP-51 CAR：守卫升级为活跃证书集合的合取，任一失效→fail-closed
IP-45 总线：新增 tactile-cert / handover-cert / vla-plan / contact-event / xmc-alarm 话题

## 3. 算法骨架

每控制周期（VLA 低频 + 证书计划中频 + 接触事件高频）：
1. 取 VLA 提案 P；若 conf<conf_min 直接走认证安全原语（simplex 安全控制器）
2. compile(P)：阶段分解→逐阶段绑定证书类型与 guard；任一阶段不可编译→否决整块
3. 执行阶段：approach 用 IP-69/70 管监控；handover 用 IP-73 冲击界与接触确认；grasp/force 用 IP-72 触觉证书 + 力 CBF
4. 1kHz 接触事件监控（IP-75）：onset/slip/break 抢占当前块并强制重签
5. 每阶段跑 XMC（IP-76）：冲突即告警并 fail-closed
6. 证书失效/事件/冲突→级联失效→回退认证原语或停机；样本回灌 DCL

## 4. 本轮最大风险

**一句话**：认证盾的安全保证只到“阶段被正确分类”为止——若阶段分解器把一个力控/接触阶段误判为自由空间 approach，VCS 就会用错误的证书类型（伺服管而非触觉+力 CBF）去认证它，接触力会在“证书看似有效”时越过摩擦锥或冲击上界；再叠加 sim-to-real 摩擦系数漂移与事件检测延迟，滑移可能在 1kHz 反射前发生，因此必须以最保守证书类型兜底（阶段类型不确定一律按接触处理）、用独立审计集标定 μ_lo 与 δ_sim、并让事件触发器在硬件层快于证书循环。

**定义 64（触觉证书）** C^ft=(c,λ_slip,μ_lo,σ_ft,δ_sim,ℓ_ft)，λ_slip=1−‖f_t‖/(μ_lo f_n)；sound ⇔ κ_ct=1 ∧ λ_slip≥λ_min ∧ f_n∈[F_min,F_max] ∧ force_closure_feasible ∧ 未饱和 ∧ δ_sim≤δ_sim,max ∧ ℓ_ft 有效。

**定义 65（切换证书）** F_impact≤k_env(v_n δ_det+v_n²/(2a_ref))；C^h sound ⇔ C^vs 在 [t,t_c] sound ∧ σ_pre≤σ_pre,max ∧ v_n≤v_n,max ∧ F_impact≤F_impact,max ∧ 接触在确认窗内被触觉确认。

**定义 66（动作块编译与认证盾）** compile(P)=(φ_i,τ(φ_i),guard_i)；可执行 ⇔ ∀i 证书 sound 且 conf≥conf_min；S 满足 soundness/最小侵入/fail-closed。

**定义 67（事件中断）** τ_evt=ε_f/L_f；事件在容忍延迟内检出则 τ_evt 内切力安全反射，S_f 前向不变。

**定义 68（接触能量-力租约）** P_hold(f)=p_0+k_t‖f‖；ℓ_c=(B_t,P_hold,E_impact,max,τ_c,B_min)；B_t−∫(P_idle+P_hold)≥E_min 且 ∫f_n v_n≤E_impact,max。

**定义 69（跨模态一致性）** r_xmc=‖p_ft−p̂‖；r_xmc≤r_v+σ_ft+ε_m 则一致，否则至少一个前提为假→告警并 fail-closed。

## 2. 关键算法 伪代码

### IP-72 FTC（接触门控触觉证书）
```
def force_closure_feasible(w, G, calib):
    # G: 抓取矩阵；摩擦锥线性化，求内力可行解
    fc = linearized_friction_cone(calib.mu_lo, calib.n_edges)
    return qp_feasible(G, -w, fc, calib.internal_force_min)

def tactile_certify(sensor, obj, calib):
    if not sensor.contact_flag:
        return None                        # 非接触态：触觉证书无定义
    if sensor.saturated or sensor.sigma > calib.sigma_max:
        return None
    w = sensor.wrench()                    # (f, tau) in sensor frame
    fn = max(w.f_n, EPS)
    ft = norm(w.f_tangential)
    lam_slip = 1.0 - ft / (calib.mu_lo * fn)
    if lam_slip < calib.lambda_min:
        return None                        # 已逼近滑动边界
    if not force_closure_feasible(w, obj.G, calib):
        return None
    if w.f_n > calib.F_max - calib.margin_f:
        return None                        # 法向力 CBF 边界
    if calib.delta_sim > calib.delta_sim_max:
        return None                        # sim-to-real 间隙超限
    lease = calib.lease.bind(sensor.version, obj.model_id, calib.mu_lo)
    return TactileCert(contact=True, slip_margin=lam_slip,
                       fn=w.f_n, ft=ft, lease=lease)
```

### IP-73 HOC（切换证书）
```
def handover_guard(pre_pose_cert, approach_plan, contact_pred, calib):
    if pre_pose_cert is None or \
       not pre_pose_cert.valid_until(contact_pred.t):
        return None                        # 视觉证书撑不到接触预测时刻
    if contact_pred.sigma_pose > calib.max_precontact_sigma:
        return None                        # 预接触位姿太不确定
    if approach_plan.v_normal > calib.v_normal_max:
        return None                        # 接近速度过快
    d_pen = (approach_plan.v_normal * calib.delta_det
             + approach_plan.v_normal**2 / (2 * calib.a_ref))
    F_impact = calib.k_env * d_pen
    if F_impact > calib.F_impact_max:
        return None                        # 冲击可能超限
    return HandoverCert(t_pre=contact_pred.t,
                        F_impact_max=calib.F_impact_max,
                        confirm_window=calib.delta_on)
```

### IP-74 VCS（动作块编译 + 认证盾）
```
def compile_chunk(proposal, state, calib):
    phases = decompose(proposal.intent, proposal.chunk)
    plan = []
    for ph in phases:
        if ph.kind == 'approach':
            cert = servo_certify(ph.s, ph.s_star, ph.depth,
                                 ph.F, calib, ph.lam, ph.H)
            guard = ('tube', trajectory_tube(ph.nodes, calib, ph.H,
                                            calib.delta, calib.alpha_trj))
        elif ph.kind == 'handover':
            cert = handover_guard(ph.pose_cert, ph.approach,
                                  ph.contact_pred, calib)
            guard = ('impact', ph.F_impact_max)
        elif ph.kind in ('grasp', 'force'):
            cert = tactile_certify(ph.sensor, ph.obj, calib)
            guard = ('cbf', ph.force_bounds)
        elif ph.kind == 'retreat':
            cert = servo_certify(ph.s, ph.s_star, ph.depth,
                                 ph.F, calib, ph.lam, ph.H)
            guard = ('tube', trajectory_tube(ph.nodes, calib, ph.H,
                                            calib.delta, calib.alpha_trj))
        else:
            return None                    # 未知阶段：默认不可认证
        if cert is None:
            return None                    # 任一阶段失败即整块否决
        plan.append(Phase(ph, cert, guard))
    return plan

def certified_primitive(state, calib):
    # simplex 安全控制器：退回到带力限的合规/阻抗原语
    if energy_ok(state, calib) and pose_ok(state, calib):
        return ImpedancePlan(calib.safe_impedance, calib.F_max)
    return 'fail-closed'

def vla_shield(proposal, state, calib):
    if proposal.conf < calib.conf_min:
        return certified_primitive(state, calib)
    plan = compile_chunk(proposal, state, calib)
    if plan is None:
        return certified_primitive(state, calib)   # 不可认证→安全原语
    for ph in plan:
        if not execute_phase_with_monitor(ph, state, calib):
            broadcast_invalidate(ph.cert)          # 旧计划级联失效
            return certified_primitive(state, calib)
    return 'ok'
```

### IP-75 CET（接触事件触发与反射）
```
def classify_contact(sensor, calib):
    if not sensor.contact_flag and sensor.f_n < calib.f_contact_on:
        return 'free'
    if sensor.f_n < calib.f_contact_off:
        return 'break'
    if 1.0 - norm(sensor.f_t) / (calib.mu_lo * max(sensor.f_n, EPS)) \
       < calib.lambda_alert:
        return 'slip'
    return 'contact'

def contact_event_monitor(sensor, calib, prev_state):
    c = classify_contact(sensor, calib)
    if prev_state == 'free' and c == 'contact':
        return Event('onset', now(), sensor.f_n, sensor.f_t)
    if c == 'slip':
        return Event('slip', now(), sensor.f_n, sensor.f_t)
    if prev_state == 'contact' and c == 'break':
        return Event('break', now(), sensor.f_n, sensor.f_t)
    return None

def contact_reflex(e, state, calib):
    if e.kind == 'slip':
        # 降低切向力、增加法向力或释放，强制回 S_f
        return ForceSafeReflex(target_slip_margin=calib.lambda_min,
                               fn_min=calib.F_min,
                               rate=calib.reflex_rate)
    if e.kind == 'break':
        return RetreatReflex(dir=calib.safe_retreat_dir,
                             v_max=calib.v_normal_max)
    return 'recertify_contact'

def on_event(e, current_plan, calib):
    if e.kind in ('slip', 'break', 'onset'):
        preempt(current_plan)              # 抢占大模型动作块
        return contact_reflex(e, state_of(current_plan), calib)
    return None
```

### IP-76 XMC（跨模态一致性）
```
def cross_modal_consistency(pose_cert, tactile_cert, obj, calib):
    if pose_cert is None and tactile_cert is None:
        return 'no_certificate'
    if pose_cert is not None and tactile_cert is None:
        return 'contact_missing' if obj.expect_contact else 'ok_free'
    if tactile_cert is not None and pose_cert is None:
        return 'pose_blind_contact'
    p_hat = contact_point(pose_cert, obj)
    r = dist(p_hat, tactile_cert.contact_point)
    if r > pose_cert.radius + calib.sigma_ft + calib.eps_m:
        return 'inconsistent'              # 视觉/触觉/本体冲突
    return 'consistent'
```

### 全局闭环（接触丰富执行）
```
def contact_rich_execute(P, state, calib):
    if P.conf < calib.conf_min:
        return certified_primitive(state, calib)
    plan = compile_chunk(P, state, calib)
    if plan is None:
        return certified_primitive(state, calib)

    for ph in plan:
        while phase_active(ph):
            e = contact_event_monitor(sensor, calib, ph.prev_contact)
            if e is not None:
                preempt(plan)              # 高频事件优先
                return contact_reflex(e, state, calib)
            if not revalidate_phase(ph, state, calib):
                broadcast_invalidate(ph.cert)
                return certified_primitive(state, calib)
            if cross_modal_consistency(ph.pose_cert, ph.tactile_cert,
                                       ph.obj, calib) == 'inconsistent':
                dcl_ingest(('xmc_conflict', state))
                return 'fail-closed'
            execute_phase_tick(ph, calib)
    return 'ok'
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| IP-72 FTC | O(n_edges)（摩擦锥 QP 可行性）+ O(1) | O(1) | λ_slip≥λ_min ∧ 力闭合 ⇒ 接触稳定裕度成立 |
| IP-73 HOC | O(1) | O(1) | 冲击界成立 ∧ 确认窗命中 ⇒ 切换不超冲击预算 |
| IP-74 VCS | O(k·（阶段证书）) 编译；O(1) 逐 tick 重签 | O(k) | 逐阶段 sound + 最小侵入 ⇒ 盾 soundness |
| IP-75 CET | O(1) 每 1ms | O(1) | 检测延迟≤τ_evt ⇒ 力安全集前向不变 |
| IP-76 XMC | O(1) | O(1) | 残差超界 ⇒ 至少一个前提为假（高概率） |
| 全局闭环 | 由 VLA 延迟与逐阶段重签主导 | O(k) | 事件/违例/冲突必抢占或 fail-closed |

**命题 1（触觉证书 + 力 CBF 的前向不变性）**
取力安全集 S_f={f: F_min≤f_n≤F_max, ‖f_t‖≤μ_lo f_n−ε_m}，定义 h(f)=min(F_max−f_n, μ_lo f_n−‖f_t‖−ε_m)。接触控制器满足 ḣ+α h≥0 时 S_f 前向不变。若力变化率有界 ‖ḟ‖≤L_f、检测延迟为 δ，则检测时刻的真实裕度至少为 h(f)−L_f δ；因此证书必须把安全裕度膨胀为 ε_m≥L_f δ，否则 CBF 名义可行而实际已越界。这把“触觉证书 sound”从静态力检查升级为带延迟补偿的鲁棒 CBF 条件。

**命题 2（切换冲击界）**
设接触检测延迟为 δ_det，反射减速度 a_ref，法向接近速度 v_n，环境接触刚度 k_env。检测前额外侵入深度为 v_n δ_det，检测后制动距离为 v_n²/(2a_ref)，故峰值侵入 d_pen≤v_n δ_det+v_n²/(2a_ref)，冲击力 F_impact≤k_env d_pen。令 C^h 强制 v_n≤v_n,max 且 k_env(v_n δ_det+v_n²/(2a_ref))≤F_impact,max，则切换阶段峰值接触力不超过预算。**要点**：该界依赖独立估计的 k_env 与 δ_det；若真实刚度更高，必须用更保守的 k_env 上界，否则冲击界失效。

**命题 3（认证盾的 soundness / 最小侵入 / simplex）**
对任意提案 π（可含对抗/幻觉），认证盾 S 只在 compile(π) 每阶段证书 sound 时执行原计划；执行中逐 tick 重签，任一 guard 违例即在下一 tick 前抢占；无认证计划时回退 certified_primitive，后者按命题 1 维持不变集，故可安全切换；若连安全原语都不可行则 fail-closed。由此 (a) 被执行动作始终落在活跃证书安全集内；(b) compile 成功时行为与 π 一致（除违例改写），即最小侵入；(c) 无解即停机。**边界**：保证只对“阶段被正确分类”成立；阶段误分类等价于用错证书类型，是安全论证的破口。

**命题 4（事件中断的前向不变性 / 延迟预算）**
设接触事件在 t_e 真实发生，检测延迟 δ_det≤τ_evt，力变化率≤L_f。则事件被检出时力状态相对事件时刻漂移≤L_f τ_evt。若证书/反射使用裕度 ε_f≥L_f τ_evt，则检出瞬间系统仍在 S_f 内部，反射能在下一拍将其拉回；因此 τ_evt=ε_f/L_f 是 1kHz 事件环设计的上限。若检测或抢占串行化延迟超过 τ_evt，滑移可能在反射前发生，前向不变性不成立。

**命题 5（跨模态一致性覆盖）**
若位姿证书覆盖 X_t 的概率≥1−α_p，触觉接触点测量噪声有界 σ_ft，对象模型正确，则真实接触点落在 B(p̂, r_v+σ_ft) 内（概率≥1−α_p），从而 r_xmc≤r_v+σ_ft+ε_m。反之若实测 r_xmc 超过该界，则在覆盖事件成立的条件下至少一个前提为假（错对象/位姿越界/触觉故障），误报率≤α_p。XMC 因此是一个带覆盖保证的单侧冲突检验——它不能证明一致时一定对，但冲突时报出是可靠的。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 阶段误分类导致用错证书类型 | 高 | 类型不确定一律按接触处理；独立审计集评估阶段分类；最保守证书兜底 |
| sim-to-real 摩擦系数漂移抬高滑移风险 | 高 | 用 μ_lo 下界；域随机化 + 在线残余摩擦估计；定期独立重标 |
| 事件检测/抢占延迟超预算 | 高 | 事件检测下沉固件/1kHz 硬实时；L_f 保守估计；裕度 ε_f≥L_f τ_evt |
| 触觉传感器饱和/漂移 | 中 | 饱和即判证书无效；租约绑定标定版本；多传感器交叉校验 |
| VLA 幻觉“已接触” | 高 | XMC 冲突检验；tactile 证书独立于 VLA；conf<conf_min 直接原语 |
| 认证盾过于保守、任务效率下降 | 中 | 最小侵入执行；仅在违例时改写；阶段级重签而非整块丢弃 |
| 能量紧张导致内力下降→滑移 | 中 | 接触能量租约 ℓ_c；能量临界时提前释放或降负载；ECPS 联合预算 |
| 力 CBF 与证书循环频率不匹配 | 中 | 力控内环高频、证书外环低频；事件触发抢占；延迟补偿膨胀裕度 |

## 6. 本轮最大风险

**一句话**：认证盾的安全保证只到“阶段被正确分类”为止——若阶段分解器把一个力控/接触阶段误判为自由空间 approach，VCS 就会用错误的证书类型（伺服管而非触觉+力 CBF）去认证它，接触力会在“证书看似有效”时越过摩擦锥或冲击上界；再叠加 sim-to-real 摩擦系数漂移与事件检测延迟，滑移可能在 1kHz 反射前发生，因此必须以最保守证书类型兜底（阶段类型不确定一律按接触处理）、用独立审计集标定 μ_lo 与 δ_sim、并让事件触发器在硬件层快于证书循环。
