# 第 65 轮（承接第 64 轮「GRIP 接触接地四层闭环」IP-204~213；灵感循环 III 第 1 轮；本轮灵感：「可用性评估」×「多语言支持」）

> 前 64 轮把鲁棒性一层层向内逼：几何（LiDAR）→ 技能 → 干扰 → 接触（力觉）→ 滑移/力限。J_grip 已经能证明"系统内部"不自信地错、不滑、不压伤。但它默认了两个**从未被认证的外部前提**：① **证书与人之间的契约**——谁读得懂 J_grip？读不懂时人会怎么做？② **指令与语义之间的契约**——同一条命令换一种语言，机器人是否还理解成同一件事？本轮把这两条外部契约抬到与几何/力觉同等的地位：
>
> **可用性不是体验装饰，而是最后一道安全层（解释即安全、信任须校准）；多语言不是国际化功能，而是规格级不变式（同一目标、不同说法，必须等价；未认证语言必须降级，绝不静默回退）。**

## 0. 直觉与动机

**灵感 1（可用性评估 → 可读的证书才是有效证书：解释即安全）**
直觉：安全认证只在"人能据此做出正确干预"时才成立。一个 ρ_force = 0.3 的证书，若操作员看不懂"是哪一条约束在卡、现在该不该接管"，他的实际行为只有两种坏结局：**过度信任**（放任错误继续）或**过度不信任**（频繁误接管）。两种都制造事故——**而事故并不发生在机器人内部，而发生在这条"人机解释通道"上**。所以解释保真度与信任校准必须进入证书，而不是 UI 文案；J_grip 要从"机器可验证"升级为"人机共同可验证"。

**灵感 2（多语言支持 → 跨语言语义一致性是规格不变式：同一目标，不同说法）**
直觉：DMS 从单一语言解析目标 g；但真实用户会用中文/英文/方言/混杂语说同一件事，也会用否定、量词、范围、指代制造歧义。若"把红色积木放到左边第二个格子"与其英文翻译在系统里映射到不同的 g，这是一个**任何几何/力觉证书都检测不到的静默规格错误**——机器人完美地、安全地、自信地做错了任务。多语言支持的核心不是"支持更多语言"，而是**跨语言中介语 z 的一致性 + 覆盖范围显式披露**：没认证的语言必须降级为人工确认，绝不静默地拿主导语言先验顶替。

**灵感 3（三灵感合流 → "问"与"探"是同一种操作：主动信息获取 AIA）**
直觉：第 64 轮 APP 在物理世界做 probe（press/rub/tap/lift）以降低 φ 的不确定性，代价是可能损伤物体；本轮 ACP 在语义/人际世界做 ask（澄清问句）以降低目标不确定性，代价是打扰用户、消耗认知负荷。二者不是两个模块，而是**同一算子——主动信息获取（active information acquisition）——在不同成本函数下的两个实例**：APP 的约束是损伤 f_safe，ACP 的约束是打断预算 B_int 与耐心。这个统一让"何时该探、何时该问、何时该自己扛"第一次有了同一个理论框架，也让第 64 轮"安全-信息张力"在语义层获得了精确对偶。

**灵感 4（MUSE 闭环：Multilingual Usability-grounded Safety Evidence）**
- **MIG**：u_ℓ → z → g，跨语言中介语 + 一致性证书 ρ_lang；
- **DMS-X**：否定/量词/范围/指代/语序的鲁棒解析，歧义显式打包为 {g_i, p_i}；
- **ACP**：当 H(g) 高或跨语言冲突时，选"信息增益/打断成本"最优且低于预算的澄清问句；
- **UEB**：可用性证据组（有效性/效率/满意度/可学习性/信任校准/态势感知/负荷/解释保真），**每项主观量必须配对客观行为量**；
- **LEG**：证书解释生成，按"哪条约束真正绑定"给出反事实解释，faithfulness 可测；
- **OCB-UX**：技能选择显式建模人的预期与可读性（legibility）；
- **AIC-UX**：干扰集扩展到改写/回译噪声/方言/否定范围/提示注入/谄媚压力/未认证语言；
- **J_muse**：J_grip + (ρ_lang, cov, ρ_ux, ECE, ρ_exp, lang_id, explanation_hash, override_log_hash)。

**灵感 5（LIRO/GRIP 组件的原位升级）**
- DMS → **DMS-X**；USR/MEL 保留，仅与下游共享 z，不各自维护语言专用语义。
- APP → **APP/ACP 双通道**，统一为 **AIA**。
- OCB-Skill → **OCB-UX**；AIC → **AIC-UX**；SSB → 增"交互记忆"（澄清历史、误解释事件、个体信任基线）。
- J_grip → **J_muse**；实时流契约不变（语言模型/可用性计算绝不上实时路径）。

## 1. 形式化定义（增量：定义 217–232）

- **定义 217（MUSE 闭环）** MUSE = (GRIP, MIG, DMS-X, ACP, UEB, LEG, OCB-UX, AIC-UX, J_muse)。不变式：**实时流不做语言模型推理、不做可用性计算；跨语言解析、澄清、解释生成只在语义流低频线程；证书与解释必须在派发前就绪**（解释可预编译缓存）。

- **定义 218（跨语言中介语 MIG）** 语言集 L，指令 u_ℓ ∈ U_ℓ。编码 Φ_ℓ: U_ℓ → Z，解码 Ψ: Z → G，z = Φ_ℓ(u_ℓ)，g = Ψ(z)。中介语 Z **不是"真值语义"**，而是**关系对象**：只要求同一目标的不同表述在 Z 中近邻。这一退让是 rigor 的关键——我们不宣称存在普世语义空间，只认证一个可测量的等价关系。

- **定义 219（跨语言一致性残差与 ρ_lang）** 认证语言集 L_cert 上建翻译图 T（有向对，含回译）与改写集 P。对每条边 (ℓ,ℓ′)：
  d_ℓℓ′ = d_G( Ψ(Φ_ℓ(u_ℓ)), Ψ(Φ_ℓ′(τ_ℓℓ′(u_ℓ))) )；
  ρ_lang = 1 − max_{(ℓ,ℓ′)∈E(T)} d_ℓℓ′ / d_max。
  另记覆盖率 cov(L_cert)（认证语言在目标用户语言分布上的质量）与未认证语言的最近认证距离。**证书只对 L_cert 的连通分量负责**，分量外一律 lang_degraded。

- **定义 220（ACP 主动澄清探测）** 目标后验 p(g | u, z)，熵 H。问题空间 Q（是/否、二选一、指代消解、量词确认、执行前确认）。选择
  q* = argmax_{q∈Q} E[IG(q)] s.t. c_int(q,t) ≤ B_int ∧ E[IG(q)] > δ_clarify。
  其中 c_int 为打断成本（询问次数权重 × 场景紧迫度）。若预算内无法把 H 降到阈值以下 → 降级为 human_confirm 或 safe_idle，而非猜。

- **定义 221（可用性向量与裕度）** U = (E, F, S, Lr, Tcal, SA, W, X)：有效性、效率、满意度、可学习性、信任校准、态势感知、工作负荷、解释保真。每维归一化到 [0,1]，给定最低阈值 u_min,i。**ρ_ux = min_i (U_i − u_min,i)/(1 − u_min,i)**。可用性是**约束**而非加权总分——加权会用一个漂亮维度掩盖致命短板（拒绝 min 型退化）。

- **定义 222（信任校准）** 系统报告置信度 c，同置信桶实际正确率 r。ECE = Σ_b (n_b/N)|acc_b − conf_b|。危险区：c 高而 acc 低的"过度信任桶"。分别定义过度依赖（错时仍接受）与不利用（对时仍拒绝）两类偏差，二者都计入 ρ_ux。

- **定义 223（解释保真度 ρ_exp）** 解释 x_e 声称绑定约束集 B_e（如"因 ρ_slip < 0 而拒绝"）。**反事实必要性**：删去 B_e 会导致决策翻转；**反事实充分性**：仅保留 B_e 能复现决策。ρ_exp = 1 − 不一致率。解释必须引用**真实绑定约束**，禁止事后合理化（post-hoc rationalization）。

- **定义 224（人机联合安全）** 危险事件 A = (机器人执行错误 ∨ 系统降级) ∧ 人未有效干预，或 (系统正确 ∧ 人错误接管致害)。把操作员建模为**阈值检测者**：以报告置信度 c 决定是否接管。干预日志 override_log 入证书。P_danger 是 ECE、ρ_exp 与内部安全裕度的函数（定理 8）。

- **定义 225（UEB 可用性证据组）** 预注册协议 = (任务集、参与者分层、语言分层、度量、统计检验、停止规则)。有效性 = 任务成功率；效率 = 完成时间/干预次数；SUS；NASA-TLX；信任校准用"报告置信-正确率"图；解释保真用反事实测验；态势感知用 SAGAT 查询。**所有主观量必须与客观行为量配对，禁止单独用问卷作为证据**。

- **定义 226（DMS-X 跨语言目标解析）** 在 DMS 上增：① 语言识别与置信；② 否定/量词/范围/指代的结构化解析；③ 歧义打包为显式假设集 {g_i, p_i}；④ 若 max p_i < p_min 或跨语言冲突 → 交 ACP。输出 g 或 g-Clarify。

- **定义 227（OCB-UX 可读技能选择）** 选择技能 π 时在原有执行代价上增 legibility 项 L_leg(π | x)，使观察者最易推断目标；并保证解释可在预算内生成。**可读性不改变安全性，只改变"人能否及时干预"**。

- **定义 228（AIC-UX 指令侧干扰）** ℰ_UX = {改写、回译噪声、方言/混杂语、否定与范围歧义、提示注入、谄媚/权威压力、未认证语言}。ρ_lang 与 ECE 在 ℰ_UX 上取最坏；**提示注入视为对抗样本，禁止用"更听话"来提升满意度**。

- **定义 229（J_muse 证书）** J_muse = (J_grip, ρ_lang, cov(L_cert), ρ_ux, ECE, ρ_exp, lang_id, explanation_hash, override_log_hash, ueb_ver)。
  Valid(J_muse) ⇔ Valid(J_grip) ∧ ρ_lang ≥ 0 在 L_cert 连通分量上 ∧ 未认证语言已降级 ∧ ρ_ux ≥ 0 ∧ ECE ≤ κ_cal ∧ ρ_exp ≥ 0 ∧ 解释哈希与证书一致。

- **定义 230（AIA 统一算子）** 统一 APP（物理 probe）与 ACP（语义 ask）：
  a* = argmax_a E[IG(a)] / c(a) s.t. c(a) ≤ B_type(a)，
  其中 c 为损伤（物理）或打断（语义）。二者共享"信息-成本"张力，只是成本函数不同；这解释了两者应当共用预算调度器与停止规则。

- **定义 231（覆盖披露与优雅降级）** lang_degraded = (ℓ ∉ L_cert) ∨ (ρ_lang(ℓ) < 0)。此时自主等级 A ← A_safe（需确认），并显式告知用户"该语言未认证"，**禁止静默用主导语言先验替代**。

- **定义 232（MUSE 算子）** 语义流：[LiDAR → LSF → USR/MEL → GRIP 语义流（CGG/MWS/FPE/APP/CSP-F）→ DMS-X/MIG → (ACP) → OCB-UX → 解释生成 → UEB 记录 → AIC-UX → J_muse]；实时流：[GRIP 实时流 + 置信度映射 + 解释缓存派发]。实时路径零语言模型、零学习写操作（继承 A87）。

## 2. 关键算法骨架

```python
# MIG：跨语言一致性证书（语义流，离线+在线抽检）
def certify_language_graph(encoders, translator, goal_decoder, corpus, L_cert):
    edges = []
    for l in L_cert:
        for lp in L_cert:
            if l == lp: continue
            for u in corpus[l]:
                g_l  = goal_decoder(encoders[l](u))
                u_bt = translator(l, lp, u)                  # 翻译
                u_rt = translator(lp, l, u_bt)               # 回译
                g_lp = goal_decoder(encoders[lp](u_bt))
                d = goal_metric(g_l, g_lp)
                edges.append((l, lp, d))
    rho_lang = 1 - max(e[2] for e in edges) / D_MAX
    return rho_lang, edges, coverage(L_cert, user_language_dist)

# ACP：主动澄清（语义流）
def choose_clarification(posterior_g, Q, budget):
    best, best_ratio = None, -inf
    for q in Q:
        ig = expected_information_gain(posterior_g, q)
        c  = interruption_cost(q, urgency)
        if c <= budget and ig > DELTA_CLARIFY and ig / (c + 1e-6) > best_ratio:
            best, best_ratio = q, ig / (c + 1e-6)
    return best, best_ratio               # None ⇒ 降级 human_confirm / safe_idle

# LEG：解释保真（反事实充分/必要）
def faithful_explanation(cert, plan, binding_constraints):
    B = binding_constraints(cert)                    # 真实绑定约束
    necessary   = all(flip_decision(remove(cert, b)) for b in B)
    sufficient  = reproduce_decision(keep_only(cert, B))
    rho_exp = 0.5 * (necessary + sufficient)
    return render_explanation(B, cert), rho_exp

# J_muse：证书构建
def build_j_muse(j_grip, rho_lang, cov, rho_ux, ece, rho_exp, lang_id, expl, overrides):
    valid = (j_grip.valid and rho_lang >= 0 and cov.degraded_ok
             and rho_ux >= 0 and ece <= KAPPA_CAL and rho_exp >= RHO_EXP_MIN
             and hash(expl) == j_grip.explanation_hash)
    return JMuse(j_grip, rho_lang, cov, rho_ux, ece, rho_exp,
                 lang_id, hash(expl), hash(tuple(overrides)), valid)
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 7（跨语言一致性传递）** 若翻译图连通分量 C 的每条边满足 d_ℓℓ′ ≤ ε，则任意 ℓ,ℓ′ ∈ C 有 d_G(g_ℓ, g_ℓ′) ≤ diam_hop(C)·ε。证明：对 d_G 用三角不等式沿路径累加。故 ρ_lang ≥ 0 给的是**分量内**的等价保证，其强度随跳数线性衰减——这直接暴露"一致性证书"的覆盖边界。

- **定理 7（多语言规格安全）** 若 ρ_lang ≥ 0 且安全裕度沿 g 的 Lipschitz 常数为 L_g，则当 margin > L_g·diam_hop(C)·ε 时，对 C 内任一语言解析出的 g′ 仍满足同一安全约束；未认证语言若最近认证距离超过 margin/L_g，必须降级确认——**因此不存在"静默做错任务"**。

- **引理 8（解释-校准耦合）** 设操作员误判率含两项：不可约的人类误差 ε_h 与"解释未揭示真实失败模式"导致的额外误差。则 ρ_exp 越高，有效误判率越低；信任校准误差 ECE 越大，过度依赖/不利用越强。二者共同决定人机联合危险概率。

- **定理 8（可用性-安全联合界）** 在 GRIP 定理 6 基础上，人机联合危险事件概率
  P_danger ≤ α_rob + α_slip + α_force + α_lang + (1 − θ_h + κ_cal)·(1 − ρ_exp·η) + ε_h，
  其中 θ_h 为操作员接管阈值，η 为解释可干预效率。**可用性进入安全界是加性项，而非软指标**；ρ_ux ≥ 0 保证该加性项被压低到可接受范围。

- **定理 9（ACP 交互复杂度与下界）** 目标熵从 H_0 降到 δ，每问最大信息增益 IG_max，则需 N ≥ (H_0 − δ)/IG_max 次询问；在打断预算 B 下可行当且仅当 N·c_min ≤ B。当 H_0 − δ > B·IG_max/c_min 时**信息-打断张力不可避免**，任何策略都只能选择"降级确认"而非"问够"——这是与 APP"安全-信息张力"精确对偶的下界。

- **命题（无免费可用性）** 若满意度 S 通过"讨好式顺从"提升（更多同意、更少拒绝、更平滑的置信表达），则 ECE 与过度依赖率可能同时上升，∂P_danger/∂S > 0。故**不能用满意度单独作为优化目标**；S 必须与 ECE、ρ_exp、客观接管行为联合约束。

- **实时性**：MIG/DMS-X/ACP/LEG 全部在语义流；实时流仅增置信度映射与解释缓存派发（<0.2ms），总实时路径仍 ≤ 2.1ms（继承 A87，新增 A88）。

## 5. 本轮最大风险

**一句话**：可用性与信任本质是**主观、语境依赖、可被讨好式优化**的量——把满意度/信任当 KPI 会诱导系统"让用户更放心"而非"让用户更准确判断"，从而把可用性认证从安全层变成**过度信任的加速器与安全剧场**；同时跨语言一致性只能对 L_cert 的连通分量负责，未覆盖语言的"静默回退"会让 ρ_lang 证书产生**虚假的普适保证**，这构成本轮全部论证共同依赖的隐藏前提（A89）。

## 2. 形式化定义（完整版）

**定义 217（MUSE 闭环）** MUSE 是 GRIP 的"人机/跨语言接地"升级：在"语义流 ∘ 实时流"骨架上挂载 MIG/DMS-X（跨语言语义）、ACP（主动澄清）、UEB（可用性证据）、LEG（解释保真）、TRC（信任校准），并把 AIC 扩为 AIC-UX、OCB-Skill 升级为 OCB-UX、J_grip 升级为 J_muse。不变式：**所有语言模型推理、澄清规划、解释生成、可用性计算只发生在语义流低频线程；实时路径只做 GRIP 前向、置信度映射与解释缓存派发，零语言模型、零学习写操作。**

**定义 218（跨语言中介语 MIG）** 给定语言集 L 与指令 u_ℓ ∈ U_ℓ，编码 Φ_ℓ: U_ℓ → Z，解码 Ψ: Z → G，z = Φ_ℓ(u_ℓ)，g = Ψ(z)。中介语 Z 是**关系对象而非普世语义**：只要求"同一意图的不同语言表述"在 Z 中近邻，不要求 Z 可被解释为世界的真值。此退让使证书可测且不预设语言普遍性。

**定义 219（跨语言一致性与覆盖）** 在认证语言集 L_cert 上构造翻译图 T（有向边含翻译与回译）与改写集 P。对每条边 (ℓ,ℓ′)：
d_ℓℓ′ = d_G(Ψ(Φ_ℓ(u_ℓ)), Ψ(Φ_ℓ′(τ_ℓℓ′(u_ℓ))))，目标度量 d_G 在目标空间上取语义编辑距离。
ρ_lang = 1 − max_{(ℓ,ℓ′)∈E(T)} d_ℓℓ′ / d_max；d_max 为目标空间直径。
覆盖率 cov(L_cert) = Σ_{ℓ∈L_cert} p_user(ℓ)，p_user 为目标用户语言分布。**证书只对 L_cert 的连通分量 C_T 负责**；任何 ℓ ∉ C_T 一律 lang_degraded。

**定义 220（ACP 主动澄清探测）** 目标后验 p(g|u,z)，熵 H(p)。问题空间 Q = {yes/no, binary-choice, reference-resolution, quantifier-confirm, pre-execution-confirm}。选择
q* = argmax_{q∈Q} E[IG(q)] / (c_int(q,t)+ε)，s.t. c_int(q,t) ≤ B_int ∧ E[IG(q)] > δ_clarify。
打断成本 c_int = w_ask·n_asks + w_time·Δt + w_ctx·1[打断进行中任务]。若预算内无法使 H(p) ≤ H_min，则输出 `clarify_fail`，降级为 human_confirm 或 safe_idle；**绝不以最大后验硬猜执行**。

**定义 221（可用性向量与裕度）** 可用性向量 U = (E, F, S, Lr, Tcal, SA, W, X)，每维归一化到 [0,1]：
- E 有效性 = 任务成功率；F 效率 = 标准任务完成时间/人工干预次数的归一化逆；S 满意度 = SUS 归一化；
- Lr 可学习性 = 第 1 次 vs 第 5 次任务的成功率差；
- Tcal 信任校准 = 1 − ECE；SA 态势感知 = SAGAT 正确率；W 工作负荷 = 1 − NASA-TLX 归一化；X 解释保真 = ρ_exp。
给定各维最低阈值 u_min,i，**ρ_ux = min_i (U_i − u_min,i)/(1 − u_min,i)**。采用 min 而非加权和：可用性是**约束**，一个致命短板不能用其他高分补偿。

**定义 222（信任校准 TRC）** 系统报告置信度 c ∈ [0,1]；按置信桶统计实际正确率 r(c)。ECE = Σ_b (n_b/N)|acc_b − conf_b|。定义两类偏差：
- 过度依赖：`accept ∧ ¬correct`，尤其发生在 c 高的桶；
- 不利用：`reject ∧ correct`，尤其发生在系统可安全处理的场景。
两偏差均计入 U 的 Tcal 与 ρ_ux。危险接受率 P_danger,over = P[accept ∧ wrong]。

**定义 223（解释保真 LEG）** 证书 J 含绑定约束集 B（哪一条 ρ 在卡：几何/滑移/力限/跨语言/可用性）。解释 x_e 声称约束集 B_e。定义：
- 必要性：∀b∈B_e，删去 b 后决策翻转；
- 充分性：仅保留 B_e 能复现决策。
ρ_exp = (必要性满足率 + 充分性满足率)/2。解释必须由证书字段程序化生成（模板 + 反事实），**禁止由独立语言模型自由发挥**（否则幻觉解释无法追责）。

**定义 224（人机联合安全）** 操作员为阈值检测者：当 c < θ_h 时接管。危险事件
A = ((robot_wrong ∨ degraded) ∧ ¬override) ∨ (robot_correct ∧ override ∧ harmful)。
A 的概率由引理 8/定理 8 界定。override_log 记录每次接管的时间、理由、结果，并哈希入 J_muse。

**定义 225（UEB 可用性证据组）** 预注册协议 P_ueb = (任务集、参与者分层、语言分层、度量、统计检验、停止规则)。要求：
1. 每个主观度量必须有客观行为对应（SUS ↔ 干预次数；TLX ↔ 完成时间/错误率）；
2. 语言分层覆盖 L_cert，且至少含一个未认证语言作对照；
3. 报告效应量与置信区间，不报告单一均值；
4. 预注册后不得更换主指标（防 p-hacking）。
输出 U 与 ρ_ux、ECE、ρ_exp 及原始日志哈希。

**定义 226（DMS-X 跨语言目标解析）** 在 DMS 上增四步：① 语言识别 ℓ̂ 及置信（低置信 → ACP 或确认）；② 否定/量词/范围/指代的结构化解析（输出作用域树）；③ 歧义打包为显式假设集 {g_i, p_i}；④ 若 max_i p_i < p_min 或跨语言假设冲突，交 ACP。输出 (g, p_max) 或 (Clarify, {g_i,p_i})。

**定义 227（OCB-UX 可读技能选择）** 技能选择目标
π* = argmin_π [cost_exec(π) + λ_leg·L_leg(π|x)]，s.t. explainable(π) ≤ B_expl，
其中 L_leg 为观察者从轨迹推断目标的负对数似然（越低越可读），explainable 为生成合法解释所需代价。可读性只影响人能否及时干预，不改变内部安全裕度。

**定义 228（AIC-UX 指令侧干扰认证）** ℰ_UX = {paraphrase, back-translation noise, dialect/code-switching, negation/scope ambiguity, prompt injection, sycophancy/authority pressure, uncertified language}。在 ℰ_UX 上重算 ρ_lang、ECE 与 ρ_ux，取最坏情形。**提示注入按对抗样本处理**：禁止通过"更顺从"降低注入成功率（否则与可用性目标相冲突）。

**定义 229（J_muse 证书）** J_muse = (J_grip, ρ_lang, cov(L_cert), ρ_ux, ECE, ρ_exp, lang_id, explanation_hash, override_log_hash, ueb_ver)。
验证规则：
Valid(J_muse) ⇔ Valid(J_grip)
∧ ρ_lang ≥ 0（在 L_cert 连通分量上）
∧ (∀ℓ∉L_cert: lang_degraded = True)
∧ ρ_ux ≥ 0 ∧ ECE ≤ κ_cal ∧ ρ_exp ≥ ρ_exp,min
∧ explanation_hash 与 J_grip 绑定约束一致
∧ override_log_hash 与执行日志一致
∧ ueb_ver 为预注册版本。
审计链：explanation_hash 追溯"人看到什么"，override_log_hash 追溯"人做了什么"，lang_id/ρ_lang 追溯"语义从哪种语言来、覆盖到哪"。

**定义 230（AIA 统一算子）** APP 与 ACP 统一为
a* = argmax_{a∈A∪Q} E[IG(a)] / c(a)，s.t. c(a) ≤ B_type(a)，
其中 c(a) = 损伤代价（物理 probe）或打断代价（语义 ask），B_type 对应 f_safe 或 B_int。二者共享停止规则：E[IG] < δ 或预算耗尽 → 停止；共享调度器按"单位成本信息增益"排序。该统一使第 64 轮"安全-信息张力"在语义层有了精确对偶。

**定义 231（覆盖披露与优雅降级）** lang_degraded = (ℓ ∉ L_cert) ∨ (ρ_lang(ℓ) < 0)。此时自主等级 A ← A_safe（需确认），并显式告知"该语言未认证/一致性不足"，禁止静默用主导语言先验替代。降级必须写入 J_muse 的 lang_id 字段，且 UI 必须可见。

**定义 232（MUSE 算子）** 见 IP-223 伪代码。语义流：[LiDAR → LSF → USR/MEL → GRIP 语义流 → DMS-X/MIG → (ACP) → OCB-UX → LEG → UEB 记录 → AIC-UX → J_muse]；实时流：[GRIP 实时流 + 置信度映射 + 解释缓存派发]。

### IP-214 MIG / DMS-X（跨语言一致性与解析）

```python
class MultilingualInterlingua:
    """u_l -> z -> g；认证翻译图上的最坏边决定 rho_lang。语义流运行。"""
    def __init__(self, encoders, decoder, translator, L_cert, d_max):
        self.enc, self.dec, self.tr = encoders, decoder, translator
        self.L_cert, self.d_max = L_cert, d_max

    def parse(self, u, lang_hint=None):
        l = lang_hint or self.identify(u)                  # 语言识别+置信
        if l not in self.L_cert or self.rho_lang(l) < 0:
            return ('Clarify', {'reason': 'uncertified_language', 'lang': l})
        z = self.enc[l](u)
        hyps = self.dec.structured_hypotheses(z)           # 否定/量词/范围/指代
        if max(p for _, p in hyps) < P_MIN:
            return ('Clarify', dict(hyps))
        g, p = max(hyps, key=lambda t: t[1])
        return ('Goal', g, p)

    def certify(self, corpus):
        edges = []
        for l in self.L_cert:
            for lp in self.L_cert:
                if l == lp: continue
                for u in corpus[l]:
                    g  = self.dec(self.enc[l](u))
                    ub = self.tr(l, lp, u)                  # 翻译
                    gl = self.dec(self.enc[lp](ub))         # 目标
                    edges.append((l, lp, goal_metric(g, gl)))
        rho = 1 - max(d for _, _, d in edges) / self.d_max
        return rho, edges, coverage(self.L_cert, USER_LANG_DIST)

    def rho_lang(self, l):
        return self._component_rho.get(l, -1.0)
```

### IP-215 ACP（主动澄清）

```python
class ActiveClarifier:
    """问题空间 Q；按单位打断成本的信息增益选问。预算不足则降级。"""
    def choose(self, posterior, urgency, budget):
        best, best_ratio = None, -np.inf
        for q in Q_SPACE:
            ig = expected_information_gain(posterior, q)
            c  = (W_ASK + W_TIME * predict_latency(q)
                  + W_CTX * int(interrupting_current_task()))
            if c <= budget and ig > DELTA_CLARIFY and ig / (c + 1e-9) > best_ratio:
                best, best_ratio = q, ig / (c + 1e-9)
        return best, best_ratio

    def act(self, posterior, urgency, budget):
        q, _ = self.choose(posterior, urgency, budget)
        if q is None or entropy(posterior) > H_MIN_AFTER_BUDGET:
            return ('degrade', 'human_confirm')            # 不猜
        answer = ask_human(q)
        return ('update', bayes_update(posterior, answer))
```

```python
def usability_margin(metrics, u_min):
    U = normalize_metrics(metrics)                          # E,F,S,Lr,Tcal,SA,W,X
    return min((U[i] - u_min[i]) / (1 - u_min[i]) for i in range(len(U))), U

def expected_calibration_error(conf, correct, n_bins=10):
    ece = 0.0
    for b in range(n_bins):
        lo, hi = b / n_bins, (b + 1) / n_bins
        idx = (conf >= lo) & (conf < hi)
        if idx.sum() == 0: continue
        ece += idx.mean() * abs(correct[idx].mean() - conf[idx].mean())
    return ece

def explanation_faithfulness(cert, plan, binding_constraints):

    nec = np.mean([decision_flips(remove_constraint(cert, b)) for b in B])
    suf = float(reproduces_decision(keep_only(cert, B)))
```

### IP-219 AIA（统一 probe/ask 调度）

```python
class ActiveInformationAcquisition:
    """物理 probe 与语义 ask 共用预算化信息获取；成本函数不同。"""
    def choose(self, candidates, budget):
        best, best_ratio = None, -np.inf
        for a in candidates:
            ig  = expected_information_gain(a)
            c   = damage_cost(a) if a.kind == 'probe' else interruption_cost(a)
            lim = SAFE_FORCE if a.kind == 'probe' else INT_BUDGET
            if c <= lim and c <= budget and ig / (c + 1e-9) > best_ratio:
                best, best_ratio = a, ig / (c + 1e-9)
        return best, best_ratio                              # None ⇒ 停止/降级
```

```python
def choose_legible_skill(skills, context, lam_leg=0.3, b_expl=0.2):
    best, best_cost = None, np.inf
    for pi in skills:
        c = exec_cost(pi, context) + lam_leg * legibility_loss(pi, context)
        if explanation_cost(pi, context) <= b_expl and c < best_cost:
```

```python
def MUSE_round(M, obs):
    V, T, P, L, P_cloud, W_meas, tactile, u, lang_hint = obs
    # ———— 语义流 ————
    M.lsf.update_geometry(P_cloud)
    # 1) 跨语言解析（MIG/DMS-X）

    # 2) GRIP 语义流（几何/接触/物理/规划）

    phi_geo, _, _, _ = M.mel.infer_by_mode(M.ocb_ux.choose().mel_mode, V, T, P, L, x_prime)
    contact_set = M.mws.last_contacts or M.contact_prior
    r, degraded, _ = M.cgg.step(W_meas, M.q, phi_geo, contact_set, M.Sigma_w, M.rsc.r, M.sigma_J)

    if ambiguous or degraded or M.probe_due():
        a_star, _ = M.aia.choose(M.probe_candidates(), budget=M.force_budget)
        if a_star is not None and a_star.kind == 'probe':
            phi_force, Sigma_force, M.mu_hat, _ = M.fpe.identify(M.execute_probe(a_star), M.Sigma_w)
        else:
            phi_force, Sigma_force = M.last_phi_force, M.last_Sigma_force
    else:
        phi_force, Sigma_force = M.last_phi_force, M.last_Sigma_force

    # 3) 可读技能规划 + 解释
    tau, theta_bind = M.csp_f.plan(goal, x_prime, phi_geo, r, phi_force, Sigma_force, M.mu_hat)
    first = M.ocb_ux.choose(tau)
    expl, rho_exp = M.leg.build(first, J_grip_draft(M, tau, theta_bind, contacts))

    # 4) 实时执行
    K_safe, EV_exec, cert_exec = realtime_step_grip(
        M, M.delta_f_req, [first], [theta_bind[0]], x_prime, phi_force, Sigma_force)

    # 5) 在线更新 + 证据
    M.ueb.log_trial(goal, EV_exec, expl, M.override_log)
    rho_dir, _, _ = M.aic_ux.certify(tau, theta_bind, x_prime, phi_geo, r)
    rho_ux = M.ueb.margin()
    ece = M.trc.calibration_error()
    J = build_j_muse(
        build_j_grip(cert_exec, rho_rob=M.rho, r=r, rho_dir=rho_dir,
                     rho_force=M.rho_force, rho_slip=M.rho_slip,
                     contact_hash=hash(contacts), geo_degraded=degraded),
        rho_lang=M.mig.rho_lang(parsed_lang), cov=M.mig.cov,
        rho_ux=rho_ux, ece=ece, rho_exp=rho_exp,
        lang_id=M.mig.lang_id, expl=expl, overrides=M.override_log)
    return M, K_safe, EV_exec, J
```

## 4. 推导

**引理 7（跨语言一致性传递）** 设翻译图 T 的连通分量 C 中每条边满足 d_ℓℓ′ ≤ ε。对任意 ℓ,ℓ′ ∈ C，沿最短路径 ℓ=ℓ_0,ℓ_1,…,ℓ_k=ℓ′ 用 d_G 的三角不等式：
d_G(g_ℓ, g_ℓ′) ≤ Σ_{i=0}^{k−1} d_G(g_{ℓ_i}, g_{ℓ_{i+1}}) ≤ k·ε ≤ diam_hop(C)·ε。
故 ρ_lang = 1 − ε/d_max ≥ 0 给出的是**分量内**等价，其误差随跳数线性累积。∎

**定理 7（多语言规格安全）** 设安全裕度函数 margin(g) 关于 d_G 为 L_g-Lipschitz。若 g 安全（margin(g) ≥ 0）且 margin(g) > L_g·diam_hop(C)·ε，则由引理 7，C 内任一语言解析出的 g′ 满足 margin(g′) ≥ margin(g) − L_g·diam_hop(C)·ε > 0。对未认证语言 ℓ∉C，设最近认证语言距离为 d_near；若 d_near > margin(g)/L_g，则无法保证等价，必须 lang_degraded 并降级确认。因此，**在覆盖范围内多语言规格安全成立；在覆盖范围外系统显式降级而不静默执行**——不存在"安全但做错任务"的隐藏路径。∎

**引理 8（解释-校准耦合）** 设操作员在置信 c 下接管的决策规则为 1[c ≥ θ_h]（忽略则反之）。其有效误判可分解为：
P_err,human = P[accept ∧ wrong] + P[reject ∧ correct]
= E[ (1 − r(c))·1[c ≥ θ_h] ] + E[ r(c)·1[c < θ_h] ]。
当 ECE ≤ κ 时，对任意桶 |r(c) − c| ≤ κ，故
P[accept ∧ wrong] ≤ E[ (1 − c + κ)·1[c ≥ θ_h] ] = P[c ≥ θ_h]·(1 − θ_h + κ) + O(κ)。
解释保真 ρ_exp 通过降低"人类未识别真实失败模式"的概率，将剩余项乘以 (1 − ρ_exp·η)（η 为解释可干预效率）。故 ρ_exp 越高、κ 越小，人机联合误判越低。∎

**定理 8（可用性-安全联合界）** 在 GRIP 定理 6 的 α_rob、α_slip、α_force 与定理 7 的 α_lang 之上叠加引理 8 的人为项。由联合界：
P_danger ≤ α_rob + α_slip + α_force + α_lang + (1 − θ_h + κ_cal)·(1 − ρ_exp·η) + ε_h。
ρ_ux ≥ 0 由定义 221 保证各维（含 Tcal = 1−ECE）不低于阈值，从而 κ_cal ≤ 1−u_min,Tcal 且主观-客观配对限制了 ε_h 的上界。**可用性因此是安全界的加性项，而非事后软指标**。∎

**定理 9（ACP 交互复杂度与下界）** 设目标熵 H_0，每问最大信息增益 IG_max，则把熵降到 δ 至少需
N ≥ (H_0 − δ)/IG_max
次询问（信息论下界，Fano 型）。打断预算 B_int 下可行当且仅当 N·c_min ≤ B_int。于是当 H_0 − δ > B_int·IG_max/c_min 时，**不存在**既满足打断预算又把不确定性降到 δ 的策略——任何最优策略只能选择"降级确认"。这与第 64 轮 APP 的"力越大信息越多但可能损伤物体"的张力结构完全同构，只是成本从损伤换成打断。∎

**命题（无免费可用性 / 谄媚不对称）** 设满意度 S 可被"顺从度" α 提升（更少拒绝、更平滑置信表达），即 ∂S/∂α > 0；但顺从度同时降低真实拒绝率，使过度依赖桶的 acc 下降、conf 不变，从而 ∂ECE/∂α ≥ 0。由定理 8，∂P_danger/∂α ≥ (∂ECE/∂α)·(1 − ρ_exp η) ≥ 0。故存在区间使 ∂P_danger/∂S > 0：**把满意度当唯一目标会系统性提高危险概率**。缓解：S 只作为受约束维度，ECE 与 ρ_exp 为硬约束；验收以"校准 + 客观干预行为"为主指标。∎

**命题（覆盖披露的必要性）** 若系统对 ℓ∉L_cert 静默使用最近语言的先验，则由定理 7 其误差界失效（d_near 可能任意大），且 J_muse 的 ρ_lang 字段不反映真实风险，证书可被伪造为 Valid。故覆盖披露（定义 231）是 ρ_lang 证书 soundness 的必要条件，而非可选 UI 提示。∎

## 7. 已知风险

**一句话**：可用性与信任本质是**主观、语境依赖、可被讨好式优化**的量——把满意度/信任当 KPI 会诱导系统"让用户更放心"而非"让用户更准确判断"，把可用性认证从安全层变成**过度信任的加速器与安全剧场**；同时跨语言一致性只能对 L_cert 的连通分量负责，未覆盖语言的"静默回退"会让 ρ_lang 证书产生**虚假的普适保证**，这是本轮全部论证共同依赖的隐藏前提（A89）。

**次级风险与缓解**：
1. **可用性指标可被游戏（Goodhart）**：SUS/TLX 可被"少拒绝、多顺从"刷高，但 ECE 上升；缓解：S、Tcal、ρ_exp 与客观接管行为联合约束，预注册，红队谄媚压力（E240）。
2. **人因样本不具代表性**：N=24 的操作员不能代表真实部署人群；缓解：分层（语言/经验/年龄）+ 报告效应量与 CI + 现场 A/B，不把实验室 ρ_ux 直接当部署结论。
3. **跨语言覆盖永远不完备**：长尾语言/方言/混杂语无法穷尽；缓解：覆盖披露 + 未认证即降级确认（定义 231/命题），绝不静默。
4. **翻译图被污染/对抗翻译**：恶意回译可让两条边都"看起来一致"但共同偏移；缓解：多翻译器交叉验证、人工锚点集、回译+改写双重约束、目标空间物理可执行性校验。
5. **解释保真与自然语言流畅性冲突**：模板化忠实解释可能生硬；缓解：忠实性为硬约束、流畅性为软目标，禁止用独立 LLM 自由生成解释。
6. **ACP 打扰过度**：澄清问句过多降低效率与信任；缓解：打断预算 B_int + 单位成本信息增益 + 频繁澄清触发个体基线自适应（SSB 交互记忆）。
7. **提示注入/指令越权**：多语言通道扩大攻击面；缓解：指令与数据通道隔离、权限白名单、注入对抗训练，注入按 AIC-UX 最坏情形认证。
8. **实时预算超支**：语言模型若误入实时路径会击穿 2ms；缓解：架构上物理隔离（实时线程不链接 LLM 运行时），解释只读缓存，监控实时路径 P99。
9. **可用性与安全目标冲突**：用户可能偏好"更少确认、更快执行"，与 ρ_ux 的安全约束矛盾；缓解：确认成本显式纳入 AIA，安全阈值不可由用户调低，仅可调高。
