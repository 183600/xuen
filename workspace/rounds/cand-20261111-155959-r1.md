# 第 56 轮（承接第 55 轮语义-接触层；灵感循环第 2 轮；本轮灵感：「UniBot-V1」×「跨物体泛化」）

> 第 55 轮把“感知标签”落到“接触约束 + 全身生存核”。本轮把“一个统一策略会很多物体”这一泛化主张拆开：**UniBot-V1 的泛化边界不在语言或外观空间，而在物理交互签名空间**。核心矛盾：**H24（泛化假象）**：跨物体泛化的成败由“物体在任务中诱发的接触签名”决定，而非外观相似度；视觉域随机化只会让人“看起来见过”，却可能从未见过“质量 3 倍、摩擦 1/5、可变形”的同类物。**H25（物体维度不可折叠）**：物体差异经质量、摩擦、柔顺性、拓扑进入接触力，直接改变第 55 轮的全身生存核 `K(Σ)`；单物体鲁棒不能推出物体集合鲁棒，物体维度必须在证书里被显式参数化，而不是藏在数据增广里。

## 0. 直觉与动机

**灵感 1（UniBot-V1 → 把“统一策略”重述为“等价类上的不变量”）**
直觉：一个统一模型能处理很多物体，不等于它对任意物体都灵。更准确、也更可检验的陈述是：存在一个**任务条件化的物体等价类**，在类内策略行为几乎不变，出类则性能断崖。于是“跨物体泛化”应从跑分变成 **成员判定 + 不变量证书**：部署时先问“这个新物体是否落在某个已认证等价类的 ε-邻域内”，再决定是否放行接触丰富动作。

**灵感 2（跨物体泛化 → 物体交互签名，而非外观嵌入）**
直觉：让机器人失败的不是“看不出这是杯子”，而是“以为是空杯、其实是满杯”（质量/质心），或“以为是干的、其实是湿滑的”（摩擦）。把物体在任务 `T` 下的 **交互签名** `s(O,T)` 定义成与接触动力学直接相关的物理量：几何抓取度、质量-惯量（含质心）、表面摩擦、柔顺性/可变形、关节拓扑、接触可供性剖面。泛化 = 在该签名度量空间里的邻域包含，而不是图像嵌入的余弦相似。

**灵感 3（泛化假象 → 用“物理对抗球”替代“外观增广”）**
直觉：外观增广让模型见过更多“看起来不同”的物体，但可能从未见过“重 3 倍、滑 5 倍、软到会塌”的物体。真正该做的是在交互签名空间里做 **物理对抗扰动** `𝓞_ε = {O' : d_S^T(s(O,T), s(O',T)) ≤ ε}`，并报告最坏成功率 `ρ_obj(ε)`。这与第 53 轮鲁棒性谱、第 55 轮语义谱共用同一证书框架，只是在 `ρ` 上再加一个**物体维**。

**灵感 4（先探后抓 → 用安全探测把签名不确定性压进证书预算）**
直觉：面对新物体，直接做接触丰富抓取等于把安全押在未标定的质量/摩擦上。应先做 **低风险探测**（轻推、短程称重、小幅滑动、视觉-力觉互证）以最大化签名信息增益，再把更新后的后验送入证书。`a* = argmax_a I(s; y_a | ŝ)`，约束是单步安全、接触轻量、可逆。这把第 54 轮的“主动动作剖面采样”升级为 **主动物体系统辨识**。

**灵感 5（泛化的充分条件 → 变换群等变性做“可证明迁移”的锚）**
直觉：如果策略对某些物体变换是等变/不变的（尺度、水平旋转、外观换肤、夹爪坐标系重参数化），那么在群轨道内的迁移不需要重新学。等变性不是泛化的全部，却是一个**可检验的充分条件**：检查 `π(g·O) ≈ g·π(O)`，反例即迁移风险证人。它把“我觉得它能泛化”变成“在 `G_obj` 的轨道上它必然泛化”。

**灵感 6（统一物体-具身迁移 → 物体签名 × 具身签名双匹配）**
直觉：UniBot-V1 若还要跨形态（不同臂长、手指数、自由度），只匹配物体不够。需同时匹配 **具身签名** `e(E)`（可达性、抓取包络、力上限、关节限位）。只有当 `s(O,T)` 与 `e(E)` 在任务约束下共同落入证书域，迁移才成立；否则会得到“模型会、身体够不着/夹不住”的假泛化。

**灵感 7（组合域 → 物体切换必须重算技能兼容）**
直觉：第 54 轮的技能组合图 `G_S` 是在固定物体分布上建的。换物体后，接触点、抓取宽度、允许力都会变，原来 `compat(S_i,S_j) ≥ θ_a` 的两项技能可能因“交接时物体滑脱”而不兼容。因此物体切换不是一个前置分类问题，而是 **对技能链重算接触连续性**：沿组合路径检查 `Δ_contact`（接触签名漂移）是否始终在预算内。

## 1. 形式化定义（增量：定义 127–132）

**定义 127（任务条件化物体交互签名 OIS）**
给定任务 `T` 与物体 `O`，交互签名
`s(O,T) = (g, m, μ, β, τ, c) ∈ S = G×M×F×B×𝒯×𝒞`，
其中 `g` 为几何/抓取度量（尺寸、曲率、最小抓取宽度），`m` 为质量-惯量参数（含质心），`μ` 为接触摩擦（静/动/各向异性），`β` 为柔顺性/可变形参数，`τ` 为关节/拓扑（自由度、连通性、开合），`c` 为接触可供性剖面 `κ(·;O)`。
任务条件化度量
`d_S^T(s,s') = (Σ_k w_k(T)·ρ_k(s_k,s'_k)²)^{1/2}`，
`ρ_k` 为各分量归一化距离（质量取对数、摩擦截断到 `[0,1]`、柔顺取对数刚度、拓扑取图编辑距离），`w_k(T) ≥ 0` 由任务对物理量的敏感度给出。任务无关分量降权，保证同一物体在不同任务下属于不同等价类。

**定义 128（ε-交互等价类与泛化域）**
`O ≡_{T,ε} O' ⇔ d_S^T(s(O,T), s(O',T)) ≤ ε`。
泛化域 `𝓞_ε(O) = {O' : O ≡_{T,ε} O'}`。`ε` 由证书的物理扰动预算决定，**不由外观相似度决定**。

**定义 129（物体条件化生存核与跨物体鲁棒性谱）**
`K(Σ,O) = {x | ∃u,λ : f(x,u,λ)=ẋ ∧ supp(λ)⊆C(Σ;O) ∧ λ∈FC(μ(O)) ∧ x_{t+1}∈𝒳_safe}`。
`ρ_obj(ε_o) = inf_{O'∈𝓞_{ε_o}(O)} P(success(π,O') | ŝ(O))`，即签名扰动球内的最坏保持概率；与第 55 轮 `ρ_sem` 正交叠加，共同构成 `(ρ, ρ_sem, ρ_obj)` 三维谱。

**定义 130（跨物体泛化证书 OGC）**
`J_o = (𝓞_cert, s_core, d_{S,max}, ρ_obj, Δ_contact, evidence)`：
- `𝓞_cert` 已认证等价类，`s_core` 类中心签名，`d_{S,max}` 类内最大签名偏差；
- `ρ_obj` 物理扰动球内最坏成功率，`Δ_contact` 沿动作链的接触签名漂移上界；
- `evidence` 含物理对抗反例、探测日志、失效锚点。
成员判定采用保守规则：`d_S^T(ŝ(O_t), s_core) + U_s ≤ d_{S,max}`（`U_s` 为签名估计不确定度）。由三角不等式，真实类内距离必在 `d_{S,max}` 内，故判定是 sound 的。

**定义 131（信息增益探测策略 IGP）**
安全探测集 `A_probe`（轻接触、可逆、能耗受限）。选择
`a* = argmax_{a∈A_probe} I(s; y_a | ŝ)`，`s.t. risk(a,O) ≤ θ_r ∧ contact_mass(a) ≤ θ_m`。
探测后验 `p(s|y)` 收缩到 `U_s ≤ U_max` 才允许进入接触丰富动作；否则维持保守策略或请求外部标定。

**定义 132（物体-具身双签名统一迁移 UOE）**
具身签名 `e(E)=(reach, grasp_envelope, f_max, dof, jlim)`。统一迁移算子 `Φ:(π,O,E) → π_{O,E}`。
可迁移条件：`(ŝ(O), ê(E)) ∈ 𝓓_cert`，其中联合证书域 `𝓓_cert` 要求
`∃ grasp ∈ grasp_envelope(E) ∩ C^+(Σ;O)` 且 `λ_required ≤ f_max(E)`，且沿技能链 `Δ_contact ≤ Θ_c`。
这把“模型会不会”与“身体能不能”合并成一个可判定条件。

## 2. 关键算法 伪代码

### IP-127 OSE（Object Signature Estimation）

```python
def estimate_signature(rgbd, proprio, force, task, calibrator):
    z = fuse_encoder(rgbd, proprio, force)
    mu_s, log_sigma_s = signature_head(z, task)        # g,m,mu,beta,tau,c
    mu_s = calibrator.inverse(mu_s)                    # 温度/分位数校准
    U_s = conformal_radius(mu_s, log_sigma_s, alpha)   # 校准后误差上界
    return Signature(mu_s, U_s)
```

### IP-128 OEC（Object Equivalence Certification）

```python
def certify_object_equivalence(Ot, J_src, task):
    s_hat, U_s = estimate_signature(*Ot.obs(), task, ...)
    gap = d_S(s_hat, J_src.s_core, task)
    if gap + U_s > J_src.d_S_max:                      # 不确定度算进距离：保守
        return ('out_of_domain', gap + U_s, J_src.d_S_max)
    C = contact_affordance(s_hat, task)
    if not (C & J_src.contact_core):
        return ('contact_mismatch', C)
    return ('in_domain', gap + U_s)
```

### IP-129 OGS（Object Generalization Spectrum）

```python
def object_generalization_spectrum(O, task, eps, sampler, policy):
    worst = 1.0
    for O_adv in sampler.signature_ball(s(O, task), eps, worst_case=True):
        O_sim = realize_object(O, O_adv)               # 重设质量/摩擦/柔顺/拓扑
        p = empirical_success(policy, O_sim, task)
        worst = min(worst, p)
    return worst
```

### IP-130 OGP（Object-Gain Probing）

```python
def safe_probe(O, s_prior, A_probe, risk_model, theta_r, U_max):
    s_post = s_prior
    for a in sorted(A_probe, key=lambda a: -expected_info_gain(s_post, a)):
        if risk_model(a, s_post) > theta_r:
            continue
        y = execute_probe(a)
        s_post, U_s = bayes_update(s_post, y)
        if U_s <= U_max:
            return s_post, 'calibrated'
    return s_post, 'probe_budget_exhausted'
```

### IP-131 OGE（Object-Group Equivariance Check）

```python
def equivariance_check(policy, G_obj, objects, tol):
    # G_obj: 尺度/水平旋转/外观/夹爪重参数化等任务无关变换群
    for g in G_obj:
        for O in objects:
            a1 = policy(O)
            a2 = policy(g(O))
            if d_action(a1, g_inv(a2)) > tol:
                return ('violate', g, O, witness=(O, a1, a2))
    return ('pass', G_obj)
```

### IP-132 UGC（Unified Generalization Certificate）

```python
def unified_generalization_certificate(pi, O, E, task, budgets):
    s_hat, U_s = estimate_signature(*O.obs(), task, ...)
    if U_s > budgets.U_max:
        s_hat, st = safe_probe(O, s_hat, budgets.A_probe, ...)
        if st != 'calibrated':
            return ('reject', 'signature_uncertain')
    if certify_object_equivalence(O, budgets.J_src, task)[0] != 'in_domain':
        return ('reject', 'object_out_of_domain')
    if not embodiment_compatible(E, s_hat, task):
        return ('reject', 'embodiment_incompatible')
    if contact_drift_along_chain(pi, O, task) > budgets.Theta_c:
        return ('reject', 'contact_drift')
    rho_obj = object_generalization_spectrum(O, task, budgets.eps_o, ...)
    if rho_obj < budgets.rho_min:
        return ('reject', 'object_robustness_fail')
    if equivariance_check(pi, budgets.G_obj, ...)[0] != 'pass':
        return ('reject', 'equivariance_violation')
    return ('ok', ObjectCert(s_hat, U_s, rho_obj, contact_drift, ...))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| OSE | O(N_enc + |S|) | O(|S|) | 保形校准、传感器时间同步 |
| OEC | O(|S|) | O(|S|) | 三角不等式 + 不确定度上界 sound |
| OGS | O(N_adv·T_rollout) | O(|S|·N_adv) | 物理对抗球覆盖/外近似 sound |
| OGP | O(|A_probe|·T_probe + update) | O(|S|) | 探测安全、后验收缩可验证 |
| OGE | O(|G_obj|·|O_test|·T_infer) | O(1) | 变换群正确、容差可审计 |
| UGC | O(OSE + OGS + OGE) | O(|S|) | 各子证书合取、预算闭合 |

**正确性定理（Cross-Object Transfer Soundness）**
假设第 55 轮 (A29)–(A32) 成立；**(A33)** 签名估计器满足保形覆盖：对可交换物体 `P(d_S^T(s,ŝ) ≤ U_s) ≥ 1-α`；**(A34)** `d_S^T` 为度量且认证类为 ε-球，成员判定单调；**(A35)** 物理对抗采样器对 ε-球 sound（或给出保守外近似）；**(A36)** 探测动作有界风险且可逆；**(A37)** 等变性检查的容差与动作度量一致，无漏检。
则目标物体上的迁移安全概率满足
```
P(transfer ∧ safe) ≥ 1 - α - P(ρ_obj < ρ_min) - P(φ_hidden) - P(E incompatible) - P(equivariance miss)
```
其中 `φ_hidden` 是“存在未纳入签名的物理因素改变了任务成败”的概率。
关键：**等价类判定把估计不确定度加到距离上、物理谱覆盖签名球、探测把 `U_s` 压进预算、双签名排除“身体做不到”**。但 `φ_hidden` 不受保形校准控制，它是模型设定误差而非采样误差，是公式里唯一不能靠加数据消除的项。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 签名不完备，漏掉隐藏物理因素 | 高 | 残差监测 + 隐藏因素对抗集 + 保守外近似 |
| 任务条件权重 `w_k(T)` 标定主观 | 高 | 用下游成功率做权重敏感性分析，报告谱下界 |
| 物理对抗采样未覆盖真实失效模式 | 高 | 仿真-真机同构校验 + 反例回灌 + 主动找最坏 |
| 探测扰动本身改变物体状态 | 中 | 可逆探测、力/位移预算、探测后重置校验 |
| 等变性容差过松导致漏检 | 中 | 容差与动作度量绑定 + 见证自动归档 |
| 双签名域过保守导致“拒绝一切新物体” | 中 | 分层域 + 探测驱动扩张 + 人工标定通道 |

## 6. 本轮最大风险

**一句话**：把跨物体泛化重写为“物理交互签名等价类 + 物理对抗谱 + 物体-具身双匹配”使其从跑分变成可判定证书，但其 soundness **根本依赖签名 `s(O,T)` 已覆盖所有会改变任务成败的物理因素**；一旦存在未建模的隐藏因素（内部液体晃动、温度、表面污染、柔性铰链磨损），保形校准仍会让一个“签名相同、物理不同”的新物体被判为域内，证书会把最危险的分布外失败包装成“已认证”，因此必须以 **残差监测 + 隐藏因素对抗集 + 物理谱保守外近似** 三重护栏，宁可误拒新物体，绝不把“签名相似”当作“已证实可迁移”。

# 第 56 轮产物 · 创新点清单 v32：UniBot-ObjGen（OSE×OEC×OGS×OGP×OGE×UGC）

> 承接第 55 轮语义-接触层（IP-121~126）与第 54 轮 v31 GroundEdge-GenSim+++。本轮在“接触是否可信、全身是否可行”之上新增 **物体维度**：把“跨物体泛化”从外观跑分改写为 **物体交互签名空间中的等价类认证 + 物理对抗谱 + 主动探测 + 物体-具身双匹配**。
> - **OSE** Object Signature Estimation：任务条件化交互签名的估计与保形校准；
> - **OEC** Object Equivalence Certification：ε-交互等价类的保守成员判定；
> - **OGS** Object Generalization Spectrum：物理对抗扰动下的跨物体鲁棒性谱 `ρ_obj`；
> - **OGP** Object-Gain Probing：安全信息增益探测，先探后抓；
> - **OGE** Object-Group Equivariance：物体变换群等变性/不变性检查与反例证人；
> - **UGC** Unified Generalization Certificate：物体签名 × 具身签名 × 技能链接触漂移的统一泛化证书。
>
> IP 编号：IP-127~IP-132（新增 6 个）；并入第 55 轮 IP-121~126，形成 v32。

def object_generalization_spectrum(O, task, eps, sampler, policy):

### IP-130 OGP

```python
def safe_probe(O, s_prior, A_probe, risk_model, theta_r, U_max):
    for a in sorted(A_probe, key=lambda a: -expected_info_gain(s_prior, a)):
        if risk_model(a, s_prior) > theta_r:
            continue
        s_post, U_s = bayes_update(s_prior, execute_probe(a))
        if U_s <= U_max:
            return s_post, 'calibrated'
    return s_post, 'probe_budget_exhausted'
```

### IP-131 OGE

```python
def equivariance_check(policy, G_obj, objects, tol):
    for g in G_obj:
        for O in objects:
            d = d_action(policy(O), g_inv(policy(g(O))))
            if d > tol:
                return ('violate', g, O, witness=(O, d))
    return ('pass', G_obj)
```

### IP-132 UGC

```python
def unified_generalization_certificate(pi, O, E, task, budgets):
    s_hat, U_s = estimate_signature(*O.obs(), task, ...)
    if U_s > budgets.U_max:
        s_hat, st = safe_probe(O, s_hat, budgets.A_probe, ...)
        if st != 'calibrated':
            return ('reject', 'signature_uncertain')
    if certify_object_equivalence(O, budgets.J_src, task)[0] != 'in_domain':
        return ('reject', 'object_out_of_domain')
    if not embodiment_compatible(E, s_hat, task):
        return ('reject', 'embodiment_incompatible')
    drift = contact_drift_along_chain(pi, O, task)
    if drift > budgets.Theta_c:
        return ('reject', 'contact_drift', drift)
    rho_obj = object_generalization_spectrum(O, task, budgets.eps_o, ...)
    if rho_obj < budgets.rho_min:
        return ('reject', 'object_robustness_fail')
    if equivariance_check(pi, budgets.G_obj, ...)[0] != 'pass':
        return ('reject', 'equivariance_violation')
    return ('ok', ObjectCert(s_hat, U_s, rho_obj, drift))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| OSE | O(N_enc+|S|) | O(|S|) | 保形覆盖 `≥1-α`，传感器同步 |
| OEC | O(|S|) | O(|S|) | 三角不等式 + `U_s`，域判定 sound |
| OGS | O(N_adv·T_rollout) | O(|S|·N_adv) | 物理球覆盖/外近似 sound |
| OGP | O(|A_probe|·T_probe) | O(|S|) | 探测有界风险、后验收缩 |
| OGE | O(|G_obj|·|O|·T_infer) | O(1) | 群作用正确、容差可审计 |
| UGC | O(OSE+OGS+OGE) | O(|S|) | 子证书合取、预算闭合 |

**正确性定理（Cross-Object Transfer Soundness）**
假设第 55 轮 (A29)–(A32) 与**这一轮**的 (A33)–(A37) 成立：保形覆盖、签名度量为度量、物理对抗球 sound、探测安全、等变检查无漏检。则
```
P(transfer ∧ safe) ≥ 1 - α - P(ρ_obj<ρ_min) - P(φ_hidden) - P(E incompatible) - P(equivariance miss)
```
四层结构：**签名等价类（保守含不确定度）→ 物理谱（覆盖签名球）→ 探测（把 `U_s` 压进预算）→ 双签名与等变（排除身体做不到与可证明迁移）**。其中只有 `φ_hidden` 不可由校准/加数据消除，必须在证书里显式保留为残余风险。
