# 第 12 轮（灵感循环第 2 轮；本轮灵感：「真实世界泛化」×「参数高效微调」）

> **基线**：第 11 轮 MetricVoiceGauge-NCD-H（定义 554–570；引理 96–103；实验 E589–E606；IP-363–366）。
> 本轮纪律：**泛化必须被认证、适配必须低秩、适配不得越过证书、失效即整体退回 v11**。不推倒 v11：HAS/HCC/HATD/HDT、MetricVoiceGauge 九不变式、NGE/DSL/CC/CWM/CAE/NCP、AC/MW/ID、DA/SPR/Cal 全部保留；四个新组件挂在一条**单点可关断的适配旁路**上，任一失效即关闭整条旁路，严格等价退回 v11（引理 111），再沿 v11 十三级链退回 v10/v9/v8/v7/v6。本轮只做三件事：把"真实世界泛化"变成可检查的元证书、把"参数高效微调"限制在证书允许的低秩子空间、把"适配"变成可版本化/可回滚/可审计的生命周期。

## 0. 直觉与动机

### 0.1 v11 真正遗留的两个缺口

v11 已经把规范、接触、因果、谐波四类约束接进同一个块级决策闭环，并把执行器柔顺度提升为技能与证书的一等公民。但它仍默认两件事：

1. **证书的适用范围等于标定分布。** v11 的四重证书（物理、接触、谐波、规范）都在"标定数据 + HDT 参数化域随机化"内被认证。D_DR 覆盖 k_h、d_h、滞回、负载惯量、摩擦与温度，但这些全是**参数漂移**；真实世界还会发生**结构漂移**（新物体、新材质、新接触模式、新传感器、新用户规范）与**语义漂移**（新任务、新偏好、新禁忌）。v11 的证书没有回答："换一个结构不同的真实域，我这套证书还成立多少？"它知道自己"在仿真里多安全"，却不知道"在真实部署分布上还能信谁"。

2. **系统没有"低成本变可信"的中间路径。** 要么冻结 v11（在漂移下失效），要么全参数重训（破坏九不变式、引理与证书，且灾难性遗忘）。真实世界泛化需要的是一条中间路径：只改少量参数、只改证书允许的方向、改错能拔掉、改对能积累。v11 没有参数预算、没有适配版本、没有证书包络，因此它只能"全信"或"全不信"。

两个缺口会互相放大：**越不敢改，越依赖仿真；越依赖仿真，越容易在真实世界自信地失效。** 这不是"鲁棒性不够"，而是"泛化没有被认证"。

### 0.2 灵感 1（真实世界泛化 → 泛化不是鲁棒，而是"知道证书的边界"）

直觉：我们常把"真实世界泛化"理解成"在分布外还能完成任务"。但在一个已经带四重安全证书的系统里，更重要的不是平均成功率，而是**证书在真实分布上还成立多少**。一个在 99% 的样本上成功的策略，可能在 1% 的接触相变上越界；平均性能会把这 1% 藏起来，证书不会。真正的泛化能力不是"我到处都能做"，而是"我知道我在哪里还能安全地做、在哪里必须停下来"。

核心创新：**泛化元证书监视器（Generalization Certificate Monitor, GCM）**。它是"证书的证书"：不签发新的物理/接触/谐波证书，而是给出现有证书在真实分布 P_t 上的**违规率上界**与**余量下界**。

形式化直觉：把每个证书在状态 x 的归一化松弛量记为 c_j(x)，令 C(x)=min_j c_j(x)，违规指示 V(x)=1[C(x)<0]。真实风险 R_t=E_{P_t}[V]。GCM 不给"平均性能"，而给 R_t 的高概率上界，以及 C 在漂移下的下界。关键是**泛化前沿**：

```
F_δ = { P_t : UCB_δ(R_t) ≤ δ_g  且  m_eff(P_t) > 0 }
```

系统的能力不是一个点，而是这个集合。GCM 的职责是判断"当前 P_t 是否还在 F_δ 内"，而不是假装它永远在。这个"边界意识"比任何鲁棒训练都更接近真实世界泛化的本质。

### 0.3 灵感 2（参数高效微调 → 只长一颗可拔的器官）

直觉：PEFT 最诱人的地方不是"省算力"，而是**它把学习变成了一个可插拔、可检查、可拔除的器官**。LoRA 的 W→W+BA（r≪min(d,k)）意味着主干完全冻结：v11 的九不变式、引理与四重证书原封不动；增量是低秩的：参数、存储、审计都可控；适配器可版本化、按域路由、按需切换、一键回滚。相比"重训一个黑箱"，这是更符合安全关键系统的学习形态。

核心创新：**低秩适配器银行（Low-Rank Adaptation Bank, LRAB）**。适配器只挂在"软端口"上：

- CWM 的任务残差预测头；
- HATD 的段评分/启发式偏置；
- HAS 的柔顺残差（不改变硬限幅）；
- NGE 的软偏好头（不改变硬规范）。

硬安全端口——力限、停止条件、硬规范、谐波耗散、接触中止点——**零适配**。这不是工程洁癖，而是把"可学习"与"不可学习"用结构分开：安全不靠适配器学会，而靠主干保证。

关键警告：**低秩不等于安全。** ΔW=BA 仍然可以改变证书输出；一个只追求任务损失的 LoRA 完全可能学到"绕过力限的捷径"，而且低秩让这种越界更难被全参数审计发现。所以 PEFT 必须与证书包络同轮交付。

### 0.4 灵感 3（两者统一 → 泛化消耗余量，适配花剩余余量）

直觉：把适配参数 a 看成一个向量，把证书输出 c(x;a) 在 a=0 处线性化：

```
c(x;a) ≈ c_0(x) + J_c(x)·a
```

真实世界漂移先消耗证书余量，适配再消耗剩下的。于是有本轮的**泛化–适配预算方程**：

```
m_0 = L_C·W_1(φ#P_t, φ#P_0) + β_cov + L_a·||a|| + m_reserve
```

其中 m_0 是参考域上的最小证书余量，W_1 是域指纹空间中的漂移，L_C 是证书对域特征的 Lipschitz 常数，β_cov 是有限样本覆盖误差，L_a 是证书对适配参数的敏感度，m_reserve 是必须保留的安全储备。

这条方程是本轮的核心：它不把泛化和安全相加，而是让它们**共享同一个余量预算**。漂移越大，可安全适配的秩/范数越小；余量不够时，系统只能保守执行或求助。这也解释了为什么"先泛化再适配"是错的：泛化不是免费的，它花掉的正是适配想用的余量。

核心创新：**证书感知适配投影器（Certificate-Aware Adapter Projector, CAAP）** 与 **适配器生命周期注册表（Adapter Lifecycle Registry, ALR）**。CAAP 把任意候选适配器投影到认证适配子空间：

```
S_cert = { a : sup_x ||J_c(x)||·||a|| ≤ m_0 − L_C·W_1 − β_cov − m_reserve }
```

ALR 负责版本化、影子验证、原子切换、回滚、正交合并与遗忘控制。CAAP 是"安全笼子"，ALR 是"可拔器官"。

### 0.5 四者如何统一

GCM 判断"要不要适配、还能不能信"；LRAB 提供"低成本适配"；CAAP 保证"适配不越证书"；ALR 保证"适配可回滚、可审计、可积累而不遗忘"。四者共享域指纹 φ 与适配版本 a_t，形成慢环：

```
感知 → 域指纹 → 泛化元证书 → 触发/拒绝适配 → 低秩适配
     → 证书投影 → 影子验证 → 原子切换 → 再认证
```

执行侧仍然只跑 v11 的 50Hz 证书守卫；适配器只提议、不认证、不进入实时关键路径。适配器可以改变"候选长什么样"，但不能改变"什么被允许执行"。

### 0.6 为什么不是这些"显然的解法"

- **不是全参数微调**：破坏九不变式、引理与实时预算，无法回滚，且灾难性遗忘。
- **不是只在仿真里加大域随机化**：DR 覆盖参数不确定性，不覆盖结构/语义漂移；v11 已把参数 DR 用到极致。
- **不是用 OOD 检测器替代泛化证书**：检测器只回答"像不像"，不回答"证书还能不能信"的概率上界。
- **不是直接把 LoRA 接到策略上**：没有证书包络的低秩增量可以学到绕过安全约束的捷径；低秩不是安全属性。
- **不是在线 50Hz 适配**：破坏实时性与可复现性；适配必须在慢环，执行侧只读版本号。
- **不是把适配器当成新的证书签发者**：适配器没有签发权；四重对象级证书仍由 v11 认证器签发，`Ĉ_g` 由 GCM 签发，适配器只提供候选与评分。

## 1. 研究问题（轮次升级版）

- **Q1（泛化元证书可估性）**：如何用有限真实样本 + 域指纹，给出证书违规率的高概率上界与余量下界，且对结构漂移敏感、对域指纹遗漏稳健？
- **Q2（认证适配子空间紧致性）**：如何计算/近似 S_cert，使一阶/区间界既安全又不过度保守？当 S_cert 为空时，如何区分"真的不能适配"与"界太松"？
- **Q3（低秩适配的偏差–方差–证书三角）**：rank r、样本数 n、漂移 W_1 如何共同决定可安全适配的边界？是否存在最优 r？
- **Q4（多域生命周期）**：如何组合/正交化/回滚适配器，避免灾难性遗忘、组合越界与证据投毒？
- **Q5（与 v11 的兼容）**：GCM/LRAB/CAAP/ALR 任一失效是否严格等价 v11？六重证书会不会过度保守导致无可行段？适配器能否保证不改变 v11 的物理执行集？

## 2. 设计原则（在 P16–P18 基础上新增 P19–P22）

**P19 泛化元证书一等公民律（Generalization Meta-Certificate First-Class）**
任何真实世界部署都必须携带 GCM 签发的元证书 Ĉ_g=(UCB_δ(R_t), m_eff, φ_id, W_1, coverage, valid_region)。Ĉ_g 不替代任何对象级证书，只声明"它们在当前 P_t 上还成立多少"。Ĉ_g 失效 ⇒ 禁止适配，并进入保守执行或求助；禁止用"平均成功率"替代元证书。

**P20 冻结主干–低秩适配律（Frozen Backbone, Low-Rank Adaptation）**
适配只能发生在显式声明的软端口上，参数增量必须是低秩的（rank ≤ r_max，参数量 ≤ B_adapt），主干参数永不改写。硬安全端口（力限、停止、硬规范、谐波耗散）参数冻结；适配器必须可版本化、可路由、可回滚、可移除。

**P21 证书包络律（Certificate Envelope）**
任何适配器在执行前必须通过 CAAP 投影，满足 L_a·||a|| ≤ m_adapt。适配器只能缩小候选集、改变评分/预测/软偏好，不能签发或放宽任何 v11 证书。若投影失败，适配器被禁用；若执行时证书守卫发现实际越界，立即回滚到父版本并触发 GCM 复检。

**P22 适配生命周期与单点旁路律（Lifecycle & Single-Point Bypass）**
适配器必须经过"证据账本 → 影子验证 → 原子切换 → 漂移监控 → 回滚/隔离"的生命周期。GCM/LRAB/CAAP/ALR 任一失效，整条适配旁路关闭（不是只关单个组件），严格等价 v11。旁路关闭是单点的、可审计的、默认安全的。

## 3. 与基线的接口（如何退化）

- **GCM 失效** ⇒ 无泛化门，禁止启动适配，执行冻结 v11；**等价 v11 保守路径**；
- **LRAB 失效** ⇒ 无适配器可用，planner 只看到 v11 候选；**等价 v11 规划路径**；
- **CAAP 失效** ⇒ 禁止裸跑适配器，整条适配旁路关闭；**等价 v11 灵巧/执行路径**；
- **ALR 失效** ⇒ 无法保证版本/回滚，整条适配旁路关闭；**等价 v11**；
- **四者全失效** ⇒ MetricVoiceGauge-NCD-H v11，再沿 v11 十三级链退回 v10/v9/v8/v7/v6；
- **安全继承**：适配器无证书签发权；CAAP 只缩小适配集；GCM 只读证书余量；ALR 只切换版本。v11 的物理/接触/谐波/规范四重证书在 v11 子集上继续成立（引理 112）。

## 4. 预期贡献

1. **泛化元证书与泛化前沿**：把"真实世界泛化"从训练目标变成可检查的证书对象，给出违规率上界与余量下界，并显式定义系统能力的边界 F_δ。
2. **认证低秩适配**：把 PEFT 限制在证书余量允许的子空间，提出泛化–适配预算方程、CAAP 投影算法与安全性证明，回答"低秩为什么不等于安全"。
3. **适配器生命周期**：版本化、影子验证、原子切换、回滚、正交合并与遗忘控制，支撑长期多域真实部署，而不是一次性 sim-to-real。
4. **向后兼容的 v12 单点旁路**：证明适配旁路关闭逐位等价 v11，实时预算不变，实验 E607–E624 覆盖元证书、投影、秩权衡、组合、遗忘、投毒与端到端收益。

## 5. 本轮最大风险

**一句话**：把泛化证书建立在与被适配数据同源、且只覆盖可观测域指纹的漂移上，会让系统把"没见过的真实世界"误认证成"已泛化"；低秩适配器再把这种错误洗成局部合规的行为——**最危险的泛化，是被自己的证书认证过的泛化**。

- Level-11：v8 的 DA/SPR/Cal 任一失效 ⇒ 中立元注入，**等价 v7**；
- Level-12：全失效 ⇒ 完整退回 v7，再退回 v6。

**为什么是"单点旁路"而不是四个独立中立元。** v11 的四个中立元作用于互不相交端口，任一失效都能落到 v11 的明确退化点。v12 不同：一个**没有被证书包络约束的适配器**不是 v11 的退化版本，而是一个新的越界攻击面；"关掉包络但保留适配器"不是安全降级，而是把安全带剪断后继续开车。因此 v12 只承认一种中性状态：`v12^⊥` 关闭整条适配旁路，`K_adapt=∅`、`a≡0`、`plan≡plan_v11`，主闭环逐位退回 v11。这不是保守，而是把"适配"定义为全有或全无的安全关键操作。

## 1. 符号体系增量（定义 571–585）

**定义 571（泛化元证书 Generalization Meta-Certificate）** 由参考分布统计、真实样本与当前适配范数签发：

```
Ĉ_g = ( R̂_t, UCB_δ(R̂_t), m_eff, Ŵ_1, φ_id, n_t, coverage, valid_region )
```

其中

```
R̂_t = (1/n_t) Σ_i V(x_i)
m_eff = m_0 − L_C·Ŵ_1 − β_cov(n_0,δ) − L_a·‖a‖
```

有效条件：

```
UCB_δ(R_t) ≤ δ_g  ∧  m_eff > m_reserve  ∧  φ_id ∈ valid_region
```

`Ĉ_g` 不替代任何对象级证书，只声明"它们在当前 P_t 上还成立多少"；它是**关于证书的证书**。

**定义 572（域指纹与泛化前沿）** 冻结特征映射 φ 把多模态观测压到域指纹空间。参考分布 P_0 由仿真+标定数据估计。漂移

```
W_1(φ#P_t, φ#P_0) = inf_{γ∈Γ(P_t,P_0)} ∫ ‖φ(x)−φ(y)‖ dγ(x,y)
```

由熵正则 OT 或域分类器上界估计。**泛化前沿**定义为

```
F_δ = { P_t : Ĉ_g(P_t) 有效 }
```

系统的能力不是一个点，而是这个集合；GCM 的任务是判断当前 P_t 是否仍在 F_δ 内。

**定义 573（参数高效适配器 Parameter-Efficient Adapter）** 冻结主干权重 W_l，只在软端口 l 上加低秩增量：

```
W_l(a_l) = W_l + s_l·B_l A_l,   B_l∈ℝ^{d_l×r_l}, A_l∈ℝ^{r_l×k_l}, r_l ≤ r_max
a = vec({A_l,B_l})
```

硬安全端口（力限、停止条件、硬规范、谐波耗散、接触中止点）的适配参数恒为 0。适配器是**读多写少**的：执行时只读，训练/切换只发生在慢环。

**定义 574（认证适配子空间 Certified Adaptation Subspace）** 对每个证书 j，设参考域最小余量 m_0j 与敏感度 L_{a,j}=sup_{x∈X_cert}‖J_{c,j}(x)‖。给定漂移 W 与覆盖误差 β_cov,j：

```
m_adapt,j = m_0j − L_C,j·W − β_cov,j − m_reserve,j
S_cert = { a : L_{a,j}·‖a‖ ≤ m_adapt,j  对所有 j }
```

若任一 m_adapt,j ≤ 0，则 S_cert=∅，本轮禁止适配。S_cert 是"证书余量允许的适配球"；它把泛化漂移与适配范数放进同一个预算。

**定义 575（证书感知投影 Certificate-Aware Projection）** 对候选适配器 a，定义

```
Π_cert(a) = a · min_j min( 1, m_adapt,j / (L_{a,j}·‖a‖ + ε) )
```

若存在二阶项，则用半径 ρ 解

```
(H_j/2)·ρ² + L_{a,j}·ρ ≤ m_adapt,j
```

并取 ρ_j=min(ρ, m_adapt,j/L_{a,j})。投影是一阶/二阶包络下的保守收缩；它幂等、非扩张，且若 S_cert≠∅ 则输出必在 S_cert 内。

**定义 576（适配器银行与路由 Adapter Bank & Routing）** 适配器银行

```
𝒜 = { a_j = (params, hash, φ_j, ledger_j, shadow_j, parent_j) }
```

路由：

```
j* = argmin_j ‖φ(x)−φ_j‖
```

若距离 > ρ_route，则不使用适配器，退回 v11 并触发"需要适配"信号。**同一时刻只允许一个适配器激活**；组合仅在定义 578 的正交条件下允许。适配器只改变候选评分/残差，不改变 v11 证书。

**定义 577（适配器生命周期与影子验证 Adapter Lifecycle & Shadow Validation）** 状态机：

```
candidate → shadow → active → deprecated → quarantined
```

候选进入 shadow 前必须有定义 583 的证据账本。影子验证集包含：真实留出域、结构漂移压力集、对抗/近失集、仿真反事实集。激活条件：

```
证据量 ≥ N_min ∧ 影子证书违规 = 0 ∧ 包络有效 ∧ 漂移监控为绿
```

激活采用**原子版本切换**（episode 边界），旧版本保留为回滚父版本；失败则隔离，不删除。

**定义 578（适配器组合与干扰界 Adapter Composition & Interference）** 组合 `a=Σ_j a_j`。由三角不等式与双线性交叉项：

```
‖Δc‖ ≤ Σ_j L_{a,j}‖a_j‖ + C·Σ_{i≠j} ‖a_i‖‖a_j‖·cos θ_ij
```

其中 θ_ij 是两适配器参数子空间的主角。若 cos θ_ij ≤ ρ（近正交），交叉项 ≤ Cρ(Σ‖a_j‖)²；若不能保证，则**串行激活**而非同时合并。组合也必须通过 CAAP 的联合投影。

**定义 579（泛化触发适配决策 Generalization-Triggered Adaptation）** 慢环决策在四个模式中选择：

```
execute_v11  : Ĉ_g 有效且性能缺口小
adapt        : Ĉ_g 失效但 m_adapt > 0 且证据充分
ask/fallback : Ĉ_g 失效且 m_adapt ≤ 0 或影子失败
quarantine   : 适配器被检出越界/投毒
```

这是**认识论级**决策：它不直接产生 50Hz 动作，只决定"下一步是否值得花余量去学"。

**定义 580（慢环适配闭环 Slow Adaptation Loop）** 适配在 episode 边界/后台运行：

```
收集证据 → 训练低秩 a → CAAP 投影 → 影子验证 → 原子切换 → 再认证
```

50Hz 控制回路只读当前 `v_t` 与适配器前向，不执行训练/投影/验证。适配的时间尺度是分钟到小时，执行的时间尺度是毫秒。

**定义 581（中立元与单点旁路 Neutral Element & Single-Point Bypass）**

```
v12^⊥ = ( GCM≡valid-on-P_0, LRAB≡∅, CAAP≡identity, ALR≡no-op )
```

注入 `v12^⊥` 后 `K_adapt=∅`、`a≡0`、`plan≡plan_v11`，主闭环逐位等价 v11。与 v11 不同，v12 的四个组件是**合取旁路**：任一组件的失效都触发整个 `v12^⊥`，而不是只替换该组件。理由是：未被包络约束的适配器不是安全降级，而是新的越界面。

**定义 582（六重证书合取 Six-Fold Certificate Conjunction）**

```
Ĉ_all = Ĉ_phys ∧ Ĉ_contact ∧ Ĉ_h ∧ Ĉ_norm ∧ Ĉ_g ∧ Ĉ_adapt
```

其中 `Ĉ_g` 是泛化元证书，`Ĉ_adapt` 是适配包络证书：

```
Ĉ_adapt = ( hash_a, rank, ‖a‖, L_a·‖a‖, m_adapt,
            envelope_valid, shadow_report, parent_version )
```

有效 ⇔ `a∈S_cert` ∧ `envelope_valid` ∧ `shadow_report.violations=0` ∧ `parent_version` 可达。`Ĉ_g` 与 `Ĉ_adapt` 只能删候选，不能替代或放宽前四者。

**定义 583（适配证据账本 Adaptation Evidence Ledger）** 每条账本记录：

```
(hash_data, domain_id, φ_id, hash_adapter, rank, train_loss,
 shadow_report, certificate_envelope, parent_version, timestamp, approver)
```

账本强制"训练证据"与"证书证据"分离：证书证据必须来自独立留出域，不能与适配训练数据同源。它是防止"自证泛化"的审计抓手。

**定义 584（升级中止点 Upgraded Abort Points）**

```
P_t = P_t^nav ∪ P_t^c ∪ P_t^h ∪ P_t^g
```

`P_t^g` 是泛化安全中止点：从该点开始，在当前 `Ĉ_g` 下存在 v11 认证的回退/保守轨迹。若 `P_t^g=∅`，禁止适配，只允许 v11 保守执行或求助。

**定义 585（升级任务分解 Upgraded HATD Segment）** HATD 输出的每段增加 `(adapter_id, Ĉ_g)`：

```
seg = ( π_h^{1:K}, Ĉ_h, Ĉ_contact, Ĉ_safety, Ĉ_norm, Ĉ_g, Ĉ_adapt, P^nav, P^c, P^h, P^g )
```

分段可行性要求 `Ĉ_g` 有效；若无效，该段只能使用 v11 技能或直接拒绝。适配器只能在 v11 认证候选集内重排序/重加权，不能新增候选。

## 2. 形式化定义（要点与升级）

**升级定义 547（接触证书，v12）** 证书合取升级为

```
Ĉ_joint = Ĉ_contact ∧ Ĉ_h ∧ Ĉ_g ∧ Ĉ_adapt
```

有效 ⇔ 四者均有效。中止点 `P^joint = P^c ∩ P^h ∩ P^g`；若交集为空，该段不可执行，HATD 必须重新切分或退回 v11。

**升级定义 534'（中止点，v12）** 中止点集加入 `P^g`。块可执行必要条件：当前模式对应的中止点集非空，且 `P^g≠∅` 才能使用适配器。

**升级定义 557（谐波感知任务分解，v12）** HATD 的候选集仍是 v11 候选集；适配器只提供评分偏置/残差，不扩张候选。段的可行性检查增加 `Ĉ_g` 与 `Ĉ_adapt`。

**升级定义 560（中立元表，v12）** v11 的 HAS/HCC/HATD/HDT 中立元保持不变；v12 在它们之前增加**旁路级中立元** `v12^⊥`。注入顺序：先 `v12^⊥` 关闭适配旁路，再按 v11 链退化。

**升级定义 531（软硬约束衔接，v12）** M₀ 硬检查增加：

- `Ĉ_g` 失效却尝试适配 ⇒ 硬违规；
- 适配器输出超出 `S_cert` ⇒ 硬违规；
- 执行时实际证书越界且适配器为当前激活版本 ⇒ 立即回滚并标记账本。

v11 的物理/接触/谐波/规范 M₀ 判据不因适配而放宽。

# IP-367 GeneralizationCertificateMonitor
class GeneralizationCertificateMonitor:
    def __init__(self, phi, delta_g, m_reserve, L_C, beta_cov, L_a):
        self.phi = phi                  # frozen multimodal fingerprint
        self.delta_g = delta_g
        self.m_reserve = m_reserve
        self.L_C = L_C
        self.beta_cov = beta_cov
        self.L_a = L_a

    def certificate(self, real_batch, P0_stats, adapter_norm):
        # violation rate on real batch
        violations = [int(self._min_slack(x) < 0) for x in real_batch]
        R_hat = sum(violations) / max(len(violations), 1)
        ucb = hoeffding_upper(R_hat, len(violations), self.delta_g)

        # domain shift in fingerprint space
        W_hat = wasserstein1(self.phi(real_batch), P0_stats.phi_samples)

        # effective margin after shift and adaptation
        m_eff = (P0_stats.m0
                 - self.L_C * W_hat
                 - self.beta_cov
                 - self.L_a * adapter_norm)

        return GenCert(R_hat=R_hat, UCB=ucb, m_eff=m_eff, W_1=W_hat,
                       phi_id=P0_stats.phi_id, n_t=len(real_batch),
                       valid=(ucb <= self.delta_g and m_eff > self.m_reserve))

    def _min_slack(self, x):
        return min(c.slack(x) for c in self.certifiers)   # v11 四重证书

    def allows_adaptation(self, cert):
        return cert.m_eff > self.m_reserve


# IP-368 LowRankAdaptationBank
class LowRankAdaptationBank:
    def __init__(self, soft_ports, r_max, budget):
        self.soft_ports = soft_ports     # explicit allow-list
        self.r_max = r_max
        self.budget = budget
        self.adapters = {}               # id -> AdapterVersion

    def adapt(self, domain_data, base_policy, port_id, rank, steps):
        assert port_id in self.soft_ports
        rank = min(rank, self.r_max)
        a = init_lowrank(rank)           # A, B for frozen W
        for _ in range(steps):
            loss = task_loss(base_policy, a, domain_data)
            loss += cert_hinge(base_policy, a, domain_data)   # penalize margin loss
            loss += l2(a)
            a = gradient_step(a, loss)
        return a

    def route(self, phi_x):
        if not self.adapters:
            return None
        j = min(self.adapters, key=lambda k: self.adapters[k].distance(phi_x))
        if self.adapters[j].distance(phi_x) > self.adapters[j].route_radius:
            return None                  # out of frontier -> v11
        return self.adapters[j]

    def hard_ports_frozen(self):
        return all(a.mask_hard == 0 for a in self.adapters.values())


# IP-369 CertificateAwareAdapterProjector
class CertificateAwareAdapterProjector:
    def __init__(self, certifiers, L_a_by_cert, H_by_cert):
        self.certifiers = certifiers
        self.L_a = L_a_by_cert          # sup ||J_c(x)||
        self.H = H_by_cert              # second-order bound

    def project(self, a, m_adapt_by_cert):
        if any(m <= 0 for m in m_adapt_by_cert.values()):
            return None                  # S_cert empty -> disable adaptation

        # first-order radii per certificate
        radii = []
        for j, L in self.L_a.items():
            radii.append(m_adapt_by_cert[j] / (L + 1e-12))
        rho = min(radii)

        # second-order refinement: (H/2) rho^2 + L rho <= m
        for j, L in self.L_a.items():
            H = self.H.get(j, 0.0)
            r2 = solve_quadratic(H / 2.0, L, -m_adapt_by_cert[j])
            rho = min(rho, r2)

        norm = vector_norm(a)
        if norm <= rho:
            return a
        return scale(a, rho / (norm + 1e-12))

    def envelope_valid(self, a, m_adapt_by_cert):
        for j, L in self.L_a.items():
            if L * vector_norm(a) > m_adapt_by_cert[j]:
                return False
        return True


# IP-370 AdapterLifecycleRegistry
class AdapterLifecycleRegistry:
    def __init__(self, test_suite, drift_monitor):
        self.test_suite = test_suite
        self.drift = drift_monitor
        self.active = None
        self.parent = None
        self.quarantine = []

    def submit(self, cand, ledger):
        assert ledger.data_hash not in ledger.seen      # independent evidence
        cand.ledger = ledger
        return cand

    def shadow_validate(self, cand, cert_g):
        report = self.test_suite.run(cand)
        ok = (report.certificate_violations == 0
              and report.success >= report.baseline - report.eps
              and report.envelope_valid
              and cert_g.valid)
        cand.shadow = report
        return ok

    def activate(self, cand):
        self.parent = self.active
        self.active = cand              # atomic pointer swap at episode boundary

    def rollback(self):
        self.active = self.parent

    def quarantine_adapter(self, cand, reason):
        cand.state = 'quarantined'
        self.quarantine.append((cand, reason))

**实现纪律：**

1. 适配器**没有证书签发权**：`apply_adapter_scores` 只改排序，不改 `Ĉ_contact/Ĉ_h/Ĉ_norm`；
2. `caap.envelope_valid` 在 50Hz 只做 O(p) 范数比较，不做投影；投影只在慢环；
3. `alr.activate` 只在 episode 边界，绝不在 chunk 中途切换；
4. 任一适配组件异常 ⇒ `v12^⊥` ⇒ 直接调用 `metricvoicegauge_round_11`；
5. 训练数据与证书证据在账本中分离，禁止同源自证。

## 4. 推导

**引理 104（泛化元证书的覆盖–漂移界）** 设 (A1) 证书域 X_cert 紧致，φ 是 L_φ-Lipschitz，最小松弛 C 对 φ 是 L_C-Lipschitz；(A2) P_0 与 P_t 存在耦合，W_1(φ#P_0,φ#P_t)≤W；(A3) 参考集 n_0 个 i.i.d. 样本、真实集 n_t 个可交换样本。则置信度 ≥1−δ 下：

```
m_eff(P_t) ≥ m_0 − L_C·W − β_cov(n_0,δ)
UCB_δ(R_t) ≤ R̂_t + sqrt( log(1/δ) / (2n_t) )
```

若真实样本不可交换，则再加一项域差异惩罚。证明：由 C 的 Lipschitz 性与最优耦合，对任意耦合样本 (x,y) 有 |C(x)−C(y)|≤L_C‖φ(x)−φ(y)‖，积分得最小松弛下降不超过 L_C·W；有限样本项由 DKW/Clopper–Pearson 给出；违规率由 Hoeffding 给出。∎

**引理 105（泛化–适配预算方程）** 在引理 104 的假设下，对任意适配器 a：

```
m_eff(P_t; a) ≥ m_0 − L_C·W − β_cov − L_a·‖a‖
```

其中一阶 `L_a=sup_x‖J_c(x)‖`；二阶时加 `(H/2)‖a‖²`。因此安全适配集恰为定义 574 的 S_cert，可适配余量为 `m_adapt=m_0−L_CW−β_cov−m_reserve`。证明：对 c(x;a) 在 a=0 处 Taylor 展开，一阶项由 J_c(x)a 控制，余项由 Hessian 控制；对 x 取上确界并代入引理 104 的 m_eff 即得。∎

**引理 106（证书感知投影的安全性）** 若 S_cert≠∅，则对任意 a，`Π_cert(a)∈S_cert`，且 Π_cert 幂等、非扩张。投影后适配器满足所有证书约束，并保留 `m_reserve` 的安全储备。证明：径向缩放把范数压到最小半径 ρ=min_j m_adapt,j/L_{a,j}，故每个约束 L_{a,j}‖Π(a)‖≤m_adapt,j；幂等性来自 `Π(Π(a))=Π(a)`；非扩张性来自到凸球的径向投影。二阶情形由二次方程的正根给出保守半径。∎

**引理 107（低秩适配的偏差–方差–证书三角）** 设真实漂移可由秩 r 的适配器以残差 ε_r 近似。则适配策略在 P_t 上的风险满足

```
R_t(a_r) ≤ R_0 + ε_r + O( sqrt( r(d+k)·log(n/δ) / n ) ) + L_C·W
```

因此存在最优 r* 平衡近似误差 ε_r 与样本复杂度项；r 太大反而过拟合，r 太小则表达不足。证明：标准 PEFT 泛化界（参数量 p=r(d+k)）+ 近似误差 + 域漂移项；对 r 求导/离散扫描得最优。∎

**引理 108（适配器组合的干扰界）** 对 `a=Σ_j a_j`，证书扰动满足

```
‖Δc‖ ≤ Σ_j L_{a,j}‖a_j‖ + C·Σ_{i≠j} ‖a_i‖‖a_j‖·cos θ_ij
```

若 `cos θ_ij ≤ ρ`，交叉项 ≤Cρ(Σ‖a_j‖)²；正交（ρ=0）时组合与单独适配的证书界同阶。证明：双线性交叉项展开 + 主角定义 `cos θ_ij=‖P_iP_j‖`；对交叉项用 Cauchy–Schwarz。∎

**引理 109（影子验证与回滚的失效概率）** 设影子验证使用 m 个独立留出域，候选在观测到零违规时才被接受。若候选真实违规率 ≥p，则接受概率 ≤(1−p)^m。若漂移检测每轮以 ≥γ 的概率发现坏适配器，则在 k 轮后仍激活的概率 ≤(1−p)^m + (1−γ)^k。证明：零违规事件的概率 (1−p)^m；坏适配器每轮未被发现的概率 ≤1−γ，几何衰减；两者取并集界。∎

**引理 110（慢环适配的实时预算守恒）** GCM 估计、LRAB 训练、CAAP 投影、ALR 影子验证均在慢环/离线执行；50Hz 路径只做 O(1) 版本读取与 O(r·d) 低秩前向。取 r≤8、软端口≤4，增量 <0.2ms；决策侧 p99 仍 ≤22ms，50Hz 不丢拍。证明：逐项复杂度代入 + 静态 EDF 校验 `ΣŴ_m≤B_dec`；训练/投影移出实时路径。∎

**引理 111（单点旁路等价 v11）** 注入 `v12^⊥` 后，GCM 恒返回 "P_0 有效"、LRAB 为空、CAAP 为恒等、ALR 为 no-op；因此 `K_adapt=∅`、`a≡0`，planner 只看到 v11 候选，主闭环调用序列与 v11 逐位一致。再由 v11 引理 102 可继续退化到 v10/v9/v8/v7/v6。证明：定义 581 直接给出空适配集与恒等算子；主闭环在旁路自检失败时直接调用 `metricvoicegauge_round_11`。∎

**引理 112（适配不扩张认证执行集）** 对任意激活适配器 a∈S_cert，通过六重证书的执行动作集合是 v11 四重证书执行集合的子集。适配器只能重排序/重加权 v11 候选，不能新增 v11 拒绝的候选。证明：`Ĉ_all=Ĉ_v11∧Ĉ_g∧Ĉ_adapt`，合取只删不增；CAAP 保证 `Ĉ_adapt`；GCM 保证 `Ĉ_g`；v11 认证器未改；`apply_adapter_scores` 只改评分。∎

**引理 113（泛化前沿的单调性）** 若 `W_1(φ#P_t,φ#P_0)` 减小（更接近参考域），则 `m_adapt` 单调增大，S_cert 单调扩张，F_δ 单调增大；反之漂移增大则适配预算收缩。证明：由定义 574 与引理 105，m_adapt 对 W 线性递减，S_cert 的半径对 m_adapt 单调递增。∎

## 8. 已知风险与失效模式

1. **自证泛化**：GCM 与适配器使用同一批真实数据，元证书在训练集上"自证"，在新域失效。缓解：训练/证书证据账本分离、独立留出域、conformal 校准、对抗漂移压力集、影子验证。
2. **域指纹遗漏**：φ 看不到的漂移方向（新材质、透明物体、接触声学变化）导致 W_1 低估。缓解：多模态指纹、重构误差、集成 φ、主动探针、残差检测。
3. **低秩表达不足/过拟合**：r 太小无法覆盖结构漂移，r 太大过拟合且样本复杂度上升。缓解：秩扫描、逐层秩、混合适配器、元初始化、残差非参数模型。
4. **证书包络过度保守**：Lipschitz/一阶界太松，S_cert 为空，系统永远退回 v11。缓解：IBP 收紧、逐层界、二阶项、分层余量、S_cert 空时诊断"真不能"与"界太松"。
5. **组合与遗忘**：多适配器合并越界或相互干扰。缓解：正交子空间（O-LoRA）、单适配器激活、串行组合、联合投影、EWC。
6. **适配器投毒/后门**：恶意数据训练出"局部合规、全局越界"的适配器。缓解：证据账本哈希、影子验证、签名适配器、异常检测、隔离区。
7. **实时预算**：适配器前向与包络检查增加延迟。缓解：低秩、缓存、慢环训练、GPU 批处理、只读版本号。
8. **规范漂移**：用户偏好变化被适配器学成"新规范"，可能绕过硬规范。缓解：硬规范端口冻结、软偏好头独立、NGE 硬约束不放宽、a_ask 兜底。

## 9. 本轮最大风险

**一句话**：把泛化证书建立在与被适配数据同源、且只覆盖可观测域指纹的漂移上，会让系统把"没见过的真实世界"误认证成"已泛化"；低秩适配器再把这种错误洗成局部合规的行为——**最危险的泛化，是被自己的证书认证过的泛化**。
