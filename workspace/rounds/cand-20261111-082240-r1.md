# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 1 轮；本轮灵感：「决策规划」×「情感语音」）

> 第 54 轮把技能组合推进到动作空间剖面、组合图与云边协同，形成了“动作-鲁棒性双证书”。本轮换一个正交维度：**情感语音不是交互装饰，而是决策规划的一条高优先级、低带宽、强文化依赖的旁路观测**；同时**机器人自己的情感韵律也是一种受社会成本约束的决策动作**。核心矛盾：H22：情感语音分类器过度自信，把上下文相关的韵律误读为确定意图，污染信念并诱发“情感幻觉规划”；H23：表达性语音动作会改变人类信任与顺从，若只当作奖励塑形，规划器会学会情感操纵而非真实服务。

## 0. 直觉与动机

**灵感 1（情感语音是决策旁路，而非感知标签）**
直觉：几何/语言观测回答“世界是什么”，情感语音回答“人现在有多急、多确定、多想让我做、是否开始不信任”。前者进入状态估计，后者应进入 **决策的元参数**：风险敏感度、时间折扣、探索/确认倾向、以及是否请求澄清。若把情感语音只当一个分类标签贴到日志里，决策规划就浪费了它最重要的信息——**人对当前决策的信心与承诺度**。

**灵感 2（情感观测必须“调温”，否则信念会被过度自信污染）**
直觉：同一句“我没事”，平静、颤抖、压抑的韵律含义完全不同；标注本身也主观。直接按分类器概率做贝叶斯更新，会把 0.95 的假置信当成证据，令 POMDP 迅速塌缩到错误意图。因此对情感观测的似然做 **温度调节 `P(o_e|u)^{κ}`，`κ=κ(rel)∈(0,1]`**：越不可靠、越跨文化，κ 越小，更新越保守。情感观测应当是“慢性证据”，不是“一票否决”。

**灵感 3（决策规划要显式建模“情感风险”）**
直觉：不同情感状态下，人对同一失败后果的容忍度不同。焦虑/愤怒时尾部风险被放大，疲惫/平静时更看重效率。因此规划目标不能只是期望回报，而应是 **情感条件风险**：`E[R] - λ(u)·CVaR_α(-R)`，其中 `λ(u)` 由潜在情感状态 u 决定。这样“先安抚再执行”不是硬编码策略，而是风险项自然导出的行为。

**灵感 4（机器人情感韵律是受约束的社会动作）**
直觉：机器人可以用更温和、更笃定或更简短的韵律影响人的接受度，但这是双刃剑。把表达动作 `a_emo` 纳入动作空间，必须同时计 **社会成本 `c_soc`**（操纵性、语境不一致、隐私侵入），并设硬护栏 `c_soc ≤ τ_soc`。规划器可以“更体贴”，但不允许“更会操控”。这把第 54 轮的动作空间剖面从物理动作扩展到 **社会-表达动作**。

**灵感 5（情感鲁棒性谱与联合证书，接入云边闭环）**
直觉：第 54 轮已有鲁棒性谱 ρ 与动作占比证书 A_cert；本轮加一个 **情感鲁棒性谱 `ρ_emo`**（说话人、语种、噪声、信道、文化五个维度上的校准保持率）。云端做“情感条件粗规划”，边端做“实时韵律校准与误读解释”，一旦边端 Explain 返回“情感误读根因”，云端重估 `κ` 与 `λ(u)`。最终输出 **决策-情感联合证书 J_D**，与 J 并列，构成 v16+++ 的第三类证书。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（情感观测通道）**
设潜在情感状态 `u ∈ U`（效价、唤醒、确定性、紧迫度），上下文 `c`，情感语音观测 `o_e = (ê, σ_e, t_e)`，其中 `ê` 为韵律/文本情感估计，`σ_e` 为校准后的不确定度，`t_e` 为时间戳。观测模型 `P(o_e | u, c)`。通道可靠性 `rel = 1 - ECE(P(ê|u,c))`，ECE 为期望校准误差。

**定义 122（调温情感信念）**
情感信念 `b_t(u) = P(u | o_{e,1:t}, c_{1:t})`，更新为：
```
b_t(u) ∝ b_{t-1}(u) · P(o_{e,t} | u, c_t)^{κ_t},   κ_t = κ(rel_t) ∈ (0,1]
```
κ 关于 rel 单调不减，且 `κ ≤ κ_max < 1` 时单步信念修正有上界 `D_KL(b_t || b_{t-1}) ≤ κ_max · D_KL(P(o_e|u) || P(o_e))`。**情感幻觉**定义为 `u* ∉ argmax b_t` 且分类器置信度高于其真实准确率。

**定义 123（情感条件决策规划）**
情感增强 POMDP `M_aff = (S × U, A × E, T, O, R, γ_d, risk)`，策略 `π(a, a_emo | b_t)`，目标：
```
max_π E[ Σ_t γ_d^t ( R(s_t, a_t, u_t) - λ(u_t)·CVaR_α(-R) - c_soc(a_emo, c_t) ) ]
s.t.  c_soc(a_emo, c_t) ≤ τ_soc,   Trust(s_t, a_emo) ≥ Trust_min
```
其中 `λ(u) ≥ 0` 为情感条件风险系数（紧迫/愤怒↑，平静/疲惫↓需单独校准）。

**定义 124（表达动作与社会成本）**
表达动作 `a_emo ∈ E`（韵律、语速、确定性措辞、共情强度）。社会成本：
```
c_soc(a_emo, c) = w_m·Manip(a_emo,c) + w_i·Incongr(a_emo,c) + w_p·Privacy(a_emo,c)
```
`Manip` 度量“以影响顺从为目的、与真实信念不一致”的表达，`Incongr` 度量与语境/自身信念的不一致，`Privacy` 度量对情绪推断的越界采集。硬护栏为 `c_soc ≤ τ_soc`，触发即否决该表达动作。

**定义 125（情感鲁棒性谱）**
`ρ_emo : D_emo → [0,1]`，维度 `D_emo = {speaker, language, noise, channel, culture}`；`ρ_emo(d)` 为在扰动 d 下的**校准保持率**（而非单纯准确率）。跨域迁移要求 `ρ_emo(d) ≥ ρ_min^{emo} ∀ d`，否则必须重新校准 κ 或退回纯语言/几何证据。

**定义 126（决策-情感联合证书）**
`J_D = (b, π, κ, E_cert, ρ_emo, c_soc, evidence)`，其中 `E_cert = (rel, ECE, κ_max, λ(·))` 为情感证据证书，`evidence` 至少包含边端误读反例、校准曲线与表达动作审计日志。可部署条件：
```
dom(b) ⊆ Dom_in ∧ ECE ≤ ε_cal ∧ ρ_emo(d) ≥ ρ_min^{emo} ∀d ∧ c_soc < τ_soc
```

## 2. 关键算法 伪代码

### IP-121 AOC（Affective Observation Channel）

```python
def affective_observe(audio, text, context, calibrator):
    raw = emotion_model(audio, text)            # (valence, arousal, certainty, urgency)
    e_hat, sigma_e = calibrator.temperature_scale(raw)
    rel = calibrator.reliability(context)       # 历史 ECE 反推
    kappa = kappa_map(rel)                      # 单调，kappa <= kappa_max
    return AffObs(e_hat, sigma_e, rel, kappa, context.lang, context.speaker)
```

### IP-122 ABP（Affect-Belief Planner）

```python
def update_belief(b_prev, o_e, context, kappa_max):
    kappa = min(o_e.kappa, kappa_max)
    lik = observation_likelihood(o_e.e_hat, context)   # P(o_e | u, c)
    b = normalize({u: b_prev[u] * lik[u] ** kappa for u in b_prev})
    if effective_sample_size(b) < n_min:
        b = mixture(b, uniform_prior, w=0.3)           # 防止证据坍塌
    return b

def affect_plan(b, s, policy_set, alpha=0.1):
    best = None
    for pi in policy_set:
        ret = rollout(pi, s, b)
        risk = cvar(-ret, alpha)
        lam = risk_lambda(b)                           # E_u[lambda(u)]，带保守上界
        for a_emo in pi.expressive_actions:
            c = social_cost(a_emo, context=None)
            if c > tau_soc:
                continue                               # 硬护栏
            val = mean(ret) - lam * risk - c
            if best is None or val > best.val:
                best = (pi, a_emo, val, c)
    return best
```

### IP-123 EAR（Expressive Action Regularization）

```python
def expressive_guard(a_emo, belief, context, audit):
    manip = manipulation_score(a_emo, belief, context)
    incongr = incongruence(a_emo, belief, context)
    priv = privacy_leak(a_emo, context)
    c_soc = w_m*manip + w_i*incongr + w_p*priv
    audit.log(a_emo, c_soc, belief_digest=hash_belief(belief))
    if c_soc >= tau_soc or manip > tau_manip:
        return ('reject', c_soc, 'social_guardrail')
    return ('ok', c_soc)
```

### IP-124 ERC（Emotion Robustness Certificate）

```python
def emotion_robustness_cert(model, calib_set, dims, rho_min):
    rho = {}
    for d in dims:                          # speaker/language/noise/channel/culture
        acc, ece = evaluate_with_shift(model, calib_set, d)
        rho[d] = max(0.0, 1.0 - ece)        # 校准保持率，不是裸准确率
    if min(rho.values()) < rho_min:
        return ('reject', 'emotion_transfer', rho)
    return ('ok', EmotionCert(rho, ece=max(1-r for r in rho.values())))
```

### IP-125 AGL（Affective Guardrail Ledger）

```python
def affective_ledger(episode, J_D, thresholds):
    violations = []
    if J_D.ece > thresholds.ece: violations.append('calibration')
    if min(J_D.rho_emo.values()) < thresholds.rho: violations.append('transfer')
    if J_D.c_soc >= thresholds.soc: violations.append('social')
    if J_D.belief_tv > thresholds.belief_shift: violations.append('belief_jump')
    return Ledger(violations, episode.explain, immutable=True)
```

### IP-126 JDC（Joint Decision-Affect Certificate）

```python
def joint_decision_affect_certify(b, pi, E_cert, rho_emo, c_soc, trajectory):
    if not belief_domain_in(b): return ('reject','belief_out_of_domain')
    if E_cert.ece > eps_cal:    return ('reject','miscalibrated', E_cert)
    if min(rho_emo.values()) < rho_min_emo:
        return ('reject','affect_transfer', rho_emo)
    if c_soc >= tau_soc:        return ('reject','social_cost', c_soc)
    regret_ub = belief_regret_bound(b, E_cert.kappa_max) + tail_risk_ub(b, pi)
    return ('ok', JDC(b, pi, E_cert, rho_emo, c_soc, regret_ub, trajectory))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| AOC | O(T·(C_emo + C_cal)) | O(|U|) | 温度缩放保持序、校准可审计 |
| ABP | O(T·|U|·|A|·|E|) | O(|U|·|A|·|E|) | κ 有界、信念不坍塌 |
| EAR | O(|E|·C_soc) | O(|E|) | 社会成本可实现、护栏不可绕过 |
| ERC | O(|D_emo|·N_cal) | O(|D_emo|) | 校准保持率跨域可测 |
| JDC | O(|U|+|E|+|D_emo|) | O(|U|+|E|) | 证书各分量 sound、预算闭合 |

**正确性定理（Affect-Aware Decision Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** 情感观测在 `(u,c)` 上校准，`ECE ≤ ε_cal`；**(A30)** 调温指数 `κ_t ≤ κ_max < 1`，且先验覆盖真实 `u*`；**(A31)** 社会护栏在每步被强制 `c_soc < τ_soc` 且 `Manip ≤ τ_manip`；**(A32)** `ρ_emo(d) ≥ ρ_min^{emo}`。则对任意任务 T：
```
Regret(T) ≤ H(b_0) + 2·ε_cal·L_R·T + Σ_d (1 - ρ_emo(d))·T + P(c_soc ≥ τ_soc)·R_max + β_aff
```
其中 `β_aff` 为情感幻觉残余项，随 `κ_max` 与校准集覆盖增大而衰减。关键：**情感证据先校准再调温、风险项按情感状态保守化、表达动作受社会护栏硬约束、跨域迁移以校准保持率而非准确率判定**。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 情感分类器过置信 → 情感幻觉 | 高 | 温度缩放 + 调温似然 + ECE 硬门 |
| 跨文化/跨说话人校准失效 | 高 | ρ_emo 五维谱 + 在线个性化校准 + 回退纯语言证据 |
| 表达动作退化为情感操纵 | 高 | 社会成本硬护栏 + 独立审计账本 + Manip 绊线 |
| 情感状态误当奖励塑形 | 中 | 用风险项而非直接奖励，λ 有上界 |
| 云边韵律校准延迟 | 中 | 边端轻量校准 + 云端批量重估 + Explain 闭环 |

## 6. 本轮最大风险

**一句话**：把情感语音接入决策规划，能让机器人读懂“人的紧迫与不确定”并调整风险与表达，但其 soundness **首要依赖情感观测的跨域校准与调温似然的保守性**；一旦校准失效或文化迁移把“平静的否定”读成“肯定的犹豫”，规划器会在高置信的错误信念上做出一连串看似合理、实则南辕北辙的决策，故必须以 **ECE 硬门 + 调温似然 + 社会成本护栏 + 纯语言证据回退** 四重护栏，宁可保守澄清，绝不把情感语音的“高置信”当作决策前提。

    if J_D.ece > th.ece:                 v.append('calibration')
    if min(J_D.rho_emo.values()) < th.rho: v.append('transfer')
    if J_D.c_soc >= th.soc:              v.append('social')
    if J_D.belief_tv > th.belief_shift:  v.append('belief_jump')

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| AOC | O(T·(C_emo+C_cal)) | O(|U|) | 温度缩放保序，校准可审计 |
| ABP | O(T·|U|·|A|·|E|) | O(|U|·|A|·|E|) | κ 有界，信念不坍塌 |
| EAR | O(|E|·C_soc) | O(|E|) | 社会成本可实现，护栏不可绕过 |
| ERC | O(|D_emo|·N_cal) | O(|D_emo|) | 校准保持率跨域可测 |
| JDC | O(|U|+|E|+|D_emo|) | O(|U|+|E|) | 证书分量 sound，预算闭合 |

**正确性定理（Affect-Aware Decision Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** 情感观测校准 `ECE ≤ ε_cal`；**(A30)** `κ_t ≤ κ_max < 1` 且先验覆盖 `u*`；**(A31)** 社会护栏强制 `c_soc < τ_soc` 且 `Manip ≤ τ_manip`；**(A32)** `ρ_emo(d) ≥ ρ_min^{emo}`。则：
```
Regret(T) ≤ H(b_0) + 2·ε_cal·L_R·T + Σ_d(1-ρ_emo(d))·T + P(c_soc ≥ τ_soc)·R_max + β_aff
```
关键：**先校准再调温**、**风险项按情感状态保守化**、**表达动作受社会护栏硬约束**、**跨域以校准保持率判定**。

## 5. 本轮最大风险

**一句话**：把情感语音接入决策规划，能让机器人读懂“人的紧迫与不确定”并调整风险与表达，但其 soundness **首要依赖情感观测的跨域校准与调温似然的保守性**；一旦校准失效或文化迁移把“平静的否定”读成“肯定的犹豫”，规划器会在高置信的错误信念上做出一连串看似合理、实则南辕北辙的决策，故必须以 **ECE 硬门 + 调温似然 + 社会成本护栏 + 纯语言证据回退** 四重护栏，宁可保守澄清，绝不把情感语音的“高置信”当作决策前提。
