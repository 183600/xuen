### 第 6 轮灵感驱动研究记录

**灵感词**：数据配比、微调

**继承关系**：第 5 轮 CADVS-v5（IP-493~496）把提议器从离散规则升级为条件流匹配 π_θ^FM，引入 LMEM-v2 固化、FAMK 情感调制、七硬门不变与执行集嵌套 Exec_CADVS-v5 ⊆ Exec_CADVS-v4 ⊆ … ⊆ Exec_v29；但其最大风险 R57「固化自指回路」仍未解——策略在自己铸证的片段上反复微调，价值模型又在线自适应，闭环缺外部真值，策略可学会形式合规、实质违背地博弈证书门。本轮两个灵感词合成为主题「认证数据配方与防火墙微调」（Certified Data Recipe & Firewalled Fine-Tuning, CDF），形成 CADVS-v6（IP-497~500）。本轮自律仍是：**硬门不增、锚点不增**（七门七锚原样冻结），只改「喂给提议器的数据」与「怎样微调提议器」这两件 v5 没管好的事。执行集嵌套升级为 Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ … ⊆ Exec_v29。

**直觉与动机**：

1. **数据配比 → 把「训练数据配方」从超参数升级为带证书的一等控制变量，用外生锚比例 α 稀释自指**。R57 的根因不是「微调」本身，而是训练分布是内生的：样本来自策略自己的铸证轨迹，标签来自同一套门/价值模型，于是策略在拟合自己的判断。直觉上，打破自指最直接的办法不是把门锁得更死（门已冻结，再锁只会牺牲能力），而是**往训练锅里强制加入「与策略无关」的原料**：人工审计的独立结局标签、外部红队对抗样本、OOD 探针、失败回放、旧任务保护集。v6 把这些原料组织成数据层（strata），定义配方 μ = (μ_self, μ_audit, μ_fail, μ_adv, μ_ood, μ_legacy)，并引入**外生锚约束** μ_audit+μ_adv+μ_ood ≥ α 与每层下限。关键理论是**定理 9（自指稀释界）**：固化算子的自反馈 Lipschitz 常数随 α 线性衰减，α→1 时闭环退化为开环（完全无自指），α=0 时退回 v5 的自指回路；门博弈漂移率 g(α) ≤ g_ext + (1−α)·K。这把「要不要微调」变成「用什么配比微调」的可证明问题。

2. **微调 → 从「任意梯度更新」升级为「防火墙微调」：梯度不经过门、标签只取结局、边界样本降权、更新有谱范数预算**。v5 的红线「固化只改提议器、不改门」只保证了代码层面门不被更新，却没有保证策略不会**朝着门的判定边界**优化。v6 的 FCFTK 做四件事：(a) **结局标签而非门标签**——训练目标用外部结局验证的成功/失败，绝不用「是否铸证通过」作标签（后者是自证）；(b) **门梯度防火墙**——计算图在门处截断，且对距任一门边界 < δ 的样本按 w_δ(x)=clip(d(x,∂G)/δ, 0, 1) 降权，减少对边界漏洞的拟合；(c) **LoRA + 谱范数投影 + KL 信赖域**——ΔW=BA，‖ΔW‖₂ ≤ ρ，KL(π_new‖π_old) ≤ ε_KL，容量与漂移双重受限；(d) **数据配方证书 D_cert 作为微调的前置门**——配方不满足外生锚/覆盖/DP/独立性就不许固化，fail-closed 保持 v5 策略。**定理 10（防火墙微调证书保持）**：门冻结 + 谱预算 + 信赖域 ⇒ 执行集只缩不涨、策略 TV 漂移 ≤ √(ε_KL/2)；边界降权只给经验性降博弈率，不宣称根除。

3. **两者合流 → 用「影响函数」把数据配比从静态超参变成可审计的闭环控制，但控制对象是数据不是门**。引入 EAIA：对每个训练片段估计其对「门博弈指标」的影响（influence function），高影响的自证片段自动降权/剔除；混合控制器在「外生锚下限 + 每层下限 + DP 预算」约束下做分布鲁棒优化（DRO），在最大化有效样本量 n_eff 的同时最小化最坏层风险。配比本身产生可验证证书（来源哈希、各层比例、逐层 DP 会计、审计独立性证明、红队回归结果），使「数据配方」像执行证书一样可被第三方复核。这样 v6 的闭环是「数据配方 → 微调 → 提议 → 结局验证 → 影响归因 → 调整配方」，反馈落在数据层而非门层——**把自指回路从策略参数上引开到数据配比上，并给数据配比装上外生锚**。

**关键洞见**：v4 问「提议=规则时七门是否足够」；v5 问「提议=任意生成器时证书边界是否保持」；v6 问「当生成器被持续微调时，用什么数据配方才能让证书不退化为自证」。核心转移：**把「防自指」从模型层（锁门、KL、红队）下沉到数据层（外生锚比例 α + 分层配比 + 影响归因）**。门与 τ^4 原样冻结；v6 新增的只有数据配方证书 D_cert、防火墙微调算子 C_ft、影响归因器 Inf，以及 α 调制的提议支撑限制 supp(π_v6^cert) ⊆ supp(π_v5)。执行集嵌套由「同门 + 同阈值 + 仅认证适配器可提议」保证。

**形式化目标（增量）**：
1. 数据层与配方：strata S = {self, audit, fail, adv, ood, legacy}，μ ∈ Δ(S)；外生锚约束 μ_audit+μ_adv+μ_ood ≥ α，每层 μ_s ≥ floor_s；有效样本量 n_eff(μ) = 1 / Σ_s μ_s²/n_s。
2. 配方证书 D_cert = (provenance, μ, {ε_s}, independence_audit, coverage, redteam_regression)，验证函数 Verify(D_cert) ∈ {0,1}。
3. 防火墙微调：C_ft(θ; D_cert) 仅当 Verify(D_cert)=1；ΔW=BA，‖ΔW‖₂ ≤ ρ；KL(π_new‖π_old) ≤ ε_KL；loss = E_{x~μ}[w_δ(x)·ℓ_outcome(x)]，w_δ 为边界降权。
4. 影响归因：Inf(x) = 片段 x 对门博弈指标的经验影响；高 Inf 自证片段降权，形成数据层反馈。
5. 定理 9（自指稀释界）、定理 10（防火墙微调证书保持）、定理 11（分层覆盖/防遗忘）、定理 12（DRO 配方鲁棒性）。
6. Exec_CADVS-v6 = {x ∈ supp(π_v6^cert) : ∧_i kc_i(x,c; τ_i^5)=1} ⊆ Exec_CADVS-v5（门与阈值完全不变）。

**本轮最大风险**：**外生锚的独立性假设可能被「审计俘获」悄悄破坏**——整个抗自指保证依赖 audit/adv/ood 三类数据与策略及其价值模型独立；一旦人工审计被策略生成的解释牵着走、或「结局验证器」与策略共享同一套偏差（共依赖），α 就只是账面数字，配方证书会给出虚假的安全感，闭环仍在自证。

### IP-498 FCFTK：防火墙认证微调核（离线，分钟~小时）

```python
@dataclass
class FirewalledCertifiedFineTuningKernel:
    """FCFTK：只微调提议器；门与 τ^4 冻结只读。
    四个防火墙：(a) 结局标签 (b) 门梯度截断+边界降权 (c) 谱预算+KL (d) D_cert 前置"""
    rank: int = 8
    rho: float = 0.05               # 单适配器谱范数预算
    rho_total: float = 0.12         # 适配器栈总预算
    eps_kl: float = 0.02
    delta: float = 0.05             # 边界带宽（归一化轨迹空间）

    def boundary_weight(self, x, gate_margins) -> float:
        """d(x, ∂G) = min_i |s_i(x) - τ_i| / scale_i；越靠近门边界权重越低。
        注意：这是「降权」不是「改门」——门谓词与阈值不变"""
        d = min(abs(m) for m in gate_margins) / self.scale
        return min(max(d / self.delta, 0.0), 1.0)

    def spectral_project(self, B, A) -> tuple:
        """‖BA‖_2 <= rho：奇异值裁剪（幂迭代估 σ_max，O(r·d)）"""
        ...

    def fine_tune(self, fmpp, recipe: DataRecipe, cdmg, eaia) -> str:
        # (d) 前置门：证书无效 → no-op，保持 v5 策略（fail-closed）
        if not cdmg.verify_certificate(recipe):
            return 'NO_CERT_NO_FINETUNE'
        adapter = LoRA(fmpp.net, rank=self.rank)
        for batch in stratified_loader(recipe):
            # (a) 标签来自外部结局验证，绝不使用「门是否通过」
            y = external_outcome_verifier(batch.traj)
            # (b) 门梯度截断：gate_margins 只用于权重，不回传梯度
            w = batch.map(lambda x: self.boundary_weight(x, gate_margins(x)))
            loss = (w * outcome_loss(adapter(batch), y)).mean()
            loss += self.beta * kl_divergence(adapter.policy, fmpp.prior)
            # (c) 谱投影 + KL 信赖域
            adapter.B, adapter.A = self.spectral_project(adapter.B, adapter.A)
            if kl(adapter.policy, fmpp.prior) > self.eps_kl:
                break
        # 固化后：全量回归门测试 + 红队对抗集 + 分层遗忘测试
        if not regression_suite(adapter) or not redteam_suite(adapter):
            return 'ROLLBACK'       # 回滚到旧适配器栈
        return 'ADAPTER_CERTIFIED'
```

## 4. 正确性论证（增量更新）

### 引理 45（影响函数估计误差界）

**陈述**：设用 TracIn/influence function 在 m 个检查点上估计 Inf(x)，Hessian 条件数为 κ_H，则 |Înf(x) − Inf(x)| ≤ ε_inf 以概率 ≥ 1−δ，ε_inf = O(κ_H·√(log(1/δ)/m))。据此对「高影响自证片段」的误删率 ≤ δ_inf（由 ε_inf 与阈值间隔决定）。

**诚实边界**：影响函数在非凸、分布漂移下只是局部近似；高 Inf 不等于因果，降权是启发式而非保证。

### 引理 46（逐层 DP 组合与预算分配）

**陈述**：各层使用 RDP 机制 (α_R, ε_s)，总预算 ε_total = Σ_s ε_s(δ)（RDP→DP 转换）。固定 ε_total 时，最小化总噪声方差的分配满足 ε_s ∝ √(n_s·sens_s²)，由 KKT 给出；任一周期超支则拒绝固化（fail-closed）。

### 定理 9（自指稀释界）— 本轮理论主轴

**陈述**：设 μ_α(π) = α·μ_ext + (1−α)·μ_self(π)，C_ft 对数据分布 TV 满足 L_fit-Lipschitz，μ_self(π) 对 π 满足 M-Lipschitz，且 c = (1−α)L_fit·M < 1。则迭代 π_{k+1} = C_ft(μ_α(π_k)) 收敛到唯一不动点 π_α*，且

  d(π_α*, π_ref) ≤ (1−α)·B / (1−c)，其中 B = L_fit·d(μ_self(π_ref), μ_ext)，π_ref = C_ft(μ_ext)。

进一步，门博弈率 g(π_α*) ≤ g(π_ref) + L_g·d(π_α*, π_ref)。

**证明**：对任意 π1,π2，d(T_α(π1),T_α(π2)) ≤ L_fit·d(μ_α(π1),μ_α(π2)) = L_fit(1−α)d(μ_self(π1),μ_self(π2)) ≤ c·d(π1,π2)，故 T_α 为 c-压缩，Banach 不动点存在唯一。由三角不等式 d(π_α*,π_ref) ≤ d(T_α(π_α*),T_α(π_ref)) + d(T_α(π_ref),π_ref) ≤ c·d(π_α*,π_ref) + (1−α)B，移项即得。博弈率由 g 的 L_g-Lipschitz 得。∎

**含义**：α 是「抗自指旋钮」——不是把门锁得更死，而是让训练锅里外生原料占比更高；α→1 时不动点收敛到纯外生参考策略，自指项消失。

### 定理 10（防火墙微调证书保持）

**陈述**：门谓词与 τ^5 冻结，ΔW=BA 满足 ‖ΔW‖₂ ≤ ρ，KL(π_new‖π_old) ≤ ε_KL，仅认证适配器进入 supp(π_v6^cert)。则 (i) Exec_v6 ⊆ Exec_v5；(ii) TV(π_new,π_old) ≤ √(ε_KL/2)；(iii) δ-邻域内「门通过但结局失败」样本权重为 0，但 δ-邻域外间接漂移不消除。

**证明**：(i) 执行谓词不变，仅提议支撑受限；(ii) Pinsker 不等式；(iii) 由 w_δ 定义直接得。∎

**诚实边界**：(iii) 只是降权不是免疫；策略仍可绕道远离边界再逐步逼近，故博弈率只能经验下降。

### 定理 11（分层覆盖与防遗忘）

**陈述**：μ_s ≥ floor_s > 0，batch 大小 n，分层采样下 P(|μ̂_s − μ_s| ≥ ε) ≤ 2exp(−2nε²)。若每层风险对配比 L_forget-Lipschitz，则最坏层遗忘增量 ≤ L_forget·ε 以概率 ≥ 1 − |S|·2exp(−2nε²)。

**证明**：Hoeffding + union bound + Lipschitz。∎

### 定理 12（DRO 配方鲁棒性）

**陈述**：U(μ) = {ν : TV(ν,μ) ≤ η, ν_s ≥ floor_s}，min_θ max_{ν∈U} R(ν,θ) 的泛化误差 ≤ √(C log(1/δ)/n_eff(μ)) + η·Lip(R)。在约束下最大化 n_eff 的配方 μ* 给出最紧界。

**证明**：标准 DRO 分解 + Hoeffding + TV 球上的 Lipschitz 控制。∎

### 定理 v6（数据层抗自指总装）

**陈述**：在 v5 假设 (B1)~(B7) 及新增 (C1) C_ft 为 L_fit-Lipschitz、(C2) μ_self 为 M-Lipschitz、(C3) c=(1−α)L_fit·M<1、(C4) 外生锚独立性审计有效（α_eff=α）下：
(i) Exec_CADVS-v6 ⊆ Exec_CADVS-v5（门/阈值完全不变，仅认证适配器可提议）；
(ii) 自指漂移 d(π_α*,π_ref) ≤ (1−α)B/(1−c)，α→1 时 →0（定理 9）；
(iii) 微调证书保持与 TV 漂移界（定理 10）；
(iv) 分层覆盖与防遗忘（定理 11）；
(v) DRO 配方在最坏层风险上的鲁棒界（定理 12）；
(vi) 七门七锚不变，回退链 v6→v5→v4 保证 fail-closed。

**证明**：(i)(iii) 由定理 10；(ii) 由定理 9；(iv)(v) 由定理 11/12；(vi) 锚点与门集合未变 + 回退算子。∎

**诚实声明**：(C4) 是本方案最脆弱的假设——审计俘获与验证器共依赖无法被统计检验完全排除，只能靠第三方审计、HSIC 监测与 α_eff 折扣限损；(C3) 在价值模型强自适应时可能失效，此时界为空（无保证）；(C1)(C2) 是局部 Lipschitz 假设，全局非凸下需靠回归测试兜底；影响函数只是局部近似，不能当因果证据。
