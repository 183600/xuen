# 第 1 轮 · PM-DA-ROADMAP-LITE —— 预测性维护 × 数据增强 × 技术路线图分级部署

## 直觉锚点与动机链条

- **稀缺性动机**：工业协作机器人的致命失效模式年发生率 <0.1%，真实故障数据极度稀缺，传统监督学习易欠拟合长尾风险。灵感词「预测性维护」要求在故障发生前可量化的剩余寿命估计 RUL 与置信度。
- **合成数据动机**：灵感词「数据增强」并非简单的图像扰动，而是**物理一致的退化轨迹合成**。机械磨损、润滑衰减、轴承微裂纹的动力学演化可由Isaac Sim / 摩擦-磨损子模型驱动，生成带标注的罕见失效轨迹，实现“渲染即标签”。
- **风险控制动机**：灵感词「技术路线图」映射到**四阶段门控部署**：S0遥测收集 → S1影子模式 → S2顾问预警 → S3主动干预。每阶段由可验证的门槛 G_acc / G_fpr / G_latency 决定，fail-safe 回退链始终存在，避免一次上线即承担全风险。

三者耦合形成闭环：数据增强解决样本稀缺 → 预测模型获得长尾覆盖 → 技术路线图控制部署风险 → 部署反馈补充真实数据用于增强迭代。

## 形式化定义的深化

### 系统与健康状态
- 组件集合 C = {1..m}
- 健康指数 h_i(t) ∈ [0,1]，h_i=1 完美，h_i=0 失效
- 退化动力学：dh_i/dt = -λ_i(s_i(t),u(t)) + w_i(t)， w_i ~ N(0,σ²_w)
- 观测 o_t = [s_t, τ_t, T_t, V_t]，s 为传感器，τ 力矩，T 温度，V 振动
- 剩余寿命 RUL_i(t) = inf{Δ>0 : h_i(t+Δ) ≤ h_thr}

### 预测模型
- f_θ : O_window → p(RUL|o_{t-W:t})，参数化为均值 μ_RUL 与方差 σ²_RUL
- 不确定性分解：Aleatoric σ_a 与 Epistemic σ_e，经 MC Dropout 估计
- 决策阈值：预警触发条件 E_t = { μ_RUL < τ_warn ∧ σ_RUL < σ_max }

### 数据增强算子
- 物理增强 A_phys : 参数 p ~ P_phys(磨损系数, 润滑损耗, 负载谱) → 生成轨迹 τ_syn = Sim(p)，标注 RUL_gt = T_fail(p)-t
- 生成增强 A_gen : 基于真实稀有故障子集 D_rare，用条件扩散模型 G_φ 生成中间退化样本，保持物理单调性约束 h(t+1) ≤ h(t)
- 重要性加权 w_syn = beta· p_real/p_syn，防止合成数据主导

### 技术路线图门控
- 阶段集合 S = {S0,S1,S2,S3}
- 门槛 G1: MAE_RUL ≤ 12h 且 Coverage_95 ≥ 0.9 on Hold-out Rare
- 门槛 G2: FPR < 0.5%/周 且 FNR_critical < 1%
- 门槛 G3: P99 延迟 < 2ms/步 且内存 < 50MB
- 转移规则：S_k → S_{k+1} iff G_k 成立连续 4 周，否则回退

## 算法步骤精炼

离线:
1. 真实数据清洗与退化标签对齐，构建 D_real
2. 物理增强： muestreo p ~ P_phys，Sim 生成 D_phys，渲染即标签
3. 生成增强：训练 G_φ 于 D_rare，合成 D_gen 并强制单调约束
4. 混合训练：L = L_nll(D_real) + α·E_{D_phys}[w_syn L_nll] + β·E_{D_gen}[L_nll] + λ_EWC·||θ-θ_anc||²
5. 校准：温度缩放 + conformal prediction 得到 95% 置信区间
6. 路线图烧录：记录门槛、基线指标、回滚点

在线:
1. 滑动窗口采集 o_{t-W:t}，推理 μ_RUL, σ_RUL
2. 新鲜度检查：若传感器超时 > T_stale，回退到 S1 影子模式
3. 决策：E_t 成立 → 生成工单，优先级 = f(μ_RUL, σ_RUL, 组件关键度)
4. 影子记录：S1 阶段记录建议 vs 人工决策用于 offline A/B
5. 维护窗口：利用 PREDICT-MAINT 调度低负载时段执行再标定

## 复杂度分析

- 推理：1kHz 循环中模型为轻量 Temporal CNN + 2 层 LSTM，WCET <0.8ms，P99 <1.5ms
- 内存：模型 18MB + 窗口缓冲 4MB < 50MB
- 训练：一次性 1.2 GPU·天（物理模拟 0.4 + 生成模型 0.5 + 主模型 0.3）
- 持续适配：0.03 GPU·天/周，增量学习仅更新最后 2 层
- 路线图审计成本：每周 <0.01 GPU·天

## 正确性论证

命题 1（安全单调性）：若在 S2/S3 阶段触发预警，则 P(RUL_true < τ_warn | E_t) ≥ 1 - δ_fp，其中 δ_fp 由 conformal 保证。证明依赖校准不变性与 σ_RUL 上界。

命题 2（增强覆盖）：在物理约束下，A_phys 的支持集包含真实退化动力学的 ε-邻域。由 Sim 模型验证误差界，合成数据不会引入反单调轨迹。

命题 3（路线图无负收益）：阶段转移仅在 G_k 同时满足时发生，回退链 S3→S2→S1→S0 保证任意时刻系统行为不劣于上阶段基线。门控不依赖可 OTA 参数。

## 风险登记簿

- 数据增强分布漂移：物理参数先验 P_phys 与真实工厂偏差 → 假阴性。对策：在线重要性权重 + 每季度 P_phys 再校准。
- 置信度校准漂移：长期退化超出训练范围 → 过度自信。对策：conformal 分位数每周更新，Epistemic 阈值 σ_max 保守。
- 路线图门槛僵化：过严导致永不晋升，过松导致过早放行。对策：双门 + 人工审计，门槛值禁 OTA。
- 计算资源抖动：推理延迟超标导致错过预警。对策：WCET 隔离 + 影子模式自动降级。

**本轮最大风险一句话**：数据增强合成的罕见失效轨迹若在物理参数先验上存在系统性偏差，会导致预测模型在真实长尾失效上产生过度自信的假阴性，而技术路线图的门控无法在线检测这种分布漂移，须在 S1 影子阶段强制保留真实故障捕获与定期先验重校准，否则安全论证 collapses。

## 2. 离线算法：增强烧录与模型训练

```python
def build_pm_model():
    D_real = load_and_align_real_telemetry()
    # 物理增强
    D_phys = []
    for p in sample_phys_params(N=50000):
        traj = isaac_sim_degradation(p)  # 渲染即标签
        D_phys.append(label_rul(traj))
    # 生成增强
    G_phi = train_conditional_diffusion(D_real.rare)
    D_gen = G_phi.sample(N=20000, monotonic=True)
    # 混合训练
    θ = init_temporal_cnn_lstm()
    for epoch in range(E):
        loss = nll(D_real, θ) \
             + α * weighted_nll(D_phys, θ, w_importance) \
             + β * nll(D_gen, θ) \
             + λ_EWC * ewc_penalty(θ)
        θ = optimizer.step(loss)
    # 校准
    θ_cal = temperature_scale(θ, D_cal)
    intervals = conformal_prediction(θ_cal, D_cal, q=0.95)
    # 路线图基线
    baseline = evaluate_gates(θ_cal, D_holdout)
    return θ_cal, intervals, baseline
```
