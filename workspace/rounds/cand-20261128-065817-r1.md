### 第 1 轮灵感驱动研究记录

**灵感词**：状态机、物体泛化

**继承关系**：承接状态文件中的 CADVS-v5（上一循环第 5 轮，IP-493~496，「认证的生成式执行」CGE）。v5 已把提议升级为条件流匹配 π_θ^FM、记忆升级为 LMEM-v2、人因升级为 FAMK 阈值调制，并证明证书不变性（提议无关）、调制单调性、固化有界。本轮不推翻 v5，而是补 v5 的两个结构性短板：(a) 提议与证书都假设**单段连续轨迹**，不建模接触模式的离散切换——接近/接触/夹持/抬升/运输/放置/释放的物理约束在模式间根本不同，「一条轨迹一套门」在模式边界处会出现证书真空或误判；(b) 「物体泛化」在 v5 里只是**经验性的**：流策略按物体嵌入做条件生成，但七门对未见物体没有任何结构性保证，OOD 只能靠密度回退。两个灵感词统一为主题「认证混合状态机 + 物体轨道泛化」（Certified Hybrid-State Execution & Object-Orbit Generalization, CHEO），形成 CADVS-v6（IP-497~500）。本轮自律：**硬门数量仍不增**（维持七门），只做「门的提升（lifting）+ 物体参数化 + 信任状态机」三条非侵入改造；对固定物体，执行集只缩不涨。

**直觉与动机**：

1. **状态机 → 从单轨迹证书升级为混合自动机上的组合证书，模式边界处不再有证书真空**。把执行写成混合自动机 H=(Q,X,E,Inv,Guard,Reset,F)：Q 是接触模式（接近/接触/夹持/抬升/运输/放置/释放），每个模式有自己的不变量 Inv_q 与动力学 F_q，模式间有守卫 Guard_e 与重置 Reset_e。七门被**提升**到乘积空间 Q×X：每门有作用域 Q_i 与聚合方式（ALL/TERMINAL/ANY），例如平衡门只在承重模式 {夹持,抬升,运输,放置} 上全称量化，末点门只在终态模式上检查。**定理 9（模式组合可靠性）**：若初始态在 C_{q0}、每次驻留都在 C_q、每次切换 e 满足 Reset_e(Guard_e ∩ C_q) ⊆ C_{q'}，则由归纳法整段执行都落在认证集内。这把 v5「一条轨迹七门」推广为「一条模式序列 × 每模式七门 × 每次切换一纸过渡证书」，且 fail-closed 语义原样保持：任何一环缺证书即拒绝。

2. **物体泛化 → 从经验条件生成升级为「群轨道 + Lipschitz 鲁棒半径」的可证明迁移，覆盖增长靠证书搬运而非阈值放松**。v5 的流提议对未见物体只是「猜得像」，门并不因此更可信。本轮引入物体族上的群作用 G（SE(3)×尺度，必要时加保形子群）：若七门对 G **等变**、阈值对 G **不变**，则**定理 10（轨道等变性）**给出 CertTrace(g·o)=g·CertTrace(o)——一个原型物体的证书经群作用精确覆盖整个轨道（不同位姿/尺度/朝向），无需逐物体重证。对不在同一轨道的形状变化，用**定理 11（鲁棒半径）**：若门的边际 m_i=s_i−τ_i 对状态与物体几何度量 (d_X,d_O) 联合 L_i-Lipschitz、原型证书的最小边际为 δ_i、闭环跟踪误差 ≤ ε_x，则任何 d_O(o,o') ≤ ρ(o)=min_i(δ_i/L_i − ε_x) 的物体 o' 继承同一策略的证书。轨道之外一律 UNCERTIFIED、fail-closed 请求教师。**关键口号：执行集在物体维度上的扩张只能来自「已有 v5 证书沿等变/Lipschitz 管搬运」，绝不来自放松任何门。**

3. **状态机（第二义）→ 证书信任生命周期也是一台单调状态机，从结构上切断 v5 最担心的自证回路**。v5 最大风险 R57 是「铸证→学习→再铸证」的自指闭环：提议器可以自己产生「已铸证」样本喂给固化。引入 CTSM：每个证书条目处于 {U 未验证, P 已提议, E 证据已收集, C 已认证, X 已消费, S 已挂起, R 已撤销}，其中 **P→C 没有直接边**，E→C 必须由提议器动作集之外的**外部证据事件**（结局验证/人工抽检/形式重放）触发；固化只能从 C ∧ 结局成功 ∧ 人工抽检 的片段采样。**定理 12（非自证性）**：任何到达 C 的路径必含一个外部事件，故提议器无法自我签发证书——R57 的「直接自证边」被结构性删除（诚实地：外部证据若与提议器同源，仍可被博弈；只删直接自环，不删全部循环）。

**关键洞见**：v4 问「提议=规则时七门够不够」；v5 问「提议=任意生成器时边界是否不变」；v6 问「执行=离散模式序列、物体=未见族时，证书如何组合与搬运」。答案是两个「不变量」：**模式组合不变量**（过渡证书保证拼接安全）与**物体等变不变量**（轨道/鲁棒半径保证迁移安全），二者都不改门、不放松阈值，只增加结构。于是「泛化」第一次有了可检查的充分条件，而不是只靠流模型的经验成功率。

**形式化目标（增量）**：
1. H=(Q,X,E,Inv,Guard,Reset,F,Init)，混合执行 σ；门的提升算子 L_i（作用域 Q_i + 聚合 agg_i）；模式证书 C_q(o)、过渡证书 T_e(o)、轨迹证书 CertTrace(o)。
2. 定理 9（模式组合可靠性/归纳不变式）；定理 10（物体轨道等变性 Cert(g·o)=g·Cert(o)）；定理 11（Lipschitz 鲁棒半径 ρ=min_i(δ_i/L_i−ε_x)）；定理 12（CTSM 非自证性）。
3. 物体等变编码器 + 轨道索引；ρ 的离线区间界估计（谱范数/区间传播），运行时只做 O(log|P|) 最近原型查询与 O(1) 半径比较。
4. EFA-v6：模式条件流提议 → 每模式七门级联 → 过渡证书检查 → 轨道/鲁棒半径准入 → CTSM 状态推进；软评分 ECS_v6 = ECS_v5 · η_mode · η_orbit。
5. 嵌套：固定物体、退化单模式（|Q|=1、无过渡）时 v6 精确退化为 v5，且 Exec_v6(o) ⊆ Exec_v5(o)；物体维度扩张仅由证书搬运产生。

**本轮最大风险**：**等变性假设的假安全**——轨道证书把「未验证物体」当作「已验证物体的群像」，一旦真实接触门因摩擦、重力方向、柔性形变而破坏 G-等变（或 Lipschitz 常数被低估），系统会带着一份「看起来有证明」的证书去执行，比 v5 的密度盲区更危险，因为失败不再是「未知」而是「被误证为已知」。

## 2. 关键算法骨架

### IP-497 HCSM：接触模式混合自动机核（准入/10 Hz 预览；控制环只消费模式证书）

```python
@dataclass
class HybridContactStateMachineKernel:
    """HCSM：把七门提升到 Q×X，并为每次模式切换单独发过渡证书。
    定理 9：初始证书 + 驻留证书 + 过渡证书 ⇒ 整段执行认证（归纳）。"""
    Q: tuple                       # 接触模式
    Inv: dict                      # q -> 不变量谓词（状态空间约束）
    Guard: dict                    # (q,q') -> 守卫谓词（切换使能）
    Reset: dict                    # (q,q') -> x -> x（切换重置）
    F: dict                        # q -> 模式动力学（供 BCC/BCK 预览）
    scope: dict                    # gate_i -> (Q_i, agg_i)
    fmpp_q: Any                    # 模式条件流 v_θ(x,t|c,q)

    def mode_cert(self, q, x, o, gamma) -> bool:
        """模式级七门（只查 q∈Q_i 的门），阈值 τ^6=γ·τ^4（只紧）"""
        return all(self._gate(i, q, x, o, gamma)
                   for i in self._active_gates(q))

    def transition_cert(self, q, qp, x, o, gamma) -> bool:
        """过渡证书：守卫成立且重置后落在下一模式不变量与证书集内"""
        if (q, qp) not in self.Guard:
            return False
        xp = self.Reset[(q, qp)](x)
        return (self.Guard[(q, qp)](x)
                and self.Inv[qp](xp)
                and self.mode_cert(qp, xp, o, gamma))

    def certify_trace(self, trace, o, gamma) -> tuple[bool, str]:
        """归纳检查整段混合执行；任一环缺失即 fail-closed"""
        q, x = trace[0]
        if not (self.Inv[q](x) and self.mode_cert(q, x, o, gamma)):
            return False, 'INIT_UNCERTIFIED'
        for seg in trace.segments:                 # 驻留段：检查不变量/流形
            if not self._invariant_along(seg, o, gamma):
                return False, 'INVARIANT_VIOLATION'
        for (q, qp, x_switch) in trace.switches:   # 切换：检查过渡证书
            if not self.transition_cert(q, qp, x_switch, o, gamma):
                return False, 'TRANSITION_UNCERTIFIED'
        return True, 'TRACE_CERTIFIED'

    def propose(self, c, q_seq) -> list:
        """模式条件流：对每个候选模式序列生成连续轨迹；q_seq 来自模式选择器"""
        return [self._flow_mode(c, q) for q in q_seq]
```

**模式选择器**：优先用 BCK/EEK 的接触状态估计给出候选 q_seq（≤2 条，控制分支），流提议只生成每模式内的连续段；不允许流模型直接“发明”模式序列，模式序列由离散规则 + 传感器估计共同决定（fail-closed：模式不确定则停在上一个已认证模式）。

### IP-498 OOGK：物体轨道泛化核（准入时域；运行时 O(log|P|)）

```python
@dataclass
class ObjectOrbitGeneralizationKernel:
    """OOGK：同轨道精确搬运 + 不同轨道鲁棒迁移 + 轨道外 fail-closed。
    口号：覆盖靠证书搬运，绝不靠放松门。"""
    group: Any                     # G: SE(3)×R_+（或保形子群）
    emb: Any                       # 等变几何编码器 / 规范化坐标
    orbit_index: Any               # 原型 p -> Orbit(p) 的 KD-tree
    lip: dict                      # L_i：离线区间界/谱范数上界
    eps_x: float                   # 闭环跟踪误差上界
    rho0: float = 0.02             # 软评分参考半径（米）

    def admit(self, o) -> Certificate | None:
        p, d = self.orbit_index.nearest(self.emb(o))      # O(log|P|)
        # (1) 同轨道：求 g∈G 使 o=g·p，精确搬运原型证书
        g = self.group.align(p, o)
        if g is not None and self.group.in_G(g):
            return self._transport(self.cert_of(p), g)
        # (2) 不同轨道：鲁棒半径迁移
        rho = self.radius(p)
        if rho > 0.0 and d <= rho:
            return self._robust_transport(self.cert_of(p), o, d)
        # (3) 轨道外：fail-closed，请求教师或退保守模式
        return None

    def radius(self, p) -> float:
        """ρ(p)=min_i(δ_i(p)/L_i − ε_x)；任一非正 ⇒ 不可迁移"""
        return min(self.delta(p, i) / self.lip[i] - self.eps_x
```

### IP-499 CTSM：证书信任状态机（事件驱动；控制环只读状态）

```python
@dataclass
class CertificateTrustStateMachine:
    """CTSM：证书生命周期。P->C 无直接边，E->C 必须外部证据事件。
    定理 12：任何到达 C 的路径必含 ExtEv，提议器不能自我签发。"""
    state: dict                    # cert_id -> Z
    external_events: set           # 仅独立检查器/人工/形式重放可写
    proposer_actions: set          # 提议器可触发的动作名

    def propose(self, cert_id):                       # U -> P
        self._require(cert_id, 'U'); self.state[cert_id] = 'P'

    def collect_evidence(self, cert_id, ev):          # P -> E
        self._require(cert_id, 'P')
        assert ev.source not in self.proposer_actions  # 证据不得由提议器产生
        self.state[cert_id] = 'E'

    def certify(self, cert_id, ext_ev):               # E -> C（唯一入边）
        self._require(cert_id, 'E')
        if ext_ev.source in self.proposer_actions or ext_ev not in self.external_events:
            raise PermissionError('SELF_CERTIFICATION_FORBIDDEN')
        self.state[cert_id] = 'C'

    def consume(self, cert_id, fresh_check: bool):    # C -> X
        self._require(cert_id, 'C')
        if not fresh_check: raise RuntimeError('STALE_CERTIFICATE')
        self.state[cert_id] = 'X'

    def suspend(self, cert_id, anomaly):              # C/X -> S
        self.state[cert_id] = 'S'

    def revoke(self, cert_id, reason):                # any -> R
        self.state[cert_id] = 'R'

    def consolidation_eligible(self, ep) -> bool:
        """固化入口：只接受已认证 ∧ 结局成功 ∧ 人工抽检 的片段"""
        return (self.state.get(ep.cert_id) in ('C', 'X')
                and ep.outcome_ok and ep.human_audit
                and ep.cert_event.is_external)
```

### IP-500 EFA-v6：模式提升 + 过渡证书 + 轨道准入 + 信任状态机

```python
@dataclass
class EvidenceForgingAssemblerV6:
    """EFA-v6：七硬门不变；阈值可调制且只紧；增加模式/过渡/轨道/信任四层结构。"""
    hcsm: HybridContactStateMachineKernel
    oogk: ObjectOrbitGeneralizationKernel
    ctsm: CertificateTrustStateMachine
    v5: EvidenceForgingAssemblerV5

    def select(self, x0, t_now, rule_id, context):
        # 0) 物体准入（先于一切提议；未认证物体直接 fail-closed）
        cert = self.oogk.admit(context.object)
        if cert is None:
            return False, None, 'OBJECT_UNCERTIFIED'
        # 1) 情感调制（v5 原样，只紧）
        s_emo = self.v5.famk.observe(context.face, t_now)
        gamma = self.v5.famk.gamma(s_emo)
        # 2) 模式序列（离散规则+传感器；不确定则停在已认证模式）
        q_seq = self._mode_selector(context, cert)
        if q_seq is None:
            return self._hold_last_certified_mode(gamma)
        # 3) 每模式级联：廉价门 → VACK(≤3) → BCK 预览 → 过渡证书
        c = build_ctx_v6(context, s_emo, self.v5.lmem, cert)
        cands = self.hcsm.propose(c, q_seq)
        for cand in cands:
            ok, why = self.hcsm.certify_trace(cand.trace, context.object, gamma)
            if ok and self._ctsm_consume(cand.cert_id):
                best = self._max_margin(cands)
                return True, best, 'FORGED_CHEO'
        return self._fallback_rule_proposal(gamma)   # fail-closed 回退 v5 规则提议

    def ecs_v6(self, base_ecs_v5, m_min_mode, rho, rho0):
        eta_mode = sigmoid(m_min_mode - b_mode)
        eta_orbit = sigmoid(rho / rho0 - b_orbit) if rho > 0 else 0.0
        return base_ecs_v5 * eta_mode * eta_orbit
```

## 4. 正确性论证（增量更新）

### 定义 1（混合执行）

设 H=(Q,X,E,Inv,Guard,Reset,F,Init)。混合执行 σ 是一列交替的驻留段与切换：从 (q_0,x_0)∈Init 出发，在模式 q_k 内按 F_{q_k} 演化且始终 x(t)∈Inv_{q_k}；当 x∈Guard_{e_k} 时切换到 q_{k+1}，新状态 x'=Reset_{e_k}(x)∈Inv_{q_{k+1}}；重复至终止。记 modes(σ) 为经过的模式序列。

### 定义 2（门的提升）

给定每门的作用域 Q_i 与聚合 agg_i，定义轨迹级门
kc_i^↑(σ;o) = agg_{q∈Q_i∩modes(σ)} kc_i^{(q)}(x_q;o)，
其中 ALL 为全称、TERMINAL 仅终态模式、ANY 为存在。模式证书 C_q(o) 与过渡证书 T_e(o) 如符号表。定义
CertTrace(o) = {σ : (q_0,x_0)∈Init∩C_{q0}(o)，每段驻留 x(t)∈C_{q_k}(o)，每次切换 x∈T_{e_k}(o)}。

### 定理 9（模式组合可靠性）

**陈述**：若 σ 满足 CertTrace(o) 的三条归纳前提，则 σ∈CertTrace(o) 且对所有 i，kc_i^↑(σ;o)=1。反之，任一前提失败时 certify_trace 返回 false（fail-closed）。

**证明**：对切换次数 m 归纳。m=0：初始条件给出 (q_0,x_0)∈C_{q0}(o)，驻留不变性给出整段在 C_{q0}(o)，故所有作用域含 q_0 的门通过。归纳步：设前 k 段与 k 次切换已认证，第 k 次切换 x∈T_{e_k}(o) ⊆ Guard_{e_k}，且 Reset_{e_k}(x)∈C_{q_{k+1}}(o)；第 k+1 段驻留保持在该证书集，故下一步归纳前提成立。终态时，各门按其作用域与聚合在相应模式上取值，由 C_q 的定义均为 1，故 kc_i^↑=1。fail-closed 由 certify_trace 的短路返回直接得到。∎

**工程含义**：v5 只需在整条轨迹上过七门；v6 把“过门”分解为“每模式过局部门 + 每次切换过过渡证书”。这既消除了模式边界的证书真空，也把证书检查局部化，便于缓存与增量重证。

### 定理 10（物体轨道等变性）

**陈述**：设群 G 作用在物体与状态上，且 (a) Inv、Guard、Reset、F 对 G 等变（如 g·Inv_q = Inv_q∘g^{-1}）；(b) 每门等变：kc_i^{(q)}(g·x;g·o)=kc_i^{(q)}(x;o)；(c) 阈值 G-不变。则 C_q(g·o)=g·C_q(o)，T_e(g·o)=g·T_e(o)，进而 CertTrace(g·o)=g·CertTrace(o)。

**证明**：x∈C_q(g·o) ⇔ 对所有活跃门 i，kc_i^{(q)}(x;g·o)=1 ⇔（由等变性）对所有 i，kc_i^{(q)}(g^{-1}x;o)=1 ⇔ g^{-1}x∈C_q(o) ⇔ x∈g·C_q(o)。过渡证书同理：x∈Guard_e 且 Reset_e(x)∈C_{q'}(g·o) ⇔ g^{-1}x∈Guard_e 且 g^{-1}Reset_e(x)=Reset_e(g^{-1}x)∈C_{q'}(o)（Reset 等变）⇔ x∈g·T_e(o)。轨迹层面由定理 9 的归纳结构对 G 等变，故 CertTrace(g·o)=g·CertTrace(o)。∎

**推论**：一个原型证书经 g∈G 搬运后，对 g·o 精确有效，无需重证。**边界**：真实重力方向固定、摩擦锥各向异性、柔性形变均会破坏全 SE(3) 等变；实际可用子群限于绕重力轴的 yaw×平移×尺度（必要时加保形形变子群），并在实现中显式声明 `group.in_G(g)`。

### 定理 11（Lipschitz 鲁棒半径）

**陈述**：设门边际 m_i^{(q)}(x;o)=s_i^{(q)}(x;o)−τ_i^{(q)} 在 (x,o) 上联合 L_i-Lipschitz：
|m_i^{(q)}(x;o)−m_i^{(q)}(x';o')| ≤ L_i(d_X(x,x')+d_O(o,o'))。
设原型执行 σ 的最小边际 δ_i=min_{q∈Q_i,x∈tube(σ)} m_i^{(q)}(x;o)>0，且物体 o' 的闭环执行 σ' 满足 sup_t d_X(x(t),x'(t)) ≤ ε_x。则当 d_O(o,o') ≤ ρ_i := δ_i/L_i − ε_x（对所有 i 取最小得 ρ）时，σ' 的每门边际仍 >0，即 kc_i^{(q)}(x';o')=1。

**证明**：m_i(x';o') ≥ m_i(x;o) − L_i(d_X(x,x')+d_O(o,o')) ≥ δ_i − L_i(ε_x+d_O) ≥ 0（严格 >0 当 d_O<ρ_i）。对作用域内所有 (q,t) 取最小，得所有门通过；过渡证书的不变量/守卫部分同理，因其亦由同一组边际界定。∎

**诚实边界**：L_i 只能“估计”不能“验证”（神经网络门的真实 Lipschitz 常数可能更大）；ε_x 依赖闭环跟踪，接触冲击时可能瞬时超界。故 ρ 是**充分条件**，不是必要条件；实现取保守下界并在运行时用新鲜传感器复核（CTSM 的 fresh_check）。

### 定理 12（CTSM 非自证性）

**陈述**：设提议器只能触发动作集 A_P；外部事件 ExtEv 的来源 source∉A_P。CTSM 的转移图中，C 的唯一入边来自 E→C 且带标签 ExtEv，E 的唯一入边来自 P→E。则任何到达状态 C 的运行必含至少一个 ExtEv；仅用 A_P 无法到达 C。

**证明**：在转移图上做割：删除 E→C 边后 C 不可达（C 无其他入边），而该边标签为 ExtEv，故任何到 C 的路径包含该边，从而包含 ExtEv。仅用 A_P 的路径不可能标注 ExtEv，故不能到达 C。∎

**推论**：固化集合 {ep : state(ep.cert)∈{C,X} ∧ outcome_ok ∧ human_audit} 与“仅由提议器动作完成认证”的片段不相交，故 v5 的“铸证→学习”直接自环被结构性切断。**诚实边界**：若外部证据与提议器同源（例如共用同一价值模型且无独立审计），相关性仍可被利用；CTSM 只删除**直接**自证边，不消除所有循环。这正是本轮最大风险的来源之一。

### 定理 v6（组合收缩、证书搬运与诚实边界，总装）

**陈述**：在 v5 假设 (B1)~(B7) 及新增 (B8) G 为门的真实对称子群、(B9) L_i 为边际的可靠上界、(B10) ε_x 为闭环跟踪上界下，有：
(i) **退化一致**：固定物体 o、退化单模式（|Q|=1、无过渡）时，v6 的门提升退化为 v5 的七门，且 Exec_v6(o) ⊆ Exec_v5(o)（多出模式不变量、过渡证书与鲁棒收紧，均为额外合取项）；
(ii) **模式组合可靠**：σ∈CertTrace(o) ⇒ 所有提升门通过（定理 9）；
(iii) **轨道搬运**：CertTrace(g·o)=g·CertTrace(o)（定理 10），轨道内覆盖为精确搬运；
(iv) **鲁棒迁移**：d_O(o,p)≤ρ(p) ⇒ o 继承 p 的证书（定理 11）；
(v) **覆盖扩张不放松门**：Cov_v6 = ∪_p (G·p ∪ B_{ρ(p)}(p))，其每个元素的安全依据都是一份已存在的 v5 原型证书的搬运，而非阈值放松；对 o∉Cov_v6，Exec_v6(o)=∅（fail-closed）；
(vi) **非自证**：提议器无法自我签发证书（定理 12），固化只消费 C 状态片段；
(vii) **fail-closed 兜底**：任一前提（物体未认证、模式不确定、过渡无证书、边际不足、信任状态过期）失败时，回退 v5 规则提议或停在上一已认证模式。

**证明**：(i) 令 G 平凡、Q 单点、E=∅，则 C_q 与 T_e 退化为 v5 的门集；额外不变量/过渡为空合取，鲁棒收紧只会缩小阈值，故包含关系成立。(ii)(iii)(iv)(v)(vi) 分别由定理 9、10、11、覆盖域定义、定理 12 得到。(vii) 由 certify_trace 与 select 的短路返回直接得到。∎

**诚实声明**：(B8) 等变性在真实接触中常被摩擦各向异性、重力固定方向与柔性形变破坏；(B9) 的 L_i 只能离线估计，可能低估；(B10) 的 ε_x 在冲击/滑移瞬态可能超界；外部证据可能与提议器相关。因此 v6 的“可证明泛化”是**条件性**的：一旦等变/界假设失效，轨道证书会给出“看起来有证明”的假安全——这比 v5 的密度盲区更隐蔽，必须用运行时新鲜校验、轨道外强制教师与周期性等变性审计来限损，而无法从结构上根除。

## 7. 本轮最大风险（最终确认）

**一句话**：**等变性假设的假安全**——轨道证书把“未验证物体”当作“已验证物体的群像”，一旦真实接触门因摩擦、重力方向、柔性形变而破坏 G-等变（或 Lipschitz 常数被低估），系统会带着一份“看起来有证明”的证书去执行，比 v5 的密度盲区更危险，因为失败不再是“未知”而是“被误证为已知”；对称子群收紧 + 等变审计 + 运行时新鲜校验 + 轨道外强制教师只能限损，无法根除。
