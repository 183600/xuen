# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「通用机器人平台」×「低成本方案」）

> 第 54 轮把技能组合升级为动作-鲁棒性双证书（`α_S`、`A_cert`、`γ_ce`、`δ_a`），但整套体系默认「一机一标定」：每条动作剖面、每个鲁棒性谱都在特定硬件上采过。本轮灵感直击「通用平台 × 低成本」：**证书必须能在一群异构、廉价、批次不一的机器人之间迁移与复用，且标定预算必须成为显式的一等资源**。核心矛盾 H22：证书的「具体性」与平台的「通用性」冲突——为单机标定的 `ρ`/`A_cert` 换一台廉价同型机就可能失效；H23：低成本意味着少样本、噪声大、无高精度外部测量，精确证书不可得，只能得到带认知半径的**区间证书**。

## 0. 直觉与动机

**灵感 1（把「机器人」参数化为指纹 φ，而不是型号）**
直觉：通用平台不该问「你是什么型号」，而该问「你的物理能力落在哪个点」。用一组固定、廉价的**探针动作**（原地转向、短距直线、负载举升、柔性接触、急停响应……）测出**本体指纹 `φ_R ∈ Φ`**（重复性、跟踪带宽、柔顺度、传感器噪声、执行器饱和）。证书以 `φ` 为条件：`ρ(d | φ)`。低成本体现在探针是一次性小电池，成本 `O(m)`，而全动作空间扫描是 `O(|A|)`，`m ≪ |A|`。指纹把「无限多种机器人」压成低维流形上的点，这是通用性的数学入口。

**灵感 2（规范动作空间 A*：让不同本体说同一种动作语言）**
直觉：不同机器人坐标系、关节限位、传感延迟都不同，直接比 `compat` 没有意义。先用每台机器人的重参数化 `π_R : A_R → A*` 拉回到**规范动作空间 `A*`**，技能、动作剖面、兼容性都在 `A*` 中定义。指纹 `φ` 决定 `π_R` 的形变；形变越剧烈，失真 `d_R` 越大，迁移越不可信。这把「通用」变成「在 `A*` 上共享语义、在 `A_R` 上各自执行」。

**灵感 3（标定预算 → 认知半径：便宜被翻译成保守，而非不可靠）**
直觉：低成本不是「少做事」，而是「承认不确定」。给定标定预算 `b`（探针数、rollout 数、时间、钱），得到的是估计 `ρ̂(b)` 和**认知半径 `ε(b,δ)`**，满足 `P(‖ρ̂−ρ‖∞ ≤ ε) ≥ 1−δ`（Hoeffding/Bernstein + 噪声膨胀）。部署判据不用点估计，而用**下界** `ρ̂(d) − ε ≥ ρ_min(d)`。预算越小，`ε` 越大，可部署动作域越窄——**soundness 不被牺牲，牺牲的是覆盖**。这为「低成本和可靠性如何兼得」提供了可计算的答案。

**灵感 4（跨本体迁移：用指纹距离换标定次数）**
直觉：便宜的机器人不必从零标定。若 `φ_{R'}` 落在已标定 `φ_R` 的邻域内，则 `ρ_{R'}` 与 `ρ_R` 的差被 `L_ρ·dist_Φ(φ_R, φ_{R'})` 界定，动作域差被 `L_A·dist_Φ` 界定。于是「买第二台便宜机」的成本只是测指纹 + 一次迁移校验，而非重跑全套实验。**低成本通过「复用」实现，而不是通过「削减证据」实现**。

**灵感 5（机队是标定放大器：多样性替代精度）**
直觉：单台廉价机样本少、`ε` 大；但一个异构机队在 `Φ` 空间上铺开，其**并联覆盖** `cov_Φ = μ(∪ Ball(φ_i, r_i))` 可远大于任何单机。平台的通用性不应由最强的一台定义，而由机队覆盖的指纹区域定义。代价是**相关失效**：同批次电机、同款传感器可能一起坏，故需用有效多样性 `N_eff` 对下界打折。低成本机队的风险不是「单机不准」，而是「大家一起错」。

**灵感 6（成本-通用性-可靠性三角与节俭前沿）**
直觉：把三者画成一条**节俭前沿 `F(b)`**：预算 `b` 下能达到的最大认证动作覆盖。平台竞争力的正确指标不是「成功率多高」，而是「每美元能认证多少可部署动作/任务」。这直接对应 UniBot 这类通用平台赛题：看的不是单点 demo，而是**单位成本下的可迁移能力**。

## 1. 形式化定义（增量：定义 121–128）

**定义 121（本体指纹）**
给定固定探针电池 `B = {β_1,…,β_m}`，每个探针返回廉价可观测量。本体指纹
```
φ_R = (rep_R, bw_R, comp_R, σ_obs,R, sat_R, τ_R) ∈ Φ ⊂ R^m
```
即重复性、跟踪带宽、柔顺度、观测噪声、执行器饱和、响应延迟。探针成本 `cost(B) = m·c_probe + t_probe`。假设 `B` 在全平台统一（同一物理量纲），故 `φ` 可跨机型比较。

**定义 122（规范动作空间与重参数化）**
存在可逆重参数化 `π_R : A_R → A*`，其在 `A*` 上的失真 `d_R(a*) = ‖π_R^{-1}(a*) − a*‖`（归一化单位）。技能 `S` 在 `A*` 上的规范剖面
```
α*_S(a*) = α_S(π_R^{-1}(a*))
```
跨本体兼容性、覆盖、组合图均在 `A*` 上重新计算；执行时经 `π_R^{-1}` 落回 `A_R`。

**定义 123（标定预算与认知证书）**
预算 `b = (n_probe, n_rollout, t_cpu, c_$)`。鲁棒性估计 `ρ̂_R(b)` 的**认知半径** `ε_R(b,δ)` 定义为满足
```
P(‖ρ̂_R(b) − ρ_R‖∞ ≤ ε_R(b,δ)) ≥ 1 − δ
```
的最小 `ε`。下界 `ρ_lb(d) = ρ̂(d) − ε_R(b,δ)`；剖面下界 `α_lb(a*) = α̂(a*) − ε_α`。技能在预算 `b` 下可部署当且仅当
```
∀d∈D_task : ρ_lb(d) ≥ ρ_min(d)  ∧  ∀a*∈A*_T : α_lb(a*) ≥ θ_cov。
```

**定义 124（认证平台域）**
```
Ω_cert(κ) = { φ ∈ Φ : min_d [ ρ_lb,calib(d) − L_ρ·dist_Φ(φ, Φ_calib) − β_batch ] ≥ ρ_min(d), κ = 1−δ }
```
即「用已有标定指纹 + 迁移界仍能保证可靠性的指纹区域」。`φ_target ∈ Ω_cert` 是平台证书可复用的必要条件。

**定义 125（跨本体迁移界）**
对任意 `R, R'`，设 `φ, φ'` 为其指纹，则
```
|ρ_{R'}(d) − ρ_R(d)| ≤ L_ρ·dist_Φ(φ, φ') + ν_batch(φ, φ')
d_H(A*_core,R , A*_core,R') ≤ L_A·dist_Φ(φ, φ')
```
其中 `d_H` 为 Hausdorff 距离，`ν_batch` 为批次方差上界。迁移有效当且仅当 RHS 小于对应裕度。

**定义 126（机队证书）**
机队 `ℛ = {R_1,…,R_N}`，每台以 `Ball(φ_i, r_i)` 认证。覆盖
```
cov_Φ(ℛ) = μ(∪_i Ball(φ_i, r_i)) / μ(Φ_task)
N_eff = (Σ_i w_i)^2 / Σ_i w_i^2
```
相关失效惩罚 `γ_corr(N_eff, ρ_corr)`。机队证书
```
C_fleet = ( cov_Φ, N_eff, ρ_lb,fleet = min_i ρ_lb,i − γ_corr, cost_fleet )。
```

**定义 127（平台通用性证书 PGCert）**
```
PGCert = ( A*_valid, Ω_cert, ρ_lb, α_lb, cost_cert, evidence )
```
其**通用性密度** `gen(PGCert) = μ(A*_valid ∩ A*_task) / cost_cert`（单位成本下可认证的可部署动作体积）。部署规则：`φ_target ∈ Ω_cert ∧ ρ_lb ≥ ρ_min ∧ α_lb ≥ θ_cov ∧ cost_cert ≤ budget`。

**定义 128（节俭前沿）**
```
F(b) = sup_{PGCert} { μ(A*_valid ∩ A*_task) : soundness(PGCert) ≥ 1−δ, cost_cert ≤ b }
```
在边际收益递减假设下 `F` 单调非降且凹。平台比较用 `F` 在赛题预算点的值或 `∫_0^{B} F(b) db`（AUC）。

## 2. 关键算法 伪代码

### IP-121 EPF（Embodiment Probe Fingerprint）

```python
def probe_fingerprint(robot, battery, budget):
    phi = {}
    for probe in battery.select(budget.n_probe):
        traj, timing, effort, contact = robot.execute(probe)
        phi['repeat'] = repeatability(traj)
        phi['bw']     = tracking_bandwidth(timing)
        phi['comp']   = compliance(contact)
        phi['sat']    = saturation(effort)
        phi['sigma']  = sensor_noise(traj)
    return EmbodimentFingerprint(phi, cost=battery.cost(budget.n_probe))
```

### IP-122 CAR（Canonical Action Re-parameterization）

```python
def canonicalize(robot, phi, A_star, calib_pairs):
    pi  = fit_reparam(phi, calib_pairs)          # A_R -> A*
    inv = invert(pi)                             # A* -> A_R
    alpha_star = {a: robot.alpha.get(inv(a), 0.0) for a in A_star}
    return CanonicalMap(pi, inv, alpha_star, distortion=distortion(pi))
```

### IP-123 CBA（Calibration Budget Allocation → 认知证书）

```python
def epistemic_certificate(robot, skill, b, delta):
    rho_hat, n = estimate_robustness(skill, b.n_rollout)
    eps   = hoeffding_radius(n, delta) + noise_inflation(robot.phi['sigma'])
    eps_a = profile_radius(robot, b, delta)
    rho_lb   = {d: max(0.0, rho_hat[d] - eps) for d in rho_hat}
    alpha_lb = {a: max(0.0, v - eps_a)
                for a, v in robot.canonical.alpha_star.items()}
    return Cert(rho_hat, rho_lb, alpha_lb, eps, cost=b.cost())

def deployable(cert, rho_min, theta_cov):
    return (all(cert.rho_lb[d] >= rho_min[d] for d in rho_min)
            and all(v >= theta_cov for v in cert.alpha_lb.values()))
```

### IP-124 XET（Cross-Embodiment Transfer）

```python
def transfer_certificate(src, phi_src, phi_dst, L_rho, L_A, beta_batch):
    gap = dist_phi(phi_src, phi_dst)
    rho_lb = {d: src.rho_lb[d] - L_rho*gap - beta_batch(d) for d in src.rho_lb}
    A_valid = erode(src.A_valid, L_A*gap)
    if any(rho_lb[d] < RHO_MIN[d] for d in RHO_MIN):
        return ('reject', 'transfer_gap', gap)
    if volume(A_valid) < THETA_COV:
        return ('reject', 'action_shrink', gap)
    return ('ok', PGCert(A_valid, ball(phi_dst), rho_lb, src.alpha_lb,
                         cost=src.cost + C_PROBE))
```

### IP-125 FLC（Fleet-Level Certificate）

```python
def fleet_certificate(robots, phi_space, L_rho, rho_corr):
    centers = [r.phi for r in robots]
    r_i     = [max_radius(r, RHO_MIN, L_rho) for r in robots]
    cov     = measure_union(centers, r_i, phi_space)
    N_eff   = (sum(w)**2) / sum(w_i**2 for w_i in w)
    pen     = correlated_penalty(N_eff, rho_corr)
    rho_lb  = {d: min(r.rho_lb[d] for r in robots) - pen for d in RHO_MIN}
    return FleetCert(cov, N_eff, rho_lb, sum(r.cost for r in robots))
```

### IP-126 PGCert（Platform Generality Certificate）

```python
def platform_certify(calib_set, phi_space, budget, delta):
    certs  = [epistemic_certificate(r, s, budget, delta)
              for r in calib_set for s in skills_of(r)]
    fleet  = fleet_certificate(calib_set, phi_space, L_rho, rho_corr)
    Omega  = union_balls([r.phi for r in calib_set], fleet.r_i)
    A_val  = intersect(A_STAR, union(c.A_valid for c in certs))
    gen    = volume(A_val & A_TASK) / total_cost(certs)
    return PGCert(A_val, Omega, fleet.rho_lb,
                  union(c.alpha_lb for c in certs), total_cost(certs),
                  evidence=[c for c in certs] + [fleet])

def deploy(pgcert, robot):
    if robot.phi not in pgcert.Omega:
        return ('reject', 'fingerprint_out_of_domain')
    if min(pgcert.rho_lb.values()) < RHO_MIN_MIN:
        return ('reject', 'robustness')
    return ('ok', assign_skills(pgcert.A_valid))
```

### IP-127 FFA（Frugal Frontier Allocation）

```python
def frugal_allocate(robots, skills, budget_units, delta):
    F = []
    while budget_units > 0:
        best = argmax(
            (marginal_coverage_gain(r, s, p) / marginal_cost(p))
            for r in robots for s in skills for p in probes
            if marginal_cost(p) <= budget_units
        )
        if best is None or marginal_coverage_gain(*best) <= 0:
            break
        apply(best); budget_units -= marginal_cost(best[2])
        F.append((spent_so_far(), certified_coverage()))   # 前沿折线
    return allocation, F
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| EPF | O(m·T_probe) | O(m) | 探针电池固定、量纲归一、可复现 |
| CAR | O(|A*| + |calib|) | O(|A*|) | 重参数化可逆、失真可测 |
| CBA | O(n_rollout·T_ep) | O(|D_ρ|) | 集中不等式成立（近 iid）+ 噪声膨胀 |
| XET | O(|D_ρ| + |A*|) | O(|A*|) | Lipschitz 界与批次界 sound |
| FLC | O(N·|Φ| + |Φ|) | O(N) | 覆盖可测、相关失效有上界 |
| FFA | O(B_units·|R|·|S|·log) | O(B_units) | 子模贪心 ≈ (1−1/e) 最优 |

**正确性定理（Frugal Platform Generality Soundness）**
假设 `(A29)–(A33)`：**(A29)** `φ` 是充分统计量，`ρ(d|φ)` 与 `A*` 由 `φ` 决定且分别 `L_ρ`、`L_A`-Lipschitz；**(A30)** 探针测量噪声有界、指纹可复现；**(A31)** 跨批次差异 ≤ `β_batch`；**(A32)** 鲁棒性估计满足 PAC 界 `P(‖ρ̂−ρ‖∞ > ε) ≤ δ`；**(A33)** 机队失效相关性由 `N_eff` 捕获、上界为 `ρ_corr`。
则对满足 `φ' ∈ Ω_cert` 的目标机 `R'`：
```
P_success ≥ 1 − δ − Σ_d (1 − ρ_min(d))
                − L_ρ·dist_Φ(φ', Φ_calib) − β_batch − γ_corr(N_eff, ρ_corr)
```
且其可认证动作覆盖为 `μ(A*_valid)`。
**推论**：`F(b)` 关于 `b` 单调；每单位预算要么买更小的 `δ/ε`（更多 rollout），要么买更大的 `Ω_cert`（更多指纹点），故分配问题是一个子模最大化，子模贪心有 `(1−1/e)` 近似保证。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 指纹不是充分统计量（探针漏掉隐藏模态） | 高 | 探针电池覆盖设计 + 残差检测 + 拒绝域外推 |
| 批次方差污染 `Ω_cert` | 高 | 分批校准 + `β_batch` 上界 + 出厂抽检 |
| Lipschitz 常数不可验证 | 高 | 机队数据经验估计 + 保守上界 + 迁移绊线 |
| 机队相关失效（大家一起错） | 高 | `N_eff` 折价 + 异构采购 + 独立失效监控 |
| 低预算导致覆盖过窄、不可用 | 中 | 分层技能 + 关键动作优先 + 主动探针选择 |
| 节俭前沿只在单批次合成数据成立 | 中 | 多批次多机型现场复现 + 分布外测试 |

## 6. 本轮最大风险

**一句话**：低成本通用平台把证书从「单机精确值」改造成「指纹条件下的区间证书」，其 soundness **完全依赖本体指纹 φ 是动作剖面与鲁棒性的充分统计量**；一旦探针电池漏掉某个隐藏的本体模态（如某种廉价减速器的回差），平台会把在 `φ` 邻域内有效的证书系统性地复用到实际不成立的机器人上——这比单机标定失败更危险，因为错误被**跨机器共享和放大**，故必须以 **探针残差检测 + 批次方差上界 + 拒绝域外推绊线** 三重护栏，宁可缩小 `Ω_cert`，也绝不把「指纹相近」当作「行为等价」。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-FrugalPort（EPF×CAR×CBA×XET×FLC×PGCert×FFA）

> 承接第 54 轮产物 v31。本轮在「动作-鲁棒性双证书」之上，增加面向 **通用机器人平台 × 低成本** 的六大算子，核心是把「具体机器人」抽象为低维**本体指纹 φ**，并把标定预算变成带认知半径的显式资源：
> - **EPF（Embodiment Probe Fingerprint）**：一组廉价探针动作测出可跨机型比较的本体指纹 `φ_R`；
> - **CAR（Canonical Action Re-parameterization）**：把各本体动作空间拉回规范空间 `A*`，使技能/剖面/兼容性可跨机型比较；
> - **CBA（Calibration Budget → Certificate）**：预算 `b` → 认知半径 `ε(b,δ)` → 区间证书，只按下界部署；
> - **XET（Cross-Embodiment Transfer）**：以指纹距离为代价，把证书从已标定本体迁移到新廉价本体；
> - **FLC（Fleet-Level Certificate）**：用异构机队的指纹覆盖替代单机精度，并对相关失效折价；
> - **PGCert（Platform Generality Certificate）**：平台级证书，兼报 `A*_valid`、`Ω_cert`、`cost_cert`；
> - **FFA（Frugal Frontier Allocation）**：在 `F(b)` 节俭前沿上做子模预算分配。
>
> IP 编号：IP-121~IP-127（共 7 个新增），升级 IP-115/116/118/120 以纳入指纹与预算维度。

## 0. 核心 IP 设计

| 编号 | 名称 | 类型 | 关键改进 |
|---|---|---|---|
| IP-121 | EPF Embodiment Probe Fingerprint | 新增 | 探针电池 → `φ_R ∈ Φ`，成本 `O(m)` 而非 `O(|A|)` |

| IP-125 | FLC Fleet-Level Certificate | 新增 | 指纹覆盖 + 有效多样性 `N_eff` + 相关失效折价 |
| IP-126 | PGCert Platform Generality Certificate | 新增 | `(A*_valid, Ω_cert, ρ_lb, α_lb, cost_cert)` |

## 1. 符号体系增量（新增定义 121–128）

| 符号 | 含义 |
|---|---|
| `φ_R ∈ Φ ⊂ R^m` | 本体指纹（重复性/带宽/柔顺/噪声/饱和/延迟） |
| `B = {β_1,…,β_m}` | 固定探针电池，成本 `O(m)` |
| `π_R : A_R → A*` | 规范动作重参数化 |
| `α*_S(a*)` | 技能在规范动作空间上的剖面 |
| `b = (n_probe, n_rollout, t_cpu, c_$)` | 标定预算向量 |
| `ε_R(b,δ)` | 认知半径，PAC 保证 `P(‖ρ̂−ρ‖∞≤ε) ≥ 1−δ` |
| `ρ_lb = ρ̂ − ε` | 可部署鲁棒性下界 |
| `Ω_cert(κ)` | 认证平台指纹域 |
| `L_ρ, L_A` | 指纹→鲁棒性 / 指纹→动作域的 Lipschitz 常数 |
| `ν_batch / β_batch` | 跨批次方差上界 |
| `cov_Φ(ℛ), N_eff, γ_corr` | 机队指纹覆盖、有效多样性、相关失效惩罚 |
| `PGCert = (A*_valid, Ω_cert, ρ_lb, α_lb, cost_cert)` | 平台通用性证书 |
| `gen = μ(A*_valid∩A*_task)/cost_cert` | 通用性密度（每美元认证覆盖） |
| `F(b)` | 节俭前沿：预算 b 下最大认证覆盖 |

## 2. 关键算法 伪代码

### IP-121 EPF

```python
def probe_fingerprint(robot, battery, budget):
    phi = {}
    for probe in battery.select(budget.n_probe):
        traj, timing, effort, contact = robot.execute(probe)
        phi['repeat'] = repeatability(traj)
        phi['bw']     = tracking_bandwidth(timing)
        phi['comp']   = compliance(contact)
        phi['sat']    = saturation(effort)
        phi['sigma']  = sensor_noise(traj)
    return EmbodimentFingerprint(phi, cost=battery.cost(budget.n_probe))
```

### IP-122 CAR

```python
def canonicalize(robot, phi, A_star, calib_pairs):
    pi  = fit_reparam(phi, calib_pairs)          # A_R -> A*
    inv = invert(pi)                             # A* -> A_R
    alpha_star = {a: robot.alpha.get(inv(a), 0.0) for a in A_star}
    return CanonicalMap(pi, inv, alpha_star, distortion=distortion(pi))
```

### IP-123 CBA

```python
def epistemic_certificate(robot, skill, b, delta):
    rho_hat, n = estimate_robustness(skill, b.n_rollout)
    eps   = hoeffding_radius(n, delta) + noise_inflation(robot.phi['sigma'])
    eps_a = profile_radius(robot, b, delta)
    rho_lb   = {d: max(0.0, rho_hat[d] - eps) for d in rho_hat}
    alpha_lb = {a: max(0.0, v - eps_a)
                for a, v in robot.canonical.alpha_star.items()}
    return Cert(rho_hat, rho_lb, alpha_lb, eps, cost=b.cost())

def deployable(cert, rho_min, theta_cov):
    return (all(cert.rho_lb[d] >= rho_min[d] for d in rho_min)
            and all(v >= theta_cov for v in cert.alpha_lb.values()))
```

### IP-124 XET

```python
def transfer_certificate(src, phi_src, phi_dst, L_rho, L_A, beta_batch):
    gap = dist_phi(phi_src, phi_dst)
    rho_lb = {d: src.rho_lb[d] - L_rho*gap - beta_batch(d) for d in src.rho_lb}
    A_valid = erode(src.A_valid, L_A*gap)
    if any(rho_lb[d] < RHO_MIN[d] for d in RHO_MIN):
        return ('reject', 'transfer_gap', gap)
    if volume(A_valid) < THETA_COV:
        return ('reject', 'action_shrink', gap)
    return ('ok', PGCert(A_valid, ball(phi_dst), rho_lb, src.alpha_lb,
                         cost=src.cost + C_PROBE))
```

### IP-125 FLC

```python
def fleet_certificate(robots, phi_space, L_rho, rho_corr):
    centers = [r.phi for r in robots]
    r_i     = [max_radius(r, RHO_MIN, L_rho) for r in robots]
    cov     = measure_union(centers, r_i, phi_space)
    N_eff   = (sum(w)**2) / sum(w_i**2 for w_i in w)
    pen     = correlated_penalty(N_eff, rho_corr)
    rho_lb  = {d: min(r.rho_lb[d] for r in robots) - pen for d in RHO_MIN}
    return FleetCert(cov, N_eff, rho_lb, sum(r.cost for r in robots))
```

### IP-126 PGCert

```python
def platform_certify(calib_set, phi_space, budget, delta):
    certs  = [epistemic_certificate(r, s, budget, delta)
              for r in calib_set for s in skills_of(r)]
    fleet  = fleet_certificate(calib_set, phi_space, L_rho, rho_corr)
    Omega  = union_balls([r.phi for r in calib_set], fleet.r_i)
    A_val  = intersect(A_STAR, union(c.A_valid for c in certs))
    gen    = volume(A_val & A_TASK) / total_cost(certs)
    return PGCert(A_val, Omega, fleet.rho_lb,
                  union(c.alpha_lb for c in certs), total_cost(certs),
                  evidence=[c for c in certs] + [fleet])

def deploy(pgcert, robot):
    if robot.phi not in pgcert.Omega:
        return ('reject', 'fingerprint_out_of_domain')
    if min(pgcert.rho_lb.values()) < RHO_MIN_MIN:
        return ('reject', 'robustness')
    return ('ok', assign_skills(pgcert.A_valid))
```

### IP-127 FFA

```python
def frugal_allocate(robots, skills, budget_units, delta):
    F = []
    while budget_units > 0:
        best = argmax(
            (marginal_coverage_gain(r, s, p) / marginal_cost(p))
            for r in robots for s in skills for p in probes
            if marginal_cost(p) <= budget_units
        )
        if best is None or marginal_coverage_gain(*best) <= 0:
            break
        apply(best); budget_units -= marginal_cost(best[2])
        F.append((spent_so_far(), certified_coverage()))   # 前沿折线
    return allocation, F
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| EPF | O(m·T_probe) | O(m) | 探针固定、量纲归一、可复现 |
| CAR | O(|A*| + |calib|) | O(|A*|) | 重参数化可逆、失真可测 |
| CBA | O(n_rollout·T_ep) | O(|D_ρ|) | PAC 集中不等式 + 噪声膨胀 |
| XET | O(|D_ρ| + |A*|) | O(|A*|) | Lipschitz 界与批次界 sound |
| FLC | O(N·|Φ| + |Φ|) | O(N) | 覆盖可测、相关失效有上界 |
| FFA | O(B·|R|·|S|·log) | O(B) | 子模贪心 (1−1/e) 近似 |

**正确性定理（Frugal Platform Generality Soundness）**
假设 `(A29)–(A33)`：**(A29)** `φ` 是充分统计量，`ρ(d|φ)` 与 `A*` 分别 `L_ρ`、`L_A`-Lipschitz；**(A30)** 探针噪声有界、指纹可复现；**(A31)** 跨批次差异 ≤ `β_batch`；**(A32)** 鲁棒性估计满足 PAC 界 `P(‖ρ̂−ρ‖∞ > ε) ≤ δ`；**(A33)** 机队失效相关性由 `N_eff` 捕获、上界 `ρ_corr`。
则对 `φ' ∈ Ω_cert` 的目标机：
```
P_success ≥ 1 − δ − Σ_d (1 − ρ_min(d))
                − L_ρ·dist_Φ(φ', Φ_calib) − β_batch − γ_corr(N_eff, ρ_corr)
```
可认证覆盖为 `μ(A*_valid)`。
**推论 1**：`F(b)` 单调非降；预算每增加一单位，要么降低 `δ/ε`（多 rollout），要么扩大 `Ω_cert`（多指纹点）。
**推论 2**：在边际收益递减下 `F` 为凹、覆盖函数为子模，故 FFA 的 `(1−1/e)` 近似成立。
**推论 3（成本-通用性对偶）**：固定 `δ, ρ_min` 时，存在单调映射 `b ↦ F(b)`；平台比较应报告 `(F(b), b)` 而非单点成功率。

## 5. 与 UniBot 通用平台赛题的对应

| 赛题关注点 | 本方案对应 |
|---|---|
| 通用性（换个机器人还能用） | 指纹条件证书 + 跨本体迁移 `XET` + 平台域 `Ω_cert` |
| 低成本（不能靠昂贵标定/传感） | 探针电池 `EPF` + 预算-认知半径 `CBA` + 节俭前沿 `FFA` |
| 可靠性（不能只是 demo） | 只用下界部署 + PAC 保证 + 联合证书 `J` |
| 可复现（评委可核查） | `PGCert` 携带 `evidence`（探针日志、rollout、批次信息） |
| 可扩展（多机/机队） | 机队证书 `FLC` + `N_eff` 相关失效折价 |

## 6. 本轮最大风险

**一句话**：低成本通用平台把证书从「单机精确值」改造成「指纹条件下的区间证书」，其 soundness **完全依赖本体指纹 φ 是动作剖面与鲁棒性的充分统计量**；一旦探针电池漏掉某个隐藏的本体模态（如某种廉价减速器的回差），平台会把在 `φ` 邻域内有效的证书系统性地复用到实际不成立的机器人上——这比单机标定失败更危险，因为错误被**跨机器共享和放大**，故必须以 **探针残差检测 + 批次方差上界 + 拒绝域外推绊线** 三重护栏，宁可缩小 `Ω_cert`，也绝不把「指纹相近」当作「行为等价」。
