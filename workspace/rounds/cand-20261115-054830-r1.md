# 第 4 轮（灵感循环第 4 轮；本轮灵感：「基准测试」×「多端口部署」）

> **基线**：第 3 轮 InstructGauge（IP-321–327；定义 432–447；引理 51–58；实验 E441–E456）。第 2 轮 ToolGauge 与第 1 轮 LeanGauge / MODGAUGE 骨架继续继承不变。
> 本轮纪律：**内环不变、外环增量、严格退化**。基准与多端口只作用于「认证—部署」外环；任一外环组件不可用 ⇒ 回退到单端口 InstructGauge，内环的安全性与 50Hz 实时性不受影响。

## 0. 直觉与动机

**灵感 1（基准测试 → 基准是量具，不是真值）**
直觉：我们习惯把 benchmark 分数当「能力真相」，但分数本身是**测量结果**：换一批端口、换一组任务、换一次重复，排名就会抖。计量学早就给了答案——先做 **Gauge R&R**（重复性 + 可重复性），确认量具的分辨力足以区分被测对象，再谈排名。若基准的测量噪声 `σ_meas` 大于策略间真实差异 `Δ`，那么「第一名」只是噪声的一次抽样。因此本轮把基准提升为**一等测量仪器**：先估方差分量、最小可检测效应 MDE 与留一端口排名稳定性；不达标就诚实地输出 `INCONCLUSIVE`，而不是硬选一个赢家。

**灵感 2（多端口部署 → 可重复性就是跨端口）**
直觉：一个策略在 A 工位好，不代表在 B 工位好。不同端口的传感噪声、时钟、运动学误差、物理包线和局部安全契约都不同；把 A 的标定直接搬到 B，可能产生**负迁移**。但完全不共享又浪费 B 的冷启动样本。正确做法是「**同一内环、分层外环**」：每个端口保留完全独立的 InstructGauge 闭环与本地安全盾；跨端口只共享**冻结的、已认证的先验**（队列阈值/初始化），并用端口指纹判断「能不能借」。部署本身则按影子→金丝雀→舰队分级推进，回滚也按端口/队列/舰队分级。

**灵感 3（二者耦合 → 基准—端口混杂、Goodhart 与舰队尾部风险）**
直觉：把「基准测试」与「多端口部署」直接相乘，最危险的三个耦合是：
1. **基准—端口混杂**：各端口任务构成不同，聚合均值可能掩盖最差端口（Simpson 反转）；
2. **Goodhart / 基准污染**：策略一旦能反复查询认证集，排名会被选择膨胀污染；
3. **舰队尾部风险**：N 个端口只要有一个失效，舰队就算失败；平均风险低不代表最差端口安全。
因此本轮的三根结构支柱是：**密封认证集 + 查询预算**（防污染与选择膨胀）、**端口分层估计量 + 最差端口/CVaR 门槛**（防聚合偏倚与尾部掩盖）、**分级回滚 + 租约自治**（防跨端口级联与分区失控）。

## 1. 研究问题（本轮要回答什么）

- **Q1（基准的有效性）**：一个基准在什么条件下才有资格作为「认证量具」？如何用方差分量、MDE 与留一端口排名稳定性，把「不可判定」显式地暴露出来？
- **Q2（多端口的安全性）**：如何让同一策略在异构端口上部署，既不发生负迁移，也不破坏任一端口的局部安全契约？跨端口到底允许共享什么、禁止共享什么？
- **Q3（耦合的尾部与 Goodhart）**：当基准选择与端口部署耦合，聚合均值会怎样掩盖最差端口？如何用密封认证、分层估计、尾部风险门槛与分级回滚，把「平均好看、局部出事」压回可审计的约束？

## 2. 三条设计原则（P4–P6，续第 3 轮 P1–P3；正式化见产物区定义 448–463）

**P4 基准即量具（Benchmark-as-Instrument）**
先做测量系统分析，再谈排名。认证基准与开发基准物理隔离：`D_cert` 密封、访问留痕、查询计预算；认证任务不得进入训练/奖励/规划目标。若 `MDE > Δ_claim`、`DR < DR_min`、存在污染或留一端口排名不稳，则输出 `INCONCLUSIVE`，**不允许**据此部署。这是「诚实不可判定」原则：宁可承认量具不够，也不把噪声包装成能力。

**P5 端口分层、内环不变（Port-Stratified, Inner-Loop Invariant）**
每个端口有自己的清单、契约、时钟与安全盾；内环始终是完整的 InstructGauge-7C，跨端口协调器不能内联进 50Hz 路径。跨端口只允许共享**冻结的认证先验**与**已签名的认证数据**，禁止让一个端口的实时动作成为另一个端口动作函数的输入。端口指纹超出 `τ_fp` 即退化为 singleton 队列，只借本地样本——用结构而不是调参来阻断负迁移。

**P6 最差端口与分级回滚（Worst-Port, Scoped Rollback）**
舰队准入看 `max_p R_p` 与 `CVaR_β({R_p})`，不看平均。回滚分端口/队列/舰队三级，恢复点必须是经 FleetCert 签名的快照，且只能在 `q_quiesce` drain 后替换；每端口持有租约，租约过期即冻结版本、拒绝新版本但继续以最后认证契约自治运行。这样网络分区只损失可用性/性能，不损失安全性。

## 3. 与基线的接口（如何退化）

- 基准无法估计 MSA（端口数 `< n_min`）/ 端口不足 ⇒ 禁止跨端口排名与池化，只做单端口认证，退化为逐端口 InstructGauge；
- G1 不通过（`DR < DR_min` / `MDE > Δ_claim` / 污染 / 排名不稳）⇒ 输出 `INCONCLUSIVE`，保留最后认证版本，不产生新部署；
- PortRegistry / GateFlow 不可用 ⇒ 冻结最后认证版本，禁止新版本上线；端口继续以本地契约自治；
- HiPAC 样本不足 ⇒ 队列阈值 ⇒ 全局阈值 ⇒ 保守阈值；指纹越界 ⇒ 只用本地；
- FleetBreaker 不可用 ⇒ 禁止舰队级毕业，但保留端口级回滚；
- InstructGauge 失效 ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE 原样。

## 4. 预期贡献

1. 一个 **metrology-grade** 的基准口径：把 Gauge R&R、DR、MDE、留一端口排名稳定性、密封认证与查询预算组合成可执行的「量具有效性闸门」，让基准第一次能输出「不可判定」而不是被迫排名；
2. 一个 **端口分层部署** 方案：端口指纹/队列、部分池化冷启动、每端口自适应共形、五态闸门，保证异构端口上不借错先验、不跳过本地安全盾；
3. 一个 **舰队级安全** 论证：最差端口/CVaR 准入、三级回滚、租约自治、无实时跨端口耦合，把「平均安全」升级为「尾部可界」；
4. 一条完整可证伪路径：E457–E472 覆盖基准分辨力、排名稳定性、污染/Goodhart、冷启动、每端口覆盖、闸门可靠性、分区自治、舰队尾部风险与 50Hz 时序保全。

## 5. 本轮最大风险

**一句话**：真正的风险不是某个组件失效，而是**基准的分辨力不足却被组织压力当成真值**——端口数少、测量噪声大时，G1 会频繁输出「不可判定」，而团队可能绕过闸门改用聚合均值部署，从而把最差端口的长尾风险藏进「平均提升」里。

## 2. 形式化定义（要点）

**定义 448（端口与端口清单）** 端口 `p = (id_p, hw_p, C_p, clk_p, ver_p, snapshot_p)`，其中 `hw_p` 为传感/执行/算力配置，`C_p` 为端口局部契约（包含 ToolGauge 五不变式、物理包线、采样与延迟约束），`clk_p` 为时钟/延迟模型，`ver_p` 为当前认证策略版本，`snapshot_p` 为最近一次签名的 FleetCert 快照。端口潜在参数 `θ_p ∈ Θ`；端口之间可以异构，但必须共享同一动作/回执类型系统。

**定义 449（端口指纹与队列）** 诊断探测在**不执行不可逆动作**的前提下产生
`fp(p) = (噪声谱, 延迟分位, 运动学残差, 漂移率, 温漂系数)`。
队列分配 `κ(p) = argmin_k d(fp(p), μ_k)`，仅当 `d(fp(p), μ_κ) ≤ τ_fp` 时接纳；否则 `κ(p) = {p}` 为 singleton 队列。队列先验 `π_κ(θ)` 只允许由**冻结的认证数据**估计，不得吸收任一端口未认证的实时动作。

**定义 450（认证基准协议 B）** `B = (D_dev, D_cert, split, seal, b, watermark)`：`D_dev` 可自由用于开发；`D_cert` 密封、按查询计预算 `b`、每次访问留痕；`split` 同时按端口 `P_ho` 与任务族 `T_ho` 留出；`watermark` 为带已知期望的水印任务。污染指示
`contam(B, π) = 1[ ∃ e ∈ D_cert : hash(e) ∈ Train(π) ∪ D_dev ∨ watermark_anomaly(π) ]`。
认证实例输出不是标量，而是每端口得分矩阵 `Z ∈ R^{|P_ho|×m}`，以保留端口异质性。

**定义 451（基准的 Gauge R&R 与分辨力）** 把候选策略族视为随机效应，端口、任务、重复为随机效应：
`y_{π,p,t,r} = μ + α_π + β_p + (αβ)_{πp} + γ_t + ε_{πptr}`。
记方差分量 `σ²_α, σ²_β, σ²_{αβ}, σ²_ε`，定义
`σ²_meas = σ²_β + σ²_{αβ} + σ²_ε`（可重复性 + 跨端口可重复性），
`DR = σ_α / σ_meas`（策略效应相对测量噪声的分辨力比），
`R = σ²_α / (σ²_α + σ²_meas)`（基准信度），
`MDE = (z_{1−α/2} + z_{1−β}) · σ_meas · sqrt(2/n_eff)`（双侧两样本最小可检测效应）。
所有分量必须报告置信区间；`n_eff` 由端口×任务的有效独立样本数给出，而不是把同端口重复当成独立端口。

**定义 452（G1 量具有效性闸门）**
`G1(B, Δ_claim) = VALID` 当且仅当
`contam = 0 ∧ |P_ho| ≥ n_min ∧ DR ≥ DR_min ∧ MDE ≤ Δ_claim ∧ ρ_LOO ≥ ρ_min`，
其中 `ρ_LOO` 为留一端口后策略排名的 Spearman 稳定性。否则 `G1 = INCONCLUSIVE`。`INCONCLUSIVE` 是**一等输出**：它禁止基于该基准做部署决策，但允许继续收集端口/任务样本；绝不把不显著差异包装成「第一名」。

**定义 453（HiPAC：分层部分池化 + 每端口 ACI）** 设端口 `p` 的本地校准集为 `C_cal(p)`，本地阈值 `q_p^loc`、队列阈值 `q_κ`、全局阈值 `q_0`。冷启动初始化
`q_p^(0) = λ_p q_p^loc + (1−λ_p) q_κ`，`λ_p = n_p/(n_p+λ_0)`；
若 `d(fp(p), μ_κ) > τ_fp` 则强制 `λ_p = 1`（只用本地，阻断负迁移）；若队列样本也不足则用 `q_0`；再不足则用保守阈值 `q_max`。运行期对每端口独立做自适应共形：
`α_{p,t+1} = Π_{[α_min, α_max]}( α_{p,t} + γ(α − ε_{p,t}) )`，
`q_{p,t} = Quantile(C_cal(p) ∪ 新回执, 1 − α_{p,t})`。
池化只影响初始化与暂态；长期覆盖由每端口 ACI 自己负责，因此队列错配不会造成永久性覆盖失效。

**定义 454（GateFlow 部署闸门自动机）** 状态集 `{Registered, Qualified, Shadow, Canary, Fleet, Quarantined, RolledBack}`。迁移谓词：
- `Q_p`（合格）：`manifest_ok ∧ cert_replay_ok ∧ contract_ok ∧ shield_ok`；
- `S_p`（影子）：`N_shadow ≥ n_sh ∧ max_t |ŷ_{p,t} − y_{p,t}| ≤ ε_sh ∧ safety_p = 0`；
- `C_p`（金丝雀）：`N_canary ≥ n_can ∧ ACI_cov_p ≥ 1−α−ε_cov ∧ D_p < η ∧ safety_p = 0`；
- `F_p`（毕业）：`R_worst ≤ R_max ∧ R_tail ≤ R_tail^max ∧ rollback_drill_ok ∧ cohort_consistency_ok`。
迁移只在谓词为真时发生；任一回归谓词为真、或租约失效，立即进入回滚路径。闸门谓词必须由**独立证据**评估（认证回执、影子对比、金丝雀覆盖），不能由被认证策略自报。

**定义 455（分级回滚、租约与舰队断路器）** 回滚作用域 `scope ∈ {port, cohort, fleet}`；`rollback(scope, reason)` 对作用域内每个端口在 `q_quiesce`（定义 439）恢复 `snapshot_p`；若不在静默点，则按块 `abort`/CVC 规则 drain 到边界后恢复。端口租约 `L_p = (ver_p, expiry, sig_p)`；若 `now > expiry`，端口冻结 `ver_p`、拒绝任何新版本，但继续以最后认证契约自治运行。FleetBreaker 接受单调安全信号 `S(t)`；`S(t) ≥ θ_break` 时按预设 scope 触发回滚。爆炸半径 `BR(scope) = |{p : p 受该次回滚影响}|`。

**定义 456（基准感知规划与查询预算）** 策略族只允许在 `D_dev` 上优化；`D_cert` 只能经 CertBench 查询，总查询数 `≤ b`，且认证任务不得进入 reward、梯度或规划目标。选择膨胀估计
`infl = max_{m≤M} ( Ŝ_m − S_m )`，其中 `Ŝ_m` 为认证估计、`S_m` 为真实泛化值。认证规则：仅当 `Δ̂_m ≥ MDE + infl` 且 G1 通过时才发布「优于基线」的主张；否则降级为 `INCONCLUSIVE`。水印任务异常或认证项哈希命中训练集即判污染，整轮认证作废。

**定义 457（端口分层估计量与聚合偏倚）** 舰队关心的估计量是**预注册加权**的端口分层均值
`S_w(π) = Σ_p w_p · E_{D|p}[ y | π, p ]`，`w_p` 由目标部署人口预先固定，不能随策略改变。若策略分配与端口相关（`I(π; p) > 0`），原始样本均值 `S_raw` 会被端口构成混杂；此时必须使用分层/标准化估计或分块随机化。`S_raw` 只能作为描述统计，不能作为舰队准入证据。

**定义 458（舰队风险与尾部门槛）** 端口风险 `R_p(π)` 为安全违约率、契约违约率与覆盖亏损的预注册组合。舰队风险向量
`R_fleet = ( R_worst, R_tail ) = ( max_p R_p, CVaR_β({R_p}) )`。
准入要求 `R_worst ≤ R_max` 且 `R_tail ≤ R_tail^max`。平均值 `R_avg` 只用于成本核算，不能替代尾部约束——这是多端口相对单端口最重要的风险语义变化。

**定义 459（舰队安全包络与跨端口隔离）**
`Inv_fleet = (∧_p Inv_p) ∧ NoLiveCoupling`。
`NoLiveCoupling`：除非存在已认证的 `CoordContract`，任一端口的执行动作不得以另一端口**实时**状态/动作为输入。跨端口学习只允许使用**冻结的、已签名的认证数据**。该约束保证一个端口的故障不会通过实时耦合级联到其它端口；协调契约必须单独走 G1/G2/G3。

**定义 460（端口漂移与舰队漂移）** 端口漂移统计量 `D_p(t)` 由预测收缩/实测收缩残差、覆盖误差与延迟偏差合成；若 `D_p > η` 连续 `q` 次，端口从 `Fleet` 降级到 `Canary` 或 `Quarantined`，并重新校准。若同一队列内多个端口同时漂移，则判定为队列漂移：重跑 G1 的 MSA、重估队列先验，并暂停该队列的毕业。漂移图 `DriftMap(t) = {p ↦ D_p(t)}` 进入 FleetCert。

**定义 461（部署成本与净收益）**
`Cost = c_q|P| + c_sh N_shadow|P| + c_ca N_canary|P| + c_rb E[BR] + c_orch`，
`NB = G·(1 − p_fail) − Cost − λ_R · R_tail`。
闸门阈值在满足 `R_worst ≤ R_max ∧ R_tail ≤ R_tail^max` 的约束下最大化 `NB`；若 `NB ≤ 0`，正确决策是**不部署**，而不是降低安全门槛。

**定义 462（FleetCert 审计证书）**
`FleetCert = (B, MSA_report, {manifest_p}, gate_traces, {coverage_p}, rollback_drills, claims, signatures)`。
它把第 3 轮 `RepairCert′` 的四级证据链（指令→块→回执→主张）延伸到「端口→队列→舰队→认证基准」。任一条目必须可重放：审计者用相同输入应得到逐位一致的 MSA 报告、闸门判定与覆盖统计。

**定义 463（舰队静默点与部署波次）** `q_quiesce^fleet` 指某波次内所有端口均处于本地 `q_quiesce`、无在途块、无待处理不可逆动作的时刻。部署波次 `Wave ⊆ κ(p)` 按队列原子推进：同一波次内不允许混合版本；跨波次才允许灰度。这样任一端口都不会在块执行中观察到「混合契约」。

# IP-328 BenchMSA：先当量具，再谈排名
class BenchMSA:
    def fit(self, Z):
        vc = reml_variance_components(Z)          # sigma_alpha/beta/ab/eps
        s_meas = sqrt(vc.s_beta**2 + vc.s_ab**2 + vc.s_eps**2)
        dr  = vc.s_alpha / max(s_meas, 1e-9)
        mde = (z(1 - ALPHA/2) + z(1 - BETA)) * s_meas * sqrt(2 / n_eff(Z))
        return MSAReport(vc, dr, mde, loo_rank_stability(Z))

    def gate(self, msa, delta_claim, contaminated):
        if contaminated or msa.n_port < N_MIN:       return INCONCLUSIVE
        if msa.dr < DR_MIN:                          return INCONCLUSIVE
        if msa.mde > delta_claim:                    return INCONCLUSIVE
        if msa.rho_loo < RHO_MIN:                    return INCONCLUSIVE
        return VALID

# IP-329 CertBench：密封认证 + 查询预算（防 Goodhart）
class CertBench:
    def certify(self, policy, port_set):
        if self.queries[policy] >= B_BUDGET:
            return INCONCLUSIVE                      # 预算耗尽即拒绝继续窥视
        z = [self._sealed_score(policy, p) for p in port_set]
        self.queries[policy] += 1
        self.log(policy, z)
        return z

    def contaminated(self, policy):
        return any(hash(e) in policy.train_hashes for e in self.D_cert) \
               or self.watermark_anomaly(policy)

# IP-330 PortRegistry：端口注册、指纹与队列
class PortRegistry:
    def register(self, manifest):
        fp = diagnostic_probe(manifest.hw)           # 不执行不可逆动作
        k, d = nearest_cohort(fp)
        cohort = k if d <= TAU_FP else singleton(manifest.id)
        return Port(manifest, fp, cohort, lease=issue_lease(manifest))

# IP-331 HiPAC：冷启动部分池化 + 运行期每端口 ACI
class HiPAC:
    def init_threshold(self, port, cal):
        q_loc = conformal_quantile(cal.local, 1 - ALPHA)
        if port.fp_dist > TAU_FP:
            return q_loc                            # 指纹越界：只用本地
        q_coh = conformal_quantile(cal.cohort, 1 - ALPHA)
        lam = len(cal.local) / (len(cal.local) + LAMBDA0)
        return lam * q_loc + (1 - lam) * q_coh

    def update(self, port, err):
        port.alpha = clip(port.alpha + GAMMA * (ALPHA - err), ALPHA_MIN, ALPHA_MAX)
        port.q = conformal_quantile(port.cal, 1 - port.alpha)

# IP-332 GateFlow：五态闸门与回滚
class GateFlow:
    def step(self, port, ev):
        s = port.state
        if s == "Registered" and ev.Q:                port.state = "Qualified"
        elif s == "Qualified" and ev.S:                port.state = "Shadow"
        elif s == "Shadow" and ev.C:                   port.state = "Canary"
        elif s == "Canary" and ev.F:                   port.state = "Fleet"
        if ev.regression or ev.lease_expired:
            return self.rollback(port, scope="port", reason=ev.reason)
        return port.state

# IP-333 FleetBreaker：分级回滚 + 租约自治
class FleetBreaker:
    def rollback(self, scope, reason):
        for p in fleet.ports_in(scope):
            if at_quiesce(p):
                p.restore(p.snapshot)
            else:
                p.request_drain(then_restore=True)   # 按 CVC/abort 截断
            p.reject_new_versions()
        fleet.record_rollback(scope, reason, blast_radius=len(fleet.ports_in(scope)))

    def heartbeat(self, p, now):
        if now > p.lease.expiry:
            p.freeze_version()
            p.reject_updates()
            return False
        return True

# IP-335 FleetGauge-3G：内环不变，外环三闸
def fleetgauge_meta(M, fleet, delta_claim):
    msa = M.bench.fit(fleet.pilot_scores())
    if M.bench.gate(msa, delta_claim, fleet.contaminated()) != VALID:
        return INCONCLUSIVE                          # 不部署；保留最后认证版本
    for p in fleet.registered:
        port = M.registry.register(p.manifest)
        if M.gateflow.step(port, M.gate_evidence(port)) != "Qualified":
            continue
        port.q = M.hipac.init_threshold(port, M.cal(port))
        if not M.gateflow.shadow(port):  continue
        if not M.gateflow.canary(port):  return M.breaker.rollback(p, "port")
    for cohort in fleet.cohorts():
        if M.fleetrisk.worst(cohort) > R_MAX or M.fleetrisk.tail(cohort) > R_TAIL:
            return M.breaker.rollback(cohort, "tail_risk")
        M.gateflow.graduate(cohort)                  # 只在 q_quiesce^fleet 推进 Wave

# 50Hz 内环：完全继承 InstructGauge / ToolGauge；外环异步、慢时间尺度
def FleetGauge_round(M, obs, audio, tac, depth, det, ell=None):
    for p in M.fleet.active:
        if M.breaker.heartbeat(p, M.now):
            InstructGauge_round(p.M, obs, audio, tac, depth, det, ell)
    M.meta_loop.schedule(fleetgauge_meta, M, M.fleet, M.delta_claim)
    return MODGAUGE_round(M, obs, audio, tac, depth, det)

## 4. 推导

**引理 59（基准分辨力下界：不可判定必须显式）** 若 `MDE > Δ_claim`，则在水平 `α` 下任何检验对「真实效应 `≥ Δ_claim`」的功效都 `< 1−β`；因此该基准不具备认证该主张的资格，G1 必须返回 `INCONCLUSIVE`。*证明*：MDE 按定义为在功效 `1−β` 下可检测的最小效应；若最小可检测效应已大于声明效应，则声明效应落在检验的不可区分区。推论：强行部署时，「提升」与「噪声」在统计上不可分离；正确行为是扩大端口/任务样本或降低声称效应，而不是降低门槛。

**引理 60（留一端口排名稳定性）** 对两个策略 `A, B`，令 `Δ_p = y_{A,p} − y_{B,p}`，`Δ = Σ_p w_p Δ_p`，`ε = max_p |Δ_p − Δ|`。移除端口 `q` 后 `Δ^{(-q)} = (Δ − w_q Δ_q)/(1−w_q)`，故
`|Δ^{(-q)} − Δ| = w_q |Δ − Δ_q| / (1−w_q) ≤ w_q ε / (1−w_q)`。
因此若 `Δ > 2 · max_q w_q ε/(1−w_q)`，则移除任一端口都不改变两策略的排序。*证明*：直接代入；排序翻转需要偏差至少 `Δ/2`。推论：G1 的 `ρ_LOO` 是对该充分条件的经验版本；当端口效应异质性过大时，基准只能报告「按端口分层结果」，不能报告全局冠军。

**引理 61（每端口 ACI 的长期覆盖）** 在每端口独立执行定义 453 的 ACI、且错误指示有界时，端口 `p` 的长期误覆盖满足
`|(1/T) Σ_{t≤T} ε_{p,t} − α| ≤ (α_max − α_min)/(γT) + O(γ)`。
分层池化只改变初始阈值，影响 `O(1/√n_p)` 的暂态；即使队列先验错配，ACI 仍会把长期覆盖拉回 `α` 附近。*证明*：Gibbs–Candès 型自适应共形论证逐端口应用；池化项只进入初始条件。推论：端口指纹守卫不必「一次判对」，它只需限制暂态的负迁移幅度。

**引理 62（部分池化的冷启动风险界）** 对收缩估计 `θ̂_p = λ_p θ̂_p^loc + (1−λ_p) θ̂_κ`，其均方误差满足
`E(θ̂_p − θ_p)² ≤ λ_p² σ²/n_p + (1−λ_p)² ‖θ_κ − θ_p‖²`。
若 `d(fp(p), μ_κ) > τ_fp` 则强制 `λ_p = 1`，偏置项消失，只剩本地方差；若在指纹球内，则偏置被 `τ_fp` 界住。*证明*：偏差-方差分解；收缩估计的偏置为 `(1−λ_p)(θ_κ − θ_p)`。推论：冷启动收益与负迁移风险由同一个 `λ_p` 控制，指纹距离给出可审计的开关，而不是靠事后调参。

**引理 63（闸门可靠性：未认证策略零执行）** 假设各闸门谓词在独立证据上可靠评估、且回滚在 `q_quiesce` 安全（引理 57/52）。则对 GateFlow 的迁移图做归纳：任一时刻处于 `Fleet` 的端口必已通过 `G1 + Q_p + S_p + C_p + F_p`；任一失败谓词只会触发回滚或停留原状态。因此不存在「未认证策略在舰队中执行」的路径。*证明*：对状态迁移次数归纳；回滚恢复签名快照，快照本身是上次认证通过的版本。推论：若仍发生安全违约，则必是某个闸门谓词的假阴性，即**认证量具本身失效**——这正好把系统级事故归因回 G1，而不是归咎于单个端口。

**引理 64（分区自治与租约安全）** 若端口租约过期，它只能继续最后认证版本 `ver_p` 并拒绝新版本；又由 `Inv_fleet` 的 `NoLiveCoupling`，其动作不依赖其它端口的实时状态。因此网络分区只会降低可用性/更新速度，不会破坏本地 `Inv_p`。*证明*：本地内环与安全盾独立于外环；冻结版本 + 拒绝更新把状态限制在已认证集合；无实时耦合切断了级联路径。

**引理 65（选择膨胀/Goodhart 界）** 设认证分数有界，候选策略数 `≤ M`、总认证查询 `≤ b`。即使查询自适应，至多评估 `b+1` 个不同策略；由 Hoeffding 联合界，
`P( max_m (Ŝ_m − S_m) ≥ t ) ≤ M(b+1) exp(−2n t²)`。
取 `t = sqrt( log(M(b+1)/δ) / (2n) )` 即以概率 `≥1−δ` 控制选择膨胀。故认证规则要求 `Δ̂ ≥ MDE + t`，且 `b` 必须预注册、查询必须留痕。*证明*：对每个候选/查询时刻做 Hoeffding 界再取并集。推论：不限制查询次数的「反复刷榜」会把 `t` 推高到吞掉真实效应；预算本身就是认证可信度的一部分。

**引理 66（聚合偏倚/Simpson 反转）** 当策略的端口构成不同（`I(π;p)>0`）时，原始均值 `S_raw` 可以与预注册分层估计 `S_w` 给出相反排序。反例：端口 A 上 `X=0.9, Y=0.85`，端口 B 上 `X=0.2, Y=0.3`。若 X 的样本几乎全在 A、Y 的样本几乎全在 B，则 `S_raw(X)≈0.9 > S_raw(Y)≈0.3`；但等权分层 `S_w(X)=0.55 < S_w(Y)=0.575`。*证明*：加权平均的权重随策略变化；固定权重的分层估计消除构成差异。推论：舰队准入必须使用 `S_w` 或分块随机化，`S_raw` 只能作描述。

**引理 67（舰队尾部风险不可由均值替代）** 对端口失败事件，`max_p R_p ≤ P(any) ≤ Σ_p R_p`；因此 `R_avg` 可以任意小，而 `R_worst` 仍接近 1（例如一个高风险端口加许多零风险端口）。若端口风险经共享队列先验相关，尾部还会进一步放大。*证明*：并集界与 Fréchet 不等式；构造单端口高风险例子即得均值/最差分离。推论：G3 必须同时约束 `R_worst` 与 `CVaR_β`；只约束平均风险的门槛在舰队规模增大时会系统性低估事故概率。

**引理 68（外环开销与 50Hz 保全）** BenchMSA 与 CertBench 只在离线/慢时间尺度运行；PortRegistry 注册为 `O(log|P|)`；GateFlow 每端口每慢拍 `O(1)`；FleetBreaker 只改变控制面状态。50Hz 内环仍是未修改的 InstructGauge-7C，新增每周期仅一次租约/契约检查，`< 0.1ms`。*证明*：外环全部异步下沉；内环调用图不变，继承 ToolGauge 引理 50 与 InstructGauge 引理 58。推论：多端口规模 `|P|` 影响控制面吞吐，不影响单端口硬实时。

## 8. 本轮最大风险

**一句话**：`FleetGauge` 把「基准是否可信」和「最差端口是否安全」都变成了硬闸门，但这也意味着当端口数不足、测量噪声过大时，系统会频繁输出 `INCONCLUSIVE`；真正的残余风险是**组织层面绕过 `INCONCLUSIVE`**——改用聚合均值或单端口漂亮数字部署，从而把最差端口的长尾风险重新藏回「平均提升」里。缓解只能靠：密封认证与查询预算（E459/E460）、端口分层估计（E468）、`R_worst`/`CVaR` 双门槛（E469）、租约与分级回滚（E465/E466），以及把 `INCONCLUSIVE` 写进 FleetCert 使其成为不可绕过的审计事实。
