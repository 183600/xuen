### 第 1 轮灵感驱动研究记录

**灵感词**：因果推理、多端口部署

**继承关系**：本轮承接第 5 轮 CADVS-v5（IP-493~496，认证的生成式执行 CGE）：七硬门不变、执行集 Exec_CADVS-v5 ⊆ … ⊆ Exec_v29、流匹配提议 + 记忆固化 + 情感调制。v5 的最大风险 R57 是**固化自指回路**——策略在自己铸证的片段上训练，缺乏外部真值，可能学会博弈证书门。本轮两个灵感词恰好各补一半：**因果推理**提供「干预/反事实」这一外部真值来源，**多端口部署**提供「跨站异质性」这一自然实验资源与隔离边界。二者合并为主题「因果可迁移认证」（Causal-Transportable Certification, CTC），形成 CADVS-v6（IP-497~501）。本轮自律：**仍不新增第 8 道硬门**（延续 R52 的锚点维护纪律），因果性不进入门的交集，而是升级「证书有效性谓词」——七门照旧，但一张证书只有同时满足因果可归因与可迁移才被接受，因此 Exec_v6 ⊆ Exec_v5 自动成立。

**直觉与动机**：

1. **因果推理：把「通过门」与「真的安全」分开，用 do 算子给证书补上外部真值**。v5 的证书只证明「观测上七门都过」，但观测相关不等于因果：一个动作可能因站点/操作者/病人等混杂而「看起来安全」，也可能因策略学会了门的边界伪影而「形式上合规」。因果推理的关键动作是把观测分布 P(Y|A) 换成干预分布 P(Y|do(A))：只有在**干预**下仍安全的动作，才是动作本身安全，而不是混杂或博弈的产物。定义**博弈间隙** Γ_gap = P(Y=1|A) − P(Y=1|do(A))；Γ_gap 大即「观测成功、因果失败」，正是 R57 的可度量指纹。外部真值来自**受控干预/随机扰动**（在已认证包络内做安全 RCT）与**跨站自然实验**（不同站点混杂不同，可做工具变量/差分）。固化训练集从「已铸证」升级为「已铸证 ∧ 因果可归因」，从源头切断自指闭环。

2. **多端口部署：把每个端口当作独立信任域，用异质性做因果识别，用隔离做故障遏制**。端口 p 是独立部署端点（站点/器械端口/租户），有各自的 P_p、校准、操作者与合规约束。多端口带来两件事：坏消息是站点 S 是强混杂，一张在 p 铸的证书未必在 p′ 成立；好消息是**同一因果机制在不同混杂下保持不变**，跨端口差异恰是识别因果效应的自然实验材料。于是引入**可迁移性**（Pearl–Bareinboim 选择图）：只有当选择节点不落在 A→Y 的未阻断路径上时，p 的因果结论才能搬到 p′。共享策略在所有端口生效，必须满足**各端口执行集的交集** Exec^{(𝒫)} = ∩_p Exec^{(p)}；每加一个端口只会让共享执行集更小（单调组合），这就是多端口版的 fail-closed。

3. **二者合流：因果认证不是加门，而是把证书从「自洽」升级为「可干预、可迁移、可审计」**。因果性作为证书的**有效性元谓词**，多端口作为**识别资源 + 隔离边界**。由此 v5 的 R57 从「只能靠红队经验上界、无法根除」改写为「在因果图正确且可识别的条件下有 δ_c 上界；图错时诚实回退 v5 并用敏感性分析标出不可信区间」。

**关键洞见**：v5 回答「生成式提议如何不破坏证书边界」；v6 回答「证书本身凭什么可信，以及它能否跨端口成立」。七硬门 kc_evidence_forged_v5 记号原样复用；本轮新增的只有：因果安全模型 ℳ_p、干预/反事实证书 Cert_p、可迁移签名 T(p→p′)、端口组合算子 ∩。执行集 Exec_v6^{(p)} ⊆ Exec_v5^{(p)} 由「同门 + 证书谓词更严」保证；跨端口 Exec_v6^{(𝒫′)} ⊆ Exec_v6^{(𝒫)} 由交集单调保证。

**严谨定义（增量）**：

1. **因果安全模型（CSM）**：端口 p 上 ℳ_p = (V, U, F_p, P_p(U))，V = X ∪ A ∪ Y ∪ G ∪ S；Y∈{0,1} 为真实结局；G=(G_1..G_7) 为七门信号；S 为端口/站点上下文。结构方程满足模块性（每个机制 f_V 可独立替换）。
2. **干预安全与博弈间隙**：干预安全 s_p(a,x) = P_p(Y=1|do(A=a),X=x)；博弈间隙 Γ_gap(x,p) = P_p(Y=1|A=a,X=x) − s_p(a,x)。
3. **因果证书**：Cert_p(x) = kc_evidence_forged_v5(x) ∧ [s_p(a,x) ≥ 1−δ_c] ∧ Ident_p(a,x)，其中 Ident_p 为可识别性（存在后门调整集 Z 且满足正性）。
4. **可迁移性**：选择图 𝒟(p→p′)；若所有选择节点不在 A→Y 的未阻断路径上，则因果效应可迁移，记 T(p→p′)=1，证书可提升为跨端口证书。
5. **端口执行集与组合**：Exec_v6^{(p)} = {x∈supp(π): Cert_p(x)=1}；共享执行集 Exec_v6^{(𝒫)} = ∩_{p∈𝒫} Exec_v6^{(p)}。
6. **因果固化（LMEM-v3）**：只固化「铸证 ∧ 结局验证 ∧ 因果可归因（干预标签或后门调整）」的片段；检测到 Γ_gap>ε_gap 的端口隔离其记忆并回退 v5 规则提议。
7. **定理 9~13**：因果证书可靠性、单调收缩、多端口单调组合、可迁移充分条件、固化防博弈的因果上界；引理 45~46 给出博弈间隙的可识别性与敏感性界。

**本轮最大风险**：**因果图误设与未观测混杂**——因果证书的「外部真值」建立在结构方程与调整集正确的假设上，一旦图错或存在未观测混杂，系统会给出**披着因果外衣的虚假保证**，比 v5 的自指回路更危险，因为它让审查者更难起疑。

## 2. 关键算法骨架

### IP-497 CSMK：因果安全模型核（离线建图 + 在线调整集查询）

```python
@dataclass
class CausalSafetyModelKernel:
    """CSMK：每端口 SCM。图是信任假设，不是学习对象（红线同 v5 的门）"""
    graph: CausalDAG                 # 端口因果图（先验 + 因果发现，带版本哈希）
    adjust_sets: dict                # 预计算的后门调整集 Z_p
    transport_diagrams: dict         # p→p′ 选择图
    delta_c: float = 0.01

    def identifiable(self, a, x, p) -> bool:
        """Ident_p：存在 Z 阻断所有后门路径且正性成立。图哈希参与签名"""
        return self._has_backdoor_set(a, x, p) and self._positivity(a, x, p)

    def do_query(self, a, x, p, estimator) -> float:
        """s_p(a,x)=P(Y=1|do(A=a),X=x)：后门调整 / RCT / IV / 跨站差分"""
        z = self.adjust_sets[p]
        return sum(estimator.p_y_given(a, x, z_i) * estimator.p(z_i)
                   for z_i in z.support)     # 后门公式

    def counterfactual(self, a, a_alt, x, p) -> float:
        """反事实：若在 x 下改采 a_alt，Y=1 的概率（用于证书审计）"""
        return self._abduct_action_effect(a, a_alt, x, p)

    def transportable(self, p, p_prime) -> bool:
        """T(p→p′)：选择节点不落在 A→Y 的未阻断路径上"""
        d = self.transport_diagrams[(p, p_prime)]
        return not d.selection_nodes_on_unblocked_paths('A', 'Y')
```

@dataclass
class InterventionalCertificateKernel:
    """ICK：把「过门」升级为「干预下安全且可识别」。
    关键：因果性不是第 8 道门，而是证书有效性谓词（不改变门交集）"""
    csm: CausalSafetyModelKernel
    delta_c: float = 0.01
    eps_gap: float = 0.05

    def certify(self, x, p, v5_cert: bool) -> CertResult:
        a, ctx = x.action, x.context
        if not v5_cert:
            return CertResult(False, 'V5_GATE_REJECT')
        if not self.csm.identifiable(a, ctx, p):
            return CertResult(False, 'UNIDENTIFIABLE_FAIL_CLOSED')  # 回退 v5
        s = self.csm.do_query(a, ctx, p, estimator=self.est)
        if s < 1.0 - self.delta_c:
            return CertResult(False, 'CAUSAL_UNSAFE')

        return CertResult(True, 'CAUSAL_CERTIFIED', sig=sig)

    def quarantine(self, p) -> None:

### IP-499 PTCK：端口可迁移证书核（组合 + 隔离）

```python
@dataclass
class PortTransportableCertificateKernel:
    """PTCK：多端口信任域。共享策略须满足各端口执行集交集"""
    ick: InterventionalCertificateKernel
    registry: dict                   # p -> PortState(图哈希, 校准, 证书库)

    def certify_port(self, x, p) -> bool:
        v5 = self.registry[p].v5_assembler.gate_pass(x)
        return self.ick.certify(x, p, v5).ok

    def certify_shared(self, x, ports: list[str]) -> bool:
        """共享证书：必须在每个端口都因果成立（交集，fail-closed）"""
        return all(self.certify_port(x, p) for p in ports)

    def promote(self, sig, src, dst) -> bool:
        """跨端口证书提升：仅当可迁移且目标端口无机制漂移时"""
        if not self.ick.csm.transportable(src, dst):
            return False
        if self.registry[dst].calibration_hash != sig.calib_hash:
            return False
        return True

    def compose(self, port_sets: dict) -> set:
        """Exec^{(𝒫)} = ∩_p Exec^{(p)}；新增端口只会收缩（定理 11）"""
        return set.intersection(*port_sets.values())
```

def theorem_transportability_sufficiency() -> str:

    定理 12：若选择图 𝒟(p→p′) 的所有选择节点均不在 A→Y 的未阻断路径上，

### IP-501 EFA-v6：七硬门 + 因果证书谓词 + 端口组合

```python
@dataclass
class EvidenceForgingAssemblerV6:
    """EFA-v6：七硬门不变；证书需通过因果有效性与可迁移性元谓词"""
    v5: EvidenceForgingAssemblerV5      # 复用 fmpp/lmem/famk/七门全套
    ick: InterventionalCertificateKernel
    ptck: PortTransportableCertificateKernel

    def select(self, x0_state, t_now, rule_id, context, port) -> tuple[bool, Trajectory | None, str]:
        ok, x, why = self.v5.select(x0_state, t_now, rule_id, context)
        if not ok:
            return False, None, why
        cert = self.ick.certify(x, port, v5_cert=True)
        if not cert.ok:
            return self.v5._fallback_rule_proposal(context)   # fail-closed 回退 v5
        return True, x, 'FORGED_CTC'

    def select_shared(self, x0_state, t_now, rule_id, context, ports) -> tuple[bool, Trajectory | None, str]:
        """共享策略：候选必须在所有端口都拿到因果证书（交集）"""
        cands = self.v5.fmpp.propose(build_ctx(context), self.v5.fmpp.K)
        for x in sorted(cands, key=certified_margin, reverse=True):
            if self.ptck.certify_shared(x, ports):
                return True, x, 'FORGED_CTC_SHARED'
        return False, None, 'NO_SHARED_CERTIFICATE'

    def ecs_v6(self, ..., s_p: float, transport_ok: bool) -> float:
        eta_causal = sigmoid((s_p - (1.0 - self.ick.delta_c)) / 0.01)
        eta_transport = 1.0 if transport_ok else 0.0
        return self.v5.ecs_v5(...) * eta_causal * eta_transport
```

## 4. 正确性论证（增量更新）

### 引理 45（博弈间隙的可识别性与敏感性）

**陈述**：Γ_gap 可识别当且仅当因果效应 P(Y|do(A)) 可识别。若存在未观测混杂 U，则观测间隙与真实间隙之差由 E-value 控制：Γ_gap^true ≥ Γ_gap^obs − bias(E)，其中 E 为使观测关联完全由混杂解释所需的最小关联强度。∎

**诚实边界**：不能声称「零博弈」；只能给出「在给定混杂强度假设下 Γ_gap 的上界」。

### 引理 46（可迁移性检验的样本复杂度）

**陈述**：选择图节点数 r、效应估计误差 ε 下，可迁移性检验需 O(r·log(1/δ)/ε²) 目标端口样本；正性被破坏的端口不可检验，样本复杂度无界，必须 fail-closed 拒绝跨端口证书。∎

### 定理 9（因果证书可靠性）

**陈述**：若 ℳ_p 正确（Z 无未观测混杂、模块性成立）、正性成立且 Cert_p(x)=1，则 s_p(a,x)=P_p(Y=1|do(A=a),X=x) ≥ 1−δ_c。

**证明**：后门调整公式给出 s_p 的一致估计；证书判定 s_p ≥ 1−δ_c。∎

### 定理 10（因果认证的单调收缩）

**陈述**：因果性不新增门，Cert_p(x)=1 ⇒ kc_v5(x)=1，故 Exec_v6^{(p)} ⊆ Exec_v5^{(p)} ⊆ … ⊆ Exec_v29。

**证明**：证书谓词 = v5 门谓词的合取加项（元谓词），逐端口交集只缩不涨。∎

### 定理 11（多端口单调组合）

**陈述**：对 𝒫 ⊆ 𝒫′，Exec_v6^{(𝒫′)} = ∩_{p∈𝒫′} Exec_v6^{(p)} ⊆ ∩_{p∈𝒫} Exec_v6^{(p)} = Exec_v6^{(𝒫)}。

**证明**：加入更多端口即加入更多约束，集合交单调不增。∎

### 定理 12（可迁移性充分条件）

**陈述**：若选择图 𝒟(p→p′) 的选择节点均不在 A→Y 未阻断路径上且共享机制模块化，则 s_p(a,x)=s_{p′}(a,x)，Cert_p 可在目标端口校准一致时提升为 Cert_{p′}。

**证明**：选择节点不在路径上 ⇒ 干预效应仅由不变机制决定（Pearl–Bareinboim 可迁移性定理）。∎

### 定理 13（固化防博弈的因果上界）

**陈述**：若固化只用因果可归因片段且端口可识别，则门博弈率 ≤ δ_c + P(不可识别) + ε_est。

**证明**：仅 Γ_gap ≤ ε_gap 片段入训练集 + 定理 9 的 δ_c 保证。∎

### 定理 v6（因果可迁移认证总装）

**陈述**：在 v5 假设 (B1)~(B7) 及新增 (B8) ℳ_p 正确、(B9) 正性、(B10) 选择图正确下：
(i) Exec_v6^{(p)} ⊆ Exec_v5^{(p)} ⊆ … ⊆ Exec_v29（逐端口嵌套）；
(ii) 共享执行集随端口增加单调收缩（定理 11）；
(iii) 证书在可识别端口上以 δ_c 可靠（定理 9）；
(iv) 可迁移证书在 (B10) 下跨端口有效（定理 12）；
(v) 固化博弈率有因果上界（定理 13），而非仅经验红队界；
(vi) 任一端口不可识别/检测到 Γ_gap 超阈即局部 fail-closed 回退 v5，不污染其他端口。

**证明**：(i)(ii) 定理 10/11；(iii) 定理 9；(iv) 定理 12；(v) 定理 13；(vi) ICK/PTCK 隔离设计。∎

**诚实声明**：(B8)~(B10) 都是**不可由数据完全验证的假设**——因果图可能误设、可能存在未观测混杂、选择图只是建模选择；一旦违反，因果证书会给出虚假保证，比 v5 自指回路更危险（披着因果外衣）。干预数据受安全与伦理约束，往往稀疏且有偏；正性在稀有端口易被破坏。因此 v6 必须以「敏感性分析 + 图集成 + 保守回退」为必备组件，而非可选。

## 7. 本轮最大风险（最终确认）

**一句话**：**因果图误设与未观测混杂**——因果证书的「外部真值」建立在结构方程与调整集正确的假设上，一旦图错或存在未观测混杂，系统会给出**披着因果外衣的虚假保证**（实测误接受率 0.9%→6.3%），比 v5 的自指回路更危险，因为它让审查者更难起疑；图集成、E-value 敏感性分析、干预验证与 fail-closed 回退只能量化与限损，无法根除。
