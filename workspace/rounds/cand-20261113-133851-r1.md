# 第 68 轮（承接第 67 轮「SimRAS 仿真增强风险闭环」IP-233~242；灵感循环重启第 1 轮；本轮灵感：「碰撞避免」×「专利布局」）

> SimRAS 解决了「未来风险怎么演化、怎么可解释地审计」，但它对碰撞的处理仍然是**软约束**：`λ_risk` 只是把控制量乘一个系数，世界模型给出的是「大概率安全」的前瞻，而不是「必然不碰」的硬边界。软约束在分布内好用，在分布外（Sim2Real gap、遮挡行人、对抗扰动）恰恰最不可靠——这与第 67 轮自述的最大风险同源：双黑箱给出的「前瞻信心」可能被误当成「安全事实」。
>
> 本轮灵感的核心命题是：
>
> **把「软风险缩放」升级为「硬主张覆盖」：借鉴专利布局的六个机制——独立/从属权利要求、覆盖度、自由实施 FTO、规避设计、专利池、审查/无效——把碰撞避免的安全知识组织成一个可量化覆盖、可被「设计绕过」攻击检验、可在线再审查的「安全主张格（Claim Lattice）」，构成 CLASP（Claim-Lattice Avoidance Safety Portfolio）。**
>
> CLASP 问的不是「风险有多大概率」，而是「**这条轨迹是否落在某条有效安全主张的辖区之内；若不在，谁该让行、该补哪条主张、这次近失该无效掉哪条过宽的主张**」。

## 0. 直觉与动机

**灵感 1（碰撞避免 → 从「避障」到「主张辖区」）**
直觉：经典碰撞避免（势场、VO/ORCA、控制屏障函数 CBF、HJ reach-avoid）都在回答「如何不碰」。但它们给出的安全集合往往是**单一、静态、全域适用**的；真实系统里的安全知识其实是**分片**的：某条 CBF 只在摩擦系数 ≥ `μ_min` 时成立，某个 reach-avoid tube 只在行人速度 ≤ `v_max` 时成立，某个世界模型只在 Sim2Real gap ≤ `δ_sim` 时可信。把带前提的安全知识当成**权利要求**，系统就不再假装存在一个全域安全集合，而是显式管理「哪片辖区、在什么前提下、归哪条主张管」。这一步把「碰撞避免」从一个控制问题，变成一个**知识组织 + 辖区治理**问题。

**灵感 2（专利布局 → 独立/从属权利要求 = 宽/窄安全主张）**
直觉：独立权利要求宽，但容易被现有技术无效；从属权利要求窄，但抗无效。安全主张同理：
- **独立主张**：`S_c` 大、前提强（如「全场无障碍且感知完好 ⇒ 前向不变」），覆盖广，但一被近失证据证伪就失效；
- **从属主张**：`S_c` 小、前提弱（如「仅当前 2m、低速、单行人」），覆盖窄，但鲁棒。
专利布局从不追求「一条超宽专利」，而追求**一张有层次的 claim lattice**：宽主张圈地，窄主张兜底，彼此有依赖与继承。CLASP 的安全性正来自这种层次，而不是任何单条主张——这与 SimRAS 把安全押在单一世界模型上形成鲜明对照。

**灵感 3（自由实施 FTO → 运行时「不侵权」检查）**
直觉：专利 FTO 是「实施前先确认不落入他人有效权利要求」。碰撞避免的 FTO 是：**执行一个动作块之前，先确认其整条预测轨迹都落在某条有效安全主张的辖区内**（且留足边界余量）。若某一步落到所有主张之外（进入 gap/空白区），就是「侵权」——必须让行、改道、请求授权（减速/停下/重规划），而不是硬执行。这把 SimRAS 的「审计建议」变成**执行前的硬门禁**：不是「建议你小心」，而是「这一步没有辖区，禁止通行」。

**灵感 4（规避设计 → 主张缺口攻击与安全红队）**
直觉：任何有限专利组合都能被「设计绕过」；任何有限安全主张族也一定有**未被覆盖的缺口**。与其假设缺口不存在，不如**主动构造绕过**：DAA（Design-Around Adversary）在扰动预算内搜索一条「从主张缝隙穿过去、却仍骗过监视器」的轨迹，作为安全红队。若找得到，就暴露了一个 gap；补一条从属主张（收窄 `S` 或放松前提）把它堵上；若已无预算可补，就把它写进 `J_CLASP` 的残余风险。这把「设计绕过」从威胁变成**主张生长的驱动力**。

**灵感 5（专利池 + 审查/无效 → 多体互惠避碰 + 再认证）**
直觉：多机/人机共存时，各自的主张可能**冲突**（都声称自己优先通过）或**都不覆盖交叉区**。专利池的「交叉许可」对应**互惠避碰**：各智能体公开自己的公共主张，按优先权（紧迫度/主张新鲜度/路权）协商谁让行；若交叉区无主张覆盖，双方共同「补一条联合主张」。而审查/无效对应**再认证**：一次近失（prior art）可以证伪某条宽主张，系统随即「无效」它并「续案」出更窄的子主张，保证覆盖不下降。这是对第 67 轮「离线审计缓冲」的在线化、可诉讼化升级。

**灵感 6（六机制合流 → CLASP）**
CLASP 在 SimRAS 之上加一层硬安全壳：
1. **CLC Claim Lattice Constructor**：把 CBF / reach-avoid / WM 证书编译成带前提的安全主张，排成格；
2. **CGA Coverage-Gap Analyzer**：在估计可达集上算覆盖度 `κ_cov` 与缺口测度 `γ`；
3. **FTO-RC Freedom-to-Operate Runtime Checker**：执行前逐块检查「是否落入有效辖区 + 边界余量」；
4. **DAA Design-Around Adversary**：红队式设计绕过，暴露并封堵缺口；
5. **CPR Claim-Pool Reciprocal avoidance**：多体主张池 + 路权仲裁 + 死锁消解；
6. **RCP Recertification / Prosecution**：近失日志作为 prior art，在线无效/续案与覆盖单调再认证。

**灵感 7（SimRAS 组件的专利化升级）**
- `λ_risk` → `FTO`：软缩放变成硬门禁，λ 只保留为「辖区内的风险排序」，不再承担安全责任；
- `VQAuditor` → `DAA`：从「解释过去」变成「攻击未来」，审计对象由「轨迹合理性」变为「主张缺口可穿越性」；
- `AuditBuf` → `PriorArtBuf`：审计报告变成可证伪的 prior art，直接驱动「无效宣告」；
- `k*RAS` → `k_FTO`：认证前缀不仅要满足风险缩放，还要满足「每一步都有有效辖区覆盖」；
- `J_SimRAS` → `J_CLASP`：证书增 `claim_lattice_hash`、`kappa_cov`、`fto_flag`、`gamma_gap`、`designaround_robustness`、`pool_priority`。

## 1. 形式化定义（增量：定义 276–290）

- **定义 276（CLASP 总览）**：`CLASP = (CLC, CGA, FTO-RC, DAA, CPR, RCP)`。定位：在 SimRAS 的「预测-审计」之上，提供**执行前的硬碰撞避免契约**。不变式：CLC/CGA/DAA/RCP 只在语义流与离线流运行；实时流只做「主张查表 + FTO 逐点判定 + 早停」，零学习写操作。
- **定义 277（安全主张）**：一条安全主张是七元组 `c = (S_c, b_c, V_c, A_c, Δ_c, p_c, t_c)`：`S_c ⊆ 𝒳` 为经认证的安全状态集；`b_c: 𝒳 → ℝ` 为控制屏障函数，`x ∈ S_c ⇔ b_c(x) ≥ 0`；`V_c: Context → {0,1}` 为外部前提（摩擦、光照、行人速度、感知质量等）；`A_c` 为模型假设集（继承 SimRAS 的 `ε_wm, δ_sim` 等）；`Δ_c` 为可复现证书对象（SOS / 区间可达管 / 哈希）；`p_c ∈ ℕ` 为优先权（越新鲜/越紧迫越高）；`t_c` 为认证时刻。
- **定义 278（主张格）**：`(C, ⪯)` 为偏序集，`c ⪯ c'` 当且仅当 `S_{c'} ⊆ S_c`、`V_{c'} ⇒ V_c`、`A_{c'} ⊇ A_c`。含义：`c'` 是 `c` 的**从属主张/细化**（辖区更小、前提更弱、更抗无效）。`c ∨ c'` 为覆盖并（更宽的独立主张），`c ∧ c'` 为辖区交（联合主张）。格上无全域 `⊤` 的自动有效性——`⊤` 允许存在，但其 `V_⊤` 通常一验即伪。
- **定义 279（主张有效性）**：`val(c, t) = V_c(ctx_t) ∧ A_c 成立 ∧ ¬invalidated_c(t)`。当前有效辖区 `Σ_t = ⋃_{c: val(c,t)} S_c`。**关键**：有效性是时变的；主张不是「注册即永恒」，而是「持续举证」。
- **定义 280（覆盖度与缺口）**：对估计可达集 `ℛ_t`，`κ_cov(t) = μ(ℛ_t ∩ Σ_t) / μ(ℛ_t)`，缺口测度 `γ(t) = 1 - κ_cov(t) = μ(ℛ_t ∩ G_t)/μ(ℛ_t)`，其中 `G_t = 𝒳 \ Σ_t` 为**主张缺口**（未申领辖区）。`κ_cov` 是 CLASP 的「安全覆盖率」，不是「成功率」。
- **定义 281（自由实施 FTO）**：对预测块 `x̂_{t+1:t+k}`，`FTO(t,k) = True` 当且仅当 `∀i∈[1,k]`：`x̂_{t+i} ∈ Σ_{t+i}` 且 `dist(x̂_{t+i}, ∂Σ_{t+i}) ≥ m_fto`。`m_fto` 为边界余量。FTO 失败即「落入未申领区/贴边」，必须触发重规划或让行。
- **定义 282（缺口评分）**：`gap(x,t) = dist(x, Σ_t)`（在辖区内为 0）。用于规划器把「向缺口靠近」当作成本，而非只在越界后急停。
- **定义 283（设计绕过攻击）**：给定扰动预算 `‖δ‖ ≤ ε_a` 与检测器 `D_θ`，攻击成功当且仅当轨迹 `x^δ` 在某步进入 `G_t` 且 `D_θ(x^δ) < τ_det`。脆弱性 `Vuln(C, ε_a) = sup_δ [1{成功}·(1 - D_θ(x^δ))]`。
- **定义 284（规避鲁棒性）**：主张族 `C` 是 `(ε_a, p)`-robust，若 `Vuln(C, ε_a) ≤ p`。`p` 是「可被设计绕过的残余概率」，必须写进证书，而不是被宣称不存在。
- **定义 285（主张池与路权）**：多智能体 `{1..N}` 各自公开主张 `C_i^pub`；路权序 `≺_ro` 按 `p_c`（紧迫度）、`t_c`（新鲜度）、任务权重排序。若 `i` 的意图进入 `j` 的辖区保护域，则 `i` 需获得 `j` 的交叉许可（`j` 承诺让行/保持辖区），否则 `i` 必须改道。
- **定义 286（主张丛林与冻结）**：若某时刻对所有候选块都 `FTO = False`，称系统进入**主张丛林冻结（thicket freeze）**。冻结时长超过 `τ_freeze` 即视为一种新的失效模式（过度保守），与碰撞同级记账。
- **定义 287（再审查 / 无效 / 续案）**：prior art 集 `P_t` 记录近失与反例。主张 `c` 被**无效宣告**当且仅当 `ν_c(P_t) > δ_c`（经验违背率超阈）。无效后由**收窄算子** `N(c) = {c_1',...,c_m'}` 生成从属主张，满足 `c_j' ⪯ c`，且 `S_{c_j'}` 覆盖 `S_c` 中未被证伪的部分。
- **定义 288（覆盖单调再认证）**：一次再审查是可接受的，当且仅当 `κ_cov(C_new) ≥ κ_cov(C_old) - ε_cov` 且 `Vuln(C_new) ≤ Vuln(C_old)`。否则拒绝该次修订——防止「越改越不安全」。
- **定义 289（主张引导规划）**：`min_{a_{1:k}} J = E[collision] + λ_g·γ_{t+k} + λ_f·1{freeze} + λ_u·‖a‖²`，约束 `FTO(t,k) = True`。规划器在「辖区内部」优化风险排序，而不是在「辖区外部」赌概率。
- **定义 290（J_CLASP 证书）**：`J_CLASP = (J_SimRAS, claim_lattice_hash, κ_cov, γ_gap, fto_flag, designaround_robustness, pool_priority_seq)`。`Valid ⇔ Valid(J_SimRAS) ∧ fto_flag ∧ κ_cov ≥ 1-γ_max ∧ Vuln ≤ p_max`。

```python
# CLC：把 CBF / reach-avoid / WM 证书编译成主张，并插入格
class SafetyClaim:
    def __init__(self, S, barrier, validity, assumptions, cert, priority, t):
        self.S, self.b, self.V, self.A = S, barrier, validity, assumptions
        self.cert, self.p, self.t = cert, priority, t
        self.invalid = False

    def valid(self, ctx, t):
        return self.V(ctx) and self.A.hold() and not self.invalid

    def contains(self, x, margin=0.0):
        return self.b(x) >= margin


class ClaimLattice:
    def __init__(self):
        self.claims = []

    def add(self, c):
        # 仅维护偏序索引；真正的几何判定交给 S_c.contains / 空间哈希
        self.claims.append(c)

    def valid_claims(self, ctx, t):
        return [c for c in self.claims if c.valid(ctx, t)]

    def covers(self, x, ctx, t, margin=0.0):
        return [c for c in self.valid_claims(ctx, t) if c.contains(x, margin)]

    def sigma(self, ctx, t):
        return lambda x: bool(self.covers(x, ctx, t))

    def gap_distance(self, x, ctx, t):
        cs = self.covers(x, ctx, t)
        if cs:
            return 0.0
        # 到最近辖区边界的近似：用 b_c 的最大值做代理
        return max(0.0, -max((c.b(x) for c in self.valid_claims(ctx, t)),
                             default=-1e9))


# CGA：覆盖度与缺口
class CoverageGapAnalyzer:
    def analyze(self, reach_samples, lattice, ctx, t):
        sigma = lattice.sigma(ctx, t)
        covered = [x for x in reach_samples if sigma(x)]
        gaps = [x for x in reach_samples if not sigma(x)]
        kappa = len(covered) / max(1, len(reach_samples))
        return {'kappa_cov': kappa, 'gamma': 1 - kappa,
                'gap_clusters': cluster(gaps),
                'reach_n': len(reach_samples)}


# FTO-RC：执行前硬门禁
class FTORuntimeChecker:
    def __init__(self, m_fto=0.15):
        self.m_fto = m_fto

    def check(self, xhat_seq, lattice, ctx, t):
        for i, x in enumerate(xhat_seq):
            cs = lattice.covers(x, ctx, t + i)
            if not cs:
                return False, ('gap', i, x)
            if max(c.contains(x, self.m_fto) for c in cs) is False:
                return False, ('margin', i, x)
        return True, None


# DAA：设计绕过红队（离线/低优先级在线）
class DesignAroundAdversary:
    def __init__(self, eps_a=0.1, horizon=5):
        self.eps_a, self.horizon = eps_a, horizon

    def attack(self, lattice, policy, x0, ctx, t, detector):
        # 在 ||δ||<=eps_a 内做投影梯度/交叉熵，最大化 gap 进入且 D_θ 低于阈值
        best = None
        for delta in sample_perturbations(x0, self.eps_a, n=256):
            traj = rollout_with_perturbation(policy, x0, delta, self.horizon)
            if any(lattice.gap_distance(x, ctx, t + i) > 0
                   for i, x in enumerate(traj)):
                score = 1 - detector(traj)
                if best is None or score > best[0]:
                    best = (score, delta, traj)
        return {'success': best is not None and best[0] > 0.5,
                'delta': None if best is None else best[1],
                'traj': None if best is None else best[2],
                'vuln_hat': 0.0 if best is None else best[0]}


# CPR：主张池 + 路权 + 死锁消解
class ClaimPool:
    def __init__(self):
        self.public = {}     # agent_id -> public claims

    def negotiate(self, agents, ctx, t, freeze_time):
        order = sorted(agents, key=lambda a: (a.priority, a.t), reverse=True)
        grants = {}
        for i, a in enumerate(order):
            for j in order[:i]:
                inter = intersect(a.intent_tube, self.public[j].protected)
                if inter and not self.cross_licensed(j, a, inter):
                    grants[a.id] = 'yield_to_' + j.id
                    break
        if all(g is not None for g in grants.values()) and len(grants) == len(agents):
            # 全体让行 → 死锁，按优先权强制最高者通行
            grants[order[0].id] = 'force_pass'
        return grants

    def cross_licensed(self, j, a, region):
        # 联合主张覆盖交叉区才视为许可
        return any(c.contains_all(region) for c in self.public[j].joint_claims)


# RCP：再审查（近似专利审查：无效 + 续案）
class Recertifier:
    def __init__(self, delta_c=0.05, eps_cov=0.02):
        self.delta_c, self.eps_cov = delta_c, eps_cov

    def prosecute(self, lattice, prior_art, ctx, t):
        old_kappa = estimate_coverage(lattice)
        for c in list(lattice.claims):
            if violation_rate(c, prior_art) > self.delta_c:
                c.invalid = True
                children = narrow(c, prior_art)   # 收窄 S / 放松 V / 拆子管辖
                for child in children:
                    lattice.add(child)
        new_kappa = estimate_coverage(lattice)
        if new_kappa < old_kappa - self.eps_cov:
            raise CoverageRegression('拒绝修订：覆盖度回退')
        return new_kappa


# 在线闭环：SimRAS 预测 → CLASP 硬门禁 → 执行 → 再审查
def CLASP_round(M, obs):
    sim = M.simras.step(obs)                 # 复用第 67 轮
    xhat, act, ctx, t = sim['xhat'], sim['A'], sim['ctx'], sim['t']

    # 1) 覆盖度体检（语义流，低频）
    cov = M.cga.analyze(M.reachable.sample(xhat, n=512), M.lattice, ctx, t)

    # 2) FTO 硬门禁
    ok, why = M.fto.check(xhat[:M.k], M.lattice, ctx, t)
    if not ok:
        # 2a) 先重规划到辖区内部（最大化 gap 距离）
        alt = M.cgp.replan_into_claims(xhat, M.lattice, ctx, t)
        ok, why = M.fto.check(alt[:M.k], M.lattice, ctx, t)
        if not ok:
            # 2b) 多体：尝试主张池让行 / 请求交叉许可
            if M.multi_agent:
                grant = M.pool.negotiate(M.agents, ctx, t, M.freeze_time)
                if grant.get(M.self_id) in ('force_pass',) or \
                   str(grant.get(M.self_id)).startswith('yield'):
                    alt = M.cgp.replan_into_claims(xhat, M.lattice, ctx, t)
                    ok, why = M.fto.check(alt[:M.k], M.lattice, ctx, t)
            if not ok:
                return M.safe_stop(reason=why)   # 无辖区，禁止通行

    # 3) 执行并采集近失作为 prior art
    outcome = M.execute(alt if not ok else xhat)
    M.prior_art.add(outcome, ctx, t)

    # 4) 异步再审查（无效 + 续案），不阻塞实时环
    M.recertifier.submit_async(M.lattice, M.prior_art, ctx, t)

    # 5) 低频红队：设计绕过攻当前主张族
    M.daa.submit_async(M.lattice, M.policy, xhat[0], ctx, t, M.detector)

    return {'k_fto': M.k if ok else 0, 'kappa_cov': cov['kappa_cov'],
            'fto_flag': ok, 'why': why, 'gap_clusters': cov['gap_clusters']}
```

## 3. 推导

**引理 13（主张可靠性 ⇒ 前向不变）** 若 `b_c` 是策略 `π_c` 在 `S_c` 上合法的控制屏障函数，且 `val(c,t)` 在 `[t,t+T]` 内保持为真，则 `x_t ∈ S_c ⇒ ∀i≤T, x_{t+i} ∈ S_c`。证明要点：离散时间下 `b_c(x_{t+1}) ≥ (1 - αΔt)·b_c(x_t)`，故 `b_c ≥ 0` 在 `S_c` 内封闭；`V_c` 持续为真保证 `π_c` 的前提不被破坏。

**引理 14（覆盖-碰撞界）** 设每个时刻主张有效性以概率 `≥ 1-δ_v` 成立、证书可靠性误差为 `δ_cert`、WM 预测误差为 `ε_wm`，则 `T` 步内碰撞概率满足
`P(collision) ≤ γ(t) + T·(δ_v + δ_cert + ε_wm / ρ_safe)`。
直觉：碰撞只有两种来路——(a) 轨迹落进未申领的 gap（概率 ≤ γ），或 (b) 某条「看似有效」的主张实际失效（每步概率 `δ_v+δ_cert+ε_wm/ρ_safe` 的并集界）。这与第 67 轮的软 `λ_risk` 不同：那里没有「gap」概念，只有「风险大小」。

**引理 15（细化-冻结权衡）** 对 `c' ⪯ c`，`S_{c'} ⊆ S_c`，故单纯细化会**降低**原始覆盖度，但若父主张已被 prior art 证伪，则父主张的「名义覆盖」本就无效；替换为子主张后**有效覆盖**反而上升。另一方面，主张数 `|C|` 增大时，任一动作块「同时落入所有相关主张的冲突域」的概率上升，冻结概率下界约为 `1 - exp(-|C|·η)`（`η` 为平均冲突率）。因此存在一个最优粒度 `|C|*`：太粗则有 gap，太细则 frozen。

**定理 14（FTO 可靠性）** 在引理 13、14 与 WM 误差界下，若 `FTO(t,k)=True`，且碰撞集 `𝒳_coll` 与 `Σ_t` 不相交，则执行前缀 `x_{t+1:t+k}` 在 `[t,t+k]` 内无碰撞，概率至少 `1 - k(δ_v+δ_cert+ε_wm/ρ_safe)`。逆否形式更锋利：**任何碰撞都必然对应一次 gap 进入或一次主张失效**——碰撞不再是「运气不好」，而是可归因的**辖区漏洞**。

**定理 15（设计绕过下界 / 无完备主张族）** 设可达集 `ℛ` 的覆盖维数为 `d`、单条主张辖区半径至多 `r`、`ℛ` 直径为 `D`。则覆盖 `ℛ` 至少需要 `N ≥ c·(D/r)^d` 条主张；等价地，任意 `N` 条主张族的缺口测度满足
`γ_min ≥ 1 - N·(r/D)^d`（忽略重叠的更松界）。
特别地，`(ε_a,p)`-robust 要求 `N ≥ (D/r)^d·log(1/p)`。**结论**：有限主张族不可能达到 `γ=0`；任何声称「绝对碰撞免疫」的证书都是伪造的。CLASP 的诚实承诺只能是「`γ ≤ γ_max` 且 `Vuln ≤ p_max`」。

**定理 16（主张池死锁消解）** 若路权 `≺_ro` 是全序且公开主张的交叉判定是确定的，则 CPR 协商在至多 `N` 轮内终止；若全体让行，强制最高优先权者通行，可在 `O(N log N)` 内解除冻结。无全序（同优先级）时死锁概率上界为 `N·2^{-b}`（`b` 为优先权分辨率位数）。

**定理 17（再认证的覆盖单调收敛）** 在平稳环境下，若违背率估计以 `N_audit` 样本达到 `(ε,δ)` 精度，则每轮再审查以概率 `≥1-δ` 满足覆盖单调（定义 288），且 `κ_cov` 收敛到该主张族的最优有效覆盖；样本复杂度 `N_audit = O((1/ε²)log(|C|/δ))`。在非平稳漂移率 `ρ_drift` 下，覆盖度衰减速度上界为 `ρ_drift·τ_recert`（`τ_recert` 为再审查时延），因此**再审查必须快于环境漂移**。

## 2. 形式化定义（完整版）

**定义 276（CLASP 总览）** CLASP 是在 SimRAS 之上增加的一层**执行前硬安全壳**：
```
CLASP = (CLC, CGA, FTO-RC, DAA, CPR, RCP)
```
不变式：`CLC/CGA/DAA/RCP` 仅在语义流与离线流运行；实时流只做「主张查表 + FTO 逐点判定 + 覆盖度早停」，零学习写操作。`λ_risk` 被降级为「辖区内的风险排序权重」，不再承担安全兜底职责。

**定义 277（安全主张）** 一条安全主张是七元组：
```
c = (S_c, b_c, V_c, A_c, Δ_c, p_c, t_c)
```
其中 `S_c ⊆ 𝒳` 为经认证的安全状态集；`b_c: 𝒳→ℝ` 为控制屏障函数，`x ∈ S_c ⇔ b_c(x) ≥ 0`；`V_c` 为外部前提谓词；`A_c` 为模型假设集（继承 `ε_wm, δ_sim`）；`Δ_c` 为可复现证书（SOS / 区间可达管 / 哈希）；`p_c` 为优先权；`t_c` 为认证时刻。

**定义 278（主张格）** 偏序 `(C, ⪯)`：
```
c ⪯ c'  ⇔  S_{c'} ⊆ S_c  ∧  (V_{c'} ⇒ V_c)  ∧  A_{c'} ⊇ A_c
```
`c'` 是 `c` 的从属主张：辖区更小、前提更弱、更抗无效。`c ∨ c'` 为覆盖并（更宽的独立主张），`c ∧ c'` 为辖区交（联合主张）。允许存在全域 `⊤`，但其前提 `V_⊤` 通常一验即伪——这正是「超宽专利必被无效」的安全类比。

**定义 279（主张有效性）**
```
val(c,t) = V_c(ctx_t) ∧ A_c.hold() ∧ ¬invalidated_c(t)
Σ_t = ⋃_{c: val(c,t)} S_c
```
主张不是「注册即永恒」，而是「持续举证」。任一条前提被观测证伪，该主张立即退出辖区并集。

**定义 280（覆盖度与缺口）**
```
κ_cov(t) = μ(ℛ_t ∩ Σ_t) / μ(ℛ_t)
γ(t) = 1 - κ_cov(t) = μ(ℛ_t ∩ G_t) / μ(ℛ_t),   G_t = 𝒳 \ Σ_t
```
`ℛ_t` 是当前估计可达集。`κ_cov` 是「安全覆盖率」，不是「任务成功率」；两者必须分别报告，防止用成功率掩盖覆盖漏洞。

**定义 281（自由实施 FTO）**
```
FTO(t,k) = True  ⇔  ∀i∈[1,k]:
    x̂_{t+i} ∈ Σ_{t+i}  ∧  dist(x̂_{t+i}, ∂Σ_{t+i}) ≥ m_fto
```
失败即「落入未申领区或贴边」，触发重规划 / 让行 / 安全停车。这是 CLASP 与 SimRAS 的分水岭：SimRAS 给建议，CLASP 给通行证。

**定义 282（缺口评分）** `gap(x,t) = dist(x, Σ_t)`。规划器把 `gap` 当作一阶成本，使智能体「未越界就先远离缺口」，而不是越界后急停。

**定义 283（设计绕过攻击）** 扰动预算 `‖δ‖ ≤ ε_a`，检测器 `D_θ`：
```
success(δ) = 1{ ∃i: x^δ_{t+i} ∈ G_{t+i} } · 1{ D_θ(x^δ) < τ_det }
Vuln(C, ε_a) = sup_{‖δ‖≤ε_a} success(δ)·(1 - D_θ(x^δ))
```

**定义 284（规避鲁棒性）** 主张族 `C` 为 `(ε_a, p)`-robust，若 `Vuln(C, ε_a) ≤ p`。`p` 是必须写入证书的**残余可绕过概率**；宣称 `p=0` 等价于宣称有限主张族完备（定理 15 直接否定）。

**定义 285（主张池与路权）** 多智能体各自公开 `C_i^pub`。路权序：
```
≺_ro = lexicographic( p_c(紧迫度), -t_c(新鲜度), w_task )
```
若 `i` 的意图进入 `j` 的保护域，需 `j` 的交叉许可（联合主张覆盖交叉区），否则 `i` 让行。

**定义 286（主张丛林与冻结）** 若某时刻对所有候选块 `FTO=False`，称**主张丛林冻结**。冻结时长超过 `τ_freeze` 记为失效事件，与碰撞同级记账——**过度保守也是不安全**（任务失败、阻塞他人）。

**定义 287（再审查 / 无效 / 续案）** prior art `P_t` 记录近失与反例。无效宣告：
```
invalidated_c(t) = True  ⇔  ν_c(P_t) > δ_c
```
收窄算子 `N(c) = {c_1',...,c_m'}`，满足 `c_j' ⪯ c`，且 `∪_j S_{c_j'}` 覆盖 `S_c` 中未被证伪的部分。

**定义 288（覆盖单调再认证）** 一次修订可接受当且仅当：
```
κ_cov(C_new) ≥ κ_cov(C_old) - ε_cov  ∧  Vuln(C_new) ≤ Vuln(C_old)
```
防止「越改越安全」的幻觉——每一次无效/续案都必须用同一把覆盖度尺子复核。

**定义 289（主张引导规划）**
```
min_{a_{1:k}} J = E[collision] + λ_g·γ_{t+k} + λ_f·1{freeze} + λ_u·‖a‖²
s.t.  FTO(t,k) = True
```

**定义 290（J_CLASP 证书）**
```
J_CLASP = (J_SimRAS, claim_lattice_hash, κ_cov, γ_gap,
           fto_flag, designaround_robustness, pool_priority_seq)
Valid ⇔ Valid(J_SimRAS) ∧ fto_flag
        ∧ κ_cov ≥ 1 - γ_max ∧ Vuln ≤ p_max
```
证书是「可诉讼」的：任何一次碰撞都应能反查到「当时哪条主张声称覆盖了它、该主张为何失效」。

```python
# IP-243 CLC：安全主张与主张格
class SafetyClaim:
    def __init__(self, S, barrier, validity, assumptions, cert, priority, t):
        self.S, self.b, self.V, self.A = S, barrier, validity, assumptions
        self.cert, self.p, self.t = cert, priority, t
        self.invalid = False

    def valid(self, ctx, t):
        return self.V(ctx) and self.A.hold() and not self.invalid

    def contains(self, x, margin=0.0):
        return self.b(x) >= margin


class ClaimLattice:
    def __init__(self):
        self.claims, self.index = [], None

    def add(self, c):
        self.claims.append(c)
        for d in self.claims:            # 维护偏序（离线，可批处理）
            if c.S.subset(d.S) and c.V.implies(d.V):
                c.parents = getattr(c, 'parents', []) + [d]
            if d.S.subset(c.S) and d.V.implies(c.V):
                d.parents = getattr(d, 'parents', []) + [c]

    def valid_claims(self, ctx, t):
        return [c for c in self.claims if c.valid(ctx, t)]

    def covers(self, x, ctx, t, margin=0.0):
        return [c for c in self.valid_claims(ctx, t) if c.contains(x, margin)]

    def gap_distance(self, x, ctx, t):
        if self.covers(x, ctx, t):
            return 0.0
        return max(0.0, -max((c.b(x) for c in self.valid_claims(ctx, t)),
                             default=-1e9))


# IP-244 CGA：覆盖度-缺口分析
class CoverageGapAnalyzer:
    def analyze(self, reach_samples, lattice, ctx, t):
        covered = [x for x in reach_samples if lattice.covers(x, ctx, t)]
        gaps = [x for x in reach_samples if not lattice.covers(x, ctx, t)]
        kappa = len(covered) / max(1, len(reach_samples))
        return {'kappa_cov': kappa, 'gamma': 1 - kappa,
                'gap_clusters': cluster(gaps), 'reach_n': len(reach_samples)}


# IP-245 FTO-RC：执行前硬门禁
class FTORuntimeChecker:
    def __init__(self, m_fto=0.15, k_max=5):
        self.m_fto, self.k_max = m_fto, k_max

    def check(self, xhat_seq, lattice, ctx, t):
        for i, x in enumerate(xhat_seq):
            cs = lattice.covers(x, ctx, t + i)
            if not cs:
                return False, ('gap', i, x)
            if max(c.b(x) for c in cs) < self.m_fto:
                return False, ('margin', i, x)
        return True, None


# IP-246 DAA：设计绕过红队
class DesignAroundAdversary:
    def attack(self, lattice, policy, x0, ctx, t, detector,
               eps_a=0.1, horizon=5, n=256):
        best = None
        for delta in sample_perturbations(x0, eps_a, n):
            traj = rollout_with_perturbation(policy, x0, delta, horizon)
            if any(lattice.gap_distance(x, ctx, t + i) > 0
                   for i, x in enumerate(traj)):
                score = 1 - detector(traj)
                if best is None or score > best[0]:
                    best = (score, delta, traj)
        return {'success': best is not None and best[0] > 0.5,
                'delta': None if best is None else best[1],
                'traj': None if best is None else best[2],
                'vuln_hat': 0.0 if best is None else best[0]}


# IP-247 CPR：主张池 + 路权 + 死锁消解
class ClaimPool:
    def negotiate(self, agents, ctx, t):
        order = sorted(agents, key=lambda a: (a.priority, -a.t), reverse=True)
        grants, yielded = {}, set()
        for i, a in enumerate(order):
            for j in order[:i]:
                if intersects(a.intent_tube, self.public[j].protected) and \
                   not self.cross_licensed(j, a):
                    grants[a.id] = f'yield_to_{j.id}'; yielded.add(a.id); break
        if len(yielded) == len(agents):          # 全体让行 = 死锁
            grants[order[0].id] = 'force_pass'   # 优先权最高者强制通行
        return grants

    def cross_licensed(self, j, a):
        return any(c.contains_all(a.intent_tube)
                   for c in self.public[j].joint_claims)


# IP-248 RCP：再审查（无效 + 续案）
class Recertifier:
    def __init__(self, delta_c=0.05, eps_cov=0.02):
        self.delta_c, self.eps_cov = delta_c, eps_cov

    def prosecute(self, lattice, prior_art, ctx, t):
        old_kappa = estimate_coverage(lattice, ctx, t)
        for c in list(lattice.claims):
            if violation_rate(c, prior_art) > self.delta_c:
                c.invalid = True
                for child in narrow(c, prior_art):   # 收窄 S / 放松 V / 拆子管辖
                    lattice.add(child)
        new_kappa = estimate_coverage(lattice, ctx, t)
        if new_kappa < old_kappa - self.eps_cov:
            raise CoverageRegression('拒绝修订：覆盖度回退')
        return new_kappa


# IP-252 CLASP 在线闭环
def CLASP_round(M, obs):
    sim = M.simras.step(obs)                 # 复用第 67 轮 SimRAS
    xhat, ctx, t = sim['xhat'], sim['ctx'], sim['t']

    cov = M.cga.analyze(M.reachable.sample(xhat, n=512), M.lattice, ctx, t)
    ok, why = M.fto.check(xhat[:M.k], M.lattice, ctx, t)

    if not ok:
        alt = M.cgp.replan_into_claims(xhat, M.lattice, ctx, t)
        ok, why = M.fto.check(alt[:M.k], M.lattice, ctx, t)
        if not ok and M.multi_agent:
            grant = M.pool.negotiate(M.agents, ctx, t)
            if grant.get(M.self_id) == 'force_pass':
                alt = M.cgp.replan_into_claims(xhat, M.lattice, ctx, t)
                ok, why = M.fto.check(alt[:M.k], M.lattice, ctx, t)
        if not ok:
            return M.safe_stop(reason=why)

    outcome = M.execute(alt if not ok else xhat)
    M.prior_art.add(outcome, ctx, t)
    M.recertifier.submit_async(M.lattice, M.prior_art, ctx, t)
    M.daa.submit_async(M.lattice, M.policy, xhat[0], ctx, t, M.detector)

    return {'fto_flag': ok, 'why': why,
            'kappa_cov': cov['kappa_cov'], 'gap_clusters': cov['gap_clusters']}
```

## 4. 推导

**引理 13（主张可靠性 ⇒ 前向不变）** 若 `b_c` 是 `π_c` 在 `S_c` 上的合法 CBF，且 `val(c,t)` 在 `[t,t+T]` 内为真，则 `x_t∈S_c ⇒ ∀i≤T, x_{t+i}∈S_c`。

**引理 14（覆盖-碰撞界）** 设主张有效性每步以概率 `≥1-δ_v` 成立、证书误差 `δ_cert`、WM 误差 `ε_wm`、安全裕度 `ρ_safe`，则
```
P(collision in T) ≤ γ(t) + T·(δ_v + δ_cert + ε_wm/ρ_safe)
```
碰撞只可能来自「gap 进入」或「主张失效」；这是比 SimRAS 的软 `λ_risk` 更可归因的分解。

**引理 15（细化-冻结权衡）** 细化 `c'⪯c` 使 `S_{c'}⊆S_c`，原始覆盖下降；但若 `c` 已被 prior art 证伪，其名义覆盖本无效，替换后**有效覆盖**上升。主张数增大时冻结概率约 `1-exp(-|C|·η)`，故存在最优粒度 `|C|*`：太粗有 gap，太细 frozen。

**定理 14（FTO 可靠性）** 在引理 13/14 与 WM 误差界下，若 `FTO(t,k)=True` 且 `𝒳_coll ∩ Σ_t = ∅`，则执行前缀无碰撞，概率 `≥1 - k(δ_v+δ_cert+ε_wm/ρ_safe)`。逆否形式：**任何碰撞必对应一次 gap 进入或一次主张失效**——碰撞从「运气」变成「可审计的辖区漏洞」。

**定理 15（设计绕过下界 / 无完备主张族）** 设 `ℛ` 覆盖维数 `d`、单主张辖区半径 `≤r`、直径 `D`，则覆盖 `ℛ` 至少需
```
N ≥ c·(D/r)^d
```
任意 `N` 条主张族的缺口满足 `γ_min ≥ 1 - N·(r/D)^d`；`(ε_a,p)`-robust 需 `N ≥ (D/r)^d·log(1/p)`。**故 `γ=0` 不可达，CLASP 只能承诺 `γ≤γ_max ∧ Vuln≤p_max`。**

**定理 16（主张池死锁消解）** 路权全序 + 确定性交叉判定下，CPR 在 `≤N` 轮终止；全体让行时强制最高优先权者通行，`O(N log N)` 解除冻结；同优先级死锁概率 `≤N·2^{-b}`。

**定理 17（再认证覆盖单调收敛）** 平稳环境下，若违背率估计以 `N_audit` 样本达 `(ε,δ)` 精度，则每轮再审查以 `≥1-δ` 满足覆盖单调，`κ_cov` 收敛到最优有效覆盖；`N_audit = O((1/ε²)log(|C|/δ))`。非平稳漂移率 `ρ_drift` 下覆盖衰减上界 `ρ_drift·τ_recert`，故**再审查必须快于环境漂移**。

## 7. 权利要求树与 prior-art 自我审查（灵感的内化）

> 「专利布局」不仅提供隐喻，也要求本轮对自己做一次 novelty/FTO 检查，避免把已有思想当创新点。

**独立主张（本轮核心）**
- **C1**：一种基于**安全主张格**的碰撞避免方法：将带前提的 CBF/reach-avoid 证书编译为可偏序化的主张，并以「主张并集」而非「单一安全集」定义安全辖区。
- **C2**：一种**运行时自由实施（FTO）门禁**：执行动作块前逐点验证预测轨迹落入有效主张辖区且保留边界余量，未覆盖则禁止通行。
- **C3**：一种**主张缺口红队**：在扰动预算内搜索穿越主张缝隙且规避检测的轨迹，并以搜索结果驱动主张收窄。

**从属主张（细化）**
- C1-a：主张七元组中含 `V_c` 前提谓词与 `A_c` 模型假设，使「有效性」时变；
- C1-b：从属主张由 prior art 触发续案生成，且满足覆盖单调约束；
- C2-a：FTO 失败时按路权序进行主张池协商/交叉许可；
- C2-b：冻结超时与碰撞同级记账；
- C3-a：红队结果写入 `J_CLASP` 的 `designaround_robustness` 字段。

**与 prior art 的差异**

| 已有工作/既往轮次 | 已有内容 | CLASP 的新增边界 |
|---|---|---|
| CBF / HJ reachability | 单一安全集与不变性证明 | 把「带前提的安全知识」组织为可无效/可续案的主张格，并量化覆盖缺口 |
| VO / ORCA / 互惠避碰 | 速度障碍与对称让行 | 用公开主张 + 路权优先序 + 交叉许可替代速度障碍；死锁有强制通行定理 |
| 第 64 轮 CAPO | 能力声明的覆盖/冗余/空白 | CAPO 管「模块是否该保留」，CLASP 管「状态空间是否被安全证书覆盖」；对象与失效模式不同 |
| 第 61 轮 PTA | ROS 权项冲突仲裁 | PTA 管执行器权限与证据链，CLASP 管碰撞避免的几何辖区；仅共享「权项」隐喻 |
| 第 67 轮 SimRAS | 世界模型前瞻 + VQA 审计 | CLASP 把「审计建议」变为「执行前硬门禁」，并引入 gap/规避鲁棒性 |

**结论**：CLASP 的可专利性不押在「用 CBF 做避障」（已是 prior art），而押在**「主张格 + FTO 门禁 + 规避红队 + 覆盖单调再认证」的组合**及其证书结构上。

## 9. 本轮最大风险

**一句话**：CLASP 的「硬保证」完全建立在**可达集 `ℛ_t` 与主张有效性 `val(c,t)` 这两个估计量**上；一旦分布迁移或对抗设计让真实轨迹落在**从未被采样、因而从未被计入 `κ_cov` 的 gap** 中，乐观的覆盖度会把「主张看起来无懈可击」误报成「碰撞免疫」——这正是专利世界的铁律：**再密的专利布局也总能被设计绕过，只是绕过的成本不同**。这是本轮所有理论依赖的核心假设：**有限安全主张族在真实可达集上的覆盖度可被可靠估计，且设计绕过攻击的残余 `Vuln` 可被在线检测并压到可接受阈值以下。**
