# 第 14 轮（新灵感循环第 1 轮；本轮灵感：「运动规划」×「深度相机」）

> **基线**：第 13 轮 MetricVoiceGauge-NCD-HUTD（定义 583–594；引理 113–121；实验 E627–E646）。
> 本轮纪律：**深度单侧自由空间证书 + 未知即障碍的认知保守规划 + 看—动联合截止期路由**。不推倒 v13：v11 的 HAS/HCC/HATD/HDT、v12 的 USG/TGC/BAA/GAGP/UC、v13 的 AIO/CPD/DDL/RTCR、v10 的 NGE/DSL/CC/CWM/CAE/NCP、v9 的 AC/MW/ID、v8 的 DA/SPR/Cal 与九不变式全部保留。三个新能力——DFC（深度自由空间证书，含 DIC）、EMP（认知运动规划器，含 CMP/SSC）、APS（主动感知调度器，含 DVC）——加一个集成层 PMR（感知—运动路由器），一律以**中立元**接入；任一失效即严格退回 v13（引理 126），再沿 v13 退化链退回 v12/v11/v10/v9/v8/v7/v6。本轮只做三件事：把深度相机从“建图传感器”改写为**逐像素、单侧、带失效证书的自由空间证明器**；把运动规划从“已知地图上找路”改写为**未知即障碍的认知保守规划**；把看与动合成一条**共享截止期、单调可退化的联合证书**。

## 0. 直觉与动机

**灵感 1（深度相机 → 单侧自由空间证书与幻影自由空间的排除）**
直觉：深度相机不是一张地图，而是一个**单侧见证者**。一个像素的读数只证明：沿该像素射线的第一命中点之前是空的；它不证明命中点之后的任何东西。最常见的错误是把未观测区域当成自由空间，以保持规划可行——这正是透明玻璃、镜面、细线、掠射角、深度空洞与强吸收表面的事故来源。核心创新：**深度自由空间证书（Depth-Grounded Free-space Certificate, DFC）+ 深度完整性证书（Depth Integrity Certificate, DIC）**。DFC 只把“有效像素前方、扣除标定误差与机体半径之后的射线段”放进已认证自由空间 `F_cert`；其余全部进入未知 `U_obs`，并与障碍一样不可穿越。DIC 逐像素、按距离/入射角/材质/温度分层校准单侧深度误差，并把缺失、透明/镜面、低置信、跨帧不一致的像素标为无效。关键反直觉点：**安全不来自于“看见了很多”，而来自于“从未把没看见的当成自由”**；未知即障碍会让系统暂时变慢甚至死锁，但不会把幻影自由空间变成可执行路径。

**灵感 2（运动规划 → 未知即障碍的认知保守规划与前沿规划）**
直觉：经典运动规划假设占据地图已知；深度相机给出的是部分、视角依赖、有时效的地图。若在未知区域上做乐观捷径，规划器会不断产生“看起来可行、实际没有证据”的路径。核心创新：**认知运动规划器（Epistemic Motion Planner, EMP）+ 认证运动计划（Certified Motion Plan, CMP）+ 时空扫掠体证书（Spatiotemporal Swept-volume Certificate, SSC）**。EMP 只在已认证自由空间上建路线图与搜索；每条边、每个扫掠体都必须落在 `F_cert` 内，并按深度帧龄、相对速度与加速度做腐蚀/膨胀。若目标尚不可达，EMP 不退化为盲目探索，而是返回**前沿计划**：规划到“最值得看”的已认证视点，把未知显式记为一笔**认知债务**。关键反直觉点：**死锁不是规划器的失败，而是信息不足的诊断**；正确的反应是“看”，不是“赌一条乐观边”。

**灵感 3（运动规划 × 深度相机 → 看—动联合证书与主动感知路由）**
直觉：看要花时间，动会改变可见性；在 v13 的截止期下，看与动争同一毫秒。若先看完再动，可能错过截止期；若边冲边看，则执行了未认证的自由空间。核心创新：**主动感知调度器（Active Perception Scheduler, APS）+ 深度视角证书（Depth-View Certificate, DVC）+ 感知—运动路由器（Perception-Motion Router, PMR）**。每个视角都携带“能证明多少、要花多久、失效概率多大”的 DVC；APS 在预算内选择期望新认证体积最大的视角序列；PMR 在 `move / look / replan / stop / ask` 之间选一个，运动段只使用当前已认证的 `F_cert`，视角未完成或深度超龄就停，不以“正在看”为理由执行未认证轨迹。关键反直觉点：**主动感知不是给规划器加速，而是给规划器增加“可执行的前沿”；它买来的不是更大胆，而是更少死锁**。

**三者如何统一**
统一为 **v13 语义/时限层之下的几何实现层**：v13 回答“哪些技能在语义与截止期上被允许”（`Exec_v13`），v14 回答“用哪条连续轨迹、在什么视角条件下、以什么几何证书实现这些技能”（`Exec_v14`）。DFC 把深度变成单侧自由空间证书；EMP 把自由空间证书变成带扫掠体与时效的轨迹；APS/PMR 把“看”和“动”排进同一个剩余时间预算。共享状态 `ζ_pm=(M_cert,CMP,DVC,age,B_look,B_move,B_safe,mode)`。**DFC 回答“什么是被证明空的”，EMP 回答“什么轨迹能被证明安全地实现”，APS/PMR 回答“这一帧该看、该动、还是该停”**。三者不是三个感知补丁，而是“证据—轨迹—调度”的几何实现链。

## 1. 研究问题（轮次升级版）

- **Q1（单侧自由空间的可证语义）**：如何把逐像素深度读数变成“真实障碍不进入”的自由空间证书？单侧误差在距离、入射角、材质、温度与动态场景下如何分层校准？透明/镜面/强吸收/细结构导致的“幻影自由空间”如何被 DIC 识别，识别失败时如何保守失效？静态累积与动态失效如何切换而不产生“旧自由空间仍然有效”的缝隙？
- **Q2（未知即障碍的规划完备性与死锁）**：在 `U_obs` 不可穿越的约束下，如何定义概率完备/分辨率完备的认证路线图？扫掠体证书如何在深度帧龄、相对速度、加速度与跟踪误差下保持保守？当前沿计划也无法产生进展时，如何区分“真不可达”与“只是没看见”，并把死锁率纳入预算？
- **Q3（看—动联合调度）**：一个视角的“信息价值”如何定义才与任务进度、死锁减少和几何风险对齐？期望新认证体积在冻结计划下是否单调子模，贪心是否有 `1−1/e` 保证？在 v13 的 RTCR/DDL 与 `B_time` 下，`look` 与 `move` 的预算如何分配，才能不退化为“无谓等待”或“盲目冲刺”？
- **Q4（与 v13 的兼容与活性）**：v14 是否可能通过“更细的轨迹”绕过 v13 的技能、TGC/UC/四重证书或 DGC？DFC 的深度间隙、v13 的蒸馏间隙与 v12 的迁移间隙是否会相加而在新场景里共同低估？全未知/全遮挡场景下 PMR 是否频繁 `a_ask` 或永久停机？新增几何层能否守住 50Hz/p99≤22ms，并严格退回 v13？

## 2. 设计原则（在 P22–P24 基础上新增 P25–P27）

**P25 深度单侧安全律（One-Sided Depth Safety）**
自由空间必须由有效深度读数**正面证明**：只有“有效像素前方、扣除分层单侧误差与机体半径之后的射线段”可以进入 `F_cert`。缺失、饱和、低置信、透明/镜面/强吸收、跨帧不一致、标定支撑外的像素一律 `valid=0`，不得贡献任何自由空间。**未观测不等于自由；未知与障碍同等不可穿越。**

**P26 未知即障碍律（Unknown-as-Obstacle）**
运动规划只允许在 `F_cert` 内建边、搜索与执行；任何经过 `U_obs` 的捷径、乐观边或“先动后看”的轨迹一律禁止。目标不可达时，只能规划到已认证前沿视点，并把未知记为认知债务；执行前必须由新的深度证据把该段前沿变成 `F_cert`。死锁是信息不足的诊断，不是放宽自由空间的理由。

**P27 看—动联合截止期律（Joint Look-Move Deadline）**
每个视角必须携带 DVC，每个运动段必须携带 SSC；`look` 与 `move` 共享 `B_time`，但都不能挪用 `B_safe`。视角未完成、深度超龄、DIC 失效或扫掠体证书失效时，只能 `stop`/`ask`，**不得执行迟到或未认证的轨迹**。主动感知只能增加“已认证前沿”，不能增加 v13 未允许的技能、阈值或授权。

## 3. 与基线的接口（如何退化）

- DFC 失效 ⇒ 不产生新的 `F_cert`，直接使用 v13 既有的几何执行器/标称轨迹；无新增深度保证，**等价 v13 几何路径**；
- EMP 失效 ⇒ 不重规划，执行 v13 技能轨迹；深度只做监控，**等价 v13 轨迹执行 + 被动监控**；
- APS 失效 ⇒ 被动感知，不产生主动视角；未知即障碍仍然生效，**等价“v13 + DFC 被动证书”**；
- PMR 失效 ⇒ 由 v13 的 RTCR 按固定顺序调度，v14 只做证书监控，**等价 v13 调度路径**；
- 四者全失效 ⇒ MetricVoiceGauge-NCD-HUTD v13，再沿 v13 退化链退回 v12/v11/v10/v9/v8/v7/v6；
- **安全继承**：DFC 只删除自由空间，EMP 只在 `F_cert` 内选轨迹，APS 只选视角，PMR 只选 `look/move/replan/stop/ask`。四端口互不相交，均不能新增技能、放宽阈值或绕过 v13 证书；`Exec_v14⊆Refine(Exec_v13)` 由引理 125 保证。

## 4. 预期贡献

1. **单侧深度自由空间证书**：把深度相机从“平均精度建图”改写为逐像素、带失效证书的自由空间证明，显式排除透明/镜面/细结构造成的幻影自由空间，解决“未看见却被当成可走”的结构性安全问题；
2. **未知即障碍的认知保守规划**：把运动规划从“已知地图上找路”改写为“只在已证明自由空间内找路、把未知记为认知债务”，给出扫掠体/时效证书与前沿规划的退化语义；
3. **看—动联合证书与主动感知路由**：把视角选择、运动规划与 v13 截止期合成为一条单调可退化的调度链，使系统在遮挡/未知场景中主动减少死锁，而不是用乐观自由空间换取速度；
4. **几何实现层与安全继承**：v13 管“允许什么技能、何时允许”，v14 管“用哪条连续轨迹、在什么证据下实现”，用 `Exec_v14⊆Refine(Exec_v13)` 把几何安全与语义授权解耦；E647–E666 覆盖 DFC 可靠性、幻影自由空间、死锁、动态障碍、看—动预算、端到端与消融。

## 5. 本轮最大风险

**一句话**：DFC 的单侧保证完全系于 DIC 的深度有效性模型，而透明/镜面/强吸收/动态物体与标定漂移恰好落在该模型的支撑之外；一旦 DIC 漏检，系统会得到一个“逐像素都有证书、物理上却是幻影自由空间”的计划，并在主动感知的帮助下更自信地执行它——即**一个处处合规、却在真实世界里撞上“看不见的障碍”的几何计划**。

# 第 14 轮产物 · 创新点清单 v14：**MetricVoiceGauge-NCD-HUTD-P**（Metric Voice Gauge with Norm Grounding, Contact Dexterity, Causal Attribution, Harmonic Compliance, Universal Skills, Transfer Certification, Deadline-aware Distillation & **P**erception-grounded Motion Planning）

> 背景：第 13 轮 MetricVoiceGauge-NCD-HUTD（定义 583–594；引理 113–121；实验 E627–E646），其基线为第 12 轮 MetricVoiceGauge-NCD-HUT。

**定义 595（深度完整性证书 DIC）**
```
DIC = ( S_dep, E_hi, α_dep, valid, τ_max, support, dynamic )
```
有效当且仅当：
1. 在支撑域 `support` 内，以同时覆盖概率 ≥`1−α_dep` 对所有 `valid_u=1` 的像素有
   `z*_u ≥ z_u − E_hi(u)`；
2. `E_hi` 按距离、入射角、材质类、温度与积分时间分层，并用分层共形/风险控制做有限样本修正；
3. `valid_u=0` 覆盖缺失、饱和、低置信、透明/镜面/强吸收、细结构、跨帧不一致与标定支撑外的像素；无效像素**不产生任何自由空间声明**；
4. `τ_max` 为深度帧最大有效期；`age>τ_max` 时 DIC 失效；
5. 动态模式下还必须给出 `v_obs_max` 与 `a_obs_max` 上界；否则不能认证动态安全。
DIC 是**单侧、逐像素、带失效状态**的证书，不是平均深度误差统计量。

**定义 596（深度自由空间证书与认知地图）**
```
F_cert(t) = { p = o_t + r·n(u) : valid_u=1,
              r_min ≤ r ≤ z_u − E_hi(u) − m_body } \ B_body
O_meas(t) = ∪_{valid_u=1} B( c_u, E_hi(u) + m_body )
U_obs(t) = W \ ( F_cert(t) ∪ O_meas(t) )
M_cert(t) = ( F_cert, O_meas, U_obs, t, age, DIC, static/dynamic )
```
其中 `c_u` 为像素 `u` 的测量三维点，`m_body` 为机体半径/跟踪余量，`B_body` 为机器人本体。约定：
1. `F_cert` 是**已证明为空**的空间；`O_meas` 是已观测障碍的保守膨胀；`U_obs` 是未证明区域；
2. 规划与执行只允许 `F_cert`；`U_obs` 与 `O_meas` 一样不可穿越；
3. 静态模式且 DIC 有效时，累积地图
   ```
   F_acc(t) = F_acc(t−1) ∪ F_cert(t)
   ```
   动态模式或 DIC 失效时
   ```
   F_acc(t) = F_cert(t)
   ```
   以防旧自由空间在动态场景中继续被信任。

**定义 597（时空扫掠体证书 SSC）**
```
S(γ) = ∪_{s∈[0,T]} ( B_body(γ(s)) ⊕ B(0, d_safe(s)) )
d_safe(s) = v_rel_max(s)·τ + ½·a_max·τ² + m_track
F_safe(t,τ) = F_cert(t) ⊖ B(0, d_safe)     (dynamic)
            = F_cert(t)                    (static)
SSC(γ) 有效 ⇔ τ ≤ τ_max
            ∧ S(γ) ⊆ F_safe(t,τ)
            ∧ dist( S(γ), ∂F_safe(t,τ) ) ≥ m_geo
```
`v_rel_max` 为机器人与任何障碍的最大相对速度上界，`a_max` 为最大相对加速度，`m_track` 为跟踪误差余量。`SSC` 对轨迹的**每个前缀**都要成立，否则不能作为随时可停的执行计划。

**定义 598（认证运动计划 CMP）**
```
CMP = ( a, γ, v(·), t0, T, SSC, views, fallback )
```
有效当且仅当：
1. `a ∈ Exec_v13` 且 `γ ∈ Refine(a)`；`γ(0)=x_t`，`γ(T)∈G_a`，`a` 的效果签名不被改变；
2. `SSC` 在 `t0` 有效，且对任意 `s∈[0,T]` 的前缀 `γ|[0,s]` 有效；
3. 存在已认证的停止点序列，任一前缀都能在 `P^rt_geom` 内安全停止；
4. `fallback ∈ P^rt_geom`；
5. 若 `γ` 依赖未来视角，则这些视角已包含在 `views` 且其 DVC 有效。
`CMP` 是 v14 的执行单元：**它只能细化 v13 已允许的技能，不能新增技能**。

**定义 599（认知路线图与前沿规划）**
```
G_cert = (V,E)
V ⊆ F_acc
(u,v) ∈ E ⇔ seg(u,v) ⊆ F_acc ∧ dist(seg(u,v), ∂F_acc) ≥ m_geo
EMP(x,g;M_cert) = argmin_{γ⊆G_cert, γ(0)=x, γ(T)∈G_g} J(γ)
```
若不存在到目标的认证路径，则返回
```
FrontierPlan(M_cert,g) = argmax_{v∈∂F_acc, v 从 x 可达且可见}
                          Progress(v;g) / cost(v)
```
若无满足 DVC 的前沿，则返回 `NoPlan`。**未知即障碍**：`G_cert` 不含任何乐观边；`FrontierPlan` 只是“去看”的目标，不是“穿过未知”的许可。

**定义 600（深度视角证书 DVC 与主动感知调度）**
```
DVC(v) = ( cov_v, latency_v, α_view, valid )
I(v∣M_cert,CMP) = E[ |F_cert(v) ∩ S(γ*) \ F_acc|
                    + λ_g · ΔProgress(γ*∣v) ]
Σ = ( v_1, γ_1, …, v_k, γ_k )
```
有效调度条件：
1. 每个 `v_i` 的 DVC 有效，且 `Σ latency(v_i) ≤ B_look`；
2. 每个 `γ_i` 只使用执行 `v_i` 后的 `F_acc` 建图与认证；
3. `Σ latency(v_i) + Σ time(γ_i) ≤ B_look + B_move`；
4. 每个运动段都有当前 `SSC`，不得用“未来视角会看见”来为当前未认证段背书。
APS 在预算内最大化 `Σ I(v_i∣·)`；实现上用冻结当前计划 `γ*` 的替代增益，要求其单调子模，以便贪心有 `1−1/e` 保证（引理 124）。

**定义 601（感知—运动路由状态与策略）**
```
ζ_pm = ( M_cert, CMP, DVC, age, B_look, B_move, B_safe, mode )
mode ∈ { move, look, replan, stop, ask }
```
路由优先级为：
```
1. DIC 无效 ∨ age>τ_max ∨ 无安全前缀          → stop / ask
2. 无认证进展 ∧ 存在可负担的 DVC 前沿         → look
3. 当前 CMP 被新障碍阻挡 ∧ 有 B_move          → replan
4. 当前 CMP 前缀仍被 F_cert 覆盖               → move
5. 无 CMP、无前沿、无 B_look                  → ask
```
PMR 只决定本帧把预算花在 `look/plan/move` 的哪一项，**不改变 v13 证书、不新增技能、不放宽任何阈值**。

**定义 602（v14 执行集与细化）**
```
Refine(a) = { γ : γ 实现 a 的前置/后置条件与效果签名
                 ∧ v11/v12/v13 的全部证书仍有效 }
Exec_v14 = { π : ∃a∈Exec_v13, ∃CMP=(a,γ,…),
                 proj_skill(π)=a,
                 SSC 有效 ∧ DIC 有效 ∧ P^rt_geom≠∅ }
```
于是 `Exec_v14 ⊆ Refine(Exec_v13)`，且 `proj_skill(Exec_v14) ⊆ Exec_v13`。v14 的几何安全与 v13 的语义/时限安全是**合取**关系，不是替代关系。

**定义 603（中立元表 v14 扩展）**

| 新组件 | `v^⊥` | 等价退化点 |
|---|---|---|
| DFC | 不产生新 `F_cert`；直接使用 v13 既有几何执行器/标称轨迹 | Level-4（v13 几何路径） |
| EMP | 不重规划；执行 v13 技能轨迹；深度只做监控 | Level-3（v13 轨迹 + 被动监控） |
| APS | 被动感知；无主动视角；未知即障碍仍生效 | Level-2（v13 + DFC 被动证书） |
| PMR | v13 RTCR 静态调度；v14 只做证书监控 | Level-1（v13 调度路径） |

**定义 604（四预算不可挪用 Four-Budget Non-Fungibility）**
```
B_total = B_transfer + B_distill + B_depth
B_time  = B_safe + B_infer + B_look + B_move
```
四类预算（迁移/蒸馏/深度证据/时间）各自独立，**不得互相冲抵**：深度校准与多视角证据不能拿迁移或蒸馏预算买单，`look` 也不能拿 `B_safe` 买单。任一预算耗尽时，唯一允许的动作是 `stop`、`ask` 或沿 v13 阶梯更保守；不得用“更快的学生”替代“更可靠的深度证据”。

# IP-375 DepthFreespaceCertifier：单侧自由空间 + 完整性证书
class DepthFreespaceCertifier:
    def __init__(self, dic, m_body=0.08, m_track=0.02):
        self.dic, self.m_body, self.m_track = dic, m_body, m_track

    def certify(self, depth, K, pose, t):
        valid = self.dic.validity_mask(depth)          # 缺失/透明/低置信→0
        E = self.dic.error_bound(depth, valid)         # 分层单侧误差 E_hi
        if not self.dic.valid(valid, depth, t):
            return INVALID
        F = self.carve_near_rays(depth, E, valid,        # r ≤ z_u - E_hi - m_body
                                 m_body=self.m_body)
        O = self.inflate_returns(depth, E, valid,        # B(c_u, E_hi + m_body)
                                 m_body=self.m_body)
        U = self.world_complement(F, O)                  # 未知区域
        F_acc = self.accumulate(F, reset=not self.dic.static)
        return MCert(F_acc, O, U, t, age=0, dic=self.dic)


# IP-376 EpistemicMotionPlanner：只在 F_cert 内规划；目标不可达则看前沿
class EpistemicMotionPlanner:
    def __init__(self, m_geo=0.05, planner="rrt_star"):
        self.m_geo, self.planner = m_geo, planner

    def plan(self, x, goal, mcert, deadline):
        G = self.build_certified_roadmap(mcert.F_acc, margin=self.m_geo)
        path = self.anytime_search(G, x, goal, deadline)     # v13 AIO 可中断
        if path is not None:
            ssc = self.ssc(path, mcert, m_geo=self.m_geo)
            if all(self.ssc_valid_prefix(path, s) for s in ssc.samples):
                return CMP(a=self.skill, gamma=path, ssc=ssc,
                           views=[], fallback=self.stop_fallback(path))
        frontier = self.best_frontier(mcert, x, goal)        # ∂F_acc 上可见视点
        return FrontierPlan(frontier) if frontier else NoPlan()


# IP-377 ActivePerceptionScheduler：预算内最大化期望新认证体积
class ActivePerceptionScheduler:
    def __init__(self, dvc, lambda_g=0.5):
        self.dvc, self.lambda_g = dvc, lambda_g

    def schedule(self, mcert, cmp, B_look):
        chosen, spent = [], 0.0
        while spent < B_look:
            best, best_ratio = None, 0.0
            for v in self.candidate_views(mcert, cmp):
                if not self.dvc(v).valid:
                    continue
                gain = self.expected_new_certified_volume(v, mcert, cmp)
                ratio = gain / max(self.dvc(v).latency, 1e-6)
                if ratio > best_ratio:
                    best, best_ratio = v, ratio
            if best is None:
                break
            chosen.append(best)
            spent += self.dvc(best).latency
            mcert = self.predict_certificate(mcert, best)     # 预测，不当作已认证
        return Schedule(chosen)


# IP-378 PerceptionMotionRouter：look / move / replan / stop / ask
class PerceptionMotionRouter:
    def __init__(self, tau_max, min_prefix=0.05):
        self.tau_max, self.min_prefix = tau_max, min_prefix

    def step(self, x, mcert, cmp, B_look, B_move):
        if mcert is INVALID or mcert.age > self.tau_max:
            return StopOrAsk("stale_or_invalid_depth")
        if cmp is None or not self.safe_prefix(cmp, mcert, self.min_prefix):
            if B_look > 0 and self.has_frontier(mcert):
                return Look()
            return StopOrAsk("no_certified_prefix")
        if self.blocked(cmp, mcert):
            if B_move > 0:
                return Replan()
            if B_look > 0:
                return Look()
            return StopOrAsk("blocked_no_budget")
        return Move(cmp.first_certified_segment())

## 4. 推导

**引理 122（单侧自由空间的可靠性）** 若 DIC 在支撑域内以同时覆盖概率 ≥`1−α_dep` 给出所有有效像素的单侧界，且 `F_cert` 按定义 596 构造，则
```
P( F_cert(t) ∩ O_true(t) = ∅ ) ≥ 1 − α_dep .
```
证明：任取 `p∈F_cert(t)`，则存在有效像素 `u` 与 `r`，使 `p=o_t+r·n(u)` 且 `r ≤ z_u − E_hi(u) − m_body`。DIC 给出 `z*_u ≥ z_u − E_hi(u)`，故 `r < z*_u`。沿该射线的第一命中点在 `p` 之后，因此 `p` 不在任何真实障碍内。对所有有效像素取并集，由 DIC 的同时覆盖概率得结论。∎ 推论：**自由空间的正确性只依赖于“有效像素的单侧误差界”，不依赖于深度图的平均精度**；DIC 失效时 `F_cert` 必须为空或整体不可信。

**引理 123（扫掠体/时效安全性）** 若 `CMP` 的 `SSC` 在 `t0` 有效、DIC 有效，且机器人与障碍的相对速度/加速度不超过 `v_rel_max,a_max`，则在 `[t0,t0+τ]` 内执行 `γ` 无碰撞的概率至少 `1−α_dep−α_dyn`。证明：任意能在 `τ` 内进入 `S(γ)` 的障碍点，在 `t0` 必须位于 `S(γ)⊕B(0,v_rel_max·τ+½a_max·τ²)` 内。`F_safe` 已腐蚀该膨胀量，而 `SSC` 要求 `S(γ)⊆F_safe`，故该障碍点不在真实障碍中；再与引理 122 的单侧自由空间可靠性合取。∎ 推论：**深度帧龄不是性能参数，而是安全半径**；`τ` 越大，`F_safe` 越小，规划越保守。

**引理 124（主动感知的贪心保证）** 固定当前计划 `γ*`，若每个视角的新认证体积是集合覆盖函数，则 `I(v∣M,CMP)` 关于已选视角集合单调子模；在预算 `B_look` 下，贪心选择达到最优期望新认证体积的至少 `1−1/e`。证明：集合覆盖函数单调子模，期望保持单调子模；标准预算贪心界。∎ 注：计划随视角变化时，`I` 只是冻结计划的替代增益；实际收益由 E651 检验，不以替代界冒充端到端保证。

**引理 125（安全继承与不可绕过性）** 对任意 `π∈Exec_v14`，存在 `a∈Exec_v13` 使 `π∈Refine(a)`，从而
```
Exec_v14 ⊆ Refine(Exec_v13) ,   proj_skill(Exec_v14) ⊆ Exec_v13 .
```
证明：定义 598 要求 `a∈Exec_v13` 且 `γ∈Refine(a)`；定义 602 要求 `SSC`、DIC 与 `P^rt_geom` 同时有效。DFC 只删除自由空间，EMP 只在 `F_cert` 内选轨迹，APS 只选视角，PMR 只选模式；四者都不新增技能、不修改 v13 阈值。故任一 v14 执行都细化某个 v13 允许的技能。∎ 因此 v13 引理 117 与 v12/v11 的安全继承在 v14 上继续成立。

**引理 126（中立元退化等价 v13）** 将定义 603 的四个中立元注入 DFC/EMP/APS/PMR 端口，则：DFC 不产生新自由空间、EMP 不重规划、APS 不产生主动视角、PMR 退化为 v13 RTCR 调度；主闭环调用序列与 v13 逐位一致，再沿 v13 链退回 v12/v11/v10/v9/v8/v7/v6。证明：逐端口代入定义 603，并用定义 595–604 的边界条件核对；四端口互不相交，中立元不改变 v13 任何证书检查。∎

**引理 127（看—动联合截止期）** 若 v13 RTIC 有效，且 `B_look+B_move+B_infer ≤ B_time−B_safe`，则任意 v14 执行满足 `P(latency≤D)≥1−δ_t`；若截止期内没有有效 CMP/DVC，则执行 `P^rt_geom`（停/问），**不执行迟到轨迹**。证明：`look` 与 `move` 的预算被硬约束在 `B_time−B_safe` 内；PMR 优先级保证深度超龄/证书失效时立即停；v13 RTIC 给出计算侧截止期。∎ 推论：**主动感知不能把“没看完”变成“先执行”**；它只能在预算内把未知前沿变成已认证前沿。

**引理 128（死锁是信息不足，不是乐观的理由）** 在路线图分辨率/概率完备性意义下，若真实自由空间存在从 `x` 到 `g` 的路径但 `EMP` 返回 `NoPlan`，则该路径必穿过 `U_obs` 或依赖 `valid=0` 的像素。因此
```
P(deadlock) ≤ P(path ∩ U_obs ≠ ∅) + P(DIC invalid) + P(no frontier) .
```
证明：`G_cert` 只在 `F_acc` 上建边；若一条路径完全位于 `F_acc`，则它在路线图中被搜索到（在分辨率/概率完备意义下）。否则路径必经过未证明区域或依赖无效深度。∎ 推论：**正确的反应是增加视角/提高覆盖，而不是放宽 `F_cert`**；E650/E663 专门检验这一点。

**引理 129（迁移、蒸馏与深度间隙的联合可加界）** 记
```
Δ_tr  = J_real(a)   − J_sim(a)
Δ_dis = J_real(S)   − J_real(T)
Δ_dep = J_real(π*)  − J_cert(π*)
```
则
```
J_real(π) − J_sim(a) ≤ U_gap + U_dis + U_dep + I_cross   （w.h.p.）
```
且
```
B_total = B_transfer + B_distill + B_depth
```
必须是加性的。证明：代数展开；`Δ_tr` 由 v12 TGC 单侧覆盖，`Δ_dis` 由 v13 DGC 单侧覆盖，`Δ_dep` 由 DIC/SSC 单侧覆盖；三者各自以 `1−α` 成立，联合用并集界得到 `1−α_gap−α_dis−α_dep`。负的、偶然更好的项不计入收益，因为安全界只取 `max(0,·)`。∎ 推论：**深度证据不能拿迁移/蒸馏预算冲抵**；新场景中三个间隙可能同时被低估，这是 v14 的根本脆弱点。

**引理 130（静态认知地图的单调性）** 在静态模式且 DIC 有效的条件下，`F_acc(t)` 单调不减且
```
P( F_acc(t) ⊆ F_true_free ) ≥ 1 − Σ_{s≤t} α_dep(s) .
```
动态模式或 DIC 失效时按定义 596 重置。证明：对 `t` 归纳。`F_acc(0)=F_cert(0)⊆F_true_free` 由引理 122；静态模式下 `F_acc(t)=F_acc(t−1)∪F_cert(t)`，并集仍 ⊆ 真实自由空间；DIC 的逐帧同时覆盖概率用并集界累积。∎ 推论：**静态探索不会“越看越不安全”**；但动态场景必须重置，否则旧自由空间会变成安全漏洞。

## 8. 已知风险与失效模式

1. **DIC 漏检导致幻影自由空间**：透明/镜面/强吸收/细结构可能让深度读数偏大，`z*_u < z_u−E_hi(u)`，而 `valid` 仍为 1。缓解：材质/置信度分类、跨帧一致性、主动多视角、可疑像素一律置无效；任何 DIC 漏检即触发全局保守。
2. **标定/温度/时间同步漂移**：外参或时钟漂移会让 `support` 失效，单侧误差不再成立。缓解：在线自检、温度补偿、硬件同步、漂移检测后重置 `F_acc` 并停/问。
3. **未知即障碍导致死锁与活动性塌缩**：遮挡严重时 `F_cert` 过小，PMR 频繁 `look`/`ask`。缓解：主动视角、前沿规划、分层 `B_look`、把死锁率显式计入目标；不得用乐观自由空间换取活动性。
4. **主动感知的短视与替代增益失配**：冻结计划贪心只保证替代目标，计划变化后可能选到低价值视角。缓解：多步 lookahead、精确小规模搜索、按 E651 检验端到端收益。
5. **动态场景的时效缝隙**：深度帧龄、跟踪误差、障碍加速度可能超过 `d_safe`。缓解：扩大膨胀、降低速度、提高深度帧率、动态模式下缩短 `τ_max`；超龄立即停。
6. **薄障碍/小物体在低分辨率深度中消失**：细线、桌沿、透明边缘可能不产生有效返回。缓解：多视角、主动靠近、边缘检测、保守膨胀；无法证明时不得进入。
7. **仿真到真实的深度差距**：合成深度缺少噪声、反射、透明与运动模糊，导致 DIC 在真机上失效。缓解：真实标定集、域随机化、硬件在环、上线前压力测试。
8. **与 v13/v12 间隙联合低估**：新场景同时进入深度校准外、蒸馏校准外与迁移分布外，`U_dep+U_dis+U_gap` 可能同向偏低。缓解：引理 129 的加性界、四预算不可挪用、双重漂移检测、任一间隙失效即 `stop/ask`。
9. **几何层计算尖峰**：深度处理、路线图重建与视角评分同时变重。缓解：v13 AIO 随时化、缓存路线图、5–10Hz 规划 + 50Hz 前缀检查、保留 `B_safe`。

## 9. 本轮最大风险

**一句话**：DFC 的单侧保证完全系于 DIC 的深度有效性模型，而透明/镜面/强吸收/动态物体与标定漂移恰好落在该模型的支撑之外；一旦 DIC 漏检，系统会得到一个“逐像素都有证书、物理上却是幻影自由空间”的计划，并在主动感知的帮助下更自信地执行它——即**一个处处合规、却在真实世界里撞上“看不见的障碍”的几何计划**。
