# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「双臂协调」×「评测基准」）

> R69 教会系统「问」：把不确定性拆成 aleatoric/epistemic，用注视、探针、问句去消解可约歧义，并立下「k 个正交证据源一致」的纪律。但这条纪律里有一个从未被检验的字——**正交**。引理 18 的 ρ 是假设的，不是测出来的；而 FLUID-RAS 自陈的最大风险（模态分布不可信 → 自信地追问幻影、给误导回答盖章）恰恰是「证据源其实高度相关」的下游症状：**问了三遍，问的是同一双眼睛。**
>
> 本轮两个灵感从两侧把这个字补上：
> - **双臂协调**：两条臂不是两个独立的单臂。它们共享躯干、相机、标定、电源与工作空间，因此在物理上**相关**；而共同抓握时又构成闭环运动链，任何「各干各的」策略都会退化为内力对抗或角色震荡。双臂因此既是**协调问题**（谁主谁从、何时让、何时接），也是一种**天然的冗余评测通道**（第二臂可以否决/确认/挑战第一臂的计划）——前提是它们的失败**不共模**。
> - **评测基准**：一个基准是**虚拟的第二条臂**——它会「碰撞」（对抗任务）、「确认」（通过）、「挑战」（失败）。但基准若与训练共享仿真器、种子、资产、策略族，它的 ρ≈1，k 个基准不过是同一句话说了 k 遍。于是「评测基准」不是榜单，而是一个**需要被评测的证据源**。
>
> 核心命题：**双臂协调与评测基准是同一个问题的两个实例——冗余证据的价值不由证据数量决定，而由其去相关程度决定。** 把「协调模式」作为新的离散决策变量，把「协调间隙」作为新的不确定性通道，把「去相关」作为新的可付费动作，把「基准可信度」作为进入安全论证的门票。命名 **DUET-RAS**（Dual-arm Uncertainty-aware Evaluation-Triangulated Risk-adaptive Autonomy）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**两个证人异口同声，是因为它们真的独立，还是因为它们共用了一双眼睛**」。

## 0. 直觉与动机

**灵感 1（双臂不是两个单臂 → 协调模式是新决策）**
直觉：单臂策略只需决定「做什么」；双臂还要决定「谁做、谁让、何时交接」。同一任务至少有三类协调模式：主从（一臂主导、一臂跟随）、对称协作（两臂共同承重/共同塑形）、支撑-操作（一臂固定世界、一臂改变世界）。此外还有「犹豫」：两臂同时想主导（冲突）或同时想让（死锁）。这些不是世界的不确定性，而是**分工的不确定性**——把它塞进 R69 的 U_epi，会把「选哪个世界」与「选哪种合作」混为一谈。

**灵感 2（闭环运动链 → 各干各的会产生看不见的内力）**
直觉：两臂抓住同一物体时，末端不再是两个自由点，而是一个闭环。两条独立生成的轨迹即便各自都「安全」，合起来也可能把物体拉长、压扁、扭转，或让关节产生巨大内力——**这种力不出现在任何单臂的观测里**。所以耦合必须写进生成过程本身：动作块要落在约束流形上（相对位姿、闭链、摩擦锥、避碰），而不是生成后再用滤波器硬掰。约束流形上的流匹配，是本轮第一个技术支点。

**灵感 3（协调间隙 → 用「单方面反悔的收益」量化不一致）**
直觉：一个好的联合计划应让两条臂都「不想单方面改主意」——这正是纳什均衡。若左臂看到右臂的计划后大幅改变自己的计划，说明二者不互认；若两臂都等对方先动，就是死锁。于是定义一个可计算的**协调间隙**：把「各自在知道对方计划后还能改进多少」加起来。间隙为 0 ⇔ 互相最佳响应；间隙大 ⇔ 需要一个协调动作（让、领、交接、触觉探询）来消解。这把「默契」变成能测量、能估值、能被安全认证的量。

**灵感 4（触觉对话 → 共享物体是通信信道）**
直觉：人类双手协调不靠一个中心规划器喊话，而靠**力**对话：一只手推，另一只手让；刚度是语气，力矩是措辞。共享物体因此是一条有容量的信道。于是 R69 的信息动作空间自然扩张：让（降刚度/松共握/后撤）、领（提刚度/给明确轨迹）、触觉探针（小幅力脉冲估质量/摩擦/滑移）、相对标定（小幅安全共动重估双臂外参）、交接（受控转移）。关键：这些动作**改变的是协调模式**，不只是世界信念；它们同样必须过 C-RAS-WM 安全认证。

**灵感 5（冗余证据的硬上限 → 共模故障投不掉）**
直觉：R69 的证据纪律假设 k 个源彼此独立，于是错误率随 k 指数下降。但双臂共享标定与电源、基准共享训练数据与仿真器：它们的错误里有一个**共模分量**。共模发作时，所有源一起错——再多源也投不过。统计上这就是设计效应：k 个两两相关 ρ 的源，有效独立数只有 `k_eff = k/(1+(k−1)ρ)`。ρ=0.5、k=4 时 k_eff≈1.6，而不是 4。**「再加一个证人」在 ρ 高时几乎不增值；「让证人真正独立」才增值。**

**灵感 6（去相关是可付费的动作 → 与加证据同台竞价）**
直觉：去相关不是免费的：重标定第二臂要动，换视角要时间，造一个真正 held-out 的基准要成本。于是「加一个证据源」与「把一个现有源去相关」应在同一预算下比较边际收益。定义**去相关价值 VoD**：降低 ρ 带来的风险界下降除以成本，与 R69 的 VoI 同台竞价。若 VoD > VoI，正确的做法不是多问一句，而是**先换一双眼睛**。这正面回应 FLUID 的最大风险：模态分布不可信时，采样再多也还是同一双眼睛。

**灵感 7（基准是证据源，不是裁判 → 元评测）**
直觉：基准可以被污染（训练/测试同源）、被过拟合（chasing the leaderboard）、被 Goodhart（刷代理指标而损害真目标）、被共谋（基准与策略共享同一盲区）。所以基准分数不是结论，而是一条**带泄漏与偏置的证据**。本轮交付四件套：覆盖度、泄漏、Goodhart 间隙、预测效度，合称基准可信度 BCS；再用一个**元评测**（evaluate the evaluator）审计审计者。只有 BCS 过门的结论才能进入安全论证，否则只能标为「基准局部有效」。

**灵感 8（对偶 → 臂与基准是同一台机器）**
直觉：臂是物理评测器，基准是虚拟臂；二者的价值都由去相关决定，二者都能被共模故障骗过，二者都能被当作安全论证的证据。把它们放进同一个 `k_eff / VoD` 框架，本轮才不是「双臂」加「基准」的拼盘，而是**一个关于冗余证据的统一理论**。这也是本轮的理论姿态：FLUID-RAS 是 DUET-RAS 在「两臂完全独立、基准完全可信、协调交互无利可图」边界上的退化情形。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（DUET-RAS 总览）** DUET-RAS = (BCC, CMD, HAD, ECD, VOD, MEB, CEB, RAS-WM†)。五条不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **协调安全**：联合动作 (a_L,a_R,g) 整体过 C-RAS-WM 认证；让/领/交接的切换不得使安全包络扩张，也不得产生超过 τ_int 的内力或角色振荡；
(iii) **证据独立下限**：任何「独立证据」声明必须报告 k_eff 与 ρ̄；k_eff < k_min 时不得据此放松保守；k=1 永不单独定案（继承 R69 定义 293-iii）；
(iv) **基准可信门**：任何「泛化/安全提升」的结论必须附 BCS 与泄漏上界；BCS < τ_BCS 或 ρ_leak^U > δ_leak 时结论降级为「基准局部」，不得进入 J_DUET 的安全侧；
(v) **单调降级**：任一层失效时，DUET → FLUID → R68 的保守性单调不降。

**定义 311（双臂耦合动作与约束流形）** 单臂动作块 a_i ∈ ℝ^{H×d_a}，i∈{L,R}；信息动作 g ∈ 𝒜_info（继承 R69 定义 294 并扩张，见定义 316）。联合动作 ξ=(a_L,a_R,g) ∈ 𝒜_+²。耦合约束 C(ξ)=0 定义流形 ℳ_C ⊂ 𝒜_+²，含：(a) 闭链约束（共同抓握的相对位姿恒定）；(b) 抓握稳定（接触力在摩擦锥内）；(c) 避碰（两臂及负载不互穿）；(d) 共享底座/躯干可行域。可允许动作 = ℳ_C ∩ 安全包络。

**定义 312（耦合流匹配 BCC）** 噪声 x_0 ~ 𝒩(0,I)，目标 x_1=ξ。速度场 v_θ(x_s,s|o) 经投影层保证切于 ℳ_C：P_C = I − J_C⁺J_C。训练目标 L_BCC = E‖(I−P_C)(v_θ−(x_1−x_0))‖² + λ_c‖J_C v_θ‖²；采样每步 x_{s+Δ} ← Proj_{ℳ_C}(x_s+Δv_θ)，Proj 为 2–3 次牛顿投影。跨臂条件用交叉注意力：π_L(a_L|a_R,o) 与 π_R(a_R|a_L,o) 可直接从同一速度场读出。**耦合是生成的一部分，不是事后修补。**

**定义 313（协调模式分解 CMD）** K 个联合采样聚类为 K̂ 个协调模式 m_k=(m_L^k,m_R^k,rel_k)，rel_k ∈ {主从, 对称协作, 支撑-操作, 交接, 让位, 撤退}；权重 ŵ_k；原型 ξ̄_k；模态内协方差 Σ_k。联合熵 H_joint=H(M_L,M_R)；边缘熵 H_L,H_R；协调互信息 I_c = H_L+H_R−H_joint（两臂选择的耦合强度）。

**定义 314（协调间隙 U_coord）** 对联合模式 m_k，Q_i 为臂 i 的任务-协调代价（负回报）。单方面改进间隙
g_i(m_k) = max_{a_i'} E_{a_{−i}~π_{−i}(·|a_i',o)}[Q_i(a_i',a_{−i})] − E_{a_{−i}~π_{−i}(·|a_i,o)}[Q_i(a_i,a_{−i})]，
U_coord(m_k) = g_L(m_k)+g_R(m_k)。U_coord=0 ⇔ 互为最佳响应（稳定协调）。死锁（双方都想让）与冲突（双方都想领）都表现为 U_coord>0，但改进方向相反（由 argmax 的符号区分）。廉价代理：用条件流似然的 KL 近似 g_i。

**定义 315（三分解与通道映射）** U=(U_ale,U_epi,U_coord)：U_ale=Σ_k ŵ_k tr(Σ_k)（模态内噪声，含耦合噪声）；U_epi=H_mode·g(Δ_min)（世界歧义，沿用 R69 定义 297）；U_coord=Σ_k ŵ_k U_coord(m_k)（协调不一致）。三者不对易、不简单相加，分通道：U_ale→λ_floor；U_epi→MINT 世界交互；U_coord→HAD 协调动作。任一道未消解即计入 λ_floor 兜底。

**定义 316（触觉对话 HAD 与协调信息动作）** g ∈ {g_yield（降刚度/开共握/后撤）, g_lead（提刚度/给明确轨迹）, g_handover（受控转移）, g_probe^h（小幅力脉冲估质量/摩擦/滑移）, g_recal（小幅安全共动重估双臂外参 T_LR）}。信息论刻画：共享物体为信道，力/力矩轨迹 f 与协调模式 M 的互信息 I(f;M|o) 受能量/力/位移约束。HAD 取 g* = argmax_g [I(f_g;M|o) − c_had(g)]，s.t. risk(g) ≤ ε_int 且 g 过 C-RAS-WM。无利可图则不动作，U_coord 未消解→计入兜底。

**定义 317（协调 VoI 与仲裁）** VoI_c(g) = H(M_L,M_R|o) − E_{y~p(·|g,o)}[H(M_L,M_R|o,y)]，y 为触觉/力反馈。仲裁：若 U_coord>τ_coord 且 max_g[VoI_c−c]>0，执行 g；若 U_coord 高但所有候选 g 的净收益 ≤0（如死锁无法通过让位安全解除），进入**保守锚定**：一臂固定/阻抗保持，另一臂只在认证包络内小步执行，直到外部条件变化。**「不动」也是一种协调动作，但必须被显式认证为安全保持，而不是消极超时。**

**定义 318（证据相关性与有效独立数 ECD）** 证据源 i=1..k（第二臂否决、视觉、力觉、流似然、基准分数…），失败指示 E_i∈{0,1}，两两相关 ρ_ij。有效独立数
k_eff = k / (1 + (k−1)ρ̄)，ρ̄ = (2/(k(k−1)))Σ_{i<j}ρ_ij。
（等相关时即设计效应；非等相关用 ρ̄ 近似。）共模上界：若存在共同故障 C，P(C)=ρ_c 且 C 发生时所有源同时失败，则任意多数投票的错误率 ≥ ρ_c，与 k 无关。

**定义 319（去相关动作与 VoD）** 去相关动作 d ∈ {重标定第二臂, 改变视角/传感器, 生成 held-out 基准, 更换仿真器/资产, 分工隔离}，成本 c_d，执行后相关性估计 ρ̄(d)。定义
VoD(d) = [B(ρ̄,k) − B(ρ̄(d),k)] / c_d，
B 为风险上界（定义 318 与 R69 引理 18 的推广）。调度：在「加证据（VoI_add）」与「去相关（VoD）」之间按每单位成本边际收益择优；当 ρ̄>ρ_max 时，去相关优先于加源。

**定义 320（基准作为证据源与可信度 BCS）** 基准 B=(𝒯_B,s_B)。四维有效性：
(a) **覆盖度** Cov(B)=min_{c∈𝒞} frac_B(c)，𝒞 为协调失败分类（死锁/交接掉落/角色震荡/负载不对称/相对标定漂移/共模传感失效）；
(b) **泄漏** ρ_leak(B,π)；
(c) **Goodhart 间隙** D_B=|s_B(π)−U_gold(π)|，U_gold 在专家审计的 gold 子集上测；
(d) **预测效度** PV(B)=corr(s_B, s_adv)，对 held-out 对抗集测排序相关。
BCS = min{Cov, 1−ρ_leak^U, 1−D_B, PV} ∈ [0,1]。BCS ≥ τ_BCS 才可作为独立证据源，其有效权重 ∝ (1−ρ_leak)。

**定义 321（基准泄漏估计 BLE）** 泄漏三源：(i) 成员推断/近重复（任务与训练轨迹的嵌入距离）；(ii) 种子/资产/仿真器重叠（元数据依赖图）；(iii) 策略族重叠（同一预训练骨干）。ρ̂_leak 用三源证据的保守融合（取上界或 max），并给置信上界 ρ_leak^U（聚类 bootstrap）。**泄漏本身也需要 k_eff**——单源泄漏估计同样不可单独定案。

**定义 322（协调评测基准 CEB）** CEB 是面向协调的基准族，至少含：CEB-Deadlock（谁先动）、CEB-Handover（遮挡下交接）、CEB-Symmetry（对称任务的确定性破对称）、CEB-Load（一臂失效/负载不对称下的优雅降级）、CEB-Drift（注入双臂相对标定慢漂移）、CEB-Adv（对抗生成，且与训练集有显式去相关控制）。每个子基准标注所覆盖的失败类，用于计算 Cov(B)。

**定义 323（元评测 MEB）** MEB 审计基准本身：在 gold 子集上估 D_B；用 BLE 估泄漏；用 CEB-Adv 估预测效度；输出 BCS 及其不确定性。**元评测的结论也不能由单一基准自证**：至少两个来源（gold 物理真值 + 独立对抗集）一致，才可宣称 BCS 过门（继承 R69 定义 293-iii 的升格）。

**定义 324（证书 J_DUET）** J_DUET = (J_FLUID, U_coord_before/after, G_coord_p95, k_eff, ρ̄^U, vod_spent, BCS, ρ_leak^U, D_B, ceb_version_hash, duet_ver)。Valid ⇔ Valid(J_FLUID) ∧ k_eff≥k_min ∧ BCS≥τ_BCS ∧ ρ_leak^U≤δ_leak ∧ 协调安全不变式成立。

**定义 325（三级保守退避）** 若 U_coord 与 U_epi 均在预算内消解：λ=λ_floor(U_ale)（resolution bonus）；若任一未消解：λ=λ_floor(U_ale + 未消解项)；若 k_eff<k_min、BCS<τ_BCS 或 ρ_leak^U>δ_leak：λ=λ_floor(U_ale+U_epi+U_coord) 且禁用一切「基准背书」的放松。⇒ FLUID 是「双臂独立、基准可信、永不协调交互」边界；R68 是再往下的「永不交互」边界。

**定义 326（协调-评测对偶）** 第二臂与基准都是「冗余评测器」：臂通过力/碰撞给出物理判决，基准通过任务给出统计判决；二者证据价值同由 (1−ρ) 决定，同受共模故障支配，同需元评测。形式化：把「第二臂」与「基准」统一为证据源 i，其相关矩阵 Σ_ev 与 k_eff 一致适用。于是协调与评测不是两个模块，而是**同一证据代数在两个物理载体上的实例**。

## 2. 关键算法骨架

```python
# IP-264 BCC：耦合流匹配双臂策略（投影到约束流形 + 跨臂条件）
class BimanualCoupledFlow:
    def sample(self, o, K, N_step=2):
        z  = self.trunk(o)
        xs = randn(K, 2 * D)                       # 联合动作块 (a_L, a_R, g)
        for i in range(N_step):
            s  = i / N_step
            v  = self.v(xs, s, z, cross_attn=True)  # a_L 条件含 a_R，反之亦然
            v  = project_tangent(v, xs)             # (I - J_C^+ J_C) v
            xs = xs + (1.0 / N_step) * v
            xs = project_manifold(xs, iters=2)      # 闭链 / 摩擦锥 / 避碰
        return [self.decode(x) for x in xs]         # ξ=(a_L,a_R,g)

# IP-265 CMD：协调模式分解 + 协调间隙
def coordination_decompose(samples, z, mode_head):
    modes   = cluster_joint_trajectories(samples)   # 联合聚类，含 rel_k
    w       = mode_weights(modes)
    U_ale   = sum(w[k] * trace(cov(modes[k])) for k in modes)
    U_epi   = entropy(w) * sep_factor(modes)
    U_coord = sum(w[k] * unilateral_gap(modes[k]) for k in modes)  # 定义 314
    return U_ale, U_epi, U_coord, modes, mode_head(z)

# IP-266 HAD：触觉对话 / 协调仲裁（让、领、交接、探询、重标定）
def coordinate_arbitration(modes, o, budget):
    best = None
    for g in haptic_candidates(modes):              # yield/lead/handover/probe/recal
        if not budget.allow(g) or not c_ras_wm.certify_info(g, o): continue
        voi = mutual_info(force_traj(g), M, o) - cost_had(g)
        if best is None or voi > best.voi: best = (g, voi)
    return best[0] if best and best.voi > 0 else ANCHOR   # 保守锚定，非消极超时

# IP-267 ECD：证据相关性诊断
def evidence_diagnostics(evidence_hist, sources):
    R       = pairwise_failure_corr(evidence_hist, sources)  # E_i 的共同失败
    rho_bar = mean_offdiag(R)
    k_eff   = len(sources) / (1 + (len(sources) - 1) * rho_bar)
    return rho_bar, k_eff, R

# IP-268 VOD：加证据 vs 去相关的统一竞价
def allocate_evidence(rho_bar, k_eff, budget):
    voi_add = marginal_risk_drop_from_source(rho_bar, k_eff) / cost_add
    d, vod  = best_decorrelation(rho_bar, k_eff, budget)     # 定义 319
    if rho_bar > RHO_MAX or vod > voi_add:
        return ('decorrelate', d)                            # 先换一双眼睛
    return ('add_source', None)

# IP-269/270 MEB+BLE：元评测基准（离线）
def meta_evaluate(policy, benchmark):
    cov  = coverage(benchmark, taxonomy=COORD_FAILURE_CLASSES)
    leak = leakage_upper(benchmark, policy)      # 成员推断 + 元数据 + 策略族
    D_B  = abs(benchmark.score(policy) - gold_utility(policy))
    PV   = predictive_validity(benchmark, adv_suite)
    return min(cov, 1 - leak, 1 - D_B, PV)       # BCS

# IP-275 主闭环（继承 FLUID-RAS）
def DUET_RAS_round(M, obs):
    z = M.bcc.trunk(obs)
    K = 1 if M.cmd.mode_head(z) < TAU_MODE else 4
    samples = M.bcc.sample(obs, K)
    U_ale, U_epi, U_coord, modes, _ = M.cmd.coordination_decompose(
        samples, z, M.cmd.mode_head)
    rho_bar, k_eff, _ = M.ecd.evidence_diagnostics(M.history, M.sources)
    # 1) 协调优先：分工不清时先解决「谁做主」，再解决「世界是什么」
    if U_coord > TAU_COORD:
        g = M.had.coordinate_arbitration(modes, obs, M.budget)
    elif U_epi > TAU_EPI:
        g = M.mint.choose_interaction(modes, obs, M.budget)
    else:
        g = None
    coord_resolved = (g is not None and g.kind in ('yield', 'lead', 'handover'))
    epi_resolved   = (g is not None and not coord_resolved)
    # 2) 证据层：rho 高则不迷信多源，先花钱去相关
    mode_ev, d = M.vod.allocate_evidence(rho_bar, k_eff, M.budget)
    if mode_ev == 'decorrelate' and M.c_ras_wm.certify_info(d, obs):
        M.had.execute(d)                      # 重标定 / 换视角 / held-out 基准
    # 3) 三级退避
    U_floor = U_ale \
        + (0.0 if coord_resolved else U_coord) \
        + (0.0 if epi_resolved else U_epi)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    if k_eff < M.k_min or M.meb.bcs < TAU_BCS or M.meb.rho_leak_upper > DELTA_LEAK:
        lam = max(lam, lam_floor(U_ale + U_epi + U_coord))   # 基准不可信 → 不放松
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    m = select_coordinated_mode(modes, lam)
    tau = M.pi_sigma.prefix_dispatch(joint_prefix(m, k)) * lam
    M.vqa_d.submit_async(g, d, U_coord, k_eff, M.meb.bcs)
    return k, lam, m, (U_ale, U_epi, U_coord, k_eff)
```

## 3. 推导

**引理 19（投影耦合流的约束漂移有界）** 设 ℳ_C 为光滑嵌入流形，投影 Proj_{ℳ_C} 在邻域内 L_proj-Lipschitz、速度场 L_v-Lipschitz、步长 h≤1/N。则 N 步投影积分后的约束残差 ‖C(x_N)‖ ≤ (L_C L_proj)(e^{L_v}−1)h·sup‖v‖ + O(h²)，不随 horizon H 指数增长；末步硬投影可把残差压到 κ_C 阶。系：耦合流生成的动作在毫秒级内满足闭链/摩擦/避碰，而非事后滤波修补。

**引理 20（协调间隙的均衡刻画）** 若 U_coord(m*)=0，则联合模式 m* 是双臂条件策略（以 Q_i 为效用）的纯策略纳什均衡；反之，纯策略纳什均衡处 U_coord=0。死锁（双方都让）在「让」不是互为最佳响应时 U_coord>0，且改进方向指向「领」，故可用 HAD 的 g_lead/g_yield 消解；冲突（双方都领）对称。系：U_coord 可用条件流采样 + Q 估计无梯度近似，适合实时。

**引理 21（相关证据的有效独立数下界）** 设 k 个证据源失败指示 E_i 两两相关 ρ̄，则 k_eff=k/(1+(k−1)ρ̄)；若存在共同故障 C（P(C)=ρ_c，C 发生时所有源失败），则任意多数投票的错误率 ≥ ρ_c，与 k 无关。系：R69 引理 18 的 δ_p·ρ^{k−1} 只在 ρ<1 且无共同故障时成立；双臂/基准场景必须显式估计 ρ_c，否则「多源一致」只是同一故障的多次复述。

**引理 22（触觉信道容量与协调消歧）** 共享物体的力信道在力/能量约束下容量为 C_f；若协调模式熵为 H_c，则完全消解需 C_f·T ≥ H_c。当 H_c 大而 C_f 小（物体软、接触差、带宽低）时，交互无利可图，应保守锚定。系：协调交互的可行性由「力信道容量」决定，而不是由「愿不愿意问」决定——这解释了为什么有些死锁只能靠放手/重规划，而不能靠更用力地推。

**定理 18（去相关优先于加源）** 在定义 318–319 与 R69 引理 18 的推广下，风险上界 B(ρ̄,k) 对 k 单调下降但在 ρ̄→1 时饱和于 ρ_c；对 ρ̄ 的边际下降在 ρ̄ 大时严格为正。故存在 ρ*<1，当 ρ̄>ρ* 时 VoD(d) > VoI_add，最优预算分配是**先做去相关动作再考虑加源**。⇒ 「换一双眼睛」优先于「多问一句」。

**定理 19（DUET 严格包含 FLUID 与 R68）** 在 A99–A101（有界曲率、有界速度、条件策略对 Q 有界）下，当两臂证据独立（ρ̄=0）、基准可信（BCS≥τ_BCS）、且协调交互无利可图（VoI_c≤c）时，DUET 逐指令退化为 FLUID；当 U_epi 也不可消解时进一步退化为 R68。任意状态期望风险 ≤ 对应下层；安全侧不做让步，效率侧仅在被证实的独立性上获得 resolution bonus。

**定理 20（基准可信门控的安全性）** 若 BCS<τ_BCS 或 ρ_leak^U>δ_leak，则任何基于该基准的放松被禁用，λ 取最保守档；因此被污染的基准不能降低系统的安全下界。配合元评测「至少两源一致」纪律，单一被投毒基准单独无法改变证书有效性。

## 6. 本轮最大风险

**一句话**：DUET-RAS 的全部可信度建立在「第二只臂与评测基准是相对独立的证据」这一假设上——但两者恰恰最容易与主系统共享同一套标定、同一批训练数据、同一个仿真器；一旦共模相关被低估（尾部样本里它们从未同时失败过），k_eff 会在最需要独立性的时刻被高估，系统会用一个自洽却被污染的基准，给一个自洽却错误的协调策略盖章——**两个证人异口同声，只因为它们共用了一双眼睛。**

**次级风险与缓解**：
1. **投影层在接触瞬态/高曲率处不稳定** → 保守锚定 + 末步硬投影 + 内力上限 + 引理 19 的步长约束；
2. **协调间隙依赖 Q 估计，Q 偏差会把好协调误判为死锁** → Q 校准 + 人类/物理真值 gold 子集 + E302；
3. **ρ̄/ρ_c 从历史共失败估计，尾部共模样本稀疏** → 保守上界 + 聚类 bootstrap + 主动注入共模故障的对抗训练；
4. **泄漏估计本身可能被污染（元评测的元问题）** → 至少两源一致 + 多方法取上界 + 基准版本哈希；
5. **双臂共享算力击穿实时预算** → 自适应 K + 投影只在小 K 路径 + MEB/BCS 全部离线。

## 2. 形式化定义（要点版）

**定义 310（总览与五不变式）** DUET-RAS=(BCC,CMD,HAD,ECD,VOD,MEB,CEB,RAS-WM†)；零学习写继承；协调安全（联合动作整体过认证、切换不扩张包络）；证据独立下限（必须报告 k_eff/ρ̄，k_eff<k_min 不得放松）；基准可信门（BCS/泄漏过门才可进安全侧）；单调降级（DUET→FLUID→R68）。

**定义 311–312（耦合动作与 BCC）** 联合动作 `ξ=(a_L,a_R,g)` 落在闭链/摩擦锥/避碰/共享底座约束流形 `ℳ_C`；速度场切投影 `P_C`，损失 `‖(I−P_C)(v−(x_1−x_0))‖²+λ_c‖J_C v‖²`；采样每步投影 2–3 次牛顿；跨臂交叉注意力给出 `π_L(a_L|a_R)`、`π_R(a_R|a_L)`。

**定义 315（三分解与通道）** `(U_ale,U_epi,U_coord)` 不求和、分通道：U_ale→λ_floor；U_epi→MINT 世界交互；U_coord→HAD 协调动作；未消解项一律回灌 λ_floor。

**定义 316–317（触觉对话与仲裁）** `g ∈ {yield, lead, handover, probe^h, recal}`；共享物体为力信道，`VoI_c(g)=H(M_L,M_R|o)−E[H(M_L,M_R|o,y)]`；无利可图→保守锚定（显式认证的安全保持，而非消极超时）。

**定义 318–319（相关性与去相关）** `k_eff=k/(1+(k−1)ρ̄)`；共模故障下多数投票错误率 ≥ ρ_d；去相关动作 `d` 的价值 `VoD(d)=ΔB/c_d`，与加证据的 `VoI_add` 同台竞价，ρ̄>ρ_max 时去相关优先。

**定义 320–321（基准可信度与泄漏）** `BCS=min{Cov,1−ρ_leak^U,1−D_B,PV}`；Cov 覆盖协调失败分类；D_B 为基准分与 gold 真值的 Goodhart 间隙；泄漏由成员推断、元数据重叠、策略族重叠三源保守融合，并给聚类 bootstrap 上界。

**定义 322–323（CEB 与元评测）** CEB 含 Deadlock/Handover/Symmetry/Load/Drift/Adv 六子基准；MEB 用 gold 子集、泄漏估计、对抗集给 BCS；元评测结论需至少两源一致才可宣称过门。

**定义 324–326（证书/三级退避/对偶）** J_DUET 并入 U_coord、k_eff、ρ̄^U、BCS、ρ_leak^U、D_B、CEB hash；三级退避：全消解→λ_floor(U_ale)，部分未消解→λ_floor(U_ale+未消解)，证据/基准不可信→λ_floor(全部)且禁用基准背书放松；第二臂与基准统一为证据源，共用 Σ_ev 与 k_eff。

```python
# IP-264 BCC：耦合流匹配（投影流形 + 跨臂条件）
class BimanualCoupledFlow:
    def sample(self, o, K, N_step=2):
        z, xs = self.trunk(o), randn(K, 2 * D)
        for i in range(N_step):
            v  = self.v(xs, i/N_step, z, cross_attn=True)
            v  = project_tangent(v, xs)              # (I - J_C^+ J_C) v
            xs = project_manifold(xs + v / N_step, iters=2)
        return [self.decode(x) for x in xs]          # ξ=(a_L,a_R,g)

# IP-265 CMD：协调模式分解
def coordination_decompose(samples, z, mode_head):
    modes = cluster_joint_trajectories(samples); w = mode_weights(modes)
    U_ale = sum(w[k]*trace(cov(modes[k])) for k in modes)
    U_epi = entropy(w) * sep_factor(modes)
    U_coord = sum(w[k]*unilateral_gap(modes[k]) for k in modes)
    return U_ale, U_epi, U_coord, modes, mode_head(z)

# IP-266 HAD：触觉对话 / 协调仲裁
def coordinate_arbitration(modes, o, budget):
    best = None
    for g in haptic_candidates(modes):
        if not budget.allow(g) or not c_ras_wm.certify_info(g, o): continue
        voi = mutual_info(force_traj(g), M, o) - cost_had(g)
        if best is None or voi > best.voi: best = (g, voi)
    return best[0] if best and best.voi > 0 else ANCHOR

# IP-267 ECD：相关性与有效独立数
def evidence_diagnostics(hist, sources):
    R = pairwise_failure_corr(hist, sources)
    rho_bar = mean_offdiag(R)
    return rho_bar, len(sources) / (1 + (len(sources)-1)*rho_bar), R

# IP-268 VOD：加证据 vs 去相关
def allocate_evidence(rho_bar, k_eff, budget):
    voi_add = marginal_risk_drop_from_source(rho_bar, k_eff) / cost_add
    d, vod  = best_decorrelation(rho_bar, k_eff, budget)
    return ('decorrelate', d) if (rho_bar > RHO_MAX or vod > voi_add) else ('add_source', None)

# IP-269/270 MEB+BLE：元评测（离线）
def meta_evaluate(policy, benchmark):
    cov  = coverage(benchmark, COORD_FAILURE_CLASSES)
    leak = leakage_upper(benchmark, policy)          # 三源保守融合
    D_B  = abs(benchmark.score(policy) - gold_utility(policy))
    PV   = predictive_validity(benchmark, adv_suite)
    return min(cov, 1 - leak, 1 - D_B, PV)           # BCS

# IP-275 主闭环（继承 FLUID-RAS）
def DUET_RAS_round(M, obs):
    z = M.bcc.trunk(obs)
    K = 1 if M.cmd.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, U_coord, modes, _ = M.cmd.coordination_decompose(
        M.bcc.sample(obs, K), z, M.cmd.mode_head)
    rho_bar, k_eff, _ = M.ecd.evidence_diagnostics(M.history, M.sources)
    if U_coord > TAU_COORD:
        g = M.had.coordinate_arbitration(modes, obs, M.budget)
    elif U_epi > TAU_EPI:
        g = M.mint.choose_interaction(modes, obs, M.budget)
    else:
        g = None
    coord_resolved = (g is not None and g.kind in ('yield', 'lead', 'handover'))
    epi_resolved   = (g is not None and not coord_resolved)
    mode_ev, d = M.vod.allocate_evidence(rho_bar, k_eff, M.budget)
    if mode_ev == 'decorrelate' and M.c_ras_wm.certify_info(d, obs):
        M.had.execute(d)
    U_floor = U_ale + (0 if coord_resolved else U_coord) + (0 if epi_resolved else U_epi)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    if k_eff < M.k_min or M.meb.bcs < TAU_BCS or M.meb.rho_leak_upper > DELTA_LEAK:
        lam = max(lam, lam_floor(U_ale + U_epi + U_coord))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    m = select_coordinated_mode(modes, lam)
    tau = M.pi_sigma.prefix_dispatch(joint_prefix(m, k)) * lam
    M.vqa_d.submit_async(g, d, U_coord, k_eff, M.meb.bcs)
    return k, lam, m, (U_ale, U_epi, U_coord, k_eff)
```

## 4. 推导

**引理 19（投影耦合流的约束漂移有界）** ℳ_C 光滑、Proj L_proj-Lipschitz、v L_v-Lipschitz、h≤1/N 时，N 步投影积分的约束残差 ≤ `(L_C L_proj)(e^{L_v}−1)h·sup‖v‖ + O(h²)`，不随 horizon 指数增长；末步硬投影压到 κ_C 阶。⇒ 耦合约束可内生于毫秒级生成，而非事后滤波。

**引理 20（协调间隙的均衡刻画）** `U_coord(m*)=0 ⇔ m* 为双臂条件策略的纯策略纳什均衡`；死锁/冲突是 U_coord>0 的两个相反改进方向，可分别用 g_lead/g_yield 消解。⇒ U_coord 可由条件流采样 + Q 估计无梯度近似。

**引理 21（相关证据的有效独立数下界）** `k_eff=k/(1+(k−1)ρ̄)`；存在共模故障 C（P(C)=ρ_c）时，任意多数投票错误率 ≥ ρ_c，与 k 无关。⇒ R69 的 `δ_p·ρ^{k−1}` 只在无共模时成立；双臂/基准必须显式估 ρ_c。

**引理 22（触觉信道容量与协调消歧）** 力信道容量 C_f，协调模式熵 H_c；完全消解需 `C_f·T ≥ H_c`。H_c 大而 C_f 小时交互无利可图，应保守锚定。⇒ 协调交互可行性由信道容量决定，而非「愿不愿意问」。

**定理 18（去相关优先于加源）** `B(ρ̄,k)` 对 k 单调下降但在 ρ̄→1 时饱和于 ρ_c；对 ρ̄ 的边际下降在 ρ̄ 大时严格为正。故存在 ρ*<1，当 ρ̄>ρ* 时 `VoD(d) > VoI_add`，最优分配是先做去相关再考虑加源。⇒ 「换一双眼睛」优先于「多问一句」。

**定理 19（DUET 严格包含 FLUID 与 R68）** 当 ρ̄=0、BCS≥τ_BCS、VoI_c≤c 时，DUET 逐指令退化为 FLUID；U_epi 不可消解时进一步退化为 R68。任意状态期望风险 ≤ 对应下层；安全不让步，效率仅在被证实的独立性上获 resolution bonus。

**定理 20（基准可信门控的安全性）** 若 BCS<τ_BCS 或 ρ_leak^U>δ_leak，则一切基于该基准的放松被禁用、λ 取最保守档；被污染基准不能降低安全下界。配合元评测的两源一致纪律，单一投毒基准无法单独改变证书。

## 7. 本轮最大风险

**一句话**：DUET-RAS 的全部可信度建立在「第二只臂与评测基准是相对独立的证据」这一假设上——但两者恰恰最容易与主系统共享同一套标定、同一批训练数据、同一个仿真器；一旦共模相关被低估（尾部样本里它们从未同时失败过），k_eff 会在最需要独立性的时刻被高估，系统会用一个自洽却被污染的基准，给一个自洽却错误的协调策略盖章——**两个证人异口同声，只因为它们共用了一双眼睛。**

**次级风险与缓解**：投影层在接触瞬态不稳定（保守锚定 + 末步硬投影 + 内力上限）；Q 偏差误判死锁（Q 校准 + gold 子集）；ρ_c 尾部样本稀疏（保守上界 + 聚类 bootstrap + 注入共模故障对抗训练）；泄漏估计自身被污染（两源一致 + 多方法上界 + 版本哈希）；双臂算力击穿实时预算（自适应 K + MEB 离线）。
