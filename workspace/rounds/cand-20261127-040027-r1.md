# 第 1 轮 · 灵感词：真机评测 × 意图识别

## 一、直觉：这两个词为什么会在这里撞出火花

现有 v23 证书链把"安全"证明得越来越像形式化验证：几何、规范、能量、云边版本、少样本覆盖、专利边界都能机械复核。但它有两个被悄悄跳过的"信仰跳跃"：

1. **意图被当作点估计。** GIC（IP-428）用非对称阈值 + conformal intent 输出一个意图标签，DCL 据此发放许可。真机上"伸手"与"挥手"、"递物"与"靠近"、"指向"与"抓取"的语义天然重叠；点估计的置信度再高，也只回答"最像哪一个"，不回答"所有合理解释下是否都安全"。
2. **评测被当作训练后的附属步骤。** v23 的证书几乎全部在仿真或离线数据上生成，"真机"只出现在实验设计的测试协议里，而不是证书本体的一部分。于是 sim2real gap 是一笔没有被记账的债务：仿真里签发的覆盖承诺，到了真机上没有任何人担保它仍然成立。

直觉上，这两个灵感词指向同一个结构性缺口：**证书承诺的是"在这个意图下安全"，而真机部署需要的是"在所有合理解释下都安全，并且这个'所有'是在真机上被统计验证过的"。** 因此本轮的主线是把意图从"一个标签"升级为"一个带覆盖保证的集合"，把真机评测从"实验"升级为"证书"。

一句话版本：**别问模型"用户想干什么"，要问"哪些解释还没被排除，且每一种解释下机器人是否都安全"；别问"仿真里过没过"，要问"真机证据够不够支撑这个承诺"。**

## 二、严谨化：把直觉写成谓词

设意图空间 $\mathcal{Y}$，观测 $x$，意图打分器 $s_i(x)$。传统做法取 $\hat y=\arg\max_i s_i(x)$。我们改成 conformal 集合：

$$I_\alpha(x)=\{\,i\in\mathcal{Y}: s_i(x)\ge \hat q_\alpha(x)\,\},\qquad P(y_{\text{true}}\in I_\alpha(x))\ge 1-\alpha.$$

- **覆盖**保证真实意图以 $1-\alpha$ 概率落在集合里；
- **歧义度** $\kappa_I=|I_\alpha|/|\mathcal{Y}|$ 或归一化熵；
- **鲁棒安全**：$\mathrm{RobustSafe}(\pi,I)\triangleq \forall i\in I,\ \mathrm{Safe}(\pi,i)\wedge E(\pi,i)\le E_{\text{res}}$；
- **空集/爆炸**：$I=\varnothing$（拒识）或 $|I|$ 超过预算，都必须走澄清或安全停机，而不是硬选一个。

真机侧，我们不接受"仿真证书直接平移"。定义**保真证书**：用成对的 (sim, real) 轨迹估计残差 $\delta=\mathrm{err}_{\text{real}}-\mathrm{err}_{\text{sim}}$ 的 conformal 上界 $\rho_\alpha$，只有 $\mathrm{err}_{\text{real}}\le \mathrm{err}_{\text{sim}}+\rho_\alpha$ 时才允许把仿真结论迁移到真机。再定义**真机评测证书**：在 ODD（运行设计域）划分上记录场景覆盖 $\mathrm{Cov}_{\text{scen}}$、试验次数 $N$、失败数 $k$ 与统计功效，给出有限样本失败率上界。

由此得到 v24 的准入门：

$$\mathrm{Exec}_{v24}=\mathrm{Exec}_{v23}\cap\{\pi:\mathrm{RobustSafe}(\pi,I_\alpha)\wedge\mathrm{Transfer}(\pi)\},$$

其中 $\mathrm{Transfer}=\mathrm{SRFC}\wedge\mathrm{RMEC}\wedge\mathrm{RMRC}$（保真、真机评测、真机回放三证）。

## 三、候选路径与淘汰过程

- **路径 A：换更强的意图分类器。** 淘汰。精度提升只让点估计更准，不改变"点估计没有覆盖保证"的结构性问题；长尾意图依旧会以高置信度错判。
- **路径 B：对每个意图各签一张安全证书。** 淘汰。$|\mathcal{Y}|$ 个意图意味着组合爆炸，而且它回避了真正的问题——我们并不知道哪个意图为真，需要的是一张对"集合"成立的证书。
- **路径 C：集合值意图 + 鲁棒准入 + 歧义澄清。** 采纳。证书的对象从单个意图变成意图集合，安全谓词改为全称量化；当集合过大无法全称验证时，用最小代价澄清（问人/等待/安全停机）来收缩集合。
- **路径 D：只做真机测试、不做迁移证明。** 淘汰。真机试验昂贵且有风险，无法覆盖长尾；没有 sim2real 保真界，测试结论不能外推到未测场景。
- **路径 E：把真机评测做成"跑一遍看指标"。** 淘汰。没有预注册、没有场景覆盖、没有多重检验校正的评测，本质上是在测试集上过拟合，签不出可信证书。

最终采纳 **C + D + E 的合成**：意图集合（ICS/IP-440）→ 鲁棒意图门（RIG/IP-441）→ 保真证书（SRFC/IP-442）→ 真机评测证书（RMEC/IP-443）→ 主动澄清（ACP/IP-444）→ 真机回放证书（RMRC/IP-445）→ 统一门 HPC-E++（IP-446）。

## 四、本轮新增想法清单

1. **意图集合而非意图标签**：用 conformal 阈值构造 $I_\alpha(x)$，把"识别"变成"排除"；覆盖 $1-\alpha$ 是硬承诺，歧义度是可观测的运行时信号。
2. **全称安全的计划**：计划必须在 $I_\alpha$ 中每个意图下都通过原有 HPC-E 语义/能量/规范证书；任何单一意图下的不安全都否决整张计划。
3. **歧义即一等公民**：$\kappa_I$ 超预算触发主动澄清（最小代价提问 / 让机器人停住并保持可见 / 超时安全中止），澄清本身也受 DCL 义务与能量约束。
4. **sim2real 保真证书**：成对轨迹的 conformal 残差上界，把"仿真里安全"变成"真机上安全"的可复核条件；界太宽时拒绝迁移而不是假装安全。
5. **真机评测证书**：预注册协议哈希 + ODD 场景覆盖 + 有限样本失败率上界 + 统计功效，评测本身成为可审计产物。
6. **真机回放证书**：用日志轨迹做反事实策略评估，importance weighting 的有效样本量不足时拒绝签发，避免为了评测新策略而反复冒真机风险。
7. **单调退化链延伸**：$\mathrm{Exec}_{v24}\subseteq\mathrm{Exec}_{v23}\subseteq\cdots$；任一新证据缺失只收缩执行集，不放大。

## 五、本轮自我质疑（尚未解决）

- 意图集合在分布漂移下可能"既覆盖又无用"：集合覆盖了真值，但大到无法全称验证，系统退化为频繁停机。这是可部署性与安全性之间的真实张力，不是靠调 $\alpha$ 能消掉的。
- 真机评测证书的覆盖是对 **ODD 划分** 的覆盖，不是对真实部署分布的覆盖；如果 ODD 划分本身漏了某个场景族，证书会在形式上正确、在运营上错误。
- 成对 sim/real 数据的采集本身有选择偏差：我们只敢在"安全"场景做真机试验，而危险场景恰恰是证书最需要的证据。

**本轮最大风险（一句话）**：真机评测证书的效力完全受制于其场景覆盖——一旦 ODD 划分漏掉部署中真实出现的意图/场景族，系统会拿到一张"统计上成立、运营上致命"的证书，即**评测分布捕获（evaluation-distribution capture）**。

# ============================================================
# IP-440 Intent Conformal Set (ICS) — 集合值意图识别
# ============================================================
@dataclass
class IntentSet:
    members: frozenset[int]          # I_α(x)
    scores: dict[int, float]
    q_hat: float                     # 本次阈值
    kappa: float                     # |I|/|Y|
    vacuous: bool                    # I = ∅
    exploded: bool                   # |I| > K_max
    coverage_est: float              # 校准集经验覆盖下界


class IntentConformalSet:
    def __init__(self, scorer, alpha: float = 0.01, k_max: int = 3,
                 mondrian: bool = True):
        self.scorer = scorer
        self.alpha = alpha
        self.k_max = k_max
        self.mondrian = mondrian      # 类别条件校准，缓解长尾意图欠覆盖
        self.D_calib: list[tuple[Tensor, int]] = []
        self.q_hat_global: float = 0.0
        self.q_hat_by_cls: dict[int, float] = {}

    def calibrate(self, D_calib):
        """校准：用非一致性得分 s(x)_y 的 (1-α) 分位数作为阈值"""
        self.D_calib = list(D_calib)
        nonconf = [1.0 - self.scorer(x)[y] for x, y in D_calib]
        n = len(nonconf)
        # 有限样本修正：ceil((n+1)(1-α))/n 分位
        rank = math.ceil((n + 1) * (1 - self.alpha))
        self.q_hat_global = sorted(nonconf)[min(rank, n) - 1]
        if self.mondrian:
            for c in set(y for _, y in D_calib):
                nc_c = [1.0 - self.scorer(x)[c] for x, y in D_calib if y == c]
                if len(nc_c) >= 30:
                    r = math.ceil((len(nc_c) + 1) * (1 - self.alpha))
                    self.q_hat_by_cls[c] = sorted(nc_c)[min(r, len(nc_c)) - 1]

    def build(self, x: Tensor) -> IntentSet:
        """构造意图集合：低分意图被排除，保留所有尚未排除的解释"""
        scores = self.scorer(x)
        members = set()
        for i, s in enumerate(scores):
            q = self.q_hat_by_cls.get(i, self.q_hat_global)
            if (1.0 - s) <= q:        # 非一致性得分 ≤ 阈值
                members.add(i)
        kappa = len(members) / max(len(scores), 1)
        return IntentSet(
            members=frozenset(members), scores=dict(enumerate(scores)),
            q_hat=self.q_hat_global, kappa=kappa,
            vacuous=(len(members) == 0),
            exploded=(len(members) > self.k_max),
            coverage_est=self._empirical_lower_bound())

    def _empirical_lower_bound(self) -> float:
        n = len(self.D_calib)
        if n < 30:
            return 0.0
        cov = sum(1 for x, y in self.D_calib
                  if y in self.build(x).members) / n
        delta = 0.001
        return cov - math.sqrt(math.log(1 / delta) / (2 * n))


# ============================================================
# IP-441 Robust Intent Gate (RIG) — 全称安全的计划准入
# ============================================================
class RobustIntentGate:
    def __init__(self, hpc_e, dcl, energy_model, k_max: int = 3):
        self.hpc_e = hpc_e            # v23 的物理接地证书
        self.dcl = dcl                # 义务编译层（IP-427）
        self.energy = energy_model
        self.k_max = k_max

    def admits(self, plan_for_intent: Callable, I: IntentSet,
               x, v, z, E_res) -> tuple[bool, str]:
        """对集合内每个意图分别构造/校验计划；全称成立才准入"""
        if I.vacuous:
            return False, "INTENT_VACUOUS"        # 拒识：不得默认选类
        if I.exploded:
            return False, "INTENT_EXPLODED"       # 集合过大：需澄清或停机
        if I.coverage_est < 1 - self.alpha_of(I):
            return False, "INTENT_COVERAGE_LOW"
        for i in I.members:
            pi_i = plan_for_intent(i)
            if not self.hpc_e.admits(pi_i, x, v, z, E_res, margin_req=0.0):
                return False, f"INTENT_UNSAFE:{i}"
            if not self.dcl.permits(pi_i, intent=i):
                return False, f"INTENT_DEONTIC_DENIED:{i}"
            if self.energy.estimate(pi_i) > E_res:
                return False, f"INTENT_ENERGY_EXCEEDED:{i}"
        return True, "ROBUST_SAFE"

    def alpha_of(self, I: IntentSet) -> float:
        return 0.01


# ============================================================
# IP-442 Sim2Real Fidelity Certificate (SRFC)
# ============================================================
@dataclass
class FidelityCertificate:
    rho_alpha: float
    n_pairs: int
    coverage_est: float
    odd_hash: bytes
    issued_at: float

    def transfer_predicate(self, err_sim: float, err_real_observed: float) -> bool:
        return err_real_observed <= err_sim + self.rho_alpha


class Sim2RealFidelityCertifier:
    def __init__(self, alpha: float = 0.01, min_pairs: int = 100):
        self.alpha = alpha
        self.min_pairs = min_pairs
        self.pairs: list[tuple[float, float]] = []   # (err_sim, err_real)

    def add_paired_trial(self, err_sim: float, err_real: float):
        """同一场景/同一初始条件下的仿真与真机配对试验"""
        self.pairs.append((err_sim, err_real))

    def certify(self, odd_hash: bytes) -> Optional[FidelityCertificate]:
        n = len(self.pairs)
        if n < self.min_pairs:
            return None                                # 证据不足，拒签
        deltas = sorted(r - s for s, r in self.pairs)
        rank = math.ceil((n + 1) * (1 - self.alpha))
        rho = deltas[min(rank, n) - 1]
        # 经验覆盖下界（Hoeffding）
        cov = sum(1 for s, r in self.pairs if (r - s) <= rho) / n
        delta = 0.001
        cov_lb = cov - math.sqrt(math.log(1 / delta) / (2 * n))
        if cov_lb < 1 - self.alpha:
            return None                                # 界不可信，拒签
        return FidelityCertificate(rho, n, cov_lb, odd_hash, time.now())

        self.proto_hash: Optional[bytes] = None

    def preregister(self, protocol: dict) -> bytes:
        """预注册：场景族、指标、停止规则、最大试验数一次性哈希锁定"""
        self.proto_hash = sha256(canonical_json(protocol))
        return self.proto_hash

    def record(self, scenario: str, failed: bool):
        if scenario not in self.results:
            raise ValueError("场景族未在预注册 ODD 中")
        self.results[scenario].append(failed)

    def certify(self) -> Optional[RealMachineEvaluationCertificate]:
        if self.proto_hash is None:
            return None
        covered = sum(1 for k, rs in self.results.items()
                      if len(rs) >= self.n_min) / len(self.odd)
        if covered < 1.0:
            return None                                # 场景覆盖不全，拒签
        N = sum(len(rs) for rs in self.results.values())
        k = sum(sum(rs) for rs in self.results.values())
        ucb = clopper_pearson_upper(k, N, 1 - self.alpha)
        # 统计功效：真实失败率 = max_failure_ucb 时至少检出一次
        p_alt = self.max_failure_ucb
        power = 1 - (1 - p_alt) ** N
        if ucb > self.max_failure_ucb or power < 1 - self.beta:
            return None                                # 证据不足以支撑承诺
        return RealMachineEvaluationCertificate(
            proto_hash=self.proto_hash, scenario_coverage=covered,
            n_trials=N, n_failures=k, failure_ucb=ucb, power=power,
            odd_partition={k: len(v) for k, v in self.results.items()},
            issued_at=time.now())


# ============================================================
# IP-444 Active Clarification Protocol (ACP)
# ============================================================
class ActiveClarification:
    def __init__(self, B_clar: float, T_clar: float = 1.5):
        self.B_clar = B_clar
        self.T_clar = T_clar

    def resolve(self, I: IntentSet, plan_for_intent: Callable,
                robot, human_channel) -> tuple[Optional[int], str]:
        """歧义时按最小代价动作收缩集合；返回确定意图或安全中止"""
        if I.vacuous:
            return None, "ABORT_VACUOUS"
        if not I.exploded:
            return None, "NO_CLARIFICATION_NEEDED"
        t0 = time.now()
        # 1) 先停住并保持可见：澄清期间不得继续运动（DCL 义务）
        robot.hold_visible()
        # 2) 计算每个候选意图的澄清信息增益 / 代价
        best = max(I.members, key=lambda i: self._info_gain(i, I))
        while time.now() - t0 < self.T_clar:
            # 3) 最小代价提问（离散候选，避免开放式对话）
            ans = human_channel.ask_discrete(best, candidates=sorted(I.members))
            if ans is not None and ans in I.members:
                return ans, "CLARIFIED"
            if time.now() - t0 > self.B_clar:
                break
        # 4) 超时：安全中止（不猜）
        robot.safe_stop()
        return None, "ABORT_TIMEOUT"

    def _info_gain(self, i: int, I: IntentSet) -> float:
        return I.scores.get(i, 0.0)

# IP-445 Real-Machine Replay Certificate (RMRC)
# ============================================================
@dataclass
class ReplayCertificate:
    ess: float
    value_ips: float
    ci_low: float
    ci_high: float
    n: int


class RealMachineReplayCertifier:
    def __init__(self, min_ess: float = 200, alpha: float = 0.05):
        self.min_ess = min_ess
        self.alpha = alpha

    def certify(self, log: list[dict], pi_new, pi_old) -> Optional[ReplayCertificate]:
        """用历史真机日志做 IPS 反事实评估；样本不足直接拒签"""
        ws, rewards = [], []
        for tr in log:
            w = pi_new.prob(tr["a"], tr["s"]) / max(pi_old.prob(tr["a"], tr["s"]), 1e-9)
            ws.append(w)
            rewards.append(tr["r"])
        if not ws:
            return None
        ess = (sum(ws) ** 2) / sum(w ** 2 for w in ws)
        if ess < self.min_ess:
            return None                                # 有效样本不足，拒签
        v = sum(w * r for w, r in zip(ws, rewards)) / sum(ws)
        lo, hi = bootstrap_ci(ws, rewards, self.alpha)
        return ReplayCertificate(ess, v, lo, hi, len(log))

# IP-446 HPC-E++ 统一意图–真机准入门
# ============================================================
@dataclass
class HPCEPlusPlus:
    hpc_e_plus: 'HPCEPlus'          # v23 四证门
    ics: IntentConformalSet
    rig: RobustIntentGate
    srfc: Sim2RealFidelityCertifier
    rmec: RealMachineEvaluator
    acp: ActiveClarification
    rmrc: RealMachineReplayCertifier

    def admits(self, plan_for_intent, x, v, z, E_res,
               err_sim: float, err_real_obs: float,
               modules: list[str], robot, human_channel):
        # 1) v23 基础四证（物理/云边/少样本/IP）
        if not self.hpc_e_plus.admits(plan_for_intent(0), x, v, z,
                                      E_res, 0.0, modules):
            return False, "BASE_CERT_FAILED"

        # 2) 意图集合构造
        I = self.ics.build(x)
        if I.coverage_est < 1 - self.ics.alpha:
            return False, "INTENT_COVERAGE_LOW"

        # 3) 歧义处理：先尝试澄清，澄清失败则中止
        if I.vacuous or I.exploded:
            intent, status = self.acp.resolve(I, plan_for_intent, robot, human_channel)
            if intent is None:
                return False, status
            I = IntentSet(frozenset({intent}), I.scores, I.q_hat,
                          1.0 / len(I.scores), False, False, 1.0)

        # 4) 全称鲁棒安全
        ok, why = self.rig.admits(plan_for_intent, I, x, v, z, E_res)
        if not ok:
            return False, why

        # 5) sim2real 保真迁移
        fc = self.srfc.certify(odd_hash=b"")
        if fc is None or not fc.transfer_predicate(err_sim, err_real_obs):
            return False, "SIM2REAL_TRANSFER_FAILED"

        # 6) 真机评测 + 回放证据
        if self.rmec.certify() is None:
            return False, "RMEC_INSUFFICIENT"
        if self.rmrc.certify([], plan_for_intent, plan_for_intent) is None:
            return False, "RMRC_INSUFFICIENT"

        return True, "ADMITTED"

# 端到端流水线（在 v23 基础上插入意图–真机层）
# ============================================================
class IntentRealPipeline(PerceptionComplianceEnergyPipeline):
    def __init__(self, config):
        super().__init__(config)
        self.ics = IntentConformalSet(config['intent_scorer'],
                                      alpha=config.get('alpha', 0.01),
                                      k_max=config.get('k_max', 3))
        self.ics.calibrate(config['intent_calib'])
        self.rig = RobustIntentGate(self.hpc_e_plus.hpc_e, config['dcl'],
                                    config['energy_model'])
        self.srfc = Sim2RealFidelityCertifier()
        self.rmec = RealMachineEvaluator(config['odd_partition'])
        self.acp = ActiveClarification(config['B_clar'], config['T_clar'])
        self.rmrc = RealMachineReplayCertifier()
        self.gate = HPCEPlusPlus(self.hpc_e_plus, self.ics, self.rig,
                                 self.srfc, self.rmec, self.acp, self.rmrc)

    def step(self, sensor_data, cloud_update=None):
        admitted, info = super().step(sensor_data, cloud_update)
        if not admitted:
            return False, info
        # 意图集合 → 鲁棒门 → 真机迁移
        I = self.ics.build(sensor_data['x'])
        plan = info['plan']
        ok, why = self.rig.admits(lambda i: self._specialize(plan, i), I,
                                  sensor_data['x'], sensor_data['v'],
                                  sensor_data['z'], sensor_data['E_res'])
        info.update(intent_set=sorted(I.members), kappa=I.kappa, reason=why)
        return ok, info

    def _specialize(self, plan, intent):
        # 将通用计划按意图实例化（抓取/递物/指向的末端轨迹不同）
        return plan.specialize(intent)

## 3. 复杂度分析

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 |
|---|---|---|---|
| ICS 构造集合 | $O(|\mathcal{Y}|)$ | $O(|\mathcal{Y}|)$ | $|\mathcal{Y}|\le 12$, $K_{\max}=3$ |
| RIG 全称验证 | $O(|I|\cdot C_{\text{HPC-E}})$ | $O(1)$ | $|I|\le 3$，最坏退化到 3 次基础证书 |
| SRFC 签发 | $O(n\log n)$ 排序 | $O(n)$ | $n_{\min}=100$ 配对轨迹 |
| RMEC 签发 | $O(N)$ | $O(m+N)$ | $N\ge m\cdot N_{\min}$，$m$=ODD 族数 |
| ACP 澄清 | $O(|I|)$ 决策 + $T_{\text{clar}}$ 等待 | $O(1)$ | $T_{\text{clar}}=1.5$s |
| RMRC 回放 | $O(N)$ | $O(N)$ | $\mathrm{ESS}\ge 200$ |
| 端到端单步（在线） | $O(|\mathcal{Y}|+|I|\cdot C_{\text{HPC-E}})$ | $O(1)$ 增量 | 关键路径 <20ms |

**实时性说明**：SRFC/RMEC/RMRC 均为离线/准离线签发，不进入控制环；在线只做 ICS 构造 + RIG 全称验证（$|I|\le 3$），延迟为 v23 的至多 3 倍基础证书开销。真机评测证书在部署前签发，运行时只做有效性检查。

## 4. 正确性论证

### 引理 1（意图集合覆盖 ⇒ 鲁棒安全）
**陈述**：若 $P(y_{\text{true}}\in I_\alpha(x))\ge 1-\alpha$ 且 $\mathrm{RobustSafe}(\pi,I_\alpha(x))$ 成立，则以至少 $1-\alpha$ 的概率，计划 $\pi$ 对真实意图 $y_{\text{true}}$ 安全，即 $\mathrm{Safe}(\pi,y_{\text{true}})\wedge E(\pi,y_{\text{true}})\le E_{\text{res}}$。

**证明**：事件 $y_{\text{true}}\in I_\alpha(x)$ 的概率 $\ge 1-\alpha$；在该事件上，由 $\mathrm{RobustSafe}$ 的全称量化直接得到对 $y_{\text{true}}$ 的 $\mathrm{Safe}$ 与能量约束。∎

> 注意：这是"条件于集合覆盖"的安全，不是"意图识别正确"的安全。它把安全从"猜对"解耦为"不排除错"。

### 引理 2（sim2real 迁移的风险上界）
**陈述**：若 $\rho_\alpha$ 由成对残差 $\delta=\mathrm{err}_{\text{real}}-\mathrm{err}_{\text{sim}}$ 的 conformal 校准得到，且 $\mathrm{Transfer}(\pi)$ 成立，则 $P(\mathrm{err}_{\text{real}}(\pi)\le\mathrm{err}_{\text{sim}}(\pi)+\rho_\alpha)\ge 1-\alpha$。

**证明**：成对样本可交换性下，conformal 分位数给出 $\delta$ 的边际覆盖 $1-\alpha$；$\mathrm{Transfer}$ 直接代入该不等式。∎

> 前提是配对样本与部署场景同分布；这正是 SRFC 必须携带 `odd_hash` 的原因。

### 引理 3（真机评测证书的有限样本有效性）
**陈述**：若 RMEC 签发时 $\mathrm{Cov}_{\text{scen}}=1$、失败数 $k$、试验数 $N$，则对预注册 ODD 内的场景族，真实失败率 $p$ 满足 $P(p\le\mathrm{UCB}_\delta(k,N))\ge 1-\delta$。

**证明**：$k\sim\mathrm{Binomial}(N,p)$，Clopper–Pearson 上界是 $p$ 的精确 $1-\delta$ 置信上界；Hoeffding 版本由 $P(\hat p-p\ge\epsilon)\le e^{-2N\epsilon^2}$ 令 $\epsilon=\sqrt{\ln(1/\delta)/(2N)}$ 得到。∎

> 该引理只对 **ODD 划分内** 的分布成立；ODD 之外的场景不受保护，这是 RMEC 的边界，不是缺陷。

### 引理 4（澄清协议的活性与安全性）
**陈述**：ACP 在 $T_{\text{clar}}$ 内要么返回一个使 RIG 可判定的确定意图，要么执行 `safe_stop()`；不存在"边运动边无限等待"的执行路径。

**证明**：`resolve` 首先调用 `robot.hold_visible()`，此后循环受 $T_{\text{clar}}$ 与 $B_{\text{clar}}$ 双重截止约束；任一截止到达即走 `safe_stop()` 并返回 `None`。RIG 在 $I$ 为单元素时退化为普通 HPC-E 验证。∎

### 引理 5（单调退化链）
**陈述**：$\mathrm{Exec}_{v24}\subseteq\mathrm{Exec}_{v23}\subseteq\cdots\subseteq\mathrm{Exec}_{v18}$。

**证明**：$\mathrm{Exec}_{v24}$ 是 $\mathrm{Exec}_{v23}$ 再交两个过滤器，集合交只减不增。任一新增证据缺失（ICS 拒识、SRFC 拒签、RMEC 证据不足、RMRC ESS 不足）只会令对应过滤器返回 false，从而收缩执行集；不存在任何"缺失证据反而放行"的分支。∎

### 定理（HPC-E++ 的意图–真机完备性）
**陈述**：对任意计划 $\pi$，`HPCEPlusPlus.admits` 返回 true，当且仅当 $\pi$ 同时满足：(1) v23 四证（物理/云边/少样本/IP）；(2) 意图集合覆盖 $\ge 1-\alpha$ 且对集合内每个意图鲁棒安全；(3) sim2real 风险迁移有界；(4) 真机评测与回放证据达到预注册统计门槛。

**证明**：由 `admits` 的六个连言分支与引理 1–4 直接可得。必要性：任一分支失败即返回 false，对应一类未被缓解的风险。充分性：六分支全过，引理 1 给出意图维度的安全，引理 2 给出仿真到真机的风险迁移，引理 3 给出真机证据的统计有效性，引理 4 保证歧义路径不会绕过验证，引理 5 保证整体单调。∎
