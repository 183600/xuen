# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC IP-153~160；灵感驱动研究循环第 1 轮／全局第 61 轮；本轮灵感：「机器人操作系统」×「Isaac Sim」）

> 第 60 轮把「场景→意图→约束→阻抗→执行→EV-exec→场景更新」闭合成 SGEC。但这条链仍建立在**三个未被审视的假设**上：
> 1. **证据只绑定控制器，不绑定承载控制器的计算图**：EPIR 处理了 ROS 消息的乱序/丢失，却默认「产生证据的节点图」不变。ROS 2 的节点生命周期、QoS、executor、remap 都可动态改写；一次 best-effort 降级或节点重启，会让同一份 K_safe 的时序前提失效，而 EV-exec 仍被当作同一系统的证据——造成「图上下文坍塌」。
> 2. **场景先验只能从真机少量接触学，不能安全地预先探索**：π_scene 与 SIC 依赖真实接触；湿滑、楼梯边缘、柔性障碍等长尾危险场景无法在真机上安全采样，导致先验在分布外既稀疏又过度自信。
> 3. **仿真证据与真机证据没有「换算汇率」**：Isaac Sim 能并行生成海量场景/接触/故障反事实，但 sim≠real；若无转移证书，仿真证据要么被浪费，要么被过度信任——把「仿真里的安全」洗成「真机上的证书」，即「证书洗白」。

## 0. 直觉与动机

**灵感 1（机器人操作系统 → 执行图契约 REGC）**
直觉：安全证书不该只回答「K 是否安全」，而应回答「在**哪张计算图**上、以**哪种 QoS 与调度**运行 K 才安全」。ROS 图不是管道，而是安全前提的一部分：节点类型、话题 QoS、回调组/executor、生命周期、参数哈希共同决定了 τ_response 与因果序。关键洞见：**把 ROS 计算图升格为一等安全制品**——为关键子图定义带 QoS 偏序与可调度性判据的「执行图契约」，用 Merkle 指纹给每次执行打上「图纪元」；图一变，证书与证据即进入隔离，直到重新准入。

**灵感 2（机器人操作系统 → 图溯源证据 GPE）**
直觉：EV-exec 证明「机器人做了什么」，却没说「是哪张图让它这样做的」。节点重启、QoS 降级、executor 重排都会让「同一段证据」失去可比性。关键洞见：**证据必须携带图纪元、QoS 快照与 executor 血统**；不同图纪元的证据属于不同「证据上下文」，只能分别认证，不能拼接成一张证书——从根上杜绝跨上下文外推。

**灵感 3（Isaac Sim → 证据锻造厂 ISEF）**
直觉：Isaac Sim 不是「训练玩具」，而是可编程、可并行、可注入故障的**证据锻造厂**：给定场景 z 与待检验的 K，GPU 并行跑万级 episode，主动制造打滑、碰撞、执行器卡滞等真机上不敢做的反事实。关键洞见：**仿真证据必须带完整溯源**（seed、USD 资产哈希、物理参数、域随机化区间、ROS 图覆盖项、sim clock 配置），否则不可复现、不可审计、不可转移。

**灵感 4（Isaac Sim → 仿真到现实证据转移 SRET）**
直觉：仿真证据与真机证据之间需要「汇率」而非「信仰」。把现实差距建模为特征分布间的 Wasserstein 球：P_real ∈ B_r(P_sim)。若损失 ℓ_K 关于特征的 Lipschitz 常数为 L_ℓ，则对任意 K 有 E_real[ℓ_K] ≤ E_sim[ℓ_K] + L_ℓ·r（Kantorovich–Rubinstein 对偶）。关键洞见：**仿真证据只能是「先验证据」，真机锚点才是「证书证据」**；r 由少量真机锚点校准，仿真只能在转移界内收窄 K，不能把证书扩到界外。

**灵感 5（机器人操作系统 × Isaac Sim → 孪生接地闭环 TGEL + 双胞胎预算 PCE++++++）**
直觉：Isaac Sim 的 ROS bridge 让**同一张 ROS 图**既能跑在仿真也能跑在真机（software-in-the-loop）。于是可以做「仿真探索、真机确认」的覆盖导向场景课程 CDSC：仿真优先轰炸证书盲区与安全边界，真机只验证「决策价值最高」的少数单元；再用孪生一致性契约 SRPC 校验 sim/real 图与轨迹是否同构。最终形成 TGEL：图准入→仿真正验→转移校准→第 60 轮 SSM/CIEC/EEIS/ERTC→执行→图溯源证据→图纪元监控→覆盖图更新。预算拓展为双胞胎预算 B_twin=(B_sim,B_transfer,B_graph,B_cog,B_exec)，任一耗尽即回退到保守静态图与通用先验。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（ROS 执行图契约 REGC）** 在 t 时刻的 ROS 2 计算图 G_t=(N,E,Θ,Λ)：
- **N**：节点及其生命周期状态（Unconfigured / Inactive / Active / Finalized）
- **E**：话题/服务/动作边，每条边带 QoS 档 q_e=(rel, dur, depth, deadline, lifespan, liveliness)
- **Θ**：回调组→executor/线程/优先级的映射
- **Λ**：launch 参数与节点参数
契约 C_G=(G_spec, H_G, Q*, A_G, I_G, [t₀,t₁])，其中：
- **图指纹** H_G = Merkle(SHA256(规范化的 N_type, Λ, {q_e}, Θ))，运行时数据不进入指纹
- **QoS 偏序** q ⊒ q*：rel: RELIABLE ⊒ BEST_EFFORT；dur: TRANSIENT_LOCAL ⊒ VOLATILE；depth ≥ depth*；deadline ≤ deadline*；lifespan ≥ lifespan*；liveliness: AUTOMATIC ⊒ MANUAL_BY_NODE
- **关键链可调度判据**：对关键回调链 i，R_i = C_i + Σ_{j∈hp(i)} ⌈R_i/T_j⌉·C_j + B_i ≤ D_i，且 DDS deadline D_e ≥ R_e；不满足即拒绝准入
- **准入**：Adm(G_t,C_G) = [H(G_t)=H_G] ∧ [∀e∈E_crit: q_e ⊒ q_e*] ∧ [sched_test(G_t)=true] ∧ [h_Λ=H(Λ)]
- **图纪元**：e = H(G_t) 保持不变的极大时间区间；任何指纹变化开启新纪元

**定义 162（图溯源证据 GPE）** 证据消息 M=(t, seq, content, hash, h_G, q_snapshot, θ_lineage, h_Λ)。可采信谓词：
V_ev(M) = [EPIR 的 seq/hash 链完整] ∧ [h_G=H(C_G)] ∧ [q_snapshot ⊒ q*] ∧ [t∈[t₀,t₁]] ∧ [端到端时延≤τ_response]。
证据超图 E=(V_ev, E_causal, E_epoch)：
- **E_causal**：EPIR 的 happens-before 关系
- **E_epoch**：证据→图纪元归属
- **可比性**：M_i ≍ M_j 当且仅当 h_G^i = h_G^j；否则不可聚合成同一证书
- **图上下文坍塌**：若在 h_G 不同时仍拼接/外推证据，则判定证书无效

**定义 163（Isaac Sim 证据锻造厂 ISEF）** episode ω=(seed, asset_hashes, ξ_phys, DR_ranges, graph_override, sim_clock)。其中 ξ_phys=(μ, m, damping, actuator_gain, sensor_noise)。锻造算子 Forge(gap, B_sim)→{EV_sim(ω)}：
- **目标**：最大化证据缺口覆盖与安全边界附近的失败发现
- **仿真风险估计**：L_sim(K|z) = Σ_ω w_ω·ℓ(K,EV_sim(ω)) / Σ_ω w_ω
- **边界估计**：b(z) = min_ω margin(K,EV_sim(ω))
- **溯源**：每个 EV_sim 记录完整 ω 与求解器配置，保证可复现、可审计

**定义 164（仿真到现实证据转移 SRET）** 令特征 x∈R^d 为力/位移/滑移/时延的统计量，P_sim、P_real 为其分布。假设 W₁(P_real,P_sim) ≤ r，ℓ_K 满足 |ℓ_K(x)−ℓ_K(x′)| ≤ L_ℓ‖x−x′‖，则
```
E_real[ℓ_K] ≤ E_sim[ℓ_K] + L_ℓ·r
```
- **锚点校准**：真机锚点集 A={(x_i^sim,x_i^real)}，r̂ = 经验 W₁ + bootstrap 上置信界
- **转移证书**：T(K)=(K, L_sim(K), L_ℓ·r̂, α, n_anchor)
- **转移安全集**：K_safe^real = {K : L_sim(K)+L_ℓ·r̂ ≤ ε_safe} ∩ K_safe^base
- **单调性**：n_anchor↑ ⇒ r̂↓（同维数率 O(n^{−1/d})）⇒ K_safe^real 单调扩张，但永不超过 K_safe^base
- **证据等级**：仿真证据只进先验，真机锚点才进证书

**定义 165（覆盖导向场景课程 CDSC）** 覆盖单元 u=(z,I,E_cell)，覆盖图 Γ(u)=(n_real,n_sim,b(u),r̂(u))。每个候选场景 z 覆盖单元集合 Cov(z)⊆U。覆盖函数 F(S)=|∪_{z∈S} Cov(z)| 单调子模。选择：
```
z* = argmax_{z∉S} [Novelty(z)·BoundaryProx(z)·TransferValue(z)] / Cost_sim(z)
```
- **Novelty(z)** = dist(z,S)（学习度量下到已访问场景的最近距离）
- **BoundaryProx(z)** = exp(−|b(z)−b_target|/σ_b)（贴近失败边界）
- **TransferValue(z)** = E[Δcov_real(z)]·(1−1/(1+r̂(z)))
- **分工**：仿真先跑，真机只确认 argmax 决策价值的少量单元；纯覆盖贪心 ≥ (1−1/e)·OPT

**定义 166（孪生一致性契约 SRPC）** 同一 ROS 图在 sim/real 运行，定义：
```
Parity(real,sim) = [H_G^real = H_G^sim mod Δ_sim]
                 ∧ [关键话题序列在 replay 下语义等价]
                 ∧ [D_W(τ_real,τ_sim) ≤ ε_par]
```
- **Δ_sim**：允许的 sim-only 覆盖（sim clock、物理参数、传感器噪声）
- **D_W**：轨迹/力距离（Wasserstein 或 DTW）
- **失配处理**：Parity=false ⇒ 该场景仿真→真机转移失效，r̂ 膨胀或拒绝；记录「孪生失配」证据

**定义 167（孪生接地闭环 TGEL）** 算子 TGEL(M, z, I, δ_f_req)：
```
① REGC.admit(M.graph) → (H_G, epoch) or QUARANTINE
② CDSC.select(gaps) → Z_sim; ISEF.forge(Z_sim, B_sim) → {EV_sim}, π_sim
③ SRET.calibrate(A) → r̂; K_safe ← {K: L_sim(K)+L_ℓ·r̂ ≤ ε_safe} ∩ K_safe^base
④ SSM/CIEC: π_sim 作为场景先验; C_intent ← ϕ(I); ERTC.lock(C_intent)
⑤ EEIS.compile(delta_f_req, fused, ξ_exec, Z_env, π_sim) → K_safe.best
⑥ Dispatch + Execute + wait_contact
⑦ EV-exec ← build(); M ← GPE.tag(EV-exec, h_G, q_snapshot, θ_lineage); EPIR.append(M)
⑧ if REGC.epoch_changed(): QUARANTINE post-drift evidence; goto ①
⑨ SRPC.check(real, sim); CDSC.update(Γ); SRET.update(r̂, A)
⑩ Return (K_safe, J_twin, Γ, B_twin.status)
```

**定义 168（双胞胎预算 PCE++++++）** B_twin=(B_sim, B_transfer, B_graph, B_cog, B_exec)：
- **B_sim** = (episodes, GPU_time, fidelity_level)

### IP-161 REGC（ROS 执行图契约）

```python
class ROSExecutionGraphContract:
    def __init__(self, spec, critical_edges, deadlines):
        self.spec = spec
        self.critical_edges = critical_edges
        self.deadlines = deadlines
        self.epoch = None

    def fingerprint(self, graph):
        canon = {
            'nodes': sorted([(n.type, n.lifecycle_default) for n in graph.nodes]),
            'params': sorted(graph.params.items()),
            'qos': sorted([(e.topic, e.qos.as_tuple()) for e in graph.edges]),
            'executors': sorted(graph.callback_groups.items()),
        }
        return merkle_sha256(json.dumps(canon, sort_keys=True))

    def qos_dominates(self, q, q_star):
        return (REL_ORDER[q.rel] >= REL_ORDER[q_star.rel] and
                DUR_ORDER[q.dur] >= DUR_ORDER[q_star.dur] and
                q.depth >= q_star.depth and
                q.deadline <= q_star.deadline and
                q.lifespan >= q_star.lifespan and
                LIVE_ORDER[q.liveliness] >= LIVE_ORDER[q_star.liveliness])

    def schedulable(self, graph):
        for chain in graph.critical_chains():
            R = chain.C
            changed = True
            while changed:
                changed = False
                for j in chain.higher_priority():
                    R_new = chain.C + sum(math.ceil(R / t.period) * t.C
                                          for t in chain.higher_priority()) + chain.B
                    if R_new > R:
                        R, changed = R_new, True
            if R > self.deadlines[chain.id]:
                return False
        return all(e.qos.deadline >= self.response_bound(e) for e in graph.edges)

    def admit(self, graph):
        h = self.fingerprint(graph)
        ok = (h == self.spec.expected_hash
              and all(self.qos_dominates(e.qos, self.spec.q_star[e.topic])
                      for e in self.critical_edges)
              and self.schedulable(graph)
              and graph.param_hash() == self.spec.param_hash)
        if ok:
            self.epoch = h
        return ok, h

    def epoch_changed(self, graph):
        return self.fingerprint(graph) != self.epoch
```

```python
class GraphProvenancedEvidence:
```

### IP-164 SRET（仿真到现实证据转移）

```python
class SimToRealEvidenceTransfer:
    def __init__(self, lipschitz_loss):
        self.L = lipschitz_loss
        self.r = None

    def calibrate(self, anchors, alpha=0.05):
        sim_feats = [a.sim for a in anchors]
        real_feats = [a.real for a in anchors]
        emp = wasserstein1(sim_feats, real_feats)
        boot = bootstrap_upper(sim_feats, real_feats, alpha)
        self.r = emp + boot
        return self.r

    def safe_set(self, K_candidates, sim_risk, eps_safe):
        return [K for K in K_candidates
                if sim_risk(K) + self.L * self.r <= eps_safe]

    def certificate(self, K, sim_risk, n_anchor, alpha=0.05):
        return TransferCert(K, sim_risk, self.L * self.r, alpha, n_anchor)
```

### IP-165 CDSC（覆盖导向场景课程）

```python
class CoverageDirectedSceneCurriculum:
    def select(self, candidates, visited, coverage, budget):
        scored = []
        for z in candidates:
            if z in visited:
                continue
            novelty = self.metric.dist(z, visited)
            prox = math.exp(-abs(coverage.boundary(z) - self.b_target) / self.sigma)
            transfer = coverage.expected_real_gain(z) * (1 - 1/(1 + coverage.r_hat(z)))
            scored.append((novelty * prox * transfer / z.cost, z))
        return max(scored)[1]

    def update(self, z, sim_ev, real_ev=None):
        self.coverage.mark_sim(z, sim_ev)
        if real_ev is not None:
            self.coverage.mark_real(z, real_ev)
```

```python
class TwinBudget:
    def __init__(self, sim_eps, anchors, graph_reconfig, cog_budget, exec_budget):
        self.B_sim = sim_eps
        self.B_transfer = anchors
        self.B_graph = graph_reconfig
        self.B_cog = cog_budget
        self.B_exec = exec_budget
        self.used = {'sim': 0, 'transfer': 0, 'graph': 0}

    def degrade(self):
        if self.used['graph'] >= self.B_graph:
            return 'freeze_graph_static_certificate'
        if self.used['transfer'] >= self.B_transfer:
            return 'inflate_reality_gap_conservative_K'
        if self.used['sim'] >= self.B_sim:
            return 'freeze_sim_prior_in_domain_only'
        return self.B_cog.degrade() or self.B_exec.degrade()
```

1. **图上下文可靠性**：任何被采信的证据都属于已准入图纪元；图漂移后证据被隔离直到重新准入，证书不能跨纪元外推。
2. **转移可靠性**：∀K∈K_safe^real，P(E_real[ℓ_K] ≤ ε_safe) ≥ 1−α；仿真证据不能把证书扩到转移球外。

4. **预算安全性**：任一 B_twin 耗尽触发对应回退；B_graph 耗尽强制静态认证图。
5. **孪生一致性**：仅当 Parity 成立时仿真证据可转移，否则 r̂ 膨胀或拒绝。

### IP-161 REGC（ROS 执行图契约）

```python
class ROSExecutionGraphContract:
    def __init__(self, spec, critical_edges, deadlines):
        self.spec = spec
        self.critical_edges = critical_edges
        self.deadlines = deadlines
        self.epoch = None

    def fingerprint(self, graph):
        canon = {
            'nodes': sorted((n.type, n.lifecycle_default) for n in graph.nodes),
            'params': sorted(graph.params.items()),
            'qos': sorted((e.topic, e.qos.as_tuple()) for e in graph.edges),
            'executors': sorted(graph.callback_groups.items()),
        }
        return merkle_sha256(json.dumps(canon, sort_keys=True))

    def qos_dominates(self, q, q_star):
        return (REL_ORDER[q.rel] >= REL_ORDER[q_star.rel] and
                DUR_ORDER[q.dur] >= DUR_ORDER[q_star.dur] and
                q.depth >= q_star.depth and
                q.deadline <= q_star.deadline and
                q.lifespan >= q_star.lifespan and
                LIVE_ORDER[q.liveliness] >= LIVE_ORDER[q_star.liveliness])

    def schedulable(self, graph):
        for chain in graph.critical_chains():
            R = chain.C
            changed = True
            while changed:
                changed = False
                R_new = chain.C + chain.B + sum(
                    math.ceil(R / t.period) * t.C
                    for t in chain.higher_priority())
                if R_new > R:
                    R, changed = R_new, True
            if R > self.deadlines[chain.id]:
                return False
        return all(e.qos.deadline >= self.response_bound(e) for e in graph.edges)

    def admit(self, graph):
        h = self.fingerprint(graph)
        ok = (h == self.spec.expected_hash
              and all(self.qos_dominates(e.qos, self.spec.q_star[e.topic])
                      for e in self.critical_edges)
              and self.schedulable(graph)
              and graph.param_hash() == self.spec.param_hash)
        if ok:
            self.epoch = h
        return ok, h

    def epoch_changed(self, graph):
        return self.fingerprint(graph) != self.epoch
```

### IP-164 SRET（仿真到现实证据转移）

```python
class SimToRealEvidenceTransfer:
    def __init__(self, lipschitz_loss):
        self.L = lipschitz_loss
        self.r = None

    def calibrate(self, anchors, alpha=0.05):
        sim_feats = [a.sim for a in anchors]
        real_feats = [a.real for a in anchors]
        emp = wasserstein1(sim_feats, real_feats)
        boot = bootstrap_upper(sim_feats, real_feats, alpha)
        self.r = emp + boot
        return self.r

    def safe_set(self, K_candidates, sim_risk, eps_safe):
        return [K for K in K_candidates
                if sim_risk(K) + self.L * self.r <= eps_safe]

    def certificate(self, K, sim_risk, n_anchor, alpha=0.05):
        return TransferCert(K, sim_risk, self.L * self.r, alpha, n_anchor)

    def update_anchors(self, ev_exec):
        self.anchors.append(Anchor(ev_exec.sim_counterpart, ev_exec.features))
        self.r = self.calibrate(self.anchors)
```

### IP-165 CDSC（覆盖导向场景课程）

```python
class CoverageDirectedSceneCurriculum:
    def select(self, candidates, visited, coverage, budget):
        scored = []
        for z in candidates:
            if z in visited:
                continue
            novelty = self.metric.dist(z, visited)
            prox = math.exp(-abs(coverage.boundary(z) - self.b_target) / self.sigma)
            transfer = coverage.expected_real_gain(z) * (1 - 1/(1 + coverage.r_hat(z)))
            scored.append((novelty * prox * transfer / z.cost, z))
        return max(scored)[1]

    def update(self, z, sim_ev, real_ev=None):
        self.coverage.mark_sim(z, sim_ev)
        if real_ev is not None:
            self.coverage.mark_real(z, real_ev)
```

```python
class TwinBudget:
    def __init__(self, sim_eps, anchors, graph_reconfig, cog_budget, exec_budget):
        self.B_sim = sim_eps
        self.B_transfer = anchors
        self.B_graph = graph_reconfig
        self.B_cog = cog_budget
        self.B_exec = exec_budget
```
