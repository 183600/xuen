# 第 1 轮（新灵感循环第 1 轮；本轮灵感：「用户画像」×「云端协同」）

> **基线**：上一轮（灵感「大语言模型」×「机器人」×「智能体」）MetricVoiceGauge-NCD-HUTDH-v17（定义 657–686；引理 137–142；实验 E691–E710）。
> 本轮纪律：**画像只排序、云端只提议、边缘证书是唯一裁决、安全按"选择分布"而非"集合"计**。不推倒 v17：v17 的 CLP/S2C/HCG/PSV/APS/AMC、v16 的 BTS/TRM/WBC/CSC/NCS/MCA/WCB、v13 的 AIO/RTIC/CPD/DGC/DDL/RTCR、v14 的 SCD/DSD/DCA/EDC、v12 的 USG/TGC/BAA/GAGP/UC、v11 的 HAS/HCC/HATD/HDT、v10 的 NGE/DSL/CC/CWM/CAE/NCP、v9 的 AC/MW/ID、v8 的 DA/SPR/Cal 与历轮不变式全部保留。六个新组件——UPC（用户画像编译器）、RBG（风险预算守卫）、CFC（云边证书协调器）、ESC（边缘主权证书）、AQG（锚隔离门）、PPM（隐私保护画像管理器）——一律以**中立元接入 v17 语言层之上**，失效即严格退回 v17（引理 143），再沿 v17→v16→…→v6 退化链退回。本轮只做三件事：把"个性化"改写为**证书集内的偏好排序 + 选择风险预算**、把"云端协同"改写为**带来源与版本的无授权提议**、把"画像×云端"改写为**受控反馈回路**。

## 0. 直觉与动机

**灵感 1（用户画像 → 画像不是"权限"，是"排序 + 风险预算"）**
直觉：用户画像最诱人的用法是"为这个用户打开更多功能"（老人放慢、儿童禁跑、专家提速）。这在安全架构里是灾难——画像来自观测与自述，可漂移、可被投毒、可自相矛盾，一旦它能授权，就等于把证书格交给了最不可信的数据源。核心创新：**用户画像编译器（User Profile Compiler, UPC）**。画像被编译成认证锚集 `A` 上的**偏好序 ≽_P** 与**风险预算 B_P**；个性化算子 `pers(P,A) ⊆ A` 只在证书集内重排与过滤，绝不新增锚、不放宽 Θ、不抬高 m*/h*。关键反直觉点 1：**个性化的正确产物不是"更多能做的动作"，而是"同样能做的动作里更合适的那个"**——`Exec` 集合一个元素都不增，变的是选择的分布。

**灵感 2（用户画像 → 集合安全 ≠ 策略安全：被忽视的"安全集内的危险角落"）**
直觉：v16/v17 的安全性都是**集合式**的（`Exec ⊆ Exec_v16`）。但机器人每一帧只执行**一个**动作，而画像是关于"选哪个"的。一个偏好"快"的画像会持续选中证书集里**恰好合法但尾风险最高**的角落（楼梯边选最快的认证步态）。每个动作都单独持证，选择策略却可能把期望风险推到证书集的上确界。核心创新：**风险预算守卫（Risk-Budget Guard, RBG）**。把"是否安全"从"动作是否 ∈ Exec"升级为"被选中动作的 profile-conditioned 风险 `R(a|P,x)` 是否 ≤ 共形校准的风险预算 `q̂^sel_β`"。关键反直觉点 2：**集合安全是必要不充分条件；个性化真正的失效模式不是"做了错事"，而是"总在最危险的合法动作上做对的事"**——安全率 100%，期望损失却随画像集中度上升。

**灵感 3（云端协同 → 云端只能提议，边缘证书是唯一事实）**
直觉：云端有全局算力、跨用户数据、大模型，看起来"更聪明"，于是自然想让云端下发策略、阈值、甚至新技能。但云端有延迟、会分区、会被攻破、会拿过期快照——一旦云端能授权，实时安全就押在一个不可控的远程进程上。核心创新：**云边证书协调器（Cloud-Fog Certificate Coordinator, CFC）+ 边缘主权证书（Edge Sovereignty Certificate, ESC）+ 锚隔离门（Anchor Quarantine Gate, AQG）**。云端输出是带 `(version, provenance, TTL, signature)` 的**提议**：计划候选、画像先验、**新锚候选**；边缘逐项本地复验，版本单调合并，云不可达/分区严格退化到 v17。关键反直觉点 3：**云端最有价值的不是"更强的决策权"，而是"更多待认证的候选"**——云端发现的新技能必须进**隔离区**，经 v16 NCS 本地认证才能出隔离；"先认证后使用"把云端的全局视野变成**认证滞后**而非**授权泄漏**。

**三者如何统一**
统一为 **v17 语言层之上的"偏好—分发"层**：v17 回答"哪些语言计划能被安全编译并执行"（`Exec_v17`），v18 回答"在同样的安全集合内，针对这个用户、在这个云边拓扑下，应该选哪一个、以及选中的风险是否仍在预算内"（`Exec_v18`）。UPC 是偏好侧（排序），RBG 是选择侧（预算），CFC 是分发侧（提议合并），ESC 是主权侧（裁决归属），AQG 是能力侧（新锚隔离），PPM 是隐私侧（摘要化）。共享状态 `ζ_pc=(P_ver, ≽_P, B_P, q̂^sel_β, cloud_ver, cloud_cache, Q_quarantine, ε_dp, loop_state)`。**UPC 回答"偏好什么"，RBG 回答"选中后风险是否可接受"，CFC 回答"云端给了哪些候选"，ESC 回答"谁说了算"，AQG 回答"新能力何时可用"，PPM 回答"画像如何既可用又不外泄"**。六者不是六个补丁，而是"偏好—选择—分发—主权—隔离—隐私"的实现链；叠加 v17 的"提议—编译—认证—调度—记忆"，构成**多源无特权、单点裁决**的完整栈。

## 1. 研究问题（轮次升级版）

- **Q1（画像编译的序语义）**：如何把异构画像（自述、行为日志、生理/偏好、任务历史）编译成锚集上稳定、可解释、可校准的偏序 ≽_P？画像冲突（自述"怕高"但日志常走高处）如何消解而不产生越权？画像版本升级时旧偏好如何单调废弃？
- **Q2（从集合安全到策略安全的缺口）**：如何在只允许 `pers(P,A) ⊆ A` 的前提下，给出被选中动作的风险上界 `R(a|P,x)`？该上界如何按画像类共形校准、如何在画像漂移下保持有效？预算 `B_P` 与全局 `B_global` 的优先级如何定义？
- **Q3（云边单调合并与分区）**：云端提议的 `(ver, prov, ttl, sig)` 如何验证与单调合并？云不可达、分区、脑裂、回滚攻击下如何保证 `Exec` 不增？云端先验只进排序项的技术约束如何落到代码？
- **Q4（新锚隔离与认证滞后）**：云端提出的新锚候选何时可执行？隔离区 `Q` 的出入规则、认证失败处置、认证滞后期间的活动性损失如何度量？云端能否用"新锚洪泛"耗尽本地认证预算？
- **Q5（隐私画像与反馈回路）**：如何让画像只以 ε-DP 摘要上云、却仍能聚合出有用先验？联邦画像的 Sybil/投毒如何遏制？边缘偏好→云端聚合→下发先验→边缘重排的反馈回路何时稳定、何时坍缩？

## 2. 设计原则（在 P28–P30 基础上新增 P31–P33）

**P31 画像只排序律（Profile as Preference, Not Permission）**
画像只能诱导认证锚集上的偏好序与预算，不能授权：`pers(P, A) ⊆ A`，且画像不得新增锚、不得放宽 `Θ_n`、不得抬高 `m*`/`h*`、不得放松 `margin_sc` 或共形 `α`。`Exec_v18` 在集合意义上恒等于 `Exec_v17`；画像只改变 `Exec` 上的**选择分布** `π_sel`。**画像层可新增的授权基数恒为零**。

**P32 策略风险预算律（Policy Risk Budget, Not Set Membership）**
安全必须按"被选中的动作"而非"候选集合"计量：对任意 `a ∈ Exec`，选中后须满足 `R̂(a|P,x) ≤ min(B_P, q̂^sel_β)`，其中 `B_P ≤ B_global` 由画像给出但被全局上限硬截断。集合成员资格是必要条件而非充分条件；**画像越"激进"，越要证明其选择仍在预算内，而不是越能解锁动作**。

**P33 云边单调主权律（Cloud Proposes, Edge Certifies）**
云端输出只是带 `(version, provenance, TTL, signature)` 的提议，边缘是唯一裁决者：只接受 `ver_cloud ≥ ver_local`、未过期、签名有效、且重新通过本地 S2C/HCG/PSV/TRM 的提议；云不可达或分区时拒绝全部云端提议并退回 v17。新锚候选进入隔离集 `Q`，仅当 `cert_local(n)`（v16 NCS 合成 + MCA/WCB 验证）通过才进入 `Anchors_v18`。**云端可改变"候选集合"，不可改变"裁决边界"**。

## 3. 与基线的接口（如何退化）

- UPC 失效（画像缺失/损坏）⇒ 无偏好序，按 v17 默认选择——**等价 v17**；
- RBG 失效（选择风险校准失效）⇒ 关闭个性化、退回 v17 默认选择（保守但集合不变）——**等价 v17**；
- CFC 失效（云端不可达/分区）⇒ 离线模式，忽略全部云端提议——**等价 v17**；
- ESC 失效 ⇒ 拒绝云端提议（默认最保守）——**等价 v17**；
- AQG 失效 ⇒ 禁用云端新锚，只用本地锚集——**等价 v17**；
- PPM 失效 ⇒ 不上送画像摘要，仅本地画像（或关闭画像）——**等价 v17**；
- 六者全失效 ⇒ MetricVoiceGauge-NCD-HUTDH-v17，再沿 v17→v16→…→v6 退化链退回；
- **安全继承**：UPC 只排序不新增，RBG 只拒绝不放行，CFC 只提议不裁决，ESC 只收紧，AQG 只隔离不直通，PPM 只摘要不扩权。六端口互不相交，均不能新增授权或放宽任何阈值；`Exec_v18 ⊆ Exec_v17` 由引理 143 保证。

## 4. 预期贡献

1. **画像即排序**：首次把"个性化机器人"改写为"证书集内的偏好排序"，证明画像不扩权、`Exec` 集合不变，把个性化从授权问题降格为选择问题；
2. **从集合安全到策略安全**：发现并形式化"证书集安全 ≠ 选择策略安全"的缺口（安全集内的危险角落），给出 profile-conditioned 风险预算与共形选择风险上界，这是 v16/v17 集合式保证无法覆盖的空白；
3. **云边单调主权证书**：把"云端下发"改写为"带来源/版本/TTL 的无授权提议 + 边缘本地复验"，给出分区/回滚/投毒下 `Exec` 不增的边界；
4. **锚隔离与认证滞后**：把云端的全局视野转化为"更多待认证候选"而非"更早授权"，形式化"先认证后使用"与洪泛防护；
5. **隐私保护画像**：画像只以 ε-DP 摘要上云，联邦聚合仍受投毒过滤，证明隐私化不扩权；
6. **多源无特权统一栈**：语言（v17）+ 画像（UPC）+ 云端（CFC）三个提议源均无授权，只有边缘证书格裁决；用 `Exec_v18 ⊆ Exec_v17 ⊆ Exec_v16 ⊆ …` 把语言、偏好、分发、行为、路线、动力学全解耦；E711–E730 覆盖画像编译、策略风险、云边合并、隔离滞后、隐私投毒、反馈回路、端到端与消融。

## 5. 本轮最大风险

**一句话**：P32 的"选择风险预算"本身是从有限样本、且可能被云端聚合先验污染的校准集估计出来的——当画像—云反馈回路把边缘选择分布持续推向证书集里"合法但尾风险最高"的角落时，重校准的样本恰恰被这个偏置策略污染（幸存者偏差：高风险选择成功才入校准集，失败样本被截断丢弃），于是 `q̂^sel_β` 系统性低估，集合安全恒成立、每个动作都持证，而被选中的策略却在"安全集的危险边缘"上把期望风险缓慢推过真实预算。

## 1. 关键算法骨架

```python
# IP-415 User Profile Compiler：画像 → 偏好序 + 预算（绝不扩权）
class UserProfileCompiler:
    def __init__(self, global_budget):
        self.B_global = global_budget

    def compile(self, raw_profile, anchors, cloud_prior=None):
        pref = self._preference_order(raw_profile, anchors)   # 只定义在现有锚上
        if cloud_prior is not None:
            pref = self._bounded_merge(pref, cloud_prior)     # 只调排序项
        B_P = min(self._budget_from(raw_profile), self.B_global)  # 硬上限
        return Profile(order=pref, budget=B_P, version=raw_profile.version)

    def personalize(self, anchors, profile):
        # pers(P,A) ⊆ A：只排序/过滤，不新增任何锚
        return sorted(anchors, key=profile.order.score, reverse=True)


# IP-416 Risk-Budget Guard：集合安全 → 选择安全
class RiskBudgetGuard:
    def __init__(self, calib_sel_log, beta=0.05):
        self.scores = [r.sel_score for r in calib_sel_log]   # (x,a,risk) 已执行记录
        self.beta = beta
        self.q = finite_sample_quantile(self.scores, 1 - self.beta)

    def select(self, candidates, profile, x, psv):
        # 先按画像排序，再逐个用选择风险预算硬门控
        for a in profile.personalize(candidates, profile):
            r = self.estimate_risk(a, x, profile)            # 只进特征，不裁决
            if r <= min(profile.budget, self.q):
                return a
        return None    # 全部超预算 ⇒ 退回 v17 默认选择（不个性化）

    def recalibrate(self, recent, pf):
        # 关键：截断/失败样本必须保留，否则幸存者偏差会低估 q̂^sel
        clean = pf.filter(recent)
        self.scores = [r.sel_score for r in clean]
        self.q = finite_sample_quantile(self.scores, 1 - self.beta)


# IP-417 Cloud-Fog Certificate Coordinator：只提议，不裁决
class CloudFogCoordinator:
    def __init__(self, ttl, local_ver):
        self.ttl = ttl
        self.local_ver = local_ver
        self.cache = None

    def merge(self, proposal, now):
        if proposal is None:                       # 云不可达/分区
            return None
        if now - proposal.ts > self.ttl:           # 过期快照
            return None
        if proposal.ver < self.local_ver:          # 回滚/陈旧
            return None
        if not verify_sig(proposal):               # 来源不可信
            return None
        self.local_ver = max(self.local_ver, proposal.ver)
        self.cache = proposal
        return proposal                            # 仅提议，不授权

    def candidates(self):
        return self.cache.plans if self.cache else []


# IP-418 Edge Sovereignty Certificate：边缘唯一裁决
def edge_sovereign_accept(pi, proposal, ctx):
    # 云端提议必须重新通过全部本地 v17 裁决，来源不提供任何豁免
    nodes = ctx.s2c.compile_plan(pi, ctx.x, ctx.m_star, ctx.h_max)

            and ctx.psv.verify(nodes)[0]
            and ctx.hcg.accept(pi, ctx.x, ctx.psv))


# IP-419 Anchor Quarantine Gate：先认证后使用
class AnchorQuarantineGate:
    def __init__(self, nc_synth, mca, wcb):
        self.Q = {}                                # anchor_id -> candidate
        self.synth, self.mca, self.wcb = nc_synth, mca, wcb

    def admit(self, cloud_anchor_candidates):
        for n in cloud_anchor_candidates:
            self.Q[n.id] = n                       # 进隔离：不可执行

    def promote(self, ctx):
        for nid, n in list(self.Q.items()):
            if self.synth.certify(n) and self.mca.verify(n) and self.wcb.verify(n):
                ctx.anchors.add(n)                 # 出隔离：仅本地认证后
                del self.Q[nid]

    def executable(self, anchors):
        return [n for n in anchors if n.id not in self.Q]


# IP-420 Privacy-Preserving Profile Manager：只上送摘要
class PrivacyPreservingProfileManager:
    def __init__(self, eps, poison_filter):
        self.eps = eps
        self.pf = poison_filter

    def summarize(self, raw):
        return dp_summary(raw, self.eps)           # 唯一上云形态

    def aggregate(self, summaries):
        clean = [s for s in summaries if not self.pf.suspect(s)]  # 抗 Sybil/投毒
        return federated_prior(clean)              # 云端只见摘要

    def rank_only(self, prior):
        return prior                               # 只进排序项，绝不进预算


# 主闭环集成：MetricVoiceGauge-NCD-HUTDH-v18（偏好—分发层）
def metricvoicegauge_round_18_profile_cloud(M, s, obs, ...):
    # ---- v17 主路径原样保留（CLP/S2C/HCG/PSV/APS/AMC + v16 行为层）----
    drift = ctx.drift_detector.fired()
    m_star = ctx.trm.compute_reachable()
    h_max = ctx.trm.get_permitted_tier(m_star)

    # ---- CFC：云边合并（仅提议；TTL/版本/签名/分区门控）----
    prop = ctx.cfc.merge(ctx.cloud.poll_nonblocking(), now())
    if prop is not None:
        ctx.aqg.admit(prop.anchor_cands)           # 新锚进隔离，不可执行
        ctx.ppm.aggregate(prop.profile_summaries)  # 只聚合 ε-DP 摘要
    ctx.aqg.promote(ctx)                           # 仅本地认证后出隔离

    profile = ctx.upc.compile(ctx.raw_profile, ctx.aqg.executable(ctx.anchors),
                              cloud_prior=prior)

    # ---- v17 候选：语言计划 或 v16 默认 ----
    plan_nodes, rung = ctx.aps.current(now(), drift)
    candidates = plan_nodes if plan_nodes else [ctx.v16_default_node()]

    # ---- RBG：按画像排序 + 选择风险预算硬门控 ----
    chosen = ctx.rbg.select(candidates, profile, obs, ctx.psv)
    if chosen is None:
        chosen = ctx.v16_default_node()            # 全部超预算 ⇒ 退回 v17

    # ---- 本地复验与执行（来源不提供豁免）----
    action, c_low, c_up, fb, m_exec, h_exec = ctx.csc.schedule(
        x=obs, plan_nodes=[chosen],
        hw_state=ctx.hw_state, sw_cert=ctx.sw_cert, data_cov=ctx.data_cov, drift=drift)
    tau_cmd = ctx.wbc.compute_control(obs, task_spec=action)
    execute(tau_cmd if h_exec > 0 else fb)

    # ---- 低频：反馈回路（只进排序项）、重校准（保留截断样本）----
    if ctx.cycle_idx % T_loop == 0:
        ctx.cloud.push_summary(ctx.ppm.summarize(ctx.raw_profile),
                               ctx.selection_histogram(), rho=ctx.rho)
    if ctx.cycle_idx % T_recalib_sel == 0:
        ctx.rbg.recalibrate(ctx.amc.store.recent(k), ctx.pf)

    C, spatial_cert, claims, metrics, rewards = M.inherited_v17_path(ctx)
    return C, spatial_cert, claims, metrics, rewards
```

## 2. 推导

**引理 143（画像不扩权）** 若 UPC 只在 `Anchors_v17` 上诱导偏好序，`pers(P,A) ⊆ A`，且 RBG 只拒绝、ESC 只要求本地复验、AQG 只隔离、PPM 只摘要，则对任意画像内容（含对抗画像），`Exec_v18 = Exec_v17`（集合意义），且画像层新增授权基数 `|NewAuth_profile| = 0`。证明：UPC 的值域是 `A` 上的序，不产出锚；`pers` 是选择算子，输出集是输入集的子集；RBG/ESC/AQG/PPM 均只做过滤或只读变换，不触碰 `Anchors_v17`、`Θ_n`、`margin_sc`、`α`。故 `Exec_v18 ⊆ Exec_v17`；又空画像时 `pers` 退化为恒等，`Exec_v17 ⊆ Exec_v18`，两边相等。∎ 推论：**画像的失效模式只有"选得不好"，没有"做得更多"**。

**引理 144（集合安全不蕴含策略安全）** 设证书集 `S = Exec_v17` 有限、任一 `a ∈ S` 单独认证安全（`R(a) ≤ B_global`）。则对任意 `ε>0` 存在由画像诱导的选择策略 `π_sel ∈ Δ(S)`（点质量分布 δ_{a*}，`a* = argmax_{a∈S} R(a)`），使 `E_{a~π_sel}[R(a)] = max_{a∈S} R(a)`，即期望风险达到集合内最危险动作的尾风险；故仅凭 `a ∈ S` 无法给出优于 `max_a R(a)` 的策略风险上界。证明：δ_{a*} 不新增任何动作、不越出证书集，却把期望风险推到上确界；取 `a*` 即得。∎ 推论：**必须对"被选中动作"而非"候选集合"做风险预算；这是 RBG 存在的理由，也是 v16/v17 集合式保证无法覆盖的缺口**。

**引理 145（选择风险的共形上界）** 设对画像类 `P` 的校准样本 `(x_i, a_i, r_i)` 可交换、风险有界，`q̂^sel_β` 取选择风险分数第 `⌈(N+1)(1−β)⌉` 次序统计量（越界取 +∞），RBG 接受选中动作当且仅当 `R̂(a|P,x) ≤ min(B_P, q̂^sel_β)`。则对同类新用户/新情境，`P(R(a_chosen) > q̂^sel_β) ≤ β`。证明：标准共形秩论证作用于实值选择风险分数；画像只改变候选排序（进而改变被选中的 `a`），只要校准与测试同属一个可交换画像类，`a_chosen` 的分数秩仍均匀分布，超分位数概率 ≤ β。∎ 推论：**RBG 的保证是 per-profile-class 的**——换类/漂移必须重校准，且 `B_P` 被 `B_global` 硬截断。

**引理 146（云边单调主权）** 设边缘仅接受 `ver_cloud ≥ ver_local`、未过期、签名有效、且通过本地 S2C/HCG/PSV/TRM 复验的云端提议，云不可达或分区时拒绝全部云端提议并退回 v17；云端不能写本地锚集/阈值/证书。则对任意云端内容（含恶意、过期、回滚）：`Exec_v18(cloud) ⊆ Exec_v17`，且 `|NewAuth_cloud| = 0`。证明：每条云端提议进入 `Exec_v18` 前都必须重新通过 v17 全部本地裁决，与来源无关；版本单调拒绝回滚；分区退化为纯本地路径。故云端只能改变"被考虑的候选集合"，不能改变"裁决边界"。∎ 推论：**云端攻破的最坏后果是"候选变差/变旧"，不是"授权变宽"**。

**引理 147（锚隔离的认证滞后安全）** 设云端新锚候选进入隔离集 `Q`，出隔离唯一条件是 `cert_local(n)`（NCS 合成 + MCA/WCB 验证）通过；`Anchors_v18 = Anchors_v17 ∪ (Q ∩ certified)`。则任意时刻被执行的新锚必已本地认证；认证滞后期间 `Exec_v18 = Exec_v17`。证明：未认证锚不在 `Anchors_v18`，S2C 的 `compile ∈ Anchors_v18 ∪ {⊥}` 无法投影到它，故不可执行，直到 `cert_local` 完成。∎ 推论：**云端的全局视野转化为"更早开始认证"，而非"更早获得授权"**；洪泛防护只需给 `Q` 设配额与认证队列上限。

**引理 148（画像—云反馈回路的有界性）** 设反馈算子 `Φ` 把边缘选择分布回传云端聚合成先验再下发，且 (i) 云端先验只进入 UPC 的排序项、不进入 RBG 预算；(ii) RBG 对选中动作硬门控；(iii) 预算取 `min(B_P, B_global)`。则反馈只能收缩活动集、不能扩大 `Exec`；即使回路把选择分布推向证书集边界，期望风险仍被 `q̂^sel_β` 截断。若进一步要求排序更新为 L1 收缩（因子 `ρ<1`），则分布收敛，无个性化坍缩。证明：(i)(ii) 使风险侧与反馈解耦；(iii) 使预算单调不增；`Exec` 只受锚集与证书影响，反馈不触碰。L1 收缩给出 Banach 不动点条件，故收敛。∎ 推论：**反馈回路的失效模式是"活性/多样性坍缩"（总选同一角落），不是"越权"；ρ 是防坍缩旋钮**。

**引理 149（隐私画像的不可扩权与不可反演）** 设 PPM 只上送 ε-DP 摘要 `σ(P)`，云端只做聚合先验且摘要只影响排序项。则 (a) `σ(P)` 不改变 `Exec_v18`；(b) 对任意云端观察，重建原始画像的贝叶斯风险下界由 ε 控制（DP 后处理 + 抗重构界）。证明：(a) 由引理 143/148，摘要只进排序项；(b) 标准差分隐私后处理不变性与重构下界。∎ 推论：**隐私化不削弱安全保证，只可能削弱个性化精度**。

## 6. 已知风险与失效模式

1. **选择风险的幸存者偏差**：高风险选择失败/被截断的样本若不入校准集，`q̂^sel` 系统性低估。缓解：强制记录截断/失败样本、逆概率加权、保守 β、独立安全审计集。
2. **画像—云反馈坍缩**：回路把选择分布压到单一角落，多样性下降、活性与鲁棒性受损。缓解：L1 收缩 ρ<1、多样性正则、熵下限报警、周期人工抽检。
3. **画像漂移与换类**：新用户/新任务使画像类不可交换，RBG 覆盖失效。缓解：drift_P 检测、滑动窗重校准、冷启动用全局保守预算。
4. **云边版本分裂**：长时间分区导致本地版本超前，恢复时云端旧版本被拒、先验长期失联。缓解：版本栅栏 + 单调合并、恢复期只读先验、人工仲裁。
5. **锚隔离认证积压**：云端新锚洪泛耗尽本地认证预算，正常认证饥饿。缓解：隔离配额、速率限制、优先级队列、认证预算硬上限。
6. **隐私—效用权衡**：ε 过小使摘要无信息，个性化退化；ε 过大泄露画像。缓解：自适应 ε、分层摘要、聚合噪声校准、隐私审计。
7. **联邦 Sybil 投毒**：伪造多身份把恶意先验推成"多数"。缓解：鲁棒聚合（中位数/截尾）、身份证明、单源配额、投毒过滤。
8. **画像自相矛盾**：自述与行为日志冲突，序不稳定导致抖动。缓解：冲突消解规则、时间衰减、迟滞、显式置信度。
9. **风险估计的测量鸿沟**：`R̂(a|P,x)` 由模型估计，其偏差在漂移下系统化。缓解：多模型集成、一致率作置信度、人工标注抽检。
10. **云端提议延迟抖动**：虽不阻塞，但候选长期陈旧使个性化收益下降。缓解：TTL、事件触发、候选缓存、离线先验。
11. **隔离门与 v16 热更新交互**：BT 热更新使隔离锚的认证基线失效。缓解：锚携带 BT 版本号，版本不符整体重认证。
12. **过度保守的预算截断**：`min(B_P,B_global)` 与共形分位叠加使个性化长期不可用，退化为 v17 默认。缓解：分层预算、动态 β、按画像类共享校准、活性监视。

## 7. 本轮最大风险

**一句话**：P32 的"选择风险预算"本身是从有限样本、且可能被云端聚合先验污染的校准集估计出来的——当画像—云反馈回路把边缘选择分布持续推向证书集里"合法但尾风险最高"的角落时，重校准样本恰恰被这个偏置策略污染（幸存者偏差：高风险选择成功才入校准集，失败样本被截断丢弃），于是 `q̂^sel_β` 系统性低估，集合安全恒成立、每个动作都持证，而被选中的策略却在"安全集的危险边缘"上把期望风险缓慢推过真实预算。
