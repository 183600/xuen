# 第 16 轮（研究线累计第 16 轮；灵感循环第 1 轮第 2 迭代）· HEAT-ADAPT-VLA：热感知微调 + 场景锚定的在线胜任力提升

> 检索/复核日期：**2026-11-04（UTC）**。赛事身份不变：宇树 UniBot 世界挑战赛，G1 + Dex1，32 项桌面任务，通才单模型赛道。本轮三个随机灵感词：「热管理」「微调」「场景理解」。**不推倒**第 10-15 轮；本轮在 ZEST-VLA 胜任力层之上加一个**热感知自适应层** L5：ZEST 决定信不信，HEAT-ADAPT 决定「在热预算内能不能自愈」。

## 0. 先给直觉：ZEST 会降级，但不会自愈

第 15 轮 ZEST-VLA 把推理期自监督残差变成风险受控信任门：在 OOD-E/S 时禁用 SERVO、退回几何原语。它解决了「别自信地错下去」，但付出两个代价：
1. **能力天花板**：VLA 本身不提升，遇到可学习的轻度 OOD 仍只能降级；
2. **资源浪费用**：每次不信任都触发 FALLBACK，浪费 VLA 已付出的规划成本。

直觉是：**把「热」当作计算的物理预算，把「微调」当作胜任力的在线补丁，把「场景理解」当作微调的语义锚点。** 当 ZEST 检测到轻度不胜任、场景理解置信高、热头room 充足时，不直接降级，而是用一个参数高效适配器 LoRA 在推理期做几步自监督微调，用动作-观测残差 + 场景一致性损失把 VLA 拉回 ID 流形。热管理保证微调不会导致 GPU/关节过热或超时；场景理解防止微调漂移到语义错误的目标。

一句话押注：
> **第 15 轮用残差决定信不信；本轮用热预算决定能不能自愈，用场景锚定微调保证自愈不漂移，让零样本从「受控降级」进化到「受控自适应」。**

三个词落地：

| 词 | 落地 | 不做什么 |
|---|---|---|
| 热管理 | 显式热状态 T_t 与功率 P(a)，预算约束 B_therm；微调、VLA、SERVO 皆耗热，按边际收益/热成本调度 | 不假设无限算力；不做离线重训练 |
| 微调 | 推理期 LoRA 适配器 θ_a，参数冻结主模型，仅更新秩 r≤8 的低秩矩阵；更新信号来自自监督残差与场景一致性，不用成功标签 | 不做全量梯度；不改 VLA 主权重；不引入第二学习模型 |
| 场景理解 | 语义地图 M_t + 仿射场景先验；提供目标锚点、可见性、遮挡掩码，用于构造场景一致性损失与域门控 dom_heat | 不依赖额外大模型；不做在线分割/检测训练 |

## 1. 研究日志：为什么是这一层

### 1.1 第 15 轮留下的两个未付费假设

A1. 不胜任就降级是唯一安全动作。
A2. 计算资源无限、热约束可忽略。

A1 忽略了「轻度 OOD 可学习」的中间地带。A2 在真机上不成立：连续 VLA 推理 + 高频伺服 + 在线梯度会累积 GPU/电机热，触发降频或超时。

### 1.2 新判断

1. **热是第一类约束**：在 32 任务连续评测中，热累积会导致 p99 延迟上升。把热建模成可观测状态，把微调视作高热成本动作，才能与 VLA/SERVO 做联合调度。
2. **微调可以是推理期的参数高效自监督**：传统微调需要标签；本轮用 ZEST 的残差 + 场景理解的一致性作为免费监督，只更新 LoRA。**它学习的是适配，不是策略**。
3. **场景理解是防止灾变遗忘的锚**：无锚的自监督微调会把错误目标也拟合。语义地图提供目标不变性约束：微调损失必须在目标锚点附近保持稳定。

### 1.3 与第 15 轮的关系

| 层 | 第 15 轮 ZEST | 第 16 轮 HEAT-ADAPT |
|---|---|---|
| 信号 | 残差三元组 | 残差 + 热状态 T_t + 场景锚点 |
| 行动 | TRUST / FALLBACK / HOLD | 增加 ADAPT；门控前置热检查 |
| 自监督 | 只校准阈值 | 校准阈值 + LoRA 梯度 |
| 资源 | 预算 B_t | B_t + B_therm |
| 零样本 | 降级 | 降级 + 受控自适应 |

保留：FACT-VLA、GEO-RESIDUAL、CHUNK-SERVO、WAVE-SERVO、VOI-MAP、ZEST 信任门、单模型合规。
升级：从「检测-降级」升级到「检测-自适应-降级」；从「预算」升级到「预算+热」。
剪枝：不做全量微调；不做无锚自监督；不做热模型在线辨识，热模型用一阶 RC 先验+保守上界。

## 2. 机制草图

### 2.1 热状态与功率模型

```text
T_{t+1} = λ T_t + (1-λ) P(a_t) + w_t
P(a) ∈ {p_vla, p_servo, p_look, p_ft}
约束：T_t ≤ T_max，软惩罚 γ·max(0,T_t-T_warn)
```

热头room h_t = T_max - T_t。微调每步热成本 p_ft ≈ 2.5×p_vla。

### 2.2 场景锚定的自监督微调损失

在块 b 结束后，若触发 ADAPT：

```text
L_res = ||r_geo|| + ||r_tmp||            # ZEST 残差
L_scene = ||f_enc(o_b) - f_enc(o_{b-1}) - g_ξ(a_{b})||^2   # 场景一致性
         + λ_anchor·||μ_{i*} - μ̂_{i*}||               # 目标锚点不变
L = L_res + β L_scene
```

f_enc 是 VLA 视觉 encoder 的冻结特征；g_ξ 是轻量运动预测头（线性）。仅更新 LoRA 参数 θ_a。

更新：θ_a ← θ_a - η ∇L，执行 K≤3 步，K 由热头room 决定。

### 2.3 热感知调度

动作集扩展：`{SERVO, LOOK, VLA, FALLBACK, ADAPT, COMMIT, HOLD}`

门控顺序：
1. ZEST 信任门 → 允许集 A_zest
2. 热门控 → A_therm = {a | P(a) ≤ h_t/Δt}
3. 场景门控 → dom_scene(u,M_t) ∈ {adaptable, geometric, semantic}
4. VoI 选择 max Δ / (c_a + γ_th·P(a))

ADAPT 仅在 `TRUST` 且轻度惊讶 `e_b=1, S_b<h` 且 `dom_scene=adaptable` 且 `h_t>h_min` 时可用。

### 2.4 早期自愈

轻度 OOD：1-2 步 LoRA 更新可把残差拉回阈值以下，避免进入 FALLBACK。热成本可控：3 步微调 ≈ 1 次 VLA 调用 + 1.5×SERVO。

## 3. 可证伪假设

| 编号 | 假设 | 证伪条件 |
|---|---|---|
| H1 | 热感知调度在热约束下仍保持 ID 成功率不降 | ID 回归 >2pp |
| H2 | ADAPT 在轻度 OOD 上比直接 FALLBACK 成功率 +≥5pp，热成本 ≤3% | 无提升或热超限 |
| H3 | 场景锚定防止微调漂移：语义错误率不升 | 语义任务回归 >3pp |
| H4 | 热模型一阶 RC 足够预测过热事件 | 实际过热未被预测 >10% |

## 4. 什么情况下放弃

- 真机热模型误差 >20% 导致反复降频 → 退回 ZEST-only。
- ADAPT 在真实桌面上产生灾变遗忘或语义漂移 → 仅保留热感知调度，移除微调。
- LoRA 更新延迟 >80 ms → 微调移出关键路径，只在 VLA 间隙执行。

## 5. 一句话押注

**第 15 轮用残差决定信不信；本轮用热预算决定能不能自愈，用场景锚定微调保证自愈不漂移，让零样本从受控降级进化到受控自适应。**

## 6. 本轮最大的风险

**热-性能耦合失控：如果热模型低估实际功耗，连续微调会导致 GPU 降频、VLA 延迟激增，反而把轻度 OOD 变成超时失败；热管理从保护变成放大器。**

# 第 16 轮产物 · HEAT-ADAPT-VLA 技术报告

> 检索/复核日期：**2026-11-04（UTC）**。对象：宇树 UniBot 世界挑战赛 G1+Dex1，32 项桌面任务，通才单模型赛道。本报告在第 15 轮 ZEST-VLA 之上加热感知微调层 L5，保持 FACT-VLA、GEO-RESIDUAL、CHUNK-SERVO、WAVE-SERVO、VOI-MAP、ZEST 全部不变。

## 0. 结论与边界

### 0.1 一句话结论
ZEST 解决「信不信」，HEAT-ADAPT 解决「能不能在热预算内自愈」。系统保持单模型冻结主体，仅用 LoRA 适配器做推理期自监督微调，热状态显式约束调度，场景锚定防止漂移。零样本泛化从受控降级扩展为受控自适应。

### 0.2 证据等级
A：官方规则/API；B：本轮形式化与合成热-微调实验；C：真机验证需 G13-16；U：未核验文献。

### 0.3 不做什么
不全量微调；不训练第二模型；不在线学习热模型参数；不突破单模型合规。

## 1. 承接

第 15 轮 ZEST 提供残差、conformal/CUSUM 信任门、FALLBACK。未解决：轻度 OOD 可学习但被直接降级；计算热未建模；无在线改进能力。本轮保留全部 ZEST 逻辑，增加热状态观测、LoRA 自适应、场景锚定。

## 2. 符号与形式化

### 2.1 热动力学
T_{t+1}= λ T_t + (1-λ) P(a_t) + w_t,  0<λ<1
约束 T_t ≤ T_max, 警告 T_warn < T_max
热头room h_t = T_max - T_t

功率表：p_vla, p_servo, p_look, p_ft。

### 2.2 适配器与损失
主模型 π_θ 冻结，适配器 θ_a 为 LoRA：W' = W + BA, rank r≤8。
在块 b 结束后，若触发 ADAPT：
L_res = w_geo r_geo + w_tmp r_tmp + w_goal r_goal
L_scene = || φ(o_b) - φ(o_{b-1}) - M(a_b) ||^2 + λ_a || μ_{i*} - μ̂_{i*} ||
L = L_res + β L_scene
∇_{θ_a} L 通过冻结 encoder 反向传播，仅更新 B,A。

### 2.3 热感知 VoI
状态 x_b = (b_b, p_b, φ_b, B_b, M_b, c_b, S_b, T_t)
动作 a ∈ A_adm(ZEST) ∩ A_therm(h_t) ∩ A_scene(dom)
价值：V(a)= Δ_success(a) / (c_a + γ_th P(a))
调度：a* = argmax V(a)

### 2.4 门控顺序
ZEST → 热 → 场景 → VoI
ADAPT 可用条件：
e_b=1 ∧ S_b < h ∧ dom_scene=adaptable ∧ h_t > h_min ∧ c_b > c_min

## 3. 算法

### 3.1 主循环
1. 更新地图/相位
2. 计算残差 s_b, e_b, CUSUM S_b
3. 观测热 T_t, 计算 h_t
4. 判定 dom_scene
5. 构造允许集 A = A_zest ∩ A_therm ∩ A_scene
6. 若 ADAPT ∈ A 且价值最高，执行 K 步 LoRA 更新，消耗热 p_ft·K
7. 否则按 ZEST+VOI 选择 SERVO/LOOK/VLA/FALLBACK
8. 记录热、残差、θ_a 变更

### 3.2 伪代码
class HeatAdaptPolicy:
  def get_action(obs):
    update_map...
    s,e,S = zest.update(obs)
    T = thermal.read()
    dom = scene_gate(instruction, map)
    A = intersect(zest.allowed(S), thermal.allowed(T), scene.allowed(dom))
    if 'ADAPT' in A and value('ADAPT')>threshold:
      for k in 1..K:
        loss = compute_loss(obs, plan, map)
        loRA.step(loss)
        thermal.consume(p_ft)
    return voI.select(A)

## 4. 性质、复杂度与正确性

命题1 热约束安全：若调度始终选择 A_therm 内动作，则 T_t ≤ T_max 几乎必然，保证。
命题2 无标签自监督：L_res+L_scene 仅依赖观测与动作，不需成功标签。
命题3 复杂度：LoRA 更新 O(r·d) 每步，r≤8，d≈14，<0.8ms/步；热更新 O(1)。
命题4 不破坏 ZEST 保证：ADAPT 仅在 TRUST 且轻度惊讶时触发，不增加 ID 假警报率。

## 5. 实验设计

G13 热模型预测误差<15%
G14 ADAPT 在轻度 OOD 上成功率 +≥5pp，ID 不回归
G15 热头room 耗尽时无超时
G16 场景锚定防止语义漂移

合成实验：热一阶 RC + LoRA 收敛模拟，验证热感知调度优于无热调度。

## 6. 风险

热模型误估计导致降频；LoRA 过拟合残差噪声；场景锚定不足导致语义漂移；微调延迟影响实时性。

## 7. 一句话押注
热预算决定自愈时机，场景锚定保证自愈方向，LoRA 微调提供自愈能力，三者构成受控自适应闭环。

## 8. 本轮最大风险
**热-性能耦合失控：若热模型低估实际功耗，连续微调引发 GPU 降频导致 VLA 延迟激增，把轻度 OOD 转化为超时失败，热管理从保护变为放大器。**
