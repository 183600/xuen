# 第 3 轮迭代（灵感循环 v3：「本体感知」×「创新点挖掘」）—— 让身体做高频中断，让眼睛做低频确认

> 本轮承接 v2 的 UIP-01′~15，不推倒重来。新证据是**接口层的权威观测/动作目录**（`unibot_submission` README §2/§3/§5/§6，2026-11-13）：观测里有一整套**廉价、可时间堆叠的本体感知**（双臂关节 7+7、双末端位姿 6+6、夹爪 1+1、下肢 15），而图像是 480×640×3 的 JPEG。这带来一个诱人但**必须被证伪**的直觉：既然反向撤回是最大得分缺口，能不能用本体感知替代视觉做验证？本轮的答案是：**不能单独替代，但能重构验证器的成本结构**——本体感知负责"高频、遮挡无关"的中断与自执行失败检测，视觉负责"世界级"的回归确认；两者按不同时间尺度调度。

**直接推论**：本体感知的"采样成本"几乎为零，图像是主成本。**时间分辨率应该花在本体感知上，空间/语义信息花在视觉上**；而图像的采样频率只能通过**加大 chunk 长度**来降，不能靠"按需看图"来省——这条约束把本轮的方案从"事件触发收图"纠正为"事件触发计算与块长"。

## 1. 两个灵感词：直觉与定义

### 1.1 本体感知
**直觉**：它是机器人的"第六感"——快、连续、不受遮挡影响，但它只感觉"自己"，感觉不到"世界被别人改了"。你闭着眼也能知道自己手臂抬到哪、夹爪合了多少；但别人把你叠好的毛巾翻开，你闭着眼是不知道的。

**定义**：接口可见的本体感知子空间
`S_prop = {left_arm[7], right_arm[7], left_ee[6], right_ee[6], left_gripper[1], right_gripper[1], lower_body[15]}`。
一次调用 `t` 的堆叠观测记为 `Q_t = {q_{t-Δ} : Δ ∈ D_prop}`，其中 `D_prop` 是 `obs_delta_indices` 为本体键声明的偏移集合（可覆盖刚执行完的整个 chunk）。
定义**跟踪残差** `e_t = Π(q_t) − A_{t-1}(t)`（`Π` 把观测映射到动作空间；joint 模式恒等，ee 模式用 FK/IK），以及**本体签名** `σ_t = (q_t, q̇_t, gripper_t, e_t)`。签名是后续所有"中断"判据的原料。

### 1.2 创新点挖掘
**直觉**：创新点不是"灵光一现"，而是在"约束 × 信号 × 失败模式"的空间里做**受约束搜索**，再用**可证伪性**把噪声剪掉。一个不能说出"什么实验会杀死它"的想法，不是创新点，是愿望。

**定义**：一个创新点 `IP = (M, B, E, P, Δ, R, T)`：
- `M` 机制；`B` 它攻击的目标瓶颈（成功率/步骤分/可信度）；`E` 规则或数据证据；`P` 权限与合规（是否在 API 内、是否单模型）；`Δ` 预期边际收益；`R` 资源；`T` **证伪测试**（哪个实验、什么结果会判它死刑）。
定义挖掘算子：
`S` 信号替换（贵/脆→便宜/稳）、`C` 约束反转（把接口限制变成优势）、`F` 失败分解、`N` 负空间扫描（规则写了但数据没有）、`X` 组合、`T` 证伪。
挖掘流程：`生成（算子作用）→ 权限/证据过滤 → 证伪卡 → 排序（Δ/资源/风险 Pareto）`。本轮用它生成了 9 个草案，保留 4 个、剪掉 4 个、升级 2 个。

## 2. 关键洞察：本体感知的能力边界（先证伪，再设计）

把 v2 的"反向撤回"按**发生时刻**拆成三类：
- **F1 自执行失败**：跟踪误差、打滑、没接触上、插入卡住。发生在**你正在动**的时候。
- **F2 世界回退**：你完成并**松手之后**，人把进度撤回（T14 拧回、T16 翻开、T17 打开、T19 拉开、T27 拿走）。
- **F3 全局位移**：人挪动底座/工作台（T11 动底座、T25 挪底座）。

覆盖矩阵（★=强，○=中，·=弱/无）：

| 信号 | F1 自执行 | F2 世界回退 | F3 全局位移 |
|---|---|---|---|
| 视觉（单帧） | ○ | ★（物体可见时） | ★ |
| 视觉（堆叠） | ★ 但每帧一张 JPEG，昂贵 | ★ 但昂贵 | ★ 但昂贵 |
| 本体感知 | ★（遮挡无关、每步可采） | ·（松手后基本失明） | ○（仅当 lower_body/pivot 有反应） |
| 语言 | · | · | · |
| 时序/延迟 | ○ | · | · |

**结论（本轮最重要的修剪）**：**纯本体感知检测"反向撤回"是伪命题**。绝大多数 `human_*` 撤回发生在松手之后，本体感知没有信息。本体感知真正的主战场是 **F1**（接触密集任务的成功率与步骤分），以及在 F2 中"人还在碰你/物体时"的那一小段。因此旗舰不能叫"本体感知撤回检测"，只能叫**本体感知中断 + 视觉证书的跨模态回归检测**。这一步把灵感词从"替代视觉"降级为"重构视觉的调用时机与计算量"，反而更可信、更省。

## 3. 双时间尺度跨模态回归检测（旗舰直觉，含接口纠正）

**直觉**：身体是"警报器"，眼睛是"法官"。警报器一直开着（便宜），法官只在必要时**开庭审理**（贵在计算与调用频率）。世界被改了，身体可能没感觉；但只要身体出现异常，或到了一个子目标边界，就缩短下一块、立刻复核。注意接口约束：图一旦声明就每次都会传，所以我们不能"只在异常时收图"，只能"只在异常时跑视觉谓词并缩短下一块"。

**定义**：
- **L0 本体中断**：`I_t = 1[ ||e_t||_Σ > θ_e  ∨  σ_t 偏离正常签名流形 > θ_σ ]`。每步可算，成本≈0。
- **L1 视觉确认**：子目标谓词 `V(o_t, g) ∈ {done, undone, unknown}`。图像随 obs 到达；我们控制的是**何时运行 `V`**（省推理延迟）与**下一块多长**（省后续图像传输）。
- **回归证书**：`Reg(g) = ⟨done_witness(g) at t1, undone_witness(g) at t2, t2>t1, causal_check⟩`。只有拿到时间有序的"曾完成→现在未完成"证据，才允许 `regressed`。这防止"视觉抖动→反复重做"。
- **重锚定**：下一块动作必须从**观测到的当前状态**出发，而不是上一块的预测终点；若残差大但未回归，生成一段平滑桥接，避免动作跳变伤可信度。
- **两个截止期**：接触截止期 `τ_A`（F1 可容忍的未检测时长）、世界截止期 `τ_B`（F2 可容忍的未确认时长）。由此推出 chunk 长度上界 `k ≤ τ_A/Δt`；在非接触运输段允许放大到 `k ≤ τ_B/Δt`。`k` 不再是拍脑袋，而是由干扰动力学和延迟预算共同决定。

## 6. 本轮最大风险

**一句话**：本体感知的"廉价"会诱导我们把验证器做得越来越敏感，而敏感的重做会制造动作抖动与延迟尖峰，恰好撞在 README §6 的可信度枪口上——所以"中断"必须由回归证书门控，且重做次数/平滑度必须有硬预算。

**→ 最值得押注：UIP-16 CMR-D × UIP-17 PST × UIP-18 PSM**——用近乎零带宽的本体感知把 F1 接触失败率压下去，再用本体触发的视觉证书守住 F2 反向撤回，整体图像流量反而比"每步都堆图"更低。

## 1. 旗舰深潜：UIP-16 · CMR-D（Cross-Modal Regression Detector）

### 1.1 机制（四层）
1. **观测预算层（UIP-17）**：本体键密堆叠（覆盖刚执行的 chunk），图像单帧、必要时降分辨率；不堆图像。
2. **L0 本体中断层（UIP-18）**：用解析跟踪残差 `e_t` + 本体签名异常分 `a_t`，每步判断"身体是否经历了没被命令的事"。
3. **L1 视觉证书层**：运行子目标谓词 `V(o,g)`；只有拿到 `⟨done@t1, undone@t2, t2>t1⟩` 的时间有序证据，才判 `regressed`。
4. **动作层**：从**观测到的当前状态**重锚定；未回归→平滑桥接；已回归→门控重做；超预算→降级为安全推进（保前置步骤分）。

### 1.2 状态机
```text
NORMAL --(L0 中断或到子目标边界)--> CONFIRM
CONFIRM --(V=done)--> NORMAL (g←g+1, 清空 done_witness)
CONFIRM --(V=undone 且有 done_witness)--> REDO (计数+1)
CONFIRM --(V=unknown 或 无证书)--> NORMAL (不重做)
REDO --(完成或计数>max_redo)--> BRIDGE --> NORMAL
任意状态 --(延迟/抖动超预算)--> SAFE (只保前置、不搏末步)
```

### 1.3 关键伪代码
```python
class CMRD_Policy:                       # UIP-16 + UIP-13′ + UIP-17 + UIP-18
    def __init__(self, policy, V, body, sig, theta_e, theta_s,
                 tau_A, tau_B, dt, max_redo=2):
        self.policy, self.V, self.body, self.sig = policy, V, body, sig
        self.theta_e, self.theta_s = theta_e, theta_s
        self.tau_A, self.tau_B, self.dt = tau_A, tau_B, dt
        self.max_redo = max_redo

    def reset(self):
        self.g = 0                 # 当前子目标/计分步
        self.done_at = {}          # g -> t，回归证书的"曾完成"证据
        self.redo = 0
        self.mode = "NORMAL"
        self.last_chunk = None

    def get_action(self, obs):
        Q = obs["prop"]            # (F, 43) 密堆叠本体感知（UIP-17）
        e = self.body.residual(Q, self.last_chunk)          # 解析残差
        a = self.sig.anomaly(Q)                             # 签名异常分
        interrupt = (e > self.theta_e) or (a > self.theta_s)

        # 图像已随 obs 到达；这里决定是否运行视觉谓词（省推理延迟）
        if interrupt or self._at_boundary(Q) or self._stale():
            v = self.V(obs["images"], obs["language"], self.g)
            if v == "done":
                self.done_at[self.g] = self.t
                self.g += 1; self.redo = 0; self.mode = "NORMAL"
            elif v == "undone" and self.g in self.done_at:
                self.mode = "REDO"; self.redo += 1
            else:
                self.mode = "NORMAL"      # 无证书，不重做（防抖）

        if self.redo > self.max_redo:
            self.mode = "BRIDGE"; self.redo = 0

        k = self._deadline_k(self.g, interrupt)   # UIP-13′
        anchor = self._latest_state(Q)            # 重锚定到观测状态
        self.last_chunk = self.policy.get_action(
            obs, k=k, anchor=anchor, mode=self.mode)
        self.t += k
        return self.last_chunk

    def _deadline_k(self, g, interrupt):
        tau = self.tau_A if (interrupt or self._contact_phase(g)) else self.tau_B
        return max(1, min(int(tau / self.dt), self.policy.k_max))
```

> 形状合规：`get_action` 返回 `(T_a, …)`，索引 0 先执行；`T_a` 为 metadata 声明值，实际块长只可 ≤ `T_a`（v2 §3 约束继续有效）。所有"重做"都是**新调用**，不改变已返回块的形状。

### 1.4 与 v2 旗舰的差异
- v2 的 `regressed` 主要靠视觉时序差分；v3 增加 **L0 本体中断**，把 F1（打滑/跟踪失败/接触异常）从"事后发现"变成"当块内可定位"。
- v2 的验证器每步都跑；v3 用本体中断**门控视觉推理**，并把图像传输频率交给 chunk 长度控制。
- v3 新增**重锚定**：这是开放环 chunk 接口下最容易被忽视、却直接决定动作连续性与可信度的一步。

## 2. UIP-17 · PST（Proprioceptive Stacking & Transmission budget）

### 2.1 配置模板
```python
T = 8
obs_delta_indices = {
    "observation.language": [0],
    # 图像：单帧，不堆叠；按任务需要保留 2–4 路，必要时降分辨率
    "observation.images.cam_left_high":  [0],
    "observation.images.cam_right_high": [0],
    "observation.images.cam_left_wrist": [0],
    "observation.images.cam_right_wrist":[0],
    # 本体：密堆叠，覆盖刚执行完的整个 chunk
    "observation.state.left_arm":  list(range(-T, 1)),
    "observation.state.right_arm": list(range(-T, 1)),
    "observation.state.left_ee_pose_gripper_base":  list(range(-T, 1)),
    "observation.state.right_ee_pose_gripper_base": list(range(-T, 1)),
    "observation.state.left_gripper":  list(range(-T, 1)),
    "observation.state.right_gripper": list(range(-T, 1)),
    "observation.state.lower_body":    list(range(-T, 1)),
}
image_resize = {
    "observation.images.cam_left_high":  [240, 320],
    "observation.images.cam_right_high": [240, 320],
}
action_chunk_size = T
```

### 2.2 成本算术（每次调用）
| 方案 | 图像传输 | 本体传输 | 备注 |
|---|---:|---:|---|
| A：4 图 × 4 帧堆叠 | 16 张 JPEG | ≈0 | v2 式"多帧视觉"，延迟/带宽最高 |
| B：4 图 × 1 帧 + 本体 1 帧 | 4 张 JPEG | 172 B | 无时序信息 |
| **C：4 图 × 1 帧 + 本体 9 帧（本方案）** | **4 张 JPEG** | **≈1.5 KB** | 时序分辨率给本体，成本≈B |
| D：纯本体（不声明图像） | 0 | ≈1.5 KB | 只在完全无 F2 的任务可行 |

> 结论：C 用 B 的传输成本拿到接近 A 的本体时序分辨率；图像时序分辨率则交给 **chunk 长度**（调用频率）来调。**不要堆图像**。

### 2.3 待测量（不拍脑袋）
- JPEG q95 4:4:4 在 480×640 与 240×320 下的实际字节数与解码延迟；
- `lower_body[15]` 与 `pivot[7]` 在外部挪底座时的响应（F3 可观测性）；
- 关节位置伺服误差 `e_t` 与接触力的相关性（作为"无力矩传感"的代理，见 §8 假设表）。

## 3. UIP-18 · PSM（Proprioceptive Signature Model）

### 3.1 两件套
- **解析 body model（零学习，默认开启）**：用上一条动作块 `A_{t-1}` 与观测 `Q_t` 计算残差 `e_t`；阈值 `θ_e` 由正常演示的残差分位数标定。它只回答"身体是否偏离了命令"，不回答"世界是否被改"。
- **学习式签名（可选增强）**：小时间卷积/线性注意力模型，输入 `σ_t=(q,q̇,gripper,e)` 的短窗，输出异常分 `a_t`。正常数据（32 数据集）做自监督下一状态预测/重构；UIP-12 DRF 的合成干扰做正样本校准。

### 3.2 训练与合规
- 正样本：32 个公开数据集（无干扰）→ 学"正常签名流形"。
- 负样本：DRF 在 Gazebo 里复现 `human_*` 的"反向撤回"与"接触中推/拉/拿走"→ 只用于**校准阈值/评估**，不依赖真机干扰标签。
- 合规：优先做成**共享骨干上的小头**，或纯确定性滤波；不引入第二个大模型。若用外部模型，按 v2 §8 的"单模型"红线处理。

### 3.3 风险
伺服误差未必等于接触力（取决于控制器刚度与重力补偿）；必须用 §2.3 的标定实验验证，否则 `e_t` 只能当"跟踪异常"而非"接触事件"。

## 4. UIP-13′ · DCD（Deadline-Centric chunk scheduler）

- **推导**：设控制步长 `Δt`，接触段可容忍未检测时长 `τ_A`，世界回退可容忍未确认时长 `τ_B`，则
  `k_contact = floor(τ_A/Δt)`，`k_transport = floor(τ_B/Δt)`，且 `1 ≤ k ≤ T_a`。
- **取值来源**：`τ_A` 由任务接触动力学给（插入/拧动/拉链/合盖取小），`τ_B` 由"步骤分被回退的代价"给（末步分值高→`τ_B` 取小）。
- **调度规则**：L0 中断→下一块取 `k_contact`；平滑运输→取 `k_transport`；`REDO`→`k_contact`；`SAFE`→`k_transport` 且只保前置。
- **与 v2 ACS 差异**：v2 是"按阶段经验选 k"；v3 把 k 写成 `τ/Δt` 的可测函数，并明确"图像频率 = 调用频率 = 1/k"。

## 5. UIP-19 · IPM（Innovation-Point Mining protocol）

### 5.1 协议
```text
输入：规则事实 R、数据事实 D、接口事实 I、目标口径 O（成功率+步骤分+可信度）
1. 负空间扫描 N：找 R 写了但 D 没有的现象（如 human_* 反向撤回）
2. 失败分解 F：把 O 的损失拆成 F1 自执行 / F2 世界回退 / F3 全局位移
3. 信号替换 S：对每个 F，问"接口里最便宜且能覆盖它的信号是什么"
4. 约束反转 C：把接口限制变成机制（chunk→本体模板；固定 obs→堆本体不堆图）
5. 组合 X：把覆盖不同 F 的机制串起来（本体中断 × 视觉证书 × 块调度）
6. 证伪 T：为每个候选写"哪个实验、什么结果判死刑"
7. 过滤 P：权限（API 内）/合规（单模型）/证据（R 或 D 支持）
8. 排序：按 (Δ, 资源, 风险) 的 Pareto 前沿，而不是单一分数
输出：候选清单 + 证伪卡 + 账本
```

### 5.2 排序 rubric（每项 0–3 分）
| 维度 | 0 | 3 |
|---|---|---|
| 证据强度 | 纯猜测 | 规则/接口白纸黑字 + 数据缺口 |
| 权限内 | 需改评测端 | 纯 `get_action/reset/metadata` |
| 单模型合规 | 需外部大模型 | 共享骨干/确定性规则 |
| 预期 Δ | 无路径到分数 | 直接命中计分步或可信度 |
| 可证伪性 | 无法测 | 有明确对照实验与阈值 |
| 资源 | 多卡多周 | 单卡/CPU 可跑 |

### 5.3 证伪卡（存活项）
| 编号 | 一句话证伪测试 | 判死条件 |
|---|---|---|
| UIP-16 | 在 F2 撤回任务上，本体中断能否把视觉复核的延迟/漏检降下来 | 相对"每块都跑 V"无显著改善，或重做误报率 > 阈值 |
| UIP-17 | 方案 C vs A/B 的端到端延迟、带宽、步骤分 | C 的步骤分显著低于 A，或延迟无改善 |
| UIP-18 | 正常 vs DRF 干扰的异常分 AUROC | AUROC ≈ 0.5（残差无区分度） |
| UIP-13′ | 固定 k vs DCD 的步骤分与延迟方差 | 步骤分下降或方差未降 |
| UIP-19 | 用/不用协议各挖 20 个候选，比较存活率与专家评分 | 无显著差异（则协议只是文档） |

## 9. 合规与风险

- **单模型**：UIP-18 优先共享骨干小头或确定性滤波；不引入外部大模型。
- **接口红线**：`obs_delta_indices` 偏移 ≤0 且严格递增；`language=[0]`；动作形状 `(T_a,…)`；返回块长不得超过声明值；`meta.token` 每次必带。
- **可信度**：UIP-15 升级为"重锚定/重做"的延迟-抖动预算；`SAFE` 模式优先保前置步骤分，避免为搏末步而超时。
- **仿真过拟合**：GSO/DRF 仍是结构代理；F2 与 F1 的真机校准不可省。
- **手册未取到**：位置/干扰物/背景三轴与评测轮次/时限/控制频率仍待飞书手册公开后核实。

## 11. 本轮最大风险 & 押注

**一句话**：最可能翻车的不是"本体感知不够强"，而是**把 F1 的廉价信号误当成 F2 的证据**，于是该看图时没看、或在不该重做时反复重做，最终既丢步骤分又伤可信度。

**→ 押注：UIP-16 CMR-D（本体中断 + 视觉回归证书 + 重锚定）× UIP-17 PST（堆本体不堆图）× UIP-18 PSM（F1 签名）**——它把"最便宜的信号"用在它真正擅长的 F1 上，把"最贵的信号"只用于 F2 的证书时刻，并用 UIP-19 的证伪卡持续修剪，避免再次把灵感词直接当成方案。
