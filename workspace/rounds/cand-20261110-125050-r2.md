# 第 44 轮（新循环第 4 轮） · Repro-Cert × Claim-Ledger：把「论文发表」与「基线复现」纳入可验证研究闭环（五层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 已堆到 3 个新 IP、10 项升级、E87–E94 八条硬门槛，却从未回答一个更基础的问题：**这些结论里，哪些真的能发表？** 审稿人会追问三件事——(Q1) **基线**是谁，是否在同等预算下被复现？(Q2) 每个组件是否做过**消融**，去掉它还成立吗？(Q3) 结果能否被第三方**复现**？v20 对三问皆无答案。本轮灵感词「论文发表」「基线复现」正好把研究对象从「机器人的证书」翻转成「论文主张的证书」：一篇论文不是架构图，而是一组可证伪主张；基线是控制变量，复现是控制变量的证书。

## 0. 直觉与动机

**灵感 1（论文发表 → 论文是「主张集合」，每条主张都要证据证书）**：直觉上，论文里最脆弱的不是算法，而是「我们比 X 好」这句话——它默认了 X 被正确实现、在同等预算下比较、且差异不是噪声。于是把每条主张写成六元组 c=(陈述 S, 实验 E, 基线集 B, 效应量 Δ 与置信区间 CI, 工件哈希 A, 证伪条件 F)。**主张收缩免费、扩张持证**：说「在我测过的 N 次里没出事」永远安全；说「一般安全」就必须付出证据。这与 v20 的「收缩免费、扩张持证」是同一结构，只是对象从动作域换成**证据域**。

**灵感 2（基线复现 → 基线是尺子，未复现的基线是没刻度的尺子）**：与一个没复现的基线比较，等于用一把不知道刻度的尺子量长度。因此先给基线发**复现证书** R_k=(基线, 匹配预算 β, 容差 ε_k, 复现差距 g_k, 是否有效)。只有在**同等算力/数据/人类被试**下复现到 g_k≤ε_k，该基线才允许进入对比。复现差距本身是结果，必须报告——负结果也是科学产出。

**灵感 3（耦合 → 证据域是三个集合的交，而且会过期）**：主张能覆盖的范围 **E_c = E_预注册 ∩ E_实测 ∩ E_可复现**，与 v20 的 C_u=C_global∩Π_u 同构——三者取交，任一为空则主张不可发表。更狠的是证据会**过期**：软件版本、硬件批次、数据集漂移会让旧复现失效，所以证据需要**租约**（复用定义 41 的衰减思想）。最后，「0 起违例」不是零概率：N 次零失败只能给出**统计上界** 1−α^{1/N}，v20 的 E87–E94 若不标注 (N, p0, α)，红线实验在统计上无法证伪。

**元层升级**：在 v8 机器人架构之外加一个 **M 层（科研证据层）**：RBH 复现基线、CLC 给主张发证、AOA 做消融与最小性审计、PRL 预注册锁定。机器人架构不动，但所有「创新点」必须先过 M 层才能写进论文。一句话：**先证明我们没骗自己，再证明我们比基线好。**

## 1. 形式化定义（增量：定义 44–49）

**定义 44（预算匹配复现证书）**：基线 B_k 在环境 E 下以匹配预算 β=(算力, 数据, 人类被试时长) 复现，得 R_k=(B_k, β, ε_k, g_k, valid)。其中 g_k=d(复现指标, 原文指标) 为加权差距（成功率、违例率、p99 时延、能耗），ε_k 预注册。**有效判据**：g_k≤ε_k 且复现置信区间与原文在容差内重叠。**引理**：若 B_k 无有效 R_k，则任何「优于 B_k」的主张不可发表（尺子未校准）。

**定义 45（主张证书与证据域）**：主张 c=(S,E,B,Δ,CI,A,F)，证据域 **E_c=E_pre∩E_meas∩E_repro**。c **可发表**当且仅当：(1) E_pre 覆盖 c（预注册）；(2) ∀B_k∈B，R_k.valid；(3) Δ 在预注册检验下显著且 CI 不含 0；(4) A 达到 Reusable 级工件；(5) 证伪条件 F 未被观测。**命题（证据单调性）**：收缩 S（限定条件、降低强度）只会扩大 E_c，永不使已可发表的主张失效；扩张 S 必须新增证据。

**定义 46（消融必要性与组件最小集）**：对架构 A 的组件 x，做留一消融 A\{x}。x **必要**当且仅当存在红线实验 e，使指标相对全集下降超过预注册阈值且显著（配对检验）。必要集 N={x: necessary}。**发表要求**：报告 N；不在 N 中的组件必须显式标注「仅设计/未证收益」或直接删除。**推论**：该定义把「堆 IP」从优点变成待证负担。

**定义 47（零违例的统计上界）**：N 次独立试验零失败时，单侧 1−α 置信上界 **U(N,0,1−α)=1−α^{1/N}**（Clopper–Pearson）。要声称违例率 < p0（置信 1−α），需 **N ≥ ln α / ln(1−p0)**。例：p0=10⁻³, α=0.05 ⟹ N≈2995；p0=10⁻² ⟹ N≈299。**规范**：任何「0 起」红线必须写成 (N,p0,α) 三元组；不写即视为不可证伪。

**定义 48（证据租约与时效性）**：复现证书带租约 ℓ_R=(版本哈希, 硬件批次, 数据集指纹, 签发时刻 τ, 有效期 T)。**时效判据**：t−τ≤T 且依赖哈希未变，R_k 才可用于对比；否则过期，必须重跑。**命题**：证据复用不跨版本——把旧证书套到新代码/新硬件上，与定义 41 的陈旧边际误用同类错误。

**定义 49（预注册锁定与修订日志）**：执行前把 (E87–E94, 指标, 阈值, N, 统计检验, 分析计划) 规范化并哈希 h0 发布（时间戳）。任何执行中的改动必须记修订 (diff, 理由, 新哈希)，论文报告**全部修订**。**推论**：阈值只能预先声明，不能看到结果后回调（防 HARKing / p-hacking / 阈值漂移）。

## 2. 四大新增产出与既有 IP 的「发表化」改造

### 2.1 IP-60 REPRO-BASELINE-HARNESS（复现基线夹具 RBH）
1. **匹配预算复现**：把强基线（CBF-only、conformal-only、simplex/串行 anytime、VLM+RAG）在同一仿真/硬件/数据/被试预算下重建。
2. **复现证书签发**：计算 g_k、bootstrap CI、有效性；未达标基线标记「未复现」并排除出对比。
3. **差距报告**：复现差距作为一等结果输出（含失败原因：超参、缺失数据、硬件差异）。

### 2.2 IP-61 CLAIM-LEDGER-CERT（主张账本 CLC）
1. **主张编译**：论文每句话 → c=(S,E,B,Δ,CI,A,F)，拒绝「无实验/无基线/无 CI」的主张。
2. **证据域求交**：自动计算 E_c=E_pre∩E_meas∩E_repro；空集即禁止发表。
3. **统计闸门**：配对检验 + 效应量 + Holm 多重比较校正；零违例自动补 Clopper–Pearson 上界。

### 2.3 IP-62 ABLATION-ORACLE（消融与最小性审计 AOA）
1. **留一 + 构建式消融**：对 IP-57/58/59 及关键升级逐一剔除。
2. **2×2 因子设计**：persona(on/off) × concurrency(on/off)，检验「个性化×并发」的交互是否真实存在（这是 v20 的核心卖点）。
3. **必要性裁决**：输出必要集 N 与冗余集；冗余组件必须删除或降级为「设计说明」。

### 2.4 IP-63 PRE-REGISTRATION-LOCK（预注册锁 PRL）
1. **哈希锁定**：E87–E94 设计与阈值执行前锁定并公开。
2. **修订审计**：所有改动进修订日志，论文附录全量披露。
3. **工件徽章**：按 ACM Available/Functional/Reusable 三级要求打包（Docker、种子、配置、原始日志）。

## 5. 本轮最大风险

**一句话**：用「证书化科研」再叠一层未经验证的元架构，同时严格的 N 与预注册会把 v20 大量「0 起」红线证伪为**样本不足**、把多数 IP 证伪为**冗余**——科学诚实与「创新点数量」叙事正面冲突，最坏结果是论文被自己的 M 层判为不可发表。

## 2. 关键算法（伪代码）

### IP-60 QCA：误差传播、格点守卫、双层边际与混合精度
```
def quant_error_bound(net_q, x):
    # 区间/仿射算术，端到端：权重/激活量化误差各带噪声符号
    xa = Affine(x)
    for layer in net_q.layers:
        xa = layer.affine(xa)                    # 权重量化误差作为新噪声符号
        xa += noise_symbol(layer.act_step)       # 激活量化误差
    return xa.radius()                           # δ(x) = ||e_Q||

def lattice_guard(g_float, x, delta, L_g):
    lo = g_float(x) - L_g * delta                # 决策下界
    hi = g_float(x) + L_g * delta                # 决策上界
    if lo <= 0 <= hi:                            # 边界落入误差区间
        return UNDECIDED                         # 禁止硬判安全
    return SAFE if lo > 0 else UNSAFE

def two_tier_margin(m_float, x, delta_wc, delta_cal, regime):
    m_A = m_float - L_g * delta_wc               # 构造性 sound
    if regime == 'tight' and coverage_ok(x) and not drift(x):
        m_B = m_float - L_g * delta_cal(x)       # 三闸门后的概率 sound
        return min(m_A, m_B), 'tight'
    return m_A, 'robust'                         # 红线守卫只用此支

def allocate_precision(modules, E_max, b_min):
    b = {i: b_min[i] for i in modules}
    while E(b) > E_max:                          # E 必须是 sound 上界
        i = argmax_{i: b_i < b_max[i]} sensitivity(i, b[i]) / cost_delta(i)
        b[i] += 1                                # 把比特花在证书敏感处
    return b

def quant_aware_threshold_compile(monitor, delta, L_h):
    # CMC 阈值修正：保证量化后监控器仍覆盖 float 语义
    return {e: monitor.theta[e] + L_h * delta(e) for e in monitor.edges}
```

```
def pose_modes(obs, model, sym_group, k):

    if identity_changed(H_prev, H_cur) and \
       dist_between_modes(H_prev, H_cur) > tau_flip:
        return ESCALATE                          # 触发重观测/精度升级
    return OK
```

```
def joint_stress(quant_net, pose_net, sym_objects, alpha_q, alpha_p):

def audit_ledger(cert, realized_margin):

    assert all(e.provenance for e in cert.ledger)  # 禁止未记账误差
    return gap, blame

def escalate_or_degrade(trigger, deadline, shadow_float):
    if trigger and shadow_float.ready_within(deadline):
```
