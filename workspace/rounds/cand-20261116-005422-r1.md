# 第 11 轮（新灵感循环第 2 轮；本轮灵感：「机器人操作系统」×「夹爪控制」）
> **基线**：第 10 轮 MetricVoiceGauge-STF-NRB-LS（定义 540–548；引理 87–91；实验 E571–E590）。
> 本轮纪律：**运行时前提可验证 + 接触物理判真 + 只收缩不扩权**。两个灵感分别治理 v10 的两笔债：**前提债**（STF 的 freshness/Δ_dom 前提默认"数据按时、按源、按契约到达"，但这是对运行时系统的假设，从未被监控——v10 自认的最大风险是 τ_sem 分割被穿透，而穿透的一个必要前提正是数据链路本身可信）、**落地债**（证书把"抓得稳"压缩成标量 γ̂_grasp，但真正的失败发生在接触面：滑移、压碎、摩擦锥越界——这是操纵任务里唯一不可逆的物理损失）。必须保持 v10 铁律：任一新模块失效 ⇒ 声明中立元，行为严格**等价**（ROCP/CRC/STF/AC/ID/MW）或**支配**（GSE/NRB）于 v10；更强地，本轮证明 **K_eff^v11 ≤ K_eff^v10、物理可行集 ⊆ v10**，v11 是 v10 的保守精化而非能力扩张。

## 0. 直觉与动机

**灵感 1（机器人操作系统 → 把"数据及时可信"从假设变成可执行契约）**
直觉：v10 的证书像一个只在实验室里成立的证明——它假定输入是新鲜的、来自它以为的那个节点、在预算内到达。但真实机器人是**节点图**：相机、IMU、检测器、估计器、规划器通过中间件以消息相连，每条边都有自己的截止期、可靠性、存活性与消息年龄。这些恰恰是证书前提的物理载体。ROS 的 QoS（deadline/liveliness/reliability/durability）与生命周期节点，给了我们**把前提编译成可执行契约**的语言。核心创新：**ROS 图运行契约与溯源（ROCP）**——把证书的 freshness/Δ_dom 前提编译为依赖锥 Dep(ζ) 上每条边的 QoS 契约 q_e=(D_e,R_e,A_e,L_e)，每条消息携带溯源戳 prov(m)；守卫每周期检查**运行溯源向量 o_t∈{0,1}^{|E_dep|}**，任一上游边违约 ⇒ 证书失效 ⇒ K_eff←1。理论上关键一步：v10 的前提"数据新鲜"是**不可在线证伪的强命题**；ROCP 把它换成"依赖锥上每条边在窗口内满足其契约"这一**运行时可直接测量的弱命题**——这正是 v10 对 v9 做过的那种"前提降级"，只是这次作用在系统层而非语义层。同时 ROS 2 的 lifecycle 把九级退化链变成**确定性状态迁移**，rosbag+溯源使**确定性重放**成为台账审计的物理基础。

**灵感 2（夹爪控制 → 把"抓得稳"从标量分数换成接触物理判据）**
直觉：γ̂_grasp 是一个分数，但物体不会因为分数低而掉——它掉是因为**接触力越出摩擦锥**。夹爪控制提供的是接触层的物理真值：摩擦锥、力闭合、滑移裕度、压碎力上限。核心创新：**接触稳健性证书（CRC）**——用抓取矩阵 G 把预测的物体加速度/外力矩映射为所需接触力 f_req，用**标定摩擦下界 μ_lo** 计算滑移裕度 ρ_c = min_i (μ_lo f_{i,n} − ‖f_{i,t}‖)/f_scale；块只有在 ρ_c ≥ ρ_min（可证阈值，非经验调参）且峰值接触力满足压碎约束时才有效。配套**夹爪安全包络（GSE）**：1kHz 力/位投影器，把夹持力夹在 [f_min_slip, f_max_crush] 并保持摩擦锥可行；失效 ⇒ **最大裕度保持**（在压碎上限内夹紧、机械臂零加速度），绝不松开。关键：接触通道**独立于视觉/语义**，对抗纹理无法让摩擦锥变宽——这是对 v10 最大风险（语义分割被穿透）的第二条物理独立防线。

**灵感 3（咬合：两侧证书）**
直觉：系统有两侧——上游是"信息怎么来"，下游是"力怎么落到物体上"。v10 只证了中间"预测—间隙—努力"这一段。ROCP 证上游（时间/来源可信），CRC+GSE 证下游（接触稳固），v10 证中间。三者合成**两侧证书 Ĉ_t^op = (ĝ_min, ê_max, γ̂_grasp, β_STF, o_t, ρ_c, n_t)**。两侧都是**不可被语义欺骗**的通道：时间戳与存活性是系统事实，摩擦锥是物理事实。

## 1. 研究问题（轮次升级版）

- **Q1（运行可信）**：如何把证书的 freshness/Δ_dom 前提编译为 ROS 依赖锥 QoS 契约与溯源监控，使"数据及时可信"成为运行时可测谓词、违约在 1 个守卫周期内被捕获（注入故障检出 ≥99%、误失效 ≤1%），且 ROCP 失效严格等价 v10？
- **Q2（接触判真）**：如何用标定摩擦下界 μ_lo 的摩擦锥裕度 ρ_c 替换/精化标量 γ̂_grasp，使在 μ_true ≥ μ_lo 时预测扰动下滑移率 0、压碎力 ≤ 上限、ρ_c 覆盖 ≥99%，且接触模型不可用时退化为 v10 而非静默信任？
- **Q3（两侧支配）**：ROCP+CRC+GSE 如何合成两侧证书，使 K_eff^v11 ≤ K_eff^v10、物理可行集 ⊆ v10，并满足时序/内存/能耗预算与确定性重放审计？

## 2. 设计原则（在 P13–P15 基础上新增 P16–P18）

**P16 运行时前提可验证律（Runtime-Verifiable Premise, ROCP）**
证书依赖的每个时间/新鲜度/来源前提，必须编译为可执行的 QoS 契约与运行时监控；未被监控的前提不得授予信任。监控不可用时声明中立（o≡1）并回退 v10，绝不比 v10 更信任。

**P17 接触物理判真律（Contact-Physical Grounding, CRC）**
抓取安全必须由接触层物理裕度（摩擦锥、滑移、压碎）判定，不得由标量外观/质量分数判定；摩擦下界 μ_lo 必须标定且保守。接触模型不可用时不得静默信任——退化为 v10 的 γ̂_grasp（中立）或收缩。

**P18 边缘包络支配律（Edge-Envelope Dominance, GSE）**
夹爪安全包络只许把指令裁剪进 C_g_safe，绝不产生新指令；失效 ⇒ 最大裕度保持，绝不松开；物理行为 ⊆ v10。

## 3. 与基线的接口（如何退化）

- **ROCP 失效**（QoS 监控/图发现/溯源缺失）⇒ o_t≡1、U_t^op←v10 freshness 检查：严格等价 v10；
- **CRC 失效**（接触模型不可用/μ 标定过期/力觉故障）⇒ ρ_c←∞（中立，不施加接触约束）、证书回 v10 Ĉ⁺：严格等价 v10；
- **GSE 失效**（投影超时/力觉饱和）⇒ 保持当前夹持力 + 重力补偿臂（v6 级），绝不松开：支配 v10；
- **STF 失效** ⇒ K=1、β←β_base（v10 Level-1）；**NRB 失效** ⇒ Π_r（v10 Level-2）；**AC 失效** ⇒ K=1（v10 Level-3）；**ID 失效** ⇒ 全模块 active（v10 Level-4）；**MW 失效** ⇒ 手写网关；**v8 失效** ⇒ 中立元 ⇒ v7 ⇒ v6。
- **单调性（本轮新增硬约束）**：o_t 是 AND 门（只会 valid→invalid）；K_eff^v11=min(K_eff^v10, K_candidate) ≤ K_eff^v10；GSE 只裁剪不生成；三者共同保证 v11 物理可行集 ⊆ v10。

## 4. 预期贡献

1. **运行可信证书**：把 v10 未监控的时间前提编译为 ROS QoS 契约 + 溯源，前提从"假设"变"可测"（引理 92–93）；
2. **接触稳健证书**：用摩擦锥裕度替换标量抓取分数，滑移/压碎成为可证约束（引理 94–95）；
3. **两侧独立安全通道**：系统时间事实 + 接触物理事实均不可被对抗纹理欺骗，正面削弱 v10 的 τ_sem 风险（引理 96）；
4. **E591–E610** 覆盖 μ 标定、QoS 故障注入、时钟同步、湿滑摩擦、滑移/压碎、两侧联合压测、重放审计、长跑与竞赛。

## 5. 本轮最大风险

**一句话**：ROCP 依赖"依赖锥与时钟同步正确"、CRC 依赖"摩擦下界 μ_lo 保守"这两个不可在线证伪的系统/物理前提——隐藏依赖或跨节点时钟漂移会让 o_t 假阳（误以为数据可信），湿滑/油污表面会让 μ_true < μ_lo 使 ρ_c ≥ ρ_min 却仍滑移，此时系统以"时间已证 + 接触已证"的双重外观错误放行，比 v10 的单点经验阈值更隐蔽。

**新增定义 549（ROS 依赖锥）** 对块 ζ，Dep(ζ)=(V_dep,E_dep) ⊆ G 是所有因果贡献于 ζ 生成输入（传感器、估计、地图、规划）的节点及其消息边。E_dep 由数据流溯源图与显式订阅关系确定；**隐藏依赖**（共享参数、全局时钟、隐式环境依赖）不计入 E_dep——这是本轮风险之一，须由 E593 显式探测。

**新增定义 550（QoS 契约编译）** 每条边 e∈E_dep 的契约 q_e=(D_e,R_e,A_e,L_e)。证书生成时由 freshness/Δ_dom 前提**编译**：A_e ≤ T_fresh；D_e ≤ 该数据在决策预算中的份额；R_e、L_e 取安全关键流的最低要求。**契约不是新假设，而是把 v10 已有假设显式化为可监控量**。

**新增定义 551（溯源戳与运行满足）** 消息 m 携带 prov(m)=(producer, seq, t_gen, t_recv, q_e, delivered)。边 e 在 t **运行满足** opsat_e(t) ⇔ (liveliness 保持) ∧ (t−t_gen(m*) ≤ A_e) ∧ (deadline 违约计数=0) ∧ (丢失率 ≤ 1−R_e)，m* 为最近消息。**运行信任域** U_t^op ⇔ ∧_{e∈E_dep} opsat_e(t) ∧ freshness ≤ T_fresh。o_t(e)=1[opsat_e(t)]。

**新增定义 552（两侧块证书）** Ĉ_t^op = (ĝ_min, ê_max, γ̂_grasp, β_STF, o_t, ρ_c, n_t, g_abort)。有效 ⇔ v10 定义 543 条件 ∧ o_t 全 1 ∧ (CRC 离线时 ρ_c=∞ 视为中立，否则 ρ_c ≥ ρ_min) ∧ g_abort 非空。

**新增定义 553（有效块长升级）**
```
K_eff(t) = 1                                    若 ¬U_t^op 或 ¬U_t^sem 或 Ĉ_t^op 不可得
         = 2                                    若 NRB 失效（Π_r 级）
         = max(1, ⌊K_max·(1 − min(1, max(Δ_dom/τ_dom,
                                          sup_走廊 T/τ_sem,
                                          op_viol/τ_op)))⌋)   否则
```
其中 op_viol = 1 − mean(o_t)（依赖锥违约比例），τ_op 由 E592 标定。**运行通道与语义通道取 max：任一越阈即收缩**。

**新增定义 554（摩擦锥与力闭合）** 接触 i 法向 f_{i,n}≥0、切向 f_{i,t}；FC_i(μ)={f: ‖f_{i,t}‖≤μ f_{i,n}, f_{i,n}≥0}。抓取矩阵 G∈ℝ^{6×3c} 映射接触力到物体外力。**力闭合** ⇔ ∃ f_int∈ker(G) 使 f_int,i∈int FC_i(μ_lo) 且内部力裕度>0。

**新增定义 555（所需接触力与滑移裕度）** 预测物体加速度 a_obj(t) 与外矩 w_ext(t)（重力 + 预测接触），物体 Newton–Euler：需 G f = M a_obj − w_ext。取 f_req(t)=G⁺(M a_obj − w_ext)+f_int（f_int 取最大裕度内力的解析解）。**滑移裕度** ρ_c = min_i (μ_lo f_{i,n} − ‖f_{i,t}‖)/f_scale，f_scale 为归一化（如最大法向力）。ρ_c>0 ⇔ 接触力在 μ_lo 摩擦锥内。

**新增定义 556（接触稳健性证书）** CRC 对块 ζ 时间线逐点计算：ρ_c(ζ)=min_{t∈ζ} min_i ρ_{c,i}(t)，其中 f_req 用**证书误差最坏角** w_ext±β_w 计算（β_w 由 β_STF 传播到物体外矩）。块接触有效 ⇔ ρ_c(ζ) ≥ ρ_min ∧ max_t‖f_req(t)‖_∞ ≤ f_max_crush。

**新增定义 557（可证接触阈值 ρ_min）** 由 E591 标定：ρ_min = k_σ·σ_contact + ε_model，使正常抓取 ρ_c ≥ ρ_min 概率 ≥1−ε_c（k_σ=3）。**非经验调参**，与 γ_min 同构；μ_lo 用同样的保守标定（取 μ 置信下界）。

**新增定义 558（安全夹持集与 GSE）** C_g_safe = {f_grip : f_min_slip(ρ_c) ≤ f_grip ≤ f_max_crush, 接触力∈FC(μ_lo) 且裕度≥ρ_min, 电流/温度限内}。1kHz 投影 Proj_{C_g_safe}(f_cmd)。**仅依赖力/触觉本体感觉与标定接触模型，不依赖视觉/语义**。

**新增定义 559（滑移检测）** 触觉/力导数 s(t)=‖df_t/dt‖/(f_n+ε)；若 s>s_slip 且持续 k_s 帧 ⇒ 滑移预警 ⇒ 收缩（增夹持力至上限或中止）。s_slip、k_s 由 E595 标定。

**新增定义 560（最大裕度保持与中止映射）** CRC 失败或滑移预警 ⇒ g_abort = argmax_{f∈C_g_safe} ρ_c(f)（在压碎上限内取最大裕度），同时机械臂减速度受限 a_dec ≤ a_max^slip(μ_lo)，使沿中止轨迹 ρ_c(t)≥ρ_min。GSE 失效 ⇒ 保持当前夹持力 + 重力补偿臂（零速）。**任务空间中止点 p* 与 g_abort 成对下发**。

**新增定义 561（六检守卫）** 50Hz 六检（全部 O(k)，k≤8）：(i) 证书有效；(ii) 停车不变式；(iii) 语义创新度 sup ν̄ ≤ τ_sem；(iv) 快规范；(v) **运行溯源 o_t 全 1（QoS 未违约）**；(vi) **接触裕度 ρ_c ≥ ρ_min 且无滑移预警**。任一失败 ⇒ 最近中止点 + GSE 最大裕度保持。总预算 ≤0.7ms。

**新增定义 562（溯源台账与确定性重放）** Λ 扩展记录 prov(m)、o_t、ρ_c、GSE 投影位移与活跃约束。ROS 时间戳 + 溯源使 rosbag 可**确定性重放**：离线按同一 o_t/ρ_c 复算，定位"当时为何放行/中止"。哈希链 κ_h=256 不变。

# IP-361 ROSGraphOperationalContract：把证书时间前提编译成可监控的 QoS 契约
class ROSGraphOperationalContract:
    def __init__(self, graph, qos, clock, T_fresh=2.0, tau_op=0.05):
        self.graph = graph          # ROS discovery 得到的节点图
        self.qos = qos              # e -> (D_e, R_e, A_e, L_e)
        self.clock = clock          # ROS time（跨节点同步）
        self.T_fresh, self.tau_op = T_fresh, tau_op
        self._dep_cone = {}         # chunk_class -> E_dep（可缓存）

    def compile_from_certificate(self, assumptions):
        # freshness/Δ_dom 前提 -> 每边 A_e、D_e 的保守上界
        for e, a in assumptions.items():
            q = self.qos[e]
            self.qos[e] = (min(q.D_e, a.deadline),
                           q.R_e, min(q.A_e, a.max_age), q.L_e)

    def opsat(self, e, now):
        st = self.graph.edge_state(e)
        q = self.qos[e]
        if not st.liveliness_ok:
            return False
        if now - st.last_msg.t_gen > q.A_e:      # 用 t_gen 而非 t_recv：防缓冲造假
            return False
        if st.deadline_miss_count > 0:
            return False
        if st.loss_rate > 1.0 - q.R_e:
            return False
        return True

    def provenance_vector(self, chunk, now):
        o = {}
        for e in self.dep_cone(chunk):
            o[e] = 1 if self.opsat(e, now) else 0
        return o

    def operational_trust(self, chunk, now):
        return all(self.provenance_vector(chunk, now).values())

    def dep_cone(self, chunk):
        return self._dep_cone.setdefault(chunk.cls, self.graph.causal_ancestors(chunk.inputs))


# IP-362 ContactRobustnessCertificate：摩擦锥/滑移/压碎的接触判据
class ContactRobustnessCertificate:
    def __init__(self, grasp_map, mu_lo, rho_min, f_max_crush,
                 mass, inertia, f_scale, eps_model):
        self.G = grasp_map          # 6 x 3c
        self.G_pinv = np.linalg.pinv(grasp_map)
        self.mu_lo = mu_lo          # 标定下界，<= mu_true
        self.rho_min = rho_min      # 可证阈值（E591）
        self.f_max_crush = f_max_crush
        self.M, self.I = mass, inertia
        self.f_scale, self.eps = f_scale, eps_model

    def required_force(self, a_obj, alpha_obj, w_ext):
        # 物体 Newton-Euler：广义力 = M*a - w_ext（含转动）
        w = self._obj_wrench(a_obj, alpha_obj) - w_ext
        return self.G_pinv @ w

    def slip_margin(self, f_req):
        rho = float('inf')
        for i in range(len(f_req) // 3):
            fn, ft = f_req[3*i], np.linalg.norm(f_req[3*i+1:3*i+3])
            if fn <= 0:
                return -float('inf')
            rho = min(rho, (self.mu_lo * fn - ft) / self.f_scale)
        return rho

    def certify(self, pred, grasp, beta_w):
        worst = float('inf')
        for t in pred.timeline:
            for dw in beta_w.corners():                 # 误差最坏角
                f_req = self.required_force(pred.a_obj(t), pred.alpha(t),
                                            pred.w_ext(t) + dw) + grasp.f_int
                if np.any(f_req[0::3] <= 0):
                    return False, -float('inf')
                if np.max(np.abs(f_req)) > self.f_max_crush:
                    return False, worst
                rho = self.slip_margin(f_req)
                worst = min(worst, rho)
                if rho < self.rho_min:
                    return False, rho
        return True, worst


# IP-363 GripperSafetyEnvelope：1kHz 接触力投影 + 滑移预警 + 最大裕度保持
class GripperSafetyEnvelope:
    def __init__(self, crc, f_min, f_max, s_slip, k_s, dt=0.001):
        self.crc, self.f_min, self.f_max = crc, f_min, f_max
        self.s_slip, self.k_s, self.dt = s_slip, k_s, dt
        self._slip_count = 0
        self.healthy = True

    def project(self, f_cmd, contact, a_obj):
        if not self.healthy:
            return self._secure_hold(contact)
        if self._slip_warning(contact):
            return self._secure_hold(contact)           # 先夹紧/停，再谈轨迹
        f_lo = self._min_force_for_slip(contact, a_obj)  # 保证 rho_c >= rho_min
        f_hi = min(self.f_max, self.crc.f_max_crush)
        f_safe = np.clip(f_cmd, f_lo, f_hi)
        if not self._friction_feasible(f_safe, contact):
            self.healthy = False
            return self._secure_hold(contact)
        return f_safe

    def _slip_warning(self, contact):
        s = np.linalg.norm(contact.df_t) / (contact.f_n + 1e-9)
        self._slip_count = self._slip_count + 1 if s > self.s_slip else 0
        return self._slip_count >= self.k_s

    def _secure_hold(self, contact):
        # 最大摩擦锥裕度（压碎上限内），机械臂由 AC 同步降至零加速度
        return self._argmax_margin_force(contact, upper=self.crc.f_max_crush)


# IP-354（升级）：两侧证书分块执行器
class TwoSidedChunkCertifier(StructuredChunkCertifier):
    def __init__(self, *a, rocp=None, crc=None, gse=None, **kw):
        super().__init__(*a, **kw)
        self.rocp, self.crc, self.gse = rocp, crc, gse

    def generate_chunk(self, state, ctx, stf, nrb):
        K = self.effective_K(ctx.delta_dom, ctx.tau_dom,
                             trust_ok=stf.trust_ok(ctx),
                             op_ok=self.rocp.operational_trust(ctx, ctx.now))  # 定义 553
        if K == 1:
            return self._single_step_fallback(state)
        best = None
        for cand in self.policy.sample_sequences(state, K, n=64):
            pred = self.Fq.rollout(state, cand)
            beta_stf = self.beta_base + self.lam * stf.field_on_footprint(pred.corridor)
            g_min = pred.min_clearance - beta_stf
            e_max = pred.max_effort + beta_stf
            if g_min < self.d_safe or e_max > state.tau_eff:
                continue
            pts = self._abort_points(state, cand, pred)
            if not pts:
                continue
            # CRC：接触层证书（误差最坏角由 beta_stf 传播）
            contact_ok, rho_c = self.crc.certify(pred, state.grasp,
                                                 beta_w=beta_from(beta_stf))
            if not contact_ok:
                continue
            chunk = Chunk(cand, TwoSidedCert(g_min, e_max, beta_stf, rho_c, pts), pts)
            chunk, verdict = nrb.review_chunk(chunk, stf, ctx)
            if chunk is None:
                continue
            chunk.cert.o_t = self.rocp.provenance_vector(chunk, ctx.now)
            if not all(chunk.cert.o_t.values()):
                chunk.cert.valid = False
                continue
            chunk.cert.g_abort = self.gse.secure_hold(state.contact)
            score = self.policy.score(chunk, pred)
            if best is None or score > best.score:
                best = chunk
        return best or self._single_step_fallback(state)

    def midchunk_guard(self, chunk, k_exec, live_obs, stf, nrb, rocp, crc, gse):
        """50Hz 六检 ≤0.7ms"""
        if not chunk.cert_still_valid(live_obs):
            return self._abort(chunk, k_exec, gse)
        stop_inv = (live_obs.nearest_clearance
                    - self.d_brake(live_obs.speed) - self.d_safe)
        if stop_inv < chunk.remaining_len(k_exec):
            return self._abort(chunk, k_exec, gse)
        if stf.surprise_near(live_obs.pose) > stf.tau_sem:
            return self._abort(chunk, k_exec, gse)
        if nrb.fast_norms(live_obs).violated:
            return self._abort(chunk, k_exec, gse)
        if not all(rocp.provenance_vector(chunk, live_obs.now).values()):  # 检 5
            return self._abort(chunk, k_exec, gse)
        if (live_obs.contact.rho_c < crc.rho_min
                or gse._slip_warning(live_obs.contact)):                  # 检 6
            return self._abort(chunk, k_exec, gse)
        return ('continue', k_exec + 1)

    def _abort(self, chunk, k_exec, gse):
        p_star = chunk.nearest_abort_point(k_exec)
        g_abort = gse.secure_hold(chunk.contact)
        return ('abort', (p_star, g_abort))

## 4. 推导

**引理 92（运行前提的降级与可测性）**
设 QoS 契约由证书前提编译（A_e ≤ T_fresh）。则 (i) U_t^op 成立 ⇒ v10 所用的 freshness/Δ_dom 前提成立；(ii) ¬U_t^op ⇒ 守卫检 5 在 1 个周期（20ms）内使证书失效并切中止；(iii) 时间戳、存活性、丢失率均为**系统可直接测量的事实**，故 v10 的"数据新鲜及时"强前提被替换为运行时弱前提。证明：(i) A_e ≤ T_fresh 直接蕴含消息年龄界；(ii) opsat 是逐边布尔谓词，任一为假即 o_t 非全 1；(iii) 测量不依赖任何模型假设。∎

**引理 93（ROCP 的严格等价与单调收缩）**
(a) ROCP 失效 ⇒ o_t≡1，U_t^op 退化为 v10 freshness，行为严格等价 v10；(b) o_t 是 AND 门：只可能把 valid→invalid，绝不 invalid→valid，故 K_eff^v11 ≤ K_eff^v10；(c) ROS 2 lifecycle 退化是确定性状态迁移，配合 prov 戳可重放复现。证明：(a) 中立元定义；(b) 布尔与的单调性；(c) 状态机 + 时间戳确定。∎

**引理 94（接触裕度的无滑移充分性）**
设 (A1) μ_true ≥ μ_lo；(A2) 接触模型误差有界 ε_model，预测外矩误差 ≤ β_w（由 v10 β_STF 传播）；(A3) 刚性接触、准静态。若 ρ_c(ζ) ≥ ρ_min ≥ 0（用最坏角 w_ext±β_w 计算），则块内每个接触点所需力落在 μ_lo 摩擦锥内 ⇒ 在 μ_true 下亦在内 ⇒ 无滑移。证明：摩擦锥对 μ 单调（μ_true ≥ μ_lo ⇒ FC(μ_lo) ⊆ FC(μ_true)），且 ρ_c ≥ 0 ⇔ f_req ∈ FC(μ_lo)；最坏角保证扰动不越界。∎

**引理 95（GSE 的支配性与安全中止）**
(i) Proj_{C_g_safe} 只把夹持力裁剪进 C_g_safe，**不产生新指令** ⇒ 物理行为 ⊆ v10；(ii) 最大裕度保持 g_abort 在 FC(μ_lo) 内且 ≤ f_max_crush ⇒ 不滑移、不压碎，且比 v10 的中止（假定抓取完好）更保守；(iii) GSE 失效 ⇒ 保持当前夹持力 + 重力补偿（v6 级），绝不松开。证明：投影算子的值域是安全集子集；最大裕度解由定义在可行集内取 argmax；失效分支不产生释放指令。∎

**引理 96（两侧证书联合保守性）**
在引理 92–95 假设下，任一中块危险事件以概率 ≥1−ε_op−ε_c−ε_β 满足：或 (i) 运行违约（o_t=0）⇒ 检 5 捕获；或 (ii) 接触危险（ρ_c<ρ_min 或滑移预警）⇒ 检 6/GSE 捕获；或 (iii) 两者皆正常 ⇒ 由 v10 β_STF 覆盖。且物理行为 ⊆ v10。证明：并集界；运行通道（时间戳/存活性）与接触通道（摩擦锥/力）**物理独立**，均不能被语义外观欺骗；GSE 只裁剪保证支配性。∎

## 8. 本轮最大风险

**一句话**：ROCP 依赖"依赖锥与时钟同步正确"、CRC 依赖"摩擦下界 μ_lo 保守"这两个不可在线证伪的系统/物理前提——隐藏依赖或跨节点时钟漂移会让 o_t 假阳（误以为数据可信），湿滑/油污/软体表面会让 μ_true < μ_lo 使 ρ_c ≥ ρ_min 却仍滑移或压碎，此时系统以"时间已证 + 接触已证"的双重外观错误放行，比 v10 的单点经验阈值更隐蔽；GSE 的力觉/触觉一旦饱和或失效，滑移检测同时失明，三条通道可能同时给出虚假安全感。
