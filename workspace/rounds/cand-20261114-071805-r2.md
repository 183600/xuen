# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「具身智能」×「智能体」）

> R69 问「我该向谁求证、还能问什么」，把不确定性拆成 aleatoric 与 epistemic，并用流匹配多模态策略 + 主动交互去消解 epistemic。但 R69 悄悄预设了两件事：
> - **动作空间是给定的、身体是理想的**：𝒜_+ 里的每个动作都被默认可执行，VoI 都在「我能做」的前提下计算；
> - **提问者是一个无身体、无历史、无身份的推理核心**：它只需要「问到答案」，不需要对「谁在问、谁来做、做过什么承诺」负责。
>
> 具身智能与智能体恰好拆掉这两个预设：
> - **具身智能**说：能力不是抽象动作集，而是由身体形态、传感—运动闭环、可供性（affordance）共同定义的；更关键的是，身体是系统中**唯一已知的信号源**——自己发出的动作（efference copy）与随之而来的感觉（reafference）构成一条外部世界给不了的校准通道。R69 最怕的「模态权重不可信」，可以用自己的身体来标定。
> - **智能体**说：系统不是一次函数调用，而是一个跨时间持续、有身份、有承诺、可把动作或问题委托出去的实体；「向谁求证」不只有人类，也可能是另一个具身智能体、一个工具、一个更合适的身体。委托本身是新的安全边界。
>
> 核心命题：**在 R69 的 (U_ale, U_epi) 之外补上第三种不确定性 U_ag（agential：我能不能做、这个变化是不是我造成的、我该不该自己做）；用「具身自模型 + 可供性接地 + 再入校准」把「我是谁 / 我能做什么」变成可测量、可认证、可退避的一层；当自模型不可信或能力不覆盖时，委托给另一个具身智能体，但绝不转移安全责任。** 命名 **SOMA-RAS**（Self-model, Ownership, Morphology, Affordance for embodied agents）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**这个动作/这个问题属于我吗——我能做、我配做，还是该交给别人做**」——不确定性不只关于世界，也关于「我」；身体与身份不是求解问题的外部常数，而是求解问题的先验。

## 0. 直觉与动机

**灵感 1（具身智能：身体是能力的边界，也是校准的锚）**
直觉：R69 的流策略在抽象动作空间里采 K 个模态，然后问「哪个是对的」。但真实机器人不是先有一个无限动作空间再去选择；它的可达范围、关节限位、抓握力、视野、甚至「能不能转身看一眼」都由身体决定。一个对某台机器人可行的消歧动作，对另一台可能根本不存在。更微妙的是：**身体是唯一能提供已知输入的通道**。你命令电机转 3 度，你知道自己发了什么命令；随后本体感觉/视觉的变化，至少有一部分是你自己造成的。这个「命令—再入」（efference–reafference）对，是外部世界给不了的监督信号。R69 的最大风险是「流模型幻觉出不存在的模态，VoI 在错误信念上计算」；具身智能的回答是：**用你自己发起的、已知的动作去检验策略密度**——如果策略把一个真实执行过的、物理可行的动作判成极低概率，那它的模态分布就已经不可信。

**灵感 2（智能体：身份、承诺与可委托性）**
直觉：R69 的闭环每一轮都像「失忆的专家」：它问、它看、它更新，但不记得上一轮问过谁、承诺过什么、哪个身体做过什么。智能体的核心不是「更会规划」，而是**跨时间的连续性**：同一个智能体要对昨天的承诺负责，要避免反复问同一个问题，要知道哪些能力是自己的、哪些是借来的。于是「向谁求证」升级为「**谁应该行动/回答，凭什么，出了问题谁负责**」：自己能力不够就把动作委托给更合适的具身智能体，把问题委托给更有信息的人或工具；委托不是免责，而是把安全责任显式写进契约。

**灵感 3（第三种不确定性：agential）**
直觉：R69 的 U_epi 是「世界有歧义，问一下就好」；但还有两种不确定，问世界问不出来：
- **U_aff（affordance）**：这个动作在我的身体上到底可不可行？我是「不知道该走哪条路」，还是「根本走不过去」？
- **U_own（ownership / self-model）**：眼前的变化是我自己造成的，还是世界变了？我的身体模型还准吗？
把它们塞进 U_epi 会导致一个危险错误：系统会去「问」一个物理上根本做不到的动作，或者把传感器漂移误判成外部事件。U_ag 只能通过**自探测（self-probe）、再入校准、换身体/委托**来降低；降不下去时，不是「再问一次」，而是退回 R69/R68 的保守，或明确拒绝。

**灵感 4（三通道对偶：残差、似然、再入）**
直觉：R68 有 r_res（传感器残差，测「外感受是否自洽」），R69 有 Δa（动作似然差，测「行为是否自洽」）。R70 再加一条 r_aff（再入残差，测「这个变化是否由我自己造成」）。三条通道的联合模式能分开四类故障：
- 外部世界真的变了：r_res↑，Δa 可能↑，r_aff 正常且归属为外部；
- 外感受漂移：r_res↑，r_aff 不解释；
- 身体/本体感觉漂移：r_aff↑ 且自探测可复现，r_res 可能正常；
- 策略模态分布失准：Δa↑（对已知可行动作给低似然），其余正常。
这就是 R69 最脆弱处的第三意见：**不是所有「行为异常」都是世界异常，也可能是「我」异常**。

**灵感 5（严格包含：身体理想时退化为 FLUID）**
直觉：如果自模型完全已知（U_ag=0）、身体能力覆盖全部 𝒜_+、只有一个可信智能体、承诺集为空，那么 SOMA 的可行性门恒真、归属门恒真、委托永不触发，逐指令退化为 R69 的 FLUID；再令 VoI≤成本，则退化为 R68。新层只能**缩小**当前身体可采纳的动作集，或把动作**转交**给另一个已认证的身体；它绝不扩大物理安全包络。这与 R68→R69 的姿态一致：每一层都是前一层的严格泛化，安全侧不让步。

**灵感 6（新攻击面：自我欺骗比世界欺骗更难发现）**
直觉：R69 已经担心「人会撒谎」；R70 的新危险是「自己的身体/代理身份会撒谎」：
- **再入伪造**：注入与命令一致的假本体感觉，让系统相信动作是自己做的（ownership spoofing）；
- **身体模型投毒**：缓慢篡改运动学参数，使自探测也按错误模型解释，系统自洽但全错；
- **委托伪造**：冒充一个更有能力的智能体/工具，或伪造能力契约，把危险动作骗进别人的安全包络；
- **承诺漂移**：智能体重启/换身体后忘记承诺，重复提问或自相矛盾。
最坏的情形不是「世界不可信」，而是「**自我校验的闭环本身被污染**」——系统所有通道都自洽，却系统性地错。因此必须有独立锚（硬件根信任、不可篡改的本体感受通道、跨智能体交叉验证、人工检查）与「自信任上限」。

## 1. 形式化定义（增量：定义 310–328）

**定义 310（SOMA-RAS 总览）** SOMA-RAS = (ESM, AGL, REC, SPC, AUG, DEL, PCL, FLUID-RAS†, RAS-WM‡)。五条不变式：
(i) **实时零学习写操作**（继承 R68 定义 276-i / R69 定义 293-i）；
(ii) **自模型门控**：任何任务/信息动作必须先通过可行性与归属门（定义 312–315、323），未通过不得进入 VoI 或执行；
(iii) **委托不转移安全**：被委托动作必须在接收方坐标系内重新通过 C-RAS-WM 认证；委托失败/超时/被伪造时单调退化为 R69/R68；
(iv) **承诺一致**：活跃承诺是动作集硬约束，撤销需显式、可审计的 retraction，不得静默遗忘；
(v) **自信任上限**：单一自模型证据源不得把自己的置信度推到超过独立锚支持的上界（定义 327）。

**定义 311（具身自模型 ESM）** 记 b_t = (q_t, θ_body, 𝒞_t, h_t) ∈ B：本体状态 q_t、身体参数 θ_body（运动学/动力学/传感器安装）、能力包络 𝒞_t、身份与承诺摘要 h_t。ESM 维护后验 p(b_t | ℋ_t)（或至少其充分统计量与置信集 B_t^δ）。能力包络
𝒞_t = { (a,g) ∈ 𝒜_+ : feasible(a,g; b_t) ≥ 1−δ_c }。
ESM 不是外感受世界模型的一部分：它只描述「我这个身体如何响应命令、能到达哪里」。

**定义 312（可供性流形与接地）** 可供性评分 φ: 𝒜_+ × O × B → [0,1]；接地动作集 𝒜_aff(o,b) = { ξ : φ(ξ;o,b) ≥ τ_aff }。动作级 U_aff(ξ) = 1 − φ(ξ;o,b)；集合级 U_aff = E_{ξ~π_θ}[1−φ(ξ;o,b)]。流策略生成的 ξ 先投影/过滤到 𝒜_aff；**不可行模态不是「世界歧义」，而是「身体不匹配」**，不能交给 R69 的 VoI 去「问」，只能换身体、改形态或委托。

**定义 313（再入与效应副本）** 发出动作 a_t（含信息动作 g_t）时保留效应副本 â_t；前向身体模型 f_body: (â_t, b_t, o_t) ↦ ŷ_{t+1}；再入残差
r_aff = y_{t+1} − ŷ_{t+1}，d_self = ‖r_aff‖²_{Σ_aff^{-1}}。
再入增益 Λ_aff = ∂y/∂a 的经验估计，用于判断某个感觉变化是否**可能**由自己造成。

**定义 314（归属/能动性信号）** 归属后验
o_own = P(self-caused | y_{t+1}, â_t, b_t) = σ( log p(y|â,b) − log p(y|∅,b) )。
o_own ≥ τ_own 判为自我造成；U_own = H(o_own) 的校准版本。关键：o_own 只在有效应副本时可信；无命令时的变化默认归为外部。

**定义 315（自探测与自模型漂移）** 自探测 g_sp ∈ 𝒜_info 是一类特殊信息动作，满足 (i) 对任务状态影响 ≤ ε_sp；(ii) 命令已知、可重复；(iii) 通过 C-RAS-WM 认证。用已知命令 a† 与再入 y† 检验前向模型：若 d_self > τ_self 且重复自探测可复现，则判为身体模型漂移；更新 b_t 或进入 re-grounding（定义 321）。

**定义 316（模态权重的已知信号校准）** 对已知可行命令 a†（自探测或经过认证的上一轮动作），计算策略似然 ℓ† = −log p_θ(a†|o)。校准缺口
c_gap = ℓ† − E_{ξ~π_θ}[−log p_θ(ξ|o)]
用于检测模态分布失准：若真实可行动作落在低密度区，则模态权重不可信。用 n 次自探测得到 {a†_i, ℓ†_i}，对模态权重做**锚定校准**（约束版温度缩放/保序回归）得到 ŵ_cal；校准后 ECE 超过 τ_ece 则触发 R69 定义 306 的 MCG：禁用 VoI，退回 FLUID 保守。

**定义 317（agential 不确定性）** U_ag = (U_aff, U_own, U_self)，其中 U_self 为 ESM 后验熵/置信集半径。R69 的二分升级为三分：
U = (U_ale, U_epi, U_ag)。
三者不简单相加，分别进入不同通道：U_ale → λ_floor；U_epi → VoI 交互；U_ag → 自探测/换身体/委托/拒绝。退避时取保守标量上界 U_ag^+ = U_aff + U_own + U_self。

**定义 318（行动者/工具选择 DEL）** 可用行动者集合 𝒫 = {self} ∪ {agents, tools}，每个 p 有能力契约 C_p = (𝒞_p, ε_p, cost_p, trust_p, expiry_p)。给定需执行或询问的 ξ 与当前不确定性，选择
p* = argmax_{p∈𝒫, ξ∈𝒞_p} [ V(ξ; p) − cost_p(ξ) − ρ·risk_trust(p, ξ) ]，
s.t. 认证可就地完成；若 p* = self 且 ξ ∉ 𝒞_self，则不可执行。委托问题 q 时类似，但需满足来源/时效/合法性（继承 R69 定义 303 与证据纪律）。

**定义 319（委托安全与契约）** 委托分两步：host 先在自身坐标系认证「把 ξ 交给 p」这件事是安全的（动作边界、时序、通信）；p 接收后用自己的 C-RAS-WM 重新认证 ξ。两者都通过才执行。契约字段：能力范围、安全包络、责任方、有效期、撤销方式。**安全认证不可转移**；任何一方缺失 → 委托作废，返回 R69 保守。

**定义 320（持久承诺账本与智能体身份）** 智能体身份 A = (id, ESM, PCL, key)。PCL 记录活跃承诺 {(c_j, scope_j, expiry_j, retract_j, audit_j)}。活跃承诺构成动作集硬约束：ξ 必须满足所有未过期 c_j；撤销只能通过显式 retraction 并留审计迹。身份迁移（重启/换身体）需重新接地 ESM，PCL 随身份签名迁移；不允许「新身体 + 旧承诺」在未验证时自动继续。

**定义 321（再具身/迁移）** 当 b_t 发生不连续变化（换传感器/执行器/身体），所有依赖旧 b 的标定、能力包络、策略条件失效：进入 re-grounding 模式（冷启动安全），执行自探测序列，重建 𝒞_t 与模态校准；期间 λ 取 R68 最保守，禁止委托与不可逆动作，直至 U_self 回落到阈值以下。

**定义 322（三通道故障融合 TCF）** 通道 z = (r_res, Δa, r_aff)；故障类集合 ℱ = {external_change, extero_drift, body_drift, policy_miscal, combo}。后验 P(f|z) 由校准的似然模型给出。判决规则：
body_drift 需 r_aff↑ 且自探测复现；policy_miscal 需 Δa↑ 且已知动作低似然；external_change 需 r_res↑ 且 r_aff 不解释该变化。
无法分离时按「最保守故障类」处理（安全侧优先）。

**定义 323（agential 门，置于 VoI 之前）** 每个候选 ξ（任务或信息动作）先过
gate(ξ) = [feasible(ξ; b_t) ≥ 1−δ_c] ∧ [o_own 与 ξ 的因果假设一致] ∧ [commitments(ξ) = true] ∧ [trust(p) 足够]。
只有 gate=1 的 ξ 才进入 R69 的 VoI/风险缩放。若所有候选都被门掉：先自探测（若 U_self 高），再考虑委托，最后拒绝或退 R68。由此 **VoI 不再在幻影动作上计算**。

**定义 324（证书 J_SOMA）** J_SOMA = (J_FLUID, esm_version, U_aff, U_own, U_self, self_probe_log_hash, calib_gap, delegation_log_hash, commitment_hash, soma_ver)。Valid ⇔ Valid(J_FLUID) ∧ 自模型门未越界 ∧ 委托契约有效 ∧ 承诺一致 ∧ 自信任未超上界。

**定义 325（威胁模型 ℰ_SOMA）** ℰ_SOMA = ℰ_FLUID × ℰ_embodiment × ℰ_agent：
- ℰ_embodiment：再入伪造、本体感觉投毒、身体参数缓慢篡改、传感器—执行器错位、自探测重放；
- ℰ_agent：冒充更优行动者、能力契约伪造、委托后背叛、承诺账本回滚、跨智能体共谋。
并入 AIC（对应 R69 定义 304），并增加「自探测/归属」对抗样本。

**定义 326（三级保守退避）** 
- U_ag 可解（自探测/委托成功且可信）：λ = λ_floor(U_ale)（保持 R69 的 resolution bonus）；
- U_ag 未解但 U_epi 可解：λ = λ_floor(U_ale + U_epi)（退回 FLUID）；
- 自模型不可信/委托不可信/承诺冲突/身份迁移：λ = λ_floor(U_ale + U_epi + U_ag^+)，禁用交互与委托，执行 R68 最保守；仍不可行则拒绝。
安全性单调不弱于 R68；理想身体下与 R69 逐指令一致。

**定义 327（自信任上限）** 设独立锚集 𝒜_ind = {硬件根信任, 不可篡改本体感受通道, 跨智能体交叉验证, 人工检查}。自模型置信度满足
conf_self ≤ Γ(𝒜_ind)，
Γ 为锚支持的认证上界。任何自探测结果若不能被独立锚复核，只能**降低**而不能提高 conf_self 超过 Γ。这条直接限制「自我欺骗闭环」。

**定义 328（预算与调度）** 自探测 ≤ 1 次/单位时间，且与 R69 信息动作共享预算；委托通信/切换成本计入 c(g)；K 采样、自探测、委托的总 P99 受硬约束。自探测本身也必须过 C-RAS-WM 与承诺检查——**连「检查自己」都不是免费的、也不是无风险的**。

```python
class EmbodiedSelfModel:

        self.b = self.bayes_update(obs.proprio, efference)   # b_t 后验

def ground(modes, b):
    kept, dropped = [], []
    for m in modes:
        (kept if phi(m.xi, b) >= TAU_AFF else dropped).append(m)
    U_aff = 1.0 - mean(phi(m.xi, b) for m in modes)
    return kept, dropped, U_aff

# IP-266 REC：再入残差与归属信号
def reafference(eff, y_next, b):
    y_hat = f_body(eff.a, b, eff.o)
    r_aff = y_next - y_hat
    o_own = sigmoid(logp(y_next, eff.a, b) - logp(y_next, None, b))
    return r_aff, o_own

    y_dag = execute_and_observe(a_dag)              # 效应副本 -> 再入
    d_self = mahalanobis(y_dag - f_body(a_dag, b), Sigma_aff)
    l_dag  = -policy.log_likelihood(a_dag, o)       # 已知可行动作的策略似然
    gap    = l_dag - expected_nll(policy, o)        # c_gap（定义 316）
    w_cal  = anchored_calibrate(modes.weights, gap, n_probe)
    return d_self, gap, w_cal, (policy.ece(w_cal) <= TAU_ECE)

# IP-268 AUG：agential 门（在所有 VoI 之前）
def agential_gate(xi, b, own, commitments, actor):
    return (feasible(xi, b) and own_consistent(xi, own)
            and all(c.satisfied(xi) for c in commitments)
            and trust(actor) >= TAU_TRUST)

# IP-269 DEL：跨智能体/工具委托（双向认证，不转移责任）
def select(modes, b, trust, budget):
    return choose_actor([self, *agents, *tools], modes, b, trust, budget)

def delegate(xi, modes, o, b):
    best = None
    for p in actors:                                 # self + agents + tools
        if xi not in p.contract.C or not p.contract.valid(): continue
        if not c_ras_wm.certify_handoff(p, xi, o):       continue   # host 侧
        score = value(xi, p) - p.contract.cost - RHO * risk_trust(p, xi)
        if best is None or score > best.score: best = (p, score)
    if best is None: return None
    p = best[0]
    ack = p.accept(xi, contract=best_contract)           # receiver 侧重新认证
    return (p, ack) if ack.certified else None

# IP-274 SOMA 主闭环（R69 之上只加「自模型/可供性/归属/委托」四道门）
def SOMA_RAS_round(A, obs):
    z, o = A.mtm.forward(obs)
    b, U_self = A.esm.update(obs, A.last_efference)
    # 1) R69 原有分支：流采样 + 不确定性二分
    K = 1 if A.fmp.mode_head(z) < TAU_MODE else 4
    samples = A.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = A.aud.decompose(samples, z, A.fmp.mode_head)
    # 2) 具身门：先问「做不做得到」，再问「值不值得问」
    modes_f, dropped, U_aff = ground(modes, b)
    r_aff, o_own = reafference(A.last_efference, obs, b)
    U_own = entropy_own(o_own)
    if U_self > TAU_SELF or U_own > TAU_OWN:
        d_self, gap, w_cal, cal_ok = self_probe_and_calibrate(A.fmp, b, modes_f)
        if d_self > TAU_SELF: A.esm.reground()           # 或进入定义 321
    else:
        gap, w_cal, cal_ok = 0.0, modes_f.weights, True
    # 3) 校准门与 agential 门：不可信模态不得驱动交互
    if cal_ok:
        g = A.mint.choose_interaction(modes_f, w_cal, o, A.budget)
    else:
        g = None                                          # MCG -> 退 FLUID
    if g is not None and not agential_gate(g, b, o_own, A.pcl, A.self):
        g = None
    # 4) 做不了/问不出 -> 先自探测，再委托，最后退保守
    need_help = (not modes_f) or (g is None and U_epi > TAU_EPI)
    if need_help and U_aff > TAU_AFF:
        p_star = A.del.select(modes, b, A.trust, A.budget)
        if p_star is not None:
            handoff = delegate(p_star, modes, o, b)
            if handoff is not None: return handoff
    # 5) 三通道故障融合 + 三级退避
    f = A.tcf.classify(A.last_r_res, A.fma.score(A.last_action, o), r_aff)
    U_ag = U_aff + U_own + U_self
    U_floor = U_ale + (U_epi if g is None else 0.0) + (U_ag if f != 'ok' else 0.0)
    lam = max(A.efs.risk_scale(...), lam_floor(U_floor))
    if f in ('body_drift', 'policy_miscal', 'combo'):
        lam = max(lam, 0.8)                               # 回 R68 最保守
    # 6) 承诺约束 + 认证前缀 + 审计/证书
    mode = A.pcl.constrain(A.select_mode(modes_f, lam), A.pcl.active())
    k = A.c_ras_wm.certified_prefix(mode.a, ..., wm_preds)
    A.vqa_e.submit_async(g, gap, r_aff, o_own, U_ag, A.del.last_log)
    return k, lam, mode, (U_ale, U_epi, U_ag)
```

## 3. 推导

**引理 19（可供性门把「幻影交互」的代价从无穷降为可控）** 设可供性评分在 A99 下 β-sound：P(φ(ξ) ≥ τ_aff | ξ 不可行) ≤ β。R69 在 𝒜_+ 上计算 VoI，若其最优候选不可行，执行代价可视为 +∞（越界、损坏、不可逆）。SOMA 将候选限制在 𝒜_aff：期望浪费的交互概率 ≤ β + (1−coverage)，期望越界代价 ≤ β·L_aff。另一方面，𝒜_aff ⊆ 𝒜_+ ⇒ VoI_{𝒜_aff} ≤ VoI_{𝒜_+}：门控不会虚增信息价值，只会把「声称的 VoI」变成「可兑现的 VoI」。系：当 𝒜_aff = 𝒜_+ 时，引理退化为 R69 的原始 VoI。

**引理 20（再入已知信号的校准下界）** 自生成动作 a† 给出监督对 (a†, y†)。设 A100：(i) 前向身体模型误差 ‖f_body − f_true‖ ≤ δ_b；(ii) 策略密度对动作 L_v-Lipschitz；(iii) 噪声有界。则校准缺口的估计满足
|ĉ_gap − c_gap| ≤ L_v·δ_b + ε_n，ε_n = O(1/√n)。
故 n 次自探测把模态权重的 ECE 以 O(1/√n) 压低，直到身体模型误差地板 L_v·δ_b。当 δ_b→0 时校准无偏。系：这正是 R69 缺少的「独立已知信号通道」；若校准后 ECE 仍高于 τ_ece，则问题不在估计方差，而在策略模态分布本身不可信——应触发 MCG，而不是继续交互。

**引理 21（三通道故障可分离性）** 在 A101 下，给定故障类 f，三通道残差条件独立且已校准；故障类到期望残差的映射 f ↦ (E[r_res|f], E[Δa|f], E[r_aff|f]) 列满秩。则贝叶斯分类器可分离 ℱ 中的 external_change / extero_drift / body_drift / policy_miscal。关键是：r_res 与 Δa 对「变化是否由自己造成」不敏感，只有 r_aff（有效应副本时）携带干预/归属信号；若 r_aff 缺失或被伪造，则 external_change 与 body_drift 不可辨识。系：三通道不是冗余，而是**可辨识性的必要条件**；但 r_aff 本身需要独立锚，见引理 22。

**引理 22（自验证天花板）** 若某个自探测同时用自模型生成探针 a† = π_probe(b) 又用同一自模型解释结果 ŷ = f_body(a†, b)，则存在一类身体模型腐蚀 δ_b（保持复合映射 f_body∘π_probe 不变）使 d_self 完全不变。故**任何纯本体感受的自测试都无法认证自模型本身**；必须引入不经过该复合映射的独立锚 𝒜_ind。形式化：self-test 的可辨识子空间是 ker(∂(f_body∘π_probe)/∂b)，非空当且仅当身体参数维度大于探针可激励维度。这是定义 327 与「自信任上限」的理论依据，也是本轮最大风险的根源。

**定理 18（SOMA 严格包含 FLUID 与 R68）** 在 A95–A102 下：
(i) 若身体理想（U_ag=0，𝒜_aff=𝒜_+）、单一可信行动者、承诺集为空、不自探测，则 gate≡1、TCF≡R69、DEL 不触发，SOMA 与 FLUID **逐指令相同**；
(ii) 再令 VoI(g*) ≤ c(g*)，则两者同时退化为 R68；
(iii) 一般情形下，SOMA 的可采纳动作集 ⊆ FLUID 的可采纳动作集，且 U_ag 未解时 λ_soma ≥ λ_floor(U_ale+U_epi)，故期望风险 ≤ FLUID ≤ R68。
所以 R70 不是在 R69 旁边加一个并列黑箱，而是把 R69 作为「理想身体 + 单智能体 + 无承诺」的边界包含进来。

**定理 19（委托安全 / 无责任转移）** 采用 host 侧交接认证 + receiver 侧重新认证的双向契约（定义 319）。若两侧认证都 sound，则被委托动作的物理风险 ≤ max(ε_host, ε_recv) ≤ ε_int；若任一侧认证缺失、超时或被伪造，委托被拒绝并单调退化为 FLUID/R68。切换过程满足 R69 定理 17 的提交/换装不变式 ⇒ 控制连续、无突变。系：伪造契约最坏导致「拒绝执行」（fail-safe），而不是「不安全执行」——**前提是接收方的认证不可被契约字段绕过**；这个前提本身必须写进硬件/运行时信任根。

**引理 23（承诺单调性）** 活跃承诺只缩小可采纳集，retraction 是显式且审计的，故不存在「未审计地使某动作从禁止变为允许」的路径。系：承诺不会导致静默的不一致，但过期承诺会导致死锁，因此 expiry 与重协商是必需的，而不是可选的。

## 6. 本轮最大风险

**一句话**：SOMA-RAS 把「我是谁、我能做什么」变成安全闭环的前置门，但这个门由**自模型自己**来测量——一旦身体模型或再入通道被缓慢投毒（且投毒方式恰好穿过自探测的复合映射），系统会所有通道自洽地误判能力、误认归属、并把危险动作自信地委托出去；**「我」错了，比「世界」错了更难发现，因为发现「我」错了的工具正是「我」**。

**次级风险与缓解**：
1. **自验证闭环**（自探测也经被污染的身体模型解释）→ 定义 327 自信任上限 + 独立锚 𝒜_ind + 引理 22 显式承认可辨识边界；
2. **委托责任转移**（把动作交给别人就以为安全了）→ 双向认证 + 契约责任字段 + 定理 19；认证不可转移；
3. **再具身冷启动**（换身体后旧标定仍被使用）→ 定义 321 强制 re-grounding + 定义 326 退 R68；
4. **承诺死锁/漂移**（旧承诺阻止新任务，或重启后遗忘）→ expiry + 签名迁移 + 引理 23 审计；
5. **实时预算被自探测击穿** → 自探测预算 ≤1 次/周期 + 与交互共享预算 + E315。

## 2. 形式化定义（要点版）

**定义 310（总览与五不变式）** SOMA-RAS = (ESM, AGL, REC, SPC, AUG, DEL, PCL, FLUID-RAS†, RAS-WM‡)；实时零学习写操作继承；自模型门控（动作先过可行性与归属门）；委托不转移安全（接收方重新认证）；承诺一致（撤销显式可审计）；自信任上限（单一自模型不得自证超过独立锚支持的上界）。

**定义 311–312（ESM 与可供性）** `b_t=(q_t,θ_body,𝒞_t,h_t)`；`𝒞_t={ξ: feasible(ξ;b_t)≥1−δ_c}`；`𝒜_aff={ξ:φ(ξ;o,b)≥τ_aff}`；`U_aff=E[1−φ]`。不可行模态是「身体不匹配」，不是世界歧义，不能交给 VoI。

**定义 313–314（再入与归属）** `r_aff=y_{t+1}−f_body(â_t,b_t,o_t)`；`d_self=‖r_aff‖²_{Σ_aff^{-1}}`；`o_own=σ(log p(y|â,b)−log p(y|∅,b))`；`U_own=H(o_own)`。无效应副本时变化默认归为外部。

**定义 315–316（自探测与校准）** 自探测 `g_sp`：任务影响 ≤ε_sp、命令已知可重复、过 C-RAS-WM；`d_self>τ_self` 且复现 ⇒ 身体漂移。已知动作 `a†` 给策略似然 `ℓ†`，`c_gap=ℓ†−E[−log p_θ]`；n 次自探测做锚定校准得 `ŵ_cal`，ECE>τ_ece 触发 MCG（禁用 VoI，退回 FLUID）。

**定义 317（三分不确定性）** `U=(U_ale,U_epi,U_ag)`；`U_ale→λ_floor`，`U_epi→VoI 交互`，`U_ag→自探测/换身体/委托/拒绝`；退避时用保守上界 `U_ag^+=U_aff+U_own+U_self`。

**定义 318–319（委托与安全）** `p*=argmax_{p,ξ∈𝒞_p}[V−cost−ρ·risk_trust]`；委托需 host 交接认证 + receiver 就地重新认证，任一缺失即作废；**安全认证不可转移**。

**定义 320–321（承诺与再具身）** `A=(id,ESM,PCL,key)`；活跃承诺是动作集硬约束，retraction 需审计；换身体 ⇒ 所有旧标定/能力/策略条件失效，强制 re-grounding，期间 λ 取 R68 最保守、禁止委托与不可逆动作。

**定义 322–323（三通道融合与 agential 门）** `z=(r_res,Δa,r_aff)`，故障类 `{external_change, extero_drift, body_drift, policy_miscal, combo}`；无法分离按最保守故障处理。`gate(ξ)=feasible ∧ own_consistent ∧ commitments ∧ trust`；只有 gate=1 才进入 VoI。

**定义 324–325（证书与威胁）** `J_SOMA=(J_FLUID, esm_version, U_aff, U_own, U_self, self_probe_log_hash, calib_gap, delegation_log_hash, commitment_hash, soma_ver)`；`ℰ_SOMA=ℰ_FLUID×ℰ_embodiment×ℰ_agent`（再入伪造/本体投毒/契约伪造/冒充/承诺回滚/共谋）。

**定义 326–328（三级退避、自信任上限、预算）** U_ag 可解 ⇒ `λ=λ_floor(U_ale)`；U_ag 未解但 U_epi 可解 ⇒ `λ=λ_floor(U_ale+U_epi)`；自模型/委托/承诺/迁移不可信 ⇒ `λ=λ_floor(U_ale+U_epi+U_ag^+)` 并禁交互与委托，必要时拒绝。`conf_self ≤ Γ(𝒜_ind)`；自探测 ≤1 次/周期且与交互共享预算。

## 3. 关键算法伪代码

```python
# IP-264 ESM：只描述身体
class EmbodiedSelfModel:
    def update(self, obs, efference):
        self.b = self.bayes_update(obs.proprio, efference)
        self.C = {xi for xi in action_space if self.feasible(xi, self.b)}
        return self.b, self.entropy()                       # U_self

# IP-265 AGL：可供性接地
def ground(modes, b):
    kept = [m for m in modes if phi(m.xi, b) >= TAU_AFF]
    return kept, 1.0 - mean(phi(m.xi, b) for m in modes)    # U_aff

# IP-266 REC：再入 + 归属
def reafference(eff, y_next, b):
    r_aff = y_next - f_body(eff.a, b, eff.o)
    o_own = sigmoid(logp(y_next, eff.a, b) - logp(y_next, None, b))
    return r_aff, o_own, entropy(o_own)

# IP-267 SPC：已知信号校准模态权重（回应 R69 最大风险）
def self_probe_and_calibrate(policy, b, modes):
    a_dag = choose_known_safe_probe(b, budget)              # 已知/可复现/已认证
    y_dag = execute_and_observe(a_dag)
    d_self = mahalanobis(y_dag - f_body(a_dag, b), Sigma_aff)
    gap = -policy.log_likelihood(a_dag, o) - expected_nll(policy, o)
    w_cal = anchored_calibrate(modes.weights, gap, n_probe)
    return d_self, gap, w_cal, policy.ece(w_cal) <= TAU_ECE

# IP-268 AUG：VoI 之前的 agential 门
def agential_gate(xi, b, own, commitments, actor):
    return (feasible(xi, b) and own_consistent(xi, own)
            and all(c.satisfied(xi) for c in commitments)
            and trust(actor) >= TAU_TRUST)

# IP-269 DEL：双向认证的委托
def select(modes, b, trust, budget):
    return choose_actor([self, *agents, *tools], modes, b, trust, budget)

def delegate(xi, modes, o, b):
    best = None
    for p in actors:
        if xi not in p.contract.C or not p.contract.valid(): continue
        if not c_ras_wm.certify_handoff(p, xi, o): continue      # host 侧
        s = value(xi, p) - p.contract.cost - RHO * risk_trust(p, xi)
        if best is None or s > best.score: best = (p, s)
    if best is None: return None
    p = best[0]; ack = p.accept(xi, contract=best_contract)       # receiver 侧
    return (p, ack) if ack.certified else None

# IP-274 主闭环（R69 之上加四道门）
def SOMA_RAS_round(A, obs):
    z, o = A.mtm.forward(obs)
    b, U_self = A.esm.update(obs, A.last_efference)
    K = 1 if A.fmp.mode_head(z) < TAU_MODE else 4
    samples = A.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = A.aud.decompose(samples, z, A.fmp.mode_head)
    # 具身门：先「做不做得到」
    modes_f, U_aff = ground(modes, b)
    r_aff, o_own, U_own = reafference(A.last_efference, obs, b)
    # 自探测 + 已知信号校准
    if U_self > TAU_SELF or U_own > TAU_OWN:
        d_self, gap, w_cal, cal_ok = self_probe_and_calibrate(A.fmp, b, modes_f)
        if d_self > TAU_SELF: A.esm.reground()
    else:
        gap, w_cal, cal_ok = 0.0, modes_f.weights, True
    # 校准不可信 -> MCG 退 FLUID；再做 agential 门
    g = A.mint.choose_interaction(modes_f, w_cal, o, A.budget) if cal_ok else None
    if g is not None and not agential_gate(g, b, o_own, A.pcl, A.self): g = None
    # 做不了/问不出 -> 先自探测，再委托，最后保守
    if (not modes_f or (g is None and U_epi > TAU_EPI)) and U_aff > TAU_AFF:
        p_star = A.del.select(modes, b, A.trust, A.budget)
        if p_star is not None:
            handoff = delegate(p_star, modes, o, b)
            if handoff is not None: return handoff
    # 三通道融合 + 三级退避
    f = A.tcf.classify(A.last_r_res, A.fma.score(A.last_action, o), r_aff)
    U_ag = U_aff + U_own + U_self
    U_floor = U_ale + (U_epi if g is None else 0.0) + (U_ag if f != 'ok' else 0.0)
    lam = max(A.efs.risk_scale(...), lam_floor(U_floor))
    if f in ('body_drift', 'policy_miscal', 'combo'): lam = max(lam, 0.8)
    mode = A.pcl.constrain(A.select_mode(modes_f, lam), A.pcl.active())
    k = A.c_ras_wm.certified_prefix(mode.a, ..., wm_preds)
    A.vqa_e.submit_async(g, gap, r_aff, o_own, U_ag, A.del.last_log)
    return k, lam, mode, (U_ale, U_epi, U_ag)
```

## 4. 推导

**引理 19（可供性门抑制幻影交互）** A99（β-sound 可供性）下，R69 在 𝒜_+ 上算 VoI，若最优候选不可行则代价 +∞；SOMA 限制到 𝒜_aff 后，期望浪费交互概率 ≤ `β + (1−coverage)`，期望越界代价 ≤ `β·L_aff`。且 `VoI_{𝒜_aff} ≤ VoI_{𝒜_+}`——门控不虚增价值，只把「声称的 VoI」变成「可兑现的 VoI」。`𝒜_aff=𝒜_+` 时退化为 R69。

**引理 20（再入已知信号的校准下界）** 自生成动作给监督对 `(a†,y†)`。A100（身体模型误差 ≤δ_b、策略密度 L_v-Lipschitz、噪声有界）下，`|ĉ_gap−c_gap| ≤ L_v·δ_b + O(1/√n)`。n 次自探测把模态 ECE 以 `O(1/√n)` 压低到误差地板 `L_v·δ_b`；`δ_b→0` 时无偏。系：这正是 R69 缺的独立已知信号通道；ECE 仍高 ⇒ 问题在策略模态分布本身，应触发 MCG 而非继续问。

**引理 21（三通道故障可分离）** A101（给定故障类条件独立且校准、故障类到期望残差映射列满秩）下，external_change / extero_drift / body_drift / policy_miscal 可由 `z=(r_res,Δa,r_aff)` 贝叶斯可分。r_res 与 Δa 对「变化是否由我造成」不敏感；只有 r_aff（有效应副本时）携带干预/归属信号。缺 r_aff 时 external 与 body_drift 不可辨识——三通道是可辨识性的必要条件。

**引理 22（自验证天花板）** 若自探测同时用自模型生成探针 `a†=π_probe(b)` 又用同一自模型解释 `ŷ=f_body(a†,b)`，则存在保持复合映射 `f_body∘π_probe` 不变的身体腐蚀 δ_b 使 `d_self` 完全不变。故纯本体感受自测试无法认证自模型；可辨识子空间是 `ker(∂(f_body∘π_probe)/∂b)`，非空当且仅当身体参数维度大于探针可激励维度。必须引入不经过该复合映射的独立锚 `𝒜_ind`（定义 327）。

**定理 18（SOMA 严格包含 FLUID 与 R68）** A95–A102 下：理想身体（U_ag=0、𝒜_aff=𝒜_+）、单可信行动者、空承诺、不自探测 ⇒ gate≡1、TCF≡R69、DEL 不触发，逐指令等于 FLUID；再令 VoI≤cost ⇒ 等于 R68。一般情形下 SOMA 可采纳集 ⊆ FLUID，U_ag 未解时 `λ_soma ≥ λ_floor(U_ale+U_epi)`，故期望风险 ≤ FLUID ≤ R68。

**定理 19（委托安全 / 无责任转移）** host 交接认证 + receiver 就地重新认证均 sound 时，委托动作物理风险 ≤ `max(ε_host,ε_recv) ≤ ε_int`；任一缺失/超时/伪造 ⇒ 委托拒绝并单调退化为 FLUID/R68；提交/换装不变式保持 ⇒ 控制连续无突变。系：伪造契约最坏导致 fail-safe 拒绝，而非不安全执行——前提是接收方认证不可被契约字段绕过。

**引理 23（承诺单调性）** 活跃承诺只缩小可采纳集，retraction 显式且审计 ⇒ 不存在「未审计地使动作从禁止变为允许」的路径；过期承诺会造成死锁，故 expiry 与重协商必需。

## 7. 本轮最大风险

**一句话**：SOMA-RAS 把「我是谁、我能做什么」变成安全闭环的前置门，但这个门由**自模型自己**来测量——一旦身体模型或再入通道被缓慢投毒，且投毒方式穿过自探测的复合映射，系统会所有通道自洽地误判能力、误认归属、并把危险动作自信地委托出去；**「我」错了，比「世界」错了更难发现，因为发现「我」错了的工具正是「我」**。

**次级风险与缓解**：自验证闭环（定义 327 自信任上限 + 独立锚 + 引理 22）；委托责任转移（双向认证 + 契约责任 + 定理 19）；再具身冷启动（定义 321 强制 re-grounding + 定义 326 退 R68）；承诺死锁/漂移（expiry + 签名迁移 + 引理 23）；实时预算被自探测击穿（≤1 次/周期 + 共享预算 + E315）。
