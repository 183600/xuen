# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 2 轮；本轮灵感：「低延迟推理」×「伦理与合规」）

> 第 57 轮把赌注换到"少样本可校准、跨模态可对账、个性化有界的证据承诺"，纵深五层，并把一切判定器送进隔离区。但它默认了两件从未被计费的东西：**(a) 时间**——共形带、跨模态对账、元推断与信任状态机都要算，可四足的控制回路不等人；一个晚到 20 ms 的"健全判据"在物理上等于没有判据，机器人早已迈出或跌倒，且固定样本校准/共形在"看够就停"下会失效（可选停时破坏覆盖率）。**(b) 权限**——它只证明"接触是安全的"，从不证明"接触是被允许的"。安全是概率权衡（R≤δ），合规却是道义结构：有些动作无论期望收益多高都禁止、有些义务必须履行、规则随辖区与版本变化并会冲突；把合规塞进同一个可加风险预算，等于允许"用高收益买违规"——这正是制度层的橡皮章。更尖锐的是：第 57 轮为个性化去监视操作者（橡皮章/疲劳检测），本身就是隐私与劳动监控问题；而为防"坏先验普遍"又要求长期保留语料与审计链，与被遗忘权/数据最小化直接冲突。本轮不加第七层证据，而是**给认证加硬节拍、给合规加职权结构**：认证改为**任意时刻有效**（anytime-valid）的 e-过程/置信序列，使提前停不破坏有效性；动作只按**节拍内可得的证据下界**承诺，来不及就退到**预先认证的安全港**；合规成为**不可交易**的道义门，且规则源/审计权必须外部独立。核心命题由"少样本可校准、跨模态可对账、个性化有界的证据说可信"升级为 **"节拍内可判、证据地板不随截止期下降、合规不可交易且可问责的证据说可信"**。

核心矛盾：
- **H29（认证深度 vs 控制节拍）**：第 55–57 轮的每一层纵深都在买"更健全"，代价是延迟。健全性论证默认样本可以等齐、对账可以做完；但控制回路要求判决在 $\tau_{rt}$ 内到达执行器，而且真正的截止期还要预留制动/安全停的时间。更深证书 ⇔ 更长延迟，于是**安全层本身成了延迟攻击面**：对手只要制造 OOD/对账风暴，就能把系统逼进"来不及判"的默认分支。固定样本的覆盖率在可选停时（early stopping）下蒸发，必须换成 time-uniform 的界。
- **H30（安全 vs 合规；合规不可交易）**：物理安全可写成"风险≤δ"的概率权衡，合规却是禁止/义务/许可的道义结构。一个动作可以风险极低、收益极高却仍被明令禁止；"更多证据/更高收益"不能把禁止变成许可。规则还是模糊、冲突、随辖区与版本漂移的，无法冻结成单一谓词。若把合规折算进风险预算，就会系统性出现"合规剧场"：系统学会在高收益场景里买通阈值。
- **H31（可问责 vs 可遗忘）**：问责要求事后能重建"当时凭什么允许这次不可逆动作"（模型版本、语料、证书下界、授权独立性）；伦理要求数据最小化、目的限定、被遗忘权与机器遗忘，且差分隐私的噪声会抹去个体贡献。于是同一次动作可能同时**不可复核**（删了数据就复现不了）又**未真正遗忘**（其影响仍在元模型里）——两头都输。审计与隐私不是可以相加的两项，而是必须在结构上分层。

## 0. 直觉与动机

**灵感 1（低延迟推理 → 任意时刻可停的证据认证）**
直觉：不要把"算完再判"当成前提，而要把"什么时候停都算数"当成前提。统计上这有现成武器：**e-过程/置信序列**保证对任意停时都有效，早停不会偷走覆盖率；于是证书可以像视频流一样"随时截一帧都是一张合法照片"。把证据认证做成 **anytime**：每一步都维护一个**证据下界** $L_e(t)$（最坏情形），只允许用下界承诺；剩余节拍越多，就把界压得越紧（多保真探针、更深对账），剩余越少就交出一个更宽但依然诚实的界，或干脆不承诺。关键纪律：**时间的价值只能换"动作保守度"，不能换"证据标准"**。

**灵感 2（低延迟推理 → 实时裕度、多保真探针与安全港）**
直觉：真正的延迟不是推理时间，而是"传感器→推理→决策→执行→兜底"整条链。定义实时裕度 $S_{rt}=\tau_{rt}-(c_{cert}+c_{act}+c_{fb})$；一旦预测 $S_{rt}<0$，正确的反应不是"加速算"，而是**提前降速/降接触级/加大间距**，让兜底来得及时。兜底动作不能临时想——必须**离线预先认证**成一个安全港集合 $\mathcal S_h$：在任何已认证上下文球与时间窗内，刹车/保持/后退/卸载都是物理安全且规范允许的。多保真探针按"每毫秒信息增益"排序，而非只看 VOI 绝对值。**截止期只许让动作更保守，绝不许让证据地板下降**——这是本轮的第一条公理。

**灵感 3（伦理与合规 → 不可交易的道义门）**
直觉：合规不是"风险很低所以可以"，而是"没被禁止、义务已履行、且有许可"。把规则写成机器可读的 $\mathcal R_{v,r}$：禁止集 $P$、义务集 $O$、许可集 $M$ 与优先序 $\succ$（法律 > 安全禁令 > 合同 > 政策 > 偏好）；冲突无解就**升级给外部**，不许系统自己拍板。合规门是**前置过滤器**：禁止的动作根本不进入风险评估，任何证据、收益、紧急度都不能解锁它。另一条硬纪律：**职权独立**——需要人授权的动作，审批者不得是唯一受益人、不得与被审事项同线汇报；第 57 轮的 auth 只能调节"要多少佐证"，永远不能替代"有没有独立制衡"。一个校准良好的橡皮章仍是橡皮章。

**灵感 4（伦理与合规 → 限时解释与隐私可验证问责）**
直觉：需要解释的动作，如果解释赶不上节拍，就不该做（否则是"先斩后奏"）。解释也做成 anytime：带覆盖度的部分解释，未达最低覆盖即拒绝承诺。问责用**防篡改 Merkle 溯源账本**记录每次承诺的证书下界、模型/规则版本、授权独立性与安全港可达性；审计通过**选择性披露/零知识证明**只验证谓词，不碰原始个人数据。诚实区分两级：**可查验**（签名证书可独立验真，即使原数据已删）与**可复核**（能在保留期内完整复现）。高风险动作要求保留期内可复核，普通动作至少可查验——这是"可问责 vs 可遗忘"的结构性调和，而不是假装二者不冲突。

**灵感 5（伦理与合规 → 合规相容的元学习：可撤回忆、可遗忘、公平）**
直觉：第 57 轮的效率来源 $\mathcal D_{meta}$ 是一份"永久的记忆"，它可能含操作者标注、现场影像与被监控行为。合规要求：贡献带同意范围（目的/保留期/辖区），只在范围内训练；按影响函数做数据归因；给每个主体差分隐私预算；收到删除请求就执行**机器遗忘**并出具遗忘证书，其输出变化有界 $\Delta_{unl}$。更关键的是**遗忘后重新认证**：受影响元模型签发的 ID 证书一律作废、退回共形带重跑——宁可又宽又慢，不许"删了数据还用旧自信"。公平性上审计不同区域/人群的**证书宽度与延迟差**，防止元先验把弱势场景变成"又慢又保守"的二等安全。

**灵感 6（合流 → 算子 PCE-R：节拍、合规、问责三线并行）**
直觉：PCE-R 在每个检查点先做**合规前置**（禁止即止/冲突即升级），再算**实时裕度**（不够就先降档选安全港），再在剩余节拍内跑**anytime 认证**（取最深可负担层，只用证据下界），探针按"每毫秒信息增益"排序；承诺当且仅当"合规过 ∧ 下界满足 R≤δ ∧ 证据地板达到 ∧ 需解释已就绪 ∧ 安全港可达"，否则按 安全港 → 独立人工升级 → 安全停 的顺序。所有新机制只经"更准（含加宽）的界"或"更保守的动作"两个安全通道起作用；**截止期单调性、合规不可交易性、证据地板不变性**三条红线由构造保证并被审计。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（任意时刻证据认证 AEC）** 对证据命题 H（如"裕度≥m"），以 e-过程 $(E_t)_{t\ge0}$（$E_0=1$，H 为真时非负鞅）或置信序列积累证据；**任意时刻有效**：对任意停时 $\tau$，$P_{H0}(E_\tau\ge1/\alpha)\le\alpha$（可选停时定理）。**证书** $C_e(t)=(\text{verdict}\in\{\text{pass},\text{fail},\text{undecided}\},\,L_e(t),U_e(t),\alpha_e,c_e,\text{ver},\text{exp})$，其中 $L_e$ 为证据下界（最坏端点），$c_e$ 为计算时延。承诺规则：**只允许用 $L_e$**；$U_e$ 乐观量不得进入决策。认证深度 $d\in\{0,1,2,3\}$ 对应"不解/单模态/跨模态对账/元+共形联合"，按剩余节拍取**最深可负担**者；若未达最低深度即输出 `undecided`。证书缓存带失效条件（健康告警/规则版本/语料版本/过期），失效即降为共形带最坏值。固定样本量 $k$ 被停时 $\tau$ 取代，$k$ 只在报告中作为"实际消耗"出现。

**定义 140（实时裕度 RTS、多保真探针与安全港）** 控制节拍 $\tau_{rt}$（含传感、推理、决策、执行与兜底），$S_{rt}=\tau_{rt}-(c_{cert}+c_{act}+c_{fb})$。**安全港** $\mathcal S_h^{v,r}$ 为离线预认证动作集：对每个 $(s_h,\text{上下文球},\text{时间窗 }\tau_h)$ 均证明物理安全且规范允许；运行态须落在某个 $s_h$ 的认证球内才可用作兜底，否则**预防性降档**（降速/扩间距/升接触级）直至被覆盖。多保真探针 $p$ 的排序键为**信息增益密度** $\rho_{voi}(p)=\Delta H(p)/\mathbb E[c_p]$，在 $S_{rt}$ 预算内做背包式选择。**截止期单调性（公理 A41）**：若 $\tau_1\le\tau_2$，则策略满足 $\pi_{\tau_1}\sqsubseteq\pi_{\tau_2}$（$\sqsubseteq$ 为"更保守"偏序：速度更低/接触级更低/佐证更多/分块更短）**或**延期；且**证据地板** $E_{min}(a)$ 对不可逆与规范敏感动作与 $\tau$ 无关。禁止用更短的截止期去削减任何必需证据类。

**定义 141（规范合规门 NCG）** 规则集 $\mathcal R_{v,r}=(P,O,M,\succ)$，版本 $v$、辖区/上下文 $r$；每个规范 $n$ 绑定谓词 $\varphi_n(s,a,\text{role},\text{consent},r)$。**合规** $\mathrm{Comp}_{\mathcal R}(a)=(\nexists p\in P:\varphi_p)\wedge(\forall o\in O:\text{discharged}(o))\wedge(\exists m\in M:\varphi_m)$；冲突按 $\succ$（法律 ≻ 安全禁令 ≻ 合同 ≻ 政策 ≻ 偏好）消解，仍无解或无许可 ⇒ **abstain/escalate**，不得自行权衡。**不可交易性**：对任意证据集 $E$、收益 $u$、风险 $R$，$\mathrm{Comp}$ 不含 $E,u,R$ 项；增加约束只能撤销许可，增加证据/收益永不创造许可。**职权独立** $\mathrm{Indep}(o,a)$：审批者非唯一受益人、与被审事项无同线汇报、非同一会话的自我复核；第 57 轮 auth 仅进入 `corrob*(auth)`，**不得**替代 $\mathrm{Indep}$。合规证书 $C_{comp}=(\mathcal R$ 版本, 辖区, 谓词求值轨迹, 冲突裁决, 授权人独立性) 与 $J_p,J_t$ 分离，任一缺失即拒。

**定义 142（限时解释与隐私可验证问责 LEA）** 解释覆盖度 $\mathrm{cov}(Exp)$，要求 $\mathrm{cov}\ge\kappa_{exp}$ 且渲染/输入往返时延 $\tau_{exp}\le\tau_{rt}$；未达即禁承诺（"先斩后奏"不被允许）。**溯源账本** $\mathcal L$ 为只追加 Merkle 日志，叶 = H(承诺, 证据下界集合, 模型/规则/语料版本, 授权独立性证明, 安全港可达性证明, 解释摘要)。审计分两级：**可查验**（持能力令牌者用 Merkle 证明 + 零知识证明验证谓词，不接触原始个人数据）与**可复核**（保留期内可从冻结快照完整复现）。高风险不可逆动作要求保留期内可复核，普通动作至少可查验并签名冻结证书摘要。删除/遗忘后，受影响证书由"可复核"降级为"可查验"或直接作废，并显式标注。

**定义 143（合规相容元学习 CML）** 语料贡献 $x$ 携带同意范围 $\sigma_x$（目的集、保留期、辖区、可撤回标志）与来源证明。训练仅用 $\{x:\sigma_x\ni\text{当前目的}\}$；每主体差分隐私预算 $(\varepsilon_{dp},\delta_{dp})$；以影响函数做归因。删除请求触发遗忘算子 $\mathcal U$，出具**遗忘证书**（$\|q_\phi-q_{\phi'}\|\le\Delta_{unl}$ 的概率上界）。**遗忘后重新认证**：$q_{\phi'}$ 影响到的 ID 证书全部作废，退回第 57 轮共形带重跑；未重跑前只允许"更保守"的结论。跨辖区：原始数据不出境，仅交换 DP 模型增量与遗忘意图（联邦式）；云端更新须过"合规回归"影子测试（禁止召回不降、辖区谓词不误判、节拍达标）方可接管承诺。**公平审计**：按区域/人群报告证书宽度与延迟差 $\Delta_{gap}$，超阈即触发语料补盲或对该群体强制走非参保底。

**定义 144（算子 PCE-R：Real-time × Regulatory）** 每检查点：①**合规前置**：载入 $\mathcal R_{v,r}$，若动作落在 $P$ 或义务未履行或无许可 ⇒ 立即 abstain/升级（任何证据不可解锁）；②**实时裕度**：算 $S_{rt}$，若 $S_{rt}<S_{min}$ ⇒ 预防性降档 + 选定 $\mathcal S_h$ 兜底；③**anytime 认证**：在剩余节拍内取最深可负担层，只用 $L_e$；④**探针调度**：按 $\rho_{voi}$ 选多保真探针，对 OOD/对账风暴设**风暴预算**（超限视为延迟攻击，转安全港并审计）；⑤**承诺** $\iff$ Comp $\wedge$ ($L_e$ 下 $R\le\delta_f$) $\wedge$ $E_{min}\subseteq$ 已得证据 $\wedge$ (需解释则 $cov\ge\kappa_{exp}$) $\wedge$ 安全港可达；⑥否则 安全港 → 独立人工升级（$\mathrm{Indep}$ 通过）→ 安全停；⑦追加溯源账本并在健康/规则/语料变化时重验或作废证书；⑧由构造强制截止期单调性、不可交易性与证据地板不变。

## 2. 关键算法伪代码（完整版见产物区）

```python
def anytime_certify(claim, obs_stream, deadline, alpha):     # IP-139
    E, L = 1.0, claim.prior_lower()                           # e-过程 + 下界
    while now() < deadline and not claim.decided(L):
        d = deepest_affordable(claim, slack=deadline - now())  # 深度按时延取
        if d == 0:
            break
        x = obs_stream.next(fidelity=d)                        # 多保真观测
        E *= claim.likelihood_ratio(x)                         # 任意时刻有效
        L = claim.lower_bound(E, alpha, budget=deadline - now())
    return Cert(verdict=('pass' if claim.decided(L) else 'undecided'),
                L=L, c=now() - start, alpha=alpha)

def realtime_fallback(x, M, rulebook, safe_harbor):           # IP-140
    s = realtime_slack(plan, x, M)                            # tau_rt - (cert+act+fb)
    if s < S_MIN:
        x = conservative_downgrade(x)                         # 只可更保守
        sh = safe_harbor.nearest(x) if safe_harbor.covers(x) else None
        audit.log(('slack_negative', s, sh is not None))
        return x, sh, 'preemptively_conservative'
    return x, None, 'nominal'

def compliance_gate(a, s, rulebook, authority):               # IP-141
    for p in rulebook.P:
        if p.predicate(s, a):            return reject('prohibited', p)
    for o in rulebook.O:
        if not o.discharged(s, a):       return reject('obligation_open', o)
    if not any(m.predicate(s, a) for m in rulebook.M):
        return reject('no_permission')
    if conflict(rulebook, a) and not resolve(rulebook.succ, a):
        return escalate('norm_conflict', a)                   # 系统不自裁
    if requires_human(a) and not authority.indep(a):
        return escalate('oversight_not_independent', a)
    return ok(ComplianceCert(rulebook.version, rulebook.region, a))  # 无 u/R 项
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| AEC | 每步 O(d_claim)；总受 τ_rt 封顶 | O(\|cache\|+\|obs\|) | e-过程任意时刻有效（A41） |
| RTS | O(log\|𝒮_h\|) 检索 | O(\|𝒮_h\|) | 安全港认证有效域、截止期单调（A41/A42） |
| NCG | O(\|ℛ\|·d_pred)/动作 | O(\|ℛ\|) | 规则诚实完备、优先序固定（A43） |
| LEA | 追加 O(log N)；验证 O(log N) | O(N) Merkle | 防篡改、选择性披露可信（A44） |
| CML | 遗忘 O(\|D_aff\|) 摊销 | O(\|D_meta\|) | Δ_unl 界诚实、重认证完备（A44） |
| PCE-R | O(\|CP\|·(k_p+k_c)·C_VOI + \|CP\|·log\|𝒮_h\|) | O(\|V\|+\|σ\|) | 三红线由构造保证、τ_rt 内终止 |

**正确性定理（RTC：Real-Time Tractable Compliance）**：在 A22–A40 之上加 **(A41)** AEC 任意时刻有效（对任意停时 $P_{H0}(E_\tau\ge1/\alpha)\le\alpha$）且单步计算受 $c_{max}$ 封顶、截止期单调性成立；**(A42)** 安全港在声明上下文球与 $\tau_h$ 内物理安全且规范允许、运行时可检索；**(A43)** 规则集诚实完备、优先序固定、谓词求值无漏判；**(A44)** 溯源/证明与选择性披露可信，遗忘界 $\Delta_{unl}$ 诚实且重认证完备。则：
1. **限时健全性**：对任意停时 $\tau\le\tau_{rt}$，$P(\text{承诺为假})\le\alpha+\delta_{model}+\delta_{probe}+\varepsilon_{meta}$；**截止期本身不增加不可靠性**（可选停时被 e-过程吸收）。
2. **节拍单调性**：$\tau_1\le\tau_2\Rightarrow\pi_{\tau_1}\sqsubseteq\pi_{\tau_2}$ 或延期；对不可逆/规范敏感动作，证据地板 $E_{min}$ 不随 $\tau$ 变化。
3. **合规不可交易**：给定诚实 $\mathcal R$ 与求值，被禁止动作永不承诺，且该结论不依赖 $E,u,R$；冲突必升级。
4. **可问责性**：每次不可逆承诺均有可验证溯源（至少可查验；高风险在保留期内可复核），且验证不需要原始个人数据。
5. **实时终止**：决策在 $\tau_{rt}$ 内产出；否则进入安全港；无决策概率 $\le\delta_{rt}$。

**部署界**（对检查点取联合界，且合规与安全分开计）：

```
P(违规) ≤ P(规则集错误) + P(谓词漏判) + P(职权共谋) + P(审计被篡改)
P(不安全 | 合规) ≤ Σ_cp (α_t + δ_model + δ_probe + ε_meta(k) + δ_ood·α_conf + δ_xm·1[L1])
                   + P(安全港失效) + P(τ_rt 超时 ∧ 兜底失败)
```

关键：**时间只买保守度，不买证据标准**；**合规只能否决，不能被收益买通**；**审计与隐私分层**（可查验/可复核），而非假装二者可加。

```python
def anytime_certify(claim, obs_stream, deadline, alpha):
    E, L = 1.0, claim.prior_lower()
    start = now()
    while now() < deadline and not claim.decided(L):
        d = deepest_affordable(claim, slack=deadline - now())  # 深度 0..3
        if d == 0: break
        x = obs_stream.next(fidelity=d)                        # 单模态/跨模态/元
        E *= claim.likelihood_ratio(x)                         # 非负鞅（H0 下）
        L = claim.lower_bound(E, alpha,
                              budget=deadline - now())         # time-uniform
    verdict = 'pass' if claim.decided(L) else 'undecided'
    return Cert(verdict, L, claim.upper_bound(E, alpha),
                alpha, now() - start, claim.version, claim.expiry)

def cert_valid(C, M, rulebook_version, corpus_version, health):
    return (C.exp > now() and C.ver == model_version(M)
            and rulebook_version == C.rule_ver
            and corpus_version == C.corpus_ver
            and health == C.health)                            # 任一不符即失效
```

```python
def realtime_slack(plan, x, M, rules):
    c_cert = estimate_cert_cost(plan, M, depth=3)              # 最深可行层
    c_act  = actuation_latency(plan)
    c_fb   = fallback_latency(plan)                            # 含安全停

        return None, conservative_downgrade(x)                 # 预防性降档
    sh = S_h.nearest(x)                                        # O(log|S_h|)
    assert sh.safety_cert.valid and sh.norm_cert.valid         # 双证齐备
    return sh, x
```

### IP-144 PCE-R（节拍 × 合规 × 问责 三线并行）

```python
def probe_commit_evolve_r(x0, M, task, budget, consent, personas, rules):
    route = plan_on_map(M, task, risk_model)
    sched, log = [], []
    for cp in route.checkpoints:
        a = propose(cp, M)                                     # 含 VLA/策略提案
        cg = compliance_gate(a, bridge_state(M, cp), rules, personas.active)
        if cg.kind == 'reject':  return escalate_or_stop(cp, cg, rules)  # 前置否决
        if cg.kind == 'escalate' and not resolve_external(cg):
            return escalate_or_stop(cp, cg, rules)

        slack, parts = realtime_slack(cp, x0, M, rules)
        if slack < S_MIN:
            x0 = conservative_downgrade(x0)                   # 只许更保守
            sh, x0 = choose_safe_harbor(x0, safe_harbor)
            if sh is None: return stop_at(cp, 'no_safe_harbor')  # 失效即拒动
            return commit_safe_harbor(sh, cp, M, log)          # 立即兜底

        inf = anytime_certify(claim_of(cp), M.obs[cp.region],
                              deadline=now() + slack_for(cp), alpha=ALPHA)
        M.b[cp.region] = inf.L if inf.is_id else worst_in(inf.belt)  # 只用下界
        while budget.left and need_more(inf):
            p = select_probes(admissible_probes(cp, M, F_abs), slack_for(cp))[0]
            if storm_budget_exceeded(cp):                       # 延迟攻击

                return commit_safe_harbor(sh, cp, M, log) if sh else stop_at(cp,'storm')

            inf = anytime_certify(claim_of(cp), M.obs[cp.region],
                                  deadline=now() + slack_for(cp), alpha=ALPHA)

            return fallback_chain(cp, x0, M, consent, personas, rules)  # 不降地板

                                        personas.active, deadline=now()+tau_exp)

              and safety_lower_bound(inf, M) <= delta_f(cp)
              and safe_harbor.covers(x0))
```

**正确性定理（RTC：Real-Time Tractable Compliance）**
假设 A22–A40（第 53–57 轮）成立；**(A41)** AEC 任意时刻有效（对任意停时 $\tau$ 有 $P_{H0}(E_\tau\ge1/\alpha)\le\alpha$）、单步计算受 $c_{max}$ 封顶、截止期单调性成立（$\tau_1\le\tau_2\Rightarrow\pi_{\tau_1}\sqsubseteq\pi_{\tau_2}$ 或延期，且 $E_{min}$ 与 $\tau$ 无关）；**(A42)** 安全港在声明上下文球与 $\tau_h$ 内物理安全且规范允许、运行时可检索；**(A43)** 规则集 $\mathcal R_{v,r}$ 诚实完备、优先序 $\succ$ 固定、谓词求值无漏判；**(A44)** 溯源与选择性披露可信、遗忘界 $\Delta_{unl}$ 诚实且重认证完备。则：

1. **限时健全性**：对任意停时 $\tau\le\tau_{rt}$，
   $$P(\text{承诺为假})\le\alpha+\delta_{model}+\delta_{probe}+\varepsilon_{meta}(k)+\delta_{ood}\alpha_{conf}+\delta_{xm}\mathbb 1[L1];$$
   截止期收缩本身不增加不可靠性（可选停时被 e-过程吸收），只可能把 `pass` 变 `undecided`。
2. **节拍单调性**：$\tau$ 减小只产生更保守动作或延期；对不可逆/规范敏感动作，证据地板 $E_{min}$ 恒定。形式化：不存在 $\tau_1<\tau_2$ 与动作 $a$ 使 $\pi_{\tau_1}(a)$ 在 $\sqsubseteq$ 上比 $\pi_{\tau_2}(a)$ 更激进，或使 $E_{min}$ 下降。
3. **合规不可交易**：给定诚实 $\mathcal R$ 与求值，$\forall a\in P$ 永不承诺，且该结论不含 $E,u,R$；未决冲突必升级至外部。
4. **可问责性**：每次不可逆承诺存在可验证溯源；高风险动作在保留期内可复核，删除后至少可查验（签名冻结证书 + 选择性披露）。
5. **实时终止**：决策在 $\tau_{rt}$ 内产出；否则进入已验证安全港或安全停；$P(\text{无决策})\le\delta_{rt}$。

**部署界**（合规与安全分开计，对检查点取联合界）：

```
P(违规) ≤ P(规则集错误) + P(谓词漏判) + P(职权共谋) + P(审计被篡改)
P(不安全 | 合规) ≤ Σ_cp (α_t + δ_model + δ_probe + ε_meta(k) + δ_ood·α_conf + δ_xm·1[L1])
                   + P(安全港失效) + P(τ_rt 超时 ∧ 兜底失败) + P(解释迟滞 ∧ 强制承诺)
```

关键：**元先验给效率、任意时刻界给保底、安全港给兜底**（效率/安全/实时解耦）；**合规只做减法**（只能撤销许可）；**审计与隐私分层**（可查验/可复核）而非相加；三条红线（截止期单调、证据地板不变、合规不可交易）由构造与审计双保证。

## 6. 本轮最大风险

**一句话**：本轮把"来得及判"与"有权去判"同时托付给一份预先认证的安全港和一份机器可读规则集，最大风险是**制衡者缺席**——若规则来源、安全港预认证与审计权都来自部署方自己，低延迟降级会把"来不及查"制度化为"不用查"，合规沦为自己签发的橡皮章；必须以规则/审计外部独立、证据地板不随截止期下降、安全港失效即拒动三条不可交易红线兜底，宁可停下等一个独立的人，也不采信系统给自己的许可。
