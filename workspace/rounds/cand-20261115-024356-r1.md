# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「行为树」×「结构优化」）

> R69 让系统学会了「问」：aleatoric 收紧、epistemic 交互消解、信息动作也要认证。但它把「不确定性处置」写成了一条**固定的线性管线**：标定 → 流采样 → 二分 → VoI → 似然 → 选模 → 认证 → 审计。这条管线隐含了两个工程假设：
>
> - **同构假设**：所有任务、所有技能、所有状态下，不确定性都走同一套全局流程、付同一份最坏成本。可真实系统是异质的：接触时不能转头看人，高速行走时问句有社交风险，标定只在长周期需要，恢复动作必须抢占一切。固定管线要么在不需要处浪费预算，要么在需要处来不及切换。
> - **单一权威假设**：安全由整条管线的 `J_FLUID` 一次认证。但当系统由几十个可替换技能组成时，**组合**才是失效的温床：两个各自安全的子树并行时会争抢同一份交互预算；一个在 `Running` 中被抢占的探针会把机械臂留在半空中；优先级写错会让「恢复」永远轮不到。R69 没有语言去说「谁先、谁让、谁能打断谁」。
>
> 本轮两个灵感正好补上这两块：
>
> - **行为树**给出一门**可组合、可反应、可审计**的决策语言：叶是带合同的技能，组合子（Sequence/Fallback/Parallel）是推理规则，整棵树是一个**证明项**。安全性不再由一张全局证书「盖章」，而由「叶合同 + 组合规则」逐层归纳出来；离散模式切换、优先级、抢占、并发都被显式写进结构。
> - **结构优化**给出一套**优化结构本身**的纪律：设计域、拓扑变量、尺寸变量、传力路径、逐点应力约束、鲁棒性、可制造性。它教给我们的最重要一课不是「怎么省材料」，而是「**任何优化器都会寻找约束的缝隙；必须把安全写成不可删除的承力路径**」。
>
> 核心命题：**把 R69 的固定管线编译成一棵可认证行为树 `T_R69`，把它当作结构优化的设计域基线与「不可删除的承力骨架」；只允许在「保证书语法 CPT」内做拓扑/尺寸编辑；优化目标是最小化任务成本与交互/延迟/开关消耗，约束是逐点安全裕度（用 KS 聚合做保守可微近似）、组合资源守恒与开关疲劳上界。于是任一被优化出的树都「构造即认证」，且 R69 是其恒等编辑边界——安全侧严格不弱，效率侧获得结构重分配的红利。** 命名 **TRUSS-RAS**（Tree-structured Risk-aware Uncertainty-aware Safe Synthesis for Risk-Adaptive Safety）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我的决策结构本身可信吗、该把预算给哪根承力梁、切换时会不会塌**」——安全不只是刹车与提问，也是一棵被证明过、且只被允许越优化越稳的树。

## 0. 直觉与动机

**灵感 1（行为树 → 决策是一个证明项，不是一条流水线）**
直觉：把 R69 的 `if g is not None: ... else: ...` 展开，它其实已经是一棵隐式的树，只是被写死在代码里。行为树的贡献不是「换一种控制写法」，而是把**组合推理**摆到台面上：`Sequence` 是「前一个的后条件蕴含后一个的前条件」，`Fallback` 是「前一个失败仍保持不变量，才允许试下一个」，`Parallel` 是「互不干扰才可并发」。每一片叶只承诺局部合同（`Pre/Post/Inv/Abort/Res`），整棵树的安全由结构归纳得到。于是「加一个新技能」不再是往管线里插一行，而是**往证明里加一个引理**；「关掉一个技能」也不再是删代码，而是检查它是否承力。安全性因此从「一张全局证书」变成「一棵可局部替换、可局部重证的证明树」。

**灵感 2（行为树 → 反应性让不确定性处置局部化）**
直觉：R69 的 VoI 是全局的，每个周期都要问「要不要交互」。但交互是否可行高度依赖**当前正在执行的技能**：抓取接触阶段不能转头看人；高速行走时问句可能造成社交危险；只有在「接近—对准—释放」这些低风险窗口才适合探询。行为树把「什么时候可以问」写成守卫条件（guard）和装饰器（`Timeout/BudgetGate/Hysteresis`），让交互预算**只在该花的地方、只在该花的时候**花。这不是把 R69 的 MINT 删掉，而是给它加了一层「技能局部性」：全局预算被结构分配到子树，局部 VoI 只需在子树内比较。

**灵感 3（结构优化 → 决策也有「传力路径」与「承力梁」）**
直觉：一根桁架之所以安全，不是因为每根杆都粗，而是因为**从载荷到支座的每一条传力路径都不断**。决策树也一样：从「感知到的不确定性」到「执行器的安全动作」，中间有一条条**认证路径**；有些节点是装饰（可选、可剪），有些节点是承力梁（一旦删掉，某类场景的安全裕度立刻变负）。结构优化教我们把「材料」从低应力处搬到高应力处：在决策树里，就是把**交互次数、采样预算 K、计算节拍、授权**从低荷载子树搬到高荷载子树；对应力饱和的子树只许加冗余（fallback），不许减配。更关键的是，它把「安全」写成**逐点应力约束**，而不是平均性能：平均值好看但某一状态裕度为负，结构就是塌的。

**灵感 4（结构优化 → 优化器的敌人是规范，不是数据）**
直觉：拓扑优化里最经典的失败不是收敛不了，而是**约束漏了一项**：没写应力约束，优化器就给你一个满是细杆、应力爆表的「最轻结构」；没写制造约束，就给你一个造不出来的形状。优化器不会偷懒，它会**精确地利用你写的规范的每一处缝隙**。因此本轮最重要的不是「怎么优化」，而是「**怎么让优化器没有机会优化掉安全**」：只允许保证书变换（CPT）——加守卫、包 fallback、拆并行、在认证区间内调参；禁止剪掉承力节点；禁止把「平均安全」当「逐点安全」；禁止在优化目标里用代理指标替代真实证书。这是把「可制造性约束」翻译成「可认证性约束」。

**灵感 5（结构健康监测 → 树的激活谱是一条独立的损伤通道）**
直觉：结构工程里，损伤往往先改变**传力路径**，再在局部应力上显现；所以健康监测看的是模态/应变分布的漂移，而不只是某一个传感器的读数。R69 的两条通道（传感器残差 `r_res`、流似然 `Δa`）都可能被标定或自适应「解释掉」；但一个技能退化后，树会**绕路**：fallback 停留变长、交互重试变多、名义叶激活变短。把「节点—状态—驻留时间」的激活谱按任务上下文建参考分布，其漂移 `r_str` 就是第三条、**结构耦合**的损伤证据。它不能替代前两条，但它与前两条正交：前者测传感器自洽，后者测行为自洽，`r_str` 测**组织自洽**。

**灵感 6（反应性是双刃剑 → 切换会抖、会累、会半途而废）**
直觉：树越反应，越容易在守卫条件附近**抖动**（chattering）：epistemic 阈值上下浮动，系统在「问」与「做」之间来回切；这既消耗交互预算，也让人类困惑。更危险的是**抢占副作用**：一个 `Running` 的探针被 fallback 打断，机械臂可能停在力包络边缘；一个已经问出口的问题被取消，回答却晚到，污染下一轮证据。结构工程里，静载安全的结构会死于**疲劳**；行为树里，静态安全的树会死于**切换疲劳**。所以必须交付：迟滞带、驻留时间、可抢占合同（`Abort`）、事务式叶（要么提交要么安全撤回）、以及开关疲劳预算。没有这些，R70 只是给 R69 装了一个更灵活、也更容易抽风的骨架。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（TRUSS-RAS 总览）** TRUSS-RAS = (CBT, TCL, SOD, CPT, LBA, RAG, TSA, HIA, SHM, RAS-WM‡)。五不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **组合证书**：任一 tick 的激活路径都在 `Certified(T)` 内，且叶合同与组合规则同时成立（定义 313）；
(iii) **保证书编辑**：结构优化只允许 `CPT` 语法内的编辑；任何承力节点/边不可删除或弱化（定义 318）；
(iv) **资源守恒**：交互、延迟、采样、开关预算在组合下按定义 320 的代数守恒，任何并发子树不得重复花费同一份预算；
(v) **单调细化**：`T_R69` 是设计域的恒等基线；优化失败/证书失效/结构异常时回退到 `T_R69`，沿回退链证书单调不弱、`λ` 单调不降（定义 326）。

**定义 311（可认证行为树 CBT 与 tick 语义）** 树 `T=(N,E,type,ℓ,mem)`。叶 `ℓ ∈ 𝔏 = {NominalFlow, InteractiveDisambiguation, ConservativeHold, Calibrate, Declare, Recover, ...}`。内部节点 `type ∈ {Seq, Fall, Par, Hyst, Timeout, BudgetGate, Guard}`。一次 tick 是部分函数
`Tick_T: (bb, mem, o_t) → (status ∈ {S,F,R}, bb', mem', τ_tick)`，
其中 `bb` 是类型化黑板，`mem` 是 `Running` 记忆；`W(ℓ)` 为叶的写集合。`Guard` 只读黑板；`Hyst` 带上下阈值；`BudgetGate` 在进入子树前预留资源令牌。**约定：tick 是事务式的**——一个 tick 内要么完整提交黑板写入，要么在 `Abort_ℓ` 保证下撤回（定义 321）。

**定义 312（叶合同）** 每个认证叶附带
`C_ℓ = (Pre_ℓ, Post_ℓ, Inv_ℓ, Abort_ℓ, Res_ℓ, Cap_ℓ)`：
- `Pre_ℓ/Post_ℓ`：黑板上的假设/保证谓词；
- `Inv_ℓ`：叶执行期间（含 `Running`）恒真的安全不变量；
- `Abort_ℓ = (τ_abort, a_abort, Inv_abort)`：抢占合同，`a_abort` 在 `τ_abort` 内把系统带回 `Inv_abort`，且 `Inv_abort` 蕴含 `Inv_ℓ`；
- `Res_ℓ ⊆ ℝ^d_+`：最坏资源向量（交互次数、延迟、采样数、开关数、社交成本）；
- `Cap_ℓ`：叶被认证的能力域（状态/任务子集）；域外必须返回 `F`，不得返回 `S`。
`CertifiedLeaf(ℓ)` ⇔ 在 `Cap_ℓ` 上 `Pre_ℓ` 成立时，`Inv_ℓ` 全程保持、`Post_ℓ` 在 `S` 时成立、`Abort_ℓ` 可认证、`Res_ℓ` 有界。

**定义 313（组合规则与 Certified(T)）**
- `Seq(c_1,…,c_n)`：对每个成功转移要求 `Post_{c_i} ⇒ Pre_{c_{i+1}}`；`Inv = ∧_i Inv_{c_i}`；`Res = Σ_i Res_{c_i}`；`Post = Post_{c_n}`。
- `Fall(c_1,…,c_n)`：`Pre = ∨_i Pre_{c_i}`；每个 `c_i` 返回 `F` 或 `R` 时 `Inv_{c_i}` 保持；若 `c_i` 失败，则要求 `Pre_{c_{i+1}}` 或整棵 fallback 以 `Inv` 保持地返回 `F`；`Res = max_i Res_{c_i} + Res_select`（同一时刻只激活一支）。
- `Par(c_1,…,c_n)`：要求**非干扰** `W_i ∩ W_j ⊆ ReadOnly`（或写入可交换），否则必须显式加锁/串行化；`Inv = ∧_i Inv_{c_i}`；`Res = Σ_i Res_{c_i}`。
- 装饰器：`Hyst` 只收窄激活域，`Timeout` 到时强制走 `Abort`，`BudgetGate(r)` 在 `Res` 会越界时返回 `F` 且不改黑板。
`Certified(T) ⇔ ∀ℓ CertifiedLeaf(ℓ) ∧ ∀n 组合规则成立`。**注意：合同只承诺「条件成立时安全」，不对 `Pre` 本身的充分性负责——这正是最大风险的根源（§6）。**

**定义 314（超树与设计域）** 设计域是一棵**超树** `T_max=(N_max,E_max)`，包含 R69 编译出的基线 `T_R69`、所有候选技能叶、可选交互/恢复/声明子树、以及候选优先级边。`T_max` 是结构优化的「毛坯」；优化只能在其子结构中选择，不得引入未认证的新叶。`T_R69` 可由 R69 管线机械编译，例如
`Seq(Calibrate, Fall(Seq(FlowSample, Decompose, Fall(Ask, Hold)), ConservativeHold), FMA, Select, Certify, Audit)`。

**定义 315（结构设计变量）** `x = (ρ, c, π, s, α)`：
- 拓扑 `ρ ∈ {0,1}^{|N_opt|}`（可选节点/边的存在性；连续松弛 `ρ̃∈[0,1]` 用于梯度优化，投影回 `{0,1}` 后必须过证书）；
- 组合类型 `c_n ∈ {Seq,Fall,Par}` 与 fallback 顺序 `π`；
- 尺寸 `s`：叶的 tick 周期、采样数 `K`、阈值 `(τ_epi, τ_mode, τ_fma, τ_ece)`、迟滞宽度 `h`、驻留 `τ_dwell`、交互配额、`λ` 下限参数；
- 授权 `α_ℓ ∈ [0,1]`：子树可支配的决策/资源份额，`Σ_ℓ α_ℓ ≤ 1`（与预算代数耦合）。
`T(x)` 为由 `x` 实例化的树；`x_0` 为 `T_R69` 的恒等参数。

**定义 316（逐点安全裕度与 KS 聚合）** 对状态/结果 `ω`，安全裕度 `m(x,ω) ≥ 0` 表示「离安全边界还有多远」（可取 `m_esc`、证书松弛、碰撞距离、力包络余量等的归一化下确界）。逐点安全是无限约束 `min_ω m(x,ω) ≥ 0`。用 Kreisselmeier–Steinhauser 聚合：
`M_KS(x) = −(1/κ) ln Σ_{i=1}^{N} exp(−κ m(x,ω_i))`。
则 `M_KS ≤ min_i m_i` 且 `min_i m_i − M_KS ≤ ln N / κ`。取 `κ = ln N / ε`，强制 `M_KS ≥ δ_m` 即保证 `min_i m_i ≥ δ_m`（保守方向），误差 `≤ ε`。`Ω_N` 由「名义场景 + 红队最坏场景 + 证书边界场景」组成；对未采样区域用区间/区域证书兜底（A95）。

**定义 317（结构优化问题）**
`min_x  E[cost(x)] + λ_lat E[τ_tick] + λ_int E[n_int] + λ_sw E[n_switch] − λ_prog E[progress]`
s.t. `M_KS(x) ≥ δ_m`（逐点安全），`Certified(T(x))`，`Res_total(x) ≤ R_max`（定义 320），`x ∈ CPT-Closure(T_R69)`（定义 318），以及 `P99(τ_tick) ≤ τ_rt`。
鲁棒版把期望换成 `CVaR_α` 或分布鲁棒 `max_{P∈𝒫} E_P[·]`，`𝒫` 覆盖观测噪声、人的响应模型、执行器退化。**安全约束不进入拉格朗日松弛的「可交易项」：它是硬约束，永不被性能赎买。**

**定义 318（保证书变换 CPT 与承力判定）** 编辑语法 `G_CPT`：
`AddGuard`, `WrapFallback`, `SplitParallel`, `ReorderFallback`, `PruneOptional`, `Inline`, `Specialize`, `Retune`。
每个编辑 `e` 带证明义务 `O(e)`；`x' = e(x)` 可接受 ⇔ `O(e)` 成立 ∧ `M_KS(x') ≥ δ_m` ∧ `Certified(T(x'))` ∧ `x'` 仍是 `T_R69` 的安全细化（定义 326）。拓扑编辑只在离线设计周期/维护窗口执行；在线只允许认证区间内的 `Retune` 与 `AddGuard`，且需重签证书。
- `AddGuard(g)`：只收窄激活域，不改变任何叶的合同；
- `WrapFallback(n,F)`：`F` 在 `¬Post_n` 上认证，且 `Inv` 保持；
- `SplitParallel`：非干扰证明 + 资源求和；
- `ReorderFallback(π)`：仅当**最坏情况**（而非期望）证书不弱化，或两支均认证且 `Inv` 与选择无关；
- `PruneOptional(n)`：仅当 `n` **非承力**：对所有 `ω∈Ω_N`，删去 `n` 后 `m` 不降、`Certified` 不破、`Res` 不超；
- `Inline/Specialize/Retune`：合同匹配/参数仍在认证区间。
**承力节点** `n`：存在 `ω` 使 `n` 位于所有认证路径，或删去 `n` 后 `M_KS < δ_m`。`G_CPT` 禁止删除/弱化承力节点与承力边。这条就是决策树的「可制造性约束」。

**定义 319（决策荷载与结构应力）** 节点 `n` 的荷载
`L_n = E[1{n 在激活路径}] · Δprogress_n + E[1{n 是唯一认证路径}] · Δsafety_n`，
应力 `σ_n = 1 − min_{ω∈Ω_n} m_n(ω)/δ_m`（`Ω_n` 为经过 `n` 的临界场景）。`σ_n → 1` 表示该节点已接近安全边界，只允许加冗余、不允许再减配；`σ_n` 低且 `L_n` 高的节点是资源迁移的接收方。结构优化因此不是「均匀加粗」，而是「把预算搬到高荷载、低应力处，把冗余加到高应力处」。

**定义 320（资源代数与预算守恒）** 资源向量 `r = (n_int, τ_lat, n_samp, n_switch, c_social)`。组合：
`Seq: r = Σ r_i`；`Fall: r = max_i r_i + r_select`（分支互斥，取最坏）；`Par: r = Σ r_i`。
全局不变式：任一执行窗口 `Res_total = Σ_active r + r_guard ≤ R_max`；交互叶在进入前必须从 `BudgetGate` **原子地**取得令牌，退出/中止时归还；并发交互不得共享同一令牌。交互的**影子价格** `μ_t ≥ 0` 由对偶上升更新：`μ_{t+1} = [μ_t + η(Res_total − R_max)]_+`；子树只在 `VoI(g) > (1+μ_t)c(g)` 时提问。这把「全局一次问一次」变成「全局预算 + 局部 VoI」的 KKT 分配，也防止两个子树同时把同一份社交预算花掉。

**定义 321（开关安全、迟滞与疲劳）** 守卫信号 `d_t`，激活阈值 `θ_on`、失活阈值 `θ_off = θ_on − h`，驻留 `τ_dwell`。切换事件只允许发生在**安全切换点**：`Abort_ℓ` 可认证、`τ_abort` 满足、后继 `Pre` 在当前黑板成立、且没有半开的交互事务（问句未撤回/探针未归位）。定义
`switch_fatigue F = Σ_{switches} w(ℓ→ℓ')`，要求 `F ≤ F_max`；`w` 反映中止代价与副作用。抖振界：对同一守卫，任意两次切换间隔 `≥ max(τ_dwell, h/|ḋ|)`，故窗口 `T` 内切换数 `≤ T/τ_dwell + TV(d)/h`。**这把行为树的反应性从「无限快切换」约束为「有疲劳寿命的切换」。**

**定义 322（结构健康监测 SHM）** 滑动窗口内激活谱
`A_t(n, status, dwell | c_t)`，`c_t` 为任务/上下文标签；参考谱 `A_ref(·|c_t)` 来自认证日志，并在每次 CPT 结构变更后**重新基线化**。结构残差
`r_str = D(A_t(·|c_t) || A_ref(·|c_t)) − E[D | c_t, phase]`，
`D` 用 KL/MMD。结构异常判据：`r_str > τ_shm` 且**不能**由任务阶段、合法重规划、或已知 CPT 变更解释。典型损伤签名：`fallback` 驻留↑、交互重试↑、名义叶驻留↓、`r_res≈0`、`Δa≈0`。`r_str` 与 `(r_res, Δa)` 正交：它测「组织是否在带病绕路」，而不是「传感器是否自洽」或「动作是否低概率」。

**定义 323（分层交互分配 HIA）** 全局预算 `B`，子树 `j` 的局部候选 `g`；局部 VoI `VoI_j(g)` 用子树后验计算；选择
`g* = argmax_{j,g} [VoI_j(g) − (1+μ_t)c_j(g)]`，s.t. 认证、预算令牌、子树安全窗口。
当 `μ_t` 大（预算紧）时，只有高判别力、低成本的交互被选中；当所有 `VoI ≤ (1+μ)c` 时全局不交互，退化为 R69 的「不交互」路径。**结构优化决定交互节点长在哪，HIA 决定这一拍花不花、花在哪。**

**定义 324（威胁模型 ℰ_TRUSS）** `ℰ_TRUSS = ℰ_FLUID × ℰ_struct × ℰ_switch × ℰ_profile`：
- `ℰ_struct`：守卫篡改、优先级投毒、删除 fallback 边、叶合同伪造（叶谎报 `Pre/Post`）、优化器奖励黑客（利用缺失约束）；
- `ℰ_switch`：在守卫阈值附近振荡以耗尽交互/疲劳预算、在不安全时刻触发抢占、半开事务攻击；
- `ℰ_profile`：模仿健康激活谱以逃避 SHM、重放旧谱、伪造上下文标签；
- `ℰ_FLUID` 继承 R69（投毒、幻影模态、流采样故障）。
并入 AIC；红队优化（E304）是 `ℰ_struct` 的主动版本。

**定义 325（证书 J_TRUSS）** `J_TRUSS = (J_FLUID, h_T, h_cert, M_KS_min, F, budget_util, r_str_p95, cpt_log_hash, truss_ver)`。
`Valid ⇔ Valid(J_FLUID) ∧ Certified(T) ∧ M_KS ≥ δ_m ∧ Res_total ≤ R_max ∧ F ≤ F_max ∧ r_str ≤ τ_shm`（最后一项异常时进入只读/回退，而不是继续优化）。

**定义 326（退化链与严格细化）** `TRUSS → FLUID → CALM`：
- 停用结构优化 ⇒ `x = x_0` ⇒ `T = T_R69`，行为与 R69 **逐指令一致**；
- CPT 失败/证书失效/结构异常 ⇒ 回退到最近一棵认证树，再不行回 `T_R69`；
- 任一在线守卫失败 ⇒ 关闭相应子树，回 R69 的纯保守（`λ_floor`）。
沿链 `λ` 单调不降、证书单调不弱：`Valid(TRUSS) ⇒ Valid(FLUID) ⇒ Valid(CALM)`。**R69 不是被替代，而是被「结构优化禁用」这个边界严格包含。**

# IP-264 CBT：带合同、资源令牌、事务抢占的 tick 引擎
def tick(node, bb, mem, tok):
    if is_leaf(node):
        if not node.Pre(bb):            return F, bb, mem
        if not tok.reserve(node.Res):   return F, bb, mem      # BudgetGate
        st, bb2, mem2 = node.run(bb, mem)
        if st == R and not node.Inv(bb2):
            return F, abort(node, bb)                          # Abort 合同
        if st != R: tok.release(node.Res)                      # 事务提交
        return st, bb2, mem2
    if node.type == 'Seq':
        for c in node.children:
            st, bb, mem = tick(c, bb, mem, tok)
            if st != S: return st, bb, mem
        return S, bb, mem
    if node.type == 'Fall':
        for c in node.children:
            if not c.Pre(bb): continue
            st, bb2, mem2 = tick(c, bb, mem, tok)
            if st in (S, R): return st, bb2, mem2
            if not node.Inv(bb2): return F, abort(node, bb)
        return F, bb, mem
    if node.type == 'Par':
        # 非干扰已在编译期证明；任一 Running 则整树 Running
        return parallel_tick(node, bb, mem, tok)

# IP-265 TCL：静态组合证书（离线；实时环只查 h_cert）
def certify(T, scenarios):
    assert all(CertifiedLeaf(l) for l in leaves(T))
    for n in postorder(T):
        assert compose_rule_ok(n)          # Seq/Fall/Par 的证明义务（定义 313）
    return ks_margin(T, scenarios)         # 定义 316

# IP-266/267/268 SOD+CPT+LBA：结构优化 = 松弛 + 投影 + 保证书过滤
def structural_optimize(T_max, T_R69, scenarios, budget):
    x = warm_start(T_R69)                  # 恒等基线，必可行
    for _ in range(N_outer):
        x_relax = solve_relaxed(x, ks_constraint, robust_cvar)   # rho~, s, alpha
        for cand in project_and_cpt(x_relax):                    # 投影 + CPT 语法
            if load_bearing_violation(cand, scenarios): continue # 承力梁不可删
            if not certify(cand, scenarios):            continue
            if ks_margin(cand, scenarios) < delta_m:    continue
            if not refines_R69(cand):                   continue
            x = better(x, cand)                # 目标 + 资源 + 疲劳
    return x, tree_hash(x)

# IP-271 HIA：影子价格下的分层交互（局部 VoI + 全局预算）
def choose_interaction(tree, bb, mu):
    best = None
    for j, g in local_candidates(tree, bb):
        if not tree.certify_info(j, g, bb): continue
        score = local_voi(j, g, bb) - (1 + mu) * cost(j, g)
        if best is None or score > best.score: best = (j, g, score)
    return best if best and best.score > 0 else None   # 无利可图 -> 不交互

# IP-272 SHM：结构残差（上下文条件化 + CPT 后重基线）
def structural_health(act_window, ctx, ref):
    A = spectrum(act_window, ctx)          # (node,status,dwell) 分布
    return mmd(A, ref[ctx]) - expected_divergence(ctx)   # r_str

# IP-275 主闭环：实时路径只多了 tick/guard/token/SHM
def TRUSS_round(M, obs):

    tok = M.budget_gate.begin_tick(M.R_max)
    T   = M.cbt.active_tree                # 已认证、已优化

    # 结构层只决定「谁被 tick、何时切换、预算给谁」
    M.audit.submit(st, T.hash, tok.ledger, M.shm.snapshot())
    M.shm.push(T.hash, bb.activation_trace)
    return st, bb, tok.ledger

## 3. 推导

**引理 19（组合证书的可靠性）** 若所有叶满足 `CertifiedLeaf` 且每个内部节点满足定义 313 的组合规则，则对任意 tick，`Certified(T)` 蕴含 `Inv(T)` 全程成立、且安全相关输出不越出叶的 `Cap` 并集。证明：对树高结构归纳。基例为叶合同；`Seq` 由 `Post_i ⇒ Pre_{i+1}` 把归纳假设逐段接起来；`Fall` 的关键是「失败也保持 `Inv`」和「后继 `Pre` 成立才切换」，因此任何时刻至多一个 `Running` 叶，其 `Inv` 覆盖整树；`Par` 由非干扰把任意交错等价为串行组合，再由归纳假设与 `Inv = ∧ Inv_i` 得证。装饰器只收窄激活域/强制 `Abort`，不扩大输出集。∎

**引理 20（保证书变换保持证书与细化）** 若 `x' = e(x)` 只使用 `G_CPT` 且 `O(e)`、`M_KS(x') ≥ δ_m` 成立，则 `Certified(T(x'))` 且 `T(x')` 是 `T_R69` 的安全细化。证明：逐个编辑检查。`AddGuard` 只缩小激活域，输出集单调缩小；`WrapFallback` 在 `¬Post_n` 上增加一条认证恢复路径，原成功路径不变；`SplitParallel` 的非干扰证明使交错不引入新状态；`ReorderFallback` 的最坏情况单调条件保证任何状态下的安全裕度不降；`PruneOptional` 只删非承力节点，由承力定义 `M_KS` 与 `Certified` 不降；`Inline/Specialize/Retune` 在合同/认证区间内。归纳得 `Certified`。细化传递性由「输出集单调缩小 + `Inv` 保持」给出。∎

**引理 21（KS 的保守性）** 对任意 `m_i`，`M_KS = −(1/κ)ln Σ e^{−κm_i}` 满足 `M_KS ≤ min_i m_i` 且 `min_i m_i − M_KS ≤ ln N/κ`。取 `κ = ln N/ε`，则 `M_KS ≥ δ_m ⇒ min_i m_i ≥ δ_m`。证明：标准 log-sum-exp 双侧界；指数和 ≥ 最大项给出下界，≤ `N·最大项` 给出上界，取负号后方向反转。∎ 系：`M_KS` 是逐点安全约束的**保守可微代理**；它只会高估风险，不会低估，因此不会给优化器「漏掉一个负裕度」的机会（在 `Ω_N` 覆盖的范围内）。

**定理 18（TRUSS 严格包含 R69）** 设 `T_R69` 满足基线安全约束，取 `δ_m := M_KS(T_R69)`。则：
(a) `x_0`（恒等编辑）可行，且 `T(x_0) = T_R69`，行为逐指令一致；
(b) 任一可行 `x` 满足 `M_KS(x) ≥ δ_m = M_KS(T_R69)`，故逐点安全裕度不低于 `T_R69`（在 `Ω_N` 与区域证书覆盖内）；
(c) 目标函数中 `x_0` 可行，故最优值 `≤ cost(T_R69)`，即效率侧不劣于 R69；
(d) 若不存在改进的 CPT 编辑（或优化被禁用），返回 `x_0`，与 R69 完全相同。
因此 R69 是 TRUSS 在「禁用结构优化」边界上的严格退化；安全侧不让步，效率侧获得结构重分配红利。∎

**定理 19（开关安全与抖振/疲劳界）** 在定义 321 的迟滞、驻留与抢占合同下：
(a) 任何切换不破坏 `Inv(T)`：切换前 `Inv` 成立；`Abort_ℓ` 在 `τ_abort` 内把状态带回 `Inv_abort ⊇ Inv_ℓ`；后继 `Pre` 成立后由引理 19 保持 `Inv`；半开事务被禁止，故无跨切换的悬空副作用。
(b) 同一守卫的切换间隔 `≥ max(τ_dwell, h/|ḋ|)`，故窗口 `T` 内切换数 `≤ T/τ_dwell + TV(d)/h`；当输入有界变差时抖振有界。
(c) 疲劳 `F ≤ F_max` 由 `BudgetGate` 强制；一旦将超预算，树冻结在当前认证配置并降级到 R69 保守路径。
(d) 输出连续性：每个叶在安全切换点输出位于认证包络内，切换不产生超过 `ε_sw` 的跳变；因此 R68/R69 的无突变不变式保持。∎

**引理 22（分层交互的影子价格最优性）** 设局部 VoI 函数在预算内凹、成本线性，全局问题为 `max Σ_j VoI_j(g_j) s.t. Σ_j c_j(g_j) ≤ B`。其 KKT 条件给出 `∇VoI_j = μ ∇c_j`，即每个子树按同一影子价格 `μ` 选择 `VoI_j − μ c_j` 的最大点；对偶上升 `μ ← [μ + η(Σc − B)]_+` 在标准对偶收敛条件下收敛到最优 `μ*`。因此 HIA 的局部贪心 + 全局价格与集中式分配同解，且资源代数保证不重复花费。∎

**命题 1（SHM 的正交性，条件性）** 在 A103–A105 下：（A103）树的失败路由对技能成功率单调（成功率下降 ⇒ fallback/重试激活增加）；（A104）参考谱按任务上下文条件化并在 CPT 后重新基线化；（A105）退化未被其他子树完全补偿。则技能退化使 `r_str` 的期望增加至少 `c·Δp − ε`，而 `r_res` 可因标定吸收保持 `≈0`、`Δa` 可因策略自适应保持小。故 `r_str` 是与 `(r_res, Δa)` 正交的第三条损伤通道。**注意：这是条件性命題，不是无条件定理；E309/E310 专门检验其功效与误报。**

## 6. 本轮最大风险

**次级风险与缓解**：
1. **合同是假设-保证，不对假设充分性负责** → 合同必须保守、加运行时监控、用红队优化（E304）主动找缝隙；
2. **行为树抖振/抢占副作用/半开事务** → 迟滞 + 驻留 + `Abort` 合同 + 事务式叶 + 开关疲劳预算（定义 321、定理 19）；
3. **并发交互重复花预算** → 资源代数 + 原子令牌 + 影子价格（定义 320、引理 22）；
4. **SHM 误报与谱模仿** → 上下文条件化 + CPT 后重基线 + 反事实重放 + `ℰ_profile` 对抗（定义 322/324、E310）；
5. **优化器过拟合训练场景** → CVaR/分布鲁棒 + 留出场景 + 跨本体迁移（定义 317、E312）；

# IP-264 CBT：事务式 tick + 合同 + 资源令牌
def tick(node, bb, mem, tok):
    if is_leaf(node):
        if not node.Pre(bb) or not tok.reserve(node.Res): return F, bb, mem
        st, bb2, mem2 = node.run(bb, mem)
        if st == R and not node.Inv(bb2): return F, abort(node, bb)
        if st != R: tok.release(node.Res)
        return st, bb2, mem2
    if node.type == 'Seq':
        for c in node.children:
            st, bb, mem = tick(c, bb, mem, tok)
            if st != S: return st, bb, mem
        return S, bb, mem
    if node.type == 'Fall':
        for c in node.children:
            if not c.Pre(bb): continue
            st, bb2, mem2 = tick(c, bb, mem, tok)
            if st in (S, R): return st, bb2, mem2
            if not node.Inv(bb2): return F, abort(node, bb)
        return F, bb, mem
    return parallel_tick(node, bb, mem, tok)   # Par：非干扰已静态证明

## 4. 推导

**引理 19（组合证书可靠性）** 所有叶认证 + 组合规则成立 ⇒ 任意 tick 全程 `Inv(T)` 成立、输出不越出叶的能力域。证明：对树高归纳；`Seq` 用 `Post_i⇒Pre_{i+1}` 接续，`Fall` 用「失败保持 `Inv` + 后继 `Pre` 成立才切换」，`Par` 用非干扰把交错等价为串行；装饰器只收窄输出集。∎

**引理 20（CPT 保持证书与细化）** `G_CPT` 编辑 + 证明义务 + `M_KS≥δ_m` ⇒ `Certified(T(x'))` 且 `T(x')` 是 `T_R69` 的安全细化。证明：逐编辑检查；`AddGuard` 缩域、`WrapFallback` 加认证恢复路径、`SplitParallel` 用非干扰、`ReorderFallback` 用最坏情况单调、`PruneOptional` 用非承力、`Retune` 留在认证区间；归纳并传递细化。∎

**引理 21（KS 保守性）** `M_KS ≤ min m ≤ M_KS+lnN/κ`；取 `κ=lnN/ε`，则 `M_KS≥δ_m ⇒ min m≥δ_m`。证明：log-sum-exp 双侧界；指数和的下界由最大项给出、上界由 `N×最大项` 给出，取负后方向反转。∎ 系：KS 只会高估风险，不会给优化器漏掉负裕度的机会（在 `Ω_N` 覆盖内）。

**定理 18（TRUSS 严格包含 R69）** 取 `δ_m := M_KS(T_R69)`。则：(a) 恒等编辑 `x_0` 可行且 `T(x_0)=T_R69`，行为逐指令一致；(b) 任一可行 `x` 有 `M_KS(x)≥M_KS(T_R69)`，安全不弱；(c) `x_0` 可行 ⇒ 最优目标 `≤ cost(T_R69)`，效率不劣；(d) 无改进编辑/禁用优化时返回 `x_0`，与 R69 完全相同。故 R69 是「禁用结构优化」边界上的严格退化。∎

**定理 19（开关安全与抖振/疲劳界）** 迟滞 + 驻留 + `Abort` 合同下：(a) 切换不破坏 `Inv`（切换前成立 → `Abort` 回到 `Inv_abort⊇Inv` → 后继 `Pre` 成立后由引理 19 保持；半开事务禁止）；(b) 同守卫两次切换间隔 `≥max(τ_dwell,h/|ḋ|)`，窗口内切换数 `≤T/τ_dwell+TV(d)/h`；(c) `F≤F_max` 由 `BudgetGate` 强制，超预算即冻结并降级；(d) 安全切换点输出在认证包络内，跳变 `≤ε_sw`，R68/R69 无突变不变式保持。∎

**引理 22（HIA 影子价格最优性）** 凹 VoI + 线性成本 + 全局预算 `Σc≤B` 的 KKT 给出 `∇VoI_j=μ∇c_j`；每个子树按同一 `μ` 最大化 `VoI_j−μc_j`；对偶上升在标准条件下收敛到 `μ*`。故局部贪心 + 全局价格 = 集中式分配，资源代数保证不双花。∎

**命题 1（SHM 正交性，条件性）** 在 A103（失败路由对成功率单调）、A104（上下文条件化 + CPT 后重基线）、A105（退化未被其他子树完全补偿）下，技能退化使 `r_str` 期望增加 `≥c·Δp−ε`，而 `r_res` 可被标定吸收、`Δa` 可被策略自适应压小。故 `r_str` 是与 `(r_res,Δa)` 正交的第三通道；E309/E310 检验功效与误报。∎

## 7. 本轮最大风险

**次级风险与缓解**：合同假设不完备（保守合同 + 运行时监控 + E304 红队）；抖振/抢占副作用/半开事务（定义 321 + 定理 19）；并发交互双花（资源代数 + 原子令牌 + 影子价格）；SHM 误报与谱模仿（上下文条件化 + 重基线 + 反事实重放 + `ℰ_profile`）；优化器过拟合（CVaR/分布鲁棒 + 留出场景 + E312）；在线拓扑变更不稳定（拓扑离线、在线只 `Retune/AddGuard` 并重签）；树投毒/篡改（树哈希 + CPT 日志 + VQAuditor-S）。

**一句话**：结构优化的优化器会主动寻找安全证书的每一处缝隙——只要叶合同、组合规则或 KS 场景覆盖有一处不完备，它就会把「被优化掉的冗余」变成「被优化掉的安全路径」；**被优化掉的不是冗余，而是你以为证书已经保护的那条命**。
