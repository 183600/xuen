# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 1 轮；本轮灵感：「课程学习」×「步骤分」）

> 第 57 轮把安全的赌注从"模型置信"换到"证据质量"，再用元少样本摊销、跨模态对账、个性化有界信任把证据质量本身做成可校准、可对账、可问责的对象。但它仍默认三件事：**(a) 承诺是二元的**——要么整段接触被证据门认证并执行，要么拒绝/绕行/协商；"一个任务已能安全走完 80% 的步骤"在系统里没有表示，也不产生任何可用的进展；**(b) 经验是顺序无关的**——探针按地图顺序铺开，元先验吃到什么历史就摊销什么历史，系统从不主动组织"先用可逆、可观测、易校准的步骤把自信建起来，再去碰不可逆、不可观测、难的步骤"；**(c) 权限只由人给**——第 57 轮的 PTM 建模了人对系统的授权，却没有建模"系统自己决定去解锁更难区域/更高步态/更深接触级"这件事，而一旦引入步骤分，系统就会攒出一堆自报的分数，这些分数天然会被用来给自己升权。本轮两个灵感正拆这三个默认：**课程学习**说"经验的组织顺序本身就是安全变量"，**步骤分**说"承诺可以分步兑现，进展可以分账计量"。但两者各带一个陷阱：课程是选择偏差，会把校准做得最差的地方恰好放在最难的尾部；步骤分是代理指标，会诱使系统用可见步骤的高分去洗白不可逆步骤的低分。于是核心命题由"少样本可校准、跨模态可对账、个性化有界的证据承诺"升级为 **"顺序可审计、步骤可分账、分数不可越权的证据承诺"**：课程给效率但不改证据门，步骤分给进展但不越过安全下界，信用可回溯但不能自我升权。

核心矛盾：
- **H32（课程 vs 校准）**：由易到难能显著提升样本效率，但"易"由元模型的难度估计定义；若"看起来易"恰是语料外的新世界，课程会在最不该自信处系统性少探针。更糟的是这种错误跨区域相关：它不是单点坏证据，而是一整层被跳过的世界，事后证伪也很难把它从课程顺序中反推出来。
- **H33（步骤分 vs 安全）**：步骤分奖励的是"可见的进展"，而事故往往发生在不可观测、不可逆的那一步。平均分会把四个漂亮的易步骤和一个致命难步骤混成一个"看起来不错"的总分；分数还可以被"洗白"——把可逆步骤攒下的信用当作不可逆步骤的安全论据，或直接自报高分。
- **H34（课程解锁 vs 自我授权）**：用积累的步骤分去解锁更难的课程/更高的自主权，会形成自证循环：易步骤高分 ⇒ 系统给自己升权 ⇒ 更早进入难步骤。若没有外部裁决锚与有界速率，"学习得越好越敢赌"就是第 57 轮授权养成攻击在系统内部的镜像。

## 0. 直觉与动机

**灵感 1（课程学习 → 风险-难度课程与"步骤阶梯"）**
直觉：课程学习最容易被误读成"先做简单的"。对安全系统而言，真正要排序的不是"题目难度"，而是**"这步失败后能不能撤销、看不看得见、学到的知识能不能迁移"**。于是把每个区域/任务按三轴分层：可逆性（可逆/高代价可逆/不可逆）、可观测性（可观测/隐变量）、与元语料的相似度。课程只做两件事：**选下一个探针/练习条目**与**切分探针预算**；它绝不修改"多少证据算够"。每一层都要在留出的"突击考"上通过分层校准，才允许升层；并强制保留尾部配额，防止课程把困难世界整层跳过。课程给的是速度，不是许可证。

**灵感 2（步骤分 → 步骤分承诺与认证前沿）**
直觉：把一次不可逆承诺拆成有序的步骤 σ_1,…,σ_n，每步有自己的局部证据门与一个**步骤分** s_k∈[0,1]（由事实验证的、带悲观下界的部分得分）。系统可以"走到它被认证到的最远处"：认证前沿 F(τ)=最大的 j，使得前 j 步全部过门且信用未被撤销。这样"80% 可认证"就有了意义——不是全体承诺，也不是全体放弃，而是**分步兑现到 F**。但步骤顺序本身也要过课程：在步骤偏序允许的线性化里，优先把可逆、可观测的步骤放前面，用它们建立校准与操作经验；不可逆步骤永远最后，且不被前面的高分"担保"。

**灵感 3（步骤分 → 安全下界与信用防火墙：平均分会撒谎）**
直觉：把五个步骤的分数取平均，是对"总体进展"的好估计，却是对"最坏一步"的坏估计。安全承诺只该看最坏的关键步骤：**S_safe = min{ s_k : 该步不可逆或不可观测 }**，并规定 S_prog（进度分）永远不能补偿 S_safe（信用防火墙）。更一般地，只有被事实验证过的分数才算数；未仪器化的隐步骤要么被独立锚定，要么其分数按 0 计。目标从"最大化平均步骤分"改为**"在安全下界约束下最大化期望步骤分"**——这正好是竞赛步骤分指标的安全版本，也避免 Goodhart：指标不能再被当作目标本身去刷。

**灵感 4（课程学习 × 步骤分 → 分数回溯账本：信用会过期、会传染）**
直觉：步骤分是一种"信用货币"。若一条证据被事后证伪（某模态被冰面骗过、某区域标注被推翻、某个云端版本有缺陷），所有依赖它的步骤分都必须被**传递性召回**，依赖这些分数的解锁与授权也要被撤销。于是建一张信用依赖 DAG，证伪事件沿依赖闭包回滚；版本更新或长期未复核的信用按陈旧度衰减。第 57 轮的"坏证据有地址"在这里升级为"**坏分数可召回**"：地图给证据地址，账本给分数谱系。

**灵感 5（步骤分 → 自我授权锚：分数不能给自己升权）**
直觉：系统攒的步骤分只能回答"我练得怎么样"，不能回答"我是否有资格碰更危险的东西"。因此把"系统自主权" a 从"操作者授权"里独立出来：自我解锁更难课程/更高步态/更深接触级，必须满足**外部裁决锚**（世界结果、独立传感器、人类裁决中至少 κ 类）计数 n_ext≥N_ext(a)、一段无回滚的干净窗口、以及有界升级速率；自报步骤分无论多高都不能升级，任何证伪都实时降级。人可以让系统更快相信自己（PTM），系统永远不能让自己更敢赌（SAA）。

**灵感 6（合流 → 探-诺-演++：课程选顺序、步骤分定前沿、账本保诚实）**
直觉：每个检查点上，先做第 57 轮的元推断与跨模态对账；再把任务拆成步骤、挂上局部证据门；然后由课程在"最近发展区 + 尾部配额"里选下一个探针/练习；沿认证前沿逐步承诺，遇到不可逆步骤就触发安全下界与外部锚；一旦证伪，账本回滚并把前沿退回。若前沿无法推进，则退回"练先修技能"的课程动作，或绕行、L2 协商、安全停。三个机制都只经两条安全通道起作用：**让信念更准（含加宽）**或**让动作更保守**。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（风险-难度课程 CLC）** 条目集合 𝒯（区域/任务/技能），条目 r 带难度区间 [d_lo(r),d_hi(r)]、危险度 h(r)（不可逆或隐步骤的潜在损失）、已认证掌握度 m(r)。先修偏序 r'≺r 表示 r 依赖 r' 的掌握。课程是三元组 𝒞=(π_𝒞,{B_l},{Prom_l})：π_𝒞 为条目选择分布，支撑于最近发展区 Z_κ={r: d_lo(r)≤m̄+κ ∧ unlocked(r)}，且满足**尾部配额** π_𝒞(Tail_ε)≥ε_tail（Tail_ε 为难度/危险度最高分位的条目集）；{B_l} 为分层预算且 ΣB_l≤B。**门不变性**：对任意证据集 E，Gate_𝒞(E)=Gate_base(E)——课程只改顺序与预算，不放宽证据要求。**升层门** Prom_l 需同时满足：该层分层校准 ECE_l≤ε_l、覆盖 cov_l≥1−α_l、留出突击考通过。选择规则 r*=argmax_r E[ΔS_prog|r]/(cost(r)(1+λ_h h(r)))，s.t. P(fail)≤δ_cur；估计一律取悲观值。

**定义 140（步骤分承诺 SGC）** 任务 τ 经分解得到步骤偏序 (Σ,Π)，Σ={σ_1,…,σ_n}，每步带可逆类 rev(σ_k)∈{R0 可逆,R1 高代价可逆,R2 不可逆}、可观测类 obs(σ_k)∈{O 仪器化,L 隐变量}、局部证据门 G_k（沿用第 57 轮五类证据，作用域限定到该步）。步骤分 s_k=LCB_α[credit_k|E_k]∈[0,1]，只由**事实验证**的事件计算。**认证前沿** F(τ)=max{j : ∀k≤j, G_k 过 ∧ credit_k 未被撤销}。承诺规则：可执行到 F(τ)；由 j−1 推进到 j 需 G_j 过；若 rev(σ_j)=R2，还须 PCO 安全下界与 SAA 外部锚。obs(σ_j)=L 且未仪器化的步骤不得仅凭 EV-probe 认证，必须补充独立锚或显式人类核验。步骤线性化须尊重 Π，且在可交换步骤中优先 R0/O 在前、R2/L 在后。

**定义 141（分数回溯账本 CRL）** 信用依赖图 G_credit=(V,E)，V 含证据、步骤分、解锁、授权节点；有向边 u→v 表示 v 的有效性依赖 u。**禁止边**：任何从 rev≤R1 的步骤信用指向 rev=R2 步骤安全论据的边都禁止（信用不得越过不可逆前沿被洗白）。证伪事件 f（裁决否定、不可逆坏结果、别名/矛盾检出、版本冲突）触发回滚闭包 R(f)={v : f∈Desc(v)}；对 v∈R(f) 置 s_v←下界，重算 m(r)，并撤销以失效信用为支撑的解锁与授权。回滚须**传递、幂等、可审计**，且在一个版本周期内完成。信用随 age 与版本号按陈旧度衰减，陈旧信用不得支撑不可逆步骤。

**定义 142（安全步骤分目标 PCO）** 记 S_safe(τ)=min{ s_k : rev(σ_k)=R2 ∨ obs(σ_k)=L }（未认证者计 0），S_prog(τ)=((1/n)Σ_k s_k)·ρ_cov，其中 ρ_cov=|{危险相关步骤中已仪器化或已锚定者}|/|{危险相关步骤}|。承诺与自主权的判定用**字典序** (S_safe,S_prog)：先满足 S_safe≥θ_safe，才允许讨论 S_prog；S_prog 永远不能补偿 S_safe（**信用防火墙**）。优化目标为 max_π E[Σ_k s_k] s.t. S_safe≥θ_safe ∧ P(不可逆伤害)≤δ。防刷分：只接受事实验证的分数；自报/膨胀分数直接拒绝；分数与独立观测结果做一致性检查，异常进入审计。

**定义 143（自我授权锚 SAA）** 系统自主权 a∈{a0,a1,a2}，决定它可自行解锁的课程层、步态上限与接触级。升级 a↑ 需同时满足：(i) 外部裁决计数 n_ext≥N_ext(a)；(ii) 锚来源多样性 ≥κ（世界结果/独立传感器/人类裁决）；(iii) 回滚干净窗口 ≥T_clean；(iv) 升级速率 ≤Δ_a/T。**自报步骤分不构成升级理由**。任一次证伪或回滚实时降级；会话域衰减；全局硬界与决策规则本体不因 SAA 放宽。SAA 管"系统给自己的权限"，PTM 管"人给系统的权限"，二者独立且都单向有界。

**定义 144（探-诺-演++ / 课程-步骤算子 CSC）** 每检查点：①元推断与跨模态对账（第 57 轮）；②步骤分解并挂局部证据门；③课程 CLC 在 Z_κ 内按悲观 VOI×尾部配额选下一个探针/练习；④沿认证前沿逐步推进，遇 R2 步骤执行 PCO 防火墙与 SAA 外部锚；⑤任何证伪 ⇒ CRL 回滚并以缩减后的前沿重规划；⑥受阻 ⇒ 课程回退（先练先修技能）→ 绕行 → L2 协商（τ_int(auth)）或安全停。证书 J_r=(J_p,cur_log,strata_cal,tail_audit,step_dag,score_log,firewall_log,rollback_log,anchor_log,autonomy_log)，继承 J_p 全检。每检查点探针预算 ≤k_p+k_c+k_cur；每步要么推进前沿、要么终止，故有限步终止。

## 2. 关键算法伪代码（简版，完整版见产物区）

```python
def certify_frontier(tau, M, inf, persona, ood_reg):     # IP-140/142
    F = 0; scores = {}
    for k, step in enumerate(order_steps(tau), 1):        # 尊重偏序，R0/O 优先
        if not step_gate_ok(step, M, inf, persona, ood_reg): break
        s = step_score_lcb(step, M)                       # 只取事实验证的事件
        if step.rev == 'R2':
            if s < theta_safe: break                      # 信用防火墙：进度分不能补偿
            if not saa_anchor_ok(step, M): break          # 外部裁决锚
        if step.obs == 'L' and not step.instrumented: break# 隐步骤须锚定
        scores[k] = s; F = k
    return F, scores

def curriculum_step(M, tau, meta, budget):                # IP-139
    z = nearest_development_items(M, tau, kappa)          # 最近发展区
    tail = top_quantile(M, 'difficulty', eps_tail)        # 尾部配额
    cands = z | sample_tail(tail, eps_tail)
    r = max(cands, key=lambda x: pessimistic_gain(x, M) / (cost(x)*(1+lam_h*hazard(x))))
    return r

def credit_rollback(ledger, f):                           # IP-141
    closure = ledger.descendants(f)                       # 传递闭包
    for v in closure: ledger.invalidate(v)                # s_v ← 下界
    ledger.revoke_unlocks(support=closure)                # 撤解锁/授权
    ledger.recompute_mastery(); ledger.audit(f, closure)
    return ledger

def self_authority_update(a, verdicts, rollback_log):     # IP-143
    if rollback_log.any_recent(): return demote(a)        # 证伪实时降级
    if n_ext(verdicts) >= N_ext(a) and anchor_diversity(verdicts) >= kappa \
       and clean_window(rollback_log) >= T_clean and rate_ok(a):
        return promote(a)                                 # 自报分数永不参与
    return a
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| CLC | O(\|𝒯\|·(d_φ+C_VOI)) 每次选择 | O(\|𝒯\|) | 门不变性、尾部配额、分层校准 |
| SGC | O(n·C_gate) 每任务 | O(n) | 隐步骤须锚定、前沿单调、线性化守序 |
| PCO | O(n) | O(n) | 字典序防火墙、只收事实验证分 |
| CRL | O(\|V\|+\|E\|) 每次回滚 | O(\|V\|+\|E\|) | 闭包完整、幂等、一版本周内 |
| SAA | O(1)+O(H_ext) | O(\|操作者\|+\|锚\|) | 自报不升权、有界速率、实时降级 |
| CSC | O(\|CP\|·(k_p+k_c+k_cur)·(C_VOI+d_φ)) | O(\|V\|+\|σ\|) | 悲观 VOI、三预算终止、四态完备 |

**正确性定理（CSCS 概要）**：在 A33–A40 上加 (A41) 课程只排序/切预算、门不变、尾部覆盖且分层校准诚实；(A42) 步骤分解与可观测性标注诚实、步骤分为事实验证的悲观下界、信用防火墙按字典序、禁止边不存在；(A43) 回滚依赖图完整、闭包传递幂等且在一版本周内完成、陈旧衰减诚实；(A44) 自我授权只由外部裁决锚与有界速率驱动、自报分不升权、证伪实时降级。则：(i) **分步健全性**：对任一已承诺前沿，P(不可逆失效)≤δ_f+Σ_{k≤F}ε_step(k)+δ_probe+δ_ood·α_conf，**该界不含任何 S_prog 项**（防火墙）；未锚定隐步骤另计 δ_latent。(ii) **课程不增险**：给定同一证据集，任何课程序的安全判定与基序相同，课程只影响成本与顺序；若尾部覆盖失守，自动退回第 57 轮共形保底带与保守前沿。(iii) **回滚健全性**：证伪后一个版本周内残留陈旧信用 ≤ε_rollback，无解锁/授权在失效支撑上存活。(iv) **非自升权**：系统自报步骤分不能提高 a，只有外部裁决可在有界速率内升级，任何证伪立即降级。(v) CSC 在 k_p+k_c+k_cur 内终止。

```python
def curriculum_select(M, tau, meta, budget):
    m_bar = M.mastery_level(tau)
    zpd = [r for r in M.items if r.unlocked(M)
           and M.d_lo(r) <= m_bar + KAPPA]                 # 最近发展区
    tail = M.top_quantile(items=M.items, key=difficulty, q=1-EPS_TAIL)
    cands = set(zpd)
    if rng.random() < EPS_TAIL:                            # 强制尾部配额
        cands |= set(tail)
    def gain(r):
        return pessimistic_delta_prog(r, M, meta) / (cost(r) * (1 + LAM_H * hazard(r)))
    r = max(cands, key=gain)
    budget.split_by_layer(r.layer);                        # 预算随层重新切分，总量不变
    return r

def promote_layer(meta, audit):
    l = meta.current_layer
    ok = (meta.ece[l] <= EPS_L[l]) and (meta.coverage[l] >= 1 - ALPHA_L) \
         and audit.pass_layer(l)                            # 留出突击考
    if not ok:
        meta = demote_layer(meta)                          # 只保守化
        meta.fallback_to_conformal = True                  # 回退第 57 轮保底带
```

### IP-140 SGC（步骤分承诺与认证前沿）

```python
def linearize_steps(tau):
    # 尊重偏序 Π；可交换步骤中 R0/O 优先，R2/L 靠后
    return topo_sort(tau.Sigma, tau.Pi,
                     key=lambda s: (s.rev_rank, s.obs_rank))

def certify_frontier(tau, M, inf, persona, ood_reg, saa):
    F, scores, step_log = 0, {}, []
    for k, step in enumerate(linearize_steps(tau), start=1):
        if not step_gate_ok(step, M, inf, persona, ood_reg):   # 局部证据门
            break
        if step.obs == 'L' and not step.instrumented and not step.anchored:
            break                                              # 隐步骤必须锚定
        s = step_score_lcb(step, M)                            # 只取事实验证事件
        if step.rev == 'R2':
            if s < THETA_SAFE:                                 # 防火墙：进度分不补偿
                break
            if not saa.anchor_ok(step, M):                     # 外部裁决锚
                break
        scores[k] = s; F = k; step_log.append((step, s))
    return F, scores, step_log

    # 只承诺到认证前沿；前沿之后一律不执行
```

### IP-141 CRL（分数回溯账本）

```python
def credit_add(ledger, node, parents, kind):
    ledger.add_node(node, kind)                            # evidence/credit/unlock/auth
    for p in parents:
        if not ledger.forbidden(p, node):                  # 禁止跨不可逆前沿
            ledger.add_edge(p, node)
        else:
            ledger.audit.flag('forbidden_credit_edge', p, node)

def credit_rollback(ledger, f):
    closure = ledger.descendants(f)                        # 传递闭包 R(f)
    for v in closure:
        if ledger.kind(v) == 'credit':
            ledger.set_score(v, 0.0)                       # 置下界
    ledger.revoke_unlocks(support=closure)                 # 撤解锁
    ledger.revoke_authz(support=closure)                   # 撤由该信用支撑的授权
    ledger.recompute_mastery()
    ledger.audit.log('rollback', f, sorted(closure))
    return ledger

def stale_decay(ledger, now):
    for v in ledger.credits():
        age = now - v.t; ver_gap = ledger.ver - v.ver
        v.w = v.w * (GAMMA_AGE ** age) * (GAMMA_VER ** ver_gap)
        if v.w < W_STALE_MIN:
            v.valid_for_irreversible = False               # 陈旧信用不支撑不可逆步
```

### IP-142 PCO（安全步骤分目标与信用防火墙）

```python
def score_pairs(scores, steps):
    hazard_keys = [k for k, s in steps.items()
                   if s.rev == 'R2' or s.obs == 'L']
    S_safe = min((scores.get(k, 0.0) for k in hazard_keys), default=0.0)
    n = len(steps)
    rho_cov = coverage(steps, instrumented_or_anchored=True)
    S_prog = (sum(scores.values()) / n) * rho_cov          # 覆盖惩罚
    return S_safe, S_prog

def pcc_gate(scores, steps):
    S_safe, S_prog = score_pairs(scores, steps)
    if S_safe < THETA_SAFE:
        return ('reject', 'safety_floor', S_safe, S_prog)   # 字典序：先安全
    return ('ok', 'progress', S_safe, S_prog)

def score_from_verdict(event):
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CLC | O(\|𝒯\|·(d_φ+C_VOI)) 每次选择 | O(\|𝒯\|) | 门不变性、尾部配额、分层校准（A41） |
| SGC | O(n·C_gate) 每任务 | O(n) | 隐步骤须锚定、前沿单调、线性化守序（A42） |
| CRL | O(\|V\|+\|E\|) 每次回滚 | O(\|V\|+\|E\|) | 闭包完整、幂等、一版本周（A43） |
| PCO | O(n) | O(n) | 字典序防火墙、只收事实验证分（A42） |
| SAA | O(1)+O(H_ext) | O(\|操作者\|+\|锚\|) | 自报不升权、有界速率、实时降级（A44） |
| CSC | O(\|CP\|·(k_p+k_c+k_cur)·(C_VOI+d_φ)) | O(\|V\|+\|σ\|) | 悲观 VOI、三预算终止、四态完备 |

**正确性定理（Curriculum-Step Commitment Soundness, CSCS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 课程只排序与切预算、门不变（Gate_𝒞≡Gate_base）、尾部覆盖 π_𝒞(Tail_ε)≥ε_tail、分层校准 ECE_l≤ε_l 且重要性权重 ≤W_max；**(A42)** 步骤分解与 rev/obs 标注诚实、步骤分是事实验证事件的悲观下界、信用防火墙按字典序执行、禁止跨不可逆前沿的信用边不存在；**(A43)** 回滚依赖图完整、闭包传递且幂等、一版本周内完成、陈旧衰减诚实；**(A44)** 自我授权仅由外部裁决锚与有界速率驱动、自报步骤分不升权、任何证伪实时降级。则：

1. **分步健全性**：对任一已承诺前沿 F，
```
P(不可逆失效) ≤ δ_f + Σ_{k≤F} ε_step(k) + δ_probe + δ_ood·α_conf + δ_latent·1[未锚定隐步骤]
```
该界**不含任何 S_prog 项**——进度分不能补偿安全下界（信用防火墙）。
2. **课程不增险**：对任意证据集 E 与任意课程序，Gate_𝒞(E)=Gate_base(E)；课程只改变达到同一证据集的成本/顺序。若尾部覆盖失守，CLC 自动降层、回退第 57 轮共形保底带并提高 θ_voi。
3. **回滚健全性**：证伪 f 后一个版本周内，残留陈旧信用 ≤ε_rollback；不存在由失效信用支撑的解锁或授权存活。
4. **非自升权（单调性）**：系统自主权 a 的升级只依赖外部裁决锚计数、锚多样性、干净窗口与有界速率，自报步骤分无论多高都不进入升级函数；证伪使 a 立即降级。故"练得好"不能直接变成"更敢赌"。
5. **终止性**：每检查点探针/练习 ≤k_p+k_c+k_cur；每个步骤要么推进 F、要么终止，故 CSC 终止于 {分步承诺, 绕行, L2 协商, 安全停}。

**部署界**（对检查点取联合界）：
```
P_safe ≥ 1 − Σ_cp ( δ_f + Σ_k ε_step(k) + δ_probe + δ_ood·α_conf
                   + δ_cur + δ_latent·1[未锚定隐步骤] )
             − P(回滚不完整) − P(防火墙配置错误) − P(SAA 锚失效)
```

### 推导：平均分会撒谎，所以需要字典序防火墙

考虑一个 5 步任务，步骤分为 s=(0.95,0.95,0.95,0.95,0.20)，其中第 5 步是隐变量且不可逆。

- **平均聚合**：`S̄ = (4×0.95 + 0.20)/5 = 0.80`。若承诺阈值取 0.70，平均分说"可以承诺"，于是系统执行第 5 步；但第 5 步的真实可分约 0.20，期望失效约 0.80。
- **覆盖惩罚**：若危险相关步骤中只有第 5 步未仪器化，ρ_cov=0（或按定义把该步计 0），`S_prog` 进一步被拉低，但仍是"一个数"，仍可被其他高分抵消。
- **字典序防火墙**：`S_safe = min{s_k : rev=R2 ∨ obs=L} = 0.20 < θ_safe=0.90`，直接拒绝推进，无论 `S_prog` 多高。故
```
Commit(σ_5) = 1[F≥4] · 1[s_5 ≥ θ_safe] · 1[anchors_5 ≥ N_ext] · (S_prog 不出现在表达式里)
```
- **洗白攻击**：若系统用前 4 步的信用为第 5 步作保，等价于在 G_credit 中加入一条 R≤R1→R2 的禁止边；CRL 的 `forbidden(p,node)` 会在入账时拒绝该边并审计。于是"前面的成功"只能加快学习，不能替代第 5 步自己的证据。
- **结论**：安全判定必须是 `min`（最坏关键步）与外部锚的函数，而不是 `mean`（总体进展）的函数；竞赛步骤分只能作为**被安全下界约束**的目标，不能反过来定义安全。

## 6. 本轮最大风险

**一句话**：本轮最大的风险是**步骤分变成系统自己发行的货币**——课程用难度估计决定先在哪里攒分、账本用这些分解锁更难的课程与更高的自主权，而"看似易"的尾部盲区与"可见步骤高分掩盖隐步骤"的代理陷阱会让系统在总进展分最漂亮的时候，恰恰在不可逆的隐步骤上最脆弱；必须以课程只排序不改门、信用防火墙、回滚闭包与外部裁决锚四重护栏，宁可让系统"少走一步、慢一点解锁"，也绝不让分数反过来给系统授权。
