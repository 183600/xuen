# 第 1 轮 · 思维启发：CAL-LoRA-FALL —— 传感器标定残差引导的 LoRA 快速跌倒恢复

## 直觉锚点与动机链条

- **传感器标定偏差是跌倒恢复的隐形放大器**：人形/轮足机器人跌倒检测依赖 IMU、关节编码器、力矩传感器融合的 CoM、ZMP、角动量估计。标定漂移 b(t) 使状态观测 x̂ = x + J⁺b + v 产生系统性偏差，跌倒检测阈值 τ_fall 被提前触 发或延后触发，导致恢复动作过早介入或错过可恢复窗口。传统方案先标定后控制，无法在线耦合两者的不确定性。

- **跌倒恢复需要“快收敛 + 低风险”的策略切换**：跌倒过程时间窗口仅 200–500ms，要求控制策略在检测后 1–2 步内切换至恢复基元 roll/pitch/upright。完整重训练不可行，需求参数高效、低延迟的策略微调。

- **LoRA 恰好提供参数高效的在线微调接口**：低秩适配 ΔW = B A，秩 r ≪ min(d_in,d_out)，将策略网络 π_θ 的更新限制在低维子空间，既保留预训练的通用平衡能力，又能快速吸收当前身体动力学与地形特定残差。关键洞察：适配信号不应直接用原始传感器读数，而应由标定残差 e_cal = y - H x̂_cal 引导，确保 LoRA 只学习“标定已解释之外的真实动力学变化”，避免把标定误差当成环境变化学习。

- **三者耦合形成闭环**：标定模块提供偏差估计 b̂ 与不确定度 Σ_b → 跌倒检测器使用保守阈值 τ_fall(Σ_b)；检测触发后，过去 T_mem 窗内的标定残差序列 {e_cal} 与恢复标签构建小样本适配集 D_fall；LoRA 在线求解 r 秩更新，使恢复基元在标定残差空间内最小化轨迹跟踪误差，同时保持非跌倒域的性能不劣化。

## 形式化定义

### 符号
- 传感器输出 y_k ∈ ℝ^m = H x_k + b_k + v_k, v_k ∼ N(0,R)
- 标定状态 b_k ∈ ℝ^m，动态 b_{k+1}=b_k + w_b, w_b ∼ N(0,Q_b)
- 状态估计 x̂_k = f(x̂_{k-1}, u_{k-1}, y_k - b̂_k)
- 标定残差 e_k = y_k - H x̂_k - b̂_k
- 跌倒指示 f_k ∈ {0,1}，触发条件 f_k = 1 ⇔ ‖ω_k‖ > ω_th ∧ z_com < z_th ∧ Σ_b,k < Σ_max
- 策略 π_θ : s → a，参数 θ ∈ ℝ^p
- LoRA 适配 θ' = θ + [ΔW]，其中 ΔW = B A, B∈ℝ^{d_out×r}, A∈ℝ^{r×d_in}
- 适配目标 L_fall(θ') = 𝔼_{(s,a*)∈D_fall}[‖π_{θ'}(s)-a*‖²] + λ_reg ‖B A‖_F² + λ_cal tr(Σ_b)

### 假设
A1 感知可观测：(H,Q_b,R) 使卡尔曼滤波收敛
A2 跌倒可区分：存在间隔 δ>0 使 P(f_k=1|fall) ≥ 1-ε_f, P(f_k=1|no fall) ≤ ε_f
A3 LoRA 子空间包含恢复方向：存在 rank r 解使 L_fall 梯度投影误差 ≤ ε_LoRA

## 算法步骤概览

离线：预训练平衡策略 π_θ0 于仿真域；初始化标定滤波器 P_b0；构建 LoRA 骨架 B0=0,A0=0。

在线每步 k：
1. 标定更新：b̂_k|k = b̂_k|k-1 + K_k e_k，P_b,k|k = (I-K_k H) P_b,k|k-1
2. 状态估计与跌倒检测：x̂_k 计算，f_k 判定；若 f_k=0 则正常 rollout
3. 记忆收集：若 f_k=1 启动 T_mem 缓冲，记录 {s_t,a*_t,e_t}
4. LoRA 微调：当 |D_fall|≥N_min 且 Σ_b,k < Σ_thr 时，解
   min_{B,A} L_fall(θ+B A) 用 1-step SGD + 梯度裁剪
5. 恢复执行：π_{θ'} 输出动作，强制力矩饱和与关节限位保护
6. 安全回退：若适配后验证误差增幅 >Δ_max 或 Σ_b 超界，丢弃 ΔW，回退 π_θ0 并进入保守站立模式

## 复杂度分析

- 标定滤波：O(m³) 初始化，后续 O(m²) 每步，m≤12 可忽略
- 跌倒检测：O(1)
- LoRA 前向：额外 O(r(d_in+d_out))，r=4~8 时 <0.05ms @ 1kHz
- LoRA 反向：一轮微调约 O(|D_fall| r d )，|D_fall|≈128，耗时 <5ms，可在带外完成
- 内存：B A 两矩阵 ≈ 2 r d 参数，< 50KB

## 正确性论证要点

- 命题 1 标定收敛：依 A1，E‖b_k - b̂_k‖² ≤ tr(P_b,k) →0
- 命题 2 保守跌倒触发：阈值 τ_fall(Σ_b) 单调增 Σ_b，使误报概率 ≤ ε_f
- 命题 3 LoRA 不劣化：若适配集 D_fall 与原域分开，则正则项保证外域损失增幅 ≤ λ_reg ‖ΔW‖_F²
- 命题 4 端到端恢复可行：标定误差有界 + LoRA 适配误差 ε_LoRA ⇒ 恢复动作与最优动作距离 ≤ C1 tr(Σ_b)+C2 ε_LoRA

## 已知风险

- 标定-适配耦合正反馈：标定未收敛时残差 e_k 含系统偏差，LoRA 可能学习错误模式
- 小样本过拟合：跌倒样本稀少，r 过大导致记忆而非泛化
- 实时性：带外微调与在线推理的同步可能出现延迟抖动
- 硬件差异：真实机器人传感器噪声非高斯，卡尔曼假设失效

## 本轮最大风险一句话

标定未收敛时的残差被 LoRA 错误拟合为动力学特征，形成“标定误差→错误适配→更差恢复”的正反馈闭环，导致跌倒恢复策略在真机上系统性恶化，必须以 Σ_b 上界与适配冻结门实现严格解耦。

# 第 1 轮产物 · CAL-LoRA-FALL 完整算法设计

## 0. 结论
本轮以传感器标定、跌倒恢复、LoRA 三个灵感词融合，提出 CAL-LoRA-FALL：标定残差引导的低秩策略适配跌倒恢复算法。核心创新在于将标定不确定度显式纳入跌倒触发与 LoRA 适配门控，实现“标定诚实 → 检测保守 → 适配可控”。在线推理仅增加 r 秩矩阵乘法，离线预训练不变，满足 1kHz 控制带宽。

## 1. 符号定义

| 符号 | 含义 |
|---|---|
| y_k | 传感器向量 IMU+编码器+力矩 |
| H | 观测矩阵 |
| b_k | 标定偏差 |
| b̂_k,P_b,k | 标定估计与协方差 |
| e_k | 标定残差 |
| x̂_k | 状态估计 |
| f_k | 跌倒指示 |
| π_θ | 基策略 |
| B,A | LoRA 低秩因子 |
| D_fall | 跌倒适配集 |
| Σ_b | 标定不确定度上界 |

## 2. 算法步骤

### 2.1 离线
```
预训练 π_θ0 于仿真域
初始化卡尔曼滤波器 (b̂0,P_b0)
初始化 LoRA 因子 B0=0, A0=0
设置超参 r, λ_reg, λ_cal, N_min, Σ_thr, Δ_max
```

### 2.2 在线
```python
def step(k, y_k, u_{k-1}):
    # 1. 标定更新
    e_k = y_k - H x̂_{k|k-1} - b̂_{k|k-1}
    K_k = P_b Hᵀ (H P_b Hᵀ + R)^{-1}
    b̂_k = b̂_{k|k-1} + K_k e_k
    P_b = (I - K_k H) P_b

    # 2. 状态估计与跌倒检测
    x̂_k = f(x̂_{k-1}, u_{k-1}, y_k - b̂_k)
    Σ_b = tr(P_b)
    f_k = (||ω_k||>ω_th and z_com<z_th and Σ_b<Σ_max)

    # 3. 记忆收集
    if f_k:
        buffer.append((s_k, a*_k, e_k))
        active = True

    # 4. LoRA 微调
    if active and len(buffer)>=N_min and Σ_b<Σ_thr:
        D = buffer[-N_min:]
        loss = mean(||π_{θ+BA}(s)-a*||²) + λ_reg||BA||_F² + λ_cal Σ_b
        B,A = sgd_step(B,A,∇loss)
        # 验证
        if val_error_increase > Δ_max:
            B,A = 0,0  # 回滚

    # 5. 动作输出
    a_k = π_{θ+BA}(s_k)
    a_k = clip(a_k, torque_limit)
    return a_k, b̂_k, f_k
```

## 3. 复杂度分析
- 标定：O(m²)=144 FLOPs/步
- LoRA 前向：O(r d)=~4*512=2k FLOPs
- LoRA 反向：每跌倒事件约 5ms 带外
- 内存：< 100KB

## 4. 正确性论证
命题 1：若 A1 成立，则 lim sup E‖b_k-b̂_k‖² ≤ tr(Q_b)
证明：标准卡尔曼不动点。

命题 2：保守触发
P(false alarm) ≤ ε_f 因阈值含 Σ_b 调整。

命题 3：LoRA 不劣化
E_{s∼D0}[L(π_{θ+BA})] ≤ E[L(π_θ)] + λ_reg‖BA‖_F²

命题 4：恢复误差界
‖a_opt - a_lo​ra‖ ≤ Lπ (C1√tr(P_b)+C2 ε_LoRA)

## 5. 已知风险
- 正反馈闭环：标定未收敛时 LoRA 学习误差模式
- 小样本过拟合：跌倒样本稀少
- 延迟抖动：带外微调与在线推理同步
- 非高斯噪声：卡尔曼假设失效

缓解：Σ_b 上界冻结门、r≤8、梯度裁剪、鲁棒滤波替代

## 6. 实验设计
E1 标定收敛：模拟漂移，验证 P_b 单调递减
E2 跌倒检测保守性：注入标定误差，误报率<1%
E3 LoRA 恢复成功率：在 3 种地形上对比无适配基线，成功率提升 ≥15%
E4 正反馈压力测试：故意延迟标定收敛，验证冻结门阻止适配

## 7. 最大风险总结
本轮最大风险是标定未收敛的残差被 LoRA 错误拟合为动力学特征，形成标定误差→错误适配→更差恢复的正反馈闭环，需以 Σ_b 上界与适配冻结门严格解耦。
