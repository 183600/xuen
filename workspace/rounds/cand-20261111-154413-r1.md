# 第 56 轮（承接第 55 轮 v32 GroundEdge-GenSim++++；灵感循环第 1 轮；本轮灵感：「虚拟仿真」×「通用机器人平台」）

> 第 55 轮把证书推进到“接触语义是否可信、全身是否可行”。本轮再退一层：**这些结论由虚拟仿真给出，而通用机器人平台宣称的“通用”是跨具身、跨任务、跨环境的**。核心矛盾：**H24**：虚拟仿真只能在“有效域”内充当证人，而有效域随具身/任务变化、不可由单一仿真器全局预知，于是“通用性”被仿真有效流形截断；**H25**：仿真会制造“伪通用”——策略过拟合仿真伪影，在 benchmark 上跨任务高分，跨仿真器或一到实机即崩；**H26**：多仿真器分歧可当风险信号，但仿真器共享物理近似、渲染资产与训练数据，独立性是假的，一致可能只是共同盲区。

## 0. 直觉与动机

**灵感 1（虚拟仿真 → 有管辖权的证人，而非真值）**
直觉：仿真器不是“现实的廉价复制”，而是一个只在某些区域有作证资格的证人。它给出的每一条证据都应附带一个“管辖范围”：在这之内误差有界，出了范围就没有发言权。把仿真输出当作无条件的 ground truth，等于让证人在自己没去过的辖区里作证。

**灵感 2（通用机器人平台 → 具身参数族上的均匀性，而非单机 SOTA）**
直觉：通用平台不是“一台更强的机器人”，而是同一个技能库在具身参数族 `Θ`（连杆长度、自由度、驱动器、传感器配置）上的可迁移性。真正的“通用”不是平均分高，而是**流形上的最差点也过线**：`inf_{θ∈Θ} ρ(θ) ≥ ρ_min`。平均分掩盖最差具身，正是通用性宣称最常见的偷换。

**灵感 3（多仿真器三角测量 → 测的是误差之差，不是误差本身）**
直觉：让多个仿真器投票听起来稳健，但若它们共享同一套接触模型或同一份资产，它们会一起错。分歧 `D` 只能约束“误差之间的差异”，约束不了“共同的偏差 `b`”。因此三角测量只能降低方差，不能替代真实锚点；独立性必须被估计并折价，而不是假设。

**灵感 4（伪通用性 → 必须被判别式实验证伪，而非由分数自证）**
直觉：一个策略可以在仿真里跨任务高分，却只是学会了仿真伪影。要区分“可迁移通用性”和“仿真特定通用性”，不能看得分，要看它对**伪影扰动**（接触参数、延迟、噪声、渲染）是否敏感：真通用的失效模式随扰动慢变，伪通用的失效模式在特定扰动上断崖。审计应主动选择最能区分两种假设的实验。

**灵感 5（证据汇率 → 仿真证据不能一比一兑换实机证据）**
直觉：仿真能便宜地产生海量回合，若按条数计入证据，就会发生“证据洗白”：一万次仿真覆盖不了仿真器本身的系统偏差。需要给仿真证据一个随保真度、独立度、血缘重叠度衰减的汇率，实机锚点按面值计，证书只认“实机等效能”。

**灵感 6（有效域可扩张 → 有限实机预算应花在扩张管辖上）**
直觉：有效域不是静态的。与其在已知有效域内重复刷分，不如把有限实机预算花在“最不确定、最能扩张 `V_M` 边界”的点上。这把真实数据从“考试”变成“领地扩张”，也解释了为什么通用平台的实机预算必须按覆盖增益分配，而不是按任务数量平均分配。

## 1. 形式化定义（增量：定义 127–132）

**定义 127（具身-任务-环境流形与通用性泛函）**
通用平台 `P=(Θ,𝒯,ℰ)`：具身参数 `θ∈Θ`、任务 `τ∈𝒯`、环境 `e∈ℰ`；技能/策略 `π_θ`。通用性泛函
`G(π;Θ,𝒯,ℰ) = inf_{θ∈Θ, τ∈𝒯, e∈ℰ} P_succ(π_θ, τ, e)`。
称 `π` 为 `(γ,δ)`-通用，若
`P_{θ,τ,e∼μ}[P_succ(π_θ,τ,e) < γ] ≤ δ`。
注意：`G` 是**最差点**泛函，不是平均分；平台可以平均很强而 `G` 很低。

**定义 128（仿真有效域 / 保真管辖）**
仿真器 `M` 的有效域
`V_M = {(θ,τ,e) | d(P_real(·|θ,τ,e), P_M(·|θ,τ,e)) ≤ ε_fid}`，
其中 `d` 为总变差或 Wasserstein 距离。`V_M` 不可先验全局已知，只能由真实锚点与共形/分位数回归估计为 `V̂_M`。有效域证书
`F_M = (V̂_M, ε_fid, δ_fid, anchors)`，
表示 `P(V_M ⊇ V̂_M) ≥ 1-δ_fid`。**在 `V̂_M` 之外，仿真不具作证资格。**

**定义 129（具身流形覆盖与均匀迁移）**
在 `Θ` 上取设计点 `Θ_s={θ_i}`、半径 `r_i`。覆盖度
`cov_Θ = μ(∪_i B(θ_i, r_i)) / μ(Θ)`。
若技能鲁棒性 `ρ(θ)` 在 `Θ` 上 `L_θ`-Lipschitz，则均匀下界
`ρ_Θ = min_i ρ(θ_i) - L_θ · max_i r_i`
是 `inf_{θ∈Θ} ρ(θ)` 的保守估计。仅当 `cov_Θ ≥ 1-ε_cov` 且 `ρ_Θ ≥ ρ_min` 时，技能才可称**具身均匀可迁移**。

**定义 130（仿真器共识与有效独立度）**
对同一 `x=(θ,τ,e)`，仿真器族 `{M_1,…,M_k}` 给出风险 `R_i`。分歧
`D = max_{i,j} |R_i - R_j|`。
令 `ρ_eff` 为误差相关系数（由共享引擎、物理近似、资产血缘估计）。三角测量保守上界
`R_tri = (1/k)Σ_i R_i + c_k(ρ_eff)·D + b_anchor + ε_fid`，
`c_k(ρ) = sqrt((1+(k-1)ρ)/(k(1-ρ+ε)))`。
关键：`ρ→1` 时 `c_k→∞`——高度相关的仿真器族提供不了独立性，分歧再小也不能当安全。`b_anchor` 是实机锚点给出的共享偏差共形上界，**不可由任何仿真器内部量替代**。

**定义 131（判别式通用性审计）**
设两假设：`H_gen`（失效模式对仿真伪影扰动不敏感、跨仿真器一致）；`H_spur`（失效由仿真伪影驱动）。审计实验 `a∈𝒜` 取自伪影扰动族（接触参数、控制延迟、传感噪声、渲染/材质）。选取
`a* = argmax_{a∈𝒜, cost(a)≤B} D_KL(P(r|a,H_gen) ‖ P(r|a,H_spur))`。
在 `a*` 上计算似然比 `Λ = P(r|a*,H_gen)/P(r|a*,H_spur)`，审计结论
`A = (a*, Λ, decision)`，`decision='genuine'` 当 `Λ ≥ τ_Λ`。该审计只回答“是否伪通用”，不替代有效域与覆盖检查。

**定义 132（证据汇率与通用性证书）**
证据条目 `e_i=(type, quantity, ε_fid, η, lineage)`。仿真证据汇率
`w_i = exp(-λ_1 ε_fid - λ_2(1-η) - λ_3·leakage_i) ∈ [0,1]`，
实机锚点 `w_i=1`；`leakage_i` 为与其他证据的仿真器血缘重叠度。实机等效证据
`E_eff = Σ_i w_i · quantity_i`。
通用性证书
`G_cert = (G_lower, V̂_M, cov_Θ, ρ_Θ, R_tri, η, A, E_eff, δ_G)`，
其中
`G_lower = G_sim|V̂_M - ε_fid - L_θ r_cov - c_k(η)D - b_anchor`。
可部署条件：
`target ⊆ V̂_M ∧ cov_Θ ≥ 1-ε_cov ∧ ρ_Θ ≥ ρ_min ∧ R_tri ≤ ρ_min ∧ A.decision='genuine' ∧ E_eff ≥ E_min`。
任一不满足即拒绝；**“出管辖”不是低置信，而是无证书。**

## 2. 关键算法 伪代码

### IP-127 VJD（Validity Jurisdiction Discovery，仿真有效域发现与扩张）

```python
def discover_validity(sim, real, Theta, Tau, E, anchor_budget, eps_fid, delta_fid):
    D = coverage_design(Theta, Tau, E)          # D-optimal / 覆盖设计
    pairs, uncertain = [], []
    for x in D:
        y_sim = sim.rollout(x)
        y_real = real.query(x) if anchor_budget.can(x) else None
        if y_real is not None:
            pairs.append((x, discrepancy(y_sim, y_real)))
    d_hat = conformal_quantile_regressor(pairs, level=1 - delta_fid)
    V_hat = {x for x in D if d_hat(x) <= eps_fid}
    # 边界带：d_hat 贴近 eps_fid 的点，下一笔实机预算优先花在这里
    uncertain = {x for x in D if eps_fid - margin <= d_hat(x) <= eps_fid + margin}
    return ValidityCert(V_hat, eps_fid, delta_fid, uncertain, d_hat)

def expand_validity(cert, real, sim, anchor_budget, eps_fid):
    for x in select_by_coverage_gain(cert.uncertain, anchor_budget):
        e = discrepancy(sim.rollout(x), real.query(x))
        cert.update(x, e)
    return cert.refit()
```

### IP-128 EMT（Embodiment Manifold Transfer，具身流形均匀迁移）

```python
def embodiment_uniform_cert(skill, Theta, theta_samples, L_theta, rho_min, eps_cov):
    vals, radii = [], []
    for theta in theta_samples:
        rho = robustness_spectrum(skill.instantiate(theta))
        vals.append((theta, rho))
        radii.append(sample_radius(theta, theta_samples))
    cover = measure(union_balls(theta_samples, radii)) / measure(Theta)
    rho_lower = min(r for _, r in vals) - L_theta * max(radii)
    refine = [theta for theta, r in vals
              if lipschitz_gap(theta, theta_samples, L_theta) > gap_tol]
    ok = (cover >= 1 - eps_cov) and (rho_lower >= rho_min)
    return EmbodimentCert(ok, cover, rho_lower, refine)

def active_embodiment_sample(skill, Theta, cert, budget):
    # 在 Lipschitz 上界最松的区域加点，收窄 rho_lower 的保守间隙
    return argmax_points(Theta, gap=lambda t: lipschitz_gap(t, cert.samples, cert.L),
                         n=budget)
```

### IP-129 SCT（Simulator Consensus Triangulation，仿真器共识三角测量）

```python
def triangulate(sim_family, x, real_anchors, eps_fid, rho_min):
    R = [M.risk(x) for M in sim_family]
    D = max(R) - min(R)
    rho_eff = estimate_error_correlation(sim_family, real_anchors)  # 血缘/引擎/物理近似
    c = sqrt((1 + (len(R)-1)*rho_eff) / (len(R)*(1 - rho_eff + 1e-9)))
    b = conformal_upper(shared_bias(sim_family, real_anchors), level=1-delta_b)
    R_tri = mean(R) + c*D + b + eps_fid
    return TriCert(R_tri, D, rho_eff, b, sound=(R_tri <= rho_min))
```

**关键推导（为什么分歧不能替代锚点）**
令仿真误差 `e_i = R_real - R_i`，则 `R_i - R_j = e_j - e_i`，故 `D` 只约束误差**差**。若所有 `M_i` 共享偏差 `b`（相同接触模型/渲染/数据），则 `e_i≈b`、`D≈0`，而 `R_real - mean(R_i)≈b` 完全不可见。三角测量的作用是把独立噪声项的方差从 `σ²` 降到 `σ²(1+(k-1)ρ)/k`，对共享偏差无任何信息增益；所以 `b_anchor` 必须由实机锚点给出。

### IP-130 GAD（Generality Audit by Discrimination，判别式通用性审计）

```python
def audit_generality(policy, sim_family, artifact_perturbations, budget):
    best, best_gain = None, -inf
    for a in artifact_perturbations:                 # 接触/延迟/噪声/渲染
        p_gen  = predict_failure(policy, a, hypothesis='genuine')
        p_spur = predict_failure(policy, a, hypothesis='spurious')
        gain = kl_divergence(p_gen, p_spur)
        if gain > best_gain and budget.can(a):
            best, best_gain = a, gain
    # 在最有判别力的扰动上做真实/跨仿真验证
    lr = likelihood_ratio(observe(policy, best), hyp='genuine', alt='spurious')
    decision = 'genuine' if lr >= tau_lambda else 'spurious'
    return AuditCert(best, best_gain, lr, decision)
```

### IP-131 EAB（Evidence Audit & exchange-rate Budget，证据审计与汇率）

```python
def evidence_audit(evidence, lambda_vec, lineage_graph):
    ledger = []
    for e in evidence:
        lineage = lineages_of(e, lineage_graph)       # 同引擎/同资产/同数据源
        leak = jaccard(lineage, union_lineages(ledger, lineage_graph))
        w = exp(-lambda_vec[0]*e.eps_fid
                - lambda_vec[1]*(1 - e.eta)
                - lambda_vec[2]*leak)
        ledger.append((e, clamp(w, 0.0, 1.0)))
    E_eff = sum(w * e.quantity for e, w in ledger)
    return EvidenceCert(ledger, E_eff, min_weight=min(w for _, w in ledger))

def refuse_laundering(cert, E_min, min_weight):
    # 条数很多但汇率极低 = 证据洗白，直接拒绝
    return cert.E_eff >= E_min and cert.min_weight >= min_weight
```

### IP-132 GCE（Generality Certificate，通用性证书）

```python
def generality_certificate(policy, target, sim_family, real, budgets):
    F = discover_validity(sim_family[0], real, budgets.Theta, budgets.Tau,
                          budgets.E, budgets.anchor, budgets.eps_fid, budgets.delta_fid)
    if not subset(target, F.V_hat):
        return ('reject', 'out_of_jurisdiction', F)
    E = embodiment_uniform_cert(policy, budgets.Theta, budgets.theta_samples,
                                budgets.L_theta, budgets.rho_min, budgets.eps_cov)
    if not E.ok:
        return ('reject', 'embodiment_coverage', E)
    T = triangulate(sim_family, target, real.anchors, budgets.eps_fid, budgets.rho_min)
    if not T.sound:
        return ('reject', 'triangulated_risk', T)
    A = audit_generality(policy, sim_family, budgets.perturbations, budgets.audit)
    if A.decision != 'genuine':
        return ('reject', 'spurious_generality', A)
    Ev = evidence_audit(budgets.evidence, budgets.lambdas, budgets.lineage)
    if not refuse_laundering(Ev, budgets.E_min, budgets.min_weight):
        return ('reject', 'evidence_laundering', Ev)
    G_lower = lower_bound(policy, F, E, T, budgets)
    return ('ok', GeneralityCert(G_lower, F.V_hat, E.cover, E.rho_lower,
                                 T.R_tri, T.rho_eff, A, Ev.E_eff))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| VJD | O(|D|·(T_sim+T_real)) | O(|D|) | 共形覆盖、校验交换性 |
| EMT | O(|Θ_s|·|A|·T) | O(|Θ_s|) | 覆盖完备、Lipschitz 常数可信 |
| SCT | O(k·|X| + |anchors|) | O(k+|X|) | η 估计、共享偏差有锚 |
| GAD | O(|𝒜|·B) | O(|𝒜|) | 扰动族含高判别项 |
| EAB | O(|E|·|lineage|) | O(|E|) | 血缘去重、汇率上界 |
| GCE | 各组件之和 | O(|D|+|E|) | 任一检查失败即拒绝 |

**正确性定理（General-Platform Generality Soundness）**
假设第 55 轮 (A29)–(A32) 成立；**(A33)** 在 `V̂_M` 上保真界成立，`P(V_M ⊇ V̂_M) ≥ 1-δ_fid`；**(A34)** `Θ` 覆盖完备且 `L_θ` 为真 Lipschitz 常数；**(A35)** `η` 的估计误差 ≤ `δ_η` 且 `R_tri` 为 `R_real` 的保守上界；**(A36)** 审计扰动族中存在 `D_KL ≥ β_audit` 的判别项；**(A37)** 证据汇率不高于真实证据的等效置信。
则对任意 `target ⊆ V̂_M`：
```
P( G_real ≥ G_lower ) ≥ 1 - (δ_fid + δ_cov + δ_η + δ_audit + δ_evid)
G_lower = G_sim|V̂_M - ε_fid - L_θ·r_cov - c_k(η)·D - b_anchor
```
关键：**通用性只在 `target ∩ V̂_M` 上有定义**；`c_k(η)` 显式惩罚仿真器相关性，`b_anchor` 强制真实锚点进入下界。任何“仿真器们都很一致所以很通用”的论证，若缺 `b_anchor`，在本定理下不成立。

## 4. 实验设计 E167–E172

| 实验 | 指标 | 目标 |
|---|---|---|
| E167 有效域估计 | `V̂_M` 的覆盖/误纳率、保真界紧致度 | 覆盖 ≥ 95%，误纳 ≤ 5% |
| E168 具身均匀迁移 | 留出具身上的预测-实测误差、最差具身成功率 | 最差具身 ≥ 0.85，误差 ≤ 8% |
| E169 三角测量校准 | `D` 与真实风险相关性、`η` 消融 | 相关性 ≥ 0.8；单引擎基线明显高估安全 |
| E170 伪通用检测 | 对伪影过拟合策略的检测 AUC/功效 | AUC ≥ 0.90，功效 ≥ 0.8 |
| E171 证据审计 | 洗白检测率、`E_eff` 与实机成功率一致性 | 检测率 ≥ 0.9，校准误差 ≤ 0.07 |
| E172 端到端通用平台 | N 具身×M 任务上证书通过率 vs 实机成功率、保守比 | 通过者成功率 ≥ 0.9，保守比 ≤ 1.3 |

**消融设计**：(i) 去掉 `b_anchor` 只用三角测量；(ii) 去掉 `ρ_eff` 假设独立；(iii) 去掉具身 Lipschitz 直接平均。这三个消融分别对应“共同盲区”“虚假共识”“平均掩盖最差具身”，预期都会系统性高估通用性。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 仿真器相关性导致虚假共识 | 高 | 估计 `ρ_eff`、跨引擎/跨资产选族、强制 `b_anchor` |
| 有效域估计循环依赖实机 | 高 | 小样本共形 + 保守先验 + 主动扩张预算 |
| 具身流形维数灾难、覆盖不可达 | 高 | 低维参数化 + 分层证书 + 每族单独声明 |
| 证据洗白（仿真条数刷证据） | 高 | 血缘去重 + 汇率衰减 + `min_weight` 下限 |
| 证书过保守使平台显得不通用 | 中 | 主动锚定收窄间隙、分级证书（受限通用/全域通用） |
| 审计扰动族不覆盖真实伪影 | 中 | 从失效日志反推扰动、在线扩充 `𝒜` |

## 6. 本轮最大风险

**一句话**：三角测量与具身覆盖把“通用性”从分数变成可证书的流形性质，但其 soundness 的关键支点是**仿真器误差的独立性与有效域估计的可迁移性**；一旦仿真器族共享同一个物理近似或资产偏差（`ρ_eff→1`），分歧会趋近于零而共享偏差完全不可见，此时证书会在“所有仿真器都同意”的假共识上放行一个只在共同盲区里成立的“通用平台”——因此必须以**实机锚点估计 `b_anchor` + 血缘折价 + 主动边界扩张**为硬约束，宁可把“通用”缩小到有管辖权的子流形，也绝不把仿真器的一致当作现实的保证。

## 2. 关键算法 伪代码

### 2.1 语义-接触层（IP-121~126，v32 补落盘）

```python
def semantic_contact_map(rgbd, seg_model, kappa, theta_k, theta_conf):
    Sigma = seg_model.predict_soft(rgbd)
    C = {(p,c) for p in grid(rgbd)
         if confidence(Sigma[p]) >= theta_conf
         and kappa[argmax(Sigma[p])][c] >= theta_k}
    return Sigma, C, boundary_margin(Sigma)

def viability_kernel(Sigma, C_plus, x0, horizon, eps):
    K, margins = set(), []
    for x in sample_state_space(x0, horizon):
        feas, u, lam = solve_contact_dynamics(x, C_plus, friction_cone=mu)
        if feas:
            K.add(x); margins.append(distance_to_infeasible(x, C_plus))
    return KernelApprox(inner_hull(K), outer_hull(K, eps), min(margins, default=0))

def semantic_shield(u_nom, x, Kernel, C_plus, W):
    u = qp_solve(H=W, g=-W @ u_nom,
                 constraints=[viability_constraint(x, u, Kernel.K_in),
                              contact_constraint(u, C_plus),
                              friction_cone_constraint(u, mu),
                              joint_limit_constraint(u)])
    return (safe_brake(x), 'shield_infeasible') if u is None else (u, 'ok')
```

### 2.2 IP-127 VJD（仿真有效域发现与主动扩张）

```python
def discover_validity(sim, real, Theta, Tau, E, anchor_budget, eps_fid, delta_fid):
    D = coverage_design(Theta, Tau, E)
    pairs, uncertain = [], []
    for x in D:
        y_sim = sim.rollout(x)
        if anchor_budget.can(x):
            pairs.append((x, discrepancy(y_sim, real.query(x))))
    d_hat = conformal_quantile_regressor(pairs, level=1 - delta_fid)
    V_hat = {x for x in D if d_hat(x) <= eps_fid}
    uncertain = {x for x in D if eps_fid - margin <= d_hat(x) <= eps_fid + margin}
    return ValidityCert(V_hat, eps_fid, delta_fid, uncertain, d_hat)

def expand_validity(cert, sim, real, anchor_budget, eps_fid):
    for x in select_by_coverage_gain(cert.uncertain, anchor_budget):
        cert.update(x, discrepancy(sim.rollout(x), real.query(x)))
    return cert.refit()
```

### 2.3 IP-128 EMT（具身流形均匀迁移）

```python
def embodiment_uniform_cert(skill, Theta, theta_samples, L_theta, rho_min, eps_cov):
    vals = [(t, robustness_spectrum(skill.instantiate(t))) for t in theta_samples]
    radii = [sample_radius(t, theta_samples) for t in theta_samples]
    cover = measure(union_balls(theta_samples, radii)) / measure(Theta)
    rho_lower = min(r for _, r in vals) - L_theta * max(radii)
    ok = (cover >= 1 - eps_cov) and (rho_lower >= rho_min)
    return EmbodimentCert(ok, cover, rho_lower, vals)

def active_embodiment_sample(skill, Theta, cert, budget):
    return argmax_points(Theta, key=lambda t: lipschitz_gap(t, cert), n=budget)
```

### 2.4 IP-129 SCT（仿真器共识三角测量）

```python
def triangulate(sim_family, x, real_anchors, eps_fid, rho_min, delta_b):
    R = [M.risk(x) for M in sim_family]
    D = max(R) - min(R)
    rho_eff = estimate_error_correlation(sim_family, real_anchors)
    c = sqrt((1 + (len(R)-1)*rho_eff) / (len(R)*(1 - rho_eff + 1e-9)))
    b = conformal_upper(shared_bias(sim_family, real_anchors), level=1-delta_b)
    R_tri = mean(R) + c*D + b + eps_fid
    return TriCert(R_tri, D, rho_eff, b, sound=(R_tri <= rho_min))
```

**不可省项**：`b_anchor`。若移除它，共享偏差在 `D=0` 时完全不可见，证书退化为“共同盲区投票”。

### 2.5 IP-130 GAD（判别式通用性审计）

```python
def audit_generality(policy, sim_family, artifact_perturbations, budget):
    best, best_gain = None, -inf
    for a in artifact_perturbations:                 # 接触/延迟/噪声/渲染
        gain = kl_divergence(predict_failure(policy, a, 'genuine'),
                             predict_failure(policy, a, 'spurious'))
        if gain > best_gain and budget.can(a):
            best, best_gain = a, gain
    lr = likelihood_ratio(observe(policy, best), hyp='genuine', alt='spurious')
    return AuditCert(best, best_gain, lr, 'genuine' if lr >= tau_lambda else 'spurious')
```

### 2.6 IP-131 EAB（证据汇率与反洗白）

```python
def evidence_audit(evidence, lambdas, lineage_graph):
    ledger = []
    for e in evidence:
        lineage = lineages_of(e, lineage_graph)
        leak = jaccard(lineage, union_lineages(ledger, lineage_graph))
        w = exp(-lambdas[0]*e.eps_fid - lambdas[1]*(1-e.eta) - lambdas[2]*leak)
        ledger.append((e, clamp(w, 0.0, 1.0)))
    E_eff = sum(w * e.quantity for e, w in ledger)
    return EvidenceCert(ledger, E_eff, min_weight=min(w for _, w in ledger))

def refuse_laundering(cert, E_min, min_weight):
    return cert.E_eff >= E_min and cert.min_weight >= min_weight
```

### 2.7 IP-132 GCE（通用性证书总装）

```python
def generality_certificate(policy, target, sim_family, real, budgets):
    F = discover_validity(sim_family[0], real, budgets.Theta, budgets.Tau,
                          budgets.E, budgets.anchor, budgets.eps_fid, budgets.delta_fid)
    if not subset(target, F.V_hat):
        return ('reject', 'out_of_jurisdiction', F)
    E = embodiment_uniform_cert(policy, budgets.Theta, budgets.theta_samples,
                                budgets.L_theta, budgets.rho_min, budgets.eps_cov)
    if not E.ok:
        return ('reject', 'embodiment_coverage', E)
    T = triangulate(sim_family, target, real.anchors, budgets.eps_fid,
                    budgets.rho_min, budgets.delta_b)
    if not T.sound:
        return ('reject', 'triangulated_risk', T)
    A = audit_generality(policy, sim_family, budgets.perturbations, budgets.audit)
    if A.decision != 'genuine':
        return ('reject', 'spurious_generality', A)
    Ev = evidence_audit(budgets.evidence, budgets.lambdas, budgets.lineage)
    if not refuse_laundering(Ev, budgets.E_min, budgets.min_weight):
        return ('reject', 'evidence_laundering', Ev)
    G_lower = lower_bound(policy, F, E, T, budgets)
    return ('ok', GeneralityCert(G_lower, F.V_hat, E.cover, E.rho_lower,
                                 T.R_tri, T.rho_eff, A, Ev.E_eff))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SCG | O(|Ω|·(|L|+|C|)) | O(|Ω|·|L|) | 置信校准、可供性标定 |
| WBV | O(|X|·T·QP) | O(|X|) | 核外近似 sound、接触集完备 |
| SSF | O(QP) | O(|A_WB|) | 可行或安全回退 |
| VJD | O(|D|·(T_sim+T_real)) | O(|D|) | 共形覆盖、可交换性 |
| EMT | O(|Θ_s|·|A|·T) | O(|Θ_s|) | 覆盖完备、`L_θ` 可信 |
| SCT | O(k·|X|+|anchors|) | O(k+|X|) | `η` 校准、共享偏差有锚 |
| GAD | O(|𝒜|·B) | O(|𝒜|) | 扰动族含高判别项 |
| EAB | O(|E|·|lineage|) | O(|E|) | 血缘去重、汇率上界 |
| GCE | Σ 组件 | O(|D|+|E|) | 任一检查失败即拒绝 |

**正确性定理（General-Platform Generality Soundness）**
假设 (A29)–(A32)（第 55 轮）成立；**(A33)** `P(V_M ⊇ V̂_M) ≥ 1-δ_fid` 且 `V̂_M` 上保真界为 `ε_fid`；**(A34)** `Θ` 覆盖完备、`L_θ` 为真 Lipschitz 常数；**(A35)** `η` 估计误差 ≤ `δ_η`，`R_tri` 为 `R_real` 保守上界；**(A36)** 审计族存在 `D_KL ≥ β_audit` 判别项；**(A37)** 证据汇率不超过真实证据等效置信。
则对任意 `target ⊆ V̂_M`：
```
P(G_real ≥ G_lower) ≥ 1 - (δ_fid + δ_cov + δ_η + δ_audit + δ_evid)
G_lower = G_sim|V̂_M - ε_fid - L_θ·r_cov - c_k(η)·D - b_anchor
```
关键：**通用性只在 `target ∩ V̂_M` 有定义**；三角测量只降方差，`b_anchor` 才是共享偏差的唯一下界来源；具身 Lipschitz 把离散样本扩成流形结论，但覆盖不到的具身不享受任何保证。

**三个必做消融（对应三种自欺）**
1. 去掉 `b_anchor` 只用多仿真器：验证“共同盲区”会被误判为安全；
2. 令 `ρ_eff=0` 假设独立：验证“虚假共识”使风险上界系统性偏低；
3. 直接用具身平均分替代 `inf_θ`：验证“平均掩盖最差具身”。

预期三个消融在留出集上都会高估通用性 ≥ 10 个百分点，这是 v32 相对 v31 最直接的证伪价值。

## 6. 本轮最大风险

**一句话**：v32 把“通用性”从 benchmark 分数改造成有管辖权、可审计、按汇率计证的流形证书，但其 soundness 的全部支点在于**仿真器误差独立性与有效域可迁移性**；若仿真器族共享同一物理近似或资产偏差，`ρ_eff→1` 会让分歧趋零而共享偏差不可见，证书就会在“全体仿真器一致”的假共识上放行一个只在共同盲区中成立的伪通用平台——因此必须把 **实机锚点估 `b_anchor`、血缘折价、主动边界扩张** 设为不可协商的硬约束，宁可把“通用”缩到有管辖权的子流形，也绝不拿仿真器的一致兑换现实的保证。
