# 第 11 轮（承接第 10 轮 MetricVoiceGauge-STF-NRB-LS；本轮灵感：「大语言模型」×「全身控制」）

> **基线**：第 10 轮 MetricVoiceGauge-STF-NRB-LS（定义 540–548；引理 87–91；实验 E571–E590）。
> 本轮纪律：**语言可验证 + 物理可站住**。两个灵感各治 v10 的一笔债：**表达债**——NRB 的规范表是手写、封顶 |N|≤12 的谓词数据，能"把治理变数据行"，却接不住人类自然语言的任务书与临场指令，也无法组合/解释；**体魄债**——v10 的块证书（ĝ_min、ê_max、中止点 p*）是**几何+力矩**的，默认机体一定能执行、一定能刹住；一旦平台是腿足/人形，"几何上安全"与"动力学上站得住"不再等价：一个净空充裕的块可能让机器人摔倒，一个几何上最近的 p* 可能动态不可达。必须保持 v10 铁律：任一新模块失效 ⇒ 注入声明中立元，行为严格**等价**或**支配**于 v10，而非行为漂移。

## 0. 直觉与动机

**灵感 1（大语言模型 → 从手写规范表到可验证语言契约）**
直觉：规范表的真正瓶颈不是算法，而是**作者瓶颈**与**信任边界**。人能说话，系统要的是机器可判的约束；LLM 恰好极擅长"翻译与组合"，却极不适合当信任根（幻觉、提示注入、分布漂移、不可复现）。所以要把两件事拆开：**提议（propose）**交给 LLM，放在离线/慢环；**处置（dispose）**交给确定性判定器，放在信任边界内。核心创新：**语言契约编译器（Language-to-Contract, L2C）**——自然语言任务书/规范/临场指令 → 受限类型化契约语言 L_C 中的候选（谓词只引用**冻结**的观测词汇：地标类、位姿、距离、接触状态、有界时序算子）→ 判定器 Chk 只在（类型正确 ∧ 全函数 ∧ 前瞻有界 ∧ O(k) 可判 ∧ 修复只取自固定算子库 R ∧ **不引入新动作/不放宽**）时采纳；采纳即与 N 合取。LLM 另有一用：**离线红队**生成对抗语义样本与规范冲突，专门攻击 τ_sem 与 N——它是测试生成器，不是运行时。让这条路安全的关键性质很朴素：**LLM 的错误只可能收缩动作空间，不可能扩张**；模型错了，最多损失活性（过度保守），绝不新增物理权限。于是信任锚从"模型"移到"**受限语法结构 + 判定器**"——这是诚实且可测的。

**灵感 2（全身控制 → 从几何证书到全身动力学可行证书）**
直觉：v10 问"有没有净空、力矩够不够"，但腿足/人形可以两者都满足仍然摔倒，因为真正约束是**接触一致的活力**：质心/DCM 必须在捕获区内，接触要满足摩擦锥，关节/自碰撞不能越界，而且这些在**执行块的每一步、以及刹车到中止点的全过程**都要成立。v10 的 p* 是一个**几何点**；真正的需求是"存在一条全身刹车轨迹到 p*，且全程留在活力核里"。核心创新：**全身可行性证书（Whole-Body Feasibility Certificate, WBFC）**——降阶活力裕量 ρ_t（DCM 到活力核边界的保守距离，附模型误差 β_WB）、摩擦/关节/自碰撞裕量，以及**动态中止不变量**：每一微步都存在 H_b 时域内的刹车计划，进入静态稳定的 p* 且全程 ρ ≥ β_WB。配套**严格优先级分层 QP（HQP）**：L0 硬物理（自碰撞、限位、摩擦锥、活力）> L1 证书约束 > L2 规范/任务分数，零空间投影保证低层永不侵犯高层——**分数不能买裕量**。接触模式未知/降阶不可得 ⇒ **姿势收缩 Π_wb**（降重心、扩支撑、冻结手臂、限速、禁腾空），只收缩不扩权（与 P13 同构）。这也是对 v10 最大风险（τ_sem 被对抗语义穿透）的一路**非语义**兜底：对抗纹理骗得过嵌入，骗不过"机体在倒"——但降阶模型本身是近似，故设 P18 约束它。

**咬合**：L2C 管"人类要什么"（语言→可验证约束），WBFC 管"机体能不能做到"（动力学可行）；二者共享同一条纪律：**语言不进快环、分数不买裕量、降阶必须带据**。联合证书从 v10 的 Ĉ⁺ 升级为 **Ĉ^◊ = (Ĉ⁺, ρ_t, γ_fric, γ_jl, γ_sc, n_t^L, u_t)**：n_t^L 为语言契约通过向量，u_t 为动态中止见证（刹车计划哈希）。v10 的"显著/非显著语义二分"仍是第一道门；v11 新增两条尽量正交的独立证据：**语言契约的单调收缩**（治理侧）与**全身活力的物理可行**（体魄侧）。

## 1. 研究问题（轮次升级版）

- **Q1（语言可验证）**：如何把开放式自然语言要求编译进一个受限类型化契约语言，使得任何 LLM 错误都只能**收缩**动作集而绝不扩张（受限语法为结构性信任锚），且 L2C 失效时精确退化为 v10 手写 N？
- **Q2（全身可行）**：如何把块/中止证书从几何条件升级为全身动力学可行（捕获区活力 + 摩擦锥 + 关节/自碰撞 + 动态中止），把降阶模型误差以保守 β_WB 吸收，并用严格优先级 HQP 保证任务分数永不交易安全裕量？
- **Q3（联合退化与预算）**：任一模块失效时如何保证行为**等价或支配**于 v10，且 50Hz 六检守卫 ≤20ms、功耗 ≤25W、任务完成率不低于 v10？

## 2. 设计原则（在 P13–P15 基础上新增 P16–P18）

**P16 语言不可信律（Untrusted Language / Propose–Verify, L2C）**
LLM 只可在离线/慢环提议**约束**，不得进入 50Hz 控制面；不得产生修复算子、新动作或任何放宽；未过确定性判定器的一律不入 N；采纳即合取（只收缩）。**受限类型化语法结构**是安全论证的结构性信任锚（语法上无法表达"扩张"），判定器负责良构与活性。L2C 失效/超时/拒收 ⇒ N^L=N，精确退化为 v10。

**P17 全身层级安全律（Whole-Body Lexicographic Safety, WBFC）**
硬物理约束（自碰撞、关节限位、摩擦锥、活力核）具有最高优先级；证书、规范、语言与任务目标只能在硬约束的零空间内优化；分数永远不能购买裕量。中止点必须是**动态可达且全程可行**的，不是几何点。L0 可行性由 WBFC 独立复核，不依赖 QP 求解器自证。

**P18 降阶有据律（Evidence-Backed Reduction, WBFC）**
用降阶模型（LIPM/DCM）换取实时性，必须携带经标定的误差 β_WB 并被证书吸收；未知接触模式或非平面地形 ⇒ 退化到最保守剖面 Π_wb + 标量几何门控；纯几何证书不许在整身平台上单独签发。

## 3. 与基线的接口（如何退化）

- L2C 失效（LLM 超时/判定器不可用/全部拒收）⇒ N^L=N（v10 手写规范表），行为等价 v10；
- 已采纳语言契约运行期求值超时/异常 ⇒ 该行降级为保守默认（ν-PROX 式 d_eth+δ_r）或撤销至 v10 对应行；不触控制权（P16）；
- WBFC 失效（降阶状态不可得/接触模式未知/标定过期）⇒ Π_wb 姿势收缩 + 几何证书 + K_eff←1，动作 ⊆ v10（P17/P18）；
- HQP 不可解 ⇒ 沿用上一可行解；仍不可行 ⇒ 安全停驻；动作 ⊆ v10；
- NRB/STF/AC/ID/MW/v8 各层沿 v10 六级退化链原样；
- ID：L2C 编译器、离线红队 φ^elig=false 永不消融；WBFC/HQP/Π_wb 永不消融；仅"降阶模型在线更新"可蒸馏。

## 4. 预期贡献

1. **可验证语言治理**：把规范/任务书写的作者瓶颈从"人写代码"变为"人说话 + 机器判定"，并以**单调收缩定理**保证 LLM 错误只损活性、不损安全（引理 92–93）；
2. **全身可行性证书**：把块/中止证书从几何升级为动态活力（捕获点 + 接触 + 分层 QP），给出动态中止不变量、降阶误差吸收与对 v10 的支配性（引理 94–96）；
3. **失效边界**：Π_wb 姿势收缩中立元 + 六检守卫 + 全路径等价/支配（引理 97）；
4. **E591–E610** 覆盖判定器对抗、语言单调性、降阶标定、动态中止、非平面地形、优先级防套利、联合失效与竞赛。

## 5. 本轮最大风险

**一句话**：安全论证的信任锚从"经验校准的 τ_sem"搬到了"降阶模型的误差界 β_WB"与"受限语法的表达边界"，而二者恰在分布外最不可测——非平面/接触丰富地形上 LIPM 捕获区可能朝**乐观方向**偏，使 WBFC 给一个动态不可行的块签发证书，机器人在 v10 所有守卫全绿时摔倒；与此同时，一个类型正确但语义错误的语言契约可以骗过健全却**不完备**的判定器，造成慢性过度收缩（活性死亡）而永不触发安全告警。

**新增定义 549（受限契约语言 L_C）** 项由只读观测 V_p 经类型化运算与**有界时序算子**（□_{≤h}、◇_{≤h}、U_{≤h}）构造；禁止对执行量做算术、禁止无界量词、禁止调用外部代码。求值全函数（无除零/无异常/无超时）、O(k)（k≤8 近邻地标）、前瞻 ≤H_c（默认 2s）。表达力被**故意限制**：只能表达对既有动作谓词的**过滤/否决**，语法上无法书写"放宽""新动作""新修复"。

**新增定义 550（L2C 编译与判定）** LLM: NL→c（可给 k 个候选）。Chk(c) 采纳当且仅当：
(i) type_ok：c 在 L_C 中良类型且仅引用 V_p；
(ii) total_ok：任意合法输入下终止、无异常，WCET ≤O(k)；
(iii) horizon_ok：所有时序算子前瞻 ≤H_c；
(iv) remedy_ok：rem∈R（v10 定义 545 的 {r₁,r₂,r₃}），不含新动作或放宽；
(v) shrink_ok：语法结构上是合取过滤（满足 c 的动作 ⊆ 不满足时的 v10 动作）；
(vi) safe_ok：只读、无副作用、可沙箱求值。
拒绝返回反例 ce 并写入 Λ。**判定器不是定理证明器**：它保证"良构 + 只收缩"，语义正确性不由它保证——语义错误的契约仍只是"多删了点动作"，由引理 92 兜底。

**新增定义 556（HQP 分层）** 决策变量为全身关节加速度/力矩；L0 硬约束（自碰撞、限位、摩擦锥、ρ≥β_WB）；L1 证书/规范约束；L2 任务分数。严格优先级：低层在高层零空间内优化。`A_HQP` 为满足 L0 的可行集；L0 可行性由 WBFC **独立复核**，不信任求解器自证（引理 95）。

# IP-362 ContractChecker + IP-361 L2C（离线/慢环；永不进入 50Hz）
class ContractChecker:
    GRAMMAR = bounded_typed_grammar(V_p, H_c)
    FIXED_REMEDIES = {'r1', 'r2', 'r3'}          # v10 定义 545，禁止 LLM 自带
    def check(self, c):
        if not type_ok(c, self.GRAMMAR):        return 'reject', {'why': 'type'}
        if not total_ok(c) or c.wcet > O_k:     return 'reject', {'why': 'total/budget'}
        if max_horizon(c) > H_c:                return 'reject', {'why': 'horizon'}
        if c.remedy not in self.FIXED_REMEDIES: return 'reject', {'why': 'remedy'}
        if not shrink_only(c):                  # 语法上必须是合取过滤
            return 'reject', {'why': 'expand'}
        return 'admit', {}

class LanguageContractCompiler:                  # IP-361
    def __init__(self, llm, checker, ledger):
        self.llm, self.checker, self.ledger = llm, checker, ledger
    def compile(self, nl_text):
        cands = self.llm.propose(nl_text, schema=L_C)   # 不可信提议
        admitted = []
        for c in cands:
            verdict, info = self.checker.check(c)
            self.ledger.append(('l2c', hash(c), verdict, info))
            if verdict == 'admit':
                admitted.append(c)
        return admitted          # 合取进 N^L；LLM 挂掉/超时 ⇒ 空 ⇒ N^L=N

# IP-363 WBFC（50Hz，O(1) 查表 + 见证检索）
class WholeBodyFeasibilityCertifier:
    def __init__(self, viability_table, beta_by_terrain, beta_fric, H_b):
        self.V, self.beta_map = viability_table, beta_by_terrain
        self.beta_fric, self.H_b = beta_fric, H_b
    def margins(self, s, contact_mode):
        b = self.beta_map.conservative(contact_mode)   # 未知 ⇒ +inf ⇒ fail
        xi = s.x + s.xdot / omega(s.z_c)               # DCM
        rho = self.V.distance_to_boundary(xi)          # 保守下界
        return dict(rho=rho, beta=b,
                    fric=s.min_friction_margin(),
                    jl=s.min_joint_margin(),
                    sc=s.min_self_collision_margin())
    def certify(self, s, chunk, contact_mode):
        m = self.margins(s, contact_mode)
        if (m['rho'] < m['beta'] or m['fric'] < self.beta_fric
                or m['jl'] < 0 or m['sc'] < 0):
            return None                                 # WBFC 失效 ⇒ Π_wb
        witness = self.braking_library.find(
            s, chunk.nearest_abort, H=self.H_b,
            keep=lambda x: self.V.distance_to_boundary(x) >= m['beta'])
        if witness is None:
            return None                                 # 无动态中止见证 ⇒ Π_wb
        return WBFC(m, witness)                         # u_t = hash(witness)

# IP-364 HQP（5Hz 块级；1kHz 跟踪侧同一优先级）
class HierarchicalTaskSolver:
    LEVELS = ['L0_physics', 'L1_cert_norm', 'L2_task']
    def solve(self, state, tasks, wbfc):
        prev = None
        for lvl in self.LEVELS:                        # 低层在高层的零空间内
            tasks[lvl].constraints += hard_constraints(lvl, state, wbfc)
            sol = qp_solve(tasks[lvl], nullspace=prev)
            if sol is None:
                return None                            # ⇒ 上一可行解 / 停驻
            prev = sol
        if not wbfc.certify(state, tasks['cert'], state.contact_mode):
            return None                                # L0 独立复核（不信任 QP）
        return prev

# IP-365 Π_wb（事件驱动；只删/降，不新增）
class PostureRestrictiveProfile:
    def apply(self, cmd, state):
        cmd.com_z   -= delta_c
        cmd.support  = widen(state.support)
        cmd.arm_vel  = 0.0
        cmd.v_max   *= kappa_wb                        # ≤0.5

# IP-354（升级）：联合证书分块执行器
class JointChunkCertifier(StructuredChunkCertifier):
    def generate_chunk(self, state, ctx, stf, nrb, wbfc, hqp):
        K = self.effective_K(ctx.delta_dom, ctx.tau_dom,
                             trust_ok=stf.trust_ok(ctx),
                             wb_ok=wbfc.precheck(state))    # 定义 539-v11
        if K == 1:
            return self._single_step_fallback(state)
        for cand in self.policy.sample_sequences(state, K, n=64):
            pred = self.Fq.rollout(state, cand)
            beta_stf = self.beta_base + self.lam * stf.field_on_footprint(pred.corridor)
            cb = wbfc.certify(state, cand, state.contact_mode)   # IP-363
            if cb is None:
                continue                                          # 跳过不可行候选
            g_min = pred.min_clearance - beta_stf
            e_max = pred.max_effort + beta_stf
            if g_min < self.d_safe or e_max > state.tau_eff:
                continue
            pts = self._abort_points(state, cand, pred)
            if not pts:
                continue
            chunk = Chunk(cand, CertDiamond(g_min, e_max, beta_stf,
                                            cb.rho, cb.margins, cb.u), pts)
            chunk, verdict = nrb.review_chunk(chunk, stf, ctx)
            if chunk is None:
                continue
            u = hqp.solve(state, chunk.tasks, wbfc)              # IP-364
            if u is None:
                continue
            chunk.control = u
            chunk.cert.n_l = self.language_vector(ctx)           # 定义 552
            score = self.policy.score(chunk, pred)
            if best is None or score > best.score:
                best = chunk
        return best or self._single_step_fallback(state)

    def midchunk_guard(self, chunk, k_exec, live, stf, nrb, wbfc):
        """50Hz 六检 ≤0.8ms；返回 ('continue',k+1) | ('abort',p*) | ('pi_wb',None)"""
        if not chunk.cert_still_valid(live):                       # 检 1
            return self._nearest_abort(chunk, k_exec)
        stop_inv = (live.nearest_clearance
                    - self.d_brake(live.speed) - self.d_safe)
        if stop_inv < chunk.remaining_len(k_exec):                 # 检 2
            return self._nearest_abort(chunk, k_exec)
        if stf.surprise_near(live.pose) > stf.tau_sem:             # 检 3
            return self._nearest_abort(chunk, k_exec)
        if nrb.fast_norms(live).violated:                          # 检 4
            return self._nearest_abort(chunk, k_exec)
        m = wbfc.margins(live, live.contact_mode)                  # 检 5
        if m['rho'] < m['beta']:
            return ('pi_wb', None)                                 # 姿势收缩 + 停驻
        if not fast_language_ok(live, self.norms):                 # 检 6
            return self._nearest_abort(chunk, k_exec)
        return ('continue', k_exec + 1)

## 4. 推导

**引理 92（语言契约单调收缩与失效等价——L2C 的安全方向性）** 设语法 L_C 只含只读观测与有固定修复库 R 的合取过滤（定义 549/550(iv)(v)），且 v10 安全论证对 A_v10 成立。则：
(a) N^L ⊇ N ⇒ A(N^L) ⊆ A(N)；
(b) 任意 LLM 输出（含畸形、注入、对抗）或被拒、或作为过滤合取进 N^L，**不可能扩张动作集**；
(c) L2C 不可用/超时/全拒 ⇒ N^L=N，行为精确等价 v10；
(d) 因此 LLM 错误的安全代价为 0，只可能损失活性。证明：(a) 每条 c 是合取过滤，R 中修复算子经 v10 引理 89 已证只收缩；过滤的合取单调。(b) 由语法封闭性：L_C 无法书写"放宽/新动作/新修复"，畸形候选被 Chk 拒。(c) 空扩展即恒等。(d) 由 (a)(b)。∎
> 关键限定：安全性由**结构**（只收缩）而非模型正确性保证；判定器的语义健全性只影响活性控制（引理 93）。

**引理 93（判定器不完备的代价界与活性保护）** 设红队集上 Chk 的误采纳率为 δ_ce、误拒率为 ε_lr。则安全不受影响（引理 92），活性损失由误采纳的过度约束与误拒的能力缺失构成；引入**影子模式**（admitted 契约先只求值不执行 N_s 个块，若其否决率 >θ_l 或与手写 N 矛盾 >θ_c 则强制人工复核）可使部署期过度收缩的期望暴露 ≤δ_ce·P(影子未捕获)。证明：安全部分同引理 92；活性部分为影子采样的标准界。∎

**引理 94（WBFC 对几何证书的细化与支配）** 若 Ĉ^◊ valid，则其承载块同时满足 v10 的 Ĉ⁺ 全部条件（几何/力矩/语义/规范），且额外满足 ρ_t≥β_WB、摩擦/关节/自碰撞裕量与动态中止见证。故 `A(Ĉ^◊) ⊆ A(Ĉ⁺) ⊆ A_v10`；动态可达中止是几何可达中止的**细化**（每个动态可行刹车轨迹的终点都是几何可行 p*，反之不成立）。证明：合取引入 + 轨迹投影。∎

**引理 95（HQP 严格优先级的安全保持）** 在严格优先级分层 QP 中，低层解限制在高层的零空间内；故任一返回解满足 L0 硬约束，L1/L2 的目标与分数**不能**改变 L0 可行集，也不能交易 ρ_t/γ_fric/γ_jl/γ_sc。且 L0 可行性由 WBFC 独立复核，即使 QP 求解器静默松弛也会被检 5 捕获。证明：零空间投影保持高层约束不变（归纳）；独立复核切断求解器信任。∎

**引理 96（动态中止的保守性）** 设 (A_WB) 在标定地形族上，全动力学与 LIPM/DCM 在 ρ 上的偏差 ≤β_WB；(A_B) 刹车库是可行刹车计划的 ε_B-覆盖。若 ρ_t≥β_WB 且存在见证 u_t 使 [t,t+H_b] 全程 ρ≥β_WB，则存在全动力学可行刹车轨迹到静态稳定 p* 且全程活力裕量 ≥0。证明：三角不等式把降阶偏差折算到真实裕量；ε_B 覆盖保证见证可提升为真实计划。∎
> 这是 v11 的**唯一硬假设**：β_WB 在分布外不可测时，(A_WB) 失效；故定义 553 对未知接触模式取 +∞，强制 Π_wb（P18）。

**引理 97（联合退化等价/支配）** 任一新模块单点失效：L2C ⇒ 精确 v10（引理 92c）；WBFC/Π_wb/HQP ⇒ 动作 ⊆ v10（引理 94/95，Π_wb 只删降）；六检超时 ⇒ 保守停驻（⊆ v10）。结合 v10 引理 89 与退化链，任一失效下行为 ∈ {≈v10, ⊆v10}，即等价或支配，无行为漂移。最坏六检 WCET ≤0.8ms，50Hz 保持。∎

## 8. 本轮最大风险

**一句话**：安全论证的信任锚从"经验校准的 τ_sem"搬到了"降阶模型的误差界 β_WB"与"受限语法的表达边界"，而二者恰在分布外最不可测——非平面/接触丰富地形上 LIPM 捕获区可能朝**乐观方向**偏，使 WBFC 给一个动态不可行的块签发证书，机器人在 v10 所有守卫全绿时摔倒；与此同时，一个类型正确但语义错误的语言契约可以骗过健全却**不完备**的判定器，造成慢性过度收缩（活性死亡）而永不触发安全告警。
