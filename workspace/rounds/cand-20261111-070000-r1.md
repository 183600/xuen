# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「常识推理」×「因果推理」）

> 第 54 轮把技能组合提升为动作-鲁棒性双证书（`α_S`、`A_cert`、`J`），但证书只回答“动作能不能覆盖 / 能不能对齐”，没有回答“这个动作是否**合乎常识**、其效果是否**真的由该动作因果产生**”。本轮引入 **常识合理性先验** 与 **因果结构约束**。核心矛盾：H22：动作覆盖 `α_S` 只保证可执行，不保证合理——覆盖了“把满杯水高速横穿窄缝”的动作，却违反物理/社会常识；H23：Explain 与鲁棒性谱本质是相关性证据，边端回传的“重剖分建议”可能利用混杂变量 Z 的虚假相关，云端据此重规划会产生**不迁移的伪鲁棒**。

## 0. 直觉与动机

**灵感 1（常识 = 廉价的可行性先验，而非硬规则）**
直觉：动作剖面 `α_S(a)` 是“能不能做”，常识合理性场 `π_S(a|c)` 是“这么做是否讲得通”。例如“抓取杯子”在 `α_S` 上完全覆盖，但当杯子已满且路径需高速转向时，`π_S` 会因液体溢出的物理常识骤降。把常识作为**软先验 + 常识悬崖**：`cs_ok(S,a,c) ⇔ π_S(a|c) ≥ θ_cs(c)`，并在 `∇_a π` 超过阈值的悬崖 `∂_cs` 上要求减速/桥接，而不是一刀切禁用。这样常识以极低成本剪掉大量“可执行但荒谬”的组合。

**灵感 2（因果 = 把技能从状态转移黑箱变为干预算子）**
直觉：技能 S 不只是 `α_S` 与 `ρ_S`，而是一个干预 `do(A_S=a)`，带因果签名 `Σ_S=(Pre_S, Eff_S, M_S, U_S)`。组合 `S_i ≻ S_j` 必须满足 `Eff_{S_i} ⊨ Pre_{S_j}`（或存在桥接集 B），且因果图无环、无效应冲突。更关键的是识别**混杂**：若存在 Z 使 `P(Eff|A,c) ≠ P(Eff|do(A),c)`，则第 54 轮测到的鲁棒性是“相关鲁棒”，换环境即失效——这正是负迁移的因果根源。

**灵感 3（反事实解释替代相关解释）**
直觉：第 54 轮 Explain 返回“哪一维 ρ 掉了”，这是相关归因；本轮用 **反事实解释** `CF(τ)=argmin_{I⊆A}|I| s.t. P(success|do(I),τ) ≥ θ_cf`，返回“最小干预集”。这把反向解释信道从“描述失败”升级为“给出可执行修复”，云端据此重剖分 `reprofile(A_c)` 才有因果依据，而非拟合噪声。

**灵感 4（因果-常识包络 → 组合图的两级剪枝）**
直觉：SCOM 的 `G_S` 是“动作相容”的松弛图。先过常识 veto 得到 `G_CS`，再过因果相容得到 `G_CC ⊆ G_CS ⊆ G_S`。搜索只在 `G_CC` 上进行，每条边附 `CCC` 证书；若 `G_CC` 无路径，系统应**弃权或请求桥接技能**，而不是回退到 `G_S` 硬拼。

**灵感 5（金字塔新增因果-常识层 ℂ）**
直觉：在第 54 轮动作-协同层 `𝔸` 之上叠加 `ℂ`：`ℂ_0` 物理常识（守恒、接触、支撑），`ℂ_1` 因果机制（前置-效果），`ℂ_2` 反事实可识别性，`ℂ_3` 跨环境因果可迁移性。跨层证书从 `J` 升级为 `J⁺=(J,CCC,trans_causal,abstain)`，形成 **动作-鲁棒-因果-常识四证书体系**。

## 1. 形式化定义（增量：定义 121–128）

**定义 121（常识合理性场）**
给定上下文 `c ∈ C`，技能 S 在动作 a 上的常识合理性 `π_S(a|c) ∈ [0,1]`，`1` 表示完全符合常识，`0` 表示明确违反。常识可行性 `cs_ok(S,a,c) ⇔ π_S(a|c) ≥ θ_cs(c)`。**常识悬崖** `∂_cs = {a | ||∇_a π_S(a|c)|| > τ_π}`，组合路径穿越 `∂_cs` 时必须插入减速/桥接动作，否则否决。

**定义 122（因果签名与干预语义）**
技能 S 的因果签名 `Σ_S = (Pre_S, Eff_S, M_S, U_S)`：前置条件、效果、结构机制、外生变量。执行对应干预 `do(A_S=a)`，效果分布 `P(Eff_S | do(a), c)`。若存在混杂 Z 使 `P(Eff|A,c) ≠ P(Eff|do(A),c)`，则称 S 存在**相关-因果间隙** `gap_S = sup |P(Eff|A,c) - P(Eff|do(A),c)|`。

**定义 123（因果相容）**
组合 `S_i ≻ S_j` 因果相容当且仅当存在桥接集 B（可为空或其他技能）使 `Eff_{S_i} ∪ Eff_B ⊨ Pre_{S_j}`，且组合因果图 `G_causal` 无环、无同一变量的矛盾赋值。记 `caus_compat(S_i,S_j,B) = 1`。

**定义 124（因果-常识组合图）**
`G_CC = (V, E_CC)`，`E_CC = {(i,j) | compat(S_i,S_j) ∧ c_trans ≤ τ_e ∧ cs_ok(S_i,a,c) ∧ caus_compat(S_i,S_j,B)}`。每条边附因果-常识证书 `CCC`。显然 `G_CC ⊆ G_CS ⊆ G_S`（`G_S` 为第 54 轮松弛图）。

**定义 125（反事实解释）**
失败轨迹 τ 的反事实解释 `CF(τ) = argmin_{I⊆A} |I| s.t. P(success | do(I), τ) ≥ θ_cf`，并给因果归因 `attr(a) = E[Y|do(a=1)] - E[Y|do(a=0)]`。与 Explain 的分工：Explain 给相关维度，CF 给**可干预变量**；仅当 `do(I)` 可识别时 CF 才可签发。

**定义 126（因果-常识证书）**
`CCC = (π_CS|_τ, Σ_seq, B_seq, I_min, G_causal, assumption_ledger, evidence)`。`assumption_ledger` 显式记录“无未观测混杂 / 机制稳定 / 常识先验来源与适用上下文”等**可证伪假设**；证据至少含干预实验或结构化仿真反例。

**定义 127（因果可迁移性）**
源环境 `e_s` 到目标 `e_t` 的选择图 D，若 `P(Eff|do(a),e_t)` 可由 `P(Eff|do(a),e_s)` 经允许的机制变换得到，则 `trans_causal(S,e_s→e_t)=1`；否则证书必须降级为相关性 `ρ` 并标注“不可迁移”。

**定义 128（联合扩展证书）**
`J⁺ = (J, CCC, trans_causal, abstain)`。当常识先验不覆盖当前上下文、或因果效应不可识别、或 `assumption_ledger` 中任一关键假设被证据否定时，`abstain=1`，宁可弃权也不部署。

## 2. 关键算法 伪代码

### IP-121 CSC（Commonsense Sanity Check）

```python
def commonsense_check(skill, a, context, theta_cs, tau_pi):
    pi = prior.pi(skill, a, context)          # 来源标注的常识先验
    if pi < theta_cs(context):
        return ('veto', pi, 'implausible')
    grad = prior.grad_norm(skill, a, context)
    if grad > tau_pi:
        return ('bridge_required', pi, 'commonsense_cliff')
    return ('ok', pi, None)
```

### IP-122 CCM（Causal Composition Model）

```python
def causal_compatible(si, sj, B=None):
    B = B or []
    effects = si.effects.union(*[b.effects for b in B])
    if not effects.entails(sj.preconditions):
        return ('reject', 'precondition_unsatisfied')
    g = build_causal_graph([si] + B + [sj])
    if has_cycle(g) or has_effect_conflict(g):
        return ('reject', 'causal_conflict')
    return ('ok', bridge_set=B, graph=g)
```

### IP-123 CCG（Causal-Commonsense Graph）

```python
def build_cc_graph(skills, G_S, context, theta_cs, tau_pi, theta_a, tau_e):
    G = nx.DiGraph()
    for (i, j, e) in G_S.edges(data=True):
        si, sj = skills[i], skills[j]
        cs = commonsense_check(si, e['action'], context, theta_cs, tau_pi)
        if cs[0] == 'veto':
            continue
        ca = causal_compatible(si, sj, e.get('bridge', []))
        if ca[0] != 'ok':
            continue
        G.add_edge(i, j, compat=e['compat'], cost=e['cost'],
                   rho_comp=e['rho_comp'], ccc=CCC(cs, ca, e['action']))
    return G
```

### IP-124 CFX（Counterfactual Explanation）

```python
def counterfactual_explain(traj, causal_model, theta_cf, max_interventions):
    for k in range(1, max_interventions + 1):
        for I in combinations(traj.actions, k):
            if not causal_model.identifiable(I):
                continue
            if causal_model.P_success(do(I), traj.context) >= theta_cf:
                return ('ok', I, causal_model.attr(I), causal_model.ledger())
    return ('abstain', None, None, 'no_identifiable_intervention')
```

### IP-125 CTC（Causal Transport Certificate）

```python
def causal_transport_certify(skill, e_source, e_target, selection_diagram):
    if not selection_diagram.mechanism_stable(skill):
        return ('reject', 'mechanism_shift')
    if not causal_model.identifiable_across(e_source, e_target):
        return ('degrade', 'correlational_only')
    return ('ok', TransportCert(skill, e_source, e_target,
                                selection_diagram.assumptions))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| CSC | O(1) 查询 + O(d) 梯度 | O(1) | 先验校准、上下文分层 |
| CCM | O((|Pre|+|Eff|)²) | O(|G_causal|) | 图无环、效应无冲突 |
| CCG | O(|E_S|·(d+|G_causal|)) | O(|E_CC|) | 两级剪枝 sound、不误回退 |
| CFX | O(Σ_k C(|A|,k)·T_infer) | O(|A|) | 干预可识别性门控 |
| CTC | O(|𝔇|·|G_causal|) | O(|G_causal|) | 机制稳定性、选择图假设 |

**正确性定理（Causal-Commonsense Composition Soundness）**
假设第 54 轮 (A22)–(A28) 成立；**(A29)** `π_CS` 由带来源标注的常识知识库与结构化仿真联合校准，`θ_cs` 有校准曲线；**(A30)** 部署范围内因果图 Markov 且 faithful，未观测混杂影响有上界 `β_conf`；**(A31)** CF 的 `do(I)` 在可识别子集上可识别；**(A32)** `abstain=1` 时不计入成功（保守下界）。则：
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a)
             - P(¬cs_ok) - P(¬caus_compat) - β_cf - β_conf
```
关键：**常识先验只做保守剪枝**，**因果相容保证效果可传递**，**反事实解释只在可识别子集签发**。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 常识先验跨文化/跨场景偏见 | 高 | 多来源标注 + 上下文分层 + 允许弃权 |
| 因果图错误或未观测混杂 | 高 | 敏感性分析 + 干预实验 + assumption_ledger |
| 反事实模型不可识别却强行签发 | 高 | 可识别性门控 + 仅可识别子集发证 |
| 常识 veto 过保守致图稀疏 | 中 | 软约束 + 悬崖减速桥接 + 桥接技能检索 |
| 云边因果假设版本不一致 | 中 | 共享因果本体 + 版本化假设账本 |

## 6. 本轮最大风险

**一句话**：常识与因果的引入把“可执行”升级为“合理且可干预”，但其 soundness **同时依赖常识先验的跨场景校准与因果图的忠实性 / 无未观测混杂**；一旦常识先验带文化偏见、或因果图把混杂当成机制，系统会以“合乎常识的因果证书”系统性地否决正确方案、或放行伪因果捷径，故必须以 **来源标注的常识先验 + 假设账本 + 可识别性门控 + 弃权机制** 四重护栏，宁可不部署，也绝不把相关当因果。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（CSC×CCM×CCG×CFX×CTC）

> 承接第 54 轮产物 v31。本轮在动作-鲁棒性双证书之上，增加 **常识合理性剪枝、因果相容组合、反事实解释、因果可迁移性** 四类算子：
> - **CSC（Commonsense Sanity Check）**：上下文相关的常识合理性场 `π_S(a|c)` 与常识悬崖 `∂_cs`；
> - **CCM（Causal Composition Model）**：技能因果签名 `Σ_S` 与 `Eff⊨Pre` 相容判定；
> - **CCG（Causal-Commonsense Graph）**：`G_CC ⊆ G_CS ⊆ G_S` 两级剪枝，边附 `CCC`；
> - **CFX（Counterfactual Explanation）**：最小干预集 `I_min`，替代相关型 Explain；
> - **CTC（Causal Transport Certificate）**：跨环境因果可迁移性证书与降级规则。
>
> IP 编号：IP-121~IP-125（共 5 个新增），升级 IP-116/118/120 以纳入常识与因果约束。

### 升级版联合证书（IP-118+ / IP-120+）

```python
def joint_certificate_v2(skill_seq, gamma_ce, delta_a_budget, rho_min,
                         context, theta_cs, theta_cf):
    # 1) 常识剪枝
    for s in skill_seq:
        if commonsense_check(s, s.action, context, theta_cs, 1e9)[0] == 'veto':
            return ('reject', 'commonsense_violation')
    # 2) 因果相容链
    for si, sj in zip(skill_seq, skill_seq[1:]):
        if causal_compatible(si, sj)[0] != 'ok':
            return ('reject', 'causal_incompatible')
    # 3) 第 54 轮动作-鲁棒性证书
    base = joint_certificate(skill_seq, gamma_ce, delta_a_budget, rho_min)
    if base[0] != 'ok':
        return base
    # 4) 反事实解释（失败时给可干预修复）
    cf = counterfactual_explain(base.traj, causal_model, theta_cf, 3)
    if cf[0] == 'abstain':
        return ('abstain', 'causal_unidentifiable')
    return ('ok', JointCertPlus(base, CCC(cf), trans_causal=True, abstain=False))
```

| CCG | O(|E_S|·(d+|G_causal|)) | O(|E_CC|) | 两级剪枝 sound，不静默回退 |
| CFX | O(Σ_k C(|A|,k)·T_infer) | O(|A|) | 仅可识别干预签发 |
| CTC | O(|𝔇|·|G_causal|) | O(|G_causal|) | 机制稳定 + 选择图假设 |

**正确性定理（Causal-Commonsense Composition Soundness）**
假设第 54 轮 (A22)-(A28) 成立；**(A29)** `π_CS` 经来源标注知识库与结构化仿真校准；**(A30)** 因果图 Markov + faithful，未观测混杂上界 `β_conf`；**(A31)** `do(I)` 在可识别子集上可识别；**(A32)** 弃权不计入成功。则：
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a)
             - P(¬cs_ok) - P(¬caus_compat) - β_cf - β_conf
```
关键：**常识只做保守剪枝**，**因果保证效果传递**，**反事实只在可识别处签发**。

## 5. 本轮最大风险

**一句话**：常识与因果的引入把“可执行”升级为“合理且可干预”，但其 soundness **同时依赖常识先验的跨场景校准与因果图的忠实性 / 无未观测混杂**；一旦常识先验带文化偏见、或因果图把混杂当成机制，系统会以“合乎常识的因果证书”系统性地否决正确方案、或放行伪因果捷径，故必须以 **来源标注的常识先验 + 假设账本 + 可识别性门控 + 弃权机制** 四重护栏，宁可不部署，也绝不把相关当因果。
