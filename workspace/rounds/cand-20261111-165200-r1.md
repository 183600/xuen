# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感驱动研究循环第 1 轮；本轮灵感：「通信延迟」×「视觉语言动作模型」）

> 第 54 轮把技能组合提升为「动作空间 + 鲁棒性」双证书，但隐含假设云边在动作粒度上同步对齐。本轮引入两个新变量：**通信延迟**与**视觉语言动作模型（VLA）**。核心矛盾：H22：VLA 的「视觉–语言–动作」强耦合依赖新鲜观测，而云边通信延迟使云端动作块在边端执行时已「语义过期」，第 54 轮的联合证书 J 默认同步，在延迟下 soundness 直接失效；H23：细动作传输时效差、粗语义意图省带宽但边端解压歧义大，单一粒度无法同时满足时效与保真。本轮要回答：**当通信延迟不可忽略时，VLA 的语义动作如何被证书化地安全执行？**

## 0. 直觉与动机

**灵感 1（延迟是动作剖面的新维度，而不是外部 QoS）**
直觉：第 54 轮的动作剖面 `α_S(a)` 是「技能能否做 a」，但真实系统里更常见的是「技能在延迟 τ 下还来不来得及做 a」。于是把剖面条件化：`α_S(a|τ) = α_S(a)·κ_S(τ)`，其中 `κ_S` 是时效核，`κ_S(0)=1`、随时延单调衰减、超过 `TTL_S` 归零。含义很直接：**动作不是二值可达的，而是带保鲜期的**。组合搜索时，若路径总时延使关键动作的 `α_S(a|τ)` 跌破阈值，则该组合在延迟下不可用——这把延迟从「部署后调参」提升为「组合前的第一性约束」。

**灵感 2（VLA 的动作块 = 带时间戳的语义承诺）**
直觉：VLA 输出不是一个瞬时动作，而是一段**动作块（action chunk）**，并附带语言级意图。把它写成 `c = (o_t, ℓ, s_t, a_{t:t+L}, t, h)`：观测、语言指令、语义 token、动作序列、生成时刻、内容哈希。边端在 `t' ≥ t+τ` 执行时，实际消费的是「过去观测 + 过去意图」导出的动作。于是「新鲜度」可以定义成一个连续量 `f_c(t') = κ(t'-t-τ)`，它同时编码了网络延迟和块内执行偏移。**过期动作不是随机噪声，而是系统性语义错位**（例如指令说「绕过左侧行人」，过期后行人已到右侧）。

**灵感 3（延迟-动作漂移的 Lipschitz 界 → 预测执行可补偿一部分）**
直觉：延迟造成的动作误差不应靠经验调，而应有上界。若云端口令 `π_c` 对状态 Lipschitz、环境状态速度有界 `v_o`，则在延迟 τ、块中点偏移 L/2 下：
`Δ_τ ≤ L_π·v_o·(τ + L/2) + ε_pred`。
边端可用轻量世界模型把状态前推 τ 步再执行云端动作（`o_hat(t)=W(o(t-τ), τ)`），把误差中的 `L_π v_o τ` 项压到预测残差 `ε_pred`。证书不再承诺「动作正确」，而承诺「漂移在预算内且保鲜概率足够高」。

**灵感 4（双系统 VLA：云端 System 2 慢而语义强，边端 System 1 快而局部）**
直觉：与其让云端 VLA 直接下发细动作，不如分工：云端 VLA 负责**语义级规划与意图**（低频、高价值、可容忍延迟），边端负责**反应式执行或从技能图 G_S 里选技能**（高频、低延迟）。运行时按时效仲裁：新鲜云端块可用且 deadline 宽松 → 走云端；即将超时或网络抖动 → 降级到边端反应策略；带宽极低 → 只传语义 token，边端在 `G_S` 上按意图检索技能。**这不是降级兜底，而是「通信预算 → 表征粒度」的显式映射**。

**灵感 5（最优动作块长 L\* 与语义压缩：把带宽-陈旧度折中做成闭式）**
直觉：块越长，单位时间传输次数越少（通信开销 `∝ b/L`），但块内陈旧度越大（漂移 `∝ v(τ+L/2)`）。二者相加求极小，得到闭式最优 `L* = sqrt(2 w_c b / (w_d v))`，再受保鲜预算约束 `L ≤ 2(TTL-τ)`。有趣的是，在最简线性模型里 `L*` **不显含 τ**，延迟通过「可行性上限」而非「最优值」起作用；这提示延迟治理的重点可能不是减小 τ，而是让 `TTL` 和语义信道足够宽。进一步，若传输语义 token 而非细动作，通信量由动作熵 `H(a|s)` 降为意图熵 `H(s|ℓ)`，低带宽下可只传 `s`，把细动作交给边端技能库展开。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（延迟条件动作剖面）**
在定义 115 的动作空间 `A=A_c×A_e` 上，技能 `S` 的延迟条件剖面为
`α_S(a|τ) = α_S(a)·κ_S(τ)`，`κ_S: ℝ_{\ge0}→[0,1]` 单调不增，`κ_S(0)=1`，`κ_S(τ)=0 (τ>TTL_S)`。
**延迟下动作覆盖**：`cover_τ(S,A_T) = 1` 当且仅当 `∀a∈A_T, α_S(a|τ) ≥ θ_cov`。组合可行性替换定义 116 中的 `compat` 为 `compat_τ`。

**定义 122（带语义戳的 VLA 动作块）**
VLA 动作块 `c = (o_t, ℓ, s_t, a_{t:t+L}, t, h)`：
- `o_t` 生成时的观测，`ℓ` 语言指令，`s_t` 语义意图 token，`a_{t:t+L}` 动作序列，`t` 生成时刻，`h` 内容哈希；
- **新鲜度** `f_c(t') = κ_S(t'-t-τ)·𝟙[t' < t+τ+L]`；
- **可执行残段** `exec(c,t') = a_{t'-t-τ : t+τ+L}`（已消费部分不可重放）；
- **语义有效** 要求 `s_t` 与 `o_{t'}` 的指代一致性 `sim(s_t, o_{t'}) ≥ θ_s`。动作块只有在「时间有效 ∧ 语义有效」时才可执行。

**定义 123（通信剖面）**
通信剖面 `D = (F_τ, B, J, p_loss)`：`F_τ` 为单程延迟分布，`B` 为有效带宽（byte/s），`J` 为抖动上界，`p_loss` 为丢包率。工程上取 `τ_eff = F_τ^{-1}(0.95) + J` 作为证书用的保守延迟。

**定义 124（延迟诱导动作漂移）**
在核心动作集 `A_core` 上，
`Δ_τ(S,D) = sup_{a∈A_core} d_A( π_c(o_{t-τ},ℓ), π_e(o_t,ℓ) )`。
在 Lipschitz 假设下 `Δ_τ ≤ L_π·v_o·(τ+L/2) + ε_pred`，其中 `ε_pred` 为预测执行残差、`d_A` 为动作空间度量（可复用第 54 轮动作哈希索引）。

**定义 125（时效预算）**
任务要求时效预算 `Θ_τ = (TTL, ε_f, Θ_d, ε_d)`：
`P(t'-t-τ ≤ TTL) ≥ 1-ε_f`（保鲜）且 `P(Δ_τ ≤ Θ_d) ≥ 1-ε_d`（漂移）。二者缺一，证书不成立。

**定义 126（延迟感知联合证书）**
`J_τ = (J, τ_cert, fallback)`，其中
`τ_cert = (τ_eff, TTL, L, P_fresh, Δ_bound, s_hash)`，
`J` 为第 54 轮联合证书，`s_hash` 为语义意图哈希，`fallback` 为超时/失配时必可用的边端技能（其失败上界 `β_F`）。部署条件：
`dom_J(T)=in ∧ P_fresh ≥ 1-ε_f ∧ Δ_bound ≤ Θ_d ∧ τ_eff ≤ TTL ∧ fallback ≠ ⊥`。

## 2. 关键推导：最优动作块长

设块长 `L`（时间单位），单块传输字节 `b`，单位时间通信成本 `w_c·b/L`；漂移期望近似 `E[Δ]≈v·(τ+L/2)`，单位漂移成本 `w_d`。总成本
```
Cost(L) = w_d·v·(τ + L/2) + w_c·b/L
dCost/dL = w_d·v/2 - w_c·b/L² = 0
⇒ L* = sqrt( 2·w_c·b / (w_d·v) )
```
再叠加保鲜与实时约束：
```
L*_feasible = min( L*, 2·(TTL - τ_eff), L_max )
L*_feasible ≥ max( L_min, 2·(τ_eff - TTL) )   # 保证不会整块在到达前就过期
```
**结论**：在线性陈旧度模型下，`L*` 与 τ 无关；延迟通过可行域上限 `TTL-τ_eff` 起作用。因此在延迟升高时，优先应提高语义压缩率/放宽 TTL 或切换双系统，而不是盲目缩短块长（缩短反而放大通信开销并加剧抖动敏感性）。

## 3. 关键算法 伪代码

### IP-121 DAP（Delay-conditioned Action Profiling）

```python
def delay_conditioned_profile(skill, A, delays, sampler):
    alpha0 = action_profile(skill, A, sampler)      # 复用 IP-115
    kappa = {}
    for tau in delays:
        ok = 0
        for a in A:
            if alpha0[a] >= 0.8 and sampler.executes_within(skill, a, tau):
                ok += 1
        kappa[tau] = ok / max(1, len(A))
    return alpha0, monotone_envelope(kappa)          # 强制单调，向下包络
```

### IP-122 FWC（Freshness-Weighted Chunking）

```python
def choose_chunk_length(b, v, tau_eff, TTL, w_c, w_d, L_min, L_max):
    L_star = math.sqrt(2 * w_c * b / max(1e-9, w_d * v))
    upper = min(L_max, 2 * max(0.0, TTL - tau_eff))
    lower = max(L_min, 2 * max(0.0, tau_eff - TTL))
    if lower > upper:
        return None                                  # 时效预算不可满足，触发双系统降级
    return clamp(L_star, lower, upper)
```

### IP-123 DCX（Delay-Compensated Execution）

```python
def execute_with_compensation(c, now, W, sim_model, drift_budget):
    tau = now - c.t
    if tau > c.TTL or not semantic_valid(c.s, sim_model.observe(now)):
        return ('stale', c.t, tau)
    o_hat = W.predict(sim_model.observe(now - tau), tau)      # 前推到 now
    a = map_action(c.a_chunk, tau)                            # 消费剩余动作段
    resid = W.residual(sim_model.observe(now), o_hat)
    if resid > drift_budget:
        return ('drift', resid, fallback_skill(c.s))
    return ('ok', a, o_hat, resid)
```

### IP-124 S2S（System-2 / System-1 Arbitration）

```python
def arbitrate(c, now, D, G_S, edge_policy):
    tau_eff = quantile(D.F_tau, 0.95) + D.J
    fresh = c is not None and (now - c.t) <= c.TTL and semantic_valid(c.s, obs(now))
    if fresh and (now - c.t + tau_eff) <= c.TTL and D.B >= rate_needed(c):
        return ('cloud', c)                     # System 2：语义强、允许慢
    if can_local_expand(c.s, G_S, edge_policy):
        return ('edge_skill', select_skill(G_S, c.s))   # 语义 token -> 边端技能
    return ('edge_reactive', edge_policy(obs(now)))     # System 1：快而局部
```

### IP-125 LAC（Latency-Aware Certificate）

```python
def latency_certificate(J, skill_seq, D, Theta_tau, W):
    tau_eff = quantile(D.F_tau, 0.95) + D.J
    L = choose_chunk_length(...)
    if L is None:
```

### IP-126 LEX（Latency Explain 回传）

```python
def explain_latency_failure(sim_model, D, cert, observed):
    causes = []
    if observed.stale_rate > cert.eps_f:      causes.append(('stale', 'raise_compression'))
    if observed.drift > cert.Theta_d:         causes.append(('drift', 'tighten_L_update_W'))
    if observed.semantic_mismatch > 0:        causes.append(('decompress_ambiguity', 'send_explicit_refs'))

```

## 4. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| DAP | O(|A|·|𝒯_τ|·|S|) | O(|A|·|𝒯_τ|) | 时效核单调、延迟分层覆盖 |
| FWC | O(1) | O(1) | 成本模型凸、约束闭合 |
| DCX | O(|τ_max|·C_W) | O(|τ_max|) | 预测残差可观测、语义校验前置 |
| S2S | O(log|V| + |E|) | O(|V|+|E|) | 降级路径必达、G_S 可检索 |
| LAC | O(|S|·|𝒯_τ|) | O(|S|) | 保守 τ_eff、漂移上界 sound |
| LEX | O(|causes|) | O(1) | 根因可区分、回传有界 |

**正确性定理（Latency-Aware VLA Deployment Soundness）**
假设第 54 轮 (A26)–(A28) 成立；新增：
**(A29)** `α_S,κ_S` 在延迟分层仿真下校准，单调包络成立；
**(A30)** 云端口令 `π_c` 对状态 Lipschitz（常数 `L_π`），状态速度上界 `v_o`；
**(A31)** 边端世界模型在预报时域 `τ_max` 内残差 `≤ ε_pred`；
**(A32)** 降级技能必存在且失败概率 `≤ β_F`。
则对满足 `J_τ` 条件的任务：
```
P_success ≥ 1 - ε_f - ε_d - β_E - β_F - P(τ_eff > TTL)
```
其中 `ε_f, ε_d` 由定义 125 的时效预算给出，`β_E` 为第 53 轮解释误差项。证明要点：将失败事件拆为「保鲜失败」「漂移超界」「规划/解释错误」「降级失败」四类互斥上界；漂移项由 A30/A31 的 Lipschitz 链给出，`τ_eff` 用 P95+J 保守化。

## 6. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 延迟分布非平稳、P95 估计漂移 | 高 | 在线分位数估计 + 滑动窗口 + 保守上界 |
| VLA 语义 token 在边端解压歧义 | 高 | 显式指代绑定 + `sim(s,o)≥θ_s` 硬门 + 回退技能 |
| 预测世界模型误差在长延迟下累积 | 高 | 限制 `τ_max`、残差触发回退、双模型投票 |
| 块长切换引发执行抖动 | 中 | 滞回 + 块重叠过渡 + 时钟同步 |
| LEX 回传在弱网下拥塞 | 中 | 根因压缩 + 令牌桶限速 + 优先级队列 |
| 双系统切换语义不一致 | 高 | 共享意图本体 + 切换时强制语义对齐检查 |

## 7. 本轮最大风险

**一句话**：把通信延迟纳入动作剖面与联合证书，能把「VLA 动作过期」从工程抖动变成可判定预算，但它的 soundness **同时依赖延迟尾部分布的可估、语义 token 在边端可无歧义解压、以及预测世界模型在 τ_max 内残差有界**；一旦 P95 被低估或语义解压产生系统性指代漂移，证书会在弱网下给出虚假的「保鲜」承诺，导致 VLA 动作大面积语义错位，故必须以 **尾部延迟保守上界 + 语义一致性硬门 + 预测残差回退** 三重护栏，宁可提前降级到边端局部策略，也不把「低延迟假象」当作部署前提。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim+++τ（DAP×FWC×DCX×S2S×LAC×LEX）

> 承接第 54 轮产物 v31。第 54 轮解决「技能动作空间 + 鲁棒性」的双证书，并假设云边同步。本轮把**通信延迟**与**VLA（视觉语言动作模型）**纳入体系，新增六个算子：
> - **DAP（Delay-conditioned Action Profiling）**：延迟条件动作剖面 `α_S(a|τ)` 与时效核 `κ_S`；
> - **FWC（Freshness-Weighted Chunking）**：动作块长的闭式最优与保鲜约束；
> - **DCX（Delay-Compensated Execution）**：预测执行 + 残差回退，压低延迟诱导漂移；
> - **S2S（System-2/System-1 Arbitration）**：云端语义规划与边端反应执行的时效仲裁；
> - **LAC（Latency-Aware Certificate）**：在联合证书 `J` 上增加 `τ_cert` 与 `fallback`；
> - **LEX（Latency Explain）**：延迟故障根因压缩回传，驱动块长/压缩率/粒度重配置。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-115/116/117/118 以纳入延迟维度。

| 符号 | 含义 |

| `c=(o_t,ℓ,s_t,a_{t:t+L},t,h)` | 带语义戳的 VLA 动作块 |
| `f_c(t')` | 动作块新鲜度 |

| `Δ_τ` | 延迟诱导动作漂移 |
| `Θ_τ=(TTL,ε_f,Θ_d,ε_d)` | 时效预算 |

| `L*` | 最优动作块长 |

## 2. 关键推导：带宽-陈旧度折中

```
Cost(L) = w_d·v·(τ + L/2) + w_c·b/L
dCost/dL = w_d·v/2 - w_c·b/L² = 0
L* = sqrt( 2·w_c·b / (w_d·v) )

可行性：
L*_feasible = min( L*, 2(TTL-τ_eff), L_max )
              ≥ max( L_min, 2(τ_eff-TTL) )
```
**解读**：在「漂移随时域线性增长」的一阶模型里，最优块长与 τ 无关；延迟主要压缩可行域上界。因此延迟升高时，正确动作是**提高语义压缩率 / 放宽 TTL / 切换双系统**，而不是简单缩短块长（那会放大通信频率并加剧抖动敏感）。当 `2(TTL-τ_eff) < L_min` 时，时效预算不可满足，直接触发降级。

**语义压缩收益**：细动作信道需求 `R_a ≥ H(a|o,ℓ)/L`，语义信道需求 `R_s ≥ H(s|o,ℓ)/L`。经验上 `H(s) ≪ H(a)`，故低带宽下传输 `s` 并由边端在技能图 `G_S` 上展开，可把可达延迟上限提高数倍，代价是引入解压歧义 `sim(s,o) ≥ θ_s` 门控。

### IP-121 DAP

```python
def delay_conditioned_profile(skill, A, delay_grid, sampler):
    alpha0 = {}
    for a in A:
        alpha0[a] = sampler.occupancy(skill, a)          # 复用 IP-115
    kappa = {tau: 0.0 for tau in delay_grid}
    for tau in delay_grid:
        ok = sum(1 for a in A
                 if alpha0[a] >= 0.8 and sampler.executes_within(skill, a, tau))
        kappa[tau] = ok / max(1, len(A))
    kappa = monotone_envelope(kappa, nonincreasing=True)  # 向下包络，保证 sound
    return alpha0, kappa

def profile_tau(alpha0, kappa, a, tau):
    return alpha0[a] * kappa[tau]
```

### IP-122 FWC

```python
def choose_chunk_length(D, b, v, TTL, w_c, w_d, L_min, L_max):
    tau_eff = quantile(D.F_tau, 0.95) + D.J
    L_star = math.sqrt(2 * w_c * b / max(1e-9, w_d * v))
    upper = min(L_max, 2 * max(0.0, TTL - tau_eff))
    lower = max(L_min, 2 * max(0.0, tau_eff - TTL))
    if lower > upper:
        return None, tau_eff                 # 不可满足 -> S2S 降级
    return clamp(L_star, lower, upper), tau_eff
```

### IP-123 DCX

```python
def execute_with_compensation(c, now, W, obs_fn, Theta_d):
    tau = now - c.t
    if tau > c.TTL:
        return Fail('stale', tau, fallback_skill(c.s))
    o_now = obs_fn(now)
    if semantic_sim(c.s, o_now) < THETA_S:
        return Fail('semantic_drift', tau, fallback_skill(c.s))
    o_hat = W.predict(obs_fn(now - tau), tau)
    a = consume_chunk(c.a_chunk, offset=tau)
    resid = W.residual(o_now, o_hat)
    if resid > Theta_d:
        return Fail('prediction_residual', resid, fallback_skill(c.s))
    return Ok(a, frame=o_hat, residual=resid)
```

### IP-124 S2S

```python
def arbitrate(c, now, D, G_S, edge_policy, cert):
    tau_eff = quantile(D.F_tau, 0.95) + D.J
    fresh = c is not None and (now - c.t) <= c.TTL
    semantic_ok = fresh and semantic_sim(c.s, obs(now)) >= THETA_S
    if semantic_ok and (now - c.t + tau_eff) <= c.TTL and D.B >= cert.rate_needed:
        return ('cloud_vla', c)                        # System 2
    if c is not None and can_local_expand(c.s, G_S):
        return ('edge_skill', select_skill(G_S, c.s))  # 语义 token -> 技能
    return ('edge_reactive', edge_policy(obs(now)))    # System 1
```

### IP-125 LAC

```python
def latency_certificate(J, skill_seq, D, Theta_tau, W):
    L, tau_eff = choose_chunk_length(D, b=payload_bytes(skill_seq), v=MAX_V,
                                     TTL=Theta_tau.TTL, ...)
    if L is None:
        return Reject('freshness_budget_infeasible', tau_eff)
    p_fresh = empirical_freshness(skill_seq, D, L)      # 离线仿真 + 在线滚动校准
    delta_bound = (L_pi * v_o * (tau_eff + L / 2)
                   + W.eps_pred)
    if p_fresh < 1 - Theta_tau.eps_f:
        return Reject('freshness_prob_low', p_fresh)
    if delta_bound > Theta_tau.Theta_d:
        return Reject('drift_bound_exceeded', delta_bound)
    tau_cert = (tau_eff, Theta_tau.TTL, L, p_fresh, delta_bound, hash_intent(skill_seq))
    return Ok(JointCertTau(J, tau_cert, fallback=guaranteed_fallback(skill_seq)))
```

### IP-126 LEX

```python
def explain_latency_failure(sim, D, cert, observed):
    causes = []
    if observed.stale_rate > cert.eps_f:
        causes.append(('stale', 'raise_compression_or_TTL'))
    if observed.drift > cert.Theta_d:
        causes.append(('drift', 'update_W_or_switch_edge'))
    if observed.semantic_mismatch > 0:
        causes.append(('decompress_ambiguity', 'bind_explicit_referents'))
    if D.B < cert.rate_needed:
        causes.append(('bandwidth', 'semantic_only_mode'))
    return {'t': now, 's_hash': cert.s_hash,
            'causes': causes, 'delay_p95': quantile(D.F_tau, 0.95)}
    # 只回传根因 + 时间戳 + 统计量，禁止回传全轨迹（弱网拥塞）
```

## 4. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| DAP | O(|A|·|𝒯_τ|·|S|) | O(|A|·|𝒯_τ|) | 时效核单调包络，分层覆盖 |
| FWC | O(1) | O(1) | 成本凸、约束闭合 |
| DCX | O(τ_max·C_W) | O(τ_max) | 残差可观测、语义门前置 |
| S2S | O(log|V|+|E|) | O(|V|+|E|) | 降级路径必达 |
| LAC | O(|S|·|𝒯_τ|) | O(|S|) | 保守 τ_eff、漂移上界 sound |
| LEX | O(|causes|) | O(1) | 根因可区分、回传有界 |

**正确性定理（Latency-Aware VLA Deployment Soundness）**
假设第 54 轮 (A26)–(A28) 成立；新增 (A29) 时效核与剖面经延迟分层校准；(A30) `π_c` 状态 Lipschitz、环境速度有界；(A31) 世界模型预报残差 `≤ ε_pred`；(A32) 降级技能存在且失败概率 `≤ β_F`。则
```
P_success ≥ 1 - ε_f - ε_d - β_E - β_F - P(τ_eff > TTL)
```
**证明要点**：失败事件划分为 `E_fresh ∪ E_drift ∪ E_plan ∪ E_fallback ∪ E_τ`。`P(E_fresh)≤ε_f` 由预算定义；`P(E_drift)≤ε_d` 由 A30/A31 的 Lipschitz 链与 `Δ_bound≤Θ_d` 保证；`E_plan` 由第 53 轮 `β_E` 覆盖；`E_fallback` 由 A32；`E_τ` 由 `τ_eff` 保守分位数。取并集上界即得。

**与第 54 轮的关系**：令 `τ≡0, L→0, D→(δ_0,B→∞)`，则 `κ_S(0)=1`、`LAC` 退化为 `AEC`，定理退化为第 54 轮结论，故本轮是严格扩展而非替换。

**离线合成预实验（玩具 2D 抓取 + 模拟网络，N=500，仅用于 sanity check，非真实 VLA 结论）**

| 配置 | τ=0 | 50ms | 100ms | 200ms | 400ms |

## 7. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 延迟分布非平稳、P95 漂移 | 高 | 在线分位数 + 滑动窗口 + 保守上界 |
| 语义 token 解压歧义 | 高 | 显式指代绑定 + `sim≥θ_s` 硬门 + 回退 |
| 预测模型误差累积 | 高 | 限制 τ_max + 残差回退 + 双模型投票 |
| 块长切换抖动 | 中 | 滞回 + 块重叠 + 时钟同步 |

| 双系统语义不一致 | 高 | 共享意图本体 + 切换强制对齐 |

## 8. 本轮最大风险

**一句话**：把通信延迟纳入动作剖面与联合证书，能把「VLA 动作过期」从工程抖动变成可判定预算，但它的 soundness **同时依赖延迟尾部分布的可估、语义 token 在边端可无歧义解压、以及预测世界模型在 τ_max 内残差有界**；一旦 P95 被低估或语义解压产生系统性指代漂移，证书会在弱网下给出虚假的「保鲜」承诺，导致 VLA 动作大面积语义错位，故必须以 **尾部延迟保守上界 + 语义一致性硬门 + 预测残差回退** 三重护栏，宁可提前降级到边端局部策略，也不把「低延迟假象」当作部署前提。
