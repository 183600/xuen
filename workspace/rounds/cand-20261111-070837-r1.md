# 第 55 轮（承接第 54 轮 v16++；灵感循环第 6 轮；本轮灵感：「演示方案」×「迭代验证」）

> 第 54 轮把技能与协同推进到“动作-鲁棒性双证书”，但整套证书体系仍停留在**定义层**：证书“sound”与否不可被观测、不可被证伪。本轮转向**方法论层**，用「演示方案」给每个证书绑定可执行的演示义务，用「迭代验证」把演示失败反灌为证书细化。核心矛盾：**H22：证书只声明“应当成立”，却未规定“用哪次演示、哪个可观测量、多少样本才可判定成立”，使 soundness 沦为不可证伪的修辞**；**H23：若迭代只做“失败就收窄定义域”，循环必然收敛，但可能收敛到“永远正确且永远无用”的空洞证书，或只对演示分布成立的过拟合证书**。

## 0. 直觉与动机

**灵感 1（证书 = 可证伪的演示义务）**
直觉：一个证书 `C` 若不能被一次演示“打脸”，它就没有信息量。于是要求每个证书声明 `φ_C`（如 `ρ_d ≥ ρ_min`、`δ_a < Θ_a`）都投影为一组**演示义务** `O(C)`：每条义务规定“在哪个分布 `D_o` 上、观测哪个量 `ψ_o`、采集多少样本 `n_o`、达到多少置信 `α_o` 才算通过”。这把“我觉得 sound”变成“这些演示都通过且反例为零”。证书的强度不再由公式长度决定，而由**它敢承诺的可证伪程度**决定。

**灵感 2（演示方案 = 分级演示阶梯）**
直觉：演示不应一步到位跳到真实场景，而应像验收一样分层放行：`𝕃_0` 静态台架（单技能、单动作）→ `𝕃_1` 结构化仿真（多技能组合、动作剖面标定）→ `𝕃_2` 真实桌面（云边映射、时延）→ `𝕃_3` 动态扰动（对抗动作、遮挡）→ `𝕃_4` 红队演示（主动搜索反例）。**上一级全部义务通过，才解锁下一级**；这既控制演示成本，又保证“强结论必须由更强的演示支撑”。

**灵感 3（迭代验证 = 证伪驱动的细化循环）**
直觉：每次演示失败 `f=(episode, observable, context)` 都不是“再跑一遍”，而是对证书做一次**单调细化** `FRO(C,f)`：要么收窄定义域（把失败上下文排除出承诺范围），要么抬高阈值（把 `ρ_min` 收紧）。二者都只让证书**更弱但更真**，绝不允许“调参把失败盖过去”。循环 `C_0 →(演示)→ C_1 → … → C*` 直到在该演示分布上反例为零。

**灵感 4（收敛判据 = 覆盖-强度前沿，而非“零失败”）**
直觉：“演示零失败”是必要不充分条件——把定义域收成一个点也能零失败。因此引入**非空洞约束**：在**覆盖-强度前沿** `DCF` 上，要求最终证书 `C*` 同时满足 `cov(C*) ≥ cov_min`（覆盖不能塌缩）与 `str(C*) ≥ str_target`（强度不能注水）。只有落在前沿非空区间的 `C*` 才允许部署，否则判为**空洞证书**并由 `VCC` 拦截。

**灵感 5（元循环：研究者 = 云端，演示机器人 = 边端）**
直觉：第 54 轮的“云规划-边校验-反向解释-重剖分”闭环，其实是**任何验证过程**的模板。把“研究者/理论侧”当云端、“演示/硬件侧”当边端，则演示失败就是反向解释，证书细化就是重剖分。于是本轮得到的不是又一个证书，而是**生产证书的元算法**：证书体系从此自带“如何被推翻”的说明书。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（演示义务）**
对证书 `C` 的可证伪声明 `φ_C`，其演示义务 `o = (D_o, ψ_o, n_o, α_o)`：`D_o` 为演示分布，`ψ_o` 为可观测量上的判定谓词（`ψ_o=1` 表示该次演示支持 `φ_C`），`n_o` 为样本数，`α_o` 为置信水平。`C` 在等级 `α` 下**已被演示**当且仅当对 `∀ o∈O(C)`，经验反例率 `\hat{p}_o ≤ 1-α_o`。`O(C)` 完整（obligation-complete）当且仅当 `φ_C` 中每个自由变量都被至少一条 `ψ_o` 观测到。

**定义 122（演示方案）**
演示方案 `DS = (𝕃, {O_l}_{l=0..4}, Π, B)`：`𝕃` 为五级演示阶梯；`O_l` 为第 `l` 级义务集；`Π` 为执行协议（顺序、重置、日志）；`B` 为预算（次数、时长、样本）。**放行规则**：`gate(l) = 1` 当且仅当 `∀ l'≤l, O_{l'}` 全部通过且 `cost(Π) ≤ B`。

**定义 123（证伪驱动细化算子 FRO）**
`FRO(C,f) → C'`，`f=(episode, ψ, context)` 为一次失败。两种合法动作：
1. **域收窄**：`dom(C') = dom(C) \ N(context)`，其中 `N` 为失败邻域；
2. **阈值收紧**：`Θ(C') = Θ(C) + η`（`η>0`）。
要求**单调性** `C' ⪯ C`（`dom' ⊆ dom` 且 `Θ' ≥ Θ`），禁止任何放宽动作。`C` 与 `C'` 的证据集满足 `evidence' ⊇ evidence ∪ {f}`。

**定义 124（迭代验证不动点）**
序列 `C_{k+1}=FRO(C_k, f_k)`，`f_k` 为第 `k` 轮在第 `l(k)` 级演示中采到的反例。若某轮无新反例或 `k ≥ K_max` 则停止；称 `C*` 为**演示不动点**，当 `∀ f ~ DS, FRO(C*,f)=C*`。记收敛轮数 `K(C_0, DS)`。

**定义 125（覆盖-强度前沿 DCF）**
对证书 `C*`，覆盖 `cov(C*) = vol(dom(C*)) / vol(dom(C_0))`，强度 `str(C*) = 1 - Σ_d(1-ρ*_d) - β_E`（其承诺的成功下界）。演示方案在 `(cov, str)` 平面的可行集为 `𝔇 = {(cov, str)}`，前沿 `DCF = Pareto(𝔇)`。部署准入要求 `C* ∈ DCF` 且 `cov(C*) ≥ cov_min`、`str(C*) ≥ str_target`。

**定义 126（空洞证书与拦截器 VCC）**
若 `cov(C*) < cov_min` 或 `dom(C*)` 为空或 `str(C*)` 仅靠“排除全部困难上下文”获得，称 `C*` **空洞（vacuous）**。`VCC(C*) = block` 当且仅当 `C*` 空洞或 `C*` 在留出演示集 `D_holdout` 与对抗演示集 `D_adv` 上反例率 > `θ_v`。

## 2. 关键算法 伪代码

### IP-121 DOP（演示义务投影）

```python
def project_obligations(cert):
    obs = []
    for claim in cert.claims:            # e.g. ρ_d ≥ ρ_min, δ_a < Θ_a
        for var in free_vars(claim):     # 每个自由变量必须可观测
            psi = make_predicate(claim, var)
            obs.append(Obligation(D_o=claim.domain,
                                  psi=psi, n_o=sample_size(claim, var),
                                  alpha_o=claim.conf))
    assert all(o.observable for o in obs), "obligation incomplete"
    return obs
```

### IP-122 DSL（演示阶梯放行）

```python
def run_demo_scheme(ds, cert):
    for l in range(5):
        for o in ds.O[l]:
            stats = execute(ds.Pi, o)          # demos on level l
            if empirical_fail_rate(stats) > 1 - o.alpha:
                return ('fail', l, o, stats)   # gate stays closed
        if not ds.gate(l):
            return ('blocked', l)
    return ('pass', cert)
```

### IP-123 DVL（演示-验证迭代循环）

```python
def demo_validation_loop(C0, DS, K_max=8):
    C, hist = C0, []
    for k in range(K_max):
        res = run_demo_scheme(DS, C)
        if res[0] == 'pass':
            if not vacuous(C, DS.cov_min, DS.str_target):
                return ('converged', C, k)
            return ('vacuous', C, k)          # 零失败但无用
        f = next_falsifier(res)               # 选取最具信息量的反例
        C = FRO(C, f)                         # 单调细化
        hist.append((k, f, C.domain_size, C.theta))
    return ('non_converged', C, K_max)
```

### IP-124 FRO（证伪驱动细化）

```python
def FRO(C, f):
    if f.failure_type == 'context':
        C2 = shrink_domain(C, f.context, f.neighborhood)
    elif f.failure_type == 'magnitude':
        C2 = tighten_threshold(C, eta=f.margin)
    else:
        raise ValueError('unsupported falsifier')
    assert C2 <= C, "FRO must be monotone (no weakening)"
    C2.evidence = C.evidence | {f}
    return C2
```

### IP-126 VCC（空洞证书拦截）

```python
def vacuous(C, cov_min, str_target):
    if volume(C.domain) == 0: return True
    if coverage(C) < cov_min: return True
    if strength(C) < str_target: return True
    if fail_rate(C, D_holdout) > theta_v: return True
    if fail_rate(C, D_adv) > theta_v: return True
    return False
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| DOP | O(|claims|·|vars|) | O(|O(C)|) | 义务完整、谓词可观测 |
| DSL | O(Σ_l |O_l|·n_o) | O(|𝕃|) | 放行单调、预算闭合 |
| DVL | O(K·Σ|O|·n) | O(K·|C|) | FRO 单调、K_max 有界 |
| FRO | O(|dom|) | O(|f|) | 只收窄/收紧，绝不放宽 |
| VCC | O(|D_holdout|+|D_adv|) | O(|C|) | 非空洞 + 分布移检测 |

**正确性定理（Demonstration-Grounded Certificate Soundness）**
假设第 54 轮 (A26)–(A28) 成立；本轮新增：**(A29)** 演示分布 `D` 与部署分布 `P` 的 TV 距离 `||D-P||_TV ≤ ε`；**(A30)** 义务完整（证书每个可证伪声明都有可观测 `ψ_o`）；**(A31)** `FRO` 单调（只收窄/收紧，绝不放宽）；**(A32)** 演示样本 i.i.d. 来自 `D`。
则当 `DVL` 在 `D` 上以零反例收敛到 `C*`、共 `N` 条演示样本时，以概率 `≥ 1-δ`：

```
P_P(fail) ≤ ε + Σ_d(1-ρ*_d) + β_E + P(δ_a > Θ_a) + sqrt(ln(1/δ)/(2N))
```

其中前三项是证书的结构性残差（承接第 54 轮），`ε` 是演示-部署分布鸿沟，末项是零失败的统计不确定性。**关键洞察**：`ε` 无法从演示内部估计，只能由留出/对抗/两样本检验给出代理上界——这正是本方案最脆弱处。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 演示过拟合（只对 `D` 成立） | 高 | 留出集 + 对抗演示 + 两样本漂移检测 |
| 证书空洞化（域塌缩） | 高 | VCC 非空洞门 + DCF 前沿准入 |
| 义务不可观测/不可测 | 中 | 观测性审计 + 埋点 + 拒收不可测声明 |
| 迭代震荡/不收敛 | 中 | FRO 单调 + K_max + 冷启动锚点 |
| `ε` 不可直接估 | 高 | `ε` 代理上界 + 分布移绊线 + 保守放大 |

## 6. 本轮最大风险

**一句话**：演示-迭代循环可以把“零演示失败”做成一个**看似收敛、实则空洞或过拟合**的证书——要么把定义域收窄到“永远正确、永不落地”，要么只对演示分布成立而在部署分布 `P` 上系统性失效；而二者之间的鸿沟 `ε = ||D-P||_TV` 在演示内部**原理上不可测**，因此本方案的最大风险不是“证明太难”，而是把 Goodhart 式的“演示过关”误当成“部署可信”，必须以**留出/对抗演示 + 非空洞门 + 分布移绊线**三重护栏，宁可交付一份标着“未验证”的诚实证书，也不签发一张演示幻觉的通行证。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-Verify（DOP×DSL×DVL×FRO×DCF×VCC）

> 承接第 54 轮产物 v31。本轮不新增“更强的证书”，而是新增**证书的生产与验收线**：
> - **DOP（Demonstration Obligation Projection）**：把证书声明投影为可观测、可证伪的演示义务；
> - **DSL（Demonstration Scheme Ladder）**：五级演示阶梯与放行门；
> - **DVL（Demonstration-Validation Loop）**：演示→证伪→细化的迭代验证机；
> - **FRO（Falsification-driven Refinement Operator）**：保证单调的证书细化算子；
> - **DCF（Demo-Coverage Frontier）**：覆盖-强度前沿，防证书注水；
> - **VCC（Vacuous-Certificate Checker）**：空洞证书拦截器。
>
> IP 编号：IP-121~IP-126（共 6 个新增）；升级 IP-118/120，使其输出可被 DOP 投影的义务。

```python
def gate(level, ds, cert):
    for l in range(level+1):
        for o in ds.O[l]:
            if empirical_fail_rate(run(ds.Pi, o)) > 1 - o.alpha:
                return False
    return cost(ds.Pi) <= ds.B
```

### IP-123 DVL

```python
def DVL(C0, ds, K_max=8):
    C = C0
    for k in range(K_max):
        res = run_demo_scheme(ds, C)
        if res[0] == 'pass':
            return ('converged' if not VCC(C, ds) else 'vacuous', C, k)
        C = FRO(C, pick_most_informative(res.failures))
    return ('non_converged', C, K_max)
```

```python
def FRO(C, f):
    if f.type == 'context':
        C2 = shrink_domain(C, f.context, f.neighborhood)
    else:

    assert C2 <= C
```

### IP-125 DCF

```python
def frontier(certs):
    pts = [(coverage(c), strength(c)) for c in certs if not VCC(c)]
    return pareto_max(pts)   # cov 与 str 同时不劣

def admits(C, dcf, cov_min, str_target):
    return (coverage(C), strength(C)) in dcf and \
           coverage(C) >= cov_min and strength(C) >= str_target
```

### IP-126 VCC

```python
def VCC(C, ds):
    if volume(C.domain) == 0: return True
    if coverage(C) < ds.cov_min: return True
    if strength(C) < ds.str_target: return True
    return (fail_rate(C, ds.D_holdout) > ds.theta_v or
            fail_rate(C, ds.D_adv) > ds.theta_v)
```

| DOP | O(|claims|·|vars|) | O(|O|) | 义务完整、谓词可观测 |
| DSL | O(Σ_l |O_l|·n_o) | O(|𝕃|) | 放行单调、预算闭合 |
| DVL | O(K·Σ|O|·n) | O(K·|C|) | FRO 单调、K 有界 |
| FRO | O(|dom|) | O(|f|) | 只收窄/收紧 |
| DCF | O(|certs| log|certs|) | O(|certs|) | Pareto 非劣 |
| VCC | O(|D_holdout|+|D_adv|) | O(|C|) | 非空洞 + 漂移检测 |

**正确性定理（Demonstration-Grounded Certificate Soundness）**
假设 (A26)–(A28) 承接第 54 轮，(A29)–(A32) 为本轮新增（`ε-接近`、义务完整、FRO 单调、i.i.d.）。DVL 在 `D` 上零反例收敛到 `C*`、样本数 `N` 时，以概率 `≥1-δ`：
```
P_P(fail) ≤ ε + Σ_d(1-ρ*_d) + β_E + P(δ_a>Θ_a) + sqrt(ln(1/δ)/(2N))
```
**结论**：演示零失败只能把结构残差之外的统计项压到 `O(1/√N)`，**压不掉 `ε`**。因此 `ε` 的代理上界（留出/对抗/两样本）是整套体系的真正瓶颈。

## 6. 本轮最大风险

**一句话**：演示-迭代可以稳定产出“零失败证书”，但零失败既可能来自真实可靠，也可能来自**定义域塌缩（空洞）**或**演示分布过拟合**；由于 `ε=||D-P||_TV` 在演示内部不可测，本轮最大风险是把 Goodhart 式的“演示过关”当作“部署可信”，必须以留出/对抗演示、非空洞门、分布移绊线三重护栏，守住“宁可标未验证，不签发演示幻觉”。
