# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「自主导航」×「上下文理解」）

> R69 教会系统「问」：把 epistemic 歧义显式摆出来，用 VoI 选择看/触/问去消解。但它和 R68 共享一个从未言明的前提：**系统已经知道自己身处哪个「世界」**——动力学、安全包络、动作语义都属于同一个上下文。R69 的不确定性是「同一世界内的动作歧义」，它从不怀疑**世界本身可能选错了**。
>
> 这正是「上下文理解」要补的洞。真实部署中，同一个观测在不同上下文里含义相反：空旷走廊里「加速直行」是高效，拥挤市场里同一动作是危险；医院里「靠近」是帮助，车站里「靠近」是侵扰。更致命的是，**上下文误判是「模型未识别」的**——系统不觉得自己有歧义，U_epi 很低、VoI 很低，于是自信地做错事。R69 的不确定性估计器对此完全失明：**未知的未知，根本不在它的后验里**。
>
> 「自主导航」提供了独一无二的解药：**上下文往往不是局部可读的，而是空间分布、需要移动才能读到**。门牌、人群密度、地面材质、声音景观、地标，只在特定位置可观测。于是「搞清楚我在哪类环境」本身可以是一个导航子目标——R69 的 VoI 从「问一句」升级为「走一段去亲眼看看」。
>
> 核心命题：**在 R68/R69 的两级不确定性（aleatoric / epistemic）之外，加入第三级——上下文级（meta-epistemic）不确定性 U_ctx：不是「该选哪个动作」，而是「我在哪个世界」。用「安全等价上下文抽象」把假设集压到可处理；用「跨上下文鲁棒安全包络」保证识别完成前不越界；用「上下文可观测性地图 + 主动导航取证」在预算内识别；识别后按上下文分派回 R69/R68，未识别则停在交集安全集内。** 命名 **LUCID-RAS**（Latent-context Uncertainty-aware Identification & Decision for Risk-Adaptive Safety）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我到底在哪个世界、这些证据足以证明吗**」——不确定性从动作层、测量层升到**世界模型层**。

## 0. 直觉与动机

**灵感 1（上下文理解 → 第三级不确定性：不是动作错，是世界观错）**
直觉：R69 的 U_epi = H(模态)，它默认所有模态共享同一个动力学与安全包络。但真实错误常常不是「动作选错」，而是「用错了世界的规则」。上下文 c 决定三样东西：f_c（动力学）、S_c（安全集）、π_c（行为先验）。若 c 判错，即使每个动作在「自认为的 c」下都最优，在真实 c* 下也可能灾难。关键区别：U_epi 是**可被模型自己看见**的（多峰），U_ctx 是**模型看不见**的（单峰但错峰）。所以 R70 的核心不是「更会估不确定性」，而是**给不确定性估计器本身加一个元层：我的假设集里有没有真相？**

**灵感 2（自主导航 → 上下文是空间分布的，移动即取证）**
直觉：对话里问一句就能消歧；导航里「我在哪类环境」的答案常常只写在**某个地方**：走到门口看标牌、靠近人群听声音、上一段坡看地面、回到已知地标做重定位。上下文不是均匀可观测的，而是有**见证点（witness）**。这把 R69 的信息动作从「原地看/问」扩展为「规划一条去见证点的轨迹」，且这条轨迹本身必须在所有可能上下文下都安全。导航由此不只是被控制的对象，而是**主动上下文识别的传感器**。

**灵感 3（安全等价抽象 → 只有「改变安全集」的上下文区别才值得花钱）**
直觉：上下文假设集组合爆炸，且很多区别与安全无关（墙是米色还是灰色）。若把上下文按「安全集 + 策略先验 + 闭环可达集」做等价类，得到商空间 𝒞/~；同一等价类内的差别**不值得**任何交互/导航预算。更妙的是，这直接处理最危险的情形——**上下文混叠（aliasing）**：两个上下文观测上几乎相同，但如果安全集相同，混叠无害；只有**安全关键混叠**（观测不可分、安全集却不同）才是真威胁，也正是必须花预算导航取证之处。这把「可处理性」与「该关注什么」合并成一个抽象操作。

**灵感 4（跨上下文鲁棒包络 → 识别前绝不「自信地错」）**
直觉：R69 在消歧成功后才敢放宽（resolution bonus）。R70 同理但更强：在 U_ctx 未消解前，动作必须对**所有仍可能的上下文**都满足风险约束——即落在交集/鲁棒包络内。这不是「更保守的 λ」，而是**换了一个可行集**：若交集为空，唯一合法动作是「停/取证/退回已知安全锚点」，而不是「随便选一个然后慢一点」。这正面回应 R69 的最大风险：R69 会自信地追问幻影；R70 连「自信」这个状态本身都要先证明自己配得上。

**灵感 5（上下文漂移与切换抖动 → 新的时序威胁）**
直觉：上下文会变（门开了、人群聚集、白天转夜晚），且**在边界处会来回抖**。若每帧都重新识别，机器人会在两个包络间振荡（chattering），既不安全也不舒适。需要迟滞、切换成本、变点检测，以及「上下文一旦确立仍要能被独立证据再次证伪」。这把 R68 的慢漂移、R69 的单次交互纪律，统一到**上下文级的时间一致性**上。

## 1. 形式化定义（增量：定义 310–330）

**定义 310（LUCID-RAS 总览）** LUCID-RAS = (CHS, CSA, RSE, COM, NIC, CCM, MCD, RAS-WM‡)。四个不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **分层退化**：单例上下文且标定可信 ⇒ 逐指令退化为 FLUID，进而退化为 CALM；
(iii) **识别前鲁棒**：U_ctx 未消解时，任何任务动作必须属于所有仍可能上下文的交集安全集；
(iv) **上下文证据纪律（元层）**：上下文判定至少需两条正交「可读线索」（视觉地标 / 声学 / 人群动力学 / 地图先验）一致，单一线索不得翻转上下文。

**定义 311（上下文假设集 CHS）** 上下文 c ∈ 𝒞_t = {c_1,…,c_N}，每个含五元组 (f_c, S_c, π_c, h_c, L_c)：动力学、安全集（状态-动作约束集）、行为先验、观测模型、可读线索集。赋予先验 b_0(c)，并允许开集项 c_∅（「不在已知集内」）。

**定义 312（上下文证据与可读性）** 证据 e ∈ ℰ 由线索生成 e = φ_c(x_t) + noise；线索在空间上的可读区域 W_c(e) ⊂ 𝒳（见证区域）。可读性 ρ_c(x) = P(线索可分辨 | 位于 x)。上下文似然 p(o_t | c) 由 h_c 与 L_c 给出。

**定义 313（上下文级不确定性 U_ctx）** 闭集版 U_ctx = H(b_t)；但实际使用须按安全相关性加权（定义 326）。开集版 U_nov = −log p_θ(o_t | ∪_{c∈𝒞} h_c)（所有已知上下文都解释不了的「新颖度」）。二者语义不同：闭集问「选哪个」，开集问「是不是一个都不对」，绝不混算。

**定义 314（鲁棒安全包络 RSE）** 对阈值 δ，可行上下文集 𝒞_δ = {c : b_t(c) ≥ δ}；鲁棒包络 S_robust = ∩_{c∈𝒞_δ} S_c。动作 a 合法 ⇔ a ∈ S_robust 且对每个 c∈𝒞_δ 的风险 ≤ ε。若 S_robust = ∅ ⇒ 仅允许 {stop, seek_info, retreat_to_anchor}。注意这是**集合级**而非标量级保守：它同时约束了不同上下文下互不相同的可行动作，严格强于「取最大 λ」。

**定义 315（安全等价上下文抽象 CSA）** 定义等价关系 c ~ c′ ⇔ (S_c = S_{c′}) ∧ (π_c 的模态支撑相同) ∧ (f_c 的闭环可达集在 ε 内相同)。商空间 𝒞/~ 的元素称**上下文型（context type）**。只有跨 context type 的区别才进入 U_ctx^s 与 VoI 计算；同型内部区别被抽象掉。⇒ 同时获得可处理性，并只关注安全关键歧义。

**定义 316（安全关键混叠）** 两上下文 c ≠ c′ 称**安全关键混叠**，若 (i) 在当前可及范围内观测分布的总变差距离 ‖P_c − P_{c′}‖_TV < ε_obs（局部不可分）；且 (ii) S_c ≠ S_{c′}（安全集不同）。这是 U_ctx 中唯一「不可局部消解」的部分，必须靠移动到见证区域（定义 317）或保持鲁棒来处理。

**定义 317（上下文可观测性地图 COM）** 地图 M_ctx : 𝒳 → { 对每对安全关键混叠的预期可分辨增益 g_e(x)、风险 r(x)、代价 d(x) }。对每对 (c,c′)，见证区域 W_{cc′} = {x : ρ_c(x)·ρ_{c′}(x) 足够大且线索可区分}。COM 是「去哪能读懂世界」的地图，等价于把 SLAM 的几何/语义地图升维到**上下文可辨识性**。

**定义 318（上下文信息导航 NIC）** 候选取证轨迹 ζ（到某见证点或环视/重定位），上下文信息增益 VoI_ctx(ζ) = H(C|o) − E_{y~p(·|ζ,o)} H(C|o,y)。选择 ζ* = argmax_ζ [VoI_ctx(ζ) − cost(ζ)]，s.t. 沿 ζ 全程属于鲁棒包络 S_robust（定义 314）。若无利可图或包络为空 ⇒ 不移动，退回 R69 的原地信息动作或纯保守。

**定义 319（上下文判定与切换纪律）** 上下文 c* 被「确立」⇔ 后验 b(c*) ≥ τ_ctx 且至少有两条正交线索一致（定义 310-iv）且连续 k 帧稳定。切换需迟滞：b(c*) ≥ τ_ctx + h 且原上下文后验 < τ_ctx − h。切换触发重新进入「识别前鲁棒」状态，直到再次确立。

**定义 320（上下文条件分派）** 上下文确立后，在 S_{c*} 内把控制交给 R69 的 FLUID 层（其内部再按 U_epi→U_ale 走 R68）。⇒ 分层嵌套：LUCID（世界）⊃ FLUID（动作歧义）⊃ CALM（测量）。证书逐层嵌套。

**定义 321（上下文漂移与变点）** 变点统计量 Λ_t = log p(o_{t−m:t} | c_old) − log p(o_{t−m:t} | c_new)；Λ_t > τ_cp 且 U_nov 低 ⇒ 上下文切换；U_nov 高 ⇒ 新颖上下文（开集），不得强行归类到最近邻。

**定义 322（元校准 MCD）** 校准上下文后验 b_t(c)：可靠性图与 ECE_ctx。ECE_ctx > τ_ctx_ece ⇒ 禁用上下文分派，永久停留在鲁棒包络（不允许 resolution bonus）。这是「对不确定性估计器本身」的校准，是 R69 的 MCG 的元层版本。

**定义 323（冻结机器人问题的有序退出）** 若 S_robust 长期为空且 VoI_ctx 无正收益（所有见证点都不可达），定义**有序退避**：回到最近已知安全锚点 a0（其上下文已确立），在该上下文内执行 R68 最保守模式并请求人类/外部干预；禁止在空包络下继续探索。同时防止「永远停在原地」与「鲁莽探索」两个极端。

**定义 324（上下文证书 J_LUCID）** J_LUCID = (J_FLUID, ECE_ctx, U_ctx_before/after, context_type_cardinality, robust_envelope_nonempty, voi_ctx_ratio, switch_count, open_set_rate, lucid_ver)。Valid ⇔ Valid(J_FLUID) ∧ ECE_ctx ≤ τ ∧ 上下文证据纪律满足 ∧ 识别前动作始终 ∈ S_robust。

**定义 325（上下文级对抗干扰 ℰ_ctx）** 欺骗性线索（假门牌、伪装地面、误导性人群）、人为制造的安全关键混叠、过期地图（旧门牌）、见证点被遮挡。并入 AIC：ℰ_LUCID = ℰ_FLUID × ℰ_ctx。

**定义 326（安全相关性加权熵）** U_ctx^s = −Σ_k (Σ_{c∈type_k} b(c)) log (Σ_{c∈type_k} b(c))，即对 context type 后验的熵；同型内部不确定性不计入，避免为无关区别花预算。

**定义 327（见证预算与取证收益）** 每次上下文取证受导航预算约束（位移 ≤ D_max、时间 ≤ T_max、沿途风险 ≤ ε）；收益按「包络体积扩张」度量：ΔV = volume(S_{c*}) − volume(S_robust)（resolution bonus 的空间版）。

**定义 328（切换稳定性）** 若窗口内切换次数 > N_sw，强制提升迟滞 h 并冻结分派一个窗口，防止抖动；迟滞撤除需连续稳定超过窗口长度。

**定义 329（开集拒识）** 若对某观测 min_c(−log p(o|c)) > τ_nov 且残差呈结构性（非 aleatoric，借用 R69 的 Δa 通道判别），判为新颖上下文；此时不建立新上下文模型（遵守零学习写操作），而是退化为「更大鲁棒包络 + 请求人类标签」。

**定义 330（与 R68/R69 的嵌套退化）** 当 |𝒞_δ| = 1 ⇒ S_robust = S_c，NIC 无正 VoI ⇒ U_ctx 视为消解，LUCID 逐指令等于 FLUID；当 FLUID 的 VoI ≤ 成本 ⇒ 等于 CALM。故安全侧严格不弱，效率侧获 resolution bonus。

# IP-264/265 CHS + CSA：上下文假设集与安全等价抽象（离线建，商空间维护）
def safe_equiv_abstraction(hypotheses, eps):
    # 只有安全集/先验支撑/可达集都相同的上下文才允许合并
    groups = union_find(hypotheses,
                        key=lambda c: (c.S, c.pi_modes, reachable_set(c.f, eps)))
    return [merge(g) for g in groups]          # 商空间 context types

# IP-267 CBM：上下文后验滤波 + 开集分数（复用 R69 trunk 的 z_t）
class ContextBelief:
    def update(self, o_t, z_t):
        for k in self.types:                    # 只在 context types 上维护
            self.logb[k] += log_likelihood(o_t, k, z_t)
        self.logb = normalize(self.logb)
        self.novelty = -logsumexp([ll_known(o_t, k) for k in self.types])
        return self

# IP-266 RSE：识别前的交集安全包络（空则只许停/取证/撤退）
def robust_envelope(b, delta):
    types = [k for k in b if b[k] >= delta]
    S = intersect([k.S for k in types])
    return S, types

# IP-269 NIC：把「去哪能看到上下文证据」当成信息动作来规划
def choose_context_traversal(types, b, map_ctx, budget, cur):
    best = None
    for pair in safety_critical_aliases(types):          # 只对安全关键混叠花预算
        for x in map_ctx.witnesses(pair):
            zeta = plan_path(cur, x)                     # A* / RRT*
            if zeta is None or not robust_safe(zeta, types): continue
            voi   = entropy(b) - expected_entropy(b, pair, x)
            score = voi - cost(zeta)
            if best is None or score > best.score: best = (zeta, score)
    return best if best and best.score > 0 else None     # 无利可图 → 不走

# IP-276 主闭环（继承 R69，仅在「世界层」插入 LUCID 门）
def LUCID_round(M, obs):
    z = M.trunk(obs)
    b = M.ctx.update(obs, z)                             # 上下文后验 + 开集
    if M.mcd.ece_ctx > TAU_ECE:                          # 元校准不可信
        return M.ordered_retreat(b)                      # 不许 resolution bonus
    S, types = robust_envelope(b, DELTA)
    if len(types) == 1 and b.novelty < TAU_NOV:
        M.latch_context(types[0], hysteresis=H)          # 世界已定
        return M.fluid.round(obs)                        # 分派给 R69（定义 320）
    if S.is_empty():
        zeta = choose_context_traversal(types, b, M.com, M.budget, M.pose)
        if zeta is None: return M.ordered_retreat(b)     # 定义 323
        M.execute_robust(zeta); return M.hold()          # 只取证，不做任务位移
    zeta = choose_context_traversal(types, b, M.com, M.budget, M.pose)
    if zeta is not None and b.novelty < TAU_NOV:
        M.execute_robust(zeta)                           # 边走边取证
    c_star = argmax(b)
    if b[c_star] >= TAU_CTX and M.ctx.orthogonal_agreement(c_star):
        M.latch_context(c_star, hysteresis=H)            # 定义 319
        return M.fluid.round(obs)                        # 上下文条件分派
    return M.hold_in(S)                                  # 未确立：交集内保守

# IP-271 MCD：上下文级元校准（对不确定性估计器本身的校准）
def meta_calibrate(context_logits, labels):
    return reliability_diagram_ece(context_logits, labels)   # ECE_ctx 门控

## 3. 推导

**引理 19（上下文识别的不可约下界）** 对任意两上下文 c, c′，在位置 x 处任一检验的期望错误率 ≥ (1 − ‖P_c(·|x) − P_{c′}(·|x)‖_TV)/2（Le Cam）。⇒ 若局部 TV 距离 < ε_obs（安全关键混叠），**无论采多少样本、花多少交互预算都无法可靠区分**；唯一出路是移动到见证区域改变 TV 距离，或保持鲁棒。这从信息论上证明了「上下文理解必须包含导航」。

**引理 20（上下文理解的分辨率红利）** 设上下文为随机变量 c ~ b，包络体积 vol(S_c)：E_b[vol(S_c)] = Σ_c b(c) vol(S_c) ≥ vol(∩_c S_c) = vol(S_robust)，等号当且仅当单一上下文或所有 S_c 相同。差额 ΔV 即「理解上下文」的期望收益；NIC 选择使 ΔV 最大的见证点。⇒ 主动导航的收益可被量化，且**只在安全集不同处非零**（与定义 315 的抽象一致）。

**引理 21（安全关键混叠的不可约权衡）** 若两上下文在含见证区域的可达集内仍有 TV < ε_obs 且 S_c ≠ S_{c′}，则任何策略在识别前要么承受 ≥ min(risk_c, risk_{c′})·(1 − ε_obs)/2 的最坏情形风险，要么停留在交集内、以 ≤ min 效率运行。⇒ 安全关键混叠是「安全-效率」的根本权衡点，无法同时消灭，只能定价。

**引理 22（切换抖动的界）** 在迟滞带 τ+h > τ−h 内，若观测噪声方差 σ²，则长度 T 的窗口内期望切换次数 ≤ T·Φ(−h/σ)/τ_dwell；取 h ≥ 2σ√(2 log T) 可使切换次数 < 1 w.h.p.（标准高斯尾部/经验过程界）。⇒ 定义 319 的迟滞把 chattering 压到可忽略，代价是切换略滞后。

**定理 18（LUCID 严格包含 FLUID 与 CALM）** 当 |𝒞_δ| = 1 时 S_robust = S_c、NIC 无正 VoI，LUCID 逐指令等价于 FLUID；当 FLUID 无正 VoI 时等价于 CALM。且对任意 b，识别前的动作 ∈ S_robust ⊆ S_c (∀c∈𝒞_δ)，故安全侧风险 ≤ 任一单上下文策略（以其真实上下文为准）。⇒ 世界层的加入不削弱下两层，只在识别后给 resolution bonus。

**定理 19（上下文不确定下的安全性）** 若真实上下文 c* ∈ 𝒞_δ（闭集且后验校准），则任何满足定义 314 的动作在 c* 下风险 ≤ ε；若包络为空，则唯一合法动作集不含任何任务位移，故不存在「自信进入错误上下文」的灾难动作。⇒ 把最危险的失效模式——自信地错——在结构上排除，代价是可能冻结（由定义 323 有序退出兜底）。

**定理 20（开集不完备的必然残余风险）** 若真实上下文 c* ∉ 𝒞（开集遗漏），则定义 314 的证书**不覆盖** c*，安全性无法由 J_LUCID 保证；只能靠 U_nov 检测「一个都不像」后请求人类标签，或由最小风险兜底（有序退避）。⇒ **闭集假设是 LUCID 的信任边界**：证书只在 𝒞 覆盖真实世界时有效。这是本轮无法内部消除的残余风险（第 6 节）。

def safe_equiv_abstraction(hypotheses, eps):
    groups = union_find(hypotheses,
                        key=lambda c: (c.S, c.pi_modes, reachable_set(c.f, eps)))
    return [merge(g) for g in groups]                  # context types

class ContextBelief:
    def update(self, o_t, z_t):
        for k in self.types:
            self.logb[k] += log_likelihood(o_t, k, z_t)
        self.logb   = normalize(self.logb)
        self.novelty = -logsumexp([ll_known(o_t, k) for k in self.types])

## 4. 推导

**引理 19（上下文识别的不可约下界）** 位置 x 处任一检验的期望错误率 ≥ (1−‖P_c(·|x)−P_{c′}(·|x)‖_TV)/2（Le Cam）。⇒ 局部 TV<ε_obs 时，采样/交互再多也无法可靠区分，唯一出路是移动到见证区域或保持鲁棒。这从信息论上证明「上下文理解必须包含导航」。

**引理 20（上下文理解的分辨率红利）** E_b[vol(S_c)] = Σ_c b(c)vol(S_c) ≥ vol(∩_c S_c) = vol(S_robust)，等号当且仅当单一上下文或所有 S_c 相同。差额 ΔV 即理解上下文的期望收益；NIC 选择使 ΔV 最大化的见证点。⇒ 主动导航收益可量化，且只在安全集不同处非零。

**引理 21（安全关键混叠的不可约权衡）** 若可达集内仍 TV<ε_obs 且 S_c≠S_{c′}，识别前策略要么承受 ≥ min(risk_c,risk_{c′})·(1−ε_obs)/2 的最坏风险，要么停在交集内、以 ≤ min 效率运行。⇒ 安全-效率根本权衡，只能定价。

**引理 22（切换抖动界）** 迟滞带 τ+h>τ−h 内，长度 T 窗口的期望切换次数 ≤ T·Φ(−h/σ)/τ_dwell；取 h≥2σ√(2log T) 可使切换 <1 w.h.p.。⇒ 迟滞把 chattering 压到可忽略，代价是切换略滞后。

**定理 18（LUCID 严格包含 FLUID 与 CALM）** 单例上下文 ⇒ S_robust=S_c、NIC 无正 VoI，LUCID 逐指令=FLUID；FLUID 无正 VoI ⇒ =CALM。且识别前动作 ∈ S_robust ⊆ S_c，安全侧风险 ≤ 任一单上下文策略。安全不让步，识别后获 resolution bonus。

**定理 19（上下文不确定下的安全性）** 若真实 c*∈𝒞_δ 且后验校准，则满足定义 314 的动作在 c* 下风险 ≤ ε；空包络时唯一合法动作不含任务位移，故不存在「自信进入错误上下文」。⇒ 结构性排除「自信地错」，代价是可能冻结（定义 323 兜底）。

**定理 20（开集不完备的必然残余风险）** 若真实 c*∉𝒞，J_LUCID 不覆盖 c*，安全性无法由证书保证；只能靠 U_nov 拒识后请求人类标签，或最小风险兜底。⇒ **闭集假设是 LUCID 的信任边界**，证书只在 𝒞 覆盖真实世界时有效，必须显式声明，绝不可外推。

## 7. 本轮最大风险

**一句话**：LUCID-RAS 的全部安全保障都押在「上下文假设集 𝒞 覆盖真实世界、且每个 S_c 被正确建模」这一**闭集前提**上——**一旦发生开集遗漏或安全集建模错误，交集包络会给出一个「看似稳健」的假证书，让机器人以前所未有的自信驶入一个它根本没建模的危险上下文**；「在错误的世界模型下证明了安全」是本轮最危险的自欺，且比 R69 的自欺更隐蔽，因为它披着「鲁棒」的外衣。

**次级风险与缓解**：上下文集组合爆炸（CSA 只保留 context type，预算只花在安全关键混叠）；一直鲁棒→冻结机器人（有序退出 + 安全锚点 + 请人类）；切换抖动（迟滞 + 切换成本 + 稳定性窗口）；见证点不可达/被遮挡（备选见证点 + 原地 R69 兜底）；元校准不可信（MCD 的 ECE_ctx 门控，越界即禁用分派、永久鲁棒）；开集遗漏的残余风险无法内部消除（U_nov 拒识 + 人类标签 + 最小风险兜底，并在证书中显式声明信任边界，绝不把 J_LUCID 当覆盖未建模世界的安全证明）。
