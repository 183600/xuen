# 第 70 轮（承接第 69 轮「FLUID-RAS」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「对比实验」×「竞赛策略」）

> R69 用「流匹配多模态策略 + 主动多模态交互」把不确定性一分为二，让系统学会了「看、问、触、等」。但 R69 留下了一个更深的循环缺口：**它从不验证「问」到底有没有用**。VoI 是模型在同一套可能失准的模态分布上算出来的自评——用 R69 自己指认的最大风险（模态权重未校准）来给 R69 的交互决策打分，是拿被告当法官。R66–R69 的每一层都在用「另一个模型」回答「这一层该不该信」：R67 信 VISTA 的预测，R68 信标定残差，R69 信流模型的模态权重。层数越多，需要独立信任的黑箱越多。
>
> 本轮两个灵感正好把「信任」从模型内部搬到设计外部：
> - **对比实验**给出**识别**：不要求模型是对的，只要求**设计**是对的（随机化、重叠、预注册）。「因果效应」与「模型预测」是两种证据，前者可以被实验设计保证，后者只能被模型校准保证。
> - **竞赛策略**给出**选择**：不再手工调阈值，而是让一族完整假设（R68 保守、R69 交互、K/阈值/校准变体）在共享的证据流上**锦标赛式竞争**，用无遗憾算法晋升/淘汰，并把它同时理解为**对抗会操纵指标的世界**的竞赛。
>
> 核心命题：**把闭环再抬一层——对象级仍由 R68/R69 控制，元级新增「证据层」。系统自己发起安全受控的对比实验，用因果识别而非模型自评来判断「某个假设是否真的更好」，再用抗策略性操纵的锦标赛把赢家晋升为下一赛季的冠军。** 命名 **TRIAL-RAS**（Tournament-based Randomized Identification And Learning）——"Trial" 双关：**受控试验**与**选拔赛**。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我凭什么相信『求证有效』**」——不确定性不只是可以被问出来，还必须被**可识别地验证**；否则「证据驱动」只是给旧偏见换了张更权威的证书。

## 0. 直觉与动机

**灵感 1（对比实验 → 从「模型告诉我」到「设计告诉我」）**
直觉：R69 的 VoI 是一个**模型预测**：H(M|o) − E[H(M|o,y)]，两项都来自同一个流模型。如果模态后验本身就是幻觉，VoI 会自信地算出一个错误的方向。对比实验换了一个问题：不问「模型认为交互值多少」，而问「在可比条件下，执行交互的潜在结局与不执行的潜在结局之差是多少」。前者需要模型对，后者只需要设计对。这就是「预测」与「识别」的分野，也是循证医学相对临床直觉的分野。最刺眼的一点是**指征混杂（confounding by indication）**：R69 在 U_epi 高时才交互，而 U_epi 高本身就让结局更差；于是朴素地比较「交互过」与「没交互」的样本，会把「因为难才问」误读成「问了更糟」，**甚至符号反转**。这正是 R69 若用观测日志自评（E288/E296）会踩的坑。

**灵感 2（竞赛策略 → 让假设竞争，而不是让一个阈值独裁）**
直觉：R69 的 K、τ_epi、λ_floor、ECE 阈值都是一次性手调的。真实系统里应保留一个**假设场**：保守的 R68、交互的 R69、不同 K、不同校准门，各自是一个完整"选手"。它们在同一批可比状态上竞争，用 racing/UCB/EXP4 一类无遗憾算法维护置信序列，输者淘汰、赢者晋升。竞赛还必须是**对抗性**的：世界和人都能学会我们的指标并操纵它（Goodhart），所以选择机制要配严格适当评分、预注册端点、隐藏/轮换端点与硬护栏。**竞争保证效率，护栏保证安全，二者必须分离**——无遗憾不等于无事故。

**灵感 3（安全随机化 → 安全不是实验的对立面，而是实验的约束）**
直觉：安全关键系统不能为了做 A/B 测试就随机执行危险动作。但随机化不必发生在整个动作空间，只需发生在**认证安全等价类**内部：两个动作若最坏情形风险之差 ≤ δ_eq，就可交换、可比较、可随机。于是"对照实验"获得了一个安全版本——**安全保持的微随机化**。代价是：识别出的是**可比层上的局部平均处理效应（LATE）**，不是全局 ATE；不可比区（无重叠、高 stakes）只能标记"未识别"并退回保守。诚实地承认这一点，比用一个漂亮但外推过度的 ATE 更安全。

**灵感 4（证据分层 → 模型的自我评价是最低等级证据）**
直觉：医学不会用"医生觉得很有效"来批准药物，工程也不该用"策略觉得自己很确定"来晋升自己。建立证据等级：Level 0 模型预测（R69 VoI）< Level 1 观测关联 < Level 2 准实验（IV/DiD/断点）< Level 3 随机化试验。效率类主张至少 Level 2，高风险主张至少 Level 3，Level 0 永不单独定案。这把 R69 的「自评」明确降级为最弱证据，而不是推翻它——它是先验，不是判决。

**灵感 5（双时间尺度 → 快环零学习写操作仍然成立）**
直觉：R68 的铁律是实时流零学习写操作。R70 要"学习谁更好"，看起来违反它，其实不然：证据累积、锦标赛更新、晋升换装都放到**慢环**（静默检查点/赛季边界），快环只运行**冻结的冠军版本**。换装走 R68 定理 15 的提交/换装不变式，原子切换或回滚。于是"学习"发生在慢环，"控制"发生在快环，R68 不变式原样保留，控制连续无突变。

**灵感 6（对抗与伦理 → 会撒谎的不只是被试，还有实验者与指标）**
直觉：一旦系统奖励"不确定性下降"，提供答案的人就会变得更"自信"；一旦系统奖励"试验成功"，试验日志就可能被投毒、端点就可能被事后挑选。R70 的威胁模型必须包含：策略性回答者、指标操纵者、试验日志投毒者、以及系统自己的 p-hacking。防御不是更强的模型，而是**机制**：严格适当评分（诚实是占优策略）、预注册（禁止换端点）、证据审计（VQAuditor-T）、稳健估计（DR/IV）与敏感性分析（E-value）。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（TRIAL-RAS 总览）** TRIAL-RAS = (HYP, CEC, SMR, CID, TOUR, PG, PSR, EBR, DRL, AUDIT†)。四不变式：
(i) **快环零学习写操作**（继承 R68 定义 276-i、R69 定义 293-i）：回合内只运行冻结的冠军假设；
(ii) **安全随机化**：任何随机化只在 C-RAS-WM 认证的安全等价类内、且仅在安全裕度充足时进行；
(iii) **证据纪律与预注册**：晋升所用端点必须在赛季开始前注册，禁止事后换端点或选择性报告；
(iv) **证据分层与保守默认**：证据等级不足时默认最保守假设（R68），安全侧永不弱于 R69。

**定义 311（假设场 HYP）** 假设场 ℋ = {h_1,…,h_n}，每个 h_i = (π_i, θ_i, ver_i, J_i) 是一个完整对象级策略（R68 保守、R69 交互、K/阈值/校准变体等）及其版本与安全证书。给定状态 s，h_i 提出动作 a_i = π_i(s) 与自评 (U_ale^i, U_epi^i)。部署的是"当前冠军" h_{κ(t)} 的单一动作，不是动作混合。

**定义 312（安全等价类与可比性 CEC）** 由 C-RAS-WM 的认证安全集 S_cert(s) 出发，定义 a ~_s a′ ⇔ 二者最坏情形风险之差 ≤ δ_eq，且信息状态 z、时域 H、终止语义一致。等价类 [a]_s ⊆ S_cert(s)。两假设在 s **可比** ⇔ 其动作落在同一等价类且 z 相同（无信息差）。不可比时禁止随机化与晋升比较，记为"未识别"。

**定义 313（安全随机化 SMR）** 在可比状态 s，以倾向 e_i(s) ∈ [e_min, 1−e_min] 抽取部署臂；仅当安全裕度 m(s) ≥ m_0 且不可逆度/时域成本低于阈值时允许。记录 (s, z, {a_i}, e_i, y, season)。高 stakes（m(s) < m_0）不随机化，直接取最保守认证动作。

**定义 314（对比单元与预注册端点 Trial）** 一次试验 τ = (s, A_s, e, y)，端点与护栏在赛季前注册并哈希入 trial registry：主端点 ℓ(τ)（损失/完成时间），护栏 c_g(τ)（安全违规、越界力、社交打扰）。y = (ℓ, c_g, U_epi_before/after, a_score)。禁止赛季中途改端点。

**定义 315（因果 estimand 与识别）** 潜在结果 Y(a)。全局 ATE_{ij} = E[Y(a_i) − Y(a_j)]；安全随机化下主要可识别的是**可比层局部效应** LATE_{ij} = E[Y(a_i) − Y(a_j) | s ∈ 𝒞]。识别假设：SUTVA（无干扰）、positivity（e ∈ (0,1)）、consistency、可比层内可交换性。估计量：IPW、双重稳健 DR、以随机种子为工具的 IV、以赛季切换为自然实验的 DiD。**LATE 不外推到不可比区。**

**定义 316（指征混杂 Confounding by indication）** R69 在 U_epi 高时触发交互，而 U_epi 亦影响结局。观测日志的朴素差 Δ̂_naive = E[Y|T=1] − E[Y|T=0] = ATE + B，其中
B = [E(Y(0)|T=1) − E(Y(0)|T=0)] + [E(Δ|T=1) − E(Δ)]，Δ(U)=Y(1)−Y(0)。
一般 B ≠ 0，且效应异质时可导致**符号反转**。系：R69 若用观测日志自评收益，可能把"因为难才问"读成"问了更糟"。

**定义 317（证据分层 Evidence hierarchy）** Level 0：模型自评/预测（R69 VoI）；Level 1：观测关联；Level 2：准实验（IV/DiD/断点）；Level 3：安全随机化试验。晋升规则：效率主张 ≥ Level 2；涉及安全裕度或高风险行为的主张 ≥ Level 3；Level 0 永不单独定案。

**定义 318（锦标赛 TOUR）** 为每个 h_i 维护值的置信序列 [L_i, U_i]；采用 racing / successive halving / UCB；当 U_i < max_j L_j 时淘汰 i。目标：相对最佳固定假设的 regret 有亚线性上界（EXP4 风格，抗自适应对手）。赛季（season）边界重置或折扣，处理非平稳。

**定义 319（策略性对手与适当评分 PSR）** 世界/人类是可操纵指标的战略对手。用严格适当评分规则（Brier / log score）做答案与信念的激励相容 elicitation：诚实报告是唯一最优。端点随机轮换、部分隐藏。定义指标操纵缺口 G = 真实目标改善 − 测得指标改善，目标是使 G 有界。

**定义 320（护栏与晋升门 PG）** 晋升 h_i 需同时满足：证据等级达标；护栏违规的上置信界 = 0；效应置信区间下界 > 最小实际显著差 Δ*；敏感性通过（E-value < τ_E）；探索预算未越界。

**定义 321（非平稳与赛季重置）** 分布漂移使旧冠军可能失效。以变点检测 + 折扣证据 + 赛季重置控制"过期冠军"的 regret；检测延迟 d 导致的额外后悔 ≤ O(d·Δ_max)（引理 23）。

**定义 322（探索预算与安全探索 EBR）** 探索代价 = 未选当前最优的期望损失。硬预算：累计探索 regret ≤ B_explore。保守 bandit：仅当认证裕度 ≥ 探索所需裕度时探索；否则贪心最保守。给出安全—探索 Pareto 前沿。

**定义 323（双时间尺度与原子换装 DRL）** 快环（控制）冻结冠军、零学习写；慢环（证据/锦标赛）在静默安全检查点更新，写版本化检查点，经 C-RAS-WM 换装不变式（R68 定理 15）原子切换或回滚。故快环不变式 (i) 保持、控制连续无突变。

**定义 324（证书 J_TRIAL）** J_TRIAL = (J_FLUID, trial_registry_hash, propensity_ECE, overlap_diag, LATE_CI, guardrail_UCB, evidence_level, tournament_regret_bound, season_id)。Valid ⇔ Valid(J_FLUID) ∧ 预注册一致 ∧ 护栏 UCB = 0 ∧ 证据等级达标 ∧ 预算未越界。

**定义 325（参与式审计 VQAuditor-T）** 审计实验伦理与有效性：是否只在安全类内随机化、是否预注册、有无端点漂移/p-hacking、是否在混杂数据上晋升、对手是否操纵指标、试验日志是否被投毒。结论回灌 AuditBuf，成为下一赛季的预算与端点先验。

**定义 326（严格包含链）** 当 |ℋ| = 1、探索预算为 0 或证据不足时，TRIAL 退化为 FLUID（R69）；当进一步 VoI ≤ 成本或禁用交互时退化为 CALM（R68）。即 **TRIAL ⊇ FLUID ⊇ CALM**，且安全侧不弱于最保守的被晋升者。

## 2. 关键算法骨架

```python
# IP-264 HYP：假设场（版本化；每个假设带完整安全证书）
class HypothesisField:
    def __init__(self, hyps):
        self.hyps = {h.id: h for h in hyps}
        self.champion = pick_most_conservative(hyps)
    def propose(self, s, z):
        return {hid: h.act(s, z) for hid, h in self.hyps.items()}

# IP-265 CEC：认证安全等价类与可比性
def certified_classes(actions, s):
    S = c_ras_wm.certified_safe(s)                      # 硬安全集
    return partition(S, key=lambda a: risk_bucket(a, s, DELTA_EQ))

def comparable(actions, s):
    cls = certified_classes(actions, s)
    return (len({class_of(a, cls) for a in actions}) == 1
            and same_information_state(actions, s))

# IP-266 SMR：安全随机化 + 试验记录（倾向、上下文、结局回填）
def safe_randomized_step(field, s, z, season):
    acts = field.propose(s, z)
    if not comparable(acts.values(), s) or margin(s) < M0:
        return field.champion.act(s, z), None           # 不随机化：最保守
    e = propensities(acts, s, season)                   # e_i ∈ [e_min, 1-e_min]
    hid = sample(list(acts), e)
    log.append(Trial(s, z, acts, e, season))
    return acts[hid], hid                               # 下一拍回填 y

# IP-267 CID：识别（IPW / DR / IV / DiD）+ 倾向校准 + overlap 诊断
def identify(trials, season):
    e = propensity_model(trials)
    assert ece(e) <= TAU_PROP and overlap(trials) > 0
    return {pair: dr_ate(trials, pair, e) for pair in pairs(field)}

# IP-268 TOUR：无遗憾锦标赛（racing / UCB），赛季重置
def tournament(values, season, budget):
    for hid, (lb, ub) in confidence_sequences(values, season).items():
        if ub < max_lb(values): eliminate(hid)
    return argmax_lower_bound(values)                   # 证据足够才换冠军

# IP-269 PG：晋升门（证据等级 + 护栏 + 实际显著 + 敏感性）
def promote(candidate, cid, season):
    if evidence_level(candidate) < required_level(candidate): return False
    if guardrail_ucb(candidate) > 0:                          return False
    lo, _ = cid[candidate].ci
    if lo <= DELTA_STAR:                                      return False
    if e_value(cid[candidate]) > TAU_E:                       return False
    return True

# IP-270 PSR：严格适当评分 → 激励相容的答案/信念 elicitation
def score_report(report, outcome):
    return brier_score(report.p, outcome)               # 诚实报告是唯一最优

# IP-271 EBR：探索预算与安全探索
def may_explore(margin, spent):
    return margin >= M_EXPLORE and spent < B_EXPLORE

# IP-272 DRL：双时间尺度（快环冻结，慢环换装）
def fast_loop(s, z):
    return field.champion.act(s, z)                     # 零学习写

def slow_loop_quiescent():
    cid   = identify(trials, season)
    champ = tournament(cid.values, season, budget)
    if promote(champ, cid, season):
        atomic_swap(champion=champ, via=c_ras_wm.handover)   # R68 定理 15
    rollback_if_invalid(J_TRIAL)

# IP-274 TRIAL-RAS 主闭环（R69 之上加"证据层"，快环仍零学习写）
def TRIAL_RAS_round(M, obs, season):
    z, o = M.mtm.forward(obs)
    if M.ebr.may_explore(M.margin(o), M.spent):
        a, hid = M.smr.safe_randomized_step(M.hyp, o, z, season)
    else:
        a, hid = M.hyp.champion.act(o, z), None
    k, lam, mode, U = M.fluid.step(a, o, z)             # R69 认证 + 模态选择
    y = M.env.execute(mode.a[:k]); M.trials.fill(y)     # 回填结局
    if M.checkpoint.quiescent():                        # 慢环：仅静默检查点
        cid   = M.cid.identify(M.trials, season)
        champ = M.tour.update(cid, season)
        if M.pg.promote(champ, cid, season): M.drl.atomic_swap(champ)
        M.vqa_t.submit_async(cid, champ, M.trials)      # 审计 + 证书
    return k, lam, mode, U
```

## 3. 推导

**引理 19（安全随机化的识别域）** 在可比层 𝒞 上，若倾向 e_i(s) ∈ [e_min, 1−e_min] 且满足 SUTVA/consistency/可交换性，则 LATE_{ij} 被 IPW 识别：
LATE_{ij} = E[ 1{a=a_i}·Y/e_i − 1{a=a_j}·Y/e_j | s ∈ 𝒞 ]。
安全约束只改变**估计目标**（从 ATE 缩到 LATE），不破坏有效性；但在 𝒞 之外 overlap = 0，效应**不可识别**，任何外推都没有设计保证。

**引理 20（指征混杂的符号反转）** 令 T = 1{U_epi > τ}，Δ(U) = Y(1) − Y(0)。则
Δ̂_naive = ATE + [E(Y(0)|T=1) − E(Y(0)|T=0)] + [E(Δ|T=1) − E(Δ)]。
当 U_epi 同时抬高基线损失与交互收益时，第一项为正、第二项可正可负；两者叠加可使 Δ̂_naive 与 ATE **异号**。系：R69 的观测自评（非随机）不能作为交互收益的证据；这正是本轮预实验复现的现象（§6：朴素 +0.601 vs 真值 −0.400）。

**引理 21（安全探索的遗憾—安全界）** 采用保守 bandit（仅当认证裕度 ≥ M_EXPLORE 时探索）且硬护栏过滤臂，则：累积探索后悔 ≤ O(√(T n log n))；在 m(s) < M0 时禁止探索，护栏违规 = 0（硬约束成立）。安全不是用 regret 换来的，而是用**可行域限制**换来的。

**引理 22（严格适当评分的激励相容与 Goodhart 界）** 对二元结局与信念 p，Brier 分数在报告 c = p 时唯一最小；任何系统性过度自信 σ 使期望分数上升约 σ²。若端点部分隐藏并以固定频率轮换，则指标操纵缺口 G 被"隐藏端点的不可观测性 + 硬护栏"联合界住；策略性回答者的最优策略退化为诚实报告。

**引理 23（赛季重置的过期冠军后悔）** 设漂移后最佳假设改变、变点检测延迟为 d 拍，则沿用旧冠军的额外后悔 ≤ d·Δ_max + C_reset；因此赛季长度与检测灵敏度共同决定非平稳下的遗憾上界。

**定理 18（包含链与安全保持）** 在 A99（安全类划分保守、晋升门护栏 UCB = 0、默认最保守）下，TRIAL 的部署安全风险 ≤ min_{被晋升假设} risk ≤ R69，且当 |ℋ|=1 或证据不足时逐指令退化为 FLUID，再退化为 CALM。即 TRIAL ⊇ FLUID ⊇ CALM，安全侧不做任何让步。

**定理 19（抗自适应对手的无遗憾竞赛）** 以 EXP4 / FTRL 维护假设权重、以置信序列淘汰，则对任意自适应对手，相对最佳固定假设的后悔 ≤ O(√(T n log n))。但**无遗憾 ≠ 安全**：锦标赛只优化效率类端点，安全由独立硬护栏与晋升门保证（分离原则）。

**定理 20（双时间尺度无突变）** 慢环仅在静默检查点更新，并经 C-RAS-WM 换装不变式（R68 定理 15）原子切换；快环在回合内只读冻结冠军。故任一回合内假设不变、控制连续、无突变；R68 的实时零学习写不变式保持。

## 6. 本轮最大风险

**一句话**：TRIAL-RAS 把「信任」从模型搬到实验设计，但**实验设计本身可能成为新的、未被验证的权威**——若安全等价类被错误认证、可比层不具代表性、或试验日志/端点被战略对手投毒与操纵，系统就会用一场**错的实验**自信地证明自己没错，把 R69 的「诚实的不知道」升级成「**有证书的错误**」。**问错比不问更危险（R69）；用错的实验证明自己没问错，比问错更危险（R70）。**

**次级风险与缓解**：
1. **LATE 外推 / 可比层不具代表性** → 明令不外推 + 敏感性分析 + 不可比时默认 R68；
2. **试验日志投毒 / 端点操纵** → 预注册 + 稳健估计（DR/IV）+ 适当评分 + VQAuditor-T；
3. **探索本身带来风险** → EBR 硬预算 + 认证裕度门槛 + 护栏 UCB；
4. **多重比较 / p-hacking** → 预注册 + always-valid 置信序列 + 赛季级 FDR 控制；
5. **非平稳导致冠军过期** → 变点检测 + 赛季重置 + 回滚（引理 23）；
6. **慢环泄漏到快环** → 冻结版本 + 静默检查点 + 原子换装（定理 20）。

```python
# IP-264 HYP：假设场（版本化；每个假设带完整安全证书）
class HypothesisField:
    def __init__(self, hyps):
        self.hyps = {h.id: h for h in hyps}
        self.champion = pick_most_conservative(hyps)
    def propose(self, s, z):
        return {hid: h.act(s, z) for hid, h in self.hyps.items()}

# IP-265 CEC：安全等价类与可比性
def certified_classes(actions, s):
    S = c_ras_wm.certified_safe(s)
    return partition(S, key=lambda a: risk_bucket(a, s, DELTA_EQ))

def comparable(actions, s):
    cls = certified_classes(actions, s)
    return (len({class_of(a, cls) for a in actions}) == 1
            and same_information_state(actions, s))

# IP-266 SMR：安全随机化 + 记录
def safe_randomized_step(field, s, z, season):
    acts = field.propose(s, z)
    if not comparable(acts.values(), s) or margin(s) < M0:
        return field.champion.act(s, z), None
    e = propensities(acts, s, season)
    hid = sample(list(acts), e)
    log.append(Trial(s, z, acts, e, season))
    return acts[hid], hid

# IP-267 CID：识别（IPW / DR / IV / DiD）+ 诊断
def identify(trials, season):
    e = propensity_model(trials)
    assert ece(e) <= TAU_PROP and overlap(trials) > 0
    return {pair: dr_ate(trials, pair, e) for pair in pairs(field)}

# IP-268 TOUR：无遗憾锦标赛
def tournament(values, season, budget):
    for hid, (lb, ub) in confidence_sequences(values, season).items():
        if ub < max_lb(values): eliminate(hid)
    return argmax_lower_bound(values)

# IP-269 PG：晋升门
def promote(candidate, cid, season):
    if evidence_level(candidate) < required_level(candidate): return False
    if guardrail_ucb(candidate) > 0:                          return False
    lo, _ = cid[candidate].ci
    if lo <= DELTA_STAR:                                      return False
    if e_value(cid[candidate]) > TAU_E:                       return False
    return True

# IP-270 PSR：严格适当评分
def score_report(report, outcome):
    return brier_score(report.p, outcome)

# IP-272 DRL：双时间尺度
def fast_loop(s, z):
    return field.champion.act(s, z)                 # 零学习写

def slow_loop_quiescent():
    cid   = identify(trials, season)
    champ = tournament(cid.values, season, budget)
    if promote(champ, cid, season):
        atomic_swap(champion=champ, via=c_ras_wm.handover)
    rollback_if_invalid(J_TRIAL)

# IP-274 主闭环
def TRIAL_RAS_round(M, obs, season):
    z, o = M.mtm.forward(obs)
    if M.ebr.may_explore(M.margin(o), M.spent):
        a, hid = M.smr.safe_randomized_step(M.hyp, o, z, season)
    else:
        a, hid = M.hyp.champion.act(o, z), None
    k, lam, mode, U = M.fluid.step(a, o, z)
    M.trials.fill(M.env.execute(mode.a[:k]))
    if M.checkpoint.quiescent():
        cid   = M.cid.identify(M.trials, season)
        champ = M.tour.update(cid, season)
        if M.pg.promote(champ, cid, season): M.drl.atomic_swap(champ)
        M.vqa_t.submit_async(cid, champ, M.trials)
    return k, lam, mode, U
```

## 4. 推导

**引理 19（识别域）** 可比层 𝒞 上，`e_i ∈ [e_min,1−e_min]` 且 SUTVA/consistency/可交换时，`LATE_{ij} = E[1{a=a_i}Y/e_i − 1{a=a_j}Y/e_j | s∈𝒞]`；安全约束只把目标从 ATE 缩为 LATE，不破坏有效性；𝒞 外 overlap=0，效应不可识别。

**引理 20（指征混杂的符号反转）** `Δ̂_naive = ATE + [E(Y0|T=1)−E(Y0|T=0)] + [E(Δ|T=1)−E(Δ)]`；两项可叠加至与 ATE 异号。系：R69 观测自评不可作为交互收益证据。

**引理 21（安全探索界限）** 保守 bandit + 硬护栏：累积探索后悔 ≤ O(√(T n log n))；m(s)<M0 时禁止探索，护栏违规 = 0。安全来自可行域限制，不靠 regret 交换。

**引理 22（适当评分与 Goodhart 界）** Brier 在 c=p 时唯一最小，系统性过度自信使期望分数升约 σ²；端点隐藏/轮换 + 硬护栏使操纵缺口 G 有界，战略回答者最优策略退化为诚实。

**引理 23（赛季重置）** 检测延迟 d 下，沿用旧冠军额外后悔 ≤ d·Δ_max + C_reset。

**定理 18（包含链与安全保持）** A99 下 TRIAL 风险 ≤ min 被晋升假设 ≤ R69；|ℋ|=1/证据不足时逐指令退化为 FLUID，再退化为 CALM。

**定理 19（抗自适应对手的无遗憾）** EXP4/FTRL 后悔 ≤ O(√(T n log n))；但无遗憾 ≠ 安全，安全由独立硬护栏与晋升门保证（分离原则）。

**定理 20（双时间尺度无突变）** 慢环仅静默检查点更新 + C-RAS-WM 换装不变式 ⇒ 回合内假设不变、控制连续、无突变；快环零学习写保持。

## 6. 预实验（本轮已跑，合成验证识别逻辑）

> 目的：验证「指征混杂可致符号反转」与「安全随机化 + OPE 能选对假设」，不是机器人性能声明。生成模型：`U~Unif(0,1)`；`L0(U)=1+3U`，`L1(U)=1.6+U=L0−(2U−0.6)`，噪声 `N(0,0.3²)`；真效应 `Δ(U)=0.6−2U`（U>0.3 时交互有益）；R69 触发规则 `U>0.5`；高 stakes 尾 `U≥0.9` 不可随机化（占 10%）。

**A. 指征混杂复现（N=4×10⁵，R69 式触发）**

| 量 | 数值 |
|---|---|
| 朴素 `E[Y\|交互]−E[Y\|不交互]` | **+0.6008**（看起来有害） |
| 真实全局 ATE | **−0.4000**（平均有益） |
| 可比层（U<0.9）真 LATE | −0.3000 |
| 观测日志 overlap | **0.000**（positivity 失效，不可识别） |

结论：观测自评发生**符号反转**，与引理 20 一致；R69 若用日志自评交互收益会被混杂误导。

**B. 安全随机化（M=1.5×10⁶，仅 U<0.9 随机化）**

| 量 | 数值 |
|---|---|
| 可随机化比例 / 高 stakes 尾 | 0.900 / 0.100 |
| LATE（差分均值） | −0.3010 ± 0.0022 |
| LATE（IPW） | −0.2931 ± 0.0077 |
| 分层 ATE：U<0.3 | **+0.2980 ± 0.0021**（有害） |
| 分层 ATE：0.3≤U<0.6 | −0.2999 ± 0.0021 |
| 分层 ATE：U≥0.6 | −0.9010 ± 0.0021 |

结论：随机化恢复 overlap 并正确识别局部效应；分层揭示**效应异质与阈值 0.3**；高 stakes 尾未随机化，体现「安全保持随机化」的 LATE 边界。

**C. 假设锦标赛（band U<0.9）**

| 假设 | 真实 band 损失 | IPS 估计（随机化日志） |
|---|---|---|
| never | 2.3500 | 2.3483 ± 0.0044 |
| always | 2.0500 | 2.0502 ± 0.0036 |
| thr03（最优） | **1.9499** | **1.9501 ± 0.0035** |
| thr05（R69 式） | 1.9947 | 1.9934 ± 0.0036 |

朴素证据（交互看似 +0.601 有害）会把 `never` 推上冠军，真实后悔 **0.491**；随机化 IPS 锦标赛选中 `thr03`，选择后悔 **0.000**。

**D. Goodhart / 适当评分（真实正确率 p=0.7）**

| 报告置信 c | 测得「不确定性已消解」 | 期望 Brier |
|---|---|---|
| 0.70（诚实） | 0.70 | **0.2100** |
| 0.85（过度自信） | 0.85 | 0.2325 |
| 1.00（极端自信） | **1.00** | 0.3000 |

结论：以「自报确定性」为端点可被战略回答者刷高；Brier 严格适当评分使诚实最优，支持定义 319 / 引理 22。

**可复现性**：合成种子 20261114；脚本 `tmp` 级纯 Python，无外部依赖；上述数字为固定种子下的单次大样本结果（CI 为渐近正态）。

**预实验局限**：单混杂、线性损失、无真实机器人/人类；只验证**估计量逻辑与选择机制**，不构成系统性能结论。真实部署需 E301–E315，尤其 E303 倾向校准、E304 LATE 可迁移性、E308 日志投毒。

## 7. 本轮最大风险

**一句话**：TRIAL-RAS 把「信任」从模型搬到实验设计，但**实验设计本身可能成为新的、未被验证的权威**——若安全等价类被错误认证、可比层不具代表性、或试验日志/端点被战略对手投毒与操纵，系统就会用一场**错的实验**自信地证明自己没错，把 R69 的「诚实的不知道」升级成「**有证书的错误**」。**问错比不问更危险（R69）；用错的实验证明自己没问错，比问错更危险（R70）。**

**次级风险与缓解**：LATE 外推/可比层偏差（不外推 + 敏感性 + 默认 R68）；日志投毒/端点操纵（预注册 + DR/IV + 适当评分 + 审计）；探索风险（EBR 预算 + 裕度门槛 + 护栏 UCB）；多重比较/p-hacking（预注册 + always-valid CI + 赛季 FDR）；非平稳过期冠军（变点检测 + 赛季重置 + 回滚）；慢环泄漏快环（冻结版本 + 静默检查点 + 原子换装）。
