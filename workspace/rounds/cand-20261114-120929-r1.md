# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互的不确定性二分」IP-253~263；灵感循环新循环第 1 轮；本轮灵感：「移动底盘」×「手眼标定」）

> R69 让系统学会了「问」：看、问、触。但 R69 的整个「问」发生在一个**固定基座、已经标定好眼睛**的世界里：手眼关系是一个常数，身体不动，信息动作只是传感器的指向。真实机器人不是这样——**眼睛长在会动的身体上，身体每走一步都在重新定义「我看见的」与「我够到的」之间的变换**。移动底盘给了系统「换一个地方看」的自由；手眼标定则提醒我们：这个自由既是解药，也是毒药——足够的运动让眼睛与手的关系**可辨识**，而更多的自由度也让一个**错误的关系**更容易找到自洽的解释。
>
> 本轮两个灵感正好补上两块缺失：
> - **移动底盘**把 R69 的信息动作从「看 / 问 / 触」升级为「**走到一个看得清、也够得到的位置**」——信息动作第一次有了位姿、能耗、时间、稳定性与社交代价；更重要的是，底盘运动本身就是手眼标定最关键的激励源。
> - **手眼标定**把 R68 的「我的测量还准吗」推进到「**我的感知与我的动作还在同一个坐标系里吗**」。手眼外参不是标定一次就永恒的常数，而是随负载、悬架、温漂、底盘倾角缓变的隐状态；更致命的是，当激励不足时，它的残差可以**恒为零而完全错误**。
>
> 核心命题：**把移动底盘的运动同时当作任务动作与标定激励（dual-use excitation），把手眼外参当作带不确定性的隐状态，用「可观测性门 + 世界锚定留出验证」阻止主动标定退化为自我确认；一旦可观测性不足或验证失败，严格退化为 R69 的保守兜底。** 命名 **STRIDE-RAS**（**S**patiotemporal **T**rajectory **R**ecalibration with **I**nformation-driven **D**ual-use **E**xcitation）——「stride」既是迈出的一步，也是一次暴露步态的测试：每一步都在移动，也都在标定。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我该站在哪里求证——我走过去的这一步，是在让答案更清楚，还是在让错误更像真的**」。

## 0. 直觉与动机

**灵感 1（移动底盘 → 信息动作第一次有了身体）**
直觉：R69 的 `g = (g_gaze, g_probe, g_ask)` 默认「世界从我当前的位置看出去」。可是当目标被遮挡、反光、或视角太斜时，最优的信息动作往往不是「转头」，而是**整个人走过去**。底盘把信息动作扩展成「选一个 vantage point」：移动改变可见性、基线、深度歧义、可达性，也改变风险（稳定性、碰撞、能耗、社交打扰）。更微妙的是，**同一个位姿既服务任务又服务标定**——一次转弯可能既绕过障碍，又给手眼标定提供了它最缺的那段旋转激励。信息动作因此从「传感器指向」升级为「整机轨迹上的一个决策」。

**灵感 2（手眼标定 → 残差为零并不等于标定正确）**
直觉：R68 的铁律是「残差小 ⇒ 测量可信」。但手眼标定是 `A X = X B`：若运动集合退化（纯平移、绕单一轴旋转、平行转轴），外参的一部分**根本不可观测**，此时任意错误的 `X` 都能让残差为零。也就是说，**零残差只证明「这套数据没有反驳我」，不证明「我被检验过」**。移动底盘恰恰最容易制造退化运动：仓库里长距离直线行驶、差速底盘原地打转、只在平坦地面上做平面运动。R69 的「歧义可约就去问」在这里必须加一道门：**先问「我这套运动有没有资格谈标定」，再谈标定准不准**。

**灵感 3（双用途 → 标定不是额外开销，而是可以被任务顺带完成）**
直觉：传统流程是「先标定、再干活」，标定运动是纯成本。但移动机械臂在正常任务中本来就会转、会走、会换视角。如果任务轨迹已经足够激励，手眼外参就是**免费**被观测到的；只有当任务轨迹退化（例如推箱子走直线）时，才需要插入最小代价的「标定步」——一段经认证的 S 形或回转微动。这把标定从「离线阶段」变成「在线预算项」：**不是多花动作去标定，而是让已有的动作更会标定**。

**灵感 4（可观测性可控 → 主动实验设计，不是被动估计）**
直觉：在固定基座上，你能做的只是「换几个机械臂位姿」。移动底盘把可观测性变成**可规划量**：站得远一点、侧一点、绕到背面、抬高或降低视角，都会改变 Fisher 信息矩阵的条件数。于是 R69 的 value-of-information 可以推广到「移动的 VoI」：移动的收益 = 意图歧义下降 + 外参不确定度下降 + 未来任务可观测性增益 − 运动/风险代价。R69 的 MINT 是它在「候选位姿只有原地」时的边界。

**灵感 5（世界锚定 → 运动既能揭穿标定，也能掩盖标定）**
直觉：如果只让系统最小化「训练轨迹上的重投影残差」，它会主动寻找让当前错误外参最自洽的位姿——这和多层网络过拟合没有本质区别。移动底盘给了它更多自由度去寻找这种「**标定回声室**」：错误的外参 + 被它吸收掉的底盘里程计漂移，可以在某一类运动上完美互相解释。破解办法不是更聪明的优化，而是**外部锚点**：让同一世界固定目标从多个不同底盘位姿被看到，并用**留出的**锚点做验证。自己出的题不能自己判卷。

**灵感 6（严格包含 → R69 是「基座固定、外参已知」的边界）**
直觉：如果底盘不动、手眼外参已知且无不确定度、世界锚点静止，那么 vantage 动作退化为 R69 的注视/探针/问句，双用途规划的 beta 项为零，外参风险为零，STRIDE 应当**逐指令**等于 FLUID。只有当底盘会动、外参未知或漂移时，新层才提供额外能力。理论姿态仍是：**新层必须是旧层的严格泛化，安全侧永不让步**——不许因为「我会走路」就把 R69 的保守兜底丢掉。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（STRIDE-RAS 总览）** STRIDE-RAS = (MBE, HEX, VOG, V-MINT, ERS, LCX, HAD, BOC, RAS-WM§)。四条不变量：
(i) **实时流零学习写操作**（继承 R68 定义 276-i；外参重估、轨迹优化、锚点验证全部异步或离线）；
(ii) **整机运动权威与安全**：任何底盘运动（任务运动或信息运动）必须通过 C-RAS-WM 的整机认证，包含支撑多边形/倾覆、速度/加速度、碰撞、能耗与社交成本；信息运动不得扩大安全包络；
(iii) **可观测性纪律**：外参更新只在激励满足 `E(τ) ≥ E_min` 时允许；退化激励下的低残差视为「无证据」，不得用于确认或更新外参；
(iv) **世界锚定纪律**：任何外参更新必须由至少 `m` 个不同底盘位姿观测到的、世界固定锚点做**留出验证**；单一位姿的自洽永不构成充分证据。

**定义 311（整机增广动作空间）** 底盘动作 `a_b ∈ se(2)`（或带地形姿态的 se(3)），机械臂动作 `a_r ∈ ℝ^{d_r}`，信息动作 `g = (g_gaze, g_probe, g_ask)`，观察位姿动作 `ν ∈ SE(3)`（vantage target）。整机动作 `ξ = (a_b, a_r, g, ν) ∈ 𝒜_whole`。任务轨迹 `τ = ξ_{t:t+H}`。R69 的 `𝒜_+` 是本定义在 `a_b ≡ 0, ν = I` 时的子空间。

**定义 312（手眼外参隐状态 HEX）** 相机到末端的外参 `X_t ∈ SE(3)`，后验 `p(X_t | ℋ_t) = N_{SE(3)}(μ_t, Σ_t)`。引入**动态工况** `η_t = (roll, pitch, a_b, payload)`，外参可随工况变化：
`X_t = X_0 ∘ exp(Σ_j η_{t,j} · ξ_j^∧)`，`ξ_j` 为预标定的工况基 twist（悬架压缩、负载引起的柔性变形）。
外参在事件点（换负载、重新装夹、跌落冲击）发生跳变；事件之间为慢漂移。整条链的残余不确定性通过 AX=XB 相对运动约束观测：对运动对 `(A_i, B_i)`，残差 `r_i(X) = log((A_i X)(X B_i)^{-1})`。

**定义 313（激励与可观测性门 VOG）** 对给定运动集合，外参 Fisher 信息
`J(τ) = Σ_i H_i^T W_i H_i`，`H_i = ∂r_i/∂X`。
激励分 `E(τ) = λ_min(J(τ))`，条件数 `κ(τ) = λ_max/λ_min`。VOG 判据：`E ≥ E_min ∧ κ ≤ κ_max`。
退化子空间 `N(τ) = ker(J(τ))`：纯平移使旋转分量不可观测，绕单一/平行轴旋转使其余分量不可观测。**任何 `δX ∈ N(τ)` 都产生一阶零残差**，故定义「零残差非证据」。

**定义 314（双用途轨迹 DUA）** 在整机安全与激励约束下规划
`τ* = argmax_τ E[R_task(τ)] − λ_r Risk(τ) − c_e Energy(τ) + β I_cal(τ)`，
其中 `I_cal(τ) = ½ log det(J(τ) + J_0)`（D-最优），并约束 `E(τ) ≥ E_min` 或允许在低激励任务中插入最小「标定步」`δτ` 使其满足。若任务轨迹本身满足 `E(τ_0) ≥ E_min`，则 `δτ = ∅`，称为**免费标定**；否则按 `β` 与运动成本求最小插入。

**定义 315（观察位姿 VoI / V-MINT）** 候选信息动作包含观察位姿 `ν`：
`VoI(ν) = H(M | o) + H(X | o) − E_{y~p(·|ν,o)}[H(M, X | o, y)]`。
选择 `ν* = argmax_ν [VoI(ν) + γ·I_cal_future(ν) − c_move(ν) − risk(ν)]`，s.t. 整机认证与预算。若最大值 ≤ 0：原地不动，退化为 R69 MINT。`I_cal_future` 是该项运动对未来可观测性的期权价值。

**定义 316（外参风险传播 ERS）** 任务空间误差对外参的敏感度 `S = ∂e_task/∂X`，任务误差协方差
`Σ_task = S Σ_X S^T`，外参风险 `U_X = λ_floor(σ_task)`。
关键放大：相机角度误差 `δθ` 在深度 `d` 处造成的任务位置误差约为 `d·δθ`，而它在图像上的角签名与 `d` 无关；因此**远处目标对外参旋转误差更敏感，却更不容易从图像残差看出**。外参误差必须进入任务空间，而不能只看像素残差。

**定义 317（世界锚定回环 LCX）** 设世界固定锚点 `w` 被两个不同底盘位姿 `i, j` 观测，预测观测 `ẑ_{ij}(X)` 由外参与两姿态的几何链计算。回环残差 `r_w(i,j) = z_{ij} − ẑ_{ij}(X)`。若在 `m` 个不同位姿、非平行视向下 `max_{w,i,j} ||r_w|| ≤ τ_anchor`，称 `X` **世界验证通过**。世界锚点可以是已知标记、重力方向、接触点、或长期稳定的环境特征。

**定义 318（标定回声室与表观标定）** 数据一致集 `C(τ) = {X : r(X, τ) ≤ ε}`，其体积 `V_gauge(τ) = vol(C(τ))`。当训练残差下降而留出锚点误差不下降时，称发生**表观标定**，定义指数
`ACI = Δr_train / (Δe_heldout + ν)`。
高 ACI 表示模型在用自由度拟合自己：残差越来越小，外参越来越错。移动底盘的自由度会增大 `C(τ)` 的形状空间，使回声室更容易存在。

**定义 319（留出反确认纪律 HAD）** 轨迹必须被划分为**激励集**（用于估计）与**验证集**（用于检验），且验证集应包含不同底盘位姿、不同深度层、不同视向。仅当 `E ≥ E_min ∧ e_heldout ≤ τ_anchor ∧ 里程计混淆 ≤ τ_odo` 三者同时满足时，才接受外参更新；否则拒绝更新，并保持先验膨胀。

**定义 320（底盘-里程计混淆 BOC）** 外参 `X` 与底盘位姿 `T_b` 可能被联合估计。若里程计噪声的敏感方向与外参的敏感方向重叠，则外参更新可能吸收里程计漂移（或反之）。定义归一化混淆度
`ρ_odo = ||Σ_{X,T_b}||_F / sqrt(tr Σ_X · tr Σ_{T_b})`。
`ρ_odo > τ_odo` 时禁止仅凭底盘相对运动更新外参，必须引入独立的世界锚点或外部基座位姿测量。

**定义 321（事件与跳变模型）** 外参在事件点分段常值：`X_t = X_{k(t)}`。用新息监测检测跳变；跳变与慢漂移分开处理——**不得跨事件外推**，跳变后必须重新进入可观测性门与留出验证。事件包括负载变化、悬架异常压缩、装夹碰撞、轮胎打滑进入不同摩擦域。

**定义 322（威胁模型 ℰ_STRIDE）** `ℰ_STRIDE = ℰ_FLUID × ℰ_excite × ℰ_anchor × ℰ_odo`：
`ℰ_excite` = 退化激励注入（诱导系统在不可观测运动上「确认」外参）、激励饥饿、抖动洪泛（用大量无效微动耗尽预算）；
`ℰ_anchor` = 锚点伪造/移动锚点/反光欺骗；
`ℰ_odo` = 打滑注入、轮式里程计投毒、地面反射导致的视觉里程计漂移。

**定义 323（证书 J_STRIDE）** `J_STRIDE = (J_FLUID, E, κ(J), σ_X, e_heldout^p95, ACI, V_gauge, base_motion_used, ρ_odo, stride_ver)`。
Valid ⇔ Valid(J_FLUID) ∧ `E ≥ E_min` ∧ `e_heldout^p95 ≤ τ_anchor` ∧ 独立锚点位数 ≥ m ∧ 整机运动认证通过 ∧ `ρ_odo ≤ τ_odo`。

**定义 324（两级安全运动与保守退避）** 若外参更新被接受且世界验证通过：`U_X` 使用收缩后的后验，允许精度关键动作，并获得 **resolution bonus**（比 R69 更不保守但不更低安全）。
若不可观测 / 验证失败 / 事件跳变 / 混淆超限：`U_X` 膨胀回先验，`λ = λ_floor(U_ale + 未消解 U_epi + U_X^prior)`，并禁止在无外部锚定的情况下越过安全站位执行抓取/推压；可选地移动到一个**经认证的验证位姿**再试，否则原地保守。

**定义 325（严格退化链）** 当 `a_b ≡ 0`、`ν = I`、外参已知且 `Σ_X = 0`、锚点静止时：MBE 返回原任务轨迹，HEX 不更新，VOG 恒真，V-MINT 退化为 R69 MINT，ERS 输出 0，LCX/HAD/BOC 不触发，`U_X = 0` ⇒ **STRIDE-RAS ≡ FLUID-RAS**。再叠加「VoI ≤ 成本」退化为 R68；再叠加「永不交互」退化为 R67。安全侧永不弱于上一层。

**定义 326（标定步调度与时间耦合）** 「标定步」只能在自由空间/运输段/非接触窗口插入，接触、精密对位、人机近距离阶段禁止；单位时间底盘激励位移 ≤ `ε_b`，社交/能耗成本 ≤ `c_b`；若任务进入长直线退化段，调度器在进入前寻找最近的合法窗口插入一次最小激励，而不是在关键阶段临时补标。

# IP-264 MBE：双用途轨迹规划（异步，任务级；实时环只做认证查询）
def plan_dual_use(task_goal, X_post, budget):
    tau0 = task_planner(task_goal)
    E0   = excitation_score(tau0, X_post)          # λ_min(J)
    if E0 >= E_MIN:                                # 任务本身已充分激励
        return tau0, 0.0                           # 免费标定
    dither = min_certified_dither(E_MIN - E0, budget)   # S 形/回转，整机认证
    return interleave(tau0, dither), dither.cost

# IP-265 HEX：手眼外参隐状态滤波（SE(3)，含动态工况与事件）
class HandEyeState:
    def predict(self, dt, eta):                    # eta: 倾角/加速度/负载
        self.mu     = retract(self.mu, drift(eta, dt))
        self.Sigma += Q(eta) * dt                  # 工况相关过程噪声
    def update(self, motions, W):
        for A, B in motions:                       # AX=XB
            r = se3_log((A @ self.mu) @ inv(self.mu @ B))
            H = jacobian_X(r, self.mu)
            self.Sigma = inv(inv(self.Sigma) + H.T @ W @ H)
            self.mu    = retract(self.mu, -self.Sigma @ H.T @ W @ r)

# IP-266 VOG：可观测性门（零残差 ≠ 证据）
def observability_gate(motions):
    J = fisher_information(motions)                # 6x6 外参信息
    return lambda_min(J) >= J_MIN and cond(J) <= COND_MAX, lambda_min(J), cond(J)

# IP-267 V-MINT：把「换一个观察位姿」当信息动作
def vantage_voi(modes, X_post, candidates, budget):
    best = None
    for nu in candidates:                          # 底盘/臂候选观察位姿
        if not certify_whole_body(nu): continue    # 稳定性/碰撞/社交
        H_after = expected_entropy_after_move(modes, X_post, nu)
        voi = H(modes) + H(X_post) - H_after
        score = voi + GAMMA * future_excitation(nu) - move_cost(nu) - risk(nu)
        if best is None or score > best.score: best = (nu, score)
    return best if best and best.score > 0 else None   # 无利可图 → 原地 R69

# IP-268 ERS：外参不确定度 → 任务空间风险（深度放大）
def extrinsic_risk(X_post, grasp_pose, standoff):
    S = d_task_error_d_X(grasp_pose, standoff)      # 角度误差 ~ standoff
    return sigma_floor(S @ X_post.Sigma @ S.T)

# IP-269 LCX：世界锚定 + 留出验证（异步）
def heldout_anchor_error(X, anchor_log, holdout):
    errs = []
    for (i, j, w) in holdout:                       # 不同底盘位姿看同一锚点
        errs.append(anchor_reproj(X, anchor_log[i], anchor_log[j], w))
    return percentile(errs, 95)

## 3. 推导

**引理 19（退化激励下的零残差不构成证据）** 设外参残差 `r_i(X)` 在真值 `X*` 附近线性化 `r_i(X*+δX) ≈ r_i(X*) + H_i δX`。若运动集合的 Fisher 信息有零特征方向 `δX ∈ ker J`，则 `H_i δX = 0` 对所有 `i` 成立，于是 `r_i(X*+δX) = r_i(X*)` 到一阶。由 Cramér–Rao，`Cov(X̂) ⪰ J^{-1}`；当 `λ_min(J) → 0` 时，误差下界发散。**系**：R68 的「残差≈0 ⇒ 标定可信」对手眼外参不成立；必须先用 VOG 检验「我是否被检验过」，再谈残差大小。这也解释了为什么长直线行驶的移动底盘最容易在「零残差」中丢失外参。

**引理 20（双用途激励的收益-成本阈值）** 设任务轨迹 `τ_0` 的外参后验协方差为 `Σ_0`，插入标定步 `δτ` 增加信息 `ΔJ`，成本 `c(δτ)`。后验变为 `Σ_1 = (Σ_0^{-1} + ΔJ)^{-1}`。任务收益的边际近似为
`ΔR ≈ ½ tr(S Σ_0 S^T) − ½ tr(S (Σ_0^{-1}+ΔJ)^{-1} S^T)`。
插入当且仅当 `ΔR > c(δτ) + risk(δτ)`。**系**：当任务轨迹已满足 `E(τ_0) ≥ E_min` 时 `ΔR` 已被任务顺带获得，标定是免费的；只在退化任务段才需要付费。因此标定应作为任务规划的一项，而不是独立阶段。

**引理 21（外参误差的深度放大）** 对焦深 `d`、相机角度误差 `δθ`，任务空间位置误差 `||δp|| ≈ d·δθ + δt`；而该旋转误差在图像上的角位移约为 `δθ`（与 `d` 无关），平移误差的图像位移约为 `δt/d`。故随着 `d` 增大，**任务误差对角度外参越来越敏感，而图像残差对它的可分辨性并不增强**；对平移外参则相反（远处几乎不可见）。**系**：外参不确定性必须通过 ERS 传播到任务空间；同一 `Σ_X` 在不同站位对应完全不同的风险，规划应同时选择站位与精度。

**引理 22（世界锚定与留出验证的可辨识性）** 在 A103（锚点在至少两个深度层、至少两个非平行视向下可观测；底盘位姿与锚点测量噪声独立）下，映射 `X ↦ {r_w(i,j)}` 在真值邻域局部单射。因此存在错误 `X' ≠ X` 能在一组位姿上自洽，但它无法同时解释另一组不同视向/深度的留出锚点，除非引入额外的里程计补偿。**系**：留出世界锚定不是「多一道保险」，而是把 `C(τ)` 从「训练轨迹一致集」收缩到「跨位姿世界一致集」的**唯一**手段；单靠训练残差永远无法排除回声室。

**定理 18（STRIDE 严格包含 R69）** 在 A102–A104 下，STRIDE 在任意状态上的期望风险 ≤ FLUID-RAS；当 `a_b ≡ 0`、`Σ_X = 0`、锚点静止时两者**逐指令相同**（定义 325）。当 VOG/HAD/BOC 任一失败时，`λ` 单调不降地退化为 R69/R68，且执行动作被限制在同一安全集内。故 R69 是 STRIDE 在「固定基座、已知外参」边界上的精确退化；安全侧不做任何让步。

**定理 19（整机运动安全与无缝退化）** 若所有底盘运动均通过 C-RAS-WM 整机认证（定义 310-ii），则信息运动与任务运动的物理风险均 ≤ 认证包络；`ν` 只改变观察位姿与后续选择的模态，不改变当前已认证的安全包络。外参更新只通过连续的前馈变换作用于控制，事件跳变必须在静止/受控窗口内过渡；失败/超时/不可观测时 `λ` 单调退化为 R69 ⇒ 控制连续、无突变。

**定理 20（反自我确认下界）** 在 A103 与独立底盘位姿测量下，任何被 HAD 接受的外参 `X̂` 满足 `||X̂ − X*|| ≤ ε` 的概率 ≥ `1−δ`；反之，若只最小化训练残差、不使用留出世界锚定，则存在高 `V_gauge` 的轨迹使任意错误 `X'` 以任意高的训练置信度通过。**系**：held-out 世界锚定是**必要**条件而非可选项；「走到让残差最小的地方」与「走到能被验证的地方」是两件不同的事——前者可以自欺，后者才可证伪。

## 6. 本轮最大风险

**一句话**：STRIDE 的全部收益押在「运动会让标定更可辨识」这一前提上，但移动底盘同时也把「不可辨识」变成了可主动选择的对象——**系统可能主动走到一个让当前错误手眼外参最自洽的位姿，把「主动标定」变成「主动自我确认」；它以为自己走到了能看清的地方，其实只是走到了能证明自己没错的地方**。

**次级风险与缓解**：
1. **退化激励下的零残差**（纯平移、平行转轴）→ VOG 门 + 引理 19 的 CRLB 下界，低残差不得作为证据；
2. **标定回声室 / 留出污染** → 世界锚定 LCX + 跨视向/深度的 HAD 留出验证 + 定理 20；
3. **底盘里程计与外参混淆**（打滑被吸收成外参修正）→ BOC 混淆度 + 独立基座位姿/锚点，禁止单靠相对运动更新；
4. **事件跳变被当成慢漂移** → 事件检测 + 分段常值模型，跨事件不外推；
5. **标定步本身不安全/扰民** → 定义 310-ii 整机认证 + 定义 326 窗口调度，接触/精密阶段禁止插入；
6. **外参误差的深度放大** → ERS 把 `Σ_X` 传播到任务空间，远距任务降速或先缩站位，而不是只看像素残差。

**当前方案的最大风险（一句话）**：移动让手眼标定第一次变得「可做」，也让「做错」第一次变得「可自证」——**最难防的不是标不准，而是系统找到了一个让自己相信标得准的位置**。

**定义 311–312（整机动作与手眼隐状态）** `ξ=(a_b,a_r,g,ν)`，`a_b≡0,ν=I` 时退化为 R69 的 `𝒜_+`；`X_t=X_0∘exp(Σ_j η_{t,j}ξ_j^∧)`，事件点跳变、事件间慢漂移；观测方程 `r_i=log((A_iX)(XB_i)^{-1})`。

**定义 313（VOG 与零残差非证据）** `E=λ_min(J)`，`κ=cond(J)`；纯平移使旋转分量不可观测，单轴/平行轴旋转使其余分量不可观测；`δX∈ker J ⇒ r(X+δX)=r(X)` 一阶成立。**低残差只说明数据没反驳我，不说明我被检验过。**

**定义 314（双用途 DUA）** `τ*=argmax E[R_task]−λ_rRisk−c_eEnergy+βI_cal`，约束 `E(τ)≥E_min`；任务轨迹已激励则 `δτ=∅`（免费标定），否则插入最小认证标定步。

**定义 315（观察位姿 VoI）** `ν*=argmax[VoI(ν)+γI_cal_future(ν)−c_move−risk]`；≤0 则原地，退化为 R69 MINT。R69 的 MINT 是「候选位姿只有原地」的边界。

**定义 316（外参风险 ERS）** `Σ_task=SΣ_XS^T`，`U_X=λ_floor(σ_task)`；角度误差 `δθ` 在深度 `d` 处任务误差 `≈dδθ`，而图像角签名与 `d` 无关 ⇒ 远距任务对旋转外参更敏感、却更难从残差看出。

**定义 317（世界锚定 LCX）** 锚点 `w` 在底盘位姿 `i,j` 的预测/实测差 `r_w(i,j)`；`m` 个位姿、非平行视向下 `max||r_w||≤τ_anchor` 才算世界验证通过。

**定义 318（回声室与表观标定）** `C(τ)`、`V_gauge`、`ACI`；训练残差降而留出误差不降 ⇒ 表观标定。底盘自由度会扩大 `C(τ)` 的形状空间。

**定义 319（留出反确认 HAD）** 激励集/验证集分离，验证集需跨视向、跨深度；`E≥E_min ∧ e_heldout≤τ_anchor ∧ ρ_odo≤τ_odo` 同时成立才接受外参更新。

**定义 320–321（里程计混淆与事件模型）** `ρ_odo=||Σ_{X,T_b}||_F/√(trΣ_X·trΣ_{T_b})`；超限时禁止仅凭底盘相对运动更新外参；外参分段常值，事件跳变与慢漂移分开，跨事件不外推。

**定义 322–323（威胁与证书）** `ℰ_STRIDE=ℰ_FLUID×ℰ_excite×ℰ_anchor×ℰ_odo`（退化激励注入/激励饥饿/抖动洪泛；锚点伪造/移动锚点；打滑/里程计投毒）。`J_STRIDE` 并入 `E,κ,σ_X,e_heldout,ACI,V_gauge,base_motion,ρ_odo`。

**定义 324–325（两级退避与严格包含）** 外参验证通过：`U_X` 用收缩后验，获 resolution bonus；不可观测/验证失败/事件跳变/混淆超限：`U_X` 膨胀回先验，`λ=λ_floor(U_ale+未消解U_epi+U_X^prior)`，禁止无锚定越站位精确操作。`a_b≡0,Σ_X=0` 时 STRIDE ≡ FLUID，再退化 R68/R67。

**定义 326（标定步调度）** 只在自由空间/运输段/非接触窗口插入标定步；单位时间激励位移 `≤ε_b`，社交/能耗 `≤c_b`；长直线退化段进入前提前安排，不在接触/精密阶段临时补标。

# IP-264 MBE：双用途轨迹规划（免费标定优先，退化段才插入最小标定步）
def plan_dual_use(task_goal, X_post, budget):
    tau0 = task_planner(task_goal)
    if excitation_score(tau0, X_post) >= E_MIN:      # 任务本身已激励
        return tau0, 0.0
    dither = min_certified_dither(E_MIN, budget)      # S 形/回转，整机认证
    return interleave(tau0, dither), dither.cost

# IP-265 HEX：手眼外参 SE(3) 隐状态（动态工况 + 事件跳变）
class HandEyeState:
    def predict(self, dt, eta):
        self.mu     = retract(self.mu, drift(eta, dt))
        self.Sigma += Q(eta) * dt
    def update(self, motions, W):
        for A, B in motions:
            r = se3_log((A @ self.mu) @ inv(self.mu @ B))   # AX = XB
            H = jacobian_X(r, self.mu)
            self.Sigma = inv(inv(self.Sigma) + H.T @ W @ H)
            self.mu    = retract(self.mu, -self.Sigma @ H.T @ W @ r)

# IP-266 VOG：可观测性门（退化激励下零残差不算证据）
def observability_gate(motions):
    J = fisher_information(motions)
    return lambda_min(J) >= J_MIN and cond(J) <= COND_MAX, lambda_min(J), cond(J)

# IP-267 V-MINT：把「换观察位姿」当信息动作
def vantage_voi(modes, X_post, candidates, budget):
    best = None
    for nu in candidates:
        if not certify_whole_body(nu): continue
        voi = entropy(modes) + entropy(X_post) - expected_entropy_after_move(modes, X_post, nu)
        score = voi + GAMMA * future_excitation(nu) - move_cost(nu) - risk(nu)
        if best is None or score > best.score: best = (nu, score)
    return best if best and best.score > 0 else None      # 原地 → R69

# IP-268 ERS：外参 → 任务风险（深度放大）
def extrinsic_risk(X_post, grasp_pose, standoff):
    S = d_task_error_d_X(grasp_pose, standoff)
    return sigma_floor(S @ X_post.Sigma @ S.T)

# IP-269/270 LCX+HAD：世界锚定留出验证，拒绝表观标定
def accept_extrinsic(train_res, X_post, anchor_log, holdout, E, rho_odo):
    if E < E_MIN:                 return REJECT_UNOBSERVABLE
    if rho_odo > TAU_ODO:         return REJECT_CONFOUNDED
    e_ho = percentile([anchor_reproj(X_post, anchor_log[i], anchor_log[j], w)
                       for (i, j, w) in holdout], 95)
    if e_ho > TAU_ANCHOR:         return REJECT_ECHO
    return ACCEPT

# IP-275 主闭环
def STRIDE_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    M.hex.predict(dt, eta=M.chassis.regime)
    ok_obs, E, cond = M.vog(M.motion_window)
    U_X = M.ers.extrinsic_risk(M.hex.post, M.grasp_pose, M.standoff)
    if not ok_obs: U_X = M.ers.prior_inflate(U_X)
    tau, stride_cost = M.mbe.plan_dual_use(M.task_goal, M.hex.post, M.budget)
    nu = M.vmint.choose(modes, M.hex.post, M.vantage_candidates, M.budget)
    verdict = M.had.accept(M.pending.train_res, M.hex.post, M.anchor_log,
                           M.holdout, E, M.boc.confound())
    if verdict == ACCEPT: M.hex.commit(M.pending.update)
    else:                 U_X = M.ers.prior_inflate(U_X)
    U_floor = U_ale + (U_epi if nu is None else 0.0) + U_X
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    A = M.ach.propose(x_prime, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, whole_body=True, ..., wm_preds)
    mode = select_mode(modes, U_epi, lam)
    tau_cmd = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_v.submit_async(nu, verdict, E, U_X, stride_cost)
    return k, lam, mode, (U_ale, U_epi, U_X)

## 4. 推导

**引理 19（退化激励下的零残差不构成证据）** `r_i(X*+δX) ≈ r_i(X*)+H_iδX`。若 `δX∈ker J`，则 `H_iδX=0` 对所有 `i`，故 `r_i(X*+δX)=r_i(X*)` 至一阶。由 Cramér–Rao `Cov(X̂)⪰J^{-1}`，`λ_min(J)→0` 时误差下界发散。**系**：R68 的「残差≈0 ⇒ 标定可信」对手眼外参失效；必须先过 VOG。长直线行驶的移动底盘最容易在零残差中丢失外参。

**引理 20（双用途激励的收益-成本阈值）** `Σ_1=(Σ_0^{-1}+ΔJ)^{-1}`，
`ΔR≈½tr(SΣ_0S^T)−½tr(S(Σ_0^{-1}+ΔJ)^{-1}S^T)`；插入标定步当且仅当 `ΔR>c(δτ)+risk(δτ)`。**系**：任务本身 `E(τ_0)≥E_min` 时标定免费；只有退化任务段才付费。标定是任务规划的一项，不是独立阶段。

**引理 21（外参误差的深度放大）** 角度误差 `δθ` 在深度 `d` 处任务误差 `≈dδθ`，其图像角位移 `≈δθ` 与 `d` 无关；平移误差图像位移 `≈δt/d`。故远处目标对旋转外参更敏感、却更难从图像残差看出。**系**：外参不确定性必须经 ERS 进入任务空间；同一 `Σ_X` 在不同站位风险不同。

**引理 22（世界锚定与留出验证的可辨识性）** A103（锚点跨 ≥2 深度层、≥2 非平行视向；底盘位姿与锚点噪声独立）下，`X↦{r_w(i,j)}` 在真值邻域局部单射。错误 `X'` 可在训练位姿自洽，但无法同时解释不同视向/深度的留出锚点，除非引入额外里程计补偿。**系**：留出世界锚定是排除回声室的唯一手段，不是可选项。

**定理 18（STRIDE 严格包含 R69）** A102–A104 下，STRIDE 任意状态期望风险 ≤ FLUID；`a_b≡0,Σ_X=0,`锚点静止时逐指令相同；VOG/HAD/BOC 失败时 `λ` 单调不降退化为 R69/R68，执行动作限制在同一安全集内。

**定理 19（整机运动安全与无缝退化）** 所有底盘运动经整机 C-RAS-WM 认证 ⇒ 物理风险 ≤ 包络；`ν` 只改观察位姿与模态选择，不改当前安全包络；外参更新只经连续前馈变换作用，事件跳变在受控窗口过渡；失败/超时/不可观测时 `λ` 单调退化 ⇒ 控制连续、无突变。

**定理 20（反自我确认下界）** A103 + 独立底盘位姿测量下，被 HAD 接受的 `X̂` 满足 `||X̂−X*||≤ε` 的概率 ≥ `1−δ`；若只用训练残差、无留出世界锚定，则存在高 `V_gauge` 轨迹使任意错误 `X'` 以任意高训练置信度通过。**系**：「走到让残差最小处」与「走到能被验证处」是两件事——前者可自欺，后者才可证伪。

## 7. 本轮最大风险

**一句话**：STRIDE 的全部收益押在「运动会让标定更可辨识」上，但移动底盘同时把「不可辨识」变成可主动选择的对象——**系统可能主动走到一个让当前错误手眼外参最自洽的位姿，把「主动标定」变成「主动自我确认」；它以为自己走到了能看清的地方，其实只是走到了能证明自己没错的地方**。

**次级风险与缓解**：退化激励零残差（VOG + 引理 19）；标定回声室/留出污染（LCX + 跨视向 HAD + 定理 20）；底盘里程计混淆（BOC + 独立锚点，禁止单靠相对运动更新）；事件跳变被当慢漂移（分段常值 + 事件检测，跨事件不外推）；标定步扰民/越界（整机认证 + 窗口调度）；深度放大（ERS 进入任务空间，远距降速或缩站位）。
