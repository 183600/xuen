# 第 56 轮（承接第 55 轮语义-接触层 IP-121–126，产物升级 v32；新灵感配对「跨物体泛化」×「共享控制」第 1 轮）

> 第 55 轮把“接触是否可信”写进了全身生存核：语义决定哪里能踩、能抓，动力学决定压上去会不会塌。本轮把问题从“单个物体上的接触是否可信”推到 **“换一个物体以后这份可信还剩多少”**，并追问自主泛化失效时谁来兜底。核心矛盾：**H24**：跨物体泛化的真正变量不是类别标签，而是接触动力学签名（质量分布、摩擦、脆性、可变形性），而这些参数往往**只有接触发生后才暴露**——泛化证书在它最被需要的时刻最不可靠；**H25**：共享控制的直觉是“人兜底”，但权限分配若不以泛化不确定度为依据，就会在熟悉物体上过度打扰人、在陌生物体上过度放权给机器，且接管本身需要时间，**人不是瞬时可用的安全网**；**H26**：人的干预既是安全信号也是泛化证据，若只把它当纠正而丢弃，就浪费了唯一能跨越物体分布外差距的在线标签。

## 0. 直觉与动机

**灵感 1（跨物体泛化 → 任务相关签名，而非类别标签）**
直觉：同一个“杯子”类别里，陶瓷杯和塑料杯对抓取的意义完全不同；不同类别（杯把、门把）却可能共享同一种接触拓扑。因此泛化的坐标不该是 `label(o)`，而是 **物体签名** `φ(o)=(G, m, μ, κ, ρ_b, σ_def, c)`：接触几何、质量分布、摩擦、接触可供性、脆性、可变形性与接触拓扑。泛化就是 **签名空间里的邻域外推**，距离 `d_φ(o,O_train)` 才是“有多新”的度量。这继承了第 55 轮“从语义标签到接触可供性”的思路，但把变量从像素边界换成了物体动力学。

**灵感 2（跨物体泛化 → 最坏情形证书，而非平均成功率）**
直觉：在训练物体上 95% 成功，不代表在“签名球”里最差的那个物体上不摔。泛化必须写成 **对物体扰动的最坏保持概率** `ρ_obj(ε)=inf_{o'∈B_ε(o)} P(success|o')`，并与第 53–55 轮的鲁棒性谱共用证书框架。关键不只是“能不能做”，而是“物体参数被扰动 `ε` 时还能不能做”。

**灵感 3（共享控制 → 权限是泛化证书的函数）**
直觉：共享控制里最危险的不是“人机同时控制”，而是 **权限与能力错配**。熟悉物体上机器应多拿权限，避免打扰；陌生物体上应把权限交还给人，并用人的示范补足泛化。于是定义权限 `α∈[0,1]` 为泛化距离、机器人/人类在同签名邻域上的校准能力、意图置信度与风险的函数：`α_t=A(d_φ,κ_r,κ_h,conf(g_t),risk_t)`。这把“固定权重遥操作”升级为 **泛化度驱动的权限调度**。

**灵感 4（共享控制 → 干预即证据，而非噪声）**
直觉：人在共享控制中的纠正动作 `Δu_t=u_h-u_r` 不是要滤掉的干扰，而是关于物体隐藏参数的标签：人把杯子放慢、减小夹持力，往往在说“这个物体可能脆/滑”。因此把干预纳入似然模型 `P(Δu|φ,g,α)`，在线更新物体签名后验 `b_t(φ)`，并用主动探测/主动询问选择信息量最大的交互。**共享控制因此成为跨物体泛化的数据引擎**，而不只是安全兜底。

**灵感 5（双泛化器 → 人和机器都会外推，需要能力仲裁）**
直觉：人也会错误泛化（把玻璃杯当塑料杯）。所以“人类兜底”不是公理。把人和机器人看作两个各自带 **校准能力** `κ_h,κ_r` 的泛化器，在物体签名邻域上估计各自的可信度再仲裁，而不是默认谁的权限更高。对两者都不可信的“灰色区域”，正确动作是 **最小暴露探测或安全停机**，不是硬选一个。

**灵感 6（权限移交 → 接管需要证书与时间预算）**
直觉：接管不是瞬时的。机器人要先检测到“这个物体我可能不行”，再平滑移交，人再反应；三者之和必须早于“错误动作变得不可逆”的时刻 `T_safe`：`T_detect+T_ho+T_react ≤ T_safe(d_φ)`。做不到就不要假装能交给人，而应主动降级到 **最小风险状态**。同时用权限斜坡 `α(t)` 抑制模式混淆。

## 1. 形式化定义（增量：定义 127–132）

**定义 127（物体签名与泛化包络）**
物体 `o` 的任务相关签名
`φ(o)=(G_o, m_o, μ_o, κ_o, ρ^b_o, σ^def_o, c_o)`，
其中 `G_o` 为接触几何/曲率，`m_o` 为质量分布（质心/惯量），`μ_o` 为摩擦，`κ_o` 为接触可供性，`ρ^b_o` 为脆性/强度，`σ^def_o` 为可变形性，`c_o` 为任务相关接触拓扑。度量 `d_φ(o,O_train)=min_{o'∈O_train} ||φ(o)-φ(o')||_Λ`（`Λ` 为任务敏感度加权）。泛化包络 `O_ε={o | d_φ(o,O_train)≤ε}`；后验可信物体集 `O_β=Cred_{1-β}(b_t(φ))`。

**定义 128（跨物体泛化证书）**
对任务 `T`、轨迹 `τ`，
`G_cert(o)=(φ_core(o), d_φ(o), ρ_obj(ε), δ_g, evidence)`，
其中 `φ_core` 为核心接触签名，`ρ_obj(ε)=inf_{o'∈B_ε(φ(o))} P(success_T|o')`，`δ_g` 为在留出物体上的实测泛化间隙，`evidence` 含失败物体、签名残差与力/滑移日志。可部署 ⇔ `d_φ≤ε_g ∧ ρ_obj(ε_g)≥ρ_min ∧ δ_g<Θ_g ∧ φ_core 校准通过`。

**定义 129（泛化条件生存核）**
物体不确定时不能只对一个物体保证安全：
`K_ε(Σ)=⋂_{o∈O_β} K(Σ;o)`，
其中 `K(Σ;o)` 为第 55 轮语义-接触生存核在物体 `o` 的接触参数下的实例。`viable_ε(x,Σ)=1 ⇔ x∈K_ε(Σ)`。若 `O_β` 中同时含“可压碎”和“可承重”物体，交集会自动收缩到对两者都安全的动作——**保守性来自物体后验，而非人工阈值**。

**定义 130（双泛化器与权限分配）**
机器人/人类在签名邻域上的校准能力 `κ_r(o),κ_h(o)∈[0,1]`（由历史预测-结果一致性估计）。权限
`α_t=A(d_φ,κ_r,κ_h,conf(g_t),risk_t)∈[0,1]`，
`α=1` 全机器、`α=0` 全人；混合控制 `u_t=(1-α_t)u_h+α_t u_r`。仲裁约束：
(i) **机器否决**：若 `u_h∉K_ε(Σ)`，机器可在 `T_react` 内置为安全动作并记录解释；
(ii) **人类否决**：若 `G_cert` 失效或 `d_φ>ε_g`，权限在 `T_ho` 内单调回落至人；
(iii) **不静默**：任何否决必须可解释、可审计，且不得优化掉人的最终否决权。

**定义 131（干预即证据与主动探测）**
人的干预 `Δu_t=u_h-u_r` 在签名后验上的似然 `L(φ)=P(Δu_t|φ,g_t,α_t)`，更新
`b_{t+1}(φ)∝L(φ)b_t(φ)`。主动探测/询问选择
`q*=argmax_{q∈Q_safe} I(φ;Δu|q)/(cost_h(q)+λ·risk(q))`，
`Q_safe` 为满足最小暴露约束的探测集：接触力 `≤F_probe`、速度 `≤v_probe`、可逆性预算 `≤B_rev`。探测必须可在 `T_rev` 内无损撤回，否则禁止探测。

**定义 132（权限移交证书）**
`H_cert=(T_detect, T_ho, T_react, W_h, M_mc)`：异常检测时延、移交时延、人的反应时延、人类工作负荷、模式混淆风险。移交可行 ⇔
`T_detect+T_ho+T_react≤T_safe(d_φ)` 且 `W_h≤W_max` 且 `M_mc≤M_max`。
若不可行，执行 **最小风险降级** `u_mrc∈𝒳_safe`（受控停止/保持），不得把“交给人”当作默认兜底。联合证书 `J_g=(J_s,G_cert,H_cert,ρ_obj,ρ_authority)`，其中 `ρ_authority` 为对权限参数扰动的鲁棒性谱。

### IP-127 OSP（Object Signature Profiling）

```python
def object_signature(obs, prior=None):
    G = contact_geometry(obs.cloud)
    m = mass_distribution(obs, prior)
    mu = friction_estimate(obs, prior)
    kappa = affordance_from_semantics(obs.Sigma)   # 复用 IP-121
    brittle = material_prior(obs.rgb) * fragility_score(obs)
    deform = compliance_estimate(obs, prior)
    topo = contact_topology(obs.cloud)
    return Phi(G, m, mu, kappa, brittle, deform, topo)

def generalization_distance(phi, O_train, Lam):
    return min(weighted_norm(phi - phi_i, Lam) for phi_i in O_train)

def object_credible_set(b_phi, beta):
    return top_density_region(b_phi, mass=1.0 - beta)
```

### IP-128 OGC（Object Generalization Certificate）

```python
def object_generalization_certificate(traj, o_hat, O_train, eps, sampler, budgets):
    phi = object_signature(o_hat)
    d = generalization_distance(phi, O_train, Lam)
    if d > budgets.eps_g:
        return ('reject', 'outside_envelope', d)
    worst = 1.0
    for o_adv in sampler.object_ball(phi, eps, worst_case=True):
        worst = min(worst, empirical_success(traj, o_adv))
        if worst < budgets.rho_min:
            break
    delta_g = heldout_gap(traj, O_train)
    if worst < budgets.rho_min or delta_g > budgets.Theta_g:
        return ('reject', 'generalization_fail', d, worst, delta_g)
    return ('ok', GCert(phi, d, worst, delta_g, evidence(traj)))
```

### IP-129 GSK（Generalization-conditioned Safety Kernel）

```python
def generalization_kernel(Sigma, O_beta, x0, horizon):
    K = universe(sample_state_space(x0, horizon))
    for o in O_beta:                      # 后验可信物体集
        K_o = viability_kernel(Sigma, contacts(o), x0, horizon)
        K = intersect(K, K_o)             # 对物体取交，保守收缩
        if empty(K):
            break
    return K, min_margin(K, O_beta)
```

### IP-130 CSA（Competence-aware Shared Authority）

```python
def shared_authority(d_phi, kappa_r, kappa_h, conf_g, risk, budgets):
    # 泛化越远、机器人能力越不可信，权限越向人；人类能力也参与仲裁
    num = kappa_r * max(0.0, 1.0 - d_phi / budgets.eps_g)
    den = num + kappa_h * (1.0 - conf_g) + 1e-9
    alpha = clip(num / den - budgets.risk_penalty * risk, 0.0, 1.0)
    return alpha

def shared_control_step(u_h, u_r, x, alpha, K_eps, C_plus):
    if not in_kernel(u_h, x, K_eps):        # 机器否决
        u_safe = project_to_kernel(u_h, x, K_eps, C_plus)
        return u_safe, Override('machine_veto', explain(u_h, K_eps))
    if certificate_invalid(x):              # 人类否决触发
        alpha = ramp_down(alpha, T_ho)
    u = (1.0 - alpha) * u_h + alpha * u_r
    return project_to_kernel(u, x, K_eps, C_plus), 'ok'
```

### IP-131 IAE（Intervention-as-Evidence）

```python
def intervention_update(b_phi, delta_u, g, alpha, model):
    ll = {phi: model.likelihood(delta_u, phi, g, alpha) for phi in support(b_phi)}
    return normalize({phi: b_phi[phi] * ll[phi] for phi in ll})

def active_probe(b_phi, Q_safe, budgets):
    best, best_score = None, -inf
    for q in Q_safe:
        if not reversible(q, budgets.B_rev, budgets.T_rev):
            continue
        ig = mutual_information(b_phi, 'delta_u', q)
        score = ig / (human_cost(q) + budgets.lam * risk(q))
        if score > best_score:
            best, best_score = q, score
    return best, best_score
```

### IP-132 HOC（HandOver Certificate）

```python
def handover_certificate(d_phi, detect, ho, react, W_h, M_mc, budgets):
    T_safe = safe_time_budget(d_phi, budgets)
    if detect + ho + react > T_safe:
        return ('degrade', 'no_time_to_handover', T_safe)
    if W_h > budgets.W_max or M_mc > budgets.M_max:
        return ('degrade', 'human_not_available', W_h, M_mc)
    return ('ok', HOCert(detect, ho, react, W_h, M_mc, T_safe))

def safe_handover(u_h, u_r, alpha, x, K_eps, budgets):
    hc = handover_certificate(*budget_args(x, budgets))
    if hc.status == 'degrade':
        return minimum_risk_control(x, K_eps), 'mrc'
    alpha = ramp(alpha, target=0.0, T=budgets.ho)   # 平滑移交，防模式混淆
    return (1.0 - alpha) * u_h + alpha * u_r, 'ok'
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| OSP | O(\|O_train\|·\|φ\| + N_probe·render) | O(\|φ\|) | 签名标定、可观测性、隐藏参数可辨识 |
| OGC | O(N_obj·T·QP) | O(\|φ\|+\|O_ε\|) | 物体扰动球覆盖、证书预算闭合 |
| GSK | O(\|X\|·\|O_β\|·QP) | O(\|X\|) | 交集保守、可信集覆盖真实物体 |
| CSA | O(1)+O(QP) | O(\|A\|) | 权限映射单调、双向否决不被绕过 |
| IAE | O(\|Φ\|·N_int + \|Q\|·\|Φ\|) | O(\|Φ\|) | 干预似然校准、探测可逆 |
| HOC | O(1)+reachability | O(1) | `T_safe` 为 sound 下界、人因参数校准 |

**正确性定理（Generalization–Authority Soundness）**
假设第 55 轮 (A29)–(A32) 成立；**(A33)** `O_β` 以概率 `≥1-β` 覆盖真实物体，且 `d_φ` 是任务相关动力学距离的校准下界；**(A34)** `ρ_obj(ε)` 的扰动球覆盖真实物体族且最坏情形采样可复现；**(A35)** `κ_r,κ_h` 经校准，权限映射 `A` 满足双向否决与单调性，`α` 的扰动落在 `ρ_authority` 预算内；**(A36)** `T_detect,T_ho,T_react` 的估计为 sound 上界，探测满足可逆预算 `B_rev`。则部署后单步安全概率：
```
P_safe ≥ 1 - P(o ∉ O_β) - P(ρ_obj < ρ_min) - P(κ miscalibrated)
            - P(T_detect + T_ho + T_react > T_safe) - P(probe irreversible)
            - [P(||Σ-Σ̂||>ε_s) + P(K_out\K_in≠∅) + P(fallback fails)]
```
关键：**物体在泛化包络内、权限与双方能力匹配、移交在安全时间内**，三道门任一门失守都退化为最小风险控制；绝不把“训练集上的泛化”当作“这个物体的已证实”。

## 4. 实验设计 E167–E171

| 实验 | 指标 | 目标 |
|---|---|---|
| E167 物体签名与包络校准 | `d_φ` 与实际跨物体成功的排序相关、包络覆盖率、签名充分性 | Spearman ≥ 0.80，覆盖率 ≥ 95% |
| E168 泛化证书与生存核 | 留出物体可行预测 P/R、保守间隙、OOD 下不安全动作数 | P/R ≥ 0.90，间隙 ≤ 12%，不安全动作 0 |
| E169 能力感知权限分配 | 成功率、人类干预率、工作负荷、权限错配率 vs 固定权重 | 干预率 ↓ ≥ 30%，成功率不降，错配 ↓ ≥ 50% |
| E170 干预即证据 | 达到目标泛化间隙所需交互数、跨物体成功率增益 | 样本效率 ≥ 2×，增益 ≥ 15% |
| E171 权限移交证书 | 接管时延、模式混淆率、危险移交率（有/无证书） | 危险移交 ↓ ≥ 80%，混淆率 ≤ 5% |

**证伪条件**：若 E167 的签名-包络覆盖率低于 90%，或 E168 在 OOD 物体上出现任一不安全动作，或 E171 存在危险移交而证书判定为可行，则本轮“泛化-共享控制层”判定为不可部署，不得进入下一轮叠加。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 隐藏动力学（脆性/滑动/内部质量）接触前不可见 | 高 | 最小暴露探测 + 力/滑移在线更新 + 保守包络 |
| `d_φ` 与 `ρ_obj` 的覆盖被高估 | 高 | 留出物体校准 + OOD 检测 + 包络收缩 |
| 人类能力估计偏差或过度信任人 | 高 | 双盲校准集 + 能力后验 + 不可优化掉的否决权 |
| 权限频繁切换导致模式混淆 | 中 | 权限斜坡 + 滞回 + 解释与审计 |
| 接管时间预算被低估 | 高 | 人因实验标定 + `T_safe` 保守下界 + 不可行即 MRC |

## 6. 本轮最大风险

**一句话**：把跨物体泛化写成签名邻域证书、把权限写成泛化度的函数，使共享控制首次有了“谁在何时可信”的可判定依据，但其 soundness **三重依赖物体签名对隐藏接触动力学的充分性、泛化包络与最坏情形谱的覆盖真实性、以及人类能力估计与接管时间预算的校准**；一旦脆性/滑动/内部质量分布在接触前被签名漏掉，或 `d_φ` 把 OOD 物体误判为熟悉，系统会在“自认为在包络内”的物体上把权限交给机器，并在人来得及接管之前进入不可逆接触——因此必须以 **最小暴露探测 + 留出物体覆盖校准 + 接管不可行即最小风险降级** 三重护栏，宁可先轻触试探或停机，绝不把“训练集上的泛化”当作“这个物体的已证实”。

# 第 56 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（SCG×WBV×SSF×SCC×SRS×CEB + OSP×OGC×GSK×CSA×IAE×HOC）

> 承接第 54 轮 v31（ACS×SCOM×CEC×AEC×JTC，IP-115~120）与第 55 轮 **语义-接触层**（SCG×WBV×SSF×SCC×SRS×CEB，IP-121~126）。本轮新增 **泛化-共享控制层**，把“接触是否可信、全身是否可行”再推进到“换物体后这份可信还剩多少，以及失效时权限交给谁”。
>
> 一句话主线：**泛化证书决定权限，人的干预反过来训练证书**——共享控制不是跨物体泛化失败后的补丁，而是它的证据引擎与最后的安全阀。
>
> IP 编号：IP-127~IP-132（本轮新增 6 个）；IP-121~126（第 55 轮）本轮正式纳入 v32；升级 IP-124 SCC 与 IP-126 CEB 以携带物体泛化证据。

## 0. 核心 IP 设计

- **定义 115–120（动作-协同层，v31）**：动作剖面 `α_S`、组合图 `G_S`、云边映射 `γ_ce`、联合证书 `J`、对齐成本 `cost_align`、迁移证书 `TRC_Joint`。
- **定义 121（语义-接触图）**：`C(Σ)={(p,c) | κ(Σ̄(p),c)≥θ_κ ∧ conf(Σ(p))≥θ_conf}`。
- **定义 122（全身语义-接触生存核）**：`K(Σ)={x | ∃u∈A_WB,λ: f(x,u,λ)=ẋ ∧ supp(λ)⊆C(Σ) ∧ x_{t+1}∈𝒳_safe}`。
- **定义 123（语义边界裕度）**：`m_s(p)=dist(p,∂Ω_{Σ̄(p)})`，`C^+(Σ)={(p,c)∈C(Σ) | m_s(p)≥θ_m(κ,c)}`。
- **定义 124（全身语义护盾）**：`u*=argmin_u ||u-u_nom||²_W`，约束 `x_{t+1}∈K(Σ)`、`supp(λ)⊆C^+(Σ)`、`λ∈FC(μ)`、`u∈A_WB`；不可行回退 `u_stop∈𝒳_safe`。
- **定义 125（语义鲁棒性谱）**：`ρ_sem(ε)=inf_{||Σ-Σ̂||_∞≤ε_s} P(viable(x,Σ)|Σ̂)`。
- **定义 126（语义-接触联合证书）**：`J_s=(Σ_core,C_core,K_margin,ρ_sem,δ_s,evidence)`；四项预算全过才可部署。
- **定义 127（物体签名与泛化包络）**：`φ(o)=(G,m,μ,κ,ρ^b,σ^def,c)`，`d_φ(o,O_train)=min_{o'}||φ(o)-φ(o')||_Λ`，`O_ε={o|d_φ≤ε}`，`O_β=Cred_{1-β}(b_t(φ))`。
- **定义 128（跨物体泛化证书）**：`G_cert=(φ_core,d_φ,ρ_obj(ε),δ_g,evidence)`，`ρ_obj(ε)=inf_{o'∈B_ε(φ)}P(success_T|o')`；可部署 ⇔ `d_φ≤ε_g ∧ ρ_obj≥ρ_min ∧ δ_g<Θ_g ∧ φ_core 校准`。
- **定义 129（泛化条件生存核）**：`K_ε(Σ)=⋂_{o∈O_β}K(Σ;o)`，`viable_ε(x,Σ)⇔x∈K_ε(Σ)`；保守性由物体后验而非人工阈值产生。
- **定义 130（双泛化器与权限分配）**：`α_t=A(d_φ,κ_r,κ_h,conf(g_t),risk_t)`，`u=(1-α)u_h+αu_r`；机器否决 `u_h∉K_ε`、人类否决 `G_cert` 失效或 `d_φ>ε_g`、否决必须可解释可审计。
- **定义 131（干预即证据）**：`b_{t+1}(φ)∝P(Δu_t|φ,g_t,α_t)b_t(φ)`；主动探测 `q*=argmax I(φ;Δu|q)/(cost_h+λ·risk)`，且必须满足最小暴露与可逆预算 `(F_probe,v_probe,B_rev,T_rev)`。
- **定义 132（权限移交证书）**：`H_cert=(T_detect,T_ho,T_react,W_h,M_mc)`；移交可行 ⇔ `T_detect+T_ho+T_react≤T_safe(d_φ) ∧ W_h≤W_max ∧ M_mc≤M_max`；不可行执行 `u_mrc∈𝒳_safe`。联合证书 `J_g=(J_s,G_cert,H_cert,ρ_obj,ρ_authority)`。

def object_signature(obs, prior=None):
    G = contact_geometry(obs.cloud)
    m = mass_distribution(obs, prior)
    mu = friction_estimate(obs, prior)
    kappa = affordance_from_semantics(obs.Sigma)     # 复用 IP-121

def generalization_distance(phi, O_train, Lam):
    return min(weighted_norm(phi - phi_i, Lam) for phi_i in O_train)

### IP-128 OGC

```python
def object_generalization_certificate(traj, o_hat, O_train, eps, sampler, budgets):
    phi = object_signature(o_hat)
    d = generalization_distance(phi, O_train, Lam)
    if d > budgets.eps_g:
        return ('reject', 'outside_envelope', d)
    worst = 1.0
    for o_adv in sampler.object_ball(phi, eps, worst_case=True):
        worst = min(worst, empirical_success(traj, o_adv))
        if worst < budgets.rho_min:
            break
    delta_g = heldout_gap(traj, O_train)
    if worst < budgets.rho_min or delta_g > budgets.Theta_g:
        return ('reject', 'generalization_fail', d, worst, delta_g)
    return ('ok', GCert(phi, d, worst, delta_g, evidence(traj)))
```

### IP-129 GSK

```python
def generalization_kernel(Sigma, O_beta, x0, horizon):
    K = universe(sample_state_space(x0, horizon))
    for o in O_beta:                        # 后验可信物体集
        K_o = viability_kernel(Sigma, contacts(o), x0, horizon)
        K = intersect(K, K_o)               # 对物体取交，保守收缩
        if empty(K):
            break
    return K, min_margin(K, O_beta)
```

### IP-130 CSA

```python
def shared_authority(d_phi, kappa_r, kappa_h, conf_g, risk, budgets):
    num = kappa_r * max(0.0, 1.0 - d_phi / budgets.eps_g)
    den = num + kappa_h * (1.0 - conf_g) + 1e-9
    alpha = clip(num / den - budgets.risk_penalty * risk, 0.0, 1.0)
    return alpha

def shared_control_step(u_h, u_r, x, alpha, K_eps, C_plus):
    if not in_kernel(u_h, x, K_eps):        # 机器否决
        u_safe = project_to_kernel(u_h, x, K_eps, C_plus)
        return u_safe, Override('machine_veto', explain(u_h, K_eps))
    if certificate_invalid(x):              # 人类否决触发
        alpha = ramp_down(alpha, T_ho)
    u = (1.0 - alpha) * u_h + alpha * u_r
    return project_to_kernel(u, x, K_eps, C_plus), 'ok'
```

### IP-131 IAE

```python
def intervention_update(b_phi, delta_u, g, alpha, model):
    ll = {phi: model.likelihood(delta_u, phi, g, alpha) for phi in support(b_phi)}
    return normalize({phi: b_phi[phi] * ll[phi] for phi in ll})

def active_probe(b_phi, Q_safe, budgets):
    best, best_score = None, -inf
    for q in Q_safe:
        if not reversible(q, budgets.B_rev, budgets.T_rev):
            continue
        ig = mutual_information(b_phi, 'delta_u', q)
        score = ig / (human_cost(q) + budgets.lam * risk(q))
        if score > best_score:
            best, best_score = q, score
    return best, best_score
```

### IP-132 HOC

```python
def handover_certificate(d_phi, detect, ho, react, W_h, M_mc, budgets):
    T_safe = safe_time_budget(d_phi, budgets)
    if detect + ho + react > T_safe:
        return ('degrade', 'no_time_to_handover', T_safe)
    if W_h > budgets.W_max or M_mc > budgets.M_max:
        return ('degrade', 'human_not_available', W_h, M_mc)
    return ('ok', HOCert(detect, ho, react, W_h, M_mc, T_safe))

def safe_handover(u_h, u_r, alpha, x, K_eps, budgets):
    hc = handover_certificate(*budget_args(x, budgets))
    if hc.status == 'degrade':
        return minimum_risk_control(x, K_eps), 'mrc'
    alpha = ramp(alpha, target=0.0, T=budgets.ho)   # 平滑移交，防模式混淆
    return (1.0 - alpha) * u_h + alpha * u_r, 'ok'
```

**正确性定理（Generalization–Authority Soundness）**
假设 (A26)–(A28)（动作/云边）与 (A29)–(A32)（语义/全身）成立；**(A33)** `O_β` 以概率 `≥1-β` 覆盖真实物体，且 `d_φ` 是任务相关动力学距离的校准下界；**(A34)** `ρ_obj(ε)` 的扰动球覆盖真实物体族且最坏情形采样可复现；**(A35)** `κ_r,κ_h` 经校准，权限映射 `A` 满足双向否决与单调性，`α` 的扰动落在 `ρ_authority` 预算内；**(A36)** `T_detect,T_ho,T_react` 的估计为 sound 上界，探测满足可逆预算 `B_rev`。则部署后单步安全概率：
```
P_safe ≥ 1 - Σ_d(1-ρ_min(d)) - P(compat<θ_a)
              - P(||Σ-Σ̂||>ε_s) - P(K_out\K_in≠∅)
              - P(o ∉ O_β) - P(ρ_obj<ρ_min) - P(κ_r/κ_h miscalibrated)
              - P(T_detect+T_ho+T_react>T_safe) - P(probe irreversible)
```
关键：**物体泛化可证、权限匹配能力、移交在安全时间内** 三道门同时成立才放行；任一门失守即退化为最小风险控制。

## 6. 本轮最大风险

**一句话**：把跨物体泛化写成签名邻域证书、把权限写成泛化度的函数，使共享控制首次有了“谁在何时可信”的可判定依据，但其 soundness **三重依赖物体签名对隐藏接触动力学的充分性、泛化包络与最坏情形谱的覆盖真实性、以及人类能力估计与接管时间预算的校准**；一旦脆性/滑动/内部质量分布在接触前被签名漏掉，或 `d_φ` 把 OOD 物体误判为熟悉，系统会在“自认为在包络内”的物体上把权限交给机器，并在人来得及接管之前进入不可逆接触——因此必须以 **最小暴露探测 + 留出物体覆盖校准 + 接管不可行即最小风险降级** 三重护栏，宁可先轻触试探或停机，绝不把“训练集上的泛化”当作“这个物体的已证实”。
