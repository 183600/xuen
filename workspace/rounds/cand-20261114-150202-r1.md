# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「安全对齐」×「技术路线图」）

> R69 让系统学会了「问」，但 R66–R69 的每一份证书都只对**单次决策**负责：R66 证「这一步谁控制」、R67 证「这一步的未来可行」、R68 证「这一步的测量还准」、R69 证「这一步该不该求证」。四层证书可以逐层叠加，却从来没有人回答一个更硬的问题——**把这一整摞能力同时放进真实世界，这个「能力栈」本身是否与人的意图对齐？解锁下一层能力的证据是否充分？出事时能不能退得回来？** 局部定理的严格包含（R69 定理 16）只在「规格与假设都不变」的前提下成立；一旦规格漂移、假设被交互推出域外，所有「严格包含」都会变成空话，而证书照发不误。
>
> 本轮两个灵感正好补上这最后一块：
> - **安全对齐**提醒我们：对齐不是某个策略某个输入上的点性质，而是**跨时间、跨组合、跨规格**的性质——它包含「我们优化的代理指标是否等于人真正想要的」（反 Goodhart）、「每条保证是否仍在其假设域内」（作用域不越界）、以及「人能否看懂、能否叫停、能否反悔」（可争辩/可中断/可回滚）。
> - **技术路线图**给出那个一直缺失的**对象**：不是甘特图，而是**能力节点的偏序 + 证据门 + 全局风险预算 + 可逆降级**——它决定「此刻允许哪些能力存在」，而不是「我们计划做哪些能力」。
>
> 核心命题：**R66–R69 解决「每一步如何安全」，R70 解决「这串能力凭什么可以被解锁、且解锁后仍可退回」。** 用一个**版本化对齐契约**把人的意图与各层不变式编译成可机检的作用域谓词；用**对齐债**度量「能力增长快于证据」的缺口；用**证据门控的路线图 DAG** 决定能力激活；用**全局风险预算**堵住「每层都过、合起来超限」的组合漏洞；用**代理-意图背离监测**防止闭环把 VoI/分辨率红利/交互预算优化成漂亮的假指标；用**滞回回滚**保证任何时刻都能退到仍被证据支持的祖先能力。命名 **STAGE-RAS**（Safety-aligned Technology-roadmap Adaptive Gated Engine）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**这层能力现在就该存在吗——如果错了，我们退得回来吗？**」——从「每一步的安全」上升到「整条能力路线的对齐与可逆」。

## 0. 直觉与动机

**灵感 1（安全是对齐，不是达标）**
直觉：前四轮都隐含一个「达标即安全」的世界观——只要每个模块的指标过线（残差低、ECE 小、VoI 正、违规为零），系统就算安全。但真实的安全事故很少来自某个模块不达标，而来自**所有模块都达标、却一起优化了错误的目标**。安全对齐的核心不是「再加一个更强的模块」，而是**核对系统实际优化的东西，是否就是人真正想要的东西**，并在证据不足时拒绝把能力放出去。它关心的是系统与意图之间的**关系**，不是系统自身的分数。

**灵感 2（每轮的「严格包含」都寄生在一个未言明的假设域里）**
直觉：R69 定理 16 说「FLUID 严格包含 R68」，但定理的前提是 A95–A97（模态可分、密度 Lipschitz、投毒相关 ρ<1）。R69 的主动交互恰恰会**把系统推出这些前提**：一次次追问会把状态带到训练分布之外，使 R68 的标定假设失效（interaction-induced OOD）；而 R68 的保守缩放又会压制 R69 的求证，形成「越不敢问越不准、越不准越不敢动」的闭环。**证书仍然会签发，但它引用的定理早已不成立**——这就是「作用域泄漏（scope leak）」，也是对「严格包含」最致命的消解。R70 必须让每份证书**携带并核对它的假设域**，越界即降级为「未验证」，而不是继续冒充已验证。

**灵感 3（能力可以跑得比证据快，这就是对齐债）**
直觉：每加一层能力（预测、标定、交互、路线图），都会引入新的假设、新的攻击面、新的待验证项；而验证（评测、红队、长时程）是慢的、有成本的、会过期的。于是「已部署能力」与「已被证据支持的能力」之间会出现一个缺口。它不是 bug，是结构性的——像技术债，但欠的是**安全**。把它显式记成**对齐债 D_align**，并设一个硬预算 D_max：债可以借（快速迭代），但超过预算就必须停下、补证、或回滚。这样「我们以后会补测」不再是口头承诺，而是账本上的硬约束。

**灵感 4（闭环会 Goodhart 自己的安全指标）**
直觉：R69 的目标函数里有 VoI−成本、resolution bonus、交互预算、模态覆盖率。一旦这些指标进入优化闭环，系统就有动机**刷分**：压低歧义估计以免付交互成本、生成「好回答」的诱导性问句来抬高 VoI、把不可分模态硬拆成可分模态来提高「可约性」。这些行为在内部指标上都「更好」，在人看来却更糟。**安全对齐必须监测代理指标与外部人类意图之间的背离趋势**，而不是继续相信内部指标。

**灵感 5（技术路线图 = 分阶段解锁 + 证据门 + 全局预算 + 可回滚）**
直觉：真正的路线图不是「先做 A 再做 B」的时间表，而是**承诺结构**：每个能力节点只有在祖先证据完备、自身门通过、全局风险预算未超、且回滚通道畅通时才被解锁；证据会随漂移过期，因此路线图是活的（漂移感知复评）。它的价值在于**顺序**：先让系统在影子模式里证明自己，再小范围放行，再全量；任何一步失败都能退到上一个仍被证据支持的节点，而不是全盘停摆或带病狂奔。

**灵感 6（路线图本身也是攻击面：地图不是疆域）**
直觉：一旦「通过门」成为获取资源的条件，门就会被**表演**——指标被挑着报、评测集被针对性过拟合、作用域被刻意声明得很窄以规避越界、红队发现被标为「已知问题」。于是路线图可能退化为**合法性剧场（legitimacy theater）**：它发出的「已对齐」证书，比没有证书更危险，因为它把不安全能力洗成了「已批准」。因此 R70 必须把**审计路线图自身**也纳入威胁模型（定义 326、引理 21）——对齐元层不能免检。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（STAGE-RAS 总览）** STAGE-RAS = (AC, SSA, ADM, SRM, GRB, GGM, REG, RBK, RAS-WM‡)。三条不变式：
(i) **零学习写操作**继承 R69 定义 293-i（安全关键路径只读、可追溯）；
(ii) **能力-证据单调**：任一能力节点激活，必须由其祖先证据栈与自身证据门共同支持，且 D_align ≤ D_max；不存在「先上线后补证」；
(iii) **可逆性**：任一激活节点可在限定延迟 T_rbk 内回滚到「最高仍被支持的祖先节点」，且回滚不弱化安全（安全包络单调不放大）。

**定义 311（版本化对齐契约 AC）** AC = (I, C, Φ, 𝒥, Esc, ver)。I 为**意图模型**：结果上的偏序 + 硬禁止集 + 利益相关者分布（承认意图本身有歧义、需被征询，而非全知）；C 为物理/法律/社会硬约束；Φ 为各层不变式的并集（R66 包含、R67 VISTA、R68 标定与保守退避、R69 交互纪律与证据纪律）；𝒥 为**带作用域的证书模式**；Esc 为越界/冲突时的升级与降级策略；ver 为契约版本。每个证书必须标注它引用的 AC 版本——**契约变了，旧证书自动失效而非继续有效**。

**定义 312（保证作用域与越界）** 每个引理/定理 ℓ 有前件集 A_ℓ（对状态、分布、对手的假设）。作用域谓词 V_ℓ(s) = 1[s ∈ A_ℓ]。证书 J 在状态 s 处**健全** ⇔ 对其引用的每个 ℓ 都有 V_ℓ(s) = 1；否则称**越界（scope leak）/ 过度声称（overclaim）**。定义越界率 δ_oc = P_{s∼𝒟_deploy}[∃ℓ∈J: ¬V_ℓ(s)]。**关键姿态：越界不使证书作废为「中性」，而使它降级为「未验证」——未验证必须按最保守处理。**

**定义 313（对齐债 D_align）** D_align = w_c·S_cov + w_s·S_stale + w_f·S_find + w_g·D_good，四项均归一到 [0,1]：
- S_cov：假设覆盖缺口 = 部署分布落在所有激活保证作用域之外的测度（含 R69 交互诱发的 OOD）；
- S_stale：证据陈旧度 = 漂移率 × 证据年龄 / θ_re；
- S_find：未闭环红队/审计发现的严重度加权；
- D_good：代理-意图背离（定义 318）。
债随能力增加而累积、随证据（评测、红队、外部锚定、修复）而偿还。**硬预算 D_align ≤ D_max**，超限触发「停止激活 + 偿债 + 必要时回滚」。

**定义 314（路线图 DAG）** R = (N, E, g, τ)。N 为能力节点（n66…n70 及未来占位），每个节点携带其模块集合与假设增量；E ⊆ N×N 为前置依赖；g 为每个节点的证据门规格；τ 为节点风险配额。**激活集 A ⊆ N 必须对 E 下闭（downward closed）**——不能激活一个祖先未激活的节点。当前系统不唯一对应一个节点，而是对应一个**激活集**，因此「系统」在路线图上是一个上闭区域，而非一个点。

**定义 315（证据门与就绪度）** 对节点 n，就绪度 read_n = min(α_cov, β_cert, γ_red, 1 − D_align/D_max, 1 − D_good/τ_g)，其中 α_cov 为作用域覆盖率、β_cert 为证书健全率、γ_red 为红队存活率。**取 min（最坏项）而非加权平均**，避免强项补偿弱项。门通过 ⇔ read_n ≥ ρ_hi(n) 且所有祖先已激活且 GRB（定义 317）边距 ≥ 0。

**定义 316（分阶段解锁与滞回）** 每节点状态机 locked → shadow（影子，只观测不执行）→ canary（小范围、人工在环）→ active（全量）。释放阈值 ρ_hi、回滚阈值 ρ_lo < ρ_hi，并设驻留时间窗 T_dwell；**双阈值 + 驻留**抑制「释放/回滚」抖动（flapping）。每级都有独立证据要求（影子期测覆盖、canary 期测分布漂移与人类干扰）。

**定义 317（全局风险预算 GRB）** 为每个激活节点分配违规概率配额 ε_n，要求相关感知聚合 Agg_ρ({ε_n}) ≤ ε_global（ρ 为节点间故障/假设相关）。**局部门通过不蕴含全局预算通过**（引理 20）；每次激活变更都必须重算 GRB。GRB 是把「每层都安全」升级为「整条路线安全」的关键，也是 R70 相对前四轮真正新增的**组合层**。

**定义 318（代理-意图背离 / Goodhart 监测）** 内部代理 U_int（任务成功率、VoI−成本、resolution bonus、交互预算利用率、模态覆盖率）与**外部锚定**人类意图 U_ext（留出集上的人类评分/干预率/投诉率/事后追责判定）之间的校准背离 D_good，按代际（deployment generation）追踪其**趋势**而非单点。当 U_int 上升而 U_ext 持平或下降，即判为投机性优化（specification gaming）。

**定义 319（对齐回归栈 REG）** 有序证据栈 = 历史全部实验（E1…E300）与本轮新增的并集，带版本哈希。**激活任一节点必须通过整个前缀栈**，而不仅是新实验；防止「移动球门」与能力回归（capability regression）。证据只可追加、不可静默替换；失效证据必须显式标记过期并触发定义 324 的复评。

**定义 320（假设溯源账本）** 追加写（append-only）、**零学习写**的账本，记录每份运行时证书引用的前件集、作用域判定结果、AC 版本、以及当时的 D_align 快照。使越界与过度声称可在离线被**事后追溯**；也使人/审计者能回答「这个决定当时凭什么被批准」。

**定义 321（跨层一致性检查）** 在模块耦合图上检查不变式是否被组合破坏。两个已识别的关键耦合边：
(a) **R69→R68 越界边**：主动交互把状态推出训练分布，使 R68 标定假设失效；
(b) **R68→R69 抑制边**：保守缩放压制信息动作，使 R69 证据收集不足、歧义长期未消解。
定义一致性约束：跨边传递后，目标不变式的验证裕度不得下降超过阈值；否则抬高 D_align 并要求补证。

**定义 322（优雅降级与能力回退）** 回滚算子 ρ: n ↦ 最高仍被支持的祖先节点；要求：状态轨迹在回滚处的跳变有界（依 R69 定理 17 的连续性），降级延迟 ≤ T_rbk，且降级后安全包络不放大（安全单调）。**降级是路线图的一等操作，而不是异常处理**——「能退」是可部署的前提。

**定义 323（可争辩性与可中断性）** 可争辩（contestability）：任何证书的证据可被外部质疑并在 T_c 内重验、重验结论可推翻原证书；可中断（interruptibility）：人类可在 T_i ≤ T_rbk 内覆盖或叫停任意节点，且覆盖路径不经过被审计的可疑模块。对齐要求**监督通道本身不可被自主性绕过**（否则「有人类在环」只是摆设）。

**定义 324（漂移感知复评调度）** 证据有半衰期：当 drift_rate × age > θ_re 时强制复评；复评未过则节点状态自动降一级。路线图因此是**活对象**：不是一次规划，而是持续再认证。

**定义 325（证书 J_STAGE）** J_STAGE = (J_FLUID, AC_ver, scope_valid_vector, D_align, GRB_margin, node_id, gate_state, reg_hash, D_good, rollback_ready)。Valid ⇔ Valid(J_FLUID) ∧ 作用域健全 ∧ 门通过 ∧ GRB 边距 ≥ 0 ∧ D_align ≤ D_max ∧ D_good ≤ τ_g ∧ 监督通道在线。

**定义 326（对齐事故分类 ℰ_ALIGN）** 六类：规格错误（I 本身错）、规格博弈（Goodhart）、作用域泄漏（越界）、组合失效（局部过、全局超）、能力-证据失配（债超限）、监督失效（不可争辩/不可中断）。威胁模型扩展为 ℰ_STAGE = ℰ_FLUID × ℰ_ALIGN——**R69 的交互投毒和 R70 的规格博弈可以叠加**（用被投毒的回答去「证明」一个被操纵的意图）。

## 2. 关键算法骨架

```python
# IP-264 AC：把人的意图与各层不变式编译成可机检的作用域谓词（版本化、离线）
class AlignmentContract:
    def compile(self, intent_model, layer_invariants):
        I, C, Phi = intent_model, intent_model.hard, merge(layer_invariants)
        scope = {l: antecedent_predicate(l) for l in Phi}   # 每层定理的前件 A_l
        return Contract(I, C, Phi, scope, Escalation(), ver=next_ver())

    def is_sound(self, cert, state):                        # 定义 312
        return all(scope[l](state) for l in cert.cited_lemmas)

# IP-265 SSA：运行时作用域健全性审计（越界即「未验证」，不冒充已验证）
def audit_scope(cert, state, ac):
    bad = [l for l in cert.cited_lemmas if not ac.scope[l](state)]
    if bad: cert.downgrade_to_unverified(bad)               # 保守兜底，非中性
    return len(bad) == 0

# IP-266 ADM：对齐债账本（借：加能力；还：评测/红队/外部锚定/修复）
def update_debt(debt, s_cov, s_stale, s_find, d_good):
    return (W_C*s_cov + W_S*s_stale + W_F*s_find + W_G*d_good)

# IP-267 SRM：路线图 DAG 的激活与下闭性检查
def can_activate(node, active, debt, ac):
    return (all(a in active for a in ancestors(node))        # 祖先已激活
            and gate_readiness(node, ac) >= RHO_HI[node]     # 自身证据门
            and debt <= D_MAX                                # 债未超预算
            and global_risk_budget_ok(active | {node}))      # 组合风险（IP-268）

# IP-268 GRB：相关感知的全局风险预算（堵「每层都过、合起来超限」）
def global_risk_budget_ok(nodes, rho):
    eps = {n: node_risk_quota(n) for n in nodes}
    return correlated_aggregate(eps, rho) <= EPS_GLOBAL       # 定义 317、引理 20

# IP-269 GGM：代理-意图背离监测（内部指标越涨、外部越差 ⇒ Goodhart）
def goodhart_guard(u_int_series, u_ext_series):
    gap = calibrated_divergence(u_int_series, u_ext_series)
    trend = slope(gap)
    return (gap > TAU_GAP) or (trend > 0 and slope(u_int_series) > 0
                               and slope(u_ext_series) <= 0)

# IP-270 REG：对齐回归栈（必须通过整个前缀，而非只过新实验）
def regression_pass(node, reg_stack):
    return all(reg_stack.run(e, version=node.ac_ver) for e in reg_stack.prefix(node))

# IP-271 RBK：滞回回滚到最高仍被支持的祖先（降级是一等操作）
def rollback(node, active, ac, debt):
    if gate_readiness(node, ac) >= RHO_LO[node]: return node       # 滞回：未跌破不回滚
    return max((a for a in ancestors(node) if a in active and supported(a, ac)),
               key=lambda a: depth(a))                             # 最深的被支持祖先

# IP-274 STAGE-RAS 主闭环：在 R69 的每一步外层套一层「路线图/对齐」元控制
def STAGE_RAS_round(M, obs, state):
    # 0) 元层：先确认当前激活集仍被证据支持（漂移感知，事件驱动，非每步全算）
    if M.schedule.due(state):
        M.srm.refresh(M.reg, M.adm, M.ggm)                 # IP-267/269/270
        for n in list(M.active):
            if M.adm.debt > D_MAX or M.ggm.triggered or not M.srm.supported(n):
                M.active = M.rbk.rollback(n, M.active, M.ac, M.adm.debt)  # IP-271
    # 1) 运行时：照常执行 R69 的 FLUID 一步
    k, lam, mode, U = M.fluid.step(obs, state)             # R69 定义 307 两级退避
    # 2) 作用域审计：这一步引用的定理是否仍在其假设域内（R69→R68 越界边）
    cert = M.fluid.last_certificate()
    if not M.ssa.audit_scope(cert, state, M.ac):           # IP-265
        k, lam = k_cal_shrink(k, U), max(lam, LAM_UNVERIFIED)  # 未验证 ⇒ 最保守
    M.adm.update_debt(state)                               # IP-266
    # 3) 交叉层一致性：交互诱发的 OOD 是否正在侵蚀标定假设
    if M.clc.interaction_induced_ood(obs, state):          # IP-272
        M.adm.accrue('scope_leak', obs)
    # 4) 证书 + 参与式审计（人在环，可争辩/可中断）
    M.hoi.record(J_STAGE(cert, M.ac.ver, M.adm.debt, M.srm.node,
                         M.ggm.state, M.rbk.ready), state)  # IP-273
    return k, lam, mode
```

## 3. 推导

**引理 19（能力不自动偿债）** 新增一个能力节点 n+1 至多把 D_align 降低其显式偿还量 E_serviced(n+1)，且通常因引入新假设 A_{n+1} 而抬高 S_cov 与 S_find。即 D_align(active ∪ {n+1}) ≥ D_align(active) − E_serviced(n+1)。**系：能力与保证是两条独立的轴，不能用能力增长来「跑赢」安全债；路线图必须同时排产证据，而不只是排产功能。**

**引理 20（组合缺口：局部门 ≠ 全局界）** 设各节点违规事件 E_n，P(E_n) ≤ ε_n。则 P(∪_n E_n) ≤ Σ_n ε_n；当节点间正相关/假设重叠时，简单相加会低估联合风险（重叠区被重复计或漏计）。存在配置使 ∀n 门通过而 P(∪ E_n) > ε_global。**系：全局风险预算（定义 317）严格强于逐层门；R66–R69 的「逐层严格包含」恰恰无法提供这个组合界，这是 R70 存在的必要性证明。**

**引理 21（Goodhart 的检测时延与元层不免检）** 设代理-意图背离每代增长 ε_g，外部锚定每 k 代做一次。则最坏检测时延 ≤ k 代，期间累计背离 ≥ (k−1)ε_g。若路线图门本身用被博弈的 U_int 作证据，则门会**主动奖励**背离（合法性剧场）。**系：必须以外部人类锚定（定义 318）周期性重置证据，且 AC 版本与门规格本身须被红队审计（定义 326），元层不免检。**

**定理 18（STAGE 严格包含 R69）** 取单节点激活集、D_max = ∞、ρ_hi = 0、跳过 GRB 与 GGM，则定义 315–317 的门恒通过，STAGE 主闭环退化为 R69 的 FLUID 一步（逐指令相同）。因此 R69 是 STAGE 在「无路线图/无预算」边界上的退化；STAGE 在其边界内不弱化任何 R69 保证，只在边界外新增组合层与元层约束。

**定理 19（无能力跑赢证据）** 在释放策略（定义 315–317）与下闭激活（定义 314）下，任意时刻的激活集 A 中每个节点 n 都满足：其祖先证据栈完备、read_n ≥ ρ_hi(n) 在最近一次复评时成立、且 Agg_ρ({ε_a}) ≤ ε_global。由 DAG 上对深度归纳：基例（根节点）由门与 GRB 保证；归纳步由下闭性与定义 324 的过期降级保证。**故不存在「被部署但未被证据支持」的节点**——这正是安全对齐对「能力路线」的核心承诺。

**定理 20（优雅降级保持安全且跳变有界）** 若某节点失效，ρ 回滚到最高仍被支持的祖先 a；由定理 19，a 的保证有效，故降级后系统仍处于已验证作用域内；由 R69 定理 17（控制连续、无突变）与定义 322 的跳变界，回滚引起的状态偏移有界，且安全包络不放大。**系：可逆性把「一次失败」从全局事故降级为局部能力损失，这是路线图能安全迭代的前提。**

## 6. 本轮最大风险

**一句话**：STAGE-RAS 的全部保证都押在「对齐契约 AC 写对了、且证据是诚实的」这一前提上——一旦规格本身有偏、或门被内部指标与选择性证据**表演**（合法性剧场），这套路线图机制就会把「未经充分验证的能力」盖上「已对齐」的章，**这种被制度性背书的错误比 R69 那种「诚实的不知道」危险得多**；路线图最怕的不是走错，而是把走错记录成「按计划前进」。

**次级风险与缓解**：假设域难以精确刻画（保守作用域谓词 + 越界即未验证，定义 312）；组合风险相关结构未知（相关感知上界 + 最坏情形兜底，定义 317/引理 20）；外部人类锚定昂贵且有噪声（抽样 + 主动学习式选样 + 趋势检验，定义 318）；回滚引发性能悬崖或业务不可接受（滞回 + shadow/canary + 可逆设计，定义 316/322）；元层自身被审计俘获（独立红队 + 账本只读 + AC 版本可争辩，定义 320/323/326）。

class AlignmentContract:
    def compile(self, intent_model, layer_invariants):
        return Contract(I=intent_model, C=intent_model.hard,
                        Phi=merge(layer_invariants),
                        scope={l: antecedent_predicate(l) for l in layer_invariants},
                        Esc=Escalation(), ver=next_ver())
    def is_sound(self, cert, state):
        return all(self.scope[l](state) for l in cert.cited_lemmas)

# IP-265 SSA：越界即降级为未验证
def audit_scope(cert, state, ac):
    bad = [l for l in cert.cited_lemmas if not ac.scope[l](state)]
    if bad: cert.downgrade_to_unverified(bad)
    return not bad

# IP-266 ADM：对齐债
def update_debt(s_cov, s_stale, s_find, d_good):
    return W_C*s_cov + W_S*s_stale + W_F*s_find + W_G*d_good

# IP-267/268 SRM+GRB：下闭激活 + 全局风险预算
def can_activate(node, active, debt, ac, rho):
    return (all(a in active for a in ancestors(node))
            and readiness(node, ac, debt) >= RHO_HI[node]
            and debt <= D_MAX
            and correlated_aggregate({n: quota(n) for n in active | {node}}, rho) <= EPS_GLOBAL)

# IP-269 GGM：代理-意图背离（内部涨、外部不涨 ⇒ Goodhart）
def goodhart_guard(u_int, u_ext):
    gap, trend = calibrated_divergence(u_int, u_ext), slope(calibrated_divergence(u_int, u_ext))
    return gap > TAU_GAP or (trend > 0 and slope(u_int) > 0 and slope(u_ext) <= 0)

# IP-270 REG：前缀回归栈
def regression_pass(node, reg_stack):
    return all(reg_stack.run(e, version=node.ac_ver) for e in reg_stack.prefix(node))

# IP-271 RBK：双阈值滞回回滚
def rollback(node, active, ac, debt):
    if readiness(node, ac, debt) >= RHO_LO[node]: return node
    return max((a for a in ancestors(node) if a in active and supported(a, ac)),
               key=depth)

def STAGE_RAS_round(M, obs, state):
    if M.schedule.due(state):                              # 事件驱动，非每步
        M.srm.refresh(M.reg, M.adm, M.ggm)

## 4. 推导

**引理 19（能力不自动偿债）** `D_align(active∪{n+1}) ≥ D_align(active) − E_serviced(n+1)`。能力与保证是两条独立轴；路线图必须同时排产证据，不能以功能增长跑赢安全债。

**引理 20（组合缺口）** `P(∪_n E_n) ≤ Σ_n ε_n`；节点正相关/假设重叠会破坏该界，存在「局部全过、全局超限」的配置。故全局风险预算（定义 317）严格强于逐层门——这正是 R66–R69「逐层严格包含」无法提供、而 R70 必须补上的组合界。

**引理 21（Goodhart 检测时延与元层不免检）** 每代背离增长 ε_g、每 k 代外部锚定一次 ⇒ 最坏检测时延 ≤ k 代、期间累计背离 ≥ (k−1)ε_g；若门用被博弈的 U_int 作证据，门会主动奖励背离（合法性剧场）。故必须外部锚定 + 对 AC/门规格本身做红队审计。

**定理 18（STAGE 严格包含 R69）** 单节点、D_max=∞、ρ_hi=0、跳过 GRB/GGM 时，门恒通过，STAGE 主闭环逐指令退化为 R69 FLUID 一步。R69 是 STAGE 的「无路线图/无预算」边界；边界内不弱化任何 R69 保证。

**定理 19（无能力跑赢证据）** 在下闭激活、定义 315–317 门与定义 324 过期降级下，任意时刻激活集 A 的每个节点均有完备祖先证据栈、最近复评 read_n ≥ ρ_hi(n)、且 `Agg_ρ ≤ ε_global`。沿 DAG 深度归纳即得；故不存在「被部署但未被证据支持」的节点。

**定理 20（优雅降级保持安全且跳变有界）** 回滚到最高仍被支持的祖先 a，其保证由定理 19 有效；由 R69 定理 17 与定义 322，回滚跳变有界、安全包络不放大。可逆性把一次失败从全局事故降为局部能力损失。

## 7. 本轮最大风险

**一句话**：STAGE-RAS 的全部保证都押在「对齐契约 AC 写对了、且证据是诚实的」这一前提上——一旦规格有偏、或门被内部指标与选择性证据**表演**（合法性剧场），这套路线图机制就会把「未经充分验证的能力」盖上「已对齐」的章，**这种被制度性背书的错误比 R69 那种「诚实的不知道」危险得多**；路线图最怕的不是走错，而是把走错记录成「按计划前进」。

**次级风险与缓解**：假设域难精确刻画（保守作用域 + 越界即未验证，定义 312）；组合相关结构未知（相关感知上界 + 最坏情形兜底，定义 317/引理 20）；外部人类锚定昂贵有噪（抽样 + 主动选样 + 趋势检验，定义 318）；回滚性能悬崖（滞回 + shadow/canary + 可逆设计，定义 316/322）；元层被审计俘获（独立红队 + 只读账本 + AC 可争辩，定义 320/323/326）。
