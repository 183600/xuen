# 第 61 轮（承接第 60 轮「场景感知闭环」IP-153~160；灵感循环第 7 轮；本轮灵感：「竞品分析」×「位姿估计」）

> 第 60 轮把执行反馈升级为「场景-认知闭环」：SSM 场景语义建模、CIEC 意图约束、EPIR 证据隔离、SERC 闭环、SIC 三元校验、CESC 联合决策、EPIR-Protocol、PCE++++ 四维预算。但**三个结构性盲点**尚未触及：
> 1. **位姿被默认为「已知点」**：`K_safe` 在任务坐标系中编译，而接触点由对象位姿、相机外参、基座标定共同决定。1–2° 或数毫米的位姿误差会直接平移接触点，使「安全阻抗」作用在错误位置；SIC 三元组中没有 `pose_certainty` 这一维，因此「证据层高度确定」可与「位姿其实错了」同时成立。
> 2. **位姿估计本质是多峰竞争后验**：对称物体、无纹理表面、遮挡会产生多个近似合理的假设。把后验压缩为单高斯，等于让视觉先验提前「选边」；选错时仍携带高置信度，形成**模式坍缩（mode collapse）**——这是第 60 轮「认知先行」最危险的失效形态。
> 3. **创新性缺少「竞品对账」**：E187–E191 的 ≥85%、≥20% 均为自设阈值，未与基线在**同等执行预算**下做配对比较。没有差异化证书的「创新点」不可证伪，也无法在竞赛评审中经受「你和已有方案相比强在哪」的追问。

## 0. 直觉与动机

**灵感 1（位姿估计 → 竞争位姿假设集 CPHS）**
直觉：位姿不是一个点，而是一个**由多个「竞品假设」组成的后验**。每个假设 `h_i` 有自己的权重 `w_i`、局部协方差 `Σ_i` 与证据来源。系统不应问「位姿是什么」，而应问「当前哪个假设领先、领先多少」。领先幅度即竞争边际 `μ_comp = w_(1) − w_(2)`：边际大才允许下注执行，边际小就必须先做**主动位姿探针**去淘汰错误假设。关键洞见：**位姿不确定性不是需要被平均掉的噪声，而是需要被仲裁掉的竞争者。**

**灵感 2（竞品分析 → 双层对账：假设竞争 + 基线差异化）**
直觉：竞品分析有两个尺度。
- *微观尺度*：把每个位姿假设当作「竞品」，用 proper scoring rule（对数分数）给每个假设打分，维护「假设排行榜」；排行榜的**边际**就是执行决策的置信闸门。
- *宏观尺度*：把「我们的方法 vs 基线方法」当作竞品对账。建立**基线登记表**，在同等预算、同等接触次数、同等算力下做配对实验；每个创新点必须挂接一张**差异化证书**，只有当配对差的置信下界 `LCB > ε_m` 时才允许声称 WIN，否则标记 UNVERIFIED。关键洞见：**创新性主张必须是可证伪的统计命题，而不是自设阈值的达标声明。**

**灵感 3（合流 → 位姿不确定性感知阻抗编译 PUA-EEIS）**
直觉：第 60 轮的 `K_safe = {K | Feasible(K, x*)}` 应升级为混合分布下的机会约束：
`K_safe^pose = {K | P_{x~b_t}(接触力 ∈ F_tol) ≥ 1−δ_exec 且 ∀高密度假设可行}`。
位姿越不确定，约束越保守——不是简单降低 `K_p`，而是同时**收缩允许工作域**并**抬高阻尼**，把位姿风险转化为可执行的鲁棒约束。关键洞见：**安全必须对「位姿后验的整个高密度域」成立，而不是只对 argmax 假设成立。**

**灵感 4（主动位姿探针 APV → 用执行预算买信息）**
直觉：当 `μ_comp < τ_margin` 时，继续执行等于赌博。此时应调用下一最佳视角 / 微接触 / 轻推等**物理探针**，选择使互信息增益最大的动作：
`a* = argmax_a IG(a) − λ·cost(a)`，受 `B_probe` 约束。
探针成功后竞争边际上升，再决定 commit / retreat。关键洞见：**「先看后动」在物理世界里不是免费的，必须用 VOI 决定「值不值得看一眼」。**

**灵感 5（竞争预算 CPB / PCE+++++）**
直觉：第 60 轮的 `B_cog` 需再扩展为 `B_comp = (B_pose, B_probe, B_arb, B_diff, B_exec)`：位姿推断、物理探针、仲裁计算、差异化统计功效、执行预算。若 `B_pose` 耗尽 ⇒ 退化为「本体+场景先验」点估计并放大协方差；若 `B_probe` 耗尽 ⇒ 保守 retreat；若 `B_arb` 耗尽 ⇒ 沿用上次 commit 并膨胀不确定度；若 `B_diff` 不足 ⇒ 创新主张只能标记 UNVERIFIED（科学诚实）；若 `B_exec` 耗尽 ⇒ 回退第 60 轮降级。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（竞争位姿假设集 CPHS）** 位姿信念
`H_t = {(h_i, w_i, Σ_i, S_i)}_{i=1}^{K}`，其中：
- `h_i ∈ SE(3)`：对象/相机/末端的第 i 个位姿假设；
- `w_i ∈ [0,1]`，`Σ_i w_i = 1`：后验权重；
- `Σ_i ∈ R^{6×6}`：在 twist 坐标下的局部协方差；
- `S_i ⊆ {vision, tactile, proprio, scene_prior}`：该假设的支撑证据源。
混合密度 `b_t(x) = Σ_i w_i · N(x; h_i, Σ_i)`（在 se(3) 局部坐标展开）。
- **竞争边际**：`μ_comp = w_(1) − w_(2)`（排序后的前两名权重差）；
- **有效支撑域**：`X_{1−δ} = {x | b_t(x) ≥ q_{1−δ}}`，`q` 为最高密度区域的 `1−δ` 分位；
- **有效假设数**：`K_eff = exp(H(w))`，`H` 为 Shannon 熵；
- **未决判定**：`μ_comp < τ_margin` 或 `K_eff > K_max` 或校准误差 `ECE > ε_cal` 时，位姿竞争「未决」。

**定义 162（位姿不确定性感知阻抗编译 PUA-EEIS）** 给定 `b_t`、执行容差 `δ_exec`、力容差 `F_tol`：
```
K_safe^pose = { K ∈ K_safe^scene |
    ∀i: ∀x ∈ X_i^{1−δ_i}: Feasible(K, x)
    ∧  P_{x~b_t}( |F(x, K) − F_ref| ≤ F_tol ) ≥ 1 − δ_exec }
```
- `X_i^{1−δ_i}` 为第 i 个高密度假设的支撑域；
- **位姿风险溢价**：`ρ_pose(K) = max_{x∈X_{1−δ}} ||∂F/∂x|| · ||Σ^{1/2}||`，用于量化「为容纳位姿不确定性，K 需额外保守多少」；
- **求解**：对每个混合分量做无迹变换（sigma points）传播接触力分布，再用 scenario optimization / 加权最坏情况求解，样本数 `N_s ≥ N_min(α, β)` 给出 `(1−α)` 机会约束保证；
- **退化**：若 `K_safe^pose = ∅`，依次放宽 `δ_exec` → 收缩工作域 → 触发探针或 retreat。

**定义 163（竞争证据评分与仲裁 CESA）** 给定执行证据 `EV-exec`（含位姿残差与力残差）：
- **对数分数**：`ℓ_i = log p(EV-exec | h_i)`（proper scoring rule，抑制「自信但错误」）；
- **温度化 Bayes 更新**：`w_i^+ ∝ w_i · exp(η·ℓ_i)`，`η ∈ (0,1]` 防止过度自信；
- **校准**：对 `w` 做温度缩放，要求 `ECE ≤ ε_cal`；
- **仲裁规则**：
```
if μ_comp ≥ τ_margin and calibrated:
      commit h_(1)
elif μ_comp < τ_margin and VOI_probe > θ_probe and B_probe > 0:
      APV.select_and_probe()
elif K_safe^pose = ∅ or B_probe = 0:
      retreat(K_robust)            # 保守执行或暂停
else:
      hold_and_resense()
```
- **假设排行榜**：按场景记录每次仲裁的 `(μ_comp, winner, outcome)`，用于检测**模式坍缩**（同一错误假设反复获胜）。

**定义 164（主动位姿探针 APV）** 候选动作集 `A`（下一最佳视角、微接触、轻推、重抓取）：
- **信息增益**：`IG(a) = H(b_t) − E_{z~p(z|a)} H(b_{t+1})`；
- **最优探针**：`a* = argmax_{a∈A} IG(a) − λ·cost(a)`，s.t. `cost(a) ≤ B_probe`；
- **终止条件**：`μ_comp ≥ τ_margin` 或预算耗尽或 `risk(a*) > risk_max`；
- **安全护栏**：探针本身必须在 `K_safe^pose` 的保守子集上执行，且探针行程受 `v_max` 限制。

**定义 165（竞争基线与差异化证书 CBDC）** 
- **基线登记表** `B = {β_1, …, β_M}`：点估计 EEIS（第 60 轮）、固定阻抗、纯视觉位姿、无位姿不确定度、单高斯后验等；
- **匹配预算协议**：同等 `B_exec`、同等接触次数、同等算力、同等场景分布；
- **配对差**：`Δ_{z,m} = metric_ours(z,m) − metric_β(z,m)`；
- **差异化证书**：`J_diff = (z, m, Δ̂, LCB, n, p, verdict)`，`LCB` 为单侧置信下界（BCa bootstrap 或 Hoeffding）；
- **判定**：`verdict ∈ {WIN, TIE, LOSS, UNVERIFIED}`；仅当 `LCB > ε_m` 且经 Holm–Bonferroni 多重比较校正后判 WIN；
- **预注册**：实验前对指标、假设、场景划分做哈希预注册；留出场景集 `Z_holdout` 不得参与调参。

**定义 166（竞争位姿-证据闭环 CPEC）** 算子 `CPEC(M, objective, budget)`：
```
① CPHS:   H_t ← M.pose_belief.update(vision, proprio, scene_prior)
② SIC+:   (scene_conf, pose_cert, K_certainty, feasibility)
③ PUA:    K_safe^pose ← PUA_EEIS.compile(b_t, δ_exec, K_safe^scene)
④ 仲裁:   if μ_comp < τ_margin and VOI_probe > θ_probe:
              a* ← APV.select(H_t, B_probe); execute(a*); goto ①
⑤ 派发:   dispatch_impedance_params(K_safe^pose.best, Cert_eeis)
⑥ 执行:   telemetry ← wait_contact(); EV-exec ← build_exec_evidence(...)
⑦ 评分:   CESA.score_update(H_t, EV-exec); arbitrate
⑧ 场景:   SERC 更新 scene belief（第 60 轮）
⑨ 对账:   CBDC.ledger.record(scene, μ_comp, Δ_ours_vs_β)
⑩ 返回:   (H_t, K_safe^pose, EV-exec, verdict)
```

**定义 167（位姿-执行一致性残差 PER）** 对假设 `h_i`：
- **位姿残差**：`r_pose = log(T_exp^{-1} T_obs) ∈ se(3)`（6 维）；
- **马氏距离**：`d_pose = r_pose^T Σ_i^{-1} r_pose ~ χ²_6`；
- **力残差**：`r_F = F_meas − F_pred(K, h_i)`，`d_F = r_F^T Σ_F^{-1} r_F`；
- **联合分数**：`ℓ_i = −½(d_pose + λ_F·d_F) − ½ log|Σ_i|`；
- **一致性闸门**：若 `d_pose > χ²_{6,1−α}` 则拒绝 `h_i`；若所有假设被拒 ⇒ 触发「位姿-执行失配」⇒ 探针或 retreat。

**定义 168（竞争预算 CPB 与 PCE+++++）** `B_comp = (B_pose, B_probe, B_arb, B_diff, B_exec)`：
- `B_pose = (Inference_latency, K_max, Reestimate_rate)`
- `B_probe = (Probe_count, Motion_cost, Risk_budget)`
- `B_arb = (Scoring_ops, Calibration_ops)`
- `B_diff = (Trial_count, Statistical_power, Holdout_ratio)`
- `B_exec = (WCET_slack, Bus_bw_slack, Thermal_slack, Prio_headroom)`（沿用）
```
voi_comp(π) = VOI_meta_pessimistic(π) − cost_pose(π) − cost_probe(π)
              − cost_diff(π) − cost_exec(π)
```
降级：`B_pose` 耗尽 ⇒ 点估计+协方差放大 `γ` 倍并稳健化；`B_probe` 耗尽 ⇒ 保守 retreat；`B_arb` 耗尽 ⇒ 沿用上次 commit 并膨胀不确定度；`B_diff` 不足 ⇒ 创新主张标 UNVERIFIED；`B_exec` 耗尽 ⇒ 第 60 轮降级。

### IP-161 CPHS（竞争位姿假设集）

```python
class CompetingPoseBelief:
    def __init__(self, K_max=5, tau_margin=0.25):
        self.hypotheses = []          # list of (h, w, Sigma, sources)
        self.K_max = K_max
        self.tau_margin = tau_margin
        self.history = deque(maxlen=200)

    def update(self, vision_hyp, proprio, scene_prior):
        merged = self._merge(vision_hyp, proprio, scene_prior)
        self.hypotheses = self._prune(merged, self.K_max)
        self._normalize()
        return self

    def margin(self):
        w = sorted((h.w for h in self.hypotheses), reverse=True)
        return w[0] - w[1] if len(w) > 1 else 1.0

    def effective_count(self):
        w = np.array([h.w for h in self.hypotheses])
        return float(np.exp(-(w * np.log(w + 1e-12)).sum()))

    def top(self):
        return max(self.hypotheses, key=lambda h: h.w)

    def calibrate(self, ece):
        if ece > 0.05:
            self.hypotheses = [h._temper(eta=0.8) for h in self.hypotheses]
            self._normalize()
```

### IP-162 PUA-EEIS（位姿不确定性感知阻抗编译）

```python
def compile_pose_aware(eeis, belief, delta_exec=0.01, F_tol=0.1, N_s=64):
    candidates = []
    for K in eeis.candidate_grid():
        ok = True
        for h in belief.hypotheses:
            pts = sigma_points(h.h, h.Sigma, N_s)
            forces = [eeis.contact_force(K, x) for x in pts]
            if not all(abs(f - eeis.F_ref) <= F_tol for f in forces):
                ok = False
                break
        if not ok:
            continue
        viol = estimate_violation_prob(eeis, K, belief, N_s)
        if viol <= delta_exec:
            candidates.append((K, viol))
    if not candidates:
        return None
    return min(candidates, key=lambda t: t[0].robust_cost)
```

### IP-163 CESA（竞争证据评分与仲裁）

```python
class CompetitiveArbiter:
    def __init__(self, tau_margin=0.25, eta=0.9, theta_probe=0.1):
        self.tau_margin = tau_margin
        self.eta = eta
        self.theta_probe = theta_probe
        self.leaderboard = []

    def score_update(self, belief, ev_exec):
        logits = []
        for h in belief.hypotheses:
            d_pose = mahalanobis(pose_residual(h.h, ev_exec), h.Sigma)
            d_F = mahalanobis(force_residual(h.h, ev_exec), ev_exec.Sigma_F)
            logits.append(-0.5 * (d_pose + 0.5 * d_F) - 0.5 * logdet(h.Sigma))
        w = np.array([h.w for h in belief.hypotheses])
        w = w * np.exp(self.eta * (np.array(logits) - max(logits)))
        belief.hypotheses = [h._with_weight(wi) for h, wi in zip(belief.hypotheses, w / w.sum())]
        self.leaderboard.append((belief.margin(), belief.top().h))

    def arbitrate(self, belief, vois):
        if belief.margin() >= self.tau_margin and belief.calibrated:
            return ('COMMIT', belief.top())
        if belief.margin() < self.tau_margin and vois.probe > self.theta_probe:
            return ('PROBE', None)
        return ('RETREAT', None)
```

### IP-164 APV（主动位姿探针）

```python
def select_probe(belief, action_set, budget, lam=0.1):
    best, best_val = None, -inf
    for a in action_set:
        if a.cost > budget.remaining:
            continue
        ig = entropy(belief) - expected_entropy_after(belief, a)
        val = ig - lam * a.cost
        if val > best_val:
            best, best_val = a, val
    return best
```

### IP-165 CBDC（差异化证书）

```python
class DifferentiationLedger:
    def __init__(self, baselines, eps_m=0.0, alpha=0.05):
        self.baselines = baselines
        self.eps_m = eps_m
        self.alpha = alpha
        self.certificates = []

    def paired_test(self, scene, metric, ours, base):
        d = np.array(ours) - np.array(base)
        lcb = bootstrap_lcb(d, alpha=self.alpha)      # BCa one-sided
        p = permutation_pvalue(d, alternative='greater')
        verdict = 'WIN' if lcb > self.eps_m and p < self.alpha else (
                  'LOSS' if lcb < -self.eps_m else 'TIE')
        self.certificates.append(dict(scene=scene, metric=metric,
                                      delta=d.mean(), lcb=lcb, p=p,
                                      n=len(d), verdict=verdict))
```

### IP-166 CPEC（竞争位姿-证据闭环）

```python
def competitive_pose_evidence_loop(M, objective, budget):
    belief = M.pose_belief.update(M.vision_hyp, M.proprio, M.scene_prior)
    sic_plus = (M.scene_conf, 1.0 - normalized_entropy(belief),
                M.k_certainty, M.feasibility)

    K_safe_pose = compile_pose_aware(M.eeis, belief, delta_exec=M.delta_exec)
    if K_safe_pose is None:
        return retreat_or_probe(M, belief, budget)

    if belief.margin() < M.tau_margin:
        a = select_probe(belief, M.action_set, budget.B_probe)
        if a is not None:
            M.observe(a.execute())
            return competitive_pose_evidence_loop(M, objective, budget)

    dispatch_impedance_params(K_safe_pose, M.cert)
    M, fused, D_plus, ev_exec, cert = closed_loop_exec_probe(
        M, M.current_cp, objective.delta_f, budget.B_exec)

    M.arbiter.score_update(belief, ev_exec)
    action = M.arbiter.arbitrate(belief, M.voi)
    if action[0] == 'PROBE':
        a = select_probe(belief, M.action_set, budget.B_probe)
        a and M.observe(a.execute())
    elif action[0] == 'RETREAT':
        M = retreat(M)

    M.scene_model.update(M.telem_force, M.telem_pos)
    M.diff_ledger.record(M.scene, 'success', [cert.success], [M.baseline_success])
    return M, belief, K_safe_pose, ev_exec, action
```

### IP-167 PER（位姿-执行一致性残差）

```python
def per_score(h, ev_exec):
    r_pose = se3_log(inv(h.h) @ ev_exec.T_obs)
    d_pose = r_pose.T @ inv(h.Sigma) @ r_pose
    r_F = ev_exec.F_meas - contact_force(h.h, ev_exec.K)
    d_F = r_F.T @ inv(ev_exec.Sigma_F) @ r_F
    if d_pose > chi2_ppf(0.99, 6):
        return -inf
    return -0.5 * (d_pose + 0.5 * d_F) - 0.5 * logdet(h.Sigma)
```

### IP-168 CPB（竞争预算）

```python
class CompetitiveBudget:
    def __init__(self, pose_ops=200, probe_count=3, arb_ops=1000,
                 diff_trials=30, exec_budget=None):
        self.B_pose = pose_ops
        self.B_probe = ProbeBudget(probe_count)
        self.B_arb = arb_ops
        self.B_diff = diff_trials
        self.B_exec = exec_budget or ExecBudget()

    def degradation(self):
        if self.B_pose <= 0:
            return 'point_estimate_inflated'
        if self.B_probe.remaining <= 0:
            return 'conservative_retreat'
        if self.B_arb <= 0:
            return 'reuse_last_commit'
        if self.B_diff < self.B_exec.min_trials:
            return 'claims_unverified'
        if self.B_exec.exhausted:
            return 'round60_degrade'
        return 'normal'
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CPHS | O(K·d²) 更新 / O(K) 排序 | O(K·36) | 校准后 ECE ≤ 0.05；top-1 误差较单高斯 ↓ ≥ 30% |
| PUA-EEIS | O(N_s·K·C_EEIS) | O(N_s·K) | 机会约束满足 ≥ 1−δ_exec（scenario 界） |

| CPEC | O(闭环) | 复用 | 位姿诱导失败率 ↓ ≥ 50% |

**正确性定理（CPEC）**：
假设 **(A66)** 位姿混合已校准，真实位姿以概率 ≥ 1−δ 落于 `X_{1−δ}`；**(A67)** 对数分数为 proper scoring rule，温度化 Bayes 更新一致；**(A68)** PUA-EEIS 的场景优化样本数 `N_s ≥ N_min(α,β)`；**(A69)** APV 的信息增益估计无偏且成本模型准确；**(A70)** CBDC 采用配对、匹配预算、预注册的检验，`LCB` 有效。则：
1. **鲁棒安全性**：若 A66、A68 成立，则接触力越界概率 ≤ `δ_exec + α`。
2. **仲裁一致性**：若真实假设在支撑域内且 A66、A67 成立，则 `w` 几乎必然收敛到真实模式，`μ_comp` 单调趋大，错误模式留存概率指数衰减。
3. **探针有效性**：APV 在预算约束下达到最优信息增益的 `(1−ε_IG)` 倍。
4. **差异化可靠性**：仅当真实配对差 > 0 时判 WIN，家族错误率 ≤ α；否则标 TIE / UNVERIFIED，避免「自设阈值式创新」。
5. **预算安全性**：任一 `B_comp` 分量耗尽即触发定义 168 的对应降级，不出现无界执行。

### IP-161 CPHS（竞争位姿假设集）

```python
class CompetingPoseBelief:
    def __init__(self, K_max=5, tau_margin=0.25):
        self.hypotheses = []          # list of (h, w, Sigma, sources)
        self.K_max = K_max
        self.tau_margin = tau_margin
        self.calibrated = False
        self.history = deque(maxlen=200)

    def update(self, vision_hyp, proprio, scene_prior):
        merged = self._merge(vision_hyp, proprio, scene_prior)
        self.hypotheses = self._prune(merged, self.K_max)
        self._normalize()
        return self

    def margin(self):
        w = sorted((h.w for h in self.hypotheses), reverse=True)
        return w[0] - w[1] if len(w) > 1 else 1.0

    def effective_count(self):
        w = np.array([h.w for h in self.hypotheses])
        return float(np.exp(-(w * np.log(w + 1e-12)).sum()))

    def top(self):
        return max(self.hypotheses, key=lambda h: h.w)

    def calibrate(self, ece):
        if ece > 0.05:
            self.hypotheses = [h._temper(eta=0.8) for h in self.hypotheses]
            self._normalize()
            self.calibrated = True
```

### IP-162 PUA-EEIS（位姿不确定性感知阻抗编译）

```python
def compile_pose_aware(eeis, belief, delta_exec=0.01, F_tol=0.1, N_s=64):
    candidates = []
    for K in eeis.candidate_grid():
        ok = True
        for h in belief.hypotheses:
            pts = sigma_points(h.h, h.Sigma, N_s)
            forces = [eeis.contact_force(K, x) for x in pts]
            if not all(abs(f - eeis.F_ref) <= F_tol for f in forces):
                ok = False
                break
        if not ok:
            continue
        viol = estimate_violation_prob(eeis, K, belief, N_s)
        if viol <= delta_exec:
            candidates.append((K, viol))
    if not candidates:
        return None
    return min(candidates, key=lambda t: t[0].robust_cost)
```

### IP-163 CESA（竞争证据评分与仲裁）

```python
class CompetitiveArbiter:
    def __init__(self, tau_margin=0.25, eta=0.9, theta_probe=0.1):
        self.tau_margin = tau_margin
        self.eta = eta
        self.theta_probe = theta_probe
        self.leaderboard = []

    def score_update(self, belief, ev_exec):
        logits = []
        for h in belief.hypotheses:
            d_pose = mahalanobis(pose_residual(h.h, ev_exec), h.Sigma)
            d_F = mahalanobis(force_residual(h.h, ev_exec), ev_exec.Sigma_F)
            logits.append(-0.5 * (d_pose + 0.5 * d_F) - 0.5 * logdet(h.Sigma))
        w = np.array([h.w for h in belief.hypotheses])
        w = w * np.exp(self.eta * (np.array(logits) - max(logits)))
        belief.hypotheses = [h._with_weight(wi)
                             for h, wi in zip(belief.hypotheses, w / w.sum())]
        self.leaderboard.append((belief.margin(), belief.top().h))

    def arbitrate(self, belief, vois):
        if belief.margin() >= self.tau_margin and belief.calibrated:
            return ('COMMIT', belief.top())
        if belief.margin() < self.tau_margin and vois.probe > self.theta_probe:
            return ('PROBE', None)
        return ('RETREAT', None)
```

def select_probe(belief, action_set, budget, lam=0.1):
    best, best_val = None, -np.inf
    for a in action_set:
        if a.cost > budget.remaining:
            continue
        ig = entropy(belief) - expected_entropy_after(belief, a)
        val = ig - lam * a.cost
        if val > best_val:

    return best

class DifferentiationLedger:
    def __init__(self, baselines, eps_m=0.0, alpha=0.05):
        self.baselines = baselines
        self.eps_m = eps_m
        self.alpha = alpha
        self.certificates = []

    def paired_test(self, scene, metric, ours, base):

        lcb = bootstrap_lcb(d, alpha=self.alpha)      # BCa one-sided

                                      delta=d.mean(), lcb=lcb, p=p,
                                      n=len(d), verdict=verdict))

### IP-167 PER（位姿-执行一致性残差）

```python
def per_score(h, ev_exec):
    r_pose = se3_log(inv(h.h) @ ev_exec.T_obs)
    d_pose = r_pose.T @ inv(h.Sigma) @ r_pose
    r_F = ev_exec.F_meas - contact_force(h.h, ev_exec.K)
    d_F = r_F.T @ inv(ev_exec.Sigma_F) @ r_F
    if d_pose > chi2_ppf(0.99, 6):
        return -np.inf
    return -0.5 * (d_pose + 0.5 * d_F) - 0.5 * logdet(h.Sigma)
```

    def __init__(self, pose_ops=200, probe_count=3, arb_ops=1000,
                 diff_trials=30, exec_budget=None):

        self.B_probe = ProbeBudget(probe_count)
