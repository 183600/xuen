### 第 1 轮灵感驱动研究记录

**灵感词**：专利布局、多语言支持

**直觉与动机**：

上一轮 CADVS 把控制安全落成「证书链」：每条常识规则 KC 是一张证书，证书携带时序窗口、质量阈值与回退语义。但两个新词暴露出证书体系尚未回答的两个「元问题」。

1. **专利布局**：专利从来不是一篇文件，而是一个「权利要求组合」——用宽泛的属权利要求（genus）覆盖一类方法，用狭窄的种权利要求（species）锁定具体实施例，再用防御性公开（defensive publication）封堵他人的周边改进。直觉上，证书也不该是「单张全有或全无的合格证」，而应是一个**证书组合（certificate portfolio）**：
   - 宽证书给出「不变量级」的弱保证（如「任意步态下质心投影落在支撑多边形内」），覆盖广但信息量低；
   - 窄证书给出「工况级」的强保证（如「湿滑地面上支撑面积 > 260cm² 且摩擦系数 > 0.6」），覆盖窄但可执行性强；
   - 每条证书必须标注它的「现有技术」（prior art）——即已知会失效的工况集合与历史违规轨迹。正如一项权利要求若被现有技术覆盖就应被驳回，一条常识规则若其适用范围已被已知反例覆盖，就**不得**被授予证书。

   这恰好击中上一轮最大风险「跨任务迁移的负外部性」：μ_i≈1 的虚假满迁移，本质是一条「过宽且被现有技术击穿」的权利要求。专利法用新颖性（novelty）与可实施性（enablement）约束权利要求宽度；我们用它约束迁移因子 μ_i，把「看起来适用」升级为「可证明未被反例覆盖」。

2. **多语言支持**：软件的多语言（i18n/l10n）表面是翻译，实质是**语义在跨语境下的保持**。证书同样存在三种「语言」：
   - 自然语言（操作员读的规则说明，如「支撑面积足够大」）；
   - 形式语言（STL/LTL/谓词逻辑，控制器执行的判据）；
   - 运行时语言（C++/Rust/micro-ROS/PLC 的具体实现）。

   同一张证书在三种语言间转译时，必须携带一张「翻译证书」，声明转译是**保守的（sound）**还是**近似等价的（ε-equivalent）**。例如把「support area」译成另一种自然语言或换到另一种单位制，可能把「足底接触面积」悄悄换成「支撑凸包面积」；把 STL 编译到定点 PLC 可能把 `>` 变成 `≥`。这类语义漂移（semantic drift）在单语言下不可见，在多语言下会被放大成「每种语言看起来都对，但彼此不等价」。

**关键洞见**：专利布局与多语言支持在深层是同构的——两者都在处理**「一个核心语义，如何在多个语境（法域/任务/平台/自然语言）中被保持而不被稀释或越界」**。专利回答「我的保护范围在哪些变体上仍然成立」，多语言回答「我的意思在哪些译文中仍然成立」。证书体系同时需要这两种「范围语义」：对任务变体的范围（专利）与对表达形式的范围（多语言）。因此本轮提出统一框架 **PG-CADVS（Polyglot Certificate CADVS）**，其两条支柱是：
- **证书-权利要求同构（CCI）**：证书 = (适用范围 S, 不变量 φ, 现有技术 A, 证据 E, 有效期 τ)，授予需通过新颖性/支持度/可实施性/边界可判定四道检验；
- **多语言证书互操作（MCI）**：证书以「证书中间表示 CIR」为权威语义，向自然语言、形式语言、运行时目标编译，每份译文附翻译证书（方向、漂移界 δ、方法、置信度）。

**形式化目标（增量）**：
1. 定义证书权利要求 C = (cid, S, φ, A, E, τ)，及授予谓词 Grant(C) ⇔ Novelty ≥ ν_min ∧ Support ≥ 1−α ∧ Enabled ∧ Decidable。
2. 定义权利要求格 (𝒞, ≼) 与组合覆盖：C₁ ≼ C₂ ⇔ S₁ ⊆ S₂ ∧ (φ₂ ⇒ φ₁)；组合 P 覆盖工作包络 X ⇔ ⋃S_i ⊇ X。
3. 定义先验技术感知迁移因子 μ_i(τ_s→τ_t) = sim(τ_s,τ_t) · |(S_i ∩ S_t) \ A_i| / |S_t|，并以「未覆盖区支持度」为门槛拒绝虚假满迁移。
4. 定义翻译证书 TC = (src, dst, δ, sound, method, conf)，其中 δ 为迹集合的差异度量；安全关键方向要求 sound（⟦T(C)⟧ ⊆ ⟦C⟧）。
5. 定义受控自然语言（CNL）+ 共享本体，使多语言解释由同一逻辑形式生成；回译一致性作为解释证书的一部分。
6. 证明：在授予与保守翻译条件下，Exec_PG ⊆ Exec_CADVS ⊆ Exec_v29，且虚假包容率 ≤ α；解释在回译一致时保持逻辑形式。

**本轮最大风险**：**专利类比的形式化失真**——新颖性、非显而易见性、可实施性本质是法律-社会建构，而非控制安全的充分条件；把「程序上被授予」误当作「语义上安全」，会产生一种比虚假包容更危险的「已授权但未证明」证书，而多语言渲染会让这张证书在每种语言中都显得同样可信。

### IP-478 Certificate Claim Portfolio (CCP)

```python
@dataclass(frozen=True)
class CertificateClaim:
    cid: str
    scope: Scope                      # S: (state, task) -> bool, 带 unit/frame 元数据
    invariant: Predicate              # φ: state -> bool
    prior_art: frozenset[Fingerprint] # A: 已知失效/反例指纹
    evidence: tuple[Trace, ...]       # E
    tau: float                        # 有效期（s）
    parent: Optional[str] = None      # 属权利要求链接（格结构）

class ClaimPortfolio:
    def __init__(self, nu_min=0.15, alpha=0.05, latency_budget=0.002,
                 min_evidence=64):
        self.nu_min, self.alpha = nu_min, alpha
        self.latency_budget, self.min_evidence = latency_budget, min_evidence
        self.granted: list[CertificateClaim] = []

    def _stratified(self, scope, task, n=4096):
        """按工况分层采样，避免只在常见工况上估计新颖性/支持度。"""
        return stratified_sample(scope, task, n=n, strata=('terrain','speed','load'))

    def novelty(self, c: CertificateClaim, task) -> float:
        """S* / S 的估计：未被现有技术覆盖的比例。"""
        xs = self._stratified(c.scope, task)
        if not xs:
            return 0.0
        anticipated = sum(
            1 for x in xs
            if any(fp.match(x) for fp in c.prior_art)
        )
        return 1.0 - anticipated / len(xs)

    def support(self, c: CertificateClaim) -> float:
        """E ∩ S* 上 φ 成立的频率；证据不足直接判 0。"""
        in_scope = [e for e in c.evidence
                    if c.scope(e.x, e.task)
                    and not any(fp.match(e.x) for fp in c.prior_art)]
        if len(in_scope) < self.min_evidence:
            return 0.0
        return sum(1 for e in in_scope if c.invariant(e.x)) / len(in_scope)

    def enabled(self, c: CertificateClaim) -> bool:
        return (self._checker_exists(c)
                and self._checker_latency(c) <= self.latency_budget)

    def decidable(self, c: CertificateClaim) -> bool:
        return c.scope.is_decidable() and c.invariant.is_decidable()

    def grant(self, c: CertificateClaim, task) -> GrantDecision:
        reasons = []
        nu, sup = self.novelty(c, task), self.support(c)
        if nu < self.nu_min:
            reasons.append('anticipated_by_prior_art')
        if sup < 1 - self.alpha:
            reasons.append('insufficient_support')
        if not self.enabled(c):
            reasons.append('not_enabled')
        if not self.decidable(c):
            reasons.append('indefinite_scope')
        if not reasons:
            self.granted.append(c)
        return GrantDecision(granted=not reasons, reasons=reasons,
                             novelty=nu, support=sup)

    def covers(self, envelope) -> bool:
        """工作包络覆盖：每个包络样本至少被一条授予证书放行。"""
        return all(any(c.scope(x, t) and c.invariant(x) for c in self.granted)
                   for (x, t) in envelope)

    def conflicts(self) -> list[tuple[str, str]]:
        """重叠区不变量判决必须一致，否则证书组合自相矛盾。"""
        bad = []
        for c1, c2 in itertools.combinations(self.granted, 2):
            for x in overlap_samples(c1, c2):
                if c1.invariant(x) != c2.invariant(x):
                    bad.append((c1.cid, c2.cid))
                    break
        return bad

    def fto(self, x, t) -> FTOVerdict:
        """Freedom-to-Operate：有放行且无否决才可执行。"""
        admits = [c.cid for c in self.granted if c.scope(x, t) and c.invariant(x)]
        denies = [c.cid for c in self.granted if c.scope(x, t) and not c.invariant(x)]
        if denies:
            return FTOVerdict(ok=False, admits=admits, denies=denies)
        return FTOVerdict(ok=bool(admits), admits=admits, denies=[])
```

### IP-479 Prior-Art-Aware Transfer Gate (PAATG)

```python
def prior_art_aware_transfer(c_src, tau_s, tau_t, sim, support_estimator,
                             alpha=0.05):
    """把 v30 的 μ_i 从『相似度乘积』改为『未覆盖且被支持的范围占比』。"""
    target = stratified_sample(tau_t, n=4096, strata=('terrain','speed','load'))
    in_scope = [x for x in target if c_src.scope(x, tau_t)]
    if not in_scope:
        return TransferDecision(mu=0.0, reason='empty_intersection')

    uncovered = [x for x in in_scope
                 if not any(fp.match(x) for fp in c_src.prior_art)]
    if not uncovered:
        return TransferDecision(mu=0.0, reason='fully_anticipated')

    support = support_estimator(c_src.invariant, uncovered)
    raw_mu = sim(tau_s, tau_t) * len(uncovered) / len(target)

    # 关键修补：未覆盖区支持度不足时，迁移因子归零，而非静默取 1。
    if support < 1 - alpha:
        return TransferDecision(mu=0.0, reason='unsupported_uncovered_region')

    # 迁移范围不得超过经验支持范围，杜绝『虚假满迁移』。
    mu = min(raw_mu, support)
    return TransferDecision(mu=mu, reason='granted',
                            coverage=len(uncovered) / len(target),
                            support=support)
```

### IP-480 Certificate IR & Multi-Target Compiler (CIR-CC)

```python
@dataclass(frozen=True)
class CIR:
    op: str                         # AND/OR/GT/GE/LE/IN/LATCH/EVENTUALLY...
    args: tuple
    unit: Optional[Unit] = None     # 单位必须显式，禁止隐式换算
    frame: Optional[Frame] = None   # 坐标系必须显式
    strict: bool = True             # > 与 ≥ 的严格性必须可追踪
    source_span: SourceSpan = None  # 回溯到原始规则文本

TARGETS = ('py', 'cpp', 'stl', 'plc', 'cnl')

def compile_target(cir: CIR, target: str) -> CompiledCert:
    """每个目标都生成精化证明义务，译文不是『重写』而是『带证明的投影』。"""
    ir = lower(cir, target)
    if target == 'plc':
        ir = insert_rounding_guards(ir)      # 定点/时钟量化守卫
    if target == 'cnl':
        ir = attach_ontology(ir)             # 绑定共享本体版本
    obligations = generate_refinement_obligations(cir, ir, target)
    return CompiledCert(code=emit(ir, target),
                        obligations=obligations,
                        target=target)

def certify_translation(src: CIR, dst: CIR, target: str,
                        delta_max=1e-3) -> TranslationCert:
    delta = estimate_drift(src, dst, n=10_000)
    sound = check_soundness(src, dst)        # ⟦dst⟧ ⊆ ⟦src⟧
    return TranslationCert(src=hash_cir(src), dst=hash_cir(dst),
                           delta=delta, sound=sound, method=target,
                           conf=1.0 - delta,
                           accepted=(sound and delta <= delta_max))
```

### IP-481 Semantic Drift Monitor (SDM)

```python
class SemanticDriftMonitor:
    def __init__(self, delta_max=1e-3, n_probe=2048):
        self.delta_max, self.n_probe = delta_max, n_probe
        self.quarantined: set[str] = set()

    def estimate_delta(self, ref: CIR, cand: CIR, dist) -> float:
        xs = boundary_samples(ref, dist, n=self.n_probe)  # 优先采样边界/临界工况
        return sum(1 for x in xs if ref.eval(x) != cand.eval(x)) / len(xs)

    def on_translation(self, tc: TranslationCert) -> str:
        if (not tc.sound) or tc.delta > self.delta_max:
            self.quarantined.add(tc.dst)
            return 'QUARANTINE'
        return 'ACCEPT'

    def runtime_guard(self, ref: CIR, cand: CIR, x) -> GuardVerdict:
        r, c = ref.eval(x), cand.eval(x)
        if (not r) and c:                    # 译文放行了权威语义拒绝的状态
            return GuardVerdict(ok=False, reason='unsafe_omission')
        if r and (not c):                    # 译文更保守，安全但损失效用
            return GuardVerdict(ok=True, reason='conservative_reject')
        return GuardVerdict(ok=r, reason='agree')
```

### IP-482 Multilingual Explanation Renderer (MLER)

```python
class MultilingualExplanationRenderer:
    def __init__(self, ontology, cnl_grammar, langs=('zh', 'en', 'de', 'ja')):
        self.ontology, self.cnl, self.langs = ontology, cnl_grammar, langs

    def to_logical_form(self, claim: CertificateClaim) -> LogicalForm:
        """证书 → 版本化 interlingua；单位/坐标系/量词全部显式化。"""
        return self.ontology.lift(claim.invariant, claim.scope)

    def realize(self, lf: LogicalForm, lang: str) -> str:
        return self.cnl.realize(lf, lang)    # 受控自然语言，非自由翻译

    def render(self, claim, lang) -> ExplanationCert:
        lf = self.to_logical_form(claim)
        surf = self.realize(lf, lang)
        back = self.cnl.parse(surf, lang)
        consistent = logical_equiv(lf, back, self.ontology)
        ambiguous = self.detect_ambiguity(surf, lf)
        return ExplanationCert(lf_hash=hash_lf(lf), lang=lang, text=surf,
                               roundtrip=consistent, ambiguous=ambiguous,
                               ontology=self.ontology.version)

    def detect_ambiguity(self, surf, lf) -> bool:
        """多解析/单位歧义/框架歧义/量词辖域歧义任一出现即标记。"""
        parses = self.cnl.parse_all(surf)
        return len({canonical(p) for p in parses}) > 1
```

### IP-483 Polyglot Certificate Registry (PCR)

```python
class PolyglotCertificateRegistry:
    def __init__(self):
        self.claims: dict[str, CertificateClaim] = {}
        self.translations: dict[tuple[str, str], TranslationCert] = {}
        self.patent_family: dict[str, str] = {}
        self.defensive: dict[str, tuple[float, str]] = {}

    def register_claim(self, c, family=None, priority=None):
        self.claims[c.cid] = c
        if family:
            self.patent_family[c.cid] = family

    def register_translation(self, cid, target, tc):
        self.translations[(cid, target)] = tc

    def register_defensive_publication(self, cid, ts, content_hash):
        """防御性公开：时间戳先于潜在对抗申请，降低被围堵风险。"""
        self.defensive[cid] = (ts, content_hash)

    def fto_query(self, x, task, jurisdiction) -> FTOVerdict:
        """法域 = (平台, 任务, 语言/单位制)；缺任一必需译文即视为不可实施。"""
        required = self._required_targets(jurisdiction)
        for c in self.claims.values():
            if not c.scope(x, task):
                continue
            if any((c.cid, t) not in self.translations for t in required):
                return FTOVerdict(ok=False, reason='missing_translation')
            if not all(self.translations[(c.cid, t)].accepted for t in required):
                return FTOVerdict(ok=False, reason='unsound_translation')
        return portfolio_fto(self.claims, x, task)

    def consistency_audit(self) -> list[str]:
        """每条授予证书在必需目标上都应至少有一份 sound 译文。"""
        return [c.cid for c in self.claims.values()
                if any((c.cid, t) not in self.translations or
                       not self.translations[(c.cid, t)].accepted
                       for t in self._required_targets('default'))]
```

### PG-CADVS 统一执行流（单步）

```python
def pg_step(state, sensor, task, locale) -> ControlOutput:
    """
    在 CADVS 之上增加两层门控：先验技术/组合 FTO（专利维度），
    翻译 soundness/漂移（多语言维度）。任一不过则退回教师路径。
    """
    # 1) 证书组合的自由实施判定
    fto = pcr.fto_query(state, task, jurisdiction=locale)
    if not fto.ok:
        return fallback_to_teacher(state, sensor, reason=f'fto:{fto.reason}')

    # 2) 当前 locale 的译文必须 sound 且漂移在界内
    cert = pcr.active_cert(locale)
    if (not cert.tc.sound) or cert.tc.delta > delta_max:
        return fallback_to_teacher(state, sensor, reason='translation_unsound')

    # 3) 复用 CADVS 单步（学生/视觉伺服/教师/回退）
    out = cadvs_step(state, sensor)

    # 4) 运行时漂移守卫：译文不得放行权威语义拒绝的状态
    g = sdm.runtime_guard(cert.ref, cert.cand, state)
    if not g.ok:
        return fallback_to_teacher(state, sensor, reason=g.reason)

    # 5) 解释证书随控制输出下发（多语言、可回译）
    out.explanation = mler.render(cert.claim, locale.lang)
    return out
```

## 4. 正确性论证（增量更新）

### 引理 32（权利要求授予的局部健全性）

**陈述**：设 Grant(C) 成立，S* = S \ A，且支持度由 E∩S* 上的独立同分布样本估计、样本量 n ≥ n_min。则对从工作分布 𝒟 中抽取的 x∈S*，有 P(φ(x) | x∈S*) ≥ 1 − α − ε_est(n, α)，且任何被 C 放行的 x 都不属于现有技术 A。其中 ε_est 为有限样本估计误差。

**证明**：由 Grant 的构造，⟦C⟧ = S*，故 x∈S* ⇒ x∉A，后半部分按定义成立。支持度在 E∩S* 上估计，由 Hoeffding 不等式，n 个独立伯努利样本的经验均值与真实概率以至少 1−2exp(−2nα²) 的概率相差不超过 α；令 ε_est = sqrt(ln(2/δ_est)/(2n))，在置信度 1−δ_est 下得 P(φ|S*) ≥ 1−α−ε_est。∎

**工程含义**：ν_min 与 α 分别控制「范围是否被反例击穿」与「范围内是否被证据支持」；二者缺一不可，这正是对 v30 虚假满迁移的显式修补。

### 引理 33（证书组合的覆盖与无冲突）

**陈述**：设组合 P 中任意 C₁,C₂ 在重叠区 S₁*∩S₂* 上不变量判决一致（无冲突），且 ⋃_{C∈P} S_C* ⊇ X。则对任意 x∈X，FTO(x) 至少返回一条放行证书；若不存在否决证书，则按任一放行证书执行的局部保证在 x 处成立。

**证明**：由覆盖性，存在 C 使 x∈S_C*，故 admits 非空。由无冲突性，对任意同时覆盖 x 的 C'，φ_C(x)=φ_C'(x)，故不存在「一条放行、另一条否决」的矛盾。局部保证由引理 32 逐证书成立，取覆盖 x 的那条即可。∎

**推论**：组合把「单张全有或全无证书」的脆性，替换为「宽窄互补 + 重叠一致」的韧性；单条证书失效只缩小覆盖，不一定导致整体拒绝。

### 引理 34（保守翻译的安全性传递）

**陈述**：设权威证书 C 的译名为 C' = T(C)，且 T 是 sound 的（⟦C'⟧ ⊆ ⟦C⟧）。则运行时守卫在 C' 上放行的任何状态都被 C 放行，故 C 的安全保证原样传递到 C'；若 T 还是 ε-complete 的（在 𝒟 下 |⟦C⟧ \ ⟦C'⟧| ≤ ε），则相对权威语义的效用损失不超过 ε。

**证明**：sound 性即 C' 的放行集是 C 放行集的子集，故 C' 不会引入 C 未批准的行为，安全结论由子集关系传递。ε-complete 性给出被 C' 误拒的测度 ≤ ε，即保守翻译的效用损失上界。∎

**工程含义**：SDM 的 `unsafe_omission` 判据正是 sound 性的运行时反证；一旦触发，说明编译或译文破坏了包含关系，必须隔离并回退。

### 引理 35（受控自然语言回译的保义性）

**陈述**：设 CNL 语法是组合式的，且共享本体 𝒪 的逻辑形式到表层实现是一个同态映射（复合结构的实现等于实现的复合）。则对任意 LF，parse(realize(LF, ℓ), ℓ) 与 LF 在 𝒪 下逻辑等价；若不等价，则 MLER 的歧义检测器标记 `ambiguous=True`。

**证明**：组合性保证 realize 保持结构，同态性保证语义随结构逐层保持，故回译得到同构的逻辑形式，在 𝒪 的公理下逻辑等价。若解析器产生多个非同构结果，则 `parse_all` 的规范形式集合基数 > 1，检测器按定义标记歧义，命题对「未标记」的情形成立。∎

**工程含义**：解释证书不能只存字符串，必须存「逻辑形式哈希 + 本体版本 + 回译一致标志」，否则同一句话在不同语言/版本下可能指向不同规则。

### 定理（PG-CADVS 的执行集收缩与虚假包容消除）

**陈述**：在以下条件下：
(A1) 每条进入执行集的证书均满足 Grant（引理 32）；
(A2) 组合无冲突且覆盖当前工作包络（引理 33）；
(A3) 每个在线消费的译文均 sound 且 δ ≤ δ_max（引理 34）；
(A4) 解释仅在 roundtrip=True 时作为证书元数据下发（引理 35）；
则 Exec_PG ⊆ Exec_CADVS ⊆ Exec_v29，且虚假包容率（被放行但实际违反 φ 的测度）≤ α + ε_est；同时每条下发的解释与其 CIR 在 𝒪 下逻辑等价。

**证明**：
- 执行集收缩：PG 在 CADVS 之前增加 FTO 门与翻译门，任一失败即回退教师路径，故 PG 的放行集是 CADVS 放行集的子集；CADVS 已证 ⊆ Exec_v29，传递得证。
- 虚假包容率：由 A1 与引理 32，每条放行证书在其 S* 上的违反概率 ≤ α+ε_est；由 A2 无冲突，重叠区不会出现「一条保证成立、另一条保证失效」的掩盖；由 A3，译文不会扩大放行集，故不引入新的违反测度。取并集界即得。
- 解释保义：由 A4 与引理 35 直接得到。∎

**诚实声明**：α 与 ε_est 是**统计**保证，不是形式化证明；现有技术 A 只能枚举已知反例，无法覆盖未知未知（unknown unknowns），故「新颖」不等于「安全」。CNL 的组合性/同态性是理想假设，真实自然语言存在指代、省略与隐喻，回译一致只是必要条件而非充分条件。PG-CADVS 用「授予 + 保守翻译 + 运行时守卫 + 回退」管理风险，而非消除风险。

## 6. 本轮最大风险（最终确认）

**一句话**：**专利类比的形式化失真会被多语言渲染放大**——新颖性/支持度/可实施性本是法律-社会建构，却被包装成证书的「授予条件」，于是一张统计上仅有 1−α 把握、且可能被未知反例击穿的规则，会在四种语言、五种运行时目标中都以「已授权、已翻译、已验证」的整齐面貌出现；**程序合法性替代了语义安全性**，而多语言一致性恰好制造了「处处都可信」的错觉——这是比 v30 的虚假常识包容更隐蔽、也更难在事后审计中定位的系统性风险。
