# 第 3 轮（灵感循环第 3 轮；本轮灵感：「多机协同」×「安全对齐」）

> **基线继承**：第 2 轮 **ToolGauge**（IP-315–320；定义 416–431；引理 46–50；实验 E426–E440），
> 其下依次为 LeanGauge（第 1 轮）、MODGAUGE（基座）。
> 本轮纪律：**继续在前人基础上改进**——ToolGauge 的 L-Box / T-Box / AP-Cal / P-Quarantine 全部保留；
> 两条新灵感轴各升级一层：多机协同把「单机修复」升级为「联邦修复」，安全对齐把「能不能修」升级为「该不该修」。
> MODGAUGE 五不变式 + 第 2 轮主张绑定语言扩展 + 严格退化链全部保留，并新增两条不变式
> （**集体安全不变式**、**对齐单调性**）。

## 双灵感 → 三层升级映射

| 灵感词 | 第 2 轮对象 | 升级为 | 一句话动机 |
|---|---|---|---|
| 多机协同 | 单机 ToolGauge：一台机器人独自发现、探测、校准盲区 | **FML 联邦计量账本 + 拜占庭稳健证据共识**：回执、修复证书跨机共享，但以来源链、信任分、f-of-3f+1 共识约束 | 盲区是**环境**的属性，不是某台机器人的属性；但共享会把局部误差变成集体误差——共享必须自带反污染机制 |
| 安全对齐 | 6C：只要信息增益够、交叉验证过就热替换 | **宪章门控 + 价值延迟 + 对齐税账本**：先过硬约束，再看价值模型，价值不确定就交给人 | 「能修」不等于「该修」；安全不是可优化目标，而是一组不可交易的前置约束 |
| 协同 × 对齐（合流） | 第 2 轮 P-Quarantine：只监控**跨盲区**的时间相关偏差 | **联盟级对齐**：分布式否决 + 安全棘轮 + 分歧即元盲区 | 共识可以把**多数相关错误**洗成「真值」；对齐在多机场景下不是逐机对齐，而是「即使多数错了也安全」 |

**核心命题**：把 ToolGauge 的「语义假设 → 契约化工具调用 → 摊销校准 → 交叉验证后局部热替换」升级为
「**联邦假设 → 带来源链的共享回执 → 拜占庭稳健共识 → 宪章门控的对齐评估 → 分布式背书后热替换**」。
计量层继续独占数值真值；价值层只决定「该不该动」，且只能**移除**动作、不能修改数值；联盟层只决定「大家认不认」，
且不能覆盖宪章。三层职责正交：**能不能（计量）× 该不该（对齐）× 认不认（共识）**。

**不变式保持声明**：
- MODGAUGE 五不变式 + 第 2 轮主张绑定语言扩展全部保留；
- 新增**集体安全不变式**：任何单机或任意联盟（含多数联盟）都不能使联邦动作违反宪章（定义 440 / 引理 54）；
- 新增**对齐单调性**：有效安全集跨版本只增不减，除非有人类签名的显式授权记录在案（定义 448）；
- **严格退化链再延长**：CovenantGauge（联邦 + 宪章）⇒ ToolGauge（联邦/对齐不可用）⇒ LeanGauge ⇒ MODGAUGE。

## 0. 直觉与动机

**灵感 1（多机协同 → 联邦计量，但「共享即污染」）**
直觉：一台机器人冒着物理风险探明的盲区，另一台在同类环境下本可直接复用——拒绝共享是巨大的重复冒险。
但朴素共享有三重病理：
(a) **相关先验**：舰队共用同一个 MP-Φ 时，所有机器人朝同一方向犯同一错，「多数」只是同一个错误的 n 次复制；
(b) **拜占庭/失准同伴**：漂移或恶意机器人可向账本注入毒化回执，单机无法分辨；
(c) **真实分歧**：不同视角、不同标定谱系会产生真实的不一致，这恰恰是「语义假设可能错了」的证据。
因此共享必须同时具备：**来源链**（定义 432）、**信任分**（433）、**稳健聚合 + 证据共识**（434）、**账本**（435），
以及把分歧转化为行动的**元盲区联合探测**（442）。我们会证明：真正限制联邦收益的不是机器人数量，而是**去相关程度**
（引理 52：`n_eff = n/(1+(n−1)ρ) < 1/ρ`）。

**灵感 2（安全对齐 → 把「可修」与「该修」分离，安全是约束不是目标）**
直觉：ToolGauge 的增益注 β 会鼓励系统去探测「信息量大」的盲区，但「为了学习而扰动靠近人的透明体」不是信息问题，是规范问题。
安全对齐的工程智慧是：**先立宪、再优化、必要时问人**。
于是设三层裁判：(i) **宪章**（437）是不可交易的硬约束，字典序优先于一切收益；
(ii) **价值模型**（438）学习人类偏好「这个盲区值不值得用这次探测去修」，并输出认知不确定性，不确定即 **DEFER**（默认不行动）；
(iii) **计量层**照旧独占真值。关键性质：对齐门是动作集上的**投影**（447），只能删动作/延迟，不能加动作或改数值——
所以第 2 轮全部数值安全引理原样成立，对齐的代价只体现为可量化的**对齐税**（439），且超预算时**降能力而非降安全**。

**灵感 3（合流：共识可以把错误合法化——联盟级对齐）**
直觉：拜占庭稳健聚合防的是「少数恶意」，却防不住「多数相关地错」。如果整个舰队共享错误先验或错误宪章，
那么共识、语言证书、联邦签名会**共同为一件事背书到最高置信度**，这比单机犯错更危险。
因此本轮真正的安全资产不是「更强的共识」，而是三件反合谋机制：
**去相关**（异构工具/视角/标定谱系，使 ρ 下降）、**安全棘轮**（448，约束集只增不减）、
**分布式否决 + 冗余覆盖**（440 / 引理 54：每个安全关键区域被 ≥ f+1 台诚实机器人覆盖，否则安全保证失效）。
一句话：多机系统里，对齐的问题从「它会不会做坏事」变成「它们会不会**一致地**做错事」。

## 1. 形式化定义（增量：定义 432–449）

**定义 432（机器人、联邦与回执来源链）** 机器人集合 𝒜 = {a₁,…,aₙ}。在定义 417 的回执 r 上追加来源链
prov(r) = (a_k, cert_k, ts, hash(parent_r), region_id)，cert_k 为 a_k 的有效标定证书。
valid_f(r) ⇔ valid(r) ∧ VerifyCert(cert_k, ts) ∧ hash(parent_r) 在 FML 中可达。
不同机器人的回执只有在**同源标定谱系**下才可直接叠加；异构标定须先做**传递对齐**（transfer alignment）。

**定义 433（信任分）** 每台机器人维护 τ_a ∈ [0,1]，以 Beta 后验更新：
τ_a ← (α₀ + s_a) / (α₀ + β₀ + s_a + f_a)，其中 (s_a, f_a) 为独立审计的成功/失败计数。
审计定义为「一台**未参与该回执产生**的机器人」对它做交叉验证（定义 421.V 的联邦化）。
长期不参与按半衰期衰减 τ_a ← τ_a·2^{−Δt/T_τ}，防止一次性信誉被永久背书。

**定义 434（联邦证据聚合与拜占庭稳健共识）** 本地校准更新 {u_a}：
- **数值聚合**：ū = 逐坐标截尾均值（两端各截掉 f 个，或用信任分加权），几何中位数作抗塌陷兜底；
- **证据共识**：修复被**联邦采纳** ⇔ 至少 q = 2f+1 台**互不相同**的机器人各自独立回执验证通过（或信任加权和 ≥ Θ_q），
  参数满足 n ≥ 3f+1，f 为可容忍的恶意/失准机器人上限。
**断言边界**：该机制只保证「多数恶意无法单方面改写」与「冲突修复不会同时被采纳」（引理 51）；
**不保证多数不犯错**——后者由去相关、安全棘轮、分布式否决负责（§6）。

**定义 435（联邦计量账本 FML）** 只追加、哈希链、逐机签名的 DAG，节点 ∈ {receipt, repair_cert, constitution_version, audit}。
查询返回**证据包** E_b(s)，供 L-Box / AlignGate / 人工审计复算。
FML 不存原始高分辨率点云，只存统计量与语义指纹，以降低泄露面（E453）。

**定义 436（联邦共形覆盖与有效样本量）** 合并 n 条相关回执时，设组内相关为 ρ：
**n_eff = n / (1 + (n−1)ρ)**。
联邦共形分位数必须用 n_eff 而非 n，否则覆盖率被系统性高估。
**天花板**：n_eff < 1/ρ，故即使 n → ∞，只要 ρ > 0 就只能获得有限独立证据——这是「回声室」的可计算上限。

**定义 437（安全宪章）** 有序硬约束集 C = (c₁,…,c_K)，部署前预注册、版本化、签名。
每条 c_k : (state, repair_action, context) → {pass, violate}，例如人眼安全等级、力/温硬限、
禁止对未验证透明体施加接触探测。语义为**字典序**：先满足全部 c_k，才允许任何优化。
修订需同时满足：(i) 人类签名授权；(ii) 联邦超多数；(iii) 通过单调性检查（定义 448）。

**定义 438（价值模型与不确定性感知延迟）** V_ψ(s, repair) ∈ [0,1] 由人类偏好对训练（「这个盲区值不值得用这次探测去修」）；
认知不确定性 σ_V 由深集成/Bayes 后验给出。
**对齐门**：仅当 V_ψ ≥ v_min 且 σ_V ≤ ε_V 才自动放行，否则 **DEFER**（提交人类）；价值不确定时默认不行动。
三类裁判分工明确：宪章判「允不允许」，价值模型判「该不该/合不合意」，计量判「修得对不对」。

**定义 439（对齐税账本）** A-tax = (覆盖率损失 Δcov, 修复率损失 Δrep, 附加时延 Δτ, 延迟率 r_def)，逐项入账并设预算 A_budget。
方向约束：**预算超支时降低能力，而非降低安全**（safety-dominant）。A-tax 必须可审计，禁止「用安全换指标」的隐性权衡。

**定义 440（分布式否决与集体安全）** 对任一候选联邦动作 P，若存在任一诚实机器人 a 在其感知范围内观测到 P 将违反某 c_k，
则 a 广播 veto，P 被阻断：
Veto(P) ⇔ ∃a ∈ Honest, Observe_a(P) ∧ violates_C(P)。
**硬约束不可被任何法定人数覆盖**（quorum 无权 override 宪章）。
**推论（冗余要求）** 集体安全成立的一个充分条件是：每个安全关键区域被 ≥ f+1 台诚实机器人覆盖。

**定义 441（CovenantGauge 七段闭环 7C）** H → C → E → C → V → A → U：
1. H：联邦假设（L-Box，输入证据包 E_b(s)）；
2. C：编译探测程序（TCV，定义 418）；
3. E：执行（多机可并行/协同，需同步时钟）；
4. C：校准（AP-Cal + 联邦稳健聚合）；
5. V：交叉验证，**必须包含至少一台未参与该修复的机器人**的独立回执；
6. A：对齐门（宪章 + V_ψ + DEFER + 联邦证据共识）；
7. U：热替换（仅本机，或经共识的联邦替换）。
A 失败 ⇒ DEFER / stub，**绝不热替换**。

**定义 442（分歧即元盲区）** 若两台受信机器人对同一物理格子的回执标准化残差 |z| > ε_cross，则登记**元盲区**
m = (s, {a_i, a_j}, z)，触发**联合探测**（同步激励、多视角三角化、共享时钟）。
若未解决且双方均可信 ⇒ 标记「物理歧义」，该格子进入 quarantine（不热替换，交人工/更强工具）。
**分歧不是噪声，而是「语义假设可能错了」的证据。**

**定义 443（过程式抗奖励黑客）** 对齐门只接受**过程证据**：有效回执 + 完整来源链 + 至少一台未参与修复者的独立复验；
**禁止自我认证**（修复发起者不能是唯一验证者）。输出指标不能替代过程证据；
语言证书（定义 427）在联邦层面必须附共识签名，否则只作本地注释。

**定义 444（信任演化与同伴隔离）** 审计结果更新 τ_a；若 τ_a < τ_min 持续一个窗口 W，则 quarantine 该同伴
（其回执不进联邦共识/聚合，只可作本机弱先验），并触发重标定审计。
残差聚类区分「失准（可修）」与「对抗（隔离）」：失准者进再标定队列，对抗者永久降权并留痕。

**定义 445（通信预算与新鲜度）** 联邦通信预算 B_comm；回执带半衰期 T_fresh，权重 w = 2^{−Δt/T_fresh}；
异步 disseminate，**绝不阻塞 50Hz 控制路径**；联邦平均轮数 ≤ R_comm。

**定义 446（联邦采样复杂度，修正定义 426）** 沿定义 436，欲使 n_eff ≥ n_req，需
**n ≥ n_req(1−ρ)/(1 − n_req·ρ)**，且必须 ρ < 1/n_req。
故「堆机器」不能突破相关性天花板；ρ ≥ 1/n_req 时无论多少机器人都无法达标，唯一出路是**去相关**（异构工具/视角/先验）。
低于门槛即触发定义 428 的告警。

**定义 447（对齐门是安全投影）** 对齐门 A 是动作集上的投影：A(P) ∈ {P, DEFER} 且 A(P) ⊆ P；
被移除的动作不产生物理副作用。因此第 2 轮数值安全引理（46–50）在 A 的像集上原样成立；
对齐层只能**减少能力**，不能**增加数值风险**。

**定义 448（对齐单调性 / 安全棘轮）** 有效安全集 S_t = {动作 : 满足 C_t}。跨版本要求 S_{t+1} ⊇ S_t，
除非存在人类签名的显式授权并记录于 FML。任何修复、聚合或宪章修订若使 S 收缩，一律阻断。**安全只增不减。**

**定义 449（继承与编号约定）** 第 2 轮记号（R, s, λ, γ, M_ver, N_bl, EC, MP-Φ, T₀, H_s, P-Quarantine, …）全部沿用定义 416–431。
本文增量以 ToolGauge 为退化特例：令 n = 1、FML = ∅、C = ∅、V_ψ ≡ 1、无 deferral ⇒ CovenantGauge ≡ ToolGauge。

```python
# IP-322 拜占庭稳健联邦聚合（截尾均值 + 信任加权 + 几何中位数兜底）
def federated_aggregate(updates, trust, f):
    # updates: [(a, u, sigma)]
    kept = sorted(updates, key=lambda x: trust[x.a])[f : len(updates) - f]
    if not kept: return None
    w = np.array([trust[x.a] / max(x.sigma, 1e-9) for x in kept])
    med = geometric_median([x.u for x in kept])
    u_bar = (w @ np.stack([x.u for x in kept])) / w.sum()
    return u_bar if robust_ok(u_bar, med) else med        # 均值被拉走则退回中位数

# IP-321 FML 证据共识
def federated_consensus(repair, fml, f):
    endorsers = fml.distinct_verifiers(repair.cert)       # 来源链独立的复验者
    return len(endorsers) >= 2 * f + 1 and fml.provenance_ok(repair)

# IP-323 对齐门（宪章 → 分布式否决 → 价值 → 延迟）
def align_gate(P, state, C, Vpsi, vetoes):
    if any(violates(c, state, P) for c in C): return "REJECT"   # 硬约束，字典序优先
    if vetoes.blocking(state, P):             return "REJECT"   # 分布式否决（定义 440）
    val, sig = Vpsi(state, P)                                    # 价值 + 认知不确定性
    if val < Vpsi.v_min or sig > Vpsi.eps:    return "DEFER"    # 不确定 ⇒ 交人
    return "ALLOW"

# IP-325 CovenantGauge 7C 闭环
def covenant_7c(M, s):
    H    = M.lbox.hypothesize(s, M.fml.evidence_bundle(s))              # H（联邦先验）
    prog = M.tbox.select(H, M.tools, M.tcv, M.budget_left(s))           # C
    recs = M.executor.run(prog, M.fleet, sync=True)                     # E（多机、同步时钟）
    recs = [r for r in recs if valid_f(r)]                              # 定义 432
    if M.fml.divergent(s, recs):                                        # 定义 442
        recs += M.fleet.joint_probe(s)                                  # 分歧 ⇒ 联合探测
    if len(recs) < n_min(s): return stub_and_red(s, "insufficient")     # 定义 426
    mu, Sig = M.apcal.calibrate(recs, H, s)                             # C
    mu, Sig = federated_aggregate(M.fml.peer_updates(s), M.trust, M.f)  # 拜占庭稳健
    if not M.apcal.cross_validate(mu, Sig,
            M.fml.independent_receipt(s, exclude=M.self, require_hetero=True)):
        return stub_and_red(s, "cross_failed")                          # V：必须异构独立
    repair  = M.build_repair(s, mu, Sig)
    verdict = align_gate(repair.prog, M.state, M.C, M.Vpsi, M.vetoes)   # A（定义 437/438/440）
    if verdict == "DEFER":  return defer_to_human(s, repair)            # 不确定 ⇒ 人
    if verdict == "REJECT": return stub_and_red(s, "constitution")      # 硬约束/否决
    if not federated_consensus(repair, M.fml, M.f):
        return apply_local_only(repair)                                 # 仅本机，不称联邦真值
    M.mreg.hot_replace(M.dpe, repair)                                   # U
    M.dbox.update_from_posterior(s, mu, Sig)
    M.fml.append(repair, cert=bind_claims(repair, H, recs))             # 联邦证书
    M.pquar.record(M.apcal.last_gain, realized_gain(recs))              # 跨机 + 跨盲区双监控
    return True

        if s not in M.inflight:
            M.inflight.add(s); submit_async(covenant_7c, M, s)
    if M.pquar.triggered():       M.apcal.pause(); M.use_bpcal_fallback = True
    if M.fleet.trust_degraded():  M.fml.quarantine(M.fleet.suspects(), M.trust)   # 定义 444
    return MODGAUGE_round(M, obs, audio, tac, depth, det)                # 主控不变
```

## 3. 推导

**引理 51（拜占庭证据共识的安全性）** n ≥ 3f+1、法定人数 q = 2f+1、拜占庭 ≤ f，且诚实者不对冲突修复同时背书，
则不存在两个冲突修复同时被联邦采纳。
证明：任意两个 q 集合交集 ≥ 2q − n = f+1，其中至少 1 台诚实；它必对冲突二者之一拒绝，矛盾。
活性在部分同步下由超时重试保证（不作强断言）。**系**：联邦采纳的「一致性」与「少数不可改写」有保证，但「正确性」不在此列。

**引理 52（相关回执的覆盖修正与回声室天花板）** 组内相关 ρ 下 n_eff = n/(1+(n−1)ρ)；
以 n_eff 计算共形分位数可近似恢复 1−α 覆盖；以 n 计算则覆盖率被系统性高估，高估量随 ρ 单调增大。
且 n_eff < 1/ρ ⇒ 相关性为证据设定硬上限。
**系 52.1**：ρ ≥ 1/n_req 时增加机器人数量对达到 n_req 无效；此时唯一出路是**去相关**（异构工具/视角/标定谱系），而非扩编。
**系 52.2**：这解释了为何「同款机器人 × 同一预训练先验」的联邦收益远低于纸面想象。

**引理 53（对齐门不破坏数值安全）** 由定义 447，A 只做投影/延迟；故引理 46–50 在像集上原样成立。
结合引理 51 的证据共识与定义 443 的过程证据，联邦层面不引入新的数值安全漏洞——只可能降低修复率。
证明：数值行为完全由被保留的 P 决定，A 不修改 μ/Σ/χ_R 等任何数值字段。

**引理 54（分布式否决的安全-覆盖权衡）** 若每个安全关键区域被 ≥ f+1 台诚实机器人覆盖，
则任何硬约束违反都会在至少一台诚实观测者处被否决（无假阴性）；
若覆盖不足 f+1，则存在一个场景使全部观测者恰为拜占庭或处于感知盲区，集体安全保证失效。
故**集体安全等价于一个冗余度设计约束**，不是算法参数；这把「安全」从软件属性变为部署属性。

**引理 55（对齐税有界与实时保持）** A-tax 的时延部分 ≤ O(1) 每候选（宪章谓词 + 价值前向可异步化）；
DEFER 为异步阻塞；50Hz 路径新增 ≤ 0.1ms。能力损失有界于「宪章拒绝域测度 + 延迟率」。
预算超支时按 safety-dominant 规则降低能力。硬实时（引理 45/50）保持。

**引理 56（严格退化与等价）** n = 1、C = ∅、V_ψ ≡ 1、无 FML 时：align_gate 恒 ALLOW、
federated_consensus 退化为本地验证 ⇒ CovenantGauge ≡ ToolGauge；再依次退化到 LeanGauge、MODGAUGE。
退化过程只删功能不删安全（安全棘轮 448 在退化时保持）。

## 6. 本轮最大风险（一句话）

**一句话**：拜占庭稳健共识只防「少数恶意」，防不住「多数**相关地**错」——若整个舰队共享同一错误先验或同一份写错的宪章，
共识、来源链、语言证书与联邦签名会把这个错误**洗白为最高置信度的集体真值（error laundering）**，
届时系统不是「偶尔修错一个盲区」，而是「以最一致、最可信的方式一致地做错事」，且分布式否决保证的是「一致地执行宪章」而非「宪章本身正确」。

**次级风险与缓解**：
1. **相关性合谋** → 强制去相关（异构工具/视角/谱系）+ 安全棘轮（448）+ 定期人工抽样重验；
2. **宪章自身失准** → 人类签名授权 + 版本化 + 修订超多数 + 单调性检查（437/448）；
3. **价值模型被奖励黑客** → 过程证据（443）+ 未参与方独立复验 + 输出指标不得替代回执；
4. **分布式否决失效于覆盖不足** → 冗余度设计约束 ≥ f+1（引理 54），部署前做覆盖审计（E448）；
5. **联邦通信/新鲜度** → B_comm + 半衰期权重 + 异步 disseminate（445），绝不阻塞 50Hz；
6. **回执泄露专有几何** → FML 只存统计量与指纹（435），E453 量化泄露面；
7. **联邦/对齐不可用** → 严格退化链（引理 56），VLA/联邦/价值模型都是增强项而非依赖项。

## 2. 形式化定义（要点）

**定义 432/433（来源链 / 信任分）** 回执须附标定证书与父哈希链，异构标定先传递对齐；信任分为 Beta 后验并按半衰期衰减，审计者必须未参与该回执产生。
**定义 434（联邦证据共识）** 数值聚合用截尾均值/几何中位数 + 信任加权；联邦采纳需 q = 2f+1 台互异机器人独立验证，n ≥ 3f+1。只保证一致性与少数不可改写，**不保证多数正确**。
**定义 435（FML）** 只追加、哈希链、逐机签名的账本；只存统计量与语义指纹，不存原始高分辨率点云。
**定义 436/446（联邦共形与采样复杂度）** n_eff = n/(1+(n−1)ρ)；欲达 n_req 需 n ≥ n_req(1−ρ)/(1−n_reqρ) 且 ρ < 1/n_req；否则堆机器无效，须去相关。
**定义 437/438（宪章 / 价值延迟）** 宪章是字典序硬约束；价值模型输出（价值, 认知不确定性），不确定即 DEFER，默认不行动。
**定义 439（对齐税）** 覆盖率/修复率/时延/延迟率四项入账，超预算时降能力不降安全（safety-dominant）。
**定义 440（分布式否决）** 任一诚实观测者即可否决宪章违反；quorum 无权 override。充分条件是安全关键区域被 ≥ f+1 台诚实机器人覆盖。
**定义 441（7C）** H→C→E→C→V→A→U；V 必须异构独立，A 为宪章/价值/否决门，联邦采纳需证据共识。
**定义 442（元盲区）** 跨机残差 |z| > ε_cross ⇒ 联合探测；未解决 ⇒ quarantine，不热替换。
**定义 443（过程式抗奖励黑客）** 只认过程证据 + 完整来源链 + 未参与方独立复验；禁止自我认证；语言证书联邦化需共识签名。
**定义 444（信任演化与隔离）** τ_a < τ_min 持续 W ⇒ quarantine；残差聚类区分失准（可修）与对抗（隔离）。
**定义 445（通信预算/新鲜度）** B_comm、半衰期权重、异步 disseminate、平均轮数 ≤ R_comm，绝不阻塞 50Hz。
**定义 447/448（安全投影 / 安全棘轮）** 对齐门只能移除或延迟动作，故不破坏数值安全；有效安全集跨版本只增不减，除非人类签名授权。
**定义 449（继承）** 第 2 轮记号全部沿用；n = 1、C = ∅、V_ψ ≡ 1、无 FML ⇒ CovenantGauge ≡ ToolGauge。

```python
# IP-322 拜占庭稳健联邦聚合
def federated_aggregate(updates, trust, f):
    kept = sorted(updates, key=lambda x: trust[x.a])[f : len(updates) - f]
    if not kept: return None
    w = np.array([trust[x.a] / max(x.sigma, 1e-9) for x in kept])
    med = geometric_median([x.u for x in kept])
    u_bar = (w @ np.stack([x.u for x in kept])) / w.sum()
    return u_bar if robust_ok(u_bar, med) else med

# IP-321 FML 证据共识
def federated_consensus(repair, fml, f):
    endorsers = fml.distinct_verifiers(repair.cert)        # 来源链独立的复验者
    return len(endorsers) >= 2 * f + 1 and fml.provenance_ok(repair)

# IP-323 对齐门（宪章 → 否决 → 价值 → 延迟）
def align_gate(P, state, C, Vpsi, vetoes):
    if any(violates(c, state, P) for c in C): return "REJECT"  # 硬约束优先
    if vetoes.blocking(state, P):             return "REJECT"  # 分布式否决
    val, sig = Vpsi(state, P)
    if val < Vpsi.v_min or sig > Vpsi.eps:    return "DEFER"   # 不确定 ⇒ 人
    return "ALLOW"

# IP-325 CovenantGauge 7C 闭环
def covenant_7c(M, s):
    H    = M.lbox.hypothesize(s, M.fml.evidence_bundle(s))              # H
    prog = M.tbox.select(H, M.tools, M.tcv, M.budget_left(s))           # C
    recs = M.executor.run(prog, M.fleet, sync=True)                     # E
    recs = [r for r in recs if valid_f(r)]                              # 定义 432
    if M.fml.divergent(s, recs): recs += M.fleet.joint_probe(s)         # 定义 442
    if len(recs) < n_min(s): return stub_and_red(s, "insufficient")     # 定义 426
    mu, Sig = M.apcal.calibrate(recs, H, s)                             # C
    mu, Sig = federated_aggregate(M.fml.peer_updates(s), M.trust, M.f)  # 拜占庭稳健
    if not M.apcal.cross_validate(mu, Sig,
            M.fml.independent_receipt(s, exclude=M.self, require_hetero=True)):
        return stub_and_red(s, "cross_failed")                          # V：异构独立
    repair  = M.build_repair(s, mu, Sig)
    verdict = align_gate(repair.prog, M.state, M.C, M.Vpsi, M.vetoes)   # A
    if verdict == "DEFER":  return defer_to_human(s, repair)
    if verdict == "REJECT": return stub_and_red(s, "constitution")
    if not federated_consensus(repair, M.fml, M.f):
        return apply_local_only(repair)                                 # 仅本机
    M.mreg.hot_replace(M.dpe, repair)                                   # U
    M.dbox.update_from_posterior(s, mu, Sig)
    M.fml.append(repair, cert=bind_claims(repair, H, recs))
    M.pquar.record(M.apcal.last_gain, realized_gain(recs))
    return True

# IP-326 主闭环
def CovenantGauge_round(M, obs, audio, tac, depth, det):
    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight:
            M.inflight.add(s); submit_async(covenant_7c, M, s)
    if M.pquar.triggered():      M.apcal.pause(); M.use_bpcal_fallback = True
    if M.fleet.trust_degraded(): M.fml.quarantine(M.fleet.suspects(), M.trust)
    return MODGAUGE_round(M, obs, audio, tac, depth, det)
```

## 4. 推导

**引理 51（拜占庭证据共识安全性）** n ≥ 3f+1、q = 2f+1、拜占庭 ≤ f、诚实者不对冲突修复同时背书 ⇒ 不存在两个冲突修复同时被联邦采纳。
证明：任两 q 集交集 ≥ 2q − n = f+1 ≥ 1 台诚实，必否决冲突之一。**边界**：只保证一致性与少数不可改写，不保证多数正确。
**引理 52（相关回执覆盖修正 / 回声室天花板）** n_eff = n/(1+(n−1)ρ) < 1/ρ；以 n_eff 计共形分位数可近似恢复 1−α，以 n 计则覆盖被高估。
系：ρ ≥ 1/n_req 时扩编无效，唯一出路是**去相关**（异构工具/视角/标定谱系）。
**引理 53（对齐门不破坏数值安全）** A 是投影/延迟，不修改任何数值字段 ⇒ 引理 46–50 在像集成立；联邦层不引入新数值漏洞，只降修复率。
**引理 54（分布式否决的安全-覆盖权衡）** 安全关键区域被 ≥ f+1 台诚实机器人覆盖 ⇒ 硬约束违反无假阴性地被否决；覆盖不足则存在全拜占庭/全盲区场景使保证失效。故集体安全是**部署冗余约束**。
**引理 55（对齐税有界 / 实时保持）** 对齐门每候选 O(1) 且可异步；DEFER 异步阻塞；50Hz 新增 ≤ 0.1ms；能力损失有界于宪章拒绝域测度 + 延迟率；超预算降能力不降安全。
**引理 56（严格退化与等价）** n = 1、C = ∅、V_ψ ≡ 1、无 FML ⇒ 恒 ALLOW、共识退化为本地验证 ⇒ ≡ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE；退化只删功能不删安全。

## 8. 本轮最大风险

**一句话**：拜占庭稳健共识只防「少数恶意」，防不住「多数**相关地**错」——若整个舰队共享同一错误先验或同一份写错的宪章，
共识、来源链、语言证书与联邦签名会把这个错误**洗白为最高置信度的集体真值（error laundering）**，
系统将以最一致、最可信的方式一致地做错事，而分布式否决保证的是「一致地执行宪章」而非「宪章本身正确」。

**缓解**：去相关（异构工具/视角/谱系，引理 52）＋ 安全棘轮（448）＋ 宪章人类签名与超多数修订（437）
＋ 过程证据与未参与方复验（443）＋ 冗余覆盖 ≥ f+1（引理 54）＋ 定期人工抽样重验；E443/E447/E448/E456 为证伪实验。
