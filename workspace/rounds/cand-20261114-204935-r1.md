# 第 2 轮（承接第 1 轮「LeanGauge」IP-310~314、定义 398–415；灵感循环第 2 轮；本轮灵感：「移动操作」×「知识图谱」）

> 第 1 轮的 LeanGauge 把「等待大数据」改造成「主动发现需求盲区 + 少样本局部校准」，但它保留了一个从未被写进定义的空间前提：**需求盲区被当作与地点无关的（距离 × 材质 × 互扰）子空间**。移动操作恰好打破这个前提——同一个杯子放在 0.6 m 的桌边与放在 1.8 m 的桌角，其「可抓」契约并不相同；底座定位误差会被机械臂力臂放大，机械臂标定误差又依赖底座把臂带到哪里。更麻烦的是，部署中不可能在每个地点重采一遍：**知识图谱**（地点—物体—技能—构型的类型化关系）天然提供了「这里和那里相似、这个物体属于那一类、这个技能适用于这种可供性」的迁移假设。
>
> 但知识图谱是**语义的**，计量契约是**几何与统计的**。语义等价可传递（A 类 ≈ B 类，B 类 ≈ C 类 ⇒ A 类 ≈ C 类），证据输运却不天然传递（A 的标定搬到 B 有效、B 搬到 C 有效，不保证 A 直接搬到 C 仍有效，因为误差会沿多跳累积，并在力臂上放大）。于是本轮的核心命题是：
>
> **把知识图谱从「真值 / 常识先验」降格为「契约输运的候选索引」，把移动操作的可达性从「各模块分别认证」升级为「底座—机械臂—物体的联合认证」，并明确规定：只有携带输运证书的图路径才允许复用证据；语义等价绝不自动等于证据等价。**
>
> 设计 **REACHGAUGE-RAS**（Reachability-graph, Evidence-transport, Arm-base Coupled metrology with GAuged audits for RAS）：「可达图计量」。IP-315~321；定义 416–429；实验 E426–E437。理论姿态：**REACHGAUGE 是 LeanGauge 的严格空间泛化**——图无输运边时退化为逐地点 LeanGauge；禁止输运时退化为逐地点重见证；安全侧只增不减，退化链逐指令等价。

## 0. 直觉与动机

**灵感 1（移动操作 → 力臂把「地点」变成契约的一部分）**

直觉：导航模块报告「定位误差约 2°、5 cm」，这听起来很小；但把机械臂伸到 2 m 外的杯子上时，2° 的底座偏航会在末端变成约 70 mm 的横向误差。一个在导航域被认证为「优秀」的模块，进入操作域后可能直接吃掉整个夹爪间隙。**底座姿态不是操作的前置条件，而是操作不确定度的齿轮。** 更一般地，末端协方差不是各模块协方差的标量相加，而是

Σ_ee = J_base Σ_base J_baseᵀ + J_arm Σ_arm J_armᵀ + Σ_obj，

其中 J_base 的旋转块范数正好等于「底座到末端的水平力臂」。因此，任何把底座不确定度按导航坐标系原样搬进操作契约的做法，都会在长臂展处**系统性高估**认证裕度。这条不是实现细节，而是「模块化计量」在移动操作中的结构性漏洞：移动底盘与机械臂各自持有正确的证书，组合起来却是错的。

**灵感 2（知识图谱 → 语义可传递，证据不可传递）**

直觉：知识图谱让系统可以推理「这个马克杯与上周那个马克杯同类，所抓取标定可复用」「这个桌角与隔壁桌角同属‘靠墙放置点’，所以底盘可以停过去」。这是强大的摊销机制：一次标定，多处复用。但语义关系的传递性来自类型系统，证据输运的有效性来自几何与噪声的连续性。二者只在**局部**重合：如果两个节点在契约相关度量下距离很近，且输运算子在该邻域内 Lipschitz，那么旧证据可以带膨胀项复用；否则，语义上再「同类」，旧的误差界也可能完全失效。

关键反直觉：**多跳语义链不是一条免费的高速公路**。A（某桌角）~B（同房间另一桌角）~C（另一房间同类桌），每一跳单独都「差不多」，但材质、光照、桌面高度、轮子打滑率会沿路径累积；三步之后，系统手里拿着的可能是一张「语法正确、语义连通的图路径」和一份「几何上已经越界」的旧标定。图论上的连通性不能替代计量学上的输运证书。

**灵感 3（开放世界 → 三值可达性，缺边不等于不可达）**

直觉：知识图谱通常是开放世界的局部快照。图中没有「这个物体—这个技能」的边，可能只是因为还没人录入，而不是因为物理上不可达。若规划器采用封闭世界假设（negation as failure：无边 ⇒ 不可达），它会在遇到新物体时**错误地拒绝**可行任务；更危险的是，若它为了「能干活」而把缺边默认成可达，又会绕过证书。正确的姿态是三值的：**YES（有证书的可达） / NO（有负见证的不可达） / UNKNOWN（无证据）**。只有 YES 允许执行；UNKNOWN 触发取证或重规划；NO 必须来自几何穷举或显式负证书，绝不能仅由「图上没边」推出。安全系统必须承认自己的无知，而不是把无知翻译成许可。

**灵感 4（证据搬运的经济学 → 输运半径与最小重见证）**

直觉：如果每个地点都重标定，知识图谱就没有意义；如果无条件相信图谱，安全就没有意义。折中不是拍一个阈值，而是把「搬运」本身计量化：每条边带一个**输运缺陷上界 ρ_e**，搬运后的不确定度膨胀 ρ_e；当累积膨胀仍在预算内，复用是合算的；一旦超出，就必须在最小集合的节点上重新见证（re-witness）。这形成一个可优化的帕累托前沿：证据成本 vs 认证裕度。知识图谱的价值不再是「知道答案」，而是「知道去哪里花最少的钱把答案买回来」。

## 1. 形式化定义（增量：定义 416–429）

**定义 416（锚点知识图谱 A-KG）** 锚点知识图谱 G = (V, E, τ, ξ)，其中：
- V = P ∪ O ∪ S ∪ B：P 为地点/干部署位节点，O 为物体/可供性节点，S 为技能节点，B 为底座构型分箱节点；
- E 为类型化边，关系 rel(e) ∈ {near, supports, same_class, graspable_by, staged_at, compatible_with}；
- 每条边 e 携带证据描述符 ξ(e) = (T_e, ρ_e, q_e, prov_e, t_e, κ_e)：输运算子、输运缺陷上界、可靠度、来源、时间戳、可输运证据类型；
- 关键语义约定：**e 不是真值断言，而是一张「在缺陷 ρ_e 内允许搬运证据」的条件许可证**。

**定义 417（移动—操作计量契约 MOC）** 对任务节点 c = (p, o, s)，其计量契约
EC_c = (D_c, u_base, u_arm, u_obj, χ_base, χ_arm, χ_obj, m_req, α_c)，
其中 D_c ⊆ SE(2)_base × Q_arm × SE(3)_obj 为认证域；u_* 为各源不确定度；χ_* 为反作用通道（轮滑/里程计残差、关节力矩/柔顺残差、物体位姿残差）；m_req 为任务所需净空；α_c 为风险预算。EC_c 有效当且仅当
∀(b,q,o) ∈ D_c：P( m(b,q,o) ≥ 0 ) ≥ 1 − α_c，
其中 m 为带符号净空裕度。

**定义 418（力臂因子与有效不确定度）** 设末端位姿 p_ee = f(b,q)，J_base = ∂p_ee/∂b，J_arm = ∂p_ee/∂q。定义
Λ(c) = sup_{(b,q)∈D_c} ‖J_base(b,q)‖₂。
对平面底座，绕竖直轴的旋转灵敏度范数等于底座到末端的水平距离，故 Λ ≥ ‖p_ee − p_base‖。有效底座不确定度
u_base^eff = sqrt(λ_max(J_base Σ_base J_baseᵀ))。
若某模块只在底座坐标系声明 u_base，而下游按标量相加得到 u_naive = u_base + u_arm + u_obj，则当 Λ > 1 + (u_arm+u_obj)/u_base 时，u_naive < u_eff，认证必然不保守。

**定义 419（MOC 合成与认证裕度）** 给定标称裕度 m_nom(b,q,o) 与置信分位数 k_α，
m_lo(b,q,o) = m_nom(b,q,o) − k_α · sqrt( (u_base^eff)² + (u_arm^eff)² + u_obj² )。
节点 c 的认证裕度 M(c) = inf_{(b,q,o)∈D_c} m_lo(b,q,o)。EC_c 有效 ⇔ M(c) ≥ 0。合成满足单调性：扩大 D_c、增大任一 u_*、或减小 m_req，都只能降低 M(c)，不能提高认证结论。

**定义 420（干部署证书与可认证可达集）** 对物体 o 与技能 s：
CReach(o,s) = { b ∈ SE(2) : ∃(q,o′) 使 (b,q,o′)∈D_c 且 m_lo(b,q,o′) ≥ 0 }。
若存在区间/分支定界证明 B ⊆ CReach(o,s)，则称 B 为**干部署证书** BC_c = (B, proof, α_c)。注意 CReach 是投影集合，不能只对单个 IK 分支认证后取平均；多 IK 分支必须逐一覆盖，否则证书对分支切换不成立。

**定义 421（证据输运算子与输运证书 GTC）** 对边 e = (c → c′)，输运算子 T_e 把源节点证据（标定/契约/残差模型）映射到目标节点。**图输运证书** GTC_e = (T_e, ρ_e, q_e) 表示：
‖ φ_{c′}(x) − (T_e φ_c)(x) ‖_∞ ≤ ρ_e，∀x ∈ D_{c′}，
其中 φ 为契约相关函数（噪声尺度、残差上界、净空修正等）。若源证据在度量 d_c 下为 ε-稠密，则目标在 d_{c′} 下为 (ε + ρ_e)-稠密；认证裕度相应至少扣除 k_α ρ_e。

**定义 422（输运间隙 δ_tr）** 边 e 的输运间隙
δ_tr(e) = sup_{x∈D_{c′}} | φ_{c′}(x) − (T_e φ_c)(x) |。
实际只能得到带 conformal/e-process 上界的估计 δ̂_tr(e) + q_conf。GTC 有效 ⇔ δ̂_tr 的上界 ≤ δ_budget 且 q_e ≥ q_min。δ_tr > 0 是常态而非异常：它计价的是「语义相似但几何不等价」的那一部分。

**定义 423（语义—几何失谐与边可靠度）** 对实际使用过的边 e，收集残差 z_e = φ_{c′}(x) − (T_e φ_c)(x)。在原假设 H₀（边仍满足缺陷 ρ_e）下，z_e 应落在带内。定义失谐分数 Δ_sg(e) 为归一化越界量，并用 anytime-valid e-process 在线检验 H₀。若拒绝，则按序执行：降低 q_e → 膨胀 ρ_e → 隔离该边。该机制用于发现**过期边**（物体被移动、桌面高度改变）与**投毒边**（被恶意写入的错误等价关系）。

**定义 424（三值可达性）** 对给定物体 o、技能 s、底座位姿 b：
R_G(o,s,b) ∈ {YES, NO, UNKNOWN}：
- YES：b ∈ 某干部署证书 B，且从已认证节点到 c 的路径上每条边 GTC 有效、累积膨胀在预算内；
- NO：存在覆盖 D_c 的负见证，使 m_lo 的上界 < 0（几何穷举或显式负证书）；
- UNKNOWN：其余全部情形。
安全规则：**只有 YES 允许执行**；UNKNOWN 触发取证/重规划；NO 禁止。图中缺边只能产生 UNKNOWN，绝不能产生 NO。

**定义 425（图路径契约与路径证书）** 路径 π = (c₀, e₀, c₁, …, e_{k−1}, c_k)。路径证书
PathCert(π) = ( {EC_{c_i}}, {GTC_{e_i}}, Δ_total = Σ ρ_{e_i}, M_path )，
其中 M_path 为按节点顺序合成、扣除累积膨胀后的最坏认证裕度。PathCert 有效 ⇔ 每个 EC 有效 ∧ 每个 GTC 有效 ∧ Δ_total ≤ Δ_budget ∧ M_path ≥ 0（置信度 ≥ 1 − α − Σδ_tr,e）。**合成顺序不可交换**：先搬底座证据再搬操作证据与反向搬运，可能在力臂上得到不同膨胀；证书必须记录实际顺序。

**定义 426（最小重见证集）** 给定一条失效路径 π 与候选见证位置 W（节点或边），求
W* = argmin_{W′⊆W, PathCert(π | W′ 重标定) 有效} cost(W′)。
该问题是加权命中集（weighted hitting set）：每条失效约束至少被一个重见证覆盖。设预算 B_wit；若 cost(W*) > B_wit，则不得伪造证书，转入定义 428 的退化链。

**定义 427（图级契约完整性与五不变式扩展）** 一个部署计划准入当且仅当：
(i) **节点契约完整性**：每个 c 的 EC_c 有效且覆盖实际执行的 (b,q,o)；
(ii) **边输运可靠性**：每条被使用的 e 有有效 GTC，且 ρ_e、q_e 绑定到独立见证；
(iii) **路径合成单调性**：增加节点/边/膨胀只能降低 M_path；
(iv) **来源绑定**：每个证书可追溯到具体见证、时间与观测源，不允许「图上有边」作为唯一来源；
(v) **严格退化链**：任一条件失败只能收缩 D 或拒绝，不得静默扩张认证域。

**定义 428（图级退化链）** 失效时按严格顺序退化：
GTC 失效 → 在最小重见证集上重新标定；预算耗尽 → 只允许直接认证节点（禁用跨地点输运）；仍无 YES → 保守停靠（只依赖第 0 层物理包络）或交还遥操作/拒绝操作。退化是单调的：每一步只能减小可执行集合，不能反向放宽。

**定义 429（REACHGAUGE 总览）** REACHGAUGE = (MODGAUGE, LeanGauge, A-KG, MOC/CGR, GTC/SGA, TWR/WR, Degradation)。当 E = ∅ 时退化为逐地点 LeanGauge；当禁止输运时退化为逐地点重见证；当所有 ρ_e = 0 且图完备时退化为「一次标定全图复用」的理想情形。三类退化都是原系统的严格特例。

## 2. 关键算法骨架

```python
# IP-315 锚点知识图谱：只提供候选与输运许可证，不提供真值
class AnchorKG:
    def candidate_paths(self, obj, skill, base_hint):
        # 返回按 (q_e 降序, Δ_total 升序) 排序的候选路径
        return heapq.nsmallest(K, self._search(obj, skill),
                               key=lambda p: (p.defect, -p.reliability))

    def transport(self, path, evidence):
        ev = evidence
        for e in path.edges:
            ev = e.T(ev)                 # 证据搬运
            ev = inflate(ev, e.rho)      # 按输运缺陷膨胀
        return ev, path.total_defect

# IP-316 移动—操作联合契约认证器：底座不确定度必须过 Jacobian
class MOCCertifier:
    def margin_lower(self, node, b, q, obj_ell):
        Jb, Ja = jacobians(node.model, b, q)
        u_base_eff = sqrt(lambda_max(Jb @ node.Sigma_base @ Jb.T))
        u_arm_eff  = sqrt(lambda_max(Ja @ node.Sigma_arm  @ Ja.T))
        sigma = sqrt(u_base_eff**2 + u_arm_eff**2 + obj_ell.sigma**2)
        return node.m_nom(b, q) - k_alpha(node.alpha) * sigma

    def certify_region(self, node, B):
        # 区间分支定界：b ∈ B, q ∈ IK 分支集, obj ∈ 不确定椭球
        yes, unknown, no = [], [], []
        for cell in branch_and_bound(B, lipschitz=node.L):
            lo = interval_inf(self.margin_lower, cell)   # 下界
            hi = interval_sup(self.margin_lower, cell)   # 上界
            (yes if lo >= 0 else no if hi < 0 else unknown).append(cell)
        return DeploymentCertificate(yes, unknown, no)

# IP-317 可认证可达集：干部署不是「选个近点」，而是求投影集合
class CGRPlanner:
    def reachable_base_regions(self, obj, skill):
        regions = []
        for node in self.kg.nodes_for(obj, skill):
            B = self._star_region(node.place)       # 图谱给候选
            cert = MOCCertifier.certify_region(node, B)
            regions.append((B, cert))
        return regions

# IP-318 图输运证书：多跳必须逐跳累加，不能语义短路
class TransportCertificate:
    def compose(self, path):
        total = 0.0
        for e in path.edges:
            assert e.gtc_valid()                 # 每条边独立有效
            total += e.rho + e.delta_tr_upper
            if total > self.delta_budget:
                return INVALID, total
        return VALID, total

# IP-319 语义—几何失谐审计：发现过期/投毒边
class SemanticGeometricAudit:
    def observe(self, edge, x, phi_true):
        z = phi_true - edge.T(edge.source_phi(x))
        self.e_process[edge].update(z, band=edge.rho)
        if self.e_process[edge].rejected:
            edge.q *= self.downgrade
            edge.rho = inflate(edge.rho, self.sigma_z)
            if edge.q < Q_MIN:
                self.kg.quarantine(edge)

# IP-320 三值规划 + 最小重见证
class ThreeValuedPlanner:
    def plan(self, obj, skill):
        best = None
        for path in self.kg.candidate_paths(obj, skill, self.base_hint):
            cert = TransportCertificate.compose(path)
            if cert is not VALID:
                continue
            regions = CGRPlanner.reachable_base_regions(obj, skill)
            if any(r.status == YES for r in regions):
                best = path
                break
        if best is not None:
            return YES, best
        # 无 YES：求最小重见证集，而不是默认放行
        W = self._failed_constraints(obj, skill)
        W_star = self._greedy_hitting_set(W, budget=B_wit)
        return (UNKNOWN, W_star) if W_star.cost <= B_wit else (NO, "degrade")

# IP-321 REACHGAUGE 主闭环（嵌入 MODGAUGE + LeanGauge）
def REACHGAUGE_round(M, obs, task):
    # 1) 在联合子空间上发现盲区（LeanGauge D-Box 的空间扩展）
    blind = DBox.detect_joint_blind_spots(task, M.kg)
    # 2) 图只给候选；先做输运，再决定是否值得重见证
    plan = ThreeValuedPlanner(M.kg, M.moc).plan(task.obj, task.skill)
    if plan.status == UNKNOWN:
        IBox.sample_at(plan.witness_set)          # 最小重见证
        BPCal.calibrate(plan.witness_set)         # 少样本局部校准
        SGA.audit_edges(plan.witness_set)
        return REACHGAUGE_round(M, obs, task)     # 重新认证
    if plan.status == NO:
        return M.degrade("no_certified_reach")
    # 3) 只有带路径证书的 YES 才进入 MODGAUGE 执行
    return MODGAUGE_round(M, obs, task, path_cert=plan.cert)

## 3. 推导

**引理 46（力臂放大与朴素合成的不保守性）** 设底座不确定度在底座坐标系声明为 Σ_base，末端协方差含项 J_base Σ_base J_baseᵀ。若下游用标量 u_naive = u_base + u_arm + u_obj 代替 u_eff = sqrt(λ_max(J_base Σ_base J_baseᵀ) + …)，则对任意使 Λ > 1 + (u_arm+u_obj)/u_base 的契约，m_lo^naive > m_lo^true，认证不保守。特别地，平面底座绕竖直轴的 Λ 等于底座到末端的水平距离，故「导航精度合格」不能推出「操作精度合格」；底座停靠必须被视为一次计量动作，而不是一次纯运动动作。

**引理 47（输运缺陷的膨胀）** 若源证据在 d_c 下 ε-稠密，且 ‖φ_{c′} − T_e φ_c‖_∞ ≤ ρ_e，则目标证据在 d_{c′} 下 (ε+ρ_e)-稠密，且认证裕度至少下降 k_α ρ_e。证明：对任意目标点 x，取源见证 x′ 使 d_c(x′, T_e^{-1}x) ≤ ε，三角不等式给出 d_{c′}(x, T_e x′) ≤ ε+ρ_e；代入 m_lo 的 Lipschitz 界即得。

**引理 48（多跳输运的非传递性与上界）** 沿路径 e₁…e_k，累积缺陷 ≤ Σ ρ_{e_i}（当输运算子兼容、缺陷可加时取等号上界）；但语义关系的传递性不保证存在一条直接边 e* 使 ρ_{e*} ≤ Σ ρ_{e_i}。定义**输运三角间隙** γ = ρ_{direct} − Σ ρ_{e_i}；当 γ > 0 时，系统必须逐跳累加而不能「语义短路」；当 γ < 0 时，直接边反而更保守。一般情形下多跳膨胀可超线性（算子不兼容时），故规划器只能使用实际路径的累加账本，不能使用图上的最短语义距离。

**引理 49（三值可达性的执行可靠性）** 若规划器只在 R_G = YES 时执行，且 YES 要求 (a) 节点 MOC 的区间下界 m_lo ≥ 0、(b) 路径每条 GTC 有效、(c) 累积膨胀 ≤ Δ_budget，则在 MOC/GTC 假设成立时，不存在被执行却被认证为 NO 或 UNKNOWN 的位姿。证明：按 YES 的三个合取条件分情况，任一失败都会落入 UNKNOWN/NO，而安全规则禁止其执行。

**引理 50（最小重见证的 NP-hard 性与贪心界）** 定义 426 的最小重见证集是加权命中集问题，NP-hard；对单调证书约束，贪心算法达到 (1+ln |W|) 近似。系：在实时规划中不应求精确最优，而应使用「按单位成本边际裕度增益」排序的贪心，并在预算耗尽时严格退化。

**引理 51（开放世界的负证据不可能性）** 对任意有限知识图谱 G 与任意底座位姿 b，总存在一个与 G 一致、但在其中 b 可达的世界（只需令 G 未表示的新物体/新技能存在于该世界）。因此仅凭 G 的拓扑无法认证 NO；任何可靠的 NO 必须来自几何穷举覆盖或显式负见证。系：negation-as-failure 在开放世界移动操作中是不安全的；缺边只能产生 UNKNOWN。

**定理 21（图路径端到端安全）** 若 (a) 所有被使用的 MOC 以 1−α 覆盖其认证域；(b) 所有被使用的 GTC 满足 δ_tr,e ≤ δ_e；(c) 失谐审计对超出界的漂移漏检概率 ≤ ν；则任一被执行的图路径计划，其「未认证碰撞或越界接触」概率 ≤ α + Σ_e δ_e + ν。证明：对节点证书失效、边输运越界、审计漏检三类事件取并集界；路径合成只使用已被证书覆盖的节点与边，故无额外未计量项。

**引理 52（严格退化）** 当 E = ∅ 时，REACHGAUGE 的 PathCert 退化为单节点 EC，算法退化为逐地点 LeanGauge；当设置 ρ_e = ∞ 或禁止输运时，退化为逐地点重见证。两种退化都只能减小可执行集合，故 REACHGAUGE 是 LeanGauge 的安全增强而非替代。

## 6. 本轮最大风险

**一句话**：REACHGAUGE 的核心假设是「知识图谱的每条输运边都能给出可信的缺陷上界 ρ_e，且力臂 Jacobian 有界」——但 ρ_e 是从有限见证估计出来的，移动操作的力臂会把任何未建模的形变（桌面高度差、轮子打滑、物体质心偏移、多跳语义累积）放大到净空尺度；一旦一条过期或被投毒的「语义等价边」在预算内通过审计，系统就会**带着完整路径证书、自信地执行一个物理上不可达或高接触力的抓取**——这既是 LeanGauge「自信地组合错误世界」的图论版本，也是移动操作把认知误差转成机械伤害的最短路径。

次级风险与缓解：
1. **ρ_e 被低估** → 强制独立见证 + conformal 上界 + 保守膨胀；无边见证时 ρ_e=∞（禁止输运）。
2. **Jacobian/力臂模型误差** → 区间 Jacobian 包络；在线用关节力矩与视觉残差校验 Λ。
3. **多跳累积被语义短路** → 路径账本逐跳累加；优先直接边；枢纽节点强制重见证；禁止用最短语义距离替代输运距离。
4. **图谱投毒/过期** → 来源溯源、anytime-valid e-process、独立来源根、隔离与回滚；高价值边要求双源见证。
5. **开放世界新物体被误判 NO** → 缺边只产生 UNKNOWN；NO 必须附几何负见证；新物体默认取证而非默认放行。
6. **CGR 过保守导致不可用** → 分支定界收紧 + LeanGauge 主动采样；在干部署空间上做主动学习而非全网格。
7. **IK 多分支漏认证** → 逐分支认证，禁止对分支取平均；分支切换视为新契约。
8. **审计循环性（同一证据既标定又审计）** → 留出独立见证；跨地点交叉审计；审计集轮换。
9. **实时性** → anytime 证书 + 预计算安全区域缓存；预算耗尽即退化。
10. **仿真到现实** → 第 0 层物理包络（力/能量/速度）作为最后地板；证书失效时物理 stub 接管。

## 2. 形式化定义（要点）

**定义 416（A-KG）** 边不是真值断言，而是「在缺陷 ρ_e 内允许搬运证据」的条件许可证；每条边必须携带来源、时间、可靠度、可输运证据类型。

**定义 417（MOC）** `EC_c = (D_c, u_base, u_arm, u_obj, χ_base, χ_arm, χ_obj, m_req, α_c)`，认证目标为
`∀(b,q,o)∈D_c : P(m(b,q,o) ≥ 0) ≥ 1−α_c`。

**定义 418（力臂因子）** `Λ(c)=sup‖J_base(b,q)‖₂`，`u_base^eff=sqrt(λ_max(J_base Σ_base J_baseᵀ))`。平面底座绕竖直轴的力臂等于底座到末端水平距离。

**定义 419（MOC 合成）** `m_lo = m_nom − k_α·sqrt((u_base^eff)²+(u_arm^eff)²+u_obj²)`，`M(c)=inf_{D_c} m_lo`；`EC_c` 有效 ⇔ `M(c)≥0`。

**定义 420（干部署证书）** `CReach(o,s)={b : ∃(q,o′), m_lo(b,q,o′)≥0}`；区间证明 `B⊆CReach` 才发证；多 IK 分支必须逐一认证。

**定义 421（GTC）** `‖φ_{c′} − T_e φ_c‖∞ ≤ ρ_e`；源 ε-稠密 ⇒ 目标 (ε+ρ_e)-稠密，认证裕度扣 `k_α ρ_e`。

**定义 422（输运间隙）** `δ_tr(e)=sup|φ_{c′}−(T_eφ_c)|`；用 conformal/e-process 上界判定 `δ_tr ≤ δ_budget`。

**定义 423（SGA）** 用实际残差 `z_e` 在线检验边的 H₀；拒绝后按 `q_e↓ → ρ_e↑ → 隔离` 顺序处置。

**定义 424（三值可达性）** YES = 干部署证书 + 有效 GTC 路径；NO = 几何负见证；UNKNOWN = 其余。**只有 YES 可执行；缺边只产生 UNKNOWN。**

**定义 425（路径证书）** `PathCert(π)=({EC},{GTC}, Δ_total=Σρ_e, M_path)`；有效 ⇔ 节点/边均有效 ∧ `Δ_total≤Δ_budget` ∧ `M_path≥0`。合成顺序不可交换。

**定义 426（最小重见证）** `W* = argmin cost(W′)`，s.t. 重标定后路径有效；等价于加权命中集，NP-hard。

**定义 427（图级五不变式）** 节点契约完整性、边输运可靠性、路径合成单调性、来源绑定、严格退化链。

**定义 428（退化链）** GTC 失效 → 最小重见证 → 仅直接认证节点 → 保守停靠/遥操作/拒绝；每步只能收缩可执行集合。

**定义 429（总览）** `REACHGAUGE=(MODGAUGE,LeanGauge,A-KG,MOC/CGR,GTC/SGA,TWR/WR,Degradation)`；`E=∅` 退化为 LeanGauge。

                               key=lambda p: (p.defect, -p.reliability))

# IP-316 MOC：底座不确定度必须过 Jacobian
class MOCCertifier:
    def margin_lower(self, node, b, q, obj_ell):
        Jb, Ja = jacobians(node.model, b, q)
        u_base_eff = sqrt(lambda_max(Jb @ node.Sigma_base @ Jb.T))
        u_arm_eff  = sqrt(lambda_max(Ja @ node.Sigma_arm  @ Ja.T))
        sigma = sqrt(u_base_eff**2 + u_arm_eff**2 + obj_ell.sigma**2)
        return node.m_nom(b, q) - k_alpha(node.alpha) * sigma

    def certify_region(self, node, B):
        yes, unknown, no = [], [], []
        for cell in branch_and_bound(B, lipschitz=node.L):
            lo, hi = interval_bounds(self.margin_lower, cell)
            (yes if lo >= 0 else no if hi < 0 else unknown).append(cell)
        return DeploymentCertificate(yes, unknown, no)

        BPCal.calibrate(plan.witness_set)
        SGA.audit_edges(plan.witness_set)
        return REACHGAUGE_round(M, obs, task)
    if plan.status == NO:
        return M.degrade("no_certified_reach")
    return MODGAUGE_round(M, obs, task, path_cert=plan.cert)
```

## 4. 推导

**引理 46（力臂放大）** 朴素标量合成 `u_naive=u_base+u_arm+u_obj` 在 `Λ>1+(u_arm+u_obj)/u_base` 时高估裕度，认证不保守。平面底座旋转力臂 = 底座到末端水平距离；导航精度合格 ⇏ 操作精度合格。

**引理 47（输运膨胀）** 源 ε-稠密 + 缺陷 ρ_e ⇒ 目标 (ε+ρ_e)-稠密，认证裕度至少下降 `k_α ρ_e`。

**引理 48（多跳非传递性）** 路径累积缺陷 `≤Σρ_e`；语义传递不保证存在直接边 `ρ_{e*}≤Σρ_e`。输运三角间隙 `γ=ρ_direct−Σρ_e`；规划必须使用实际路径账本。

**引理 49（三值可靠性）** 只在 YES 执行且 YES 要求区间下界 + 有效 GTC + 预算内，则不会执行 NO/UNKNOWN 位姿。

**引理 50（最小重见证）** 加权命中集，NP-hard；单调约束下贪心 `(1+ln|W|)` 近似。

**引理 51（开放世界负证据不可能性）** 有限图无法证明 NO；可靠 NO 必须来自几何穷举或显式负见证。缺边只能产生 UNKNOWN。

**定理 21（图路径端到端安全）** 若节点 MOC 覆盖 ≥1−α、每条 GTC 满足 `δ_tr≤δ_e`、SGA 漏检 ≤ν，则执行计划未认证碰撞/越界概率 `≤ α+Σδ_e+ν`。

**引理 52（严格退化）** `E=∅` ⇒ 逐地点 LeanGauge；禁止输运 ⇒ 逐地点重见证；安全可执行集合只减不增。

## 7. 本轮最大风险

**一句话**：REACHGAUGE 依赖「每条输运边能给出可信的缺陷上界 ρ_e 且力臂 Jacobian 有界」，但 ρ_e 由有限见证估计，力臂会放大任何未建模形变（桌面高度差、轮滑、质心偏移、多跳语义累积）；一旦过期或被投毒的等价边在预算内通过审计，系统就会**带着完整路径证书自信地执行物理上不可达或高接触力的抓取**——这是 LeanGauge「自信地组合错误世界」的图论版本，也是移动操作把认知误差转成机械伤害的最短路径。
