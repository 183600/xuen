# 第 70 轮（承接第 69 轮「FLUID-RAS」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「零样本泛化」×「智能体」）

> R69 把不确定性拆成 **aleatoric / epistemic**，并教会系统「问」。但它有一个从未言明的前提：**正确答案已经在我抽出的那个模态集合里**，只是权重不明。这是**闭世界假设（closed-world）**。真实的零样本场景恰恰违反它——机器人第一次见到透明杯子、第一次听到「把那个会发光的东西递给我」、第一次踩上没见过的地面材质时，正确的动作模态**根本不在 π_θ 的支持集里**。此时 R69 的 VoI 是在一个不完整的候选集上计算的：它会把「最能区分两个错误模态」的动作当成最优；交互后后验熵下降、信心上升，却离真相更远。**R69 最危险的失败不是不知道，而是不知道自己不在图上。**
>
> 本轮两个灵感正好补上这块：
> - **零样本泛化**提醒我们，真正的未知不是「在选项之间选哪个」，而是「选项集本身是错的」（support gap / novelty）；而泛化既不该靠实时适应（违反 R68/R69 的实时流零学习不变式），也不该靠一句「相信大模型能泛化」——它应来自**组合**：用已经认证过的技能，拼出一个任务级上从未执行过的新解。
> - **智能体**提供了这个组合器：技能库、能力契约、情景记忆、工具调用、委托升级，以及最重要的——**知道何时不该自己动手**的弃权能力。智能体的强项不是「更强的策略」，而是**在能力边界上诚实**：能拼就拼，不能拼就委托，再不能就弃权，而不是幻觉一个计划一路执行到底。
>
> 核心命题：**在 R69 的 (U_ale, U_epi) 之外显式引入第三种不确定性 U_nov（决策相关新颖性 / 支持缺口）；先做支持测试，只有落在已认证能力支持内才允许走 R69 的 VoI 交互；落在支持外则进入「组合—委托—弃权」三级协议，用技能契约的组合（而非实时学习）实现零样本，且组合的每一步都过 R69 的认证与分界屏蔽。** 命名 **NOVA-RAS**（Novelty-aware Open-world Verified Agent risk-adaptive system）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量准吗」，R69 问「我该向谁求证」，R70 问「**我根本不在图上吗——能不能用手里的积木拼出一条没走过的安全路？**」

## 0. 直觉与动机

**灵感 1（零样本泛化 → 未知有两层，R69 只解决了第一层）**
直觉：不确定有两种完全不同的形状。第一种是「我知道有左和右两条路，但不知道哪条对」——这是 R69 的 epistemic 歧义，问一句、看一眼就能消解。第二种是「我连『有第三条路』都不知道」——真实解不在候选集里。前者是**假设之间的不确定**，后者是**假设集合本身的不确定**。R69 的所有机制（流匹配采样、模态聚类、VoI）都定义在后者为假的前提下。零样本泛化的本质，就是直面第二种未知：**当训练分布没有覆盖当前任务时，系统还能不能给出一个可被认证的解？**

**灵感 2（智能体 → 泛化不靠适应，靠组合与升级）**
直觉：一个熟练的智能体遇到没做过的事，不是「当场重训自己」，而是拆解——这件事像不像我做过的 A？能不能用 B 的工具达到 C 的效果？能不能问一个更懂的人？这正是零样本的工程形态：**任务级新颖，技能级已知**。把「技能」当作积木，把它们的**前置条件、后置条件、能力域、安全包络、成本、失败签名**写成契约，泛化就变成在技能图上找一条契约可串、包络可交、能力域可覆盖的路径。智能体负责提议与搜索，认证层负责否决——**LLM 提议，验证器裁决**。

**灵感 3（三分解 → R69 是 U_nov = 0 的边界）**
直觉：把不确定性写成三项：U_ale（噪声，问不出）、U_epi（歧义，可问出）、U_nov（新颖，问不出但可以拼/委托/弃权）。R69 的整个闭环，是 U_nov = 0 时的特例；正如 R68 是 R69「永不交互」时的特例。这是本轮的理论姿态：**每一层新能力都必须把旧层包含为边界情形，否则每加一层就多一个需要独立信任的黑箱**。于是风险单调性可以沿着 R68 ⊂ R69 ⊂ R70 这条链传递。

**灵感 4（快慢双系统 → 保住实时零学习不变式）**
直觉：零样本听起来像「在线学习」，而在线学习会打破 R68 立下的「实时流零学习写操作」。其实不必：把系统分成两个时间尺度——**慢系统（智能体/规划器）**离线或低频地获取、认证、晋升新技能；**快系统（R69 闭环）**实时地只做「已认证技能的只读组合与执行」。新技能在进入技能库前必须过校准、红队、金丝雀；实时回路里技能库是**只读**的。这样「零样本」= 组合已认证积木，而不是「在控制回路里边跑边学」。智能体的记忆也只作为**提议与证据**，绝不是策略的写入通道。

**灵感 5（智能体的新风险 → 组合会把单点谎言放大成整条计划）**
直觉：R69 的风险是「问错，比不问更危险」。R70 的风险更大：一旦技能契约是错的（能力域被高估、示范被投毒、后置条件被漏写），智能体会用一条**看起来严密**的组合证明把错误技能串成一条完整计划，并因为「每一步都认证过」而放心执行到底。**单技能的标定误差，会被组合沿时间轴累加、被契约的传递性掩盖、被 LLM 的流畅叙事合法化。** 所以本轮必须同时交付：契约代数（组合可证性）、异构验证团（防相关失败）、分界屏蔽与回滚（防误差累积）、校准弃权（防「被证实的错误」）、以及责任账本（可归因审计）。否则 NOVA-RAS 只是给 R69 的嘴巴配了一双会自己编故事的手。

## 1. 形式化定义（增量：定义 310–324）

**定义 310（NOVA-RAS 总览与四不变式）** NOVA-RAS = (SCC, CRT, CZP, NEP, HVP, BSH, SPL, MEM-E, VQAuditor-N, RAS-WM†)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i；技能库在实时回路中只读、带版本号）；
(ii) **支持先于消歧**：任何 VoI 交互之前必须先过支持测试（定义 313）；U_nov > 0 时禁用 R69 的 VoI 决策，只允许组合/委托/弃权；
(iii) **组合只认契约**：进入执行的计划必须通过契约代数（定义 315）的可证性检查，未证不可执行；
(iv) **弃权是一等输出**：无法认证时输出集合值「我不知道 / 我还需要什么」，而非强行给一个点动作；弃权必须可审计、可回灌。

**定义 311（技能契约与能力域 SCC）** 技能 σ = (Pre_σ, Post_σ, C_σ, Env_σ, cost_σ, fail_σ, cert_σ)，其中 Pre_σ, Post_σ 是前置/后置断言（状态谓词），C_σ ⊆ 𝒵 是该技能被认证过的**能力域**（representation 空间区域），Env_σ 是安全包络，cost_σ 是时间/能量/社交成本，fail_σ 是失败签名，cert_σ 是其校准证书。技能库 Σ = {σ_i} 带只读版本号 ν_Σ。

**定义 312（决策相关新颖性 U_nov / 支持缺口）** 给定情境 z_t 与任务 τ，令 Π_cert(z_t, τ) 为满足定义 315 的认证计划集合。定义
U_nov(z_t, τ) = 0 if Π_cert ≠ ∅，否则 U_nov = dist(z_t, Pre(Π_cert)) / δ_norm ∈ (0,1]，
即「到最近认证计划前置条件集的距离」。**关键：U_nov 不是原始输入 OOD，而是「我有没有一条被认证过的路」**。输入再怪，只要落在某认证技能的能力域内，U_nov = 0；输入再熟，只要任务要求的组合无契约支撑，U_nov > 0。

**定义 313（支持测试 CRT）** 支持测试依次回答三个问题：(a) z_t 是否落在某技能能力域 C_σ 内（ANN 距离 + 校准半径）；(b) 是否存在契约可串的技能链覆盖任务子目标；(c) 链上每步的预测后置状态是否落在下一步能力域的置信半径内。任一为否 ⇒ U_nov > 0，转入定义 316 的新颖性协议。支持测试是 R69 FMA（定义 301）的上游：FMA 说「哪里不对」，CRT 说「不对，但我还有没有可证的路」。

**定义 314（组合零样本规划器 CZP）** 智能体在技能图 G_Σ 上搜索计划 γ = (σ_1, …, σ_n)。LLM 冻结、只提议计划骨架与技能检索查询（不回传梯度）；候选计划必须被定义 315 的验证器接受。搜索目标：最大化认证覆盖、最小化成本与风险，而非最大化 LLM 似然。CZP 运行在**慢通道**（航点/边界处或 U_nov 触发时），不在实时控制节拍内。

**定义 315（契约代数与组合可证性）** 计划 γ=(σ_1,…,σ_n) 相对当前状态 s_0 是**可证零样本**的，当且仅当存在中间断言 s_1,…,s_n 使：
(a) **前置链**：s_0 ⊨ Pre_{σ1}，且 s_i ⊨ Post_{σi} ⇒ s_i ⊨ Pre_{σi+1}；
(b) **能力链**：s_{i-1} ∈ C_{σi}，且 Post_{σi} 的置信半径 ⊆ C_{σi+1}；
(c) **包络链**：Env_{σ1} ∩ … ∩ Env_{σn} ∩ Safe ≠ ∅，且组合后的不变式未被任何 σ 破坏；
(d) **预算链**：Σ cost_σ ≤ 任务预算。
记 Π_cert = {γ : (a)–(d)}。注意：**契约可串是逐边的局部证明，组合安全性仍需定义 319 的分界屏蔽在运行时兜底**——局部证明不能自动提升为全局保证。

**定义 316（新颖性协议 NEP：组合 / 委托 / 弃权）** U_nov > 0 时按安全约束下的优先级执行：
1. **组合（Compose）**：若存在 γ ∈ Π_cert，则在 BSH 下执行；
2. **委托（Delegate）**：若组合不存在，但存在通信通道，且 VoI_delegate − cost_delegate > 0（值不值得问一个更有能力的智能体/人），则发出**能力请求**（不是答案请求），且对方回复必须携带其证书，按 R69 的 k 正交证据纪律处理，单源不立；
3. **弃权（Abstain）**：以上都不成立（或超时/不可信/被投毒），输出集合值 A(z_t) ⊆ 𝒜 ∪ {⊥}，进入 R68 安全保持，并把缺口写入技能缺口账本，驱动离线获取。
优先级可由安全约束重排：例如无委托通道或风险过高时，委托直接跳过，弃权优先。

**定义 317（校准弃权 CAL-A）** 弃权输出为集合值动作 A(z)（含「需要什么」的描述），定义覆盖率 cov(A) = P(a* ∈ A) 与选择性风险 risk(A) = E[ℓ | a* ∈ A]。要求在目标覆盖率 1−α 下最小化选择性风险，并校准「我是否需要弃权」的门槛；弃权不是系统故障，而是**诚实的、可度量的输出**。安全侧：弃权动作本身必须落在 Safe 包络内（安全保持），不得因「不动」而违反时间窗约束。

**定义 318（异构验证团 HVP 与去相关）** 验证团 V = {V_1,…,V_k}，成员必须在**结构上不同**：世界模型回放、形式化契约检查、情景记忆最近邻结果、外部智能体/人的证书。成员两两失败相关系数 ρ < 1；要求多数一致才接受计划。**同源 LLM 自评不计入 k**（ρ≈1，等于没加）。这是 R69 引理 18「k 正交证据源」在计划层的推广。

**定义 319（分界屏蔽与回滚 BSH）** 执行计划 γ 时，在每个技能边界 b_i 检查：实际状态 s_i 是否落在 Post_σ 的容差内、是否仍在下一技能能力域与安全包络内。任一失败 ⇒ **回滚/回溯**到最近一个认证状态，并降级为弃权或重规划。屏蔽是运行时对契约局部证明的补偿：契约证明「应当安全」，屏蔽保证「确实安全」。

**定义 320（离线技能获取与晋升门 SPL）** 新技能来自示范、自博弈或工具封装，必须依次通过：(i) 能力域估计与校准（ECE 门）；(ii) ℰ_skill 红队（示范投毒、契约走私、过乐观能力域）；(iii) 金丝雀影子部署；(iv) 签名并带证书入 Σ。**晋升只在离线/慢通道发生，实时回路永远只读 Σ**——这是零样本与 R68 不变式的接口。

**定义 321（情景记忆作为证据 MEM-E）** 记忆 M 存储 (z, γ, outcome, cert, verifier_votes)。记忆用于：(a) 给 CZP 提供提议与检索先验；(b) 作为 HVP 的一票「最近邻结果」。记忆**不得单独认证**计划（ℰ_mem：记忆投毒），只提供似然。

**定义 322（责任账本与可归因审计 VQAuditor-N）** 每次决策记录：任务、z_t、U_nov、所选 γ 与契约链、HVP 每个成员的身份与票、弃权/委托的原因、技能库版本、记忆检索哈希、责任 ID。审计对象从「一次动作」升级为「一条决策链」，使组合错误可定位到具体契约边与验证器。

**定义 323（证书 J_NOVA）** J_NOVA = (J_FLUID, U_nov, coverage(K(z)), plan_proof_hash, verifier_panel_ids_votes_rho, abstention_flag, skill_lib_version, memory_hash, responsibility_id, nova_ver)。Valid ⇔ Valid(J_FLUID) ∧ 契约链可证 ∧ HVP 多数一致（或合法弃权）∧ 预算未越界 ∧ 账本完整。

**定义 324（威胁模型 ℰ_NOVA）** ℰ_NOVA = ℰ_FLUID × ℰ_agent × ℰ_skill，其中
ℰ_agent = {幻觉计划、错误工具/参数、由工具输出触发的提示注入、验证器共谋、责任扩散（「是那个子智能体决定的」）}；
ℰ_skill = {示范投毒、过乐观能力域、契约走私（漏写后置/包络）、后置条件外推越界}；
ℰ_mem = {记忆投毒、检索诱饵}。
三者并入 AIC-NOVA，用于对抗训练与红队。

```python
# IP-264 NOVA-RAS 主闭环：支持先于消歧；实时只做只读组合与执行
def NOVA_RAS_round(M, obs, task):
    z, o = M.mtm.forward(...)                        # R68/R69 一次前向
    c, U_cal, thr = M.cof.step(...)                  # R68 标定
    # 1) 支持测试：我到底在不在图上？（定义 312–313）
    plan = M.crt.find_certified_plan(z, task, M.skill_lib)   # ANN + 契约图缓存
    U_nov = 0.0 if plan is not None else M.crt.novelty(z, task)
    if U_nov > 0:
        return M.nep.novelty_protocol(z, task, o, M)         # 组合/委托/弃权
    # 2) 在已认证支持内：完全退回 R69 的 FLUID 闭环（逐指令一致）
    return M.fluid.round(o, task)                    # R69 定义 293–309

# IP-267 CZP：组合零样本规划（慢通道，一次搜索，缓存结果）
def plan_compose(z, task, skill_lib):
    skeleton = frozen_llm.propose(task)              # 只提议，不裁决
    best = None
    for gamma in graph_search(skill_lib, skeleton):  # 契约图上的候选链
        if not contract_chain_ok(gamma, z): continue # 定义 315 (a)–(d)
        if not hvp.majority_accept(gamma, z): continue# 定义 318
        score = certified_coverage(gamma) - cost(gamma) - risk(gamma)
        if best is None or score > best.score: best = gamma
    return best                                      # None ⇒ 交给 NEP

# IP-268 契约代数：组合可证性（逐边 + 预算）
def contract_chain_ok(gamma, s0):
    s = s0
    for sigma in gamma:
        if not entails(s, sigma.Pre):                 return False
        if not in_competence(s, sigma.C):             return False
        if not envelopes_intersect(gamma, safe_set):  return False
        s = predict_post(sigma, s)                    # 带置信半径
    return total_cost(gamma) <= budget

# IP-269 NEP：组合 → 委托 → 弃权（安全约束可重排）
def novelty_protocol(z, task, o, M):
    gamma = M.czp.plan(z, task)
    if gamma is not None:
        return M.bsh.execute(gamma, z, o)             # 分界屏蔽下执行
    if M.channel.ok() and M.nep.delegate_voi(z, task) > 0:
        reply = M.nep.delegate(z, task)               # 要「能力/计划」，不只要答案
        if M.hvp.accept_external(reply, z):           # 必须带证书
            return M.bsh.execute(reply.plan, z, o)
    return M.cal_a.abstain(z, task)                   # 集合值：我不知道 / 我还需要 X

# IP-272 BSH：分界屏蔽 + 回滚（运行时补偿契约证明）
def execute(gamma, z, o):
    for sigma in gamma:
        if not shield_ok(z, sigma):                   # 边界检查
            z = rollback_to_last_certified()
            return abstain_or_replan(z, sigma)
        z, o = run_skill(sigma, z, o)
        if not post_ok(z, sigma):                     # 后置条件越界
            return rollback_to_last_certified()
    return z

# IP-270 CAL-A：校准弃权（覆盖率-选择性风险）
def abstain(z, task):
    A = self.candidate_set(z, task, alpha=self.alpha) # 目标覆盖率 1-alpha
    assert self.safe_hold_ok(A)                       # 弃权本身必须安全
    self.ledger.log(z, task, A, reason='uncertified_novelty')
    return A, 'abstain'

# IP-271 HVP：异构验证团（去相关）
def majority_accept(plan, z):
    votes = [v.check(plan, z) for v in self.members]  # WM / 契约 / 记忆 / 外部证书
    return sum(votes) >= self.quorum and self.rho_est < RHO_MAX
```

## 3. 推导

**引理 19（支持缺口的 VoI 盲区）** 设真实解 m* 不在策略/计划可达集 𝒮_rep 内。则对任意信息动作 g，I(m*; Y | g, o) = 0，因为证据只在 𝒮_rep 内部产生判别；而 R69 在 𝒮_rep 上计算的 VoI 仍可 > 0，并会把交互预算花在区分两个「都不对」的模态上。系：**U_nov > 0 时，R69 的 VoI 不仅是零收益，而且会系统性放大自信**（后验熵下降但后验支撑错误）——必须先做支持测试，再谈消歧。

**引理 20（契约组合的可靠性）** 若 γ 满足定义 315 的 (a)–(d)，且每个 σ 的 Post 断言在其能力域内被认证，则沿 γ 执行时，在无外部扰动、预测误差不超过契约容差的条件下，状态始终落在 ⋃_i Env_σi ∩ Safe 内。证明：对技能边界归纳；每步 Pre 由前步 Post 蕴含，能力域由置信半径覆盖，包络交集非空。系：**组合可证性把「零样本」从「相信泛化」降为「逐边可查」**；误差随步数最多线性累加 Σ ε_σ，且被 BSH 在边界截断。

**引理 21（弃权的支配性）** 设 U_nov > 0 且不存在认证计划，强行行动采用幻觉计划的概率为 p_h，其代价 C_h；弃权代价为 C_a（含机会成本与安全保持成本）。若 p_h ≥ C_a / C_h，则校准弃权的期望代价不高于强行行动；且覆盖率-选择性风险曲线在弃权门槛处单调。系：**弃权不是失败，而是在信息不足时对期望风险的支配性选择**；它把 R69 的「被证实的错误」还原为「诚实的不知道」。

**定理 18（严格包含链 R68 ⊂ R69 ⊂ R70）** 在 A95–A99 下：
(i) 当 z_t 落在认证能力支持内且存在契约计划时，NOVA 逐指令等于 FLUID（定义 313 后直接调用 R69 闭环），故 R69 是 NOVA 在 U_nov = 0 边界上的退化；
(ii) 当 FLUID 的 VoI ≤ 成本、ECE 越界或 slow_fault_suspect 时，FLUID 逐指令退化为 R68；
(iii) 当 U_nov > 0 时，NOVA 只在原动作集之外**新增**组合/委托/弃权三个选项，从不移除 R69 已有的认证动作，故期望风险单调不增；在最坏情形下弃权落到 R68 安全保持，风险不回退。
因此 R68、R69 是 R70 的两级边界情形；安全侧不做任何让步。**严格性**：在存在支持缺口且 R69 必然自信选错模态的状态上，R70 的弃权/组合严格降低最坏情形损失。

**定理 19（分界屏蔽与无突变）** 在 BSH 每个技能边界检查、失败即回滚到最近认证状态的条件下，组合执行不会越出安全包络；任何一次边界失败都触发单调降级（组合 → 弃权/安全保持），控制量在切换点连续（继承 R68 定理 15 的换装不变式），且回滚距离 ≤ 契约容差 ε_σ。系：局部契约证明 + 运行时屏蔽 = 全局安全；**证明负责「本来应该对」，屏蔽负责「确实对」**。

**定理 20（异构验证的漏检上界）** 设 k 个结构异构验证器各自的漏检率为 ε_v、两两失败相关系数为 ρ<1，多数票漏检率 ≤ ε_v·ρ^{k−1} + ε_σ。当 ρ=1（同源 LLM 自评）时退化为 ε_v，**增加同源验证器数量不带来任何安全性**。系：智能体验证的关键不是「多问几个模型」，而是「问结构和失效模式不同的东西」（世界模型 vs 契约检查 vs 记忆 vs 外部证书）。

## 6. 本轮最大风险

**一句话**：NOVA-RAS 的安全性最终押在「技能契约与能力域估计是诚实的」这一前提上——一旦能力域被高估（离线标定过乐观、示范投毒、或 OOD 下能力域被外推），智能体会用一条**看起来严密**的契约链把从未真正验证过的组合认证为「可证零样本」，于是**组合把单个技能契约的谎言放大成一条完整计划的系统性错误**：它比 R69 的「问错」更危险，因为它会一路执行到底，且每一步都盖着「已认证」的章。

**次级风险与缓解**：
1. **能力域外推（新颖性伪装成已知）** → 能力域带校准半径 + 过乐观惩罚 + E310 晋升门，越界即 U_nov 抬升；
2. **契约走私 / 后置条件漏写** → 定义 315 强制四链检查 + BSH 运行时兜底（定理 19），契约本身纳入红队；
3. **验证器相关失败（同源自评）** → 定义 318 要求结构异构 + 估计 ρ，定理 20 给出 ρ<1 才增益；
4. **组合误差沿时间累加** → 分界屏蔽截断 + 回滚 + 线性容差预算，禁止无界链；
5. **责任扩散 / 审计断链** → 定义 322 责任账本 + VQAuditor-N，把「谁批准的这条链」写进证书；
6. **弃权滥用（消极怠工）** → 引理 21 的覆盖率-风险约束 + E305 上限，弃权率纳入审计。

```python
        if not entails(s, sigma.Pre):                return False
        if not in_competence(s, sigma.C):            return False
        if not envelopes_intersect(gamma, safe_set): return False
        s = predict_post(sigma, s)                   # 带置信半径
    return total_cost(gamma) <= budget

# IP-269 NEP：组合 → 委托 → 弃权（安全可重排）
def novelty_protocol(z, task, o, M):
    gamma = M.czp.plan(z, task)
    if gamma is not None: return M.bsh.execute(gamma, z, o)
    if M.channel.ok() and M.nep.delegate_voi(z, task) > 0:
        reply = M.nep.delegate(z, task)                       # 要能力/计划，不只答案
        if M.hvp.accept_external(reply, z):                   # 必须带证书
            return M.bsh.execute(reply.plan, z, o)
    return M.cal_a.abstain(z, task)                           # 集合值输出

# IP-272 BSH：分界屏蔽 + 回滚
def execute(gamma, z, o):
    for sigma in gamma:
        if not shield_ok(z, sigma): return rollback_or_abstain(z, sigma)
        z, o = run_skill(sigma, z, o)
        if not post_ok(z, sigma):   return rollback_to_last_certified()
    return z

# IP-270 CAL-A：校准弃权
def abstain(z, task):
    A = self.candidate_set(z, task, alpha=self.alpha)         # 目标覆盖率 1-alpha
    assert self.safe_hold_ok(A)                               # 弃权本身必须安全
    self.ledger.log(z, task, A, reason='uncertified_novelty')
    return A, 'abstain'

# IP-271 HVP：结构异构多数票
def majority_accept(plan, z):
    votes = [v.check(plan, z) for v in self.members]          # WM/契约/记忆/外部证书
    return sum(votes) >= self.quorum and self.rho_est < RHO_MAX
```

## 4. 推导

**引理 19（支持缺口的 VoI 盲区）** 若真实解 m* ∉ 策略/计划可达集 𝒮_rep，则 ∀g：`I(m*; Y|g,o)=0`——证据只在 𝒮_rep 内产生判别。R69 在 𝒮_rep 上算出的 VoI 仍可 >0，于是把预算花在区分两个「都不对」的模态上，**后验熵下降但正确率下降**。系：U_nov>0 时必须先支持测试，再谈消歧。

**引理 20（契约组合的可靠性）** γ 满足定义 315 (a)–(d) 且各 σ 在其能力域内被认证，则在预测误差 ≤ 契约容差、无外部扰动下，沿 γ 的状态始终落在 `⋃Env_σ ∩ Safe` 内（对边界归纳）。误差至多线性累加 `Σ ε_σ`，并被 BSH 边界截断。系：零样本从「相信泛化」降为「逐边可查」。

**引理 21（弃权的支配性）** U_nov>0 且无认证计划时，设幻觉计划概率 p_h、代价 C_h，弃权代价 C_a；若 `p_h ≥ C_a/C_h`，弃权期望代价 ≤ 强行行动；覆盖率-选择性风险在门槛处单调。系：弃权把 R69 的「被证实的错误」还原为「诚实的不知道」。

**定理 18（严格包含链 R68 ⊂ R69 ⊂ R70）** (i) U_nov=0 且存在 Π_cert 时，NOVA 逐指令等于 FLUID；(ii) FLUID 在其 VoI≤成本/ECE 越界/slow_fault 边界逐指令退化为 R68；(iii) U_nov>0 时 NOVA 仅在原动作集外**新增**组合/委托/弃权，从不移除认证动作，期望风险单调不增，最坏落回 R68 安全保持。故 R68、R69 是 R70 的两级边界情形；在支持缺口状态上，R70 严格降低最坏情形损失。

**定理 19（分界屏蔽与无突变）** BSH 每边界检查、失败回滚最近认证状态 ⇒ 不越出安全包络；失败触发单调降级（组合 → 弃权/安全保持），切换点连续（继承 R68 定理 15 换装不变式），回滚距离 ≤ ε_σ。系：**契约证明负责「本来应该对」，BSH 负责「确实对」**。

**定理 20（异构验证的漏检上界）** k 个结构异构验证器、单体检漏率 ε_v、两两相关 ρ<1，多数票漏检 ≤ `ε_v·ρ^{k−1}+ε_σ`。ρ=1（同源 LLM 自评）时退化为 ε_v：**增加同源模型数量不带来任何安全性**。系：关键是「问结构不同的东西」，不是「多问几个」。

## 7. 本轮最大风险

**一句话**：NOVA-RAS 的安全性最终押在「技能契约与能力域估计是诚实的」这一前提上——一旦能力域被高估（离线标定过乐观、示范投毒、OOD 外推），智能体会用一条**看起来严密**的契约链把从未验证过的组合认证为「可证零样本」，于是**组合把单个技能契约的谎言放大成一条完整计划的系统性错误**；它比 R69 的「问错」更危险，因为它会一路执行到底，且每一步都盖着「已认证」的章。

**次级风险与缓解**：能力域外推（校准半径 + 过乐观惩罚 + E310）；契约走私/后置漏写（四链检查 + BSH 兜底 + 契约红队）；验证器相关失败（结构异构 + 估 ρ，定理 20）；组合误差累加（边界截断 + 回滚 + 线性容差预算，禁止无界链）；责任扩散（责任账本 + VQAuditor-N）；弃权滥用（覆盖率-风险约束 + E305 上限 + 弃权率入审计）。
