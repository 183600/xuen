# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧闭环」IP-253~263；本轮灵感：「续航能力」×「动力学」）

> R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」。这四层越做越精细，却共享一个从未被审视的隐含假设：**资源是免费的、未来是无限的**。每一层都在优化「当前这一步」——当前控制权限、当前预测、当前标定、当前该不该问——默认能量、时间、安全余量、信任额度取之不尽。
>
> 本轮两个灵感正好戳破这个假设：
> - **续航能力**说：安全不是状态属性，而是**会耗尽的储备**。悬停去「看清」要耗电，减速求稳要耗时，多采样做 FMA 要耗算力——R69 的「好奇」有能量价格；
> - **动力学**说：储备彼此耦合、随时间演化，所以**逐点安全 ≠ 全程可续**。一个策略可以每一步都满足风险 ≤ ε，却在第 N 步把电量/时间/安全余量耗到再也退不回来——像青蛙在温水里被煮熟，只是这次被煮的是**续航**。
>
> 核心命题：**把闭环从「瞬时安全」升级为「续航约束下的可续性（viability）」——把能量/时间/安全余量/信任额度建成耦合动力系统，要求每个动作（包括信息动作与采样算力）都留下足够执行一次认证退避的储备；用「能量归一化 VoI」给好奇心标上影子价格；在储备见底前沿认证的降级阶梯有序收缩，而不是耗尽后失控。** 命名 **ENDURE-RAS**（Endurance-constrained, Dynamics-aware, Uncertainty-regularized Risk-Adaptive System）。
>
> 一句话定位：R69 问「我该向谁求证」，R70 问「**我还能撑多久、还能安全退到哪**」——不确定性可以是一句提问，但问问题也要烧油；真正的研究对象不是某一步的最优，而是**整条轨迹的可续性**。

## 0. 直觉与动机

**灵感 1（续航 → 安全是消耗品，不是状态属性）**
直觉：R68 的 λ_floor 把「慢一点」当成免费的保险，R69 的 MINT 把「问一句」当成零成本的信息获取。但在真实系统里，减速可能意味着更长的悬停时间（能耗不降反升），注视/探针/问句要额外的电机与算力，K 从 1 升到 4、FMA 多回放一次都在吃电。于是「安全动作」和「信息动作」都在**透支未来**。把安全看成储备而非常量，是范式转变：**当前的安全裕度是过去省下来的，未来的安全裕度是现在要留出来的**。

**灵感 2（动力学 → 逐点安全 ≠ 全程可续）**
直觉：R68 已经识破「缓变传感器故障被标定吸收」这一时间尺度陷阱；但同样的陷阱在**资源维度**更致命。设每步风险都 ≤ ε，但策略持续选择「保守减速 + 反复求证」，则时间预算单调流失、能量单调流失。存在这样的场景：前 999 步都无可指摘，第 1000 步电量不足以完成唯一的退避机动。**这是 R68「缓变故障」的资源版镜像**：局部看不见，整体是悬崖。所以 R70 的核心不是再补一个 per-step 约束，而是引入一个**跨时间积分/可达性约束**。

**灵感 3（返航储备 → 正确的下界不是 0，而是「够回家」）**
直觉：把电量耗到 0 再谈安全是荒谬的；正确的最低储备是**从当前状态退到最近认证安全终态（停机位/降落点/安全停车区）所需的能量**，记 E_abort(s)。这一项随位置、载荷、风况变化——离得越远、飞得越高、载得越重，E_abort 越大。这就是「里程焦虑」的严格形式化：**你必须始终保留回家的油**。它天然是一个以可达性定义的控制屏障函数（CBF），比 R68 的标量 λ 收缩更结构化：不是把动作整体缩小，而是在**可行集内选最省/最稳的可行动作**。

**灵感 4（能量归一化 VoI → 好奇心有影子价格）**
直觉：R69 选信息动作是 argmax[VoI − c]，其中 c 只算物理/社交成本，漏掉了最大的成本项——**能量**。把目标改成「每焦耳信息增益」VoI/ΔE，并引入能量影子价格 η_t = ∂τ_end/∂E（多用一焦耳能延长多少续航）。最优交互条件变成 **VoI(g) ≥ η_t·ΔE(g) + c(g)**：当能量充裕（η≈0）时逐字退化为 R69；当濒临见底（η 很大）时，再诱人的信息也不值得问。这把 R69 的「该不该问」升级成「**这个信息值不值这些油**」。K 的自适应同理：多采样只有当边际信息增益 ≥ 边际电能×η 时才值得。

**灵感 5（双刃剑升级 → 被武器化的好奇心）**
直觉：R69 已警告「问错比不问更危险」；一旦问问题要耗续航，就出现一种全新攻击：**对手只需不断制造「看起来值得问」的幻影歧义，诱使系统把储备烧在追问上，直到它回不了家**——认知型拒绝服务（epistemic DoS）。这与 R69 的投毒模型相连但后果不同：投毒让你「信错」，耗竭让你「死掉」。还有更隐蔽的一层：**能量模型本身可能撒谎**（乐观的功耗模型、伪造的剩余电量、被误设的任务时限），一旦储备模型偏乐观，可续性门就会认证一条注定失败的轨迹。所以必须同时交付：悲观能量模型守卫、续航投毒干扰集、储备消耗审计、以及「单次信息动作不得单独定案」纪律的能量版延续。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（ENDURE-RAS 总览）** ENDURE-RAS = (FLUID†, ESM, ABR, VKG, ENV, RAA, LHM, EMG, DRA, VJT, RAS-WM‡)。三不变式：
(i) 继承 R69 定义 293 的实时流零学习写操作与交互预算硬约束；
(ii) **退避储备不变式**：任何被派发的前缀都满足 E_{t+1} ≥ E_abort(s_{t+1}) + ε_res 且 s_{t+1} ∈ K̂_end；
(iii) **可续性支配/严格泛化**：当 η_t = 0、τ_need ≤ H、储备约束非紧时，ENDURE 与 FLUID **逐指令相同**（定义 325）。

**定义 311（储备状态）** 扩展 R69 状态为 s_t = (x_t, E_t, T_t, S_t, C_t)：x_t 物理状态；E_t ∈ ℝ_+ 能量储备（焦耳）；T_t 剩余任务时间；S_t 安全储备（到不安全集的控制屏障裕度/可吸收扰动距离）；C_t 信任储备（标定新鲜度、证据一致性、审计欠账的合成额度）。

**定义 312（储备耦合动力学）**
E_{t+1} = E_t − [P_move(a) + P_comp(K, N_step, FMA) + P_info(g)]·Δt + R_E(o_t)
T_{t+1} = T_t − Δt
S_{t+1} = S_t + G(a, o_t) − L(o_t)（G 为纠偏增益，L 为扰动损失；S<0 即越界）
C_{t+1} = C_t − d_cal(o_t) − d_evidence + r_refresh(标定/审计触发)
关键耦合项：P_comp 随 K、N_step、FMA 回放次数单调上升，P_info 随信息动作上升——**R69 消歧直接压低 E**。

**定义 313（续航时间、可续包络与续航裕度）** τ_end(s) = sup{ τ ≥ 0 : ∃π 使 s_t ∈ K_end 对所有 t ≤ τ 成立，且终止于认证安全终态集 𝒢 }。可续包络 K_end = { s : τ_end(s) ≥ τ_need(s) }，其中 τ_need 为完成任务/退避所需时间。续航裕度 μ(s) = τ_end(s) − τ_need(s)。

**定义 314（可行核及其可靠内近似）** 真可行核 K* 为「安全集 ∩ {E,T,S,C ≥ 0}」的最大受控不变子集。在线用**可靠内近似** K̂ ⊆ K*：由悲观功耗下界、退避可达性区间、以及一个屏障/Lyapunov 储能函数共同界定。可靠性要求 K̂ ⊆ K* ⇒ 门**只会保守拒绝可行状态，绝不认证注定失败的状态**（保守但不虚假）。

**定义 315（退避储备 ABR）** E_abort(s) = 在认证退避策略 π_abort 与风险 ≤ ε_abort 下，把状态从 s 驱入 𝒢 所需的最小能量，过程中须保持 S ≥ 0。E_abort 是一个**以可达性定义的控制屏障函数**：它是状态相关的、非负的、在 𝒢 内为 0。要求 E_{t+1} − E_abort(s_{t+1}) ≥ ε_res（ε_res 为不可动用的安全余量）。

**定义 316（可续性门 VKG）** 动作 (a, g) 可采纳 ⇔ 投影 s_{t+1} ∈ K̂_end ∧ 退避储备不变式成立 ∧ 证书 J 有效。被拒时不简单「整体变慢」（R68 的标量 λ），而是在可行集内重选：a_v = argmin risk(a) s.t. s_{t+1}(a) ∈ K̂_end。**这是对 R68 λ_floor 的结构性升级：从「缩动作」变成「换可行动作」。**

**定义 317（能量归一化 VoI / ENV）** VoI_E(g) = VoI(g)/ΔE(g)（bit/J）。接纳条件：VoI(g) ≥ η_t·ΔE(g) + c(g)，其中能量影子价格 η_t = ∂τ_end/∂E |_{s_t} ≥ 0（多用 1 J 能换来多少续航），由 ESM 的离线 DP 表或伴随法在线估计。⇒ R69 的 MINT 恰为 **η_t = 0** 的边界。

**定义 318（边际采样经济学）** 在 K ∈ {1,4}、N_step、FMA 回放间选择，当且仅当边际信息增益 ΔI_K ≥ η_t·ΔE_comp(K) + c_sw 时升档；否则维持 K=1。R69 的 mode_head 门控是「能量无限」的退化特例。采样不再是「歧义就采样」，而是「**这笔电买的信息值不值**」。

**定义 319（储备感知分配 RAA 与任务削减）** 若在完整任务集下不存在满足 VKG 的动作，则按**价值密度**（任务价值 / 焦耳·秒）从低到高削减子任务，直至可行；削减顺序被认证并记录。这是有序的任务降级，而非仓促急停。

**定义 320（降级阶梯 LHM）** 模式 ℓ ∈ {NORMAL, CONSERVE, LIMP, SAFE_STOP}。CONSERVE：禁止信息动作、K=1、限速；LIMP：执行到最近安全终态的退避；SAFE_STOP：认证停车/悬停。向下转移当 μ 低于阈值 τ_1 > τ_2 > τ_3；向上恢复需 μ 高于阈值加滞回 h 并满足驻留时间（防抖振）。

**定义 321（续航证书 VJT / J_ENDURE）** J_ENDURE = (J_FLUID, reserve_trajectory_hash, E_abort_bound, μ_min, η_estimate, mode_switch_log, energy_model_ver, K_end_inner_ver)。Valid ⇔ Valid(J_FLUID) ∧ 全时程退避储备不变式成立 ∧ K̂ 对所声明能量模型可靠 ∧ 模式迁移合规。

**定义 322（能量模型守卫 EMG）** 功耗模型 P̂ 必须满足 **P̂ ≥ P_true**（对消耗取悲观上界，从而剩余能量是下界）。在线用实测能量核对预测；若实测消耗更快（残差显示 P̂ 偏低），触发重估并**收缩 K̂**。EMG 是资源侧的 MCG：**未经校验的储备模型一律禁止做出长时程可续性断言**，只允许退化为短时程 FLUID 行为。

**定义 323（续航投毒与认知 DoS / ℰ_drain）** 通过 R69 的 ℰ_poison/ℰ_flow 注入幻影歧义，诱发反复信息动作或 K 升档直至储备耗尽；伪造剩余电量/任务时限；用标定吸收掩盖慢速能量异常。并入 AIC：ℰ_ENDURE = ℰ_FLUID × ℰ_drain × ℰ_energy_model。

**定义 324（消耗-信息耦合表 / burn table）** 一张把每个子系统（K 采样、FMA 回放、注视、探针、问句、减速悬停）映射到 (ΔE, ΔT, ΔS, ΔC) 的边际消耗表。用于给信息定价、识别「跨储备陷阱」（例如减速在省瞬时风险的同时可能因悬停而更费电），并作为 RAA 的成本先验。

**定义 325（严格泛化的退化边界）** 当 η_t = 0、τ_need ≤ H、E_abort ≤ ε_res、C 充裕时：VKG 非紧、ENV ≡ MINT、K 经济学 ≡ mode_head 门控、LHM 恒在 NORMAL ⇒ ENDURE 输出与 R69 逐指令一致。R69 = 「能量免费 + 短时程」边界上的退化。

```python
# IP-264 ESM：储备动力学（悲观功耗模型 P_hat >= P_true）
class EnduranceStateModel:
    def __init__(self, power_model, tau_table):
        self.P, self.tau = power_model, tau_table     # P 对消耗取上界
    def project(self, s, a, g, K, N_step):
        dE = (self.P.move(a) + self.P.comp(K, N_step) + self.P.info(g)) * DT
        return Reserve(E=max(0.0, s.E - dE + s.recharge),
                       T=s.T - DT,
                       S=s.S + self.P.gain(a) - self.P.loss(),
                       C=s.C - self.P.trust_drift(DT) + s.C_refresh)
    def shadow_price(self, s):                        # ∂τ_end/∂E，离线 DP 查表
        return self.tau.grad_E(s)

# IP-265 ABR：退避储备 = 可达性 CBF
def abort_reserve(s):
    return reachability_min_energy(s, goal=SAFE_TERMINALS,
                                   policy=PI_ABORT, risk=EPS_ABORT)

# IP-266 VKG：可靠内近似上的可续性门
def feasible_after(s, action, eps_res):
    sn = M.esm.project(s, action.a, action.g, action.K, action.N)
    return (sn.E - abort_reserve(sn) >= eps_res
            and sn.T >= 0 and sn.S >= 0 and sn.C >= 0
            and sn in M.vkg.K_hat)                     # K_hat ⊆ K*

# IP-267 ENV：能量归一化 VoI（好奇心有影子价格）
def choose_interaction_E(modes, w, s, eta):
    best = None
    for g in info_action_candidates(modes):
        if not budget.allow(g) or not c_ras_wm.certify_info(g, s): continue
        dE  = power_info(g)
        voi = entropy(w) - expected_entropy(w, g, s)
        if voi < eta * dE + social_cost(g): continue   # 电不够值 → 不问
        score = voi / max(dE, EPS)
        if best is None or score > best.score: best = (g, score)
    return best[0] if best else None                   # 无利可图 → R69/R68 退化

# IP-268 RAA：边际采样经济学 + 任务削减
def choose_K(s, dI_hat, eta):
    dE = power_comp(K=4) - power_comp(K=1)
    return 4 if dI_hat >= eta * dE + C_SWITCH else 1

def shed_until_feasible(s, modes):
    for task in sorted(TASKS, key=value_density):       # 价值密度升序
        if feasible_after(s, plan_without(task)): return plan_without(task)
    return ABORT_PLAN                                  # 全削减仍不可行 → LIMP

# IP-269 LHM：带滞回的降级阶梯（防抖振）
def degradation_step(s, mode):
    mu = M.esm.tau_end(s) - tau_need(s)
    down = {NORMAL: (TAU1, CONSERVE), CONSERVE: (TAU2, LIMP), LIMP: (TAU3, SAFE_STOP)}
    up   = {SAFE_STOP: LIMP, LIMP: CONSERVE, CONSERVE: NORMAL}
    if mode in down and mu < down[mode][0]:  return down[mode][1]
    if mode in up   and mu > TAU_UP[mode] + H: return up[mode]
    return mode

# IP-276 主闭环（继承 R69，仅在派发前插入可续性层）
def ENDURE_RAS_round(M, s, obs):
    z, o = M.mtm.forward(...); c, U_cal, _ = M.cof.step(...)
    eta = M.esm.shadow_price(s)                        # 能量影子价格
    K   = M.raa.choose_K(s, M.fmp.delta_I_hat(z), eta) # 先算“多采样值不值电”
    U_ale, U_epi, modes = M.aud.decompose(M.fmp.sample(o, K), z)
    g = None
    if U_epi > TAU_EPI and not M.fma.slow_fault_suspect(...):
        g = M.env.choose_interaction_E(modes, s, eta)  # R69 的交互 + 能量定价
        if g is not None and not M.vkg.feasible_after(s, g): g = None
    cand = M.c_ras_wm.propose_viable(s, modes, g, K_hat=M.vkg.K_hat)
    a = argmin_risk(cand, s)                           # 可行集内选优，非标量收缩
    if not M.vkg.feasible_after(s, a):
        a = M.raa.shed_until_feasible(s, modes)        # 任务降级
    mode = M.lhm.step(s)                               # NORMAL→…→SAFE_STOP
    M.vqa_e.submit_async(g, a, s, eta)                 # 审计储备消耗
    return a, M.esm.project(s, a, g, K, M.fmp.N_step), mode
```

## 3. 推导

**引理 19（储备单调性与耦合）** 在定义 312 下，无回充时 E、T 沿任意可采纳轨迹单调不增；且 (K, g) ↦ ΔE 单调不减。故 R69 的每个信息动作/升采样都是对未来所有安全裕度的**负外部性**——这一步的「聪明」由未来买单。

**引理 20（能量归一化 VoI 的 KKT 最优性）** 在能量约束 E_t − ΔE(g) ≥ E_abort(s_{t+1}) + ε_res 下最大化 VoI，拉格朗日乘子即影子价格 η；最优必要条件 VoI'(g) = η·ΔE'(g)，接纳判据 VoI(g) ≥ ηΔE(g) + c(g)。系：**原始 VoI（R69）在 η>0 时系统性问得太多**，多问的量与 (1/η) 成正比，资源越紧、过度求证越致命。

**引理 21（可续性门的可靠性）** 若 K̂ ⊆ K* 且 P̂ ≥ P_true（悲观功耗），则任何被派发的轨迹都不离开 K*；因 K* 受控不变且可退避到 𝒢，任务要么完成，要么在储备越界前进入 LIMP。可靠性完全由「内近似正确 + 模型悲观」两点支撑；**它只保证不认证失败轨迹，不保证不误拒可行轨迹**（保守性由 E310 度量）。

**定理 18（ENDURE 严格包含 FLUID）** 当 η=0、τ_need ≤ H、E_abort ≤ ε_res、C 充裕时，VKG 非紧、ENV≡MINT、采样经济学≡mode_head 门控、LHM 恒在 NORMAL ⇒ 与 R69 逐指令相同。一般情形下，执行前缀上的 per-step 风险与 R69 相同（门只剔除不可续动作，不改变已采纳动作的风险上界），而**可续性调整后的期望代价 ≤ R69**。R69 即「零能量价格 + 短时程」边界。

**定理 19（逐点安全 ≠ 全程可续）** 存在一条策略与一个环境/对手，使每一步都满足风险 ≤ ε，却以正概率在任务截止前离开可行集。构造：持续注入可分的幻影歧义诱使 R69 反复「看/问」，每步都安全但 E 单调下降；或让系统持续减速，每步安全但 T 单调流失。故 J_CALM/J_FLUID 这类**逐点证书充分性不成立**，必须补一条储备轨迹证书（VJT）。这是 R68「慢变故障被标定吸收」在资源维度的镜像。

**引理 22（认知 DoS 的续航上界）** 设幻影歧义注入率 ν、单次信息动作耗能 ΔE_g，则期望烧速率 ≥ νΔE_g + P_base；VKG 把累计信息支出封顶在 E_t − E_abort − ε_res，故攻击下「到可续性越界」的时间下界为 (E_t − E_abort − ε_res)/(νΔE_g + P_base)，且对手要加速耗竭就必须提高信息请求频率与动作幅度，从而抬高 R69 的流似然异常分 a_score——**ℰ_drain 与 ℰ_flow 因此耦合可检**。

**定理 20（降级无抖振与单调安全）** 取滞回 h>0 与驻留时间，LHM 不存在 Zeno/抖振迁移；对递减的 μ，迁移序列 NORMAL→CONSERVE→LIMP→SAFE_STOP 单调，高一级模式的可行动作集是低一级的子集 ⇒ 风险与储备抽取沿阶梯弱单调；复合控制连续（保持 R68 定理 15 的换装不变式）。

```python
# IP-264 ESM：悲观功耗下的储备投影与影子价格
class EnduranceStateModel:
    def project(self, s, a, g, K, N_step):
        dE = (self.P.move(a) + self.P.comp(K, N_step) + self.P.info(g)) * DT
        return Reserve(E=max(0.0, s.E - dE + s.recharge), T=s.T - DT,
                       S=s.S + self.P.gain(a) - self.P.loss(),
                       C=s.C - self.P.trust_drift(DT) + s.C_refresh)
    def shadow_price(self, s):                 # ∂τ_end/∂E，离线 DP/伴随查表
        return self.tau.grad_E(s)

# IP-265 ABR：退避储备（可达性 CBF）
def abort_reserve(s):
    return reachability_min_energy(s, goal=SAFE_TERMINALS,
                                   policy=PI_ABORT, risk=EPS_ABORT)

# IP-266 VKG：可靠内近似上的可续性门
def feasible_after(s, action, eps_res):
    sn = M.esm.project(s, action.a, action.g, action.K, action.N)
    return (sn.E - abort_reserve(sn) >= eps_res and sn.T >= 0
            and sn.S >= 0 and sn.C >= 0 and sn in M.vkg.K_hat)   # K_hat ⊆ K*

# IP-267 ENV：能量归一化 VoI（好奇心有影子价格）
def choose_interaction_E(modes, w, s, eta):
    best = None
    for g in info_action_candidates(modes):
        if not budget.allow(g) or not c_ras_wm.certify_info(g, s): continue
        dE, voi = power_info(g), entropy(w) - expected_entropy(w, g, s)
        if voi < eta * dE + social_cost(g): continue            # 电不值 → 不问
        score = voi / max(dE, EPS)
        if best is None or score > best.score: best = (g, score)
    return best[0] if best else None

# IP-268 RAA：经济采样 + 有序任务削减
def choose_K(s, dI_hat, eta):
    dE = power_comp(K=4) - power_comp(K=1)
    return 4 if dI_hat >= eta * dE + C_SWITCH else 1

def shed_until_feasible(s, modes):
    for task in sorted(TASKS, key=value_density):
        if feasible_after(s, plan_without(task)): return plan_without(task)
    return ABORT_PLAN

# IP-269 LHM：带滞回的降级阶梯
def degradation_step(s, mode):
    mu = M.esm.tau_end(s) - tau_need(s)
    down = {NORMAL: (TAU1, CONSERVE), CONSERVE: (TAU2, LIMP), LIMP: (TAU3, SAFE_STOP)}
    up   = {SAFE_STOP: LIMP, LIMP: CONSERVE, CONSERVE: NORMAL}
    if mode in down and mu < down[mode][0]:   return down[mode][1]
    if mode in up   and mu > TAU_UP[mode] + H: return up[mode]
    return mode
```

## 4. 推导

**引理 19（储备单调性与耦合）** 无回充时 E、T 单调不增；`(K,g)↦ΔE` 单调不减。故 R69 的每次信息动作/升采样都是对未来安全裕度的负外部性——这一步的「聪明」由未来买单。

**引理 20（ENV 的 KKT 最优性）** 在 `E_t−ΔE(g) ≥ E_abort+ε_res` 下最大化 VoI，拉格朗日乘子即 η：`VoI'(g)=ηΔE'(g)`，接纳判据 `VoI(g) ≥ ηΔE(g)+c`。系：原始 VoI 在 η>0 时系统性过度求证，多问量与 1/η 成正比。

**引理 21（可续性门的可靠性）** 若 `K̂⊆K*` 且 `P̂≥P_true`，任何被派发轨迹不离开 `K*`；因 `K*` 受控不变且可退避到 𝒢，任务要么完成、要么在越界前进入 LIMP。可靠性由「内近似正确 + 模型悲观」支撑；只保证不认证失败轨迹，不保证不误拒（保守性由 E310 度量）。

**引理 22（认知 DoS 的续航上界）** 注入率 ν、单次信息耗能 ΔE_g 下，烧速率 ≥ νΔE_g+P_base；VKG 把累计信息支出封顶在 `E_t−E_abort−ε_res`，故到越界时间的下界为 `(E_t−E_abort−ε_res)/(νΔE_g+P_base)`；对手要加速耗竭须提高信息请求频率/幅度，从而抬高 R69 的 `a_score`——ℰ_drain 与 ℰ_flow 耦合可检。

**定理 18（ENDURE 严格包含 FLUID）** `η=0 ∧ τ_need≤H ∧ E_abort≤ε_res ∧ C 充裕` 时 VKG 非紧、ENV≡MINT、采样经济学≡mode_head 门控、LHM 恒 NORMAL ⇒ 与 R69 逐指令相同；一般情形执行前缀的 per-step 风险与 R69 相同，而可续性调整后的期望代价 ≤ R69。R69 = 「零能量价格 + 短时程」边界。

**定理 19（逐点安全 ≠ 全程可续）** 存在一条每步风险 ≤ ε 的策略与环境/对手，使其以正概率在截止前离开可行集（持续注入幻影歧义反复求证，或持续减速耗尽时间）。故逐点证书 J_CALM/J_FLUID 不充分，必须补储备轨迹证书 VJT。这是 R68「慢变故障被标定吸收」的资源维度镜像。

**定理 20（降级无抖振与单调安全）** 滞回 h>0 + 驻留时间下 LHM 无 Zeno 迁移；对递减 μ 迁移序列单调，高一级模式的动作集是低一级子集 ⇒ 风险与储备抽取沿阶梯弱单调；复合控制连续（保持 R68 定理 15 换装不变式）。

## 7. 本轮最大风险

**一句话**：ENDURE-RAS 的全部安全保证押在「**储备/能量模型是真实消耗的悲观下界，且退避终态确实可达**」上——若功耗模型偏乐观、时限被误设、或退避机动真实代价超过 E_abort 估计，可续性门就会**精准认证它本应排除的那条注定失败的轨迹**；而与前几层不同，能量花掉无法回溯、也没有「退回保守」的余地——**传感器错了还能降级，续航算错了是不可逆的耗尽**。

**次级风险与缓解**：K̂ 过保守导致误拒可行任务（E310 度量 + 任务削减兜底）；η 估计漂移使定价失真（EMG 重估 + 在线校准）；认知 DoS（ℰ_drain 对抗训练 + 引理 22 上界 + 请求频率异常检测）；降级抖振（滞回 + 驻留 + 定理 20）；多任务/回充调度耦合（RCS 统一约束，E312 验证）。
