# 第 68 轮（承接第 67 轮「SimRAS 仿真增强风险自适应闭环」IP-233~242；灵感循环第 1 轮；本轮灵感：「双足机器人」×「多任务学习」）

> 第 67 轮 SimRAS 用「离线仿真预训练 + 在线世界模型 + 视觉问答审计」把风险闭环推到了长时程。但它默认了两件事：
> 1. **系统是单相位的**：安全裕度 ρ_safe 在时间上连续可微，认证前缀 k 可以平滑地跨过任意时刻；
> 2. **任务是单一的**：世界模型的动力学/情绪/故障头服务于同一个任务，任务之间只是“拼装”。
>
> 双足机器人和多任务学习恰好从两个方向打破这两个默认：
> - **双足机器人**是典型的**混合动力学系统**：连续摆动段 + 离散足地冲击段。安全裕度在支撑相与摆动相的定义根本不同，冲击 reset map 会放大误差。让一个认证前缀跨过相位边界，在数学上是未定义操作。
> - **多任务学习**让一个共享骨干同时服务行走、地形、恢复、跌倒风险、故障归因与认证。共享带来样本效率，也带来**负迁移**：辅助任务的梯度可能悄悄抬高安全任务的损失。
>
> 本轮核心命题：
>
> **把 SimRAS 的「单相位、单任务、连续证书」升级为「相位索引、多任务共享、混合证书」的 PACT（Phase-Aware Certified multi-Task closure）：连续段用相位条件安全裕度认证，离散段用转移证书认证；多任务骨干在“安全地板”约束下共享表示，任何一次更新都不允许安全任务退化超过 ε_floor；相位边界既是误差放大器，也是天然的证书检查点。**

## 0. 直觉与动机

**灵感 1（双足机器人 → 相位索引的混合安全）**
直觉：双足行走不是一条光滑轨迹，而是一条**分段连续轨迹**：左脚支撑 → 右脚触地（冲击）→ 双脚支撑 → 左脚离地 → 右脚支撑。连续段由拉格朗日动力学主导，离散段是足地冲击的 reset map。

这直接击穿了 SimRAS 的两个隐含假设：
- **裕度不可比**：支撑相的安全裕度看 ZMP/CoP 是否落在支撑多边形内、DCM 是否可被支撑脚“抓住”；摆动相的安全裕度看落脚点是否可达、摆动腿是否会在触地前耗尽时间。用同一个标量 ρ_safe 贯穿两相，会把“支撑相的稳定”和“摆动相的可行”混为一谈。
- **冲击会放大误差**：落地瞬间 1cm 的落脚误差，经过 reset map 可能变成 5~10cm 的 CoM 速度跳变。SimRAS 的世界模型只做连续滚动，把足触地当成一个“普通观测更新”，完全漏掉了这个离散放大环节。

因此，本轮的**第一个结构性改动**是：证书必须以相位为索引，且把「转移证书」提升为与「连续证书」同等的一等公民。

**灵感 2（多任务学习 → 安全地板下的共享表示）**
直觉：双足机器人天然是多任务系统——平地行走、坡面、楼梯、抗推、负载、跌倒恢复、故障归因。它们共享同一套接触物理与平衡原理，所以共享表示能显著提升样本效率（真实双足机器人的数据极其昂贵）。

但“多任务一定更好”是错觉。真正的问题是**负迁移**：
- 地形任务学到的“大胆迈步”可能污染跌倒风险头；
- 视觉/情绪等辅助任务的梯度，可能在某个 mini-batch 上把安全头推离安全区；
- 共享骨干一旦在相位边界附近过拟合，安全任务最先遭殃。

安全的 MTL 不是“共享越多越好”，而是“**共享必须带安全地板**”：定义安全任务集合 S，要求任意一次参数更新后都满足 `L_S(θ') ≤ L_S(θ) + ε_floor`。这不是“多目标调权重”，而是一条**硬约束**。

**灵感 3（合流 → PACT：相位感知的认证多任务闭环）**
PACT 把 SimRAS 的「连续世界模型 + 单任务证书」换装为：
1. **HPG（Hybrid Phase Graph）**：显式建模离散相位与 reset map；
2. **PE（Phase Estimator）**：从本体/IMU/足底接触估计 `p_t=(σ_t, θ_t)` 及其不确定性；
3. **HP-WM（Hybrid-Phase World Model）**：在 SimRAS 的 WM 上增加模式头与转移时间头；
4. **PAC-Prefix**：在下一个 guard 前截断认证前缀，并要求转移证书成立；
5. **MTL-SF（Multi-Task Learning with Safety Floor）**：相位条件专家 + 安全地板梯度手术；
6. **TSC（Task-Safety Conflict monitor）**：在线检测任务-安全梯度冲突，触发保守回退；
7. **恢复律（protective recovery）**：跌倒裕度不足时，不“冻结”，而是主动降低 CoM、加宽支撑、准备坐地。

**灵感 4（相位边界既是危险，也是机会）**
直觉：SimRAS 的最痛点是长时程误差累积。而双足机器人每个步态周期都会触地——**触地是一次强观测**，它把 CoM/足端位置的误差“重新观测”了一遍。因此相位边界可以当作**天然的证书检查点**：把一条长轨迹切成若干短段，每段独立认证，段间用转移证书拼接。这样长时程证书问题被降解为多个短时程证书 + 若干离散转移证书。

**灵感 5（组件映射）**
- `WM → HP-WM`：增加离散模式头 `mode_head` 与转移时间头 `trans_head`；
- `C-RAS-WM prefix → PAC-Prefix`：`k_pac = min(k_simras, k_guard)`；
- 单任务骨干 → **相位条件低秩专家**（shared trunk + `A_σ = U_σ V_σᵀ`）；
- `AuditBuf → PSKB`（相位安全案例库）：按 `(phase, contact, terrain)` 索引转移失败案例；
- `AIC → AIC-PACT`：新增 `ℰ_phase`（相位估计/定时误差）、`ℰ_contact`（滑移/下陷/边缘）、`ℰ_mtl`（负迁移/专家坍缩）；
- `J_SimRAS → J_PACT`：新增 phase_hash、contact_schedule_hash、k_pac、transfer_cert、fall_margin、mtl_floor_slack、conflict_flag。

## 1. 形式化定义（增量：定义 266–285）

- **定义 266（PACT 总览）** `PACT = (HPG, PE, HP-WM, PAC-Prefix, MTL-SF, TSC, REC, AIC-PACT, J-PACT)`。定位：把 SimRAS 的连续单任务风险闭环升级为混合相位、多任务共享的安全闭环。不变式：连续证书按相位段独立计算，离散证书在 guard 处计算；实时流只做推理与早停，零学习写操作。
- **定义 267（混合相位图 HPG）** `HPG = (Σ, E, F, G, Δ)`：
  - `Σ = {LS, RS, DS}`（左支撑、右支撑、双支撑；跑步时加 `FL` 飞行相）；
  - `F = {f_σ}_{σ∈Σ}`，`ẋ = f_σ(x,u)`，`x ∈ ℝ^{n_x}` 为 CoM/关节/角动量状态；
  - `G = {G_e}_{e∈E}`，`G_{σ→σ'} ⊂ ℝ^{n_x}` 为 guard 超曲面；
  - `Δ = {Δ_e}_{e∈E}`，`x⁺ = Δ_{σ→σ'}(x⁻)` 为冲击 reset map。
- **定义 268（相位状态与相位钟）** 相位状态 `p_t = (σ_t, θ_t)`，`θ_t ∈ [0,1)` 为归一化相位钟。相位估计器 `PE: o_t ↦ p̂_t`，其定时误差分布满足 `|t̂_guard - t_guard| ≤ η_t`，模式误判概率 `P(σ̂ ≠ σ) ≤ η_σ`。定义总相位不确定度 `η_phase = η_σ + λ_t·η_t`。
- **定义 269（相位条件安全裕度）** 对每个模式 σ 定义标量裕度 `ρ_σ(x)`：
  - 支撑相：`ρ_LS/RS(x) = signed_dist(ZMP(x), P_support) ∧ margin_DCM(x)`（ZMP 到支撑多边形的有符号距离与 DCM 可捕获裕度取小）；
  - 摆动相：`ρ_swing(x) = min(foot_reach_margin, swing_time_margin)`；
  - 双支撑相：`ρ_DS(x) = 两侧支撑多边形交集的裕度`。
  安全集 `C_σ = {x : ρ_σ(x) ≥ 0}`。注意：**不同 σ 的 ρ_σ 不可直接比较**。
- **定义 270（HP-WM 混合相位世界模型）** `HP-WM_θ = (Enc, mode_head, dyn_head, safety_head, trans_head, {h_τ})`。编码 `z_t = Enc(o_t, u_t, p̂_t)`；`mode_head(z_t) → q_t ∈ Δ^{|E|}`，`dyn_head → ẑ_{t+1}`，`safety_head → ρ̂_σ`，`trans_head → (τ̂_guard, Σ̂_t)`，`h_τ` 为任务头（τ∈T，见定义 274）。损失 `L = L_recon + λ_ρL_ρ + λ_modeL_mode + λ_transL_trans + Σ_τ λ_τ L_τ`。
- **定义 271（转移预测）** `q_t(e)` 为在当前模式下发生转移 e 的概率；`τ̂_guard` 为下一次 guard 的预计时刻，`Σ̂_t` 为定时误差协方差。定义预期 guard 步数 `k_guard = ⌊(τ̂_guard - t)/Δt⌋ - κ_margin`，`κ_margin = ⌈3√Σ̂_t/Δt⌉`。
- **定义 272（PAC 认证前缀）** `k_pac = min(k_simras, k_guard, m_pac)`。含义：认证前缀**不得跨过未经认证的相位边界**。若 `k_guard ≤ 0`，则只允许执行到当前 guard 前的最后一个安全步。
- **定义 273（转移证书）** 对候选转移 `e = (σ→σ')`：
  ```
  T_e(x) = ρ_{σ'}(Δ_e(x̂⁻)) - L_Δ·|ẋ̂⁻|·η_t - L_ρ·ε_obs
  ```
  要求 `T_e ≥ 0` 才允许跨相。若 `T_e < 0`，PACT 不执行该转移，而是切换到**恢复律**（定义 285）或延长双支撑。`L_Δ` 为 reset map 的 Lipschitz 常数，`L_ρ` 为相位条件裕度的 Lipschitz 常数。
- **定义 274（多任务集合）** `T = {T_loco, T_terrain, T_recover, T_fall, T_fault, T_cert, T_emo}`，其中**安全任务集** `S = {T_fall, T_cert}`，辅助任务集 `A = T \ S`。`T_emo` 保留第 66 轮的情绪/操作者风险头，作为兼容的辅助任务。
- **定义 275（相位条件低秩专家）** 共享骨干 `φ(x; θ_0)`，相位专家 `A_σ = U_σ V_σᵀ`，`U_σ, V_σ ∈ ℝ^{d×r}`，`r ≪ d`。前向 `z_σ = φ(x) + A_σ φ(x)`。任务头 `h_τ(z_σ)`。参数 `θ = (θ_0, {U_σ,V_σ}_σ, {h_τ}_τ)`。
- **定义 276（安全地板约束）** 令 `L_S(θ) = Σ_{s∈S} w_s L_s(θ)`。训练第 t 步要求：
  ```
  L_S(θ^{t+1}) ≤ L_S(θ^t) + ε_floor
  ```
  `ε_floor` 是每步允许的安全损失抬升（默认 1e-3·L_S^0）。
- **定义 277（安全地板梯度手术 SFGS）** 记安全梯度 `g_S = ∇L_S`，辅助梯度 `g_A = ∇L_A`。若 `⟨g_A, g_S⟩ < 0`（辅助任务会降低安全性能），投影：
  ```
  g_A' = g_A - (⟨g_A, g_S⟩ / (||g_S||² + ε)) · g_S   （当 ⟨g_A,g_S⟩<0）
  g_A' = g_A                                          （否则）
  ```
  更新 `θ^{t+1} = θ^t - η(g_S + g_A')`，并做一次投影回安全地板球（若超界则沿 `g_S` 反方向回拉）。
- **定义 278（负迁移度）** 对任务 τ，`NT_τ = L_τ(MTL) - L_τ(STL)`。安全负迁移 `NT_S = max_{s∈S} NT_s`。PACT 要求 `NT_S ≤ ε_floor + O(η)`（由定理 15 保证）。
- **定义 279（任务-安全冲突监视器 TSC）** 在线冲突分：
  ```
  C_t = max(0, -cos(g_S^probe, g_A^probe)) · (1 + σ_ρ)
  ```
  `g^probe` 由轻量探针（小批量/有限差分）估计，`σ_ρ` 为安全头预测方差。若 `C_t > τ_conflict`，冻结相位专家更新、令 `λ_risk ↑`、`k_pac ↓`，并在证书标记 `conflict_flag=True`。
- **定义 280（AIC-PACT 干扰集）** `ℰ_PACT = ℰ_SimRAS × ℰ_phase × ℰ_contact × ℰ_mtl`。`ℰ_phase = {相位定时误差, 模式误判, guard 抖动}`；`ℰ_contact = {足底滑移, 地面下陷, 边缘踩空, 摩擦系数突变}`；`ℰ_mtl = {负迁移, 专家坍缩, 任务头共振}`。
- **定义 281（J-PACT 证书）** `J_PACT = (J_SimRAS, phase_hash, contact_schedule_hash, k_pac, T_e, fall_margin, mtl_floor_slack, conflict_flag)`。`Valid ⇔ Valid(J_SimRAS) ∧ (k_pac ≥ 1) ∧ (T_e ≥ 0 或有恢复律接管) ∧ (mtl_floor_slack ≥ 0)`。
- **定义 282（分段证书拼接）** 轨迹 `x_{0:T}` 被 guards `t_1<...<t_m` 切分为 `m+1` 段。若每段 `[t_i,t_{i+1})` 的 PAC 证书有效，且每个 `T_{e_i}(x(t_i)) ≥ 0`，则整条轨迹证书有效。记 `Cert(x_{0:T}) = ∧_i Cert_seg(i) ∧ ∧_i Cert_trans(i)`。
- **定义 283（相位安全案例库 PSKB）** 键值库 `PSKB[(σ, σ', terrain_class, fault_class)] = {case_id, margin_trace, Δ_mismatch, recommendation}`。HP-WM 的 `trans_head` 在 guard 前检索相似案例，作为转移证书的先验修正。
- **定义 284（PACT 在线部署不变式）** 实时环路：`PE → HP-WM(≤1ms) → PAC-Prefix → MTL heads → 控制`。PSKB 与 VQAuditor 异步；MTL 训练/梯度手术仅在离线或低频后台。实时环路永不写参数。
- **定义 285（恢复律 REC）** 当 `fall_margin < τ_recover` 或转移证书失败时，进入恢复模式：`u_rec = argmin_u ||u||² s.t. ρ_σ(x_{t+1}) ≥ 0`，并执行「降 CoM + 加宽支撑 + 停止摆动 + 预备坐地」的四级降级。恢复律本身也要在 HPG 上认证，不能成为未认证的后门。

```python
# 相位估计器
class PhaseEstimator:
    def estimate(self, obs):
        sigma_hat = self.mode_clf(obs.imu, obs.contacts)      # LS/RS/DS/FL
        theta_hat = self.phase_reg(obs.imu, obs.joint_vel)    # [0,1)
        eta_t = self.timing_uncertainty(obs)                  # 秒
        eta_sigma = self.mode_uncertainty(obs)
        return {'sigma': sigma_hat, 'theta': theta_hat,
                'eta_t': eta_t, 'eta_sigma': eta_sigma}


# 混合相位世界模型：带 guard 的滚动
class HybridPhaseWorldModel(WorldModel):
    def rollout_phase(self, z, act_seq, sigma, k=5):
        preds, crossings = [], []
        for i, a in enumerate(act_seq[:k]):
            q = self.mode_head(z)              # 下一模式分布
            tau, Sig = self.trans_head(z)      # guard 时刻
            z = self.dyn(z, a, sigma)
            rho = self.safety_head(z, sigma)   # 相位条件裕度
            preds.append({'z': z, 'q': q, 'rho': rho,
                          'tau_guard': tau, 'Sigma': Sig})
            if tau <= self.dt:                 # 本步内触地/离地
                crossings.append(i)
                sigma = q.argmax()
        return preds, crossings


# PAC 认证前缀：在 guard 前截断
class PACPrefix:
    def certify(self, A, wm_preds, crossings, joint_post, m_pac, alpha_chunk):
        k_simras = self.simras_prefix(A, joint_post, m_pac, alpha_chunk)
        # 最近一次 guard
        k_guard = len(wm_preds) if not crossings else crossings[0]
        k_pac = max(0, min(k_simras, k_guard, m_pac))
        # 若恰在 guard 处，必须通过转移证书
        if k_pac > 0 and k_pac == k_guard:
            e = wm_preds[k_pac - 1]['q'].argmax()
            if not self.transfer_ok(wm_preds[k_pac - 1], e):
                k_pac = max(0, k_pac - 1)      # 提前停在双支撑内
        return k_pac

    def transfer_ok(self, pred, e):
        rho_next = pred['rho']                 # 已在 HP-WM 中按 sigma' 计算
        return rho_next - self.L_delta * self.v * pred['eta_t'] \
               - self.L_rho * self.eps_obs >= 0


# 安全地板梯度手术
def safety_floor_step(theta, g_S, g_A, eta, eps_floor, L_S_prev, L_S_fn):
    inner = dot(g_A, g_S)
    if inner < 0:
        g_A = g_A - (inner / (norm(g_S)**2 + 1e-12)) * g_S
    theta_new = theta - eta * (g_S + g_A)
    if L_S_fn(theta_new) > L_S_prev + eps_floor:
        # 超界：沿 g_S 反方向回拉（线搜索最小回拉量）
        theta_new = backtrack_to_floor(theta, theta_new, L_S_prev + eps_floor, L_S_fn)
    return theta_new


# PACT 在线一轮
def PACT_round(M, obs):
    # 1) 相位估计
    p_hat = M.pe.estimate(obs)
    # 2) 混合世界模型滚动（含 guard 预测）
    act_seq = M.vista.ach.propose_actions(M.x_prime, steps=5)
    wm_preds, crossings = M.hp_wm.rollout_phase(
        M.z, act_seq, p_hat['sigma'], k=5)
    # 3) SimRAS 的联合归因（保留情绪/故障头）
    face_gate = M.erg_wm.recognize(obs.img, M.x_prime, act_seq)
    joint_post, _ = M.efs_wm.synthesize(M.rho, face_gate, M.x_prime, act_seq)
    # 4) PAC 前缀（相位截断 + 转移证书）
    A = M.vista.ach.propose(M.x_prime)
    k_pac = M.pac.certify(A, wm_preds, crossings, joint_post,
                          m_pac=min(5, len(A)), alpha_chunk=M.alpha_chunk)
    # 5) 多任务头：安全头优先
    z_phase = M.mtl.encode_phase(M.x_prime, p_hat['sigma'])
    rho_hat = M.mtl.head('T_fall')(z_phase)
    rho_cert = M.mtl.head('T_cert')(z_phase)
    # 6) 冲突监视 + 恢复律
    conflict = M.tsc.score(g_S_probe=M.mtl.grad_S(),
                           g_A_probe=M.mtl.grad_A(),
                           sigma_rho=rho_hat.var)
    if rho_hat.margin < M.tau_recover or conflict > M.tau_conflict:
        u = M.rec.solve(M.x_prime, p_hat, rho_hat)
        M.cert.flag('conflict', conflict)
        return u, k_pac, conflict, p_hat
    # 7) 正常控制
    u = M.vista.pi_sigma.prefix_dispatch(A[:k_pac])
    u = u * M.efs_wm.risk_scale(joint_post)
    return u, k_pac, conflict, p_hat
```

## 3. 推导

**引理 13（相位条件证书的可靠性）** 若对模式 σ 存在控制不变集 `C_σ`，且 PAC 前缀 `k_pac` 内 `ρ_σ(x_{t+i}) ≥ 0`，则在段内 `x` 不离开 `C_σ`。证明：由 `k_pac ≤ k_simras` 与 SimRAS 的连续段风险一致性，段内每个执行步满足 `λ_risk·ρ_σ ≥ 0`；相位未切换时 `ρ_σ` 定义不变，故不变集保持。∎

**引理 14（冲击放大与定时误差）** 设 reset map `Δ_e` 关于状态局部 Lipschitz，常数 `L_Δ`；定时误差 `η_t` 使实际冲击状态偏移 `|ẋ|·η_t`。则转移后的裕度误差满足：
```
|ρ_{σ'}(Δ_e(x)) - ρ_{σ'}(Δ_e(x̂))| ≤ L_ρ·L_Δ·(|δx| + |ẋ̂|·η_t)
```
因此转移证书必须扣除 `L_Δ·|ẋ̂|·η_t` 与观测噪声项，否则会在落地瞬间“假通过”。

**引理 15（guard 截断的完备性）** 若 `k_pac ≤ k_guard`，则在认证前缀内不发生未认证的相位转移。证明：`k_guard` 由 `trans_head` 的 `3σ` 上界保守估计；只要 `τ_guard` 的预测误差不超过 `Σ̂_t`，转移必发生在 `k_pac` 之后。∎

**定理 14（PACT 端到端风险一致性）** 在 A87–A91、定义 272–273 与引理 13–15 下，PACT 输出的控制指令满足：
1. `P(fall) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_phase + α_mtl`；
2. 每个执行段都携带有效 `Cert_seg`，每个跨相都携带 `T_e ≥ 0`；若 `T_e < 0`，恢复律接管且 `P(fall | REC) ≤ α_rec`；
3. `η_phase ↑ ⇒ k_pac ↓`（单调保守），且 `conflict_flag=True ⇒ λ_risk ≥ 0.9`。

**定理 15（安全地板下的负迁移界）** 设 `L_S` 为 `L`-光滑，步长 `η ≤ ε_floor / (L·||g_S||)`，SFGS 每步投影后满足 `L_S(θ^{t+1}) ≤ L_S(θ^t) + ε_floor`。于是对任意安全任务 `s∈S`：
```
NT_s ≤ ε_floor + O(η·L·d) ，其中 d 为参数维度
```
即安全任务的负迁移被 `ε_floor` 与步长共同封顶；辅助任务仍可承受有界负迁移（允许 `NT_a > 0`），从而保留 MTL 的样本效率收益。

**定理 16（分段证书的拼接与样本复杂度）** 设一条轨迹被切成 `m` 段，每段长度 `≤ H`。若每段证书的失败概率 `≤ δ_seg`，每个转移证书失败概率 `≤ δ_trans`，则整条轨迹证书失败概率 `≤ m(δ_seg + δ_trans)`。相比 SimRAS 单段长时程证书的 `exp` 级误差累积，PACT 把误差从“随 T 指数增长”降为“随 m 线性增长”；同时 MTL 共享骨干使达到同样 `δ_seg` 所需样本从 `N_STL` 降为 `N_MTL ≈ N_STL/√|T_shared|`（任务相关性越高收益越大）。

## 6. 本轮最大风险

**一句话**：PACT 把双足机器人的安全寄托在「相位估计 + 转移预测 + 安全地板负迁移界」三者同时可靠上，但相位定时误差与 reset map 的 Lipschitz 常数在真实接触（滑移、软地、边缘）下可能被严重低估，一旦 `k_guard` 估计偏乐观，系统就会在**未认证的相位边界**上执行动作，而多任务共享骨干又可能把这种错误从辅助任务“平滑”进安全头，最终表现为「证书看似有效、实则在最危险的落地瞬间失效」——这是本轮所有理论依赖的核心假设：**离散相位边界可被在线精确预测，且安全地板的负迁移界在分布外接触条件下仍然成立**。

**次级风险与缓解**：
1. **相位估计抖动**：引入 IMU+足底接触+关节扭矩三源融合，并用 `κ_margin = 3σ` 强制保守；
2. **reset map 建模误差**：PSKB 中记录 `Δ_mismatch`，每次落地后回灌，在线修正 `L_Δ`；
3. **安全地板约束过紧**：`ε_floor` 自适应退火，训练早期放宽、收敛期收紧；
4. **MTL 任务头共振**：对安全头使用独立低秩专家 + 梯度正交正则，避免与地形头共享过多；
5. **恢复律本身未认证**：把 REC 也纳入 HPG 的 guard 集合，恢复动作必须经过 `Cert_seg` 检查。

```python
class HybridPhaseWorldModel(WorldModel):
    def rollout_phase(self, z, act_seq, sigma, k=5):
        preds, crossings = [], []
        for i, a in enumerate(act_seq[:k]):
            q = self.mode_head(z)
            tau, Sig = self.trans_head(z)
            z = self.dyn(z, a, sigma)
            rho = self.safety_head(z, sigma)
            preds.append({'z': z, 'q': q, 'rho': rho,
                          'tau_guard': tau, 'Sigma': Sig})
            if tau <= self.dt:
                crossings.append(i)
                sigma = q.argmax()
        return preds, crossings


def train_mtl_sf(model, batch, eta, eps_floor):

    g_S, g_A = grad(L_S), grad(L_A)
    inner = dot(g_A, g_S)
    if inner < 0:
        g_A = g_A - (inner / (norm(g_S)**2 + 1e-12)) * g_S
    theta_new = model.theta - eta * (g_S + g_A)
    if model.safety_loss(batch, theta_new) > L_S + eps_floor:
        theta_new = backtrack_to_floor(model, theta_new, L_S + eps_floor)
    model.set_theta(theta_new)


# IP-246/247 PAC 前缀 + 转移证书
class PACPrefix:
    def certify(self, A, wm_preds, crossings, joint_post, m_pac, alpha_chunk):
        k_simras = self.simras_prefix(A, joint_post, m_pac, alpha_chunk)
        k_guard = len(wm_preds) if not crossings else crossings[0]
        k_pac = max(0, min(k_simras, k_guard, m_pac))
        if 0 < k_pac == k_guard:
            e = wm_preds[k_pac - 1]['q'].argmax()
            if not self.transfer_ok(wm_preds[k_pac - 1], e):
                k_pac = max(0, k_pac - 1)
        return k_pac

    def transfer_ok(self, pred, e):
        return pred['rho'] - self.L_delta * self.v * pred['eta_t'] \
               - self.L_rho * self.eps_obs >= 0


# IP-250/251 TSC + REC
class TaskSafetyConflictMonitor:
    def score(self, g_S_probe, g_A_probe, sigma_rho):
        cos = dot(g_S_probe, g_A_probe) / (norm(g_S_probe)*norm(g_A_probe)+1e-9)
        return max(0.0, -cos) * (1.0 + sigma_rho)


class ProtectiveRecovery:
    def solve(self, x, p_hat, rho_hat):
        # 四级降级：降 CoM → 加宽支撑 → 停摆动 → 预备坐地
        stage = self.select_stage(rho_hat.margin)
        return self.qp_control(x, p_hat, stage)


# IP-252 PACT 在线一轮
def PACT_round(M, obs):
    p_hat = M.pe.estimate(obs)
    act_seq = M.vista.ach.propose_actions(M.x_prime, steps=5)
    wm_preds, crossings = M.hp_wm.rollout_phase(M.z, act_seq,
                                                p_hat['sigma'], k=5)
    face_gate = M.erg_wm.recognize(obs.img, M.x_prime, act_seq)
    joint_post, _ = M.efs_wm.synthesize(M.rho, face_gate, M.x_prime, act_seq)

    A = M.vista.ach.propose(M.x_prime)
    k_pac = M.pac.certify(A, wm_preds, crossings, joint_post,
                          m_pac=min(5, len(A)), alpha_chunk=M.alpha_chunk)

    z_phase = M.mtl.encode_phase(M.x_prime, p_hat['sigma'])
    rho_hat = M.mtl.head('T_fall')(z_phase)
    rho_cert = M.mtl.head('T_cert')(z_phase)

    conflict = M.tsc.score(M.mtl.grad_S(), M.mtl.grad_A(), rho_hat.var)
    if rho_hat.margin < M.tau_recover or conflict > M.tau_conflict:
        u = M.rec.solve(M.x_prime, p_hat, rho_hat)
        M.cert.mark('conflict', conflict)
        return u, k_pac, conflict, p_hat

    u = M.vista.pi_sigma.prefix_dispatch(A[:k_pac])
    u = u * M.efs_wm.risk_scale(joint_post)
    return u, k_pac, conflict, p_hat
```

## 4. 推导

**引理 13（相位条件证书可靠性）** 若段内 `ρ_σ(x_{t+i})≥0` 且 `k_pac≤k_simras`，则段内不离开 `C_σ`。

**引理 14（冲击放大与定时误差）**
```
|ρ_{σ'}(Δ_e(x)) − ρ_{σ'}(Δ_e(x̂))| ≤ L_ρL_Δ(|δx| + |ẋ̂|η_t)
```
故转移证书必须扣除 `L_Δ|ẋ̂|η_t` 与观测噪声，否则会在落地瞬间假通过。

**引理 15（guard 截断完备性）** `k_pac≤k_guard ⇒` 认证前缀内无未认证相位转移。

**定理 14（PACT 端到端风险一致性）** 在 A87–A91、定义 272–273、引理 13–15 下：
1. `P(fall) ≤ α_chunk+δ_fi+α_emotion+α_wm+α_phase+α_mtl`；
2. 每段携带 `Cert_seg`，每跨相携带 `T_e≥0`；`T_e<0` 时 REC 接管且 `P(fall|REC)≤α_rec`；
3. `η_phase↑ ⇒ k_pac↓`；`conflict_flag=True ⇒ λ_risk≥0.9`。

**定理 15（安全地板负迁移界）** `L_S` 为 L-光滑，`η≤ε_floor/(L||g_S||)`，SFGS 每步满足 `L_S^{t+1}≤L_S^t+ε_floor`，于是 `NT_s≤ε_floor+O(ηLd)`；辅助任务允许有界负迁移。

**定理 16（分段证书拼接与样本复杂度）** 轨迹切成 m 段，`P(cert_fail)≤m(δ_seg+δ_trans)`；相比 SimRAS 的指数累积，PACT 降为线性；MTL 使达到同 δ_seg 的样本量约降为 `N_STL/√|T_shared|`。

## 8. 本轮最大风险

**一句话**：PACT 的安全性同时依赖「相位估计精度」「reset map 的 Lipschitz 常数估计」与「安全地板负迁移界」三条假设，而真实接触中的滑移、软地、边缘会让 `L_Δ` 被显著低估、`k_guard` 被高估；一旦相位边界预测偏乐观，系统就会在**未认证的落地瞬间**执行动作，多任务共享骨干还可能把这一错误从辅助任务“平滑”进安全头，形成「证书看似有效、实则在最危险时刻失效」的假安全——这是本轮全部理论的核心依赖：**离散相位边界可被在线精确预测，且安全地板的负迁移界在分布外接触条件下仍然成立**。
