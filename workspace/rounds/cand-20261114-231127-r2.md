# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「行为树」×「人机协作」）

> R69 把不确定性一分为二，让机器人学会了「问」。但它留下三个未言明的前提：
> (a) **提案即承诺**——流策略采样出哪个模态，就默认可以执行哪个模态；多模态只是「更丰富的候选」，缺少一层显式的、可拒绝、可降级的**承诺结构**。
> (b) **交互是单向的**——VoI 只计算「机器人能从人那里学到什么」，不计算「人能从机器人动作里读懂什么」；好像机器人越会问，协作就越好。
> (c) **权威是固定的**——默认机器人拥有决定权，人在需要时被动回答；但真实人机协作里，「谁说了算」本身是要协商、要交接、要能被否决的变量。
>
> 本轮两个灵感正好各补一块：
> - **行为树**是一台天然的**承诺机器**：它把连续策略的「可能性」变成离散、可检查、可回退的「承诺」，用 Sequence / Fallback / Guard / Timeout 提供 R69 缺失的组合安全与可审计性。它不替代流策略，而是约束流策略的**支撑集**，并在每次模式切换处插入可验证的契约。
> - **人机协作**说明承诺是**共享的**：动作不仅是任务动作，还是给人看的**沟通动作**；可信度不仅取决于证据通道，还取决于人是否听懂了问题、是否过载、是否真的在看；权威必须能被显式交接和否决。
>
> 核心命题：**在 R69 的「提案层」（流匹配多模态策略）与「执行层」之间，插入一个「契约式协作行为树」承诺层：任何模态只有在拿到「提交票据」（证据独立、风险认证、权限允许、可读性达标）后才可执行；交互目标从单向 VoI 升级为双向 MVoI（机器人获得信息 + 人获得可读性）；证据可信度加入「人是否听懂」与「共享上下文相关性」；权威作为一等变量，用同意账本与超时安全回退保证活性。** 命名 **TANDEM-RAS**（Tree-structured, Authority-negotiated, Mutual-legibility Disambiguation & Escalation Machinery）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**求证之后，谁有权拍板？我怎样让这件事对人也是可读、可拒、可追责的**」——协作不是把人的答案喂给机器人，而是把「决定权」本身变成可协商、可审计的状态。

## 0. 直觉与动机

**灵感 1（行为树 → R69 缺的是一台「承诺机器」）**
直觉：流匹配策略像一台**可能性机器**：它告诉你「世界可能是 A 或 B，我可以走左或走右」。但它不告诉你「现在到底承诺哪一条、凭什么承诺、承诺错了怎么退」。R68/R69 用 λ_floor 和 VoI 做了「软化」，却没有一个**离散骨架**来保证：安全回退真的会被触发、每次模式切换真的经过检查、每个动作真的有人授权。行为树恰好是这个骨架：Sequence 表达「先看再问再做」，Fallback 表达「主方案不行就退到更保守方案」，Guard 表达「前置条件不满足就不许进」，Timeout 表达「人不回应就退回安全态」。更关键的是，BT 是**可读的**：人、审计器、形式化工具看的是同一棵树，而不是一个黑箱策略的隐空间。于是 R69 的「幻觉模态」有了结构性防线：**幻觉模态可以存在，但拿不到提交票据；它最多触发一次询问或一次保守回退，不能直接变成动作。**

**灵感 2（人机协作 → 动作同时是「做事」和「说话」）**
直觉：R69 把交互当成信息动作（看、问、触），把其余动作当任务动作。但在人身边，**每个动作都在被人读**：你突然加速，人读到「它要抢」；你停顿，人读到「它犹豫」；你伸手，人读到「它要去拿那个」。所以任务动作天然带有**沟通副作用**，可读性不是可选的附加项，而是协作的安全约束。一个信息上最优的探询动作，可能在人看来像故障；一个最可读的动作，可能对机器人毫无信息。R70 必须把「可读性」提升为与 VoI 并列的目标，并允许行为树插入 **announce / slow / point / explain** 这类「说明性节点」——即「先说再做」和「边做边说」两种模板。

**灵感 3（权威是一等变量 → 从「机器人问」到「谁拍板」）**
直觉：R69 的 MINT 默认机器人决定何时问、问什么；人只是证据源。但协作的核心恰恰是**混合主动（mixed initiative）**：有时人该接管，有时机器人该请求许可，有时该共同决定，有时该升级给第三方。把「谁有权」写死在代码里，会在两种情况下出错：人以为机器人会停，机器人以为人会接——**权威死锁**；或者机器人越权执行，人来不及否决。R70 把权限 `auth ∈ {robot, human, shared, escalate}` 作为行为树节点的契约字段，并引入**同意账本**与**超时安全回退**：没得到同意，就不算授权；人不回应，默认拒绝而非默认同意。这既是安全，也是活性（liveness）。

**灵感 4（信任是预算，不是要最大化的信念）**
直觉：R69 敢问，是因为它假设人答得对。但人会没听懂、会累、会过度信任机器人、会敷衍。把人当成「可靠 oracle」是危险的；反过来，永远不信人又会让协作退化为遥控。正确的姿态与 R68 的 λ_floor 同构：**安全决策里只使用人可靠性的下置信界（LCB），绝不用点估计**。信任高时可以让协作更流畅（效率），但安全阈值不能因为「我很信任他」而放松。信任校准的目标是**让人和机器对彼此能力的判断一致**，不是让人更信任机器。

**灵感 5（共享上下文 → 证据独立性会被「共同看见」骗过）**
直觉：R69 的证据纪律是「k 个正交源一致才定案」。在 HRC 里，机器人和人常常看同一块屏幕、同一个场景、同一段历史；他们的错误会**相关**。一个被污染的共享观测，会同时污染机器人和人的判断，于是「两个来源一致」其实是「同一个错误说了两遍」。所以独立性必须在 **provenance（物理通道 × 视角 × 数据分片 × 标定 × 共享上下文）** 上度量，并显式扣除共享相关性。否则 R69 的 k 一致纪律在协作场景里会被共同模态错误轻易击穿。

**灵感 6（理论姿态与新的最大风险）**
直觉：TANDEM 必须是 FLUID 与 R68 的严格泛化：单叶、恒真契约、无人、零共享相关时逐指令等于 R69；不交互时逐指令等于 R68。安全侧只加不减。但这也带来一个更深的风险：**行为树的「可验证」只是把不确定性从策略层搬到了人模型 / 可读性 / 信任估计层**。如果这些估计错了，BT 会以完全合法、完全可审计的方式，把决定权交给一个过载的人，或把一个幻觉模态包装成「已获同意」。**形式化外壳可能把「未知」洗成「已授权」——这比 R69 的「问错」更危险，因为它看起来没有错。**

## 1. 形式化定义（增量：定义 310–326）

**定义 310（TANDEM-RAS 总览）** TANDEM-RAS = (CBT, FLOW†, MVOI, LEG, HEC, AUTH, RAS-WM‡)。三不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i；BT 结构与信任下界只在离线/换装窗更新）；
(ii) **承诺需票据**：任何任务动作或信息动作在执行前必须获得契约提交票据 CCT（定义 313），票据绑定证据充分性、风险认证、权限归属与可读性；无票据即不执行；
(iii) **人的授权不可被默认**：任何委托、交接、询问都必须有显式同意语义与有界超时；超时进入安全回退，而非默认同意。

**定义 311（契约式协作行为树 CBT）** CBT 是一棵有序有根树 T=(N,E,root)，节点类型 type(n) ∈ {Sequence(→), Fallback(?), Parallel(⇉), Guard, Action, Ask, Hold, Defer, Handover, Monitor, Announce}。每个节点携带契约
`C_n = (Pre_n, Post_n, Inv_n, auth_n, evid_n, budget_n, fallback_n, ℓ_n)`。
节点状态扩展为 {Success, Failure, Running, Waiting, Disputed, Escalated}；`Waiting` 用于等待人类回答/接管，`Disputed` 用于证据冲突，`Escalated` 用于运行时不变式被破坏后的交权。tick 是偏函数：只有 `Pre_n` 成立且 `auth_n` 允许时才可能进入 Running。

**定义 312（契约与权限）** `auth_n ∈ {R, H, S, E}` 分别表示机器人、人类、共识、升级第三方拥有决定权。`Pre_n / Post_n` 是信念状态 `b_t` 与世界状态 `s_t` 上的谓词集合；`Inv_n` 包含继承自 R68 的 C-RAS-WM 安全包络。契约 **sound** 当且仅当：在 `Pre_n` 成立且 `Inv_n` 全程保持的前提下，执行 n 必然得到 `Post_n` 或进入安全 Failure。`ℓ_n` 是可读性下限（定义 316）。

**定义 313（模式提交票据 CCT）** 对流策略提出的模态 `m_k`（权重 `w_k`、动作 `a_k`），BT 仅当以下条件同时成立时签发票据
`τ = (m_k, cert, auth, justify, evid_hash)`：
1. `w_k ≥ w_min` 且有效独立证据数 `k_eff ≥ k_req`（定义 318）；
2. `c_ras_wm.certify(a_k, s) = True`，且风险 `risk(a_k) ≤ ε`；
3. `auth_n` 允许当前提交者（R/H/S/E 匹配）；
4. 若在工作共享区，可读性 `Leg(m_k) ≥ ℓ_n` 或已插入 Announce 节点；
5. 人类否决集 `V` 为空（定义 321）。
任一不满足 ⇒ 不签发，BT 返回 Wait / Ask / Hold / Fallback；**任何未签发票据的模态都不能进入执行器**。

**定义 314（提案—承诺分离）** R69 的流策略给出提案分布 `P_prop(m|o)`；BT 给出承诺核 `K_commit(m | b, ticket)`，其支撑集仅含可获票据的模态。执行分布
`P_exec(m|o) = K_commit(m|b,ticket) · P_prop(m|o)`。
当 CBT 退化为单个恒真契约的 Action 叶、且无人、无共享相关时，`K_commit ≡ 1`，故 `P_exec = P_prop`，逐指令等于 FLUID-RAS。

**定义 315（双向信息价值 MVOI）** 机器人信息价值
`VoI_R(g) = H(M|o) − E_{y~p(·|o,do(g))}[H(M|o,y)]`；
人类可读性价值
`VoI_H(g) = H(H_intent | h_t) − E_{obs(g)}[H(H_intent | h_t, obs(g))]`，
其中 `h_t` 是从人的注视、停顿、接管、提问估计出的人类信念。再加「可协助性」项：人读懂机器人意图后，其碰撞/过载风险下降的期望 `A(g)`。定义
`MVoI(g) = VoI_R(g) + λ_H·VoI_H(g) + λ_A·A(g) − c_act(g) − c_cog(g) − λ_T·trust_risk(g)`。
选择 `g* = argmax_g MVoI(g)`，s.t. 安全认证、交互预算、可读性约束；若 `max MVoI ≤ 0` ⇒ 不交互，退回 R68/R69 边界。与 R69 的区别：R69 的 `g*` 是 `VoI_R − c`，这里是**双向**价值，且显式计入「会让人更困惑」的负价值。

**定义 316（可读性约束与说明性动作）** 可读性
`Leg(g) = −E_{m}[KL(p(human predicts m | obs(g)) ‖ δ_m)]`
（负的预测散度，越大越易读；也可用互信息 `I(H_pred; M)` 的负数版本）。工作共享区强制 `Leg ≥ ℓ_min`。若信息最优动作违反它，BT 提供两种组合模板：
- **Explain-then-Act**：`Sequence(Announce(意图), Action(g))`，用一次低带宽说明换取可读性；
- **Act-Legibly**：在 `g` 上加入可见的减速/指向/注视前导，`g' = g ⊕ legibility_shaping`，代价是时间与信息量。
两个模板都进入 MVOI 的候选集，可读性不是事后修饰，而是**决策变量**。

**定义 317（人证据可信额度 HEC）** 人的回答可信额度
`T_H = clip( f(U(q), comp_κ, 1−L_h, 1−ρ_shared), 0, 1 )`，
其中 `U(q)` 为问题可理解度（回述、延迟、追问率估计）、`comp_κ` 为该覆盖单元上人的胜任度、`L_h` 为认知负荷、`ρ_shared` 为与机器人共享上下文的相关性。人证据进入 Bayes 更新时取温度 `T_H`：`p(y|m)^{T_H}`。若 `U(q) < U_min`，回答被标记为 **非证据**（not evidence），既不能支持也不能反驳；系统只能换问法或转其他通道，**不得把「没听懂后的猜测」当成否定证据**。人的「我不知道」是有效信息，必须被接受，不得被追问施压。

**定义 318（共享上下文下的有效独立证据数）** 证据 `i` 的 provenance 相关
`ρ(i,j) = 1 − (1−ρ_perc)(1−ρ_view)(1−ρ_cal)(1−ρ_data)(1−ρ_model)`，
其中 `ρ_perc` 由共享观测/同一相机/同一场景图给出，`ρ_view` 由产生证据的视角动作耦合给出，`ρ_cal` 由共享标定参数给出，`ρ_data` 由训练分片重叠给出，`ρ_model` 由共享策略/语言模型给出。有效独立证据数
`k_eff = (Σ_i T_i)² / Σ_{i,j} T_i T_j ρ(i,j)`，
其中 `T_i` 对机器人证据取 R69 的模态可信额度，对人证据取 `T_H`。**人和机器人看同一场景得出的「两个一致判断」，其 `ρ_perc→1`，对 `k_eff` 的贡献趋近于 1，而不是 2。**

**定义 319（信任—胜任度联合状态与下界使用）** 联合信任状态 `(τ_{R→H}, τ_{H→R})`：前者是机器人估计的人可靠度，后者是人估计的机器人可靠度（由接管率、响应延迟、注视、纠错行为在线估计）。安全决策只使用下置信界
`τ_{R→H} = LCB_{1−α}(ρ_H)`；
人的信任 `τ_{H→R}` 只用于**设计沟通**（解释密度、提示频率、可读性下限），**不得用于放松任何安全阈值**。定义过度信任旗标 `OT = 1[τ_{H→R} > ρ_R + δ]`，用于触发「主动暴露不确定性」而非「利用信任」。

**定义 320（权限分配与协商）** 权限是决策变量 `a_auth ∈ {R,H,S,E}`，由 BT 节点的 `auth_n` 与运行时协商决定。`Shared` 需要共识谓词（双方一致或人在超时内弃权）；`Handover` 需要同时满足：(a) 接收方胜任度下界达标；(b) 接收方注意力在线（注视/应答）；(c) 世界处于交接安全态（R68 不变式）；(d) 显式接受或超时转入安全回退。安全关键动作处于 Running 时不得无 fallback 交接。

**定义 321（否决与同意语义）** 人否决 `V ∈ {stop, hold, override, take-over}`。安全关键否决对机器人**不可覆盖**，立即触发最保守回退；机器人可以请求，但不能强制。定义「同意账本」记录每次 offer / accept / decline / timeout / veto 及其哈希；不回应在超时后视为拒绝。账本进入证书，任何越权执行都可追责。

**定义 322（协作节奏与轮次）** 回合状态机 `{robot-active, human-active, shared, paused}`。转移仅在**同步点**（安全态）发生，紧急情况例外。引入「交互时限」：询问与交接都有 deadline；超时按定义 321 视为拒绝，并触发单调安全回退。**禁止** R69 式「问完立即按答案执行」的竞态——回答必须先并入信念、再重新求票据。

**定义 323（单调安全回退序）** 每个子树有有序回退链 `f_0 ≻ f_1 ≻ … ≻ f_m`，满足：风险上界非增、动作表达力非增、对许可的依赖非增；最后一档 `f_m` 恒为 R68 的纯保守策略。Fallback 节点从左到右 tick，且回退序在组合下保持（定理 18）。这保证「越退越安全」，而不是「越退越乱」。

**定义 324（协作证书 J_TANDEM）** 
`J_TANDEM = (J_FLUID, cbt_hash, commit_tickets, authority_log, consent_ledger, legibility_min, human_evidence_quota, k_eff, shared_rho, trust_lcb, interaction_timeline, tandem_ver)`。
Valid ⇔ `Valid(J_FLUID)` ∧ 每个执行动作都有 CCT ∧ 非可覆盖否决未被违反 ∧ 每次交接都有同意 ∨ 超时回退 ∧ 共享区可读性达标 ∧ 提交模态的 `k_eff ≥ k_req` ∧ 安全决策使用的是信任 LCB 而非点估计。

**定义 325（协作干扰集 ℰ_TANDEM）** `ℰ_TANDEM = ℰ_FLUID × ℰ_collab`，其中 ℰ_collab 包含：
(a) **人误解/过载**——问题没说清导致「自信地答错」；
(b) **权威混淆**——双方都以为对方在控制，导致都不动或都动；
(c) **信任操纵**——机器人夸大置信、人假装在线、社交工程式诱导；
(d) **共享上下文投毒**——污染共同观测，使相关错误伪装成独立一致；
(e) **行为树注入/错配**——恶意或错误节点、guard 被绕过、回退链耗尽、并行节点资源冲突；
(f) **可读性作假**——动作«看起来»安全、可理解，实际意图不同（legibility gaming）。

**定义 326（行为树审计与可证明降级）** TAuditor 静态检查：每条 CCT 的证据独立性是否达标、每条回退链是否单调、是否存在恒真 guard、是否有不可达的安全回退、权限图是否无环、同意账本是否自洽；运行时每 tick 检查 `Inv_n`。任一违反 ⇒ 状态置 `Escalated`，绝不允许「带着违规继续跑」。审计产物是一份附在 `J_TANDEM` 上的证明草图（proof sketch），可被人或形式化工具复核。

## 2. 关键算法骨架

```python
# IP-264 CBT：契约式协作行为树的一次 tick（带新状态与回退）
class CBT:
    def tick(self, n, b, s, t):
        if not n.contract.pre(b, s):          # Guard 语义内置
            return self.safe_fail(n, b, s)
        if n.type == "Sequence":
            for c in n.children:
                st = self.tick(c, b, s, t)
                if st != SUCCESS:
                    return self.fallback(c, b, s)
            return SUCCESS
        if n.type == "Fallback":              # children 已按单调回退序排列
            for c in n.children:
                if self.tick(c, b, s, t) == SUCCESS:
                    return SUCCESS
            return self.safe_fail(n, b, s)
        if n.type == "Parallel":              # 仅允许 non-interfering 子树
            return self.tick_parallel(n, b, s, t)
        if n.type == "Action":
            return self.act(n, b, s, t)
        if n.type in ("Ask", "Hold", "Defer", "Handover", "Announce"):
            return self.interact(n, b, s, t)
        if n.type == "Monitor":
            return SUCCESS if n.contract.inv(b, s) else ESCALATE

    def safe_fail(self, n, b, s):
        return self.fallback(n, b, s) if n.fallback else FAILURE

    def fallback(self, n, b, s):              # 单调回退序，末档 = R68 纯保守
        for f in n.contract.fallback_chain:
            if f.pre(b, s): return self.tick(f, b, s, monotonic_guard=True)
        return self.tick_r68_conservative(b, s)
```

## 3. 推导

**引理 19（提案—承诺的幻觉隔离）** 设流模型以概率 `ε_h` 生成一个不对应任何真实状态/意图的模态 `m_h`。若执行必须持有 CCT，且票据要求 `k_eff ≥ k_req ≥ 2` 的（共享相关校正后的）独立证据，则 `m_h` 获得票据的概率不超过 `P(至少 k_req 个独立证据同时虚假一致)`；在单源欺骗率 `δ_p`、共享相关 `ρ` 下该概率 ≤ `δ_p·ρ^{k_req−1} + ε_σ`。**系**：R69 的「问错」在 TANDEM 里最多退化为「浪费一次询问 / 一次保守回退」，不会直接变成错误动作；幻觉的唯一合法后果是 Wait/Ask，而不是执行。

**引理 20（双向价值的信息—可读性张力）** 存在信念状态 `b`，使机器人信息最优动作 `g_R = argmax VoI_R` 与可读性最优动作 `g_L = argmax Leg` 满足 `g_R ≠ g_L`，且二者在人类可读性上的差距随「人机感知分歧」单调增大。故不存在单一标量目标能同时最优；BT 必须按「误解代价」选择模板：当共享区碰撞/协作代价 `c_mis` 高时，Explain-then-Act 的 MVoI 可超过纯信息动作，即使后者 `VoI_R` 更高。**系**：可读性不是 VoI 的加项，而是与 VoI 竞争预算的**第二目标**；这正是 R69 单向 VoI 无法表达的。

**引理 21（共享证据的相关性收缩）** 若人证据与机器人证据共享同一观测，`ρ_perc ≥ ρ_0`，则对任意权重都有
`k_eff ≤ 1 / (ρ_0 + (1−ρ_0)/k) < k`，
其中 `k` 为名义来源数。**系**：一个被污染的共享观测可使「k 个来源一致」退化为「1 个错误被复制 k 次」；R69 的证据纪律在 HRC 中必须用 `k_eff` 替换 `k`，否则共同模态错误可稳定通过门槛。这是 R69 最脆弱处在协作场景的镜像。

**引理 22（信任下界的安全性）** 若机器人在一切涉及委托或人证据加权的决策中只使用 `τ = LCB_{1−α}(ρ_H)`，则按真实可靠度 `ρ_H` 实现的期望风险不超过规划器按 `τ` 计算的风险，概率至少 `1−α`。故保守信任不可被「高估人」攻击；代价是可能低估人类可用性，产生**保守—利用权衡**，该权衡不能靠更好的估计消除，只能靠降低估计不确定性来缓解。

**定理 18（契约组合的安全性）** 在假设 A99–A102 下：
A99 每个叶节点契约 sound；A100 每条回退链单调（定义 323）；A101 Guard 可判定且在每个 tick 内求值；A102 Parallel 子树的共享资源互不干扰（non-interference）。
则整棵 CBT 执行的动作序列满足全局安全包络；任一节点 Failure/Escalated 时，树进入不弱于当前的安全回退。证明：对树结构归纳。Sequence 的安全由各子契约的 Post→Pre 传递保证；Fallback 由单调回退序保证风险非增；Parallel 由非干扰保证不变式可组合；Guard/Inv 的 tick 检查保证前提不成立时不进入危险分支。**这是 R69 单体策略不具备的组合安全。**

**定理 19（对 R69 与 R68 的严格包含）** 退化 CBT（单 Action 叶、恒真契约、无共享区、`k_req=1`、无人类、`ρ_shared=0`）使 `P_exec = P_prop`，逐指令等于 FLUID-RAS；在此基础上关闭交互（`MVoI ≤ 0`）并令末档回退为 R68，则逐指令等于 CALM-RAS。反向，TANDEM 的每个安全约束在退化时都不增加风险。故 TANDEM 是 R69/R68 的保守扩展：**安全侧只增不减，效率侧通过可读性与协商获得额外收益，但从不以放松安全为代价。**

**定理 20（协作活性与无权威死锁）** 在人有界响应时间、回合状态机（定义 322）、超时视为拒绝（定义 321）且机器人不得在无 fallback 时持有安全关键动作的前提下，任意交互在有限 tick 内到达 {票据执行, 安全回退, 人类显式接管, 升级} 之一；不存在「双方都等对方」的无限等待状态。证明：定义待决义务的 well-founded 测度（未决 offer 数 + 剩余 deadline 的字典序），每次 tick 要么消耗义务、要么在 deadline 后强制转移；超时与回退链保证测度严格下降。

## 6. 本轮最大风险

**一句话**：TANDEM 把安全性寄托在「契约成立」上，但契约里最关键的三样东西——人的胜任度下界、可读性估计、人机共享相关性——**本身就是学出来且无法被行为树验证的**；一旦它们错了，行为树会以完全合法、完全可审计的方式，把决定权交给一个过载或误解的人，或给一个幻觉模态盖上「已获同意」的章。**形式化外壳最大的危险不是不够严，而是把「未知」洗成「已授权」——看起来最可靠的错误，比看起来可疑的错误更难被人类拦截。**

**次级风险与缓解**：
1. **契约 soundness 依赖人模型** → 只用 LCB + 离线对抗校准 + E309，且人模型失配时强制降级；
2. **可读性可被「演」** → 可读性与真实意图的一致性用独立行为通道交叉验证（E312）、ℰ_collab 对抗训练；
3. **共享共模投毒** → `k_eff` 显式扣除共享相关（引理 21）+ 至少一个物理独立通道；
4. **权威死锁/交接竞态** → 超时视为拒绝 + 单调回退 + 定理 20 的活性检查；
5. **行为树自身被注入/配错** → 静态审计（定义 326）+ 运行时 Inv 监控 + 回退链可达性证明；
6. **过度形式化扼杀协作柔性** → 保留 Defer/Shared/Escalate 与人类否决；把 BT 当「安全下限」而非「交互脚本」。

## 2. 形式化定义（要点版）

**定义 310（总览与三不变式）** `TANDEM-RAS = (CBT, FLOW†, MVOI, LEG, HEC, AUTH, RAS-WM‡)`；实时流零学习写操作；承诺需票据；人的授权不可默认（超时 = 拒绝）。

**定义 311–312（CBT 与契约）** 节点类型含 Sequence / Fallback / Parallel / Guard / Action / Ask / Hold / Defer / Handover / Monitor / Announce；每节点带 `(Pre, Post, Inv, auth, evid, budget, fallback, ℓ)`；状态扩展 Waiting / Disputed / Escalated；契约 sound ⇔ 前置成立且不变式保持 ⇒ 后置或安全 Failure。

**定义 313–314（票据与提案—承诺分离）** CCT 需同时满足：`w≥w_min ∧ k_eff≥k_req ∧ 风险认证 ∧ 权限匹配 ∧ 可读性达标 ∧ 无否决`；执行分布 `P_exec = K_commit·P_prop`，单叶恒真契约时 `P_exec=P_prop` ⇒ R69。

**定义 315–316（MVOI 与可读性）** `MVoI = VoI_R + λ_H·VoI_H + λ_A·A − c_act − c_cog − λ_T·trust_risk`；共享区强制 `Leg≥ℓ_min`；Explain-then-Act 与 Act-Legibly 两种模板进入候选集。

**定义 317（HEC）** 人证据温度 `T_H=f(U,comp,1−L,1−ρ_shared)`；`U<U_min` 标记为非证据（不得当反对证据）；「我不知道」必须被接受。

**定义 318（共享上下文 k_eff）** provenance 相关包含感知/视角/标定/数据/模型五项；`k_eff` 替换名义 `k`；人和机器看同一场景的一致判断贡献趋近 1。

**定义 319–320（信任与权限）** 安全决策只用 `τ_{R→H}=LCB(ρ_H)`；人的信任只用于沟通设计；`auth` 由节点与协商决定；Shared 需共识，Handover 需胜任 + 在线 + 安全态 + 同意/超时回退。

**定义 321–322（否决与节奏）** 安全关键否决不可覆盖；同意账本记录 offer/accept/decline/timeout/veto；回合只在同步点转移；询问/交接有 deadline，超时视为拒绝。

**定义 323–324（单调回退与证书）** 回退链风险非增、表达力非增、依赖非增，末档 = R68；`J_TANDEM` 并入票据、权限、账本、可读性、HEC、k_eff、trust_lcb。

**定义 325–326（干扰集与审计）** `ℰ_TANDEM = ℰ_FLUID × ℰ_collab`（误解、权威混淆、信任操纵、共模投毒、树注入、可读性作假）；TAuditor 静态检查 + 运行时 Inv 监控，违规即 Escalated，绝不带病继续。

```python
# IP-264 CBT tick：契约前置 + 单调回退
class CBT:
    def tick(self, n, b, s, t):
        if not n.contract.pre(b, s):
            return self.safe_fail(n, b, s)
        if n.type == "Sequence":
            for c in n.children:
                if self.tick(c, b, s, t) != SUCCESS:
                    return self.fallback(c, b, s)
            return SUCCESS
        if n.type == "Fallback":                  # 子节点按单调回退序
            for c in n.children:
                if self.tick(c, b, s, t) == SUCCESS: return SUCCESS
            return self.safe_fail(n, b, s)
        if n.type == "Action":  return self.act(n, b, s, t)
        if n.type in ("Ask","Hold","Defer","Handover","Announce"):
            return self.interact(n, b, s, t)
        if n.type == "Monitor":
            return SUCCESS if n.contract.inv(b, s) else ESCALATE

    def fallback(self, n, b, s):                  # 末档 = R68 纯保守
        for f in n.contract.fallback_chain:
            if f.pre(b, s): return self.tick(f, b, s, monotonic_guard=True)
        return self.tick_r68_conservative(b, s)

# IP-266 CCT：幻觉模态的结构性隔离
def commit_ticket(mode, w, b, s, contract):
    ev = gather_evidence(mode, b, s)
    k_eff = effective_independent(ev)
    if w < W_MIN or k_eff < contract.k_req:            return None
    if not c_ras_wm.certify(mode.action, s):           return None
    if not contract.auth.allows(contract.owner):       return None
    if contract.in_shared_space and legibility(mode,b,s) < contract.ell_min:
        return None                                    # 先 Announce 再重试
    if human_veto(b):                                   return None
    return Ticket(mode, ev_hash=k_eff, contract=contract,
                  justify=explain(mode, b))

# IP-267 MVOI：机器人信息 + 人类可读性 + 可协助性
def mv_voi(g, b, s):
    voi_r = entropy(b.M) - expected_entropy(b.M, g, s)
    voi_h = entropy(b.H_intent) - expected_entropy(b.H_intent, g, s)
    assist = expected_risk_drop_from_understanding(g, b, s)
    return (voi_r + LAM_H*voi_h + LAM_A*assist
            - c_act(g) - c_cog(g) - LAM_T*trust_risk(g, b))

# IP-269/270 HEC 与共享相关 k_eff
def human_evidence_quota(q, b, s):
    U = question_understanding(q, b.human)
    if U < U_MIN: return NON_EVIDENCE        # 没听懂 ≠ 否定证据
    return clip(f(U, comp(b.human), 1-b.load, 1-shared_rho(b)), 0, 1)

def effective_independent(evidence):
    T = [e.quota for e in evidence]
    R = provenance_corr_matrix(evidence)     # perc/view/cal/data/model
    return (sum(T)**2) / sum(T[i]*T[j]*R[i,j]
                             for i in range(len(T)) for j in range(len(T)))

# IP-271/272 权威协商 + 同意账本 + 超时安全回退
def interact(node, b, s, t):
    if node.type == "Announce":
        emit_legible_intent(node.intent); return SUCCESS
    if node.type == "Ask":
        if not consume_budget(node): return FAILURE
        q = simplify(node.instantiate(b)) if not legible_question(q, b) else q
        offer(q); b.consent.log("ask_offer", q, t)
        ans = await_answer(deadline=node.deadline)      # 超时 = 拒绝
        if ans is None: return node.fallback_tick(b, s)
        T_H = human_evidence_quota(q, b, s)
        if T_H is NON_EVIDENCE: return node.retry_with_simpler_question(b, s)
        b.update_human(ans, quota=T_H); b.consent.log("answer", ans, T_H, t)
        return SUCCESS
    if node.type == "Handover":
        if not handover_safe(s, b) or not trust_lcb_ok(b): return node.fallback_tick(b, s)
        offer_handover(); b.consent.log("handover_offer", t)
        if accept_within(node.deadline):
            b.authority = HUMAN; b.consent.log("accept", t); return SUCCESS
        b.consent.log("timeout_decline", t); return node.fallback_tick(b, s)

# IP-277 主闭环：提案 → 票据 → 可读性 → 认证 → 权威 → 审计
def TANDEM_round(M, obs, tree):
    b = M.belief.update(obs); s = M.world_state
    node = tree.select(b, s)
    modes, w = M.flow.propose(obs, node.skill, K=M.adaptive_K(b))
    U_ale, U_epi = M.aud.decompose(modes, w)
    mode, ticket = None, None
    for m in rank(modes, w):
        ticket = commit_ticket(m, w[m], b, s, node.contract)
        if ticket: mode = m; node.ticket = ticket; break
    if mode is None: return tree.tick(node, b, s)       # Ask/Hold/Fallback
    if node.in_shared_space and legibility(mode, b, s) < node.contract.ell_min:
        tree.tick(Announce(node.intent), b, s)
        if human_veto(b): return tree.fallback(node, b, s)
    k = M.c_ras_wm.certified_prefix(mode.action, s, M.wm_preds)
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + (0.0 if ticket else U_epi)))
    if ticket.auth in (HUMAN, SHARED) and tree.tick(Handover(node), b, s) != SUCCESS:
        return tree.fallback(node, b, s)
    M.t_auditor.submit(tree, ticket, b.consent, b.human_evidence_log)
    return k, lam, mode, ticket
```

## 4. 推导

**引理 19（幻觉隔离）** 流模型生成非真实模态 `m_h` 的概率为 `ε_h`；票据要求 `k_eff≥k_req≥2` 的独立证据，则 `m_h` 获票概率 ≤ `δ_p·ρ^{k_req−1}+ε_σ`。故 R69 的「问错即执行」在 TANDEM 里最多退化为「浪费一次询问/一次保守回退」。系：幻觉的合法后果只有 Wait/Ask，没有执行。

**引理 20（双向价值张力）** 存在状态使 `argmax VoI_R ≠ argmax Leg`，且两者差距随人机感知分歧单调增大；当共享区误解代价高时，Explain-then-Act 的 MVoI 可超过纯信息动作。系：可读性是与 VoI 竞争预算的第二目标，不是加项。

**引理 21（共享证据收缩）** 若 `ρ_perc ≥ ρ_0`，则 `k_eff ≤ 1/(ρ_0+(1−ρ_0)/k) < k`。系：一个被污染的共享观测可让「k 源一致」退化为「1 个错误复制 k 次」；R69 的 `k` 必须换成 `k_eff`。

**引理 22（信任下界安全性）** 只用 `τ=LCB_{1−α}(ρ_H)` 时，真实风险 ≤ 按 τ 规划的风险（概率 ≥1−α）；保守信任不可被高估人攻击，代价是保守—利用权衡，只能靠降低估计不确定性缓解。

**定理 18（契约组合安全）** 在 A99–A102（叶契约 sound、回退链单调、guard 可判定、Parallel 非干扰）下，整棵 CBT 满足全局安全包络；任一节点失败/升级时进入不弱于当前的安全回退。证明：对树结构归纳，Sequence 用 Post→Pre 传递，Fallback 用单调回退，Parallel 用非干扰组合 Inv。

**定理 19（严格包含 R69/R68）** 单叶恒真契约、无人、零共享相关、`k_req=1` 时 `P_exec=P_prop`，逐指令等于 FLUID-RAS；关闭交互并令末档为 R68 时逐指令等于 CALM-RAS。TANDEM 安全侧只增不减。

**定理 20（活性与无死锁）** 在有界人类响应、超时视为拒绝、且机器人不在无 fallback 时持有安全关键动作的前提下，任意交互在有限 tick 内到达 {执行, 安全回退, 人类接管, 升级}；不存在双方无限互等。证明：以待决 offer 数与剩余 deadline 的字典序为 well-founded 测度，每 tick 严格下降。

## 7. 本轮最大风险

**一句话**：TANDEM 把安全性寄托在「契约成立」上，但契约里最关键的三样东西——人的胜任度下界、可读性估计、人机共享相关性——本身是学出来且无法被行为树验证的；一旦它们错了，行为树会以完全合法、完全可审计的方式，把决定权交给一个过载或误解的人，或给一个幻觉模态盖上「已获同意」的章。**形式化外壳最大的危险不是不够严，而是把「未知」洗成「已授权」——看起来最可靠的错误，比看起来可疑的错误更难被人类拦截。**

**次级风险与缓解**：人模型失配（LCB + 对抗校准 + 强制降级）；可读性被「演」（独立行为通道交叉验证 + 对抗训练）；共享共模投毒（`k_eff` 扣除共享相关 + 至少一个物理独立通道）；权威死锁/竞态（超时视为拒绝 + 单调回退 + 定理 20）；树注入/配错（静态审计 + Inv 监控 + 回退可达性证明）；过度形式化（保留 Defer/Shared/Escalate 与人类否决，把 BT 当安全下限而非交互脚本）。
