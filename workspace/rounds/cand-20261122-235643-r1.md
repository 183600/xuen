## 0. 本轮增量：从「检测并重试」到「定位并治疗」

一句话：**第 2 轮把执行栈做成了流水线（路标 → 伺服 → 断言），本轮把它升级为「带契约的技能图 + 残差诊断器」——流水线只能告诉你「这一步没过」，技能图 + 诊断器能告诉你「哪个技能、哪条契约、哪种故障、该用哪种恢复」。**

| # | 增量 | 方法来源（非网络核实） | 对策略的影响 |
|---|---|---|---|
| M1 | **技能组合**：技能 = 可复用、可组合的 option/契约；任务 = 技能图上的计划 | options 框架 / HTN / 行为树 / 设计契约 | IP-09 的线性路标序列升级为**技能契约图（IP-13）**；失败获得「节点 + 契约条款」坐标 |

**本轮核心主张**：在「数据同质、底座趋同」的赛场上，**可诊断性（diagnosability）** 是一种被低估的护城河——它要求契约工程、真机故障注入与残差标定同时做对，抄起来比换底座慢得多；而且它直接决定「恢复是否安全」。

## 1. 两个灵感的第一性原理

### 灵感 1 ·「技能组合」→ 任务不是一条轨迹，而是技能图上的一个计划

**直觉**：人类学新任务很少从零学一条完整轨迹；更常见的是「把已会的动作重新编排」——抓起 → 移动 → 对齐 → 插入 → 松手。若把每个动作做成带**前置条件 / 后置条件 / 不变式**的技能，则：

- 新任务 = 已知技能的新组合 ⇒ **组合泛化**（compositional generalization）；
- 组合的正确性可被契约逐段检查 ⇒ 失败可定位到「哪个技能、哪条契约」；
- 技能可顺序 / 并行 / 分支 / 重试 ⇒ 执行栈从线性序列升级为图。

**严谨化**：把技能写成契约（U16），把任务写成组合项（U17）。组合可靠性由「后置 ⇒ 前置」的传递性保证（L11）；样本效率来自「学 m 个技能而非最多 m^K 个任务」（L12）。关键风险是**契约误设**：契约太松 → 诊断没有坐标；太紧 → 把 VLA 的合法灵活性判成故障。

**与第 2 轮的关系**：第 2 轮 IP-09 的「路标序列」本质是 `seq` 组合的特例；本轮把它一般化，并给每个路标补上机器可检查的契约。IP-01 的 SkillToken-MoE 也从「任务 token × 阶段 token」升级为「技能节点 token × 契约状态」。

### 灵感 2 ·「故障诊断」→ 检测只是第一步，隔离与识别才决定恢复

**直觉**：医生不会「发烧就重试」；流程是「症状 → 假设 → 检查 → 定位 → 治疗」。机器人当前栈只有「症状」（断言失败）和「盲目治疗」（重抓 / 重试）。同一个「插入失败」可能来自：抓握滑移、物体位姿偏差、腕部遮挡、标定漂移、通信延迟、关节饱和——**不同病因需要完全不同的恢复**；盲目重试不仅低效，还可能把「可恢复的偏移」变成「碰撞 / 掉落」。

**严谨化**（FDI 三层次）：

1. **检测**：残差 `r_k` 超阈值（第 2 轮断言器已覆盖一部分）；
2. **隔离**：在故障集合 `F` 上定位 `f`（靠故障签名矩阵 `S`，U19）；
3. **识别**：估计故障幅值 / 方向（如偏移 1.2 cm、延迟 80 ms），供恢复参数化。

可隔离性有信息下界：若两个故障的残差分布 TV 距离为 ε，任何诊断器的两类错误率之和 ≥ 1−ε（L13）。**不能隔离的故障，不允许触发定向恢复**（P11）——只能走安全兜底。

**与第 2 轮的关系**：IP-02 的「抓握确认」是检测器的一个通道；IP-06 的「六因子失败分解」是离线诊断；本轮把二者统一为在线残差诊断器，并新增「恢复选择」这一环。

### 灵感 1 × 灵感 2 的合成：组合契约 + 残差诊断 = 运行时可验证的「解剖学 + 病理学」

- 技能图给**解剖坐标**（在哪个节点、哪条边、哪条契约）；
- 残差给**病理证据**（哪种故障模式、多大置信度）；
- 二者相乘得到诊断后验 `p(f, node | r)`，恢复策略据此选择（U20）。

这正是「可诊断性」成为护城河的原因：它需要**技能边界定义 + 真机故障注入 + 残差标定**三件事同时做对；任何一件缺失，诊断都会退化为猜测。

## 2. 研究问题（Q10–Q14，接上轮 Q1–Q9）

- **Q10（契约可表达性）**：32 项任务的关键技能能否用有限契约词汇（Pre / Post / Inv + 阈值）覆盖？每个契约的在线检查能否在控制周期内完成？（E628）
- **Q11（组合泛化）**：在见过的技能组合上训练，能否泛化到未见过的组合 / 物体-技能配对？相对单体 VLA 的样本效率收益有多大？（E629）
- **Q12（可隔离性）**：在腕部相机 + EE 位姿 + 夹爪标量的观测下，top-5 故障模式的残差签名能否两两分离（AUC ≥ 0.8）？哪些故障天然不可隔离？（E630）
- **Q13（诊断驱动恢复的净收益）**：相对盲目重试，诊断驱动恢复在成功率、恢复时延、附带损伤上是否全面占优？误诊的代价有多大？（E631）
- **Q14（主动诊断的边界）**：在哪些状态、用多大风险预算，安全探针的净信息收益为正？（E632；与 E633 的跨本体迁移合并跟踪）

## 3. 设计原则（P10–P12，接上轮 P1–P9）

- **P10（契约优先）**：任何进入技能库的技能必须有机器可检查的 Pre / Post / Inv；没有契约的技能只能作为「黑盒原语」，不得参与诊断定位。
- **P11（可隔离才可定向恢复）**：只有通过 E630 可隔离性门槛的故障模式，才允许触发对应的定向恢复；否则一律走安全兜底（回退 / 中止 / 人工）。
- **P12（诊断优先于重试）**：先诊断后动作；盲目重试只作为最后手段且次数有界；主动探针必须带风险预算与可逆性检查。

## 5. 本轮最大风险

**误诊比不诊更危险**：若故障签名矩阵在真机域标定不足（尤其遮挡、接触、延迟三类），诊断器可能以高置信度给出错误病因，触发「定向但错误」的恢复（例如把「标定漂移」误判为「抓握滑移」而反复重抓），其代价高于盲目重试。因此 IP-14 必须带「置信度门槛 + 安全兜底 + 可回滚」，且 E630 未过门槛时只保留检测、不启用定向恢复。

**本轮最大风险一句话：契约误设与故障签名域偏移叠加，会让诊断器「自信地误诊」，从而触发比盲目重试更有害的定向恢复。**

## 6. 下一轮迭代计划（深化与修剪，不推倒重来）

- **深化**：IP-13 的技能契约库（先覆盖 grasp / align / insert 三节点）；IP-14 的残差通道设计与 E630 故障注入协议；IP-15 的风险预算形式化。
- **修剪预案**：若 E628 覆盖率 < 95% → 契约只保留三个关键节点；若 E629 无组合泛化收益 → IP-13 退化为「仅运行时监视」；若 E630 top-5 不可隔离 → IP-14 退化为「检测 + 安全兜底」，砍掉定向恢复；若 E631 误诊代价过高 → 提高置信门槛、扩大兜底比例。
- **待外部事件**：榜单开放 → F2 复核（48 h 内重算）；规则手册可读 → Q3 / Q4 / Q9 合规关闭；真机故障注入窗口 → E630 / E631 真机标定。

## 0. 本轮结论摘要

**一句话路线**：第 2 轮的「路标 → 伺服 → 断言」流水线保持不变；本轮在其上增加两层——**技能契约图（IP-13）** 提供失败定位的解剖坐标，**残差诊断器（IP-14）** 提供故障隔离与识别，二者合成「诊断 → 定向恢复」闭环；主动探针（IP-15）作为条件项，仅在可逆、高歧义状态启用。

本轮三条方法面依据（非外部事实）：

| 依据 | 内容 | 推出的设计 |
|---|---|---|
| 技能组合（options / HTN / 行为树 / 设计契约） | 任务 = 共享技能的组合；组合正确性可由 Pre/Post 传递性保证 | 路标序列升级为技能契约图；新增 IP-13，失败定位到「节点 + 契约条款」 |
| 故障诊断（FDI：检测 → 隔离 → 识别） | 同一症状对应多种病因；隔离依赖残差签名可分性 | 二元断言升级为残差诊断器；新增 IP-14，恢复由病因参数化 |
| 可隔离性信息下界（TV / Le Cam） | 签名重叠时任何诊断器错误率之和 ≥ 1−ε | 「可隔离才可定向恢复」升为设计原则 P11；E630 成为 IP-14 上线门槛 |

**与第 2 轮的连续性**：不推翻任何已有 IP；IP-09 / IP-02 / IP-06 被「契约化 / 残差化 / 签名化」，从三个独立组件收敛为一个可诊断栈。

## 1. 概念跃迁与差异化（新增章节）

### 1.1 与成熟框架的关系（不重复发明，只做「接回」）

| 框架 / 文献传统 | 它解决什么 | 本方案借什么 | 本方案的不同点 |

## 3. 新增 / 深化 IP 详述

### IP-13 · SkillContractGraph 技能契约图 + 运行时监视（P0-lite / P1-full，新）

- **动机**：第 2 轮的路标序列是线性的，失败只能定位到「当前路标」，无法区分「进入状态就错了」（前置违反）与「技能执行错了」（不变式违反）与「执行完却没达到效果」（后置违反）。技能组合把任务变成图，契约把失败定位到**节点 + 条款**，为 IP-14 提供诊断坐标。
- **与现有方案差异**：不是「再拆细一层」，而是给已有路标补上机器可检查的契约与组合算子；技能仍由同一模型/控制器实现，不改变单 checkpoint、单 API 的合规形态（技能图是策略内部结构）。
- **技术可行性**：高–中。契约用几何/视觉/夹爪判据，单次检查 < 5 ms；组合图从 IP-06 阶段标注半自动抽取；`seq/par/branch/retry` 执行器为常规工程。
- **资源**：小算力；依赖 IP-06 的 32 任务阶段标注。
- **落地步骤**：①从 E619 路标映射抽取技能节点与边；②先定义三节点契约（grasp / align / insert）；③实现组合执行器与契约监视；④失败按 Pre / Inv / Post 三元分类；⑤E628（覆盖率/时延）与 E629（组合泛化）。
- **风险**：①契约误设（太松无坐标、太紧压死 VLA 灵活性）；②技能粒度不当导致图爆炸；③并行技能的效果冲突。对冲：只对关键节点建契约；黑盒原语不参与定位；E628 门槛；并行仅限效果集不相交的技能。

### IP-14 · FaultSignatureDiagnoser 残差诊断 + 故障签名（P1，新）

- **动机**：检测不等于隔离。第 2 轮的断言器能说「没过」，但「滑移 / 位姿偏差 / 遮挡 / 标定漂移 / 延迟 / 关节饱和」需要不同恢复；盲目重试可能把可恢复偏移变成碰撞或掉落。FDI 的成熟答案是「残差 + 签名矩阵 + 隔离/识别」。
- **与现有方案差异**：把 IP-02（抓握）、IP-06（离线因子）、IP-10（世界模型预测误差）、IP-09（伺服误差）四路信号统一为残差向量，离线标定故障签名矩阵，在线输出 `(故障模式, 置信度, 幅值)`；恢复由病因参数化，而非统一重抓。
- **技术可行性**：中。残差通道：断言余量、WMA-0 潜空间预测误差、EE 指令-实际跟踪误差、腕部重投影误差、夹爪电流/位置差、时延统计。签名矩阵需要**故障注入**（仿真批量 + 真机小样本）。
- **资源**：中算力 + 真机故障注入时段（稀缺，但正因稀缺而构成护城河）。
- **落地步骤**：①定义 top-5 故障模式（滑移、空抓、位姿偏差、遮挡、标定漂移；延迟/饱和作为干扰项）；②仿真注入 + 真机小样本标定签名；③实现在线诊断（轻量判别器或贝叶斯后验）；④接 U20 恢复选择；⑤E630（可隔离性）/ E631（恢复净收益）/ E633（跨本体迁移）。
- **风险**：①真机域偏移使签名矩阵失真；②遮挡导致残差缺失；③签名重叠不可隔离；④误诊触发有害恢复。对冲：P11 门槛、置信度门控、残差缺失时降级为检测、E630 未过则只保留检测与安全兜底。

### IP-15 · ActiveProbe 安全探针主动诊断（P2·条件，新）

- **动机**：被动残差在高歧义状态（如「空抓」与「夹到薄边」）可能不足以隔离；主动诊断可用小幅、可撤销的探针（轻触、微移、短暂停留）获取信息。
- **与现有方案差异**：探针不是任务动作，而是**信息获取动作**，必须满足可逆性与风险预算；只在 pre-grasp / 有间隙的 transport 等安全相位启用，绝不在 insert/contact 相位使用。
- **技术可行性**：中–低（安全风险高）。需信息增益估计（L14）+ 风险预算 + 安全门。
- **资源**：仿真评估为主；真机需安全员与急停。
- **落地步骤**：①定义可逆状态集与探针动作库；②实现熵/信息增益估计；③风险预算与安全门（预测碰撞概率、任务进度损失）；④E632。
- **风险**：①探针扰动任务或造成碰撞；②被规则解释为「主动干扰」；③信息收益被风险抵消。对冲：默认离线评估；真机小步、可撤销；净收益不显著则砍掉。

### 对既有 IP 的深化（不新增编号）

- **IP-09**：路标 → 技能节点 + 契约；伺服器是 `align/insert` 节点的内部控制器；到点断言成为契约监视的一个子句。
- **IP-02**：抓握确认 → 残差通道 + 故障子类（slip / empty / wrong-object），与 IP-14 共享分类器。
- **IP-06**：六因子 → 故障签名矩阵的离线标定器；离线因子到在线残差的映射是 E630 的前置工作。
- **IP-10**：世界模型预测误差 → IP-14 的可选残差通道；在线前瞻因延迟不可行，默认离线。

## 4. 符号与定义（新增 U16–U20；U1–U15 沿用第 1–2 轮）

- **定义 U16（技能契约）**：技能 `s = (π_s, Pre_s, Post_s, Inv_s, E_s, μ_s)`，其中 `π_s: O → A` 为控制器（VLA chunk 生成器或伺服器），`Pre_s / Post_s / Inv_s` 为可运行时检查（或在时延预算内可估计）的谓词，`E_s` 为效果集（被改变的物理量/资源），`μ_s` 为最大执行步数。契约检查的代价必须 < 控制周期。
- **定义 U17（技能组合图）**：`G = (V, E, op)`，`op ∈ {seq, par, branch, retry}`。良构条件：`seq(s1, s2)` 需 `Post_{s1} ⇒ Pre_{s2}`；`par(s1, s2)` 需 `E_{s1} ∩ E_{s2} = ∅` 且资源不相交；`retry` 需可重建前置。计划 `P` 是该代数上的一个项；执行时在节点入口/出口/周期内评估契约。
- **定义 U18（残差）**：对第 `k` 个监视器，`r_k(t) = ρ_k(o_{t-h:t}, u_{t-h:t}) ∈ R^{d_k}`。本方案使用六类：断言余量、世界模型预测误差、EE 跟踪误差、腕部重投影误差、夹爪电流/位置差、时延统计；`r = (r_1..r_m)`。
- **定义 U19（故障模式与签名 / 可隔离性）**：故障模式 `f ∈ F`（滑移、空抓、位姿偏差、遮挡、标定漂移、延迟、饱和等）；签名矩阵 `S_{kf} = E[r_k | f]`（或残差分布）。`f_i` 与 `f_j` **可隔离**当且仅当其残差分布可分性超过阈值（用两两 TV / AUC 度量）。诊断输出为后验 `p(f | r_{1:t}, P, node)`。
- **定义 U20（诊断驱动的恢复）**：恢复策略 `R: (f, conf, P, node) → {重建前置, 重试节点, 切换技能, 重规划, 安全中止}`。恢复**可采纳**当且仅当 `conf ≥ τ_iso` 且预测伤害 ≤ 预算；否则走安全兜底。`τ_iso` 由 E630/E631 标定。

## 5. 关键算法骨架（新增片段；主体沿第 1–2 轮 `UniBotSAGEPolicy`）

```python
# ===== IP-13: 技能契约 + 组合执行（嵌入 get_action 主循环）=====
@dataclass
class Skill:
    name: str
    pre: Callable[[State], bool]
    post: Callable[[State], bool]
    inv: Callable[[State], bool]
    effect: frozenset[str]
    max_steps: int
    controller: Callable[[State, Obs], Action]

def run_plan(plan, s, obs):
    while not plan.done():
        node = plan.current()
        if not node.pre(s):
            return diagnose_and_recover(plan, node, s, obs, clause="pre")
        if s.steps_in_node >= node.max_steps:
            return diagnose_and_recover(plan, node, s, obs, clause="post")
        if not node.inv(s):
            return diagnose_and_recover(plan, node, s, obs, clause="inv")
        a = node.controller(s, obs)
        s = apply(s, a)
        if node.post(s):
            plan.advance()
        s.steps_in_node += 1
    return a  # 计划完成

# ===== IP-14: 残差 + 诊断 + 恢复 =====
def residuals(s, obs, hist):
    return {
        "assert_margin": s.assert_margin,
        "wm_pred_err":   world_model.latent_error(hist, obs),   # 可选（IP-10）
        "ee_track_err":  norm(s.ee_cmd - s.ee_actual),
        "reproj_err":    wrist_reprojection_error(obs),
        "gripper_gap":   abs(s.gripper_cmd - s.gripper_pos),
        "latency":       s.control_latency,
    }

def diagnose(r, hist, plan, node):
    feats = phi(r, hist, plan.node_id(node))     # 特征含上下文与计划位置
    post  = diagnoser.predict_proba(feats)       # p(f | r)
    f, conf = argmax(post)
    if conf < TAU_ISO:                           # P11: 不可隔离 → 不定向恢复
        return None
    return Fault(mode=f, conf=conf, magnitude=estimate_magnitude(r, f))

def diagnose_and_recover(plan, node, s, obs, clause):
    fault = diagnose(residuals(s, obs, s.hist), s.hist, plan, node)
    if fault is None:
        return safe_fallback(plan, s)            # Level-2.5: 有界重试/中止
    return RECOVERY[fault.mode](plan, node, fault, s)

RECOVERY = {
    "grasp_slip":      lambda p, n, f, s: p.rewind_to("grasp", reestablish=True),
    "empty_grasp":     lambda p, n, f, s: p.rewind_to("grasp", reestablish=True),
    "pose_offset":     lambda p, n, f, s: p.reestablish("align", bias=f.magnitude),
    "occlusion":       lambda p, n, f, s: p.switch_view("wrist_clearance"),
    "calib_drift":     lambda p, n, f, s: p.reestablish("align", bias=f.magnitude),
}

# ===== IP-15: 主动探针（仅可逆、高歧义、风险预算内）=====
def maybe_probe(post, s, risk_budget):
    H = entropy(post)
    if H < H_MIN or not is_reversible(s) or risk_budget <= 0:
        return None
    cand = max(PROBES, key=lambda p: info_gain(p, post) - risk(p, s))
    return cand if info_gain(cand, post) > risk(cand, s) else None
```

## 6. 推导（新增引理 L11–L14；L1–L10 沿用第 1–2 轮）

**引理 L11（契约传递与失败定位）** 设计划为良构组合，且每个执行技能在入口满足 `Pre_i`、执行中满足 `Inv_i`、出口满足 `Post_i`；由 `Post_i ⇒ Pre_{i+1}` 的传递性，计划终止时 `Post_K` 成立。若计划失败，则存在首个失败节点 `j`，且失败必属于以下三类之一：(a) 入口 `Pre_j` 违反（前置/上游后置故障）；(b) 执行中 `Inv_j` 违反（技能内部故障）；(c) 出口 `Post_j` 违反而 Pre/Inv 均成立（效果故障）。故失败被**定位到节点与契约条款**，构成诊断的坐标。∎

**引理 L12（组合泛化的样本复杂度收益）** 设任务分布由 `m` 个共享技能、组合长度 ≤ `K` 生成，最多 `m^K` 个任务；每技能需 `d` 个样本学其策略。共享技能方案需 `O(m·d)`，任务独立方案最坏需 `Ω(m^K·d)`，样本效率比最坏为 `m^{K-1}`。该收益依赖**组合可识别性假设**（技能效果跨上下文不变）；若契约误设或效果强耦合，共享失效，收益上界不成立。∎

**引理 L13（可隔离性的信息下界）** 若故障 `f_i, f_j` 的残差分布总变差 `TV(P_i, P_j) = ε < 1`，则任何诊断器的两类错误概率满足 `P(err_i) + P(err_j) ≥ 1 − ε`（TV/Le Cam 下界）。故签名重叠时，调阈值无法隔离；只能**增加残差通道**或**主动探针**。推论：签名矩阵的两两可分性是定向恢复（P11）的必要条件。∎

**引理 L14（主动诊断的净收益条件）** 设探针使故障后验熵下降 `ΔH`，正确隔离带来的恢复价值为 `V_info`（定向恢复相对盲目重试的期望增益），探针风险为 `risk(p)`（任务进度损失 + 碰撞/损伤期望）。探针可采纳当且仅当 `ΔH · V_info > risk(p) + opportunity_cost`。故主动探针只在可逆、高歧义、`V_info` 大的状态启用；接触/插入相位 `risk` 高，默认禁用。∎

## 11. 本轮最值得押注的创新点（一句话）

**押注「IP-13 技能契约图 + IP-14 残差诊断器」这一对：它把第 2 轮的「检测并重试」升级为「定位并治疗」——技能图给出「哪里错」的解剖坐标，故障签名给出「错在哪、为什么」的病理证据，恢复由病因参数化；第一交付物是 IP-14-lite 的 top-5 故障签名，因为真机故障数据与公共成功演示正交，是最难被一周抄走的资产。**

**本轮最大风险一句话：契约误设与故障签名域偏移叠加，会让诊断器「自信地误诊」，从而触发比盲目重试更有害的定向恢复。**
