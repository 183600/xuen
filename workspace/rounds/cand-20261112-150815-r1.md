# 第 61 轮（承接第 60 轮 SGEC；灵感循环第 7 轮；本轮灵感：「竞赛策略」×「评测指标」）

> 第 60 轮建立了「场景语义→认知意图→ROS 因果隔离」的 SGEC 闭环，但**四个评价性局限**尚未解决：
> 1. **预算分配是中心化的**：PCE++++ 的四维预算由单一调度器切分，候选探针之间**没有竞争**，无法回答“把 1ms 预算给探针 A 还是探针 B 更值”——缺乏**信息价值的相对排序机制**。
> 2. **评测是静态且自指的**：E187–E191 在固定场景集上测固定指标，容易**基准饱和**与**对测试集过拟合**；没有“生成难例的对手”，测出的鲁棒性是**对已知场景的鲁棒性**，不是对部署分布的鲁棒性。
> 3. **指标是可标量化的**：把安全、证据、能力、效率加权成一个分数，隐含允许「用一次安全违规换 5% 成功率」。这违反安全工程的第一原则——**安全是硬约束，不是可交易项**。
> 4. **统计声明缺乏随时有效性**：跑 N 次取均值/置信区间、看到显著就停，会产生**可选停止偏差**；且没有机制防止指标本身被优化过程“钻空子”（Goodhart 定律）。
>
> 本轮引入 **CGEC（Competitive Game-theoretic Evaluation Contract，竞争性评测契约）**：用竞标分配预算、用红蓝对抗生成难例、用词典序指标格阻断安全交易、用随时有效 LCB 保证统计严谨、用反 Goodhart 审计守住度量本身。

## 0. 直觉与动机

**灵感 1（竞赛策略 → 竞争性探针竞标 CBA）**
直觉：预算分配本质是一个**带预算约束的拍卖**。每个候选探针 p_i 报出自己对“降低 D⁺/不确定性”的贡献，但必须报**悲观下界** b_i = LCB_δ(VOI_i) − c_i。竞争会让“高价值低成本”的探针胜出；悲观报价抑制“先吹牛拿到预算、再交付失败”的赢家诅咒。关键洞见：**竞标不是为了提高效率，而是为了让「相对价值」显式化、可审计**——第二价格与失败回溯让每个探针的报价留下证据。

**灵感 2（竞赛策略 → 红蓝对抗评测 ABR）**
直觉：评测若要回答“部署时会不会失败”，就必须有一个**主动制造失败**的对手。把场景空间写成文法 G（桌面→楼梯→湿滑→充电站的可组合规则），红队在该文法与预算 B_red 内搜索使蓝队得分最低的场景。关键洞见：**评测分数应取 min-over-adversary 而不是 average-over-benchmark**；平均分会掩盖长尾，而最坏情形才是安全系统真正要面对的。

**灵感 3（评测指标 → 词典序指标格 MEL）**
直觉：指标体系应像**字典**而不是**算盘**：先比较安全，安全相同再比较证据完整性，再比较能力，最后才看效率。关键洞见：**词典序（lexicographic）比较是唯一同时满足「安全不可补偿」与「完全序」的简单聚合**；任何加权和都等价于宣布“1 次违规 ≈ 若干成功率”。

**灵感 4（评测指标 → 反 Goodhart 度量审计 MAA）**
直觉：一旦指标成为优化目标，它就不再是好的度量。必须像金融审计一样持续检查**代理指标与真实效用的相关性**：设置金丝雀任务（已知答案）、计算有效性系数 ρ、检测 top 分位上的效用塌陷 g。关键洞见：**审计对象不只是被测系统，还包括度量函数本身**；发现 ρ 下降就先冻结指标，而不是继续发证书。

**灵感 5（评测指标的统计严谨性 → 随时有效 LCB）**
直觉：评测预算有限且可以随时停止，因此区间必须对**任意停止时刻**有效。用置信序列（confidence sequence）构造 LCB_t；只有 LCB_t ≥ 目标才认证。关键洞见：**“证书”是拒绝选项的产物**——不发证书是默认，发证书需要统计证据越过可随时检验的门槛。

**灵感 6（合流 → 竞争性评测闭环 CEL）**
直觉：红队生成难例 → 探针竞标预算 → 蓝队执行 → 词典序度量 → 反 Goodhart 审计 → 锦标赛课程更新 → 再生成更难例。评测由“一次性打分”升级为**持续对抗 + 可审计认证**的闭环。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（竞争性预算拍卖 CBA）** 设候选探针集合 P = {p₁,…,pₙ}，执行预算 B_exec。每个探针对自身信息价值 VOI_i 给出样本，报价与分配规则为：
- **悲观报价**：b_i = LCB_δ(VOI_i) − c_i，其中 c_i 为探针 i 的预估执行成本，LCB_δ 为 δ 分位下界。
- **分配**：按 score_i = b_i / max(c_i, ε) 降序贪心装入，直至 Σ c_i ≤ B_exec；被拒探针不消耗预算。
- **支付/价格**：采用**边界第二价格** price = 第一个未被装入探针的报价（无则为 0），用于事后核算“竞争边际”。
- **可审计痕迹**：每份报价写入 EV-exec，包含 (probe_id, LCB, cost, score, accepted)。CBA 的正确性目标不是最优，而是**预算可行 + 近似真实报价 + 决策可追溯**。

**定义 162（对抗场景文法 ASG 与红队）** 文法 G = (Σ, R, s₀, μ, cost)：
- 终结符 Σ 为场景原语（材质、坡度、摩擦、光照、障碍密度）；
- 产生式 R 定义可组合场景（例如 wet(floor) ∧ slope(θ<15°)）；
- μ 为可行域/物理约束；cost(s) 为场景复杂度预算。
- **红队策略** ρ：H → L(G)，在历史 H 与预算 B_red 下选择场景；以贝叶斯优化/进化搜索最大化“蓝队失败或低分”的采集函数。
- **鲁棒分数**：S_robust(π) = min_{s∈L(G), cost(s)≤B_red} S(π, s)，并附机会约束 P(fail | s) ≤ α。

**定义 163（词典序指标格 MEL）** 指标向量 m = (m_safe, m_evid, m_comp, m_eff, m_calib)。给定容差 ε_k：
- **ε-词典序**：m ⪰_lex m′ 当且仅当存在首个 k 使 |m_k − m′_k| > ε_k，且 m_k > m′_k；若所有维度都在容差内则视为等价。
- **硬约束层**：m_safe 与 m_evid 为**门控指标**，任一不达标则整体判为 INVALID，不参与后续比较。
- **Pareto 前沿**：在通过门控的候选中，用逐分量支配（≥ 且至少一维 >）保留非支配集；最终选择再按 lex 序。
- **聚合禁令**：禁止把 m_safe 与 m_comp 放进同一个线性加权函数；任何报告必须给出五元组与门控结论。

**定义 164（反 Goodhart 度量审计 MAA）** 设代理指标 p、潜在效用 u、审计集 D_audit、金丝雀集 C：
- **有效性系数**：ρ_t = corr(p, u) on D_audit。
- **博弈缺口**：g_t = E[u | p ∈ top-10%] − E[u]（代理高分是否真的高效用）。
- **金丝雀一致性**：canary_ok = ∀c∈C: |p(c) − u_known(c)| ≤ tol_c。
- **审计通过**：pass = (ρ_t ≥ ρ_min) ∧ (g_t ≤ g_max) ∧ canary_ok。
- **动作**：若 pass=false，指标**冻结**（不再用于证书），并触发「度量漂移」告警；只有重新标定后才解冻。

**定义 165（随时有效置信下界 LCB-Safe）** 对成功/安全指示序列 X₁,…,X_t ∈ {0,1}，构造置信序列 (L_t)：
- 要求：P(∃t: L_t > E[X]) ≤ δ（时间一致覆盖）。
- 认证规则：仅当 L_t ≥ τ_target 且审计 pass 时颁发 EvalCert；任一次 L_t 跌破 τ_target 则证书撤销。
- 停止规则：预算耗尽或证书成立即停；**不得因“看到均值达标”提前停止**。

**定义 166（评测博弈契约 GEC）** 评测是一个零和博弈 (E, π)：
- 评估者 E（红队）选择场景 s，收益为 −S(π,s)；策略 π（蓝队）收益为 S(π,s)。
- **契约** C_eval = (G, m, ρ_min, g_max, τ_target, δ, B_eval) 固定文法、指标、审计阈值、统计参数与预算。
- **评测证书**：EvalCert = (S_robust, LCB_t, coverage, audit_pass, seed_commit, n)。seed_commit 为预先承诺的随机种子哈希，防止事后挑种子。
- **均衡语义**：报告值解释为 minimax 下界的统计估计，而非某个固定基准上的均值。

**定义 167（锦标赛课程 TCL）** 用 Elo/Bradley–Terry 维护场景与策略变体的相对强度：
- 每场比赛（策略 π 对场景 s）按得分更新 rating(scene) 与 rating(policy)。
- **晋升**：top-q 高 rating 场景进入「困难集」；**退役**：连续 k 轮全胜且低方差的场景标记为饱和并从主基准移出（保留为回归测试）。
- **防泄漏**：进入困难集的场景在下一轮不再用于策略训练，只用于红队种子与留出验证。

**定义 168（竞争性评测闭环 CEL）** 算子 CEL(π, G, B_eval)：
```
① Red.propose(H) → 候选场景集 S_cand（受 B_red、G 约束）
② CBA.allocate({probe(s) | s∈S_cand}) → 中标探针与剩余预算
③ 对每个中标场景 s：π.execute(s) → trace，measure(trace) → m
④ MEL.gate(m) → 若安全/证据门控失败：记录硬违规，禁止进入能力比较
⑤ LCB.update(success ∧ safe ∧ evid)；MAA.audit(proxy, utility, audit_set)
⑥ TCL.update(scene, policy, score)；promote/retire
⑦ 若 LCB ≥ τ_target ∧ audit_pass：颁发 EvalCert；否则继续或预算耗尽
⑧ Return (S_robust, LCB, coverage, EvalCert | NO_CERT)
```

## 2. 关键算法伪代码

### IP-161 CBA（竞争性预算拍卖）

```python
class CompetitiveBudgetAuction:
    def __init__(self, budget_exec: float, delta: float = 0.05):
        self.B = budget_exec
        self.delta = delta

    def bid(self, probe) -> dict:
        samples = probe.voi_samples()               # 历史/模型采样的 VOI 分布
        lcb = float(np.quantile(samples, self.delta))
        cost = max(probe.estimated_cost(), 1e-6)
        return {"probe": probe.id, "lcb": lcb, "cost": cost,
                "score": lcb / cost, "accepted": False}

    def allocate(self, probes) -> tuple:
        bids = sorted((self.bid(p) for p in probes),
                      key=lambda b: b["score"], reverse=True)
        chosen, spent = [], 0.0
        for b in bids:
            if b["lcb"] > 0 and spent + b["cost"] <= self.B:
                b["accepted"] = True
                chosen.append(b); spent += b["cost"]
        price = next((b["lcb"] for b in bids if not b["accepted"]), 0.0)
        return chosen, price, self.B - spent
```

### IP-162 ABR（对抗场景红队）

```python
class AdversarialSceneRedTeam:
    def __init__(self, grammar, budget_red, seed):
        self.G = grammar
        self.B_red = budget_red
        self.opt = BayesianOptimizer(seed=seed)
        self.used = set()

    def propose(self, history, n=64):
        cands = self.G.sample(n, budget=self.B_red)
        return max(cands, key=lambda s: self.opt.acquisition(s.params))

    def update(self, scene, score):
        self.opt.observe(scene.params, score)
        self.used.add(self.G.hash(scene))
        self.B_red -= self.G.cost(scene)

    def holdout_ok(self, scene):
        # 文法外/训练集中出现过的场景不得用于认证
        return self.G.in_support(scene) and self.G.hash(scene) not in self.train_hashes
```

### IP-163 MEL（词典序指标格）

```python
class LexicographicMetricLattice:
    ORDER = ("safe", "evid", "comp", "eff", "calib")
    EPS = {"safe": 0.0, "evid": 1e-3, "comp": 1e-2, "eff": 2e-2, "calib": 1e-2}

    def gate(self, m) -> bool:
        return m["safe"] >= 1.0 and m["evid"] >= 0.999   # 硬约束，不可补偿

    def compare(self, a, b) -> int:
        for k in self.ORDER:
            if abs(a[k] - b[k]) <= self.EPS[k]:
                continue
            return 1 if a[k] > b[k] else -1
        return 0

    def pareto(self, candidates):
        def dominates(x, y):
            return all(x["m"][k] >= y["m"][k] for k in self.ORDER) and \
                   any(x["m"][k] > y["m"][k] for k in self.ORDER)
        return [c for c in candidates
                if not any(dominates(o, c) for o in candidates if o is not c)]
```

### IP-164 MAA（反 Goodhart 度量审计）

```python
class MetricAuditor:
    def __init__(self, rho_min=0.7, gap_max=0.05, canaries=None, delta=0.05):
        self.rho_min, self.gap_max = rho_min, gap_max
        self.canaries = canaries or []
        self.delta = delta

    def audit(self, proxy, utility, audit_set) -> dict:
        p = np.array([proxy(x) for x in audit_set])
        u = np.array([utility(x) for x in audit_set])
        rho = float(pearsonr(p, u).statistic) if len(p) > 2 else 0.0
        top = p >= np.quantile(p, 0.9)
        gap = float(u[top].mean() - u.mean()) if top.any() else 0.0
        canary_ok = all(abs(proxy(c) - c.expected) <= c.tol for c in self.canaries)
        passed = (rho >= self.rho_min) and (gap <= self.gap_max) and canary_ok
        return {"rho": rho, "gap": gap, "canary_ok": canary_ok, "passed": passed}
```

### IP-165 LCB-Safe（随时有效置信下界）

```python
class AnytimeLCB:
    """基于混合鞅的简化置信序列；仅示意，实际需实现 time-uniform 界。"""
    def __init__(self, delta=0.05):
        self.delta, self.n, self.mean, self.m2 = delta, 0, 0.0, 0.0

    def update(self, x: float):
        self.n += 1
        d = x - self.mean
        self.mean += d / self.n
        self.m2 += d * (x - self.mean)

    def lower(self) -> float:
        if self.n < 2:
            return 0.0
        var = self.m2 / (self.n - 1)
        logt = math.log(2 * self.n)
        radius = math.sqrt(2 * var * (logt + math.log(logt)) / self.n) + 3 * logt / self.n
        return max(0.0, self.mean - radius)

    def certified(self, target: float) -> bool:
        return self.lower() >= target
```

### IP-167 TCL（锦标赛课程）

```python
class TournamentCurriculum:
    def __init__(self, k=16):
        self.k, self.rating = k, defaultdict(lambda: 1200.0)

    def update(self, scene_id, policy_id, score):
        rs, rp = self.rating[scene_id], self.rating[policy_id]
        exp_p = 1 / (1 + 10 ** ((rs - rp) / 400))
        self.rating[policy_id] += self.k * (score - exp_p)
        self.rating[scene_id] += self.k * ((1 - score) - (1 - exp_p))

    def promote(self, q=0.1):
        ids = sorted(self.rating, key=self.rating.get, reverse=True)
        return ids[:max(1, int(len(ids) * q))]
```

### IP-168 CEL（竞争性评测闭环）

```python
def competitive_evaluation_loop(policy, grammar, budget_eval, delta=0.05):
    auc = CompetitiveBudgetAuction(budget_eval.exec, delta)
    lcb = AnytimeLCB(delta)
    audit = MetricAuditor(rho_min=budget_eval.rho_min,
                          gap_max=budget_eval.gap_max,
                          canaries=budget_eval.canaries)
    red = AdversarialSceneRedTeam(grammar, budget_eval.red, budget_eval.seed)
    records = []
    while budget_eval.remaining() > 0 and not lcb.certified(policy.target):
        cands = red.propose(policy.history)
        chosen, _, _ = auc.allocate([policy.probe(s) for s in cands])
        for bid in chosen:
            s = bid.probe.scene
            trace = policy.execute(s, budget=bid.cost)
            m = measure(trace)
            if not lattice.gate(m):
                records.append(("HARD_VIOLATION", s, m)); continue
            lcb.update(1.0 if (m["safe"] and m["evid"] and m["succ"]) else 0.0)
            red.update(s, m["comp"])
            records.append((s, m))
        verdict = audit.audit(measure_proxy, measure_utility, records[-64:])
        if not verdict["passed"]:
            return {"status": "METRIC_FROZEN", "audit": verdict, "lcb": lcb.lower()}
    cert = (lcb.certified(policy.target) and audit.passed)
    return {"S_robust": lcb.mean, "LCB": lcb.lower(), "n": lcb.n,
            "certified": cert, "status": "CERT" if cert else "NO_CERT"}
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CBA | O(n log n) 排序/轮 | O(n) | 预算可行；近似真实报价；决策可审计 |
| ABR | O(n·T_BO)/轮 | O(n + 历史) | 难例发现率优于随机；留出集防泄漏 |
| MEL | O(1) 比较；O(n²) Pareto | O(n) | 安全不可补偿；ε-词典序为全预序 |
| MAA | O(N_audit) / 审计 | O(N_audit) | ρ/缺口/金丝雀三阈值；漂移即冻结 |
| LCB | O(1) 更新 | O(1) | 时间一致覆盖 ≥ 1−δ |
| CEL | O(B_eval) 轮 | O(记录) | 仅当 LCB 与审计双通过才发证书 |

**正确性定理（CGEC）**：
假设 A66–A70 成立：
- **(A66) CBA**：VOI 近似子模且 LCB 校准；贪心分配给出 (1−1/e) 近似，总花费 ≤ B_exec，报价在单调性下近似真实（单峰偏离收益 ≤ 0）。
- **(A67) ABR**：红队只在文法 G 的支撑集内搜索；认证场景与训练场景哈希不交。
- **(A68) MEL**：m_safe、m_evid 为门控硬约束；ε-词典序是完备、传递的全预序，且安全占优策略永不被高效率策略取代。
- **(A69) MAA**：审计集与金丝雀可交换；当 p 与 u 脱钩时审计在有限样本内以高概率检出。
- **(A70) LCB**：置信序列对任意停止时刻有效，覆盖误差 ≤ δ。

则：
1. **鲁棒下界有效**：以概率 ≥ 1−δ，报告 S_robust 不低于真实鲁棒分数；证书仅在 LCB ≥ τ_target 时颁发。
2. **预算安全**：任意轮次总执行花费 ≤ B_exec；被拒探针零消耗。
3. **安全非补偿性**：任何含硬违规的策略无法通过门控，因而不能排在零违规策略之前。
4. **反 Goodhart**：若 ρ_t < ρ_min 或 g_t > g_max，指标在发证前被冻结。
5. **课程单调性**：在评分噪声有界时，TCL 的困难集评分随轮次单调不降。

## 2. 关键推导

### 2.1 为什么必须用词典序而不是加权和

设加权分数 F = Σ w_k m_k，w_safe > 0。若某策略以 Δm_comp > 0 换取 Δm_safe < 0，则当 w_comp·Δm_comp > w_safe·|Δm_safe| 时 F 上升。即**任何正权重都允许“安全换性能”**——这与「安全是硬约束」矛盾。词典序把 m_safe 放在首维且设 ε_safe = 0：只要安全下降，无论能力提升多少，排序必下降。门控层进一步把“安全不达标”从“排序较低”升级为“无效”，彻底切断补偿路径。

### 2.2 为什么报价要用下界

若探针报 E[VOI] 而非 LCB，则高方差探针会系统性高估自身价值（赢家诅咒），预算被“吹牛者”占据且事后无法追责。用 δ 分位下界报价，等价于要求探针“用悲观承诺换取预算”，并以报价痕迹支持事后归因。贪心分配在 VOI 近似子模时具有 (1−1/e) 近似保证。

### 2.3 为什么评测要采用 min-over-adversary

平均分 S_avg = E_{s∼D_bench}[S] 只对 D_bench 负责；部署失败发生在 D_deploy 的长尾。若 D_bench 与 D_deploy 有支撑集差，S_avg 可任意高而真实风险不变。S_robust 直接优化最坏情形，其统计估计（LCB）给出对未观测场景的保守下界——这正是安全认证需要的方向。

### 2.4 证书的统计语义

EvalCert 不是“系统永远安全”的证明，而是「在契约 C_eval 与预算 B_eval 下，以 ≥ 1−δ 的置信度，真实鲁棒分数不低于 LCB_t」的**可废止声明**。任何一次后续评测中 L_t 跌破 τ_target 或审计失败，证书立即撤销。这避免了“一次性过测 = 永久合格”的静态认证谬误。

### IP-161 CBA

```python
class CompetitiveBudgetAuction:
    def __init__(self, budget_exec, delta=0.05):
        self.B, self.delta = budget_exec, delta

    def bid(self, probe):
        lcb = float(np.quantile(probe.voi_samples(), self.delta))
        cost = max(probe.estimated_cost(), 1e-6)
        return {"probe": probe, "lcb": lcb, "cost": cost,
                "score": lcb / cost, "accepted": False}

    def allocate(self, probes):
        bids = sorted((self.bid(p) for p in probes),
                      key=lambda b: b["score"], reverse=True)
        chosen, spent = [], 0.0
        for b in bids:
            if b["lcb"] > 0 and spent + b["cost"] <= self.B:
                b["accepted"] = True; chosen.append(b); spent += b["cost"]
        price = next((b["lcb"] for b in bids if not b["accepted"]), 0.0)
        return chosen, price, self.B - spent
```

### IP-162 ABR

```python
class AdversarialSceneRedTeam:
    def __init__(self, grammar, budget_red, seed):
        self.G, self.B_red = grammar, budget_red
        self.opt, self.used = BayesianOptimizer(seed), set()

    def propose(self, history, n=64):
        return max(self.G.sample(n, budget=self.B_red),
                   key=lambda s: self.opt.acquisition(s.params))

    def update(self, scene, score):
        self.opt.observe(scene.params, score)
        self.used.add(self.G.hash(scene)); self.B_red -= self.G.cost(scene)
```

### IP-163 MEL

```python
class LexicographicMetricLattice:
    ORDER = ("safe", "evid", "comp", "eff", "calib")
    EPS = {"safe": 0.0, "evid": 1e-3, "comp": 1e-2, "eff": 2e-2, "calib": 1e-2}

    def gate(self, m):
        return m["safe"] >= 1.0 and m["evid"] >= 0.999

    def compare(self, a, b):
        for k in self.ORDER:
            if abs(a[k] - b[k]) <= self.EPS[k]:
                continue
            return 1 if a[k] > b[k] else -1
        return 0
```

### IP-164 MAA

```python
class MetricAuditor:
    def __init__(self, rho_min=0.7, gap_max=0.05, canaries=None):
        self.rho_min, self.gap_max, self.canaries = rho_min, gap_max, canaries or []

    def audit(self, proxy, utility, audit_set):
        p = np.array([proxy(x) for x in audit_set])
        u = np.array([utility(x) for x in audit_set])
        rho = float(pearsonr(p, u).statistic) if len(p) > 2 else 0.0
        top = p >= np.quantile(p, 0.9)
        gap = float(u[top].mean() - u.mean()) if top.any() else 0.0
        canary_ok = all(abs(proxy(c) - c.expected) <= c.tol for c in self.canaries)
        passed = rho >= self.rho_min and gap <= self.gap_max and canary_ok
        return {"rho": rho, "gap": gap, "passed": passed}
```

### IP-165 LCB-Safe

```python
class AnytimeLCB:
    def __init__(self, delta=0.05):
        self.delta, self.n, self.mean, self.m2 = delta, 0, 0.0, 0.0

    def update(self, x):
        self.n += 1; d = x - self.mean
        self.mean += d / self.n; self.m2 += d * (x - self.mean)

    def lower(self):
        if self.n < 2:
            return 0.0
        var = self.m2 / (self.n - 1); logt = math.log(2 * self.n)
        radius = math.sqrt(2 * var * (logt + math.log(logt)) / self.n) + 3 * logt / self.n
        return max(0.0, self.mean - radius)
```

### IP-168 CEL

```python
def competitive_evaluation_loop(policy, grammar, budget_eval, delta=0.05):
    auc = CompetitiveBudgetAuction(budget_eval.exec, delta)
    lcb = AnytimeLCB(delta)
    audit = MetricAuditor(budget_eval.rho_min, budget_eval.gap_max, budget_eval.canaries)
    red = AdversarialSceneRedTeam(grammar, budget_eval.red, budget_eval.seed)
    records = []
    while budget_eval.remaining() > 0 and not lcb.certified(policy.target):
        chosen, _, _ = auc.allocate([policy.probe(s) for s in red.propose(policy.history)])
        for bid in chosen:
            m = measure(policy.execute(bid.probe.scene, budget=bid.cost))
            if not lattice.gate(m):
                records.append(("HARD_VIOLATION", m)); continue
            lcb.update(1.0 if (m["safe"] and m["evid"] and m["succ"]) else 0.0)
            red.update(bid.probe.scene, m["comp"]); records.append((bid.probe.scene, m))
        if not audit.audit(measure_proxy, measure_utility, records[-64:])["passed"]:
            return {"status": "METRIC_FROZEN", "lcb": lcb.lower()}
    return {"S_robust": lcb.mean, "LCB": lcb.lower(),
            "certified": lcb.certified(policy.target)}
```

## 4. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性 |
|---|---|---|---|
| CBA | O(n log n) / 轮 | O(n) | 预算可行；近似真实；可审计 |
| ABR | O(n·T_BO) / 轮 | O(n + 历史) | 难例发现优于随机；留出防泄漏 |
| MEL | O(1) 比较 | O(n) | 安全不可补偿；全预序 |
| MAA | O(N_audit) | O(N_audit) | 漂移即冻结 |
| LCB | O(1) | O(1) | 任意停止覆盖 ≥ 1−δ |
| CEL | O(B_eval) | O(记录) | 双通过才发证 |

**正确性定理（CGEC）**：若 A66–A70 成立，则
1. 以概率 ≥ 1−δ，S_robust 不低于真实鲁棒分数，证书仅在 LCB ≥ τ_target 时成立；
2. 任意轮次总花费 ≤ B_exec；
3. 含硬安全违规的策略无法通过门控，不能排在零违规策略之前；
4. ρ_t < ρ_min 或 g_t > g_max 时指标冻结，证书不颁发；
5. 有界噪声下困难集评分随轮次单调不降。
