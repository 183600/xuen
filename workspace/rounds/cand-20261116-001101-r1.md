# 第 11 轮（新灵感循环第 2 轮；本轮灵感：「语义地图」×「动力学」）
> **基线**：第 10 轮 MetricVoiceGauge-STF-NRB-LS（定义 540–548；引理 87–91；实验 E571–E590）。
> 本轮纪律：**预测只许收缩 + 双通道互证 + 有界动力学**。两个灵感分别治理 v10 的两种债：**时域债**（STF 回答的是"此刻哪里变了"，是反应式空间信任；它不知道"接下来谁会进入走廊"，块证书仍是静态空间证书，移动体可在块内穿过）与**单证债**（v10 把安全押在单一语义分割面 τ_sem 上，上轮自认最大风险即对抗纹理可在 ν≤τ_sem 下穿透）。必须保持 v10 铁律：任一新模块失效 ⇒ 严格退化为 v10（SDM/预测失效 ⇒ 静态 STF；DCM 失效 ⇒ 单通道 ν），行为不漂移。

## 0. 直觉与动机

**灵感 1（语义地图 → 从静态地标图到语义-动力学场景图）**
直觉：v10 的 G_LM 是"带语义标签的点云骨架"——它知道那里有个"人/椅子"，却不知道这个人正以 1.2 m/s 朝走廊走来。语义地图真正的价值不只是**命名**，而是给动力学提供**对象级身份与类别先验**：同一个 ℓ 跨帧可跟踪，类别先验给出速度/加速度的可行域（人不会瞬移、椅子通常静止、球会滚动、门会开合）。核心创新：**语义-动力学场景图（SemanticDynamicsMap, SDM）**——在 G_LM 上为每个地标增挂动力学状态 d_ℓ=(v_ℓ, a_max^{c_ℓ}, Σ_ℓ, ι_ℓ, t_track, o_ℓ) 与交互边（对向、跟随、横穿、遮挡），用类别条件的有界动力学（CTRV + 学习残差）做 K 步预测，得到地标轨迹管道（tube）。这把"地图"从名词变成动词：地图不仅记录世界，还外推世界；而"语义"的作用是让外推有身份、有类别上界、可跨帧复用。

**灵感 2（动力学 → 从静态空间证书到时空证书）**
直觉：v9/v10 的块证书是"沿几何走廊的最小间隙 ĝ_min"——它默认走廊里的障碍在块内不动。但危险恰恰来自**相对运动**：一个静止时距离 0.9m 的人，若以 1.5m/s 对向走来，0.5s 的块内就会侵入 d_safe。动力学给证书补上时间维：间隙不再是空间最小值，而是**时域最小值** g_min^[0:K]=min_{τ,k}(预测间隙(τ)−增长界(τ))；停车不变式从"当前距离 > 刹车距离"升级为"存在可达安全停驻点，且对向体在停驻完成前不侵入"，即相对运动版。第二个关键用途是**独立证据通道**：语义嵌入创新 ν 衡量"外观变了"，动力学残差 ρ_ℓ=‖观测运动−预测运动‖ 衡量"运动规律变了"；对抗纹理可以骗过前者，却通常改变不了后者的物理一致性。两通道取"或"触发守卫，把 v10 的单点校准假设换成可检验的双通道并集界。

两者咬合：SDM 提供对象级可跟踪的动力学管道（预测有身份、有类别先验、有误差界），时空证书把管道翻译成可证的时域间隙与动态停车不变式，DCM 提供与语义通道正交的异常证据——共同把 v10 的结构化证书升级为**时空证书 Ĉ^‡=(g_min^[0:K], e_max, γ_grasp, β_SDT, n_t, ρ_dyn)**。理论上关键一步：把"危险必被单一分割面捕获"改写为"危险必被语义或动力学通道之一捕获"；前提从**单通道召回**变为**双通道条件覆盖 + 显式共模失效项**（引理 93 不假设独立，不掩盖共模）。

## 1. 研究问题（轮次升级版）

- **Q1（预测式信任）**：如何在不把预测变成新安全前提的条件下，用对象级语义-动力学场景图把信任场从 T(x,t) 升级为 T(x,t+τ)，使块内移动障碍被提前表征，且预测失效时严格退化为 v10 的静态 STF？
- **Q2（时空证书）**：如何把块证书从静态空间间隙升级为时域证书 g_min^[0:K]，并在预测误差随 τ 增长时给出显式的可解时域 K*，使动态停车不变式在相对运动下仍可证（或诚实报告不可证并降级）？
- **Q3（双通道与共模）**：语义创新与动力学残差如何组合，使危险检测从单通道召回 ≥1−ε_sem 升级为双通道 ≥1−ε_cm，且 ε_cm 是可实验测量、可写入证书的共模项，而不是被"独立性假设"藏起来？

## 2. 设计原则（在 P13–P15 基础上新增 P16–P18）

**P16 预测只许收缩律（Prediction-Shrinks-Only, SDM）**
SDM 的预测只能收紧证书（↑β_SDT、↓g_min、↓K_eff），绝不扩大可行集；预测缺失/中性时严格退化为 v10（精确等价，引理 94）。预测不是安全前提，只是保守性的增强项。

**P17 双通道互证律（Two-Channel Cross-Evidence, DCM）**
语义创新 ν 与动力学残差 ρ 是两个独立触发源，任一越阈即触发守卫；两通道**不一致**（一高一低）按更保守者处理；共模失效 ε_cm 必须被显式建模、写入证书并由实验测量，禁止用"独立"假设把风险乘小。

**P18 有界动力学律（Bounded Dynamics, DBC）**
只有携带误差界 ε_dyn(τ)（随时域增长）且在校准域内的动力学模型可进入证书；ε_dyn(τ) 超预算或模型失配 ⇒ 立即截断时域，最坏退化为当前测量（v10 静态证书）。

## 3. 与基线的接口（如何退化）

- SDM 失效/预测过期（t_track<3、遮挡超时、时钟漂移）⇒ 静态 STF（v10）原样，T 与 ν 机制不变；
- DCM 失效 ⇒ 单通道 ν（v10 原样），守卫退回 v10 四检；
- 时空证书不可解（K*=0）⇒ 静态证书 + K_eff←min(K,2)，再不行 K=1（v8 逐步）；
- NRB/台账/AC/ID/MW 失效 ⇒ 沿 v10 六级退化链，新增 SDM/DCM 一律 φ^elig=false，仅"地标跟踪维护"可蒸馏；
- 关键不变量：任一新增模块失效都退化为 v10 而非更差；"预测"从不成为安全前提。

## 4. 预期贡献

1. **语义-动力学场景图**：把地标图从静态语义骨架升级为可跟踪、类别条件有界、带交互边的预测对象图，为证书提供对象级时域管道（定义 549–551）；
2. **时空块证书与动态停车不变式**：把静态空间间隙升级为时域间隙，给出预测误差随时域增长的显式可解界 K*（定义 552–554、引理 92/95/96）；
3. **双通道异常检测与显式共模界**：语义与动力学互证，检测界写成含 ε_cm 的并集界而非独立性乘积，对 v10 单分割面风险做正面但诚实的拆除（引理 93）；
4. **E591–E610** 覆盖动力学标定、时域覆盖、动态障碍注入、共模失效、长尾动力学、退化等价与竞赛。

## 5. 本轮最大风险

**一句话**：双通道互证的安全性依赖"语义异常与动力学异常不同时发生"——协同对抗（既改纹理又改运动学）或人群/非刚体等长尾动力学可造成共模失效，而 ε_dyn(τ) 随预测时域膨胀会使 β_SDT 大到证书不可行，系统在"过度保守导致任务失活"与"共模穿透导致隐蔽失效"之间被双向挤压。

**新增定义 549（语义-动力学场景图）** G_SD=(V,E,D)。在 v10 G_LM 的每个地标上增挂 d_ℓ；数据关联用马氏距离门 + 类别一致，连续跟踪 t_track≥3 帧才允许进入预测；遮挡 o_ℓ>T_occ 时降级为"幽灵"（只保留位置先验，不参与预测）；同类同位合并且速度取保守上界 max‖v‖。边 e=(ℓ,ℓ',type) 编码对向/跟随/横穿/遮挡关系，仅用于预测时的交互修正，不进入证书主项。

**新增定义 550（类别条件有界动力学与预测管道）** 对 ℓ 与 τ∈[0,KΔt]：
p̂_ℓ(τ)=p_ℓ+v_ℓτ+½a_ℓτ²（CTRV 简化；转弯率由类别先验约束），
ε_dyn^{c}(τ)=ε_0+α_cτ+½a_max^cτ²+σ_ℓ√τ，

**新增定义 551（动力学残差与双通道证据）** 观测运动 u_ℓ(t) 由跟踪器位置差分或光流给出；ρ_ℓ(t)=‖u_ℓ(t)−(p̂_ℓ(t−1,t)−p_ℓ(t−1))/Δt‖_{Σ_ℓ^{-1}}，ρ̄_ℓ 为 3 帧 EMA（比语义 ν 的 5 帧更快，因为运动可直接测量），ρ_dyn(t)=sup_{ℓ∈N_k(Φ(ζ))}ρ̄_ℓ。双通道证据 E_t=1[sup_{Φ}ν̄>τ_sem]∨1[ρ_dyn>τ_dyn]；不一致标志 δ_dis=1[1[ν̄>τ_sem]≠1[ρ_dyn>τ_dyn]]。δ_dis=1 时按更保守通道处理，并写入 v10 伦理台账（定义 559）。

**新增定义 552（时空足迹）** Φ_K(ζ)=∪_{τ=0}^{KΔt}(Φ(ζ_τ)⊕⋃_{ℓ}P_ℓ(τ))，其中 Φ(ζ_τ) 为块内第 τ 步的几何扫掠足迹。时空足迹同时包含机器人自身运动与所有可预测地标的预测管道。

**新增定义 553（时空块证书）** Ĉ_t^‡=(g_min^[0:K], e_max, γ̂_grasp, β_SDT, n_t, ρ_dyn)，其中
g_min^[0:K]=min_{τ,k}[F̂_q.clearance(ζ_τ,k,p̂(τ))−β_SDT(ζ,τ)−ε_dyn^sup(τ)]，
e_max=max_{τ,k}[F̂_q.effort(ζ_τ,k)+β_SDT(ζ,τ)]，
ε_dyn^sup(τ)=sup_{ℓ∈Φ_K(ζ)}ε_dyn^{c_ℓ}(τ)。
Ĉ_t^‡ valid ⇔ g_min^[0:K]≥d_safe ∧ e_max≤τ_eff ∧ γ̂_grasp valid ∧ n_t 全通过 ∧ freshness(G_SD)≤T_fresh ∧ U_t^sem ∧ ρ_dyn≤τ_dyn（或 DCM 声明失效并退化为 v10 单通道）。

**新增定义 554（时空余量）** β_SDT(ζ,τ)=β_base+λ_s·sup_{x∈Φ(ζ)}T(x)+λ_d·ε_dyn^sup(τ)。预测不确定性以显式项进入余量，随 τ 单调不减；λ_s、λ_d 由 E593/E592 联合标定。中性预测（ε_dyn≡0、ρ_dyn≡0）时 β_SDT=β_STF，精确退化 v10。

**新增定义 555（动态停车不变式）** 在守卫时刻 t，对最近预测运动地标的相对速度 v_rel，存在中止点 p*∈A(ζ) 使：
(i) p* 在相对刹车距离内可达：‖p*−p_t‖≤d_brake_rel(v_rel)=v_rel²/(2a_brake)+v_relτ_react；
(ii) 对停驻过程任意 τ_stop≤T_brake，预测间隙(p*(τ_stop),P_ℓ(τ_stop))≥d_safe+β_SDT(ζ,τ_stop)+ε_dyn(τ_stop)。
不满足 ⇒ 立即沿 v9 定义 534 切最近中止点；若连最近中止点也不满足 ⇒ 受控最小风险停驻并语音披露。

**新增定义 556（五检守卫）** 50Hz 守卫（全部 O(k)，k≤8 近邻地标）：(i) 时空证书有效性（含 ρ_dyn 与新鲜度）；(ii) 动态停车不变式；(iii) 语义创新度 sup ν̄≤τ_sem；(iv) 动力学残差 ρ_dyn≤τ_dyn；(v) 快规范（ν-PROX/ν-PRIV）。任一失败 ⇒ 切 p* 或安全停驻；总预算 ≤0.7ms。

**新增定义 557（预测只收缩算子与 K_eff 升级）** 记候选块集 C。Π_pred(C)={ζ∈C:Ĉ^‡ valid}；预测不可用/中性时 Π_pred(C)=C（精确 v10）。由构造 Π_pred(C)⊆C。有效块长升级为：
```
K_eff^v11(t) = min( K_eff^v10(t), K_cert(t) )
K_cert(t)    = max{ K≤K_max : ∀τ≤KΔt, g_pred(τ)−β_SDT(τ)≥d_safe ∧ 动态停车不变式成立 }
```
K_cert=0 ⇒ 不生成块，转单步/停驻。该式保证 v11 的块长永不超过 v10。

**新增定义 558（动力学预算契约）** κ_DYN=(ε_0,α_c,a_max^c,ε_max,K_max,D_m,Ŵ_m,M_m,E_m)。部署期校验 ΣM_m≤RAM、ΣE_m≤25W；运行期每块边界检查 ε_dyn^sup(τ)≤ε_max 与 K*≥1，否则截断时域至最大可行 τ，最坏退化为静态 v10（K=1）。

**新增定义 559（DCM 契约与共模记录）** κ_DCM=(D=0.2ms@50Hz, v^⊥=单通道 v10, φ^elig=✗)。每次 δ_dis=1 或 E_t=1 时，将 (t,ζ_id,ν̄,ρ_dyn,判定,修复) 追加 v10 伦理台账；离线按 E595 统计 ε_cm=P(ν≤τ_sem∧ρ≤τ_dyn|危险)。台账缺口沿用 v10 P13 ⇒ Π_r。

**新增定义 560（可解时域 K*）** 设 ε_dyn(τ)=ε_0+ατ+½a_maxτ²，最坏接近速度 v_rel，预测间隙下界 g_pred(τ)≥g_0−v_relτ。定义
A=g_0−d_safe−β_base−λ_s·supT−λ_dε_0。
若 A≤0 ⇒ K*=0；否则 K*=⌊τ*/Δt⌋，τ* 为 A−(v_rel+λ_dα)τ−(λ_da_max/2)τ²=0 的正根。K* 对 v_rel、α、a_max、λ_d 单调不增（引理 96）。

# IP-361 SemanticDynamicsMap：语义-动力学场景图（复用 v10 STF 地标图与 v8 检测栈）
class SemanticDynamicsMap:
    def __init__(self, stf, tau_occ=1.0, T_occ=1.5, T_pred=0.5, K_max=8):
        self.stf = stf                    # v10 SemanticTrustField（含 G_LM）
        self.tau_occ, self.T_occ = tau_occ, T_occ
        self.T_pred, self.K_max = T_pred, K_max
        self.tracks = TrackTable()        # 对象级身份与 d_ℓ

    def update(self, detections, dt):
        # 马氏门 + 类别一致关联；t_track≥3 才允许预测
        for d in detections:
            tr = self.tracks.associate(d, gate=self.tau_occ)
            if tr is None:
                self.tracks.create(d, d_ell=self.class_prior(d.cls))
            else:
                tr.update(d, dt, a_max=self.class_prior(d.cls).a_max)
            tr.o = 0 if tr.matched else tr.o + 1
        for tr in self.tracks:
            if tr.o > self.T_occ:
                tr.ghost = True           # 幽灵：只留位置先验，不参与预测
        self.stf.update(detections)       # 语义创新 ν 原样维护

    def predict(self, horizon):
        # 定义 550：类别条件管道；超出 ε_max 的 τ 截断
        tubes = {}
        for tr in self.tracks.active():
            tubes[tr.id] = [tr.tube_at(tau, eps_fn=self.eps_dyn)
                            for tau in horizon if self.eps_dyn(tr, tau) <= self.eps_max]
        return tubes

    def eps_dyn(self, tr, tau):
        c = tr.cls
        return (self.eps0 + self.alpha[c] * tau
                + 0.5 * self.a_max[c] * tau * tau
                + tr.sigma * sqrt(tau))


# IP-363 DynamicsConsistencyMonitor：动力学残差（第二条证据通道）
class DynamicsConsistencyMonitor:
    def __init__(self, tau_dyn=0.4, ema=1/3):
        self.tau_dyn, self.ema = tau_dyn, ema

    def residual(self, sdm, live_obs):
        rho = 0.0
        for tr in sdm.tracks.near(live_obs.pose, k=8):
            u_obs = tr.observed_velocity(live_obs.dt)
            u_pred = tr.predicted_velocity(live_obs.dt)
            r = mahalanobis(u_obs - u_pred, tr.Sigma)
            tr.rho_bar = self.ema * r + (1 - self.ema) * tr.rho_bar
            rho = max(rho, tr.rho_bar)
        return rho

    def evidence(self, sdm, live_obs):
        sem = sdm.stf.surprise_near(live_obs.pose) > sdm.stf.tau_sem
        dyn = self.residual(sdm, live_obs) > self.tau_dyn
        return {'fire': sem or dyn, 'disagree': sem != dyn,
                'sem': sem, 'dyn': dyn}


# IP-362 SpatiotemporalCertifier：时空证书（继承 v10 StructuredChunkCertifier）
class SpatiotemporalCertifier(StructuredChunkCertifier):
    def __init__(self, *a, sdm=None, dcm=None, lam_d=0.5, eps_max=0.15, **kw):
        super().__init__(*a, **kw)
        self.sdm, self.dcm = sdm, dcm
        self.lam_d, self.eps_max = lam_d, eps_max

    def generate_chunk(self, state, ctx, stf, nrb):
        K10 = self.effective_K(ctx.delta_dom, ctx.tau_dom,
                               trust_ok=stf.trust_ok(ctx))       # v10 定义 539
        tubes = self.sdm.predict(horizon=range(1, K10 + 1))
        K = min(K10, self.solvable_horizon(state, tubes))        # 定义 557/560
        if K <= 0:
            return self._single_step_fallback(state)            # 静态 v10 / v8
        best = None
        for cand in self.policy.sample_sequences(state, K, n=64):
            pred = self.Fq.rollout(state, cand)                 # v10 INT8 前向模型
            g_min, e_max, beta = self._spatiotemporal_bounds(pred, tubes)
            if g_min < self.d_safe or e_max > state.tau_eff:
                continue
            pts = self._abort_points_dynamic(state, cand, pred, tubes)
            if not pts:
                continue
            chunk = Chunk(cand, CertDagger(g_min, e_max, beta,
                                           rho=self.dcm.residual(self.sdm, state)),
                          pts)
            chunk, verdict = nrb.review_chunk(chunk, stf, ctx)   # v10 IP-358
            if chunk is None:
                continue
            score = self.policy.score(chunk, pred)
            if best is None or score > best.score:
                best = chunk
        return best or self._single_step_fallback(state)

    def _spatiotemporal_bounds(self, pred, tubes):
        g_min, e_max, beta = float('inf'), 0.0, self.beta_base
        for tau, step in pred.steps():                         # τ=1..K
            beta_tau = (self.beta_base
                        + self.lam * self.stf.field_on_footprint(step.corridor)
                        + self.lam_d * self._eps_sup(tubes, tau))   # 定义 554
            g_min = min(g_min, step.min_clearance_to_centers(tubes, tau)
                        - beta_tau - self._eps_sup(tubes, tau))    # 定义 553
            e_max = max(e_max, step.max_effort + beta_tau)
            beta = max(beta, beta_tau)
        return g_min, e_max, beta

    def solvable_horizon(self, state, tubes):
        # 定义 560：A≤0 ⇒ 0；否则解二次方程取正根
        A = (state.g0 - self.d_safe - self.beta_base
             - self.lam * self.stf.field_on_footprint(state.corridor)
             - self.lam_d * self.eps0)
        if A <= 0:
            return 0
        vr = state.v_rel
        b = vr + self.lam_d * self.alpha
        c = 0.5 * self.lam_d * state.a_max
        tau_star = (-b + sqrt(b * b + 4 * c * A)) / (2 * c)
        return min(self.K_max, int(tau_star / state.dt))

    def midchunk_guard(self, chunk, k_exec, live_obs, stf, nrb, sdm, dcm):
        """50Hz 五检 ≤0.7ms；返回 ('continue', k+1) 或 ('abort', p*)"""
        if not chunk.cert_still_valid(live_obs):                # 检 1
            return self._nearest_abort(chunk, k_exec)
        if not self._dynamic_stop_invariant(chunk, k_exec, live_obs, sdm):
            return self._nearest_abort(chunk, k_exec)           # 检 2：定义 555
        ev = dcm.evidence(sdm, live_obs)
        if ev['sem']:                                           # 检 3：语义领先
            return self._nearest_abort(chunk, k_exec)
        if ev['dyn']:                                           # 检 4：动力学残差
            return self._nearest_abort(chunk, k_exec)
        if nrb.fast_norms(live_obs).violated:                   # 检 5：快规范
            return self._nearest_abort(chunk, k_exec)
        if ev['disagree']:
            self._ledger_disagreement(live_obs, ev)             # 只写账，不回灌控制
        return ('continue', k_exec + 1)

## 4. 推导

**引理 92（时空证书可靠性）** 设 (A1) 对任意 ℓ 与 τ≤KΔt，真实位置 q_ℓ(τ)∈P_ℓ(τ) 的概率 ≥1−ε_p；(A2) 前向模型在足迹上的误差 ≤β_base+λ_s·supT 的概率 ≥1−ε_β（v10 引理 87 同构）；(A3) 机器人位置在相邻守卫 tick 间以 v_max 为 Lipschitz 界；(A4) Ĉ_t^‡ valid。则概率 ≥1−ε_p−ε_β 下，对所有 τ∈[0,KΔt] 有真实间隙 ≥d_safe 且真实 effort ≤τ_eff。证明：由 A1，q_ℓ(τ)∈P_ℓ(τ)，故真实间隙 ≥ F̂_q 对预测中心 p̂ 的间隙 −ε_dyn^sup(τ)；再由 A2 得真实间隙 ≥ F̂_q 对 p̂ 的间隙 −ε_dyn^sup(τ)−(β_base+λ_s supT)。证书的 g_min 恰为该式在 τ,k 上的最小值再减 β_SDT+ε_dyn，故 g_min≥d_safe ⇒ 每 τ 的真实间隙 ≥d_safe；A3 把离散 tick 界延拓到连续时域（相邻 tick 间隙变化 ≤v_maxΔt）。effort 同理。对 τ 与 ℓ 取并集界收尾。∎

**引理 93（双通道检测并集界与显式共模项）** 令 A={语义通道触发}，B={动力学通道触发}，P(A^c)≤ε_sem，P(B^c)≤ε_dyn。则无需独立性假设有 P(A∪B)≥1−ε_sem−ε_dyn；若两通道独立则 ≥1−ε_semε_dyn。定义共模失效率 ε_cm=P(A^c∩B^c)，恒有 ε_cm≤min(ε_sem,ε_dyn)，且证书风险应使用 ε_cm（E595 实测）而非独立乘积。若任一通道在事件首帧给出证据，则守卫（50Hz）检测延迟 ≤20ms。推论：当 ε_cm 接近 min(ε_sem,ε_dyn) 时，第二通道增益很小——这是可测事实，不是可假设的独立性。∎

**引理 94（预测单调性与精确退化）** (i) 中性预测（P_ℓ(τ)={p_ℓ}、ε_dyn≡0、ρ_dyn≡0）⇒ β_SDT=β_STF、g_min^[0:K]=min_τ ĝ_min(τ)，Ĉ^‡ 与 v10 Ĉ⁺ 等价，K_eff^v11=K_eff^v10；(ii) 任一非退化管道只会减小 g_min、增大 β_SDT，故 Π_pred(C)⊆C，可行集只收缩；(iii) 若 ε_dyn(τ)→∞（τ>Δt），则 K*=0，证书退化为静态 v10 且 K≤1。证明：min 与 sup 的单调性、β_SDT 对 ε_dyn 的线性正系数直接可得。∎

**引理 95（动态停车不变式充分性）** 若在每一守卫 tick 定义 555 成立，且真实地标位于预测管道内，则存在一条刹车/中止轨迹在停驻完成前对所有真实地标保持间隙 ≥d_safe。证明：由定义 555(i) 存在可达 p*，由 v9 定义 534 的中止点可达性构造执行轨迹；由 (ii) 与 A1 的管道包含关系，真实间隙 ≥ 预测间隙−ε_dyn ≥d_safe+β_SDT；对 tick 归纳，每次重规划仍满足不变式。注：若走廊内不存在任何满足 (i)(ii) 的 p*，则不变式不可建立，系统必须更早中止——这是活性假设（E597/E598 验证），不是安全定理的免费部分。∎

**引理 96（可解时域与保守性权衡）** 在定义 560 的线性接近/二次误差界下，时域证书可行性等价于 A−(v_rel+λ_dα)τ−(λ_da_max/2)τ²≥0 对所有 τ≤KΔt 成立。故 K*=⌊τ*/Δt⌋，且 ∂K*/∂v_rel≤0、∂K*/∂α≤0、∂K*/∂a_max≤0、∂K*/∂λ_d≤0；A≤0 时 K*=0，必须中止或退化为静态。证明：二次式对 τ 单调递减（系数非负），正根唯一；各参数均为非负系数，隐函数求导即得单调性。∎

**引理 97（双通道与预测的联合可靠性，诚实版）** 若引理 92 的时空证书在非显著事件上成立，引理 93 的双通道在显著事件上成立，则任一中块危险事件的漏检概率 ≤ε_cm+ε_p+ε_β；不存在"双通道独立"的额外折扣，除非 E595 实测支持。证明：按事件是否被 E_t 捕获二分，未被捕获者为共模事件，其概率 ε_cm；再叠加预测/模型误差项，并集界收尾。∎

## 8. 本轮最大风险

**一句话**：双通道互证的安全性依赖"语义异常与动力学异常不同时发生"——协同对抗（既改纹理又改运动学）或人群/非刚体等长尾动力学可造成共模失效（引理 93/97 已显式保留 ε_cm），而 ε_dyn(τ) 随预测时域膨胀会使 β_SDT 大到 K*=0（引理 96），系统在"过度保守导致任务失活"与"共模穿透导致隐蔽失效"之间被双向挤压。
