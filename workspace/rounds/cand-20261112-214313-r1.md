# 第 1 轮（灵感循环 v2：「移动底盘」×「阻抗控制」）—— 从「无执行权」到「柔顺姿态动作端口」的第二次方向校正

> 承接 v1 的赛制校正（选手 = 远程 `observation→action` API 提交者）。本轮用两个灵感词做**第二次、且更细的方向校正**：v1 断言「选手不接触执行层」只对了一半。接口里有一个**每个提交都必须返回、却被官方示例全部置零**的 7 维 `action.pivot` 通道；公开数据的逐行统计又表明，它在 32 个桌面任务里几乎从不平移底盘，只用来调**身高 / 腰姿**。因此在本赛制里，「移动底盘」应读作**准静态姿态宏自由度**，「阻抗控制」应读作**动作端口上的导纳 / 参考整形**。两者合流成一个 v1 清单完全没覆盖的杠杆：**用姿态与参考柔顺性，去换接触类任务的成功率与步骤分**。

---

## 0. 直觉先行（Intuition）

**直觉 A：示例代码把 `action.pivot` 置零，等于扔掉了一条免费的慢速执行通道。** 一个必须返回的 7 维动作键，官方示例用 `np.zeros((T,7))` 打发；而公开数据里它并非零，而是 `[0,0,0, ·, 0.15, ·, 0.74]` 这样的**姿态设定**。多数队伍大概率照抄示例——这构成一个低竞争、低风险的差异化点。

**直觉 B：阻抗控制的本质不是「调增益」，而是「命令流对外力的让步」。** 我们没有力矩/刚度通道，改不了电机阻抗；但我们能改**目标本身**。当「命令领先于实测」持续存在时，把它当作接触代理，让目标回退——这就是导纳控制（admittance control）。**用位置端口实现柔顺**，不需要任何执行层权限。

**直觉 C：这个 benchmark 里的「移动底盘」不是「车」，而是「可蹲起的身体」。** 数据里 `vx=vy=yaw=0`，`height` 在 0.637–0.740 m 间变化，`pivot_4≈0.15 rad` 恒定。把它当导航底盘去平移是分布外（OOD）；把它当**姿态宏自由度**（蹲起、腰俯仰）则完全在分布内。灵感词要按数据落地，而不是按字面落地。

**直觉 D：柔顺不是越软越好，而是「只在会丢分的地方软」。** 排行榜按成功率 + 步骤分；过度柔顺会把「本可精确插入」变成「永远差一点」。所以柔顺必须由**分数期望**门控，而不是由「检测到接触」门控。这是与常规阻抗控制研究最反直觉的分歧：**优化对象是排名收益，不是力跟踪误差。**

## 2. 严谨定义（Definitions）

### D1 动作端口模型
第 \(t\) 步策略输出
\[
u_t=(u^{arm}_t,\ u^{grip}_t,\ u^{piv}_t),\qquad
u^{piv}_t=(v_x,v_y,\omega_z,\pi_3,\pi_4,\pi_5,h).
\]
joint 模式下 \(u^{arm}\) 为 7 维关节目标；ee 模式下为基座系 EE 位姿目标。评测器内部闭环 \(\mathcal C\) 把参考 \(u_t\) 变成下一状态 \(y_{t+1}\)，但 \(\mathcal C\) 未知。**我们唯一能控制的是参考流 \(u_{0:t}\)，不是力矩。**

### D2 跟踪残差与接触代理
令 \(r_t=u_{t-1}-y_t\)（命令减实测）。把它分解为
\[
r_t=r^{lag}_t+r^{sat}_t+r^{con}_t+\epsilon_t,
\]
其中 lag 是内环跟随滞后、sat 是关节/速度限幅、con 是外部约束（接触/卡阻）。用自由空间段拟合 \(\hat r^{lag}_t=\hat v_t\,(1-\alpha)/\alpha\)（\(\alpha\) 为内环一阶增益估计），定义接触代理
\[
\hat f_t=K_e\,\max\!\big(0,\ r_t-\hat r^{lag}_t-\hat r^{sat}_t\big).
\]
\(\hat f_t\) 只是**代理力**，不是力传感器读数；它的尺度 \(K_e\) 由离线/在线标定吸收。

### D3 命令空间导纳（参考整形）
给定标称参考 \(u^{nom}_t\)，导纳状态 \(a_t\) 满足
\[
M_d\ddot a+D_d\dot a+K_d a=-\hat f_t,\qquad u_t=u^{nom}_t+a_t,
\]
并加**单向让步**约束 \(a_t\le 0\)、幅值 \(|a_t|\le a_{\max}\)、速率 \(|\dot a_t|\le \dot a_{\max}\)。ee 模式直接作用于 EE 目标；joint 模式经臂雅可比映射 \(q^{cmd}=q^{nom}+J^\dagger a\)。稳态让步比例可解析得到：
\[
a_\infty=-\frac{K_e}{K_d+K_e}\,r^{0},\qquad r^0=u^{nom}-y,
\]
即**吸收比例只由 \(K_e/K_d\) 决定**，与接触刚度无关——这正是「用位置端口实现柔顺」的关键。

### D4 姿态宏自由度与全身柔顺分配
把 `pivot` 的姿态分量记为 \(p=(h,\pi_3,\pi_4,\pi_5)\)。数据支撑集
\[
\mathcal H=[0.637,0.740]\ \text{m},\qquad \pi_4\approx0.15\ \text{rad}.
\]
定义慢时标姿态让步 \(a^p_t\)（高度/腰俯仰），快时标臂让步 \(a^a_t\)。期望世界系 EE 修正 \(\Delta x\) 由臂、腰、身高共同承担：
\[
\Delta x\approx J_a\Delta q_a+J_\theta\Delta\theta+J_h\Delta h .
\]
在 chunk 边界解
\[
\min_{\Delta q_a,\Delta\theta,\Delta h}\ \|\Delta x-J_a\Delta q_a-J_\theta\Delta\theta-J_h\Delta h\|^2
+\lambda_a\|\Delta q_a\|^2_{W_a}+\lambda_p\|(\Delta\theta,\Delta h)\|^2_{W_p}+\lambda_s\|\Delta^2(\cdot)\|^2
\]
s.t. 关节限位、\(\sigma_{\min}(J_a)\ge\epsilon\)、\(h+\Delta h\in\mathcal H\)、\(|\Delta h|\le\Delta h_{\max}\)。低频/大幅分量分给姿态，高频/小幅分量分给臂——这就是**宏微分配**。

### D5 框架一致性
EE 目标在基座系。姿态一动，基座系随动。设基座位姿 \(T_{WB}(p)\)，世界目标 \(x^W\)，则正确基座系目标为 \(x^B=T_{WB}(p)^{-1}x^W\)。若忽略此项，姿态变化会叠加一个未受控的世界位移
\[
\Delta x^W_{\text{err}}=\big(T_{WB}(p')-T_{WB}(p)\big)x^B .
\]
因此必须从数据辨识 \(J_h,J_\theta\)（pivot → EE 基座/躯干位移），并在每次姿态让步后做前馈补偿；否则「柔顺」会变成「整只手跟着身体漂」。

### D6 无源性与可信度约束
离散能量罐 \(E_t\ge0\)：每次导纳更新最多取用 \(E_t\)，不允许注入能量；命令加加速度满足 \(\|u_t-2u_{t-1}+u_{t-2}\|\le J_{\max}\)；每步计算量固定（不做变长优化）。可信度约束
\[
P[\text{latency}>L_{\max}]\le\delta_\ell,\qquad D_{\text{smooth}}\le D_{\max}.
\]
这直接对应赛制「逐步延迟及其波动 + 动作统计规律性」的可信度检查。

### D7 分数感知门控
主动柔顺只在
\[
\mathbb E[\Delta S\mid \hat f_t]\ >\ \lambda_\ell\,\mathbb E[\Delta t]+\lambda_c\,P(\text{cred flag})+\lambda_j\,\Delta D_{\text{smooth}}
\]
时触发；否则走被动包络（标称参考）。这把「检测到接触就软」改成「**会丢分才软**」。

### D8 任务-相位刚度调度
按任务 \(i\) 与相位 \(\phi\in\{\text{free},\text{approach},\text{contact},\text{insert},\text{release}\}\) 配置
\[
\theta_{i,\phi}=(M_d,D_d,K_d,a_{\max}).
\]
相位边界由数据中的接触事件（夹爪开合、EE 速度骤降、物体相对运动）切分，得到一个小型「阻抗原语库」。接触/插入相位用低刚度、高阻尼；自由空间用高刚度、零让步。

## 3. 两个灵感词的合流

- **移动底盘 → 姿态宏自由度**：不是导航，而是**可蹲起、可俯仰的身体**。它慢、稳、幅度有限（数据内 ~10 cm 身高 + ~0.15 rad 腰俯仰），适合吸收**准静态、大幅值**的接触误差，并做**够不到**时的可达性修剪。
- **阻抗控制 → 命令空间导纳**：不是调电机增益，而是**参考整形**。它快、细、幅度小，适合吸收**动态、小幅值**的接触误差。
- **合流命题**：两者是同一件事的两个时间尺度。**慢姿态吸收大误差，快手臂吸收小误差**；用分数门控决定「何时软、软多少」，用无源性/平滑约束保证「软得可信」。这比单独做「手臂柔顺」或单独做「身高调节」都更接近阻抗控制的原始动机——**在不确定环境中维持可接受的交互性能**。

## 4. 瓶颈假设与边际收益算术

- 32 个任务里约 1/3 是接触密集（插充电器、插/拔网线、开锁、注射器、倒药、拉拉链、折毛巾、叠杯、取电池、收纳耳机等）。刚性位置目标在这些任务上最典型的失效不是「抓不到」，而是**插入时卡住 / 顶飞物体 / 超时**，直接丢掉后续步骤分。
- 设某接触任务失败的条件均分为 \(s\)，成功率 \(p\)。v1 已给出 \(R=100p+(1-p)s\)；在 \(p=0.25,s=40\) 时，失败部分分 \(+10\) 约 \(+7.5\) 榜分，成功率 \(+10\text{pp}\) 约 \(+6.0\) 榜分。柔顺主要抬的是 \(s\) 与「接触步完成率」，因此**与 v1 的重试/安全网互补，而不是重复**。
- 可达性：腰俯仰 0.15 rad、躯干长约 0.30 m 时，肩部前移约 \(0.30\sin0.15\approx4.5\) cm；对 0.60 m 臂展、0.63 m 目标，归一化伸展从 1.05（不可达）降到 0.975（可达）。这是一个**纯几何、无需学习**的小幅收益，但足以救回「位置泛化」轴上的边缘样本。
- 代价：导纳每步 O(1)，延迟可忽略；主要成本是**误判接触**导致的错误让步。因此瓶颈不是算力，而是**接触代理的判别质量**与**门控**。

## 6. 旗舰点的直觉

**CAP-01 / PACT** 的默认状态是**被动包络**：直接输出标称策略的动作块，零额外风险、零额外延迟。只有当「命令领先实测」持续存在、且腕部视觉/夹爪状态支持接触假设、且当前相位属于接触/插入时，才启动两时标导纳：手臂在细方向让步，腰/身高在粗方向让步；让步有幅值/速率上限，能量罐保证不振荡；一旦接触代理消失或位置误差超限，平滑回退到标称。**它不追求「检测所有接触」，而追求「在会丢分的接触上，用最便宜、最平滑的让步把步骤分保住」。**

## 7. 本轮最大风险（一句话）

**最大风险：`action.pivot` 的 height/腰姿语义与评测器实际执行方式尚未在真机核实——若评测器忽略、重置或对 pivot 做安全限幅，整套姿态柔顺会退化为纯手臂导纳，收益明显缩水；因此必须先做 PSI 语义辨识并保留「仅手臂」降级路径，再谈押注。**

## 1. 动作端口的形式化与可观测性

### 1.1 状态与动作
- 观测：4 路图像；双臂 7 维关节；双臂基座系 EE 位姿 \(x^B\in SE(3)\)；夹爪开度；`lower_body` 15 维（12 腿 + 3 腰）；语言指令。
- 动作：joint 模式 \(q^{cmd}\in\mathbb R^{14}\) 或 ee 模式 \(x^{B,cmd}\in SE(3)^2\)；夹爪 2 维；`pivot` 7 维 \(u^{piv}=(v_x,v_y,\omega_z,\pi_3,\pi_4,\pi_5,h)\)。
- **不可观测**：接触力/力矩、电机电流、真实世界系基座位姿、物体位姿真值。

### 1.2 可辨识量
从公开数据可离线辨识：
1. \(u^{piv}\) 的字段语义与单位（尤其 \(h\) 与 \(\pi_4\)）；
2. \(u^{piv}\mapsto\) `lower_body` / EE 基座/躯干位姿的雅可比 \(J_h,J_\theta\)；
3. 内环一阶增益 \(\alpha\) 与 lag 偏置（用自由空间段回归）；
4. 任务/相位的接触事件分布（用于 D8 刚度调度）。

## 2. 旗舰 CAP-01 · PACT（Postural Admittance + Contact-aware Tracking）

### 2.1 架构

```
obs ──► 标称策略 π0 ──► u_nom ──────────────────────────┐
  │                                                      │
  ├─► CPD 接触代理估计 f_hat ──► D7 分数门控 ──否──► 直出 u_nom（零风险）
  │                                   │是
  │                                   ▼
  ├─► D8 相位/任务刚度 θ_{i,φ} ──► D3 导纳 a_t（臂 + 姿态）
  │                                   │
  │                                   ▼
  ├─► D5 框架补偿 ◄── PSI J_h,J_θ ── D4 全身分配 QP（chunk 边界）
  │                                   │
  └───────────────────────────────► D6 无源/平滑护栏 ──► u_t
```

### 2.2 伪代码

```python
class PACT:
    def __init__(self, nominal, psi, cpd, schedule, wbca, fcps, pcg,
                 k=4, ke=100.0, f_on=1.5, f_off=0.5, tau_on=2, tau_off=4):
        self.nominal, self.psi, self.cpd = nominal, psi, cpd
        self.schedule, self.wbca, self.fcps, self.pcg = schedule, wbca, fcps, pcg
        self.k, self.ke = k, ke
        self.f_on, self.f_off, self.tau_on, self.tau_off = f_on, f_off, tau_on, tau_off
        self.reset()

    def reset(self):
        self.nominal.reset()
        self.adm = AdmittanceState()      # a, da, energy tank
        self.last_u_arm = None
        self.last_y_arm = None
        self.phase = "free"
        self.on_count = self.off_count = 0
        self.active = False

    def get_action(self, obs):
        u_nom = self.nominal.get_action(obs)          # dict of chunks (T_a, ...)
        task = obs["observation.language"]

        # (1) 接触代理：lag / sat / contact 分解
        f_hat = self.cpd.estimate(obs, self.last_u_arm, self.last_y_arm,
                                  phase=self.phase)

        # (2) 分数门控 + 迟滞（D7）
        self.on_count = self.on_count + 1 if f_hat > self.f_on else 0
        self.off_count = self.off_count + 1 if f_hat < self.f_off else 0
        if not self.active and self.on_count >= self.tau_on:
            self.active = True
        if self.active and self.off_count >= self.tau_off:
            self.active = False

        if not self.active:
            self.pcg.account(0.0)                     # 无能量支出
            self.last_u_arm = u_nom["action.left_arm"][0]
            return u_nom

        # (3) 导纳（D3）：单向让步 + 幅值/速率上限
        theta = self.schedule.get(task, self.phase)   # (M,D,K,a_max)
        a, da, ok = self.adm.update(f_hat, theta, dt=1/30)
        if not ok:                                    # 能量罐/稳定性拒绝
            self.active = False
            return u_nom

        # (4) 全身分配（D4）：低频给姿态、高频给臂
        a_arm, a_post = self.wbca.allocate(a, obs, self.psi, theta)

        # (5) 框架一致补偿（D5）：姿态动，基座系 EE 目标要反补
        a_arm = self.fcps.compensate(a_arm, a_post, obs, self.psi)

        # (6) 只承诺前 k 步，之后保持（避免整块盲走）
        u = self.apply(u_nom, a_arm, a_post, self.k)
        u = self.pcg.shape(u, self.last_u_arm)        # 加加速度限幅
        self.last_u_arm = u["action.left_arm"][0]
        return u
```

### 2.3 接触代理消歧（CPD）

```python
def estimate(obs, u_prev, y, phase):
    r = u_prev - y                                  # 命令 - 实测（臂）
    v_hat = (y - y_prev) / dt
    r_lag = max(0.0, v_hat) * (1 - alpha_hat) / alpha_hat
    r_sat = sat_indicator(y, u_prev)                # 关节/速度限幅
    r_con = max(0.0, r - r_lag - r_sat)
    persist = persistence_count(r_con > tau_r) >= tau_on
    vis = wrist_contact_classifier(obs)             # 腕部图像：物体贴近/遮挡/形变
    grip = gripper_force_proxy(obs)                 # 夹爪开度变化率/堵转代理
    if persist and vis > c_vis and grip > c_grip and phase in {"contact","insert"}:
        return K_e * r_con
    return 0.0
```

> 关键：**单帧残差不够**，必须要求「持续 + 视觉支持 + 夹爪支持 + 相位正确」四者同时成立，才能把误报压到可接受水平。

## 3. 关键推导

### 3.1 导纳离散化与稳定性
连续方程 \(M\ddot a+D\dot a+Ka=-\hat f\)。半隐式欧拉（\(dt=1/30\)）：
\[
\dot a_{t+1}=\dot a_t+\frac{dt}{M}\big(-\hat f_t-D\dot a_t-Ka_t\big),\qquad
a_{t+1}=a_t+dt\,\dot a_{t+1}.
\]
状态矩阵
\[
A=\begin{pmatrix}1-\frac{dt^2K}{M} & dt\big(1-\frac{dtD}{M}\big)\\[2pt]-\frac{dtK}{M} & 1-\frac{dtD}{M}\end{pmatrix}.
\]
实用稳定条件：\(\omega_a=\sqrt{K/M}\ll\omega_{\text{inner}}\)，\(D\ge2\sqrt{MK}\)（临界阻尼），\(dt\,\omega_a\le0.2\)。本轮仿真取 \(M=1,D=6.3,K=10\)，\(\omega_a=3.16\) rad/s，\(dt\omega_a=0.105\)，满足条件。

### 3.2 稳态让步比例（为什么位置端口也能柔顺）
设接触代理 \(\hat f=K_e(r^0+a)\)，其中 \(r^0=u^{nom}-y\) 是零让步时的残差。稳态 \(Ka=-\hat f\)，故
\[
a_\infty=-\frac{K_e}{K_d+K_e}r^0 .
\]
- \(K_e\gg K_d\)：几乎完全吸收残差（软）；
- \(K_e\ll K_d\)：几乎不让步（硬）。
**让步比例与接触刚度无关**，只由代理尺度与导纳刚度之比决定——这就是「用位置目标实现导纳」的核心。仿真中 \(K_e=100,K_d=10\)，理论吸收 90.9%，与结果一致。

### 3.3 残差 lag 偏置
一阶内环 \(y_{t+1}=y_t+\alpha(u_t-y_t)\) 在匀速 \(v\) 下稳态 \(r=u-y=v(1-\alpha)/\alpha\)。若直接用 \(r\) 当接触，会把**快速运动**误判为接触。故必须先减 \(\hat r^{lag}\)。\(\alpha\) 可由自由空间段回归 \(r\sim v\) 得到；\(\alpha\) 估计偏差 \(\Delta\alpha\) 造成的力偏置约为 \(K_e v\,\Delta\alpha/\alpha^2\)，因此低速段（接近接触时）误报最小——这也解释了为什么门控要加「相位=contact/insert」。

### 3.4 全身分配 QP
令 \(z=(\Delta q_a,\Delta\theta,\Delta h)\)，\(A=[J_a,J_\theta,J_h]\)：
\[
z^\star=\arg\min_z\ \|Az-\Delta x\|^2+z^\top Wz
\quad\text{s.t.}\quad
q_a+\Delta q_a\in Q_{\lim},\ \sigma_{\min}(J_a)\ge\epsilon,\ h+\Delta h\in\mathcal H.
\]
闭式（无约束）为 \(z^\star=(A^\top A+W)^{-1}A^\top\Delta x\)；有约束时用 7–14 维小 QP + 热启动，单次 <1 ms。频率分配可用一阶低通 \(L(s)=1/(1+\tau s)\)：姿态吃 \(L(s)\Delta x\)，臂吃 \((1-L(s))\Delta x\)，\(\tau\) 取 3–5 步。

### 3.5 可达性修剪（解析估计）
躯干长 \(l=0.30\) m、腰俯仰 \(\theta=0.15\) rad，肩部前移
\[
\Delta s=l\sin\theta=0.30\times0.1494\approx0.0448\ \text{m}.
\]
目标 \(d=0.63\) m、臂展 \(R=0.60\) m：
\[
\frac{d}{R}=1.05\ \longrightarrow\ \frac{d-\Delta s}{R}=0.975.
\]
即 **4.5 cm 的姿态前移把「不可达」拉回「可达」**。这是几何估计，未计腰-臂耦合与奇异，需 PSI 用数据校准。

### 3.6 分数门控阈值
把 D7 简化为可执行的迟滞门：
\[
\text{engage if } \hat f>f_{\text{on}}\ \text{持续}\ \tau_{\text{on}}\ \text{步};\qquad
\text{disengage if } \hat f<f_{\text{off}}\ \text{持续}\ \tau_{\text{off}}\ \text{步}.
\]
\(f_{\text{on}}\) 由「错误让步的期望分数损失」与「卡阻的期望分数损失」相等点确定；在拿到真实榜单前，用离线回放的步骤分代理校准。

## 4. PSI：pivot 语义辨识（离线，零真机风险）

1. 读 `meta/info.json` 的 features，确认 `action.pivot` 的 7 个字段名与 `action.base_command` 的对应关系。
2. 逐任务统计：`vx,vy,angle_z` 非零率（预期 0）；`height` 支撑集；`pivot_4` 是否恒定。
3. 在 height 有变化的任务（OrganizeBookshelf、PaperCupStacking、FoldTowel）上拟合
   \[
   \Delta z^{B}_{EE,t}\approx a_h\,\Delta h_t+a_\theta\,\Delta\pi_{4,t}+b,
   \]
   并检验 \(a_h\approx1\)（若 height 就是基座高度）与 \(a_\theta\) 的符号/量级。
4. 用留出任务做 \(R^2\) 与残差检验；若 \(R^2\) 低，退回「仅手臂导纳」。
5. **OOD 护栏**：只允许 \(h\in[\min_{\text{task}}h,\max_{\text{task}}h]\)；`vx=vy=angle_z=0` 永久锁定；`pivot_3/5` 保持数据众数。
6. 可选在线探针：episode 开始时给 \(h\) 一个 ±5 mm 小阶跃，观测 EE 基座 \(z\) 响应；仅当离线映射不确定时启用，且必须在安全高度内。

| \(k_c\) (N/m) | 方案 | 峰值代理力 (N) | 接触后均值 (N) | 冲量 (N·s) | 卡阻比例 | 命令 RMS jerk |

**读法**：
- 三档刚度下峰值代理力均下降 **87.7%**，冲量下降 **94.7%**；最硬环境下卡阻比例从 **0.60 → 0.00**。
- 代价是命令 RMS jerk 从 8.05e-5 升到 9.78e-5（**+21.6%**），但命令总变差反而下降 **13.5%**（0.120 → 0.104）——说明让步是**平滑的、非振荡的**。

## 7. 风险与下一步

1. **最大风险**：pivot 语义/执行方式未真机核实；评测器可能忽略或重置 pivot。→ 先做 PSI + 仅手臂降级路径。
2. 接触代理误报：lag/sat 分解依赖 \(\alpha\) 估计；→ 用自由空间回归 + 四条件门控 + 迟滞。
3. 过度柔顺导致「永远差一点」：→ 分数门控 + 让步幅值/时长上限 + 插入阶段末段提高刚度（刚度调度）。
4. 姿态变化影响平衡/安全：→ 只在数据支撑集内调 height/腰俯仰，且速率限幅。
5. 可信度：导纳带来额外命令变化；→ 能量罐 + jerk 限幅 + 固定计算量；离线先测动作统计包络。
6. 真机不可反复试：→ 先用 E-CAP-01/03/05 的离线代理做门禁，再预约真机 A/B。

**下一步（若进入下一轮）**：把 PSI 在 32 个数据集上跑通，产出 `pivot→EE/下肢` 的回归表与 OOD 护栏；用 E-CAP-03 在 3–5 个接触密集任务上做离线回放，确定 \(K_e/K_d\)、\(f_{\text{on}}\)、\(a_{\max}\) 的可行域。

**本轮最大风险（承接想法区 §7，一句话）**：`action.pivot` 的 height/腰姿语义与评测器执行方式尚未真机核实；若评测器忽略、重置或限幅 pivot，姿态柔顺会退化为纯手臂导纳——所以必须先做 PSI 辨识并保留降级路径，再谈押注。
