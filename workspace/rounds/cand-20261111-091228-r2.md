# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「异常检测」×「手眼标定」）

> 第 54 轮把技能组合推进到动作空间剖面与云边联合证书，但整套体系有一个未言明的前提：**感知与动作共享同一个已知坐标系**。现实中手眼标定 `T_he` 是隐变量、会漂移、且在动作空间上非均匀地污染证书；异常检测则是这套证书体系缺失的**运行时证伪器**。核心矛盾：H22：所有 `α_S`、`γ_ce`、`ρ` 与组合证书都在名义坐标系中评估，手眼误差使它们在“错误的尺子”上被判定为 sound；H23：朴素异常检测把“世界变了”和“我们的眼/手偏了”混为一谈，导致恢复动作南辕北辙（该重标定时去重探索，该重规划时去重标定）。

## 0. 直觉与动机

**灵感 1（手眼误差不是一个噪声标量，而是一个 se(3) 隐变量管）**
直觉：第 54 轮把动作空间写成 `A = A_c × A_e`，却默认存在一个精确的 `T_he : camera → end-effector`。真实的手眼标定误差 `δξ ∈ se(3)` 是**系统性、持续性、随位姿变化**的：同一个偏移在小臂展处几乎无害，在伸展/遮挡/近距离处会把动作效应放大成几厘米的偏差。因此证书不能建立在单点 `T_he` 上，而应建立在一条**不确定管** `B_Σ(ε) = {T_he·exp(δξ^) : δξᵀΣ⁻¹δξ ≤ ε²}` 上。技能不是“在某个坐标系里可用”，而是“在一条标定管里仍然可用”。这把标定从一次性离线步骤变成证书的一等公民。

**灵感 2（异常检测应发生在动作-效应残差空间，而不是像素空间）**
直觉：像素空间的 novelty 无法区分“桌上多了一个杯子”和“相机外参偏了 2°”。但机器人天然拥有一个更强的信号：**我命令了动作 a，预期效应是 ê(a)，实际效应是 e**，残差 `r = e − ê`。对手眼误差，一阶展开给出 `r ≈ J_he(a)·δξ + 噪声`，即残差落在 `J_he` 的列空间里；对任务/环境异常，残差一般不在该低维子空间。于是“异常检测”被改写成**结构化残差的子空间归因问题**：先问“残差像不像坐标系错了”，再问“残差有多大”。这是从 novelty detection 到 certificate-violation detection 的转变。

**灵感 3（主动标定：把探测动作当作信息采集，而不是停机标定）**
直觉：既然残差能估计 `δξ`，就不必停机做一整套 `AX=XB`。可以选一组**探测动作**，让它们在当前标定管内仍然安全、却能最大化对手眼参数的 Fisher 信息（D-optimal）。机器人一边执行任务，一边在证书允许的 `A_core` 内“顺路”激发可观测方向，用少量动作把 `ε` 收缩。关键是安全约束：探测动作必须在当前不确定管的**最坏情况**下仍落在 `A_buffer` 内，否则宁可放弃信息增益。

**灵感 4（标定相容的技能组合：先对齐坐标系，再谈动作交集）**
直觉：第 54 轮的 `compat(S_i,S_j)` 假设两技能共享同一标定。若 `S_i` 在东侧工作区标定、`S_j` 在西侧工作区标定，它们的**可接受标定集** `E_i, E_j` 可能根本不交。组合可行的第一性条件不是动作重叠，而是 `E_i ∩ E_j ≠ ∅` 且交集直径不超过容差：**两个技能必须对“世界在哪里”达成共识，才配谈“动作怎么接”**。这把组合证书从 `(A_overlap, ρ_comp, γ_ce)` 扩展为带回共同标定估计的 `C_cal`。

**灵感 5（异常触发的重剖分闭环：错误坐标系里的一切证书都应立即失效）**
直觉：第 54 轮的 Explain 回传解决“为什么失败”，但没有回答“是不是尺子先错了”。新闭环应为：边端 CSAD 检测到结构化标定异常 → 估计 `δξ̂` 并定位受污染的动作区域 `A_drift` → 云端只重剖分受影响技能与组合边 → 重建 `J_cal`。若归因为任务异常，则**冻结标定**，走保守技能子集与重规划。两条恢复路径必须互斥，否则会陷入“越标越偏、越偏越标”的震荡。

**灵感 6（金字塔扩展：在动作-鲁棒性层之下补一层“坐标系一致性”）**
直觉：第 53 轮的 `𝕃` 是鲁棒性层，第 54 轮的 `𝔸` 是动作-协同层，但两者都悬空在一个未验证的坐标系上。本轮补上 `ℂ` 层：`ℂ_0` 原始传感与驱动，`ℂ_1` 手眼估计及其不确定管，`ℂ_2` 标定条件动作剖面，`ℂ_3` 标定相容技能组合，`ℂ_4` 证书运行时异常监控。`ℂ` 是 `𝔸` 与 `𝕃` 的**地基**：地基偏移时，上层证书越精致，错得越系统。

## 1. 形式化定义（增量：定义 121–128）

**定义 121（手眼变换与不确定管）**
手眼变换 `T_he ∈ SE(3)`，误差用李代数参数化：`T(δξ) = T_he·exp(δξ^)`，`δξ ∈ ℝ⁶`。给定标定协方差 `Σ` 与半径 `ε`，不确定管
```
B_Σ(ε) = { T_he·exp(δξ^) : δξᵀΣ⁻¹δξ ≤ ε² }.
```
`ε` 由标定残差、温漂先验与在线后验共同给出；`T_he` 永远只是管的中心，不是“真值”。

**定义 122（标定条件动作剖面与标定裕度）**
技能 `S` 的标定条件剖面 `α_S(a | T) ∈ [0,1]` 表示在坐标系 `T` 下动作 `a` 的可执行/覆盖度；最坏情况剖面
```
α_S^ε(a) = inf_{T∈B_Σ(ε)} α_S(a | T).
```
**标定裕度**定义为
```
m_cal(S, A_T) = sup{ ε : α_S(a|T) ≥ θ_cov, ∀a∈A_T, ∀T∈B_Σ(ε) }.
```
若 `α_S` 对 `δξ` 是 `L_α`-Lipschitz 的，则可用下界 `m_cal ≥ min_{a∈A_T}(α_S(a|T_he) − θ_cov)/L_α` 快速估计。称技能在 `ε` 下**标定可部署**当且仅当 `m_cal ≥ ε`。

**定义 123（动作-效应残差的结构化分解）**
对动作 `a`，名义模型预测效应 `ê(a; T_he)`，实际观测效应 `e`，残差 `r = e − ê(a; T_he)`。一阶模型：
```
r ≈ J_he(a)·δξ + J_task(a)·δθ + n,   n ~ N(0, Σ_n),
```
其中 `J_he = ∂e/∂ξ` 为手眼雅可比，`J_task` 为任务/环境参数雅可比。定义 `Σ_n`-加权到 `col(J_he)` 的投影 `P_he(a)`，以及**结构化比例**
```
ψ(a) = ||P_he(a) r||²_{Σ_n⁻¹} / ||r||²_{Σ_n⁻¹}.
```
`ψ≈1` 表示残差可由坐标系偏移解释；`ψ≈0` 表示残差在标定自由度之外，更像环境/任务异常。

**定义 124（标定异常检验与归因）**
在 `H_cal: r = J_he δξ + n` 下，广义最小二乘估计
```
δξ̂ = (J_heᵀΣ_n⁻¹J_he)⁻¹ J_heᵀΣ_n⁻¹ r,   Σ_δ = (J_heᵀΣ_n⁻¹J_he)⁻¹.
```
检验统计量 `Λ = δξ̂ᵀΣ_δ⁻¹δξ̂ ~ χ²_6`。归因规则：
- **标定异常**：`Λ > χ²_{6,1−α}` 且 `ψ ≥ θ_ψ`，且残差在时间窗内**持续且随位姿可重复**；
- **任务异常**：残差显著但 `ψ < θ_ψ`，或标定解释的边际似然增益不足；
- **混合/不可判**：两者都不占优，进入主动探测消歧，禁止直接重标定。
为控制误报，阈值取在线残差经验分布的共形分位数（conformal quantile），而非固定卡方分位。

**定义 125（标定相容技能组合）**
技能 `S` 在任务动作集 `A_T` 上的可接受标定集
```
E_S(A_T) = { T ∈ SE(3) : α_S(a|T) ≥ θ_cov ∀a∈A_T,  ρ_S(d|T) ≥ ρ_min ∀d }.
```
组合 `S_1⊗…⊗S_k` **标定相容**当且仅当
```
E_common = ⋂_i E_{S_i}(A_T) ≠ ∅  且  diam(E_common) ≤ δ_E.
```
其组合标定证书 `C_cal = (T*, E_common, ε_common, evidence)`，其中 `T*` 取交集的 Chebyshev 中心。动作兼容性 `compat` 只在 `C_cal` 通过后才有意义：**先坐标系共识，后动作重叠**。

**定义 126（主动标定探测与信息增益）**
探测序列 `π = (a_1,…,a_k) ⊆ A_safe(ε)`，累积 Fisher 信息
```
I_k = I_0 + Σ_t J_he(a_t)ᵀΣ_n⁻¹J_he(a_t).
```
D-optimal 探测目标：
```
max_π  log det(I_k)
s.t.   a_t ∈ A_safe(ε)  （在 B_Σ(ε) 最坏情况下效应仍落在 A_buffer）
       Σ_t risk(a_t) ≤ B_risk.
```
其中 `A_safe(ε) = { a : ∀T∈B_Σ(ε), effect(a,T) ∈ A_buffer }`。信息增益只对**可观测方向**有效：若 `J_he` 在 `A_safe` 上秩亏，则拒绝宣称收缩，转入外部标定。

**定义 127（标定条件鲁棒性证书）**
标定条件联合证书
```
J_cal = (T_he, Σ, ε, α_S^ε, ρ_S^ε, C_cal, detector_policy, probe_policy).
```
称组合**可部署**当且仅当：
```
cover(α_S^ε, A_T) ∧ min_d ρ_S^ε(d) ≥ ρ_min ∧ ε ≤ ε_max ∧ m_cal ≥ ε
∧ CSAD 误报率 ≤ α ∧ 探测风险预算未超支.
```
`J_cal` 是第 54 轮 `J` 的**前置证书**：先证明尺子没错，再证明动作与鲁棒性成立。

**定义 128（异常触发重剖分闭环）**
闭环状态 `(T_he, Σ, ε, G_S, J_cal)`，每个监控周期执行：
- 正常：继续任务；
- 标定异常：估计 `δξ̂`，融合更新 `(T_he, Σ, ε)`，令 `A_drift = {a : ψ(a) ≥ θ_ψ}`，云端只重剖分 `A_drift` 涉及的技能及 `G_S` 中相应边，重建 `J_cal`；
- 任务异常：冻结标定，切换到保守技能子集 `K_safe` 或请求云端重规划；
- 不可观测：证书作废，请求外部标定/安全停机，禁止在线“盲标”。
若每轮探测使 `ε_{t+1} ≤ κ ε_t + w`（`κ<1`，`w` 为漂移上界），则稳态半径 `ε_ss ≤ w/(1−κ)`，故闭环收敛要求 `ε_max > w/(1−κ)`。

## 2. 关键算法伪代码

### IP-121 HE-CAP（Hand-Eye Calibration-Aware Profiling）

```python
def calibration_conditioned_profile(skill, T_nom, tube, A, n_mc=64):
    alpha = {}
    for a in A:
        worst = 1.0
        for dxi in tube.samples(n_mc):
            T = T_nom @ se3_exp(dxi)
            worst = min(worst, skill.occupancy(a, T))
        alpha[a] = worst
    return alpha

def calibration_margin(skill, T_nom, A_T, L_alpha, theta_cov=0.8):
    base = min(skill.occupancy(a, T_nom) for a in A_T)
    return max(0.0, (base - theta_cov) / max(L_alpha, 1e-9))
```

### IP-122 CSAD（Calibration-Structured Anomaly Detection）

```python
def residual_decompose(a, e_obs, T_nom, model, Sigma_n):
    e_hat = model.predict_effect(a, T_nom)
    r = e_obs - e_hat
    J_he = model.jacobian_handeye(a, T_nom)
    J_task = model.jacobian_task(a, T_nom)
    P_he = weighted_projection(J_he, Sigma_n)
    psi = energy(P_he @ r, Sigma_n) / max(energy(r, Sigma_n), 1e-12)
    dxi_hat, Sigma_d = gls(r, J_he, Sigma_n)
    Lambda = float(dxi_hat @ inv(Sigma_d) @ dxi_hat)
    return r, psi, dxi_hat, Sigma_d, Lambda

def classify_anomaly(r, psi, Lambda, thr_psi, thr_lambda, tau_r,
                     persistence, min_persist):
    if norm(r) <= tau_r:
        return 'normal', None
    cal_like = (psi >= thr_psi and Lambda > thr_lambda)
    persistent = persistence >= min_persist
    if cal_like and persistent:
        return 'calibration_anomaly', psi
    if psi < thr_psi:
        return 'task_anomaly', psi
    return 'ambiguous', psi          # 触发主动探测消歧，禁止直接重标定
```

### IP-123 ACP（Active Calibration Probing）

```python
def select_probes(T_nom, tube, A_safe, Sigma_n, k, B_risk, lam=1.0):
    I = prior_information(tube)
    probes, spent = [], 0.0
    for _ in range(k):
        best = None
        for a in A_safe:
            if not safe_under_tube(a, T_nom, tube):
                continue                     # 最坏情况越出 A_buffer，拒绝
            J = jacobian_handeye(a, T_nom)
            gain = logdet(I + J.T @ inv(Sigma_n) @ J) - logdet(I)
            risk = worst_case_risk(a, T_nom, tube)
            if spent + risk > B_risk:
                continue
            score = gain - lam * risk
            if best is None or score > best[0]:
                best = (score, a, gain, risk)
        if best is None or best[2] <= 0:
            break                            # 无可观测增益：停止而非盲探
        _, a, _, risk = best
        probes.append(a); spent += risk
        J = jacobian_handeye(a, T_nom)
        I = I + J.T @ inv(Sigma_n) @ J
    return probes, I
```

### IP-124 CCC（Calibration-Compatible Composition）

```python
def calibration_compatible(skills, A_T, rho_min, delta_E):
    sets = [admissible_set(s, A_T, rho_min) for s in skills]
    common, feasible = intersect_ellipsoids(sets)   # se(3) 椭球交集
    if not feasible:
        return ('reject', 'frame_disagreement')
    if common.diameter() > delta_E:
        return ('reject', 'tube_too_wide', common.diameter())
    T_star = common.chebyshev_center()
    return ('ok', CalibCert(T_star, common, common.radius(), evidence=sets))
```

### IP-125 CRC（Calibration-Robust Certificate）

```python
def calibration_robust_certificate(skill_seq, T0, tube, A_T, rho_min):
    alpha_eps = {a: min(calibration_conditioned_profile(s, T0, tube, [a])
                        [a] for s in skill_seq) for a in A_T}
    if not cover_check(alpha_eps, A_T):
        return ('reject', 'coverage_lost_under_tube', alpha_eps)
    rho_eps = worst_case_robustness(skill_seq, T0, tube)
    if min(rho_eps.values()) < rho_min:
        return ('reject', 'robustness_lost_under_tube', rho_eps)
    if tube.radius > tube.eps_max:
        return ('reject', 'calibration_uncertainty_too_large')
    return ('ok', JCal(T0, tube, alpha_eps, rho_eps,
                       detector='CSAD', probe='ACP'))
```

### IP-126 ARL（Anomaly-triggered Re-profiling Loop）

```python
def anomaly_reprofile_loop(robot, cert, monitor, cloud, budget):
    T, tube = cert.T0, cert.tube
    persist = 0
    while robot.running():
        e = robot.observe_effect()
        r, psi, dxi, Sigma_d, Lambda = residual_decompose(
            robot.last_action, e, T, robot.model, robot.Sigma_n)
        verdict, _ = classify_anomaly(
            r, psi, Lambda, monitor.thr_psi, monitor.thr_lambda,
            monitor.tau_r, persist, monitor.min_persist)

        if verdict == 'normal':
            persist = max(0, persist - 1)

        elif verdict == 'calibration_anomaly':
            if not observable(robot.J_he_history):
                cert.invalidate(); return safe_stop('unobservable')
            T, tube = fuse_calibration(T, tube, dxi, Sigma_d)
            A_drift = monitor.localize_drift(robot.action_log)
            cloud.reprofile(skills_in(A_drift), T, tube)
            cloud.recompose_edges(affected_by(A_drift))
            cert = calibration_robust_certificate(
                cloud.skill_seq, T, tube, cloud.A_T, cloud.rho_min)
            if cert.status != 'ok':
                return safe_stop('certificate_lost')
            persist = 0

        elif verdict == 'task_anomaly':
            cert.freeze_calibration()                 # 关键：不重标定
            plan = cloud.replan_conservative(cert.K_safe)
            if plan is None:
                return safe_stop('task_anomaly_unrecoverable')

        else:  # ambiguous
            probes, _ = select_probes(T, tube, cert.A_safe, robot.Sigma_n,
                                      budget.k, budget.B_risk)
            if not probes:
                return safe_stop('unobservable')
            for a in probes:
                robot.execute(a)
            persist += 1
    return cert
```

## 3. 关键推导与正确性

**为什么结构化投影能区分两类异常。** 在 `H_cal` 下，`r` 的均值落在 `col(J_he)` 内（维度 ≤6）；在一般任务异常下，`r` 的均值落在 `col(J_task)` 或更大的空间。若 `col(J_he)` 与任务异常方向近似正交，则 `ψ→1` 对前者、`ψ→0` 对后者。即使有重叠，跨多个动作的 `J_he(a_t)` 不同，而 `δξ` 是**跨动作共享**的低维参数；拟合优度的提升必须由“共享的 6 维参数”解释，而不能由每个动作独立的自由度解释。因此归因判据本质是一个**带维数惩罚的嵌套模型比较**，不是单帧阈值。

**命题（标定裕度的保守性）**
若 `α_S(·|T)` 在 `B_Σ(ε)` 上 `L_α`-Lipschitz，且 `α_S(a|T_he) − θ_cov ≥ L_α·ε` 对所有 `a∈A_T` 成立，则 `α_S^ε(a) ≥ θ_cov`，即 `m_cal ≥ ε`。故用最坏情况管做覆盖检查是 sound 的，代价是保守。

**正确性定理（Calibration-Conditioned Certificate Soundness）**
假设第 54 轮 (A26)–(A28) 成立；新增：
- **(A29)** 在 `‖δξ‖ ≤ ε0` 内一阶残差模型成立，线性化误差 `≤ η`；
- **(A30)** 探测动作对上 `J_he` 充分激励，`σ_min(J_he) ≥ σ0 > 0`；
- **(A31)** 标定漂移有界 `‖δξ_{t+1} − δξ_t‖ ≤ w`，融合估计一致；
- **(A32)** CSAD 误报率 `≤ α`，归因错误率 `≤ β_attr`，检测延迟 `≤ τ_det`；
- **(A33)** `ε_max > w/(1−κ)`，闭环可收敛。

则部署证书 `J_cal` 的成功概率满足
```
P_success ≥ 1 − Σ_d (1 − ρ_min^ε(d)) − β_E − P(ε > ε_max)
            − α − β_attr − P(可观测性失效).
```
其中 `ρ_min^ε(d)` 是标定管内的最坏情况鲁棒性下界。关键：**先保证坐标系一致性，再把动作与鲁棒性证书叠加**；任何一项不成立，证书必须降级而非外推。

## 4. 实验设计 E162–E166

| 实验 | 指标 | 目标 |
|---|---|---|
| E162 标定异常归因 | 标定漂移 vs 环境异常的 AUROC；误归因率 | AUROC ≥ 0.90，误归因 ≤ 5% |
| E163 标定裕度校准 | 估计 `m_cal` vs 实测最大可容忍 `δξ` | 相对误差 ≤ 10% |

| E166 闭环漂移跟踪 | 稳态 `ε_ss`；成功率恢复时间 | `ε_ss ≤ ε_max`，`τ_loop` 内恢复 ≥ 90% |

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 手眼参数不可观测（平面运动/单轴旋转） | 高 | 可观测性检查 + 主动激励 + 明确拒绝外推 |
| 大漂移下线性化失效 | 高 | SE(3) 迭代 Gauss–Newton + 多假设 + 只在 `ε0` 内信任一阶模型 |
| 标定异常与任务异常混淆 | 高 | 跨动作共享参数检验 + 时间持续性 + 共形阈值 + 消歧探测 |

| 最坏情况管过度保守 | 中 | 后验自适应管 + 分层证书（宽松运行 / 严格部署两档） |

## 6. 本轮最大风险

**一句话**：把异常检测改写成“结构化残差归因”并让手眼标定进入证书，能把 v31 从“错误坐标系上的精致证书”拉回可证伪的地基，但整条链条依赖**残差模型正确、手眼参数持续可观测、且归因不把环境变化误判为坐标系漂移**；一旦模型失配或运动退化，系统会以很高置信度“重标定到错误的世界”，比不检测更危险，故必须以**可观测性门控 + 多假设归因 + 最坏情况管 + 任务异常冻结**四重护栏，宁可拒绝部署，也不在线盲标。

### IP-121 HE-CAP

```python
def calibration_conditioned_profile(skill, T_nom, tube, A, n_mc=64):
    alpha = {}
    for a in A:
        worst = 1.0
        for dxi in tube.samples(n_mc):
            T = T_nom @ se3_exp(dxi)
            worst = min(worst, skill.occupancy(a, T))
        alpha[a] = worst
    return alpha

def calibration_margin(skill, T_nom, A_T, L_alpha, theta_cov=0.8):
    base = min(skill.occupancy(a, T_nom) for a in A_T)
    return max(0.0, (base - theta_cov) / max(L_alpha, 1e-9))

def worst_case_profile(skill_seq, T_nom, tube, A_T):
    out = {}
    for a in A_T:
        out[a] = min(calibration_conditioned_profile(s, T_nom, tube, [a])[a]
                     for s in skill_seq)
    return out
```

### IP-122 CSAD

```python
def residual_decompose(a, e_obs, T_nom, model, Sigma_n):
    e_hat = model.predict_effect(a, T_nom)
    r = e_obs - e_hat
    J_he = model.jacobian_handeye(a, T_nom)
    J_task = model.jacobian_task(a, T_nom)
    P_he = weighted_projection(J_he, Sigma_n)       # Σ_n⁻¹ 加权投影
    psi = energy(P_he @ r, Sigma_n) / max(energy(r, Sigma_n), 1e-12)
    dxi_hat, Sigma_d = gls(r, J_he, Sigma_n)
    Lambda = float(dxi_hat @ inv(Sigma_d) @ dxi_hat)
    return r, psi, dxi_hat, Sigma_d, Lambda

def classify_anomaly(r, psi, Lambda, thr_psi, thr_lambda, tau_r,
                     persistence, min_persist):
    if norm(r) <= tau_r:
        return 'normal', None
    cal_like = (psi >= thr_psi and Lambda > thr_lambda)
    if cal_like and persistence >= min_persist:
        return 'calibration_anomaly', psi
    if psi < thr_psi:
        return 'task_anomaly', psi
    return 'ambiguous', psi        # 先消歧，禁止直接重标定
```

### IP-123 ACP

```python
def select_probes(T_nom, tube, A_safe, Sigma_n, k, B_risk, lam=1.0):
    I = prior_information(tube)
    probes, spent = [], 0.0
    for _ in range(k):
        best = None
        for a in A_safe:
            if not safe_under_tube(a, T_nom, tube):
                continue                      # 最坏情况越出 A_buffer
            J = jacobian_handeye(a, T_nom)
            gain = logdet(I + J.T @ inv(Sigma_n) @ J) - logdet(I)
            risk = worst_case_risk(a, T_nom, tube)
            if spent + risk > B_risk:
                continue
            score = gain - lam * risk
            if best is None or score > best[0]:
                best = (score, a, gain, risk)
        if best is None or best[2] <= 0:
            break                             # 无信息增益：停止而非盲探
        _, a, _, risk = best
        probes.append(a); spent += risk
        J = jacobian_handeye(a, T_nom)
        I = I + J.T @ inv(Sigma_n) @ J
    return probes, I
```

def calibration_compatible(skills, A_T, rho_min, delta_E):
    sets = [admissible_set(s, A_T, rho_min) for s in skills]
    common, feasible = intersect_ellipsoids(sets)   # se(3) 椭球交集

    if common.diameter() > delta_E:
        return ('reject', 'tube_too_wide', common.diameter())
    T_star = common.chebyshev_center()
    return ('ok', CalibCert(T_star, common, common.radius(), evidence=sets))

def build_calibration_aware_graph(skills, A_T, rho_min, delta_E, theta_a):
    G = nx.DiGraph()
    for i, s1 in enumerate(skills):
        for j, s2 in enumerate(skills):
            if i == j:
                continue
            ok, cert = calibration_compatible([s1, s2], A_T, rho_min, delta_E)
            if ok != 'ok':

            compat = jaccard(s1.alpha, s2.alpha)     # v31 的动作兼容性
            if compat < theta_a:
                continue
            G.add_edge(i, j, compat=compat, C_cal=cert.cert)
    return G

### IP-126 ARL

```python
def anomaly_reprofile_loop(robot, cert, monitor, cloud, budget):
    T, tube = cert.T0, cert.tube
    persist = 0
    while robot.running():
        e = robot.observe_effect()
        r, psi, dxi, Sigma_d, Lambda = residual_decompose(
            robot.last_action, e, T, robot.model, robot.Sigma_n)
        verdict, _ = classify_anomaly(
            r, psi, Lambda, monitor.thr_psi, monitor.thr_lambda,
            monitor.tau_r, persist, monitor.min_persist)

        if verdict == 'normal':
            persist = max(0, persist - 1)

        elif verdict == 'calibration_anomaly':
            if not observable(robot.J_he_history):
                cert.invalidate(); return safe_stop('unobservable')
            T, tube = fuse_calibration(T, tube, dxi, Sigma_d)   # 收缩 ε
            A_drift = monitor.localize_drift(robot.action_log)
            cloud.reprofile(skills_in(A_drift), T, tube)        # 局部重剖分
            cloud.recompose_edges(affected_by(A_drift))
            cert = calibration_robust_certificate(
                cloud.skill_seq, T, tube, cloud.A_T, cloud.rho_min)
            if cert.status != 'ok':
                return safe_stop('certificate_lost')
            persist = 0

        elif verdict == 'task_anomaly':
            cert.freeze_calibration()                            # 不重标定
            plan = cloud.replan_conservative(cert.K_safe)
            if plan is None:
                return safe_stop('task_anomaly_unrecoverable')

        else:  # ambiguous
            probes, _ = select_probes(T, tube, cert.A_safe, robot.Sigma_n,
                                      budget.k, budget.B_risk)
            if not probes:
                return safe_stop('unobservable')
            for a in probes:
                robot.execute(a)
            persist += 1
    return cert
```

## 3. 关键推导

**（1）残差结构。** 设真实手眼为 `T_he·exp(δξ^)`，名义预测 `ê(a;T_he)`。一阶展开：
```
r = e_obs − ê(a;T_he) ≈ J_he(a)·δξ + J_task(a)·δθ + n.
```
`J_he` 的列空间最多 6 维，且 `δξ` 在**不同动作间共享**；任务异常参数 `δθ` 与动作无关但通常维度更高，或其方向不与 `col(J_he)` 对齐。故用跨动作联合残差做嵌套模型比较，而非逐帧阈值。

**（2）归因判据。** 在 `H_cal` 下 `Λ ~ χ²_6`。为避免固定阈值在真实分布偏移下失效，取在线残差经验分布的共形分位数 `q_{1−α}`，令 `Λ > q_{1−α}` 且 `ψ ≥ θ_ψ`。归因错误率上界 `β_attr` 由消歧探测（在 `col(J_he)` 正交方向激励）进一步压低。

**（3）标定裕度。** 若 `α_S` 对 `δξ` `L_α`-Lipschitz，则
```
α_S^ε(a) ≥ α_S(a|T_he) − L_α·ε.
```
因此 `ε ≤ min_a(α_S(a|T_he)−θ_cov)/L_α` 足以保证最坏情况覆盖，且该界保守但 sound。

**（4）闭环收敛。** 每轮信息融合与探测使 `ε_{t+1} ≤ κ ε_t + w`，`κ<1` 来自 Fisher 信息增加，`w` 为未建模漂移。稳态 `ε_ss = w/(1−κ)`；要求 `ε_max > ε_ss`，否则证书必然周期性失效，应改为外部标定而非在线盲标。

## 4. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| HE-CAP | `O(|A|·N_mc·|S|)` | `O(|A|)` | 最坏情况覆盖下界 sound（Lipschitz） |
| CSAD | `O(|A|·(d_e²d_ξ + d_ξ³))` | `O(d_e d_ξ)` | 归因统计在 `H_cal` 下 `χ²_6`；共形控误报 |
| ACP | `O(k·|A_safe|·d_ξ³)` | `O(d_ξ² + |A_safe|)` | 仅对可观测方向宣称收缩 |
| CCC | `O(|S|²·T_ellip)` | `O(|S|·d_ξ²)` | 交集非空 + 直径界，否则拒绝 |
| CRC | `O(|S|·|A_T|·N_mc + |𝔇_ρ|)` | `O(|A_T|+|𝔇_ρ|)` | 管内最坏情况证书 sound |
| ARL | 每周期 `O(cost(CSAD)+cost(CRC))` | `O(|A|+d_ξ²)` | 归因互斥 + 冻结机制防震荡 |

**正确性定理（Calibration-Conditioned Certificate Soundness）**
假设第 54 轮 (A26)–(A28) 成立；新增 (A29) 一阶残差模型在 `‖δξ‖≤ε0` 成立，(A30) 探测充分激励 `σ_min(J_he)≥σ0`，(A31) 漂移有界 `‖δξ_{t+1}−δξ_t‖≤w` 且融合一致，(A32) CSAD 误报 `≤α`、误归因 `≤β_attr`、延迟 `≤τ_det`，(A33) `ε_max > w/(1−κ)`。则
```
P_success ≥ 1 − Σ_d(1 − ρ_min^ε(d)) − β_E − P(ε > ε_max)
            − α − β_attr − P(可观测性失效).
```
其中 `ρ_min^ε(d)` 为标定管内最坏情况鲁棒性。关键：**`J_cal` 是 `J` 的前置条件**；坐标系不确定度超预算时，任何动作-鲁棒性结论都不得外推。

## 7. 与 v31 的边界：本轮明确不做什么

- **不做通用异常检测 benchmark 的 SOTA**：CSAD 只在动作-效应残差空间工作，面向证书证伪，不宣称覆盖所有 OOD。
- **不假设手眼参数恒定**：只承诺在 `w` 界定的漂移速率与 `ε_max` 预算内有效。
- **不以单点标定作为真值**：所有部署结论都必须带管半径 `ε`。
- **不在不可观测时强行在线标定**：不可观测即拒绝，转外部 `AX=XB` 或安全停机。
