# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「抓取」×「模块化设计」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**触觉接地 + 装配代数**。v9 把安全寄托在视觉前向模型的块证书上，而它自己承认的最大风险正是「域偏移时证书最不可靠」。抓取灵感提供一条物理旁路：接触力与滑移是视觉域偏移最不敏感的量；模块化灵感提供一条结构旁路：把整机证书拆成可组合的模块证书，用接口义务而非全局枚举保证装配安全。两条旁路合成核心命题——**抓取安全不应由「预测」承担，而应由「接触物理 + 装配代数」承担**。

## 0. 直觉与动机

**灵感 1（抓取 → 抓取不是布尔标签，而是一张力封闭证书）**
v9 的 `γ̂_grasp` 只是前向模型输出的一个学习布尔，这是整条安全链上最软的一环：它既没有力封闭的物理含义，也无法在域偏移下给出可证伪的边界。抓取的经典语言恰好补上：接触点、摩擦锥、力封闭裕度、滑移裕度、载荷/动态 wrench。核心创新：**抓取证书器（GraspCertifier, GC）** 把 `γ_grasp` 从「预测值」升级为「证书」——`G_t=(Q_fc, σ_slip, ρ_pay, h_contact, sat)`，只有力封闭裕度与滑移裕度同时过阈，抓取才被 M₀ 硬层允许。由此 `γ_grasp=valid` 变成可证明的几何-力学命题，而不是模型置信度。

**灵感 2（模块化设计 → 证书的装配代数）**
v9 的契约中间件解决了「模块怎么接线」，却没解决「模块怎么共同取证」。模块化的真正价值不在拆分，而在**组合**：一旦每个抓取阶段、每根手指、每个夹爪都是带类型化端口的模块，并各自携带局部证书，整机证书就能由「局部证书 + 接口义务」折叠得到，而不必对整机做指数级枚举。核心创新：**模块化抓取套件与装配验证器（GraspModuleKit + AssemblyVerifier, MAA）**：串行装配用 assume-guarantee（前级出口必须落在后级入口域）；并联装配用力封闭单调性（`Q_fc(A⊕_pB) ≥ max(Q_fc(A), Q_fc(B))`，加接触点不会降低力封闭裕度——前提是无接触冲突）。附带得到**模块可替换定理**：若 `m ≼ m'`（同接口且证书域包含），则换模块保安全。这让「换夹爪/换抓取策略」从冒险变成受证书约束的代数操作。

**灵感 3（两条灵感的交叉 → 阶段化触觉信任域）**
把上面两条接起来，恰好正面命中 v9 的最大风险，但必须诚实划界。v9 的信任域 `U_t` 只有视觉 DA-ML 与 SLAM 风险；域偏移时 `Δ_dom` 滞后，块证书可能在已失效的块上仍被判有效。抓取提供触觉这一**接触期内的域不变锚**：在 contact/lift/transport 阶段，用实测接触力落在预测带内 + 滑移裕度为正来**佐证**（corroborate）块证书中**抓取相关的分量**。关键限制：触觉不能佐证避障/间隙分量，自由空间逼近阶段也没有触觉，此时只能 `K_eff=1`。所以核心创新是**阶段化且分量化的信任域（PhaseConditionedTrust, TTA）**，而不是「触觉包治百病」。

## 1. 研究问题（轮次升级版）

- **Q1（抓取证书的可靠边界）**：力封闭裕度 `Q_fc` 与滑移裕度 `σ_slip` 在点接触 + 线性化摩擦锥模型下，能以多大概率覆盖真实抓取失败？软指、扭转摩擦、接触点估计误差如何折进证书余量，而不使证书退化为「永不通过」？
- **Q2（装配代数的健全性）**：串行 assume-guarantee 与并联力封闭单调性在什么接口条件下健全？局部证书的合取在什么意义上等价于全局稳定？接触冲突/内力对抗这一模块化盲区，能否被静态谓词 `η` 提前排除？
- **Q3（触觉锚的适用域）**：触觉佐证能在多大幅度、多快变化率的视觉域偏移下维持证书接受？其误接受率（false accept）能否标定到 `≤α`，且自由空间阶段严格退回 `K_eff=1`？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 抓取力封闭证书律（Grasp Force-Closure Certificate, GFC）**
抓取被允许 ⇔ 抓取证书 `G_t` 有效：`Q_fc ≥ Q_min ∧ σ_slip ≥ σ_min ∧ ρ_pay ≥ δ ∧ f_{n,i} ≤ f_max ∧ h_contact ≥ h_min`。`γ_grasp` 不再来自学习预测，而由 `G_t` 判定；证书失效 ⇒ 拒绝抓取/重规划/请求人类，绝不「带着不确定的抓取继续」。滑移观测在 50Hz 每拍更新，检测到 `σ_slip < 0` 或滑移速度超阈 ⇒ 立即进入受控释放（定义 550）。

**P14 模块化装配代数律（Modular Assembly Algebra, MAA）**
每个抓取模块 `m` 声明类型化端口 `(I^in_m, I^out_m)`、能力规格 `C_m`、局部证书生成器 `G_m`、中立元 `v_m^⊥`、组合相容谓词 `η_m`。装配 `A` 的证书由折叠得到：串行 `⊕_s` 施加接口义务 `I^out_A ⊆ I^in_B` 与 assume-guarantee；并联 `⊕_p` 施加接触冲突谓词 `η` 与力封闭单调合并。模块可替换 `m ≼ m'` ⇔ 同接口且 `Cert(m) ⊆ Cert(m')`，替换只保安全性质、不保任务成功率与性能。装配验证在部署期完成，运行期只查证书是否仍有效。

**P15 阶段化触觉锚定信任律（Tactile Trust Anchor, TTA）**
信任域按阶段与分量条件化：`U_t = (U_t^vis, U_t^tac)`。`U_t^vis` 为 v9 的 `{Δ_dom<τ_dom ∧ risk_SLAM<τ_SLAM}`；`U_t^tac` 仅定义在接触期（contact/close/lift/transport/place），要求实测接触力落在预测带 `±β_f` 内且 `σ_slip ≥ σ_min` 持续 `h_corr` 拍。块证书逐分量取证：间隙/努力分量只接受 `U_t^vis`；抓取分量接受 `U_t^vis ∨ U_t^tac`。自由空间阶段 `U_t^tac ≡ false`，故 `K_eff=1`。触觉只能**佐证**已有证书，不能凭空生成证书。

## 3. 与基线的接口（如何退化）

- GC 失效/无触觉 ⇒ `γ_grasp ≡ invalid`，拒绝抓取并转推/放置/请人，等价 v9 的「不抓」安全行为；
- MAA 装配验证器失效 ⇒ 退回 v9 单体块证书 `Ĉ_t`（不装配取证），等价 v9 证书路径；
- TTA 失效或不在接触期 ⇒ `U_t ≡ U_t^vis`，等价 v9 信任域；
- 装配证书与单体证书冲突 ⇒ 取二者之交（更保守），并记审计事件；
- 全部失效 ⇒ 完整退回 v9 → v8 → v7 → v6。

## 4. 预期贡献

1. **抓取证书**：用可证伪的力封闭/滑移裕度替代学习布尔 `γ̂_grasp`，把抓取安全从「预测可信」移到「力学可证」；
2. **装配代数**：串行 assume-guarantee + 并联力封闭单调性 + 可替换定理，使整机验证从指数枚举降为线性接口检查；
3. **阶段化、分量化的触觉信任域**：在不牺牲自由空间保守性的前提下，用接触期域不变量修补 v9 的「域偏移下证书最不可靠」风险；
4. **诚实边界**：明确「触觉只佐证抓取分量」「并联单调性以无接触冲突为前提」，把模块化盲区写成可测试谓词与实验（E580、E589）。

## 5. 本轮最大风险

**一句话**：模块化证书代数把安全论证局部化，但抓取是多接触强耦合——并联装配的力封闭单调性假设各模块接触点互不冲突且内力可协调；一旦接触几何冲突或内力对抗，局部证书可以全部为真而全局仍滑落，而触觉锚只能事后观测滑移、无法在装配前证明稳定性。

# 第 10 轮产物 · 创新点清单 v10：**MetricVoiceGauge-GAMA**（Grasp-certified Assembly with Modular Anchoring）

**新增定义 540（抓取模块 GraspModule）** `m = (I^in_m, I^out_m, C_m, G_m, v_m^⊥, η_m, π_m)`。`I^in/out_m` 为类型化状态谓词（如 `ObjectInHand ∧ contact_set ∈ 𝒞`）；`C_m` 为能力规格（最大载荷、μ 区间、`f_max`）；`G_m: State → GraspCertificate ∪ {⊥}` 是局部证书生成器；`v_m^⊥` 为失效时的安全中立行为（保持/受控释放/不动作）；`η_m` 为与其他模块并联时的接触相容谓词；`π_m ⊆ S` 为作用阶段。模块「安全」意为 `dom(G_m)` 覆盖其入口区域。

**新增定义 541（抓取阶段语法 GraspStageGrammar）** 阶段集合 `S` 上的类型化有向图；边 `s → s'` 标注接口谓词 `I_{s→s'}`。一个抓取计划 `ρ = s_0 s_1 … s_k` 是语法中的词。接口即相邻阶段的边界状态谓词；串行装配的合法性归结为 `I^out_{s_j} ⊆ I^in_{s_{j+1}}`。

**新增定义 542（力封闭裕度 ForceClosureMargin）** 对接触集 `C`，摩擦锥 `FC_i = {f_i : ‖f_t‖ ≤ μ_i f_n, f_n ∈ [0, f_max]}` 用 `m=8` 条边线性化，生成原始 wrench `W(C) = {G_i u_{i,j}/‖G_i u_{i,j}‖}`。定义
```
Q_fc(C) = sup{ r : B_r(0) ⊆ conv W(C) } = min_h b_h / ‖a_h‖,
```
其中 `a_h·x = b_h` 是 `conv W(C)` 的支撑面方程且 `b_h>0`。力封闭 ⇔ `Q_fc > 0`（原点在凸包内部）。计算用 6 维凸包 + 面距最小值，接触数 `|C|≤6`、`m=8` ⇒ 至多 48 个点。

**新增定义 543（滑移裕度与滑移观测 SlipMargin & SlipObserver）** 接触 `i` 的库仑滑移裕度 `σ_slip,i = μ_i f_{n,i} − ‖f_{t,i}‖`，整体取最小。触觉滑移速度 `v_slip` 由触觉阵列光流/微振动估计；早期滑移（ESL）谓词为 `d‖f_t‖/dt > κ ∧ σ_slip < σ_warn`。硬违规 ⇔ `σ_slip < 0` 或 `v_slip > v_max` 连续 `h_slip` 拍。

**新增定义 544（抓取证书 GraspCertificate）** `G_t = (Q_fc, σ_slip, ρ_pay, h_contact, sat)`，其中 `ρ_pay = 1 − ‖w_req‖/Q_fc`，`w_req = w_gravity + w_inertial`，`sat = min_i(f_max − f_{n,i})`，`h_contact` 为连续保持接触的拍数。证书有效 ⇔
```
Q_fc ≥ Q_min ∧ σ_slip ≥ σ_min ∧ ρ_pay ≥ δ
∧ sat ≥ 0 ∧ h_contact ≥ h_min ∧ 接触身份一致（无滑脱换点）
∧ 当前阶段 ∈ π_m。
```
`Cert(m) = {(s,a) : G_t(s,a) 有效}`。`Q_min, σ_min, δ` 由 E572–E573 标定。

**新增定义 545（接口同构与安全可替换 Substitutability）** `m ≼ m'` ⇔（i）`I^in_m = I^in_{m'}`、`I^out_m = I^out_{m'}`、`π_m = π_{m'}`；（ii）`Cert(m) ⊆ Cert(m')`；（iii）中立元相容：`v_{m'}^⊥` 在 `v_m^⊥` 安全的区域上同样安全。`≼` 只保安全性质，不保任务成功率、时延或能耗（见引理 90 的边界）。

**新增定义 546（装配代数 AssemblyAlgebra）**
- 串行 `A ⊕_s B`：要求接口义务 `I^out_A ⊆ I^in_B`；证书
  ```
  Cert(A ⊕_s B) = Cert(A) ∩ {exit_A ∈ I^in_B} ∩ Cert(B),
  ```
  即 assume-guarantee：`A` 在其执行域内保 `Inv_A`，出口满足 `B` 的入口假设，`B` 在入口假设下保 `Inv_B`。
- 并联 `A ⊕_p B`：要求 `η(A,B)` 成立（接触点互异、法向不构成互抵死锁、内力可协调、同一物体参考系）；接触集取并 `C = C_A ∪ C_B`；证书约束
  ```
  Q_fc(A ⊕_p B) ≥ max(Q_fc(A), Q_fc(B)),
  σ_slip(A ⊕_p B) ≥ min(σ_slip(A), σ_slip(B))（保守界，实际可更优），
  ```
  并**重新检查** `sat`（内力可能抬升法向力）。

**新增定义 547（装配即证书 Assembly-as-Certificate）** 装配表达式 `A` 的证书由装配树自底向上折叠：叶节点取模块局部证书，内部节点按 546 的规则合成，若任一接口义务或 `η` 失败则输出 `UNSAT` 并附**失效见证**（违规接口或冲突模块对）。部署期完成折叠，运行期只做证书有效性复查。

**新增定义 548（阶段化分量化信任域 PhaseConditionedTrust）** 令 `U_t^vis = {Δ_dom < τ_dom ∧ risk_SLAM < τ_SLAM}`；`U_t^tac` 仅定义于 `π ∈ {contact, close, lift, transport, place}`：
```
U_t^tac(π) = [π ∈ 接触阶段] ∧ Corroborate(f_meas, f_pred, σ_slip, h_corr).
```
块证书逐分量取证：间隙/努力分量 `trust_clr = U_t^vis`；抓取分量 `trust_grasp = U_t^vis ∨ U_t^tac`。块被接受 ⇔ 所有分量在各自信任源下有效；否则 `K_eff ← 1`（定义 539 升级）。

**新增定义 549（触觉佐证 TactileCorroboration）** 谓词
```
Corroborate ⇔ ∀i: |f_{meas,i} − f_{pred,i}| ≤ β_f,i
              ∧ σ_slip ≥ σ_min ∧ h ≥ h_corr,
```
`β_f` 由接触期内的分裂共形分位数在 `1−α` 水平标定（E578）。注意其统计保证以「给定状态-动作下触力残差分布不随视觉域偏移改变」为前提；该前提失效时由残差检验触发 `U_t^tac ← false` 并回退 `K_eff=1`。

**新增定义 550（抓取拒止语义 GraspRefusalSemantics）** 证书失效时允许的动作集 `R(s)`：受控释放（速度指数衰减到 0）、保持当前接触并请求人类、退回 `place` 阶段。禁止「继续执行未取证抓取」。拒止本身必须满足 `M₀` 硬层：释放不导致自由落体、保持不进入力饱和。

## 2. 形式化定义（要点与升级）

**定义 493（六层指标层级）** 继承 v9，不变。
**定义 532（动作块）/533（块证书）** 继承；但定义 533 中 `γ̂_grasp` 被替换为 `G_t` 有效（定义 544）。块证书升级为 `Ĉ_t = (ĝ_min, ê_max, G_t)`。

```
K_eff(t) = 1                                       若 trust_clr 不成立
```

```python
# IP-357 GraspCertifier：抓取证书器
class GraspCertifier:
    def __init__(self, m_edges=8, Q_min=0.08, sigma_min=0.30,
                 delta=0.15, f_max=40.0, h_min=3, dt=0.02):
        self.m_edges, self.Q_min, self.sigma_min = m_edges, Q_min, sigma_min
        self.delta, self.f_max, self.h_min, self.dt = delta, f_max, h_min, dt

    def _cone_generators(self, mu):
        # 线性化摩擦锥：法向 + m 条切向边
        return [(1.0, 0.0, 0.0)] + [
            (1.0, mu * math.cos(2*math.pi*j/self.m_edges),
                  mu * math.sin(2*math.pi*j/self.m_edges))
            for j in range(self.m_edges)]

    def primitive_wrenches(self, contacts):
        W = []
        for c in contacts:                                  # c: (p, n, mu, G)
            for u in self._cone_generators(c.mu):
                w = c.G @ np.array(u)
                nw = np.linalg.norm(w)
                if nw > 1e-9:
                    W.append(w / nw)
        return np.asarray(W)

    def force_closure_margin(self, contacts):
        W = self.primitive_wrenches(contacts)
        hull = ConvexHull6D(W)                              # 6 维凸包
        return min_facet_distance_to_origin(hull)           # 定义 542

    def certify(self, state, contacts, tactile, phase):
        Q = self.force_closure_margin(contacts)
        sigma = min(c.mu * tactile.fn[c.id] - np.linalg.norm(tactile.ft[c.id])
                    for c in contacts)
        w_req = state.gravity_wrench + state.inertial_wrench
        rho = 1.0 - np.linalg.norm(w_req) / max(Q, 1e-9)
        sat = min(self.f_max - tactile.fn[c.id] for c in contacts)
        cert = GraspCertificate(Q, sigma, rho, state.contact_persistence,
                                sat, phase)
        return cert

    def gate(self, cert, phase):
        if phase not in GRASP_PHASES:
            return ('not_applicable', None)
        if (cert.Q_fc >= self.Q_min and cert.sigma_slip >= self.sigma_min
                and cert.rho_pay >= self.delta and cert.sat >= 0
                and cert.h_contact >= self.h_min):
            return ('valid', cert)
        return ('refuse', GraspRefusalSemantics.plan(cert))  # 定义 550

    def slip_guard(self, cert, tactile, h_slip=2):
        hard = (cert.sigma_slip < 0.0 or tactile.v_slip > V_MAX)
        if hard and tactile.h_slip_violation >= h_slip:
            return ('controlled_release', None)             # 单拍界，引理 93
        return ('hold', cert)


# IP-358 GraspModuleKit + AssemblyVerifier：模块化装配代数
class GraspModule:
    def __init__(self, name, In, Out, cap, cert_fn, neutral, eta, phase_scope):
        self.name, self.In, self.Out, self.cap = name, In, Out, cap
        self.cert_fn, self.neutral, self.eta, self.phase = \
            cert_fn, neutral, eta, phase_scope
    def cert(self, s, a):
        return self.cert_fn(s, a)

class Assembly:
    def __init__(self, left, right, kind):
        self.left, self.right, self.kind = left, right, kind   # 's' | 'p'

class AssemblyVerifier:
    def __init__(self, eta_parallel):
        self.eta = eta_parallel

    def series(self, A, B):
        if not subset(A.Out, B.In):                       # I^out_A ⊆ I^in_B
            return UNSAT(witness=('interface', A.name, B.name))
        return Assembly(A, B, 's')

    def parallel(self, A, B):
        if not self.eta(A, B):                            # 接触冲突/内力死锁
            return UNSAT(witness=('contact_conflict', A.name, B.name))
        return Assembly(A, B, 'p')

    def verify(self, node, s, a):
        if isinstance(node, GraspModule):
            return node.cert(s, a)
        L = self.verify(node.left, s, a)
        if L is UNSAT: return L
        if node.kind == 's':
            # assume-guarantee：前级出口进入后级入口
            s_mid = node.left.post(s, a)
            if not node.right.In(s_mid):                  # 接口义务失败
                return UNSAT(witness=('entry_domain', node.left.name,
                                       node.right.name))
            R = self.verify(node.right, s_mid, a)
            return L.meet(R)                              # 证书域之交
        # 并联：力封闭单调 + 滑移 min + 重查饱和
        R = self.verify(node.right, s, a)
        if R is UNSAT: return R
        return L.parallel_combine(R)                      # 定义 546


# IP-359 TactileTrustAnchor：阶段化分量化信任域
class TactileTrustAnchor:
    def __init__(self, beta_f, sigma_min, h_corr=5, alpha=0.01):
        self.beta_f, self.sigma_min = beta_f, sigma_min
        self.h_corr, self.alpha = h_corr, alpha
        self.contact_phases = {'contact', 'close', 'lift', 'transport', 'place'}

    def corroborate(self, phase, f_pred, f_meas, sigma_slip, h):
        if phase not in self.contact_phases:
            return False                                  # 自由空间不扩权
        if any(abs(fm - fp) > b
               for fm, fp, b in zip(f_meas, f_pred, self.beta_f)):
            return False
        return sigma_slip >= self.sigma_min and h >= self.h_corr

    def trust(self, delta_dom, tau_dom, risk_slam, tau_slam,
              phase, f_pred, f_meas, sigma_slip, h):
        vis = (delta_dom < tau_dom) and (risk_slam < tau_slam)
        tac = self.corroborate(phase, f_pred, f_meas, sigma_slip, h)
        if vis:
            return {'clr': True, 'grasp': True, 'source': 'vis'}
        if tac:
            return {'clr': False, 'grasp': True, 'source': 'tac'}  # 仅抓取分量
        return {'clr': False, 'grasp': False, 'source': 'none'}
```

## 4. 推导

**引理 87（抓取证书的力封闭健全性）** 设 `Q_fc(C) ≥ Q_min`、`‖w_req‖ ≤ (1−δ)Q_fc`、`sat ≥ 0`，则存在接触力 `f_i ∈ FC_i` 使 `Σ_i G_i f_i = −w_req`，即静态平衡可达。
证明：由 `B_{Q_fc}(0) ⊆ conv W(C)`，有 `−w_req ∈ B_{\|w_req\|}(0) ⊆ conv W(C)`，故 `−w_req = Σ_k λ_k w_k`，`λ_k ≥ 0`，`Σ_k λ_k = ‖w_req‖ ≤ (1−δ)Q_fc`。每个 `w_k = G_i u_k/‖G_i u_k‖` 对应一个摩擦锥生成方向。令 `f_i = Σ_{k∈i} λ_k u_k/‖G_i u_k‖`；摩擦锥是凸锥，故 `f_i ∈ FC_i` 且 `Σ_i G_i f_i = −w_req`。法向饱和由 `sat≥0` 保证；若 `Σλ_k` 使某 `f_{n,i}>f_max`，则 `sat<0` 已被前提排除。∎
**边界**：该证明使用线性化摩擦锥与点接触模型；软指扭转摩擦、接触点估计误差会侵入 `Q_fc` 与 `sat`，须由 `β` 型余量吸收（E572/E573）。

**引理 88（并联装配的力封闭单调性）** 若 `η(A,B)` 成立且两模块作用于同一物体参考系，则 `Q_fc(A ⊕_p B) ≥ max(Q_fc(A), Q_fc(B))`；即增加相容抓取模块不会缩小已证明的外部 wrench 球。
证明：并联接触集为并，`W(A⊕_pB) = W_A ∪ W_B`，故 `conv W_A ⊆ conv(W_A∪W_B)`，原点内切球半径单调不减。∎
**边界（关键）**：`η` 必须排除接触点重合、法向互抵导致的内力死锁、以及内力抬升法向力超过 `f_max` 的情形。前两者是几何/相容条件，第三者由 546 的 `sat` 重查捕获。**局部证书全真并不自动推出全局稳定**，`η` 是唯一的静态闸门（见引理 92、E580）。

**引理 89（串行装配的 assume-guarantee 健全性）** 若 `I^out_A ⊆ I^in_B`，`Cert(A)` 在其执行域内保持安全不变式 `Inv_A`，且 `Cert(B)` 在入口满足 `I^in_B` 时保持 `Inv_B`，则 `A ⊕_s B` 保持 `Inv_A ∧ Inv_B`。
证明：对阶段序归纳。`A` 结束时出口状态落于 `I^in_B`（接口义务），故 `B` 的入口假设成立，`B` 的证书前提被满足；`Inv_A` 在交接后仍由 `B` 的入口域包含而保持。标准 rely-guarantee 推理。∎
**边界**：只保证安全不变式，不保证活性/任务完成；若 `B` 在入口域内无可行动作，则出现「安全但卡死」，需由 E576 的任务成功率单独度量。

**引理 90（安全可替换性）** 若 `m ≼ m'` 且系统 `S[m]` 满足安全性质 `φ`，则 `S[m']` 满足 `φ`，前提是串行/并联算子对证书域单调。
证明：`Cert(m) ⊆ Cert(m')`；串行算子对子集单调（交集），并联的 `max`/`min` 对参数单调；故折叠后的装配证书域不减，`S[m']` 的可接受执行集包含 `S[m]` 的，`φ` 在更大集合上仍成立。∎
**边界**：不保任务成功率/时延/能耗——更严格的模块可能让某些计划不可行（活性回退），这正是 E574 要测的副作用。

**引理 91（触觉佐证的域偏移降解界）** 设视觉域偏移只改变视觉特征分布；若（A1）接触期给定状态-动作下触力残差分布对视觉偏移不变，且（A2）`β_f` 以分裂共形在 `1−α` 水平标定，则 `P(false accept) ≤ α`；若 A1 失效，残差分布偏移使该界失效，必须由残差检验将 `U_t^tac` 置假并回退 `K_eff=1`。
证明：A1 下共形交换性成立，覆盖保证直接给出误接受率上界；A1 不成立时，用 `TV(P_shift, P_cal)` 修正上界为 `α + TV`，而工程上无法保证 `TV` 小，故采取「检测即降级」的保守策略。∎
**边界**：触觉只佐证抓取分量，不能佐证避障间隙；自由空间阶段 `U_t^tac≡false`。

**引理 92（装配验证的复杂度与模块化盲区）** 对 `n` 个模块、`e` 条接口，装配折叠的验证代价为 `O((n+e)·c_hull)`，`c_hull` 为 `|C|·m` 个 6 维点的凸包代价；证书规模对串行为 `O(n+|C|)`，对并联为 `O(|C|·m)`。相比对模块子集全枚举的 `O(2^n)`，是指数到线性的改进。但折叠只证明「局部证书 + 接口义务」，**不证明**跨模块的动力学耦合；`η` 是唯一的补丁，且完备性不可判定。
证明：对装配树结构归纳；每个内部节点做常数次接口包含检查与一次证书合成，凸包代价由接触点规模决定。盲区来自：`η` 是对真实接触力学的有限谓词近似，无法枚举所有内力分配。∎

**引理 93（滑移中止的单拍界）** 触觉每 50Hz 更新、滑移裕度估计延迟 ≤1 拍；若第 `t` 拍检测到 `σ_slip<0` 且连续 `h_slip` 拍成立，则受控释放最迟在第 `t+h_slip` 拍启动，物体在释放前的位移 `≤ v_max·h_slip·Δt`。取 `h_slip=2, Δt=20ms`，位移 `≤ v_max·40ms`，对 `v_max≤0.5m/s` 为 `≤2cm`，落在 `d_safe` 余量内。
证明：由采样与延迟假设直接得到时间界，再由速度积分得位移界；`h_slip` 与 `v_max` 由 E586 标定使位移不超 `d_safe`。∎

## 8. 本轮最大风险

**一句话**：模块化证书代数把安全论证局部化，但抓取是多接触强耦合——并联装配的力封闭单调性假设各模块接触点互不冲突且内力可协调；一旦接触几何冲突或内力对抗，局部证书可以全部为真而全局仍滑落，而触觉锚只能事后观测滑移、无法在装配前证明稳定性。
