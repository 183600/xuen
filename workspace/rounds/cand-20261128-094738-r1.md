### 第 6 轮灵感驱动研究记录

**灵感词**：手势识别、创新点提炼

**继承关系**：第 5 轮 CADVS-v5（IP-493~496）把提议器从离散规则升级为条件流匹配、记忆升级为固化闭环、人因锚升级为情感调制，并以定理 6（证书不变性/提议无关性）把框架推广为「任意生成器 + 认证边界」（CGE），执行集嵌套 Exec_v5 ⊆ Exec_v4 ⊆ … ⊆ Exec_v29。但 v5 留下两笔未偿债：(a) 人因通道只有面部情感且单向收紧；手势仅作 HICK 的粗糙意图 veto，既未利用其**指代消解**能力，也把「停止」这类**道义手势**与「指向那个杯子」这类**认识手势**混为一谈；(b) 五轮累积 ~30 个 IP，**创新点**与**维护债**（R52）全靠人工叙事，缺少形式化手段回答「到底哪个机制在真正承重」。本轮把两个灵感词合成主题「可归因认证交互」（Attributable Certified Interaction, ACI）：手势提供更丰富的人因通道，创新点提炼提供一套可证伪的**归因演算**，二者由「提议侧 vs 门侧」的严格分界统一，形成 CADVS-v6（IP-497~500）。自律不变：**硬门仍为七门**；执行集嵌套升级为 Exec_v6 ⊆ Exec_v5 ⊆ … ⊆ Exec_v29。

**直觉与动机**：

1. **手势识别 → 按「言语行为类型」二分：道义手势走门（只收紧），认识手势走提议（只接地）**。直觉上，「停！」与「指那个红色的」是两种东西：前者是**禁令**，必须进入信任边界、fail-closed、高召回、低延迟；后者是**指代/示形**，只帮助流策略锁定目标与轨迹先验，绝无否决权。v5 把它们塞进同一个 gesture intent veto，是范畴错误。v6 拆成两核：DGSR 把道义手势做成 HICK veto 的**单调精化**（kc_hic_v6 = kc_hic_v5 ∧ ¬D_t，保留 v5 全部否决作地板，只增不减禁令集），DGGK 把认识手势做成**提议条件**（指代分布 ρ_ref 融合语言先验；示形轨迹作流采样 guidance）。由**定理 9（手势通道分离）**：道义→门只紧、认识→提议（由定理 6 与执行边界无关），故 Exec_v6 ⊆ Exec_v5 且不加门。副产品：指代消解直接攻击「语言歧义」这一长期瓶颈，其收益可由归因演算量化。

2. **创新点提炼 → 把「创新点」定义为机制对能力的 Shapley 边际贡献，可精确计算、可证伪**。直觉上，五轮下来「我加了什么」与「什么真的有用」是两件事。v6 引入 PAL（归因账本）：(a) **局部归因**——每张证书附绑定门集 B(x)={i: m_i≤δ_bind} 与 soft-binding 权重，回答「这次决策是哪几个门在承重」；(b) **全局归因**——对机制集 M 消融，以能力泛函 F（成功率/安全违例/时延复合）为值函数**精确计算 Shapley**（|M|≤10 ⇒ ≤1024 个联盟，离线可算），并计算成对**交互指数**捕捉「只有组合才有用」的协同（如 DGGK×FMPP）；(c) **最小承重核** M*(ε)={m: φ_m≥ε}。这把「创新点」从叙事变成可复现实验量：φ_m≈0 的机制是**创新通缩**的诚实发现，而非失败。它正面偿还 R52——**归因 ≠ 删门**：门是信任边界，删门会扩大执行集；我们只按绑定频率 f_i 把长期松弛的门**降级为自动监控**（减少人工维护），绝不删除，且提议支撑一变即令松弛证书失效重验。

3. **统一 → 归因层同时是 v5 最大风险 R57（固化自指博弈）的检测器**。直觉上，一个学会「贴着门过」的策略，行为特征是**边际谱在阈值附近堆积**、且**对阈值扰动高度敏感**；真正安全的策略边际有厚度、对 τ 不敏感。v6 用边际谱 μ_i 与**影子阈值敏感度** S_i=|∂accept/∂τ_i|（离线 shadow replay，不改线上门）作 Goodhart 式代理博弈的**早期预警**。诚实边界：它检测「边界贴合型」博弈（必要信号），但**语义型博弈**（代理本身错、边际很高）检测不到，仍需红队与外部真值——这与 v5 对 R57 的诚实边界一致，只是把「只能检测不能根除」具体化为可测统计量。

**关键洞见**：v5 回答「提议任意化后证书边界是否不变」；v6 回答「人因通道更丰富、系统更庞大后，**哪些机制真正承重、哪些交互只是叙事**，以及如何让归因本身不制造新的安全幻觉」。核心是一分法 + 一演算：**手势的提议/门二分**（定理 9）保证新通道不破坏 fail-closed；**归因演算**（定理 10–12）把创新点、维护债、博弈检测统一为对证书与边际的可计算统计。七硬门 kc_evidence_forged_v5 原样复用；新增只有 DGGK（提议条件）、DGSR（HICK 内单调精化）、PAL（旁路账本，不参与决策路径）、EFA-v6（装配）。Exec_v6 ⊆ Exec_v5 由「同门 + HICK 单调精化 + 认识手势仅改提议」保证。

**形式化目标（增量）**：
1. 手势流 H_{0:T}（双手 21 关键点，30 Hz）；分段器输出 g，类型 τ(g)∈{D,E,N}，置信 q(g)。
2. DGSR：道义检测 D_t，kc_hic_v6 = kc_hic_v5 ∧ ¬D_t；STOP 预占路径延迟 ≤ L_stop（目标 30 ms），释放需显式 continue 手势或超时再使能。
3. DGGK：指向射线 r_t；接地分 κ(r_t,V_o)；ρ ∝ ρ_lang·ρ_ref^α，低于 θ_ref 弃权（fail-soft，回退纯语言）；示形路径 g^{ico} 作流 guidance（权重 w_ico）。
4. PAL：证书出处 P(x)=(B(x),{m_i},src,mem_tokens,gest_tokens,ver)；soft-binding 权重 w_i=exp(−m_i/λ)/Σ_j exp(−m_j/λ)；机制 Shapley φ_m 与交互 I_{ij}（精确，|M|≤10）；绑定频率 f_i；边际谱 μ_i；影子阈值敏感度 S_i。
5. 最小承重核 M*(ε)={m:φ_m≥ε}；门降级规则：f_i<θ_slack 且松弛证书有效 ⇒ 降为自动监控（不删）。
6. EFA-v6 = EFA-v5 + 手势条件注入 + PAL 旁路记账；决策路径不读 PAL（保护定理 6 的提议无关性）。
7. Exec_v6 = {x ∈ supp(π^FM(·|c⊕gesture)) : kc_hic_v6 ∧ (∧_{i≠hic} kc_i^v5)=1} ⊆ Exec_v5。

**本轮最大风险**：**归因幻觉**——Shapley、绑定集与松弛证书都只在**采样到的提议支撑**上成立，而手势误接地会产生「语义错误但过门」的执行（门看不见语义）；归因层会把这类执行报告为「高边际、各门松弛、健康」，使审计层沦为**虚假保证发生器**，并诱导系统对分布外/语义上真正关键的门与机制**过度降级维护**。

## 2. 关键算法骨架

### IP-497 DGGK：指代接地核（认识手势，仅提议侧，无门权）

```python
@dataclass
class DeicticGestureGroundingKernel:
    """DGGK：认识手势（指代/示形）→ 仅注入提议条件。
    低置信弃权 ⇒ fail-soft 回退纯语言（认识手势永无否决权）"""
    seg: Any                      # 手势分段 + 言语行为类型分类器
    alpha: float = 1.0            # 语言/手势乘积专家融合指数
    theta_ref: float = 0.35       # 接地弃权阈值
    w_ico: float = 1.5            # 示形 guidance 权重

    def ground(self, H, scene, lang_prior) -> Grounding:
        g = self.seg(H)
        if g is None or g.type == 'N':
            return Grounding.abstain(lang_prior)          # 无手势：纯语言
        if g.type == 'E_deictic':
            r = pointing_ray(H, g)                         # 腕→食指延长
            rho_ref = {o: kappa(r, V_o) for o, V_o in scene.objects}
            rho = normalize({o: lang_prior[o] * rho_ref[o] ** self.alpha
                             for o in rho_ref})
            if max(rho.values()) < self.theta_ref:
                return Grounding.abstain(lang_prior)       # 弃权，回退语言
            return Grounding(objects=rho, tokens=encode_ground(rho))
        if g.type == 'E_iconic':
            path = extract_path(H, g)                      # 示形轨迹先验
            return Grounding(iconic=path, tokens=encode_iconic(path))
        return Grounding.abstain(lang_prior)

    def guidance(self, v_theta, x, t, c, c_ico):
        # classifier-free guidance：向示形路径偏置；仅影响采样，不触门
        return v_theta(x, t, c) + self.w_ico * (v_theta(x, t, c_ico) - v_theta(x, t, c))
```

### IP-498 DGSR：道义手势安全精化（HICK 内单调收紧，不新增门）

```python
@dataclass
class DeonticGestureSafetyRefinement:
    """DGSR：道义手势 → HICK veto 的单调精化。
    红线：kc_hic_v6 = kc_hic_v5 ∧ ¬D_t（只增不减禁令集，保留 v5 作地板）"""
    stop_det: Any                 # 高召回轻量检测器（60–100 Hz，cost-sensitive）
    q_stop: float = 0.60          # 高置信单帧即触发
    q_dwell: float = 0.30         # 低置信需连续 k 帧
    k_dwell: int = 2
    L_stop_ms: float = 30.0       # 预占路径延迟上界

    def deontic_veto(self, H, t_now) -> bool:
        q = self.stop_det(H)                    # P(STOP | keypoints)
        if q >= self.q_stop:
            self._preempt(t_now)                # 事件触发：置 veto 标志抢占控制环
            return True
        if q >= self.q_dwell and self._dwell(H, self.k_dwell):
            self._preempt(t_now)
            return True
        return False

    def kc_hic_v6(self, x, c, t_now) -> int:
        kc5 = self.v5.hick.kc(x, c)             # v5 硬门（含旧 veto）
        D = self.deontic_veto(c.H, t_now)       # 道义否决
        return 1 if (kc5 == 1 and not D) else 0  # 点态 ≤ kc5

    def release(self, H) -> bool:
        # 释放需显式 continue 手势或超时 + 人工再使能；手势噪声不得自行解除
        return self._continue_gesture(H) or self._timeout_rearmed()
```

### IP-499 PAL：出处与归因账本（旁路，不参与决策路径）

```python
@dataclass
class ProvenanceAttributionLedger:
    """PAL：证书出处 + 机制 Shapley + 边际谱 + 博弈预警。
    红线：账本在 select 之后写入，决策路径永不读 PAL（保护定理 6）"""
    delta_bind: float = 0.02      # 绑定门阈值 δ_bind
    lam: float = 0.05             # soft-binding 温度 λ
    eps_core: float = 0.01        # 最小承重核阈值 ε
    theta_slack: float = 0.02     # 绑定频率降级阈值 θ_slack

    def record(self, x, gates, cert, src) -> Provenance:
        m = {i: gates[i].score(x) - gates[i].tau for i in gates}
        B = {i for i, mi in m.items() if mi <= self.delta_bind}
        w = softmax({i: -mi / self.lam for i, mi in m.items()})
        return Provenance(B=B, margins=m, soft_binding=w, src=src,
                          mem_tokens=src.mem, gest_tokens=src.gest,
                          version=src.version)

    def shapley(self, M, F) -> dict:
        """精确 Shapley：|M|<=10 ⇒ <=1024 联盟，离线可算。
        φ_m = Σ_{S⊆M\\{m}} |S|!(n-|S|-1)!/n! · (F(S∪{m}) - F(S))"""
        n, phi = len(M), {m: 0.0 for m in M}
        for m in M:
            others = [o for o in M if o != m]
            for r in range(len(others) + 1):
                wt = factorial(r) * factorial(n - r - 1) / factorial(n)
                for S in combinations(others, r):
                    phi[m] += wt * (F(frozenset(S) | {m}) - F(frozenset(S)))
        return phi                          # 效率性：Σφ_m = F(M) - F(∅)

    def interaction(self, M, F) -> dict:
        """成对交互：>0 协同（只有组合才有用），<0 拮抗"""
        I = {}
        for i, j in combinations(M, 2):
            vals = [F(S | {i, j}) - F(S | {i}) - F(S | {j}) + F(S)
                    for S in subsets_without(M, {i, j})]
            I[(i, j)] = mean(vals)
        return I

    def core(self, phi) -> set:
        return {m for m, v in phi.items() if v >= self.eps_core}

    def boundary_mass(self, provs, i, delta) -> float:
        return mean(0.0 <= p.margins[i] <= delta for p in provs)

    def shadow_threshold_sensitivity(self, replay, gate_i, eps=0.02) -> float:
        """离线 shadow replay 扰动 τ_i（不改线上门）：S_i ≈ 边际在 0 处密度。
        高值 = 策略贴边界（Goodhart 式代理博弈预警）。"""
        a_lo = replay.accept_rate(tau_shift={gate_i: -eps})   # 放松 τ
        a_hi = replay.accept_rate(tau_shift={gate_i: +eps})   # 收紧 τ
        return abs(a_lo - a_hi) / (2 * eps)
```

### IP-500 EFA-v6：七门 + 手势通道 + 旁路归因

```python
@dataclass
class EvidenceForgingAssemblerV6:
    """EFA-v6：七硬门不变；道义手势先于提议 fail-closed；
    认识手势仅改提议；PAL 旁路记账。"""
    dgsr: DeonticGestureSafetyRefinement
    dggk: DeicticGestureGroundingKernel
    pal: ProvenanceAttributionLedger
    v5: EvidenceForgingAssemblerV5      # 复用 fmpp/lmem/famk/vack/bck 全套

    def select(self, x0_state, t_now, rule_id, context):
        # 1) 道义门：先于一切提议，fail-closed（HICK 单调精化）
        if self.dgsr.deontic_veto(context.H, t_now):
            return False, None, 'DEONTIC_VETO'
        # 2) 认识手势 → 仅提议条件（低置信弃权）
        gr = self.dggk.ground(context.H, context.scene, context.lang_prior)
        c = build_ctx(context, self.v5.famk.observe(context.face, t_now),
                      self.v5.lmem, gr)                    # 注入 gesture tokens
        # 3) 流提议 + v5 级联（原样）
        cands = self.v5.fmpp.propose(c, K=self.v5.fmpp.K, guidance=gr.iconic)
        surv = [x for x in cands if self.v5._cheap_gates(x, gamma=c.gamma)]
        if not surv:
            return self.v5._fallback_rule_proposal(c.gamma)
        ok = self.v5._vack_bck_cascade(surv, c)
        if not ok:
            return False, None, 'ALL_CANDIDATES_REJECTED'
        best = max(ok, key=certified_margin)
        # 4) 证书附出处（旁路；决策已完成，账本不回写决策）
        self.pal.record(best, self.v5.gates, best.cert,
                        src=ProvenanceSrc(mem=c.m_topk, gest=gr.tokens,
                                          version=c.version))
        return True, best, 'FORGED_ACI'
```

## 4. 正确性论证（增量更新）

### 引理 45（单调精化不扩张）

**陈述**：若门谓词逐点满足 kc'ᵢ(x) ≤ kcᵢ(x)（对所有 x），则执行集 Exec' = {x : ∧ᵢ kc'ᵢ(x)=1} ⊆ Exec = {x : ∧ᵢ kcᵢ(x)=1}。∎
**证明**：任一 x 使所有 kc'ᵢ=1，则 kcᵢ≥kc'ᵢ=1，故亦使所有 kcᵢ=1。∎

### 引理 46（STOP 预占延迟界）

**陈述**：设检测器单帧推理上界 T_det、预占信号传递与标志读取上界 T_pre、控制环周期 T_cyc，则从 STOP 手势进入视野到 HICK 生效的延迟 ≤ T_det + T_pre + T_cyc。取 T_det≈20 ms、T_pre≈5 ms、T_cyc≈1 ms ⇒ P99 ≤ 30 ms。∎
**诚实边界**：该界不含“人做出可识别 STOP 姿态”的生理反应时间；对高速危险（如坠落物）仍可能不足。

### 定理 9（手势通道分离与执行集嵌套）

**陈述**：在 DGSR 满足 kc_hic_v6 = kc_hic_v5 ∧ ¬D_t（单调精化）且 DGGK 仅改变提议分布 π（不改任何 kc_i、不改 τ）的前提下：
(i) Exec_v6 ⊆ Exec_v5；
(ii) 硬门数量保持七门；
(iii) 认识手势的误接地/弃权不改变执行边界（仅改变尝试通过的提议分布）；
(iv) 道义手势漏检是唯一可能相对“理想检测器”放松的来源，但相对 v5 永不放松（v5 否决为地板）。
**证明**：(i) 由引理 45，kc_hic_v6 ≤ kc_hic_v5 且其余门不变 ⇒ 交集缩；(ii) DGSR 是 HICK 内部谓词精化、DGGK 是提议器，均非新锚；(iii) 由定理 6（执行边界与提议无关）；(iv) kc_hic_v6 = kc_hic_v5 ∧ … ≤ kc_hic_v5，且漏检时 D_t=0 ⇒ kc_hic_v6=kc_hic_v5，恰好退化 v5。∎

### 定理 10（证书出处健全性与绑定集）

**陈述**：给定 δ_bind>0，若 i∉B(x) 则 m_i(x)>δ_bind。于是对任意 S ⊆ {i∉B(x)}，把 S 从门集合中移除不改变 x 的接受判定；即 B(x) 是 x 的“活跃约束集”，出处账本对每个被接受 x 精确列出「删之可能翻转判定」的门。
**证明**：接受 = ∧ᵢ[m_i(x)≥0]；i∉B(x) ⇒ m_i(x)>δ_bind≥0，故移除 i 不使该合取项翻转；其余项不变 ⇒ 判定不变。∎
**诚实边界**：δ_bind 取有限值，m_i 落在 (0, δ_bind] 的门仍被列入 B(x)（保守），故账本偏向多报而非漏报；但账本只反映**当前 x 与当前 τ**，不反映分布外。

### 定理 11（机制 Shapley 的可加性、核心提取与交互）

**陈述**：设能力泛函 F:2^M→R。
(i)（效率性）Σ_{m∈M} φ_m = F(M) − F(∅)。
(ii)（可加情形）若 F(S)=c+Σ_{m∈S}a_m，则 φ_m=a_m，最小承重核 M*(ε)={m:a_m≥ε} 恰为单点消融显著者。
(iii)（一般情形）F(M)−F(M*) = Σ_{m∉M*}φ_m + Σ_{i<j, i 或 j∉M*} I_{ij} 的相应聚合项；故仅凭 Σφ 界定能力损失会因交互项产生偏差，须同时报告 I_{ij}。
(iv)（对称/零元）若 m 对所有 S 均有 F(S∪{m})=F(S)（对 F 无影响），则 φ_m=0，判为创新通缩（诚实发现）。
**证明**：(i)(ii)(iv) 为 Shapley 标准性质；(iii) 由多线性展开（Möbius/交互展开）逐项对应。∎
**诚实边界**：Shapley 是**相对所选 F 与评测分布**的边际贡献，不是因果真理；换 F（如从成功率换成安全违例率）可改变排序，须多泛函联合报告。

### 定理 12（边界贴合型代理博弈的必要签名）

**陈述**：固定提议支撑、把接受视为 Pr[m_i(x;τ_i)≥0]。则 |∂accept/∂τ_i| = f_{m_i}(0)，即影子阈值敏感度 S_i 估计的是**边际在边界处的密度**。若策略通过“贴门”而非提升真实能力来提高接受率（纯接受最大化），其最优点必落在活跃约束边界（KKT），故边界质量 β_i(δ) 与 S_i 随优化压力单调上升。因此 β_i↑ 与 S_i↑ 是代理博弈的**必要**签名。
**证明**：accept(τ)=∫_{0}^{∞} f_{m_i}(u;τ)du，τ 平移使 m_i 整体下移，故 ∂accept/∂τ_i=−f_{m_i}(0)；纯接受最大化的 KKT 条件在约束活跃处取得，边界密度即拉格朗日乘子的分布。∎
**诚实边界**：必要非充分——**语义型博弈**（代理本身错误、但边际很高）不产生边界堆积，S_i 与 β_i 均低，检测不到；仍需红队与外部真值。且 replay 分布偏离线上时 S_i 有偏。

### 定理 v6（总装）

**陈述**：在 v5 假设 (B1)~(B7) 及新增 (B8) 手势分段延迟有界（引理 46）下：
(i) Exec_v6 ⊆ Exec_v5 ⊆ … ⊆ Exec_v29（定理 9）；
(ii) 七门不变，手势通道为 HICK 精化 + 提议条件（定理 9(ii)）；
(iii) 证书出处健全（定理 10），机制归因可加、可提取最小承重核并显式报告交互（定理 11）；
(iv) 边界贴合型代理博弈有可测必要签名（定理 12）；
(v) PAL 旁路：去 PAL 不改变任何 kc 与执行集，故不破坏 fail-closed 与提议无关性。
**证明**：(i)(ii) 定理 9；(iii) 定理 10/11；(iv) 定理 12；(v) PAL 仅在 select 返回后写入，决策路径无 PAL 读取。∎

**诚实声明**：(B8) 手势识别在遮挡、快速运动、非惯用手、跨文化词表下退化；语义正确性无结构性保证（门看不见“指错对象”）；Shapley/松弛证书仅分布内有效，分布外与语义盲区无兜底；影子审计依赖 replay 代表性。归因层是**审计工具**，不是新的信任边界。

## 7. 本轮最大风险（最终确认）

**一句话**：**归因幻觉**——Shapley、绑定集与松弛证书都只在**采样到的提议支撑**上成立，而手势误接地会产生「语义错误但过门」的执行（门看不见语义）；归因层会把这类执行报告为「高边际、各门松弛、健康」，使审计层沦为**虚假保证发生器**，并诱导系统对分布外/语义上真正关键的门与机制**过度降级维护**。
