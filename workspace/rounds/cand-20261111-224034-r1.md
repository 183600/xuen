# 第 57 轮（承接第 56 轮「证据地图×主动探询×信任协商」IP-127~132；灵感循环第 3 轮；本轮灵感：「竞赛策略」×「可靠性」）

> 第 56 轮把"模型置信"换成了"证据承诺"，用持久地图 𝓜、主动探针、交互契约与证据门把不确定性挡在不可逆接触之前。但它的风险自陈已经点明软肋：证据门本质上是"**给证据贴类别 + 给来源赋静态权重**"，而**类别不是可靠性、权重不是寿命、通道数量不是独立性**。一次会塌的探针、一条高置信错标注，会在地图里长寿，并被多访融合放大成系统性偏差。本轮两个灵感各补一刀：**可靠性**把"证据可信"从定性分类升级为带时变失效率的定量工程（hazard、冗余、共因、置信下界），**竞赛策略**则补上两个此前缺失的机制——(i) 让竞争假设正面对抗，用"分辨性探针"决出冠军并要求**胜出边际**才承诺，而不是过早地 average 掉分歧；(ii) 把全任务可靠性预算当作一场要跑完的"赛程配额"，在简单地形储蓄裕度、在困难地形支取，而不是每个检查点各自贪心。核心命题由"证据说可信"升级为 **"可量化可靠地说可信，并且在竞赛中赢下承诺"**。

核心矛盾：
- **H26（证据 ≠ 可靠性）**：第 56 轮的证据门是"有证据类即放行"的布尔门，源权重 `w(src)` 是静态标量；但可靠性是**时变、带尾、受共因支配**的——一个平均校准良好的源可以在尾部失效；`seg/probe/human/cloud` 看似四路冗余，却可能共用同一感知骨干、同一种反光材质、同一种标注偏置，在共因下一起倒。证据的**数量**与**独立性**都被高估，而时序上只靠人为半衰期衰减。
- **H27（局部安全 ≠ 全局可靠）**：PCE 在每个检查点贪心交易不确定性，会过早花光探针预算、或把裕度用在不该用的地方；它缺少"整场比赛"的可靠性预算观（哪里该保、哪里该冲），也缺少"两个假设势均力敌时必须先分辨、不许和稀泥"的承诺纪律。
- **H28（可靠性模型自身也会失准）**：任何"可靠性证书"都是从有限、非平稳、可能分布漂移的测试数据估出来的；若测试集没有覆盖部署尾部，`R_LCB` 会给出**虚假的安心**，把"我没有见过失效"误当成"失效概率低"。

## 0. 直觉与动机

**灵感 1（可靠性 → 证据源的生存函数，而不是一个权重）**
直觉：把每个证据源当作一个会在时间中"失效"的部件。它在 `[0,t]` 内不产生误导性输出的概率是生存函数 `R_s(t)=exp(-∫λ_s)`，风险率 `λ_s(t)` 呈浴盆形：新源早期偏高（未校准/冷启动）、稳定期低而平、长期运行或换域后进入磨损期上升。于是：
- 权重不是常数，而是 `R_s^LCB(t)·(1-β_s)`；"旧证据变弱"来自生存函数本身，不必再拍脑袋设半衰期。
- 多源不是简单加权，而是 **k-of-n 冗余**：至少 k 个**互异多样性类**（视觉/触觉/几何/人类/云端先验）同意才放行；并用 β-factor 显式建模**共因失效**，拒绝把同源通道当独立冗余。
- 可靠性用生存分析（Kaplan–Meier / Weibull / 删失数据）估计，证书只采 **单侧置信下界 `R_LCB`**——宁可低估，不拿点估计下注。

**灵感 2（竞赛策略 → 冠军-挑战者假设竞赛，赢够边际才承诺）**
直觉：第 56 轮的 VOI 探针问的是"哪种探针最能降方差"；竞赛策略要求先问**谁在和谁竞争**。维持一组候选假设 `H`（世界模型/接触参数/路线），找出当前冠军 `h⁺` 与最强挑战者 `h⁻`；只有当 `Δ=log p(h⁺)/p(h⁻) ≥ Δ_commit`（**赢够边际**）才承诺；若势均力敌，就选**分辨性探针** `π*=argmax I_π(h⁺;h⁻)`，把预算花在"能改变胜负"的探针上，而不是泛泛降方差。这在数学上等价于带边际的序贯概率比检验（SPRT）：假承诺率 α、漏判率 β 可由阈值直接控制，并给出所需平均探针数的界。**承诺不是"当前最高分"，而是"赢到足以压住挑战者"**——领先不等于稳赢，要会管理优势。

**灵感 3（竞赛策略 → 可靠性预算是赛程配额：裕度银行）**
直觉：把整个任务看成一场有难易地形的比赛，全局只有一份可靠性预算 `δ_mission`。简单地形不必把预算浪费到极致安全，而应**储蓄可靠性信用**；困难/不可逆地形才**支取信用 + 加探针**。形式化为检查点序列上的约束优化：`max 期望进度/分数 s.t. Rel_mission({δ_i}) ≥ 1-δ_mission`，并保留**不可动用的应急储备**。像赛车手：直道保胎、弯道用胎，但永远留着回维修区的那点油。这直接治第 56 轮"每个检查点独立贪心"的短视。

**灵感 4（可靠性 → 共因屏障与多样性，而不是通道数量）**
直觉：可靠性的敌人不是"源太少"，而是"源太像"。给每个通道标注多样性类 `d_s` 与共因耦合 `β`，门限要求 k-of-n 且多样性类去重；一旦检测到源间误差相关性上升（同涨同跌），自动把它们的**等效冗余折为 1**，并触发补充**异质**证据（触觉替代视觉、几何替代语义）。这直接针对第 56 轮"四路证据其实一路"的伪冗余。

**灵感 5（竞赛策略 → 红队对抗赛，把可靠增长搬进闭环）**
直觉：可靠性不能只在部署后被动统计。设一个红队在一个**合法扰动模糊集 `𝒰`**（反光、透明、标注偏置、分布漂移）内搜索能同时骗过 k 个通道的最坏配置，蓝队每轮修补多样性、更新 β 与 `R_LCB`；直到红队找不到新的最小割集，或 `R_LCB` 达标。这等于赛前把最坏情况先打一遍，把"对抗测试 / 可靠增长"做成闭环。

## 1. 形式化定义（增量：定义 133–138）

**定义 133（证据源可靠性模型 RSM）** 源 `s` 的可靠度 `R_s(t)=exp(-∫_0^t λ_s(τ)dτ)`，风险率 `λ_s(t)` 取浴盆模型（早期递减 / 稳定常数 / 磨损递增）；由含删失的"误导事件"观测用生存分析估计，证书只用单侧下界 `R_s^LCB(t)`。有效权重 `w_s(t)=R_s^LCB(t)·(1-β_s)`，`β_s` 为与其余通道的共因失效概率。

**定义 134（多样性法定人数与共因屏障）** 证据按多样性类 `D={vision, tactile, geometric, human, cloud}` 去重；门限要求至少 `k` 个互异类且加权一致度 `agree ≥ θ_agree`。带共因的 k-of-n 可靠度 `R_sys = R_CC·Σ_{i=k}^n C(n,i) R^i(1-R)^{n-i}`，其中 `R_CC=1-β`。若测得源间误差相关 `ρ_ERR > ρ_max`，把同相关簇折叠为单一部件（等效冗余=1）。

**定义 135（冠军-挑战者假设竞赛 HTC）** 假设集 `H`，后验 `p(h|E)`；冠军 `h⁺=argmax p`，挑战者 `h⁻=argmax_{h≠h⁺} p`；胜出边际 `Δ=log(p(h⁺)/p(h⁻))`。承诺条件 `Δ ≥ Δ_commit(δ_f)`；不满足则执行分辨性探针 `π*=argmax_π I_π(h⁺;h⁻)`（期望 KL / 互信息），预算耗尽仍难分胜负则转保守动作。`Δ_commit` 控制假承诺率 α，配套的下界控制漏判率 β，与 SPRT 阈值一一对应。

**定义 136（可靠性预算与裕度银行 RBB）** 全局 `δ_mission`；分配 `{δ_i}` 解 `max_{δ_i} E[score] s.t. Rel_mission({δ_i}) ≥ 1-δ_mission, δ_i ≥ δ_floor(irreversible)`。信用 `c_i=max(0, δ_i-r_i)` 可在后续支取，但受 `c_i ≤ c_max` 约束，且不可逆地形必须保留 `δ_reserve`。`Rel_mission` 由联合界或 RBD 计算，目标函数对进度/分数单调。

**定义 137（对抗可靠性竞赛 ARC）** 红队扰动模糊集 `𝒰`；每轮求最小割集 `cs*=argmin_{u∈𝒰} R_sys(u)` 及对应共因模式；蓝队扩多样性、更新 `β`、重估 `R_LCB`；终止条件：无新割集 or `min R_LCB ≥ 1-δ_mission`。给定覆盖假设，最坏可靠度 `R_worst=min_{u∈𝒰} R_sys(u)`。

**定义 138（任务可靠性证书 MRC）** `J_r=(FT, RBD, β, R_s^LCB, {δ_i}, HTC_log, ARC_log, cov)`；由故障树最小割集与带共因 RBD 计算 `R_LCB(mission)`；要求 `R_LCB ≥ 1-δ_mission`、所有承诺接触满足第 56 轮证据门、所有最小割集至少含 `k` 个互异多样性类、且证书**带操作包络与有效期**（超包络/超时自动失效）。

### IP-133 RSM（Reliability Source Model）

```python
def source_reliability(events_s, t, conf=0.95):
    km = kaplan_meier(events_s)                # 含删失的误导事件
    fit = weibull_bathtub_fit(events_s)        # 早期/稳定/磨损
    R_hat = min(km(t), weibull_survival(fit, t))
    return lower_confidence_bound(R_hat, events_s, conf)   # 宁低估

def reliability_fuse(M, batch, t):
    groups   = group_by_diversity_class(batch)             # A38: 去重
    clusters = correlation_fold(groups, rho_err_max)       # 共因: 折为单部件
    agree = weighted_agreement(clusters, w=lambda s: w_s(M, s, t))
    if n_distinct(clusters) < k_quorum or agree < theta_agree:
        return M, 'quorum_not_met'                         # 不放行, 补异质证据
    for e in batch:
        M.b[e.region] = bayes_update(M.b[e.region], like(e),
                                     weight=w_s(M, e.src, t))
    return M, 'ok'
```

### IP-135 HTC（Hypothesis Tournament Commitment）

```python
def hypothesis_tournament_commit(cp, H, M, budget):
    while budget.probes_left > 0:
        post = posterior(H, M, cp)
        h_pos, h_neg = top_two(post)
        delta = log(post[h_pos]) - log(post[h_neg])
        if delta >= delta_commit(cp.risk):                 # 赢够边际
            if evidence_gate_ok(cp, M) and reliability_quorum_ok(M):
                return commit(h_pos, cp)                   # 仍需过第56轮证据门
            return request_heterogeneous_evidence(cp)      # 伪冗余 → 补异质
        pi = argmax(admissible_probes(cp, M),
                    key=lambda q: mutual_info_top2(q, h_pos, h_neg))
        if expected_gain(pi) < theta_gain: break
        M, _ = map_fuse(M, [execute_probe(pi, cap=F_abs)])
        budget.spend(pi)
    return conservative_action(cp, 'challenger_unresolved')  # 不分胜负 → 保守
```

### IP-136 RBB（Reliability Budget & Margin Bank）

```python
def allocate_reliability_budget(route, score_model, delta_mission):
    V, policy = backward_dp(route, score_model, delta_mission)  # 预算离散化
    return policy[0, delta_mission]        # {delta_i} + 储备约束

def margin_bank(state, cp, delta_i, realized_risk):
    state.credit = min(state.credit + max(0.0, delta_i - realized_risk),
                       state.c_max)
    if irreversible(cp):
        state.credit = max(state.credit - delta_reserve, 0.0)   # 先扣储备
    return state
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| RSM | O(|事件|·log|事件|) 估计；O(|ΔE|) 融合 | O(|源|·|时间桶|) | 删失正确、LCB 覆盖、共因 β 显式 |
| HTC | O(|H|·(C_post+C_MI)) / 检查点 | O(|H|+|E|) | 边际阈值控 α/β、分辨性探针、难分则保守 |
| RBB | O(|CP|·|B|·|A|) DP | O(|CP|·|B|) | 全局约束、储备下界、receding horizon |
| ARC | O(R·|𝒰|·RBD) | O(|割集|) | 模糊集覆盖、最小割集完备、可靠增长单调 |
| MRC | O(|FT|+|割集|) | O(|FT|) | LCB 进入证书、共因割集拒绝、包络/有效期 |

**正确性定理（Reliability-Grounded Commitment Soundness, RGCS）**：在 A33–A36（第 56 轮）基础上加 **(A37)** 可靠性观测可交换且 LCB 覆盖真实可靠度（覆盖率 ≥ 1-ε_r）；**(A38)** 多样性类互异、共因由 β 上界刻画、相关簇折叠保守；**(A39)** HTC 边际 `Δ_commit` 对应假承诺率 ≤ α、漏判率 ≤ β；**(A40)** 预算分配保守且储备 `δ_reserve` 不可侵用；**(A41)** 红队模糊集 `𝒰` 覆盖部署分布（或证书仅在其内有效）。则：
1. **承诺可靠性**：承诺接触的误导性证据概率 ≤ `α + β + ε_r`；
2. **任务可靠性**：`P_safe ≥ R_LCB(mission) − P(部署漂出 𝒰) − P(RBD 近似误差 > ε_b)`；
3. **伪冗余消除**：若真实共因 β 被 A38 上界住，则 k-of-n 不会把相关通道当独立，`P(共因击穿) ≤ β`；
4. **安全单调性继承**：HTC 难分、法定人数不足、储备不足均只触发保守动作，不存在升险路径；
5. **终止性**：HTC 在探针预算内终止于 {承诺, 保守}；RBB 的 DP 有限；ARC 有限轮或割集不再增长。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| `R_LCB` 来自不代表部署的测试集（可靠性地基失准） | 高 | 覆盖率保证 + 在线删失更新 + ARC 最坏情形搜索 |
| 独立性是幻觉（共用感知骨干/同种材质） | 高 | 多样性类去重 + 误差相关折叠 + β-factor |
| `Δ_commit` 过高导致过度保守、过低导致假承诺 | 中 | 按风险分档 + SPRT 阈值标定 + 失败回放 |
| 预算 DP 模型失配，把不存在的储备花掉 | 中 | 储备下限 + receding horizon + CVaR 保守化 |
| 证书被误用为"永久安全证明" | 中 | 操作包络 + 有效期 + 审计 + 超界自动失效 |

## 6. 本轮最大风险

**一句话**：本轮把赌注从"证据质量"进一步换到"**可靠性模型的质量**"，于是出现了自指的**二阶可靠性缺口**——`R_LCB`、共因 β 和 k-of-n 独立性都是从有限、平稳、良性的测试分布估出来的；一旦部署发生分布漂移或出现测试集从未见过的隐藏共因，看似四路冗余的通道会同时失效，而预算优化器会**自信地花掉一份从未真实存在的储备**，产出一张内部自洽、外部错误的"可靠"证书；因此必须以 **覆盖率保证的 LCB + 多样性去重与相关折叠 + 红队最坏尾巴搜索 + 包络/有效期 + 不可侵用的应急储备** 五重护栏，并且永远把"未见失效"当作上界未知而不是概率为零。

# 第 57 轮产物 · 创新点清单 v33：RelTournament（可靠性证据×冠军挑战者竞赛×预算裕度银行，RSM×HTC×RBB×ARC×MRC）

> 承接第 56 轮 IP-127~132（SMM/PCE/BVK/ISE/TAF/MEC）与第 55 轮 IP-121~126。第 56 轮把部署前提从"模型置信"升级为"证据承诺"；本轮再把它升级为 **"可量化可靠、且经竞赛胜出的承诺"**：证据源从静态权重升级为**带时变失效率的生存部件**，证据融合从加权平均升级为 **k-of-n 多样性法定人数 + 共因屏障**，承诺从"当前最高后验"升级为 **冠军-挑战者胜出边际 + 分辨性探针**，裕度从逐点贪心升级为 **全任务可靠性预算与裕度银行**，可靠性本身则经 **红队对抗竞赛** 反复压力测试，最终由 **任务可靠性证书（RBD + 最小割集 + LCB）** 封口。

### IP-133 RSM（Reliability Source Model）

```python
def source_reliability(events_s, t, conf=0.95):
    # events_s: 误导事件（事后被探针/实测证伪）与删失观测
    km  = kaplan_meier(events_s)
    fit = weibull_bathtub_fit(events_s)          # 早期递减/稳定/磨损递增
    R_hat = min(km(t), weibull_survival(fit, t))
    return lower_confidence_bound(R_hat, events_s, conf)   # 宁可低估

def w_s(M, s, t):
    return source_reliability(M.events[s], t) * (1 - beta_est(M, s))

def update_source_reliability(M, s, event, t):
    M.events[s].append((t, event))               # event ∈ {miss, false_alarm, censored}
    M.R[s] = source_reliability(M.events[s], t)
    if drift_test(M.events[s]):                  # 换域/磨损 → 缩短寿命
        M.hazard[s].shift_wearout(t)
    return M
```

### IP-134 DCQ（Diversity-Quorum Gate，接入 SMM 融合）

```python
def diversity_quorum_fuse(M, batch, t):
    groups   = group_by_diversity_class(batch)             # A38: 按类去重
    clusters = correlation_fold(groups, rho_err_max)       # 共因相关簇 → 单部件
    if n_distinct(clusters) < k_quorum:
        return M, 'quorum_not_met'                         # 不放行，请求异质证据
    agree = weighted_agreement(clusters, w=lambda s: w_s(M, s, t))
    if agree < theta_agree:
        return M, 'disagreement'                           # 分歧 → 不得承诺
    for e in batch:
        M.b[e.region] = bayes_update(M.b[e.region], like(e),
                                     weight=w_s(M, e.src, t))
        M.prov[e.region] = touch(M.prov[e.region], e)
    M.ver.bump_all(batch)
    return M, 'ok'

def effective_redundancy(M, cluster):
    # 相关簇内等效冗余折为 1，只按"类"计数，防伪冗余
    return 1 if pairwise_error_corr(cluster) > rho_max else len(cluster)
```

### IP-135 HTC（Hypothesis Tournament Commitment）

```python
def hypothesis_tournament_commit(cp, H, M, budget):
    while budget.probes_left > 0:
        post = posterior(H, M, cp)
        h_pos, h_neg = top_two(post)
        delta = log(post[h_pos]) - log(post[h_neg])
        if delta >= delta_commit(cp.risk, posture(M)):
            if evidence_gate_ok(cp, M) and diversity_quorum_ok(M, cp):
                return commit(h_pos, cp)                   # 双门齐备才承诺
            return request_heterogeneous_evidence(cp)      # 伪冗余 → 补异质
        pi = argmax(admissible_probes(cp, M),
                    key=lambda q: mutual_info_top2(q, h_pos, h_neg))
        if expected_gain(pi) < theta_gain:
            break                                          # 分辨无望 → 保守
        M, _ = map_fuse(M, [execute_probe(pi, cap=F_abs)])
        budget.spend(pi)
    return conservative_action(cp, 'challenger_unresolved')  # 不许和稀泥

def delta_commit(risk_class, posture):
    # SPRT 阈值：α 假承诺、β 漏判 → Δ_commit=log((1-β)/α)；高风险再抬门槛
    base = log((1 - beta_sprt) / alpha_sprt)
    return base + kappa_risk * risk_class
```

### IP-136 RBB（Reliability Budget & Margin Bank）

```python
def allocate_reliability_budget(route, score_model, delta_mission):
    # V[i,b] = 从第 i 个检查点起、剩预算 b 的最大期望分数
    V, policy = backward_dp(route, score_model, delta_mission,
                            reserve=delta_reserve,
                            floor=lambda cp: delta_floor(cp) if irreversible(cp) else 0.0)
    return policy[0, delta_mission]              # {delta_i}

def margin_bank(state, cp, delta_i, realized_risk):
    state.credit = min(state.credit + max(0.0, delta_i - realized_risk),
                       state.c_max)              # 简单地形储蓄
    if irreversible(cp):
        state.credit = max(state.credit - delta_reserve, 0.0)   # 先扣应急储备
    return state

def receding_horizon_execute(route, M, budget, delta_mission):
    while route.remaining:
        alloc = allocate_reliability_budget(route, score_model, delta_mission)
        cp = route.next()
        delta_i = alloc[cp.index]
        if budget.available(delta_i):
            sched = probe_commit_evolve(cp, M, budget, delta_i)   # 第 56 轮 PCE
            budget.consume(realized_risk(sched))
            state = margin_bank(state, cp, delta_i, realized_risk(sched))
        else:
            return safe_stop(cp, 'budget_exhausted')
    return state
```

### IP-137 ARC（Adversarial Reliability Contest）

```python
def adversarial_reliability_contest(M, U, blue, max_rounds):
    cut_sets = []
    for rnd in range(max_rounds):
        u  = argmin(U, key=lambda u: reliability_rbd(blue.M, u))   # 红队
        cs = min_cut_set(blue.M, u)                                # 最坏割集
        if cs in cut_sets: break
        cut_sets.append(cs)
        blue = add_diversity(blue, cs)          # 蓝队：补异质证据/冗余
        update_common_cause_beta(blue, cs)      # 修正 β 与 R_LCB
        blue.R_lcb = rbd_lower_bound(blue.M, beta=blue.beta)
        if blue.R_lcb >= 1 - blue.delta_mission:
            break
    return cut_sets, blue.R_lcb, blue.beta
```

### IP-138 MRC（Mission Reliability Certificate）

```python
def mission_reliability_certificate(sched, J_m, R_lcb, delta_alloc,
                                    htc_log, arc_log, env, t_now):
    ft   = build_fault_tree(sched, J_m)                 # 接触/感知/交互事件
    cuts = minimal_cut_sets(ft)
    for cs in cuts:
        if n_diversity_classes(cs) < k_quorum:          # 共因割集：拒绝
            return ('reject', 'common_cause_cutset', cs)
    R_cc  = 1 - beta_est(arc_log)
    R_lcb_mission = rbd_lower_bound(ft, R_lcb, R_cc)     # 带共因的 k-of-n
    if R_lcb_mission < 1 - delta_mission:
        return ('reject', 'mission_reliability', R_lcb_mission)
    if not all(c.evidence_gate_ok for c in contacts(sched)):
        return ('reject', 'evidence_gate', None)        # 第 56 轮证据门
    if not coverage_ok(arc_log, env):                   # 模糊集/包络覆盖
        return ('reject', 'coverage', env)
    return ('ok', ReliabilityCert(
        ft=ft, cuts=cuts, R_lcb=R_lcb_mission, beta=R_cc,
        delta_alloc=delta_alloc, htc_log=htc_log, arc_log=arc_log,
        envelope=env, valid_until=t_now + t_expire))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| RSM | O(\|事件\|·log\|事件\|) 估计；O(1) 权重查询 | O(\|源\|·\|时间桶\|) | 删失正确、LCB 覆盖（A37） |
| DCQ | O(\|ΔE\|·(\|D\|+\|E\|²_corr)) | O(\|D\|+跨度) | 多样性去重、共因折叠（A38） |
| HTC | O(\|H\|·(C_post+C_MI)) / cp | O(\|H\|+\|E\|) | 边际控 α/β、分辨性探针（A39） |
| RBB | O(\|CP\|·\|B\|·\|A\|) DP | O(\|CP\|·\|B\|) | 全局约束、储备下限（A40） |
| ARC | O(R·\|𝒰\|·RBD) | O(\|割集\|) | 模糊集覆盖、可靠增长（A41） |
| MRC | O(\|FT\|+\|割集\|) | O(\|FT\|) | LCB 入证、共因割集拒绝、包络/有效期 |

**正确性定理（Reliability-Grounded Commitment Soundness, RGCS）**
假设 A22–A28（第 53/54 轮）、A29–A36（第 55/56 轮）成立；并新增 **(A37)** 源可靠性观测可交换，`R_s^LCB` 以 ≥ 1-ε_r 概率覆盖真实可靠度；**(A38)** 多样性类互异、共因由 β 上界刻画、误差相关簇折叠保守；**(A39)** HTC 边际 `Δ_commit` 对应假承诺率 ≤ α、漏判率 ≤ β；**(A40)** 预算分配保守、储备 `δ_reserve` 不可侵用；**(A41)** 红队模糊集 `𝒰` 覆盖部署分布，证书仅在 `𝒰` 与操作包络内有效。则：

1. **承诺可靠性**：承诺接触的误导性证据概率 `≤ α + β + ε_r`；
2. **伪冗余消除**：真实共因被 A38 上界住时，k-of-n 不会把相关通道当独立，`P(共因击穿) ≤ β`；
3. **任务可靠性**：
   ```
   P_safe ≥ R_LCB(mission) − P(部署漂出 𝒰) − P(RBD 近似误差 > ε_b)
   ```
   其中 `R_LCB(mission)` 由带共因的故障树最小割集与源 LCB 计算；
4. **安全单调性**：HTC 难分、法定人数不足、预算不足均只触发保守动作（补异质证据 / 绕行 / 降档 / L2 / 安全停），不存在升险路径；
5. **终止性**：HTC 在探针预算内终止于 {承诺, 保守}；RBB 的 DP 有限；ARC 在割集不再增长或 LCB 达标时终止。

关键：**承诺从"最高后验"变为"赢够边际 + 双门齐备"**；**可靠性从定性类别变为带 LCB 的生存函数**；**冗余从"通道数"变为"互异多样性类"**；**裕度从逐点贪心变为全局配额 + 不可侵用储备**；**可靠性本身经红队最坏情形搜索获得增长**。

## 6. 本轮最大风险

**一句话**：本轮把赌注从"证据质量"进一步换到"**可靠性模型的质量**"，于是出现自指的**二阶可靠性缺口**——`R_LCB`、共因 β 与 k-of-n 独立性都从有限、平稳、良性的测试分布估出；一旦部署发生分布漂移或出现测试集从未见过的隐藏共因，看似四路冗余的通道会同时失效，而预算优化器会自信地花掉一份从未真实存在的储备，产出一张内部自洽、外部错误的"可靠"证书；必须以 **覆盖率保证的 LCB + 多样性去重与误差相关折叠 + 红队最坏尾巴搜索 + 操作包络/有效期 + 不可侵用的应急储备** 五重护栏，并且永远把"未见失效"当作上界未知而非概率为零。
