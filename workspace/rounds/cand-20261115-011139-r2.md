# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「开源生态」×「轻量化设计」）

> R69 用一条漂亮的分工处理了不确定性：aleatoric 收紧、epistemic 提问。但它默认整个闭环是一个**固定构型**、由一组**你信得过的组件**组成、并且**算力管够**。这三条在真实部署里没有一条成立：闭环是拼出来的（编码器、流头、标定器、LLM、审计器来自不同上游、不同版本、不同许可）；零件随时可能被替换或被投毒；实时预算只够跑其中一小部分。于是 R69 的证书 J_FLUID 有一个从未被追问的前提——「**我信的那一整套东西，恰好就是这一轮在跑的那一整套东西，而且它们确实按说明书工作。**」
>
> 本轮两个灵感各拆掉这个前提的一半：
> - **开源生态**把「一个可信单体」变成「一个可组装、可替换、可被第三方审计、也可被第三方投毒的供应链」：信任对象从*模型*迁移到*组合 + 出处*（bill of materials）。
> - **轻量化设计**把「算力免费」变成「算力要定价」：不是把模型做小，而是让**算力花在证书当前真正绷紧的那条约束上**；蒸馏/量化必须携带可度量的「保真欠债」并显式补偿，否则「更轻」就等于「更不安全」。
>
> 核心命题：**把每一轮闭环视为一次「按需组装」——在开放组件生态里选出一个在预算 B 内、在给定假设域内、其组合证书仍成立的最小充分装配；若选不出，就退回一个不依赖任何可选组件的「最小认证内核」（MCK）。** 命名 **LOOM-RAS**（Lightweight Open-source Orchestrated Modular Risk-Adaptive System）——像织机一样，用最少的线织出足够强度的布。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我这套系统究竟由什么拼成、每一件凭什么可信、我付得起多少算力来证明它**」。

## 0. 直觉与动机

**灵感 1（开源生态 → 系统是一个物料清单，而不是一个单体）**
直觉：今天的机器人栈早已不是一家公司从传感器写到执行器，而是 pybullet+ROS+一堆 pip 包+第三方权重。开源生态的真实含义不是「免费」，而是**可替换性 + 可审计性 + 出处可追溯**，同时也意味着**任意一个环节都可能被换成一个坏的**。因此「系统是否安全」不再是对单个模型的性质判断，而是对**一个装配（assembly）及其物料清单**的性质判断。直觉上，这和工业界的「安全件必须可追溯批次与供应商」是同一件事：安全性是组合出来的，不是许愿出来的。
严谨对应：每个组件携带一张**能力契约清单**（manifest），声明的不是「我很强」，而是「在假设域 A_c 内，我对性质 G_c 给出概率 ≥ 1−δ_c 的下界保证」，外加成本模型、依赖、出处签名、已知失效模式与有效期。证书沿组合算子传播，而不是在最后一步凭空产生。

**灵感 2（轻量化设计 → 算力按「证书约束」定价，而非按模型大小定价）**
直觉：把 6 亿参数压到 600 万，未必更轻，只是把成本从 GPU 挪到了「因为你不再知道它错在哪，于是必须更保守地开」上。真正的轻量化是**证书感知的**：每轮先看当前证书的哪一条约束最紧（是模态熵？是标定 ECE？是流似然的 Marsh 阈值？），把下一毫秒的算力投到能最有效抬高该约束裕度的动作上；约束一旦全绿就停。于是「轻」=「刚好够把话说圆」，不是「尽量小」。
严谨对应：把计算建模成**边际保证/成本**的递减收益分配问题，用 anytime 调度在预算内逼近最优；蒸馏与量化被建模为**保真欠债 ε_d**，必须用可证明的补偿（抬 λ_floor、抬 FMA 阈值）换回等价保证——「更轻但保证不更弱」。

**灵感 3（两者对偶 → 开放给你选择，预算逼你选择）**
直觉：开源生态提供大量可互换实现（同一接口下不同精度/延迟/校准档位），这是**多样性红利**；轻量预算逼迫你只选一个**最小充分子集**，这是**稀缺性约束**。二者相乘就是一个安全感知的背包问题：在「组合后证书仍成立」的可行域里，找成本最小的装配。R69 的固定全栈，恰好是「所有件、全精度、永不裁剪」这唯一一个装配；而「最小认证内核」是另一个极端装配。新框架的价值，是把这两点之间的一整条**保证—成本前沿**显式地画出来。
严谨对应：装配规划器 AP 在缓存的等价类前沿上做约束优化；R69 = 单点特殊情形（定理 18）。

**灵感 4（信任的迁移 → 签名只证明「谁说的」，不证明「说的是真的」）**
直觉：开源供应链最危险的错觉，是把「有签名、有 CI、有 README」当成「可信」。签名只绑定身份，不绑定真实性。一个清单可以诚实地错，也可以恶意地错。因此 LOOM 的信任必须是**可复现 + 可证伪**的两段式：清单声明必须在标准化评测协议下可复现（证明「在声明分布上测过」），并在运行时被连续探针证伪（证明「在你这台机器、这个分布上仍然成立」）。静态信任在开放生态里是不成立的。
严谨对应：`runtime falsification monitor` + 信任衰减 α_c(t)，清单一旦被证伪就从「可认证」降级为「实验性」并逐出装配；证据独立性由**出处类别**而非模态类别度量（同一上游 fork 的十份审计只算一份）。

**灵感 5（新失效模式 → 供应链是新的攻击面）**
直觉：R69 已经防了「人会撒谎」，但那假设「零件是真的、只是回答可能假」。开放生态多出一整类此前不存在的失效：木马权重、拼写抢注/依赖混淆、被投毒的社区失败语料、过期或语义漂移的清单、接口同名但语义不同的「李鬼组件」、以及「清单是在评测集上真的、在你车上假的」假设错配。更隐蔽的是**组合非单调**：两个各自安全的件拼起来可能不安全（单位、坐标系、时序约定不一致），而开源恰恰放大了这种「接口语义漂移」。
严谨对应：威胁集扩展为 ℰ_LOOM = ℰ_FLUID × ℰ_supply；组合只允许单调收紧的组合规则；接口语义用契约测试（contract test）钉死；任何假设不满足 → 不放宽，只退 MCK。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（LOOM-RAS 总览）** LOOM-RAS = (REG, AP, CAC, FID, PIM, LEDGER, MCK, RAS-WM‡)。三不变式：
(i) **安全底线与生态无关**：MCK 不含任何可选组件，其最坏时延 B_min 预先离线测定，任何时刻可调度；
(ii) **组合单调**：任一有效装配的组合证书风险 ≤ MCK 证书风险；加入/升级组件只能收紧、不能放宽已认证界；
(iii) **物料完整**：每次执行都携带 BOM 哈希与构建证明；任一清单缺失/伪造/过期/假设不满足 ⇒ 该组件被排除；排除**永不静默放宽**假设，只能触发 MCK 或显式的「假设放宽 + λ 补偿」。

**定义 311（组件与能力契约清单）** 组件 c = (impl π_c, M_c, cost_c, prov_c)。清单
M_c = (id, ver, semver, interface, assumptions A_c, claims G_c, evidence E_c, cost_model, license, content_hash, signature, deps, known_failures, eval_protocol_id, expiry)。
声称分两类：**可认证（sound）**——给出假设域内性质的下界保证；**实验性（experimental）**——只给经验数值，禁止参与证书。

**定义 312（契约语义）** 记 c ⊨ (A_c, G_c, δ_c)：若输入 x ∈ A_c，则性质 G_c 以概率 ≥ 1−δ_c 成立。假设域 A_c 包含输入分布、传感器包络、温度/量化档、标定范围。**soundness** 要求 G_c 是保守下界（宁可低估自己）。

**定义 313（组合算子 ⊕ 与清单传播）** c₁ ⊕ c₂ 先做接口统一（类型、单位、坐标系、时序约定必须通过契约测试），再令 A = A₁ ∩ A₂ ∩ A_iface，G 按固定规则集 R 组合（风险界相加、Lipschitz 相乘、误差互补），成本相加并计入通信。⊕ 只允许**单调收紧规则**：不允许任何「两个不确定相互抵消」式的乐观合并。

**定义 314（装配、保证目标与预算）** 装配 α = ⊕_{c∈S} c，S ⊆ REG。给定保证目标 ε 与预算 B（P99 时延 / 显存 / 能耗）。α 可行（feasible）⇔ 假设域相交非空 ∧ 出处校验通过 ∧ cost_p99(α) ≤ B ∧ risk_cert(α) ≤ ε。

**定义 315（装配规划器 AP）** α* = argmin_{α feasible} cost_p99(α)（或对固定成本最大化保证裕度）。离线在等价类上预计算「保证—成本」Pareto 前沿并缓存；在线只做前沿查表 + 少量修复；前沿为空或查询超时 ⇒ 返回 MCK。

**定义 316（证书感知 anytime 计算 CAC）** 证书由若干约束 {g_i(α) ≤ 0} 组成（模态校准 ECE、FMA 阈值、模态熵、前缀认证等），裕度 m_i = −g_i。每步计算 e 带来收益 Δm(e) 与成本 Δcost(e)。调度规则：反复选 `argmax_e Δm(e)/Δcost(e)`，直到所有 m_i ≥ 0（证书成立）或预算耗尽或 max Δm/Δcost ≤ 0。**部分计算只产生部分证书**：未成立即按未认证处理。

**定义 317（轻量化的保真欠债与补偿）** 由重型组件 c 经蒸馏/量化/剪枝得 c′，度量 d(c, c′)（输出 TV / 对数似然 sup 差）≤ ε_d。补偿算子 Δ(ε_d) = (L_risk·ε_d 抬入 λ_floor，L_lik·ε_d 抬入 FMA 阈值，…)。**认证等价**：risk_cert(c′)+Δ(ε_d) ≤ risk_cert(c)。若 ε_d 不可度量或不可界，则 c′ 不可认证，只能当实验件。

**定义 318（最小认证内核 MCK）** 固定最小集合：低分辨率编码 + 廉价 mode_head + 保守 λ_floor + 认证前缀选择器；不含 LLM、不含主动交互、不含 Hutchinson。其最坏时延 B_min 与证书 J_MCK 离线预置；**不依赖注册表里任何可选件**。

**定义 319（出处图与证明独立性）** 出处图节点 = 组件/构建，边 ∈ {depends-on, fork-of, audited-by, signed-by}。两个证据源**出处独立** ⇔ 签署组织不同 ∧ 最近公共祖先的代码贡献占比 < θ_prov。独立性类别数 k_eff ≤ 证据条数。

**定义 320（社区审计账本 LEDGER）** 审计记录以 Merkle 树组织，附包含证明；审计者押注声誉 r_a，记录权重 = r_a · 1[谓词可复现] · inclusion_ok。被证伪的审计扣减押注。

**定义 321（供应链威胁集 ℰ_supply）** 木马权重、拼写抢注/依赖混淆、投毒失败语料、清单过期/语义版本漂移、接口语义伪装（同名不同义）、许可陷阱。总威胁集 ℰ_LOOM = ℰ_FLUID × ℰ_supply。

**定义 322（清单证伪监视器 MFM）** 用签名自检集与无标签一致性探针，比较清单声称与实际观测；违规计数 v_c，信任按 α_c(t+1) = α_c(t)·exp(−κ v_c)。α_c < τ_trust ⇒ 声称降级为实验性并逐出装配。

**定义 323（BOM 与可复现证明）** BOM_hash = H(sorted{(id, ver, content_hash, sig)})。可复现证明 attest(c) = 「在本协议 eval_protocol_id 下、用签名基准集重跑，得到 claims」。注意 attest 证明「测过」，不证明「在你的分布上仍真」——后者由 A_c 契约与 MFM 负责。

**定义 324（预算—名义安全 BNR）** BNR(ε, B) = min{cost_p99(α) : risk_cert(α) ≤ ε, α 可行}。系统 (ε, B)-名义安全 ⇔ 每轮要么返回 cost ≤ B 且 risk ≤ ε 的已认证装配，要么返回 MCK 并附 J_MCK；**绝不在超预算时声称更高保证**。

**定义 325（证书 J_LEAN）** J_LEAN = (J_FLUID, BOM_hash, assembly_id, {manifest_hash}, fidelity_debt, margin_profile, prov_ok, trust_min, budget_used, loom_ver)。Valid ⇔ Valid(J_FLUID) ∧ prov_ok ∧ 清单均未过期 ∧ 保真欠债已补偿 ∧ cost_p99 ≤ B ∧ 组合单调界成立 ∧ 假设域覆盖当前输入。

## 2. 关键算法骨架

```python
# IP-264/265 REG + AP：注册表与「保证—成本」装配规划
class AssemblyPlanner:
    def __init__(self, registry, frontier_cache):
        self.reg, self.cache = registry, frontier_cache   # 离线 Pareto 前沿

    def plan(self, x, eps, budget):
        cls = self.cache.classify(x, eps, budget)         # 等价类：输入域×目标×预算档
        for alpha in self.cache.frontier(cls):            # 已按 cost 升序
            if alpha.cost_p99 > budget: continue
            if not self.reg.provenance_ok(alpha): continue
            if not alpha.assumptions.cover(x):   continue
            if not alpha.sound:                  continue
            return alpha
        return MCK                                       # 不可行 → 最小认证内核

# IP-266 CAC：把算力花在证书最紧的那条约束上
def certificate_aware_compute(alpha, x, deadline):
    budget = deadline - now()
    while budget > 0 and not alpha.cert.valid():
        e = max(alpha.cert.cheap_steps(), key=lambda e: e.margin_gain / e.cost)
        if e.margin_gain <= 0: break
        if e.cost > budget: break
        alpha = alpha.apply(e); budget -= e.cost
    return alpha if alpha.cert.valid() else MCK          # 未认证即当未认证

# IP-267 FID：轻量化保真欠债 → 可证明补偿
def compensate(heavy_risk, light_risk, eps_d, L_risk, L_lik):
    # 认证等价：light_risk + Δ ≤ heavy_risk
    lam_bonus = max(0.0, light_risk + L_risk * eps_d - heavy_risk)
    tau_bonus = L_lik * eps_d
    return lam_bonus, tau_bonus                          # 抬 λ_floor 与 FMA 阈值

# IP-268 MCK：不依赖生态的安全底线
def minimal_certified_kernel(o_t):
    z  = lowres_encode(o_t)
    K  = 1                                             # 不升 K，不做主动交互
    lam = lam_floor_conservative(z)
    k  = certified_prefix(propose(z), H=1, conservative=True)
    return k, lam, cert_J_MCK                          # 预置 B_min 内必然返回

# IP-269/272 PIM：出处校验 + 运行时证伪
def provenance_and_falsify(alpha, probes):
    bom = hash_bom(alpha)
    if not verify_signatures(alpha) or expired(alpha): return False, 0.0
    trust = min(alpha.components, key=lambda c: manifest_trust(c))
    for c in alpha.components:                         # MFM
        v = count_violations(c, probes)
        c.alpha_trust *= exp(-KAPPA * v)
        if c.alpha_trust < TAU_TRUST: c.demote_to_experimental()
    return trust.alpha_trust >= TAU_TRUST, bom

# IP-270/271 LEDGER：社区审计，按出处计独立性
def evidence_independence(audits):
    classes = provenance_classes(audits)               # 同上游 fork 折叠为一类
    k_eff   = len(classes)
    w       = {cl: max(a.reputation for a in audits if prov_class(a) == cl)
               for cl in classes}
    return k_eff, w                                    # 供 R69 的 k-一致纪律使用

# IP-275 主闭环（继承 R69，仅在「用哪套件」处插入 LOOM 层）
def LOOM_RAS_round(M, obs):
    x = M.perceive(obs)
    alpha = M.ap.plan(x, eps=M.eps, budget=M.budget)   # 1) 选最小充分装配
    if alpha is MCK:
        return minimal_certified_kernel(obs)           # 安全底线，永不过期
    trust_ok, bom = M.pim.provenance_and_falsify(alpha, M.probes)
    if not trust_ok:
        return minimal_certified_kernel(obs)
    alpha = M.cac.run(alpha, x, deadline=M.deadline)   # 2) 证书感知 anytime 计算
    if not alpha.cert.valid() or alpha.cost_p99 > M.budget:
        return minimal_certified_kernel(obs)
    # 3) 落到 R69 的 FLUID 层（组件是选出来的，语义不变）
    k, lam, mode, U = R69_FLUID_core(alpha, x)
    lam = max(lam, lam_floor_conservative(x) + alpha.fid.lam_bonus)  # 4) 欠债补偿
    M.ledger.append_audit(bom, alpha.id, U, signed=True)
    return k, lam, mode, J_LEAN(bom, alpha, U)         # 5) 物料齐全的证书
```

## 3. 推导

**引理 19（轻量化证书转移）** 设重型策略 p 与轻量策略 p′ 的输出分布满足 d_TV(p, p′) ≤ ε_d，风险泛函对分布满足 L-Lipschitz；则 |R(p′) − R(p)| ≤ L·ε_d。故把 λ_floor 抬高 L·ε_d 后，p′ 的认证风险不高于 p。对 FMA，若 ‖log p − log p′‖∞ ≤ ε_l，则阈值平移 ε_l 后异常漏检率不升。**系：轻量化可认证 ⇔ 欠债可度量且已补偿；不可度量的「差不多」不构成轻量化，只构成降级。**

**引理 20（出处加权证据独立性）** 设单源被污染概率 δ_p，同一出处类内欺骗相关 ρ<1，有效独立类数 k_eff；则「k_eff 类一致才定案」的错误采纳率 ≤ δ_p·ρ^{k_eff−1} + ε_σ。**系：十条同上游 fork 的审计必须折叠为一条；开源生态不会自动送来独立性，独立性要按出处度量。**

**引理 21（CAC 贪心的近似最优）** 若各计算步的证书裕度增益非负且递减（次模），步成本可加，则按收益/成本贪心在背包约束下取得最优的至少 (1/2)(1−1/e)；采用标准部分枚举变体可达 (1−1/e)。**系：「约束全绿即停 / 边际收益≤成本即停」是近最优停止规则，不是拍脑袋。**

**定理 18（装配可靠性与 R69 严格包含）** 在清单 sound、组合规则单调、假设域相交的前提下，任一有效装配的认证风险 ≤ MCK 认证风险；且当注册表被限制为 R69 的原始组件、全精度、不裁剪、预算充足时，AP 返回该唯一装配，J_LEAN 退化为 J_FLUID，**逐指令行为相同**。故 R69 = LOOM 的「单点全栈装配」特殊情形。

**定理 19（预算可行的 anytime 安全）** MCK 的最坏时延 B_min 离线预置。若 B ≥ B_min，则 LOOM 每轮要么返回 cost ≤ B 且已认证的装配，要么返回 MCK；**实时截止与证书诚实被联合保证**：系统不会在超预算时仍声称更高保证。

**定理 20（清单证伪的有界性）** 若某清单把保证夸大了 Δ，且运行时探针在 A_c 内分布覆盖、单次检出功效 β，则 N = O((1/β)·log(1/τ)) 次使用内该组件被降级概率 ≥ 1−τ。**系：自报清单只有在「连续证伪」下才近似可用；静态信任在开放生态中本身就不成立。**

## 6. 本轮最大风险

**一句话**：LOOM-RAS 的整栋安全大厦押在「清单说的是真的」上，而签名只证明**谁**做了声明、可复现证明只证明「在声明分布上测过」——**若清单自证清白而实际撒谎（或只是诚实地在评测集上对、在你的部署上错），组合证书就是在一个不可信的物料清单上做可信推理；此时「轻量化」只是把不可信的零件更便宜、更准时地装进实时预算，而「开源生态」把信任从一个模型扩散成一堆互相担保的清单**。

**次级风险与缓解**：
1. **假设错配**（清单在 A_c 内真、运行时越界）→ 输入域监视 + 假设不满足只退 MCK，不放宽；
2. **组合非单调/接口语义漂移** → 只允许单调收紧规则 + 契约测试 + ℰ_supply 对抗回归；
3. **CAC 抖动/饥饿**（每轮反复换装配）→ 滞后与装配粘滞（hysteresis）+ 前沿缓存；
4. **声誉博弈/互刷审计** → 押注 + 出处多样性惩罚 + 跨组织独立才计数；
5. **不可度量的保真欠债被默认接受** → 无 ε_d 界即降级为实验件，禁止参与认证。

# IP-264/265 REG + AP：注册表与「保证—成本」装配规划
class AssemblyPlanner:
    def plan(self, x, eps, budget):
        cls = self.cache.classify(x, eps, budget)          # 输入域×目标×预算档
        for alpha in self.cache.frontier(cls):             # 已按 cost 升序
            if alpha.cost_p99 > budget: continue
            if not self.reg.provenance_ok(alpha): continue
            if not alpha.assumptions.cover(x):   continue
            if not alpha.sound:                  continue
            return alpha
        return MCK                                         # 不可行 → 最小认证内核

# IP-266 CAC：算力花在证书最紧的约束上
def certificate_aware_compute(alpha, x, deadline):
    budget = deadline - now()
    while budget > 0 and not alpha.cert.valid():
        e = max(alpha.cert.cheap_steps(), key=lambda e: e.margin_gain / e.cost)
        if e.margin_gain <= 0 or e.cost > budget: break
        alpha = alpha.apply(e); budget -= e.cost
    return alpha if alpha.cert.valid() else MCK            # 未认证即当未认证

# IP-267 FID：轻量化保真欠债 → 可证明补偿
def compensate(heavy_risk, light_risk, eps_d, L_risk, L_lik):
    lam_bonus = max(0.0, light_risk + L_risk * eps_d - heavy_risk)
    tau_bonus = L_lik * eps_d
    return lam_bonus, tau_bonus                            # 抬 λ_floor 与 FMA 阈值

# IP-268 MCK：不依赖生态的安全底线
def minimal_certified_kernel(o_t):
    z   = lowres_encode(o_t)
    lam = lam_floor_conservative(z)
    k   = certified_prefix(propose(z), H=1, conservative=True)
    return k, lam, cert_J_MCK                              # B_min 内必然返回

# IP-269/274 PIM：出处校验 + 运行时证伪
def provenance_and_falsify(alpha, probes):
    if not verify_signatures(alpha) or expired(alpha): return False, None
    for c in alpha.components:                             # MFM
        c.alpha_trust *= exp(-KAPPA * count_violations(c, probes))
        if c.alpha_trust < TAU_TRUST: c.demote_to_experimental()
    return min(c.alpha_trust for c in alpha.components) >= TAU_TRUST, hash_bom(alpha)

# IP-270/271 LEDGER：社区审计，按出处计独立性
def evidence_independence(audits):
    classes = provenance_classes(audits)                   # 同上游 fork 折叠
    w = {cl: max(a.reputation for a in audits if prov_class(a) == cl) for cl in classes}
    return len(classes), w                                 # 供 R69 的 k-一致纪律

# IP-275 主闭环（继承 R69）
def LOOM_RAS_round(M, obs):
    x = M.perceive(obs)
    alpha = M.ap.plan(x, M.eps, M.budget)                  # 1) 最小充分装配
    if alpha is MCK: return minimal_certified_kernel(obs)
    trust_ok, bom = M.pim.provenance_and_falsify(alpha, M.probes)
    if not trust_ok: return minimal_certified_kernel(obs)
    alpha = M.cac.run(alpha, x, M.deadline)                # 2) 证书感知计算
    if not alpha.cert.valid() or alpha.cost_p99 > M.budget:
        return minimal_certified_kernel(obs)
    k, lam, mode, U = R69_FLUID_core(alpha, x)             # 3) 落到 R69 语义
    lam = max(lam, lam_floor_conservative(x) + alpha.fid.lam_bonus)   # 4) 欠债补偿
    M.ledger.append_audit(bom, alpha.id, U, signed=True)
    return k, lam, mode, J_LEAN(bom, alpha, U)             # 5) 物料齐全证书

## 4. 推导

**引理 19（轻量化证书转移）** 若 `d_TV(p,p′)≤ε_d` 且风险泛函 L-Lipschitz，则 `|R(p′)−R(p)|≤L·ε_d`；λ_floor 抬高 `L·ε_d` 后 p′ 的认证风险不高于 p。对 FMA，`‖log p − log p′‖∞≤ε_l` 时阈值平移 ε_l，漏检率不升。**系：轻量化可认证 ⇔ 欠债可度量且已补偿；不可度量不算轻量化，只算降级。**

**引理 20（出处加权证据独立性）** 单源污染率 δ_p、类内相关 ρ<1、有效独立类 k_eff，则错误采纳率 ≤ `δ_p·ρ^{k_eff−1}+ε_σ`。**系：同上游十份审计折叠为一份；开放生态不自动提供独立性。**

**引理 21（CAC 贪心近优）** 步收益非负递减（次模）、成本可加时，收益/成本贪心在背包约束下 ≥ 最优的 `(1/2)(1−1/e)`；部分枚举变体达 `(1−1/e)`。**系：「全绿即停/边际≤成本即停」是近优停止规则。**

**定理 18（装配可靠性与 R69 包含）** 清单 sound、组合单调、假设相交时，任一有效装配风险 ≤ MCK 风险；当注册表限定为 R69 原始组件、全精度、不裁剪且预算充足时，AP 返回该唯一装配，J_LEAN≡J_FLUID，**逐指令行为相同**。故 R69 = 单点全栈装配特例。

**定理 19（预算可行 anytime 安全）** B_min 预置；若 B ≥ B_min，每轮要么返回已认证且 cost≤B 的装配、要么返回 MCK；**实时截止与证书诚实联合保证**，不会超预算还声称更高保证。

**定理 20（清单证伪有界）** 清单夸大 Δ、探针分布覆盖且单次功效 β 时，N = O((1/β)log(1/τ)) 次内降级概率 ≥ 1−τ。**系：自报清单只在连续证伪下近似可用；静态信任不成立。**

## 7. 本轮最大风险

**一句话**：LOOM-RAS 的整栋安全大厦押在「清单说的是真的」上，而签名只证明**谁**做了声明、可复现证明只证明「在声明分布上测过」——**若清单自证清白而实际撒谎（或只是诚实地在评测集上对、在你的部署上错），组合证书就是在一个不可信的物料清单上做可信推理；此时「轻量化」只是把不可信的零件更便宜、更准时地装进实时预算，而「开源生态」把信任从一个模型扩散成一堆互相担保的清单**。

**次级风险与缓解**：假设错配（输入域监视 + 越界只退 MCK）；组合非单调/接口语义漂移（单调规则 + 契约测试 + ℰ_supply 回归）；CAC 抖动/饥饿（滞后 + 前沿缓存）；声誉博弈/互刷审计（押注 + 出处多样性惩罚 + 跨组织才计数）；不可度量保真欠债（无 ε_d 界即降级实验件，禁入认证）。
