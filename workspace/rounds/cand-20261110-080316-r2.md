# 第 41 轮 · 双灵感落地 v18：随机化预算治理 × 接口感知域随机化 × 环境条件化策略（「Γ 训练资源平面」横切，四层架构 v6）

> 承接第 40 轮（v17：热预算治理 × 步数感知规划 × 学习-TO 混合轨迹，四层架构 v5）。本轮灵感词「机器人 / 域随机化」。第一反应本是「把 v16 的 IP-26 五轴增广加强一下」，但把 v17 与 2026 年这批 DR / 鲁棒 VLA 文献并排读完，冒出来的不是「更大的增广」，而是一个 v17 从未治理的账本：v17 的 Δ 资源平面只管运行时（热 / 时延 / 步数），却把「泛化」当成训练时的一次性配方——而域随机化恰恰是「用训练算力买测试分布覆盖」的技术，它有剂量、有方向、有副作用。更尖锐的是，官方接口的 chunk 开环执行、未知控制环、无深度 / 无力 / 无温度、N 台机器并发（F67）说明：最该被随机化的「域」不是背景纹理，而是**本体、控制环与部署协议本身**。v18 的主轴因此是：**把域随机化从固定配方升级为一等训练资源（Γ 平面），并让鲁棒性来自「条件化识别」而不是「平均化牺牲」**。

## 0. 联网核实（先事实后推理；检索 / 核验口径 2026-11-10，来源见产物区 §5）

- **事实 F67（官方提交仓库 README 逐字复核，github.com/unitreerobotics/unibot_submission）**：`metadata` 握手时只读一次，含 `control_space`（joint `[7]×2` / ee `[6]×2` 互斥）、`obs_delta_indices`、`image_resize`、`action_chunk_size=T_a`、`token`；**评测端把整个 chunk 按 index 0..T_a−1 顺序执行完，才再次调用 `get_action`——块内无观测、无反馈**；动作是绝对目标；观测只有 4 路 RGB（480×640）+ 本体关节 / EE / 夹爪 / lower_body + 单条静态语言，**没有深度、力 / 力矩 / 触觉、温度 / 电流 / 电压**；N 台测试机、N 个 8765 起连续端口可并发、每端口 reset / 历史隔离；**§6 记录每步时延稳定性与动作统计规律性，作为结果可信度依据**。
- **事实 F68（官方赛事站，unibot.unitree.com）**：UniBot-V1 = 32 项真实桌面任务、32000 条演示、169 小时；榜单按平均成功率 + 步骤分综合排序（当前 Coming Soon）；核心目标含「跨任务、跨物品、抗干扰的泛化操作」。
- **事实 F69（Grounding Sim-to-Real，arXiv 2603.22876，2026）**：超 1 万次真机试验发现——**空间随机化（相机位姿、桌面高度）是 Sim2Real 泛化的第一驱动**，外观（背景 / 光照）单独收益较小但可互补；**帧级随机化稳定优于 episode 级**；RL 微调显著优于纯 SFT。其五轴分解与「泛化优先看几何 / 视角而非纹理」直接反驳了把 DR 预算均匀撒在背景上的做法。
- **事实 F70（DRIS，arXiv 2605.09789，2026）**：传统 DR 每个 episode 只随机化一个实例，对真实动力学不确定性的暴露很有限；**同一 episode 内同时传播一组随机实例（如 10 个）**，让策略对多个可能后果负责，理论分析与反应性接球实验均显示更强鲁棒性与零样本迁移。
- **事实 F71（DexSim2Real，arXiv 2605.05241，2026）**：DR 的两大痛点是**范围靠手工 / 昂贵试错**、**大范围均匀随机化会训练到大量不真实配置而降低策略性能**；其 FM-DR 用 VLM 作视觉真实性批评家、CMA-ES 闭环调参，六项任务真机平均 78.2%。
- **事实 F72（DR-SPCRL，arXiv 2511.05694；SPiDR，arXiv 2509.18648）**：前者把 DRO 的**鲁棒性预算 ε 当作连续课程**自适应调度，扰动下平均回报 +24.1%；后者用随机化动力学模型的预测分歧量化 Sim2Real 不确定性，做**悲观 DR**，在 Unitree Go1 等真机上满足安全约束而普通 DR 会显著违约。二者共同说明：**随机化的「剂量」本身应是可学习 / 可调度的对象**。
- **事实 F73（RobustVLA，ICLR 2026 / arXiv 2510.00037；View Collapse，arXiv 2609.33707）**：在 17 种跨动作 / 指令 / 环境 / 观测扰动中，**动作模态最脆弱**；对输出做最坏情况动作噪声的鲁棒优化（并配多臂老虎机选最有害噪声）在 π0 上绝对提升 12.6%、真机 FR5 在少样本下提升 65.6%；但对抗训练可能造成**视角坍缩**——鲁棒性来自「少看某个视角」而非更好感知，必须区分 robust perception 与 robust fusion。
- **事实 F74（VLA-Gauge，arXiv 2610.16567，2026）**：12 个 VLA 在统一协议下**零样本均分仅 22.3%**，三类组合扰动下 R-Score 仅 9.3；熟悉任务上的高成功率不能保证零样本泛化；诊断驱动的定向增广 / 微调可把 π0.5 的零样本与组合鲁棒性分别提升 72.4 / 31.8 分。
- **事实 F75（DexScale，ICML 2025；Flow-based DR，ICML 2025；ReMix，CoRL 2024）**：DexScale 自动化 DR 与适配、跨多本体零样本；Flow-based DR 用归一化流**学习随机化采样分布**而非手工指定，并用于 OOD 检测；ReMix 用 DRO 学数据域混合权重，最坏情况比均匀权重高 40% 以上。说明「随机化分布」可以作为被优化的对象。
- **事实 F76（SEVO，arXiv 2605.11114；FPSA，arXiv 2609.18293；HyperSim，arXiv 2605.26638）**：SEVO 发现**系统性地变化光照 / 背景 / 干扰物的数据采集协议是泛化的第一因素**（训练环境 95% / 新环境 85%，不这样做会从 30–35% 崩塌）；FPSA 用**保功能形状增广**（保持任务关键接口、位姿对齐、间隙关系）避免几何增广破坏接触可行性；HyperSim 用对抗轨迹生成 + 仿真-真实共训，在物理扰动下完成率 +35%。这提示 DR 必须**保任务语义 / 保接触可行性**，否则是「随机化出不可完成的任务」。
- **事实 F77（榜单 / 数据缺口）**：HF 挑战数据集仍 401 门控（A39）；Leaderboard 仍 Coming Soon，「榜首 <30%」不可公开核实（A40，按假说处理）；官方是否允许仿真预训练、N 台机器的硬件 / 标定差异、真实标定集规模均未公布。
- **经典（记忆级引用，未本轮复核，低置信登记）**：Tobin et al., Domain Randomization, IROS 2017（arXiv 1703.06907）；Peng et al., Sim-to-Real with Dynamics Randomization, ICRA 2018（arXiv 1710.06537）；OpenAI et al., Solving Rubik's Cube with ADR（arXiv 1910.07113）；Kumar et al., RMA（arXiv 2107.04034）；Rakelly et al., PEARL（arXiv 1903.12436）。

## 1. 研究者直觉（先直觉与动机，后形式化）

**直觉 1（「机器人」提醒我们：要随机化的是身体与接口，不是像素）。** 过去两年 VLA 的「鲁棒性」大多被做成视觉增广：换背景、换光照、加噪声。但 F73 把 17 种扰动排了个序，发现**动作模态最脆弱**；F69 在 1 万次真机上发现**空间几何扰动（相机位姿、桌面高度）远比外观纹理重要**；F76 进一步说明，真正决定成败的是采数据时有没有系统性地改变光照 / 背景 / 干扰物，而不是训练时多叠几层滤镜。于是「机器人」这个词在本轮的正确读法是：**domain = 本体（质量 / 惯量 / 摩擦 / 夹爪柔顺 / 相机外参 / 标定）+ 控制环（未知增益 / 延迟 / 抖动）+ 部署协议（chunk / 丢帧 / 分辨率 / 控制空间）+ 感知（视角 / 遮挡 / 压缩）**。这四类里，前三类在本赛道的官方接口下**完全没被随机化过**，却恰好是 N 台测试机之间最可能不同的部分。结论：把 IP-26 的「五轴视觉增广」降级为基线，把 DR 预算重新分配到「本体 + 接口」这两条高杠杆轴上。

**直觉 2（「域随机化」不是免费午餐，而是有剂量曲线的预算）。** 直觉上「随机化越多越鲁棒」，但 F71 明确说大范围均匀 DR 会训练到大量不真实配置、反而降性能；F72 说鲁棒性预算 ε 需要课程化调度；F70 说每个 episode 只采一个实例的暴露远远不够。把这三条并起来，我得到的是一个**三难（tri-lemma）**：增大随机化半径 ρ 会提高对测试分布的覆盖，但会同时付出 (a) **专业化损失**——策略必须为所有 θ 平均，牺牲名义精度；(b) **步数膨胀**——更保守的鲁棒策略走更长的路，直接吃步骤分；(c) **动作方差 / 精度损失**——与官方「动作统计规律性」可信度条款和 v17 的 TO 精度目标正面冲突。因此 ρ 不是一个「越大越好」的超参，而是一个**内点最优**的决策变量；DR 的工程本质是「在有限训练算力下买覆盖」，应该像 v17 管热 / 时延 / 步数一样，被记进一本**Γ 训练资源账本**。

**直觉 3（条件化 > 平均化：把「域」变成可观测的隐变量）。** 无条件 DR 的代价来自「一个策略覆盖所有 θ」。但机器人不是瞎的：它可以通过**本体响应**（前几步的实际关节 / EE 轨迹）感知自己的质量、摩擦、延迟与夹爪柔顺；服务器也能测到**往返时延**。于是正确的形态不是「训练一个平均策略」，而是训练一个**环境条件化策略** `π(a | o, ẑ)`，其中 `ẑ` 是在线系统辨识出的环境 / 本体隐变量。信息价值非负：**条件化在期望上不会比平均化更差**；若 `ẑ` 足够准，专业化损失可以趋近于零，DR 就只负责「扩大训练时见过的 θ 集合」，而不再强迫策略在测试时「装傻平均」。这同时救了 v17 的 IP-50：`θ̂` 直接给出每台机器 / 每个端口的跟踪模型，**不需要 URDF、不需要离线全解 TO**。而 F67 的 chunk 开环执行给出一个残酷但重要的约束：**系统辨识只能在 chunk 边界更新，不能步内更新**——所以 `T_a` 不只是 v17 的热 / 反应性旋钮，它还是**系统辨识的带宽旋钮**。`T_a` 越大，单位时间可用的反馈事件越少，条件化的价值越低，所需的**无条件鲁棒半径 ρ 就越大**。这是 v17 与 v18 之间最漂亮的一条耦合。

**直觉 4（接口就是最便宜的「域」，而且必须同时管住动作方差）。** F67 把部署协议写死到可以逐字建模：metadata 一次握手、chunk 开环、观测经 resize / JPEG、可能有丢帧与延迟、控制空间二选一、N 端口并发。我们完全可以写一个**协议模拟器（Sim_prot）**，把这些「域」注入到任何策略 / 任何真实演示回放里，**不需要物理引擎、不需要 URDF**——这是零成本的 DR，而且正好命中最不可控的评测环境。更妙的是，F73 的 RobustVLA 已经把「动作空间最坏情况噪声」的训练做出来了，而官方又记录动作统计规律性；所以 I-DR 必须同时包含**输入域随机化 + 动作空间鲁棒优化 + 动作正则项**三件套，否则我们会用「更鲁棒」换来「更抖」，在可信度条款上扣分。F73 的 view collapse 还提醒：多视角随机化不能让策略退化成「只用腕部相机」；要加 view dropout / view swap 一致性约束，区分「感知鲁棒」与「融合退化」。

**直觉 5（修剪即深化：v17 里恰好有三件「没有身份 / 没有剂量 / 没有遥测」的东西）。** 本轮逐条对照 F67–F76，v17 的 IP-26 是**无剂量配方**（固定五轴增广）；IP-50 是**无身份的动力学**（假设一个 URDF + 一个跟踪模型覆盖所有机器）；IP-48 是**无遥测的热账本**（只有代理积分，没有温度）；IP-42 是**无数据的跨本体**（没有多本体演示）。因此本轮把 **IP-26 降为基线、IP-42 并入 IP-53、IP-50 收窄为「条件化跟踪模型 + 块级参考整形」、IP-48 四级热机降为二级时延守护、IP-44 渐进蒸馏降 P1**。省下的复杂度预算全部投给 Γ 平面——因为 DR 是本轮唯一「训练时可控、测试时可证伪」的东西：随机化轴、半径、覆盖率都能在仿真 / 回放里测，而电机温度和元学习不能。

## 2. 灵感词 → 落地线（新增 + 重构 + 修剪登记）

- 「**域随机化**」→ **IP-51 RANDOMIZATION-BUDGET（P0 新增）**：Γ 训练资源平面（覆盖 / 专业化损失 / 步数膨胀 / 精度 / 动作方差五账本）+ 三难目标 + **覆盖校准半径**（用真实标定集选 ρ，而不是手工范围）+ **轴弹性 / 预算分配**（knapsack / 贝叶斯优化）+ 鲁棒性预算课程（DR-SPCRL 式 ε 调度）+ 保功能随机化（FPSA / HyperSim：不随机化坏任务接口）。
- 「**机器人**」→ **IP-53 CONTEXT-DR（P0 新增，吸收 IP-42）**：**环境条件化策略** `π(a|o,ẑ)` + **块级在线系统辨识** `ẑ_t=E_ψ(o_{0:T_a},a_{0:T_a−1})`；辨识对象 = 本体动力学（质量 / 摩擦 / 夹爪柔顺）+ 控制环（延迟 / 跟踪增益）+ 感知标定（相机外参 / 尺度）；`ẑ` 同时喂 v17 的 IP-50 作**每机跟踪模型**，并喂 IP-49 作场景画像；用 DR 训练一个「隐变量先验」，测试时只做**推理**而不是再平均。**关键耦合**：`T_a` 越大，辨识带宽越低，所需无条件 ρ 越大（P54）。
- 「**接口 / 泛化**」→ **IP-52 INTERFACE-DR（P0 新增）**：协议模拟器 Sim_prot + 接口域随机化（延迟 / 抖动 / 丢帧 / resize / JPEG / 控制空间 / 跟踪控制器 / 相机外参 / 标定偏移）+ **动作空间最坏情况鲁棒优化**（RobustVLA 式 `max_δ L(a+δ)`）+ **动作正则（jerk / 方差）** + **多视角一致性 / view-swap**（防 view collapse）；与 v17 的 IP-43 prosody、IP-48 时延守护联动。
- 「**证伪 / 守门**」→ **IP-54 DR-FALSIFY（P1 新增）**：DR 不只训练，还做**测试预言机**——用 DRIS 式多实例同 episode、对抗 / 课程随机化搜索高风险轴，估计最坏情况得分与方差，作为提交门（E76）；失败样本回灌 IP-51 的轴弹性与 IP-49 的失败记忆。
- **升级**：IP-26（固定五轴 → Γ 平面下的**保功能基线增广**，P1）、IP-36（语义图增**可随机化属性 / 接触可行性标签**）、IP-39（规划器吃 `ẑ` 与 Γ 预算）、IP-43（prosody 同时是动作正则 / 平滑先验）、IP-49（场景画像 σ 由 `ẑ` 在线更新）、IP-50（**P1 收窄**：条件化跟踪模型 + 块级参考整形，不再要求 URDF 离线全解）、IP-48（四级热机 → 二级时延守护 + DR 训练方差监控）、IP-44（P1）、IP-45（最小并发 + 每端口 `ẑ` 隔离）。
- **修剪登记（规则 51）**：**IP-26 固定五轴增广 → P1 基线**（无剂量、无覆盖校准；被 IP-51/52 吸收）；**IP-42 CROSS-EMBODIMENT-MOTION → 并入 IP-53**（没有多本体数据，跨本体先验无法验证）；**IP-50 离线全解学习-TO → P1**（URDF / 跟踪模型未核实，块内无反馈；改为 `θ̂` 驱动 + 块级参考整形）；**IP-48 四级热状态机 → P1 二级时延守护**（无温度遥测，热时间尺度长于 episode）；**IP-44 三阶段渐进蒸馏 → P1**（训练成本高、边际得分低，P0 用 LoRA + 数据配比）。**本轮不为新增而新增：Γ 平面的全部复杂度预算来自这五项修剪。**

## 3. 形式化直觉（严格版见产物区 §3）

**定义 37（域参数与随机化半径）**：`θ=(θ_phys,θ_emb,θ_perc,θ_prot)∈Θ`，分别为物理（质量 / 摩擦 / 惯量 / 接触刚度 / 阻尼）、本体（连杆 / 限位 / 夹爪几何与柔顺 / 相机外参 / 标定）、感知（光照 / 纹理 / 遮挡 / 噪声 / JPEG）、协议（`T_a` / 延迟 / 抖动 / 丢帧 / resize / 控制空间 / 跟踪增益）。随机化分布 `P_ρ=⊗_i P_{i,ρ_i}`，半径向量 `ρ`；模糊集 `B_ρ={P: W_1(P,P_0)≤ρ}`（或逐轴区间），`P_0` 为名义域。

**定义 38（Γ 训练资源平面）**：`Γ=(ρ,w,B_data,B_compute,η_ID,T_a)`，可行域 `Σ_i c_iρ_i≤B`；五本账：覆盖 `C(ρ)`、专业化损失 `A(ρ)`、步数膨胀 `ΔN(ρ)`、精度损失 `Δσ(ρ)`、动作方差 `Var(a|ρ)`。Γ 与 v17 的 Δ 正交：Δ 管运行时够不够快 / 省，Γ 管训练时见过多少世界。

**定义 39（鲁棒-精度-步数三难）**：`Score(ρ)=S_rob(ρ;P_ρ)·g(N(ρ))−λ_σ σ(ρ)−λ_v Var(a|ρ)`，其中 `S_rob` 取 `B_ρ` 上的最坏情况或 `CVaR_β`；`g` 为 v17 的步骤分函数。于是 `∂Score/∂ρ_i = 覆盖增益 − 专业化损失 − 步数 / 精度 / 正则成本`；在温和条件下 `Score(ρ)` 严格凹且有唯一内点最优 `ρ*`（命题 P51）。

**定义 40（覆盖校准半径）**：给定真实标定集 `D_cal`（少量真机观测 / 轨迹 / 本体响应），取 `ρ*_α = inf{ρ: P_{θ~P_ρ}(d(θ,D_cal)≤q_{1−α})≥1−α}`，即**随机化分布以 1−α 概率覆盖真实域**。这把「随机化范围多大」从手工超参变成**带覆盖保证的统计量**；跨 N 台机器时按机器 / 端口分桶标定（ACI 跟踪硬件偏移）。

**定义 41（轴弹性与预算分配）**：`e_i(ρ)=∂Score/∂ρ_i`（小扰动有限差分）；单位成本 `c_i`（算力 / 数据 / 标注）。解 `max Σe_iρ_i s.t. Σc_iρ_i≤B, 0≤ρ_i≤ρ_i^max`；凹收益下贪心按 `e_i/c_i` 排序近优（子模时 `1−1/e`），工程上用连续臂 Bandit / 贝叶斯优化。

**定义 42（接口域与协议模拟器）**：`θ_prot=(T_a,τ_lat,jitter,p_drop,resize,control_space,K_track,cam_extrinsic,JPEG_q)`；`Sim_prot` 包裹任意策略或真实演示回放，注入这些域。**chunk 开环 ⇒ 辨识只在块边界**；定义 `η_ID(T_a)` 为单块辨识效率，`T_a↑ ⇒ η_ID↓`（每单位时间反馈事件变少，且块内漂移不可观测）。

**定义 43（条件化随机化与信息价值）**：`π(a|o_{0:t},ẑ_t)`，`ẑ_t=E_ψ(o_{0:t},a_{0:t−1})`。平均化税 `A(ρ)=E_{θ~P_ρ}[S(π_uncond,θ)]−E[S(π_cond,ẑ,θ)]`。由信息价值（条件期望 / Jensen），`A(ρ)≥0`；若 `ẑ` 是 θ 的充分统计且精确，`A=0`；若辨识误差为 `ε_ID`，则残余损失 `≤ε_ID·L`（命题 P52）。**关键推论 P54**：`η_ID(T_a)` 随 `T_a` 下降 ⇒ 条件化边际价值下降 ⇒ 最优无条件半径 `ρ*(T_a)` 单调不减——**大 chunk 必须配更保守的无条件鲁棒性**。

**定义 44（动作空间鲁棒与正则性）**：`min_π max_{‖δ‖≤ε_a} L_flow(π;a+δ) + λ_J·J(a) + λ_V·Var(a) + λ_C·Consistency(a; view-swap/dropout)`。前项来自 RobustVLA（动作最脆弱），后三项分别守住官方动作规律性、v17 的精度 / prosody、以及 view collapse（F73）。**随机化不能拿方差换鲁棒**。

**定义 45（DR 证伪门）**：`ρ_adv=argmax_{ρ∈B} Risk(π;P_ρ)`；提交门 `s(π)=1 ⇔ Score(ρ_adv)≥τ_gate ∧ Var(a|ρ_adv)≤τ_var`。用 DRIS 多实例同 episode 暴露多后果，用对抗 / 课程搜索找高风险轴；这不是训练技巧，而是**可证伪的验收标准**。

**命题 P51（内点最优半径）**：设 `C(ρ)` 凹增饱和、`N(ρ)=N_0+c_2ρ`、`σ(ρ)=σ_0+c_3ρ`、`S_rob(ρ)=S_0C(ρ)−bρ`，则 `Score(ρ)=S_rob(ρ)g(N(ρ))−λσ(ρ)` 在 `C'(0)` 足够大、`C'(∞)=0` 时严格凹且有唯一内点最大（证明见产物区 §3.9）。**命题 P52（条件化支配平均化）**：对任意适当评分规则，`E[S(π_cond,ẑ)]≥E[S(π_uncond)]`；残余差距由 `ε_ID` 控制。**命题 P53（轴分配近优）**：凹 / 子模收益下按 `e_i/c_i` 贪心近优。**命题 P54（T_a-ρ 耦合）**：若 `η_ID(T_a)` 递减且条件化价值随 `η_ID` 递增，则由 Topkis 单调比较静态，`ρ*(T_a)` 单调不减。

## 4. 关键决断

1. **泛化也是资源**：把 DR 升格为 Γ 训练资源平面，与 v17 的 Δ 运行时平面正交；随机化半径 / 轴 / 数据 / 算力统一记账，不再用「固定五轴增广」当配方。
2. **剂量由覆盖定，方向由弹性定**：ρ 用真实标定集的 conformal 覆盖率选，轴用 `e_i/c_i` 分配；拒绝「均匀大范围随机化」（F71）。
3. **条件化而非平均化**：鲁棒性来自在线辨识 `ẑ` + 专业化策略，而不是一个对所有 θ 都平庸的策略；`T_a` 同时是辨识带宽旋钮，大 chunk 配大 ρ。
4. **接口是最便宜的域**：用 Sim_prot 把延迟 / 丢帧 / resize / 控制空间 / 跟踪控制器随机化，零物理引擎成本；动作空间鲁棒 + 正则必须同时上，守住可信度条款。
5. **DR 也是证伪器**：用多实例 + 对抗 / 课程随机化估计最坏情况，作为提交门；训练分布与验收分布必须是同一套 Γ 账本。
6. **修剪换预算**：IP-26、IP-42、IP-50 离线全解、IP-48 四级热机、IP-44 渐进蒸馏降级 / 合并——省下的复杂度全投 Γ。

## 5. 本轮最大风险（一句话）

**若真实标定集太小导致 conformal 覆盖半径严重低估测试分布、若 chunk 开环使 `ẑ` 在块内不可辨识从而条件化退化为平均化、若动作鲁棒训练反而放大动作方差并触发官方可信度条款——「覆盖校准 → 条件化识别 → 动作鲁棒」这条链就会变成一个用更多训练算力换更少可验证收益的负循环；必须以 E73–E79 七重守门，任一失败即回退到「仅接口随机化 + 正则」的最小 Γ 方案，再失败则回退 v17 加保守视觉增广。**

## 0. 结论

- **Γ 训练资源平面（本轮总纲）**：`Γ=(ρ,w,B_data,B_compute,η_ID,T_a)`，五本账 = 覆盖 `C(ρ)` / 专业化损失 `A(ρ)` / 步数膨胀 `ΔN(ρ)` / 精度损失 `Δσ(ρ)` / 动作方差 `Var(a|ρ)`。它与 v17 的 Δ 运行时平面正交：Δ 管「够不够快 / 省」，Γ 管「训练时见过多少世界」；两者在 `T_a`、动作正则（IP-43）与 `ẑ`（IP-50/IP-49）处交汇。
- **IP-51 RANDOMIZATION-BUDGET（P0 新增）**：把随机化半径从手工超参变成**覆盖校准的统计量**（用真实标定集 `D_cal` 的 conformal 覆盖率选 ρ），把轴选择变成**弹性 / 成本 knapsack**（`e_i/c_i` 贪心 + 贝叶斯优化），并显式优化**鲁棒-精度-步数三难**；随机化必须**保功能**（FPSA：不破坏任务关键接口 / 接触可行性）。
- **IP-52 INTERFACE-DR（P0 新增）**：用 `Sim_prot` 把**部署协议本身**随机化（延迟 / 抖动 / 丢帧 / resize / JPEG / 控制空间 / 跟踪控制器 / 相机外参 / 标定偏移），零物理引擎、可直接回放真实演示；同时做**动作空间最坏情况鲁棒优化**（RobustVLA）+ **jerk / 方差正则** + **view-swap / dropout 一致性**（防 view collapse），守住官方可信度条款。
- **IP-53 CONTEXT-DR（P0 新增，吸收 IP-42，升级 IP-50）**：训练 `π(a|o,ẑ)`，`ẑ` 由**块级在线系统辨识**得到（本体动力学 + 控制环 + 标定）；条件化的信息价值非负，可把「平均化税」压到 `ε_ID·L`；`ẑ` 直接喂 IP-50 作每机跟踪模型，**不再依赖 URDF**。**关键新耦合**：`T_a` 越大，单位时间反馈事件越少，`η_ID(T_a)` 越低，最优无条件半径 `ρ*(T_a)` 越大（P54）。
- **IP-54 DR-FALSIFY（P1 新增）**：DR 不只训练，还做**测试预言机**——DRIS 多实例同 episode + 对抗 / 课程轴搜索 + 失败回灌，输出 `ρ_adv` 与提交门（E76）。

### 3.2 IP-51 RANDOMIZATION-BUDGET（随机化预算，完整设计）

**IP 卡片（六字段）**：
- **动机**：F69–F72/F75 证明 DR 的剂量 / 轴 / 采样分布决定成败；F71 明确手工范围与均匀大范围会降性能；F70 证明每 episode 单实例暴露不足；F76 证明随机化必须保任务功能。v17 的 IP-26 是固定配方，无法回答「随机化多少、随机化哪根轴、值不值」。
- **与现有方案差异**：ADR / Flow-DR / DR-SPCRL 学习采样分布或调度鲁棒预算，但不优化**成功率 + 步骤分 + 精度 + 动作方差**的统一得分，不做**真实标定集上的覆盖率校准**，也不把**部署协议**当作域。我们把随机化变成**带覆盖保证的预算分配问题**，并用保功能约束排除不可完成域。
- **技术可行性**：轴数 15–25，单轴 / 交互扫描可在仿真或真实演示回放上完成；conformal 覆盖率只需几百条真实标定轨迹；knapsack / 贝叶斯优化成熟；ρ 的冻结配置可按场景预选 2–3 档。
- **所需资源**：数据=`D_cal`（100–500 条真实 / 开源轨迹 + 本体响应）；算力=DR 扫描（可离线，与主训练并行）；接口=零改造。
- **落地步骤**：① 定义 θ 轴与合法范围 `Θ_valid`；② 建 `D_cal` 与 conformal 覆盖率统计；③ one-at-a-time 敏感性 + 交互筛选；④ 拟合剂量-响应曲线；⑤ `e_i/c_i` 分配 + BO 精调；⑥ 鲁棒性预算课程；⑦ E73/E78 验证；⑧ 按场景冻结 Γ 配置。
- **风险**：标定集太小 / 分布偏移 → 覆盖率低估（ACI + 分桶）；轴交互使弹性估计失真（分组扫描 + 二阶筛选）；保功能约束过严导致半径退化（放宽到「任务成功率不变」）。

**符号表**：

| 符号 | 含义 | 取值 / 来源 |
|---|---|---|
| θ=(θ_phys,θ_emb,θ_perc,θ_prot) | 域参数 | 物理 / 本体 / 感知 / 协议 |
| ρ=(ρ_i) | 逐轴随机化半径 | 连续，`0≤ρ_i≤ρ_i^max` |
| P_ρ=⊗_i P_{i,ρ_i} | 随机化分布 | 均匀 / 截断高斯 / 学习流（F75） |
| B_ρ | 模糊集 | `W_1(P,P_0)≤ρ` 或逐轴区间 |
| C(ρ) | 真实域覆盖 | conformal，`≥1−α` |
| A(ρ) | 专业化 / 平均化税 | 条件化前后名义得分差 |
| N(ρ), σ(ρ), Var(a|ρ) | 步数 / 精度 / 动作方差 | v17 定义 27 + 官方可信度 |
| c_i, e_i | 轴成本 / 弹性 | `e_i=∂Score/∂ρ_i` |
| B | 总预算 | 数据 / 算力 |

**算法（覆盖校准 + 轴分配）**：
```
输入：D_cal, 轴集合 Axes, 预算 B, 置信 α, 合法域 Θ_valid
1. 逐轴定义 P_{i,ρ_i} 与合法范围；用拒绝采样保证 supp(P_ρ) ⊆ Θ_valid
2. 覆盖校准：
   for ρ in coarse grid:
       cov(ρ) = conformal_coverage(D_cal, P_ρ, α)
   ρ_min = inf{ρ : cov(ρ) ≥ 1−α}                 # 最小覆盖半径
3. 轴弹性（在 ρ_min 附近做小扰动 / Sobol 筛选）：
   e_i = (Score(P_{ρ_min+ε e_i}) − Score(P_{ρ_min})) / ε
4. 预算分配：
   max Σ e_i·Δρ_i  s.t. Σ c_i·Δρ_i ≤ B − c(ρ_min), 0≤ρ_i≤ρ_i^max
   → 凹收益：贪心 e_i/c_i（子模 1−1/e）；否则 BO / 连续臂 Bandit
5. 鲁棒预算课程（DR-SPCRL）：ε_t = ε_0 + (ε_1−ε_0)·min(1, t/T_warm)
6. 返回 Γ 配置；(E73/E78) 验证内点最优与轴排序
```

**保功能随机化（function-preserving）**：对几何 / 物体 / 接触轴，定义合法性谓词 `Valid(θ)`：任务前置条件、关键接口几何、位姿对齐、间隙 / 接触关系在容差内（F76 FPSA）。采样时拒绝 `¬Valid(θ)`，并在 IP-36 语义图中记录「可随机化属性」与「接触可行性标签」；这样 DR 不会把任务随机化成不可完成的任务。

**正确性论证**：P51（内点最优，见 §3.9）；P53（轴分配近优）；P55（保功能不改变任务可解性）——若 `Valid(θ)` 保持任务前后置条件与接触可行性，则 `θ` 的随机化不引入「无解任务」，只改变解的风格 / 难度；因此 `C(ρ)` 的增益不会被「不可完成样本」污染（对照 F76 的 shape augmentation 失败模式）。

### 3.3 IP-52 INTERFACE-DR（接口感知域随机化，完整设计）

**IP 卡片（六字段）**：
- **动机**：F67 的 chunk 开环、延迟 / 丢帧 / resize / 控制空间 / N 端口是评测环境中最不可控、却最容易被建模的部分；F73 证明动作模态最脆弱、对抗训练可能 view collapse；官方记录动作统计规律性——随机化若放大动作方差会扣可信度分。
- **与现有方案差异**：传统 sim-to-real DR 随机化物理 / 视觉；我们**随机化部署协议**，可在**无物理引擎、无 URDF** 的条件下直接回放真实演示；并把**动作空间鲁棒 + 动作正则 + 多视角一致性**作为同一目标，避免「鲁棒但抖」。
- **技术可行性**：延迟缓冲 / 丢帧掩码 / resize / JPEG / chunk 截断 / 控制空间变换 / 跟踪控制器变体（P / PI / 速度限幅）/ 相机外参扰动都可在数据管线实现；动作鲁棒项可复用 flow-matching 训练管线（F73）。
- **所需资源**：基线演示（官方 / 自采 / 开源）、GPU 增广、无额外传感器；`Sim_prot` <1ms/step。
- **落地步骤**：① 实现 Sim_prot；② 回放基线演示并注入协议域；③ 加动作空间最坏情况项 + jerk / 方差正则 + view-swap/dropout；④ E74/E77 消融；⑤ 按 `T_a` 档位冻结协议随机化强度；⑥ 与 IP-48 时延守护 / IP-43 prosody 联动。
- **风险**：协议随机化过强伤名义性能（按 `T_a` 分档 + 覆盖率校准）；动作鲁棒训练不稳定（线搜索 / 小 ε_a 起步）；view collapse（一致性约束 + 多视角均衡采样）。

**符号表**：`θ_prot=(T_a,τ_lat,jitter,p_drop,resize,control_space,K_track,cam_ext,JPEG_q)`；`Sim_prot(π,D;θ_prot)` 为协议回放算子；`δ` 为动作空间扰动；`J(a)` 为 jerk；`Var(a)` 为动作方差；`Consistency` 为 view-swap / dropout 一致性。

**算法（协议回放 + 动作鲁棒）**：
```
def sim_prot_episode(policy, demo, theta_prot, z_hat):
    obs, acts = demo
    hist_o, hist_a = [], []
    for t in range(len(acts)):
        # 1) 观测协议：延迟 + 丢帧 + resize + JPEG + 外参扰动
        o_t = corrupt(obs[max(0,t-int(theta_prot.tau_lat))],
                      drop=theta_prot.p_drop,
                      resize=theta_prot.resize,
                      jpeg=theta_prot.JPEG_q,
                      cam_ext=theta_prot.cam_ext)
        hist_o.append(o_t)
        # 2) 策略（块边界才更新 z_hat）
        if t % theta_prot.T_a == 0:
            z_hat = encode_env(hist_o[-K:], hist_a[-K:], theta_prot)
        a_t = policy(o_t, z_hat)
        # 3) 跟踪控制器（未知闭环）
        a_exec = track(a_t, theta_prot.K_track)
        hist_a.append(a_exec)
    return hist_o, hist_a

# 训练目标（flow-matching 基座）
L = L_flow(a, a_gt)
  + max_{||δ||≤ε_a} L_flow(a, a_gt + δ)          # RobustVLA 式动作鲁棒
  + λ_J * mean(||a_{t+1}-2a_t+a_{t-1}||^2)       # 官方动作规律性
  + λ_V * Var(a)                                  # 方差约束
  + λ_C * Consistency(a; view-swap / dropout)     # 防 view collapse
```

**正确性论证**：P56（协议不变性）——若策略在 `θ_prot` 的支撑集上训练且 `Sim_prot` 覆盖评测协议的真实范围（由 E74/E77 标定），则部署时的协议偏移落在训练分布内，成功率不因延迟 / 丢帧 / resize 显著下降；P57（动作正则不损任务）——jerk / 方差正则只约束实现方式，不改变任务目标，且与 v17 的 prosody 同向；P58（view-swap 防坍缩）——一致性约束要求策略在视角替换下输出同一任务动作，排除「少看一个视角」的伪鲁棒（F73）。

### 3.4 IP-53 CONTEXT-DR（环境条件化策略，完整设计）

**IP 卡片（六字段）**：
- **动机**：无条件 DR 要一个策略覆盖所有 θ，付平均化税；F67 的 chunk 开环意味着只能在块边界适应；N 台机器 / 多端口需要每端口独立状态；v17 的 IP-50 需要每机跟踪模型但没有 URDF；F70/F75 证明多实例 / 多本体暴露有价值。
- **与现有方案差异**：RMA / PEARL 式在线系统辨识多见于腿式 / RL；我们把它落到**块级、chunk 开环、无深度 / 无力**的桌面 VLA 接口，并把 `ẑ` 同时用于**策略条件化 + TO 跟踪模型 + 规划场景画像**；显式给出 `T_a` 与辨识带宽的耦合（P54），这是现有 DR 文献没有的。
- **技术可行性**：`ẑ` 可由前 K 步本体响应 + EE 轨迹 + 实测往返时延估计；编码器 <1ms；训练用带 θ 标签的仿真 / 多实例数据；真实侧用**探针 chunk**（信息量大的安全动作）做一次快速辨识。
- **所需资源**：带 θ 标签的多物理 / 多本体数据（仿真优先；无仿真则用真实回放 + 参数扰动增强）；每端口独立的 `ẑ` 容器；A43 的块级可辨识性实验。
- **落地步骤**：① 建 θ 标签数据；② 训练 `E_ψ`（对比 / 变分 / 监督）；③ 条件化策略与 IP-50；④ 设计探针 chunk（信息增益 vs 步数 / 安全）；⑤ E75 可辨识性；⑥ 每端口隔离；⑦ 失败回灌 IP-49。
- **风险**：θ 不可辨识（质量 / 摩擦混淆、延迟 / 增益混淆）→ 多假设 `ẑ` 分布 / 集合；块太长 → `T_a` 分档 + 更大无条件 ρ；编码器 OOD → 置信度门 + 回退无条件策略；探针费步 → 只在场景不确定时触发。

**符号表**：θ（真实域）；`ẑ=E_ψ(o_{0:K},a_{0:K−1})`（估计）；`η_ID(T_a)`（块级辨识效率）；`ε_ID`（辨识误差）；`π(a|o,ẑ)`（条件化策略）；`f_track(·;ẑ)`（每机跟踪模型）；`I(θ;o,a)`（互信息）；`a_probe`（探针动作）。

**算法（块级辨识 + 条件化）**：
```
# 训练：θ 标签来自仿真 / 多实例采样
def train_context_dr(policy, E_psi, domains):
    for (o, a, theta) in domains:
        z_hat = E_psi(o[:K], a[:K-1])
        L = imitation_or_flow(policy(o, z_hat), a)
          + lambda_z * ||z_hat - encode(theta)||^2        # 或对比损失
          + regularity_terms(a)
    return policy, E_psi

# 测试：每端口独立；块边界更新；首块可作探针
def infer_env(port_state, obs_hist, act_hist, latency):
    z_hat, conf = E_psi(obs_hist[-K:], act_hist[-K:], latency)
    if conf < tau_conf:
        return prior_z, False          # 回退无条件 / 多假设
    return z_hat, True

def probe_chunk(port_state, plan, budget):
    # 在安全约束下最大化 I(theta; o_{1:T_a}) - lambda_step * T_a
    return to_probe(plan, info_bonus=beta, safety=IP_33)
```

**正确性论证**：P52（条件化支配平均化，见 §3.9）；P54（`T_a`-ρ 耦合）；P59（每端口隔离）——`ẑ` 与历史按端口容器隔离，满足 F67 的 reset / 状态隔离要求；P60（探针不损任务）——探针只在 `IP-33` 安全集内、且信息增益超过步数成本时触发（定义 35 的 `E[Δ]>0` 条件）。

### 3.5 IP-54 DR-FALSIFY（DR 作为证伪器，P1）

**动机**：训练分布与验收分布必须一致；DR 若只用于训练，容易「在训练分布里自嗨」。F70 的多实例、F72 的悲观 DR、F74 的 VLA-Gauge 都说明：**最坏情况搜索**比平均随机化更能暴露失败。

**设计**：
- **多实例同 episode（DRIS）**：每个 episode 采样 `k` 个 θ 实例同时传播（或按 batch 共享），估计得分分布而非单点。
- **对抗 / 课程轴搜索**：用 CMA-ES / 贝叶斯优化 / 多臂老虎机在合法域内最大化 `Risk(π;P_ρ)`，得到 `ρ_adv`；失败样本回灌 IP-51 的轴弹性与 IP-49 的失败记忆。
- **提交门**：`s(π)=1 ⇔ Score(ρ_adv)≥τ_gate ∧ Var(a|ρ_adv)≤τ_var`；不通过则回到 IP-51 重新分配预算，而不是盲目加数据。
- **与主训练线（IP-51/52/53）的诚实边界**：它是 P1（验证基础设施），不改变主训练；但 E76 的失败率 / 与留出真机的相关性决定它能否升级为 P0。

### 3.7 训练 / 服务伪代码（v18 增量版）

```python
# ===== 离线：Γ 预算校准（IP-51）=====
def build_gamma(D_cal, axes, B, alpha):
    rho_min = calibrate_radius(D_cal, axes, alpha)          # conformal 覆盖
    e = axis_elasticity(score_fn, axes, rho_min)            # 小扰动 / Sobol
    rho = allocate_budget(e, costs(axes), B, rho_min)       # knapsack / BO
    return Gamma(rho=rho, axes=axes, B=B, alpha=alpha)

# ===== 离线：条件化策略 + 编码器（IP-53）=====
def train_context_dr(base_policy, E_psi, domains, gamma):
    for epoch in range(E):
        eps = curriculum_epsilon(epoch, gamma)              # DR-SPCRL 式
        for batch in domains:
            theta = sample_domains(gamma.rho, valid=Valid)  # 保功能
            theta_prot = sample_protocol(gamma, T_a=batch.T_a)
            z_hat = E_psi(batch.obs[:K], batch.act[:K-1])
            a_hat, acts = sim_prot_episode(base_policy, batch, theta_prot, z_hat)
            loss = robust_flow_loss(a_hat, batch.act, eps_a=eps)
                 + lambda_J * jerk(acts) + lambda_V * var(acts)
                 + lambda_C * view_consistency(base_policy, batch)
                 + lambda_z * z_loss(z_hat, batch.theta)
            update(base_policy, E_psi, loss)
    return base_policy, E_psi

# ===== 离线：证伪门（IP-54）=====
def falsify(policy, gamma):
    rho_adv = adversarial_search(policy, gamma.rho)         # CMA-ES / BO / bandit
    return score(policy, rho_adv), var_action(policy, rho_adv)

# ===== 运行期：每端口（F67 状态隔离）=====
def act_v18(obs, port_state):
    # 1) 块边界：测时延 + 更新 ẑ（块内不更新，因 chunk 开环）
    latency = port_state.measure_rtt()
    z_hat, conf = infer_env(port_state, port_state.obs_hist,
                            port_state.act_hist, latency)
    if conf < tau_conf:
        z_hat = port_state.prior_z                     # 回退无条件 / 多假设
    # 2) Δ 守护决定 T_a / resize / 准入（v17）
    knobs = delta_governor(port_state.ledger, T_a_bound=eta_id_bound(z_hat))
    # 3) 规划 / 中层 / TO（吃 ẑ 与 Γ 预算）
    plan = ip49_plan(obs.language, port_state.semantic_map,
                     scenario=z_hat, budget=knobs, gamma=port_state.gamma)
    task = ip39_midlevel(plan, obs, budget=knobs, z_hat=z_hat)
    traj = ip50_to(task, warm=ip43_head(obs), z_hat=z_hat,
                   f_track=port_state.f_track[z_hat], deadline=0.5*chunk_window(knobs))
    # 4) 动作正则 + 协议鲁棒 + CBF
    chunk = ip52_regulate(traj, T_a=knobs.T_a, gamma=port_state.gamma)
    if not ip33_cbf(chunk):
        chunk = resample_or_fallback(port_state, r=2)
    port_state.act_hist.append(chunk)
    return chunk
```

### 3.9 理论推导（P51–P54）

**P51（内点最优半径）**。为把三难拆开，先固定步数预算 `N̄`（或取 `g(N)` 在该区间的局部常数近似），令 `S_rob(ρ)=S_0C(ρ)−bρ`，`σ(ρ)=σ_0+c_3ρ`，`C` 凹增且 `C'(0)>0, C'(∞)=0`。则
`F(ρ)=[S_0C(ρ)−bρ]g(N̄)−λ(σ_0+c_3ρ)`，
`F'(ρ)=[S_0C'(ρ)−b]g(N̄)−λc_3`，
`F''(ρ)=S_0C''(ρ)g(N̄)<0`。
故 `F` 严格凹；`F'(0)>0 ⇔ S_0C'(0)g(N̄)>b g(N̄)+λc_3`，`F'(∞)<0`，由介值定理存在唯一 `ρ*` 满足
`C'(ρ*) = b/S_0 + λc_3/(S_0 g(N̄))`。
直观：**最优半径在「覆盖的边际收益 = 专业化 + 精度 + 正则的边际成本」处**。完整三难（`N` 随 ρ 变）用坐标上升：固定 `N̄` 求 `ρ*`，再由 `N(ρ*)` 更新 `N̄`；不保证全局最优，但给出可解释的 Pareto 前沿，E78 验证。

**P52（条件化支配平均化）**。设真实域 `θ~P`，观测 `o`，附加信息 `ẑ=f(o)`。对任意适当评分规则 `S`，贝叶斯最优策略满足
`E_{o}[max_a E_{θ|o,ẑ}S(a,θ)] ≥ E_o[max_a E_{θ|o}S(a,θ)]`，
因为 `σ(ẑ)` 是 `σ(o)` 的加细；对加细的划分取条件期望最大值不会更小（Jensen / 信息价值）。若策略训练误差为 `ε_ID` 且 `ẑ` 是 θ 的近似充分统计，则
`0 ≤ E[S_cond]−E[S_uncond] ≤ V(θ;ẑ) − ε_ID·L`，
其中 `V` 为信息价值。故**条件化把「鲁棒性」从平均化税换成辨识误差**；当 `ε_ID` 足够小，DR 只负责扩大训练覆盖，不再牺牲精度。

**P53（轴分配近优）**。若 `Score` 对 `ρ` 的收益可分解为逐轴凹函数或为子模函数，则按 `e_i/c_i` 贪心分配在子模情形达到 `1−1/e` 近似；连续凹情形由 KKT，贪心边际增益均衡即最优。工程上用 BO 处理交互项。

**P54（T_a-ρ 耦合）**。设 `Score(ρ,η)=S_rob(ρ)·(1+η·V0)` 近似（条件化价值随辨识效率 η 增），若 `∂²Score/∂ρ∂η ≤ 0`（条件化与无条件鲁棒性互为**替代品**），则 Topkis 单调比较静态给出：`η` 下降 ⇒ 最优 `ρ` 上升。由定义 42，`η_ID(T_a)` 随 `T_a` 下降，故 `ρ*(T_a)` 单调不减。**管理含义**：大 chunk 省推理 / 省热（v17），但会降低在线辨识带宽，必须用更大的无条件随机化半径补偿；这两个旋钮不能独立调。

**P55（保功能不改变可解性）**：若 `Valid(θ)` 保持任务前置 / 后置条件与接触可行性，则 `θ` 的随机化只改变解的风格 / 难度，不引入无解任务；因此 `C(ρ)` 的增益不被「不可完成样本」污染（对照 F76 的几何增广失败模式）。

**P56（协议不变性）**：若 `Sim_prot` 的支撑覆盖评测协议真实范围（E74/E77 标定），且策略在 `θ_prot` 上训练，则协议偏移落在训练分布内，成功率不因延迟 / 丢帧 / resize 显著下降。

**P57（动作正则不损任务）**：`J(a)` 与 `Var(a)` 只约束实现方式，不改变任务目标；与 v17 的 prosody 同向，故在任务可行域内不降低成功率，且改善官方动作规律性。

**P58（view-swap 防坍缩）**：一致性约束要求 `π(a|o_{swap})≈π(a|o)`，排除「少看一个视角」的伪鲁棒；与 F73 的 view collapse 诊断对应。

**P59（每端口隔离）**：`ẑ`、历史、reset 按端口容器隔离，满足 F67 的并发 / 状态隔离条款；共享后端只共享只读权重。

**P60（探针不损任务）**：探针只在 `IP-33` 安全集内、且信息增益 `E[Δ]>0`（定义 35）时触发；否则按 MAP 行动，故不增加不可逆失败概率。
