### 第 4 轮灵感驱动研究记录

**灵感词**：参数高效微调、灵巧手

**直觉与动机**：

上一轮 CADVS 把「安全」建立在证书链与分布式时序有效性上，但策略层的**适配**仍是空白：每换一只灵巧手、每换一类物体、每换一个台面摩擦条件，就要重训学生网络。全量再训练既昂贵，又会让原有证书整体失效——因为证书是绑在参数上的。两个灵感词恰好在这里交汇：**参数高效微调**提供了「小改动」的工具，**灵巧手**提供了「必须频繁改动」的场景。问题于是变成：能否让**适配本身也「小而可证」**？

1. **参数高效微调 → 证书保持的适配（PEFT as certificate preservation）**：不更新已认证主干 θ₀，只学低秩增量 ΔW = BA（rank r ≪ d）。低秩把「改多少」量化为可约束的量：谱范数 ‖BA‖₂ ≤ β 直接给出适配后策略相对已认证策略的**动作偏移上界** ‖Δu‖ ≤ L_σ β ‖h‖。于是安全证书不必重证，只需证「偏移落在证书裕度之内」。这把 PEFT 从「省算力」重解释为「省证书」——**适配半径**成为可审计、可熔断的一等公民，而不是训练完才事后检查的黑箱。

2. **灵巧手 → 接触证书（Dexterity lives at contacts, not joints）**：多指手的危险不在 20 维关节空间，而在接触瞬间：滑移、失稳、力闭合破坏。灵巧操作的高频修正天然是高维、非连续、接触驱动的，这与「低秩平滑」的适配存在根本张力。因此需要**接触质量证书** CQC = (n_c, p_slip, M_fc, H_f, σ_tac)，把「抓得住」从直觉量化为可门控的量；并让低秩适配只在「接触构型已由主干保证」的连续段内生效。

3. **二者结合 → 协同子空间对齐（Low-rank actuation meets low-rank adaptation）**：灵巧手常用姿态协同（postural synergy）q = S z，S ∈ ℝ^{n×k}，k ≈ 5~6 ≪ n。执行端低秩与参数端低秩**同构**：适配只劫持协同子空间内的低秩方向，未被触及的零空间由已认证的阻抗/力控保持。于是「低秩」不再是牺牲表达力的近似，而是与手的物理自由度结构吻合的归纳偏置——秩预算 r 与协同维数 k 具有可解释的对应关系。

**关键洞见**：把 PEFT 的秩 r 与谱预算 β 解释为**证书半径**，把灵巧手的接触切换解释为**证书断点**——适配在接触连续段内可被证明继承安全，在接触切换点必须回退到已认证主干。这样「适配的灵活性」与「证书的保守性」被折中成一条**可计算的 Pareto 前沿**，而不是二选一。CPEDA（Certified Parameter-Efficient Dexterous Adaptation）就是沿这条前沿运行的框架。

**形式化目标（增量）**：

1. 定义证书保持低秩适配 CPLoRA：θ = θ₀ + BA，rank(BA) ≤ r，‖BA‖₂ ≤ β；输出 AdapterCert = (r, β, γ_adapt, drift, t_valid)，其中 γ_adapt = L_σ β H 为动作偏移上界。
2. 定义接触质量证书 CQC = (n_c, p_slip, M_fc, H_f, σ_tac)，并给出 KC 规则 kc_grasp_stable、kc_slip_margin、kc_contact_continuous。
3. 定义协同子空间适配：q = S z + ε⊥，仅对 z 维适配、零空间由主干锁定；给出截断误差 ‖ε⊥‖ ≤ e_max 与力闭合裕度 M_fc 的传递关系。
4. 定义 CPEDA 统一框架：CPLoRA ∪ TCCK ∪ DHCK ∪ THAR ∪ CTG，目标 Exec_CPEDA ⊆ Exec_CADVS（v30 相对 v29 更严格，不放大执行集）。
5. 证明或给出条件：**证书继承引理**——若 γ_adapt < γ* = κρ / L_g（ρ 为证书裕度、L_g 为闭环增益 Lipschitz 界、κ 为收缩率），则适配策略仍在安全集内；实验目标：r ∈ {4,8,16} 下新物体成功率提升 ≥ 20%，且证书违规率 < 1%。

**本轮最大风险**：**接触不连续性摧毁低秩适配的 Lipschitz 前提**——证书继承依赖「动作偏移有界 + 动力学 Lipschitz」，而灵巧手的抓取/释放/滚动正是接触集合切换导致的非连续事件；恰在安全性最关键的接触切换点，扰动上界失效，低秩适配要么因过度保守而丧失灵巧性，要么为覆盖接触切换而抬高秩/预算从而让证书形同虚设。

### IP-478 Certificate-Preserving Low-Rank Adapter (CPLoRA)

```python
@dataclass
class AdapterCertificate:
    rank: int
    spectral_budget: float
    action_dev_bound: float      # gamma_adapt = L_sigma * ||BA||_2 * H
    drift: float                 # 适配后特征分布漂移（OOD 指标）
    valid: bool
    t_stamp: float

class CertificatePreservingLoRA:
    """冻结主干 + 低秩增量 ΔW=BA；谱预算硬约束；输出可继承证书。"""

    def __init__(self, backbone, d_in: int, d_out: int,
                 r: int = 8, beta: float = 0.05, L_sigma: float = 1.0):
        self.backbone = freeze(backbone)      # theta_0 不可训练
        self.A = init_lowrank(d_in, r)         # 高斯小初始化
        self.B = np.zeros((d_out, r))          # 零初始化保证起始 ΔW=0
        self.r, self.beta, self.L_sigma = r, beta, L_sigma
        self.H = None                          # 特征范数上界（校准期估计）

    # ---------- 谱预算投影：始终维持 ||BA||_2 <= beta ----------
    def _spectral_norm(self) -> float:
        return float(np.linalg.norm(self.B @ self.A, 2))

    def project_to_budget(self):
        nu = self._spectral_norm()
        if nu > self.beta and nu > 0:
            self.B *= self.beta / nu           # 等比缩放最省信息损失
        return self._spectral_norm()

    # ---------- 前向：主干 + 投影后的低秩残差 ----------
    def adapt_forward(self, s: np.ndarray) -> np.ndarray:
        h = self.backbone.encode(s)
        du = self.B @ (self.A @ h)
        return self.backbone.head(h) + du

    # ---------- 证书：偏移上界 + 特征漂移 ----------
    def cert(self, gamma_max: float, drift: float) -> AdapterCertificate:
        nu = self.project_to_budget()
        gamma = self.L_sigma * nu * (self.H if self.H is not None else 1.0)
        return AdapterCertificate(
            rank=self.r, spectral_budget=nu, action_dev_bound=gamma,
            drift=drift, valid=(gamma <= gamma_max and drift <= 0.10),
            t_stamp=time.time(),
        )

    # ---------- 约束更新：只在谱球内做一步自然梯度 ----------
    def update(self, grad_A, grad_B, lr: float):
        self.A -= lr * grad_A
        self.B -= lr * grad_B
        self.project_to_budget()               # 每步硬投影，杜绝越界
```

### IP-479 Tactile Contact Certificate Kernel (TCCK)

```python
@dataclass
class ContactQualityCertificate:
    n_contact: int
    p_slip: float
    force_closure_margin: float
    force_entropy: float
    tactile_noise: float
    valid: bool

class TactileContactCertificateKernel:
    """taxel/接触力 → CQC；滑移、力闭合、熵、噪声四项守门。"""

    def __init__(self, mu_s: float = 0.6, n_c_min: int = 3,
                 p_slip_max: float = 0.05, M_fc_min: float = 0.02,
                 sigma_tac_max: float = 0.15):
        self.mu_s = mu_s
        self.n_c_min, self.p_slip_max = n_c_min, p_slip_max
        self.M_fc_min, self.sigma_tac_max = M_fc_min, sigma_tac_max

    def compute_cqc(self, taxels, contacts, G: np.ndarray) -> ContactQualityCertificate:
        n_c = len(contacts)
        if n_c < self.n_c_min:
            return ContactQualityCertificate(n_c, 1.0, 0.0, 0.0, 0.0, False)

        # 1) 滑移概率：切向/法向比值超过 mu_s 的 taxel 占比（含触觉噪声裕度）
        ratios = np.array([np.linalg.norm(t.f_t) / (t.f_n + 1e-6) for t in taxels])
        p_slip = float(np.mean(ratios > 0.8 * self.mu_s))

        # 2) 力闭合裕度：摩擦锥内抓取矩阵最小奇异值（归一化后）
        M_fc = self._force_closure_margin(G, contacts, self.mu_s)

        # 3) 力分布熵：多指协同均衡度，H_f↓ 表示少数指承担全部载荷
        f_n = np.array([t.f_n for t in taxels]) + 1e-9
        p = f_n / f_n.sum()
        H_f = float(-np.sum(p * np.log(p)) / np.log(len(p) + 1e-9))

        # 4) 触觉噪声：静息段方差的滑动估计
        sigma_tac = self._tactile_noise(taxels)

        valid = (n_c >= self.n_c_min and p_slip < self.p_slip_max
                 and M_fc > self.M_fc_min and sigma_tac < self.sigma_tac_max)
        return ContactQualityCertificate(n_c, p_slip, M_fc, H_f, sigma_tac, valid)

    def _force_closure_margin(self, G, contacts, mu_s) -> float:
        # 在摩擦锥生成方向上构造约束矩阵，取最小奇异值为裕度代理量
        W = build_friction_cone_basis(contacts, mu_s)     # (6*m, p)
        GW = G @ W
        return float(np.min(np.linalg.svd(GW, compute_uv=False)) if GW.size else 0.0)

    def _tactile_noise(self, taxels) -> float:
        return float(np.median([t.rest_var for t in taxels])) if taxels else 1.0

    def kc_rules(self, cqc: ContactQualityCertificate) -> dict:
        return {
            'kc_grasp_stable': cqc.valid,
            'kc_slip_margin': cqc.p_slip < self.p_slip_max,
            'kc_force_closure': cqc.force_closure_margin > self.M_fc_min,
        }
```

### IP-480 Dexterous Hand Certificate Kernel (DHCK)

```python
class DexterousHandCertificateKernel:
    """姿态协同 q=Sz 的低秩执行；协同通道做任务，零空间通道做稳定/保持。"""

    def __init__(self, S: np.ndarray, Kp_z, Kd_z, Kd_null, q_hold):
        assert np.allclose(S.T @ S, np.eye(S.shape[1]), atol=1e-5)
        self.S = S
        self.Kp_z, self.Kd_z, self.Kd_null = Kp_z, Kd_z, Kd_null
        self.S_null = np.eye(S.shape[0]) - S @ S.T
        self.q_hold = q_hold

    def project(self, q_des: np.ndarray):
        z = self.S.T @ q_des
        eps_null = q_des - self.S @ z
        return z, eps_null

    def control(self, q, dq, z_des, cqc, adapter_active: bool):
        """cqc 不通过 → 零空间阻抗保持；通过 → 协同通道跟踪 + 零空间阻尼。"""
        if not cqc.valid or not adapter_active:
            tau = -self.Kp_z @ (q - self.q_hold) - self.Kd_null @ dq
            return tau, False                          # 冻结适配，回退主干
        z, _ = self.project(q)
        tau_syn = self.S @ (self.Kp_z @ (z_des - z) - self.Kd_z @ dq)
        tau_null = self.S_null @ (-self.Kd_null @ dq)
        return tau_syn + tau_null, True

    def truncation_bound(self, q_des, L_G: float) -> float:
        """协同截断误差对抓取矩阵的扰动上界 ||ΔG|| <= L_G ||eps_null||。"""
        _, eps_null = self.project(q_des)
        return L_G * float(np.linalg.norm(eps_null))
```

### IP-481 Task-Hand Adapter Router (THAR)

```python
@dataclass
class RoutedAdapter:
    adapter: CertificatePreservingLoRA
    merged_W: np.ndarray
    weights: dict

class TaskHandAdapterRouter:
    """按 (task, hand) 检索/合并 adapter；合并后总谱范数超预算即回退主干。"""

    def __init__(self, bank: dict, beta_total: float):
        self.bank = bank                 # {(task_id, hand_id): CPLoRA}
        self.beta_total = beta_total

    def route(self, task_id, hand_id, s, drift_fn) -> RoutedAdapter | None:
        cands = self._candidates(task_id, hand_id)     # 同任务/同手/近邻迁移
        if not cands:
            return None
        alpha = self._gate(cands, s)                   # softmax/相似度门控，Σα<=1
        merged = sum(a * c.adapter.B @ c.adapter.A
                     for a, c in zip(alpha.values(), cands))
        # 关键守门：合并后总谱范数不得超过预算，否则不冒险
        if np.linalg.norm(merged, 2) > self.beta_total:
            return None                                # → 调用方回退主干
        base = next(iter(cands)).adapter
        routed = copy.deepcopy(base)
        routed.B = merged @ np.linalg.pinv(routed.A)   # 反解等价 B（或直接用 merged 前向）
        drift = drift_fn(routed, s)
        return RoutedAdapter(routed, merged, dict(zip(cands.keys(), alpha.values())))

    def _candidates(self, task_id, hand_id):
        exact = (task_id, hand_id)
        out = {}
        if exact in self.bank:
            out[exact] = SimpleNamespace(adapter=self.bank[exact], sim=1.0)
        for key, ad in self.bank.items():
            if key != exact and (key[0] == task_id or key[1] == hand_id):
                out[key] = SimpleNamespace(adapter=ad, sim=0.5)
        return out

    def _gate(self, cands, s):
        sims = np.array([c.sim for c in cands.values()])
        w = np.exp(sims) / np.exp(sims).sum()
        return dict(zip(cands.keys(), w))
```

### IP-482 Sim-to-Real Adapter Calibration (SRAC)

```python
class SimToRealAdapterCalibration:
    """冻结 A（方向来自仿真），只在实机残差上校准 B；输出域差距证书。"""

    def __init__(self, adapter: CertificatePreservingLoRA, lam: float = 1e-3):
        self.adapter = adapter
        self.lam = lam

    def calibrate(self, H_real, y_residual, max_steps: int = 200):
        # 约束最小二乘：min ||B A H - y||^2 + lam||B||^2, s.t. ||BA||<=beta
        for _ in range(max_steps):
            pred = self.adapter.B @ (self.adapter.A @ H_real)
            grad_B = 2 * (pred - y_residual) @ (self.adapter.A @ H_real).T \
                     + 2 * self.lam * self.adapter.B
            self.adapter.B -= 0.01 * grad_B
            self.adapter.project_to_budget()
        return self.adapter.cert(gamma_max=float('inf'), drift=self._drift(H_real))

    def domain_gap_cert(self, sim_stats, real_stats) -> dict:
        delta_dyn = float(np.abs(sim_stats['friction'] - real_stats['friction']))
        delta_obs = float(np.linalg.norm(sim_stats['tac_mean'] - real_stats['tac_mean']))
        delta = float(np.clip(delta_dyn / (real_stats['friction'] + 1e-6)
                              + delta_obs, 0.0, 1.0))
        return {'DGC': (delta_dyn, delta_obs, delta),
                'valid': delta < 0.30}
```

### IP-483 Contact-Transition Guard (CTG)

```python
class ContactTransitionGuard:
    """检测接触集合切换；切换窗口内冻结适配、切回主干（断点证书）。"""

    def __init__(self, debounce: int = 3, hold_steps: int = 8):
        self.prev_contacts = frozenset()
        self.debounce, self.hold_steps = debounce, hold_steps
        self._cnt = 0
        self._hold = 0

    def transition_detected(self, contacts) -> bool:
        cur = frozenset((c.link_name, c.face_id) for c in contacts)
        if cur == self.prev_contacts:
            self._cnt = 0
            self.prev_contacts = cur
            return self._hold > 0 and self._advance_hold()
        self._cnt += 1
        if self._cnt >= self.debounce:          # 去抖：连续变化才认定切换
            self.prev_contacts = cur
            self._cnt = 0
            self._hold = self.hold_steps        # 冻结适配 hold_steps 步
            return True
        return self._hold > 0 and self._advance_hold()

    def _advance_hold(self) -> bool:
        self._hold = max(0, self._hold - 1)
        return True

    def kc_contact_continuous(self) -> bool:
        return self._hold == 0
```

```python
def cpeda_step(state, sensors, task_id, hand_id) -> ControlOutput:
    """
    证书驱动的灵巧手适配单步：
    主干始终在线；适配仅在接触连续、CQC 通过、AdapterCert 有效时叠加。
    """
    cqc = TCCK.compute_cqc(sensors.taxels, sensors.contacts, sensors.G)
    if not cqc.valid:
        # 接触质量不达标：零空间阻抗保持，冻结适配
        tau, _ = DHCK.control(state.q, state.dq, state.z_des, cqc, False)
        return ControlOutput(tau, path='backbone_hold', certs=(cqc,))

    if CTG.transition_detected(sensors.contacts):
        # 接触切换断点：证书继承前提失效，强制回退主干
        tau, _ = DHCK.control(state.q, state.dq, state.z_des, cqc, False)
        return ControlOutput(tau, path='backbone_transition', certs=(cqc,))

    routed = THAR.route(task_id, hand_id, state.s, drift_fn=estimate_drift)
    if routed is None:
        tau, _ = DHCK.control(state.q, state.dq, state.z_des, cqc, True)
        return ControlOutput(tau, path='backbone', certs=(cqc,))

    cert = routed.adapter.cert(gamma_max=ADAPT_RADIUS, drift=estimate_drift(routed, state.s))
    if not cert.valid:
        tau, _ = DHCK.control(state.q, state.dq, state.z_des, cqc, False)
        return ControlOutput(tau, path='backbone_cert_fail', certs=(cqc, cert))

    # 适配动作经协同子空间投影后执行
    u_ad = routed.adapter.adapt_forward(state.s)
    z_des = DHCK.project(u_ad)[0]
    tau, active = DHCK.control(state.q, state.dq, z_des, cqc, True)
    return ControlOutput(tau, path='adapter+synergy', certs=(cqc, cert))
```

## 4. 正确性论证（增量更新）

### 引理 32（低秩适配的动作偏移界）

**陈述**：设主干输出 u₀ = σ(W₀ h)，适配输出 u = σ((W₀+BA)h)，σ 为 L_σ-Lipschitz 的分段线性激活。则
‖u − u₀‖₂ ≤ L_σ ‖BA‖₂ ‖h‖₂ ≤ L_σ β H = γ_adapt，
其中 H = sup_{s∈𝒟}‖h(s)‖₂。

**证明**：
‖σ((W₀+BA)h) − σ(W₀h)‖ ≤ L_σ ‖BA h‖ ≤ L_σ ‖BA‖₂ ‖h‖ ≤ L_σ β H。
第一式用 σ 的 Lipschitz 性，第二式用诱导 2-范数定义，第三式用谱预算与特征范数上界。∎

**工程含义**：γ_adapt 是**可在部署前静态计算**的偏移上界，不依赖输入分布之外的假设；它把「低秩」与「可证安全」直接连起来，是 AdapterCert 的核心字段。

### 引理 33（证书继承 / 适配半径）

**陈述**：设安全集 𝒮_safe 在主干策略下受控不变，且状态到边界距离 ≥ ρ_cert；闭环误差动力学在控制扰动下满足 ISS，收缩率 κ、增益 Lipschitz 界 L_g。若 γ_adapt < γ* := κ ρ_cert / L_g，则适配策略的闭环轨迹仍停留在 𝒮_safe 内。

**证明要点**：
把适配视为对主干控制的有界加性扰动 δu，‖δu‖ ≤ γ_adapt。由 ISS 性质，稳态状态偏差满足 ‖δx‖_∞ ≤ L_g γ_adapt / κ。代入 γ_adapt < κ ρ_cert / L_g 得 ‖δx‖_∞ < ρ_cert，即扰动轨迹不会越出安全集边界；由 𝒮_safe 受控不变与连续性，轨迹全程不越界。∎

**工程含义**：γ* 是**证书半径**；r、β 越小越安全，但表达力越弱。CPEDA 的 Pareto 前沿就是「成功率(r,β) vs 证书违规率(r,β)」的折中曲线（见 §6）。

### 引理 34（协同截断与力闭合裕度的传递）

**陈述**：设 q_des = S z_des + ε⊥，‖ε⊥‖ ≤ e_max，抓取矩阵对关节误差的 Lipschitz 界为 L_G（即 ‖G(q) − G(q')‖₂ ≤ L_G‖q − q'‖）。若主干在完整 q_des 下满足力闭合裕度 M_fc > L_G e_max · ‖w_ext‖ / σ_min，则截断后的 q = S z_des 仍保持力闭合。

**证明**：
‖G(q) − G(q_des)‖ ≤ L_G ‖ε⊥‖ ≤ L_G e_max。抓取平衡 G(q) f_c = −w_ext 的可行域在 G 的扰动下连续收缩；当扰动幅度 L_G e_max 小于原裕度对应的可行域内半径（以 σ_min 归一化），摩擦锥约束仍可行，故力闭合保持。∎

**工程含义**：协同维数 k 的下界由 e_max 与 L_G 共同决定；适配只动 z 维时，零空间残差必须足够小，否则力闭合证书不成立。这解释了为什么「协同低秩」不是免费午餐。

### 引理 35（滑移证书的置信传播）

**陈述**：设触觉对切向/法向比的估计误差有界 ‖κ̂_slip − κ_slip‖ ≤ ε_μ，且以概率 ≥ 1−δ 成立。若 κ̂_slip < 1 − ε_μ，则真实 κ_slip < 1（无滑移）以概率 ≥ 1−δ。

**证明**：κ_slip ≤ κ̂_slip + ε_μ < (1 − ε_μ) + ε_μ = 1，事件概率由估计误差界给出。∎

**工程含义**：p_slip 阈值必须扣除触觉噪声裕度 ε_μ，否则「证书通过」可能只是噪声假象；σ_tac 因此进入 CQC 作为独立守门项。

### 定理（CPEDA 执行集包含性与适配 Pareto）

**陈述**：在 (A1) CQC.valid、(A2) CTG 未检测到接触切换、(A3) AdapterCert.valid（即 γ_adapt ≤ γ*）、(A4) THAR 合并谱范数 ≤ β_total 同时成立时，Exec_CPEDA ⊆ Exec_CADVS；且在此条件下，成功率随 (r, β) 单调不降直至表达力饱和，证书违规率随 (r, β) 单调不降，二者构成 Pareto 前沿。

**证明**：
- 包含性：cpeda_step 的每条适配分支都额外要求 CQC/CTG/AdapterCert/THAR 四项守门，任一项失败即回退主干（主干 ⊆ CADVS）；适配只在守门全通过时叠加，故 CPEDA 不产生 CADVS 之外的执行。∎
- Pareto：由引理 32–33，增大 (r,β) 提高表达力（拟合误差↓、成功率↑），同时 γ_adapt 增大、离 γ* 更近（违规率↑）；两目标关于 (r,β) 单调，故存在非支配前沿。∎

**诚实声明**：引理 33 的 Lipschitz/ISS 假设在**接触切换瞬间不成立**——接触集合改变使动力学右端不连续，L_g、κ 不再有界。定理因此只在接触连续段成立；CTG 用「检测到切换即回退」把断点隔离成主干段，但这属于**工程补救而非形式证明**，无法覆盖未检测到的微滑移/滚动切换。

## 7. 本轮最大风险（最终确认）

**一句话**：**接触不连续性摧毁低秩适配的 Lipschitz 前提**——证书继承（引理 33）依赖「动作偏移有界 + 闭环动力学 Lipschitz」，而灵巧手的抓取/释放/滚动正是接触集合切换导致的非连续事件；恰在安全性最关键的接触切换点，扰动上界失效，低秩适配要么因过度保守而丧失灵巧性，要么为覆盖接触切换而抬高秩/预算从而让证书形同虚设。这不是调参问题，而是**「可证安全」与「接触丰富灵巧性」之间的模型语义鸿沟**：连续控制理论给出的是连续段的证书，接触力学给出的是离散事件的跳变，二者之间目前只有工程去抖（CTG）而没有统一的混合系统证书——这是 CPEDA 能否真正用于灵巧操作的分水岭。
