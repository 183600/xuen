# 第 61 轮（承接第 60 轮 IP-153~160；灵感循环第 7 轮；本轮灵感：「工具调用」×「开源硬件」）

> 第 60 轮把闭环升级为「场景→意图→约束→阻抗→执行→EV-exec→场景更新」的认知驱动场景落地（SSM×CIEC×EPIR×SERC×PCE++++）。但把镜头拉远到「高层规划器如何真正调用机器人」与「机器人由谁造」这两个问题时，暴露出**三个更深的结构性局限**：
> 1. **工具调用的接口幻觉**：第 60 轮的 SERC 是机器人内部的闭环，而真正下命令的往往是 LLM 规划器或人类操作员——他们通过**工具调用**交互。但 K_safe、π_scene、ERTC 锁、预算在接口上只是「自由文本 + 隐式动作」，缺少**类型化的输入/输出、前置/后置条件、物理安全包络、副作用声明与代价**。于是「把力加大一点」在湿滑场景里也可能被当作合法调用，系统没有「契约拒绝」这一动作。
> 2. **开源硬件的同质化假设**：SSM 的 π_scene(K|z) 与 EEIS 的 K_safe 都假设执行机构语义固定且已知。但开源硬件是**异构、可替换、厂商众多**的：同一个语义工具「轻触抓取」，在柔性夹爪、舵机夹爪、无刷力控夹爪上应降级为完全不同的 K_p/K_d/F_max/电流限。缺少**硬件能力清单 + 语义到设备的降级编译**，所谓「同一工具」跨硬件即失效。
> 3. **硬件来源的可信度缺口**：开源固件、标定文件、device tree、社区贡献的硬件 profile 可以被伪造或抄错。第 60 轮的 SIC 只校验「场景—阻抗—可行性」，却不校验**硬件模型本身从哪来、是否被验证**。于是契约可能在一个「声称 torque_max=10N·m、实际只有 3N·m」的假清单上被成功 discharge——得到一张「形式正确、物理致命」的证书。

## 0. 直觉与动机

**灵感 1（工具调用 → 工具契约 TC）**
直觉：一次工具调用不是「发个 JSON」，而是**带副作用的承诺**。软件里函数调用有签名和返回值；物理世界里还多出四件事：安全包络（力/速度/力矩/温度）、可观测证据（怎么证明它真的发生了）、可逆性（能否补偿/撤销）、资源代价（占用多长时间、多少算力）。关键洞见：**把工具调用当成「带物理副作用的类型化契约」**——调用前做类型检查 + 前置条件检查 + 安全包络包含检查 + 预算检查；调用后必须由 EV-exec 作为「见证」来 discharge 后置条件。没有见证的「成功」不算成功。

**灵感 2（开源硬件 → 能力清单 HCM 与语义降级编译 L）**
直觉：开源硬件像一门门方言：同一个抽象工具在不同板子上要「翻译」。把每个硬件模块的能力写成机器可读的**能力清单**（力矩/力/速度上限、带宽、分辨率、可行阻抗包络 E_K、时延分布、固件哈希、标定不确定度），再定义一个**降级编译函数** L：ToolOp × HCM → DeviceCmd，把「轻触 2N」翻译成具体增益、限幅与电流指令。关键洞见：**语义契约留在工具层，参数绑定下沉到硬件层**——可移植性来自「重新编译」而不是「重写代码」；编译必须是**可靠的（sound）**：翻译成功且设备按清单执行，则后置条件成立。

**灵感 3（工具调用 × 开源硬件 → 来源证明 PA）**
直觉：社区贡献的 profile 可能错、可能旧、可能恶意。每份硬件清单、固件、标定都应携带**可验证的来源链**（构件哈希、签名者、父节点、时间戳），并维护一个**信任分数**。工具运行时在 discharge 契约前先过「来源闸门」：来源不可信 → 不得使用其声称的能力上界，只能回退到保守通用包络。更关键的是：**把执行观测当作对清单的审计**——若实测力矩在 3N·m 饱和而清单声称 10N·m，则自动收缩能力盒并下调信任。关键洞见：**信任是类型的一部分；未经验证的清单是「未净化类型」，不能直接参与安全证明。**

**灵感 4（能力差距 → 契约松弛 RC，而非静默降级）**
直觉：开源硬件常常「差一点」：要求的带宽 200Hz，实际 120Hz。此时最危险的不是失败，而是**静默降级**——系统仍返回 ok，但保证悄悄变弱。因此引入**契约松弛格**：当 L 无法在完整包络内实现时，显式生成一个更弱但诚实的契约 TC'（性能后置条件变弱、安全包络只能更紧、结果标记 degraded=true），并把「弱在哪」写进证书；若无任何松弛能同时保持 Env'⊆Env 与安全，则返回类型化错误 E_CAPABILITY。关键洞见：**降级必须是一等公民，且安全包络单调收紧、绝不放松。**

**灵感 5（工具组合 → 组合契约 CTC 与非干扰）**
直觉：规划器很少只调一个工具，而是链式/并发调用（定位→抓取→移动→放置）。若只逐个校验，组合仍可能出事：前一个工具的后置条件不满足后一个的前置条件；两个工具的写集合重叠导致竞态。关键洞见：**给工具组合定义组合契约**——前置条件沿链传递、后置条件逐段见证、安全包络取交集、证据按因果序拼接；并发调用必须写集合不相交，或由 ERTC 资源锁串行化。

**灵感 6（合流 → 工具接地闭环 TGL 与 PCE+++++）**
直觉：把所有环节串成**工具接地闭环**：规划器发 ToolCall → 契约类型检查/前置检查 → 来源闸门 → 硬件降级编译（必要时契约松弛）→ ERTC/预算守卫 → 执行 → EV-exec 见证 → 审计并更新来源信任 → 返回带证书的类型化 ToolResult。预算从第 60 轮的 B_cog 扩展为 **B_th = (B_call, B_lower, B_attest, B_exec)**：调用次数、降级编译算力、来源验证/标定刷新、执行预算。任一项耗尽即触发显式受限模式，而不是悄悄放宽安全。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（工具契约 TC）** 一个物理能力工具由九元组刻画：
```
TC = (name, Sig, Pre, Post, Env, Wit, Cost, Rev, Idem)
```
- **签名** Sig = (X, Y)：输入模式 X、输出模式 Y 均为强类型（数值带单位、区间、枚举）；
- **前置条件** Pre: X×State→Bool，例如「夹爪张开且未接触」；
- **后置条件** Post: X×Y×Evidence×State→Bool，必须由证据见证；
- **安全包络** Env = {τ≤τ_max, F≤F_max, v≤v_max, K∈E_K, T≤T_max}；
- **见证规范** Wit：该调用必须写入 EV-exec 的最小字段集（时间戳、序列号、实测力/位/电流、哈希）；
- **代价** Cost = (ΔB_call, ΔB_lower, ΔB_attest, ΔB_exec)；
- **可逆性** Rev ∈ {reversible, compensable, irreversible}；
- **幂等语义** Idem：call_id 去重与重放规则。
一次调用 c = (name, args, call_id, deadline, intent_ref)。**契约可 discharge** 定义为：
```
discharge(c) ⇔ type_ok(Sig,args) ∧ Pre(args,state) ∧ Env(c)⊆E_K(H)
             ∧ budget_ok(Cost) ∧ provenance_ok(H) ∧ deadline_feasible(c)
```
不满足任一合取项 ⇒ 返回**类型化拒绝**（E_TYPE/E_PRECOND/E_ENVELOPE/E_BUDGET/E_PROVENANCE/E_DEADLINE），绝不「尽力执行」。

**定义 162（硬件能力清单 HCM 与语义降级编译 L）** 硬件模块 h 的清单：
```
H = (dev_id, Cap, Cal, fw_hash, Prov)
Cap = (τ_max, F_max, v_max, bw, res, E_K, Lat)
```
其中 E_K⊆R^n 为**可行阻抗包络**（由驱动、减速器、传感器、热约束共同决定），Lat 为时延分布，Cal 为带不确定度的标定，Prov 为来源证明标识。降级编译：
```
L: (TC, X, H) → DeviceCmd ∪ {⊥}
```
**可靠性（soundness）**：若 L(TC,args,H)=cmd≠⊥，且运行环境满足 H 的标定假设，则执行 cmd 后 Post 成立且 Env 不被突破。硬件可达工具集：
```
Tools(H) = { TC | L(TC,·,H) ≠ ⊥ }
```
不可达并不意味着必然失败——见定义 163 的显式松弛。

**定义 163（能力差距与契约松弛 RC）** 设工具要求的安全包络为 Env，硬件可行包络为 E_K(H)。能力差距 g(TC,H) = dist(Env, E_K(H)) ≥ 0。当 g>0 时，允许构造松弛契约：
```
TC' = relax(TC, H) = (Sig, Pre, Post_δ, Env', Wit, Cost', Rev, Idem)
```
并强制约束：
1. **安全单调**：Env' ⊆ Env（只能更保守，绝不能更宽松）；
2. **后置诚实**：Post_δ 显式弱化（如「轻触」→「力不超上限」），δ 写入证书；
3. **可观测**：ToolResult.degraded=true 且携带 weakening 说明；
4. **不存在的松弛**：若不存在 Env'⊆Env 且 Post_δ 可被 Wit 见证的 TC'，返回 E_CAPABILITY。
因此「降级」是**对用户可见、可审计的类型**，而不是静默的数值截断。

**定义 164（硬件来源证明 PA 与信任）** 来源图 PA 是有向无环图，节点
```
node = (artifact_hash, kind, signer, parents, timestamp, signature)
```
kind ∈ {firmware, calibration, device_tree, capability_profile}。信任分数 trust(Prov) ∈ [0,1] 由签名者信誉、链深度、标定新鲜度、历史证据一致性聚合。**来源闸门**：
```
admit(H, risk) ⇔ chain_verified(H.Prov)
               ∧ (fw_hash ∈ allowlist ∨ reproducible_build(H))
               ∧ calibration_fresh(H.Cal)
               ∧ trust(H.Prov) ≥ τ_trust(risk)
```
**观测即审计**：若 EV-exec 显示实测能力与清单冲突（如力矩在低于声称上限处饱和），则收缩能力盒 H.Cap ← H.Cap ∩ H_obs，并按贝叶斯规则下调 trust(Prov)；连续冲突达到 k 次则把该来源列入隔离名单。

**定义 165（工具接地闭环 TGL）** 算子 TGL(M, c)：
```
① TC ← M.registry.resolve(c.name)；不存在 ⇒ E_UNKNOWN_TOOL
② type_check(TC.Sig, c.args) ∧ TC.Pre(c.args, M.state) ⇒ 否则 E_TYPE/E_PRECOND
③ H ← M.hw_pool.select(TC, M.task_context)
④ provenance_ok ← admit(H, risk(M.task_context))；否则 H ← H_general，degraded←true
⑤ cmd ← L(TC, c.args, H)；若 ⊥ ⇒ TC' ← relax(TC,H)（定义 163）
⑥ 若 Cost 超出 B_th 或 ERTC 无法在 deadline 内锁定 Env ⇒ E_BUDGET/E_DEADLINE
⑦ ERTC.lock(TC.Env, c.deadline)；evidence ← execute(cmd)
⑧ 若 ¬TC.Post(c.args, result, evidence, M.state) ⇒ E_POSTCOND（并回收资源）
⑨ J_tool ← certify(TC, c, H, cmd, evidence)；M.pa.audit(H, evidence)
⑩ Return ToolResult(value, cert=J_tool, degraded, weakening=δ)
```
关键点：**任何「成功」都必须同时有 Post 见证与来源审计回写**；否则成功只是文本。

**定义 166（组合契约 CTC 与非干扰）** 对工具链 c₁;c₂;…;c_n，组合契约：
```
Pre_chain  = Pre₁ ∧ ⋀_{i≥2} (Post_{i-1} ⇒ Pre_i)   // 运行时以 guard 兑现
Post_chain = ⋀_i Post_i
Env_chain  = ⋂_i Env_i                              // 安全包络取交集
Wit_chain  = concat_ordered(Wit₁,…,Wit_n)           // 按 seq_id 因果排序
```
**非干扰条件**：并发调用满足 W(c_i) ∩ W(c_j) = ∅（写集合不相交），否则必须由 ERTC 资源锁按固定顺序串行化，避免死锁；锁顺序由图序给出。组合证书以链式父指针引用各 J_tool。

**定义 167（工具证据证书 J_tool 与组合证书）** 
```
J_tool = (call_id, TC_hash, args_hash, H_hash, lowering_trace,
          witness_hash, env_check, provenance_root, budget_receipt,
          degraded, weakening, parents[])
```
验证者可离线重放 lowering_trace 并检查 witness 是否满足 Post；组合时 parents 指向子调用证书，形成与第 59 轮 J_exec、第 60 轮 EPIR 同构的**执行证据链**。J_tool 与 J_exec 可组合校验：`J_tool ⊗ J_exec` 同时证明「契约被正确翻译」与「物理执行确实发生」。

**定义 168（工具-硬件预算 B_th 与 PCE+++++）** 
```
B_th = (B_call, B_lower, B_attest, B_exec)
B_call   = 单轮允许的工具调用/松弛搜索次数
B_lower  = 降级编译与松弛求解算力
B_attest = 来源验证、签名检查、标定刷新开销
B_exec   = 原第 59/60 轮执行预算
```
耗尽策略：B_call 耗尽 ⇒ 只允许只读/查询类工具；B_lower 耗尽 ⇒ 使用预编译的安全默认 lowering；B_attest 耗尽 ⇒ 冻结新硬件清单，仅复用已认证缓存；B_exec 耗尽 ⇒ 原有降级。代价函数：
```
cost_th(π) = λ_call·#calls + λ_lower·LowerCost(π)
           + λ_attest·AttestCost(π) + cost_exec(π)
```

### IP-161 工具契约运行时（TCR）

```python
class ToolContract:
    def __init__(self, name, sig, pre, post, env, wit, cost, rev, idem):
        self.name, self.sig, self.pre, self.post = name, sig, pre, post
        self.env, self.wit, self.cost = env, wit, cost
        self.rev, self.idem = rev, idem

class ToolRuntime:
    def __init__(self, registry, hw_pool, ertc, budget, pa):
        self.registry, self.hw_pool = registry, hw_pool
        self.ertc, self.budget, self.pa = ertc, budget, pa
        self.seen = {}

    def invoke(self, call, state):
        if call.call_id in self.seen:                 # Idem 语义
            return self.seen[call.call_id]
        tc = self.registry.resolve(call.name)
        if tc is None: return TypedError("E_UNKNOWN_TOOL")
        if not type_check(tc.sig, call.args): return TypedError("E_TYPE")
        if not tc.pre(call.args, state):      return TypedError("E_PRECOND")

        H = self.hw_pool.select(tc, state)
        degraded = False
        if not self.pa.admit(H, risk=state.task_risk):
            H, degraded = self.hw_pool.general(), True
        cmd = lower(tc, call.args, H)
        weakening = None
        if cmd is None:
            tc2, cmd, weakening = relax_search(tc, call.args, H)
            if cmd is None: return TypedError("E_CAPABILITY")
            tc, degraded = tc2, True

        if not self.budget.reserve(tc.cost):  return TypedError("E_BUDGET")
        if not self.ertc.can_lock(tc.env, call.deadline):
            return TypedError("E_DEADLINE")
        with self.ertc.lock(tc.env, call.deadline):
            result, evidence = execute(cmd, wit_spec=tc.wit)

        if not tc.post(call.args, result, evidence, state):
            return TypedError("E_POSTCOND", evidence=evidence)
        cert = build_jtool(tc, call, H, cmd, evidence,
                           degraded, weakening)
        self.pa.audit(H, evidence)                    # 观测即审计
        out = ToolResult(result, cert, degraded, weakening)
        self.seen[call.call_id] = out
        return out
```

### IP-162 HCM 与语义降级编译（HCL）

```python
@dataclass
class HardwareCapabilityManifest:
    dev_id: str
    tau_max: float; f_max: float; v_max: float
    bandwidth_hz: float; resolution: float
    impedance_envelope: "IntervalSet"     # 可行 K 的盒/椭球
    latency: "Dist"
    calibration: dict
    fw_hash: str
    prov: "ProvenanceId"

def lower(tc, args, H):
    req = tc.lower_spec(args)             # 抽象语义→物理请求(单位化)
    if not req.env <= H.impedance_envelope:
        return None                       # 能力不足，交给 relax_search
    cmd = DeviceCmd(
        kp=project(req.kp, H.impedance_envelope),
        kd=project(req.kd, H.impedance_envelope),
        f_max=min(req.f_max, H.f_max),
        v_max=min(req.v_max, H.v_max),
        tau_max=min(req.tau_max, H.tau_max),
        id=next_cmd_id(),
    )
    assert cmd.env <= req.env             # lowering 只收紧，不放松
    return cmd
```

### IP-163 契约松弛（RCS）

```python
RELAX_LATTICE = ["exact", "tighter_env", "weaker_post", "sample_only"]

def relax_search(tc, args, H):
    for level in RELAX_LATTICE[1:]:
        tc2 = relax(tc, H, level)
        if tc2 is None: continue
        assert tc2.env <= tc.env                 # 安全单调
        cmd = lower(tc2, args, H)
        if cmd is not None and witnessable(tc2, cmd):
            return tc2, cmd, {"level": level,
                              "weakened": diff(tc.post, tc2.post)}
    return None, None, None
```

### IP-164 来源证明（PAG）

```python
class ProvenanceGraph:
    def admit(self, H, risk):
        if not self.verify_chain(H.prov): return False
        if H.fw_hash not in self.allowlist and not reproducible(H): return False
        if not fresh(H.calibration): return False
        return self.trust(H.prov) >= tau_trust(risk)

    def audit(self, H, evidence):
        obs = observed_envelope(evidence)
        if conflicts(obs, H.cap):
            H.cap = intersect(H.cap, obs)        # 收缩，不扩张
            self.trust[H.prov] *= beta           # 下调信任
            if self.conflict_count[H.prov] >= k:
                self.quarantine(H.prov)
```

### IP-165 组合契约（CTC）

```python
def compose(chain):
    pre = chain[0].pre
    post = all_of([t.post for t in chain])
    env = intersect_all([t.env for t in chain])
    for a, b in zip(chain, chain[1:]):
        assert runtime_guard(lambda s: a.post(...) <= b.pre(...))
    # 并发：写集合不相交，否则按锁序串行
    for a, b in combinations(chain, 2):
        if writes(a) & writes(b):
            schedule_serial([a, b])
    return CompositeContract(pre, post, env, concat_wit(chain))
```

### IP-166 工具接地闭环（TGL）

```python
def tool_grounding_loop(M, call):
    tc = M.registry.resolve(call.name)
    if tc is None: return TypedError("E_UNKNOWN_TOOL")
    if not type_check(tc.sig, call.args): return TypedError("E_TYPE")
    if not tc.pre(call.args, M.state):    return TypedError("E_PRECOND")

    H = M.hw_pool.select(tc, M.task_context)
    degraded = not M.pa.admit(H, M.task_context.risk)
    if degraded: H = M.hw_pool.general()

    cmd = lower(tc, call.args, H)
    weakening = None
    if cmd is None:
        tc, cmd, weakening = relax_search(tc, call.args, H)
        if cmd is None: return TypedError("E_CAPABILITY")
        degraded = True

    if not M.budget.reserve_th(tc.cost): return TypedError("E_BUDGET")
    with M.ertc.lock(tc.env, call.deadline):
        result, evidence = execute(cmd, tc.wit)

    if not tc.post(call.args, result, evidence, M.state):
        return TypedError("E_POSTCOND")
```

**正确性定理（VTGC，Verifiable Tool Grounding Correctness）**

- **(A66)** 工具签名强类型且完备：每个物理副作用都有对应 Wit 字段；
- **(A67)** 对已认证硬件，HCM 在标定不确定度内准确；

1. **类型安全**：任何被执行的工具调用都满足 `discharge(c)`；未通过检查的调用不产生物理副作用。
2. **翻译可靠**：若 `L(TC,args,H)=cmd` 且执行满足 H 假设，则 Post 成立且 Env 不被突破。
3. **来源可靠**：未通过 `admit` 的清单只能进入保守包络；能力冲突观测只会收缩 `Cap`、降低 trust，不会扩权。
4. **组合安全**：`Env_chain = ⋂ Env_i` 且证据按 seq 因果序拼接；并发写冲突被串行化，组合后置条件逐段可见证。
5. **审计闭环**：每个成功的 ToolResult 携带可离线重放的 J_tool，并与 J_exec 组合成完整执行链；「成功」等价于「有见证的成功」。

### IP-161 TCR（工具契约运行时）

```python
class ToolContract:
    def __init__(self, name, sig, pre, post, env, wit, cost, rev, idem):
        self.name, self.sig, self.pre, self.post = name, sig, pre, post
        self.env, self.wit, self.cost = env, wit, cost
        self.rev, self.idem = rev, idem

class ToolRuntime:
    def invoke(self, call, state):
        if call.call_id in self.seen:                 # 幂等去重
            return self.seen[call.call_id]
        tc = self.registry.resolve(call.name)
        if tc is None: return TypedError("E_UNKNOWN_TOOL")
        if not type_check(tc.sig, call.args): return TypedError("E_TYPE")
        if not tc.pre(call.args, state):      return TypedError("E_PRECOND")

        H = self.hw_pool.select(tc, state)
        degraded = False
        if not self.pa.admit(H, risk=state.task_risk):
            H, degraded = self.hw_pool.general(), True

        cmd = lower(tc, call.args, H)
        weakening = None
        if cmd is None:
            tc, cmd, weakening = relax_search(tc, call.args, H)
            if cmd is None: return TypedError("E_CAPABILITY")
            degraded = True

        if not self.budget.reserve_th(tc.cost):
            return TypedError("E_BUDGET")
        if not self.ertc.can_lock(tc.env, call.deadline):
            return TypedError("E_DEADLINE")
        with self.ertc.lock(tc.env, call.deadline):
            result, evidence = execute(cmd, wit_spec=tc.wit)

        if not tc.post(call.args, result, evidence, state):
            return TypedError("E_POSTCOND", evidence=evidence)
        cert = build_jtool(tc, call, H, cmd, evidence, degraded, weakening)
        self.pa.audit(H, evidence)                    # 观测即审计
        out = ToolResult(result, cert, degraded, weakening)
        self.seen[call.call_id] = out
        return out
```

### IP-163 RCS（契约松弛搜索）

```python
RELAX_LATTICE = ["exact", "tighter_env", "weaker_post", "sample_only"]

def relax_search(tc, args, H):
    for level in RELAX_LATTICE[1:]:
        tc2 = relax(tc, H, level)
        if tc2 is None: continue
        assert tc2.env <= tc.env                 # 安全单调：只紧不松
        cmd = lower(tc2, args, H)
        if cmd is not None and witnessable(tc2, cmd):
            return tc2, cmd, {"level": level,
                              "weakened": diff(tc.post, tc2.post)}
    return None, None, None                      # ⇒ E_CAPABILITY
```

### IP-164 PAG（来源证明与审计）

```python
class ProvenanceGraph:
    def verify_chain(self, prov):
        return all(self.verify_sig(n) for n in self.ancestors(prov))

    def admit(self, H, risk):
        if not self.verify_chain(H.prov): return False
        if H.fw_hash not in self.allowlist and not reproducible(H): return False
        if not fresh(H.calibration): return False
        return self.trust(H.prov) >= tau_trust(risk)

    def audit(self, H, evidence):
        obs = observed_envelope(evidence)
        if conflicts(obs, H.cap):
            H.cap = intersect(H.cap, obs)        # 能力盒只收缩
            self.trust[H.prov] *= beta           # 信任下调
            if self.conflict_count[H.prov] >= k:
                self.quarantine(H.prov)          # 来源隔离
```

```python
def compose(chain):
    pre  = chain[0].pre
    post = all_of([t.post for t in chain])
    env  = intersect_all([t.env for t in chain])
    for a, b in zip(chain, chain[1:]):
```

```python
def tool_grounding_loop(M, call):
```

```python
class ToolHardwareBudget:
    def __init__(self, calls=32, lower_ops=200, attest_ops=20, exec_budget=None):
        self.B_call, self.B_lower = calls, lower_ops
        self.B_attest = attest_ops
        self.B_exec = exec_budget or ExecBudget()
        self.used = {"call": 0, "lower": 0, "attest": 0}

    def reserve_th(self, cost):
        if self.used["call"] + cost.d_call > self.B_call:
            return False
        if self.used["lower"] + cost.d_lower > self.B_lower:
            return self._fallback_precompiled()

        self.used["call"]  += cost.d_call
        self.used["lower"] += cost.d_lower
        self.used["attest"] += cost.d_attest
        return True

    def mode(self):
        if self.used["call"] >= self.B_call:   return "readonly_tools"
        if self.used["attest"] >= self.B_attest: return "cached_profiles_only"
        return "normal"
```
