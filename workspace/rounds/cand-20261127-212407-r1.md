### 第 4 轮灵感驱动研究记录

**灵感词**：虚拟仿真、知识图谱

**继承关系**：第 3 轮 CADVS-v3（IP-485~488）在 v2 三锚点（空间 3DCF / 物理 MSRG / 人因 HICK）上追加末点锚 EEK（kc_ee）与记忆锚 LTEM（kc_mem），并以 FFA 做联邦校准，形成五硬门 kc_evidence_forged_v3 = kc_coverage ∧ kc_physics ∧ kc_human ∧ kc_ee ∧ kc_mem，执行集 Exec_CADVS-v3 ⊆ Exec_CADVS-v2 ⊆ Exec_CADVS-v1 ⊆ Exec_v29。本轮不推翻 v3，而是用「虚拟仿真」补强证据的**获取方式**（主动证伪而非被动采信），用「知识图谱」补强证据的**作用域**（证书允许泛化到哪些上下文），形成 CADVS-v4（IP-489~492），执行集再收缩为 Exec_CADVS-v4 ⊆ Exec_CADVS-v3。

**直觉与动机**：

1. **虚拟仿真：把仿真从「物理验证的背景板」变成「主动证伪的对手」**。v2/v3 的 MSRG 只在规则入库时做一次 MuJoCo 判定，本质是「标称点验证」；真实失败常出现在参数边缘（摩擦、质量、延迟、传感器噪声），而非标称点。虚拟仿真便宜、可并行、可对抗搜索，因此它最可靠的角色不是「证明安全」，而是「寻找反例」：在域随机化的参数包络 Θ_plausible 内主动搜索使规则失败的 θ_sim，产出虚拟反例证书 VCC。关键设计是**单侧性（one-sidedness）**：仿真找到落在实机包络内的反例 → 硬拒绝（反例是构造性的，可信）；仿真没找到反例 → 不授予任何正证据，只表示「暂未证伪」。这样虚拟仿真只能收缩执行集，绝不能扩张，避免 sim-to-real gap 把「仿真通过」洗成「实机安全」。为了让「未找到反例」有一点意义，必须声明保守仿真包络 Θ_real ⊆ Θ_sim 与迁移证书；若包络不可信，kc_sim 直接 fail-closed。

2. **知识图谱：把证书从「单点事实」变成「带作用域的断言」**。一张证书 c 是在某些上下文 supp(c) 上真正铸造的；但规则常被复用到「看起来一样」的新物体/新场景。v3 的 kc_coverage 只问「此处是否被观测」，并不问「这条证书的语义作用域是否覆盖此处」。构建类型化证书知识图谱 CKG，节点为物体类/实例/上下文/规则/证书/失效模式，边带泛化强度（等价 ≃ > 特化 ⊑ > 相似 ≈）。核心是**证据传播的不对称性**：负证据（失败）可沿特化边向上传播（特例失败 ⇒ 通例不能宣称全称有效），正证据（成功）绝不沿相似边传播，除非每条边都附带可核验的等价/特化证明。这样既能让一次失败及时「污染」整类、防止重复授信，又能阻止「语义洗白」（把 A 的成功借给相似的 B）。

3. **两者的耦合：仿真提出假设，图谱限定作用域，实机铸造证据**。虚拟仿真给出「哪里最可能失败」的先验风险图 R_v(x)，知识图谱给出「哪些上下文语义上属于同一族」。用 R_v 与覆盖不确定度 U(x) 做主动实机采样（SGACA），把昂贵的真实探测投到仿真最怀疑、图谱上又尚未被真实覆盖的上下文；虚拟风险图只用于调度，永远不作为证据。闭环为：仿真提出假设 → 图谱限定作用域 → 实机铸造证据 → 反例回灌图谱与仿真。

**关键洞见**：v3 的五锚点回答「证据是否真实、是否可靠」；v4 追加两件事——**证据能否被廉价地主动攻击**（VCSK 单侧证伪）与**证据的语义作用域是否被越界使用**（CKG 泛化守卫）。二者共同把「证据铸造」从「收集正例」转为「可证伪 + 可界定」。七硬门 kc_evidence_forged_v4 = kc_evidence_forged_v3 ∧ kc_sim ∧ kc_kg，fail-closed；ECS_v4 仅作分级与仪表盘，不参与安全决策。

**形式化目标（增量）**：
1. 定义虚拟反例证书 VCC = (rule_id, θ_sim, x, y ∈ {fail, pass}, envelope, sim_version, t) 与保守包络假设 Θ_real ⊆ Θ_sim；定义 kc_sim = envelope_trusted ∧ ¬∃ 反例落在 x 的实机包络内。未找到反例不等于正证据，仅表示「未被证伪」。
2. 定义证书知识图谱 CKG = (V, E, τ, ≺)，边泛化强度 ≺ 为等价 ≃、特化 ⊑、相似 ≈ 的偏序；定义负证据向上传播 risk↑、正证据隔离；定义 kc_kg = 存在已铸造支持路径 ∧ 无未消解的下位反例 ∧ 正支持路径不含仅相似边。
3. 定义仿真引导主动覆盖 SGACA：虚拟风险图 R_v(x) 与覆盖不确定度 U(x)，采样 x* = argmax_x R_v(x)·U(x)，仅作调度不作证据；给出加权覆盖的子模贪心 (1−1/e) 保证。
4. 定义 EFA-v4 七硬门与软评分 ECS_v4 = ECS_v3 · η_sim · η_kg（软层仅记录仿真支持度与图谱作用域完整度）。
5. 定义 Exec_CADVS-v4 = Exec_CADVS-v3 ∩ {kc_sim = 1} ∩ {kc_kg = 1} ⊆ Exec_CADVS-v3，严格收缩。

**本轮最大风险**：**「推理洗白」**——虚拟仿真的 sim-to-real 包络与知识图谱的相似/特化边，都是「未经实机观测的推理」；一旦包络被错误声明为保守、或图谱边被错误标注为等价，系统就会在形式上收缩执行集的同时，悄悄把从未被真实证据覆盖的上下文重新放行，这是比 v3 联邦伪神谕更隐蔽的证据链断裂。

### IP-489 VCSK：虚拟反例搜索与单侧证伪门（准入前，离线可缓存）

```python
@dataclass
class VirtualCounterfactualSimulationKernel:
    """VCSK：域随机化对抗搜索反例；kc_sim 只拒不放，绝不授予正证据"""
    n_rollouts: int = 256
    n_adv_steps: int = 32
    sim_version: str = "mujoco-3.x/mjx"
    envelope_trusted: bool = True       # 由离线 sim-to-real 标定给出
    failure_margin: float = 0.0         # 判定失败的代价裕度

    def plausible_envelope(self, x) -> ParameterSet:
        """从实机日志估计 x 的 Θ_plausible（分位数包络）；不可估计时返回 None"""
        ...

    def adversarial_search(self, rule_id: str, x, env: ParameterSet) -> list[VCC]:
        """以 CEM/随机射击在 env 内搜索使 rollout 失败的最小反例"""
        counterexamples = []
        for theta in self._sample(env, self.n_rollouts):
            y = self._rollout(rule_id, x, theta)
            if y.cost > y.budget + self.failure_margin:
                counterexamples.append(VCC(rule_id, theta, x, 'fail',
                                           env.fingerprint, self.sim_version, y.t))
        return counterexamples

    def kc_sim(self, rule_id: str, x) -> tuple[bool, str]:
        """单侧门：反例 ⟹ 拒；无保存包络 ⟹ 拒；无保存反例 ⟹ 仅表示未被证伪"""
        if not self.envelope_trusted:
            return False, 'SIM_ENVELOPE_UNTRUSTED'
        env = self.plausible_envelope(x)
        if env is None:
            return False, 'SIM_ENVELOPE_UNKNOWN'
        cex = self.adversarial_search(rule_id, x, env)
        if cex:
            return False, 'SIM_COUNTEREXAMPLE'
        return True, 'NOT_FALSIFIED'    # 注意：不是 PASS，不得写入正证据集

    def update_from_real_failure(self, rule_id, x, eec: EEC):
        """实机失败反例回灌：收紧包络、写 CKG FailureMode、作为下一轮搜索种子"""
        ...
```

**设计要点**：kc_sim 的输出语义只有 `REJECT` 与 `NOT_FALSIFIED` 两种，永远没有 `CERTIFIED`。规则准入流程把 `NOT_FALSIFIED` 视为「允许继续申请 v3 五门」，而不是「仿真已证明」。这样即使 sim-to-real 偏移，最坏情况也只是漏拒，而不会误放。

### IP-490 CKG：证书知识图谱与泛化守卫（准入/切换/复用）

```python
@dataclass
class CertificateKnowledgeGraph:
    """CKG：负证据向上传播、正证据隔离；kc_kg 阻止跨相似边的语义洗白"""
    graph: nx.MultiDiGraph                # 节点带 type；边带 τ ∈ {≃, ⊑, ≈} 与 proof_id
    support: dict[str, frozenset]         # cert_id -> supp(cert)（真实铸造上下文）
    failures: dict[str, set]              # rule_id -> 已观测失败的上下文

    def has_support_path(self, rule_id: str, x) -> bool:
        """正支持：x ∈ supp(c)，或存在从 supp(c) 出发、每步为 ≃/⊑ 且证明已消解的路径"""
        for cert in self.certs_for(rule_id):
            if x in self.support[cert]:
                return True
            for y in self.support[cert]:
                if self._sound_path(y, x):   # 只允许 ≃ / ⊑，且 proof_id 已核验
                    return True
        return False

    def negative_closure(self, x) -> set:
        """负证据：x 的下位特化失败向上传播（特例失败 ⇒ 通例不能全称有效）"""
        return {f for f in self.failures_of_descendants(x)}

    def kc_kg(self, rule_id: str, x) -> tuple[bool, str]:
        if not self.has_support_path(rule_id, x):
            return False, 'KG_NO_SUPPORT'          # 未铸造 / 泛化无证明
        if self.negative_closure(x):
            return False, 'KG_NEG_CONFLICT'        # 下位反例未消解
        if self._positive_path_uses_similarity(rule_id, x):
            return False, 'KG_SEMANTIC_LAUNDERING' # 成功不得借相似边外推
        return True, 'KG_SCOPED'

    def ingest_failure(self, rule_id, x, eec: EEC):
        """失败入库：写 FailureMode，向上标记 risk↑，并触发受影响证书的降权/重验"""
        ...
```

**不对称性规则**（引理 42 的核心）：
- `≃` 边：可双向承载正/负证据，但每条边必须有可核验的等价证明（proof_id）。
- `⊑` 边：负证据由特化指向泛化（向上）传播；正证据由泛化指向特化（向下）传播，但必须证明规则在该特化上闭合。
- `≈` 边：只允许负证据传播（相似物体失败 → 提醒排查），**永不承载正证据**。

### IP-491 SGACA：仿真引导主动覆盖（慢时域，不在控制环）

```python
@dataclass
class SimulationGuidedActiveCoverage:

    scf: SpatialCoverageFieldKernel

    def virtual_risk(self, x) -> float:
        """R_v(x)：仿真集合失败率（含对抗反例密度的平滑）"""
        ...

    def uncertainty(self, x, t_now) -> float:
        """U(x)：体素样本数、τ_rec 衰减、邻域方差的合成不确定度"""
        ...

    def select_next(self, candidates) -> Context:
        """加权覆盖是单调子模函数，贪心达到 (1−1/e)·OPT（Nemhauser et al.）"""
        return max(candidates, key=lambda x: self.virtual_risk(x) * self.uncertainty(x, self.t))
```

**关键约束**：SGACA 只输出「下一批实机探测点」，不写入任何证书。其收益是减少达到目标覆盖所需的真实探测次数；其风险是若 R_v 系统性错误，会把探测预算集中在仿真已知的失效模式上，形成「未知的未知」盲区（见 R49）。

### IP-492 EFA-v4：七硬门 + 软评分 + 证据铸造流水线 v4

```python
@dataclass
class EvidenceForgingAssemblerV4:
    """EFA-v4：七硬门 fail-closed；软评分仅分级，不参与安全决策"""
    scf: SpatialCoverageFieldKernel
    msrg_cache: dict
    hic: HumanIntentCertificateKernel
    eek: EndEffectorFidelityKernel
    ltem: LongTermEpisodicMemory
    vcsk: VirtualCounterfactualSimulationKernel
    ckg: CertificateKnowledgeGraph
    mu_S: float = 0.75

    def hard_gate(self, x, t_now, rule_id, hic, eec: EEC,
                  object_class, geo_sig, theta_domain_fp) -> tuple[bool, str]:
        if self.hic.veto_active(hic):            return False, 'HIC_STOP'
        if not self.scf.kc_coverage(x, t_now):   return False, 'COVERAGE_BLIND'
        s2rc = self.msrg_cache.get(rule_id)
        if s2rc is None or s2rc.verdict != 'accept' or s2rc.mu_pass < self.mu_S:
            return False, 'PHYSICS_UNPROVEN'
        if not self.eek.kc_ee(eec):              return False, 'EE_UNPROVEN'
        pass_mem, eta_mem, novelty = self.ltem.query(
            object_class, geo_sig, theta_domain_fp, rule_id)
        if not pass_mem:                         return False, 'MEMORY_REJECT'
        ok_sim, why_sim = self.vcsk.kc_sim(rule_id, x)
        if not ok_sim:                           return False, why_sim
        ok_kg, why_kg = self.ckg.kc_kg(rule_id, x)
        if not ok_kg:                            return False, why_kg
        return True, 'FORGED' + ('|NOVELTY' if novelty else '')

    def ecs_v4(self, x, t_now, rule_id, A_att=0.0, eta_mem=0.5,
               eta_sim=1.0, eta_kg=1.0) -> float:
        base = (self.scf.gamma3d(x, t_now)**0.4
                * getattr(self.msrg_cache.get(rule_id), 'mu_pass', 0.0)**0.4
                * (1 + 0.2*A_att))
        return base * eta_mem * eta_sim * eta_kg
```

```
      ├─ HIC_STOP            → S_stop（MSRV 预验证制动集）
      ├─ COVERAGE_BLIND      → 回退 STCK 球域 + SGACA 探测请求 + 教师
      ├─ PHYSICS_UNPROVEN    → 规则降权（统计模式）
      ├─ EE_UNPROVEN         → 末端复位/重触 + 教师
      ├─ MEMORY_REJECT       → 教师介入或重新 MSRG
      ├─ SIM_COUNTEREXAMPLE  → 规则禁用 + 反例回灌 + 重新设计
      ├─ SIM_ENVELOPE_*      → 仿真包络不可信，退回 v3 并人审
      └─ KG_NO_SUPPORT / KG_NEG_CONFLICT / KG_SEMANTIC_LAUNDERING
```

## 4. 正确性论证（增量更新）

### 引理 41（虚拟仿真的单侧证伪与保守包络）

**陈述**：设真实失败参数集 F_real(r,x) = {θ ∈ Θ_real : rollout_real(r,x,θ) 失败}，仿真失败集 F_sim 同理。若 (a) 保守包络 Θ_real ⊆ Θ_sim，且仿真对包络内行为是过近似（F_real ⊆ F_sim）；(b) 反例判定精确（无漏检）。(i) 则 `F_sim ∩ Θ_plausible = ∅ ⟹ F_real ∩ Θ_plausible = ∅`（通过可安全外推）。(ii) 若 (a) 不成立，则 kc_sim 通过不提供任何实机保证，但 kc_sim 拒绝仍然保守安全。(iii) 无论 (a) 是否成立，VCSK 只增加拒绝、不增加通过，故 Exec_CADVS-v4 ⊆ Exec_CADVS-v3。

**证明**：(i) 由 F_real ⊆ F_sim 与交集单调性直接得。(ii) 拒绝是对仿真实证反例的响应，最多误拒，不会误放。(iii) kc_sim 是施加在 v3 已通过路径上的合取过滤项，且其「通过」分支不写入正证据、不放宽任何 v3 门。∎

**工程含义**：虚拟仿真被严格限定为「证伪器」。安全性的代价从「仿真必须正确」降为「仿真反例必须可信」，后者只需构造性反例即可，不依赖 sim-to-real 的完整保真。

### 引理 42（知识图谱的不对称传播与泛化守卫）

**陈述**：在 CKG 语义下，(a) 若规则 r 在 y 失败且 y ⊑ x（y 是 x 的特化），则 r 不是 x 上的全称有效规则；负证据沿 ⊑ 向上传播只删除路径，是 sound 的。(b) 若仅存在相似边 y ≈ x 而无等价/特化证明，则 y 上的成功不能推出 x 上的成功；禁止正证据跨 ≈ 传播不损失 soundness。(c) kc_kg 通过 ⟹ 存在一条由已核验 ≃/⊑ 边构成的支持链；其不健全接受概率 ≤ Σ_e P(proof_e 失效)（并集界）。

**证明**：(a) 反证：若 r 在 x 全称有效，则对任意特化 y ⊑ x 必有效，与 y 失败矛盾。(b) 相似关系不保语义等价，存在反例使成功不迁移，故禁止是必要的保守化。(c) 支持链每个 proof_id 对应一个可核验义务，任一失效即链断；并集界给出总体失效概率上界。∎

**工程含义**：一次特例失败会「污染」整类，避免 v3 在相似上下文重复授信；而成功不会自动外推，堵住「语义洗白」通道。

### 引理 43（仿真引导主动覆盖的近似保证与脆弱性）

**陈述**：设目标为加权覆盖 f(S) = Σ_x w(x)·1[x ∈ N(S)]，w(x) = R_v(x)，N(S) 为已探测点的覆盖邻域。f 单调子模，SGACA 的贪心选择满足 f(S_greedy) ≥ (1−1/e)·f(S_OPT)。但若 R_v 与真实失败分布系统性偏离，则贪心优化的是错误目标，可能遗漏高真实风险区域。

**证明**：加权覆盖是标准单调子模函数（Nemhauser–Wolsey–Fisher）；贪心 (1−1/e) 保证成立。脆弱性由目标函数误设直接给出，不构成 soundness 结论。∎

**工程含义**：SGACA 只应作为「探测预算分配器」，其输出必须与均匀/分层采样的对照共同使用，以防仿真先验造成覆盖盲区。

### 定理 v4（执行集收缩与七锚点补全）

**陈述**：在假设 (B1)~(B4)（继承 v3）以及 (B5) 仿真保守包络 Θ_real ⊆ Θ_sim 且 envelope_trusted 的标定有效；(B6) CKG 的 ≃/⊑ 边语义正确、proof 义务可核验；则：
(i) Exec_CADVS-v4 ⊆ Exec_CADVS-v3 ⊆ Exec_CADVS-v2 ⊆ Exec_CADVS-v1 ⊆ Exec_v29（严格收缩）；
(ii) 在包络内，kc_sim 通过 ⟹ 无真实反例（引理 41）；
(iii) 已知下位失败不会通过相似边被正证据抵消，泛化接受有可核验支持链（引理 42）；
(iv) SGACA 在正确风险图下达到加权覆盖的 (1−1/e) 近似（引理 43）；
(v) 七硬门 fail-closed，任一不通过即拒，仅 HIC veto 旁路至 S_stop。

**证明**：(i) v4 在 v3 每条路径上追加 kc_sim 与 kc_kg 两个合取项，只删不增；严格性由 v3 中存在「未被仿真证伪但实机打滑/越界」的路径在 v4 被拒保证。(ii) 引理 41(i)。(iii) 引理 42。(iv) 引理 43。(v) 由 EFA-v4.hard_gate 的短路合取结构直接得。∎

**诚实声明**：(B5) 与 (B6) 是本轮最脆弱假设。(B5) 的「保守包络」难以被实证证明——只能在有限工况上标定 envelope_trusted；一旦真实动力学落在 Θ_sim 之外，kc_sim 的「通过」就退化为无保证，但由于它从不授予正证据，最坏后果是漏拒而非误放，这是单侧设计换来的安全性。(B6) 的图谱边可能被错误标注或投毒，因此所有 ≃/⊑ 边必须绑定可核验 proof_id，高风险规则禁止仅凭图谱复用。

## 5. 实验设计与初步结果（计划中，第 5 轮实机）

### 5.1 实验设计

- **平台**：MuJoCo 3.x + MJX 域随机化（摩擦 0.2–1.2、质量 ±20%、控制延迟 0–20 ms、力噪声 σ_f∈[0.5,2] N）+ N 台实机 Panda（N=3~5）；知识图谱由 YCB 物体分类层级 + 规则本体半自动构建（约 300 节点、900 边）。
- **对照**：v3-full、v4-full、消融 C1（去 VCSK）、C2（去 CKG）、C3（去 SGACA，均匀采样）、C4（把 kc_sim 误用为双侧「仿真通过即放行」的错误变体，用于暴露推理洗白）。
- **协议**：
  (a) **sim-to-real 越界**：在实机注入仿真包络外的摩擦/延迟，测 kc_sim 误放率；预期正确变体为 0，C4 显著升高。
  (b) **语义洗白攻击**：向图谱注入「杯子 ≈ 碗」「圆柱 ≈ 棱柱」等错误相似边，尝试把已铸造证书外推到未观测物体，测 kc_kg 阻断率。
  (c) **负证据传播**：令某子类（如带柄杯）连续失败，检查父类规则是否被正确限制，而非继续全类授信。
  (d) **主动覆盖效率**：比较 SGACA、均匀采样、纯不确定度采样达到 95% 覆盖所需实机探测次数。
  (e) **准入延迟**：VCSK 256 rollouts 的缓存命中/未命中两种路径，验证 < 2 s/规则。
- **指标**：全门通过但实机失败率（false accept）、过度拒绝率、语义洗白阻断率、达到目标覆盖的探测次数、准入 P50/P99 延迟、ECS_v4 与失败的 AUC、图谱支持链证明覆盖率。

## 7. 本轮最大风险（最终确认）

**一句话**：**「推理洗白」**——虚拟仿真的 sim-to-real 包络与知识图谱的相似/特化边，都是「未经实机观测的推理」；一旦包络被错误声明为保守、或图谱边被错误标注为等价，系统就会在形式上收缩执行集的同时，悄悄把从未被真实证据覆盖的上下文重新放行，这是比 v3 联邦伪神谕更隐蔽的证据链断裂。
