# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「安全性」×「自适应控制」）

> R69 把不确定性一分为二，并让系统学会「问」：看、问、触、等，都是可生成、可认证、可审计的信息动作。但 R69 有一个结构性盲点：**它给每一个「动作」发了安全证书，却没有给「改变信念/参数」这件事本身发证书。** R69 的 VoI 交互、模态权重更新、交互成本先验、在线校准，本质上全是**在线自适应**——而自适应控制半个世纪的核心教训是：**自适应律本身就在反馈回路里；一个在固定参数下稳定的系统，加上自适应就可能发散**（Rohrs 反例；参数漂移与 bursting）。R69 自陈的「模态分布不可信、VoI 在错误信念上计算」不是单纯的数据问题，而是**它把自适应当成了免费的午餐**。
>
> 更尖锐地说，R69 在整条 RAS 谱系里**第一次引入了「向上的」安全调整**：resolution bonus 允许消歧后把 λ 从 `λ_floor(U_ale+U_epi)` 放松到 `λ_floor(U_ale)`。R66–R68 全都是「只收紧」，所以安全性是单调的；R69 打开了唯一的放松通道，却没有给这条通道装**棘轮**。一旦模态被幻觉或投毒污染，系统会「合法地」把安全裕度越放越大。
>
> 本轮两个灵感正好是解药：
> - **自适应控制**回答「什么样的学习才是安全的」：持久激励、投影/σ-泄漏/死区、驻留时间与滞回、非伪证切换、抗积分饱和；以及最重要的——**谨慎对偶控制（cautious dual control）**：探测与稳定必须一起优化，而不是先探测再补救。
> - **安全性**回答「用什么兜底」：控制屏障函数（CBF）不变式、Simplex/运行时保证、独立监护、可回滚、双钥匙扩张。安全不能依赖模型正确，只能依赖**架构**。
>
> 核心命题：**把 R69 的「动作级安全」升级为「闭环级安全」——快环零学习、只跑经认证的基线与安全滤波；慢环才允许自适应，但每一次参数更新都必须持有一张可撤销的「自适应许可证」（充分激励 ∧ 有界增益 ∧ 投影/死区 ∧ 非伪证 ∧ 回滚点）。安全包络只可收紧，扩张必须两把钥匙。** 命名 **AEGIS-RAS**（Adaptive Envelope-Guarded Invariant Safety）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**求证之后，我凭什么相信这个改变是安全的**」——不是所有学到的东西都配进入安全回路。

## 0. 直觉与动机

**灵感 1（自适应控制 → 学习是反馈，不是附加物）**
直觉：R69 把交互当成「查一下再决定」的准离线动作，但系统查完之后会更新模态权重、成本先验、校准偏移——这些更新会改变下一时刻的控制器，所以它**已经在闭环里了**。自适应控制最著名的反例（Rohrs 1985）说明：**未建模动态 + 缺乏激励 + 自适应 = 参数漂移，甚至发散**。这不是调参能解决的，是结构性的。R69 的「VoI 在错误信念上计算」正是参数漂移的现代版本。因此 R70 的第一原则是：**先给自适应发许可证，再让自适应发生。**

**灵感 2（安全性 → 安全是架构不变式，不是模型置信度）**
直觉：R69 的安全论证仍要依赖「流模型的模态分布可信」，而这恰好在最坏情况下不成立。真正工业级的安全（Simplex、runtime assurance）从不假设先进控制器正确：它永远保留一个**可认证的基线**，并让一个**架构上独立**的监护器在必要时切回基线。安全不是「我算出来不会撞」，而是「即使我算错，也有东西兜住」。这把 R69 的「可信度低就收紧」升级为「**无论可信不可信，基线都在**」。

**灵感 3（对偶控制 → R69 的 VoI 是「没有安全约束的探测」）**
直觉：R69 的 VoI 只最大化「信息增益 − 成本」，这是经典对偶控制里的 probing，但它漏掉了对偶控制真正的一半：**探测会改变状态，可能把系统推到危险区**。谨慎对偶控制的答案是：不确定性越大，控制增益越小；安全对偶控制还要再加一条：**只有探测提供的激励落在「会影响安全边界」的参数方向上时，这次探测才值得做**。于是 VoI 升级为 **SVoI（safety-relevant VoI）**：不是「能降低多少熵」，而是「能降低多少与安全相关的可辨识性」。

**灵感 4（棘轮 → R69 唯一的放松通道必须单向可撤销）**
直觉：R66–R68 的安全性来自单调收紧；R69 的 resolution bonus 是唯一的「向上」。任何向上的调整都应满足三条：**可撤销（有回滚点）、双钥匙（两个独立证书）、有驻留（不因一次侥幸就永久放宽）**。否则「消歧成功」会被投毒者改写成「合法扩权」。这把 R68 的「只收紧」从一条教条变成一个**热力学第二定律式的安全棘轮**：收紧随时可以，放松必须做功（出示证书）。一个具体例子：辅助外骨骼根据用户一句「我还好」把助力增益调大；若这句话来自一个被诱导或共谋的回答，增益会越调越高，最后在用户真正疲劳时造成跌倒。R69 的 per-action 认证拦不住，因为每一步都「合法」。

**灵感 5（安全性的两个面 → safety 与 security 在自适应层汇合）**
直觉：自适应层是最诱人的攻击面。攻击者不需要让车撞墙，只需要**慢慢地**把模态权重推向错误方向（温水煮青蛙）、让系统长期缺乏激励（excitation starvation）、或制造一次「恰好一致」的假证据。这些攻击在 R69 的 per-action 证书下全部合法。AEGIS 必须把「自适应投毒」纳入威胁模型，并用独立监护 + 回滚 + 双钥匙给出**概率上界**。

**灵感 6（对 R69 的一个诚实修正）**
直觉：R69 的定理 16 说「FLUID 期望风险 ≤ R68」，但这句话只有在把「过度保守造成的时效失败」也算作风险时才成立。AEGIS 把风险拆成两个不可混同的分量：`r_safe`（物理/安全违规）与 `r_live`（时效/活性/任务失败）。R68 的弱项是 `r_live`，FLUID 的弱项是 `r_safe`；AEGIS 的目标是**对 FLUID 安全占优、对 R68 活性占优**，而不是用一个含混的标量风险宣称全面更优。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（AEGIS-RAS 总览）** AEGIS-RAS = (TLS, SEC, LAG, XAG, UMS, SER, RAW, RAM, RAS-WM†)。四不变式：
(i) **快环零学习写**：安全回路（基线与安全滤波）在实时环内不更新任何参数（强化 R68 定义 276-i）；
(ii) **自适应许可证**：慢环任何对安全相关参数的更新，必须同时满足 充分激励 ∧ 有界增益 ∧ 投影/死区 ∧ 非伪证 ∧ 回滚点存在（定义 313–316）；
(iii) **安全棘轮**：认证安全包络只可收紧或保持；扩张必须两把钥匙（定义 318）；
(iv) **独立监护**：运行时监护器在架构、传感、训练数据上与先进控制器解耦，任何单点不得自证安全（定义 321）。

**定义 311（双时间尺度与参数分级）** 快环周期 τ_f（控制周期），慢环周期 τ_s ≥ 100·τ_f。参数 θ = (θ_safe, θ_perf)：θ_safe 为影响安全边界或风险缩放的参数（用于 VoI 的模态权重、标定偏移、λ floor 常数、边界估计）；θ_perf 为仅影响性能者（问句软提示、注视策略）。**θ_safe 只在慢环、且持证更新；θ_perf 可较快更新，但永远不得进入安全滤波。**

**定义 312（认证安全包络 SEC）** 状态 x，基线控制器 π_0（R68 保守策略）。安全集 𝒮_0 = {x : h(x) ≥ 0}，h 为控制屏障函数；π_0 使 𝒮_0 前向不变。认证包络 𝒮_cert(t) ⊆ 𝒮_0，由证书（离线可达集 + 在线监护）界定。安全滤波为 QP：`u* = argmin_u ‖u − u_adv‖²  s.t. h(x_{k+1}) ≥ (1−γ_b)h(x_k), u ∈ 𝒰`。**π_adv 只能提议，不能直接执行。**

**定义 313（持证自适应律 LAG）** `θ ← Proj_Θ( θ + η_t φ_t e_t · 1{|e_t| > d_t} )`，其中 e_t 为预测/校准残差，φ_t 为归一化回归向量，Proj_Θ 为投影到安全参数域，`d_t = κ_d·√U_ale`（死区：不超过 aleatoric 噪声底的残差一律不学），并叠加 σ-泄漏 `θ ← (1−σ)θ + σθ_prior`（防止无激励时漂移）。**无激励不更新，噪声内不更新，出域即投影。**

**定义 314（安全条件化增益）** `η_t ≤ γ_a·h(x_t) / (L_θ·‖φ_t‖·(1+‖θ_t−θ_prior‖))`，γ_a∈(0,1/2)。即**离安全边界越近，允许的适应步长越小**；当 h→0，η→0（冻结）。这与 R68 的 λ_floor 同构：不确定性进安全裕度，安全裕度反过来限制学习速度——**安全裕度是学习的预算。**

**定义 315（安全相关激励与 SVoI）** 参数 Fisher 信息 `F_g = Σ φφ^T`（在信息动作 g 下）。安全敏感方向 `s = ∂h/∂θ_safe`。**安全相关激励** `SE(g) = s^T F_g s / (1 + s^T F_g s)`。`SVoI(g) = H(θ_safe|o) − E_{y~p(·|g,o)}[H(θ_safe|o,y)]`，且只在 `SE(g) ≥ ε_PE` 时计入可用信息。R69 的 VoI 是 `SE≡1`、`θ_safe≡θ` 的特例。选 `g* = argmax_g [SVoI(g) − c(g)]`，s.t. `SE(g) ≥ ε_PE` 且认证通过。

**定义 316（非伪证自适应监督 UMS）** 候选模型/控制器集 ℳ = {M_0 (R68), M_1 (FLUID), …}；候选 j 的累积代价 `V_j(t) = Σ_k λ^{t−k}‖e_j(k)‖²`。只有当 `V_j(t) ≤ V_0(t) + δ_f` 时 M_j 才「未被伪证」。切换只允许发生在未伪证集合内；被伪证者进入冷却期，需新的激励证据才能重新入集。**不是「谁更自信用谁」，而是「谁没被数据否证用谁」。**

**定义 317（驻留时间与滞回切换）** 模态/控制器切换满足平均驻留时间 `τ_a ≥ ln μ / λ_0`（多 Lyapunov 函数稳定条件），并带滞回带 Δ_h：仅当新候选代价优于当前超过 Δ_h 才切换。禁止零驻留（Zeno）。**切换本身是一等公民**：每次切换记录证书与理由。

**定义 318（安全棘轮 SER 与双钥匙扩张）** 𝒮_cert 的更新规则：
- **收缩**：随时允许（安全侧单调）；
- **扩张**：必须同时持有 (K1) 离线/形式化证书（可达集或 CBF 条件在扩张区成立）与 (K2) 在线独立监护的持续无违反证据，且满足驻留时间 τ_exp 后才生效；
- 任一把钥匙失效 ⇒ 立即回滚到上一个 𝒮_cert。
**单点（包括流模型自身）永远不能单独扩张安全包络。**

**定义 319（可回滚自适应 RAW）** 慢环每次持证更新前，把 checkpoint `(θ, 𝒮_cert, 信念 b, 代价先验)` 写入不可变日志；证书失效/监护报警/攻击检测 ⇒ 原子回滚到 last-known-good（LKG）。**回滚路径本身不依赖被回滚的组件**（日志与恢复逻辑在独立分区）。

**定义 320（抗积分饱和 AWG）** 交互预算 b_t 与成本先验 c_t 采用条件积分/反算：当预算触界或 SVoI 长期为负时停止累积，避免 R69 的成本先验「饱和 → 永久不敢问」或「通胀 → 永久乱问」。

**定义 321（独立运行时保证 RAM）** 监护器 m 观测 `(x, h, 𝒮_cert, 日志哈希)`，与先进控制器在传感/特征/训练数据上至少一项独立。输出三值：Run-adv / Hold / Fallback(π_0)。切换依据是**证书谓词**而非模型置信度。定义失效相关性 ρ_fail<1：任何单点故障不得同时使 m 与 π_adv 失效。

**定义 322（自适应对抗干扰集 ℰ_adapt）** 慢推漂移（温水煮青蛙）、激励饥饿、伪一致证据（相关源共谋）、回放/重放、模态切换振荡攻击、证书重放。`ℰ_AEGIS = ℰ_FLUID × ℰ_adapt`。

**定义 323（证书 J_AEGIS）** `J_AEGIS = (J_FLUID, h_min, adaptation_license_hash, SE_stat, dwell_time, rollback_pointer, monitor_independence_proof, ratchet_state, aegis_ver)`。Valid ⇔ `Valid(J_FLUID) ∧ h_min ≥ 0 ∧ 许可证链完整 ∧ 驻留满足 ∧ 监护独立 ∧ 无未回滚报警`。

**定义 324（安全对偶控制目标）** 每个慢环步联合求解
`min_{u,g} E[ Σ cost_task + c(g) ]  s.t. 安全不变式(312)、SE(g) ≥ ε_PE、自适应许可证(313–316)`。
这是一个**约束对偶控制**：R68 是「g≡∅、η≡0」的顶点；R69 是「去掉安全约束、只留 VoI−c」的顶点；AEGIS 是二者可行域的交集。**谨慎（λ_floor）与探测（VoI）不再是两套逻辑，而是同一约束优化的两个乘子。**

**定义 325（非自证与两把钥匙的概率上界）** 若监护器与被监护者的失效相关性 ρ<1，单次欺骗成功概率 δ_p，则一次未被拦截的非法扩张概率 `≤ δ_p·ρ^{k−1} + δ_K1·δ_K2`，其中 k 为独立证据源数，δ_K1、δ_K2 为两把钥匙各自的漏检率。**扩张的安全性是乘积级，而非单点级。**

```python
# IP-264 TLS：快环（零学习写）+ 慢环（持证自适应）
def AEGIS_fast_loop(x, u_adv, u_base, cert, monitor):
    # 1) 独立监护：先看证书，不看模型置信度
    verdict = monitor.check(x, cert)                 # Run / Hold / Fallback
    u_ref = u_adv if verdict == "Run" else u_base
    # 2) CBF-QP 安全滤波：先进提议只能被投影，不能被直接执行
    u_safe = cbf_qp(x, u_ref, h, gamma_b, U)         # h(x_{k+1}) >= (1-gamma_b)h(x_k)
    # 3) 快环不写任何参数
    return u_safe

# IP-266 LAG：持证自适应（慢环，仅在许可证满足时）
def licensed_update(theta, phi, e, U_ale, h_x, cert):
    if not cert.valid:                     return theta, "no_cert"
    if not se_gate(cert.SE):               return theta, "no_excitation"
    d = kappa_d * sqrt(U_ale)              # 死区 = aleatoric 噪声底
    if abs(e) <= d:                        return theta, "dead_zone"
    eta = min(eta_max,
              gamma_a * h_x / (L_theta * norm(phi) * (1 + norm(theta - theta0))))
    theta_new = project(theta + eta * phi * e, Theta_safe)
    theta_new = (1 - sigma) * theta_new + sigma * theta0   # sigma-leakage
    return theta_new, "licensed"

# IP-267 XAG：SVoI 交互选择（只买安全相关的可辨识性）
def choose_interaction_safe(modes, w, o_t, budget, h_grad):
    best = None
    for g in info_action_candidates(modes):
        if not budget.allow(g) or not c_ras_wm.certify_info(g, o_t): continue
        SE = safety_relevant_excitation(g, h_grad)    # s^T F_g s
        if SE < EPS_PE: continue                      # 无安全激励不探测
        svoi = H_safe(w) - expected_H_safe(w, g, o_t)
        score = svoi - cost(g) - risk(g)
        if best is None or score > best.score: best = (g, score, SE)
    return best if best and best.score > 0 else None

# IP-268/269 SER/UMS：非伪证 + 滞回驻留 + 安全棘轮
def supervise(models, costs, S_cert, certs, dwell, monitor):
    unfalsified = [j for j in models if costs[j] <= costs[0] + DELTA_F]
    cand = argmin(costs[j] for j in unfalsified)
    if cand != current and dwell.ok() and costs[current] - costs[cand] > DELTA_H:
        current = cand; dwell.reset()
    if S_cert.expand_requested:
        if certs.K1 and monitor.no_violation_for(TAU_EXP) and certs.K2:
            S_cert = S_cert.expand()
        else:
            S_cert = rollback(S_cert)             # 单钥匙失效即回滚
    return current, S_cert

# IP-275 主闭环（快慢分离；继承 R68/R69）
def AEGIS_round(M, obs):

    x = M.state_est(obs)
    u_adv = M.last_safe_action                        # 上一慢环产出的认证动作
    u_base = M.r68.baseline(x)
    J = M.aegis.certificate(M)
    u = AEGIS_fast_loop(x, u_adv, u_base, J, M.ram)
    # ---- 慢环：FLUID + 持证自适应 ----
    z, o = M.mtm.forward(obs)
    c, U_cal, thr = M.cof.step(...)                    # R68 标定

    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o, M.last_o_cal)
    slow = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    # 安全相关激励门：无激励不交互、不学习

    # 许可证 + 有界增益 + 死区 + 投影 + 回滚点
    M.raw.checkpoint(M.theta, M.S_cert, M.belief, M.cost_prior)
    M.theta, lic = M.lag.licensed_update(M.theta_safe, M.phi, M.err,
                                         U_ale, M.h(x), J)
    # 安全棘轮：只有双钥匙 + 驻留才扩张，否则回滚
    M.S_cert = M.ser.update(M.S_cert, M.ram, M.dwell, J)
    # 风险缩放：未持证消解 = 未消解，回到 R68 边界
    U_floor = U_ale + (U_epi if (g is None or lic != "licensed") else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    if slow: lam = max(lam, 0.8)
    # 认证前缀 + 安全滤波前置校验
    A = M.ach.propose(x_prime, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, ..., M.wm_preds)
    mode = select_mode(modes, U_epi, lam, dwell=M.dwell)   # 滞回，防抖动
    tau = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_i.submit_async(g, U_epi, a_hat, J, lic)
    return k, lam, mode, (U_ale, U_epi), J
```

## 3. 推导

**引理 19（安全条件化增益 ⇒ 一步不变式）** 设基线滤波保证 `h(x_{k+1}) ≥ (1−γ_b)h(x_k)`，且 h 对 θ 的 Lipschitz 常数为 L_θ（A99）。若自适应增益满足定义 314，则一次参数更新引起 `|Δh_adapt| ≤ γ_a h(x_k)`，故 `h(x_{k+1}) ≥ (1−γ_b−γ_a)h(x_k) > 0`（取 γ_b+γ_a<1）。**即自适应不能把状态一步推出认证包络；h 越小时允许的更新越小，h→0 时更新冻结。** 系：安全裕度是学习率的硬上界——R69 缺少的正是这条耦合。

**引理 20（无激励冻结与参数最终有界）** 在投影 + σ-泄漏 + 死区 `d_t = κ_d√U_ale` 下，存在有界未建模动态时，参数误差 `‖θ−θ*‖` 最终有界，界为 `O((σ‖θ_prior‖ + d + η_unmodeled)/λ_leak)`；而去掉泄漏/死区后，存在 Rohrs 型未建模动态与慢推攻击使 `‖θ‖` 无界（参数漂移/bursting）。**R69 的「模态幻觉」恰是「无泄漏、无死区」的特例：它把 aleatoric 噪声也当成了学习信号。** 系：`U_ale` 不只用于风险收紧，也用于决定「什么时候不该学」。

**引理 21（SVoI 与激励-安全对偶）** 若 `SE(g) < ε_PE`，则 g 在安全敏感方向 s 上几乎不提供 Fisher 信息；`θ_safe` 的后验在该方向不被更新，任何参数改变都由先验/噪声驱动。于是 g 对 `r_safe` 的期望下降为 0，而 `risk(g) > 0`，故「不交互」严格占优。反之，**只降熵不增安全可辨识性的交互会制造「没有可辨识性的自信」**——这正是 R69 把「诚实的不知道」升级成「被证实的错误」的机制。系：VoI 应按 `s^T F_g s` 加权，而不是按总熵。

**引理 22（非伪证 + 驻留 ⇒ 无 Zeno 且切换稳定）** 滞回带 Δ_h>0 与平均驻留时间 `τ_a ≥ ln μ/λ_0` 使切换次数在任意有限区间内有界（无 Zeno）；多个 Lyapunov 函数满足 `V_σ(t) ≤ μ V_σ(t−)` 与衰减条件，故切换系统稳定（Liberzon 判据）。系：R69 的 `select_mode` 若不加滞回，会在两个近等权模态间以控制频率抖动；抖动本身就是一种未建模高频扰动，会反过来破坏自适应。

**定理 18（AEGIS 的安全-活性双占优与严格包含）** 在 A95–A99 下，定义 `r_safe`（安全违规概率）与 `r_live`（时效/任务失败概率）。则：
(i) `r_safe(AEGIS) ≤ r_safe(FLUID)`：因为 AEGIS 只删除了 FLUID 中「无证消解」与「非法扩张」这两类向上调整，安全侧是 FLUID 可行域的子集；
(ii) `r_live(AEGIS) ≤ r_live(R68)`：当许可证可得（SE≥ε_PE、双钥匙齐备、驻留满足）时，AEGIS 发放与 FLUID 相同的 resolution bonus，从而回收 R69 的效率；许可证不可得时退回 R68，故不劣于 R68；
(iii) 当 `SE<ε_PE`、`|e|≤d`、证书无效或监护报警时，AEGIS 与 FLUID/R68 **逐指令相同**（定义 313、318、321）。
故 R68 是「永不持证、永不扩张」的边界顶点，R69 是「无安全约束的探测」的边界顶点，AEGIS 是二者可行域的交，**对 FLUID 安全占优、对 R68 活性占优**。这修正了 R69 定理 16 把所有风险压成一个标量的含糊之处。

**定理 19（双钥匙 + 独立监护 ⇒ 非法扩张概率上界）** 由定义 325，一次非法扩张需同时通过 K1、K2 并熬过驻留 τ_exp，且不被独立监护拦截。若攻击者只能污染单一证据源，则 `P(非法扩张) ≤ δ_p·ρ^{k−1} + δ_K1·δ_K2`；若两条钥匙的失效模式独立（ρ_fail<1），乘积项使上界显著低于任一单钥匙方案。系：慢推漂移攻击被转化为「持续违反证据」——棘轮要求**持续**无违反而非单次幸运样本，故 R69 的「单次交互定案」漏洞在自适应层被关闭。

**定理 20（安全对偶控制的连续过渡）** 定义 324 的约束优化中，当 `h→0` 或 `SE→0` 时，可行探测集收缩为空，最优解连续收敛到 R68 的纯谨慎控制；当 `h` 充足且 `SE≥ε_PE` 时，约束不再绑定，最优解恢复 R69 的 resolution bonus。故 AEGIS 是 R68 与 R69 之间由「安全裕度 × 激励」参数化的同伦，**两端都是严格退化，中间不引入新的需要独立信任的黑箱**。

## 6. 本轮最大风险

**一句话**：AEGIS 把安全寄托在「独立监护 + 双钥匙」上，但**当监护器与被监护者共享传感器、共享训练分布、或遭遇共模故障时，独立性假设失效——「安全棘轮」与「可回滚」会同时失灵，盾牌自己需要盾牌，系统可能用一层新的不可证伪的元信任掩盖了原来的不可信**；其次，若棘轮过度保守，系统会永久冻结在 R68，AEGIS 退化为一个昂贵的安全壳，白付了慢环与证书的复杂度。

**次级风险与缓解**：
1. **共模故障**（共享传感器/训练数据）→ 定义 321 的独立性证据 + 多样性冗余 + E311 注入共模故障；独立性无法证明时按「不独立」处理，退回单钥匙收紧。
2. **双钥匙被协同欺骗** → 定义 325 的乘积上界 + K1/K2 使用不同证据族 + 驻留 τ_exp + 回滚；E306/E309 对抗测试。
3. **棘轮过度冻结（活性损失）** → 显式的 `r_safe–r_live` Pareto 目标（E315）+ 定期「证书化扩张」窗口 + 人类可审计的扩张请求。
4. **慢环延迟与快慢不一致** → 证书总线只传「已验证的常量」，快环不等待慢环；慢环超时即视为无证，回退 R68。
5. **安全参数的维度爆炸** → 只对 `s = ∂h/∂θ_safe` 敏感的低维子空间做 SE 统计，其余参数划入 θ_perf，不进安全回路。

**定义 316–317（非伪证与驻留切换）** 候选 j 未伪证 ⇔ `V_j≤V_0+δ_f`；切换只在未伪证集合内，带滞回 Δ_h 与平均驻留 `τ_a≥lnμ/λ_0`；禁止 Zeno，每次切换留证书。

**定义 318（安全棘轮与双钥匙扩张）** 收缩随时；扩张需 (K1) 离线/形式化证书 ∧ (K2) 在线独立持续无违反 ∧ 驻留 τ_exp；任一失效即回滚。单点（含流模型）不可单独扩张。

**定义 319–320（可回滚与抗积分饱和）** 持证更新前 checkpoint `(θ,𝒮_cert,b,c_prior)` 入不可变日志，报警即原子回滚 LKG；预算/成本先验用条件积分/反算，避免冻结或通胀。

**定义 321（独立运行时保证）** 监护器 m 观测 `(x,h,𝒮_cert,日志哈希)`，与 π_adv 在传感/特征/训练数据至少一项独立；输出 Run/Hold/Fallback(π_0)；按证书谓词切换；ρ_fail<1。

**定义 322–323（攻击集与证书）** `ℰ_AEGIS=ℰ_FLUID×ℰ_adapt`；`J_AEGIS=(J_FLUID,h_min,license_hash,SE_stat,dwell,rollback_ptr,independence_proof,ratchet_state,ver)`，Valid ⇔ 各项满足且无未回滚报警。

**定义 324–325（安全对偶控制与概率上界）** `min_{u,g}E[Σcost_task+c(g)] s.t. 不变式∧SE≥ε_PE∧许可证`；R68 是「g≡∅,η≡0」顶点，R69 是「去安全约束」顶点。非法扩张概率 `≤δ_p ρ^{k−1}+δ_K1 δ_K2`。

```python
# IP-264/265/272 TLS+SEC+RAM：快环（零学习写）
def AEGIS_fast_loop(x, u_adv, u_base, cert, monitor):
    verdict = monitor.check(x, cert)                  # Run / Hold / Fallback
    u_ref = u_adv if verdict == "Run" else u_base
    return cbf_qp(x, u_ref, h, gamma_b, U)            # h(x+) >= (1-gamma_b)h(x)

# IP-266 LAG：持证自适应（慢环）
def licensed_update(theta, phi, e, U_ale, h_x, cert):
    if not cert.valid:          return theta, "no_cert"
    if not se_gate(cert.SE):    return theta, "no_excitation"
    d = kappa_d * sqrt(U_ale)                          # 死区 = aleatoric 底
    if abs(e) <= d:             return theta, "dead_zone"
    eta = min(eta_max, gamma_a*h_x/(L_theta*norm(phi)*(1+norm(theta-theta0))))
    theta = project(theta + eta*phi*e, Theta_safe)
    theta = (1-sigma)*theta + sigma*theta0             # sigma-leakage
    return theta, "licensed"

# IP-267 XAG：SVoI 交互（只买安全相关可辨识性）
def choose_interaction_safe(modes, w, o_t, budget, h_grad):
    best = None
    for g in info_action_candidates(modes):
        if not budget.allow(g) or not c_ras_wm.certify_info(g, o_t): continue
        SE = safety_relevant_excitation(g, h_grad)
        if SE < EPS_PE: continue
        score = (H_safe(w) - expected_H_safe(w, g, o_t)) - cost(g) - risk(g)
        if best is None or score > best.score: best = (g, score, SE)
    return best if best and best.score > 0 else None

# IP-268/269 SER+UMS：非伪证 + 滞回驻留 + 棘轮
def supervise(models, costs, S_cert, certs, dwell, monitor):
    unfalsified = [j for j in models if costs[j] <= costs[0] + DELTA_F]
    cand = argmin(costs[j] for j in unfalsified)
    if cand != current and dwell.ok() and costs[current]-costs[cand] > DELTA_H:
        current = cand; dwell.reset()
    if S_cert.expand_requested:
        if certs.K1 and monitor.no_violation_for(TAU_EXP) and certs.K2:
            S_cert = S_cert.expand()
        else:
            S_cert = rollback(S_cert)                  # 单钥匙失效即回滚
    return current, S_cert

# IP-275 主闭环（快慢分离，继承 R68/R69）
def AEGIS_round(M, obs):
    # 快环：只读证书，零学习写
    x = M.state_est(obs)
    J = M.aegis.certificate(M)
    u = AEGIS_fast_loop(x, M.last_safe_action, M.r68.baseline(x), J, M.ram)

    # 慢环：FLUID + 持证自适应
    z, o = M.mtm.forward(obs); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o, M.last_o_cal)
    slow  = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    g = (M.mint.choose_interaction_safe(modes, M.budget, M.h_grad)
         if (U_epi > TAU_EPI and not slow and M.xag.se_gate(z, modes)) else None)
    if g is not None:
        U_epi = M.cia.update_belief(modes, M.cia.execute(g))   # k-正交证据纪律
    M.raw.checkpoint(M.theta, M.S_cert, M.belief, M.cost_prior)
    M.theta, lic = M.lag.licensed_update(M.theta_safe, M.phi, M.err, U_ale, M.h(x), J)
    M.S_cert = M.ser.update(M.S_cert, M.ram, M.dwell, J)
    U_floor = U_ale + (U_epi if (g is None or lic != "licensed") else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    if slow: lam = max(lam, 0.8)
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., M.wm_preds)
    mode = select_mode(modes, U_epi, lam, dwell=M.dwell)       # 滞回防抖
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_i.submit_async(g, U_epi, a_hat, J, lic)
    return k, lam, mode, (U_ale, U_epi), J
```

## 4. 推导

**引理 19（安全条件化增益 ⇒ 一步不变式）** 基线滤波保证 `h(x_{k+1})≥(1−γ_b)h(x_k)`；h 对 θ 的 Lipschitz 常数 L_θ。定义 314 的 η 使 `|Δh_adapt|≤γ_a h(x_k)`，故 `h(x_{k+1})≥(1−γ_b−γ_a)h(x_k)>0`（γ_b+γ_a<1）。系：**自适应不能一步推出认证包络；h→0 时更新冻结，安全裕度是学习率的硬上界。**

**引理 20（无激励冻结与参数最终有界）** 投影 + σ-泄漏 + 死区 `d=κ_d√U_ale` 下，存在有界未建模动态时 `‖θ−θ*‖` 最终有界，界为 `O((σ‖θ_prior‖+d+η_unmodeled)/λ_leak)`；去掉泄漏/死区则存在 Rohrs 型反例与慢推攻击使参数无界（漂移/bursting）。系：**R69 的模态幻觉 = 无泄漏、无死区，把 aleatoric 噪声也当学习信号；`U_ale` 应同时决定「何时不该学」。**

**引理 21（SVoI 与激励-安全对偶）** 若 `SE(g)<ε_PE`，则 g 在安全敏感方向 s 上不提供 Fisher 信息，`θ_safe` 后验在该方向不被更新；任何改变由先验/噪声驱动，`r_safe` 期望下降为 0 而 `risk(g)>0`，故「不交互」严格占优。反之，**只降熵不增安全可辨识性的交互会制造「没有可辨识性的自信」**——R69 把「诚实的不知道」升级成「被证实的错误」的机制。系：VoI 应按 `s^T F_g s` 加权，而非总熵。

**引理 22（非伪证 + 驻留 ⇒ 无 Zeno 且切换稳定）** 滞回 Δ_h>0 与平均驻留 `τ_a≥lnμ/λ_0` 使有限区间内切换次数有界（无 Zeno）；多 Lyapunov 函数满足 `V_σ(t)≤μV_σ(t−)` 与衰减条件，故切换系统稳定。系：R69 的 `select_mode` 不加滞回会在近等权模态间以控制频率抖动，抖动本身是未建模高频扰动，会反过来破坏自适应。

**定理 18（安全-活性双占优与严格包含）** A95–A99 下，记 `r_safe`（安全违规概率）、`r_live`（时效/任务失败概率）：
(i) `r_safe(AEGIS) ≤ r_safe(FLUID)`：AEGIS 只删除 FLUID 中「无证消解」与「非法扩张」，安全可行域是子集；
(ii) `r_live(AEGIS) ≤ r_live(R68)`：许可证可得时发放与 FLUID 相同的 resolution bonus，否则退回 R68；
(iii) `SE<ε_PE`、`|e|≤d`、证书无效或监护报警时，AEGIS 与 FLUID/R68 **逐指令相同**。
故 R68 = 「永不持证/永不扩张」顶点，R69 = 「无安全约束探测」顶点，AEGIS 为可行域交，**对 FLUID 安全占优、对 R68 活性占优**——修正 R69 定理 16 把所有风险压成单一标量的含糊。

**定理 19（双钥匙 + 独立监护 ⇒ 非法扩张概率上界）** 由定义 325，非法扩张需同时通过 K1、K2、熬过 τ_exp 且不被独立监护拦截。单源污染时 `P(非法扩张)≤δ_p ρ^{k−1}+δ_K1 δ_K2`；两钥匙失效独立（ρ_fail<1）时上界显著低于任一单钥匙。系：慢推漂移被转化为「持续违反证据」——棘轮要求持续无违反而非单次幸运样本，关闭 R69「单次交互定案」在自适应层的漏洞。

**定理 20（安全对偶控制的连续过渡）** 定义 324 中，`h→0` 或 `SE→0` 时可行探测集收缩为空，最优解连续收敛到 R68 纯谨慎；`h` 充足且 `SE≥ε_PE` 时约束不绑定，恢复 R69 的 resolution bonus。故 AEGIS 是 R68 与 R69 之间由「安全裕度 × 激励」参数化的同伦，两端均为严格退化，中间不引入需独立信任的新黑箱。

## 7. 本轮最大风险

**一句话**：AEGIS 把安全寄托在「独立监护 + 双钥匙」上，但**当监护器与被监护者共享传感器、共享训练分布或遭遇共模故障时，独立性假设失效——「安全棘轮」与「可回滚」会同时失灵，盾牌自己需要盾牌，系统可能用一层新的不可证伪的元信任掩盖了原来的不可信**；其次，若棘轮过度保守，系统会永久冻结在 R68，AEGIS 退化为昂贵的安全壳。

**次级风险与缓解**：共模故障 → 独立性证据 + 多样性冗余 + E311；双钥匙协同欺骗 → 乘积上界 + 异族证据 + 驻留 + 回滚（E306/E309）；棘轮过度冻结 → 显式 `r_safe–r_live` Pareto（E315）+ 证书化扩张窗口 + 人类可审计扩张；慢环延迟/快慢不一致 → 证书总线只传已验证常量，慢环超时视为无证回退 R68；安全参数维度爆炸 → 只对低维 `s=∂h/∂θ_safe` 子空间做 SE 统计，其余划入 θ_perf。
