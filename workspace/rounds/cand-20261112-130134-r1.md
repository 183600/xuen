# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 1 轮；本轮灵感：「关节空间控制」×「碰撞避免」）

> 第 57 轮把证据的判定权分散到元先验、跨模态对账与个性化信任，纵深做到五层；但它的全部证据都活在**任务空间**与**概率置信域**里，暗含两个从未被检验的前提：**(a)** 任务空间"可信"的承诺天然能翻译成一条关节空间可行轨迹——限位、奇异、力矩饱和、自碰撞与扫掠间隙这些真正决定摔不摔的量，被留到执行边才暴露；**(b)** 碰撞避免要么是"底层硬化反射"，要么等价于一条普通概率证据——把硬碰撞约束与概率正证据塞进同一个证据门，于是"更高置信的预测"可以"覆盖"一条碰撞证书，这是范畴错误。本轮两个灵感各补一刀：**关节空间控制**把"承诺"变成一张必须在关节空间兑现的支票（JSC 兑现证书），**碰撞避免**把"负证据"提升为一等公民（HNE 硬负证据：正证据永不可覆盖，只可由几何变更证书撤销），并顺手带来两个副产品：冗余零空间里的**免费安全裕度**（ZSM），以及毫秒级反射的**持证上岗**（RAR 预授权反射弧注册表）。核心命题由第 57 轮"少样本可校准、跨模态可对账、个性化有界的证据说可信"升级为 **"证据可在关节空间兑现、硬负约束不可被正证据覆盖、反射弧持证上岗的证据说可信"**。

核心矛盾：
- **H29（任务空间可信 vs 关节空间可兑现）**：证据门回答"这个落脚点/区域可不可信"，失败却发生在关节空间（限位、奇异、力矩饱和、自碰撞、扫掠间隙）。任务空间可行 ≠ 关节空间可兑现；若把兑现留到执行时，安全的赌注又多押一层——"证书本身健全"这一从未被审计的前提。
- **H30（硬约束 vs 概率证据）**：证据是可被更多信息"说服"的概率量；碰撞/限位/奇异/力矩是硬负约束，不能被正证据覆盖。混入同一证据门，高置信预测即可"覆盖"碰撞证书，导致系统"持着高置信撞上去"。硬负只能被"世界确实变了"的几何证据撤销，不能被"我更相信它安全"撤销。
- **H31（反射速度 vs 审议/授权）**：碰撞避免要毫秒级行动，证据审议在秒级、人机同意更慢。紧急反射必然"未经本轮审议"地行动：无预授权与离线证书，要么反射违反"无证据不承诺"，要么为遵守它而撞上去。反射必须持证上岗、只向保守触发，而证书本身依赖模型——模型错则"持证地错"。

## 0. 直觉与动机

**灵感 1（关节空间控制 → 证据兑现层 JSC）**
直觉：把"承诺"看成一张必须能在关节空间兑现的支票。任务层说"去这个落脚点、用这个步态"，真正决定成败的是那条从当前构型到目标构型的关节轨迹——会不会顶到限位、穿过奇异、力矩打饱和、小腿撞大腿、机身扫到台阶。引入**关节空间兑现证书 JSC**：承诺前先证明存在一条连续关节轨迹，全程满足限位/速度加速度界、力矩与摩擦锥、奇异裕度、自碰撞间隙、环境扫掠间隙；证不出就承诺无效，并返回"最近可行变体"。于是证据门从"任务空间可信"升级为"任务空间可信 ∧ 关节空间可兑现"——不可兑现的承诺在承诺前被拒，而不是执行中急停。

**灵感 2（碰撞避免 → 双空间对账 SRC + 硬负证据 HNE）**
直觉：碰撞避免生产的是**负证据**——"这些构型/区域不可穿越"。它有两条不对称来源：环境几何只在笛卡尔空间可见，自碰撞/限位/奇异只在关节空间可见。单空间永远漏一半。做**双空间对账 SRC**：取两空间裕度的保守下界，分歧本身作为不确定性下限（第 57 轮"分歧即下限"的空间对偶）。更关键的是把碰撞类证据从概率门里拿出来，放进**硬负证据 HNE**：可行 = 软可行 ∧ ¬H，任何概率正证据都不能使 ¬H 成立；H 只由"几何变更证书"（重感知证明障碍移除、构型变更、推力改变支撑面）撤销并审计。这修掉了"高置信覆盖碰撞"的范畴错误。

**灵感 3（冗余 → 零空间安全裕度 ZSM）**
直觉：腿式与冗余臂都有任务零空间。可以在不改变已承诺任务动作的前提下，用零空间运动最大化碰撞/限位/奇异裕度——**零成本安全**：不耗探针预算、不改任务、只增裕度。ZSM 只做单调增裕度的投影，正是第 57 轮"交互单调性"在关节空间的物理实现；零空间提升不了裕度时就不动（no harm）。

**灵感 4（碰撞即探针 + 反射持证 → 接触台账 CL 与预授权反射弧 RAR）**
直觉：系统本就装备力矩/触觉/接近觉，**软接触是免费探针**：预测-实测残差可更新地图与模型，信息量按探针计而成本≈0（已发生）。但硬碰撞绝不可作为探针（不可逆）。把接触分三级——接近（非接触）/软接触（可恢复）/硬碰撞（不可逆）——只有前两级入账为证据；硬碰撞立即写入 H 并做最坏估计的碰撞后审计。与此同时，紧急动作（急停、退让、卸力）预编译成**带离线证书的反射弧注册表 RAR**：每条反射弧有安全集与前向不变/收敛证书，在线只能在注册表内切换且切换须连续。这给"无证据不承诺"一个精确例外边界："**无证书不反射；非反射的刻意动作仍需证据承诺**"。

**灵感 5（合流 → 兑现-约束-反射三段桥与免费裕度）**
直觉：JSC 管"到得了且留裕度"，HNE/SRC 管"哪里绝对不可去"，ZSM 管"同一任务下白赚裕度"，RAR/CL 管"来不及想时怎么安全地动、以及碰撞能换回什么信息"。四者合流成一段从证据到执行的桥：证据门（第 57 轮，五类证据）→ 兑现门（JSC）→ 硬负边界（HNE）→ 在线增裕度（ZSM）→ 反射兜底（RAR）→ 接触回流（CL）。新增两条证据类：**EV-redeem**（兑现证书）与 **EV-contact**（软接触残差）。承诺必要证据集变为 {EV-probe* ∨ EV-margin ∨ EV-redeem} ∪ 佐证，且必须 JSC≠⊥ ∧ ¬H；EV-redeem 只证"可执行"不证"该执行"，不能单独替代不可逆接触的探针证据。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（关节空间兑现证书 JSC）** 构型 q∈𝒬⊂ℝⁿ，承诺动作 a 由任务层给出（落脚点/末端位姿/步态）。兑现证书 JSC(a;q₀,𝓜,θ_j) ⇔ 存在连续轨迹 q:[0,T]→𝒬、q(0)=q₀、q(T)∈Goal(a)，使 ∀t：q(t)∈𝒬_lim（限位/速度/加速度界）、τ(q,q̇,q̈)∈𝒯_sat（力矩与摩擦锥）、σ_min(J(q(t)))≥θ_sing（奇异裕度）、d_self(q(t))≥θ_self（自碰撞间隙）、d_env(q(t),𝓜)≥θ_env（环境扫掠间隙）。兑现裕度 m_JSC(a)=min over 约束的归一化 slack；不可兑现返回 ⊥ 与最近可行变体 a′=Proj(a)。证书由 CBF/可达集/采样可达性之一给出，模型误差按 η_model 直接收缩各 θ。承诺门：Gate(a) ⇔ TaskEvidence(a) ∧ JSC(a)≠⊥ ∧ m_JSC(a)≥θ_J。

**定义 140（双空间对账 SRC 与硬负证据 HNE）** 空间证据 e_cart（环境几何/扫掠体）与 e_joint（自碰撞/限位/奇异/力矩）各自给出裕度 m_cart(a)、m_joint(a)。对账：m(a)=min(m_cart,m_joint)（保守取小）；分歧 D_sp(a)=|m_cart−m_joint|/scale，D_sp>θ_sp ⇒ 额外加宽/降档。硬负集 H(a)={碰撞,限位,力矩饱和,奇异证书}，语义为不可穿越约束：Feas(a)=SoftFeas(a) ∧ ⋀_{h∈H(a)}¬h，**任意概率正证据 e⁺ 都不改变 ⋀¬h**。H 仅由几何变更证书 G（重感知移除障碍、构型变更、推力改支撑面）撤销：H←H∖{h} 当且仅当 G(h) 成立并审计。正证据在证据偏序上是可击败的（defeasible），H 只被世界变更回撤（retractable-only-by-world-change）。

**定义 141（零空间安全裕度 ZSM）** 任务雅可比 J_task(q)，零空间投影 N=I−J_task⁺J_task。安全裕度 m(q)=min 约束 slack。零空间修正 q̇=q̇_task+N·∇_q m(q)，或求解 max m(q) s.t. J_task q̇=q̇_task、m 不降。单调性契约：m(q_{t+1})≥m(q_t)−ε_num，任务保持 ‖J_task q̇−q̇_task‖≤ε_task；零空间无法增裕度则 q̇=q̇_task（no harm）。ZSM 不消耗探针预算、不改承诺，故对交互单调性只增不减。

**定义 142（接触分级与接触台账 CL）** 接触事件 c=(t,位置,法向,冲量,模态)。分级：c∈{prox（d>0，非接触）, soft（可恢复：冲量≤J_soft ∧ 可退 ∧ 无损坏）, hard（不可逆：超冲量/损坏/卡死）}。软接触可作证据：残差 r_c=预测响应−实测响应 入地图/模型更新，信息量按 EV-probe 计而成本≈0；硬碰撞永不作为探针，写入 H（未注册障碍）并触发碰撞后审计（取最坏估计）。台账 L_c 记全部接触，供第 57 轮 R3 式事后证伪回溯的接触版（按 ρ 与模型证据降权/恢复）。

**定义 143（预授权反射弧注册表 RAR 与反射证书）** 反射弧 ρ=(触发 φ_ρ, 关节策略 π_ρ, 安全集 𝒮_ρ, 终止条件)。离线证书：∀q∈𝒮_ρ，π_ρ 前向不变（状态留在 𝒮_ρ）、𝒮_ρ⊆𝒬_lim∧¬H、且在有限时间收敛到停机/静止安全集；φ_ρ 只依赖可观测信号且具单调保守性（宁可误触发）。在线：q̂∉𝒮_ρ 或 φ_ρ 触发 ⇒ 允许执行 ρ；切换 ρ→ρ′ 需 𝒮_ρ∩𝒮_ρ′≠∅ 且控制连续（bumpless），否则先经"安全停"过渡。紧急反射属**常备预授权**（standing consent），每次触发审计；"无证书不反射"。

**定义 144（兑现证据门 CEG 与探-诺-演-反射算子 PCXR）** 证据门（升级 IP-137 FSE）在 EV-probe*/visit/margin/xmodal/human 之外新增 **EV-redeem**（JSC≠⊥ ∧ m_JSC≥θ_J）与 **EV-contact**（软接触残差证据，仅 L0/L1，不可替代不可逆接触证据）；不可逆接触必要证据集={EV-probe*∨EV-margin∨EV-redeem}∪佐证，且必须 ∧JSC≠⊥ ∧¬H；EV-redeem 只证可执行、不证该执行，不得单独替代探针证据。PCXR 在每个检查点先算 JSC：不可兑现则选最近可行变体/绕行/降档；执行中 ZSM 持续增裕度；m_JSC<θ_reflex 或 φ_ρ 触发则交 RAR；软接触入 CL 并触发对账。终止态仍为 {承诺,绕行,L2 协商,安全停}，新增瞬时子态"反射接管"。

## 2. 关键算法伪代码（完整版见产物区）

```python
def redeem(a, q0, M, theta):                       # IP-139/140: 兑现 + 双空间对账
    m_cart  = sweep_margin(a, M)                   # 环境几何（笛卡尔）
    m_joint = joint_margin(a, q0, M)               # 限位/奇异/自碰撞（关节）
    if hard_negative(a, M): return None, 0.0, a   # HNE：硬负直接否，正证据不可覆盖
    m = min(m_cart, m_joint); Dsp = abs(m_cart - m_joint)/SCALE
    if m < theta.J or Dsp > theta.sp: return None, m, best_variant(a, M)  # 兑不出→变体
    return certificate(a, q0, m), m, a

def nullspace_safety(q, qd_task, M):               # IP-141: 零空间只增裕度
    N = I - pinv(J_task(q)) @ J_task(q)
    qd = qd_task + N @ grad_margin(q, M)
    return qd if margin_ok(q, qd) else qd_task     # no harm 回退

def contact_update(L, c, M):                       # IP-142: 接触分级 / 碰撞即探针
    lvl = classify(c)                              # prox / soft / hard
    L.append((c, lvl))
    if lvl == 'soft':   M = learn_residual(M, c.pred - c.meas)   # 免费探针
    elif lvl == 'hard': M.H.add(unregistered_obstacle(c)); audit.worst_case(c)  # 永不作探针
    return M, L

def reflex_dispatch(x, qhat, RAR):                 # IP-143: 无证书不反射
    for rho in RAR.eligible(qhat):                 # 触发仅依赖可观测信号
        if breach(rho, qhat) and cert_valid(rho):
            return switch_bumpless(x, rho) or safe_stop(x)
    return x

def probe_commit_evolve_redeem(x0, M, task, budget, consent, RAR):
    for cp in route(M, task).checkpoints:
        a = propose(cp, M)
        cert, m, a = redeem(a, q0(cp), M, theta)   # ①兑现门
        if cert is None and not alt_ok(a): return negotiate_or_stop(cp, M, consent)
        qd = nullspace_safety(q0(cp), task_vel(a), M)          # ②免费增裕度
        while select_gait(risk(qd, M)) == 'halt' and budget.left:
            M = probe(M, voi_meta_pessimistic, budget)         # ③第57轮探询
        if m < theta.reflex or RAR.triggered(qhat):
            return reflex_dispatch(x0, qhat, RAR)              # ④反射接管
        if gate_ok(a, cert, M, consent, RAR): commit(a); continue
        return negotiate_or_stop(cp, M, consent)
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| JSC | O(N_sample·C_check) 每次承诺；可预编译缓存 | O(N_sample·n) | 证书无漏、η_model 收缩裕度 |
| SRC/HNE | O(\|H\|+\|约束\|) | O(\|H\|) | 保守取小、正证据不可覆盖 H |
| ZSM | O(n²)+O(n·\|约束\|)/节拍 | O(n²) | 只增裕度、任务保持、no harm |
| CL | O(1)/接触 | O(\|L_c\|) | 分级诚实、硬碰撞不入证据 |
| RAR | O(\|RAR\|) 分发；离线证书 | O(\|RAR\|) | 前向不变、切换连续 |
| CEG/PCXR | O(\|CP\|·(JSC+k_p·VOI+\|RAR\|)) | O(\|V\|+\|σ\|) | 兑现优先、反射兜底、终止 |

**正确性定理（Redeemable-Collision-Safe Soundness, RCSS 概要）**：在 A33–A40 上加 (A41) JSC 证书健全、模型误差按 η_model 收缩、证书失效率 ≤δ_JSC；(A42) SRC 保守且 HNE 正证据不可覆盖、H 仅由几何变更证书撤销；(A43) 接触分级诚实、硬碰撞不入证据；(A44) RAR 前向不变/驻留安全/切换连续、触发只依赖可观测信号。则：(i) 兑现健全：承诺失效率 ≤δ_f+ε_meta(k)+δ_probe+ε_h+δ_ood·α_conf+δ_xm·1[L1]+δ_JSC；(ii) 硬负安全与证据置信解耦：对 h∈H 的失败贡献不随任何正证据置信增长，仅随几何变更证书失效率 δ_G 变化；(iii) 单调性：ZSM 只增裕度、HNE 只缩可行集、RAR 只导向安全集、CL 只新增证据或硬负，均无升险路径；(iv) 终止：每检查点探针 ≤k_probes+k_cons，PCXR 终止于 {承诺,绕行,L2 协商,安全停}。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 证书依赖模型，模型错则"持证地错" | 高 | 显式 η_model 收缩裕度 + 在线残差监测触发证书降级 + 保守安全停不依赖模型 |
| ZSM 零空间与任务/反射冲突 | 中 | 严格任务不变量 + 单调增裕度 + 冲突时 no harm |

def joint_space_certificate(a, q0, M, th):
    # 任务层给出目标构型集；用 CBF / 采样可达性 / 运动规划三选一
    if hard_negative(a, M):                       # 先问 HNE：硬负直接否
        return Cert(ok=False, m=0.0, viol='hard_negative')
    qT = goal_configs(a)
    traj = reachable_path(q0, qT, th)             # 连续轨迹候选
    if traj is None:
        return Cert(ok=False, m=0.0, variant=best_variant(a, M))
    m = +inf
    for q, qd, qdd in traj:
        m = min(m,
                slack_limits(q, qd, qdd, th),      # 限位/速度/加速度
                slack_torque(q, qd, qdd, th),      # 力矩与摩擦锥
                slack_sing(J(q), th),              # 奇异裕度 σ_min≥θ_sing
                slack_self(q, th),                 # 自碰撞间隙
                slack_sweep(q, M, th))             # 环境扫掠间隙
        m -= eta_model * model_unc(q, M)           # 模型误差收缩裕度
    return Cert(ok=(m >= th.J), m=m, traj=traj)

def hard_negative(a, M):
    return (collision_cert(a, M) or limit_cert(a) or
            torque_sat_cert(a) or singularity_cert(a))     # H(a) 非空

def spatial_reconcile(a, q0, M, th):
    m_cart  = sweep_margin(a, M)                  # 环境几何，笛卡尔可见
    m_joint = joint_margin(a, q0, M)              # 自碰撞/限位/奇异，关节可见
    m = min(m_cart, m_joint)                      # 保守取小
    Dsp = abs(m_cart - m_joint) / SCALE
    if Dsp > th.sp: m = widen_or_downshift(m, Dsp)  # 分歧即不确定性下限
    feasible = (m >= th.J) and not hard_negative(a, M)
    return feasible, m, Dsp

def retract_hard_negative(H, g):

### IP-141 ZSM（零空间安全裕度）

def zsm_step(q, qd_task, M, th):
    J = J_task(q); N = I - pinv(J) @ J
    g = grad_margin(q, M)                          # 对 m(q) 求梯度
    qd = qd_task + N @ g
    if margin(q, qd, M) >= margin(q, qd_task, M) - th.eps \
       and task_error(q, qd, qd_task) <= th.task:

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|

**正确性定理（Redeemable-Collision-Safe Soundness, RCSS）**
假设 A22–A40 成立；**(A41)** JSC 证书健全：可达性/CBF 证明无漏、模型误差按 η_model 收缩各阈值、证书失效率 ≤δ_JSC；**(A42)** SRC 保守取小、HNE 不可被正证据覆盖、H 仅由几何变更证书撤销且撤销失效率 ≤δ_G；**(A43)** 接触分级诚实：软/硬误判率 ≤δ_cls，硬碰撞永不作为证据；**(A44)** RAR 每条反射弧满足前向不变/驻留安全/有限时间收敛，切换满足安全集交集非空且 bumpless，触发只依赖可观测信号。则：

1. **兑现健全性**：承诺失效率 ≤ δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1] + δ_JSC。
2. **硬负与置信解耦**：对 h∈H 的失败贡献不随任何概率正证据的置信增长，只随几何变更证书失效率 δ_G 与分级误差 δ_cls 变化——"更高置信"不再能"覆盖"碰撞。
3. **交互单调性（关节空间实现）**：ZSM 只增裕度、HNE 只缩可行集、RAR 只导向安全集/安全停、CL 只新增证据或硬负；四者对第 57 轮的"信念更准或动作更保守"两通道只增不减，无升险路径。
4. **终止性**：每检查点探针 ≤k_probes+k_cons，PCXR 终止于 {承诺, 绕行, L2 协商, 安全停}，反射接管为可审计的瞬时子态。
5. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1] + δ_JSC + δ_G·1[H])
             − P(𝓜 陈旧未检出) − P(护盾回退失败) − P(RAR 证书失效) − P(切换不连续) − P(接触误分级)
```

关键：**兑现给可行性、硬负给边界、零空间给免费裕度、反射给时延**；效率（探针数、承诺前置条件）与安全（硬负不可覆盖、证书健全）被显式解耦——正证据只影响软可行与探询优先级，硬边界只由世界变更回撤。

## 6. 本轮最大风险

**一句话**：本轮把"承诺能否落地"的安全判定权交给**离线关节空间证书与反射弧证书**，而这两类证书的有效性完全寄生在动力学/几何/摩擦/负载模型上——一旦出现未建模负载、磨损、柔性、动态障碍或打滑，系统会在毫秒级、常备预授权、无人复核的条件下"持证地"撞上去或摔下去；硬负约束只保护已知几何，零空间只优化已建模裕度，反射证书更把模型误差放大到执行末端，因此必须让证书携带显式模型误差裕度、用在线残差监测触发证书降级，并保留一条不依赖任何模型、只减小能量/增大间隙的单向安全停。
