# 第 67 轮（承接第 66 轮「RAS 情绪驱动闭环」IP-224~233；灵感循环第 4 轮；本轮灵感：「伦理与合规」×「移动操作」）

> 第 66 轮 RAS 把 VISTA 的「故障响应闭环」升级为「意图感知闭环」，其最大贡献是让控制输入第一次包含「主体的风险态度」。但 RAS 的整个构造建立在一个从未被审查的规范性假设上：**情绪这条通道是"干净"的，并且它有权决定"放松多少"**。两层问题随之而来。
>
> 第一层是**权限错配**：RAS 允许 `λ_risk ∈ (0.5, 1.2)`，即情绪证据可以把保护阈值放宽 20%。可面部情绪推断恰恰是隐私敏感、可被遮挡/光照/假笑欺骗、且在多地受到法律严格限制的通道。**把一个最不可靠的感知通道，赋予削弱安全的能力**，在工程与伦理上都是不可接受的。
>
> 第二层是**合规维度缺失**：VISTA/RAS 的证书只回答「物理上能否安全执行」，不回答「在此辖区、此同意状态、此旁观者分布、此数据边界下是否**被允许**执行」。移动操作把这两个缺口同时放大：基座在动，人机相对速度、支撑多边形、扫掠体积、可达工作区都在连续变化，任何只针对固定机械臂的合规结论，在基座移动后立即失效。
>
> 本轮核心命题：
>
> **把「情绪驱动闭环」升级为「权限分层闭环」：把伦理与合规写成只能收紧、不可放松、必须携带见证的硬包络；把情绪写成单向证据——只能增益安全，不能削减安全；再把它嵌入全身移动操作包络与溯源审计账本，构成 LEX-M（Legal-ethical eXecution envelope for Mobile manipulation，法度·移动操作闭环）。**
>
> LEX-M 问的不再是「谁控制多少」（RAS），而是：「**这条动作，在该辖区、该同意状态、该全身构型下，是否有资格被执行？若被质疑，证据链在哪里？**」

## 0. 直觉与动机

**灵感 1（伦理与合规 → 证据的"权限不对称"）**
直觉：合规不是再往损失函数里加一项。法规与伦理条款在逻辑上有两种不可交易的地位：**禁止**（不可用效用抵消）与**义务**（不可被遗忘）。把「禁止接触」和「任务想接触」做 0.4/0.6 的加权平均，得到的是「少接触一点」——这不是合规，而是把红线打折。
更关键的洞见是：**不同证据对安全的权限本就应该不对称**。合规约束、保守先验、传感器故障证据，只能**收紧**可行域；情绪、舒适度、意图猜测这类软证据，最多也只能收紧，绝不能放宽。RAS 的 `λ>1` 分支恰好违反这一条。于是本轮把这种不对称提升为首要不变式：
> **证据可以踩刹车，不可以踩油门。** 形式化为 `λ_affect ≤ 1`，硬规范不参与任何缩放。

**灵感 2（移动操作 → 合规包络必须是全身的）**
直觉：移动操作的安全不是「机械臂安全 + 底盘安全」的并集。基座一移动，至少三件事同时改变：
1. **人机相对速度**：机械臂伸向人的同时基座也朝人移动，末端相对人的速度是两者叠加；只按臂末端速度算停止距离，会系统性低估一个 `v_base·(T_react + T_stop)` 项；
2. **支撑多边形**：臂的伸展改变了全身质心，轮式底盘的稳定裕度随构型变化，同一个末端力限在不同基座位置下可能一边安全一边倾覆；
3. **扫掠体积**：基座位移会把机械臂的扫掠体推进禁区、推到人身上，或把相机视锥推进隐私区域。
所以合规约束必须定义在全身构型 `x = (q_base, q_arm, \dot q_base, \dot q_arm)` 上，用耦合质量矩阵、全身质心与全身停止时间。**「合规」不是附加在末端的标签，而是全身状态空间里的一个时变可行域。**

**灵感 3（两灵感合流 → 三权分立的闭环）**
直觉：安全的闭环不应只有「执行」一种权力。LEX-M 把它拆成互相制衡的三权：
- **执行权**：VISTA/RAS 的感知、归因、控制与认证前缀；
- **规范权**：NRC 把规则书编译成有界道义时序自动机与全身包络；
- **审计权**：PAL 记录每步见证，HOC 接受人类覆写与争议，CJA 处理辖区切换。
每一步执行必须同时获得三权许可：`k*_LEX = min(k_VISTA, k_RAS', m_ras, m_lex)`，且每一步都要过 WCE 与规范监测器。若交集为空，进入 EFP 回退（安全停 / 最小风险合规态），**绝不"带着警告继续"**。
这个结构天然回应 RAS 的最大风险：即使情绪被假笑或对抗 patch 欺骗，AEG 也只能让系统变保守或让情绪通道失效，**不能让它放行**。

**灵感 4（伦理不确定性预算 EUB）**
直觉：规范不是二值的。「合理」「必要时」「适当距离」这些开放条款怎么处理？辖区冲突怎么办？规则书过期怎么办？把它们假装成确定值，是合规系统最常见的自欺。
LEX-M 把这些不确定性显式记账为 `ε_eth`（规则模糊度 + 辖区冲突 + 模型误差 + 观测误差），并要求**物理安全裕度 ≥ L_eth·ε_eth**；不够就减速或回退。这把「伦理不确定性」变成可测量的工程量，而不是事后免责声明。

**灵感 5（与 VISTA/RAS 的接口）**
- VISTA 的几何/力/模型安全证书 → WCE 的物理子集；
- RAS 的 `λ_risk` → AEG 的 `λ_affect ∈ [λ_min, 1]`（上界被钉死为 1）；
- RAS 的 AIC 干扰集 → 增加 `ℰ_norm`（规则书错误、辖区切换、同意撤回）与 `ℰ_coupled`（基座-臂耦合误差）；
- `J_vista / J_RAS` → `J_lex`：一张第三方可离线重放的合规证书。

- **定义 246（规范单元）**：`r = (id, J_r, mode, φ_r, [t0,t1], hardness, severity, priority, prov)`。`mode ∈ {F, O, P}` 为禁止/义务/允许；`φ_r` 为定义 247 的 BDTL 公式；`hardness ∈ {hard, soft}`；`prov = (source, version, sha256)` 为规则出处。硬规范 = 全部 `F` + 安全关键的 `O`。
- **定义 247（有界道义时序逻辑 BDTL）**：在有限执行迹 `ξ = x_0 u_0 x_1 u_1 …` 上：
  `φ ::= p | ¬φ | φ∧φ | ○φ | φ U_{[a,b]} ψ | □_{[a,b]}φ | ◇_{[a,b]}φ`，`p` 为原子命题（距离、力、同意状态、区域、数据通道等），`[a,b] ⊆ [0,H_lex]`，`H_lex ≤ 2s`。

- **定义 248（多辖区规则合成）**：活动规则集 `R(x,t) = { r : J_r ∈ J_active(loc, task) }`。合成算子 `⊓`：禁止取并、义务取并、允许取交；优先级只用于消解显式冲突；无法消解时取**最严组合并升级人类**。性质：`R ⊆ R' ⇒ CertSet(R') ⊆ CertSet(R)`。

  1. 人机分离：`d_i(x) ≥ d_sep,i(x)`（定义 250）；
  2. 稳定性：`m_stab(x,u) ≥ m_min`（定义 251）；
  3. 接触：法向力、压强、切向摩擦满足 `f_n ≤ f_max(region)`、`p ≤ p_max(region)`、`|f_t| ≤ μ f_n`；
  4. 空间：`swept_volume(x,u) ∩ ProtectedZones = ∅`；
  5. 数据边界：相机视锥不得进入隐私区，原始人脸不出设备。
- **定义 250（全身速度-分离约束 SSM-WB）**：

  其中 `v_rel,i` 是**基座 + 机械臂**相对第 `i` 个人的最近点相对速度，`T_s^WB(x)`、`d_stop^WB(x)` 由全身耦合动力学与基座制动能力给出。臂-only 的停止距离是该式的一个下界近似，移动基座下不安全。
- **定义 251（稳定性与接触约束）**：支撑多边形 `P_sup(x)` 由轮/足接触点凸包给出；捕获点 `ξ(x) = c(x) + \dot c(x)/ω_0`；要求 `ξ(x) ∈ P_sup(x) ⊖ B(m_min)`，并同时校验 ZMP 不越界。接触约束按身体区域（手、前臂、躯干）取不同的 `f_max, p_max`。

- **定义 253（同意与目的绑定）**：同意令牌绑定用途、设备、时限；撤回即刻生效——`λ_affect` 立即回 1，令牌清除，已采集特征的派生数据一并作废。禁止用「已同意」外推至未声明用途（目的限制原则）。
- **定义 254（合规感知认证前缀 CAP）**：`k*_LEX` 为满足下式的最大 `k ≤ min(k_VISTA, k_RAS', m_ras, m_lex)`：对所有 `s ≤ k`，

  5. 每一步都产出见证 `w_s`。

- **定义 255（合规见证）**：`w_s = (d_sep_margin, v_rel, f_ratio, p_ratio, m_stab, zone_clearance, consent_token, rule_ids, λ_affect, sensor_conf)`。见证必须足以让第三方在离线审计中独立重放并判定该步是否合规。

- **定义 258（人类覆写与可争议 HOC）**：覆写 `o = (authority, type, scope, T_ov, justification)`。`type = TIGHTEN` 与 `STOP` 始终允许；`type = EXCEPTION` 仅当授权级别足够、显式记录、时长有界 `T_ov`，且系统须在 `T_return` 内回到合规态。**任何未记录的"放宽"一律拒绝。** 争议时，系统可以关闭情绪通道（`λ→1`）以回应质疑，但**不得**关闭硬规范。

- **定义 261（跨辖区切换 CJA）**：物理地理围栏、任务模式或司法辖区变化触发原子切换；切换期间使用**新旧规则集的交集**（最严）直至新规则确认，证书同时记录两个辖区，杜绝「辖区缝隙」利用。

# IP-236 AEG：情绪只能踩刹车
class AsymmetricEthicalGate:
    def __init__(self, alpha=0.4, tau_risk=0.4, lam_min=0.6):
        self.alpha, self.tau_risk, self.lam_min = alpha, tau_risk, lam_min

    def gate(self, consent, pi, R_emotion):
        if consent.status != 'GRANTED' or not consent.covers('safety_tightening'):
            return {'lam': 1.0, 'mode': 'NO_AFFECT', 'token': None}
        lam = 1.0 - self.alpha * max(0.0, R_emotion - self.tau_risk)
        lam = max(self.lam_min, min(1.0, lam))        # 上界钉死为 1
        token = tokenize(pi, consent.nonce, ttl=1.0)  # 不可逆、短时
        return {'lam': lam, 'mode': 'TIGHTEN', 'token': token}

## 3. 推导

**引理 11（非放宽不变量）** 在 AEG 下 `λ_affect(t) ≤ 1` 对所有 `t` 成立。因此对任意名义指令 `u_nom`，`risk(λ_affect·u_nom) ≤ risk(u_nom)`；故 `Safe_LEX ⊆ Safe_VISTA`。情绪欺骗（假笑、对抗 patch、遮挡）最多使 `λ_affect` 回到 1 或更小，**不可能触发 RAS 的 `λ>1` 放行分支**。

**引理 12（全身 SSM 必要性）** 设基座朝人的速度为 `v_b^→`，则 `d_stop^WB ≥ d_stop^arm + v_b^→·(T_r + T_s)`。因此仅用臂末端速度的分离距离至少低估 `v_b^→·(T_r+T_s)`；当 `v_b^→>0` 时，臂-only 证书可能给出实际违规的近距离。移动操作必须使用 SSM-WB。

**定理 11（LEX-M 证书可靠性）** 在假设 A1–A5 下——A1 NRC 对 BDTL 有界片段健全；A2 见证误差 ≤ 传感器容差；A3 WCE 是真实可行集的保守内近似；A4 CAP 只执行已认证前缀；A5 HOC 遵守定义 258——已执行轨迹满足全部活动硬规范与 WCE 的概率至少为
`1 − (α_chunk + δ_fi + α_emotion + α_rule + α_obs)`，
且 `J_lex` 可被第三方审计函数 `Ver` 重放接受。

**定理 12（局部见证 ⇒ 全局可审计）** 因 `H_lex` 有界，任意违规都存在长度不超过 `H_lex` 的局部见证窗口。于是前缀合规性等价于「每步局部见证成立 + 有限状态自动机在接受态」，审计可流式进行，内存不随轨迹长度增长；责任归因也被局部化到有界窗口，而不是整段历史。

## 6. 本轮最大风险

**一句话**：LEX-M 把「合规」降维成对某版规则书的可编译硬约束，但真实法规与伦理包含开放条款、价值权衡与辖区冲突；一旦规则编译器不健全或规则书存在缺口，系统会以「已认证合规」的更高置信度执行实质违规——**证书带来的虚假保证，是本轮所有理论依赖的核心风险**。

**次级风险与缓解**：
1. **规则书不完备/开放纹理**：`?` 一律不放行，EUB 显式记账，超预算升级人类；
2. **过度保守导致任务不可用**：硬/软规范分层，软规范用严重度折算，硬规范绝不折价；
3. **隐私泄露**：AEG 只输出不可逆短时令牌，PAL 不存原始人脸，目的限制 + 撤回即焚；
4. **辖区冲突死锁**：CJA 取交集并显式升级，避免「最严规则互斥」导致永久停摆；
5. **全身模型误差**：WCE 用保守内近似 + 鲁棒管，基座速度不确定性单独计入 EUB；
6. **人类覆写侵蚀合规**：覆写分级授权、限时、留痕，技术上无法也不应阻止有权限的紧急覆写，但保证事后可追责。

## 2. 形式化定义（完整版）

**定义 245（LEX-M 总览）** LEX-M 是 VISTA/RAS 之上的「规范-权限」外骨骼：
```
LEX-M = (NRC, WCE, AEG, CAP, PAL, HOC, CJA, EUB, EFP)
```
不变式：硬规范不进梯度、不进贝叶斯后验、不被 `λ` 缩放；情绪/意图证据只能收缩可行域；无见证不执行。

**定义 246（规范单元）**
```
r = (id, J_r, mode, φ_r, [t0,t1], hardness, severity, priority, prov)
mode ∈ {F, O, P}，hardness ∈ {hard, soft}
prov = (source, version, sha256)
```
硬规范 = 全部禁止条款 + 安全关键义务；软规范按 `severity` 折算，但不参与硬约束交集。

**定义 247（有界道义时序逻辑 BDTL）**
```
φ ::= p | ¬φ | φ∧φ | ○φ | φ U_[a,b] ψ | □_[a,b] φ | ◇_[a,b] φ
p ∈ AP，[a,b] ⊆ [0, H_lex]，H_lex ≤ 2s
```
三值运行时语义 `M_r(ξ) ∈ {⊤, ⊥, ?}`：确定满足 / 确定违反 / 视界内未定。**`?` 不得解释为允许**；若 EUB 不能覆盖该不确定性，则按 `⊥` 处理。

**定义 248（多辖区规则合成）**
```
R(x,t) = { r : J_r ∈ J_active(loc, task) }
⊓：禁止取并，义务取并，允许取交；显式优先级消解冲突
```
无法消解时取最严组合并升级人类。性质：`R ⊆ R' ⇒ CertSet(R') ⊆ CertSet(R)`。

**定义 249（全身合规包络 WCE）**
```
C_lex(x,u) ≤ 0  ⇔
  (1) ∀i: d_i(x) ≥ d_sep,i(x)
  (2) m_stab(x,u) ≥ m_min
  (3) f_n ≤ f_max(region), p ≤ p_max(region), |f_t| ≤ μ·f_n
  (4) swept_volume(x,u) ∩ ProtectedZones = ∅
  (5) camera_fov(x) ∩ PrivacyZones = ∅
```

**定义 250（全身速度-分离约束 SSM-WB）**
```
d_sep,i(x) = v_rel,i·(T_r + T_s^WB(x)) + d_stop^WB(x) + C_i + Z_d + Z_r
v_rel,i = || d/dt p_closest(robot(x), human_i) ||
```
其中 `v_rel,i` 包含基座速度与机械臂末端速度的叠加；`T_s^WB`、`d_stop^WB` 由全身耦合惯量与基座制动能力计算。臂-only 版本是它的下界近似。

**定义 251（稳定性与接触约束）**
支撑多边形 `P_sup(x)` 为轮/足接触点凸包；捕获点 `ξ(x) = c(x) + \dot c(x)/ω_0`；要求

ξ(x) ∈ P_sup(x) ⊖ B(m_min)
```
并同时校验 ZMP 不越界。接触力/压强按身体区域取不同上限。

**定义 252（非放宽伦理门 AEG）**

token = H(π, nonce, ttl)   # 不可逆、短时
```
**不变式：`λ_affect ≤ 1`。** 情绪不再有 `λ>1` 的放行分支。

**定义 253（同意与目的绑定）** 同意令牌绑定用途、设备、时限；撤回即刻生效：`λ_affect → 1`，令牌清除，派生数据作废。禁止把「已同意」外推到未声明用途。

**定义 254（合规感知认证前缀 CAP）**
```
k*_LEX = max { k ≤ min(k_VISTA, k_RAS', m_ras, m_lex) :

若 `k*_LEX = 0`，转 EFP；不执行未认证动作。

**定义 255（合规见证）**

w_s = (d_sep_margin, v_rel, f_ratio, p_ratio, m_stab,
       zone_clearance, consent_token, rule_ids, λ_affect, sensor_conf)
```
见证必须足以让第三方独立重放并判定该步合规。

**定义 256（J_lex 证书）**
```
J_lex = (J_vista, λ_affect, J_active, rulebook_hash,
         witnesses, ε_eth, override_record, prev_hash, hash)
Valid(J_lex) ⇔ Valid(J_vista) ∧ (λ_affect ≤ 1) ∧ WCE ∧ BDTL
               ∧ 见证在容差内 ∧ 哈希链连续
```
注意：没有 `∨ face_unobservable` 之类的逃逸分支；不可观测不是合规理由。

**定义 257（溯源审计账本 PAL）** 只追加哈希链；每条记录含规则出处、活动辖区、见证、覆写记录。审计函数 `Ver(J_lex, rulebook, ξ) → {accept, reject}` 可离线重放。账本只存令牌与聚合量。

**定义 258（人类覆写与可争议 HOC）**
```
o = (authority, type, scope, T_ov, justification)
type = TIGHTEN | STOP     -> 始终允许
type = EXCEPTION          -> 需 authority ≥ θ_auth，限时 T_ov，T_return 内回归合规

任何未记录、未授权的放宽一律拒绝。争议时系统可关闭情绪通道（`λ→1`），但不得关闭硬规范。

ε_eth = w1·a_rule + w2·c_juris + w3·e_model + w4·e_obs
要求：d_i − d_sep,i ≥ L_eth·ε_eth

```

class AsymmetricEthicalGate:
    def __init__(self, alpha=0.4, tau_risk=0.4, lam_min=0.6):
        self.alpha, self.tau_risk, self.lam_min = alpha, tau_risk, lam_min

    def gate(self, consent, pi, R_emotion):
        if consent.status != 'GRANTED' or not consent.covers('safety_tightening'):
            return {'lam': 1.0, 'mode': 'NO_AFFECT', 'token': None}

        lam = max(self.lam_min, min(1.0, lam))        # 上界恒为 1

class ComplianceAwarePrefix:

## 4. 推导

**引理 11（非放宽不变量）** AEG 输出 `λ_affect ≤ 1`。对任意名义指令 `u_nom`，若风险随指令幅值单调，则 `risk(λ_affect·u_nom) ≤ risk(u_nom)`，故 `Safe_LEX ⊆ Safe_VISTA`。情绪欺骗只能使 `λ_affect` 回到 1 或更小，无法触发 RAS 的 `λ>1` 放行。

**引理 12（全身 SSM 必要性）** 基座朝人速度 `v_b^→` 使 `d_stop^WB ≥ d_stop^arm + v_b^→·(T_r+T_s)`。臂-only 分离距离至少低估该乘积项，因此移动基座下臂-only 证书可能给出实际违规的近距离。

**定理 11（LEX-M 证书可靠性）** 在 A1–A5 下，已执行轨迹满足全部活动硬规范与 WCE 的概率 ≥ `1 − (α_chunk + δ_fi + α_emotion + α_rule + α_obs)`，且 `J_lex` 可被 `Ver` 离线重放接受。
（A1 NRC 对 BDTL 有界片段健全；A2 见证误差 ≤ 传感器容差；A3 WCE 为保守内近似；A4 只执行认证前缀；A5 HOC 遵守分级覆写。）

**定理 12（局部见证 ⇒ 全局可审计）** 因 `H_lex` 有界，任意违规存在长度 ≤ `H_lex` 的局部见证窗口。前缀合规 ⇔ 每步局部见证成立 + 有限状态自动机处于接受态。审计流式、内存有界；责任归因被局部化到有界窗口。

**推论 11（RAS 过度放宽的消除）** 第 66 轮 RAS 的最大风险是「情绪被欺骗 → `λ>1` → 过度放行真实几何故障」。在 LEX-M 中，`λ>1` 分支不存在；情绪通道失效时 `λ=1`，WCE 与 BDTL 仍然生效。因此该风险被结构性消除，而不是靠阈值调参缓解。

## 6. 本轮最大风险

**一句话**：LEX-M 把「合规」降维成对某版规则书的可编译硬约束，但真实法规与伦理包含开放条款、价值权衡与辖区冲突；一旦规则编译器不健全或规则书存在缺口，系统会以「已认证合规」的更高置信度执行实质违规——**证书带来的虚假保证，是本轮所有理论依赖的核心风险**。

**次级风险与缓解**：
1. **规则书不完备/开放纹理**：`?` 不放行，EUB 显式记账，超预算升级人类；
2. **过度保守导致任务不可用**：硬/软分层，软规范按严重度折算，硬规范绝不折价；
3. **隐私泄露**：AEG 只输出不可逆短时令牌，PAL 不存原始人脸，目的限制 + 撤回即焚；
4. **辖区冲突死锁**：CJA 取交集并显式升级，避免最严规则互斥导致永久停摆；
5. **全身模型误差**：WCE 保守内近似 + 鲁棒管，基座速度不确定性计入 EUB；
6. **人类覆写侵蚀合规**：分级授权、限时、留痕；不阻止有权限的紧急覆写，但保证事后可追责。
