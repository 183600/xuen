# 第 70 轮（承接第 69 轮「FLUID-RAS 不确定性二分交互消歧」IP-253~263；灵感循环新循环第 1 轮；本轮灵感：「世界模型」×「技术融合」）

> R69 学会了「问」：它把不确定性拆成 aleatoric / epistemic，用流匹配策略显式表示动作模态，用 VoI 决定是否注视、探问、轻触，并用流似然作为标定不可吸收的第二意见。但 R69 的成功建立在一次**未受检验的融合**上：流策略、标定器、LLM、世界模型、交互控制器、审计器被串成一条流水线，每一块的证书都默认自己那组前提成立；而它们共享同一个**世界模型**——既作为安全认证的预测器（C-RAS-WM），又作为反事实与未来推演的基础（VISTA.H）。
>
> 这就留下两个被本轮灵感正面击中的洞：
> 1. **世界模型**不是一面中立的镜子，而是一台**想象机器**。它可以廉价地回答「如果我看一眼会看到什么」，但它的反事实只在**训练支撑域内**可信；更糟的是，如果用它的输出去更新信念、再用更新后的信念证明它可信，就构成**自证循环**。R69 从未区分「想象出来的证据」与「测量到的证据」。
> 2. **技术融合**不是把模块拼起来，而是一次**假设的交换**。每个模块的保证都带前提；融合时，一个模块的保证常常被另一个模块当作前提使用，而那个前提可能早已被第三者破坏。R69 的 k-源证据纪律更是悄悄假设了各证据源**相互独立**——但当所有源都条件在同一个世界模型上时，它们的错误高度相关，独立性被融合本身摧毁。**融合既是胶水，也是共模故障源。**
>
> 核心命题：**把世界模型降级为「可证伪的想象引擎」，把技术融合升级为「假设-保证契约的组合」；想象只能提议、不能确认；融合后的证书只有在假设被清算、且见证独立性被认证时才有效；假设未清算的「融合债务」单调地换回 R69 / R68 的保守。** 命名 **FORGE-RAS**（Fusion Of Region-gated Guarantees & Evidence）——注意 forge 的双关：**锻造**，也是**伪造**；不做假设清算的融合，就是在伪造证书。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**当我把所有技术焊在一起，谁的保证还活着**」——融合的代价不是接口，而是那些没人写进合同的假设。

## 0. 直觉与动机

**灵感 1（世界模型 → 想象是可证伪的资源，不是免费的真相）**
直觉：R67 造了 VISTA，R69 把它当成安全认证与未来推演的公共底座。可世界模型真正稀缺的能力不是「预测」，而是「**试穿未来**」：不用真去看、真去问、真去碰，就能先估计「若我看向左边会看到什么」「若我问一句对方会怎么答」「若我轻触这个表面读数会变成什么」。这让交互的试错成本骤降。但想象有一道硬边界：**训练支撑域之外的世界模型输出是 confabulation（虚构）**，而且模型越自信越危险——置信头并不测量正确性。于是想象应被当作「候选生成器 / 成本估计器 / 排序器」，而不是「证据」。严谨地说：对反事实查询 q=(x,do(a))，只有 q 落在可认证支撑域 Q_adm 内、且支撑分数由**外生见证**（不是模型自己的置信）给出时，想象才能进入决策；否则必须丢弃。**想象能降低试错成本，不能降低确认成本。**

**灵感 2（技术融合 → 融合是有损的假设交换）**
直觉：把流策略、标定、LLM、世界模型、交互、审计焊在一起，表面是能力相加，实际是**假设互换**。模块 A 的保证 G_A 常被模块 B 当作前提 A_B 使用，但 B 从不检查 G_A 的适用域 Φ_A：流策略的多模态保证只在条件编码 z 位于训练分布时成立，而标定模块恰好改动了 o、把 z 推出了分布；交互模块又基于这些模态去提问，LLM 再假设语义接地成立——每一块的局部保证都是真的，拼起来却错了。这就是 **guarantee laundering（保证洗白）**。严谨地说，融合是契约的组合：C_i=(A_i,G_i,Φ_i,u_i,τ_i)；组合有效当且仅当每个被消费的保证都落在自己的 Φ 内、且其前提有运行时监视器放电。融合不是加法，是**用某模块的保证去支付另一模块的假设**。

**灵感 3（融合的悖论 → 共享世界模型摧毁独立性）**
直觉：R69 的「k 个正交证据源一致」像「多找几个人对答案」。但如果这几个人都偷看了同一本错误答案——共享同一个世界模型——他们的错误就完全相关，多问等于没问。**融合通过共享 WM 获得公共语义层，却也制造了共模故障源。** 严谨地说，若见证两两错误相关为 ρ，则有效独立见证数 k_eff = 1+(k−1)(1−ρ̄)；当 ρ→1，k_eff→1，R69 的投毒上界 δ_p·ρ^{k−1}+ε 退化为 δ_p。于是得到一个反直觉结论：**融合不一定让系统更安全；用共享世界模型把多个弱而独立的模块熔成一个强而相关的整体，可能比保留它们的多样性更危险。融合的收益上界，等于它保留的多样性。**

**灵感 4（想象 / 测量二分 → 打断自证循环）**
直觉：如果 WM 想象一个观测，用想象更新信念，再用更新后的信念反过来证明 WM 可信，就形成了一个没有外部接地的闭环——系统会越来越自信地错下去。破解办法是给证据**分层**：E_imag（想象）只能提议，E_meas（测量）才能确认，E_cal（标定残差）只作校准证据。支撑分数必须由**不共享 WM 失效模式的通道**给出（集成分歧、独立重建误差、不变量检查、原始数据 OOD 密度、无模型动力学残差）。一句话：**Imagine to plan, measure to believe.** 这也给出一条干净的算力经济学：想象便宜、测量昂贵，但只有测量计入确认。

**灵感 5（假设账本 → 让 R69 / R68 成为边界）**
直觉：每个保证都是有条件的；把尚未被监视器放电的前提记成「融合债务」D_F。债越多越保守：债=0、支撑满、见证独立、想象不参与确认时，FORGE 逐指令退回 R69；债高或 k_eff<2 时退回 R68 纯保守。这与前几轮的理论姿态一致——**新层必须是旧层的严格泛化，而不是并列替代**。而且「未被监视的假设默认计债」这一条，能阻止系统廉价地宣称自己「无债一身轻」。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（FORGE-RAS 总览）** FORGE-RAS = (AGL, WMX, CIE, IMS, HWX, CMC, GLG, FDC, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i / R69 定义 293-i）；
(ii) **契约纪律**：任何被消费的输出必须携带契约 id，消费一个保证必须显式放电其前提或记入债务；未被监视的假设默认计债；
(iii) **想象 / 测量分离**：E_imag 只能提议动作与估计成本，绝不能单独确认模态或支撑；
(iv) **独立性纪律**：每条关键假设至少保留一个**无模型见证**；k_eff < k_min 时视同不独立，退回 R68。

**定义 311（技术融合 = 契约组合）** 组件 i 的契约 C_i = (id_i, A_i, G_i, Φ_i, u_i, τ_i)：A_i 为前提谓词集（定义在运行时状态与其他组件输出上），G_i 为在 A_i 成立且输入落在 Φ_i 内时有效的保证（风险 / 精度 / 安全界），u_i ∈ {ale, model, imag} 为不确定性类型，τ_i 为运行时监视器。组合 C_1 ⊗ … ⊗ C_n 有效 ⇔ 对所有被消费的保证 g∈G_j，其消费点满足 Φ_j；对所有 a∈∪A_i，存在某 g∈G 蕴含 a 且由某个 τ 放电。未被放电的前提进入 D_F（定义 312）。类型系统禁止「无契约消费」。

**定义 312（融合债务 D_F）** D_F = Σ_{a ∈ A_undischarged} w(a)·crit(a)，其中 w(a) 为由监视器 / 先验给出的「前提已失效」后验，crit(a) 为关键度。未被监视的假设取 w=1（保守默认）。D_F 对违规单调不减。

**定义 313（世界模型想象算子 WMX）** 世界模型 M 对反事实查询 q=(x_t, do(a_{t:t+H})) 给出 ŷ ~ M(q)。**支撑分数** s_sup(q) = min_{ρ∈W_exo} ρ(q)，W_exo 为外生见证集：集成分歧、独立编码器重建误差、不变量 / 因果一致性、原始数据 OOD 密度、无模型一步预测残差。可认证支撑域 Q_adm = {q : s_sup(q) ≥ τ_sup}。**关键约束：s_sup 不得使用 M 自己的置信头**——否则一个自信而错误的 M 会给自己盖章。

**定义 314（想象 / 测量证据分层 IMS）** 证据分三类：E_meas（传感器 / 交互的真实测量）、E_imag（世界模型想象）、E_cal（标定残差）。确认算子 Conf(·) 只接受 E_meas；E_imag 只能作为先验 / 候选，遇到反证必须撤销，且**永远不计入独立源数**。形式化要求：不存在仅由 M 的输出构成的不动点使 M 自我认证。

**定义 315（两级 VoI：想象规划 + 测量确认）** 想象增益 VoI_imag(g) = H(M_mode|o) − E_{ŷ~M(g)}[H(M_mode|o,ŷ)]，用于廉价排序与筛除；真实增益 VoI_real(g) 只在 g 通过支撑、安全、预算、成本筛选后估计。算法每轮至多执行 1 个真实信息动作，且确认只许用 E_meas。即「**用想象挑问题，用测量定答案**」。

**定义 316（异质见证与独立性矩阵 HWX）** 见证集 W = {w_flow（无模型流似然）, w_wm（世界模型 rollout）, w_llm（语言语义自洽）, w_cal（标定残差）, w_dyn（无模型动力学残差）}。由共失败统计估计两两相关矩阵 R=[ρ_ij]；有效见证数 k_eff = 1+(k−1)(1−ρ̄)（或 R 谱形式 1/(1ᵀR1/k)）。认证要求 k_eff ≥ k_min（默认 2）。

**定义 317（共模失效上界 CMC）** 相关见证下的错误 / 投毒上界 ≤ δ_p·ρ_max^{k_eff−1}+ε。共享 WM 使 ρ_max ≥ ρ_0>0，因此 k_eff ≤ k_eff^0；当 ρ_max→1 时上界退化为 δ_p。系：**融合的安全收益不可能超过其保留的见证多样性**。

**定义 318（保证洗白守卫 GLG）** τ_i 连续检查 A_i；若某保证在 Φ_i 之外被消费，或在其前提已失效后仍被消费，记一次 guarantee laundering，隔离依赖它的下游保证，D_F 增加，并写入审计。监视器缺失 ⇒ 该假设默认计债（不默认成立）。

**定义 319（融合债务控制器 FDC）** λ = max(λ_R69, λ_floor(U_base + κ·D_F))，其中 U_base 为 R69 的 U_ale（及未消解 U_epi）。若 D_F > τ_D 或 k_eff < k_min：禁用想象交互，λ = λ_floor(U_ale+U_epi) 并取 max(λ, λ_R68)，即退回 R68 纯保守。λ 对 D_F 单调不减。

**定义 320（支撑域证书 J_sup）** J_sup = (support_coverage, s_sup_calibration_ece, exogenous_agreement, off_support_rejection)。Valid ⇔ coverage ≥ γ ∧ ECE ≤ τ_sup_ece ∧ 外生见证一致 ∧ 越界拒绝率 ≥ ρ_rej。

**定义 321（契约携带模型注册表 CMR）** 每个模型 / 组件登记 (contract_id, version, monitor, last_audit)，其输出在运行时被打上契约标签；类型系统阻止未登记 / 未打标签的输出被下游消费。

**定义 322（VQAuditor-F）** 审计对象新增：契约完整性抽样、前提放电记录、证书是否被伪造、支撑声明是否有外生依据、想象 / 测量比、共模相关性变化。结论回灌 AuditBuf，成为下一轮 D_F 的先验。

**定义 323（威胁模型 AIC-FORGE）** ℰ_FORGE = ℰ_FLUID × ℰ_launder × ℰ_commonsource × ℰ_imag。ℰ_launder：伪造监视器 / 放电记录、在适用域外消费保证；ℰ_commonsource：污染共享世界模型，使所有见证一起犯同向错误；ℰ_imag：世界模型在支撑域外自信虚构、或伪造支撑分数。

**定义 324（证书 J_FORGE）** J_FORGE = (J_FLUID, contract_ids, D_F, k_eff, support_coverage, imag_meas_ratio, launder_flags, rho_max, forge_ver)。Valid ⇔ Valid(J_FLUID) ∧ D_F ≤ τ_D ∧ k_eff ≥ k_min ∧ Valid(J_sup) ∧ launder_flags=∅。

```python
# IP-264 AGL：假设-保证账本与契约组合
class Contract:
    def __init__(self, cid, A, G, phi, monitor, unc):
        self.cid, self.A, self.G = cid, A, G
        self.phi, self.monitor, self.unc = phi, monitor, unc

class ContractLedger:
    def compose(self, cs):                    # 静态检查：被消费的保证须落在其 Φ 内
        for c in cs:
            for g in c.G:
                if not c.phi(g.consumer_state): raise ContractError(g)
        return FusedContract(cs)
    def debt(self, state):                    # 未放电前提计债；未监视默认 w=1
        return sum(w(a, state) * crit(a)
                   for a in self.assumptions if not self.discharged(a, state))

# IP-265 WMX：外生支撑分数（绝不用 WM 自己的置信）
def support_score(q, wm, exo):
    return min(rho(q) for rho in exo)         # 集成分歧/重建/不变量/OOD/无模型残差

def admissible(q, wm, exo):
    s = support_score(q, wm, exo)
    return s >= TAU_SUP, s

# IP-266 CIE + IP-315：想象规划，测量确认
def plan_by_imagination(wm, modes, o_t, budget, exo):
    best = None
    for g in info_action_candidates(modes):
        if not budget.allow(g) or not c_ras_wm.certify_info(g, o_t):
            continue
        ok, s = admissible((o_t, do(g)), wm, exo)
        if not ok:                            # 越界想象不可作为候选依据
            continue
        y_hat = wm.imagine((o_t, do(g)))
        score = entropy(modes.w) - expected_entropy(modes.w, y_hat) - cost(g)
        if best is None or score > best.score:
            best = (g, score)
    return best if best and best.score > 0 else None

# IP-267 IMS：想象不得确认
def confirm_modes(modes, g, ledger):
    y_meas = execute_real_measurement(g)      # 只接受 E_meas
    return bayes_update(modes, y_meas, require='meas_only')

# IP-268/269 HWX+CMC：独立性认证
def certify_independence(witnesses, recent):
    R = cofailure_correlation(witnesses, recent)
    k_eff = 1 + (len(witnesses) - 1) * (1 - mean_offdiag(R))
    return R, k_eff

# IP-270 GLG：保证洗白守卫
def launder_guard(ledger, state):
    bad = [a for a in ledger.assumptions
           if not eval(a, state)]
    if bad: ledger.quarantine_downstream(bad)
    return bad

# IP-275 主闭环
def FORGE_RAS_round(M, obs):

    # 1) 先算债务与独立性，再决定敢不敢用想象

    D_F = M.agl.debt(M.state)
    # 2) R69 的廉价歧义门控

    samples = M.fmp.sample(o, K)
```

## 3. 推导

**引理 19（想象不可自证）** 若支撑分数或证据只由 M 自身的输出 / 置信构成，则对任意阈值 τ 与任意错误的世界模型，都存在参数化使 P(s_sup ≥ τ | M 错误) → 1；此时想象通道对真实模态 m* 的互信息不超过训练数据先验已提供的信息，反复自我更新只放大偏差、不增加外部信息。故支撑分数必须外生，且确认必须经过 E_meas。系：**用想象替代测量会把「不确定」变成「自信」**。

**引理 20（融合的独立性坍缩）** 设 k 个见证两两错误相关为 ρ̄，则 k_eff ≤ 1+(k−1)(1−ρ̄)；多数一致的投毒 / 共失败上界为 δ_p·ρ_max^{k_eff−1}+ε。当所有见证共享同一个世界模型而 ρ_max→1，k_eff→1，上界退化为 δ_p。系：**技术融合的安全收益上界 = 保留下来的无模型多样性；共享 WM 越深，越接近「只问一个人」**。

**引理 21（支撑门控的必要性）** 对 q∈Q_adm，想象误差满足 |ŷ−y| ≤ ε_M + L·d(q, ∂Φ)（ε_M 为支撑内模型误差，L 为边界 Lipschitz 常数）；对 q∉Q_adm，不存在与 M 无关的有限误差界。因此越界想象不可作为候选、成本或证据，**支撑门控不是可选项，而是想象能被使用的先决条件**。

**定理 18（FORGE 严格包含 R69）** 在 D_F=0、所有 q∈Q_adm、监视器齐全、k_eff≥k_min、E_imag 不参与确认的条件下，FORGE 的决策与 R69 逐指令相同；当 D_F>0 时，因 λ 对 D_F 单调不减，FORGE 的期望风险 ≤ R69；当 D_F>τ_D 或 k_eff<k_min 时，FORGE 退化为 R68。故 R70 是 R69 的保守扩展：**安全侧不做任何让步，效率侧只在不借债时获得想象红利**。

**定理 19（共模安全的条件融合）** 若每条关键假设至少保留一个无模型见证，且 k_eff≥k_min，则融合系统的错误 / 投毒界 ≤ δ_p·ρ_max^{k_eff−1}+ε，且不超过 R69 的单见证界；若 k_eff<k_min，FDC 与 GLG 使其退回 R68。该定理是**条件性**的：它保证的是「在独立性被认证时安全」，而不是「融合天然安全」——独立性估计本身的误差，正是 R70 的残余风险。

```python
    mode = select_mode(modes, U_epi, lam)
    tau = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_f.submit_async(g, D_F, k_eff, M.wmx.last_support, M.ims.imag_meas_ratio)
    return k, lam, mode, (U_ale, U_epi, D_F, k_eff)
```

## 4. 推导

**引理 19（想象不可自证）** 若支撑分数或证据只由 WM 自身输出/置信构成，则存在参数化使错误 WM 也以高概率通过任意 `τ` 的自检；此时想象通道对真实模态的互信息不超过训练先验，反复自我更新只放大偏差。故支撑分数必须外生、确认必须经 `E_meas`。系：**用想象替代测量，会把「不确定」变成「自信」**。

**引理 20（融合的独立性坍缩）** k 个见证两两相关 `ρ̄` 时 `k_eff ≤ 1+(k−1)(1−ρ̄)`，错误/投毒界 ≤ `δ_p·ρ_max^{k_eff−1}+ε`；共享 WM 使 `ρ_max→1`，`k_eff→1`，界退化为 `δ_p`。系：**融合的安全收益不可能超过其保留的无模型多样性**。

**引理 21（支撑门控的必要性）** 支撑内想象误差 ≤ `ε_M + L·d(q,∂Φ)`；支撑外无有限误差界。故越界想象不可作候选/成本/证据，支撑门控是想象可被使用的先决条件。

**定理 18（FORGE 严格包含 R69）** `D_F=0`、全支撑、监视器齐全、`k_eff≥k_min`、想象不确认时，FORGE 与 R69 逐指令相同；`D_F>0` 时风险 ≤ R69（λ 单调）；高债 / 低多样性时退化为 R68。R70 是 R69 的保守扩展。

**定理 19（共模安全的条件融合）** 每条关键假设至少一个无模型见证且 `k_eff≥k_min` 时，错误/投毒界 ≤ `δ_p·ρ_max^{k_eff−1}+ε`，且不超过 R69 单见证界；`k_eff<k_min` 时 FDC/GLG 退回 R68。注意：这是**条件性**保证——独立性估计本身的误差是残余风险。

## 7. 预期结果与验收口径

- **严格包含**：E309 必须在「债=0 / 全支撑 / 独立见证 / 想象不确认」四条件下给出逐指令零差异；否则 R70 不是扩展而是替换，方案作废。
- **共模可检出**：E304/E305 必须显示「共享 WM 污染 → k_eff 下降 → 策略自动回退」的因果链，而不是只在日志里报一个相关性数字。
- **想象红利**：E303 的真实交互次数应显著下降，且 E302 不得出现「想象越多、越自信、越错」的自证曲线。
- **假设账本**：E307 中，任何未被监视的注入前提都必须让证书失败；若系统仍宣称有效，说明默认计债策略失效。
- **延时**：常规路径不得突破 3.0ms；歧义路径允许一次性 <3.8ms，超出即触发 K=1 降级。

## 8. 本轮最大风险

**一句话**：FORGE-RAS 最危险的假设是「**账本已经写全了**」——任何没被写进合同的假设都不会产生债务，于是 `D_F=0`、证书显示「有效」，而系统恰恰错在没人想到的地方；技术融合还会制造任何单模块合同都未预见的**涌现耦合**，使缺失的假设既不可见、也不可监视——**证书最危险的不是它证明了什么，而是它没有列出的前提**。

**次级风险与缓解**：支撑估计器的二阶循环（强制外生见证 + J_sup 交叉校验，但外生性不可完全证明）；独立性估计受数据限制（保留无模型见证 + 最坏按 ρ=1 兜底 + E304/E305 对抗采样）；契约爆炸与维护成本（静态组合 + 默认债务自动化 + 只对关键假设人工审计）；想象 rollout 延迟（仅歧义路径 + 潜空间 1–2 步 + 缓存）；LLM 语义见证不独立/可被诱导（冻结模型 + 独立接地检查 + 语义见证只算一个源）。
