# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「多语言支持」×「意图识别」）

> R69 把不确定性一分为二，并给了系统一张嘴：问。它用流匹配生成「看—问—触—等」的信息动作，用 VoI 决定值不值得问，用「k 个正交证据源一致」防止被单次回答骗。整套机器成立在一个未被言明的前提上：**`g_ask` 经冻结 LLM 解码成一句问句，对方的回答再被同一套语义理解吸收——语言是一条透明的信道，意图是一个语言无关的标签。**
>
> 两个灵感同时拆掉这个前提：
> - **意图识别**告诉我们，意图不是可以直接读出的标签，而是 `(目标, 语用力量, 承诺)` 的复合潜变量。同一句话可以是请求也可以是拒绝（「我再考虑一下」「検討します」「I'll think about it」），同一个意图可以用完全不同的语言、礼貌策略和间接程度表达。R69 的模态聚类只处理了「做哪件事」，没有处理「**这句话到底是不是在让我做**」——而后者才是不可逆伤害的真正来源。
> - **多语言支持**告诉我们，语言不是透明信道，而是**带折射率的介质**：同一个意图穿过不同语言后，语义、语用、承诺强度都会漂移；更致命的是，多语言输出共享同一套英语中心预训练表征，**「用三种语言问同一个问题」看起来是三个证人，实际高度相关**，恰好会制造 R69 最害怕的「被证实的错误」。
>
> 核心命题：**把意图从「标签」升级为「语言纤维丛上的截面」：底空间是语言无关的意图本体（目标 × 语用力量 × 承诺），每根纤维是一个语言的表达与语用透镜；意图不确定性沿语言与语用两个方向分解；跨语言一致性只作为「语言信道自洽」的证据，绝不被当作独立证人；任何不可逆动作必须在用户自己的语言里被 teach-back 或非语言确认，否则退化为 R69 的保守。** 命名 **LINGUA-RAS**（Language-Indexed iNtent Grounding & Uncertainty Arbitration for Risk-Adaptive Systems）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我听懂的是你的意图，还是我自己的语言？我有没有让用户为了被理解而放弃自己的语言**」。

## 0. 直觉与动机

**命题 P1（意图是带类型的潜变量，不是分类标签）**
直觉：经典意图识别把一句话映射到封闭标签集上的一个点，但人说话同时携带三层信息：**目标**（想让我做什么）、**语用力量**（我是在请求、告知、确认、拒绝、授权，还是只是在客气）、**承诺强度**（这件事可不可逆、要不要再确认一次）。把三层压成一个标签，会把「礼貌拒绝」误读为「同意」、把「听见了」误读为「照做」、把「我考虑一下」误读为「可以」。Austin/Searle 的言语行为理论、Grice 的合作原则、Brown & Levinson 的礼貌理论都在说同一件事：**字面内容不等于交际意图**。R69 把意图当成「动作模态」的来源，实际上只用了目标层；语用层与承诺层几乎空白，而恰恰是这两层决定了一个错误是否可挽回。

**命题 P2（语言是测量信道，翻译不是预处理）**
直觉：多语言支持常被实现成「内部先翻成英语再理解」。这不是支持，而是把用户的表达强行投影到一个高资源语言的坐标系里，并且把投影误差当成噪声吞掉。更严谨的看法是：**翻译是一次测量**，有增益、有偏置、有分辨率；不同语言对同一意图的「可分辨半径」不同。低资源语言上模型更不校准，而这正是用户最需要被理解的地方。R69 的 `ECE` 是一个标量；R70 必须把它变成按语言、按语用力量索引的矩阵。**系统最自信的地方，可能正是它最听不懂的地方。**

**命题 P3（多语言不是多证人，而是相关证人）**
直觉：R69 的证据纪律说「单源不得定案，要 k 个正交证据源一致」。一个自然的想法是：那我用中文、英文、日文各问一遍，不就得到三个证据源了吗？错了。三种语言共享同一套预训练表征、同一套世界知识、同一套对齐偏差；它们的错误是**共模**的，不会在多数投票中相互抵消。**跨语言一致性度量的是「我的翻译器自洽不自洽」，不是「世界是不是这样」。** 真正的正交证据只能来自语言之外：示范、指向、选项选择、动作、传感器，或用户明确的二次确认。

**命题 P4（把翻译损失变成可测量的 holonomy）**
直觉：设想意图从中文出发，翻成英文，再翻成日文，再翻回中文——如果回到的句子与原来不同，那个差额就是语言信道在绕行一圈后留下的「曲率」。微分几何里叫 holonomy。它不是一个比喻而已：它给出一个**可测的不可识别半径**——若环回误差为 e，则任何仅使用该语言信道的解码器，都无法把距离小于 e/L 的两个意图稳定分开（L 为转移映射的 Lipschitz 常数）。于是「翻译得好不好」从主观判断变成了一个证书：`e_cyc` 超过决策间隔，就不许在该信道上定案。

**命题 P5（R69 是本轮在「单语言、已校准、语用无歧义」边界上的严格退化）**
直觉：当只有一种语言、没有 code-switch、该语言校准良好、语用力量可从句法/上下文唯一确定、也没有开放集意图时，纤维丛退化为单点，holonomy 为零，相关证据修正因子为一，语用确认协议自动跳过。此时 LINGUA-RAS 必须与 FLUID-RAS **逐指令相同**。这是本轮的理论底线：**新层不是并列替代，而是旧层的严格泛化**；否则每加一层就多一个需要独立信任的黑箱，R66–R69 累积的安全论证会被稀释。

**命题 P6（语言本身就是新的攻击面）**
直觉：一旦系统「会多语言」，攻击者就有了新入口：切到低资源语言绕过安全对齐、用对抗性回译污染意图、用过度礼貌/间接言语行为掩盖拒绝、在另一种语言里冒充权威、把 paraphrases 集成投毒成「一致」。R69 的 `ℰ_poison` 只覆盖了「人撒谎」；R70 必须覆盖「语言这一层本身被武器化」。**系统越流利，越容易被流利地骗。**

## 1. 形式化定义（增量：定义 310–325）

**定义 310（LINGUA-RAS 总览）** LINGUA-RAS = (LIP, PRAG, XCA, LCG, LNA, PSI, RAS-WM†)。三不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **不可逆动作不得仅凭语言证据定案**：当承诺强度 c = irreversible 时，语用力量/授权必须至少经过一次 teach-back 或一次非语言确认；
(iii) **语言公平**：默认使用用户自己的语言；切换语言是一个显式信息动作，必须计入用户负担并写审计日志，不能作为内部预处理偷偷发生。

**定义 311（多语言意图观测）** 第 t 轮用户产生表达 u（允许 code-switching 序列），语言标签 ℓ ∈ L ∪ {mixed}。意图 m = (g, f, c) ∈ M = G × F × C：目标 g、语用力量 f ∈ {request, inform, confirm, refuse, consent, uncertain}、承诺强度 c ∈ {none, revocable, irreversible}。观测 o^L_t = (u, ℓ, s, p)，其中 s 为对话/场景上下文、p 为可得的韵律/表情等副语言线索。意图识别输出后验 p(m, ℓ | o^L_t)。

**定义 312（意图纤维丛）** 底空间 B 为语言无关的意图本体（M 对语言等价关系取商），投影 π: E → B；纤维 F_ℓ 为语言 ℓ 的表达空间 U_ℓ 及其语用透镜。编码器 E_ℓ: U_ℓ → Z，实现器 D_ℓ: Z → U_ℓ，语用映射 φ_ℓ: Z → P(F)。语言间转移 φ_{ℓℓ'} = E_{ℓ'} ∘ D_ℓ 是「翻译」的形式化，它不保证可逆，也不保证等距。截面 σ_ℓ: B → E 表示「用语言 ℓ 表达某个意图」的一致选择。

**定义 313（语义 holonomy 与环回误差）** 对语言环路 γ = (ℓ_0, ℓ_1, …, ℓ_k = ℓ_0)，holonomy H_γ = φ_{ℓ_{k-1}ℓ_k} ∘ … ∘ φ_{ℓ_0ℓ_1} − id。工程代理：`e_cyc(u) = d(u, D_{ℓ_0}(E_{ℓ_k}(…D_{ℓ_0}(u)…)))`，即回译/改写环回后的语义距离；`e_cyc_p95` 为其 95 分位。H_γ ≠ 0 表示语言信道不是无损的；它不是「翻译质量分数」，而是**该信道在当前意图邻域内的不可识别性证书**。

**定义 314（意图不确定性分解）** U_int = (U_ale^int, U_epi^int, U_lang, U_prag, U_trans, U_open)：
- `U_ale^int`：用户自己也未决定的真实意图歧义（不可约；反复追问是胁迫，不是消歧）；
- `U_epi^int`：可通过澄清消除的解释歧义；
- `U_lang`：语言识别/code-switch 不确定（该用哪种语言理解与回答）；
- `U_prag`：语用力量不确定（请求/拒绝/授权分不清）；
- `U_trans`：翻译/holonomy 引入的语义漂移（进入语言信道的噪声底）；
- `U_open`：开放集/本体失配（用户的目标不在系统标签集内）。
处置规则：`U_epi^int, U_lang, U_open` 可「问」；`U_prag` 只能「确认」（teach-back/选项/示范）；`U_trans` 只能「测」（holonomy + 校准）；`U_ale^int` 只能「保守」（R68 λ_floor）。六者语义不同，不做简单加和。

**定义 315（语言-语用联合校准）** 对每种语言 ℓ，维护意图校准 `ECE_ℓ` 与语用混淆矩阵 `C_ℓ(f' | f)`：
`ECE_ℓ = Σ_b (n_b/N) |acc_b − conf_b|`，`R_prag,ℓ = max_{f≠f'} C_ℓ(f' | f)`。
低资源语言样本少，校准阈值随有效样本量膨胀：`τ_ℓ = τ_0 + κ/√n_ℓ`。语言校准门 LCG 接受该语言，当且仅当 `ECE_ℓ ≤ τ_ℓ` 且 `R_prag,ℓ ≤ δ_f`；否则该语言上的 VoI 决策被禁用，只能走确认协议或非语言通道。

**定义 316（相关性感知的有效独立源数）** 证据源 i 的权重 w_i，任意两源错误相关系数 ρ_ij。有效独立源数
`k_eff = (Σ_i w_i)^2 / (Σ_i Σ_j w_i w_j ρ_ij)`。
对等相关的 k 个跨语言改写/回译，`k_eff = k / (1 + (k−1)ρ)`；当 ρ→1 时 `k_eff→1`，多加语言不增加证据。非语言锚点（示范、指向、动作、传感器）只有在与语言通道错误去相关时才按独立源计。R69 的「k 个正交源」纪律升级为 `k_eff ≥ k_min`。

**定义 317（语言协商 LNA）** 选择交流语言与澄清形式：
`ℓ* = argmax_ℓ [ VoI(m; y | ℓ) − c_user(ℓ) − c_social(ℓ) ]`，s.t. 语言公平约束与交互预算。
`c_user(ℓ)` 对非母语表达是非对称的：要求用户改用不熟悉的语言，会提高其表达误差与认知负担；`c_social(ℓ)` 覆盖礼貌、身份与场合成本。语言税 `τ_lang = E[额外澄清轮数 | ℓ ≠ ℓ_user]` 必须被度量，不能转嫁给用户。

**定义 318（语用安全交互 PSI）** 在 R69 的 `g_gaze/g_probe/g_ask` 之外新增信息动作：
`g_paraphrase`（teach-back：用用户的语言复述「我理解你是想要 X，对吗」）、
`g_option`（给出 2–3 个具体选项，让用户指选）、
`g_demo`（请用户示范一次）、
`g_switch`（显式协商交流语言）、
`g_confirm`（对不可逆承诺做显式确认）。
对 c = irreversible 的意图，至少需要 {teach-back, 选项选择, 示范, 显式确认} 中的两项，且其中至少一项是非语言证据或用户明确二次确认；单句「是/好/OK」永不单独定案。

**定义 319（意图可识别性与两个下界）** 用 `I(m; o^L)` 度量语言信道对意图的信息量，`I(f; proposition)` 度量字面内容对语用力量的信息量。
(i) **holonomy 下界**：若转移映射 L-Lipschitz 且 `e_cyc ≥ ε`，则存在两个意图 m ≠ m'，`d_B(m, m') ≥ ε/L`，在语言信道上产生不可区分观测；任何解码器的均匀误差半径 ≥ `ε/(2L)`。
(ii) **语用内容下界**：对间接言语行为，`I(f; proposition)` 可以为零（「我考虑一下」既可以是告知也可以是拒绝）；仅凭字面内容的语用错误率 ≥ `min(π_f, 1−π_f)`。高承诺场景下，确认的 VoI 在「错判代价 > 询问成本」时严格为正。

**定义 320（LINGUA 证书 J_LINGUA）** J_LINGUA = (J_FLUID, {ECE_ℓ}, {R_prag,ℓ}, e_cyc_p95, k_eff_min, intent_ECE, language_fairness_log, clarification_log_hash, lingua_ver)。Valid ⇔ Valid(J_FLUID) ∧ 活跃语言均过 LCG ∧ `k_eff ≥ k_min` ∧ 不可逆承诺已确认 ∧ 语言税未越界。

**定义 321（三级保守退避，严格包含 R69）**
- Level 0（语言校准良好、意图已消解、语用无歧义）：`λ = λ_floor(U_ale^int)`，获得与 R69 相同的 resolution bonus；
- Level 1（语言/语用未校准、holonomy 超阈、code-switch 未定）：禁用该语言上的 VoI 定案，改用 PSI 在用户语言里确认；确认成功按 Level 0，失败/超时把残余 `U_epi^int + U_prag` 折入 aleatoric；
- Level 2（不可逆承诺未确认、开放集未解、语言税超预算、被投毒）：不执行不可逆动作，回 R68 纯保守并显式交接。
⇒ 当 L={ℓ0}、无 code-switch、`ECE_ℓ0 ≤ τ`、`I(f; proposition)` 可识别、无开放集时，LINGUA-RAS 逐指令退化为 FLUID-RAS。

**定义 322（跨语言攻击面 ℰ_lingua）** 至少包含：切到低资源语言绕过安全对齐（code-switch injection）、对抗性回译/改写投毒、以过度礼貌或间接言语行为掩盖拒绝、方言/语用语域错配、跨语言冒充权威的社交工程、paraphrase 集成共谋制造「一致」。并入 AIC：`ℰ_LINGUA = ℰ_FLUID × ℰ_lingua`。

**定义 323（语言公平指标）** 对每种语言分别报告：意图准确率、语用力量准确率、校准误差、澄清负担、不可逆误执行率。定义公平缺口 `Δ_fair = max_ℓ metric_ℓ − min_ℓ metric_ℓ`；安全侧的不可逆误执行率缺口必须被 LCG 与确认协议压到与高资源语言同量级。

**定义 324（主动澄清的停止与非胁迫规则）** 当后验熵 < τ_H、`VoI ≤ c`、预算耗尽、或继续追问会越过用户负担阈值时停止。对 `U_ale^int`（用户真的没想好）最多追问 `n_max` 次；超过即视为胁迫，直接走安全默认，不允许用重复提问「逼出」一个看似确定的答案。

**定义 325（LINGUA 与 R69 的双向接口）** 意图后验只负责**选择与授权**，不直接改变控制安全包络；选中的目标 g 交给 R69 的模态/动作层，`U_prag` 与 `U_trans` 通过 Level 1/2 退避影响风险缩放 λ 与认证前缀长度 k。信息动作 g 仍必须通过与任务动作相同的 C-RAS-WM 认证。

## 2. 关键算法骨架

```python
# IP-264 LIP：语言索引的意图后验（复用 R69 的 z_t 与 MTM trunk）
class LanguageIntentPosterior:
    def infer(self, u, lang, ctx):
        lang_post = detect_language_and_codeswitch(u)      # p(ℓ), mixed 标记
        z = self.trunk.encode(u, lang, ctx)
        p_goal  = self.head_goal(z)                        # 目标后验
        p_force = self.head_force(z)                       # 语用力量后验
        p_commit = self.head_commit(z)                     # 承诺强度
        return IntentPosterior(p_goal, p_force, p_commit, lang_post)

    def decompose(self, post):
        U_ale  = entropy(post.p_goal) * indecision_mass(post)
        U_epi  = mutual_info_gap(post)                     # 可由澄清消除的部分
        U_lang = entropy(post.lang_post)
        U_prag = entropy(post.p_force) * high_stakes(post)
        U_trans = 0.0                                      # 由 XCA 在线测量
        U_open = open_set_score(post)
        return U_ale, U_epi, U_lang, U_prag, U_trans, U_open

# IP-265 PRAG：语用力量解析（区分字面内容与言语行为）
def resolve_force(post, ctx, prosody):
    if is_indirect_speech_act(post.utterance, ctx):
        return force_from_context(post, ctx, prosody)      # 需要上下文/副语言
    return post.p_force

# IP-266 XCA：holonomy / 环回一致性审计（只在歧义或高承诺时触发）
def holonomy_score(encoder, decoder, u, langs):
    cur = u
    for ℓ in cycle(langs):                                 # ℓ0 → ℓ1 → … → ℓ0
        cur = decoder[ℓ](encoder[ℓ](cur))
    return semantic_distance(u, cur)                       # e_cyc，越大越不可信

# IP-270 CECA：把跨语言一致性折成有效独立源数
def effective_sources(evidence, rho):
    w = weights(evidence)
    denom = sum(w[i] * w[j] * rho[i][j] for i in evidence for j in evidence)
    return (sum(w) ** 2) / denom                           # ρ→1 时 k_eff→1

# IP-267 LCG：语言-语用校准门
def language_gate(lang, ece, prag_confusion, n_lang):
    tau = TAU0 + KAPPA / sqrt(n_lang)                      # 低资源阈值更宽
    return ece <= tau and max_offdiag(prag_confusion) <= DELTA_F

# IP-268 LNA：语言协商（默认留在用户语言，切换是显式动作）
def choose_language(user_lang, candidates, budget):
    best = None
    for ℓ in candidates:
        voi  = expected_intent_info(ℓ) - expected_translation_loss(ℓ)
        cost = user_burden(ℓ, user_lang) + social_cost(ℓ)
        s    = voi - cost
        if best is None or s > best.s: best = (ℓ, s)
    # 公平约束：除非收益超过 Δ_fair，否则留在用户语言
    return user_lang if best is None or best.s <= DELTA_FAIR else best.ℓ

# IP-269 PSI：语用安全交互（不可逆承诺必须确认）
def pragmatic_safe_confirm(intent, post, budget):
    if intent.commit != "irreversible":
        return True
    actions = [g_paraphrase, g_option, g_demo, g_confirm]
    supporting = [a for a in actions if budget.allow(a) and c_ras_wm.certify_info(a)]
    # 至少两项，且至少一项非语言证据或显式二次确认
    ok = len(supporting) >= 2 and any(is_nonverbal(a) or a.is_explicit for a in supporting)
    return ok and execute_confirmation(supporting)         # 失败/超时 → Level 2

# IP-274 LINGUA-RAS 主闭环（继承 R69，仅在意图层插入语言/语用处理）
def LINGUA_RAS_round(M, obs):
    z, o = M.mtm.forward(...)                              # R69 一次前向
    post = M.lip.infer(obs.u, obs.lang, obs.ctx)           # 意图后验
    force = M.prag.resolve_force(post, obs.ctx, obs.prosody)
    U_ale, U_epi, U_lang, U_prag, _, U_open = M.lip.decompose(post)
    # 1) 只在高歧义/高承诺时测 holonomy，避免实时浪费
    U_trans = (M.xca.holonomy_score(obs.u, obs.langs)
               if (U_epi > TAU_EPI or post.commit == "irreversible") else 0.0)
    # 2) 语言-语用校准门；不过门则禁用该语言上的 VoI 定案
    gate = M.lcg.language_gate(obs.lang, M.ece[obs.lang], M.prag_conf[obs.lang], M.n[obs.lang])
    # 3) 语言协商：默认用户语言；切换必须值得且记入语言税
    lang = M.lna.choose_language(obs.lang, M.langs, M.budget)
    # 4) 语用确认优先于「问更多」：不可逆承诺先 teach-back/选项/示范
    confirmed = M.psi.pragmatic_safe_confirm(post, force, M.budget)
    if not confirmed:
        return M.ras_wm.safe_default(post), "level2_handover"
    # 5) 可消解的意图歧义才交给 R69 的 VoI 交互
    if gate and U_epi > TAU_EPI and U_open < TAU_OPEN:
        g = M.mint.choose_interaction(post, o, M.budget, lang=lang)
        if g is not None:
            answer = M.cia.execute(g)
            k_eff = M.ceca.effective_sources(answer.sources, M.rho)
            if k_eff >= K_MIN:
                post = M.cia.update_belief(post, answer)
                U_epi = post.residual_entropy
    # 6) 退避：语言/语用未消解的部分折入 aleatoric
    U_floor = U_ale + (U_epi + U_prag if not gate or not confirmed else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    A = M.ach.propose(post.goal, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    if U_trans > TAU_CYC or not gate:
        lam = max(lam, 0.8)                                # 回 R68 最保守
    tau = M.pi_sigma.prefix_dispatch(A[:k]) * lam
    M.vqa_l.submit_async(post, force, e_cyc=U_trans, k_eff=k_eff, lang=lang)
    return k, lam, post, (U_ale, U_epi, U_prag, U_trans)
```

## 3. 推导

**引理 19（跨语言证据的相关性折损）** 设有 k 个跨语言改写/回译证据，各自错误率为 δ，两两错误相关系数为 ρ。令 `k_eff = k / (1 + (k−1)ρ)`。则多数投票的误差下降由 `k_eff` 而非 k 支配；当 ρ→1 时 `k_eff→1`，增加语言不降低误差。证明要点：把每个证据的错误分解为共模分量与特异分量，等权平均的方差为 `σ²[(1−ρ)/k + ρ]`，只有特异分量随 k 衰减，有效样本量即 `k_eff`。系：**R69 的「k 个正交源」不能由语言多样性满足**；跨语言一致只能作为「语言信道自洽」的弱证据，真正的第二意见必须来自语言之外。

**引理 20（holonomy 给出的不可识别半径）** 设语言转移映射 L-Lipschitz，环路 γ 的 holonomy 范数为 `e_cyc`。则存在两个意图 m ≠ m'，满足 `d_B(m, m') ≥ e_cyc / L`，使语言信道对二者的观测分布不可区分；因此任何仅用该信道的解码器，其均匀误差半径下界为 `e_cyc / (2L)`。证明要点：若所有距离小于 e_cyc/L 的意图都可区分，则沿环路复合回原点的映射必须为恒等，与 holonomy 非零矛盾；取 holonomy 作用下的点与其像即可构造不可区分对。系：XCA 的 `e_cyc` 超过决策所需间隔时，必须拒绝在该信道上定案，这正是 Level 1 退避的触发条件。

**引理 21（语用力量的内容不可识别性）** 对间接言语行为，字面命题 P 与语用力量 F 可以满足 `I(F; P) = 0`。此时仅凭 P 的 Bayes 语用错误率 ≥ `min(π_f, 1−π_f)`，其中 π_f 为先验。证明：构造两个语用力量 f1 ≠ f2 对应同一命题（如「我考虑一下」既可为 inform 也可为 refuse），观测 P 不改变后验，错误率即少数类比例。系：高承诺场景下，确认动作的信息增益严格为正；其成本低于错判的期望损失时，teach-back/选项/示范是**理性且必要**的，而不是礼貌装饰。

**定理 18（LINGUA 严格包含 R69）** 在 A95–A99 下，当语言集 L = {ℓ0}、无 code-switch、`ECE_ℓ0 ≤ τ_ℓ0`、`R_prag,ℓ0 ≤ δ_f`、`e_cyc ≤ ε`、`U_open = 0` 时，LIP/PRAG/XCA/LCG/LNA/PSI 全部退化为恒等或零操作，LINGUA-RAS 与 FLUID-RAS 在任意状态上**逐指令相同**。因此 LINGUA 的期望风险 ≤ R69，且在无交互时取等。语言层只在旧层之上增加「不执行未确认的不可逆动作」这一安全约束，安全侧不做任何让步。

**定理 19（语用确认的安全性与无突变）** 对 c = irreversible 的意图，PSI 要求至少两项证据且至少一项非语言/显式确认；在确认失败、超时、被投毒或语言税越界时，λ 单调不降地退化为 R68 纯保守。由于确认动作只改变「是否选择/授权某个目标」，不改变 C-RAS-WM 的安全包络，且所有动作仍需前缀认证，R69 定理 17 的连续性与无突变性保持。语言协商也不扩大安全包络，只改变信息获取方式。

**定理 20（语言公平不降低安全性）** 在 LCG 与 PSI 生效时，未校准语言不会被用于 VoI 定案，而是回退到用户语言中的确认协议或非语言选项；因此不可逆误执行率的跨语言缺口不超过「确认协议的残余错误率」而非校准缺口。若某语言连确认协议都不可用，则 Level 2 显式交接，系统不静默地把理解责任转嫁给用户。**语言公平在这里不是伦理附加项，而是防止「低资源语言 → 高置信误执行」的安全约束。**

**定义 317（语言协商）** `ℓ* = argmax_ℓ [VoI(m;y|ℓ) − c_user(ℓ) − c_social(ℓ)]`，默认留在用户语言；语言税 τ_lang 必须被度量且不转嫁。

**定义 318（语用安全交互）** 新增 `g_paraphrase / g_option / g_demo / g_switch / g_confirm`；不可逆承诺需至少两项证据且至少一项非语言/显式确认；单句「是/好/OK」永不单独定案。

**定义 319–320（两个下界与证书）** holonomy 下界：`e_cyc ≥ ε ⇒` 误差半径 ≥ `ε/(2L)`；语用内容下界：`I(f;proposition)` 可为 0，语用错误率 ≥ `min(π_f,1−π_f)`。J_LINGUA 并入每语言 ECE、语用混淆、e_cyc、k_eff、公平日志。

**定义 321–323（三级退避与攻击面）** Level 0 消解→R69 resolution bonus；Level 1 未校准/holonomy 超阈→禁用语言 VoI，转 PSI 确认；Level 2 不可逆未确认/开放集/超预算/被投毒→不执行并回 R68。`ℰ_LINGUA = ℰ_FLUID × ℰ_lingua`；公平指标含不可逆误执行率的跨语言缺口。

**定义 324–325（非胁迫停止与接口）** 对 `U_ale^int` 最多追问 `n_max` 次，超过即视为胁迫并走安全默认；意图层只负责选择与授权，动作仍走 R69 模态层与 C-RAS-WM 认证。

## 3. 关键算法伪代码

```python
# IP-264 LIP：语言索引的意图后验（复用 R69 的 MTM trunk / z_t）
class LanguageIntentPosterior:
    def infer(self, u, lang, ctx):
        lang_post = detect_language_and_codeswitch(u)
        z = self.trunk.encode(u, lang, ctx)
        return IntentPosterior(self.head_goal(z), self.head_force(z),
                               self.head_commit(z), lang_post)

    def decompose(self, post):
        return (entropy(post.p_goal) * indecision_mass(post),   # U_ale^int
                mutual_info_gap(post),                          # U_epi^int
                entropy(post.lang_post),                        # U_lang
                entropy(post.p_force) * high_stakes(post),      # U_prag
                0.0,                                            # U_trans ← XCA
                open_set_score(post))                           # U_open

# IP-266 XCA：holonomy / 环回一致性
def holonomy_score(encoder, decoder, u, langs):
    cur = u
    for ℓ in cycle(langs):                                  # ℓ0→ℓ1→…→ℓ0
        cur = decoder[ℓ](encoder[ℓ](cur))
    return semantic_distance(u, cur)                        # e_cyc

# IP-270 CECA：跨语言一致性的相关性折损
def effective_sources(evidence, rho):
    w = weights(evidence)
    denom = sum(w[i] * w[j] * rho[i][j] for i in evidence for j in evidence)
    return (sum(w) ** 2) / denom                            # ρ→1 ⇒ k_eff→1

# IP-267 LCG：语言-语用校准门
def language_gate(lang, ece, prag_confusion, n_lang):
    tau = TAU0 + KAPPA / sqrt(n_lang)
    return ece <= tau and max_offdiag(prag_confusion) <= DELTA_F

# IP-268 LNA：语言协商（默认用户语言）
def choose_language(user_lang, candidates, budget):
    best = max(candidates, key=lambda ℓ: expected_intent_info(ℓ)
               - expected_translation_loss(ℓ) - user_burden(ℓ, user_lang)
               - social_cost(ℓ), default=None)
    return user_lang if best is None or best.score <= DELTA_FAIR else best.ℓ

# IP-269 PSI：不可逆承诺的语用确认
def pragmatic_safe_confirm(intent, post, budget):
    if intent.commit != "irreversible":
        return True
    acts = [a for a in (g_paraphrase, g_option, g_demo, g_confirm)
            if budget.allow(a) and c_ras_wm.certify_info(a)]
    ok = len(acts) >= 2 and any(is_nonverbal(a) or a.is_explicit for a in acts)
    return ok and execute_confirmation(acts)                # 失败→Level 2

# IP-274 主闭环（继承 R69，仅在意图层插入语言/语用处理）
def LINGUA_RAS_round(M, obs):
    z, o = M.mtm.forward(...); post = M.lip.infer(obs.u, obs.lang, obs.ctx)
    U_ale, U_epi, U_lang, U_prag, _, U_open = M.lip.decompose(post)
    U_trans = (M.xca.holonomy_score(obs.u, obs.langs)
               if (U_epi > TAU_EPI or post.commit == "irreversible") else 0.0)
    gate = M.lcg.language_gate(obs.lang, M.ece[obs.lang],
                               M.prag_conf[obs.lang], M.n[obs.lang])
    lang = M.lna.choose_language(obs.lang, M.langs, M.budget)
    if not M.psi.pragmatic_safe_confirm(post, U_prag, M.budget):
        return M.ras_wm.safe_default(post), "level2_handover"
    if gate and U_epi > TAU_EPI and U_open < TAU_OPEN:
        g = M.mint.choose_interaction(post, o, M.budget, lang=lang)
        if g is not None:
            ans = M.cia.execute(g)
            k_eff = M.ceca.effective_sources(ans.sources, M.rho)
            if k_eff >= K_MIN:
                post = M.cia.update_belief(post, ans); U_epi = post.residual_entropy
    U_floor = U_ale + (U_epi + U_prag if not gate else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    A = M.ach.propose(post.goal, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    if U_trans > TAU_CYC or not gate: lam = max(lam, 0.8)
    tau = M.pi_sigma.prefix_dispatch(A[:k]) * lam
    M.vqa_l.submit_async(post, U_prag, e_cyc=U_trans, k_eff=k_eff, lang=lang)
    return k, lam, post, (U_ale, U_epi, U_prag, U_trans)
```

## 4. 推导

**引理 19（跨语言证据的相关性折损）** k 个跨语言改写/回译证据、两两错误相关 ρ 时，`k_eff = k/(1+(k−1)ρ)`；多数投票的误差下降由 k_eff 支配，ρ→1 时 `k_eff→1`，增加语言不降低误差。系：R69 的「k 个正交源」**不能由语言多样性满足**；跨语言一致只是语言信道自洽的弱证据，真正的第二意见必须来自语言之外（示范/指向/动作/传感器/显式确认）。

**引理 20（holonomy 的不可识别半径）** 若转移映射 L-Lipschitz、环路 holonomy 范数为 `e_cyc`，则存在 m≠m'，`d_B(m,m') ≥ e_cyc/L`，在语言信道上不可区分；任何仅用该信道的解码器误差半径 ≥ `e_cyc/(2L)`。系：`e_cyc` 超过决策间隔即触发 Level 1 退避——这是可证明的证书，不是启发式。

**引理 21（语用力量的内容不可识别性）** 对间接言语行为，`I(f; proposition)=0` 可以成立；仅凭字面内容的语用错误率 ≥ `min(π_f,1−π_f)`。系：高承诺场景下确认动作的 VoI 在「错判代价 > 询问成本」时严格为正，teach-back/选项/示范是必要安全动作。

**定理 18（LINGUA 严格包含 R69）** 单语言、无 code-switch、`ECE≤τ`、`R_prag≤δ`、`e_cyc≤ε`、`U_open=0` 时，所有新组件退化为恒等/零操作，LINGUA-RAS 与 FLUID-RAS 逐指令相同；期望风险 ≤ R69，无交互时取等。语言层只增加「不可逆动作须确认」这一安全约束，安全侧不让步。

**定理 19（语用确认与无突变）** 不可逆承诺需至少两项证据且至少一项非语言/显式确认；失败/超时/投毒/超预算时 λ 单调不降地退化为 R68；确认只改变「选/授权哪个目标」，不改变安全包络，R69 定理 17 的连续性与换装不变式保持。

**定理 20（语言公平不降低安全性）** LCG 与 PSI 生效时，未校准语言不用于 VoI 定案，而回退到用户语言中的确认协议或非语言选项；不可逆误执行的跨语言缺口由确认协议残余误差而非校准缺口决定；若确认不可用则 Level 2 显式交接，系统不静默转嫁理解责任。

## 7. 本轮最大风险

**一句话**：LINGUA-RAS 的全部收益押在「语言纤维上的校准与语用标签可信」这一前提上——**若低资源语言的语用力量被系统性误读，而跨语言一致性又被当成独立证据，系统会在最听不懂的用户身上最自信地执行不可逆动作；多语言里最危险的不是听不懂，而是「听错得很流利」。**
