# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 4 轮；本轮灵感：「路径规划」×「具身智能大模型」）

> 第 57 轮把安全的赌注从"模型置信"升级为"少样本可校准、跨模态可对账、个性化有界的证据承诺"，但它仍是一个**点状承诺系统**：证据门、回退与人的同意都围绕"下一步踩不踩"展开，默认机器人一旦踩稳就能继续往前走。真实地形不是独立格点的集合，而是一张**有方向、有陷阱、退路会消失的图**：一段局部证据充分的缓坡可能把机器人带进"下得去、上不来"的盆地；一次为了获取证据的绕行可能消耗掉回撤所需的能量与时间；而路径之间的证据并不独立——同一块冰面被三个相邻区域"看到"，不等于三个独立样本。与此同时，具身智能大模型给了系统一种前所未有的**语义先验**：它能在没踩过之前说出"那边像水泥地""这条沟可以跨"，也能用流畅语言把猜测包装成解释；但语言先验不是物理证据，模型自洽不是世界自洽。本轮两个灵感各补一条结构：**路径规划**把承诺的单位从"点接触"提升为"带可回退证书的路由前缀"，用生存核与回退场拒绝单向陷阱，用证据账本防止路由复用造成的重复计数；**具身智能大模型**被降格为**提案者而非判定者**：它提出的路线、语义标签与失败模式必须先编译成可测的接地义务，义务未清偿前只能改变"去哪里探"，不能改变"敢不敢承诺"。核心命题由"点级证据承诺"升级为 **"路由可回退、证据不重复、语义必接地的承诺"**。

核心矛盾：
- **H29（局部证据充分 vs 全局退路消失）**：第 57 轮逐点认证"这一步是否安全"，却无法回答"走下去以后还能不能回来"；每一步都过门，仍可能组成一条通向单向陷阱的路。更麻烦的是，回退能力本身是消耗品：探针、绕行、坡度都在花掉回撤所需的能量与时间。
- **H30（证据复用 vs 重复计数）**：路径规划天然复用证据：相邻区域共享同一材质、同一到访被多个检查点引用、同一探针为多段路由提供支持。天真系统把相关证据当独立样本，越走越自信；而路由级联合界若直接套用逐点失效率，会系统性低估风险。
- **H31（语义先验 vs 接地与洗白）**：具身大模型能提供广覆盖的语义先验、路线候选与流畅解释，但这些输出不是物理证据；更危险的是"语义洗白"——幻觉出的"可通行"经模型流畅解释后，可能让操作者更容易同意，模型没有伪造证据，却伪造了让人相信证据的理由。

## 0. 直觉与动机

**灵感 1（路径规划 → 从"点承诺"到"可回退的路由前缀"）**
直觉：第 57 轮像在每一步问"这块地能不能踩"，但野外真正致命的问题常常是"踩下去以后还回不回得来"。一条局部每一步都安全的路线，可能是一个漏斗形盆地：下去容易、上来摩擦不足；也可能为了多拿一个探针证据，把回撤所需的电量与时间花光。路径规划在这里不是找最短路径，而是找**最长可承诺前缀**：地图上先划出一个"已认证安全集" S0，再用生存核 K_κ 标记"从这里出发，存在一条回撤策略能以 ≥1−κ 的概率回到 S0"的状态；只有落在 K_κ 里的边才允许承诺，承诺到第一次"再往前就回不来"的位置为止，这个位置叫承诺前沿 k*。超过 k* 的路线只是计划意图，不是承诺；单向边（没有回撤策略）默认拒绝，除非人显式签"无退路"同意。

**灵感 2（具身智能大模型 → 博学的向导，不是可靠的证人）**
直觉：具身大模型能在没踩过之前说出"那边像水泥地""这条沟可以跨""建议从左侧绕"，也能用流畅语言解释得头头是道。这对探索是巨大加速，但它的一切输出都是**先验/提案**，不是物理证据；模型自洽不等于世界自洽。更危险的是"语义洗白"：一个幻觉出来的"可通行"标签，经大模型流畅解释后，可能让操作者更容易点下同意按钮——模型没有直接伪造证据，却伪造了让人相信证据的理由。因此本轮把大模型降格为**提案者**：它只能提出路线候选、语义假设、探针假设与失败模式；每个提案必须先经接地编译器变成可测的物理义务（谓词+测试协议+通道+阈值），义务由独立物理证据清偿之前，语义标签的证据权重恒为 0。模型可以让你看得更远，不能让你退得更少；模型可以建议多探一次，不能建议少验一次。

**灵感 3（合流 → 路由证书与接地义务进入同一证据门）**
直觉：第 57 轮证据门 EV-probe/visit/margin/xmodal/human 管的是"这一步的局部证据"；本轮新增两类路由级证据：**EV-recover**（可回退证书：从该前缀存在满足概率与资源约束的回撤策略）与 **EV-ground**（接地义务已由独立物理证据清偿）。不可逆路由承诺的必要证据集变成：局部证据 ∧ 可回退证书 ∧ 接地义务（若路线受大模型提案影响）∧ 人的佐证；EV-xmodal 仍旧只限 L1。这样击穿安全需要同时发生：局部证据错 ∧ 回退路径也错 ∧ 语义接地失败 ∧ 人也被洗白——四层纵深，而且第 57 轮的所有机制都保留。

**灵感 4（证据复用 → 路由不是免费样本）**
直觉：一条路线会反复经过相似区域，同一块冰面可能被视觉看三次、被相邻三个区域各探一次；天真系统会把这些当成独立证据，越走越自信。本轮给证据记账：每个证据原子带 provenance（来源探针/到访/模型提案）、空间相关核与时间衰减；路由级风险用有效样本量 n_eff 与复用折扣 γ_eff 计算，同一来源只算一次，相邻区域按相关矩阵打折。**绕行取证据不是免费的**——它必须落在 K_κ 内，且新增证据的边际权重可能远小于名义探针数。

**灵感 5（PCE++ → 提案-编译-路由-探询-承诺-回退闭环）**
直觉：第 57 轮 PCE+ 是"探-诺-演"；本轮在前后各加一道：前面加"大模型提案→接地义务"，后面加"回退/重规划"。每个规划周期先让大模型给候选路线、语义假设和失败模式（红队），编译成义务；然后在生存核内搜索具有最长承诺前沿的路线；检查点照旧做元推断、跨模态对账、局部证据门，并额外检查回退证书与证据账本；能承诺就承诺前缀，不能就绕行/重规划，单向边进入 L2 显式协商。安全不再只靠"更相信下一步"，而是靠**永远保留不走的权利**。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（可回退场 VRF）**
设状态 x=(位姿,步态,能量,时间)，b 为地图信念，S0⊆X 为已认证安全集。对回撤策略 π∈Π_ret 与地图 M∈supp(b)，令 τ_S0, τ_fail 为首达时间，定义

  V(x;b)=min_{M∈supp(b)} max_{π∈Π_ret} P_M^π(τ_S0 < min(τ_fail, B_ret(x))).

κ-生存核 K_κ(b)={x:V(x;b)≥1−κ}。边 e=(x,x') 为 κ-可回退，当且仅当 x'∈K_κ(b) 且存在回撤策略只用接触级别不高于当前、且不重穿未验证不可逆边的路径；否则 1_ow(e)=1。回撤深度 H_ret(e) 与回撤资源 B_ret(e) 一并记录。注意 V 对信念取最坏、对策略取最好，故它是**鲁棒下界**，不是平均成功率。

**定义 140（路由承诺证书 RCC 与承诺前沿）**
路线 ρ=(x0,e1,…,xn)，接触级别 ℓ_i。条件计划树 T 以探针结果为分支，叶为 {commit, retreat, detour, safe_stop}。前缀 k 的证书 RCC(ρ,k) 成立当且仅当：(i) 每个已承诺边过 FSR；(ii) 每个前缀状态 x_i∈K_κ(b)；(iii) T 从每个 x_i 给出可行回撤；(iv) 证据账本一致；(v) 不可逆边接地义务清偿；(vi) k 之后边只标记为条件意图。承诺前沿 k*(ρ)=max{k:RCC(ρ,k)}；系统只承诺 ρ 的前 k* 段，绝不把"计划走完"当"已经承诺走完"。

**定义 141（证据独立账本 EIL）**
证据原子 a=(src,r,t,m,prov,class)。相关矩阵 Σ_ev 由空间核、时间衰减与共享 provenance 构造。有效证据量

  w_eff=(Σ_i w_i)^2 / (Σ_{i,j} w_i w_j Σ_ev,ij)，复用折扣 γ_eff=w_eff/Σ_i w_i∈(0,1]。

规则：(E1) 同一 provenance 不得跨边重复计入；(E2) 路由联合界必须用 w_eff 而非名义探针数；(E3) 大模型提案可生成探针，但生成不出独立性——证据独立性只由物理通道与采集过程声明。

**定义 142（具身大模型接地契约 EGC）**
具身模型 f 输出提案集 P，类型 {route,label,hyp,redteam}。接地编译器 G 把每个提案 p 映为义务集 O(p)，每条义务 o=(可测谓词,测试协议,物理通道,接受阈值)。p 在 O(p) 全被**独立于 f 的**物理证据清偿前，语义证据权重为 0；只能影响探针排序、路线候选与失败模式清单，不能清偿任何 EV 类，也不能降低证据要求。语义标签带租约 T_lease，到期或到下一接地检查点即失效；f 的版本、提示与提案全量入账。红队模式要求 f 对每条不可逆边提出至少一个"若此边失败，最可能原因"的失败模式，并把可测者转为强制义务。

**定义 143（路由证据门 FSR 与证书 J_r）**
证据类扩展为 EV-probe\*/EV-visit/EV-margin/EV-xmodal（限 L1）/EV-human/EV-recover/EV-ground。不可逆路由承诺的必要证据集：

  {(EV-probe\*∨EV-margin) ∧ EV-recover ∧ (EV-ground 若该边或探针顺序受 f 影响) ∧ 人佐证(auth)}。

EV-xmodal 仍不得进入不可逆必要集。FSR(ρ,k)=ok 当且仅当 RCC(ρ,k) ∧ 账本一致 ∧ 义务清偿 ∧ 无未处理单向边。J_r=(J_p, VRF 证书, T, k*, evidence_ledger, proposal_log, obligation_log, model_version, semantic_lease)。

**定义 144（PCE++ 算子）**
每规划周期六步：①提案：f 生成候选路线/语义假设/失败模式（全部标 provenance，不标 evidence）；②编译：G→O(p)，未接地标签权重 0，红队模式补义务；③路由搜索：在 K_κ 内最大化承诺前沿，其次最小化风险与资源，信息性绕行必须 κ-可回退；④检查点：MFSL 元推断 + XMC 对账 + 局部证据门 + VRF 检查 + EIL 记账；D>θ_D 发共识探针，VOI_元悲观≥θ_voi 且探针边可回退才探；f 只能重排探针，不能免除探针；⑤承诺：前沿前进且 FSR 通过则承诺前缀并更新 S0；否则绕行/重规划/安全停；1_ow=1 必须 L2 显式"无退路"协商；⑥演化：更新地图/账本/义务/租约；发现语义矛盾则触发事后证伪与提案隔离（回滚该 f 版本对该类区域的语义权重）。

## 2. 关键算法伪代码（完整版见产物区）

```python
def viability_field(M, S0, b, kappa, B_ret):
    V = robust_return_value(M, S0, b, horizon=H_ret, B_ret=B_ret)  # 对信念取最坏
    K = {x for x in M.states if V[x] >= 1 - kappa}
    return V, K

def grounded_proposal(f, ctx, M, b):
    P = f.propose(ctx, map=M, beliefs=b, redteam=True)   # route/label/hyp/redteam
    for p in P:
        p.obligations = compile_obligations(p)            # 谓词+协议+通道+阈值
        p.weight = 0.0                                    # 未接地=零证据
        p.lease = T_lease
    return P, merge_redteam_obligations(P)

def route_commit_plan(M, b, task, K, ledger, proposals):
    cands = route_candidates(M, task, b, proposals)
    best = None
    for rho in cands:
        k = max_prefix(rho, lambda k: RCC(rho, k, M, b, K, ledger))
        if best is None or (k, -route_risk(rho[:k])) > (best.k, -route_risk(best.rho[:best.k])):
            best = (rho, k)
    return best                                           # 承诺前沿，而非整条路线
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| VRF | O(H_ret·|X|·|A|·|supp(b)|) 每次重规划；可采样近似+区间 | O(|X|) | V 是信念最坏下的回撤下界，非平均 |
| RCCP | O(|E|·C_VRF+|V|log|V|) | O(|V|·H_ret) | 只承诺前沿，不承诺整条路线 |
| EIL | O(|atoms|²) 精确；块稀疏近似 O(|atoms|·b) | O(|atoms|) | provenance 不重复，n_eff 保守 |
| EGC | O(|P|·|O|)+f 推理 | O(|P|+|O|) | 未接地零权重，义务独立清偿 |
| FSR | O(|ρ|) | O(|ρ|) | 单向边硬拒，EV-xmodal 限 L1 |
| PCE++ | O(N_replan·(VRF+RCCP)+|CP|·(k_p+k_c)(C_VOI+d_φ)) | O(|V|+|σ|) | 无进展检测、有限探针预算 |

**正确性定理（RCPS 概要）**：在 A37–A40 上增加 (A41) VRF 证书健全（V 为信念支撑下回撤概率下界，回撤策略经校验）；(A42) EIL 不重复计数且相关折扣保守；(A43) EGC 提案接地（影响承诺的提案义务已由独立证据清偿，未接地提案权重为 0）；(A44) 承诺前沿不变式（每个已承诺前缀状态 ∈K_κ 且回撤资源 ≤B_ret）；(A45) 审计与版本完备（f 版本、提示、提案、租约可回溯）。则：(i) 路由级失效率 ≤ Σ_{i≤k*}(δ_f+ε_meta+δ_probe+ε_h+δ_ood·α_conf+δ_xm·1[L1]) + κ + δ_ledger + δ_ground；(ii) **可选性单调**：任何 f 提案、语义标签或信息性绕行只能经"改变探针顺序/候选集"或"增加义务/更保守动作"影响系统，不能降低证据要求、不能增加证据权重、不能缩小回退证书；(iii) 无单向陷阱：承诺前缀内每个状态存在概率 ≥1−κ 的回撤策略，单向边未经 L2 显式同意不进入承诺；(iv) PCE++ 在有限探针+有限重规划（无进展即停）内终止。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |

## 6. 本轮最大风险

**一句话**：本轮把安全从"这一步有没有证据"提升为"这条路有没有退路"，但退路证书本身仍由同一张有盲区的信念地图与同一个大模型语义先验生成——若回撤路径也被系统自洽地误判为可行，机器人会在一张"看起来处处能回"的假地图上大胆深入，把第 57 轮的"坏先验"从"敢不敢下脚"放大成"敢不敢进去、还能不能出来"；必须以独立证据复核退路、信念最坏下界、单向边 L2 硬协商与语义洗白隔离四重护栏，宁可停在能回来的地方，绝不把"计划中的退路"当"已验证的退路"。

## 1. 定义与符号增量（定义 139–144）

### 定义 139（可回退场 VRF）

设状态 x=(位姿,步态,能量,时间)，b 为地图信念，S0⊆X 为已认证安全集。对回撤策略 π∈Π_ret 与地图 M∈supp(b)，令 τ_S0, τ_fail 为首达时间，定义

  V(x;b)=min_{M∈supp(b)} max_{π∈Π_ret} P_M^π(τ_S0 < min(τ_fail, B_ret(x))).

κ-生存核 K_κ(b)={x:V(x;b)≥1−κ}。边 e=(x,x') 为 κ-可回退，当且仅当 x'∈K_κ(b) 且存在回撤策略只用接触级别不高于当前、且不重穿未验证不可逆边的路径；否则 1_ow(e)=1。回撤深度 H_ret(e)、回撤资源 B_ret(e) 与支撑地图采样数 N_supp 一并记录。V 对信念取最坏、对策略取最好，是**鲁棒下界**而非平均成功率；当信念支撑无法枚举时，用区间证书 [V_lo,V_hi] 且只以 V_lo 放行。

### 定义 140（路由承诺证书 RCC 与承诺前沿）

路线 ρ=(x0,e1,…,xn)，接触级别 ℓ_i。条件计划树 T 以探针结果为分支，叶为 {commit, retreat, detour, safe_stop}。前缀 k 的证书 RCC(ρ,k) 成立当且仅当：

1. 每个已承诺边过 FSR；
2. 每个前缀状态 x_i∈K_κ(b)；
3. T 从每个 x_i 给出可行回撤策略，且回撤资源 ≤B_ret(x_i)；
4. 证据账本 EIL 在 ρ[:k] 上一致，无重复 provenance；
5. 不可逆边的 EGC 接地义务全部清偿；
6. k 之后的边只标记为条件意图，不进入 sched/log。

承诺前沿 k*(ρ)=max{k:RCC(ρ,k)}；系统只承诺 ρ 的前 k* 段。超过 k* 的部分是"计划"，不是"承诺"。

### 定义 141（证据独立账本 EIL）

证据原子 a=(src,r,t,m,prov,class)，其中 prov 是采集过程的不可伪造标识（探针编号/到访编号/物理通道观测编号），class 是独立性等价类。相关矩阵 Σ_ev 由空间核 k_s(r,r')、时间衰减 e^{−λΔt} 与共享 provenance 构造。有效证据量

  w_eff=(Σ_i w_i)^2 / (Σ_{i,j} w_i w_j Σ_ev,ij)，

复用折扣 γ_eff=w_eff/Σ_i w_i∈(0,1]。三条规则：

- **(E1) 同源不重复**：同一 provenance 不得跨边重复计入；
- **(E2) 路由界用 w_eff**：路由级联合界不得直接使用名义探针数；
- **(E3) 提案不产生独立性**：大模型可以建议探针，但证据独立性只由物理通道与采集过程声明，模型版本/提示不得进入独立类。

### 定义 142（具身大模型接地契约 EGC）

具身模型 f 输出提案集 P，类型 {route,label,hyp,redteam}。接地编译器 G 把每个提案 p 映为义务集 O(p)，每条义务 o=(可测谓词,测试协议,物理通道,接受阈值)。提案 p 在 O(p) 全被**独立于 f 的**物理证据清偿前，语义证据权重为 0；只能影响探针排序、路线候选与失败模式清单，不能清偿任何 EV 类，也不能降低证据要求。语义标签带租约 T_lease，到期或到下一接地检查点即失效；f 的版本、提示、提案与租约全量入账。红队模式要求 f 对每条不可逆边提出至少一个"若此边失败，最可能原因"的失败模式，可测者转为强制义务。

### 定义 143（路由证据门 FSR 与证书 J_r）

证据类扩展为 EV-probe\*/EV-visit/EV-margin/EV-xmodal（限 L1）/EV-human/EV-recover/EV-ground。不可逆路由承诺的必要证据集为

  {(EV-probe\*∨EV-margin) ∧ EV-recover ∧ (EV-ground 若该边或探针顺序受 f 影响) ∧ 人佐证(auth)}，

其中 EV-xmodal 仍不得进入不可逆必要集。FSR(ρ,k)=ok 当且仅当 RCC(ρ,k) ∧ 账本一致 ∧ 义务清偿 ∧ 无未处理单向边。证书

  J_r=(J_p, VRF 证书, T, k*, evidence_ledger, proposal_log, obligation_log, model_version, semantic_lease)。

### 定义 144（PCE++ 算子）

每规划周期六步：

1. **提案**：f 生成候选路线/语义假设/失败模式，全部标 provenance，不标 evidence；
2. **编译**：G→O(p)，未接地标签权重 0，红队模式补义务；
3. **路由搜索**：在 K_κ 内最大化承诺前沿，其次最小化风险与资源；信息性绕行必须 κ-可回退；
4. **检查点**：MFSL 元推断 + XMC 对账 + 局部证据门 + VRF 检查 + EIL 记账；D>θ_D 发共识探针，VOI_元悲观≥θ_voi 且探针边可回退才探；f 只能重排探针，不能免除探针；
5. **承诺**：前沿前进且 FSR 通过则承诺前缀并更新 S0；否则绕行/重规划/安全停；1_ow=1 必须 L2 显式"无退路"协商；
6. **演化**：更新地图/账本/义务/租约；发现语义矛盾则触发事后证伪与提案隔离（回滚该 f 版本对该类区域的语义权重）。

### IP-139 VRF（鲁棒回撤值与生存核）

```python
def robust_return_value(M, S0, b, H_ret, B_ret):
    V = {x: 0.0 for x in M.states}
    for x in S0:
        V[x] = 1.0
    for _ in range(H_ret):
        for x in reversed(M.states - S0):
            worst = float('inf')
            for Mb in sample_support(b, n=N_supp):          # 信念支撑采样
                best = max(return_success(Mb, S0, x, a, B_ret)
                           for a in M.actions[x])
                worst = min(worst, best)                    # 对地图取最坏
            V[x] = worst
    return V

def viability_field(M, S0, b, kappa, B_ret):
    V = robust_return_value(M, S0, b, H_ret, B_ret)
    K = {x for x in M.states if V[x] >= 1 - kappa}
    return V, K

def edge_recoverable(e, M, b, K, B_ret, kappa):
    if e.x2 not in K:
        return False, None
    ret = best_retreat_policy(e.x2, M, b, S0, B_ret)
    uses_unverified_irreversible = any(
        x.level == 'irreversible' and not verified(x) for x in ret.path
    )
    ok = (ret.success >= 1 - kappa and ret.cost <= B_ret
          and not uses_unverified_irreversible)
    return ok, ret
```

### IP-140 RCCP（最长承诺前缀与条件计划树）

```python
def max_prefix(rho, ok):
    k = 0
    while k < len(rho.edges) and ok(k + 1):
        k += 1
    return k

def RCC(rho, k, M, b, K, ledger, obligations, auth):
    for i, e in enumerate(rho.edges[:k], 1):
        if not route_edge_evidence_ok(e, M, b, K, ledger, obligations, auth):
            return False
    return ledger.consistent(rho[:k])

def route_commit_plan(M, b, task, K, ledger, proposals, obligations, auth):
    cands = route_candidates(M, task, b, proposals)
    best = None
    for rho in cands:
        k = max_prefix(rho, lambda k: RCC(rho, k, M, b, K, ledger,
                                          obligations, auth))
        key = (k, -route_risk(rho[:k], ledger))
        if best is None or key > (best.k, -route_risk(best.rho[:best.k], ledger)):
            best = RoutePlan(rho=rho, k=k)
    return best
```

### IP-141 EIL（证据账本与复用折扣）

```python
def evidence_atom(src, r, t, modality, prov, indep_class):
    return Atom(src=src, r=r, t=t, modality=modality,
                prov=prov, indep_class=indep_class)

def effective_weight(atoms, Sigma):
    w = sum(a.w for a in atoms)
    if w <= 0:
        return 0.0
    denom = sum(a.w * b.w * Sigma[(a, b)] for a in atoms for b in atoms)
    return (w * w) / max(denom, 1e-12)

def ledger_update(L, atom):
    if L.has_provenance(atom.prov):          # E1: 同源只算一次
        return L
    L.add(atom)
    L.Sigma = update_correlation(L, atom)    # 空间核×时间衰减×共享来源
    return L

def reuse_discount(L, atoms):
    nominal = max(sum(a.w for a in atoms), 1e-12)
    return effective_weight(atoms, L.Sigma) / nominal
```

### IP-142 EGC（提案编译、接地义务与语义租约）

```python
def compile_obligations(p):
    if p.type == 'label':
        return [Obligation('physical_class', at=p.r,
                           test='grounded_probe_or_vision',
                           channel=p.channel, threshold=0.9)]
    if p.type == 'route':
        return [Obligation('traversable', at=e, test='FSE+VRF',
                           channel='independent', threshold=1.0)
                for e in p.edges]
    if p.type == 'hyp':
        return [Obligation('testable', at=p.r, test=p.protocol,
                           channel=p.channel, threshold=p.threshold)]
    if p.type == 'redteam':
        return [Obligation('failure_checked', at=p.edge, test=p.protocol,
                           channel='independent', threshold=1.0)]

def grounded_proposal(f, ctx, M, b, redteam=True):
    P = f.propose(ctx, map=M, beliefs=b, redteam=redteam)
    for p in P:
        p.obligations = compile_obligations(p)
        p.weight = 0.0                       # A43: 未接地零证据
        p.lease = T_lease
        p.provenance = (f.version, ctx.hash, p.id)
    O = merge_redteam_obligations(P)         # 红队失败模式转为强制义务
    return P, O

def semantic_quarantine(proposal_log, ledger, verdict):
    if verdict.falsifies(proposal_log.region, proposal_log.label):
        proposal_log.freeze(proposal_log.model_version, proposal_log.region)
        ledger.invalidate(prov=proposal_log.provenance)
```

### IP-143 FSR（路由级证据门与 J_r）

```python
def route_edge_evidence_ok(e, M, b, K, ledger, obligations, auth):
    rec_ok, ret = edge_recoverable(e, M, b, K, B_ret[e], kappa)
    if not rec_ok:
        return False
    if any(not o.discharged for o in obligations_on(e)):
        return False                         # 未接地提案不得进入承诺
    if e.level == 'irreversible' and one_way(e) and not l2_consent(e, auth):
        return False                         # 单向边 L2 硬约束
    if e.level == 'irreversible' and e.ev == 'EV-xmodal':
        return False                         # 继承第 57 轮硬禁令
    return few_shot_evidence_gate(e.cert, M, auth, ood_reg)[0] == 'ok'

def route_gate(rho, k, M, b, K, ledger, obligations, auth):
    if not RCC(rho, k, M, b, K, ledger, obligations, auth):
        return ('reject', 'no_recover_or_evidence')
    if any(one_way(e) and not l2_consent(e, auth) for e in rho[:k]):
        return ('reject', 'one_way_without_consent')
    if any(not o.discharged for o in obligations_in(rho[:k])):
        return ('reject', 'ungrounded_proposal')
    return ('ok', J_r(rho, k, ledger, obligations_in(rho[:k])))

def map_route_certificate(rho, k, M, b, K, ledger, obligations,
                          consent_log, auth_log, proposal_log, ood_reg):
    st = route_gate(rho, k, M, b, K, ledger, obligations, active_auth())
    if st[0] != 'ok':
        return st
    if ledger.effective_weight(rho[:k]) < budgets.w_min:
        return ('reject', 'effective_evidence_insufficient')
    if semantic_perturbation(M.core) > budgets.Theta_s:
        return ('reject', 'delta_s')
    if not all(l2.resolved for l2 in consent_log):
        return ('reject', 'consent_open')
    return ('ok', st[1])
```

### IP-144 PCE++（提案-编译-路由-探询-承诺-回退）

```python
def path_commit_evolve_plus(x0, M, b, task, budget, consent, personas, f):
    P, O = grounded_proposal(f, task, M, b, redteam=True)   # 提案，不是证据
    V, K = viability_field(M, S0, b, kappa, B_ret)
    plan = route_commit_plan(M, b, task, K, ledger, P, O, personas.active)
    route, sched, log = plan.rho, [], []

    for cp in plan.rho.prefix(plan.k):                      # 只遍历承诺前沿内
        inf = meta_few_shot_infer(M, cp.region, M.obs[cp.region], meta)
        M.b[cp.region] = inf.post if inf.cls == 'ID' else worst_in(inf.belt)
        sigma = foothold_schedule(x0, cp, M)
        R = schedule_risk(sigma, M)

        while select_gait(R) == 'halt' and budget.probes_left > 0:
            cands = [q for q in admissible_probes(cp, M, F_abs)
                     if edge_recoverable(q.edge, M, b, K, B_ret[q.edge], kappa)[0]]
            if not cands:
                break
            p = argmax(cands, key=lambda q: voi_meta_pessimistic(q, M, inf) - cost(q))
            if voi_meta_pessimistic(p, M, inf) < theta_voi:
                break
            M, _, D = xmodal_fuse(M, cp.region, execute_probe(p, cap=F_abs))
            ledger = ledger_update(ledger, evidence_atom(
                'probe', cp.region, t_now, p.modality, p.prov, p.indep_class))
            if D > theta_D and 'consensus' not in cp.done:
                p2 = most_disagreeing_modality_probe(M, cp.region)
                M, _, D = xmodal_fuse(M, cp.region, execute_probe(p2, cap=F_abs))
                ledger = ledger_update(ledger, evidence_atom(
                    'probe', cp.region, t_now, p2.modality, p2.prov, p2.indep_class))
                cp.done.add('consensus')
            sigma = reselect_footholds(x0, cp, M)
            R = schedule_risk(sigma, M)
            budget.spend(p)

        g = select_gait(R)
        ev = tag_evidence_p(sigma, M, contact_level(cp))
        st = route_gate(route, cp.index + 1, M, b, K, ledger, O, personas.active)
        if g != 'halt' and st[0] == 'ok':
            sched.append(commit(sigma, g))
            log.append(ev)
            S0 = S0 | certified_states(sigma, M)              # 扩展已认证安全集
            continue

        alt = reroute(M, cp, risk_model, K)
        if alt and route_gate(alt, len(alt.edges), M, b, K, ledger, O,
                              personas.active)[0] == 'ok':
            route = alt
            continue

        if any(one_way(e) for e in route[:cp.index + 1]):
            return negotiate_one_way(cp, M, sigma, R, consent,
                                     tau_int=tau_int(personas.active.auth))
        return negotiate_or_stop(cp, M, sigma, R, consent,
                                 tau_int=tau_int(personas.active.auth))

    return sched, log, M, J_r(route, plan.k, ledger, O)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| VRF | O(H_ret·|X|·|A|·N_supp) 每次重规划；分层抽象可降至 O(|X_local|) | O(|X|) | V 为信念最坏下回撤概率下界（A41） |
| RCCP | O(|E|·C_VRF+|V|log|V|) | O(|V|·H_ret) | 只承诺前沿 k*，不承诺整条路线（A44） |
| EIL | O(|atoms|²) 精确；块稀疏 O(|atoms|·b) | O(|atoms|) | provenance 不重复，n_eff 保守（A42） |
| EGC | O(|P|·|O|)+f 推理 | O(|P|+|O|) | 未接地零权重，义务独立清偿（A43） |
| FSR | O(|ρ|) | O(|ρ|) | 单向边硬拒，EV-xmodal 限 L1 |
| PCE++ | O(N_replan·(VRF+RCCP)+|CP|·(k_p+k_c)(C_VOI+d_φ)+|CP|·A*) | O(|V|+|σ|) | 无进展检测、有限探针与重规划预算 |

### 路由级联合界推导

设边 i 的局部失效率上界为 q_i，证据复用折扣为 γ_eff,i∈(0,1]。朴素联合界 Σ_i q_i 假设边间独立，路由复用证据时会低估风险；用有效证据量把每条边的失效率保守放大为

  q_i^eff = q_i / γ_eff,i，

则

  P_fail(ρ[:k*]) ≤ Σ_{i≤k*} q_i^eff + κ + δ_ground + P(VRF 证书错误)。

其中 κ 是生存核允许的最坏回撤失败概率，δ_ground 是"义务被误判为已清偿"的概率。定义账本惩罚 δ_ledger=Σ_i q_i(1/γ_eff,i−1)，则等价写成

  P_fail(ρ[:k*]) ≤ Σ_{i≤k*} q_i + δ_ledger + κ + δ_ground + P(VRF 证书错误)。

q_i 继续展开为第 57 轮的局部界 δ_f+ε_meta(k_i)+δ_probe+ε_h(w_max)+δ_ood·α_conf+δ_xm·1[L1_i]。

### 正确性定理（RCPS：Recoverable Proposal Soundness）

假设 A22–A32（第 53–55 轮）、A33–A36（第 56 轮）、A37–A40（第 57 轮）成立；并增加：

- **(A41) VRF 证书健全**：V(x;b) 为信念支撑下回撤成功概率的鲁棒下界，回撤策略经独立校验；
- **(A42) EIL 保守**：同一 provenance 不重复计入，Σ_ev 覆盖真实相关结构的上界，n_eff 不高于真实有效样本量；
- **(A43) EGC 接地诚实**：影响承诺的提案义务均由独立于 f 的物理证据清偿，未接地提案权重严格为 0；
- **(A44) 承诺前沿不变式**：每个已承诺前缀状态 ∈K_κ(b)，回撤资源 ≤B_ret，单向边未经 L2 显式同意不进入承诺；
- **(A45) 审计与版本完备**：f 版本、提示、提案、租约、义务、证据 provenance 可完整回溯。

则：

1. **路由级安全性**：对任意已承诺前缀 ρ[:k*]，

   P_safe ≥ 1 − Σ_{i≤k*}(δ_f+ε_meta(k_i)+δ_probe+ε_h(w_max)+δ_ood·α_conf+δ_xm·1[L1_i])
                − δ_ledger − κ − δ_ground − P(VRF 证书错误)。

2. **可选性单调（Option Monotonicity）**：系统接受的路由前缀集合满足 Acceptor ⊆ Cert，其中 Cert 由 S0/K_κ/证据门/账本独立定义；具身大模型只能扩大候选集 P 与义务集 O，不能修改 Cert 的阈值、证据权重或生存核。因此加入任意 f 都不会降低安全界；f 的唯一安全作用是更早发现义务或提供更保守的候选。

3. **无单向陷阱**：若边 e 满足 1_ow(e)=1，则 e 不进入任何未经 L2 显式"无退路"同意的承诺前缀；承诺前缀内每个状态存在概率 ≥1−κ 的回撤策略。

4. **证据不膨胀**：路由级风险按 γ_eff 折算后计算；增加重复到访、相邻区域探针或模型生成的探针，不能把同一 provenance 变成多个独立样本。

5. **终止性**：每检查点共识探针 ≤k_cons，总探针 ≤k_probes+k_cons；重规划至多 N_replan 次，无进展检测（未新增证据且承诺前沿不前进）立即停机。

6. **部署界**：

```
P_safe(route) ≥ 1 − Σ_{i≤k*} (δ_f + ε_meta(k_i) + δ_probe + ε_h
                              + δ_ood·α_conf + δ_xm·1[L1_i])
                 − δ_ledger − κ − δ_ground
                 − P(VRF 证书错误) − P(护盾回退失败)
                 − P(τ_int ∧ τ_mm 超时 ∧ 安全停失效)
```

关键：**路径规划给可选性、证据账本给独立性、接地契约给语义可信**。三者都只经"更保守的动作"或"更准的信息排序"影响系统，不引入"更敢承诺"的通道。

### 预期结果与判据

- **E177 曲线**：随着 κ 从 0.01 放宽到 0.10，可承诺前缀长度应单调增加；假可回退率应随 χ=κ 收紧而下降。若"实际回撤成功率"持续低于 `1−κ`，说明 VRF 的信念支撑采样不足，应增大 N_supp 或改用区间证书。
- **E178 判据**：若路由承诺的成功率提升主要来自"更少进入死路"而非"更少探针"，则说明可选性通道有效；若时间增幅超过 25%，需把 VRF 计算限制在局部走廊并做分层缓存。
- **E179 判据**：注入 m 倍重复证据后，若系统后验宽度不降或降幅 ≤1/m，说明 γ_eff 生效；若路由界经验覆盖率低于 1−α，说明相关矩阵低估了空间相关，应提高核宽度或直接按独立类计数。
- **E180 判据**：把大模型从"提案者"切换到"判定者"作为对照，预期假承诺率显著上升，用以证明"接地契约"而非"模型能力"是安全来源。
- **E181 判据**：端到端必须同时报告"成功率"与"安全违规"，禁止只用成功率作为主指标；若安全违规为 0 但时间显著变差，优先保安全。

## 6. 本轮最大风险

**一句话**：本轮把安全从"这一步有没有证据"提升为"这条路有没有退路"，但退路证书本身仍由同一张有盲区的信念地图与同一个大模型语义先验生成——若回撤路径也被系统自洽地误判为可行，机器人会在一张"看起来处处能回"的假地图上大胆深入，把第 57 轮的"坏先验"从"敢不敢下脚"放大成"敢不敢进去、还能不能出来"；必须以独立证据复核退路、信念最坏下界、单向边 L2 硬协商与语义洗白隔离四重护栏，宁可停在能回来的地方，绝不把"计划中的退路"当"已验证的退路"。
