# 第 43 轮（新循环第 3 轮） · PEFT × 谐波减速器：把「关节级结构化残差」炼成可认证的轻量适配器（四层架构 v8）

> 承接第 42 轮 v19（SCV × CKB × ECR）。第 42 轮自陈最大风险是「仿真偏差累积 + 检索幻觉」。本轮两个灵感词恰好补上它最薄弱的一环：域随机化能扰动参数，却**无法表达某一台真实谐波减速器特有的迟滞、空回、传动误差与磨损**——这条残差是「系统性、结构化、随寿命漂移」的，正是 Sim-to-Real 迁移界 α_e 失效的物理根源。**谐波减速器**给出残差的物理基（Fourier 传动误差 + Preisach 迟滞 + Stribeck 摩擦 + 热漂移 + 磨损），而且它天生低维；**参数高效微调**给出利用低维性的算法——冻结基础模型，每关节只学几十到几百个参数的**结构化低秩适配器**。关键一步：适配器范数有界 ⇒ 对监控器输出的扰动可由区间传播界出 ⇒ **个性化不破坏 soundness**。于是 v19 的「每条边一个全局标量 α_e」升级为「每关节、每序列号、带证书的适配器」，飞轮从「仿真→现实」变为「仿真→现实→每台机器自己的证书」。

## 0. 直觉与动机

**灵感 1（谐波减速器：一条被域随机化系统性漏掉的残差）**：谐波减速器靠柔轮弹性变形传力矩，优点是高减速比、低背隙、轻量，代价是**强非线性**：波发生器每转一圈，传动误差呈现以转角为周期的谐波；柔轮扭转刚度随负载非线性变化，形成迟滞环（lost motion 常在 1–5 arcmin）；润滑与预滑移带来 Stribeck 摩擦；发热与磨损让空回、迟滞面积随寿命单调增长；还存在随负载/温度漂移的扭转共振。这些不是「随机噪声」，而是**低频、结构化、可复现、会老化**的确定性偏差。第 42 轮的 D_sim = D_nom ⊗ Δ_dyn 只能把摩擦/质量随机抖动 ±30%，却几乎不可能覆盖「这台机器此刻的迟滞环形状」。直觉结论：**把 W_1 / α_e 当成全局标量，是在用平均误差掩盖关节级系统偏差**——仿真里边际充足，实机上某关节正好落在迟滞环的坏相位，证书就静默失效。

**灵感 2（PEFT：在低维残差上花小参数，在证书上花有界预算）**：既然残差结构化、低维，就不该重训整个动力学模型。参数高效微调的直觉是：**冻结物理标称模型，只学一小块「修正」**。对关节，修正项可用极少的物理参数表示：K 阶 Fourier 系数（传动误差）、B 个 Preisach play 算子（迟滞）、3 个 Stribeck 参数、1 个热漂移系数，总计 p≈50；对神经网络监控器，用 rank-r 的 LoRA 增量 ΔW=BA。二者共享同一个安全论证：**只要适配器的算子范数被预算 ρ 约束住，它对任意 Lipschitz 监控器输出的影响就能被区间算术界出**。于是「个性化」不再是安全的敌人，而是一个可计入阈值的预算项：m_cert = m_nom − ρ_res − Δ_ad。这就是「认证 PEFT」（certified PEFT）的核心。

**灵感 3（适配器即传感器：范数漂移 = 磨损，检索 = 机群共享）**：更深一层的直觉是，适配器不只补偿，它还是**免额外传感器的磨损计**。谐波减速器的磨损表现为空回增大、迟滞面积增大、摩擦上升，这些恰好就是 π_h 的缓慢漂移；因此在线更新的适配器参数轨迹 ‖π_h(t)−π_h(0)‖ 是一个可解释的**预测性维护指标**。同时，同型号机器共享残差结构，只有每台序列号的出厂公差不同——于是可以「元适配器 + 每序列号低秩 delta」，新机器先按**硬件指纹**从 CKB 检索最像的适配器，再在机端用几分钟、几百个参数微调完成个性化。v19 的 RAG 知识库由此从「任务/环境指纹」扩展到「硬件指纹」，检索到的不是抽象模板，而是**一台具体机器可执行的证书修正**。

**耦合升级**：谐波减速器提供「残差从哪来」，PEFT 提供「用多少参数学它」，CKB 提供「从哪台机器借它」，ECR 提供「在哪跑它」，SCV 提供「怎么验它」。四层架构 v8 的具体变化：L1 的关节模型从「刚体 + 噪声」变为「刚体 + 结构化残差适配器」；L3 的守卫从 θ ← α_e·θ_sim 变为 θ 与 m_cert 都带适配器预算；L4 的飞轮新增「硬件残差回传 → 适配器再训练 → 磨损告警/再认证」。

## 1. 形式化定义（增量：定义 38–45）

**定义 38（关节传动算子与结构化残差）**：记关节传动映射 θ_link = T(θ_m, τ, ω, T_e; π)。分解为 T = T_rigid + δ_harm，其中

δ_harm(θ_m,τ,ω,T_e;π_h) = Σ_{k=1}^{K}[a_k cos(kθ_m)+b_k sin(kθ_m)] + Σ_{j=1}^{B} w_j Π_j[τ](t) + f_Stribeck(ω;μ_s,μ_c,v_s) + c_T(T_e−T_0)。

参数 π_h = (a_{1:K}, b_{1:K}, w_{1:B}, μ_s, μ_c, v_s, c_T) ∈ R^p，p = 2K+B+5。取 K=8、B=16 ⇒ p=53，可整块放进 MCU 的只读参数区。**命题 38**：若 π_h 慢变（磨损时间常数 ≫ 控制周期），则 δ_harm 对 θ_m 的 Lipschitz 常数由 Fourier 导数界出，且随 K 单调收敛；对 τ 的迟滞部分满足 ‖Π_j[τ_1]−Π_j[τ_2]‖_∞ ≤ ‖τ_1−τ_2‖_∞（play 算子的 1-Lipschitz 性）。

**定义 39（低秩适配器与谱范数预算）**：对监控器第 ℓ 层权重 W_ℓ，适配后 W_ℓ' = W_ℓ + B_ℓ A_ℓ，rank r_ℓ，B_ℓ∈R^{m×r}，A_ℓ∈R^{r×n}。定义**适配器预算** ρ_ad = Σ_ℓ ‖B_ℓ‖_2‖A_ℓ‖_2，训练每步后投影回预算球。采用 IP-53 区间电路，把每个 LoRA 增量建模为区间 [−ρ_ℓ, ρ_ℓ] 前向传播，得到**逐区域紧致扰动界** Δ_ad(x)（优于粗糙的连乘上界）。**引理 39（单调保守性）**：若 Δ_ad(x) ≥ |g_{W+ΔW}(x) − g_W(x)|，则用 m_cert = m_lo − Δ_ad 做守卫判定不会漏报不安全状态。证明：由三角不等式 m_true ≥ m_lo ≥ m_cert，故 m_cert ≥ θ ⇒ m_true ≥ θ。∎

**定义 40（认证适配器证书 CAC）**：CAC = (π_h, ρ_res, Δ_ad, A_cert, prov_hash)。定义**适配器感知边际**

**m_cert(x) = m_nom(x) − ρ_res(x) − Δ_ad(x)**，守卫通过 iff m_cert(x) ≥ θ。

**有效域** A_cert = {x : ρ_res(x)+Δ_ad(x) ≤ m_nom(x)−θ}。**命题 40**：若真实残差 |δ_harm − δ̂_harm| ≤ ρ_res 且引理 39 成立，则 m_cert(x) ≤ m_true(x)，故 m_cert ≥ θ ⇒ m_true ≥ θ（保 sound）；当 x ∉ A_cert 时无结论，必须单调降档。

**定义 41（共形残差包络）**：给定标定残差集 {r_i = |δ_true(x_i) − δ̂(x_i)|}_{i=1..n}，取 split-conformal 分位数 q_{⌈(n+1)(1−α)⌉/n}，令 ρ_res = max(q, interval_bound(π_h))。**命题 41**：在标定样本与部署样本可交换（exchangeable）假设下，P(|δ_true−δ̂| ≤ ρ_res) ≥ 1−α，且与残差分布无关。对非平稳磨损，改用块共形（block-conformal）或自适应共形推断（ACI）以维持长期平均覆盖率 ≥ 1−α。这把 v19 的「经验分位数」升级为**有限样本、分布无关**的覆盖保证，也给出可审计的置信语义。

**定义 42（磨损/老化指标与再认证触发）**：W_t = ‖π_h(t) − π_h(0)‖_{Σ^{-1}}（Mahalanobis，Σ 为正常工况下参数波动协方差）。**假设 42**：谐波减速器的空回与迟滞面积随磨损单调增长，故 W_t 是磨损的单调代理（待 E90 实证）。当 W_t > W_max（由出厂背隙公差反推）或 ‖π_h(t)−π_h(0)‖ > ρ_wear 时，证书进入 ReCertify：扩大 ρ_res、降档、并请求返厂/换件。**推理**：W_t 是「模型需要补偿多少」的直接度量，比振动/电流等间接指标更贴近证书失效的物理机制。

**定义 43（硬件指纹与元适配器检索）**：ψ_hw = (减速器型号, 序列号, 出厂背隙, 批次, 热历史摘要)，KB 记录 (φ_task, ψ_hw, Δ_meta, δ_serial, CAC)。检索 sim(φ,ψ) = sim_task(φ)·sim_hw(ψ_hw)，取 Top-k；新机器初值 = Δ_meta + δ_serial^{(k)}，仅微调 δ_serial 的 p 个参数。**命题 43**：若同批次 ‖δ_serial‖_2 ≤ ρ_δ，则机群可统一用 ρ_ad+ρ_δ 作为预算界；检索错误只降低效率、不破坏 soundness——最终仍由该机自己的 CAC 复核通过才部署。

**定义 44（谐波共振安全约束）**：设关节扭转共振频率 ω_r(τ,T_e)。定义禁带 Ω_f = {ω : |ω−ω_r| ≤ Δω}。控制力矩需满足谱能量约束 E(u;Ω_f) ≤ E_max，用短时 Fourier 能量估计 + 陷波/投影实现。证书边际额外扣除共振惩罚 ρ_res(ω) = c_Ω·max(0, E(u;Ω_f)−E_max)。**直觉**：位置误差可能很小，但持续在共振带注入能量会让迟滞环迅速扩张，随后边际崩塌——这是一种「误差未超限但能量先超限」的隐性失效，必须显式建模。

**定义 45（成本模型 v3）**：COT_v3 = C_sim/N + C_edge·T + C_adapter·N_update + C_human·N_verify。其中单关节适配器存储 p·4 B ≈ 212 B，机端一次更新 C_adapter = O(p²·n_step) 次整数乘加，远低于重训；磨损监控零额外传感器。**推论**：当 p ≪ 参数总量且 N_update 不大时，COT_v3 相对 v19 的增量可忽略，却把 α_e 的全局标量换成逐关节证书，性价比极高。

## 2. 三大产出设计（增量 IP-57/58/59 + 升级既有 IP）

### 2.1 IP-57 CERT-PEFT（认证参数高效适配器）
1. **三处适配**：监控器每层 LoRA（r=4–8，仅作用于特征层，安全头保持单调/可验证）；关节动力学结构化参数 π_h；VLA 策略动作头 LoRA（只用于任务适配，**不参与**安全守卫，避免把黑箱引入安全路径）。
2. **证书感知训练**：冻结主干，最小化 L = L_task + λ·L_cert + μ‖π‖²，其中 L_cert = max(0, θ − m_hat)；每步把 ρ_ad、‖π_h‖ 投影回预算球。预算球即部署许可证。
3. **离线认证**：训练后跑区间传播得 Δ_ad 与 ρ_res，写入 CAC；未通过预算或有效域为空的适配器**拒绝部署**。
4. **双缓冲热切换**：影子适配器先过 CAC 复核，再原子切换；任何一步失败保留旧版，运行期永不出现「半更新」状态。

### 2.2 IP-58 HARMONIC-JOINT-CERT（HJC，谐波关节证书）
1. **结构化辨识**：Fourier + Preisach + Stribeck + 热项，岭回归/递推最小二乘；仿真先验作正则（等价于在物理基上做 PEFT）。
2. **共形包络**：split-conformal 起步，非平稳段切块共形 / ACI；滑窗在线更新，覆盖率告警。
3. **磨损指标**：Mahalanobis 参数漂移 + 迟滞面积/空回估计；趋势外推做预测性维护，W_t 随证书一起上报。
4. **共振防护**：STFT 能量监控 + 陷波 + CBF 投影；ω_r 随负载/温度在线更新，禁带能量进证书惩罚项。
5. **证书输出**：CAC 写入 L0 表（按单元存 ρ_res、Δ_ad 上界）与 CKB（按硬件指纹存适配器）。

### 2.3 IP-59 ADAPTER-FLEET-MESH（AFM，适配器机群网）
1. **元学习**：跨机器训练 Δ_meta（Reptile / 一阶 MAML），每台只学低秩 δ_serial，降低冷启动样本量。
2. **硬件指纹嵌入 + 两层检索**：先型号/批次，再任务；HNSW 索引，重排用轻量交叉编码器。
3. **机端微调**：递推最小二乘 / QAT，整数运算，WCET 预算内完成；影子参数复核后切换。
4. **版本化与溯源**：适配器带 (serial, date, W_t, cert_hash, parent_adapter)，支持回滚与审计。
5. **联邦可选**：只上传低秩 δ_serial（可做差分隐私/安全聚合），原始轨迹不出厂，兼顾隐私与机群进化。

## 3. 四层架构 v8

```
L1: TRI-FUSE(INT8) + IP-49 LIO + IP-58 HJC(π_h 结构化残差 + W_t 磨损 + 共振禁带)
    → C_ms + B_t + L_m(含刚度非线性) + CAC_joint

    ← IP-56 ECR(L0 查表含 Δ_ad 上界 + INT8 监控 + 机端适配器更新)
    → IP-47 乘积模板(有效域交集) → IP-39 规划(CBF margin=m_cert)
    → IP-45 总线(适配器心跳 + 共振禁带) → IP-48 认证流匹配 → IP-43 韵律调度
    → IP-53 CMC(看门狗 + 适配器导出)
L4: IP-59 AFM(元适配器 + 硬件指纹检索 + 机端微调)
    ← IP-54 SCV(Δ_gear 结构化故障注入 + 共形残差采集)
    → IP-58 HJC(结构化辨识 + 共形包络) → IP-55 CKB(适配器版本库 + 磨损档案)
    → IP-44 蒸馏(QAT→INT8) + IP-50 课程(W_t 调制) → RCA 重颁 CAC → 契约热更新
运行期：L0查表(5μs)+INT8监控(100μs)+适配器校验(<20μs) → W_t/共振/偏移监控
        → ReCertify 或飞轮触发 → Sim重跑/机群检索 → 新 CAC 复核 → 双缓冲热切换
```

## 4. 实验设计（E87–E94 硬门槛，承接 E79–E86）

| 实验 | 指标 | 门槛 |
|---|---|---|
| E87 谐波残差辨识 | 传动误差/迟滞预测 RMSE vs 全量神经网络；参数占比 | RMSE ≤ 全量模型的 1.3x；参数 ≤ 全量 1% |
| E88 认证适配器 soundness | 留出 10k 样本违例数；界紧致度（certified/empirical） | 0 违例；紧致度 < 3x |
| E89 共形覆盖 | 实测覆盖率 vs 名义 1−α；非平稳段块共形 | 覆盖率 ≥ 1−α−1pp；W_1 漂移下不破 |
| E90 磨损指标 | W_t 与实测空回/迟滞面积相关性；维护提前量；误报 | Spearman ≥ 0.8；提前 ≥ 20h；误报 < 5% |
| E91 机群检索冷启动 | 新序列号达到目标精度所需标定样本数 | 比从零训练少 ≥ 10x |
| E92 机端更新 | STM32H7 / Orin Nano 上更新 WCET、RAM | < 5s / < 200ms；RAM < 4KB |
| E93 共振防护 | 禁带能量抑制；共振工况不安全事件 | 抑制 ≥ 10dB；0 起 |

### IP-57 CERT-PEFT：证书感知适配与区间认证

```
def train_cert_peft(base_net, adapter, data, theta, rho_budget, lam=1.0, mu=1e-3):
    freeze(base_net)
    for batch in data:
        m_hat = forward_with_adapter(base_net, adapter, batch.x)
        loss = task_loss(m_hat, batch.y) \
             + lam * max(0.0, theta - margin_of(m_hat)) \
             + mu  * adapter_energy(adapter)
        loss.backward(); optimizer.step()
        project_spectral_budget(adapter, rho_budget)   # 训练即持证
    delta_ad = interval_adapter_bound(base_net, adapter, data.x)
    return adapter, delta_ad

def interval_adapter_bound(net, adapter, X):
    # 把每层 LoRA 增量视作区间盒 [-rho_l, rho_l]，走 IP-53 区间传播
    # 输出为给定输入域上的最大可能输出扰动；优于连乘粗界
    bound = 0.0
    for l in range(len(net.layers)):
        rho_l = spectral_norm(adapter.B[l]) * spectral_norm(adapter.A[l])
        bound += lip_after(net, l) * rho_l * activation_bound(net, l, X)
    return bound * (1.0 + interval_slack)   # 含舍入/浮点余量

def certify_cell_L0(m_nom_cell, rho_res_cell, delta_ad_cell, theta):
    m_cert = m_nom_cell - rho_res_cell - delta_ad_cell
    return m_cert, (m_cert >= theta)

def safeguard_cell(x, cac):
    if norm_pi(cac.pi_h) > cac.rho_wear or cac.W_t > cac.W_max:
        return 'RECERTIFY'
    m_cert, ok = certify_cell_L0(cac.m_nom(x), cac.rho_res(x), cac.delta_ad(x), cac.theta)
    if not in_valid_region(x, cac.A_cert):
        return 'DEGRADE'
    return 'OK' if ok else 'TRIP'
```

### IP-58 HJC：谐波关节结构化辨识、共形包络与磨损
```
def build_structured_basis(log, K=8, B=16):
    cols = []
    for k in range(1, K + 1):
        cols += [cos(k * log.theta_m), sin(k * log.theta_m)]     # 传动误差
    for j in range(1, B + 1):
        cols += [play_operator(log.tau, threshold=j * dtau)]      # Preisach 迟滞
    cols += [stribeck_basis(log.omega), thermal_offset(log.temp)]
    return stack_columns(cols)                                    # n × p

def fit_harmonic_residual(log, sim_prior, lam_reg=1e-2):
    Phi = build_structured_basis(log)
    y = log.theta_link - rigid_model(log)          # 只拟合残差
    # 结构化 PEFT：冻结物理标称模型，仅解 pi；仿真先验作正则中心
    pi = ridge(Phi, y, lam=lam_reg, prior=sim_prior)
    return pi

def conformal_envelope(residuals, alpha=0.1, block=None):
    if block is None:                                # split-conformal
        n = len(residuals)
        idx = ceil((n + 1) * (1 - alpha)) - 1
        return max(0.0, sorted(residuals)[idx])
    # 非平稳：块共形 / ACI，按块重置分位数并做在线修正
    q = []
    for blk in chunk(residuals, block):
        q.append(conformal_envelope(blk, alpha))
    return adjust_aci(q, coverage_target=1 - alpha)

def wear_index(pi_t, pi_0, Sigma, backlash_est, hyst_area_est):
    d_pi = mahalanobis(pi_t, pi_0, Sigma)            # 参数漂移
    d_bl = (backlash_est - backlash_est_0) / bl_tol
    d_hy = (hyst_area_est - hyst_area_est_0) / hy_tol
    return max(d_pi, d_bl, d_hy)                      # 任一维度超限即告警

def resonance_guard(u, omega_r, band, E_max, c_Omega):
    E = stft_band_energy(u, omega_r, band)
    if E <= E_max:
        return u, 0.0
    penalty = c_Omega * (E - E_max)                   # 进证书边际惩罚
    u_safe = notch_filter(u, omega_r, band)           # 陷波 + CBF 投影
    return u_safe, penalty
```
