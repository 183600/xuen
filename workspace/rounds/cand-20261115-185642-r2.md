# 第 9 轮（灵感循环第 9 轮；本轮灵感：「动力学」×「遥操作」）

> **基线**：第 8 轮 MetricVoiceGauge-DA-SPR-Cal（定义 493–540；引理 77–81；实验 E531–E550）。
> 本轮纪律：**动力量化 + 遥操作能量透明性**。两个灵感分别把指标从「状态快照」推进到「沿向量场的预测裕度」，把遥操作从「指令通道」推进到「带能量账本的两端口」。新增模块一律为**可选增强**：任一失效 ⇒ 逐级退回 MetricVoiceGauge-DA-SPR-Cal v8。

## 0. 直觉与动机

**灵感 1（动力学 → 指标从「现在在哪」变成「沿轨迹还能撑多久」）**
直觉：v8 的六层指标本质上是对当前状态 x 做快照式检查——机器人此刻离障碍 0.3m 是安全的，但若它以 2m/s 冲向障碍且加速度为正，这个「安全」只是瞬时假象。动力学的第一层价值是把 ḣ、hö 纳入判据：不再问「现在是否安全」，而问「在当前向量场下，安全还能维持多久」。第二层价值是能量：机器人不是位置点，而是储能系统（动能+势能+接触弹性能）；危险常常不是「越界」，而是「能量无处可去」。
于是提出 **动态障碍梯度（Dynamic Barrier Ladder, DBL）**：用高阶控制障碍函数（HOCBF）把每个约束 h_i(x) ≥ 0 展开为 ψ_i = h_i + γ₁ḣ_i + …，取 m_dyn = min_i ψ_i/Λ_i 作为动态裕度，risk_dyn = exp(−m_dyn/σ_dyn)。它是**预测性风险**，不是事后风险。

**灵感 2（遥操作 → 人也是能量源，延迟会「发电」）**
直觉：遥操作最反直觉的事实是——**通信延迟能让一个被动的从端变成主动振子**。操作员的力经时延通道传到从端，反力再延迟回来，相位错位就向系统注入能量。教科书解法是波变量（wave variables）与时间域被动控制（TDPC）：把 (f,v) 变为行波 (u,w)，任意常值时延下通道仍无源。
因此遥操作指标不该只看「指令到没到」，而应显式记账：**无源裕度 P(t)**（两端口净注入能量 + 能量箱初值）、**透明性误差 e_t**（主端感受阻抗 Z_m 与期望环境阻抗 Z_t 的偏差）、**往返时延 τ_rtt**（不是越低越好，须与无源裕度联合判断）。提出 **无源能量账本（PEL）** 与 **遥操作透明性度量（TTM）**，压成 risk_tel。

**综合（人-机-环境闭环）**
v8 风险向量 5 维（感知、语义、效能、完善、SLAM），本轮扩为 **7 维**，新增 risk_dyn、risk_tel。更进一步：操作员不是外生的，**权限分配 α_h(s)** 应随 risk_dyn、risk_tel 连续变化——不是「人控/自控」二值切换，而是「人类权限平滑衰减、机器权限平滑接管」，并在无源裕度不足时注入阻尼。把「动力学校验」与「能量账本」在同一时间尺度上闭合。

## 1. 研究问题

- **Q1（动态裕度的可计算性）**：在 ≤1 个控制周期、且只有近似动力学模型时，如何得到不因模型误差而频繁误报的 m_dyn？
- **Q2（无源性如何进入指标层）**：P(t)、e_t、τ_rtt 如何被归一化，并与既有 5 维风险向量在同一 softmax 尺度上共存？
- **Q3（权限连续分配）**：如何在 risk_dyn/risk_tel 上升时平滑地把权限从人转给机器，同时保证不产生权限抖动（chattering）？

## 2. 设计原则（P10–P12）

**P10 动态障碍梯度（DBL）**
对约束 h_i(x) ≥ 0（相对阶 r_i ≤ 2）定义
```
ψ_{i,0} = h_i
ψ_{i,k} = ψ̇_{i,k−1} + α_{i,k}(ψ_{i,k−1}),  k = 1..r_i
m_dyn(x) = min_i ψ_{i,r_i}(x) / Λ_i
risk_dyn = exp(−m_dyn / σ_dyn) ∈ (0,1]
```
其中 α_{i,k} 为 class-κ 函数（默认 α(s)=γs），Λ_i 为量纲归一化常数。CBF-QP 可行 ⇒ ψ_{i,r_i} ≥ 0 ⇒ risk_dyn 是「到动态不可行边界的距离」。

**P11 无源能量账本（PEL）**
```
P(t) = E₀ + ∫₀ᵗ [ f_mᵀv_m − f_sᵀv_s ] dτ
```
波变量保证常值时延通道无源；当 P(t) < 0 时注入阻尼 f_damp = −c_d(v_m − v_s)，并以 ΔE_d = c_d‖v_m−v_s‖²Δt 回补账本，保证补偿后 P ≥ 0。

**P12 权限连续分配（AA）**
```
α_h = clip(1 − β_dyn·risk_dyn − β_tel·risk_tel, α_min, 1)
|α̇_h| ≤ ρ（速率限制） + Schmitt 迟滞带 h_σ
u = α_h·u_human + (1 − α_h)·u_auto
```

## 3. 与基线的接口（如何退化）

- DBL 失效 ⇒ risk_dyn ≡ 0、m_dyn ≡ +∞，退回 v8 的状态快照指标；
- PEL 失效 ⇒ P ≡ +∞，risk_tel 只保留时延项，退回固定阻抗；
- TTM 失效 ⇒ e_t ≡ 0，risk_tel 不含透明性项；
- AA 失效 ⇒ α_h ≡ 1（安全条件下），退回 v8 的人控逻辑；
- 全部失效 ⇒ 完全退回 v8，再退回 v7/v6。

## 4. 预期贡献

1. 把指标层级从「状态快照」升级为「动态预测裕度」，risk_dyn 具备前馈预警能力；
2. 首次把遥操作无源性/透明性显式编码进奖励与证书体系（risk_tel）；
3. 权限连续分配 + 能量箱阻尼注入，形成「人-机-环境」能量守恒闭环；
4. 7 维风险 + 六级退化：E551–E570 覆盖动态裕度、无源性、权限分配与跨时延鲁棒。

## 5. 本轮最大风险

**一句话**：动力学模型误差与力/速度测量噪声会被高阶微分放大，使 m_dyn 抖动、risk_dyn 误报；叠加时延抖动使 P(t) 反复穿越零点，权限 α_h 可能在「人控/自控」之间高频切换——「系统为追求动态预测与无源安全，反而制造了它想消除的权限抖动」。

**新增定义 541（动态障碍梯度 DynamicBarrierMargin, DBM）** 对相对阶 r_i ≤ 2 的约束 h_i，递归定义
```
ψ_{i,0}(x) = h_i(x)
ψ_{i,1}(x) = ḣ_i(x) + α_{i,1}(h_i(x))
ψ_{i,2}(x) = ψ̇_{i,1}(x) + α_{i,2}(ψ_{i,1}(x))
          = hö_i(x) + α_{i,1}ḣ_i(x) + α_{i,2}(ψ_{i,1}(x))
m_dyn(x) = min_i ψ_{i,r_i}(x) / Λ_i
```
更高相对阶按同一递归外推。m_dyn ≥ 0 ⇔ 全部约束在当前向量场下保持前向不变（见引理 82）。

**新增定义 542（动态风险 DynamicRisk）** 将动态裕度映射到与既有风险同尺度：
```
risk_dyn(s) = exp( − m_dyn(x) / σ_dyn ) ∈ (0, 1]
```
σ_dyn > 0 控制敏感度；m_dyn→+∞ 时 risk_dyn→0，m_dyn→0 时 risk_dyn→1。相比 v8 的静态指标，risk_dyn 是**前馈量**：它在 h_i 真正越界前就开始上升。

**新增定义 543（预计违约时间 TimeToViolation）** 一阶外推下的预警时域：
```
T_lead,i = h_i(x) / max(0, −ḣ_i(x))   若 ḣ_i < 0
         = +∞                         否则
T_lead = min_i T_lead,i
```
T_lead 作为诊断量与 risk_dyn 联合报告：当 T_lead < T_react（系统反应时间）时，即使 m_dyn ≥ 0 也应提前降速。T_lead 不直接进入风险向量，避免双重计数。

**新增定义 544（无源能量账本 PassivityEnergyLedger）** 遥操作两端口的能量守恒：
```
P(t) = E₀ + ∫₀ᵗ [ f_m(τ)ᵀ v_m(τ) − f_s(τ)ᵀ v_s(τ) ] dτ
```
符号约定：f_m 为主端施加于网络的力，f_s 为从端施加于网络的力，v 为对应端口速度。P(t) ≥ 0 ∀t ⇔ 网络无源。τ_rtt 只影响 P 的时间对齐，不改变无源性的定义。

**新增定义 545（波变量通道 WaveVariableChannel）** 令特征阻抗 b>0：
```
u = (f + b v)/√(2b),   w = (f − b v)/√(2b)   ⇒   f v = u² − w²
```
主端发 u_m(t)，从端经常值时延 T 收到 u_m(t−T) 并回传 w_s(t−T)。延迟散射算子 S_T 的频域增益恒为 1（全通），故常值时延下通道无源（见引理 84）。

**新增定义 546（透明性误差 TransparencyError）** 主端传送阻抗与期望阻抗的相对偏差：
```
Z_m = LPF( f_m / v_m )   （|v_m| > ε 时更新；MIMO 用 RLS 估计矩阵）
e_t = ‖Z_m − Z_t‖ / (‖Z_t‖ + ε) ∈ [0, ∞)
```
截断入风险：sat(e_t/e_max) = min(1, e_t/e_max)。

**新增定义 547（遥操作风险 TeleopRisk）** 三项归一化凸组合：
```
risk_tel(s) = w_τ·min(1, τ_rtt/τ_max)
            + w_P·min(1, max(0, −P)/P_ref)
            + w_T·min(1, e_t/e_max)
```
默认 w_τ=0.35, w_P=0.45, w_T=0.20，且 Σw=1 ⇒ risk_tel ∈ [0,1]。无源性缺口占最大权重，因为它是失稳的根因；时延与透明性是表征。

**新增定义 548（权限连续分配 AuthorityAllocation）** 人类权限系数：
```
α_raw(s) = clip(1 − β_dyn·risk_dyn − β_tel·risk_tel, α_min, 1)
α_h(t)   = RateLimit_{ρ}( α_raw ) 经 Schmitt 迟滞带 h_σ
u        = α_h·u_human + (1 − α_h)·u_auto
```
默认 β_dyn=1.2, β_tel=0.8, α_min=0.1, ρ=2.0/s, h_σ=0.05。α_h 连续 ⇒ 权限转移无跳变；速率限制+迟滞 ⇒ 无抖振（引理 86）。

**新增定义 549（七维风险向量）**
```
risk(s) = [risk_SEN, risk_SEM, risk_EFF, risk_PERF, risk_SLAM, risk_dyn, risk_tel] ∈ ℝ⁷
```
前 5 维继承 v8；后 2 维由 DBL/PEL/TTM 提供。MetaWeight/ER 的 softmax 维数同步扩为 7。

**新增定义 550（软触发 v9）** 「保持软层」的联合条件：
```
δ_trigger = { σ < τ_safe ∧ γ_grasp valid ∧ Δ_dom < τ_dom ∧ risk_SLAM < τ_SLAM
              ∧ m_dyn ≥ 0 ∧ P ≥ −E_ε ∧ e_t < τ_trans }
```
任一条件不满足 ⇒ 直接触发 M₀ 硬约束检查。E_ε 是工程容差，用于吸收测量噪声导致的短暂负裕度。

**新增定义 551（八层指标闭合 MetricLadder v9）**
```
M = (M₀, M₁, M₂, M₃, M_dom, M_SLAM, M_dyn, M_tel)
M_dyn: m_dyn ≥ 0          （动态可行性）
M_tel: risk_tel < τ_tel   （遥操作通道健康）
```
M_dyn、M_tel 均具备到 M₀ 的退化映射 δ_dyn、δ_tel，定义为「直接触发 M₀ 检查」。

**新增定义 552（能量箱阻尼回补 EnergyTankInjection）** 当 P(t) < 0：
```
选择 c_d = max(0, −P(t)) / ( ‖v_m − v_s‖²·Δt + ε )
f_damp  = − c_d (v_m − v_s)          （耗散力，不从环境中取能）
P(t⁺)  ← P(t) + c_d‖v_m − v_s‖²Δt ≥ 0
```
阻尼力方向与相对速度相反，故 ΔE_d ≥ 0，回补不会引入新的能量（引理 85）。

**新增定义 553（动态故障隔离 DynamicFaultIsolation）** DBL 模型残差监测：
```
r_dyn(t) = ‖ẋ_meas − (f(x)+g(x)u)‖ / (‖ẋ_meas‖ + ε)
if r_dyn > ε_model:
    DBL.freeze(m_dyn ← m_dyn_hold);  risk_dyn 置信度 γ_dyn ← 0.5·γ_dyn
    if γ_dyn < γ_min:  DBL.disable()   # 退化为 Level-1
```
模型失真时先冻结再降级，避免用错误模型产生虚假高裕度或虚假低裕度。

## 2. 形式化定义要点

**定义 493'（MetricLadder）** 由六层扩为八层，新增 M_dyn、M_tel；每层具备到 M₀ 的退化映射，保持「无空洞」性质。

**定义 495'（RewardDecomposer）** w'_i(s) = softmax(α·risk_i(s) + β·emo(s)·Ṽ_i)_{i=0..6}，risk ∈ ℝ⁷，Ṽ ∈ [0,1]⁷。

**定义 496'（SoftCert）** δ_trigger 追加三个动态/能量条件（定义 550），四条件变七条件，同一「违背概率/风险上界」尺度。

**定义 497'（MetaWeight）** w_i(s) = softmax(α·risk(s))_i，i=0..6。

**定义 521'（DA-OTL）** 阈值层数扩为 8，新增 τ_dyn、τ_tel，更新律不变：
τᵢ(t) = clip(τᵢ(0)+ηθ(t)+κᵢΔ_dom(t), ε_min,i, ε_max,i)。

**定义 541–553** 见上，构成 v9 的动态/无源/权限三组新定义。

import numpy as np

# IP-373 DynamicBarrierLadder：HOCBF 动态裕度
class DynamicBarrierLadder:
    """二阶 HOCBF（r<=2）实现；更高阶按同一递归外推。"""
    def __init__(self, constraints, g1, g2, Lambda, sigma_dyn=0.2, eps=1e-9):
        # constraints: list of dict(id, h(x), hdot(x,xd), hddot(x,xd,xdd), r)
        self.constraints = constraints
        self.g1 = g1            # {id: gamma1}
        self.g2 = g2            # {id: gamma2}
        self.Lambda = Lambda    # {id: Lambda_i}
        self.sigma_dyn = sigma_dyn
        self.eps = eps
        self.frozen = False
        self.m_hold = 1e9

    def step(self, x, xd, xdd):
        if self.frozen:
            return self.m_hold, float(np.exp(-self.m_hold / self.sigma_dyn)), float('inf'), {}
        m = float('inf'); details = {}; t_lead = float('inf')
        for c in self.constraints:
            cid = c['id']
            h = float(c['h'](x))
            hd = float(c['hdot'](x, xd))
            if c.get('r', 2) == 1:
                psi = hd + self.g1[cid] * h
            else:
                hdd = float(c['hddot'](x, xd, xdd))
                psi1 = hd + self.g1[cid] * h
                psi = hdd + self.g1[cid] * hd + self.g2[cid] * psi1
            m = min(m, psi / self.Lambda[cid])
            details[cid] = {'h': h, 'hdot': hd, 'psi': psi}
            if hd < -self.eps and h > 0:
                t_lead = min(t_lead, h / (-hd))
        risk_dyn = float(np.exp(-m / self.sigma_dyn))
        self.m_hold = m
        return m, risk_dyn, t_lead, details

    def freeze(self):
        self.frozen = True

    def disable(self):
        self.frozen = True
        self.m_hold = float('inf')


# IP-374 PassivityEnergyLedger：两端口能量账 + 波变量 + 能量箱
class PassivityEnergyLedger:
    def __init__(self, dt, E0=1.0, b=50.0, E_eps=0.05, cd_max=200.0):
        self.dt = dt
        self.E0 = E0
        self.P = E0
        self.b = b
        self.E_eps = E_eps
        self.cd_max = cd_max
        self.tau_rtt = 0.0
        self.E_hist = [E0]

    def step(self, f_m, v_m, f_s, v_s, tau_rtt=0.0):
        f_m, v_m = np.asarray(f_m), np.asarray(v_m)
        f_s, v_s = np.asarray(f_s), np.asarray(v_s)
        dE = (float(f_m @ v_m) - float(f_s @ v_s)) * self.dt
        self.P += dE
        self.tau_rtt = tau_rtt
        f_damp = np.zeros_like(v_m)
        if self.P < 0.0:
            rel_v = v_m - v_s
            denom = float(rel_v @ rel_v) * self.dt + 1e-9
            cd = min(self.cd_max, max(0.0, -self.P) / denom)
            f_damp = -cd * rel_v
            self.P += cd * float(rel_v @ rel_v) * self.dt   # 能量箱回补
        self.E_hist.append(self.P)
        if len(self.E_hist) > 1000:
            self.E_hist.pop(0)
        return self.P, f_damp

    def risk_tel(self, e_t, w=(0.35, 0.45, 0.20), tau_max=0.5, P_ref=1.0, e_max=0.5):
        r_tau = min(1.0, self.tau_rtt / tau_max)
        r_P = min(1.0, max(0.0, -self.P) / P_ref)
        r_T = min(1.0, e_t / e_max)
        return w[0] * r_tau + w[1] * r_P + w[2] * r_T

    def to_wave(self, f, v):
        return (f + self.b * v) / np.sqrt(2 * self.b), (f - self.b * v) / np.sqrt(2 * self.b)


# IP-375 TeleopTransparencyMonitor：透明性误差
class TeleopTransparencyMonitor:
    def __init__(self, alpha_lpf=0.98, eps=1e-6):
        self.alpha = alpha_lpf
        self.Zm = None
        self.eps = eps

    def update(self, f_m, v_m, Zt):
        # 标量近似；MIMO 版本用 RLS 估计阻抗矩阵
        if abs(v_m) > self.eps:
            z = float(f_m) / float(v_m)
            self.Zm = z if self.Zm is None else self.alpha * self.Zm + (1 - self.alpha) * z
        if self.Zm is None:
            return 0.0
        return abs(self.Zm - Zt) / (abs(Zt) + self.eps)


# IP-376 AuthorityAllocator：权限连续分配 + 防抖
class AuthorityAllocator:
    def __init__(self, beta_dyn=1.2, beta_tel=0.8, alpha_min=0.1,
                 rho=2.0, dt=0.02, hyst=0.05):
        self.beta_dyn = beta_dyn
        self.beta_tel = beta_tel
        self.alpha_min = alpha_min
        self.rho = rho
        self.dt = dt
        self.hyst = hyst
        self.alpha = 1.0

    def step(self, risk_dyn, risk_tel):
        raw = 1.0 - self.beta_dyn * risk_dyn - self.beta_tel * risk_tel
        raw = float(np.clip(raw, self.alpha_min, 1.0))
        # 迟滞：目标与当前差小于 hyst 时不动作，抑制边界抖振
        if abs(raw - self.alpha) < self.hyst:
            raw = self.alpha
        d = float(np.clip(raw - self.alpha, -self.rho * self.dt, self.rho * self.dt))
        self.alpha = float(np.clip(self.alpha + d, self.alpha_min, 1.0))
        return self.alpha


# IP-377 DynamicFaultIsolation：动力学模型残差监测
class DynamicFaultIsolation:
    def __init__(self, eps_model=0.25, gamma_init=1.0, gamma_min=0.3):
        self.eps_model = eps_model
        self.gamma = gamma_init
        self.gamma_min = gamma_min

    def update(self, xd_meas, xd_pred):
        denom = float(np.linalg.norm(xd_meas)) + 1e-9
        r = float(np.linalg.norm(np.asarray(xd_meas) - np.asarray(xd_pred))) / denom
        if r > self.eps_model:
            self.gamma *= 0.5
        else:
            self.gamma = min(1.0, self.gamma * 1.05)
        return r, self.gamma

    def unreliable(self):
        return self.gamma < self.gamma_min


# IP-360/366 主闭环集成关键片段：MetricVoiceGauge-DBL-PEL
def metricvoicegauge_round_9(M, s, obs, audio_stream=None, ell=None,
                             online_learner=None, grasp_typing=None,
                             emotional_reweighter=None, domain_adapter=None,
                             slam_risk=None, calib_fi=None,
                             dbl=None, pel=None, ttm=None, aa=None, d_fi=None):
    """50Hz 主环；v8 全流程 + 动态/无源/权限三增强，任一 None 即自动退化。"""
    x, xd, xdd = M.state.x, M.state.xd, M.state.xdd
    u_prev = M.last_u

    # --- 0. 动力学模型残差与故障隔离 ---
    gamma_dyn = 1.0
    if d_fi is not None:
        xd_pred = M.dyn_model.f(x) + M.dyn_model.g(x) @ u_prev
        _, gamma_dyn = d_fi.update(xd, xd_pred)
        if d_fi.unreliable() and dbl is not None:
            dbl.disable()

    # --- 1. 动态障碍梯度 (DBL) ---
    if dbl is not None and gamma_dyn >= 0.5:
        m_dyn, risk_dyn, t_lead, dyn_detail = dbl.step(x, xd, xdd)
    else:
        m_dyn, risk_dyn, t_lead, dyn_detail = float('inf'), 0.0, float('inf'), {}

    # --- 2. 继承 v8 的感知侧：DA-ML / SPR / Calib-FI ---
    delta_dom = 0.0
    if domain_adapter is not None:
        domain_adapter.update(obs)
        delta_dom = domain_adapter.compute_domain_shift()
        if online_learner is not None:
            online_learner.update_domain_shift(delta_dom)
    risk_slam = 0.0
    if slam_risk is not None:
        risk_slam, _ = slam_risk.compute_risk_slam(M.slam_state())
    if calib_fi is not None:
        M.perception_fusion.set_sensor_weights(calib_fi.get_sensor_weights())
        if online_learner is not None:
            online_learner.update_kappa(calib_fi.get_kappa())

    # --- 3. 无源能量账本 (PEL) + 透明性 (TTM) ---
    P_passive, e_t, risk_tel = float('inf'), 0.0, 0.0
    f_damp = np.zeros_like(xd[:M.n_dof])
    if pel is not None:
        fm, vm = M.master.wrench(), M.master.velocity()
        fs, vs = M.slave.wrench(), M.slave.velocity()
        P_passive, f_damp = pel.step(fm, vm, fs, vs, tau_rtt=M.chan.rtt())
        if ttm is not None:
            e_t = ttm.update(fm, vm, M.env.estimated_impedance())
        risk_tel = pel.risk_tel(e_t)
        M.slave.apply_damping(f_damp)

    # --- 4. 7 维风险向量 + softmax 权重 ---
    base_risk_5d = M.reward_decomposer._compute_risk_5d(M.env.state)
    risk_7d = np.array([*base_risk_5d, risk_dyn, risk_tel])
    w_prime = emotional_reweighter.compute_emotional_weights_7d(risk_7d, M.emo, M.V7) \
        if emotional_reweighter is not None else M.reward_decomposer.w_7d(risk_7d)

    # --- 5. 权限连续分配 (AA) ---
    alpha_h = 1.0
    if aa is not None:
        alpha_h = aa.step(risk_dyn, risk_tel)
    u_human = M.master.command()
    u_auto = M.autonomy.safe_command()
    u_cmd = alpha_h * u_human + (1 - alpha_h) * u_auto

    # --- 6. 软触发 v9：任一动态/能量条件不满足 → M₀ 硬检查 ---
    soft_ok = (m_dyn >= 0.0) and (P_passive >= -pel.E_eps if pel is not None else True) \
              and (e_t < M.tau_trans)
    if not soft_ok or (ttm is not None and risk_tel > M.tau_tel):
        u_cmd = M.metric_ladder.hard_check_and_clamp(x, u_cmd)

    M.last_u = u_cmd

    # --- 7. 继承 v8/v7 的证书、指标、奖励流程 ---
    C, spatial_cert, claims, metrics, rewards = M.metricvoicegauge_round_8(
        M, s, obs, audio_stream, ell=ell,
        online_learner=online_learner, grasp_typing=grasp_typing,
        emotional_reweighter=emotional_reweighter,
        domain_adapter=domain_adapter, slam_risk=slam_risk, calib_fi=calib_fi)

    metrics.update({'m_dyn': m_dyn, 'risk_dyn': risk_dyn, 't_lead': t_lead,
                    'P_passive': P_passive, 'risk_tel': risk_tel,
                    'e_t': e_t, 'alpha_h': alpha_h})
    return C, spatial_cert, claims, metrics, rewards

## 4. 推导

**引理 82（HOCBF 前向不变性与动态裕度非负）** 对每个相对阶 r_i ≤ 2 的约束，若初值满足 ψ_{i,k}(t₀) ≥ 0（k=0..r_i），且控制 u 满足 ψ̇_{i,r_i} + α_{i,r_i+1}(ψ_{i,r_i}) ≥ 0，则由比较引理逐层得 ψ_{i,k}(t) ≥ 0 ∀t ≥ t₀，特别地 h_i(t)=ψ_{i,0}(t) ≥ 0。故 CBF-QP 可行时 m_dyn ≥ 0、risk_dyn < 1；risk_dyn 是「尚未越界」的严格内点度量。

**引理 83（risk_dyn 有界单调）** m_dyn 已用 Λ_i > 0 归一化，故 m_dyn 与 σ_dyn 同量纲。risk_dyn = exp(−m_dyn/σ_dyn) ∈ (0,1]，且 ∂risk_dyn/∂m_dyn = −(1/σ_dyn)exp(−m_dyn/σ_dyn) < 0，对裕度严格单调递减。由于 risk_dyn 与其余 6 维风险同处 [0,1]，7 维 softmax 的温度 α 不需要重标定；新增维度不会因量纲差异主导权重。

**引理 84（波变量常时延无源性）** 由定义 545，f v = u² − w²。常值时延 T 只把 u(t)、w(t) 平移为 u(t−T)、w(t−T)，其傅里叶增益 |e^{−jωT}|=1，故散射算子 S_T 全通、‖S_T‖₂=1。两端若各自无源，则级联两端口网络在任意常值 T 下无源，即 P(t) ≥ E₀ − E_loss(t)，E_loss 仅来自控制器主动耗散。因此时延本身不产生无界能量，risk_tel 的时延项是表征而非失稳根因。

**引理 85（能量箱阻尼回补保持非负）** 当 P<0 时取 c_d = max(0,−P)/(‖v_m−v_s‖²Δt+ε)，注入 f_damp = −c_d(v_m−v_s)。该力与相对速度反向，瞬时功率 f_dampᵀ(v_m−v_s) = −c_d‖v_m−v_s‖² ≤ 0，即从系统抽取能量；回补量 ΔE_d = c_d‖v_m−v_s‖²Δt ≥ −P。故补偿后 P⁺ = P + ΔE_d ≥ 0。回补不引入新能量，不会破坏闭环无源性。

**引理 86（权限分配无抖振）** α_raw 对 (risk_dyn, risk_tel) 是 1-Lipschitz（clip 不增 Lipschitz 常数）；速率限制使 |α̇_h| ≤ ρ；Schmitt 迟滞带 h_σ 要求风险穿越幅度超过 h_σ 才切换方向。每次方向反转至少要跨过 h_σ，耗时 ≥ h_σ/ρ，故切换频率 f_sw ≤ ρ/(2h_σ)。取 ρ=2.0/s、h_σ=0.05 得 f_sw ≤ 20Hz，仍可能接近控制频率；工程上取 h_σ=0.1 ⇒ f_sw ≤ 10Hz，低于 50Hz 主环的 1/5，避免权限抖动。

**引理 87（七维退化正交性）** DBL 只写 risk_dyn（及 m_dyn、T_lead），PEL/TTM 只写 risk_tel（及 P、e_t），AA 只写 α_h；v8 的 DA-ML 只写 Δ_dom/τ，SPR 只写 risk_SLAM，Calib-FI 只写 sensor_weight/κ。写集两两不交。因此任意子集失效可用「恒等默认值」替换（risk_dyn≡0、risk_tel 仅时延项、α_h≡1），组合结果等于其余模块的复合；全失效即 v8。退化正确性由接口正交性直接给出，无级联副作用。

**引理 88（v9 软硬约束无空洞）** δ_trigger 追加 m_dyn ≥ 0、P ≥ −E_ε、e_t < τ_trans，且任一不满足都直接调用 M₀ 的 hard_check_and_clamp。τ_dyn、τ_tel、E_ε、τ_trans 均在归一化风险尺度 [0,1]（m_dyn 经 Λ 归一，P 经 P_ref 归一，e_t 经 e_max 归一），与 v8 的 τ_safe、τ_dom、τ_SLAM 同尺度。故任一软层违背必经 M₀，不存在「软层通过、硬层失效」的空洞。

## 8. 本轮最大风险

**一句话**：动力学模型误差与力/速度测量噪声被高阶微分放大，使 m_dyn 抖动、risk_dyn 误报；叠加时延抖动使 P(t) 反复穿越零点，权限 α_h 可能在「人控/自控」之间高频切换——「系统为追求动态预测与无源安全，反而制造了它想消除的权限抖动」。
