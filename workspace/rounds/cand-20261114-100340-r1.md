# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环第 3 轮；本轮灵感：「多传感器融合」×「创新点」）

> R69 教会系统「去问」，并用「k 个正交证据源一致」防止被一次回答骗过。但它把「正交」当成了**宣言**，而不是**测量**：真实的多传感器在物理上高度相关——两个相机共享光照，LiDAR 与深度相机共享几何，力觉与视觉共享同一次接触，一个人的表情、语气、姿态由同一个内在状态联合生成。于是 R69 的「k 个正交源」很可能是**同一句谎话的 k 个副本**；朴素融合会让系统**更自信、也更错**。
>
> 更深一层：R69 用**边际**互信息 `IG(M; r_ij)` 衡量证据，而多传感器融合的正确计价单位是**增量**信息——一个传感器值钱，不是因为它与 M 的互信息高，而是因为它**不能被已有传感器解释的那部分**与 M 的互信息高。这两件事在相关传感器上可以差一个数量级：冗余传感器边际 IG 很高，增量 IG ≈ 0。
>
> 本轮两个灵感恰好是同一枚硬币的两面：
> - **多传感器融合**给出「信息 = 正交化后的新息」这套算子（Kalman 的 innovation 就是测量减去预测的残差）；
> - **创新点**给出同一算子的科研版本：一个创新点，恰恰是「新方法效应向量减去所有基线可解释部分」的**正交残差**；能被现有层重新推导出的东西，不是创新。
>
> 核心命题：**把「信息」重新定义为「正交新息」：融合只计增量信息（OIF），交互只买增量信息（VoI_⊥），并用同一个正交投影算子给研究本身发「新颖性证书」（NCD）——能被基线张成的部分不算创新，剩余的高相关-高残差方向才是下一轮的创新点。** 命名 **NOVA-RAS**（Novelty-Orthogonalized Valuation of Added-information）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**这条新信息里，有多少是我已经知道的？这个新机制里，有多少是别人已经能解释的？**」——不重复计费，也不重复邀功。

## 0. 直觉与动机

**灵感 1（多传感器融合 → 相关传感器让「共识」变成「共谋」）**
直觉：R69 的证据纪律说「k 个正交源一致才定案」。但如果这些源共享同一个误差源（同一盏灯、同一次标定偏差、同一段对抗纹理、同一个人同时控制表情和语气），它们的一致不是独立验证，而是**同一次错误被复制了 k 遍**。统计上，若 n 个等精度、两两相关 ρ 的传感器求平均，方差是 σ²[ρ + (1−ρ)/n]，当 n→∞ 时**收敛到 ρσ² 而不是 0**——融合存在一个**共模地板**。所以多传感器融合的第一课不是「如何融合得更好」，而是「**何时不该融合**」：当新增传感器的新息几乎为零时，它只贡献成本、延迟和被攻击面。

**灵感 2（信息 = 正交新息 → 只对「解释不了的部分」计价）**
直觉：Kalman 滤波里 innovation 是 `ν = z − Hx̂`，即「测量里模型还没预测到的部分」。把这条搬进多传感器：第 i 个传感器相对已有证据子空间的**新息** `ν_i = φ_i − P_{<i}φ_i`，其协方差是 Schur 补 `S_i`；只有 `ν_i` 携带**增量信息**。融合 `ν_i`（而不是原始 `φ_i`）就自动避免了对相关传感器重复计费。这解释了为什么「融合越多越好」是错的：信息的正确单位是**条件**互信息，不是边际互信息。

**灵感 3（创新点 = 正交残差 → 估计论与科研是同一个算子）**
直觉：一个「创新点」在评审眼里是什么？是**所有基线都解释不掉的那部分**。把新方法的效应向量 v 投影到基线/消融效应的张成空间 B 上，残差 `ν = (I − P_B)v` 才是真正的新颖贡献；若 `ν ≈ 0`，无论效果多好，它都只是基线的线性组合——**再推导（re-derivation），不是创新**。这与 Kalman 的 innovation 是同一个 `P_{B^⊥}`：一个对「状态」做残差，一个对「贡献」做残差。于是「多传感器融合」与「创新点」不是两个灵感，而是**同一个正交化原理在两个层面的实例**。

**灵感 4（增量 VoI → R69 的提问经济学需要重新定价）**
直觉：R69 的 MINT 选 `argmax[VoI−c]`，但 VoI 用的是边际熵降。若已经通过视觉知道「人在犹豫」，再问一句（高度相关的语言通道）边际熵降可能很高，**条件**熵降却接近 0——R69 会为已知的答案再付一次钱，还会因重复计费把后验**过度锐化**。把 VoI 换成条件 VoI `IG(M; y_g | ℰ_fused)`，并设 `VoI_⊥ ≤ 0 则不交互`，系统就只在「真不知道且问得出来」时才花预算。这同时修正了 R69 的过度自信与交互疲劳。

**灵感 5（新颖性证书 → 防止「层层叠加」变成「层层重推导」）**
直觉：这个研究计划已经叠了 70 轮。每轮都声称自己加了新层，但**谁能保证新层不是旧层的重新参数化**？用同一套正交化：对任意新机制，测其效应向量相对「全部已有组件 + 全部消融」的残差；残差显著才发证，否则记为「已达基线」。更进一步，把「任务目标方向 u」与「基线张成空间 B」比较：`coverage = ‖P_B u‖/‖u‖` 低而相关性高的方向，就是**开放创新点**——它给下一轮生成研究议程，而不是靠灵感词随机碰撞。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（NOVA-RAS 总览）** NOVA-RAS = (OIF, MID, CMC, IGA, KEFF, CMF, NCD, IGD, RAS-WM†)。三不变式：
(i) **信息只计一次**：任意证据/传感器的贡献按正交新息计入，禁止边际重复计费；
(ii) **未认证不锐化**：独立性未被 KEFF 认证时，融合必须使用共模保守融合（CI），其不确定度不小于任一单源；
(iii) **新颖性可证伪**：任何被声称为「创新」的机制，必须通过 NCD 的残差显著性检验，否则降级为基线。

**定义 311（证据模型与共模分解）** 任务相关隐变量 M（离散模态或连续量），证据通道 i 给出 `φ_i = H_i M + ε_i`。误差分解为共模与个体分量：`ε_i = c + δ_i`，`c ~ 𝒩(0,Σ_c)` 对所有 i 相同，`δ_i ~ 𝒩(0,Σ_i)` 独立。故 `Cov(ε_i,ε_j)=Σ_c (i≠j)`，`Var(ε_i)=Σ_c+Σ_i`。记联合协方差 Σ，分块对角部分为 Σ_d。

**定义 312（朴素融合及其过度自信）** 朴素融合假设 `Σ=Σ_d`（忽略 Σ_c），得精度 `Λ_naive = Π^{-1} + Σ_i H_i^T Σ_i^{-1} H_i`；真实精度 `Λ_true = Π^{-1} + H^T Σ^{-1} H`。定义过度自信量 `OC = ½ log det(Λ_naive) − ½ log det(Λ_true)`；仅当 `Σ_c=0` 时 OC=0。R69 的独立证据融合即 `Σ_c=0` 的隐式假设。

**定义 313（正交新息与 OIF）** 给定证据序（或对称化），第 i 通道相对已融合集 `E_{<i}` 的线性新息与 Schur 补：
`ν_i = φ_i − Σ_{i,<i} Σ_{<i,<i}^{-1} φ_{<i}`，`S_i = Σ_{ii} − Σ_{i,<i} Σ_{<i,<i}^{-1} Σ_{<i,i}`。
正交新息融合 OIF：`Λ_OIF = Π^{-1} + Σ_i H_i^T S_i^{-1} H_i`，`x̂ = Λ_OIF^{-1}(Π^{-1}μ + Σ_i H_i^T S_i^{-1} ν_i)`。
性质：OIF 与按 Σ 做 GLS 等价；每个通道只按其**不能被已有通道解释**的部分计费；最终估计与融合顺序无关（对称化后）。

**定义 314（增量信息与冗余度）** 对证据集 S：`IG(S|E) = I(M;φ_{S∪E}) − I(M;φ_E) ≥ 0`，高斯下 `I(M;φ_S) = ½ log det(I + Π^{1/2} H_S^T Σ_{SS}^{-1} H_S Π^{1/2})`。通道 i 的**冗余度** `ρ_i = 1 − IG(i|E_{<i}) / I(M;φ_i) ∈ [0,1]`；`ρ_i→1` 表示已被已有证据完全解释。R69 的边际 IG 恰为 `IG(i|∅)`，是 ρ=0 的特例；真实计价应使用 `IG(i|E)`。

**定义 315（有效独立源数 KEFF）** 对误差相关矩阵 R（相关化后）特征值 {λ_k}，定义 `k_eff = (Σ_k λ_k)² / Σ_k λ_k²`（参与比）。等相关 ρ 的 n 源闭式：`k_eff = n² / ([1+(n−1)ρ]² + (n−1)(1−ρ)²)`。证据纪律升级为：`k_eff(ℰ_agree) ≥ k_req` 才允许「k 源一致」定案；否则一致无效，U_epi 保持未消解并走保守分支。

**定义 316（共模地板与停止律）** 等精度等相关 n 源的最优线性融合方差 `v_n = σ²[ρ+(1−ρ)/n] ≥ ρσ²`；故信息 `I_n = ½ log(1+Π/v_n)` 随 n 饱和于 `½ log(1+Π/(ρσ²))`。给定单传感器成本 c，停止律：选最大 n* 使增量增益 `ΔI_n = I_n − I_{n−1} ≥ c`；`n>n*` 的传感器**禁止加入**（负收益）。这给「何时不融合」一个可计算判据。

**定义 317（增量 VoI 交互控制器 IGA）** 用条件信息增益替代边际：`VoI_⊥(g) = IG(y_g | ℰ_fused) − c(g)`；`g* = argmax_g VoI_⊥(g)`，若 `max VoI_⊥ ≤ 0` 则不交互。与 R69 的 MINT 关系：`VoI_⊥ = VoI_R69 − IG(y_g; ℰ_fused)`，即 R69 把「已知道的部分」也计入收益；NOVA 将其扣除。

**定义 318（独立性认证、两级融合退避）** 独立性认证 `Cert_indep(S) ⇔ k_eff(S) ≥ k_req ∧ OC(S) ≤ τ_oc`（OC 用 CMC 估计）。认证通过 → OIF（更锐、更省预算）；未通过/估计不可信/检测到共模注入 → 共模保守融合（CI）：`P_CI^{-1} = Σ_i ω_i P_i^{-1}, Σω_i=1`，其对任意相关结构都**一致**（不低估）。安全侧：未认证分支的融合不确定度 ≥ R69 独立假设下的不确定度 ⇒ λ_floor 不降。

**定义 319（共模相关估计 CMC）** 从残差流在线估计 Σ_c 与 Σ_d：用收缩估计 `Σ̂ = (1−α)Σ̂_sample + α diag(Σ̂_sample)`（α 由 Ledoit–Wolf 或交叉验证给出），并把共模分量投影为低秩因子 `Σ_c ≈ UU^T`。约束：估计不确定度进入 OC 并触发保守分支，绝不让「估错的相关性」制造虚假独立。

**定义 320（新颖性分解 NCD）** 标准化指标空间上，机制效应向量 `v ∈ ℝ^q`，基线/消融效应张成 `B = span{b_1,…,b_m}`。正交残差 `ν = (I−P_B)v`；**新颖性比** `N = ‖ν‖/‖v‖`。`N=0 ⇔ v∈B`（可被基线重新推导）。证书条件：`N ≥ δ_N` 且残差显著性检验（零假设 v∈B）`p < α`，并在留出基准/独立种子上复现。

**定义 321（新颖性检验与创新缺口 IGD）** 零假设下 `T = ‖ν‖²/σ² ~ χ²_{q−rank(B)}`（高斯噪声），据此给 p 值。定义任务方向 u（目标梯度/关键指标方向）的**基线覆盖率** `Cov_B(u)=‖P_B u‖/‖u‖`；**创新缺口** `Gap(u) = (1−Cov_B(u))·rel(u)`，rel(u) 为任务相关性。高 Gap 方向即「重要但现有层解释不了」的开放创新点，直接生成下一轮议程。

**定义 322（融合安全不变式）** 融合输出不确定度 `U_fuse ≥ U_CI`（CI 为共模保守融合）；认证独立时 `U_fuse = U_OIF`，否则 `U_fuse = U_CI`。传感器子集选择必须满足定义 316 的停止律与 R69 信息动作安全认证（定义 302）；融合不得改变 C-RAS-WM 的安全包络。

**定义 323（NOVA 证书 J_NOVA）** `J_NOVA = (J_FLUID, OC, k_eff, S_indep_flag, n_fuse, ΔI_p95, novelty_ratio N, novelty_p, gap_ids, nova_ver)`。`Valid ⇔ Valid(J_FLUID) ∧ (未认证独立 ⇒ 走 CI 分支) ∧ 新增传感器满足停止律 ∧ 声明的创新通过 NCD`。

**定义 324（威胁模型 ℰ_NOVA）** 在 ℰ_FLUID 上追加：共模注入（对全部传感器施加同向偏置）、相关欺骗（多通道联合伪造一致证据）、协方差投毒（污染 CMC 样本使相关性被低估）、冗余传感器 DoS（用大量高相关通道耗尽预算/延迟）。并入 AIC：`ℰ_NOVA = ℰ_FLUID × ℰ_commonmode × ℰ_covpoison`。

**定义 325（审计与参与式新颖性 VQAuditor-O）** 审计两类声明：(a) 融合层：k_eff/OC/独立认证是否被采样偏差欺骗；(b) 研究层：NCD 基线集是否完整、是否遗漏能解释该效应的既有层。结论回灌 CMC 先验与下一轮 IGD 议程；审计记录进入证书哈希链。

# IP-264 OIF：正交新息融合（只对解释不了的部分计费）
def oif_fuse(phi, H, Sigma, prior):
    order = symmetric_order(Sigma)              # 对称化/归一化排序
    Lam, eta = prior.Prec, prior.Prec @ prior.mu
    used = []
    for i in order:
        S_i = schur(Sigma, i, used)             # 创新协方差
        nu  = phi[i] - Sigma[i, used] @ inv(Sigma[used, used]) @ phi[used]
        Lam = Lam + H[i].T @ inv(S_i) @ H[i]
        eta = eta + H[i].T @ inv(S_i) @ nu
        used.append(i)
    return Gauss(Lam, Lam @ eta)               # 与 GLS 等价，顺序无关

# IP-265 MID + IP-315 KEFF：增量信息与有效独立源数
def decompose_information(evidence, M_prior):
    IG_marg = {i: mutual_info(M, evidence[i]) for i in evidence}
    IG_inc  = {i: cond_mutual_info(M, evidence[i], evidence[:i]) for i in evidence}
    rho     = {i: 1 - IG_inc[i]/IG_marg[i] for i in evidence}
    k_eff   = participation_ratio(corr(evidence))       # 参与比
    return IG_marg, IG_inc, rho, k_eff

# IP-268/269：独立认证 + 共模地板停止律
def certify_and_select(evidence, budget):
    k_eff = participation_ratio(corr(evidence))
    oc    = overconfidence(evidence)                    # ½logdet 差
    if k_eff < K_REQ or oc > TAU_OC:
        return conservative_CI(evidence), 'unverified'  # 不锐化
    keep = []
    for i in sorted_by_marginal_gain(evidence):
        if incremental_gain(i, keep) < unit_cost(i):    # 停止律
            continue
        keep.append(i)
    return oif_fuse(select(evidence, keep)), 'certified'

# IP-267 IGA：条件 VoI 交互（R69 扣掉「已知道」）
def choose_interaction(modes, evidence_fused, budget):
    best = None
    for g in info_action_candidates(modes):
        if not budget.allow(g) or not c_ras_wm.certify_info(g): continue
        voi_perp = cond_mutual_info(M, y_g, evidence_fused) - cost(g)
        if best is None or voi_perp > best.score: best = (g, voi_perp)
    return best if best and best.score > 0 else None    # VoI_⊥<=0 → 不交互

# IP-270/271 NCD + IGD：新颖性证书与创新缺口
def novelty_certificate(v, baselines, sigma, alpha=0.05):
    B  = orthonormal_basis(baselines)
    nu = v - B @ (B.T @ v)                              # 正交残差
    N  = norm(nu) / (norm(v) + 1e-12)
    T  = norm(nu)**2 / sigma**2                         # ~ chi2_{q-rank(B)}
    p  = chi2_sf(T, df=len(v)-rank(B))
    return N, p, (N >= DELTA_N and p < alpha)

def innovation_gap(task_direction, baselines):
    cov = norm(proj(baselines, task_direction)) / norm(task_direction)
    return (1 - cov) * relevance(task_direction)        # 开放创新点分数

# IP-273 主闭环（继承 R69，在融合与交互处换成增量计价）
def NOVA_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    evid = M.channels.extract(o)                        # 多模态证据
    fused, mode = M.cmc.certify_and_select(evid, M.budget)  # OIF 或 CI
    U_ale, U_epi, modes = M.aud.decompose(M.fmp.sample(o, K_of(z)), z)
    g = M.iga.choose_interaction(modes, fused)          # 条件 VoI（增量）
    if g is not None:
        ans = M.cia.execute(g)
        U_epi = M.cia.update_conditional(modes, ans, fused)
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(...)
    M.vqa_o.submit_async(fused.k_eff, fused.OC, g, U_epi)
    return k, lam, mode, (U_ale, U_epi, fused)

## 3. 推导

**引理 19（OIF 不重复计费）** 设误差联合协方差 Σ 已知。OIF 的融合精度等于 `Λ_true = Π^{-1} + H^T Σ^{-1} H`，故与 GLS 等价、与融合顺序无关；而朴素融合的过度自信 `OC = ½ log det(Λ_naive/Λ_true) ≥ 0`，等号当且仅当 `Σ_c=0`。系：R69 的「k 源独立融合」是 OC=0 的理想化；真实相关性下它系统性低估方差，低估量随 ρ、n 单调增。

**引理 20（共模地板）** 等精度 σ²、两两相关 ρ 的 n 源，最优线性融合方差 `v_n = σ²[ρ+(1−ρ)/n]`。故 `lim_{n→∞} v_n = ρσ² > 0`，信息 `I_n` 饱和；增量增益 `ΔI_n = ½ log[(1+Π/v_n)/(1+Π/v_{n−1})]` 对 n 严格递减且 `→0`。系：存在有限最优 n*，由 `ΔI_{n*}=c` 唯一确定——**多传感器融合有硬性边际收益递减，冗余传感器是负资产**。

**引理 21（有效独立源数）** 对等相关 n 源，`k_eff = n² / ([1+(n−1)ρ]² + (n−1)(1−ρ)²)`，满足 `k_eff(ρ=0)=n`、`k_eff(ρ=1)=1`、对 ρ 严格递减。故 R69 的「k 源一致」在 ρ→1 时实际只有 1 个独立源；证据纪律若用名义 k 而非 k_eff，错误采纳率上界（R69 引理 18）失效，因为「欺骗相关 ρ<1」的假设被物理相关性打破。

**定理 18（NOVA 严格包含 R69，且安全侧不弱）** 当所有跨通道协方差为 0 且被 KEFF 认证时，OIF=独立融合、`VoI_⊥=VoI`、停止律自动保留全部传感器，NOVA 逐指令退化为 R69（`J_NOVA` 中 OC=0、`k_eff=k`）。当相关性存在且未认证时，NOVA 走 CI 保守分支，其融合方差 ≥ R69 独立融合方差 ⇒ λ_floor 不降 ⇒ 期望风险不高于 R69。因此「相关性」是 R69 的对偶：R69 在 ρ=0 边界上正确，NOVA 补上它在 ρ>0 时系统性不安全的部分。

**定理 19（新颖性证书的正确性与可证伪性）** 在零假设 `v∈B` 与次高斯噪声下，NCD 的残差检验以水平 α 控制「把再推导误判为创新」的错误率；任意 `v∈B` 有 `N=0`；且 N 对指标空间的可逆线性重参数化不变（用白化内积）。系：创新点不是「指标变好」，而是「变好的方向无法被既有层张成」；一个只能被旧层线性组合解释的增益，无论多大都不该记为创新。

**定理 20（创新缺口议程的最优性）** 在 A100（给定 M 后各通道条件独立）下，`IG(S|E)` 是单调子模函数，故按边际增益/成本的贪心传感器选择达到 `(1−1/e)` 近似；`Cov_B(u)` 关于基线集单调不减，故「高 Gap、高 rel」方向在贪心议程下优先被探索，且不会重复已被覆盖的方向。

# IP-264 OIF：只对正交新息计费
def oif_fuse(phi, H, Sigma, prior):
    order = symmetric_order(Sigma)
    Lam, eta, used = prior.Prec, prior.Prec @ prior.mu, []
    for i in order:
        S_i = schur(Sigma, i, used)
        nu  = phi[i] - Sigma[i, used] @ inv(Sigma[used, used]) @ phi[used]
        Lam = Lam + H[i].T @ inv(S_i) @ H[i]
        eta = eta + H[i].T @ inv(S_i) @ nu
        used.append(i)
    return Gauss(Lam, Lam @ eta)                # == GLS, 顺序无关

# IP-265/268/269：增量信息、有效独立源数、认证与停止律
def certify_and_select(evidence, budget):
    k_eff = participation_ratio(corr(evidence))
    oc    = overconfidence(evidence)             # ½logdet(Λ_naive/Λ_true)
    if k_eff < K_REQ or oc > TAU_OC:
        return conservative_CI(evidence), 'unverified'   # 不锐化
    keep = []
    for i in sorted_by_marginal_gain(evidence):
        if incremental_gain(i, keep) < unit_cost(i):     # 共模地板停止律
            continue
        keep.append(i)
    return oif_fuse(select(evidence, keep)), 'certified'

# IP-267 IGA：条件 VoI（扣除已知信息）
def choose_interaction(modes, fused, budget):
    best = None
    for g in info_action_candidates(modes):
        if not budget.allow(g) or not c_ras_wm.certify_info(g): continue
        score = cond_mutual_info(M, y_g, fused) - cost(g)   # VoI_⊥
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None

# IP-270/271 NCD/IGD：新颖性证书与创新缺口
def novelty_certificate(v, baselines, sigma, alpha=0.05):
    B  = orthonormal_basis(baselines)
    nu = v - B @ (B.T @ v)                      # 正交残差 = 真创新
    N  = norm(nu) / (norm(v) + 1e-12)
    p  = chi2_sf(norm(nu)**2 / sigma**2, df=len(v) - rank(B))
    return N, p, (N >= DELTA_N and p < alpha)

def innovation_gap(task_direction, baselines):
    cov = norm(proj(baselines, task_direction)) / norm(task_direction)
    return (1 - cov) * relevance(task_direction)

## 4. 推导

**引理 19（OIF 不重复计费）** OIF 精度 `=Π^{-1}+H^TΣ^{-1}H`，与 GLS 等价、顺序无关；朴素融合的过度自信 `OC=½logdet(Λ_naive/Λ_true)≥0`，等号当且仅当 `Σ_c=0`。系：R69 的独立融合在高相关下系统性低估方差。

**引理 20（共模地板）** 等精度等相关 n 源最优融合方差 `v_n=σ²[ρ+(1−ρ)/n]`，`lim v_n=ρσ²>0`；信息饱和，增量增益 `ΔI_n` 严格递减。系：存在有限最优 n*，由 `ΔI_{n*}=c` 唯一确定，冗余传感器是负资产。

**引理 21（有效独立源数）** 等相关 n 源 `k_eff=n²/([1+(n−1)ρ]²+(n−1)(1−ρ)²)`，`k_eff(ρ=0)=n`、`k_eff(ρ=1)=1`、对 ρ 严格递减；名义 k 源在高相关下不等价于 k 个独立证据，R69 引理 18 的 ρ<1 前提被物理相关性打破。

**定理 18（NOVA 严格包含 R69，安全侧不弱）** `Σ_c=0` 且认证时退化为 R69（OIF=独立融合、VoI_⊥=VoI、停止律保留全部传感器）；`Σ_c≠0` 且未认证时走 CI，融合方差 ≥ R69 独立融合方差 ⇒ λ_floor 不降 ⇒ 风险不高于 R69。相关性是 R69 的对偶缺口。

**定理 19（新颖性证书正确且可证伪）** 零假设 `v∈B`、次高斯噪声下，残差检验以水平 α 控制「再推导误判为创新」；`v∈B ⇒ N=0`；N 对指标空间可逆线性重参数化不变。系：创新点不是「变好」，而是「变好的方向不可被既有层张成」。

**定理 20（议程最优性）** 在 A100（给定 M 后条件独立）下 `IG(S|E)` 单调子模，边际增益/成本贪心达 `(1−1/e)`；`Cov_B(u)` 对基线集单调不减，故高 Gap/高 rel 方向优先探索且不重复。

## 7. 本轮最大风险

**一句话**：NOVA-RAS 的全部正确性押在「跨通道协方差估计是对的」这一前提上——**若 CMC 低估了共模相关（小样本、非平稳或被协方差投毒），系统就会把「同一句谎话的 k 个副本」当成 k 个独立新息去融合，得到比 R69 更自信也更错的结论；更隐蔽的是，正交化会把真正的共模误差投影成「新颖信息」并盖上独立认证的章**——**错误地证明「我独立」，比不知道相关性更危险**。

**次级风险与缓解**：相关估计误差（收缩/低秩先验 + 估计不确定度入 OC + CI 兜底）；共模注入/相关欺骗（ℰ_commonmode 对抗训练 + E302/E315）；冗余传感器 DoS（停止律硬约束 n* + 预算）；NCD 基线集不完整（VQAuditor-O 审计 + 外部基线 + E316 回溯）；实时预算（n≤8、低维投影、Schur 增量缓存）。
