# 第 70 轮（承接第 69 轮「FLUID-RAS」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「微调」×「语音交互」）

> R69 让系统学会了「问」：把不确定性拆成 aleatoric / epistemic，用流匹配策略呈现多模态，用 VoI 选择注视、探针、问句去主动消歧，并用流似然做标定不可吸收的第二意见。但它有两个被自己点破却始终没修的盲点：
>
> 1. **只会问，不会听**：回答被当成一截干净文本。可真实的语音交互里，说话人自己也在犹豫——拖长的「呃……」、上扬的尾音、说到一半的自我更正（「不对，是左边」），都是关于**回答可靠性**的一手证据。R69 的 g_ask 丢掉了整条副语言通道。
> 2. **只会问，不会记**：模型是冻结的。R69 的 MCG 只能**检测**模态权重失准（ECE 越界）然后退回保守，却永远**修不好**——系统的结构性无知（不认识这个口音、这位用户、这类场景）不会因为问了一百次而减少。这正是 R69 最大风险的根源：模态权重不可信，问错比不问更危险。而权重不可信是**慢变量**，快环里的任何技巧都修不了。
>
> 本轮两个灵感恰好补上同一个环的两端：
> - **语音交互**把「问」升级为**双工、带韵律、可复述、可被打断**的通道——它既是消歧证据，也是**教学信号**；
> - **微调**把「记」补上——它是唯一能**修复**标定的慢通道，但也会把快环的一次误听永久焊进权重。
>
> 核心命题：**把不确定性分成三层时标——偶发可约（快环交互消解）、偶发不可约（保守）、结构性无知（仅慢环微调可减）；用「证据门控」把语音交互产生的教学信号延迟、审计后再喂给慢环；安全关键子空间冻结、函数空间信任域、安全回归门、证书版本化，确保「学」不会悄悄改写「安全」。** R69 被严格包含为「慢环关闭 + 语音退化为文本」的边界。命名 **DUPLEX-RAS**（Dual-timescale, Uncertainty-aware, Prosody-grounded, Learning-safe EXchange）。
>
> 一句话定位：R68 问「测量还准吗」，R69 问「该向谁求证、还能问什么」，R70 问「**我该怎么听、又该记住什么**」——不确定性第一次有了记忆：既能被一句带犹豫的语气当场化解，也能被一次受审计的微调缓慢修复，但绝不被一次误听偷偷固化。

## 0. 直觉与动机

**灵感 1（微调 → 不确定性的第三时标）**
直觉：R69 默认「环内的不确定都能在环内解决」。但有一类不确定性根本不在环内：模型没见过这个口音、这个人的习惯、这个厂房的光照。每一次交互都能**测得**它，却无法在本回合**消除**它——这就是**结构性无知**。它解释了 R69 的尴尬：「第 100 次仍犯第 1 次的错」。微调是唯一能压低它的操作：把「检测到失准」变成「修复失准」。所以 R70 不是给 R69 再加一层，而是给它补上**缺失的时标**：快环（毫秒）消偶发歧义，慢环（回合间）减结构无知。

**灵感 2（语音交互 → 人不是干净的证据源，而是可读、可伪造、可教的信号源）**
直觉：把回答当文本，等于把一个人压缩成一个标签。语音至少多给三样东西：(a) **副语言**——犹豫、急促、自信、讽刺，直接告诉你「她对这个答案有多确定」；(b) **双工性**——可以打断、可以「嗯？」、可以复述确认，这些是低成本的**纠错码**；(c) **可教性**——同一句话既能消歧，又能当训练样本。但语音也最脏：ASR 会错、TTS 会伪、情绪会演。所以语音不是免费的证据，而是**必须被建模、被认证、被交叉验证**的观测。

**灵感 3（合成 → 问是取证，记是消化）**
直觉：R69 把每次交互当一次性取证，用完即弃。R70 把它当**持续教学**：快环从每次交互里同时抽两样东西——即时消歧证据，和候选训练样本。候选样本不立刻学，而是进**延迟学习缓冲区**，等结果验证、等 k 源一致、等审计通过，才在回合间被慢环「消化」。一句话：**语音交互负责产生经验，证据门控负责决定哪些经验配变成记忆，微调负责把记忆写成权重。** 没有门控的微调，就是给系统喂毒。

**灵感 4（微调是双刃剑 → 学习必须有安全证明）**
直觉：微调会带来四类新事故：灾难性遗忘（学会新口音、忘了旧安全）、安全漂移（适配器顺手把「靠近人类」学成「更激进」）、模型坍塌（用自己的伪标签训练，越训越自信越错）、证书陈旧（改了权重，R69 的流似然基线与 FMA 阈值全变，旧证书却还挂着「已验证」）。所以慢环必须附四道锁：**安全子空间冻结**（安全梯度掩蔽）、**函数空间信任域**（更新后策略函数逐点不突变）、**安全回归门**（晋升前安全套件不回退）、**证书版本化**（换权重即作废旧证书、重算基线）。

**灵感 5（包含关系 → R70 是 R69 的严格泛化）**
直觉：关掉慢环（DLB 不训练）、把 g_voice 退化为 R69 的 g_ask 文本、关闭副语言通道，DUPLEX 就逐指令退回 FLUID-RAS。开慢环时，快环路径与 R69 完全一致，安全侧不做任何让步；慢环只改变「未来的 θ」，且每次改变都过安全回归门与版本化。这保证新层不会成为又一个需要独立信任的黑箱——它要么等价于旧层，要么被旧层的安全约束夹住。

## 1. 形式化定义（增量：定义 310–329）

**定义 310（DUPLEX-RAS 总览）** DUPLEX-RAS = (FLUID†, VOC, DEP, PEC, DLB, EGF, SRG, SFS, SCV, DTL)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i；快环只写 DLB，从不写权重）；
(ii) **慢环独占学习**：一切权重更新只在回合间（T_slow ≫ T_fast）发生，且不阻塞快环；
(iii) **证据门控**：样本进入可训练集需同时满足 k-正交证据一致、审计通过、无投毒命中、证书哈希匹配；
(iv) **安全冻结与版本化**：安全关键子空间梯度恒零、晋升前过安全回归门、权重一变旧证书即失效。

**定义 311（双时标环路与三层不确定性）** 快环（毫秒）执行 R69 FLUID；慢环（分钟~小时，回合间）执行 EGF。不确定性三分：U = U_ale + U_epi + U_struct，其中 U_struct（结构性无知）只受 θ 影响、只有慢环能减；R69 只处理前两项。时标分离条件：T_fast ≤ 3ms，T_slow ≥ 10³·T_fast。

**定义 312（语音交互空间与命令/证据二分）** g_voice = (c, p, τ, mode)。c ∈ ℝ^{d_q} 内容软提示；p ∈ ℝ^{d_p} 韵律特征（F0 轮廓斜率/方差、能量包络、语速、停顿与犹豫标记、backchannel 类型）；τ 为时序（barge-in、重叠、响应延迟）。mode ∈ {evid, cmd}：**evid** 为回答/澄清（弱权威，必须可被交叉验证）；**cmd** 为控制指令（强权威，需说话人认证 + liveness + 安全包络）。增广动作 ξ = (a, g_gaze, g_probe, g_voice)。

**定义 313（语音信道模型）** ASR 输出为分布 p(c | audio) 而非字符串；交互证据按对 ASR 不确定性的积分给出：p(y | g_voice, o) = ∫ p(y | c, o) p(c | audio) dc。定义 H_asr = H(c | audio)。**复述确认（read-back）是一个可降低 H_asr 的信息动作**，其 VoI 仍由定义 298 计算，故语音交互天然继承 R69 的预算与安全约束。

**定义 314（副语言证据通道 PEC）** u_s = h_ψ(audio_p) ∈ [0,1] 为说话人自身不确定度预测；φ = agree(u_s, c) 为韵律-内容一致性。PEC 只在与 liveness 通过（定义 320）、且说话人已注册时，作为**关于证据来源可靠性**的正交通道并入 ℰ（与 r_geo、r_sync… 并列），**不替代内容证据，也永不单独定案**。检测到伪造时 PEC 置信度置 0。

**定义 315（双工交互协议 DEP）** 允许打断、backchannel、复述确认、修复（repair）。修复动作 r 把候选解释推回给用户核对，成本 c_repair，纠错增益 G_repair = P(错→对) − P(对→错)。DEP 把 R69 的「问一次」变成「问一次 + 可纠错的一次」。

**定义 316（语音投毒与伪造威胁 ℰ_voice）** TTS/deepfake、重放（replay）、语气+内容共谋、ASR 对抗扰动、以提问为名的社交工程。并入 AIC：ℰ_DUPLEX = ℰ_FLUID × ℰ_voice × ℰ_learn（学习投毒 / 后门 / 模型坍塌）。

**定义 317（延迟学习缓冲区 DLB）** 记录 e = (o, g_voice, answer, prosody, provenance, cert_hash, outcome?, t)，三态 pending / verified / quarantined。只有 verified（k-正交一致 + 审计通过 + 无投毒 + outcome 到达，见定义 326）且 consent=True（定义 325）的样本可进入训练集。

**定义 318（证据门控微调 EGF）** 训练集 D = {e ∈ DLB : verified}；低秩适配器 Δθ = BA（rank r ≪ d）。目标 L_EGF = L_task + λ_r L_replay + λ_c L_consistency + λ_s L_safety。L_consistency 约束更新后策略在旧状态上的输出（防突变），L_safety 为安全套件损失。

**定义 319（安全关键冻结子空间 SFS）** 存在投影 P_safe，安全关键梯度被掩蔽：Δθ = −η P_safe^⊥ ∇L_EGF，即 P_safe ∇L_EGF = 0。安全子空间由安全套件激活方向张成，冻结后任何更新不改变安全行为（至一阶）。

**定义 320（语音认证与隐私 AudioGuard）** liveness（反重放 / deepfake）、说话人验证、cmd 模式强认证；语音为生物特征，DLB 存储需 consent、去标识、可遗忘（删除或 unlearning），删除事件写入谱系。

**定义 321（函数空间信任域 FTD）** 晋升条件 ‖f_{θ⊕Δθ} − f_θ‖_∞ ≤ ε_trust（在覆盖状态集上），或等价 KL(π_θ ‖ π_{θ⊕Δθ}) ≤ ε_KL；确保控制连续、无突变（承接 R68 定理 15、R69 定理 17）。

**定义 322（安全回归门 SRG）** 晋升前在安全套件 𝒮 上评估：Viol(θ⊕Δθ) ≤ Viol(θ) + ε_s，且关键安全行为集合不变；否则拒绝并回滚到 rollback_point。

**定义 323（防模型坍塌与谱系 MCD）** 禁止以系统自生成伪标签训练；仅人类/环境验证真值可入 D；replay 真实历史；数据谱系 provenance_root 记录来源链，任何未溯源样本不得训练。

**定义 324（证书版本化 SCV）** J_DUPLEX = (J_FLUID, model_ver, adapter_hash, train_set_hash, safety_regression, ece_before, ece_after, rollback_point, provenance_root)。Valid ⇔ Valid(J_FLUID) ∧ model_ver = hash(θ_current) ∧ SRG 通过。**权重一变，旧 J_FLUID 与其 FMA 基线（a_score 分布、TAU_FMA）立即作废并重估**（见定义 327）。

**定义 325（语音隐私与遗忘）** DLB 记录含生物特征，受 consent 与保留期约束；遗忘请求触发样本删除 + 对已训练适配器的 unlearning / 回滚，遗忘事件参与证书谱系。隐私预算 ε_dp 与学习效用权衡。

**定义 326（延迟信用分配 LCG）** 交互答案的「正确性」常需结果到达才可判定；样本在 outcome 到达前保持 pending、不参与训练；到达后按结果 commit 为 verified / quarantined。**禁止把「即时看起来很合理」当作真值。**

**定义 327（快慢环漂移门 DTL-Gate）** 慢环更新后，若快环证据分布 D(Φ(o)) 或 a_score 分布相对旧 θ 的偏移超过阈值，则触发重标定：重估 FMA 基线、重签 J_FLUID、必要时回滚。防止「训练后自检器失效却仍被信任」。

**定义 328（自适应学习预算）** 慢环触发受漂移、ECE 越界、同类错误重复率、算力与交互疲劳约束；定义 learning budget B_learn，超预算则**延后学习而非降级安全**。

**定义 329（双时标总后悔）** R_total = R_fast + R_slow，其中 R_fast 为环内决策后悔，R_slow 为慢环估计误差导致的结构性后悔；目标是 min_Δθ R_slow，s.t. 安全约束（定义 319–322）与隐私约束（定义 325）。

# IP-264 VOC：语音前端（内容分布 + 韵律 + liveness）
class VoiceChannel:
    def observe(self, audio):
        c_dist = self.asr(audio)                  # 分布，不是字符串
        z_pros = self.prosody(audio)              # F0/能量/语速/停顿
        live   = self.audioguard.liveness(audio)  # 反重放 / deepfake
        u_s    = self.pec(z_pros)                 # 说话人自身不确定度
        return c_dist, z_pros, live, u_s

    def integrate(self, y, c_dist, z_pros, live):
        # 对 ASR 不确定性积分；live=False 时韵律证据置信置零
        return integrate_over_asr(y, c_dist, z_pros, live)

# IP-265 DEP：双工修复（复述确认 / 打断 / backchannel）
def duplex_resolve(voice, modes, budget):
    c_dist, z, live, u_s = voice.observe(...)
    if entropy(c_dist) > TAU_ASR and budget.allow_readback():
        return read_back_confirm(c_dist)          # 复述即纠错码
    return best_transcript(c_dist)

# IP-266 PEC：韵律作为「来源可靠性」正交证据
def paralinguistic_evidence(u_s, content_sem, live):
    if not live: return None                      # 伪造 => 不提供证据
    return agree(u_s, content_sem)                # 说话人确定性与内容一致性

# IP-267 DEP：证据门控（k 源一致 + 审计 + 投毒 + 证书）
def evidence_gate(record, k_sources, auditor):
    agree = count_orthogonal_agree(record, k_sources)
    ok    = (agree >= 2
             and auditor.pass_(record)
             and not poison_detect(record)
             and record.cert_hash == current_cert_hash())
    record.state = 'verified' if ok else 'quarantined'
    return record.state == 'verified'

def commit_on_outcome(dlb):                       # 延迟信用分配
    for e in dlb.pending():
        if e.outcome is not None:
            e.state = 'verified' if e.outcome.correct else 'quarantined'

# IP-268 EGF：安全冻结 + replay + 信任域 的慢环微调
def evidence_gated_finetune(model, dlb, cfg):
    D = [e for e in dlb
         if e.state == 'verified' and e.consent
         and e.provenance.is_trusted()]           # 禁自生成伪标签
    if len(D) < cfg.n_min: return model
    for batch in replay_mix(D, model.replay_buffer, cfg):
        g = grad(L_EGF(model, batch), model.adapter.params())
        g = model.sfs.mask(g)                     # 安全子空间冻结
        model.adapter.step(g)
        model.adapter.clip_to_trust(model.base, cfg.eps_trust)  # FTD
    return model

# IP-269/273 晋升：安全回归门 + 函数信任域 + 证书版本化
def promote_if_safe(model, cand, cert):
    if not srg.pass_(cand, model.safety_suite):   # 拒绝
        return model, cert
    if not within_trust_region(cand, model, eps_trust):
        return model, cert
    new_cert = scv.reissue(cert, cand,
                           ece_before=cert.ece,
                           ece_after=ece(cand))
    scv.invalidate_old(cert)                      # 旧 FMA 基线作废
    return cand, new_cert

# IP-278 主闭环：快环完全继承 R69；慢环只在回合间
def DUPLEX_episode(M, audio, obs):
    c_dist, z_pros, live, u_s = M.voc.observe(audio)
    g_ev = M.dep.duplex_resolve(...)              # 双工修复后的证据动作
    k, lam, mode, U = M.fluid_round(obs, g_ev)    # R69 快环，逐指令不变
    rec = make_record(obs, g_ev, z_pros, u_s, live,
                      cert_hash=M.cert.hash)
    M.dlb.add(rec)                                # 只写缓冲区，不写权重
    return k, lam, mode, U

def DUPLEX_between_episodes(M):
    M.lcg.commit_on_outcome(M.dlb)                # 延迟验证
    for e in M.dlb.pending():
        M.evidence_gate(e)
    if M.learn_budget.allows() and M.dtl_gate.should_learn(M):
        cand = M.egf.finetune(M.model, M.dlb, M.cfg)
        M.model, M.cert = M.promote_if_safe(M.model, cand, M.cert)
        M.dtl_gate.recalibrate_fma(M.model)       # 重估 a_score 基线

## 3. 推导

**引理 19（双时标误差分解）** 总贝叶斯后悔可分解为 R_total ≲ R_fast(U_ale + U_epi) + R_struct(U_struct)，且快环交互对 U_struct 的一阶影响为 0（定义 311）。系：**快环再强也压不下结构性后悔**，这解释了「第 100 次仍犯第 1 次的错」；反之慢环若无快环提供的、经过验证的监督信号，则 U_struct 估计方差 ∝ 1/|D|，收敛慢。两个时标互为条件，缺一不可。

**引理 20（副语言正交证据的增益与伪造上界）** 设 u_s 与回答正确性相关 ρ_s，且与内容证据在给定真实模态下条件独立；则并入 PEC 后错误率满足 e′ ≤ e·√(1 − ρ_s²)（高斯近似）。若攻击者能伪造韵律且 liveness 失效，则 ρ_s 反号、e′ ≥ e；故 **PEC 必须门控于 liveness，且永不单独定案**。

**引理 21（证据门控对训练污染的上界）** 若单样本被投毒概率 δ_p、k 个正交源欺骗相关 ρ<1、审计漏检率 α，则污染训练集概率 ≤ δ_p·ρ^{k−1} + α；再由影响函数界，单个污染样本对 Δθ 的期望偏移 ≤ G·‖∇ℓ‖/|D|。系：**k 与 |D| 同时增大时污染影响二次衰减**——门控不是礼貌，是可证明的防御。

**引理 22（安全冻结子空间的一阶安全不变性）** 若 P_safe 张成安全套件激活方向，且更新满足 P_safe ∇L_EGF = 0，则在安全约束可行域内安全行为的一阶变化为 0；再经 SRG 与 FTD 约束高阶项 ⇒ 晋升后安全违规不增（至多 ε_s）。

**定理 18（DUPLEX 严格包含 R69/FLUID）** 关闭慢环（DLB 不训练）、令 g_voice→g_ask 文本、关闭 PEC，则 DUPLEX 与 FLUID 快环逐指令相同；开慢环时快环路径不变，安全侧因 SFS+SRG+FTD 不弱于 FLUID。故 R69 是 DUPLEX 在「不学习」边界上的退化，新层不引入需要独立信任的黑箱。

**定理 19（EGF 收敛、无坍塌、守信任域）** 在 replay 覆盖历史真实数据、禁用自生成标签、步长满足 Robbins–Monro 且 KL 约束有界的条件下，EGF 收敛到受限最优；模型坍塌（输出熵单调下降）被 provenance 禁令与 replay 阻断；FTD 保证 ‖f_{θ⊕Δθ} − f_θ‖_∞ ≤ ε_trust，控制连续、无突变。

**定理 20（双工修复的纠错增益）** 若 ASR 错误可被复述发现的概率为 p_d、修复纠正概率为 p_f，则 n 轮双工交互后的残余错误率 ≤ (1 − p_d·p_f)^n·e₀ + ε_σ；存在成本阈值使复述仅在高 H_asr 时启用即为最优。系：**「问」是采样，「复述」才是纠错**——R69 缺的正是纠错环。

**定理 21（证书版本化与自检一致性）** 若每次权重更新后强制重估 FMA 基线并重签 J_DUPLEX、且旧证书立即失效，则「证书有效 ⇒ 当前权重可被该证书的安全与校准断言覆盖」；否则存在更新使旧 a_score 分布漂移而旧阈值仍被信任，导致 FMA 假阴性（缓变故障漏检）。

## 6. 本轮最大风险

**一句话**：DUPLEX 把 R69 的「问错」风险从**单次决策**抬到了**权重层面**——只要证据门有一次泄漏（投毒样本被 k 源共谋骗过、或审计漏检），微调就会把一次可回滚的误听焊成永久偏见；而微调一旦改变策略密度，R69 赖以自检的 FMA 基线与证书全部漂移，若版本化失效，系统会用**旧的自检器**给**新的错误**盖章——**学错，比问错更难撤销**。

**次级风险与缓解**：
1. **灾难性遗忘**（学会新口音、忘了旧安全）→ replay + FTD 信任域 + E307；
2. **安全漂移**（适配器顺手学激进）→ SFS 安全冻结 + SRG 安全回归门 + E306；
3. **语音伪造/重放**（TTS 冒充用户下达 cmd）→ AudioGuard liveness + PEC 永不单独定案 + cmd/evid 二分 + E312；
4. **模型坍塌**（用自身伪标签越训越自信越错）→ provenance 禁令 + 真实 replay + E308；
5. **隐私与遗忘**（语音是生物特征）→ consent/去标识/可遗忘 + 定义 325 + E314；
6. **证书陈旧**（自检器随权重漂移而失效却仍被信任）→ SCV 版本化 + DTL-Gate 重估 + 定理 21 + E315。

# IP-264/266 VOC+PEC：语音取证（内容分布 + 韵律正交证据）
class VoiceChannel:
    def observe(self, audio):
        return (self.asr(audio),        # 分布 p(c|audio)
                self.prosody(audio),    # F0/能量/语速/停顿
                self.audioguard.liveness(audio),
                self.pec(self.prosody(audio)))  # u_s

def paralinguistic_evidence(u_s, content_sem, live):
    return agree(u_s, content_sem) if live else None   # 伪造 => 无证据

# IP-265 DEP：双工修复（复述即纠错码）
def duplex_resolve(c_dist, budget):
    if entropy(c_dist) > TAU_ASR and budget.allow_readback():
        return read_back_confirm(c_dist)
    return best_transcript(c_dist)

# IP-267 证据门控 + IP-275 延迟信用分配
def evidence_gate(rec, k_sources, auditor):
    ok = (count_orthogonal_agree(rec, k_sources) >= 2
          and auditor.pass_(rec) and not poison_detect(rec)
          and rec.cert_hash == current_cert_hash())
    rec.state = 'verified' if ok else 'quarantined'

def commit_on_outcome(dlb):
    for e in dlb.pending():
        if e.outcome is not None:
            e.state = 'verified' if e.outcome.correct else 'quarantined'

# IP-268/270/271 EGF：安全冻结 + replay + 信任域
def evidence_gated_finetune(model, dlb, cfg):
    D = [e for e in dlb if e.state=='verified' and e.consent
         and e.provenance.is_trusted()]            # IP-272 禁自生成
    if len(D) < cfg.n_min: return model
    for batch in replay_mix(D, model.replay_buffer, cfg):
        g = model.sfs.mask(grad(L_EGF(model, batch)))  # IP-270
        model.adapter.step(g)
        model.adapter.clip_to_trust(model.base, cfg.eps_trust)  # IP-271
    return model

# IP-269/273 晋升：SRG + 证书版本化
def promote_if_safe(model, cand, cert):
    if not srg.pass_(cand, model.safety_suite): return model, cert
    if not within_trust_region(cand, model, eps_trust): return model, cert
    new_cert = scv.reissue(cert, cand, ece_before=cert.ece,
                           ece_after=ece(cand))
    scv.invalidate_old(cert)                       # 旧 FMA 基线作废
    return cand, new_cert

def DUPLEX_episode(M, audio, obs):

    return k, lam, mode, U

## 4. 推导

**引理 19（双时标误差分解）** `R_total ≲ R_fast(U_ale+U_epi) + R_struct(U_struct)`，快环交互对 `U_struct` 一阶影响为 0。系：快环压不下结构性后悔（解释「第 100 次仍犯第 1 次的错」）；慢环缺快环的 verified 监督则方差 ∝ 1/|D|。两时标互为条件。

**引理 20（副语言增益与伪造上界）** 相关性 ρ_s、条件独立时 `e′ ≤ e·√(1−ρ_s²)`；liveness 失效且韵律可伪时 ρ_s 反号、`e′ ≥ e`。故 PEC 必须 liveness 门控、永不单独定案。

**引理 21（证据门控污染上界）** 投毒入训概率 `≤ δ_p·ρ^{k−1}+α`；单污染样本致 Δθ 期望偏移 `≤ G‖∇ℓ‖/|D|`。系：k 与 |D| 同增时污染影响二次衰减。

**引理 22（安全冻结一阶不变性）** `P_safe∇L_EGF=0` ⇒ 安全行为一阶变化为 0；SRG+FTD 约束高阶项 ⇒ 晋升后违规不增（≤ ε_s）。

**定理 18（DUPLEX 严格包含 R69/FLUID）** 关慢环、g_voice→文本、关 PEC ⇒ 与 FLUID 快环逐指令相同；开慢环时快环不变、安全侧因 SFS+SRG+FTD 不弱于 FLUID。R69 为「不学习」边界退化。

**定理 19（EGF 收敛 / 无坍塌 / 守信任域）** replay 覆盖真实历史、禁自生成标签、步长 Robbins–Monro、KL 有界 ⇒ 收敛到受限最优；熵坍塌被 provenance+replay 阻断；FTD 保证函数逐点 `≤ ε_trust`，控制连续。

**定理 20（双工修复纠错增益）** 残余错误率 `≤ (1−p_d·p_f)^n·e₀ + ε_σ`；复述仅在高 `H_asr` 时启用即最优。系：「问」是采样，「复述」才是纠错。

**定理 21（证书版本化与自检一致性）** 每次更新后强制重估 FMA 基线并重签、旧证书立即失效 ⇒「证书有效 ⇒ 当前权重被该证书覆盖」；否则旧 a_score 分布漂移而旧阈值仍被信 ⇒ FMA 假阴性（缓变故障漏检）。

## 7. 本轮最大风险

**一句话**：DUPLEX 把 R69 的「问错」风险从**单次决策**抬到了**权重层面**——只要证据门有一次泄漏（投毒样本被 k 源共谋骗过、或审计漏检），微调就会把一次可回滚的误听焊成永久偏见；而微调一旦改变策略密度，R69 赖以自检的 FMA 基线与证书全部漂移，若版本化失效，系统会用**旧的自检器**给**新的错误**盖章——**学错，比问错更难撤销**。

**次级风险与缓解**：灾难性遗忘（replay+FTD）；安全漂移（SFS+SRG）；语音伪造/重放（AudioGuard liveness + PEC 永不单独定案 + evid/cmd 二分）；模型坍塌（provenance 禁令 + 真实 replay）；隐私与遗忘（consent/去标识/可遗忘 + 定义 325）；证书陈旧（SCV + DTL-Gate + 定理 21）。
