# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「强化学习训练」×「视觉定位」）

> 第 54 轮已把技能组合提升为「动作占用 α_S + 鲁棒性谱 ρ」的双证书体系，并建立云边闭环。但该体系隐含两个静态假设：**证书在训练后一次性标定**、**视觉定位被视为理想输入**。本轮把这两个假设打开：强化学习训练是不断移动策略的运动靶，会侵蚀既有证书（H22）；视觉定位是隐藏在动作执行之下、尚未进入 ρ 的鲁棒性维度（H23）。核心问题：一个在 π_k 上 sound 的证书，凭什么在 π_{k+1} 与位姿误差下仍然 sound？

## 0. 直觉与动机

### 灵感 1（训练是证书的「运动靶」：从 train-then-certify 到 certify-as-you-train）

直觉：第 53–54 轮的证书默认是**训练完成后的静态快照**。可现实中强化学习训练每做一次策略更新，就在参数空间里移动一步；`ρ`、`α_S`、`A_cert` 都是策略的函数，策略一动，证书就旧了。证书不是「事实」，而是「在策略可行域内成立的带租期的断言」。

所以正确姿势不是「先训练、后发证」，而是**把证书反写进训练目标**：RL 只在一个被证书约束的可信域内改进，走出可信域就冻结或触发重新认证。这与 PPO/TRPO 的 KL 信赖域在形式上同源，但约束对象从「策略分布」升级为「证书下界」。训练优化的是回报，证书负责划出「可部署但尚未被验证」的边界。

### 灵感 2（证书漂移有「时钟」：漂移率、半衰期与租约）

直觉：证书会「腐坏」，而且腐坏速度可估。设策略从 θ_k 走到 θ，若证书泛函 `ρ(π_θ)` 关于策略是 Lipschitz 的，则参数位移或 KL 距离直接给出证书衰减上界。于是每张证书都带一个**新鲜度 F** 与**半衰期 h**：`F = exp(-λ·Δ)`。漂移超过阈值或新鲜度跌破底线，就必须重新仿真认证。证书从「永久有效」变成「有租约的凭证」，云边协同里的 `Explain_loop` 顺理成章承担续租失败的回传。

### 灵感 3（视觉定位是被漏掉的鲁棒性维度）

直觉：第 54 轮的 ρ 覆盖了扰动、噪声、域偏移等维度，却把「我知道自己在哪」当成免费前提。真实视觉定位会给出带协方差的位姿估计：光照、纹理缺失、重复结构（perceptual aliasing）会让同一个观测对应多个位姿。策略在 sim 里以完美位姿训练，一到真实场景位姿抖动就系统性失效——这不是控制问题，而是**感知锚点缺失**。

因此应在 ρ 中显式增加**定位维 `ρ_loc`**，并定义场景/动作的**可定位性 ℓ**：位姿后验熵越低，ℓ 越高。技能的动作剖面也应从 `α_S(a)` 扩展为**位姿条件剖面** `α_S(a | p̂, Σ_p)`：同一个动作在低可定位性区域可能根本不可安全执行。

### 灵感 4（定位本身是一个动作：主动视觉定位）

直觉：如果位姿不确定，机器人可以「看一眼前面」或「稍微移动一下」来消歧。**感知不是被动输入，而是动作空间里的一类动作 u**。这自然接入强化学习：给信息增益 `I(pose; obs | u)` 一个内在奖励，让策略学会在进入高风险技能前主动把位姿熵降下来。

于是动作空间从 `A_c × A_e` 再扩展出**感知动作子空间 A_s**，并引入「先感知后执行」门控：当位姿熵高于阈值时，拒绝执行需要高 `ρ_loc` 的技能，先执行主动定位技能。主动定位本身也应获得自己的信息增益证书。

### 灵感 5（RL 也是证书的「红队」：训练-证伪对偶）

直觉：训练在「把策略推过证书边界」的方向上做梯度上升，而验证在「把证书推过失败边界」的方向上做对抗搜索——两者是同一个梯度的两个符号。可以训练一个**对抗定位策略**，在定位误差预算内主动寻找让 `ρ_loc` 最小的轨迹，产出的反例直接回填 `Explain` 通道，更新 ρ_loc 并触发重剖分。

这把 RL 从「只负责变强」变成**既变强又证伪**：一个负责提升回报，一个负责压低下界。二者共享同一套环境与证书，形成「训练-证伪守恒」：证书的提升必须至少覆盖对抗方新发现的缺口，否则视为假提升。

### 灵感 6（金字塔再叠训练层 𝕋）

在第 53 轮鲁棒性层 𝕃、第 54 轮动作协同层 𝔸 之上叠加**训练层 𝕋**：

- `𝕋_0` 参数空间与更新算子；
- `𝕋_1` 证书可行域（ρ、A_cert、ρ_loc 的交集）；
- `𝕋_2` 定位不确定性（位姿后验、歧义集）；
- `𝕋_3` 课程与对抗（训练分布、红队分布）。

跨层证书必须同时携带 `ρ`、`A_cert`、`ρ_loc`、`drift/lease` 与 `adversary_evidence`，形成**训练-定位-动作-鲁棒性四元证书**。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（证书约束 MDP，CC-MDP）**
在 MDP `M=(S,A,P,r,γ)` 上附加证书约束集合 `C`，可行策略集
```
Π_cert = { π : J_C(π) ≤ b  ∧  ρ(π) ≥ ρ_min  ∧  ρ_loc(π) ≥ ρ_loc,min  ∧  δ_a(π) ≤ Θ_a }
```
训练目标为 `max_{π∈Π_cert} J_r(π)`。即：**回报最大化只在证书可行域内进行**，而非先优化后过滤。若 `Π_cert = ∅`，返回 `('infeasible', Explain)` 触发重剖分，而不是降级硬跑。

**定义 122（证书漂移与新鲜度租约）**
设证书泛函 `Φ ∈ {ρ, α_S, ρ_loc}` 关于策略分布满足 `|Φ(π)-Φ(π')| ≤ L_Φ·TV(π,π')`。由 Pinsker，`TV ≤ sqrt(KL(π‖π')/2)`。对训练第 k 步到第 t 步：
```
D_Φ(k,t) = L_Φ · sqrt(KL(π_{θ_k}‖π_{θ_t})/2)
fresh(Φ, t) = exp(-λ_Φ · (t - t_k))
```
证书在 t 时刻仍可用当且仅当 `D_Φ(k,t) ≤ D_max` 且 `fresh ≥ F_min`；否则进入 `re-certify`。`λ_Φ` 为经验漂移率，`h_Φ = ln2/λ_Φ` 为半衰期。租约到期由 `Explain_loop` 回传并触发重认证。

**定义 123（定位条件鲁棒性谱与可定位性）**
设视觉定位输出位姿 `p̂` 与协方差 `Σ_p`，真实位姿 `p = p̂ + δ`。定位歧义集 `B_ε(p̂) = {p : (p-p̂)ᵀΣ_p^{-1}(p-p̂) ≤ ε}`。场景 x 的可定位性
```
ℓ(x) = -H(p | o) = -E[ -log q(p|o) ]
```
技能的定位条件鲁棒性 `ρ_loc(S) = inf_{p∈B_ε(p̂)} ρ(S; p)`。当 `ℓ(x) < ℓ_min` 时，技能必须携带定位证据或先执行主动定位。

**定义 124（定位感知动作剖面）**
动作剖面从 `α_S(a)` 扩展为
```
α_S(a | p̂, Σ_p) = E_{p~N(p̂,Σ_p)}[ α_S(a; p) ] · 1[ m_S(a,p) ≥ m_min ]
```
其中 **位姿裕度** `m_S(a,p) = min_{δ∈B_ε} margin(S,a;p+δ)`。动作 a 在定位感知下「可用」当且仅当 `α_S(a|p̂,Σ_p) ≥ θ_cov` 且位姿裕度达标。这样，定位不确定性直接收缩了动作可行域，而不是执行后才发现偏差。

**定义 125（主动定位技能与信息增益证书）**
感知动作 `u ∈ A_s`（转头、注视、短距移动、重观测）。其信息增益
```
IG(u | b) = I(p; o' | b, u) = H(p|b) - E_{o'}[H(p|b,u,o')]
```
主动定位技能 `S_loc` 的动作价值含内在奖励 `r_info = β·IG(u|b)`。信息增益证书 `G_loc = (IG_accum, H_before, H_after, evidence)`，部署门控要求执行高风险技能前 `H(p|b) ≤ H_max`。

**定义 126（训练证书 T_cert）**
```
T_cert = (π_hash, ρ, A_cert, ρ_loc, drift_record, lease, adversary_evidence, provenance)
```
其中 `provenance` 记录训练步、数据分布、仿真版本与红队反例。部署判定：
```
deployable  ⇔  dom(T)=in ∧ δ_a ≤ Θ_a ∧ fresh ≥ F_min
             ∧ ρ_loc ≥ ρ_loc,min ∧ adversary_coverage ≥ 1-β_loc
```
证书不再是「某次测量」，而是**带来源、带租期、带反例集的活文档**。

## 2. 关键算法 伪代码

### IP-121 CPT（Certificate-Preserving Training）

```python
def certify_as_you_train(policy, cert, env, budget, kl_max=0.02):
    lag = Lagrangian(cert.constraints)
    for step in range(budget):
        batch = rollout(policy, env, cert.covered_distribution)
        adv = gae(batch, policy.value)
        # 回报梯度 + 证书约束的拉格朗日修正
        loss = -surrogate(policy, batch, adv) + lag.penalty(policy, cert)
        grad = autograd(loss)
        new_policy = policy.step(grad, trust_region=kl_max)
        kl = empirical_kl(policy, new_policy, batch)
        drift = {f: L[f]*sqrt(kl/2) for f in cert.functionals}
        if any(drift[f] > D_max[f] for f in drift) or not cert.lease_ok(step):
            cand = recertify(new_policy, cert.spec)   # 仿真重认证
            if not cand.sound:
                policy = rollback(policy, cert.last_good_ckpt)
                cert = explain_and_reprofile(cand.explain)
                continue
            cert = cand
        policy = new_policy
        lag.update(cert.violation(policy))
    return policy, cert
```

### IP-122 CDM（Certificate Drift Monitor）

```python
def drift_monitor(cert, policy, step, L, D_max, F_min, lam):
    # 用 KL/参数位移批量估计漂移，而非仅靠点采样
    kl = probe_kl(cert.reference_policy, policy, cert.probe_states)
    drift = {f: L[f] * sqrt(kl / 2.0) for f in cert.functionals}
    fresh = {f: exp(-lam[f] * (step - cert.issued_at)) for f in cert.functionals}
    status = {}
    for f in cert.functionals:
        if drift[f] > D_max[f]:
            status[f] = ('re-certify', 'drift', drift[f])
        elif fresh[f] < F_min:
            status[f] = ('re-certify', 'lease_expired', fresh[f])
        else:
            status[f] = ('ok', drift[f], fresh[f])
    return status
```

### IP-123 LAP（Localization-Aware action Profile）

```python
def localization_aware_profile(skill, a, pose_hat, Sigma, eps, m_min, theta_cov):
    # 采样位姿后验，传播到动作剖面与位姿裕度
    samples = sample_pose(pose_hat, Sigma, n=256)
    vals, margins = [], []
    for p in samples:
        vals.append(skill.alpha(a, p))
        margins.append(skill.margin(a, p, eps))
    alpha_loc = mean(vals) * (1.0 if min(margins) >= m_min else 0.0)
    localizable = alpha_loc >= theta_cov
    return alpha_loc, localizable, percentile(margins, 5)
```

### IP-124 ALR（Active Localization RL）

```python
def active_localization_step(policy, belief, skill, H_max, beta):
    if entropy(belief.pose) <= H_max:
        return ('act', skill)
    u = policy.sample_sensing_action(belief)          # A_s 中的感知动作
    o = env.observe(u)
    ig = mutual_information(belief.pose, o, u)
    belief = bayes_update(belief, u, o)
    reward = beta * ig - cost_sensing(u)
    cert = InfoGainCert(IG_accum=ig, H_before=entropy_prev,
                        H_after=entropy(belief.pose), evidence=o)
    # 感知动作也受动作空间/带宽约束
    if not cert.meets_floor() and entropy(belief.pose) > H_max:
        return ('reject', Explain('localization_not_reached', belief))
    return ('continue', belief, reward, cert)
```

### IP-125 CFT（Certificate Falsification Training）

```python
def cert_falsification_train(cert, loc_model, eps, budget):
    adv = AdversaryPolicy(action_space=LocalizationPerturbation(eps))
    failures = []
    for step in range(budget):
        delta = adv.act(context=cert.scene_distribution)   # 位姿扰动
        traj = simulate(cert.reference_policy, loc_model, delta)
        if violates(traj, cert.lower_bound):
            failures.append(CounterExample(delta, traj, explain(traj)))
            adv.reward = severity(traj)                     # 越严重越奖励
        adv.update()
    rho_loc_robust = min_over_failures(cert.rho_loc, failures)
    return rho_loc_robust, failures, adversary_coverage(failures, eps)
```

### IP-126 TCC（Training Certificate Compiler）

```python
def compile_training_cert(policy, cert, drift_status, loc_report, adv_report):
    if any(s[0] != 'ok' for s in drift_status.values()):
        return ('reject', 'stale_certificate', drift_status)
    if loc_report.rho_loc < rho_loc_min:
        return ('reject', 'localization_brittle', loc_report)
    if adv_report.coverage < 1 - beta_loc:
        return ('reject', 'insufficient_red_team', adv_report)
    return ('ok', TrainingCert(
        policy_hash=hash(policy),
        rho=cert.rho, A_cert=cert.A_cert, rho_loc=loc_report.rho_loc,
        drift=drift_status, lease=cert.lease,
        adversary_evidence=adv_report.failures,
        provenance=cert.provenance))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| CPT | O(B·(|S|+|A|) + R·|π|) | O(|π|+|cert|) | 证书可行域非空、回滚原子性 |
| CDM | O(|probe|·|π| + |Φ|) | O(|Φ|) | Lipschitz 常数 L_Φ 可信 |
| LAP | O(|A|·n_pose·|S|) | O(n_pose) | 位姿后验校准、裕度保守 |
| ALR | O(|A_s|·|b| + |A|) | O(|b|) | 互信息估计无偏、门控单调 |
| CFT | O(budget·(|S|+|A|)) | O(|failures|) | 对抗覆盖 ε-网、反例可复现 |
| TCC | O(|cert|·|Φ|) | O(|cert|+|failures|) | 租约/反例/定位证据齐全 |

**正确性定理（Training-Preserving Deployment Soundness）**
在第 53–54 轮 (A22)–(A28) 基础上追加：**(A29)** 证书泛函对策略 TV 距离 Lipschitz，常数 `L_Φ` 由留出集校准；**(A30)** 视觉定位误差满足 `P(‖δp‖ ≤ ε_loc) ≥ 1-ζ_loc`，且协方差经温度校准；**(A31)** 重认证延迟 ≤ τ_rec，回滚幂等；**(A32)** 对抗定位策略在 ε_loc-网上的失败模式覆盖率 ≥ `1-β_loc`。则：
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - P(drift > D_max) - ζ_loc
            - β_E - β_loc - P(δ_a > Θ_a)
```
关键：**证书只在租约内被信任**，**定位误差被显式定价**，**对抗反例驱动下界更新**，三者缺一则右侧界失去意义。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 证书漂移 Lipschitz 常数低估 | 高 | 留出集校准 + 悲观上界 + 漂移超限即冻结 |
| 定位误差重尾/分布外 | 高 | 对抗重采样 + 多传感器冗余 + 可定位性门控 |
| 主动定位奖励被「刷分」 | 中 | 信息增益校准 + 反事实验证 + 传感器代价约束 |
| 红队过拟合固定场景 | 中 | 场景课程 + 程序化生成 + 覆盖证书 |
| 训练-证伪目标相互拖拽 | 中 | 双时间尺度优化 + 证书单调性检查 |

## 6. 本轮最大风险

**一句话**：把证书写进训练约束、把定位写进鲁棒性谱，理论上让「训练中不越界、部署时知所在」，但整条链的 soundness 压在**漂移 Lipschitz 常数、定位误差模型与对抗覆盖率这三个估计量**上；一旦真实场景的位姿误差重尾分布外、或策略更新沿证书泛函的非光滑方向跳跃，监控器会给出「仍然新鲜」的假安全，训练反而更高效地走出证书边界——因此必须以**悲观漂移上界 + 可定位性门控 + 红队反例闸门**三重护栏，并保留「证书失效即冻结部署」的硬回滚，绝不把训练曲线的平滑当作证书仍然成立的证据。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（CPT×CDM×LAP×ALR×CFT×TCC）

> 承接第 54 轮产物 v31。本轮在「动作-鲁棒性双证书」之上，补上此前被静态假设掩盖的两个维度：
> - **CPT（Certificate-Preserving Training）**：证书约束下的可信域强化学习，train-then-certify → certify-as-you-train；
> - **CDM（Certificate Drift Monitor）**：漂移率、半衰期与证书租约，量化「证书多久会过期」；
> - **LAP（Localization-Aware Profile）**：把视觉定位误差传播进动作剖面与位姿裕度；
> - **ALR（Active Localization RL）**：把「看/移动以消歧」作为感知动作，主动降低位姿熵；
> - **CFT（Certificate Falsification Training）**：训练对抗定位策略，主动证伪证书下界；
> - **TCC（Training Certificate Compiler）**：编译带租期、带定位证据、带红队反例的训练证书。
>

## 2. 关键算法 伪代码

### IP-121 CPT

```python
def certify_as_you_train(policy, cert, env, budget, kl_max=0.02):
    lag = Lagrangian(cert.constraints)
    for step in range(budget):
        batch = rollout(policy, env, cert.covered_distribution)
        adv = gae(batch, policy.value)
        loss = -surrogate(policy, batch, adv) + lag.penalty(policy, cert)
        new_policy = policy.step(autograd(loss), trust_region=kl_max)
        kl = empirical_kl(policy, new_policy, batch)
        drift = {f: cert.L[f] * sqrt(kl / 2.0) for f in cert.functionals}
        if any(drift[f] > cert.D_max[f] for f in drift) or not cert.lease_ok(step):
            cand = recertify(new_policy, cert.spec)
            if not cand.sound:
                policy = rollback(policy, cert.last_good_ckpt)
                cert = explain_and_reprofile(cand.explain)
                continue
            cert = cand
        policy = new_policy
        lag.update(cert.violation(policy))
    return policy, cert
```

### IP-122 CDM

```python
def drift_monitor(cert, policy, step, probe_states):
    kl = probe_kl(cert.reference_policy, policy, probe_states)
    status = {}
    for f in cert.functionals:
        drift = cert.L[f] * sqrt(kl / 2.0)
        fresh = exp(-cert.lam[f] * (step - cert.issued_at))
        if drift > cert.D_max[f]:
            status[f] = ('re-certify', 'drift', drift)
        elif fresh < cert.F_min:
            status[f] = ('re-certify', 'lease_expired', fresh)
        else:
            status[f] = ('ok', drift, fresh)
    return status
```

### IP-123 LAP

```python
def localization_aware_profile(skill, a, pose_hat, Sigma, eps, m_min, theta_cov):
    samples = sample_pose(pose_hat, Sigma, n=256)
    vals = [skill.alpha(a, p) for p in samples]
    margins = [skill.margin(a, p, eps) for p in samples]
    alpha_loc = mean(vals) * (1.0 if min(margins) >= m_min else 0.0)
    return alpha_loc, alpha_loc >= theta_cov, percentile(margins, 5)

def localizability(belief):
    # 位姿后验熵，越低越可定位
    return -entropy(belief.pose)
```

### IP-124 ALR

```python
def active_localization_step(policy, belief, skill, H_max, beta):
    if entropy(belief.pose) <= H_max:
        return ('act', skill)
    u = policy.sample_sensing_action(belief)          # u ∈ A_s
    o = env.observe(u)
    ig = mutual_information(belief.pose, o, u)
    H_before = entropy(belief.pose)
    belief = bayes_update(belief, u, o)
    reward = beta * ig - cost_sensing(u)
    cert = InfoGainCert(ig, H_before, entropy(belief.pose), o)
    if not cert.meets_floor() and entropy(belief.pose) > H_max:
        return ('reject', Explain('localization_not_reached', belief))
    return ('continue', belief, reward, cert)
```

### IP-125 CFT

```python
def cert_falsification_train(cert, loc_model, eps, budget):
    adv = AdversaryPolicy(action_space=LocalizationPerturbation(eps))
    failures = []
    for _ in range(budget):
        delta = adv.act(context=cert.scene_distribution)
        traj = simulate(cert.reference_policy, loc_model, delta)
        if violates(traj, cert.lower_bound):
            failures.append(CounterExample(delta, traj, explain(traj)))
            adv.reward = severity(traj)
        adv.update()
    return (min_over_failures(cert.rho_loc, failures),
            failures, adversary_coverage(failures, eps))
```

### IP-126 TCC

```python
def compile_training_cert(policy, cert, drift_status, loc_report, adv_report):
    if any(s[0] != 'ok' for s in drift_status.values()):
        return ('reject', 'stale_certificate', drift_status)
    if loc_report.rho_loc < cert.rho_loc_min:
        return ('reject', 'localization_brittle', loc_report)
    if adv_report.coverage < 1 - cert.beta_loc:
        return ('reject', 'insufficient_red_team', adv_report)
    return ('ok', TrainingCert(
        policy_hash=hash(policy),
        rho=cert.rho, A_cert=cert.A_cert, rho_loc=loc_report.rho_loc,
        drift=drift_status, lease=cert.lease,
        adversary_evidence=adv_report.failures,
        provenance=cert.provenance))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CPT | O(B·(|S|+|A|) + R·|π|) | O(|π|+|cert|) | `Π_cert` 非空、回滚原子 |
| CDM | O(|probe|·|π| + |Φ|) | O(|Φ|) | `L_Φ` 由留出集校准且取悲观上界 |
| LAP | O(|A|·n_pose·|S|) | O(n_pose) | 后验校准、裕度取 5% 分位保守值 |
| ALR | O(|A_s|·|b| + |A|) | O(|b|) | 互信息估计校准、门控单调 |
| CFT | O(budget·(|S|+|A|)) | O(|failures|) | ε-网覆盖、反例可复现 |
| TCC | O(|cert|·|Φ|) | O(|cert|+|failures|) | 租约/定位/红队证据三证齐全 |

**正确性定理（Training-Preserving Deployment Soundness）**
在第 53–54 轮 (A22)–(A28) 基础上追加：**(A29)** 证书泛函对策略 TV 距离 Lipschitz，常数由留出集校准；**(A30)** 定位误差 `P(‖δp‖≤ε_loc) ≥ 1-ζ_loc` 且协方差温度校准；**(A31)** 重认证延迟 ≤ τ_rec，回滚幂等；**(A32)** 对抗定位策略在 ε_loc-网上失败模式覆盖率 ≥ `1-β_loc`。则：
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - P(drift > D_max) - ζ_loc
            - β_E - β_loc - P(δ_a > Θ_a)
```
关键：**租约内才信任证书**、**定位误差显式定价**、**红队反例驱动下界更新**。

## 6. 本轮最大风险

**一句话**：把证书写进训练约束、把定位写进鲁棒性谱，理论上让「训练中不越界、部署时知所在」，但整条链的 soundness 压在**漂移 Lipschitz 常数、定位误差模型与对抗覆盖率这三个估计量**上；一旦真实场景的位姿误差重尾分布外、或策略更新沿证书泛函的非光滑方向跳跃，监控器会给出「仍然新鲜」的假安全，训练反而更高效地走出证书边界——因此必须以**悲观漂移上界 + 可定位性门控 + 红队反例闸门**三重护栏，并保留「证书失效即冻结部署」的硬回滚，绝不把训练曲线的平滑当作证书仍然成立的证据。
