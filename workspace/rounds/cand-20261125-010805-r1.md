研究循环·新灵感三元组第 1 轮；本轮灵感：「惯性测量单元」×「实时推理」

> **基线**：MetricVoiceGauge-NCD-HUTDH-v22 + IP-431–435（HDL / ACSC / DCSC / HPC-E / CFC++；其上承 v21 的语义-规范层与 v20/v19/v17 证书链）。不推倒 v22：HPC-E、分层过滤、机械臂配空间、深度 conformal、CFC++ 全部保留。本轮只做一件事：**给整套证书体系补上"时间"与"惯性"两个维度**——把证书从"瞬时快照"升级为"带有效期的对象"，并用 IMU 作为在线完整性校验器与实时证伪通道。

## 0. 直觉与动机

**灵感 1（惯性测量单元 → 证书的老化模型、在线物理证伪与独立模态）**
直觉：现有证书几乎全是"外感"的（点云、检测框、手势），更新率 10–30Hz、延迟 100–300ms，于是两个外感快照之间存在一段"证据真空"。IMU 是唯一高频（≥1kHz）、低延迟、且测量对象是"我自己"的传感器。它恰好补三件事：**（1）惯性传播**——把证书从瞬时快照外推成带有效期的区间对象，漂移不是缺陷而是"证书老化速率"，可由零偏/噪声界显式标定出安全视界 `Δ_max(ε)`；**（2）在线物理证伪**——计划隐含 `a_plan(t)`，IMU 实测 `a_I(t)`，残差超 conformal 阈值即"现实已给出反例"，立刻撤销 v22 的 `W_sim=∅` 信用，把 PGFO 从离线仿真证伪升级为实时、独立于感知的证伪通道；**（3）独立模态**——"自运动 vs 世界运动"的判别是最不易被视觉相关故障污染的第三方投票，撞击/跌倒的大加速度尖峰又是最低延迟的"人可能在场/发生了意外"证据。关键反直觉点：**IMU 不告诉你"那里有什么"，但它告诉你"我是否按我所以为的方式在动"——而证书失效恰恰总是始于"世界与模型的偏离"，所以 IMU 是一个廉价的证书校验和（checksum），而不是又一个传感器。**

**灵感 2（实时推理 → 正确性必须包含时序，证书是"会过期的谓词"）**
直觉：传统安全论证默认"证书一旦成立就成立"，但 50Hz 硬实时环里，**一个"正确但迟到"的证书与"错误"同样危险**——控制消费的是"当前有效"的证书，不是"曾经正确"的证书。实时推理的硬约束不是平均延迟，而是**最坏情况执行时间（WCET）+ 有界抖动**。核心创新：**把时序有效性提升为证书的一等公民**，令 `Cert = (φ, [t_issue, t_expiry], π)`，执行准入改为 `Fresh(C,t) ∧ φ`，于是"证书过期"与"证书为假"被统一处理——都退化为保守包络。第二层：**anytime 证书细化**——签发是慢的（conformal / 共识 / 分层过滤），消费是快的（O(1) 查表）。令签发产出保守保底证书 `C_0` 到逐步收紧的 `C_1 ⊇ C_2 ⊇ …`（执行集单调放宽但恒 ⊆ v22），deadline 到达时消费"已完成且仍 Fresh 的最紧者"，一张都没完成就用 `C_0`——**慢只损失活性，不损失安全**。第三层：**模型级联 + conformal**——快模型（保守、窄 WCET）到慢模型（紧、宽 WCET）级联，每级各有 conformal 宽度与预算，调度器在预算内选能完成的最高级，延迟-精度-保守性被显式 trade 且每级统计有效。关键反直觉点：**实时性不是"把推理做快"，而是"让证书的老化、过期与降级成为可证明、单调、默认安全的状态机"——真正的实时保证来自降级路径的 WCET，而不是主路径的速度。**

**两者如何与基线统一**
统一为 v22 之上的**"惯性-时序层"**：IKC 给证书加"老化模型"，PFW 给证书加"在线完整性校验"，TCA 把证书变成带有效期的对象，ARCS 在硬实时预算内完成签发/级联/降级，HPC-ET 把 `(HPC-E, Fresh, ¬Falsified_I)` 合成统一准入门，CFC+++ 把本体模态与时间戳一致性纳入法定人数。共享状态扩展为 `ζ_it = ζ_pgev ∪ (B_I, Σ_I, P, Δ_max, r, ρ, cascade, budget)`。全局不变量：对任意 `t`，`Exec_v23(t) ⊆ Exec_v22(t)`，且同一证书未被刷新时允许域随时间**只收缩不扩张**（aging monotonicity）。

## 2. 设计原则（在 P37–P42 基础上新增 P43–P45）

**P43 证书老化律（Certificate Aging）**
每张证书携带有效期 `[t_issue, t_expiry]`。惯性传播把外感证书有效期延展至至多 `Δ_max(ε)`，延展期内 `CertBox` 按协方差半轴膨胀。同一证书在被刷新前，允许执行域随时间**只收缩**：若 `t1 < t2` 且证书未更新，则 `Exec(t2) ⊆ Exec(t1)`。一旦 `Stale`，立即退化为无证保守域，绝不"续命"。

**P44 惯性证伪律（Inertial Falsification）**
当 IMU 残差统计量 `ρ_t > τ_falsify` 或出现撞击/跌倒尖峰，立即置 `Falsified_I(t)=⊤`，撤销 `W_sim=∅` 信用，使 HPC-ET 拒绝该计划；恢复须同时满足滞回窗口、重新标定、连续 N 帧残差回落。证伪**只会让执行域收缩，绝不扩张**；撞击/跌倒以最高优先级触发 SafeStop。

**P45 anytime 时序安全律（Anytime Temporal Safety）**
证书签发是 anytime 过程，产出一族 `C_0`（最保守）→`C_1`→…（逐步收紧）。任一时刻消费"已完成 ∧ Fresh"的最紧证书；若 deadline 前无任何细化完成，消费 `C_0`。故对任意调度、抢占、丢帧：`Exec_v23(t) = Exec_v22(t) ∩ ⋂_{已完成且 Fresh} C_i(t) ⊆ Exec_v22(t)`。WCET 预算必须覆盖"降级到 `C_0`"这条路径——它才是实时性的真正瓶颈。

## 3. 与基线的接口（如何退化）

- IKC 失效 / IMU 掉线 ⇒ 证书退回瞬时快照并令 `t_expiry=t_issue`，比 v22 更保守；
- PFW 误报 ⇒ 执行域收缩（活性损失），安全方向不变；PFW 漏报 ⇒ 仍有外感与离线 PGFO 兜底，不劣于 v22；
- ARCS 超时 ⇒ 消费 `C_0`，等价 v22 保守域；
- TCA 失效 ⇒ 所有证书视为 `Stale`，全域保守；
- HPC-ET 失效 ⇒ 回退 HPC-E（v22）；
- 全失效 ⇒ v22 ⇒ v21 ⇒ … ⇒ v18（引理 163/164）。
- **安全继承**：惯性只延展有界有效期、证伪只收缩、anytime 只取交、时序只按 `Fresh` 过滤；任意失效向更保守方向退化，`Exec_v23(t) ⊆ Exec_v22(t)` 对所有 `t` 成立。

## 4. 预期贡献

1. **证书老化模型**：把外感证书从瞬时快照升级为带有效期与膨胀律的区间对象，用 IMU 标定"安全能外推多久"；
2. **在线物理证伪**：IMU 把 PGFO 从离线仿真推进到实时、独立于感知的现实反例探测，并提供低延迟撞击/跌倒通道；
3. **时序一等公民**：给出 `Cert=(φ,有效期,溯源)` 与 `Fresh/Stale` 统一算子，证明"正确但迟到 = 不安全"的等价处理；
4. **anytime + 模型级联**：实时性由降级路径 WCET 保证，慢只损失活性、不损失安全；
5. **惯性-时序共识**：IMU 作为第三方模态进入 CFC+++，自运动/世界运动判别降低相关误判；
6. **HPC-ET 统一门 + 全局 aging 单调**，闭环 `Exec_v23(t) ⊆ Exec_v22(t)`。

## 5. 本轮最大风险

**一句话**：惯性传播的 `Δ_max` 与实时调度的 `WCET` 都是"标定出来的界"，一旦碰上"外感长时间断流 + IMU 零偏越界 + 尾延迟"三者叠加，证书会呈现"仍在有效期内、却已被现实证伪"的**假新鲜**状态，机器人在一个自洽但过时的世界模型里做出"有安全感"的错误决策。

## 1. 关键推导（证书老化与安全继承）

**引理 163（老化单调律）**：对同一张未刷新的证书，若 `t1 < t2 ≤ t_expiry`，则 `Exec(t2) ⊆ Exec(t1)`。
*证明*：允许域由 `CertBox(t)` 决定，协方差半轴 `g(Δ)=√λmax(P(Δ))` 关于外推时长 `Δ` 单调不减（见下），故 `CertBox(t1) ⊆ CertBox(t2)`，其补集（可行域）随之收缩；`Fresh` 在此区间恒真，不改变方向。∎

**引理 164（安全继承）**：`∀t, Exec_v23(t) ⊆ Exec_v22(t)`。
*证明*：`Exec_v23(t)=Exec_v22(t) ∩ Fresh ∩ ¬Falsified_I`，即 v22 集合再与两个谓词求交；交只会收缩。任一子模块失效时谓词回退为"恒真/更严"，方向不变。∎

**Δ_max(ε) 的导出**：设零偏按随机游走、外推 `Δ` 的协方差上界为
`P(Δ) ⪯ P_{k|k} + Δ·Σ_I + (Δ²/2)·B_max B_maxᵀ`。
取半轴上界 `g²(Δ) = λmax(P_{k|k}) + Δ·λmax(Σ_I) + (Δ²/2)·λmax(B_max B_maxᵀ)`，要求 `g²(Δ) ≤ ε²`，解二次不等式
`aΔ² + bΔ + c ≤ 0`，得
`Δ_max(ε) = (−b + √(b² − 4ac)) / (2a)`，其中 `a=λmax(B_max B_maxᵀ)/2`，`b=λmax(Σ_I)`，`c=λmax(P_{k|k}) − ε²`。
零偏越界检测：以滑动窗口估计 `b̂`，若 `b̂ ∉ B_I` 持续 `m` 帧则置 `Stale`，`Δ_max:=0`。

## 2. 关键算法骨架（在 IP-431–435 骨架上扩展）

# IP-439 Temporal Certificate Algebra
@dataclass
class Cert:
    phi: Callable[["Plan", float], bool]   # 谓词（HPC-E 等）
    t_issue: float
    t_expiry: float
    provenance: dict                        # merkle 溯源：模态、规则号、模型版本

def is_fresh(c: Cert, t: float) -> bool: return c.t_issue <= t <= c.t_expiry
def is_stale(c: Cert, t: float) -> bool: return t > c.t_expiry

class TemporalCertificateAlgebra:
    def admit(self, plan, certs, now):
        if any(is_stale(c, now) for c in certs):
            return self.conservative_envelope   # 过期即退保守，绝不续命
        return all(c.phi(plan, now) for c in certs)

# IP-436 Inertial Kernel Certificate
class InertialKernelCertificate:
    def __init__(self, imu, bias_bound, sigma_I, delta=1e-6):
        self.imu, self.B, self.S, self.delta = imu, bias_bound, sigma_I, delta

    def max_horizon(self, P_kk, eps_loc):
        # g²(Δ) = λmax(P_kk) + Δ·λmax(Σ_I) + (Δ²/2)·λmax(B Bᵀ) ≤ ε²
        a = 0.5 * max_eig(self.B @ self.B.T)
        b = max_eig(self.S)
        c = max_eig(P_kk) - eps_loc ** 2
        disc = b * b - 4 * a * c
        return 0.0 if disc < 0 else (-b + math.sqrt(disc)) / (2 * a)

    def propagate(self, cert_k, P_kk, t_now):
        D = t_now - cert_k.t_issue
        if D > self.max_horizon(P_kk, cert_k.eps):
            return replace(cert_k, t_expiry=cert_k.t_issue)   # 立即 Stale
        # 依 g(D) 膨胀 CertBox，返回外推后的证书（有效期到 t_now）
        return replace(cert_k, t_expiry=t_now, prov={**cert_k.provenance,
                       "imu_prop": D, "halfaxis": math.sqrt(self._g2(P_kk, D))})

# IP-437 Proprioceptive Falsification Witness
class ProprioceptiveFalsificationWitness:
    def __init__(self, kappa, h, tau_falsify, spike_thresh, alpha=0.01):
        self.kappa, self.h, self.tau, self.spike = kappa, h, tau_falsify, spike_thresh
        self.cusum, self.falsified = 0.0, False

    def update(self, a_I, a_plan, t):
        r = a_I - a_plan
        rho = mahalanobis(r, self.cov)                 # ρ_t
        self.cusum = max(0.0, self.cusum + rho - self.kappa)
        spike = norm(r) > self.spike                   # 撞击/跌倒尖峰
        if self.cusum > self.h or spike:
            self.falsified = True                       # 撤销 W_sim=∅ 信用
        return FalsificationEvent(t, rho, self.cusum, self.falsified, spike)

    def try_recover(self, ok_streak, recalibrated):
        # 滞回：连续 N 帧残差回落 ∧ 已重标定，才解除证伪
        if ok_streak >= self.N and recalibrated:
            self.falsified, self.cusum = False, 0.0

# IP-438 Anytime Real-Time Certificate Scheduler
class AnytimeCertificateScheduler:
    def __init__(self, cascade, wcet, deadline):
        self.cascade, self.wcet, self.D = cascade, wcet, deadline

    def issue_and_consume(self, state, now):
        budget = self.D - self.overhead(state)          # B_rt
        certs = [self.cascade[0].conservative(state)]  # C_0 保底（WCET 已覆盖）
        for i, level in enumerate(self.cascade[1:], start=1):
            if budget < self.wcet[level]:
                break                                   # 预算不足 → 停在此级
            budget -= self.wcet[level]
            c = level.solve(state)                      # anytime 细化
            if c is not None and is_fresh(c, now):
                certs.append(c)                         # 允许域单调 ⊆ v22
        return self._consume(certs, now)

    def _consume(self, certs, now):
        fresh = [c for c in certs if is_fresh(c, now)]
        if not fresh:
            return self.cascade[0].conservative_only    # 全过期 → 最保守
        return max(fresh, key=lambda c: allowed_volume(c))  # 最紧但最保守的可行者

# IP-440 HPC-ET 统一准入门
@dataclass
class HPCET:
    hpce: HPCE
    ikc: InertialKernelCertificate
    pfw: ProprioceptiveFalsificationWitness

    def admits(self, plan, now):
        temporal_ok = is_fresh(plan.cert, now) and self.ikc.covers(plan, now)
        inertial_ok = not self.pfw.falsified
        return self.hpce.admits(plan) and temporal_ok and inertial_ok

# IP-441 CFC+++ 惯性-时序模态法定人数
class CFCPlusPlusPlus(CertificateFederatedConsensusPlusHierarchical):
    def consensus_round(self, now):
        results = {}
        for key, votes in self.votes.items():
            fresh = [v for v in votes.values() if is_fresh(v.cert, now)]
            modalities = {v.modality for v in fresh}
            modality_ok = len(modalities) >= 2
            proprio_ok = any(v.modality == "imu" for v in fresh)     # ITQ: 本体模态
            ego_ok = self._ego_world_disentangled(fresh)             # ψ_own 判别
            ts_ok = self._timestamp_consistent(fresh)                # 时间戳一致性
            if len(fresh) >= self.N - self.F and modality_ok and proprio_ok and ego_ok and ts_ok:
                results[key] = self._majority_with_outlier_filter(fresh)
            else:
                results[key] = "CI"                                   # 保守仲裁
        return results

    def _ego_world_disentangled(self, votes):
        # deltas 同时可由"自运动"与"物体运动"解释时，禁止据此签发障碍/自由空间增补
        return not any(v.ambiguous_ego_world for v in votes)

## 3. 实验设计

**数据集与仿真**：在 v22 闭环仿真中注入三类工况——(a) 外感断流 200–800ms；(b) IMU 零偏阶跃越界（模拟温漂/标定失配）；(c) 计算平台尾延迟（注入 p99.9 尖峰）。真实数据取公开行人/跌倒/搬运序列，IMU 与视觉时间同步。

**E1 证书老化（IKC）**：扫描零偏界 `B_I` 与噪声 `Σ_I`，测安全视界 `Δ_max` 与"假自由空间率"（传播证书声称安全而真值碰撞）。对照：纯末次外感快照 vs 惯性传播。预期：惯性传播把有效视界延长 3–8 倍，假自由空间率在 `1−δ` 内；零偏越界时 `Stale` 在 ≤2 帧内触发。

**E2 在线证伪（PFW）**：注入打滑/碰撞/负载突变，测检出延迟（ms）、AUC、误报率（正常重规划/地面材质切换）；对照瞬时 Mahalanobis vs CUSUM。预期：CUSUM 在同等误报下检出一致更快；撞击/跌倒 ≤ 1 个控制周期。

**E3 实时正确性（ARCS+TCA）**：测 p50/p99/p99.9 延迟、deadline 缺失率、各级级联被选中比例、以及"安全不变量"审计（每步断言 `Exec_v23(t) ⊆ Exec_v22(t)` 与老化单调）。对照：固定最高级、固定最快级、无 anytime。预期：ARCS p99.9 控制在 `D` 内，deadline 缺失率 `≈0`，且不变量零违反。

**E4 集成消融**：逐一移除 IKC/PFW/ARCS/CFC+++，指标=安全违规数（目标 0）、任务完成率、平均速度、`Stale` 事件数、假许可率。预期：移除 IKC 使活性显著下降；移除 PFW 在工况 (b) 出现安全违规；移除 ARCS 在工况 (c) deadline 缺失上升；移除 CFC+++ 相关误判共识回升。

## 4. 本轮最大风险

**一句话**：惯性传播的 `Δ_max` 与实时调度的 `WCET` 都是标定出来的界，一旦"外感长时间断流 + IMU 零偏越界 + 尾延迟"三者叠加，证书会呈现"仍在有效期内、却已被现实证伪"的**假新鲜**状态，机器人在一个自洽但过时的世界模型里做出"有安全感"的错误决策。
