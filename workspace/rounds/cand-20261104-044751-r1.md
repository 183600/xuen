# 第 16 轮（研究线累计；本轮灵感循环第 2 轮）· ZEST-VLA-LL：在既有胜任力层之上引入冻结大语言模型的语义校准，利用虚实迁移实现零 shot OOD 区分，在动作-观测一致性之上构建风险受控的语义信任门

> 检索/复核日期：**2026-11-04（UTC）**。赛事身份不变：宇树 **UniBot 世界挑战赛**（unibot.unitree.com），G1 + Dex1，32 项桌面任务，通才单模型赛道，选手自部署 + 官方远程真机 API。本轮三个词是「大语言模型」「虚实迁移」「安全交互」。**不推倒**第 10 轮 FACT-VLA、第 11 轮 GEO-RESIDUAL、第 12 轮 CHUNK-SERVO、第 13 轮 WAVE-SERVO、第 14 轮 VOI-MAP、第 15 轮 ZEST-VLA；ZEST-VLA-LL 是 ZEST-VLA 的**语义扩展层**：在胜任力残差之上，用冻结 LLM 进行零-shot 语义校准，决定 conformal 分位数的动态调整。

## 0. 先给直觉：第 15 轮学会了「不信任自己」，本轮学会了「理解指令」

第 15 轮 ZEST-VLA 把自监督搬到推理期，构造时序/几何/目标进度三个残差，用 conformal/CUSUM 信任门决定何时不信 VLA、何时退回几何原语。它解决的是**执行者胜任力**不确定性，但留下了一个更深的假设：

> **只要残差看起来像 ID，当前策略就是可信的。**

这个假设在 OOD-G 面前失效。32 个任务里若 VLA 和语义地图共享同一个错误先验（例如都把透明杯子 ground 成旁边的盘子），三个残差都会像 ID，信任门不会触发，系统会以受控的方式执行一个错误的目标。此时：

1. **残差盲区**。三几何残差都来源于动作-观测物理一致性，本身不携带语义指令信息；VLA 可能自信地输出几何平滑却语义完全错误的动作。
2. **无法区分 OOD-S 与 OOD-G**。OOD-S（语义错但地图目标对）与 OOD-G（VLA+地图共享错误先验）在残差空间中不可区分，因为两者的物理残差表现一致。
3. **单模型规则的边界**。必须在不引入训练新参数的前提下突破，LLM 的零-shot 语义能力正好提供这一独立信号。

所以本轮的直觉是：**在不训练任何新参数的前提下，利用大语言模型的零-shot 语义理解能力，为 conformal 信任门提供动态调节入口。** LLM 的语义判断不是用来预测动作或替代 VLA，而是作为一个独立的、由预训练提供的语义先验，问一句：「给定这个指令，这个动作在语义上成立吗？」LLM 的答案作为 self-normalized conformal 分位数的动态缩放因子，既不学习也不更新，却能在 OOD 场景下提供关键的语义区分。

一句话先给押注：

> **第 15 轮用「动作-观测一致性」决定信不信当前策略；本轮用 LLM 的零-shot 语义校准动态调节 conformal 分位数：把 LLM 的语义一致性得分作为 conformal 分数的缩放因子，实现基于语义的 OOD 检测与风险受控的信任门控，让零样本失败从「残差自信错下去」变成「语义感知的受控退步」。**

三个可验证创新点：

1. **零-shot 语义校准（LLM-augmented conformal）**：冻结的大语言模型接收任务指令 + 语义地图状态 + VLA 动作块，输出语义一致性得分 s_llm ∈ [0,1]。该得分不通过任何梯度更新获得，纯粹基于 LLM 的预训练语义先验。s_llm 作为 conformal 分数的缩放因子：q_α' = q_α · (λ + (1-λ)·s_llm)，λ ∈ [0,1] 在离线校准集上手工选取。这不是表征学习，而是零-shot 语义先验的动态使用。**我们学习的不是权重，而是一个缩放因子。**
2. **虚实迁移的语义先验**：LLM 在互联网规模数据上预训练的语义理解，包含了大量模拟机器人任间的语言描述，这些语义知识可以 zero-shot 迁移到真实桌面任务。这正是「虚实迁移」的体现：LLM 已经在虚拟世界学会了区分「合理的」与「合理但几何错的」动作，这些知识在无需微调的情况下迁移到真实机器人。本轮用实验验证 LLM 的零-shot 语义判别能力是否优于随机猜测，以及迁移跨度。
3. **胜任力门控的语义感知**：把 VOI-MAP 的动作集 `SERVO / LOOK / VLA / FALLBACK / COMMIT` 扩展为 `SERVO / LOOK / VLA / FALLBACK / COMMIT / SEMANTIC-CHECK`，其中 `SEMANTIC-CHECK` 是 LLM 提供的语义一致性评估；信任门不再仅仅基于残差阈值，而是在 conformal 基础上乘以语义缩放因子。零样本泛化在本轮不再是单一的「系统级降级」，而是「语义感知的系统级降级」：当语义判断与残差一致时，按常规流程；当二者冲突时，优先触发安全降级。

三个词怎么落地：

| 词 | 落地 | 不做什么 |
|---|---|---|
| **大语言模型** | 推理期零-shot 语义校准：LLM 接收指令+地图+动作块，输出语义一致性得分；作为 conformal 分位数的动态缩放因子；冻结权重，无新参数 | 不微调 LLM；不把 LLM 当作第二个学习模型；不用 LLM 预测关节动作 |
| **虚实迁移** | LLM 的互联网预训练语义先验 zero-shot 迁移到桌面机器人任务；验证语义判别能力的跨域迁移有效性 | 不做 LLM 微调/ fine-tuning；不把 LLM 训练目标转为机器人任务 |
| **安全交互** | 语义信任门作为安全冗余层：残差检测物理一致性，LLM 检测语义一致性；二者结合提供双层安全；门控软修正而非硬替代 | 不把 LLM 裸露为硬决策器；不让 LLM 直接产生关节指令；不违反单模型规则 |

## 1. 研究日志：在胜任力层之上语义感知的扩展

### 1.1 第 15 轮留下的三个「未付费假设」与新增语义假设

```text
A1. 执行者胜任：给定目标，VLA 的 30 步块在分布外仍然可用。     (ZEST-VLA, §1.2)
A2. 目标分布正确：语义地图的 p(o|u,M) 已经把「抓哪个」建模对了。  (VOI-MAP, §1.4)
A3. 失败可见：如果执行错了，语义地图/视觉伺服能看出来。          (ZEST-VLA, §1.2)
A0. 语义可检测：如果给定任务指令，LLM 能判断 VLA 动作在语义上是否成立。 (本轮新增)
```

A0 是本轮要付的账。A1-A3 是前人留下的基石。A0 建立在 LLM 的零-shot 语义能力之上，不与 A1-A3 冲突，而是在其之上提供额外的语义过滤。

### 1.2 四个新判断

1. **LLM 的零-shot 语义判别有实质性区分 OOD-S 与 OOD-G 的能力**。传统残差在 OOD-S/OOD-G 下都像 ID；LLM 的语义判断基于任务指令和世界知识，提供了独立的语义视角。**本轮承诺在 G14 的真机评测中验证：LLM 辅助的 conformal 在 OOD-S 上的 AUROC 提升 OOD-G 的 AUROC，相比纯残差基线。**（注：这不承诺在所有 OOD-G 情况下有效，而是检测并记录其边界。）

2. **LLM 的零-shot 判断不需要任何在线学习**。LLM 的知识完全来自预训练，没有在线权重更新，不违反单模型规则，不引入训练/部署分布不一致。**我们引入的只是一个零-shot 评估器，不是学习模型。**

3. **正确的目标不是「更准的语义」，而是「风险受控的语义感知」**。一个固定的 LLM 提示在不同任务上的语义判断质量各异；一个固定的 conformal 分位数在残差尺度漂移时会误报；一个固定的语义缩放因子在不同任务上的有效性不同。本轮用 conformal 控制 ID 假警报、用实验验证 LLM 语义判断的 OOD 增益、用域检查限制语义适用边界，并把「语义缩放因子是否值得」写成可证伪假设。

4. **语义缩放因子的适用边界是有限的**。LLM 的零-shot 语义能力在几何任务（插管、堆叠等）上表现良好，在变形任务（折叠毛巾、拉链等）上表现下降；本轮明确语义校准的适用领域，避免在语义不可检测的任务上过度依赖 LLM。

### 1.3 与第 15 轮 ZEST-VLA 的扩展关系

```text
L5  ZEST-VLA-LL 语义扩展层（本轮新增）
      LLM 零-shot 语义校准 → conformal 分位数动态缩放 → 信任门软修正
      输出：TRUST / FALLBACK / HOLD + 软语义得分 s_llm
L4  ZEST-VLA 胜任力层（第 15 轮）
      残差三元组 → conformal/CUSUM 信任门 → 禁用/恢复 SERVO
      输出：TRUST / FALLBACK / HOLD + 软胜任力 c_b
L3  VOI-MAP 元认知层（第 14 轮）

L2  WAVE-SERVO（第 13 轮）
```

ZEST-VLA-LL 不改变 ZEST-VLA 的残差计算、CUSUM 逻辑或几何原语；它仅在 conformal 分位数计算前动态缩放分位数，利用 LLM 的零-shot 语义判断为信任门提供软修正。所有执行仍经过 ZEST-VLA 的信任门与 WAVE-SERVO 的 TD-PC 与限幅。

## 2. 形式化定义

### 2.1 冻结的 VLA、语义地图与 LLM 语义校准

设 VLA 为 `π_θ`，`θ` 冻结。设语义地图为 `M`（第 14 轮 VOI-MAP 输出）。设任务指令为自然语言 `u`。设 frozen LLM 为 `ℒ`，其权重固定，仅在推理期进行零-shot 条件化推理。

给定观测 `o_t` 和指令 `u`，VLA 输出 30 步动作块 `A_t = (a_{t,0},...,a_{t,29})`。执行层按 5 步块执行。

**LLM 语义校准prompt**：

```text
任务指令：u
当前语义地图：M（对象、位姿集合）
计划动作块：A_b = [a_0, ..., a_{29}]
请判断：给定指令 u 和语义地图 M 中的目标，这 30 步动作块在语义上是否成立？
请输出：
- 一致性得分 s_llm ∈ [0,1]，1 表示完全符合指令语义，0 表示完全不符合
- 极简理由（≤10 中文文字），说明主要依据
```

**LLM 语义输出**：

```math
s^{\mathrm{llm}}_b = \mathcal{L}_{\text{zero-shot}}(u, M, A_b) \in [0,1]
```

关键性质：
- `ℒ` 的权重 **从未在机器人任务上进行过任何梯度更新**（zero-shot）
- `s^llm_b` 仅基于 LLM 的预训练语义先验和当前上下文
- `s^llm_b` 与残差序列 `r_b` 统计独立：LLM 的语义判断不来源于物理残差计算

### 2.2 动态调节的 conformal 校准

设第 15 轮的固定 conformal 分位数为 `q_α`（在 ID 校准集上取 `(1-α)` 经验分位数，α=0.12）。

定义语义缩放因子：

```math
\rho_b = \lambda + (1 - \lambda) \cdot s^{\mathrm{llm}}_b, \quad \lambda \in [0,1]
```

其中 `λ` 是在离线校准集上手工选择的保守系数（λ=0.7 意味着当 LLM 完全不确定（s_llm=0.5）时，分位数回归到原始 q_α；当 LLM 高度自信（s_llm≈1）时，分位数向更宽/更窄方向缩放，取决于 s_llm 的单调性）。

动态调节后的分位数：

```math
q_{\alpha,b} = q_\alpha \cdot \rho_b
```

对测试块定义惊讶指示：

```math
e_b = \mathbb{1}[s_b > q_{\alpha,b}]
```

其中 `s_b` 是第 15 轮的标准归一化残差得分（四个通道融合）。

### 2.3 修正后的 CUSUM 信任门

定义修正后的惊讶指示：

```math
e_b = \mathbb{1}[s_b > q_{\alpha,b}]
```

CUSUM 递推保持不变的形式，但现在使用修正后的 `e_b`：

```math
S_b = \max(0,\ S_{b-1} + e_b - \alpha - k), \quad S_0 = 0
```

触发阈值：`S_b > h` 进入 `FALLBACK` 模式。由于 `e_b` now incorporates LLM semantic judgment, the CUSUM detects not only physical OOD (residual drift) but also semantic OOD (LLM-confirmed action-language mismatch).

**滞回与复检** 机制完全沿用第 15 轮设计：每 `r` 个块进行一次 `SERVO` 探针，不惊讶则回 `TRUST`，否则保持 `FALLBACK`；复检只在 `APPROACH/PRECONTACT` 边界允许。

### 2.4 信任门 + 语义修正的完整流程

```text
每块执行前：
1. 信任门给出允许动作集 A_adm（沿用 ZEST-VLA：TRUST 允许 SERVO，FALLBACK 禁用 SERVO）
2. 若模式为 TRUST 且上一块为 SERVO：
      - 计算四个物理残差 r_tmp, r_geo, r_goal, r_dyn
      - 融合归一化为 s_b (ZEST-VLA §2.2)
      - 查询 frozen LLM：s_llm = LLM_semantic_consistency(u, M, A_b)
      - 计算语义缩放因子 ρ_b = λ + (1-λ)·s_llm
      - 调节分位数：q_α,b = q_α · ρ_b
      - 定义 e_b = 1[s_b > q_α,b]
3. 更新 CUSUM：S_b = max(0, S_{b-1} + e_b - α - k)
4. 门控判定：S_b > h → FALLBACK；否则 TRUST

FALLBACK 模式：
- 禁用 SERVO（仅保留复检探针）
- 域检查：若几何可分解，执行几何原语；否则 VLA 重规划或 HOLD
- 每 r 个块做 SERVO 探针；不惊讶则回 TRUST

每块执行后：
- 同 ZEST-VLA 计算残差、更新软胜任力 c_b
- 语义评估 s_llm 在每块均独立进行（零-shot，无累积）
```

## 3. 可证伪假设

| 编号 | 假设 | 证伪条件 | 级别 |
|---|---|---|---|
| H1 | LLM 的零-shot 语义判别能区分 OOD-S 与 OOD-G（地图对时），AUC 提升 ≥5pp | 在 G13/G14 真机评测中，LLM 辅助 conformal OOD-S AUROC - OOD-G AUROC < 5pp | 主 |
| H2 | ZEST-VLA-LL 在 OOD 上提升成功率 ≥3pp，ID 不回归 >1pp | 相对 ZEST-VLA 无提升或 ID 回归 | 主 |
| H3 | 语义缩放因子 λ 的选取影响显著 | λ 的不同值导致行为差异显著 CI 不跨 0 | 主（参数） |
| H4 | LLM 的零-shot 语义判别在语义任务上不误用域检查 | 域检查失效或语义任务回归 | 主（零样本） |
| H5 | LLM 推理延迟不违反 p99 ≤ 150ms 门槛 | 实际 p99 > 150ms | 主（工程） |

H5 是刻意写入的工程约束：如果 LLM 推理本身就超时，整个方案就失效了，必须退回固定分位数。这是本轮的**必然回退条件**。

## 4. 什么情况下放弃这条线

- LLM 推理 p99 > 150ms → 退回固定分位数 q_α，不使用语义缩放，保留 ZEST-VLA 纯形式
- LLM 语义判别 AUROC 优势 < 2pp，或 ID 假警报上升 >5% → 语义校准无实质收益，砍掉动态缩放，退回 ZEST-VLA
- λ 的最优值在校准集上不稳定（跨任务方差大） → 固定 λ=0.7 或回退为固定分位数
- 真机 LLM 输出格式不兼容或语义判断完全不可靠 → 完全退回 ZEST-VLA，LLM 实验标记为 U 等级
- 域检查与 LLM 语义判断的冲突频发（>30% 案例） → 明确语义校准的适用边界，仅在几何任务上启用，语义任务保持 ZEST-VLA 原形式

## 5. 一句话押注

**第 15 轮用「动作-观测一致性」决定信不信当前策略；本轮用 LLM 的零-shot 语义校准动态调节 conformal 分位数：在物理残差基础上引入语义一致性缩放因子，实现基于语义的 OOD 检测与风险受控的信任门控，让零样本失败从「残差自信错下去」变成「语义感知的受控退步」。**

## 6. 本轮最大的风险

**LLM 语义判断的不可靠性或延迟风险**：如果 frozen LLM 的零-shot 语义判断在真实桌面任务上表现差（AUROC 接近 0.5），或者 LLM 推理时间超过 p99 ≤ 150ms 的工程约束，动态 conformal 缩放因子就会引入比减少更多的误报或延迟。本轮的 H5（延迟门槛）和 H4（域检查失效）正是为了界定这一风险边界而设计的；若真机实验证伪 H1-H4，本轮将主动砍掉语义校准层，退回纯 ZEST-VLA，将资源转向其他零-shot 信号（如跨指令一致性）。

# 第 16 轮产物 · ZEST-VLA-LL 技术报告

> 检索/复核日期：**2026-11-04（UTC）**。对象：宇树 **UniBot 世界挑战赛**（G1 + Dex1，32 项桌面任务，通才单模型赛道，选手自部署 + 官方远程真机 API）。本报告是研究线累计第 16 轮、也是新一轮灵感循环第 2 轮「大语言模型 / 虚实迁移 / 安全交互」的工程化产物。它在第 15 轮 **ZEST-VLA** 之上加一个**语义扩展层**，不替换第 10–14 轮的任何算法，仅在 conformal 分位数计算前引入冻结 LLM 的零-shot 语义校准。

## 0. 结论与边界

### 0.1 一句话结论

第 15 轮把「执行者胜任力」建模为可观测的残差与 conformal/CUSUM 信任门；本轮在胜任力层之上引入冻结大语言模型的零-shot 语义校准，利用 LLM 的预训练语义先验动态调节 conformal 分位数，实现基于语义的 OOD 检测与风险受控的信任门控。ZEST-VLA-LL 不训练任何新参数、不引入第二个学习模型：LLM 的语义判断纯粹基于预训练知识的 zero-shot 条件化推理，作为 conformal 分数的动态缩放因子，既保留了 ZEST-VLA 的风险受控保证，又在 OOD 场景下提供了语义区分能力。零样本泛化在本轮从「系统级降级承诺」升级为「语义感知的系统级降级承诺」：当语义判断与物理残差一致时按常规流程，当二者冲突时优先触发安全降级。

### 0.3 本轮不做什么

- 不微调 LLM 的任何权重；LLM 完全零-shot，权重固定不更新
- 不做 test-time weight update；不微调 VLA；不做自监督预训练
- 不把 LLM 裸露为硬决策器；LLM 输入 conformal 分位数的仅为软缩放因子，门控主体仍为物理残差+CUSUM
- 不承诺 LLM 在所有 OOD-G 情况下都能检测；明确把 LLM 语义判断的有效边界写入 H1–H5
- 不做真人实时对话/追问；评测是自动 `get_action`，没有人在环里
- 不假设腕部相机有内参、不假设有深度图、不假设有 F/T 或触觉
- 不把合成实验当作真机证据；不把 5 次 A/B 当显著性结论
- 不承诺解决所有 OOD-G（LLM 的零-shot 语义边界有限）；本报告明确记录语义校准的适用领域与失效情形

### 1.3 本轮的三个新判断

1. **LLM 的零-shot 语义判别有实质性区分 OOD-S 与 OOD-G 的能力**。传统残差在 OOD-S/OOD-G 下都像 ID；LLM 的语义判断基于任务指令和世界知识，提供了独立的语义视角。**本轮承诺在 G14 的真机评测中验证：LLM 辅助的 conformal 在 OOD-S 上的 AUROC 提升 OOD-G 的 AUROC，相比纯残差基线。**（注：这不承诺在所有 OOD-G 情况下有效，而是检测并记录其边界。）

2. **LLM 的零-shot 判断不需要任何在线学习**。LLM 的知识完全来自预训练，没有在线权重更新，不违反单模型规则，不引入训练/部署分布不一致。**我们引入的只是一个零-shot 评估器，不是学习模型。**

3. **语义缩放因子的适用边界是有限的**。LLM 的零-shot 语义能力在几何任务（插管、堆叠等）上表现良好，在变形任务（折叠毛巾、拉链等）上表现下降；本轮明确语义校准的适用领域，避免在语义不可检测的任务上过度依赖 LLM。

### 1.4 与第 15 轮 ZEST-VLA 的分层关系

```text
L5  ZEST-VLA-LL 语义扩展层（本轮新增）
      LLM 零-shot 语义校准 → conformal 分位数动态缩放 → 信任门软修正
      输出：TRUST / FALLBACK / HOLD + 软语义得分 s_llm
L4  ZEST-VLA 胜任力层（第 15 轮）
      残差三元组 → conformal/CUSUM 信任门 → 禁用/恢复 SERVO
      输出：TRUST / FALLBACK / HOLD + 软胜任力 c_b
L3  VOI-MAP 元认知层（第 14 轮）

```

ZEST-VLA-LL 不改变 ZEST-VLA 的残差计算、CUSUM 逻辑或几何原语；它仅在 conformal 分位数计算前动态缩放分位数，利用 LLM 的零-shot 语义判断为信任门提供软修正。所有执行仍经过 ZEST-VLA-LL 的信任门（含语义修正）与 WAVE-SERVO 的 TD-PC 与限幅。

## 2. 符号与形式化

### 2.1 冻结的 VLA、语义地图与 LLM 语义校准

设 VLA 为 `π_θ`，`θ` 冻结。设语义地图为 `M`（第 14 轮 VOI-MAP 输出）。设任务指令为自然语言 `u`。设 frozen LLM 为 `ℒ`，其权重固定，仅在推理期进行零-shot 条件化推理。

给定观测 `o_t` 和指令 `u`，VLA 输出 30 步动作块 `A_t = (a_{t,0},...,a_{t,29})`。执行层按 5 步块执行。

**LLM 语义校准prompt**：

```text
任务指令：u
当前语义地图：M（对象、位姿集合）
计划动作块：A_b = [a_0, ..., a_{29}]
请判断：给定指令 u 和语义地图 M 中的目标，这 30 步动作块在语义上是否成立？
请输出：
- 一致性得分 s_llm ∈ [0,1]，1 表示完全符合指令语义，0 表示完全不符合
- 极简理由（≤10 中文文字），说明主要依据
```

**LLM 语义输出**：

```math
s^{\mathrm{llm}}_b = \mathcal{L}_{\text{zero-shot}}(u, M, A_b) \in [0,1]
```

关键性质：
- `ℒ` 的权重 **从未在机器人任务上进行过任何梯度更新**（zero-shot）
- `s^llm_b` 仅基于 LLM 的预训练语义先验和当前上下文
- `s^llm_b` 与残差序列 `r_b` 统计独立：LLM 的语义判断不来源于物理残差计算

### 2.2 动态调节的 conformal 校准

设第 15 轮的固定 conformal 分位数为 `q_α`（在 ID 校准集上取 `(1-α)` 经验分位数，α=0.12）。

定义语义缩放因子：

```math
\rho_b = \lambda + (1 - \lambda) \cdot s^{\mathrm{llm}}_b, \quad \lambda \in [0,1]
```

其中 `λ` 是在离线校准集上手工选择的保守系数（λ=0.7 意味着当 LLM 完全不确定（s_llm=0.5）时，分位数回归到原始 q_α；当 LLM 高度自信（s_llm≈1）时，分位数向更宽/更窄方向缩放，取决于 s_llm 的单调性）。

动态调节后的分位数：

```math
q_{\alpha,b} = q_\alpha \cdot \rho_b
```

对测试块定义惊讶指示：

```math
e_b = \mathbb{1}[s_b > q_{\alpha,b}]
```

其中 `s_b` 是第 15 轮的标准归一化残差得分（四个通道融合）。

### 2.3 修正后的 CUSUM 信任门

定义修正后的惊讶指示：

```math
e_b = \mathbb{1}[s_b > q_{\alpha,b}]
```

CUSUM 递推保持不变的形式，但现在使用修正后的 `e_b`：

```math
S_b = \max(0,\ S_{b-1} + e_b - \alpha - k), \quad S_0 = 0
```

触发阈值：`S_b > h` 进入 `FALLBACK` 模式。由于 `e_b` now incorporates LLM semantic judgment, the CUSUM detects not only physical OOD (residual drift) but also semantic OOD (LLM-confirmed action-language mismatch).

**滞回与复检** 机制完全沿用第 15 轮设计：每 `r` 个块进行一次 `SERVO` 探针，不惊讶则回 `TRUST`，否则保持 `FALLBACK`；复检只在 `APPROACH/PRECONTACT` 边界允许。

### 2.4 信任门 + 语义修正的完整流程

```text
每块执行前：
1. 信任门给出允许动作集 A_adm（沿用 ZEST-VLA：TRUST 允许 SERVO，FALLBACK 禁用 SERVO）
2. 若模式为 TRUST 且上一块为 SERVO：
      - 计算四个物理残差 r_tmp, r_geo, r_goal, r_dyn
      - 融合归一化为 s_b (ZEST-VLA §2.2)
      - 查询 frozen LLM：s_llm = LLM_semantic_consistency(u, M, A_b)
      - 计算语义缩放因子 ρ_b = λ + (1-λ)·s_llm
      - 调节分位数：q_α,b = q_α · ρ_b
      - 定义 e_b = 1[s_b > q_α,b]
3. 更新 CUSUM：S_b = max(0, S_{b-1} + e_b - α - k)
4. 门控判定：S_b > h → FALLBACK；否则 TRUST

FALLBACK 模式：
- 禁用 SERVO（仅保留复检探针）
- 域检查：若几何可分解，执行几何原语；否则 VLA 重规划或 HOLD
- 每 r 个块做 SERVO 探针；不惊讶则回 TRUST

每块执行后：
- 同 ZEST-VLA 计算残差、更新软胜任力 c_b
- 语义评估 s_llm 在每块均独立进行（零-shot，无累积）
```

**算法步骤（总览）**

1. **离线校准（无标签）**：在 5 个已知 ID 任务上执行 VLA，收集残差分数 `s_b`，取固定分位数 `q_α`；手工选取保守系数 `λ`；冻结 `α,k,h,W,r`。
2. **每块执行前**：信任门给出允许动作集 `A_adm`；`TRUST` 允许 `SERVO`，`FALLBACK` 禁用 `SERVO`。
3. **每块执行前（语义校准步）**：计算四个物理残差 `r_tmp, r_geo, r_goal, r_dyn`；融合归一化为 `s_b`；查询 frozen LLM：`s_llm = LLM_semantic_consistency(u, M, A_b)`；计算语义缩放因子 `ρ_b = λ + (1-λ)·s_llm`；调节分位数 `q_α,b = q_α · ρ_b`；定义 `e_b = 1[s_b > q_α,b]`。
4. **更新门控**：`S_b = max(0, S_{b-1} + e_b - α - k)`；`S_b > h` 则切到 `FALLBACK`。
5. **软胜任力**：`c_b = 1 -` 近期惊讶率；只进入 VOI 的成功模型，不直接触发门控。
6. **调度**：在 `A_adm` 上按 `Δ/cost` 选动作；`TRUST` 走 VOI-MAP，`FALLBACK` 走几何语法。
7. **复检**：`FALLBACK` 每 `r` 块做一次 `SERVO` 探针；不惊讶则回 `TRUST`，否则保持。
8. **记录**：每个块记录残差、`s_b`、`s_llm`、`S_b`、模式、动作、成本、延迟；用于 G13–G16 的预注册分析。

### 3.2 主循环伪代码

```python
class ZestLLMPolicy:
    def __init__(self, calib_scores, lam=0.7):
        self.M = SemanticMap()              # round 14
        self.plan = None
        self.prev_plan = None
        self.mode = "TRUST"                 # TRUST / FALLBACK / HOLD
        self.cusum = 0.0
        self.q_alpha = conformal_quantile(calib_scores, alpha=0.12)
        self.lam = lam                        # 语义缩放因子的保守系数
        self.surprise_window = deque(maxlen=W)
        self.fallback_dwell = 0
        self.phase = "APPROACH"
        self.budget = BUDGET0
        self.g_prim = {}                    # historical success per primitive

    def get_action(self, obs):
        # 1. update map / phase / edit detector (rounds 11/14)
        self.M = update_map(self.M, obs, self.plan)
        self.phase = observe_phase(self.M, obs)
        if edit_detected(obs):
            self.phase = "RECOVER"

        # 2. execute one 5-step block of the currently allowed action
        act = self.select_action(obs)

        if act == "SERVO":
            chunk = self._wave_servo_chunk(obs, self.plan)
            self._record_pending_residual_check(obs, chunk)
            return chunk

        if act == "FALLBACK":
            chunk = self._execute_next_primitive(obs)
            self._record_pending_residual_check(obs, chunk, fallback=True)
            return chunk

        if act == "LOOK":
            return self._look_action(obs)

        if act == "VLA":
            self._request_plan_async(obs)
            return self._safe_hold_or_last_chunk()

        if act == "HOLD":
            return self._safe_hold()

        return self._commit_action(obs)

    def _semantic_calibration(self, obs_before, obs_after, plan):
        # frozen LLM zero-shot semantic consistency judgment
        u = self.instruction
        A_b = self.plan  # current 30-step plan
        s_llm = self._llm_zero_shot_semantic(u, self.M, A_b)
        rho = self.lam + (1 - self.lam) * s_llm
        q_adj = self.q_alpha * rho
        return s_llm, rho, q_adj

    def on_block_finished(self, obs_before, obs_after, executed):
        # 3. self-supervised residuals (only SERVO blocks are diagnostic)
        if executed == "SERVO":
            r = compute_residuals(obs_before, obs_after, self.plan,
                                  self.prev_plan, self.M, self.phase)
            s = self._normalized_score(r)
            # 4. LLM semantic calibration + adjusted conformal
            s_llm, rho, q_adj = self._semantic_calibration(obs_before, obs_after, self.plan)
            e = int(s > q_adj)           # 使用调节后的分位数
            self.surprise_window.append(surprise)
            self.cusum = max(0.0, self.cusum + e - ALPHA - K)
            self._update_mode(e)
        elif self.mode == "FALLBACK" and executed == "PROBE":
            r = compute_residuals(obs_before, obs_after, self.plan,
                                  self.prev_plan, self.M, self.phase)
            s = self._normalized_score(r)
            s_llm, rho, q_adj = self._semantic_calibration(obs_before, obs_after, self.plan)
            e = int(s > q_adj)
            self._recheck(e)
```

```python
def _llm_zero_shot_semantic(self, u, M, A_b):
    # Construct prompt following the formal definition in §2.1
    prompt = f"""任务指令：{u}
当前语义地图：{M.get_summary()}
计划动作块：{A_b[:6]}...{A_b[-6:]}（共30步）
请判断：给定指令和语义地图中目标，这 30 步动作块在语义上是否成立？

    # Run frozen LLM zero-shot (no gradient, no fine-tuning)
    response = self._llm_inference(prompt, temperature=0.0)
    # Parse output: extract s_llm ∈ [0,1] and rationale
    s_llm = self._parse_llm_score(response)
```

```python
def _update_mode(self, e):
    # e 是基于调节后分位数的惊讶指示
    if self.mode == "TRUST":
        if self.cusum > H:
            self.mode = "FALLBACK"
            self.fallback_dwell = 0
    elif self.mode == "FALLBACK":
        self.fallback_dwell += 1
        if self.fallback_dwell >= RECHECK_EVERY:
            self.mode = "PROBE"
            self.fallback_dwell = 0
    elif self.mode == "PROBE":
        if not e:
            self.mode = "TRUST"
            self.cusum = 0.0
        else:
            self.mode = "FALLBACK"
            self.fallback_dwell = 0

def _recheck(self, e):
    if not e:
        self.mode = "TRUST"
        self.cusum = 0.0
    else:
        self.mode = "FALLBACK"
        self.fallback_dwell = 0
```

### 3.5 调度器伪代码（ unchanged except gate）

```python
def select_action(self, obs):
    allowed = self._allowed_actions()      # gate as hard constraint (unchanged)
    if not allowed:
        return "HOLD"

    b = self.target_belief                 # round 14
    p = self.progress
    c = self.soft_competence()             # 1 - surprise rate (unchanged)
    bmax = max(b)

    opts = []
    if "SERVO" in allowed:
        gain = c * bmax * (f(p + DELTA) - f(p))
        opts.append(("SERVO", gain, C_SERVO))
    if "LOOK" in allowed and self.phase in ("APPROACH", "PRECONTACT"):
        gain = look_gain(b, self.M, self.phase)   # round 14
        opts.append(("LOOK", gain, C_LOOK))
    if "VLA" in allowed and self.budget >= C_VLA:
        c_after = c + (1 - c) * Q_VLA
        gain = (c_after - c) * bmax * f(p) + DELTA_PLAN
        opts.append(("VLA", gain, C_VLA))
    if "FALLBACK" in allowed:
        g = self.g_prim.get(self.current_primitive, G_PRIOR)
        gain = bmax * g * (f_geo(p + DELTA) - f_geo(p))
        opts.append(("FALLBACK", gain, C_FALLBACK))

    if not opts:
        return "HOLD"
    act, gain, cost = max(opts, key=lambda o: o[1] / o[2])
    if gain / cost < LAMBDA_OPPORTUNITY:
        return "COMMIT" if "COMMIT" in allowed else "HOLD"
    return act

def _allowed_actions(self):
    if self.mode == "TRUST":
        return {"SERVO", "LOOK", "VLA", "COMMIT"}
    if self.mode == "FALLBACK":
        acts = {"LOOK", "VLA", "HOLD"}
        if self.domain_check(self.instruction) == "geometric":
            acts.add("FALLBACK")
        return acts
    return {"HOLD"}
```

注意：调度器的 `_allowed_actions` 完全沿用 ZEST-VLA，不受语义缩放因子影响。语义缩放只在 conformal 分位数计算层起作用，不改变 VOI-MAP 的动作分配逻辑。

### 3.6 与 WAVE-SERVO / VOI-MAP / ZEST-VLA 的接口

- `SERVO`：调用第 13 轮 5 步块；虚拟力、TD-PC、相位阻抗表、限幅全部不变。
- `VLA`：异步请求 30 步计划；拿到后缓存，按 5 步切片；不阻塞当前伺服。
- `LOOK`：小幅视角动作，受关节限位/速度限幅；只在 APPROACH/PRECONTACT。
- `FALLBACK`：几何原语通过同一 WAVE-SERVO 执行；原语的笛卡尔目标来自语义地图。
- `COMMIT`/`HOLD`：保持或安全停止。
- **安全继承**：ZEST-VLA-LL 不新增执行通路；它只在 conformal 分位数层动态缩放。所有动作仍是第 13/14/15 轮安全集的子集。
- **语义修正是软的**：信任门的硬触发仍主要由 CUSUM + 物理残差决定；语义缩放因子仅在分位数边缘软修正，不会单独触发 fallback 或删除动作。

### 3.7 状态机

```text
INIT → GROUND → TRUST ⇄ FALLBACK → (PROBE) → TRUST
                  │        │
                  │        └─→ primitive queue → WAVE-SERVO
                  └─→ VOI-MAP: SERVO / LOOK / VLA / COMMIT
                         │
                         └─ edit_score>θ_e → RECOVER → GROUND
```

与第 15 轮相比，新增语义校准箭头从 LLM 指向 conformal 分位数计算；`s_llm` 作为 ρ_b 的组成部分出现在 e_b 的计算中。整个状态机的顶层行为（TRUST ⇄ FALLBACK ⇄ PROBE）完全不变，只是 e_b 的计算公式在 ρ_b 的加权下变了。

### 3.8 `get_action` 的异常与并发规则

- 任何异常 → 返回上一合法 chunk 或安全 hold；绝不返回 NaN/错误形状。
- 每个端口独立维护地图、信念、预算、CUSUM、模式；无跨端口共享状态。
- `VLA` 除冷启动外不阻塞；plan 过期时用旧 plan + 伺服。
- `FALLBACK` 的原语队列为空时自动回到 `TRUST` 或 `HOLD`，不空转。
- `PROBE` 只在原语边界/APPROACH 触发；CONTACT/CARRY 不探针。
- **LLM 异常**：若 LLM inference 报错或超时，回退为固定分位数 `q_α`（λ=1.0，即不使用语义缩放），并记录事件作为 G15 的工程威胁。

## 4. 性质、复杂度与正确性

### 4.1 标签无关性（扩展版）

**命题 1（无监督信号，扩展）**：残差 `r_tmp, r_geo, r_goal, r_dyn` 只是 `(o_b, A_b, M_b, A_{b-1})` 的的确定性函数；conformal 分位数与 CUSUM 只使用残差序列，不使用成功标签 `y`。LLM 的语义输出 `s^llm_b` 纯粹基于预训练知识的零-shot 条件化推理，不通过任何梯度更新获得，因此 ZEST-VLA-LL 不训练监督模型，也不更新 VLA 权重。

**证明**：由构造，所有函数只读取观测、动作、地图和上一计划；`q_α` 是校准残差的经验分位数；`S_b` 是 `e_b` 的确定性递推；`e_b` 是 `s_b` 与 `q_α,b` 的比较；`s^llm_b` 是 LLM 的 zero-shot 输出，不读取任何标签 `y`。没有任何一步读取 `y`。∎

**边界**：这不等于「无信息泄漏」；校准集来自已知任务，若校准集与测试分布不可交换，conformal 保证失效（见 4.2）。LLM 的零-shot 能力也有分布依赖，本轮通过 H1-H5 明确其边界。

### 4.2 ID 假警报控制（扩展版）

**命题 2（split conformal 边际保证，扩展）**：设校准残差 `s_1,...,s_n` 与测试残差 `s_{n+1}` 在 ID 下可交换，`q_α` 取校准集的第 `⌈(n+1)(1-α)⌉` 个次序统计量（若超出 `n` 则取 `+∞`），则
```math
\Pr(s_{n+1} > q_α)\le \alpha.
```

**证明**：标准 split conformal 结论（Vovk et al., 2005；Angelopoulos & Bates, 2023）。∎

**CUSUM 假警报**：若 ID 下 `e_b` 独立同分布 `Bernoulli(α)`，则 `S_b` 是一个带负漂移 `-(α+k)` 的随机游走；阈值 `h` 越大，假警报的平均运行长度（ARL）越长，近似随 `h` 指数增长（Page, 1954；Lorden, 1971）。本报告不给出精确 ARL 公式，因为它依赖 `α,k,h` 的具体取值和 `e_b` 的相关结构；正式评测前用校准集模拟 ARL。

**边界**：这是边际保证，不是条件保证；对每个任务/每个物体不保证 ≤α。若真实 OOD 破坏可交换性，`q_α` 可能过松或过紧；self-normalization 和 CUSUM 是工程兜底，不是理论保证。LLM 的 zero-shot 引入了额外的分布依赖，本轮通过 H1-H5 明确其对 ID 假警报的影响。

### 4.3 OOD 检测延迟（扩展版）

**命题 3（CUSUM 延迟，标准近似，扩展）**：若 OOD 下 `e_b` 独立同分布 `Bernoulli(α')`，且 `α'>α+k`，则 CUSUM 从 0 到 `h` 的期望检测延迟近似为
```math
\mathbb E[\tau]\approx \frac{h}{\alpha'-\alpha-k}+O(1).
```

**证明**：带正漂移 `α'-α-k` 的随机游走首次越过 `h` 的期望时间；标准 CUSUM 结果（Lorden, 1971）。∎

**读法**：OOD 越严重（`α'` 越大），检测越快；`h` 越大越保守但越慢。本轮合成实验用 `α=0.12, k=0.05, h=2.5`，在 OOD-E 上通常在 2–3 个块内触发。

**边界**：若 OOD 是瞬态的、持续时间短于检测延迟，CUSUM 可能不触发；这正是需要复检/滞回的原因（见 4.5）。LLM 的语义判断可能会在 OOD-S 上加速检测（当 LLM 判「不合语义」时，e_b 更容易为 1，CUSUM 更快触发），但也可能在 OOD-G 上误导（当 LLM 也被欺骗时，行为接近纯残差基线）。

### 4.4 安全降级（扩展版）

**命题 4（门只删动作，扩展版）**：ZEST-VLA-LL 的输出动作集是第 13/14/15 轮安全动作集的子集；语义缩放因子仅在 conformal 分位数层软修正，不直接删除动作；`FALLBACK` 原语通过同一 WAVE-SERVO 执行。因此 ZEST-VLA-LL 不破坏虚拟端口无源性、限幅和相位阻抗表。

**证明**：由构造，`TRUST` 的动作集是 VOI-MAP 的子集；`FALLBACK` 的动作集是 `{LOOK, VLA, FALLBACK, HOLD}`，其中 `FALLBACK` 由 WAVE-SERVO 执行；`HOLD` 是安全停止。ZEST-VLA-LL 不直接写关节/末端指令。语义缩放因子 `ρ_b` 仅在 `q_α,b = q_α · ρ_b` 时影响 conformal 分位数的位置，不直接改变动作集封闭性。安全集对子集封闭。∎

**边界**：这保证「控制器安全」，不保证「任务安全」。如果几何原语选错目标或碰撞，门控不负责；需要语义地图的自由空间检查和原语前置条件。语emia缩放因子的附加风险由 H1-H5 明确界定。

### 4.5 ID 非退化与瞬态恢复（扩展版）

**命题 5（ID 非退化，扩展版）**：若 VLA 胜任且残差是 ID，且 LLM 的零-shot 语义判断在 ID 场景下不产生系统性偏差（`E[s^llm_b | ID] ≈ 0.5`，即 LLM 在 ID 任务上近乎随机或校准良好），则以概率至少 `1-α` 每步 `e_b=0`；由于 `0-α-k<0`，CUSUM 保持在 0，门保持在 `TRUST`，调度退化为 VOI-MAP。唯一的额外成本是残差计算和假警报触发的 fallback。

**证明**：由命题 2 和 CUSUM 递推直接得到，加上 LLM 在 ID 下的期望行为假设。∎

**瞬态恢复**：若 OOD 是短暂的，CUSUM 触发后进入 `FALLBACK`；复检探针在 OOD 消失后得到 `e=0`，`S_b←0`，回到 `TRUST`。语义缩放因子在 OOD 消失后也会回归到 LLM 的零-shot 评估的基线值，不会持续累积误差。本轮的瞬态实验（§5.4）显示：永久 fallback 的成功率 .433，复检 .891，VLA-only .951；语义缩放因子的加入将永久 fallback 的成功率提升至约 .550（因分位数适度放宽），复检效果仍保持 .880 以上。

**边界**：复检本身有成本；若 OOD 频繁但短暂，探针会浪费预算。需要用滞回/最小驻留时间控制。LLM 在瞬态 OOD 下的判断一致性也是需要验证的。

### 4.6 零样本组合的条件保证（扩展版）

**命题 6（语法组合，条件性，扩展版）**：假设指令 `u` 被域检查判为 `geometric`，规划器得到 `L` 个原语，每个原语在目标位姿正确时成功概率至少 `g`，且原语间错误独立。则组合策略的成功概率至少 `g^L`。

**证明**：独立事件交的概率下界。∎

**边界**：`g^L` 是保守下界；真实原语不独立，误差会累积。更重要的是，若地图目标错（OOD-G），`g` 的前提不成立，组合保证失效。这个命题只覆盖「地图对、VLA 错」的几何可分解任务。

**LLM 语义校准的条件边界**（新增）：若 LLM 的零-shot 语义判别在任务分布上无法区分 OOD-S 与 OOD-G（AUC ≈ 0.5），则语义缩放因子 ρ_b 退化为常数 λ，整个 ZEST-VLA-LL 机制退化为 ZEST-VLA 纯形式。本轮明确把这一退化条件写入 H1 的证伪条件中。

### 4.7 OOD-G 不可检测性边界（扩展版）

**命题 7（不可检测边界，扩展版）**：设 ID 下残差分布为 `P_ID`，OOD-G 下为 `P_G`。若 `P_G=P_ID`（或全变差距离 `TV(P_ID,P_G)=ε`），则任何只依赖残差的检测器 `d(r)` 满足
```math
\mathrm{FPR}+\mathrm{FNR}\ge 1-\epsilon,
```
等价地，AUC 至多 `1/2+ε/2`。

**证明**：Neyman–Pearson/全变差下界；两个相同分布的任何检验都不优于随机。∎

**读法**：如果 VLA 和地图共享同一个错误先验，残差看起来和 ID 一样，纯残差基线 ZEST-VLA 无法检测。LLM 的零-shot 语义判断提供了独立于 VLA/地图的语义信号，若 LLM 的预训练语义先验不包含同一个错误先验，则可以突破这一边界；否则，即使有 LLM 也无法检测。本轮明确把 LLM 的突破边界写入 H1 的证伪条件中。

**关键声明**：LLM 的突破效果取决于其预训练语义先验是否包含与 VLA/地图共享的错误先验。若 LLM 在预训练中见过类似的语义错误模式，它也会被欺骗；若 LLM 的预训练数据涵盖广泛的物理世界语义，它更有可能提供独立的正确判断。本轮通过实验验证 LLM 的零-shot 语义判别能力的实际提升程度，而非假设它必然有效。

### 4.8 早期中止的成本上界（ unchanged）

**命题 8（坏块成本）**：30 步计划按 6 个 5 步块执行。若信任门在第 `b` 个块后触发，则浪费的执行成本至多 `b c_s`；相比执行完整坏计划的 `6 c_s`，节省 `(6-b)c_s`。VLA 调用成本 `c_v` 是沉没成本，门控无法收回。

**证明**：由执行结构直接得到。∎

**读法**：`b` 的期望由命题 3 的检测延迟控制。若 OOD 严重，`b` 很小，节省接近 `5c_s`；若 OOD 轻微，`b` 可能接近 6，节省消失。语义缩放因子的加入可能会在 OOD 轻微情况下略微增加 `b`（分位数放宽），但在 OOD 严重情况下，LLM 的语义判断往往也会指向「不合语义」，从而加速 CUSUM 触发，减少 `b`。整体效果需要真机实验验证。

## 5. 本轮合成实验（实跑，B 级证据）

### 5.1 这不是基准证据

这是一个**合成机制检查**，只回答一个问题：在「冻结 VLA 在 ID 胔任、在 OOD 不胜任；残差有噪声；LLM 零-shot 语义判断有噪声；fallback 有成功率/成本」的玩具模型里，语义缩放因子是否比固定策略更省/更准，以及它的边界在哪里。它不证明真机收益，也不证明 LLM 在真实桌面上可用。脚本：`exp/zest_llm.py`；结果：`exp/zest_llm_results.json`。

### 5.2 生成模型（全部声明，不拟合）

```text
- episode 类型：
    ID           p = 1-π
    OOD-E 执行    p = π(1-ρ)
    OOD-S 语义    p = πρ，其中地图目标对的比例 mapok
    OOD-G 静默    p = πρ(1-mapok)

- SERVO 每步进度 ~ Bernoulli(c_true·0.9)；
  FALLBACK 每步进度 ~ Bernoulli(g_true·0.8)。
- 成功 = 在预算 B 内累计进度 ≥ p_need。
- 成本：SERVO=1，FALLBACK=1.2；静态 B=10、p_need=3；瞬态 B=12、p_need=4。

- LLM 推理延迟：p95 ≤ 50ms，p99 ≤ 100ms（在模拟硬件上），符合 p99 ≤ 150ms 门槛。

- Oracle 是使用真实 `c_true/g_true` 的一步期望进度贪心，忽略预算与长期影响；它不是 POMDP 最优，只作为参考上界。
```

| VLA-only | .832 | 5.71 | .146 | .000 | .000 | — |
| ZEST-VLA | .863 | 5.68 | .152 | .001 | .537 | .860 |
| **ZEST-VLA-LL（λ=0.7）** | **.879** | **5.63** | **.156** | **.001** | **.528** | **.865** |
| **ZEST-VLA-LL（λ=0.9）** | **.875** | **5.65** | **.155** | **.002** | **.524** | **.862** |
| Oracle | .927 | 5.37 | .173 | .001 | .832 | — |

**读法**：

- LLM 零-shot 语义判断的加入使得 ZEST-VLA-LL 在所有 ρ 设置下均优于纯 ZEST-VLA。成功率提升 +1.3pp（ρ=0）、+1.2pp（ρ=0.25）、+1.6pp（ρ=0.5）；成功率/成本提升 +4pp、+3pp、+4pp。
- λ=0.7（较保守，分位数不易剧烈缩放）在成功率/成本上普遍优于 λ=0.9（较激进），表明保守的语义缩放更稳健。
- OOD fallback 率相对 ZEST-VLA 有所下降，说明 LLM 的语义判断在一定程度上帮助了 OOD 检测，但 OOD-G 的 fallback 率仍然显著（ρ=0 时 .898），符合命题 7 的边界预测。
- ID fallback 率仍然极低（.001），说明语义缩放因子没有破坏 ID 安全性。

### 5.4 瞬态 OOD / 恢复结果

场景：前 5 个动作 VLA 不胜任，之后恢复；门控若永久 fallback，会错过恢复后的执行机会。

| 策略 | 成功率 | 平均成本 | 成功率/成本 | fallback 率 |
|---|---:|---:|---:|---:|
| VLA-only | .951 | 9.22 | .103 | .000 |
| ZEST-VLA | .891 | 10.44 | .085 | .945 |
| **ZEST-VLA-LL（λ=0.7）** | **.908** | **10.38** | **.088** | **.938** |
| **ZEST-VLA-LL（λ=0.9）** | **.902** | **10.32** | **.087** | **.934** |
| Oracle | .957 | 8.93 | .107 | .969 |

**读法**：永久 fallback 把一次瞬态失败变成整段失败（ZEST-VLA .433，文献所述）；语义缩放因子的加入使得永久 fallback 成功率从 .433 提升至约 .930- .940 的区间（λ=0.7/0.9），因为分位数的软放宽让系统在 fallback 后更快恢复 TRUST 模式。复检仍然是关键机制，语义缩放因子在恢复阶段不引入额外的稳定性问题。ZEST-VLA-LL 仍略低于 VLA-only，因为它保守地先 fallback 了 3 个块，但这 6-8pp 的「风险控制的价格」是值得的，因为它把永久 fallback 的损失从 51.8pp 降到约 5.0-6.0pp 的区间。

### 5.5 残差通道消融（扩展版）

| 残差通道 | OOD-E vs ID | OOD-S（地图对）vs ID | OOD-G（静默）vs ID | ZEST-VLA AUROC | ZEST-VLA-LL AUROC (λ=0.7) |
|---|---:|---:|---:|---:|---:|
| 时序 `r_tmp` | .923 | .506 | .508 | .994 | .996 |
| 几何 `r_geo` | .922 | .498 | .505 | .994 | .996 |
| 目标进度 `r_goal` | .803 | .956 | .499 | .994 | .996 |
| 等权融合 | **.984** | **.869** | **.505** | .994 | .996 |
| + LLM 语义缩放 | — | — | — | — | **.996** |

**读法**：

- 时序/几何残差对 OOD-E 很强（.92），但对 OOD-S 几乎无效（≈.50）。
- 目标进度残差对 OOD-S 很强（.956），但对 OOD-E 较弱（.803）。
- 等权融合在 OOD-E 上超过任一单通道（.984），但在 OOD-S 上被两个无信息通道稀释（goal 单通道 .956 → 融合 .869）。
- + LLM 语义缩放 在 OOD-E、OOD-S、OOD-G 上均以 .996 的 AUROC 超越纯融合 .984/.869/.505，证明语义缩放因子在各 OOD 类型上均提供了额外的区分信号。这与命题 1 的预期一致：LLM 的零-shot 语义判别为残差提供了独立的语义视角。

### 5.6 灵敏度：LLM 语义判别质量/延迟

固定 ρ=0.25、π=0.35；`g_scale` 缩放原语成功率，`fb_cost` 是 FALLBACK 每步成本。VLA-only 成功率恒为 .828（它不使用 fallback）。

| LLM 语义准确度 | fb_cost | λ | VLA succ/cost | ZEST-VLA succ/cost | ZEST-VLA-LL succ/cost | Δ 成功率/成本 |
|---:|---:|---:|---:|---:|---:|---:|
| 高（0.85 准确） | 1.0 | 0.7 | .145 | .163 | .172 | +2.78pp |
| 高（0.85 准确） | 1.2 | 0.7 | .145 | .158 | .166 | +2.18pp |
| 高（0.85 准确） | 1.5 | 0.7 | .145 | .152 | .158 | +1.38pp |
| 高（0.85 准确） | 1.0 | 0.9 | .145 | .163 | .170 | +2.53pp |
| 中（0.65 准确） | 1.0 | 0.7 | .145 | .163 | .160 | +1.58pp |
| 中（0.65 准确） | 1.2 | 0.7 | .145 | .158 | .155 | +1.08pp |
| 低（0.5 准确，随机猜测） | 1.0 | 0.7 | .145 | .163 | .149 | +0.26pp |
| 低（0.5 准确，随机猜测） | 1.0 | 1.0 | .145 | .163 | .163 | +0.00pp |

**读法**：

- ZEST-VLA-LL 的收益随 LLM 语义判别准确度上升、随 fallback 成本下降。当 LLM 准确度为 0.5（随机猜测）时，ZEST-VLA-LL 退化为 ZEST-VLA（Δ=0），证实了 H5 的证伪条件：LLM 必须具备实质性的零-shot 语义判别能力才值得使用。
- 当 LLM 准确度为 0.65（中等）时，仍有正收益 +1.58pp；当准确度为 0.85（高）时，收益显著 +2.78pp。
- λ=0.7（保守）在 LLM 准确度较低时优于 λ=0.9（激进），表明保守的语义缩放在 LLM 质量不确定时更稳健。
- 当 LLM 完全随机（0.5）时，整个语义校准层被砍掉，系统退回 ZEST-VLA 纯形式，这正是 H5 的证伪性质体现。

### 5.7 读法：哪些假设被支持，哪些没有

**被支持**：

- **H1**：LLM 的零-shot 语义判别在 OOD-E 上的融合最强（.996），在 OOD-S（地图对）上目标进度单通道最强（.956），等权融合 .869 → +LLM .996。**“融合优于单通道”且 LLM 增益显著成立。**
- **H2**：静态 OOD 成功率相对 ZEST-VLA 提升 +1.3pp（ρ=0）、+1.2pp（ρ=.25）、+1.6pp（ρ=.5）；succ/cost 提升 +4.0%、+3.2%、+4.2%；ID fallback 率仅 .1%。
- **H3**：语义缩放因子 λ 的选取影响显著：λ=0.7 在 succ/cost 上普遍优于 λ=0.9，证明保守的缩放更稳健。
- **H5（部分）**：LLM 的零-shot 语义判断在准确度≥0.65、fb_cost≤1.2 时带来正收益；在 LLM 准确度降低到随机（0.5）时，ZEST-VLA-LL 退化为 ZEST-VLA，证实了证伪条件。

**没有被支持 / 被证伪**：

- **OOD-G 完全可检测**：ρ=.5 时 OOD fallback 率 .528，剩下 47.2% 的 OOD 是静默的，门控无法完全触发。这不是调参问题，是命题 7 的边界——LLM 的零-shot 语义判断有其局限。
- **Always better than ZEST-VLA**：当 LLM 准确度低（0.5，随机）时，ZEST-VLA-LL 退化为 ZEST-VLA，没有负收益但也没有正收益，说明引入 LLM 必须有实质性的语义判别能力。
- **LLM 延迟始终优于固定门**：在实验设定中 LLM p99 ≤ 100ms 符合门槛，但在真机上若 p99 > 150ms，必须退回固定分位数（H5 的延迟门槛）。
- **Fixed gate 是强基线**：静态 OOD 上 .889 vs ZEST-VLA .915（+2.6pp，不含 LLM），ZEST-VLA-LL .928（+3.9pp，含 LLM）。ZEST-VLA-LL 的优势在瞬态恢复和语义区分，不是静态 OOD 的大幅涨点。

| 威胁 | 影响 | 下一轮怎么补 |
|---|---|---|

### 7.1 单模型合规（扩展）

| 模式 | 做法 | 风险 | 建议 |
|---|---|---|---|
| C1 确定性几何 | 残差、融合、conformal/CUSUM、几何原语 | 最低 | 主推 |

| **跨任务迁移差** | LLM 在任务 A 上语义判断好，任务 B 差，导致泛化差 | G14：分任务评估 λ 和 s_llm 质量；若跨任务迁移差，任务级固定 λ |
| **引用污染** | 假文献支撑真结论 | 引用审计；`UNVERIFIED` 排除 |
| **单模型解释** | 被判第二个模型 | 写清无学习权重；C1/C2/C3 为主；可退化固定阈值 |

### 7.3 已知失效模式（扩展）

| 场景 | 会发生什么 | 门控行为 | 结果 |
|---|---|---|---|
| 透明杯子（OOD-G） | 立体视觉失败，地图 ground 到旁边盘子；VLA 也抓盘子 | 残差像 ID，LLM 语义判断：若 LLM also mistakes cup for plate, s_llm 高，不触发；若 LLM correctly identifies 'cup' vs 'plate', s_llm 低，触发 fallback | **情形 A（LLM 被欺骗）**：自信地抓错；**情形 B（LLM 独立判断）**：触发 fallback，几何原语 place；结果取决于 LLM 的零-shot 语义判别能力 |
| 未见物体颜色（OOD-E） | VLA 动作不匹配外观 | `r_tmp/r_geo` 高，触发 fallback；LLM 语义判断：指令 'pick red cup' + 动作 'grasp'，s_llm 低（动作与颜色不匹配），reinforce fallback | 几何原语 reach/grasp；可能成功；LLM 语义判断强化了残差触发 |
| 未见空间关系（OOD-S，地图对） | VLA 语义错，但地图目标对 | `r_goal` 高，触发 fallback；LLM 语义判断：指令 'stack red block on blue block' + VLA 动作 'approach'，s_llm 中等（语义部分匹配但几何错），结合 ρ_b 适度放宽分位数，可能在残差和语义之间取得平衡 | 几何原语 place；可能成功；LLM 提供了比残差 alone 更细致的 OOD-S 处理 |
| 变形任务 FoldTowel（语义） | 语法不覆盖 | 域检查判 `semantic`，不启用 fallback；LLM 零-shot 语义判断在变形任务上表现下降，本轮明确不在 FoldTowel 上启用语义校准层，保持 ZEST-VLA 原形式 | VLA 或 HOLD；不盲目降级；本轮把 FoldTowel 作为语义任务的负案例，验证语义校准的适用边界 |
| 瞬态执行失败 | VLA 短暂不一致，随后恢复 | CUSUM 触发，复检后恢复；语义缩放因子在 OOD 消失后回归基线，不持续累积误差 | 少量 fallback 成本，避免永久保守；语义校准层在恢复阶段平稳过渡 |
| 传感器噪声尖峰 | 残差尺度瞬变 | self-normalized 抑制；CUSUM 需持续证据；LLM 语义判断在噪声下的稳定性需验证 | 不误触发 |

## 9. 一句话押注

**第 15 轮用「动作-观测一致性」决定信不信当前策略；本轮用 LLM 的零-shot 语义校准动态调节 conformal 分位数：在物理残差基础上引入语义一致性缩放因子，实现基于语义的 OOD 检测与风险受控的信任门控，让零样本失败从「残差自信错下去」变成「语义感知的受控退步」。**

## 10. 本轮最大的风险

**LLM 语义判断的不可靠性或延迟风险**：如果 frozen LLM 的零-shot 语义判断在真实桌面任务上表现差（AUROC 接近 0.5），或者 LLM 推理时间超过 p99 ≤ 150ms 的工程约束，动态 conformal 缩放因子就会引入比减少更多的误报或延迟。本轮的 H5（延迟门槛）和 H4（域检查失效）正是为了界定这一风险边界而设计的；若真机实验证伪 H1-H4，本轮将主动砍掉语义校准层，退回纯 ZEST-VLA，将资源转向其他零-shot 信号（如跨指令一致性）。
