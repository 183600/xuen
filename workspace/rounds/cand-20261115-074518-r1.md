# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「MuJoCo」×「异常检测」）

> R69 把「不确定性」拆成 aleatoric / epistemic，并给 epistemic 配了一张嘴：看、问、触。它还用流似然（FMA）做「标定不可吸收的第二意见」。但这条第二意见仍是**自指的**——策略用自己的密度审判自己。R69 自陈的最大风险正是「模态分布不可信」，而 FMA 恰恰建立在这个不可信的分布上；当真实世界进入一个**训练里从未有过的物理机制**（打滑、柔性接触、颗粒、液压迟滞、执行器卡滞），流模型会自信地给出一个「分布内」的模态，FMA 也可能给它低分——**不是因为它对，而是因为它俩错在同一处**。
>
> 本轮两个灵感补上这条缺失的「外部通道」：
> - **MuJoCo** 提供一个**非学习、可审计、带约束**的物理裁判：它不问「像不像训练数据」，只问「**在物理上解释得通吗**」；模型族 + 扰动界给出集合隶属可达管，接触锥、摩擦、执行器模型都是硬约束；
> - **异常检测**提供把它用对的统计纪律：共形预测给出**分布无关的误报率控制**，不要求密度正确；集合隶属给出**单侧可靠性**（模型对则零假阳）。一物理一统计，正好互补。
>
> 核心命题：**在 R69 的 aleatoric / epistemic 之外，增加第三通道——本体不确定性 U_ont（「我脚下的物理还成立吗」）。用 MuJoCo 模型族 + 集合隶属 + 共形异常检测做独立裁判；异常时单调保守，模型类异常时硬升级；并且——这是本轮最关键的一条——模型族的扩张必须受 MDL 预算与外部验证约束，否则裁判会被自己不断放宽的模型族收买，把异常吸收成「新参数」。** 命名 **PARC-RAS**（Physics-Adjudicated Reality Check）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我脚下的物理还成立吗**」——异常不是更大的噪声，是**世界换了一本物理书**。

## 0. 直觉与动机

**灵感 1（MuJoCo → 从「典型性」到「可容许性」）**
直觉：R69 的 FMA 只回答一个问题——这段动作/轨迹**像不像**我见过的。但「像」不等于「可能」。一个平滑、连续、统计上很典型的轨迹，可能**违反摩擦锥**（凭空产生切向力）、**穿透接触面**（负间隙）、**无源加速**（违反能量守恒）。反过来，一个罕见但合法的接触（轮子恰好卡在台阶边缘）统计上 atypical，却完全 admissible。MuJoCo 把这两根轴分开：它编码的是**约束**，不是**频率**。于是「异常」第一次有了一个不依赖训练分布的定义——**在给定模型族与扰动界下不可解释**。

**灵感 2（异常检测 → 物理残差需要统计纪律，否则只是又一个阈值）**
直觉：光有物理残差还不够。真实系统永远有 sim-real gap、未建模柔顺、传感器噪声；一个拍脑袋的 τ_phys 要么天天误报（报警疲劳），要么宽到什么都放过（形同虚设）。异常检测的现代做法给的是**纪律**而不是阈值：共形预测只要求「标定集与测试点可交换」，就能给出有限样本的误报率上界 α——**它不要求流密度正确**，这恰好正面回应 R69 的最大风险。物理给「可容许」，统计给「可控误报」，二者缺一不可。

**灵感 3（本体不确定性 → 第三通道，且 R69 的交互救不了它）**
直觉：R69 的 epistemic 是「**在已知模型里选哪个动作**」，可以靠问/看消解。但如果异常是**模型类**的——世界换了物理机制——再问一百句也没用：你问的是人，不是物理。这类不确定性只能靠**主动激励**（用小而安全的探针把系统推出「不可辨识」的方向）或**安全撤退**来处置。把 U_ont 单列，等于承认：**有些不知道，不是靠问能解决的，而是靠做实验**。这也把 R69 的 g_probe 从「探询」升级为「系统辨识」。

**灵感 4（可辨识性 → 异常检测的「无激励，无检测」）**
直觉：如果一条故障只作用在你**从未激励过**的自由度上（某个关节几乎不动、某个方向的摩擦从未被切向力激发），那么无论检测器多好，残差里都没有它的影子。这不是算法缺陷，是信息论下界：**Fisher 信息为零的方向上，故障不可辨识**。R69 的 VoI 说的是「问之前先算值不值」，R70 要补一句更硬的：**不算激励，连问题都问不出来**。于是异常检测第一次和主动控制闭环：检测器告诉你去激励哪里，激励又让检测器看得见。

**灵感 5（模型族膨胀 → 裁判会被收买，这是递归版的 R68 风险）**
直觉：R68 的风险是标定把缓变故障「解释掉」；R70 有一个同构的风险，而且更高一层：**模型族可以把模型类异常「解释掉」**。每当裁判报警，最省事的做法不是撤退，而是往 Θ 里加一个新参数、一个新接触模型，直到残差归零——**于是异常被吸收成「我早就知道会这样」**。这在数学上等价于「假设类无限灵活 ⇒ 任何有限数据都正常 ⇒ 检测功效为零」。所以本轮必须给模型族扩张上锁：**MDL 复杂度预算 + 留出验证 + 外部独立证据**，三缺一不许扩。裁判的诚实，取决于它**不被允许随意修改自己的物理书**。

**灵感 6（相关盲区 → 独立通道不是免费的）**
直觉：我们说 MuJoCo 是「独立」通道，但独立不是口号。如果策略和裁判共享同一套刚体/接触先验，那么落在**共同盲区**的异常（柔性、颗粒、液压）会让两者同时沉默——**一致地错**，比单独错更危险，因为它看起来像「两个证据源都同意」。所以本轮要显式建模相关性 ρ，并用**模型形式多样性**（刚体 + 软接触 + 数据驱动残差）去解耦，而不是假设它不存在。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（PARC-RAS 总览）** PARC-RAS = (MJM, SMR, CAD, FDI, ASI, MCE, MDL, PSC, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i / R68 定义 276-i）；
(ii) **物理裁判只读、非学习、可复现**：裁判参数不随在线策略更新，任何模型族修改都留痕；
(iii) **异常单调保守**：检测到异常后 λ 不降、安全包络不扩；模型类异常必须硬升级，禁止静默继续；
(iv) **反自我收买**：模型族扩张须同时满足 MDL 预算、留出集验证、外部独立证据（定义 318）。

**定义 311（MuJoCo 模型族 MJM）** 模型族 𝕄 = {(m, θ) : m ∈ ℳ_form, θ ∈ Θ_m}，其中 m 为**模型形式**（刚体 / 软接触 / 摩擦模型 / 执行器模型 / 传感器模型），θ 为形式内参数（质量、惯量、几何、solref/solimp、摩擦系数、增益/偏置/armature/阻尼、噪声）。𝕄 是一个**集合**而非单点；配扰动界 W 与测量不确定度。形式多样性是解耦相关盲区的手段（灵感 6）。

**定义 312（集合隶属可达管 SMR）** 给定 𝕄、W 与初始不确定集 X_0，时刻 t 的可容许状态集
T_t(𝕄) = { x_t : ∃(m,θ)∈𝕄, ∃w_{0:t}∈W^{t+1}, x_{k+1}=f_{m,θ}(x_k,u_k)+w_k }。
观测 o_t **可容许** ⇔ o_t ∈ T_t ⊕ 𝒩_meas。

**定义 313（物理非一致度）** s_phys(o_t,u_t) = min_{(m,θ)∈𝕄} min_{w∈W} ‖o_t − h(f_{m,θ}(x_{t−1},u_{t−1})+w)‖_R。可解释为「要解释这条观测，最少需要多大的未建模力/扰动」。

**定义 314（共形异常检测 CAD）** 在名义标定集上取非一致度分数 s_i，测试点 s 的共形 p 值 p = (1 + #{i: s_i ≥ s}) / (n+1)；p ≤ α 判异常。在可交换性下 FPR ≤ α，**不要求 s 的密度正确**（对 R69 密度不可信的直接回应）。物理硬违反（s_phys 超过测量不确定度）不受 α 约束、直接触发；共形只负责「边界地带」的误报预算。

**定义 315（异常三分与本体不确定性）** A_contact（接触机制改变：打滑/柔性/颗粒/卡滞）、A_fault（执行器/传感器参数偏移）、A_ont（模型类异常：不存在 (m,θ) 能解释）。定义本体不确定性 U_ont = d(𝕄, 观测) 的归一化（「世界离我的物理书有多远」）。U_ont 与 U_ale/U_epi 语义正交，**R69 的交互无法消解它**。

**定义 316（故障签名与判别 FDI）** 签名 σ = (s_phys, s_act, s_sens, s_contact)，分别来自物理残差、执行器残差、传感器自洽、接触流形一致。按故障类分别做元校准（定义 320），输出故障类后验 p(fault | σ)，供仲裁。

**定义 317（可辨识性与主动激励 ASI）** 沿方向 v 的 Fisher 信息 J_v(θ) = E[(∂log p(o|u,θ)/∂θ·v)²]。若 J_v=0，则该方向故障**不可辨识**。激励选择 g* = argmax_g [I_g(θ 或模型形式) − c(g)]，s.t. C-RAS-WM 认证、幅度 ≤ ε_exc、预算未超。可检测性下界：E[s] ≥ c·σ_min(J)^{1/2}‖δ‖ − √(trΣ)。

**定义 318（模型类升级与 MDL 门 MCE）** 若 T_t(𝕄)=∅（或 s_phys 无法被任何 (m,θ) 解释）⇒ 判 A_ont。扩张 𝕄→𝕄' 当且仅当：
ΔMDL = MDL(𝕄') − MDL(𝕄) ≤ B_MDL，且留出名义集验证通过，且**外部独立证据**（不同传感模态 / 不同物理形式）一致。否则**不扩张**，走硬升级（安全撤退 / 请求人类 / 降级到 R68 最保守）。此门是反吸收的核心。

**定义 319（物理安全证书 PSC）** 对候选动作在 𝕄 上做最坏情形 rollout，检查约束集 C（关节限位、力锥、间隙、速度）；全过则发证。与 R68/R69 的学习 WM 证书**取交集**：两者都过才放行，冲突时以更保守者为准并记录。

**定义 320（检测器元校准）** 对每个故障类 c 与每个检测器 j，用标定集估 FPR_{j,c} 与 TPR_{j,c}；若某检测器在类 c 上不可靠（共形覆盖失效、ECE 越界），则在该类上**门控掉**它。R69 的 MCG 是这里的单检测器特例。

**定义 321（三级异常退避与第三通道）** 无异常：走 R69（允许 resolution bonus）；A_fault/A_contact：λ = λ_floor(U_ale + 未消解 U_epi + U_ont)，并进入故障特定安全模式（必要时一次 ASI）；A_ont：**硬升级**——安全停/撤退/人工接管，不得静默继续。单调性：λ_anomaly ≥ λ_nominal，安全包络非增。

**定义 322（参与式审计 VQAuditor-P）** 审计对象新增：误报率漂移、吸收事件（残差被新参数抹平）、模型族扩张记录、相关盲区告警。结论回灌 AuditBuf，成为下一轮 MDL 预算与 α 的先验。

**定义 323（AIC-PARC 异常注入干扰集）** ℰ_PARC = ℰ_FLUID × ℰ_fault × ℰ_regime × ℰ_camouflage × ℰ_corr，其中 ℰ_fault 为执行器/传感器故障，ℰ_regime 为接触机制切换，ℰ_camouflage 为**模型形式伪装**（异常刻意落在 Θ 内、看似只是参数变化），ℰ_corr 为**相关盲区攻击**（同时骗过策略与裁判）。

**定义 324（证书 J_PARC）** J_PARC = (J_FLUID, s_phys_p95, conformal_fpr, fault_posterior, mdl_delta, expansion_log_hash, psc_pass, corr_blindspot_flag, parc_ver)。Valid ⇔ Valid(J_FLUID) ∧ FPR ≤ α ∧ 无未授权扩张 ∧（A_ont 时）已硬升级。

**定义 325（实时预算与 MJX 代理）** 物理裁判只在「可疑触发」（FMA 异常 / 周期性低频 / 共形临界）时运行；用 MJX 批量 GPU rollout + 降阶代理模型守 P99。代理与全模型的分歧本身是一个异常信号。

**定义 326（严格包含关系）** 无异常且 𝕄 可解释时，PARC 逐指令等于 R69；无交互且无异常时等于 R68。R68 ⊂ R69 ⊂ PARC，安全侧逐层不减。

```python
# IP-264 MJM：MuJoCo 模型族（形式 × 参数 × 扰动界），MJX 批量
class MuJoCoModelFamily:
    def __init__(self, forms, theta_prior, W, mjx):
        self.forms, self.theta, self.W, self.mjx = forms, theta_prior, W, mjx

    def sample(self, n):                       # 采样 (m, θ, w) 场景
        return [(sample_form(self.forms), sample_theta(self.theta), sample_w(self.W))
                for _ in range(n)]

    def rollout_batch(self, x0, U, n=256):     # MJX 批量前向（GPU）
        return self.mjx.batch_rollout(x0, U, self.sample(n))

# IP-265 SMR：集合隶属可达管 + 物理非一致度
def set_membership_residual(family, o_t, u_t, x_prev):
    trajs = family.rollout_batch(x_prev, u_t)              # 覆盖 𝕄 × W
    return min(robust_distance(o_t, tr) for tr in trajs)   # 最小所需未建模扰动

# IP-266 CAD：共形异常检测（分布无关 FPR）
def conformal_anomaly(scores_cal, s_now, alpha):
    p = (1 + sum(s >= s_now for s in scores_cal)) / (len(scores_cal) + 1)
    return p, (p <= alpha)                                  # 可交换 ⇒ FPR ≤ α

# IP-267 FDI：故障签名判别
def classify_fault(sig, meta_cal):                          # σ=(s_phys,s_act,s_sens,s_contact)
    return argmax(meta_cal.loglik(fault, sig) for fault in FAULT_TYPES)

# IP-268 ASI：主动激励（复用 R69 g_probe，目标从探询变辨识）
def choose_excitation(family, modes, budget):
    best = None
    for g in excitation_candidates(modes):                  # 小幅、可认证探针
        if not budget.allow(g) or not c_ras_wm.certify_info(g): continue
        score = fisher_info_gain(family, g) - excitation_cost(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None        # 无信息增益则不激励

# IP-269/270 MCE + MDL：模型类升级与反自我收买
def model_class_gate(family, resid, validation, external):
    if resid <= TAU_PHYS: return ('in_family', family)
    cand = propose_expansion(family)                        # 候选新形式/新参数
    if (mdl_delta(cand, family) <= B_MDL
        and validation.passes(cand)                         # 留出名义集
        and external.agrees(cand)):                         # 外部独立证据
        return ('expand', cand)
    return ('ontological_anomaly', None)                    # 拒绝收买 → 硬升级

# IP-271 PSC：物理安全证书（与学习 WM 取交集）
def physics_shield(family, action, x0, constraints):
    return all(constraints.satisfied(s)
               for s in family.worst_case_rollout(action, x0))

# IP-275 PARC 主闭环（继承 R69，在不确定性处置处插入物理裁判）
def PARC_round(M, obs):
    # 1) R69 路径：MTM 前向、标定、流匹配多模态、不确定性二分
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o_obs, o_calibrated)
    # 2) 物理裁判（仅在可疑/周期触发，守实时预算）
    s_phys = M.smr.residual(M.mjm, o_obs, u_last, x_prev)
    p_val, stat_anom = M.cad.test(s_phys)
    fault  = M.fdi.classify((s_phys, a_hat, s_sens, s_contact))
    phys_anom = (s_phys > TAU_PHYS) or stat_anom
    # 3) 异常处置：单调保守；模型类异常硬升级
    U_ont = 0.0
    if phys_anom:
        kind, cand = M.mce.gate(M.mjm, s_phys, M.validation, M.external)
        if kind == 'ontological_anomaly':
            return hard_retreat(M, reason='U_ont')          # 禁止静默继续
        U_ont = normalized_distance(M.mjm, s_phys)
        if fault in ('actuator', 'sensor'):
            g = M.asi.choose_excitation(M.mjm, modes, M.budget)  # 可辨识才激励
    # 4) 沿用 R69：可约则交互消歧，不可约/被污染则保守
    g = (M.mint.choose_interaction(modes, o, M.budget)
         if (U_epi > TAU_EPI and not phys_anom) else None)
    if g is not None: U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    U_floor = U_ale + (U_epi if g is None else 0.0) + U_ont
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    if phys_anom: lam = max(lam, 0.8)                       # 异常单调收紧
    # 5) 物理安全证书 ∩ 学习 WM 证书
    action = M.ach.propose(x_prime, M.vista.H)
    k = M.c_ras_wm.certified_prefix(action, ..., wm_preds)
    if not M.psc.shield(M.mjm, action, x0, M.constraints):
        k = min(k, k_cal_shrink(action, U_cal + U_ont))     # 更保守者胜
    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_p.submit_async(s_phys, fault, kind, M.mjm.expansion_log)
    return k, lam, mode, (U_ale, U_epi, U_ont)
```

## 3. 推导

**引理 19（集合隶属的单侧可靠性）** 若真实系统 (m*,θ*)∈𝕄 且真实扰动 w*∈W，则真实状态 x_t*∈T_t(𝕄)，故在无测量噪声时 s_phys=0；含测量噪声时用鲁棒距离，s_phys 超过测量不确定度 ⇒ **必为异常或模型违反**。即：**模型族正确时零假阳**；代价是 W 越大、功效越低（可容许集变胖）。这是与共形检测对偶的「可靠性—功效」权衡。

**引理 20（共形误报控制，且不依赖密度正确）** 若标定分数与测试分数可交换，则对任意非一致度函数 s，P(p≤α)≤α。故即使 R69 的流密度完全不可信，只要用物理残差作 s 并做共形校准，误报率仍受控。注意其反面：慢漂移破坏可交换性时，需窗口化共形 + CUSUM（定义 320），否则 α 失效。

**引理 21（无激励、无检测）** 设故障沿参数方向 v 偏移 δ，残差灵敏度为 ∂s/∂θ·v。若激励 u 使 J_v=0（该方向未被激发），则 E[∂s/∂θ·v]=0，检测统计量对 δ 无响应：**该故障在原理上不可辨识**。反之 E[s] ≥ c·σ_min(J)^{1/2}‖δ‖ − √(trΣ)。系：异常检测的盲区不是检测器的缺陷，而是**激励的缺陷**；这为 ASI（定义 317）提供了必要性证明，也说明为什么被动监控永远有一块看不见的地方。

**引理 22（模型族膨胀的吸收性——裁判会被收买）** 若允许 𝕄 无复杂度约束地扩张，则对任意有限样本存在 𝕄' 使 s_phys→0，检测功效趋于零：**无限灵活的假设类下，一切异常都可被解释为「新参数」**。引入 MDL 预算 B_MDL 后，可吸收的异常幅度受 ΔMDL 限制；超过预算的模型形式变化只能判 A_ont。故**异常检测只有在「固定或复杂度受限」的假设类下才有意义**——这正是定义 318 三把锁的理论依据，也是 R68「标定吸收」风险的递归版本。

**定理 18（PARC 严格包含 R69）** 在 𝕄 可解释且无异常时，PARC 的两阶段（先物理裁判、后 R69 处置）与 R69 逐指令相同（λ、k、mode 一致）；检测到 A_fault/A_contact 时 λ 单调不降；检测到 A_ont 时硬升级。故任意状态期望风险 ≤ R69，且安全侧不做让步，名义场景保留 R69 的 resolution bonus。R68 ⊂ R69 ⊂ PARC。

**定理 19（裁判独立性的收益与其相关盲区上界）** 设策略通道与物理裁判通道的错误指示变量相关系数为 ρ。加入裁判后的检测增益 ∝ (1−ρ)·(TPR_ref − TPR_policy)；当 ρ→1（共享刚体/接触先验）增益→0，且存在**共同盲区**上的异常被两者同时漏检。故「独立第二意见」不是免费的：必须用**模型形式多样性**（刚体 + 软接触 + 数据驱动残差）压低 ρ；任何声称「两个通道都同意」的结论，都必须先报告 ρ 的估计，否则一致性可能只是同源偏差。

## 6. 本轮最大风险

**一句话**：PARC 的全部可靠性押在「物理裁判与学习策略的盲区不相关」这一假设上——但二者往往共享同一套刚体/接触先验，一旦真实异常恰好落在**共同盲区**（柔性接触、颗粒介质、液压迟滞），系统会面临两难：模型族太窄则**把一切都报成异常**（报警疲劳、频繁硬升级），为消除报警而放宽模型族则**把异常吸收成「新参数」**——**裁判被自己的模型族收买，比没有裁判更危险**。

**次级风险与缓解**：
1. **模型族膨胀吸收异常** → MDL 预算 + 留出验证 + 外部独立证据三把锁（定义 318、引理 22、E308）；
2. **相关盲区（一致地错）** → 模型形式多样性压低 ρ + 显式报告 ρ（定理 19、E309）；
3. **共形可交换性被慢漂移破坏** → 窗口化共形 + CUSUM + 周期重标定（定义 320、E303）；
4. **实时预算被 MJX 击穿** → 仅可疑触发 + 降阶代理 + 代理/全模型分歧作为异常信号（定义 325、E311）；
5. **物理裁判本身是错的形式** → 裁判只做「可容许性」不做「正确性」；A_ont 一律硬升级而非静默外推（定义 321、E306）。

```python
        if fault in ('actuator', 'sensor'):
            g = M.asi.choose_excitation(M.mjm, modes, M.budget)
    g = (M.mint.choose_interaction(modes, o, M.budget)
         if (U_epi > TAU_EPI and not phys_anom) else None)
    if g is not None: U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    U_floor = U_ale + (U_epi if g is None else 0.0) + U_ont
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    if phys_anom: lam = max(lam, 0.8)
    action = M.ach.propose(x_prime, M.vista.H)
    k = M.c_ras_wm.certified_prefix(action, ..., wm_preds)
    if not M.psc.shield(M.mjm, action, x0, M.constraints):
        k = min(k, k_cal_shrink(action, U_cal + U_ont))
    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_p.submit_async(s_phys, fault, kind, M.mjm.expansion_log)
    return k, lam, mode, (U_ale, U_epi, U_ont)
```

## 4. 推导

**引理 19（集合隶属的单侧可靠性）** 若 (m*,θ*)∈𝕄 且 w*∈W，则真实状态在 `T_t(𝕄)` 内，无测量噪声时 `s_phys=0`；含噪用鲁棒距离，超过测量不确定度 ⇒ 必为异常或模型违反。模型族正确时**零假阳**；代价是 W 越大功效越低（可容许集变胖）。

**引理 20（共形误报控制，不依赖密度正确）** 可交换性下对任意分数 `P(p≤α)≤α`。故即使 R69 流密度完全不可信，用物理残差作分数并共形校准，误报率仍受控。反面：慢漂移破坏可交换性时需窗口化共形 + CUSUM。

**引理 21（无激励、无检测）** 故障沿 v 偏移 δ，若激励使 `J_v=0`，则残差对该方向无响应，**原理上不可辨识**；反之 `E[s] ≥ c·σ_min(J)^{1/2}‖δ‖ − √(trΣ)`。系：检测盲区往往是**激励的缺陷**，不是检测器的缺陷——为 ASI 提供必要性证明。

**引理 22（模型族膨胀的吸收性——裁判会被收买）** 若无复杂度约束地扩张 𝕄，则任意有限样本都存在 𝕄' 使 `s_phys→0`，检测功效趋零——无限灵活假设类下，一切异常都可被解释为「新参数」。MDL 预算 B_MDL 限制可吸收幅度，超出者只能判 A_ont。**异常检测只在固定或复杂度受限的假设类下才有意义**，这是定义 318 三把锁的理论依据，也是 R68「标定吸收」的递归版本。

**定理 18（PARC 严格包含 R69）** 无异常且 𝕄 可解释时，PARC 与 R69 逐指令相同（λ、k、mode 一致）；A_fault/A_contact 时 λ 单调不降；A_ont 时硬升级。故任意状态期望风险 ≤ R69，安全侧不让步，名义场景保留 resolution bonus；R68 ⊂ R69 ⊂ PARC。

**定理 19（裁判独立性的收益与相关盲区上界）** 设两通道错误指示变量相关系数 ρ，则加入裁判的检测增益 ∝ `(1−ρ)(TPR_ref − TPR_policy)`；ρ→1（共享刚体/接触先验）时增益→0，且存在共同盲区上的异常被同时漏检。故「独立第二意见」不免费：须用模型形式多样性压低 ρ；任何「两通道都同意」的结论都必须先报告 ρ，否则一致性可能只是同源偏差。

## 7. 本轮最大风险

**一句话**：PARC 的全部可靠性押在「物理裁判与学习策略的盲区不相关」这一假设上——但二者往往共享同一套刚体/接触先验，一旦真实异常恰好落在**共同盲区**（柔性接触、颗粒介质、液压迟滞），系统会面临两难：模型族太窄则**把一切都报成异常**（报警疲劳、频繁硬升级），为消除报警而放宽模型族则**把异常吸收成「新参数」**——**裁判被自己的模型族收买，比没有裁判更危险**。

**次级风险与缓解**：模型族膨胀吸收异常（MDL + 留出验证 + 外部证据三锁，定义 318、引理 22、E308）；相关盲区一致地错（模型形式多样性压低 ρ + 显式报告 ρ，定理 19、E309）；共形可交换性被慢漂移破坏（窗口化共形 + CUSUM + 周期重标定，E303）；实时预算被 MJX 击穿（仅可疑触发 + 降阶代理 + 代理/全模型分歧作异常信号，E311）；裁判形式本身错误（裁判只判可容许性、不判正确性；A_ont 一律硬升级，E306）。
