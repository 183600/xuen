## 1. 两个灵感的第一性原理

### 灵感 1 ·「分层规划」→ 缺的不是更多技能，而是「把技能排成计划、并允许局部回滚」

**直觉解释**：当前 v3 栈把「任务」压平成一串路标（IP-09），技能只是被 MoE（IP-01）条件化地选出来，状态层（IP-13）只做逐点断言。对短任务这够了；但挑战里的 `OrganizeBookshelf`、`ToolboxStorage`、`ArrangePlates` 以及新数据里的装配类任务都是长程多阶段。扁平策略的失败是**指数式复合**：每一步 0.95 的成功率，60 步后只剩 0.05。人做长任务的秘诀不是每一步更准，而是把它切成「先……再……」的子目标，并在某一子目标没做成时**只重做那一段**，而不是从头再来。

**第一性原理拆解**：
- **层次 = 抽象 + 终止判据**。一个子目标只有在「能判断它是否完成」时才有意义；否则只是把扁平序列换了个名字。因此分层规划的第一性问题不是「怎么分解」，而是「**终止判据可信吗、回滚便宜吗**」。
- **反直觉但关键**：如果终止判据完美且不允许重试，纯分解不改变成功率——`p^T = (p^{T/K})^K`。分层的全部收益来自**局部回滚 + 重规划**（把指数复合换成逐段几何重试）与**降低搜索/信用分配难度**；代价是**接口税**（终止检测开销 + 假终止惩罚）。这解释了为什么很多「层级 VLA」论文只在长程任务上有效、在短任务上反而退化（产物区引理 L14）。
- **与现有栈的接口天然存在**：IP-09 是子目标内的执行器；IP-01 的技能词表就是「语法」；IP-13 的卡方断言（U17）就是子目标终止判据；IP-02 的介入家族正好可以升一级，增加 `replan`。所以分层规划不是另起炉灶，而是把 v3 的四个部件用「计划图」串起来。

**严谨定义**：
- **U19（技能语法）**：有限原语集 `S = {reach, grasp, transport, place, insert, pour, fold, open, close, handover, ...}`，每个原语带类型化前置/后置条件；任务 = 语法上的一个计划，而非一段隐式策略。
- **U21（分层计划）**：`Π = (V, E, A, τ, b)`。`V` 是子目标节点（每个节点绑定一个原语或原语序列），`E` 是先后/并发约束，`A: V → Agents` 是执行体分配，`τ: V → {0,1}` 是子目标终止断言（复用 U17），`b: V → ℝ⁺` 是步数预算。单臂是 `|Agents|=1` 的退化情形——这个退化视角是下一节统一两个灵感的关键。

### 灵感 2 ·「多机器人协作」→ 先分清「双臂」与「双机」，再统一为「所有权 + 分配」

**直觉解释**：这次灵感有两条真实支线，必须分开看，否则会做出赛内无法部署的方案：
1. **双臂（bimanual）**：赛内主角是一台 G1，有两条手臂。`双手协调` 已被写进 32 项任务的官方描述。典型收益场景是「一只手稳住、另一只手操作」「大物体双手搬运」「双手交接」——即**并行 + 互补**。
2. **双机（dual-robot）**：新语料里的 `DualRobot_Clean_Table` 与 `Two_Robot_Clean_Table_Left/Right` 是两台机器人协同。但挑战评测是「单个模型 API 接一台真机」，所以双机数据只能作为**协调先验/角色先验的迁移来源**，不能假设赛内会给你两台机器人。**范围声明**贯穿本轮：赛内协作 = 单 G1 双臂；双机数据 = 离线迁移，不改变单 API 合规前提。

**第一性原理拆解**：
- **协作的本质是「分配」而不是「多一个模型」**。把任务拆成子目标后，每个子目标要么给左臂、要么给右臂、要么需要两只手同时；这正好是 U21 里 `A: V → Agents` 这一维。**单臂是 |A|=1，双臂是 |A|=2，双机是 |A|=2 且跨本体**——三者是同一个分配问题的不同规模。因此本轮不新增两套系统，而是给 IP-16 的计划图加一个 agent 维度（IP-17）。
- **协作不是免费的（Amdahl 定律的机器人版）**：可并行的比例 `f`、协调开销比例 `c`（通信、对齐、交接、避碰）决定双手机器人是否真的更快。产物区 L16 给出：双臂加速比 `S = 1 / (1 − f/2 + cf)`，**当且仅当 `c < 0.5` 时协作才严格占优**，且与 `f` 无关。这条结论直接给出设计纪律：**紧耦合任务（`f` 小、`c` 大）宁可串行单臂，也不要做「看起来很高级」的双臂**。
- **冲突来自「所有权不清」**：双抓同一物体、互相等待、路径交叉，本质是共享世界里没有单一所有权。解法不是更复杂的策略，而是**所有权令牌 + 显式交接原语 + 死锁看门狗**（U20）。

**严谨定义**：
- **U20（多智能体共享黑板）**：在 U16 场景图 `M=(T,D,F)` 上增加所有权映射 `ω: Objects ∪ V → Agents ∪ {unowned}` 与计划状态 `π_t`（当前子目标）；所有 agent 只读同一张图，写操作须持有所有权令牌。双机时 `F` 为共享工作台坐标系（首帧锚定，两机共视）。

### 统一视角（本轮的核心洞见）

**分层规划与多机器人协作是同一件事的两个维度**：计划图 `Π` 的每一层是「子目标分解」，横向每一列是「把子目标分配给哪个执行体」。分解解决「长程复合」，分配解决「并行/互补」。两者共用一个接口——**子目标终止断言（U17）**和**步数预算（L15）**——所以应实现为一个「计划-分配」层（IP-16 计划器 + IP-17 协作层），而不是两个互不相干的模块。

## 2. 研究问题（新增 Q13–Q15，接第 1–3 轮 Q1–Q12）

- **Q13（分解与终止的可靠性）**：从演示语料（IP-06 阶段标注 + 110 个 Dex1 任务）自动切出的子目标边界，F1 能到多少？U17 终止断言的**假终止率 β** 能否压到让局部回滚净收益为正（L14）？（E634 / E635）
- **Q14（预算分配）**：在「成功率 + 步骤分」综合排序下，显式给子目标分配步数预算（L15）是否严格优于贪心执行？「及时止损」能否避免为不可完成计划烧光预算？（E636）
- **Q15（协作的盈亏与迁移）**：挑战中的双臂任务里，可并行比例 `f` 与协调开销 `c` 是否满足 `c<0.5`（L16）？双机 Left/Right 数据能否迁移到单机双臂的角色分配？所有权协议能否把双抓/死锁压到可忽略？（E638 / E639 / E640）

## 3. 设计原则（新增 P13–P15，接第 1–3 轮 P1–P12）

- **P13（可回滚才分解 / No rollback, no hierarchy）**：只在「终止判据可靠且回滚便宜」的边界分解；否则保持扁平 IP-09。分解前必须先测边界 F1 与假终止率 β（E634 门槛），不得凭直觉切任务。
- **P14（预算即资源）**：每个子目标、每个 agent 都有显式步数预算；计划器必须能「止损」（剩余预算 < 完成下界时放弃并重规划），禁止无界重试。预算分配按 L15 的边际收益均衡。
- **P15（所有权单一 / Single owner）**：任一时刻每个物体/子目标最多一个 owner；所有权只经显式 `handover` 原语转移；共享黑板（U20）是所有权唯一事实源。所有权不清时默认「不抢、等待或交还」，而非盲目竞争。

## 5. 本轮最大风险

**子目标假终止（false termination）——计划器「自信地宣布这一步做完了」，后续子目标在错误状态上继续，且因为高层已判成功而更难被下层发现；它和上一轮的「地图毒化」是同一种病（在错误锚点上自信失败），但对长程任务的伤害更大。** 对冲：①终止断言必须「U17 卡方 + 驻留确认 + 下一子目标前条件交叉校验」三重；②E634 边界 F1 与 β 不达标就不分解（P13）；③预算看门狗 + Level-1.7 降级回扁平。次要风险：接口税吃掉收益（过度分解）、协作开销超过并行收益（L16，`c≥0.5` 时回退串行）、双机→双臂域差导致角色先验负迁移。

- **定义 U21（分层计划）**：`Π = (V, E, A, τ, b)`；`V` 子目标（绑定 U19 原语或子计划），`E ⊆ V×V` 先后/并发约束，`A: V → Agents`，`τ: V → {pass, fail, uncertain}` 为终止断言（U17 三区），`b: V → ℝ⁺` 步数预算。单臂 = `|Agents|=1`。

```python
# ===== IP-16: 计划构建（离线模板 + 在线检索；无运行时 LLM）=====
def build_plan(task_token, blackboard):
    templates = PLAN_LIB.retrieve(task_token, blackboard.scene_signature())
    plan = best_by_expected_score(templates, blackboard)   # success*step，见 L15
    allocate_budget(plan, B_total)                          # 见 L15/KKT
    return plan

# ===== IP-16: 子目标执行与局部回滚（三重终止校验）=====
def run_subgoal(v, obs, blackboard):
    for _ in range(v.budget):
        a = IP09.executor.step(v, obs, blackboard)         # 路标内伺服
        if assert_waypoint(v.wp, blackboard.state, obs):
            if dwell_ok(v) and next_precondition_ok(v, blackboard):
                return "done"                               # 三重通过才判完成
        if abort_condition(v, blackboard):                  # 预算耗尽/高置信失败
            return "fail"
    return "fail"

def execute(plan, obs, blackboard):                         # 分层主循环
    for v in plan.topological():
        r = run_subgoal(v, obs, blackboard)
        if r == "fail":
            if not replan(plan, v, blackboard):             # IP-02: replan 阶梯
                return "abort"
    return "success"
```

```python
# ===== L15: 预算分配（边际收益均衡 + 止损）=====
def allocate_budget(plan, B):
    # q_k(b) = 1 - exp(-lambda_k * b)，最大化 Π q_k(b_k)，Σ b_k ≤ B
    # KKT: lambda_k e^{-lambda_k b_k} / (1 - e^{-lambda_k b_k}) = mu  （对活跃项）
    b = water_filling(plan.nodes, B, rate=plan.lambda_)
    for v in plan.nodes:                                    # 止损
        v.b = b[v]
        if B_remaining < min_cost_to_finish(v):
            plan.mark_abandon(v)
    return b
```

```python
# ===== IP-17: 所有权 / 交接 / 死锁看门狗 =====
def claim(agent, obj, B):
    if B.omega.get(obj) in (None, "unowned"):
        B.omega[obj] = agent; return True
    return B.omega[obj] == agent                       # 单一所有权：不抢

def handover(src, dst, obj, obs):
    if not claim(src, obj, B): return False
    if not release_ready(src, obs): return False       # 先稳定、再释放
    B.omega[obj] = dst
    return assert_handover(obj, obs)                   # 双夹爪闭合 + 相对位姿稳定

def deadlock_watchdog(B, idle_cnt, T_DEAD):
    if idle_cnt[L] > T_DEAD and idle_cnt[R] > T_DEAD:  # 双方都等

    if double_grasp(B): return "YIELD_TO_OWNER"         # 交还并退让
```

## 7. 推导（新增引理 L14–L16；L1–L13 沿用第 1–3 轮）

**引理 L14（分层收益 = 局部回滚 − 接口税）** 设单步成功率 `p`，任务长度 `T`。扁平（失败后从头重来）的期望步数 `C_flat = T / p^T`。将任务切成 `K` 段、每段 `τ=T/K`、段成功率 `q=p^τ`，且段内失败可回滚到段首重做，则 `C_hier = Σ_k τ/q_k + K·o = T·p^{-T/K} + K·o`（`o` 为每段终止检测开销）。比值 `C_hier/C_flat ≈ p^{T(1-1/K)} < 1`（`p<1`），即**只要回滚可行，分层就把指数复合换成逐段几何重试**。但若终止断言有假阳率 `β`（未完成却判完成），每次假终止引入下游返工期望 `R`，则分层占优的充要条件为 `T(p^{-T/K} − p^{-T}) > K·o + K·β·R`。⇒ **分层的瓶颈不是分解粒度，而是终止判据的假阳率与接口成本**；这直接推出 P13 与 E634 的门槛。∎

**引理 L15（跨子目标预算的边际均衡与止损）** 设备选子目标 `k` 的成功率 `q_k(b)=1−e^{−λ_k b}`、相互独立，目标为在 `Σ b_k ≤ B` 下最大化 `Π q_k(b_k)`（成功率项）。取对数并用 KKT，活跃子目标满足 `λ_k e^{−λ_k b_k}/(1−e^{−λ_k b_k}) = μ`，即**边际成功增益/步相等**；`λ_k` 越大（越难）分到越多预算，但受凹性约束不会无限倾斜。若目标还含步骤分惩罚（每步成本 `κ`），则用 `log q_k − κ b_k` 替代，KKT 右端改为 `μ+κ`，最优预算整体下移——**分数口径决定「多试几次」还是「早点止损」**。当剩余预算低于完成下界时，任何正预算都劣于放弃并重规划（P14 止损）。∎

**引理 L16（双臂/双机的 Amdahl 型加速条件）** 归一化任务总工作量 1，其中可并行比例 `f`（可同时由两臂完成），串行比例 `1−f`（必须单臂/顺序）。双臂协调开销按并行工作量的比例 `c` 计（对齐、通信、交接、避碰）。则单臂时间 `T_1=1`，双臂时间 `T_2=(1−f)+f/2+c·f`；加速比 `S = 1/(1−f/2+c·f)`。`S>1 ⇔ c<1/2`，**与 `f` 无关**；但 `S` 的大小随 `f` 增大而增大（`f→1` 时 `S→1/(1/2+c)`）。⇒ **判据是协调开销是否低于并行工作量的一半**；紧耦合任务（`f` 小、`c` 大）应保持串行单臂（P15 / Level-1.75），这也是 E638 的门槛。∎
