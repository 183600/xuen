# 第 62 轮（承接第 61 轮「具身语义进化闭环」IP-173~182；灵感循环第 1 轮；本轮灵感：「SLAM」×「小样本学习」）

> 第 61 轮 ESEC 把「场景语义、意图语义、阻抗、证据」统一进 USR，用 MEL 做零样本物理推断，用 DMS 做多轮对话，用 SRT-Dual 解耦语义流与实时流，用 PCE+++++ 做六维预算。但它留下四个核心局限：
> 1. **语义锚点没有「空间身份」**：`Anchor_t` 只是时间轴上的一次快照，同一张桌子第二次进入时会被当成一个全新锚点，**没有地标 id、没有位姿、没有回环边、没有跨 session 记忆**。更危险的是，USR 的嵌入碰撞（两个不同地点 scene_emb 很接近）与 SLAM 的「感知混淆（perceptual aliasing）」是同一个数学现象，第 61 轮却没有任何机制区分「真的回到了老地方」与「只是看起来像」。
> 2. **零样本 ≠ 可适应**：MEL 的 ZSSG 是一次性泛化，遇到真正的新材质只能带着系统性偏差硬跑；真实系统需要「摸 K 次就能校正」的小样本适应能力，而第 61 轮既无 support set、无元学习、无测试时适配，也无防灾难遗忘。
> 3. **感知是被动的**：MEL/DMS 只消费当前观测，从不会主动决定「往哪看、摸哪里、问什么」才能最快降低不确定性；PCE 预算里也没有「建图成本」与「元学习/适配成本」。
> 4. **泛化保证缺空间-物理联合项**：位姿协方差如何放大阻抗保守裕度、K-shot 证据如何收紧安全界、回环误匹配如何污染物理先验，三者从未被写进同一个安全证书。

## 0. 直觉与动机

**灵感 1（SLAM → 度量-语义锚点地图 MSSAM）**
直觉：第 61 轮的 USR 是一块「语义黑板」，写完就擦；SLAM 的核心遗产是**地标（landmark）**——每个地标有 id、位姿、协方差，以及连接它们的因子图。把 `Anchor_t` 升级为**度量-语义锚点地图**：节点 = 语义地标 `(id, pose ∈ SE(3), scene_emb, φ_phys, Σ_pose, Σ_phys, visits)`，边 = 里程计约束、语义相似约束、回环约束。关键洞见：**语义不是快照，而是地图上的持久地标**；同一地点被再次观测时做贝叶斯融合（visits++，Σ 收缩），于是「第 N 次进同一房间」不必重新零样本推断，只需少量验证。位姿协方差还天然给出「定位越不确定、阻抗越保守」的物理安全裕度。

**灵感 2（SLAM 回环检测 → 语义回环验证 SLCV）**
直觉：SLAM 最难的从来不是「认出相似」，而是「拒绝假相似」。USR 的嵌入碰撞与之同构：两个不同地点的 `scene_emb` 余弦相似度很高，若直接融合，**错误的语义/物理先验会通过图优化传播到整张地图，比单帧错误更难恢复**。因此回环必须三重验证：描述子候选 → 几何一致性（特征 RANSAC 内点率、位姿图可达性）→ 物理一致性（`φ_phys` 是否相容）。验证失败但描述子相似 ⇒ 标记为**别名集 A_alias**，降低该描述子权重，并触发主动探测消歧。关键洞见：**「语义像」不等于「空间是」；回环验证是把语义嵌入从「相似性」提升为「可辨识性」的桥梁**。

**灵感 3（小样本学习 → 小样本物理先验元学习 FSPM）**
直觉：零样本先验是「常识」，小样本适应是「上手摸两下就懂」。把物理属性推断写成**元学习任务分布**：每个任务 τ 对应一种材质/物体，support set 是 K 次交互得到的 `(观测, φ̂)`，其中 `φ̂` 由力-位移斜率、阶跃响应、滑移起始比、断裂事件概率**自监督反演**成伪标签。用 episode 式元训练得到基先验 `θ`，测试时只训练一个**低秩适配器 Δθ（‖Δθ‖ ≤ ε_adapt）**，并做安全投影与置信度回退。关键洞见：**小样本不是把大模型再训一遍，而是在安全信任域内做一次低秩、可回退、可审计的局部校正**；适配失败就退回基先验，而不是让系统「越学越自信地错」。

**灵感 4（主动 SLAM × 主动学习 → 主动小样本探索 AFSE）**
直觉：不确定性有两个来源——**我在哪（位姿熵）**和**它是什么（物理熵）**。主动 SLAM 选择「往哪走能最快定位」，主动学习选择「摸哪里能最快认识材质」，二者可以统一为同一个信息价值目标：`VOI(a) = 期望熵减 − 动作成本 − 安全风险`，动作集 `{move, look, touch, ask, wait}`。关键洞见：**探索不是随机试错，而是买信息**——只有当信息的边际价值超过动作的边际成本与风险时才行动；这也把「问用户一句」与「多摸一次」放进同一把经济尺子。

**灵感 5（元-持续对话 + 记忆巩固 → MCDM + SSMC）**
直觉：第 61 轮 DMS 每次从零开始对话；真实用户有稳定偏好（「我总是要轻一点」）。用**用户原型记忆**做 few-shot 个性化，用 EWC + episode replay 做**防灾难遗忘**，用规则安全掩码保证个性化永不越过 ERTC 约束。地图侧同理：新 session 的新地标不能覆盖旧地标，需要「睡眠期」记忆巩固——回放、剪枝、原型合并。关键洞见：**空间记忆与对话记忆共享同一套「巩固-回放-防遗忘」机制**。

**灵感 6（六灵感合流 → SSEL 空间锚定小样本具身闭环 + PCE+++++++ 八维预算）**
直觉：MSSAM 回答「在哪」，FSPM 回答「是什么、摸几次就够」，SLCV 回答「别把相似当相同」，AFSE 回答「下一步该看/摸/问哪里」，MCDM 回答「怎么和人把意图对齐」，SSMC 回答「怎么不忘记」。预算从六维扩到八维，新增 `B_map`（建图/回环/位姿图优化）与 `B_meta`（support 大小/适配步数/适配器秩/回放）；任一耗尽都退化为「冻结地图 + 基先验 + 更保守阻抗」，实时契约永不降级。

## 1. 形式化定义（增量：定义 173–184）

**定义 173（度量-语义锚点地图 MSSAM）** 地图 `M_t = (V_t, E_t, X_t, Z_t, Φ_t, Σ_t, L_t)`：
- **节点（语义地标）**：`v_i = (id_i, session_i, p_i ∈ SE(3), z_i ∈ ℝ^{d_us}, φ_i, Σ_i^pose, Σ_i^phys, t_i, visits_i)`，其中 `z_i` 复用第 61 轮 USR 的 scene_emb，`φ_i` 为物理先验。
- **边**：里程计边 `(i,j,u_ij,Σ_ij^odo)`、语义边 `(i,j,s_ij,Σ^sem)`、回环边 `(i,j,T_ij^loop,Σ^loop)`。
- **因子图优化**：
  `X*, Z*, Φ* = argmin Σ_odo ‖log(ΔT_ij^{-1} T_i^{-1} T_j)‖²_{Σ_odo} + Σ_sem ‖z_i − z_j‖²_{Σ_sem} + Σ_loop ‖log((T_ij^loop)^{-1} T_i^{-1} T_j)‖²_{Σ_loop} + Σ_phys ‖φ_i − φ_j‖²_{Σ_phys}`。
- **地点查询**：`d_place(i) = λ_d(1 − cos(z, z_i)) + λ_g ‖p − p_i‖²_{Σ_i^pose} + λ_φ ‖φ − φ_i‖²_{Σ_i^phys}`；`d_place < τ_place` 且再观测验证通过 ⇒ 复用节点并做贝叶斯更新（`visits++`，`Σ ← (Σ^{-1} + Σ_obs^{-1})^{-1}`），否则新建地标。
- **多 session 持久化**：地图跨 session 保存；新 session 以「重定位」而非「从零」开始。

**定义 174（语义回环验证 SLCV）** 候选对 `C = {(i,j): d_desc(z_i,z_j) < τ_desc, |t_i − t_j| > τ_min}`，验证分数：
- 几何内点率 `ρ_ij = inlier_ratio(RANSAC(match(o_i, o_j)))`
- 里程计/位姿图一致性 `g_ij = exp(−‖log((T_ij^odo)^{-1} T_i^{-1} T_j)‖² / σ_g)`
- 物理一致性 `h_ij = exp(−‖φ_i − φ_j‖²_{Σ_φ} / σ_h)`
- 接受条件：`ρ_ij ≥ ρ_min ∧ g_ij ≥ g_min ∧ h_ij ≥ h_min ∧ cycle_consistent(i,j)`。
- **别名检测**：若 `d_desc < τ_desc` 但验证失败 ⇒ `(i,j) ∈ A_alias`，`w_ij ← w_ij(1 − η_alias)`（降低该描述子权重），置 `alias_flag = 1` 并触发 AFSE 主动消歧。

**定义 175（小样本物理先验元学习 FSPM）** 元任务 `τ ~ p(τ)`，每个任务对应一种材质/物体，其真实物理属性为 `φ_τ`：
- **support 集**：`S_τ = {(o_k, φ̂_k)}_{k=1..K}`，`φ̂_k` 由交互信号自监督反演：`k̂` 取 `F-x` 线性回归斜率，`η̂` 取阶跃响应衰减，`μ̂` 取滑移起始力比，`σ̂` 取断裂事件似然。
- **基先验** `f_θ`，**低秩适配器** `Δθ = ABᵀ`，`rank(ABᵀ) = r`，信任域 `‖Δθ‖_F ≤ ε_adapt`。
- **内层适配**：`Δθ*(θ, S_τ) = argmin_{‖Δθ‖ ≤ ε_adapt} Σ_{(o,φ̂)∈S_τ} ℓ(f_{θ+Δθ}(o), φ̂) + λ‖Δθ‖²`。
- **元目标**：`min_θ 𝔼_{τ~p(τ)}[ L_{Q_τ}(θ + Δθ*(θ, S_τ)) ]`。
- **安全投影与回退**：`φ_out ← Proj_{Φ_safe}(φ_out)`；若适配置信度 `c < c_min` 或适配损失未下降 ⇒ 回退基先验并放大方差 `Σ_φ ← Σ_φ · γ_fallback`。
- **伪标签偏差**：`b_φ = 𝔼[φ̂ − φ_τ]`，实验中须标定并纳入风险界。

**定义 176（小样本-空间联合泛化界）** 对目标任务 `τ ~ p_test`、K-shot support，以概率 `≥ 1 − δ`：
```
R_Q(θ') ≤ R̂_S(θ') + sqrt( (C(Θ) + ln(1/δ)) / (2M) )      # 元训练任务数 M
                 + L_adapt · ε_adapt                        # 适配器复杂度
                 + δ_shift                                  # 元任务分布漂移
                 + O( sqrt( (d_eff + ln(1/δ)) / K ) )       # K-shot 有限样本
                 + L_pose · 𝔼[ sqrt(λ_max(Σ_pose)) ]        # 位姿不确定性
                 + L_b · ‖b_φ‖                              # 伪标签偏差
```
其中 `d_eff` 为有效维度，`L_adapt, L_pose, L_b` 为对应 Lipschitz 常数。**解读**：增加 K 与 M、收紧 `ε_adapt` 会降低界；但若定位很差（`λ_max(Σ_pose)` 大）或伪标签有系统偏差，后两项会主导——这正是必须做 SLCV 与 AFSE 的数学理由。

**定义 177（主动小样本探索 AFSE）** 信念 `b = (b_map, b_phys)`，熵 `H(b) = λ_p H_pose + λ_φ H_phys`：
- 动作 `a ∈ {move(v), look(region), touch(obj), ask(q), wait}`；
- `VOI(a) = 𝔼_{o~p(o|b,a)}[ H(b) − H(b|o,a) ] − λ_c c(a) − λ_r r(a)`；
- 选择 `a* = argmax_a VOI(a)  s.t.  c(a) ≤ B_active, r(a) ≤ r_max`；
- 在自适应次模（adaptive submodularity）假设下，贪婪策略达到最优熵减的 `1 − 1/e` 近似。

**定义 178（元-持续对话管理 MCDM）** 在 DMS 上增加：
- **用户原型记忆** `P = {p_u ∈ ℝ^{d_u}}`，`p_u ← (1−β)p_u + β·mean_embed(dialogues_u)`；
- **元策略** `π_meta(·|s, e_u)` 跨用户/任务训练，few-shot 个性化（K 条对话）；
- **防遗忘**：`Ω(θ) = Σ_i F_i(θ_i − θ_i*)^2`（EWC）+ episode replay（比例 `ρ_rep`）；
- **安全掩码**：`A_safe(s) = {a : c(a) 满足 ERTC}`，`π_mcdm = Mask(π_meta)`；
- **遗忘界**：若 `ρ_rep ≥ ρ_min` 且 EWC 系数足够大，则后向迁移 `BWT ≥ −ε_forget`。

**定义 179（空间-语义联合对账 XMC++++）** 在 XMC+++ 上增加空间与物理通道：
```
D⁺_ss = D⁺_sem + λ_pose·ρ_pose + λ_loop·(1 − ρ_ij) + λ_phys·d_phys
C_ss   = exp(−D⁺_ss / σ_ss) ∈ [0,1]
alias_flag = 1[ d_desc < τ_desc ∧ (ρ_ij < ρ_min ∨ d_phys > τ_φ) ]
若 alias_flag：C_ss ← C_ss·(1 − η_alias)，并触发 AFSE 消歧
```

**定义 180（空间-小样本联合证书 J_ss）**
```
J_ss = ( J_sem_exec, Σ_pose, ρ_loop, K_support, ‖Δθ‖_F,
         R̂_bound, alias_flag, map_version )
Valid(J_ss) ⇔ Valid(J_sem_exec)
            ∧ tr(Σ_pose) ≤ ε_pose
            ∧ ρ_loop ≥ ρ_min
            ∧ R̂_bound ≤ ε_risk
            ∧ (alias_flag = 0 ∨ disambiguated)
```

**定义 181（八维认知-空间-元学习预算 PCE+++++++）** `B_cog8 = (B_scene, B_intent, B_ros, B_exec, B_mel, B_usr, B_map, B_meta)`：
- `B_map = (Update_freq, LC_candidates, PGO_iters, Map_memory)`；
- `B_meta = (K_support, Adapt_steps, Adapter_rank, Replay_size, Forgetting_tol)`；
- `cost_cog8 = cost_cog5 + λ_map(LC_candidates/N_lc + PGO_iters/Max_iters + Map_memory/Mem_max) + λ_meta(K/K_max + Adapt_steps/Steps_max + Replay/Replay_max)`；
- **降级**：`B_map` 耗尽 ⇒ 冻结地图、关闭回环、放大 `Σ_pose`、阻抗保守；`B_meta` 耗尽 ⇒ 关闭测试时适配、回退基先验、放大 `Σ_φ`。**实时流永不因建图/元学习而降级。**

**定义 182（空间锚定小样本具身闭环 SSEL）**
```
SSEL(M, Obs, L, δ_f):
  # 异步语义-空间流（~10–100Hz）
  v_obs, T_obs, P_obs ← Obs
  cand ← MSSAM.query_place(E_scene(v_obs), pose, φ_prev)
  if cand is not None:
      loop ← SLCV.verify(cand, v_obs, φ_prev)
      if loop.accepted: MSSAM.bayesian_update(cand, ...); MSSAM.add_loop_closure(...)
      elif loop.alias:  alias_flag ← 1
  φ_base, U_mel ← MEL.infer(...)
  if K_support ≥ K_min and B_meta 可用:
      φ_fs, c_fs ← FSPM.adapt_and_predict(support_set, Obs)   # 低秩 + 安全投影
  else: φ_fs ← φ_base
  a_diag ← MCDM.step(U_mel, e_u)
  if alias_flag or U_mel.epistemic > τ_unc:
      b ← AFSE.run(belief, candidates)                        # 主动看/摸/问
  MSSAM.add_anchor(pose, z_scene, φ_fs, Σ_pose, Σ_phys)
  # 同步实时流（~1–10kHz，不变）
  anchor, fresh ← USR.read_latest_anchor()
  K_prior ← Π(anchor.scene_emb + anchor.intent_emb)
  K_safe  ← EEIS.compile_with_phys_prior(δ_f, K_prior, φ_fs, Σ_pose, U_mel)
  ERTC.dispatch(K_safe); EV_exec ← wait_contact()
  J_ss ← build_joint_certificate(EV_exec, XMC++++(...), MSSAM.version, ...)
  return M, K_safe, EV_exec, J_ss
```

**定义 183（感知混淆下的可辨识性）** 对地点对 `(i,j)` 定义可分边界 `m_ij = max(d_desc(z_i,z_j) − τ_desc, 几何可分度, 物理可分度)`。地点集合是 `ε_alias`-可辨识的，若对所有 `i ≠ j` 有 `m_ij ≥ 0` 且严格裕度成立；此时假回环概率满足 `P(假回环) ≤ N_c · p_col · p_geo`（`N_c` 候选数，`p_col` 描述子碰撞率，`p_geo` 几何验证误接受率）。若不可辨识，则必须由 AFSE 主动探测，直到可分边界转正。

**定义 184（小样本-空间联合安全泛化）** 若 `K ≥ K_min`、`R̂_bound ≤ ε_risk`、`tr(Σ_pose) ≤ ε_pose`、`P(假回环) ≤ ε_alias`，且适配输出经 `Φ_safe` 投影，则 EEIS 编译的 `K_safe` 以概率 `≥ 1 − α` 包含真实安全阻抗集合；其中 `α = α_risk + α_pose + α_alias` 为三类误差的并集界。此定义把「摸几次」「定位多准」「回环多可信」统一进同一个安全概率。

## 2. 关键推导

**2.1 假回环上界（定义 174/183）**
对 `N_c` 个候选对，任一假回环需同时发生「描述子碰撞」与「几何误接受」，独立近似下
`P(至少一次假回环) ≤ 1 − (1 − p_col p_geo)^{N_c} ≤ N_c p_col p_geo`。
故 `ρ_min` 越严、RANSAC 内点阈值越紧，`p_geo` 指数下降；而 `τ_desc` 越松，`p_col` 线性上升。**回环召回与语义记忆污染之间存在可量化的权衡曲线**，这正是 SLCV 要做「先松召回、再严验证」的原因。

**2.2 位姿不确定性 → 阻抗安全裕度（定义 173/184）**
设真实接触点 `p*` 与估计位姿的偏差服从 `N(0, Σ_pose)`。取保守裕度
`γ(Σ_pose) = 1 + κ·sqrt(λ_max(Σ_pose))`，
则 EEIS 可用 `K_p ← K_p/γ`、`K_d ← K_d·γ`、`F_max ← F_max/γ` 实现「定位越糊、动作越软」。该式把 SLAM 的协方差直接变成控制层的安全旋钮，避免「语义很自信、定位很漂移」的隐性风险。

**2.3 小样本界的可操作性（定义 176）**
`O(sqrt(d_eff/K))` 项说明：K 从 1 增到 5 时该项约降 `sqrt(5) ≈ 2.24` 倍；但若 `L_pose·sqrt(λ_max(Σ_pose))` 与 `L_b‖b_φ‖` 不降，增加 K 的收益会被地板效应吃掉。因此**「多摸几次」必须与「先定位准、先校正伪标签偏差」联合设计**，否则只是昂贵的自我安慰。

**2.4 VOI 贪婪近似（定义 177）**
在自适应次模假设下，贪婪选择满足 `H(b_0) − H(b_T) ≥ (1 − 1/e)·OPT`。直觉：每次「看/摸/问」的信息增益边际递减，故贪心不会太差；这为「最多 10 步主动探索」提供了理论依据。

## 3. 实验设计 E201–E209（摘要）

| 实验 | 核心指标 | 目标 |
|---|---|---|

### IP-183 MSSAM（度量-语义锚点地图）

```python
class MetricSemanticAnchorMap:
    def __init__(self, d_us=256, max_nodes=10000,
                 tau_place=0.25, w=(0.5, 0.3, 0.2)):
        self.nodes = {}                 # id -> AnchorNode
        self.edges = []                 # (i, j, type, T_ij, Sigma, weight)
        self.pose_graph = FactorGraph()
        self.next_id = 0
        self.last_node = None
        self.map_version = 0
        self.alias_set = set()
        self.tau_place = tau_place
        self.w = w                      # (desc, pose, phys) 权重

    def query_place(self, z, pose, phi):
        best, best_d = None, float("inf")
        for nid, n in self.nodes.items():
            d = (self.w[0] * (1 - cosine(z, n.scene_emb))
                 + self.w[1] * mahalanobis(pose, n.pose, n.Sigma_pose)
                 + self.w[2] * mahalanobis(phi, n.phys_prior, n.Sigma_phys))
            if d < best_d:
                best, best_d = nid, d
        return best if best_d < self.tau_place else None

    def bayesian_update(self, nid, pose, z, phi, S_pose, S_phys, obs):
        n = self.nodes[nid]
        n.pose = information_fuse_pose(n.pose, n.Sigma_pose, pose, S_pose)
        n.Sigma_pose = fuse_cov(n.Sigma_pose, S_pose)
        n.scene_emb = normalize(0.8 * n.scene_emb + 0.2 * z)
        n.phys_prior = information_fuse_phys(n.phys_prior, n.Sigma_phys, phi, S_phys)
        n.Sigma_phys = fuse_cov(n.Sigma_phys, S_phys)
        n.visits += 1
        self.map_version += 1
        return n

    def add_anchor(self, pose, z, phi, S_pose, S_phys, obs, session_id):
        nid = self.query_place(z, pose, phi)
        if nid is not None and self.reobserve_ok(nid, obs, phi):
            return self.bayesian_update(nid, pose, z, phi, S_pose, S_phys, obs), False
        nid = self.next_id
        self.next_id += 1
        self.nodes[nid] = AnchorNode(nid, session_id, pose, z, phi,
                                     S_pose, S_phys, obs, visits=1)
        if self.last_node is not None:
            T_ij = relative_pose(self.nodes[self.last_node].pose, pose)
            self.edges.append((self.last_node, nid, "odom", T_ij, S_pose, 1.0))
        self.last_node = nid
        self.map_version += 1
        return self.nodes[nid], True

    def add_loop_closure(self, i, j, T_ij, rho, d_phys):
        if rho >= RHO_MIN and d_phys <= TAU_PHI:
            self.edges.append((i, j, "loop", T_ij, sigma_loop(rho), rho))
            self.optimize(iters=self.pgo_iters)
            self.map_version += 1
            return True
        self.alias_set.add((i, j))
        self.nodes[i].desc_weight *= (1 - ETA_ALIAS)
        self.nodes[j].desc_weight *= (1 - ETA_ALIAS)
        return False

    def optimize(self, iters=20):
        X = self.pose_graph.optimize(self.nodes, self.edges, iters=iters)
        for nid, pose, S_pose in X:
            self.nodes[nid].pose = pose
            self.nodes[nid].Sigma_pose = S_pose
        return X

    def reobserve_ok(self, nid, obs, phi):
        n = self.nodes[nid]
        return (descriptor_consistent(obs, n.obs_ref)
                and mahalanobis(phi, n.phys_prior, n.Sigma_phys) < TAU_PHI)
```

### IP-184 SLCV（语义回环验证）

def semantic_loop_closure_verify(map_, i, j, obs_i, obs_j, phi_i, phi_j):
    z_i, z_j = map_.nodes[i].scene_emb, map_.nodes[j].scene_emb
    d_desc = 1 - cosine(z_i, z_j)

    if d_desc > TAU_DESC:
        return LoopResult(candidate=False)

    rho = ransac_inlier_ratio(match_features(obs_i, obs_j))
    g = geometric_consistency(map_, i, j)                 # 位姿图/里程计可达性
    h = exp(-mahalanobis(phi_i, phi_j, SIGMA_PHI))
    cycle_ok = cycle_consistent(map_, i, j)

    accepted = (rho >= RHO_MIN) and (g >= G_MIN) and (h >= H_MIN) and cycle_ok
    alias = (not accepted) and (d_desc < TAU_DESC)

    if alias:
        map_.alias_set.add((i, j))
        map_.nodes[i].desc_weight *= (1 - ETA_ALIAS)
        map_.nodes[j].desc_weight *= (1 - ETA_ALIAS)

    return LoopResult(candidate=True, accepted=accepted, rho=rho, g=g,
                      h=h, cycle_ok=cycle_ok, alias=alias,
                      d_desc=d_desc)

```python
class FewShotPhysicalMetaLearner:
    def __init__(self, base_model, rank=8, eps_adapt=0.1, steps=5, lr=1e-3):
        self.theta = base_model.parameters()
        self.adapter = LowRankAdapter(rank)
        self.rank = rank
        self.eps_adapt = eps_adapt
        self.steps = steps
        self.lr = lr
        self.phi_safe = PhysicalSafeSet()

    def estimate_pseudo_labels(self, trials):
        """从力-位移/滑移/振动信号自监督反演物理属性伪标签。"""
        out = []
        for tr in trials:
            k_hat = fit_stiffness(tr.F, tr.x)            # 线性回归斜率
            eta_hat = fit_damping(tr.F, tr.xdot)         # 阶跃响应衰减
            mu_hat = slip_onset_ratio(tr.F_normal, tr.F_tangent)
            sigma_hat = brittle_event_prob(tr.vibration, tr.force_spike)
            out.append(PhysLabel(mu_hat, k_hat, eta_hat, sigma_hat))
        return out

    def adapt(self, support_obs, support_phi):
        A, B = self.adapter.init()
        for _ in range(self.steps):
            pred = self.forward(support_obs, A, B)
            loss = mse(pred, support_phi) + 1e-4 * (A.norm() ** 2 + B.norm() ** 2)
            A, B = grad_step(loss, A, B, self.lr)
            A, B = project_frobenius(A, B, self.eps_adapt)   # 信任域投影
        return A, B

    def predict(self, obs, A=None, B=None):
        phi = self.forward(obs, A, B)
        phi = self.phi_safe.project(phi)                     # 物理安全投影
        conf = self.confidence(obs, phi)
        if conf < C_MIN:
            phi = self.base_prior(obs)                       # 回退基先验
            phi.cov = phi.cov * FALLBACK_INFLATE
        return phi, conf

    def meta_train(self, task_batch):
        meta_loss = 0.0
        for task in task_batch:
            A, B = self.adapt(task.support.obs, task.support.phi)
            meta_loss += mse(self.forward(task.query.obs, A, B), task.query.phi)
        return meta_loss / len(task_batch)
```

### IP-186 AFSE（主动小样本探索）

```python
class ActiveFewShotExplorer:
    def __init__(self, map_, meta, budget, lam=(0.5, 0.5), lam_c=0.1, lam_r=1.0):
        self.map = map_
        self.meta = meta
        self.budget = budget
        self.lam_p, self.lam_phi = lam
        self.lam_c, self.lam_r = lam_c, lam_r

    def entropy(self, b):
        return self.lam_p * b.H_pose + self.lam_phi * b.H_phys

    def voi(self, a, b):
        H0 = self.entropy(b)
        H1 = expected_entropy_after(a, b)      # 高斯近似 / 采样估计
        return (H0 - H1) - self.lam_c * a.cost - self.lam_r * a.risk

    def select(self, b, candidates):
        feasible = [a for a in candidates
                    if a.cost <= self.budget.B_active and a.risk <= R_MAX]
        return max(feasible, key=lambda a: self.voi(a, b), default=Wait())

    def run(self, b, candidates, max_steps=10):
        for _ in range(max_steps):
            if b.H_phys < H_PHYS_STOP and b.H_pose < H_POSE_STOP:
                break
            a = self.select(b, candidates)
            if isinstance(a, Wait):
                break
            o = execute_action(a)
            b = bayes_update(b, a, o)
            self.budget.consume_active(a.cost)
        return b
```

class MetaContinualDialogueManager(DialogueManagementSystem):
    def __init__(self, *args, replay_size=200, ewc_lambda=0.5,
                 beta=0.3, **kwargs):
        super().__init__(*args, **kwargs)
        self.user_prototypes = {}
        self.replay = deque(maxlen=replay_size)
        self.ewc = EWCRegularizer(ewc_lambda)
        self.beta = beta

    def personalize(self, user_id, dialogues):
        proto = mean_embedding([self.embed(d) for d in dialogues])
        old = self.user_prototypes.get(user_id)
        self.user_prototypes[user_id] = (
            proto if old is None else (1 - self.beta) * old + self.beta * proto
        )
        return self.user_prototypes[user_id]

    def select_action(self, state, user_id):
        e_u = self.user_prototypes.get(user_id, self.default_proto)
        a = self.meta_policy.select(state, e_u)
        a = self.safety_mask(a, state.C_exec)      # 规则硬约束优先
        self.replay.append((state, a))
        return a

    def consolidate(self):
        for s, a in self.replay:
            self.meta_policy.update(s, a)
        self.ewc.penalize(self.meta_policy)        # 防灾难遗忘

class SpatialMetaBudget(CognitiveSemanticBudget):
    def __init__(self, map_freq=2, lc_candidates=10, pgo_iters=20,
                 map_mem=10000, k_support=5, adapt_steps=5,
                 adapter_rank=8, replay_size=200, forgetting_tol=0.05,

                          pgo=pgo_iters, mem=map_mem)

                           replay=replay_size, forget_tol=forgetting_tol)

        self.meta_ops = 0
        self.map_frozen = False
        self.meta_frozen = False

    def can_loop_close(self):
        return (not self.map_frozen) and self.map_ops < self.B_map["lc"]

    def can_adapt(self):
        return (not self.meta_frozen) and self.meta_ops < self.B_meta["steps"]

    def degrade(self, map_latency, adapt_loss, bwt):
        if map_latency > MAP_LAT_MAX or self.map_ops >= self.B_map["pgo"]:
            self.map_frozen = True
        if (adapt_loss > self.B_meta["forget_tol"]
                or bwt < -self.B_meta["forget_tol"]
                or self.meta_ops >= self.B_meta["steps"]):
            self.meta_frozen = True

    def voi_cog8(self, action):
        base = self.voi_cog5(action)
        cost_map = 0.1 * (action.lc_candidates / self.B_map["lc"])
        cost_meta = 0.2 * (action.adapt_steps / self.B_meta["steps"])
        return base - cost_map - cost_meta

| MCDM | O(1)/轮 + O(replay)/巩固 | O(replay) | BWT ≥ −ε_forget；安全掩码保证 ERTC 可行 |
| SSMC | O(N log N)/巩固 | O(N) | 回放 + EWC 保持旧任务性能 |
| PCE+++++++ | O(1) | O(1) | 任一预算耗尽触发对应安全降级 |
| SSEL 实时流 | 不变（≤ 1ms，不含 EEIS 优化） | 共享内存 | 建图/元学习异步，绝不阻塞实时流 |

**正确性定理（SSEL-Complete）**
假设 A61–A70 及：
**(A71) MSSAM**：因子图在给定初值下收敛到局部最优；位姿协方差估计一致（NEES 落在 χ² 置信带内）。
**(A72) SLCV**：几何验证误接受率 `p_geo` 有界；描述子碰撞率 `p_col` 有界；物理一致性对异材质可分。
**(A73) FSPM**：元任务分布覆盖目标分布（漂移 `δ_shift`）；伪标签偏差 `‖b_φ‖` 有界；适配器在信任域内且安全投影不排除真实解。
**(A74) AFSE**：VOI 关于动作集自适应次模；动作风险 `r(a) ≤ r_max`。
**(A75) MCDM**：安全掩码保证所有输出动作满足 ERTC；replay 覆盖历史任务分布。
**(A76) SSMC**：EWC + 回放使巩固后旧任务性能下降 ≤ ε_forget。
**(A77) PCE+++++++**：八维预算单调消耗；`B_map`/`B_meta` 耗尽只触发保守降级，不降低实时安全性。
**(A78) 双流隔离**：建图/元学习全部异步，实时流只读语义锚点与物理先验快照。

则：
1. **空间一致性**：无假回环时，多 session 位姿图 ATE ≤ 2cm；重定位时间 ≤ 0.5s；同地点复用使物理先验方差单调收缩。
2. **别名安全**：`P(假回环) ≤ N_c p_col p_geo`；被拒绝的别名进入 `A_alias` 并触发主动消歧，语义记忆污染概率 ≤ ε_alias。
3. **小样本安全泛化**：`K ≥ K_min` 且 `R̂_bound ≤ ε_risk` 时，EEIS 编译的 `K_safe` 以概率 ≥ 1−α 覆盖真实安全阻抗（定义 184）。
4. **主动探索效率**：在自适应次模假设下，贪婪 AFSE 的熵减 ≥ (1−1/e)·OPT；达到同一不确定性阈值所需探测次数比随机策略少 ≥ 50%。
5. **对话-空间联合接地**：MCDM 个性化后任务完成率 ≥ 90%，BWT ≥ −5%，安全违规率 = 0%；回环/别名事件可经 DMS 触发澄清。
6. **预算安全性**：`B_map` 耗尽 ⇒ 冻结地图、放大位姿协方差、阻抗保守；`B_meta` 耗尽 ⇒ 回退基先验、放大物理协方差；实时契约不退化。
7. **端到端**：相对第 61 轮 ESEC，未见场景 few-shot 成功率 +30%，适应时间 −60%，假回环率 ≤ 0.5%。

## 5. 本轮最大风险

**一句话**：若回环验证把「语义相似但空间不同」的地点误判为同一地标，错误位姿与错误物理先验会沿因子图传播并污染整张地图（**空间记忆污染**），其恢复难度远高于单帧错误；必须以「几何-物理双重验证 + 别名集 + 地图版本回滚 + 位姿协方差驱动的保守阻抗」构建空间安全护栏。
