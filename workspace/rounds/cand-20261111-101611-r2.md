# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 2 轮；本轮灵感：「知识图谱」×「多任务学习」）

> 第 54 轮把技能组合做成动作空间上的可判定图搜索，并用联合证书 `J=(ρ,A_cert,γ_ce,δ_a)` 绑定云边对齐。本轮追问一个更根本的问题：**这些证书的知识从哪来、能不能跨任务复用？** 核心矛盾：**H22** 组合证书在跨任务迁移时依赖隐式的任务相关性，知识图谱里的结构关系与多任务共享表征不一致，导致证书“引用可追溯但语义不可迁移”；**H23** 手工/仿真得到的技能关系图天然不完备，知识图谱补全的链接预测误差会被组合与迁移证书逐层放大为系统性误判。

## 0. 直觉与动机

**灵感 1（从“组合图”升级为“技能知识图谱” → 证书第一次拥有出处）**
直觉：第 54 轮的 `G_S` 只有“技能—技能”一种边，信息太薄。真实世界里一条组合之所以可信，是因为它背后有一串**有类型的关系证据**：技能需要某动作原子、动作原子在某种鲁棒维度上会退化、某种失败模式曾在仿真中被解释为某动作越界。把这些建成**技能知识图谱 SKG**：节点类型 `{Skill, ActionAtom, Task, RobustDim, FailureMode}`，边类型 `{composes_with, requires_action, conflicts_with, transfers_to, degrades_on, explains}`。于是组合不再是“找一条技能路径”，而是**在 SKG 上回答一条元路径查询**，而每个证书都能指回它引用的那张**溯源子图**。证书从此有出处，而不是拍脑袋的标量。

**灵感 2（多任务学习 → 把 ρ 从“一个谱”变成“任务条件下的谱族”）**
直觉：同一个技能在“抓取”任务里鲁棒，不代表在“递送”任务里鲁棒。鲁棒谱应是**任务条件化**的 `ρ_S^{(t)}(d)`，而不是全局 `ρ_S(d)`。用**共享编码器 + 任务私有头**的多任务结构：共享部分学“动作原子—鲁棒维度”的通用关系，私有头学任务特有的敏感性。这样小样本技能可以从关系先验里借力，但必须警惕**负迁移**——共享表征把任务 A 的偏置灌进任务 B。

**灵感 3（关系化多任务学习 → 在图上做消息传递，多头部联合预测）**
直觉：把 SKG 当作归纳偏置，用**关系感知的消息传递（R-GCN/注意力）**做共享编码器，配多个头分别预测：动作兼容性、动作剖面、任务条件鲁棒谱、失败模式。这等价于**把“组合可判定”变成多任务监督下的链接/属性预测**。好处是缺边可补、冷启动有先验；坏处是预测误差会顺着证书链传播，所以必须给每条预测带上**置信度**并与证书门限联动。

**灵感 4（负迁移门控 → 迁移不是“能迁”，而是“迁移风险可承受”**）
直觉：知识图谱里存在 `transfers_to` 边，不代表迁过去会更好。真正决定跨任务迁移能否发生的，是**任务亲和度** `A_{ij}` 与**梯度冲突**：若两任务共享层梯度方向长期相反（余弦 < 0）或标签分布漂移过大，则负迁移风险高。把“亲和度 + 冲突”做成一个**负迁移门控 NTG**，只有 `A_{ij} ≥ θ_aff` 且 `NT(i→j) ≤ B_nt` 才允许跨任务复用证书。

**灵感 5（证书的第三只脚 → 溯源 + 亲和 + 动作-鲁棒）**
直觉：第 54 轮的联合证书只有“动作 + 鲁棒”两只脚；在知识图谱与多任务设定下必须长出第三只脚——**溯源与迁移资格**。新证书 `J_KG=(ρ^{(t)}, A_cert, P_prov, a_mt, δ_a, evidence)`：`P_prov` 是证书所依赖的 SKG 子图，`a_mt` 是跨任务亲和度。缺了这只脚，证书就只是“本任务此刻的断言”，不能作为可迁移知识。

**灵感 6（知识-任务金字塔）**
直觉：在第 54 轮 `𝕃`（鲁棒）与 `𝔸`（动作）之上，再叠一层 `𝕂`（知识）与一层 `𝕄`（多任务）：`𝕂_0` 实体/关系本体，`𝕂_1` 技能—动作—鲁棒关系子图，`𝕂_2` 溯源与链接置信，`𝕂_3` 跨任务元路径；`𝕄_0` 单任务头，`𝕄_1` 共享表示，`𝕄_2` 任务亲和/冲突，`𝕄_3` 迁移资格。跨层证书必须同时携带 `ρ^{(t)}`、`A_cert`、`P_prov`、`a_mt` 四元证据。

## 1. 形式化定义（增量：定义 121–127）

**定义 121（技能知识图谱 SKG）**
`SKG = (E, R, τ_E, τ_R)`，实体集合 `E = E_S ∪ E_A ∪ E_T ∪ E_D ∪ E_F` 分别为技能、动作原子、任务、鲁棒维度、失败模式；关系 `R ⊆ E × τ_R × E`，`τ_R = {composes_with, requires_action, conflicts_with, transfers_to, degrades_on, explains}`。每条关系边携带**置信度** `w_r ∈ [0,1]` 与**出处** `src_r`（仿真 / 日志 / 专家 / 链接预测）。

**定义 122（元路径与组合查询）**
元路径 `π = e_0 \xrightarrow{r_1} e_1 \xrightarrow{r_2} … \xrightarrow{r_k} e_k`。给定任务 `T` 的动作需求 `A_T`，**组合查询**为在 `SKG` 上求满足 `π` 的实体路径集合 `Π(T) = {p | p ⊨ π ∧ cover(p, A_T)}`。路径置信度沿边取几何平均：`conf(p) = (∏_{e∈p} w_e)^{1/|p|}`。

**定义 123（任务条件鲁棒谱与共享-私有分解）**
技能 `S` 在任务 `t` 上的鲁棒谱 `ρ_S^{(t)} : 𝔇_ρ → [0,1]`。共享-私有分解：`ρ_S^{(t)}(d) = h_θ(E_φ(S,d)) ⊕ g_{ψ_t}(E_φ(S,d))`，其中 `E_φ` 为 SKG 上的关系感知共享编码器，`g_{ψ_t}` 为任务私有头，`⊕` 为可学习的门控融合。

**定义 124（任务亲和度）**
任务 `i,j` 的亲和度 `A_{ij} = (1/|D|) Σ_{d∈D} CKA(H_i^d, H_j^d) · sign(cos(∇_φ L_i, ∇_φ L_j))`，`CKA` 为表征相似度，第二项惩罚梯度冲突。仅当 `A_{ij} ≥ θ_aff` 时认为两任务“可共享知识”。

**定义 125（负迁移风险）**
迁移 `i→j` 的负迁移风险
```
NT(i→j) = α·max(0, -cos(∇_φ L_i, ∇_φ L_j)) + β·D_KL(P_i(y|x) || P_j(y|x)) + γ·(1 - A_{ij})
```
迁移资格门控：`NT(i→j) ≤ B_nt`。

**定义 126（知识图谱增强联合证书）**
`J_KG = (ρ^{(t)}, A_cert, P_prov, a_mt, δ_a, evidence)`：
- `ρ^{(t)}` 为任务条件鲁棒谱；
- `A_cert = (A_core, A_buffer, δ_a)` 沿用第 54 轮动作占用证书；
- `P_prov ⊆ SKG` 为**溯源子图**（证书推理实际引用的实体/关系子图）；
- `a_mt = (A_{t,t'}, NT(t'→t))` 为迁移资格；
- `evidence` 至少含链接预测置信、边端反例、MTL 验证损失。部署条件：`dom_J(T)=in`、`δ_a<Θ_a`、`a_mt` 通过门控、`P_prov` 溯源校验通过。

**定义 127（溯源忠实性与组合可判定条件）**
`P_prov` 对证书决策**忠实**，当且仅当移除 `P_prov` 会使证书断言翻转（必要性），且加入 `P_prov` 足以复现断言（充分性）。组合可判定条件：
```
conf(π) ≥ θ_kg ∧ cover(p,A_T) ∧ ρ^{(t)}_{comp}(d) ≥ ρ_min ∀d
∧ NT(t'→t) ≤ B_nt ∧ faithful(P_prov)
```

## 2. 关键算法 伪代码

### IP-121 SKG Builder（知识图谱构建）

```python
def build_skg(skill_lib, sim_logs, explanations, experts):
    G = TypedGraph()
    for s in skill_lib:
        G.add_node(s.id, type='Skill')
        for a in s.action_atoms:
            G.add_node(a, type='ActionAtom'); G.add_edge(s.id, a, 'requires_action', w=1.0)
        for d in s.robust_dims:
            G.add_node(d, type='RobustDim')
    for exp in explanations:                      # Explain -> FailureMode -> degrades_on
        f = G.upsert(exp.root_cause, type='FailureMode')
        G.add_edge(exp.skill, f, 'explains', w=exp.confidence)
        G.add_edge(f, exp.dim, 'degrades_on', w=exp.confidence)
    for (si, sj, gain) in experts.transfer_claims:
        G.add_edge(si, sj, 'transfers_to', w=gain)
    return calibrate_weights(G, sim_logs)        # 置信度校准
```

### IP-122 KGLink（关系感知链接/属性预测）

```python
def kg_link_predict(SKG, relation, theta_conf=0.8):
    enc = RGCN(SKG, layers=2, hidden=128)         # 关系感知共享编码器
    scores = link_head(enc)                       # 对每类关系各一个头
    for (h, r, t), s in scored_edges(SKG, relation):
        if s.prob >= theta_conf:
            SKG.add_edge(h, t, r, w=float(s.prob), src='link_prediction')
    return SKG, scores
```

### IP-123 MTL-Rho（任务条件鲁棒谱多任务学习）

```python
def train_mtl_rho(SKG, tasks, encoder, heads, steps):
    for step in range(steps):
        batch = sample_multi_task(tasks)
        h = encoder(SKG, batch)
        losses = [task_loss(heads[t], h, batch[t]) for t in tasks]
        grads = [grad(losses[t], encoder.params()) for t in tasks]
        grads = pcgrad(grads)                     # 投影消解梯度冲突
        encoder.step(sum(grads))
        for t in tasks: heads[t].step(grad(losses[t], heads[t].params()))
        affinity = cka_matrix(h, tasks)
        nt = negative_transfer_matrix(grads, affinity, batch)
        if step % eval_every == 0:
            heads = task_group_prune(heads, affinity, nt, B_nt)
    return encoder, heads, affinity, nt
```

### IP-124 MetaPathComp（元路径约束的组合搜索）

```python
def metapath_compose(SKG, task, A_T, theta_kg, rho_min, nt_budget):
    best = None
    for pi in enumerate_metapaths(task, max_len=L_max):
        for path in kg_query(SKG, pi, goal=task):
            if not cover(path, A_T): continue
            if conf(path) < theta_kg: continue
            if not nt_gate(path, task, nt_budget): continue
            rho = compose_task_rho(path, task)
            if min(rho.values()) < rho_min: continue
            cost = path_cost(path)
            best = min(best, (cost, path, rho), key=lambda x: x[0])
    return best
```

### IP-125 ProvCert（溯源证书与忠实性校验）

```python
def provenance_certificate(cert, SKG, decision, model):
    P_prov = min_subgraph(SKG, cert.used_edges)   # 证书实际引用的边
    if flip_on_remove(model, decision, P_prov) != decision:
        return ('reject', 'not_necessary', P_prov)
    if reproduce_on_insert(model, decision, P_prov) != decision:
        return ('reject', 'not_sufficient', P_prov)
    return ('ok', J_KG(cert.rho, cert.A_cert, P_prov, cert.a_mt, cert.delta_a))
```

### IP-126 NTG + XTaskCert（负迁移门控与跨任务证书迁移）

```python
def cross_task_certify(J_src, t_src, t_dst, SKG, B_nt, theta_aff):
    if not path_exists(SKG, t_src, t_dst, 'transfers_to'): return ('reject','no_meta_path')
    A = affinity[t_src][t_dst]; NT = nt[t_src][t_dst]
    if A < theta_aff or NT > B_nt: return ('reject','negative_transfer', A, NT)
    rho_dst = adapt_head(J_src.rho, heads[t_dst], SKG)
    if min(rho_dst.values()) < rho_min: return ('reject','rho_fail', rho_dst)
    return ('ok', J_KG(rho_dst, J_src.A_cert, J_src.P_prov, (A,NT), J_src.delta_a))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| SKG Builder | O(|E|+|R|+|log|·|E_F|) | O(|E|+|R|) | 关系抽取精度、置信校准 |
| KGLink | O(L·(|R|·|E|·d + |R|·d²)) | O(|E|·d+|R|·d²) | 链接预测校准、置信下界 |
| MTL-Rho | O(T·B·d²) / step | O(|φ|+Σ|ψ_t|) | 梯度冲突可控、亲和度无偏 |
| MetaPathComp | O(|Π|·(L_max·|E|+k·|A|)) | O(|Π|·L_max) | 元路径生成 sound、conf 单调 |
| ProvCert | O(|P_prov|·C_model) | O(|P_prov|) | 移除/插入必要性充分性 |
| NTG/XTask | O(|T|²·d+|P_prov|) | O(|T|²) | NT 上界闭合、门控不误放 |

**正确性定理（Knowledge-Task Transferable Composition Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** 组合实际使用的元路径上，SKG 关系完备率 ≥ `κ_kg`，链接预测假阳性率 ≤ `ε_link`；**(A30)** 共享编码器的 MTL 干扰满足 `|ρ^{(t)}_shared - ρ^{(t)}_single| ≤ β_mt`；**(A31)** 溯源子图忠实性校验通过率 ≥ `κ_prov`；**(A32)** 负迁移门控的估计误差 ≤ `ε_nt`。则部署成功概率：
```
P_success ≥ 1 - Σ_d(1-ρ_min^{(t)}(d)) - β_E - β_mt
            - P(δ_a>Θ_a) - ε_link - ε_nt - (1-κ_prov) - (1-κ_kg)
```
关键：**知识先验只在被溯源证实后才可入证书**，**跨任务复用必须先过亲和的负迁移门控**，**链接补全误差必须显式计入成功下界**。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| SKG 关系缺失 / 补全幻觉 | 高 | 置信阈值 + 溯源必要充分性 + 人工抽检 |
| 多任务负迁移 | 高 | PCGrad + 任务分组剪枝 + NTG 硬门控 |
| GNN 过平滑 / 长尾关系欠拟合 | 中 | 残差 + 关系特定参数 + 长尾重采样 |
| 溯源子图不忠实（事后编故事） | 高 | 移除/插入反事实检验 + 最小子图约束 |
| 亲和度估计有偏 | 中 | 多随机种子 + held-out 任务验证 |
| 证书链误差累积 | 高 | 每层显式预算 + 端到端反例回归 |

## 6. 本轮最大风险

**一句话**：知识图谱与多任务学习把证书从“本任务断言”提升为“可溯源、可迁移的知识”，但其 soundness **同时押注于 SKG 关系完备、链接预测校准、MTL 无负迁移、以及溯源子图忠实**四件事；其中最危险的是**溯源忠实性被“事后合理化”污染**——模型先给结论再挑一条看似合理的元路径，于是证书在跨任务时引用了一条结构上成立、语义上错误的迁移链，且因“有出处”而更难被质疑，故必须以**反事实移除/插入检验 + 链接置信下界 + 负迁移硬门控 + 跨任务回滚绊线**四重护栏，宁可不迁移，也绝不把“有出处的错误”包装成可迁移知识。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（SKG×KGLink×MTL-Rho×MetaPath×ProvCert×NTG）

> 承接第 54 轮产物 v31。本轮在“动作-鲁棒双证书”之上，补上证书的**知识来源与跨任务迁移资格**，新增六大算子：
> - **SKG（Skills Knowledge Graph）**：`{Skill, ActionAtom, Task, RobustDim, FailureMode}` 类型化知识图谱，技能关系第一次有类型、有出处、有置信；
> - **KGLink（KG Link/Attribute Prediction）**：关系感知编码器补全缺失关系，输出带置信度的候选边；
> - **MTL-Rho（Multi-Task Robustness Spectrum）**：共享-私有分解的任务条件鲁棒谱 `ρ^{(t)}`，PCGrad 抑制梯度冲突；
> - **MetaPathComp（Meta-Path Composition）**：把组合从“技能图路径”升级为“SKG 元路径查询”；
> - **ProvCert（Provenance Certificate）**：为每条证书抽取溯源子图 `P_prov` 并做移除/插入反事实校验；
> - **NTG/XTask（Negative-Transfer Gate / Cross-Task Certificate）**：以任务亲和度与负迁移风险为硬门控，决定证书能否跨任务复用。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-115/116/118/120 以纳入知识图谱与多任务维度。

| `E_φ, g_{ψ_t}` | 共享关系编码器 / 任务私有头 |
| `A_{ij}` | 任务亲和度（CKA × 梯度方向） |
| `NT(i→j)` | 负迁移风险 |
| `P_prov` | 证书溯源子图 |
| `J_KG=(ρ^{(t)},A_cert,P_prov,a_mt,δ_a,evidence)` | 知识图谱增强联合证书 |
| `a_mt=(A_{t,t'},NT(t'→t))` | 迁移资格二元组 |
| `κ_kg, ε_link, κ_prov, ε_nt` | 图谱完备率 / 链接假阳率 / 溯源通过率 / NT 估计误差 |

### IP-121 SKG Builder

```python
def build_skg(skill_lib, sim_logs, explanations, experts):
    G = TypedGraph(types={'Skill','ActionAtom','Task','RobustDim','FailureMode'})
    for s in skill_lib:
        G.add_node(s.id, 'Skill')
        for a in s.action_atoms:
            G.add_node(a, 'ActionAtom'); G.add_edge(s.id, a, 'requires_action', w=1.0, src='spec')
        for d in s.robust_dims:
            G.add_node(d, 'RobustDim'); G.add_edge(s.id, d, 'degrades_on', w=0.5, src='spec')
    for exp in explanations:                    # 第 53/54 轮 Explain 的直接产物
        f = G.upsert(exp.root_cause, 'FailureMode')
        G.add_edge(exp.skill, f, 'explains', w=exp.confidence, src='sim')
        G.add_edge(f, exp.dim, 'degrades_on', w=exp.confidence, src='sim')
    for (si, sj, gain) in experts.transfer_claims:
        G.add_edge(si, sj, 'transfers_to', w=gain, src='expert')
    return calibrate_confidences(G, sim_logs)   # 用仿真日志做保序回归校准
```

### IP-122 KGLink

```python
def kg_link_predict(SKG, relations, theta_conf=0.8):
    enc = RGCN(SKG, layers=2, hidden=128, rel_specific=True)
    heads = {r: LinkHead(r) for r in relations}
    new_edges = []
    for r in relations:
        for h, t in candidate_pairs(SKG, r):
            p = sigmoid(heads[r](enc[h], enc[t]))
            if p >= theta_conf:
                new_edges.append((h, r, t, p))
    return add_as_hypotheses(SKG, new_edges, src='link_prediction'), new_edges
    # 注意：补全边标记为 hypothesis，不得直接进入证书，必须经 ProvCert 检验
```

### IP-123 MTL-Rho

```python
def train_mtl_rho(SKG, tasks, encoder, heads, B_nt, eval_every=500):
    for step in range(max_steps):
        batch = sample_multi_task(tasks)
        h = encoder(SKG, batch)
        losses = {t: task_loss(heads[t], h, batch[t]) for t in tasks}
        grads = [grad(losses[t], encoder.params()) for t in tasks]
        proj = pcgrad(grads)                    # 冲突梯度投影
        encoder.step(sum(proj))
        for t in tasks:
            heads[t].step(grad(losses[t], heads[t].params()))
        if step % eval_every == 0:
            A = cka_matrix(h, tasks)
            NT = negative_transfer_matrix(proj, A, batch)
            heads = group_prune(heads, A, NT, B_nt)
    return encoder, heads, A, NT
```

### IP-124 MetaPathComp

```python
def metapath_compose(SKG, task, A_T, theta_kg, rho_min, B_nt):
    assert SKG.only_certified_edges()           # 只用已被证实/校准的边
    best = None
    for pi in enumerate_metapaths(task, max_len=L_max):
        for path in kg_query(SKG, pi, goal=task):
            if not cover(path, A_T):          continue
            if conf(path) < theta_kg:          continue
            if not nt_gate(path, task, B_nt):  continue
            rho = compose_task_rho(path, task) # 聚合 ρ^{(t)}
            if min(rho.values()) < rho_min:    continue
            cand = (path_cost(path), path, rho)
            best = cand if best is None or cand[0] < best[0] else best
    return best
```

### IP-125 ProvCert

```python
def provenance_certificate(cert, SKG, decision, model):
    P_prov = min_subgraph(SKG, cert.used_edges)
    if model.flip_on_remove(decision, P_prov) == decision:
        return ('reject', 'not_necessary', P_prov)
    if model.reproduce_on_insert(decision, P_prov) != decision:
        return ('reject', 'not_sufficient', P_prov)
    if contains_hypothesis_edge_without_support(P_prov):
        return ('reject', 'uncertified_edge', P_prov)
    return ('ok', J_KG(cert.rho, cert.A_cert, P_prov, cert.a_mt, cert.delta_a))
```

### IP-126 NTG / XTask

```python
def cross_task_certify(J_src, t_src, t_dst, SKG, A, NT, B_nt, theta_aff, rho_min):
    if not path_exists(SKG, t_src, t_dst, 'transfers_to'):
        return ('reject', 'no_meta_path')
    if A[t_src][t_dst] < theta_aff or NT[t_src][t_dst] > B_nt:
        return ('reject', 'negative_transfer', A[t_src][t_dst], NT[t_src][t_dst])
    rho_dst = adapt_head(J_src.rho, heads[t_dst], SKG)
    if min(rho_dst.values()) < rho_min:
        return ('reject', 'rho_fail', rho_dst)
    prov_ok = provenance_certificate(J_src, SKG, decision='transfer', model=transfer_model)
    if prov_ok[0] != 'ok':
        return prov_ok
    return ('ok', J_KG(rho_dst, J_src.A_cert, J_src.P_prov, (A[t_src][t_dst], NT[t_src][t_dst]), J_src.delta_a))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SKG | O(|E|+|R|+|log|·|E_F|) | O(|E|+|R|) | 关系类型封闭、置信保序校准 |
| KGLink | O(L·|R|·|E|·d + L·|R|·d²) | O(|E|·d+|R|·d²) | 补全边为 hypothesis，假阳率 ≤ ε_link |
| MTL-Rho | O(T·B·d²) / step | O(|φ|+Σ|ψ_t|) | 干扰 ≤ β_mt，冲突梯度投影收敛 |
| MetaPathComp | O(|Π|·(L_max·|E|+k·|A|)) | O(|Π|·L_max) | 只用认证边，conf 门限 sound |
| ProvCert | O(|P_prov|·C_model) | O(|P_prov|) | 移除必要 + 插入充分 |
| NTG/XTask | O(|T|²·d+|P_prov|·C_model) | O(|T|²+|P_prov|) | NT 上界闭合、门控硬约束 |

**正确性定理（Knowledge-Task Transferable Composition Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** 元路径完备率 ≥ `κ_kg` 且链接假阳率 ≤ `ε_link`；**(A30)** MTL 干扰 `|ρ^{(t)}_shared−ρ^{(t)}_single| ≤ β_mt`；**(A31)** 溯源忠实率 ≥ `κ_prov`；**(A32)** `|NT_hat − NT_true| ≤ ε_nt`。则：
```
P_success ≥ 1 - Σ_d(1-ρ_min^{(t)}(d)) - β_E - β_mt
            - P(δ_a>Θ_a) - ε_link - ε_nt - (1-κ_prov) - (1-κ_kg)
```
三条不可交换的纪律：**hypothesis 边不得入证书**；**未过 NTG 的证书不得跨任务**；**溯源不忠实的证书一律降级为“观察”而非“知识”**。

## 6. 本轮最大风险

**一句话**：知识图谱与多任务学习把证书从“本任务断言”提升为“可溯源、可迁移的知识”，但其 soundness **同时押注于 SKG 关系完备、链接预测校准、MTL 无负迁移、以及溯源子图忠实**四件事；其中最危险的是**溯源忠实性被“事后合理化”污染**——模型先给结论再挑一条看似合理的元路径，于是证书在跨任务时引用了一条结构上成立、语义上错误的迁移链，且因“有出处”而更难被质疑，故必须以**反事实移除/插入检验 + 链接置信下界 + 负迁移硬门控 + 跨任务回滚绊线**四重护栏，宁可不迁移，也绝不把“有出处的错误”包装成可迁移知识。
