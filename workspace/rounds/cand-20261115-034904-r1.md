# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态主动交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「演示方案」×「群体智能」）

> R69 把不确定性拆成 aleatoric / epistemic，第一次让系统学会「问」。但它有两个未言明的孤注：**(a) 模态分布来自单一流模型**——R69 自陈的最大风险恰是「模态权重未校准则追问幻影」；**(b) 证据纪律要求「k 个正交证据源」**，可 R69 从未给出机制保证这些源真的正交——它复用同一个 MTM trunk，多个「源」很可能只是同一个模型的多个视角，ρ 接近 1。于是 R69 的「k 一致」在实践中可能退化为「同一模型的 k 次自我确认」。
>
> 本轮两个灵感正好各补一刀：
> - **群体智能**把「一个模型的一次采样」换成「一群异构智能体的可测独立判断」：多样性不是口号，而是可估计的残差相关矩阵；共识不是投票，而是带相关性折扣的法定人数仲裁；
> - **演示方案**把「证据的单位」从「一条回答」升级为「一次他人可复现的演示」：回答只需被相信，演示必须被重放；「trust me」变成「reproduce this」。
>
> 核心命题：**只有在演示可被独立复现、且见证者之间独立性可测时，群体的一致才计为证据；否则退化为 R69 单智能体保守。** 命名 **CHORUS-RAS**（Collective Heterogeneous Observation, Reproducible-demonstration, Uncertainty arbitration System）。合唱的隐喻：每个声部必须独立在调上，且共享同一份总谱（演示方案）；**若所有人都把同一个错音唱对，合唱只是更响的错误**。
>
> 一句话定位：R66 问「谁控制」→ R67 问「未来怎样」→ R68 问「我的测量还准吗」→ R69 问「我该向谁求证」→ R70 问「**拿什么让人信，凭什么说他们独立**」。

## 0. 直觉与动机

**灵感 1（群体智能 → 从「一个模型的后验」到「一群模型的独立后验」）**
直觉：R69 的致命处是「自证」——同一个流模型既提出模态、又给出权重，没有任何外部制衡。人类不会只问自己一遍就确信；我们会让不同的人、从不同角度、独立地说。群体智能给的正是这种「冗余 + 异质」：不同具身、不同视点、不同训练数据的智能体，其错误若彼此独立，则集体错误概率随 n 下降（Condorcet 陪审团定理的工程版）。但这句话有一个必须被测量而非假设的前提——**独立性**。同一个底座微调出的十个智能体，不是十个证人，是**一个证人换十件衣服**。

**灵感 2（演示方案 → 证据的最小可采信单位是「可复现」）**
直觉：R69 的交互产出是「回答 / 观测」，它只能被信任，不能被检验。演示方案（demo / lesson plan）改变这一点：一个有价值的断言必须打包成「主张 + 复现脚本 + 预期可观测 + 容差 + 见证人 + 有效期」。任何见证者用自己的具身重放脚本，若观测落在容差内，断言才被采信。「演示」不是给观众看的花架子，而是**可证伪的实验设计 + 可重放的验收**——把 R69 的「问」从请求信任，升级为请求复现。

**灵感 3（法定人数 → 把 R69 的「k 一致」从口号变成机制）**
直觉：R69 引理 18 假设「各源欺骗相关 ρ<1」，却没有任何机制去估计 ρ 或强制执行。群体智能的答案是工程化的：拜占庭容错需要 `n ≥ 3f+1`、法定人数阈值、少数派报告通道，以及**多样性 / 独立性认证**。R70 把这些搬进 R69 的证据纪律：只有当有效独立源数 `n_eff ≥ k_min`、法定人数足够时，共识才被采纳；否则该一致性不计分，退化为 R69。

**灵感 4（共识 ≠ 真相 → 群体极化与从众必须被设计防御）**
直觉：群体智能不是万灵药。群体可以一起错（共享偏差）、可以极化（互相强化）、可以从众（沉默的少数不敢反对）。所以本轮必须显式交付：**少数派报告通道**（任何智能体可在有效期内提交可复现的反演示，强制重裁）、**演示方案的留出验收**（held-out demo，防 teaching-to-the-test）、**外部锚定 oracle**（验收判据不能由被验者共享的模型兼任，否则就是 Goodhart）。

**灵感 5（演示即准入 → 把 R68 表征坍缩 / R69 模态校准变成「入职考试」）**
直觉：新智能体凭什么获得投票权？不是自报 ECE，而是通过一册**未公开的演示课程**：在它没见过的情境上重放演示、达到通过率才准入。这同时解决三件事：拒绝同源克隆（克隆体在留出课程上同样通过，但会被残差相关矩阵记为高相关、权重被折减）、把 R68 的表示坍缩变成可检测的入职失败、让演示方案成为人机参与式审计的天然接口（人类审的是「计划」，不是「黑箱输出」）。

**灵感 6（stigmergy → 审计从「只增日志」变成「会蒸发的信息素场」）**
直觉：群体共享经验若只增不减，会固化成教条（「上次大家都这么说」）。把 AuditBuf 升级为带衰减的 stigmergic 证据场：每条证据以演示哈希沉积、可信度随时间按 γ 蒸发。这样旧共识不会永久压制新反证，也天然给出存储上界。

## 1. 形式化定义（增量：定义 310–327）

**定义 310（CHORUS-RAS 总览）** `CHORUS-RAS = (DPL, SWARM, DEMO, DIV, QAR, STIG, DEG, J_CHORUS)`。四条不变式：
(i) **实时流零学习写**（继承 R69 定义 293-i）；
(ii) **演示准入**：任何证据进入集体后验前，必须是一个可复现演示（定义 313）；裸「回答 / 模态」只能作为**假设**，不能作为证据；
(iii) **独立性可测**：「正交」由多样性矩阵估计（定义 315），不得声明；有效独立源数不足则一致性不计分；
(iv) **可退化为 R69**：`n=1`、演示不可复现、多样性门控失败或超预算时，逐指令退化为 FLUID-RAS（定义 325，定理 18）。

**定义 311（异构智能体与投票权）** 群体 `A = {a_1,…,a_n}`，每个 `a_i` 带策略 `π_i`（同族 FMP）、校准 `κ_i`（ECE_i）、领域能力 `c_i`、具身 `e_i`、视点 `v_i`。投票权 `w_i = softmax(−ECE_i)_i · 1[pass_admit_i]`；未通过演示准入（定义 319）的智能体 `w_i = 0`。

**定义 312（演示方案 DP）** `DP = (c, o, ρ, ỹ, ε_tol, W, T_exp)`：主张 `c`（模态身份 / 动作契约 / 安全断言）、情境 `o`、复现脚本 `ρ`（由信息动作与任务动作组成、见证者可独立执行的动作序列）、预期可观测 `ỹ`（轨迹 / 测量）、容差 `ε_tol`、见证集 `W ⊆ A∖{author}`、有效期 `T_exp`。演示方案是**可证伪的证据单元**；`ρ` 必须只依赖 `o` 与公共接口，不得依赖作者的私有隐状态。

**定义 313（可复现演示与复现率）** 演示 `D = (DP, author i, witnesses W)`。在水平 `q` 下 `D` 有效，当且仅当存在 `W' ⊆ W`，`|W'| ≥ q`，对每个 `j∈W'` 以自身具身执行 `ρ` 得到观测 `y_j`，满足 `d(y_j, ỹ) ≤ ε_tol`，且 `W'` 两两独立（定义 315）。复现率 `R(D) = |{j: d(y_j,ỹ)≤ε_tol}| / |W|`。证据强度 `S(D) = R(D)·(1−ε_tol)·(1−β_collude)`，`β_collude` 为见证共谋上界（定义 322）。

**定义 314（陈述 vs 演示的信息差）** R69 的裸回答是点断言，可采信度仅由源自报的信任决定；演示把可采信度锚定在**独立重放**上。对二元真值主张，给定至少一名诚实且 oracle 独立的见证者，`P(误采信 | 演示) ≤ ε_tol + β_collude`；而单源裸回答的误采信率下界仍为 `δ_p`（R69 引理 18）。这是「问」与「演示」的本质差。

**定义 315（多样性 / 独立性矩阵）** 对智能体 `i,j`，在留出探针集上计算残差相关 `ρ_ij = corr(r_i, r_j)`，得多样性矩阵 `P=[ρ_ij]`（对角为 1）。有效独立源数
`n_eff = n / (1 + (n−1)·ρ̄)`，`ρ̄` 为 `P` 的非对角均值。
门控：`n_eff ≥ k_min` 且 `P` 中存在规模 `≥ q` 的团，团内两两 `ρ_ij < ρ_max`；否则判定「伪独立」，一致性不计分。**`ρ_ij` 必须在留出集上估计，不能用被检证据本身（防循环）。**

**定义 316（相关性折扣的集体后验）** 个体后验 `p_i(M|o)` 经各自校准温度重标定后，用对数意见池聚合：
`log p̄(M) ∝ Σ_i α_i log p_i(M)`，`α_i = w_i / (1 + (n−1)·ρ̄)`（等及相关近似），等价于把「n 个相关证人」折算为 `n_eff` 个独立证人。当 `ρ̄→1`，`n_eff→1`，集体后验退回**单个最优智能体**，不产生任何虚假置信。系：朴素投票（`α_i=w_i`）在相关时**系统性过自信**，这是本项目必须显式折扣的偏差。

**定义 317（法定人数仲裁 QAR）** 主张 `m*` 提交当且仅当同时满足：
(a) 支持演示的加权票 `Σ_{i: support} w_i·S(D_i) ≥ τ_q`；
(b) 不存在有效的反演示（定义 318）其权重 `≥ τ_m`；
(c) 多样性门控通过（定义 315）。
三者任一不满足 ⇒ `U_epi` 保持未消解，走 R69 兜底（定义 325）。拜占庭参数取 `n ≥ 3f+1`、`τ_q > (n+f)/2`、`τ_m > f`。

**定义 318（少数派报告通道 MINOR）** 任何智能体可在 `T_exp` 内提交反演示 `D⁻` 挑战 `c`；若 `D⁻` 可复现，则强制重裁（回到定义 317），并提升该智能体在下一窗口的权重。目的：防止过早共识、群体极化与「沉默的少数」（pluralistic ignorance）。

**定义 319（演示准入课程 CURR）** 新智能体 `i` 获得投票权，当且仅当在**未公开**的留出演示课程 `{DP_ℓ}` 上复现通过率 `≥ r_admit`。克隆体会在留出课程上同样通过，但随后在定义 315 的相关矩阵中被记为 `ρ≈1`、投票权被 `n_eff` 折扣——**准入允许它加入，折扣禁止它刷票**。这同时把 R68 表征坍缩转成可检测的入职失败。

**定义 320（演示方案选择器 DPL-Sel）** 主动设计演示，而非被动等回答：
`DP* = argmax_{DP} [ ΔD(DP) − c_exec(DP) − c_social(DP) ]`，s.t. `ε_tol` 可验收、预算未超；`ΔD` 为**可被复现验证**的集体模态不确定性下降期望（相对于裸问的 `VoI`，这里只计入「能被他人重放」的部分）。若无 `ΔD > 成本` 的演示，则不演示、退 R69。这把 R69 MINT 的 VoI 从「问」升级为「设计一个可复现的实验」。

**定义 321（stigmergic 证据场 STIG）** 共享证据场 `E(x,t)`，沉积 `E ← (1−γ)E + Σ deposit(D)`，`deposit` 仅接受含演示哈希的条目；随 `γ` 蒸发。智能体只读写环境，不直接互信。`γ` 保证陈旧共识的权重有界 `≤ dep_max/γ`，避免教条固化。

**定义 322（演示投毒与共谋干扰集 ℰ_demo）** 伪造复现脚本；**共享 oracle 的共谋见证**（作者与见证者用同一个仿真 / 同一个学会的验收器）；teaching-to-the-test（针对验收函数过拟合的演示）；陈旧演示重放；樱桃挑选见证人。`ℰ_CHORUS = ℰ_FLUID × ℰ_demo`。

**定义 323（演示审计 VQAuditor-S）** 审计对象升级为演示方案：见证独立性、验收 oracle 的出处、随机留出抽检、演示过拟合分（在扰动情境下复现率下降幅度）。结论回灌 STIG 与 DPL-Sel 的成本先验。

**定义 324（证书 J_CHORUS）** `J_CHORUS = (J_FLUID, n, n_eff, diversity_cert, quorum_margin, repro_rate, demo_merkle_root, minority_reports, demo_overfit_score, chorus_ver)`。`Valid ⇔ Valid(J_FLUID) ∧ n_eff ≥ k_min ∧ diversity_cert ∧ quorum_margin ≥ 0 ∧ repro_rate ≥ r_min`。

**定义 325（退化到 R69 的硬开关 DEG）** 若 `n_eff < k_min`、oracle 不可信（定义 327）、复现失败、共谋嫌疑或超预算 ⇒ 进入**单智能体模式**（`n=1`，权重全给最优校准体），行为逐指令等价于 FLUID-RAS；`λ` 单调不降。安全侧永不弱于 R69。

**定义 326（演示预算与时序）** 每窗口演示执行数 `≤ B_demo`、通信 `≤ B_comm`、见证查询最多 1 轮法定人数 + 1 轮少数派；复现执行全部**异步离线**，控制环路只读缓存结论；`P99` 控制预算仍按 R69 核定。

**定义 327（外部锚定验收 oracle）** 验收判据 `Ω` 必须**物理接地**（共享传感器真值）或**外部审计**；若 `Ω` 由作者与见证者共享的同一学习模型兼任，则 `Ω` 不构成独立锚点，相关演示一律视为高相关（`ρ_ij→1`）。这是本轮防 Goodhart 的硬约束。

```python
# IP-264 DPL：把「主张 + 复现脚本 + 预期观测 + 容差 + 见证」打包成证据单元
class DemoProtocol:
    def __init__(self, claim, context, script, expected, tol, witnesses, ttl):
        self.c, self.o, self.rho, self.y_hat = claim, context, script, expected
        self.eps, self.W, self.T = tol, witnesses, ttl
    def hash(self):  # 演示哈希，用于 STIG 沉积与证书
        return merkle_hash(self.c, self.o, self.rho, self.y_hat, self.eps)

# IP-265 DIV：可测独立性（残差相关矩阵 → 有效样本量）
def independence_gate(agents, probe_suite):
    R = {i: residual_profile(agents[i], probe_suite) for i in agents}
    P = pairwise_corr(R)                     # 留出探针上估计，非被检证据本身
    rho_bar = offdiag_mean(P)
    n      = len(agents)
    n_eff  = n / (1 + (n - 1) * rho_bar)     # 等及相关近似
    ok     = (n_eff >= K_MIN) and has_clique(P, q=Q_MIN, rho_max=RHO_MAX)
    return n_eff, ok, P

# IP-266 QAR：相关性折扣的集体后验 + 法定人数 / 少数派仲裁
def arbitrate(claims, demos, agents, P, n_eff):
    logpost = defaultdict(float)
    for i in agents:
        alpha = agents[i].w / (1 + (len(agents) - 1) * offdiag_mean(P))
        for m, p in agents[i].posterior.items():
            logpost[m] += alpha * log(p + EPS)       # 对数意见池（折扣版）
    p_bar = softmax_dict(logpost)
    for m, score in p_bar.items():
        support = sum(agents[i].w * demos[i].strength() for i in demos if supports(i, m))
        counter = sum(agents[j].w for j in minority_reports if challenges(j, m))
        margin  = support - max(counter, 0)
        if support >= TAU_Q and counter < TAU_M and margin >= 0:
            return m, margin                          # commit
    return None, None                                 # 未消解 → DEG 退回 R69

# IP-267 DEMO：跨具身重放验收（异步离线，不进控制环）
def reproduce(dp, witness):
    if not witness.pass_admit:            return None
    if not oracle.independent(dp.author, witness):  # 定义 327
        return Reproduced(y=None, correlated=True)
    y = witness.execute(dp.rho, dp.o)     # 用自己的具身执行复现脚本
    return Reproduced(y=y, ok=dist(y, dp.y_hat) <= dp.eps)

def repro_rate(dp, witnesses):
    res = [reproduce(dp, w) for w in witnesses]
    valid = [r for r in res if r and r.ok and not r.correlated]
    return len(valid) / max(len(witnesses), 1)

# IP-268 CURR：演示准入（未公开留出课程）
def admit(agent, heldout_curriculum):
    rate = mean(reproduce(dp, agent).ok for dp in heldout_curriculum if dp.author != agent)
    return rate >= R_ADMIT

# IP-269 DPL-Sel：主动设计演示方案（把 VoI 升级为可复现实验设计）
def design_demo(modes, agents, budget):
    best = None
    for dp in demo_candidates(modes, agents):       # 候选复现脚本 + 见证集
        if not budget.allow(dp):               continue
        delta = expected_verifiable_disagreement_drop(dp)   # 只计可复现部分
        score = delta - exec_cost(dp) - social_cost(dp)
        if best is None or score > best.score: best = (dp, score)
    return best if best and best.score > 0 else None        # 无利可图 → 不演示

# IP-270 STIG：证据场沉积 + 蒸发
def stig_deposit(field, dp, strength, t, gamma):
    field[dp.hash()] = (1 - gamma) * field.get(dp.hash(), 0.0) + strength
    field.prune(threshold=EPS_STIG)                 # 存储有界，陈旧共识被蒸发

# IP-273 主闭环（继承 R69，仅在证据采信处插入 CHORUS 层）
def CHORUS_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)   # R68/R69 一次前向
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o_obs, o_calibrated)
    slow  = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    # 1) 独立性门控：只有可测独立才允许群体仲裁
    n_eff, div_ok, P = M.div.independence_gate(M.agents, M.probe_suite)
    # 2) 主动设计一个可复现演示（而非裸问）
    dp = (M.dpl_sel.design_demo(modes, M.agents, M.budget)
          if (U_epi > TAU_EPI and not slow) else None)
    if dp is not None:
        rate = M.demo.repro_rate(dp, dp.W)               # 异步离线重放
        M.stig.stig_deposit(M.field, dp, rate, M.t, M.gamma)
        m_star, margin = (M.qar.arbitrate(modes, M.demos(dp), M.agents, P, n_eff)
                          if (div_ok and rate >= R_MIN) else (None, None))
    else:
        rate, m_star, margin = 0.0, None, None
    # 3) 采纳条件不满足 ⇒ 逐指令退化 R69
    if m_star is None or not div_ok:
        U_epi_after = U_epi                                # 未消解
        lam = max(M.efs.risk_scale(...), lam_floor(U_ale + U_epi_after))
        mode = M.agent0.select_mode(modes, U_epi_after, lam)  # 单智能体 = R69
    else:
        U_epi_after = post_entropy(M.qar.p_bar)            # 已消解
        lam = max(M.efs.risk_scale(...), lam_floor(U_ale))  # resolution bonus
        mode = mode_of(m_star)
    # 4) 安全认证与执行（不变式继承 R69）
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    if slow: lam = max(lam, 0.8); k = min(k, k_cal_shrink(x_prime, U_cal))
    tau = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    # 5) 演示审计 + 证书
    M.vqa_s.submit_async(dp, rate, n_eff, m_star, margin)
    return k, lam, mode, (U_ale, U_epi_after, n_eff, rate)
```

## 3. 推导

**引理 19（相关性折扣与有效样本量）** 设 `n` 个智能体的残差等相关 `ρ̄`、方差 `σ²`，则均值残差方差 `Var(r̄) = (σ²/n)·(1 + (n−1)ρ̄)`，故有效独立源数 `n_eff = n/(1+(n−1)ρ̄)`。当 `ρ̄→1`，`n_eff→1`，群体证据强度与单个最优智能体相同；当 `ρ̄=0`，`n_eff=n`。系：**R69 复用同一 trunk 的「k 源」若不做相关性估计，就会把 `n_eff≈1` 误当成 `n_eff=k`，从而系统性过自信。** 这是 R70 对 R69 证据纪律的直接修正。

**引理 20（演示相对裸回答的判别力）** 对二元主张，设单源谎报率 `δ_p`、见证共谋相关 `ρ_c<1`、验收容差 `ε_tol`。裸回答单源采纳的误采信率 `≥ δ_p`（R69 引理 18）。若要求至少 `q` 名 oracle 独立的见证者复现通过，则
`P(误采信 | 演示) ≤ ε_tol + β_collude·ρ_c^{q−1} + ε_σ`。
即演示把「相信一个人」换成「相信一次可重放、且被多个独立方验收过的实验」，误差随 `q` 指数下降。系：`ε_tol` 越小、`q` 越大、oracle 越独立，演示越强；三者任一退化，演示退化为裸回答。

**引理 21（法定人数仲裁的安全性）** 设 `n ≥ 3f+1`、`τ_q > (n+f)/2`、`τ_m > f`，至多 `f` 个拜占庭智能体。则不存在两个互相冲突的主张 `m, m'` 同时满足定义 317 的提交条件（否则支持票之和 `≥ 2τ_q > n+f`，超过诚实票上限 `n−f`，矛盾）；且在部分同步下，少数派报告通道保证有效反演示必被处理 ⇒ 活性。系：定义 317 把 R69 的「k 一致」从**假定**变成**可证明的提交规则**。

**引理 22（多样性–能力权衡）** 设个体正确率 `c_i`、两两误差相关 `ρ̄`。集体多数正确率随 `n_eff` 提升，**仅当** `c_i > 1/2` 且 `ρ̄` 低于阈值；若 `c_i ≤ 1/2` 或 `ρ̄→1`（克隆），集体正确率可**低于**最优个体。系：CHORUS 不能「全用」，必须按校准与能力**选子集**（定义 311 的投票权、定义 315 的门控），否则群体只是放大器。

**定理 18（CHORUS 严格包含 FLUID/R69）** 在 A99–A102 下，CHORUS 的期望风险 `≤` FLUID；且当 `n_eff < k_min`、演示复现率 `< r_min`、oracle 不独立、存在有效反演示或超预算时，两者**逐指令相同**（定义 325）。因此 R69 是 CHORUS 在「单智能体 / 不可复现 / 伪独立」边界上的严格退化：安全侧不让步，效率侧仅在**可复现且真独立**时获得 resolution bonus。

**定理 19（演示层无突变与单调退化）** 演示与仲裁只改变「选哪个模态 / 是否消解 `U_epi`」，不改变安全包络（`C-RAS-WM` 认证、`π_σ` 前缀调度不变）；演示失败 / 超时 / 投毒 / 共谋嫌疑时 `λ` 单调不降地退回 R69 保守；R68 换装不变式与 R69 定理 17 保持 ⇒ 控制连续、无突变。

**命题 20（stigmergy 的陈旧证据有界）** 在蒸发率 `γ>0`、单条沉积上界 `dep_max` 下，任一旧证据在场中的权重 `≤ dep_max/γ`，与存在时长无关；故共享记忆不会无限累积成不可挑战的教条。配合定义 318，新反证总能在有界权重内触发重裁。

## 6. 本轮最大风险

**一句话**：CHORUS-RAS 的全部收益都押在「演示验收判据 `Ω` 独立且不可被优化」这一前提上——若 `Ω` 由被验者共享的同一底座 / 同一仿真提供，或能被智能体针对性刷分，那么群体只是在**同一个错误上达成更大规模的一致**，「可复现的演示」退化为「可刷分的应试」，`n` 个智能体不过是一个智能体的 `n` 张面具。

**次级风险与缓解**：
1. **伪独立 / 同源克隆** → 定义 315 相关性矩阵 + `n_eff` 折扣 + 演示准入（定义 319）；
2. **共享 oracle 共谋** → 定义 327 外部锚定 + 定义 322 ℰ_demo + E305/E306；
3. **群体极化 / 从众** → 少数派报告通道（定义 318）+ E309；
4. **演示成本击穿预算** → 复现全部异步离线（定义 326）+ DPL-Sel 只在 `ΔD>成本` 时演示；
5. **多样性–能力权衡反噬** → 按校准 / 能力选子集 + 定义 325 硬退化，绝不让劣质群体驱动决策。

## 3. 关键算法伪代码

```python
# IP-264 DPL：证据单元
class DemoProtocol:
    def __init__(self, claim, context, script, expected, tol, witnesses, ttl):
        self.c, self.o, self.rho, self.y_hat = claim, context, script, expected
        self.eps, self.W, self.T = tol, witnesses, ttl
    def hash(self): return merkle_hash(self.c, self.o, self.rho, self.y_hat, self.eps)

# IP-265 DIV：可测独立性
def independence_gate(agents, probe_suite):
    P = pairwise_corr({i: residual_profile(a, probe_suite) for i, a in agents.items()})
    n, rho_bar = len(agents), offdiag_mean(P)
    n_eff = n / (1 + (n - 1) * rho_bar)          # 等及相关近似
    ok = (n_eff >= K_MIN) and has_clique(P, q=Q_MIN, rho_max=RHO_MAX)
    return n_eff, ok, P

# IP-266 QAR：折扣 logOP + 法定人数 / 少数派仲裁
def arbitrate(claims, demos, agents, P, n_eff):
    logpost = defaultdict(float)
    for i in agents:
        alpha = agents[i].w / (1 + (len(agents) - 1) * offdiag_mean(P))
        for m, p in agents[i].posterior.items():
            logpost[m] += alpha * log(p + EPS)
    p_bar = softmax_dict(logpost)
    for m in p_bar:
        support = sum(agents[i].w * demos[i].strength() for i in demos if supports(i, m))
        counter = sum(agents[j].w for j in minority_reports if challenges(j, m))
        if support >= TAU_Q and counter < TAU_M and support - counter >= 0:
            return m, support - counter
    return None, None                            # 未消解 → DEG

# IP-267 DEMO：跨具身重放（异步离线，不进控制环）
def reproduce(dp, witness):
    if not witness.pass_admit: return None
    if not oracle.independent(dp.author, witness):      # 定义 327
        return Reproduced(y=None, correlated=True)
    y = witness.execute(dp.rho, dp.o)
    return Reproduced(y=y, ok=dist(y, dp.y_hat) <= dp.eps)

def repro_rate(dp, witnesses):
    res = [reproduce(dp, w) for w in witnesses]
    return len([r for r in res if r and r.ok and not r.correlated]) / max(len(witnesses), 1)

# IP-268 CURR：留出课程准入
def admit(agent, heldout_curriculum):
    return mean(reproduce(dp, agent).ok for dp in heldout_curriculum
                if dp.author != agent) >= R_ADMIT

# IP-269 DPL-Sel：主动设计可复现实验
def design_demo(modes, agents, budget):
    best = None
    for dp in demo_candidates(modes, agents):
        if not budget.allow(dp): continue
        score = expected_verifiable_disagreement_drop(dp) - exec_cost(dp) - social_cost(dp)
        if best is None or score > best.score: best = (dp, score)
    return best if best and best.score > 0 else None    # 无利可图 → 不演示

# IP-270 STIG：沉积 + 蒸发
def stig_deposit(field, dp, strength, gamma):
    field[dp.hash()] = (1 - gamma) * field.get(dp.hash(), 0.0) + strength
    field.prune(EPS_STIG)

# IP-273 主闭环（继承 R69，仅在证据采信处插入 CHORUS 层）
def CHORUS_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o_obs, o_calibrated)
    slow  = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    n_eff, div_ok, P = M.div.independence_gate(M.agents, M.probe_suite)
    dp = (M.dpl_sel.design_demo(modes, M.agents, M.budget)
          if (U_epi > TAU_EPI and not slow) else None)
    rate, m_star = 0.0, None
    if dp is not None:
        rate = M.demo.repro_rate(dp, dp.W)                  # 异步离线
        M.stig.stig_deposit(M.field, dp, rate, M.gamma)
        if div_ok and rate >= R_MIN:
            m_star, margin = M.qar.arbitrate(modes, M.demos(dp), M.agents, P, n_eff)
    if m_star is None or not div_ok:                        # 逐指令退化 R69
        lam  = max(M.efs.risk_scale(...), lam_floor(U_ale + U_epi))
        mode = M.agent0.select_mode(modes, U_epi, lam)
        U_epi_after = U_epi
    else:
        U_epi_after = post_entropy(M.qar.p_bar)
        lam  = max(M.efs.risk_scale(...), lam_floor(U_ale))  # resolution bonus
        mode = mode_of(m_star)
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    if slow: lam = max(lam, 0.8); k = min(k, k_cal_shrink(x_prime, U_cal))
    tau = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_s.submit_async(dp, rate, n_eff, m_star, margin)
    return k, lam, mode, (U_ale, U_epi_after, n_eff, rate)
```

## 4. 推导

**引理 19（相关性折扣）** 等及相关下 `Var(r̄)=(σ²/n)(1+(n−1)ρ̄)`，故 `n_eff=n/(1+(n−1)ρ̄)`；`ρ̄→1 ⇒ n_eff→1`，集体不优于单个最优体。系：R69 复用同一 trunk 的「k 源」若不估相关，就是把 `n_eff≈1` 当过 `k`，系统性过自信。

**引理 20（演示判别力）** `P(误采信|演示) ≤ ε_tol + β_collude·ρ_c^{q−1}+ε_σ`，裸回答单源 `≥δ_p`。演示把「相信一个人」变成「相信一次多方独立验收的实验」。

**引理 21（BFT 仲裁安全）** `n≥3f+1, τ_q>(n+f)/2, τ_m>f` ⇒ 无冲突双提交；部分同步下少数派报告保活性。把 R69 的「k 一致」从假设变成可证明提交规则。

**引理 22（多样性–能力权衡）** 集体正确率仅当 `c_i>1/2` 且 `ρ̄` 低于阈值时随 `n_eff` 提升；克隆或劣质成员会使集体劣于最优个体 ⇒ 必须选子集，不能「全用」。

**定理 18（CHORUS 严格包含 FLUID/R69）** `n_eff<k_min ∨ 复现率<r_min ∨ oracle 不独立 ∨ 有效反演示 ∨ 超预算` ⇒ 逐指令等价 R69；安全风险 `≤` R69，效率只在「可复现且真独立」时获益。

**定理 19（演示层无突变与单调退化）** 演示只改模态选择、不改安全包络；失败/超时/投毒/共谋时 `λ` 单调不降退回 R69；R68 换装不变式与 R69 定理 17 保持 ⇒ 控制连续。

**命题 20（stigmergy 陈旧证据有界）** `γ>0` 下旧证据权重 `≤dep_max/γ`，与时长无关；共享记忆不会固化教条，新反证总能在有界权重内触发重裁。

## 7. 本轮最大风险

**一句话**：CHORUS-RAS 的全部收益都押在「演示验收判据 `Ω` 独立且不可被优化」这一前提上——若 `Ω` 由被验者共享的同一底座 / 同一仿真提供，或能被智能体针对性刷分，那么群体只是在**同一个错误上达成更大规模的一致**，「可复现的演示」退化为「可刷分的应试」，`n` 个智能体不过是一个智能体的 `n` 张面具。

**次级风险与缓解**：伪独立 / 同源克隆（定义 315 相关性矩阵 + `n_eff` 折扣 + 演示准入）；共享 oracle 共谋（定义 327 外部锚定 + ℰ_demo + E305/E306）；群体极化 / 从众（少数派报告通道 + E309）；演示成本击穿预算（复现全异步离线 + DPL-Sel 只在 `ΔD>成本` 时演示）；多样性–能力权衡反噬（按校准 / 能力选子集 + DEG 硬退化，绝不让劣质群体驱动决策）。
