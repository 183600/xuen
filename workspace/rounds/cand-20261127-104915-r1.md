### 第 3 轮灵感驱动研究记录（新灵感循环 · 第 1 轮）

**灵感词**：机械臂抓取、传感器融合

**直觉与动机**：
抓取是「感知—接触—力控」三者强耦合的问题。人类抓一只杯子时，并不会先把杯子的位姿精确重建到毫米级、再解一个力闭合优化；真实过程更像「看—摸—试」：视觉给出大致方位与形状，触觉确认是否真的接触、接触面是否滑动，本体感觉确认手指是否到位，最后轻抬一下试探是否抓稳。多模态融合的真正价值不在于把噪声「平均掉」，而在于让不同模态**互相证伪**。

现有抓取管线常把融合当成纯降噪：用 Kalman/粒子滤波把 RGB-D、触觉、力/力矩压成一个后验，再基于该后验做力闭合规划与抓取执行。但融合有一个被忽视的结构性事实：**融合只会增信，不会凭空纠偏**。当所有模态共享同一系统性错误时（透明/反光物体让深度相机一致地「看错」；标定漂移让触觉一致地「感觉错」；抓取对象的真实摩擦系数整体低于模型），乘积式融合会把这些错误当成独立证据而进一步放大，得到一个「高置信度的错误后验」。我把这种现象称为**共识幻觉（consensus hallucination）**。它比单模态失败更危险，因为系统的自评置信度反而更高、更难触发告警。

要打破共模误差，仅靠被动融合在信息论上是不可能的：若各模态误差同源，则它们不提供独立信息。必须引入一个与错误源**因果独立**的通道——主动物理探针：在正式提升前执行一次微小挤压/微抬升，用「施加已知动作 → 观测接触力/位移响应」的因果残差去证伪当前假设。这一步把不可观测的认知不确定性转化为可观测的物理证据，也为前几轮的「证书驱动」框架提供了一个新的证据来源。

**关键洞见**：把前几轮的证书思想从「运动/常识」迁移到「抓取/感知」，构建**探针式融合抓取（Probe-based Fusion Grasping, PFG）**：
- **多模态证据链（MEC）**：每个抓取假设都附带可追溯的证据图（哪个传感器、何时、何种置信度、支持哪个假设），避免「后验黑箱」；
- **模态一致性证书（MCC）**：用成对 Bhattacharyya/JS 散度检测模态冲突；冲突时**隔离异常模态**而非平均，防止污染融合；
- **主动证据证书（AEC）**：用微探针的预测—实测残差与信息增益，同时验证「假设是否可信」与「探针是否有区分力」，专门打击共模幻觉；
- **鲁棒抓取稳定证书（RGSC）**：在摩擦系数下界与位姿/质量不确定集上验证 ε-力闭合，给出滑移概率上界；
- **接触动力学证书（CDC）**：保证预测时域内接触冲量始终落在摩擦锥内、累计滑移有界；
- **融合感知抓取 MPC（FG-MPC）**：在融合信念上做机会约束规划，联合优化抓取位姿、接近轨迹与夹持力；
- **抓取常识知识库（GKB）**：编码「先合拢再抬」「沿法向接近」「脆弱物限力」「滑动时先增法向力」等人类抓取常识；
- **多模态抓取准入门（MGG）**：MEC ∧ MCC ∧ AEC ∧ RGSC ∧ CDC ∧ GKB ∧ 任务可行性，八证合一，保证 Exec_v28 ⊆ Exec_v27。

**形式化目标**：
1. 定义模态集合 M = {vision, depth, tactile, proprio, ft}，证据链 E = {(m, z_m, t_m, w_m, h)}，其中 h 为被支持假设、w_m 为标定后的信任权重；
2. 定义融合信念 b(x) ∝ b_0(x) · ∏_m ℓ_m(z_m | x)^{w_m}，并刻画其熵单调下降性质（融合必增信）；
3. 定义 MCC：max_{m≠n} D_B(b_m, b_n) ≤ τ_cons 且融合信念对假设空间的覆盖率 ≥ γ；
4. 定义 AEC：存在探针动作 a_p，使归一化残差 ρ = ‖r_pred − r_meas‖_{Σ⁻¹} ≤ ρ_max，且后验信息增益 D_KL(b'‖b) ≥ Δ_min；
5. 定义 RGSC：∀μ_i ≥ μ_i^L，力闭合裕度 ε(g, C, μ) ≥ ε_min，且由场景优化给出 P(slip) ≤ δ；
6. 定义 CDC：H 步内每个接触满足非穿透与摩擦锥约束，累计切向滑移 ≤ s_max；
7. 定义 FG-MPC：min E[J_task] + λ_u·tr(Σ) + λ_c·J_contact + λ_k·W_kc，subject to 动力学、机会约束、摩擦锥下界；
8. 定义 MGG 八证合一，Exec_v28 = Exec_v27 ∩ Fil_fusion ∩ Fil_contact ⊆ Exec_v27；
9. 论证共模误差的可检测性、鲁棒力闭合的单调性，以及探针预算耗尽/冲突不可消解时的退化路径。

**本轮最大风险**：共模误差下的「共识幻觉」与探针扰动相互耦合——多模态可能一致地给出错误的高置信度，而主动探针本身可能破坏脆弱物体或诱发滑动，使证书建立在一个错误且已被扰动污染的前提上。

## 2. 关键算法骨架（在 IP-455~474 上扩展）

### IP-465 多模态证据链（MEC）

```python
@dataclass(frozen=True)
class Evidence:
    modality: str          # "vision" | "depth" | "tactile" | "proprio" | "ft"
    payload: Any           # 原始或预处理后的观测
    timestamp: float
    trust: float           # w_m ∈ [0,1]，由离线标定/在线校准给出
    supports: str          # 被支持的假设 id，如 "pose#17" / "mu#0.4"
    provenance: str        # 传感器 id + 标定版本，支持审计

class MultimodalEvidenceChain:
    def __init__(self, calibration_id: str):
        self.calibration_id = calibration_id
        self.edges: list[Evidence] = []

    def add(self, ev: Evidence) -> None:
        self.edges.append(ev)

    def support(self, hypothesis_id: str) -> list[Evidence]:
        return [e for e in self.edges if e.supports == hypothesis_id]

    def is_calibrated(self) -> bool:
        # 任何一条证据来自过期标定版本即视为证据链不可信
        return all(e.provenance.startswith(self.calibration_id) for e in self.edges)

    def independent_channels(self) -> set[str]:
        # 用于估计「独立证据数」，防止同源多帧被误当成独立证据
        return {e.modality for e in self.edges}
```

### IP-466 模态一致性证书（MCC）

```python
@dataclass
class ModalConsistencyCertificate:
    tau_cons: float = 0.5      # Bhattacharyya 距离阈值
    gamma_cov: float = 0.80    # 融合信念覆盖率下界
    max_conflict: float = 0.0
    conflicting: tuple = ()

    def verify(self, beliefs: dict[str, GaussianBelief]) -> bool:
        # beliefs[m] = (mu_m, Sigma_m)，为各模态单独反演的后验
        D = {}
        for a, b in combinations(beliefs, 2):
            D[(a, b)] = bhattacharyya_gaussian(beliefs[a], beliefs[b])
        if D:
            self.conflicting = max(D, key=D.get)
            self.max_conflict = D[self.conflicting]
        fused = fuse(beliefs)                    # 乘积式融合（带信任权重）
        cov = coverage(fused, self.gamma_cov)    # 融合信念对假设空间的覆盖
        return self.max_conflict <= self.tau_cons and cov >= self.gamma_cov

def bhattacharyya_gaussian(b1: GaussianBelief, b2: GaussianBelief) -> float:
    # 高斯 Bhattacharyya 距离；作为 JS 散度的可解析、可微代理
    S = 0.5 * (b1.Sigma + b2.Sigma)
    dmu = b1.mu - b2.mu
    term_mean = 0.125 * dmu.T @ np.linalg.solve(S, dmu)
    term_cov = 0.5 * np.log(
        np.linalg.det(S) / np.sqrt(np.linalg.det(b1.Sigma) * np.linalg.det(b2.Sigma))
    )
    return float(term_mean + term_cov)
```

### IP-467 主动证据证书（AEC）

```python
@dataclass
class ActiveEvidenceCertificate:
    probe: ProbeAction          # 挤压 Δf / 微抬升 Δz / 侧推 Δx，含方向与时长
    rho_max: float = 3.0        # Mahalanobis 残差阈值
    delta_min: float = 0.10     # 最小信息增益（nats），防止「无区分力探针」蒙混通过

    def verify(self, b_before: GaussianBelief, dynamics, sensor
               ) -> tuple[bool, GaussianBelief]:
        r_pred = predict_contact_response(b_before, self.probe, dynamics)
        r_meas = sensor.execute(self.probe)          # 真实施加并测量
        rho = mahalanobis(r_pred, r_meas, sensor.cov)
        b_after = bayes_update(b_before, r_meas, dynamics)
        gain = kl_divergence(b_after, b_before)
        ok = (rho <= self.rho_max) and (gain >= self.delta_min)
        return ok, b_after
```

### IP-468 鲁棒抓取稳定证书（RGSC）

```python
@dataclass
class RobustGraspStabilityCertificate:
    contacts: list[Contact]
    mu_lower: list[float]
    eps_min: float = 0.05
    f_max: float = 60.0          # 单指法向力上限（N）
    delta_slip: float = 0.01
    n_scenarios: int = 256

    def margin(self, grasp_matrix, w_ext) -> float:
        # 逐步放大 ε，检查在 μ_i^L·(1-ε) 的收紧摩擦锥下是否仍可行
        eps = 0.0
        for _ in range(20):
            cones = [linearize_friction_cone(c, self.mu_lower[i] * (1 - eps))
                     for i, c in enumerate(self.contacts)]
            if not lp_feasible(grasp_matrix, w_ext, cones, self.f_max):
                break
            eps = min(1.0, eps + 0.01)
        return eps

    def verify(self, g, w_ext, scenarios) -> bool:
        # 名义情形
        if self.margin(g, w_ext) < self.eps_min:
            return False
        # 场景优化：N 个位姿/质量场景全部通过 ⇒ 以高置信度 P(slip) ≤ δ
        feasible = sum(
            self.margin(g_s, w_ext_s) >= self.eps_min
            for g_s, w_ext_s in scenarios
        )
        return feasible == len(scenarios)
```

### IP-469 接触动力学证书（CDC）

```python
@dataclass
class ContactDynamicsCertificate:
    s_max: float = 0.005         # 累计切向滑移上限（m）
    def verify(self, traj, contacts, mu_lower) -> bool:
        slip = 0.0
        for k in range(len(traj) - 1):
            for c in contacts:
                f = traj[k].contact_wrench[c.id]
                if f.normal < 0.0:                       # 非穿透
                    return False
                if norm(f.tangential) > mu_lower[c.id] * f.normal + 1e-9:
                    return False                         # 摩擦锥
                slip += norm(traj[k].v_tangential[c.id]) * traj[k].dt
        return slip <= self.s_max
```

### IP-470 融合感知抓取 MPC（FG-MPC）

```python
@dataclass
class FusionAwareGraspMPC:
    dynamics: Callable
    horizon: int = 15
    dt: float = 0.02
    weights: dict
    kc_list: list            # 复用 v27 的 KnowledgeCertificate 作为 GKB 规则

    def solve(self, b0, target, budget: int):
        scenarios = sample_belief(b0, K=64)          # 机会约束的场景近似
        best = None
        for s in scenarios:
            g, u = self._solve_nominal(s, target)    # 名义 SQP/QP
            if not self._chance_feasible(g, u, scenarios):
                continue
            cost = self._evaluate(g, u, s)           # E[J_task]+λ_u tr(Σ)+λ_c J_contact+λ_k W_kc
            if best is None or cost < best[0]:
                best = (cost, g, u)
        if best is None:
            return self._fallback(b0, target, budget)  # 见 IP-473/474
        return best[1], best[2]
```

### IP-472 多模态抓取准入门（MGG）

```python
@dataclass
class MultimodalGraspGate:
    mec: MultimodalEvidenceChain
    mcc: ModalConsistencyCertificate
    aec: ActiveEvidenceCertificate
    rgsc: RobustGraspStabilityCertificate
    cdc: ContactDynamicsCertificate
    gkb: GraspKnowledgeBase

    def admits(self, plan) -> bool:
        # 1. 证据链完整且标定未过期
        if not self.mec.is_calibrated():
            return False
        # 2. 模态一致性；冲突时禁止「平均」，必须由 AEC 证伪
        if not self.mcc.verify(plan.modal_beliefs):
            ok, b = self.aec.verify(plan.fused_belief, plan.dynamics, plan.sensor)
            if not ok:
                return False
            plan.fused_belief = b
        # 3. 关键抓取（高价值/易碎/重载）强制探针
        if plan.critical:
            ok, b = self.aec.verify(plan.fused_belief, plan.dynamics, plan.sensor)
            if not ok:
                return False
            plan.fused_belief = b
        # 4. 鲁棒力闭合
        if not self.rgsc.verify(plan.grasp, plan.w_ext, plan.scenarios):
            return False
        # 5. 接触动力学
        if not self.cdc.verify(plan.contact_traj, plan.contacts,
                               self.rgsc.mu_lower):
            return False
        # 6. 抓取常识
        if self.gkb.violations(plan):
            return False
        # 7. 任务可行性（工作空间、关节限位、碰撞）
        return plan.task_feasible
```

| RGSC 场景验证 | O(N_s·LP) | O(N_s) | N_s=256 |
| CDC 验证 | O(H·n_c) | O(1) | H≤15 |
| FG-MPC 求解 | O(N·(n_x³ + n_u²·n_c)) | O(N·n_x) | N=15, n_x=20, n_u=9 |
| GKB 规则 | O(N_rule) | O(N_rule) | N_rule≤60 |
| MGG 总体 | 由 FG-MPC + RGSC 场景主导 | — | 见实时性 |

**实时性**：抓取规划频率通常 5–20Hz，比双足 50Hz 宽松。典型单次：FG-MPC 8–20ms，RGSC 256 场景约 3–8ms（可缓存锥线性化），MCC<1ms，AEC 探针为物理动作（50–200ms，计入任务时间而非计算时间）。总体计算 <30ms，满足 10–30Hz 规划；探针延迟以「试探—验证」阶段显式计入任务时长，不伪装为零成本。

## 4. 正确性论证（增量）

### 引理 23（融合必增信）

**陈述**：设 b(x) ∝ b_0(x)∏_m ℓ_m(z_m|x)^{w_m}，w_m>0，且各 ℓ_m 非退化，则微分熵 H(b) ≤ min_m H(b_m)（在各自后验可比的意义下），即融合只会提高置信度、不会自发降低置信度。

**证明**：对任意模态 m，b 相对于 b_m 额外乘入了其他模态的似然项；在对数域相当于在 b_m 的对数密度上叠加一项非恒定函数并重新归一化，一般使分布更集中。更直接地，KL 链式分解给出 log b(x) = log b_m(x) + Σ_{n≠m} w_n log ℓ_n(z_n|x) − log Z，额外的似然项构成对 b_m 的再加权；若这些项与 b_m 的支撑一致，则后验方差单调不增。∎

**推论 23.1（共识幻觉的必然性）**：当各模态误差同源（共模）时，额外似然项与真实状态无关而只强化同一错误，融合置信度上升但后验偏差不降。故仅靠被动融合无法纠正共模误差，必须引入独立通道（AEC）。

### 引理 24（AEC 的可检测性下界）

**陈述**：设真实状态 x* 与当前假设 x̂ 的偏差为 Δx，探针 a_p 在该方向上的敏感度为 s(a_p)（单位偏差引起的响应变化），传感器噪声范数 ≤ ν。若 ‖Δx‖ ≥ (ρ_max + ν)/s(a_p)，则 AEC 的归一化残差 ρ > ρ_max，探针以至少 1−β 的概率拒绝该假设（β 为噪声越界概率）。

**证明**：由三角不等式，‖r_pred − r_meas‖ ≥ s(a_p)‖Δx‖ − ν。代入条件得 ‖r_pred − r_meas‖ > ρ_max，归一化后 ρ > ρ_max。噪声越界概率由 ν 的尾界给出 β。∎

**推论 24.1（探针选取）**：应选取在「最可能出错的假设方向」上敏感度 s(a_p) 最大、同时对物体的扰动（力/位移）不超过脆弱性约束的探针；这解释了 IP-473 的预算调度为何要按风险定向分配，而非均匀试探。

### 引理 25（RGSC 的鲁棒单调性）

**陈述**：若 RGSC 在摩擦下界 μ_i^L 下验证 ε_min 裕度，则对任意真实 μ_i ≥ μ_i^L，抓取仍保持至少 ε_min 的力闭合裕度。

**证明**：摩擦锥随摩擦系数单调扩张，即 K_i(μ_i^L(1−ε)) ⊆ K_i(μ_i(1−ε))（μ_i ≥ μ_i^L）。RGSC 找到的接触力 f 属于收紧锥，故必属于真实锥，且满足 Gf = −w_ext 与力上限。因此同一 f 在真实摩擦下仍可行，裕度不小于 ε_min。∎

### 引理 26（CDC 的无滑移充分条件）

**陈述**：若在 H 步内每个接触满足非穿透与 ‖f_t‖ ≤ μ_i^L f_n，且累计切向速度积分 ≤ s_max，则实际累计滑移 ≤ s_max，接触不发生宏观滑移。

**证明**：库仑摩擦模型下，当切向力严格位于摩擦锥内时接触点无相对切向加速度（静摩擦）；累计滑移由切向速度积分给出上界，CDC 直接检查该上界。∎

### 定理（MGG 的可靠性与单调性）

**陈述**：对任意抓取计划 Π，若 MGG.admits(Π)=True，则 Π 在摩擦下界与场景不确定集下满足：(1) 证据链标定有效；(2) 模态冲突已被 AEC 证伪或消解；(3) 力闭合裕度 ≥ ε_min 且 P(slip) ≤ δ；(4) 接触动力学无宏观滑移；(5) 无抓取常识违规。从而 Exec_v28 ⊆ Exec_v27。

**证明**：由 MGG.admits 的逐项合取定义，分别调用引理 24（AEC）、引理 25（RGSC）、引理 26（CDC）与 GKB 的定义即得 (1)–(5)。由于新增两个过滤器 Fil_fusion、Fil_contact 只做交集、不放大原集合，故 Exec_v28 = Exec_v27 ∩ Fil_fusion ∩ Fil_contact ⊆ Exec_v27。∎

**注（非完备性）**：该定理是可靠性（soundness）而非完备性；探针敏感度不足、场景采样未覆盖的极端位姿仍可能漏检。这正是引理 24 中 (ρ_max+ν)/s(a_p) 分辨率下界所刻画的固有极限，必须由 IP-473/474 的保守退化来兜底。

## 5. 实验设计（预期结果，非已观测数据）

**平台与数据**：MuJoCo + Isaac Gym 双仿真；三类夹爪（平行夹爪、Allegro 灵巧手、软体夹爪）；对象集 = 300 个 YCB 物体 + 50 个透明/反光/可变形压力测试物体。模态：RGB-D 位姿估计（FoundationPose 风格）、仿真 GelSight 触觉、关节力矩、六维力/力矩。噪声模型 = 高斯噪声 + 系统性偏置/标定漂移 + 5–50ms 随机时延。

**基线**：1) 纯视觉抓取（GraspNet 风格）；2) 纯触觉抓取；3) EKF/粒子滤波朴素融合；4) FG-MPC 去掉 AEC；5) 经典力闭合 + 固定摩擦系数。

**指标**：抓取成功率；滑移事件率；**共识幻觉率**（融合置信度 > 0.9 但真实失败的比例）；探针开销（次数/时间）；安全违规数；端到端时延。

**消融**：去掉 MCC、去掉 AEC、扫描 τ_cons、扫描 μ^L、改变探针预算；分别验证每个证书对共识幻觉率与成功率的边际贡献。

**压力测试**：透明/反光物体（视觉共模错误）、遮挡、传感器掉线、标定漂移、对抗性触觉欺骗（伪造接触信号）、可变形物体。

**预期**（待实验验证）：AEC 应显著降低透明/反光场景的共识幻觉率（假设从视觉主导融合的两位数百分比降到个位数），代价是 50–200ms 的探针时间与少量额外能耗；过度收紧 μ^L 会提升安全性但降低成功率，需用 Pareto 前沿选择工作点；若 AEC 被移除，MCC 单独不足以发现共模错误，共识幻觉率应回升——这正是本方案的核心可证伪预测。

## 7. 本轮最大风险（最终确认）

**一句话**：**当多模态共享共模误差时，融合会产生「共识幻觉」——置信度越高、错误越隐蔽；而用于打破幻觉的主动探针又可能扰动脆弱物体或诱发滑动，使证书建立在「错误前提 + 已被扰动污染的证据」之上，这是当前方案最危险且最难在线自检的失效模式。**
