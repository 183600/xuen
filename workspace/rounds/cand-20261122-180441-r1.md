# 第 1 轮（新灵感循环第 1 轮；本轮灵感：「MuJoCo」×「多模态大模型」）

> **基线**：上一循环产出 MetricVoiceGauge-NCD-HUTDH-v20+IP-420–424（几何/感知/联邦证书体系）。
> 本轮纪律：**物理是证伪器、语义是假设源、证书是交集**。不推倒 v20：v20 的 PCA/CTS/CFC/HPC/CFCtrl 全部保留。本轮只做一件事：**用 MuJoCo 的接触物理与多模态大模型的场景理解，为既有几何证书叠加一层「只会收缩」的物理-语义证伪层**。

## 0. 直觉与动机

**灵感 1（MuJoCo → 物理引擎不是验证器，而是证伪器）**
直觉：MuJoCo 通常被当作"仿真里跑通了 = 策略可用"的验证器。但它的接触模型（solref/solimp 软接触、线性化摩擦锥、无黏附/无各向异性摩擦）与真实世界存在 sim-to-real 鸿沟，任何"仿真通过"都不构成安全授权。反过来用：**只允许 MuJoCo 说"不"**。核心创新：**物理证伪器 (Physics-Grounded Falsifier, PGF)**。它在参数域内做批量对抗 rollout（摩擦、质量、时延、初态抖动、传感噪声），只要找到一条违反接触动力学约束（滑移、翻倒、穿透、冲击力超限）的轨迹，就用 Lipschitz 裕度把该轨迹的整个邻域从证书域中挖掉；找不到反例时**恒等返回**，不扩域。关键反直觉点：**"仿真通过"零信息量，"仿真失败"才是信息**——证书的活性来自"尚未被证伪"，而不是"已被验证"。

**灵感 2（多模态大模型 → 语义不是权威，而是反例的生成器）**
直觉：多模态大模型能从 RGB-D、任务指令与物体元数据里读出几何证书看不见的风险（"杯子是薄壁易碎"、"把手会勾住相邻物体"、"桌面湿滑"）。但 VLM 会幻觉、会过度自信，绝不能让它直接授权动作。核心创新：**语义约束编译器 (Semantic Constraint Compiler, SCC)**。把 VLM 的自由文本风险主张编译成**形如 `θ ∉ R_k` 的禁入区谓词**（只允许加约束，绝不允许放宽）；编译失败或"放宽型"主张进入隔离区；置信度用保形校准（conformal）扩张成更保守的禁入区。关键反直觉点：**让模型多想象失败，反而让真实成功率上升**——VLM 的价值不是证明安全，而是把"可能出错的世界"补全，交给 PGF 去证伪。

**灵感 3（两者如何统一 → 提议-证伪证书循环）**
直觉：单独看，PGF 只会在"已采样的物理参数"里找反例，VLM 只会给出"语言层面的风险"。两者相乘才完整：VLM 负责**拓宽失效假设空间**，MuJoCo 负责**在该空间内搜索可执行的反例**，失败画廊再把真实反例回灌给 VLM。核心创新：**反例引导证书精化 (Counterexample-Guided Certificate Refinement, CGCR)**：VLM 提议禁入区 → MuJoCo 在剩余域内对抗搜索反例 → 反例经 Lipschitz 管保守扩张后从域中挖除 → 失败轨迹进入画廊、驱动下一轮提议。共享状态 `ζ_v21 = (Θ_col, Φ_dyn, R_sem, gallery, ledger, mode_v21)`。统一接口：**几何证书回答"是否无碰撞"，PGF 回答"是否动态可行"，SCC 回答"是否有语义禁入"，三者都只做集合差；任意一层失效都退回 v20 的 Θ_col**。

**三者如何与 v20 统一**
v20 回答"给定几何/感知，节点 n 在 θ 下是否零碰撞"，v21 回答"在零碰撞的前提下，θ 是否经得起接触物理与语义风险的证伪"。PGF 是物理侧（证伪动力学），SCC 是语义侧（生成禁入假设），CGCR 是循环侧（把反例变成收缩），MPL/RMC 是保证侧（可审计与 sim-to-real 覆盖）。最终域 `Θ_v21 = Θ_col \ Tube(Φ_dyn) \ ∪_k Expand(R_k, q_{1-α})`，由构造保证 `Exec_v21 ⊆ Exec_v20`。

## 1. 研究问题（轮次升级版）

- **Q1（有限采样证伪的保守性与紧致性）**：PGF 的批量 rollout 只能覆盖有限物理场景，如何用 Lipschitz 裕度把"点反例"扩张成"整球反例"从而保证不漏留不安全点？Lipschitz 常数/梯度如何在线估计而不引入不安全？对抗场景采样如何在给定预算内优先覆盖最坏物理参数，同时避免过度挖除导致活性崩塌？

- **Q2（自然语言风险的稳定编译）**：SCC 如何把"薄壁易碎""把手会勾住"这类模糊主张稳定编译成可判定的禁入区谓词？如何机械地拒绝"放宽型"主张与幻觉？VLM 的置信度如何经保形校准映射为禁入区扩张半径，使"越不确定挖得越多"？

- **Q3（CGCR 的终止、单调与诚实性）**：提议-证伪循环如何保证每轮体积单调不增、在有限预算内终止？"未找到反例"如何被诚实标注为"未证伪"而非"已证明"？失败画廊如何维持反例多样性，避免对同一失效模式反复采样？

- **Q4（sim-to-real 覆盖与版本漂移）**：如何用真实残差以保形方式标定 PGF 的扰动族，使"仿真未证伪"在概率意义下覆盖真实物理？当 VLM/MuJoCo 版本、标定或提示模板漂移时，语义层如何 fail-closed 地整体作废并回退到物理层？

## 2. 设计原则（在 P31–P33 基础上新增 P34–P36）

**P34 物理证伪单调律（Falsification Monotonicity）**
对参数域 `Θ_col`，PGF 输出 `Θ_phys = Θ_col \ Tube(Φ_dyn)`，其中 `Φ_dyn = {θ : ∃w ∈ P(θ), rollout(θ,w) ⊨ φ_dyn}` 为证伪集，`Tube(θ0) = Ball(θ0, δ(θ0)/L)` 为反例保守管（δ 为违规裕度，L 为动力学对 θ 的 Lipschitz 常数）。**"未找到反例"返回恒等映射，绝不放宽域**。任何 `Tube` 只覆盖已证伪点，故挖除不触及真实安全点；L 估计偏差只会改变紧致性，不改变安全性。由此 `Θ_phys ⊆ Θ_col`。

**P35 语义禁入律（Semantic Forbidden-Region Law）**
SCC 只接受形如 `ψ_k : θ ∉ R_k` 的**禁入型**谓词；"放宽型"主张（如"可以抓得更紧"）一律隔离。语义域 `Θ_sem = Θ_phys \ ∪_k Expand(R_k, q_{1-α,k})`，其中 `Expand` 对禁入区做保守膨胀，`q_{1-α,k}` 为 VLM 置信度的保形分位。**不确定性越大，禁入区越大**。编译失败即丢弃，故 `Θ_sem ⊆ Θ_phys`。

**P36 提议-证伪可审计律（Propose-Falsify Auditability）**
每个语义谓词与每个物理见证都写入**多模态溯源账本 (MPL)**：记录模型版本、提示哈希、图像哈希、仿真种子、solver 参数、结果与反例管半径，并以 Merkle 链防篡改。给定账本可离线重放。**当前版本与账本不兼容时，语义层整体作废并回退到 Θ_phys**（fail-closed）。终止时证书显式标注"在采样场景族 P 内未证伪"，而非"已证明安全"。

## 3. 与基线的接口（如何退化）

- PGF 失效（MuJoCo/MJX 不可用、超预算）⇒ 跳过物理层，`Θ_phys = Θ_col` ⇒ 等价 v20；
- SCC 失效（VLM 不可用、编译全失败）⇒ 跳过语义层，`Θ_sem = Θ_phys` ⇒ 等价 v20；
- RMC 失效（无真实残差）⇒ 扰动族取先验上界（更宽）⇒ 更保守，仍等价 v20 的子集；
- MPL 失效（账本不可写/校验失败）⇒ 语义层作废 ⇒ 回退物理层；
- CGCR 耗尽预算 ⇒ 返回当前最大已证伪收缩域，标注"未证伪"；
- 全部失效 ⇒ 完全回退到 v20 的 `Θ_col`；
- **安全继承**：PGF 只挖除、SCC 只加禁入、CGCR 只做集合差、MPL 只做 fail-closed；任意失效都使域收缩或恒等，`Exec_v21 ⊆ Exec_v20` 由引理 157–163 保证（在 RMC 覆盖假设下）。

## 4. 预期贡献

1. **物理证伪证书**：首次把 MuJoCo 从"仿真验证器"改写为"只说不的证伪器"，用 Lipschitz 反例管把有限采样升级为保守挖除，使接触动力学风险进入可证明的收缩链；
2. **语义禁入编译**：给出 VLM 风险主张到禁入区谓词的编译规则、隔离机制与保形置信扩张，使"多模态理解"以只收缩的方式注入证书，而非成为不可审计的授权源；
3. **提议-证伪循环**：给出 CGCR 的单调收缩、有限预算终止与失败画廊多样性机制，把"生成假设 + 证伪假设"统一为证书精化算子；
4. **sim-to-real 保形覆盖**：用真实残差标定扰动族，使"仿真未证伪"具备概率覆盖保证，并给出覆盖失效时的显式回退；
5. **三层可审计证书**：几何（v20）+ 物理（PGF）+ 语义（SCC）合成 TSVC，配合 MPL 溯源账本，实现"碰撞安全 → 动态可行 → 语义合规"的闭环，且 `Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18`。

## 5. 本轮最大风险

**一句话**：若 MuJoCo 的接触模型与多模态大模型**共享同一个系统性盲区**（如都忽略薄壁结构的黏附/各向异性摩擦），则 PGF 找不到反例、SCC 也不提出对应禁入区，CGCR 对该区域保持 SAFE，把"未找到反例"误当作"不存在反例"——形成**证伪者与被证伪者共谋的共享盲区**。

# IP-425 Physics-Grounded Falsifier
class PhysicsGroundedFalsifier:
    def __init__(self, mjx_model, horizon, dt, lipschitz_est, budget):
        self.model = mjx_model
        self.horizon = horizon
        self.dt = dt
        self.L = lipschitz_est          # 违规裕度对 theta 的 Lipschitz 估计
        self.budget = budget            # 单轮 rollout 预算

    def scenario_family(self, theta, B):
        # 对抗采样：优先在摩擦下界、质量上界、时延上界、初态抖动边界取场景
        ws = adversarial_sample(B, n=self.budget, theta=theta)
        return ws

    def falsify(self, theta_dom, B, n_theta):
        thetas = sobol_sample(theta_dom, n_theta)
        witnesses = []
        for theta0 in thetas:
            ws = self.scenario_family(theta0, B)
            traj = mjx.rollout_batch(self.model, theta0, ws, self.horizon, self.dt)
            delta = contact_violation_margin(traj)   # 逐场景违规裕度
            if delta.max() > 0.0:
                r = float(delta.max()) / max(self.L, EPS)
                witnesses.append(Witness(theta0=theta0, delta=delta.max(),
                                         radius=r, trajectory=traj))
        return witnesses

    def remove(self, theta_dom, witnesses):
        # 只做集合差：整球挖除，绝不并集/扩张
        for w in witnesses:
            theta_dom = theta_dom.difference(Ball(w.theta0, w.radius))
        return theta_dom


# IP-426 Semantic Constraint Compiler
class SemanticConstraintCompiler:
    def __init__(self, vlm, alpha=0.1):
        self.vlm = vlm
        self.alpha = alpha
        self.quarantine = []

    def compile(self, rgbd, instruction, metadata, gallery_summary):
        raw = self.vlm.propose(rgbd, instruction, metadata, gallery_summary)
        preds = []
        for claim in raw:
            psi = self.formalize(claim)              # -> 谓词 or None
            if psi is None or not self.well_formed(psi):
                self.quarantine.append(claim); continue
            if not psi.is_restrictive():
                # 放宽型主张一律拒绝：语义层只允许加约束
                self.quarantine.append(claim); continue
            preds.append(Predicate(psi=psi, confidence=claim.confidence,
                                   provenance=hash_provenance(claim, rgbd)))
        return preds

    def shrink(self, theta_dom, preds):
        for p in preds:
            q = conformal_quantile(p.confidence, self.alpha)
            theta_dom = theta_dom.difference(expand(p.R, q))
        return theta_dom


# IP-427 Counterexample-Guided Certificate Refinement
class CounterexampleGuidedRefinement:
    def __init__(self, pgf, scc, rmc, max_iter=8):
        self.pgf, self.scc, self.rmc = pgf, scc, rmc
        self.max_iter = max_iter
        self.gallery = FailureGallery()

    def run(self, theta_col):
        theta = theta_col
        B = self.rmc.scenario_bounds()
        for _ in range(self.max_iter):
            preds = self.scc.compile(self.gallery.summary())
            theta_sem = self.scc.shrink(theta, preds)
            witnesses = self.pgf.falsify(theta_sem, B, n_theta=self.pgf.budget)
            if not witnesses:
                return theta_sem, self.gallery, "NOT_FALSIFIED"
            theta_next = self.pgf.remove(theta_sem, witnesses)
            assert volume(theta_next) <= volume(theta)     # 单调不增
            self.gallery.add(witnesses)
            theta = theta_next
        return theta, self.gallery, "BUDGET_EXHAUSTED"


# IP-428 Multimodal Provenance Ledger
class MultimodalProvenanceLedger:
    def __init__(self):
        self.merkle = MerkleTree()
        self.versions = []

    def record(self, kind, payload, versions):
        leaf = hash((kind, payload, versions))
        self.merkle.add(leaf)
        self.versions.append(versions)
        return leaf

    def verify(self, cert):
        return replay(cert) and self.merkle.verify(cert.merkle_path)

    def compatible(self, current_versions):
        return all(v == current_versions for v in self.versions)


# IP-429 Robustness Margin Calibrator
class RobustnessMarginCalibrator:
    def __init__(self, alpha=0.1):
        self.alpha = alpha
        self.B = None

    def calibrate(self, real_residuals, physical_priors):
        q = conformal_quantile(real_residuals, 1.0 - self.alpha)
        self.B = build_scenario_bounds(q, physical_priors)
        return self.B

    def scenario_bounds(self):
        return self.B if self.B is not None else PRIOR_UPPER_BOUND

    def coverage_guarantee(self):
        return 1.0 - self.alpha

## 3. 推导

**引理 157（物理证伪单调性）** PGF 更新为 `Θ_phys = Θ_col \ Tube(Φ_dyn)`，是集合差；无见证时返回恒等映射。故 `Θ_phys ⊆ Θ_col`，`Exec_v21 ⊆ Exec_v20`。∎

**引理 158（反例管保守性）** 设违规裕度 δ 对 θ 满足 L-Lipschitz。若 `δ(θ0) > 0` 且 `r ≤ δ(θ0)/L`，则 ∀θ∈Ball(θ0,r)：`δ(θ) ≥ δ(θ0) − L‖θ−θ0‖ > 0`，整球均被证伪，挖除不触及真实安全点。若 L 被低估，r 偏大，最多多挖（更保守）但绝不少留不安全点；若 L 被高估，r 偏小，仅紧致性下降。故 L 估计误差只影响活性，不影响安全性。∎

**引理 159（语义禁入收缩性）** SCC 只接受禁入型谓词 `θ ∉ R_k`，且 `Expand` 对 R_k 单调、`q_{1-α,k}` 随不确定性单调增大；放宽型与编译失败主张被隔离。故 `Θ_sem = Θ_phys \ ∪ Expand(R_k,q) ⊆ Θ_phys`。∎

**引理 160（CGCR 终止与单调）** 每轮或恒等（无见证）而终止，或体积严格减小（正测度反例管）；体积非负，故有限步终止或耗尽预算。终止结果显式标注为"在采样场景族 P 内未证伪"，不蕴含全称安全。∎

**引理 161（溯源可审计性）** MPL 对每个谓词与见证记录模型版本、提示哈希、图像哈希、仿真种子、solver 参数与结果，并以 Merkle 链防篡改；给定账本可离线重放，故 TSVC 可机械复核。∎

**引理 162（版本漂移失效安全）** 若当前模型/引擎版本与账本记录不兼容，语义层整体作废，`Θ` 回退到 `Θ_phys`，且 `Θ_phys ⊆ Θ_col`。故版本漂移只会使域收缩。∎

**引理 163（sim-to-real 覆盖下安全继承）** 若 RMC 的保形扰动族满足 `P(w_real ∈ P(θ)) ≥ 1−α`，且 `φ_dyn` 覆盖真实违规，则在 1−α 置信下 `Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18`。∎

**引理 164（共享盲区不可自证）** 若区域 ρ 同时满足 (i) MuJoCo 接触模型在 ρ 上系统性无违规、(ii) VLM 未提出覆盖 ρ 的禁入区，则 CGCR 对 ρ 恒等，ρ 保持 SAFE。故本体系**无法自证**该类盲区，须引入异构证伪器（真实触觉、黏附模型、独立物理引擎）。∎

## 7. 已知风险与失效模式

1. **共享盲区（最大风险）**：MuJoCo 接触模型与 VLM 同时漏掉某类失效（黏附、各向异性摩擦、薄壁变形），导致 CGCR 恒等、"未证伪"被误当安全。缓解：异构证伪器（触觉、独立引擎、真实残差在线监测）、盲区探测实验 E792、对"长时间无新反例"的区域主动注入扰动。

2. **Lipschitz 常数低估导致过度挖除**：L 低估使反例管偏大，挖掉本可安全执行的点，活性下降（但不会不安全）。缓解：保守上界估计、局部梯度修正、活性反馈闭环、E795 参数敏感性。

3. **VLM 幻觉产生"看似合理但物理无意义"的禁入区**：即使只收缩，也会浪费活性甚至挖空域。缓解：禁入区必须绑定可测物理量（力/速度/接触点）、人工可读模板、E794 对抗注入、隔离率监控。

4. **保形覆盖的分布假设**：RMC 的 1−α 覆盖依赖真实残差与标定集可交换；若部署环境发生分布漂移（新桌面材质、新物体），覆盖失效。缓解：在线残差监测、滑窗重标定、覆盖率跌破阈值即回退 v20。

5. **MuJoCo 数值刚性与接触求解误差**：软接触参数、时间步长、solver 迭代不足会产生假违规或假安全。缓解：多组 solver 参数交叉验证、时间步收敛性检查、账本记录全部 solver 参数。

6. **CGCR 预算耗尽下的"伪不动点"**：预算耗尽时返回的域可能仍含未发现反例。缓解：证书显式标注 `BUDGET_EXHAUSTED`、禁止将其用于高风险任务、按风险分级增加预算。

7. **账本存储与隐私**：图像哈希与提示可能泄露场景信息。缓解：只存哈希与必要元数据、差分隐私提示摘要、账本本地化。

## 8. 本轮最大风险

**一句话**：本体系的安全性完全依赖"MuJoCo 的违规谓词 + VLM 的禁入假设"能覆盖真实失效；一旦二者共享同一系统性盲区（尤其接触物理的黏附/各向异性摩擦与薄壁变形），CGCR 会把"在采样场景族内未找到反例"错当作"不存在反例"，产生**证伪者与被证伪者共谋的共享盲区**——这是任何"生成-证伪"式安全框架都无法自证的根风险。
