# 第 1 轮（新循环 v3：「示教学习」×「面部表情识别」）—— 把人类从“干扰源”改写为“示教源 + 意图源”

> 这是新循环的第 1 轮；保留区承接上一循环 v2 的 UIP 清单与事实。**本轮不是推倒重来**：保留 UIP-01′/02′/05/08′/09′/11–15，新增 7 个想法，旗舰改为 **SAGE**。核心转向：规则把人类写成“会撤回你进度的干扰者”，但示教学习告诉我们，**同一个人的动作也是最好的老师**；面部表情识别告诉我们，**这个“老师”在动手前已经把意图写在脸上**。于是把“被动恢复”升级为“预测—预防—检测—恢复”的四段闭环。

## 0. 两个直觉（先讲人话）

1. **示教学习的直觉**：32k 条遥操作演示不是“标准答案”，而是“人类在犯错与纠错中完成任务”的录像。一个遥操作员抓歪了、松开重抓、把拉链拉过头再退回——这些片段本身就是稀缺的“撤回→恢复”数据，只是没人给它打标签。更进一步，**把一段演示倒着放，就是一次“进度被撤回”的免费模拟**：正放是“叠好”，倒放就是“翻开”；正放是“拉上”，倒放就是“拉开”。这正是 `human_*` 干扰的形状。
2. **面部表情识别的直觉**：人不会无缘无故伸手。伸手前会有前兆：皱眉、抿嘴、身体前倾、视线移向目标、手从画面边缘进入。表情/面部行为是**意图的提前量**。如果机器人能读出这个提前量，就可以在人类真正撤回之前“让一下 / 稳一下 / 抢一步做完”，把恢复问题变成预防问题。

## 1. 严谨定义（把直觉变成可检验对象）

### 1.1 示教数据与进度泛函

设第 i 条演示 τ_i = {(o_{i,t}, a_{i,t}, l_i)}_{t=0}^{T_i}，潜在物理状态 s_t。任务有 G 个计分步，权重 w_g，谓词 φ_g(s)∈{0,1}，步骤分 S(τ)=Σ_g w_g φ_g(s_{T_i})。定义**进度泛函** Φ: S→[0,1]，满足 Φ(s_t) 沿演示时间总体上升（允许局部平台）。Φ 可以由语言条件下的时序对比学习、目标图像距离或“时间距离”回归得到；它只需要**相对进度**，不要求与官方计分点完全一致。

### 1.2 自纠正事件（Correction Event）

给定 Φ 与阈值 δ, ε, H，若存在区间 [t1,t2] 使

- **局部回退**：∃ t'∈[t1,t2]，Φ(s_{t'}) < Φ(s_{t1}) − ε；
- **净恢复**：Φ(s_{t2}) − Φ(s_{t1}) ≥ δ；
- **无外部执行者**：该区间内没有第二个人手进入操作区（可用手部检测/三角化近似）；

则称 [t1,t2] 为一个**自纠正事件**，三元组 (s_{t1}, s_{t'}, s_{t2}) 为一条**纠正样本**。这是“示教里的免费恢复数据”：它不是人为干扰，但它与干扰共享“进度回退后重做”的因果结构。

### 1.3 时间反向判别器（TRD）

训练 D_ψ(s_t, s_{t+k}, l) → {forward, reverse}：正样本取真实演示的 (s_t, s_{t+k})，负样本取同一段倒序的 (s_{t+k}, s_t)（或倒放视频帧）。定义**进度速度**

v_t = logit D_ψ(s_t, s_{t+k}, l) − logit D_ψ(s_{t−k}, s_t, l)。

若 v_t < −τ 连续 m 帧，则判为 `regressed`。注意：TRD 只学“时间箭头/进度方向”，不学“成功与否”；它是 UIP-01′ 的 `regressed` 检测器，而不是成败裁判。TRD 还有第二种用法：把演示的动作段倒序后送回 Gazebo/真机做“状态回滚”，即可生成 `(完成→被撤回→恢复)` 的训练三元组。

### 1.4 干预风险与面部行为

设 N(t) 为人类干预计数，F_t 为到 t 为止的机器人观测与人类面部行为。**干预风险**定义为

λ_t = lim_{Δ↓0} P(N(t+Δ)−N(t)=1 | F_t) / Δ。

用生存分析或时序 Transformer 估计。面部行为 e_t 不只取 7 类表情，而取**动作单元（AU）+ 视线 + 头姿**：皱眉（AU4）、抿嘴（AU24）、微笑（AU12）、视线偏移、头向目标转动。**纯 7 类情绪标签噪声大、跨文化漂移重；AU/视线/头姿更接近“意图的物理量”。** 这是把“面部表情识别”操作化为“面部行为/意图识别”。

### 1.5 特权表情蒸馏

训练期有人脸 e_t，部署期不保证有人脸。把 e_t 当**特权信息**（privileged information）：训练学生 q_θ(e_t | o_t, 本体感觉, 手部检测) 与风险头 h_θ(λ_t | o_t)，测试时若人脸检测置信度低，就用学生预测；若检测到人脸，用教师信号。最终仍是**一条骨干 + 几个头**，满足单模型合规。这样即使比赛现场的脸不可见，训练期的表情仍能作为“教师”把意图先验灌进策略。

### 1.6 表情加权模仿

L_BC = Σ_t w_t · ℓ(π(o_t,l), a_t)，w_t = g(e_t)。工作假设：**挫败/犹豫/惊讶的片段更可能是坏示范或高噪声片段，应降权；专注/中性片段应保权。** 这条不是先验真理，必须用 E204 检验；若无效则退化为“仅用表情做阶段分割”，不要硬凹因果。

## 2. 本轮核实/待核实的事实

承接 v2（均 2026-11-12 已核实）：32 任务与计分步权重；`human_*` 存在大量“反向撤回”；`get_action` 返回开环动作块、评测端整块执行；N 端口并发且状态需隔离；图像 JPEG q95；平均成功率+步骤分排序；单模型/实时性/可信度约束；32 个公开数据集约 32k 条遥操作演示，但**没有专门的“人为撤回”演示**。

**本轮新增的“必须先审计”的事实（不假设）**：

| 审计 | 问题 | 若否，如何降级 |
|---|---|---|

> 这四行是本轮最重要的“反自我欺骗”设计：**先证明信号存在，再谈方法。** 任何跳过 A0–A3 的“表情驱动”方案，都是在用未经验证的因果链讲故事。

## 3. 瓶颈假设

- **H1（示教侧）**：遥操作演示中的自纠正片段，是公开数据里唯一“零成本”的撤回-恢复监督；其密度足以训练一个恢复头。
- **H2（示教侧）**：时间反向判别器能从演示中提取“进度方向”，且比手工几何谓词更任务通用；倒放演示可低成本生成撤回样本。
- **H3（表情侧）**：人类撤回不是瞬发的，面部行为/视线/手部进入提供了 0.5–2 秒的提前量；预测它可以把“恢复”变成“预防”。
- **H4（表情侧）**：表情在部署期不可靠，但作为**特权信息**可蒸馏出“无脸也可用”的意图预测器。
- **H5（耦合）**：示教提供“什么是正向进度”，表情提供“人类何时要反向”；两者结合才能既判得准又躲得开。单靠任一侧都不够。

## 4. 候选与合并

围绕两个词发散 9 个草案，合并为 7 个新 UIP + 1 个集成旗舰：

- **UIP-16 CRM**：示教自纠正挖掘（Correction-Rich Mining）
- **UIP-17 TRD**：时间反向示教（Time-Reversal Demonstration）
- **UIP-18 FIA**：面部行为/干预前兆（Facial/Intention Anticipation）
- **UIP-19 PED**：特权表情蒸馏（Privileged Expression Distillation）
- **UIP-20 EWI**：表情加权模仿（Expression-Weighted Imitation）
- **UIP-21 DRR**：演示检索式恢复（Demonstration-Retrieval Recovery）
- **UIP-22 SAGE**：四段闭环旗舰（Predict–Prevent–Detect–Recover）
- **UIP-23 HEC**：人类表情课程（Human-Expression Curriculum，可选，降级为训练技巧）
- **UIP-24 FER-OOD**：表情新颖性检测（封存：因果链弱，容易变成“看脸猜 OOD”）

合并逻辑：UIP-16/17 是**不依赖人脸、立刻可做**的示教侧主线；UIP-18/19/20 是**有条件的表情侧增强**；UIP-21 是把示教变成“外置记忆”；UIP-22 把四者串成闭环。**先做 16/17，再按 A0–A2 的审计结果决定 18/19/20 的投入比例。**

## 5. 与 v2 的差异（为什么不是重复）

- v2 的 DCR-R/DRF 是“检测到撤回→重做”，属于**反应式**；本轮把“人类意图”提前到动作之前，属于**预测式**。
- v2 的 DRF 主要靠 Gazebo 脚本化干扰；本轮先用**演示自身**造纠正样本与倒放样本，把 Gazebo 降为“补足长尾”的第二来源。
- v2 的验证器偏几何/规则；本轮新增 **TRD 时间箭头**这一任务通用的自监督信号，减少逐任务写谓词的成本。
- v2 的“单模型”只强调共享骨干；本轮把 FER 明确为**训练期特权信息**，从合规上更干净。

## 6. 本轮最大风险

**一句话**：最大的风险不是“表情识别不准”，而是**把表情当成因果信号**——它可能只是灯光、遮挡、个体差异，甚至镜头里根本没有脸；若不先做 A0–A3 审计与误报预算校准，SAGE 会把“预测干扰”变成“过度让路”，反而丢掉步骤分。

**→ 本轮最值得押注：UIP-22 SAGE 的“示教—表情—恢复”闭环，但执行顺序必须是“先 16/17（不依赖人脸、立刻可做），后 18/19（按审计结果有条件增强）”。先审计，后投入；先证明信号，再谈系统。**

## 1. 旗舰深潜：UIP-22 · SAGE（Socially-Aware Guided Experience，社会感知的示教经验闭环）

### 1.1 直觉

把人类干扰想象成一场“双人舞”：对方伸手之前，肩膀会先动、视线会先到、表情会先变。SAGE 先读这些前兆（Predict），再决定是让开、稳住还是抢做（Prevent）；如果还是被撤回，就用演示里学到的“时间箭头”发现它（Detect），并从演示/仿真里挖出的恢复片段重做（Recover）。**它把“恢复”从被动反应变成了有提前量的社会性行为。** 这里的“reverse experience”专指 CRM/TRD 从演示中挖出的反向经验（自纠正 + 倒放），不是指强化学习里的 experience replay。

### 1.2 严谨定义

一个 SAGE 策略是一个五元组 π = (π_base, D_ψ, h_θ, V_φ, π_rec)，其中：

- π_base(a_t | o_t, l, g) 是共享骨干的动作块策略（ACT/Diffusion Policy 类）；
- D_ψ(s_t, s_{t+k}, l) 是时间反向判别器，输出 forward/reverse 概率；
- h_θ(λ_t | o_t, e_t) 是干预风险头（e_t 可为空，见 PED）；
- V_φ(o_t, l, g) 是计分步子目标验证器（几何谓词 + 学到的进度头）；
- π_rec(a_t | o_t, l, g, R) 是恢复头，R 为检索到的演示片段（可选）。

在线决策：

1. **Predict**：若人脸可用，e_t = FaceBehavior(o_t)；否则 e_t = Student(o_t)。估计 λ_t。
2. **Prevent**：若 λ_t > θ_hi，按“剩余进度 r_g、预计完成时间、碰撞风险”在 {yield, stabilize, finish} 中选一个：
   - `finish`：当前步只差最后一点，加速做完（保住步骤分）；
   - `stabilize`：抓住/压住当前物体，降低被撤回概率；
   - `yield`：松手后退，避免人机碰撞，等干预结束再重做。
3. **Detect**：块间用 TRD 的 v_t 与 V_φ 共同判 `done/fail/regressed`；v_t < −τ 连续 m 帧 → `regressed`。
4. **Recover**：`regressed` 时，若 DRR 检索到高相似演示段 R，则 π_rec(o_t,l,g,R)；否则用 CRM 训练的通用恢复头重做当前子目标。

### 1.3 伪代码

```python
class SAGE:
    def __init__(self, base, trd, hazard, verifier, recovery,
                 theta_hi=0.7, tau=0.5, m=3):
        self.base, self.trd = base, trd
        self.hazard, self.verifier = hazard, verifier
        self.recovery = recovery
        self.theta_hi, self.tau, self.m = theta_hi, tau, m
        self.g, self.buf, self.neg = 0, [], 0

    def reset(self):
        self.base.reset(); self.g = 0; self.buf = []; self.neg = 0

    def get_action(self, obs):
        # 1) Predict：人脸可用则用教师，否则用蒸馏学生
        e = self.hazard.face_behavior(obs)          # None if not visible
        lam = self.hazard(obs, e)                   # P(intervention within τ_h)

        # 2) Prevent：只在置信度高时介入，避免过度让路
        if lam > self.theta_hi:
            mode = self.hazard.arbitrate(obs, self.g, lam)
            if mode == "yield":
                return self.hazard.yield_action(obs)   # 后退/松手/避开
            if mode == "finish":
                return self.base.get_action(obs, self.g, fast=True)

        # 3) Detect：时间箭头 + 子目标谓词
        v = self.trd.progress_velocity(obs)
        if v < -self.tau:
            self.neg += 1
        else:
            self.neg = 0
        if self.neg >= self.m:
            self.neg = 0
            self.g = self.recovery.target(obs, self.g)  # 退回被撤回的子目标
            return self.recovery.get_action(obs, self.g)  # 4) Recover

        if self.verifier.done(obs, self.g):
            self.g += 1
        return self.base.get_action(obs, self.g)
```

> 与 API 对齐：`get_action` 每次返回 ≤ metadata 声明的块长；块间做上述判断。`reset` 每个 episode 一次。所有头共享骨干与视觉编码器，满足单模型。

### 1.4 与 v2 旗舰的差异

| 维度 | v2 UIP-01′ | v3 SAGE |
|---|---|---|
| 触发 | 子目标 done→undone 的**事后**检测 | 面部/手部前兆的**事前**预测 + TRD 事后检测 |
| 数据 | Gazebo 脚本化干扰为主 | 演示自纠正 + 倒放演示为主，Gazebo 补长尾 |
| 判定 | 逐任务几何谓词 | TRD 任务通用时间箭头 + 几何谓词 |
| 表情 | 未使用 | 训练期特权信息，部署期可无脸 |
| 风险 | 误判导致反复重做 | 误报导致过度让路（新增 FYR 指标） |

## 2. UIP-16 · CRM（Correction-Rich Mining，示教自纠正挖掘）

### 2.1 直觉

遥操作员不是完美示范者。他们会抓空、抓歪、拉过头、松开重来。**这些“错误—纠正”片段，恰好就是公开数据里缺失的“撤回—恢复”监督**，只不过干扰源是操作员自己，而不是外部人手。它们不需要额外采集，只需要被“看见”。

### 2.2 严谨定义

输入演示 τ 与进度泛函 Φ。对每个 t1，找最小 t2>t1 使 Φ(s_{t2})−Φ(s_{t1}) ≥ δ；令 t' = argmin_{t∈[t1,t2]} Φ(s_t)。若 Φ(s_{t'}) < Φ(s_{t1})−ε 且区间内无外部执行者，则输出纠正三元组 (s_{t1}, s_{t'}, s_{t2})。对三元组做两类增强：

- **状态回滚增强**：在仿真里把 s_{t2} 的物体位姿“回拨”到 s_{t'}，让策略从“已完成”状态重新经历“被撤回”；
- **动作重放增强**：把 [t', t2] 的动作段作为“恢复示范”，条件化为“从 t' 状态回到 t2 目标”。

### 2.3 挖掘伪代码

```python
def mine_corrections(tau, Phi, delta=0.05, eps=0.02, H=40):
    events = []
    for t1 in range(len(tau) - 1):
        t2 = t1 + 1
        while t2 < min(len(tau), t1 + H) and Phi[t2] - Phi[t1] < delta:
            t2 += 1
        if t2 >= len(tau) or Phi[t2] - Phi[t1] < delta:
            continue
        trough = min(range(t1, t2 + 1), key=lambda t: Phi[t])
        if Phi[trough] < Phi[t1] - eps and no_external_agent(tau, t1, t2):
            events.append((t1, trough, t2))
    return events          # 每条 = (纠正前, 最差点, 恢复后)
```

### 2.4 关键细节与风险

- **Φ 的质量决定一切**：优先用“语言条件的时间距离”或“目标图像嵌入距离”，不要用像素重建误差（它对视角/光照敏感）。
- **不要把“抖动”当纠正**：加最小持续时间与动作一致性约束；速度高频抖动不算进度回退。
- **外部执行者检测**：演示里通常只有机器人，但可能有第二只手入镜；用检测框 + 轨迹一致性过滤。
- **风险**：若 A1 审计发现自纠正密度 <10%，CRM 不足以单独训练恢复头，必须与 TRD/DRF 合流。

## 3. UIP-17 · TRD（Time-Reversal Demonstration，时间反向示教）

### 3.1 直觉

正放的“把碗叠上去”倒过来就是“把碗拿下来”。人类干扰 `human_*` 的文本大量是“合上后再打开”“拉上后再拉开”“叠好后翻开”——**这些几乎就是演示的倒放**。所以倒放演示是免费的“撤回模拟器”；而学会区分正放/倒放，就等于学会了一个任务通用的“进度方向感”。

### 3.2 严谨定义

**判别器**：D_ψ(s_t, s_{t+k}, l) → [0,1]，正样本来自真实演示，负样本来自同段倒序。**进度速度** v_t = logit D(s_t,s_{t+k}) − logit D(s_{t−k},s_t)。在线时，连续 m 帧 v_t < −τ 判 `regressed`。

**数据生成器**：对演示段 τ_{a:b}，构造反向状态序列 \tilde{s}_t = s_{a+b−t} 与反向动作 \tilde{a}_t = a_{a+b−t}。注意：

- 反向动作**不保证物理可行**，所以只用于两类场景：① 在 Gazebo 里做状态回滚（teleport 物体到 \tilde{s}），不直接执行反向动作；② 作为 D 的负样本，不进入动作克隆。
- 对“对称/可逆”任务（拉链、开合、拧盖、叠/翻），反向动作往往近似可行，可直接重放；对“不可逆”任务（倒水、撕纸、插拔），只用状态回滚。

### 3.3 训练与在线伪代码

```python
# 离线：训练时间反向判别器
for (s_t, s_tk, l) in demos:
    D.train(s_t, s_tk, l, label=1)          # forward
    D.train(s_tk, s_t, l, label=0)          # reverse
    # 可选：加入速度/接触/夹爪状态，防止只学光照/运动模糊伪影

# 在线：块间回归检测
def regressed(obs, D, k=8, tau=0.5, m=3):
    v = logit(D(obs_t, obs_tk, l)) - logit(D(obs_tk, obs_t, l))
    return v < -tau   # 连续 m 次由状态机计数
```

### 3.4 防止“学错时间箭头”

- **捷径风险**：倒放视频有独特的光流/运动模糊/阴影方向，D 可能只学这些伪影。对策：① 输入加物体中心裁剪 + 本体感觉 + 夹爪开合，不只给 RGB；② 随机化相机、光照、帧率；③ 用“正放但物体被移回”的硬负样本（hard negative），强迫 D 看任务进度而不是低层统计。
- **语言条件**：D 必须条件于 l；否则“把杯子放进去”和“把杯子拿出来”在纯视觉上可能互为反向，语言是消歧关键。
- **与成功解耦**：TRD 只判方向，不判成败；成败由 V_φ/计分谓词判。不要让 TRD 单独决定 episode 成功。

## 4. UIP-18 · FIA（Facial/Intention Anticipation，面部行为/干预前兆）

### 4.1 直觉

人伸手撤回之前，身体已经“泄漏”了意图：视线先落到目标、头先转过去、眉头先皱、手从画面边缘进入。**表情不是读心术，而是提前量。** 读到 0.5–2 秒的提前量，就足够让机器人做一个“让/稳/抢做完”的决策。

### 4.2 严谨定义

设 N(t) 为干预计数，F_t 为机器人观测与人类面部行为历史。干预风险 λ_t = lim_{Δ↓0} P(N(t+Δ)−N(t)=1 | F_t)/Δ。用时序模型估计，输出：

- λ_t：未来 τ_h 秒内发生干预的风险；
- \hat{t}_int：预计干预时刻；
- u_t：不确定性（熵/方差），用于弃权。

**特征**：AU4（皱眉）、AU24（抿嘴）、AU12（微笑）、视线方向、头姿、手部进入时间、手到目标距离、机器人当前阶段、剩余进度。**不要只用 7 类基本情绪**；AU + 视线 + 手部运动更稳。

### 4.3 决策规则（关键：不是“有表情就停”）

```python
def arbitrate(lam, u, g, progress_left, t_est):
    if u > U_MAX or lam < THETA_LO:
        return "continue"                 # 弃权，避免过度让路
    if lam >= THETA_HI:
        if progress_left < EPS and t_est < T_FAST:
            return "finish"               # 只差一点，抢做完
        if is_contact_rich(g):
            return "stabilize"            # 压住/抓住，降低被撤回概率
        return "yield"                    # 后退让开
    return "monitor"                      # 中间态：缩小块长，准备反应
```

### 4.4 训练数据与伦理

- **数据**：小规模、经同意的真人实验：让被试在脚本化任务中随机时刻伸手撤回/移动物体；同步采集头相机、手部、面部。标签为“干预前 τ_h 秒”窗口；硬负样本为“伸手去拿无关物体/只是经过”。
- **类不平衡**：干预是稀有事件；用 focal loss / 时序采样；报告 PR-AUC 而不是只看准确率。
- **伦理与合规**：**只在规则允许且被试同意时使用**；人脸不出机器人、不落盘、端侧处理；训练数据匿名化。若 A3 不允许，FIA 整体降级为“手部/身体前兆”，不使用人脸。

### 4.5 风险

表情/ AU 的跨人、跨文化、跨光照漂移很大；单帧表情几乎没有预测力，必须用时序 + 手部 + 任务阶段。**最大陷阱是用“微笑=成功”这类常识替代因果验证**。FIA 必须报告 A2 的 AUROC/PR-AUC 与误报预算，否则不进入正式方案。

## 5. UIP-19 · PED（Privileged Expression Distillation，特权表情蒸馏）

### 5.1 直觉

比赛现场不一定能看见人脸，甚至可能只有机器人视角。**那就把“脸”留在训练室里当老师**：训练时用表情教一个“意图预测器”，部署时只靠机器人自己的观测去猜“人类是不是要动手”。脸是奢侈品，意图是必需品。

### 5.2 严谨定义

训练数据同时有 (o_t, e_t)。学习：

- 教师风险头 h_T(λ_t | o_t, e_t)（训练期可用 e_t）；
- 学生风险头 h_S(λ_t | o_t)；
- 表情学生 q_θ(e_t | o_t, 本体感觉, 手部检测)。

损失：

L = L_task + α·L_expr(q_θ, e_t) + β·KL(h_T(·) || h_S(·)) + γ·L_hazard。

部署时：

- 若人脸检测置信度 > c_face：用 h_T；
- 否则：用 h_S；
- 两者都低置信：弃权，退回 TRD/DCR-R 的反应式恢复。

### 5.3 为什么这能过“单模型”

所有头共享一条视觉-语言骨干；表情教师不是外部 API，而是训练期的辅助监督。最终提交的是一个网络（或一个网络 + 轻量头）。若规则对“预训练 FER 模型”敏感，则把 FER 教师也蒸馏进骨干，提交物中不出现第二个模型。

### 5.4 风险

- **学生学不到**：如果 o_t 里根本没有人类线索（人从背后伸手），h_S 不可能预测；此时必须弃权，不能硬猜。
- **教师噪声**：表情标签噪声会通过蒸馏传给学生；用 AU 强度 + 不确定性加权，而不是硬 7 类标签。
- **分布漂移**：训练室的人 vs 比赛现场的人；用多人、多光照、多角度采集；报告跨人被试的 AUROC。

## 6. UIP-20 · EWI（Expression-Weighted Imitation，表情加权模仿）

### 6.1 直觉

不是所有演示帧都值得学。操作员皱眉、犹豫、反复微调的片段，可能是“坏示范”或“高噪声动作”。如果能让模型少学这些片段，动作会更干净。**但这是一个假设，不是常识**：皱眉也可能只是操作员在认真对齐。必须用实验检验。

### 6.2 严谨定义

L_BC = Σ_t w_t·ℓ(π(o_t,l), a_t)，w_t = g(e_t)，g 可取：

- g(e) = 1 − p(frustration/confusion)（降权负面表情）；
- g(e) = 1 + κ·p(engagement)（提升专注片段）；
- 或只用表情做**阶段分割**：把“注视—伸手—接触—释放”分段，给策略加阶段 token，而不改权重。

### 6.3 实验优先

先做 E204：在留出任务上比较 uniform BC vs 表情加权 BC vs 仅阶段 token。若加权无显著提升，**果断放弃加权**，只保留阶段分割。不要把“表情”硬塞进损失函数来凑创新点。

## 7. UIP-21 · DRR（Demonstration-Retrieval Recovery，演示检索式恢复）

### 7.1 直觉

被撤回后，机器人最想知道的是：“这个局面，人类当时是怎么救回来的？” 32k 演示就是一本“救援案例库”。检索最相似的片段，把它当作提示，比从零生成恢复动作更稳。

### 7.2 严谨定义

检索键 q_t = (l, 物体位姿/类别, 夹爪状态, 视觉嵌入, 当前子目标 g)。在演示库中检索 top-k 个“从相似状态恢复到目标”的片段 R。恢复策略 π_rec(a_t | o_t, l, g, R) 通过 cross-attention 或 goal-image conditioning 使用 R。检索索引离线预计算；在线只做近似最近邻，保证实时。

### 7.3 合规与风险

- 检索是**非参数记忆**，不引入第二个模型；嵌入用主骨干。
- 风险：检索到“表面相似但因果不同”的片段（比如同样是“碗”，但叠法不同）→ 用语言 + 子目标 + 物体类别三重过滤；加一个“检索置信度”，低置信度回退到 CRM 恢复头。
- 延迟：预计算 + 每端口独立缓存；不要把所有端口的检索混在一起。

## 9. 关键公式与判定

### 9.1 步骤分代理与恢复收益

设当前 episode 已锁定的前置步骤分为 S_pre，当前子目标 g 的权重为 w_g，恢复成功概率 p_rec，恢复耗时 t_rec。恢复的期望收益：

E[ΔS] = p_rec·w_g − c(t_rec) − (1−p_rec)·w_g·P(超时)。

**含义**：不是所有撤回都值得恢复。若 w_g 很小、剩余时间紧、p_rec 低，**放弃当前子目标、保后面的步骤**可能更优。这与 UIP-02′ 的“保前置、搏末步”一致，但把“恢复成本”显式化。

### 9.2 误报预算

设误报率（无干预却让路）为 α，漏报率为 β。让路一次损失的时间/步骤分期望为 C_yield，被撤回一次损失为 C_undo。最优阈值满足

(1−α)·C_yield ≈ β·C_undo。

**含义**：FIA 的阈值不能拍脑袋；要按“让路成本 vs 撤回成本”校准。多数情况下 β 更贵，但 α 也不能无限大，否则会一直让路。

### 9.3 TRD 的在线判定

```python
def trd_regressed(v_hist, tau=0.5, m=3):
    return sum(1 for v in v_hist[-m:] if v < -tau) == m
```

不要用单帧 v_t 判定；用滑动窗口 + 迟滞（hysteresis），避免在平台期抖动。

**核心指标定义**：

- **RSR**：恢复成功率；**TTR**：恢复耗时；
- **FYR**：误报让路率（无干预却 yield）；
- **ECE**：风险预测校准误差；
- **Latency p50/p95**：逐步延迟及波动。

---

## 11. 数据与实现细节

### 11.1 进度泛函 Φ 的三种实现

1. **时间距离回归**：用同一演示内的时间差做自监督，学习 f(o_t, o_t', l) → |t−t'|；Φ 可用“到终点的预测时间”单调变换。
2. **目标图像距离**：用主骨干嵌入，计算当前帧与“子目标完成帧”的余弦距离；需要子目标帧标注（可由计分点文本 + 视频半自动定位）。
3. **TRD 积分**：v_t 的累积和作为 Φ 的相对版本；不需要绝对标尺，但会漂移，需用几何谓词锚定。

**建议**：1 + 3 组合，几何谓词只在 7 个优先任务上做锚点。

### 11.2 人脸/面部行为的轻量化

- 人脸检测 + 关键点 + AU 强度，用轻量模型；在 head 相机上以 5–10 Hz 运行，只在“有人进入操作区”时激活。
- 表情教师输出的是 **AU + 视线 + 头姿**，不是 7 类硬标签；风险头用这些连续量。
- 所有面部数据端侧处理、不落盘；训练数据匿名化；只在规则允许时启用。

### 11.3 实时性预算

- TRD：每块结束后一次前向，输入降采样帧 + 本体感觉；目标 <10 ms。
- Hazard：只在检测到人/手时运行；目标 <15 ms。
- Retrieval：离线索引；在线 ANN <5 ms；每端口独立缓存。
- 总预算：在 metadata 声明的块长内完成，p95 不超过评测端超时阈值；用 UIP-15 CSG 兜底。

## 12. 合规、伦理与风险

- **单模型合规**：所有头共享骨干；FER 教师只做训练期辅助，提交物不含第二个模型/外部 API。
- **人脸合规**：A3 未通过则不使用人脸；A0 人脸不可见则只用特权蒸馏 + 手部前兆；A2 不显著则砍掉表情分支。
- **隐私**：端侧、匿名、不存储、可撤回同意；不采集比赛现场观众/工作人员面部。
- **误报风险**：FIA 最大副作用是“过度让路”。必须报告 FYR，并用误报预算校准阈值；宁可漏报（退回 DCR-R），不可频繁误报。
- **捷径风险**：TRD 可能学倒放伪影；用物体中心、本体感觉、硬负样本、跨相机随机化。
- **仿真过拟合**：GSO/DRF 只做结构代理；真机锚点不可省。
- **规则未知**：飞书手册仍未取到；A3 是硬门槛，不能假设“可以用脸”。

## 14. 本轮最大风险 & 押注

**一句话**：如果把人脸当成“可靠的因果信号”，SAGE 会在没有脸、表情误读或人类只是路过时频繁误让路，把“预防干扰”变成“主动丢步骤分”；因此本轮把 FIA/PED 设为**有条件增强**，把 CRM/TRD 设为**无条件主线**，并先做 A0–A3 审计。

**→ 押注：UIP-16 CRM × UIP-17 TRD 组成的“示教侧撤回-恢复数据闭环”（由 UIP-01″ 调度、UIP-12′ 补长尾），再用 UIP-22 SAGE 把 UIP-18/19 作为通过审计后的增强。** 这条路线不依赖人脸、不违反单模型、直接命中公开数据里“人为撤回演示为零”的最大空白；即使表情分支全部失败，示教侧仍能独立成立。
