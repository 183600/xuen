# 第 2 轮（灵感循环 v2：「数据集构建」×「最优控制」）—— 把验证器“离线化”：从成功演示构造进度势函数，用滚动最优控制选动作

> 承接第 1 轮：UIP-01（RHPV-V）的方向是对的——在成功率可能 <30% 时，**部分得分/步骤分**比单纯冲成功率更划算；但它的实现把“验证”押在在线 VLM 上，带来延迟方差与误判重试。本轮用两个灵感词重写这一层：**用“数据集构建”把验证离线摊销为进度势函数/价值函数，用“最优控制”把“重试”换成带约束的滚动决策**。

**由 F3/F4 得到的硬约束**：这是一个**成功演示语料库**，不是带成功/失败标签的 RL 数据集。任何“成功分类器/验证器”都不能直接监督训练；必须从**演示的时序结构**中构造监督（相位、进度、偏好、反事实负例）。这正是“数据集构建”在本轮的真正含义。

**由 F5/F6 得到的硬约束**：训练输入/输出必须做**接口投影**。数据集中 torso/d435/waist/legs/双空间动作等是“特权信息”，只能用于训练期辅助（asymmetric critic / distillation），推理期不可依赖；第 1 轮 UIP-10 的“joint/ee 运行时仲裁”在本赛制下**不成立**（除非提交两个不同 control_space 的版本），应降级/封存。

## 1. 对第 1 轮的诊断

- **正确的部分**：UIP-01 把“子目标—验证—重规划”作为一等公民；UIP-02 指出步骤分是低成功率下的关键；UIP-07/08 的离线 harness 与延迟工程仍然必要。
- **错误的成本结构**：RHPV-V 用**在线 VLM** 做验证。VLM 每步数百 ms 的延迟会直接进入 §6 的延迟方差；误判会触发 `max_retry`，在 episode 预算内反而降低成功率。第 1 轮把“重试”当作控制手段，但它同时消耗**时间预算**与**可信度预算**，是一个未建模的约束。
- **缺失的数据视角**：33k 条成功演示本身已经隐含了“什么是好动作、进度如何推进、何时该闭合夹爪”的信息；第 1 轮却把这部分信息留在数据里，转而用外部模型去猜。
- **结论**：本轮不改“部分得分”的目标，而改**验证与决策的实现方式**：
  1. 验证器 → **从数据构造的进度势函数/价值函数**（离线摊销，推理时只跑一个小头）；
  2. 重试 → **带约束的滚动最优控制/候选重排**（把延迟与平滑度作为显式约束，而不是事后补救）；
  3. 手写子目标 → **从对齐演示中自动发现的里程碑**（change-point / DP 分割）。

## 2. 两个灵感词的直觉与严谨定义

### 2.1 数据集构建：数据不是“给”的，是“构造”的

**直觉**：33k 条成功演示像一本没有目录的菜谱。先按时间把每道菜“对齐”，标出阶段（拿起—对准—插入—放下），再从“演示动作 vs 被我故意弄坏的动作”中学习“哪一步更像专家”。这样就把一本无标签的录像，构造成一个**带相位、带里程碑、带偏好、带安全包络**的数据集。

**严谨定义（构造数据集）**：给定任务 τ 的成功演示集合 \(D_\tau=\{e=(o_{0:T_e},a_{0:T_e},l)\}\)，构造
\[
\tilde D_\tau=\{(o_t,a_t,l,\phi_t,m_t,y_t,\mathcal C_\tau)\}
\]
其中 \(\phi_t\in[0,1]\) 是单调相位，\(m_t\) 是里程碑/子目标指示，\(y_t\) 是“专家动作 vs 负例”的偏好标签，\(\mathcal C_\tau\) 是行为包络（速度/加速度/关节限位分位数）。构造算子由四步组成：**对齐（DTW/DP）→ 分割（change-point）→ 价值/偏好（IOC）→ 负例与包络（反事实）**。

- **对齐**：对每个任务求中位模板 \(\bar e_\tau\)，用带 Sakoe–Chiba 带的 soft-DTW 求单调路径 \(\pi\)，使
  \[
  \pi^\*=\arg\min_{\pi}\sum_{(i,j)\in\pi} d(o_i,\bar o_j),\quad \pi \text{ 单调、端点固定、步长有界}.
  \]
  这是一个 DAG 上的最短路径（动态规划 = 离散最优控制的 Bellman 递推）；soft-DTW 用 log-sum-exp 平滑，可反传。相位 \(\phi_i = j^\*/|\bar e|\)。
  **注意**：单模板假设“唯一正确顺序”。对 ArrangePlates/OrganizeBookshelf/FoldTowel 等多模态任务，先对轨迹聚类（DTW barycenter / 相位不变特征 k-means），每个簇一个模板，得到**混合相位**，避免把合法顺序判成“退步”。

- **里程碑分割**：在相位对齐后的信号 \(z(\phi)=[\Phi,\ \text{gripper},\ \text{EE speed},\ \text{contact proxy}]\) 上做**带惩罚的变点检测 / 最优分段**：
  \[
  \min_{0=\phi_0<\cdots<\phi_K=1}\sum_{k}\sum_{\phi\in(\phi_{k-1},\phi_k]}\|z(\phi)-\mu_k\|^2+\lambda K.
  \]
  这又是一个 DP。得到的 \(K_\tau\) 个分段就是**数据驱动的计分点候选**；若后续拿到官方 Scoring Steps，则用其校准权重，而不是重新发明。

- **势函数/价值**：训练 \(\Phi_\theta(o,l)\)（只用在线可见的 obs 键），满足
  1. 同 episode 内 \(t_1<t_2\Rightarrow \Phi(o_{t_1})<\Phi(o_{t_2})\)（pairwise ranking / margin）；
  2. 端点校准 \(\Phi(o_0)\approx0,\ \Phi(o_T)\approx1\)；
  3. 跨 episode 的相位回归 \(\Phi(o_t)\approx\phi_t\)（soft label）；
  4. 语言一致性：同一 episode 的 5 条同义指令共享 \(\Phi\)；换目标语言的 goal-swap 负例应得低 \(\Phi\)。
  这是一个**偏好学习 + 回归 + 对比**的多任务目标。推理时只跑一个小网络（或小 VLM 的标量头），延迟可做到毫秒级。

- **IOC（逆最优控制）**：假设演示是某个未知代价下的近似最优：
  \[
  c_\omega(o,a)=\omega^\top f(o,a),\quad f=[-\Delta\Phi,\ \|v\|^2,\ \|jerk\|^2,\ \text{gripper switch},\ \text{joint-limit margin},\ \text{contact}] .
  \]
  用最大熵 IOC（\(p(a|o)\propto\exp(-c_\omega(o,a))\)）或 Bradley–Terry 偏好学习拟合 \(\omega\)，使演示动作的代价低于扰动/跨任务负例。这样得到的不只是 \(\Phi\)，还有一个**可解释的动作代价**，可直接作为 MPC 的运行代价。
  **可辨识性**：\(\omega\) 只在特征变化充分时、且至多差一个尺度；需归一化特征、加 \(\ell_2\) 正则，并报告置信区间。

- **负例构造（因为 F3：没有失败样本）**：

  | 负例类型 | 构造 | 标签 | 注意 |
  |---|---|---|---|
  | 时间反向 | 取子轨迹倒放 | 进度下降 | 不应把“倒放”当成物理可达 |
  | 跨 episode 帧拼接 | 同任务不同相位的帧互换 | 相位错配 | 会破坏时序因果，只用于表征 |
  | 目标交换 | 同一状态配另一任务语言 | 低 \(\Phi\) | 训练语言 grounding |
  | 动作扰动 | 缩放/偏移/延迟专家动作，用学到的动力学预测下一状态 | 低 \(\Phi\)/高代价 | 依赖模型，需 ensemble 不确定性 |
  | 遮挡/人手叠加 | 合成遮挡或人手 | **不确定**，不是失败 | 否则会把“看不见”误判成“做错了” |

  最后一条很关键：人为干扰轴要求“暂停/等待/重观察”，而不是把遮挡当失败去重试。

- **行为包络**：对每个动作维度统计 \(q_{0.1},q_{0.5},q_{0.9},q_{0.99}\) 的速度/加速度/jerk，形成 \(\mathcal C_\tau\)。它不是硬性物理限制，而是**演示分布的支持集**；用于约束投影与异常检测（见 UIP-15）。

### 2.2 最优控制：不是“再训一个更大的模型”，而是“在短时域上解一个带约束的代价问题”

**直觉**：既然演示已经告诉我们“好动作长什么样”，推理时就不必盲从一次前向输出。让基础策略给出若干候选动作块，用一个学到的“进度势 + 平滑/能耗/安全代价”在短时域上打分，选最好的执行一小段，再重新观测、重新打分。这就是滚动时域控制（MPC），只不过“模型”可以很轻：最轻时连动力学都不需要，直接用学到的 Q/势函数给候选块排序。

**严谨定义（约束最优控制）**：把 episode 写成有限时域 MDP \(M=(O,A,P,r,\gamma,H)\)，其中
\[
r(o,a,o')=\underbrace{\Delta\Phi_\theta(o,o')}_{\text{进度}}+\underbrace{\sum_k w_k \mathbf 1[g_k \text{ 达成}]}_{\text{步骤分代理}}-\underbrace{\lambda_s\|a-a_{\rm prev}\|^2-\lambda_e\|a\|^2}_{\text{平滑/能耗}}.
\]
评测可信度给出两个**约束**：每步延迟 \(L\le L_{\max}\)、动作统计异常 \(S\le S_{\max}\)。于是
\[
\max_{\pi}\ \mathbb E_\pi\Big[\sum_{t=0}^{H}\gamma^t r_t\Big]\quad \text{s.t.}\quad \mathbb E[L]\le L_{\max},\ \mathbb E[S]\le S_{\max}.
\]
拉格朗日化后，代价里出现 \(\lambda_L L+\lambda_S S\)；这解释了为什么“延迟”和“平滑”不是工程细节，而是**对偶变量**。在每一步，给定观测 \(o_t\)，解
\[
a^\*_{t:t+k}=\arg\min_{a_{t:t+k}\in\mathcal A}\ J=\sum_{h=0}^{k}\Big[-r(o_{t+h},a_{t+h})+\lambda_u u(o_{t+h})\Big]+\underbrace{-\gamma^k \Phi_\theta(o_{t+k})}_{\text{终端代价}},
\]
执行前 \(k\) 步，令 \(t\leftarrow t+k\)，重复。\(\mathcal A\) 是候选动作块集合（策略采样 / CEM / 梯度优化），\(u\) 是集成不确定性（认知不确定性），用于惩罚“模型没见过的动作”。

**两层实现（按风险从低到高）**：

- **L0 Q-重排（默认）**：不学动力学。训练一个 chunk-level 价值 \(Q_\theta(o,A,l)\)（或用 \(\Phi\) 的有限差分近似），对 \(M\) 个候选块打分，选最大者。成本 = \(M\) 次小网络前向，可批处理；延迟可控。
- **L1 潜在 MPC（可选）**：训练动作条件 latent dynamics \(\hat f\)（从 33k episodes），在 latent 里 rollout \(k\) 步，用 \(\Phi\) 作终端代价，CEM/MPPI 选块。只在 L0 的离线 action-ranking 指标证明有增益时启用。
- **L2 全 MPPI（研究上限）**：更大候选数/更长时域，仅用于离线对照，不作为默认提交路径。

**理论依据（要点）**：

- **势函数塑形不变性**（Ng et al., 1999）：若 \(\Phi\) 是真实最优价值函数，则 \(r'=r+\gamma\Phi(o')-\Phi(o)\) 不改变最优策略；因此用 \(\Phi\) 做终端代价/塑形，原则上不会“教坏”策略。近似 \(\Phi\) 时，次优性由近似误差与可达性条件控制；这要求我们**不要**把 \(\Phi\) 当成绝对真理，必须加不确定性惩罚与保守回退。
- **最大熵 IOC**：在演示次优/多模态时，用分布 \(p(a|o)\propto e^{-c_\omega}\) 而不是硬最优，能避免“把示教抖动当成最优”。
- **MPC 的滚动可行性**：只要每一步的候选集合包含一个“安全动作”（如保持/小幅回退），约束投影保证动作在 \(\mathcal C_\tau\) 内，则闭环不会产生越界动作；代价下降不保证全局最优，但保证**可信度约束不被打破**。

## 3. 本轮的核心判断

1. **验证必须离线摊销**：在成功演示语料上，学 \(\Phi\)/Q 比在线 VLM 更便宜、更稳定，而且直接给出“步骤分代理”。VLM 只保留为**慢速、低置信度时的可选复核**，不再是主循环。
2. **“重试”应改写为“带终端代价的滚动选择”**：不是“失败了再来一次”，而是“每一步都在候选动作里选一个使 \(\Phi\) 最大且不破坏平滑/延迟约束的”。这从根上避免第 1 轮的重试发散。
3. **步骤分可以“发现”而不是“抄”**：官方 rubric 拿不到时，用对齐演示的变点检测得到里程碑候选；拿到后再校准。这样 UIP-02 从“依赖飞书文档”变成“数据驱动 + 可校准”。
4. **接口投影是数据构建的第一公民**：F5/F6 意味着不能把数据集里所有字段都喂给模型；必须构造一个与在线接口同构的视图，其余作为特权信息。否则离线指标会虚高。
5. **多模态任务必须多模板**：单模板 DTW 会把合法的不同顺序误判为退步；需要聚类 + 混合相位，否则 \(\Phi\) 会在多模态任务上系统性偏低。

## 5. 本轮最大风险

**一句话**：成功演示只覆盖“专家流形”，从它学出的 \(\Phi\)/Q 与 DTW 模板在分布外（背景/未见物/人为干扰）会系统性失准；而 MPC 又天然擅长利用模型误差“刷分”，把离线看起来更优、真机上却是分布外的动作选出来——必须用集成不确定性惩罚、保守回退、多模板对齐与真机校准把这条风险关进笼子，否则“最优控制”会变成“最优过拟合”。

**→ 本轮最值得押注：UIP-11 + UIP-12 + UIP-13 组成的 PACT-PAV 栈**：先用数据构造把“验证”变成离线可学的势函数与里程碑，再用滚动候选重排把“重试”变成带约束的最优控制；它同时服务成功率与步骤分，且完全落在远程 API 权限内。

# 第 2 轮产物 · UniBot 创新点清单 v2（UIP-11~18）与 PACT-PAV 技术方案

> 事实基线：32 个任务 / 33,276 episodes / 18.28M frames / 169.3 h；数据为**成功演示，且无 success/reward/failure 字段**；每个 episode 带 5 条同义指令；在线接口为 4 路图像 + 6 类状态 + `language`；`control_space` 提交时固定 joint 或 ee；N 端口；延迟与动作统计计入可信度（README §6）。详见想法区 §0 的 F1–F8。

## 0. 一句话结论

把“在线 VLM 验证 + 失败重试”替换为“**数据集构造出的进度势函数/价值 + 带约束的滚动候选重排**”：验证离线摊销、决策在线最优控制、步骤分自动发现、平滑与延迟显式约束。

## 1. 系统总览

```
[33k 成功演示]
   │  接口投影（只用在线可见 obs）
   ▼
PACT 数据构造：DTW 相位 → 变点里程碑 → IOC 势/Q → 反事实负例 → 行为包络 → coreset
   │
   ├── Φθ(o,l) 进度势（小头，毫秒级）
   ├── Qθ(o,A,l) 块级价值 / 代价权重 ω
   ├── {g_k, w_k} 计分步代理
   └── Cτ 速度/加速度/限位包络
   │
   ▼
在线：基础策略 π0 → M 个候选动作块 → PAV-Q 重排 →（可选 latent MPC）→ 约束投影 → 执行 k 步 → 重观测
   │
   └── 不确定性高 → DUAL-AP 主动感知/保守回退
```

## 2. PACT：数据集构建流水线

### 2.1 接口投影（DIP, Dataset–Interface Projection）

- 只保留在线可见键：`cam_left_high/right_high/left_wrist/right_wrist`、`left_arm/right_arm`、`left_ee_pose_gripper_base/right_ee_pose_gripper_base`、`left_gripper/right_gripper`、`lower_body`、`language`。
- 数据集键映射：`head_stereo_left→cam_left_high`、`head_stereo_right→cam_right_high`、`wrist_left→cam_left_wrist`、`wrist_right→cam_right_wrist`；`action.pivot` 从数据集 `action.pivot` 取，缺失时用任务中位数常量（需逐任务核验，不能全局假设）。
- 数据集独有的 `state_torso/state_d435/waist/legs`、双空间动作、`recomputed_ee_valid` 作为**特权信息**：只在训练期进入 critic/辅助头，推理期不依赖（asymmetric critic）。
- 训练目标按所选 `control_space` 投影：选 joint 就只监督 `action.left_arm/right_arm`；选 ee 就只监督 `action.*_ee_pose_gripper_base`；另一空间作辅助损失。

**验收**：构造出的 `PACT-view` 与 `example_env.py` 的 `OBSERVATION_SPEC`/`*_ACTION_SPEC` 逐键对齐；任何在线不可见字段不得进入推理图（用单元测试切断）。

### 2.2 相位对齐（DP/DTW）

- 每任务先做轨迹聚类（对相位不变特征：EE 相对位移、夹爪事件、接触代理）得到 \(M_\tau\) 个模式；每个模式一个 medoid 模板。
- 带 Sakoe–Chiba 带的 soft-DTW：
  \[
  D(i,j)=d(o_i,\bar o_j)+\min\{D(i-1,j),D(i,j-1),D(i-1,j-1)\}
  \]
  soft 版本用 \(\min_\gamma\) 的 log-sum-exp 平滑；反传得到软相位 \(\phi_t\)。
- 输出：`phase[t]`、`mode_id`、对齐残差 \(r_e\)。残差高的 episode 不丢弃，打上 `atypical` 标签（可能是泛化轴的有价值样本）。

### 2.3 里程碑/计分步发现（ASSD）

- 对齐后信号 \(z(\phi)=[\Phi,\ \text{gripper}(t),\ \|\Delta EE\|,\ \text{contact proxy},\ \text{object motion}]\)。
- 最优分段 DP（见想法区公式），惩罚 \(\lambda K\) 用 BIC/肘点选择；得到每个任务的 \(K_\tau\)（预期 3–8）。
- 里程碑权重 \(w_k\)：无官方 rubric 时先均匀/按段时长反比；拿到 Scoring Steps 后用最小二乘/保序回归校准，**不覆盖**数据驱动边界，只调权重。
- 推理期定义 **不倒退约束**：维护 \(\Phi_{\max}\)，若候选动作预测 \(\Phi < \Phi_{\max}-\delta\)，加惩罚；这直接保护已获得的步骤分。

### 2.4 势函数与 IOC 代价

- \(\Phi_\theta(o,l)\)：视觉骨干（共享）+ 语言条件（FiLM/CLIP 文本）+ 标量头；输入只用在线 obs 的当前帧/历史栈。
- 损失：
  \[
  \mathcal L_\Phi=\mathcal L_{\text{rank}}+\lambda_1\mathcal L_{\text{reg}}(\Phi,\phi)+\lambda_2\mathcal L_{\text{cal}}(\Phi(o_0),\Phi(o_T))+\lambda_3\mathcal L_{\text{lang}}
  \]
  - \(\mathcal L_{\text{rank}}\)：同 episode 内 \(t_1<t_2\) 的 margin ranking；
  - \(\mathcal L_{\text{reg}}\)：软相位回归；
  - \(\mathcal L_{\text{cal}}\)：端点 0/1 校准（分任务）；
  - \(\mathcal L_{\text{lang}}\)：5 条同义指令一致性 + goal-swap 负例对比。
- 代价特征 \(f(o,a)\)：\(-\Delta\Phi\)、EE 速度/加速度/jerk、关节速度、夹爪切换、限位裕度、接触代理、动作块边界差。
- 拟合 \(\omega\)：
  - 方案 A（推荐，简单）：Bradley–Terry 偏好，对 \((a^+,a^-)\) 最小化 \(-\log\sigma(c_\omega(a^-)-c_\omega(a^+))\)；
  - 方案 B（更严谨）：最大熵 IOC，\(p(a|o)\propto\exp(-c_\omega(o,a))\)，用重要性采样/对比估计配分函数；
  - 两者都归一化特征、加 \(\ell_2\)，并报告 \(\omega\) 的 bootstrap 置信区间。
- 产出 Q 的两种用法：
  1. **块级 Q**：\(Q_\theta(o,A)\approx\sum_{h}\Delta\Phi-\lambda^\top\text{cost}\)，用于 L0 重排；
  2. **逐步 Q**：用于解释/调试与动作维度诊断。

### 2.5 反事实负例与包络

- 负例表（类型/构造/标签/用途）见想法区 §2.1；核心原则：**遮挡≠失败**，只标“不确定”。
- 动作扰动用 ensemble latent dynamics 生成，若 ensemble 分歧大则丢弃该负例（避免把模型误差当标签）。
- 行为包络：每任务每维 \(v_{99}, a_{99}, j_{99}\)；同时记录动作 chunk 边界处的跳变分布，供 UIP-15 使用。

### 2.6 数据选择（coreset）

- 任务内用 k-center / 子模覆盖选择 \(N_\tau\) 条（例如 300–500），特征 = 相位对齐后的 state/action 摘要 + 视觉 embedding + 语言 embedding。
- 目标是覆盖 5 个泛化轴：位置/干扰物/背景/未见物/人为干扰；公开数据没有这 5 轴的显式标签，故用**合成增广后的 embedding 距离**近似覆盖，并保留 `atypical` 样本。
- 训练时对稀有模式/高残差样本加权，防止“平均化”。

## 3. PAV-Q：在线滚动候选重排

### 3.1 输入输出

- 基础策略 \(\pi_0\) 输出 \(A\in\mathbb R^{T_a\times d}\)。
- 候选生成（任选/组合）：
  1. 多次采样（若 \(\pi_0\) 随机）；
  2. 观测增强（不同历史步长/裁剪）；
  3. 动作块加噪/时间缩放；
  4. 若 \(\pi_0\) 可微，对 \(A\) 做几步梯度上升最大化 \(Q_\theta(o,A)\)。
- 选择：
  \[
  A^\*=\arg\max_{A^{(j)}} Q_\theta(o,A^{(j)},l)-\lambda_s\text{Smooth}(A^{(j)})-\lambda_u u(o,A^{(j)}).
  \]

### 3.2 成本/价值设计

\[
Q_\theta(o,A,l)=\sum_{h=0}^{T_a}\gamma^h\Big[\Delta\Phi_\theta(\hat o_h,l)+\sum_k w_k\Delta \mathbf 1[g_k]\Big]-\lambda_s\sum_h\|a_h-a_{h-1}\|^2-\lambda_e\sum_h\|a_h\|^2-\lambda_g\sum_h|g_h-g_{h-1}|-\lambda_r\,\text{Regress}(\Phi)
\]

- \(\hat o_h\)：L0 用“当前 obs + 动作块本身作为隐式预测”的近似（不再 rollout）；L1 用 latent dynamics。
- \(u(o,A)\)：\(\Phi\)/dynamics ensemble 的方差；用于惩罚分布外动作。
- \(\text{Regress}\)：\(\max(0,\Phi_{\max}-\delta-\hat\Phi)\)，保护已得步骤分。

### 3.3 延迟分层（UIP-18）

| 层 | 触发 | 计算 | 目标 p99 |
|---|---|---|---|
| L0 | 默认 | M 个候选 × 小 critic 前向（批处理） | 与基础策略同量级 + 少量 |
| L1 | 剩余预算充足且 L0 不确定 | latent rollout H≤4，CEM 8–16 样本 | 显式预算内 |
| L2 | 离线研究/极端困难 | MPPI 32–64 样本，H≤8 | 不作为默认 |
| Fallback | 延迟逼近上限/不确定爆表 | 直接执行 \(\pi_0\) 均值或保守动作 | 保证不超时 |

预算分配：每步记录实际耗时，滑动窗口估计 p95；若接近 \(L_{\max}\) 降层；episode 结束前留固定回退余量。

## 4. DUAL-AP：对偶控制主动感知

- 不确定性来源：\(\Phi\)/dynamics ensemble 方差、视觉遮挡率、语言-视觉 grounding 熵、动作包络外程度。
- 信息增益代理：\(\text{IG}(a)\approx \text{Var}_{ens}[\Phi(\hat o')]-\text{Var}_{ens}[\Phi(o)]\) 或 dynamics disagreement 的下降；加入代价 \(-\lambda_{\rm IG}\text{IG}(a)\)。
- 行为：不确定时优先“移动到能看清的位置/换腕相机视角/轻触试探/重抓”，而不是原地重试；若仍然高不确定，进入有界暂停/安全保持，等待人为干扰离开。
- 与 UIP-09 的区别：UIP-09 是“检测到人→暂停”；DUAL-AP 是“把信息价值写进最优控制目标”，对未见物/遮挡同样适用。

## 5. CBF-ENV：约束投影与平滑

- 约束集：
  \[
  \mathcal C_\tau=\{a:\ |a_t-a_{t-1}|\le v_{\max},\ |a_t-2a_{t-1}+a_{t-2}|\le a_{\max},\ a\in[\ell,u]\}
  \]
  \(v_{\max},a_{\max}\) 取演示的 99.9 分位（不是 99，避免过紧）。
- 投影：
  \[
  a^\*=\arg\min_{a\in\mathcal C_\tau}\|a-a_{\rm prop}\|^2
  \]
  逐维/逐关节求解（QP 或差分约束的最短路径）；对 EE 姿态的 rpy 用角度差/四元数，避免 wrap-around。
- chunk 边界：新块与上一块重叠 \(k_{\rm blend}\) 步，线性/余弦混合；或对重叠区域做 temporal ensembling。目标是压 §6 的“动作统计异常”。
- 软硬两层：默认软惩罚（保性能）；仅当动作超出 99.9 分位或延迟异常时硬投影（保可信度）。

## 6. 离线评估设计（真机前）

### 6.1 代理指标

| 指标 | 定义 | 用途 |
|---|---|---|
| 相位单调性 | Spearman(\(\Phi_t,t\))、逆序率 | 验证对齐/\(\Phi\) |
| 对齐残差 | DTW cost / episode | 发现多模态任务 |
| Action-ranking acc | 专家动作块得分 > 扰动块的比例 | **核心**：IOC/Q 是否真的会选动作 |
| Regret@M | 在 M 个候选中，选中块与专家块的 Q 差 | 重排质量 |
| 里程碑覆盖代理 | \(\sum_k w_k\mathbf 1[g_k]\)（离线回放） | 步骤分代理 |
| OOD AUC | 合成背景/干扰物/遮挡上的 \(\Phi\) 不确定性 | 泛化/安全 |
| 延迟 p50/p99/jitter | 模拟与本地服务 | 可信度 |
| 动作异常率 | 超包络、jerk 超分位、chunk 跳变 | 可信度 |

### 6.2 实验矩阵

| 实验 | 对照 | 主指标 | 预期/判据 |
|---|---|---|---|
| E201 对齐 | 时间线性归一 vs DTW vs 多模板 DTW | 单调性、残差、下游 action-ranking | 多模板不劣于单模板，长任务显著更好 |
| E202 势函数 | 回归相位 vs pairwise ranking vs 两者 | action-ranking acc、校准误差 | 两者 > 单回归；校准误差 < 0.1 |
| E203 负例 | 无负例 vs 随机 vs 反向 vs goal-swap vs 扰动 | OOD AUC、遮挡误报率 | goal-swap 提升语言 grounding；遮挡负例若标失败会显著误报 |
| E204 重排 | 纯策略 vs RHPV-V(VLM) vs PAV-Q(L0) vs latent MPC(L1) | 成功率代理、步骤分代理、p99 延迟 | L0 接近/超过 VLM 且延迟低一个量级；L1 仅在 L0 饱和后有增益 |
| E205 约束 | 无投影 vs 软 vs 硬 | jerk 降幅、动作异常率、代理成功率 | 软投影降异常且不降成功率；硬投影只作兜底 |
| E206 主动感知 | 无 vs DUAL-AP | 遮挡/人为干扰 split 的成功率、信息增益 | DUAL-AP 在遮挡 split 显著更好，无误停泛滥 |
| E207 数据选择 | 全量 vs 随机子集 vs coreset | 32 任务宏平均、方差 | coreset 以更少数据接近全量 |
| E208 全栈 | 基线 vs PACT-PAV vs +DUAL-AP vs +CBF-ENV | 综合代理、延迟/异常 | 逐步显著，且无一项可信度指标恶化 |

### 6.3 统计协议

- 以 **episode 为独立单位**，按任务分层；报告 32 任务宏平均 ± bootstrap 95% CI，不只报 pooled。
- 离线 split 必须按 episode 划分，禁止同 episode 帧泄漏到训练/测试。
- 所有“真机”结论在提测前标注为**代理指标**；真机只用于校准，不用于选型迭代（与 UIP-07 原则一致）。
- 复现：固定 5 个随机种子；记录数据版本、DTW 参数、负例生成器版本、critic checkpoint。

## 7. 伪代码

```python
class PACT_PAV_Policy:
    def __init__(self, base_policy, phi, q_head, envelope, cfg):
        self.pi = base_policy
        self.phi = phi              # Phi_theta(o, l) -> [0,1]
        self.q = q_head             # Q_theta(o, A, l)
        self.env = envelope         # per-task v/a/j quantiles
        self.cfg = cfg
        self.reset()

    def reset(self):
        self.pi.reset()
        self.hist = []
        self.phi_max = 0.0
        self.prev_chunk = None
        self.budget = TimeBudget(self.cfg.latency_ms)

    @torch.no_grad()
    def get_action(self, obs):
        # 1) 计时与降层
        tier = self.budget.choose_tier()
        # 2) 基础策略候选
        cand = self.pi.sample_chunks(obs, n=self.cfg.M[tier])
        # 3) 价值/代价评分（L0）
        scores = [self.score(obs, A, tier) for A in cand]
        # 4) 选择 + 不倒退约束
        A = cand[argmax(scores)]
        # 5) 可选 L1 latent MPC（仅当 tier>=L1）
        if tier >= 1:
            A = self.latent_mpc(obs, A)
        # 6) 平滑/包络投影 + chunk 边界混合
        A = self.project(A, self.prev_chunk)
        self.prev_chunk = A
        self.phi_max = max(self.phi_max, self.phi(obs, obs["observation.language"]))
        self.budget.observe()
        return A[: self.cfg.k]          # 只承诺 k 步，滚动重观测

    def score(self, obs, A, tier):
        l = obs["observation.language"]
        phis = self.phi_rollout(obs, A) if tier >= 1 else self.phi_proxy(obs, A)
        q = self.q(obs, A, l)
        p = torch.relu(self.phi_max - self.cfg.delta - min(phis))
        u = self.uncertainty(obs, A)
        smooth = self.smoothness(A)
        return q - self.cfg.lam_p * p - self.cfg.lam_u * u - self.cfg.lam_s * smooth
```

> 真实实现中候选生成/评分需批处理，且 `phi_rollout` 只在 L1 启用；L0 的 `phi_proxy` 用块级 Q 或“末帧 \(\Phi\)”的保守估计。

## 8. 资源与时间线

- 第 1 周：`PACT-view` 接口投影 + 数据加载/对齐（DTW/聚类）；建立离线 split 与基线。
- 第 2 周：ASSD 里程碑 + \(\Phi\) 训练；action-ranking 评测；多模板消融。
- 第 3 周：IOC 代价/块级 Q；L0 重排；延迟与平滑投影。
- 第 4 周：L1 latent dynamics（可选）；DUAL-AP；E201–E208。
- 第 5 周起：真机预约，用真实榜单校准 \(\Phi\)/权重/代理指标；只做小幅超参校准，不做结构性改动。

## 9. 失败模式与缓解

| 失败模式 | 机制 | 缓解 |
|---|---|---|
| 多模态任务单模板错配 | DTW 强制唯一顺序 | 多模板/混合相位；用模式后验加权 \(\Phi\) |
| 成功演示无失败标签 | 负例是构造的，可能学到伪特征 | 多源负例 + ensemble 过滤 + 真机校准；优先使用“时间/目标”负例而非模型生成负例 |
| MPC 利用模型误差 | 选择离线 Q 高但真实失败的动作 | 不确定性惩罚 + 保守回退 + L0 优先；L1 仅在离线 action-ranking 有显著增益时启用 |
| \(\Phi\) 在长平台段不敏感 | 长时间搬运/行走，进度变化小 | 加入事件/接触/夹爪特征；段内用速度/朝向等辅助信号；里程碑而非均匀相位 |
| 延迟/动作异常 | 候选/rollout 计算、chunk 跳变 | TIER-LAT + 批处理 + 软投影 + 边界混合；p99 门禁 |
| 在线语言分布漂移 | 训练 5 条同义句，测试可能不同 | 模板化 + 同义增强 + goal-swap 对比；保留语言无关的视觉进度头 |

## 10. 与第 1 轮的关系

第 1 轮把“验证”放在在线 VLM 上，第 2 轮把它**摊销到数据集构造出的 \(\Phi\)/Q** 中；第 1 轮用“重试”对抗失败，第 2 轮用“带约束的滚动候选重排”替代重试。目标函数不变（成功率 + 步骤分），但延迟、平滑与泛化从“事后风险”变成“显式约束”。

## 11. 本轮最大风险

**一句话**：\(\Phi\)/DTW 模板只覆盖专家流形，MPC 又最擅长利用模型误差；一旦分布外（背景/未见物/人为干扰）失准，离线更优的动作会变成真机失败——所以必须把不确定性惩罚、保守回退、多模板与真机校准作为**第一优先级**，而不是等 L1/L2 做完再补。
