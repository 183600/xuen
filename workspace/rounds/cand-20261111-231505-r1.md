# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim++；灵感循环第 6 轮；本轮灵感：「同步定位与建图」×「关节空间控制」）

> 第 54 轮把技能组合推进到动作空间剖面 + 云边协同 + 动作-鲁棒性联合证书，但动作空间 `A` 始终是抽象符号。本轮用 **关节空间** 把 `A` 落到物理底座，用 **SLAM** 引入地图帧不确定性，提出两条新矛盾：**H22：任务空间兼容 ≠ 关节空间可行**——两技能在任务空间都可达，但其间可能不存在满足关节限位与奇异裕度的连续关节路径；**H23：定位漂移与控制误差经雅可比相乘放大**，并在退化场景中形成正反馈，使逐帧证书系统性失效。

## 0. 直觉与动机

**灵感 1（关节空间是动作空间的第一性底座）**
直觉：第 54 轮的 `α_S : A→[0,1]` 本质是任务空间的能力投影，但机器人真正执行的是关节轨迹 `q(t) ∈ 𝒞`。两个技能"都够得到"杯子，不代表从 `S1` 的终止位形到 `S2` 的起始位形存在一条满足关节限位与奇异裕度的连续路径。**组合可行性 = 任务空间覆盖 ∩ 关节空间连通性**。因此必须把 `α_S` 抬升为关节空间剖面 `β_S : 𝒞→[0,1]`，并在 `𝒞` 上做连通性判定，而不是只在任务空间算 Jaccard。

**灵感 2（SLAM 漂移经雅可比放大为关节误差）**
直觉：SLAM 给出 `T_map←base` 及协方差 `Σ_T`。任务目标定义在 map 帧中，一旦 map 帧漂移 `δT`，任务参考误差 `δx` 会经逆雅可比传回关节：`δq = J^† δx`。远离奇异时 `κ_J = ||J^†|| = 1/σ_min(J)` 很小；接近奇异时 `κ_J` 爆炸，微小的定位误差被放大成巨大的关节指令。**所以定位精度不能与雅可比条件数各自独立达标，必须联合认证**。

**灵感 3（感知-控制共退化与环路增益）**
直觉：定位误差本身依赖运动——快速运动导致运动模糊、视差不足、退化场景（纯旋转、白墙）让 SLAM 观测性骤降；而运动恰恰由关节空间指令驱动。于是存在反馈环：`关节速度↑ → 特征跟踪质量↓ → 定位误差↑ → J^† 放大 → 关节误差↑`。定义环路增益 `G_pc = γ_obs·κ_J·L_map`，只有 `G_pc < 1` 才能保证该正反馈收敛。这把第 54 轮的 Lipschitz 条件 A27 推广为 **控制-估计联合稳定性条件**，而不是单边误差界。

**灵感 4（主动 SLAM × 技能组合 → 观测性感知的技能序列）**
直觉：选择下一个技能不应只看任务进度，还要看它是否维持/提升地图观测性。把观测性边际 `λ_obs(t)=λ_min(Λ(t))` 纳入组合代价，技能图搜索的状态从"技能节点"扩展为"(技能, 信息矩阵估计, 地图帧)"。这使技能组合同时是 **任务规划** 与 **主动感知规划**：为了看得清，可能故意插入一个"绕行"技能，这与第 54 轮纯任务驱动的 SCOM 形成本质区别。

**灵感 5（回环闭合 = 证书重锚定事件）**
直觉：SLAM 回环闭合会让地图帧瞬间跳变 `ΔT_c`，正在执行的技能其关节参考会瞬间跳变 `Δq_c = J^† ΔT_c x_ref`。这不是普通噪声，而是 **证书坐标系失效事件**：旧 `α_S` 定义在旧 map 帧里。必须建立重锚定协议——检测事件、估计 `Δq_c`、检查预算、混合或中断重规划，并在新帧重估 `α_S/β_S`，把第 54 轮的云边 Explain 回传扩展为 **地图帧事件通道**。

## 1. 形式化定义（增量：定义 121–128）

**定义 121（关节空间动作剖面与可达核）**
设关节空间 `𝒞 ⊆ ℝ^n`（含关节限位 `q_min ≤ q ≤ q_max`），任务空间 `𝒳 ⊆ SE(3)`，正运动学 `f: 𝒞→𝒳`。技能 `S` 的关节剖面 `β_S : 𝒞→[0,1]`，任务剖面为其推前 `α_S = f_*β_S`。可达核 `C_S^θ = {q∈𝒞 : β_S(q) ≥ θ}`。称 `S` 在关节空间覆盖任务动作 `a∈𝒳`，当且仅当 `∃ q ∈ f^{-1}(a)` 使 `β_S(q) ≥ θ`。注意 `f` 多对一（冗余），故任务覆盖不等于单一关节实现。

**定义 122（地图帧、漂移与回环事件）**
地图帧变换 `T_mb(t) ∈ SE(3)`，SLAM 估计 `\hat T_mb(t)` 及协方差 `Σ_T(t)`。漂移 `δT(t) = T_mb \hat T_mb^{-1}`，不确定性椭球 `E_T(ε) = {δT : ||vec(δT)||_{Σ_T^{-1}} ≤ ε}`。回环闭合在 `t_c` 产生跳变 `ΔT_c`，一般 `||ΔT_c|| >> ||δT(t)||`，且伴随协方差骤降；它是 **分布式不连续事件**，不能用连续漂移模型吸收。

**定义 123（雅可比不确定性放大）**
`J(q)=∂f/∂q ∈ ℝ^{m×n}`。放大因子 `κ_J(q)=||J(q)^†||=1/σ_min(J(q))`。对任务扰动 `δx`，关节扰动 `δq=J^†δx`，协方差 `Σ_q ≼ κ_J²·Σ_x`。特别地，若 map 帧误差诱导任务误差 `||δx|| ≤ L_f||δT||`，则 `||δq|| ≤ κ_J·L_f·||δT||`。

**定义 124（感知-控制环路增益）**
定位误差动力学 `e_{k+1} ≤ e_0 + γ_obs·κ_J(q_k)·L_map·||u_k||`，`u_k` 为关节速度指令。环路增益 `G_pc(q)=γ_obs·κ_J(q)·L_map`。称轨迹 **感知-控制稳定**，当且仅当 `sup_t G_pc(q(t)) < 1`。其收敛上界为 `limsup_k ||e_k|| ≤ e_0/(1-G_pc)`。

**定义 125（观测性边际与共退化指数）**
SLAM 信息矩阵 `Λ(t)=Σ_j H_j(t)^T Ω_j H_j(t)`，观测性边际 `λ_obs(t)=λ_min(Λ(t))`。共退化指数 `χ(q,scene)=κ_J(q)/λ_obs(t)`。称位形-场景对 **共退化**，当 `χ > χ_max`。直觉：奇异位形（控制退化）与低视差/纯旋转场景（感知退化）常沿同一轨迹同时出现，单独检查各自阈值会漏检其乘积风险。

**定义 126（关节空间连通性）**
技能 `S_i→S_j` 在关节空间可组合，当且仅当存在连续路径 `γ:[0,1]→𝒞`，`γ(0)∈C_{S_i}^θ`，`γ(1)∈C_{S_j}^θ`，满足关节限位、`sup_s κ_J(γ(s)) ≤ κ_max`、`inf_s λ_obs(γ(s)) ≥ λ_obs^min`，且转换成本 `c_trans(γ) ≤ τ_e`。`C_conn(S_i,S_j)` 记该路径集合，非空才允许建边。

**定义 127（SLAM-关节联合证书）**
`J_SJ = (ρ, A_cert, Σ_T, κ_J, λ_obs, G_pc, C_conn, ΔT_events, evidence)`。可部署当且仅当：
```
dom_J(T)=in ∧ δ_a<Θ_a ∧ κ_J≤κ_max ∧ λ_obs≥λ_obs^min
∧ G_pc<1 ∧ C_conn≠∅ ∧ ∀δT∈E_T(ε): ρ(d|δT)≥ρ_min
```

**定义 128（漂移鲁棒谱与回环重锚定算子）**
漂移鲁棒谱 `ρ^drift_S(d,ε)=inf_{δT∈E_T(ε)} ρ_S(d|δT)`。回环重锚定算子 `R_lc : (J_SJ, ΔT_c) → J_SJ'`：令 `Δq_c = J^†ΔT_c x_ref`，若 `||Δq_c|| > δq_lc` 则 reject/replan；否则在新帧重估 `β_S` 并回写 `A_cert`。组合规则：
```
ρ^drift_{S1⊗S2}(d) = min( ρ^drift_{S1}(d), ρ^drift_{S2}(d), 1 - P(ΔT_c > δT_budget) )
```

## 2. 关键算法 伪代码

### IP-121 JSL（Joint-Space Lift & Connectivity）

```python
def joint_profile(skill, C, ik_sampler, theta_cov=0.8):
    beta = {}
    for q in sample_configurations(C, density='coverage'):
        ok, margin = skill.feasible_at(q)          # 含碰撞/关节限位
        beta[q] = margin if ok else 0.0
    return beta

def joint_connectivity(si, sj, C, kappa_max, lambda_min):
    starts = [q for q, v in si.beta.items() if v >= theta_cov]
    goals  = [q for q, v in sj.beta.items() if v >= theta_cov]
    for q0 in starts:
        for q1 in goals:
            path = c_space_rrt_star(C, q0, q1, limits=joint_limits)
            if path is None:
                continue
            qs = densify(path)
            if max(kappa_J(q) for q in qs) > kappa_max:
                continue
            if min(observability_margin(q) for q in qs) < lambda_min:
                continue
            return path                        # 首个可行即可，后续按成本排序
    return None
```

### IP-122 SAA（Singularity-Aware Amplification）

```python
def amplification_certify(traj, Sigma_T, L_f, kappa_max, dq_budget):
    worst = 0.0
    for q in traj:
        J = jacobian(q)
        s_min = smallest_singular_value(J)
        if s_min < EPS_SINGULAR:
            return ('reject', 'singularity', q)
        kappa = 1.0 / s_min
        if kappa > kappa_max:
            return ('reject', 'kappa_exceeded', kappa)
        dq = kappa * L_f * spectral_norm(Sigma_T)
        worst = max(worst, dq)
        if dq > dq_budget:
            return ('reject', 'drift_amplified', dq)
    return ('ok', worst)
```

### IP-123 OSA（Observability-aware Skill Assignment）

```python
def observability_aware_plan(skills, G, task, Q0, lambda_min):
    # 状态 = (skill, 信息矩阵估计, 地图帧)；边权含任务成本 + 观测性惩罚
    start = ('root', Q0, identity_frame())
    return a_star_augmented(
        start, task,
        expand=lambda s: [
            (n, G[s[0]][n].cost + obs_penalty(n, s) + cond_penalty(n, s))
            for n in G.successors(s[0])
            if edge_conn_ok(s[0], n)
        ],
        goal=lambda s: task.done(s),
        constraint=lambda s: eig_min(s[1]) >= lambda_min)
```

### IP-124 DRC（Drift-Robust Certificate）

```python
def drift_robust_spectrum(skill_seq, Sigma_T, eps, rho_min):
    rho = {}
    for d in dimensions:
        worst = 1.0
        for dT in worst_case_drift_samples(Sigma_T, eps):  # 椭球内对抗采样
            worst = min(worst, evaluate_robustness(skill_seq, d, drift=dT))
        rho[d] = worst
    return ('ok', rho) if all(v >= rho_min for v in rho.values()) else ('reject', rho)
```

### IP-125 LCR（Loop-Closure Re-anchoring）

```python
def reanchor(J_SJ, delta_T_c, x_ref, dq_budget, sim_model):
    J = jacobian(current_config())
    dq = pseudo_inverse(J) @ transform_point(delta_T_c, x_ref)
    if norm(dq) > dq_budget:
        return ('reject', 'loop_closure_overshoot', norm(dq))
    new_frame = compose_frame(J_SJ.frame, delta_T_c)
    beta = joint_profile(current_skill(), C, ik_sampler)   # 新帧重估
    alpha = lift_to_task(beta, new_frame)
    if not cover_check(alpha, task_action_set(), theta_cov=0.8):
        exp = explain_failure(sim_model.run(current_skill(), dq), sim_model)
        return ('replan', exp)
    return ('ok', reissue(J_SJ, beta, alpha, new_frame))
```

### IP-126 SJC（SLAM-Joint Coupled Certificate）

```python
def slam_joint_certificate(skill_seq, Sigma_T, bounds, got_c):
    A_core = intersection([s.alpha for s in skill_seq])
    path = joint_connectivity_chain(skill_seq)        # 逐边调用 IP-121
    if path is None:
        return ('reject', 'joint_disconnected')
    qs = densify(path)
    kappa = max(kappa_J(q) for q in qs)
    lam   = min(observability_margin(q) for q in qs)
    G     = max(perception_control_gain(q) for q in qs)
    if kappa > bounds.kappa_max or lam < bounds.lambda_min or G >= 1.0:
        return ('reject', 'codegeneracy', (kappa, lam, G))
    status, rho_d = drift_robust_spectrum(skill_seq, Sigma_T, bounds.eps, bounds.rho_min)
    if status != 'ok':
        return (status, 'drift_fragile', rho_d)
    return ('ok', JointCert_SLAM(rho_d, A_core, Sigma_T, kappa, lam, G, path))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| JSL | O(|𝒞|·|S| + |E_conn|·T_rrt) | O(|𝒞| + |E_conn|) | IK 采样覆盖、RRT* 概率完备 |
| SAA | O(|traj|·(m·n² + n³)) | O(n²) | σ_min 估计下界、L_f 标定 |
| OSA | O(|V| log|V| + |E|·|𝔇_Λ|) | O(|V|·|𝔇_Λ|) | 观测性估计保守、状态扩展完备 |
| DRC | O(|𝔇_ρ|·|E_T|·|S|) | O(|𝔇_ρ|·|E_T|) | 椭球覆盖、最坏情形采样 sound |
| LCR | O(n² + |𝒞|) | O(n + |𝒞|) | 事件检测延迟、重锚定预算闭合 |
| SJC | O(|S|·|𝒞| + |E_conn|·T_rrt + |𝔇_ρ|·|E_T|) | O(|𝒞| + |E_conn|) | 三重裕度联合、证书 sound |

**引理 1（不确定性放大界）**
设 `||δT|| ≤ ε_T` 且 `||∂f/∂T|| ≤ L_f`，则 `||δx|| ≤ L_f ε_T`，`||δq|| ≤ κ_J L_f ε_T`。因此关节预算 `δq_budget` 等价于要求
```
κ_J ≤ δq_budget / (L_f ε_T)
```
即 **定位精度与关节条件数必须成反比配置**：定位越差，允许的奇异裕度越保守。

**正确性定理（SLAM-Joint Composition Soundness）**
在第 54 轮 (A26)–(A28) 成立的基础上，增加：**(A29)** `β_S` 由结构化仿真 + IK 采样校准，`C_S^θ` 覆盖误差 ≤ ε_IK；**(A30)** 认证走廊上 `σ_min(J(q)) ≥ σ_0 > 0` 且 `J` 为 `L_J`-Lipschitz；**(A31)** 回环事件检测延迟 ≤ τ_detect，且 `R_lc` 完整执行；**(A32)** `G_pc ≤ 1-η`（严格环路稳定）。则
```
P_success ≥ 1 - Σ_d(1 - ρ^drift_min(d)) - β_E - P(δ_a>Θ_a)
            - P(κ_J>κ_max) - P(λ_obs<λ_obs^min)
            - P(ΔT_c>δT_budget) - ε_IK
```
且定位误差有界 `limsup ||e|| ≤ e_0/(1-G_pc)`。关键：**三项裕度（κ_J、λ_obs、G_pc）必须在同一轨迹上联合成立**，任一单独满足都不足以推出 soundness。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| IK 抬升欠采样导致虚假连通 | 高 | 区间/盒式可达性 + 冗余分支保留 + 主动采样 |
| 奇异附近 κ_J 估计噪声大 | 高 | 阻尼最小二乘 (DLS) + 条件数在线监控 + 逃逸轨迹 |
| SLAM 观测性模型失配 | 高 | 在线信息矩阵估计 + 退化场景检测（纯旋转/白墙） |
| 回环误闭合/跳变 | 中 | 可切换约束后端 + 事件门控 + 迟滞 |
| 共退化正反馈发散 | 高 | 环路增益护栏 + 限速 + 保守回退策略 |

## 6. 本轮最大风险

**一句话**：把技能组合落到关节空间并耦合 SLAM 不确定性后，soundness 从"动作覆盖"变成 **雅可比条件数、观测性边际、漂移协方差三者沿整条轨迹同时成立**；最致命的失败不是各自越界，而是 **共退化正反馈**——奇异位形与低视差场景沿同一轨迹相遇，使 `G_pc ≥ 1`，逐帧检查全部通过、执行中误差却几何级发散，因此必须以 **环路增益 < 1 的硬约束 + 共退化指数护栏 + 回环重锚定绊线** 三重防线兜底，宁可牺牲任务成功率，也绝不把"逐帧达标"误当成"整轨安全"。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（JSL×SAA×OSA×DRC×LCR×SJC）

> 承接第 54 轮产物 v31。本轮把抽象动作空间落地为 **关节空间**，并引入 **SLAM 地图帧不确定性**，新增六个算子：
> - **JSL（Joint-Space Lift & Connectivity）**：把任务空间动作剖面抬升到关节空间，做连通性判定；
> - **SAA（Singularity-Aware Amplification）**：雅可比条件数驱动的定位漂移放大认证；
> - **OSA（Observability-aware Skill Assignment）**：把主动 SLAM 观测性纳入技能序列规划；
> - **DRC（Drift-Robust Certificate）**：地图漂移椭球内的最坏情形鲁棒谱；
> - **LCR（Loop-Closure Re-anchoring）**：回环闭合触发的证书重锚定协议；
> - **SJC（SLAM-Joint Coupled Certificate）**：控制-感知联合证书，统一 κ_J / λ_obs / G_pc。

## 2. 关键算法 伪代码

### IP-121 JSL

```python
def joint_profile(skill, C, ik_sampler, theta_cov=0.8):
    beta = {}
    for q in sample_configurations(C, density='coverage'):
        ok, margin = skill.feasible_at(q)
        beta[q] = margin if ok else 0.0
    return beta

def joint_connectivity(si, sj, C, kappa_max, lambda_min, theta_cov=0.8):
    starts = [q for q, v in si.beta.items() if v >= theta_cov]
    goals  = [q for q, v in sj.beta.items() if v >= theta_cov]
    best = None
    for q0 in starts:
        for q1 in goals:
            path = c_space_rrt_star(C, q0, q1, limits=joint_limits)
            if path is None: continue
            qs = densify(path)
            if max(kappa_J(q) for q in qs) > kappa_max: continue
            if min(observability_margin(q) for q in qs) < lambda_min: continue
            cost = path_length(qs)
            if best is None or cost < best[0]:
                best = (cost, path)
    return best[1] if best else None
```

### IP-122 SAA

```python
def amplification_certify(traj, Sigma_T, L_f, kappa_max, dq_budget):
    worst = 0.0
    for q in traj:
        J = jacobian(q)
        s_min = smallest_singular_value(J)
        if s_min < EPS_SINGULAR:
            return ('reject', 'singularity', q)
        kappa = 1.0 / s_min
        if kappa > kappa_max:
            return ('reject', 'kappa_exceeded', kappa)
        dq = kappa * L_f * spectral_norm(Sigma_T)
        worst = max(worst, dq)
        if dq > dq_budget:
            return ('reject', 'drift_amplified', dq)
    return ('ok', worst)
```

### IP-123 OSA

```python
def observability_aware_plan(skills, G, task, Q0, lambda_min):
    start = ('root', Q0, identity_frame())
    return a_star_augmented(
        start, task,
        expand=lambda s: [
            (n, G[s[0]][n].cost + obs_penalty(n, s) + cond_penalty(n, s))
            for n in G.successors(s[0])
            if joint_connectivity(skills[s[0]], skills[n], C, kappa_max, lambda_min)
        ],
        goal=lambda s: task.done(s),
        constraint=lambda s: eig_min(s[1]) >= lambda_min)
```

### IP-124 DRC

```python
def drift_robust_spectrum(skill_seq, Sigma_T, eps, rho_min):
    rho = {}
    for d in dimensions:
        worst = 1.0
        for dT in worst_case_drift_samples(Sigma_T, eps):
            worst = min(worst, evaluate_robustness(skill_seq, d, drift=dT))
        rho[d] = worst
    if any(v < rho_min for v in rho.values()):
        return ('reject', rho)
    return ('ok', rho)
```

### IP-125 LCR

```python
def reanchor(J_SJ, delta_T_c, x_ref, dq_budget, sim_model):
    J = jacobian(current_config())
    dq = pseudo_inverse(J) @ transform_point(delta_T_c, x_ref)
    if norm(dq) > dq_budget:
        return ('reject', 'loop_closure_overshoot', norm(dq))
    new_frame = compose_frame(J_SJ.frame, delta_T_c)
    beta = joint_profile(current_skill(), C, ik_sampler)
    alpha = lift_to_task(beta, new_frame)
    if not cover_check(alpha, task_action_set(), theta_cov=0.8):
        exp = explain_failure(sim_model.run(current_skill(), dq), sim_model)
        return ('replan', exp)
    return ('ok', reissue(J_SJ, beta, alpha, new_frame))
```

### IP-126 SJC

```python
def slam_joint_certificate(skill_seq, Sigma_T, bounds):
    A_core = intersection([s.alpha for s in skill_seq])
    path = joint_connectivity_chain(skill_seq)
    if path is None:
        return ('reject', 'joint_disconnected')
    qs = densify(path)
    kappa = max(kappa_J(q) for q in qs)
    lam   = min(observability_margin(q) for q in qs)
    G     = max(perception_control_gain(q) for q in qs)
    if kappa > bounds.kappa_max or lam < bounds.lambda_min or G >= 1.0:
        return ('reject', 'codegeneracy', (kappa, lam, G))
    status, rho_d = drift_robust_spectrum(skill_seq, Sigma_T, bounds.eps, bounds.rho_min)
    if status != 'ok':
        return (status, 'drift_fragile', rho_d)
    A_cert = (A_core, buffer_zone(A_core, bounds.delta_a))
    return ('ok', JointCert_SLAM(rho_d, A_cert, Sigma_T, kappa, lam, G, path))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| JSL | O(\|𝒞\|·\|S\| + \|E_conn\|·T_rrt) | O(\|𝒞\|+\|E_conn\|) | IK 采样覆盖、RRT* 概率完备 |
| SAA | O(\|traj\|·(m·n²+n³)) | O(n²) | σ_min 下界估计、L_f 标定 |
| OSA | O(\|V\| log\|V\| + \|E\|·\|𝔇_Λ\|) | O(\|V\|·\|𝔇_Λ\|) | 观测性保守、状态扩展完备 |
| DRC | O(\|𝔇_ρ\|·\|E_T\|·\|S\|) | O(\|𝔇_ρ\|·\|E_T\|) | 椭球覆盖、最坏采样 sound |
| LCR | O(n²+\|𝒞\|) | O(n+\|𝒞\|) | 事件延迟、重锚定预算闭合 |
| SJC | O(\|S\|·\|𝒞\|+\|E_conn\|·T_rrt+\|𝔇_ρ\|·\|E_T\|) | O(\|𝒞\|+\|E_conn\|) | 三重裕度联合、证书 sound |

**引理 1（不确定性放大界）**
若 `||δT|| ≤ ε_T`、`||∂f/∂T|| ≤ L_f`，则 `||δq|| ≤ κ_J L_f ε_T`，从而关节预算 `δq_budget` 要求
```
κ_J ≤ δq_budget / (L_f ε_T)
```

**正确性定理（SLAM-Joint Composition Soundness）**
第 54 轮 (A26)–(A28) 成立，且：**(A29)** `β_S` 覆盖误差 ≤ ε_IK；**(A30)** 认证走廊上 `σ_min(J) ≥ σ_0 > 0`、`J` 为 `L_J`-Lipschitz；**(A31)** 回环检测延迟 ≤ τ_detect 且 `R_lc` 完整执行；**(A32)** `G_pc ≤ 1-η`。则
```
P_success ≥ 1 - Σ_d(1-ρ^drift_min(d)) - β_E - P(δ_a>Θ_a)
            - P(κ_J>κ_max) - P(λ_obs<λ_obs^min)
            - P(ΔT_c>δT_budget) - ε_IK
```
且 `limsup ||e|| ≤ e_0/(1-G_pc)`。关键：**κ_J、λ_obs、G_pc 必须在同一轨迹上联合成立**，任一单独达标都不构成 soundness。

## 6. 本轮最大风险

**一句话**：把技能组合落到关节空间并耦合 SLAM 不确定性后，soundness 从"动作覆盖"变成 **雅可比条件数、观测性边际、漂移协方差三者沿整条轨迹同时成立**；最致命的失败不是各自越界，而是 **共退化正反馈**——奇异位形与低视差场景沿同一轨迹相遇，使 `G_pc ≥ 1`，逐帧检查全部通过、执行中误差却几何级发散，因此必须以 **环路增益 < 1 的硬约束 + 共退化指数护栏 + 回环重锚定绊线** 三重防线兜底，宁可牺牲任务成功率，也绝不把"逐帧达标"误当成"整轨安全"。
