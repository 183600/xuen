### 第 6 轮灵感驱动研究记录（新循环第 1 轮）

**灵感词**：多视角视觉、共情表达

**继承关系**：第 5 轮 CADVS-v5（IP-493~496）把提议从离散规则升级为条件流匹配（FMPP），把记忆升级为「嵌入检索 + 铸证固化」（LMEM-v2），把人因锚从手势意图升级为面部情感调制（FAMK），并证明证书不变性（定理 6）、调制单调性（定理 5）、固化有界性（定理 7），执行集 Exec_v5 ⊆ Exec_v4。本轮不推翻 v5，而是补 v5 的两个结构性短板：(a) 感知仍以单视角为主，遮挡/视角退化下覆盖门（3DCF）的不确定性只能靠保守阈值硬扛，且单目面部情感极易被遮挡、侧脸与伪造攻击；(b) 人因回路是**单向**的——只读人类情感，不会表达共情，机器人无法主动维持信任与协作；而一旦补上表达，就引入「情感闭环」这一全新攻击面。两个灵感词统一为主题「**可核验的共情**」（Verifiable Empathy, VE）：多视角既为几何覆盖提供跨视角一致性证书，又为情感推断提供跨视角互证；共情表达则被约束为「证书接地的诚实表达」。形成 CADVS-v6（IP-497~500）。本轮自律：**硬门仍为七门、数量不增**——多视角一致性并入既有 kc_cov（覆盖门）作为更强的合取谓词，共情表达是**执行输出而非新门**，情感因果分离器是**调制通道而非新门**。执行集升级为 Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ … ⊆ Exec_v29。

**直觉与动机**：

1. **多视角视觉 → 覆盖门从「单视角可见性」升级为「跨视角一致性合取」，只紧不松**。单目覆盖门在遮挡与斜视下只有两种选择：要么阈值保守（大量误拒），要么冒险（把被遮挡面当成可见）。多视角给出第三条路——**几何自证**：同一 3D 点在至少两个视角的重投影残差 ξ_mv 若在冻结阈值 ε_mv 内，则「看见」不再是单帧置信度的主观声明，而是可被独立视角复核的客观事实。关键设计是把 ξ_mv 作为 kc_cov 的**合取项**（kc_cov^mv = kc_cov^5 ∧ 1[ξ_mv ≤ ε_mv]），而非新增第八门：门数量不变，谓词更强。多视角融合把重建方差随视角数与视差增大而下降（引理 45），因此**误拒率下降而阈值一寸不松**；新增视角只会让合取更难过，执行集单调收缩。副产品：3D 人脸/人体/步态重建天然抗遮挡，为第 2 点提供互证底座。

2. **共情表达 → 把单向「读情感」升级为双向回路，但表达必须「接地」**。v5 的 FAMK 只读痛苦并收紧门；v6 增加输出通道 E=(显示效价, 韵律, 手势, 运动风格)。天真的做法是「痛苦高就安抚」，这同时埋下两颗雷：(i) **过度安抚即欺骗**——在认证边际很低时用温暖表情宣称「没事」，是拿表达透支信任；(ii) **安抚会反向放松安全门**——若表达真的降低了观测痛苦 p_obs，而 v5 的 γ 又随 p_obs 下降而放松，就形成「安抚→痛苦↓→门松→更冒险」的正反馈。因此设两条硬约束：**诚实接地** G_exp（每条安抚断言必须被证书支撑，表达强度受认证边际 m 约束，m 低时只能表达谨慎而非安心）；**因果分离** p_endo = p_obs + β̂·E（β̂ ≥ 0 为表达缓解系数，用机器人自身表达作工具变量估计），安全调制只用内生痛苦 p_endo 而非被安抚污染的 p_obs。由于 p_endo ≥ p_obs，因果分离在结构上只收紧、不放松（定理 11）。

3. **多视角 × 共情 → 多视角是「可核验共情」的接地底座**。单视角情感可被遮挡、侧脸、口罩、甚至对抗贴片欺骗；多视角 3D 人脸动作单元 + 人体张力 + 步态给出**跨视角情感互证**，既降低 FER 漏检，又抬高伪造成本。更重要的是：共情表达本身是**被人类观测的输出**，所以它必须与内部认证状态因果一致，否则就是操纵。两个灵感词由此合流——多视角提供「可核验的感知」，共情表达提供「可核验的输出」，二者共同把「信任」从主观承诺变成可审计对象。

**关键洞见**：v5 回答「提议可换、门不变」；v6 回答「当感知是多视角、人因是双向闭环时，如何让证书边界仍不变，并让共情表达本身可被核验」。v6 新增的不是门，而是两类**证书来源**（跨视角一致性、表达接地）与一个**因果分离器**。执行集收缩由「同七门 + kc_cov 加合取 ξ_mv + 阈值冻结 + 表达不参与门 + 内生痛苦只增不减」五重保证。

**形式化目标（增量）**：
1. 多视角一致性证书：ξ_mv(x)=max_{v≠v'} 重投影残差；kc_cov^mv(x)=kc_cov^5(x) ∧ 1[ξ_mv ≤ ε_mv]；视差条件不确定度 σ_mv；软因子 η_mv。
2. 多视角 3D 人因：a_3d=(face_3d, body_3d, gait)；跨视角 AU/张力/步态互证，降低 FER 漏检与伪造面。
3. 共情表达：E=(e_disp,e_pros,e_gest,e_style)；表达预算 E_max=clip(α·m+β·p_endo, 0, E_cap)；接地证书 G_exp；运动风格只做认证包络内的重参数化。
4. 因果分离：p_endo=p_obs+β̂·E（β̂≥0）；不可识别时取保守上界 p_endo^UB=p_obs+β_max·E；hold-out 抑制窗口周期重基线。
5. 定理 9（多视角合取收缩）、定理 10（诚实共情/防过度安抚）、定理 11（因果分离单调收紧 + 情感闭环小增益稳定）、定理 12（七锚完备性在双向回路下保持）。
6. Exec_v6 = {x ∈ supp(π_FM^v6) : ∧_i kc_i(x;τ_i^5)=1 ∧ kc_cov^mv(x)=1} ⊆ Exec_v5。

**本轮最大风险**：**情感闭环的反向杠杆**——机器人越成功地用共情表达安抚人类，观测痛苦越低，而安全调制若误用观测痛苦，就会「安抚→痛苦↓→门松→更冒险」，系统还会把这种自我制造的平静误读为安全；多视角互证与因果分离只能缓解，一旦表达与感知共享同一观测通道、缓解系数不可识别，这一杠杆原理上无法根除。

## 2. 关键算法骨架

### IP-497 MVCK：多视角一致性核（感知时域 10–30 Hz，与控制环解耦）

```python
@dataclass
class MultiViewConsistencyKernel:
    """MVCK：多视角几何融合 + 跨视角一致性证书。
    定理 9：一致性是 kc_cov 的合取项——加视角只会让门更难通过，不会更易"""
    n_views: int = 4
    eps_mv: float = 0.02          # 重投影残差阈值（冻结只读）
    sigma_max_mv: float = 0.03    # 不确定度软因子上限

    def fuse(self, views, t_now) -> MVState:
        # 三角化 + 视差条件不确定度；单视角被遮挡的面由其他视角补
        X, sigma = triangulate(views)                 # O(N^2) 点对
        xi = max_reprojection_residual(views, X)      # ξ_mv
        return MVState(X3d=X, sigma=sigma, xi_mv=xi,
                       face3d=fit_3d_face(views),     # 抗遮挡 3D AU
                       body3d=fit_3d_body(views),
                       gait=estimate_gait(views))

    def kc_cov_mv(self, x, mv, kc_cov_v5: bool) -> bool:
        # 同门加强谓词：v5 覆盖 ∧ 跨视角一致；绝不新增第八门
        return kc_cov_v5 and (mv.xi_mv <= self.eps_mv)

    def eta_mv(self, mv) -> float:
        return sigmoid(self.sigma_max_mv - mv.sigma)  # 不确定度越低分越高
```

### IP-498 EEXK：诚实共情表达核（输出时域 10–30 Hz，运动风格入控制环但仅重参数化）

```python
@dataclass
class EmpatheticExpressionKernel:
    """EEXK：证书接地的共情表达。
    定理 10：表达强度受认证边际约束，边际低时只能表达谨慎，不能表达安心"""
    E_cap: float = 1.0
    alpha: float = 0.6
    beta: float = 0.4
    lam_emp: float = 0.3

    def budget(self, m: float, p_endo: float) -> float:
        return clip(self.alpha * m + self.beta * p_endo, 0.0, self.E_cap)

    def express(self, state, m, p_endo, G_exp: bool) -> E:
        if not G_exp:
            return E_caution(state)          # 无接地证书：中性/谨慎，不给虚假安心
        planned = plan_empathy(state, p_endo)   # 痛苦高→支持性表达
        return project_to_budget(planned, self.budget(m, p_endo))

    def style_project(self, certified_traj, e_style):
        """运动风格只做认证包络内的时间重参数化/速度剖面微调，
        不产生包络外轨迹：kc_ee/kc_bal/kc_wrench 的证书原样有效"""
        return reproject_within_envelope(certified_traj, e_style)
```

```python
    定理 12：v6 不增删锚点：七锚 {3DCF, MSRG, HICK, EEK, LTEM, VACK, BCK} 完备性（v4 定理 4）保持；

    ACGS 是 HICK 的调制估计器（非新锚）。证明：锚集不变 + 只紧（定理 9/11）。∎
    """
    return "Proven"
```

### IP-500 EFA-v6：七硬门 + 多视角合取 + 诚实共情

```python
@dataclass
class EvidenceForgingAssemblerV6:
    """EFA-v6：七硬门与 τ^5 全部冻结；kc_cov 加合取 ξ_mv；表达接地"""
    mvck: MultiViewConsistencyKernel
    eexk: EmpatheticExpressionKernel
    acgs: AffectCausalityGroundingSeparator
    v5: EvidenceForgingAssemblerV5

    def select(self, x0_state, t_now, rule_id, context) -> tuple[bool, Trajectory | None, str, E | None]:
        mv = self.mvck.fuse(context.views, t_now)              # 多视角融合
        p_obs = self.v5.famk.observe(mv.face3d, t_now)         # 多视角 3D 情感
        p_endo = self.acgs.endogenous(p_obs.p_distress, E_prev) # 因果分离
        gamma = self.v5.famk.gamma(with_p(p_obs, p_endo))       # 只用内生痛苦调制
        c = build_ctx(context, mv, p_endo, self.v5.lmem)
        cands = self.v5.fmpp.propose(c, self.v5.fmpp.K)
        # 廉价门：coverage 现为 kc_cov^mv（合取 ξ_mv），其余不变
        surv = [x for x in cands
                if self.mvck.kc_cov_mv(x, mv, self.v5._kc_cov_v5(x))
                and self.v5._other_cheap_gates(x, gamma)]
        if not surv:
            return self._fallback_rule_proposal(gamma, mv)     # fail-closed 回退 v4 规则
        surv.sort(key=self.v5._prefilter_score, reverse=True)
        finals = [x for x in surv[:3]
                  if self.v5.vack.kc_val(self.v5.vack.evaluate(x, c, t_now),
                                         tau=gamma['val'] * TAU_VAL4)]
        ok = [x for x in finals if self.v5._bck_preview(x, gamma)]
        if not ok:
            return False, None, 'ALL_CANDIDATES_REJECTED', None
        best = max(ok, key=certified_margin)
        m = certified_margin(best)
        # 共情表达：先算接地证书，再在预算内表达；不参与门
        G_exp = self.acgs.grounding_certificate(plan_claims(m, p_endo), cert_of(best))
        E_out = self.eexk.express(best, m, p_endo, G_exp)
        return True, best, 'FORGED_VE', E_out

    def ecs_v6(self, ..., n_flow, s_emo, mv, G_exp) -> float:
        eta_mv = self.mvck.eta_mv(mv)
        eta_emp = (1.0 - self.eexk.lam_emp) if not G_exp else 1.0
        return self.v5.ecs_v5(..., n_flow=n_flow, s_emo=s_emo) * eta_mv * eta_emp
```

## 4. 正确性论证（增量更新）

### 引理 45（多视角重建方差收缩）

**陈述**：设 N 个视角对同一 3D 点的观测独立、噪声方差 σ²，基线/视差张成矩阵 B，则三角化重建协方差 ≈ σ²(BᵀB)⁻¹，其迹 ≤ C/N（B 满秩时）；由此 σ_mv 随 N 与视差单调下降，同一 ε_mv 下的误拒率单调不增。∎

**诚实边界**：视角高度共线（视差退化）时 B 病态，方差反而放大——因此 ξ_mv 与 σ_mv 同时门控，视差不足时 fail-closed 收紧。

### 引理 46（情感因果分离的偏差界）

**陈述**：设 p_obs = p_endo − β‖E‖ + ε，ε 为有界噪声/未测混淆，|ε| ≤ δ。则用 p̂_endo = p_obs + β̂‖E‖ 估计内生痛苦时，|p̂_endo − p_endo| ≤ |β̂−β|‖E‖ + δ。取 β̂=β_max ≥ β 时误差单边偏保守（p̂_endo ≥ p_endo − δ）。∎

**诚实边界**：β 的符号与大小依赖工具变量排他性（机器人表达只经由情感影响观测痛苦，不直接影响真实危险），该假设不可完全检验；不可识别时退化为保守上界。

### 定理 v6（多视角合取 + 诚实共情的总装）

**陈述**：在 v5 假设 (B1)~(B7) 及新增 (B8) 多视角标定误差 ≤ ε_mv/2、(B9) β̂ ≥ 0 或取 β_max 下：
(i) Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ … ⊆ Exec_v29（多视角合取 + p_endo ≥ p_obs 双重只紧）；
(ii) 多视角一致性不新增门：kc_cov^mv 是 kc_cov^5 的合取强化（定理 9）；
(iii) 共情表达不进入任何门，且受认证边际约束，过度安抚结构性排除（定理 10）；
(iv) 因果分离只收紧；情感闭环在 κ_loop < 1 时稳定（定理 11）；
(v) 七锚完备性保持（定理 12）；
(vi) 多视角误拒由引理 45 界，情感分离偏差由引理 46 界。

**证明**：(i) 由定理 9（合取）与定理 11（p_endo ≥ p_obs ⇒ γ 更大）；(ii)(iii)(iv)(v) 分别由定理 9、10、11、12；(vi) 由引理 45/46。∎

**诚实声明**：(B8) 多视角标定/同步误差会造成 ξ_mv 假阴性（把不一致当一致），只能靠在线标定监测与 ε_mv 只紧不松限损；(B9) 情感因果分离依赖工具变量排他性与 κ_loop 估计，未测混淆下只有保守上界，无精确分离；(iii) 共情表达的「适当性」是价值判断，接地证书只保证不欺骗、不保证被人类正确理解；(iv) 3D 人脸属生物特征，多视角放大隐私面，端侧与 DP 只能缓解不能消除合规风险。

## 7. 本轮最大风险（最终确认）

**一句话**：**情感闭环的反向杠杆**——机器人越成功地用共情表达安抚人类，观测痛苦越低，而安全调制若误用观测痛苦，就会「安抚→痛苦↓→门松→更冒险」，系统还会把这种自我制造的平静误读为安全；多视角互证与因果分离只能缓解，一旦表达与感知共享同一观测通道、缓解系数不可识别，这一杠杆原理上无法根除。
