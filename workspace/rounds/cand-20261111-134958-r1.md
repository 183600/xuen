# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感驱动研究循环 第 1 轮；本轮灵感：「仿真到现实迁移」×「长程任务」）

> 第 54 轮把技能组合提升为「动作空间剖面 + 鲁棒性谱 + 云边联合证书」。本轮把视角从「单次组合是否可部署」推进到「一次部署能在真实世界连续跑多久」。核心矛盾：H22：仿真到现实（sim-to-real）间隙不是一个可一次性标定的标量，而是随状态-动作变化的**间隙场**，且会被长程任务逐步放大；H23：长程任务的成功不是各子任务成功的简单连乘，点误差经闭环动力学**复利**后可在无锚点条件下指数发散，导致短程验证通过的策略在长程部署中系统性失效。

## 0. 直觉与动机

**灵感 1（迁移间隙是「场」而不是「标量」）**
直觉：把 sim-to-real 误差当作一个数（如平均成功率差）几乎必然误导。真实间隙依赖具体状态-动作：摩擦主导的接触动作间隙大，自由空间视觉伺服间隙小。因此应把间隙建模为**间隙场** `g(x,a)`，并分解为感知 / 动力学 / 执行 / 接触四个可归因分量。只有知道「哪一类间隙在任务轨迹的哪一段注入」，才能谈长程补偿。

**灵感 2（长程任务 = 误差的闭环复利）**
直觉：单步误差 `g_t` 不可怕，可怕的是它进入反馈环后被放大。若真实-仿真误差在闭环下满足 `e_{t+1} ≤ κ e_t + g_t`，则 `κ<1` 时误差收敛到 `g/(1-κ)`，`κ≥1` 时误差随视界指数增长。长程任务的第一个科学问题不是「策略多强」，而是「闭环误差传递的谱半径是多少」。这把长程任务从「步数多」重新定义为「误差被放大还是被收缩」。

**灵感 3（认证视界 → 从「能否迁移」到「能迁移多久」）**
直觉：既然误差有复利，就不该问一个二值的「能否 sim-to-real」，而应输出一个**认证迁移视界** `H_cert(ε,δ)`：在置信度 `1-δ` 下，累计任务相关误差不超过 `ε` 的最大步数。超过 `H_cert` 不是「策略坏了」，而是「证书过期」，必须插入现实锚点重新校准。这把迁移从一次性验收变为**带有效期的可续期证书**。

**灵感 4（现实锚点与迁移信用）**
直觉：现实世界的少量真机校准（锚点）能把累计误差重置。锚点昂贵，所以应优化**锚点放置**：在误差即将越过预算的临界点插入一次最便宜、信息量最大的校准。定义**迁移信用** `Φ = 延长的认证视界 / 锚点成本`，把「什么时候必须回真实世界」变成可计算的调度问题，而不是凭经验定期校准。

**灵感 5（长程任务的风险预算账本）**
直觉：长程任务由子目标/选项组成，总风险不是连乘而是可**分账**的：给每个子任务分配误差预算 `ε_i` 与失败置信 `δ_i`，沿关键路径求和。若某一段实际消耗超预算，就重分配或插入锚点。这把长程规划从「找一条能走通的路」变为「找一条总预算可闭合的路」，并与第 54 轮的动作-鲁棒性证书对齐。

**灵感 6（迁移契约 → 云边闭环的时间维度扩展）**
直觉：第 54 轮的云边契约只规定「动作如何对齐」，本轮增加时间维度：云端持有高保真仿真并签发 `SRC` 迁移契约，边端在真实世界执行并用 anytime-valid 监控器审计间隙；一旦监控器报警或契约到期，云端必须重新签发而非静默续期。云规划-边审计-锚点回灌-重签发形成闭环。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（现实间隙场）**
对状态-动作 `(x,a)`，现实间隙场
```
g(x,a) = (g_perc, g_dyn, g_act, g_con)(x,a) ∈ ℝ_+^4
```
其中 `g_perc = d_o(φ(o^R), φ(o^S))`，`g_dyn = ||f^R(x,a) - f^S(x,a)||_Σ`，`g_act` 为执行器响应差，`g_con` 为接触/摩擦差。以任务相关投影 `Π_T` 加权得标量 `||g||_W = ||W Π_T g||_2`；与任务无关的间隙权重为 0。间隙场由配对仿真-真实 rollout 校准，记为 `ĝ`，并附分量归因向量。

**定义 122（间隙递推与收缩证书）**
设任务相关累计误差 `e_t`，闭环误差传递满足
```
e_{t+1} ≤ κ_t e_t + ||g_t||_W,     e_0 = 0
```
`κ_t` 为闭环误差谱半径。**收缩证书** `K_cert = (κ_U, b_U, n, conf)` 由 rollout 数据的稳健回归 + bootstrap 上界给出，要求 `κ_U < 1`。在锚点 `t_k` 处允许测量并重置：`e_{t_k}^+ ≤ κ_a e_{t_k}^- + ν`，`κ_a<1`，`ν` 为锚点测量噪声界。

**定义 123（迁移性谱与认证迁移视界）**
技能/策略 `S` 的迁移性谱
```
τ_S(d,h) = inf{ p : P(∀t≤h, ||e_t||_W ≤ d | S) ≥ p }
```
对 `h` 单调不增。**认证迁移视界**
```
H_cert(ε,δ) = max{ h : LCB_{1-δ}( τ_S(ε,h) ) ≥ 1-δ }
```
其中 `LCB` 由 anytime-valid 置信序列（e-process / 测试鞅）给出，允许沿长程不断「偷看」而不损失有效性。若无锚点且 `κ_U≥1`，约定 `H_cert=0`。

**定义 124（长程任务风险预算）**
长程任务建模为选项 DAG `T = (G, ≺, {ε_i, δ_i})`，关键路径 `P`。风险账本 `L` 为沿 `P` 的预算分配。组合规则：
```
P(fail | T) ≤ Σ_{i∈P} δ_i + δ_shift,
Σ_{i∈P} ε_i ≤ ε_total
```
**可行性**：存在分配 `L` 使上述两式同时成立。单个选项的 `(ε_i,δ_i)` 直接取自其 `SRC` 与第 53 轮鲁棒性谱 `ρ`（取 `ε_i = 1-ρ_i`、`δ_i = 1-τ_i`）。

**定义 125（锚点策略与迁移信用）**
锚点策略 `π_a = {(t_k, type_k, c_k)}`，`c_k` 为第 k 次现实校准成本。其延长的认证视界为 `H_cert(π_a)`。**迁移信用**
```
Φ(π_a) = (H_cert(π_a) - H_cert(∅)) / Σ_k c_k
```
最优锚点放置为 `max_{π_a} H_cert(π_a)  s.t.  Σ c_k ≤ B_a`，并可用分段 DP 求解。虚拟锚点（高保真子仿真/数字孪生）作为 `c` 更低但 `κ_a` 更差的锚点类型参与同一优化。

**定义 126（仿真到现实迁移契约 SRC）**
迁移契约
```
SRC = (H_cert, ε, δ, K_cert, π_a, ĝ, D_cov, evidence)
```
- `D_cov` 为真实任务分布相对锚点校准支撑集的覆盖度（加权 conformal）；
- `evidence` 至少包含配对 rollout、间隙分量归因、e-process 审计轨迹、锚点日志。
**可部署条件**：`H_req ≤ H_cert ∧ D_cov ≥ θ_dom ∧ K_cert.κ_U < 1`。契约在监控器报警、`D_cov` 跌破阈值或超过 `H_cert` 时**自动失效**，不得静默续期，必须重新签发。

## 2. 关键算法 伪代码

### IP-121 RGF（Reality Gap Field Profiling）

```python
def profile_gap_field(policy, sim, real, states, ablation):
    g = {}
    for x in states:
        a = policy(x)
        o_s, o_r = sim.rollout(x,a), real.rollout(x,a)
        g_perc = obs_metric(phi(o_r), phi(o_s))
        g_dyn  = dyn_metric(sim.f(x,a), real.f(x,a))
        g_act  = actuation_diff(sim, real, a)
        g_con  = contact_diff(sim, real, x, a)
        g[x] = (g_perc, g_dyn, g_act, g_con)
    return attribute(g, ablation), task_project(g, W)
```

### IP-122 DRC（Drift Recursion Certificate）

```python
def contraction_certificate(e_pairs, alpha=0.05, B=2000):
    # e_pairs = [(e_t, e_next)] 由同轨迹配对 rollout 得到
    kappa = robust_regress_slope(e_pairs)
    boots = [robust_regress_slope(resample(e_pairs)) for _ in range(B)]
    kappa_U = quantile(boots, 1-alpha)
    b_U = quantile([max(resid(p)) for p in boots], 1-alpha)
    if kappa_U >= 1.0:
        return ('reject', 'non_contractive', kappa_U)
    return ('ok', K_cert(kappa_U, b_U, len(e_pairs), 1-alpha))
```

### IP-123 HCH（Horizon Certification）

```python
def certify_horizon(gap_stream, K_cert, eps, delta, anchor_policy):
    M = EProcess(lam=choose_lambda(K_cert.b_U))
    e = 0.0
    H_cert = 0
    for t in range(1, H_max+1):
        g_t = gap_stream.observe(t)          # anytime-valid 观测
        M.update(g_t)
        if not M.within(1-delta):            # Ville 不等式：P(∃t 越界) ≤ delta
            break
        b_hat = max(K_cert.b_U, M.upper_mean())
        e = K_cert.kappa_U * e + b_hat
        if t in anchor_policy.times:
            e = K_cert.kappa_a * e + K_cert.nu
        if e > eps:
            break
        H_cert = t
    return H_cert, M.audit_trail()
```

### IP-124 RBL（Risk-Budget Ledger）

```python
def allocate_budget(T, skill_certs, eps_total, delta_total):
    # 沿关键路径做 DP：最小化最大段风险 / 或可行性判定
    for path in critical_paths(T):
        # 按灵敏度 s_i 与收缩 1/(1-kappa_i) 分配，再二分可行阈值
        alloc = water_fill(path, eps_total, key=lambda i: skill_certs[i].sens)
        if sum(alloc.values()) > eps_total:
            return ('infeasible', path)
        if sum(skill_certs[i].delta for i in path) > delta_total:
            return ('infeasible', 'delta', path)
    return ('ok', L_budget(alloc))
```

### IP-125 OAP（Optimal Anchor Placement）

```python
def place_anchors(gap_field, K_cert, eps, budget, anchor_types):
    # dp[t][b] = 到 t 为止、花费 b 时的最小累计误差
    dp = defaultdict(lambda: inf); dp[(0,0)] = 0.0
    for t in 1..H_max:
        for (prev,b0), e in list(dp.items()):
            for typ in anchor_types:           # 含 "无锚点"
                c = typ.cost; e2 = evolve(e, gap_field[t], K_cert)
                if typ.is_anchor: e2 = K_cert.kappa_a*e2 + typ.nu
                if b0+c <= budget:
                    dp[(t,b0+c)] = min(dp[(t,b0+c)], e2)
        if min(dp[(t,b)] for b in budgets) > eps:
            break
    return argmin_credit(dp), H_cert(dp)
```

### IP-126 SRC（Sim2Real Contract Issuance）

```python
def issue_SRC(policy, task, sim, real, anchors, delta=0.05):
    g_hat = profile_gap_field(policy, sim, real, anchors.states)
    K = contraction_certificate(paired_rollouts(policy, sim, real))
    if K.status == 'reject':
        return ('reject', 'non_contractive')
    H = certify_horizon(g_hat.stream, K, task.eps, delta, anchors.policy)
    D_cov = weighted_conformal_coverage(anchors.calib, task.dist)
    if D_cov < theta_dom:
        return ('reject', 'domain_coverage', D_cov)
    if H < task.H_req:
        return ('reject', 'horizon_too_short', (H, task.H_req))
    return ('ok', SRC(H, task.eps, delta, K, anchors.policy, g_hat, D_cov,
                      evidence=[g_hat.audit, K.audit, anchors.log]))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| RGF | O(|X|·(c_sim+c_real)) | O(|X|·4) | 配对采样、任务投影 |
| DRC | O(n·B) | O(n) | 回归无偏、bootstrap 覆盖 |
| HCH | O(H·(1+log(1/δ))) | O(1) | e-process 有效性、κ_U<1 |
| RBL | O(|P|·|budget|²) | O(|P|·|budget|) | 预算单调、并集界 |
| OAP | O(H·B·|types|) | O(H·B) | 误差递推精确、成本可加 |

**正确性定理（Horizon-Certified Sim2Real Transfer Soundness）**
假设承接第 54 轮 (A26)–(A28)，并新增：**(A29)** 每步间隙注入 `||g_t||_W ≤ b` 且由 anytime-valid 序列在 `1-δ` 下给出上界 `b_U`；**(A30)** 闭环收缩 `κ_U<1` 且由配对 rollout 在 `1-δ` 下验证；**(A31)** 锚点重置 `e^+ ≤ κ_a e + ν`，`κ_a<1`；**(A32)** 真实任务分布落在加权 conformal 校准支撑内（`D_cov≥θ_dom`）。
则在锚点间隔为 `m` 时，段末误差满足
```
e_{t+m} ≤ κ_U^m e_t + b_U (1-κ_U^m)/(1-κ_U) ≤ b_U/(1-κ_U)
```
故 `sup_t e_t ≤ b_U/(1-κ_U) + ν/(1-κ_a) =: B`。若在 `t_s` 后发生未被检测的非平稳漂移，检测延迟 `τ_d`、漂移增速 `β`，则
```
sup_t e_t ≤ B + β·(H - t_s - τ_d)_+
```
于是当 `H_req ≤ H_cert(ε,δ)` 时，部署失败概率满足
```
P(fail) ≤ δ + δ_shift + Σ_{i∈P} δ_i
```
关键：**收缩性把长程从乘性复利变成有界误差**；**锚点与 anytime-valid 监控把「长程」变成可续期的有限契约**。

## 4. 实验设计 E162–E166

| 实验 | 指标 | 目标 |
|---|---|---|
| E162 间隙场归因准确度 | 分量归因与真实扰动的一致性（AUC / 排序相关） | 接触/动力学分量 AUC ≥ 0.85 |
| E163 认证视界覆盖性 | 在 `H_cert` 处的经验失败率 vs `δ` | 经验失败率 ≤ δ，且不过度保守（效率 ≥ 0.8） |

| E166 非平稳下契约误接受率 | 渐变磨损/光照漂移下的假接受率、检测延迟 | 假接受 ≤ 2%，检测延迟 P95 ≤ 20 步 |

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 交换性/平稳性被破坏，conformal 失效 | 高 | 加权 conformal + ACI + e-process 随时有效 |
| `κ` 估计偏低导致虚假收缩 | 高 | bootstrap 上界 + 锚点独立复核 + `κ≥1` 直接拒签 |
| 接触/摩擦间隙不可观测 | 高 | 可观测代理 + 物理先验 + 主动激励辨识 |
| 锚点成本高或不可行 | 中 | 预算约束 DP + 虚拟锚点作为低质锚点 |
| 风险预算过保守导致长程不可行 | 中 | 自适应重分配 + 超预算段触发重签发 |
| 监控器报警抖动 | 中 | e-process 天然 anytime-valid + 迟滞重签发 |

## 6. 本轮最大风险

**一句话**：把 sim-to-real 从标量验收升级为「间隙场 + 收缩证书 + 认证视界」使长程迁移第一次有了可续期的定量边界，但其 soundness **同时依赖间隙场采样的代表性、闭环收缩系数 `κ` 的无偏上界、以及真实分布不跳出 conformal 校准支撑**；一旦真实世界发生缓慢非平稳漂移（磨损、光照、负载），`κ` 与覆盖度会同时失真，迁移契约可能在「看起来仍然有效」时被静默违反，故必须以 **anytime-valid 监控 + 漂移检测 + 契约到期强制重签发** 为硬护栏，宁可短视界频繁续期，也不签一张无法被真实世界审计的长程空头支票。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-TransHorizon（RGF×DRC×HCH×RBL×OAP×SRC）

> 承接第 54 轮产物 v31（GroundEdge-GenSim+++）。本轮把「单次可部署」推进为「长程可审计的仿真到现实迁移」，新增六个算子：
> - **RGF（Reality Gap Field）**：把 sim-to-real 间隙从标量升级为可归因的四分量场；

> - **HCH（Horizon Certification）**：基于 e-process 的认证迁移视界 `H_cert(ε,δ)`；
> - **RBL（Risk-Budget Ledger）**：长程任务沿关键路径的风险预算账本；
> - **OAP（Optimal Anchor Placement）**：以迁移信用最大化为目标的现实锚点调度；
> - **SRC（Sim2Real Contract）**：带有效期、可失效、可重签发的迁移契约。
>

### IP-121 RGF

```python
def profile_gap_field(policy, sim, real, states, W):
    g = {}
    for x in states:
        a = policy(x)
        o_s, o_r = sim.rollout(x, a), real.rollout(x, a)
        g[x] = (
            obs_metric(phi(o_r), phi(o_s)),          # perception
            dyn_metric(sim.f(x,a), real.f(x,a)),      # dynamics
            actuation_diff(sim, real, a),             # actuation
            contact_diff(sim, real, x, a),            # contact
        )
    return GapField(task_project(g, W),
                    attribution=ablate_components(g),
                    stream=paired_replay(g))
```

### IP-122 DRC

```python
def contraction_certificate(e_pairs, alpha=0.05, B=2000):
    kappa = robust_regress_slope(e_pairs)          # e_next ~ kappa*e_t
    boots = [robust_regress_slope(resample(e_pairs)) for _ in range(B)]
    kappa_U = quantile(boots, 1-alpha)
    b_U = quantile([max(resid(p)) for p in boots], 1-alpha)
    if kappa_U >= 1.0:
        return ('reject', 'non_contractive', kappa_U)
    return ('ok', K_cert(kappa_U, b_U, len(e_pairs), 1-alpha))
```

### IP-123 HCH

```python
def certify_horizon(gap_stream, K_cert, eps, delta, anchor_policy):
    M, e, H_cert = EProcess(lam=choose_lambda(K_cert.b_U)), 0.0, 0
    for t in range(1, H_max + 1):
        M.update(gap_stream.observe(t))
        if not M.within(1 - delta):                # Ville: P(∃t 越界) ≤ delta
            break
        b_hat = max(K_cert.b_U, M.upper_mean())
        e = K_cert.kappa_U * e + b_hat
        if t in anchor_policy.times:
            e = K_cert.kappa_a * e + K_cert.nu
        if e > eps:
            break
        H_cert = t
    return H_cert, M.audit_trail()
```

### IP-124 RBL

```python
def allocate_budget(T, skill_certs, eps_total, delta_total):
    alloc = {}
    for path in critical_paths(T):
        alloc[path] = water_fill(
            path, eps_total,
            key=lambda i: skill_certs[i].sens / (1 - skill_certs[i].kappa))
        if sum(alloc[path].values()) > eps_total:
            return ('infeasible', 'eps', path)
        if sum(skill_certs[i].delta for i in path) > delta_total:
            return ('infeasible', 'delta', path)
    return ('ok', L_budget(alloc))
```

### IP-125 OAP

```python
def place_anchors(gap_field, K_cert, eps, budget, anchor_types):
    dp = {(0, 0): 0.0}                              # (t, cost) -> min error
    best = (0, None)
    for t in range(1, H_max + 1):
        nxt = {}
        for (_, b0), e in dp.items():
            for typ in anchor_types:                # 含 "无锚点"
                c = typ.cost
                if b0 + c > budget:
                    continue
                e2 = K_cert.kappa_U * e + gap_field[t]
                if typ.is_anchor:
                    e2 = K_cert.kappa_a * e2 + typ.nu
                key = (t, b0 + c)
                if e2 < nxt.get(key, inf):
                    nxt[key] = e2
                    if e2 <= eps:
                        best = max(best, (t, (b0 + c, typ)))
        dp = nxt
    return best                                   # 迁移信用最大的可行锚点序列
```

### IP-126 SRC

```python
def issue_SRC(policy, task, sim, real, anchors, delta=0.05):
    g_hat = profile_gap_field(policy, sim, real, anchors.states, W)
    K = contraction_certificate(paired_rollouts(policy, sim, real))
    if K.status == 'reject':
        return ('reject', 'non_contractive', K.kappa_U)
    H = certify_horizon(g_hat.stream, K, task.eps, delta, anchors.policy)
    D_cov = weighted_conformal_coverage(anchors.calib, task.dist)
    if D_cov < theta_dom:
        return ('reject', 'domain_coverage', D_cov)
    if H < task.H_req:
        return ('reject', 'horizon_too_short', (H, task.H_req))
    return ('ok', SRC(H, task.eps, delta, K, anchors.policy, g_hat, D_cov,
                      evidence=[g_hat.audit, K.audit, anchors.log]))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| RGF | O(|X|·(c_sim+c_real)) | O(|X|·4) | 配对采样 + 任务投影 |
| DRC | O(n·B) | O(n) | bootstrap 上界覆盖 `κ_U` |
| HCH | O(H) | O(1) | e-process anytime-valid，Ville 界 |
| RBL | O(|P|·|budget|²) | O(|P|·|budget|) | 预算单调、并集界 |
| OAP | O(H·B·|types|) | O(H·B) | 误差递推精确、成本可加 |
| SRC | O(RGF+DRC+HCH+conformal) | O(H+|X|) | 三条件联动、契约到期失效 |

**正确性定理（Horizon-Certified Sim2Real Transfer Soundness）**
假设第 54 轮 (A26)–(A28) 成立，并新增：
**(A29)** `||g_t||_W ≤ b` 且 anytime-valid 序列在 `1-δ` 下给出 `b_U`；
**(A30)** 闭环收缩 `κ_U<1` 由配对 rollout 在 `1-δ` 下验证；
**(A31)** 锚点重置 `e^+ ≤ κ_a e + ν`，`κ_a<1`；
**(A32)** 真实任务分布落在加权 conformal 校准支撑内（`D_cov≥θ_dom`）。

则对锚点间隔 `m`：
```
e_{t+m} ≤ κ_U^m e_t + b_U(1-κ_U^m)/(1-κ_U) ≤ b_U/(1-κ_U)
sup_t e_t ≤ b_U/(1-κ_U) + ν/(1-κ_a) =: B
```
存在未检测非平稳漂移时（起点 `t_s`、检测延迟 `τ_d`、增速 `β`）：
```
sup_t e_t ≤ B + β·(H - t_s - τ_d)_+
```
故 `H_req ≤ H_cert(ε,δ)` 时：
```
P(fail) ≤ δ + δ_shift + Σ_{i∈P} δ_i
```
关键：**收缩性把长程乘性复利转为有界误差**；**锚点 + anytime-valid 监控把「长程」变成可续期的有限契约**；**风险预算沿关键路径可加闭合**。

## 5. 本轮最大风险

**一句话**：把 sim-to-real 从标量验收升级为「间隙场 + 收缩证书 + 认证视界」使长程迁移第一次有了可续期的定量边界，但其 soundness **同时依赖间隙场采样的代表性、闭环收缩系数 `κ` 的无偏上界、以及真实分布不跳出 conformal 校准支撑**；一旦真实世界发生缓慢非平稳漂移（磨损、光照、负载），`κ` 与覆盖度会同时失真，迁移契约可能在「看起来仍然有效」时被静默违反，故必须以 **anytime-valid 监控 + 漂移检测 + 契约到期强制重签发** 为硬护栏，宁可短视界频繁续期，也不签一张无法被真实世界审计的长程空头支票。
