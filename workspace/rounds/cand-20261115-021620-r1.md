# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「跌倒恢复」×「能耗优化」）

> R69 把「不确定」拆成 aleatoric 与 epistemic，并让系统学会看、问、触。但在 R69 的决策式里，所有代价仍被压缩成一个抽象的 `c(g)`：**能量从未作为状态变量进入安全论证**。系统不知道自己还剩多少可用的焦耳，不知道「站起来这一下」需要多大的峰值功率，也不知道「省着用」会把可恢复性本身吃掉。R68 的标定层能吸收传感器残差，却吸收不了电池内阻、温度与老化的乐观偏差；R69 的流似然能发现行为异常，却测不出一颗「电量显示 20%、实际已带不动起立脉冲」的电池。
>
> 本轮两个灵感正好补上这块：
> - **跌倒恢复**告诉我们：安全不是「永不跌倒」，而是「任何时刻都还买得起一次恢复」。恢复是一个**脉冲式能量事件**——能量够 ≠ 功率够；而且恢复能力会随着能耗优化被悄悄卖掉。
> - **能耗优化**告诉我们：能量的最优使用不是「越省越好」，而是「先锁死一笔恢复押金，再把活期花在最有价值的地方」。长时间保持站立本身耗能，**策略性卧倒/休息**可以是省能动作，但它必须是一笔**可撤销的承诺**：到期必须能站起来。
>
> 核心命题：**把能量提升为一等安全状态，建立「能量-可恢复性对偶」：用恢复储备托管（RRE）锁住一笔永不挪用的恢复押金；用能量-可恢复核（EVK）把剩余能量与峰值功率映射成可恢复域；用能量归一化 VoI（EVoI）给每一次看/问/触标上焦耳价；用战略休息（SRS）与受控降姿（CDP）赚取利息；用能量状态观测器（ESO）与储备演练（RRP）防止乐观偏差；用能量-行为双通道（FMA-E）识别被标定吸收的电池漂移。** 命名 **FALLBACK-RAS**（**F**all-**A**ware **L**ow-energy **L**edger with **B**udgeted **A**utonomy and **C**ertified **K**ernel）。
>
> 一句话定位：R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我还买得起一次站起来吗？现在省下的每一焦耳，会不会正好花掉我最后的恢复能力？**」——能量不只是成本，它还是安全本身的计价单位。

## 0. 直觉与动机

**0.0 范围声明（避免把「能耗优化」误解成又一个低层步态模块）**
本轮**不**重新发明低层能量最优步态/MPC/RL；低层控制器可以继续使用任何能量最优策略。FALLBACK 是**监督层**：它决定「留多少恢复押金、现在花多少活期、何时用一次信息动作、何时休息/降姿、何时必须把恢复当作唯一任务」。因此它的接口是预算、储备、模式与证书，而不是关节轨迹。这样新层与 R66–R69 的既有层是**正交叠加**，而不是并列替代。

**灵感 1（跌倒恢复 → 安全是「随时买得起一次恢复」）**
直觉：人踉跄时不会先问「我摔了吗」，而是先问「我还来不来得及迈这一步、撑这一下」。恢复能力不是无限资源：它需要力矩、行程、时间与冲击余量；而这些都要用能量买。更反直觉的是，**能量够并不等于功率够**——一颗低 SoC 或低温电池可能还有 200 Wh，却因为内阻升高而无法在 300 ms 内输出起立所需的 1.5 kW 脉冲。于是「剩余能量」与「可恢复性」之间不是一条单调直线，而是一个**二维可行域**：能量 × 峰值功率 × 热余量。
关键：把安全从「不跌倒」改写为「**保持在能量-可恢复核内**」；一旦出核，唯一合法的目标是受控降姿与可撤销的保护，而不是继续假装 nominal。

**灵感 2（能耗优化 → 恢复能力是一笔必须锁死的押金）**
直觉：银行不会把客户的押金拿去做高风险投资。机器人的能量也应分成两个账户：**恢复押金**（一旦需要跌倒恢复就必须可用）与**活期能量**（任务、信息、休息可以花）。R68 的 `λ_floor` 是「不确定就收紧」的标量版；本轮把它升级成**有物理单位的硬托管**：`E_disc = E_lo − E_res`，任务/信息/休息只能花 `E_disc`，恢复才能动 `E_res`。
关键：押金不是常数，而是当前状态、扰动管、电池不确定性的函数；**不确定性越宽，押金越高**。因此「做一次校准/演练」不仅能提高效率，还能**释放押金**——信息第一次有了以焦耳计的安全价值。

**灵感 3（能耗优化 → 站着也费电，策略性休息是可撤销的承诺）**
直觉：对双足/人形机器人，静态站立并不免费：踝/膝持续出力、陀螺仪与感知常开、关节摩擦与发热都在耗能。长时间待机时，「坐下/卧倒/四点支撑」可能比「站着」省一个数量级的功率。但躺下不是免费的：进入要能量，唤醒要能量，更关键的是——**你必须证明自己在任何可能的唤醒时刻都还站得起来**。如果休息期间电池自放电、温度下降导致内阻升高，原本够用的押金可能变得不够。
关键：战略休息是一个**可撤销的承诺（reversible commitment）**：收益是 `(p_stand − p_rest)·T_idle`，代价是进入/退出能量与**唤醒失败风险**；只有在 `T_idle` 足够长、且 `∀t ≤ T_rest_max` 都满足唤醒时储备条件时，才允许进入。这样「省能」不再是短视的功耗优化，而是带到期履约条件的金融决策。

**灵感 4（跌倒恢复 → 受控降姿是能量最优动作，不是失败）**
直觉：当所有「站住」的轨迹都要付出一次高能量、高冲击的挣扎时，**主动、受控地降到低势能姿态**可能同时更省能、更少伤害、也更容易恢复。关键是把它和「失控跌倒」区分开：受控降姿是一个有认证的动作，带冲击上界、头颈净空、关节力矩上限与**降姿后的恢复可达性**；失控跌倒是失败，必须触发保护与求助。
关键：把「跌」建模成一笔**能量交易**：`总代价 = 降姿能量 + 冲击能量 + 后续恢复能量 + 伤害惩罚`。有时这笔交易比「硬撑」便宜；但只有在降姿后仍买得起恢复时，交易才合法。

**灵感 5（信息有焦耳价 → 能量归一化 VoI）**
直觉：R69 的 MINT 用「信息增益 − 物理/社会成本」选动作，但成本和收益不同量纲。真实系统里，一次注视要转头（能量+时间）、一次探针要动臂（能量+碰撞风险）、一次问句要走通信/语音（能量+社交）。如果电池只剩 30% 的活期，系统应该**自然地问得更少、看得更粗**，而不是继续按 nat 最大化的理想策略行动。
关键：引入**能量-信息汇率 `κ`（J/nat）**，把信息增益换成焦耳，与信息动作的真实能耗同币种比较。信息永远不能动用押金；这给出一个优雅的退化行为：电量越低，`E_disc` 越小，交互越少，但恢复能力始终不变。**储备演练**则是反向交易：花一点焦耳去降低押金的不确定性，从而释放更多活期。

**灵感 6（电池会漂移，且会被在线估计「标定吸收」→ 双通道第二意见）**
直觉：电池模型最危险的错误不是随机噪声，而是**乐观的慢漂移**：内阻随老化/低温上升、可用容量下降、电压回弹变慢。一个在线效率估计器可以把这些偏差吸收成「效率变低」，让稳态能耗预测看起来仍然自洽；但在需要恢复脉冲的那一刻，电压骤降会把「还有电」变成「带不动」。这与 R68 的「缓变故障被标定吸收」是同构的，只是观测通道从传感器残差换成了能量账本。
关键：稳态能量残差 `δE` 可以被效率参数吸收，但**峰值功率残差 `δP`** 不能——因为 `P_max ≈ V_oc²/(4R_int)` 由内阻与开路电压决定，不是标量效率能解释的。于是 `(δE, δP)` 构成一条**标定不可吸收**的联合判据；再用受控的储备演练直接测一次真实恢复能量，作为最终的第二意见。

**灵感 7（会休息/会求助就有新攻击面 → 能量安全威胁模型）**
直觉：一旦系统会「主动卧倒」「等待救援」「反复校准」，攻击者就有了新的杠杆：用无休止的提问/探询耗尽活期（能量 DoS）；伪造跌倒信号诱骗系统做昂贵的恢复；用「我马上来」让机器人在低势能休息中等待，错过真正的救援窗口；或观察机器人「变懒了」推断电量低、择时发动攻击（能量行为侧信道）。
关键：这些威胁不是加一个过滤器能解决的，而是要把**能量证据、救援证据、唤醒请求**都纳入证据纪律：单源不可定案、救援必须物理验证、休息必须对抗性唤醒约束、交互能量必须审计。

## 1. 形式化定义（增量：定义 310–328）

**定义 310（FALLBACK-RAS 总览与四不变式）** FALLBACK-RAS = (EVK, RRE, HMP, SRS, CDP, ESO, RRP, EVoI, IBG-E, FMA-E, AIC-FALL, VQAuditor-F, RAS-WM†)。四条不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **恢复押金硬锁**：任意 tick 满足 `E_lo(t) ≥ E_res(x_t)` 且 `P_lo(t) ≥ P_res(x_t)`（所有活期支出只能把 `E_lo` 花到 `E_res` 为止）；任务/信息/休息优化器无权分配押金；
(iii) **可恢复性不变式**：`x_t ∈ K_δ(E_lo, P_lo)`，否则必须进入经认证的受控降姿/保护性休息，且不得再宣称 nominal；
(iv) **能量账本闭合**：每一焦耳归属到明确科目（任务/信息/通信/恢复/冲击/再生/损耗），并由独立物理通道审计；信息与社交能量不得漏记。

**定义 311（混合模式自动机 HMP）** 模式 `M = {N 标称, P 预跌倒/制动, F 跌倒中, I 冲击, G 地面/恢复, R 战略休息}`。迁移关系 `→` 带守卫与驻留时间 `τ_dwell` 和双阈值迟滞：
- `N→R`：空闲预测满足休息收益、`R_lo ≥ R_min`、押金与唤醒储备均满足；
- `R→G→N`：收到经认证的唤醒请求，且唤醒时储备仍够、重新认证通过；
- `N→P`：跌倒风险超阈；`P→F`：恢复策略不可行；`F→I`：冲击不可避免；`I→G`：冲击结束；`G→N`：站立稳定且 `J_CALM` 重新有效。
任一迁移可采纳，当且仅当迁移后状态仍在 `K_δ` 内（或进入 `CDP` 的受保护子集），且不破坏押金不变式（恢复支取除外）。

**定义 312（能量账本与脉冲约束）** 对轨迹 `ξ_{0:H}`：
`E_cost(ξ) = E_act + E_comp + E_comm + E_loss − E_regen`，
其中 `E_act = ∫ Σ_i |τ_i q̇_i| dt`（保守机械功），`E_comp/E_comm` 为计算与通信，`E_regen ∈ [0, η_r E_kin]` 为再生回收，`E_loss` 为铜损/热损。另记：
`p_peak(ξ) = max_t v_b(t) i_b(t)`，`E_burst(ξ) = max_{|W|=τ_burst} ∫_W p dt`，`Q(ξ)=∫ i_b² R_int dt`。
账本 `L = (E_act, E_comp, E_comm, E_regen, E_loss, p_peak, E_burst, Q, δE_audit)`；所有安全判断使用账本的**保守下界**，而非模型点估计。

**定义 313（恢复能量/功率/热函数）** 对恢复策略 `π ∈ Π_rec`（含 `G` 内动作与 `R→G` 唤醒）：
`E_rec(x; π) = E[E_cost(ξ_{0:T_rec}) | x, π]`，`P_rec(x; π) = ess sup p_peak(ξ)`，`Q_rec(x; π) = ess sup Q(ξ)`。
认证最坏值定义为
`E_rec^wc(x) = min_{π∈Π_rec} max_{w∈𝒲, θ∈Θ_c} E_cost`，s.t. `P(success within T_rec) ≥ 1−δ_rec`、`damage ≤ D_max`；`P_rec^wc, Q_rec^wc` 同式。所有 `wc` 量以共形下/上界输出，并带区间宽度 `w_rec`。

**定义 314（能量-可恢复核与鲁棒裕度）** 给定可用能量下界 `E_u := E_lo`、峰值功率下界 `P_u := P_lo`、热余量 `Q_u`：
`K_δ(E_u, P_u, Q_u) = { x : E_rec^wc(x) ≤ E_u, P_rec^wc(x) ≤ P_u, Q_rec^wc(x) ≤ Q_u, P(success) ≥ 1−δ_rec, damage ≤ D_max }`。
在扰动集 `𝒲` 与接触不确定集 `Θ_c` 下定义鲁棒可达管 `Reach_Δ(x)`。能量裕度 `m_E(x) = E_u − max_{x'∈Reach_Δ(x)} E_rec^wc(x')`；`m_P, m_Q` 同理。控制目标保持 `m_E ≥ ε_E, m_P ≥ ε_P, m_Q ≥ ε_Q`；任一项跌破即进入 `P` 模式并准备 `CDP`。`K_δ` 用降阶模型（LIP/捕获点 + 能耗上界）+ 学习残差 + 共形修正实现，在线只查表/插值。

**定义 315（恢复储备托管 RRE）** 
`E_res(x) = max_{x'∈Reach_Δ(x)} E_rec^wc(x') + ε_E + κ_w·w_rec`，
`P_res(x) = max_{x'} P_rec^wc(x') + ε_P + κ_w·w_P`，`Q_res(x)` 同理。
活期能量 `E_disc(x) = max(0, E_lo(x) − E_res(x))`。
规则：任务、信息动作、休息进入只能花 `E_disc`；只有 `G` 模式下经认证的恢复动作可以支取 `E_res`，且支取后立即重算并冻结活期。`E_res` 对不确定性宽度单调不降；因此**缩小区间 = 释放押金**。

**定义 316（恢复就绪度与唤醒）** 休息姿态 `x_rest` 的就绪度：
`R_lo(x_rest) = P( ∃π∈Π_rec：E_rec^wc(x_rest)+E_wake ≤ E_lo(t_wake), P_rec^wc ≤ P_lo(t_wake), τ_wake ≤ τ_wake_max )`，取校准下界。
唤醒储备不变式：`∀t ∈ [0, T_rest_max]`，
`E_lo(t) − p_rest·t − E_wake(t) ≥ E_res(x_rest)` 且 `P_lo(t) ≥ P_res(x_rest)`，其中 `E_lo(t)` 计入自放电与温度模型；`T_rest_max` 是满足该式的最长休息时长。要求 `R_lo ≥ R_min` 且 `τ_wake` 的 p95 ≤ `τ_wake_max` 才允许进入或继续休息。

**定义 317（战略休息 SRS）** 休息动作 `r = (posture, T_rest)`，进入能量 `E_enter`、保持功率 `p_rest`、唤醒能量 `E_wake`、社交成本 `c_soc`。对空闲时长 `T_idle` 的生存函数 `S(t)`：
`ΔE_rest = ∫_0^{T_rest_max} S(t)(p_stand − p_rest) dt − E_enter − E_wake − c_soc`。
仅当 `ΔE_rest > 0`、`R_lo ≥ R_min`、`CVaR_β(wake failure) ≤ ε_w`、且无任务/人类安全期限时进入。对抗性唤醒下用最坏到达分布 `S_ad(t)=e^{−μt}` 替换 `S(t)`；阈值 `T*` 随 `μ` 单调上升（见引理 22）。

**定义 318（受控降姿/保护性下降 CDP）** 当 `P→F` 且 `N` 下恢复不可认证时，从 `r_cd ∈ {brace, squat, sit, roll, breakfall, protected_rest}` 中选择：
`r* = argmin_r [ E_desc(r) + E_impact(r) + E_rec^after(r) + λ_D·D(r) + λ_T·τ(r) + λ_R·1[恢复不可认证] ]`，
s.t. 头颈净空 ≥ `h_min`、关节力矩 ≤ `τ_inj`、峰值冲击 ≤ `F_max`、不朝向人类、降姿后状态 ∈ `K_δ`（或受保护休息子集且有唤醒路径）。受控降姿是**有认证的能量交易**，不是失败；失控跌倒仍触发保护与求助。

**定义 319（能量状态观测器 ESO）** 电池/热状态 `e = (SoC, R_int, T_b, T_m, θ_age, η)`。ESO 输出区间 `[e_lo, e_hi]`，覆盖率 ≥ `1−α`，用集员/约束滤波 + 库仑计数 + 热模型。独立审计通道给出：
`δE_t = |E_audit(t) − E_model(t)|`，`δP_t = |P_audit(t) − P_model(t)|`（在受控脉冲/演练窗口内测峰值能力）。
安全层只使用 `E_lo, P_lo`，绝不使用点估计；模型参数只在**经认证的演练**后更新，或做有界慢自适应（带漂移检测）。

**定义 320（恢复储备演练 RRP）** RRP 是一次受控、可中止的迷你恢复（如 `R→G→R` 或 `sit→stand→sit`），在安全环境下测量真实 `E_rec` 与 `P_rec`，从而缩小 `w_rec`。其代价 `E_rrp + risk_rrp + time_rrp`，收益为释放的押金与降低的失败概率：
`VoI_RRP = ΔE_res + λ_s·ΔP_fail − E_rrp − risk_rrp − λ_T·time_rrp`。
仅当 `VoI_RRP > 0`、预算允许、当前不在低押金状态且环境认证通过时执行；频率 ≤ `1/τ_rrp`。这是「花一点活期去验证押金」的元决策。

**定义 321（能量归一化 VoI / 能量-信息汇率）** 设信息增益 `ΔH(g) = H(M|o) − E_{y~p(·|g,o)}H(M|o,y)`。定义汇率 `κ`（J/nat）为「每减少 1 nat 模态不确定性，期望节省的恢复+任务能量」的单调上界 `κ_hi`（由历史 `(ΔH, ΔE_saved)` 对偶拟合上包络，或取保守常数）。信息动作评分：
`VoI_E(g) = κ_hi·ΔH(g) − c_E(g) − c_soc(g) − λ_s·ΔP_fail(g) − λ_T·τ(g)`，
s.t. `c_E(g) ≤ E_disc`（**永不动押金**）、`g` 过 C-RAS-WM 认证、预算未越界。选 `g* = argmax`；若 `VoI_E(g*) ≤ 0`，不交互，退化为 R69。R69 的 MINT 是 `κ` 取单位换算、`c_E(g)=c(g)` 的特例。

**定义 322（能量-信息联合预算 IBG-E）** 单位时间约束：
`E_info ≤ η_i E_disc`、`E_task ≤ η_t E_disc`、`E_rest ≤ η_r E_disc`，`Ση ≤ 1`；信息动作频率 ≤ `1/τ_int`；恢复支取押金必须持证。优先级为**恢复 > 安全保护 > 任务 > 信息 > 舒适性休息**（同层内按 `VoI_E` 排序）；当 `E_disc` 低于阈值时，先禁用信息，再降级任务，绝不降低押金。预算随 `E_lo, P_lo, Q_u` 动态重算，形成优雅降级。

**定义 323（能量-行为一致性 FMA-E）** 在 R69 的 `(r_res, Δa)` 通道之外，新增能量双通道 `(δE, δP)`：
- `δE` 可被在线效率/老化参数吸收（稳态共性偏差）；
- `δP` 由峰值脉冲测得，满足 `P_max ≈ V_oc²/(4R_int)`，**不能被标量效率吸收**。
判据：`δE` 低而 `δP` 高 ⇒ 电池模型乐观（内阻/低温/老化）；两者皆高 ⇒ 真实退化；两者皆低 ⇒ 一致。ESO 区间保证即使漏检，安全侧仍用下界；但若区间模型本身错了，则触发最高级风险（见第 6 节）。

**定义 324（能量安全威胁模型 AIC-FALL）** `ℰ_FALL = ℰ_FLUID × ℰ_energy × ℰ_contact × ℰ_rescue × ℰ_wake`：
- `ℰ_energy`：能量 DoS（反复提问/探询/请求校准耗尽活期）、诱导高能耗恢复、通过观察「变懒/变慢」推断电量的**行为侧信道**；
- `ℰ_contact`：伪造跌倒/滑移信号、用看似低成本但恢复昂贵的地形设陷；
- `ℰ_rescue`：虚假救援（「我马上来」）、社会工程劝阻求助、伪造「已安全」；
- `ℰ_wake`：在休息期间对抗性触发任务（伏击唤醒），造成唤醒脉冲失败或能量透支。
证据纪律：能量读数须独立审计；救援须物理验证（接近/接触/授权）；唤醒请求须认证；休息决策须对对抗到达鲁棒；单源救援永不释放押金。

**定义 325（参与式审计 VQAuditor-F）** 审计对象新增：押金是否被越权支取、账本是否闭合、休息进入/退出是否满足 `R_lo` 与 `T_rest_max`、演练是否值得、信息能耗是否漏记、虚假跌倒/救援、唤醒延迟、行为侧信道泄漏。审计结论异步回灌，成为 IBG-E 的成本先验与 ESO 的漂移证据；可撤销 `J_FALLBACK`。

**定义 326（证书 J_FALLBACK）** 
`J_FALLBACK = (J_FLUID, ledger_hash, E_res_min, m_P_min, m_Q_min, K_δ_ver, P_recover, rest_log, τ_wake_p95, ESO_interval, δE_p95, δP_p95, rrp_log, mode_trace_hash, fallback_ver)`。
Valid ⇔ `Valid(J_FLUID)` ∧ 押金不变式全程未破 ∧ `m_P,m_Q ≥ 0` ∧ 每次休息进入满足 `R_lo ≥ R_min` 且唤醒储备成立 ∧ 每次降姿有认证的后继恢复 ∧ 账本闭合 ∧ 审计通过。

**定义 327（对 R69/FLUID 的严格包含）** 当 `E_u → ∞`、`P_u → ∞`、无空闲休息收益（`p_stand = p_rest` 或 `T_idle = 0`）、无跌倒/冲击事件、ESO 精确且 `w_rec=0` 时：`E_res = 0`、`K_δ = 𝒳`、`SRS/CDP/HMP-R` 全部不激活、`EVoI` 退化为 R69 的 MINT。于是 FALLBACK **逐指令等价**于 FLUID-RAS；而当押金恰好只够恢复时，所有活期动作被禁用、系统只执行认证恢复——这是安全的边界行为。结合 R68 ⊂ FLUID，得到 **R68 ⊂ FLUID ⊂ FALLBACK** 的三级塔。

**定义 328（峰值-热 governor EPG）** 硬件级（≥500 Hz、不学习、只读）的电流/功率/温度守卫：`P_avail(t)` 取 ESO 下界；若 `P_res > P_avail`，则 (a) 若活期允许，执行**预充**（电容/弹簧/冷却）花 `E_pre` 在窗口内换取 `ΔP_pre`，或 (b) 收缩 `K_δ`，禁止进入需要该脉冲的状态。预充是一种「用能量买脉冲能力」的期权；EPG 拥有对 `HMP/CDP/SRS` 的抢占权。

## 2. 关键算法骨架

```python
# IP-264 EVK：能量-可恢复核（降阶模型 + 学习残差 + 共形下界）
class EnergyViabilityKernel:
    def __init__(self, rom, residual, conformal, grid):
        self.rom, self.res, self.cp, self.grid = rom, residual, conformal, grid

    def margins(self, x, e_lo, p_lo):
        tube = robust_reachable(self.rom, x, DELTA, W)          # 鲁棒可达管
        e_need = max(self.e_rec_wc(xp) for xp in tube) + EPS_E
        p_need = max(self.p_rec_wc(xp) for xp in tube) + EPS_P
        return e_need, p_need

    def inside(self, x, e_lo, p_lo):
        e_need, p_need = self.margins(x, e_lo, p_lo)
        return (e_lo >= e_need and p_lo >= p_need), e_need, p_need

# IP-265 RRE：恢复押金托管（安全账户，任务不得挪用）
def escrow(x, e_lo, p_lo, eso):
    e_need, p_need = evk.margins(x, e_lo, p_lo)
    e_res = e_need + KAPPA_W * eso.width_E + EPS_E
    p_res = p_need + KAPPA_W * eso.width_P + EPS_P
    return Escrow(e_res=e_res, p_res=p_res, e_disc=max(0.0, e_lo - e_res))

# IP-266 HMP：模式守卫（任何迁移都必须保持押金/可恢复性）
def next_mode(x, esc, fall_risk, task, now):
    if fall_risk > TAU_FALL:
        if certified_recovery(x, esc): return 'P'
        return 'F'                                            # 进入受控降姿流程
    if task.idle and not task.deadline and srs.admissible(x, esc, now):
        return 'R'
    return 'N'

# IP-267 SRS：战略休息（可撤销承诺 + 唤醒时储备）
def rest_plan(x, idle_dist, esc, ready):
    if ready.R_lo(x) < R_MIN: return None
    Tcap = ready.T_rest_max(x, esc)                           # ∀t≤Tcap 唤醒仍够
    if Tcap <= 0: return None
    dE = expected_saving(idle_dist, Tcap, p_stand, p_rest, E_enter, E_wake)
    if dE <= 0 or cvar(wake_fail, BETA) > EPS_W: return None
    return RestPlan(posture=choose_posture(x), T=Tcap)

# IP-268 CDP：受控降姿（有认证的能量交易，不是失败）
def choose_descent(x, esc):
    best = None
    for r in CDP_CANDIDATES:                                  # brace/squat/sit/roll/...
        if not cdp.preconditions(x, r): continue
        cost = (E_desc(r) + E_impact(r) + E_rec_after(r)
                + LAM_D * damage(r) + LAM_T * tau(r))
        if not cdp.certified_post_recovery(x, r, esc): cost += LAM_R
        if best is None or cost < best.cost: best = (r, cost)
    return best.r

# IP-269 ESO：区间观测 + 独立审计（安全只用下界）
def eso_step(eso, meas):
    eso.predict(meas.dt)
    eso.innovate_interval(meas)                               # 集员/约束滤波
    eso.dE = abs(meas.E_audit - eso.E_model)
    eso.dP = abs(meas.P_audit - eso.P_model)
    eso.drift = classify_drift(eso.dE, eso.dP)                # 乐观/老化/一致
    return eso

# IP-270 RRP：储备演练（用一点活期验证押金，换回押金松弛）
def maybe_rehearse(eso, esc, budget, now):
    if now - eso.last_rrp < TAU_RRP or not eso.safe_to_rehearse: return False
    gain = reduce_width(eso) * KAPPA_W + LAM_S * expected_fail_drop(eso)
    cost = eso.E_rehearsal + RISK_RRP + LAM_T * TIME_RRP
    if gain - cost <= 0 or not budget.allow_info(eso.E_rehearsal): return False
    return run_certified_mini_recovery()                      # R→G→R，可中止

# IP-271 EVoI：能量归一化信息价值（信息永不动押金）
def choose_info(modes, w, x, esc, budget):
    best = None
    for g in info_candidates(modes):                          # gaze/probe/ask
        if not budget.allow_info(g) or not c_ras_wm.certify_info(g, x): continue
        if g.energy > esc.e_disc: continue                    # 不得支取押金
        dH = entropy(w) - expected_entropy(w, g, x)
        score = (KAPPA_HI * dH - g.energy - g.social
                 - LAM_S * g.fail_delta - LAM_T * g.tau)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None          # None → 退化 R69

# IP-276 FALLBACK 主闭环（R69 的 FMP/AUD/CIA 保留；本层只改能量与模式）
def FALLBACK_round(M, obs):
    z, o = M.mtm.forward(...)                                 # R69 一次前向
    eso = M.eso.step(..., M.power.measure())
    esc = M.rre.escrow(..., eso.e_lo, eso.p_lo)
    ok, e_need, p_need = M.evk.inside(..., eso.e_lo, eso.p_lo)

    if not ok:                                                # 已买不起恢复
        r = M.cdp.choose_descent(..., esc)                    # 受控降姿/保护
        return M.hmp.execute(r, certified=False)

    mode = M.hmp.next_mode(..., esc, M.vista.fall_risk(...), M.task)
    if mode == 'R':                                           # 战略休息
        plan = M.srs.rest_plan(..., esc, M.ready)
        if plan is None: mode = 'N'

    samples = M.fmp.sample(o, K=M.fmp.adaptive_K(z))
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    g = M.evoi.choose_info(modes, ..., esc, M.budget) if mode == 'N' else None

    if g is not None:
        ans = M.cia.execute(g)
        U_epi = M.cia.update_belief(modes, ans)
    # 只有活期进入任务/信息/休息；恢复支取押金
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    if mode in ('P', 'F', 'I', 'G'):
        r = M.cdp.choose_descent(...) if mode in ('P', 'F') else M.recover(...)
        M.budget.spend_recovery(esc, r)                       # 唯一合法支取
    else:
        M.budget.spend_discretionary(esc, g, mode)            # 不得越界
    M.epg.guard(...)                                          # 峰值/热抢占
    M.vqa_f.submit_async(esc, eso, mode, g, r if 'r' in locals() else None)
    return M.hmp.commit(mode, ...)
```

## 3. 推导

除 R69 的 A95–A98 外，本轮新增假设：
- **A99（能量模型有界误差）**：降阶能量模型对真实 `E_cost` 的相对误差 ≤ `ε_model`，且共形区间覆盖真实值；
- **A100（扰动/接触有界）**：`𝒲, Θ_c` 有界且已知；OOD 触发时 `K_δ := ∅`，直接进入保护性降姿；
- **A101（恢复策略类可认证）**：`Π_rec` 有限且每个策略可被 C-RAS-WM† 前缀认证；演练在安全环境下可中止。

**引理 19（能量-捕获域的平方根标度，以及安全裕度的二次代价）**
在点质量/固定时长降阶模型下，用最大力 `F` 在 `T_rec` 内消除速度扰动，捕获半径 `ρ` 与能量 `E` 满足
`ρ ≤ (T_rec/2)·√(2E/m)`，等价地 `E ≥ 2mρ²/T_rec²`。
故水平可恢复域随 `√E` 扩张，而**恢复能量随安全半径平方增长**；竖直起身还额外需要 `E ≥ m g Δh_com/η_act` 与冲击损耗。
系：把安全裕度加倍需要约四倍恢复能量——这解释了为什么一个只按「每焦耳收益」优化的策略会系统性卖掉恢复能力；因此押金必须**硬锁**，不能交给同一个优化器（RRE 的理论依据）。

**引理 20（押金不变式 ⇒ 可恢复性）**
若 `∀t` 有 `E_lo(t) ≥ E_res(x_t)`、`P_lo(t) ≥ P_res(x_t)`，ESO 区间以概率 ≥ `1−α` 覆盖真实能量/功率，且 `x_t` 的鲁棒可达管被 `Reach_Δ` 覆盖，则从 `x_t` 出发存在认证恢复策略，其成功率 ≥ `1−δ_rec−α`，峰值功率不超过 `P_lo`，且伤害 ≤ `D_max`。
证明：由 `K_δ` 定义与 `E_res` 取可达管上最坏值，任意扰动后的状态都仍有足够 `E/P`；对区间覆盖与恢复成功率用联合界。系：押金不变式把「能量优化」与「恢复安全」解耦——前者只能影响 `E_disc`，不能影响 `E_res`。

**引理 21（能量归一化 VoI 的阈值与优雅降级）**
在 `κ_hi` 为上界、信息不支取押金的约束下，若 `κ_hi·ΔH(g) ≤ c_E(g)+c_soc(g)+λ_s·ΔP_fail+λ_T·τ`，则不交互是能量最优；否则贪心选择最大化期望能量调整收益的下界。由于 `E_disc` 随 `E_lo` 单调下降，**最优交互频率随剩余活期单调不增**，而押金不变式保证恢复能力不随交互减少而下降。
系：能量 DoS 的效果被 `IBG-E` 限制为「减少信息/任务」，不能击穿恢复安全；这与 R69 的「交互预算」是同一纪律的能量版。

**引理 22（战略休息的阈值与对抗唤醒）**
给定空闲生存函数 `S(t)`、站立/休息功率 `p_s, p_r`、进入/唤醒能量 `E_e, E_w`，休息优于站立当且仅当
`∫_0^{T_rest_max} S(t)(p_s−p_r) dt > E_e + E_w + c_soc`。
若空闲到达是速率 `μ` 的对抗过程，`S_ad(t)=e^{−μt}`，则阈值 `T*(μ)` 随 `μ` 单调上升；在误判下休息的后悔值不超过 `E_e+E_w+p_r T_rest_max`。若 `∀t≤T_rest_max` 的唤醒储备成立，唤醒失败概率 ≤ `α`。
系：**休息不是「越久越省」**；收益被 `T_rest_max`（电池/温度/储备）与对抗到达率共同截断，因此 SRS 必须把「到期能否醒来」作为硬约束。

**引理 23（ESO 双通道的标定不可吸收性）**
设电池端电压 `v = OCV(SoC) − I·R_int`，峰值能力 `P_max ≈ V_oc²/(4R_int)`（或受 `I_max` 限制）。稳态效率偏差可把 `δE` 吸收进效率参数，但 `δP` 在受控脉冲下满足
`δP ≥ c·|R_int^true − R_int^model|·I_pulse² − noise`，
与标量效率无关。故 `(δE 低, δP 高)` 是「乐观电池模型/内阻漂移」的判别性联合模式；`(δE 高, δP 高)` 指示真实老化。押金使用区间下界，因此未检测到的漂移首先表现为押金变宽（效率损失），而不是直接的安全违约——除非区间模型本身失效（第 6 节）。

**定理 18（FALLBACK 严格包含 FLUID，安全侧不让步）**
在 A95–A101 下：
(1) 当 `E_u,P_u → ∞`、无休息收益、无跌倒/冲击、ESO 精确且 `w_rec=0` 时，`E_res=0`、`K_δ=𝒳`、`SRS/CDP/HMP-R` 不激活、`EVoI=MINT`，FALLBACK 与 FLUID **逐指令相同**；
(2) 一般情况下，FALLBACK 的期望风险 ≤ FLUID（押金不变式给恢复安全，`CDP` 只在认证后执行）；
(3) 在相同的任务成功率与安全约束下，凡 FALLBACK 采用经认证且 `ΔE_rest>0`（或 `VoI_E>0`）的休息/信息动作，其期望总能量 ≤ FLUID 的对应可行策略；若 FLUID 在跌倒链中已不可行，FALLBACK 以认证降姿取得有界伤害，而不是与 FLUID 做无意义的能量比较。
故 R68 ⊂ FLUID ⊂ FALLBACK，且新增层在安全侧是**严格的保护性扩展**，不是并列替代。

**定理 19（混合模式安全与单调退化）**
在认证迁移与押金不变式下，HMP 不会进入未认证的不可恢复状态；若外部扰动使 `x_t ∉ K_δ`，系统只能进入 `CDP` 的受保护子集（或保护性休息 + 求助），且该子集仍满足伤害/峰值/头颈约束；若认证失败，系统选择最小伤害的受保护动作并撤销 `J_FALLBACK`，**退化方向单调**：不确定性↑ ⇒ 押金↑、活期↓、信息/任务↓，绝不出现「不确定性↑ 而恢复储备↓」。
证明：对迁移逐条检查守卫；由 `E_res` 对 `Reach_Δ` 与 `w_rec` 的单调性、`CDP` 的伤害上界、以及 `IBG-E` 的优先级得到。

**命题 1（能量账本的可审计性）**
若独立审计通道（库仑计数、母线电压/电流、热流、机械功）不与策略模型共谋，则任何被策略宣称的节能必须落到至少一个账本科目；未被解释的 `δE` 只能来自模型误差或漏记，且被 `VQAuditor-F` 标记。故「通过少记信息能耗/再生能量来伪造节能」在审计下不可持续。

## 6. 本轮最大风险

**次级风险与缓解**：
1. **乐观押金**（最大风险的直接形态）→ ESO 区间下界 + 独立库仑/热审计 + `(δE,δP)` 双通道 + 定期 RRP；宁可押金偏大，不可偏小。
2. **战略休息变成陷阱**（自放电/降温/对抗唤醒）→ `T_rest_max` + 唤醒时储备不变式 + `R_lo` 校准 + 对抗到达的 CVaR 约束。
3. **能量够但功率不够**→ 二维 `(E,P)` 押金 + EPG 预充/缩核；绝不把 SoC 当唯一安全指标。
4. **能量-信息汇率 `κ` 失准**→ 用 `κ_hi` 保守上界 + 审计回灌 + 低电量时自动降低交互，不让错误定价驱动高风险探询。
5. **受控降姿伤人/伤己**→ 冲击/头颈/关节硬约束 + 不朝向人类 + 假人/护栏测试 + 只在认证后执行。
6. **休息的社会接受度**（公共场景躺下）→ 社交成本 `c_soc` + 场景白名单 + 人类安全期限；不允许在有人依赖时休息。
7. **账本被侧信道利用**（行为泄露电量）→ 交互/速度与押金解耦、审计侧信道、必要时随机化行为节奏。

**一句话最大风险**：FALLBACK 的全部安全性都押在「恢复押金 `E_res` 的估计是保守且可信的」这一前提上，而这份估计在第一次真正需要恢复之前无法被完整检验——**如果 EVK/ESO 对电池老化、低温内阻或接触地形做了乐观外推，能耗优化会合法地花掉本应留给恢复的能量，战略休息则把这种乐观变成长期空头；第一次真实跌倒就是第一次压力测试，而它可能没有第二次机会。**

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** FALLBACK-RAS 由 13 个组件构成；四不变式：(i) 实时流零学习写操作（继承 R69 293-i）；(ii) **恢复押金硬锁**：`E_lo ≥ E_res` 且 `P_lo ≥ P_res`（活期支出不得把 `E_lo` 花到 `E_res` 以下），任务/信息/休息无权分配押金；(iii) **可恢复性**：`x_t ∈ K_δ`，否则只能进入认证的受控降姿/保护性休息且不得宣称 nominal；(iv) **账本闭合**：每焦耳归属明确科目并由独立物理通道审计。

**定义 311（HMP 混合模式）** `M={N,P,F,I,G,R}`（标称/预跌倒/跌倒/冲击/地面恢复/战略休息）。迁移带守卫、双阈值迟滞与驻留 `τ_dwell`；`N→R` 需休息收益、`R_lo≥R_min` 与唤醒储备；`R→G→N` 需认证唤醒与重新认证；`N→P→F→I→G→N` 为跌倒—恢复链。任何迁移后状态须在 `K_δ` 或 `CDP` 受保护子集内。

**定义 312（能量账本）** `E_cost = E_act+E_comp+E_comm+E_loss−E_regen`，`E_act=∫Σ|τ_i q̇_i|dt`；另记 `p_peak=max v_b i_b`、`E_burst`（`τ_burst` 窗内峰值能量）、`Q=∫i_b²R_int dt`。安全判断只用账本保守下界。

**定义 313（恢复能量/功率/热）** `E_rec^wc(x)=min_{π∈Π_rec} max_{w,θ} E_cost`，s.t. 成功率 `≥1−δ_rec`、伤害 `≤D_max`；`P_rec^wc,Q_rec^wc` 同式；全部带共形区间宽度 `w_rec`。

**定义 314（EVK 与裕度）** `K_δ={x: E_rec^wc≤E_u, P_rec^wc≤P_u, Q_rec^wc≤Q_u, 成功率≥1−δ_rec, 伤害≤D_max}`（`E_u:=E_lo, P_u:=P_lo`）。`m_E(x)=E_u−max_{x'∈Reach_Δ}E_rec^wc(x')`，`m_P,m_Q` 同理；要求 `m_E≥ε_E, m_P≥ε_P, m_Q≥ε_Q`。在线用降阶模型 + 残差 + 共形修正。

**定义 315（RRE 押金托管）** `E_res = max_{x'∈Reach_Δ}E_rec^wc(x')+ε_E+κ_w·w_rec`，`P_res` 同理，`Q_res` 同理；`E_disc=max(0,E_lo−E_res)`。只有 `G` 内经认证的恢复可支取押金，支取后立即重算并冻结活期。**`E_res` 对不确定性宽度单调不降 ⇒ 缩小区间 = 释放押金。**

**定义 316（就绪度与唤醒）** `R_lo(x_rest)=P(∃π: E_rec^wc+E_wake≤E_lo(t), P_rec^wc≤P_lo(t), τ_wake≤τ_wake_max)` 的校准下界。唤醒储备不变式：`∀t≤T_rest_max`，`E_lo(t)−p_rest t−E_wake(t)≥E_res(x_rest)` 且 `P_lo(t)≥P_res(x_rest)`；`T_rest_max` 为满足该式的最长时长。要求 `R_lo≥R_min`、`τ_wake` 的 p95 `≤τ_wake_max`。

**定义 317（SRS 战略休息）** 对空闲生存函数 `S(t)`：`ΔE_rest=∫_0^{T_rest_max}S(t)(p_stand−p_rest)dt−E_enter−E_wake−c_soc`。仅当 `ΔE_rest>0`、`R_lo≥R_min`、`CVaR_β(wake failure)≤ε_w` 且无任务/人类安全期限时休息；对抗到达用 `S_ad(t)=e^{−μt}`，阈值 `T*(μ)` 随 `μ` 单调上升。

**定义 318（CDP 受控降姿）** `r*=argmin_r[E_desc+E_impact+E_rec^after+λ_D D(r)+λ_T τ(r)+λ_R·1(恢复不可认证)]`，s.t. 头颈净空、关节力矩、峰值冲击、不朝向人类、降姿后 ∈ `K_δ`。受控降姿是**有认证的能量交易**，不是失败；失控跌倒触发保护与求助。

**定义 319（ESO）** 电池/热状态 `e=(SoC,R_int,T_b,T_m,θ_age,η)`；区间观测 `[e_lo,e_hi]` 覆盖率 `≥1−α`；独立审计给出 `δE=|E_audit−E_model|`、`δP=|P_audit−P_model|`（受控脉冲窗口）。安全只用 `E_lo,P_lo`；模型参数只在认证演练后更新或有界慢自适应。

**定义 320（RRP 演练）** 受控、可中止的迷你恢复（`R→G→R` / `sit→stand→sit`）实测 `E_rec,P_rec`，缩小 `w_rec`。`VoI_RRP=ΔE_res+λ_s·ΔP_fail−E_rrp−risk_rrp−λ_T·time_rrp`；仅当 `>0`、预算允许、非低押金、环境认证通过时执行，频率 `≤1/τ_rrp`。

**定义 321（EVoI 能量归一化信息价值）** `ΔH(g)=H(M|o)−E[H(M|o,y)]`；`κ_hi` 为「每 nat 不确定性可省能量」的保守上界（历史 `(ΔH,ΔE_saved)` 上包络）。`VoI_E(g)=κ_hi·ΔH(g)−c_E(g)−c_soc(g)−λ_s·ΔP_fail−λ_T·τ(g)`，s.t. `c_E(g)≤E_disc`（**永不动押金**）、过 C-RAS-WM 认证、预算未越界。选 `g*=argmax`；`≤0` 则不交互，退化为 R69。MINT 是 `κ` 取单位换算、`c_E=c` 的特例。

**定义 322（IBG-E 联合预算）** `E_info≤η_i E_disc`、`E_task≤η_t E_disc`、`E_rest≤η_r E_disc`、`Ση≤1`；信息频率 `≤1/τ_int`；恢复支取押金须持证。优先级：**恢复 > 安全保护 > 任务 > 信息 > 舒适性休息**；`E_disc` 低于阈值时先禁信息、再降任务，绝不降低押金 ⇒ 优雅降级。

**定义 323（FMA-E 双通道）** 除 R69 的 `(r_res,Δa)` 外，新增 `(δE,δP)`：`δE` 可被效率/老化参数吸收；`δP` 由峰值脉冲测得，`P_max≈V_oc²/(4R_int)`，**不能被标量效率吸收**。`(δE低,δP高)` ⇒ 乐观电池模型；`(δE高,δP高)` ⇒ 真实退化；两者皆低 ⇒ 一致。押金用区间下界，漏检首先表现为押金变宽。

**定义 324（AIC-FALL 威胁模型）** `ℰ_FALL=ℰ_FLUID×ℰ_energy×ℰ_contact×ℰ_rescue×ℰ_wake`：能量 DoS（反复探询/校准耗活期、行为侧信道推断电量）、伪造跌倒/滑移、虚假救援（「我马上来」）、休息中对抗唤醒。证据纪律：能量须独立审计、救援须物理验证、唤醒须认证、单源救援永不释放押金。

**定义 325（VQAuditor-F）** 审计押金越权、账本闭合、休息进入/退出、演练收益、信息能耗漏记、假跌倒/假救援、唤醒延迟、行为侧信道；结论异步回灌 IBG-E/ESO，可撤销证书。

**定义 326（J_FALLBACK）** `(J_FLUID, ledger_hash, E_res_min, m_P_min, m_Q_min, K_δ_ver, P_recover, rest_log, τ_wake_p95, ESO_interval, δE_p95, δP_p95, rrp_log, mode_trace_hash, fallback_ver)`。Valid ⇔ `Valid(J_FLUID)` ∧ 押金不变式全程未破 ∧ `m_P,m_Q≥0` ∧ 每次休息满足 `R_lo≥R_min` 与唤醒储备 ∧ 每次降姿有认证后继恢复 ∧ 账本闭合 ∧ 审计通过。

**定义 327（严格包含 FLUID）** 当 `E_u,P_u→∞`、无休息收益、无跌倒/冲击、ESO 精确且 `w_rec=0` 时：`E_res=0`、`K_δ=𝒳`、`SRS/CDP/HMP-R` 不激活、`EVoI=MINT`，FALLBACK 与 FLUID **逐指令相同**。当押金恰好只够恢复时，所有活期动作被禁用、只执行认证恢复——安全边界行为。故 **R68 ⊂ FLUID ⊂ FALLBACK**。

**定义 328（EPG 峰值-热 governor）** 硬件级（≥500Hz、不学习、只读）守卫：`P_avail` 取 ESO 下界；若 `P_res>P_avail`，则 (a) 用活期**预充**（电容/弹簧/冷却）花 `E_pre` 换窗口内 `ΔP_pre`，或 (b) 收缩 `K_δ` 禁止进入需要该脉冲的状态。预充是「用能量买脉冲能力」的期权；EPG 对 HMP/CDP/SRS 有抢占权。

## 3. 关键算法（节选）

```python
# IP-264/265：EVK + RRE（押金先行，任务只用活期）
def reserve_and_discretionary(x, e_lo, p_lo, eso):
    tube = robust_reachable(rom, x, DELTA, W)
    e_need = max(e_rec_wc(xp) for xp in tube) + EPS_E
    p_need = max(p_rec_wc(xp) for xp in tube) + EPS_P
    e_res = e_need + KAPPA_W * eso.width_E
    p_res = p_need + KAPPA_W * eso.width_P
    return Escrow(e_res=e_res, p_res=p_res, e_disc=max(0.0, e_lo - e_res))

# IP-267：SRS（可撤销承诺；唤醒时储备仍够才允许休息）
def rest_plan(x, idle_dist, esc, ready):
    if ready.R_lo(x) < R_MIN: return None
    Tcap = ready.T_rest_max(x, esc)                  # ∀t≤Tcap 唤醒仍够
    dE = expected_saving(idle_dist, Tcap, p_stand, p_rest, E_enter, E_wake)
    if dE <= 0 or cvar(wake_fail, BETA) > EPS_W: return None
    return RestPlan(posture=choose_posture(x), T=Tcap)

# IP-268：CDP（受控降姿 = 有认证的能量交易）
def choose_descent(x, esc):
    best = None
    for r in CDP_CANDIDATES:
        if not cdp.preconditions(x, r): continue
        c = E_desc(r)+E_impact(r)+E_rec_after(r)+LAM_D*damage(r)+LAM_T*tau(r)
        if not cdp.certified_post_recovery(x, r, esc): c += LAM_R
        if best is None or c < best.cost: best = (r, c)
    return best.r

# IP-271：EVoI（信息永不动押金；无利可图即退化 R69）
def choose_info(modes, w, x, esc, budget):
    best = None
    for g in info_candidates(modes):
        if not budget.allow_info(g) or not c_ras_wm.certify_info(g, x): continue
        if g.energy > esc.e_disc: continue
        dH = entropy(w) - expected_entropy(w, g, x)
        score = KAPPA_HI*dH - g.energy - g.social - LAM_S*g.fail_delta - LAM_T*g.tau
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None

# IP-276：主闭环（R69 的 FMP/AUD/CIA 保留；本层只改能量与模式）
def FALLBACK_round(M, obs):
    z, o = M.mtm.forward(...)
    eso = M.eso.step(..., M.power.measure())
    esc = reserve_and_discretionary(..., eso.e_lo, eso.p_lo, eso)
    ok = (eso.e_lo >= esc.e_res) and (eso.p_lo >= esc.p_res)
    if not ok: return M.hmp.execute(M.cdp.choose_descent(..., esc), certified=False)
    mode = M.hmp.next_mode(..., esc, M.vista.fall_risk(...), M.task)
    if mode == 'R' and M.srs.rest_plan(..., esc, M.ready) is None: mode = 'N'
    samples = M.fmp.sample(o, K=M.fmp.adaptive_K(z))
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    g = M.evoi.choose_info(modes, ..., esc, M.budget) if mode == 'N' else None
    if g is not None: U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    if mode in ('P','F','I','G'): M.budget.spend_recovery(esc, ...)   # 唯一合法支取
    else:                         M.budget.spend_discretionary(esc, g, mode)
    M.epg.guard(...)                                                   # 峰值/热抢占
    M.vqa_f.submit_async(esc, eso, mode, g)
    return M.hmp.commit(mode, ...)
```

## 4. 推导

除 A95–A98 外新增：**A99** 降阶能量模型相对误差 ≤`ε_model` 且共形区间覆盖；**A100** 扰动/接触有界，OOD 时 `K_δ:=∅` 直接保护性降姿；**A101** `Π_rec` 可认证且演练可中止。

**引理 19（能量-捕获域平方根标度 + 安全裕度二次代价）**
点质量/固定时长模型：`ρ ≤ (T_rec/2)√(2E/m)` ⇔ `E ≥ 2mρ²/T_rec²`。故水平可恢复域随 `√E` 扩张，而恢复能量随安全半径**平方**增长；竖直起身另有 `E ≥ m g Δh_com/η_act` 与冲击损耗。
系：安全裕度加倍约需四倍恢复能量——按「每焦耳收益」优化的策略会系统性卖掉恢复能力，因此押金必须硬锁（RRE 的理论依据）。

**引理 20（押金不变式 ⇒ 可恢复性）**
若 `∀t`：`E_lo≥E_res(x_t)`、`P_lo≥P_res(x_t)`，ESO 区间以概率 `≥1−α` 覆盖真值，且 `Reach_Δ` 覆盖鲁棒可达管，则存在认证恢复策略，成功率 `≥1−δ_rec−α`、峰值功率 `≤P_lo`、伤害 `≤D_max`。
系：押金不变式把「能量优化」与「恢复安全」解耦——前者只能影响 `E_disc`，不能影响 `E_res`。

**引理 21（EVoI 阈值与优雅降级）**
在 `κ_hi` 为上界、信息不支取押金下，若 `κ_hi·ΔH ≤ c_E+c_soc+λ_sΔP_fail+λ_Tτ`，则不交互为能量最优；否则贪心最大化能量调整收益下界。`E_disc` 随 `E_lo` 单调下降 ⇒ **最优交互频率随活期单调不增**，而押金不变式保证恢复能力不降。
系：能量 DoS 只能减少信息/任务，不能击穿恢复安全——R69 交互预算的能量版。

**引理 22（战略休息阈值与对抗唤醒）**
休息优于站立 iff `∫_0^{T_rest_max}S(t)(p_s−p_r)dt > E_e+E_w+c_soc`。对抗到达 `S_ad(t)=e^{−μt}` ⇒ 阈值 `T*(μ)` 随 `μ` 单调上升；误判后悔值 `≤E_e+E_w+p_r T_rest_max`。若 `∀t≤T_rest_max` 唤醒储备成立，唤醒失败概率 `≤α`。
系：休息不是「越久越省」，收益被 `T_rest_max` 与对抗到达率截断。

**引理 23（ESO 双通道标定不可吸收性）**
`v=OCV(SoC)−I·R_int`，`P_max≈V_oc²/(4R_int)`（或受 `I_max` 限制）。稳态效率偏差可吸收 `δE`，但受控脉冲下 `δP ≥ c·|R_int^true−R_int^model|·I_pulse²−noise`，与标量效率无关。故 `(δE低,δP高)` 判乐观电池模型，`(δE高,δP高)` 判真实老化；押金用区间下界，漏检先表现为押金变宽。

**定理 18（FALLBACK 严格包含 FLUID）**
(1) `E_u,P_u→∞`、无休息收益、无跌倒/冲击、ESO 精确且 `w_rec=0` 时，`E_res=0`、`K_δ=𝒳`、SRS/CDP/HMP-R 不激活、EVoI=MINT，FALLBACK 与 FLUID 逐指令相同；(2) 一般情况下期望风险 ≤ FLUID（押金给恢复安全，CDP 只在认证后执行）；(3) 在相同任务成功率与安全约束下，凡采用经认证且收益为正的休息/信息动作，期望总能量 ≤ FLUID 对应可行策略；若 FLUID 在跌倒链中不可行，FALLBACK 以认证降姿取得有界伤害，而不做无意义的能量比较。故 **R68 ⊂ FLUID ⊂ FALLBACK**，新层是保护性扩展而非并列替代。

**定理 19（混合模式安全与单调退化）**
认证迁移 + 押金不变式下，HMP 不会进入未认证的不可恢复状态；若 `x_t∉K_δ`，只能进入 CDP 受保护子集（或保护性休息 + 求助），仍满足伤害/峰值/头颈约束；认证失败则选最小伤害动作并撤销 `J_FALLBACK`。退化方向单调：不确定性↑ ⇒ 押金↑、活期↓、信息/任务↓，绝不出现「不确定性↑ 而恢复储备↓」。

**命题 1（能量账本可审计性）**
独立审计通道（库仑计数、母线 V/I、热流、机械功）不与策略模型共谋时，任何宣称的节能必须落到至少一个账本科目；未解释的 `δE` 只能来自模型误差或漏记，并被 `VQAuditor-F` 标记。故「少记信息/再生能量来伪造节能」不可持续。

## 7. 本轮最大风险

**次级风险与缓解**：乐观押金 → ESO 区间下界 + 独立库仑/热审计 + `(δE,δP)` 双通道 + 定期 RRP；休息陷阱 → `T_rest_max` + 唤醒时储备 + 对抗到达 CVaR；能量够功率不够 → 二维 `(E,P)` 押金 + EPG 预充/缩核；`κ` 失准 → `κ_hi` 保守上界 + 审计回灌 + 低电量自动少问；降姿伤人 → 冲击/头颈/关节硬约束 + 不朝向人类 + 假人测试；社交不可接受 → `c_soc` + 场景白名单 + 人类安全期限；行为侧信道 → 交互/速度与押金解耦 + 审计。

**一句话最大风险**：FALLBACK 的全部安全性都押在「恢复押金 `E_res` 的估计保守且可信」这一前提上，而这份估计在第一次真正需要恢复前无法被完整检验——**若 EVK/ESO 对电池老化、低温内阻或接触地形做了乐观外推，能耗优化会合法地花掉本应留给恢复的能量，战略休息把这种乐观变成长期空头；第一次真实跌倒就是第一次压力测试，而它可能没有第二次机会。**
