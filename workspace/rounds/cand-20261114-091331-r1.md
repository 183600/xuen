# 第 73 轮（承接第 72 轮「EMBODIED-GAUGE-RAS」IP-287~294；灵感循环第 1 轮；本轮灵感：「课程学习」×「技能组合」）

> R72 把计量审计从认知层下沉到具身层（REG/IRL/DMEM/EREFLEX），给出了单次执行的 J_EMB 证书。但它仍是一个「**单技能、单指令、单时刻**」的框架：
> - **课程学习视角**：J_EMB 只回答「这个技能此刻可不可信」，不回答「这个技能的**信任是从哪来的**」。真实技能库是**逐步长出来的**：先在自由空间验证接触计量，再在贴合态验证力控，再在滑移态验证重抓，最后才敢在意图模糊的人面前做灵巧操作。R72 把这一切压成一张扁平证书，**没有验证顺序、没有前置依赖、没有毕业标准**。若跳过前置直接在对抗场景验证，证书会建立在未审计的假设上（如「触觉噪声是高斯」），产生**证书债**。
> - **技能组合视角**：J_EMB 是**不可组合的**。两个各自 ε-safe 的技能串联，接口处的接触状态传递（A 以 sliding 结束、B 假设 sticking）、意图漂移（人中途改主意）、标定新鲜度衰减，会让复合风险**超可加**；R72 的「逐指令风险界」在技能边界断裂。需要**假设-保证契约（assume-guarantee）**与**接口守卫**。
> - 两个灵感恰好是**一对对偶分解**：课程是**纵向**分解（难度/不确定度阶梯，谁先获得证书），组合是**横向**分解（把已验证技能拼成长程任务）。二者共享同一个**分解预算**——你不能既想课程便宜又想组合可靠。
>
> 本轮提出 **CURRICULUM-SKILL-GAUGE（CSG，课程-技能计量审计）**：把「技能库」建成一张**带毕业门的证书 DAG**，把「长程执行」建成一个**带接口守卫的证书代数**，并用一条**分解预算守恒律**把二者锁死。核心命题：**不再问「这个技能此刻安全吗」，而问「这个技能的信任链是否良基、它的证书能否在技能边界上逐段传递？」**

## 0. 直觉与动机

**灵感 1（课程学习 → 计量信任也有先修课）**
直觉：人类学开车先停车场、再小路、再高速；不是因为「简单」，而是因为**简单场景能先验证你的仪表（后视镜、刹车、油门）可信**。R72 的 J_EMB 是「你在高速上开得安全」的证书，但它没说「你的刹车读数在停车场校准过」。**课程不是样本从易到难的排序，而是证书依赖从公理到定理的排序**：自由空间接触计量是公理，贴合态力控是定理，滑移态重抓是更上层的定理。没有公理，定理就是空中楼阁。**「先易后难」的正确读法是「先验证假设，再验证结论」。**

**灵感 2（技能组合 → 证书是态射，组合需要接口契约）**
直觉：单条定理对，拼起来不一定对；需要**前提与结论对得上**。技能 A 的 post 必须落在技能 B 的 pre 里，且要留**鲁棒余量**（不是刚好相等）。更麻烦的是：A 结束时接触可能正在滑移、标定可能已过期、人的意图可能刚漂移——**技能边界恰恰是状态跳变最大的地方，而契约恰恰在此处假设连续性**。因此组合必须配**运行时接口守卫**：进入 B 前重新核验 (s,z,c) ∈ post(A)，越界就调用恢复技能（重新观测/重抓/澄清意图），而不是硬闯。**组合不是把两个控制器接起来，而是把两个证书用受监控的接口焊起来。**

**灵感 3（课程×组合的对偶 → 分解预算守恒）**
直觉：课程把任务**拆成先修链**，组合把任务**拼成执行链**，两条路都在花同一种钱——**验证预算**。课程省钱的方式是「复用已毕业技能」，组合省钱的方式是「复用技能证书」；若把预算全花在课程（把每级门都设得极松），组合时接口就处处漏；若把预算全花在组合（每个边界都重验证），课程就退化成扁平库。**存在一条守恒律：课程成本 + 组合成本 ≥ 一个由目标风险与覆盖率决定的下界。** 这直接否定了「用课程学习让安全认证变便宜」的幻想。

**灵感 4（课程塌缩与证书债 → 新的 Goodhart 面）**
直觉：课程设计者为了让技能「顺利毕业」，会**悄悄降低毕业门**或**用下游数据训练上游**（应试教学）。于是技能看起来都毕业了，但每级都欠了一点**证书债**（certificate debt = 承诺的余量 − 实际余量）。组合时这些债在接口处**连本带利**地暴露：滑移没检出、意图校准偏、标定过期，三者叠加。R72 防的是「自信地错自己的可执行性」，R73 要防的是「**自信地错自己的学习顺序**」。课程必须有一条**非补偿、单调、可审计**的毕业门，且证书债必须显式为零才能组合。

**灵感 5（与 R72 的关系 → 不是替代，是给证书加"证明树"）**
直觉：R72 的 J_EMB 是证书的**叶子**；CSG 要长出**证明树**：叶子是单技能 J_EMB，内部节点是课程毕业与技能组合，根是长程任务证书 J_CSG。**每一条边都要可复算、可追溯、带余量。** 这保持了 R72 的严格退化：树只有一层时就是 R72；没有内部节点时就是扁平技能库。

## 1. 形式化定义（增量：定义 366–378）

**定义 366（CSG 总览与五不变式）** CURRICULUM-SKILL-GAUGE = (CDAG, 𝒜, ⊗, CURR, D, J_CSG)。五不变式：
(i) **证书良基性**：每个有效证书都有一条从**基础公理**（传感器标定、自由空间计量、人类知情态）出发的有限推导；无循环信任；
(ii) **毕业门非补偿性**：课程的每一级毕业门是若干硬条件的**逻辑合取**，任一项不满足即不毕业，不允许「平均分过线」；
(iii) **接口受监控组合**：任意两个技能的复合必须经过带鲁棒余量的接口契约与**运行时接口守卫**，越界即触发恢复技能；
(iv) **分解预算守恒**：课程验证成本 D_curr + 组合验证成本 D_comp ≤ D_total，且二者不可互相挪用；
(v) **严格退化链**：去组合 ⇒ R72 单技能；去课程 ⇒ 扁平技能库；二者皆去 ⇒ R72/R68；全有效 ⇒ CSG。

**定义 367（技能原子与假设-保证契约）** 技能原子 A = (id, ctx, π, pre, post, ε, u_iface, τ, J, sig)：
- ctx：任务/物体/人类意图分布上下文类；
- π：策略（可包裹 R72 的 λ 调制控制器）；
- pre, post ⊆ Ω × 𝒰：容许区与保证区，Ω 为 (s,z,c) 状态，𝒰 为不确定度向量；
- ε ∈ ℝ⁺：在 pre 上执行并落入 post 的**认证风险上界**（相对 R72 测量模型）；
- u_iface：边界不确定度（接触状态残差、标定新鲜度、意图漂移）；
- τ：证书新鲜期（超过则须重验）；
- J：单技能 J_EMB 证书；
- sig = (in, out, res)：组合签名（输入/输出类型与资源向量）。

**定义 368（证书良基与基础公理）** 设 ≼ 为「证书依赖」关系。基础公理集 𝒳 包含：传感器零点/增益标定证书、自由空间接触计量证书、人类知情与授权态。A 良基 ⇔ 存在有限链 A ≽ x₁ ≽ … ≽ x₀ ∈ 𝒳。**证书 DAG 无环是良基的必要条件；有环意味着「用结论证明前提」，直接判无效。**

**定义 369（课程 DAG 与毕业门）** CDAG = (V, E, ℓ, Gate, m)：
- V ∋ v = (技能原子候选, 上下文类)，E 为先修边；
- ℓ: V → ℕ 难度/不确定度层级；
- Gate(v) = J_EMB 有效 ∧ held-out 风险 ≤ ε_budget(v) ∧ SEAL-Intent/SEAL-Tac 全过 ∧ 依赖新鲜度 ∧ slack(v) ≥ 0；
- **slack(v) = ε_budget(v) − ε_measured(v) − Σ_{c∈children(v)} δ_iface(c)**，即「自己的余量减去下游接口要借的余量」；
- m: V → ℝ⁺ 为余量标记，要求沿任意课程路径**不增长**（下游不能比上游更「松」）。
毕业门是逻辑合取，**任一不满足即熄灭**。

**定义 370（课程策略 CURR）** CURR: 𝒮_cert → V 选择「下一个尝试毕业的节点」，受先修约束与预算约束。目标
max_π E[Σ_v 𝟙[v 毕业] · coverage(v) − λ_c · cost(v)]，s.t. 先修已毕业、D_curr 未耗尽。
这是**证书覆盖率的序贯决策**（非梯度训练的课程），可用 DP / 上下文 bandit 求解。

**定义 371（技能组合算子 ⊗）** A ⊗ B 有定义当且仅当：
(a) 类型匹配：sig(A).out ⊇ sig(B).in；
(b) 鲁棒包含：post(A) ⊆ pre(B) ⊕ δ_iface（即 post(A) 经 δ_iface 膨胀仍在 pre(B) 内）；
(c) 新鲜度兼容：τ_A ≥ 过渡时长 t_tr(A,B)；
(d) 预算允许：D_comp 可支付 δ_iface。
此时 C = A ⊗ B 满足 pre(C)=pre(A)，post(C)=post(B)，
ε(C) = ε(A) + ε(B) + δ_iface，u_iface(C) = combine(u_iface(A), u_iface(B), δ_iface)，τ(C) = min(τ_A − t_tr, τ_B)。
**注意：ε 不是简单相加，接口项 δ_iface 是新增的、不可消除的「焊接成本」。**

**定义 372（接口守卫与受监控组合 ⊗_g）** 在 A→B 边界插入守卫 g：执行 A 后核验状态 x ∈ post(A)；
- 若在：正常进入 B；
- 若越界：调用恢复技能 R（重新观测 / 重抓 / 澄清意图 / 退回安全态），R 自身须有证书；恢复成功后再判是否进入 B，失败则 FAIL-SAFE 退回 R68 包络。
受监控组合 A ⊗_g B 的证书额外携带「守卫覆盖率」g_cov = P(守卫在越界时可恢复) 与「守卫延迟」g_lat ≤ δ_guard。

**定义 373（组合风险次可加性）** 对技能链 A₁,…,Aₙ，定义复合风险
ε_{1:n} ≤ Σ_i ε_i + Σ_i δ_iface,i + (1−g_cov)·ε_fail。
在接口鲁棒包含与守卫有效时，上式给出有限上界；**若放弃 (b) 或守卫，ε_{1:n} 可任意大**（见引理 34 的反例）。

**定义 374（课程-组合对偶与分解预算）** 定义两个互逆算子：
- **Refine**：把课程节点 v 展开为子技能组合 A⊗B（增大组合深度、减小单节点覆盖）；
- **Flatten**：把已验证的组合 A⊗B 塌缩为一个宏技能节点（减小组合深度、增大课程层级）。
要求 Flat(Refine(v)) 与 v 证书等价（风险界与 pre/post 保持）。分解预算 D_total = D_curr + D_comp，**Refine 从 D_curr 借到 D_comp，Flatten 反向，借贷必须记账。**

**定义 375（证书债）** D_debt = Σ_v max(0, need(v) − slack(v)) + Σ_{边} max(0, δ_required − δ_allocated)。
**不变式：D_debt = 0 才允许组合**；否则组合证书无效。证书债是「承诺了但没兑现的验证劳动」，会被长程执行连本带利暴露。

**定义 376（CSG 证书 J_CSG）** J_CSG = (J_EMB 根, cdag_hash, grades, interface_proofs, decomp_ledger, D_debt, guard_stats, version)。
Valid ⇔ 所有原子 J_EMB 有效 ∧ CDAG 良基 ∧ 所有毕业门通过 ∧ 接口余量已验 ∧ D_debt = 0 ∧ 预算守恒。

**定义 377（威胁模型 AIC-CSG）** ℰ_CSG = ℰ_EMB × ℰ_curr × ℰ_comp：
- ℰ_curr = {课程投毒（恶意排序）、毕业门阈值利用、层级间数据泄漏（「应试教学」：用 SEAL 训练）、伪造新鲜度、余量标记造假}；
- ℰ_comp = {接口状态欺骗（post 伪报）、边界条件违约、组合预算记账欺诈、恢复技能被绕过、宏技能证书伪造}。

**定义 378（CSG 严格退化链）**
- 全有效 ⇒ CSG；
- 去组合（⊗_g 禁用）⇒ 每个技能单点执行，等价 R72；
- 去课程（CDAG 退化为公理层）⇒ 扁平技能库：每个技能必须在目标上下文直接持有 J_EMB，否则不可用；
- 两者皆去 ⇒ R72 单技能 / R68；
- 任一失效 ⇒ 安全侧只增不减，保留 R68 硬包络与 λ_floor。

## 2. 关键算法骨架

```python
@dataclass
class SkillAtom:
    sid: str; ctx: Context; pi: Policy
    pre: Region; post: Region
    eps: float; u_iface: Vec; tau: float
    J: J_EMB; sig: Signature

@dataclass
class GateResult:
    passed: bool; measured_eps: float; slack: float; reasons: List[str]

# IP-295 CDAG：课程 DAG + 良基检查（拓扑序 = 证明顺序）
class CurriculumDAG:
    def __init__(self, nodes, prereq, base_axioms):
        self.V, self.E, self.base = nodes, prereq, base_axioms
    def grounded(self) -> bool:
        order = topo_sort(self.V, self.E)          # 无环才返回
        if order is None: return False             # 循环信任 => 直接无效
        ok = set(self.base)
        for v in order:                            # 按证明顺序
            if all(p in ok for p in self.E[v]) and self.V[v].gate_passed:
                ok.add(v)
        return len(ok) == len(self.V)
    def slack(self, v) -> float:
        need = sum(self._iface_need(c) for c in self.children(v))
        return self.V[v].eps_budget - self.V[v].eps_measured - need

# IP-296 毕业门：非补偿合取 + 余量守恒 + 债务记账
class GraduationGate:
    def __init__(self, eps_budget, tau, seal_intent, seal_tac):
        self.budget, self.tau = eps_budget, tau
        self.seal_i, self.seal_t = seal_intent, seal_tac
    def check(self, v, dag, heldout):
        reasons = []
        if not v.J.valid():                         reasons.append("J_EMB")
        r = evaluate_risk(v.pi, heldout[v.ctx])     # held-out，非训练集
        if r > self.budget:                         reasons.append("risk")
        if not self.seal_i.pass_(v):                reasons.append("SEAL-Intent")
        if not self.seal_t.pass_(v):                reasons.append("SEAL-Tac")
        if any(age(p) > self.tau for p in dag.parents(v)):
                                                    reasons.append("freshness")
        s = dag.slack(v)
        if s < 0:                                   reasons.append("slack")
        debt = max(0.0, -s)
        dag.ledger.charge_debt(v, debt)             # 欠账显式化
        return GateResult(not reasons, r, s, reasons)

# IP-297 组合算子：类型 + 鲁棒包含 + 新鲜度 + 预算
def compose(A, B, delta_iface, budget):
    if not type_match(A.sig, B.sig):                return None
    if not robust_subset(A.post, B.pre, delta_iface): return None
    t_tr = transition_time(A, B)
    if A.tau < t_tr:                                return None
    if not budget.charge_comp(delta_iface):         return None
    return SkillAtom(
        sid=f"({A.sid}⊗{B.sid})", ctx=B.ctx,
        pi=Seq(A.pi, B.pi), pre=A.pre, post=B.post,
        eps=A.eps + B.eps + delta_iface,
        u_iface=combine(A.u_iface, B.u_iface, delta_iface),
        tau=min(A.tau - t_tr, B.tau),
        J=CSG_cert(A.J, B.J, delta_iface, t_tr),
        sig=compose_sig(A.sig, B.sig))

# IP-298 接口守卫：越界即恢复，恢复失败即 FAIL-SAFE
class InterfaceGovernor:
    def __init__(self, recover_policy, r68_envelope):
        self.recover, self.envelope = recover_policy, r68_envelope
    def run_pair(self, A, B, env):
        A.run(env)
        if not in_region(env.state, A.post):        # 边界核验
            rec = self.recover(env)                 # 重观测/重抓/澄清意图
            if rec is None or not in_region(rec, B.pre):
                return self.envelope(env)           # 退回 R68 安全包络
            env.state = rec
        return B.run(env)

# IP-299 分解预算账本：课程↔组合不可挪用
class DecompBudget:
    def __init__(self, D_total):
        self.D_total = D_total
        self.spent_curr = 0.0; self.spent_comp = 0.0
        self.transfers = []                          # Refine/Flatten 借贷记录
    def charge_curr(self, c):
        if self.spent_curr + c > self.D_total - self.spent_comp: return False
        self.spent_curr += c; return True
    def charge_comp(self, c):
        if self.spent_comp + c > self.D_total - self.spent_curr: return False
        self.spent_comp += c; return True
    def transfer(self, frm, to, amt):
        # Refine: curr->comp；Flatten: comp->curr；必须双方余额足够
        if frm == 'curr' and self.spent_curr < amt: return False
        if frm == 'comp' and self.spent_comp < amt: return False
        self.transfers.append((frm, to, amt)); return True

# IP-300 CSG 认证规划器：课程选点 + 组合验证 + 证书装配
def CSG_plan(cdag, cur, budget, task_chain):
    while not budget.exhausted():
        v = cur.select(cdag, budget)                 # IP-370 策略
        if v is None: break
        g = GraduationGate(v.eps_budget, v.tau, SEAL_I, SEAL_T)
        res = g.check(v, cdag, heldout_for(v.ctx))
        if not res.passed: cdag.mark_collapsed(v, res.reasons); continue
        cdag.mark_graduated(v)
    # 组合阶段：按任务链逐边验证
    C = task_chain[0]
    for B in task_chain[1:]:
        delta = estimate_iface_delta(C, B)
        C2 = compose(C, B, delta, budget)
        if C2 is None: return Degrade(R72, reason="composition_invalid")
        C = C2
    if cdag.ledger.debt() != 0.0:
        return Degrade(R72, reason="certificate_debt")
    return C if J_CSG(C, cdag, budget).valid() else Degrade(R68)
```

## 3. 推导

**引理 33（课程良基 ⇒ 信任无环）** 在定义 368–369 下，若 CDAG 无环且每个毕业节点的先修均已毕业，则按拓扑序归纳，每个节点都有从基础公理出发的有限证明链。证明：拓扑序保证先修在前；基例为公理；归纳步由毕业门的合取性保证依赖全部为真。**系：任何「用下游数据回过头修改上游证书」的操作都会引入环，被判无效——这正是应试教学的检测器。**

**引理 34（组合次可加性及其边界）** 在定义 371–373 下，若每个 A_i 在 pre_i 上风险 ≤ ε_i、接口鲁棒包含成立、守卫覆盖率 g_cov>0，则 ε_{1:n} ≤ Σε_i + Σδ_i + (1−g_cov)ε_fail。反例：A 以 sliding 结束、B 假设 sticking 且无守卫，则 B 的触觉似然完全失效，ε_B 无界，故复合风险无有限上界。**系：没有接口余量与守卫，单技能证书的算术相加是伪安全。**

**引理 35（余量守恒与债务传播）** 若对每个内部节点 v 有 slack(v) ≥ 0，且每条组合边 δ_allocated ≥ δ_required，则 D_debt = 0 且在任意深度的 Refine/Flatten 下保持为 0。证明：slack 定义已预留全部下游接口需求；组合只消耗预留量，不新增债。反之，任一节点 slack<0 会沿证明树向上传播为父子系统的债。**系：证书债是可加、可追溯、不可隐藏的。**

**引理 36（课程-组合对偶的证书保持）** Refine 与 Flatten 在定义 374 的预算记账下互逆，且保持 (pre, post, ε, τ)：Refine 把 ε 拆为 Σε_i+Σδ_i 并要求其 ≤ 原 ε（否则拒绝细化）；Flatten 反向聚合。证明：直接由风险次可加性与鲁棒包含的传递性。**系：课程与组合是同一证明树的两种视角，不是两套系统。**

**定理 27（CSG 组合可靠性）** 在 A111–A115（原子证书有效、CDAG 良基、接口鲁棒包含、守卫有效、D_debt=0、预算守恒）下，若 J_CSG 有效，则长程任务在 R72 测量模型下的风险 ≤ ε_task = Σε_i + Σδ_i + (1−g_cov)ε_fail。证明：对任务链归纳，用引理 34 合并风险界，用引理 35 保证无隐藏债务，用 J_EMB 的逐指令界保证每段内部；守卫把越界情形显式计入 ε_fail。**安全界的重量落在「接口鲁棒包含在实机边界上真实成立」与「守卫恢复覆盖率未被高估」上。**

**定理 28（严格包含与退化）** 在定义 378 下，CSG 在去组合时逐指令等价于 R72 单技能执行，在去课程时等价于「扁平技能库 + 每技能直接 J_EMB」，两者兼去等价于 R72/R68；且对任意有效执行，CSG 的风险界 ≤ R72 风险界 + 接口项，去掉接口项即回到 R72。**安全单调不减，长程能力只在「课程良基、接口可验」时获益。**

**定理 29（分解预算守恒下界 / 无免费课程）** 设目标为以风险 ε_task 覆盖任务链长度 n，基础公理覆盖率为 c₀。则任意满足 J_CSG 有效性的认证方案必满足
D_curr + D_comp ≥ D_min(ε_task, n, c₀)，
其中 D_min 随 n 增大、随 ε_task 减小、随 c₀ 增大。证明：每条组合边至少需要 δ_required 的接口验证（否则由引理 34 风险无界）；每个未被公理直接覆盖的技能至少需要一次 held-out 毕业验证（否则由引理 33 不可良基）；两类成本不可互相替代，故取下界。**系：课程学习不能凭空降低认证成本；它只能把成本从「重复验证」转移到「复用已毕业证书」，总预算守恒。**

**定理 30（课程塌缩的可检测性）** 若某课程的余量标记 m 沿路径增长（下游比上游更松）或 D_debt>0，则存在一条「接口压力测试」在有限样本下以高概率检出其证书不可靠；反之，m 不增长且 D_debt=0 是课程未塌缩的充分条件（在 SEAL 有效时）。**系：课程塌缩不是不可观测的软风险，而是可写成审计断言的硬约束。**

## 6. 本轮最大风险

**一句话**：CSG 的安全性完全押在「**课程 DAG 的每一级毕业门都真的在自己的测量模型内成立**、**技能边界的 post(A) ⊆ pre(B) 鲁棒包含在实机上真的成立**、**接口守卫的恢复覆盖率没有被高估**」上——而技能边界恰恰是接触状态跳变（滑移、重抓、掉落）与人类意图漂移最剧烈的地方，一旦课程为了「顺利毕业」悄悄降低了某一级门（或把下游 SEAL 数据泄漏进上游训练），证书债就会在长程任务的第一个边界处以「交互式误差累积」的方式爆发：每段都拿着盖章 J_EMB、整条链拿着盖章 J_CSG，事后审计却发现「每一级毕业时指标都在有效域内、每一条接口当时都通过了包含检验」，而真实世界早已越过了那个被契约假设掉的边界——这就是**课程学习层面的「自信地错自己的学习顺序」**。

次级风险与缓解：
1. **课程塌缩/应试教学** → 毕业门用**独立 SEAL 分层**（训练/验证/审计三层物理隔离），并强制余量标记 m 沿路径不增长；D_debt 非零即拒绝组合。
2. **接口鲁棒包含在实机失效** → 把 δ_iface 从「离线估计」升级为**在线自适应余量**：守卫每次越界都回写 δ 的后验，余量只增不减。
3. **守卫恢复覆盖率被高估** → 恢复策略本身须持有 J_EMB；g_cov 用**逐技能分层校准**，取 95% 置信下界。
4. **分解预算记账造假** → 账本哈希链 + 每笔 Refine/Flatten 可复算；预算挪用即触发 IVG 降级。
5. **组合爆炸** → |技能库|≤256、链长≤50、每个内部节点保留一条可复算证明；复杂度本身纳入审计。
6. **课程策略短视** → 课程选点用**覆盖率-成本 VoI**，并预留探索预算；禁止用测试集回报作为选点信号。
7. **与 R72 实时性冲突** → 课程/组合验证全部在**离线/异步**完成，在线只做 O(1) 接口守卫与账本查询，控制域零阻塞。

# 第 73 轮产物 · 创新点清单 v4：CURRICULUM-SKILL-GAUGE（CSG，课程-技能计量审计；Curriculum × Skill-Composition × Gauge：把「单技能证书」长成「可组合、可追溯、不可作弊的证明树」）

> 承接第 72 轮 IP-287~294（EMBODIED-GAUGE-RAS）。R72 完成了「具身层」的计量审计：REG 实时执行图（调度即语义）、IRL 意图隐变量（意图不确定度进风险分母）、DMEM 灵巧接触计量（四分量接触不确定度）、EREFLEX 三层反作用预算、S2R-UQ 仿真-实机不确定度桥接，并给出单次执行的 J_EMB 证书与严格逐指令退化链。但 R72 仍是「**单技能、单指令、单时刻**」：
> - **缺课程学习（Curriculum）**：J_EMB 只认证「此刻这个技能安全」，不认证「这个技能的信任从哪来」。真实灵巧技能库是**逐步长出**的（自由空间 → 贴合 → 滑移 → 意图模糊的人），R72 把它压成扁平证书，**没有验证顺序、没有先修依赖、没有毕业标准**，跳过前置即产生**证书债**。
> - **缺技能组合（Skill Composition）**：J_EMB **不可组合**。两个各自 ε-safe 的技能串联，接口处的接触状态传递、意图漂移、标定新鲜度衰减会让复合风险**超可加**；R72 的逐指令界恰在技能边界断裂。需要**假设-保证契约 + 运行时接口守卫**。
> - **缺课程×组合的对偶与预算守恒**：课程是纵向分解（谁先拿证书），组合是横向分解（怎么拼证书），二者共享同一笔**验证预算**；把预算全押一边都会在另一边漏水。
>
> 本轮提出 **CSG**：
> - **CDAG（课程 DAG）**：把技能库建成**带非补偿毕业门的证书 DAG**，证书必须从基础公理（标定/自由空间计量/人类知情态）良基推导，**严禁循环信任**；
> - **技能契约（Skill Contract）**：每个技能是带 pre/post 区域、风险界 ε、接口不确定度 u_iface、新鲜期 τ 的**证明态射**；
> - **组合算子 ⊗ / 受监控组合 ⊗_g**：类型匹配 + 鲁棒包含 post(A)⊆pre(B)⊕δ + 新鲜度 + 预算；复合风险 ε = Σε_i + Σδ_i + 守卫失败项；
> - **接口守卫**：技能边界在线核验，越界调用恢复技能（重观测/重抓/澄清意图），失败退回 R68；
> - **分解预算守恒 D_curr + D_comp ≥ D_min**：**没有免费课程**——课程只能转移成本，不能消灭成本；
> - **证书债 D_debt**：承诺余量 − 实际余量，**必须为零才能组合**；
> - **J_CSG**：长程任务证书 = 证明树根，逐边可复算。
>
> 核心命题：**从「这个技能此刻安全吗」进化为「这个技能的信任链是否良基、它的证书能否在技能边界上逐段传递？」** ——**课程-技能计量审计闭环**。
>

**定义 366（CSG 总览与五不变式）** 证书良基性、毕业门非补偿性、接口受监控组合、分解预算守恒、严格退化链。**任何一项破坏即 J_CSG 无效。**

**定义 367（技能原子）** 技能 = 假设-保证契约：pre/post 区域 + 认证风险 ε + 接口不确定度 u_iface + 新鲜期 τ + J_EMB + 组合签名 sig。**策略可包裹 R72 的 λ 调制控制器，故 CSG 不重造控制层。**

**定义 368（证书良基与公理）** 依赖关系 ≼ 必须无环；链条须终止于 𝒳={标定, 自由空间计量, 人类知情态}。**有环=用结论证明前提=直接判无效。**

**定义 369（课程 DAG 与毕业门）** Gate = J_EMB ∧ held-out risk ≤ ε_budget ∧ SEAL-Intent ∧ SEAL-Tac ∧ freshness ∧ slack≥0；slack 已扣除全部下游接口需求；m 沿路径不增长。**非补偿：任一失败即熄灭。**

**定义 370（课程策略）** 选择下一个毕业节点以最大化证书覆盖率/成本，受先修与 D_curr 约束；**禁止用测试集回报选点**。

**定义 371（组合算子 ⊗）** 有定义 ⇔ 类型匹配 ∧ post(A)⊆pre(B)⊕δ ∧ τ_A≥t_tr ∧ 预算允许。复合 ε=ε_A+ε_B+δ_iface，τ=min(τ_A−t_tr, τ_B)。**δ_iface 是焊接成本，不是误差，不可省。**

**定义 372（接口守卫 ⊗_g）** 边界核验 x∈post(A)；越界→恢复技能 R（须有证书）→再验 pre(B)；失败→R68 包络。证书带 g_cov、g_lat。**技能边界是状态跳变最大处，必须在线监控。**

**定义 373（组合风险次可加性）** 有守卫+鲁棒包含时有限上界；无守卫/无余量时无界（引理 34 反例：sliding→sticking 触觉似然失效）。

**定义 374（课程-组合对偶）** Refine 把节点展开为组合（ε 拆分须 ≤ 原 ε）；Flatten 把组合塌缩为宏技能；两者证书保持。D_total=D_curr+D_comp，借贷记账。

**定义 375（证书债）** D_debt 为承诺未兑现的验证劳动；**D_debt=0 才允许组合**。债沿证明树向上传播（引理 35）。

**定义 376（CSG 证书 J_CSG）** Valid ⇔ 原子 J_EMB 全有效 ∧ CDAG 良基 ∧ 全部门过 ∧ 接口余量已验 ∧ D_debt=0 ∧ 预算守恒。

**定义 377（威胁模型 AIC-CSG）** ℰ_CSG=ℰ_EMB×ℰ_curr×ℰ_comp：课程投毒/阈值利用/应试教学/伪造新鲜度/余量造假；接口欺骗/边界违约/记账欺诈/绕过恢复/宏技能伪造。

**定义 378（严格退化链）** 全有效⇒CSG；去组合⇒R72 单技能；去课程⇒扁平技能库（每技能直接 J_EMB）；皆去⇒R72/R68。**安全单调不减。**

## 3. 关键算法伪代码

```python
@dataclass
class SkillAtom:
    sid: str; ctx: Context; pi: Policy
    pre: Region; post: Region
    eps: float; u_iface: Vec; tau: float
    J: J_EMB; sig: Signature

@dataclass
class GateResult:
    passed: bool; measured_eps: float; slack: float; reasons: List[str]

# IP-295 CDAG：证书 DAG + 良基（拓扑序 = 证明顺序）
class CurriculumDAG:
    def __init__(self, nodes, prereq, base_axioms):
        self.V, self.E, self.base = nodes, prereq, base_axioms
    def grounded(self) -> bool:
        order = topo_sort(self.V, self.E)
        if order is None: return False             # 有环 => 循环信任
        ok = set(self.base)
        for v in order:
            if all(p in ok for p in self.E[v]) and self.V[v].gate_passed:
                ok.add(v)
        return len(ok) == len(self.V)
    def slack(self, v) -> float:
        need = sum(iface_need(c) for c in self.children(v))
        return self.V[v].eps_budget - self.V[v].eps_measured - need

# IP-296 毕业门：非补偿合取 + 余量 + 债务记账
class GraduationGate:
    def __init__(self, eps_budget, tau, seal_i, seal_t):
        self.budget, self.tau, self.seal_i, self.seal_t = eps_budget, tau, seal_i, seal_t
    def check(self, v, dag, heldout):
        reasons = []
        if not v.J.valid():                          reasons.append("J_EMB")
        r = evaluate_risk(v.pi, heldout[v.ctx])
        if r > self.budget:                          reasons.append("risk")
        if not self.seal_i.pass_(v):                 reasons.append("SEAL-Intent")
        if not self.seal_t.pass_(v):                 reasons.append("SEAL-Tac")
        if any(age(p) > self.tau for p in dag.parents(v)):
                                                     reasons.append("freshness")
        s = dag.slack(v)
        if s < 0:                                    reasons.append("slack")
        dag.ledger.charge_debt(v, max(0.0, -s))      # 欠账显式化
        return GateResult(not reasons, r, s, reasons)

# IP-297 组合算子：类型 + 鲁棒包含 + 新鲜度 + 预算
def compose(A, B, delta_iface, budget):
    if not type_match(A.sig, B.sig):                 return None
    if not robust_subset(A.post, B.pre, delta_iface): return None
    t_tr = transition_time(A, B)
    if A.tau < t_tr:                                 return None
    if not budget.charge_comp(delta_iface):          return None
    return SkillAtom(
        sid=f"({A.sid}⊗{B.sid})", ctx=B.ctx,
        pi=Seq(A.pi, B.pi), pre=A.pre, post=B.post,
        eps=A.eps + B.eps + delta_iface,
        u_iface=combine(A.u_iface, B.u_iface, delta_iface),
        tau=min(A.tau - t_tr, B.tau),
        J=CSG_cert(A.J, B.J, delta_iface, t_tr),
        sig=compose_sig(A.sig, B.sig))

# IP-298 接口守卫：越界→恢复→再验；失败→R68
class InterfaceGovernor:
    def __init__(self, recover_policy, r68_envelope):
        self.recover, self.envelope = recover_policy, r68_envelope
    def run_pair(self, A, B, env):
        A.run(env)
        if not in_region(env.state, A.post):
            rec = self.recover(env)                  # 重观测/重抓/澄清意图
            if rec is None or not in_region(rec, B.pre):
                return self.envelope(env)            # 退回 R68 安全包络
            env.state = rec
        return B.run(env)

# IP-299 分解预算账本：D_curr 与 D_comp 不可挪用
class DecompBudget:
    def __init__(self, D_total):
        self.D_total, self.spent_curr, self.spent_comp = D_total, 0.0, 0.0
        self.transfers, self.chain = [], []
    def charge_curr(self, c):
        if self.spent_curr + c > self.D_total - self.spent_comp: return False
        self.spent_curr += c; self._log(('curr', c)); return True
    def charge_comp(self, c):
        if self.spent_comp + c > self.D_total - self.spent_curr: return False
        self.spent_comp += c; self._log(('comp', c)); return True
    def transfer(self, frm, to, amt):
        if frm == 'curr' and self.spent_curr < amt: return False
        if frm == 'comp' and self.spent_comp < amt: return False
        self.transfers.append((frm, to, amt)); self._log(('transfer', frm, to, amt)); return True
    def _log(self, e):
        self.chain.append((hash_chain(self.chain[-1] if self.chain else GENESIS), e))

# IP-300 CSG 认证规划器：课程选点 + 组合验证 + 证书装配
def CSG_plan(cdag, cur, budget, task_chain):
    while not budget.exhausted():
        v = cur.select(cdag, budget)                 # 覆盖率-成本 VoI
        if v is None: break
        gate = GraduationGate(v.eps_budget, v.tau, SEAL_I, SEAL_T)
        res = gate.check(v, cdag, heldout_for(v.ctx))
        if not res.passed:
            cdag.mark_collapsed(v, res.reasons); continue
        cdag.mark_graduated(v)
    C = task_chain[0]
    for B in task_chain[1:]:
        delta = estimate_iface_delta(C, B)            # 在线可自适应上调
        C2 = compose(C, B, delta, budget)
        if C2 is None: return Degrade(R72, reason="composition_invalid")
        C = C2
    if cdag.ledger.debt() != 0.0:
        return Degrade(R72, reason="certificate_debt")
    return C if J_CSG(C, cdag, budget).valid() else Degrade(R68)
```

## 4. 推导

**引理 33（课程良基 ⇒ 信任无环）** CDAG 无环 ∧ 先修已毕业 ⇒ 拓扑序归纳给出从 𝒳 出发的有限证明链。**系：任何「用下游数据回改上游证书」都引入环，被判无效——应试教学检测器。**

**引理 34（组合次可加性及边界）** 鲁棒包含 + 守卫 ⇒ ε_{1:n} ≤ Σε_i + Σδ_i + (1−g_cov)ε_fail。反例：A 以 sliding 结束、B 假设 sticking 且无守卫，B 的触觉似然失效，ε_B 无界。**系：无接口余量与守卫时，单技能证书的算术相加是伪安全。**

**引理 35（余量守恒与债务传播）** 每个内部节点 slack≥0 且 δ_allocated≥δ_required ⇒ D_debt=0 且在任意 Refine/Flatten 下保持；任一 slack<0 沿证明树向上传播。**系：证书债可加、可追溯、不可隐藏。**

**引理 36（课程-组合对偶的证书保持）** Refine/Flatten 在预算记账下互逆且保持 (pre,post,ε,τ)；Refine 要求 Σε_i+Σδ_i ≤ 原 ε 否则拒绝。由风险次可加性与包含传递性立得。**系：课程与组合是同一证明树的两种视角。**

**定理 27（CSG 组合可靠性）** 在 A111–A115 下，J_CSG 有效 ⇒ 长程任务风险 ≤ ε_task=Σε_i+Σδ_i+(1−g_cov)ε_fail。证明：任务链归纳 + 引理 34 合并 + 引理 35 无隐藏债 + J_EMB 段内界；守卫把越界显式计入 ε_fail。**重量落在「接口鲁棒包含实机成立」与「g_cov 未高估」。**

**定理 28（严格包含与退化）** 去组合逐指令等于 R72 单技能；去课程等于扁平技能库；皆去等于 R72/R68；且风险界 ≤ R72 + 接口项。**安全单调不减，长程能力只在课程良基、接口可验时获益。**

**定理 29（分解预算守恒下界 / 无免费课程）** 覆盖长度 n、目标风险 ε_task、公理覆盖率 c₀ 时，任意有效认证方案满足 D_curr+D_comp ≥ D_min(ε_task,n,c₀)，D_min 随 n↑、随 ε_task↓、随 c₀↑。证明：每条组合边至少需 δ_required（否则引理 34 无界）；每个非公理技能至少需一次 held-out 毕业（否则引理 33 不良基）；两类成本不可替代。**系：课程只能把成本从重复验证转移到复用证书，总预算守恒。**

**定理 30（课程塌缩可检测）** m 沿路径增长或 D_debt>0 ⇒ 存在接口压力测试以高概率检出；反之 m 不增长 ∧ D_debt=0 是未塌缩的充分条件（SEAL 有效时）。**系：课程塌缩是可写进审计断言的硬约束，而非不可观测的软风险。**

## 7. 本轮最大风险

**一句话**：CSG 的安全性完全押在「**课程 DAG 的每一级毕业门都真的在自己的测量模型内成立**、**技能边界的 post(A) ⊆ pre(B) 鲁棒包含在实机上真的成立**、**接口守卫的恢复覆盖率没有被高估**」上——而技能边界恰恰是接触状态跳变（滑移、重抓、掉落）与人类意图漂移最剧烈的地方，一旦课程为了「顺利毕业」悄悄降低了某一级门（或把下游 SEAL 数据泄漏进上游训练），证书债就会在长程任务的第一个边界处以「交互式误差累积」的方式爆发：每段都拿着盖章 J_EMB、整条链拿着盖章 J_CSG，事后审计却发现「每一级毕业时指标都在有效域内、每一条接口当时都通过了包含检验」，而真实世界早已越过了那个被契约假设掉的边界——这就是**课程学习层面的「自信地错自己的学习顺序」**。

次级风险与缓解：
1. **课程塌缩/应试教学** → 训练/验证/审计三层物理隔离的 SEAL；余量标记 m 沿路径不增长；D_debt 非零即拒绝组合。
2. **接口鲁棒包含实机失效** → δ_iface 在线自适应：守卫每次越界回写后验，**余量只增不减**。
3. **守卫恢复覆盖率高估** → 恢复策略自身持有 J_EMB；g_cov 取 95% 置信下界并逐技能分层校准。
4. **分解预算记账造假** → 账本哈希链 + 每笔 Refine/Flatten 可复算；挪用即 IVG 降级。
5. **组合爆炸** → |技能库|≤256、链长≤50、每个内部节点保留一条可复算证明；复杂度纳入审计。
6. **课程策略短视** → 覆盖率-成本 VoI + 探索预算；禁止用测试集回报作选点信号。
7. **与 R72 实时性冲突** → 课程/组合验证全在离线/异步；在线仅 O(1) 接口守卫与账本查询，控制域零阻塞。
