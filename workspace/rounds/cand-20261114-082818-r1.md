# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「场景泛化」×「能耗优化」）

> R69 把不确定性一分为二，并给了系统一张嘴：不确定就问、就看、就摸。但它悄悄假设了三件在真实部署里几乎从不成立的事：
> - **一个世界**：流策略、模态权重、交互回答的语义都在训练场景的分布内；可一旦换地面、换光照、换人、换负载，R69 的「K 个模态」可能整个是错的——不是「在 A/B 间犹豫」，而是「根本不该用这套 A/B」。
> - **一张固定成本表**：VoI 减去的 c(g) 是一个与电量、温度、地形无关的标量；可问一句话、多采 K 个样本、做一次测试时适应，都要花焦耳，而不同场景的每焦耳买到的信息量天差地别。
> - **能量不是状态**：R69 的闭环里没有电池。真实机器人会在 15% 电量时改变策略，会在电机发热时降额，会在爬坡时发现「同样的动作贵了三倍」。
>
> 本轮两个灵感正好补上：
> - **场景泛化**：把「场景」从背景变成隐变量 z_s，显式估计「我还在不在我的世界里」（U_scene），并用不变核 + 有界适应壳 + 场景条件保形风险界，把「泛化」从一个愿望变成一张可审计的证书；
> - **能耗优化**：把能量从成本项升级为状态 B_t 与影子价格 μ_t，用「每焦耳的信息增益/风险下降」统一调度采样、适应、交互与运动；低电量时自动降级，但绝不降穿安全底线。
>
> 核心命题：**泛化与能耗是同一个资源分配问题的两面——泛化问「我的模型在哪儿还成立」，能耗问「用多少焦耳去弄清它/适应它」；二者共享一个隐变量（场景）和一个约束（能量），因此必须联合估计、联合调度。** 命名 **TERRA-RAS**（Transferable, Energy-aware, Risk-adaptive Autonomy）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我还在我的世界里吗；用最后的焦耳，值得去弄清/适应它，还是该退回我确定安全的地方**」。

## 0. 直觉与动机

**灵感 1（场景泛化 → R69 的 U_epi 有一个未言明的前提）**
直觉：R69 的流策略能给出 K 个模态，前提是「模态集合本身是对的」。换一个场景，策略可能把「从未见过的楼梯」误分成「平地/斜坡」两个熟悉模态，模态权重还很自信。这时 R69 的 VoI 会认真地在两个错误选项间做信息规划——**它不是不知道，而是不知道自己的词典错了**。所以必须把「场景内歧义 U_epi」与「场景有效性 U_scene」分开：前者是「选哪个」，后者是「这套选项还成不成立」。U_scene 不能靠框内提问消解；它需要分布外检测、跨场景不变特征、以及主动的、可能超出当前模式集的取证。

**灵感 2（场景是隐变量，不是标签 → 不变核 + 适应壳）**
直觉：把场景当成离散标签（室内/室外/雨天）既不可扩展，也无法覆盖连续变化（坡度、摩擦、负载、光照）。更合理的做法是把场景看成隐变量 z_s，并问两个问题：(a) 哪些能力应对所有场景不变（安全包络、接触约束、动力学守恒）？(b) 哪些参数应随场景快速调整（步高、抓力、速度、增益）？答案是一个**不变安全核 π_core + 低维适应壳 π_shell(z_s)**：核永不在线更新，壳只在认证包络内、用量子化的能量预算做有界适应，并可回滚。泛化不是「一个网络打天下」，而是「把不该变的东西冻住，把该变的东西做得又小又可证」。

**灵感 3（能耗优化 → 能量是所有信息与计算的影子价格）**
直觉：R69 的 VoI 是「nats」，能耗是「焦耳」，两者本来不可比。约束优化给出一个漂亮的翻译：能量约束的对偶变量 μ_t（影子价格）就是「多一焦耳值多少任务价值」。有了 μ，所有决策都可统一：多采一个模态样本，值不值 μ 乘以它的能耗？问一句话，值不值它消耗的电量加社交成本？做一次测试时适应，值不值？低电量时 μ 高，系统自然少采样、少问、少适应；但**证据下限 K_min 与安全包络不可被 μ 压穿**——省电可以省掉「更好」，不能省掉「可证」。

**灵感 4（能耗是场景的被动探针 → 近乎免费的第二意见）**
直觉：R69 用流似然 Δa 做「标定不可吸收」的第二意见；本轮发现能量本身就是一条物理探针：同样的动作，在沙地、上坡、负重、低温下耗电不同。视觉可能没变（都是「灰色地面」），但能耗残差 Δe = |e_obs − e_model| 会变。于是 **(Δφ, Δe) 构成场景漂移的二维诊断**：φ 是场景指纹的漂移，e 是物理代价的漂移。视觉新但能耗不变 ⇒ 表观变化；视觉不变但能耗变 ⇒ 隐藏的物理场景变化（负载/摩擦/坡度）；两者都变 ⇒ 强漂移。这条通道不花额外能量——它是执行任务时自然产生的「免费证据」。

**灵感 5（泛化与能耗的耦合 → 低电量会改变「什么算安全」）**
直觉：R69 的保守退避只看不确定性，不看「退回去要花多少电」。但真实系统里，低电量时「停在原地等」可能比「用确定安全的小步走到充电点」更危险；而高电量时「多花一点电做适应」可能显著降低长期风险。所以安全不应是一个与能量无关的常数，而应是**在能量约束下的风险-能量 Pareto 前沿**：给定剩余电量、场景漂移与任务截止期，选一个既可证又可行的点。关键是，这条前沿必须包含「现在不省，留电给未知」的期权价值。

**灵感 6（双刃剑 → 省电可能省掉证据，适应可能适错世界）**
直觉：能耗优化的最坏情况不是「没省到电」，而是**为了省电关掉了唯一能发现场景漂移的那路证据**；泛化的最坏情况不是「没适应」，而是**用错误的场景指纹选了一个看似高效的适应壳，并用电量残差为它背书**。两者共享同一个失效模式：场景漂移使场景指纹与能耗模型同时失真，系统却仍能生成一张自洽的证书。R70 必须把「场景估计器自身的可信度」和「能耗模型自身的可信度」也纳入证据纪律，否则 TERRA-RAS 只是给 R69 装了一个会省电、也会自我欺骗的调度器。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（TERRA-RAS 总览）** TERRA-RAS = (SGE, SCD, ICU, ECM, ESP, EIV, ACR, GAT, DSE, SCA, RAS-WM†)。五条不变式：
(i) **安全实时流零学习写**（继承 R68 定义 276-i 的精神）：不变核与优化器状态在线零写；仅允许适应壳的有界、可回滚、证书化更新；
(ii) **能量硬预算**：任意 H 步窗口内，运动/感知/计算/交互/适应的累计能耗 ≤ B_t − B_reserve，且 P(B_{t+H} < B_reserve) ≤ δ_E；
(iii) **场景门控**：p_nov > τ_scene 时不得使用 R69 的 resolution bonus，不得宣称跨场景校准，必须进入定义 321 的降级梯；
(iv) **证据下限**：任何「已消解」的声明必须满足 K ≥ K_min 且至少一个场景外证据源；能量不足以支付 K_min 时，放弃声明而非降低证据；
(v) **安全不让步**：所有动作仍过 C-RAS-WM 认证；能量优化只能收缩可行集，不能扩张安全包络。

**定义 311（场景隐变量与场景指纹）** 场景 z_s ∈ 𝒵 是决定观测与动力学/代价规律的隐变量：o_t, y_t, e_t ~ p(· | a_{t−1}, z_s)。场景指纹 φ_t = Ψ(o_{1:t}, e_{1:t}) ∈ ℝ^{d_s}，同时使用视觉/几何历史与**能耗历史**（能耗是物理场景的被动探针）。训练场景指纹集 Φ_train。

**定义 312（场景有效集与泛化间隙）** 有效集 𝒱_τ = {z : d(φ(z), Φ_train) ≤ τ}（d 为 Mahalanobis/kNN/密度非一致性分数）。场景新异概率 p_nov = P(z ∉ 𝒱_τ | o_{1:t})。泛化间隙 G(π) = sup_{z∈𝒱_τ} [R_z(π) − R̂_train(π)]，用场景条件保形给出上界（定义 313、引理 21）。

**定义 313（场景条件保形风险界）** 以场景指纹为条件的分组/加权保形：对候选策略 π，非一致性分数 s_i = R_{z_i}(π) − R̂_{z_i}(π)；新场景 φ 的风险上界
R_bound(π|φ) = R̂_train(π) + q_{1−α}(φ) + L_φ · d(φ, Φ_train)，
其中 q_{1−α}(φ) 为场景邻域内的保形分位数，L_φ 为 Lipschitz 常数。满足 P(R_z(π) ≤ R_bound(π|φ)) ≥ 1−α−η（η 为指纹估计误差）。这是「泛化」第一次以有限样本、可审计的形式出现。

**定义 314（三分解与有效性折扣）** 不确定性拆为 (U_ale, U_epi, U_scene)：U_ale 同 R68；U_epi 同 R69（场景内模态歧义）；U_scene = H(z_s|o) 或 p_nov 的单调函数（场景有效性不确定）。三者不求和，分通道：
U_epi^eff = (1−p_nov)·U_epi + p_nov·U_epi^max，
其中 U_epi^max 是在「模式集可能整体错误」时的最大保守宽度。p_nov→0 时退化为 R69；p_nov→1 时模态权重被剥夺发言权，直接进入保守。

**定义 315（能量状态与情境能耗模型 ECM）** 能量状态 B_t ∈ [0,1]，热状态 Θ_t（降额因子）。能耗分解
e_total = e_move(a|z_s) + e_sense + e_comp(K,N) + e_int(g) + e_adapt + e_comm。
情境能耗模型 e(·|z_s) 输出**保守分位数** ê_δ(·|φ)（而非均值），以覆盖模型误差与场景漂移；其自身的不确定性进入 DSE（定义 324）。

**定义 316（能量预算与机会约束）** 预算约束：Σ_{i=t}^{t+H−1} e_i ≤ B_t − B_reserve(z_s) − margin，且 P(B_{t+H} < B_reserve) ≤ δ_E。B_reserve 是「到达最近安全态/充电点」的估计能耗上界，随场景变化。低电量不是线性降速，而是**改变可行集**：先删掉高能耗、低信息量的动作。

**定义 317（能量影子价格 ESP）** 令 V_t(B, s) 为能量约束下的值函数，μ_t = −∂V_t/∂B ≥ 0。μ_t 是「多一焦耳的任务价值」。决策统一的净价值：
NV(ξ) = E[任务收益] + λ_info·VoI(ξ) + λ_E·E[下游节能] − (1+μ_t)·e_total(ξ) − c_social
s.t. 风险界 ≤ ρ、能量机会约束、C-RAS-WM 认证。μ_t 由对偶/MPC 在线估计；低电量 ⇒ μ_t↑ ⇒ 采样/交互/适应自动变贵。

**定义 318（自适应计算调节 ACR）** R69 固定 K∈{1,4}、N_step=2。ACR 选择 (K, N_step, n_adapt) 以最大化信息/风险收益减 μ 乘能耗，并受截止期约束。证据下限：凡要宣称 resolution bonus，必须 K ≥ K_min(τ_epi) 且至少一个场景外证据源；能量不足以支付 K_min 时，**放弃 bonus**，退回 R68 保守。

**定义 319（不变安全核与有界适应壳 ICU）** π = (π_core, π_shell(φ_t))。π_core 用跨场景不变风险训练（IRM/因果不变特征 + 安全包络），在线**冻结**；π_shell 是低维 FiLM/偏置/增益，更新量 ||Δθ_shell|| ≤ ε_shell，且只在认证包络内改变动作选择，不改变安全前缀。回滚：任一监控触发即恢复上一版 shell 并记录 adaptation_hash。

**定义 320（适应能量与信任域）** 一次适应的能耗 e_adapt(n) 与可证收益上界 ΔR_shell(n) 满足边际递减；仅在 ΔR_shell(n)/e_adapt(n) ≥ μ_t + κ_robust 时允许适应。适应必须在「场景指纹可信」时进行（p_nov ≤ τ_scene），否则先取证/降级，避免「适错世界」。

**定义 321（泛化感知降级梯 GAT）** 按 (p_nov, μ_t, B_t) 分四级：
L0 场景内、能量足：R69 FLUID 正常 + ACR；
L1 轻度漂移/中等能量：关闭 resolution bonus 的高风险部分，启用场景外探针与有界 shell，使用 R_bound 而非经验风险；
L2 强漂移/低能量：冻结 shell，只执行不变核的安全动作，交互仅限「能显著降低 p_nov 或节能」的探针；
L3 未知/极低能量：最小能耗安全策略，前往最近安全态/充电点，停止一切非必要采样与交互。
降级**单调**：条件恶化不会使 λ 或能耗预算反向放宽。

**定义 322（能量感知信息价值 EIV/EROI）** 信息动作的能量回报率
EROI(g) = E[下游节能(g)] / e_total(g)；
净信息价值 EIV(g) = λ_info·VoI(g) + λ_E·E[下游节能(g)] − (1+μ_t)e_total(g) − c_social。
仅当 EIV(g) > 0 且 EROI(g) > 1+μ_t 时才交互。R69 是 λ_E=0、μ=0、e 为常数的特例。典型正例：问「前面有无坡道」以省一次爬坡；典型负例：为 0.1 nat 的模态熵减花 5% 电量。

**定义 323（离线场景课程 SCA）** 长期学习受能量约束：选下一个采集/训练场景 z 以最大化
E[ΔR_bound / e_collect(z)]，
即「每焦耳降低多少跨场景风险上界」。这把泛化从「被动遇到什么学什么」变成「用有限能量买最有信息量的场景」。

**定义 324（场景-能量双残差 DSE）** 视觉/指纹残差 Δφ = d(φ_t, Φ_train) 与能耗残差 Δe = |e_obs − ê_model(φ_t)|。二维诊断：
- (Δφ↑, Δe→)：表观场景变化，物理规律可能未变；
- (Δφ→, Δe↑)：隐藏物理场景变化（负载/摩擦/坡度/低温），视觉不可见；
- (Δφ↑, Δe↑)：强漂移，两者互证；
- (Δφ→, Δe→)：场景稳定。
DSE 与 R69 的 (r_res, Δa) 正交：前者测「场景/物理代价」，后者测「传感器/行为自洽」。

**定义 325（AIC-TERRA 干扰集）** ℰ_TERRA = ℰ_FLUID × ℰ_scene × ℰ_energy。ℰ_scene：留出场景、对抗光照/地形、新物体、指纹欺骗；ℰ_energy：电池骤降、热降额、能耗模型误差、负载突变、低温容量损失、能耗读数操纵。

**定义 326（证书 J_TERRA）** J_TERRA = (J_FLUID, p_nov, R_bound, coverage_α, B_end, B_reserve_margin, P_reserve, μ_t, compute_K/N, adaptation_hash, shell_norm, rollback_ready, Δφ, Δe, terra_ver)。Valid ⇔ Valid(J_FLUID) ∧ (p_nov ≤ τ_scene ∨ 处于 L1–L3 且已正确降级) ∧ R_bound ≤ ρ ∧ 能量机会约束满足 ∧ 证据下限满足 ∧ shell 在信任域且可回滚。

```python
# IP-264 SGE：场景指纹、新异概率、场景条件保形
class SceneGapEstimator:
    def update(self, o_hist, e_hist):
        phi = self.fingerprint(o_hist, e_hist)        # 视觉/几何 + 能耗历史
        dphi, de = self.dse.residuals(phi, e_hist)     # IP-272 双残差
        p_nov = self.novelty(phi, de)                  # 融合隐藏物理漂移
        q = self.conformal.quantile(phi)               # 邻域保形分位
        return phi, p_nov, q, (dphi, de)

# IP-265 SCD：三分解 + 有效性折扣
def decompose_scene_aware(samples, p_nov, u_epi_max):
    u_ale, u_epi, modes = r69_decompose(samples)
    u_epi_eff = (1 - p_nov) * u_epi + p_nov * u_epi_max
    return u_ale, u_epi, u_epi_eff, modes

# IP-267/268 ECM/ESP：保守能耗与能量影子价格
def energy_price(B, phi, H, delta):
    e_hat = ecm.quantile(phi, q=1-delta)              # 保守估计
    mu = dual_price(value_fn, B, phi, H)              # 一阶对偶
    return e_hat, max(mu, 0.0)

# IP-269/270 EIV/ACR：能量感知采样与交互
def choose_compute_info(modes, u_epi, p_nov, B, mu, budget):
    K = acr.optimal_K(u_epi, mu)                       # 引理 20
    if u_epi > TAU_EPI:
        K = max(K, K_MIN)                              # 证据下限
    if budget.e_comp(K) > B - budget.reserve:
        return None, 1, False                          # 付不起证据 → 放弃 bonus
    best = None
    for g in info_candidates(modes, out_of_frame=(p_nov > TAU_SCENE_LOW)):
        if not budget.allow(g) or not c_ras_wm.certify_info(g, o): continue
        eiv = (lam_info * voi(g) + lam_E * expected_energy_saved(g)
               - (1 + mu) * budget.e_total(g) - social_cost(g))
        if eiv > 0 and eroi(g) > 1 + mu:
            if best is None or eiv > best.eiv: best = (g, eiv)
    return best, K, True

# IP-271 GAT：单调降级梯
def tier(p_nov, B, mu):
    if p_nov > TAU2 or B < B2: return "L3"
    if p_nov > TAU1 or B < B1: return "L2"
    if p_nov > TAU0 or B < B0 or mu > MU0: return "L1"
    return "L0"

# IP-277 主闭环
def TERRA_RAS_round(M, o_hist, e_hist):
    phi, p_nov, q, (dphi, de) = M.sge.update(o_hist, e_hist)
    mu = M.esp.price(M.B, phi, M.H)
    lev = M.gat.tier(p_nov, M.B, mu)
    # 1) 只有 L0/L1 才值得多采样；L2/L3 用最少证据保安全
    K = M.acr.K(u_epi_prev, mu) if lev in ("L0", "L1") else 1
    samples = M.fmp.sample(o, K)
    u_ale, u_epi, u_epi_eff, modes = decompose_scene_aware(samples, p_nov, U_MAX)
    # 2) 场景条件风险界（不是经验风险）
    R_b = M.sge.risk_bound(phi, q, M.policy)
    # 3) 交互/适应：仅当场景指纹可信且在能量预算内
    g = adapt = None
    if lev in ("L0", "L1"):
        g, K2, ok = M.eiv.choose_compute_info(modes, u_epi, p_nov, M.B, mu, M.budget)
        if not ok: lev = "L2"                          # 证据付不起 → 降级
        if lev == "L1" and M.icu.can_adapt(p_nov, mu, R_b):
            adapt = M.icu.bounded_adapt(phi, M.budget.adapt)
    # 4) 执行：安全前缀始终来自冻结的不变核
    a_core = M.icu.core_propose(...)
    a_shell = M.icu.apply(adapt, a_core) if adapt else a_core
    k = M.c_ras_wm.certified_prefix(a_shell, ..., wm_preds)
    # 5) 风险缩放：ale + 有效 epi + 场景项
    U_floor = u_ale + (u_epi_eff if g is None else 0.0) + U_SCENE(p_nov, R_b)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    if lev in ("L2", "L3"):
        lam = max(lam, LAM_L2 if lev == "L2" else LAM_L3)
        k = min(k, k_safe(lev))
    # 6) 能量账本、证书、审计
    M.energy.charge(k, K, g, adapt)
    M.vqa_t.submit_async(g, p_nov, R_b, mu, M.energy.ledger, (dphi, de))
    return k, lam, a_shell, (u_ale, u_epi_eff, p_nov, mu, lev)
```

## 3. 推导

**引理 19（框内 VoI 不能消解 U_scene）** 设当前框架 ℱ 生成的模态集为 M。若场景 z 在 ℱ 的可达邻域外，且任何框内信息动作 g 的似然满足 p(y|g,o,z) = p(y|g,o)（对 z 局部不变），则 I(z; y|g,o)=0，R69 的 VoI 对 U_scene 的下降为 0，而 U_epi 仍可下降。系：**场景泛化必须引入框架外证据**（分布外检测、能量残差、开放探针），否则再多的「问」也只是在错误的词典里做更精细的查表。

**引理 20（能量-信息最优采样）** 设 K 个样本带来的 epistemic 信息满足饱和模型 I(K) = U_epi(1−e^{−K/τ})，计算能耗 e_comp(K) = e_0 + c_K K。在净价值 I(K) − μ e_comp(K) 下，最优
K* = τ ln(U_epi/(μ c_K τ))（若括号 >1），否则 K*=1；且 ∂K*/∂μ < 0。系：低电量（μ↑）时系统自动少采样；但证据下限 K_min 优先于该式，付不起 K_min 时应放弃 resolution bonus 而非伪造证据。

**引理 21（场景条件保形覆盖）** 在场景可分簇且簇内可交换的假设下，定义 313 的 R_bound 满足 P(R_z(π) ≤ R_bound(π|φ)) ≥ 1−α−η；当 φ 落在训练场景邻域边界时，额外项 L_φ·d(φ, Φ_train) 线性增长。系：**泛化保证是「邻域内」的**；指纹欺骗或全新场景会使保形前提失效，必须由 DSE 与降级梯兜底。

**引理 22（有界适应壳的安全性）** 若 π_core 在所有 z∈𝒱_τ 上满足安全包络，且 ||Δθ_shell|| ≤ ε_shell、shell 只做包络内的动作选择，则对任意 z∈𝒱_τ，
risk(π_core+shell) ≤ risk(π_core) + β·ε_shell；
若监控触发回滚，则风险回到 core 水平。系：适应可以提升效率，但不能把风险推过 β·ε_shell + 认证边界。

**定理 18（TERRA 严格包含 R69/R68）** 当 p_nov≤τ_scene、B≥B_high、μ=0（能量不受约束）、shell 关闭、K_min 满足时，TERRA 的 EIV 退化为 R69 的 VoI，ACR 退化为 R69 的自适应 K，GAT 停在 L0，因此逐指令与 FLUID-RAS 相同；再令「永不交互」即得 R68。有限能量或场景漂移时，TERRA 只会收缩可行集并增加保守项，安全侧不弱于 R69；效率侧以能量-风险 Pareto 为条件获得收益。

**定理 19（联合风险-能量保证与单调降级）** 在定义 310–326 下，若 J_TERRA 有效，则
P(R_z(π) ≤ ρ) ≥ 1−α−η−η_φ，P(B_{t+H} ≥ B_reserve) ≥ 1−δ_E，
且当 (p_nov, B_t) 恶化时，GAT 的级别、λ 与允许的交互/采样集合单调不增；任意 shell 回滚不增加风险；C-RAS-WM 认证保持控制连续。⇒ 系统不会因为「省电」而跳过安全认证，也不会因为「适应」而扩张安全包络。

**定理 20（能量感知交互的必要条件）** 若 EROI(g) ≤ 1+μ_t 或 EIV(g) ≤ 0，则执行 g 不改善净能量-任务价值；因此将其剪枝不损失最优性（在定义 322 的净价值目标下）。系：R69 的「有 VoI 就问」在能量受限时是次优的，甚至可能让系统在关键时刻没电可用。

## 6. 本轮最大风险

**一句话**：TERRA-RAS 的最大风险是**双重分布漂移的自指**——场景指纹与能耗模型往往在同一个未见场景中同时失效，系统可能用错误的场景 ID 选择一个「看似高效」的适应壳，又用被同一漂移污染的能耗残差为这个选择背书，于是在电量耗尽前自信地适应了一个它并不认识的世界；更糟的是，为了省电它可能先关掉了唯一能发现漂移的那路证据。

**次级风险与缓解**：
1. **场景指纹欺骗 / 保形前提失效** → DSE 双残差 + 至少一个正交证据源 + E313 对抗训练；p_nov 高即降级。
2. **能耗模型误差 / 电池骤降** → 保守分位数 + B_reserve 机会约束 + 单调降级梯 + E304/E308。
3. **适应壳遗忘或安全漂移** → 不变核冻结 + 信任域 ε_shell + 回滚 + 引理 22/E307。
4. **省电省掉证据** → 证据下限 K_min + 付不起就放弃 resolution bonus；禁止用低 K 伪造「已消解」。
5. **双重漂移使两个估计器同时自信地错** → (Δφ, Δe) 联合诊断 + 两路都异常时强制 L3；审计器 VQAuditor-T 检查「场景/能量证据是否同源」。
6. **实时预算被场景估计与适应击穿** → 廉价门控（新异度/μ 先算），昂贵适应仅在 L1 且按需触发；E315 验收。

## 3. 关键算法伪代码

```python
# IP-264 SGE：场景指纹 + 双残差 + 新异概率 + 保形
class SceneGapEstimator:
    def update(self, o_hist, e_hist):
        phi = self.fingerprint(o_hist, e_hist)        # 视觉/几何 + 能耗历史
        dphi, de = self.dse.residuals(phi, e_hist)     # IP-272
        p_nov = self.novelty(phi, de)                  # 隐藏物理漂移也计入
        q = self.conformal.quantile(phi)               # 场景邻域保形分位
        return phi, p_nov, q, (dphi, de)

# IP-265 SCD：三分解 + 有效性折扣
def decompose_scene_aware(samples, p_nov, u_epi_max):
    u_ale, u_epi, modes = r69_decompose(samples)
    u_epi_eff = (1-p_nov)*u_epi + p_nov*u_epi_max
    return u_ale, u_epi, u_epi_eff, modes

# IP-267/268 ECM/ESP：保守能耗 + 能量影子价格
def energy_price(B, phi, H, delta):
    e_hat = ecm.quantile(phi, q=1-delta)
    mu = dual_price(value_fn, B, phi, H)
    return e_hat, max(mu, 0.0)

# IP-269/270 EIV/ACR：能量感知采样与交互
def choose_compute_info(modes, u_epi, p_nov, B, mu, budget):
    K = acr.optimal_K(u_epi, mu)                       # 引理 20
    if u_epi > TAU_EPI: K = max(K, K_MIN)              # 证据下限
    if budget.e_comp(K) > B - budget.reserve:
        return None, 1, False                          # 付不起证据 → 放弃 bonus
    best = None
    for g in info_candidates(modes, out_of_frame=(p_nov > TAU_SCENE_LOW)):
        if not budget.allow(g) or not c_ras_wm.certify_info(g, o): continue
        eiv = (lam_info*voi(g) + lam_E*expected_energy_saved(g)
               - (1+mu)*budget.e_total(g) - social_cost(g))
        if eiv > 0 and eroi(g) > 1 + mu:
            if best is None or eiv > best.eiv: best = (g, eiv)
    return best, K, True

# IP-271 GAT：单调降级梯
def tier(p_nov, B, mu):
    if p_nov > TAU2 or B < B2: return "L3"
    if p_nov > TAU1 or B < B1: return "L2"
    if p_nov > TAU0 or B < B0 or mu > MU0: return "L1"
    return "L0"

# IP-277 主闭环
def TERRA_RAS_round(M, o_hist, e_hist):
    phi, p_nov, q, (dphi, de) = M.sge.update(o_hist, e_hist)
    mu  = M.esp.price(M.B, phi, M.H)
    lev = M.gat.tier(p_nov, M.B, mu)
    K   = M.acr.K(u_epi_prev, mu) if lev in ("L0","L1") else 1
    samples = M.fmp.sample(o, K)
    u_ale, u_epi, u_epi_eff, modes = decompose_scene_aware(samples, p_nov, U_MAX)
    R_b = M.sge.risk_bound(phi, q, M.policy)           # 场景条件风险界
    g = adapt = None
    if lev in ("L0","L1"):
        g, K2, ok = M.eiv.choose_compute_info(modes, u_epi, p_nov, M.B, mu, M.budget)
        if not ok: lev = "L2"
        if lev == "L1" and M.icu.can_adapt(p_nov, mu, R_b):
            adapt = M.icu.bounded_adapt(phi, M.budget.adapt)
    a_core  = M.icu.core_propose(...)                  # 冻结不变核
    a_shell = M.icu.apply(adapt, a_core) if adapt else a_core
    k = M.c_ras_wm.certified_prefix(a_shell, ..., wm_preds)
    U_floor = u_ale + (u_epi_eff if g is None else 0.0) + U_SCENE(p_nov, R_b)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    if lev in ("L2","L3"):
        lam = max(lam, LAM_L2 if lev=="L2" else LAM_L3)
        k = min(k, k_safe(lev))
    M.energy.charge(k, K, g, adapt)
    M.vqa_t.submit_async(g, p_nov, R_b, mu, M.energy.ledger, (dphi, de))
    return k, lam, a_shell, (u_ale, u_epi_eff, p_nov, mu, lev)
```

## 4. 推导

**引理 19（框内 VoI 不能消解 U_scene）** 若场景 z 在当前框架的可达邻域外，且框内信息动作的似然对 z 局部不变，则 `I(z;y|g,o)=0`：R69 的 VoI 只能降 U_epi，不能降 U_scene。故场景泛化必须引入框架外证据（分布外检测、能量残差、开放探针）。

**引理 20（能量-信息最优采样）** 在饱和信息 `I(K)=U_epi(1−e^{−K/τ})`、线性能耗 `e=e_0+c_K K` 下，`K*=τ ln(U_epi/(μ c_K τ))`（若 >1），且 `∂K*/∂μ<0`。低电量自动少采样；但 `K_min` 优先，付不起就放弃 resolution bonus。

**引理 21（场景条件保形覆盖）** 在场景可分簇、簇内可交换假设下，`P(R_z(π) ≤ R_bound(π|φ)) ≥ 1−α−η`；远离训练场景时多出 `L_φ·d(φ,Φ_train)` 项。故泛化保证是「邻域内」的，邻域外靠 DSE 与降级梯兜底。

**引理 22（有界适应壳的安全性）** 若 core 在 𝒱_τ 上满足安全包络，且 `||Δθ_shell||≤ε_shell`、shell 只做包络内动作选择，则 `risk(core+shell) ≤ risk(core)+β ε_shell`；回滚则回到 core 水平。

**定理 18（TERRA 严格包含 R69/R68）** 当 `p_nov≤τ_scene`、`B≥B_high`、`μ=0`、shell 关闭且 `K_min` 满足时，EIV 退化为 R69 的 VoI，ACR 退化为 R69 的自适应 K，GAT 停在 L0，逐指令相同；再令「永不交互」即得 R68。有限能量/场景漂移时只收缩可行集并增加保守项，安全侧不弱于 R69。

**定理 19（联合风险-能量保证与单调降级）** 若 J_TERRA 有效，则 `P(R_z≤ρ)≥1−α−η−η_φ` 且 `P(B_{t+H}≥B_reserve)≥1−δ_E`；条件恶化时级别、λ 与允许的交互/采样集合单调不增；shell 回滚不增风险，C-RAS-WM 认证保持控制连续。

**定理 20（能量感知交互的必要条件）** 若 `EROI(g)≤1+μ` 或 `EIV(g)≤0`，执行 g 不改善净能量-任务价值，剪枝不损失最优性。R69 的「有 VoI 就问」在能量受限时可能让系统在关键时刻没电可用。

## 7. 本轮最大风险

**一句话**：TERRA-RAS 的最大风险是**双重分布漂移的自指**——场景指纹与能耗模型往往在同一个未见场景中同时失效，系统可能用错误的场景 ID 选择一个「看似高效」的适应壳，又用被同一漂移污染的能耗残差为这个选择背书，于是在电量耗尽前自信地适应了一个它并不认识的世界；更糟的是，为了省电它可能先关掉了唯一能发现漂移的那路证据。

**次级风险与缓解**：场景指纹欺骗/保形失效（DSE 双残差 + 正交证据 + E313）；能耗模型误差/电池骤降（保守分位 + B_reserve 机会约束 + E304/E308）；适应壳遗忘或安全漂移（core 冻结 + 信任域 + 回滚 + 引理 22/E307）；省电省掉证据（K_min 证据下限，付不起即放弃 bonus）；双漂移使两估计器同时自信地错（(Δφ,Δe) 联合诊断 + 双异常强制 L3 + VQAuditor-T 审计同源性）；实时预算被场景估计与适应击穿（廉价门控，昂贵适应仅 L1 按需触发 + E315）。
