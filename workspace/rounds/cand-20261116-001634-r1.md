# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「视觉语言模型」×「决策规划」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**语义接地 + 指令条件规划 + 单调安全**。两个灵感分别治理 v9 的两种债：**语义盲区债**（指标层 M 全是几何/度量量，看不见"易碎/高温/禁入区/社交距离"，也回答不了"我抓的是不是任务要的那个物体"）、**规划失语债**（PrimitiveGraph 存在，但自然语言指令无法接地为子目标，决策规划停留在隐式）。必须用**语义单调安全律**保证：VLM 只能收紧可行域、永不放松 v9 的度量安全，从而把 VLM 幻觉的失败方向锁定为"过度保守"而非"危险放行"。

## 0. 直觉与动机

**灵感 1（视觉语言模型 → 语义接地与约束编译）**
直觉：v9 的指标层级 M=(M₀,M₁,M₂,M₃,M_dom,M_SLAM) 全部是几何/度量量——间隙、力矩、抓取几何、域偏移、SLAM 风险。它能回答"会不会撞、会不会超力矩"，却回答不了"这个杯子易碎、这只手要轻拿""这是禁入区""刀口朝向人""与人保持社交距离"。VLM 恰好补这一块：它把图像+语言映射为物体类别、可供性（affordance）、关系与意图。但 VLM 有三个致命属性：**慢**（百毫秒到秒级）、**不可信**（幻觉）、**不确定**（置信度未校准）。因此核心设计不是"把 VLM 接进控制环"，而是**把 VLM 的自由输出编译成可验证、带时标、可退化的类型化约束**：语义约束编译器（SCC）+ 接地一致性门（GCG）+ 语义-度量投影（SMP）。关键立场：语义是**叠加在度量安全之上的收紧层**，不是替代层。

**灵感 2（决策规划 → 指令条件的分块规划）**
直觉：v9 有 PrimitiveGraph，但"该做哪个原始动作/子目标"是隐式的、手写的或由单一策略隐式决定的；自然语言指令（"把杯子放进洗碗机"）无法接地为子目标序列。决策规划视角给出清晰分工：指令 → 子目标 DAG → 原始图上的先验权重 → 影响 AC 的候选采样与打分。VLM 做高层任务分解，但必须经过**符号可行性校验**（前置条件/效果对照语义场景图 + 原始图可达性），且只作为**先验**而非硬约束。核心创新：任务子目标规划器（TSP）+ 原始图先验（w）。

**两者的正交耦合（为什么必须一起做）**
语义约束属于**安全侧**，只改变可行域（做子集）；任务先验属于**任务侧**，只改变同一可行域内的采样/打分分布（不碰可行性）。两条线正交的好处：可独立退化、独立验证，且共同保证"语义不放松安全、任务不污染安全"。若把二者混成一个 VLM 端到端策略，就丧失了单调性这一唯一可靠的安全锚。

## 1. 研究问题（轮次升级版）

- **Q1（语义单调安全）**：如何把 VLM 输出编译成只收紧可行域的约束，使任意 VLM 错误至多导致过度保守、而不导致度量安全违背？语义-度量投影 π 的单调性如何形式化，并与 v9 的 AC 块证书（定义 533）兼容？
- **Q2（异步时标与失效）**：在 VLM 延迟 ≥ 控制周期一个数量级的前提下，如何用「场景哈希 + 时标 + 跟踪复核」界定约束的新鲜/陈旧/过期，使过期严格退回 v9，而不是把旧约束施加到已经移动/消失的对象上？
- **Q3（指令条件规划与退化）**：指令 → 子目标 DAG → 原始图先验的接地误差如何被符号校验约束？先验在 VLM/TSP 失效时如何退化为均匀分布（v9 默认），且不改变引理 87 的安全单调性？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 语义约束律（Semantic Constraint Law, SCC）**
VLM 输出永不直接驱动控制，一律先编译为类型化语义约束 c=(φ,τ,ℓ,h,T_valid,H_scene)：φ 为白名单谓词（clearance/upright/avoid_region/social_dist），τ∈{hard,soft,prior}，ℓ 为接地置信，h≥0 为代价权重，T_valid 为有效时域，H_scene 为接地时的场景哈希。初编译一律为 soft；只有通过 GCG 且 ℓ≥ℓ_hard 的约束才可升为 hard；ℓ<ℓ_soft 直接丢弃。

**P14 语义单调安全律（Semantic Safety Monotonicity, SSM）**
语义-度量投影 π 是单调收紧映射：对 hard 约束只做 min 收紧（ĝ_min^sem ≤ ĝ_min）、障碍并集扩张或方向界收紧；对 soft 约束只加非负代价。逐点成立：A^sem(t) ⊆ A^metric(t)（v9 可行域）。语义永远不能删除或放宽任何 v9 约束，尤其不能放宽 M₀。因此 VLM 假阳性只会过度保守（活性代价），不会放行危险动作。

**P15 异步时标退化律（Asynchronous Semantic Time-Stamping, AST）**
VLM 以 ≤5Hz 或事件触发在独立线程运行，输出携带 (t_g, H_scene, T_valid)。主环只在块边界（5Hz）或事件触发时消费。fresh（age≤Δ_stale 且哈希匹配且跟踪复核）按编译类型施加；stale（哈希不符/遮挡但未过期）**保留 hard 以过度保守并触发重接地**；expired（age>Δ_stale）直接丢弃并退回 v9。场景哈希 + 跟踪复核把"约束施加到错误对象"的窗口压到 Δ_stale+τ_tr 内。

## 3. 与基线的接口（如何退化）

- SCC 失效（VLM 超时/无模型）⇒ C^sem=∅，纯 v9 几何规划；
- GCG 失效 ⇒ 全部语义约束丢弃（保守）⇒ 等价 v9 安全层；
- SMP 失效 ⇒ 块证书不被语义修正 ⇒ 等价 v9 AC；
- TSP 失效 ⇒ 原始图先验均匀 ⇒ 等价 v9 PrimitiveGraph 默认；
- 约束陈旧/过期/场景哈希不符 ⇒ 该约束中性（stale 保留 hard 属过度保守，仍 ⊆ v9）；
- v9 的 AC/MW/ID 任一失效 ⇒ 按 v9 五级退化链处理；
- 全部失效 ⇒ 完整退回 MetricVoiceGauge-OTL-GC-ER v7，再退回 v6。

## 4. 预期贡献

1. **VLM→约束的编译式语义接地框架**（SCC+GCG+SMP）：核心是**语义单调安全**——语义只能收紧可行域，把 VLM 幻觉的失败方向锁定为"过度保守"而非"危险放行"，使不可信模型可以安全地进入实时决策环；
2. **异步语义时标与场景哈希失效机制**（AST）：把 VLM 的延迟/陈旧问题转化为可界定的保护窗口，过期严格退回 v9；
3. **指令条件的分块决策规划**（TSP + 原始图先验）：VLM 子目标 DAG + 符号可行性校验 + 原始图先验，与安全约束正交、可独立退化；
4. **语义-度量双闭环与 E571–E590 实验矩阵**：覆盖接地精度、幻觉遏制、时标失效、单调性审计、指令任务、对抗 VLM 与端到端竞赛。

## 5. 本轮最大风险

**一句话**：语义层是单调收紧的——它只能防住 VLM 的假阳性（幻觉约束导致过度保守），却对假阴性（漏检真实语义危险）无免疫；而异步时标与 Δ_stale 又恰好扩大"真实危险未被约束"的窗口，系统最可能以"度量安全、语义失守"的方式失败。

## 1. 符号体系增量（定义 540–549）

| G^task=(V,E,ψ,pre,eff) | 子目标 DAG：节点、时序边、原始动作映射、前置条件/效果 |
| w: Primitive → [0,1] | 原始图先验权重 |
| M_sem | 语义风险层（监控软层，非硬层） |

| ℓ_hard, ℓ_soft | 接地门双阈（默认 0.85 / 0.5，E582 标定） |

**新增定义 540（语义场景图 SemanticSceneGraph）** S_t=(E_t,R_t)，E_t={e_i} 为语义实体，R_t⊆E_t×E_t×Rel 为关系（on/in/near/holding…）。e_i 由 VLM 异步输出与几何检测器对齐得到：cls_i/aff_i 来自 VLM，pose_i/bbox_i 来自几何，ℓ_i^vlm 为 VLM 自报置信，ℓ_i^geo 为几何一致度（IoU/位姿误差），h_i 为接地时场景哈希。

**新增定义 541（类型化语义约束 TypedSemanticConstraint）** c=(φ,τ,ℓ,h,T_valid,H_scene)。φ 取自白名单谓词集合 Φ={clear(e_i,d_sem), upright(e_j), avoid(R), social_dist(person,d_soc)}，仅允许可被几何/状态检查的谓词；τ 为约束类型；ℓ∈[0,1] 为接地置信；h≥0 为软代价权重；T_valid 为有效时域（控制周期数）；H_scene 为接地时场景哈希。**初编译一律 τ=soft**，hard 只能由 GCG 授予。

**新增定义 542（接地一致性门 GroundingConsistencyGate）**
```
ℓ(c) = min( ℓ^vlm(e_i), geo_agreement(e_i,S_t),
            temporal_stability(e_i), physical_plausibility(e_i,aff_i) )
τ = hard   若 ℓ(c) ≥ ℓ_hard ∧ φ 可检查 ∧ 物理可行
  = soft   若 ℓ_soft ≤ ℓ(c) < ℓ_hard
  = drop   若 ℓ(c) < ℓ_soft
```
geo_agreement 为 VLM 声称实体与几何检测的匹配度；temporal_stability 为最近 n 帧声明一致性；physical_plausibility 检查可供性与几何是否相容（如"易碎"需可抓取/可见）。ℓ 的可靠性由 E582 校准（ECE≤0.05）。

**新增定义 543（语义-度量投影 SemanticMetricProjection）** π 把约束投影到 AC 块证书与打分：
```
hard clear(e_i,d_sem)   ⇒ ĝ_min^sem = min(ĝ_min, dist(s,e_i) − d_sem)
hard upright(e_j)       ⇒ θ̂_max^sem = min(θ̂_max, θ_max(e_j))
hard avoid(R)           ⇒ 障碍集 O ← O ∪ R（带 margin）
soft c                  ⇒ score ← score − h_c · viol_c(ζ)
prior                   ⇒ 采样权重 w 与子目标进展加成（不进入可行性）
```
单调性：ĝ_min^sem ≤ ĝ_min，可行域只缩不扩；M₀ 判据只在原有合取项上**增加** φ_c，从不删除 v9 约束。

**新增定义 544（语义时标与场景哈希 SemanticTimeStamp）** 约束 c 在 t 时刻状态：
```
fresh   ⇔ t−t_g ≤ Δ_stale ∧ H_scene = H(S_t) ∧ tracker 复核通过
stale   ⇔ t−t_g ≤ Δ_stale ∧ (哈希不符 ∨ 遮挡)   ⇒ 保留 hard（过度保守）并请求重接地
expired ⇔ t−t_g > Δ_stale                        ⇒ 丢弃（中性，退回 v9）
```
"保留 hard"是刻意的：对已移动/消失对象仍施加旧约束只会过度保守（⊆ v9），绝不放松安全；过期则严格退回 v9。

**新增定义 545（子目标 DAG SubgoalDAG）** G^task=(V,E,ψ,pre,eff)。V 为子目标节点，E 为时序边，ψ:V→2^Primitive 将子目标映射到 PrimitiveGraph 的原始动作集，pre/eff 为对 S_t 的前置条件与效果谓词。VLM 提出候选 DAG，符号校验器检查：每个子目标前置条件在 S_t 下可满足、效果相容、ψ(v) 在 PrimitiveGraph 中可达。校验失败节点被丢弃或标记需修复。

**新增定义 546（原始图先验 PrimitivePrior）** 当前子目标 g 下，对 PrimitiveGraph 原始动作 v 的先验
```
w_v ∝ exp(−dist_ψ(g, v) / T_w),  v ∈ ψ(g)；其余 v 取极小底权
```
w 仅用于 AC 的候选采样与打分偏置，**不进入可行性判定**。TSP 中性时 w 为均匀分布（v9 默认）。

**新增定义 547（语义风险层 SemanticRiskLayer）** M_sem(s,a)=Σ_c h_c·viol_c(s,a)，作为监控软层并入指标层级：M=(M₀,M₁,M₂,M₃,M_dom,M_SLAM,M_sem)。M₀ 仍是唯一硬层；M_sem 仅在经 GCG→SMP 升为 hard 时以**附加合取项**方式参与 M₀ 判定。

**新增定义 548（语义单调可行域 MonotoneFeasibleSet）** 逐点定义
```
A^sem(t) = { a : a ∈ A^metric(t) ∧ ∀c(τ=hard): φ_c(s_t,a)=1 } ⊆ A^metric(t)
```
其中 A^metric(t) 为 v9 可行域。该式即 P14 的形式化，逐点成立（不要求跨时刻单调）。

**新增定义 549（异步语义预算 SemanticBudget）** VLM 推理在独立线程按 MW 契约行执行：预算 B_vlm、截止期 D_vlm（默认 300ms）、队列 drop-oldest、按场景哈希合并同场景请求。主环仅在块边界（5Hz）或事件触发时读取，读取成本 O(|C^sem|)。

## 2. 形式化定义（要点与升级）

**定义 493（六层指标层级）** 升级为七层 M=(M₀,M₁,M₂,M₃,M_dom,M_SLAM,M_sem)（定义 547）；M₀ 仍为唯一硬层。
**定义 495/524（MetaWeight/情感，5 维）** 继承 v9 不变；情感与语义软代价解耦，语义代价不计入情感奖励。
**定义 521（DA-OTL）** 继承 v9 不变；τᵢ(t) 在 K_eff>1 时以块证书（含语义修正后的 ĝ_min^sem）替代逐层逐步复核。
**升级定义 496（软证书，v10）** δ_trigger 增加语义项，但只加不减：
```
δ_trigger = δ_trigger^v9  ∨  (∃ hard c : ¬φ_c)
```
即语义硬约束违规与几何违规同样触发 M₀ 硬检查——语义只能让触发**更早/更严**，绝不更晚/更松。
**升级定义 531（软硬约束衔接）** M₀ 判据增加语义硬约束入口：SMP 投影后的 ĝ_min^sem 与 θ̂_max^sem 直接进入块级入口检查；任一中块守卫（几何或语义）违规 ⇒ 立即切换 p* 或安全停驻。

## 3. 关键算法骨架

# IP-357 SemanticConstraintCompiler：VLM → 类型化约束（独立线程，MW 契约 D_vlm）
class SemanticConstraintCompiler:
    PREDICATES = {'clear', 'upright', 'avoid_region', 'social_dist'}  # 白名单
    def __init__(self, vlm, d_stale=150, t_valid=50):
        self.vlm, self.d_stale, self.t_valid = vlm, d_stale, t_valid

    def async_infer(self, image, instruction, scene_hash):

        cs = []
        for item in raw.constraints:
            if item.kind not in self.PREDICATES:          # 白名单：不可检查的谓词拒绝
                continue
            phi = compile_predicate(item)                 # 仅几何/状态可检查
            cs.append(Constraint(phi, tau='soft',          # 初编译一律 soft
                                 l=item.conf, h=max(0.0, item.cost),
                                 T_valid=self.t_valid, H_scene=scene_hash))
        return cs


# IP-358 GroundingConsistencyGate：多源一致 → hard/soft/drop
class GroundingConsistencyGate:
    def __init__(self, l_hard=0.85, l_soft=0.5):
        self.l_hard, self.l_soft = l_hard, l_soft

    def evaluate(self, c, S_t, tracker):
        geo   = self.geo_agreement(c, S_t)
        tmp   = tracker.temporal_stability(c.entity)
        plaus = self.physical_plausibility(c, S_t)
        c.l = min(c.l, geo, tmp, plaus)                   # 定义 542
        if c.l >= self.l_hard and c.phi.checkable and plaus:
            c.tau = 'hard'
        elif c.l >= self.l_soft:
            c.tau = 'soft'
        else:
            c.tau = 'drop'
        return c


# IP-359 TaskSubgoalPlanner：指令 → 子目标 DAG → 原始图先验（仅偏置）
class TaskSubgoalPlanner:
    def plan(self, instruction, S_t, primitive_graph):

        G = self._build_dag(raw)
        return self.symbolic_validate(G, S_t, primitive_graph)  # pre/eff + 可达性

    def primitive_prior(self, G, g, primitive_graph):
        if G is None:
            return uniform(primitive_graph)               # 中性 = v9 默认
        prims = G.psi[g]
        return softmax({v: -dist_psi(g, v) / self.T_w for v in primitive_graph})


# IP-360 SemanticMetricProjector：单调收紧（只减 ĝ_min、只加代价）
class SemanticMetricProjector:
    def project(self, cert, constraints, state):
        g_min, extra_cost = cert.g_min, 0.0
        for c in constraints:
            if c.tau == 'hard':
                if c.phi.kind == 'clear':
                    g_min = min(g_min, c.phi.dist(state) - c.phi.d_sem)
                elif c.phi.kind == 'upright':
                    cert.theta_max = min(cert.theta_max, c.phi.theta_max)
                elif c.phi.kind == 'avoid_region':
                    cert.obstacles |= c.phi.region
            elif c.tau == 'soft':
                extra_cost += c.h * c.phi.violation(state)  # 非负
        cert.g_min, cert.extra_cost = g_min, extra_cost     # 单调：只收紧
        return cert


# 主闭环集成：MetricVoiceGauge-SGC
def metricvoicegauge_round_10(M, s, obs, image, instruction, ...):

    results = middleware.run_cycle(runners={...}, ctx=ctx)

    # ---- 异步语义：独立线程产出，经场景哈希合并；主环只取新鲜约束 ----
    sem = semantic_bus.poll(scene_hash=obs.hash())        # fresh / stale / expired

    constraints = [c for c in constraints if c.tau != 'drop']
    hard = [c for c in constraints if c.tau == 'hard']

    # ---- 5Hz 块生成：任务先验偏置采样；SMP 收紧证书（只收紧）----
    if current_chunk is None or current_chunk.exhausted:
        w = tsp.primitive_prior(G_task, current_subgoal, primitive_graph)
        cands = policy.sample_sequences(state, K, n=64, prior=w)
        current_chunk = chunker.generate_chunk(
            state, cands,
            cert_filter=lambda cert: smp.project(cert, constraints, state))

    # ---- 50Hz 中块守卫：几何 + 语义硬约束的廉价复核 ----
    verdict, k_next = chunker.midchunk_guard(
        current_chunk, k_exec, live_obs, semantic_hard=hard)
    if verdict == 'abort':
        current_chunk.execute_safe_stop_at(k_next)
        current_chunk = None
    else:
        execute(current_chunk.actions[k_next])

    # ---- v8 继承路径（契约化调用）：GCT/ER/5 维风险/奖励 ----
    C, spatial_cert, claims, metrics, rewards = M.inherited_v8_path(ctx)

    # ---- 事件触发的子目标推进/重规划（非 50Hz）----
    if subgoal_done(current_subgoal, obs) or obs.hash_changed_major():
        G_task = tsp.plan(instruction, sem.scene_graph, primitive_graph)
        current_subgoal = G_task.next()
    return C, spatial_cert, claims, metrics, rewards

## 4. 推导

**引理 87（语义单调安全）** 设 π 为 SMP 投影，A^metric(t) 为 v9 可行域。则对任意 VLM 输出与任意时刻 t：A^sem(t) ⊆ A^metric(t)。证明：π 对 hard 约束只做 min 收紧（ĝ_min^sem ≤ ĝ_min）、障碍并集扩张与方向界收紧；对 soft 只加非负代价；M₀ 判据仅在原有合取项上增加 φ_c，未删除任何 v9 约束；GCG 只把 soft 升 hard 或丢弃，从不放宽任何 v9 约束。故任何在 v10 中被认证可行的动作在 v9 中亦可认证可行。∎

**引理 88（假阳性遏制与活性代价）** 幻觉产生的 hard 约束只会移除动作。若导致块不可行，AC 依 v9 骨架回退单步或安全停驻（定义 534），故最坏后果是活性/效率损失，而非安全违背。∎

**引理 89（时标-哈希失效界）** 约束 c 在 t 被施加当且仅当 age≤Δ_stale 且（fresh 或 stale-保留）。跟踪器在 τ_tr 内检出显著场景变化，场景哈希可分辨变化时延为 τ_hash；故 c 被施加到"错误对象/位置"的时间窗 ≤ Δ_stale + τ_tr + τ_hash。过期即丢弃，由引理 87 逐点成立退回 v9。∎（依赖哈希粒度假设）

**引理 90（接地门校准可靠性）** 若 ℓ(c) 经 E582 校准（可靠性图误差 ≤ ε_cal），则 hard 约束的假阳性率 ≤ (1−ℓ_hard)+ε_cal。证明：GCG 以 ℓ 为阈值，校准保证标称置信与经验精度偏差 ≤ ε_cal。∎（条件于校准假设；未校准时该界失效——见第 8 节风险）

**引理 91（异步非干扰与 50Hz 守恒）** VLM 在独立线程按 MW 契约行执行，D_vlm ≫ Δt；主环仅在块边界（5Hz）或事件触发时读取约束，读取成本 O(|C^sem|) ≤ 0.5ms；VLM 超时注入中立元（C^sem=∅），不阻塞主环。故主环 ≤ 感知 2ms + 决策 20ms + 语义读取 0.5ms，50Hz 守恒（承接 v9 引理 86）。∎

**引理 92（指令先验退化等价）** TSP 中性时 w 为均匀分布，AC 的采样与打分回到 v9 分布；先验仅改变候选排序/采样，不进入可行性判定（定义 546）。故 TSP 失效严格等价 v9 PrimitiveGraph 默认，且不改变引理 87 的安全单调性。∎

## 8. 本轮最大风险

**一句话**：语义层是单调收紧的——它只能防住 VLM 的假阳性（幻觉约束导致过度保守），却对假阴性（漏检真实语义危险）无免疫；而异步时标与 Δ_stale 又恰好扩大"真实危险未被约束"的窗口，系统最可能以"度量安全、语义失守"的方式失败。
