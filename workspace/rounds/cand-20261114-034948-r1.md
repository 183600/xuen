# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「记忆检索」×「技术路线图」）

> R69 用「aleatoric 收紧、epistemic 交互」把不确定性一分为二，交出了一份漂亮的单步决策理论。但它自陈的最大风险一针见血：**VoI 建立在「流模型的模态分布可信」这一未经验证的先验上；一旦模态权重未校准，系统会自信地追问一个幻影，或把一个误导性回答盖上「已验证」的章**。根因不在流模型，而在 R69 是**无记忆（memoryless）**的：它每一轮都用同一个生成先验重新计算「问什么值钱」，却从不问「上次问这类问题时，到底有没有问对」。它同样缺乏**时间尺度上的纪律**：一个能力一旦被设计出来就默认可信，没有「先证明、再放行」的分级。
>
> 本轮两个灵感正好补上这两块：
> - **记忆检索**把「这个问题值不值得问、这个模态可不可信」从**生成先验**改写成**对历史情景的检索**——用真实发生过的（歧义→信息动作→事后结果）三元组做非参数校准；问错过的别再问，问对过的可复用。
> - **技术路线图**把「现在能信任什么」从**一次性设计决定**改写成**带门控的分级演进**——每个能力只有在审计流上通过里程碑才被解锁，失败即降级。它给闭环补上了此前完全缺失的**时间维度与就绪度（readiness）**。
>
> 核心命题：**用检索到的情景经验校准「问什么」，用技术路线图门控「信什么」；二者合起来把 R66–R69 的「无记忆单步控制器」升级为「有历史、有阶段、可退化的闭环」**。命名 **EPOCH-RAS**（Episodic Provenance-calibrated, roadmap-gated Closed-loop Hybrid risk-adaptive safety；epoch 双关「情景纪元」与「路线图的评估周期」）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我曾经在哪里、学到了什么、现在准备好做什么**」——安全不只是当下的判断，也是记忆与日程。

## 0. 直觉与动机

**灵感 1（记忆检索 → VoI 应该是可查的，不是只能从零算）**
直觉：人类判断「要不要问」几乎不靠从零推导后验熵，而是靠**案例**——「上次在这种看不清的路口多看了一眼，发现是反光，有用」；「上次追问一个含混的回答，对方其实在敷衍，没用」。R69 的 MINT 用的是模型内生的 p(y|g,o)，它从不校验这个预测是否兑现。把 MINT 的 VoI 换成对**情景记忆**的检索估计：找出与当前上下文最相似的若干次交互，统计信息动作 g 实际带来的后验熵下降或任务收益，再与模型先验做收缩混合。于是「问什么」第一次有了**经验闭环**。

**灵感 2（记忆检索 → 模态权重可以被经验校准）**
直觉：R69 的模态权重 ŵ_k 是采样频率，不是可信度；它用 ECE 门做静态检查，却没有任何机制去**改善**权重。记忆提供监督：每次交互后最终会观察到真实模态（任务成功/失败、人类确认、延迟标签），这条「当时以为的模态 vs 后来证实的模态」就是一条校准样本。用检索邻域内的经验频率对先验做 Dirichlet / James–Stein 收缩，就把 MCG 从「只判断、不学习」升级为「用经验自我校准」。**这正打在 R69 最大风险的命中点上**：幻影模态会在历史里持续表现为「问了也没用 / 被证伪」，从而被下压。

**灵感 3（技术路线图 → 能力要分级解锁，而非一次性信任）**
直觉：R69 的所有新能力（交互、流似然、证据纪律）被同时引入、同时信任，工程上等于「一口气把所有安全门都拆了」。技术路线图恰好相反：按依赖排成阶段，每阶段有**进入条件、验收指标、失败回退**。把它形式化为**能力就绪图（capability readiness DAG）**：节点是能力，边是依赖；节点只有在其父节点已认证、且自身在独立审计流上过门后才被激活，任一门失败即降级到上一稳定阶段。于是「能否信任记忆」从一个设计假设，变成**可审计的部署决定**。

**灵感 4（两者相乘 → 记忆给内容，路线图给时序）**
直觉：记忆回答「该问什么」，路线图回答「现在允不允许靠记忆来问」。缺了记忆，路线图只是空转的门；缺了路线图，记忆会立刻把所有赌注押在不可信的回忆上。二者相乘，闭环第一次具备**时间一致性**：同一场景下，系统不会因一次偶然成功就永久自信，也不会因一次投毒就永久失能——它按 epoch 巩固、按 gate 升降。

**灵感 5（记忆是新的攻击面 → 再巩固、回音室、门控自证）**
直觉：记忆不是中立数据库。**检索会放大投毒**：攻击者只需插入少量高相似度假情景，就能占据 top-k，让系统「回忆起」一个从未发生的成功。**再巩固会被劫持**：回忆若允许回写，错误信息就会在回忆时被写回、越洗越真。**门控会自证**：路线图的验收数据来自系统自己的审计流，若审计流被同一套偏见污染，门就替偏见盖章。因此本轮必须同时交付：只读回忆不变式、来源（provenance）多样性纪律、离线巩固窗口、以及独立于在线闭环的门控审计。否则 R70 只是给 R69 的幻觉装了一座更宏伟的档案馆。

## 1. 形式化定义（增量：定义 310–322）

**定义 310（EPOCH-RAS 总览）** EPOCH-RAS = (EMR, MCH, RRG, RMP, MPC, RAS-WM†)。在 R69 三不变式之上再加三条：
(i) **只读回忆（read-only recall）**：在线检索不写记忆；记忆只在 epoch 边界离线巩固（强化 R68 定义 276-i 的「实时流零学习写操作」）；
(ii) **来源纪律（provenance discipline）**：每条情景携带不可变来源与哈希链；单条或同源回忆不得单独改变策略，需跨来源一致；
(iii) **路线图单调性（roadmap monotonicity）**：能力只能经认证门激活，门失败即降级；任何情况下不得绕过当前已认证的基线能力。

**定义 311（情景轨迹 e）** e = (τ, φ_τ, M_τ, g_τ, a_τ, y_τ, u_τ, prov, h)，其中 τ 时间戳、φ_τ 上下文嵌入、M_τ 当轮模态集（含权重）、g_τ 执行的信息动作（可为空）、a_τ 任务动作、y_τ 事后证据（延迟标签 / 人类确认 / 任务结果）、u_τ 实际观测到的熵降或收益、prov 来源签名、h = H(e_prev, e) 哈希链。情景库 B = {e_i}，容量上界 |B| ≤ B_max。

**定义 312（检索算子 EMR）** 给定当前观测 o_t，R(o_t) = TopK_{e∈B} s(φ_t, φ_e)·1[rel(e, o_t)]，其中 s 为核相似度（默认 exp(−‖·‖²/τ_s)），rel 为**机制相关性掩码**（只有同一因果机制才可迁移，由经认证的相关性头给出）。定义有效样本量 n_eff = (Σ_i w_i)² / Σ_i w_i²，w_i 为检索权重。**相似不等于可迁移**：高 s 低 rel 的样本必须剔除，这是与「朴素向量检索」的关键区别。

**定义 313（历史 VoI 与收缩混合 MCH）** 对候选信息动作 g：
VoI_hist(g) = Σ_i w_i u_i(g) / Σ_i w_i（仅统计执行过 g 的检索样本）；
VoI_blend(g) = [n_eff/(n_eff+κ)]·VoI_hist(g) + [κ/(n_eff+κ)]·VoI_model(g)。
κ 为先验强度；n_eff→0 时退化为 R69 的 VoI_model。选择 g* = argmax_g [VoI_blend(g) − c(g)]，且仍受 R69 定义 298 的安全与预算约束。

**定义 314（记忆校准模态先验）** p_hist(m_k|o_t) = (Σ_i w_i 1[m_i = m_k] + α) / (Σ_i w_i + Kα)；校准后先验 p_cal = [n_eff/(n_eff+κ_m)]·p_hist + [κ_m/(n_eff+κ_m)]·p_flow。以留出情景上的 ECE 作为记忆校准质量。**关键**：p_cal 只在 RRG 通过时替代 p_flow 进入 VoI 与模态选择。

**定义 315（检索可靠性门 RRG）** 记检索半径 ε_ret（邻域内最大上下文距离）、机制漂移 δ_mech（邻域与当前机制的总变差上界）、校准误差 ECE_mem。门条件：ε_ret ≤ ε̄ ∧ δ_mech ≤ δ̄ ∧ ECE_mem ≤ τ_ece ∧ n_eff ≥ n_min。任一不满足 ⇒ 禁用记忆校准，退化为 R69 纯先验路径。

**定义 316（能力就绪图 RMP）** 有向无环图 G = (V, E_dep)，节点 v 为能力（如 MINT 交互、记忆校准、跨本体迁移），带：就绪度 r_v ∈ [0,1]、进入条件 Entry_v、验收门 Gate_v（在一段独立审计流上评估的指标向量）、回退边 fallback(v) ∈ V ∪ {⊥}。激活集 A_t ⊆ V 满足**下闭性**：v ∈ A_t ⇒ 其所有父节点 ∈ A_t 且 Gate_v 已通过。r_v 按 TRL 式样标定（1–9 → 0–1）。

**定义 317（Epoch 与巩固）** 一个 epoch 为 [t_s, t_s+Δ_e) 的固定评估窗口。在线期只读；epoch 边界执行**巩固算子** C(B, AuditBuf) → B'：按重要度、来源、时效做保留 / 衰减 / 合并，并重算校准表；巩固是唯一允许写记忆的时刻，且必须在来源校验后以批处理完成。

**定义 318（记忆完整性与防再巩固 MPC）** 记忆条目不可变（immutable）；回忆返回引用而非可变副本；写入仅发生在巩固并以 prov 链校验。再巩固攻击定义为「在回忆路径上注入可回写的错误」，被只读不变式阻断。投毒检测：同一事实需 ≥ k 个**来源正交**（不同 prov 根）的条目支持，且高相似度单源条目不得占满 top-k（多样性配额）。

**定义 319（时滞与漂移跟踪）** 巩固采用带遗忘的指数加权（半衰期 h_½）与容量淘汰；定义漂移率 β = 每 epoch 机制变化上界。校准误差 e_t 在稳定机制下以 O(1/√n_eff) 收敛，在漂移下满足 e_{t+1} ≤ (1−α)e_t + β + σ/√n_eff，故 e_∞ ≤ (β+σ/√n_eff)/α 有界。

**定义 320（三级退化阶梯）** 按可信度自高到低：L2 = EPOCH-RAS（记忆 + 路线图门控）→ L1 = R69 FLUID-RAS（纯先验交互）→ L0 = R68 CALM-RAS（纯保守）。RRG 或路线图门失败 ⇒ 降到 L1；L1 的 ECE / 安全门失败 ⇒ 降到 L0。退化是**逐指令可判定**的，且每级安全侧不弱于下一级。

**定义 321（证书 J_EPOCH）** J_EPOCH = (J_FLUID, retrieval_precision, retrieval_coverage, σ_min_prov, ECE_mem, n_eff_p50, roadmap_state, epoch_id, memory_chain_hash)。Valid ⇔ Valid(J_FLUID) ∧ 检索指标达标 ∧ 来源多样 ∧ 路线图状态与声明一致。

**定义 322（路线图风险预算与门控部署）** 设节点 v 认证风险上界为 r_v，门控假通过概率 ≤ p_fp(v)，误用惩罚为 L_v。则部署集合 A 的期望风险 ≤ Σ_{v∈A} r_v + Σ_{v∈A} p_fp(v)·L_v；且 A 下闭保证任一时刻存在有效回退路径到 L0。这给出「分级解锁」的量化风险预算，而非口头承诺。

## 2. 关键算法骨架

```python
# IP-264 EMR：只读情景检索（机制相关性门 + 来源多样性配额）
def recall(B, o_t, k, quota):
    phi = embed_context(o_t)
    cand = [e for e in B if relevance_head(phi, e.phi) > REL_TAU]   # 先过机制门
    cand.sort(key=lambda e: sim(phi, e.phi), reverse=True)
    return diversity_topk(cand, k, quota)          # 同源不得占满 top-k

# IP-265 MCH：历史 VoI 与模态先验的收缩混合
def blended_voi(g, R_set, o_t, kappa):
    n_eff = effective_n(R_set)
    hist  = sum(w(e) * e.u(g) for e in R_set if e.g == g) / max(sum(w(e) for e in R_set if e.g == g), EPS)
    prior = flow_voi(g, o_t)                        # R69 定义 298
    return n_eff/(n_eff+kappa)*hist + kappa/(n_eff+kappa)*prior

def calibrated_mode_prior(R_set, p_flow, kappa_m):
    return dirichlet_shrink(empirical_modes(R_set), p_flow, kappa_m)

# IP-266 RRG：检索可靠性门
def retrieval_gate(R_set, o_t):
    eps   = max(dist(embed_context(o_t), e.phi) for e in R_set)
    dmech = mechanism_drift(R_set, o_t)
    ece   = mem_calibration_ece(R_set)
    return (eps <= EPS_BAR) and (dmech <= DELTA_BAR) and (ece <= TAU_ECE) and (effective_n(R_set) >= N_MIN)

# IP-267 RMP：能力就绪图门控（只升已认证、失败即降）
def roadmap_step(G, A, audit_stream):
    A_new = set(A)
    for v in topo_order(G):                          # 下闭性
        if v in A: continue
        if all(p in A_new for p in parents(G, v)) and gate_pass(v, audit_stream):
            A_new.add(v)
    for v in list(A_new):                            # 回归检测：门失败即降级
        if not gate_holds(v, audit_stream):
            A_new = demote_closure(G, A_new, v)
    return A_new

# IP-274 主闭环（继承 R69，插入记忆层与路线图门）
def EPOCH_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    # 1) 只读回忆（不写 B）；路线图判断记忆能力是否已解锁
    R_set   = M.emr.recall(M.B, o, k=K_R) if "MEMORY" in M.roadmap.active else []
    use_mem = bool(R_set) and M.rrg.retrieval_gate(R_set, o)
    # 2) 可约才交互：VoI 用记忆收缩（未解锁则用 R69 先验）
    vois = {g: M.mch.blended_voi(g, R_set, o, M.kappa) if use_mem
               else M.flow_voi(g, o) for g in info_action_candidates(modes)}
    g = M.mint.choose_with(vois, modes, o, M.budget) if U_epi > TAU_EPI else None
    ans, U_epi_after = None, U_epi
    if g is not None:
        ans   = M.cia.execute(g)
        prior = M.mch.calibrated_mode_prior(R_set, modes, M.kappa_m) if use_mem else modes
        U_epi_after = M.cia.update_belief(prior, ans)
    # 3) 风险缩放与 R69 完全一致（记忆只影响「问不问 / 选哪个模态」）
    U_floor = U_ale + (U_epi_after if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k   = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    mode = select_mode(modes, U_epi_after, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    # 4) 在线只读：仅登记待巩固情景（幂等、无回写）
    M.trace_log.append(make_trace(o, modes, g, ans, U_epi, U_epi_after, M.last_outcome))
    return k, lam, mode, (U_ale, U_epi_after)

# IP-269 巩固（仅在 epoch 边界、离线、来源校验后）
def consolidate(M):
    M.B = C(M.B, M.trace_log, M.audit_buf, half_life=M.half_life, cap=B_max)
```

## 3. 推导

**引理 19（检索偏差–方差界）** 设检索邻域内上下文距离 ≤ ε_ret、机制漂移 ≤ δ_mech，单条 VoI 泛函对 (φ, 机制) 为 L-Lipschitz，单样本方差 σ²。则 |E[VoI_hist] − VoI_true| ≤ L(ε_ret + δ_mech) + σ/√n_eff。**系（邻域存在最优半径）**：扩大邻域降方差、增偏差，故存在 k* 平衡二者——这是「凭记忆」相对「凭先验」的定量权衡，也解释了为何 RRG 必须同时约束半径与漂移，而不能只看样本量。

**引理 20（收缩校准的收敛与漂移跟踪）** 机制稳定时，VoI_blend 的均方误差 ≤ (κ/(n_eff+κ))²·Bias_prior² + σ²/(n_eff+κ)，以 O(1/√n_eff) 收敛到真实 VoI；在漂移率 β、遗忘因子 α 下，稳态误差 ≤ (β + σ/√n_eff)/α。**系**：记忆不是「越多越好」，遗忘是收敛的必要条件——它与 R68「只收紧」互补：λ_floor 管瞬时安全，遗忘管长期校准。

**引理 21（检索放大的投毒上界）** 若攻击者以速率 δ_p 注入情景，且 top-k 中同源条目数受配额 q 限制、每源被污染概率相关 ρ<1，则需 ≥k 个正交来源一致才采纳时，错误率 ≤ δ_p·ρ^{k−1} + ε_σ；若不做来源多样性约束，top-k 被单源占满时错误率退化为 δ_p（攻击者只需少量高相似度注入）。**系**：**来源多样性不是锦上添花，而是把投毒上界从线性压成指数衰减的唯一手段**——这是 R69 引理 18 在记忆侧、也是更危险侧的镜像。

**引理 22（有界记忆的稳定性）** 容量 B_max、指数淘汰、epoch 边界离线巩固下，校准表的更新量有界且与在线延迟解耦；故系统在 24h / 30d 长时程上不会出现「记忆无限增长导致的校准漂移或实时预算击穿」。

**定理 18（路线图门控的单调安全与严格包含）** 在 A99（下闭激活 + 每节点认证风险上界 + 失败降级）下，任一时刻期望风险 ≤ Σ_{v∈A} r_v + Σ_{v∈A} p_fp(v)L_v + r_baseline；且当 B = ∅（空记忆）、或 RRG 未过、或 MEMORY 未解锁时，EPOCH-RAS **逐指令等于 R69**；当 R69 的 VoI−c ≤ 0 时逐指令等于 R68。故 L2 ⊇ L1 ⊇ L0 是严格退化链，安全侧不做任何让步。

**定理 19（只读回忆的实时性与抗再巩固）** 在线检索只读、巩固只在 epoch 边界批处理，故在线路径无记忆写操作、可确定性重放、P99 延迟与记忆规模解耦；再巩固攻击被定义 318 的不变性阻断，攻击面被迁移到可审计的离线巩固窗口。**系**：这使「记忆」第一次能进入硬实时安全闭环，而不是只能当离线建议系统。

## 6. 本轮最大风险

**一句话**：EPOCH-RAS 把「信什么」交给了记忆与路线图，但二者可能构成**自我确认的回音室**——检索用系统自己偏置过的历史、校准用同一批历史、路线图的验收又用系统自己产生的审计流，于是「记忆只回忆它已经相信的东西，门只为它已经相信的东西盖章」，系统会越来越自信地重复同一个错误；**最危险的不是记错，而是错误被记忆反复证实、再被路线图正式认证**。

**次级风险与缓解**：
1. **检索放大投毒**（少量高相似度假情景占据 top-k）→ 机制相关门 + 来源多样性配额 + 引理 21；
2. **再巩固劫持**（回忆时回写污染）→ 只读回忆不变式 + 离线巩固窗口（定义 318、定理 19）；
3. **检索偏差–方差陷阱**（一味扩大邻域导致偏差）→ RRG 同时约束 ε_ret 与 δ_mech + 引理 19 的最优 k*；
4. **门控自证 / 评估污染** → 审计流与在线闭环隔离 + E314 + 独立门控审计；
5. **记忆无限增长击穿实时** → 容量上界 + 遗忘 + epoch 离线巩固（引理 22）。

## 4. 推导

**引理 19（检索偏差–方差界）** 邻域内 `ε_ret`、机制漂移 `δ_mech`、单条 VoI 泛函 `L`-Lipschitz、单样本方差 `σ²`，则 `|E[VoI_hist]−VoI_true| ≤ L(ε_ret+δ_mech)+σ/√n_eff`。系：扩大邻域降方差增偏差，存在最优 `k*`；故 RRG 必须同时约束半径与漂移，不能只看样本量。

**引理 20（收缩校准的收敛与漂移跟踪）** 稳定机制下 `MSE ≤ (κ/(n_eff+κ))²Bias_prior² + σ²/(n_eff+κ)`，以 `O(1/√n_eff)` 收敛；漂移率 `β`、遗忘因子 `α` 下稳态误差 `≤ (β+σ/√n_eff)/α`。系：遗忘是收敛的必要条件——`λ_floor` 管瞬时安全，遗忘管长期校准。

**引理 21（检索放大的投毒上界）** 注入速率 `δ_p`、top-k 同源配额 `q`、源间污染相关 `ρ<1`，需 `k` 个正交来源一致时错误率 `≤ δ_p·ρ^{k−1}+ε_σ`；无多样性约束（top-k 被单源占满）时退化为 `δ_p`。系：来源多样性是把投毒从线性压成指数衰减的唯一手段。

**引理 22（有界记忆的稳定性）** 容量 `B_max`、指数淘汰、epoch 边界离线巩固下，校准更新量有界且与在线延迟解耦，故长时程不会因记忆增长导致漂移或实时击穿。

**定理 18（路线图门控的单调安全与严格包含）** A99（下闭激活 + 每节点认证风险上界 + 失败降级）下，期望风险 `≤ Σ_{v∈A} r_v + Σ_{v∈A} p_fp(v)L_v + r_baseline`；且 `B=∅`／RRG 未过／MEMORY 未解锁时逐指令等于 R69；R69 的 `VoI−c≤0` 时逐指令等于 R68。故 `L2 ⊇ L1 ⊇ L0`，安全侧不让步。

**定理 19（只读回忆的实时性与抗再巩固）** 在线只读、巩固仅 epoch 边界批处理 ⇒ 在线无记忆写、可确定性重放、P99 与记忆规模解耦；再巩固攻击被定义 318 阻断，攻击面迁移到可审计的离线窗口。

## 8. 本轮最大风险

**一句话**：EPOCH-RAS 把「信什么」交给了记忆与路线图，但二者可能构成**自我确认的回音室**——检索用系统自己偏置过的历史、校准用同一批历史、路线图的验收又用系统自己产生的审计流，于是「记忆只回忆它已经相信的东西，门只为它已经相信的东西盖章」，系统会越来越自信地重复同一个错误；**最危险的不是记错，而是错误被记忆反复证实、再被路线图正式认证**。

**次级风险与缓解**：检索放大投毒（机制门 + 来源配额 + 引理 21）；再巩固劫持（只读回忆 + 离线巩固，定义 318 / 定理 19）；检索偏差–方差陷阱（RRG 双约束 + 引理 19 的 k*）；门控自证 / 评估污染（审计流隔离 + E314 + 独立门控审计）；记忆无限增长击穿实时（容量上界 + 遗忘 + 引理 22）。
