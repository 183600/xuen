### 第 6 轮灵感驱动研究记录

**灵感词**：动作空间、安全交互

**继承关系**：第 5 轮 CADVS-v5（IP-493~496）把 v4 的「规则提议 + 七硬门」升级为「认证的生成式执行」（CGE）：流匹配提议 π_θ^FM、嵌入记忆固化 LMEM-v2、情感调制 FAMK、EFA-v5 级联选证，并证明定理 5（调制单调）、6（证书不变性/提议无关）、7（固化有界）、8（七锚完备保持），执行集 Exec_CADVS-v5 ⊆ Exec_CADVS-v4 ⊆ … ⊆ Exec_v29。本轮不推翻 v5，而是补 v5 的三个结构性短板：(a) 证书只落在**名义轨迹点**上，真实 1 kHz 控制器有跟踪误差、交互有扰动，证书与执行之间存在「点对点间隙」，实际轨迹可能越界而名义仍「已认证」；(b) 动作空间是**隐式**的（=整条轨迹空间），缺少从「已认证轨迹」到「控制层可执行动作集」的显式映射，控制器可能取到计划外但「接近」的动作；(c) 交互是**单边**建模（人只是 HICK veto / FAMK 调制 / 扰动），没有「人-机动作空间耦合」下的联合安全保证。两个灵感词统一为主题「认证的动作空间与安全交互」（Certified Action Space & Safe Interaction），形成 CADVS-v6（IP-497~500）。本轮自律：**硬门数量仍不增**（维持七门），改走「点证书 → 集合证书（管）+ 联合安全集（契约）+ 动作集投影」三条非侵入路径，执行集嵌套升级为 Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ … ⊆ Exec_v29。

**直觉与动机**：

1. **动作空间 → 从「认证一个点」升级为「认证一个管」（集合证书），闭合证书-执行间隙**。v5 的 kc_i(x) 只对名义轨迹 x 判真，但真实执行 x̃ = x + e，e 来自跟踪误差与交互扰动。直觉：只要给名义轨迹留出与 Lipschitz 常数相匹配的**安全边际**，并把「管」（可达误差集 E）一起送进七门做最坏情形评估，就能把「名义合规」变成「所有可实现轨迹都合规」。形式化：CATK 用辅助反馈 K 把误差动力学 e_{t+1}=(A+BK)e_t+w_t 收敛到不变椭球 E（离散 Lyapunov），鲁棒门 kc_i^rob(x,T)=1[s_i(x)−Lip_i·ε ≥ τ_i]；只要 ρ_i := s_i(x)−τ_i ≥ Lip_i·ε，则 ∀x̃∈T 门仍成立（**定理 9 管可靠性**）。再由管反推控制层**可执行动作集** A_t={a : f(x_t,a)⊕E ⊆ T_{t+1}}，只要 a∈A_t，下一时刻实测状态仍在管内（**定理 10 动作空间可达性/递归可行**）。这把 v5 的「点证书」推广为「集合证书」，且集合证书更强（更保守），执行集只会更小——嵌套保持。

2. **安全交互 → 从「单边 veto/调制」升级为「双边动作空间契约」**。v5 的人因锚只做单边否决（HICK veto）与单边收紧（FAMK γ），本质是把人当「外部约束/扰动」。但真实的安全交互是**双方动作空间的耦合**：机器人让出多少、人进入多少、接触功率如何交换。直觉：把交互写成一份**契约** C=(A_H, A_R, h, E_tank)——人的动作空间 A_H 有界（速度/力/能量）、机器人动作空间 A_R 受管约束、联合安全集 S={h(x)≥0 ∧ dist≥d_min ∧ 交换能量≤E_max}，用控制屏障函数（CBF）保证 S 前向不变，用能量罐（energy tank）保证端口无源性（不向人注入净能量）。**定理 11（交互契约前向不变）**：若 h 对 ∀a_H∈A_H 是有效 CBF 且能量罐非负，则 S 前向不变、无单边违约。诚实边界：保证**条件于** a_H∈A_H 与人的端口无源——人一旦越出 A_H，只能检测不能结构性兜底。

3. **动作空间仲裁 → 共享控制下的投影与 fail-closed 退让**。共享控制里人和机器人同时给动作，仲裁器把合成动作投影到 A_t ∩ A_R ∩ CBF 可行集；交集为空时**不是硬闯也不是静默冻结**，而是退让（retreat）到最近的安全点并升级接管请求（handover）。这把「动作空间」从被动约束变成主动仲裁对象，同时把 v5-R58「调制致执行集塌缩」从纯保守改为「有方向的退让 + 可检测的死锁」。

**关键洞见**：v5 回答「任意生成器如何不改变证书边界」；v6 回答「当执行有误差、交互是双边时，证书如何从点扩张到集合而不失可靠性」。七硬门 kc_evidence_forged_v4 记号原样复用；本轮新增只有：鲁棒门 kc_i^rob（Lipschitz 边际）、管 T 与动作集 A_t、契约 C 与联合安全集 S、软评分 ECS_v6 = ECS_v5·η_tube·η_contract。执行集 Exec_CADVS-v6 ⊆ Exec_CADVS-v5 由「同门 + 鲁棒边际 > 0 + 契约约束 + 动作集投影」四重保证。同时正面回应 v5-R58（调制致执行集塌缩）：把「塌缩」从纯保守改为「有方向的退让 + 可检测的死锁」。

**形式化目标（增量）**：
1. 误差动力学与不变椭球：e_{t+1}=(A+BK)e_t+w_t，w∈W；E={e:e^TP^{-1}e≤1}，P 解离散 Lyapunov；管 T_t = x_t ⊕ E，半径 ε=√λ_max(P)。
2. 鲁棒门：kc_i^rob(x,T;τ_i^6)=1[min_{x̃∈T}s_i(x̃)≥τ_i^6]=1[s_i(x)−Lip_i·ε≥τ_i^6]，τ_i^6=γ_i·τ_i^5（继承调制，只紧）。
3. 动作集：A_t={a:x_{t+1}=f(x_t,a), x_{t+1}⊕E⊆T_{t+1}}；投影 Π_{A_t∩A_R∩CBF}。
4. 交互契约：C=(A_H,A_R,h,E_tank)；S={h≥0∧dist≥d_min∧E≤E_max}；越界检测器 + 退让算子。
5. 定理 9（管可靠性/间隙闭合）、定理 10（动作空间可达性）、定理 11（交互契约前向不变）、定理 12（嵌套与组合退化）。
6. Exec_CADVS-v6 = {x∈supp(π_FM) : ∧_i kc_i^rob(x,T;τ_i^6)=1 ∧ contract_sat(x)} ⊆ Exec_CADVS-v5。

**本轮最大风险**：**鲁棒管与交互契约的前提外推**——v6 的全部保证都条件于「扰动/跟踪误差界 ε 成立」与「人类动作落在 A_H 内」这两个开放世界中最易被突破的假设，而管式认证把 v5 的逐点显式检查换成集合级隐式假设：任一界被悄悄突破（未建模接触、打滑、突发人动作）都会让整条管的证书同时失效、系统却仍自报「已认证」，鲁棒性反而制造比 v5 更危险的虚假安全；且过度保守的管使 A_t 为空时只能退让/冻结，而冻结本身在某些场景即是安全危害。

## 2. 关键算法骨架

### IP-497 CATK：认证动作管核（离线不变椭球；在线 O(1) 成员判定）

```python
@dataclass
class CertifiedActionTubeKernel:
    """CATK：把 v5 的点证书升级为集合证书（管）。
    定理 9：鲁棒边际 ρ_i ≥ Lip_i·ε ⇒ 管上所有可实现轨迹仍过门。
    定理 10：a∈A_t ⇒ 下一时刻实测状态仍在 T_{t+1}。"""
    A: np.ndarray; B: np.ndarray
    K: np.ndarray                  # 辅助反馈，使 A+BK 稳定
    W: Ellipsoid                   # 有界扰动集
    P: np.ndarray = None           # 不变椭球形状（离线解离散 Lyapunov）

    def build_tube(self, x_nom: Trajectory) -> Tube:
        # 离线：P 解 (A+BK)^T P (A+BK) - P + Q = 0，E 关于 W 不变
        # 在线：T_t = x_nom_t ⊕ E，成员判定 e^T P^{-1} e ≤ 1，O(1)
        eps = float(np.sqrt(np.max(np.linalg.eigvalsh(self.P))))
        return Tube(nominal=x_nom, E=self.E, eps=eps)

    def robust_gate(self, score_fn, lip: float, x_nom, eps: float, tau: float) -> bool:
        # 定理 9：s(x) - Lip*eps >= tau  ⇒  min_{x~ in T} s(x~) >= tau
        return score_fn(x_nom) - lip * eps >= tau

    def admissible_actions(self, x_t, T_next: Tube, action_set) -> ActionSet:
        # A_t = {a : f(x_t,a) ⊕ E ⊆ T_{t+1}}；椭球/多面体包含判定
        # 递归可行：A_t 非空则管前向不变（定理 10）
        return {a for a in action_set if self._reach_subset(f(x_t, a), T_next)}
```

### IP-499 ASPK：动作空间投影与仲裁核（共享控制）

```python
@dataclass
class ActionSpaceProjectionKernel:
    """ASPK：共享控制仲裁：合成动作 → 投影到 A_t ∩ A_R ∩ CBF 可行集。"""
    def arbitrate(self, a_h, a_r, A_t, A_R, cbf) -> tuple[Action | None, str]:
        a_mix = blend(a_h, a_r)               # 共享控制混合（权重由接管等级定）
        feas = A_t & A_R & cbf.feasible_set()
        if not feas.is_empty():
            return project(a_mix, feas), 'ARBITRATED'
        return None, 'EMPTY_SET_RETREAT'      # 交给 ISCK.retreat + handover

    isck: InteractionSafetyContractKernel
    aspk: ActionSpaceProjectionKernel
    v5: EvidenceForgingAssemblerV5

    def select(self, x0_state, t_now, rule_id, context, human_obs
               ) -> tuple[bool, Trajectory | None, str]:
        ok5, x, why = self.v5.select(x0_state, t_now, rule_id, context)
        if not ok5:
            return False, None, why
        T = self.catk.build_tube(x)
        # 级联第 4 层：鲁棒门（复用 v5 七门得分 + Lipschitz 边际，定理 9）
        for i, (score_fn, lip, tau) in self.robust_gates.items():
            if not self.catk.robust_gate(score_fn, lip, x, T.eps, tau):
                return False, None, f'TUBE_REJECT_{i}'
        # 级联第 5 层：交互契约（CBF + 能量罐 + 越界检测，定理 11）
        sat, why_c = self.isck.contract_sat(x0_state, x, human_obs)
        if not sat:
            return False, self.isck.retreat(x0_state), f'CONTRACT_{why_c}'
        # 级联第 6 层：动作集投影（共享控制仲裁，定理 10）
        a, why_a = self.aspk.arbitrate(human_obs.action, x.action(0), 
                                       self.catk.admissible_actions(x0_state, T, self.A_R),
                                       self.isck.A_R, self.isck.h)
        if a is None:
            return False, self.isck.retreat(x0_state), 'EMPTY_SET_RETREAT'
        return True, x, 'FORGED_ROBUST_INTERACTION'

    def ecs_v6(self, ..., n_flow, s_emo, tube_vol, contract_margin) -> float:
        eta_tube = math.exp(-self.lam_tube * tube_vol)          # 管越胖越不确信
        eta_contract = sigmoid(contract_margin / self.b_contract)
        return self.v5.ecs_v5(..., n_flow, s_emo) * eta_tube * eta_contract
```

### 集成流水线（v5 → v6）

```
离线/慢时域：
  不变椭球：辨识 (A,B) + 扰动集 W ──▶ 离散 Lyapunov ──▶ P, E, ε（版本化）
  Lipschitz 界：各门得分 s_i 的局部/全局 Lip_i 估计 ──▶ 鲁棒边际表
  契约标定：A_H（人动作空间先验）、h、d_min、E_max、能量罐初值
  固化（继承 v5）：铸证片段 ──▶ 证书过滤 ──▶ DP-SGD + KL 正则 ──▶ θ_FM
       ──▶ 回归门测试 + 红队 + 「管/契约回归」──▶ 通过才上线

在线准入（异步，秒级）：
  v5 全流程（FAMK → FMPP → 廉价门 → VACK → BCK 预览）
       └─ 产出候选 x ──▶ 管 T=x⊕E ──▶ 鲁棒门（s_i−Lip_i·ε≥τ_i^6）
            ──▶ 契约（CBF-QP 可行 ∧ 能量罐≥0 ∧ 人在 A_H）
            ──▶ 动作集投影（A_t∩A_R∩CBF）
            ──▶ 任一失败：退让 + 接管请求（fail-closed，非静默冻结）

在线控制环（目标 < 0.6 ms）：
  每周期：EEK(kc_ee) + BCK（事件触发）+ 动作投影 Π_{A_t}（O(n_a)）
  证书消费：τ^6=γ·τ^5 预计算；管成员判定 O(1)；CBF-QP 仅事件触发（~10%）
```

## 4. 正确性论证（增量更新）

### 引理 45（门得分的 Lipschitz 界与鲁棒边际）

**陈述**：若各门得分 s_i 在管 T 上局部 Lip_i-Lipschitz，则 min_{x̃∈T} s_i(x̃) ≥ s_i(x) − Lip_i·ε。因此鲁棒门 kc_i^rob 是「管上最坏情形过门」的**充分**条件（非必要，可能保守）。∎

### 引理 46（不变椭球的存在性与半径界）

**陈述**：若 (A+BK) Schur 稳定，则对任意正定 Q 存在唯一 P≻0 解离散 Lyapunov 方程；取 E 为关于 W 的鲁棒正不变集，其半径 ε=√λ_max(P) 满足 ε ≤ √(λ_max(P)/λ_min(Q))·sup_{w∈W}‖w‖ 的量级界。W 有界是前提（无界扰动无有限管）。∎

### 定理 v6（鲁棒动作空间与安全交互，总装）

**陈述**：在 v5 假设 (B1)~(B7) 及新增 (B8) 误差界 ε 成立、(B9) 人动作 a_H∈A_H 且端口无源下：
(i) 管可靠性：ρ_i ≥ Lip_i·ε ⇒ 所有 x̃∈T 过门（定理 9）；
(ii) 动作空间可达：a∈A_t ⇒ 实测状态留在管（定理 10）；
(iii) 契约前向不变：CBF 可行 + 能量罐非负 ⇒ S 不变、无单边违约（定理 11）；
(iv) 嵌套：Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ … ⊆ Exec_v29，ε→0 且 A_H 无界时精确退化 v5（定理 12）；
(v) 七锚完备性保持（继承定理 8，门集合不变）。

**证明**：(i) 引理 45；(ii) 可达集定义 + 归纳；(iii) CBF + passivity；(iv) 子集约束；(v) 门集合不变 + 只紧。∎

**诚实声明**：(B8) ε 依赖线性化与扰动界，未建模接触/打滑会破坏它且**静默**（R60）；(B9) 人的有界性无法强制，越界只能检测（R62）；管越保守越可能 A_t=∅ → 退让/死锁（R61）；CBF-QP 在非凸安全集上可能不可行/超时（R63）；鲁棒化叠加 v5 调制会使执行集过度收缩（R65）；v5-R57 固化自指回路仍未解决。

## 7. 本轮最大风险（最终确认）

**一句话**：**鲁棒管与交互契约的前提外推**——v6 的全部保证都条件于「扰动/跟踪误差界 ε 成立」与「人类动作落在 A_H 内」这两个开放世界中最易被突破的假设，而管式认证把 v5 的逐点显式检查换成集合级隐式假设：任一界被悄悄突破（未建模接触、打滑、突发人动作）都会让整条管的证书同时失效、系统却仍自报「已认证」，鲁棒性反而制造比 v5 更危险的虚假安全；且过度保守的管使 A_t 为空时只能退让/冻结，而冻结本身在某些场景即是安全危害。
