### 第 1 轮灵感驱动研究记录（承接 SRC-USC v25）

**灵感词**：运动学、演示方案

**直觉与动机**：
现有 SRC-USC v25 已把「语义-重构-协同」纳入七证准入链，但存在两个结构性缺口：

1. **可执行性缺口**：证书链验证的是「任务是否语义正确、协同是否一致」，却没有验证「这些计划在给定本体上是否运动学可达、可执行」。一个语义完美、协同一致的计划，可能因目标位姿超出工作空间、接近奇异、违反关节速度/加速度约束而根本无法执行。运动学是可执行性的物理地基，是把任务空间计划投影为关节空间轨迹的「存在性算子」。
2. **可检验性缺口**：七证体系越叠越厚，却缺少「如何让人相信证书为真」的消费协议。没有可复现、可审计、统计有效的演示方案，证书只是内部断言。演示方案应被形式化为证书的「可证伪消费协议」，而不是事后挑选的成功视频。

核心洞见：**运动学证书把抽象计划投影为物理可执行轨迹（存在性证书）；演示方案把证书谓词编译为可观测、可复现、可审计的证伪断言（可检验性证书）。前者回答「能不能动」，后者回答「凭什么信」。**

**形式化目标**：
1. 定义运动学可行性证书（KFC）：工作空间可达性 ∀t ∃q_t∈Q_free∩Q_lim, ‖FK(q_t)−p_t‖≤ε_ik 且轨迹连续；奇异性裕度 σ_min(J(q_t))≥ε_σ ∧ κ(J(q_t))≤κ_max；关节速度/加速度约束 |q̇|≤q̇_max ∧ |q̈|≤q̈_max；运动学模型校准误差 ‖FK_model−FK_real‖≤ε_cal，并用三角不等式把模型内可达性提升为真机可达性。
2. 定义演示方案证书（DPC）：可复现清单（代码/环境/数据/随机种子哈希）；统计验收（Clopper–Pearson 单侧下界 ≥1−α，零失败规则样本量 n≥ln γ/ln(1−α)）；场景覆盖（演示集 D 对运行包络 O 的 ε-net 覆盖 + 每个已知风险的负向故障注入）；审计哈希链与第三方可重放。
3. 定义证书→演示断言编译器（CDC）：把每个证书谓词 P 编译为断言 A(P)=(场景, 可观测量, 阈值, 统计规则)，并证明其单侧可靠性 P⇒A(P)，从而 ¬A(P)⇒¬P；明确「演示只能证伪、不能证明」的认识论边界。
4. 构建运动学-演示统一准入门（KD-UC）：SRC-USC ∪ KFC ∪ DPC 九证一体，Exec_v26 = Exec_v25 ∩ Fil_kin ∩ Fil_demo ⊆ Exec_v25。
5. 证明单调退化链在「运动学不可达/近奇异/超限/校准超差」与「演示不可复现/统计不达标/覆盖不足/审计失败」下的保持性，并给出两条新的降级路径。

```python
# ============================================================
# IP-448 Kinematic Feasibility Certificate (KFC) — 运动学可行性证书
# ============================================================
@dataclass
class KinematicFeasibilityCertificate:
    """可达性 + 奇异性 + 关节运动学限 + 模型校准 四重证书"""
    q_plan: Tensor                       # [T, n] 关节轨迹（上游 IK 生成）
    poses: Tensor                        # [T, 7] 期望末端位姿 (pos+quat)
    robot: 'KinematicModel'              # FK/IK/Jacobian/碰撞/限位接口
    eps_ik: float = 1e-3                 # IK 残差容差 (m/rad)
    eps_sigma: float = 0.05              # 最小奇异值下界
    kappa_max: float = 50.0              # 条件数上界
    eps_cal: float = 1e-3                # 模型校准误差上界 (m)
    joint_margin: float = 0.02           # 关节限位安全裕度 (rad)
    qd_max: Optional[Tensor] = None      # [n] 关节速度上限
    qdd_max: Optional[Tensor] = None     # [n] 关节加速度上限

    def verify_reachability(self) -> bool:
        """∀t: q_plan[t]∈Q_free∩Q_lim ∧ ‖FK(q_plan[t])−p_t‖≤ε_ik"""
        T = self.poses.shape[0]
        if self.q_plan.shape[0] != T:
            return False
        for t in range(T):
            q_t = self.q_plan[t]
            if not self.robot.within_limits(q_t, margin=self.joint_margin):
                return False
            if not self.robot.collision_free(q_t):
                return False
            if torch.norm(self.robot.fk(q_t) - self.poses[t]) > self.eps_ik:
                # 计划构型不可达时尝试一次 IK 兜底（存在性检查）
                q_alt = self.robot.ik(self.poses[t], seed=q_t)
                if q_alt is None:
                    return False
                if torch.norm(self.robot.fk(q_alt) - self.poses[t]) > self.eps_ik:
                    return False
        return True

    def verify_singularity(self) -> bool:
        """∀t: σ_min(J(q_t)) ≥ ε_σ ∧ κ(J(q_t)) ≤ κ_max"""
        for t in range(self.q_plan.shape[0]):
            J = self.robot.jacobian(self.q_plan[t])       # [m, n]
            s = torch.linalg.svdvals(J)
            s_min = s[-1].item()
            s_max = s[0].item()
            if s_min < self.eps_sigma:
                return False
            if s_max / max(s_min, 1e-12) > self.kappa_max:
                return False
        return True

    def verify_kinematic_limits(self) -> bool:
        """|q̇|≤q̇_max ∧ |q̈|≤q̈_max（有限差分，边界单侧差分）"""
        if self.qd_max is None or self.qdd_max is None:
            return False
        qd = self._finite_diff(self.q_plan, order=1)
        qdd = self._finite_diff(self.q_plan, order=2)
        return bool((qd.abs() <= self.qd_max).all() and
                    (qdd.abs() <= self.qdd_max).all())

    def verify_model_calibration(self, calib_set: list) -> bool:
        """校准集上 ‖FK_model(q)−p_real‖≤ε_cal ∧ ‖J_model−J_real‖₂≤ε_cal"""
        if not calib_set:
            return False
        for q, p_real, J_real in calib_set:
            if torch.norm(self.robot.fk(q) - p_real) > self.eps_cal:
                return False
            J_model = self.robot.jacobian(q)
            if torch.linalg.norm(J_model - J_real, ord=2) > self.eps_cal:
                return False
        return True

    def verify_all(self, calib_set: list) -> bool:
        return (self.verify_reachability() and
                self.verify_singularity() and
                self.verify_kinematic_limits() and
                self.verify_model_calibration(calib_set))

    def _finite_diff(self, q: Tensor, order: int) -> Tensor:
        T = q.shape[0]
        if order == 1:
            if T < 2:
                return torch.zeros_like(q)
            if T == 2:
                return (q[1] - q[0]).unsqueeze(0).repeat(2, 1)
            inner = (q[2:] - q[:-2]) / 2.0
            return torch.cat([(q[1] - q[0]).unsqueeze(0), inner,
                              (q[-1] - q[-2]).unsqueeze(0)], dim=0)
        if T < 3:
            return torch.zeros_like(q)
        inner = q[2:] - 2 * q[1:-1] + q[:-2]
        return torch.cat([inner[:1], inner, inner[-1:]], dim=0)

# IP-449 Demonstration Protocol Certificate (DPC) — 演示方案证书
# ============================================================
@dataclass
class Demo:
    scenario_id: str
    feature: Tensor                 # 场景特征（地形/负载/光照/遮挡/接触刚度...）
    success: bool
    predicate_id: str = ''
    injected_risks: set = field(default_factory=set)


@dataclass
class Manifest:
    code_hash: str
    env_hash: str
    data_hash: str
    seed: int
    expected_root: str


@dataclass
class DemonstrationProtocolCertificate:
    """可复现 + 统计验收 + 场景/故障覆盖 + 审计链 四重证书"""
    demos: list['Demo']
    manifest: 'Manifest'
    claimed_alpha: float = 0.05     # 声称成功率下界 1-α
    confidence: float = 0.95        # 置信水平 1-γ
    eps_cov: float = 0.10           # 场景覆盖半径
    chain: 'HashChain' = None

    def verify_reproducibility(self, current_env_hash: str) -> bool:
        """清单哈希一致 ∧ 同种子两次重放哈希相同"""
        if self.manifest is None:
            return False
        if self.manifest.env_hash != current_env_hash:
            return False
        if self.manifest.code_hash != hash_tree('.'):
            return False
        h1 = self._replay_hash(self.manifest.seed)
        h2 = self._replay_hash(self.manifest.seed)
        return h1 == h2

    def verify_statistical_acceptance(self) -> bool:
        """Clopper–Pearson 单侧下界 L(k,n) ≥ 1−α"""
        n = len(self.demos)
        if n == 0:
            return False
        k = sum(1 for d in self.demos if d.success)
        gamma = 1.0 - self.confidence
        lower = 0.0 if k == 0 else float(beta.ppf(gamma, k, n - k + 1))
        return lower >= 1.0 - self.claimed_alpha

    def required_sample_size(self) -> int:
        """零失败规则 n ≥ ln γ / ln(1−α)"""
        gamma = 1.0 - self.confidence
        return int(math.ceil(math.log(gamma) / math.log(1.0 - self.claimed_alpha)))

    def verify_scenario_coverage(self, envelope: 'OperatingEnvelope') -> bool:
        """(1) ε-net 覆盖运行包络；(2) 每个已知风险至少一次负向注入"""
        for f in envelope.sample_features():
            d_min = min(torch.norm(f - d.feature) for d in self.demos)
            if d_min > self.eps_cov:
                return False
        for r in envelope.risks:
            if not any(r in d.injected_risks for d in self.demos):
                return False
        return True

    def verify_audit_chain(self) -> bool:
        return (self.chain is not None and
                self.chain.verify() and
                self.chain.root() == self.manifest.expected_root)

    def verify_all(self, envelope: 'OperatingEnvelope',
                   current_env_hash: str) -> bool:
        return (self.verify_reproducibility(current_env_hash) and
                self.verify_statistical_acceptance() and
                self.verify_scenario_coverage(envelope) and
                self.verify_audit_chain())

    def _replay_hash(self, seed: int) -> str:
        """在沙箱中按清单重放全部演示，返回运行日志 Merkle 根"""
        logs = replay_suite(self.demos, seed=seed,
                            env=self.manifest.env_hash)
        return merkle_root([h(log) for log in logs])

# IP-450 Certificate-to-Demo Compiler (CDC) — 证书-演示编译器
# ============================================================
@dataclass
class DemoAssertion:
    predicate_id: str
    scenario: 'Scenario'
    observable: Callable
    threshold: float
    direction: str                  # 'ge'（越大越好）/ 'le'（越小越好）
    statistical_rule: str = 'clopper_pearson'
    proof_tag: str = ''             # P⇒A(P) 的证明义务标识


class CertificateToDemoCompiler:
    """把证书谓词 P 编译为可观测断言 A(P)，并承担 P⇒A(P) 的证明义务"""

    def __init__(self):
        self._registry = {}         # (cert_type, predicate_name) -> builder

    def register(self, cert_type, predicate_name, builder):
        self._registry[(cert_type, predicate_name)] = builder

    def compile(self, cert) -> list['DemoAssertion']:
        out = []
        for (ct, pname), builder in self._registry.items():
            if isinstance(cert, ct) and getattr(cert, f'has_{pname}',
                                                 lambda: True)():
                out.append(builder(cert))
        return out

    def covers(self, assertions: list['DemoAssertion'],
               demos: list['Demo']) -> bool:
        """每个证书谓词都必须有一个通过的演示断言（覆盖性）"""
        required = {a.predicate_id for a in assertions}
        observed = {d.predicate_id for d in demos if d.success}
        return required.issubset(observed)

    def falsified(self, assertion: 'DemoAssertion', value: float) -> bool:
        """单侧可证伪判定：¬A(P) 即谓词被证伪"""
        if assertion.direction == 'ge':
            return value < assertion.threshold
        return value > assertion.threshold

# IP-451 KD-UC 运动学-演示统一准入门
# ============================================================
@dataclass
class KinematicDemonstrationUnifiedCertificate:
    src_usc: 'SemanticReconfigCoordUnifiedCertificate'  # v25 七证
    kfc: KinematicFeasibilityCertificate
    dpc: DemonstrationProtocolCertificate
    compiler: CertificateToDemoCompiler

    def admits(self, multi_plan: 'MultiRobotPlan', sensor_data: dict,
               envelope: 'OperatingEnvelope', current_env_hash: str) -> bool:
        # 1. v25 七证
        if not self.src_usc.admits(
                multi_plan, sensor_data,
                gt_entities=sensor_data.get('gt_entities'),
                queries=sensor_data.get('queries'),
                retrieved=sensor_data.get('retrieved')):
            return False
        # 2. 运动学可行性（每条机器人轨迹）
        for i in range(len(multi_plan.robot_plans)):
            if not self.kfc[i].verify_all(sensor_data['calib_set'][i]):
                return False
        # 3. 演示协议（可复现/统计/覆盖/审计）
        if not self.dpc.verify_all(envelope, current_env_hash):
            return False
        # 4. 证书→演示断言覆盖性（每个 v25 谓词都要有通过的演示）
        assertions = self.compiler.compile(self.src_usc)
        if not self.compiler.covers(assertions, self.dpc.demos):
            return False
        return True

class KinematicDemoPipeline(MultiRobotPerceptionComplianceEnergyPipeline):
    def __init__(self, config: dict):
        super().__init__(config)
        self.kd_uc = KinematicDemonstrationUnifiedCertificate(
            src_usc=self.src_usc,
            kfc=config['kfc_list'],
            dpc=config['dpc'],
            compiler=config['compiler'],
        )
        self.ipam.register_module("kfc", ["IP-448"],
            ["reachability", "singularity_margin", "kinematic_limits", "model_calibration"])
        self.ipam.register_module("dpc", ["IP-449"],
            ["reproducible_manifest", "clopper_pearson", "scenario_coverage", "audit_hash_chain"])
        self.ipam.register_module("cdc", ["IP-450"],
            ["cert_to_demo_compilation", "falsification_soundness"])
        self.ipam.register_module("kd_uc", ["IP-451"],
            ["nine_certificate_gate", "kinematic_demo_monotonic_chain"])

    def step(self, multi_sensor_data: dict, cloud_update=None,
             envelope=None, current_env_hash=None) -> tuple[bool, dict]:
        admitted, info = super().step(multi_sensor_data, cloud_update)
        if not admitted:
            return False, info
        multi_plan = info['multi_plan']
        if not self.kd_uc.admits(multi_plan, multi_sensor_data,
                                 envelope, current_env_hash):
            return False, {**info, 'reason': 'KD_UC_reject',
                           'kfc_ok': [c.verify_all(cal)
                                      for c, cal in zip(self.kd_uc.kfc,
                                                        multi_sensor_data['calib_set'])],
                           'dpc_ok': self.kd_uc.dpc.verify_all(envelope, current_env_hash)}
        return True, {**info,
                      'kin': {'sigma_min': self._min_sigma(multi_plan),
                              'calib_err': self._calib_err(multi_sensor_data)},
                      'demo': {'n': len(self.kd_uc.dpc.demos),
                               'required_n': self.kd_uc.dpc.required_sample_size()}}

    def _min_sigma(self, plan) -> float:
        return min(float(torch.linalg.svdvals(self.kd_uc.kfc[i].robot.jacobian(
            self.kd_uc.kfc[i].q_plan[t]))[-1])
            for i in range(len(self.kd_uc.kfc))
            for t in range(self.kd_uc.kfc[i].q_plan.shape[0]))

    def _calib_err(self, data) -> float:
        return max(float(torch.norm(self.kd_uc.kfc[i].robot.fk(q) - p))
                   for i, cal in enumerate(data['calib_set'])
                   for q, p, _ in cal)


# 辅助函数
def hash_tree(path: str) -> str:
    """对代码/配置目录做确定性 Merkle 哈希（忽略时间戳/缓存）"""
    files = sorted(f for f in glob.glob(f'{path}/**/*', recursive=True)
                   if os.path.isfile(f) and '.git' not in f and '__pycache__' not in f)
    return merkle_root([h(open(f, 'rb').read()) for f in files])


def merkle_root(leaves: list[str]) -> str:
    layer = leaves[:]
    if not layer:
        return h(b'')
    while len(layer) > 1:
        if len(layer) % 2 == 1:
            layer.append(layer[-1])
        layer = [h((layer[i] + layer[i + 1]).encode()) for i in range(0, len(layer), 2)]
    return layer[0]
```

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 |

## 3. 正确性论证（增量）

### 引理 13（运动学可行性证书的四重保证与模型迁移）
**陈述**：`KFC.verify_all(calib_set)=True` ⇒ 在模型 M 下：
(1) 每个期望位姿由限位内、无碰撞、IK 残差 ≤ε_ik 的构型实现；
(2) ∀t, σ_min(J(q_t))≥ε_σ ∧ κ(J(q_t))≤κ_max；
(3) 关节速度/加速度在界内；
(4) 校准集上 FK 与雅可比误差 ≤ε_cal。
进一步，若「校准误差上界在整个运行域可迁移」即 ∀q, ‖FK_M(q)−FK_R(q)‖≤ε_cal，则真机末端可达误差 ≤ ε_ik+ε_cal。

**证明**：
1. `verify_reachability` 逐位姿检查限位、碰撞、FK 残差，失败时以 IK 兜底做存在性复核，故 (1) 成立。
2. `verify_singularity` 直接对每时刻 J(q_t) 做 SVD，阈值比较即 (2)。
3. `verify_kinematic_limits` 用边界单侧、内部中心的有限差分构造 q̇、q̈，逐分量比较上限即 (3)。
4. `verify_model_calibration` 在校准集上比较 FK 与雅可比，即 (4)。
5. 真机误差：‖FK_R(q)−p‖ ≤ ‖FK_R(q)−FK_M(q)‖ + ‖FK_M(q)−p‖ ≤ ε_cal + ε_ik（三角不等式）。
∎

### 引理 14（演示方案证书的四重保证）
**陈述**：`DPC.verify_all(envelope, env_hash)=True` ⇒
(1) 清单哈希与当前环境一致且同种子两次重放哈希相同；
(2) Clopper–Pearson 单侧下界 L(k,n) ≥ 1−α；
(3) 演示集对运行包络 ε-net 覆盖，且每个已知风险至少一次负向注入；
(4) 哈希链可验证且根等于清单承诺根。

**证明**：
1. `verify_reproducibility` 比较 `env_hash`、`code_hash`，并要求 `_replay_hash` 两次一致，故 (1)。
2. Clopper–Pearson 下界满足 ℙ(p ≥ L(k,n)) ≥ 1−γ（p 为真实成功率）；L≥1−α 即 (2)。零失败时 n≥ln γ/ln(1−α) 由 (1−α)^n≤γ 推出。
3. `verify_scenario_coverage` 对包络采样点做最近邻半径判定（ε-net 定义），并遍历风险集合检查注入标签，故 (3)。
4. `verify_audit_chain` 校验链式哈希与承诺根，篡改任一日志都会改变根，故 (4)。
∎

### 引理 15（证书→演示编译器的单侧可靠性/可证伪性）
**陈述**：若编译器对谓词 P 构造的断言满足 P⇒A(P)（A(P) 是 P 的必要可观测后果），则 ¬A(P)⇒¬P；反之 A(P) 成立不蕴含 P 成立。

**证明**：
1. P⇒A(P) 的逆否命题即 ¬A(P)⇒¬P。
2. 反向蕴含 A(P)⇒P 是「肯定后件」谬误：A(P) 只是 P 的一个必要观测投影，可能有其他原因使 A(P) 成立。故演示只能证伪、不能证明。
3. 该边界正是本方案把 IP-449 命名为「演示协议」而非「演示证明」的原因，也是 R17 的根源。
∎

### 引理 16（v26 单调退化链）
**陈述**：Exec_v26 = Exec_v25 ∩ Fil_kin ∩ Fil_demo ⊆ Exec_v25 ⊆ … ⊆ Exec_v18 恒成立。

**证明**：交集对集合单调。新增两条退化路径：
- 运动学不可达/近奇异/超限/校准超差 → KFC=false → KD-UC 拒证 → 退回 Exec_v25（保留语义-协同计划，但降级为重规划/保守构型/停位，禁止执行原运动轨迹）。
- 演示不可复现/统计不达标/覆盖不足/审计失败 → DPC=false → KD-UC 拒证 → 退回「离线已验证配置」，禁止在线部署新计划。
- 组合失效取交集，单调性保持。∎

### 定理（KD-UC 九证准入门完备性）
**陈述**：对任意多机计划 Π 与演示协议 𝒟，`KD-UC.admits(Π,𝒟)=True` ⟺ Π 同时满足 v25 七证、KFC 四重、DPC 四重，且每个 v25 证书谓词都有通过的演示断言。

**证明**：由 `admits` 的四段合取（v25、KFC、DPC、CDC 覆盖性）直接给出；必要性为任一条件缺失即拒证，充分性由引理 13–16 保证运动学可执行、演示可检验、单调链不断裂。∎

## 6. 本轮最大风险（最终确认）

**一句话**：**运动学证书（KFC）只在标定模型上成立、其校准误差向整个运行域的迁移是无法被有限校准集证明的假设；演示方案证书（DPC）又只能在有限场景分布上做单侧证伪而永远无法证明部署分布上的普遍命题——二者在「未建模接触/柔性 + 分布漂移 + 演示过拟合」叠加时可能同时通过，使 KD-UC 产生「证书剧场」式的虚假保证，恰好在最需要拦截的模型-现实鸿沟处失效。**
