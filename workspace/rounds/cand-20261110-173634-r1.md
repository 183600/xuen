# 第 47 轮（承接第 46 轮 v23；本轮灵感：课程学习 × 视觉语言动作模型） · Curriculum-VLA-Cert：课程难度场驱动的 VLA 动作先验与姿态证书对齐的自主性阶梯（五层架构 v11）

> 承接 v23 Memory-Safety-Voice。v23 把记忆检索、语音分发、指令-姿态绑定接成闭环，但仍隐含假设 H5：**学习型策略（VLA）被当作单一能力等级的黑箱**，且证书/记忆/绑定函数的校准数据按 i.i.d. 采样，与真实任务的难度分布无关。UniBot 的目标是长程操作，VLA 能把「把杯子放进水槽」这类语言指令直接映射为动作块，但语言流畅性会掩盖几何错误；同时任务难度高度异质（空场景抓取 vs 透明容器叠放），同一套 α 预算在简单层浪费、在困难层不足。两个灵感词精确命中 H5：**课程学习**提供「按难度排序」的训练与部署统一原则，使证书校准和自主性升级都沿一条可验证的难度阶梯推进；**VLA**提供语言接地的动作先验，其潜变量不确定性恰可作为难度的自监督信号。耦合出新问题：**如何用 VLA 自身不确定性构造难度场与课程链，在每一阶上做分阶覆盖校准，并让课程闸门只在覆盖成立时把自主性从遥操作升级到 VLA 全自动；若课程覆盖了错误分布或 VLA 在课外样本上过度自信，自主性会在一阶看不见的分布缝隙上被错误提升，姿态证书静默失效**。

## 0. 直觉与动机

**灵感 1（课程学习 → 难度场与分阶证书）**
直觉：不是所有任务都值同样的安全预算。先定义任务切片 ξ=(任务, 场景, 物体, 语言) 上的难度场 h(ξ)，用「该切片下姿态证书的期望半径 + VLA 动作熵」度量。课程链 D_1 ≺ D_2 ≺ … ≺ D_K 要求 h 沿链近似单调。直觉上，证书应在每一阶单独校准而不是全局一个半径：简单阶可以给更宽证书却仍覆盖，困难阶必须给更保守的半径，否则全局覆盖被困难样本拉爆。关键新意：课程不仅是训练时的采样顺序，更是**证书覆盖的分配结构**。

**灵感 2（VLA → 语言接地的动作先验与自监督难度）**
直觉：VLA 的价值不是「直接执行」，而是给出语言条件的动作块 a_{t:t+k} 与接地目标 g_t（末端/物体/区域）。语言流畅 ≠ 几何正确，必须用对齐度 A_t=P(g_t∈P_t) 把语言意图投影到几何证书上。反过来，VLA 的动作熵 H(π_VLA) 与潜变量 z 的离散度是**无需人工标注的难度信号**：模型自己越犹豫，切片越可能难。于是课程难度可以自监督估计，把「课程学习」从人工排课变成 VLA 不确定性驱动。

**灵感 3（课程 × VLA → 测试时自主性阶梯）**
直觉：部署时也应「先易后难」。把自主性建模为等级 ℓ∈{0 遥操作, 1 共享, 2 VLA 辅助, 3 VLA 全自动}。只有当当前阶及更简单阶的覆盖证书在滑动窗口内成立、且对齐度达标，才允许升级；任一阶覆盖违约立即降级并回退到更保守等级。这把课程学习从离线训练扩展到**在线能力阶梯**：安全不是一次性证明，而是随着证据沿难度链积累而逐级解锁。

**耦合升级**：v11 在 v10 四层上把 L2 升级为「语义-动作层（VLA + 记忆 + 语音）」，L4 升级为「课程-数据闭环（课程采样器 + 护照）」，并新增 L5「自主性闸门（AGE）」。五层：根信任 / L1 几何证书 / L2 语义-动作 / L3 安全守卫 / L4 课程-数据 / L5 自主性闸门。

## 1. 形式化定义（增量：定义 59–63）

**定义 59（难度场与课程链）**
切片 ξ∈Ξ，姿态证书半径 rad(P_t)。难度
h(ξ)=E_{τ~ξ}[ rad(P_τ) ] + λ_H·E_{τ~ξ}[ H(π_VLA(·|o_τ,l_τ)) ]。
课程链 C={D_1,…,D_K}，D_k⊆Ξ，满足 k<j ⇒ h(D_k)≤h(D_j)+ε_mono。课程采样器按链顺序暴露 D_k。

**定义 60（VLA 动作先验与接地目标）**
VLA 策略 π_VLA(a_{t:t+k}, z_t | o_{≤t}, l)。动作熵 H_t=H(π_VLA(·|o_{≤t},l))。接地映射 G:(o,l)→g_t∈R^3（末端/物体/区域目标）。VLA 提议的动作块记为 A_t^{VLA}。

**定义 61（分阶覆盖证书与 α 分配）**
对阶 k 用独立校准集 D_k^{cal} 拟合共形半径 r_k，使
P_{τ~D_k}( |x̂_τ - x_τ| ≤ r_k ) ≥ 1-α_k，且 Σ_{k=1}^K α_k ≤ α。
**分阶一致性**：若每阶覆盖成立，则全课程并集覆盖 ≥ 1-α（union bound）。

**定义 62（VLA-证书对齐度）**
A_t = P( g_t ∈ P_t | o_{≤t}, l, m_t )，用校准的 grounding 误差模型估计。
对齐裕度 marg_t = dist(g_t, ∂P_t)/rad(P_t)。执行条件：A_t≥θ_align 且 marg_t≥0，否则触发语言澄清或安全回退。

**定义 63（课程闸门自主性策略）**
等级 ℓ_t∈{0,1,2,3}。升级条件（在滑动窗口 W 上）：
ℓ_t = min{ ℓ ≥ ℓ_{t-1} : ∀k≤ℓ, Coverage_k(W) ≥ 1-α_k 且 Alignment(W) ≥ θ_align 且能量租约 ℓ_e 有效 }。
降级：任一 Coverage_k(W)<1-α_k 或 Alignment<θ_align 或 ℓ_e 失效 ⇒ ℓ_t=ℓ_{t-1}-1（或直接 0），并 fail-closed 至对应保守策略。

## 2. 新增产出与既有 IP 升级

**IP-69 CVC（Curriculum-VLA Calibrator）**
- 难度场估计：用 VLA 动作熵 + 证书半径的历史分位数构造 h(ξ)
- 课程链构造：按 h 排序后做分位数分桶，得到 D_1…D_K 与单调性审计
- 分阶共形校准：每阶独立校准 r_k，α 预算按阶分配（困难阶多给）
- 课程护照：每阶记录校准集、覆盖率、OOD 比例、版本哈希

**IP-70 VLA-GA（VLA Grounding-Alignment Adapter）**
- 动作块解析：a_{t:t+k} → 末端轨迹与接地目标 g_t
- 对齐度估计：校准的 grounding 误差模型输出 A_t 与 marg_t
- 语言澄清回路：A_t<θ_align 时生成澄清问句（复用 VAD 槽位）
- 动作块级证书：把块内最坏时钟点纳入 P_t 的时域扩张

**IP-71 AGE（Autonomy Gating Escalator）**
- 自主性状态机：0/1/2/3 四档，升级需窗口证据，降级即时
- 覆盖窗口统计：每阶有效样本数 + Wilson 下界
- 降级与回退：任一违约 ⇒ 退一档并切到保守策略 / fail-closed
- 与 ECPS 联动：高阶默认需要更多深度/能量预算，低电量时主动降档

**既有 IP 升级**
IP-66 MVR：检索键加入 VLA 潜变量 z_t 与难度 h(ξ)，命中要求同阶或更简单阶
IP-67 VAD：新增澄清子流程，语音槽位可回填 VLA 接地目标
IP-68 SAB：绑定概率 B 乘以对齐度 A_t，θ_safe 随自主性档位收紧
IP-63 ECPS：困难阶自动提升深度/双目预算，降档时回收能量
IP-61 DCL：采集任务按课程链排序，优先补困难阶覆盖缺口
IP-62 CCA：新增课程偏置红队、课外 OOD 与 VLA 过度自信测试
IP-51 CAR：守卫增加自主性档位约束与对齐度约束
IP-45 总线：新增 curriculum-rung / vla-grounding / alignment-score / autonomy-level 话题

## 3. 算法骨架

离线：
1. 用 π_VLA 在未标注/半标注切片上估计动作熵，构造难度场 h
2. 按 h 分桶得课程链 D_1…D_K，审计单调性
3. 每阶独立共形校准 r_k，按困难度分配 α_k（Σα_k≤α）
4. 课程护照写盘；DCL 只对覆盖缺口最大的阶发采集任务

在线（每控制周期）：
1. 读 o_t, l, ℓ_e, 当前档位 ℓ_{t-1}
2. VLA 输出动作块与 z_t，VLA-GA 计算 g_t、A_t、marg_t
3. AGE 用窗口覆盖与对齐度决定升级/降级
4. 若执行：P_t 用当前阶半径 r_{ℓ} 签发，SAB 用 B·A_t 守卫
5. 若 A_t<θ_align → VAD 澄清；若覆盖违约/能量失效 → 降档 + fail-closed
PSE 签发分阶证书，CAR 用 (ℓ_t, A_t, ℓ_e) 联合守卫。

## 4. 本轮最大风险

**一句话**：课程链的单调性假设与 VLA 不确定性作为难度代理，会在「简单阶看起来覆盖很好、困难阶样本稀少」时制造能力幻觉，闸门把自主性升到课外分布上，VLA 语言接地的自信错误恰落在证书未覆盖的缝隙里而静默失效；因此必须以 Wilson 下界做保守升级、以独立 OOD 审计集拒绝课程外样本，并在任何覆盖证据不足时强制降档而非等待违约。

## 2. 关键算法 伪代码

### IP-69 CVC
```
def estimate_difficulty(slices, vla, cert, lambda_H=0.5):
    h = {}
    for xi in slices:
        ent = mean(entropy(vla.policy(obs, lang)) for obs, lang in xi)
        rad = mean(cert.radius(sample) for sample in xi)
        h[xi] = rad + lambda_H * ent
    return h

def build_curriculum(h, K=4, eps_mono=0.05):
    ordered = sorted(h.items(), key=lambda kv: kv[1])
    buckets = split_quantiles(ordered, K)
    for k in range(K - 1):
        if bucket_mean(buckets[k]) > bucket_mean(buckets[k+1]) + eps_mono:
            raise CurriculumMonotonicityViolation(k)
    return buckets

def calibrate_rungs(buckets, alpha=0.1):
    # 困难阶多分失败预算，简单阶少分；保证总预算不超
    weights = normalize([bucket_hardness(b) for b in buckets])
    alpha_k = alpha * weights
    radii = []
    for b, a_k in zip(buckets, alpha_k):
        scores = [residual(s) for s in b.cal]
        radii.append(quantile(scores, 1 - a_k))
    assert sum(alpha_k) <= alpha + 1e-9
    return radii, alpha_k
```

### IP-70 VLA-GA
```
def vla_ground_and_align(vla, obs, lang, P_t, ground_model, theta_align=0.9):
    a_chunk, z = vla.act(obs, lang)
    g = ground_target(a_chunk, obs)                 # 末端/物体/区域
    A = ground_model.coverage_prob(g, P_t, z)       # 已校准
    marg = signed_distance(g, P_t.boundary) / max(P_t.radius, eps)
    if A >= theta_align and marg >= 0:
        P_chunk = temporal_dilate(P_t, horizon=len(a_chunk))
        return a_chunk, g, A, P_chunk, 'aligned'
    if A < theta_align:
        return None, g, A, P_t, 'clarify'
    return None, g, A, P_t, 'fallback_safe'
```

### IP-71 AGE
```
def wilson_lower(k, n, z=1.96):
    if n == 0:
        return 0.0
    p = k / n
    denom = 1 + z*z/n
    centre = p + z*z/(2*n)
    half = z * sqrt(p*(1-p)/n + z*z/(4*n*n))
    return (centre - half) / denom

def autonomy_step(level_prev, rung, cov_win, align_win, lease_e, alpha_k,
                  theta_align=0.9):
    if not energy_lease_valid(lease_e):
        return 0, 'demote_energy'
    cand = min(level_prev + 1, 3)          # 每步最多升一档
    for L in range(cand, -1, -1):
        ok_cov = all(wilson_lower(cov_win[k].succ, cov_win[k].n)
                     >= 1 - alpha_k[k] for k in range(L + 1))
        ok_align = wilson_lower(align_win.succ, align_win.n) >= theta_align
        ok_rung = rung >= L
        if ok_cov and ok_align and ok_rung:
            return L, ('promote' if L > level_prev else 'hold')
    return 0, 'demote_coverage'
```

### 课程-VLA 联合决策
```
def curriculum_vla_decision(obs, lang, P_t, state):
    a_chunk, g, A, P_chunk, status = vla_ground_and_align(
        state.vla, obs, lang, P_t, state.ground_model)

    level, reason = autonomy_step(
        state.level, state.rung, state.cov_win, state.align_win,
        state.lease_e, state.alpha_k)
    state.level = level

    if status == 'clarify':
        return state.vad.clarify(g, lang), None, 'clarify'
    if status == 'fallback_safe' or level == 0:
        return state.safe_policy(obs), P_chunk, 'safe_fallback'
    if reason.startswith('demote'):
        return state.safe_policy(obs), P_chunk, reason
    if state.sab.bind(g, P_chunk, A) < theta_safe(level):
        return state.safe_policy(obs), P_chunk, 'queued'
    return a_chunk, P_chunk, 'execute'
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| 难度估计 | O(N·d_vla) 一次离线 | O(N) | 熵+半径排序给出可审计的难度代理 |
| 课程构造 | O(N log N) | O(K) | 分桶后单调性审计，违例立即报错 |
| 分阶共形校准 | O(N log N) | O(K) | 各阶覆盖 ≥1-α_k，并集 ≥1-Σα_k |
| VLA-GA 对齐 | O(d_vla + |P_t|) 每块 | O(k) | A_t≥θ_align 且 marg≥0 才执行 |
| AGE 升级 | O(K) 每步 | O(K·W) | Wilson 下界 + 每步最多升一档 |
| 联合决策 Π | O(d_vla + K) | O(K·W) | 覆盖/对齐/能量任一不足即降档 fail-closed |

**覆盖引理（union bound）**：若每阶校准集与部署样本在 D_k 内可交换，则
P(∃k: 第 k 阶违约) ≤ Σ_{k=1}^K α_k ≤ α，
故 P(所有阶同时覆盖) ≥ 1-α。

**正确性定理**：设 (C1) 课程链满足 h 近单调；(C2) 每个 D_k 内校准样本与测试样本可交换；(C3) grounding 对齐模型在校准集上给出有效覆盖；(C4) AGE 使用 Wilson 下界且每步最多升一档。则对任意 L，只要 AGE 把 ℓ_t 升到 L，就有置信 1-δ 下 ∀k≤L 的分阶覆盖成立；且只要部署样本落在 ∪_{k≤L}D_k 内，联合姿态证书 soundness ≥ 1-α。**反之，若部署样本落在课程外（∉∪D_k），定理不提供任何保证**——这正是必须加入独立 OOD 审计与强制降档的原因。

| E119 课程偏置/课外 | OOD 检出率；课外执行失败率 | 检出 ≥ 90%；失败 ≤ 1% |
| E120 100h 闭环 | 自主性占比；人工干预；证书违约 | 自主 ≥ 60%；干预 ≤ 1 次/h；违约 0 |

回退策略：E115 单调违例 > 10% → 放弃单调假设，改为配对偏序课程；E116 困难阶样本不足 → 该阶禁止升级并触发 DCL 定向采集；E117 对齐 AUC < 0.85 → 关闭 VLA 执行，仅保留 VLA 提议 + 人工确认；E119 OOD 检出 < 80% → 强制最高档位为 1（共享）；E120 违约 > 0 → 全线降档并冻结对应课程护照。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 真实难度非单调，课程链排序错误 | 高 | 序回归/配对比较审计；违例切片单独成阶，不强行并链 |
| 困难阶样本稀少致 r_k 过紧或过松 | 高 | 最少样本门槛 + Wilson 下界；不足则拒绝升级并定向采集 |
| VLA 在课外样本上过度自信 | 高 | 独立 OOD 检测 + 温度缩放校准 + 对齐度门槛 + 强制降档 |
| 接地目标 g_t 解析错误 | 中 | 多视角/深度互检；A_t 低时走 VAD 澄清而非直接执行 |
| 升级过慢影响任务效率 | 低 | 自适应窗口长度；证据充足时允许单步快升，但上限一档 |
| 高阶自主性与能量预算冲突 | 中 | 与 ECPS 联动，低电量主动降档并回收深度/双目能耗 |
| 课程护照数据漂移 | 低 | 定期重校准并换哈希；漂移检测触发重新分阶 |

## 6. 本轮最大风险

**一句话**：课程链只保证其并集内的覆盖，而 VLA 的语言接地错误最可能发生在课程外的分布缝隙上；一旦 AGE 用「简单阶覆盖很好」的窗口证据把自主性升到课外任务，VLA 的自信错误会绕过未覆盖区间使姿态证书静默失效，因此必须以独立 OOD 审计集做准入、以 Wilson 下界做保守升级，并在证据不足时默认降档而非等待违约。
