# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧闭环」IP-253~263；灵感循环新循环第 1 轮；本轮灵感：「无刷电机」×「原型验证」）

> R68 教会闭环「不确定就收紧」，R69 教会它「拿不准就去问、去看、去摸」。但这两层都建立在一个从未被写进任何证书的隐藏前提上：**策略输出 a，被执行成了 a**。真实的信任链最底端不是世界模型，也不是传感器，而是**逆变器—电流环—无刷电机—减速器**这段「命令变成力矩」的执行层。而这段执行层恰恰有两类最根本的不可信：
> - **无感观测盲区**：无刷电机换相必须知道转子位置，低速/堵转时反电动势 ∝ ω，位置在**当前激励下原理上不可观测**——等多久都测不出，只能主动注入；
> - **验证证书过期**：原型验证从来不是「这台电机是好的」，而是一句四重条件句「这个设计、这一台、在这个工况包络内、通过这些测试」。量产差异、维修换件、工况越界、热老化，每一条都会让证书失效，而系统对此一无所知。
>
> 两个灵感正好补上两块缺失：
> - **无刷电机**把「不确定性」下沉到本体执行层，并给出一个 R69 没有的概念：**不可观测 ≠ 不确定**。R69 的 epistemic 是「可以问出来的」；执行层存在「在当前激励下无论如何都不可辨识」的方向，它不响应采样、只响应**激励改变**。
> - **原型验证**把「验证」从一次性的设计活动，升级为**带来源、带包络、会过期、可按证据扩展的运行时义务**；并且验证的哲学是证伪，不是确认——主动去找能推翻自己的证据。
>
> 核心命题：**在执行层插入一个自验证层：用可观测性缺口把「可估的不确定」与「不可观测的方向」分开；对前者用任务零空间的主动探针去激发，对后者显式降额；用集总参数与结构指纹两条正交通道检测「被参数吸收的故障」；用验证覆盖集 + 验证溯源把「原型验证」变成每次运行都要兑现的证书；一切探针由证伪增益驱动，而不是由降低熵驱动。** 命名 **PROVE-RAS**（Prototype-validated, Runtime, Observability-aware Validation of Executors）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我的身体真的照做了吗，它被验证过能这么做吗**」——信任只能向下传递到被验证的执行器为止。

## 0. 直觉与动机

**灵感 1（无刷电机 → 命令与执行之间存在一个「看不见的转子」）**
直觉：无刷直流/永磁同步电机的换相依赖转子位置；无感方案用反电动势估计位置，而反电动势幅值正比于转速。低速与堵转时信噪比趋零，位置**不是测不准，而是原理上观测不到**。这意味着一个极其日常却危险的事实：机器人以为自己发出的力矩，可能建立在一个它根本看不见的转子上。R66–R69 的所有安全证明都默认 `τ_exec = a`，这正是执行层的「无感盲区」。启发：不确定性不只来自世界与传感器，也来自**把命令变成力的那一毫秒**；而且其中一类不是「样本不够」，是「当前激励根本不含信息」。

**灵感 2（无感方案 → 必须区分「可估不确定」与「不可观测方向」）**
直觉：面对位置不确定，新手的第一反应是「多测几次/滤波久一点」。但对不可观测方向，采样再多，Cramér–Rao 下界依然是无穷——你只是在平均零信息。正确动作只有两个：**改变激励**（高频注入、脉冲、d 轴偏置、微动），或**显式降额**（承认这个方向没有信息，别假装知道）。这直接改写 R69 的不确定性本体论：U_epi 可以「问出来」，U_unobs 问不出来，只能「激出来」或「认下来」。

**灵感 3（原型验证 → 验证是有条件、会过期、按覆盖计量的证书）**
直觉：原型验证报告从来不是「这台电机是好的」，而是「这个设计、这一台、在这个工况包络内、通过这些测试，才合格」。部署同时破坏四个条件：量产公差（不是原型那台）、维修换件（来源变了）、工况越界（出了验证包络）、热/寿命老化（证据过期）。所以「验证」不该是一次性事件，而应是**每次运行都要兑现的运行时义务**：覆盖显式化、来源可追溯、换件即作废、越界即降额或先扩覆盖。

**灵感 4（可辨识性 → 验证按「激励子空间」计量，而非按时间/样本数）**
直觉：在线辨识最容易被误读成「跑久一点就准」。Fisher 信息给出冷酷答案：某参数方向若从未被激励，样本再多也降不了它的方差。于是「这个电机被验证过」应精确改写为「这个电机的这个参数，在这些**激发它**的工况上被验证过」。这把原型验证从一次性设计活动变成**持续激励（PE）覆盖管理**，也解释了为什么「台架上全过、上路就出问题」——台架激励了部署时不会出现的子空间，却没激励部署真正需要的子空间。

**灵感 5（结构指纹 → 非吸收的第二意见）**
直觉：集总参数（R_s、L_d、L_q、ψ_f）像 R68 的标定层，会把故障「解释掉」：退磁 ≈ ψ_f 变小，匝间短路 ≈ R_s 变大，温升又能解释一大半。要抓「已被参数吸收的故障」，必须找**参数灵敏度张成空间之外**的观测量——反电动势谐波、负序分量、d/q 凸极比、齿槽阶次。这些是转子几何与磁体健康的**指纹**，不是拟合几个标量能仿造的。原则不是「换更灵敏的传感器」，而是**找一个与参数灵敏度正交的观测量**。这是 R68「标定吸收」与 R69「流似然第二意见」在执行层上的统一镜像。

**灵感 6（证伪优先 + 观察者效应 → 验证是主动找死，但要死在任务零空间里）**
直觉：R69 的 VoI 驱动系统「降低自己的熵」，本质是求确认；而原型验证的哲学是波普尔式的——**验证 = 尽最大努力证伪**。所以执行层的信息动作应由「证伪增益」驱动：选那段最可能推翻当前模型、又尽量不改变任务输出的探针。同时，探针本身是观察者效应：注入会扰动被验证的系统。解法是**任务零空间激励**：一阶不影响任务输出、二阶扰动有界，把「验证的动作」塞进任务不关心的方向。于是 R69 与 R70 形成漂亮对照：R69 问「我该问谁」，R70 问「我该怎么让自己出错」——**只有能让自己出错的系统，才配说自己被验证过**。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（PROVE-RAS 总览与四不变式）** PROVE-RAS = (SVA, OGD, ACT, FDP, SIG, VCG, VPT, TNC, ALC, RAS-WM†)。四不变式：
(i) **上层零改写**：R66–R69 的策略与证书层不改，只在「命令 → 执行」之间插入可验证执行层；实时策略流零学习写操作（继承 R69 定义 293-i）；执行器模型只在独立的慢环（≥ 10ms）以受限速率更新，且**绝不向上回写策略**；
(ii) **探针有界透明**：任何验证探针在任务输出上一阶影响为零，二阶偏差 ≤ ε_probe，热/声/机械预算 ≤ B_probe；
(iii) **验证显式化**：任何安全声明必须附带执行器验证覆盖集 C_val 与来源 provenance；离开 C_val 必须降额或先扩展覆盖；
(iv) **不可吸收第二意见**：只有当集总残差与结构指纹残差**同时**通过时，才允许宣称「无故障」；指纹不可信时只降额、不认证。

**定义 311（R69 的隐藏执行假设与执行误差）** R66–R69 把策略输出 a 当作已执行：τ_exec = a。真实链路 a → (逆变器, PWM, 电流环, 无刷电机, 减速器) → τ_exec，定义执行误差 e_exec = τ_exec − a。本轮命题：**上层所有安全证明都以 ‖e_exec‖ 落在其假设的界内为前提**；一旦 e_exec 越界，上层证书失效，必须降额或重建。

**定义 312（自验证执行器模型 SVA）** SVA 是两级模型：
- 集总层 θ_lump = (R_s, L_d, L_q, ψ_f, J, B, τ_c, T_w)（电阻、dq 电感、磁链、转动惯量、粘滞、齿槽/摩擦、绕组温度）；
- 结构层 φ_struct = 反电动势/电流的空间谐波向量（5/7 次、齿槽阶次、负序分量、d/q 凸极比 λ = L_q/L_d），与转子几何和磁体健康绑定。
SVA 输出 τ̂_exec、参数后验与指纹后验，并给每个参数/指纹分量贴三张标签：`observable? / identifiable? / validated?`。

**定义 313（可观测性缺口 OGD）** 在当前工作点 x_op = (ω, i_d, i_q, T_w) 取回归模型 y = Φ(x_op)θ + v，Fisher 信息矩阵 F = ΦᵀΣ_v⁻¹Φ。可观测子空间 = range(F)，不可观测方向 = ker(F) 中的单位向量。位置/速度通道因 ∂y/∂θ_pos ∝ ω，低速时对应特征值 → 0。OGD 输出：
- **U_obs**：可观测但仍有噪声的不确定（可估、可等）；
- **U_unobs**：不可观测方向上的不确定（**在当前激励下等多久都测不出**）。
关键区分：R69 的 U_epi 是「可问出来的」；U_unobs 是「原理上问不出来」的，只能改变激励（ACT）或认下来（降额）。

**定义 314（持续激励与可辨识性覆盖）** 参数 θ 在轨迹 τ 上可辨识 ⇔ 回归矩阵满足 PE 条件 λ_min(∫_τ ΦΦᵀ) ≥ αI（A99）。因此「验证」不是电机的静态属性，而是**（电机, 激励轨迹, 工作包络）三元组**的属性。定义可辨识覆盖 𝒳_id(τ) = { x : F(x;τ) ⪰ αI }。⇒ 一个参数只在**激发它**的工作点子集上被验证过；离开该子集，它的状态是「未验证」，不是「已失效」，更不是「仍然有效」。

**定义 315（主动调试测试 ACT 与任务零空间约束 TNC）** 验证探针 u_probe ∈ 𝒰 是一段注入的电压/电流/转矩模式（HF 注入、脉冲、d 轴偏置、微动）。TNC 要求存在任务输出映射 h(a) 使 J_h u_probe = 0（一阶）且 ‖h(a+u_probe) − h(a)‖ ≤ ε_probe（二阶，见引理 21）。ACT 在预算 B_probe =（能量、热、声、时间、磨损）下选择探针，并必须经 ALC（定义 321）认证。探针位于最底层、最快环，与 R69 的 gaze/probe/ask 构成一个信息动作塔。

**定义 316（证伪增益与 FDP）** 设当前模型 M（SVA），候选故障假设空间 ℋ = {退磁, 匝间短路, 轴承, 偏心, 传感器偏置}。证伪增益 FG(u) = P(M 被证伪 | u, M) · V_falsify，其中 V_falsify 为「提前发现故障」的期望安全价值。FDP 选 u* = argmax_u [FG(u) − c(u)]，仅当「当前模型被高估的风险」超过阈值时触发。与 R69 的 VoI（降低熵/求确认）不同：**FDP 主动寻找能推翻自己的证据**。系：验证质量应由「单位预算下成功证伪率」度量，而非确认次数或样本量。

**定义 317（结构指纹与非吸收性 SIG）** 令参数灵敏度子空间 S_θ = span{∂y/∂θ_1, …, ∂y/∂θ_p}。故障 h 的签名 g_h ∈ ℝ^m（谐波/序分量空间）。h 可被参数吸收 ⇔ g_h ∈ S_θ；否则不可吸收残差 r_⊥ = ‖(I − P_{S_θ}) g_h‖。SIG 监控 r_⊥ 与指纹距离 d_fp(t) = ‖φ̂_struct(t) − φ_struct^val‖_{Σ⁻¹}。判别模式：**集总残差 r_lump ≈ 0 而 d_fp 或 r_⊥ 超阈 ⇒ 参数层已被吸收、结构层未通过**——这是 R68/R69「标定吸收」在执行器层的镜像与升级。

**定义 318（验证覆盖集与保形覆盖 VCG）** 把工作包络离散为单元 𝒞 = {(τ̄, ω̄, T̄_w, n_cycle)}（转矩、转速、温度、寿命）。对每单元 c，验证状态 v(c) ∈ {validated, unvalidated, invalid, expired}，并给保形覆盖保证：对新的运行点，`P(v=true 但实际越界) ≤ α_conf`。VCG 维护 v(c) 与证书有效期；任务需求离开 validated 区域时，触发 ACT 扩覆盖或按定义 320 降额。

**定义 319（验证溯源与迁移 VPT）** 每条验证证据带 provenance = (design_id, unit_serial, test_plan, envelope, date, sensor_calibration_hash)。设计原型 P 的证书不能自动迁移到量产/维修替换单元 U，除非等价性检验 E(P,U) 在容差内（指纹 + 抽样工况 + 制造公差）。**换电机/换驱动/换减速器 ⇒ 证书作废**，必须重验或降额。这把「原型验证」从一次性活动变成**带来源跟踪的运行时义务**。

**定义 320（两级退避与降额）** 若 U_unobs 未处置、覆盖未验证、或被证伪风险高：执行器进入降额区 τ_exec ≤ γ·τ_cmd（0 < γ < 1），并把降额上界写回 R66–R69 的安全滤波（C-RAS-WM 的加速度/力矩上限按 γ 收缩）。若 SIG 证伪成立（真故障）：进入保护/停机/求助，**禁止带病认证**。⇒ R69 是 PROVE 在「执行器全验证、全可观测、指纹通过、γ=1」边界上的严格退化。

**定义 321（探针安全与环路契约 ALC）** 任何 u_probe 必须满足：(a) TNC；(b) 力矩/电流/温度/声学峰值 ≤ 包络；(c) 可中止延迟 ≤ τ_abort；(d) **不遮盖故障**（探针激励不得把故障频带推进观测盲区）；(e) 与任务动作叠加后经 C-RAS-WM 前缀认证。任一不满足 ⇒ 探针作废，按未验证降额——**不得以「为了验证安全」为由引入不安全探针**。

**定义 322（统一信息动作塔与单调信任）** 信息动作按时间尺度分层：电气探针 inject（μs–ms, OGD/ACT）⊂ 物理探针 probe（ms–s, R69 触觉）⊂ 注视 gaze（ms）⊂ 语言问询 ask（s）。统一价值 = 对**该层目标不确定性**的增益 − 成本；层目标依次为转子状态/参数 → 动作模态 → 人类意图。关键约束：**低层验证失败时，高层交互被禁止作为补救**——上层信息无法修复执行器的物理不可信。⇒ 一个单调信任塔：**下层不可信，上层全部不可诉**。

**定义 323（执行器威胁模型 AIC-PROVE）** ℰ_true = ℰ_FLUID × ℰ_sensor × ℰ_fp × ℰ_val：
- ℰ_sensor：无位置观测器欺骗（反电动势注入/电磁干扰使估计偏移）；
- ℰ_fp：结构指纹重放/伪造（用录制的正常谐波覆盖故障谐波）；
- ℰ_val：验证数据投毒（验证工况表现良好、部署工况故障）与热欺骗（用冷却掩盖热漂移）；
- ℰ_absorb：故意让故障落在 S_θ 张成空间内，伪装成正常参数漂移。
并入 AIC 后，证书必须能抵抗「在验证时表现良好」的对抗策略。

**定义 324（证书 J_PROVE）** J_PROVE = (J_FLUID, obs_gramian_min, unobs_subspace_dim, active_probe_log_hash, fingerprint_distance, nonabsorb_residual, coverage_map_hash, provenance, derating_factor, thermal_margin, prove_ver)。Valid ⇔ Valid(J_FLUID) ∧ 当前工作点 ∈ C_val ∧ U_unobs 已通过探针/降额处置 ∧ 指纹双通道一致 ∧ provenance 匹配本单元。

**定义 325（严格包含 R69）** 当 SVA 全参数已验证、OGD 无可观测缺口、SIG 双通道残差为零、覆盖 ∈ validated、γ = 1、探针为空时，PROVE 每步输出与 R69 逐指令相同；反之任一不满足，执行器输出被 γ 收缩且上层证书显式降级。⇒ R68 ⊂ R69 ⊂ PROVE 三级塔；安全侧不弱于 R69。

## 2. 关键算法骨架

# IP-264 SVA：两级自验证执行器模型（集总层可被吸收，结构层不可）
class SelfValidatingActuator:
    def __init__(self, lumped_id, fingerprint, thermal):
        self.theta, self.phi, self.Tw = lumped_id, fingerprint, thermal

    def predict(self, cmd, state):
        return self.theta.torque(cmd, state, self.Tw)

    def update_from_window(self, i_dq, u_dq, w):      # 只在慢环、受限速率
        self.theta.step(i_dq, u_dq, w)                # 集总参数在线辨识
        self.Tw.step(i_dq)

# IP-265 OGD：可观测性缺口（区分「可估」与「当前激励下不可观测」）
def observability_gap(theta, x_op):
    F = fisher_information(x_op, theta)               # Φ^T Σ_v^{-1} Φ
    lam, V = eigh(F)

    U_unobs = [v for l, v in zip(lam, V) if l <= LAM_EPS]   # 等多久都测不出
    return U_obs, U_unobs, lam

        if not task_null(task_jac, u):                 # TNC：一阶任务无影响
            continue
        if not alc.certify_probe(u, budget):           # 峰值/热/中止/不遮故障
            continue
        score = expected_falsification_gain(sva, u) - probe_cost(u, budget)
        if best is None or score > best.score:
            best = (u, score)
    return best if best and best.score > FDP_TAU else None

# IP-268 SIG：结构指纹（参数张成空间之外的不可吸收第二意见）
def structural_integrity(sva, i_dq, u_dq, w):
    r_lump = sva.theta.residual(i_dq, u_dq, w)               # 集总层残差
    phi    = harmonic_signature(i_dq, u_dq, w)               # 谐波/负序/凸极
    d_fp   = mahalanobis(phi, sva.phi.validated)
    r_perp = project_out(phi - sva.phi.validated, sva.theta.sensitivity_span)
    absorbed = (norm(r_lump) < TAU_LUMP) and (d_fp > TAU_FP or norm(r_perp) > KAPPA)
    return absorbed, d_fp, r_perp                            # 参数吸收但结构不符

# IP-269/270 VCG + VPT：验证覆盖与来源
def validation_gate(point, cert, unit):
    if cert.provenance.unit != unit or cert.swapped():
        return DENY                                          # 换件即作废
    cell = cell_of(point)                                    # (转矩,转速,温度,寿命)
    if cert.coverage[cell] != "validated":
        return EXTEND_OR_DERATE                              # 先扩覆盖，否则降额
    return ALLOW

# IP-276 主闭环：R69 快环 + 执行器验证层（上层不改写）
def PROVE_round(M, obs, cmd):
    z, o = M.mtm.forward(...)
    a = M.fluid.policy(o)                                    # R69 候选动作
    U_obs, U_unobs, lam = M.ogd.observability_gap(M.sva.theta, M.sva.workpoint)
    u_probe = (M.act.falsification_probe(M.sva, M.ogd, M.budget, M.task_jac)
               if (U_unobs and M.risk.overconfidence(z) > TAU_OC) else None)
    absorbed, d_fp, r_perp = M.sig.structural_integrity(
        M.sva, M.last_i_dq, M.last_u_dq, M.last_w)
    gate = M.vcg.validation_gate(M.sva.workpoint, M.cert, M.unit)
    if absorbed or gate == DENY:
        gamma = gamma_safe_or_stop()                          # 真故障：保护/停机/求助
    elif gate == EXTEND_OR_DERATE or U_unobs:
        gamma = gamma_derate                                  # 未验证/不可观测：降额
    else:
        gamma = 1.0
    tau = M.sva.predict(a, o) * gamma                         # 执行层收缩
    M.sva.update_from_window(M.last_i_dq, M.last_u_dq, M.last_w)
    M.vqa_a.submit_async(u_probe, d_fp, r_perp, gate, gamma)  # 参与式审计
    return tau, gamma, (U_obs, U_unobs), (absorbed, d_fp)

## 3. 推导

**引理 19（可辨识性依赖激励，而非样本量）** 若 ∫ΦΦᵀ 在某方向 v 上特征值为 0，则该方向参数的 Cramér–Rao 下界为 ∞，任意多的同工作点样本都不能降低其方差。故「多测几次」不能消除 U_unobs，只有改变激励轨迹使 v 进入激励子空间才能。系：原型验证的覆盖必须按**激励子空间**度量，而不是按**测试时长或样本数**度量——这是「台架全过、部署失效」的根本原因。

**引理 20（结构指纹的非吸收残差下界）** 设故障签名 g_h、参数灵敏度子空间 S_θ。任意 θ 更新后的最小残差为 ‖(I − P_{S_θ}) g_h‖₂。若该值 ≥ κ 且观测噪声 σ_v ≤ κ/2，则 SIG 以概率 ≥ 1 − exp(−κ²/8σ_v²) 检出故障（高斯尾界）。系：**把故障投影到参数零空间**是设计「不可吸收」验证通道的原则——目标不是更灵敏的传感器，而是与参数灵敏度**正交**的观测量。

**引理 21（任务零空间探针的二阶代价）** 若 J_h u_probe = 0（一阶任务零影响），则任务输出偏差 ≤ ½‖H_h‖‖u_probe‖² + O(‖u‖³)；热代价 ≈ ∫ i_probe² R_s(T_w) dt。故「信息/扰动」比可在小振幅下任意好，但热/磨损成本随振幅与时长累积。系：验证探针应注入**低任务曲率方向**，以最小二阶扰动换最大 Fisher 信息；预算必须显式（定义 315/321）。

**定理 18（PROVE 严格包含 R69）** 在 A99–A101 下，PROVE 在「验证-可观测区」与 R69 逐指令相同；离开该区，执行器输出被 γ ≤ 1 收缩且上层证书显式降级，故期望风险 ≤ R69，安全集不扩张。R69 = PROVE 的「执行器完美且全验证」边界。

**定理 19（无执行器验证则无上层安全保证）** 设上层安全滤波的安全裕度 m_safe > 0，执行误差的界为 ε_e。若 ε_e > m_safe（或覆盖外推误差界 > m_safe），则存在状态使上层证书 Valid 而实际约束违反概率 ≥ 1 − δ。故**任何 R66–R69 的安全声明都必须附带执行器验证覆盖与 ε_e 界**；PROVE 通过探针/降额把 ε_e 拉回 m_safe 内，或显式声明不可保证。核心：**证书的信任只能向下传递到被验证的执行器为止**。

**定理 20（证伪优先的探针选择）** 在 A102（故障假设有限且观测分布族 KL 可分）下，同等预算时 FDP 的期望首次证伪时间不劣于熵驱动探针，因为熵驱动会把预算花在已低风险方向上；节省量下界为 Ω(Σ_h π_h · 冗余 KL)，其中冗余 KL 度量「求确认」相对于「求证伪」的信息浪费。

## 6. 本轮最大风险

**一句话**：PROVE-RAS 的全部保证押在「结构指纹确实不可被参数吸收」这一前提上——**若温度、磁饱和、制造公差或一个更灵活的模型能把指纹也解释掉（或探针自身激励把故障频带推进盲区），执行器就会在真实退磁/匝间短路下给自己签发合格证书；这种「自证清白」是信任链上最不可上诉的一种标定吸收——身体自己作证，就再没有人能为它作证。**

**次级风险与缓解**：
1. **探针观察者效应**（注入扰动任务或诱发故障）→ TNC 一阶零空间 + 二阶界 + ALC 认证 + 不遮故障约束；
2. **验证覆盖被虚假扩大**（验证工况好、部署工况坏）→ 保形覆盖 α_conf + ℰ_val 投毒对抗 + SIG 常在线；
3. **溯源被绕过**（换件未登记）→ 指纹与序列号联合校验，换件即作废；
4. **低层不可信却强行上层交互**（问人修不了电机）→ 定义 322 单调信任塔，低层失败即禁止高层补救；
5. **降额过度导致任务不可用** → E307/E314 约束降额代价，扩覆盖优先于长期降额。

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** PROVE-RAS = (SVA, OGD, ACT, FDP, SIG, VCG, VPT, TNC, ALC, RAS-WM†)。不变式：上层零改写、实时策略零学习写（执行器模型仅慢环受限更新且不回写策略）；探针一阶零扰/二阶有界；验证覆盖显式化；集总与指纹双通道同时通过才允许宣称无故障。

**定义 311（隐藏执行假设）** R66–R69 默认 `τ_exec = a`；定义 `e_exec = τ_exec − a`。上层安全证明以 `‖e_exec‖` 在假设界内为前提，越界即证书失效。

**定义 312–313（SVA 与 OGD）** 两级模型：集总参数 `θ_lump` + 结构指纹 `φ_struct`。Fisher 信息 `F = ΦᵀΣ_v⁻¹Φ`；`range(F)` 可观测，`ker(F)` 不可观测；位置通道 `∂y/∂θ_pos ∝ ω`，低速时特征值 → 0。关键是区分「可估」与「当前激励下原理不可观测」。

**定义 314（持续激励与可辨识覆盖）** 可辨识 ⇔ `λ_min(∫ΦΦᵀ) ≥ αI`；验证是（电机, 激励轨迹, 工作包络）的属性，不是电机的静态属性。离开 `𝒳_id` 只代表「未验证」。

**定义 315–316（ACT/TNC 与 FDP）** 探针 `u_probe` 满足 `J_h u_probe = 0` 且二阶偏差 ≤ ε_probe；FDP 选 `u* = argmax[FG(u) − c(u)]`，求的是「能推翻自己」的证据，不是降低熵。

**定义 317（结构指纹非吸收性）** 故障签名 `g_h`；可被参数吸收 ⇔ `g_h ∈ S_θ`。SIG 监控 `r_⊥ = ‖(I−P_{S_θ})g_h‖` 与 `d_fp`；`r_lump≈0 ∧ (d_fp↑ ∨ r_⊥↑)` ⇒ 参数层已吸收、结构层未通过。

**定义 318–319（覆盖与溯源 VCG/VPT）** 工作包络离散为 `(τ̄, ω̄, T̄_w, n_cycle)` 单元，状态 validated/unvalidated/invalid/expired，保形风险 ≤ α_conf；证书带 provenance，原型证书不自动迁移到量产/维修单元，换件即作废。

**定义 320–321（降额与探针契约 ALC）** 未验证/不可观测 → `γ<1` 并把上限写回 C-RAS-WM；真故障 → 保护/停机/求助。探针须过 TNC、峰值/热/中止/不遮故障认证，禁止以验证为名引入危险探针。

**定义 322（统一信息动作塔）** inject ⊂ probe ⊂ gaze ⊂ ask；低层验证失败即禁止高层交互补救——下层不可信，上层全部不可诉。

**定义 323–325（威胁/证书/严格包含）** `ℰ_true = ℰ_FLUID × ℰ_sensor × ℰ_fp × ℰ_val`；`J_PROVE` 并入可观测性、探针日志、指纹距离、非吸收残差、覆盖哈希、来源、降额因子；验证-可观测区内 PROVE 与 R69 逐指令相同，否则 γ 收缩并显式降级 ⇒ R68 ⊂ R69 ⊂ PROVE。

## 3. 关键算法伪代码

```python
# IP-264 SVA：两级自验证执行器模型
class SelfValidatingActuator:
    def __init__(self, lumped_id, fingerprint, thermal):
        self.theta, self.phi, self.Tw = lumped_id, fingerprint, thermal
    def predict(self, cmd, state):
        return self.theta.torque(cmd, state, self.Tw)
    def update_from_window(self, i_dq, u_dq, w):      # 仅慢环、受限速率
        self.theta.step(i_dq, u_dq, w); self.Tw.step(i_dq)

# IP-265 OGD：区分「可估」与「不可观测」
def observability_gap(theta, x_op):
    F = fisher_information(x_op, theta)
    lam, V = eigh(F)
    return ([v for l,v in zip(lam,V) if l > LAM_EPS],      # U_obs
            [v for l,v in zip(lam,V) if l <= LAM_EPS],     # U_unobs
            lam)

# IP-266/267 ACT + FDP：任务零空间的证伪探针
def falsification_probe(sva, ogd, budget, task_jac):
    best = None
    for u in probe_library(ogd.U_unobs):
        if not task_null(task_jac, u): continue           # TNC
        if not alc.certify_probe(u, budget): continue     # 峰值/热/中止/不遮故障
        score = expected_falsification_gain(sva, u) - probe_cost(u, budget)
        if best is None or score > best.score: best = (u, score)
    return best if best and best.score > FDP_TAU else None

# IP-268 SIG：不可吸收的结构指纹
def structural_integrity(sva, i_dq, u_dq, w):
    r_lump = sva.theta.residual(i_dq, u_dq, w)
    phi    = harmonic_signature(i_dq, u_dq, w)
    d_fp   = mahalanobis(phi, sva.phi.validated)
    r_perp = project_out(phi - sva.phi.validated, sva.theta.sensitivity_span)
    absorbed = (norm(r_lump) < TAU_LUMP) and (d_fp > TAU_FP or norm(r_perp) > KAPPA)
    return absorbed, d_fp, r_perp

# IP-269/270 VCG + VPT：验证覆盖与来源
def validation_gate(point, cert, unit):
    if cert.provenance.unit != unit or cert.swapped(): return DENY
    cell = cell_of(point)                                  # (转矩,转速,温度,寿命)
    return ALLOW if cert.coverage[cell] == "validated" else EXTEND_OR_DERATE

# IP-276 主闭环：R69 快环 + 执行器验证层
def PROVE_round(M, obs, cmd):
    z, o = M.mtm.forward(...); a = M.fluid.policy(o)
    U_obs, U_unobs, lam = M.ogd.observability_gap(M.sva.theta, M.sva.workpoint)
    u_probe = (M.act.falsification_probe(M.sva, M.ogd, M.budget, M.task_jac)
               if (U_unobs and M.risk.overconfidence(z) > TAU_OC) else None)
    absorbed, d_fp, r_perp = M.sig.structural_integrity(
        M.sva, M.last_i_dq, M.last_u_dq, M.last_w)
    gate = M.vcg.validation_gate(M.sva.workpoint, M.cert, M.unit)
    if absorbed or gate == DENY:      gamma = gamma_safe_or_stop()
    elif gate == EXTEND_OR_DERATE or U_unobs: gamma = gamma_derate
    else:                             gamma = 1.0
    tau = M.sva.predict(a, o) * gamma
    M.sva.update_from_window(M.last_i_dq, M.last_u_dq, M.last_w)
    M.vqa_a.submit_async(u_probe, d_fp, r_perp, gate, gamma)
    return tau, gamma, (U_obs, U_unobs), (absorbed, d_fp)
```

## 4. 推导

**引理 19（可辨识性依赖激励而非样本量）** 若 `∫ΦΦᵀ` 在方向 `v` 上特征值为 0，则该方向参数 Cramér–Rao 下界为 ∞，任意多同工作点样本都不能降低其方差。故消除 `U_unobs` 只能改变激励轨迹；原型验证覆盖必须按激励子空间而非测试时长计量。

**引理 20（结构指纹的非吸收残差下界）** 任意 θ 更新后的最小残差为 `‖(I−P_{S_θ})g_h‖₂`。若 ≥ κ 且噪声 σ_v ≤ κ/2，则检出概率 ≥ `1 − exp(−κ²/8σ_v²)`。系：设计不可吸收通道的原则是**把故障投影到参数零空间**，找与参数灵敏度正交的观测量。

**引理 21（任务零空间探针的二阶代价）** `J_h u_probe = 0` ⇒ 任务偏差 ≤ `½‖H_h‖‖u_probe‖² + O(‖u‖³)`；热代价 ≈ `∫ i_probe²R_s(T_w)dt`。信息/扰动比可在小振幅下任意好，但热/磨损随振幅与时长累积，预算必须显式。

**定理 18（PROVE 严格包含 R69）** A99–A101 下，验证-可观测区内与 R69 逐指令相同；区外 γ ≤ 1 收缩并显式降级，故期望风险 ≤ R69，安全集不扩张。R69 = PROVE 的「执行器完美且全验证」边界。

**定理 19（无执行器验证则无上层安全保证）** 设上层安全裕度 `m_safe > 0`、执行误差界 `ε_e`。若 `ε_e > m_safe`（或覆盖外推误差界 > m_safe），存在状态使上层证书 Valid 而实际约束违反概率 ≥ 1−δ。故 R66–R69 的安全声明必须附带执行器验证覆盖与 `ε_e` 界；证书的信任只能向下传递到被验证的执行器为止。

**定理 20（证伪优先的探针选择）** A102（故障假设有限且观测分布族 KL 可分）下，同等预算时 FDP 的期望首次证伪时间不劣于熵驱动探针；节省量下界 `Ω(Σ_h π_h · 冗余 KL)`，冗余 KL 度量「求确认」相对「求证伪」的信息浪费。

## 7. 本轮最大风险

**一句话**：PROVE-RAS 的全部保证押在「结构指纹确实不可被参数吸收」这一前提上——**若温度、磁饱和、制造公差或一个更灵活的模型能把指纹也解释掉（或探针自身激励把故障频带推进盲区），执行器就会在真实退磁/匝间短路下给自己签发合格证书；这种「自证清白」是信任链上最不可上诉的一种标定吸收——身体自己作证，就再没有人能为它作证。**

**次级风险与缓解**：探针观察者效应（TNC + 二阶界 + ALC + 不遮故障）；验证覆盖被虚假扩大（保形覆盖 + ℰ_val 对抗 + SIG 常在线）；溯源被绕过（指纹与序列号联合校验，换件即作废）；低层不可信却强行上层交互（定义 322 单调信任塔）；降额过度（E307/E314 约束代价，扩覆盖优先于长期降额）。
