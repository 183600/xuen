# 第 58 轮（承接第 57 轮「证据地图×主动探询×信任协商」IP-133~138；灵感循环第 1 轮；本轮灵感：「商业模式」×「场景泛化」）

> 第 57 轮把安全的赌注从"模型置信"换到"证据承诺"，并用少样本元推断、跨模态对账、个性化信任把证据质量抬到可审计层。但它仍默认两件事：**(a) 证据只在一个部署内部循环**——每个区域/任务自己付探针成本，证据没有产权、责任、折旧与跨场景价格，"证据经济"是隐式的；**(b) 泛化是二元的**——ID 复用或 OOD 拒答，没有"同机制、异环境、可计价、带除外条款"的中间态。两者相乘会产生一个危险组合：商业压力要求复用证据以摊薄成本，而技术上的复用依据往往只是"看起来像"；于是系统要么为每个新场景从零探起（贵到无法规模化），要么把视觉/统计相似误当机制相同（泛化剧场）。本轮两个灵感把这两件事接上：**商业模式**把证据从消耗品变成可承保的资产（保费、准备金、理赔、召回、偿付能力），**场景泛化**把跨场景复用从"相似性直觉"变成"不变机制的可审计迁移契约"（T0–T3 分层、加权共形、覆盖域、除外条款、机制漂移失效）。核心命题：**证据要可承保，泛化要可计价；利润可以购买速度，不能购买安全。**

核心矛盾：
- **H29（泛化的中间态缺失 vs 证据复用需求）**：第 57 轮只有"ID 复用/OOD 拒答"两挡；真实部署大量落在"同机制、异环境"的中间态。没有中间态，复用要么过度（相似外观下的机制漂移 → 跨场景共同错误），要么完全放弃（每场景从零探 → 单位经济不可持续）。中间态必须存在，而且必须能被定价、被验证、被拒保。
- **H30（不变机制的潜变量 vs 覆盖契约的可审计性）**：机制 z_inv 不可直接观测；可观测相似性可能由 nuisance（背景/位置/光照/外观）驱动；验证不变性要干预与探针，而探针正是商业模式要省的成本。承保范围越宽，验证越贵；越窄，越卖不出去——覆盖域本身成为一个需要被优化的对象。
- **H31（共享证据的网络效应 vs 相关性风险/责任）**：证据复用摊薄成本，却把多个部署绑到同一份证据上；一份错误证据可以同时击穿多张保单（共同模式失效），而商业激励会诱导隐藏失败、证书注水、把风险转嫁给再保险/人类。共享越深，系统性风险越大；必须让"召回"与"共同模式准备金"成为一等机制。

## 0. 直觉与动机

**灵感 1（商业模式 → 证据承保与安全资本）**
直觉：机器人部署不是"每次接触都尽量安全"，也不是"每次部署都从零验证"，而更像一家**承保商**：每个场景是一张保单，证据是资本，探针是防损投资，人类同意/监督是再保险，失败是理赔，理赔后要召回同源证据。关键纪律有四条：**总安全资本不可增发**（硬安全底线不能拿利润换）；**精算单元内不许交叉补贴**（不同接触机制的风险不能被平均掉）；**承保前必须验标**（T2/未知机制先探针，防止逆向选择）；**共享证据必须可召回**（一份证据被证伪，所有依赖它的保单同时降级/重定价）。"拒保/放弃部署"因此不是失败，而是一等安全动作——不承保比错误承保更便宜。

**灵感 2（场景泛化 → 不变机制迁移契约）**
直觉：泛化不是"目标场景看起来像源场景"，而是"让证据成立的那套机制在目标场景仍然成立"。把场景分解为 **z_inv（任务相关机制：物体可供性、接触物理、抓放关系、人体干扰动力学）** 与 **z_env（环境 nuisance：位置、背景、光照、干扰物、外观、标定漂移）**。只有 z_env 变化时，证据可以按加权共形"带保费迁移"；z_inv 变化时，证据作废，必须重新探针或拒保。于是泛化从二值变成四挡：**T0 同机制同环境（直接复用）/ T1 同机制异环境（有界加权共形 + 保费 + 共同保险）/ T2 机制不确定（必须先验标/探针）/ T3 机制改变（证据作废，拒保或按全新场景重做）**。保单还会因**机制漂移**而失效，不只在日历到期时失效。

对照 UniBot 的 5 类泛化轴，这一分解给出可执行的默认承保策略：

| UniBot 泛化轴 | 主要变化 | 默认 Tier | 需要的证据动作 |
|---|---|---|---|
| 位置 | z_env | T1 | 加权共形 + 保费；可选本地抽检 |
| 背景 | z_env | T1 | 同上；背景不变性 witness |
| 干扰物 | z_env + 目标绑定 | T1/T2 | 遮挡/绑定 witness；必要时验标 |
| 未见物品 | z_inv（几何/材质/可供性） | T2/T3 | 必须探针/验标；不得直接迁移 |
| 人为干扰 | z_inv（人体动力学/进度可逆） | T3/T2 | 人工在环契约 + 同意；默认拒保 |

**灵感 3（三灵感合流 → 承保感知的探-诺-演 PCE-U）**
直觉：第 57 轮的 PCE+ 是"探针—承诺—演化"；本轮在前后各加一道经济动作：**承保（underwrite）→ 验标/探针（inspect）→ 承诺（commit）→ 理赔/召回（claim/recall）**。VOI 不再只算"这次探针降多少即时风险"，还要算它把保单从 T2 升到 T1/T0 带来的**保费下降、准备金释放、未来场景复用期权**；但任何"保费收益"都不能抵扣硬安全底线。多场景部署于是变成一个组合优化：在总安全资本与相关性准备金约束下，选择承保哪些场景、先验标哪些、放弃哪些、共享哪些证据。

**灵感 4（证据门从五类到六类）**
直觉：第 57 轮的 EV-probe/visit/margin/xmodal/human 之外，本轮新增 **EV-transfer**：跨场景迁移证据。但它只在"有有效 ITC 契约 ∧ 覆盖成立 ∧ 保费/准备金已入账 ∧ 目标场景有本地抽检或同意"时成立；T2 必须先探针升级；T3 直接作废；EV-transfer **永远不能单独支撑不可逆接触**。安全纵深从五层到六层：元先验错 ∧ OOD 漏检 ∧ 跨模态无一致 ∧ 无裕度 ∧ 人错 ∧ **迁移契约失效未被召回**。

**灵感 5（商业模式的组合层 → 泛化即服务 GaaS）**
直觉：如果证据可承保、迁移可计价，那么产品不再是"一台会做 32 个任务的机器人"，而是"**一份带覆盖域、除外条款、召回承诺的泛化保单**"：客户按覆盖域订阅、按探针/共保付费、按理赔记录重定价。对 UniBot 这类 32 任务 × 5 泛化轴的评测，这意味着不再逐场景从零刷 episode，而是把可复用证据组织成"机制族账本"：位置/背景/干扰物多属 z_env 迁移（T1），未见物品与人为干扰多属 z_inv 改变（T2/T3），必须验标或拒保。商业上的可规模化，恰恰来自敢对某些场景说"不承保"。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（场景契约 SC）** 场景 s=(task, z_inv, z_env, e_emb, stakes)；证据包 E 继承 J_p。保单 P=(scope, A_P, X_P, τ, π, R, L, D, c, expiry, provenance)，其中 τ∈{T0,T1,T2,T3}，A_P 为承保假设，X_P 为除外条款，π 为保费，R 为准备金，L 为责任上限，D 为免赔/本地抽检成本，c 为共保比例。覆盖函数 Cov(P,s')=1[z_inv(s')∈scope ∧ A_P(s') ∧ s'∉X_P ∧ ¬drift(P,s')]。保单是"可迁移证据"的最小商业/技术单元；无 Cov 即无 EV-transfer。

**定义 140（不变机制迁移证书 ITC）** 观测生成过程分解为 p_s(o,θ)=p(θ|z_inv)p(o|θ,z_env)，θ 含接触物理、可供性与抓放关系。机制残差 D_inv(s,s')=sup_{φ∈Φ}|E_s[φ]−E_{s'}[φ]|，Φ 为机制见证统计（nuisance 干预不变 + 机制干预敏感）；密度比 w(s'||s)≤W_max。分层：T0 ⇔ D_inv≤θ_0 ∧ w≤1+ε；T1 ⇔ D_inv≤θ_inv ∧ w≤W_max；T2 ⇔ 灰区或无多环境证据；T3 ⇔ 机制改变。T1 由加权共形给覆盖 ≥1−α_t。除外条款 X_P 显式列出机制改变型扰动；expiry 由漂移监测 M_inv(o_{1:t})>θ_drift 触发，**机制漂移即时失效，不等日历到期**。

**定义 141（证据承保与安全资本 EUC）** 安全资本 C_safe>0，暴露 E(P)=L(P)·P_fail(P)（或 CVaR）。偿付能力硬约束：Σ_{P∈active}E(P)+R_cm≤C_safe+R_rein，且 δ_safe 与利润/分数解耦。精算单元 A=机制类；保费 π(P)=b(A)·g(τ)·(1+λ(1−cov))·(1+χ(X_P))，准备金 R=CVaR_β(loss)+loading，免赔 D=本地抽检/同意成本，共保 c 随道德风险与历史上调。**无交叉补贴**：∀A，Σπ_A≥E[loss_A]+R_A，否则重定价或拒保。T2/未知机制强制验标，防逆向选择。理赔：归因到证据项 → 支取准备金 → 更新 b(A) → 召回依赖保单。

**定义 142（迁移证据门 TEG）** 在 FSE 五类证据上新增 EV-transfer。EV-transfer 成立 ⇔ τ∈{T0,T1} ∧ Cov(P,s)=1 ∧ π/R 已入账 ∧ provenance 完整 ∧（不可逆接触时）有本地抽检或同意；T2 ⇒ 先验标；T3 ⇒ 拒绝；EV-transfer 不得单独支撑不可逆接触。J_g=(J_p, ITC, P, 保费/准备金账本, provenance DAG, 召回状态, 漂移日志)。硬规则：**无契约不迁移，无本地证据不不可逆**。

**定义 143（承保感知的探-诺-演 PCE-U）** 每场景执行：①分层与承保（accept/transfer/inspect/decline）；②若 inspect，选 argmax VOI_uw 的验标探针；③若 commit，在覆盖与本地证据下运行第 57 轮 PCE+；④失败或证伪进入理赔/召回。VOI_uw=Δrisk·L+Δπ·H+Δtier·reuse_value+option_value−cost，但 Δπ 不得用于抵扣硬安全底线。组合层：在 ΣE+R_cm≤C_safe+R_rein 与 P_fail≤δ_safe 下，选择承保场景子集 S，最大化任务价值−保费−探针成本；decline 收益为 0 但保留资本，必须是一等动作。

**定义 144（证据召回与共同模式审计 ERC）** provenance DAG 上 Dep(e) 为所有直接/间接依赖证据 e 的保单。证伪 e 时，对所有 e 为实质证据的 P∈Dep(e) 执行：suspend → draw reserve → reprice → τ←min(τ,T2)。共同模式暴露 CME(e)=Σ_{P∈Dep(e)}E(P)；共同模式准备金 R_cm≥max_e CME(e)（或经相关性压力测试），且单一证据支撑的资本占比 ≤κ_cm·C_safe。召回时延 T_recall≤一个部署周期，**禁止沉默复用**。这是对第 57 轮"坏先验普遍"的直接补丁：坏共享证据不能悄悄支撑多个部署。

## 2. 关键算法伪代码（完整版见产物区）

```python
def build_transfer_contract(E, s, s_t, meta, capital):
    D = invariance_residual(E, s, s_t, witnesses=W_inv)   # A41
    w = density_ratio(s_t, s, cap=W_max)                  # A42
    tier = 'T0' if D <= theta_0 and w <= 1 + eps else \
           'T1' if D <= theta_inv and w <= W_max else \
           'T2' if D <= theta_mech else 'T3'
    P = Policy(scope=mechanism_support(E) if tier in ('T0','T1') else None,
               assumptions=assumptions(E), exclusions=exclusions(E, s_t),
               tier=tier, expiry=drift_monitor(z_inv(s_t)),
               provenance=E.provenance)
    P.premium, P.reserve = price(P, capital.actuarial_table)
    return P

def underwrite(P, capital, task_value):
    if P.tier == 'T3': return 'decline'        # 拒保优于错误承保
    if P.tier == 'T2': return 'inspect'        # 先验标，防逆向选择
    if not capital.solvent(P, reserve=capital.R_cm): return 'decline'
    if P.tier == 'T1' and P.irreversible:
        P.deductible = local_spot_check_cost(P)  # 共同保险/免赔
    return 'accept'

def pce_u(x0, M, task, s, portfolio, capital):
    P = build_transfer_contract(M.evidence, s.source, s, meta, capital)
    d = underwrite(P, capital, task.value)
    if d == 'decline': return portfolio.decline(s)
    if d == 'inspect':
        p = argmax(admissible_probes(s), key=lambda q: voi_uw(q, P) - cost(q))
        M, P = execute_inspection(M, P, p)      # 可升 T1/T0，也可降 T3
        if P.tier == 'T3': return portfolio.decline(s)
    sig, log, M = pce_plus(x0, M, task, s, P)    # 第 57 轮承诺内核
    if sig is None: return portfolio.decline(s)
    P = capital.book(P, sig)
    try:
        if not execute_commitment(sig, P): raise Claim(s, P, P.provenance.roots())
        return portfolio.accept(s, P)
    except Claim as c:
        return claims_recall(c, M, portfolio, capital)

def claims_recall(c, M, portfolio, capital):
    e_bad = attribute(c)                        # 归因到证据项
    for P in provenance_dag.dependents(e_bad):
        if evidence_is_material(P, e_bad):
            portfolio.suspend(P); capital.draw_reserve(P, c.loss)
            capital.reprice(P, reason='recall'); P.tier = min(P.tier, 'T2')
    capital.audit.record(c, dependents(e_bad), t_recall=now())
    return portfolio, capital
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| SCU | O(\|E\|+\|Φ\|)/契约 | O(\|E\|) | provenance 完整、覆盖函数单调 |
| ITC | O(\|W_inv\|·d_φ) | O(\|Φ\|) | A41 漏检 ≤δ_inv、A42 覆盖 ≥1−α_t |
| EUC | O(\|A\|+\|P_active\|) | O(\|P\|) | A43 偿付能力、无交叉补贴 |
| TEG | O(1)+O(\|P\|) | O(\|P\|) | 无契约不迁移、EV-transfer 限 T0/T1 |
| PCE-U | O(\|S\|·(k_p+k_c)·(C_VOI+d_φ)) | O(\|S\|+\|P\|) | 四态+承保动作有限 |
| ERC | O(\|Dep(e)\|) | O(\|provenance\|) | 召回闭包、T_recall 有界 |

**正确性定理（Insurable Transferable Evidence Soundness, ITES）** 在 A22–A40 上新增：(A41) 不变性检验诚实，机制漂移漏检 ≤δ_inv、nuisance 误报 ≤δ_n、监测时延 ≤T_drift；(A42) 有界加权共形，目标/源密度比 ≤W_max，机制单元内可交换，迁移覆盖 ≥1−α_t；(A43) 承保完整性/偿付能力，资本记账诚实、无交叉补贴、任意时刻 ΣE+R_cm≤C_safe+R_rein、理赔/召回 T_recall 内闭合、δ_safe 不随利润调整；(A44) provenance/责任完整，除外条款强制执行，召回触达所有依赖保单，无证书注水。则：

(i) **迁移健全性**：若 Cov(P,s')=1 且 τ∈{T0,T1}，目标场景 P(fail)≤δ_f+ε_meta+δ_probe+δ_inv+α_t+ε_h；T2 未验标不得承诺；T3 迁移贡献为 0；EV-transfer 不单独用于不可逆接触。
(ii) **经济健全性**：在 A43 下承保组合不违反偿付能力；单元内保费覆盖期望理赔+准备金；共同模式损失在 R_cm 内可吸收；召回后无沉默复用。注意：若相关性被低估，经济健全性会先于物理安全失效。
(iii) **单调性**：商业机制只经两通道影响系统——(a) 获得更可审计的证据（T2→T1/T0），或 (b) 更保守的动作（验标、共保、拒保、召回、降档）；利润不能放宽硬安全底线或证据门。
(iv) **终止性**：每次承保决策有限；每场景 PCE-U 在 k_probes+k_cons 内终止；召回闭包在 provenance DAG 上有限步完成。
(v) **部署界**：P_safe ≥ 1−Σ_P(δ_f+ε_meta+δ_probe+δ_inv+α_t+δ_xm·1[L1]+δ_h)−P(共同模式漏估)−P(召回超时)−P(漂移监测失效)−P(偿付能力击穿)。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 共同模式相关性低估 → 系统性失效 | 高 | provenance DAG + R_cm + 相关性压力测试 + 单一证据资本占比上限 |
| 机制漂移漏检 → 错误 T1 迁移 | 高 | 双组 witness（nuisance/mechanism）+ 漂移监测 + 即时失效 + T2 灰区 |

## 6. 本轮最大风险

### IP-139/140 SCU + ITC（场景契约与不变迁移证书）

```python
def factorize(s):
    return s.z_inv, s.z_env          # z_inv: 可供性/接触物理/抓放关系/人体动力学

def invariance_residual(E, s, s_t, witnesses):
    # W_env: 位置/背景/光照/干扰物等 nuisance 干预，不应改变机制响应
    # W_mech: 质量/材质/可供性/人体接触等机制干预，应该改变机制响应
    d_env  = max(|E.predict(phi, s) - E.predict(phi, s_t)| for phi in witnesses.W_env)
    d_mech = min(|E.predict(phi, s) - E.predict(phi, s_t)| for phi in witnesses.W_mech)
    if d_env > theta_n or d_mech < theta_mech:
        return INF                      # 机制不变性不成立/不可辨
    return sup_phi |E_s[phi] - E_st[phi]|   # A41: 漏检 <= delta_inv

def build_transfer_contract(E, s, s_t, meta, capital):
    D = invariance_residual(E, s, s_t, witnesses=W_inv)
    w = density_ratio(s_t, s, cap=W_max)         # A42: 有界权重
    if   D <= theta_0   and w <= 1 + eps: tier = 'T0'
    elif D <= theta_inv and w <= W_max:   tier = 'T1'
    elif D <= theta_mech:                 tier = 'T2'
    else:                                 tier = 'T3'
    P = Policy(scope=mechanism_support(E) if tier in ('T0','T1') else None,
               assumptions=assumptions(E),
               exclusions=exclusions(E, s_t) | mechanism_changing_perturbations(s_t),
               tier=tier,
               expiry=drift_monitor(z_inv(s_t)),   # 漂移即时失效，非日历到期
               provenance=E.provenance)
    P.premium, P.reserve = price(P, capital.actuarial_table)
    return P
```

```python
def price(P, table):
    A = mechanism_cell(P)                        # 精算单元 = 机制类
    b = table.base_rate[A]                       # 历史理赔得到
    cov = coverage_fraction(P.scope, A)
    pi = b * tier_factor(P.tier) * (1 + lam * (1 - cov)) * (1 + chi * len(P.exclusions))
    R  = cvar(beta, table.loss_dist[A]) + loading(P)
    return pi, R

def solvent(capital, P, reserve):
    return capital.exposure + P.limit * P.fail_ub + reserve <= capital.C_safe + capital.R_rein

def underwrite(P, capital, task_value):
    if P.tier == 'T3':
        return 'decline'                          # 不承保 = 一等安全动作
    if P.tier == 'T2':
        return 'inspect'                          # 强制验标，防逆向选择
    if not solvent(capital, P, capital.R_cm):
        return 'decline'
    if P.tier == 'T1' and P.irreversible:
        P.deductible = local_spot_check_cost(P)   # 共同保险/免赔
        P.coinsurance = moral_hazard_rate(capital.history)
    return 'accept'
```

### IP-143 PCE-U（承保感知的探-诺-演）

```python
def voi_uw(probe, P, capital):
    return (delta_risk(probe) * P.limit
            + delta_premium(probe, capital) * P.horizon
            + delta_tier(probe) * capital.reuse_value(P)
            + option_value(probe, capital.evidence_ledger)
            - probe.cost)                          # 保费项不得抵扣硬安全底线

def pce_u(x0, M, task, s, portfolio, capital):
    P = build_transfer_contract(M.evidence, s.source, s, meta, capital)
    d = underwrite(P, capital, task.value)
    if d == 'decline':
        return portfolio.decline(s)
    if d == 'inspect':
        p = argmax(admissible_probes(s), key=lambda q: voi_uw(q, P, capital) - cost(q))
        M, P = execute_inspection(M, P, p)         # 验标可升 T1/T0，也可降 T3
        if P.tier == 'T3':
            return portfolio.decline(s)
    sig, log, M = pce_plus(x0, M, task, s, P)      # 第 57 轮承诺内核
    if sig is None:
        return portfolio.decline(s)
    P = capital.book(P, sig)                        # 入账保费/准备金
    try:
        if not execute_commitment(sig, P):
            raise Claim(s, P, evidence=P.provenance.roots())
        return portfolio.accept(s, P)
    except Claim as c:
        return claims_recall(c, M, portfolio, capital)

def portfolio_plan(scenarios, capital, value):
    # 在 Solvency 与 P_fail<=delta_safe 下选承保子集；decline 保留资本
    S = []
    for s in sorted(scenarios, key=lambda x: value(x) / capital.risk(x), reverse=True):
        P = build_transfer_contract(M.evidence, s.source, s, meta, capital)
        if underwrite(P, capital, value(s)) != 'decline' and capital.can_add(P):
            S.append(P); capital.reserve(P)
    return S
```

```python
def claims_recall(claim, M, portfolio, capital):

def common_mode_reserve(provenance_dag, policies):

           for e in provenance_dag.evidence_items()}
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SCU | O(\|E\|+\|Φ\|)/契约 | O(\|E\|) | provenance 完整、Cov 单调（假设越多覆盖越小） |
| ITC | O(\|W_inv\|·d_φ) | O(\|Φ\|) | A41 漏检 ≤δ_inv、A42 覆盖 ≥1−α_t |
| EUC | O(\|A\|+\|P_active\|) | O(\|P\|) | A43 偿付能力、无交叉补贴 |
| TEG | O(1)+O(\|P\|) | O(\|P\|) | 无契约不迁移、EV-transfer 仅 T0/T1 |
| PCE-U | O(\|S\|·(k_p+k_c)·(C_VOI+d_φ)) | O(\|S\|+\|P\|) | 承保四态 + 承诺四态有限 |
| ERC | O(\|Dep(e)\|) | O(\|provenance\|) | 召回闭包、T_recall 有界 |

**正确性定理（Insurable Transferable Evidence Soundness, ITES）**
假设 A22–A40 成立；新增 **(A41)** 不变性检验诚实：机制漂移漏检率 ≤δ_inv、nuisance 误报率 ≤δ_n、监测时延 ≤T_drift；**(A42)** 有界加权共形：目标/源密度比 ≤W_max，机制单元内可交换，迁移覆盖 ≥1−α_t；**(A43)** 承保完整性/偿付能力：资本与准备金记账诚实、精算单元无交叉补贴、任意时刻 ΣE+R_cm≤C_safe+R_rein、理赔与召回在 T_recall 内闭合、δ_safe 不随利润/分数调整；**(A44)** provenance/责任完整：来源链完整、除外条款强制执行、召回触达所有依赖保单、无证书注水。则：

1. **迁移健全性**：若 Cov(P,s')=1 且 τ∈{T0,T1}，则目标场景
   `P(fail) ≤ δ_f + ε_meta + δ_probe + δ_inv + α_t + ε_h`；
   T2 未验标不得承诺；T3 迁移贡献为 0；EV-transfer 不单独用于不可逆接触。
2. **经济健全性**：在 A43 下承保组合不违反偿付能力；每个精算单元内保费覆盖期望理赔+准备金；共同模式损失在 R_cm 内可吸收；召回后无沉默复用。注意：若相关性被低估，经济健全性会先于物理安全失效。
3. **单调性（利润不能购买安全）**：商业模式只经两个通道影响系统——(a) 获得更可审计的证据（T2→T1/T0），或 (b) 采取更保守动作（验标、共保、拒保、召回、降档）；保费/利润不能放宽硬安全底线或证据门。
4. **终止性**：每次承保决策有限（accept/transfer/inspect/decline）；每场景 PCE-U 在 k_probes+k_cons 内终止；召回闭包在 provenance DAG 上有限步完成。
5. **部署界**：

```
P_safe ≥ 1 − Σ_{P∈active} (δ_f + ε_meta + δ_probe + δ_inv + α_t + δ_xm·1[L1] + δ_h)
             − P(共同模式漏估) − P(召回超时) − P(漂移监测失效) − P(偿付能力击穿)
```

关键：**T0/T1/T2/T3 把"泛化"从二值变成可承保的中间态**；**加权共形给 T1 统计保底，witness 给 T2 可审计的不确定性**；**保费/准备金/免赔让"复用证据"这件事第一次有了成本与责任**；**provenance + 召回 + R_cm 把第 57 轮"坏先验普遍"限制在可隔离、可回滚的范围内**。

3. **Tier 门控离线回放**：在日志上先跑 `T0/T1/T2/T3` 分类与加权共形，校准 `θ_inv/θ_0/W_max/α_t`；只对 T1 开放复用，T2 强制验标。
4. **账本与召回**：给每条证据打 provenance，计算 `Dep(e)`、`CME(e)`、`R_cm`；先做离线理赔演练，再做影子部署。
5. **真机 A/B**：在同一批 32×5 场景上，比较"逐场景从零探"、"无契约暴力复用"、"本方案 T0–T3"三组；重点看单位成功成本、拒保率与召回时延。

### 6.2 商业模型：卖"泛化保单"，不卖"保证成功"

- **产品形态（Generalization-as-a-Service, GaaS）**：按机制族订阅覆盖域；T0/T1 为标准覆盖，T2 为"验标后承保"，T3 明确除外；客户可按覆盖域、免赔额、共保比例选择价格。
- **定价**：`π=b(A)·g(τ)·(1+λ(1−cov))·(1+χ|X|)`，准备金 `R=CVaR_β+loading`；理赔记录进入历史费率，形成"证据信用"。
- **风险选择**：拒保不是产品失败，而是风险选择；对 T3（未见机制/人为干扰）默认不承保，或只在人工在环 + 同意的再保险下承保。
- **差异化**：竞品卖"成功率数字"，本方案卖"**带覆盖域、除外条款、召回承诺的可审计泛化**"——对 UniBot 这类 5 轴泛化评测，能把"哪一轴能复用、哪一轴必须重探"讲清楚，比单一平均成功率更有部署价值。
- **边界**：保单承诺的是"在 A_P 成立且无 X_P 时的失败上界"，不是"任何场景都成功"；假设被打破时触发召回而非静默复用。这是商业模式能成立、又不把安全卖掉的唯一方式。

## 7. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 共同模式相关性低估 → 系统性失效 | 高 | provenance DAG + R_cm + 相关性压力测试 + 单一证据资本占比上限 κ_cm |
| 机制漂移漏检 → 错误 T1 迁移 | 高 | 双组 witness（nuisance/mechanism）+ 漂移监测 + 即时失效 + T2 灰区 |
| 逆向选择/证书注水 → 风险池污染 | 中高 | 强制验标 + 独立审计 + 无交叉补贴 + 历史费率 |
| 有保险就少探针（道德风险） | 中 | 免赔/共保 + 探针 ROI 记账 + 随机抽检 |
| 过度拒保 → 商业不可行 | 中 | T2 验标升级 + 分层覆盖 + 证据市场摊薄成本 |
| 账本/计算复杂度 | 中低 | 按精算单元增量维护 + 离线费率表 + 只对受影响依赖集召回 |

## 8. 本轮最大风险

**一句话**：本轮最大的风险不是单次迁移判错，而是**共享证据的共同模式相关性被系统性低估**——保费与准备金在账面上仍偿付能力充足，但同一份错误证据同时支撑多张保单，一次召回会在多个场景同时到期，即"精算上安全、系统上脆弱"；必须以 provenance 召回、共同模式准备金、相关性压力测试与单一证据资本占比上限四重护栏，宁可少承保，也不让风险池变成系统性风险的放大器。
