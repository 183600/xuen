# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 4 轮；本轮灵感：「模型蒸馏」×「MuJoCo」）

> 第 57 轮把安全的赌注从"证据质量"托管给一个从真实探针史摊销出的元推断器 q_φ，并在结尾自陈最大风险——**坏先验普遍**：语料有系统性盲区时，元模型会在 OOD 门学会识别的模式之外给出高度自信的错误后验，而跨模态一致加成与个性化授权加速会把这错误更快送进承诺。本轮两个灵感恰好是这条风险的"解药"与"毒药"：**MuJoCo** 用无限、可复现、带特权真值的物理仿真把语料盲区"廉价填满"（解药），**模型蒸馏**把巨大云端教师压成边端实时学生（效率）；但两者合流会制造一个更深的问题——**蒸馏压掉教师的不确定性尾巴，而仿真又让"尾巴区域"变得极其廉价可生成，于是系统恰好在现实最少覆盖的地方最自信**（毒药）。本轮把安全赌注由"元先验质量"转成 **"仿真-现实落差的可审计性 + 真实世界对合成的最终否决权"**，核心命题升级为 **"仿真只许证伪、蒸馏只许提速、现实保留最终否决"的少样本证据承诺**。

核心矛盾：
- **H29（蒸馏 vs 不确定性尾巴）**：知识蒸馏在训练分布上匹配均值即可高分，但安全性住在分布的尾部（罕见/OOD 状态恰好是接触失败发生处）；学生复制了教师的函数值，却可能压掉教师"我不知道"的认知不确定性——**平均保真不等于尾部校准**，学生在教师会弃权处给出自信答案。
- **H30（仿真 vs 现实 / 仿真作为可共谋模态）**：MuJoCo 不是真值而是一族接触假设；"仿真里安全"可被一套系统性错误的摩擦/刚度模型制造。仿真必须当作**第四个、且永不独立的模态**对待——它能与单一模态共谋一样，与现实共谋出"跨到访自洽"的假信念。
- **H31（特权信息 vs 可部署性）**：教师有特权真值 θ_gt，学生只有观测；蒸馏可能造成信息泄漏式学生——"表现得知道"却没有信息通路去知道，于是它比教师更少探针，因为教师从不需要探针。省下的计算若不兑换成真实探针，只是更快地错。

## 0. 直觉与动机

**灵感 1（模型蒸馏 → 保不确定性蒸馏 + 学生-教师分歧即 OOD）**
直觉：学生不是教师的"缩小版答案"，而是教师的"缩小版分布"。只用动作/均值做 KD 等于只传结论不传犹豫。保不确定性蒸馏同时匹配**分位数/CRPS**（分布而非均值），并把**学生-教师分歧**做成运行时的免费认知不确定性估计：两者一致时才敢用学生，一分歧就退教师或第 57 轮慢路径。同时区分两种偏差：**信息落差 δ_info**（教师用特权 θ_gt 看到、学生看不到）与**拟合落差 ε_dist**（同一信息下学生模仿误差）——前者不能靠更大网络消掉，只能靠"多探一次"补上。

**灵感 2（MuJoCo → 特权仿真教师 + 可微物理对抗证伪）**
直觉：MuJoCo 的第一用途不是"造训练数据"，而是**造压力测试**。既然可微（MJX），就能在信念支持的物理参数集里做对抗搜索 θ_adv=argmax L_fail——"找出一个合理世界里这次接触会翻车的那个世界"。若连最坏合理仿真都失败，就是强警报。但反过来**"最坏合理仿真都安全"绝不等于安全**，因为仿真-现实落差本身不可预知。于是仿真证据必须**单边**：只否决、不作证。

**灵感 3（合流 → 合成填盲区，但只当"探针候选生成器 + 否决器"）**
直觉：仿真最重要的贡献是**主动探询的样本效率**——用仿真预演"哪个探针最能降低最坏失败质量"，把真机上的一次探针花在刀刃上；再配合第 57 轮 VOI，让探询预算更省。安全结构不变：仿真只出现在"更保守"通道（否决、加宽、降档、绕行），永不出现在"授权"通道。合成数据可以填满语料盲区、让元模型见过更多材质，但**见过 ≠ 作证**。

**灵感 4（可审计性 → 蒸馏提议器，保留显式验证器）**
直觉：能审计的东西才配拥有否决权。黑箱学生无法审计，所以架构上**只蒸馏"提议/快速后验"，把证据门与安全验证器保持为显式符号规则**（第 57 轮 FSE 门原样保留、拒绝被蒸馏）。否则蒸馏会把"可审计的安全"压成一个不可审计的直觉——这正是第 57 轮"一切判定器走隔离"的进一步收紧：**判定器可以快，但不许变模糊**。

**灵感 5（经济学 → 计算节省必须兑换成真实探针下限）**
直觉：蒸馏省下的算力若被拿去"多做几次仿真"会加剧共谋风险，若被拿去"少探真机"会砍掉唯一的真值通道。设**真实探针下限 n_floor(class)**：每类区域每窗口至少若干次带事后实测的探针，合成证据只能降低下限之上的开销、不能替代下限本身。这条下限就是第 57 轮"坏先验普遍"的结构性解药——现实永远保留一次否决合成的机会。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（特权仿真教师 PST）** 参数化 MuJoCo 族 𝕄(θ)，θ=(μ,k,h,geom) 接触参数；特权真值可采样 θ_gt~p_gt；传感器模型 h(o|x,θ)；域随机化先验 p_DR(θ) 附带**覆盖声明** supp(p_DR)。教师 T_ψ(θ|o_{1:k},z) 以特权信息训练；可微物理下支持对抗参数搜索 θ_adv(r)=argmax_{θ∈𝔹(b_r,r)} L_fail(sim(x;θ))（𝔹 为 b_r 的合理支持半径）。教师只在云端训练/更新，边端不持有 θ_gt。

**定义 140（保不确定性蒸馏 UPD）** 学生 S_φ(o_{1:k},z)→(post, abstain)。蒸馏损失 L=𝔼[L_task+λ₁·CRPS(S,T)+λ₂·DisagreeCal(S,T)]。蒸馏证书 𝔇=(𝒞,ε_dist,ε_cal,δ_info,κ_st)：𝒞 为认证覆盖集（z∈𝒞 上 sup TV(S,T)≤ε_dist 且尾部 ECE 差≤ε_cal）；δ_info=𝔼[TV(T(·|θ_gt), S(·))] 特权信息落差；κ_st 学生-教师分歧弃权阈值。运行时：z∉𝒞 或 Disagree(S,T)>κ_st ⇒ 弃权并升级教师/第 57 轮路径。

**定义 141（仿真反事实证伪 SCF）** 设信念 b_r 上的物理参数集，样本集 E={θ_adv}∪{θ_j~b_r}（含 OOD 最坏代表 θ_ood）。失败质量 F_sim(x,r)=P_{θ∈E}[sim(x;θ) fails]。**单边规则**：(R4) F_sim>θ_sim(r) ⇒ 发 EV-sim⁻ **否决**（撤销候选承诺、触发加宽/降档/绕行/再探）；(R5) F_sim≤θ_sim **绝不构成授权证据**，禁止计入任何必要证据集（硬约束，A42）。仿真引导探针 p\*=argmax_p VOI_sim(p)=Ê[ΔF_sim+ΔH(b_r)]。

**定义 142（仿真-现实审计账本 SRA + 真实探针下限）** 仿真记为**永不独立**的模态 m=sim，可靠性 ρ_sim∈[ρ_min,1] 由仿真预测 vs 真实结果的残差 res_sim 更新：res↑⇒ρ_sim↓⇒否决阈值 θ_sim 收紧（更易否决，方向恒保守）。真实探针下限 n_floor(class)：每类区域在窗口 T 内至少 n_floor 次带事后实测 θ̂ 的探针；SYN 证据不可替代下限，且 sim 不计入跨模态独立性（与第 57 轮 A38 合并）。下限未满足 ⇒ 该类区域禁"仅合成支撑"的承诺。

**定义 143（仿真-蒸馏证据门 FSD 与证书 J_s）** 证据类扩为七类：EV-probe\*/visit/margin/xmodal/human（第 57 轮）\+**EV-distill**（仅当 region∈𝒞 ∧ Disagree≤κ_st，可顶替一次 L1 佐证但**禁用于不可逆接触**）\+**EV-sim**（仅否决语义，无正面授权）。不可逆接触必要证据集={真实 EV-probe\*∨EV-margin}∪佐证，且须满足 n_floor；EV-distill 与 EV-sim 均不得入集。J_s=(𝔇,𝒞,ST_disagreement_log,sim_seeds,sim_real_residual,teacher_version,real_probe_floor_log,ρ_sim)，继承 J_p 全检。

**定义 144（仿真-蒸馏探-诺-演 SDP 算子）** 每检查点：①学生快推断；②若弃权/超 κ_st/出 𝒞 ⇒ 升级教师或退第 57 轮 MFSL；③对 L2/不可逆接触先做仿真反事实预演（对抗 θ 搜索 + 集合失败质量），EV-sim⁻ 则 veto→重探/绕行/降档；④n_floor 未满足 ⇒ 安排一次真实探针；⑤承诺 ⇔ 存在 g:R≤δ_f(g) ∧ FSD 门过；⑥否则元悲观 VOI 选探（仿真可作探针提议先验）→绕行→L2 协商→安全停。

```python
def student_fast_or_escalate(S, T, r, obs, cert):
    if r not in cert.coverage:                       # 出认证覆盖：不许用学生
        return escalate(T, r, obs)
    s = S(obs, z=ctx(r))

def sim_veto_only(M, r, x, sim, b_r):
    ths = [argmax_in_support(b_r, lambda th: sim.fail_loss(x, th))] + sample(b_r, N_sim)
    F = mean(sim.fails(x, th) for th in ths)
    M.audit.log_sim(r, ths, F)
    return ('VETO', F) if F > theta_sim(M, r) else ('NO_VETO', F)  # 永不作授权
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| PST | 云端离线；对抗搜索 O(I·c_MJX) | O(\|𝕄\|) | 覆盖声明诚实、θ_gt 不下发 |
| UPD | 学生 O(d_S)≪O(d_φ)；升级 O(d_T) 有界次 | O(\|φ\|) | 𝒞 内 ε_dist/ε_cal、出覆盖必弃权 |
| SCF | O((N_sim+1)·c_sim)/预演（MJX 并行） | O(N_sim) | 仅否决、单边、模拟-现实审计 |
| SRA | O(1)/结果更新 | O(\|class\|) | ρ_sim 单调保守、n_floor 不可侵蚀 |
| FSD | O(\|σ\|) | O(\|σ\|) | EV-sim 无授权、EV-distill 限 L1 |
| SDP | O(\|CP\|·(k_p+k_c)·(C_VOI+d_S)+ \|CP\|·N_sim·c_sim) | O(\|V\|+\|σ\|) | 预演仅否决、n_floor 与终止 |

**正确性定理（SDCS, Sim-Distilled Calibrated Soundness 概要）**：在 A33–A40 上加 (A41) 蒸馏覆盖与尾部保真（z∈𝒞 上 TV(S,T)≤ε_dist、尾部 ECE 差≤ε_cal，出覆盖必弃权）；(A42) 仿真仅否决（EV-sim 不入任何授权集、sim 不独立、ρ_sim 跟踪与残差诚实）；(A43) 真实探针下限不可被经济性侵蚀（合成只降下限之上的开销）。则：(i) 合成/蒸馏对承诺失效的贡献被限制在 ε_dist+ε_cal 且只经"更保守"通道；(ii) 任意区域类在 T 窗口内至少被现实否决一次（n_floor>0），故仿真共谋导致的系统性错不能无限长寿；(iii) 学生 O(1) 快路径 + 有界升级 + 每检查点预演 ≤N_sim，SDP 在 k_probes+k_cons 内终止。

## 6. 本轮最大风险

**一句话**：教师、学生与仿真共用同一套 MuJoCo 接触假设，它们的"一致"看起来像强证据却根本不独立——仿真让盲区变得廉价可生成、蒸馏又抹平了教师的犹豫，于是系统会在现实覆盖最少的地方获得最高的一致性自信，而这一落差只在真实失败发生时才可观测；必须以"仿真只否决、学生出覆盖即弃权、真实探针下限不可侵蚀"三重护栏，坚决不让合成的一致性冒充证据。

```python
            o = sensor_model(simulate(mjcf, theta_gt, policy=\
                coverage_actions(cls)))                         # 主动覆盖
            data.append(((o, ctx(cls)), theta_gt))
    T = fit_teacher(data, privileged=True)                      # 教师见 θ_gt
    cover = coverage_declaration(theta_prior, region_classes)   # 覆盖声明
    return T, cover

def adversarial_theta(b_r, x, sim, radius):
    # 可微物理：在信念合理支持内找"最会失败"的那个世界
    return argmax(lambda th: sim.fail_loss(x, th),
                  init=proj(b_r.mean, supp(b_r)),
                  bounds=ball(b_r.mean, radius))
```

```python
def uncertainty_preserving_distill(T, data, val_grid):
    S = init_student()
    for (o, z), theta in data:
        with no_grad():
            t_dist = T.dist(o, z)                               # 教师分布，非均值
            t_priv = T.dist_priv(o, z, theta)                   # 特权后验

             + lam1 * crps(S.dist(o, z), t_dist)                # 匹配分布/分位数
             + lam2 * disagreement_calibration(S, T, o, z)
        S.update(loss)
    C, eps_dist, eps_cal = certify_coverage(S, T, val_grid)     # TV≤ε_dist 且尾部 ECE
    delta_info = mean(tv(T.dist_priv(o, z, th), S.dist(o, z))
                      for (o, z), th in data)
    return S, DistillCert(C, eps_dist, eps_cal, delta_info)

def student_fast_or_escalate(S, T, r, obs, cert):
    z = ctx(r)
    if z not in cert.coverage:                                  # 出认证覆盖：不许用学生
        return Escalate(reason='out_of_coverage')
    s = S.dist(obs, z)
    if tv(s, T.dist(obs, z)) > kappa_st:                        # 分歧=免费 OOD 警报
```

```python
def sim_counterfactual_veto(M, r, x_candidate, sim, b_r, use_adv=True):
    ths = []
    if use_adv:                                                 # 对抗最坏 + 名义样本
        ths.append(adversarial_theta(b_r, x_candidate, sim, radius=r_adv))
    ths += sample(b_r, N_sim)
    if ood_flag(r):                                             # 盲区代表也纳入
        ths.append(sim.theta_ood_rep(r))
    F = sum(sim.fails(x_candidate, th) for th in ths) / len(ths)
    M.audit.log_sim(r, ths, F)
    M.audit.log_F[r] = F
    if F > theta_sim(M, r):
        return Verdict('VETO', F, ths)                          # 仅撤销/降档/再探
    return Verdict('NO_VETO', F, ths)                           # 绝不构成授权证据

def sim_guided_probe(M, r, b_r, cap):
    cands = admissible_probes(r, M, cap)                        # 非破坏性过滤（继承 A34）
    return max(cands, key=lambda p: exp_dF_sim(p, b_r, M) + exp_dH(p, b_r))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| PST | 云端离线；对抗 O(I·c_MJX) | O(\|𝕄\|) | 覆盖声明诚实、θ_gt 不下发（A41） |
| UPD | 学生 O(d_S)≪O(d_φ)；升级 O(d_T) 有界 | O(\|φ\|) | 𝒞 内 ε_dist/ε_cal、出覆盖必弃权（A41） |
| SCF | O((N_sim+1)·c_sim)/预演（MJX 并行） | O(N_sim) | 仅否决、单边、残差审计（A42） |
| SRA | O(1)/结果更新 | O(\|class\|) | ρ_sim 恒保守、n_floor 不可侵蚀（A42/A43） |
| FSD | O(\|σ\|) | O(\|σ\|) | EV-sim 无授权、EV-distill 限覆盖∧L1 |
| SDP | O(\|CP\|·(k_p+k_c)·(C_VOI+d_S)+\|CP\|·N_sim·c_sim) | O(\|V\|+\|σ\|) | 预演仅否决、n_floor 与终止 |

**正确性定理（Sim-Distilled Calibrated Soundness, SDCS）**
假设 A22–A40 成立；**(A41)** 蒸馏覆盖与尾部保真：z∈𝒞 上 TV(S,T)≤ε_dist 且尾部 ECE 差≤ε_cal，z∉𝒞 必弃权，δ_info 诚实；**(A42)** 仿真仅否决：EV-sim 永不进入任何授权/必要证据集，sim 不计入跨模态独立性，ρ_sim 与 res_sim 跟踪诚实；**(A43)** 真实探针下限不可被经济性侵蚀：每区域类窗口 T 内真实带标签探针 ≥n_floor>0，合成证据只降低下限之上的开销。则：

1. **合成承诺健全性**：承诺中蒸馏/仿真路径的失效贡献 ≤ ε_dist+ε_cal+δ_xm·1[L1]，且 EV-sim 对承诺失效率的贡献 ≤0（只减不增）。
2. **共谋不可长寿**：对任一区域类，n_floor>0 ⇒ 每 T 窗口至少一次真实结果可证伪 ρ_sim 与合成先验，仿真相对于现实永不独立（A42/A43）。
3. **交互单调性保持**：PST/UPD/SCF/SRA 只能经 (a) 𝒞 内更准的信念或 (b) 更保守的参数（否决、θ_sim↓、弃权、降档、n_floor 强制真实探针）影响系统，不存在升险通道。
4. **终止性与预算**：学生 O(1) 快路径、每检查点教师升级有界、预演 ≤N_sim、探针 ≤k_p+k_c，SDP 终止于 {承诺, 绕行, L2 协商, 安全停}。
5. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_dist + ε_cal + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1])
             − P(n_floor 未满足 ∧ 仅合成承诺) − P(学生覆盖违约未检出)
             − P(仿真否决漏检 ∧ 现实未及时证伪)
```

关键：**教师给覆盖、学生给速度、仿真给否决、现实给否决权**——四件事解耦；一致性不再被当作证据（学生-教师一致只在 𝒞 内降级为"可用学生"，从不升格为授权）；仿真的价值被限定为"更早、更省的保守动作"，绝不支付为"更敢赌"。

## 6. 本轮最大风险

**一句话**：教师、学生与仿真共用同一套 MuJoCo 接触假设，它们的"一致"看起来像强证据却根本不独立——仿真让盲区变得廉价可生成、蒸馏又抹平了教师的犹豫，于是系统会在现实覆盖最少的地方获得最高的一致性自信，而这一落差只在真实失败发生时才可观测；必须以"仿真只否决、学生出覆盖即弃权、真实探针下限不可侵蚀"三重护栏，坚决不让合成的一致性冒充证据。
