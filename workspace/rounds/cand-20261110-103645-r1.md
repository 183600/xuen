# 第 43 轮（新循环第 3 轮）· Path-Torque Certificate Seam：用「裕度代数」把路径规划与力矩控制焊成跨层证书（四层架构 v8）

> 承接第 42 轮 v19（SCV × CKB × ECR 飞轮）。第 42 轮把证书从「静态制品」进化为「持续进化的飞轮资产」，但其自陈最大风险是「仿真偏差累积 + 检索幻觉」造成的静默失效。本轮灵感词「路径规划」「力矩控制」看似一高一低，实为同一证书链的两端：路径规划在配置空间消费**几何裕度**，力矩控制在关节空间消费**动力学裕度**。二者之间若没有显式的裕度预算契约，几何证书会在接触、摩擦、饱和处被执行的最后一厘米「悄悄击穿」——这正是飞轮最隐蔽的失效面。本轮提出**证书接缝（Certificate Seam）**：用统一的**裕度代数**把路径裕度与力矩裕度做可组合的预算分解；路径规划器消费 L0 查表边际并预留跟踪预算，力矩安全滤波器在 1kHz 反哺「可跟踪性压力」，飞轮把接缝反例作为一等公民入库与回归。

## 0. 直觉与动机

**灵感 1（路径规划 → 从「避障几何」到「证书走廊」）**：经典路径规划只回答「哪里不撞」，但证书系统真正需要回答「哪里还能保住安全裕度」。直觉是把 L0 证书表里的 m_lo(x) 当作规划空间里的**电势场**——不是只要 x∉障碍，而是要求整条路径上 m_lo 始终大于阈值加一段**鲁棒管半径**。这把路径规划从「可行性问题」升级为「裕度分配问题」：规划器显式地为未来一段轨迹**预留**跟踪误差与扰动预算，从而避免「路径很美、执行崩溃」。更进一步，规划器在生成候选时就用近似逆动力学做**力矩可行性预筛**，把「几何可行但力矩不可行」的路径挡在下游 QP 之前。

**灵感 2（力矩控制 → 最后一厘米的证书安全滤波器）**：再好的路径也要靠关节力矩落地。直觉是在力矩层放一个**证书条件安全滤波器（Torque Cert Shield, TCS）**——每 1ms 解一个极小 QP：在力矩上下限、执行器额定、接触摩擦锥与「边际不低于 θ」的约束下，找离期望力矩最近的可行力矩。它不改变上层意图，只把**不可执行的意图投影回可执行且可认证的集合**。更关键的是 QP 的对偶变量天然给出「哪个约束在紧」的信号，可作为**接缝压力 p_seam** 回传规划器：接触摩擦吃紧 → 规划器绕开高接触依赖的走廊；力矩饱和吃紧 → 规划器降速或换姿态；边际吃紧 → 提前预警而非等到不可行。

**灵感 3（接缝 → 裕度代数与飞轮的一等公民）**：路径层与力矩层各自 sound，不代表组合 sound。接缝的典型失效机制是**接口假设泄漏**：路径层默认「跟踪误差 ≤ ρ」，力矩层默认「参考不可行时上层会及时重规划」，任何一方默许另一方兜底，就会在罕见接触工况出现「局部各自正确、全局悄悄错误」。直觉是像类型系统一样给两层写**接口契约 IC**（规划承诺最小几何裕度、控制承诺最大跟踪误差与触发延迟），用**裕度代数**（预算相加、裕度取 min）做组合，并把违反契约的轨迹作为**接缝反例**存入 CKB，供 SCV 回归与 RAG 热启动。

**与第 42 轮飞轮的耦合**：SCV 增加「力矩不可行注入 + 接缝压力测试」；CKB 增加「恢复机动模板 + 接口契约快照」；ECR 增加 1kHz 定点力矩滤波；CAP/TCS 分别消费与反哺 L0 表，形成 **Plan→Torque→Seam→KB→Plan** 的内环，套在 Sim→RAG→Edge 的外环里。证书由此从「单层可验证」升级为「跨抽象层可组合」。

## 1. 形式化定义（增量：定义 38–44）

**定义 38（裕度预算分解）**：沿规划轨迹 {x_k}，执行期真实边际满足
m_exec(x_k) ≥ m_path(x_k) − L_trk·e_trk(x_k) − L_dist·d_k，
其中 m_path 为路径层几何裕度，e_trk 为跟踪误差，d_k 为未建模扰动，L_trk、L_dist 为对应 Lipschitz 界。定义总预算 Γ_total = Γ_path + Γ_trk + Γ_dist，其中 Γ_path = m_path − θ，Γ_trk = L_trk·ē_trk，Γ_dist = L_dist·d̄。**接口契约 IC**：(a) 规划器保证 m_path ≥ θ + Γ_trk + Γ_dist + ε_ic；(b) 控制器保证 e_trk ≤ ē_trk 且重规划响应延迟 ≤ T_react。若双方均守信，则 m_exec ≥ θ + ε_ic，组合证书 sound。

**定义 39（证书感知鲁棒管规划 CAP）**：π* = argmin_{π∈Π} J(π) s.t. ∀k∈[0,H]：
m_lo(x_k^nom) ≥ θ + L_m·ρ_k + Γ_trk，x_k^nom ∈ X_free，τ_k^nom ∈ F_τ(x_k^nom)。
其中 ρ_k 为扰动管半径（由 d_k 界与局部反馈增益递推），m_lo 来自 L0 查表。输出路径证书 C_path = (π, m_path(·), {ρ_k}, Γ_trk, IC_path)。**命题 39**：若 δ_grid·L_m ≤ η 且 CAP 可行，则 C_path 在管 {x : ||x − x_k^nom|| ≤ ρ_k} 上 sound（含查表插值误差 η）。

**定义 40（力矩可行域与可跟踪性证书）**：F_τ(x) = {τ : τ_min ≤ τ ≤ τ_max, |τ_i| ≤ τ_rated,i, A_c(x)τ ≤ b_c(x)（摩擦锥/接触/关节耦合），m_τ(x,τ) ≥ θ}。定义**力矩裕度** μ_τ(x) = dist(τ*, ∂F_τ)（加权 2-范数下到可行域边界的距离）。**可跟踪性证书**：存在力矩序列 {τ_k} ⊂ F_τ 使跟踪误差 ≤ ρ_k 且 μ_τ ≥ μ_min。μ_τ 把「能不能执行」从布尔量变成连续量，便于预算分配与提前预警。

**定义 41（证书条件力矩分配 CCTA）**：τ* = argmin_τ ½||τ − τ_des||_W² + λ_μ·(−μ_τ) s.t. τ ∈ F_τ(x)。工程上取两阶段：先解安全滤波 QP（硬约束 τ∈F_τ），再用对偶变量 λ_c ≥ 0 表示约束紧度。**接缝压力** p_seam = Σ_c λ_c·||c(x)||，按约束类别分解为 (torque_sat, friction, margin, contact)，作为规划器的反馈信号。

**定义 42（跨层证书组合 / 裕度代数）**：定义带预算的裕度对象 (m, Γ)，组合算子 ⊗：m_composed = min(m_path − L_trk·e_trk, m_τ)；Γ_composed = Γ_path ⊕ Γ_trk ⊕ Γ_dist（预算相加）。组合合法的充要条件是**接口契约检查** IC_path ⊓ IC_tcs 一致（双方对 ē_trk、ρ_k、触发频率、适用工况的假设相容）。**定理 42（组合 soundness）**：若 (i) 两层各自 sound，(ii) IC 一致，(iii) 接缝触发重规划延迟 ≤ T_react 且重规划落在 braking-safe envelope 内，则组合系统 sound；任一条件失效，则 soundness 不能由局部证书推出。

**定义 43（接缝反例与检索式恢复重规划）**：接缝反例 ξ_seam = (x_seam, 标签 ℓ, 局部力矩剖面 τ_[t−w,t], 触发约束类 c, 成功恢复机动 m_rec)。当 μ_τ < τ_reserve 或 QP 近不可行时，以 (φ, ψ, p_seam) 检索 CKB 中相似恢复机动，初始化局部重规划（缩短时域 H、放宽容差或切换步态），并把本次结果回写 CKB。**风险谓词**：若检索失败则退化为 SafeStop（单调保守降级），绝不允许「带着不确定继续」。

**定义 44（跨层实时预算 v3）**：在线预算 Γ_rt = Γ_plan + Γ_torque，规划层 20–50Hz 消费 L0 查表 + CAP（≈5–20ms），力矩层 1kHz 消费定点 QP/INT8 滤波（≈100–500μs）。总拥有成本 COT_v3 = COT_v2 + C_seam_verify·N_seam，其中 C_seam_verify 因 CKB 恢复模板复用而摊销下降；Pareto 前沿新增「接缝违例率」维度。

## 2. 产出设计（新增 IP-57/58/59 + 升级 IP-39/45/47/49/51/54/55/56）

### 2.1 IP-57 CERT-AWARE-PLANNER（CAP，证书感知鲁棒管规划）
1. **裕度势场**：用 L0 表 m_lo(x) 构造规划代价 J = J_len + w_m·Σ max(0, θ + L_mρ_k + Γ_trk − m_lo(x_k))，把「接近证书边界」变成软惩罚，越界成为硬约束。
2. **鲁棒管预算**：ρ_k 由局部反馈增益与 d_k 界递推；Γ_trk 由定义 38 的 IC 写入，规划器不越权假设控制更准。
3. **力矩可行耦合**：候选轨迹先过 F_τ 的快速可行性筛（近似 τ = M(q)q̈ + C(q,q̇) + g(q)），剔除「几何可行但力矩不可行」的路径，减少下游 QP 不可行率。
4. **接缝反馈**：订阅 p_seam，按约束类加权走廊代价；friction 紧 → 加大离接触面/障碍的裕度；torque_sat 紧 → 降速度/加速度上限；margin 紧 → 提前收窄管半径。

### 2.2 IP-58 TORQUE-CERT-SHIELD（TCS，力矩证书安全滤波器）
1. **1kHz 定点 QP**：变量 τ∈R^n，约束含箱约束、执行器额定、摩擦锥线性化、边际线性化 m_τ ≈ m_τ0 + G_τ(τ − τ0) ≥ θ；用主动集/显式查表在 Orin Nano 或 STM32H7 上跑。
2. **近不可行预警**：软约束松弛量 s_c ≥ 0 的极小化给出「还有多远不可行」；μ_τ < τ_reserve 时提前 T_warn 报警，而非等到 infeasible。
3. **对偶接缝信号**：按约束类聚合 λ_c，发布 p_seam；带死区与 EWMA 防抖，避免反馈震荡。
4. **安全回退**：QP 不可行 → 阻尼/制动可行力矩 + SafeStop，绝不输出未认证力矩。

### 2.3 IP-59 SEAM-CERT-COMPOSER（SCC，接缝证书组合器）
1. **接口契约 DSL**：声明 (承诺裕度, 允许误差, 触发延迟, 适用域)；组合前做契约一致性检查，不可满足即拒绝组合。
2. **裕度代数引擎**：实现定义 42 的 ⊗ 与预算核算，输出组合证书与「预算余量热力图」。
3. **接缝反例归因**：复用 IP-54 归因器，新增 seam 标签（friction_collapse / torque_saturation / tracking_lag / contact_switch / contract_mismatch）。
4. **RAG 恢复检索**：以 (φ, ψ, p_seam) 检索恢复机动模板，生成局部重规划初值并回写版本化记录。

## 3. 四层架构 v8

```
L1: TRI-FUSE(INT8) + IP-49 LIO → C_ms + B_t + L_m(经验分位) + 动力学参数估计(供 F_τ)
L2: CTC + VLM + IP-35 仲裁 → R_φ(w) + 几何残差证书 → CKB 指纹 (φ, ψ)
L3: IP-51 CAR(组合边际守卫) ← IP-56 ECR(L0查表 + L1 INT8 + IP-58 TCS 1kHz + μ_τ监控)
    → IP-57 CAP(证书走廊 + Γ_trk 预留 + F_τ 预筛) → IP-39 规划(CBF margin=查表 m_lo)
    → IP-47 乘积模板(含跨层 IC) → IP-45 总线(p_seam/μ_τ/重规划请求)
    → IP-48 认证流匹配(N*=查表 j*) + IP-43 韵律调度 → IP-53 CMC(看门狗=L1 INT8 + TCS)
L4: IP-55 CKB(接缝指纹 + 恢复机动 + IC 快照) ← IP-54 SCV(域随机化 + 力矩不可行注入 + 接缝压力测试)
    → IP-59 SCC(裕度代数 ⊗ + 契约检查 + 反例归因) → IP-44 蒸馏 + IP-50 课程(RAG 迁移)
    → RCA 重颁证书(含跨层预算) → 契约热更新
运行期: CAP 20–50Hz(5–20ms) → TCS 1kHz(100–500μs) → p_seam 反馈 → 近不可行预警 → 检索恢复重规划 → 飞轮更新
```

## 4. 实验设计（E87–E94 硬门槛，承接 E79–E86）

| 实验 | 指标 | 门槛 |
|---|---|---|
| E87 裕度预算标定 | 执行边际 ≥ 预算预测比例；Γ 各项实测占比 | ≥95% 达标；预算不超支 |
| E88 证书走廊规划 | 任务成功率、走廊保持率、规划时间 | 成功率 ≥ 基线 +10pp；保持率 ≥99%；<50ms |

| E90 接缝反馈 | p_seam 反馈后重规划率、二次不可行率 | 重规划率 <5%/min；二次不可行 ↓≥50% |

| E92 恢复检索 | 恢复机动检索命中率、重规划恢复时间 | 命中 ≥90%；<100ms |
| E93 长时程全身任务 | 100h：不安全事件、Nominal、接缝违例 | 0 起；Nominal ≥80%；违例 0 |
| E94 对比第 42 轮 | 成功率、可用性、COT、接缝失效率 | 成功率 ↑；COT ≤ 1.2×；接缝失效 ↓≥10x |

回退：E87 预算超支 → 提高 Γ_trk/Γ_dist 保守份额，降速运行；E89 实时超预算 → 显式查表 QP + 降采样力矩层；E90 反馈震荡 → p_seam 加死区/限幅；E91 出现 false-safe → 收紧 IC、扩大 ρ_k，回退第 42 轮组合方式；E92 检索无命中 → 关闭检索，走保守 SafeStop。

## 5. 本轮最大风险

**一句话**：跨层裕度代数依赖**接口契约双方同时守信**，而路径层对「跟踪误差 ≤ ē_trk」、力矩层对「上层会及时重规划」的假设在罕见接触工况下可能同时失效——若 SCV 的力矩不可行注入覆盖不到该工况、且 CKB 检索给出高置信却不适用的恢复模板，组合证书会呈现「每层都 sound、接缝处悄悄击穿」的假安全；因此 E91（跨层组合 soundness）必须作为红线实验，任何 false-safe 即熔断回退到第 42 轮的单层保守组合。

## 1. 符号体系（增量：定义 38–44 符号）

| Γ_total = Γ_path ⊕ Γ_trk ⊕ Γ_dist | 总预算 | 预算相加；各分项由 IC 分派 |
| m_path ≥ θ + Γ_trk + Γ_dist + ε_ic | 规划契约 IC_path | 规划器承诺的最小几何裕度 |
| e_trk ≤ ē_trk, T_react ≤ T_react_max | 控制契约 IC_tcs | 控制器承诺的跟踪误差与重规划延迟 |
| m_composed = min(m_path − L_trk·e_trk, m_τ) | 组合边际 | 跨层裕度取 min（保守） |
| F_τ(x) | 力矩可行域 | 箱/额定/摩擦锥/接触 + 证书边际约束的交集 |
| μ_τ(x) = dist(τ*, ∂F_τ) | 力矩裕度 | 到可行域边界的加权距离，连续可预警 |
| p_seam = Σ_c λ_c·||c(x)|| | 接缝压力 | QP 对偶按约束类聚合，反馈给规划器 |
| ξ_seam = (x, ℓ, τ_[t−w,t], c, m_rec) | 接缝反例 | 状态、标签、力矩剖面、触发约束类、恢复机动 |
| COT_v3 = COT_v2 + C_seam_verify·N_seam | 总拥有成本 v3 | 接缝验证成本随 CKB 恢复模板复用摊销 |

## 2. 关键算法（伪代码）

### IP-57 CAP：证书感知鲁棒管规划
```
def cert_aware_plan(x0, goal, L0, Ftau_approx, IC, H=20, dt=0.1):
    # 1. 证书势场：L0 查表得边际下界
    def margin(x): return L0.lookup(x).m_lo

    # 2. 鲁棒管半径递推（扰动界 + 局部反馈增益）
    rho = [tube_radius(k, dt, d_bar=IC.d_bar, K_fb=IC.K_fb) for k in range(H)]

    # 3. 代价 = 路径长度 + 证书势场惩罚 + 接缝压力加权
    J = cost_len(pi) \
        + w_m * sum(relu(theta + L_m * rho[k] + IC.Gamma_trk - margin(x_k))
                    for k, x_k in enumerate(pi)) \
        + w_seam * p_seam_weighted(pi)

    # 4. 约束
    subject_to:
        x_k not in X_obs
        margin(x_k) >= theta + L_m * rho[k] + IC.Gamma_trk      # 证书走廊
        tau_nominal(x_k) in Ftau_approx(x_k)                     # 力矩可行预筛
        if p_seam.contact_tight: corridor_width += delta_c       # 接缝反馈
        if p_seam.torque_sat:    v_max *= 0.8; a_max *= 0.7

    return C_path(pi=pi, m_path=margin, rho=rho,
                  Gamma_trk=IC.Gamma_trk, IC_path=IC.path)
```

### IP-58 TCS：力矩证书安全滤波器（1kHz）
```
def torque_shield_qp(x, tau_des, theta, tau_reserve):
    # 线性化证书边际：m_tau(x,tau) ~= m0 + G (tau - tau0)
    tau0 = nominal_torque(x)
    m0   = margin_model(x, tau0)
    G    = jacobian_margin_wrt_tau(x)

    # 硬约束：箱约束 / 额定 / 摩擦锥线性化 / 证书边际
    A, b = assemble_constraints(x)     # torque, friction, contact
    # 软松弛 s 仅用于「近不可行」度量，不用于放行硬安全
    tau_star = argmin 0.5 * ||tau - tau_des||_W^2 + rho_s * ||s||_1
               s.t. A @ tau <= b + s
                    m0 + G @ (tau - tau0) >= theta
                    tau_min <= tau <= tau_max

    lam    = dual_variables()                # 每个约束的对偶
    p_seam = classify_pressure(lam)          # {torque_sat, friction, margin, contact}
    mu_tau = distance_to_boundary(tau_star, A, b)

    if infeasible(tau_star) or mu_tau < tau_reserve:
        # 绝不输出未认证力矩：退化为制动/阻尼可行力矩
        return braking_torque(x), 'WARN', p_seam, mu_tau
    return tau_star, 'OK', p_seam, mu_tau
```

### IP-59 SCC：裕度代数组合 + 接缝反例归因
```
def compose_certificates(C_path, C_torque, IC):
    # 1. 接口契约一致性检查（误差/延迟/适用域）
    if not contracts_compatible(C_path.IC, IC, C_torque.IC):
        raise ContractMismatch('seam contract leak')

    # 2. 裕度代数 ⊗：裕度取 min，预算相加
    m_comp = min(C_path.m - L_trk * C_torque.e_trk, C_torque.m_tau)
    Gamma_comp = add_budget(C_path.Gamma_path, C_torque.Gamma_trk,
                            IC.Gamma_dist)

    # 3. 组合 soundness 前置条件（定理 42）
    pre = (C_path.m >= theta + IC.Gamma_trk + IC.Gamma_dist + IC.eps_ic
           and C_torque.e_trk <= IC.e_bar
           and C_torque.T_react <= IC.T_react_max)
    return CompositeCert(m=m_comp, Gamma=Gamma_comp,
                         precondition=pre, IC_snapshot=IC)

def attribute_seam_counterexample(xi, tau_window):
    labels = []
    if contact_switch_fast(xi):        labels.append('contact_switch')
    if torque_sat_ratio(xi) > 0.95:    labels.append('torque_saturation')
    if friction_margin(tau_window) < eps_f: labels.append('friction_collapse')
    if tracking_lag(xi) > IC.e_bar:    labels.append('tracking_lag')
    if contract_leak(xi):              labels.append('contract_mismatch')
    return SeamCounterexample(
        seam_state=xi.x0, labels=labels,
        root_cause=majority_vote(labels),
        tau_window=tau_window, recovery=None)
```

## 6. 本轮最大风险

**一句话**：跨层裕度代数依赖**接口契约双方同时守信**，而路径层对「跟踪误差 ≤ ē_trk」、力矩层对「上层会及时重规划」的假设在罕见接触工况下可能同时失效——若 SCV 的力矩不可行注入覆盖不到该工况、且 CKB 检索给出高置信却不适用的恢复模板，组合证书会呈现「每层都 sound、接缝处悄悄击穿」的假安全；因此 E91（跨层组合 soundness）必须作为红线实验，任何 false-safe 即熔断回退到第 42 轮的单层保守组合。
