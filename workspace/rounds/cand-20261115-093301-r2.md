# 第 4 轮（灵感循环第 4 轮；本轮灵感：「语言指令」×「记忆检索」）

> **基线**：第 3 轮 InstructGauge（IP-321–327；定义 432–447；引理 51–58；实验 E441–E456）。MODGAUGE / LeanGauge / ToolGauge / InstructGauge 骨架继续继承不变。
> 本轮纪律：**增量升级 + 严格退化**。记忆是增强项、不是依赖项：检索不可用 / 为空 / 全部不可信 ⇒ 逐字节退回 InstructGauge；InstructGauge 失效 ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE。

## 0. 直觉与动机

**灵感 1（语言指令 → 指令不只是解析对象，也是检索的查询）**
直觉：工程师说「先看左边金属件，反光强就上偏振」时，这句话在新工件上并不能独立消解指代——「左边」相对谁、哪个金属件、什么算反光强，都要靠**这类件以前怎么修**来补全。InstructGauge 把 ℓ 一次性接地成 ι，隐含假设是「当前场景已足够消歧」；但真实修复里，指令天然是**欠定的**，而人靠回忆补全它。正确的升级不是让语言更自由，而是把 ℓ 同时当作**记忆检索的 query**：检索返回的不是答案，而是「过去在相似场景下如何把同类欠定指令落成 ι」的候选先验。

**灵感 2（记忆检索 → 二手证据，不是权威）**
直觉：记忆有三种原生缺陷。其一是**陈旧**：上次那个工件反光强是因为涂层，这次换了材料，同样的视觉线索不再成立。其二是**选择偏差**：系统只记忆「执行过且看起来成功」的分支，未执行的反事实分支永远缺席，于是经验会系统性高估某些做法。其三是**可污染**：一条被提示注入或人为篡改的历史记录，会以「过去经验」的权威姿态进入当前决策。因此记忆的正确用法不是「检索到就用」，而是「检索到**可被当前回执重新验证的假设**」——**记忆负责提议，当前证据负责裁决**。

**灵感 3（两者耦合 → 指令既查记忆又写记忆，形成回声闭环）**
直觉：最危险的耦合不是单次检索错误，而是**回声室**。系统用指令检索到过去由自己输出生成的记忆，据此接地并执行，再把这次执行写成新记忆；下一轮检索到的是「自己的后代」，置信度被自我确认不断放大，最终把一次偶然成功固化成「经验法则」。语言指令还给它披上可读、可信的外衣。要压住它，必须同时有：**重接地硬门**（记忆必须先在当前场景重新识别锚点）、**负记忆单调**（失败经验只能剪枝，不能扩权）、**血缘衰减**（记忆的祖先深度指数折扣）、**写入闸门**（只有带回执与独立交叉验证的记录才可操作）。这四条合起来，才是「记忆增强」而非「记忆支配」。

## 1. 研究问题（本轮要回答什么）

- **Q1（何时可用）**：一条历史记忆在什么条件下可以被安全用于当前指令接地？「相似」是否足以构成使用理由？
- **Q2（是否扩权/放大）**：记忆条件化的接地与规划，会不会突破 InstructGauge 的能力闭包？会不会通过血缘自我放大错误？
- **Q3（统计保真）**：检索按指令与场景选择样本，破坏共形校准的可交换性；在这种**检索条件化**下，覆盖率还能否被守住？

## 2. 四条设计原则（雏形，正式化见产物区定义 448–462）

**P1 记忆不授权（Memory Non-Authority）**
记忆只能生成**槽位先验、候选排序与负约束**，不能命名新工具、不能指定超出物理包线的幅值、不能绕过安全盾。形式化方向：记忆条件化后的计划集仍是 `Plan_ToolGauge` 的子集，检索在类型系统里没有「扩权通道」。

**P2 可重接地硬门（Re-groundability Gate）**
任何被使用的记忆，必须在**当前场景**重新识别其指代锚点 `anchor(m)`，并匹配其适用范围 `scope(m)`；重识别置信度低于 `τ_reid` 或 scope 不匹配 ⇒ **直接丢弃**，而不是降权保留。相似不等于适用；只有当前证据能把记忆「重新接上地」，它才有资格进入接地。

**P3 负记忆单调（Negative Memory Only Prunes）**
失败经验（已验证的失败块 / 失败条件）只能以 `Φ_neg` 的形式**剪枝**候选计划，绝不能新增或放宽任何计划。这样即使负记忆本身有误，最坏后果是「少做/放弃」（可用性损失），而不是「做错」（安全性损失）；剪枝到空集则退回默认目标或放弃。

**P4 血缘衰减防回声（Lineage Decay）**
每条记忆记录其派生祖先集合，检索权重按 `γ^{ech(m)}` 指数折扣，深度上限 `D_mem`，且血缘图必须无环。单条原始噪声记忆对当前决策的总影响被几何级数夹住，回声无法发散。

## 3. 与基线的接口（如何退化）

- 检索为空 / 超时 / 全部被重接地门拒绝 ⇒ 使用 InstructGauge 原路径（逐字节等价）；
- 记忆只含轶事（anecdotal）或隔离（quarantined）记录 ⇒ 只进解释层，不进数值路径；
- 检索分层样本不足 ⇒ 回退 InstructGauge 的全局共形阈值；
- 记忆条件化后计划集为空（负记忆过度剪枝）⇒ 放弃并回退默认 ι₀，绝不放宽约束；
- InstructGauge 失效 ⇒ ToolGauge；ToolGauge 失效 ⇒ LeanGauge；LeanGauge 失效 ⇒ MODGAUGE 原样。

## 4. 预期贡献

1. 一个「指令即查询、记忆即先验」的接地口径，把历史经验限制在**只改偏好、不改能力**的子集选择层；
2. 一个**重接地硬门 + 记忆有效性证书**，把「相似」升级为「当前可重新识别且 scope 匹配」的可审计适用性；
3. 一个**负记忆单调 + 血缘衰减 + 写入闸门**的安全组合，把记忆回声与投毒从无界压到可界，并给出可证伪界；
4. 一个**检索分层 + 在线共形**的校准方案，修正「检索条件化破坏可交换性」导致的覆盖失效；
5. 一条完整可证伪路径：E457–E472 覆盖重接地、非扩张、投毒、回声、幸存者偏差、分层覆盖、陈旧检测、擦除与 50Hz 时序保全。

## 5. 本轮最大风险

**一句话**：记忆检索最危险的不是「记错」，而是让系统把「过去成功过」误当成「现在成立」；一次绕过重接地否决的高置信错误记忆，会以权威姿态同时污染指令接地与统计校准，并通过血缘在后续轮次自我确认——真正的残余风险是**记忆的权威化与回声室**，而非检索精度本身。

## 2. 形式化定义（要点）

**定义 448（记忆记录 m）** `m = (id, t_m, fp, ℓ, ι, C, R, y, scope, anchor, lin, sig)`。其中 `fp` 为场景指纹，`ℓ` 为原始指令，`ι` 为当时接地得到的指令规格，`C` 为执行块，`R` 为逐步回执，`y ∈ {success, fail, unknown}` 为**经回执验证**的结果（非自报），`scope` 为适用条件（对象类别、材质、光照区间等），`anchor` 为指代锚点（可在新场景重识别的结构化描述，而非图像坐标），`lin ⊆ Id` 为派生祖先集合，`sig` 为来源签名/信任级别。

**定义 449（信任类型与可操作性）** `ver(m) ∈ {verified, anecdotal, quarantined}`。`actionable(m) ⇔ ver(m)=verified ∧ sig ∈ Trusted ∧ ¬quarantined`。`anecdotal` 只能作为解释文本；`quarantined` 只读隔离，永不进入数值路径。此定义是 InstructGauge 定义 441（NCB 纯投影）在记忆层的延拓：**没有证据绑定的记忆不是证据**。

**定义 450（检索算子 R_ret）** 查询 `q = (embed(ℓ), fp(σ), g_prior)`，
`R_ret(q, M, k) = TopK_{m ∈ M, scope(m) ⊨ cond(σ)} score(q,m)`，
`score(q,m) = λ_s·sim_ℓ(ℓ,ℓ_m) + λ_v·sim_fp(fp, fp_m) + λ_g·sim_g(g,g_m) − λ_age·(t−t_m)`。
检索只返回候选与分数，不返回可直接执行的计划；近重复记录按 `(ℓ, scope, anchor)` 去重。

**定义 451（重接地硬门 applicable）** `applicable(m, σ) ⇔ scope(m) ⊨ cond(σ) ∧ reid(anchor(m), σ) ≥ τ_reid ∧ MVC(m,σ) ≠ ⊥`。
**关键**：不满足即丢弃，不降权保留。`reid` 由当前传感器回执在**结构化锚点**上评估（如「左侧、金属、可反光」），而非图像像素相似度；这使「看起来像」与「确实是同一指代」被区分开。

**定义 452（记忆条件化接地与冲突消解）** 设可用记忆集 `U(σ) = {m ∈ R_ret : applicable(m,σ)}`。记忆只诱导槽位先验 `π_mem(ι | ℓ, σ, U)` 与候选排序；接地仍走 InstructGauge 的 Γ。冲突消解：若按 `score·MVC` 加权后的槽位分布熵 `H(ι|ℓ,U) > H_MAX`，或前二候选的加权质量差 `< δ_conf` ⇒ 输出 ⊥，退回默认 `ι₀`。`Plan_mem(ι) = {Π ∈ Plan_ToolGauge : Π ⊨ Φ_neg(U), Π 按 π_mem 排序}`，且 `Plan_mem ⊆ Plan_ToolGauge`（引理 59）。

**定义 453（记忆有效性证书 MVC）** `MVC(m,σ) = (id, receipts_refs, reid_ev, scope_match, freshness, cross_val, ver, h_erase)`。缺任一项 ⇒ `MVC = ⊥`，该记忆降级为轶事。证书本身可被审计重放：`receipts_refs → 原始回执`，`reid_ev → 当前重识别证据`。

**定义 454（血缘 DAG 与回声系数）** `lin(m)` 指向生成 `m` 时使用的记忆祖先；要求 `lin` 无环。`ech(m)` 为从某根记忆到 `m` 的最长路径；检索有效权重 `w_m = score(q,m)·fresh(m,t)·γ^{ech(m)}`，`0 < γ < 1`，且 `ech(m) > D_mem` 的记忆被拒绝。写入时 `lin(m) = {可用祖先 id}`，故派生关系不可伪造（由写入闸门校验）。

**定义 455（负记忆与单调剪枝）** `Φ_neg(U) = ⋀_{m ∈ U, y(m)=fail, ver(m)=verified} ¬cond(m)`；负记忆只加到计划约束的合取侧，因此 `Plan_mem = Plan ∩ Φ_neg ⊆ Plan`。剪枝是**单调**的：新增负记忆只会缩小集合。若 `Plan_mem = ∅` ⇒ 放弃并回退默认目标，**绝不放宽** `Φ_neg`。注意：错误的负记忆会造成过度剪枝（可用性损失），但不会引入不安全动作（引理 61）。

**定义 456（陈旧度与重新验证）** `fresh(m,t) = exp(−λ_age·(t−t_m))·exp(−λ_shift·TV(scope(m), scope(σ_t)))`。若 `fresh < τ_fresh` 或分层漂移检测（沿用 ToolGauge 定义 446）触发 ⇒ 记忆必须用**当前新回执**重验后才能重新变为 `actionable`；否则只作解释。

**定义 457（记忆写入闸门 MWG）** `write(m) 允许 ⇔ receipts(R) 完整 ∧ independent_cross_val(R) ∧ sig ∈ Trusted ∧ scope 与 anchor 显式 ∧ lin 合法无环`。不满足 ⇒ 写入 `quarantined` 区，`actionable = false`。外部自然语言文本（网页、用户闲聊、提示注入）**没有**写入可操作记忆的通道——这是「能力闭包」在记忆层的形式对偶。

**定义 458（幸存者偏差校正 SBC）** 设日志策略 `μ_log` 决定哪些分支被记录，倾向 `e(m) = P_μ(m 被记录 | 被执行)`。成功率的 IPW 估计
`p̂_IPW = (Σ_m 1[y_m=1]/e(m)) / (Σ_m 1/e(m))`。
仅当 `e(m) ≥ e_min > 0`（正性假设）时可用；`e(m) < e_min` 的记忆标记为 `biased`，不参与成功率先验，只可用于「曾经失败」的负记忆（失败记录受选择偏差影响方向相反、更保守）。

**定义 459（检索分层共形 SC-Cal-R）** `stratum(ι,m) = (s_ι, s_r)`，其中 `s_ι` 沿用定义 438，`s_r ∈ {hit-verified, hit-anecdotal, miss}`。每层用校准集 `C_cal^s` 取分位 `q_s` 使层内 `P(h*∈H_s | s) ≥ 1−α`。当检索策略随历史自适应时，层内可交换性被破坏 ⇒ 启用 ACI 更新 `q_{s,t+1} = q_{s,t} + η(α − err_t)`，保证长期覆盖率；`|C_cal^s| < n_min` ⇒ 回退 InstructGauge 全局阈值。

**定义 460（检索预算与异步窗口）** `B_ret = (K_RET, c_ret_max, W_async)`；检索与重接地必须在 `W_async` 内完成，否则使用缓存/默认，且不得阻塞 50Hz 主路径。`c_ret` 记为单次检索（含重识别）开销。

**定义 461（MemGauge-9C 闭环）** `I→R→G→H→C→E→C→V→U`：I 解析指令；R 检索；G 重接地/记忆条件化接地；H 假设；C 分块；E 执行（含 InstructGauge CVC 否决点）；C 校准；V 验证；U 更新（含写入闸门）。相对 InstructGauge-7C 只新增 R 与 G 的记忆分支、U 的写入闸门，其余阶段接口不变。

**定义 462（记忆擦除）** `erase(id)` 沿 `lin` 反向传播，删除或匿名化所有后代可操作记忆，并在审计日志写入 `h_erase = H(id, 删除范围, 时间)`；擦除后不得残留可用于重识别的锚点明文。擦除是**安全与合规要求**，不是可选优化。

# IP-328 MIR：双塔检索（只出候选）
class MemoryRetriever:
    def retrieve(self, ell, scene, memory, k, budget):
        q = Query(embed_instruction(ell), scene.fingerprint, scene.goal_prior)
        cands = self.index.search(q, k * 3, budget)          # scope 预过滤
        cands = dedup(cands, key=lambda m: (m.ell, m.scope, m.anchor))
        ranked = sorted(cands, key=lambda m: self.score(q, m), reverse=True)
        return ranked[:k]

# IP-329/330 RGG + MVC：重接地硬门（不过则丢，不降权）
class ReGroundGate:
    def usable(self, m, scene):
        if not scope_match(m.scope, scene.cond):
            return None
        anchor = reidentify(m.anchor, scene)                 # 结构化锚点，非像素
        if anchor.conf < TAU_REID:
            return None                                      # 丢弃
        cert = MVC(m, scene, anchor, verify_receipts(m))
        return (m, cert) if cert is not None else None

# IP-331 MGP：记忆只改先验/排序/负约束
class MemGrounder:
    def ground(self, ell, scene, usable, ontology, default_iota):
        if not usable:
            return default_iota, None                        # 退化 InstructGauge
        priors = aggregate_priors([(m, c) for m, c in usable],
                                  weights=lambda m: m.weight * gamma ** ech(m))
        if conflict_entropy(priors) > H_MAX:
            return default_iota, None                        # 冲突 ⇒ ⊥
        iota = self.nlib.ground(ell, scene, ontology, priors)
        iota.cons &= neg_constraints([m for m, _ in usable]) # 只剪枝
        if iota is None or not plan_nonempty(iota):
            return default_iota, None                        # 过度剪枝 ⇒ 放弃
        return iota, GroundCert(iota, usable)

# IP-332/333 LDL + MWG：写入闸门 + 血缘
class MemoryWriteGate:
    def commit(self, m, used_ids):
        if not (complete_receipts(m) and independent_cross_val(m)
                and trusted(m.sig) and explicit_scope(m)
                and acyclic(used_ids)):
            m.ver = QUARANTINED
            self.store.write_quarantine(m)
            return False
        m.lin = set(used_ids)
        m.ech = 1 + max((self.store.ech(i) for i in used_ids), default=0)
        if m.ech > D_MEM:
            m.ver = ANECDOTAL                            # 血缘过深，不再可操作
        self.store.write_actionable(m)
        return True

# IP-335/336 SC-Cal-R + 9C
class MemGauge9C:
    def step(self, M, s, ell):
        mems = M.retr.retrieve(ell, s, M.memory, K_RET, M.ret_budget)
        usable = [u for m in mems if (u := M.gate.usable(m, s)) is not None]
        iota, gcert = M.mgp.ground(ell, s, usable, M.ontology, M.default_iota)
        H  = M.lbox.hypothesize(s, M.dbox.R[s], iota)         # 记忆只重排先验
        C  = M.iac.plan_chunk(iota, H, M.tools, M.budget_left(s), M.drift_bound(s))
        if not M.tcv.verify(C.as_program(), M.budget_left(s))[0]:
            C = M.numeric_fallback(H)
        cert = M.cvc.commit(C, M.env, iota)                   # InstructGauge 否决点
        receipts = cert.receipts
        if len(receipts) < n_min(s):
            return stub_and_red(s, "insufficient")
        q = M.sccalr.threshold(iota, [m for m, _ in usable], M.cal)  # 检索分层
        mu, Sig = M.apcal.calibrate(receipts, H, s, q)
        if not M.apcal.cross_validate(mu, Sig, M.cross_receipt(s)):
            return stub_and_red(s, "cross_failed")
        if not contract_regression(M.apcal.update_contract(M.dpe, mu, Sig, s)):
            return stub_and_red(s, "regression")
        M.mreg.hot_replace_at_quiescence(M.dpe, M.dpe.contract, cert.boundary)
        M.mwg.commit(record_from(cert, iota, [m for m, _ in usable]),
                     used_ids={m.id for m, _ in usable})
        bind_claims(cert, iota, receipts)
        return True

# 主闭环：50Hz 路径逐字节不变
def MemGauge_round(M, obs, audio, tac, depth, det, ell=None):
    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight:
            M.inflight.add(s)
            submit_async(MemGauge9C.step, M, s, ell)
    return InstructGauge_round(M, obs, audio, tac, depth, det, ell)

## 4. 推导

**引理 59（记忆不扩张 / 非授权性）** 在能力闭包 CC（定义 432）与定义 452 下，对任意记忆集 `U`：`Plan_mem(U) ⊆ Plan_ToolGauge`。故记忆不可能新增工具、超出物理包线或绕过安全盾，自由文本亦无直达执行器通道。
*证明骨架*：`Plan_mem` 由 `Plan_ToolGauge` 经三个算子得到：按 `π_mem` 重排（不改集合）、加 `Φ_neg` 合取（只过滤）、取计划非空子集（只删）。重排与过滤均不增大集合，故包含关系成立；`π_mem` 的槽位取值仍受 `O_onto` 与 `T₀` 类型约束，越权槽位在 Γ 处已落 ⊥。

**引理 60（重接地可靠性界）** 设基础（无记忆）接地错误率 `p_g^0`，已验证记忆的残余错误率 `p_mem^res`，重识别假阳率 `ε_reid`，scope 漂移全变差 `TV_scope`。则使用记忆后的接地错误率
`P(err) ≤ p_g^0 + (1−p_g^0)·(p_mem^res + ε_reid + TV_scope)`。
即记忆只有在「重识别正确 ∧ scope 未漂移 ∧ 记忆本身正确」三者同时成立时才是净收益；任一环节失效，误差被加回基线而非被放大。
*证明*：并集界。记忆导致错误的路径只有三条：(a) 记忆内容本身错误但通过证书；(b) 当前锚点已变而 `reid` 仍误报；(c) `scope` 条件已漂移而未被 `scope_match` 捕获。三者概率分别被 `p_mem^res`、`ε_reid`、`TV_scope` 控制。硬门失败时退回 `p_g^0`，故总界如上。**该界是保守的**：它要求 `ε_reid` 与 `TV_scope` 可测，否则只能给出经验置信区间。

**引理 61（负记忆的安全单调性）** 设风险函数 `Risk(·)` 对计划集合单调（`A ⊆ B ⇒ Risk(A) ≤ Risk(B)`）。则对任意 `Φ_neg`，`Risk(Plan ∩ Φ_neg) ≤ Risk(Plan)`；若 `Plan ∩ Φ_neg = ∅`，系统放弃并回退默认目标，风险不高于原计划。代价是可用性：错误负记忆可把成功计划剪掉。
*证明*：由 `Plan_mem ⊆ Plan` 与单调性直接得到。注意这是**安全**单调而非**成功率**单调；E465 必须同时报告成功率损失，防止「越剪越安全」被滥用。

**引理 62（回声衰减界）** 设血缘图分支度至多 `b`，衰减 `0 < γ < 1/b`，深度上限 `D_mem`。则单条根记忆对当前决策的权重影响
`W_root ≤ Σ_{d=0}^{D_mem} (bγ)^d ≤ 1/(1−bγ)`，与轮次数无关；若 `bγ ≥ 1`，则必须靠深度上限 `D_mem` 截断，且总影响 `≤ (bγ)^{D_mem+1}/(bγ−1)`（有限但可大）。故「`γ < 1/b` + 深度上限」是回声不发散的结构条件。
*证明*：按路径长度分组，深度 `d` 的后代至多 `b^d` 条、每条权重 `≤ γ^d`，求和得几何级数。根影响被几何级数控制，故不随自确认轮次增长。仅靠 `γ<1` 但 `bγ≥1` 时级数发散，必须由 `D_mem` 兜底。

**引理 63（IPW 去偏与正性）** 若日志倾向 `e(m) ≥ e_min > 0` 且倾向模型正确，则 `E[p̂_IPW] = P(y=1 | do(plan))`（无偏）。若倾向估计有误差 `δ_e`，偏差 `|bias| = O(δ_e / e_min²)`；当 `e_min → 0` 时不可辨识，故 `e(m) < e_min` 的记忆只能标 `biased`。
*证明*：标准重要性采样恒等式；误差项由一阶展开 `1/ê − 1/e ≈ δ_e/e²` 给出。该引理只保证**历史成功率**估计，不保证反事实策略收益；后者需额外假设（无未观测混杂）。

**引理 64（检索分层共形的覆盖）** 若每个 stratum 内样本可交换，则层内覆盖 `P(h*∈H_s | s) ≥ 1−α`；边缘覆盖 `P(h*∈H_s) ≥ 1−α − Σ_s π_s·TV_s`，`TV_s` 为检索/场景漂移。若检索策略自适应（历史影响未来样本），可交换性失效，ACI 保证长期平均覆盖趋于 `1−α`（步长 `η` 满足标准 `Ση=∞, Ση²<∞`）。低样本层回退全局使覆盖按 `−2η_global` 优雅降级。
*证明*：层内共形分位的标准覆盖论证；ACI 的长期覆盖由 Gibbs 不等式/随机逼近给出；边缘界由全变差三角不等式。**不假设**层间可交换，这正是必须分层的原因。

**引理 65（陈旧度-误差界）** 设场景单步漂移上界 `d`、记忆年龄 `a`，则记忆诱导的接地误差
`P(err | m) ≤ p_g^0 + c·min(1, d·a)`，`c` 为锚点对漂移的敏感系数。当 `fresh(m,t) < τ_fresh` 时强制重验，可把 `a` 截断在当前场景的有效时域内。
*证明*：漂移在有界步长下线性累积到锚点条件的变化，误差随「漂移 × 年龄」增长并在概率上界 1 处饱和；重验把年龄重置为 0。该界是一阶近似，`c` 需由 E464 标定。

**引理 66（检索摊销与 50Hz 保全）** 检索与重接地全部在异步路径执行，主路径新增同步开销仅为「读缓存/默认」的 `O(1)`；故主循环新增周期 `< 0.2ms`，继承 InstructGauge 引理 58 与 ToolGauge 引理 50 的硬实时结论。检索单次开销 `c_ret = O(K_RET·(d_ℓ+d_fp) + K_RET·c_reid)`，受 `W_async` 约束。
*证明*：MemGauge-9C 的 R/G 在 `submit_async` 中完成，主路径 `MemGauge_round` 只做检测与提交；同步读为常数。`c_ret` 由向量检索复杂度与重识别次数相加。

**引理 67（严格退化等价）** 若 `R_ret = ∅`、或全部候选被 RGG 拒绝、或 `W_async` 超时、或 `M = ∅`，则 MemGauge-9C 的每一步与 InstructGauge-7C **逐指令等价**；若 InstructGauge 失效，则退回 ToolGauge；再退回 LeanGauge；最后退回 MODGAUGE 原样。新增的 `claims` 与记忆解释仍是纯投影，不改变数值行为。
*证明*：退化条件使 `usable = ∅`，此时 `M.mgp.ground` 返回默认 `ι₀` 与 `None`，后续 H/C/E/C/V/U 与 InstructGauge 完全一致；写入闸门不触发或只写隔离区。逐指令等价由构造保证，唯一非确定项是异步时序，故只对「未涉及子图」声明 bit-exact，与 ToolGauge 引理 49 同口径。

## 8. 本轮最大风险

**一句话**：MemGauge 的真正薄弱点不是检索召回率，而是**记忆权威化**——一旦重接地门或写入闸门出现漏网，一条陈旧/被污染的记忆会同时污染指令接地、计划排序与检索分层校准，并通过血缘在后续轮次自我确认；缓解只能依赖结构（引理 59 的非扩张、引理 60 的重接地硬门、引理 61 的负记忆单调、引理 62 的血缘衰减、定义 457 的写入闸门），并以 E457/E459/E460/E461/E463/E464/E471 主动证伪。
