# 第 47 轮（承接第 46 轮 v23；本轮灵感：模型蒸馏 × 步骤分） · Distill-Step-Cert：可蒸馏的步骤级风险证书与过程信用闭环（四层架构 v11）

> 承接第 46 轮 v23 Memory-Safety-Voice。v10/v23 已把姿态、能量、记忆、语音安全纳入联合决策，但隐含假设 H5：**签发证书的教师模型（VLM 上下文预测器、深度质量评估器、PSE 几何认证器）始终能以控制频率在机器人本体/边缘侧运行，且其能力与离线教师一致**。实机上云端 VLM 与高精度几何认证器延迟 100–800ms、功耗高，无法进入 30–50Hz 控制环；必须把教师蒸馏为轻量学生。然而标准蒸馏只压缩典型分布，恰好在透明/镜面/弱纹理/快速运动这些长尾退化层丢失尾部覆盖；多步任务中学生的步骤级误差会沿轨迹累积，终局成功不等于每步安全。两个灵感词精确命中 H5：**模型蒸馏**把“证书签发者”本身变成需要审计的对象；**步骤分**把终局 0/1 安全判定细化为每步风险分，使有限安全预算可分配、可累积检验、可定位数据采集。耦合出的新问题是：**学生蒸馏误差与步骤风险如何共同作用，才能让序列证书在长尾与分布漂移下仍然 sound，并在证据不足时以最小教师查询代价 fail-closed**。

## 0. 直觉与动机

**灵感 1（模型蒸馏 → 蒸馏的是证书几何，不是标签）**
直觉：教师的价值不只是“给出正确类别/位姿”，而是“给出一个带覆盖保证的集合”。若只蒸馏点预测，学生学到的是一张平均准确率曲线；但安全关心尾部：学生必须在教师签发窄证书的地方也窄，在教师放大的地方也放大。于是把蒸馏目标定义为**证书几何蒸馏**：学生同时回归教师每步风险分 s_k^T 与半径 r_k^T，并在共形校准集上度量师生残差 d_k；部署时用 d_k 的分位数对学生证书做分布无关膨胀。学生不是“更小的教师”，而是“带师生差异证书的近似教师”。

**灵感 2（步骤分 → 序列风险的过程信用与 anytime 预算）**
直觉：多步任务不应只在终局判安全。每步有一个步骤分 s_k（风险）或信用 c_k=1-s_k；它让安全预算从“整段任务一次性消耗”变成“逐步消耗”。用 e-value/测试鞅可在不预分配 α 的情况下得到 anytime-valid 的序列保证：任何时刻证据累积到阈值就拒绝“安全”假设并 fail-closed。步骤分还给出过程信用：高信用但实际失败的“静默失败步”是最有价值的数据，驱动 DCL 主动采集。

**灵感 3（二者耦合 → 蒸馏间隙定位到步骤，步骤分反哺蒸馏）**
直觉：全局蒸馏误差界过松，会把整个任务拖入保守模式；步骤分把误差定位到具体步骤，只在 d_k 大的步骤查询教师（guard fallback），其余步骤用膨胀后的学生证书。反过来，DCL 用“高步骤信用 + 实际失败 + 高师生间隙”的样本做主动蒸馏，使学生的尾部逐步逼近教师，形成“蒸馏—审计—采集”闭环。

**耦合升级**：在 v10/v23 四层架构上新增 **蒸馏证书层**。根信任层增加蒸馏租约 ℓ_d（学生版本 + 校准集版本 + 师生间隙上界）；L1 几何层输出步骤级半径 r̃_k；L2 上下文层的学生预测器与教师审计双轨；L3 CAR 守卫加入序列 e-value 预算；L4 DCL 用过程信用与间隙做主动采样。四层 v11。

## 1. 形式化定义（增量：定义 59–63）

**定义 59（师生步骤证书与蒸馏间隙）**
教师 T 在学生可查询的校准分布上对步骤 k 签发 (s_k^T, r_k^T, P_k^T)，满足 P(X_k∈P_k^T | F_{k-1}) ≥ 1-α_k。学生 S 输出 (s_k^S, r_k^S)。步骤蒸馏间隙
d_k = |s_k^T - s_k^S| + λ_r·|r_k^T - r_k^S|。
在独立校准集上取 d 的 (1-β) 共形分位数 q_{1-β}，部署时
s̃_k = min(1, s_k^S + q_{1-β}),  r̃_k = r_k^S + L_r·q_{1-β},  P̃_k = Ball(ĉ_k, r̃_k)。
称 P̃_k 为**膨胀学生步骤证书**；当 q_{1-β} 有界且师生残差在层内可交换时，其覆盖不劣于教师证书减去 O(q_{1-β})。

**定义 60（步骤分与过程信用）**
步骤分 s_k∈[0,1] 为风险，信用 c_k=1-s_k。折扣过程信用
C(τ)=Σ_{k=0}^{K} γ^k c_k, γ∈(0,1]。
**静默失败步**：实际 X_k 违反但 c_k 高（学生自信安全）。其数据价值
V_k = c_k·1[X_k=1]·S_φ(ω_k)·(1+d_k)，
其中 S_φ 为下游敏感度。V_k 只用于采样排序，**绝不用于放行**。

**定义 61（序列步骤风险预算与 anytime 证书）**
设 s̃_k 为步骤 k 的保守风险上界，X_k∈{0,1} 为违反指示，且 P(X_k=1 | F_{k-1}) ≤ s̃_k。定义测试鞅
M_K = Π_{k=1}^{K} (1-X_k)/(1-s̃_k)（s̃_k=1 时直接判违反，不进入乘积）。
则 M_K 为非负上鞅，且 P(sup_K M_K ≥ 1/α_step) ≤ α_step。
**序列安全判据**：若 M_K ≥ 1/α_step，或 Σ_k s̃_k > B_step，或能量/姿态/语音/蒸馏租约失效，则 fail-closed。

**定义 62（蒸馏守卫与教师回退）**
守卫策略 g(x_k)∈{student, teacher}：
g=teacher 当 d̂_k > δ_max 或共形 p 值 < β 或 ω_k∈Ω_hard（透明/镜面/深度空洞）。
回退预算 Q_T（每任务教师查询上限）与能量代价 c_T。学生-教师版本对写入蒸馏租约
ℓ_d=(ver_S, ver_T, q_{1-β}, δ_max, Q_T)；
ℓ_d 过期或版本不匹配时所有学生证书失效。若 Q_T 耗尽而 d̂_k 仍超限，则不得降级为学生，必须 fail-closed。

**定义 63（蒸馏感知的步骤证书合成）**
轨迹 τ 的联合证书
J_τ = (P̃_{1:K}, ℓ_p, ℓ_e, ℓ_d, M_K)
在以下条件下 sound：
(i) 每步 P̃_k 覆盖 X_k；(ii) M_K < 1/α_step；(iii) ℓ_p、ℓ_e、ℓ_d 均有效。
合成顺序：先步骤覆盖，再序列预算，最后根租约；任一失败即 fail-closed，**不允许用其他步骤的好成绩抵扣**。

## 2. 三大新增产出与既有 IP 升级

**IP-69 DSC（Distilled Step Certifier）**
- 证书几何蒸馏：学生回归 (s_k, r_k)，教师提供校准标签与残差
- 共形膨胀：q_{1-β} 按退化层/步骤类型分组校准（Mondrian conformal）
- 版本化蒸馏租约 ℓ_d 与失效级联

**IP-70 SSR（Step-Score Reward / Process Credit Engine）**
- 步骤分校准：ECE/Brier + 分层可靠性图
- 过程信用 C(τ) 与静默失败价值 V_k
- 只用于 DCL 排序与预算诊断，不进入放行路径

**IP-71 DGR（Distillation Guard / Drift Referee）**
- 在线师生间隙估计：辅助分歧头 + 周期教师抽检
- 回退触发、Q_T 预算、教师预热
- 分布漂移检测：输入嵌入漂移 + 残差分位漂移

**既有 IP 升级**
IP-65 CONTEXT PREDICTOR：学生化 + 教师审计双轨，预测输出附 d_k
IP-60 PSE：签发步骤级 r̃_k，替代单步全局半径
IP-61 DCL：采样优先级改为 V_k，教师只标注高价值样本（主动蒸馏）
IP-62 CCA：新增蒸馏红队、步骤分博弈、序列 e-value 注入测试
IP-51 CAR：守卫加入 M_K 与 B_step，任一超限 fail-closed
IP-45 总线：新增 step-score / distill-gap / teacher-fallback / distill-lease 话题

## 3. 算法骨架

每控制步 k：
1. 读 x_k, ℓ_d, ℓ_p, ℓ_e；学生输出 s_k^S, r_k^S
2. DGR 估计 d̂_k 与共形 p 值；若触发回退则查教师并替换 (s_k, r_k)
3. DSC 膨胀得 s̃_k, r̃_k, P̃_k
4. SSR 计算 c_k 与 V_k，写入 DCL 缓冲
5. CAR 更新 M_K；若 M_K≥1/α_step 或 Σs̃>B_step 或租约失效 → fail-closed
6. 通过则执行步骤并记录 (s̃_k, X_k, d_k) 供下一轮校准

关键：**步骤分负责“往哪里看”，膨胀证书负责“能不能做”**；两者职责严格分离，避免步骤分成为可博弈的放行依据。

## 4. 本轮最大风险

**一句话**：师生间隙 d_k 的共形分位数在分布漂移/非可交换长尾上会低估真实尾部误差，导致学生以高步骤信用签发过窄证书，序列 e-value 又因“安全步太多”而迟迟不触发，最终在透明/镜面等硬层静默失效；因此必须用加权共形与教师抽检守住非可交换性，并在任何间隙或版本证据不足时直接回退教师或 fail-closed，而不是相信步骤分。

## 2. 关键算法伪代码

### IP-69 DSC + IP-71 DGR 联合签发

```python
def certify_step(x_k, layer, student, dgr, teacher, calib, lease):
    s_s, r_s, c_hat = student(x_k)
    d_hat = dgr.gap(x_k, s_s, r_s)              # 辅助分歧头 + 周期教师抽检
    q = calib.quantile(1 - beta, group=layer)   # Mondrian 共形，按退化层分组

    action = dgr.guard(x_k, d_hat, q, layer, lease)
    if action == 'fail-closed':
        return None

    if action == 'teacher':
        s_T, r_T, P_T = teacher(x_k)
        s_safe = max(s_T, min(1.0, s_s + d_hat + q))
        r_safe = max(r_T, r_s + L_r * (d_hat + q))
        lease.queries += 1
        return StepCert(s=s_safe, r=r_safe, P=P_T,
                        src='teacher', gap=d_hat, layer=layer)

    s_safe = min(1.0, s_s + d_hat + q)
    r_safe = r_s + L_r * (d_hat + q)
    return StepCert(s=s_safe, r=r_safe, P=Ball(c_hat, r_safe),
                    src='student', gap=d_hat, layer=layer)
```

def guard(x_k, d_hat, q, layer, lease):

### IP-70 SSR 过程信用与主动蒸馏

```python
def process_credit(steps, gamma=0.9):
    return sum(gamma**k * (1 - st.s) for k, st in enumerate(steps))

def silent_failure_value(st, outcome, sensitivity):
    # 高信用 + 实际失败 + 大师生间隙 = 最值得蒸馏的静默失败步
    return (1 - st.s) * int(not outcome.success) * sensitivity * (1 + st.gap)

def dcl_priority(st, outcome, sensitivity, eta=0.5):
    return silent_failure_value(st, outcome, sensitivity) \
           + eta * st.gap * sensitivity

def push_to_dcl(steps, outcomes, sensitivities, buffer):
    for st, out, sens in zip(steps, outcomes, sensitivities):
        buffer.push(st, priority=dcl_priority(st, out, sens))
    buffer.sort_by_priority()
```

### IP-51 CAR 序列守卫

```python
def sequential_guard(step_certs, violations, alpha_step, B_step, leases):
    M, s_sum = 1.0, 0.0
    for st, x in zip(step_certs, violations):
        if st is None:
            return 'fail-closed'
        if st.s >= 1.0:
            return 'fail-closed'                # 预测必然违反，直接停
        s_sum += st.s
        M *= (1 - x) / (1 - st.s)
        if M >= 1.0 / alpha_step:
            return 'fail-closed'                # 序列证据拒绝“安全”
        if s_sum > B_step:
            return 'fail-closed'                # 累计风险预算耗尽
        if not all(l.valid() for l in leases):
            return 'fail-closed'                # 姿态/能量/蒸馏租约失效
    return 'execute'
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| DSC 学生前向 | O(d_model) 每步 | O(d_model) | 膨胀半径覆盖师生间隙分位数 |
| 共形查询 | O(1) 分组查表 / O(log n) 有序分位 | O(n) 校准集 | 层内边际覆盖 ≥ 1-α_k-O(β) |
| SSR 过程信用 | O(K) | O(K) | 只影响采样排序，不影响放行 |
| DGR 间隙估计 | O(d) 分歧头；教师回退 O(T_teacher) | O(1) | 间隙超限即回退或停机 |
| CAR 序列守卫 | O(K) | O(1) | 上鞅 + Ville 不等式控制误报 |

**正确性定理（序列蒸馏证书）**
假设：
(A1) 教师步骤证书满足 P(X_k∈P_k^T | F_{k-1}) ≥ 1-α_k；
(A2) 层内师生残差可交换，且 d_k ≤ δ_max 以概率 ≥ 1-β 成立；
(A3) 膨胀风险 s̃_k 是真实条件违反概率的上界，即 P(X_k=1|F_{k-1}) ≤ s̃_k。
则对任意停止时刻 K，
P(∃k≤K: M_k ≥ 1/α_step) ≤ α_step，
且每步膨胀证书满足 P(X_k∈P̃_k) ≥ 1-α_k-O(β)。
若 (A2) 因分布漂移失效，则 DGR 必须回退教师或 fail-closed，否则定理不成立。

**证明草图**：在 (A3) 下，e_k=(1-X_k)/(1-s̃_k) 满足 E[e_k|F_{k-1}] ≤ 1，故 M_K 为非负上鞅；对 M_K 应用 Ville 不等式得 P(sup_k M_k ≥ 1/α_step) ≤ α_step。步骤覆盖由教师 soundness 加共形膨胀的边际覆盖得到；对 K 步做 union bound 时把 α_k 预先注册，或改用 e-value 避免事后分配。

**预算分配的严谨性提醒**：不能用同一批数据先看步骤分再决定 α_k，否则会破坏频率派有效性；步骤分只能用于**预注册权重**或 e-value 的排序诊断。安全放行永远使用保守上界 s̃_k，而不是过程信用 c_k。

## 4. 实验设计 E115–E120

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 非可交换导致共形分位数失效 | 高 | 加权共形（按时间/场景密度比）+ 周期教师抽检 + 硬层强制回退 |
| 步骤分被优化/博弈，变成奖励漏洞 | 高 | 步骤分只用于采样与诊断；放行只用保守上界；CCA 注入“刷分”对抗样本 |
| 教师回退延迟与能耗尖峰 | 中 | Q_T 预算、教师预热、同层结果缓存、软降级为保守几何盒 |
| 学生版本与校准集漂移 | 中 | 版本化 ℓ_d；版本或校准集哈希不匹配即整链失效 |
| e-value 过于保守导致频繁停机 | 中 | 分层 α_step；先软降级到教师模式，再考虑停机 |
| 静默失败样本天然稀缺 | 中 | 主动蒸馏 + 硬层合成 + 重要性加权；用 V_k 排序而非均匀采样 |

## 6. 本轮最大风险

**一句话**：蒸馏间隙的共形分位数在分布漂移与非可交换长尾上会低估真实尾部误差，使学生在硬层以高步骤信用签发过窄证书，而序列 e-value 因大量“安全步”稀释证据而延迟触发，最终造成静默安全违例；因此必须把加权共形、教师抽检与版本化租约作为硬前置条件，任何间隙证据不足时直接回退教师或 fail-closed，绝不拿步骤分当放行依据。
