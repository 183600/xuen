# 第 68 轮（承接第 67 轮「SOMA 安全在线全身控制」IP-234~243；灵感循环第 1 轮；本轮灵感：「手眼标定」×「指令泛化」）

> 第 67 轮 SOMA 把在线学习关进安全证书的零空间里，但它在「本轮最大风险」里已承认：全部保证都建立在安全函数 `h` 与可微敏感度 `A_h` **正确**之上，而它无法处理「在错误的安全模型里安全地学习」。本轮指出，这个「错误的安全模型」有两个前几轮从未建模的来源，恰好对应本轮的两个灵感词：
>
> - **手眼标定**对应**几何框架**：相机→末端→基座→世界的外参 `T`。SOMA 的残差字典只覆盖动力学（质量/摩擦/延迟/柔顺），**不覆盖坐标框架**。
> - **指令泛化**对应**语义框架**：自然语言指令→实体/关系/任务/优先级 `ℓ ↦ τ`。SOMA 的后验只覆盖「哪一层坏了」，**不覆盖「任务本身是否被正确理解」**。
>
> 二者都是**潜变换（latent transform）**：它们以共同模式同时作用于观测与安全约束，因此在各自框架内部**零残差、不可见**。一个错的外参让「相机看到的」与「安全约束算的」一起错；一个错的 grounding 让机器人**完美地执行错误的任务**。自我一致不等于正确。
>
> 本轮命题：
>
> **把「安全地学习模型参数」升级为「安全地标定框架与语义 grounding」：用闭环一致性（而非帧内残差）观测几何框架，用组合闭包（而非单指令置信）认证语义框架，并证明几何不确定性与语义新颖度共享同一条安全预算。**
>
> 命名为 **BIFOCAL（Bi-frame Identifiability with Frame-Observable Calibration And Language grounding）**：同时看近处的几何焦点与远处的语义焦点。「bi-frame」即**几何框架 + 语义框架**。

## 0. 直觉与动机

**灵感 1（手眼标定 → 框架误差是一种规范歧义，而不是普通参数）**
直觉：手眼标定的经典方程是 `A X = X B`——机器人相对运动 `A` 与相机相对运动 `B` 通过一个固定外参 `X` 相连。注意这个方程的**可辨识性来自「跨两个独立测量通道的闭合」**，而不是来自任何单帧图像。一个错误的外参 `T_c` 在相机自身的坐标系里是看不出来的：数据与模型会被同一个 `T_c⁻¹` 左乘，帧内残差不变。可是在世界坐标系里，`T_c` 的旋转误差会等量地吃掉安全裕度——**你看不见它，但它正在使你的安全球倾斜**。因此外参不是「又一个待估参数」，而是**规范（gauge）**：必须用闭环和运动多样性去定点，且必须把它的不确定度显式地计入安全阈值。

**灵感 2（指令泛化 → 语义框架同样需要闭环，而不是更高置信度）**
直觉：指令 grounding 是一个映射 `g_φ: ℓ ↦ (E, R, τ, π)`（实体、空间关系、任务骨架、优先级）。如果 grounding 错了，机器人会以零跟踪误差执行一个错误的任务：**任务层残差同样不可见**。因此「指令泛化」不能只靠分类器置信度，它需要两种闭环：其一是**组合闭包**——新指令必须能分解为已认证技能库里的原语组合，超出任务凸包就必须分解或拒绝；其二是**独立佐证**——可以用主动提问（问人）来消解语义不确定，而不是用机器人运动去「试出」人到底想说什么。

**灵感 3（两种框架共享同一条安全预算）**
直觉：几何不确定性 `ρ_T` 会以 `L_T·ρ_T` 吃掉安全裕度；语义组合深度 `d` 会以 `L_g·ε_p·d` 累积 grounding 误差。二者加起来必须不超过总裕度。于是出现一个很干净的权衡：**手眼标定越准（`ρ_T` 越小），允许的指令泛化越深（`d` 越大）**。这解释了一个工程直觉：几何没标定好时，机器人只该做「已认证的浅层技能」；标定收敛后才能放开组合泛化。

**灵感 4（串谋：语义解释掉几何，几何解释掉语义）**
直觉：最危险的不是两个框架各自出错，而是它们**互相掩护**。当一条新指令执行失败时，估计器有两种解释：`ℓ` 被错误 grounding，或 `T` 漂了。若允许帧估计读取任务完成误差，它就会悄悄旋转 `T` 去迁就错误指令——**语义错误被解释成几何漂移**，而几何证书依然「有效」。反向同理：一个漂移的框架会让 grounding 系统把物体重新「归位」到一个错误位置。唯一的解药是**证据通道独立**：帧只能由几何闭环证据更新，语义只能由指令侧证据更新，任务完成误差绝不能进入外参估计。

**灵感 5（问 vs 动：两种主动行为不能混淆）**
直觉：面对不确定性，机器人可以「问人」（消解语义框架）或「动一下」（消解几何框架）。二者信息增益与风险完全不同，却常被同一条探索策略混在一起。BIFOCAL 把它们显式分开：`query(ℓ)` 改变的是语义后验，`excite(u)` 改变的是手眼观测矩阵；按「单位风险的信息增益」择优，且激励动作必须落在 SOMA 的认证集 `Z_cert` 内。

**灵感 6（合流 → BIFOCAL 的分层结构）**
BIFOCAL 在 SOMA 的时序骨架上外挂一层「框架/grounding 层」：
1. **CLO Certified Loop-closure Observer**：用 `A X = X B` 与接触/运动学闭环产生**跨帧残差**，作为几何证据通道；
2. **HEO Hand-Eye Observability engine**：计算 `∂r/∂ξ` 的观测矩阵秩/条件数，只在秩亏时调度认证激励（move-to-see）；
3. **IGG Instruction Grounding Gate**：把新指令映射到任务骨架，输出 grounding 裕度 `m_g` 与任务凸包距离；
4. **TCC Task Certification Compiler**：把 grounding 结果编译成任务层级与安全约束，验证其活跃约束落在 SOMA 认证包络内，否则退化为**任务前缀**；
5. **NSP-G Gauge-separated Null-space Projector**：在 SOMA 的零空间投影上再加一层**规范分离**，把「可被帧变换吸收」的更新方向投影掉；
6. **GGR Gauge Guard**：拒绝由任务误差驱动的帧更新，检测语义-几何串谋；
7. **AMA Ask-vs-Move Arbitrator**：在「问人」与「认证激励」之间按信息增益/风险择优；
8. **J-BIFOCAL**：把帧协方差、观测秩、grounding 裕度、任务前缀、串谋分数写入证书。

## 1. 形式化定义（增量：定义 260–275）

- **定义 260（BIFOCAL 总览）**：`BIFOCAL = (CLO, HEO, IGG, TCC, NSP-G, GGR, AMA, J-BIFOCAL)`，包在 SOMA 外层。不变式：(i) 实时流只使用已认证的 `(T_c, τ_cert, z_safe)`；(ii) 帧与 grounding 的写操作只在语义流；(iii) 帧更新只能由几何闭环证据驱动，任务完成误差不得进入帧估计；(iv) 超出任务凸包的新指令只能被分解为认证前缀或拒绝；(v) 任一证书失效立即回滚到上一个 `Valid` 三元组。
- **定义 261（几何框架潜变量与手眼方程）**：真实外参 `T* = T_c·exp(ξ^∧)`，`ξ∈ℝ⁶`。对相对运动对 `{(A_i,B_i)}` 有手眼方程 `A_i T = T B_i`。定义跨帧残差 `r_i(T) = log((A_i T)(T B_i)^{-1})^∨ ∈ ℝ⁶`，堆叠 `R_T(T)=[r_1;…;r_N]`。帧估计 `T_c = argmin_T Σ_i ‖r_i(T)‖²_{Σ_i^{-1}}`。
- **定义 262（手眼可辨识度与观测秩）**：令 `O_T = ∂R_T/∂ξ|_ξ=0 ∈ ℝ^{6N×6}`，定义可辨识度 `ρ_obs = σ_min(O_T)/σ_max(O_T)` 与秩 `rank(O_T)`。经典结论：当所有相对旋转轴近似平行（或只有纯平移）时 `rank(O_T)<6`，沿该轴的平移不可观测，`ρ_obs→0`。
- **定义 263（认证激励，move-to-see）**：当 `ρ_obs < ρ_min` 时调度
  `u_ex = argmax_{u∈U_safe∩Z_cert} log det(O_TᵀΣ⁻¹O_T + I(δξ;y|u)) − β·risk(u)`。
  它是 SOMA 的 DES 的「静态潜变量」版本：DES 增强 Fisher，HEO 增强手眼观测矩阵。
- **定义 264（闭环一致性残差）**：`ρ_T = Σ_i ‖r_i(T_c)‖²_{Σ_i^{-1}} + ρ_contact + ρ_kin`，其中 `ρ_contact` 来自触觉/已知支撑面，`ρ_kin` 来自冗余运动学闭环。`ρ_T` 是几何证据通道，**在帧内动力学残差中不可见**。
- **定义 265（规范歧义与锚定）**：对联合残差 `r(z,ξ)=[r_dyn(z); R_T(ξ)]`，令 `J=[J_z, J_ξ]`。规范子空间 `G=ker(J)`。当存在 `δz,ξ` 使 `r(z+δz,ξ)=r(z,0)` 时，动力学误差与帧误差等价，称**规范歧义**。锚约束 `A_anchor ξ=0`（已知支撑面、IMU 重力方向、固定标识物、左右对称）可消歧，当且仅当 `rank([J; A_anchor]) = dim z + 6`。
- **定义 266（语义框架与 grounding）**：grounding 映射 `g_φ: ℓ ↦ (E,R,τ,π)`，`τ` 为任务骨架，`π` 为优先级。校准置信度 `p_g(ℓ)`。任务凸包 `H_task` 为已认证原语在组合深度 `≤d` 下的闭包。
- **定义 267（grounding 裕度）**：`m_g(ℓ) = p_g(ℓ) − dist(τ(ℓ), ∂H_task)`，其中 `dist` 为任务骨架上的 Lipschitz 距离。`m_g ≥ ε_g` 才允许直接认证。
- **定义 268（任务认证编译，TCC）**：编译器 `C: τ ↦ (≻_τ, h_τ)` 生成任务层级与安全函数。若 `h_τ` 的活跃约束集落在 SOMA 认证包络内则返回 `(τ, True)`；否则返回最长任务前缀 `τ_{1:k}`（组合意义上的前缀）与 `False`。
- **定义 269（框架条件安全裕度）**：设 `h` 对帧的 Lipschitz 常数为 `L_T`（单位：裕度/弧度）。真实裕度 `h_world = h_{T_c} + O(ξ)`，故 `|h_world−h_{T_c}| ≤ L_T‖ξ‖`。认证目标收紧为
  `ε_h' = ε_h + L_T·ρ_T`，其中 `ρ_T` 为 `Σ_T` 的保守半径；要求 `ε_h' < ε_h_max`。
- **定义 270（规范守卫与语义-几何串谋）**：帧更新 `δT` 可采纳当且仅当：(i) 由 `ρ_T` 的下降支撑；(ii) 与当前指令 `ℓ` 的完成误差条件独立，即 `I(δT; ℓ | E_geom) ≤ ε_c`；(iii) 在「无指令/旧指令」数据上同样降低 `ρ_T`（留出检验）。串谋分数 `C_collusion = cos⟨δT, δT_ℓ⟩·1[E_geom 不支持]`，其中 `δT_ℓ` 是「仅为降低任务误差」所需的帧方向。
- **定义 271（问 vs 动仲裁，AMA）**：动作集 `a ∈ {query(ℓ), excite(u)}`。
  `a* = argmax_a IG(a)/risk(a)`，`query` 只更新语义后验，`excite` 只更新几何后验；两者不得共用同一条证据去同时修改两个框架。
- **定义 272（BIFOCAL 更新律）**：交替、规范分离：
  1. 帧：`ξ_{t+1} = ξ_t − η_ξ Π_{ker(A_anchor)} ∇ρ_T`（只用几何证据）；
  2. 动力学：`z_{t+1} = Π_{Z_cert}(z_t − η_z (I − A_h⁺A_h) Π_{ker(J_ξ)} ∇L(z_t))`（投影掉可被帧吸收的方向）；
  3. grounding：只在 `Valid(J-BIFOCAL)` 下固化任务骨架。
- **定义 273（J-BIFOCAL 证书）**：
  `J-BIFOCAL = (J_SOMA, T_c, Σ_T, ρ_obs, m_g, τ_cert, C_collusion, A_anchor, d)`。
  `Valid ⇔ Valid(J_SOMA) ∧ ρ_obs ≥ ρ_min ∧ m_g ≥ ε_g ∧ C_collusion ≤ ε_c ∧ ε_h' < ε_h_max`。
- **定义 274（组合深度误差界）**：若每个原语 grounding 误差为 `ε_p`、组合 Lipschitz 常数为 `L_g`，深度 `d` 的任务误差满足 `ε_g(d) ≤ ε_p·(L_g^d − 1)/(L_g − 1)`（`L_g=1` 时退化为 `d·ε_p`）。认证深度 `d_max = max{d : ε_g(d) ≤ B_g}`，`B_g` 为语义可用裕度。
- **定义 275（闭合不变式）**：任一执行周期满足：(i) 实时只用认证三元组；(ii) 帧/grounding 写操作只在语义流；(iii) 帧更新必须有独立几何锚，任务误差不得反哺帧；(iv) 超包络指令必须分解或拒绝；(v) 失效即回滚，且回滚不得用当前指令数据「重标定」框架。

## 2. 关键算法骨架

```python
class CertifiedLoopObserver:                 # CLO：几何证据通道
    def residual(self, robot_motions, sensor_motions, T):
        # AX=XB 闭环：跨两个独立测量通道，天然不是帧内残差
        out = []
        for A, B in zip(robot_motions, sensor_motions):
            E = A @ T @ inv(B) @ inv(T)
            out.append(se3_log(E))           # ∈ R^6
        return np.concatenate(out)


class HandEyeObservability:                  # HEO：可辨识度 + 认证激励
    def observability(self, motions, T):
        O = self.stack_jacobian(motions, T)  # ∂R_T/∂ξ ∈ R^{6N×6}
        s = np.linalg.svd(O, compute_uv=False)
        return s[-1] / s[0], (s > 1e-8).sum()

    def excite(self, T, motions, safe_motions):
        rho, rank = self.observability(motions, T)
        if rho >= self.rho_min and rank == 6:
            return None
        return max(safe_motions,
                   key=lambda u: self.info_gain(T, u) - self.beta * self.risk(u))


class InstructionGroundingGate:             # IGG：语义证据通道
    def ground(self, instruction):
        spec = self.grounder(instruction)    # (E, R, tau, pi)
        p_g  = self.calibrated_confidence(spec)
        m_g  = p_g - self.distance_to_hull(spec.tau)
        return spec, m_g, p_g


class TaskCertificationCompiler:            # TCC：任务前缀
    def compile(self, spec, T_c, eps_h_tight):
        hierarchy, h_tau = self.to_tasks(spec)
        if self.within_envelope(h_tau, T_c, eps_h_tight):
            return hierarchy, True, len(spec.tau)
        return self.certified_prefix(spec), False, self.prefix_len(spec)


class GaugeGuard:                           # GGR：防语义-几何串谋
    def admissible_frame_update(self, dT, task_error, geom_evidence, heldout):
        if geom_evidence is None:
            return False
        return (self.independent(dT, geom_evidence)
                and self.heldout_reduces(dT, heldout)
                and self.collusion_score(dT, task_error) <= self.eps_c)


def BIFOCAL_round(M, obs, instruction):
    # ---------- 实时流：零学习、零标定写 ----------
    z_safe = M.ccr.safe_point(M.z_c, M.rho)
    tau_cert, task_ok, d = M.tcc.cached(M.T_c, M.eps_h_tight)
    xi = M.wbc.solve(obs.q, obs.qd, tau_cert, z_safe)

    # ---------- 语义流：先几何，后语义，最后规范分离 ----------
    geom = M.clo.residual(obs.robot_motions, obs.sensor_motions, M.T_c)
    rho_obs, rank = M.heo.observability(obs.motions, M.T_c)

    # 1) 帧更新只吃几何证据，任务误差不进入
    if M.ggr.admissible_frame_update(M.pending_dT, obs.task_error, geom, obs.heldout):
        M.T_c = M.calibrate(M.T_c, geom)
        M.Sigma_T = M.update_cov(geom, M.T_c)
    M.eps_h_tight = M.eps_h + M.L_T * M.radius(M.Sigma_T)

    # 2) 语义：grounding -> 任务凸包 -> 任务前缀
    spec, m_g, p_g = M.igg.ground(instruction)
    if m_g < M.eps_g:
        M.tcc.set_fallback(M.skill_library)          # 拒绝/分解，而非硬试

    # 3) 规范分离后的 SOMA 动力学学习
    post  = M.ras.posterior(obs)
    alpha = M.cag.weights(post)
    g = M.grad(obs, M.z_c + M.z_p, alpha)
    g = M.nsp_g.project(g, M.A_h, M.J_xi)            # 投影掉可被帧吸收的方向
    z_new = M.z_c - M.eta * g
    if M.ccr.verify(z_new, M.rho, M.k):
        M.z_c = M.ccr.consolidate(z_new)
    else:
        M.rollback_if_invalid()

    # 4) 问 vs 动：各走各的证据通道
    if m_g < M.eps_g:
        M.ama.propose_query(spec)
    if rank < 6 or rho_obs < M.rho_min:
        M.queue_excitation(M.heo.excite(M.T_c, obs.motions, obs.safe_motions))

    M.j_bifocal = M.cert.build(M.T_c, M.Sigma_T, rho_obs, m_g, tau_cert)
    return xi, M.j_bifocal
```

闭环每一轮只做四件事：**闭环观测 → 规范分离 → 语义闭包 → 认证执行**。几何与语义各自只读自己的证据，任一方的不确定度都显式进入同一条安全预算。

## 3. 推导

**引理 14（帧内残差对框架误差不可见）** 设测量 `y = T*η`（`η` 为体坐标量），残差由体坐标不变量 `r(T_c,θ)=Φ(T_c⁻¹y,θ)` 构成。当模型也在 `T_c` 下表达时，`r(T_c,θ*) = r(T*,θ*) = 0`；即框架误差 `Δ=T_c⁻¹T*` 作为一次左乘同时作用于数据与模型，落在残差的规范核里。
*证明*：把 `T_c⁻¹y = (T_c⁻¹T*)(T*⁻¹y)` 代入 `Φ`；`Δ` 是 `SE(3)` 的全局左作用，体坐标不变量对其不变，故 `Φ` 取值与 `Δ` 无关。∎
因此**任何帧内残差检验都无法拒绝一个自洽的错误框架**；能看见它的只有跨通道闭环 `A X = X B`（定义 264）——这正是引理 14 与引理 15 的分工。

**引理 15（框架不确定度吃掉安全裕度）** 若 `h` 对帧的 Lipschitz 常数为 `L_T`，则 `|h_world − h_{T_c}| ≤ L_T‖ξ‖`。要对所有 `‖ξ‖≤ρ_T` 保证 `h_world ≥ ε_h`，认证目标必须收紧为 `ε_h' = ε_h + L_Tρ_T`。
*证明*：一阶 Taylor 展开 `h_world = h_{T_c} + (∂h/∂T)ξ + O(‖ξ‖²)`，取绝对值并放缩即得。∎
这是把「标定精度」直接翻译成「安全阈值」的桥：手眼协方差不是诊断指标，而是**必须从安全预算里扣除的成本**。

**引理 16（规范分离需要独立锚）** 联合残差 `r(z,ξ)` 的规范子空间 `G=ker([J_z, J_ξ])`。当且仅当 `rank([J; A_anchor]) = dim z + 6` 时，`z` 与 `ξ` 可分别辨识。特别地，**任务完成误差不是锚**：它依赖当前指令 `ℓ`，当 `ℓ` 本身错误时会给出有偏方程，诱导 `ξ` 去吸收语义误差。
*证明*：线性化 `r(z+δz, ξ+δξ) ≈ r + J_zδz + J_ξδξ`。若存在非零 `(δz,δξ)∈ker J`，则两组参数产生同一残差，不可分。加入 `A_anchor` 后，解唯一当且仅当增广矩阵列满秩。任务误差方程含 `ℓ` 的偏置项，不满足 `A_anchorδξ=0` 的无偏条件。∎

**引理 17（grounding 误差随组合深度累积）** 在 Lipschitz 组合假设下，深度 `d` 的任务误差满足定义 274 的界；当 `L_g=1` 时 `ε_g(d) ≤ d·ε_p`。
*证明*：对组合树做归纳：每一步组合把子任务误差按 `L_g` 放大并叠加当前原语误差 `ε_p`，求和即得等比级数。∎
因此「指令泛化」不是免费的：**每深一层组合，就多花一份安全预算**。

**定理 13（BIFOCAL 端到端安全性）** 在 A5（帧管覆盖 `T*`，即 `‖ξ‖≤ρ_T`）、A6（锚 `A_anchor` 使 `z` 与 `ξ` 规范分离）、A7（TCC 在收紧阈值 `ε_h'` 下验证任务约束）、A8（GGR 拒绝语义驱动的帧更新）下，任一执行时刻：
1. 世界系安全裕度 `h_world ≥ ε_h − O(ρ_T²)`；
2. 未通过 `m_g ≥ ε_g` 或 TCC 的新指令**不会被执行**，只执行任务前缀或回退技能库；
3. 当 `ρ_obs≥ρ_min` 且 `C_collusion≤ε_c` 时，帧误差不会被误吸收进动力学参数（`z` 的可辨识分量不受帧漂移污染）；
4. 若 `T_c` 或 grounding 失效，证书拒绝，系统退化为 SOMA/VISTA/RAS 的只执行模式。
*证明*：对周期做归纳。基例由初始 `Valid(J-BIFOCAL)`。归纳步分三条：几何上，A5+A7+引理 15 保证收紧后世界裕度不破；语义上，定义 267/268 保证未认证指令不进入实时执行；分离上，A6+引理 16 保证 `z` 只在帧不变子空间更新。任一分支失败时定义 275(v) 回滚到上一 `Valid` 状态，安全性由归纳假设保持。∎

**定理 14（几何–泛化 Pareto 前沿）** 在同一条安全预算 `B` 下，几何不确定度与语义组合深度满足
`L_Tρ_T + L_g·ε_p·d ≤ B`，故
`d_max(ρ_T) = ⌊(B − L_Tρ_T)/(L_gε_p)⌋`，且 `∂d_max/∂ρ_T < 0`。
即：**手眼可辨识度越高，允许的指令泛化越深**；反之，框架未收敛时只应执行浅层认证技能。
*证明*：由引理 15 与引理 17，`ε_h'−ε_h = L_Tρ_T`，语义误差 `≈ L_gε_pd`，两者共享同一 `B`，相加不超过 `B` 即得；对 `ρ_T` 求导得负斜率。∎
**推论 14.1（向后兼容）** 当 `ξ≡0`、`d=0`（不做新指令泛化）时，BIFOCAL 退化为 SOMA；再令 `ρ_T=0` 时退化为 VISTA/RAS。因此 BIFOCAL 是 SOMA 的严格保守扩展。

## 6. 本轮最大风险

**一句话**：BIFOCAL 的全部安全性都押在「几何证据与语义证据相互独立」这一条上；但真实系统里两者都流过同一个学习式感知/grounding 模型，一旦该模型存在相关误差（相机畸变让物体看起来偏了，语言模型也把「左边」解释成同一个偏移方向），GGR 的独立性检验就会失效，帧与语义会**用同一个错误模型互相背书**，从而在「证书有效」的状态下把机器人执行到一个几何与语义同时错误的位置——这是「用同一个错误去证明自己没有错」的根本风险。

**次级风险与缓解**：
1. **锚不可得**：室内无标识物、无触觉 → 用 IMU 重力 + 冗余运动学闭环 + 已知支撑面的弱锚，并把锚的置信度计入 `Σ_T`；
2. **激励与任务冲突**：move-to-see 可能打断任务 → 激励限制在 `Z_cert∩U_safe`，且只在任务前缀执行完的间隙插入；
3. **grounding 过度保守**：`d_max` 太小导致不可用 → 用主动提问换取语义裕度（AMA），或在仿真中离线扩展认证技能库；
4. **帧协方差非高斯/有偏**：小角度近似失效 → 用区间/鲁棒管而非高斯 `Σ_T`；大规模漂移直接判 `Valid=False`；
5. **实时算力**：AX=XB 与 grounding 只在语义流；实时流只查表认证三元组，保持 `<2 ms`。

## 2. 形式化定义（完整版，260–275）

**定义 260（BIFOCAL 总览）**
```
BIFOCAL = (CLO, HEO, IGG, TCC, NSP-G, GGR, AMA, J-BIFOCAL)
```
包在 SOMA 外层。不变式：(i) 实时流只用认证三元组 `(T_c, τ_cert, z_safe)`；(ii) 帧/grounding 写操作只在语义流；(iii) 帧更新只由几何闭环证据驱动，任务完成误差不得进入帧估计；(iv) 超任务凸包的新指令只能分解或拒绝；(v) 失效即回滚，且回滚不得用当前指令数据重标定框架。

**定义 261（几何框架潜变量与手眼方程）** `T* = T_c·exp(ξ^∧)`，`ξ∈ℝ⁶`。对相对运动对 `{(A_i,B_i)}`：
```
A_i T = T B_i
r_i(T) = log( (A_i T)(T B_i)^{-1} )^∨ ∈ ℝ⁶
T_c = argmin_T Σ_i ‖r_i(T)‖²_{Σ_i^{-1}}
```
注意 `r_i` 跨机器人通道与传感器通道，是**跨帧**量，不是帧内动力学残差。

**定义 262（手眼可辨识度与观测秩）**
```
O_T = ∂R_T/∂ξ |_{ξ=0} ∈ ℝ^{6N×6}
ρ_obs = σ_min(O_T) / σ_max(O_T),   rank = rank(O_T)
```
当相对旋转轴近似平行（或纯平移）时 `rank(O_T)<6`，沿轴平移不可观测，`ρ_obs→0`。认证要求 `ρ_obs≥ρ_min`。

**定义 263（认证激励，move-to-see）** 当 `ρ_obs<ρ_min` 时：
```
u_ex = argmax_{u∈U_safe∩Z_cert} log det(O_TᵀΣ⁻¹O_T + I(δξ;y|u)) − β·risk(u)
```
它是 DES 的静态潜变量版本：DES 增强 Fisher，HEO 增强手眼观测矩阵。

**定义 264（闭环一致性残差）**
```
ρ_T = Σ_i ‖r_i(T_c)‖²_{Σ_i^{-1}} + ρ_contact + ρ_kin
```
`ρ_contact` 来自触觉/已知支撑面，`ρ_kin` 来自冗余运动学闭环。它是几何证据通道。

**定义 265（规范歧义与锚定）** 联合残差 `r(z,ξ)=[r_dyn(z); R_T(ξ)]`，`J=[J_z, J_ξ]`，规范子空间 `G=ker(J)`。锚约束 `A_anchorξ=0`（已知支撑面、IMU 重力、固定标识物、左右对称）。可分当且仅当

```
rank([J; A_anchor]) = dim z + 6
```
特别地，**任务完成误差不是锚**：它依赖当前指令 `ℓ`，`ℓ` 错误时给出有偏方程。

**定义 266（语义框架与 grounding）** `g_φ: ℓ ↦ (E,R,τ,π)`；`p_g(ℓ)` 为校准置信度；`H_task` 为已认证原语在组合深度 `≤d` 下的闭包。

```
m_g(ℓ) = p_g(ℓ) − dist(τ(ℓ), ∂H_task)
```
`m_g ≥ ε_g` 才允许直接认证；否则分解或回退。

**定义 268（任务认证编译，TCC）** `C: τ ↦ (≻_τ, h_τ)`。若 `h_τ` 活跃约束集落在 SOMA 认证包络内，返回 `(τ, True, d)`；否则返回最长任务前缀 `τ_{1:k}` 与 `False`。任务前缀是**组合意义上的前缀**（可安全执行的原语序列）。

**定义 269（框架条件安全裕度）** `L_T` 为 `h` 对帧的 Lipschitz 常数：
```
|h_world − h_{T_c}| ≤ L_T‖ξ‖
ε_h' = ε_h + L_T·ρ_T,   要求 ε_h' < ε_h_max
```
这把「标定协方差」直接翻译成「必须从安全预算中扣除的成本」。

**定义 270（规范守卫与语义-几何串谋）** 帧更新 `δT` 可采纳当且仅当：
1. 由 `ρ_T` 下降支撑；
2. `I(δT; ℓ | E_geom) ≤ ε_c`（与当前指令条件独立）；
3. 在无指令/旧指令留出数据上同样降低 `ρ_T`。

`query` 只更新语义后验，`excite` 只更新几何后验；同一条证据不得同时修改两个框架。

```
d_max = max{ d : ε_g(d) ≤ B_g }
```

**定义 275（闭合不变式）** 任一执行周期：(i) 实时只用认证三元组；(ii) 帧/grounding 写操作只在语义流；(iii) 帧更新须有独立几何锚，任务误差不得反哺帧；(iv) 超包络指令必须分解或拒绝；(v) 失效即回滚，回滚不得用当前指令数据重标定框架。

```python
    post = M.ras.posterior(obs)
    alpha = M.cag.weights(post)
    g = M.grad(obs, M.z_c + M.z_p, alpha)
```

## 4. 推导

**引理 14（帧内残差对框架误差不可见）** 残差由体坐标不变量 `r(T_c,θ)=Φ(T_c⁻¹y,θ)` 构成。当模型也在 `T_c` 下表达时，`T_c⁻¹T*=Δ` 作为全局左乘同时作用于数据与模型，落在残差的规范核内，故 `r(T_c,θ*)=r(T*,θ*)=0`。因此帧内残差检验无法拒绝自洽的错误框架；只有跨通道闭环 `A X = X B` 能看见它。

**引理 15（框架不确定度吃掉安全裕度）** `|h_world−h_{T_c}| ≤ L_T‖ξ‖`，故要对所有 `‖ξ‖≤ρ_T` 保证 `h_world≥ε_h`，须认证 `ε_h'=ε_h+L_Tρ_T`。证明：一阶 Taylor + 绝对值和放缩。

**引理 16（规范分离需要独立锚）** `G=ker([J_z,J_ξ])`。`z、ξ` 分别可辨识当且仅当 `rank([J;A_anchor])=dim z+6`。任务完成误差依赖指令 `ℓ`，带偏置项，不是合法锚；用它更新帧等价于让语义误差吸收进几何框架。

**引理 17（grounding 误差随组合深度累积）** `ε_g(d) ≤ ε_p(L_g^d−1)/(L_g−1)`，`L_g=1` 时 `≤d·ε_p`。证明：组合树归纳 + 等比级数求和。

**定理 13（BIFOCAL 端到端安全性）** 在 A5（`‖ξ‖≤ρ_T`）、A6（锚消歧）、A7（TCC 用 `ε_h'` 验证）、A8（GGR 拒绝语义驱动帧更新）下：
1. `h_world ≥ ε_h − O(ρ_T²)`；
2. 未通过 `m_g≥ε_g` 或 TCC 的新指令不执行，只执行任务前缀/回退技能库；
3. `ρ_obs≥ρ_min ∧ C_collusion≤ε_c` 时，帧误差不被误吸收进 `z`；
4. `T_c` 或 grounding 失效则证书拒绝，退化为 SOMA/VISTA/RAS 的只执行模式。
证明：周期归纳；几何由 A5+A7+引理 15，语义由定义 267/268，分离由 A6+引理 16；失败分支由定义 275(v) 回滚。∎

**定理 14（几何–泛化 Pareto 前沿）**
```
L_T·ρ_T + L_g·ε_p·d ≤ B
d_max(ρ_T) = ⌊(B − L_Tρ_T)/(L_gε_p)⌋,   ∂d_max/∂ρ_T < 0
```
即手眼可辨识度越高，允许的指令泛化越深。证明：引理 15 与引理 17 共享同一安全预算 `B`，相加约束即得；对 `ρ_T` 求导得负斜率。∎

**推论 14.1（向后兼容）** `ξ≡0 ∧ d=0 ⇒ BIFOCAL ≡ SOMA`；再令 `ρ_T=0` 则 `≡ VISTA/RAS`。BIFOCAL 是严格保守扩展。

## 7. 本轮最大风险

**一句话**：BIFOCAL 的全部安全性都押在「几何证据与语义证据相互独立」这一条上；但真实系统里两者都流过同一个学习式感知/grounding 模型，一旦该模型存在相关误差（相机畸变让物体看起来偏了，语言模型也把「左边」解释成同一个偏移方向），GGR 的独立性检验就会失效，帧与语义会**用同一个错误模型互相背书**，从而在「证书有效」的状态下把机器人执行到一个几何与语义同时错误的位置——这是「用同一个错误去证明自己没有错」的根本风险。

**次级风险与缓解**：
1. **锚不可得**（无标识物/无触觉）→ IMU 重力 + 冗余运动学 + 已知支撑面的弱锚，并把锚置信度计入 `Σ_T`；
2. **激励与任务冲突** → 激励限制在 `Z_cert∩U_safe`，只在任务前缀执行间隙插入；
3. **grounding 过度保守** → 主动提问换语义裕度（AMA），或离线仿真扩展认证技能库；
4. **帧协方差非高斯/有偏** → 用区间/鲁棒管代替高斯 `Σ_T`，大漂移直接 `Valid=False`；
5. **实时算力** → AX=XB 与 grounding 只在语义流；实时流只查表认证三元组，保持 `<2 ms`。
