## 1. 两个灵感的第一性原理

### 灵感 1 ·「SLAM」→ 从「一张全局图」到「子图 + 锚点 + 闭环」

第 3 轮把 SLAM 读成「估计 / 地图 / 重定位」三件套，落成单一 SceneState。这是**正确的第一步，但停在 ORB-SLAM 之前的时代**。现代 SLAM 的核心工程不是「一张更准的全局图」，而是：

- **子图（submap）**：把地图切成局部一致的小块，各自维护局部协方差；漂移被局部化，坏子图可丢弃而不毁全图；
- **锚点 / 闭环（anchor / loop closure）**：子图之间只在必要时用相对位姿约束连接，连接本身是一次**受门控的估计**，而不是无条件拼接；
- **不可变快照**：每个子图有唯一写者，读者拿版本化快照，杜绝「别人在我背后改图」。

一句话：**SLAM 抗漂移靠的不是更准的传感器，而是把误差关进局部、把全局一致性降级为可验证的显式约束。** 这恰好是第 3 轮 SceneState 缺的东西——它是一张**全局可变图**，于是第 3 轮 §5 的最大风险「地图毒化」在架构上不可避免。

### 灵感 2 ·「状态隔离」→ 把「共享可变状态」换成「隔离 + 显式共享契约」

「状态隔离」在成熟系统里有四个同构来源，全部指向同一个动作——**不让一份错误的状态无摩擦地流到所有消费者**：

1. **进程 / actor 隔离**：状态归单一写者，跨边界只传消息（不可变快照）；
2. **事务内存 / 写时复制**：读者看到一致快照，写者改副本再原子发布；
3. **传感器故障隔离**：每个证据源有本地滤波，融合前用卡方门控，坏源被隔离而非污染融合值；
4. **检查点 / 回滚**：在安全边界打快照，发现污染就回滚到快照重推，而不是整集重跑。

映射到我们的系统：

- **按作用域隔离**：episode 内状态默认不跨 episode 泄漏（Q9 合规问题从「模糊政策」变成「架构不变量」：没有隐式状态能穿过 episode 边界）；
- **按模块隔离**：断言 / 伺服 / 介入不再共享一个可变 M，而是各自读**同一版本的不可变快照**；
- **按证据源隔离**：检测器、本体感受、夹爪各自本地估计，门控后才进融合；
- **按时间隔离**：每个路标边界打检查点，污染可回滚（L15 给「保持 / 回滚 / 重启」三分决策）。

**与第 3 轮的关系**：第 3 轮说「最后一厘米之前的每一步该信什么」交给状态层；本轮补一句——**状态层自己也要被隔离，否则它把局部错误升级成全局自信错误**。SceneState 的内容（目标档案 / 干扰物 / 参考系）保留，但其**拓扑从单图变为子图网 + 锚点 + 快照 + 门控 + 回滚**。

## 2. 研究问题（新增 Q13–Q15，接 Q1–Q12）

- **Q13（隔离的故障传播界）**：在子图 + 门控融合 + 锚点拓扑下，单源绑定错误污染「离它 d 跳」的查询的概率是否被 `α_g^{d+1}` 界定？不可达子图是否严格 0 污染？（E634）
- **Q14（隔离的代价与最优粒度）**：子图数 K 增大时，鲁棒性收益何时饱和、校准样本与查询延迟何时反超？是否存在 U 形最优 K*？（E635）
- **Q15（回滚的步数经济学）**：在「保持 / 回滚到检查点 / 重启」三分决策里，回滚何时严格占优？检查点密度如何选？（E636）

## 3. 设计原则（新增 P13–P15，接 P1–P12）

- **P13（隔离优先）**：状态默认 episode 作用域、单写者；任何跨边界共享必须是**显式、可审计、只读**的契约（prior channel），不得有隐式泄漏。
- **P14（可回滚）**：每个路标边界的状态变更必须可检查点化；发现子图污染优先回滚重推，重启整集是最后手段。
- **P15（门控融合）**：任何证据源进入融合态前必须过卡方门控；未校准的源只能进「隔离区」待验证，不得直接进融合值（把 L11 从「断言门控」推广到「融合门控」）。

## 4. 清单处置（深化 / 修剪 / 新增）

- **重构（吸收）**：IP-13 SceneState → **IP-16 StateFabric**：场景图内容保留，拓扑升级为子图 + 锚点 + 版本快照 + 门控融合 + 检查点回滚；U17 卡方断言 = 门控的特例；重定位 = 重锚定。
- **深化**：IP-02（介入家族新增「回滚到检查点」，介于保持与重启之间）；IP-11（跨 episode 记忆降格为「显式只读 prior channel + 审计」，Q9 由架构回答）；IP-06（代理评测增加**并行 episode 隔离 / 确定性**校验 E638）；IP-14（物体档案 = 每物体一个子图，滑移只读本物体快照）；IP-15（干扰状态机改为订阅 StateFabric 事件总线）。
- **新增**：IP-16 StateFabric（P0）；IP-17 IsolationAudit 隔离审计（P1，验证不变量 + 合规）。
- **修剪**：第 3 轮「多帧一致 + 接触确认 + 低置信退化」从「三个补丁」升级为 IP-16 的**结构性不变量**；原 IP-13 的全局单图实现归档为 Level-1.6 退化形态。
- **MVP 不变**：IP-06 + IP-02 + IP-09 + IP-03 + 通用基线；IP-16 仍为 MVP 后第一扩展，但交付形态从「加一张图」变为「加一层隔离骨架」。

## 5. 本轮最大风险

**过度隔离反噬**：子图切得过细或锚点拓扑选错，会让目标跨子图拼不起来（「孤岛」）、校准样本被摊薄（L16）、查询延迟随锚点路径变长而超预算——隔离从解药变成新故障源；更隐蔽的是，**prior channel 成为绕过隔离的唯一后门**，一旦它被污染，隔离给出的是虚假的安全感。对冲：最小充分锚点集 + 校准预算上限 + K 的 U 形扫描（E635）+ prior channel 只读且审计（IP-17）+ 拼不起来时退化回全局粗图。

## 6. 下一轮迭代计划（深化与修剪，不推倒重来）

- **深化**：IP-16 的锚点拓扑生成规则与查询延迟实测（E635）；IP-17 的故障注入套件与隔离不变量清单（E634 / E637 / E638）；L15 的检查点密度优化（E636）。
- **修剪预案**：E634 污染界不成立或回滚收益 <10% → IP-16 收缩为「只保留门控融合 + 单检查点」，取消子图；E635 无 U 形或 K*<2 → 退回第 3 轮单图（承认隔离不划算）；E637 发现任何隐式跨集泄漏 → IP-11 prior channel 直接封存。

## 0. 本轮结论摘要

**一句话路线**：v3 在接地层下插入了「状态层」；v4 给状态层本身加**隔离骨架**——子图划分（误差局部化）+ 锚点拓扑（把全局一致性降级为可验证约束）+ 不可变版本快照（单写者、无背后改图）+ 门控融合（坏源隔离）+ 检查点回滚（污染可撤销）。这不是新增模型，而是把第 3 轮最大风险（地图毒化）从「打补丁缓解」升级为「结构性不可传播 + 可回滚」。

## 3. 新增 IP 详述

### IP-16 · StateFabric 隔离状态骨架（P0，新，吸收 IP-13）

- **动机**：第 3 轮 SceneState 是全局可变图，其最大风险（地图毒化）在架构上不可消除，只能靠补丁。状态隔离把它变成「误差局部化 + 可回滚」。
- **与 v3 差异**：v3 = 单图 M=(T,D,F)，所有消费者读同一可变对象；v4 = 子图网 + 锚点 + 版本快照 + 门控融合 + 检查点；内容（档案/参考系）不变，拓扑与访问协议变。
- **技术可行性**：高。子图 = 把现成图按物体/区域/时窗切分；快照 = 写时复制；门控 = 卡方（现成）；回滚 = 保存快照。无新模型、无新数据。
- **资源**：小算力（低频融合）；内存 = 快照副本（K 个子图 × 版本数，可控）；接口无新增字段（全部内部状态，合规安全）。
- **落地步骤**：①子图 schema（物体/区域/时窗三类，U20）；②单写者 + 版本快照（U21）；③门控融合（U22）；④锚点拓扑生成与查询合成；⑤检查点/回滚接入 IP-02；⑥prior channel（默认关闭）+ IP-17 审计；⑦K 扫描（E635）定默认粒度。
- **风险**：过度隔离（L16，见 §10）；锚点拓扑错导致孤岛；prior channel 后门；快照内存膨胀。

### IP-17 · IsolationAudit 隔离审计（P1，新）

- **动机**：隔离若不可测就是口号。合规（Q9 跨集记忆）与评测完整性（E638 并行隔离）都需要**可验证的不变量**。
- **差异**：离线工具链，不参与在线推理；对回放做故障注入、泄漏检测、确定性回放比对。
- **可行性**：高。全离线，复用 IP-06 回放与 IP-16 快照。
- **资源**：近零（CPU 回放）；算力小。
- **步骤**：①不变量清单（无隐式跨集读写 / 单写者 / 快照不可变 / 门控必过）；②故障注入器（绑定错 / 传感器漂移 / 锚点错）；③泄漏检测（扫描跨集句柄）；④确定性回放（逐位比对）。
- **风险**：审计漏报（不变量写不全）；审计拖慢 CI（抽样）。

## 5. 符号与定义（新增 U19–U22；U1–U18 沿用第 1–3 轮）

- **定义 U19（状态划分 StatePartition）**：`S = (∏_{k} S_k, A, C)`；`S_k` 为子图；`A={a_{kl}}` 为跨子图锚点（相对约束 + 协方差）；`C` 为共享契约（谁能读、只读与否、生命周期）。
- **定义 U20（子图 Submap）**：局部一致状态单元，含 `(内容, 协方差 Σ_k, 生命周期, 唯一写者 w_k)`；默认三类切分：物体 / 区域 / 时窗。
- **定义 U21（快照与回滚）**：快照 `σ_k^v` 为子图 k 的版本 v 不可变只读视图；检查点 `CKPT_j` 为路标 j 边界处全体子图版本向量；`rollback(CKPT_j)` 原子恢复该版本向量。
- **定义 U22（门控融合 Gated Fusion）**：证据源本地估计 `z ~ N(μ_z, Σ_z)`；门统计量 `d²=(μ_z−x̂)ᵀ(Σ_z+Σ)⁻¹(μ_z−x̂)`；`d²≤χ²_{d,α_g}` 接受融合，否则进隔离区（quarantine）待二次确认，**永不直接进融合值**。

## 6. 关键算法骨架（新增片段；主体沿 v3 `UniBotSAGEPolicy`）

```python
# ===== IP-16: 隔离状态骨架（子图 + 快照 + 门控 + 回滚）=====
class StateFabric:
    def __init__(self, task_token):
        self.submaps = {}          # U20: k -> {content, Sigma, owner, version}
        self.anchors = {}          # A: (k,l) -> {rel, cov, gated, version}
        self.snapshots = {}        # U21: (k,v) -> immutable snapshot
        self.ckpts = []            # 路标边界版本向量

    def gated_fuse(self, k, z, Sigma_z):
        x, S = self.submaps[k].state, self.submaps[k].Sigma
        d2 = (z - x).T @ inv(Sigma_z + S) @ (z - x)          # U22
        if d2 <= chi2_ppf(len(x), ALPHA_G):
            self.submaps[k].write(fuse(x, S, z, Sigma_z), owner=k)  # 单写者
        else:
            self.quarantine[k].append((z, Sigma_z))           # 坏源隔离，不进融合值
        self.publish(k)                                       # 发布新版本快照

    def query(self, target, consumers):
        # 沿锚点路径合成；不可达子图严格不参与（污染=0）
        path = self.anchor_path(consumers, target)
        return compose([self.snapshot(k) for k in path], self.anchors)

    def checkpoint(self, wp_id):
        self.ckpts.append((wp_id, {k: sm.version for k, sm in self.submaps.items()}))

    def rollback(self, wp_id):                                # IP-02 回滚介入
        _, ver = next(c for c in reversed(self.ckpts) if c[0] == wp_id)
        for k, v in ver.items():
            self.submaps[k].restore(self.snapshots[(k, v)])
```

```python
# ===== U22: 门控融合（把 L11 从断言推广到融合）=====
def fuse_gate(z, Sigma_z, x, Sigma, alpha_g):
    S = Sigma_z + Sigma
    d2 = (z - x).T @ inv(S) @ (z - x)
    if d2 <= chi2_ppf(len(x), alpha_g):
        K = Sigma @ inv(S)                              # 卡尔曼增益
        return x + K @ (z - x), Sigma - K @ Sigma       # 接受
    return x, Sigma, "QUARANTINE"                       # 拒绝：坏源隔离
```

```python
# ===== L15: 三分决策（保持 / 回滚 / 重启）=====
def recover(prefix_j, ckpt_c, h, costs):
    C_keep     = h + costs.remaining(p=prefix_j.p_after)
    C_rollback = costs.R(ckpt_c) + costs.remaining_from(ckpt_c, p=prefix_j.p_clean)
    C_restart  = costs.full()
    return min(("KEEP", C_keep), ("ROLLBACK", C_rollback), ("RESTART", C_restart),
               key=lambda t: t[1])
```

## 7. 推导（新增引理 L14–L16；L1–L13 沿用第 1–3 轮）

**引理 L14（隔离的故障传播界）** 设子图 k 收到一个故障证据源，本地门控误接受率 ≤ α_g。若消费者查询需经锚点路径 k→…→l（深度 d），且每级锚点亦门控、误接受率 ≤ α_g，则单源错误污染 l 的查询的概率 ≤ α_g^{d+1}·β（β≤1 为耦合系数）；若 k 与 l 之间无锚点路径，则污染严格为 0。⇒ **污染概率随隔离深度几何衰减，且不可达子图完全免疫**；单图（d=0）对应 α_g^1，即第 3 轮地图毒化风险的结构来源。∎

**引理 L15（保持-回滚-重启三分经济学）** 干扰发生在完成前缀 j 后。令 `C_keep = h + Σ_{i>j} s_i/p'_i`，`C_rollback = R_c + Σ_{i>c} s_i/p''_i`（c≤j，p''≥p' 因状态更干净），`C_restart = Σ_{i≤K} s_i/p_i`。则：①回滚占优于保持 ⇔ `R_c + Σ_{i>c} s_i/p''_i < h + Σ_{i>j} s_i/p'_i`，即**干净化收益 `Σ(s_i/p'_i − s_i/p''_i)` 超过回滚开销 R_c**；②回滚占优于重启 ⇔ `R_c + Σ_{i>c} s_i/p''_i < Σ_{i≤K} s_i/p_i`。两者可同时成立，故存在**回滚最优的中间区间**（保持与重启都不最优）。⇒ L12 的二元决策是 c=j（保持）与 c=0（重启）两个端点的特例；回滚是第三个一等选项。∎

**引理 L16（隔离的代价）** 设 K 个子图，校准每子图协方差需 n 个样本，则总校准样本 ~O(K·n)（锚点再乘深度因子）；查询需沿锚点路径合成，延迟 ~O(d)。鲁棒性收益（L14）随 K 单调但**饱和**（不可达子图已达 0 污染后，再细分无增益），代价随 K **线性/超线性**增长。⇒ 总目标（鲁棒性 − λ·代价）存在 **U 形最优 K\***：过粗=单点故障，过细=欠校准 + 高延迟。∎
