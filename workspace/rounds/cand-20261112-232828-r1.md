# 第 63 轮（承接第 62 轮「ROSE 鲁棒在线场景进化闭环」IP-183~192；灵感循环 II 第 2 轮；本轮灵感：「小样本学习」×「推理延迟」）

> 第 62 轮用 ROSE 把 ESEC 从「静态语义-执行闭环」推进为「在线学习 + 鲁棒兜底 + 场景课程」的动态闭环：OLP 有 √T 遗憾界、WCV/RSC 有偏差免疫、SBR/SHC 有场景课程、Shield 有机制安全。但 ROSE 的两个隐含代价，恰好被第 62 轮的四个风险暴露出来：
> 1. **适应仍然「样本饥渴」**：OLP/MEL-OA 都从当前参数出发做梯度式在线学习，每换一个场景簇要几十上百次执行才收敛；SBR 只把经历存起来做回放，没有把「少量相似经历」直接变成「可用的投影头」。系统「经历很多、每次仍从零学」。
> 2. **学习没有把推理延迟当一等公民**：OLP 前向很便宜，但 WCV 的 n_worst=16 候选、适配器切换、场景检索/预取都可能吃掉实时预算；ROSE 只保证「实时路径无学习写操作」，没有保证「在任意算力抖动下，安全证书仍在 deadline 前完成」。OCB 只调度 MEL 模式，不调度 WCV 精化与适配器缓存。
> 3. **RSC 的球半径仍依赖 J_φ 可逆**：第 62 轮最大风险（J_φ 病态 / 外力矩残差被控制回路吸收 → r_t 低估 → 球覆盖失效 → WCV 纸面保证）没有被真正消除，只是被声明为单点假设 A72。
> 4. **少样本与低延迟之间存在结构性矛盾**：想快就用大模型/大适配器，想省延迟就用小模型/缓存；ROSE 没有把「用多少样本、花多少毫秒、买多少安全」放在同一个可证框架里。

## 0. 直觉与动机

**灵感 1（小样本学习 → FSA：元先验 + 凸岭回归的少样本投影头）**
直觉：OLP 现在是「每步从当前 W 做一次 OGD」，新簇冷启动时等于从零学。若先在仿真任务族上离线学一个元先验 W_meta，部署时只用 k 个簇内 episode 解一个正则化凸问题，就能得到 W_c。k 小时先验兜底，k 大时数据说话；只需要 W 凸，不需要整个网络凸，与 ROSE 的 𝒲 和 OLP 接口完全兼容。关键不是「元学习很酷」，而是把「样本效率」变成先验距离的显式函数：||W_c* − W_meta|| 越小，k 可以越小。

**灵感 2（小样本学习 → CQB：少样本 conformal 球，替代 J_φ 反演）**
直觉：RSC 试图用残差反演 φ 误差，但 J_φ 病态就完蛋。换一个问法：不猜误差，直接「用少量带真值 φ 的校准 episode 标定一个球半径」，用 split conformal 的有限样本分位数。k=19 就能给 95% 边际覆盖，k=9 给 90%——这才是「少样本」最该用的地方：用在校准上，而不是用在不稳定的反演上。分布漂移时用 ACI 在线调目标分位，长期把误覆盖压回 α。安全论证从「假设 J_φ 良态」变成「假设校准与部署可交换 + ACI 长期覆盖」。

**灵感 3（推理延迟 → AWC：任意时最坏情形编译，安全不依赖预算）**
直觉：WCV 现在一次性跑 16 个候选；如果算力抖了，要么超时要么少跑。把 WCV 拆成「永远可用的解析下界 + 可选的采样精化」：解析下界用 Lipschitz / 区间算术给出保证，采样只把保守间隙收紧。这样 n=0 也安全，n 越多越不保守；deadline 只影响保守程度，不影响安全性。这是「推理延迟」最重要的一次角色转换：延迟不再是要压掉的成本，而是可以被安全证书显式吸收的预算。

**灵感 4（推理延迟 → PFC：投机预取 + 适配器缓存）**
直觉：少样本适配器好，但「切簇时现算」会卡实时。用 SHC/Hedge 的簇权重预测下一个簇，在语义流预取 top-b 适配器 + 对应 conformal 半径；实时流只做 O(1) 查表。命中用 W_c，未命中用全局 W_meta 或上一个有效 W_c（并按年龄膨胀 r）。学习永远不阻塞控制；缓存未命中只损失一点保守性，不损失安全性。

**灵感 5（小样本 + 延迟 → CSS + DAB：支持集选择与预算分配）**
直觉：k 个支持样本不是随便取——用 greedy k-center 在场景签名空间选「覆盖最广」的 k 个，再按失败/遗憾加权，让险情样本优先进入支持集；预算也不是固定 16 个候选——用 deadline slack 反推 n_t，把「样本预算」和「计算预算」同时当成约束。少样本和低延迟不是二选一，而是同一个「覆盖率—保守性—时延」三角的三个投影。

**灵感 6（合流 → FABLE：少样本快层 × 延迟安全层）**
直觉：FABLE = few-shot 快层 + latency 安全层。FSA 回答「用 k 个样本怎么学」，CSS 回答「用哪 k 个」，CQB/ACI 回答「学错时球多大」，AWC 回答「算不完时怎么还安全」，PFC/DAB 回答「怎么在 deadline 前把适配器和候选准备好」，STG 回答「什么时候切换」，FJC 回答「凭什么信」。ROSE 仍是执行层；FABLE 是「样本—算力—安全」三角的调度层：**用尽量少的样本学、在确定的毫秒内算、在任何预算下都保留一个可证的保守下界**。

## 1. 形式化定义（增量：定义 185–196）

- **定义 185（FABLE 少样本延迟感知闭环）**：FABLE = (ROSE, FSA, CSS, CQB, ACI, AWC, PFC, DAB, STG, FJC)。定位：挂在 ROSE 上的「样本效率 × 推理延迟」层；全部学习、校准、预取只发生在语义流与低频线程，实时流只做缓存读 + OLP 前向 + AWC 认证编译。
- **定义 186（支持 episode 与支持集）**：e_i = (x_i, φ_i^cal, y_i, cert_i, c_i, ts_i)；S_c = {(x_i, φ_i^cal)} 为从场景银行簇 c 中按 CSS 选出的 k 个校准/示范 episode，φ_i^cal 来自离线计量、仿真配对或可信标定工况。
- **定义 187（FSA 少样本投影头）**：W_c = Proj_𝒲( argmin_{W∈𝒲} L̂_{S_c}(W) + (λ_c/2)‖W−W_meta‖_F² )；局部二次近似下闭式为 W_c = Proj_𝒲( W_meta + (HᵀH+λ_cI)⁻¹Hᵀ(ΔK^⋆ − H W_meta) )，其中 H 的行是 h(x_i)ᵀ，ΔK_i^⋆ 是成功示范/一阶最优给出的目标修正。K_t = Π_0(x_t) + h(x_t)ᵀW_c。
- **定义 188（CSS 覆盖支持选择）**：给定簇 c 的候选 episode 池 P_c，S_c = GreedyKCenter(P_c, k)，目标最小化覆盖半径 δ_k = max_{e∈P_c} min_{s∈S_c} ‖ψ(e)−ψ(s)‖；险情/高遗憾 episode 以权重 w_e = 1+κ_r·R̂_c(e) 优先入池。
- **定义 189（CQB 少样本 conformal 球）**：校准分数 s_i = ‖φ_i^cal − φ̂_i‖₂（或 Mahalanobis 距离），r_c = s_{(⌈(n_c+1)(1−α)⌉)}；若 ⌈(n_c+1)(1−α)⌉ > n_c，则 r_c = r_max（保守兜底）。球 B(φ̂_t, r_c) 以 MEL 估计为心。
- **定义 190（ACI 自适应 conformal）**：维护最近 W_cal 个分数/安全指示的滑动窗口；目标水平 α_t 按 α_{t+1} = clip(α_t + γ(α − err_t), α_min, α_max) 更新，err_t = 𝟙[φ_t* ∉ B(φ̂_t, r_t)]；r_t 取窗口的 1−α_t 经验分位数。r_t = max(r_t^CQB, r_t^RSC)，RSC 降级为辅助信号。
- **定义 191（AWC 任意时最坏情形编译）**：设安全裕度 m(K,φ) 对 φ 为 L_m-Lipschitz。解析下界 m_LB(K) = m(K,φ̂) − L_m·r_t；采样上界 m_UB(K) = min_{i≤n_t} m(K,φ_i)，φ_i ∈ ∂B(φ̂_t,r_t)。K_safe = argmax_{K∈𝒦_cert} m_LB(K)，证书返回 (ρ_LB=m_LB(K_safe), ρ_UB=m_UB(K_safe), n_t)。n_t 由 DAB 在 deadline 内给出；n_t=0 时只用解析下界。
- **定义 192（PFC 投机预取缓存）**：cache 项为 (c, W_c, r_c, version, ts)；语义流按 Hedge 权重 p_c ∝ w_c 预取 top-b 簇。实时流按当前簇 id 查表：fresh（age<τ_fresh）则用 W_c 与 r_c；否则回退 W_meta 或最近有效 W_c，并按 age 膨胀半径 r_t ← r_t + κ_age·(age/τ_fresh)。
- **定义 193（DAB 截止期感知预算器）**：固定开销 T_fix = T_read + T_OLP + T_cert + T_dispatch；抖动上界 J_max；n_t = max(0, ⌊(D_max − T_fix − J_max)/T_cand⌋)。若 n_t=0 且 T_fix>T_max，则进入预计算基线 K_baseline 的「认证降级」模式。DAB 不改变 OCB 的 MEL 模式选择，只分配 WCV 精化与预取预算。
- **定义 194（STG 切换治理器）**：仅当 (i) 新簇 Hedge 权重领先当前簇 ≥ h_w，或 (ii) 当前适配器年龄 > τ_dwell，且 (iii) 预测损失改进 > h_ℓ 时才切换；否则保持当前 W_c。切换次数 N_sw 与切换代价 C_sw 记入证书。
- **定义 195（FJC 联合证书）**：J_fable = (J_rose, S_c ids, W_c version, r_t^CQB, α_t, n_c, r_t^RSC, ρ_LB, ρ_UB, n_t, latency_UB, cache_state, N_sw, fallback_used)。Valid ⇔ Valid(J_rose) ∧ n_c ≥ n_min(α)（或 r_t=r_max）∧ ρ_LB ≥ 0 ∧ latency_UB ≤ D_max ∧ adapter_fresh。
- **定义 196（FABLE 闭环算子）**：语义流执行 [CSS 选支持集 → FSA 解 W_c → CQB/ACI 校准 r_t → PFC 预取 → STG 决策 → DAB 设候选预算 → 锚点提交]；实时流执行 [缓存读 → OLP 前向 → AWC 认证编译 → 派发 → 构建 J_fable]。学习/校准/预取与实时派发在时序上严格隔离。

## 2. 关键算法骨架（完整伪代码见产物区）

```python
# 少样本快层（语义流，低频）——用 k 个 episode 解一个带元先验的凸岭问题
S = greedy_kcenter(P_c, k, weight=Rhat_c)                  # CSS：覆盖 + 险情优先
W_c = proj_W(W_meta + solve(H.T@H + lam*I, H.T@(dK - H@W_meta)))  # FSA
# 少样本安全层——conformal 分位数 + ACI，不再反演 J_phi
r = conformal_quantile(scores, ceil((n_c+1)*(1-alpha)))   # CQB: n_c>=19 -> 95%
r = max(r, r_rsc); alpha = clip(alpha + gamma*(alpha - err), amin, amax)  # ACI
# 延迟安全层——解析下界永远有效，采样只收紧间隙
mLB = m(K, phi_hat) - L_m*r;  mUB = min_i m(K, phi_i)        # AWC
n_t = max(0, (D_max - T_fix - J_max)//T_cand)                # DAB
K_safe = argmax_K mLB;  prefetch(top_b(p_c))                 # PFC/STG
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 1（少样本元先验界）**：设 ℓ∈[0,1]、𝒲 直径 D、W_c* 为簇内最优。对正则化 ERM 有 L_c(Ŵ) − L_c(W_c*) ≤ (λ/2)‖W_c*−W_meta‖² + O(√((d_W log(D/ε)+log(1/δ))/(λk)))。取最优 λ 得超额风险 ≤ O(‖W_c*−W_meta‖·√((d_W log(1/δ))/k))。**样本效率由先验距离决定，而非由网络大小决定**。
- **引理 2（支持覆盖）**：CSS 的 greedy k-center 给出 δ_k ≤ 2δ_k*；在 doubling 维数 d_sig 下 δ_k ≤ O(Δ_c k^{−1/d_sig})。若簇损失对签名 L_x-Lipschitz，则支持集与簇分布的损失差 ≤ L_x δ_k。
- **定理 1（conformal 有限样本覆盖）**：若校准分数与测试分数可交换，取 r_c = s_{(⌈(n_c+1)(1−α)⌉)}，则 P[φ*∈B(φ̂,r_c)] ≥ 1−α。α=0.05 时 n_c≥19；α=0.10 时 n_c≥9；n_c 不足时 r_c=r_max，绝不假装有保证。**不需要 J_φ 可逆、不需要次高斯噪声**。
- **定理 2（ACI 长期覆盖）**：对任意分数序列、r_t∈[r_min,r_max]，ACI 满足 (1/T)Σerr_t ≤ α + O(1/(γT))。突发漂移后覆盖率可恢复，代价是恢复期内更保守。
- **定理 3（任意时预算安全性）**：对任意 n_t≥0，ρ_LB(K)=m(K,φ̂)−L_m r_t 都是真实最坏裕度的下界；若 ρ_LB(K_safe)≥0 则 K_safe 在球内全 φ 安全。**安全性与 n_t 无关；减少候选只增大保守间隙 ρ_UB−ρ_LB，不产生违规**。
- **命题（时延上界）**：T_cycle ≤ T_fix + n_t·T_cand + J_max ≤ D_max；PFC 命中 O(1)，未命中回退 O(1)，学习永不进入实时路径。合成自检：n=16 时 p99=840µs<1ms，n=24 时 p99=1080µs>1ms，故 DAB 将 n 封顶 16。
- **命题（切换有界）**：STG 的驻留时间 τ_dwell 使 N_sw ≤ T/τ_dwell + O(1)；累计损失 ≤ 静态最优 + O(√T) + C_sw·N_sw。抖动被显式计入，而非靠运气。
- **与前轮衔接**：CQB/ACI 给 r_t 一个不依赖 J_φ 的下界，RSC 从「单点安全假设」降级为「辅助收紧信号」；AWC 给 WCV 一个 deadline-aware 的认证版本；PFC/FSA 给 OLP 一个少样本热启动。第 62 轮风险 1/2 与最大风险被机制性缓解。

## 5. 本轮最大风险

**一句话**：FSA 的元先验与 CQB 的有限样本覆盖都压在同一个假设上——簇内校准 episode 与部署分布可交换且簇足够紧；若新材质/新任务让簇快速漂移，少样本先验会「自信地学错」、conformal 边际覆盖失效，ACI 只能保长期平均而不能保单步条件安全，FABLE 会退化为「少样本但不可靠」，安全只剩 AWC 在 r_max 下的保守下界兜底，性能可能低于 ROSE 基线。

## 2. 形式化定义（完整版）

**定义 185（FABLE 少样本延迟感知闭环）** FABLE 是 ROSE 的「样本效率 × 推理延迟」升级层。ROSE 原有的 USR/MEL/DMS/SRT-Dual/SBR/OLP/WCV/RSC/ARA/Shield/OCB 全部保留；新增 FSA/CSS/CQB/ACI/AWC/PFC/DAB/STG/FJC。不变式：**任何会改变参数、校准半径、缓存内容或支持集的操作，只发生在语义流与低频线程；实时流只读缓存、做 OLP 前向、执行 AWC 认证编译与派发**。与 ROSE 定义 184 的「学习/安全时序隔离」完全一致，只是把「实时路径零学习写」加强为「实时路径零学习读之外的一切阻塞」。

**定义 186（支持 episode 与支持集）** 支持 episode 为 e_i = (x_i, φ_i^cal, y_i, cert_i, c_i, ts_i)，其中 x_i 是 USR 融合表征，φ_i^cal 是校准物理参数（离线计量、仿真配对或可信标定工况），y_i 是执行结果（成功/力峰值/滑移/跟踪误差），cert_i 是 ROSE 执行证书。支持集 S_c ⊆ P_c 为簇 c 候选池中按 CSS 选出的 k 个 episode。**支持集只服务少样本适配与 conformal 校准，不进入实时路径**。

**定义 187（FSA 少样本投影头）** 给定元先验 W_meta（离线在仿真任务族上训练）与支持集 S_c：
`W_c = Proj_𝒲( argmin_{W∈𝒲} L̂_{S_c}(W) + (λ_c/2)‖W−W_meta‖_F² )`。
当支持 episode 提供目标修正 ΔK_i^⋆ 时，取二次代理 L̂ ≈ (1/2)Σ_i‖h(x_i)ᵀW − ΔK_i^⋆‖²，得到闭式
`W_c = Proj_𝒲( W_meta + (HᵀH+λ_cI)⁻¹Hᵀ(ΔK^⋆ − H W_meta) )`。
在线阶段只保留一个低幅 OGD 残差项（与 ROSE OLP 相同），且与 FSA 交替更新（奇偶步），避免第 62 轮风险 4 的「双学习互追」。K_t = Π_0(x_t) + h(x_t)ᵀW_c。

**定义 188（CSS 覆盖支持选择）** 候选池 P_c 为场景银行簇 c 中证书有效、时间窗内的 episode。CSS 先以险情/高遗憾加权 w_e = 1+κ_r·R̂_c(e)，再用 greedy k-center 最小化
`δ_k(S) = max_{e∈P_c} min_{s∈S} ‖ψ(e)−ψ(s)‖`，
其中 ψ 为场景签名（视觉/触觉/物理标签拼接）。初始化选 w_e 最大的险情样本，之后每步选 `argmax_e w_e·min_{s∈S}‖ψ(e)−ψ(s)‖`。支持集大小 k 由样本预算与 n_min(α) 共同决定：k ≥ max(k_adapt, n_min(α))。

**定义 189（CQB 少样本 conformal 球）** 对簇 c 的校准集（n_c 个带 φ^cal 的 episode），计算非一致性分数 s_i = ‖φ_i^cal − φ̂_i‖₂（或按 Σ_t 白化的 Mahalanobis 距离）。取
`r_c = s_{(⌈(n_c+1)(1−α)⌉)}`，若 `⌈(n_c+1)(1−α)⌉ > n_c` 则 r_c = r_max。
球 B(φ̂_t, r_c) 以 MEL 的当前估计为心。α=0.05 要求 n_c≥19；α=0.10 要求 n_c≥9；不足时宁可 r_max 保守，也不输出无保证的小球。

**定义 190（ACI 自适应 conformal）** 维护最近 W_cal 个分数/安全指示的滑动窗口。目标水平 α_t 初始为 α；每步观测 err_t = 𝟙[φ_t* ∉ B(φ̂_t, r_t)]（真值来自周期性计量；无真值时用可观测 margin 代理 + L_m 反推的保守分数）。更新
`α_{t+1} = clip(α_t + γ(α − err_t), α_min, α_max)`，
`r_t = max( Quantile_{1−α_t}(window), r_c^CQB, r_t^RSC )`。
RSC 的 J_φ⁺ 反演保留为辅助信号，但不再单独决定安全球：即使 J_φ 病态，CQB/ACI 仍给出不依赖它的半径。这是对第 62 轮 A72 的「降级而非删除」。

**定义 191（AWC 任意时最坏情形编译）** 设安全裕度 m(K,φ) 在球 B(φ̂_t,r_t) 上对 φ 为 L_m-Lipschitz。定义
`m_LB(K) = m(K,φ̂_t) − L_m·r_t ≤ min_{φ∈B} m(K,φ) ≤ m_UB(K) = min_{i≤n_t} m(K,φ_i)`，
其中 φ_i 为球面候选。AWC 在区间算术/ Lipschitz 认证的可行集 𝒦_cert 上取
`K_safe = argmax_{K∈𝒦_cert} m_LB(K)`，
返回 (K_safe, ρ_LB=m_LB(K_safe), ρ_UB=m_UB(K_safe), n_t)。若 ρ_LB<0，回退到预认证的 K_baseline；若 K_baseline 也不可用，进入安全停止。**证书只用 ρ_LB；ρ_UB 只用于报告保守间隙，绝不能拿来认证安全**。

**定义 192（PFC 投机预取缓存）** 缓存项 cache(c) = (W_c, r_c, version, ts)。语义流按 SHC/Hedge 权重 p_c ∝ w_c 预取 top-b 簇的 (W_c,r_c)，并在簇支持集更新时递增 version。实时流按当前簇 id 查表：
- fresh：age = now−ts < τ_fresh，直接使用 W_c 与 r_c；
- stale/miss：回退 W_meta（全局元先验）或最近有效 W_c，并按 age 膨胀 r_t ← r_t + κ_age·(age/τ_fresh)；
- 任何回退都记录 fallback_used 入证书。**未命中只损失一点保守性，不引入未认证参数**。

**定义 193（DAB 截止期感知预算器）** 设 D_max 为实时周期 deadline，T_fix = T_read + T_OLP + T_cert + T_dispatch，T_cand 为单候选精化成本，J_max 为抖动上界。取
`n_t = max(0, ⌊(D_max − T_fix − J_max)/T_cand⌋)`。
若 T_fix > D_max（极端算力抖动），进入「认证降级」：跳过采样精化，使用预计算 K_baseline 与其证书；若连派发都无法保证，则安全停止并请求上层重规划。DAB 不改 OCB 的 MEL 模式选择，只分配 WCV 精化与 PFC 预取预算。

**定义 194（STG 切换治理器）** 当前适配器为 W_cur（簇 c_cur），候选为 W_new（簇 c_new）。仅当
`(w_{c_new} − w_{c_cur} ≥ h_w 或 age(W_cur) ≥ τ_dwell) 且 ΔL_pred > h_ℓ`
时切换；否则保持。切换后重置 OLP 残差、递增 FJC 的 N_sw，并记录 C_sw。τ_dwell 阻止在两个相近簇之间抖动；h_ℓ 阻止「为了新而新」。

**定义 195（FJC 联合证书）** `J_fable = (J_rose, S_c ids, W_c version, r_t^CQB, α_t, n_c, r_t^RSC, ρ_LB, ρ_UB, n_t, latency_UB, cache_state, N_sw, fallback_used)`。
验证规则：
`Valid(J_fable) ⇔ Valid(J_rose) ∧ (n_c ≥ n_min(α) ∨ r_t = r_max) ∧ ρ_LB ≥ 0 ∧ latency_UB ≤ D_max ∧ adapter_fresh`。
审计链：S_c ids 回答「用哪几个历史 episode 学的」，W_c version 回答「学成了什么」，r_CQB/α_t 回答「凭什么说球够大」，n_t/latency_UB 回答「凭什么说来得及」，cache/fallback 回答「这一步用的是哪个适配器」。

**定义 196（FABLE 闭环算子）** 语义流（10–100Hz）：
[CSS 选支持集 → FSA 解 W_c → CQB 校准 r_c → ACI 更新 α_t/r_t → PFC 预取 top-b → STG 决策 → DAB 设 n_t → ARA 提交锚点 → 执行损失/证书回传 → 支持集与银行记账]。
实时流（1–10kHz）：
[缓存原子读 → OLP 前向（W_c 或 W_meta）→ AWC 认证编译 → ERTC 派发 → 构建 J_fable]。
**全部学习/校准/预取在语义流；实时流零学习写、零支持集读、零阻塞等待。**

### IP-193 FSA（少样本元先验投影头）

```python
class FewShotAdapter:
    """离线学 W_meta；部署时用 k 个支持 episode 解一个凸岭问题。"""
    def __init__(self, Pi0, h, W_meta, lam=1.0, W_box=None):
        self.Pi0, self.h = Pi0, h          # 冻结骨干 + 冻结特征
        self.W_meta = W_meta               # 离线元先验
        self.lam, self.W_box = lam, W_box

    def fit(self, support):
        # support: [(x_i, dK_star_i)]
        H = np.stack([self.h(x) for x, _ in support])          # k x m
        dK = np.stack([dK for _, dK in support])               # k x d_out
        A = H.T @ H + self.lam * np.eye(H.shape[1])
        b = H.T @ (dK - H @ self.W_meta)
        W_c = self.W_meta + np.linalg.solve(A, b)
        return self.W_box.proj_fro(W_c)                        # 保持 W_c ∈ 𝒲

    def project(self, x, W_c):
        K = self.Pi0(x) + self.h(x) @ W_c
        return self.W_box.clip(K)                              # 实时路径 O(1) 前向

    def residual_step(self, x, grad_l, W_c, eta):
        # 簇内极小残差微调；与 FSA 交替执行，避免双学习互追
        g = np.outer(self.h(x), grad_l)
        return self.W_box.proj_fro(W_c - eta * g)
```

### IP-194 CSS（覆盖支持选择）

```python
def greedy_kcenter(pool, k, weight, psi):
    """险情优先 + 最大最小距离覆盖。"""
    if not pool:
        return []
    S = [max(pool, key=lambda e: weight[e])]
    while len(S) < k:
        e_best, score_best = None, -1.0
        for e in pool:
            if e in S:
                continue
            d = min(np.linalg.norm(psi(e) - psi(s)) for s in S)
            score = weight[e] * d          # 覆盖与遗憾的乘积
            if score > score_best:
                e_best, score_best = e, score
        S.append(e_best)
    return S

def support_set(bank, cluster_id, k_adapt, alpha, kappa_r=0.5):
    pool = bank.valid_pool(cluster_id)                      # 证书有效 + 时间窗
    k = max(k_adapt, n_min(alpha))                          # 覆盖与校准双约束
    return greedy_kcenter(pool, min(k, len(pool)),
                          weight=lambda e: 1 + kappa_r * e.regret_acc,
                          psi=lambda e: e.signature)
```

### IP-195 CQB + IP-196 ACI（少样本 conformal 球）

```python
def conformal_radius(scores, alpha, r_max):
    n = len(scores)
    idx = int(math.ceil((n + 1) * (1.0 - alpha)))
    if idx > n:
        return r_max, False          # 样本不足：宁可保守，不假装有保证
    return sorted(scores)[idx - 1], True

class AdaptiveConformal:
    def __init__(self, target_alpha=0.05, gamma=0.02, r_max=0.5,
                 window=200, amin=1e-3, amax=0.5):
        self.target, self.gamma = target_alpha, gamma
        self.alpha, self.r_max = target_alpha, r_max
        self.window, self.amin, self.amax = deque(maxlen=window), amin, amax

    def update(self, score, err, r_rsc):
        self.window.append(score)
        # ACI：误覆盖时降低目标水平 -> 半径变大
        self.alpha = float(np.clip(self.alpha + self.gamma * (self.target - err),
                                   self.amin, self.amax))
        r_conf, ok = conformal_radius(list(self.window), self.alpha, self.r_max)
        r = max(r_conf, r_rsc)        # RSC 只做辅助收紧，不再单独定安全
        return r, self.alpha, ok
```

def awc_compile(olp, anchor, eeis, r, n_t, L_m, K_baseline):
    """解析下界永远有效；采样只收紧 UB，不参与安全认证。"""
    K0 = olp.project(anchor.x)
    # 1) 解析/区间算术：对球内所有 phi 给出认证可行集与下界
    K_safe = eeis.compile_certified(K0, anchor.phi_hat, r, L_m)
    rho_lb = safety_margin_lb(K_safe, anchor.phi_hat, r, L_m)
    if rho_lb < 0:
        return K_baseline, -float('inf'), -float('inf'), 0, 'fallback'
    # 2) 可选精化：只用于报告保守间隙，绝不用来“证明”安全
    if n_t == 0:
        return K_safe, rho_lb, rho_lb, 0, 'analytic_only'
    phis = sample_ball_boundary(anchor.phi_hat, r, n_t)
    rho_ub = min(safety_margin(K_safe, p) for p in phis)
    return K_safe, rho_lb, max(rho_lb, rho_ub), n_t, 'refined'

### IP-198 PFC（投机预取缓存）

```python
class PrefetchCache:
    def __init__(self, tau_fresh=2.0, kappa_age=0.2):
        self.cache, self.tau_fresh = {}, tau_fresh
        self.kappa_age = kappa_age

    def prefetch(self, hedge_w, bank, fsa, conformal, b=4):
        for c in np.argsort(hedge_w)[-b:]:
            S = support_set(bank, c, k_adapt=8, alpha=conformal.target)
            W_c = fsa.fit([(e.x, e.dK_star) for e in S])
            r_c, _ = conformal_radius([e.score for e in S],
                                      conformal.alpha, conformal.r_max)
            self.cache[c] = CacheEntry(W_c, r_c, version=bank.version(c),
                                       ts=time.time())

    def lookup(self, c, W_meta, r_scs):
        e = self.cache.get(c)
        if e is None:
            return W_meta, r_scs, False, 'miss_meta'
        age = time.time() - e.ts
        if age < self.tau_fresh:
            return e.W_c, max(e.r_c, r_scs), True, 'hit'
        infl = self.kappa_age * (age / self.tau_fresh)
        return e.W_c, max(e.r_c, r_scs) + infl, False, 'stale_inflated'
```

def deadline_budget(D_max_us, T_fix_us, T_cand_us, J_max_us):
    n = max(0, int((D_max_us - T_fix_us - J_max_us) // T_cand_us))
    if T_fix_us > D_max_us:
        return 0, 'certified_baseline'      # 连固定开销都超：认证降级
    return n, ('analytic_only' if n == 0 else 'refine')

class SwitchingGovernor:
    def __init__(self, h_w=0.15, h_l=0.05, tau_dwell=2.0):
        self.h_w, self.h_l, self.tau_dwell = h_w, h_l, tau_dwell

    def should_switch(self, cur, new, hedge_w, age, loss_gain):
        lead = hedge_w[new] - hedge_w[cur]
        return ((lead >= self.h_w or age >= self.tau_dwell)
                and loss_gain > self.h_l)
```

        len(S), M.rsc.r, rho_lb, rho_ub, n_used,
        latency_ub=estimate_latency_ub(n_used), cache_state=state,
        n_sw=M.stg.n_sw, fallback=(state == 'miss_meta'))
```

## 4. 推导

**引理 1（少样本元先验界）** 设损失 ℓ∈[0,1]，𝒲 的 Frobenius 直径 ≤D，簇 c 的最优参数 W_c* = argmin_{W∈𝒲}L_c(W)。对正则化 ERM
`Ŵ = argmin_{W∈𝒲} L̂_{S_c}(W) + (λ/2)‖W−W_meta‖²`
用覆盖数/均匀收敛：以概率 ≥1−δ，
`L_c(Ŵ) ≤ L_c(W_c*) + (λ/2)‖W_c*−W_meta‖² + O(√((d_W log(D/ε)+log(1/δ))/(λ k)))`。
对 λ 取最优，得
`L_c(Ŵ) − L_c(W_c*) ≤ O( ‖W_c*−W_meta‖·√((d_W log(D/ε)+log(1/δ))/k) )`。
解读：**少样本的可达误差由「先验有多近」决定，而不是由网络有多大决定**。SBR 簇越紧（‖W_c*−W_meta‖ 越小），k 可以越小；若簇本身很散，任何少样本方法都只能退化为慢学习。这正是 FABLE 把 CSS 与 SBR 捆在一起的原因。∎

**引理 2（支持覆盖）** greedy k-center 满足 δ_k(S) ≤ 2δ_k*（标准 2-近似）。若候选签名空间具有 doubling 维数 d_sig、簇直径 Δ_c，则 δ_k* ≤ O(Δ_c k^{−1/d_sig})。若簇损失对签名 L_x-Lipschitz，则支持集经验损失与簇分布损失的差 ≤ L_x δ_k。与引理 1 合并，FSA 的总超额风险 ≤ O(L_x δ_k + ‖W_c*−W_meta‖√(d_W log(1/δ)/k))。**CSS 不是启发式采样，而是把「覆盖半径」显式放进误差界**。∎

**定理 1（conformal 有限样本覆盖）** 设校准分数 s_1..s_{n_c} 与测试分数 s_{n_c+1} 可交换，取 q = s_{(⌈(n_c+1)(1−α)⌉)}（索引越界时 q=+∞）。则
`P[s_{n_c+1} ≤ q] ≥ 1−α`。
代入 s = ‖φ*−φ̂‖ 得 `P[φ*∈B(φ̂,r_c)] ≥ 1−α`。有限样本条件：α=0.05 需 n_c≥19；α=0.10 需 n_c≥9。该结论不要求 J_φ 可逆、不要求残差次高斯、不要求 φ 的分布形式，只要求**可交换性**。因此第 62 轮 A72 的「良态反演」从安全关键路径上退役，降级为可选的收紧信号。∎

**定理 2（ACI 长期覆盖）** 设 r_t ∈ [r_min,r_max]，目标误覆盖 α，ACI 更新 α_{t+1}=clip(α_t+γ(α−err_t),α_min,α_max)，r_t 为窗口的 1−α_t 分位数。标准 ACI 分析给出
`(1/T)Σ_{t=1}^T err_t ≤ α + O(1/(γT))`。
即长期平均覆盖 ≥ 1−α−O(1/(γT))；突发漂移后 α_t 自动降低、半径增大，恢复期内更保守。代价是恢复速度与 γ 的权衡：γ 小则稳但慢，γ 大则快但抖动。∎

**定理 3（任意时预算安全性）** 对任意 n_t≥0，定义 m_LB(K)=m(K,φ̂)−L_m r_t。由 L_m-Lipschitz 得对球内所有 φ：
`m(K,φ) ≥ m(K,φ̂) − L_m‖φ−φ̂‖ ≥ m(K,φ̂) − L_m r_t = m_LB(K)`。
因此只要 m_LB(K_safe)≥0，K_safe 在球内全 φ 安全。采样上界 m_UB 只满足 m_UB ≥ min_φ m(K,φ) ≥ m_LB，**减少 n_t 只会让 m_UB 变大（更保守），不会让 m_LB 失效**。安全性由此与候选数、算力抖动、缓存命中率全部解耦。∎

**命题 1（时延上界与 DAB 正确性）** 若 DAB 观测到 T_fix、T_cand、J_max 的上界，并令 n_t=max(0,⌊(D_max−T_fix−J_max)/T_cand⌋)，则
`T_cycle ≤ T_fix + n_t·T_cand + J_max ≤ D_max`。
若 T_fix>D_max，DAB 进入认证降级：跳过采样精化，使用预计算 K_baseline 与其证书；若连派发都无法保证，则安全停止。PFC 命中为 O(1) 查表，未命中回退 W_meta/K_baseline 也是 O(1)，所以缓存不改变最坏时延阶。∎

**命题 2（缓存与切换有界）** 设 PFC 预取 top-b 簇，命中概率 h_t=Σ_{c∈top-b}p_c。则期望时延 E[T]=h_t T_hit+(1−h_t)T_miss；由于 T_miss≤T_hit+c_fallback，且 c_fallback 为常数，缓存不引入 unbounded 延迟。STG 的驻留时间 τ_dwell 给出 N_sw≤T/τ_dwell+O(1)，累计损失 ≤ 静态最优 + O(√T)+C_sw·N_sw；切换抖动被显式计入，而不是假设不存在。∎

**命题 3（证书可审计性）** 若 J_fable 的每个字段都来自可验证的本地记录（支持集 id 可回溯到 Bank、W_ver 可回溯到 FSA 快照、r_CQB 可回溯到校准分数、n_t/latency_UB 可回溯到 DAB 日志、cache/fallback 可回溯到 PFC 日志），则任一执行周期都能回答「用哪 k 个样本、学了什么、球多大、算了几毫秒、用了哪个适配器、是否回退」。审计链不依赖模型自述。∎

**正确性定理（FABLE-Complete）** 假设 A61–A76（继承 ROSE）及：
- **(A77) 校准可交换**：簇内校准 episode 与部署 episode 在 FSA 校准窗口内可交换；漂移由 ACI 检测/补偿。
- **(A78) 支持紧致**：簇最优 W_c* 满足 ‖W_c*−W_meta‖≤ρ_prior；CSS 覆盖半径 δ_k；簇损失对签名 L_x-Lipschitz。
- **(A79) 认证裕度**：m(K,φ) 在球上 L_m-Lipschitz；区间算术/ Lipschitz 认证给出有效下界；存在预认证 K_baseline 在 r≤r_max 下 m_LB≥0。
- **(A80) 时延模型**：T_fix、T_cand、J_max 的上界可观测；DAB 能在 deadline 前完成读数与派发。
- **(A81) 缓存安全**：只有通过 FJC 的适配器可入缓存；W_meta 与 K_baseline 预认证；缓存项带版本与时间戳。
- **(A82) 切换有界**：τ_dwell>0，单次切换代价 ≤C_sw，损失改进估计误差有界。

则：
1. **少样本效率**：FSA 的超额风险 ≤ O(L_xδ_k+ρ_prior√(d_W log(1/δ)/k))；k=5–20 在紧簇上即可用（E211）。
2. **覆盖可证**：CQB 给出 P[φ*∈B]≥1−α（n_c≥n_min(α)），不依赖 J_φ（E212）。
3. **漂移可恢复**：ACI 长期误覆盖 ≤α+O(1/(γT))，`r_t=max(r_CQB,r_RSC)` 保证 RSC 失效时仍有 conformal 下界（E213）。
4. **算不完也安全**：ρ_LB 对任意 n_t 有效；预算只影响保守间隙 ρ_UB−ρ_LB（E214/E215）。
5. **少样本不阻塞实时**：全部 FSA/CSS/CQB/ACI/PFC 在语义流；实时只读缓存 + OLP 前向 + AWC，≤1ms 契约不变（E215/E220）。
6. **切换不抖动**：STG 给出 N_sw≤T/τ_dwell+O(1)，切换代价显式入账（E218）。
7. **可审计**：J_fable 使「样本—参数—半径—预算—缓存」全链路可回放（E220）。

## 7. 已知风险

**一句话**：FSA 的元先验与 CQB 的有限样本覆盖共同依赖「簇内校准与部署可交换」——若新材质/新任务让簇快速漂移，少样本先验会自信地学错、conformal 边际覆盖失效，ACI 只能保长期平均而不能保单步条件安全；此时安全只剩 AWC 在 r_max 下的保守下界兜底，FABLE 会退化为「少样本但不可靠、安全但很保守」，性能可能低于 ROSE 基线。

**次级风险与缓解**：
1. **L_m 过于保守**：解析下界在高维/强非线性接触下会把机器人压得很保守 → 用分片 Lipschitz 与局部区间算术；把 L_m 的在线校准也纳入 ACI 的保守分数。
2. **校准集标签偏差**：φ_i^cal 本身有误差 → 校准分数加标签噪声上界；用成对/差分校准消除系统偏移；E203 式覆盖率审计。
3. **支持集太小/太偏**：k 小且 CSS 只覆盖签名空间，可能漏掉关键物理模式 → 险情加权 + 最小多样性约束 + 把 n_min(α) 作为硬下界；必要时回退 r_max。
4. **缓存腐败/版本不一致**：PFC 缓存了旧 W_c → 版本号 + 证书哈希 + TTL；stale 时膨胀半径；E220 注入腐败缓存。
5. **切换抖动**：STG 的 h_w/h_ℓ 难调 → 驻留时间 + 迟滞 + 切换代价入账；E218 扫描。
6. **DAB 固定开销超预算**：极端算力抖动下 T_fix>D_max → 认证降级到 K_baseline；仍不行则安全停止并请求重规划，绝不带病派发。
7. **元训练分布差距**：仿真任务族与真机差太远 → 元先验只作为正则中心，不冻结；FSA 的 λ_c 随支持集增大自动减小；E211 的 k=50 收敛说明数据最终能覆盖先验。
8. **ACI 的恢复期风险**：漂移刚发生时覆盖率会短暂下降 → 用漂移检测器（CUSUM）提前触发 α_t 下调；恢复期限制高速动作并扩大 Shield 裕度。
