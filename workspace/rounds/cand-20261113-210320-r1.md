# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「隐私保护」×「研究空白」）

> R69 把不确定性一分为二，并给了一个漂亮的答案：可约的歧义就去**问**——看、问、触。但这条答案藏着一个未言明的前提：**「问」能问到的，只能在现有表示之内。** 如果真实模态根本不在策略的假设空间里（传感器从未见过的新故障、从未被标注的新人类意图、从未出现在训练分布里的地形），再多的注视、探针、问句也只会把一个幻影问得更精致。R69 自己也承认了这一点（幻影模态攻击 E300），却把它当成校准问题；其实它是**表示缺口（research gap）**问题——只能靠「研究」补，不能靠「问」补。
>
> 更麻烦的是，R69 的每一次「问」都是一次**数据采集**：注视采集生物特征，探针采集身体反应，问句采集语言与情绪，审计日志采集完整交互。R69 的成本函数只算了物理/社交成本，没算**隐私成本**。于是它越「主动」，就越像一台**以安全为名的监视器**；而它引以为傲的审计可验证性，恰恰建立在保存原始交互日志之上——那是一个**蜜罐**。
>
> 本轮两个灵感正好各补一刀：
> - **研究空白** → 把不确定性补上第三类：**结构缺口（structural gap / unknown unknown）**——不在假设空间内的「不知道自己不知道」。它不可被「问」消解，只能被「研究」（离线探索、新表示、新基准、人因研究）消解；因此需要一张**空白地图**来指导研究预算，而不是继续加交互层。
> - **隐私保护** → 补空白必须收集证据，而证据来自人。用**本地原始、全局脱敏**的计算域分离 + 隐私预算过滤器 + 零知识证据，做到「能审计决策纪律，但看不到人的内容」；隐私不是安全的对立面，而是**证据采集的合法性边界**。
>
> 核心命题：**把不确定性三分——aleatoric（噪声→收紧，R68）、epistemic（表示内歧义→交互，R69）、structural（表示外缺口→隐私保护的研究型探索，R70）。R70 只做第三类，并明确承认：「问」解决不了表示本身的缺口；补空白必须去研究，而研究必须在隐私预算内进行。** 命名 **LACUNA-RAS**（Least-privilege Auditable Confidential Uncertainty & kNowledge-gap Allocation）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我根本不知道我不知道什么——而我要凭什么去知道，才不算监视**」。

## 0. 直觉与动机

**灵感 1（研究空白 → 空白是第三种不确定性，不是校准误差）**
直觉：R69 的 U_epi 是「在假设空间内，几个模态谁对」；而真正的空白是「假设空间里没有正确答案」。前者问一句可能就清楚了；后者问一百句也只是把错误的假设问得更自信。区分标志很清楚：**问完之后，后验是否收缩到一个已有模态**。如果多次交互后模态熵不降反升、回答持续落在所有模态之外、或不同证据源始终无法一致，那说明缺口在表示层，不在证据层。此时正确的动作不是继续问，而是**停下来、标记、带回离线研究**。把「问不出来」当成失败是 R69 的盲点；把它当成**信号**是 R70 的起点。

**灵感 2（隐私保护 → 「问」是采集，审计是蜜罐）**
直觉：每一次信息动作都在采集关于人的数据；每一条为了可审计而保存的原始日志，都在制造泄露面。R69 的证书用 `interaction_log_hash` 想让审计可验证，但低熵日志的哈希可被字典攻击还原，且审计方一旦拿到原始日志就再也收不回来。真正的解法不是「少审计」，而是**换一种证据形态**：把「决策是否遵守证据纪律」做成一个**可验证谓词**，用承诺 + 零知识证明让审计方验证谓词，而不接触内容；把群体统计（ECE、覆盖率）做成 **DP 充分统计量**。这就是「证据不暴露」（evidence-without-exposure，EWE）。

**灵感 3（两者合流 → 补空白本身要花隐私预算）**
直觉：要画空白地图，就得知道「哪些场景被覆盖过」。最直接的办法是收集所有站点的日志——这本身就是大规模监视。隐私保护给出另一条路：**联邦 + DP 的覆盖度草图**——每个站点只上报加噪的计数/草图，聚合后得到覆盖率与置信区间，看不到任何个体样本。于是「研究空白」从「谁数据多谁说了算」变成「**在隐私预算内，大家共同估计哪里还没被看过**」。这与 R69 的证据纪律一脉相承：不能被单一来源单独定案，也不能被单一来源单独定义「哪里是空白」。

**灵感 4（理论姿态 → R70 是 R69 的保守扩展，且承认自身边界）**
直觉：R69 已证明「R68 是永不交互的退化」；R70 要证明「R69 是永不研究、隐私价格为零的退化」。当隐私预算无限、空白先验均匀、无未知空白信号时，LACUNA 逐指令等于 R69。其余情况 LACUNA **只会更保守，不会更激进**：隐私过滤器耗尽 → 不问；空白信号高 → 不问、标记录、收紧。所以安全侧不做任何让步，代价是效率——而这个代价必须被**显式记账**，不能藏进「我们更安全了」的叙事里。这是本轮最重要的自我约束：**不许用隐私换安全，也不许用安全换隐私而不声明兑换率。**

**灵感 5（元层 → 允许「问不出来」是合法结论）**
直觉：一个只会加模块的研究纲领，最终会把「未知」重新命名为「还没加的模块」。R70 允许一个合法结论：**这个缺口在当前表示下补不了，需要换表示/换基准/做人因研究，而不是再加一层网络。** 为此要有「负结果账本」和预注册：先说清楚要填哪个空白、什么结果会证伪当前纲领，再去跑实验。否则「研究空白」会变成「研究借口」——反正哪里都能说成空白，预算永远花得出去。

## 1. 形式化定义（增量：定义 310–323）

**定义 310（LACUNA-RAS 总览）** LACUNA-RAS = (PLP, PVI, LGD, EWE, CGM, UGD, GAA, RGA, NRL, RAS-WM‡)。三不变式：
(i) **隐私预算硬约束**：每个个体累计 RDP 记账 ε_h ≤ ε_max；每次信息动作、每条审计记录都要记账；预算耗尽即停止采集（privacy filter，定义 312）；
(ii) **证据完整性不因脱敏而下降**：安全审计用可验证谓词 + DP 充分统计量替代原始日志（定义 315）；
(iii) **空白优先且可证伪**：研究/实验预算按「风险加权空白 × 不确定性 / 成本」分配，先预注册目标空白与证伪条件，并保留未知空白探索配额（定义 319）。

**定义 311（双向隐私与泄露通道）** 信息动作 g 有两条泄露通道：人→系统（采集身份、情绪、健康、位置）与系统→人/第三方（披露：问句暴露系统正在监视，日志可被链接）。记泄露量 I_leak(g) = I(human; y_g) + I(context; q_g)，在 RDP 下用隐私损失上界记账。**注意：哈希不是隐私**——低熵交互日志的 hash 可被字典攻击还原，故 R69 的 `interaction_log_hash` 不能作为脱敏证据。

**定义 312（隐私账本与过滤器 PLP）** 个体 h 的累计账本 ε_h（RDP，自适应组合）；信息动作 g 的隐私价格 π(g) 由其对 (人类属性, 上下文) 的互信息上界给出。过滤器：仅当 ε_h + π(g) ≤ ε_max 才允许执行。预算耗尽 ⇒ 不采集，退化为 R69（若仍有表示内歧义可解）或 R68。**隐私过滤器与 R69 的交互预算过滤器并联，任一越界即停。**

**定义 313（隐私感知 VoI，P-VoI）** P-VoI(g) = VoI(g) − c_phys/social(g) − λ_p·π(g)。选 g* = argmax_g P-VoI(g)，s.t. 安全认证与预算；若不存在或 max P-VoI ≤ 0 ⇒ 不交互。λ_p 是**显式声明的隐私-效用兑换率**，写入证书；它是一个政策参数，不是模型学出来的。

**定义 314（本地原始/全局脱敏，LGD）** 实时安全决策在设备本地用原始观测完成，**不向控制回路注入 DP 噪声**（否则隐私机制直接变成控制扰动）；只有**聚合统计**与**脱敏证明**离开设备。因此隐私-效用-安全不是同一空间里的三角权衡，而是**计算域分离**：本地保安全，全局保隐私，审计保可验证。

**定义 315（证据不暴露证书 EWE）** 审计记录 = (承诺 c = Com(evidence, salt), 零知识证明 π: 「决策满足 k 源一致 ∧ 交互预算未越界 ∧ 风险阈值正确」, 公开指标 μ)。要求：**完备性**（诚实决策必通过）、**可靠性**（作弊决策以可忽略概率被拒）、**零知识**（不泄露 evidence 内容）。审计方验证谓词，不接触原始交互。salt 高熵且每次会话轮换，防止彩虹表。

**定义 316（空白泛函与覆盖图）** 设场景-威胁空间 𝒵 = 𝒮 × 𝒯 与表示 φ。局部有效覆盖 cov(z) = 有效样本质量 / 所需质量；风险加权空白 G = ∫ max(0, 1 − cov(z)/c_min)·ℓ(z) dP(z)，ℓ 为潜在损失。**空白是表示相关的**：换 φ 就换一张地图；因此任何「空白已填满」的结论都必须附带 φ 版本号。

**定义 317（已知空白 vs 未知空白）** 已知空白：φ 能表达、cov 低 ⇒ 可用交互/实验填。未知空白：φ 表达不了 ⇒ 不可枚举，只能用**代理信号**探测：跨模型分歧 D_disagree、流似然残差（复用 R69 的 a_score）、交互后模态熵不降 ΔH_fail。定义未知空白分 u_gap = σ(α·D_disagree + β·a_score_norm + γ·ΔH_fail)。**u_gap 不是概率，而是「不该再问」的提醒分。**

**定义 318（联邦鲁棒 DP 空白估计，RGA）** 各站点上报 (ε,δ)-DP 覆盖草图；中心用 median-of-means / trimmed mean 抗投毒聚合，得 cov̂ 与置信区间。误差 ~ O(1/√(nε)) + O(β_poison)，β_poison 为被污染站点比例上界。聚合结果再经一次隐私放大后才进入 GAA。

**定义 319（空白感知实验分配 GAA）** 下一轮研究/实验预算按「单位成本可降低的风险加权空白」分配：region* = argmax_z G(z)·ℓ(z)/cost(z)；保留 ρ_explore（如 10%）给**高不确定性的空白**（探索），并设负结果配额。分配前预注册：目标空白、成功判据、证伪条件、隐私预算；预注册哈希进证书。

**定义 320（空白图投毒与对抗上报）** 恶意站点可**夸大覆盖**（藏起真实缺口），或**虚报空白**（浪费预算、诱导危险实验），或用 Sybil/共谋/选择性上报放大影响。它与 R69 的交互投毒不同：攻击对象是**研究注意力的分配**。并入 AIC：ℰ_LACUNA = ℰ_FLUID × ℰ_gap（覆盖伪造 / 空白诱导 / 站点共谋）× ℰ_priv（成员推断 / 属性推断 / 链接攻击）。

**定义 321（隐私-证据-安全三角与分离解）** 朴素三角：加噪 → 统计不准 → 安全误判；少采集 → 证据不足 → 审计失效；多审计 → 日志泄露 → 隐私受损。LACUNA 的解法是三域分离：**实时控制域**（本地原始、不脱敏）、**统计域**（DP 聚合、只出群体量）、**审计域**（ZK 谓词、只出证明）。三角不是被「平衡」，而是被**拆到三个互不干扰的域**；跨域只允许经过类型检查的接口。

**定义 322（证书 J_LACUNA）** J_LACUNA = (J_FLUID, privacy_ledger_hash, ε_spent/ε_max, zk_proof_hash, gap_map_version(φ), coverage_CI, allocation_prereg_hash, unknown_gap_flags)。Valid ⇔ Valid(J_FLUID) ∧ 隐私预算未越界 ∧ ZK 证明通过 ∧ 空白分配与预注册一致。

**定义 323（三类不确定性路由与两级退化边界）** 路由：U_ale → R68 收紧；U_epi 且非空白 → R69 交互（P-VoI>0 且隐私允许）；u_gap 高 / P-VoI≤0 / 隐私耗尽 → 不采集，U_epi 视同 aleatoric，标记空白，进离线研究队列。**R69 是 LACUNA 在 λ_p=0、空白先验均匀、无未知空白信号时的逐指令退化；R68 是再退化为永不交互的边界。**

# IP-264 PLP：隐私账本与过滤器（RDP 自适应组合）
class PrivacyLedger:
    def __init__(self, eps_max):
        self.rdp = defaultdict(float); self.eps_max = eps_max
    def price(self, g):                       # 看/问/触的隐私价格
        return mutual_info_upper(g, channel='collect+disclose')
    def can_spend(self, h, g):
        return self.rdp[h] + self.price(g) <= self.eps_max
    def spend(self, h, g): self.rdp[h] += self.price(g)

# IP-265 PVI：隐私感知交互决策（无利可图/无预算 → 退 R69/R68）
def choose_interaction_priv(modes, w, o, budget, ledger):
    best = None
    for g in info_action_candidates(modes):                  # gaze / probe / ask
        if not budget.allow(g) or not c_ras_wm.certify_info(g, o): continue
        if not ledger.can_spend(o.human_id, g): continue     # 隐私过滤器
        pvoi = (entropy(w) - expected_entropy(w, g, o)) \
               - cost_phys_social(g) - LAMBDA_P * ledger.price(g)
        if best is None or pvoi > best[1]: best = (g, pvoi)
    return best[0] if best and best[1] > 0 else None         # 不采集

# IP-267 EWE：证据不暴露（承诺 + ZK 谓词，审计无需原始日志）
def zk_audit_record(decision):
    ev = decision.evidence
    c  = commit(ev, salt=fresh_salt())                       # 高熵、会话轮换
    pi = prove(Predicate(k_agree=2, budget_ok=True,
                         threshold_ok=True), witness=decision)
    return ZKRecord(commit=c, proof=pi, metrics=decision.public_metrics)

# IP-268/269 CGM+UGD：空白地图（联邦 DP 聚合）+ 未知空白代理信号
def gap_map(sketches, fma_scores, ensembles):
    cov = robust_dp_aggregate(sketches)                      # 抗投毒 + DP
    D   = ensemble_disagreement(ensembles)
    sur = dp_quantile(fma_scores, q=0.95)                    # 复用 R69 流似然
    gap = risk_weighted(1 - cov / C_MIN) + BETA * sur + GAMMA * D
    return gap, coverage_confidence_interval(cov, sketches)

# IP-270 GAA：空白感知预算分配（预注册 + 未知空白探索配额）
def allocate(gap, loss, cost, budget):
    known   = argmax_region(gap * loss / cost)
    explore = sample_region(top_uncertainty(gap))             # 高不确定性空白
    plan = merge(known, explore, reserve=RHO_EXPLORE)
    return preregister(plan, success=..., falsifier=...)      # 哈希进证书

# IP-275 主闭环（继承 R69；仅在「是否采集/是否研究」处插入 LACUNA 层）
def LACUNA_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o_obs, o_calibrated)
    slow  = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    # R70：运行时空白信号（复用 a_hat，不新增网络）
    u_gap = M.ugd.score(z, a_hat, modes, M.fma.history())
    # 表示内歧义才问；且必须过隐私过滤器；空白高/慢故障/无利可图都不问
    ask_ok = (U_epi > TAU_EPI and not slow and u_gap < TAU_GAP)
    g = M.mint.choose_interaction_priv(modes, o, M.budget, M.ledger) if ask_ok else None
    if g is not None:
        answer = M.cia.execute(g); U_epi = M.cia.update_belief(modes, answer)
        M.ledger.spend(o.human_id, g)
    # 空白区：不采集，标记离线研究，按未消解 epistemic 收紧
    if u_gap >= TAU_GAP:
        M.gapmap.flag(o, u_gap)                              # DP 聚合，不存原始
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    if slow or u_gap >= TAU_GAP: lam = max(lam, LAM_GAP)
    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    # 审计只带 ZK 谓词，不带原始交互日志

    return k, lam, mode, (U_ale, U_epi, u_gap)

## 3. 推导

**引理 19（隐私过滤器的单调退避）** 在 RDP 自适应组合下，只要每次采集前通过 `can_spend`，个体累计隐私损失恒 ≤ ε_max；预算耗尽的唯一后果是「不采集」，因此策略从 R69 单调退化为 R68，控制安全不因隐私过滤而降低。系：隐私预算不是安全预算的竞争者，而是**采集动作的否决权**。

**引理 20（P-VoI 的监视上界 / 无未记账监视）** 若 P-VoI(g) ≤ 0，则执行 g 的期望净收益 ≤ 0；其中隐私项 λ_p·π(g) 把每一次采集折算为**必须记账的代价**。因此任何「多问一点更安全」的主张，若其安全增益 < 隐私价格 × 泄露量 + 物理/社交成本，均在期望意义下被支配。**交换率 λ_p 必须写进证书**，禁止把隐私成本藏进「安全收益」里。

**引理 21（EWE 审计的完备性-可靠性-零知识）** 在承诺绑定与 ZK 证明系统可靠性假设下，诚实决策以压倒性概率通过（完备性），违反 k 源一致/预算/阈值的决策以可忽略概率通过（可靠性），且证明不泄露 evidence 的多于谓词信息（零知识）。因此**审计可验证性不需要保存原始交互日志**；R69 的 `interaction_log_hash` 可被 EWE 取代。

**引理 22（鲁棒 DP 空白估计误差界）** 设站点数 n、单站隐私参数 ε、被污染比例 β_poison。median-of-means + DP 聚合的覆盖估计误差满足 |cov̂ − cov| ≤ O(1/√(nε)) + O(β_poison)，置信区间可由草图方差与裁剪比例估计。系：只要 β_poison < 1/2，空白地图不会被少数恶意站点整体翻转；这对应 R69 引理 18 在**研究注意力层**的镜像。

**定理 18（LACUNA 是 R69 的保守扩展）** 在定义 310–323 下，LACUNA 的可行动作集是 R69 可行集的**子集**（新增隐私/空白/证据约束均为合取项），故任意状态点态风险 ≤ R69；当 λ_p=0、空白先验均匀、无未知空白信号且隐私预算充裕时，两者**逐指令相同**。⇒ R68 ⊂ R69 ⊂ LACUNA，安全侧不做让步，效率侧显式付出隐私与研究的代价。

**定理 19（空白单调谨慎 / 未知空白不可被「问」消除）** 在表示 φ 不变时，表示内交互对 u_gap 的期望降低 ≤ 0（交互只更新模态后验，不产生新的表示轴）；若 u_gap ≥ τ_gap，策略的安全集合单调收缩且 λ 单调不降。因此「继续问」不能把未知空白变成已知，盲目增加交互只会增加采集而不减少结构风险。**承认「问不出来」是合法且更安全的结论。**

## 6. 本轮最大风险

**一句话**：LACUNA-RAS 的最大风险是**它用「隐私」和「空白」两个天然正确的词，为「不收集证据」和「不测难场景」提供了完美合法性**——隐私预算耗尽或空白图不可信时，系统可以理直气壮地退回保守，却把「我们没看」包装成「我们审慎」；更致命的是，空白图是**表示相关**的，它能找到的缺口只限于 φ 能表达的轴，而最危险的知识恰恰在 φ 之外——于是框架会把「已知空白已填满」误当成「未知已消除」，用一张漂亮的地图制造**虚假的完备感**。

**次级风险与缓解**：
1. **隐私洗白（privacy-washing）**：以隐私为名削减安全证据 → 三域分离（定义 314/321）+ EWE 完备性（引理 21）+ 证书强制披露 ε_spent；
2. **空白图投毒**：夸大覆盖藏缺口、虚报空白骗预算 → 鲁棒 DP 聚合（定义 318）+ 引理 22 + 站点签名/信誉；
3. **表示外失效**：φ 换掉后地图全错 → 地图强制版本号 φ + u_gap 代理 + E314 压力测试；
4. **研究借口化**：空白变成不干活的理由 → 预注册 + 负结果账本（定义 319）+ E311/E315；
5. **本地安全被 DP 噪声污染** → 严格 LGD（定义 314），控制回路永不注入隐私噪声。

## 2. 形式化定义（要点版）

**定义 310（总览与三不变式）** LACUNA-RAS = (PLP, PVI, LGD, EWE, CGM, UGD, GAA, RGA, NRL, RAS-WM‡)。三不变式：隐私预算硬约束（每个体 RDP ≤ ε_max，耗尽即停采）；证据完整性不因脱敏下降（ZK 谓词 + DP 充分统计量）；空白优先且可证伪（预注册目标空白与证伪条件）。

**定义 311–312（双向隐私与账本）** 泄露 = 采集（人→系统）+ 披露（系统→人/第三方）；RDP 自适应组合记账。**哈希不是隐私**：低熵日志 hash 可被字典攻击，R69 的 `interaction_log_hash` 不可作为脱敏证据。过滤器：ε_h + π(g) ≤ ε_max 才允许采集。

**定义 313（P-VoI）** `P-VoI(g)=VoI−c−λ_pπ(g)`；`g*=argmax P-VoI`；`≤0` 或不安全/超预算 ⇒ 不采集。λ_p 是显式政策兑换率，不是学出来的。

**定义 314（LGD 三域分离）** 实时控制域：本地原始、不注入 DP 噪声（否则隐私机制变成控制扰动）；统计域：DP 聚合、只出群体量；审计域：ZK 谓词、只出证明。跨域接口需类型检查。

**定义 315（EWE）** 审计记录 = (承诺 Com(evidence,salt), ZK 证明「k 源一致 ∧ 预算未越界 ∧ 阈值正确」, 公开指标)。完备性 / 可靠性 / 零知识；salt 高熵且会话轮换。

**定义 316–317（空白泛函与未知空白）** `G=∫max(0,1−cov/c_min)·ℓ dP`；空白与表示 φ 绑定。已知空白可用实验填；未知空白不可枚举，用代理 `u_gap`（跨模型分歧 + R69 流似然残差 + 交互后熵不降）探测。

**定义 318（鲁棒 DP 空白估计）** 站点上报 (ε,δ)-DP 覆盖草图；median-of-means/trimmed 聚合；误差 `O(1/√(nε))+O(β_poison)`，β_poison<1/2 时地图不被少数站点翻转。

**定义 319（GAA）** `region*=argmax G·ℓ/cost`；保留 `ρ_explore` 给高不确定性空白与负结果配额；分配前预注册目标、成功判据、证伪条件、隐私预算。

**定义 320–321（投毒与三角分离）** `ℰ_LACUNA=ℰ_FLUID×ℰ_gap×ℰ_priv`；覆盖伪造/空白诱导/共谋/推断/链接。隐私-证据-安全三角不靠平衡，而靠三域分离拆解。

**定义 322–323（证书与路由）** `J_LACUNA` 并入隐私账本、ε 使用率、ZK、空白图版本/置信区间、预注册哈希。路由：U_ale→收紧；U_epi 且非空白→交互；u_gap 高/隐私耗尽/无利可图→不采集 + 离线研究 + 视同 aleatoric 收紧。

# IP-264 PLP：隐私账本与过滤器
class PrivacyLedger:
    def price(self, g):  return mutual_info_upper(g)          # 采集 + 披露
    def can_spend(self, h, g): return self.rdp[h] + self.price(g) <= self.eps_max
    def spend(self, h, g):     self.rdp[h] += self.price(g)

# IP-265 PVI：隐私感知交互（无利可图/无预算 → R69/R68）
def choose_interaction_priv(modes, w, o, budget, ledger):
    best = None
    for g in info_action_candidates(modes):
        if not budget.allow(g) or not c_ras_wm.certify_info(g, o):      continue
        if not ledger.can_spend(o.human_id, g):                          continue
        pvoi = entropy(w) - expected_entropy(w, g, o) \
               - cost_phys_social(g) - LAMBDA_P * ledger.price(g)
        if best is None or pvoi > best[1]: best = (g, pvoi)
    return best[0] if best and best[1] > 0 else None

# IP-267 EWE：证据不暴露（承诺 + ZK，审计无需原始日志）
def zk_audit_record(decision):

    pi = prove(Predicate(k_agree=2, budget_ok=True, threshold_ok=True),
               witness=decision)
    return ZKRecord(commit=c, proof=pi, metrics=decision.public_metrics)

          + BETA * dp_quantile(fma_scores, .95) \
          + GAMMA * ensemble_disagreement(ensembles)
    return gap, coverage_confidence_interval(cov, sketches)

## 4. 推导

**引理 19（隐私过滤器的单调退避）** RDP 自适应组合下，每次采集前过 `can_spend` ⇒ 个体累计损失 ≤ ε_max；预算耗尽只导致「不采集」，策略单调退化为 R69→R68，控制安全不因隐私过滤降低。

**引理 20（P-VoI 的无未记账监视）** 若 `P-VoI(g) ≤ 0`，执行 g 的期望净收益 ≤ 0；隐私项 `λ_p·π(g)` 使每次采集都必须记账。故「多问更安全」若其增益 < 隐私价格×泄露 + 物理/社交成本，期望意义下被支配。λ_p 必须写入证书。

**引理 21（EWE 完备性-可靠性-零知识）** 承诺绑定 + ZK 可靠性下，诚实决策压倒性通过，违规决策以可忽略概率通过，证明不泄露多于谓词的信息。审计可验证性**不需要原始交互日志**，R69 的 `interaction_log_hash` 可被替代。

**引理 22（鲁棒 DP 空白估计）** `|cov̂−cov| ≤ O(1/√(nε)) + O(β_poison)`；β_poison<1/2 时空白图不被少数恶意站点翻转——R69 引理 18 在研究注意力层的镜像。

**定理 18（LACUNA 是 R69 的保守扩展）** 新增隐私/空白/证据约束均为合取项，故可行动作集 ⊆ R69 可行集，任意状态点态风险 ≤ R69；当 `λ_p=0`、空白先验均匀、无未知空白信号且隐私充裕时逐指令相同。⇒ `R68 ⊂ R69 ⊂ LACUNA`；安全不让步，效率显式付隐私与研究代价。

**定理 19（空白单调谨慎 / 未知空白不可被「问」消除）** φ 不变时，表示内交互对 u_gap 的期望降低 ≤ 0（交互只更新模态后验，不新增表示轴）；`u_gap ≥ τ_gap` 时安全集合单调收缩、λ 单调不降。故「继续问」不能把未知空白变成已知，盲目加交互只增加采集而不减少结构风险——**承认「问不出来」是合法且更安全的结论**。

## 7. 本轮最大风险

**一句话**：LACUNA-RAS 的最大风险是**它用「隐私」和「空白」两个天然正确的词，为「不收集证据」和「不测难场景」提供了完美合法性**——隐私预算耗尽或空白图不可信时，系统可以理直气壮地退回保守，却把「我们没看」包装成「我们审慎」；更致命的是，空白图是**表示相关**的，它能找到的缺口只限于 φ 能表达的轴，而最危险的知识恰恰在 φ 之外——于是框架会把「已知空白已填满」误当成「未知已消除」，用一张漂亮的地图制造**虚假的完备感**。

**次级风险与缓解**：隐私洗白（三域分离 + EWE 完备性 + 强制披露 ε_spent）；空白图投毒（鲁棒 DP 聚合 + 引理 22 + 站点信誉）；表示外失效（地图强制 φ 版本 + u_gap + E314）；研究借口化（预注册 + 负结果账本 + E311/E315）；本地安全被 DP 噪声污染（严格 LGD，控制回路永不注入隐私噪声）。
