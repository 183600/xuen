# 第 70 轮（承接第 69 轮「FLUID-RAS」IP-253~263；本轮灵感：「知识图谱」×「结构优化」）

> R69 的 FLUID-RAS 终于学会了「问」，但它有一个从 R68 继承、从未被检查的默认前提：**证据源之间的独立性是免费的**。引理 18 里的 ρ 是拍的；「k 个正交证据源」是枚举出来的，不是论证出来的。现实中，三个共享电源、共享标定、共享训练数据、共享几何遮挡的传感器，不是三个证人，而是同一份证词被复述了三遍；它们的误差在共模故障面前高度相关，`δ_p·ρ^{k−1}` 的指数级下降根本不会发生。R69 还会追问「幻影模态」——一个在数据里不存在、也无法被任何观测区分开的假设，会因为流模型的采样噪声被当成真问题。更根本的是：R69 只知道「有哪些源」，不知道「源为什么像」。
>
> 本轮两个灵感正好各补一刀：
> - **知识图谱**：把「证据、来源、失效模式、任务实体、标定/数据谱系」放进一张带类型的来源图。独立性不再是残差相关系数，而是图上的 **d-分离**；歧义不再是标量熵，而是 **多种一致的图完成**；提问不再是自由文本，而是 **指向一条待定边或实体**。
> - **结构优化**：消歧不再是「选熵减最大的动作」，而是 **最小成本的可识别性设计**——选最少的边测试，使竞争假设两两可区分；安全证书则升级为 **论证图**，用极小割集决定哪里必须有冗余、哪些信息增益绝对不能拿来换。
>
> 核心命题：**把「独立性」从统计假设升级为图上可证明的分离，把「消歧」升级为最小结构干预，把「安全」升级为不可交易的最小割。** 命名 **STRATA-RAS**（STRuctural evidence grAph for Trustworthy Adaptation in Risk-Adaptive Systems）：证据像地层（strata），两个读数若共享同一层来源，就只是同一层在重复说话。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我凭什么相信这些答案彼此独立、又凭什么认为这个问题可被回答**」——证词的价值不在它说了什么，而在它的来源是否与信念本身同源。

## 0. 直觉与动机

**灵感 1（知识图谱 → 独立性不是相关系数，而是图上的分离性）**
直觉：法庭上两个证人的证词之所以比一个强，是因为他们的信息来源彼此独立；若两人全程手拉手、看同一块屏幕，第二份证词只是复读。R69 用残差相关 ρ 来近似这种独立性，但 ρ 需要「共同失效」的样本才能估，而共模故障恰恰稀少、且总在没见过的组合里发生。知识图谱把「为什么相关」显式写出来：共享电源、共享标定谱系、共享训练数据、同一个人、同一段遮挡几何。于是独立性变成一个**结构问题**：从证据到根因的所有后门路径是否被阻断（d-分离）。这允许在故障发生**之前**就给出保守下界，而不是等出过事再估相关。

**灵感 2（知识图谱 → 歧义不是熵，而是多种一致的图完成）**
直觉：R69 把歧义压成一个标量 `H_mode`，但真正让系统犹豫的是「当前观测允许好几种互不相容的世界模型」。知识图谱天然表达这一点：固定已观测事实后，未定实体/关系仍有多种一致补全（graph completions），歧义 = 这些补全的后验分布。更关键的是，每个补全都对应一组**待定边**；「问一句」本质上是在问某一根边。于是问题可以被精确地指向缺口，而不是让语言模型自由发挥——这正面回应 R69 的最大风险：**一个没有任何可测试边的「幻影模态」，在图上根本没有提问的落点**。

**灵感 3（结构优化 → 消歧是最小成本的可识别性设计，不是贪婪熵减）**
直觉：R69 的 MINT 选 `argmax[VoI−成本]`，但 VoI 是一个标量代理，可能选出一个「看起来信息量很大、却区分不了真正竞争假设」的动作。正确的目标不是最大化熵减，而是**可识别性**：选一组测试，使候选假设两两可区分（每一对都被至少一个测试切开）。这是经典的最优实验设计 / 最小测试覆盖问题：NP-hard，但目标函数是单调子模的，贪心可得 `(1−1/e)` 近似。结构优化把「问什么」从启发式变成一个带可证明近似的组合优化。

**灵感 4（结构优化 → 安全证书是论证图，极小割集是不可交易的红线）**
直觉：R69 的 J_FLUID 是一个扁平合取，任何一项为真就通过，看不出各项之间的依赖。真实安全论证是有结构的：顶层「安全」由若干子声明支撑，子声明由证据支撑。把它画成论证图后，**极小割集**（minimal cut set）就是「最少断掉哪几根证据就会推翻整个证书」。这给出两个直接用途：安全关键路径要保留**冗余**（割集越大越稳），认知测试则追求**结构独立**（用最少的新证据切开歧义）。两者天然冲突，因此必须规定字典序：**安全割集是硬约束，信息增益是目标函数**——绝不拿安全冗余去换分辨率。

**灵感 5（知识图谱的对抗面 → 「独立性的证明」本身可以被伪造）**
直觉：一旦系统依赖来源图来判断独立，图就成了新的单点故障。对手可以注入一条「这两源独立」的假边、隐藏共享标定谱系、制造一个诱人的假实体把机器人引去追问、或回放过期 provenance 让旧证书继续生效。**R69 的风险是「问错」；R70 的风险升级为「被一份伪造的独立性证明说服」**——这比诚实的不知道更危险。所以本轮必须同时交付：边级 provenance 认证、信任下界、独立性证书的失效与重算、以及「图不可信就退回 R69」的严格退化。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（STRATA-RAS 总览）** STRATA-RAS = (PKG, AGA, SID, SOPT, SAG, GAT, CGR, RAS-WM§)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i、R69 定义 293-i）；
(ii) **结构证据纪律**：任何「独立证据」声明必须附带基于可信 provenance 的 d-分离证书，否则该对源的相关系数按保守先验 ρ_0 计；
(iii) **可识别性纪律**：只有能把决策相关的竞争假设两两切开的测试集才允许执行；无法可识别则退回 R69 的保守退避（定义 324）；
(iv) **安全论证单调性**：任何任务/信息动作不得使安全论证图的最小割集低于 μ_min（定义 319、定理 19）。

**定义 311（来源知识图谱 PKG）** PKG = (V, E, τ, π, c, ttl)，其中：
- V = V_ent ∪ V_src ∪ V_hyp ∪ V_ctx ∪ V_fail：任务实体、证据源、假设/模态、上下文（站位、时间窗）、失效模式；
- E 为带类型边：`supports` / `contradicts` / `causes` / `lineage`（数据、标定、模型、固件共用）/ `aliases` / `observes` / `tests` / `co_located` / `same_informant`；
- τ(e) 为边类型；π(e) = (signer, mechanism, timestamp, evidence_hash) 为 provenance；c(e) ∈ [0,1] 为边信任；ttl(e) 为新鲜度期限。

**定义 312（证据的谱系与地层）** 对证据源 i，其谱系 Anc(i) 是 PKG 上沿 `lineage` / `causes` 反向可达的节点集。定义地层
`L = {power, firmware, calibration, data, geometry, human, model}`。
若存在非目标节点 a ∈ Anc(i) ∩ Anc(j)，则称 i、j **同层**；同层意味着它们的误差可能共享同一个根因。R69 的「源集合」是一个扁平列表；STRATA 的源集合是一个带祖先关系的偏序。

**定义 313（歧义 = 多种图完成）** 给定证据 y 与目标假设集 ℳ，候选完成
`Ω(y) = { ω : ω 是 PKG 在未定实体/关系上的补全，且 ω ⊨ y ∧ 约束 }`。
歧义大小 `U_struct = H(Ω(y))`；歧义前沿
`∂Ω(y) = { 边/变量 x : 其取值在 Ω(y) 中不唯一，且改变它会改变 Ω(y) }`。
信息动作只能作用于 ∂Ω：`g ∈ 𝒜_info(y) ⇒ target(g) ∈ ∂Ω(y)`。

**定义 314（结构独立性证书）** 令 G_err 为「误差图」：节点是各源误差项 e_i、目标假设 M、以及共享失效根因；边表示影响。**先对 M 条件化以阻断信号路径**（两源都观测 M 是好事，不是共模），剩余未阻断路径才是误差相关。若在 G_err 中
`e_i ⫫ e_j | {M} ∪ Z`
且证明只使用信任 `c ≥ τ_trust`、未过期（`age ≤ ttl`）的边，则签发证书 `C_ij = (Z, cut, hash, ttl)`，并置 `ρ̂_ij = ε_ind`；否则置 `ρ̂_ij = ρ_0`（保守先验，由 I-ECE 校准）。证书是**派生声明**，不可无限缓存。

**定义 315（结构有效样本量）** 对源组 G，
`ρ̄(G) = max_{i<j} ρ̂_ij`（取最大而非平均，保守），
`n_eff(G) = |G| / (1 + (|G|−1)·ρ̄(G))`。
ρ̄=0 ⇒ n_eff=|G|；ρ̄=1 ⇒ n_eff=1（完全复读）。若 `n_eff < n_min`，该组不得作为独立证据支撑消歧，U_epi 维持未消解。

**定义 316（结构信息增益 GAIN）** 测试 g 的结构 VoI
`VoI_s(g) = H(Ω|y) − E_{o_g~p(·|g,y)}[H(Ω|y,o_g)]`，
并按测试与信念的谱系重叠折价：
`GAIN(g) = VoI_s(g)·(1 − ρ̂(g, Ω)) − c(g)`。
`ρ̂(g,Ω)` 衡量测试结果与当前信念共享多少来源；共享来源的测试给出的「确认」不算独立确认。

**定义 317（结构最优测试规划 SOPT）** 测试目录 𝒯，每个 t 有成本 c(t)、安全认证 `cert(t)`、以及可区分假设对 `Pairs(t) ⊆ P`（P 为决策相关的竞争假设对）。求解
`min Σ_{t∈I} c(t)  s.t.  ∀p∈P, I ∩ 𝒯_p ≠ ∅,  ∀t∈I: cert(t) ∧ SAG_preserve(t)`。
即最小权重测试覆盖（minimum test cover）。若在预算/安全约束内不存在覆盖，返回空集——**不交互**，而不是降级为部分信息就下结论。

**定义 318（幻影守卫 PG）** 假设 M 称为**可测试**，若存在预算内测试 t 与竞争者 M′，使 `p(y_t|M) ≠ p(y_t|M′)`。令 `Ω_test` 为可测试等价类的集合；不可测试的假设按**行为等价类**合并，风险取类内最坏成员。只有 `Ω_test` 参与交互决策。系：不可测试假设的 VoI 恒为 0，为其花费预算严格劣于不花费。

**定义 319（安全论证图 SAG 与极小割集）** SAG = (C, E, R)：声明节点、证据节点、推理规则。根声明为「执行安全」。有效性要求所有叶证据成立且无 defeaters。令 `μ(A)` 为从根到「不安全」的最小割集大小（或最小证据失效数）。结构优化在安全关键子图上**最大化** μ（冗余），并施加硬约束 `μ ≥ μ_min`；任务/信息动作不得降低 μ 到 μ_min 以下。

**定义 320（图认证 GAT）** 每条边携带可验证 provenance；图的可用性要求用到路径上的最小边信任 `≥ τ_trust`、无过期边、且谱系完整（A99）。「独立」不是图中一个可手填的属性，而是每次由 d-分离重新推导的证书；证书带签名与哈希，任何上游节点（标定、模型、数据）变更即失效。

**定义 321（图谱接地交互）** 问句/注视/探针的目标由 `∂Ω` 生成：先把待定边映射到已有实体/关系，再解码为语言。若目标实体在图上前提下不存在（仅有幻觉节点），PG 拦截，不生成问题。回答先做图一致性检查（与已有 supports/contradicts 边是否冲突），冲突则记为 defeater 而非证据。

**定义 322（STRATA 干扰集 ℰ_STRATA）** `ℰ_STRATA = ℰ_FLUID × ℰ_graph`，其中 ℰ_graph = {独立性伪造（假 d-分离）、别名注入（把同一源伪装成两源）、谱系隐藏（删共享标定/电源边）、诱饵实体（诱导追问）、完成幻觉（模型幻觉出不存在的图补全）、过期 provenance 回放}。

**定义 323（证书 J_STRATA）**
`J_STRATA = (J_FLUID, dsep_cert_hash, n_eff_min, I_ECE, completion_entropy, sopt_gain, sag_mincut, graph_trust_min, strata_ver)`。
Valid ⇔ Valid(J_FLUID) ∧ 所有被采信的证据对带有效 d-分离证书 ∧ `n_eff ≥ n_min` ∧ `I_ECE ≤ τ_ice` ∧ `μ(A) ≥ μ_min` ∧ 图与证书未过期。

**定义 324（三级严格退化）**
- 图不可用 / 不可信 / `I_ECE > τ_ice` ⇒ 退回 **FLUID**（ρ̂ = ρ_0，关闭 SOPT）；
- 图可用但预算内无可识别测试覆盖，或 PG 使 Ω_test 为空 ⇒ **不交互**，退回 FLUID 保守分支；
- FLUID 在 `VoI ≤ 成本` 时逐指令退回 **R68**。
因此 `STRATA ⊇ FLUID ⊇ CALM` 是行为集合的严格包含，安全侧不做任何让步。

**定义 325（实时子图检索 CGR）** 在线只检索目标周围的局部子图（半径 r）并查预计算的 d-分离表；全图维护与证书重算离线完成。局部子图规模上界保证 P99 预算（定义 308 的预算约束继续生效）。

**定义 326（谱系失效与图维护）** 标定更新、模型换版、数据集追加、站位拓扑变化都会使其下游 d-分离证书失效（谱系失效传播）。在线只读，离线做图手术（加/删/改边），每次手术记录 diff 与回滚点；回放旧证书需重新验证 ttl 与上游哈希。

```python
# IP-264 PKG：来源知识图谱（离线构建/维护，在线只读局部子图）
class ProvenanceKG:
    def local(self, query, r=2):                 # CGR：局部检索
        return self.cache.subgraph(query, radius=r)

    def d_separation_certificate(self, i, j, given):
        # 在误差图上条件化 given（通常含目标 M），检验 e_i ⫫ e_j | given
        if not self.edges_trusted(i, j) or self.stale(i, j):
            return None
        sep = self.error_dag.d_separator(source=i, target=j, given=given)
        return sep if sep else None              # 证书：分离集 + 哈希 + ttl

# IP-266 SID：结构有效样本量（证书失败即保守先验）
def effective_n(kg, sources, target, rho0=RHO_0, eps=1e-3):
    rhos = []
    for i, j in combinations(sources, 2):
        cert = kg.d_separation_certificate(i, j, given={target})
        rhos.append(eps if cert else rho0)
    rbar = max(rhos) if rhos else 0.0
    return len(sources) / (1 + (len(sources)-1) * rbar)

# IP-265/268 AGA + SOPT：歧义前沿 + 最小测试覆盖（子模贪心）
def plan_tests(kg, omega, budget):
    pairs = decision_relevant_pairs(omega)
    tests = {t: kg.pairs_separated(t, pairs)         # 每个测试能切开哪些假设对
             for t in kg.tests_on_frontier(omega)}
    chosen, covered = [], set()
    while budget.left > 0:
        best, best_ratio = None, 0.0
        for t, covers in tests.items():
            if t in chosen: continue
            if not budget.allow(t) or not c_ras_wm.certify_info(t): continue
            if not sag.preserves_mincut(t): continue
            gain = len(covers - covered)
            ratio = gain / max(cost(t), EPS_COST)
            if ratio > best_ratio: best, best_ratio = t, ratio
        if best is None or best_ratio <= 0: break
        chosen.append(best); covered |= tests[best]; budget.spend(best)
    return chosen if covered == set(pairs) else []   # 不可识别 → 不交互

# IP-269 PG + IP-275 主闭环：图可信才走结构路径，否则逐指令退回 FLUID
def STRATA_round(M, obs):
    if not M.kg.available() or not M.kg.trusted() or M.iec.ece() > TAU_ICE:
        return FLUID_RAS_round(M, obs)               # 严格退化到 R69

    z, o = M.mtm.forward(...)
    c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)

    # 1) 歧义 = 图完成；幻影守卫只保留可测试假设
    omega, U_struct = M.pkg.completions(o, modes)
    omega_test = M.pg.testable_classes(omega, M.tests, M.budget)   # 行为等价合并
    if not omega_test:
        U_epi = U_epi                                # 无可测试歧义 → 不交互
        plan = []
    else:
        # 2) 独立性先算，不够就不允许用共识消歧
        n_eff = M.sid.effective_n(M.evidence_sources, target=omega_test)
        # 3) 最优测试规划（安全割集是硬约束）
        plan = M.sopt.plan(omega_test, M.budget) if n_eff >= N_MIN else []

    # 4) 执行可识别测试；否则退回 R69 保守分支
    if plan and (U_epi > TAU_EPI) and not M.fma.slow_fault_suspect(...):
        answers = [M.cia.execute(t) for t in plan]
        U_epi_after = M.cia.update_completions(omega_test, answers)
        # 只有证书齐全才给 resolution bonus
        resolved = all(M.sid.certified(t.source) for t in plan)
        U_floor = U_ale if resolved else U_ale + U_epi_after
    else:
        U_epi_after, U_floor = U_epi, U_ale + U_epi

    # 5) 安全论证单调性检查 + 风险缩放
    if not M.sag.preserves_mincut(plan): U_floor += U_epi_after; plan = []
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    mode = select_mode(modes, U_epi_after, lam)
    M.vqa_i.submit_async(plan, U_epi, U_epi_after, M.iec)
    return k, lam, mode, (U_ale, U_epi_after, n_eff if omega_test else 0.0)
```

## 3. 推导

假设：A99（provenance 完备：所有影响证据的共模路径都在图中）、A100（误差图因果充分，无未建模隐混因）、A101（测试目录对前沿完备）、A102（图与证书在 ttl 内新鲜）。

**引理 19（结构独立性的可靠性）** 在 A99–A100 下，若 G_err 中 `e_i ⫫ e_j | {M} ∪ Z` 可被 d-分离证明，则两源误差条件独立，R69 的经验 ρ_ij ≤ ε_ind；若存在未阻断的共同祖先路径，则证书不得签发，ρ̂_ij 取保守先验 ρ_0。故结构证书**不会在 A99–A100 下产生假独立**，但可能漏签（保守）。要点：条件化在 M 上恰好阻断「都观测到目标」这条信号路径，剩下的才是共模误差；这是把「相关」与「独立」分开的关键。

**引理 20（幻影守卫）** 若 M 与 M′ 在预算内所有测试下似然比恒为 1，则任何测试的后验更新为零、VoI=0；为其花费预算严格劣于不花费。将二者并入行为等价类并以类内最坏风险做安全约束，安全不降，且 R69 的「追问幻影」失效。系：**可回答性是交互的前提，不是交互的结果**；但若真实存在能区分二者的测试而未被列入 𝒯，PG 会错误合并（A101 失效），这是可检测的漏报而非误报。

**引理 21（SOPT 的近似与难度）** 覆盖函数 `f(I)=` 被切开假设对的权重和是单调子模的；基数预算下贪心达 `(1−1/e)`，背包预算下达 `(1−1/e)/2`。最小测试覆盖是集合覆盖的归约，NP-hard；因此只在 `|Ω|≤8, |𝒯|≤12` 时做分支定界精确解，否则用贪心并保守早退。系：**「能否在预算内可识别」本身就是一个覆盖可行性问题**，不能假装总能问出答案。

**引理 22（伪造独立性需要切断一个割）** 要让真实相关的两源在图上显得 d-分离，对手必须删除/阻断它们之间每一条未阻断的共同原因路径，即修改一个节点/边割，或伪造沿途 attestation。设最小割为 κ_ij、单边篡改被检出概率为 p_d，则伪造被接受的概率 `≤ (1−p_d)^{κ_ij} + ε_sig`。故结构分离越深，伪造代价越高。**但若对手控制了图构建器或信任根，κ 失效，代价归零**——这正是本轮最大风险的来源。

**定理 18（三级严格包含）** 在 A99–A102 下，STRATA 允许的任一执行要么与 FLUID 逐指令相同（图不可用/不可信/I-ECE 越界/无可识别覆盖），要么其消歧证据带有结构独立证书且 `μ(A) ≥ μ_min`。前者的风险等于 FLUID；后者的 resolution bonus（`λ_floor(U_ale)`）只在证书可靠时发放，而 FLUID 依赖未经证明的经验 ρ，故 STRATA 的最坏风险不高于 FLUID；FLUID 在无交互时逐指令等于 R68。安全侧严格包含，效率优势是经验的、非保证的。

**定理 19（安全论证单调性）** SAG 的最小割集对动作保持单调：任一被 STRATA 接受的动作都不使 `μ(A)` 降到 μ_min 以下；J_STRATA 通过投影蕴含 J_FLUID。因此结构优化不能拿安全冗余换信息增益。字典序成立：**先满足安全可行域，再最大化认知收益**。系：若某次追问虽能切开歧义却会削弱安全关键路径的冗余，正确行为是保留歧义、接受 R68 的保守 λ，而不是「问个明白」。

**推论 2（独立性的无免费午餐）** 结构优化只能**剔除假独立**、并**发现**已存在的真独立，不能凭空创造独立证据。若预算内不存在结构独立的可识别测试，STRATA 必须停在 FLUID/R68 的保守侧；任何声称「优化出独立性」的机制都在偷换假设。

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** 零学习写操作继承；结构证据纪律（独立声明必须附 d-分离证书，否则 ρ=ρ_0）；可识别性纪律（只有能两两切开决策相关假设的测试集才执行）；安全论证单调性（动作不得使 μ(A) 低于 μ_min）。

**定义 311–312（PKG 与地层）** 图含实体/源/假设/上下文/失效节点；边类型 supports/contradicts/causes/lineage/aliases/observes/tests/co_located/same_informant；边带 π、信任 c、TTL。共享 `lineage` 祖先即同层，同层误差可能共模。

**定义 313（歧义=图完成）** `Ω(y)` 为与证据一致的所有图补全；`U_struct=H(Ω)`；`∂Ω` 为取值不唯一且改变补全的边/变量；信息动作目标必须在 ∂Ω 上。

**定义 314–315（结构独立性与 n_eff）** 在误差图 G_err 上**先条件化目标 M** 以阻断信号路径，再检验 `e_i ⫫ e_j | {M}∪Z`。证书只用可信、未过期边；成功则 ρ̂=ε_ind，否则 ρ̂=ρ_0。`n_eff=|G|/(1+(|G|−1)max ρ̂)`；`n_eff<n_min` 不得用共识消歧。

**定义 316–317（GAIN 与 SOPT）** `GAIN = VoI_s·(1−ρ̂(g,Ω))−c`；SOPT 求最小权重测试覆盖 `min Σc s.t. ∀p, I∩𝒯_p≠∅`，且每个测试过安全认证、保 μ(A)；预算内无覆盖则空集。

**定义 318（幻影守卫）** 可测试 = 存在预算内测试使 `p(y|M)≠p(y|M′)`；否则按行为等价合并、风险取最坏；不可测试假设 VoI=0，不得追问。

**定义 319（SAG 与最小割）** 安全论证图根声明「执行安全」；`μ(A)` 为从根到不安全的最小割；安全关键子图最大化 μ，硬约束 `μ≥μ_min`，交互不得降低。

**定义 320–321（GAT 与图接地）** 边携带可验证 provenance；「独立」是每次重新推导的派生证书，带签名/TTL，上游变更即失效。问句/注视/探针由 ∂Ω 映射到已有实体；幻觉实体被 PG 拦截；回答先做图一致性检查。

**定义 322–323（干扰与证书）** `ℰ_STRATA=ℰ_FLUID×ℰ_graph`（独立性伪造/别名注入/谱系隐藏/诱饵实体/完成幻觉/过期回放）；`J_STRATA=(J_FLUID, dsep_cert_hash, n_eff_min, I_ECE, completion_entropy, sopt_gain, sag_mincut, graph_trust_min, strata_ver)`。

**定义 324（三级退化）** 图不可用/不可信/I-ECE 越界 ⇒ FLUID（ρ=ρ_0）；图可用但无可识别覆盖或 Ω_test 空 ⇒ 不交互、走 FLUID 保守分支；FLUID 无利可图 ⇒ R68。严格包含 `STRATA ⊇ FLUID ⊇ CALM`。

**定义 325–326（CGR 与谱系失效）** 在线只查局部子图与预计算 d-分离表；全图手术、证书重算离线。标定/模型/数据/拓扑变更使下游证书失效，过期证书不得采信。

```python
        if not self.trusted(i, j) or self.stale(i, j): return None

def effective_n(kg, sources, target, rho0=RHO_0, eps=1e-3):
    rhos = [eps if kg.certificate(i, j, {target}) else rho0
            for i, j in combinations(sources, 2)]
    rbar = max(rhos) if rhos else 0.0
    return len(sources) / (1 + (len(sources)-1) * rbar)        # n_eff

    else:
        U_epi_after, U_floor = U_epi, U_ale + U_epi
    if not M.sag.preserves_mincut(plan):
        plan, U_floor = [], U_ale + U_epi_after             # 安全割集优先
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    mode = select_mode(modes, U_epi_after, lam)
    M.vqa_i.submit_async(plan, U_epi, U_epi_after, M.iec, gain)
    return k, lam, mode, (U_ale, U_epi_after, n_eff)
```

## 4. 推导

假设 A99（provenance 完备）、A100（误差图因果充分）、A101（测试目录对前沿完备）、A102（图与证书在 TTL 内新鲜）。

**引理 19（结构独立性可靠性）** A99–A100 下，`e_i ⫫ e_j | {M}∪Z` 的 d-分离证明 ⇒ 两源误差条件独立、经验 ρ≤ε_ind；存在未阻断共同祖先 ⇒ 不得签发证书、ρ̂=ρ_0。条件化 M 恰好阻断「都观测目标」的信号路径，只剩共模误差。结构证书不会假独立，但可能漏签。

**引理 20（幻影守卫）** 预算内所有测试似然比恒为 1 的假设对 ⇒ 后验永不更新、VoI=0；花预算严格劣于不花。按行为等价类合并、风险取最坏成员，安全不降，且消除 R69 的「追问幻影」。若真实区分测试未被列入 𝒯（A101 失效），会误合并——可检测的漏报。

**引理 21（SOPT 近似与难度）** 覆盖函数单调子模；基数预算贪心 `(1−1/e)`，背包预算 `(1−1/e)/2`；最小测试覆盖 NP-hard（集合覆盖归约）。小图分支定界精确，大图贪心保守早退。「能否可识别」本身是覆盖可行性问题。

**引理 22（伪造独立性需切断一个割）** 伪造真实相关源的 d-分离，必须修改其所有未阻断共同原因路径 = 修改一个节点/边割。最小割 κ_ij、单边篡改检出率 p_d 时，假证书接受率 `≤ (1−p_d)^{κ_ij}+ε_sig`。结构分离越深，伪造越贵；但控制图构建器或信任根时 κ 失效。

**定理 18（三级严格包含）** A99–A102 下，STRATA 的每个执行要么与 FLUID 逐指令相同（图不可信/I-ECE 越界/无可识别覆盖），要么其消歧证据具结构独立证书且 `μ(A)≥μ_min`。前者风险=FLUID；后者的 resolution bonus 仅在证书可靠时发放，而 FLUID 依赖未证明的经验 ρ ⇒ STRATA 最坏风险不高于 FLUID；FLUID 无交互时逐指令等于 R68。安全严格包含，效率优势是经验的。

**定理 19（安全论证单调性）** SAG 最小割对动作单调；被接受的动作不使 `μ(A)<μ_min`；J_STRATA 投影蕴含 J_FLUID。故结构优化不能拿安全冗余换信息增益；字典序为「先安全可行域，再认知收益」。系：若追问会削弱安全关键路径冗余，正确行为是保留歧义、接受 R68 保守 λ。

**推论 2（独立性的无免费午餐）** 结构优化只能剔除假独立、发现已存在的真独立，不能凭空创造独立证据；预算内无结构独立测试时必须停在 FLUID/R68 保守侧。

## 7. 本轮最大风险

**一句话**：STRATA-RAS 把安全性押在「来源图完备且可信」这一前提上——而 d-分离证书是一种**无需数据即可签发的确定性证明**：一旦图漏掉一条共享谱系、被注入假独立边、或信任根被攻破，系统就会拿到一张「独立性已证明」的证书，在没有任何共模故障样本能及时反驳它的情况下，把一份复读当成两个独立证人；**被证明的假独立，比被承认的相关更危险，因为它连保守的余地都不留**。

**次级风险与缓解**：1) 图不完备/隐混因（A99–A100 失效）→ 显式 latent 节点 + 保守 ρ_0 + I-ECE 校准；2) 图投毒/谱系伪造 → GAT 边级认证 + 引理 22 的割代价 + ℰ_graph 对抗训练；3) 幻影守卫误合并真可区分假设（A101 失效）→ 测试目录审计 + 漏报监控 + 保守风险取最坏；4) 图查询击穿实时预算 → CGR 局部子图 + 预计算 d-分离表 + 离线图手术；5) 安全冗余被信息增益侵蚀 → SAG 最小割硬约束 + 定理 19 字典序。
