# 第 10 轮（新灵感循环第 1 轮；本轮灵感：「实时控制」×「隐私保护」）

> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**隐私只作用于外发通道 + 隐私预算与实时预算同构调度**。两个灵感治理 v9 的两笔债：外泄债（DA-ML/OTL/跨机契约表与块证书都在"默认可共享"下运行，语音/标定/梯度没有隐私边界）、时效债（隐私机制若简单加在 50Hz 闭环上，加密/加噪/记账会吃掉 20ms 决策预算）。必须保证：隐私机制只改变"向外发布什么"，永不改变本地安全闭环的输入；任一隐私组件失效 ⇒ 停止外发（fail-closed），严格等价于 v9 的"不共享"模式。

## 0. 直觉与动机

**灵感 1（实时控制 → 隐私预算也是一种可调度资源）**
直觉：v9 的实时控制把所有成本看成"时间"——WCET、截止期、EDF。但隐私不是免费的：一次发布消耗 ε，一次梯度外传消耗 ε，且隐私预算像电池一样有容量和补充速率。真正的问题不是"隐私算法够不够快"，而是"在 20ms 的时间预算之外，我们还没有第二个预算约束，于是隐私只能事后打补丁"。核心创新：**双资源契约（Bi-resource Contract, BRC）**：把 v9 的契约 κ_m 从 (In,Out,D_m,Ŵ_m,v_m^⊥,π_m,φ^elig) 扩展为 (…, ε_m, δ_m, u_m^⊥)，调度可行性变成时间与隐私的双约束：ΣŴ ≤ B_dec 且 Σε ≤ τ(t)（隐私令牌桶）。实时松弛度与发布新鲜度之间由此出现真正的兑换关系。

**灵感 2（隐私保护 → 外发通道的本地差分隐私）**
直觉：MetricVoiceGauge 最敏感的不是内部控制量，而是它**往外说的东西**：语音音色/情绪、标定参数、域适应梯度、跨机共享的契约表与块证书（E568/E569 已经把后门打开）。核心创新：**本地差分隐私语音量规（LDP Voice Gauge, LVG）+ 私密在线学习（POL）**：原始音频与原始样本永不离开设备，外发的只有带噪的韵律充分统计量与裁剪加噪梯度；用 w-event DP 做流式记账，使隐私保证与运行时长解耦。关键安全设计：**隐私噪声只进入外发通道，绝不进入 M₀/SpatialCert/FaultCert/AC 守卫**——安全仍然只读本地原始数据。

**两灵感交汇 = 分块对齐的隐私发布（Chunk-Aligned Release, CAR）**
v9 的动作分块恰好提供了天然的隐私组合边界：一次块边界 = 一个发布纪元。把 50Hz 逐周期外发降为 5Hz 块对齐发布，查询次数降一个量级；再用隐私令牌桶在窗口内分配预算、用批处理换取 ε 节约、用发布步幅 L_rel 控制新鲜度。于是"实时控制的结构（分块）"直接变成"隐私保护的会计结构（窗口）"，两个灵感不是拼接，而是共用同一套时间骨架。

## 1. 研究问题（轮次升级版）

- **Q1（安全-隐私分离）**：在什么架构不变量下，可以证明任意 DP 机制与任意 ε 都不改变 v9 的安全保证？如何形式化"安全谓词只读本地、永不读外发"？
- **Q2（双资源可调度性）**：时间预算与 w-event 隐私预算的联合可行域是什么？在令牌桶 + 块对齐发布下，何种策略在满足 ε 窗口约束的同时最小化发布陈旧度？
- **Q3（效用-隐私-实时三角）**：LVG 的韵律统计与 POL 的梯度在多大 ε 下仍能支撑情绪/域适应效用？批处理与子采样带来的隐私节约能否补偿新鲜度损失？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 安全-隐私分离律（Safety-Privacy Separation）**
所有硬安全判定（M₀、SpatialCert、FaultCert、AC 中块守卫、停车不变式）的输入限于本地未发布数据；隐私机制（加噪、裁剪、聚合、加密）只作用于外发通道 R。形式化：安全判定函数 f_safe 的定义域与 R 的输出 σ-代数独立。于是 DP 噪声不会"污染"安全证明，ε 可以独立调节。

**P14 隐私失效即本地封闭律（Fail-Closed Release）**
隐私组件不可用（记账器异常、令牌桶欠费、机制超时、审计失败）⇒ 注入发布中立元 u^⊥ = "不发布"，而不是发布未加噪数据或伪造数据。本地闭环继续用原始本地数据运行，行为等价 v9 的非共享模式。任何隐私故障只会减少信息外泄，绝不增加。

**P15 分块对齐预算律（Chunk-Aligned Budgeting）**
隐私发布以 v9 的块边界（5Hz）为纪元，发布步幅 L_rel ≥ 1；w-event 隐私窗口 w 与发布纪元对齐。时间与隐私两个预算在每个纪元内联合结算；硬安全计算在双预算中的优先级为 ∞（不可被隐私调度挤占）。

## 3. 与基线的接口（如何退化）

- 隐私调度器/令牌桶失效 ⇒ 发布步幅视为 ∞（不发布），本地闭环等价 v9 非共享；
- LVG 失效 ⇒ 不外发语音统计，情绪仍由本地 v9 ER 计算（不发布），等价 v9 无外发；
- POL 失效 ⇒ 只用本地梯度更新、不参与联邦，等价 v9 本地 OTL；
- w-event 记账器失效 ⇒ fail-closed，全部外发停止；
- v9 的 AC/MW/ID/DA/SPR/Cal 失效 ⇒ 按 v9 五级链继续退化到 v8/v7/v6；
- 隐私预算耗尽（非故障）⇒ 不是退化而是**节流**：增大 L_rel、增加批处理，实时闭环不变。

## 4. 预期贡献

1. **双资源契约**：把隐私预算提升为与 WCET/截止期同构的一等调度资源，给出联合可行性与 fail-closed 语义；
2. **分块对齐的流式隐私记账**：用 v9 动作分块作为 w-event DP 的窗口骨架，把逐周期外发降为块对齐发布并给出组合界；
3. **LVG + POL**：可实时运行的本地差分隐私语音量规与私密在线学习，附不可逆性/重构误差下界；
4. **安全-隐私分离定理**：证明隐私机制对 v9 安全证明的正交性，使系统可独立调节 ε 而不触碰安全论证；
5. **实验 E571–E590**：隐私-效用 Pareto、重构攻击、w-event 实证漏损、相关性膨胀、fail-closed 等价、双预算调度与端到端任务。

## 5. 本轮最大风险

**一句话**：w-event DP 的组合界假设发布事件在窗口内可加/可独立核算，但 v9 的块证书与情绪指标在相邻块之间高度时间相关，"块对齐"反而让相关性集中到同一条发布链上——若相关性膨胀因子 κ_corr 标定偏低，名义 ε 会系统性低估真实漏损，出现"账面上达标、实际上可被跨块推断"的隐私失效。

# 第 10 轮产物 · 创新点清单 v10：**MetricVoiceGauge-PRISM**（Privacy-Real-time Integrated Scheduling & Minimization）

> 背景：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮灵感：「实时控制」×「隐私保护」
> **继承纪律**：MetricVoiceGauge 九不变式与 v9 的 AC/MW/ID 全部保留；v10 只新增**外发通道**上的隐私层，绝不改动本地安全闭环的输入。新组件一律为可选增强：任一隐私环节不可用 ⇒ 注入发布中立元 u^⊥（不发布），严格等价 v9 非共享模式（引理 88），而非行为漂移。

## 0. 核心 IP 设计

| 编号 | 名称 | 类型 | 关键改进（相对 MetricVoiceGauge-ACMD v9） |
|---|---|---|---|
| IP-340–356 | v9 全部模块 | 继承 | 语义不变；本地安全闭环原样保留 |
| IP-357 | BiResourceMiddleware 双资源契约中间件 | 扩展 IP-355 | 契约 κ_m 增加 (ε_m, δ_m, u_m^⊥)；每周期联合校验时间预算 ΣŴ ≤ B_dec 与外发隐私预算 Σε ≤ τ(t) |
| IP-358 | PrivacyTokenScheduler / WEventAccountant 隐私令牌调度器与 w-event 记账器 | 新增核心 | 令牌桶 τ(t)；w-event DP 记账；块对齐发布纪元；相关性膨胀 κ_corr 保守放大 |
| IP-359 | LDPVoiceGauge 本地差分隐私语音量规 | 新增核心 | 原始音频不出设备；外发裁剪+Laplace 加噪的韵律充分统计量；O(d)/帧，附重构误差下界 |
| IP-360 | PrivateOnlineLearner 私密在线学习 | 新增核心 | 只存充分统计量（不存原始样本，O(d) 内存）；联邦梯度裁剪加噪；删除/遗忘 O(1) |
| IP-361 | FailClosedReleaseGate 隐私失效封闭门 | 新增核心 | 任何隐私组件异常 ⇒ 发布中立元 u^⊥="不发布"；本地闭环无缝续跑，等价 v9 非共享 |

**退化链声明（v10 双资源六级，隐私优先于性能）：**
- Level-P0：隐私全开，块对齐 DP 发布，双预算联合可行；
- Level-P1：隐私令牌桶欠费（非故障）⇒ 增大发布步幅 L_rel、加批处理，实时闭环不变（节流，非退化）；
- Level-P2：隐私组件故障（LVG/POL/记账器/审计）⇒ FailClosedReleaseGate 注入 u^⊥，**全部外发停止**，本地闭环等价 v9 非共享；
- Level-3：v9 的 AC 证书失效 / 信任域破坏 ⇒ K_eff ← 1，逐步执行，等价 v8 决策粒度；
- Level-4：v9 的 MW 失效 ⇒ 切换 v8 手写网关；ID 失效 ⇒ 全模块 active；
- Level-5：v9 的 DA/SPR/Cal 失效 ⇒ 中立元注入，等价 v7；全失效 ⇒ 退回 v6。

> 顺序不可交换：隐私故障永远先于性能退化触发（P14）；隐私故障只减少外发，不降低本地能力（P13）。

## 1. 符号体系增量（定义 540–551）

| 符号 | 含义 |

| S(b), E(b) | 陈旧度函数、单纪元隐私成本函数；F={(S,E)} 新鲜度-隐私前沿 |

**新增定义 540（外发事件与外发通道 Release Event）** v10 把系统输出分为两条物理隔离的通道：**本地闭环通道 L**（传感器→M₀/SpatialCert/FaultCert/AC→执行器）与**外发通道 R**（→操作员日志、云端 DA-ML、联邦同伴、跨机契约表）。外发事件 r=(D_r, q_r, M_r, D_r^rel) 表示对数据片 D_r⊂S 执行查询 q_r、经机制 M_r、须在 D_r^rel 前交给接收方。敏感类 S 的五类数据永不以外发形式传送原文；仅传送 M_r 的输出。

**新增定义 541（w-event 差分隐私，逐模块）** 机制 M 在块纪元流上满足 (ε_w, δ_w)-w-event DP，当且仅当对任意两条至多一个事件不同、且事件对齐的流 X, X'，以及任意长度为 w 个连续纪元的窗口 W，有
```
Pr[M(X)_W ∈ O] ≤ exp(ε_w)·Pr[M(X')_W ∈ O] + δ_w
```
其保证与运行总时长无关（适合 8h 长跑），窗口内预算可再分配（定义 542）。δ_w 固定为 1e−5。

**新增定义 542（隐私令牌桶 Privacy Token Bucket）** 余额 τ(t) ∈ [0, B_ε]，每块纪元补充 ρ_ε，外发事件消耗 ε_r；可行外发集 Q 满足
```
Σ_{r∈Q} ε_r ≤ τ(t),     τ(t+1) = min(B_ε, τ(t) − Σ_{r∈Q} ε_r + ρ_ε)
```
默认 B_ε = 4.0，ρ_ε = 0.05/纪元（5Hz ⇒ 0.25/s），与 w-event 窗口预算对齐。令牌桶把"隐私多久用完"从论文参数变成可调度的运行量。

**新增定义 543（双资源契约 Bi-resource Contract）** v9 契约扩展为
```
κ_m = (In, Out, D_m, Ŵ_m, v_m^⊥, π_m, φ_m^elig, ε_m, δ_m, u_m^⊥)
```
部署期静态校验两式：Σ_m Ŵ_m ≤ B_dec（时间）且 Σ_{m} ε_m·f_m ≤ ρ_ε（稳态隐私补充率），其中 f_m 为模块外发频率。运行期每纪元结算 (时间, 隐私) 二元组；硬安全模块 ε_m=0 且不受隐私调度影响。**隐私可行性不足时只裁剪外发，绝不裁剪安全计算**。

**新增定义 544（双松弛度与新鲜度-隐私前沿 Freshness-Privacy Frontier）** 定义
```
σ_p(t) = τ(t)/B_ε,   σ_t(t) = 1 − (Σ_m Ŵ_m + Σ_{r∈Q} Ŵ_r^DP)/B_dec
```
对一个持续外发的聚合量，批处理 b 个纪元后发布：陈旧度 S(b) ≈ (b−1)·T_chunk（默认 T_chunk=200ms），单纪元隐私成本 E(b) 随 b 单调不增（发布次数减少、组合次数减少；在裁剪界固定时敏感度不随 b 增长）。前沿 F = {(S(b), E(b)) : b ≥ 1} 为可达集。调度目标：在 τ 约束下取 b* = min{b : E(b) ≤ σ_p·B_ε /w}，即"能少批就少批"。

**新增定义 545（本地差分隐私语音量规 LDP Voice Gauge）** 每帧提取韵律向量 x_t=(f0, energy, jitter, shimmer, HNR, rate)，裁剪到 [−C,C]^d；每个纪元对 n 帧求均值并发布
```
x̃ = clip(mean_t x_t, [−C,C]^d) + Lap(Δ/ε)^d,   Δ = 2C/n
```
发布量满足 (ε,0)-LDP。原始音频只存在于本地环形缓冲，纪元结束即丢弃（不落盘）。发布量只用于操作员展示与联邦情绪先验，不回流 M₀。默认 C=3σ_f0，ε∈{0.5,1,2,4} 可调。

**新增定义 546（私密在线学习 Private Online Learning）** OTL/DA-ML 只维护充分统计量（一阶/二阶矩的指数滑动，O(d)），不保留原始样本回放池；参与联邦时发布
```
g̃ = clip(g, C_g) + N(0, σ_g² C_g² I)
```
由 moments accountant 逐模块记账 (ε_m^POL, δ_m^POL)。因不存原始样本，"删除某用户数据"无需重训，遗忘成本 O(1)（只需回滚该用户贡献的充分统计量）。

**新增定义 547（隐私失效封闭门 Fail-Closed Release Gate）** 定义发布中立元 u^⊥="不发布"，其对发布聚合算子 ⊕_R 为吸收元：x ⊕_R u^⊥ = x（已有发布不撤回、后续发布被吞掉）。门控条件为
```
release_ok = accountant_ok ∧ token_ok ∧ mechanism_deadline_met ∧ audit_ok
若 ¬release_ok：Q ← ∅，R 输出 u^⊥
```
u^⊥ 不是恒等元而是吸收元，需单独验证（与 v9 AC 的安全停驻元同构，见表 536 扩展）。

**新增定义 548（发布账本与相关性膨胀 Release Ledger）** 每次外发记 (epoch, 数据片 id, ε_r, b, L_rel)。朴素组合假设事件独立，但相邻块的情绪/证书共享状态；定义名义与实际的关系
```
ε_eff = κ_corr · Σ_{r∈window} ε_r,   κ_corr ≥ 1
```
κ_corr 由 E582 的跨块互信息/攻击实验标定，再乘 1.2 安全系数。若 κ_corr 置信区间过宽，则强制降级到更小的 ε 或直接不发布（fail-closed）。

**新增定义 549（隐私感知发布步幅 Privacy-aware Release Stride）** L_rel ∈ {1,2,…,∞} 为每多少个块纪元外发一次；陈旧度上界
```
S_max = (L_rel·b − 1)·T_chunk + D_r^rel
```
实时性要求 S_max ≤ S_budget（操作员可接受陈旧度，默认 1s）。L_rel=∞ 即 Level-P2。L_rel 与 v9 的 K_eff 独立：块长控制动作前瞻，发布步幅控制信息新鲜度，二者正交。

**新增定义 550（隐私度量与攻击模型 Privacy Metrics）** (i) 效用：发布情绪指标与本地真值的相关系数 ρ_util；(ii) 抗重构：从发布序列反演原始韵律/语音的攻击重构误差 e_rec（相对未加噪基线）；(iii) 成员推断：对单个语音片段的 membership advantage adv；(iv) 实时：DP 机制 p99 WCET。预注册要求 ρ_util ≥ 0.8、e_rec ≥ 2× 基线、adv ≤ 0.55。

**新增定义 551（隐私-性能联合格点 Joint Degradation Lattice）** 系统状态 = (隐私级 P0–P2) × (v9 性能级 Level-3–5)，偏序为"外发信息量"与"本地能力"两个正交方向。单调性要求：沿隐私方向下降（P0→P2）只减外发；沿性能方向下降只减增强模块。任意外部故障映射到格点上的一个元素，且本地能力永不因隐私故障下降（引理 88）。

## 2. 形式化定义（要点与升级）

# IP-357/358：双资源契约 + 隐私令牌调度 + w-event 记账
@dataclass
class Contract:
    name: str; deadline_ms: float; wcet_ms: float
    fail_value: object; priority: int; distill_eligible: bool
    eps: float = 0.0; delta: float = 0.0      # 隐私成本（0=不敏感）
    release_fn: str | None = None             # 外发端口；None=本地模块
    fail_release: object = NO_RELEASE         # u^⊥

class PrivacyTokenBucket:
    def __init__(self, cap=4.0, refill=0.05):
        self.cap, self.refill, self.tokens = cap, refill, cap

    def spend(self, eps):
        if eps > self.tokens:
            return False                       # 欠费 ⇒ 停外发（Level-P1 节流）
        self.tokens -= eps
        return True

    def tick(self):
        self.tokens = min(self.cap, self.tokens + self.refill)

class WEventAccountant:
    def __init__(self, w=10, eps_w=1.0, delta_w=1e-5, kappa_corr=1.2):
        self.w, self.eps_w, self.delta_w = w, eps_w, delta_w
        self.kappa = kappa_corr                # 定义 548 保守放大
        self.ledger = deque(maxlen=w)

    def charge(self, eps_r):
        self.ledger.append(self.kappa * eps_r)
        return sum(self.ledger) <= self.eps_w

class BiResourceMiddleware(ContractMiddleware):
    def __init__(self, contracts, bucket, accountant):
        super().__init__(contracts)
        self.bucket, self.accountant = bucket, accountant
        self.policy_closed = False

    def run_cycle(self, runners, ctx, releases=()):
        # 1) 硬安全模块先跑，时间预算不可被隐私任务挤占（P13/P15）
        results = super().run_cycle(
            {k: v for k, v in runners.items()
             if self.contracts[k].eps == 0.0}, ctx)
        # 2) 外发任务：双预算联合可行才执行，否则 fail-closed
        for r in sorted(releases, key=lambda r: r.deadline_ms):
            c = self.contracts[r.module]
            time_ok = (ctx.used_ms + c.wcet_ms) <= ctx.budget_ms
            priv_ok = (not self.policy_closed
                       and self.bucket.spend(c.eps)
                       and self.accountant.charge(c.eps))
            if time_ok and priv_ok:
                ctx.used_ms += c.wcet_ms
                results[c.name] = runners[c.name](ctx)
            else:
                results[c.name] = c.fail_release      # u^⊥ = 不发布
        self.bucket.tick()
        return results


# IP-359：本地差分隐私语音量规
class LDPVoiceGauge:
    def __init__(self, dim=6, clip=3.0, eps=1.0):

    def extract(self, audio_frame):
        return clip_vec(prosody(audio_frame), self.C)  # 仅本地

    def release_epoch(self, frames):
        n = max(1, len(frames))
        mean = sum(frames) / n
        sens = 2.0 * self.C / n                       # 定义 545 敏感度
        noise = lap_sample(scale=sens / self.eps, size=self.d)
        return clip_vec(mean + noise, self.C)         # (ε,0)-LDP


# IP-360：私密在线学习
class PrivateOnlineLearner:
    def __init__(self, dim, clip_g=1.0, sigma_g=1.1, delta=1e-5):
        self.m1, self.m2 = zeros(dim), zeros(dim)     # 只存充分统计量 O(d)
        self.Cg, self.sg, self.delta = clip_g, sigma_g, delta
        self.accountant = MomentsAccountant(self.delta)

    def update(self, batch):
        g = grad_from_batch(self.m1, self.m2, batch)
        g = clip_norm(g, self.Cg)
        g += normal(0, self.sg * self.Cg, size=g.shape)
        self.m1 = 0.99 * self.m1 + 0.01 * g
        self.accountant.step_sgd(len(batch), self.sg)

    def shared_delta(self):
        return self.accountant.get_epsilon(target_delta=self.delta)


# IP-361：隐私失效封闭门
class FailClosedReleaseGate:
    def __init__(self, accountant, bucket, audit):
        self.accountant, self.bucket, self.audit = accountant, bucket, audit

    def release_ok(self):
        return (self.accountant.ok()
                and not self.accountant.budget_exhausted()
                and self.audit.consistent()
                and self.bucket.tokens > 0)

    def guard(self, release_result):
        return release_result if self.release_ok() else NO_RELEASE   # u^⊥

## 4. 推导

**引理 87（安全-隐私分离）** 若所有硬安全判定 f_safe∈{M₀, SpatialCert, FaultCert, AC 中块守卫, 停车不变式} 的输入取自本地通道 L，且外发通道 R 的输出不回流 L（架构不变量 A1），则对任意 DP 机制 M_r 与任意 (ε,δ)，v9 的安全性引理 80–86 全部成立且结论不变。
证明：f_safe 的定义域与 R 的输出 σ-代数独立，DP 噪声只改变 R 上的可观测分布，故 f_safe 的每个输入路径与 v9 逐点相同，安全判据的真值序列逐位一致；由 v9 引理 80–86 传递。∎

**引理 88（fail-closed 单调性与 v9 等价）** 当 FailClosedReleaseGate 输出 u^⊥ 时，外发信息量为 0；本地闭环与 v9 的"非共享"运行逐位一致。且对任意发布策略，关闭发布不会增加任何披露（信息论单调性），故隐私故障只能使系统更私密、不会更危险。
证明：u^⊥ 为吸收元，R 输出为空集，空集是任何发布集合的子集，披露量单调不增；本地通道 L 未被修改，故与 v9 非共享逐位等价。∎

**引理 89（块对齐 w-event 组合）** 设在发布纪元集合 E 上每次外发为 (ε_r, δ_r)-DP，且每个 w 纪元窗口内 Σ_{r} ε_r ≤ ε_w；则整条流满足 (ε_w, δ_w)-w-event DP，且 8h 运行不累积。证明：按 w-event DP 定义对任意对齐窗口做基本组合，窗口内成本由令牌桶/记账器强制不超过 ε_w；跨窗口因 w-event 语义为"任意窗口"而非"前缀"，故与总时长无关。∎

**引理 90（批处理前沿与阈值最优）** 在裁剪界 C 与纪元帧数 n 固定时，b 个纪元聚合发布的敏感度仍为 2C/(bn)，而发布次数降为 1/b；若帧数随 b 线性增长，则单纪元隐私成本 E(b) ≈ E(1)/b，陈旧度 S(b)=(b−1)T_chunk。因此在预算约束 E(b) ≤ σ_p B_ε/w 下，最优 b* 是满足约束的最小整数（阈值策略），最小陈旧度 S* = (b*−1)T_chunk。证明：E 单调不增、S 单调增，线性约束下最小可行 b 即最优点。∎（注：若敏感度随 b 增长，需改用 E582 的实测前沿，结论改为在实测 F 上取最小可行 b。）

**引理 91（LDP 量规的隐私与重构下界）** 定义 545 的 Laplace 机制满足 (ε,0)-LDP；对任意基于 x̃ 的无偏重构器，单坐标误差方差下界为 2Δ²/ε² = 8C²/(ε²n²)，故 ε→0 时重构误差发散。证明：Laplace(0, Δ/ε) 方差为 2Δ²/ε²；无偏估计量的方差受噪声方差下界约束（Cramér–Rao/信息不等式），均值敏感度 Δ=2C/n，代入即得。∎

**引理 92（私密在线学习的记忆与遗忘）** POL 仅保留 d 维充分统计量，内存 O(d)（与样本量无关）；其发布梯度满足 (ε_T,δ_T)-DP，由 moments accountant 给出。原始样本从不落盘，删除用户贡献只需从 m1/m2 减去其（已聚合的）充分统计量，遗忘成本 O(d)，无额外隐私成本（不触发重训查询）。
证明：由定义 546，状态仅含 m1,m2；DP-SGD 组合界由 moments accountant 标准结论给出；删除时线性统计量可减，剩余状态等于从未见过该样本的聚合（在裁剪线性聚合假设下），故遗忘 O(1) 且不新增查询。∎

**引理 93（双资源可调度性充分条件）** 若 (i) Σ_m Ŵ_m + max_r Σ Ŵ_r^DP ≤ B_dec；(ii) 每块纪元强制外发需求 ≤ ρ_ε，且可选外发可在 τ 上延后；(iii) 硬安全模块 ε=0 且优先级最高；则双资源调度器满足所有硬截止期与 w-event 窗口预算，且可选外发最大延后 ≤ B_ε/ρ_ε 个纪元。
证明：(i) 保证时间维度存在可行序，EDF 对单资源可行；隐私维度由令牌桶不变式 τ≥0 与 (ii) 保证不饿死；Token 不足时按定义 544 增大 b 而非超发，故 ε 预算恒满足；(iii) 保证安全任务永不被挤占。∎

**引理 94（相关性膨胀危害）** 若相邻块外发共享底层状态，实际联合分布不满足独立组合的前提，存在 κ_corr ≥ 1 使真实 ε_true ≥ κ_corr·Σε_r；当 κ_corr 被低估为 1 时，名义 (ε_w,δ_w)-DP 不再成立。
证明：构造共享状态 X，两次外发分别为 X 与 X+noise 的函数，两次输出的互信息高于独立情形，基本组合的加性界失效；由数据处理不等式可给出 κ_corr>1 的下界实例。故必须用定义 548 的实测膨胀或更强的机制（更小 ε）保守覆盖。∎
