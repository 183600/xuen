# 第 15 轮（新灵感循环第 6 轮；本轮灵感：「运动规划」×「安全对齐」）

> **基线**：第 14 轮 MetricVoiceGauge-NCD-HUTDH（定义 595–606；引理 122–124；实验 E647–E660）。
> 本轮纪律：**轨迹级证书的前缀闭扩张 + 只改序不改集的安全对齐 + 同伦/漂移重认证**。不推倒 v14：v14 的 HBR/UCCI/PAA、v13 的 AIO/CPD/DDL/RTCR、v12 的 USG/TGC/BAA/GAGP/UC、更低级版本与九不变式全部保留。三个新组件——CMP（认证运动规划，含 TC/前缀闭）、SAP（安全对齐投影，含 ALC/偏好风险预算）、MALR（运动—对齐阶梯路由器）——一律以**中立元**接入，失效即严格退回 v14（引理 130），再沿 v14 退化链退回 v13/v12/…。本轮只做三件事：把“安全”从单步动作证书提升为**带管（tube）的轨迹证书**，把“对齐”从目标函数改写为**认证集合内的排序**，把二者合成**同伦感知、前缀可执行**的轨迹阶梯。

## 0. 直觉与动机

**灵感 1（运动规划 → 单步证书不能自动复合成轨迹证书）**
直觉：v14 的每个动作都带证书，但“每一步都安全”不等于“整条轨迹安全”。接触切换、动态可行性、障碍侧的拓扑选择、执行器饱和，都会让局部安全的动作串在拼接处越界。更麻烦的是，轨迹规划天然是多步的：若只看终点余量，规划器会选出“终点安全、中途贴边”的轨迹；若只看每步余量，又会错过需要暂时靠近障碍才能完成的合法任务。核心创新：**认证运动计划（CMP）+ 轨迹证书（TC）**。轨迹证书不是一个标量，而是 `(标称轨迹, 鲁棒管道, 最小余量, 同伦签名, 停止证书)`；安全性由“管道不变式 + 每步 v14 证书 + 任意前缀可停”共同保证。关键反直觉点：**安全轨迹的认证应当前缀闭（prefix-closed）**——不是“整条轨迹事后验收”，而是“从当前状态到任意前缀都已有可执行的停止/续行证书”。这样任何时刻因计算超时、观测突变或同伦切换而中断，都只会退回更短的已认证前缀，不会把未验证的尾段执行出去。

**灵感 2（安全对齐 → 对齐只能改序，不能改集）**
直觉：安全对齐通常被写成“让策略最大化人类偏好/奖励模型”。但奖励模型会被分布外样本欺骗，也会被对抗性偏好利用；一旦对齐目标与安全证书共享同一个优化目标，系统就会用“人类更喜欢”来为“更贴边、更快、更激进”的轨迹背书。核心创新：**安全对齐投影（SAP）+ 对齐证书（ALC）+ 偏好风险预算 `ε_align`**。把授权与排序彻底分离：CMP 先构造认证轨迹集合 `MP`；SAP 只在 `MP_ε = {τ : m_τ ≥ ε_align}` 内按对齐分数 `V_a` 排序；`ε_align` 有硬下界 `ε_min`，对齐只能让系统更保守（提高 ε），不能让它更冒险（降低到 ε_min 以下）。ALC 给出 `V_a` 与真实人类偏好 `V_h` 在支撑域上的单侧间隙 `U_align`，从而把对齐错误限制为**任务次优（regret）**，而不是**越权放行**。关键反直觉点：**对齐的目标不是让系统“更敢做”，而是让系统在已经安全的集合里“更懂用户”**；若偏好模型不确定，正确动作是缩小 `MP_ε`，不是扩大 `MP`。

**灵感 3（运动规划 × 安全对齐 → 同伦感知的轨迹阶梯）**
直觉：v14 已经有一条按毫秒排序的动作/学生阶梯；但轨迹规划还有额外的离散结构——同伦类（从障碍哪一侧绕、采用哪种接触模式序列）。不同同伦类的证书不可互换：一条在“左侧绕行”下认证的管道，不能直接用于“右侧绕行”，即使几何上看起来只差一点。核心创新：**运动—对齐阶梯（MAL）+ 运动—对齐路由器（MALR）+ 轨迹证书复合器（TCC）**。把 v14 的阶梯从动作集提升为轨迹集：`MP_0 ⊆ MP_1 ⊆ … ⊆ MP_m ⊆ Exec_v14^τ`，第 0 档是零学习的停车/退让；每一档有独立 WCET 与轨迹证书；路由器先按剩余时间选档，再在档内按 `V_a` 排序，且必须通过**同伦门**与**前缀执行**。同伦切换、分布漂移或 ALC 失效时，路由器向第 0 档塌缩并重认证，而不是用旧证书“赌一把”。

**三者如何统一**
统一为 **v14 之上的轨迹语义层**：v14 回答“这一帧允许哪些动作/学生、能否按时实现”；v15 回答“在当前同伦类与偏好下，哪一条**前缀可停**的认证轨迹应当被执行，能走多远”。CMP 负责“把安全集从停车种子单调扩张成轨迹管道”；SAP 负责“在管道内按对齐偏好排序，但绝不扩集”；MALR/TCC 负责“按时间与同伦选档、复合、截断、塌缩”。共享状态 `ζ_rt^15` 在 v14 的 `ζ_rt^14` 上增加 `(MP_{i*}, τ*, ALC, ε_align, hom, prefix_k, B_align, B_plan)`。**CMP 回答“哪些轨迹可证安全”，SAP 回答“安全的轨迹里用户更喜欢哪条”，MALR 回答“这一帧能安全走到哪一档/哪一个前缀”**。

## 1. 研究问题（轮次升级版）

- **Q1（轨迹证书的可证语义）**：如何定义带管轨迹证书才使“任意前缀中断都可停”？管不变式、每步 v14 证书与停止证书在拼接处如何复合？同伦切换为什么会使证书失效，如何形式化“不可迁移”？`Exec_v15 ⊆ Exec_v14` 如何保持？
- **Q2（对齐不扩权的可证边界）**：如何定义对齐算子，使偏好模型只能重排已认证轨迹而不能新增授权？`ε_align` 的硬下界与 ALC 的单侧间隙如何共同保证“错也错在任务层，不错误在安全层”？偏好模型被对抗/分布外样本欺骗时，regret 与安全性如何分离？
- **Q3（轨迹阶梯与路由的最优性）**：如何构造/训练嵌套的轨迹档位？在未知规划耗时、动态障碍与同伦切换下，路由器如何在线选档、选前缀，使“超时率—完成率—对齐 regret”最优？`B_plan`/`B_align` 如何硬预留而不被 v14 的推理预算挪用？
- **Q4（与 v14 的兼容与活性）**：CMP/SAP/MALR 是否可能绕过 v14 的 TGC/UC/DGC/四重证书？轨迹证书误差、同伦误分类与 DGC/TGC 误差是否会相加？管道过保守或 `ε_min` 过大是否导致频繁停车/`a_ask`？新增模块能否守住 50Hz/p99≤22ms，并严格退回 v14？

## 2. 设计原则（在 P22–P24 基础上新增 P25–P27）

**P25 运动证书前缀闭律（Prefix-Closed Motion Certificate）**
每条可执行轨迹必须携带前缀闭证书：对任意执行时刻 t，前缀 `τ_{0:t}` 都有有效证书与认证停止/续行；执行器只能在 `prefix_k ≤ k*(τ)` 内前进。轨迹规划必须从**停车/退让种子** `MP_0` 出发向上扩张，不得从“看起来可行的激进轨迹”向下修补。任何中断只能返回更短的前缀，不得返回“迟到但完整”的轨迹。

**P26 对齐不扩权律（Alignment Reorders, Never Authorizes）**
对齐分数 `V_a` 只能作用于已认证集合 `MP`；实际可排序集为 `MP_ε`，且 `ε_align ≥ ε_min > 0`。`ε_align` 只能向上调（更保守），不得低于安全地板；偏好模型、用户偏好或奖励模型不得修改 `MP` 的构造、不得放宽任何 v14 证书、不得新增动作/轨迹。对齐失败、ALC 失效或支撑外输入的默认动作是缩小 `MP_ε` 或退回 `MP_0`，不是继续按 `V_a` 排序。

**P27 同伦与漂移重认证律（Homotopy/Drift Recertification）**
证书是同伦相对的：`c_τ` 只在 `hom_τ` 内有效；跨同伦类复用证书视为无效。检测到同伦切换、动态障碍改变拓扑、或分布漂移时，必须重新认证；重认证不完成则只能执行 `MP_0`（停车/退让/`a_ask`）。禁止把“旧同伦下的安全”外推为“新同伦下的安全”。

## 3. 与基线的接口（如何退化）

- TCC 失效 ⇒ 禁止多段复合与跨同伦复用，只保留单段轨迹证书；等价 v14 + 单段安全规划；
- MALR 失效 ⇒ v14 RTCR 选档，CMP 仅生成可执行轨迹、SAP 仅做集合内过滤；等价 v14 + CMP + SAP 过滤；
- SAP 失效 ⇒ `V_a≡const`、`ε_align=ε_max`，按最大余量/最小代价选轨迹；等价 v14 + CMP（无对齐）；
- CMP 失效 ⇒ 无轨迹规划，退回 v14 的动作级 anytime 阶梯；等价 v14；
- 四者全失效 ⇒ MetricVoiceGauge-NCD-HUTDH v14，再沿 v14 退化链退回 v13/v12/…；
- **安全继承**：CMP 只扩张已认证轨迹，SAP 只做子集内排序，MALR 只选档/前缀，TCC 只做同伦一致复合；四端口互不相交，均不能新增授权；`Exec_v15⊆Exec_v14` 由引理 127 保证。

## 4. 预期贡献

1. **轨迹级前缀闭证书**：把“安全”从单步动作证书提升为带管轨迹证书，解决“每步安全但拼接越界”与“终点安全但中途贴边”的结构性漏洞；
2. **对齐不扩权的可证边界**：把安全对齐从奖励最大化改写为认证集合内的排序，给出 `ε_align` 硬地板、ALC 单侧间隙与对齐 regret 界；
3. **同伦感知的运动—对齐阶梯**：把 v14 的毫秒阶梯提升为轨迹阶梯，显式处理同伦不可迁移、动态障碍与漂移重认证；
4. **四间隙可加与端到端**：把运动间隙、对齐间隙与 v14 的迁移/蒸馏间隙并入同一预算与并集界；E661–E676 覆盖前缀闭、同伦门、对齐不扩权、regret、塌缩与消融。

## 5. 本轮最大风险

**一句话**：前缀闭轨迹证书的可靠性依赖于“每段证书的管在拼接处仍然不变”，而同伦分类器与动态障碍会把拼接边界误判为同类；一旦某段在边界处的接触/动力学耦合未被管道覆盖，系统就会在“每段都认证、每个前缀都可停、每个选择都更符合用户偏好”的表象下执行一条**整体越界**的轨迹，且安全对齐只会在错误的集合里挑一条“更讨喜”的错误轨迹。

**定义 607（认证运动计划与轨迹证书 Certified Motion Plan, CMP）**
直觉：安全不是“终点在安全区”，而是“存在一个鲁棒管道，使任意扰动下的整条执行都不越界，且任意时刻都能安全停下”。形式化地，令离散动力学为 `x_{t+1}=f(x_t,a_t,w_t)`，`w_t∈W`，`m_v14` 为 v14 物理/接触/谐波/规范四类硬余量的下确界。轨迹
```
τ = (ξ_{0:H}, T_{0:H}, c_τ),   c_τ = (m_τ, hom_τ, stop_τ),
m_τ = inf_{0≤t≤H} inf_{x∈T_t} m_v14(x, π_τ(x,t))
```
称为**认证的**，当且仅当：
1. `x_0 ∈ T_0`；
2. 鲁棒管道不变式：`∀t, ∀x∈T_t, ∀w∈W : f(x,π_τ(x,t),w) ∈ T_{t+1}`；
3. 每步 v14 证书：`∀t, ∀x∈T_t : m_v14(x,π_τ(x,t)) ≥ 0`；
4. 停止条件：`∀t, T_t ⊆ Stoppable`（存在满足 `B_safe` 的认证停止/退让）；
5. 同伦一致：`hom_τ = hom(context)`。
记 `MP(x) = {τ : τ 在 x 处认证}`。条件 2–3 保证“管内的任何执行”都安全，而不是只保证标称轨迹安全。

**定义 608（前缀闭证书 Prefix-Closed Certificate）**
直觉：任何一次早退、超时或观测突变，都只能让系统执行一个更短但已认证的前缀。`τ` 称为**前缀闭的**，当且仅当对每个 `k∈{0,…,H}`，前缀 `τ_{0:k}` 满足定义 607 的 1–5，且 `stop_τ(k)` 有效、可在 `B_safe` 内完成。定义最大可执行前缀
```
k*(τ) = max{ k : τ_{0:k} 认证且 stop_τ(k) 有效 } .
```
执行器只能在 `prefix_k ≤ k*(τ)` 内前进；`k*(τ)` 不是事后验收量，而是运行时硬门。

**定义 609（保守种子轨迹扩张 Conservative Seed Expansion）**
直觉：与 v13 的 anytime 从最保守集合向上扩张完全同构，只是对象从“动作候选”换成了“轨迹段”。定义
```
MP_0(x) = { Stop(x), Retreat(x), Ask(x) } ,
MP_k(x) = MP_{k-1}(x) ∪ { τ = τ' ⊙ σ :
            τ'∈MP_{k-1}(x), σ∈Seg_k(x),
            Compose(τ',σ) 认证, hom(τ')=hom(σ) } .
```
其中 `⊙` 为轨迹拼接，`Seg_k` 为第 k 轮候选段。于是 `MP_0⊆MP_1⊆…⊆MP` 单调嵌套，任意时刻中断返回某个 `MP_k` 的元素。`MP_0` 是**零学习、零轨迹证书**的物理安全回退。

**定义 610（同伦分割与证书不可迁移 Homotopy Partition）**
直觉：从障碍左边绕和从右边绕，几何上只差一点，但接触模式、可行管道与停止条件可能完全不同；旧证书不能“平移”到新同伦类。令 `H={H_1,…,H_q}` 为按接触模式序列、障碍侧分配与绕行类划分的同伦类。轨迹证书 `c_τ` 只相对于 `hom_τ` 有效：
```
∀τ∈H_i, c_τ 只在 H_i 内成立；  H_i≠H_j ⇒ c_i ⊥ c_j .
```
定义同伦门 `G_hom(τ,ctx)=1[hom_τ=hom(ctx)]`。跨类切换必须重新认证；在重认证完成前，只允许执行 `MP_0`。

**定义 611（安全对齐算子：只改序，不改集 Alignment as One-Sided Ranking）**
直觉：把“用户/奖励模型更喜欢”与“系统被允许执行”彻底分开。令 `V_a(x,τ;θ)` 为对齐分数，`MP_ε` 由定义 612 给出。定义
```
Align_{V_a}(x,MP) = argmax_{τ∈MP_ε(x)} V_a(x,τ;θ) .
```
`V_a` 只出现在 `argmax` 内，绝不参与 `MP`、`MP_ε` 或任何 v14 证书的构造。若并列，按 `(m_τ, −cost(τ), 规范序号)` 确定性打破。于是对齐只能改变“在安全轨迹中选哪一条”，不能改变“哪些轨迹算安全”。

**定义 612（偏好风险预算与可对齐集 Preference Risk Budget）**
直觉：偏好越激进，系统越容易贴近安全边界；必须把这种“偏好换来的风险”显式定价，并设一个不可突破的地板。定义
```
MP_ε(x) = { τ∈MP(x) : m_τ ≥ ε_align } ,   ε_align ∈ [ε_min, ε_max] ,  ε_min>0 .
```
`ε_align` 可由用户/对齐策略在区间内选择，但系统在进入 `MP_ε` 前强制裁剪；**只能向上调（更保守），不能低于 `ε_min`**。`B_align` 是对齐模型的校准/验证计算预算，与 `ε_align` 是两个不同对象，二者都不得被挪用为安全预算。

**定义 613（对齐证书 Alignment Certificate, ALC）**
直觉：对齐模型只在它见过的支撑域上可信；出了支撑域，宁可不排序。定义
```
ALC = (S_align, U_align, δ_align, ε_align)
```
其中 `S_align⊆X×T` 为校准支撑，`U_align` 为单侧间隙：
```
P( sup_{(x,τ)∈S_align} |V_a(x,τ;θ) − V_h(x,τ)| ≤ U_align ) ≥ 1−δ_align .
```
若 `(x,τ)∉S_align`，则 `V_a` 不得用于排序，必须退回“最大余量/最小代价”的规范轨迹或 `a_ask`。ALC 是**排序证书**，不是运动证书；它不能替代或放宽定义 607 的任何条件。

**定义 614（运动—对齐阶梯 Motion-Alignment Ladder, MAL）**
直觉：v14 的阶梯按毫秒排列学生；v15 的阶梯按毫秒排列**轨迹族**，且每一档都保持轨迹级前缀闭与同伦一致。定义
```
MAL = ( {MP_i}_{i=0}^m, {w_i}_{i=0}^m, {c_i}_{i=0}^m, ε_align ) ,
MP_0 ⊆ MP_1 ⊆ … ⊆ MP_m ⊆ Exec_v14^τ ,
w_i = ⌊B_time · ρ^i⌋ ,   w_0<…<w_m ,
```
其中 `ρ` 继承 v14 HBR 的谐波减速比，每个 `MP_i` 都前缀闭且同伦一致，`MP_0` 为停车/退让/`a_ask`。档位越高，授权轨迹集越大、计算越贵，但永远不超过 v14。

**定义 615（运动—对齐路由器状态与策略 Motion-Alignment Router）**
```
ζ_rt^15 = ( B_time, B_safe, B_plan, B_align, i*, τ*, MP_{i*}, ALC, ε_align,
            hom, prefix_k, drift, mode, ρ, α_user, platform_id )
i*(B) = max{ i : w_i ≤ B−B_safe , c_i 有效 , ALC 在当前同伦类有效 } ,
π_15(x;B) = Align_{V_a}(x, MP_{i*(B)}(x) ∩ MP_{ε_align}(x)) .
```
并要求对所有 `x,B`：`π_15(x;B) ∈ Exec_v14^τ`。若 `MP_{i*}∩MP_ε=∅`，执行 `MP_0` 或 `a_ask`；若 `drift=1`、`G_hom=0` 或 ALC 失效，强制 `i*=0`。`α_user` 只继承 v14 UCCI 的阈值位移，**不影响** `i*` 的选档逻辑，也不影响 `MP` 的构造。

**定义 616（安全前缀执行与截断 Safe Prefix Execution）**
在每个控制 tick `t`：
```
if x_t ∉ T_t  or  hom(ctx_t) ≠ hom_τ  or  c_τ,t 失效:
      k ← last_certified_prefix(τ, t)
      τ ← replan_from(x_k) if B_plan 足够 else MP_0
else:
      execute a_t = π_τ(x_t,t);  t ← t+1
```
执行器永远不越过 `k*(τ)`；截断只能使当前执行集缩小或不变。若重规划也来不及，直接执行 `MP_0` 的认证停止。

**定义 617（v15 执行集与四预算不可挪用 Execution Set）**
```
Exec_v15 = { τ : τ∈MP_{i*(B)}∩MP_{ε_align} ,
                  τ 前缀闭且同伦一致 ,
                  每步 v14 物理/接触/谐波/规范证书有效 ,
                  U_gap+U_dis+U_motion+U_align ≤ B_total ,
                  P^rt≠∅ }
```
预算关系：
```
B_total = B_transfer + B_distill + B_align
B_time  = B_safe + B_infer + B_plan
B_ρ     = B_harmonic + B_α          （继承 v14，不变）
```
`B_plan` 与 `B_safe`、`B_align` 与 `B_distill/B_transfer` 各自独立，**不得互相冲抵**：规划计算不能吃掉安全切片，对齐校准不能借用蒸馏/迁移预算。任一预算耗尽时，唯一允许的动作是沿阶梯更保守、截断到更短前缀、或 `a_ask`。

# IP-381 TrajectoryCertificateComposer：只做同伦一致、边界管道兼容的复合
class TrajectoryCertificateComposer:
    def __init__(self, tube_checker, cert_v14):
        self.tube, self.cert14 = tube_checker, cert_v14

    def compose(self, tau1, tau2):
        if tau1.hom != tau2.hom:                  # 跨同伦：拒绝复用
            return None
        if not subset(tau1.T[-1], tau2.T[0]):     # 边界管道必须兼容
            return None
        tau = concatenate(tau1, tau2)
        if not self.tube.invariant(tau):          # 管道不变式
            return None
        if tau.margin < min(tau1.margin, tau2.margin):
            return None
        if not all(self.cert14(s) for s in tau.steps):
            return None
        if not prefix_closed(tau):                # 任意前缀可停
            return None
        return tau


# IP-378 CertifiedMotionPlanner：从停车种子单调扩张
class CertifiedMotionPlanner:
    def __init__(self, segments, wcet, tcc, fallback, max_traj=256):
        self.segments, self.wcet = segments, wcet
        self.tcc, self.fallback = tcc, fallback
        self.max_traj = max_traj

    def seed(self, x):
        return [Stop(x), Retreat(x), Ask(x)]      # MP_0：零学习安全回退

    def expand(self, x, B_time, rho, max_k):
        MP = self.seed(x)
        for k in range(1, max_k + 1):
            if int(B_time * rho ** k) < self.wcet[k]:
                break                             # 谐波预算放不下：停在上一档
            cand = []
            for tau in MP[-self.max_traj:]:
                for seg in self.segments[k](x):
                    new = self.tcc.compose(tau, seg)
                    if new is not None:
                        cand.append(new)
            MP = MP + prune_dominated(cand, cap=self.max_traj)
        return MP


# IP-379 SafetyAlignmentProjector：只排序，不扩集
class SafetyAlignmentProjector:
    def __init__(self, alc, eps_min, eps_max):
        self.alc, self.eps_min, self.eps_max = alc, eps_min, eps_max

    def alignable(self, x, MP, eps):
        eps = max(self.eps_min, min(self.eps_max, eps))   # 硬地板裁剪
        return [tau for tau in MP
                if tau.margin >= eps and self.alc.supports(x, tau)]

    def select(self, x, MP, V_a, eps):
        A = self.alignable(x, MP, eps)
        if not A:
            return None                           # 不排序，退回 MP_0/a_ask
        return max(A, key=lambda tau: (V_a(x, tau), tau.margin, -tau.cost))


# IP-380 MotionAlignmentLadderRouter：选档 + 档内排序 + 前缀执行
class MotionAlignmentLadderRouter:
    def __init__(self, ladder, sap, alc, tcc, rho, B_safe):
        self.L, self.SAP, self.alc, self.TCC = ladder, sap, alc, tcc
        self.rho, self.B_safe = rho, B_safe

    def route(self, x, B_time, drift, hom_ctx):
        if drift or not self.alc.valid_for(hom_ctx):
            return self.L.rung(0)                 # 同伦/漂移：安全塌缩
        budget = B_time - self.B_safe            # 安全切片不可挪用
        for i in reversed(range(len(self.L.MP))):
            w_i = int(budget * self.rho ** i)
            if w_i > budget or not self.L.cert_valid(i):
                continue
            tau = self.SAP.select(x, self.L.MP[i](x), self.V_a, self.eps_align)
            if tau is not None:
                return tau
        return self.L.rung(0)

    def execute_prefix(self, tau, obs, t):
        if not self.TCC.in_tube(tau, obs, t) or not self.TCC.homotopy_ok(tau, obs):
            k = self.TCC.last_certified_prefix(tau, obs, t)
            return self.replan_or_stop(obs, k)     # 只能更短/更保守
        return tau.action(obs, t)                  # 不越过 k*(tau)

## 4. 推导

**引理 125（前缀闭证书的安全截断）** 若 `τ` 满足定义 607 的 C1–C5 且满足定义 608 的前缀闭性，则对任意 `k≤H`，先执行 `τ_{0:k}` 再执行 `stop_τ(k)` 所得的完整动作序列属于 `Exec_v14`；且提前截断的授权价值不高于完整 `τ`。证明：由 C2，管道不变式在 `0..k` 上成立；由 C3，每步 v14 四类证书有效；由 C4，`T_k⊆Stoppable` 给出可在 `B_safe` 内完成的认证停止；拼接即得 v14 可执行序列。授权价值单调由 `τ_{0:k}` 的前缀包含关系与 `Exec_v14` 的合取单调性给出。∎ 推论：**中断只可能让系统更保守，不可能把未验证尾段执行出去**；WCET 误差只影响能走多远，不影响截断点的安全性。

**引理 126（轨迹证书的复合与同伦边界）** 设 `τ_1,τ_2` 均认证，`T^1_H⊆T^2_0`，且 `τ_1` 的末端控制器与 `τ_2` 的首端状态在边界上兼容。若 `hom(τ_1)=hom(τ_2)`，则 `τ_1⊙τ_2` 认证；若 `hom(τ_1)≠hom(τ_2)`，则不存在可迁移的证书，必须在目标同伦类内重新认证。证明：鲁棒管道不变式在拼接处由 `T^1_H⊆T^2_0` 与两端控制器兼容性闭合；余量取下确界仍非负；每步 v14 证书由两段各自保证。同伦签名不同意味着 C5 的前提不成立，而接触模式/障碍侧假设不可由几何连续性推出，故证书不迁移。∎ 推论：**TCC 必须在拼接处做同伦门；物理上“看起来连续”不构成证书迁移的理由**。

**引理 127（对齐不扩权）** 对任意对齐分数 `V_a`、任意 `ε_align≥ε_min`，有
```
Align_{V_a}(x,MP) ⊆ MP_ε(x) ⊆ MP(x) ⊆ Exec_v14^τ .
```
证明：`Align` 是 `MP_ε` 上的 `argmax`，故输出属于 `MP_ε`；`MP_ε` 只对 `MP` 加余量下界，故是子集；`MP` 的每条轨迹由定义 607 的 C2–C3 和 v14 证书保证属于 `Exec_v14^τ`。`V_a` 未出现在任何集合构造中，故改变 `V_a` 不改变可执行集。∎ 推论：**对齐错误只改变“选哪条安全轨迹”，不改变“哪些轨迹安全”**；偏好模型无法越过定义 612 的硬地板。

**引理 128（对齐遗憾界）** 若 ALC 在 `S_align` 上以概率 `1−δ_align` 给出 `|V_a−V_h|≤U_align`，`τ*` 是 `MP_ε` 上的人类最优，`τ_a=Align_{V_a}(x,MP)`，则
```
V_h(τ*) − V_h(τ_a) ≤ 2U_align + Δ_ε ,
Δ_ε = max_{MP} V_h − max_{MP_ε} V_h .
```
证明：标准 ε-近似论证：`V_h(τ*)−V_h(τ_a) = [V_h(τ*)−V_a(τ*)] + [V_a(τ*)−V_a(τ_a)] + [V_a(τ_a)−V_h(τ_a)] ≤ U_align + 0 + U_align`，其中中间项由 `τ_a` 在 `MP_ε` 上最大化 `V_a` 而非正；`Δ_ε` 是偏好风险预算造成的可加限制代价。支撑外无保证，必须退回规范轨迹或 `a_ask`。∎ 推论：**对齐失败的代价是任务 regret，不是安全越权**；但若 `V_h` 本身错设，ALC 无法检测——这正是本轮最大风险的结构性来源。

**引理 129（运动—对齐阶梯的单调退化）** 对嵌套阶梯 `MP_0⊆…⊆MP_m⊆Exec_v14^τ`，路由器取 `i*(B)=max{i:w_i≤B−B_safe,c_i 有效,ALC 有效}`，则：(i) 在 RTIC 与 ALC 有效时 `P(latency≤D)≥1−δ_t`；(ii) `π_15(x;B)∈Exec_v14^τ`；(iii) 期望授权价值 `v(B)=E[V_h(Align(MP_{i*(B)}))]` 关于 B 单调不减；(iv) 相对满档 `m` 的退化满足
```
E[v_m − v(B)] ≤ Σ_{i=0}^{m-1} P(B < w_{i+1}+B_safe)·(v_{i+1}−v_i) + Δ_ε .
```
证明：(i)(ii) 由 RTIC、ALC 与引理 127；(iii) 由嵌套与 `i*(B)` 单调；(iv) 对指标函数做伸缩求和，再把每段限制损失用 `Δ_ε` 上界。∎ 推论：**轨迹阶梯的退化是连续的、可预算的**；只要 `w_0≤B_safe`，最坏情况也落在零学习停车上。

**引理 130（中立元退化等价 v14）** 将定义 618 的四个中立元注入 CMP/SAP/MALR/TCC，则轨迹规划退化为 v14 动作级 anytime、`V_a≡const`、`ε_align=ε_max`、路由器退化为 v14 RTCR、同伦门退化为恒真；主闭环调用序列与 v14 逐位一致，再沿 v14 链退回 v13/v12/…。证明：逐端口代入定义 618，并用定义 607–617 的边界条件核对；四端口互不相交且中立元不改变 v14 任何证书检查。∎

**引理 131（预算守恒 v15）** 新增在线成本上界：TCC 复合与边界检查 ≤0.15ms/次；CMP 段扩张与剪枝 ≤0.5ms；管道不变式检查 ≤0.2ms；SAP 排序 ≤0.1ms；ALC 查表/支撑判定 ≤0.05ms；MALR 选档 O(log m) ≤0.05ms；总决策 p99 仍 ≤22ms，50Hz 保持；`B_plan` 与 `B_align` 硬预留，不从 `B_safe` 借用；离线 ALC 校准/轨迹库训练不在关键路径。证明：逐项代入复杂度表并做静态 EDF 校验 `ΣŴ_m≤B_dec`；安全切片与规划切片分别硬预留。∎

**引理 132（同伦/漂移下的重认证与安全塌缩）** 设漂移检测器或同伦分类器在拓扑/分布偏离支撑时触发；触发后 MALR 只允许第 0 档 `MP_0`（停车/退让/`a_ask`，不依赖任何学习证书）。则：碰撞/越界等物理硬违规概率不高于 v14 的对应回退；活动性损失满足
```
P(无可执行认证轨迹) ≤ P(drift) + P(ALC 失效|drift) + P(homotopy 分类错误) + P(MP_0 预算耗尽) .
```
证明：`MP_0` 由物理构造保证安全且前缀闭；漂移/同伦不匹配时定义 610 的证书不可迁移，故禁止使用 i≥1 档。∎ 推论：**拓扑变化不是用更快的轨迹去赌，而是用最保守的停车去买重认证时间**。

**引理 133（四间隙联合可加界）** 记
```
Δ_tr = J_real(τ_14) − J_sim(τ_14) ,   Δ_dis = J_real(τ_15) − J_real(τ_14) ,
Δ_motion = J_real(τ_15) − J_real(τ_14^plan) ,   Δ_align = J_human(τ_15) − J_human(τ_14) .
```
则
```
J_real(τ_15) − J_sim(τ_14) ≤ U_gap + U_dis + U_motion + U_align   （w.h.p.）
```
若考虑理想上限 `J*`，再叠加接触/组合交互项 `I_cross` 与近似项 `δ_approx`：
```
J_real(τ_15) − J* ≤ U_gap + U_dis + U_motion + U_align + I_cross + δ_approx .
```
证明：代数展开；`Δ_tr` 由 v14 TGC 的单侧共形覆盖，`Δ_dis` 由 v14 DGC 的单侧共形覆盖，`Δ_motion` 由定义 607 的管道/前缀闭证书单侧覆盖，`Δ_align` 由定义 613 的 ALC 单侧覆盖；四项各自以 ≥`1−α` 成立，联合用并集界得到 `1−α_gap−α_dis−α_motion−α_align`。负的间隙不计入收益，因为安全界只取 `max(0,Δ)`。∎ 推论：**运动/对齐间隙不能拿迁移/蒸馏预算冲抵**；新场景中四类间隙可能同向偏低，这是 v15 的根本脆弱点，必须靠四预算加性与四重漂移检测控制。

## 8. 已知风险与失效模式

1. **拼接处的假安全**：每段证书有效、边界管道看似兼容，但接触/动力学耦合在拼接处未被管道覆盖，导致“每段都认证、整条却越界”。缓解：边界处强制联合采样、保守放大 `T_H`、拼接后整条管复查、关键边界保留纯 v14 单步路径。

2. **管道过保守导致活性塌缩**：鲁棒管把不确定性放大后，可行轨迹集几乎为空，系统频繁停车。缓解：自适应管半径、分段管、把保守性显式计入 `B_plan`、允许 `a_ask` 但不允许扩权。

3. **同伦分类错误**：动态障碍或接触模式边界模糊，把不同同伦类误判为同类，复用旧证书。缓解：同伦签名加不确定性、分类置信度低于阈值即重认证、拓扑变化检测、切换时强制 `MP_0`。

4. **对齐目标本身错设**：ALC 只保证 `V_a` 接近 `V_h`，若 `V_h` 本身与人类真实价值不一致，系统会“忠实地”优化一个错误偏好。缓解：人类反馈审计、偏好多样性、把偏好限制在安全集合内、关键场景回退到规范策略。

5. **奖励劫持与分布外偏好**：对抗输入让 `V_a` 给出极端分数，或用户在支撑外选择偏好。缓解：ALC 支撑外禁止排序、对抗校准、`ε_align` 地板、`η_α` 式越界记录与拒绝。

6. **ALC 尾部校准不可靠**：安全边界是低概率区域，校准集覆盖不足，`U_align` 被低估。缓解：边界主动采样、EVT 尾部分位、保守 `U_align` 余量、漂移时禁用对齐排序。

7. **`ε_min` 设置过松或过紧**：过松则对齐仍可能贴近边界；过紧则频繁退回 `MP_0`。缓解：按任务风险分层设 `ε_min`、在线监控停车率、把 `ε_min` 纳入预注册。

8. **动态环境使管道快速失效**：高速障碍/人机共存下，管道在下一拍就过期，重规划预算不足。缓解：缩短规划时域、事件触发重规划、预测不确定性入管、保留 `MP_0` 硬预算。

9. **规划计算尖峰**：CMP 段扩张与 TCC 复合在复杂场景下组合爆炸，挤占 v14 推理预算。缓解：候选剪枝与上限、多分辨率段、`B_plan` 硬预留、提前中断返回 `MP_0`。

10. **共享轨迹库/管道的单点失效**：所有档位共享同一轨迹库或同一管道模型，一个结构性缺陷同时击穿所有档。缓解：异构轨迹库、教师影子抽查、关键场景纯 v14 路径、故障注入测试。

11. **四间隙联合低估**：新场景同时落入 v14 的迁移/蒸馏分布外与 v15 的运动/对齐分布外，四个间隙同向偏低。缓解：引理 133 的联合三角界、四预算加性、四重漂移检测、任一间隙失效即触发 `a_ask`/最低档。

## 9. 本轮最大风险

**一句话**：前缀闭轨迹证书的可靠性依赖于“每段证书的管在拼接处仍然不变”，而同伦分类器与动态障碍会把拼接边界误判为同类；一旦某段在边界处的接触/动力学耦合未被管道覆盖，系统就会在“每段都认证、每个前缀都可停、每个选择都更符合用户偏好”的表象下执行一条**整体越界**的轨迹，且安全对齐只会在错误的集合里挑一条“更讨喜”的错误轨迹。
