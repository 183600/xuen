### 第 1 轮灵感驱动研究记录（开源硬件 · 语音交互）

**灵感词**：开源硬件、语音交互

**直觉与动机**：
上一轮（v25，SRC-USC）的证书链从单机物理推进到群体语义-重构-协同，但隐含两个未审视前提：① 信任根由厂商/自签证书提供；② 人机接口是结构化、可校验的 API。受「开源硬件」启发：当 EDA/CAD/固件/BOM 全部开放时，物理安全证书（SOC/FCC/LSC）可由第三方**独立重放构建**复核，信任从「厂商声明」转向「k-of-n 可复现构建」；但**开放设计 ≠ 开放物料**，攻击者可构造外观等价、BOM 不等价的克隆，于是攻击面从「隐藏设计」转移到「物料溯源」。受「语音交互」启发：语音是概率化、可被欺骗、无法直接形式化验证的输入通道，必须经「意图识别—语义接地—授权」三级降维，且**语音不可直达执行器**；同时语音是把人类拉回风险预算协商环的天然接口，可缓解上轮 R15。核心洞见：**物理层用确定性可复现构建证书（开放验证物理），语义层用分布无关 conformal 证书加显式澄清（概率门控语义），二者在统一准入门以信任格乘积合成**。

**形式化目标**：
1. 定义开源硬件溯源证书（OSHC）：签名设计溯源哈希 DAG 𝒢_osh + SPDX/CERN-OHL 许可合规 + k-of-n 独立重放构建证明；构建等价 β(𝒟_local) ≅_ε β(𝒟_ref) 与 BOM 等价 ℬ_local ≡ ℬ_ref（替代件须附电气表征证书）。
2. 定义语音意图接地证书（VIGC）：conformal 意图集 ℙ(i∈C_intent(u))≥1-α_v；接地唯一性 |γ(i)|=1 否则触发显式澄清；说话人认证/活体 ℙ(genuine)≥1-β_v；开源麦克风证明 + 端侧处理 + 零留存的隐私契约。
3. 定义社区扩展证书（CEC）：第三方开源模块 m 的自声明证书经 USMC 单调传递复核后准入，附许可兼容与责任边界。
4. 定义不可直达执行器不变量（NDA）：语音通道能力集仅含意图队列与语义地图读权限，∀ 语音命令 a=π*(γ(i)) ∧ a∈Exec_v26。
5. 构建 v26 统一准入门（OVUC）：USMC∪SMC∪RMC∪MCC∪OSHC∪VIGC∪CEC，Exec_v26 ⊆ Exec_v25。
6. 在溯源失败 / 语音失配 / 社区模块失配三条退化路径下证明单调退化链保持。

**本轮最大风险（一句话）**：
**开源硬件使「克隆 + BOM 替换」可绕过重放构建证书（开放设计不等于开放物料），而语音的对抗音频又能在不触碰硬件信任根的情况下伪造合法意图；两者叠加时，物理信任根与语义信任根可能被同时污染，OVUC 仍给出「可复现且已接地」的假阳性。**

## 1. 关键算法骨架（在 IP-444–447 骨架上扩展）

```python
# ============================================================
# IP-448 Open-Source Hardware Provenance Certificate (OSHC)
# ============================================================
@dataclass
class OSHProvenanceCertificate:
    """溯源 DAG + 确定性重放构建 + BOM 等价 + k-of-n 独立验证"""
    design_dag: 'DesignDAG'              # 节点含 (hash, parents, spdx, copyleft, obligations)
    reference_hash: str                  # h(𝒟*)：参考开放设计根哈希
    local_build: 'BuildArtifact'         # 本地重放构建产物
    reference_build: 'BuildArtifact'     # 参考构建产物
    bom: list['BOMPart']                 # 本地物料清单
    reference_bom: list['BOMPart']       # 参考 BOM
    verifiers: list['VerifierAttestation']  # 独立验证者签名 + 重建哈希
    k: int = 3                           # k-of-n
    eps_build: float = 1e-6
    allowed_licenses: set[str] = field(default_factory=lambda: {
        "CERN-OHL-S-2.0", "CERN-OHL-W-2.0", "CERN-OHL-P-2.0", "TAPR-OHL-1.0"})

    def verify_provenance(self) -> bool:
        """DAG 完整签名 + 根哈希一致 + 许可义务闭合"""
        if not self.design_dag.is_acyclic_and_signed():
            return False
        if self.design_dag.root_hash() != self.reference_hash:
            return False
        for node in self.design_dag.nodes():
            if node.spdx not in self.allowed_licenses:
                return False
            if node.copyleft and not node.obligations_discharged:
                return False          # copyleft 披露/回馈义务未履行
        return True

    def verify_build_equivalence(self) -> bool:
        """确定性重放：锁工具链 + 功能等价"""
        if not self._toolchain_locked():
            return False              # 工具链未锁定则不可复现
        return functional_equivalent(
            self.local_build, self.reference_build, self.eps_build)

    def verify_bom_equivalence(self) -> bool:
        """物料等价；替代件必须有电气表征证书"""
        ref = {(p.part, p.vendor, p.lot) for p in self.reference_bom}
        for p in self.bom:
            if (p.part, p.vendor, p.lot) not in ref:
                if not p.substitute_certified:
                    return False
                if not p.electrical_within(self.reference_bom):
                    return False      # 阻抗/容差/温漂越界即视为不等价
        return True

    def verify_k_of_n_rebuild(self) -> bool:
        valid = [a for a in self.verifiers
                 if a.signature_valid() and a.rebuild_hash == self.reference_hash]
        return len({a.public_key_id for a in valid}) >= self.k

    def verify_all(self) -> bool:
        return (self.verify_provenance() and
                self.verify_build_equivalence() and
                self.verify_bom_equivalence() and
                self.verify_k_of_n_rebuild())


# ============================================================
# IP-449 Voice Intent Grounding Certificate (VIGC)
# ============================================================
@dataclass
class VoiceIntentGroundingCertificate:
    """conformal 意图覆盖 + 接地唯一性 + 说话人/活体 + 隐私契约"""
    utterance: 'Utterance'
    asr: 'ASREngine'
    intent_calibrator: 'ConformalCalibrator'
    semantic_map: 'SemanticMappingCertificate'
    speaker_model: 'SpeakerVerifier'
    alpha_v: float = 0.05
    beta_v: float = 0.01
    eps_g: float = 0.03
    auth_level: int = 1
    retention_sec: int = 0                # 0 = 音频不落地
    intent_set: frozenset = frozenset()
    grounded_entity: object = None
    needs_clarification: bool = False

    def verify_intent_coverage(self) -> bool:
        C = self.intent_calibrator.predict(self.asr.embed(self.utterance))
        self.intent_set = frozenset(C)
        return len(C) >= 1 and self.intent_calibrator.covered(self.utterance)

    def verify_grounding(self, parsed_referent) -> bool:
        cands = set()
        for i in self.intent_set:
            cands |= set(gamma(i, self.semantic_map.entities))
        if not cands:
            return False
        if len(cands) > 1:
            self.needs_clarification = True   # 歧义 -> 澄清，不执行
            return False
        s = next(iter(cands))
        self.grounded_entity = s
        return distance(s.geometry, parsed_referent) <= self.eps_g

    def verify_authentication(self) -> bool:
        audio = self.utterance.audio
        return (self.speaker_model.genuine_score(audio) >= 1 - self.beta_v
                and self.speaker_model.liveness(audio))  # 防重放/超声注入

    def verify_privacy(self) -> bool:
        return (self.utterance.mic_attested_open_hardware
                and self.utterance.processed_on_device
                and self.retention_sec == 0)

    def verify_authorization(self, action) -> bool:
        return risk_class(action) <= self.auth_level

    def verify_all(self, parsed_referent, action) -> bool:
        return (self.verify_intent_coverage() and
                self.verify_grounding(parsed_referent) and
                self.verify_authentication() and
                self.verify_privacy() and
                self.verify_authorization(action))


# ============================================================
# IP-450 Community Extension Certificate (CEC)
# ============================================================
@dataclass
class CommunityExtensionCertificate:
    """第三方开源模块：不采信自声明，须经溯源+许可+单调传递复核"""
    module: 'ModuleSpec'
    claimed: dict                     # {'soc':..., 'fcc':..., 'lsc':...}
    oshc: OSHProvenanceCertificate
    license_compat: 'LicenseCompatibility'
    liability: 'LiabilityRecord'

    def verify_all(self, usmc) -> bool:
        if not self.oshc.verify_all():
            return False
        if not self.license_compat.compatible(self.oshc.design_dag.licenses()):
            return False
        # 声明证书经 USMC 单调传递复核，而非直接采信第三方自签
        return usmc.transfer_from_claims(self.claimed, self.module)


# ============================================================
# NDA：语音不可直达执行器（能力隔离）
# ============================================================
class VoiceCommandAdapter:
    """能力集仅含意图队列写 + 语义地图读，永无执行器总线写权限"""
    CAPABILITIES = frozenset({"write:intent_queue", "read:semantic_map"})

    def __init__(self, vigc: VoiceIntentGroundingCertificate,
                 planner: 'Planner', ovuc: 'OSHVoiceUnifiedCertificate'):
        self.vigc, self.planner, self.ovuc = vigc, planner, ovuc

    def submit(self, parsed_referent, action_hint) -> 'IntentTicket':
        if not self.vigc.verify_all(parsed_referent, action_hint):
            return IntentTicket(rejected=True, reason="VIGC_fail")
        if self.vigc.needs_clarification:
            return IntentTicket(rejected=True, reason="clarification_required")
        plan = self.planner.from_grounded_intent(
            self.vigc.intent_set, self.vigc.grounded_entity)
        # 语音只产生 plan；plan 必须再过 OVUC，绝不直接下发执行器
        if not self.ovuc.admits(plan):
            return IntentTicket(rejected=True, reason="OVUC_fail")
        return IntentTicket(plan=plan)


# ============================================================
# IP-451 OVUC：开源-语音统一准入门 v26
# ============================================================
@dataclass
class OSHVoiceUnifiedCertificate:
    src_usc: 'SemanticReconfigCoordUnifiedCertificate'  # v25 七证
    oshc: OSHProvenanceCertificate
    vigc: VoiceIntentGroundingCertificate
    cec: CommunityExtensionCertificate = None

    def admits(self, multi_plan, sensor_data, voice_ctx=None) -> bool:
        # 1) v25 七证（USMC/SMC/RMC/MCC）
        if not self.src_usc.admits(multi_plan, sensor_data):
            return False
        # 2) 开源硬件物理信任根
        if not self.oshc.verify_all():
            return False
        # 3) 社区扩展模块（若有）
        if self.cec is not None and not self.cec.verify_all(self.src_usc.usmc):
            return False
        # 4) 语音语义输入通道（若本次计划由语音触发）
        if voice_ctx is not None:
            if not self.vigc.verify_all(voice_ctx['referent'], voice_ctx['action']):
                return False
            if self.vigc.needs_clarification:
                return False
        return True
```

## 3. 正确性论证（增量）

### 引理 13（OSHC 溯源-构建-物料-共识四重保证）
**陈述**：`OSHC.verify_all() = True` ⟺ 同时满足：
(1) 设计溯源 DAG 完整签名且根哈希等于参考 h(𝒟*)；
(2) 本地重放构建与参考**功能等价** β(𝒟_local)≅_ε β(𝒟_ref) 且工具链锁定；
(3) BOM 等价 ℬ_local≡ℬ_ref，或替代件附电气表征证书；
(4) 至少 k 个独立验证者重放哈希一致。

**证明**：
1. 哈希 DAG + 逐节点签名 ⇒ 设计文件不可篡改、依赖可追；SPDX 全在允许集且 copyleft 义务闭合 ⇒ 许可合规。
2. 确定性构建函数 β + 锁定工具链 ⇒ 同一 DAG 可重放；≅_ε 吸收浮点/版图实现差异，使「设计—构建」一致可判定。
3. **关键诚实点**：开放设计推不出开放物料，故 BOM 必须独立校验；替代件须有电气表征证书，否则外观等价克隆将通过。
4. k-of-n 按公钥去重，降低单点合谋；与签名锚共同构成 R_osh。
∎
**边界**：本引理只保证「设计↔构建」一致，不保证「构建↔实物」物料真实性——后者残留于 R16。

### 引理 14（VIGC 覆盖-接地-认证三重保证 + NDA 不变量）
**陈述**：`VIGC.verify_all(...) = True` ⟺ 同时满足：
(1) 意图 conformal 覆盖 ℙ(i∈C_intent(u))≥1-α_v；
(2) 接地唯一 \|γ(i)\|=1 且 d(s_j, referent)≤ε_g（否则触发澄清且不执行）；
(3) 说话人认证/活体 ℙ(genuine)≥1-β_v；
(4) 隐私契约（开源麦克风证明 + 端侧处理 + 零留存）。

**证明**：
1. 由 conformal prediction 的边际覆盖性直接得 (1)。
2. 接地归约为候选集基数判定：基数>1 即置 `needs_clarification` 并拒证，杜绝「猜一个」执行；基数=1 时用 Hausdorff 距离约束几何歧义 (2)。
3. 说话人分数 + 活体（唇动/骨传导/随机挑战词）联合拒绝重放与超声注入 (3)。
4. 开源麦克风链路可审计（无隐藏常开录音），端侧处理与 retention=0 构成可验证隐私 (4)。
5. **NDA**：`VoiceCommandAdapter.CAPABILITIES` 不含执行器写权限，语音只能产 plan 并再次过 OVUC，故 ∀ 语音命令 a=π*(γ(i))∧a∈Exec_v26，与引理 8 单调性一致。
∎

### 引理 15（CEC 社区扩展的证书传递不污染主链）
**陈述**：任意第三方模块 m，`CEC.verify_all=True` ⟹ m 并入后 `Exec_v26` 的成员仍全部通过 v25+v26 验证，且未验证模块被排除。
**证明**：CEC 不直接采信 `claimed(m)`，而是先过 OSHC 溯源与许可兼容，再由 `usmc.transfer_from_claims` 以引理 5–7 的单调关系复核声明证书；任一传递条件不满足即排除 m，主链不受影响。故社区扩展是「单调增量」而非「信任跳跃」。∎

### 引理 16（v26 单调退化链）
**陈述**：任意单点/组合失效下，`Exec_v26 ⊆ Exec_v25 ⊆ ... ⊆ Exec_v18` 恒成立。
**证明**：在引理 12 基础上增加三条路径：
- 溯源失败（DAG 篡改 / 构建不可复现 / BOM 不等价 / k-of-n 不足）→ `OSHC.verify_all=false` → OVUC 拒证 → 硬件降级为「不可信物料」保守包络运行或直接拒执行。
- 语音失配（覆盖失效 / 歧义未澄清 / 仿冒 / 隐私越界 / 越权）→ `VIGC.verify_all=false` → 拒语音来源命令，回退到遥操作或已认证的自主计划，USMC 单机安全保留。
- 社区模块失配 → `CEC.verify_all=false` → 排除该模块，其余计划不变。
- 组合失效取交集，单调性保持。∎

### 定理（OVUC 十二位一体完备性）
**陈述**：对任意计划 Π，`OVUC.admits(Π)=True` ⟺ Π 同时满足 v25 的十项条件，并额外满足：
(11) 开源硬件溯源/构建/BOM/共识四重达标；
(12) 语音意图覆盖/接地唯一/认证活体/隐私四重达标（若语音触发）；
(13) 社区扩展模块经单调传递复核且许可兼容（若存在）。
**证明**：由 `OVUC.admits` 的连言结构与引理 13–16 直接可得；必要性对应三类新风险未被缓解，充分性由引理 16 保证执行集单调链，形成「物理信任根—语义信任根—群体协同」的完整闭环。∎

## 6. 本轮最大风险（最终确认）

**一句话**：**开源硬件把信任根交给「可复现构建 + 物料溯源」，但开放设计推不出开放物料，克隆 + BOM 替换可在满足重放哈希的同时替换物理实体；语音的对抗音频又能绕过说话人/活体验证伪造合法意图——当「物料克隆」与「意图伪造」在同一任务上协同发生时，OVUC 会同时错认物理信任根与语义信任根，在实物与意图均被污染的情况下仍判定「可复现且已接地」，这是本轮方案最致命的假阳性。**
