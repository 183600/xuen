# 第 41 轮 · 复现优先 × 通用操作基：把 v5 证书体系钉回可对照的地面（四层架构 v6）

> 承接第 40 轮（v17：可认证流匹配 × 度量语义几何 × 证书课程，四层架构 v5）。本轮灵感词「基线复现、通用操作」不是再加一层理论，而是一次**方法论回调**：v5 的全部主张（N*≤8、漂移界≥99%、课程省 30%）都缺少一个可信的对照基线，且技能仍以「任务」为单位而非以「操作」为单位。本轮把「可复现性」做成架构内的一等公民（复现契约 + 复现门），把「通用操作」做成技能的最小可测单元（操作基 + 组合文法），二者共同给 v5 提供**可证伪的对照面**。

## 0. 直觉与动机

**灵感 1（基线复现 → 复现即契约，不是附录）**：在真实机器人研究里，一个创新点最容易死的地方不是算法不新，而是「比较不公平」。第 40 轮的 E67-E72 几乎全是「对照自己的旧版本」，等于用自己证明自己。直觉上，复现应有三层含义：a) **忠实复现**——先把最强的最简基线（解析 IK+阻抗、MPC/WBC、公开学习策略）在固定协议下复现到参考值的 ε 内；b) **等算力比较**——任何加速/成功率主张必须在同等 FLOPs/延迟预算下比较；c) **可复跑**——固定种子、确定性 reset、传感器回放、延迟注入，别人能一键重跑。把这三件事做成 **BRC 基线复现契约**，则「我们更好」不再是叙事，而是一个带置信区间、可被证伪的命题。

**灵感 2（通用操作 → 操作基，而不是任务列表）**：第 40 轮的技能（开门、倒水、递物……）是任务级的，任务一换，蒸馏、证书、课程全部重来——这正是「通用性」反而不成立的根源。直觉上，人形机器人真正复用的是一小组**操作动词**：接近、抓取、放置、推、拉、插入、旋拧、倾倒、递接、全身够取、恢复。把它们定义为带类型签名（C_ms 前后置）、参数化控制器族、运行时监控与恢复的**通用操作基 GOB**，复杂任务就是一个「操作词」序列，组合正确性由 C_ms 蕴含与球包含保证。这样任务数量爆炸被压回算子数量，跨本体迁移只需重标定参数（IP-49 几何）而不是重训策略。

**灵感 3（二者是对偶，而非两个独立模块）**：通用操作给出**比较单元**（同一 operator 在不同方法下可同题对话），基线复现给出**比较效度**（每个 operator 的 claim 先过复现门）。单独做复现，得到的是一堆互不可比的数字；单独做操作基，得到的是一套没有效度锚点的抽象。合起来才有「单元可测的技能基」：每个 operator 有**单元测试**（复现 B0 至 ε 内），每次组合有**集成测试**（op-word 达成 C_ms 后置）。第 40 轮的证书体系因此从「承诺」降级为「算子上的注解」，可被逐一检验。

**四层架构的定位变化**：v6 不新增感知/规划层，而是增加一条**横切**的复现台（IP-51），并把任务代数从「组合任务」下沉为「组合算子」（IP-52/53）。一句话：v5 回答「如何认证」；v6 回答「认证之前，比较是否合法；认证之后，结论能否被复跑」。

## 1. 形式化定义

**定义 27（通用操作基 GOB）**：\(\mathcal{O}=\{o_1,\dots,o_K\}\)，每个算子 \(o_k=(\mathrm{Sig}_k,\Pi_k,\mathcal{C}_k,\mathrm{Mon}_k,\mathrm{Rec}_k)\)：
- \(\mathrm{Sig}_k=(\mathrm{Pre}_k,\mathrm{Post}_k)\)，两者均为定义 25 的 \(C_{ms}=(\varphi_{sem},B)\)；
- \(\Pi_k\) 为算子模式：一族参数化控制器/策略，可在「解析控制（B0）」与「IP-48 流策略（B2）」之间多态实例化；
- \(\mathcal{C}_k\) 为证书注解（CertFlow ∪ 几何证书 ∪ 复现证书）；
- \(\mathrm{Mon}_k\) 为运行期监控谓词，\(\mathrm{Rec}_k\in\mathcal{O}\) 为恢复算子（复用 IP-38）。

**相对任务分布 \(\mathcal{T}\) 的通用性**：覆盖度
\[
\mathrm{cov}_{\mathcal{T}}(\mathcal{O})=\sup_{\tau\in\mathcal{T}}\ \inf_{w\in\mathcal{O}^{*}}\ \mathbf{1}\big[\mathrm{exec}(w)\models\mathrm{Post}(\tau)\big].
\]
称 \(\mathcal{O}\) 对 \(\mathcal{T}\) 通用，若 \(\mathrm{cov}_{\mathcal{T}}\ge 1-\epsilon_{cov}\) 且存在代表词长上界 \(L_{max}\) 使覆盖成立。注意这是**操作闭包**定义，不是「无限任务」的玄学；它明确允许「未覆盖区」存在，并要求实验只在该闭包内报告。

**定义 28（操作词与组合证书）**：操作词 \(w=o_{k_1}\circ\cdots\circ o_{k_m}\)，相邻接口须满足 \(\mathrm{Post}_{k_i}\vdash\mathrm{Pre}_{k_{i+1}}\)（即 \(\varphi\models\varphi'\wedge B\subseteq B'\)，定义 25）。组合证书按最坏情形合成：
\[
\kappa_{w}=\min_i\kappa_i,\qquad B_w=\sum_i B_i,\qquad h_{min,w}=\min_i h_{min,i},\qquad \varepsilon_{ode,w}=\sum_i \varepsilon_{ode,i}.
\]
并发/部分序算子（如一手扶稳、一手插入）用偏序 \(w=(V,\prec)\) 表示，仅对 \(\prec\) 上相邻的接口做蕴含检查，复杂度 \(O(|V|+|E|)\)。

**定义 29（基线复现契约 BRC 与复现门）**：\(\mathrm{BRC}=(B,m,\varepsilon,\mathcal{P},S,\Delta,\mathrm{budget})\)：
- \(B\) 为基线（B0 解析 / B1 模型 / B2 公开学习策略），\(m\) 为指标，\(\varepsilon\) 为复现容差；
- \(\mathcal{P}\) 为协议（观测、动作空间、时序、reset 分布、延迟/丢帧注入），\(S\) 为种子集，\(\mathrm{budget}\) 为算力预算；
- \(\Delta\) 为效应量与检验（配对 bootstrap + 置换检验）。

**复现门**
\[
G_{repro}=\mathbf{1}\Big[\,|m_{repro}(B)-m_{ref}(B)|\le\varepsilon\,m_{ref}(B)\ \wedge\ \mathrm{compute\ parity}\,\Big].
\]
门关时，任何「优于 B」的 claim 判为**无效**（invalid），而非「未达标」——这是与第 40 轮实验设计最重要的区别：先判**比较是否合法**，再判**方法是否更好**。

**定义 30（复现赤字与分离带）**：对任务 \(\tau\)，记基线复现边际 \(m_B(\tau)=m_{repro}(B,\tau)/c_B\)、配对效应量 \(d(\tau)=(m_{ours}(\tau)-m_{repro}(B,\tau))/\sigma_{pooled}\)。定义
\[
R(\tau)=\max\!\big(0,\,1-m_B(\tau)\big),\qquad
\mathcal{B}_{sep}=\{\tau:\delta_{lo}\le d(\tau)\le\delta_{hi}\}.
\]
\(R(\tau)\) 表示「基线在该任务上已接近失效」——此时任何方法都容易「赢」，比较信息量最低；分离带则选「两法差异刚好可测」的任务，统计功效最高。课程采样从第 40 轮的「能力边缘」扩展为**能力边缘 × 分离边缘**：
\[
P(\tau)\ \propto\ \exp\!\Big(-\frac{(D(\tau)-D_c)^2}{2\sigma_D^2}\Big)\cdot \mathbf{1}[\tau\in\mathcal{B}_{sep}]\cdot \mathrm{replay}_w(\tau).
\]
即：只在**能分辨方法差异**的任务上花算力，避免用弱基线刷出的假提升。

**定义 31（复现证书 CertRepro）**：\(\mathrm{CertRepro}=(\varepsilon_{repro},S,\mathrm{budget},\Delta,\rho)\)，其中 \(\rho\) 为独立种子复现率阈值；并入 CertBundle。一个 IP 只有在 \(\mathrm{CertRepro}\) 通过、且被**独立种子重跑**（replication rate ≥ ρ）后才允许写入产物区；否则进入「待复现」分区，不得作为结论。

## 2. 三大产出设计

### 2.1 IP-51 REPRO-BENCH（可复现基线台）
1. 三层基线：B0 解析（IK+阻抗/FSM），B1 模型（MPC/WBC），B2 公开学习策略（锁定 commit + 权重哈希）。
2. 冻结世界协议：固定种子、确定性 reset、传感器回放、延迟/丢帧注入、**算力计量器**（FLOPs + 端到端 p99）。
3. 自动复现卡：指标表 + 配对 bootstrap CI + 效应量 + 失败分类（近碰撞/超时/语义违约/证书违约）。
4. CI 回归门：任何 IP 的 claim 必须附 baseline card，缺卡即构建失败；基线自身漂移超 ε 触发全线告警。

### 2.2 IP-52 GENERAL-OP-BASIS（通用操作基）
1. \(K\approx 10\) 个操作动词：接近/抓取/放置/推/拉/插入/旋拧/倾倒/递接/全身够取（+ 恢复算子）。
2. 算子模式多态：同一签名下可绑定 B0 解析控制器或 IP-48 流策略，便于**同题对比**与**逐算子认证**。
3. 组合文法：op-word 由任务代数（IP-47）生成；接口用 C_ms 蕴含 + 球包含检查；失败可回退到前一算子（利用 \(\mathrm{Rec}\)）。
4. 跨本体重映射：算子参数定义在任务/工具坐标系，换本体只做标定与工作空间映射（IP-49 提供度量几何）。
5. 单元测试：每个算子必须先复现 B0 至 ε 内才能进入注册表；未过测的算子在总线中标记为 experimental。

### 2.3 IP-53 REPRO-GATED-EVOLUTION（复现门控的演化，升级 IP-50）
1. 难度仍用证书赤字 \(D(\tau)\)（定义 26），但采样加分离带约束（定义 30），只在可分辨区耗费算力。
2. **算子级**课程：选择「证书赤字 × 复现赤字 × 分离度」最大的算子去蒸馏，而不是选择整个任务。
3. 复现门控重颁：证书只有在复现卡通过后才允许热更新；否则回滚契约（比第 40 轮的「超界重颁」更保守）。
4. 负结果账本：未通过复现的 IP 自动移入 negative-results 分区，保留失败协议与种子，防止「换个 seed 再试」的隐性 p-hacking。

## 5. 本轮最大风险

**一句话**：最大风险是**基线选择的偏差**——若 B0/B1 被无意识地选弱、或复现协议与真实部署错配，「可复现」只会把确认偏误包装得更精致；通用操作基把任务切成可测单元并不能消除这种偏差，必须靠**预注册基线集 + 第三方盲复现**守门。

## 2. 关键算法

### IP-51 基线复现（伪代码）
```
def reproduce_baseline(B, protocol, seeds, budget, eps):
    cards = []
    for s in seeds:                          # 固定种子，确定性 reset
        env  = protocol.freeze(seed=s)       # 传感器回放 + 延迟/丢帧注入
        cards.append(rollout(B, env, budget))# 记录 FLOPs + p99 + 失败分类
    m     = paired_bootstrap_ci(cards)
    R_B   = abs(m.mean - B.ref) / B.ref
    gate  = (R_B <= eps) and (m.flops <= 1.1*budget.flops) \
                         and (m.p99   <= 1.1*budget.p99)
    return ReproCard(B, m, R_B, gate, seeds)

def reproduce_all(eps=0.05):
    return {b: reproduce_baseline(b, PROTOCOL, SEEDS, PARITY, eps)
            for b in (B0, B1, B2)}           # 三基线全过才算 G_repro=1
```

### IP-52 操作基单元测试与组合（伪代码）
```
def admit_operator(o, baseline=B0, eps=0.05):
    card = reproduce_baseline(baseline, o.protocol, SEEDS, PARITY, eps)
    if not card.gate:
        return Registry.mark(o, status="experimental", card=card)  # 禁止作为结论
    return Registry.admit(o, cert=CertRepro(card))                 # 进入总线

def compose_op_word(word, state):
    for o in word:
        if not implies(state.post, o.pre):          # C_ms 蕴含 + B⊆B'
            return Fallback(prev=o.rec, state=state)
        state = execute(o, state)                   # Π 多态：B0 或 IP-48
        if not o.monitor(state):
            return Fallback(prev=o.rec, state=state)
    return state                                    # 满足末算子 Post
```

### IP-53 复现门控演化（伪代码）
```
def repro_gated_curriculum_step(band, sep_band, target=0.7):
    cand = sample_tasks(band, filter=sep_band)      # 只取可分辨任务
    op   = argmax_o [ D(op) * (1 - R(op)) * sep(op) ]# 证书×复现×分离
    distill(op); recert(op)
    card = reproduce_baseline(prev_version(op), PROTOCOL, SEEDS, PARITY, EPS)
    if card.gate:
        Registry.hot_reload(op.contract)            # 过门才允许热更新
    else:
        Registry.rollback(op)                       # 否则回滚契约
        ledger.log_negative(op, card)               # 负结果留档，防 p-hacking
    band.center += eta * (success_rate(cand) - target)  # Robbins-Monro
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 正确性保证 |
|---|---|---|
| 基线复现 | \(O(|S|\cdot T_{rollout})\)，|S|=5 种子 | 配对 bootstrap CI；复现误差≤ε 才开门 |
| 算子单元测试 | \(O(K\cdot|S|\cdot T_{op})\)，K≈10 | 未过测算子不得作为结论（注册表强制） |
| 操作词组合 | \(O(|V|+|E|)\) | C_ms 蕴含传递 + κ=min、B=Σ、h=min 的最坏情形合成 |
| 覆盖度估计 | \(O(|\mathcal T|\cdot|w|)\) | 只在已测闭包内报告，未覆盖区不结论 |
| 分离带采样 | \(O(1)\)（按 \(d(\tau)\) 预索引） | 只在统计功效高的任务耗算力 |
| 课程步 | \(O(K)\)/步 | Robbins-Monro 收敛；复现门关闭即回滚 |

## 4. 实验设计（E73-E78，硬门槛）

| 实验 | 指标 | 门槛 |
|---|---|---|
| E73 基线复现保真 | B0/B1/B2 复现值 vs 参考值相对误差；3 次重跑方差 | 误差≤5%；方差≤2%；三基线全过 |
| E74 等算力诚实性 | 同等 FLOPs/p99 预算下的相对提升 | 无可 >10% 算力优势的「加速」claim |
| E75 操作基覆盖与组合 | 任务覆盖度（词长≤5）；组合成功率 | 覆盖≥90%；组合成功≥85% |
| E76 跨本体迁移 | 同操作基换本体（人形↔轮式臂），仅标定 | 成功率下降≤15% |
| E77 复现门控的效度 | 留出种子上效应量复现率；replication rate | 5 种子复现率≥80%，p<0.01 且 CI 不含 0 |
| E78 端到端 UniBot 任务套 | 成功率 vs 最佳复现基线；证书违约率 | 绝对提升≥10%；违约<0.5%；数字可一键复跑 |

失败即回退：E73 任一基线复现失败 → 冻结全部「优于基线」结论，本轮退化为纯复现报告；E75 覆盖不足 → 缩小 \(\mathcal{T}\) 至已验证算子闭包，禁止外推。

## 5. 风险与缓解

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 基线选择偏差（选弱基线刷分） | 高 | 预注册基线集 + 三层基线（B0/B1/B2）+ 第三方盲复现；E73/E77 守门 |
| 复现协议与真实部署错配（sim2real 协议差） | 高 | 协议中显式注入延迟/丢帧/传感噪声；真机小样本校准协议误差 |
| 算子基覆盖不足（闭包外任务） | 中 | 覆盖度硬门槛 E75；未覆盖区明示不结论，禁止外推 |
| 操作词组合接口脆弱（B 球求和过保守） | 中 | 仅对任务相关子空间做蕴含检验；必要时用联合分布而非独立求和 |
| 等算力口径可被钻空子（只报 FLOPs 不报 p99） | 中 | 双预算（FLOPs + p99）同时满足；E74 自动核查 |
| 负结果泄漏进主结论（换 seed 重试） | 中 | 负结果账本 + 预注册种子集 + 复现率阈值 ρ |

## 6. 本轮最大风险

**一句话**：最大风险是**基线选择的偏差**——若 B0/B1 被无意识地选弱、或复现协议与真实部署错配，「可复现」只会把确认偏误包装得更精致；操作基把任务切成可测单元并不自动消除这种偏差，必须靠预注册基线集与第三方盲复现守门。
