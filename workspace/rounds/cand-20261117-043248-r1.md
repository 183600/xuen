# 第 11 轮（新灵感循环第 2 轮；本轮灵感：「异常检测」×「UniBot世界挑战赛」）
> **基线**：第 10 轮 MetricVoiceGauge-NCD（定义 540–553；引理 87–95；实验 E571–E588）。
> 本轮纪律：**未知分布 + 可证交付**。不推倒 v10：NGE/DSL/CC/CWM/CAE/NCP 与 MetricVoiceGauge 九不变式全部保留；新组件一律以**中立元**接入，失效即严格退回 v10（引理 103），再沿 v10 九级链退回 v9/v8/v7。本轮只做两件事：把"意外"变成可校准的**异常证书**，把"隐藏测试"变成可证伪的**挑战证书**。

## 0. 直觉与动机

**灵感 1（异常检测 → 异常证书，而不是异常急停）**
直觉：v10 的所有证书都隐含一个前提——**部署分布落在校准分布之内**。可真实失败几乎总是"校准集里没有的东西"：没见过的物体、没出现过的接触模式、突然改变的照明/摩擦/网络延迟、一个不在规范库里的文化场景、或者仿真到真机的系统性偏差。异常检测的价值不是再报一次"OOD"，而是把"意外"变成一个**有统计语义的量**：用共形非一致性分数把任意黑箱检测器变成有效 p 值；用自适应共形推断（ACI）在分布漂移下控制长期误报率；用共形 e-process 给出**随时可停**的报警保证。更关键的是，异常不能被当成二元急停开关，否则机器人会在最需要行动时僵死。我们把它做成一张**异常证书 Ĉ_anom**：输出"当前最多允许哪一级自主性"，异常越强越保守，但始终有安全的下一步。还要监控"监控器"本身——证书残差、预测区间、传感器交叉校验的异常，是发现模型已经悄悄失效的最后一道信号。

**灵感 2（UniBot 世界挑战赛 → 挑战证书，而不是排行榜点估计）**
直觉：把 UniBot 世界挑战赛抽象成一个评测协议：**公开验证集 + 隐藏测试集 + 多条赛道混合 + 有限提交次数 + 排行榜**。隐藏测试的赛道权重、场景分布、甚至评测环境都可能与公开集不同；只报一个平均分，等于对一个没有保证的分布做点估计。我们要把"拿高分"改写成"做出一个在隐藏数据上仍然站得住的统计声明"：用 Learn-then-Test（LTT）逐赛道控制风险，用 anytime-valid 置信序列允许随时停止而不抬高错误率，用"逐赛道认证 ⇒ 任意未知混合权重下认证"的凸性避免猜权重，用公开-隐藏漂移审计检测排行榜过拟合。挑战赛的核心不是"比别人高 0.1 分"，而是**在没见过的世界上仍可证地交付**。可加金丝雀/绊线任务作为评测完整性检查，防止用测试集特征或规则漏洞刷分。

**灵感 3（二者合流 → 未知分布下的可信度闭环）**
直觉：异常检测与挑战赛其实是同一个问题的两个时间尺度。异常检测是**在线、逐步**地问："此刻是否还在已知世界？"挑战证书是**离线、聚合**地问："在未知世界里，我们还能不能可证地交付？"二者共用同一套共形/e-process 数学，并共享同一个可信度状态 κ_t=(p_t,M_t,l_aut,Ĉ_anom,Ĉ_chal)。闭环是：检测到异常 ⇒ 降低自主等级、收紧证书余量 ⇒ 在异常分层上重做因果归因 ⇒ 若机制在异常层不成立，禁止休眠/迁移 ⇒ 更新挑战风险预算与提交策略。**异常检测回答"还在不在已知世界"，挑战证书回答"在未知世界还能不能可证地拿分"**。

**与 v10 最大风险的关系**
v10 的最大风险是未观测人类意图 H 同时污染规范信念 b_ν 与因果模型。H 往往不会直接露脸，而是以"异常"的形式出现：人类行为超出规范 HMM 的支撑、接触结果偏离 CWM 的预测、某个技能只在异常场景里显得有效。于是我们做三件事：一是把异常水平作为**干预前**的分层变量，做异常分层 ACE；二是加入**安慰剂模块**（设计上无因果作用的空模块）作为负对照，若它在某异常层出现"因果效应"，该层大概率被 H 混杂，只能报敏感性界；三是异常持续时禁止因果迁移与 ID 休眠，把不确定性转成一次人类可纠正的询问。异常检测不能消灭 H，但能把"自信地因果错误"降级为"明确地不知道"。

## 1. 研究问题（轮次升级版）

- **Q1（异常证书的统计有效性）**：在非可交换、非平稳的具身流上，如何把多模态异常分数变成有分布无关误报控制的证书，并给出"漏检"的诚实刻画而不是虚假保证？异常证书如何与 v10 的物理/接触/规范证书合取而不把系统压成僵死？
- **Q2（挑战证书的可证性）**：在隐藏赛道权重未知、提交次数有限、公开-隐藏可能漂移的条件下，如何给出逐赛道风险控制与 anytime-valid 分数下界，并在漂移被检测到时自动撤销声明？
- **Q3（异常分层的因果可信度）**：异常分层能否识别/界定 v10 的未观测 H？什么时候可以用异常层内的 ACE，什么时候只能报敏感性界、禁止迁移与休眠？
- **Q4（安全-活性-算力三角）**：异常门控、挑战鲁棒规划与多模态共形校准会不会造成过度保守、僵死或实时性崩溃？如何在任意算力预算下只降低精度、不降低安全性？

## 2. 设计原则（在 P13–P15 基础上新增 P16–P19）

**P16 异常可证律（Anomaly Certification）**
任何异常信号都必须先被校准成共形 p 值或 e-process，禁止直接用原始阈值触发行为切换。异常输出是一张证书 `Ĉ_anom=(p_t,M_t,α_t,l_aut,G_t,cov_t,reason)`，其中 `l_aut` 是**允许的最高自主等级**，不是布尔急停。异常证书必须包含"监控器的监控器"：证书残差、预测区间残差、传感器交叉校验至少各一路。

**P17 单调保守律（Monotone Conservatism）**
异常只能减少候选集、收紧余量、降低自主等级、增大敏感性界，**绝不能**放宽任何 v10 已适用的证书或提高自主等级。异常证书的中立元是 `p≡1, M≡1, l_aut≡0`（完全等价于 v10）。自主等级允许有滞回与驻留时间，但升级（更保守）立即生效、降级（更放行）必须经过 `T_dwell` 且无新异常。

**P18 挑战可证律（Challenge Certification）**
任何关于隐藏测试性能的声明都必须是逐赛道的 LTT 证书或 anytime-valid 置信序列，禁止用单次排行榜点估计替代。报告必须同时给出赛道集合、风险预算、FWER/置信水平、漂移审计状态与可复现的评测哈希。公开-隐藏漂移报警时，挑战证书立即撤销，只能报告"未认证"。

**P19 异常分层因果律（Anomaly-Stratified Causality）**
因果归因与迁移必须按**干预前**异常层 G 分层；后处理异常层只能用于诊断，不能用于 ACE 估计（避免选择偏差/对撞偏差）。每个异常层必须有安慰剂负对照；安慰剂效应显著或跨层异质性检验拒绝时，只能报告敏感性界，禁止据此休眠、迁移或冻结归因。

## 3. 与基线的接口（如何退化）

- **异常端口失效**（CAM/AnomCert/AG 任一不可用）⇒ 注入中立项 `p≡1, M≡1, l_aut≡0`，不门控、不收紧，执行路径严格等价 v10；
- **挑战端口失效**（CRC/SA 任一不可用）⇒ 不输出挑战证书，只保留 v10 的常规评测与报告；挑战端口不影响执行安全，只影响"声明"；
- **ASA 失效** ⇒ 退回 v10 CAE 的相关/因果估计，不做异常分层；
- **CRP 失效** ⇒ 退回 v10 NCP 的规范-因果灵巧目标，异常证书仍可只做门控；
- **全部失效** ⇒ MetricVoiceGauge-NCD v10，再沿 v10 九级链退回 v9/v8/v7/v6；
- **安全继承**：物理/接触/规范证书始终是合取项；异常证书与挑战证书只能删候选、收紧余量、撤销声明，不能绕过 v10 任何适用证书（引理 99）。

## 4. 预期贡献

1. **异常证书与自主等级门控**：把多模态共形检测、ACI、e-process 合成一张可退化、可解释、可证明"只收紧不放开"的在线证书，并用自主等级阶梯替代二元急停，兼顾安全与活性；
2. **挑战证书与漂移审计**：用逐赛道 LTT + anytime-valid 置信序列 + 未知混合权重的凸性界，把隐藏测试性能变成可证伪声明；用公开-隐藏漂移审计与金丝雀任务对抗排行榜过拟合；
3. **异常分层因果**：把异常水平变成干预前分层变量与负对照触发器，直接修补 v10 的 H 混杂最大风险；不可识别时只报敏感性界并禁止迁移/休眠；
4. **统一闭环**：检测—门控—收紧—重归因—挑战预算共享同一可信度状态，实验 E589–E606 覆盖误报控制、漂移、隐藏测试、因果混杂与端到端挑战赛。

## 5. 本轮最大风险

**一句话**：共形保证只约束"在校准分布内的误报率"，对真正决定隐藏测试成败的未知异常**没有检出保证**；一旦异常静默通过，异常证书会以分布无关的置信度为一个已经失效的世界模型背书，而挑战证书会把这种失效包装成"统计上可证的高分"。

**定义 554（多模态异常分数与共形 p 值）** 对模态 m 与异常层 g，记标定分数 `{s_{m,i}}`。在线观测 x_t 的非一致性分数 `s_{m,t}=s_m(x_t)`，其分层共形 p 值为
```
p_{m,t} = (1 + #{i ≤ n_{m,g}: s_{m,i} ≥ s_{m,t}}) / (n_{m,g}+1)
p_t    = min(1, M · min_m p_{m,t})
```
其中 M 为模态数，第二式是 Bonferroni 合成，控制多模态族的误报。s_m 至少包含五路：感知能量（开放集物体/布局）、动力学残差（CWM 预测区间）、接触残差（力/滑移/模式后验）、规范残差（b_ν 与 STL 残差）、证书残差（预测余量 vs 实际余量）。**禁止**用单一重建误差充当全部异常证据。

**定义 555（自适应共形推断 ACI）** 在线维护
```
err_t   = 1{p_t ≤ α_t}
α_{t+1} = clip(α_t + γ(α − err_t), [α_min, α_max])
```
ACI 不假设可交换性；它把长期误报率拉回名义值，即使分布发生任意（甚至对抗性）漂移。α_t 的裁剪区间与 γ 由 E591 标定。

**定义 556（共形 e-process 与 anytime 报警）** 取可预测的 `λ_t ∈ [0, 1/α_t)`，定义
```
e_t = 1 + λ_t(1{p_t ≤ α_t} − α_t),   M_t = Π_{i≤t} e_i
```
若 `M_t ≥ 1/δ` 则触发 anytime 报警。该报警允许在任意时刻停止/提交而不抬高误报，适配挑战赛的有限提交与"看到结果再决定是否继续"的评测协议。其有效性依赖：给定历史后 p_t 超均匀（在线共形或分块可交换性保证）。

**定义 557（异常证书 Anomaly Certificate）**
```
Ĉ_anom = (p_t, M_t, α_t, G_t, l_aut, cov_t, reason)
```
给定分级阈值 `α^(0) > α^(1) > α^(2) > α^(3)` 与 `δ^(0) > … > δ^(3)`，限制等级定义为满足 `p_t > α^(l)` 且 `M_t < 1/δ^(l)` 的最大 l；若无满足则 `l=3`。`cov_t` 是当前异常层滑窗内的共形覆盖率，`reason` 是 p 值最小的模态（用于解释与日志）。Ĉ_anom 不是布尔量：它给出**当前允许的最严限制等级**，并随证据单调收紧。

**定义 558（自主等级门控与滞回）** 限制等级 l 的执行语义：
- l=0：完整 v10 候选集与证书；
- l=1：保守模式——`K_eff←max(1,⌊K_eff/2⌋)`，证书余量按当前异常层共形分位数膨胀，速度/力上限下调，只允许已验证技能；
- l=2：询问/保持——只执行 a_ask（定义 544）或接触安全 hold，禁止新接触与新规范假设；
- l=3：安全停机/退回安全状态。
块 ζ 可执行当且仅当 `l_aut ≤ ℓ(ζ)`。升级（l 变大）立即生效；降级（l 变小）需连续 `T_dwell` 步无新异常且 `M_t < 1/δ^(0)`。滞回避免在阈值附近抖振。

**定义 559（Mondrian 分层共形）** 按 `(m,G)` 分层，在每层内独立计算 p 值。若层内标定与在线分数可交换，则层内条件误报率 ≤α；这避免池化标定被多数正常样本淹没，使稀有异常层仍保有名义覆盖。分层变量 G 必须是**干预前**可得的场景/异常上下文；后处理异常层只能用于诊断，不能用于准入证书（引理 101）。

**定义 560（挑战分布与隐藏测试）** 挑战分布
```
D_chal = Σ_{j=1..J} w_j D_j,   w ∈ Δ^{J−1}, w 未知
```
公开集分为 dev 与 audit；隐藏测试从 D_chal 采样，提交次数有限。赛道 j 的损失 `L_j∈[0,1]`，风险 `R_j=E_{D_j}[L_j]`。目标是给出**逐赛道**证书，而不是猜测 w。

**定义 561（逐赛道 LTT 风险证书）** 对每个赛道 j，在标定集上用 Learn-then-Test 选择策略/阈值 λ_j，使经验风险低于预算 ε_j 并留出统计裕度；在独立 audit/隐藏反馈上对 `H0: R_j ≥ ε_j` 计算 p 值（Hoeffding 或 empirical Bernstein）。以 Bonferroni 在 J 个赛道上控制 FWER ≤δ：若全部拒绝，则证书声明 `∀j: R_j < ε_j`。由凸性，对任意未知 w，
```
R_chal = Σ_j w_j R_j ≤ Σ_j w_j ε_j ≤ max_j ε_j
```
因此"逐赛道认证 ⇒ 任意混合权重认证"，无需知道 w。

**定义 562（挑战分数 anytime-valid 置信序列）** 对 bounded 分数 `S_t∈[0,1]`，维护下置信界 `LCB_t`，满足
```
P(∀t: E[S] ≥ LCB_t) ≥ 1−δ
```
（Howard 时间均匀 Hoeffding 或 betting 构造）。报告区间 `[LCB_t,1]`；当 `LCB_t ≥ s_target` 才可声明达标。该序列对可选停止、重复查看和有限提交次数均有效；禁止用单次排行榜分数替代。

**定义 563（公开-隐藏漂移审计）** 若挑战赛返回隐藏集聚合分数/回放，则对公开 audit 与隐藏反馈做两样本 e-process（MMD 或能量距离）；若只返回聚合分数，则在分数序列上做变点/两样本检验。定义报警 `A_t=1` 当 e-process ≥1/δ_shift。加入一组**金丝雀任务**（已知期望分数/已知应失败项）作为绊线；若金丝雀结果偏离预期，同样报警。报警即撤销挑战证书，只能报告"未认证"，并把执行侧限制等级至少提升到 1。

**定义 564（异常分层因果效应）** 取**干预前**异常层 `G=g(p_{t−})`，定义
```
ACE_m^g = E[Y | do(A_m=1), G=g] − E[Y | do(A_m=0), G=g]
```
层内可用后门调整或 v10 的工具变量。若 G 只能在干预后测量，则只用于诊断与敏感性分析，禁止用于 ACE 点估计（避免对撞/选择偏差）。跨层用异质性检验（Cochran Q / bootstrap）检验 `ACE_m^g` 是否不变。

**定义 565（安慰剂负对照）** 设 A_∅ 是设计上无因果作用的空模块/空技能（例如只写日志、不改变执行的随机开关）。在每层 g 估计 `ACE_∅^g`。若其置信区间排除 0，则该层存在未观测混杂（或实现不惰性）的证据；此时把敏感性参数提高到 `Γ_g`，报告 `B_Γ^g`，并禁止在该层做因果迁移与 ID 休眠。安慰剂检验是诊断，不是无混杂的充分证明。

**定义 566（挑战鲁棒目标）** 对候选块 ζ：
```
J_chal(ζ) = min_j [ LCB_j(score(ζ)) − λ_j · UCB_j(risk(ζ)) ]
subject to  v10 物理/接触/规范证书 valid
          ∧ l_aut ≤ ℓ(ζ)（定义 558）
          ∧ ∀j: UCB_j(risk(ζ)) ≤ ε_j
          ∧ 异常预算 P(l_aut ≥ 2) ≤ b_a
```
ζ*=argmax J_chal；若鲁棒可行集为空，返回 a_ask（l=2）或安全停机（l=3）。该目标把"排行榜平均分"替换为"最坏赛道下界减风险"，与挑战证书的逐赛道语义一致。

**定义 567（v11 中立元表）**

| 新组件 | v^⊥ | 等价退化点 |
|---|---|---|
| CAM/AnomCert/AG | p≡1；M≡1；l_aut≡0；不收紧 | v10 执行路径 |
| CRC/SA | 不输出挑战证书；只报 v10 常规评测 | v10 评测协议 |
| ASA | c_m^do←v10 CAE；不分层 | v10 归因 |
| CRP | J_chal←v10 NCP 目标 | v10 规划 |
| v10 全部组件 | 沿用 v10 定义 553 的中立元 | v10 九级链 |

# IP-363 ConformalAnomalyMonitor
class ConformalAnomalyMonitor:
    def __init__(self, detectors, calib_scores, alpha=0.05, gamma=0.01,
                 alpha_bounds=(0.01, 0.2), delta=0.01):
        self.detectors = detectors          # 多模态：感知/动力学/接触/规范/证书残差
        self.calib = calib_scores           # calib[(m,g)] = 排序后的非一致性分数
        self.alpha0, self.gamma = alpha, gamma
        self.alpha_t = alpha
        self.a_lo, self.a_hi = alpha_bounds
        self.delta = delta
        self.M = 1.0

    def p_value(self, m, g, s):
        scores = self.calib[(m, g)]
        # 定义 554：分层共形 p 值
        k = bisect_left(scores, s)
        return (1 + len(scores) - k) / (len(scores) + 1)

    def update(self, obs, stratum):
        ps = {m: self.p_value(m, stratum, d.score(obs))
              for m, d in self.detectors.items()}
        p = min(1.0, len(ps) * min(ps.values()))       # Bonferroni
        err = 1.0 if p <= self.alpha_t else 0.0
        self.alpha_t = clip(self.alpha_t + self.gamma * (self.alpha0 - err),
                            self.a_lo, self.a_hi)      # 定义 555
        lam = min(0.9 / max(self.alpha_t, 1e-6), 1.0)  # 可预测下注
        self.M *= 1.0 + lam * (err - self.alpha_t)     # 定义 556
        return ps, p, self.alpha_t, self.M


# IP-364/365 AnomalyCertifier + AutonomyGovernor
class AnomalyCertifier:
    def __init__(self, thresholds, deltas, dwell=20):
        self.a = thresholds     # a[0] > a[1] > a[2] > a[3]
        self.d = deltas         # d[0] > ... > d[3]
        self.dwell = dwell

    def certify(self, p, M, alpha_t, g, cov, reason):
        l = 3
        for cand in (0, 1, 2, 3):                     # 定义 557
            if p > self.a[cand] and M < 1.0 / self.d[cand]:
                l = cand
                break

class AutonomyGovernor:
    def __init__(self, delta0, dwell=20):
        self.l_prev, self.counter = 0, 0
        self.dwell, self.delta0 = dwell, delta0

    def update(self, cert):
        l_new = cert.l_aut
        if l_new > self.l_prev:                       # 升级立即生效
            self.l_prev, self.counter = l_new, 0
        elif l_new < self.l_prev:                     # 降级需驻留（定义 558）
            self.counter += 1
            if self.counter >= self.dwell and cert.M < 1.0 / self.delta0:
                self.l_prev, self.counter = l_new, 0
        else:
            self.counter = 0
        return self.l_prev

## 3. 推导

**引理 96（共形误报控制）** 在层内标定与在线分数可交换时，定义 554 的 p 值满足 `P(p_t ≤ α) ≤ α`；多模态 Bonferroni 合成仍满足族误报 ≤α。证明：标准共形 p 值在可交换性下超均匀；Bonferroni 对 M 个检验给出 `P(∃m: p_m ≤ α/M) ≤ α`。∎

**引理 97（ACI 的有限时间长期误报界）** 若 `α_t` 被裁剪在 `[α_min,α_max]`，则对任意（含对抗性）序列，
```
| (1/T) Σ_{t=1..T} err_t − α | ≤ (α_max − α_min) / (γT)
```
证明：由 `α_{t+1}=α_t+γ(α−err_t)` 求和得 `α_{T+1}−α_1 = γ(Tα − Σ err_t)`，整理并取绝对值得界。∎
**推论 97.1**：误报率不需要可交换性即可被拉回名义值；但该界**不约束漏检**，漏检由异常检测器的功效决定（见风险 1）。

**引理 98（e-process 的 anytime 有效性）** 若 `λ_t` 可预测且 `0≤λ_t<1/α_t`，并给定历史后 `P(p_t≤α_t|F_{t−1})≤α_t`，则 `M_t` 是非负上鞅，`E[M_t]≤1`；由 Ville 不等式，
```
P(∃t: M_t ≥ 1/δ) ≤ δ
```
证明：`E[e_t|F_{t−1}] = 1 + λ_t(P(p_t≤α_t|F_{t−1})−α_t) ≤ 1`；乘积鞅性 + Ville。∎
该引理说明"随时看排行榜再决定是否提交"不会抬高误报；它不保证在分布漂移后 p 值仍超均匀，故与 ACI 并联使用。

**引理 99（异常证书的安全继承与单调性）** 若异常端口对每个限制等级 l 只从 v10 候选集中删除、收紧余量或替换为 a_ask/停机（即 `C_l ⊆ C_0`，`l` 越大集合越小），则 v11 的执行集是 v10 安全集的子集；中立元 `p≡1,M≡1,l=0` 时相等。证明：按定义 558 与 v10 引理 95，物理/接触/规范证书仍是合取项；异常只增加合取约束或替换为构造安全的 a_ask/停机。∎

**引理 100（门控活性与无僵死）** 设限制等级有限、升级立即、降级需 `T_dwell`、l=2 时执行 a_ask 且 `T_ask` 后 escalate、l=3 为安全停机。则系统不会无限期停留在自主等待：要么在 `T_dwell` 内异常消退并降级，要么在 `T_ask` 内升级为人类确认/安全停机。证明：由定义 558 的驻留与定义 544 的 escalate 出口直接得到；活性以人类确认或安全停机为终点。∎

**引理 101（Mondrian 条件覆盖）** 对每个异常层 g，若标定与在线分数在层内可交换，则 `P(p_t≤α|G_t=g)≤α`。因此层内误报受控，不会因稀有层样本被池化而失效。若 G 取后处理变量，则该条件概率不再是干预前分布的性质，只能作诊断，不能作为准入证书（定义 559/564）。∎

**引理 102（LTT 挑战证书与未知混合权重）** 若各赛道 audit 样本独立、损失有界、逐赛道 LTT 在 Bonferroni 下控制 FWER≤δ，则以概率 ≥1−δ 有 `∀j: R_j≤ε_j`，从而对任意未知 `w∈Δ`，`R_chal=Σw_jR_j≤max_jε_j`。证明：并集界 + 凸性；无需估计 w。∎
**推论 102.1**：隐藏赛道权重不可知时，最坏情况界由最大赛道预算决定；若需更紧的加权界，必须对 w 加额外假设或使用漂移审计后的在线权重估计，且必须标记为"条件声明"。

**引理 103（中立元退化等价 v10）** 将定义 567 的中立元分别注入异常端口、挑战端口、ASA、CRP，则执行路径、候选集、证书判据与归因量逐一退化为 v10：`p≡1` 使 l=0、无门控；`Ĉ_chal` 缺省使评测退回 v10；ASA 退回 CAE；CRP 退回 NCP。证明：逐端口代入定义 554–566 并消去恒真/恒空项，即得 v10 程序；再由 v10 引理 93 继续退回 v9/v8/v7/v6。∎

**引理 104（异常分层因果的识别、负对照与不不变惩罚）** 设 G 为干预前异常层且对 `(A_m,Y)` 满足层内后门/IV 条件，则 `ACE_m^g` 可识别。若安慰剂 `ACE_∅^g` 的置信区间排除 0，则该层存在混杂（或安慰剂非惰性）证据，必须把敏感性参数提高到 `Γ_g` 并报告 `B_Γ^g`，且禁止在该层休眠/迁移。若跨层异质性检验拒绝 `ACE_m^g` 不变，则 v10 的 `S*` 不能用于异常层间的长时预测/迁移。证明：层内后门/IV 的标准识别；安慰剂是负对照，显著即拒绝"无混杂"；异质性检验拒绝即拒绝机制不变。∎
**注 104.1**：安慰剂显著不构成"必然混杂"的证明（也可能是实现非惰性），但作为**保守触发器**足够：它把该层从"可迁移"降为"只报界"。

**引理 105（漂移下挑战证书的撤销而非保证）** 若隐藏分布与公开分布不同，引理 102 的逐赛道可交换性前提可能失效，证书**不自动迁移**。漂移审计在无漂移时误报 ≤δ_shift；一旦报警即撤销证书，因此系统不会保留一个已知失效的声明。但在任意漂移下，审计的漏检概率没有分布无关上界；残差风险由审计功效决定。证明：e-process 在无漂移零假设下的有效性 + 报警即撤销的定义；漂移下功效依赖散度，无免费保证。∎

**引理 106（预算守恒与异常时的算力反降）** 设模态数 M≤6、每模态分数维 d≤256、赛道数 J≤8、候选数 n≤64、K≤10。CAM 每步 O(M(log n+d))，AnomCert/AG O(1)；ASA 每 T_abl 摊销；CRC/SA 在提交/审计时摊销。总决策 p99 仍 ≤20ms，50Hz 保持。且当 l≥1 时 `K_eff` 与候选数单调下降，异常越强总算力越低。证明：逐项复杂度表 + 定义 558 的单调收缩；静态 EDF 校验 ΣŴ_m≤B_dec。∎

## 7. 已知风险与失效模式

1. **共形保证的边界被误读**：引理 96/97 只约束误报，不约束漏检；真正的隐藏异常可能静默通过。缓解：多模态 + 监控器的监控器 + 金丝雀 + 红队异常注入；在报告中显式写"漏检率未认证"。
2. **异常检测的低基础率/低功效**：稀有异常使 AP 很低，AUROC 好看但部署无用。缓解：分层标定、合成/仿真异常、主动学习标注、按代价而非准确率调阈值。
3. **异常门控导致过度保守或僵死**：l=2 频繁触发会显著降低任务完成率。缓解：自主等级阶梯、滞回、`T_ask` 后 escalate、异常预算 b_a、按任务代价调阈值。
4. **自适应标定的反馈回路**：门控改变数据分布，使后续标定集不再代表部署分布。缓解：保留独立 audit/探索预算、定期重置 ACI、记录门控策略版本、离线复标定。
5. **挑战赛隐藏赛道不在标定覆盖内**：逐赛道 LTT 只覆盖已知赛道；隐藏赛道可能是全新分布。缓解：最坏赛道界 + 漂移审计 + 金丝雀；无覆盖时只报"未认证"，不报高分。
6. **排行榜过拟合与 Goodhart**：反复提交/调参会把证书本身当成优化目标。缓解：预注册、隐藏 audit、anytime CS、限制提交、报告证书而非单点分数。
7. **安慰剂检验的功效/惰性假设**：安慰剂可能并非真正惰性，或样本不足导致漏报。缓解：实现级空操作审计、随机化检查、报告检验功效；安慰剂显著只作保守触发器。
8. **异常分层的选择偏差**：用后处理异常分层会诱导对撞偏差。缓解：强制使用干预前 `p_{t−}`；后处理层只做诊断；分层变量做敏感性分析。
9. **算力与实时性**：多模态共形 + 多赛道 LTT 可能挤占预算。缓解：检测器蒸馏、标定离线、LTT 低频、异常时反而降 K；静态 EDF 校验。
10. **安全不是异常检测的同义词**：异常证书不能替代物理/接触/规范证书；漏检异常仍可能绕过。缓解：v10 证书始终合取、异常只收紧、l=3 安全停机、独立安全监控。

## 8. 本轮最大风险

**一句话**：共形保证只约束"在校准分布内的误报率"，对真正决定隐藏测试成败的未知异常**没有检出保证**；一旦异常静默通过，异常证书会以分布无关的置信度为一个已经失效的世界模型背书，而挑战证书会把这种失效包装成"统计上可证的高分"。
