# 第 4 轮（灵感循环第 4 轮；本轮灵感：「真实世界泛化」×「多模态融合」）

> **基线**：第 3 轮 InstructGauge（IP-321–327；定义 432–447；引理 51–58；实验 E441–E456）。第 2 轮 ToolGauge、第 1 轮 LeanGauge / MODGAUGE 骨架继续继承不变。
> 本轮纪律：**增量升级 + 严格退化**。两个新灵感各沿一条轴升级 InstructGauge，且任一环节不可用都必须能一键退回：泛化与融合是增强项、不是依赖项。

## 0. 直觉与动机

**灵感 1（真实世界泛化 → 要迁移的是「契约的不变部分」，不是权重本身）**
直觉：实验室里有效的测量契约到现场失效，通常不是模型容量不够，而是契约里混进了只在 sim 成立的**捷径**——特定光照、纹理、相机曝光、桌面反光、接触面材质。把这些捷径当特征记住，sim 上交叉验证很漂亮，现场换一盏灯就崩。所以泛化不是又一个训练技巧，而是一个**可部署性判定问题**：给定契约 `C` 与现场允许的 nuisance 变换群 `G_nui`，`C` 的哪些关系在 `G_nui` 下仍然成立？只有通过不变性检验的子契约才允许迁移，其余必须显式裁剪、重新校准或降级。这把 sim→real 从「祈祷式迁移」改写成「部署前可审计的契约裁剪」。

**灵感 2（多模态融合 → 把「分歧」变成证据，而不是把分歧平均掉）**
直觉：多模态最诱人的用法是加权平均或早期拼接来提升鲁棒性；但真正的信息往往在**模态间分歧**：当 RGB、深度、触觉对同一物理量的估计分裂时，分歧本身就是「此处可能不可靠」的证据。朴素融合会把分歧平滑掉，制造虚假自信。更糟的是，真实世界的失效常是**共因**的：反光可以同时骗过 RGB 与结构光深度，两者一起错，分歧反而很小。因此正确姿势不是「融合得更多」，而是让融合器输出一个**跨模态一致性证书**：把分歧映射为不确定度/弃权，在分歧不可解释时升级人工或主动探测，而不是继续平均。

**灵感 3（两者耦合 → 不变性必须按模态分层，否则融合会「洗白」捷径）**
直觉：一个 cue 可能在单模态内是 nuisance，但通过与另一模态的统计耦合，在融合表示里看起来「跨域不变」。例如纹理捷径在 RGB 内随光照变化，但若触觉恰好与纹理相关，融合后的不变性测试会通过——这是**伪不变性**。解法不是禁用融合，而是三根结构支柱：**模态分层不变性**（每个模态/模态对分别检验，禁止把相关性当不变性）、**认证融合**（分歧→证书→弃权，且对共因故障有显式假设）、**有界适应**（测试时只更新 nuisance 归一化，不更新物理契约，且可一键回滚）。

## 1. 研究问题（本轮要回答什么）

- **Q1（泛化的可判定性）**：「泛化到真实世界」能否在部署前被**证书化**，而不是部署后靠平均指标事后解释？哪些契约子句可迁移、哪些必须裁剪，边界由什么量决定？
- **Q2（融合的收益条件）**：多模态融合在什么条件下真正降低失效，而不是用相关性掩盖共因故障？冗余收益能否用「有效独立模态数」量化，并给出可证伪的失效上界？
- **Q3（适应的安全性）**：测试时适应能否只改 nuisance、不改物理契约？在什么信任域与回滚机制下，适应不会破坏安全子句与共形覆盖？

## 2. 四条设计原则（雏形，正式化见产物区定义 448–463）

**P1 不变性优先（Invariance-First）**
可迁移的不是整个契约，而是契约在预注册 nuisance 群 `G_nui` 下 **ε-不变**的子契约 `C↓`。不变性检验是部署闸门：每条关系/安全子句必须逐条通过，未通过者不得进入现场数值路径。形式化方向：`Inv_ε(φ, G_nui)` 与转移证书 `TC`（定义 448/449）。

**P2 分歧即证据（Disagreement as Evidence）**
融合器必须输出 `FuseCert`：记录模态权重、成对分歧、冲突标志与弃权决定。分歧超阈且无法由已校准 nuisance 解释 ⇒ **冲突**，走仲裁（重新探测/换模态/弃权），禁止用平均把冲突抹平。形式化方向：认证融合算子与冲突仲裁（定义 450/451/457）。

**P3 可退化融合（Degradable Fusion）**
任何模态都可能掉线或失准。融合必须能退化为可用模态子集的子契约 `C_S`，并按其模态数放宽共形区间；单模态也不可用 ⇒ 弃权而非硬猜。形式化方向：模态掉线子契约与覆盖（定义 456）。

**P4 有界适应（Bounded Adaptation）**
测试时只允许更新 nuisance 参数 `θ_nui`（曝光、增益、温漂、接触面偏置），物理契约参数 `θ_phys` 冻结；更新限制在信任域 `‖Δθ‖ ≤ ρ` 且只沿降低校准残差方向；每次适应前存检查点，指标恶化即原子回滚。形式化方向：信任域与适应安全不变量（定义 455/459/460）。

## 3. 与基线的接口（如何退化）

- 不变性检验不通过 / 无 nuisance 样本 ⇒ 冻结契约、只保留最保守子句，等价 InstructGauge 契约；
- 融合分歧不可仲裁 ⇒ 弃权或退回单模态最可信通道，等价 InstructGauge 单模态路径；
- 漂移检测报警 / 适应预算耗尽 / 覆盖跌破阈值 ⇒ 回滚到适应前检查点；
- FieldGauge 失效 ⇒ InstructGauge ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE 原样。

## 4. 预期贡献

1. 一个「**可迁移子契约**」口径：把 sim→real 泛化从模型指标改写为逐子句的不变性证书，使部署前即可审计与裁剪；
2. 一个**认证多模态融合**算子：把跨模态分歧变成不确定度证据，并用「有效独立模态数」给出共因故障下的收益上界；
3. 一个**有界测试时适应**方案：只更新 nuisance、冻结物理契约、支持原子回滚，并给出适应安全的充分条件；
4. 一条完整可证伪路径：E457–E472 覆盖不变性、共因故障、模态掉线、序贯漂移、加权共形、适应稳定性、同步时延与现场迁移。

## 5. 本轮最大风险

**一句话**：多模态融合会制造「两个模态一致所以可信」的假象，而不变性检验若只在 sim 的 nuisance 群上做，就会签发一张**与真实共因故障同源**的转移证书；一旦真实世界的未建模混淆同时欺骗所有模态，分歧很小、覆盖看似达标，系统会在「自信且一致」的状态下集体失效——因此本轮真正的残余风险是**共因不变性失效**，而不是模态缺失。

## 2. 形式化定义（要点）

**定义 448（nuisance 群与 ε-不变性）** 设 `G_nui` 为预注册的现场允许变换群（光照/曝光/白平衡/视角/温漂/接触面材质等），作用于观测 `x` 与回执 `z`。表示 `φ` 对目标关系 `y` 在 `G_nui` 下 **ε-不变**，记 `Inv_ε(φ,G_nui)`，当且仅当
`sup_{g∈G_nui} E[ℓ(φ(g·x, g·z), y)] − E[ℓ(φ(x,z), y)] ≤ ε`。
`G_nui` 必须在部署前冻结并留出验证样本；不许用测试时见过的变换回填。

**定义 449（可迁移子契约与转移证书）** 契约 `C = (R, Cal, S)` 为关系集、校准集与安全子句集。对每条 `r∈R`、`s∈S` 做不变性检验，取
`C↓ = { r∈R : Inv_ε(φ_r,G_nui) } ∪ { s∈S : 安全子句在 real 回执上零违反 }`。
转移证书 `TC(C,D_real) = (ε_inv, δ_cov, safe_ok, C↓)` 仅在 (i) `C↓` 覆盖全部安全子句、(ii) 加权共形覆盖 `≥ 1−α−δ_cov`、(iii) 安全子句零违反时签发；否则部署**最大可迁移子契约**并显式标注被裁剪项。

**定义 450（跨模态分歧与融合证书）** 对每个 `m∈M`，得 `(ŷ_m, r_m, τ_m)`。成对分歧
`D_mm(i,j) = d(ŷ_i, ŷ_j) / (√(σ_i²+σ_j²)+ε₀)`，采用校准后方差归一化。
`FuseCert = (w, {D_mm}, conflict, abstain, t_sync)`；若 `max_{i,j} D_mm(i,j) > τ_dis` 且无法由已校准的 nuisance 解释（即分歧不在 `G_nui` 诱导的分歧分布分位内）⇒ `conflict = True`。

**定义 451（认证融合算子）** 对数池 `p(y|x) ∝ exp( Σ_m w_m log p_m(y|x) )`，权重
`w_m = softmax_m(β·r_m − γ·Σ_{j≠m} D_mm(m,j) − λ·1[τ_m 陈旧])`。
仅当 (i) 所有参与模态通过同步检查 `|τ_m−τ̄| ≤ Δ_max`、(ii) 各自通过模态级 CVC、(iii) `conflict=False` 时启用；否则退化为 `MDF` 子契约或单模态最可信通道。`FuseCert` 与输出一同下发。

**定义 452（模态分层不变性）** 对任意模态子集 `S⊆M`，定义 `Inv(S) = { φ_S : Inv_ε(φ_S,G_nui) }`。要求
`Inv(S₁∪S₂) ⊇ Inv(S₁) ∩ Inv(S₂)`，即融合层只能**收缩**可迁移能力，不能凭跨模态相关性扩张。禁止以 `Inv_ε(φ_{i∪j},G_nui)` 通过来反推 `Inv_ε(φ_i,G_nui)` 通过（伪不变性）。

**定义 453（序贯漂移 e-process）** 以参考分布 `P_ref` 为原假设，构造非负鞅 `E_t = ∏_{k≤t} (dP_real/dP_ref)(x_k)`（或任意 e-process）。报警
`τ_shift = inf{ t : E_t ≥ 1/α_s }`。由 Ville 不等式，无漂移下 `P(sup_t E_t ≥ 1/α_s) ≤ α_s`，故误报率 anytime-valid，不依赖固定窗口与独立同分布假设。

**定义 454（协变量漂移下的加权共形）** 设 `w(x)=dP_real/dP_cal(x)`，非一致性分数 `s_i`。阈值取加权分位
`q_w = inf{ q : Σ_{i: s_i≤q} w(x_i) / Σ_i w(x_i) ≥ 1−α }`。
权重精确时 `P(Y∈C(X)) ≥ 1−α`；以 `ε_w` 误差估计权重时覆盖降级为 `≥ 1−α − TV(P_real,P_cal) − O(ε_w)`（引理 61）。

**定义 455（有界适应信任域）** 测试时只更新 `θ_nui`，保持 `θ_phys` 不变；每次更新
`θ_nui ← θ_nui + Δ`，`‖Δ‖ ≤ ρ`，且仅当校准残差 `L_cal` 单调不增时接受。禁止任何经由 nuisance 参数间接改变安全子句的路径（定义 459 的检查项）。

**定义 456（模态掉线子契约与覆盖）** 可用模态子集 `S` 时使用 `C_S`，并取 `α_S = α/2^{|M|}`。对所有非空 `S` 做 union bound：
`P(⋃_S {Y∉C_S(X_S)}) ≤ Σ_{S≠∅} α_S < α`，故边缘覆盖 `≥ 1−α`。若 `S=∅` 或单模态自检失败 ⇒ 弃权（`stub_and_red`），不做无证据外推。

**定义 457（冲突仲裁策略）** 若 `conflict=True`，按优先级执行 `Arb`：(i) 取时间戳最新且通过自检的模态；(ii) 发起一次主动探测以消歧（可复用 InstructGauge 的探测块）；(iii) 仍冲突则弃权并升级人工。**禁止**用加权平均「消解」冲突。

**定义 458（转移风险分解）** 对任一现场假设 `h`，
`R_real(h) ≤ R_sim(h) + ε_inv + Div(P_sim,P_real) + ε_cal + ε_est`，
四项分别由不变性检验余量、域散度估计、加权共形校准与有限样本项给出。该式是 E457/E463 的可证伪骨架：每项都有独立测量，不能用一个总指标掩盖。

**定义 459（适应安全不变量 SafeInv）** `SafeInv` 要求：对每个安全子句 `s∈S`，适应前后其在回执上的判定不变；且 `θ_phys` 逐坐标相等。BTA 每次更新后必须核验 `SafeInv`；违反即拒绝该步并回滚。

**定义 460（检查点与原子回滚）** 适应前存 `CKPT=(θ_nui, Cal, q_w, FuseCert 基线)`。若连续 `q_rollback` 次出现 (i) 校准残差上升超过 `η`、(ii) 覆盖跌破 `1−α−δ_cov`、或 (iii) `SafeInv` 违规 ⇒ 原子回滚到 `CKPT`，并冻结适应至下一个 `q_quiesce`。

**定义 461（跨模态回执绑定 Chain_mm）** 每条融合输出绑定 `(m, receipt_id_m, τ_m, raw_m)` 及各模态的 `ChunkCert`，形成可追溯链；任何主张若无 `Chain_mm` 支撑，按 InstructGauge 定义 441 剥离为纯解释。

**定义 462（现场部署证书 FieldCert）** `FieldCert = (TC, FuseCert, shift_log, adaptation_log, Chain_mm, C↓)`，使审计者能从「可迁移子契约 → 融合证据 → 漂移/适应记录 → 逐模态回执」复现一次现场决策。

**定义 463（四级退化映射 Degrade_4）** `FieldGauge →(失败) InstructGauge → ToolGauge → LeanGauge → MODGAUGE`。每一级只移除本层新增能力，不改变下层语义；退化在 `q_quiesce` 原子发生（沿用 InstructGauge 定义 439）。

# IP-328 ICG：逐子句不变性检验，签发可迁移子契约
class InvarianceGate:
    def certify(self, contract, G_nui, val):
        C_down, eps_inv, dropped = [], 0.0, []
        for clause in contract.clauses:
            e = max_shift(clause.phi, G_nui, val)          # sup_g 风险增量
            if e <= EPS_INV:
                C_down.append(clause); eps_inv = max(eps_inv, e)
            else:
                dropped.append(clause)
        safe_ok = all(s in C_down for s in contract.safety_clauses)
        return TransferCert(eps_inv, C_down, dropped, safe_ok)

# IP-330 MSI：模态分层不变性（交集闭包）
def stratified_invariance(modalities, G_nui, val):
    ok = {m: self.test(phi[m], G_nui, val) for m in modalities}
    for i in modalities:
        for j in modalities:
            if i < j: ok[(i, j)] = ok[i] and ok[j]     # 交集，绝不并集
    return ok

# IP-329/331/333：认证融合 + 漂移门 + 掉线退路
class CertifiedFusion:
    def fuse(self, ests, drift_alarm, avail):
        S = [m for m in avail if ests[m].self_check()]
        if not S: return None, FuseCert(abstain=True)   # 弃权
        if drift_alarm: S = [m for m in S if m in STABLE_MODALITIES]
        if len(S) < len(ests) or skew(ests) > DELTA_MAX:
            return self.subcontract_fuse(S, ests)        # 子契约 + 放宽 α_S
        conflict = self.disagreement(ests, S) > TAU_DIS
        cert = FuseCert(S, conflict=conflict)
        if conflict: return self.arbitrate(ests, S), cert
        return log_pool(ests, S, self.weights(ests, S)), cert

# IP-332 BTA：有界适应（只动 nuisance，可回滚）
class BoundedAdapter:
    def step(self, theta, cal, receipt):
        ckpt = checkpoint(theta, cal)
        dtheta = self.nuisance_grad(theta, receipt)
        if norm(dtheta) > RHO or not self.safe_invariant(theta, dtheta):
            return theta, ckpt                              # 拒绝
        cand = theta + clip(dtheta, RHO)
        if self.cal_residual(cand) > self.cal_residual(theta):
            return theta, ckpt                              # 单调接受
        return cand, ckpt

# IP-334 8C 闭环
def fieldgauge_8c(M, s, ell, modal_obs):
    out  = M.nlib.ground(ell, M.scene, M.ontology)
    iota = out[0] if out else M.default_iota
    if not M.icg.certify(M.contract[s], M.G_nui, M.val).safe_ok:
        return instructgauge_7c(M, s, ell)                  # 退化
    H = M.lbox.hypothesize(s, M.dbox.R[s], iota)
    C = M.iac.plan_chunk(iota, H, M.tools, M.budget_left(s), M.drift_bound(s))
    cert = M.cvc.commit(C, M.env, iota)
    ests = M.cmf.estimate(modal_obs, s)
    fused, fcert = M.cmf.fuse(ests, M.dsd.alarm(), M.mdf.available(modal_obs))
    if fused is None:
        return stub_and_red(s, "no_evidence")               # 弃权
    new_theta, ckpt = M.bta.step(M.theta, M.cal, fused.receipt)
    if not M.bta.safe_invariant(M.theta, new_theta - M.theta):
        M.bta.rollback(ckpt)
    M.mreg.hot_replace_at_quiescence(M.dpe, M.apcal.update_contract(
        M.dpe, fused.mu, fused.Sig, s), cert.boundary)
    bind_claims(cert, iota, fused.receipts)
    return FieldCert(M.icg.last_tc, fcert, M.dsd.log, M.bta.log, fused.chain)

# IP-335 主闭环（50Hz 路径不变）
def FieldGauge_round(M, obs, audio, tac, depth, det, ell=None):
    modal_obs = M.mux.snapshot(obs, audio, tac, depth)      # 异步拼装，不阻塞
    for s in M.dbox.detect_blind_spot():

## 4. 推导

**引理 59（不变性 → 转移风险界）** 若表示 `φ` 在 `G_nui` 上 ε-不变，且真实域的 nuisance 变换落在 `G_nui` 内，则
`R_real(h∘φ) ≤ R_sim(h∘φ) + ε + Div(P_sim,P_real)`。
*证明骨架*：对任一 `g∈G_nui`，三角不等式把 `R_real` 拆成 `R_sim + (R_real−R_{g·sim}) + (R_{g·sim}−R_sim)`；第一项由不变性 ≤ ε，第二项由域散度控制；对 `g` 取 sup 即得。**关键前提**是 `G_nui` 覆盖真实 nuisance；未建模的共因不在界内（见引理 60 与风险）。

**引理 60（融合误差与「有效独立模态数」）** 设 `M` 个模态在给定 `y` 下条件独立、各自错误率 `p_m ≤ p < 1/2`。等权多数融合误差
`P_fuse ≤ exp(−2M(1/2−p)²)`（Hoeffding）。若错误两两等相关的共因强度为 `ρ∈[0,1]`，则有效独立模态数
`M_eff = 1 + (M−1)(1−ρ)`，上界中的 `M` 须替换为 `M_eff`。故 `ρ→1` 时 `M_eff→1`，融合**没有任何**冗余收益。推论：多模态比较优势不是「模态数量」，而是「共因强度」；E460 直接测量 `M_eff` 而非报告模态数。

**引理 61（加权共形覆盖）** 若权重 `w(x)=dP_real/dP_cal(x)` 精确且 `P_real` 对 `P_cal` 绝对连续，则加权分位给出 `P(Y∈C(X)) ≥ 1−α`。若权重只用有限样本估计、误差为 `ε_w`，则
`P(Y∈C(X)) ≥ 1−α − TV(P_real,P_cal) − O(ε_w)`。
*证明骨架*：加权分位把覆盖写成 `E_{P_real}[1{s≤q_w}]`，再做重要性加权与 TV 三角不等式；估计误差经 Lipschitz 分位稳定性传播。故 E463 必须同时报告 `TV` 估计与 `ε_w`，否则覆盖数字不可信。

**引理 62（序贯漂移误报控制）** 对任意停时 `τ`，无漂移下 `P(τ_shift ≤ t) ≤ α_s`（Ville）。因此 DSD 的误报不随检查次数累积，且无需固定窗口；代价是检测延迟依赖真实漂移幅度（E462 报 ARL 与延迟曲线）。

**引理 63（有界适应的安全性）** 若 (i) 只更新 `θ_nui`、(ii) `‖Δ‖≤ρ`、(iii) 只做单调接受、(iv) 每步核验 `SafeInv`，则安全子句的判定在适应前后保持不变，且 `θ_phys` 不变。若发生回滚，适应轨迹的期望损失不超过「检查点间隔 × 单步最大损失」，即回滚把无界漂移风险截断为线性。*证明*：单调接受保证 `L_cal` 不增；`SafeInv` 是逐步不变量；回滚把状态恢复到已验证点，构成一个有限状态回复过程。

**引理 64（模态掉线覆盖）** 若每个子集 `S` 的共形阈值取 `α_S = α/2^{|M|}`，则对所有可用子集做 union bound 得边缘覆盖 `≥ 1−α − (2^{|M|}−1)/2^{|M|}·α > 1−α`。故「少一个模态」只放宽区间、不破坏覆盖；弃权情形不产生错误覆盖声明。

**引理 65（同步误差与 50Hz 保全）** 设模态时间戳偏斜 `Δτ`、融合映射 Lipschitz 常数 `L_f`，则迟到融合的额外误差 `≤ L_f·Δτ`。要求 `Δτ ≤ Δ_max` 才允许融合，否则按 MDF 掉线处理；由于融合/检测/适应均在异步线程，主循环新增周期 `< 0.2ms`，继承 InstructGauge 引理 58 与 ToolGauge 引理 50 的硬实时结论。

**引理 66（四级退化等价）** 在 `q_quiesce` 处依次移除 ICG/CMF/MSI/DSD/BTA/MDF 的能力，剩余子图与 InstructGauge-7C 逐指令等价；再退化为 ToolGauge-6C、LeanGauge、MODGAUGE 分别回到第 3/2/1 轮引理。新增的 `FuseCert`/`FieldCert` 是纯投影，不改变数值路径。

## 8. 本轮最大风险

**一句话**：`ICG` 的不变性检验与 `CMF` 的跨模态一致在接口处形成**共因盲区**——若真实世界存在一个未建模的混淆同时欺骗所有模态，分歧会很小、不变性检验（只在 sim 的 `G_nui` 上做）会通过、加权共形覆盖也看似达标，系统将在「自信且一致」的状态下集体失效；因此本轮真正的残余风险是**共因不变性失效**，而非模态缺失、时延或单模态噪声，缓解只能依赖显式共因压力测试（E460）、模态分层交集（MSI）与把 `M_eff` 而非模态数写入部署证书。
