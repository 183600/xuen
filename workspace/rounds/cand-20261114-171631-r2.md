# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；本轮灵感：「指标体系」×「世界模型」）

> R69 给闭环装上了一张嘴：它会看、会问、会触，用 VoI 判断「值不值得求证」。但它判断要不要开口时，靠的仍是一把散落的标量——`U_ale`、`U_epi`、`ECE`、`Δa`、`VoI`、AUC 目标——每个都被当作对现实的直接读数。这默认了两件从未被检验的事：**(1) 这些数字测的正是它们声称要测的东西；(2) 计算它们所处的那个世界（提供反事实与认证的世界模型）就是真实世界。** 两处都会静默失效。
>
> 本轮两个灵感正好各补一刀：
> - **指标体系**告诉我们：安全不是一个可加权求和的标量，而是一张**有类型、有方向、不可补偿**的图；效率之间可以折中，但效率永远不能「补偿」一个失败的安全节点。每个指标都像计量学里的仪器，必须带**校准证书**，否则没有决策权。R69 的 `VoI − cost` 恰恰是可补偿的标量化——一个被污染/未校准的模态熵，可以被「省钱」抵消。
> - **世界模型**告诉我们：一个指标是否有意义，无法在单条观测轨迹上检验，只能靠反事实——「如果我把 X 改一改，这个数会不会动？」这个反事实引擎就是世界模型。于是世界模型不只是「预测/认证」的组件，它同时是**计量实验室**：用 do-干预测每个指标的**敏感度**（该动时动）与**特异度**（不该动时不动）。
>
> 但这两者拼在一起会成一个环：用世界模型验证指标，再用指标信任世界模型。若世界模型有系统性偏差，它会认证一套「与自身偏差一致」的指标，环路自洽却指向一个错误世界。**本轮真正要解的题，就是用不经过同一世界模型通道的「真实锚」与永不优化的「留出指标」，把这个自证环打破。**
>
> 核心命题：**把 R69 的标量判据升级为「带证书的指标体系」，用世界模型做构念效度的反事实检验，用真实锚 + 留出指标打破「世界模型 ↔ 指标」自证循环；只有在指标不可采纳、世界模型不可信、或古德哈特漂移时，才退化为 R69 的标量保守。** 命名 **METER-RAS**（world-**M**odel-grounded, **E**vidence-certified, **T**raceable indica**T**or system for **E**pistemic **R**isk-adaptive **S**afety）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我到底该量什么、我用来量它的那个世界是不是真的**」——从读表，到校表，再到校验那只校准尺。

## 0. 直觉与动机

**灵感 1（指标体系 → 安全是一张图，不是一个数）**
直觉：R69 的证书 `J_FLUID` 已经攒了一堆字段（ECE、U_epi_before/after、voi_ratio、a_score_p95……），但它们在决策时被压成一个 `VoI − cost` 的分数。问题在于「可补偿性」：只要总分够高，某一路指标的失败就被别处的好成绩抹平了。现实里这恰恰是最危险的失效模式——任务成功率很高、体感很顺、就一点点超速，于是加权后「整体可接受」。指标体系的要点是给它**类型与结构**：叶子是测量，节点是构念，安全节点用合取/字典序，效率节点才允许 Pareto 或标量化；上游证书失效会**沿依赖边传染**，让整个下游节点失去决策权。再往前一步，计量学还要求**溯源**：每个指标都要能沿一条锚链追到某个不依赖被审计仪器的标准。指标不是「报出来的数」，是「有证书、可追溯的仪器」。

**灵感 2（世界模型 → 指标只能在反事实里被检验）**
直觉：你不可能靠观察一条轨迹判断「这个指标测的是不是它宣称的构念」。要检验「刹车压力指标是否真的反映制动能力」，你得**干预**：把路面摩擦改低、把载重加大，看指标是否按预期动（敏感度）；再把光照、传感器噪声、无关障碍物改一改，看指标是否**不动**（特异度）。这些反事实只能在世界模型里 roll out。所以世界模型在本轮获得第二个身份：**计量实验室**。这把 R69 的「世界模型当预测器/认证器」升级为「世界模型当可干预的实验台」。

**灵感 3（真实锚 → 打破自证循环）**
直觉：如果所有「干预实验」都在同一个世界模型里做，那么指标和世界模型就是一个封闭系统：世界模型偏了，它会认证一套同样偏的指标，指标再好也只是在它自己的世界里优秀。计量学的答案是**溯源链**：仪器的校准必须最终追到一个独立基准（米原器、原子钟、真实实验）。这里就是真实世界锚——真实记录的、带已知干预的数据、独立物理不变量、跨模态独立传感器、人类专家标注。**没有任何一条锚链能不经过同一世界模型通道的指标，不得进入部署决策**（可以用于研究，不能拿来决定「安全」）。这条纪律的量化版本，是本轮的自证指数 SJ。

**灵感 4（古德哈特 → 指标一旦成为目标就不再是指标）**
直觉：R69 让策略去优化 VoI、压低 ECE、提升模态覆盖；一旦这些数变成训练/调参的目标，它们就会被「钻空子」——策略学会制造一种让指标好看但不让现实变好的行为（模型利用 / reward hacking 的计量版）。世界模型同样会被利用：策略可能发现世界模型某个物理约束的漏洞，在仿真里刷出漂亮指标。对策不能靠「更努力优化」，而要靠**留出一组永不优化的指标 + 真实锚**做「审计基准」，并持续比较「被优化指标」与「留出锚」的排序分歧；分歧超阈就**冻结指标、重新推导**。

**灵感 5（R69 是单仪器边界）**
直觉：R70 不能推翻 R69，而要把 R69 收为边界情形：当指标图坍缩为单一安全节点 `U_floor`、世界模型通过审计（WVI ≥ w_min）、无古德哈特漂移、自证指数合格时，METER 的决策必须与 R69 **逐指令相同**。这是本轮的纪律：**每加一层，旧层必须成为新层的退化边界，而不是并列的另一个需要独立信任的黑箱。**

## 1. 形式化定义（增量：定义 310–321）

**定义 310（METER-RAS 总览）** METER-RAS = (MGS, CVL, WAE, TAC, GOG, MCL, RAS-WM†)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）：效度证书在运行期**只读**，计量更新只发生在离线计量窗口；
(ii) **安全不可补偿**：安全节点是合取 / 字典序，任何效率增益不得抵消一个失败的安全节点；
(iii) **可溯源性**：进入部署决策的每个指标必须携带效度证书，且其锚链至少有一条不经过同一世界模型生成通道；
(iv) **指标可废止**：证书失效、漂移越界或世界模型出界 ⇒ 该指标**立即除名**（而非降权），决策权回落到 R69。

**定义 311（指标图 MGS）** 指标系统记作 ℐ = (V, E, τ, ⊑, agg)。
- V = V_meas ∪ V_cons ∪ V_safe ∪ V_eff：测量叶子、构念节点、安全节点、效率节点；
- τ: V → Type（传感器 / 行为 / 不确定性 / 社会 / 效度）；
- E 的边带类型：**definitional**（定义性，如成功率 = 完成任务数/总数）、**causal**（可由 do-干预检验）、**statistical**（仅相关，最弱，不能单独合法化下游）；
- ⊑ 为依赖偏序；上游任一节点证书失效 ⇒ 下游节点 `valid=False`（**证书传染**）；
- agg：安全节点用 `min`/合取；效率节点可 Pareto 或标量化，但**必须在前者全部通过后**才允许。
指标 m **可采纳（admissible）** ⇔ 自身及所有祖先证书有效且通过 GOG。

**定义 312（构念、敏感度与特异度）** 构念 c 由一个指标 m 声称测量。给定**相关干预族** 𝒟⁺（应当改变 c 的 do-干预）与**无关扰动族** 𝒟⁰（不应当改变 c 的扰动：光照、噪声、标定漂移、无关物）。
- 敏感度 `S(m|c) = Normalize(E_{d∈𝒟⁺}|m(do d) − m(base)|)`，以构念真实变化为标尺；
- 特异度 `P(m|c) = 1 − Normalize(E_{d∈𝒟⁰}|m(do d) − m(base)|)`。
**效度证书** `CV(m) = (S, P, coverage, anchor_trace, wm_ver, issued_at)`；m 可采纳要求 `S ≥ s_min` 且 `P ≥ p_min` 且锚链有效。
直观：S 低 = 死仪器（没信息）；P 低 = 易被捷径骗（古德哈特入口）。

**定义 313（反事实计量实验室 CVL）** 对每个 do(d)，在世界模型集合 {WM_j} 中 rollout，计算 S、P。**稳健效度取最差世界模型**（`min_j`），而非平均；且干预必须满足**可识别性**（do-calculus 中无未阻断混杂），不可识别时标 `uncertifiable`，该指标不得用于安全决策。CVL 的输出只进入离线证书，不进入实时回路。

**定义 314（世界模型审计 WAE / WVI）** 世界模型可信度指标 `WVI` = (预测校准、物理不变量违反率、反事实一致性、OOD/新颖度、真实锚残差)。**WVI 本身是指标图里的一个安全节点**；取最差集成成员而非均值。WVI 低 ⇒ 所有依赖反事实证书的指标暂时失效。

**定义 315（可溯源锚 TAC / 自证指数 SJ）** 锚集 A，每个锚带 provenance。指标 m 的锚链在「锚来源通道 ≠ 被审计世界模型通道」时有效。定义**自证指数** `SJ = |{用于决策的指标其整条锚链都经过同一 WM 通道}| / |已用指标|`。部署要求 `SJ ≤ σ_SJ`；`SJ=1` 时证书只能证明「世界模型自洽」，对真实误差**无任何上界**。

**定义 316（古德哈特护栏 GOG）** 把指标分为**被优化集 O** 与**留出集 H**（冻结、限频、对外不可见）。定义分歧
`D_G = λ_1·rank_divergence(O, H) + λ_2·anchor_gap(O, H)`，
其中 `anchor_gap` = 「指标改善量」与「真实锚上改善量」之差。若某窗口内 `D_G > τ_G` ⇒ 宣布**指标漂移**：冻结 O 的优化、重推指标图、决策权临时移交 H ∪ 安全节点。

**定义 317（字典序安全决策）** 候选动作 `A_adm = {a : 所有安全节点在最差世界模型下通过，且所用指标全部可采纳}`。在 A_adm 内按效率做字典序 / Pareto 选择，平局用**鲁棒裕度**（到安全边界的距离）打破。若 A_adm 为空 ⇒ 退化 R69；再空 ⇒ 退化 R68 的 `λ_floor`。R69 是「单安全节点、单仪器、可信世界」的特例。

**定义 318（指标裁剪 / 边际决策价值）** 指标必须挣得位置：`μ(m) = 期望决策后悔降低 / 计算与标注成本`。`μ(m)` 低于阈值即裁剪；`|V|` 有预算上界。对抗「指标通胀 / 指标剧场」：不是越多越安全，冗余指标会稀释证据、抬高延迟。

**定义 319（计量闭环 MCL）** 在线：读冻结证书 → 评估指标图 → GOG 检查 → 字典序决策 → 执行 → 记录锚。离线**计量窗口**：重算 CV/WVI/GOG、裁剪指标、签发新证书。在线路径**不写任何学习/证书状态**，仅读——从而保持实时性与「零学习写操作」不变式。

**定义 320（证书 J_METER）** `J_METER = (J_FLUID, indicator_graph_hash, CV_table(S,P), WVI, D_G, SJ, anchor_trace_ids, wm_ensemble_margin, worst_case_pass, meter_ver)`。Valid ⇔ `Valid(J_FLUID)` ∧ 所用指标全部可采纳 ∧ `WVI ≥ w_min` ∧ `D_G ≤ τ_G` ∧ `SJ ≤ σ_SJ`。

**定义 321（对抗性世界模型集 / 模型利用检验）** 世界模型集除「正常成员」外，注入若干**扰动成员**（物理参数偏置、约束放松、训练数据切片），用于检验：某决策在这些成员下指标虽好、但真实锚上不改善，即为**模型利用**，由 GOG 的 anchor_gap 捕获并除名对应指标。

## 2. 关键算法骨架

```python
# IP-264 MGS：有类型、不可补偿的指标图（运行期只读证书）
class MetricGraph:
    def evaluate(self, obs, wm_ensemble):
        vals = {}
        for n in self.topo_order():                 # 叶子=测量，节点=构念
            vals[n] = n.fn(vals, obs, wm_ensemble)
            if not n.cert.valid:                    # 证书传染病
                vals[n].valid = False
        return vals

    def safe_admissible(self, vals, action):
        # 安全节点合取：任一失败即不可采纳，效率不得补偿
        if not all(vals[n].passes(action) for n in self.safety_nodes):
            return False
        return all(vals[m].cert.admissible for m in self.used_indicators)

    def lexicographic_argmax(self, admissible, vals):
        return argmax_lex(admissible, [self.safety_key, self.efficiency_key], vals)

# IP-265 CVL：反事实构念效度（敏感度/特异度），最差世界模型
def certify(indicator, construct, wm_ensemble):
    certs = []
    for wm in wm_ensemble:
        if not identifiable(wm, construct):         # do-calculus 混杂
            return Uncertifiable(indicator)
        base = rollout(wm, do({}))
        s = response(indicator, [rollout(wm, do(d)) for d in D_PLUS(construct)])
        p = 1 - response(indicator, [rollout(wm, do(d)) for d in D_ZERO(construct)])
        certs.append(CV(s, p, wm.version))
    return worst_case(certs)                        # 不是平均

# IP-266 WAE：世界模型审计（WVI 也是安全节点）
def world_validity(wm, anchors):
    return dict(
        cal   = prediction_calibration(wm),
        phys  = invariant_violation(wm),            # 能量/几何/因果一致性
        cf    = counterfactual_consistency(wm),     # do() 可重复性
        ood   = novelty_score(wm),
        resid = real_anchor_residual(wm, anchors)   # 唯一非 WM 通道
    )

# IP-267 TAC：溯源校验（打破自证）
def trace_ok(indicator, anchor_graph):
    return anchor_graph.has_path(
        indicator, to=lambda a: a.provenance != indicator.wm_channel)

# IP-268 GOG：古德哈特护栏
def goodhart_guard(O_hist, H_hist, anchor_hist):
    d_rank   = rank_divergence(O_hist, H_hist)
    d_anchor = anchor_gap(O_hist, anchor_hist)
    return (d_rank > TAU_G) or (d_anchor > TAU_ANCHOR)   # → 冻结/除名

# IP-273 METER 主闭环（继承 R69；仅在判据处插入计量层）
def METER_round(M, obs):
    vals = M.mgs.evaluate(obs, M.wm_ensemble)            # <0.1ms（证书冻结）
    wvi  = M.wae.score(M.wm_ensemble, M.anchors)
    # 1) 计量前置门：世界模型不可信 / 指标漂移 / 自证超标 → 退回 R69
    if wvi < W_MIN or M.gog.drifted() or M.sj() > SIGMA_SJ:
        return M.fluid_round(obs)
    # 2) 不可补偿的安全过滤
    adm = [a for a in M.candidates if M.mgs.safe_admissible(vals, a)]
    if not adm:                                          # 无可行 → R69/R68
        return M.fluid_round(obs)
    # 3) 字典序：先安全，后效率；平局用鲁棒裕度
    a = M.mgs.lexicographic_argmax(adm, vals)
    # 4) 执行层完全复用 R69（λ、模态、认证都不变）
    k, lam, mode = M.fluid_execute(a, vals)
    M.anchor_log.append((obs, a, vals, wvi))             # 供离线计量
    return k, lam, mode, vals
```

## 3. 推导

**引理 19（特异度 → 古德哈特差距上界）** 设指标 m 的特异度 P、构念 c、策略类容量 C、优化步数 T。若在 m 上取得提升 δ，则其中来自「捷径/无关扰动」的成分 ≥ `(1−P)·δ`；于是真实构念提升 ≤ `P·δ + O(√(C/T))`。系：**P 越低，优化 m 越可能只放大捷径**——特异度证书给出的是古德哈特差距的**证书化上界**，因此低 P 指标必须在安全决策中被除名，而不是「降权后仍参与」。

**引理 20（溯源打破自证）** 设指标 m 的锚链含至少一条与 WM 通道独立的真实锚，锚误差 ≤ ε_a，世界模型集成分歧 ≤ ε_w。则由三角不等式，m 的构念误差 ≤ `ε_w + ε_a`；若全部锚都来自同一 WM 通道（SJ=1），则真实误差可等于 WM 的系统偏差而**无上界**——此时证书只证明「自洽」。系：**SJ 是有界性与无界性的相变点**，不是软性建议。

**引理 21（不可补偿安全不弱于标量化）** 对任意状态，字典序 + 合取得到的可采纳集 ⊆ 任何把安全节点折进标量目标后的「可接受集」；故违规率单调不增。R69 的 `λ_floor` 正是「安全节点集坍缩为单一 U_floor」的标量化特例。

**定理 18（METER 严格包含 R69）** 在 A99–A101（证书 sound、锚链独立、WVI 有界）下，METER 的任意状态期望风险 ≤ R69；且当指标图坍缩为单一安全节点 `U_floor`、`WVI ≥ w_min`、`D_G ≤ τ_G`、`SJ ≤ σ_SJ`、全部证书可采纳时，METER 与 R69 **逐指令相同**（同一 k、λ、mode）。故 R69 是「单仪器 + 可信世界」的退化边界：安全侧不让步，效率侧获得「可证明的仪器」红利。

**定理 19（古德哈特遏制）** 设检测窗口长 W、真实锚独立、漂移率有界 δ。指标漂移在 ≤ W 内被 GOG 检出（概率 ≥ 1−η），检出后决策权切回 H ∪ 安全节点；于是漂移造成的累计后悔 ≤ `W·δ + regret(H)`。世界模型利用由 `anchor_gap` 同界捕获（定义 321）。系：**把「永远优化」换成「优化 + 留出审计」，把无界漂移换成有界窗口损失**。

**定理 20（计量闭环的稳定性）** 若离线计量窗口的证书更新满足：新证书只在 `CV_new` 一致优于 `CV_old` 且不降低任何安全节点时生效，则在稳定环境下证书序列单调不劣，且在线决策不因更新产生跳变（证书运行期冻结 ⇒ 控制连续）。这是 R68 定理 15「换装不变式」在计量层的镜像。

## 6. 本轮最大风险

**一句话**：METER 的全部合法性建立在两个前提上——**锚是独立于世界模型的**、**证书是 sound 的**；一旦真实锚稀缺、标注延迟、或锚本身由同一套感知/世界模型生成，指标体系与世界模型就会**互相认证成一个自洽但错误的世界**——系统会拿着盖满「已验证」印章的指标，在一个自己想象出来的世界里做出「最安全」的决定；**最危险的不是读错表，而是表盘和世界一起错了还彼此作证。**

**次级风险与缓解**：
1. **构念不可识别**（do-calculus 混杂，干预做不干净）→ 标 `uncertifiable`，该指标不得用于安全决策，退回 R69；
2. **WM 集成成员高度相关**（同数据同架构，分歧低估误差）→ 注入扰动/对抗成员（定义 321）+ 真实锚残差兜底；
3. **锚稀缺 / 标注延迟**（真实实验昂贵）→ 溯源预算 + 部署冻结 + 主动选最有判别力的锚，而不是等标签；
4. **指标图膨胀/评估延迟** → 边际决策价值裁剪（定义 318），|V| 设硬上界；
5. **GOG 的留出集也被污染** → H 必须外部持有、限频、不可见于优化回路，且定期轮换；
6. **价值负载（谁定安全权重）** → 安全节点非补偿 + 全链路审计留痕，把「量什么」变成可审查的治理问题，而不是工程默认值。

class MetricGraph:
    def evaluate(self, obs, wm_ensemble):
        vals = {}
        for n in self.topo_order():
            vals[n] = n.fn(vals, obs, wm_ensemble)
            if not n.cert.valid:                       # 证书传染
                vals[n].valid = False
        return vals

    def safe_admissible(self, vals, a):
        if not all(vals[n].passes(a) for n in self.safety_nodes):  # 合取
            return False
        return all(vals[m].cert.admissible for m in self.used_indicators)

# IP-265 CVL：构念效度（敏感度/特异度），最差 WM
def certify(indicator, construct, wm_ensemble):

    for wm in wm_ensemble:
        if not identifiable(wm, construct):
            return Uncertifiable(indicator)            # 混杂 → 不得用于安全
        s = response(indicator, [rollout(wm, do(d)) for d in D_PLUS(construct)])
        p = 1 - response(indicator, [rollout(wm, do(d)) for d in D_ZERO(construct)])
        certs.append(CV(s, p, wm.version))

## 4. 推导

**引理 19（特异度 → 古德哈特差距上界）** 指标 m 特异度 P、在 m 上提升 δ，则其中来自捷径的成分 ≥ `(1−P)δ`，真实构念提升 ≤ `P·δ + O(√(C/T))`。系：低 P 指标必须**除名**而非降权，因为它参与优化就会放大捷径。

**引理 20（溯源打破自证）** 锚链含独立真实锚（误差 ε_a）、WM 集成分歧 ε_w ⇒ 构念误差 ≤ `ε_w+ε_a`；若全锚经同一 WM 通道（SJ=1），误差可等于 WM 系统偏差而**无上界**。系：SJ 是有界/无界的相变点。

**引理 21（不可补偿安全不弱于标量化）** 字典序+合取的可采纳集 ⊆ 标量化「可接受集」，违规率单调不增；R69 的 `λ_floor` 是安全节点坍缩为单节点的特例。

**定理 18（METER 严格包含 R69）** A99–A101 下 METER 任意状态期望风险 ≤ R69；当指标图坍缩为单一安全节点、`WVI ≥ w_min`、`D_G ≤ τ_G`、`SJ ≤ σ_SJ`、证书全部可采纳时，与 R69 逐指令相同（同 k、λ、mode）。R69 = 「单仪器 + 可信世界」边界。

**定理 19（古德哈特遏制）** 检测窗 W、真实锚独立、漂移率有界 δ ⇒ 漂移在 ≤ W 内被 GOG 检出（概率 ≥ 1−η），决策权切回 H ∪ 安全节点，累计后悔 ≤ `W·δ + regret(H)`；模型利用由 anchor_gap 同界捕获。

**定理 20（计量闭环稳定性）** 新证书仅在一致优于旧证书且不降低任何安全节点时生效 ⇒ 证书序列单调不劣；运行期证书冻结 ⇒ 控制连续无跳变（R68 定理 15 的计量层镜像）。

## 7. 本轮最大风险

**一句话**：METER 的全部合法性建立在「锚独立于世界模型」与「证书 sound」两个前提上——一旦真实锚稀缺、标注延迟、或锚本身由同一套感知/世界模型生成，指标体系与世界模型就会**互相认证成一个自洽但错误的世界**，系统拿着盖满「已验证」印章的指标，在一个自己想象出来的世界里做出「最安全」的决定；**最危险的不是读错表，而是表盘和世界一起错了还彼此作证。**

**次级风险与缓解**：构念不可识别（标 `uncertifiable`、退 R69）；WM 集成成员高度相关（扰动/对抗成员 + 锚残差兜底）；锚稀缺/标注延迟（溯源预算 + 部署冻结 + 主动选锚）；指标图膨胀（边际决策价值裁剪 + |V| 硬上界）；留出集被污染（外部持有、限频、不可见、定期轮换）；价值负载（安全节点非补偿 + 全链路审计 + 人类治理）。
