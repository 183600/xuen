# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC IP-153~160；灵感循环第 7 轮；本轮灵感：「关节空间控制」×「低延迟推理」）

> 第 60 轮的 SGEC 把「执行层→证据层」升级为「认知驱动的场景-执行闭环」，用 SSM/CIEC/EPIR/SERC/PCE++++ 让场景先验提前收敛 K_safe、意图锁定 ERTC、证据链防丢包。但它把全部安全承诺停留在**任务空间（Cartesian）**，并默认认知推理可以「无缝地」喂给执行。两个致命缝隙由此暴露：
> 1. **任务空间→关节空间的实现鸿沟**：K_safe、C_intent 都是笛卡尔量（K_p, K_d, F_max, v_max），而电机只认关节力矩 τ。映射 τ = Jᵀ[Λ(ẍ + K_x e + D_x ė)] 依赖构型 q：在奇异位形 σ_min(J)→0 时力矩爆炸、在关节限位/力矩饱和时笛卡尔安全阻抗根本不可实现；冗余臂还存在「同一任务阻抗的多种关节分配」。第 60 轮的 SIC 三元校验只查任务空间可行性，缺一张「关节空间可实现性」证书。
> 2. **慢想→快做的时间尺度失配**：认知栈（场景 Kalman、意图映射、EPIR 同步）延迟在 10²–10³ ms，关节伺服却在 1 kHz（1 ms）。第 60 轮把 τ_response≤2 s 当作「及时」，但对控制环而言这是 2000 个控制周期。更严重的是它从未定义：当认知快照**过期（stale）**时，关节控制器该执行什么？若盲目信任旧 K_safe，就是把「慢推理的滞后」注入「快执行的实时性」。
> 3. **语义可行 ≠ 关节可行**：`加紧` 要求 F_max 超过当前伸展构型下的力矩能力，`轻触` 要求 K_p 低到无法重力补偿——第 60 轮会「锁定一个物理上做不到的意图」。认知先行的代价必须由关节可行性来兜底。

## 0. 直觉与动机

**灵感 1（关节空间控制 → 关节空间实现算子 JR）**
直觉：任务空间的阻抗像「合同条款」，关节力矩像「现金流」——条款再漂亮，现金流断裂就违约。把 K_safe 兑现成 τ 不是一次乘法，而是一个**带约束的投影**：在关节限位、速度/加速度限位、力矩饱和、奇异裕度、接触力锥构成的多面体 Q_joint 里，找离「理想任务力矩」最近的可行力矩。关键洞见：**安全不能在任务空间「宣称」，必须在关节空间「兑现」**——所以需要 realization residual（兑现残差 ρ_real）来量化「合同打了多少折」。

**灵感 2（低延迟推理 → 任意时间推理流水线 LLIP）**
直觉：认知推理像「查资料」：先翻手边便签（缓存先验，0.1 ms），不够再查速查表（蒸馏小模型，1 ms），还不确定才开电脑检索（完整模型，50 ms）。系统 2（慢想）与系统 1（快做）之间必须有一条**截止时间驱动（deadline-aware）**的降级链：到点必须交卷，宁可交一个置信度略低但**按时**的答案，也不能让控制环空转等待。关键洞见：**推理的价值 = 质量 × 按时到达的概率**；晚到的完美答案，在控制环里等价于没有答案。

**灵感 3（双过程合流 → JANUS 双过程安全接口）**
直觉：Kahneman 的 System 1 / System 2。系统 2（SGEC 认知栈）负责「想清楚」——场景、意图、约束；系统 1（关节伺服）负责「做得快」——1 kHz 力矩输出。JANUS 是两副面孔的门神：一面朝内（认知），一面朝外（执行），中间是一道**安全闸门**。闸门规则：系统 2 的新鲜且已认证输出可以**调制**系统 1；系统 2 过期/失效时，系统 1 退回**预认证的反射策略**。关键洞见：接口不是管道，而是**带失效方向的仲裁器**——必须 fail-closed（宁可保守反射），绝不能 fail-open（盲目信任认知）。

**灵感 4（时延不变安全 → 陈旧感知包络 LCCC）**
直觉：如果我只知道「1 秒前的 K_safe 是安全的」，那我现在能安全地用哪个 K？答案不是那个旧的 K，而是**过去整段时延窗口内所有已认证安全集的交集**。给 K_safe 加一个「保质期」：越久越收缩。关键洞见：**时延不改变安全集本身，只改变你被允许使用的安全集**——用一个 Lipschitz 界把「时延」直接换算成「安全裕度的折扣」。

**灵感 5（联合预算 → 认知-控制预算 JCB）**
直觉：第 60 轮的 B_cog 是「认知花多少算力」，本轮必须加上「认知花了多少**控制周期**」。每个 tick 的时间预算是硬约束：Σ 推理耗时 + 伺服 WCET ≤ T_tick。认知多花 1 ms，控制就少 1 ms 裕度。关键洞见：**认知预算与控制预算是同一块蛋糕的两刀**，必须显式换算与抢占，而不是两个独立账户。

**灵感 6（合流 → JANUS 双过程闭环）**
直觉：把上述五者串成：场景/意图（系统2，可慢）→ LLIP 保时交付 → LCCC 用陈旧包络收缩 → JC 判定关节可实现并松弛不可行意图 → JR-QP 兑现为带约束力矩 → ZSS 零空间兜底 → J_cert⁺ 四重证书 → RFP 作为最终安全地板。整条链的原则是「**慢想可以错，快做不能死**」。

## 1. 形式化定义（增量：定义 161–169）

**定义 161（关节空间实现算子 JR）** 对任务空间阻抗指令 u_x = (x_d, ẋ_d, ẍ_d, K_x, D_x) 与构型 q，定义：
- **操作空间惯量**：Λ(q) = (J(q) M⁻¹(q) Jᵀ(q))⁻¹
- **理想任务力矩**：τ_des = Jᵀ[Λ(ẍ_d + K_x e + D_x ė)] + g(q) + C(q,q̇)q̇，其中 e = x_d − x，ė = ẋ_d − ẋ
- **关节可行集**：Q_joint(q,q̇) = {τ | τ_min ≤ τ ≤ τ_max；q̇_min ≤ q̇ ≤ q̇_max；q + q̇Δt ∈ Q_lim；σ_min(J(q)) ≥ σ_safe；|F_c| ≤ F_max^intent}
- **实现算子**：JR(u_x, q, q̇) = argmin_{τ∈Q_joint} ‖τ − τ_des‖²_{W_τ} + ρ‖N* τ − τ_null_ref‖²
- **兑现残差**：ρ_real = ‖τ* − τ_des‖_{W_τ}，可实现判据为 ρ_real ≤ ε_real
- **可实现域**：K_real = {K_safe | JR 有最优解且 ρ_real ≤ ε_real}。第 60 轮保证 K_safe ∈ K_safe^scene；本轮要求 **K_safe ∈ K_safe^scene ∩ K_real**——即场景先验必须再经过关节可实现性筛选。

**定义 162（关节空间安全契约 JC）** 契约向量 C_joint = (τ_max, τ̇_max, q̇_max, q̈_max, m_lim, m_sing, F_c)，其中 m_lim = min_i（q_i 到限位的归一化裕度），m_sing = σ_min(J)/σ_ref。意图约束经雅可比**拉回（pullback）**：C_intent 在构型 q 处关节可实现当且仅当
> Φ_JC(C_intent, q) = 1 ⟺ ∃τ ∈ Q_joint(q) 使任务空间等效约束成立且 ρ_real ≤ ε_real。
若 Φ_JC = 0，触发**语义-关节冲突消解**：按偏序「安全 > 意图 > 任务」求 C_intent 的最大可行子集 C_intent^↓ ⊆ C_intent，并生成 infeasibility 事件。**硬约束**：禁止「任务空间假装满足、关节空间偷偷违约」。

**定义 163（任意时间低延迟推理流水线 LLIP）** 推理层级 ℓ = 0..L，每层为 (代价 c_ℓ, 期望质量 g_ℓ, 提前退出阈值 τ_ℓ)。给定时延硬截止 D 与质量下限 g_min，策略 π_LLIP 按代价递增调用，直到「质量 ≥ τ_ℓ」或「剩余时间 < c_{ℓ+1}」或 ℓ = L。定义：
- **推理新鲜度**：φ(t) = exp(−(t − t_cog)/T_fresh)
- **按时-质量联合效用**：U_LLIP(π) = E[quality]·P(latency ≤ D) − λ·P(fallback)
- **任意时间保证**：返回结果要么在 D 内且质量 ≥ g_min，要么在 D 内返回 fallback（**绝不超时阻塞控制环**）。
可选「投机推理」：用廉价分类器先猜意图，昂贵模型仅在低置信时校验，从而把期望延迟压到 c_0 量级。

**定义 164（时延感知认知-控制契约 LCCC）** 控制 tick t_k 使用认知快照 c(t_k − δ_k)，陈旧度 δ_k：
- **陈旧安全包络**：K_safe^δ(t_k) = ∩_{s∈[0, δ_k]} K_safe^cert(t_k − s)
- **时延不变安全 LIS**：∀δ ∈ [0, δ_max]，以 K_safe^δ 执行同时满足任务空间与关节空间安全
- **充分条件**：若 K_safe^cert(t) 随时间 Lipschitz 连续、‖dK_safe^cert/dt‖ ≤ L_K，则 δ_max·L_K ≤ Δ_margin ⇒ LIS 成立。该式把「时延」直接折算为「安全裕度折扣」，可直接在线监测。
- 当 δ_k > δ_max 或包络为空 ⇒ 立即切入 RFP。

**定义 165（零空间安全盾 ZSS）** 对冗余自由度为 n>m 的机械臂，采用动态一致零空间投影 N* = I − Jᵀ J̄ᵀ，其中 J̄ = M⁻¹JᵀΛ。
- **关节安全势**：U_s(q) = w_lim Σ_i 1/(q_i − q_i^lim)² + w_sing/σ_min(J)² + w_τ Σ_i (τ_i/τ_max,i)²
- **零空间力矩**：τ_null = −k_N N* ∇_q U_s（不破坏任务空间力矩，仅调节姿态）
- **安全盾优先级**：安全 > 意图 > 任务。若 U_s > U_max，ZSS 允许**牺牲任务跟踪**以恢复关节裕度，并记录 override 事件；override 必须写入 J_cert⁺，可审计、可复现。

**定义 166（联合认知-控制预算 JCB）** B_J = (B_cog, B_lat, B_joint, B_task)：
- **时间硬约束**：Σ_ℓ c_ℓ(t_k) + WCET_servo + WCET_ZSS ≤ T_tick
- **预算换算**：B_lat = (T_tick − T_cog_max, δ_max, preempt_slack)；B_joint = (τ 裕度、热裕度、σ_min 裕度)；认知与控制共享同一时间片。
- **降级序**：先降 LLIP 层级（省时间）→ 缩 δ_max（更保守包络）→ 缩任务跟踪 → 最终 RFP。
- **PCE+++++ 联合 VOI**：voi_J = VOI_cog(π) − cost_cog(π) − cost_exec(π) − cost_lat(π)，其中 cost_lat = λ_lat·max(0, Σc − (T_tick − WCET_servo))。

**定义 167（联合空间证书 J_cert⁺ / JSC）** J_cert⁺ = (Cert_task, Cert_joint, Cert_time, Cert_null, hash_chain)：
- **Cert_task**：任务空间契约（承接第 59 轮 J_exec）
- **Cert_joint**：ρ_real ≤ ε_real 且 τ* ∈ Q_joint（限位/饱和/奇异/接触锥）
- **Cert_time**：δ_k ≤ δ_max 且 LLIP 按时（或显式标记 RFP）
- **Cert_null**：U_s ≤ U_max，或 override 已记录
- **hash_chain** = H(hash(EV_exec) ‖ hash(J_cert⁺_prev) ‖ seq_id)，与 EPIR 因果链拼接
- **有效性**：Valid(J_cert⁺) ⟺ 四项全真；任一不真则控制器**不得**以「认知模式」运行，只能以 RFP 运行（fail-closed）。

**定义 168（反射式回退策略 RFP）** π_reflex: (q, q̇, F_ext) → τ_reflex，例如基于无源性的阻尼控制 τ_reflex = −D_ref q̇ − K_ref(q − q_hold) + g(q)，满足：
- **无源性**：∃S(q,q̇) ≥ 0，Ṡ ≤ −q̇ᵀD_ref q̇ ≤ 0（对任意有界外力）
- **约束保持**：∀q ∈ Q_lim，τ_reflex ∈ Q_joint
- **安全地板**：P(safety | π_reflex) ≥ 1 − ε_reflex，且**与认知状态无关**。
JANUS 在 δ_k > δ_max、Valid(J_cert⁺)=false 或 B_lat 超限时切到 π_reflex——这是「慢想」彻底失效时系统 1 的最后防线。

**定义 169（JANUS 双过程闭环算子）** 设 M 为系统状态，T_tick 为控制周期：
```
JANUS(M, task):
  loop at t_k (1 kHz):
  ① System2（可异步、可延迟）: c_k ← SSM.update + CIEC.map + EPIR.append

```

## 2. 关键算法伪代码

### IP-161 JR（关节空间实现算子）

```python
def joint_realization(u_x, q, qdot, robot, intent, eps_real=1e-2):
    J = robot.jacobian(q)
    Minv = np.linalg.inv(robot.mass_matrix(q))
    Lam = np.linalg.inv(J @ Minv @ J.T)
    e = u_x.x_des - robot.fk(q)
    ed = u_x.dx_des - J @ qdot
    tau_des = (J.T @ (Lam @ (u_x.ddx_des + u_x.Kx @ e + u_x.Dx @ ed))
               + robot.gravity(q) + robot.coriolis(q, qdot))
    Q = build_joint_constraints(intent, q, qdot, robot)
    tau = solve_qp(np.eye(robot.n), tau_des, Q)   # min ||tau - tau_des||^2
    residual = np.linalg.norm(tau - tau_des)
    return tau, residual, residual <= eps_real
```

### IP-162 JC（关节空间安全契约与意图松弛）

```python
def is_joint_realizable(C_intent, q, robot):
    tau, residual, ok = joint_realization_as_constraint(C_intent, q, robot)
    return ok and in_joint_set(tau, q, robot)

def relax_intent(C_intent, q, robot):
    # 偏序：安全 > 意图 > 任务；先放松力/速度，再放松刚度
    for key in ['F_max', 'v_max', 'K_p', 'K_d']:
        if key in C_intent:
            C_intent[key] = safe_relax(C_intent[key], q, robot)
            if is_joint_realizable(C_intent, q, robot):
                return C_intent, True
    return default_safe_constraint(robot), False
```

### IP-163 LLIP（任意时间低延迟推理）

```python
class AnytimeInference:
    def __init__(self, levels):          # [(cost_s, model, tau_exit), ...]
        self.levels = levels

    def infer(self, query, deadline):
        t0 = time.perf_counter()
        best = FALLBACK_DEFAULT
        for cost, model, tau_exit in self.levels:
            if (time.perf_counter() - t0) + cost > deadline:
                break
            out = model(query)
            best = out
            if out.confidence >= tau_exit:
                break 
        return best, time.perf_counter() - t0
```

### IP-164 LCCC（时延不变安全包络）

```python
class StalenessSafeEnvelope:
    def __init__(self, delta_max, L_K, margin):
        self.delta_max, self.L_K, self.margin = delta_max, L_K, margin

    def lis_ok(self, delta):
        return delta * self.L_K <= self.margin

    def envelope(self, history, t_now, delta):
        if not self.lis_ok(delta):
            return None
        window = [s.K_safe for s in history if t_now - delta <= s.t <= t_now]
        if not window:
            return None
        return intersect_convex_sets(window)   # 保守交集，越久越收缩
```

### IP-165 ZSS（零空间安全盾）

```python
def null_space_shield(q, qdot, tau, robot, U_max):
    J = robot.jacobian(q)
    Minv = np.linalg.inv(robot.mass_matrix(q))
    Lam = np.linalg.inv(J @ Minv @ J.T)
    Jbar = Minv @ J.T @ Lam
    Nstar = np.eye(robot.n) - J.T @ Jbar.T
    U, grad = joint_safety_potential(q, tau, robot)
    if U > U_max:
        tau = tau - robot.kN * (Nstar @ grad)
        return project_to_joint_limits(tau, q, robot), True
    return tau, False
```

### IP-166 JCB（联合认知-控制预算）

```python
class JointBudget:
    def __init__(self, T_tick, wcet_servo, wcet_zss, delta_max):
        self.T_tick = T_tick
        self.T_cog_max = T_tick - wcet_servo - wcet_zss
        self.delta_max = delta_max
        self.used = 0.0

    def can_infer(self, cost):
        return self.used + cost <= self.T_cog_max

    def account(self, t_cog, tau_margin, delta):
        self.used += t_cog
        return tau_margin > 0 and delta <= self.delta_max

    def degrade(self):
        if self.delta_max > 0:
            self.delta_max *= 0.5
            return 'shrink_delta'
        return 'reflex'
```

### IP-167 J_cert⁺（联合空间证书）

```python
def build_joint_certificate(task_cert, tau, residual, q, qdot,
                            delta, U_s, robot, prev_hash, seq_id):
    body = {
        'task':  task_cert.valid,
        'joint': (residual <= robot.eps_real) and in_joint_set(tau, q, robot),
        'time':  delta <= robot.delta_max,
        'null':  U_s <= robot.U_max,
    }
    h = hashlib.sha256(json.dumps(body, sort_keys=True).encode()).hexdigest()
    chain = hashlib.sha256((prev_hash + h + str(seq_id)).encode()).hexdigest()
    return {'body': body, 'hash': h, 'chain': chain, 'valid': all(body.values())}
```

### IP-168 RFP（反射式回退策略）

```python
class ReflexiveFallback:
    def __init__(self, D_ref, K_ref, q_hold):
        self.D_ref, self.K_ref, self.q_hold = D_ref, K_ref, q_hold

    def __call__(self, q, qdot, f_ext, robot):
        tau = -self.D_ref @ qdot - self.K_ref @ (q - self.q_hold) + robot.gravity(q)
        return project_to_joint_limits(tau, q, robot)
```

### IP-169 JANUS（双过程闭环主循环）

```python
def janus_loop(M, task):
    while not done(task):
        t_k = M.clock.now()
        M.cog.submit(M.ssm.update(M.telem), M.ciec.map(M.intent), M.epir.append)
        c_k, delta = M.llip.infer(M.cog.latest(), deadline=M.budget.T_cog_max)

        K_delta = M.lccc.envelope(M.cert_history, t_k, delta)
        if K_delta is None or not M.lccc.lis_ok(delta):
            tau = M.rfp(M.q, M.qdot, M.f_ext, M.robot)
            M.log('reflex', delta=delta)
            continue

        C_int = c_k.intent_constraint
        if not M.jc.is_realizable(C_int, M.q, M.robot):
            C_int, _ = M.jc.relax(C_int, M.q, M.robot)
            M.log('intent_relaxed', C_int=C_int)

        tau, residual = M.jr(M.ux(K_delta, C_int), M.q, M.qdot, M.robot, C_int)
        U_s = M.zss.potential(M.q, tau, M.robot)
        tau, overridden = M.zss.shield(M.q, M.qdot, tau, M.robot)

        M.servo.apply(tau)
        cert = build_joint_certificate(M.task_cert, tau, residual, M.q, M.qdot,

def joint_realization(u_x, q, qdot, robot, intent, eps_real=1e-2):
    J = robot.jacobian(q)
    Minv = np.linalg.inv(robot.mass_matrix(q))
    Lam = np.linalg.inv(J @ Minv @ J.T)
    e, ed = u_x.x_des - robot.fk(q), u_x.dx_des - J @ qdot
    tau_des = (J.T @ (Lam @ (u_x.ddx_des + u_x.Kx @ e + u_x.Dx @ ed))
               + robot.gravity(q) + robot.coriolis(q, qdot))
    Q = build_joint_constraints(intent, q, qdot, robot)
    tau = solve_qp(np.eye(robot.n), tau_des, Q)
    residual = np.linalg.norm(tau - tau_des)
    return tau, residual, residual <= eps_real
```

class JointBudget:
    def __init__(self, T_tick, wcet_servo, wcet_zss, delta_max):
        self.T_tick = T_tick
        self.T_cog_max = T_tick - wcet_servo - wcet_zss
        self.delta_max, self.used = delta_max, 0.0

    def can_infer(self, cost):
        return self.used + cost <= self.T_cog_max

    def account(self, t_cog, tau_margin, delta):
        self.used += t_cog
        return tau_margin > 0 and delta <= self.delta_max

    def degrade(self):
        if self.delta_max > 0:

            return 'shrink_delta'
        return 'reflex'
