# 第 70 轮（承接第 69 轮「FLUID-RAS 不确定性二分闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「力矩控制」×「行为克隆」）

> R69 把不确定性一分为二（aleatoric / epistemic），并用「主动交互」去消解 epistemic；它把 R68 的保守主义严格包含为「永不交互」的边界。但 R69 仍默默假设了两件事：
> (a) **策略的多模态分布是可信的**——它没有回答「这些模态是从哪来的」；而 R69 自陈的最大风险恰恰是「流模型幻觉模态 / 坍缩模态」。
> (b) **不确定性一旦在动作空间里被消解，就自然变成安全的行为**——它没有回答「选定的模态如何变成物理力矩」，也没有把物理层自身当作信息源。
>
> 本轮两个灵感正好补上这两块：
> - **行为克隆**（BC）交代模态的出处：策略学的是示教者的条件分布 p_D(a|s)，不是最优分布 p*(a|s)。于是「歧义」至少有四种来源：**任务本身多峰**（问世界可解）、**示教者之间不一致**（问世界无用）、**示教覆盖空洞**（问世界无用，只能要新示教）、**控制器/动作空间迁移失配**（只能靠物理层暴露）。更尖锐的是 Polanyi 的「默会知识」：示教里有一部分知识无法被语言化，**R69 的「问」在这部分上有信息论下界**。
> - **力矩控制**交代不确定性的最终汇率：被选中的意图必须落成阻抗/力矩（刚度 K、阻尼 D、力矩上限 τ_max）。刚度就是「承诺程度」；而力矩/接触不只是执行通道，还是**本体感觉通道**——τ_meas 与模型预测之差暴露了视觉看不见的接触、负载、滑移与控制器失配。于是「让一点」——降低刚度、限制力矩——成为仅次于「慢」和「问」的**第三种不确定性响应：顺从（yield）**，且可用无源性能量罐严格认证。
>
> 核心命题：**不确定性应当按「哪一种动作能消解它」来划分，而不是只按「是否可约」来划分。** 把 R69 的 U_epi 再按消解算子拆成 U_task（问世界可解）、U_demo（只能要新示教）、U_xfer（只能顺从 + 物理层观测）；响应菜单从 {慢, 问} 扩展为 {慢, 问, 顺, 要示教}。命名 **TACIT-RAS**（Torque-Aware Compliant interaction with provenance-Identified uncertainty, from Imitation；亦取 Polanyi「默会知识」之意）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**这是谁教我的、我又能让出多少**」——不是所有不知道都能问出来；有些只能在物理上退让，或者诚实地承认「请再教我一次」。

## 0. 直觉与动机

**灵感 1（行为克隆 → 先验有出处，也有不可问的盲区）**
直觉：BC 最小化 `−log π(a|s)` 于示教集 D，所以 `π_θ(·|s) ≈ p_D(·|s)`。如果两个示教者在同一状态做不同动作，流策略会分叉；这分叉是**示教者不一致**，不是「世界有歧义」——你问环境一百次，它也不会告诉你该听哪位老师。反之，如果某个状态从未被覆盖，流模型在那里给出的「模态权重」是外推/幻觉，问环境同样无济于事，因为问题不在世界而在**数据**。更根本地，BC 只有 (s,a) 正样本，没有「如果当时问了 g 会怎样」的反事实标签，所以 **R69 的 MINT 根本不可能被克隆出来，只能被算出来**——这与 R69「复用 trunk、零重复训练」的叙事有一个隐藏裂缝。最后是 Polanyi 的默会知识：示教者自己常常说不清「为什么这样做」，事后解释还可能是编造。**能被问出来的 epistemic，只是全部 epistemic 的一个子集。**

**灵感 2（力矩控制 → 不确定性的最终汇率，以及一条新的感知通道）**
直觉：位置控制把「我有多确定」藏在控制器里；力矩控制把它暴露在台面上。刚度 K 就是承诺：K 大 =「我确信，并且要对抗扰动」；K 小 =「我不确定，让环境主导」。当 U_demo 大又无法问时，正确动作往往不是更硬的刹车（抱住一个错误模态只会更危险），而是**松一点、限力矩**：让接触本身把信息带回来。更深一层，**刚性控制会掩盖外力**（控制器把 τ_meas 顶回 τ_cmd，残差被吃掉），而柔顺控制让外力显形；所以「顺从」不只是安全退让，还是**主动感知**。无源性能量罐保证：降低刚度/力矩是耗散的、永远许可；提高刚度/注入能量才需要预算。这把「让」从一种模糊的怯懦变成可认证的动作。

**灵感 3（按消解算子分区 → R69 的二分还是太粗）**
直觉：R69 用「可约/不可约」分类。但「可约」不是一个等价关系：任务歧义可以问，示教空洞问不出来，控制器失配只能靠摸。正确的划分标准是「**哪一种动作能消解它**」——`U_ale`（无动作可消解）→慢；`U_task`（问可消解）→问；`U_demo`（只有新示教可消解）→要示教；`U_xfer`（只有物理接触可显形）→顺从。这不是把模型越拆越碎，而是把「响应」和「不确定性」做成**同一张索引表**：每种不确定性只允许走它能走的通道。R68/R69 于是成为这张菜单上的子集。

**灵感 4（严格包含 → 新响应必须是旧响应的退化）**
直觉：R68 = {慢}，R69 = {慢, 问}，R70 = {慢, 问, 顺, 要示教}。若某状态 `U_demo = U_xfer = 0`，TACIT 的响应菜单自动只剩 R69 的行为；若再 `U_task = 0`，只剩 R68。字典序上把硬安全（碰撞/跌落/伤人）放在最前，任何性能、能量、信息收益都买不断它。新层不能是并列替代，只能是严格泛化——否则每加一种响应就多一个需要独立信任的黑箱。

**灵感 5（顺从是双刃剑 → 让出控制权等于让出攻击面）**
直觉：会「问」就会撒谎，会「顺」就会被推。合规控制把一部分权限交给环境：在接触任务里这是安全与感知的来源，在敌意环境里这就是**帮凶**——推一下柔顺的机器人，它优雅地退进危险区；伪造一次接触，它就一直「等」；背驱注入假力矩，它就把假接触当真。会克隆就会被投毒：往示教池里塞几条「看似合理」的恶意示教，流策略会忠实地学出一个幻影模态，而护照还可能给它盖章。所以本轮必须同时交付：示教来源护照、合规权限预算、力矩残差的抗欺骗设计、以及新的对抗干扰集。否则 TACIT 不是进步，而是给 R69 的交互主义接上了一副**会主动松手的身体**。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（TACIT-RAS 总览）** TACIT-RAS = (PUD, DPP, ICL, PEC, TRM, RSM, HDR, RAS-WM†)。四不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **来源诚实**：若某响应 ρ 对某类不确定性的可消解增益为 0，则禁止用 ρ 去「处理」它——不能问一个问不出来的问题，也不能用顺从假装解决了示教空洞；
(iii) **无源与硬安全**：每个阻抗/力矩指令过 PEC，硬安全约束（碰撞/跌落/伤人）在字典序上高于性能、能量与信息收益；
(iv) **示教证据纪律**：新示教先过来源护照，单条示教不得认证一个区域；问世界（在线）与要示教（离线）是两种不同预算。

**定义 311（按消解算子的不确定性分解）** 响应算子 `ρ ∈ {∅, g, θ, demo}`（不动作 / 信息动作 / 阻抗动作 / 要示教）。四分量：
`U_ale = Σ_k ŵ_k tr(Σ_k)`（模态内噪声，ρ=∅）；
`U_task = H_mode · g(Δ_min) · α(o) · s(o)`（示教一致且被覆盖的模态间歧义，ρ=g；α∈[0,1] 为示教一致度，s 为支持门）；
`U_demo = I(M; demonstrator_id | o) + CovPenalty(o)`（示教不一致 + 覆盖惩罚，ρ=demo）；
`U_xfer = Γ(‖τ_res‖)`（由控制器/动作空间失配诱发的模态不确定，ρ=θ）。
四者语义不同，**不做简单加和**，按定义 320 各自进入不同通道。`CovPenalty` 用局部示教密度的 kNN 半径；`Γ` 单调不减。

**定义 312（示教护照 DPP）** 区域 B 的护照 `DPP(B) = (n_B, d_B, α_B, κ_B, t_B)`：样本数、有效密度（kNN）、示教一致度（同状态跨示教者的动作方差/模态一致率）、控制器来源标签（position/torque/impedance）、时间戳。Valid ⇔ `n_B ≥ n_min ∧ d_B ≥ d_min ∧ α_B ≥ α_min ∧ κ_B` 与执行控制器匹配（或迁移风险已标定）。覆盖率用**分裂共形校准**给出有限样本保证；护照不是一次性全局标签，而是随区域/随时间的局部证书。

**定义 313（BC 下的模态来源）** `π_θ` 在 D 上最小化负对数似然，故 `π_θ(·|s) ≈ p_D(·|s)`。给每个模态贴来源标签 `∈ {task, demo, artifact}`：task = 示教一致的真实多峰；demo = 示教者分歧；artifact = 低密度外推/流采样幻觉。辅助判别器 `q(demo_id | s, a)` 与密度估计给出部分可识别性（引理 19）。**任何模态进入 U_task 前必须先通过来源门。**

**定义 314（含阻抗承诺的增广动作）** `ξ = (a, g, θ) ∈ 𝒜_task × 𝒜_info × Θ`，`θ = (K, D, τ_max)`。θ 不是事后整定的控制器参数，而是**模态的承诺**：策略在输出任务动作与信息动作的同时输出阻抗剖面；同一任务动作配不同 θ 代表不同「确信程度」。

**定义 315（力矩/阻抗执行）** `τ = K_p(q_d − q) + K_d(q̇_d − q̇) + τ_ff`，`|τ| ≤ τ_max`；末端等效力 `F = J^{-T} τ`。强调 `τ_max` 是**关节空间**上限，奇异位形附近同一 τ_max 对应的末端力可以很大（定义 317 监控），因此「限力矩」不等于「限末端力」。

**定义 316（无源能量罐 PEC）** 罐能 `E_t ≥ 0`，`Ė_t = β·P_in − P_out`（`0 < β ≤ 1`，P_in 为刚度/前馈注入，P_out 为耗散）。**降低 K 或 τ_max 是耗散，永远许可；提高刚度或注入能量必须 `E_t ≥ ΔE(θ→θ')`。** 由此接触能量 `≤ E_t + ∫P_out`；顺从（yield）天然落在许可侧。

**定义 317（力矩残差监测 TRM）** `τ_res(t) = τ_meas(t) − [M(q)q̈_d + C(q,q̇)q̇ + g(q)]`（或 `τ_meas − τ_cmd`）。视觉/触觉无变化而 `τ_res` 持续异常 ⇒ 隐藏接触、负载、滑移或控制器失配。TRM 与 R68 的 `r_res`（传感器自洽）、R69 的 `a_score`（行为自洽）组成**三通道**：传感器自洽 / 行为自洽 / **物理自洽**；物理自洽不能被视觉标定吸收，因为它是执行器处测到的。

**定义 318（响应菜单 RSM）** `ρ* = argmin_{ρ∈{slow, ask, yield, request_demo}} E[risk_after(ρ)] + cost(ρ)`，s.t. 硬安全与 PEC。字典序：**硬安全 ≻ 无源 ≻ 来源诚实 ≻ 收益**。若某类不确定性在可行 ρ 上增益 ≤ 成本，则取最保守的可行组合（通常是 slow + yield）。

**定义 319（BC 下的 VoI 可辨识性）** `VoI_ask(g) = I(M; y_g | o) − c(g)`。把模态潜变量写成 `M = (M_task, M_demo)`，其中 `M_demo` 由示教者身份/覆盖决定、**不进入当前可观测 y_g**；则 `I(M; y_g|o) ≤ I(M_task; y_g|o) ≤ H(M_task)`。故 `U_demo` 的覆盖分量对任何在线 g 的 VoI 恒为 0。要示教的 VoI 定义在**数据分布**上：`VoI_demo = E_{s~覆盖空洞}[ΔH(M|s)]`，成本 = 人类示教时间 + 在线等待风险。这给出「问 vs 要示教」的硬判别规则。

**定义 320（三级退避与合规 resolution bonus）** 若 `U_task` 在预算内消解：`λ = λ_floor(U_ale)`，且 PEC 允许时可**提高 K**（commit bonus，比 R69 更敢做）；若 `U_demo/U_xfer` 未消解或护照无效：`λ = λ_floor(U_ale + 残余)` 且 `K ≤ K_soft, τ_max ≤ τ_safe`。R68 = 仅 slow 通道；R69 = slow+ask；TACIT 严格包含二者（定理 18）。

**定义 321（U_demo 的在线不可约下界）** `U_demo ≥ h(ε_cov)`，`ε_cov` 由留一示教/共形分位数给出。在线任何 g 不能降低该下界（引理 20）；只能离线要示教，或在线让出权限并等待人类接管。

**定义 322（三类预算与证据纪律）** 交互预算（继承 R69）+ **示教预算**（每小时人类示教次数/时长）+ **顺从权限预算**（单位时间可让出的最大力矩与最长时长）。证据纪律扩展：相机 + 力矩 + 触觉至少两源一致才可定案；单条示教不得认证区域；被顺从引导的决策不得仅凭「人推了一下」定案。

**定义 323（示教投毒 ℰ_demo）** 注入恶意示教制造假模态、伪造控制器来源标签、污染护照；共形校准在投毒示教池下会失效。

**定义 324（合规攻击 ℰ_comp）** 推合规机器人进危险区、伪造接触诱发无限 yield、背驱注入假 `τ_res`、以「接近最优」的伪造地形诱骗刚度提升、权限劫持。

**定义 325（证书 J_TACIT）** `J_TACIT = (J_FLUID, provenance_mix, passport_coverage, ece_demo, tank_min, trm_p95, comp_log_hash, tacit_ver)`。Valid ⇔ `Valid(J_FLUID) ∧` 来源分解已记录 ∧ 护照覆盖达标 ∧ `tank_min ≥ 0` ∧ 合规日志哈希可审计 ∧ 证据纪律满足。

**定义 326（多速率与无扰切换）** 策略/来源分解/RSM 运行于 10–30 Hz；阻抗/PEC/TRM 运行于 1 kHz。K/τ_max 变更须经斜坡或一阶滤波（bumpless），模态切换只在认证集内进行，保证力矩连续、无突变（延伸 R69 定理 17 的提交/换装不变式）。

# IP-264 PUD：按消解算子分解不确定性来源
def decompose_provenance(samples, z, demos, o):
    modes = cluster_trajectories(samples)
    w     = mode_weights(modes)
    U_ale = sum(w[k] * trace(cov(modes[k])) for k in modes)
    agree = inter_demo_agreement(modes, demos, o)     # 0..1
    dens  = local_density(demos, o)                   # kNN
    U_task = entropy(w) * sep_factor(modes) * agree * support_gate(dens)
    U_demo = cond_mutual_info(mode, demo_id, o) + cover_penalty(dens)
    U_xfer = trm_induced_mode_uncertainty()           # 由 IP-268 回填
    return Provenance(U_ale, U_task, U_demo, U_xfer, modes)

# IP-265 DPP：示教护照（局部、可校准）
def passport(demos, region):
    n, d = len_in(region), knn_density(region)
    a    = inter_demo_agreement_region(region)
    kappa= controller_tag(region)
    cov  = split_conformal_coverage(demos, region)     # 有限样本保证
    return Cert(n, d, a, kappa, cov,
                valid=(n>=N_MIN and d>=D_MIN and a>=A_MIN and kappa==EXEC_TAG))

# IP-266/267：阻抗承诺 + 无源能量罐
def commit(mode, prov, tank):
    theta = mode.theta
    if prov.U_demo > TAU_DEMO or prov.U_xfer > TAU_XFER:
        theta = soften(theta, K_soft, TAU_SAFE)        # 只降不升，天然许可
    elif prov.U_task > TAU_TASK and not prov.resolved:
        theta = soften(theta, K_probe, TAU_PROBE)      # 柔顺探询
    if raises_stiffness(theta, tank.current_theta):
        if not tank.allow(delta_E(theta, tank.current_theta)):
            theta = min_stiffen(tank.current_theta, theta)   # PEC 否决
    return theta

# IP-268 TRM：物理自洽第二意见（1 kHz）
def torque_residual(tau_meas, q, qd, qdd, model):
    return tau_meas - model.inverse_dynamics(q, qd, qdd)
def trm_anomaly(res, visual_change):
    return lowpass(res) > TAU_TRM and visual_change < TAU_VIS

# IP-269 RSM：三通道响应选择
def choose_response(prov, budget):
    c = [('slow',  risk_gain_slow(prov),  cost_slow(prov))]
    if prov.U_task > TAU_TASK:  c.append(('ask',     voi_task(prov),  cost_ask(prov)))
    if prov.U_demo > TAU_DEMO:  c.append(('request_demo', voi_demo(prov), cost_demo(prov)))
    c.append(('yield', safety_gain_yield(prov), cost_yield(prov)))
    c = [x for x in c if x[1] > 0 or x[0] in ('slow', 'yield')]  # 来源诚实过滤
    return argmax(c, key=lambda x: x[1] - x[2])

# IP-274 主闭环（继承 R69，插入来源分解与阻抗承诺）
def TACIT_round(M, obs):
    z, o   = M.mtm.forward(obs)
    K      = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples= M.fmp.sample(o, K)
    prov   = M.pud.decompose_provenance(samples, z, M.demos, o)
    pp     = M.dpp.check(o)
    trm    = M.trm.anomaly(M.tau_meas, M.vision_delta)
    if not pp.valid:
        prov.U_demo = max(prov.U_demo, U_DEMO_FLOOR)   # 护照缺口 → 保守
    rho    = M.rsm.choose_response(prov, M.budget)
    if rho == 'ask':
        prov = M.pud.update_task(prov, M.mint.execute(prov, o))
    elif rho == 'request_demo':
        M.hdr.request(o, pp)                           # 离线，人类接管
    # 阻抗承诺：先软化，再在 PEC 允许时提升
    theta  = M.icl.commit(M.select_mode(prov), prov, M.tank)
    lam    = lam_floor(prov.U_ale + prov.residual())
    mode   = M.select_mode(prov, lam)
    tau    = M.pi_sigma.torque(mode, theta)            # 1 kHz 内环
    M.pec.step(tau, theta, M.tank)                     # 无源守门
    M.vqa_i.submit_async(rho, prov, trm, pp)
    return mode, theta, tau, prov

## 3. 推导

**引理 19（示教来源的可辨识性）** 设 A99：跨示教者动作方差可测、局部示教密度可估、控制器来源标签已知。则在状态 s 处，来源划分 `(task / demo / artifact)` 在有限样本误差 `ε_n` 内可识别；若所有示教者在 s 邻域内一致且密度高于阈值，则多峰**不能**归因于示教方差，只能归因于任务本身或模型幻觉——而这两者只能用留出示教者区分。系：护照的 `α_B` 与 `d_B` 是「模态权重可否进入 U_task」的**必要证据**，不是元数据。

**引理 20（默会知识壁垒 / 求证上限）** 令 `M = (M_task, M_demo)`，`M_demo` 由示教者身份与覆盖决定且不进入当前信息动作的可观测 `y_g`。则 `VoI_ask(g) = I(M; y_g|o) ≤ I(M_task; y_g|o) ≤ H(M_task)`；对覆盖分量恒为 0。故 `U_demo` 是**在线不可问**的：它的唯一在线处置是顺从（让环境/人类主导），唯一离线处置是索取新示教。系：R69「问错比不问更危险」在 R70 有了精确形态——**问一个只存在于数据里的问题，连错都问不出来**。

**引理 21（合规即感知 / 物理 VoI）** 刚性位置控制下 `τ_meas ≈ τ_cmd`，外力被控制器顶回，`τ_res` 对外接触不敏感；当刚度降到 `K_soft`，接触力经 `τ = K(q_d−q)` 显形，`τ_res` 的信噪比随 `1/K` 提升（在传感器噪声以下有上界）。故 yield 同时提供安全与信息：`VoI_yield > 0` 当且仅当接触模态可观测；PEC 把注入能量限在 `E_t` 内。系：**顺从不是被动放弃，而是把物理接触变成一次探针**。

**定理 18（TACIT 严格包含 R68 / R69）** 将 RSM 限制为 `{slow}` 即 R68；限制为 `{slow, ask}` 即 R69。加入 `{yield, request_demo}` 后，由字典序硬安全 + PEC，任意状态期望风险 ≤ 旧系统；当 `U_demo = U_xfer = 0` 时，TACIT 逐指令退化为 R69，`U_task = 0` 时退化为 R68。安全侧不让步；效率侧获得 commit bonus（可更硬）与 yield bonus（可更软），二者都受 PEC 与护照约束。

**定理 19（顺从的无源性安全）** 在力矩饱和 + 能量罐下，变阻抗闭环对 `(τ_ext, q̇)` 无源；接触能量 `≤ E_t + ∫P_out`；有界时延下无源性保持。故**降刚度/限力矩不会引入不稳定**。但须强调：无源只保证稳定性，不保证任务安全——对抗性环境下「被推着走」仍可能进入危险区（见第 6 节）。

**定理 20（护照的诚实性边界）** 若用同一示教池既拟合又认证且不做留出/共形，假认证率可被示教投毒任意抬高；采用分裂共形 + 留出示教者，假认证率 `≤ α + δ_n`。推论：护照的有效性以「示教池未被投毒」为前提；一旦来源不可信，必须把 `DPP` 视为无效并退回 `slow + yield`，不能靠更多采样「自证清白」。

## 6. 本轮最大风险

**一句话**：TACIT-RAS 把安全性押在「让出刚度 = 让出安全」这一反直觉前提上——**一旦环境是敌意的，顺从就不是在保护机器人，而是在把控制权交给推它的人**；而力矩残差又可被背驱伪造，于是系统会优雅地、物理地、且「有证书地」服从一次攻击。

**次级风险与缓解**：
1. **护照自我认证偏差**（用同一示教池拟合又认证）→ 分裂共形 + 留出示教者 + 投毒检测（定理 20）；
2. **合规权限被滥用**（被推入危险区、假接触拖死）→ 顺从权限预算 + TRM 抗欺骗 + 硬安全包络不可让（定义 322/324）；
3. **关节力矩上限 ≠ 末端力上限**（奇异位形附近）→ 笛卡尔力估计 + 奇异度门控 + 实时 TRM（定义 315/317）；
4. **动作空间迁移失配**（位置示教学、力矩执行）→ 来源标签 κ + 逆动力学标定 + E307；
5. **来源误归因**（把任务歧义当示教噪声 → 该问不问；或把示教空洞当任务歧义 → 问个没完）→ E301/E303 + 护照门 + 来源诚实不变式。

# IP-264 PUD：按消解算子分解不确定性
def decompose_provenance(samples, z, demos, o):
    modes  = cluster_trajectories(samples); w = mode_weights(modes)
    U_ale  = sum(w[k]*trace(cov(modes[k])) for k in modes)
    agree  = inter_demo_agreement(modes, demos, o)
    dens   = local_density(demos, o)
    U_task = entropy(w)*sep_factor(modes)*agree*support_gate(dens)
    U_demo = cond_mutual_info(mode, demo_id, o) + cover_penalty(dens)
    return Provenance(U_ale, U_task, U_demo, trm_induced_mode_uncertainty(), modes)

# IP-265 DPP：局部护照 + 共形覆盖
def passport(demos, region):
    return Cert(len_in(region), knn_density(region),
                inter_demo_agreement_region(region), controller_tag(region),
                split_conformal_coverage(demos, region))

# IP-266/267 ICL+PEC：先软化，再在罐能允许时提升
def commit(mode, prov, tank):
    theta = mode.theta
    if prov.U_demo > TAU_DEMO or prov.U_xfer > TAU_XFER:
        theta = soften(theta, K_soft, TAU_SAFE)          # 降刚度恒许可
    elif prov.U_task > TAU_TASK and not prov.resolved:
        theta = soften(theta, K_probe, TAU_PROBE)        # 柔顺探询
    if raises_stiffness(theta, tank.theta) and not tank.allow(delta_E(theta, tank.theta)):
        theta = tank.theta                               # PEC 否决
    return theta

# IP-268 TRM：物理自洽（1 kHz）
def torque_residual(tau_meas, q, qd, qdd, model):
    return tau_meas - model.inverse_dynamics(q, qd, qdd)
def trm_anomaly(res, vision_delta):
    return lowpass(res) > TAU_TRM and vision_delta < TAU_VIS

# IP-269 RSM：四通道响应
def choose_response(prov, budget):
    c = [('slow', risk_gain_slow(prov), cost_slow(prov))]
    if prov.U_task > TAU_TASK: c.append(('ask', voi_task(prov), cost_ask(prov)))
    if prov.U_demo > TAU_DEMO: c.append(('request_demo', voi_demo(prov), cost_demo(prov)))
    c.append(('yield', safety_gain_yield(prov), cost_yield(prov)))
    c = [x for x in c if x[1] > 0 or x[0] in ('slow', 'yield')]
    return argmax(c, key=lambda x: x[1] - x[2])

# IP-274 主闭环（继承 R69）
def TACIT_round(M, obs):

    elif rho == 'request_demo': M.hdr.request(o, pp)
    theta = M.icl.commit(M.select_mode(prov), prov, M.tank)
    lam   = lam_floor(prov.U_ale + prov.residual())

    tau   = M.pi_sigma.torque(mode, theta)
    M.pec.step(tau, theta, M.tank)
    M.vqa_i.submit_async(rho, prov, trm, pp)

## 4. 推导

**引理 19（示教来源可辨识性）** 在 A99（跨示教方差可测、密度可估、控制器标签已知）下，`(task/demo/artifact)` 在有限样本误差内可识别；示教一致且被覆盖时多峰不能归因于示教方差。系：护照的 α、d 是模态能否进入 U_task 的必要证据。

**引理 20（默会知识壁垒）** `M=(M_task,M_demo)` 且 `M_demo` 不进入当前可观测 `y_g`，则 `VoI_ask ≤ I(M_task;y_g|o)`，覆盖分量恒为 0：U_demo 在线不可问，只能要新示教或顺从。系：问一个只存在于数据里的问题，连错都问不出来。

**引理 21（合规即感知）** 刚性控制使 `τ_meas≈τ_cmd` 掩盖外力；降刚度后接触力经 `τ=K(q_d−q)` 显形，`τ_res` 信噪比随 `1/K` 提升（有传感器噪声上界）。故 yield 同时提供安全与信息，PEC 限制注入能量。

**定理 18（严格包含 R68/R69）** RSM 限制为 `{slow}` 即 R68，`{slow,ask}` 即 R69；加入 `{yield,request_demo}` 后由字典序硬安全 + PEC，任意状态风险 ≤ 旧系统；`U_demo=U_xfer=0` 时逐指令退化为 R69，`U_task=0` 时退化为 R68。效率侧获 commit/yield bonus，均受 PEC 与护照约束。

**定理 19（顺从的无源性安全）** 力矩饱和 + 能量罐下变阻抗闭环对 `(τ_ext,q̇)` 无源，接触能量 `≤ E_t+∫P_out`，有界时延下保持。但无源只保证稳定，不保证对抗环境下的任务安全。

**定理 20（护照诚实性边界）** 同一示教池既拟合又认证时假认证率可被投毒任意抬高；分裂共形 + 留出示教者下 `≤ α+δ_n`。系：示教来源不可信时，护照必须判无效并退回 `slow+yield`，不能靠更多采样自证。

## 7. 本轮最大风险

**一句话**：TACIT-RAS 把安全性押在「让出刚度 = 让出安全」这一反直觉前提上——**一旦环境是敌意的，顺从就不是在保护机器人，而是在把控制权交给推它的人**；而力矩残差又可被背驱伪造，于是系统会优雅地、物理地、且「有证书地」服从一次攻击。

**次级风险与缓解**：护照自我认证偏差（分裂共形 + 留出示教者 + 投毒检测）；合规权限滥用（顺从预算 + TRM 抗欺骗 + 硬安全不可让）；关节力矩上限 ≠ 末端力上限（笛卡尔力估计 + 奇异度门控）；位置示教/力矩执行失配（来源标签 + 逆动力学标定 + E307）；来源误归因（E301/E303 + 护照门 + 来源诚实不变式）。
