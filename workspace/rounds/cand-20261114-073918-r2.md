# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「模型蒸馏」×「多机器人协作」）

> R69 让系统学会了「看 / 问 / 触」来消解动作模态的 epistemic 歧义，并把不确定性一分为二（aleatoric 收紧、epistemic 交互）。但它偷偷假设了两件事：**被问者是独立且诚实的证人**，且**系统自己的不确定性是自己挣来的**。本轮两个灵感正好同时击穿这两个前提：
> - **模型蒸馏**是编队的经济学基础——「一个教师 → 多个学生」让认证成本被摊薄；但蒸馏只保证「动作像」，不保证「何时该不确定也像」。学生继承教师的**自信**，却往往继承不了教师的**认知能力**：在教师会犹豫的地方，学生可能非常笃定。这是一种**认识论继承失真**。
> - **多机器人协作**把 R69 的「问」从问人扩展为问同伴。但同伴不是神谕，而是**共享祖先的证人**：同教师、同数据片、同视角 ⇒ 错误高度相关（回声室）。R69 用「k 个正交证据源一致」抗投毒，隐含假设源间误差相关 ρ=0；在蒸馏编队里 ρ→1，「三台机器人一致」可能只是同一个错误被复制了三份，R69 的引理 18 上界 δ_p·ρ^{k−1} 随即失效。
>
> 核心命题：**蒸馏编队中的 epistemic 不确定性是「继承的、相关的」，而不是私有的、独立的。** R70 把 R69 的「问谁」升级为三个连续问题：**问谁（who）+ 它的话能算几票（how many votes）+ 我自己的不确定性可不可信（can I trust my own doubt）**。命名 **DECOR-RAS**（Distillation- and Epistemic-CORrelation-aware Risk-Adaptive System）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我听到的一致，是独立见证，还是同一个错误的回声**」——协作的价值不在「有几个证人」，而在「这些证人到底独立到哪里」。

## 0. 直觉与动机

**灵感 1（模型蒸馏 → 蒸馏传递的是「不确定性结构」，不是「不确定性本身」）**
直觉：通常的蒸馏让学生匹配教师的动作或软标签。若只做行为匹配，学生在训练分布里看起来和教师一样好、一样自信；但「知道自己在哪不确定」是一种**二阶能力**：它体现在模态权重的校准、似然对条件的敏感性、以及「何时该停/该问」的选择性决策上。这些恰恰不进入动作匹配的损失里。结果是：学生继承了教师的高分，却没有继承教师的**犹豫**。于是一个「蒸馏版 FLUID-RAS」会自信地在教师也会迟疑的岔口上直接选一边——这比 R69 的不确定更危险，因为**它不再知道自己不知道**。

**灵感 2（多机器人协作 → 同伴是「共享祖先的证人」，不是独立神谕）**
直觉：R69 的证据纪律「k 个正交源一致才定案」在单机问人时大致成立（不同人、不同模态相对独立）。但在机器人编队里，同伴往往由同一个教师蒸馏、在同一批数据上训练、以相似视角观测同一场景。它们的错误不是独立的，而是**同源的**。此时「三票一致」并不把错误概率压到 δ^3，而可能仍是 δ。协作的收益被一个隐藏变量——**谱系相关性 ρ**——悄悄吃掉。真正要估的不是「有几个同伴」，而是「这些同伴合起来相当于几个独立证人」（有效独立票数 k_eff）。

**灵感 3（蒸馏 + 协作 → 蒸馏把「单点投毒」放大成「编队级相关故障」）**
直觉：R69 最自豪的是用多源一致来抗交互投毒。可一旦教师被投毒/后门，所有由它蒸馏出来的学生都会在同一触发条件下犯同一个错。**一次污染，整队回声**。多机器人多数表决在这里不是防御，而是放大器：它把「一个后门」变成「一份盖了多数章的共识」。因此 R70 必须换防御姿势：不是数票，而是**先证明票是独立的**；再引入至少一个**谱系之外**的锚点（未蒸馏的教师、异构传感器、人类），因为只在谱系内部，共享盲区在信息论上不可见。

**灵感 4（行为保真 ≠ 认知保真 → 需要一个「选择性保真」证书）**
直觉：我们真正该认证的不是「学生动作和教师动作的 KL 很小」，而是「学生**在该不确定时确实不确定**」。这可以写成一个选择性预测（selective prediction）一致性判据：对每个置信阈值，学生选择「直接做 / 先消歧 / 退化保守」的决策要与教师一致。只有落在被独立探针证实的**保真区域 Ω_fid** 内，学生才被允许自主消解 U_epi；出了 Ω_fid，学生的不确定性不可信，epistemic 一律视同 aleatoric，退到 R69 的保守铁律。这叫**保真门**，是 R69 的 MCG（模态校准门）在蒸馏维度上的推广。

**灵感 5（协作是双刃剑 → 独立性不可自证，相关性必须保守估计）**
直觉：一旦「有效票数」决定能否定案，谎报谱系就成了新的攻击面：同伴可以声称「我和你们不同源」来骗到第 k 票；也可以声称「我很相关」来让系统不敢定案。所以独立性必须由**与申报者无关的机制**认证：谱系指纹、数据片/视角重叠、以及在**独立探针库**上的经验误差相关。并且 ρ 必须**保守取大**（宁可低估票数），因为高估独立性会把系统推向比 R69 更自信、更危险的一侧。最后必须承认：**回声室的共享盲区在谱系内无法被检出**，只能靠外部锚点与谱系多样性覆盖，这是一个信息论下界，不是工程疏忽。

## 1. 形式化定义（增量：定义 310–324）

**定义 310（DECOR-RAS 总览与五不变式）** DECOR-RAS = (DHC, ECI, CV-MINT, DAG, HDA, EGP, FCB, PACD, RAS-WM§)。五不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i / R69）；
(ii) **交互预算硬约束**（继承 R69 定义 293-ii，并扩展为通信预算，见定义 318）；
(iii) **证据纪律（升级）**：定案要求**有效独立票数** k_eff ≥ k（定义 313），而非名义源数 ≥ k；R69 的 k 源规则是 ρ=0 的特例；
(iv) **蒸馏遗传约束**：学生仅在保真区域 Ω_fid 内被允许自主消解 U_epi；Ω_fid 外，学生的 epistemic 不确定性不可信，视同 aleatoric；
(v) **独立性不可自证**：任一证据源的独立性/谱系申报，必须由与之独立的探针或谱系审计确认；禁止以被认证对象自报的 ρ 作为唯一依据。

**定义 311（蒸馏遗传证书 DHC 与认知保真）** 设教师 T、学生 S。不确定性结构 𝒰(x) = (ŵ_k, Σ_k, U_ale, U_epi, a_score(x))。
- 行为保真：D_π(x) = KL(π_T(·|x) ‖ π_S(·|x))；
- **认知保真**：D_epi(x) = W₂(μ_T(x), μ_S(x)) + λ_ℓ·|a_score_T(x) − a_score_S(x)|，其中 μ 为策略的动作模态混合分布（定义 296）；
- **选择性风险差**：sel(x) = |Risk_T(x; τ) − Risk_S(x; τ)| 对一组决策阈值 τ 取上确界（学生「直接做 / 先消歧 / 退化保守」的选择与教师一致程度）。
DHC = (lineage_id, hash(T), hash(S), D_π^p95, D_epi^p95, sel^p95, ece_T, ece_S, Ω_fid, distill_ver)。**关键：DHC 认证「学生何时该不确定」与教师一致，而不只是「动作均值一致」。**

**定义 312（选择性保真区域 Ω_fid 与保真门）** Ω_fid = {x : D_epi(x) ≤ τ_fid ∧ sel(x) ≤ τ_sel}，且只在其被**独立探针库**覆盖的子区域上被认证（探针之外一律视为未认证）。保真门：x ∈ Ω_fid 才允许学生自主用 CV-MINT 消解 U_epi；x ∉ Ω_fid ⇒ U_epi 未消解，进入 R69 定义 307 的「未消解 epistemIC 视同 aleatoric」退避。

**定义 313（有效独立性 ECI 与有效票数 k_eff）** 对证据源集合 P = {e_1,…,e_m}，可靠性权重 λ_i，误差两两相关 ρ_ij，定义
k_eff(P) = (Σ_i λ_i)² / (Σ_{i,j} λ_i λ_j ρ_ij)，约定 ρ_ii = 1。
性质：ρ≡0 ⇒ k_eff = m；ρ≡1 ⇒ k_eff = 1；等权时 k_eff = m / (1 + (m−1)ρ̄)。ρ_ij 的估计**取保守上界**：ρ_ij ≥ max{ 谱系重叠先验 ρ_lin(prov_i, prov_j), 独立探针库上的经验误差相关 ρ_emp }。证据纪律（定义 310-iii）改为 k_eff ≥ k。

**定义 314（相关感知查询 CV-MINT）** 信息增益必须在**相关误差模型**下计算，而非朴素贝叶斯连乘：
CVoI(P) = I(M; R_P | o) = H(M|o) − E_{r_P~p(·|o,P,ρ)}[H(M | o, r_P)]。
选择查询集 P* = argmax_{P⊆Peers, |P|≤Q} [CVoI(P) − Σ_{p∈P} c_comm(p) − risk(p)]，s.t. 每个查询过 C-RAS-WM 认证、通信预算未越（定义 318）。若 max ≤ 0：不查询，退化到 R69 的 MINT/R68 兜底。要点：**与自共享盲区的同伴，名义 VoI 高但 CVoI≈0**。

**定义 315（蒸馏多样性生成 DAG）** 编队蒸馏需在「精度」与「独立性」间求 Pareto：最大化编队有效信息
max_{S_1..S_m} Σ_gain(S_i)，s.t. ρ_ij ≤ ρ_max（i≠j），Acc(S_i) ≥ Acc_min，Σ cost_i ≤ B_distill。
输出每个学生的谱系指纹 prov_i 与编队独立性矩阵 R = [ρ_ij]。系：单点精度更高的同源学生可能让编队 k_eff 更低——**多样性是编队级资源，不是单机指标**。

**定义 316（继承漂移监控 HDA：三通道判别）** 在 R69 的 FMA 之上增加两条独立通道：
- d_self = |a_score_S(ξ|o) − a_score_S(ξ|o_cal)|（学生自身；R69 定义 301）；
- d_hered = |a_score_S(ξ|o) − a_score_T(ξ|o)|（**学生 vs 教师**的似然差）；
- d_cons = dispersion({a_score_{S_i}(ξ|o)})_{i∈Peers}（**同伴间**似然离散度）。
判别：慢变故障 ⇒ d_self↑；**蒸馏幻觉/认知失真** ⇒ d_hered↑ 而 d_cons 低（学生独自分叉）；**回声室共享盲区** ⇒ d_self、d_hered、d_cons 全低——只能靠外部锚点（定义 319）或探针覆盖暴露。

**定义 317（谱系溯源与回声屏障 EGP）** 证据带谱系溯源 prov(e) = (teacher_id, ckpt_hash, data_slice_id, embodiment, view_id, ts)。若两条证据的谱系重叠 overlap(prov_i, prov_j) > τ_lin，则二者**不得同时计入独立票数**（它们是「回声」）。跨谱系复用证据需一次独立验证；EGP 是 R69 CIA 证据集在「来源可信度」维度上的加强。

**定义 318（编队通信预算 FCB）** 每轮：查询次数 ≤ Q_max、总带宽 ≤ Bw、端到端时延 ≤ L_max、同步误差 ≤ ε_sync；任一越界则查询作废、U_epi 保持未消解。**信息动作的物理/社交安全认证（R69 定义 302）继续对每次查询生效**。

**定义 319（回声室可检测性下界与外部锚点）** 若区域 R 对教师及所有学生均不可观测（谱系覆盖为零），则任一内部报告 r_P 与 R 上真实模态 M 的互信息为零：I(M; R_P | o) = 0。故**内部共识对共享盲区的检出概率为 0**，与编队大小无关；检出概率 ≤ 外部锚点（未蒸馏教师 / 异构传感器 / 人类 / 独立物理探针）对 R 的覆盖率。系：增加同谱系机器人不增加对共享盲区的可见性，只会增加「一致的错误」。

**定义 320（证书 J_DECOR）** J_DECOR = (J_FLUID, dhc_hash, coverage(Ω_fid), ece_S, rho_matrix_hash, k_eff^p95, heredity_gap_p95, diversity_index, comm_budget_used, anchor_coverage, decor_ver)。Valid ⇔ Valid(J_FLUID) ∧ 轨迹上 x∈Ω_fid ∧ 每次消解 U_epi 的决策满足 k_eff ≥ k ∧ 独立性经 PACD 认证 ∧ 会计预算未越界 ∧ anchor_coverage ≥ c_min。

**定义 321（ℰ_DECOR 威胁模型）** ℰ_DECOR = ℰ_FLUID × ℰ_echo（共享盲区 / 相关投毒）× ℰ_distill_backdoor（教师后门经蒸馏放大到全队）× ℰ_heritage_leak（学生反演教师私有行为）× ℰ_false_independence（谎报谱系以骗取独立票）。并入 AIC。

**定义 322（参与式审计 VQAuditor-D）** 审计新增：谱系申报是否真实、ρ 是否被低报、k_eff 是否被虚增、CVoI 是否用了正确相关模型、保真门是否在 Ω_fid 外被绕过、教师后门是否已扩散。结论回灌 AuditBuf，成为下一轮 DAG 的多样性预算先验。

**定义 323（多样性调度与精度–独立 Pareto）** 平台调度器在 (Acc, k_eff) 平面上选择学生组合；每新增一个同源学生，k_eff 的边际增益随 ρ 递减，故最优常是「少而异地」而非「多而同源」。可容许工作点集合 𝒫_D = {(Acc, k_eff) : k_eff ≥ k_min ∧ Acc ≥ Acc_min ∧ Σcost ≤ B}。

**定义 324（退化包含与两级退避接线）** 将 DHC/ECI 接回 R69 的 λ 退避：若 x∈Ω_fid 且 k_eff ≥ k 且交互成功 ⇒ λ = λ_floor(U_ale)（resolution bonus）；若 x∉Ω_fid、k_eff < k、超预算、被投毒或 echo_suspect ⇒ λ = λ_floor(U_ale + U_epi)（未消解 epistemic 视同 aleatoric）。单机（无同伴）且学生=教师（Ω_fid=全域）且 ρ=0 时，CV-MINT 逐点等于 R69 的 MINT ⇒ **严格包含 R69**。

# IP-264 DHC：认证「何时不确定」，而非「动作像不像」
def certify_heredity(teacher, student, probe_bank, tau_fid, tau_sel):
    d_pi   = max_kl(student.pi, teacher.pi, probe_bank)              # 行为保真（必要不充分）
    d_epi  = epi_structure_divergence(student, teacher, probe_bank)  # 模态权重 / 似然
    sel    = selective_risk_gap(student, teacher, probe_bank)        # 直接做/消歧/退避 一致率
    omega  = fidelity_region(student, teacher, probe_bank, tau_fid)  # 仅探针可证区域
    ok     = (d_pi <= EPS_PI) and (d_epi <= tau_fid) and (sel <= tau_sel)
    return DHC(ok, omega, d_epi, sel, hash(teacher), hash(student))

# IP-265 ECI：有效独立票数（Kish 有效样本量；ρ 保守取大）
def effective_independence(sources, rho, lam):
    num = sum(lam[i] for i in sources) ** 2
    den = sum(lam[i] * lam[j] * rho[i][j] for i in sources for j in sources)
    return num / max(den, EPS)                 # rho=0 -> m；rho=1 -> 1

def estimate_rho(peer_i, peer_j, probe_bank):
    prior = lineage_overlap_prior(peer_i.prov, peer_j.prov)      # 同教师/数据/视角 => 高
    emp   = corr(peer_i.errors(probe_bank), peer_j.errors(probe_bank))
    return max(prior, emp)                     # 宁可高估相关，不可低估

# IP-266 CV-MINT：相关感知查询（R69 MINT 的严格推广）
def choose_fleet_query(modes, peers, o, rho, budget):
    P = []
    while len(P) < budget.max_queries:
        cand = None
        for p in peers:
            if p in P or not budget.allow(p, o): continue
            gain  = mutual_info(modes, report(p), condition=P, rho=rho)  # 相关模型，非朴素贝叶斯
            score = gain - comm_cost(p) - risk(p, o)
            if cand is None or score > cand.score: cand = (p, score)
        if cand is None or cand.score <= 0: break
        P.append(cand[0])
    return P or None                            # 无有效增益 -> R69/R68

# IP-268 HDA：三通道（自身 / 遗传 / 共识）
def heredity_drift(student, teacher, xi, o, o_cal, peers):
    d_self  = abs(student.ll(xi, o) - student.ll(xi, o_cal))    # 慢变故障
    d_hered = abs(student.ll(xi, o) - teacher.ll(xi, o))        # 蒸馏幻觉
    d_cons  = dispersion([p.ll(xi, o) for p in peers])          # 同伴分歧
    return d_self, d_hered, d_cons
# 判别：慢变故障(d_self↑) / 蒸馏幻觉(d_hered↑, d_cons↓) / 回声室(全低，需外部锚点)

    U_floor  = U_ale + (0.0 if resolved else U_epi)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    if (not in_fid) or echo_suspect:
        lam = max(lam, lam_floor(U_ale + U_epi))               # 保真区域外：不信任自身歧义
    k = M.c_ras_wm.certified_prefix(...)
    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_d.submit_async(o, d_self, d_hered, d_cons, k_eff, M.dhc.hash)
    return k, lam, mode, (U_ale, U_epi, k_eff)
```

## 3. 推导

**引理 23（有效独立票数）** 设各源对同一隐变量 M 的估计误差方差为 σ²/λ_i、两两相关 ρ_ij，则相关误差模型下融合估计的方差 ∝ 1/k_eff，k_eff = (Σλ)²/ΣΣλ_iλ_jρ_ij。等权时 k_eff = m/(1+(m−1)ρ̄)，关于 ρ̄ 单调不增。故 R69 的「k 源一致」是 ρ=0 的边界情形；一旦 ρ→1，票数塌缩为 1，多源多数表决不再带来指数级下降。系：**协作的信息价值由 k_eff 决定，而不是由编队规模决定**。

**引理 24（行为保真不蕴含认知保真）** 仅用动作匹配（KL / 行为克隆）训练的学生，可以在 D_π ≤ ε 的同时具有任意大的 D_epi 与 sel。构造：教师为对称双模态策略（两动作各 1/2），学生取两模态均值处的确定性策略，其动作似然在温标下与教师接近（D_π 小），但 U_epi→0、sel 极大（学生认为自己毫无歧义）。故**必须用 DHC 的选择性风险判据单独认证认知保真**，行为 KL 只是必要不充分条件。

**引理 25（回声室盲区下界）** 设区域 R 对教师与全部学生的谱系覆盖为零。则任一仅由谱系内报告生成的统计量 r_P 满足 I(M_R; r_P | o) = 0。故任何基于内部共识的检测器在 R 上的功效为 0，与 m 无关；检测概率被外部锚点对 R 的覆盖率上界。系：**共享盲区不能靠「多问几个同伴」解决，只能靠谱系多样性或外部锚点**——这是信息论下界，不是工程缺陷。

**引理 26（CVoI 的单调性与退化）** 在相同先验与报告边际下，相关误差模型的后验不确定性 ≥ 独立模型，即 CVoI(P) ≤ VoI_naive(P)，等号当且仅当 P 内 ρ≡0。故 R69 的 MINT 是 CV-MINT 的独立证据边界；相关同伴的增益永不超过其朴素 VoI，且可为 0。

**定理 21（四层严格包含）** 在 A102–A105 下，对任意状态，DECOR-RAS 的期望风险 ≤ FLUID-RAS ≤ R68。且当「单机（无同伴）+ 学生=教师（Ω_fid=全域）+ ρ=0」时，CV-MINT 逐指令等于 R69 的 MINT；再叠加「不交互」时逐指令等于 R68。新层只收缩证据接受（从不凭空扩张置信），安全侧不做让步；在可认证处获得 resolution bonus。

**定理 22（蒸馏后门放大上界）** 若教师含触发概率 δ_T 的后门，且学生与教师的触发识别相关 ρ_d，则由该谱系蒸馏出的任一学生对同一触发的错误率 ≥ δ_T·ρ_d；由 m 个同谱系学生做多数表决的联合错误率不再按 δ_T^m 衰减，而是 ≥ δ_T（相关极限）。故**单点污染经蒸馏可放大为编队级相关故障**；防御必须依赖谱系多样性（DAG）与外部锚点（PACD），而非增加同源票数。

**定理 23（通信预算下的近似最优查询）** 在 A102（边际信息增益递减，即 CVoI 关于查询集单调次模）下，CV-MINT 的贪心查询集在基数预算 Q 内达到最优有效信息增益的 (1−1/e) 近似；其通信–精度曲线由 (m, ρ, Q) 共同决定。系：**先问异构者、后问同源者**在预算受限时近似最优。

## 2. 形式化定义（要点版）

**定义 310（总览与五不变式）** 继承零学习写、交互预算；证据纪律升级为**有效独立票 k_eff ≥ k**；新增**蒸馏遗传约束**（学生仅在 Ω_fid 内自主消歧，其外 epistemic 视同 aleatoric）与**独立性不可自证**（ρ/谱系须由独立探针或审计确认）。

**定义 311–312（DHC 与 Ω_fid）** DHC 认证「学生何时该不确定」与教师一致：D_π 只作必要不充分，真正判据是 D_epi 与选择性风险差 sel；Ω_fid 只在其被独立探针库覆盖处被认证，区域外一律不信任学生的歧义。

**定义 313（ECI）** `k_eff=(Σλ)²/ΣΣλ_iλ_jρ_ij`；ρ≡0⇒m，ρ≡1⇒1，等权时 m/(1+(m−1)ρ̄)。ρ 取 max{谱系先验, 探针经验相关}，**宁可高估相关、不可低估**。

**定义 314（CV-MINT）** `P*=argmax[CVoI(P)−Σc−Σrisk]`，`CVoI=I(M;R_P|o)` 在相关误差模型下计算；无有效增益则不查询、退 R69/R68。与自共享盲区的同伴 CVoI≈0。

**定义 315（DAG）** 编队蒸馏最大化 `Σgain(S_i)`，s.t. `ρ_ij≤ρ_max`、`Acc≥Acc_min`、`Σcost≤B`；输出谱系指纹与独立性矩阵。多样性是编队级资源，不是单机指标。

**定义 316（HDA 三通道）** d_self（慢变故障）、d_hered（蒸馏幻觉）、d_cons（同伴分歧）；共享盲区表现为三者全低，只能由外部锚点/探针覆盖暴露。

**定义 317–318（EGP / FCB）** 证据带 prov(e)，谱系重叠超阈值不得同时计票；查询受 Q_max/带宽/时延/同步硬约束，且每次过 C-RAS-WM 认证。

**定义 319（回声室下界）** 区域对全谱系不可观测 ⇒ I(M;R_P|o)=0，内部共识检出概率为 0，与编队大小无关；检出上界由谱系外锚点覆盖率决定。

**定义 320–324（证书 / 威胁 / 审计 / 调度 / 退避）** J_DECOR 见符号表；ℰ_DECOR 含回声、蒸馏后门、继承泄漏、假独立；VQAuditor-D 审低报 ρ 与越权消歧；DAG 在 (Acc,k_eff) 上取 Pareto；DHC/ECI 接回 R69 两级 λ 退避，单机+学生=教师+ρ=0 时严格退化为 FLUID-RAS。

# IP-264 DHC：认证「何时不确定」，而非「动作像不像」
def certify_heredity(teacher, student, probe_bank, tau_fid, tau_sel):
    d_pi  = max_kl(student.pi, teacher.pi, probe_bank)
    d_epi = epi_structure_divergence(student, teacher, probe_bank)
    sel   = selective_risk_gap(student, teacher, probe_bank)
    omega = fidelity_region(student, teacher, probe_bank, tau_fid)
    ok    = (d_pi <= EPS_PI) and (d_epi <= tau_fid) and (sel <= tau_sel)
    return DHC(ok, omega, d_epi, sel, hash(teacher), hash(student))

# IP-265 ECI：有效独立票数（ρ 保守取大）
def effective_independence(sources, rho, lam):
    num = sum(lam[i] for i in sources) ** 2
    den = sum(lam[i]*lam[j]*rho[i][j] for i in sources for j in sources)
    return num / max(den, EPS)

def estimate_rho(peer_i, peer_j, probe_bank):
    return max(lineage_overlap_prior(peer_i.prov, peer_j.prov),
               corr(peer_i.errors(probe_bank), peer_j.errors(probe_bank)))

# IP-266 CV-MINT：相关感知查询（R69 MINT 的严格推广）
def choose_fleet_query(modes, peers, o, rho, budget):
    P = []
    while len(P) < budget.max_queries:
        cand = None
        for p in peers:
            if p in P or not budget.allow(p, o): continue
            gain  = mutual_info(modes, report(p), condition=P, rho=rho)
            score = gain - comm_cost(p) - risk(p, o)
            if cand is None or score > cand.score: cand = (p, score)
        if cand is None or cand.score <= 0: break
        P.append(cand[0])
    return P or None

# IP-268 HDA：三通道漂移判别
def heredity_drift(student, teacher, xi, o, o_cal, peers):
    d_self  = abs(student.ll(xi, o) - student.ll(xi, o_cal))
    d_hered = abs(student.ll(xi, o) - teacher.ll(xi, o))
    d_cons  = dispersion([p.ll(xi, o) for p in peers])
    return d_self, d_hered, d_cons

    if P:
        reps  = [fleet.query(p) for p in P]
        k_eff = M.eci.effective_independence(P, M.eci.rho, rel=reps)
        if k_eff >= K_ORTH: U_epi = M.cia.update_belief(modes, reps, k_eff)
    resolved = P is not None and k_eff >= K_ORTH
    U_floor  = U_ale + (0.0 if resolved else U_epi)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    if (not in_fid) or echo_suspect:
        lam = max(lam, lam_floor(U_ale + U_epi))
    k = M.c_ras_wm.certified_prefix(...)
    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_d.submit_async(o, d_self, d_hered, d_cons, k_eff, M.dhc.hash)
    return k, lam, mode, (U_ale, U_epi, k_eff)
```

## 4. 推导

**引理 23（有效独立票数）** 相关误差模型下融合方差 ∝ 1/k_eff，`k_eff=(Σλ)²/ΣΣλ_iλ_jρ_ij`；等权时 `m/(1+(m−1)ρ̄)`，关于 ρ̄ 单调不增。R69 的「k 源一致」是 ρ=0 边界；ρ→1 时票数塌缩为 1。系：协作的信息价值由 k_eff 而非编队规模决定。

**引理 24（行为保真不蕴含认知保真）** 仅动作匹配可在 D_π≤ε 时具有任意大 D_epi/sel（教师双模态、学生取均值的确定性策略即反例：动作 KL 小但 U_epi→0）。故 DHC 的选择性风险判据不可省，行为 KL 只是必要不充分。

**引理 25（回声室盲区下界）** 区域对全谱系不可观测 ⇒ I(M_R;r_P|o)=0，内部共识检出功效为 0，与 m 无关；检出上界 = 外部锚点覆盖率。系：共享盲区只能靠谱系多样性或外部锚点解决，是信息论下界。

**引理 26（CVoI 单调性）** 相关模型后验不确定性 ≥ 独立模型 ⇒ CVoI ≤ VoI_naive，等号 iff ρ≡0。R69 MINT 是 CV-MINT 的独立证据边界。

**定理 21（四层严格包含）** A102–A105 下，DECOR-RAS 风险 ≤ FLUID-RAS ≤ R68；单机+学生=教师+ρ=0 时逐指令等于 R69；再不交互逐指令等于 R68。新层只收缩证据接受，安全不让步，可认证处获 resolution bonus。

**定理 22（蒸馏后门放大）** 教师后门 δ_T 经蒸馏扩散，同谱系 m 生多数表决不再按 δ_T^m 衰减，而 ≥ δ_T（相关极限）⇒ **单点污染放大为编队级相关故障**；防御须靠 DAG 多样性与 PACD 外部锚点，而非增加同源票数。

**定理 23（预算下近似最优）** A102（CVoI 单调次模）下，CV-MINT 贪心查询集在基数预算 Q 内达到 (1−1/e) 近似；系：受限预算下「先异构、后同源」近似最优。

## 7. 本轮最大风险

**一句话**：DECOR-RAS 的全部安全论证押在「相关性 ρ 被保守估计、且至少存在一个可信的谱系外锚点」上——**若 ρ 被低报、或外部锚点缺失/被污染，系统就会把回声当成独立见证，从而比 R69 更自信；新增的「有效票数」恰好在 R69 最保守之处制造一个新的、编队级相关的失效模式：问一群回声，比不问更危险。**

**次级风险与缓解**：认知保真认证的成本与覆盖不足（DHC 离线 + 探针库分期扩充，Ω_fid 外一律退避）；谱系外锚点本身被污染（多锚点异构 + 锚点可信度审计）；多样性牺牲单机精度（DAG 的 (Acc,k_eff) Pareto 工作点）；通信/时延击穿实时预算（FCB 硬约束 + 贪心查询 Q≤3）；假独立攻击（EGP 谱系指纹 + PACD 独立探针 + VQAuditor-D 回灌）。
