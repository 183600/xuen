# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 1 轮；本轮灵感：「无刷电机」×「可重构机构」）

> 第 57 轮把证据判定分散到元先验、跨模态对账与个性化信任，纵深做到五层，并把"一切判定器（含元模型）走隔离"写进云边协议。但它始终默认一个从未被审计的前提：**执行承诺的"身体"是静态、已知、与模型一致的**——执行器的能力被当成铭牌常数，机构拓扑被当成固定参数，地图证据被当成与"当前以什么形态执行"无关。**无刷电机**立刻暴露这个假设的裂缝：无感驱动靠反电动势估转子角，而反电动势 ∝ 转速，于是在最需要判断"还剩多少扭矩余量"的准静态/大负载承诺点，关键状态**结构性不可观测**——这不是噪声太大，而是工作区让信号消失；唯一补救是主动注入探针，可探针本身又要用力，形成"用未知能力测量能力"的自举悖论。**可重构机构**补上第二刀：雅可比、自由度、奇异集、乃至"哪些证据类有效"都随构型离散跳变，而**重构本身是穿越奇异或闩锁的、可能不可逆的动作**——它既是承诺，又改变未来所有承诺的模型。更隐蔽的是，既然模型随构型变，系统就能**挑一个证据门最容易过的构型**去承诺，却在实际执行的构型里承担完全不同（可能更大）的风险。本轮两个灵感合成一个新的审计对象——**本体（self）**：前 57 轮审问了世界、传感与人类，却把最靠近失效的因果链（关节到底有没有力、锁到底有没有锁上、当前是哪一构型）当成免检项。核心命题由第 57 轮"视角可观测兑现、共识须扣除共失效、价值须外部盖章"升级为 **"本体条件化的证据承诺：能力可观测、构型可兑现、重构有税、自证不可采信"**。

核心矛盾：
- **H32（能力 vs 可观测）**：执行器能力在承诺工作区（低速、准静态、大负载）恰恰最难观测——反电动势类动态信号随速度趋零，力/热/去磁健康度只能间接推断。能力探针是唯一出路，但探针要用未被证明的能力去证明能力；且能力随热状态时变，证书会"过期"，把静态铭牌换成动态证书并未消除不确定性，只是把赌注从"铭牌真实性"移到"探针可信性"。
- **H33（构型 vs 证据迁移）**：构型是模型的离散前置条件，不是模型的一个参数。构型 A 下采集的几何/可达/奇异裕度证据对构型 B 无意义；若天真迁移，等于用另一副身体的成功经验为这副身体的失败背书。世界内蕴量（摩擦、承载）可迁移但也随接触几何改变（同地面、不同足端 ⇒ 有效摩擦不同），必须带折扣。
- **H34（重构 vs 承诺）**：重构能改变动作空间本身，是"用当前能力购买新能力"的期权——但它要消耗时间/能量/结构寿命，穿越奇异或闩锁，失败可能卡在中间构型。于是重构既是逃逸手段又是新风险源；且它为**配置套利**打开大门：选构型若只为降低证据门的严格度而非降低真实风险，纵深就被从内部绕过。

## 0. 直觉与动机

**灵感 1（无刷电机 → 本体能力的结构性不可观测 + 包络自举）**
直觉：无感无刷电机最迷人的地方是"没有电刷却知道该在何时换相"——它用反电动势这个随速度生长的信号替代了机械接触。但这也是一份诚实的不确定性契约：**转速为零时反电动势也为零，转子角在静止/极低速下结构性不可观测**，必须靠高频信号注入（利用凸极/电感各向异性）或开环 I/f 起动来"制造"可观测性。机器人对自身能力的认知同构：在决定"这一步踩不踩得上去、这一推推不推得动"的准静态大负载区，最有信息量的动态响应恰恰最弱；你越是需要知道余量，越测不到余量。对策不是假装知道，而是：(a) 承认工作区依赖的**可观测性指标 κ_obs**，低可观测时退回保守下界 E_lo；(b) 在**已证包络内部**施加小幅可逆**能力探针**（力/电流微振、d 轴注入的机械类比），把上界一点点抬起来——探针幅值 ≤ 当前已证下界，故永不越界，形成单调自举；(c) 能力证书带**热时效**，τ_cap 后自动衰减回 E_lo，绝不把一次测量永久外推。

**灵感 2（可重构机构 → 构型分层 + 证据迁移契约）**
直觉：可重构机构（变形轮腿、可对接模块、变自由度并联）不是"参数可调"，而是**模型本身分层的**：每个构型是一个 stratum，有自己的自由度、雅可比、奇异集与可行构型空间；构型之间的转换要穿过奇异集或松开/锁紧闩锁。于是"地图条目"必须挂一个前置条件 `precondition=σ`；证据要分成**世界内蕴量 W**（材质、摩擦、承载、坡度）与**构型相对量 R_σ**（可达性、净空、力方向、奇异裕度、刚度）。W 可迁移但按接触几何变化打折扣，R 必须在新构型重验——**重构不创造证据，只消耗或迁移证据**。

**灵感 3（合流 → 本体证据类与"自证不可采信"）**
直觉：把"身体"的证词提升为与探针/跨模态/人类并列的证据类：**EV-cap**（能力证书）、**EV-lock**（锁定证书）、**EV-stratum**（构型身份证书）。但身体是利益相关方：它会从"自己说自己行"中获益。因此核心纪律是**证书必须至少含一路不经过指令通路的独立测量**——探针结果不能只由指令电流自报，锁不能只由下达锁令的编码器自证，构型不能只由控制器的状态机声明。把第 57 轮的"一切判定器走隔离"再推一层：**连"本体估计器"也要走隔离，自签证书一律不进承诺门。**

**灵感 4（合流 → 反配置套利与 PCE++）**
直觉：既然构型可变，系统就可能"挑软柿子捏"——在证据门最松的构型里过门，在实际执行的构型里冒险。反套利原则很朴素：**门参数（阈值、证据类要求、全局硬界）与构型无关，只有物理能力随构型变；证据在跨构型时只能折减不能升级；承诺门必须在执行构型 σ_exec 下评估。** 于是探-诺-演升级为 PCE++：先做本体自检（能力是否低可观测）、再在可达构型上联合优化"探询 + 重构期权价值"，但重构过一次门、承诺在 σ_exec 再过一次门；重构跳数计入证据势能（每跳 γ 折扣），杜绝"连续变形把证据洗白"。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（本体能力可观测性与包络自举 CESO）** 本体状态 ψ=(θ_e,ω,T_w,λ_m^{health},T_{batt})；能力包络 𝔼(ψ)={(F,v,τ): margin(F,v,τ;ψ)≥0}。承诺工作区 Ω_c 定义为准静态/低速/大负载区；反电动势类动态观测量 e∝ω 在 Ω_c 内趋于零，故定义**能力可观测性** κ_obs(ψ;Ω_c)=可辨识 Fisher 信息的最小特征值（以热/力/角估计残差归一化）。若 κ_obs<κ_min，则所需能力分量不可由常规信号辨识，须退保守下界 E_lo(ψ)（铭牌经热/SoC 降额）。**能力探针** u_p 为有界可逆激励，幅值约束 a(u_p)≤E_lo(ψ)（自举固定点：不得用未证能力去测能力）；探针只允许 L0/L1 可逆形式，能量/热预算 B_cap。证书 E_cert(t) 满足 E_lo≤E_cert≤E_phys，并在 τ_cap 后按热模型衰减回 E_lo：E_cert(t+Δ)=E_lo+(E_cert(t)−E_lo)·e^{−Δ/τ_cap}。样本效率式证书 k_cap(w)=min{探针次数: Var(Ê_cap)≤w}。

**定义 140（构型分层模型 SCM）** 构型集 Σ∋σ，每层有自由度 d_σ、雅可比 J_σ、奇异集 S_σ、可行域 和有效证据类；转移图 G_Σ 的边 (σ,σ') 带路径可行性、奇异裕度与成本。证据分账：世界内蕴 W（摩擦 μ、承载、坡度、材质）与构型相对 R_σ（可达、净空、力方向、奇异裕度、刚度）。**迁移契约** T(σ→σ')：对 e∈W，evidence_{σ'}(e)=γ_trans(σ,σ')·evidence_σ(e)，γ∈[0,1] 由接触几何/足端/力方向变化决定且需声明；对 e∈R，evidence_{σ'}(e)=0（必须重验）。地图条目带前置条件 precondition=σ；任何承诺只在 σ_exec 有效。

**定义 141（重构承诺门 RCG）** 重配置 ρ:σ→σ' 是离散动作，可能穿越奇异或不可逆闩锁。前置条件四件套：(P1) 路径 π(σ,σ') 全段奇异裕度 >θ_sing；(P2) 重构所需力/力矩 ≤E_cert（当前已证包络，含时效）；(P3) **锁定证书**：以有界试探载荷 F_pl≤E_lo 沿安全方向加载，用**独立于指令通路**的传感器（第二编码器/限位/视觉标记）测得相对位移 |Δx|≤δ_lock，且锁定机构具备物理止逆/自锁证据（摩擦锁需证明摩擦系数下界）；(P4) 存在失败安全回退构型 σ_fb。不可逆闩锁（爆炸螺栓/单向卡扣/SMA 锁）额外要求 L2 外部批准；重构后 R_σ 证据清零，W 按 T 折扣。EV-lock/EV-stratum 由此产生。

**定义 142（反配置套利 CAP）** 承诺门 G 的参数（阈值 θ、证据类最低要求、全局硬界、w_max）与 σ 无关；随 σ 变化的只有物理能力 E(ψ,σ) 与几何。规则：(R1) 门在执行构型 σ_exec 下评估，不得在"更易过"的候选构型下评估；(R2) 跨构型证据只折减不升级，连续 h 跳后 W 证据的有效权重 ≤γ^h·原值（证据势能单调不增，除非在新构型内新探）；(R3) 若选定 σ 的主要收益是降低门严格度（以"门所需证据量"度量）而非降低物理风险估计，则判为套利并拒绝。形式不变量：CommitSet(σ_exec) ⊆ {a : a 由在 σ_exec 下有效的证据支撑}；不存在仅靠换构型而使原被拒动作变为可承诺的路径。

**定义 143（本体证据证书 BEC / J_b）** 新增证据类：**EV-cap**（当所需能力 >E_lo 时，须有 E_cert 覆盖 + κ_obs 达标 + 独立负载/转速参照）、**EV-lock**（锁定证书且含独立测量）、**EV-stratum**（构型身份证书，由非指令通路的独立观测确认）。证据门扩展为 EV-probe\*/EV-visit/EV-margin/EV-xmodal/EV-human/EV-cap/EV-lock/EV-stratum；不可逆接触必要证据集追加 {EV-cap}（若所需力>E_lo）与承载类 {EV-lock}；三者均要求"至少一路独立测量"。J_b=(E_cert,τ_cap,κ_obs,σ_exec,lock_log,transfer_log,config_audit,cap_probe_log,thermal_log)，继承 J_p 全检。

**定义 144（探-诺-演++ 算子 PCE++）** 每检查点：①本体自检：估 ψ、算 κ_obs；若所需能力落在低可观测区且 >E_lo，排能力探针（幅值 ≤E_cert）或降需求；②构型规划：在可达构型上计算联合 VOI——`VOI_meta_pessimistic(q) + OptionValue(σ→σ') − cost(q) − tax(ρ)`，其中 tax(ρ)=时间+能量+寿命+转移风险；③若选 σ'≠σ，先过 RCG（四件套），失败则保持 σ 或回退 σ_fb；④世界证据继承 PCE+（元推断/跨模态对账/个性化）；⑤承诺 ⇔ R≤δ_f ∧ 证据门（在 σ_exec）过；⑥探尽/重构不可行 → 绕行 → 降档 → L2 协商 → 安全停。探针数 ≤k_probes+k_cons+k_cap，构型切换 ≤N_reconfig 且证据势能严格下降（禁止循环重构），故有限步终止。

## 2. 关键算法伪代码（完整版见产物区）

```python
def capability_certify(psi, need, cap):                 # IP-139: 包络自举（只升上界）
    E_lo = derate(nameplate(psi), thermal(psi), soc(psi))
    if need <= E_lo: return Cert(E_lo, kappa_obs=INF, cls='safe')
    if kappa_obs(psi) < cap.kappa_min: return Cert(E_lo, cls='blind')   # 结构性不可观测
    E = E_lo
    for _ in range(cap.k_cap):                           # 探针幅值 <= 当前已证包络
        y = execute_probe(amplitude=E, reversible=True, budget=cap.B_cap)
        E = min(E_phys(psi), extend(E, y))               # 单调，仅抬上界
        if E >= need: break
    return Cert(E, kappa_obs=kappa_obs(psi), t_expire=now+tau_cap)

def reconfig_gate(sigma, sigma2, M, cap, ext):           # IP-141: 重构即承诺
    if singularity_margin(path(sigma, sigma2)) < theta_sing: return 'reject_singular'
    if reconfig_force(sigma, sigma2) > cap.E_cert:          return 'reject_cap'
    if not independent_lock_probe(sigma2, F_pl=min(cap.E_lo, cap.F_pl_max),
                                  sensor=ext.independent, delta=delta_lock):
        return 'reject_lock'                                # 编码器自证不算
    if is_irreversible_latch(sigma2) and not ext.l2_approved(sigma2): return 'reject_l2'
    return 'ok'

def commit_set(sigma_exec, evidence, gate):               # IP-142: 反配置套利
    acts = {a for a in candidate_actions(sigma_exec)
            if gate.params_of(a) and evidence_valid_in(sigma_exec, evidence, a)}
    return {a for a in acts if not is_arbitrage(sigma_exec, a, evidence)}  # R3
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| CESO | O(k_cap·d_ψ) | O(\|𝔼\|+k_cap) | 探针 ≤E_cert（自举单调）、证书 τ_cap 衰减、盲区回退 |
| SCM | O(d_σ) 每次门评估；迁移 O(\|W\|) | O(\|Σ\|+\|V\|·\|W\|) | W/R 分账、γ 折扣、precondition=σ |
| RCG | O(\|π\|·A*) + O(1) 锁探针 | O(\|π\|) | 独立测量、不可逆需 L2、失败安全回退 |
| CAP | O(\|Σ\|·\|A\|) 规划期 | O(\|A\|) | 门参数 σ-不变、证据势能单调、执行构型评估 |
| BEC | O(\|σ\|) | O(\|σ\|) | 三类本体证据均含独立通路、无证书即拒 |
| PCE++ | O(\|CP\|·(k_p+k_c+k_cap)·(C_VOI+d) + N_rc·A*) | O(\|V\|+\|Σ\|+\|σ\|) | k 预算、重构跳数有界、四态完备 |

**正确性定理（BCCS 概要）**：在 A33–A40 上加 (A41) 能力可观测与自举：E_lo≤E_cert≤E_phys，探针幅值 ≤E_cert，κ_obs 声明诚实，能力证书失效率 ≤δ_cap；(A42) 构型模型分层正确、σ 身份由独立观测确认（误差 ≤δ_stratum），W/R 分账与 γ 折扣诚实；(A43) 重构门独立测量诚实、锁证书假阳率 ≤δ_lock、不可逆闩锁必过 L2、存在 σ_fb；(A44) 反套利：门参数 σ-无关、跨层证据只折减、证据势能非增。则：(i) 能力路径承诺失效率 ≤δ_cap + ε_meta(k)+...（低可观测区以 E_lo 计，故不享受探针带来的乐观）；(ii) 构型路径 ≤δ_stratum + δ_lock（承载时）+ ε_σ；(iii) 单调性：包络自举只抬上界不抬下界，重构不放松门（CommitSet 只由 σ_exec 证据决定），身体证据不能自证；(iv) PCE++ 在 k_probes+k_cons+k_cap 与 N_reconfig 内终止。

## 5. 风险与缓解

## 6. 本轮最大风险

**一句话**：本轮让机器人第一次"测量并改变自己的身体"，最大的风险随之从"坏先验/坏共识"变成"**本体自证**"——能力探针读到的是自己发出的力、锁定确认来自下达锁令的同一路编码器、构型身份来自控制器的状态机，于是系统可能拿着一份内部完全自洽、物理上却为假的"本体证书"，而这份证书同时又是**授权凭据**（抬高能力包络、允许重构进更强构型），错误会在"测得更强→敢做更险→再测得更强"的循环里复利；唯一护栏是每条本体证书都必须含一路**不经过该指令通路**的独立物理测量，并对不可逆重构强制外部批准——宁可永远停在保守铭牌包络里，也绝不接受一份自签的能力/构型证书。

### IP-139 CESO（能力包络自举与低可观测回退）

```python
def capability_certify(psi, need, cap):
    """自举固定点：探针幅值绝不超过当前已证包络，测量只抬上界不抬下界。"""
    E_lo  = derate(nameplate(psi), thermal(psi), soc(psi))     # 铭牌经热/SoC 降额
    E_phys= physical_limit(psi)
    if need <= E_lo:
        return Cert(E_cert=E_lo, kappa=INF, t_expire=INF, cls='guaranteed')
    if kappa_obs(psi, region='quasi_static') < cap.kappa_min:
        return Cert(E_cert=E_lo, kappa=kappa_obs(psi), cls='blind')  # 结构性不可观测
    E = E_lo
    used = 0.0
    for _ in range(cap.k_cap):
        if E >= need or used >= cap.B_cap:
            break
        a = min(E, E_phys)                              # 探针幅值 <= 当前证书（自举）
        y = execute_probe(amplitude=a, reversible=True) # 只许 L0/L1 可逆激励
        used += probe_cost(y)
        E  = min(E_phys, extend(E, y))                  # 单调扩张，绝不下降下界
    return Cert(E_cert=E, kappa=kappa_obs(psi),
                t_expire=now + cap.tau_cap, cls='probed')

def capability_now(cert, t):
    """能力证书的时效衰减：热状态会变，旧测量不能永久外推。"""
    if t >= cert.t_expire:
        return cert.E_lo
    return cert.E_lo + (cert.E_cert - cert.E_lo) * exp(-(t - cert.t0)/cert.tau_cap)

def need_independent_corroboration(ev):
    # 本体证据一律要求"非指令通路"的第二测量，否则视为自签、拒收
    return ev in ('EV-cap', 'EV-lock', 'EV-stratum')
```

**能力自举引理（Safe-Envelope Bootstrap）**：设 E_0=E_lo，E_{n+1}=min(E_phys, Extend(E_n, y_n))，且每次探针幅值 a_n≤E_n。则 (i) E_n 单调不降且 E_n≤E_phys；(ii) 任一探针实际施加的能量 ≤E_n≤E_phys，物理上不发生越界；(iii) 若 Extend 为一致估计（无系统乐观），则 E_n 收敛到 min(E_phys, E_true 的可辨识上界)。**关键**：测量只能抬高"可证上界"，永不抬高"安全下界"——下界始终是 E_lo，因此"测到的能力"不会被误当成"承诺时可依赖的下界"。

### IP-141 RCG（重构承诺门：重构即承诺）

def reconfiguration_gate(sigma, sigma2, M, cap, ext):
    if not path_feasible(sigma, sigma2):
        return ('reject', 'path')
    if singularity_margin(path(sigma, sigma2)) < theta_sing:
        return ('reject', 'singular_path')                 # 穿越奇异

        return ('reject', 'capability_budget')             # 用已证能力支付

    if not independent_lock_probe(sigma2, F_pl=F_pl,
                                  sensor=ext.independent, delta=delta_lock):
        return ('reject', 'lock_unverified')               # 编码器自证不算

        return ('reject', 'irreversible_requires_L2')
    if not has_safe_fallback(sigma2, sigma_fb=M.sigma_current):
        return ('reject', 'no_safe_fallback')
    return ('ok', cert_lock(sigma2, F_pl, ext.measurement))

### IP-142 CAP（反配置套利）

```python
def is_arbitrage(sigma, action, evidence):
    """选的构型主要让门变松、而不是让真实风险变小 => 套利。"""
    risk_gain = risk_estimate(action, sigma) - risk_estimate(action, evidence.exec_sigma)
    gate_gain = gate_stringency(evidence.exec_sigma) - gate_stringency(sigma)
    return gate_gain > 0 and risk_gain >= 0      # 只松门、不降险

def commit_set(sigma_exec, evidence, gate):
    # R1: 门在执行构型下评估。R2: 证据只折减。R3: 拒绝套利。
    acts = {a for a in candidate_actions(sigma_exec)
            if gate.holds(a, sigma_exec)
            and evidence_valid_in(sigma_exec, evidence, a)
            and not is_arbitrage(sigma_exec, a, evidence)}
    assert acts <= evidenced_actions(sigma_exec)   # 不变量：不凭空扩张
    return acts
```

### IP-144 PCE++（探-诺-演++：能力探针 × 重构期权 × 个性化协商）

```python
def probe_commit_evolve_body(x0, M, task, budget, consent, personas, cap):
    route = plan_over_configs(M, task, goal_sigma=task.preferred_sigma)
    sched, log = [], []
    for cp in route.checkpoints:
        # ① 本体自检
        need = required_force(cp, M)
        cert = capability_certify(state_of(M), need, cap)
        if cert.cls == 'blind' and need > cert.E_cert:
            demand = derate_demand(cp, cert.E_cert)       # 降需求，不赌盲区
            if demand is None: return reroute_or_stop(cp)
        # ② 构型规划：联合 VOI（探询收益 + 重构期权 − 成本 − 重构税）
        best = None
        for sigma2 in reachable_configs(M.sigma_current):
            v = voi_meta_pessimistic(cp, M) \
                + option_value(M.sigma_current, sigma2, cp) \
                - cost(sigma2) - tax(M.sigma_current, sigma2)
            best = max(best, (v, sigma2), key=lambda z: z[0])
        # ③ 重构需要单独过门
        if best[1] != M.sigma_current:
            st = reconfiguration_gate(M.sigma_current, best[1], M, cap, ext)
            if st[0] != 'ok':
                best = (best[0], M.sigma_current)         # 保持原构型
            else:
                M = apply_reconfig(M, best[1]); log.append(('reconfig', best[1]))
        # ④ 世界证据（继承 PCE+：元推断/对账/个性化）
        while budget.probes_left > 0 and select_gait(schedule_risk(cp, M)) == 'halt':
            p = argmax(admissible_probes(cp, M, F_abs),
                       key=lambda q: voi_meta_pessimistic(q, M, cert) - cost(q))
            if voi_meta_pessimistic(p, M, cert) < theta_voi: break
            M, _, D = xmodal_fuse(M, cp.region, execute_probe(p, cap=F_abs))
            if D > theta_D and 'consensus' not in cp.done:
                M, _, D = xmodal_fuse(M, cp.region,
                                      execute_probe(most_disagreeing(M), cap=F_abs))
                cp.done.add('consensus')
            budget.spend(p)
        # ⑤ 承诺：候选构型与执行构型都过门（CAP R1/R2/R3）
        sigma_exec = M.sigma_current
        ev = tag_evidence_body(cp, M, sigma_exec, cert)
        if few_shot_gate(cp, M, personas)[0] == 'ok' \
           and body_evidence_gate(core_contact(cp), M, cap, ext)[0] == 'ok' \
           and commit_set(sigma_exec, ev, gate):
            sched.append(commit(cp, select_gait(schedule_risk(cp, M)))); continue
        alt = reroute(M, cp, risk_model)
        if alt and commit_set(alt.sigma_exec, evidence_in(alt.sigma_exec, ev), gate):
            route = alt; continue
        return negotiate_or_stop(cp, M, consent,
                                 tau_int=tau_int(personas.active.auth))
    return sched, log, M
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CESO | O(k_cap·d_ψ) | O(\|𝔼\|+k_cap) | 探针 ≤E_cert（自举单调）、E_cert 时效衰减、盲区回退 E_lo（A41） |
| SCM | O(d_σ)/门评估；O(\|W\|)/迁移 | O(\|Σ\|+\|V\|·\|W\|) | W/R 分账、γ 折扣、precondition=σ（A42） |
| RCG | O(\|π\|·A*)+O(1) | O(\|π\|) | 独立测量、不可逆需 L2、σ_fb 存在（A43） |
| CAP | O(\|Σ\|·\|A\|) | O(\|A\|) | 门参数 σ-无关、证据势能非增、执行构型评估（A44） |
| BEC | O(\|σ\|) | O(\|σ\|) | 三类本体证据均含独立通路、无证书即拒 |
| PCE++ | O(\|CP\|·(k_p+k_c+k_cap)·(C_VOI+d)+N_rc·A*) | O(\|V\|+\|Σ\|+\|σ\|) | 预算终止、跳数有界、四态完备 |

**正确性定理（Body-Conditioned Calibrated Commitment Soundness, BCCS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 能力可观测与自举：E_lo≤E_cert≤E_phys，探针幅值 ≤E_cert 且仅可逆，κ_obs 声明诚实，能力证书失效概率 ≤δ_cap，τ_cap 后衰减；**(A42)** 构型分层：层内模型误差 ≤ε_σ，σ 身份由非指令通路独立确认（误差 ≤δ_stratum），W/R 分账与 γ_trans 折扣诚实；(**A43)** 重构门：路径奇异裕度校验、独立锁探针假阳率 ≤δ_lock、不可逆闩锁必过 L2、σ_fb 可用；**(A44)** 反套利：门参数与 σ 无关、跨层证据只折减、证据势能单调不增。则：

1. **能力路径健全性**：承诺所需力 ≤E_lo 时失效 ≤δ_f+ε_meta(k)+δ_probe+ε_h；所需力 ∈(E_lo,E_cert] 时额外 ≤δ_cap；盲区（κ_obs<κ_min）一律以 E_lo 计，故不吃探针的乐观。
2. **构型路径健全性**：承载动作额外 ≤δ_lock；跨构型动作额外 ≤δ_stratum+ε_σ；连续 h 跳的 W 证据贡献 ≤γ^h·原值，证据势能非增。
3. **本体单调性（关键）**：包络自举只抬上界、不抬下界；重构不放松门（CommitSet(σ_exec) 只由 σ_exec 证据支撑）；本体证书不能自证（每条须独立通路）——因此"测得更强→敢做更险→再测得更强"的复利被切断。
4. **终止性**：探针 ≤k_p+k_c+k_cap，重构 ≤N_reconfig 且证据势能严格下降，故 PCE++ 在有限步终止于 {承诺, 绕行, L2 协商, 安全停}。
5. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + δ_ood·α_conf + δ_cap·1[need>E_lo]
             + δ_lock·1[load_bearing] + δ_stratum + ε_σ)
             − P(𝓜 陈旧未检出) − P(护盾回退失败) − P(本体证书过期未衰减)
```

关键结论：**前 57 轮的不确定性在"世界与他人"，本轮把它扩展到"身体"，而身体的不确定性有独特的结构性（低可观测）与伦理结构（利益冲突/自证）**；因此 v34 的安全性不来自"更准的本体模型"，而来自三条不变量——**探针不许越界（自举）、证据不许跨层升级（迁移）、证书不许自签（独立通路）**。

## 6. 本轮最大风险

**一句话**：本轮让机器人第一次"测量并改变自己的身体"，最大风险从"坏先验/坏共识"转为"**本体自证**"——能力探针读到的是自己发出的力、锁定确认来自下达锁令的同一路编码器、构型身份来自控制器自己的状态机，系统可能持有一份**内部完全自洽、物理上为假**的证书，而这份证书同时是授权凭据（抬高包络、允许重构进更强构型），错误会在"测得更强→敢做更险→再测得更强"的闭环里复利；唯一护栏是每条本体证书都必须含一路不经过该指令通路的独立物理测量，并对不可逆重构强制外部批准——宁可永远停在保守铭牌包络里，也绝不接受一份自签的能力/构型证书。
