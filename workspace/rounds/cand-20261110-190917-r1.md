# 第 47 轮（承接第 46 轮产物 v23；本轮灵感：模型量化 × 运动控制） · Quant-Motion-Cert：精度租约驱动的量化感知姿态证书与运动控制联合保证（五层架构 v11）

> 承接第 46 轮 v23 Memory-Safety-Voice。v23 把记忆检索、语音分发与安全绑定接入全局决策，但隐含假设 H5：感知模型与控制策略始终以同一全精度运行，且姿态证书的共形覆盖在部署模型上保持成立。真实 UniBot 必须在 Jetson/Orin 级算力上以 INT8（甚至 INT4）运行 VLM/深度/姿态网络，并让运动控制环路跑到 200–1000Hz；量化会系统性改变误差分布，尤其在 Ω_deg 退化层，而动态切换精度（省电/降热/抢实时）会让按全精度校准的姿态证书静默失效。三个灵感词精确命中 H5：**模型量化**把“数值精度”变成可调资源并引入输入相关的误差包络；**运动控制**把姿态误差经 CBF/力矩安全滤波放大到执行层；二者耦合出**精度-频率-证书三租约**问题：低精度换高控制频率，但证书半径变宽、动作抖动变大，必须在证书 soundness、实时截止期与能量之间联合调度，任何精度切换若未重新认证即 fail-closed。

## 0. 直觉与动机

**灵感 1（模型量化 → 精度租约与证书失效）**
直觉：量化不是“换个模型”，而是换了误差分布。全精度下校准的共形半径 r_ω 不能迁移到 INT8/INT4；同一张透明/高光/弱纹理图像，量化误差可能恰好落在姿态敏感方向上。把量化配置 q 与校准纪元 τ_q、误差包络 ε_q(ω)、每精度半径 r_ω(q) 打包为**精度租约** ℓ_q，与能量租约 ℓ_e、姿态租约 ℓ_p 并列为根信任三腿；运行时精度必须等于租约精度，否则依赖它的姿态证书级联失效。

**灵感 2（运动控制 → 感知-控制联合鲁棒预算）**
直觉：姿态证书的半径不是终点，它会被控制层放大。若姿态估计误差为 e_p，量化策略动作误差为 ε_a(q)，控制屏障函数 h 的鲁棒条件需要预留 M_safe = L_h·e_p + L_g·ε_a(q) + δ_m 的裕度；否则“感知看起来安全、执行却越界”。这把感知证书与控制安全从串联的两段变成共享同一鲁棒预算的联合约束。

**灵感 3（量化 × 运动控制 → 精度-频率联合调度）**
直觉：精度与频率是同一笔算力预算的两面。INT4 让单帧推理更快，可提高控制频率、缩短证书过期窗口，但 ε_a(q)、ε_q(ω) 变大；INT8 更准但更慢，截止期风险上升。于是调度变量从模态 m 扩展为 (m, q, f)，目标是在 ℓ_e、ℓ_q、M_safe、实时截止期四重约束下最大化任务效用，并对精度/频率切换加滞回与重认证预算。

**耦合升级**：在 v10/v23 五层（根信任、几何、上下文、安全、采集）上，根信任层新增精度租约，L1 半径查表变为 r_ω(m,q)，L3 安全层新增运动控制鲁棒 CBF，L4 采集层新增量化敏感层采样。架构记为 v11。

## 1. 形式化定义（增量：定义 59–63）

**定义 59（量化配置与误差包络）**
量化配置 q=(b_w,b_a,scheme,per_channel)∈Q，b∈{4,8,16}。对模型 f 与输入层 ω，定义输出误差包络
ε_q(ω) = sup_{x∈D_ω} ||f(x)-f_q(x)||，
并用区间/Lipschitz 传播给出可计算上界：ε_q(ω) ≤ Λ_q·rad(x) + η_q，其中 Λ_q 为量化后网络累积 Lipschitz 常数，η_q 为零输入量化偏置上界。实际部署取经验分位数 ε̂_q^α 与解析上界 max，避免数据稀疏时低估。

**定义 60（精度租约）**
ℓ_q=(q, ε_q(·), τ_q, {r_ω(q)}, B_q)。其中 τ_q 为校准纪元，r_ω(q) 为在精度 q 下独立校准的共形半径。**有效判据**：q_t=q ∧ t-τ_q≤T_recal ∧ 输入分布落在校准覆盖内。失效时所有依赖 q 的证书级联失效；切换到未校准精度 q'∉Q_cal 直接 fail-closed。

**定义 61（量化-姿态联合证书）**
J_t=(P_t(q_t), ℓ_p, ℓ_e, ℓ_q, m_t)，P_t(q_t)=X̂_t(q_t)⊕B(r_ω(q_t)+ε_{q_t}(ω_t))。**联合 soundness**：
P(X_t∈P_t(q_t) | ω_t,m_t,ℓ_q 有效) ≥ 1-α_p。
**边际转移**：m_true ≥ m̂ - L_φ·rad(P_t(q_t)) - L_e·(B_min-E(t))_+ - L_q·ε_{q_t}(ω_t)。

**定义 62（量化-控制联合鲁棒安全裕度）**
系统 ẋ=f(x)+g(x)a，CBF h(x)≥0。量化策略输出 a_q=a+δa，||δa||≤ε_a(q)；状态估计误差 ||x̂-x||≤e_p=rad(P_t(q_t))。**鲁棒 CBF 条件**：
ḣ(x̂)+α h(x̂) ≥ M_safe := L_h·e_p + L_g·ε_a(q) + δ_m。
若最小可行控制输入仍不满足，则安全滤波器投影到安全集；投影不可行则停机 fail-closed。另加 jerk 约束 ||a_{t}-a_{t-1}|| ≤ J_max 抑制量化抖动。

**定义 63（精度-频率联合调度）**
控制频率 f、精度 q，算力时间 T(q)≤1/f≤τ_deadline。联合策略
π(c_t,ω_t,B_t,q_{t-1},f_{t-1})=(m_t,q_t,f_t)
= argmax_{m,q,f} U_task(m,q,f) - λ_sw·[q≠q_{t-1}] - λ_sw·[f≠f_{t-1}]
s.t. ℓ_e 有效, ℓ_q 有效, M_safe(q) 可行, T(q)≤1/f, 切换重认证成本 ≤ 预算。**滞回**：仅当效用增益 > Δ_hys 才切换，避免精度抖动。

## 2. 三大新增产出与既有 IP 升级

**IP-69 QPC（Quantization-Precision Certificate Manager）**
- 分层分 ω 量化误差剖析：经验分位 + Lipschitz 解析上界取 max
- 精度索引共形校准：每个 q 独立校准 r_ω(q)，INT4 数据不足时保守放大
- 精度租约签发、纪元管理与切换重认证预算
- 未校准精度 / 租约过期 → fail-closed

**IP-70 MCB（Motion-Control Barrier）**
- 量化动作误差包络 ε_a(q) 与状态估计误差 e_p 合成鲁棒裕度
- 鲁棒 CBF 安全滤波 + 投影 + jerk 约束
- 力矩/速度/加速度限幅与量化抖动抑制
- 不可行 → 减速 / 提精度 / 停机

**IP-71 QRS（Quantization-Rate Scheduler）**
- (m,q,f) 联合调度，延迟-精度 Pareto 前沿
- 截止期感知、能量感知、切换滞回
- 预热与重认证流水线，避免切换瞬间证书空窗

**既有 IP 升级**
IP-63 ECPS：动作空间从 m 扩展为 (m,q,f)，效用分母含 P_m(q) 与切换成本
IP-60 PSE：半径查表 r_ω(m,q)，量化误差进入半径膨胀
IP-64 DEPTH-CERT：深度网络量化误差分层统计，空洞层额外膨胀
IP-51 CAR：守卫加入 ℓ_q 有效性与 M_safe 可行
IP-62 CCA：新增量化红队、精度切换注入、INT4 覆盖缺口审计
IP-61 DCL：优先采集量化敏感层/ω 样本，补 INT4 校准集
IP-45 总线：新增 precision-lease / control-margin / quant-switch 话题

## 3. 算法骨架

QRS 每个调度周期：
1. 读 B_t, ℓ_e, ℓ_q, c_t, ω_t, q_{t-1}, f_{t-1}
2. 枚举可行 q∈Q_cal，算 T(q)、f_max=1/T(q)、ε_a(q)、r_ω(q)
3. 对 (m,q,f) 算 U_task 与切换成本，过滤能量/证书/CBF/截止期约束
4. 取最优；若切换精度则先申请重认证，未完成则保持旧 q 或 fail-closed
5. 签发 J_t=(P_t(q),ℓ_p,ℓ_e,ℓ_q,m)，MCB 做安全滤波
6. 任一步不可行 → fail-closed
PSE 用 r_ω(m,q) 签发 P_t；CAR 用三租约守卫。

## 4. 本轮最大风险

**一句话**：量化误差在 Ω_deg 退化层与快速运动时最集中，而低精度换来的高控制频率恰好用于快速运动，二者在时间上正相关；若 INT4 校准集在退化层稀疏、动态切换又赶不上重认证，姿态证书会在最需要它的时候静默失效并让鲁棒 CBF 的裕度被低估；因此必须用解析误差上界兜底、对退化层单独保守校准、并在精度切换未完成重认证时强制 fail-closed。

## 2. 关键算法 伪代码

### IP-69 QPC
```
def quant_error_envelope(model, q, omegas, D_cal, alpha):
    eps = {}
    for w in omegas:
        eps_emp = quantile([norm(f(x) - f_q(x, q)) for x in D_cal[w]], 1-alpha)
        eps_lip = lipschitz_propagate(model, q, w)   # Λ_q·rad + η_q
        eps[w] = max(eps_emp, eps_lip)               # 解析上界兜底
    return eps

def calibrate_radius_per_precision(q, D_cal, alpha_p):
    scores = []
    for (x, y) in D_cal:
        x_hat = pose_model_q(x, q)
        scores.append(conformal_score(y, x_hat))
    return conformal_quantile(scores, 1-alpha_p)

def issue_precision_lease(q, t, tau_q, budget):
    if q not in Q_cal:
        return None                                  # 未校准 -> fail-closed
    eps = quant_error_envelope(pose_model, q, OMEGA, D_cal, alpha_p)
    r = {w: calibrate_radius_per_precision(q, D_cal[w], alpha_p) for w in OMEGA}
    return Lease(q=q, eps=eps, r=r, t0=t, tau=tau_q, budget=budget)

def switch_precision(q_new, lease_q, recal_budget):
    if q_new == lease_q.q:
        return lease_q
    if q_new not in Q_cal or recal_budget < cost_recal(q_new):
        return None                                  # 无认证预算 -> fail-closed
    return issue_precision_lease(q_new, now(), T_recal, recal_budget - cost_recal(q_new))
```

### IP-70 MCB
```
def robust_cbf_margin(q, P_t, L_h, L_g, delta_m):
    e_p   = P_t.radius(q)                 # 含 r_ω(q) + ε_q
    eps_a = action_error_envelope(q)      # 量化策略动作误差
    return L_h * e_p + L_g * eps_a + delta_m

def safety_filter(x_hat, a_q, q, P_t, h, alpha, J_max):
    margin = robust_cbf_margin(q, P_t, L_h, L_g, delta_m)
    hdot = lie_derivative(h, x_hat, a_q)
    if hdot + alpha * h(x_hat) >= margin and norm(a_q - a_prev) <= J_max:
        return a_q, 'safe'
    a_safe = project_to_cbf(h, x_hat, a_q, margin)   # 最小改动投影
    if a_safe is not None and norm(a_safe - a_prev) <= J_max:
        return a_safe, 'projected'
    return STOP, 'fail-closed'
```

### IP-71 QRS
```
def joint_schedule(c_t, omega_t, B_t, q_prev, f_prev, lease_q):
    best, best_U = None, -inf
    for q in Q_cal:
        if not precision_lease_valid(lease_q, q, now()):
            continue
        f_max = 1.0 / latency(q)
        for f in rate_candidates(f_max, f_prev):
            for m in MODALITIES:
                if not energy_feasible(B_t, m, q, f):
                    continue
                if not safe_margin_feasible(q, f):
                    continue
                if 1.0 / f > tau_deadline:
                    continue
                U = task_utility(m, q, f) \
                    - lambda_sw * (q != q_prev) - lambda_sw * (f != f_prev)
                if U > best_U + delta_hys:          # 滞回，抑制抖动
                    best, best_U = (m, q, f), U
    return best if best is not None else None       # None -> fail-closed
```

### 全局量化-运动决策
```
def quant_motion_decision(c_t, omega_t, B_t, v_t, M, lease_e, lease_q, Q_safe):
    m_t, status = mvr_schedule(c_t, B_t, v_t, M, calib, S_phi)
    if m_t is None:
        return 'fail-closed', 'energy'
    sched = joint_schedule(c_t, omega_t, B_t, q_prev, f_prev, lease_q)
    if sched is None:
        return 'fail-closed', 'precision-lease'
    m_t, q_t, f_t = sched
    P_t = pose_certify(m_t, q_t)                    # 半径含 ε_q
    a_q = policy_q(P_t, q_t)
    a_safe, cbf_status = safety_filter(a_q, q_t, P_t, h, alpha, J_max)
    if cbf_status == 'fail-closed':
        return 'fail-closed', 'cbf'
    B_prob = safety_bind(v_t, P_t, omega_t)
    if B_prob < theta_safe:
        push(Q_safe, v_t)
        return (m_t, q_t, f_t, a_safe), 'queued'
    return (m_t, q_t, f_t, a_safe), status
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| QPC 误差剖析/校准 | O(|D_cal|·|Q|·|Ω|) 离线 | O(|Q|·|Ω|) | 解析上界兜底 ⇒ ε_q 不被低估 |
| QPC 运行时查租约 | O(|Q|) | O(|Q|·|Ω|) | q_t=q 且未过期 ⇒ 覆盖成立 |
| MCB 安全滤波 | O(1) 每控制拍 | O(1) | M_safe 满足 ⇒ 安全集前向不变 |
| QRS 联合调度 | O(|Q|·|F|·|M|) 每调度周期 | O(|Q|·|F|) | 四约束过滤 ⇒ 输出可行或 fail-closed |

正确性定理：设精度租约 ℓ_q 有效（q_t=q 且 t-τ_q≤T_recal），则按 q 独立校准的共形半径 r_ω(q) 使 P(X_t∈P_t(q)|ω_t,m_t)≥1-α_p 成立；设量化动作误差 ||δa||≤ε_a(q) 且状态误差 ||x̂-x||≤e_p，则鲁棒 CBF 条件 ḣ+αh≥M_safe 保证安全集在前向不变意义下不被越界。三租约任一失效（ℓ_p、ℓ_e、ℓ_q）或 M_safe 不可行，全局决策 Π 输出 fail-closed，不存在“感知证书看似有效、执行却越界”的静默路径。

| E119 动态精度切换 | 切换频次；重认证延迟；证书空窗 | 切换 ≤ 5 次/min；空窗 0 次 |
| E120 100h 全局闭环 | 安全违例；覆盖率；延迟 P99 | 违例 0 起；覆盖 ≥ 1-α-0.03；P99 ≤ τ_deadline |

回退策略：E115 解析上界 > 3× 经验误差 → 收紧网络量化粒度或回退 INT8；E116 INT4 覆盖缺口 > 0.08 → 禁用 INT4 并强制 INT8；E117 抖动超限 → 启用动作低通 + 降低切换频率；E119 重认证延迟超预算 → 预生成精度租约池，切换只做查表。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| INT4 校准集在 Ω_deg 稀疏，半径低估 | 高 | 解析 Lipschitz 上界兜底；退化层单独保守放大 r_ω(q) |
| 精度切换瞬间证书空窗 | 高 | 预生成租约池 + 滞回；未完成重认证则保持旧 q 或 fail-closed |
| 量化动作抖动触发执行器振荡 | 中 | jerk 限幅 + 动作低通 + MCB 投影 |
| 鲁棒 CBF 过于保守导致频繁停机 | 中 | 自适应 δ_m；可行动作集不可行时优先降速而非停机 |
| 精度-频率调度抖动（chatter） | 中 | 效用滞回 Δ_hys + 切换成本 λ_sw |
| 记忆库中历史决策绑定旧精度 | 中 | 记忆键加入 q；跨精度复用需重新校验 ℓ_q |

## 6. 本轮最大风险

**一句话**：量化误差在 Ω_deg 退化层与快速运动时最集中，而低精度换来的高控制频率恰好用于快速运动，二者在时间上正相关；若 INT4 校准集在退化层稀疏、动态切换又赶不上重认证，姿态证书会在最需要它的时候静默失效并让鲁棒 CBF 的裕度被低估；因此必须以解析误差上界兜底、对退化层单独保守校准、并在精度切换未完成重认证时强制 fail-closed。
