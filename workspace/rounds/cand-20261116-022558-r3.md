# 第 10 轮（灵感循环第 3 轮；本轮灵感：「实时控制」×「模型蒸馏」）

> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> **本轮纪律**：**证书优先 + 共形反馈 + 蒸馏学生**。两个灵感精确对准 v9 自己写下的最大风险——「分块执行在最需要安全的时刻暴露最不可靠的证书」。v9 把误差界 β 当离线常数、把块长门控交给滞后 20 帧的 Δ_dom；本轮把 β 变成**实时反馈回路的被控量**，把重前向模型蒸馏成**携带尾部分位包络的快学生**，并用**采样保持屏障不变式**把"守卫必须在 h_max 内触发"从工程经验升级为安全证书的推论。任一新模块失效仍注入中立元、严格退回 v9。

## 0. 直觉与动机

**灵感 1（实时控制 → 把证书宽度当作反馈被控量）**
直觉：控制工程里没有哪个"模型不确定度"应该是一次性拍定的常数——它应由误差反馈在线调节。v9 的 β 是 E554 标定一次的常数 ×1.2，域一动就失真；而负责发现域动的 DA-ML 有 20 帧滑窗滞后，反馈通道自身带延迟。核心创新：**共形证书调节器（ConformalCertificateGovernor, CCG）**——把包络宽度 β_t 当作被控量，以"本周期真实残差是否击穿包络"为误差信号，用自适应共形推断（ACI）在线更新：
`β_{t+1} = clip(β_t + η·(err_t − δ), β_min, β_max)`。
它**不用任何跨帧置信度**：哪个周期漏覆盖，下一个周期 β 就变宽、K_eff 就收缩。这把 v9 的"空间滞后"（等 DA-ML 滑窗）换成了"一步时间补偿"（共形反馈）。

**灵感 2（模型蒸馏 → 蒸馏的必须是"包络"而不只是"均值"）**
直觉：v9 冻结的前向模型 F̂ 是 12ms 的重教师，却只在 5Hz 跑。标准知识蒸馏对齐均值预测，恰恰会抹平尾部误差——而证书要的正是 1−δ 的尾部分位。核心创新：**证书蒸馏学生模型（DistilledCertificateModel, DCM）**——损失 `L = L_pred + λ·L_pinball`，用针球（分位数）损失把教师的 (1−δ) 残差分位一并蒸馏，再用分割共形在信任域校准集上给出有限样本覆盖保证。学生在线 ≤2ms，既省预算，又因"快"而能更频繁自触发重规划——**速度本身成为安全资源**。

**灵感 3（两灵感合流 → 证书优先的自触发分块）**
直觉：v9 是"先估域（Δ_dom）、再定块长"；正确顺序是"先算当下可证裕度、再定块长"。核心创新：**证书优先块长（Certificate-First Chunking）**：
`K_eff(t) = max{ K ≤ K_max : ĝ_min(K) − β_t(K,a_t,b_t) ≥ d_safe ∧ ê_max(K) + β_t(K,a_t,b_t) ≤ τ_eff }`，
其中 β_t 已显式含输入时滞 a_t 与可用预算 b_t。再叠加**自触发实时外壳（SelfTriggeredRealTimeShell, STR）**：以信任半径跌破 ρ 为事件触发重规划（而非固定 5Hz），并用采样保持屏障不变式给出守卫间隔的硬上界 `h_max ≤ (h(s_t) − m)/(L_h·v_max)`。

## 1. 研究问题（轮次升级版）

- **Q1（反馈证书的即时性）**：共形反馈 `β_{t+1}=β_t+η(err_t−δ)` 在单次分布骤变下，从漏覆盖到包络追平需要几个控制周期？该暂态能否与 K_eff 的收缩耦合，使暂态期内也不接受不安全块？
- **Q2（包络蒸馏的可迁移性）**：分位数蒸馏 + 分割共形的覆盖保证在训练分布内是有限样本的；当信任域被 Δ_dom/risk_SLAM 判为域外时，学生包络如何保证"宁宽勿窄"而非乐观外推？
- **Q3（时延—安全耦合）**：采样保持屏障不变式给出的 h_max 与检测-停车时延 L_dts 如何共同约束块执行与自触发节拍，使"实时性"不再是独立指标，而是安全证书的一部分？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 共形反馈律（Conformal Feedback, CCG）**
β 是实时被控量而非离线常数：每周期以漏覆盖指示 err_t 反馈更新；更新增益 η 由实时控制稳定性分析选取；β 对输入时滞 a_t 与预算紧张度单调不减。漏覆盖的当下即触发膨胀，不等待任何统计滑窗。

**P14 包络蒸馏律（Envelope Distillation, DCM）**
学生模型必须继承教师的尾部分位包络，而不只是均值；蒸馏损失含针球项；部署前用信任域校准集做分割共形，给出 1−δ 有限样本覆盖；信任域外按"宁宽勿窄"单调膨胀，绝不外推均值。

**P15 自触发实时律（Self-Triggered Real-Time, STR）**
重规划由信任半径跌落事件触发，非固定节拍；守卫间隔受采样保持屏障不变式硬约束 h_max ≤ (h(s_t)−m)/(L_h·v_max)；刹停距离含检测-停车时延 L_dts。Zeno 由最小事件间隔 Δ_min 保证。

## 3. 与基线的接口（如何退化）

- CCG 失效（反馈发散 / 被伪造残差攻击）⇒ η←0，β 冻结为 β_cal，等价 v9 的静态标定；
- DCM 失效（学生失准 / 覆盖检验失败）⇒ 切回重教师 F̂_t + v9 静态 β，等价 v9 AC；
- STR 失效（事件触发异常 / 无最小间隔）⇒ 固定 5Hz + 固定守卫间隔 h_max，等价 v9 分块节拍；
- AC 失效 ⇒ K_eff←1 逐步执行，等价 v8 决策粒度；
- MW 失效 ⇒ v8 手写网关；ID 失效 ⇒ 全模块 active；DA/SPR/Cal 失效 ⇒ 中立元注入，等价 v7；
- 全部失效 ⇒ 完整退回 MetricVoiceGauge-OTL-GC-ER v7，再退回 v6。

## 4. 预期贡献

1. **共形证书反馈**：把不确定度包络从"离线标定"升级为"在线反馈控制量"，直接消除 v9 对 DA-ML 滑窗滞后的一次性依赖；
2. **包络蒸馏**：分位数蒸馏 + 分割共形，使快学生携带可证尾部包络，把算力节省与安全保证统一在同一机制里；
3. **证书优先 + 自触发的实时分块**：以当下可证裕度决定块长，以采样保持屏障不变式把时延约束内化为安全条件；
4. **时延—安全—算力三者的定量缝合**：E571–E590 覆盖覆盖暂态、蒸馏迁移、自触发节拍、时延注入与端到端任务。

## 5. 本轮最大风险

**一句话**：共形反馈的覆盖率保证是**长程平均**的——单次骤变后的最初几个周期 β 尚未追上真误差，证书仍可能乐观，即 v10 把 v9 的"空间滑窗滞后"换成了"反馈暂态滞后"；若 η 取大又会在平稳期过冲、引发 K_eff 抖振。

## 1. 符号体系增量（定义 540–549）

| 符号 | 含义 |

| β_t(K,a,b) | 时间参数化包络：覆盖漂移 + 输入陈旧 + 预算截断的合成误差界 |
| β_t^ACI | 由 CCG 反馈维护的共形包络基值 |
| K_eff(t) | 证书优先有效块长（定义 542） |
| ρ_t | 信任半径：`(ĝ_min − β_t) − d_safe`，自触发判据的裕度 |
| ρ_thr, Δ_min | 自触发阈值与最小事件间隔（防 Zeno） |

| δ, η | 目标漏覆盖率与 ACI 反馈增益 |
| D_cal | 信任域校准集（分割共形用） |

**新增定义 540（输入时滞 Input Age）** `a_t := (t_now − t_sf)·Δt_s`，其中 t_sf 为最近一次通过一致性检查的传感器融合时间戳。a_t 由时钟直接测量、不依赖统计窗口；它把 v9 中"DA-ML 20 帧滑窗滞后"显式化为当周期可观测量。

**新增定义 541（时间参数化包络 Time-Parameterized Envelope）**
```
β_t(K,a,b) = clip( β_t^ACI + λ_a·a + λ_b·max(0, b_req(K) − b) + λ_K·K, β_min, β_max )
```
β_t^ACI 由 CCG（定义 545）反馈；b_req(K) 为 K 步 rollout 预算需求，b 为本周起可用决策预算。三项分别刻画覆盖漂移、输入陈旧、预算截断误差。β_t 对 a、b 单调不减（P13）。

**新增定义 542（证书优先有效块长 Certificate-First Chunk Length）**
```
K_eff(t) = max { K ∈ [1,K_max] : ĝ_min(K) − β_t(K,a_t,b_t) ≥ d_safe
                                  ∧ ê_max(K) + β_t(K,a_t,b_t) ≤ τ_eff
                                  ∧ P_t(K) ≠ ∅ }
```
空集则 K_eff=1（等价 v9/v8 逐步）。**Δ_dom 不再直接门控 K_eff**，只通过信任域校准集与 β_t^ACI 间接作用——这从结构上切除 v9 的"滑窗滞后决定块长"。

**新增定义 543（包络蒸馏损失 Envelope Distillation Loss）**
```
L = E[ ℓ(ŷ_s, y_t) + λ·ρ_{1−δ}(ŷ_s^hi − y_t) ]
```
ρ_τ 为针球损失，ŷ_s^hi 为学生上分位头。学生须在 (1−δ) 分位覆盖教师残差尾部，而非仅拟合均值。

**新增定义 544（分割共形包络 Split-Conformal Envelope）** 在信任域校准集 D_cal（|D_cal|=n）上计算学生残差分数 s_i=|y_i−ŷ_{s,i}|，取
```
β_conf = s_(⌈(n+1)(1−δ)⌉)
```
可交换性下 `P(|y−ŷ_s| ≤ β_conf) ≥ 1−δ`（引理 88）。

**新增定义 545（共形反馈调节 Adaptive Conformal Governor）**
```
err_t = 1[ |y_t − ŷ_{s,t}| > β_t^ACI ]
β_{t+1}^ACI = clip( β_t^ACI + η·(err_t − δ), β_min, β_max )
```
稳定性：`0 < η < 2/(1−δ)`（一阶低通收缩，引理 89）；η 过大过冲、过小暂态长。

**新增定义 546（信任半径与自触发谓词）**
```
ρ_t = (ĝ_min(K) − β_t(K,a_t,b_t)) − d_safe
replan(t) ⇔ ρ_t < ρ_thr ∨ (K_eff 改变) ∨ a_t > a_max
```
替代固定 5Hz：只在证书裕度真的变紧时重算。

**新增定义 547（最小事件间隔 Minimum Inter-Event Time）**
```
Δ_min = (ρ_0 − ρ_thr) / (L_ρ·v_max)
```
ρ_0 为重规划后的初始裕度，L_ρ 为 ρ 对状态的 Lipschitz 常数；保证非 Zeno（引理 90）。

**新增定义 548（时滞嵌入刹停距离 Latency-Embedded Braking Distance）**
```
d_brake^L(v,a_t) = v·(a_t + τ_guard + τ_act) + v²/(2·a_dec) + d_safe
```
将定义 534 停车不变式中的 d_brake 替换为 d_brake^L，使检测-停车延迟进入刹停预算（引理 92）。

**新增定义 549（采样保持屏障不变式 Sampling-Hold Barrier）** 安全集 {h(s)=dist(s,O)−d_safe ≥ 0}，h 为 1-Lipschitz、‖ṡ‖≤v_max。若每个采样点满足 `h(s_t) ≥ L_h·v_max·h_max + m`，则 [t, t+h_max] 内 `h ≥ m > 0`。由此守卫间隔硬上界：
```
h_max ≤ (h(s_t) − m) / (L_h·v_max)
```
把"实时性（守卫必须及时触发）"变成安全证书的推论（引理 91）。

```python
# IP-357 DistilledCertificateModel：针球/分位数蒸馏 + 分割共形
class DistilledCertificateModel:
    def __init__(self, teacher, student, delta=0.01, lam=0.5):
        self.T, self.S = teacher, student
        self.delta, self.lam = delta, lam
        self.beta_conf = None

    def distill_loss(self, s_batch, a_batch):
        with torch.no_grad():
            t_mu, t_res = self.T(s_batch, a_batch)      # 教师均值 + 残差样本
            t_tail = t_res.quantile(1 - self.delta, dim=-1)
        s_mu, s_hi = self.S(s_batch, a_batch)            # 学生均值头 + 上分位头
        L_pred = mse(s_mu, t_mu)
        L_env = pinball(s_hi, t_mu + t_tail, tau=1 - self.delta)
        return L_pred + self.lam * L_env                 # 定义 543

    def calibrate(self, calib_loader):
        scores = []
        for s, a, y in calib_loader:                     # 信任域校准集
            s_mu, _ = self.S(s, a)
            scores.extend((y - s_mu).abs().flatten().tolist())
        n = len(scores)
        k = math.ceil((n + 1) * (1 - self.delta))
        self.beta_conf = sorted(scores)[min(k, n) - 1]   # 定义 544
        return self.beta_conf


# IP-358 ConformalCertificateGovernor：ACI 反馈 + 时滞/预算膨胀
class ConformalCertificateGovernor:
    def __init__(self, eta=0.02, delta=0.01, beta_cal=0.02,
                 beta_min=0.0, beta_max=0.5,
                 lam_a=0.5, lam_b=2.0, lam_K=0.002):
        self.beta = beta_cal
        self.eta, self.delta = eta, delta
        self.beta_min, self.beta_max = beta_min, beta_max
        self.lam_a, self.lam_b, self.lam_K = lam_a, lam_b, lam_K

    def feedback(self, residual, envelope_used):
        err = 1.0 if abs(residual) > envelope_used else 0.0
        self.beta = clip(self.beta + self.eta * (err - self.delta),
                         self.beta_min, self.beta_max)    # 定义 545
        return self.beta

    def envelope(self, K, input_age, budget_avail, budget_req):
        b = (self.beta + self.lam_a * input_age
             + self.lam_b * max(0.0, budget_req(K) - budget_avail)
             + self.lam_K * K)
        return clip(b, self.beta_min, self.beta_max)      # 定义 541


# IP-359 SelfTriggeredRealTimeShell：事件触发 + 采样保持屏障
class SelfTriggeredRealTimeShell:
    def __init__(self, rho_thr=0.05, h_min=0.02, h_max=0.08,
                 L_h=1.0, v_max=1.5, m=0.05):
        self.rho_thr, self.h_min, self.h_max = rho_thr, h_min, h_max
        self.L_h, self.v_max, self.m = L_h, v_max, m

    def trust_radius(self, g_min_hat, beta, d_safe):
        return (g_min_hat - beta) - d_safe                # 定义 546

    def should_replan(self, rho, K_eff_changed, input_age, a_max=0.1):
        return rho < self.rho_thr or K_eff_changed or input_age > a_max

    def guard_interval(self, h_s):
        cap = (h_s - self.m) / (self.L_h * self.v_max)    # 定义 549
        return max(self.h_min, min(self.h_max, cap))

    def min_inter_event(self, rho_0, L_rho):
        return max(0.0, (rho_0 - self.rho_thr)
                   / max(1e-6, L_rho * self.v_max))       # 定义 547


# 主闭环集成：MetricVoiceGauge-RTCD
def metricvoicegauge_round_10(M, s, obs, audio_stream=None, ell=None, ...):
    ctx = mw_default_ctx()
    # ---- v9 契约中间件照常驱动感知侧（不变）----
    results = middleware.run_cycle(runners={
        'DA_ML':  lambda c: domain_adapter.update_and_measure(obs),
        'SPR':    lambda c: slam_risk.compute(M.slam_backend.get_latest_state()),
        'CAL_FI': lambda c: calib_fi.get_weights_kappa(),
        'OTL':    lambda c: online_learner.update_and_thresholds(c),
    }, ctx=ctx)

    # ---- 前向模型：快学生 + 时变包络（v10 核心）----
    a_t = now_s() - ctx.last_sensor_fusion_ts             # 定义 540
    pred = student_model.rollout(ctx.state, horizon=M.K_max)
    beta_env = ccg.envelope(K=M.K_max, input_age=a_t,
                            budget_avail=ctx.budget_left,
                            budget_req=student_model.budget_req)  # 定义 541

    # ---- 证书优先块长：先算裕度、再定块（定义 542）----
    K_eff, cert = select_certified_horizon(
        pred, beta_env, d_safe=M.d_safe, tau_eff=M.tau_eff,
        abort_ok=chunker._abort_points)

    # ---- 自触发：事件而非固定 5Hz（定义 546）----
    rho = shell.trust_radius(cert.g_min, beta_env, M.d_safe)
    if current_chunk is None or shell.should_replan(
            rho, K_eff != current_chunk.K, a_t):
        current_chunk = chunker.generate_chunk(ctx.state, K_eff,
                                               beta_env=beta_env)

    # ---- 采样保持屏障：守卫必须在 h_max 内触发（定义 549）----
    h_s = live_obs.nearest_clearance - M.d_safe
    validate_guard_period(shell.guard_interval(h_s))      # 调度器据此设 deadline

    # ---- 50Hz 中块守卫；刹停含 L_dts（定义 548）----
    verdict, k_next = chunker.midchunk_guard(
        current_chunk, k_exec, live_obs,
        d_brake=stopping_with_latency(a_t))
    if verdict == 'abort':
        current_chunk.execute_safe_stop_at(k_next)         # 安全停驻
        current_chunk = None
    else:
        execute(current_chunk.actions[k_next])

    # ---- 共形反馈：用本周真实指标残差更新 β（定义 545）----
    if ctx.true_metrics is not None:
        ccg.feedback(residual=ctx.true_metrics.g_min - pred.g_min,
                     envelope_used=beta_env)

    # ---- v9 继承路径（MW/ID/GCT/ER/5 维风险/奖励）----
    C, spatial_cert, claims, metrics, rewards = M.inherited_v9_path(ctx)
    distiller.step(cycle_idx, ctx)
    return C, spatial_cert, claims, metrics, rewards
```

## 4. 推导

**引理 87（证书优先块长的保守性）** 设当周期包络 β_t(K,a_t,b_t) 点式界定真实 rollout 误差：|ĝ_min−g_min| ≤ β_t 且 |ê_max−e_max| ≤ β_t。则按定义 542 选取的 K_eff，其任意已执行步满足真实 `g_k ≥ d_safe` 且真实 `e_k ≤ τ_eff`。证明：由误差界 `g_k ≥ ĝ_k − β_t ≥ ĝ_min − β_t ≥ d_safe`，对偶侧同理。与 v9 引理 82 的差别：β 不再假设"常数有效"，其有效性改为**当周期**作用于 β_t 的假设；块长因此直接随当下可证裕度收缩，而非随滞后信号。∎

**引理 88（分割共形有限样本覆盖）** 若校准残差与测试残差在信任域内可交换，则定义 544 的 β_conf 满足 `P(|y−ŷ_s| ≤ β_conf) ≥ 1−δ`。证明：标准次序统计量论证（Vovk 等）；第 ⌈(n+1)(1−δ)⌉ 个次序统计量以 ≥1−δ 概率覆盖新残差。**注意**：可交换性在跨域时失效，这是引理 89 与最大风险的来源。∎

**引理 89（ACI 的实时覆盖与滞后消除）** 记 err_t∈{0,1} 为漏覆盖指示，反馈 `β_{t+1}=β_t+η(err_t−δ)`。则 (i) 瞬态响应：一次漏覆盖在一个周期内使 β 增加 η(1−δ)，**无任何跨帧滑窗延迟**，故不存在 v9 那种"持续 K_eff 过大直到窗口滚满"的暴露；(ii) 长程平均：在 δ 可行且残差序列有界变差下，长期平均漏覆盖率趋于 δ（Gibbs–Candès ACI）；(iii) 稳定性：`0<η<2/(1−δ)` 时更新算子为收缩的一阶低通。**边界**：(ii) 是长程平均而非逐周期保证，骤变后的前若干周期覆盖仍可能不足——这正是本轮最大风险。∎

**引理 90（自触发无 Zeno）** 设信任半径 ρ 对状态 L_ρ-Lipschitz、速度 ≤v_max；每次重规划将 ρ 复位到 ≥ρ_0>ρ_thr。则相邻两次重规划的间隔 ≥ Δ_min=(ρ_0−ρ_thr)/(L_ρ·v_max)>0。证明：ρ 在两次触发之间以速率 ≤L_ρ·v_max 单调下降，从 ρ_0 降到 ρ_thr 至少需 Δ_min；再叠加 h_min 节拍约束，有限区间内事件数有限。∎

**引理 91（采样保持屏障不变式）** 设安全集 {h(s)=dist(s,O)−d_safe≥0}，h 为 1-Lipschitz（L_h=1），‖ṡ‖≤v_max。若每采样点 `h(s_t) ≥ L_h·v_max·h_max + m`，则 ∀t'∈[t,t+h_max]：`h(s(t')) ≥ h(s_t) − L_h·v_max·(t'−t) ≥ m > 0`，即区间内无碰撞。推论：守卫间隔上界 `h_max ≤ (h(s_t)−m)/(L_h·v_max)`——**时延约束由此成为安全证书的一部分**（P15）。∎

**引理 92（时滞嵌入刹停安全）** 以定义 548 的 d_brake^L 替换停车不变式中的刹停距离后，对任意检测-停车时延 `L_dts = a_t+τ_guard+τ_act ≤ L_dts,max`，从中止点 p* 停驻的轨迹终点距障碍仍 ≥ d_safe。证明：延迟段位移 ≤v_max·L_dts 已计入 d_brake^L，剩余段为纯减速，故总需距离 ≤ d_brake^L(v_p*,a_t) ≤ dist(s_p*,O)−|traj_{p*:K}|。∎

**引理 93（v10→v9→v8 退化等价）** 取中立元：CCG（η=0, β=β_cal）、DCM（学生→重教师）、STR（固定 5Hz + 固定 h_max + a_t 冻结为 0）时，主闭环输出与 v9 ACMD 的 AC/MW/ID 路径逐位一致；再经 v9 引理 83 的映射逐位退回 v8/v7。证明：三者均只改 β 的取值与调度时刻、不改端口取值集合；中立元下 β、K_eff、触发时刻回到 v9 常数值，故等价。∎
