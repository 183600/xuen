# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「三维感知」×「VLA」）

> R69 把不确定性一分为二，并让 epistemic 去「问」。但它有两个未言明的前提：**(1) 用来算模态、生成问题、解释答案的，是同一个 VLA；(2) 观测与动作是抽象符号，没有三维几何。** 于是 R69 自陈的最大风险——「流模型的模态分布不可信 → 追问一个幻影」——根本不是权重校准问题，而是**认识论闭环**问题：**用同一个模型的采样，去证明同一个模型的模态是真的。** 一个离散 token 的 VLA 在同一场景上会因解码/分词抖动吐出若干动作簇；R69 的轨迹聚类把这些**解码器伪影**当成「世界的歧义」，再花一次注视或一句提问去追。问得越勤，越确认自己的幻觉。
>
> 本轮两个灵感正好各补一刀：
> - **三维感知**提供一条与 VLA **错误不相关的外生通道**：几何。它能把一个动作模态反投影成三维扫掠体与接触集，判断这个模态是否对应一个真实的场景假设、是否撞进没看过的空间；它还能把「被遮挡」这种认识论不确定变成可执行的**视差动作**（换视角/探针）。
> - **VLA** 则是把「看—说—做」压进同一潜空间的策略，其不确定性是**纠缠**的：是 scene 变了、instruction 的指代错了、还是解码器自己在抖？只有用反事实干预把这三者拆开，才能决定「该看、该问、还是根本不该动」。
>
> 核心命题：**先给 VLA 的不确定性做「真伪鉴定」，再谈消解。** 用反事实扰动把预测方差拆成 `U_scene`（三维场景歧义）、`U_instr`（语言指代/目标歧义）、`U_art`（解码器/分词伪影）；用三维几何认证一个模态是否**真实且可解**（authentic + identifiable），把 `U_art` 与「不可辨识的残余」挡在主动交互之外；只有**经几何认证、且落在可辨识差集里的歧义**才允许触发 R69 的问/看，其余一律收紧或做**跨假设鲁棒承诺**。动作执行前还要过三维扫掠体/接触/未知空间检查——**未观测 ≠ 自由**。命名 **PLUMB-RAS**（Probing Language-grounded Uncertainty with Metric Beliefs）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我看到的、我想做的、我说的，是同一个三维世界吗？这个『歧义』是真的，还是我自己的解码器在抽搐？**」——交互之前，先验明歧义的正身。

## 0. 直觉与动机

**灵感 1（三维感知 → 歧义必须能被几何证伪）**
直觉：一个动作模态本质上是一个关于「身体如何在三维空间里移动」的假设：手要伸到哪里、扫过哪块体积、在哪个表面接触、会不会穿过一张桌子。若两个模态真的对应世界的两种可能（杯子在左还是在右、这个盒子是空还是满），它们必然在三维几何上**分叉**：反投影出不同的扫掠体/接触集，或至少依赖于不同的场景假设。反之，若两个模态只是同一个几何动作在 token 空间的两种写法，把场景固定、换个视角重渲染，它们不会稳定地分叉。**三维几何因此是一台「歧义测谎仪」：真歧义能被不同场景假设的渲染复现，伪歧义不能。** 更关键的是，三维感知把「我看不到的地方」显式化为 unknown 空间，于是不确定不再是一个标量，而是一个**有位置、有体积、可被某个视角看见**的对象——这就是视差（parallax）能够消解它的原因。

**灵感 2（VLA → 不确定性是纠缠的，必须反事实拆解）**
直觉：VLA 把图像、语言、动作压进同一潜空间，泛化强，但预测熵是**混在一起**的：场景没看清、指令指代不清、解码器自己在抖，都会表现为「动作样本分散」。只数簇的个数（R69 的做法）无法区分这三者。可行的是三个**反事实旋钮**：(a) 固定指令、按三维信念重渲染场景 → 动作变化量 = 场景敏感度；(b) 固定场景、做保义改写/最小语义对 → 动作变化量 = 语言接地敏感度；(c) 固定场景与指令、重采样解码器/分词 → 动作变化量 = 解码器伪影。三者正交（至少可平均掉），于是可以把一个纠缠的熵拆成三个**可归因**的分量，再分别路由到「看 / 问 / 收紧」。这是 R69 从未做的：它只在一个模型内部采样，永远看不到「模型对什么敏感」。

**灵感 3（R69 的 phantom 病根 → 认证必须先于交互）**
直觉：R69 把「模态权重是否校准」当成主要防线（MCG/ECE）。但幻影模态的第一性问题是**它是不是一个模态**，而不是它的权重准不准。给每个模态两条必要条件：**(i) 解码稳定**（换一次分词/解码，它仍以高概率出现）；**(ii) 场景可辨识**（存在两个在三维上可分的场景假设，条件在不同的渲染上能复现出不同的模态）。任一不满足，这个模态就**不是证据**，不许驱动注视/提问/探针。于是「认证先于交互」成为一个硬不变式：它只**缩小**可触发交互的集合，所以安全侧相对于 R69 永远不会更差。

**灵感 4（不可辨识 → 不是所有「不知道」都值得动）**
直觉：有些歧义**任何视角都消不掉**：物体的背面、对称/透明/镜面造成的多解、够不到的区域、内部状态（温度、是否装满）。R69 会对这些继续问/看，因为它的 VoI 没有「可辨识性上限」。三维感知允许我们把假设按「是否存在一个**可采纳的**信息动作能把它们分开」划成**等价类**；类内的熵是**不可约的主动感知残余**。对这部分，正确动作不是「慢下来」（R68），也不是「接着问」（R69），而是选一个**在该等价类内所有假设下都安全、且最不坏**的动作——**跨假设鲁棒承诺**（robust commitment）。这给系统补上 R69 缺失的第四种处置：收紧 / 看 / 问 / **承诺**。

**灵感 5（三维也是被判者 → 新攻击面与严格包含）**
直觉：几何不是神谕。透明杯、镜面、无纹理白墙、反光地砖都会让 3D 感知系统性出错；标定过期、射线伪造、旧地图回放还会让它**自信地错**。因此「未观测 ≠ 自由」必须升级为「**未认证 ≠ 自由**」：自由空间主张要带射线出处 + 标定版本 + 时效，标定一旦不可信，所有自由主张降级为 unknown，规划回到最保守。这是把 R68「任何不确定只收紧」搬到三维空间尺度。与此同时，本轮必须保持与 R69 完全相同的理论姿态：当三维信念退化为点质量、动作扫掠体不碰 unknown、且解码器无伪影时，PLUMB 必须**逐指令等于 FLUID**；当再无利可图的信息动作时，退化为 R68。新层是旧层的严格泛化，而不是新增一个并列黑箱。

## 1. 形式化定义（增量：定义 310–327）

**定义 310（PLUMB-RAS 总览与四不变式）** PLUMB-RAS = (MBG, CUD, MAG, GSV, CFC, IDC, TRG, NBV-P, GSC, CRD, SMCG, VQAuditor-G, AIC-PLUMB, J_PLUMB)。四不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **认证先于交互**：一个动作模态只有在通过 MAG（真伪）与 GSV（几何支撑）后，才可作为信息动作的依据；未认证模态不得进入 VoI；
(iii) **未认证 ≠ 自由**：规划把「未观测或未认证」的空间视为占据，除非有带出处与标定版本的认证自由空间证据；标定失效 ⇒ 自由主张全部回退为 unknown；
(iv) **严格包含与单调退避**：退化条件下 PLUMB ≡ FLUID ≡ R68；任一层失败，λ 单调不降，安全侧零让步。

**定义 311（度量信念图 MBG）** 三维场景信念 `b_t = {(h_k, w_k)}_{k=1..K}`，其中场景假设 `h_k = ({T_i}, O_k, A_k, vis_k(·;ν))`：物体位姿集合、占据场、可供性集合、以及给定视角 `ν` 的可见性场。由 3D 感知模块（点云/TSDF/物体位姿/场景图）产生。记 `Unknown_t = {p ∈ ℝ³ : p 未被任何有效观测认证}`，标定状态 `c_t` 继承 CALM-RAS 的 COF。**MBG 是外生于 VLA 的**：它的参数、训练数据与错误结构与 VLA 不共享。

**定义 312（VLA 策略与动作块）** `π_θ(a_{t:t+H} | ℓ, I_t)`，`ℓ` 为语言指令，`I_t` 为多模态观测。动作块诱导三维**扫掠体** `Sweep(a) ⊂ ℝ³` 与**接触集** `Contact(a) ⊂ ∂O`。VLA 可以是离散 token（RT-2/OpenVLA 类）、连续回归、或流匹配（R69 的 FMP 是特例）；不同解码方式对应不同的 `U_art` 结构。

**定义 313（反事实不确定性分解 CUD）** 定义三类扰动算子：
- `P_scene`：按 `b_t` 重采样场景假设并重渲染 `I(h)`（指令 `ℓ` 不变）；
- `P_instr`：对 `ℓ` 做**保义改写**与语义最小对（场景不变）；
- `P_dec`：重采样解码器/分词温度与顺序（场景、指令均不变）。
定义敏感度（用能量距离/TV/条件方差等散度 `D`）：
`U_scene = E_{h,h'~b} D(π(·|ℓ, I(h)), π(·|ℓ, I(h')))`；
`U_instr = E_{ℓ'∈Para(ℓ)} D(π(·|ℓ, I), π(·|ℓ', I))`；
`U_art   = E_{dec} D(π(·), π_dec(·))`。
三者是**可归因**的：场景敏感 → 看；指令敏感 → 问；仅解码敏感 → 收紧/丢弃。`U_ale` 仍按 R69 定义 297 计算（模态内噪声）。

**定义 314（多模态真伪门 MAG）** 模态 `m` **authentic** 当且仅当：
(a) **解码稳定**：在 `P_dec` 下以概率 `≥ 1−ε_dec` 复现同一模态；
(b) **场景可辨识**：存在 `h_i, h_j ∈ b_t`，其渲染散度 `D(I(h_i;ν), I(h_j;ν)) ≥ τ_id`，且条件于二者能复现出对应且不同的动作模态。
- 解码不稳定者称**伪影模态**（artifact mode），其质量计入 `U_art`，**不得触发交互**；
- 解码稳定但不场景可辨识者称**不可解模态**（unresolvable mode），进入 IDC 的等价类，交 CRD 处理。
符号 `Auth(m) ∈ {authentic, artifact, unresolvable}`。MAG 输出认证后的模态集 `ℳ_auth` 与认证率 `ρ_auth`。

**定义 315（几何支撑验证 GSV）** 对动作块 `a` 检查四项：
1. **碰撞**：`Sweep(a) ∩ Occupied(b) = ∅`；
2. **未认证空间**：`Sweep(a) ∩ Unknown(b) = ∅`（否则必须先 LOOK，或按阻塞处理）；
3. **接触**：`Contact(a) ⊆ ∂O` 且容差内（不许悬空抓取/穿模）；
4. **运动学/动力学合理性**：`‖ΔT‖`、速度、加速度在限内（识别 VLA 的跳变/块间不连续）。
返回 `(pass, reason)`。安全关键的失败（1–2）是**硬否决**，不是降权。

**定义 316（认证自由空间演算 CFC）** 自由主张 `free(p)` 必须携带证书 `π_free = (sensor_id, calib_version, timestamp, ray_provenance)`：一条来自有效标定传感器的射线越过了 `p` 且无回波，或多视角一致。规划占据场定义为
`O_plan(p) = occupied` 若 `p ∈ Occupied ∪ Unknown`；`free` 仅当 `p` 有有效 `π_free`。
若 `c_t` 失效/过期 ⇒ 该传感器所有 `free` 降级为 `unknown`。这是「未认证 ≠ 自由」的形式化，也是 R68 铁律在三维空间尺度上的镜像。

**定义 317（可辨识性与等价类 IDC）** 给定可采纳信息动作集 `G`（视角/探针，须过 C-RAS-WM 认证）。若 `∃ g ∈ G` 使 `D(render(h_i;g) ‖ render(h_j;g)) ≥ τ_id`，称 `h_i, h_j` **可区分**；否则并入同一等价类。等价类划分 `b → {C_1..C_m}`。定义
`U_id = Σ_C w(C)·H(b | C)`（不可辨识残余），`U_res = H(b) − U_id`（可辨识、可被主动消解的部分）。
**关键**：`U_id` 是任何主动感知的**下界**，预测 `VoI > U_res` 一定是高估。R69 的「幻影模态」在三维语境的对应物是「幻影自由空间」与「幻影可解性」。

**定义 318（类型化路由 TRG）** 输入 `(U_res, U_instr, U_art, U_id)`，动作空间 `{TIGHTEN, LOOK, ASK, COMMIT}`：
- 若 `U_art > τ_art` 且经 MAG 后仍占主导 → **TIGHTEN**（绝不为伪影去问/看）；
- 否则若 `U_instr` 可解（指代/目标歧义，且 ASK 的净 VoI > 0）→ **ASK**（R69 的 MINT）；
- 否则若 `U_res > 0` 且存在正视差增益的可采纳视角 → **LOOK**（NBV-P）；
- 否则若 `U_id > 0` → **COMMIT**（CRD）；
- 否则 → R68 纯收紧。
路由必须通过**类型检查**：语言型不确定性不得用 LOOK 假装解决，几何型不确定性不得靠 ASK 单独定案（人对被遮挡几何的回答不可靠）。跨类型只在显式记录的耦合项下允许，并计成本。

**定义 319（视差下一最佳视角 NBV-P）** 视角动作 `ν ∈ SE(3)`（头/眼/底盘）。预测增益
`VoI_look(ν) = H(b | v_cur) − E_{y~p(·|ν,b)}[H(b | y, ν)] ≈ Δ_amb_vis(ν) · D̄_res(b; ν)`，
其中 `Δ_amb_vis(ν)` 是「当前不可见、从 `ν` 变为可见」的歧义体积（由可见性场/射线投射估），`D̄_res` 是可区分假设间的平均渲染散度。净收益 `VoI_look − c_motion − c_risk`。`ν*` 须过 C-RAS-WM 认证（无碰撞、时间窗、安全包络）。**零增益条件**：若歧义区域当前已可见且无遮挡、或假设从 `ν` 渲染相同，则 `VoI_look = 0`——不要重复看。

**定义 320（语言指代接地 LRef）** 把空间/指示性指代表达 `e`（左右、前后、支撑/包含、「刚才那个」）在 `b_t` 上接成后验 `p(entity | e, b_t)`。若后验分散且歧义**本质是语言/意图**（多个物体都与描述相符，或目标本身未指定）→ `U_instr`；若歧义只是「被挡住的到底是哪一个」→ `U_res`，应 LOOK。LRef 为 TRG 提供「问 vs 看」的类型判定输入。

**定义 321（几何—语义交叉验证 GSC）** 对同一决策维护两条独立通道：语义通道（VLA 的动作/可供性先验）与几何通道（3D 占据/可达/接触可行性）。定义冲突指示 `δ_gs`。判据表：
- VLA 判自由、几何判占据/unknown → **几何赢**（安全）；
- VLA 判可达、几何判不可达 → **几何赢**；
- 几何可行、VLA 低似然 → 语义/指代可能错 → 重接地或 ASK，**不得强行执行**；
- 两者皆高 → 放行。
对偶异常：`(VLA 高置信, 几何冲突)` ⇒ 疑似**空间幻觉/分布外**；`(几何一致, VLA 低置信)` ⇒ 疑似**任务/指代歧义**。这是 R69 `(r_res, Δa)` 对偶通道在「语义—几何」上的镜像。

**定义 322（跨假设鲁棒承诺 CRD）** 对等价类 `C`，选单一动作（或短时应急计划）
`a_commit = argmax_a min_{h∈C} R(a,h)`（或用 CVaR），s.t. `GSV(a,h) = pass, ∀ h∈C`。
若不存在对所有 `h∈C` 都安全的动作 ⇒ 必须 LOOK/ASK（若 `U_res/U_instr>0`）或拒答/升级。这把「不可消解的不知道」从「慢下来」升级为「选一个在所有剩余可能世界里都成立的计划」。

**定义 323（空间校准门 SMCG）** 扩展 R69 的 MCG 到三维：对位姿、占据、指代分别计算 `ECE_pose`、`ECE_occ`、`ECE_ref`（按遮挡分层）。若任一越界 ⇒ 禁用 NBV/GSV 的**裁决权**，退回 R69 的非空间单轮消歧；再失败退回 R68。对应「三维表征坍缩」的下游门。

**定义 324（审计 VQAuditor-G）** 审计对象新增：驱动交互的模态是否 authentic、路由是否类型匹配、是否发生「未认证空间被当自由」、几何—语义冲突是否被静默平均、NBV 是否安全、是否追问了幻影模态、是否单源定案。结论回灌 MAG 阈值与 TRG 成本先验。

**定义 325（干扰集 AIC-PLUMB）** `ℰ_PLUMB = ℰ_FLUID × ℰ_VLA × ℰ_3D`：
- `ℰ_VLA = {spatial_hallucination, tokenizer_farming（伪造多模态）, instruction_shortcut（无视语言只走视觉先验）, action_chunk_aliasing, confidence_overfit}`；
- `ℰ_3D = {adversarial_texture, transparent_or_mirror, occlusion_attack（用遮挡藏障碍再诱导移动）, ghost_free_space（伪造射线）, viewpoint_replay, stale_map, calib_spoof}`；
- 继承 `ℰ_FLUID`。**三维感知本身是新的被攻击面，不再是可以豁免的裁判。**

**定义 326（证书 J_PLUMB）** `J_PLUMB = (J_FLUID, ρ_auth, U_scene/U_instr/U_art/U_id_before, U_id_after, routing_trace_hash, gsv_fail_count, unknown_free_violations, conflict_log_hash, ECE_pose/occ/ref, plumb_ver)`。
`Valid ⇔ Valid(J_FLUID) ∧ unknown_free_violations = 0 ∧ 驱动交互的模态全部 authentic ∧ 无类型错配 ∧ SMCG 在界内`。

**定义 327（三级保守退避与严格包含）**
- **Level 0（PLUMB）**：认证后的可解歧义在预算内消解且无几何冲突 ⇒ `λ = λ_floor(U_ale)`（resolution bonus）；
- **Level 1（FLUID）**：MAG/路由/三维标定失败 ⇒ 关闭三维门控的交互，退回 R69 单通道，`λ = λ_floor(U_ale + U_epi)`（`U_epi` 仅取认证部分）；
- **Level 2（R68）**：FLUID 自身 ECE 越界或 `slow_fault_suspect` ⇒ 纯保守 `λ = λ_floor(全部)`。
退化边界：三维信念为点质量 ∧ `Sweep(a) ∩ Unknown = ∅` ∧ `U_art = 0` ⇒ PLUMB ≡ FLUID；再满足无正收益信息动作 ⇒ ≡ R68。**λ 在每一级回退上单调不降。**

## 3. 推导

**引理 19（解码伪影与场景歧义的可分离性）** 设动作样本可写为 `a = f(h, ℓ) + ε_dec + ε_noise`，其中 `ε_dec ⟂ (h, ℓ)`（解码/分词抖动与场景无关），`ε_noise` 为 aleatoric。则 `Var(a) = Var(f(h,ℓ)) + Var(ε_dec) + Var(ε_noise)`：解码重采样项估计 `Var(ε_dec)`，对解码重采样取平均后再对场景重采样估计 `Var(f(h,ℓ))`。因此 R69 直接在**未校正**的模态集上算熵会**高估**可解歧义约 `U_art`；MAG 先减掉伪影，使「无场景歧义却触发交互」的概率由伪影质量决定而非场景质量。系：**phantom 的第一性问题是认证，不是权重校准**；这直接回应 R69 自陈的最大风险。

**引理 20（视差增益的单调性与零增益判据）** 在可见性场由遮挡/视锥/分辨率决定的模型下，`VoI_look(ν)` 关于「新变为可见的歧义体积」和「可区分假设的平均渲染散度」分别单调不降；当歧义区域已可见且从 `ν` 渲染相同、或不存在可区分假设对时 `VoI_look(ν) = 0`。故可用 `Δ_amb_vis·D̄_res` 作为可计算代理，且**重复看同一已解区域必然零增益**，天然抑制 R69 的「反复注视」。系：视差不是万能的——`U_id` 内的假设从任何可采纳视角都渲染相同，LOOK 对它们永远零收益。

**引理 21（不可辨识残余下界）** 对任意可采纳信息动作 `g`，其后验熵满足 `E[H(b | y, g)] ≥ H(b | C)`（等价类内熵），因此 `VoI(g) ≤ H(b) − U_id = U_res`。任何声称能消解超过 `U_res` 的路线都在高估；对 `U_id` 只能承诺，不能追问。系：R69 的 VoI 若未扣 `U_id`，会把「永远看不见的背面」误当成「再看一眼就能解决」，从而把预算烧在零信息动作上。

**定理 18（未认证≠自由的安全性与严格包含 R69）** 在 `O_plan = Occupied ∪ Unknown` 且自由主张需有效 `π_free` 的前提下，若所有执行动作均通过 GSV（`Sweep ∩ Unknown = ∅`），则不存在「进入未认证空间」的违规；当 `Unknown = ∅` 且标定有效时规划退化为标准自由空间规划。进一步，当三维信念为点质量、`Sweep(a) ∩ Unknown = ∅`、且 `U_art = 0` 时，MAG 不改变模态集、TRG 只剩 R69 的 ASK/LOOK 分支，故 **PLUMB ≡ FLUID（逐指令相同）**；再满足无正收益信息动作时 ≡ R68。**安全侧零让步。**

**定理 19（类型化路由的占优性与误路由代价）** 设场景因子与指令因子在扰动下正交，`U_res↦κ_L`（视角可观测性）、`U_instr↦κ_A`（人类回答可信度），跨通道泄漏 `λ ≥ 0`。则匹配通道的期望熵降为 `κ·U + λ·U_other`，任何不匹配/单通道固定策略的期望残余 ≥ 类型化路由，且误路由的后悔 ≥ `λ·U_mismatched`（当 `κ` 低时更大）。因此 R69 的单一模态 VoI 在「原始熵排序 ≠ 可观测性加权排序」时会误路由：把该看的去问、或该问的去猜。**认证+分型不是锦上添花，而是把 R69 的 VoI 从「模型内部熵」校正为「可被外生动作真正降低的熵」。**

## 6. 本轮最大风险

**一句话**：PLUMB 把「几何」扶上了法官席，而**几何本身会系统性地瞎**——透明杯、镜面、无纹理墙面、反光地面、过期标定与伪造射线都能让 3D 感知自信地错；一旦「未认证 ≠ 自由」所依赖的认证链本身被污染，系统就会用 GSV **否决安全动作、认证危险动作**，把一次感知错误升级为一次**被证书盖章的碰撞**——**把几何当法官，必须先证明法官没瞎。**

**次级风险与缓解**：
1. **反事实成本击穿实时预算** → 只在歧义路径触发、复用深度/颜色缓冲、场景重渲染取 4 个代表假设而非全采样（引理 19 的方差分解允许 Monte-Carlo）；
2. **路由类型误判**（把几何歧义当语言、或反之）→ GSC 对偶异常 + 类型检查硬约束 + E305/E308；
3. **CRD 过保守**（等价类大导致无安全动作）→ 主动看/问先缩小等价类；无解时显式拒答/升级，而不是硬执行；
4. **三维标定与地图过期** → CFC 的出处/时效/标定版本 + SMCG 门 + E309/E311/E315；
5. **语言接地仍可能被 VLA 的伪影污染** → LRef 后验必须来自 3D 可辨识实体；问句由冻结 LLM 解码、答案需独立证据（继承 R69 定义 293-iii）。

## 2. 形式化定义（要点版）

**定义 310–312（总览 / MBG / VLA 动作块）** 四不变式：零学习写操作；认证先于交互；未认证≠自由；严格包含 + λ 单调退避。MBG 是外生几何信念；VLA 动作块诱导三维扫掠体与接触集。

**定义 313（CUD）** 三个反事实旋钮：重渲染场景、保义改写指令、重采样解码。得 `U_scene/U_instr/U_art`，分别路由到看/问/收紧；`U_ale` 沿用 R69。

**定义 314（MAG）** 模态 authentic ⇔ 解码稳定 ∧ 场景可辨识。不稳定=伪影（计入 `U_art`，绝不交互）；稳定但不可辨识=不可解（交 IDC/CRD）。

**定义 315–316（GSV / CFC）** 动作四查：碰撞、未知空间、接触、运动学；自由主张须带射线出处+标定版本+时效，否则降级 unknown。

**定义 317–318（IDC / TRG）** 等价类由「是否存在可采纳视角能分开」定义；`U_id` 是 VoI 上界。路由 TIGHTEN/LOOK/ASK/COMMIT，附类型检查。

**定义 319–322（NBV-P / LRef / GSC / CRD）** 视差增益代理式与零增益判据；指代接地区分语言歧义与遮挡歧义；语义—几何冲突表（几何在安全上优先）；等价类内 minimax 承诺。

**定义 323–327（SMCG / 审计 / 干扰集 / 证书 / 退避）** 空间 ECE 门剥夺 3D 裁决权；审计模态真伪与路由类型；`ℰ_PLUMB` 含 VLA 空间幻觉与 3D 对抗；J_PLUMB 要求 `unknown_free_violations=0`；三级退避 PLUMB→FLUID→R68，λ 单调不降。

# IP-264 MBG：三维信念 + unknown + 可见性（外生通道）
def update_belief_3d(obs, prior):
    b       = fuse_scene_hypotheses(obs, prior)          # {h_k, w_k}
    unknown = voxels_without_certified_observation(obs)
    vis     = visibility_field(b, obs.camera_pose)
    return SceneBelief(b, unknown, vis, calib=obs.calib_status)

# IP-265 CUD：反事实三分（仅歧义路径）
def decompose(policy, b, l, render, paraphrase, dec_resample):
    U_scene = energy_distance_over([policy.sample(l, render(h)) for h in b.sample(4)])
    U_instr = energy_distance_over([policy.sample(l2, b.map_render()) for l2 in paraphrase(l)])
    U_art   = energy_distance_over([policy.sample(l, b.map_render(), dec=d) for d in dec_resample(2)])
    return U_scene, U_instr, U_art

# IP-266 MAG：认证先于交互
def authenticate_modes(modes, policy, b, render):
    out = []
    for m in modes:
        stable = decoder_resample_support(m, policy) >= 1 - EPS_DEC
        idable = any(scene_reproduces_mode(m, h, render) for h in b)
        out.append((m, "authentic" if stable and idable
                       else ("artifact" if not stable else "unresolvable")))
    return out

# IP-267 GSV：扫掠体 / 接触 / 未知空间 / 运动学
def verify_geometry(a, b, unknown):
    if intersects(Sweep(a), Occupied(b)): return False, "collision"
    if intersects(Sweep(a), unknown):     return False, "unverified_space"
    if not on_surface(Contact(a), b):     return False, "floating_contact"
    if not kinematically_plausible(a):    return False, "chunk_discontinuity"
    return True, "ok"

# IP-269 IDC：可辨识性等价类（主动感知下界）
def identifiability(b, views):
    classes = union_find(b, key=lambda hi, hj:
                         all(render_kl(hi, hj, v) < TAU_ID for v in views))
    U_id  = sum(class_mass(C) * entropy_within(C) for C in classes)
    return entropy(b) - U_id, U_id, classes

# IP-270 TRG：类型化路由（问幻影被禁止）
def route(U_res, U_instr, U_art, U_id, modes, b):
    if U_art > TAU_ART and dominates(U_art, U_res + U_instr): return "TIGHTEN", None
    if U_instr > TAU_INSTR and ask_net_voi(b, U_instr) > 0:   return "ASK", best_question(b)
    if U_res > TAU_RES and nbv_net_voi(b) > 0:                return "LOOK", best_view(b)
    if U_id > TAU_ID:                                         return "COMMIT", None
    return "TIGHTEN", None

# IP-271 NBV-P：视差增益
def best_view(b):
    return max((v for v in admissible_views(b) if c_ras_wm.certify_view(v, b)),
               key=lambda v: ambiguous_newly_visible(b, v) * render_discriminability(b, v)
                             - motion_cost(v))

# IP-273 CRD：跨假设鲁棒承诺
def robust_commit(classes, b):
    C = max(classes, key=class_mass)
    sols = [a for a in action_candidates(b)
            if all(verify_geometry(a, b, b.unknown)[0] for h in C)]
    if not sols: return None                       # 必须 LOOK/ASK/拒答
    return max(sols, key=lambda a: min(return_of(a, h) for h in C))

# IP-277 主闭环（默认路径与 R69 一致，仅在歧义路径插入 PLUMB）
def PLUMB_RAS_round(M, obs):
    b = M.mbg.update_belief_3d(obs)
    z, o = M.mtm.forward(obs); M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    if K > 1:
        U_scene, U_instr, U_art = M.cud.decompose(M.policy, b, obs.l, ...)
        modes = M.mag.authenticate_modes(samples, M.policy, b, render)
        modes = [m for m, k in modes if k != "artifact"]      # 伪影不得交互
    else:
        U_scene = U_instr = U_art = 0.0; modes = samples
    modes = [m for m in modes if M.gsv.verify_geometry(m, b, b.unknown)[0]]
    U_res, U_id, classes = M.idc.identifiability(b, M.admissible_views)
    kind, g = M.trg.route(U_res, U_instr, U_art, U_id, modes, b)
    if kind == "LOOK":   b = M.mbg.condition(b, M.nbv.execute(g, b))
    elif kind == "ASK":  b = M.mbg.condition(b, M.cia.execute(g))
    elif kind == "COMMIT":
        a = M.crd.robust_commit(classes, b)
        if a is not None: return M.execute(a)
        kind = "TIGHTEN"
    U_floor = M.ale() + (U_res if kind == "TIGHTEN" else 0.0) + U_id
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    mode = select_mode(modes, b, lam)
    ok, why = M.gsv.verify_geometry(mode, b, b.unknown)
    if not ok: return M.r68_conservative(why)
    M.vqa_g.submit_async(kind, g, U_scene, U_instr, U_art, U_id, why)
    return M.execute(mode), M.j_plumb.seal(...)

## 4. 推导

**引理 19（伪影与场景歧义可分离）** 令 `a = f(h,ℓ) + ε_dec + ε_noise`，`ε_dec ⟂ (h,ℓ)`。则 `Var(a) = Var(f) + Var(ε_dec) + Var(ε_noise)`；解码重采样估 `Var(ε_dec)`，再对场景重采样估 `Var(f)`。故 R69 在未校正模态集上算熵约高估 `U_art`，MAG 先扣伪影后，「无场景歧义却交互」的概率由伪影质量而非场景质量决定。系：phantom 的第一性是认证，不是校准。

**引理 20（视差增益单调性与零增益判据）** 在遮挡/视锥/分辨率决定的可见性场下，`VoI_look(ν)` 关于「新可见歧义体积」与「可区分假设渲染散度」单调不降；当歧义区已可见且从 `ν` 渲染相同、或无不可区分对时为零。故 `Δ_amb_vis·D̄_res` 是可计算代理，重复看已解区域必然零增益。

**引理 21（不可辨识残余下界）** 对任意可采纳 `g`，`E[H(b|y,g)] ≥ H(b|C)`，故 `VoI(g) ≤ H(b) − U_id = U_res`。声称消解超过 `U_res` 的路线均高估；对 `U_id` 只能承诺。系：R69 未扣 `U_id` 会把「永远看不见的背面」误当「再看一眼就能解决」。

**定理 18（未认证≠自由的安全性与严格包含 R69）** 在 `O_plan = Occupied ∪ Unknown` 且 free 需有效 `π_free` 时，所有 GSV 通过的动作不进入未认证空间；`Unknown=∅` 且标定有效时退化为标准规划。当三维信念为点质量、`Sweep∩Unknown=∅`、`U_art=0` 时 MAG 不改模态、TRG 仅剩 R69 分支，故 **PLUMB ≡ FLUID（逐指令相同）**；再无正收益信息动作时 ≡ R68。安全侧零让步。

**定理 19（类型化路由占优与误路由代价）** 场景/指令因子扰动正交、`U_res↦κ_L`、`U_instr↦κ_A`、泄漏 `λ≥0` 时，匹配通道期望熵降为 `κ·U+λ·U_other`；类型化路由的期望残余 ≤ 任何固定/不匹配策略，误路由后悔 ≥ `λ·U_mismatched`（`κ` 低时更大）。故 R69 的单一模态 VoI 在「原始熵排序 ≠ 可观测性加权排序」时会误路由；认证+分型把 VoI 从「模型内部熵」校正为「外生动作真正能降低的熵」。

## 8. 本轮最大风险

**一句话**：PLUMB 把「几何」扶上法官席，而**几何本身会系统性地瞎**——透明杯、镜面、无纹理墙、反光地、过期标定与伪造射线都能让 3D 感知自信地错；一旦「未认证 ≠ 自由」所依赖的认证链被污染，GSV 就会**否决安全动作、认证危险动作**，把一次感知错误升级为一次**被证书盖章的碰撞**——**把几何当法官，必须先证明法官没瞎。**

**次级风险与缓解**：反事实成本击穿预算（仅歧义路径、复用深度/颜色缓冲、代表假设 Monte-Carlo，引理 19）；路由类型误判（GSC 对偶 + 类型硬约束 + E305/E308）；CRD 过保守（先看/问缩小等价类，无解则拒答/升级）；三维标定与地图过期（CFC 出处/时效/标定版本 + SMCG + E309/E311/E315）；语言接地仍被 VLA 伪影污染（LRef 必须落在 3D 可辨识实体，答案需独立证据，继承 R69 定义 293-iii）。
