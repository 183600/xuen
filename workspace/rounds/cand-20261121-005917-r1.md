# 第 1 轮（新灵感循环第 1 轮；本轮灵感：「意图理解」×「社会规范理解」）

> **基线**：上一轮（灵感「大语言模型」×「机器人」×「智能体」）MetricVoiceGauge-NCD-HUTDH-v17（定义 657–686；引理 137–142；实验 E691–E710）。
> 本轮纪律：**意图是集合不是点、规范只收缩不扩权、澄清本身是认证动作**。不推倒 v17：v17 的 CLP/S2C/HCG/PSV/APS/AMC、v16 的 BTS/TRM/WBC/CSC/NCS/MCA/WCB、v13 的 AIO/RTIC/CPD/DGC/DDL/RTCR、v14 的 SCD/DSD/DCA/EDC、v12 的 USG/TGC/BAA/GAGP/UC、v11 的 HAS/HCC/HATD/HDT、v10 的 NGE/DSL/CC/CWM/CAE/NCP、v9 的 AC/MW/ID、v8 的 DA/SPR/Cal 与历轮不变式全部保留。六个新组件——CIB（可信意图信念）、VIG（信息价值闸门）、LGM（可读性与心智模型）、SND（作用域规范语义）、NAC（规范可采纳证书器）、SRR（社会修复与恢复）——一律以**中立元接入 v17 语言—行为层之上**，失效即严格退回 v17（引理 149），再沿 v17→v16→v15→v14→v13→v12→v11→v10→v9→v8→v7→v6 退化链退回。本轮把"意图理解"改写为**共形裁剪的意图信念集**、把"社会规范理解"改写为**作用域受限的规范收缩与越界让渡**、把"人机交互"改写为**认证的澄清—公告—修复三联动作**。

## 0. 直觉与动机

**灵感 1（意图理解 → 理解不是选一个意图，而是排除足够多的意图）**
直觉：传统意图识别输出一个 argmax 标签；但在人机协作中，最危险的错误不是"标签错"，而是"在不确定时仍然自信地行动"。核心创新：**可信意图信念（Credal Intent Belief, CIB）**。LLM 只提出*候选意图*（它擅长生成假设，不擅长裁决），共形非一致性分数 `r(o,i)` 在校准交互日志上给出分位数 `q̂_β`，只有 `r(o,i) ≤ q̂_β` 的候选进入信念集 `I_t`；`I_t` 可以为空（异常 → 必须澄清）或含多个意图（模糊 → 必须鲁棒行动或提问）。关键反直觉点：**"我不知道你想要哪个"是一个可验证的状态，而不是一次失败**——当 `|I_t|>1` 时，系统只在"对所有可信意图都不破坏其可达性"的动作上行动；一旦没有这样的动作，就执行一个经认证的澄清动作（提问/等待/让位/指向/递出选择），而不是猜。理解的质量不体现在"猜中了"，而体现在"可信集覆盖了真意图、且足够小以支撑决策"。

**灵感 2（社会规范理解 → 规范是安全的对偶，不是安全的同类项）**
直觉：安全回答"能不能做"（运动学/动力学/里程碑），规范回答"以什么方式做、由谁来做、在谁面前做、先后次序如何"（距离、朝向、速度、打断、隐私、征得同意、角色礼貌）。二者几乎正交：一个动作可以绝对安全却极不礼貌（贴脸递刀），也可以礼貌却危险（谦让着让人走进危险区）。核心创新：**作用域规范语义（Scoped Norm Deontics, SND）+ 规范可采纳证书器（NAC）**。规范被写成带作用域 `C_δ`、主体/角色 `s_δ`、道义模态 `μ_δ∈{O,P,F}`、动作谓词 `A_δ`、例外 `E_δ`、文化/关系标签 `κ_δ`、强度 `w_δ` 的**规范原子**；NAC 只做三件事：硬禁忌直接拒绝、软违规定价进信任预算、作用域外一律让渡（defer）。关键反直觉点：**规范不应假装拥有共形覆盖**。意图的统计保证来自"可交换的交互样本"，而规范是文化/关系/语境依赖的、标注稀疏且不可交换的；诚实的做法不是给规范编造置信度，而是**把执行权限收缩到已声明的规范作用域内，越界就交出决策权（问人/停下/保守默认）**。同时规范只能收缩 `Exec`，永不授权。

**灵感 3（二者的共同地基：他者心智与可读性）**
直觉：意图与规范都预设了一个"他者"——意图是*人想要什么*，规范是*人会如何评判我怎么做*。所以两者共享同一块地基：**对他人心智的建模（Theory of Mind, ToM）**。核心创新：**可读性与心智模型（Legibility & Mind Model, LGM）**。一个计划即使安全、意图正确，只要"看起来像在做别的事"，就会损耗信任、诱发干预、破坏协作。LGM 用校准的人类推断模型给出 `P_h(ĥ|π)`：计划必须"可读"（人类能以高概率读出与 `I_t` 一致的目标），否则选择一个等价的更可读计划，或先发一个**只承诺已认证前缀**的公告。关键反直觉点：**公告是一种动作，因而也必须被认证**——绝不能公告尚未被证书覆盖的承诺（"我马上把杯子给你"而杯子还没抓稳），否则语言层重新获得授权能力，v17 的 `Exec_v17⊆Exec_v16` 被击穿。承诺的真实性由"承诺证书"保证：只允许公告一个不可撤销的已认证前缀。

**四者如何统一**
统一为 **v17 之上的意图—规范—可读性层**：v17 回答"哪些语言计划能被安全编译并调度"（`Exec_v17`），v18 回答"在可信意图集、规范作用域与人类可读性下，哪些 v17 计划仍可执行；若都不能，执行哪个认证的澄清/修复动作"（`Exec_v18`）。CIB 是*信念侧*（意图集合），SND/NAC 是*约束侧*（规范收缩），LGM 是*呈现侧*（第二序可读性），VIG 是*决策侧*（行动/询问/等待/让渡），SRR 是*恢复侧*（修复）。共享状态 `ζ_si = (I_t, N_t, M_h, B_trust, Γ_scope, q̂_β, λ_leg, mode_si, trust_log)`。**CIB 回答"可能是哪些意图"，VIG 回答"现在该做、该问还是该等"，LGM 回答"人会把我的动作读成什么"，SND/NAC 回答"这个做法在作用域内是否被允许"，SRR 回答"越界之后如何体面地退回来"**。五者构成"信念—约束—呈现—决策—恢复"的闭环，全部是 v17 之上的**合取过滤器与认证动作选择器**。

## 1. 研究问题（轮次升级版）

- **Q1（可信意图集的覆盖）**：候选意图由 LLM 提议，如何保证 `P(i*∈I_t) ≥ 1−β−ε`（ε 为候选召回缺口）？`r(o,i)` 如何构造以同时拒绝"流畅但错误"的意图？人会对机器人建模并策略性改变行为，可交换性失效时用 ACI/滑动窗能否守住覆盖？`I_t` 为空时应视为异常并澄清，而非静默回退。
- **Q2（意图鲁棒动作与澄清）**：如何定义"对 `I_t` 中每个意图都不破坏其可达性"的选项保持？最坏价值与后悔阈值如何设？何时做、何时问、何时等、何时让渡？澄清动作如何保证是 v17 认证、可逆、非承诺的？问题内容本身如何不越规范（不刺探隐私、不羞辱、不打断）？
- **Q3（规范表示、作用域与冲突）**：如何把礼貌/距离/隐私/先后/角色写成可裁决的规范原子？文化/关系不确定性用 credal 规范集还是显式优先级？规范不可公度与冲突如何裁决（安全≻同意≻明示指令≻作用域默认≻礼貌≻效率）？为什么规范不应有共形覆盖、越界让渡如何形式化？
- **Q4（可读性、信任与修复）**：第二序可读性如何定义（`P_h` 的置信与一致）？公告如何只承诺已认证前缀而不成为新的授权通道？信任预算 `B_trust` 如何定义、累积与恢复？修复动作如何在只选认证动作的前提下不扩权？

## 2. 设计原则（在 P28–P30 基础上新增 P31–P34）

**P31 意图即集合律（Intent as Credal Set）**
LLM 只提议候选意图；唯一的裁决是共形分数 `r(o,i) ≤ q̂_β`。系统不得对点估计意图执行不可逆动作；`I_t` 为空必须进入澄清/让渡，不得静默视为"无意图"；`I_t` 多元素时必须执行意图鲁棒动作或澄清。**候选提议者无权改变置信集。**

**P32 规范只收缩且作用域受限律（Norms Contract, Scope-Bounded）**
规范原子只能拒绝（硬禁忌）、定价（软违规）或让渡（作用域外）；任何规范不得授权一个不在 `Exec_v17` 中的动作。不得对规范声称共形覆盖；NAC 的证书仅在声明作用域 `Γ_scope` 内有效，越界一律 `Defer` 到保守的 v17 默认或人。冲突按固定优先级裁决：`Safety ≻ Consent ≻ ExplicitInstruction ≻ ScopeDefault ≻ Politeness ≻ Efficiency`。规范系统来自受控本体，LLM 只能检索/实例化规范原子，**不得自主新增规范**。

**P33 澄清即可认证动作律（Inquiry is a Certified Action）**
提问、等待、让位、指向、递出选择、请求确认都是**动作**，必须取自 v17 已认证节点且可逆/非承诺；它们只消耗时间与社交预算，绝不新增授权。VIG 只在信息价值超过社会成本时选择澄清；否则选择鲁棒动作或让渡。

**P34 承诺真实性律（Announce Only the Committed Prefix）**
公告（含语言、手势示意）只能描述一个已不可撤销提交的、通过 v17 全证书的**计划前缀**；禁止公告尚未被证书覆盖的承诺。事件中止时由 SRR 发出等价的修复性撤回公告。语言层因此仍无授权能力。

## 3. 与基线的接口（如何退化）

- CIB 失效 ⇒ 退化为"显式指令单例意图"；无显式指令则 `I_t=Ω`（全不确定）→ 只允许让渡到 v17 默认；
- VIG 失效 ⇒ 永不澄清，仅在 `|I_t|=1` 且 v17 认证时行动，否则 v17 默认——**等价 v17（活性下降）**；
- LGM 失效 ⇒ 关闭公告与可读性门，仅执行 v17 计划——**等价 v17**；
- SND/NAC 失效 ⇒ 只保留最小硬禁忌集（同意/近身距离/不伤害）与作用域让渡——**等价 v17（更保守）**；
- SRR 失效 ⇒ 越界即 `stop_hold`（v17 认证的暂停）并交还控制；
- 六者全失效 ⇒ MetricVoiceGauge-NCD-HUTDH-v17，再沿 v17→v16→…→v6 退化；
- **安全继承**：CIB 只裁剪候选集、VIG 只在认证动作中选、LGM 只重排/移除并公告已认证前缀、SND/NAC 只拒绝或让渡、SRR 只在认证动作中选修复；六端口互不相交，均不能新增授权或放宽任何阈值；`Exec_v18 ⊆ Exec_v17` 由引理 144/145/149 保证。

## 4. 预期贡献

1. **可信意图集与共形裁剪**：把"意图理解"从 argmax 标签改写为"LLM 提议 + 统计裁剪"的集合值信念，给出含候选召回缺口的覆盖界 `P(i*∈I_t) ≥ 1−β−ε`，使模糊性成为可度量、可决策的对象；
2. **意图鲁棒执行**：用"选项保持 + 最坏价值"定义对整组可信意图安全的动作，把"猜错意图"从安全问题降为活性/澄清问题；
3. **规范的诚实边界**：明确规范**不该**拥有共形覆盖，提出作用域受限的规范原子、优先级裁决与越界让渡，关闭"用统计置信度给文化规范背书"的伪保证；
4. **认证的澄清—公告—修复三联**：把提问、承诺、道歉都纳入 v17 认证动作集，证明澄清只耗活性、公告只述已承诺前缀、修复只选认证动作，语言层始终无授权；
5. **第二序可读性**：用人类推断模型给出可读性门与承诺证书，把"做对了却让人误解"纳入安全—信任核算；
6. **七层分离的最终形态**：`Exec_v18⊆Exec_v17⊆Exec_v16⊆Exec_v15⊆Exec_v13⊆Exec_v12`，v18 管"意图/规范/可读性"，把协作的社会维度与物理安全维度彻底解耦；E711–E730 覆盖意图覆盖、鲁棒动作、澄清效率、规范冲突、信任预算、修复、跨文化、对抗隐藏意图与端到端。

## 5. 本轮最大风险

**一句话**：CIB 的共形覆盖与 LGM 的人类模型都假设交互样本与真实意图可交换、人不对机器人建模；但真实协作者（尤其带隐藏或策略性意图者）会**根据机器人的信念更新来改变自己的行为**，于是 `i*∈I_t` 的覆盖在自适应/欺骗分布上失效——系统可能在统计上"覆盖良好"、规范作用域内"完全合规"、动作也"可读"，却对一个被刻意隐藏的真实意图造成不可逆伤害，即"置信集校准良好、规范合规、可读性合格，而真实意图从未进入置信集"的对齐缺口。

# IP-415 Credal Intent Belief：LLM 提议，共形裁剪，空集即异常
class CredalIntentBelief:
    def __init__(self, scoring_fn, beta=0.1, min_k=1):
        self.r = scoring_fn          # r(o, i)：观察史与意图假设的非一致性
        self.beta = beta
        self.min_k = min_k
        self.q = None                # 由 calibrate 得到

    def calibrate(self, episodes):   # [(obs_hist, i_confirmed), ...]
        scores = [self.r(o, i) for (o, i) in episodes]
        self.q = finite_sample_quantile(scores, 1 - self.beta)

    def update(self, obs, candidates):      # candidates 由 LLM 提议，无裁决权
        if self.q is None:
            return CredalSet(candidates)    # 未校准：全保留（更保守）
        kept = [i for i in candidates if self.r(obs, i) <= self.q]
        return CredalSet(kept)              # 空集 => 调用方必须 ASK/DEFER

    def recalibrate_adaptive(self, recent_pairs, gamma=0.05):
        # 漂移下用 ACI 式自适应分位数，缓解可交换性失效
        scores = [self.r(o, i) for (o, i) in recent_pairs]
        self.q = adaptive_quantile(self.q, scores, self.beta, gamma)


# IP-416 Value-of-Information Gate：做 / 问 / 等 / 让渡
class ValueOfInformationGate:
    def __init__(self, info_actions, social_cost, rho_min=0.05):
        self.info = info_actions   # 全部为 v17 认证、可逆、非承诺动作
        self.cost = social_cost
        self.rho = rho_min

    def decide(self, I_t, plans, ctx, nac):
        if I_t.empty:
            return ('ASK', self._best_info(I_t, ctx, nac))   # 异常 -> 澄清
        if len(I_t) == 1:
            for p in plans:                                   # 已验证的 v17 计划
                if nac.admissible(p, ctx):
                    return ('ACT', p)
            return ('DEFER', None)
        robust = [p for p in plans
                  if option_preserve(p, I_t)
                  and worst_case_value(p, I_t) >= 0
                  and nac.admissible(p, ctx)]
        if robust:
            return ('ACT', max(robust, key=lambda p: robust_score(p, I_t, ctx)))
        a, voi = self._best_info_voi(I_t, ctx, nac)
        if a is not None and voi > self.rho:
            return ('ASK', a)
        return ('WAIT', None) if self._wait_safe(I_t) else ('DEFER', None)

    def _best_info_voi(self, I_t, ctx, nac):
        best, best_voi = None, float('-inf')
        for a in self.info:
            if not a.certified_v17 or not a.reversible:
                continue
            if not nac.admissible(a, ctx):        # 提问本身也要过规范
                continue
            voi = expected_robust_value_after(a, I_t) - robust_value_now(I_t) \
                  - self.cost(a, ctx)
            if voi > best_voi:
                best, best_voi = a, voi
        return best, best_voi


# IP-417 Legibility & Mind Model：第二序可读性与承诺真实性
class LegibilityMindModel:
    def __init__(self, human_model, lam_leg=0.6, h_max=1.0):
        self.M_h = human_model        # P_h(ĥ | π, ctx)
        self.lam = lam_leg
        self.h_max = h_max

    def legible(self, plan, I_t, ctx):
        dist = self.M_h.infer(plan, ctx)
        top = max(dist, key=dist.get)
        return (dist[top] >= self.lam
                and entropy(dist) <= self.h_max
                and intersects(top, I_t))

    def announce(self, committed_prefix, plan):
        # P34：只公告已不可撤销提交、且全证书成立的已认证前缀
        if not commit(committed_prefix) or not committed_prefix.is_prefix_of(plan):
            return None
        return SpeechAct(kind='announce',
                         content=describe(committed_prefix),
                         certified=True)

    def legible_alternative(self, plan, I_t, ctx, candidates):
        return min((p for p in candidates
                    if same_effect(p, plan) and self.legible(p, I_t, ctx)),
                   key=lambda p: self.M_h.surprise(p, ctx), default=plan)


# IP-418 Scoped Norm Deontics：受控本体 + 作用域 + 优先级
class ScopedNormDeontics:
    def __init__(self, ontology, scope, precedence):
        self.N = ontology            # 版本化受控本体；LLM 只能实例化，不可新增
        self.scope = scope           # Γ_scope
        self.prec = precedence       # Safety > Consent > Instruction > Default > Politeness > Efficiency

    def in_scope(self, ctx):
        return self.scope.covers(ctx)    # 场景/关系/文化假设均覆盖才为真

    def hard_forbid(self, plan, ctx):
        return [d for d in self.N.query(ctx)
                if d.modality == 'F' and d.hard
                and d.matches(ctx, plan) and not d.exception(ctx)]

    def soft_cost(self, plan, ctx):
        return sum(d.w for d in self.N.query(ctx)
                   if d.modality == 'F' and not d.hard
                   and d.matches(ctx, plan) and not d.exception(ctx))

    def conservative_permit(self, plan, ctx):
        # 所有可接受解释下均不违反硬禁忌，且应履行的义务已履行
        interps = self.N.acceptable_interpretations(ctx)   # credal 规范集
        return all(not any(d.hard and d.matches(ctx, plan) for d in interp)
                   and all(discharged(o, plan, ctx)
                           for interp in interps for o in interp.obligations(ctx))
                   for interp in interps)


# IP-419 Norm Admissibility Certifier：硬拒绝 / 软定价 / 越界让渡
class NormAdmissibilityCertifier:
    def __init__(self, snd, trust, margin=0.1):
        self.snd = snd
        self.trust = trust
        self.margin = margin

    def admissible(self, plan, ctx):
        ok, info = self.certificate(plan, ctx)
        return ok

    def certificate(self, plan, ctx):
        if not self.snd.in_scope(ctx):
            return (False, ('OUT_OF_SCOPE', 'DEFER'))      # P32：越界让渡
        hard = self.snd.hard_forbid(plan, ctx)
        if hard:
            return (False, ('HARD_NORM', hard))            # 绝对拒绝
        if not self.snd.conservative_permit(plan, ctx):
            return (False, ('NORM_AMBIGUOUS', 'ASK'))
        cost = self.snd.soft_cost(plan, ctx)
        if self.trust.remaining() - cost < self.margin:
            return (False, ('TRUST_BUDGET', 'DEFER'))
        return (True, ('OK', cost))


# IP-420 Social Repair & Recovery：只在 v17 认证动作中选修复
class SocialRepairRecovery:
    LIBRARY = ['stop_hold', 'retreat', 'yield_way', 'grounded_apology',
               're_ask', 'present_choice', 'hand_back_control']

    def __init__(self, certified_nodes, snd):
        self.nodes = certified_nodes     # v17 认证节点集合
        self.snd = snd

    def on_breach(self, event, ctx):
        cands = [a for a in self.LIBRARY
                 if a in self.nodes
                 and self.snd.conservative_permit(self.nodes[a], ctx)]
        if not cands:
            return self.nodes['stop_hold']       # 兜底：认证的暂停
        # 越轻的承诺、越快的止损优先
        return min(cands, key=lambda a: (commitment(self.nodes[a]),
                                         -urgency(event, a)))

    def repair_budget_update(self, event):
        # 修复只能部分恢复，重复违规不能全额愈合
        return min(event.soft_cost - event.penalty, self.snd.repair_cap(event))

## 3. 推导

**引理 143（可信意图集的共形覆盖，含候选召回缺口）**
设校准集 `{(o_k, i*_k)}_{k=1..N}` 与当前交互可交换、分数有界；`q̂_β` 取第 `⌈(N+1)(1−β)⌉` 次序统计量（越界取 `+∞`）；候选集 `C_t` 满足 `P(i*∈C_t) ≥ 1−ε_cand`。则 `P(i* ∈ I_t) ≥ 1−β−ε_cand`。证明：对真意图分数 `r(o,i*)` 用标准共形秩论证得 `P(r(o,i*) ≤ q̂_β) ≥ 1−β`；再由 `{i*∈I_t} ⊇ {i*∈C_t} ∩ {r(o,i*)≤q̂_β}` 与联合界得下界。∎ 推论：**LLM 的候选质量只进入 `ε_cand`（召回），不改变给定召回下的统计保证**——这正是"提议无特权、统计有裁决"的定量版本；若 `ε_cand=1`（候选从不含真意图），覆盖界退化为 0，故候选召回必须被单独监控（E711）。

**引理 144（意图鲁棒执行不破坏真意图可达性）**
若 `π ∈ Exec_v17` 且 `I-Robust(π,I_t)` 成立（`OptionPreserve` 且 `WCval≥0`），则在事件 `i*∈I_t` 下，执行 `π` 后 `Post(π)∩Goal(i*)≠∅`，真意图仍可达，且 v17 证书保证执行全过程安全。因此相对 v18 新增层，`Exec_v18 ⊆ Exec_v17`，且"猜错意图"导致的不可逆失败概率 `≤ β+ε_cand`。证明：`OptionPreserve` 逐意图给出可达性；`π∈Exec_v17` 给出物理安全；合取过滤器只移除计划。∎ 推论：**意图层把"意图错误"从安全问题转成"可达性/活性"问题**——只有当 `i*∉I_t`（覆盖缺口）时才可能不可逆地偏离真意图。

**引理 145（规范只收缩且作用域受限）**
设 `NAC(π)=in-scope ∧ ¬HardForbid ∧ ConservativePermit ∧ B_trust−SoftCost ≥ m_trust`，且 `Defer` 映射到 v17 保守默认。则 `Exec_v18^{norm} ⊆ Exec_v17`，且不存在任何规范通道新增 `Exec_v17` 之外的动作。证明：每个合取项都是对 `Exec_v17` 的谓词测试；`ConservativePermit` 是"所有可接受规范解释下均不被禁止"的交集语义，只会更严；`Defer` 是选择而非授权。规范本体受控、LLM 不可新增，排除"自造许可"。∎ 推论：**规范的正确性不是统计问题，而是作用域—本体—优先级三元组的一致性问题**；因此我们不主张规范的共形覆盖，只主张其可审计与可让渡。

**引理 146（澄清动作的安全保持与活性条件）**
设 `a ∈ A_info` 是 v17 认证且可逆/非承诺（不改变任务相关状态的可达选项集，`Post(a) ⊇ Post(∅^{task})`），则执行 `a` 不破坏 `OptionPreserve`，只更新观察史；若 VIG 仅在 `VoI(a)>ρ` 时选择 `a`，则在 `VoI` 模型正确的前提下，澄清的期望鲁棒价值非降。证明：可逆性 ⇒ 安全与可达性不变；`VoI>0` ⇒ 期望价值改进；`a` 过 NAC ⇒ 社会成本已计入。∎ 推论：**澄清的最坏后果是"没问到点子上"（活性损失），不是"问出危险"**；活性改进依赖 `VoI` 模型，这一依赖是本节最脆弱的假设（E714/E715）。

**引理 147（公告真实性）**
设公告只描述满足 `commit(σ)` 的已认证前缀 `σ`，且承诺窗内若中止则由 SRR 在 `≤` 一个控制周期内发出撤回公告。则在任意执行延续下，人类观察到的公告与机器人的实际已提交行为一致，无"虚假承诺"。证明：前缀不可撤销 ⇒ `σ` 必被执行或触发已声明的中止；撤回在承诺窗内发生 ⇒ 观测无矛盾；公告内容不含未认证后缀（P34）。∎ 推论：**把"说话"降格为"对一个已提交前缀的命名"**，语言层无法通过公告扩权；代价是公告可能"太晚/太保守"（活性损失）。

**引理 148（信任预算的单调记账与修复有界）**
设 `B_{t+1}=clip(B_t − SoftCost(π_t) + Repair_t + Rec_t, 0, 1)`，其中 `Repair_t ≤ SoftCost(event_t) − penalty`，`penalty>0` 固定。则重复同类违规不能全额愈合，`B_trust` 单调记账；且 `B_trust ≥ m_trust` 作为合取门只收缩 `Exec`。证明：修复上界含固定惩罚，几何累积严格递减；门的合取性只移除。∎ 推论：**信任是可耗竭但不可凭空充值的资源**；这使"反复轻微越界"在长期不可持续，而不必为每种软违规设硬阈值。

**引理 149（全层退化与对抗边界）**
若六组件任一失效，按 §3 退化映射回到 v17（再沿链回退）；对任意输入（含提示注入与对抗性人类），每个端口都只是 `Exec_v17` 上的合取过滤器或认证动作选择器，故 `Exec_v18 ⊆ Exec_v17` 恒成立。**负结果**：若把"安全"定义为"满足真实隐藏意图"，则该包含关系不再保证——对手可让观察史与某个假意图一致、同时压低 `r`，使 `i*∉I_t` 而 `I_t` 单元素，从而在"校准良好、规范合规、可读合格"的外观下偏离真意图。证明：前半由过滤器封闭性；后半给出构造：令 `i_fake` 生成与控制集一致的观察、`i_true` 被刻意隐藏，则 `r(o,i_fake)≤q̂`、`r(o,i_true)>q̂`，VIG 判为 `ACT`。∎ 推论：**v18 的保证是"相对于观察可识别的意图"，不是"相对于不可观测的真实意图"**；这条负结果定义了本轮的最大风险，而非可被工程修补的 bug。

## 7. 已知风险与失效模式

1. **共形可交换性被策略性人类打破**：人会依据机器人的提问/公告调整行为，校准集与部署分布不再可交换，覆盖界失效。缓解：ACI/滑动窗、对抗训练、交互随机化、把"被建模"作为协变量。
2. **隐藏/欺骗意图不可识别**：观察可能对假意图一致而对真意图不一致；这是引理 149 的负结果，非 bug。缓解：把"不可逆动作 + 高不确定"组合硬性转为澄清/让渡；对高风险命令要求显式二次确认；限制不可逆动作的权限。
3. **规范本体不完整/文化偏差**：未收录的规范导致"合规但失礼"或"过度保守"。缓解：本体版本化、分文化配置、作用域显式声明、越界让渡、人类审计。
4. **规范模糊导致决策瘫痪**：保守许可交集过窄，系统长期 `DEFER`。缓解：优先级表、可解释的"为何不许可"、允许低风险软违规带信任成本执行、活性监视。
5. **人类模型偏差/谄媚**：`M_h` 若拟合的是"人希望机器人怎么表现"而非"人实际如何推断"，可读性门变成讨好。缓解：多模型集成、行为验证而非问卷、A/B 轮换、人工抽检。
6. **信任预算被游戏**：对手用大量微小软违规耗尽预算或诱导机器人"补偿性冒进"。缓解：单源配额、硬禁忌不可用预算抵扣、审计、修复惩罚固定。
7. **候选召回瓶颈**：LLM 提不出真意图，`ε_cand` 大，覆盖界退化。缓解：多样化提议、检索增强、人在环补候选、候选覆盖率监控。
8. **意图集爆炸**：候选过多导致过度保守。缓解：候选剪枝、按 `V_i` 加权、分层意图（粗到细）、主动澄清。
9. **公告与承诺的竞态**：计划中止与公告撤回在时间上竞争，出现短暂"已承诺未撤回"。缓解：承诺窗 ≥ 撤回延迟、原子化提交/撤回、执行前最后一次证书复核。
10. **澄清问题的隐私/得体风险**：提问本身可能刺探隐私、暴露无知或羞辱。缓解：问题模板过 NAC、最小必要信息、允许"让渡而非追问"。
11. **多层证书叠加过度保守**：v17 证书 ∩ 意图鲁棒 ∩ 规范 ∩ 可读性可能使通过率趋零。缓解：加权而非纯求交（仅硬禁忌求交）、动态 `β/λ_leg`、共享证书族、活性报警。
12. **社会评价主观且难复现**：得体/可读性的人类评分方差大，实验难复现。缓解：预注册评分量表、多评分者一致性、行为指标与主观指标并用、开放数据与脚本。

## 8. 本轮最大风险

**一句话**：CIB 的共形覆盖与 LGM 的人类模型都假设交互样本与真实意图可交换、人不对机器人建模；但真实协作者（尤其带隐藏或策略性意图者）会**根据机器人的信念更新来改变自己的行为**，于是 `i*∈I_t` 的覆盖在自适应/欺骗分布上失效——系统可能在统计上"覆盖良好"、规范作用域内"完全合规"、动作也"可读"，却对一个被刻意隐藏的真实意图造成不可逆伤害，即"置信集校准良好、规范合规、可读性合格，而真实意图从未进入置信集"的对齐缺口（引理 149 负结果）。
