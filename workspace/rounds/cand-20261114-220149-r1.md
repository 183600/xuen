# 第 1 轮（灵感循环第 1 轮；本轮灵感：「预训练」×「任务规划」）

> **继承基线**：状态文件中已有 **ToolGauge**（IP-315–320；定义 416–431；引理 46–50；实验 E426–E440），其下还有 LeanGauge 与 MODGAUGE。本轮不推倒重来：
> ToolGauge 解决的是「**单个**盲区如何被探测、校准、验证、热替换」；本轮补上它刻意留白的**任务层**——
> 在共享预算、共享探测与硬截止期下，**先修哪些盲区、如何合并探测、计划失效后如何重规划**。
> 因此新体系命名为 **PlanGauge**，并保持严格退化链：PlanGauge ⊃ ToolGauge ⊃ LeanGauge ⊃ MODGAUGE。

## 三位一体映射（两词，但三条升级轴）

| 灵感词 | 基线对象 | 升级为 | 一句话动机 |
|---|---|---|---|
| 任务规划 | ToolGauge 的 T-Box：每盲区独立、贪心 β_t = Ĝ_t − c_t | **H-Box + G-Box**：把修复建模为带前置/效果/资源/截止期的分层任务网络与随机调度 | 盲区之间不是孤岛：一次光照扫描/敲击/双目基线可同时服务多个格子，贪心会把共享收益算丢 |
| 预训练 | ToolGauge 的 MP-Φ：只预训练「计量先验」 | **PP-θ + PV-θ**：预训练「计划先验 + 计划价值/时延模型」，摊销全局规划 | 每来一批盲区都从零搜索计划太慢；预训练让「先验计划」可复用，并让计划质量第一次有泛化界 |
| （任务规划的审计侧） | ToolGauge 的语言主张绑定 | **PlanCert + 安全盾 Shield** | 神经规划器会自信地给出不可行计划；计划必须逐条可审计、被安全盾裁剪后才能执行 |

**核心命题**：把 ToolGauge 的「单盲区贪心修复」升级为
「**预训练计划先验 → 分层任务编译 → 预算/截止期调度 → 安全盾裁剪 → 执行监控与有界重规划**」。
PP-θ 只负责**提出**计划与价值估计；数值真值、物理前置、回执与热替换仍由 ToolGauge 独占；
Shield 与 PlanCert 保证即使计划先验错了，也不会产生越界副作用或不可审计的修复。

**不变式保持声明**：
- MODGAUGE 五不变式全部保留；
- 计划证书是主张绑定的**任务级扩展**：计划中的每个修复结论必须引用 ToolGauge 回执；
- 严格退化链延长为 **PlanGauge → ToolGauge（贪心）→ LeanGauge → MODGAUGE**；
- 50Hz 主路径仍不加任何同步规划开销（规划全异步，引理 56）。

## 0. 直觉与动机

### 灵感 1（任务规划 → 从「单盲区贪心」到「全局分层任务」）
直觉：ToolGauge 的 T-Box 用 β_t = Ĝ_t(h) − c_t 决定单次探测值不值，但这是一个**近视**判据：
（i）一次 `illum.sweep` 可能同时降低 5 个相邻格子的光照不确定性，单格看它可能不值，联合看非常值；
（ii）多个盲区共享同一预算 B_tools 与同一截止期 D，先修哪个会改变后面所有盲区的可修性；
（iii）某些修复有前置依赖（先补双目基线才能做跨通道互检；先降温才能做热漂移复测）；
（iv）贪心可能让低价值但高风险的盲区**永久饥饿**，直到过期。
任务规划的语言恰好把这些显式化：**任务 = 名称 + 前置 + 效果 + 资源 + 时延**；
计划 = 任务 DAG + 资源分配 + 时间表；目标 = 在预算与截止期下最大化修复价值。
所以 H-Box 把「修复盲区」编译成分层任务网络，G-Box 在其上做预算/截止期调度，而不是继续在单格上打补丁。

### 灵感 2（预训练 → 计划先验、价值先验与摊销规划）
直觉：即使有了任务规划，在线从零搜索仍然是 NP-hard 的（带资源与时间窗的规划），而且每个新场景都要重来。
预训练的启示是：**计划的「形状」是跨环境可复用的**——哪些工具常组合、哪些盲区类型先修、
哪些共享探测值得合并、计划大约要多久，都可以在海量随机化 episode 上先学出来。
于是 PP-θ 学习计划提议分布，PV-θ 学习计划价值/代价/时延的摊销预测：
部署时只需一次前向 + 少量局部搜索，而不是完整搜索。
但预训练规划器会「自信地计划错误世界」，所以它只拿**提议权**，不拿**执行权**；
执行权归 Shield + ToolGauge，价值估计必须经过 Plan-Cal 共形校准后才能进入选择规则。

### 灵感 3（把第 2 轮的最大风险再往下压一层）
直觉：ToolGauge 的最大风险是 AP-Cal 的摊销先验在分布偏移下产生**跨盲区强相关偏差**。
PlanGauge 的双刃性在于：全局计划会**同时**调度多个修复，一旦计划价值模型系统性高估，
错误会沿计划 DAG 一次性扩散到多个盲区。反过来，正确的全局计划能把「共享探测」变成
对相关偏差的天然对照：同一探测服务多个假设时，若各盲区的回执模式不一致，会立刻暴露先验问题。
因此本轮的设计原则是「**用计划换效率，用盾与证书换安全，用跨格一致性换可证伪性**」。

## 1. 形式化定义（增量：定义 432–448）

**定义 432（修复任务实例 τ）**
τ = (S_bl, {σ_s⁰}_{s∈S_bl}, T₀, B, D, W, E_env)：
S_bl 为当前盲区集合；σ_s⁰ 为格子 s 的后验；T₀ 为 ToolGauge 预注册工具库；
B = (B_tools, B_time, B_energy) 为共享预算向量；D 为修复截止期；W = {w_s} 为格子风险权重；
E_env 为白名单数值环境摘要（定义 429 的扩展）。一个修复计划的效用定义为
V(π) = Σ_{s∈S_bl} w_s·q_s(π)·1[finish_s(π) ≤ D] − λ_R·Risk(π) − λ_C·Cost(π)，
其中 q_s(π)∈[0,1] 是修复后置信度提升（定义 435），Risk 为 PROBING 态物理风险。

**定义 433（分层修复任务网络 HRTN）**
HRTN = (C, P, Pre, Eff, Dur, Cost)，C 为复合任务（Repair(S′)、Diagnose(s)、Probe(T,S′)、Commit(s)…），
P 为原语任务；每个原语 p = (t, args, covers(p), pre_p, post_p, dur_p, cost_p)：
- covers(p) ⊆ S_bl：一次探测可同时影响的盲区集合（共享效应）；
- pre_p / post_p 继承 ToolGauge 的 MTC（定义 416/417）并增加资源与时序前置；
- dur_p / cost_p 为随机时延与代价（带已知上界）。
复合任务按预注册方法分解；未预注册的方法一律拒绝（防止规划器发明不存在的动作）。

**定义 434（计划、时间表与可行性）**
计划 π = (V, E, ρ, start)，V ⊆ P，E 为优先约束，ρ 为执行器/资源分配，start 为开始时间；
π 可行 ⇔
(i) 每个原语通过 TCV（定义 418）；
(ii) 资源不冲突（同一物理执行器同一时刻至多一个动作，允许显式并发集）；
(iii) 时间约束系统 STN(π) 可满足，且 P(finish(π) ≤ D) ≥ 1 − β_D；
(iv) Σ cost_p ≤ B 且 Σ dur_p ≤ B_time；
(v) Shield(π) = π（定义 438）。
记可行计划族为 Π_feas(τ)。

**定义 435（修复价值与共享探测的自适应子模性）**
对已执行探测集合 A，定义 F(A) = Σ_{s} w_s·(1 − σ_s²(A)/σ_s²(∅))，
即相对方差缩减的加权和。假设 A116（正态共轭下的边际递减）：对任意 A⊆A′ 与 p∉A′，
F(A∪{p}) − F(A) ≥ F(A′∪{p}) − F(A′)。
在 A116 下 F 单调自适应子模；若某工具使多个格子同时收缩，其边际收益按覆盖格子的**联合**方差缩减计算，
这正是贪心 β_t 会漏掉的项。

**定义 436（预训练计划先验 PP-θ 与计划价值模型 PV-θ）**
PP_θ : τ ↦ Dist(Π) 输出分层计划提议；PV_θ : (τ,π) ↦ (Q̂, Ĉ, T̂, ŝ) 输出计划价值、代价、时延与不确定度。
预训练分布 D_env 在「材质×光照×干扰×工具代价×盲区模式×截止期」上随机化；
元训练目标：
min_θ E_{τ∼D_env, π∼PP_θ(·|τ)}[ −Q̂_θ(τ,π) + λ_C Ĉ + λ_T max(0,T̂−D) ]
+ β_KL·KL(PP_θ(·|τ) ‖ PP_HTN(·|τ)) + β_C·(Q̂−V(π))²，
其中 PP_HTN 为经典 HRTN 规划器/贪心基线，充当**安全锚**与 KL 先验；
PV-θ 的监督来自离线小规模精确规划与执行回执的反事实重放。
PP-θ 的输入仍是白名单数值与固定枚举（扩展定义 429）。

**定义 437（计划价值共形校准 Plan-Cal）**
预注册校准集 C_plan = {(τ_i, π_i, V_i)}，非一致性分数 e_i = |V_i − Q̂_θ(τ_i,π_i)| / ŝ_θ(τ_i,π_i)；
取 1−α 分位 q_α，部署时计划价值区间 [Q̂ − q_α·ŝ, Q̂ + q_α·ŝ]。
可交换性下 P(V(π) ∈ 区间) ≥ 1−α；分布偏移下用加权共形，覆盖降级为 1−α−2η_plan。
若区间下界 ≤ 0 或宽度 > W_max，则计划进入 fallback（退化到 ToolGauge 贪心）。

**定义 438（安全盾 Shield）**
Shield(π, state) 返回 π 的最长安全前缀 π′：逐条检查 TCV、物理前置、资源、时序、力矩/温度/幅值硬限与
定义 429 输入白名单；任一检查失败即截断并记录 `shield_reject`。安全不变式
I_safe = TCV ∧ Pre_phys ∧ Resource ∧ DeadlineEnvelope ∧ NoFreeTextInPlanner。
对任意 π（含恶意/幻觉计划），Shield(π) ∈ Π_safe；被截断的计划永不补执行剩余动作。

**定义 439（计划证书 PlanCert）**
PlanCert(τ,π) = (selected S′, HRTN 推导树, {receipts_p}, PP-θ 提议哈希, PV-θ 预测, Shield 决策日志, 重规划日志)。
证书中每条「已修复」主张必须引用至少一条有效 ToolGauge 回执；无引用的主张在序列化时剥离（扩展定义 423）。
证书是纯审计产物，不改变数值行为（引理 55）。

**定义 440（执行监控与有界重规划 R-Box）**
监控器比较 PV-θ 预测与实测：价值残差、代价残差、时延残差、后验创新。
任一超过 ε_replan，或新盲区的优先级超过当前计划剩余价值，或收到 Shield 截断 ⇒ 触发重规划。
每个修复 episode 至多 R_max 次重规划；重规划输入为更新后的 τ，仍先经 PP-θ → Plan-Cal → Shield；
重规划预算耗尽 ⇒ 冻结当前安全前缀并退回 ToolGauge 贪心补修（不丢弃已完成的回执）。

**定义 441（公平与饥饿约束）**
设关键盲区集合 C_crit ⊆ S_bl（安全等级 ≥ 阈值的格子），最大等待时间 W_max。
计划 π 满足公平约束 ⇔ C_crit 中每个盲区的首次有效探测开始时间 ≤ W_max，
或计划为 C_crit 预留预算 ≥ ε_B·B_tools。
违反公平约束的计划不进入最终候选；当所有候选都违反时，Shield 强制插入最低成本的关键探测。

**定义 442（预算-截止期可行性证书）**
(B,D,β_D)-可行性证书由 STN 最晚开始时间与资源占用区间组成；
盾在执行前对每个原语复核最坏时延上界，若剩余预算不足以完成剩余关键任务，则提前截断并触发恢复。
这是 ToolGauge 的 TB-Contract（定义 424）在**多盲区计划层**的细化。

**定义 443（PlanGauge 退化链与降级算子）**
降级顺序：PlanGauge → ToolGauge 贪心 → LeanGauge → MODGAUGE。
触发条件：PP-θ 不可用/超时、Plan-Cal 区间无效、Shield 连续拒绝、重规划耗尽、任务实例超出预注册 schema。
降级算子 D(·) 只允许**减少**动作集合与语言主张，不允许新增未验证动作；每次降级写入 PlanCert。

**定义 444（任务级预训练-部署偏移）**
η_task = sup_τ TV(D_dep(τ), D_env(τ))，在盲区模式、工具代价、材质与截止期四个边缘上分别估计并取最大；
η_task 进入风险账本，并作为引理 51/57 中不可消除项的实测输入。

**定义 445（计划选择规则）**
在候选计划集 {π_j} 上选择
π* = argmax_j LCB_j = Q̂_j − q_α·ŝ_j
s.t. π_j ∈ Π_feas(τ) ∧ 公平约束(π_j)，
并以「单位时间价值」打破平局。若所有 LCB_j ≤ 0，则不执行任何修复，返回 ToolGauge 贪心候选。
这是风险厌恶的「下置信界规划」，与定义 437 的共形区间严格对应。

**定义 446（共享探测的合并条件）**
merge(p₁,…,p_k) 合法 ⇔ 物理前置兼容 ∧ 执行器不冲突 ∧ covers 并集非空 ∧
合并后的激励在任一格子的安全包络内；合并收益 Δ = F(∪covers) − Σ F(covers_i)（可正可负）。
仅当 Δ > c_merge − Σ c_i 且 Shield 通过时才合并。

**定义 447（计划级攻击面与输入白名单）**
PlanGauge 的计划器只接收数值张量与枚举 schema；禁止自由文本、二维码、OCR 结果进入 PP-θ 上下文。
计划证书的每条主张绑定回执，Shield 独立复核物理前置；因此计划注入攻击需同时伪造
PP-θ 输入、计划结构、回执签名、物理前置与证书引用五层。

**定义 448（继承与退化特例）**
未重定义的记号沿用定义 398–431。令 |S_bl|=1、PP-θ=贪心、R_max=0、Shield=TCV，
则 PlanGauge 严格退化为 ToolGauge；再令 VLA=∅、T₀={被动观测}、MP-Φ=物理先验则退化为 LeanGauge。

## 2. 关键算法骨架

```python
# IP-321 H-Box：把盲区集合编译为分层修复任务网络
class HBox:
    def compile(self, tau):
        goals = [Repair(s) for s in tau.S_bl if tau.w[s] >= tau.w_min]
        methods = self.registry.match(goals, tau)       # 仅预注册方法
        return HRTN(goals, methods, tools=tau.T0)       # 共享 covers/前置/效果

# IP-322 P-Plan：预训练计划先验 + 计划价值模型
class PlanPrior:
    def propose(self, tau, k=8):
        feats = featurize_num(tau)                      # 白名单数值（定义 447）
        plans = self.pp_theta.sample(feats, k=k)        # 摊销提议
        vals  = [self.pv_theta(feats, p) for p in plans] # (Q̂, Ĉ, T̂, ŝ)
        return plans, vals

# IP-323 S-Box：共形校准 + LCB 选择 + 调度
class SBox:
    def select(self, tau, plans, vals):
        cands = []
        for p, (Q, C, T, s) in zip(plans, vals):
            lo, hi = self.plan_cal.interval(Q, s)       # 定义 437
            if lo <= 0 or (hi - lo) > self.W_max: continue
            if not feasible(p, tau) or not fair(p, tau): continue
            cands.append((lo, p))
        if not cands:
            return self.toolgauge_greedy(tau)           # 退化
        return max(cands, key=lambda z: z[0] / unit_time(z[1]))[1]

# IP-324 R-Box：执行监控与有界重规划
class RBox:
    def monitor(self, plan, receipts, tau):
        dev = max(value_residual(plan, receipts),
                  cost_residual(plan, receipts),
                  duration_residual(plan, receipts))
        if dev > self.eps_replan or new_critical_blind_spot(tau):
            if self.replans_left > 0:
                self.replans_left -= 1
                return self.replan(tau.with_receipts(receipts))
        return plan.safe_prefix(receipts)

# IP-325 PlanGauge 主闭环：计划 → 盾 → ToolGauge 原语执行 → 重规划
def plaingauge_episode(M, tau):
    hrtn    = M.hbox.compile(tau)                       # 任务层
    plans, vals = M.plan_prior.propose(tau)             # 预训练提议
    plan    = M.sbox.select(tau, plans, vals)           # 共形 LCB + 调度
    plan    = M.shield.apply(plan, M.state)             # 安全盾裁剪
    while plan.pending():
        p = plan.next_ready()
        if not M.shield.recheck(p, M.state):            # 执行前复核
            plan = M.rbox.replan(tau)                   # 有界重规划
            plan = M.shield.apply(plan, M.state)
            continue
        ok = toolgauge_6c(M, p.targets)                 # 原语仍是 6C
        plan.commit(p, ok)
    cert = PlanCert(tau, plan, M.receipts, M.shield.log, M.rbox.log)
    M.plan_cert_store.append(cert)                      # 定义 439
    return cert

# IP-326 与既有主闭环的集成：50Hz 路径零同步规划
def PlanGauge_round(M, obs, audio, tac, depth, det):
    if not M.inflight_plan:                             # 异步、至多一个在飞计划
        tau = M.dbox.snapshot_tasks()
        if tau.S_bl:
            M.inflight_plan = submit_async(plaingauge_episode, M, tau)
    return ToolGauge_round(M, obs, audio, tac, depth, det)  # 原 50Hz 路径不变
```

## 3. 推导

**引理 51（计划先验的元泛化界）**
在 D_env 上预训练 M 个任务、部署 τ∼D_dep 且 η_task = sup TV(D_dep,D_env)，
计划族复杂度 C(Π)、上下文回执数 N_ctx，则
R̄(PP_θ) − R̄(π*) ≤ 2η_task + O(√((C(Π)+log(1/δ))/M)) + O(√((d_ctx+log(1/δ))/N_ctx)) + ε_approx，
其中 ε_approx 为 PP-θ 提议分布对最优计划的覆盖误差。
证明思路：元级 PAC-Bayes（先验=PP_HTN 经典规划器）给前两项；任务内 Bernstein 给第三项；
ε_approx 由「预注册方法库 + 局部搜索」控制。系：M→∞ 时 N_ctx 可很小，但 η_task 不可消除，必须由 E443 实测。

**引理 52（共享探测的贪心近似与截止期代价）**
若 A116 成立、预算为基数约束（每工具单位代价），自适应贪心选择最大边际 F 的计划达到 (1−1/e) 最优；
一般背包预算下，简单贪心给 (1−1/e)/2 的保守下界，离线枚举 + 贪心可恢复 (1−1/e)。
加入截止期 D 后，任何满足 STN 可行性证书的计划在 Shield 下不超期；
若最优计划因截止期被截断，则损失 ≤ 被截断任务的边际价值之和（由定义 442 的最坏时延上界控制）。

**引理 53（安全盾的保守性）**
对任意 π（包括对抗性/幻觉计划），Shield(π) ∈ Π_safe；
Shield 只会删除动作、提前结束或触发降级，不会新增未校验动作；
因此 PlanGauge 的所有物理副作用都是 ToolGauge 可接受的副作用，I_safe 与 MODGAUGE 五不变式保持。

**引理 54（有界重规划的遗憾）**
设每次原语执行的价值/时延偏差 ≤ δ，重规划次数 ≤ R_max，规划器在更新上下文后相对最优的额外损失 ≤ ε_replan，
则相对于「事先知道全部偏差的全知计划」，PlanGauge 的累计遗憾 ≤ O(R_max·(δ + ε_replan)) + L_max·δ。
系：δ→0 且 R_max 足够时，重规划收益趋近全知计划；R_max 用尽 ⇒ 冻结安全前缀，安全不退化。

**引理 55（计划证书不进入数值路径）**
PlanCert 仅引用 receipts 与哈希，不修改任何后验、契约或热替换决策；
证书剥离是纯投影，故子图数值等价性与 ToolGauge 引理 49 相同；审计开销不影响 50Hz 路径。

**引理 56（时序与严格退化）**
所有规划/校准/重规划位于 50Hz 路径之外，至多一个在飞计划；50Hz 周期新增仅计划状态查询 O(1) < 0.05ms。
当 PP-θ 不可用或 Plan-Cal 无效时，S-Box 直接返回 ToolGauge 贪心，后者再按既有链退化到 LeanGauge/MODGAUGE；
每一步降级只减少动作集合 ⇒ 硬实时（引理 45）与预算不变式保持。

**引理 57（Plan-Cal 覆盖与漂移）**
可交换性下 P(V(π)∈[Q̂±q_αŝ]) ≥ 1−α；
任务级 TV 偏移 η_plan 下覆盖 ≥ 1−α−2η_plan；加权共形可恢复至 1−α−η_plan·L′。
系：α=0.1、η_plan≤0.05 ⇒ 覆盖 ≥ 0.8；低于 SLA 时所有候选计划进入 fallback（定义 445）。

## 6. 本轮最大风险（一句话）

**一句话**：预训练规划器可能把「跨盲区共享探测」的收益系统性高估，在分布外环境生成**看似高效、实则前置/时序不可行**的全局计划，使多个本可独立局部修复的盲区被同一错误计划一起拖过截止期——全局优化把 ToolGauge 的局部风险放大成计划级的系统性风险。

**次级风险与缓解**：计划器幻觉 → Shield + 白名单 + PlanCert；Plan-Cal 漂移 → 加权共形 + fallback；共享探测物理冲突 → merge 前置与 PROBING 态；重规划震荡 → R_max + 冻结前缀；预训练偏差 → 经典 HTN 规划器作 KL 锚 + 跨格残差监控。

## 3. 关键算法骨架

```python
class HBox:
    def compile(self, tau):
        goals = [Repair(s) for s in tau.S_bl if tau.w[s] >= tau.w_min]
        return HRTN(goals, self.registry.match(goals, tau), tools=tau.T0)

class PlanPrior:
    def propose(self, tau, k=8):
        f = featurize_num(tau)                 # 白名单数值
        ps = self.pp_theta.sample(f, k=k)
        return ps, [self.pv_theta(f, p) for p in ps]

class SBox:
    def select(self, tau, plans, vals):
        cands = []
        for p, (Q, C, T, s) in zip(plans, vals):
            lo, hi = self.plan_cal.interval(Q, s)      # 定义 437
            if lo <= 0 or hi - lo > self.W_max: continue
            if not feasible(p, tau) or not fair(p, tau): continue
            cands.append((lo, p))
        if not cands: return self.toolgauge_greedy(tau)
        return max(cands, key=lambda z: z[0] / unit_time(z[1]))[1]

class RBox:
    def monitor(self, plan, receipts, tau):
        dev = max(value_residual(plan, receipts),
                  cost_residual(plan, receipts),
                  duration_residual(plan, receipts))
        if (dev > self.eps_replan or new_critical(tau)) and self.replans_left:
            self.replans_left -= 1
            return self.replan(tau.with_receipts(receipts))
        return plan.safe_prefix(receipts)

def plaingauge_episode(M, tau):
    plans, vals = M.plan_prior.propose(tau)
    plan = M.sbox.select(tau, plans, vals)
    plan = M.shield.apply(plan, M.state)
    while plan.pending():
        p = plan.next_ready()
        if not M.shield.recheck(p, M.state):
            plan = M.shield.apply(M.rbox.replan(tau), M.state); continue
        plan.commit(p, toolgauge_6c(M, p.targets))     # 原语仍是 6C
    cert = PlanCert(tau, plan, M.receipts, M.shield.log, M.rbox.log)
    M.plan_cert_store.append(cert)

def PlanGauge_round(M, obs, audio, tac, depth, det):
    if not M.inflight_plan:
        tau = M.dbox.snapshot_tasks()
        if tau.S_bl: M.inflight_plan = submit_async(plaingauge_episode, M, tau)
    return ToolGauge_round(M, obs, audio, tac, depth, det)  # 50Hz 不变
```

## 4. 推导

**引理 51（计划先验元泛化界）** 超额遗憾 ≤ 2η_task + O(√((C(Π)+log(1/δ))/M)) + O(√((d_ctx+log(1/δ))/N_ctx)) + ε_approx；
元级 PAC-Bayes + 任务内 Bernstein + 预注册方法库控制 ε_approx。系：M→∞ 时 N_ctx 可小，但 η_task 不可消除，由 E443 实测。
**引理 52（共享探测贪心）** A116 下单位代价贪心 (1−1/e)；一般背包简单贪心 (1−1/e)/2，离线枚举+贪心可恢复 (1−1/e)；
截止期损失由 STN 可行性证书与最坏时延上界控制。
**引理 53（盾保守性）** Shield(π) ∈ Π_safe，只删不加；所有物理副作用仍是 ToolGauge 可接受的副作用。
**引理 54（有界重规划遗憾）** ≤ O(R_max·(δ+ε_replan)) + L_max·δ；R_max 耗尽 ⇒ 冻结安全前缀，安全不退化。
**引理 55（证书不进入数值路径）** 证书只引用回执与哈希，剥离为纯投影；子图等价性同 ToolGauge 引理 49。
**引理 56（时序与退化）** 规划全异步、至多一个在飞；50Hz 新增 <0.05ms；降级只减动作，硬实时与预算不变式保持。
**引理 57（Plan-Cal 漂移）** 可交换下覆盖 ≥1−α；TV=η_plan 下 ≥1−α−2η_plan；加权共形可恢复至 1−α−η_plan·L′；SLA<0.8 ⇒ fallback。

## 8. 本轮最大风险

**一句话**：预训练规划器可能系统性高估「跨盲区共享探测」的收益，在分布外环境生成看似高效但前置/时序不可行的全局计划，
让多个本可独立局部修复的盲区被同一错误计划一起拖过截止期，把 ToolGauge 的局部风险放大为计划级系统性风险；
以 Shield、Plan-Cal 下置信界、PlanCert、R-Box 有界重规划与「PlanGauge→ToolGauge」严格退化链五重兜底，
并用 E441–E456 证伪。
