# 第 61 轮（承接第 60 轮「场景感知闭环」IP-153~160；灵感循环第 7 轮；本轮灵感：「仿真训练」×「机械臂」）

> 第 60 轮把执行层升级为「认知驱动的场景-执行闭环」：SSM 场景-阻抗先验、CIEC 意图约束锁定、EPIR ROS 因果隔离、SERC 闭环、PCE++++ 认知预算、SIC 三元校验。但**三个更深层的局限**仍未触及：
> 1. **先验没有「工厂」**：π_scene(K|z) 的来源要么手工设定，要么靠少量在线遥测估计；面对长尾场景（透明杯、软布、湿滑瓷砖），真实数据稀缺且昂贵。**仿真本应是先验的规模化工厂**，但 sim-to-real gap 未被度量，直接注入等于把「仿真里的自信」误当成「现实里的正确」。
> 2. **证据只验完整性、不验来源**：第 60 轮 EPIR 用 seq_id+hash 保证 EV-exec 不丢不乱，却**无法区分一条 EV-exec 到底来自真实机械臂还是仿真回放**。一旦数字孪生/仿真训练复用同一条 ROS 证据通道，仿真证据可能「洗白」为真实执行证据——证据链自洽但与现实脱钩。
> 3. **机械臂的物理结构未被当作迁移桥梁**：机械臂的运动学（连杆长度、关节限位）、惯性（质量、质心、转动惯量）、重力向量在 sim 与 real 之间高度一致；而接触刚度、摩擦、阻尼高度不一致。现有方案对所有参数一视同仁地「迁移」，既浪费了锚点的可迁移性，又放大了接触参数的危险性。

## 0. 直觉与动机

**灵感 1（仿真训练 → 数字孪生先验库 DTR）**
直觉：仿真不是「替代现实」，而是「先验工厂」——它能在真实数据到来之前，以极低成本生成大量「如果……会怎样」的反事实经验。把仿真产物（策略、阻抗先验、失效模式）连同**完整的来源元数据**（仿真器版本、资产、随机化种子、轨迹数、覆盖区域）一起入库，形成可追溯的数字孪生先验库。关键洞见：**先验的可信度不是一个标量，而是「保真度×覆盖度×校准度」的乘积**；没有元数据的仿真先验不可注入。

**灵感 2（sim-to-real → 残差分解与可辨识校准 GRC）**
直觉：sim 与 real 的差 Δθ 里混着三样东西——**系统性偏差**（可辨识、可校准，如电机实际阻尼比标称大 8%）、**尺度错配**（模型结构错，如把柔顺接触当刚体）、**不可约噪声**（接触微滑、传感噪声）。把三者混在一起校准，就会「把噪声当偏差拟合」，越校准越自信、越自信越危险。关键洞见：**只在 Fisher 信息可辨识的子空间里校正偏差，在不可辨识的方向上主动膨胀方差**——承认不知道，比假装知道更安全。

**灵感 3（机械臂 → 物理锚点 MAG）**
直觉：机械臂有一组「sim-real 天然一致」的量：连杆长度 l、质量 m、质心、转动惯量 I、关节限位 q_min/q_max、重力 g。它们是**迁移锚点**；接触参数 (K_c, μ, c, 接触几何) 是**迁移风险源**。先把 sim 与 real 在锚点上对齐（若锚点都对不上，说明 CAD/装配/标定错了，直接拒绝迁移），再只在锚点归一化坐标里迁移非锚点参数。关键洞见：**锚点不仅提供坐标，还提供「迁移准入证」**。

**灵感 4（合流 → 仿真-现实接地闭环 SRL+）**
直觉：DTR 提供先验 → GRC 校准偏差、膨胀未知 → SRT 给出可信度并门控注入 → EEIS/SSM 在真实安全域内收窄 K_safe → 机械臂执行 → EV-exec 回传 → 更新 τ_sim → 决定是否需要「定向重仿真」。闭环把「仿真训练」从一个一次性离线阶段，变成**在线、可证伪、按预算调度的先验供给回路**。

**灵感 5（证据 → 来源分型证据 PTE）**
直觉：第 60 轮的 EV-exec 只回答「有没有丢、顺序对不对」，不回答「它是不是真的」。给每条证据打上**来源类型**（sim / real / hybrid）和来源哈希，并规定「安全关键结论必须由 real 根路径覆盖」。关键洞见：**仿真证据可以当先验，但不能当证书**——这是仿真训练时代证据链的第一性约束。

**灵感 6（预算 → PCE+++++ 六维）**
直觉：在原有 B_scene/B_intent/B_ros/B_exec 之外，增加 B_sim（仿真算力/轨迹预算）与 B_calib（真机校准预算）。关键不变式：**B_calib = 0 ⇒ 所有仿真先验权重 w = 0**——没有校准预算，就没有仿真信任；防止「只仿真、不校准」的自嗨式闭环。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（数字孪生先验库 DTR）** DTR = (Θ_sim, Π_sim, P_prov, M_cov)。其中：
- **Θ_sim**：仿真物理参数空间（含 m, I, l, g, q_lim, K_c, μ, c）
- **Π_sim**：仿真训练得到的先验集合（阻抗先验 π_scene^sim、策略、失效模式）
- **P_prov**：来源元数据 P_prov = (sim_version, asset_id, seed, n_rollout, date, hash)
- **M_cov**：覆盖图 M_cov: Z_scene × Θ → [0,1]，度量真实工作域被随机化分布覆盖的密度
- **入库准入**：π 可注入 ⇔ P_prov 完整 ∧ M_cov(π) ≥ τ_cov。

**定义 162（仿真-现实残差分解 GRC）** 对参数 θ ∈ Θ，令 Δθ = θ_real − θ_sim。分解为
Δθ = U_id·δ_b + U_perp·δ_s + ε,  ε ~ N(0, Σ_noise)
其中 U_id 为 Fisher 信息 F = Jᵀ Σ_noise⁻¹ J 中 λ_i > λ_th 的可辨识子空间，U_perp 为其正交补；δ_b 为可辨识系统偏差，δ_s 为不可辨识尺度错配，ε 为不可约噪声。
- **修正先验**：μ_corr = μ_sim + U_id·δ̂_b；Σ_corr = Σ_sim + U_perp·Σ_unid·U_perpᵀ（在不可辨识方向主动膨胀方差）
- **噪声地板拒绝**：若 ‖δ̂_b‖ < k·√(tr Σ_noise)（k=2），拒绝本次校正，保持原先验并下调 τ_cal。

**定义 163（仿真可信度门控 SRT）** 可信度
τ_sim(z, θ) = τ_fid(z) · τ_cov(z, θ) · τ_cal(θ)
其中 τ_fid 为模型验证分（sim vs real 轨迹回放误差），τ_cov = M_cov(z,θ)，τ_cal = exp(−½·tr(Σ_post)/σ_ref²)。
- **注入权重**：w(z,θ) = w_max · τ_sim(z,θ)，w_max ∈ (0,1)（如 0.8），**硬安全约束永远 w_hard = 0**。
- **安全域包含**：K_safe = K_safe^real ∩ {K : d(K, μ_corr(z)) ≤ β·√(diag Σ_corr)}，保证 K_safe ⊆ K_safe^real。

**定义 164（机械臂物理锚点 MAG）** 锚点集 A = (m, I, l, g, q_min, q_max, τ_max)，非锚点集 N = (K_c, μ, c, contact_geom)。
- **锚点残差**：r_A = ‖(θ_real − θ_sim)|_A‖ / ‖θ_sim|_A‖
- **迁移准入**：r_A ≤ ε_A 才允许迁移；否则拒绝仿真先验并触发「模型/装配核对」。
- **锚点归一化迁移**：θ̃ = θ / φ(anchor)，在 θ̃ 空间迁移非锚点参数，减少跨场景/跨平台维度。

**定义 165（仿真-现实接地闭环 SRL+）** 算子 SRL+(M, z, θ, B)：
```
① DTR.retrieve(z) → (π_scene^sim, P_prov, M_cov)
② GRC.calibrate(real_probe, θ_sim) → (δ̂_b, Σ_corr, 可辨识掩码)
③ SRT.trust(z, θ) → τ_sim；w ← w_max·τ_sim
④ MAG.check(r_A) → 准入 / 拒绝
⑤ EEIS.compile_with_sim_prior(π_scene^corr, w, K_safe^real) → K_safe
⑥ 机械臂执行 → EV-exec(provenance=real) → EPIR
⑦ 更新 τ_fid/τ_cal → 若 Δτ_sim < −θ_re 触发定向重仿真 ASP.reschedule
⑧ 返回 (K_safe, τ_sim, Cert_s2r, provenance)
```

**定义 166（主动仿真调度 ASP）** 选择下一仿真实验 e*：
e* = argmax_e [ E[ΔH(K_safe | e)] / cost_sim(e) ]，受 B_sim 约束；
优先在**决策边界附近**且**高可辨识方向**采样（把仿真预算花在会改变 K_safe 选择的地方，而不是均匀随机化）。

**定义 167（来源分型证据 PTE）** 证据节点 E = (content, prov ∈ {sim, real, hybrid}, τ_sim, seq_id, hash)。证据图 G_E 的边遵循来源传播规则：
- real → real 合法；sim → real 非法（类型不匹配）；hybrid 需融合证书 Cert_fuse。
- **真实可证性谓词** Cert_real(claim) = true ⇔ claim 的所有安全关键参数都被一条 real 根、无 sim 中间节点的路径覆盖。
- **污染检测**：若标为 real 的节点 hash 命中 DTR 仿真回放注册表，则隔离并标记 provenance_contaminated。

**定义 168（六维预算 PCE+++++）** B = (B_sim, B_calib, B_scene, B_intent, B_ros, B_exec)。
- B_sim：仿真轨迹数 / 并行 worker / 渲染预算
- B_calib：真机校准试验数、标定时间
- **安全不变式**：B_calib = 0 ⇒ ∀w = 0（无校准不信任）
- 分配律：B_calib 为**不可挪用保留区**；B_sim 优先由 ASP 在决策边界消耗；其余沿用第 60 轮降级策略。

### IP-161 DTR（数字孪生先验库）

```python
class DigitalTwinRepository:
    def __init__(self):
        self.priors = {}
        self.provenance = {}
        self.coverage = {}

    def register(self, scene, prior, prov, cov):
        need = ("sim_version", "asset_id", "seed", "n_rollout", "hash")
        if not all(k in prov for k in need):
            raise ValueError("incomplete provenance: reject")
        if cov < TAU_COV:
            raise ValueError("coverage too low: reject")
        self.priors[scene] = prior
        self.provenance[scene] = prov
        self.coverage[scene] = cov

    def retrieve(self, scene):
        return (self.priors.get(scene),
                self.provenance.get(scene),
                self.coverage.get(scene, 0.0))
```

### IP-162 GRC（残差分解与可辨识校准）

```python
def gap_residual_calibration(theta_sim, theta_real, J, Sigma_noise,
                             lam_th=1e-2, k=2.0):
    F = J.T @ np.linalg.inv(Sigma_noise) @ J
    lam, U = np.linalg.eigh(F)
    id_mask = lam > lam_th
    U_id, U_perp = U[:, id_mask], U[:, ~id_mask]

    dtheta = theta_real - theta_sim
    delta_b = U_id.T @ dtheta
    noise_floor = k * np.sqrt(np.trace(Sigma_noise))
    if np.linalg.norm(delta_b) < noise_floor:
        return theta_sim, Sigma_noise, {
            "calibrated": False, "reason": "below_noise_floor"}

    mu_corr = theta_sim + U_id @ delta_b
    # inflate uncertainty only on the unidentifiable directions
    Sigma_corr = (Sigma_noise
                  + U_perp @ (U_perp.T @ Sigma_noise @ U_perp) @ U_perp.T)
    return mu_corr, Sigma_corr, {
        "calibrated": True, "U_id": U_id, "mask": id_mask}
```

### IP-163 SRT（可信度门控注入）

```python
def sim_trust(theta, tau_fid, cov, Sigma_post, sigma_ref=1.0):
    tau_cal = np.exp(-0.5 * np.trace(Sigma_post) / sigma_ref**2)
    return float(np.clip(tau_fid * cov * tau_cal, 0.0, 1.0))

def inject_sim_prior(K_safe_real, mu_corr, Sigma_corr, tau,
                     w_max=0.8, beta=2.0):
    w = w_max * tau
    if w <= 0:
        return K_safe_real, 0.0
    radius = beta * np.sqrt(np.diag(Sigma_corr))
    K_prior = [K for K in K_safe_real
               if np.all(np.abs(np.asarray(K) - mu_corr) <= radius)]
    # prior may only NARROW inside the real-safe set, never expand it
    return (K_prior if K_prior else K_safe_real), w
```

### IP-164 MAG（机械臂物理锚点）

```python
def anchor_admission(theta_sim, theta_real, anchor_idx, eps_A=0.05):
    a_sim = np.asarray(theta_sim)[anchor_idx]
    a_real = np.asarray(theta_real)[anchor_idx]
    r_A = np.linalg.norm(a_real - a_sim) / max(np.linalg.norm(a_sim), 1e-9)
    return r_A <= eps_A, r_A   # False => reject transfer, audit CAD/assembly
```

### IP-165 SRL+（仿真-现实接地闭环）

```python
def sim_real_grounding_loop(M, scene, theta_sim, budget):
    pi_sim, prov, cov = M.dtr.retrieve(scene)
    if pi_sim is None or budget.B_calib <= 0:
        return M, None, {"trust": 0.0, "mode": "no_sim_prior"}

    theta_real = M.calib_probe(budget)
    budget.B_calib -= 1
    mu_corr, Sigma_corr, info = gap_residual_calibration(
        theta_sim, theta_real, M.J, M.Sigma_noise)

    ok, r_A = anchor_admission(theta_sim, theta_real, M.anchor_idx)
    if not ok:
        return M, None, {"trust": 0.0, "mode": "anchor_reject", "r_A": r_A}

    tau = sim_trust(theta_sim, M.tau_fid[scene], cov, Sigma_corr)
    K_safe, w = inject_sim_prior(M.K_safe_real, mu_corr, Sigma_corr, tau)

    M, ev = M.execute(K_safe, provenance="real")
    M.epir.append(ev)
    M.update_trust(scene, ev)              # online tau_fid / tau_cal update
    if M.trust_drop(scene) > THETA_RE:
        budget.B_sim -= M.asp.reschedule(scene, K_safe, budget.B_sim)

    return M, K_safe, {"trust": tau, "w": w, "r_A": r_A, "ev": ev}
```

### IP-166 ASP（主动仿真调度）

```python
def active_sim_plan(candidates, budget_sim):
    best, best_score = None, -1.0
    for e in candidates:
        gain = expected_entropy_drop(e, near_decision_boundary=True)
        score = gain / max(e.cost, 1e-6)
        if e.cost <= budget_sim and score > best_score:
            best, best_score = e, score
    return best
```

### IP-167 PTE（来源分型证据）

```python
def cert_real(claim, graph):
    for p in graph.paths_to(claim):
        if any(n.prov != "real" for n in p):
            continue
        covered = union(n.params for n in p)
        if claim.safety_critical_params <= covered:
            return True
    return False   # sim evidence may inform, never certify

def detect_contamination(node, dtr_registry):
    return node.prov == "real" and node.hash in dtr_registry
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 保证 |
|---|---|---|---|
| DTR | O(1) retrieve | O(N_scene) | 无元数据/低覆盖先验拒绝入库 |
| GRC | O(d³) 特征分解 / 次校准 | O(d²) | 仅可辨识子空间校正；噪声地板拒绝 |
| SRT | O(1) | O(d) | w ≤ w_max < 1；K_safe ⊆ K_safe^real |
| MAG | O(d_A) | O(d_A) | 锚点残差 > ε_A 拒绝迁移 |
| SRL+ | O(闭环) | 复用 | 无校准预算 ⇒ 仿真权重为 0 |
| ASP | O(|候选|·d) | O(|候选|) | 预算内最大化决策边界信息增益 |
| PTE | O(V+E)（单调来源格） | O(V+E) | 安全关键结论必须 real 根路径 |

**正确性定理（SRG）**：假设 A66–A71 成立：
**(A66)** DTR 来源元数据完整；**(A67)** GRC 可辨识子空间与噪声地板条件满足；**(A68)** SRT 满足 w ≤ w_max < 1 且硬约束仅来自 real；**(A69)** MAG 锚点残差 ≤ ε_A；**(A70)** PTE 来源类型不可伪造且污染检测开启；**(A71)** 六维预算单调消耗。
则：
1. **安全不退化**：注入仿真先验后 K_safe ⊆ K_safe^real，故任何硬安全约束违反次数不高于无仿真先验基线。
2. **可辨识校正收益**：在 U_id 方向，E[‖K_safe* − K_safe^real‖²] 至少下降 1 − (1−w)²；不可辨识方向方差被单调膨胀而非虚假收窄。
3. **证据可证性**：Cert_real(claim) 成立 ⇔ 存在 real 根覆盖路径；仿真证据无法单独认证任何安全关键 claim；污染节点被隔离。
4. **预算安全**：B_calib = 0 ⇒ 所有仿真先验权重为 0，系统退化为第 60 轮纯真实闭环。

## 5. 本轮最大风险

**一句话**：若仿真回放与真实 EV-exec 共用同一哈希/序列号命名空间，一次「仿真证据洗白」就能让证据链在数值与顺序上完全自洽、却在来源上彻底脱离现实——系统会自信地为一台从未真实执行的机械臂签发合规证书；因此必须以「来源分型 + 独立命名空间 + DTR 注册表污染检测 + 无校准不信任（B_calib=0 ⇒ w=0）」四重护栏，确保仿真只能当先验、永远不能当证书。

### IP-161 DTR（数字孪生先验库）

```python
class DigitalTwinRepository:
    def __init__(self):
        self.priors = {}
        self.provenance = {}
        self.coverage = {}

    def register(self, scene, prior, prov, cov):
        need = ("sim_version", "asset_id", "seed", "n_rollout", "hash")
        if not all(k in prov for k in need):
            raise ValueError("incomplete provenance: reject")
        if cov < TAU_COV:
            raise ValueError("coverage too low: reject")
        self.priors[scene] = prior
        self.provenance[scene] = prov
        self.coverage[scene] = cov

    def retrieve(self, scene):
        return (self.priors.get(scene),
                self.provenance.get(scene),
                self.coverage.get(scene, 0.0))
```

### IP-162 GRC（残差分解与可辨识校准）

```python
def gap_residual_calibration(theta_sim, theta_real, J, Sigma_noise,
                             lam_th=1e-2, k=2.0):
    F = J.T @ np.linalg.inv(Sigma_noise) @ J
    lam, U = np.linalg.eigh(F)
    id_mask = lam > lam_th
    U_id, U_perp = U[:, id_mask], U[:, ~id_mask]

    dtheta = theta_real - theta_sim
    delta_b = U_id.T @ dtheta
    noise_floor = k * np.sqrt(np.trace(Sigma_noise))
    if np.linalg.norm(delta_b) < noise_floor:
        return theta_sim, Sigma_noise, {
            "calibrated": False, "reason": "below_noise_floor"}

    mu_corr = theta_sim + U_id @ delta_b
    Sigma_corr = (Sigma_noise
                  + U_perp @ (U_perp.T @ Sigma_noise @ U_perp) @ U_perp.T)
    return mu_corr, Sigma_corr, {
        "calibrated": True, "U_id": U_id, "mask": id_mask}
```

### IP-163 SRT（可信度门控注入）

```python
def sim_trust(theta, tau_fid, cov, Sigma_post, sigma_ref=1.0):
    tau_cal = np.exp(-0.5 * np.trace(Sigma_post) / sigma_ref**2)
    return float(np.clip(tau_fid * cov * tau_cal, 0.0, 1.0))

def inject_sim_prior(K_safe_real, mu_corr, Sigma_corr, tau,
                     w_max=0.8, beta=2.0):
    w = w_max * tau
    if w <= 0:
        return K_safe_real, 0.0
    radius = beta * np.sqrt(np.diag(Sigma_corr))
    K_prior = [K for K in K_safe_real
               if np.all(np.abs(np.asarray(K) - mu_corr) <= radius)]
    # prior may only NARROW inside the real-safe set, never expand it
    return (K_prior if K_prior else K_safe_real), w
```

### IP-164 MAG（机械臂物理锚点）

```python
def anchor_admission(theta_sim, theta_real, anchor_idx, eps_A=0.05):
    a_sim = np.asarray(theta_sim)[anchor_idx]
    a_real = np.asarray(theta_real)[anchor_idx]
    r_A = np.linalg.norm(a_real - a_sim) / max(np.linalg.norm(a_sim), 1e-9)
    return r_A <= eps_A, r_A   # False => reject transfer, audit CAD/assembly
```

### IP-165 SRL+（仿真-现实接地闭环）

```python
def sim_real_grounding_loop(M, scene, theta_sim, budget):
    pi_sim, prov, cov = M.dtr.retrieve(scene)
    if pi_sim is None or budget.B_calib <= 0:
        return M, None, {"trust": 0.0, "mode": "no_sim_prior"}

    theta_real = M.calib_probe(budget)
    budget.B_calib -= 1
    mu_corr, Sigma_corr, info = gap_residual_calibration(
        theta_sim, theta_real, M.J, M.Sigma_noise)

    ok, r_A = anchor_admission(theta_sim, theta_real, M.anchor_idx)
    if not ok:
        return M, None, {"trust": 0.0, "mode": "anchor_reject", "r_A": r_A}

    tau = sim_trust(theta_sim, M.tau_fid[scene], cov, Sigma_corr)
    K_safe, w = inject_sim_prior(M.K_safe_real, mu_corr, Sigma_corr, tau)

    M, ev = M.execute(K_safe, provenance="real")
    M.epir.append(ev)
    M.update_trust(scene, ev)              # online tau_fid / tau_cal update
    if M.trust_drop(scene) > THETA_RE:
        budget.B_sim -= M.asp.reschedule(scene, K_safe, budget.B_sim)

    return M, K_safe, {"trust": tau, "w": w, "r_A": r_A, "ev": ev}
```

### IP-166 ASP（主动仿真调度）

```python
def active_sim_plan(candidates, budget_sim):
    best, best_score = None, -1.0
    for e in candidates:
        gain = expected_entropy_drop(e, near_decision_boundary=True)
        score = gain / max(e.cost, 1e-6)
        if e.cost <= budget_sim and score > best_score:
            best, best_score = e, score
    return best
```

### IP-167 PTE（来源分型证据）

```python
def cert_real(claim, graph):
    for p in graph.paths_to(claim):
        if any(n.prov != "real" for n in p):
            continue
        covered = union(n.params for n in p)
        if claim.safety_critical_params <= covered:
            return True
    return False   # sim evidence may inform, never certify

def detect_contamination(node, dtr_registry):
    return node.prov == "real" and node.hash in dtr_registry
```

### IP-168 PCE+++++（六维预算）

```python
class CognitiveSimBudget:
    def __init__(self, B_sim=1000, B_calib=50, B_scene=100,
                 B_intent=50, B_ros_retry=3, B_exec=None):
        self.B_sim, self.B_calib = B_sim, B_calib
        self.B_scene, self.B_intent = B_scene, B_intent
        self.B_ros = B_ros_retry
        self.B_exec = B_exec or ExecBudget()

    def sim_weight(self, w_max, tau_sim):
        # no calibration budget => no simulation trust
        if self.B_calib <= 0:
            return 0.0
        return w_max * tau_sim

    def allocate(self, asp, candidates):
        if self.B_calib <= 0:
            return None                       # degrade to real-only loop
        e = asp(candidates, self.B_sim)
        if e is not None:
            self.B_sim -= e.cost
        return e
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性 |
|---|---|---|---|
| DTR | O(1) retrieve | O(N_scene) | 无元数据/低覆盖先验拒绝入库 |
| GRC | O(d³) 特征分解 / 次校准 | O(d²) | 仅可辨识子空间校正；噪声地板拒绝 |
| SRT | O(1) | O(d) | w ≤ w_max < 1；K_safe ⊆ K_safe^real |
| MAG | O(d_A) | O(d_A) | r_A > ε_A 拒绝迁移 |
| SRL+ | O(闭环) | 复用 | B_calib=0 ⇒ w=0 |
| ASP | O(|候选|·d) | O(|候选|) | 预算内最大化决策边界信息增益 |
| PTE | O(V+E) | O(V+E) | 安全关键结论须 real 根路径 |
| PCE+++++ | O(1) 分配 | O(1) | 六维预算单调消耗，B_calib 不可挪用 |

**正确性定理（SRG）**：若 A66–A71 成立（DTR 元数据完整；GRC 可辨识+噪声地板；SRT 权重有界且硬约束仅 real；MAG 锚点残差 ≤ ε_A；PTE 来源不可伪造+污染检测；六维预算单调），则：
1. **安全不退化**：K_safe ⊆ K_safe^real ⇒ 硬安全约束违反次数不高于无仿真先验基线。
2. **可辨识校正收益**：U_id 方向期望误差至少下降 1 − (1−w)²；不可辨识方向方差单调膨胀而非虚假收窄。
3. **证据可证性**：Cert_real(claim) ⇔ 存在 real 根覆盖路径；仿真证据不能独立认证；污染节点被隔离。
4. **预算安全**：B_calib = 0 ⇒ 所有仿真先验权重为 0，退化为第 60 轮纯真实闭环。

## 5. 本轮最大风险

**一句话**：若仿真回放与真实 EV-exec 共用同一哈希/序列号命名空间，一次「仿真证据洗白」就能让证据链在数值与顺序上完全自洽、却在来源上彻底脱离现实——系统会自信地为一台从未真实执行的机械臂签发合规证书；因此必须以「来源分型 + 独立命名空间 + DTR 注册表污染检测 + 无校准不信任（B_calib=0 ⇒ w=0）」四重护栏，确保仿真只能当先验、永远不能当证书。
