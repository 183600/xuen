# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「视觉编码器」×「机械臂」）

> R69 问出了「我该向谁求证、还能问什么」，把不确定性拆成 aleatoric 与 epistemic，并用流匹配策略的**动作模态**来度量 epistemic。但它默认了一件从未被检验的事：**编码器给出的 z，确实指代了世界里那个东西**。R69 的所有不确定性都活在「已知 z 之后、选哪个动作」的空间里；它对「z 本身可能把两个不同的世界压成同一个点」完全无感。而视觉编码器恰恰是一个**商映射**（quotient map）：它把连续、丰富、可干预的世界，压成有限、离散、对某些差异天生失明的嵌入。透明杯与磨砂杯、空盒与满盒、可抓把手与装饰凸棱、镜中物体与真实物体——在嵌入空间里可以是同一个点。
>
> 更危险的是：这种失明**不会表现为动作分歧**。当两个世界被编码成同一个 z，策略在两种世界里输出的是**同一个动作**、同一个模态、同样的低熵——R69 的 AUD 看到的是「毫无歧义」，MCG 看到的是「模态权重很自信」，于是它给一个建立在错误世界上的动作盖上「已验证」的章。**R69 的盲区不是「不知道该怎么办」，而是「非常自信地在错的东西上行动」——自信的错误对动作空间不确定性完全隐形。**
>
> 本轮两个灵感正好给出解药与代价：
> - **视觉编码器**告诉我们，要检查的不是动作分布，而是**编码器的等价类**：它在哪些任务相关维度上不可辨识？这种不可辨识是「该变而不变」（任务坍缩）还是「不该变而变」（噪声泄漏）？
> - **机械臂**是具身系统里唯一能同时**移动传感器**和**介入世界**的部件：它可以通过眼在手上的**视差运动**把「这个视角看不见」变成「换个视角就看见」，也可以通过**接触干预**把「看起来一样」变成「摸起来不一样」。看与摸，是两种本质不同的消歧方式——观察性的与介入性的。
>
> 核心命题：**把「不确定性」再切一刀：在 R69 的「决策歧义」之外，增加「指称歧义」（referential ambiguity）——编码器等价类导致的、动作熵看不见的歧义；用机械臂的视差/介入动作按别名类型定向消解；消解不了就发「负证书」拒绝认证，或改选对整类别名都安全的鲁棒动作，绝不把低动作熵当作看清了。** 命名 **PARALLAX-RAS**（Perceptual ALiasing aware Resolution via Arm-enabled eXploration）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我看到的是不是我以为的那个东西**」——不确定性不只在动作里，也在「我看世界的方式」里；而机械臂既是眼睛，也是手，还是这两者无法分离的证据。

## 0. 直觉与动机

**灵感 1（视觉编码器 → 等价类盲区与「自信的错误」）**
直觉：把视觉编码器想成一台只会回答「属于哪一类」的机器：它把整个世界按自己的词典归档。归档必然有碰撞——两件任务后果完全不同的事被扔进同一个抽屉。人在这种时候会犹豫，但**模型不会**：因为它的策略只看抽屉标签，两个世界给它的输入一模一样，它当然给出同一个动作、同样低的熵、同样自信的模态权重。R69 用「动作模态熵」当 epistemic 探测器，等于假设「只要我犹豫，就说明我没看清」；但真实情况常常反过来——**我最笃定的时候，可能正是编码器把关键差异抹掉的时候**。所以需要一个不依赖动作分布的通道：去问编码器「你对这个输入的任务相关差异，到底能不能分辨」。

**灵感 2（机械臂 → 眼睛可以被移动，世界可以被触碰）**
直觉：固定相机的失明是宿命，机械臂的失明不是。眼在手上（eye-in-hand）意味着**视差是可以主动制造的**：左右挪一点，遮挡关系、深度次序、镜面真假、透明边界都会显形；这就是几何上的「用基线换辨识度」。而有些差异根本不在外观里——空盒与满盒、硬木与软胶、实心与空心——看多久都一样，必须**碰一下**：轻推、下压、短促接触，读力/位移响应。这里的深刻之处是：**看是改变观测者，摸是改变世界**。前者是观察性干预（observational），后者是介入性干预（interventional）；它们消除的是不同种类的别名，用错了不但没用，还会制造「假清晰」。

**灵感 3（R69 是「可辨识已被假设」的边界情形）**
直觉：R69 的整套推导有一个没写出来的前提——`z` 对任务相关状态是可辨识的。一旦承认这个前提可能失效，R69 就不是被推翻，而是被**收进边界**：当 PAD（别名检测器）判定无别名、或辨识通道判别力为零、或没有预算/时延去消歧时，PARALLAX 逐指令退化为 R69；再往下退化为 R68。这延续 R69 立下的规矩：新层必须是旧层的严格泛化，安全侧永不让步。区别只在于，这次要泛化的不是「动作不确定性」，而是「表征的可辨识性」——一个更底层、也更难自证的假设。

**灵感 4（类型匹配 → 错的探针制造「假清晰」）**
直觉：假设物体是空盒还是满盒（接触型别名），你却用「再走近看一眼」去消歧。探针确实返回了一个结果，系统也确实更「确定」了——因为外观本来就不会随重量改变，看完还是同一个 z，于是后验熵下降、置信度上升，但**指称误差一点没降**。这就是「假清晰」：**置信度与正确性脱钩，且方向是危险的（越查越自信）**。所以本轮必须引入「歧义类型」与「通道判别力」的匹配规则：观察型别名用视差，接触型别名用介入，两者都不是的（对称、透明、完美伪装）就承认「在预算内不可辨识」，转为拒证或鲁棒动作。**错的探针比不探更糟，因为它给错误盖章。**

**灵感 5（没有中立的观察者 → 可逆性、观察者效应与时序陈旧）**
直觉：R69 的信息动作（注视/探针/问句）被当成「免费地获取信息」。但机械臂一动，世界就变了：为了看清而移动会遮挡别的目标、会错过时间窗、会让运动中的物体更模糊；接触更可能不可逆——把盒子推下桌、把软物压变形、把本来稳定的堆叠碰倒。于是「消歧」与「任务」在物理上纠缠：**不存在一个只为观察服务的机械臂**。这要求：信息动作必须过与任务动作相同的安全认证、必须记账不可逆度与裕度、必须有时效（消歧结论会过期）、并且当一切都不允许时，系统要能发一张**负证书**：明确写「视觉单独无法认证这一点」，而不是沉默地假装看见。

## 1. 形式化定义（增量：定义 310–324）

**定义 310（PARALLAX-RAS 总览）** PARALLAX-RAS = (PAD, ATM, PIX, PVC, RIL, RCL, ARS, RAS-WM‡)。三不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i / R69 定义 293-i）；
(ii) **可辨识先于自信**：任何宣称「已看清/可认证」的状态，必须附带一张在动作相关状态集上成立的辨识证书；未通过时，只允许执行 alias-robust 动作（定义 319）或拒证回退；
(iii) **类型匹配的证据纪律**：信息动作的通道对当前别名类型必须具有经校准的判别力（κ ≥ κ_min），否则其输出记为「无证据」，不得用于认证（定义 316）。

**定义 311（编码器商映射与别名集）** 视觉编码器 Φ = φ_vis ∘ fusion ∘ trunk : 𝒲 → 𝒵；任务读出 ρ : 𝒲 → 𝒴（如「可抓/不可抓」「空/满」「目标/背景」）。对观测 o 对应的世界类 w，定义**别名集** 𝒜(o) = {w′ ∈ 𝒲 : Φ(w′) = Φ(o)}，以及**任务别名集** 𝒜_ρ(o) = {ρ(w′) : w′ ∈ 𝒜(o)}。称存在**指称歧义**当且仅当 |𝒜_ρ(o)| > 1。关键观察：若 w, w′ 被压到同一 z，则 π(·|z) 与 H(π(·|z)) 在两者上完全相同——**指称歧义不能被任何只依赖 z 的动作分布统计量看见**。

**定义 312（自信–可辨识间隙 Δ_CI）** 记决策熵 B(o) = H(π(·|z))，指称熵 R(o) = H(ρ | z)。R69 只观测 B。定义**盲自信**为 B(o) → 0 而 R(o) 高的区域：系统越确定要做什么，越可能没看清在对什么做。因 R(o) 不可直接计算，运行时用辨识通道给出的校准代理 R̂(o)（定义 313–314）估计；Δ_CI = R̂(o) · (1 − B̂_norm(o))，其中 B̂_norm 为按动作维度归一化的决策熵。

**定义 313（辨识通道：视差与介入）**
（a）**视差探针**：机械臂对相机施加可行视角变换 T_δ（基线 b = ‖δ‖），等变预测器 E_δ 给出「若世界未变、任务相关结构可辨，则特征应如何变」的期望。双侧残差 r_par = min( ‖Φ(T_δ w) − E_δ Φ(w)‖, 敏感度缺口 )：前者抓「不该变却剧变」（跨过别名边界），后者抓「该随视角分离却不分离」（例如深度/遮挡信息被编码器压平）。视差判别力 κ_par(τ) = 在校准集上、单位可行视角变换带来的指称信息增益，满足 κ_par ≈ 1 − exp(−c·b·d/σ_Φ²)，d 为任务相关分离度、σ_Φ 为编码器噪声（引理 20）。
（b）**介入探针**：机械臂施加经认证的局部动作 u，观测结果 y_int。介入判别力 κ_int(τ) = E_{w_1,w_2∈𝒜} KL( p(y|w_1,u) ‖ p(y|w_2,u) )，要求 u 是「外科式」的（局部、可逆、不改变待测性质，见定义 317）。

**定义 314（别名类型分类 ATM）** τ(o) ∈ {VIEW, CONTACT, INVARIANT}：
- **VIEW**：任务相关差异可由视角变化揭示（深度次序、遮挡、镜面真假、透明边界、2.5D 压平）——κ_par 高、κ_int 低；
- **CONTACT**：差异只能由物理响应揭示（质量、刚度、摩擦、空心/实心、温度）——κ_int 高、κ_par 低；
- **INVARIANT**：在可行视角与安全干预下均不可辨识（旋转对称、完全透明、完美伪装、镜像孪生）——κ_par、κ_int 均 ≤ κ_min，**预算内不可解**。
分类器输出后验 (τ, κ̂_par, κ̂_int)，并须经校准（ECE_type ≤ τ_type）；分类不确定本身走 RCL。

**定义 315（感知价值 VoI_perc，与 R69 的 VoI_action 正交）** VoI_perc(g) = H(ρ|z) − E_{y∼p(·|g,o)}[H(ρ|z,y)]。选择 g* = argmax_g [ VoI_perc(g) − c(g) − I(g)·ℓ_irr ]，s.t. κ̂(g, τ) ≥ κ_min、RIL 可行（定义 317）、类型匹配（定义 316）。注意两种正交情形：**VoI_action = 0 而 VoI_perc > 0**（正是别名：动作一致但指称错），以及 **VoI_action > 0 而 VoI_perc = 0**（动作多峰但物体同一，属 R69 地盘）。R69 只对后者敏感。

**定义 316（类型匹配证据规则）** 仅当通道对 τ 的判别力 κ̂(g,τ) ≥ κ_min 且该通道似然模型在 τ 上校准（ECE_channel ≤ τ_ch）时，允许把 y_g 作为证据做 Bayes 更新；否则 y_g 记为 `no-evidence` 并计入审计。理由（引理 21）：当通道在给定 z 下与 ρ 条件独立（κ≈0）却被当作有信息读入时，后验熵下降而期望指称误差不变——**置信度上升、正确性不动**，这是「假清晰」，在认证目标下严格有害。类型不匹配的探针不得单独定案，也不得触发 resolution bonus。

**定义 317（可逆性与干预台账 RIL）** 每个信息动作 g 附带五元组 ( I(g), m(g), T(g), o(g), Snap(g) )：不可逆度 I ∈ [0,1]（不可恢复状态改变的期望幅度）、关节/力矩/奇异裕度 m、墙钟时间 T、目标可见性风险 o（移动相机可能丢失任务目标）、前置快照/回滚策略 Snap。g 可行 ⇔ I ≤ I_max ∧ m ≥ m_min ∧ T ≤ T_deadline ∧ E[task regret] ≤ ε。
- **可逆性**：I > 0 的介入探针必须携带恢复策略与 pre-state snapshot（数字孪生回滚），否则只允许作为 last resort，并触发 λ 升级；
- **观察者效应**：若探针改变被测量性质（压软物测刚度、推物体测质量），建模为 SCM 干预，κ_int 乘以混杂折扣（1 − confound(g)），只接受「外科式」干预；
- **无中立观察者**：视差运动也消耗时间/裕度并可能遮挡目标，故与任务动作共用认证与预算，不作免费信息。

**定义 318（拒证层 RCL）** 若 τ = INVARIANT，或预算/时限内 κ < κ_min，或类型分类器自身不确定，则输出**负证书** ¬Cert(o, ρ)：「视觉单独无法认证 ρ」。后果：(a) 任何**安全谓词依赖 ρ** 的动作不得认证；(b) 回退 R68/R69 最保守 λ；(c) **严禁**把低动作熵或高模态置信当作 clearance；(d) 负证书写入审计与证书，成为下一轮 PAD 的先验。拒证是**一等公民**，不是异常分支。

**定义 319（别名鲁棒安全 ARS）** 动作 a 在观测 o 下**别名鲁棒** ⇔ ∀ρ ∈ 𝒜_ρ(o): safe(a, ρ)。执行集 𝒜_safe(o) = {a : a 别名鲁棒}。若 𝒜_safe ≠ ∅，即使未消歧也可安全执行（定理 19）；若 𝒜_safe = ∅，则必须消歧或弃权。这把 R69 的**标量 λ 收缩**升级为**集合值安全约束**：不是「更慢地做同一个动作」，而是「选一个对整类别名都成立的动作」。

**定义 320（眼在手视角规划与奇异规避）** 可行视角集 𝒱(o) = {T_δ : 关节限位、非奇异（σ_min(J) ≥ σ_min^0）、非自遮挡、时限满足}；视角成本 c_view = T + 裕度消耗 + 运动模糊风险。规划 δ* = argmax_{δ∈𝒱} [ VoI_perc(T_δ) − c_view(δ) ]，并与任务动作做联合前缀认证（R69 的 certified prefix），保证**运动本身**不越安全包络；避免为看清而经过奇异位形或把目标移出视野。

**定义 321（时序陈旧与证书半衰期）** 别名集随场景演化。设场景变化速度 v_scene、消歧墙钟时延 L_res，则辨识证书有效期 T_cert ≈ min( T_max, α / (v_scene + ε) )。若 T_cert < 决策/执行时域，则证书**在执行前已过期**，必须重验或降级为 alias-robust/拒证。R69 的证书是瞬时的；本轮必须显式承认：**感知消歧是有物理时延的，结论会过期**。

**定义 322（编码器稳定半径：噪声泄漏 vs 任务坍缩）** 对 z，定义稳定半径 ε_Φ(z) 与两侧诊断量：
- **噪声泄漏** L_n：本应不变的 nuisance 扰动（光照、纹理、轻微位移）引起 Φ 的改变（鲁棒性差）；
- **任务坍缩** C_t：本应改变的任务相关扰动（视角、遮挡、接触后的状态）引起 Φ 的改变量低于阈值（可辨识性差）。
别名风险 ≈ C_t 高 ∧ L_n 低——**稳定地忽略正确信息**，比「噪声大」危险得多，因为前者会让校准与置信都显得良好。PAD 必须同时报 L_n 与 C_t，禁止用一个「总不确定度」把两者混为一谈。

**定义 323（证书 J_PARALLAX）** J_PARALLAX = ( J_FLUID, τ, κ̂_par, κ̂_int, R̂, Δ_CI, VoI_perc, probe_log_hash, I_used, RCL_flag, T_cert, alias_robust_ok, parallax_ver )。Valid ⇔ Valid(J_FLUID) ∧ 类型匹配满足 ∧ RIL 可行 ∧ (RCL_flag ⇒ 已回退保守) ∧ (未消歧 ⇒ 执行为 alias-robust)。任一不满足即不得声称「已看清」。

**定义 324（严格包含与退化）** 当 PAD 未报别名、或 κ̂_par = κ̂_int = 0、或预算耗尽、或 T(g) > T_deadline（不可暂停）、或 RCL 触发回退时，PARALLAX 的决策与执行**逐指令等于 R69**；当 R69 本身不可交互时等于 R68。安全侧永不弱于 R69（新增的只有「对疑似别名的额外保守/拒证」与「经认证、类型匹配的消歧」）；效率收益只来自「R69 会自信错做」的别名场景。

    k_par = kappa_cal.parallax(o, alias_set)   # 视差可达的分离度（含基线/深度）
    k_int = kappa_cal.intervention(o, alias_set)  # 接触可激发的响应差
    tau = "VIEW" if k_par >= k_int and k_par >= K_MIN else \
          "CONTACT" if k_int > k_par and k_int >= K_MIN else "INVARIANT"
    return tau, k_par, k_int

# IP-266/267 PIX+PVC：类型匹配的视差/介入规划（含可逆性与时限）
def plan_disambiguation(o, tau, budget, deadline):
    best = None
    for g in candidate_probes(o, tau):                    # gaze-parallax / contact
        if not type_matched(g, tau):            continue  # 定义 316
        if not budget.allow(g) or not ril.admissible(g):  continue
        if g.T > deadline:                      continue  # 不可暂停则不可探
        if not c_ras_wm.certify_prefix(g, o):   continue  # 信息动作同认证
        score = voi_perc(g, o) - cost(g) - g.I * LOSS_IRR
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None

# IP-268/269 RIL+RCL：执行 + 不可逆记账 + 负证书
def execute_probe(M, g, o):
    snap = M.ril.snapshot(o) if g.I > 0 else None
    y = M.arm.execute_certified(g)                        # 眼在手视差 / 外科式接触
    if g.I > 0 and M.ril.regret_exceeded(y):
        M.arm.recover(snap); return "aborted", None
    return "ok", y

def refuse_or_resolve(o, tau, k_par, k_int, budget, deadline):
    if tau == "INVARIANT" or max(k_par, k_int) < K_MIN:
        return negative_cert(o)                           # ¬Cert：视觉单独不可认证
    g = plan_disambiguation(o, tau, budget, deadline)
    return g if g is not None else negative_cert(o)

# IP-270 ARS：别名鲁棒动作（未消歧也能安全行动）
def select_alias_robust_action(A_cand, alias_task_set):
    safe = [a for a in A_cand if all(is_safe(a, r) for r in alias_task_set)]
    return max(safe, key=reward) if safe else None        # 空集 → 必须消歧或弃权

# IP-276 主闭环（继承 R69，仅在最底层插入“编码器可辨识性”检查）
def PARALLAX_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    # 0) R69 原路径：动作空间的不确定性（保留）
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    # 1) 新增：指称层——编码器等价类是否已经失明
    C_t, L_n, R_hat, susp = M.pad.detect_perceptual_alias(o, M.phi, M.ens, M.equiv)
    alias_set = M.pad.alias_set(o) if susp else {M.rho(o)}
    tau, k_par, k_int = M.atm.classify(o, alias_set, M.kappa_cal)
    # 2) 类型匹配的消歧；不可解/超时/不可暂停 → 负证书，走保守
    if susp and M.rho(o) not in alias_task_set_singleton(alias_set):
        g = M.rif.refuse_or_resolve(o, tau, k_par, k_int, M.budget, M.deadline)
    else:
        g = None
    resolved = False
    if isinstance(g, Probe):
        status, y = M.rif.execute_probe(g, o)
        if status == "ok" and M.atm.type_matched(g, tau):
            R_hat, alias_set = M.pad.update(alias_set, y, tau)   # 仅类型匹配才更新
            resolved = R_hat <= TAU_R
    # 3) 未消歧：先试别名鲁棒动作；无则拒证 + R69 保守
    a_robust = None
    if not resolved:
        a_robust = M.ars.select_alias_robust_action(M.cand_actions(o), alias_set)
    if a_robust is None and not resolved:
        M.rcl.negative_cert(o)                              # 定义 318
        U_epi = U_epi + R_hat                               # 未消解指称熵并入保守
    # 4) R69 风险缩放 + 认证（继承）
    U_floor = U_ale + (U_epi if not resolved else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    A = M.ach.propose(x_prime, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    # 5) 执行：鲁棒动作优先，否则 R69 选模；证书带时效
    mode = a_robust or M.select_mode(modes, U_epi, lam)
    tau_cmd = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_p.submit_async(g, tau, k_par, k_int, R_hat, a_robust, T_cert=M.tvc.horizon())
    return k, lam, mode, (U_ale, U_epi, R_hat, resolved)

## 3. 推导

**引理 19（指称歧义对动作熵隐形 / 假认证下界）** 设 Φ 在任务相关状态上非单射，别名质量为 μ（落在别名等价类内、且真实类别与策略默认类别不同的概率）。若认证规则只依赖「给定 z 的动作分布及其校准模态权重」，则其假认证率 ≥ μ：因为被压到同一 z 的两类世界 induce **完全相同的** π(·|z) 与 H(π(·|z))，任何 z-条件下的动作统计量都无法区分它们。系：**MCG 的模态校准对此无能为力**——校准的对象是「给定 z 的模式权重」，不是「z 的原像里有什么」；即使策略完美校准，它依然可以在别名上自信地错。

**引理 20（视差分辨与最小基线）** 设两个指称在深度方向的可辨分离为 d、相机基线为 b、编码器噪声尺度 σ_Φ。经视差运动后，任务相关特征分离的期望信噪比随 b·d 增长，判别力满足 κ_par ≥ 1 − exp(−c·b·d/σ_Φ²)。故存在**最小基线** b* ∝ σ_Φ²/d：低于它，机械臂即使移动到工作空间边界也看不清差别；高于它，小的视角变化即可解锁。系：**机械臂的工作空间直接决定视觉可辨识性上限**——这是纯软件校准无法弥补的硬件级约束（合成检查 A 与之一致：假认证率随 b 增大而指数下降）。

**引理 21（类型错配制造假清晰）** 若探针通道在给定 z 下与 ρ 条件独立（κ≈0），却被按「有信息」的似然读入，则后验熵严格下降而期望指称误差不变；在 proper scoring rule 下，期望得分因成本而变差，在认证目标下则表现为「置信度上升、认证错误率不降反升」。形式化：令 p(y|z,ρ)=p(y|z)，则 Bayes 后验 H(ρ|z,y) = H(ρ|z)（在正确模型下不更新）；若用错设的似然强更新，则得到一个熵更低但与 ρ 无关的后验。系：**类型匹配是认证的必要条件**，错配探针不是「信息不足」，而是「主动制造错误确定性」（合成检查 B：错配的「报告置信」0.89–0.91，真实错误仍 0.41–0.43，假清晰间隙约 0.32）。

**引理 22（可逆性–信息前沿）** 不可逆介入探针往往有更高 κ_int（能揭示隐藏物理属性），但带来尾部后悔 I(g)·ℓ_irr；可逆观察探针安全但判别力受限。存在阈值 ℓ*：当 ℓ_irr < ℓ* 时优先不可逆介入，否则优先可逆观察。最优策略是阈值策略，且 ℓ* 随 κ_int−κ_rev 增大而增大。系：RIL 不是「越保守越好」的开关，而是一条可计算的 Pareto 前沿（合成检查 C：ℓ 从 0 增到 20 时，不可逆探针从占优翻转为劣于可逆探针）。

**定理 18（PARALLAX 严格包含 FLUID 与 R68）** 在 A99–A104 下，PARALLAX 的期望风险 ≤ R69 FLUID-RAS，且 ≤ R68 CALM-RAS；并且当 PAD 静默、κ̂ = 0、预算耗尽、T(g) > T_deadline 或 RCL 回退时，两者**逐指令相同**（定义 324）。证明要点：新增动作只有三类——(a) 对疑似别名的额外保守/拒证（只会缩小可行动作集），(b) 经类型匹配、RIL 认证、且不改变任务安全包络的探针（只更新指称后验，不改变执行安全集），(c) alias-robust 动作（按定义对整类别名安全）。三者均不弱化安全侧；效率收益仅在 R69 会自信错做的别名场景出现。故 R69 是 PARALLAX 在「可辨识性已被认证」边界上的退化。

**定理 19（未消歧也能安全：别名鲁棒充分条件）** 若 a ∈ 𝒜_safe(o)（对 𝒜_ρ(o) 中每个 ρ 都安全），且校准后的别名集是真实指称的超集（𝒜_ρ ⊇ {ρ(w_true)}，由定义 322 的保守估计保证），则执行 a 的**别名诱导不安全结果为零**，与哪个别名成员为真无关；相对「已知真实 ρ 的 MAP 最优动作」，其代价至多是对应奖励间隙。系：**面对未消解别名，弃权不是唯一安全响应**；当存在跨别名共享的安全动作时，可以「不看清也安全地做」。合成检查 C：在 10% 错误分支上的朴素 MAP 不安全率 ≈ 0.10，alias-robust 为 0，平均奖励代价约 0.79（≈9%）。

**定理 20（主动消歧的收敛与陈旧下界）** 在 κ ≥ κ_min 且各次探针条件独立的理想化下，重复类型匹配探针使指称熵几何下降 H_{n+1} ≤ (1−κ)H_n，故 n ≥ log(H_0/H_目标)/κ 步可达目标。但若场景以速度 v_scene 演化、消歧墙钟时延为 L_res，则存在熵下界 H_∞ > 0 与证书半衰期 T_cert ≈ α/(v_scene+ε)；当决策时域超过 T_cert 时，再探也无法在「执行时刻」保持可辨识。系：**更快的场景需要更短的证书，而不是更多的探针**；这给出了「何时该停止消歧、改为 alias-robust 或拒证」的判据。

## 6. 本轮最大风险

**一句话**：PARALLAX 的全部收益押在「别名类型与判别力 κ 的估计是对的」这一前提上——**一旦 κ 被高估，系统就会用错配的探针制造「假清晰」（置信度上升、指称误差不降），再借机械臂把这个错误自信执行成物理事实；更根本地，机械臂没有「中立的观察」：它为了看清而移动会改变场景、丢失目标、甚至在不可逆接触中造成它本想避免的损害——用行动去消除无知，可能先制造不可撤销的事实。**

**次级风险与缓解**：
1. **滥发负证书（cry wolf）** → RCL 假拒率纳入 E307/E315，负证书与操作者审计闭环，避免「不会做就拒证」的退化；
2. **编码器集成共模失效**（多个头共享同一别名盲区，分歧为零）→ 去相关训练 + 异构传感器（接触/本体）交叉核对 + E314；
3. **观察者效应与混杂**（探针改变被测属性）→ 定义 317 的外科式约束、混杂折扣、快照回滚 + 引理 22 前沿；
4. **消歧时延击穿高速闭环** → 定义 321 的证书半衰期 + 「不可暂停即不探」的硬门控 + alias-robust 兜底；
5. **类型错配的假清晰** → 定义 316 的 κ 门控与 `no-evidence` 纪律 + E304，宁可「不知道」也不「假装看清」。

## 2. 形式化定义（要点版）

**定义 310（总览与三不变式）** PARALLAX-RAS=(PAD,ATM,PIX,PVC,RIL,RCL,ARS,RAS-WM‡)；继承零学习写、交互预算、证据纪律；新增「可辨识先于自信」与「类型匹配证据纪律」。

**定义 311–312（商映射、别名集、盲自信）** `𝒜(o)={w′:Φ(w′)=Φ(o)}`，`𝒜_ρ(o)={ρ(w′)}`；被压到同一 z 的两类世界 induce 完全相同的 π(·|z) 与 H(π|·)，故指称歧义对任何 z-条件动作统计量隐形；`Δ_CI=R̂(1−B̂_norm)` 刻画「越笃定越可能没看清」。

**定义 313–314（辨识通道与别名类型）** 视差双侧残差（不该变却变 / 该分离却不分离）+ 介入 KL 判别力；`τ=VIEW`（κ_par 高）、`CONTACT`（κ_int 高）、`INVARIANT`（两者皆低，预算内不可解）。`κ_par≈1−exp(−c·b·d/σ_Φ²)`。

**定义 315–316（感知 VoI 与类型匹配）** `VoI_perc(g)=H(ρ|z)−E[H(ρ|z,y)]`，`g*=argmax[VoI_perc−c−I·ℓ_irr]`；仅当 `κ̂(g,τ)≥κ_min` 且通道在 τ 上校准才允许 Bayes 更新，否则记 `no-evidence`（防假清晰）。

**定义 317–318（RIL 与拒证）** `g` 附 `(I,m,T,o,Snap)`，不可逆介入须快照回滚、观察者效应打混杂折扣；`τ=INVARIANT` 或预算内 `κ<κ_min` ⇒ 负证书 `¬Cert`，安全谓词依赖 ρ 的动作不得认证，低动作熵不得当 clearance。

**定义 319–320（别名鲁棒安全与视角规划）** `𝒜_safe={a:∀ρ∈𝒜_ρ,safe(a,ρ)}`，非空即可未消歧执行；视角规划在 `𝒱(o)` 内最大化 `VoI_perc−c_view`，避开奇异/自遮挡，并与任务动作联合前缀认证。

**定义 321–322（时效与稳定半径）** 证书半衰期 `T_cert≈α/(v_scene+ε)`，过期须重验；编码器两侧诊断 `C_t`（该变不变）与 `L_n`（不该变而变），别名风险≈`C_t↑∧L_n↓`（稳定地错）。

**定义 323–324（证书与退化）** `J_PARALLAX` 并入 τ、κ̂、R̂、VoI_perc、RCL、T_cert、alias_robust_ok；PAD 静默/κ=0/预算耗尽/超时/RCL 回退时**逐指令等于 R69**，再退化为 R68。

# IP-264/271 PAD：检测动作熵看不见的别名（双侧诊断）
def detect_perceptual_alias(o, phi, ensembles, equiv):
    C_t = task_collapse_score(o, phi, view_perturbations(o))   # 该变而不变
    L_n = nuisance_leak_score(o, phi, nuisance_group(o))       # 不该变而变
    dis = ensemble_disagreement(ensembles, o)                   # 去相关后分歧
    pro = proprio_visual_mismatch(o, phi)                       # 接触/本体交叉核对
    R_hat = calibrate_proxy(C_t, L_n, dis, pro)
    return C_t, L_n, R_hat, (R_hat > TAU_R and C_t > TAU_CT)

# IP-265 ATM：类型 + 通道判别力
def classify_alias_type(o, alias_set, kappa_cal):
    k_par = kappa_cal.parallax(o, alias_set)       # 含基线/深度/可达视角
    k_int = kappa_cal.intervention(o, alias_set)   # 接触可激发响应差
    tau = "VIEW" if k_par >= max(k_int, K_MIN) else \
          "CONTACT" if k_int >= K_MIN else "INVARIANT"
    return tau, k_par, k_int

# IP-266/267 PIX+PVC：类型匹配 + 可逆性 + 时限
def plan_disambiguation(o, tau, budget, deadline):
    best = None
    for g in candidate_probes(o, tau):
        if not type_matched(g, tau): continue                  # 定义 316
        if not budget.allow(g) or not ril.admissible(g): continue
        if g.T > deadline: continue                            # 不可暂停即不探
        if not c_ras_wm.certify_prefix(g, o): continue
        score = voi_perc(g, o) - cost(g) - g.I * LOSS_IRR
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None

# IP-268/269 RIL+RCL：执行 + 快照/恢复 + 负证书
def execute_probe(M, g, o):
    snap = M.ril.snapshot(o) if g.I > 0 else None
    y = M.arm.execute_certified(g)
    if g.I > 0 and M.ril.regret_exceeded(y):
        M.arm.recover(snap); return "aborted", None
    return "ok", y

def refuse_or_resolve(o, tau, k_par, k_int, budget, deadline):
    if tau == "INVARIANT" or max(k_par, k_int) < K_MIN:
        return negative_cert(o)                                # ¬Cert
    g = plan_disambiguation(o, tau, budget, deadline)
    return g if g is not None else negative_cert(o)

# IP-270 ARS：别名鲁棒动作
def select_alias_robust_action(A_cand, alias_task_set):
    safe = [a for a in A_cand if all(is_safe(a, r) for r in alias_task_set)]
    return max(safe, key=reward) if safe else None             # 空集→消歧或弃权

# IP-276 主闭环（继承 R69，仅在最底层插入可辨识性检查）
def PARALLAX_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    C_t, L_n, R_hat, susp = M.pad.detect_perceptual_alias(o, M.phi, M.ens, M.equiv)
    alias_set = M.pad.alias_set(o) if susp else {M.rho(o)}
    tau, k_par, k_int = M.atm.classify(o, alias_set, M.kappa_cal)
    g = (M.rif.refuse_or_resolve(o, tau, k_par, k_int, M.budget, M.deadline)
         if susp and not singleton(alias_set) else None)
    resolved = False
    if isinstance(g, Probe):
        status, y = M.rif.execute_probe(g, o)
        if status == "ok" and M.atm.type_matched(g, tau):
            R_hat, alias_set = M.pad.update(alias_set, y, tau)
            resolved = R_hat <= TAU_R
    a_robust = None
    if not resolved:
        a_robust = M.ars.select_alias_robust_action(M.cand_actions(o), alias_set)
    if a_robust is None and not resolved:
        M.rcl.negative_cert(o); U_epi = U_epi + R_hat
    U_floor = U_ale + (U_epi if not resolved else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    A = M.ach.propose(x_prime, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    mode = a_robust or M.select_mode(modes, U_epi, lam)
    tau_cmd = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_p.submit_async(g, tau, k_par, k_int, R_hat, a_robust, T_cert=M.tvc.horizon())
    return k, lam, mode, (U_ale, U_epi, R_hat, resolved)

## 4. 推导

**引理 19（指称歧义对动作熵隐形）** 若 Φ 在任务相关状态上非单射、别名质量 μ，则任何只依赖「给定 z 的动作分布及其校准模态权重」的认证规则假认证率 ≥ μ。因为被压到同一 z 的两类世界 induce 完全相同的 π(·|z) 与 H(π(·|z))。系：**MCG 校准无力**——它校准的是「给定 z 的模式权重」，不是「z 的原像里有什么」。

**引理 20（视差分辨与最小基线）** 可辨分离 d、基线 b、编码器噪声 σ_Φ 下，`κ_par ≥ 1−exp(−c·b·d/σ_Φ²)`；存在 `b* ∝ σ_Φ²/d`，低于它机械臂到工作空间边界也看不清。系：**工作空间直接决定视觉可辨识性上限**，软件校准无法弥补。

**引理 21（类型错配制造假清晰）** 若探针通道在给定 z 下与 ρ 条件独立（κ≈0）却按有信息读入，则后验熵严格下降而期望指称误差不变；在认证目标下「置信度上升、错误率不降反升」。系：**类型匹配是认证的必要条件**；错配探针是「主动制造错误确定性」。

**引理 22（可逆性–信息前沿）** 不可逆介入 κ_int 更高但带尾部后悔 I·ℓ_irr；存在阈值 ℓ*，低于它优先不可逆介入，高于它优先可逆观察；ℓ* 随 κ_int−κ_rev 增大而增大。系：RIL 是可计算的 Pareto 前沿，不是「越保守越好」。

**定理 18（严格包含 FLUID 与 R68）** A99–A104 下期望风险 ≤ R69 ≤ R68；当 PAD 静默 / κ̂=0 / 预算耗尽 / T(g)>T_deadline / RCL 回退时逐指令相同。新增动作只有「额外保守/拒证」「类型匹配且经认证的探针」「alias-robust 动作」三类，均不弱化安全侧。

**定理 19（未消歧也能安全）** 若 `a∈𝒜_safe(o)` 且校准别名集是真实指称超集，则执行 a 的别名诱导不安全结果为零，与哪个别名成员为真无关；代价至多是对应奖励间隙。系：**弃权不是唯一安全响应**；存在跨别名共享安全动作时，可以「不看清也安全地做」。

**定理 20（主动消歧收敛与陈旧下界）** 条件独立、κ≥κ_min 时 `H_{n+1}≤(1−κ)H_n`，n≥log(H_0/H_目标)/κ 步可达；但场景速度 v_scene、时延 L_res 给出熵下界 H_∞>0 与 `T_cert≈α/(v_scene+ε)`。系：**更快的场景需要更短的证书，而不是更多的探针**。

## 6. 合成机理验证（非基准证据）

纯 Python、确定性种子（`exp/parallax_sim.py`，结果 `exp/parallax_results.json`），只验证三条定性机理，**不构成基准或真实机器人证据**。

**A. 自信的错误（引理 19–20）** 别名让动作熵恒为 0；R69 把「低熵」读成「已验证」。加入视差辨识通道后，假认证率随基线 b 下降：

| 基线 b | 别名率 | R69 假认证率 | PARALLAX 假认证率 | 触发探针率 | 别名得分 AUC |
|---|---|---|---|---|---|
| 0.05 | 0.4 | 0.199 | 0.182 | 0.14 | 0.53 |
| 0.20 | 0.4 | 0.200 | 0.134 | 0.46 | 0.61 |
| 0.40 | 0.4 | 0.197 | 0.084 | 0.69 | 0.72 |
| 0.80 | 0.4 | 0.199 | 0.027 | 0.91 | 0.87 |

R69 的假认证率与基线无关（≈别名率×1/2，因为它根本看不见），而视差通道随 b 单调改善，与引理 20 的 `1−exp(−c·b·d/σ²)` 形状一致。

**B. 类型匹配（引理 21）** 匹配探针把指称误差降到 0.09（VIEW）与 0.11（CONTACT）；错配探针在「被当成匹配读入」时报告置信度 0.89–0.91，但真实误差仍是 0.41–0.43——**假清晰间隙约 0.32**。INVARIANT 两类探针都几乎无信息（误差 0.47），必须走 RCL。

## 8. 本轮最大风险

**一句话**：PARALLAX 的全部收益押在「别名类型与判别力 κ 的估计是对的」这一前提上——**一旦 κ 被高估，系统就会用错配的探针制造「假清晰」（置信度上升、指称误差不降），再借机械臂把这个错误自信执行成物理事实；更根本地，机械臂没有「中立的观察」：它为了看清而移动会改变场景、丢失目标、甚至在不可逆接触中造成它本想避免的损害——用行动去消除无知，可能先制造不可撤销的事实。**

**次级风险与缓解**：滥发负证书（E307/E315 假拒率 + 操作者审计闭环）；编码器集成共模失效（去相关训练 + 接触/本体交叉核对 + E314）；观察者效应与混杂（外科式约束 + 混杂折扣 + 快照回滚 + 引理 22）；消歧时延击穿高速闭环（证书半衰期 + 「不可暂停即不探」+ alias-robust 兜底）；类型错配假清晰（κ 门控 + `no-evidence` 纪律 + E304）。
