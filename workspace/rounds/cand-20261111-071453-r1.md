# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 1 轮；本轮灵感：「分布外泛化」×「实时控制」）

> 第 54 轮把技能组合提升为动作空间剖面 α_S + 组合图 G_S + 云边契约 C_ce 的动作-鲁棒性双证书。本轮追问两个此前被默认掉的假设：**(i)** 所有 α_S、ρ、compat 都是在训练分布 D_in 上估的，部署分布 D_out 一旦漂移，证书还成立吗？**(ii)** 检测漂移、重算证书、回退本身都要耗时，而控制回路有硬截止期；当 OOD 越强、检测越慢、反应时间越短时，闭环还能闭合吗？核心矛盾——**H22**：证书是「分布内经验量」，OOD 下可能系统性乐观；**H23**：OOD 同时抬高检测成本又压缩安全反应时间，形成「实时-OOD 可行性夹逼」。

## 0. 直觉与动机

**灵感 1（把 α_S、ρ 从点估计升级为「分布邻域内的最坏值」）**
直觉：第 54 轮的 α_S(a) 只是一个经验占用率；现实中真正该问的是「在离 D_in 不超过 ε 的任何部署分布 Q 下，这个动作还可用吗？」于是把剖面改成分布鲁棒剖面 `α_S(a; ε) = inf_{W_1(Q,D_in) ≤ ε} Q[S 能执行 a]`。这不是拍脑袋地更悲观，而是有 Kantorovich–Rubinstein 对偶给出的精确下界：`α_S(a;ε) = [E_{D_in}[g_{S,a}] - ε·Lip(g_{S,a})]_+`。OOD 半径 ε 成为一个可调、可证的旋钮：ε=0 退化为第 54 轮，ε 越大越保守。

**灵感 2（OOD 证书：把「泛化」写成可传递的衰减不等式）**
直觉：泛化不该是「测试集还凑合」的口头保证，而应是一个可组合的 Lipschitz 衰减：若鲁棒性谱 ρ 对分布是 L_ρ-Lipschitz 的，则 `ρ_out(d) ≥ ρ_in(d) - L_ρ(d)·W_1(D_out,D_in) - β_ρ`。这把「分布外会掉多少」变成与第 53/54 轮 ρ、K 同构的一个证书项，可沿组合链累加。关键诚实点：L_ρ 必须用**留出分布**估计，而不是拿同一分布自证。

**灵感 3（实时控制：证书计算本身有截止期，且 OOD 会同时压缩反应时间）**
直觉：控制回路周期 T_c（1–10ms 量级），而深度 OOD 检测常在 10–100ms，二者天然错位。更尖锐的是，用控制屏障函数 h 可推出反应截止期 `T_react = h_0 / γ`（γ 为最坏发散速率）；而 OOD 越强，γ 越大 → `T_react(ε) = h_0/(γ_0 + L_γ ε)` 越短，偏偏检测耗时 ℓ_ood(ε) 越长。于是可行域由 `ℓ_total(ε) ≤ T_react(ε)` 双向夹逼，可能根本无解。这就是「实时-OOD 可行性夹逼」，必须允许**优雅降级**而非硬算。

**灵感 4（自适应共形 + 安全滤波器：给实时控制一个分布无关的覆盖保证）**
直觉：与其相信一个可能过时的参数化不确定性，不如用共形预测给出有限样本、分布无关的覆盖：在交换性下 `P(s(z,a) ≤ q̂) ≥ 1-α`。漂移破坏交换性时，用自适应共形推断 ACI 在线调 α_t，维持长期覆盖率；再把共形集 `C_t` 与 CBF 安全集求交做动作滤波。由于分位数查表与 ACI 更新都是 O(1)，它天生适配硬实时。这把「统计保证」与「控制实时性」第一次接在同一层。

**灵感 5（漂移触发的安全回退：宁可退回已验证核心，也不在线赌泛化）**
直觉：一旦漂移剖面 Σ 越过预算或 ACI 连续失配，立即切到只在「分布无关安全核」`A_core^robust` 上动作的回退策略 π_fb；它性能差但证书不依赖 D_out。云端在后台重剖分、重标定、重发证书，边端用迟滞 + 无扰切换避免抖动。这把第 54 轮的 A_core 变成「漂移下的最后防线」。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（分布鲁棒动作剖面 DAP）**
设上下文 z ~ D，技能 S 对动作 a 的可执行性由有界光滑指示 `g_{S,a}(z)∈[0,1]` 给出。对半径 ε≥0：
```
α_S(a;ε) = [ E_{D_in}[g_{S,a}] - ε·Lip(g_{S,a}) ]_+
```
由 KR 对偶，`α_S(a;ε) = inf_{W_1(Q,D_in)≤ε} E_Q[g_{S,a}]`，即球内最坏占用。**鲁棒覆盖** `cover_ε(S,A_T)=1 ⟺ ∀a∈A_T, α_S(a;ε) ≥ θ_cov`。第 54 轮 α_S(a) 是 ε=0 特例。

**定义 122（OOD 证书 OODC 与漂移剖面）**
漂移剖面 `Σ = (ε_W, ε_TV)`：ε_W 为 W_1 半径（用于鲁棒性衰减），ε_TV 为总变差上界（用于共形覆盖衰减）。OOD 证书：
```
OODC: ρ_out(d) ≥ ρ_in(d) - L_ρ(d)·ε_W - β_ρ,  ∀d∈𝔇_ρ
```
其有效域 `dom_OOD = {d : ρ_out(d) ≥ ρ_min(d)}`；若 `𝔇_ρ ⊄ dom_OOD` 则拒绝部署。L_ρ(d) 由多源留出分布回归估计，并附置信上界 `L̂_ρ + κ·se`。

**定义 123（实时可调度证书 RTC）**
端到端时延 `ℓ_total = ℓ_perc + ℓ_ood + ℓ_cert + ℓ_fb + ℓ_ctrl`，控制周期 T_c，时延裕度 `s = T_c - ℓ_total`。由 CBF h 与最坏发散速率 γ 定义反应截止期 `T_react(ε_W) = h_0 / (γ_0 + L_γ ε_W)`。**可调度**当且仅当
```
ℓ_total(ε_W) ≤ min(T_c, T_react(ε_W))  ∧  s ≥ s_min
```
若 ℓ_ood(ε) 随 ε 单调增、T_react(ε) 随 ε 单调减，则存在可行 ε 区间 `[ε_lo, ε_hi]`，为空时进入强制回退。

**定义 124（自适应共形安全滤波 ACI-SF）**
非一致性分数 `s(z,a)`，校准集 `D_cal ~ D_in`（n 个）。分位数 `q̂_t` 与共形集 `C_t = {a : s(z_t,a) ≤ q̂_t}`。安全动作集 `C^safe_t = C_t ∩ A_core^robust`。ACI 更新 `α_{t+1} = α_t + γ_c(α* - 1{s_t > q̂_t})`，实现长期误覆盖 `(1/T)Σ 1{s_t>q̂_t} ≤ α* + (1+γ_c)/(γ_c·T)`。在 `TV(D_out,D_in)≤ε_TV` 且交换性近似成立时，单步覆盖 `P(s_t ≤ q̂_t) ≥ 1 - α - ε_TV - 1/(n+1)`。

**定义 125（漂移触发安全回退 SFC）**
回退策略 `π_fb : Z → A_core^robust`，其证书满足 `∀Q∈Ball(D_in,ε_W): ρ_Q(π_fb) ≥ ρ_min`（分布无关）。触发条件 `guard = (ε_W > ε_hi) ∨ (ACI 连续 k 次失配) ∨ (s < s_min)`。切换带迟滞 `(τ_on, τ_off)` 与无扰约束 `||u_fb - u_nom|| ≤ Δu_bumpless`。回退期间冻结组合图，云端异步执行 `reprofile + recalibrate + recertify`。

**定义 126（漂移-时序联合证书 JSTC）**
```
J' = (ρ_in, A_cert, Σ, s, cov=1-α, γ_ce, δ_a, L̂_ρ, T_react, evidence)
```
可部署当且仅当
```
dom_J(T)=in ∧ ρ_in - L̂_ρ ε_W ≥ ρ_min ∧ ℓ_total ≤ T_react(ε_W)
∧ s ≥ s_min ∧ cov ≥ 1-α ∧ δ_a ≤ Θ_a
```
即第 54 轮联合证书 J 增加**漂移维 Σ**与**时序维 (s, T_react)**，形成四维可部署判据。

## 2. 关键算法 伪代码

### IP-121 DAP（分布鲁棒剖面）

```python
def dro_profile(skill, A, D_in, eps, theta_cov=0.8):
    alpha = {}
    for a in A:
        g = smooth_exec_indicator(skill, a)          # z -> [0,1]
        mean = empirical_mean(g, D_in)
        lip  = lipschitz_estimate(g, D_in, metric='w1')
        alpha[a] = max(0.0, mean - eps * lip)
    return alpha

def cover_eps(alpha, A_T, theta_cov=0.8):
    return all(alpha.get(a, 0.0) >= theta_cov for a in A_T)
```

### IP-122 OODC（分布外衰减证书）

```python
def ood_certificate(rho_in, shift_profile, L_rho_hat, beta_rho, rho_min):
    eps_w, eps_tv = shift_profile
    rho_out = {d: rho_in[d] - L_rho_hat[d]*eps_w - beta_rho for d in rho_in}
    dom = all(rho_out[d] >= rho_min[d] for d in rho_out)
    return ('in' if dom else 'out'), rho_out
```

### IP-123 RTC（实时可调度）

```python
def schedulable(ell, T_c, h0, gamma0, L_gamma, eps_w, s_min):
    T_react = h0 / (gamma0 + L_gamma * eps_w)
    s = T_c - ell
    feas = (ell <= min(T_c, T_react)) and (s >= s_min)
    return feas, s, T_react

def feasible_eps_range(eps_grid, ell_fn, react_fn, T_c, s_min):
    return [e for e in eps_grid
            if ell_fn(e) <= min(T_c, react_fn(e))
            and (T_c - ell_fn(e)) >= s_min]
```

### IP-124 ACI-SF（自适应共形安全滤波）

```python
def aci_safety_filter(z, cand, scores_fn, q_hat, alpha_t,
                      A_core_robust, gamma_c=0.01, alpha_star=0.1):
    C = [a for a in cand if scores_fn(z, a) <= q_hat]
    C_safe = [a for a in C if a in A_core_robust]
    if not C_safe:
        return ('fallback', None, alpha_t)
    a = argmin_cost(C_safe)
    err = 1.0 if scores_fn(z, a) > q_hat else 0.0
    alpha_t = clip(alpha_t + gamma_c * (alpha_star - err), 1e-4, 1-1e-4)
    return ('ok', a, alpha_t)
```

### IP-125 SFC（漂移触发回退）

```python
def shift_fallback(gate, eps_w, eps_hi, aci_errors, k, s, s_min):
    trig = (eps_w > eps_hi) or (consec_fail(aci_errors) >= k) or (s < s_min)
    if trig and gate.state == 'nominal':
        return 'enter_fallback'      # 切到 pi_fb on A_core_robust, 迟滞 tau_on
    if not trig and gate.state == 'fallback' and gate.dwell > tau_off:
        return 'exit_fallback'       # 恢复组合计划, 无扰约束
    return gate.state
```

### IP-126 JSTC（漂移-时序联合证书）

```python
def joint_shift_timing_cert(rho_in, A_cert, shift, timing, cov, gamma_ce,
                            delta_a, L_rho_hat, rho_min, Theta_a):
    dom = all(rho_in[d] - L_rho_hat[d]*shift.eps_w >= rho_min[d] for d in rho_in)
    if not dom:                      return ('reject','ood_domain')
    if timing.ell > min(timing.T_c, timing.T_react): return ('reject','deadline')
    if timing.s < timing.s_min:      return ('reject','slack')
    if cov < 1 - timing.alpha:       return ('reject','coverage')
    if delta_a > Theta_a:            return ('reject','action_mismatch')
    return ('ok', JSTC(rho_in, A_cert, shift, timing, cov, gamma_ce, delta_a))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| DAP | O(|A|·n_cal·d) | O(|A|) | KR 对偶下界精确；Lip 估计取上界 |
| OODC | O(d·|𝔇_ρ|) | O(|𝔇_ρ|) | L_ρ 置信上界、ε 可测 |
| RTC | O(|P|) | O(1) | ℓ 取 WCET、T_react 保守 |
| ACI-SF | O(1)/step（查表） | O(n_cal) | 长期覆盖、量化 O(1) |
| SFC | O(|A_core|) | O(1) | 分布无关核、迟滞稳定 |
| JSTC | O(|A|+|𝔇_ρ|) | O(|A|+|𝔇_ρ|) | 四维判据合取 sound |

**正确性定理（Shift-Aware Real-Time Composition Soundness）**
承接第 54 轮 (A22)–(A28)，新增：**(A29)** ρ 在 W_1 下 L_ρ-Lipschitz，且 L̂_ρ 为置信上界；**(A30)** `g_{S,a}` 为 L_g-Lipschitz，DAP 由 KR 对偶精确；**(A31)** 校准/部署分布 TV ≤ ε_TV，分数有界于 [0,1]；**(A32)** WCET 满足 `ℓ_total ≤ min(T_c-s_min, T_react(ε_W))`。则
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a) - P(compat<θ_a)
            - Σ_d L_ρ(d)·ε_W - (ε_TV + 1/(n+1)) - P(ℓ_total > T_react)
```
其中前四项承自第 54 轮，`Σ_d L_ρ(d)ε_W` 是漂移的鲁棒性衰减，`ε_TV + 1/(n+1)` 是共形覆盖的漂移+有限样本折损，末项是实时截止违约概率。**推论**：当 `ε_W→0, ε_TV→0, n→∞, ℓ_total≤T_react` 时退化为第 54 轮定理，验证增量相容。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| W_1/TV 半径测不到语义漂移 | 高 | 多度量剖面 + 语义探针 + 红队新类 |
| L_ρ 在漂移下被低估 | 高 | 多源留出 + 置信上界 + 保守系数 |
| 实时算力压垮 OOD 检测 | 高 | 两级监控 + anytime 证书 + 预计算保守集 |
| ACI 与 CBF 相互干扰 | 中 | 分层滤波 + 优先级仲裁 + 冻结窗口 |

## 6. 本轮最大风险

**一句话**：把泛化写成 W_1/TV 半径上的 Lipschitz 衰减，形式漂亮，却把「分布外」偷偷约等于「度量意义下的小扰动」；一旦真实漂移是语义级、结构化或新类别的（像素 Wasserstein 很小但安全含义剧变），证书会给出**乐观的 sound 假象**，而实时压力又迫使截断标定、进一步低估 L_ρ——所以本轮最大风险不是算不动，而是**用一个测得到的漂移，冒充了真正要防的漂移**。

## 2. 关键算法 伪代码

### IP-121 DAP + 鲁棒组合图

```python
def dro_profile(skill, A, D_in, eps):
    alpha = {}
    for a in A:
        g = smooth_exec_indicator(skill, a)          # z -> [0,1]
        mean = empirical_mean(g, D_in)
        lip  = lipschitz_estimate(g, D_in, metric='w1')
        alpha[a] = max(0.0, mean - eps * lip)        # KR 对偶精确下界
    return alpha

def robust_profile_set(skill, eps, theta_cov):
    alpha = dro_profile(skill, skill.A, D_in, eps)
    return {a for a, v in alpha.items() if v >= theta_cov}

def robust_skill_graph(skills, eps, theta_cov, theta_a, tau_e, K):
    G = nx.DiGraph()
    sets = {s.id: robust_profile_set(s, eps, theta_cov) for s in skills}
    for i, s1 in skills:
        for j, s2 in skills:
            if i == j: continue
            A1, A2 = sets[i], sets[j]
            compat = len(A1 & A2) / max(1, len(A1 | A2))
            c_trans = transition_cost(s1, s2)
            if compat >= theta_a and c_trans <= tau_e:
                rho = compose_robustness(s1.rho, s2.rho, K)
                G.add_edge(i, j, compat=compat, cost=c_trans,
                           rho_comp=rho, A_overlap=A1 & A2)
    return G
```

### IP-123 RTC（时延预算 + 反应截止期）

```python
def reaction_deadline(h0, gamma0, L_gamma, eps_w):
    return h0 / (gamma0 + L_gamma * eps_w)

def schedulable(tasks, T_c, h0, gamma0, L_gamma, eps_w, s_min):
    ell = sum(t.wcet for t in edf(tasks))           # WCET 之和
    T_react = reaction_deadline(h0, gamma0, L_gamma, eps_w)
    s = T_c - ell
    feas = (ell <= min(T_c, T_react)) and (s >= s_min)
    return feas, s, T_react

def feasible_eps_interval(eps_grid, ell_fn, h0, gamma0, L_gamma, T_c, s_min):
    ok = [e for e in eps_grid
          if ell_fn(e) <= min(T_c, reaction_deadline(h0, gamma0, L_gamma, e))
          and (T_c - ell_fn(e)) >= s_min]
    return (min(ok), max(ok)) if ok else None     # None => 强制回退
```

### IP-124 ACI-SF（共形标定 + 在线滤波）

```python
def conformal_quantile(scores_cal, alpha):
    n = len(scores_cal)
    k = ceil((n + 1) * (1 - alpha))
    return sorted(scores_cal)[min(k, n) - 1]       # O(n log n) 离线一次

def aci_safety_filter(z, cand, scores_fn, q_hat, alpha_t,
                      A_core_robust, gamma_c=0.01, alpha_star=0.1):
    C = [a for a in cand if scores_fn(z, a) <= q_hat]
    C_safe = [a for a in C if a in A_core_robust]
    if not C_safe:
        return ('fallback', None, alpha_t)
    a = argmin_cost(C_safe)
    err = 1.0 if scores_fn(z, a) > q_hat else 0.0
    alpha_t = clip(alpha_t + gamma_c * (alpha_star - err), 1e-4, 1 - 1e-4)
    return ('ok', a, alpha_t)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| DAP | O(|A|·n_cal·d + |S|²·|A|) | O(|A|+|S|²) | KR 对偶下界精确，Lip 取上界 |
| OODC | O(d·|𝔇_ρ| + n_src) | O(|𝔇_ρ|) | L̂_ρ 置信上界，ε 可测 |
| RTC | O(|P| log|P|)（EDF） | O(|P|) | WCET 保守，T_react 悲观 |
| ACI-SF | O(1)/step（查表）+ O(n log n) 离线 | O(n_cal) | ACI 长期覆盖，分位 O(1) |
| SFC | O(|A_core|) | O(1) | 分布无关核，迟滞稳定性 |
| JSTC | O(|A|+|𝔇_ρ|) | O(|A|+|𝔇_ρ|) | 四维合取 sound |

**正确性定理（Shift-Aware Real-Time Composition Soundness）**
第 54 轮 (A22)–(A28) 成立；**(A29)** ρ 在 W_1 下 L_ρ-Lipschitz 且 L̂_ρ 为置信上界；**(A30)** `g_{S,a}` L_g-Lipschitz，DAP 由 KR 对偶精确；**(A31)** `TV(D_out,D_in) ≤ ε_TV`，分数有界于 [0,1]；**(A32)** `ℓ_total ≤ min(T_c-s_min, T_react(ε_W))`。则
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a) - P(compat<θ_a)
            - Σ_d L_ρ(d)·ε_W - (ε_TV + 1/(n+1)) - P(ℓ_total > T_react)
```
关键：**漂移有界则鲁棒性可量化衰减；覆盖可被共形+ACI 约束；时延满足 WCET 与反应截止期才可部署**。退化检验：`ε→0, n→∞, 无截止违约` 时回到第 54 轮定理。

## 5. 本轮最大风险

**一句话**：把泛化写成 W_1/TV 半径上的 Lipschitz 衰减，形式漂亮，却把「分布外」偷偷约等于「度量意义下的小扰动」；一旦真实漂移是语义级、结构化或新类别的（像素 Wasserstein 很小但安全含义剧变），证书会给出**乐观的 sound 假象**，而实时压力又迫使截断标定、进一步低估 L_ρ——所以本轮最大风险不是算不动，而是**用一个测得到的漂移，冒充了真正要防的漂移**。
