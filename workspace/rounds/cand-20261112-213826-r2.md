# 第 62 轮（承接第 61 轮「具身语义进化闭环」IP-173~182；灵感循环第 8 轮；本轮灵感：「移动操作」×「运动规划」）

> 第 61 轮构建了 ESEC「具身语义进化闭环」：USR 把场景/意图/阻抗/证据映射到共享语义空间、MEL 提供零样本物理先验、DMS 实现多轮对话接地、SRT-Dual 解耦语义流与实时流、PCE+++++ 拓展六维预算。但**五个结构性局限**在「移动操作」场景下暴露：
> 1. **固定基座假设**：EEIS/MSPF/USR 的阻抗编译与语义锚点都默认「基座不动、机械臂末端做阻抗」。移动操作要求基座-机械臂-（躯干）耦合，基座运动改变可达工作空间，阻抗必须在全身分配，且必须满足非完整约束与平衡（ZMP）约束——第 61 轮完全没有这些维度。
> 2. **快照语义锚点的视角依赖**：SRT-Dual 的 `Anchor_t = (scene_emb, intent_emb, ts, version)` 是提交时刻的一帧快照。基座一移动，`scene_emb` 立即过时；重跑 MEL 需 ~200ms，而语义流目标 ~10Hz——「场景」不是空间持久实体，而是「某视角下的一帧」，这与移动操作的根本前提冲突。
> 3. **纯反应式阻抗缺乏全局规划**：EEIS+ERTC 是 ~1-10kHz 的局部闭环，只能做反应式避障，无法推理长时程无碰轨迹、窄通道、或「基座停在哪里才够得着」；在复杂地形上必然陷入局部极小。
> 4. **语义与运动学/动力学可行性脱节**：MEL/DMS 给出「语义上最优」的动作（抓取位姿、接近方向），但不保证可达、不平衡、不违反关节/速度约束、不碰撞——缺少运动学/动力学可行性硬门控。
> 5. **任务规划与运动规划鸿沟**：DMS 输出的符号约束（轻一点、稳住）没有几何接地；缺少把「navigate→grasp→transport→place」符号序列与连续运动轨迹联合求解的 TAMP。

## 0. 直觉与动机

**灵感 1（移动操作 → 全身阻抗编译 WBIC）**
直觉：第 61 轮的 EEIS 只编译末端笛卡尔阻抗 `K_x`。移动操作中，「稳住」不再只靠机械臂——基座微调、躯干倾斜、机械臂柔顺共同决定接触稳定性。关键洞见：把阻抗编译升级为**全身阻抗编译（WBIC）**，决策变量 `z = (v_b, ω_b, q̇, K_x, K_q)`，在**层级 QP** 中求解：硬约束层（非完整、平衡、关节/速度限位、碰撞）优先，语义先验 `z_sem` 只注入零空间/软约束层。这样「语义先行」永远不会覆盖「动力学安全」。

**灵感 2（运动规划 → 语义可供性场 SAF + 语义信息 RRT\*）**
直觉：运动规划的本质是「在构型空间里找一条低代价、无碰、满足动力学的路径」。第 61 轮的语义信息只用于阻抗先验，没进入规划器。关键洞见：把 SEMF+MEL 的语义/物理先验转成 **SE(3) 上的可微可供性场 SAF**（抓取可供性 `A_grasp`、基座可供性 `A_base`、可通行性 `A_trav`、间隙 `A_clear`），作为 RRT\*/PRM 的**信息采样分布** `p_sample ∝ exp(β·A)` 和**代价启发式** `c(m)=∫(1-A)dt`——让规划器「往语义上该去的地方采样」，同时保持概率完备性。

**灵感 3（移动操作 → SE(3)-等变语义场 SEMF，替代快照锚点）**
直觉：基座移动时，同一个物理场景在不同视角下应得到「一致」的语义。关键洞见：把快照锚点升级为**世界坐标系下的持久语义场 SEMF**：`F_θ: SE(3) → ℝ^d_us`，近似 SE(3)-等变（相对位姿编码/帧平均），并做贝叶斯语义-占据增量融合。基座移动时只需 `scene_emb = F_θ(ξ_b)` 重新查询，不重跑大模型；只有查询点落在「未覆盖区域」时才触发 MEL 局部重推理。语义从「一帧」变成「一张可持续更新的地图」。

**灵感 4（运动规划 → 语义任务-运动规划 TAMP-S + 基座放置语义 BPS）**
直觉：移动操作的难点一半在「先停哪」。关键洞见：**TAMP-S** 分两层——符号任务层给出 `navigate→grasp→transport→place` 序列，几何运动层用 SAF 引导的 anytime RRT\* 求解每段轨迹；**BPS** 把基座停放位姿 `x_b ∈ SE(2)` 作为显式决策变量，目标 = 可操作度 × 可达体积 × 基座可供性 − 导航代价。基座放置不再是「导航模块的副产物」，而是与抓取规划联合优化的对象。

**灵感 5（合流 → 可行性证书 KFC + 语义重规划 SRR + 规划预算 MPB）**
直觉：语义上再漂亮的计划，只要运动学/动力学不可行就是灾难。关键洞见：引入**运动学/动力学可行性证书 KFC**（可达余量、速度/加速度余量、碰撞间隙、平衡余量、非完整残差），作为语义计划的**硬门控**；引入**语义重规划触发 SRR**（场漂移/执行异常/余量告急/意图变化），按「安全触发抢占语义触发」的优先级决定重规划粒度（局部 WBIC / 几何重规划 / 任务重规划）；把 PCE+++++ 扩为七维预算，新增**规划预算 B_plan**，用 anytime 规划在预算内返回最优可用解。

## 1. 形式化定义（增量：定义 173–184）

**定义 173（SE(3)-等变语义场 SEMF）** SEMF = (F_θ, U, C, d_us)。其中：
- **世界系连续语义场**：`F_θ: ℝ³ × SO(3) → ℝ^d_us`，把查询位姿 `ξ=(x,R)` 映射为语义嵌入；场在世界系定义，随基座位姿变换而无需重算
- **近似 SE(3)-等变**：存在表示 `ρ` 使 `‖F_θ(T∘ξ) - ρ(T)F_θ(ξ)‖ ≤ ε_eq`；由相对位姿编码 + 帧平均（frame averaging）实现
- **增量语义-占据融合**：`F_t = fuse(F_{t-1}, obs_t, pose_t)`，对体素做贝叶斯更新 `P(semantic|obs)` 与占据更新
- **覆盖度与新鲜度**：`freshness(ξ) = exp(-d(ξ, ∂Ω_obs)/σ_cov)`，`d` 为到已观测区域边界的距离；未覆盖点新鲜度→0
- **场漂移**：`D_field = mean_{ξ∈Ξ_ref} ‖F_t(ξ) - F_{t-1}(ξ)‖`
- **查询接口**：`scene_emb(ξ_b) = F_t(ξ_b)`，替代第 61 轮的快照锚点

**定义 174（语义可供性场 SAF）** SAF = (A_grasp, A_base, A_trav, A_clear, w)。其中：
- `A_grasp: SE(3) → [0,1]`：抓取可供性，由 `(F_t(ξ), φ_phys, freshness)` 经轻量头得到
- `A_base: SE(2) → [0,1]`：基座可供性 = 可达体积 × 间隙 × 稳定余量
- `A_trav: ℝ² → [0,1]`：底盘可通行性（地形、坡度、粗糙度）
- `A_clear: ℝ³ → ℝ_+`：到障碍的有符号间隙场
- **复合可供性**：`A(ξ) = w_g·A_grasp + w_b·A_base + w_t·A_trav`
- **可微性**：`A` 为 C¹（或次可微），`∇A` 可直接作为规划启发式

**定义 175（全身阻抗编译 WBIC）** WBIC = (QP, C_nh, C_bal, C_lim, C_coll, K_wb)。决策变量 `z = (v_b, ω_b, q̇, K_x, K_q)`：
```
min_z  ‖J_task(q,x_b) z - ẋ_des‖²_{W_task} + λ_sem‖z - z_sem‖²_{W_sem}
s.t.   C_nh : ẏ_b sinθ_b - ẋ_b cosθ_b = 0            # 非完整（差速底盘）
       C_bal: ZMP(z) ∈ P_support,  ξ_cp(z) ∈ P_support # 平衡/捕获点
       C_lim: q ∈ [q_min,q_max], |q̇| ≤ q̇_max, |z| ≤ z_max
       C_coll: d(robot(q,x_b), O) ≥ d_safe
```
- **层级优先级**：`C_nh, C_bal, C_lim, C_coll` 为硬约束（安全层）；`z_sem` 仅进入软目标/零空间
- **语义先验**：`z_sem = Π_wb(F_t(ξ_b), φ_phys)`，由 USR 投影头扩展为全身先验
- **稳定性**：QP 强凸 + 可行 ⇒ 存在唯一最优 `z*`，阻抗跟踪误差有界

**定义 176（语义任务-运动规划器 TAMP-S）** TAMP-S = (Σ_sym, Σ_geo, A_sym, Planner, SAF)。其中：
- **符号任务层**：`τ = (a_1,...,a_n)`，`a_i ∈ {navigate(x_b), grasp(o), transport(o,x), place(o,x)}`
- **几何运动层**：每段动作对应轨迹 `m_i: [0,T_i] → C_free`（构型含基座 + 机械臂）
- **语义信息采样**：`p_sample(q) ∝ exp(β·A(ξ(q)))`，以接受率下界保证概率完备性
- **可供性引导代价**：`c(m) = ∫₀ᵀ (1 - A(ξ(q(t)))) dt + λ_len·len(m) + λ_E·E(m)`
- **anytime 规划器**：语义信息 RRT\*，在 `B_plan` 内持续改进，返回 `(τ, {m_i}, cost, status)`
- **基座放置**：`x_b` 由 BPS 给出（定义 178），作为 TAMP 的决策变量

**定义 177（运动学/动力学可行性证书 KFC）** KFC = (r_reach, r_dyn, d_coll, b_bal, s_nh)。其中：
- `r_reach = min_t manip_margin(q(t))`：可操作度/奇异/关节限位余量
- `r_dyn = min_t min(v_max-|q̇|, a_max-|q̈|)`：速度/加速度余量
- `d_coll = min_t d(robot(t), O) - d_safe`：碰撞间隙余量
- `b_bal = min_t signed_dist(ZMP(t), ∂P_support)`：平衡余量
- `s_nh = max_t |非完整约束残差|`
- **验证**：`Valid(KFC) ⇔ r_reach≥0 ∧ r_dyn≥0 ∧ d_coll≥0 ∧ b_bal≥0 ∧ |s_nh|≤ε_nh`

**定义 178（基座放置语义 BPS）**
```
x_b* = argmax_{x_b ∈ SE(2)} [ α·M(x_b) + β·R(x_b) + γ·A_base(x_b) - δ·C_nav(x_b) ]
s.t.  x_b collision-free, stable(x_b), 存在从当前基座到 x_b 的非完整可行路径
```
其中 `M(x_b)=sqrt(det(J_arm(x_b)J_arm(x_b)^T))` 为移动可操作度，`R(x_b)` 为目标可达体积占比，`C_nav` 为导航代价。

**定义 179（规划预算 MPB 与 PCE++++++）** `B_cog6 = (B_scene, B_intent, B_ros, B_exec, B_mel, B_usr, B_plan)`。其中：
- `B_plan = (T_plan_max, N_samples, N_nodes, f_replan, Q_anytime)`
- **anytime 质量**：解代价 `c(t)` 单调不增；`c(t) ≤ c_target` 或预算耗尽即停
- **降级阶梯**：`TAMP-S(full) → RRT*(local) → WBIC(reactive) → safe_stop`
- **VOI 扩展**：`voi_cog6 = VOI_meta - cost_mel - cost_usr - cost_plan - cost_exec`

**定义 180（语义重规划触发 SRR）**
```
φ_replan(s) = (D_field > τ_field) ∨ EV_exec.anomaly
            ∨ (min(KFC.margins) < τ_margin) ∨ (Δb_intent > τ_intent)
```
- **重规划粒度**：安全触发 ⇒ 局部 WBIC 重解（≤1ms）；碰撞/余量触发 ⇒ 几何重规划（≤100ms）；场漂移/意图触发 ⇒ 任务重规划（≤1s）
- **优先级**：安全触发抢占语义触发；`SRR` 不得阻塞实时流

**定义 181（移动操作语义锚点 MSA，升级第 61 轮快照锚点）** `MSA_t = (ξ_b_t, F_t, coverage_t, version_t, drift_t)`：
- **查询式**：`scene_emb_t = F_t(ξ_b_t)`；基座移动时重查询而非重推理
- **覆盖触发**：若 `freshness(ξ_b_t) < τ_cov`（新视角/未覆盖区域），触发 MEL 对该区域局部重推理并融合进场
- **一致性**：版本号单调递增；场更新与查询遵循 SACP 原子读写协议

**定义 182（语义-运动联合证书 J_motion）**
```
J_motion = (J_sem_exec, KFC, τ_task, plan_cost, replan_count, field_version)
Valid(J_motion) ⇔ Valid(J_sem_exec) ∧ Valid(KFC) ∧ plan_cost ≤ c_target ∧ field_fresh
```

**定义 183（移动操作-运动规划闭环 SMMP）**
```
SMMP(M, obs, task):
  ① M.semf.update(obs, pose_wb) → F_t
  ② A ← M.saf.update(F_t, φ_phys)
  ③ x_b* ← M.bps.choose(A, task.target, pose_wb)
  ④ (τ, m) ← M.tamp.plan(task, A, x_b*, B_plan)
  ⑤ kfc ← M.kfc.evaluate(m); 若 ¬Valid(kfc) ⇒ 语义引导修复/重规划
  ⑥ z_wb ← M.wbic.compile(m, A, K_prior, φ_phys)
  ⑦ cert ← ERTC.dispatch(z_wb); EV_exec ← wait_contact()
  ⑧ 若 M.srr.trigger(F_t, EV_exec, kfc) ⇒ 按粒度重规划
  ⑨ USR/XMC+++ 更新; 签发 J_motion
```

**定义 184（语义-运动一致性 SAMC）**
```
D_motion = ‖A(ξ_exec) - A(ξ_plan)‖ + ‖[KFC.margins]₋‖ + ‖τ_exec - τ_plan‖
C_motion = exp(-D_motion / σ_m) ∈ [0,1]
```
其中 `[·]₋ = min(·,0)` 惩罚越界余量；`C_motion` 高表示执行轨迹忠实于语义规划轨迹。

### IP-183 SEMF（SE(3)-等变语义场）

```python
class SE3EquivariantSemanticField:
    def __init__(self, d_us=256, voxel=0.05, bounds=None):
        self.d_us = d_us
        self.grid = SparseVoxelGrid(voxel, bounds)      # 世界系稀疏体素
        self.encoder = SE3EquivariantEncoder(d_us)      # 相对位姿编码 + 帧平均
        self.coverage = CoverageMap(voxel)
        self.version = 0
        self.prev_snapshot = {}

    def update(self, obs, pose_wb):
        # obs: RGB-D + tactile + proprio；相对基座位姿编码，保证近似等变
        local = self.encoder.encode(obs, ref_pose=pose_wb)
        pts_world = transform(obs.depth_points, pose_wb)
        for vox, emb in fuse_points(pts_world, local):
            self.grid.bayesian_update(vox, emb)         # 语义-占据融合
            self.coverage.mark(vox)
        self.version += 1

    def query(self, pose_world):
        if self.grid.has(pose_world):
            emb = self.grid.get_embedding(pose_world)
            return emb, self.coverage.freshness(pose_world)
        return self.grid.nearest_embedding(pose_world), 0.0  # 低覆盖

    def drift(self, ref_poses):
        return np.mean([
            np.linalg.norm(self.grid.get(p) - self.prev_snapshot.get(p, self.grid.get(p)))
            for p in ref_poses
        ])

    def commit_snapshot(self, ref_poses):
        self.prev_snapshot = {p: self.grid.get(p) for p in ref_poses}
```

### IP-184 SAF（语义可供性场）

```python
class SemanticAffordanceField:
    def __init__(self, semf, mel, weights=(0.5, 0.3, 0.2)):
        self.semf, self.mel = semf, mel
        self.w = weights
        self.head_grasp = MLP(d_in=semf.d_us + 6, d_out=1)
        self.head_base = MLP(d_in=semf.d_us + 3, d_out=1)

    def grasp(self, xi, phi_phys):
        emb, fresh = self.semf.query(xi)
        return torch.sigmoid(self.head_grasp(cat([emb, phi_phys, fresh])))

    def base(self, xb, target):
        reach = self.reachability_volume(xb, target)
        clear = torch.sigmoid(self.semf.query(xb).emb.norm())
        stab = self.stability_margin(xb)
        return reach * clear * stab

    def trav(self, xy):
        emb, fresh = self.semf.query(se3(xy, yaw=0))
        return torch.sigmoid(self.head_base(cat([emb, [fresh]])))

    def composite(self, xi):
        return (self.w[0] * self.grasp(xi, self.mel.phi_phys)
                + self.w[1] * self.base(xi[:2], self.target)
                + self.w[2] * self.trav(xi[:2]))

    def gradient(self, xi):
        xi = xi.clone().requires_grad_(True)
        A = self.composite(xi)
        return torch.autograd.grad(A, xi)[0]
```

### IP-185 WBIC（全身阻抗编译）

```python
class WholeBodyImpedanceCompiler:
    def __init__(self, robot, dt=1e-3):
        self.robot, self.dt = robot, dt

    def compile(self, motion_ref, A, K_prior, phi_phys):
        # z = [v_b(3), omega_b(1), qdot(n), K_x(6), K_q(n)]
        z_prev = self.robot.current_whole_body_state()
        for k in range(len(motion_ref)):
            x_d, xdot_d = motion_ref[k]
            q, xb = self.robot.config_at(z_prev)
            J_task = whole_body_jacobian(q, xb)          # 全身任务雅可比
            z_sem = project_semantic_prior(K_prior, phi_phys, xb)  # USR 全身投影
            H = J_task.T @ W_task @ J_task + self.lam_sem * W_sem
            f = (-J_task.T @ W_task @ (xdot_d - J_task @ z_prev)
                 - self.lam_sem * W_sem @ z_sem)
            cons = [
                NonHolonomic(xb),                        # 差速/全向约束
                Balance(zmp_polygon(self.robot.support(xb))),  # ZMP/捕获点
                JointLimit(q), VelocityLimit(z_prev),
                CollisionAvoidance(self.robot, self.env, d_safe=0.05),
            ]
            z_prev = solve_qp(H, f, cons)                # 层级 QP
        return z_prev
```

### IP-186 TAMP-S（语义任务-运动规划）

```python
class SemanticTAMP:
    def __init__(self, robot, saf, budget):
        self.robot, self.saf, self.budget = robot, saf, budget

    def symbolic_plan(self, task):
        return task_planner(task.goal, task.initial_state)  # navigate/grasp/transport/place

    def sample(self, beta=2.0):
        for _ in range(self.budget.N_samples):
            q = uniform(self.robot.C_free)
            if random() < accept(self.saf.composite(fk(q)), beta):
                return q
        return uniform(self.robot.C_free)                   # 保底：保持概率完备

    def rrt_star_semantic(self, q0, qg, arm_only=False):
        tree = Tree(q0)
        while not self.budget.exhausted():
            q_rand = self.sample()
            q_near = tree.nearest(q_rand)
            q_new = steer(q_near, q_rand)
            if self.robot.collision_free(q_near, q_new):
                tree.add(q_new, parent=q_near)
                tree.rewire(q_new, self.sem_cost)            # 可供性引导代价
        return tree.best_path_to(qg)

    def sem_cost(self, m):
        pts = [fk(q) for q in m.waypoints]
        return (np.trapz([1 - self.saf.composite(p) for p in pts])
                + self.lam_len * path_length(m))

    def plan(self, task, A, xb_star, B_plan):
        plan, sym_seq = [], self.symbolic_plan(task)
```

```python
class KinodynamicFeasibilityCertificate:
    def evaluate(self, motion, robot, env):
        r_reach = min(manip_margin(q) for q in motion)
        r_dyn = min(min(robot.v_max - abs(qd), robot.a_max - abs(qdd))
```

```python
class SE3EquivariantSemanticField:
    def __init__(self, d_us=256, voxel=0.05, bounds=None):
        self.d_us = d_us
        self.grid = SparseVoxelGrid(voxel, bounds)      # 世界系稀疏体素
        self.encoder = SE3EquivariantEncoder(d_us)      # 相对位姿编码 + 帧平均
        self.coverage = CoverageMap(voxel)
        self.version = 0
        self.prev_snapshot = {}

    def update(self, obs, pose_wb):
        local = self.encoder.encode(obs, ref_pose=pose_wb)  # 近似等变
        pts_world = transform(obs.depth_points, pose_wb)
        for vox, emb in fuse_points(pts_world, local):
            self.grid.bayesian_update(vox, emb)         # 语义-占据融合
            self.coverage.mark(vox)
        self.version += 1

    def query(self, pose_world):
        if self.grid.has(pose_world):
            emb = self.grid.get_embedding(pose_world)
            return emb, self.coverage.freshness(pose_world)
        return self.grid.nearest_embedding(pose_world), 0.0

    def drift(self, ref_poses):
        return np.mean([
            np.linalg.norm(self.grid.get(p) - self.prev_snapshot.get(p, self.grid.get(p)))
            for p in ref_poses
        ])

    def commit_snapshot(self, ref_poses):
        self.prev_snapshot = {p: self.grid.get(p) for p in ref_poses}
```

### IP-184 SAF（语义可供性场）

```python
class SemanticAffordanceField:
    def __init__(self, semf, mel, weights=(0.5, 0.3, 0.2)):
        self.semf, self.mel, self.w = semf, mel, weights
        self.head_grasp = MLP(d_in=semf.d_us + 6, d_out=1)
        self.head_base = MLP(d_in=semf.d_us + 3, d_out=1)

    def grasp(self, xi, phi_phys):
        emb, fresh = self.semf.query(xi)
        return torch.sigmoid(self.head_grasp(cat([emb, phi_phys, fresh])))

    def base(self, xb, target):
        reach = self.reachability_volume(xb, target)
        clear = torch.sigmoid(self.semf.query(xb).emb.norm())
        stab = self.stability_margin(xb)
        return reach * clear * stab

    def trav(self, xy):
        emb, fresh = self.semf.query(se3(xy, yaw=0))
        return torch.sigmoid(self.head_base(cat([emb, [fresh]])))

    def composite(self, xi):
        return (self.w[0] * self.grasp(xi, self.mel.phi_phys)
                + self.w[1] * self.base(xi[:2], self.target)
                + self.w[2] * self.trav(xi[:2]))

    def gradient(self, xi):
        xi = xi.clone().requires_grad_(True)
        return torch.autograd.grad(self.composite(xi), xi)[0]
```

### IP-185 WBIC（全身阻抗编译）

```python
class WholeBodyImpedanceCompiler:
    def __init__(self, robot, dt=1e-3):
        self.robot, self.dt = robot, dt

    def compile(self, motion_ref, A, K_prior, phi_phys):
        # z = [v_b(3), omega_b(1), qdot(n), K_x(6), K_q(n)]
        z_prev = self.robot.current_whole_body_state()
        for k in range(len(motion_ref)):
            x_d, xdot_d = motion_ref[k]
            q, xb = self.robot.config_at(z_prev)
            J_task = whole_body_jacobian(q, xb)          # 全身任务雅可比
            z_sem = project_semantic_prior(K_prior, phi_phys, xb)  # USR 全身投影
            H = J_task.T @ W_task @ J_task + self.lam_sem * W_sem
            f = (-J_task.T @ W_task @ (xdot_d - J_task @ z_prev)
                 - self.lam_sem * W_sem @ z_sem)
            cons = [
                NonHolonomic(xb),                          # 差速/全向约束
                Balance(zmp_polygon(self.robot.support(xb))),  # ZMP/捕获点
                JointLimit(q), VelocityLimit(z_prev),
                CollisionAvoidance(self.robot, self.env, d_safe=0.05),
            ]
            z_prev = solve_qp(H, f, cons)                  # 层级 QP：硬约束优先
        return z_prev
```

### IP-186 TAMP-S（语义任务-运动规划）

```python
class SemanticTAMP:
    def __init__(self, robot, saf, budget):
        self.robot, self.saf, self.budget = robot, saf, budget

    def symbolic_plan(self, task):
        return task_planner(task.goal, task.initial_state)  # navigate/grasp/transport/place

    def sample(self, beta=2.0):
        for _ in range(self.budget.N_samples):
            q = uniform(self.robot.C_free)
            if random() < accept(self.saf.composite(fk(q)), beta):
                return q
        return uniform(self.robot.C_free)                    # 保底：保持概率完备

    def rrt_star_semantic(self, q0, qg, arm_only=False):
        tree = Tree(q0)
        while not self.budget.exhausted():
            q_rand = self.sample()
            q_near = tree.nearest(q_rand)
            q_new = steer(q_near, q_rand)
            if self.robot.collision_free(q_near, q_new):
                tree.add(q_new, parent=q_near)
                tree.rewire(q_new, self.sem_cost)             # 可供性引导代价
        return tree.best_path_to(qg)

    def sem_cost(self, m):
        pts = [fk(q) for q in m.waypoints]
        return (np.trapz([1 - self.saf.composite(p) for p in pts])
                + self.lam_len * path_length(m))

    def plan(self, task, A, xb_star, B_plan):
        plan, sym_seq = [], self.symbolic_plan(task)
        for act in sym_seq:
            if act == 'navigate':
                m = self.rrt_star_semantic(self.robot.base_pose, xb_star)
            else:
                m = self.rrt_star_semantic(self.robot.config,
                                           self.robot.grasp_config(act), arm_only=True)
            plan.append((act, m))
            if B_plan.exhausted():
                return plan, 'partial'
        return plan, 'complete'
```

```python
class KinodynamicFeasibilityCertificate:
    def evaluate(self, motion, robot, env):
        r_reach = min(manip_margin(q) for q in motion)
        r_dyn = min(min(robot.v_max - abs(qd), robot.a_max - abs(qdd))
                    for qd, qdd in motion.derivatives())
        d_coll = min(robot.distance(q, env) for q in motion) - robot.d_safe
        b_bal = min(zmp_signed_distance(q, robot.support(q)) for q in motion)
        s_nh = max(abs(nonholonomic_residual(q)) for q in motion)
        return KFC(r_reach, r_dyn, d_coll, b_bal, s_nh)

    def valid(self, k):
        return (k.r_reach >= 0 and k.r_dyn >= 0 and k.d_coll >= 0
                and k.b_bal >= 0 and abs(k.s_nh) <= 1e-3)

class BasePlacementSemantics:
    def choose(self, saf, target, current_base):

        def score(xb):
            return (self.alpha * mobile_manipulability(xb, target)
                    + self.beta * reachable_volume(xb, target)
                    + self.gamma * saf.base(xb, target)
                    - self.delta * nav_cost(current_base, xb))
```

```python
class PlanningBudget:
    def __init__(self, t_max=1.0, n_samples=5000, n_nodes=10000,

        return self.t_used >= self.t_max or self.n_used >= self.n_samples

class SemanticReplanTrigger:
    def trigger(self, semf, ev_exec, kfc):
        drift = semf.drift(self.ref_poses)
        if min(kfc.margins) < self.tau_margin or ev_exec.collision_risk:
            return 'reactive'        # 安全触发，抢占语义触发
        if drift > self.tau_field or ev_exec.anomaly:
            return 'geometric'
        if ev_exec.intent_changed:
            return 'task'
        return None

def SMMP(M, obs, task):
    M.semf.update(obs, M.pose_wb)
    A = M.saf.update(M.semf, M.mel.phi_phys)
    xb_star = M.bps.choose(A, task.target, M.pose_wb)
    plan, status = M.tamp.plan(task, A, xb_star, M.budget.B_plan)

    kfc = M.kfc.evaluate([q for _, m in plan for q in m], M.robot, M.env)
    if not M.kfc.valid(kfc):
        plan = M.tamp.repair(plan, kfc, A)               # 语义引导修复
        kfc = M.kfc.evaluate([q for _, m in plan for q in m], M.robot, M.env)
        if not M.kfc.valid(kfc):
            return M.safe_stop()

    for act, motion in plan:
        for q_ref in motion:
            z_wb = M.wbic.compile([q_ref], A, M.K_prior, M.mel.phi_phys)
            cert = M.ertc.dispatch(z_wb)
            EV = wait_contact_and_build_evidence()
            scope = M.srr.trigger(M.semf, EV, kfc)
            if scope == 'reactive':
                continue                                  # 局部重解，不中断
            if scope in ('geometric', 'task'):
                return SMMP(M, obs, task)                 # 重规划
    return build_j_motion(cert, kfc, plan, M.semf.version)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SEMF | 更新 O(N_vox) / 查询 O(1) 哈希 | O(N_vox × d_us) | 等变误差 ≤ ε_eq；覆盖新鲜度可判定 |
| SAF | 查询 O(d_us)；梯度 O(d_us) | O(d_us) | Lipschitz 连续；可供性排序 AUC ≥ 0.8 |
| WBIC | 层级 QP O(n³)，n≈20–40，~0.5ms | O(n²) | QP 强凸可行 ⇒ 唯一解，ZMP 在支撑多边形内 |
| TAMP-S | RRT\* O(N log N) 期望；anytime | O(N_nodes) | 语义采样保持概率完备；解代价单调不增 |
| KFC | O(T) 轨迹检查 | O(T) | 五类余量全非负 ⇒ 运动可行 |
| BPS | O(N_cand) 候选评估 | O(N_cand) | 约束内取最优，非完整路径存在 |
| MPB | O(1) 预算检查 | O(1) | 任一维度耗尽 ⇒ 安全降级 |
| SMMP | 端到端 ~10–100ms（规划）+ 实时流 1–10kHz | 共享内存 ~10MB | 任一 SRR 触发 ⇒ 安全降级 |

**正确性定理（SMMP-Complete）**：
假设 A61–A70 及 **(A71)** SEMF：近似 SE(3)-等变误差 ≤ ε_eq，贝叶斯语义-占据融合收敛，覆盖度新鲜度可判定。**(A72)** SAF：复合可供性 C¹ 且 Lipschitz，`‖∇A‖ ≤ L_A`，可供性排序与真实抓取/通行成功率单调相关。**(A73)** WBIC：层级 QP 在约束可行域内强凸，求解 ≤ 0.5ms，硬约束优先于语义软目标。**(A74)** TAMP-S：语义信息采样的接受率有正下界 ⇒ 保持概率完备；anytime 解代价单调不增。**(A75)** KFC/SRR：证书计算 O(T)，触发谓词安全优先且局部重规划 ≤ 1ms。

则：
1. **视角一致性**：基座移动下 `scene_emb = F_t(ξ_b)` 与真实场景语义误差 ≤ ε_eq + ε_cov，快照失效问题被消除。
2. **运动学/动力学可行性**：`Valid(KFC)` ⇒ 轨迹无碰、平衡、非完整与关节/速度约束全部满足。
3. **规划效率与完备性**：语义采样不破坏 RRT\* 概率完备性；期望规划时间 ≤ 非语义基线的 1/3。
4. **全身稳定性**：WBIC 的 QP 可行 ⇒ ZMP/捕获点在支撑多边形内，阻抗跟踪误差有界。
5. **闭环安全**：任一 SRR 触发 ⇒ 按安全优先级降级（局部重解/几何重规划/停止），不违反 ERTC 实时契约。
6. **语义-运动一致性**：`C_motion` 高 ⇒ 执行轨迹忠实于语义规划，语义启发式不越运动学红线。

## 5. 本轮最大风险

**一句话**：若 SEMF 的近似 SE(3)-等变误差在长距离基座移动后累积、SAF 将高可供性区域错误排序、或 TAMP-S 在动态障碍下返回「语义上合理但 KFC 余量极小」的 anytime 轨迹，而 SRR 的语义触发又慢于基座-机械臂耦合动力学的失稳时间尺度，就会在运输/放置阶段出现「规划看起来对、执行却撞上或失稳」的**语义-运动-动力学三重错位**；必须以「SEMF 等变误差在线上界估计 + SAF 校准与 OOD 检测 + KFC 硬门控（安全优先于语义）+ SRR 安全触发抢占 + WBIC 层级 QP 的零空间语义注入」构建运动级安全护栏，确保语义启发式永不越过运动学/动力学可行性红线。
