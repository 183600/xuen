# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互的不确定性二分闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「联邦学习」×「动作分块」）

> R69 把不确定性拆成 aleatoric / epistemic，并给系统装上一张嘴（主动交互）和一只鼻子（流似然第二意见）。但 R69 的认识论仍然是**单机**的：它只向「自己的」人类与环境求证，知识也只从「自己的」数据流里长出来。两个盲点随之暴露：
>
> 1. **最不知情的可能正是本机**。同一任务在机队里可能已有成百上千次经验，R69 的 VoI 却从不把「问机队」列为信息动作——它宁可追问一个近处的人，也不去借远处一百台机器的共识。
> 2. **动作分块（action chunk）既是执行单位，也是天然的共享单位**。块可以被传输、合并、拼接、回放，于是联邦学习能以极低带宽共享「行为知识」。但块是**有时间的**：不同客户端的块在速度、相位、本体上都不对齐；把块直接做 FedAvg，会平均出谁都不会执行的「幽灵块」。
>
> 更关键的是，R69 刚刚证明「绕左还是绕右」是两个必须被显式保留的模态；联邦版会把它们平均成「直直撞上去」。**安全集是非凸的，安全不可组合**：两个各自认证安全的块，拼起来或平均起来可能不安全。
>
> 核心命题：**把动作块当作联邦的基本货币；联邦不是「平均」，而是「先判同异、再对齐、簇内重心、簇间混合」；每一块共享都要付隐私与通信的租金，每一次聚合都要重做安全认证；机队共识只作为 R69 的第三条证据通道 r_fed，永不单独定案。** 命名 **FACT-RAS**（Federated Action-Chunk Trust for Risk-Adaptive Systems）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**机队知道什么，它的知识可信吗，值多少隐私与通信代价**」——知识可以借，但借来的知识有出处、有利息，也可能大家一起错。

## 0. 直觉与动机

**灵感 1（联邦学习 → 知识可以借，但「聚合 ≠ 真理」）**
直觉：联邦学习最动人的口号是「数据不动，模型动」。但它藏着一个危险的等号：把多方知识平均起来，就当作共同真理。在独立同分布假设下这近似成立；在真实的非 IID 机队里——不同任务、不同本体、不同传感器、不同人类——平均会把互不相容的经验揉成一个谁都不认的中间物。对安全攸关的具身系统，机队先验不是「权威」，而是**一条有出处的证据**：它可以帮你更快消歧，但必须带着来源、时效、校准和隐私账本一起被审计。R70 的第一姿态就是把这个等号拆掉。

**灵感 2（动作分块 → 时间是联邦的货币）**
直觉：动作分块同时解决了三件事：时间抽象、复合误差、通信频率。于是一个「块」天然成为联邦的**记账单位**——我们不是同步整个策略，而是隔一段时间交换若干个块原型。块长 L 立刻变成一个新的三向旋钮：通信开销 ∝ 1/L（块越长，发得越少），隐私泄漏 ∝ L（块越长，指纹越长、覆盖的时间步越多），知识陈旧 ∝ L（块越长，用旧知识执行得越久）。R69 只把块用于「生成」，R70 第一次把块用于「交易」，并由此推导出 L 的最优档位。

**灵感 3（非 IID 是 R69 二分在机队上的重演）**
直觉：R69 把单机不确定性分成 aleatoric（同一模态内的噪声，可平均）与 epistemic（不同模态，必须保留）。机队异构性有完全相同的二分：客户端的差异要么是**计量异构**（同一行为，采样/本体噪声不同 → 该合并、做重心），要么是**结构异构**（不同技能/任务/本体 → 绝不能合并，应作为全局图集里的不同模态并存）。朴素 FedAvg 把一切差异当计量异构，于是抹掉结构、造出幽灵。**「先聚类、后合并」正是 R69 的 U_ale/U_epi 二分在联邦层的镜像**——这是本轮最干净的理论桥。

**灵感 4（相位漂移会冒充异质性）**
直觉：不同机器的块在时间上被拉伸、平移。若不先做相位对齐，「同一招」会因快慢不同被判成两招（假分裂）；而「不同招」也可能在时间规整后变得很像（假合并）。也就是说，**不做相位对齐的联邦，测到的是时钟差，不是知识差**。因此对齐必须发生在异质性检验与聚合之前；否则后面所有统计都建立在错误的坐标系上。这是本轮最容易被忽略、却最致命的技术点。

**灵感 5（安全不可组合 → 联邦的新威胁模型）**
直觉：两个块各自通过 C-RAS-WM，不代表它们的平均或拼接也通过——安全集一般非凸，「向左躲」与「向右躲」各自安全，平均就是「撞上去」。再加上恶意客户端可以提交**个体安全但整体带偏**的块，Sybil 可以用多个身份击穿基于计数的稳健统计；长块与重叠块会让隐私泄漏按覆盖次数复合。所以 R70 必须同时交付：同异判别、相位对齐、簇内重心/簇间混合、安全可组合的聚合、块长隐私账本、来源与信任门、以及「共识 ≠ 真相」的多样性核算。否则 R70 不是让机队变聪明，而是让系统**更自信地一起错**。

**定义 312（带个人残差的联邦目标）** 参数分解 θ_i = θ_s + δ_i，目标
min_{θ_s,{δ_i}} Σ_i p_i E_{ξ~P_i}[ℓ(ξ; θ_s+δ_i)] + λ_reg‖δ_i‖² + Comm(m_i) + Privacy(ε_i)。
θ_s 全局共享，δ_i 只留本地。个人残差是「借用」与「自主」的显式分离。

**定义 313（相位规范化）** 对块 ξ 取单调时间重参数化 φ ∈ Φ（DTW/Fréchet 最优路径），规范块 C(ξ) = ξ∘φ*，对齐残差 r_φ = d(ξ, C(ξ))。定义对齐归一化距离 d_φ(P_i,P_j) = d(C(P_i), C(P_j))。**先对齐、后比较/聚合**是所有后续算子的前提。

**定义 314（传输兼容性检验：联邦版的 U_ale/U_epi）** 对两簇对齐后的块分布，取能量距离或 Sinkhorn 散度
D_E(P_i,P_j) = 2E‖X−Y‖ − E‖X−X'‖ − E‖Y−Y'‖。
原假设 H0：同一行为模态（计量异构）。若 D_E > τ_D（τ_D 由置换检验/保形分位标定），判为**结构异构**，必须分簇。等价地：H0 成立 → 可合并（aleatoric）；拒绝 → 只能混合（epistemic）。

**定义 315（先聚类后合并的全局图集）** 用定义 314 的单链接/凝聚聚类得簇 {C_k}。簇内取 2-Wasserstein 重心
μ_k = argmin_μ Σ_{i∈C_k} w_i W₂²(P_i, μ)；
簇间保留混合而非重心：全局图集 A = {(μ_k, ω_k, provenance_k, envelope_k)}，ω_k = Σ_{i∈C_k} w_i。**图集是多模态的，不是单峰平均。** 这是拒绝「幽灵块」的核心。

**定义 316（来源与信任权重）** 客户端来源元组 p_i = (证书哈希, 本体描述子, 校准 ECE_i, 时效 t_i, DP 账本, 历史可靠性)。聚合权重
w_i = softmax_i( relevance(o_t, p_i) · calibration_i · recency_i · trust_i )，
其中 relevance 为本体/任务嵌入距离，recency 为时效衰减。来源不可核对者权重为 0。

**定义 317（拜占庭稳健聚合 BRT）** 先以 W₂ 中位数为中心，剔除最远的 f 个客户端，再在剩余集合上做重心。破坏点 δ* = f/n，偏差上界 ≤ (f/(n−f))·diam(A)。**前提是身份唯一**；Sybil 攻击下计数稳健性失效，须叠加身份证明与单客户端贡献上限。

**定义 318（安全组合缺口与可组合聚合）** 记 Safe(ξ) 为 C-RAS-WM 认证通过。一般地
Safe(ξ_A) ∧ Safe(ξ_B) ⇏ Safe(merge(ξ_A,ξ_B))。
定义安全缺口 g_safe = max_{合法合并} risk(merge) − max_i risk(ξ_i)。只有满足 (a) 安全包络为凸且二者都在包络内，或 (b) 合并结果经服务器侧重新认证，才允许合并；否则只能作为两个模态并存。

**定义 319（拼接证书）** 跨簇/跨客户端拼接块时，须满足边界 C0（位置）、C1（速度）连续、力/冲量界、时间窗有效，且整体过 C-RAS-WM：stitch_risk ≤ ε_stitch。**拼接本身是一个新动作，必须有自己的证书**；不通过则丢弃拼接，不做「凑合」。

**定义 320（块差分隐私与重叠记账）** 块贡献裁剪到范数 Δ_chunk(L)；高斯机制给 (ε_i, δ_i) 预算。若每 c 步提交一次、块覆盖 L 步，则每个时间步被 ⌈L/c⌉ 个块覆盖；**重叠块不产生隐私放大**（样本相关），须按组合定理/群隐私记账，泄漏量正比于 L/c。非重叠共享才享有放大效应。

**定义 321（块长三方折中与最优 L*）** 单位时间总代价
C(L) = a/L（通信轮次） + bL（隐私噪声/效用损失） + dL（陈旧漂移） + e(L/c)（重叠泄漏）。
在 A99（裁剪范数 ~√L、漂移有界）下最优块长
L* = sqrt( a / (b + d + e/c) )，s.t. L ≥ c。
**块长不是控制参数，而是控制×隐私×通信的联合设计变量。**

**定义 322（机队证据通道 FEV）** 给定观测上下文 o_t，机队预测 p_fed(m|o_t) = Σ_k ω_k K(o_t; μ_k)，共识熵 H_fed = H(p_fed)，惊讶度 r_fed = −log p_fed(m_local)。r_fed 与 R69 的 r_res（传感器自洽）、Δa（行为似然）构成三条通道；但**正交性必须是有效正交性** ρ_eff（由共享盲区/共同训练源/协同投毒估计），而不是「来源不同」的名义正交。

# IP-264 FACT-CHD：相位对齐 + 传输兼容性检验 + 聚类（联邦版 U_ale/U_epi）
def chunk_heterogeneity(chunks_by_client, tau_D):
    canon = {i: align_phase(ps) for i, ps in chunks_by_client.items()}   # DTW/Fréchet
    clusters = agglomerative(
        canon,
        test=lambda Pi, Pj: energy_distance(Pi, Pj) <= tau_D,            # H0: 同一行为模态
    )
    return canon, clusters      # 同簇 = 计量异构（可合并）；跨簇 = 结构异构（只能混合）

# IP-265/267 FACT-ATP/BRT：簇内 W2 重心、簇间保留混合（拒绝幽灵块）
def cluster_then_merge(canon, clusters, weights, clients, f_trim):
    atlas = []
    for C in clusters:
        C_robust = trim_farthest(C, f_trim, ref=w2_median(C))            # 拜占庭剔除
        mu_k = w2_barycenter([canon[i] for i in C_robust],
                             [weights[i] for i in C_robust])             # 簇内重心
        env  = intersect_envelopes(C_robust)                            # 安全包络交集
        atlas.append({
            "mu": mu_k,
            "omega": sum(weights[i] for i in C_robust),
            "provenance": [clients[i].provenance for i in C_robust],
            "envelope": env,
        })
    return atlas                 # 全局图集 = 多模态混合，而非单一平均

# IP-268 FACT-SCA：聚合/拼接必须重新认证（安全不可组合）
def certified_merge(xi_a, xi_b, state):

# IP-269 FACT-DPL：块长 L 的三方折中（通信 / 隐私 / 陈旧 / 重叠）
def choose_chunk_length(comm_a, priv_b, stale_d, overlap_e, c):
    L_star = sqrt(comm_a / (priv_b + stale_d + overlap_e / c))
    return clip(L_star, c, L_max)          # 发送用 L，执行只提交 c 步

# IP-270/271 FACT-FEV/FTG：机队作为第三证据源，且必须过信任门
def fleet_evidence(atlas, o_t, local_mode):

            "rho_eff": estimate_effective_independence(atlas)}

## 3. 推导

**引理 19（幽灵块与聚类门）** 设两簇块分布近似为 N(μ₁,σ²I)、N(μ₂,σ²I)，间距 Δ=‖μ₁−μ₂‖。若强行做重心合并，得到位于中点的块，它到两个真实模态的马氏距离均为 Δ/(2σ)；当 Δ ≥ cσ 时，该中点块在两个模态下的密度都远低于峰值的 exp(−c²/8)。反之保留为混合，两模态质量完整。**故「先聚类、后合并」不是工程技巧，而是防止在无数据处凭空造出可执行块的统计必然。** 系：能量距离检验在 Δ/σ ≳ c·n^{−1/4} 时以高概率判出结构异构（n 为每客户端样本数）。

**引理 20（相位对齐的混杂性）** 若同一技能被时间规整 φ 拉伸，未对齐距离满足 d(ξ,ξ∘φ) ≥ c·‖φ−id‖·speed，可在真实分布相同（D_true=0）时越过 τ_D，造成假分裂；反之不同技能可因规整而靠近，造成假合并。故 **相位对齐是异质性检验的可识别性条件**：不对齐，「非 IID 判别器」测的是时钟而非知识。

**引理 21（截尾重心的稳健性边界）** 在至多 f 个恶意客户端、身份唯一的假设下，截尾 W₂ 重心的破坏点 δ*=f/n，偏差 ≤ (f/(n−f))·diam(A)。若攻击者可制造 Sybil 身份，则基于计数的截尾失效，偏差可任意大；须以身份证明、单客户端贡献上限与 DP 裁剪共同恢复上界。

**引理 22（块长—隐私—通信—陈旧的四向折中）** 在 A99 下，单位时间代价 C(L)=a/L + (b+d)L + eL/c，最优 L* = sqrt(a/(b+d+e/c))。重叠块使每步被 ⌈L/c⌉ 个块覆盖，**不产生隐私放大**，泄漏正比于 L/c；故隐私约束下应尽量取非重叠或低重叠共享，把「提交视界 c」与「共享块长 L」解耦。

**引理 23（安全不可组合）** 安全集 S 一般非凸。取一维反例 S={x≤−1}∪{x≥1}，ξ_A=−2、ξ_B=+2 均安全，而 (ξ_A+ξ_B)/2=0 不安全；在轨迹上即「向左躲/向右躲各自安全，平均则直撞障碍」。因此 Safe 在凸组合下不封闭，g_safe 可任意大；只有凸包络或服务器重认证能恢复保证。

**定理 18（FACT 严格包含 R69/FLUID-RAS）** 当 FTG 不通过（ECE/相关度/时效/剔除/多样性/DP 任一越界）、或不存在低于 τ_D 的兼容簇、或聚合/拼接重认证失败、或 r_fed 与本地一致（无新增信息）时，FACT 的控制路径与 FLUID-RAS **逐指令相同**。r_fed 单独不授予 resolution bonus，只作为 k 正交证据之一；故安全下界不弱于 R69，效率侧仅在「机队证据 + 本地证据一致且门控通过」时获得加速。

**定理 19（相关共识不增加置信度）** 设机队错误率为 δ_fed，有效独立性 ρ_eff，采用 k 源多数一致纪律时错误采纳率 ≤ δ_fed·ρ_eff^{k−1}+ε_σ。当 ρ_eff → 1（所有客户端共享同一盲区或同一投毒源），该上界退化为 δ_fed，**不随 k 改善**；此时 FTG 的多样性门必须把 r_fed 权重压到 0 并回退 R69。系：**机队的价值来自独立错误，而不是一致意见本身。**

**定理 20（联邦端到端代价）** 在 L-光滑、簇内异质性有界 B、DP 噪声 σ_dp、块陈旧漂移率 κ 下，图集收敛误差满足
E‖θ_T−θ*‖² ≲ O(1/√T) + O(B²) + O(σ_dp²) + O((κL)²)，
四类误差分别对应「轮数、结构异构、隐私、陈旧」。**四者不可能同时最小**；定义 321 的 L* 与定义 315 的分簇是唯一能显式分配这四项代价的杠杆。

## 6. 本轮最大风险

**一句话**：联邦不会把错误平均掉，它可能把**同一个错误复制 k 份**——当所有客户端共享同一训练源、同一传感器偏置或同一个投毒者时，它们会来源不同却错误相关，FTG 看到的「校准良好、来源多样」只是表象；于是 R69 的证据纪律把「同源」误当「正交」，机队共识被当成独立佐证，系统在**集体错误**上获得 resolution bonus——**共识越强，越可能一起错。**

**次级风险与缓解**：
1. **隐私泄漏（长块/重叠块）** → 定义 320 记账 + 非重叠共享优先 + 定义 321 的 L* + E307；
2. **安全不可组合（平均/拼接越界）** → 定义 318 服务器重认证 + 定义 319 拼接证书 + 引理 23 + E306；
3. **拜占庭与 Sybil** → 定义 317 截尾重心 + 身份证明 + 贡献上限 + 引理 21 + E305；
4. **负迁移/非 IID** → 定义 312 共享+个人残差 + 定义 314 结构异构分簇 + E304；
5. **陈旧与灾难性遗忘** → 定义 325 半衰期与单文化指数 + 版本化图集 + E309/E313。

def chunk_heterogeneity(chunks_by_client, tau_D):

## 4. 推导

**引理 19（幽灵块与聚类门）** 两簇近似 `N(μ₁,σ²I)`、`N(μ₂,σ²I)`、间距 Δ。强行重心合并得到中点块，其到两真实模态的马氏距离均为 Δ/(2σ)；当 Δ≥cσ 时，该块在两模态下密度都低于峰值 `exp(−c²/8)`。保留混合则两模态质量完整。故「先聚类后合并」是防止在无数据处凭空造出可执行块的统计必然。系：能量距离检验在 `Δ/σ ≳ c·n^{−1/4}` 时高概率判出结构异构。

**引理 20（相位对齐的可识别性）** 同一技能被 φ 拉伸时，未对齐距离 `≥ c·‖φ−id‖·speed`，可在真实分布相同时越过 τ_D 造成假分裂；不同技能也可能因规整而靠近造成假合并。**不对齐，非 IID 判别器测的是时钟，不是知识。**

**引理 21（截尾重心上界）** 身份唯一、至多 f 个恶意客户端时，破坏点 `δ*=f/n`，偏差 `≤(f/(n−f))·diam(A)`。Sybil 下计数稳健性失效，偏差可任意大；须靠身份证明、贡献上限、DP 裁剪恢复。

**引理 22（块长四向折中）** A99 下 `C(L)=a/L+(b+d)L+eL/c`，`L*=sqrt(a/(b+d+e/c))`。重叠块每步被 `⌈L/c⌉` 个块覆盖且**不放大隐私**，泄漏正比于 L/c；应把「提交视界 c」与「共享块长 L」解耦。

**引理 23（安全不可组合）** 一维反例 `S={x≤−1}∪{x≥1}`：`ξ_A=−2, ξ_B=+2` 均安全，均值 0 不安全；轨迹上即「向左躲/向右躲各自安全，平均则直撞障碍」。故 Safe 在凸组合下不封闭，`g_safe` 可任意大；只有凸包络或服务器重认证能恢复保证。

**定理 18（FACT 严格包含 R69）** 当 FTG 任一维越界、或无可兼容簇、或聚合/拼接重认证失败、或 r_fed 与本地一致时，FACT 与 FLUID-RAS **逐指令相同**。r_fed 单独不授予 resolution bonus，只作 k 正交证据之一；安全下界不弱于 R69。

**定理 19（相关共识不增加置信度）** 机队错误率 δ_fed、有效独立性 ρ_eff、k 源多数一致时，错误采纳率 `≤ δ_fed·ρ_eff^{k−1}+ε_σ`。当 `ρ_eff→1`，上界退化为 δ_fed，**不随 k 改善**；FTG 多样性门须将 r_fed 权重压到 0 并回退 R69。系：**机队的价值来自独立错误，而非一致意见本身。**

**定理 20（联邦端到端代价）** L-光滑、簇内异质性有界 B、DP 噪声 σ_dp、陈旧漂移率 κ 下，图集收敛误差 `≲ O(1/√T)+O(B²)+O(σ_dp²)+O((κL)²)`，分别对应轮数、结构异构、隐私、陈旧；四者不能同时最小，定义 315 的分簇与定义 321 的 L* 是显式分配这四项代价的杠杆。

## 7. 本轮最大风险

**一句话**：联邦不会把错误平均掉，它可能把**同一个错误复制 k 份**——当所有客户端共享同一训练源、同一传感器偏置或同一个投毒者时，它们来源不同却错误相关；FTG 看到的「校准良好、来源多样」只是表象，R69 的证据纪律于是把「同源」误当「正交」，系统在**集体错误**上获得 resolution bonus——**共识越强，越可能一起错。**

**次级风险与缓解**：隐私泄漏（定义 320 记账 + 非重叠优先 + L* + E307）；安全不可组合（定义 318 重认证 + 定义 319 拼接证书 + 引理 23 + E306）；拜占庭/Sybil（定义 317 截尾 + 身份证明 + 贡献上限 + E305）；负迁移（定义 312 共享+残差 + 定义 314 分簇 + E304）；陈旧与遗忘（定义 325 半衰期/单文化 + 版本化图集 + E309/E313）。
