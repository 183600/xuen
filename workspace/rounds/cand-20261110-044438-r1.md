# 第 41 轮 · 双灵感落地 v8：把「何时」变成一等证书——时序技能契约 × 混合关键级智能体运行时 × 陈旧感知实时安全（四层架构 v6）

> 承接第 40 轮（v17：可认证流匹配执行 × 度量语义几何锚定 × 证书驱动课程引擎，四层架构 v5）。本轮灵感词「智能体、实时控制」不新增传感器或执行器，而是补上 v17 证书体系唯一缺席的维度——**时间**。v17 认证了「做什么动作、在哪儿安全、抓没抓住」，却把「来不来得及」留给了 latency_p99 这类统计指标。本轮把「何时」提升为一等证书：智能体负责提出计划，运行时负责在硬截止期内交付一个**已认证**的动作，或退回一个**已认证**的兜底动作。

## 0. 直觉与动机

**灵感 1（智能体 → 会思考的部分必须在环外，但它的提案必须在环内可接纳）**：具身智能体的认知回路是「感知→推理→调工具→规划→再感知」，其耗时是**重尾、非确定、可长可短**的；能力越强（大 VLM/LLM、多步反思、检索、工具调用），思考越久、方差越大。但机器人安全只认毫秒级反应。直觉上正确的分工不是「让智能体直接发控制指令」，而是：**智能体是提案者（supervisor），运行时是处置者（real-time control plane）**。智能体可以慢、可以错、可以中断；运行时必须永远在截止期内给出一个**带证书**的动作。这颠倒了常见的「agent 调用工具」叙事——变成「工具/技能总线准入 agent 的提案」。一个提案只有带上「截止期 + 质量下界 + 有效时域」三件套，才允许进入执行层。

**灵感 2（实时控制 → 不是推理更快，而是在截止期下的可证保证）**：实时控制的核心从来不是「低延迟」这个形容词，而是三件可证明的事：a) **可调度性**（EDF/速率单调的利用率条件，保证每个硬任务不误期）；b) **混合关键级**（预算收紧时按关键级降级：先砍软任务，永不砍硬任务）；c) **采样/自触发控制的时延代价**（状态越旧，安全裕度按环境变化速率衰减，所以「下一次感知」本身有截止期）。把这三件事套到智能体上：它的 deliberation 被当作软实时任务调度；系统在压力下按关键级降级；感知/重规划由控制论的「安全年龄」触发，而不是固定频率轮询。关键洞察：**时延不是中性的延迟，而是对安全裕度的确定性扣减**，因此可以被证书化。

**灵感 3（耦合 → 用「时间契约」把慢智能体与快控制器焊成一个双层控制系统）**：`agent proposes, runtime disposes` 需要一个共享货币，这个货币就是**时序证书**（deadline slack + validity horizon）。外层是任务级智能体（慢、软实时、优化任务价值），内层是认证反应层（快、硬实时、优化时序安全）；二者通过一个「截止期 + 质量下界」的契约接口组合，因而可以**各自独立认证**。这直接延伸了 v17 的契约/证书思想：从空间（几何、接触、鲁棒性）延伸到时间。更妙的是，第 40 轮流匹配 ODE 的收缩证书 ε_ode(N) 天然随步数单调下降，于是「在截止期压力下少积几步」不再是降级缺陷，而是**带 ε_max 认证的任意时决策**——流匹配从「可认证执行」升级为「可认证的任意时执行」。

**三灵感的耦合**：智能体给出「可中断的思考」，实时控制给出「可证明的反应」，时序证书给出「二者之间的汇率」——三者共同把 v17 的证书从「空间有效」扩展为「时空有效」：一个动作不仅要「做对」，还要「在对的时间窗内做完，且做完时世界还没变坏」。

## 1. 形式化定义

**定义 27（时序技能契约 C^t）**：在定义 19/25 的技能契约 C_h 上增加时间元组 γ_h = (Ĉ_h, D_h, T_h, J_h, τ_val,h)。其中 Ĉ_h 为最坏执行时间上界（WCET，离线极值理论估计 + 在线包络），D_h 为相对截止期，T_h 为最小调用周期，J_h 为交付抖动上界，τ_val,h 为证书有效时域。语义：若在 t 时刻调用技能，则认证动作块必须在 t + D_h 前交付，交付抖动 ≤ J_h，且该动作在其执行区间上证书有效。**时序可接纳**条件：
D_h ≥ Ĉ_h + J_h + ε_ho（ε_ho 为总线交接开销），且 τ_val,h ≥ D_h + τ_exec,h。
技能契约升级为 C^t_h = (C_h, γ_h)。

**定义 28（混合关键级智能体任务系统）**：任务系统 Γ = Γ_HI ∪ Γ_LO ∪ Γ_SF，每个任务 τ_i = (Ĉ_i, D_i, T_i, χ_i)，χ_i ∈ {HI, LO}；SF 为安全守卫（永远可运行、硬截止、不依赖智能体）。运行模式 m ∈ {NOM, DEG, EMG}：NOM 运行全部；DEG 挂起全部 LO（智能体 deliberation），仅保留 HI 与 SF；EMG 仅保留 SF 与已认证兜底。模式切换有界开销 C_sw，切换策略 δ(状态, 事件) → m 带滞后。**可调度性**：对每个模式 m，活动集合 Γ_m 满足 EDF 密度条件
Σ_{τ_i∈Γ_m} Ĉ_i / min(D_i, T_i) ≤ 1（RM 情形用利用率界 n(2^{1/n}−1)）。

**定义 29（任意时规划契约与计算价值）**：deliberator A 在任意抢占时刻 t 返回计划快照 P(t)，带认证质量 q(P(t))（可定义为证书裕度、计划成功率下界或任务价值的保守估计），要求 q 对 t **单调不减**。任意时契约是一个下界函数 q_min(t)，满足对任意中断时刻都有 q(P(t)) ≥ q_min(t)。给定剩余预算 b，计算价值 VOC(b) = E[q(P(t+b)) − q(P(t))]；单位时间证书增益 g = Δq/Δt 作为调度优先级。**认证投机前缀**：在快照不确定集 U(t) 上，动作前缀 a 仅当对所有 P ∈ U(t) 都满足空间/几何证书时才可提前执行。

**定义 30（陈旧感知安全证书 C_age）**：设在 t₀ 获得认证感知 x̂(t₀)，漂移球 B₀（来自 IP-49），环境状态变化速度上界 v_max（含动态障碍估计）。对任意 t ≥ t₀，真实状态满足 ‖x(t) − x̂(t₀)‖ ≤ B₀ + v_max(t − t₀)（LIO 漂移 + 有界速度）。若安全函数 h 为 L_h-Lipschitz，则
h(x(t)) ≥ h(x̂(t₀)) − L_h·(B₀ + v_max·(t − t₀))。
定义**时序安全裕度** h_age(t) = h(x̂(t₀)) − L_h·(B₀ + v_max·(t−t₀)) − h_margin，**安全年龄**
τ_safe = (h(x̂(t₀)) − h_margin)/(L_h·v_max) − B₀/v_max（L_h·v_max = 0 时单独处理）。
C_age 在 t 有效 ⟺ h_age(t) ≥ 0。安全年龄就是「下一次感知/重规划」的硬截止期，由自触发控制给出而非固定频率。

**定义 31（时序组合与时序证书赤字）**：串行计划 π = h₁;…;hₙ 的端到端截止期
D_π = Σᵢ D_i + (n−1)·ε_ho，
有效时域 τ_val,π = minᵢ (τ_val,i − Σ_{j<i} D_j)。
π **时序良型**（well-timed）⟺ D_π ≤ D_budget 且 τ_val,π ≥ τ_exec,π。并发分支的截止期取 max、串行取 sum。
时序组合裕度 σ(π) = min(D_budget − D_π, τ_val,π − τ_exec,π)/归一化常数；
时序证书赤字 D_time(τ) = Σᵢ wᵢ·max(0, 1 − σᵢ/σ_min)，作为 IP-50 课程的新难度轴。

**定理 2（端到端有界反应）**：若 π 时序良型、每个技能时序可接纳，且运行时在剩余松弛 ≤ C_sw 时切到 DEG/兜底，则对任意 LO deliberation 到达模式，π 的每个动作要么在截止期内交付，要么由已认证兜底动作替代；不存在「未认证动作被执行」。
*证明要点*：HI/SF 的预算与 LO 隔离，EDF 密度条件保证活动集合可调度；模式切换预留 C_sw；兜底动作本身携带第 40 轮的空间证书（C_ms/C_ct/C_bal），故替换后仍是认证动作。关键在「切换前必须完成切换开销」这条不变式。

**定理 3（任意时安全降级）**：若任意时契约成立（q(P(t)) ≥ q_min(t)）且只投机执行认证前缀，则任意中断时刻被执行前缀的质量 ≥ q_min，且其空间/几何证书不被破坏。
*证明要点*：q 单调 + 前缀在不确定集 U(t) 上一致安全，取交集不放大不确定集。

**定理 4（陈旧安全界）**：C_age(t) 有效 ⟹ 真实 h(x(t)) ≥ h_margin。
*证明要点*：Lipschitz 与有界速度的三角不等式，见定义 30 的推导；这是「时间换安全裕度」的确定性版本。

## 2. 三大产出设计

### 2.1 IP-51 TEMPORAL-SKILL-CONTRACT（时序技能契约与实时证书总线）
1. 契约扩展：每个技能挂 γ_h；Ĉ_h 用极值理论（EVT/pWCET）离线估计 + 在线滑动包络；τ_val,h 由 IP-49 的 B_t 增长率与 v_max 反推。
2. 总线准入：每次调用做「时序可接纳 + 端到端良型 + EDF 密度」三重检查；不通过则拒绝或降级为更短预算的等价技能。
3. 混合关键级隔离：HI（平衡/安全）、LO（智能体 deliberation）、SF（守卫）分区；LO 用 slack stealing 吃剩余松弛，剩余松弛 < C_sw 立即降级；用 LET（logical execution time）固定释放时刻消除抖动。
4. 时序 RCA：实测执行时间持续超 Ĉ → 触发 γ 重认证；deadline miss → 归因（模型变慢/输入分布漂移/总线争用）→ 契约热更新。
5. 与 IP-45 集成：路由增加截止期维度（deadline-aware routing），超预算的技能请求在网关注入熔断，不再下传。

### 2.2 IP-52 ANYTIME-AGENT-RUNTIME（混合关键级智能体运行时）
1. 三层运行时：永远热的**认证反应策略**（HI，兜底）、可中断的**deliberative 智能体**（LO，VLM/LLM + 工具 + 记忆）、**安全守卫**（SF）。
2. 任意时 deliberation：模型级联（小快模型先给粗计划 → 大慢模型精修）、可抢占规划、单调快照、认证投机前缀；按 VOC/单位时间证书增益分配算力。
3. 有界反应：deadline-aware 预算；始终预留 C_sw；剩余 < C_sw 时提交当前最优快照并挂上兜底；滞回 + EWMA 防模式振荡。
4. 智能体提案**类型化**：只有时序良型的计划可被接纳；不可信模型输出永不直接驱动执行器。
5. 与 IP-50 闭环：把 D_time 纳入课程；用「低预算蒸馏」训练智能体在更早快照就给出高质量计划（anytime-aware distillation）。

### 2.3 IP-53 STALENESS-SAFETY-GUARD（陈旧感知实时安全守卫）
1. 每个认证实体挂时间戳；在线用 IP-49 的 B_t 增长 + 动态障碍 v_max 估计计算 h_age 与 τ_safe。
2. 自触发感知/重规划：在 τ_safe − δ 前请求下一次感知；按紧迫度（即时序赤字）排序，把感知与推理带宽优先给最小松弛的实体——**注意力本身作为一个实时控制问题**。
3. 时序 CBF：把 IP-49 的 CBF 约束中的 h 替换为 h_age，等价于按状态年龄膨胀安全裕度，得到「陈旧感知下仍然安全」的约束。
4. EMG：若 τ_safe < 控制周期或 h_age < 0，绕过智能体，触发认证停机/兜底（复用 IP-38）。
5. 多实体调度：对 N 个实体求最小松弛优先的感知调度，用 EDF 在「感知任务」上做可调度性检查。

### 2.4 对既有 IP 的升级
- **IP-45**：契约增加 γ；准入控制 + 关键级隔离 + 零抖动 LET 交接；出区/超时/关键级提升为三类熔断触发器。
- **IP-46**：CertBundle 增加 {γ, C_age, slack, p_miss}；证书带「生产时间 + 有效时域」，过期即失效。
- **IP-47**：类型系统增加时序类型；组合检查 D_π、τ_val,π 与关键级兼容；组合裕度取 min。
- **IP-48**：任意时流采样——ε_ode(k) 随步数单调下降，截止期压力下可早停到 N_min 且带 ε_max 证书；N* 从固定值变成预算化决策。
- **IP-49**：所有几何证书带时间戳与年龄；B(t) 随年龄增长；动态障碍估计 v_max 供 τ_safe 使用。
- **IP-50**：证书赤字增加 D_time；课程加入 deadline-pressure 轴与低预算蒸馏；采样偏向「时序可行性边界」。
- **IP-43**：韵律 s 增加时间尺度条件；语音/动作同步也纳入端到端截止期。
- **IP-39**：规划器做任意时时序规划，输出带 D_π 与 τ_val,π 的计划，并支持 LET 交接。
- **IP-38**：新增 EMG 模式与认证停机路径，成为关键级降级的最后一级。
- **IP-36**：语义图元素带时间戳与衰减，供 C_age 使用。
- **IP-40**：可选增加时序惩罚项（超预算/低质量早停）。

## 3. 四层架构 v6

```
L1: TRI-FUSE + IP-49 LIO/点云语义融合 → 带时间戳的 C_ms + B_t(t) + v_max
L2: CTC/VLM 智能体（LO）+ IP-35 仲裁 → 带时序类型的计划提案（D_π, q_min, τ_val）
L3: IP-47 任务代数（空间+时序类型检查）→ IP-39 任意时规划
    → IP-51 实时证书总线（准入/EDF/关键级隔离/LET）
    → IP-52 智能体运行时（deliberate → speculative → switch → fallback）
    → IP-48 任意时流执行（预算化 N，早停带 ε_max）
    → IP-53 陈旧守卫 + IP-49 几何 CBF → RCA 时序监控（deadline/slack/age）
L4: IP-44 蒸馏 + IP-50 课程（时序赤字 + 低预算）→ RCA 重颁时序契约 → 热更新
运行期：混合关键级调度 + 自触发感知 + 零抖动 LET 交接 + 认证兜底 + 流式动作块
```

## 4. 实验设计（E73–E78 硬门槛）

| 实验 | 指标 | 门槛 |
|---|---|---|
| E73 时序契约紧致性 | 认证 Ĉ / 实测 p99.9 执行时间比值；deadline miss | 比值≤2；硬任务 miss=0 |
| E74 有界反应 vs 智能体尾延迟 | 注入 LLM 卡顿/长尾时 HI 反应 p99；模式切换成功率 | p99<D_HI；切换成功≥99.9% |
| E75 任意时质量单调性 | q(P(t)) 单调率；中断时质量≥q_min 的比例 | 单调≥99%；下界成立=100% |
| E76 陈旧安全有效性 | 移动障碍近碰撞率 vs 固定频率感知；虚假安全率 | 下降≥50%；虚假安全<0.1% |
| E77 时序课程效率 | 同 deadline miss 预算下达标样本数 vs 固定课程 | 节省≥30% |
| E78 端到端智能体任务 | 成功率、证书违约率、deadline miss | ≥85%、<0.5%、<0.1% |

回退路径：E73 或 E74 不达标 → 回退 v17（无可认证时序，智能体仅离线生成技能，运行期用固定频率 + 统计 SLA），保留 IP-53 作监控告警；E76 不达标 → 退回固定高频感知，仅保留 IP-51/52。

## 5. 本轮最大风险

**一句话**：整条时序证书链悬于「智能体 WCET 可证」与「任意时质量不塌陷」两根细线——若大模型的执行时间重尾无法给出有用的 Ĉ，准入控制只能拒绝所有智能体提案（系统退化为纯反应式控制器），或放行后悄悄误期（把「实时智能体」变成一句修辞）；故 E73/E74 是本轮第一守门实验，实时性证书的紧致性与智能体降级后的质量下界必须同时成立。

## 2. 关键算法

### IP-51 时序准入与端到端组合（伪代码）
```
def temporal_admit(skill, gamma, plan, rts):
    if gamma.D < gamma.C_wc + gamma.J + EPS_HO:      return REJECT("deadline<wcet")
    if gamma.tau_val < gamma.D + exec_time(skill):   return REJECT("validity<exec")
    tasks = plan.tasks + [task_of(skill, gamma, HI)]
    if not edf_density_feasible(tasks, mode=NOM):    return DEFER("capacity")
    return ADMIT(gamma, slack=gamma.D-gamma.C_wc-gamma.J-EPS_HO)

def compose_temporal(pi1, pi2):
    if pi1.end_mode != pi2.start_mode:               return None
    D     = pi1.D + pi2.D + EPS_HO
    tau   = min(pi1.tau_val - pi2.D, pi2.tau_val)
    sigma = min(D_budget-D, tau-pi1.pi2.exec)
    return Plan(pi1.phases+pi2.phases, D, tau, sigma,
                well_timed=(D<=D_budget and tau>=exec))
```

### IP-52 混合关键级智能体运行时（伪代码）
```
def anytime_agent_loop(goal, D_budget, C_sw):
    t0   = now()
    plan = certified_reactive_fallback(goal)        # HI，永远就绪
    while now()-t0 < D_budget - C_sw:
        rem   = D_budget - (now()-t0)
        b     = min(quantum, rem - C_sw)
        snap  = deliberator.step(budget=b)          # 小模型→大模型级联
        if snap.q >= plan.q and temporal_ok(snap, goal):
            plan = snap                             # 质量单调不降
        if remaining_slack(plan) <= C_sw or not guard.age_valid():
            mode = DEG; break                       # 有界反应：及时降级
    execute_speculative_prefix(plan)                # 只在一致安全前缀上执行
    return plan

def execute_speculative_prefix(plan):
    for a in plan.prefix:
        if all(spatial_cert_holds(a, P) for P in plan.uncertainty_set):
            yield a                                 # 认证投机执行
        else:
            return certified_reactive_fallback(plan.goal)
```

### IP-53 陈旧感知守卫与自触发（伪代码）
```
def staleness_guard(xhat, t0, B0, Lh, vmax, margin, tau_replan):
    def h_age(t):
        return h_geo(xhat) - Lh*(B0 + vmax*(t-t0)) - margin
    if Lh*vmax == 0:
        tau_safe = float('inf') if h_age(t0)>=0 else 0.0
    else:
        tau_safe = (h_geo(xhat)-margin)/(Lh*vmax) - B0/vmax
    if h_age(now()) < 0 or tau_safe < tau_replan:
        if tau_safe < control_period:
            mode = EMG; return certified_stop()     # 绕过智能体
        schedule_perception(deadline=tau_safe-delta) # 自触发
        prioritize_replan(min_slack_first=True)      # 注意力=实时调度
    return VALID(tau_safe)

def temporal_cbf(xhat, u_ref, h_geo, B0, age, Lh, vmax):
    h = h_geo(xhat) - Lh*(B0 + vmax*age) - margin    # 用 h_age 替换 h
    return solve_qp(u_ref, hdot(xhat,u) >= -alpha*h)  # 退化则认证兜底
```

### IP-48 任意时流采样（升级伪代码）
```
def anytime_flow_sample(v_theta, cond, deadline, eps_max):
    k, x = 0, prior_sample(p0)
    while now() < deadline and eps_ode(k) > eps_tol:
        x = rk4_step(v_theta, x, tau=k/N_max, cond=cond)
        k += 1
    if eps_ode(k) > eps_max:                         # 预算不足以维持质量下界
        return certified_fallback(cond)              # 不交付超差动作
    return x, CertFlow(eps_ode=eps_ode(k), k=k)      # 早停也带误差证书
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 正确性保证 |
|---|---|---|
| 时序准入 | O(|Γ|) 密度检查，热路径 μs 级 | EDF 充分条件 ⟹ HI 任务可调度 |
| 端到端组合 | O(|π|) | **定理 2**：良型计划 + 降级策略 ⟹ 有界反应、无未认证动作 |
| 任意时智能体 | 与预算线性；快照 O(1) 切换 | **定理 3**：q 单调 + 认证前缀 ⟹ 任意中断质量≥q_min |
| 认证投机 | O(前缀长·不确定集大小) | 前缀对所有可能计划安全 ⟹ 无需等待规划完成 |
| 陈旧守卫 | 每实体 O(1)（h_age 解析） | **定理 4**：C_age 有效 ⟹ 真实 h≥margin |
| 自触发感知 | EDF O(N log N) | 感知任务密度≤1 ⟹ 所有 τ_safe 被满足 |
| 任意时流执行 | k 次前向，k 由预算决定 | ε_ode(k) 随 k 单调下降；早停误差可证 |
| 时序课程采样 | O(1)/任务（按 D_time 预索引） | Robbins-Monro 收敛性沿用第 40 轮 |

**与第 40 轮证书的关系**：`C_age` 是 IP-49 的 `B_t` 在时间轴上的外推；`γ` 是 IP-46 `CertBundle` 的时间子集；`D_time` 是 IP-50 六类证书赤字的第七类。三者不改变原有空间证书的语义，只是给它们加上「生产时刻 + 有效期」，因此旧证书在 age=0 时自动退化为 v17 行为（向后兼容）。

## 6. 风险与缓解

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 智能体 WCET 重尾不可证 → 准入全拒或全放 | 高 | EVT + 在线包络 + 分段限流；只认证「模型+工具+预算」的执行包络，不认证具体输出；E73 第一守门 |
| 任意时质量塌陷（早停计划很差）→ 兜底过于保守 | 高 | 模型级联 + anytime-aware 蒸馏 + 质量下界在线审计；E75 守门 |
| 模式切换抖动/振荡破坏控制稳定 | 高 | LET 零抖动交接 + 滞回 + EWMA + 切换开销预算；E74 守门 |
| v_max 低估导致 C_age 虚假安全 | 高 | 动态障碍跟踪给置信上界 + 保守放大；E76 注入高速障碍 |
| 端到端 WCET 累加过度悲观 → 几乎无计划良型 | 中 | 并发分支取 max；流水线/投机执行；松弛重分配 |
| 智能体非确定性使认证不可复现 | 中 | 只认证运行时包络与质量下界，把模型当不可信顾问；guard 永不依赖模型输出 |
| 感知自触发导致计算突发 | 中 | 最小间隔 + 感知预算上限 + EDF 可调度性检查 |

## 7. 本轮最大风险

**一句话**：全部设计压在「智能体执行时间可证」与「任意时质量不塌陷」两条腿上——若大模型重尾无法给出有用的 Ĉ，系统要么拒绝一切智能体提案而退化为纯反应控制器，要么放行后静默误期；若早停使计划质量跌破 q_min，兜底将吞掉全部智能体收益。故 E73/E74 为本轮成败判据，实时证书的紧致性与降级质量下界必须同时成立。
