# 第 1 轮 · 想法区

灵感词：**机械臂抓取 / 技术路线图**

## 1. 直觉：抓取是证书系统的「地面真值」

前几轮我们不断往系统上叠证书（IP-425→439）：语义、缺席、义务、手势、能量、云边同步、少样本、专利……每加一层都带来新的耦合与新的失效模式。上一轮的最大风险「版本协议与统计覆盖的共振崩塌」，本质上是**证书增殖的症状**：当证书是平铺的合取时，任何两个原本独立的假设一旦相关，整条链就会一起失效。

灵感词「机械臂抓取」提醒我一件被忽视的事：抓取是少有的、能提供**物理可观测成功/失败标签**的任务——物体是被抓起来还是滑掉了，不需要人工标注。于是可以反过来，用抓取作为校准所有抽象证书的「地面真值锚点」，而不是继续在感知层堆抽象。

灵感词「技术路线图」则提示第二件事：证书不该是平铺集合，而应有**成熟度顺序**。工程上真正的问题不是「有没有证书」，而是「在当前证据水平下，允许系统做到哪一级能力」。路线图 = 能力等级的单调阶梯 + 每一级所需的证据包 + 技术成熟度（TRL）门槛。

## 2. 核心转向：证书的「路线图索引化」

把证书集合从 flat conjunction 改成按能力等级索引的证据包：

```
C_0 ⊆ C_1 ⊆ C_2 ⊆ C_3 ⊆ C_4
```

部署在 L_k 需要 C_k 全有效，且实测 TRL ≥ TRL_req(k)。这样带来三个结构性好处：

- 高层能力不是「又一个新模块」，而是低层证据包的严格超集（**证据闭包**）；
- 高层失效可回退到低层，且因 C_{k-1} ⊂ C_k，回退后执行集单调扩大但仍然安全；
- 「技术路线图」变成可执行对象：每个阶段的目标 = 把某一级证据包从「未验证」推进到「已验证」。

## 3. 抓取可行性证书（GVC）作为锚点

直觉上，一次可部署的抓取要同时回答五个问题：够得着吗、会不会撞、夹得住吗、电量够吗、有多大概率成功。于是

```
GVC(π_g, o) ≜ Reach(π_g,o) ∧ ColFree(π_g,o) ∧ FC(π_g,o) ∧ E(π_g) ≤ E_res ∧ SuccProb(π_g,o) ≥ 1-α
```

关键洞察：**力闭合与滑移只能靠接触证据，不能靠视觉**。同一张物体照片可以对应 μ=0.8 的橡胶和 μ=0.2 的冰面，视觉无法区分。这给出一个不可能性结论：仅凭感知证书无法可靠签发接触层（L2+）证书——除非显式引入并经认证的摩擦下界假设。

## 4. 能力阶梯（路线图的可执行化）

| 等级 | 能力 | 核心证据 | TRL 门槛 |
|---|---|---|---|
| L0 | 看见 | 物体存在 + 位姿误差有界 | ≥4 |
| L1 | 够得着 | IK 可达 + 无碰 + 预抓取构型 | ≥5 |
| L2 | 夹得住 | 力闭合裕度 ε_fc>0 + 接触模式可辨识 | ≥6 |
| L3 | 抓得稳 | 分布漂移下 conformal 成功率 ≥1-α | ≥7 |
| L4 | 完得成 | pick-place 全链能量/义务约束满足 | ≥8 |

每一级都给出证据闭包、可审计 TRL 测量协议与回退规则。这样「路线图」不是 PPT，而是运行时准入条件。

## 5. 为什么这比继续叠证书好

1. 把「证书数量」换成「能力等级」，可度量、可规划、可对外沟通；
2. 抓取标签提供闭环校准，减少对人工 GT 的依赖；
3. 单调阶梯天然支持优雅降级，直接回应上一轮的共振崩塌；
4. 专利、合规、能量这些异质约束终于能在同一成熟度坐标下对齐。

## 6. 仍需严谨化的地方

- 证据闭包 C_{k-1} ⊂ C_k 在运行时是否真的成立，还是只在设计期成立；
- 接触模式（点/线/面 × 软指/硬指）离散切换导致的 conformal 覆盖失效；
- TRL 是主观量，必须定义可审计的测量协议，否则路线图会退化为「证书剧场」。

**本轮最大风险一句话**：路线图把能力等级当成证书的单调叠加，但低层与高层共享同一感知骨干与校准器，单一校准偏差会同时击穿多个等级，使「降级回退」沦为纸面安全。

```python
# ============================================================
# IP-440 Grasp Viability Certificate (GVC)
# ============================================================
@dataclass(frozen=True)
class Contact:
    position: np.ndarray      # 世界系接触点
    normal: np.ndarray        # 接触法向（指向物体内）
    mode: str                 # point / line / surface
    finger: str               # soft / hard

@dataclass
class GVC:
    object_id: str
    grasp_pose: np.ndarray
    reachable: bool
    collision_free: bool
    eps_fc: float             # > 0 才允许 L2+
    E_grasp: float
    succ_score: float
    contact_mode: str
    evidence_hash: bytes      # 接触/视觉/IK/能耗证据的 Merkle 根

    def force_closure_ok(self) -> bool:
        return self.eps_fc > 0.0

    def energy_ok(self, E_res: float, margin: float = 0.0) -> bool:
        return self.E_grasp + margin <= E_res

    def admits(self, E_res: float, tau_g: float, alpha: float) -> bool:
        # 低层只看几何/能量；L2+ 才要求力闭合与成功率
        if not (self.reachable and self.collision_free):
            return False
        if not self.energy_ok(E_res):
            return False
        if self.contact_mode is not None:
            if not self.force_closure_ok():
                return False
            if self.succ_score < tau_g:
                return False
        return True


def force_closure_margin(contacts: list[Contact], mu: float,
                         n_wrench_basis: int = 128) -> float:
    """摩擦锥对接触旋量空间的最小正张成余量。
    ε_fc > 0 表示存在一组非负接触力严格位于摩擦锥内部并张成所需旋量。
    实现：对单位旋量球面采样，求最小线性规划松弛的可行性余量。"""
    best = float("inf")
    for w in sample_unit_wrenches(n_wrench_basis):
        margin = lp_friction_cone_margin(contacts, mu, w)  # ≥0 可行
        best = min(best, margin)
    return best


# ============================================================
# IP-441 Contact-Grounded Conformal Calibrator (CGCC)
# ============================================================
class ContactGroundedConformal:
    def __init__(self, alpha: float = 0.01):
        self.alpha = alpha
        self.calib: dict[str, list[tuple[float, int]]] = defaultdict(list)  # mode -> (score, success)
        self.tau: dict[str, float] = {}

    def observe(self, mode: str, score: float, success: int):
        self.calib[mode].append((score, success))
        if len(self.calib[mode]) > 5000:
            self.calib[mode].pop(0)

    def recalibrate(self, mode: str) -> float:
        """在给定模式下，选取使经验成功率下界 ≥ 1-α 的最小阈值。
        采用 split-conformal：阈值取失败样本 score 的 (1-α) 分位数。"""
        data = self.calib[mode]
        if len(data) < 30:
            raise InsufficientEvidence(mode)
        fails = sorted(s for s, ok in data if ok == 0)
        if not fails:
            self.tau[mode] = float("-inf")  # 尚无失败样本，需更多证据
        else:
            idx = int(math.ceil((1 - self.alpha) * len(fails))) - 1
            self.tau[mode] = fails[min(idx, len(fails) - 1)]
        return self.tau[mode]

    def coverage_lower_bound(self, mode: str, delta: float = 1e-3) -> float:
        data = self.calib[mode]
        n = len(data)
        if n == 0:
            return 0.0
        tau = self.tau.get(mode, float("inf"))
        emp = sum(1 for s, ok in data if ok == 1 and s >= tau) / n
        return emp - math.sqrt(math.log(1 / delta) / (2 * n))  # Hoeffding 下界


# ============================================================
# IP-442 Capability Ladder Gate (CLG)
# ============================================================
class CapabilityLadder:
    LEVELS = {
        0: {"name": "perceive",  "certs": {"SDC", "CAC"},                 "trl": 4},
        1: {"name": "reach",     "certs": {"SDC", "CAC", "ACSC", "GVC_g"}, "trl": 5},
        2: {"name": "contact",   "certs": {"SDC", "CAC", "ACSC", "GVC_fc", "CGCC"}, "trl": 6},
        3: {"name": "robust",    "certs": {"SDC", "CAC", "ACSC", "GVC_fc", "CGCC", "DCSC", "FSVC"}, "trl": 7},
        4: {"name": "task",      "certs": {"SDC", "CAC", "ACSC", "GVC_fc", "CGCC", "DCSC", "FSVC", "HPCE", "DCL"}, "trl": 8},
    }

    def __init__(self, ledger: "RoadmapLedger"):
        self.ledger = ledger

    def closure_ok(self, k: int) -> bool:
        """证据闭包：C_{k-1} ⊆ C_k，且账本中低层证据仍有效。"""
        if k == 0:
            return True
        prev = self.LEVELS[k - 1]["certs"]
        cur = self.LEVELS[k]["certs"]
        return prev.issubset(cur) and self.ledger.valid(prev)

    def admits(self, k: int, valid_certs: set[str],
               trl_measured: float) -> bool:
        req = self.LEVELS[k]
        if not set(req["certs"]).issubset(valid_certs):
            return False
        if trl_measured < req["trl"]:
            return False
        if not self.closure_ok(k):
            return False
        return True

    def highest_admissible(self, valid_certs: set[str],
                           trl_measured: float) -> int:
        for k in range(4, -1, -1):
            if self.admits(k, valid_certs, trl_measured):
                return k
        return -1


# ============================================================
# IP-443 Roadmap Evidence Ledger (REL)
# ============================================================
class RoadmapLedger:
    def __init__(self):
        self.chain: list[dict] = []

    def append(self, level: int, cert: str, evidence_hash: bytes,
               trl: float, reviewer: str):
        prev = self.chain[-1]["hash"] if self.chain else b"\x00" * 32
        rec = {
            "level": level, "cert": cert, "evidence": evidence_hash,
            "trl": trl, "reviewer": reviewer, "prev": prev,
        }
        rec["hash"] = hashlib.sha256(canonical_json(rec)).digest()
        self.chain.append(rec)

    def valid(self, certs: set[str]) -> bool:
        """账本中这些证据的最近记录必须存在、未被覆盖、且哈希链完整。"""
        if not self.chain:
            return False
        if not verify_chain(self.chain):
            return False
        latest = {}
        for rec in self.chain:
            latest[rec["cert"]] = rec
        return all(c in latest for c in certs)


# ============================================================
# IP-444 Grasp Contact-Mode Monitor (GCMM)
# ============================================================
class ContactModeMonitor:
    def __init__(self, cgcc: ContactGroundedConformal):
        self.cgcc = cgcc
        self.current_mode: str | None = None

    def infer_mode(self, tactile: np.ndarray, current: np.ndarray) -> str:
        """由触觉阵列接触面积 + 关节电流纹波推断接触模式。"""
        area = tactile_contact_area(tactile)
        if area < 1e-4:
            return "point"
        if area < 1e-2:
            return "line"
        return "surface"

    def update(self, tactile, current) -> bool:
        mode = self.infer_mode(tactile, current)
        changed = mode != self.current_mode
        self.current_mode = mode
        return changed  # True 表示模式切换，需切换到对应校准集


# ============================================================
# IP-445 Graceful Degradation Controller (GDC)
# ============================================================
class DegradationController:
    def __init__(self, ladder: CapabilityLadder, gvc: GVC,
                 cgcc: ContactGroundedConformal):
        self.ladder = ladder
        self.gvc = gvc
        self.cgcc = cgcc

    def safe_level(self, valid_certs: set[str], trl: float) -> int:
        """当前可安全运行的最高等级；-1 表示必须停机。"""
        return self.ladder.highest_admissible(valid_certs, trl)

    def degrade(self, current_k: int, valid_certs: set[str],
                trl: float) -> tuple[int, bool]:
        target = self.safe_level(valid_certs, trl)
        if target >= current_k:
            return current_k, False
        if target < 0:
            return -1, True  # 无可用等级 → 安全停机
        return target, True

    def on_slip(self, valid_certs: set[str], trl: float) -> int:
        """检测到滑移 → 力闭合证据失效 → 至少回退到 L1。"""
        valid_certs = set(valid_certs) - {"GVC_fc", "CGCC"}
        target, _ = self.degrade(2, valid_certs, trl)
        return target
```

## 3. 复杂度分析

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 |
|---|---|---|---|
| GVC 力闭合 | O(S·LP(c))，S=旋量采样数，c=接触数 | O(c) | S=128, c≤6 |
| CGCC 校准 | O(n log n) / 模式 | O(n) | n≤5000，6 种接触模式 |
| CLG 准入 | O(|C_k|) | O(|C_k|) | 每级 ≤9 个证据 |
| REL 追加/校验 | O(1) 追加 / O(n) 全链校验 | O(n) | n=证据记录数 |
| GCMM 模式推断 | O(|tactile|) | O(1) | 触觉阵列 ≤ 32×32 |
| GDC 降级 | O(5·|C|) | O(1) | 等级数 5 |
| 端到端单步 | O(S·LP + |C_k| + |tactile|) | O(n) | 50Hz 关键路径 <20ms（力闭合离线预算） |

**实时性说明**：力闭合计算是唯一较重的一步，放到抓取规划阶段（非 50Hz 控制环），在线仅做 `eps_fc > 0` 与 `succ_score ≥ τ_g` 的 O(1) 比较；降级判定为 O(|C|) 级。

## 4. 正确性论证

### 引理 1（证据闭包 ⇒ 执行集单调）
**陈述**：若 `C_k ⊆ C_{k+1}`，则 `Exec_{k+1} ⊆ Exec_k`。
**证明**：`Exec_k = {π : ∀c∈C_k, Valid(c)}`。对任意 π∈Exec_{k+1}，有 `∀c∈C_{k+1}, Valid(c)`；由 `C_k ⊆ C_{k+1}` 得 `∀c∈C_k, Valid(c)`，故 π∈Exec_k。∎

### 引理 2（接触接地 conformal 覆盖）
**陈述**：在固定接触模式 m 下，若校准集与测试集可交换（exchangeable），则 `P(SuccProb ≥ 1-α) ≥ 1-α`（有限样本含 Hoeffding 修正）。
**证明**：CGCC 取失败样本 score 的 (1-α) 分位数作阈值 τ_g，是 split-conformal 的标准构造；阈值以上样本的成功率由可交换性得 `≥1-α`。有限样本用 `coverage_lower_bound` 扣除 `sqrt(ln(1/δ)/2n)`。∎

### 引理 3（降级安全性）
**陈述**：若当前运行于 L_k 且高层证据失效，则 `Degrade(k→j)` 给出的 j 满足 `Exec_j ⊇ Exec_k`，即回退后允许的计划集合只会扩大，不会引入新的、未被低层证据覆盖的计划。
**证明**：`Degrade` 返回 `highest_admissible`，其证据包 `C_j ⊆ C_k`（因失效只删除证据，且 j≤k）。由引理 1 得 `Exec_k ⊆ Exec_j`。新进入 `Exec_j \ Exec_k` 的计划只依赖 `C_j` 中仍有效的证据，故安全。∎

### 定理（接触证据必要性 / 感知不可能性）
**陈述**：在物体摩擦系数 μ 未知且视觉观测 x 不能区分 μ 的物体类上，不存在仅依赖感知证据的可靠 L2+ 证书。形式化：存在几何 g、观测 x、摩擦 μ1,μ2，使 `x(g,μ1)=x(g,μ2)`，但 `ε_fc(g,μ1)>0` 且 `ε_fc(g,μ2)<0`。任何 `f: X→{0,1}` 对二者输出相同，必在其中一个世界出错。
**证明**：取 g 为平面物体、两点接触，法向力上限随 μ 变化。μ1 使摩擦锥张成重力旋量，μ2 不张成；视觉 x 只编码几何与外观，不含 μ。故 f(x) 相同而真实 `FC` 不同，f 不可能同时正确。∎

**推论**：只有当系统显式携带经认证的摩擦下界 `μ ≥ μ_safe`，且对物体类保证 `ε_fc(g,μ_safe)>0` 时，才允许用「感知 + 材料先验」替代接触证据；该先验本身必须由 REL 记录并可审计。这条推论直接解释了为什么 L2 必须引入 CGCC，而不能只靠 IP-433 的深度 conformal 语义证书。

### 定理（路线图准入的可靠性）
**陈述**：若 `LadderAdmit(π,k)` 成立，则 π 在等级 k 的所有证据均有效、低层证据未被绕过、且实测成熟度达标。
**证明**：由 `LadderAdmit` 三个连言与 `closure_ok` 的定义直接得到；`Closure(C_k)` 中的 `LedgerConsistent` 保证证据未被事后替换。∎

## 5. 已知风险与缓解

| 编号 | 风险 | 严重度 | 缓解 | 剩余风险 |
|---|---|---|---|---|
| R1 | 证据闭包只是设计期集合包含，运行时低层证据可能已悄悄失效 | 最高 | REL 每次准入校验低层证据有效性；任何低层失效强制整链降级 | 账本被篡改或复核人失职时，闭包退化为纸面 |
| R2 | 接触模式切换导致跨模式 conformal 覆盖失效 | 高 | GCMM 在线辨识模式，切换即切换校准集；样本不足的模式拒绝签发 | 软指→硬指的过渡态模式难以离散归类 |
| R3 | 摩擦下界假设被打破（冰面/油污），感知证书误判 L2 可行 | 高 | 强制接触证据优先于材料先验；滑移检测触发 `on_slip` 回退 | 极低摩擦且无滑移前兆的瞬态仍可能漏检 |
| R4 | TRL 主观性导致「路线图剧场」 | 中 | 定义可审计测量协议（场景数、成功率、故障注入覆盖率）；REL 留痕 | 组织压力下仍可能虚报 TRL |
| R5 | 降级到 L1 后仍执行抓取，只是不保证力闭合 | 中 | L1 仅允许「接近/预抓取」，禁止闭指；GDC 与执行器联锁 | 联锁实现错误会导致越级执行 |
