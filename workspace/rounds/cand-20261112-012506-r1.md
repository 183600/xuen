# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 1 轮；本轮灵感：「研究空白」×「数据配比」）

> 第 57 轮把安全的赌注从"模型置信"经"证据质量"押到"元先验质量"，再用 OOD 门 + 共形保底赎回一部分；但它默认了三件事：**(a) 语料是完整的**——OOD 门只会喊"不像训练集"，说不出"哪道题没有答案"，也分不清"没数据""数据自相矛盾""有数据但从未被验证"；**(b) 语料是中立的**——只有成功、完成、可达的探针进入 𝒟_meta，失败/中止/拒答的探针被系统性丢弃，元先验与共形带因此建在"幸存者"之上（科学计量里的 file-drawer / 发表偏倚）；**(c) 校准是边际的**——ECE 在整个语料上平均，部署地形配比一旦偏离语料配比，边际校准可以在每个分层都严重失准时仍然好看（Simpson 悖论）。本轮两个灵感各补一刀：**研究空白**把"不知道"从匿名标量变成可命名、可定位、且"值不值得问"可判定的空白图谱；**数据配比**把语料构成从背景假设变成显式控制变量——分层校准 + 配比证书 + 对配比模糊集的分布鲁棒界，并用负结果账本把被删失的失败探针赎回来。核心命题由"少样本可校准、跨模态可对账、个性化有界的证据说可信"升级为 **"空白可命名、配比可审计、负结果可信的证据说可信"**。

核心矛盾：
- **H32（空白可命名 vs 图谱自身是假设）**：把"不知道"命名成 (分层, 问题, 类型) 能让探针有的放矢；但图谱是从同一条证据流估出来的，它最可能漏掉的正是"连删失都看不见"的空白——命名能力越强，越容易被误当成完备性。
- **H33（配比是控制变量 vs 配比不可观测）**：分层校准与 DRO 需要部署配比 w，可真实配比恰恰未知且漂移，模糊集半径 ρ_mix 又是需要有人负责的先验——安全的赌注第三次后移。
- **H34（负结果有用 vs 负结果可操纵）**：记录失败探针能纠正幸存者偏倚；但"失败/中止"由执行侧上报，漏报、错标、仪器故障都会污染账本——把安全押在"大家诚实上报负结果"上是危险的。

## 0. 直觉与动机

**灵感 1（研究空白 → 从二值 OOD 到决策相关的空白图谱）**
直觉：第 57 轮的 OOD 门像只会喊"不对劲"的烟雾报警器：不说是哪道题没做，也不区分"没见过""见过但矛盾""有数据但没验证"。真正的研究者不会停在"不熟悉"，而会写下具体空白："在 Y 条件下关于 X 我们没有数据，而能判定它的实验是 Z"。于是引入**空白图谱 𝒢**：对每个分层 z=(地形簇, 区域, 位姿桶, 模态, 假设) 记录空白类型 τ∈{覆盖, 可识别, 冲突, 删失} 与严重度。关键约束是**空白相对问题而言**：样本少不等于空白，只有"补齐它能改变决策"（VOI 高）时才记空白，否则会把探针浪费在无关的未知上。同时承认图谱是假设：**空白只用于提高效率，永不用于放宽安全**；不可命名的空白必须触发保守回退，而不是被默认安全。

**灵感 2（数据配比 → 语料不中立，配比本身是安全参数）**
直觉：机器学习早已知道数据配比会改变模型行为（代码/数学/多语比例一变，能力与偏差都变）。这里同样：第 57 轮的元语料是地形×模态×操作者的一个**配比**，而校准保证只是该配比上的边际保证；部署配比一偏（冰面比语料多），边际 ECE 就会掩盖分层 ECE 的灾难。更隐蔽的是**幸存者偏倚**：只有成功完成、到达、被记录的探针进入语料，失败/中止/拒答的探针消失——正是科学计量里的发表偏倚。两条修正缺一不可：(i) **配比分层校准**——每个权重大于 w_min 的分层都要满足 ECE(z)≤ε_meta(z)，并对部署配比的模糊集 𝒲 给分布鲁棒界，未观测质量按最坏值计；(ii) **负结果账本**——所有失败/中止/拒答探针带删失标记入账，用逆概率删失加权（IPCW）/Heckman 校正，并拿物理执行日志反查漏报。配比由此从背景假设变成**可审计的证书 J_mix**。

**灵感 3（两灵感合流 → 空白×配比 = 可审计的证据经济学）**
直觉：空白告诉你"哪里缺数据"，配比告诉你"数据按什么权重算账"；合起来就是一套**证据经济学**：把探针预算按"最坏配比下边际空白缩减最大"来分配（边际收益递减 ⇒ 贪心/子模），所有结果（含负结果）入账，最后给出一份配比证书。安全单调性靠三条硬规则维持：探索只走非破坏探针；不可命名的空白一律保守回退；负结果只能减少承诺、永不增加承诺。效率来自空白图谱，安全来自"最坏配比 + 不可处置即保守"——即使图谱漏掉一个空白，只要它落在未观测质量 w_∅ 里，DRO 界仍按最坏值兜底。

**灵感 4（四类空白 → 四种不同处置）**
直觉：不是所有空白都该用探针填。覆盖空白（样本太少）→ 补探针；可识别空白（存在判别性非破坏探针）→ 定向探针；冲突空白（跨模态/常识与数据冲突）→ 优先对质探针（接第 57 轮 XMC/CDC）；删失空白（失败探针被丢弃）→ 修账本而不是加探针。把"研究空白"拆成类型，避免"一遇未知就乱探"。

**灵感 5（PCE×Mix → 预算分配本身成为被证明的对象）**
直觉：探询预算不再按区域轮询或纯 VOI 贪心，而是解一个"最坏配比下的空白缩减"分配问题；承诺门从"证据门"扩为"证据门 ∧ 分层校准有效 ∧ DRO 界过 ∧ 无不可处置空白"。若分配不出可命名空白或 DRO 不过，直接回退第 57 轮手工先验/保守停——**新机制只增加拒绝与探针，不增加授权**。

## 1. 形式化定义（增量：定义 145–150）

**定义 145（研究空白图谱 GA）** 分层空间 𝒵={z=(c_terrain,c_region,c_pose,c_mod,c_hyp)}，问题 q(z) 为 z 上的决策相关问题（如该位姿的 P_fail）。空白对象 g=(z,q,τ,sev,prov)，类型 τ∈{cov,id,conf,cens}，严重度 sev(z)=VOI_meta(z)·deficit(z)（VOI≈0 的未知不记空白）。图谱 𝒢_t 在线更新、版本化、带来源 prov=(观测版本, 账本版本, 元模型版本)，写权限分离（检测器写、承诺门只读），可审计。

**定义 146（空白可识别性检测 GID）** 四类 deficit：覆盖 deficit_cov=1−n_eff(z)/n_min(z)，n_eff 为 Kish 有效样本量；校准 deficit_id=max(0,ECE(z)−ε_meta(z))；冲突 deficit_conf=[D(r)>θ_D 或 CDC silent_conflict 持续]；删失 deficit_cens=ĉ(z)−c_max。判定：deficit 全≤阈值 ⇒ filled；否则若 ∃ 非破坏探针 π 使 VOI_cg(π,z)≥θ_id 且假设判别增益≥θ_sep ⇒ nameable(z,π\*)；否则 **unaddressable(z)=True**，该空白不得被默认为安全，相关位姿强制保守回退。

**定义 147（负结果账本与删失校正 NRL）** 每次探针尝试 i 记录 (z_i,π_i,o_i,c_i,r_i)，o∈{succ,fail,abort,refuse,invalid}，c_i 为删失指示（未进入原语料），r_i 为原因。账本 ℒ_- 与成功账本并列。删失校正：风险估计用 IPCW 权重 1/p̂_report(z,π)（或 Heckman 选择模型），p̂_report 由物理执行日志对账估计；若对账发现漏报率 >δ_report，则按惩罚加宽共形带、下调 ρ_m/ρ_cg。**EV-negative**：经核验的负结果（发现危险/失效）是单调安全证据——只能阻断或降档，永不授权。

**定义 148（配比分层校准 MSC 与配比证书 J_mix）** 配比 w∈Δ(𝒵)，模糊集 𝒲={w': d(w,w')≤ρ_mix} ∪ {把未观测质量 w_∅ 任意分配给最坏分层的配比}。契约：∀z:w(z)≥w_min，ECE(z)≤ε_meta(z) 且 coverage(z)≥1−α_conf(z)；分布鲁棒界 sup_{w'∈𝒲} Σ_z w'(z)·risk(z)≤δ_f。J_mix=(w,{n_eff(z)},{ECE(z)},{coverage(z)},{censoring_rate(z)},𝒲,w_∅,worst_case,version)。仅边际 ECE 的证书无效；无 J_mix 的证据不得进入承诺门。

**定义 149（空白导向配比策略 GMP）** 预算 B，分配 π:𝒵→ℕ，Δ_z(n) 为边际空白缩减且随 n 递减。π\*=argmax_{Σπ≤B} min_{w'∈𝒲} Σ_z w'(z)·sev(z)·Δ_z(π_z)，约束：仅非破坏探针、unaddressable 分配 0、单分层上限 n_cap。递减性 ⇒ 目标子模，贪心达 (1−1/e)；等价"配比混合律"：最优解让各活跃分层的最坏加权边际收益相等。

**定义 150（空白感知证据门与 PCE×Mix）** 证据 e 携带分层标签 z_e 与 J_mix 版本。门规则：①unaddressable(z_e) 且影响承诺 ⇒ 拒；②EV-negative 经核验 ⇒ 仅可 block/quarantine；③其余证据类（EV-probe\*/visit/margin/xmodal/human）须 J_mix 覆盖 z_e 且 ECE(z_e)≤ε_meta(z_e)，再走第 57 轮 FSE；④不可逆接触必要证据集仍为 {EV-probe\*∨EV-margin}∪佐证，EV-xmodal 仍限 L1。J_gap=(J_p,𝒢,ℒ_-,J_mix,unaddr_mask,DRO_bound,version)。PCE×Mix：每检查点按 GMP 分配 → 探针入账 → 重估 𝒢/J_mix → 承诺 ⇔ FSE ∧ DRO 界 ∧ 无不可处置空白；否则回退第 57 轮/绕行/降档/协商/停。

## 2. 关键算法伪代码（完整版见产物区）

```python
def gap_atlas_update(G, z, q, obs, ledger):
    d = {'cov': coverage_deficit(z, obs), 'id': calib_deficit(z, obs),
         'conf': conflict_deficit(z, obs), 'cens': censoring_deficit(z, ledger)}
    tau = argmax(d, key=d.get)
    sev = voi_meta(z) * d[tau]              # 决策相关：无关问题不记空白
    G.upsert(z, q, tau, sev, prov=versions(obs, ledger, meta))
    return G

def gap_identifiability(G, z, probes):
    if all(deficit(z) <= eps for deficit in G.deficit(z)):
        return 'filled'
    cand = [p for p in probes if p.non_destructive and p.region == z.region]
    best = max(cand, key=lambda p: voi_cg(p, z), default=None)
    return ('nameable', best) if best and voi_cg(best, z) >= theta_id \
           else 'unaddressable'            # 不可命名 → 强制保守，不默认安全

def mixture_certify(G, L, meta, W_amb):
    strata = [z for z in G.strata if G.w(z) >= w_min]
    ece  = {z: cond_ece(meta, z)           for z in strata}
    cov  = {z: empirical_coverage(meta, z) for z in strata}
    cens = {z: censoring_rate(L, z)        for z in strata}
    wc   = dro_bound(meta, W_amb, unknown_mass='worst')
    ok = all(ece[z] <= eps_meta[z] and cov[z] >= 1 - alpha_conf[z]
             for z in strata) and wc <= delta_f
    return ('ok' if ok else 'reject'), Jmix(G.w, ece, cov, cens, W_amb, wc)
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| GA | O(\|𝒵\|)/更新 | O(\|𝒵\|) | 决策相关、版本化、写权限分离 |
| GID | O(\|𝒵\|·\|Π\|) | O(\|𝒵\|) | 可命名/不可处置二分，不可处置即保守 |
| NRL | O(1) 追加；O(n) 重估 | O(n) | 删失校正 + 物理日志反查 |
| MSC | O(\|𝒵\|+\|𝒲\|·\|𝒵\|)（LP） | O(\|𝒵\|) | 分层 ECE + DRO 含 w_∅ 最坏 |
| GMP | O(B·\|𝒵\|) 贪心 | O(\|𝒵\|) | 递减边际、子模 1−1/e |
| GAG/PCE×Mix | O(\|CP\|·(B+k_p+k_c)·(C_VOI+\|𝒵\|)) | O(\|V\|+\|𝒵\|) | 不可处置→保守、预算终止 |

**正确性定理（Gap-Mixture Calibrated Soundness, GMCS 概要）**：在 A33–A40 上加 (A41) 空白决策相关且不可处置空白永不被默认为安全；(A42) 负结果账本删失校正诚实、漏报率 ≤δ_report；(A43) 分层校准 ECE(z)≤ε_meta(z)、覆盖 ≥1−α_conf(z)，且真部署配比落入 𝒲 的概率 ≥1−α_mix、未观测质量按最坏计；(A44) 空白探索仅非破坏、分配不放宽承诺门。则：(i) 承诺失效率 ≤ sup_{w'∈𝒲}Σ_z w'(z)(δ_f+ε_meta(z)+δ_probe+δ_h+δ_xm·1[L1]) + δ_report + δ_censor，其中不可处置空白以最坏值计入而非乐观值；(ii) 单调性：空白检测、负结果账本、配比策略只经"去掉承诺/增加非破坏探针/加宽界"起作用，EV-negative 只减不增；(iii) PCE×Mix 在 B+k_p+k_c 内终止。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 空白图谱漏检（尤其连删失都看不见的空白） | 高 | 不可处置即保守 + w_∅ 最坏计入 + 图谱独立审计 + 回退第 57 轮 |
| 负结果账本被漏报/错标污染 | 高 | 物理日志反查 + IPCW 校正 + 漏报惩罚 + EV-negative 仅减不增 |
| 配比模糊集 𝒲 设定过窄 → DRO 界失效 | 高 | 保守 ρ_mix + 未观测质量最坏 + 经验覆盖检验 + 违约即回退 |
| 分层过细 → 每层样本稀疏、区间过宽 | 中 | 分层池化/收缩估计 + 最小分层规模 + 层级贝叶斯 |
| DRO/贪心计算进入控制回路 | 中低 | LP/闭式近似 + 增量更新 + 预算上限 |

## 6. 本轮最大风险

**一句话**：本轮把"我们不知道什么"的判定权交给一张由同一条证据流估出的空白图谱——若某类空白连删失都看不见（失败探针从未被上报），分层校准会在缺失的恰恰是关键分层时依然通过，而 DRO 模糊集若不把该分层计入 w_∅ 也无法兜底；因此安全最终只能押在"不可处置空白一律保守回退"这条硬规则上，而不是图谱的完备性上。

## 2. 关键算法伪代码

### IP-139 GA（研究空白图谱）

```python
def gap_atlas_update(G, z, q, obs, ledger):
    d = {'cov':  coverage_deficit(z, obs),      # 1 - n_eff/n_min
         'id':   calib_deficit(z, obs),         # max(0, ECE(z) - eps_meta(z))
         'conf': conflict_deficit(z, obs),      # D(r)>theta_D 或 CDC 冲突
         'cens': censoring_deficit(z, ledger)}  # 删失率 - c_max
    tau = argmax(d, key=d.get)
    sev = voi_meta(z) * d[tau]                  # 决策相关：VOI≈0 不记空白
    G.upsert(z, q, tau, sev, prov=(obs.ver, ledger.ver, meta.ver))
    return G
```

### IP-140 GID（空白可识别性：可命名 vs 不可处置）

```python
def gap_identifiability(G, z, probes):
    if all(deficit(z) <= eps for deficit in G.deficit(z)):
        return 'filled'
    cand = [p for p in probes if p.non_destructive and p.region == z.region]
    best = max(cand, key=lambda p: voi_cg(p, z), default=None)
    if best is None or voi_cg(best, z) < theta_id:
        return 'unaddressable'          # 强制保守，不得默认安全
    return ('nameable', best)
```

### IP-142 MSC（配比分层校准与 J_mix）

```python
def mixture_certify(G, L, meta, W_amb):
    strata = [z for z in G.strata if G.w(z) >= w_min]
    ece  = {z: cond_ece(meta, z)            for z in strata}
    cov  = {z: empirical_coverage(meta, z)  for z in strata}
    cens = {z: censoring_rate(L, z)         for z in strata}
    wc   = dro_bound(meta, W_amb, unknown_mass='worst')
    ok = all(ece[z] <= eps_meta[z] and cov[z] >= 1 - alpha_conf[z]
             for z in strata) and wc <= delta_f
    return ('ok' if ok else 'reject'), \
           Jmix(G.w, ece, cov, cens, W_amb, wc, version=meta.ver)
```

### IP-143 GMP（空白导向数据配比）

```python
def gap_directed_allocate(G, budget, W_amb):
    alloc = {z: 0 for z in G.gaps if not G.unaddr(z)}
    while budget > 0:
        z = argmax(alloc, key=lambda z: min_w(W_amb) * G.sev[z]
                                     * marginal_gain(z, alloc[z]))
        if marginal_gain(z, alloc[z]) < theta_gain:   # 递减边际
            break
        alloc[z] += 1
        budget -= 1
    return alloc          # unaddressable 分配 0 → 走保守回退
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| GA | O(\|𝒵\|)/更新 | O(\|𝒵\|) | 决策相关、版本化、写权限分离（A41） |
| GID | O(\|𝒵\|·\|Π\|) | O(\|𝒵\|) | 可命名/不可处置二分，不可处置即保守（A41） |
| NRL | O(1) 追加；O(n) 重估 | O(n) | 删失校正 + 物理日志反查（A42） |
| MSC | O(\|𝒵\|+\|𝒲\|·\|𝒵\|)（LP） | O(\|𝒵\|) | 分层 ECE + DRO 含 w_∅ 最坏（A43） |
| GMP | O(B·\|𝒵\|) 贪心 | O(\|𝒵\|) | 递减边际、子模 1−1/e（A44） |
| GAG/PCE×Mix | O(\|CP\|·(B+k_p+k_c)·(C_VOI+\|𝒵\|)) | O(\|V\|+\|𝒵\|) | 不可处置→保守、预算终止 |

**正确性定理（Gap-Mixture Calibrated Soundness, GMCS）**
假设 A22–A40（第 53–57 轮）成立；**(A41)** 空白对象决策相关、图谱写权限分离且可审计，不可处置空白永不被默认为安全；**(A42)** 负结果账本删失校正诚实（p̂_report 由物理日志对账），漏报率 ≤δ_report，EV-negative 仅减不增；**(A43)** 配比分层校准：∀z:w(z)≥w_min，ECE(z)≤ε_meta(z) 且 coverage(z)≥1−α_conf(z)，真部署配比落入 𝒲 的概率 ≥1−α_mix，未观测质量 w_∅ 按最坏分层计；**(A44)** 空白探索仅用非破坏探针，配比分配不放宽承诺门。则：

1. **空白-配比承诺健全性**：承诺失效率 ≤ sup_{w'∈𝒲}Σ_z w'(z)(δ_f+ε_meta(z)+δ_probe+δ_h+δ_xm·1[L1]) + δ_report + δ_censor；不可处置空白以最坏值计入而非乐观值。
2. **单调性**：空白检测、负结果账本、配比策略只能经 (a) 去掉承诺、(b) 增加非破坏探针、(c) 加宽界/降档 影响系统；EV-negative 永不授权。
3. **效率**：在 Δ_z(n) 递减（子模）下，GMP 贪心达到最优最坏空白缩减的 ≥(1−1/e)。
4. **终止性**：每轮空白探针预算 B、共识探针 ≤k_cons、常规探针 ≤k_probes，PCE×Mix 在 B+k_p+k_c 内终止于 {承诺, 绕行, L2 协商, 安全停}。

部署界（对分层与检查点取联合界）：

```
P_safe ≥ 1 − sup_{w'∈𝒲} Σ_z w'(z)·(δ_f + ε_meta(z) + δ_probe + δ_h + δ_xm·1[L1])
             − w_∅ − δ_report − δ_censor
             − P(𝓜 陈旧未检出) − P(护盾回退失败) − P(协商超时且安全停失效)
```

关键：**效率来自空白图谱，安全来自最坏配比 + 不可处置即保守**；**负结果只减不增**；配比证书把"校准究竟在哪个分层成立"从隐含假设变成可审计事实，边际 ECE 不再能冒充全局保证。

## 6. 本轮最大风险

**一句话**：本轮把"我们不知道什么"的判定权交给一张由同一条证据流估出的空白图谱——若某类空白连删失都看不见（失败探针从未被上报），分层校准会在缺失的恰恰是关键分层时依然通过，而 DRO 模糊集若不把该分层计入 w_∅ 也无法兜底；因此安全最终只能押在"不可处置空白一律保守回退"这条硬规则上，而不是图谱的完备性上。
