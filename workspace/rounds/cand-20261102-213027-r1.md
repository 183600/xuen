# 玄 · 第 1 轮灵感循环 · UNIFY-NAV-COLLAB 通用平台自主导航与人机协作

## 0. 结论与边界

### 0.1 一句话结论
在单模型冻结 VLA 约束下，通过导航残差 `r_nav`、人机意图/安全残差 `r_human / r_safe` 与形态无关能力剖面 `C_robot` 构成三重增补，将 ZEST-VLA 从固定形态操纵扩展为通用平台自主导航与人机协作的零样本鲁棒系统。

### 0.2 证据等级
A 官方文档/数据集元数据；B 公式+合成实验可复现；C 设计假设需 G26–G28 验证；D 思路论述；U 未核验。

### 0.3 不做什么
不训练新网络；不 test-time 更新；不假设深度/F-T；不解决 OOD-G；单块决策 <2ms 增量。

## 1. 承接增量

保留 FACT-VLA 相位化、GEO-RESIDUAL、5 步闭环、WAVE-SERVO、VOI-MAP、ZEST-VLA 信任门。
升级：残差从 4→7 通道，VOI-MAP 扩展导航信念，新增协作模式与平台能力归一化。
剪枝：无新学习参数。

## 2. 符号与形式化

设 VLA `π_θ` 冻结，观测 `o_t`，指令 `u`，输出 30 步块 `A_t`，5 步执行 `b`。

新增：
- `M_nav = (O, S, P)` 占用、语义、路径信念地图
- `r_nav_b` 导航一致性残差
- `r_human_b` 人机意图对齐残差
- `r_safe_b` 安全距离残差
- `σ_collab ∈ {LEAD, SHARE, YIELD}` 协作模式
- `σ_nav ∈ {FREE, OBSTACLE, REPLAN}` 导航子状态
- `C_robot = {dof, reach, payload, base_type, vel_max}` 能力剖面
- `Φ` 形态无关原语空间，`norm_morph(·;C_robot)` 归一化映射

### 2.1 残差定义

`r_nav_b = λ_o * occ_violation_b + λ_p * path_deviation_b`
`occ_violation_b = max(0, d_obs - d_safe)/d_safe`
`path_deviation_b = ||p_actual - p_plan|| / L_plan`

`r_human_b = (H_human - μ_H)/σ_H + max(0, μ_Q - Q_human)/σ_Q`
其中 `H_human` 为语言-人体姿态注意力熵，`Q_human` 为协作关键词注意力质量。

`r_safe_b = max(0, 1 - d_human / d_min)`，`d_human` 来自地图人体骨架投影距离估计，无深度传感器时用单目尺度归一化。

### 2.2 融合与校准

自归一化 `σ_{k,b}=1.4826*MAD + ε`，`z^k_b = r^k_b/σ_{k,b}`

`s_b = Σ w_k z^k_b`，`k ∈ {dyn,tmp,geo,goal,anom,nav,human,safe}`

权重 `w_dyn=3`, 其余 1。`q_α` 分位数 conformal，`e_b = 1[s_b > q_α]`，CUSUM `S_b = max(0,S_{b-1}+e_b-α-k)`。

触发条件扩展：`S_b>h` 或任一残差 > θ_k → FALLBACK。

### 2.3 平台归一化

原语参数 `θ_prim(u,M)` 经映射：
`θ̂ = clip( norm_morph(θ_prim; C_robot), C_robot.bounds )`

映射为确定性线性缩放 + 饱和，无学习。

### 2.4 协作模式切换

`σ_collab` 由 `r_human` 与 `r_safe` 共同决定：
- `r_safe > θ_safe` → YIELD 并触发 HOLD
- `r_human < -τ` 且 `r_safe < 0.5θ_safe` → SHARE
- 否则 LEAD

模式切换仅影响 VOI 成本表 `C'(a)` 与允许动作集。

## 3. 算法步骤

1. 任务启动解析指令与平台剖面 `C_robot`，初始化 `M_nav`。
2. VLA 推理 30 步，提取注意力用于 `r_human`。
3. 每 5 步块更新 `M_nav`，计算 `r_nav / r_safe`。
4. 计算 7 通道残差融合 `s_b`，conformal 校准与 CUSUM 信任门。
5. 根据 `σ_collab / σ_nav` 调整 VOI 成本与动作集。
6. 若 FALLBACK，执行 `θ_prim` 归一化后原语；导航阻塞时触发 REPLAN。
7. 平台映射 `norm_morph` 输出执行动作。
8. 状态隔离：导航子状态故障不拖垮全局生命周期，协作 YIELD 模式下禁用激进 LOOK/VLA。

伪代码核心：
```
def get_action(obs):
    update M_nav
    r = compute_residuals(obs, attn)
    s = fuse(r)
    if cusum_trigger(s,r): mode=FALLBACK
    sigma_collab = update_collab(r_human,r_safe)
    allowed = shrink_by_mode(sigma_collab, sigma_nav)
    act = voi_select(allowed, M_nav, C_robot)
    return norm_morph(execute(act), C_robot)
```

## 4. 复杂度分析

`Ψ_demand` 解析 O(|u|), `r_nav` O(|X_nav|) 可离线异步, `r_human` O(L×30), `r_safe` O(1), 归一化 O(1)。单块增量 <2ms，内存 O(|X_nav|+W)。

## 5. 正确性论证

命题1：conformal 覆盖保持。新增残差为确定性函数，无学习参数，分位数估计仍满足交换性，边际保证不变。

命题2：平台映射安全。`norm_morph` 为单调饱和映射，保持原语语义序，且 `clip` 保边界，故执行始终在 `C_robot` 可达集内。

命题3：协作安全不变式。若 `r_safe>θ_safe` 则模式强制 YIELD 并 HOLD，距离单调不减，故碰撞避免在逻辑层成立。

## 6. 实验设计

门 G26：导航残差 AUROC ≥0.7，障碍避让成功率↑≥5pp。
门 G27：人机协作模式下安全违规率下降≥60%，`r_human` 与人工标注对齐相关>0.6。
门 G28：跨形态平台成功率下降<3pp，相较无归一化基线。

消融：去掉 `r_nav` / `r_human` / `C_robot` 各自验证。

## 7. 风险

- 人体距离估计无深度时尺度漂移导致 `r_safe` 假阴性
- 多模式状态机组合爆炸：`σ × σ_collab × σ_nav` 最多 15 组合，需严格隔离
- 平台归一化过度保守导致能力浪费

## 8. 一句话押注
从「执行胜任力」到「导航信念 + 人机意图 + 平台能力」三重契合的通用零样本鲁棒框架。

## 9. 本轮最大风险
**人体距离无深度传感器的尺度不确定性**：`r_safe` 依赖单目投影距离归一化，在不同相机内参与人形尺度变化下易产生系统性低估，导致协作 YIELD 触发不足或过度保守，构成人机协作的安全底线风险，需在合成实验中以尺度扰动校准 `θ_safe` 并设置保守上界。

## 0. 前文承接与本轮划分

### 0.1 前人基础
本轮在 ZEST-VLA 体系上继续演进。已知基础：冻结 VLA `π_θ` 输出 30 步动作块，5 步闭环比执行；四通道自监督残差 `r_tmp / r_geo / r_goal / r_anom` + self-normalized conformal + CUSUM 信任门；任务条件化原语参数 `θ_prim(u,M)`；显式生命周期状态机 INIT/GROUND/TRACK/RECOVER/HOLD；VOI-MAP 语言 grounding + 预算调度；WAVE-SERVO 虚拟力 + TD-PC。约束继续生效：单模型、无新可训练参数、无 test-time 权重更新、无腕部相机内参/深度/F-T 传感器假设、OOD-G 保留边界。

### 0.2 三个灵感词的落地点

| 词 | 落地位置 | 与现有架构的关系 |
|---|---|---|
| **自主导航** | 导航感知残差 `r_nav`、VOI-MAP 扩展为 `M_nav` 占用-语义联合地图、路径成本预测 `C_path` | 在 VOI-MAP 上增加移动基与障碍信念，复用 `r_geo / r_goal` 通道，新增导航一致性残差，不改地图核心结构 |
| **人机协作** | 人机意图残差 `r_human`、安全距离残差 `r_safe`、协作模式开关 `σ_collab ∈ {LEAD, SHARE, YIELD}` | 复用 VLA 跨注意力权重提取人-动作对齐分数，零参数；安全残差来自几何地图与人体骨架距离估计；模式切换通过 VOI 成本重加权实现 |
| **通用机器人平台** | 能力剖面 `C_robot`、形态无关原语空间 `Φ`、跨形态归一化映射 `norm_morph` | 在原语库 `θ_prim` 上叠加平台能力约束，同一 VLA 计划通过确定性归一化映射到不同自由度机械臂/移动基；不引入新学习模型 |
| **消融与门控** | G26–G28 验证导航/协作/通用化贡献 | 逐个剥离 `r_nav / r_human / C_robot` 验证零样本泛化；作为安全与跨平台门控依据 |
| **状态解耦** | 生命周期 `σ` 与协作模式 `σ_collab`、导航子状态 `σ_nav` 的正交解耦 | VLA 30 步计划层与 5 步执行层解耦，导航/协作/抓取子状态独立计时与恢复，防止相互阻塞 |

### 0.3 本轮不做什么

- 不训练导航专用网络/人形检测器/协作策略网络；`r_nav / r_human / r_safe` 全部自监督/注意力复用
- 不做 test-time 微调、不新增可训练权重
- 不假设 RGB-D、激光雷达、腕部内参、力传感器
- 不承诺解决 OOD-G
- 不在单块决策中做 >10 步规划，保持 <2ms 决策增量
