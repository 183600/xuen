# 第 58 轮（承接第 57 轮「小样本×跨模态×个性化」IP-133~138；灵感循环第 1 轮；本轮灵感：「碰撞检测」×「状态机」）

> 第 57 轮把安全的赌注拆成三份——摊销先验（少样本）、跨模态对账、个性化有界信任——并以五类证据门与证书 J_p 把它们缝进承诺。但它在**时间轴**与**控制层**各留一个盲点，而且这两个盲点互相掩护：**(a) 证据只在检查点成立、不在轨迹上成立**。MFSL/XMC/FSE 都是"到点拍照"：在 t_i 采一次、判一次；可承诺是*过程*——足端从悬空到接触要扫过一段空间与时间，信念在此期间连续演化，一块"薄而滑/薄而脆"的区域完全可以整段躲在两次安全采样之间，两端安全、中间却是不安全。这正是离散碰撞检测的**隧穿（tunneling）**：采样越稀、运动越快，越会穿过薄墙。第 57 轮所有"证据说可信"的保证，在两次采样之间是空的。**(b) 承诺控制逻辑本身没有被证明**。证据门、同意阶梯、步态切换、PTM 授权、异步 L2 超时在实现里其实是一个手写的隐式状态机，而第 57 轮只用"交互单调性"做了局部论证：每个机制单独不升险。局部单调不等于全局安全——并发的降级/升级竞态、探针执行途中到来的 L2 超时、传感器掉线、人类接管，都可能让系统落进"局部都没错、组合起来却没有证书"的状态。这是状态机领域的老教训：**没有可达性证明的守卫，只能证明你想到的路径**。本轮两个灵感各补一维：**碰撞检测**把"证据是否成立"从点扩展到**扫掠区间**（宽相/窄相、保守推进、撞击时刻 TOI、猜测接触、层/掩码）；**状态机**把"承诺如何转移"从隐式代码提升为**带守卫与不变量的分层状态图 + 监督控制 + 模型检验**，把物理与人类当作不可控事件、只在获胜域里承诺。核心命题由"证据说可信"升级为 **"证据在整条接触轨迹上可证不撞、且承诺状态机可被证明安全"**。

核心矛盾：
- **H29（隧穿 vs 保守推进）**：只在检查点判证据会把"薄的不安全带"漏在采样之间；要连续判定就必须有信念演化的漂移上界 L——L 估小了就是隧穿（假安全），L 估大了就是冻结（永远不敢走）；安全的赌注从"先验质量"再次后移到"漂移界质量"。
- **H30（可靠剪枝 vs 分析瘫痪）**：宽相包络必须**过近似**不安全集才能可靠剪枝，但包络一松，模糊带变大、窄相探针全落在松包络里，系统退化为"处处都要精确检查"甚至永久停；包络一紧则可能欠近似，把不安全剪成安全。
- **H31（形式化证明 vs 模型-现实缝隙）**：状态图安全证明只在抽象模型内成立；事件字母表漏掉一个不可控事件、抽象把真实转移削掉一条，证明就从"保证"变成"虚假信心"，而且比没有证明更危险。
- **H32（不可控事件 vs 活性）**：把物理打滑、掉线、人类接管都当不可控事件并要求"任何情况下不升险"，最保守的做法是永远停在安全态——安全但不干活；必须同时证明活性（终将承诺/撤回/停止），否则"证明安全"等价于"证明放弃任务"。

## 0. 直觉与动机

**灵感 1（离散 vs 连续碰撞检测 → 证据隧穿与扫掠证据）**
直觉：游戏里用离散采样做碰撞，高速子弹会穿过薄墙；解法不是"采样更密"，而是**连续碰撞检测**：对整段扫掠体做判定、用保守推进求出最早的撞击时刻。第 57 轮的证据判定恰好是"离散采样"版本：足端在 t_i 与 t_{i+1} 各有一份安全信念，中间的扫掠段没人负责。把证据状态 e(t)=(信念、地图、信任、同意) 看成配置空间里的点，把"不可承诺"看成障碍 U，则承诺安全问题就变成**证据空间里的碰撞避免**：不是问"这个点安不安全"，而是问"这段扫掠轨迹会不会撞进 U"。

**灵感 2（宽相/窄相 + 碰撞层掩码 → 两级证据剪枝）**
直觉：碰撞检测先用廉价 AABB/BVH 粗筛，只有候选对才做昂贵精确检测；碰撞层/掩码决定哪些物体之间才需要检测。证据侧同理：先用粗地图加漂移界构造**保守不安全包络** E⁺（只许过近似），用扫掠区域与 E⁺ 做三种判定——不相交则**可靠判安全**、完全包含则**可靠判不安全**、相交则只把模糊带交给昂贵的窄相（探针/对账/共形带）。层掩码对应"哪些证据类在 L0/L1/L2 可参与"，把第 57 轮的硬禁令变成结构化的可见性规则，而不是散落的 if。

**灵感 3（TOI / 保守推进 / 猜测接触 → 撞击时刻证书与可撤回承诺）**
直觉：连续碰撞检测不只回答"会不会撞"，还回答"还有多久撞"（time of impact）。证据侧：用有符号裕度 m(e)=dist(e,U) 与漂移界 L，最早穿越时刻 t*=m(e)/L；承诺的条件从"现在安全"升级为"**在撞上不安全边界之前，一定来得及停/撤**"：t* ≥ τ_stop+τ_react+τ_cert。当 t* 落在"来不及完全确认、但还来得及撤回"的窗口时，借鉴**猜测接触（speculative contact）**：先做一个可撤回的接近/轻触（tentative），在截止前拿到升级证据就转正，否则自动回滚——把感知时延变成一个有界的可逆窗口，而不是二选一的"现在赌"或"永远等"。

**灵感 4（分层状态机 → 守卫、不变量、并行区）**
直觉：第 57 轮的协商/授权/步态/证据门是四个并发关注点，却塞在一个隐式控制流里。分层状态图（statechart）正好表达：Belief（ID/OOD/共形）、Consent（L0/L1/L2）、Trust（PTM auth）、Motion（步态/接触）作为并行区，转移带**守卫**（evidence gate ∧ CEV ∧ TIC），每个超级状态声明**不变量**（含不可逆接触 ⇒ 存在 J_s）。并行区让"个性化只改参数、不改规则本体"从口号变成结构约束：SSS 的转移拓扑被冻结，PTM 只能改守卫里的数值。

**灵感 5（监督控制/安全博弈/模型检验 → 只在获胜域承诺）**
直觉：物理打滑、掉线、人类接管不是我们能"控制"的事件，只能观测和承受；这正是监督控制理论里**可控事件 vs 不可控事件**的划分。把承诺系统建成一个安全博弈：环境（物理+人）出不可控事件，系统出可控事件；用最大受控不变集（获胜域 W）刻画"无论环境怎么出牌，都还能维持不变量"的状态集合。承诺只在 W 内发生；不可控事件只允许把状态推向更保守的方向；离线用模型检验证 □Inv 与 ◇(commit∨abort∨stop)，在线用监视器把真实事件轨迹投影回自动机，**一旦出现模型外事件就安全停，而不是静默继续**。这补上第 57 轮"局部单调"无法给出的全局保证。

**灵感 6（合流 → 证据空间避碰 = 承诺的"无碰撞配置空间"）**
直觉：把 1–5 叠起来，承诺的可行域就是"证据配置空间里的无碰撞自由空间"：宽相/窄相负责**能不能**、TOI/猜测接触负责**来不来得及**、监督状态图负责**每一步是否都在获胜域内**。碰撞检测的 C-free 对应这里的"可承诺证据域"，离散/连续之分对应"检查点证据/扫掠证据"，碰撞层对应"证据类×接触级"，运动学积分对应"信念漂移上界"。这不是隐喻，而是可计算的对偶：所有碰撞检测的可靠性论证（保守过近似、TOI 单调性、细完备）都能平移。

**副产品（未预期碰撞 = 免费探针）**
直觉：碰撞检测区分"计划接触"与"未预期碰撞"；后者在第 57 轮是纯负事件，其实它携带真实接触信息。把每次未预期碰撞登记为一次**带 provenance 的免费探针**（collision_log），更新该区域触探/本体证据并回溯校验同源标注——负事件因此也变成证据，但绝不因此放宽承诺门。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（连续证据轨迹与时隧穿 CEV）** 对接触计划 π 的时间区间 I=[t0,t1]，证据状态 e(t)=(b(t),𝓜_t,s_o(t),c(t))；不安全集 U={e : 执行不可逆接触后 P_fail>δ_f 或证据门不过}。设漂移上界 L 满足 ‖e(t′)−e(t)‖_E≤L·|t′−t|（由步速、地形梯度、信念更新与观测缺失联合给出，见 A41）。扫掠证据球 B_i=B(e(t_i),L·Δt)。若 ∃t∈(t_i,t_{i+1}) 使 e(t)∈U 而 e(t_i),e(t_{i+1})∉U，称**证据隧穿**。CEV(π)=True ⇔ 自适应细分后每个子区间满足 B(e(a),L(b−a))∩U=∅；若细分到 Δt<Δt_min 仍相交，返回**不可证/拒绝**（保守失败，绝不放行）。故 CEV 是安全的**充分条件**：通过必有全程安全，失败可能是假阳性。

**定义 140（撞击时刻证书 TIC）** 有符号证据裕度 m(e)=dist(e,U)>0。最坏漂移下最早穿越 t*=m(e(t0))/L。承诺证书 TIC.ok ⇔ t*≥τ_stop+τ_react+τ_cert（τ_stop 物理制动/撤回时间含估计误差，τ_react 决策-执行时延，τ_cert 证据刷新时延）。若 t*∈[τ_react, τ_stop+τ_react+τ_cert) 进入猜测承诺；若 t*<τ_react 则不可撤回、禁承诺。TIC 与 CEV 互补：CEV 判"整段是否无碰"，TIC 判"碰之前是否来得及反应"。

**定义 141（两级证据剪枝 BNP）** 宽相：由粗地图与 L 构造保守不安全包络 E⁺(r)⊇U∩Reach(r)（只可过近似，绝不可欠近似）。扫掠区域 S(π)=∪_t B(e(t),LΔt)。若 S∩E⁺=∅ ⇒ 可靠判安全；若 S⊆E⁺ ⇒ 可靠判不安全；否则模糊集 A=S∩E⁺ 交窄相。窄相只在 A 上用精确证据（探针/对账/共形带），误差预算按 |A|/|S| 摊销。证据层掩码 Λ 规定 L0/L1/L2 各自可见的证据类（EV-xmodal 仅 L1 等硬禁令结构化）。可靠性要求：宽相"安全/不安全"判定与窄相一致；BNP 只改变代价、不改变结论。

**定义 142（猜测承诺 SCom）** 状态 sc∈{Idle,Tentative,Confirmed,Aborted}。当 TIC 未完全满足但 t*≥τ_react 且阶段可逆（L0/L1 或接触前）时允许 Tentative：执行可撤回的接近/轻触；若在 t*−τ_react 前取得升级证据则 Confirmed，否则自动 Aborted 并进入恢复态。约束：Tentative 期间禁止不可逆动作；abort 必须在 τ_stop 内物理可行（A45）；每次窗口有界，禁止 Zeno 式反复试探。

**定义 143（监督式安全状态图 SSS）** HSM=(S,s0,E=E_c⊎E_u,T,Inv,{Belief,Consent,Trust,Motion},history)。守卫 g=evidence_gate(c)∧CEV.ok∧(TIC.ok∨SCom 合法)。不变量 Inv(s)：s 含不可逆接触 ⇒ 存在有效 J_s。监督器在抽象积自动机 A=α(S)（保守过近似：只加行为、不减行为）上计算最大受控不变集/获胜域 W=νX.{s∈X | ∀e∈E_u,δ(s,e)∈X∪{fail-safe}；∃e∈E_c 使进展}，要求 s0∈W，W⊨□Inv 且 W⊨◇(commit∨abort∨stop)。不可控事件只允许把状态推向更保守集合；模型外事件触发 fail-safe stop，绝不静默忽略。运行时监视器把实际事件轨迹投影到 A，偏离即安全停并保存反例。

**定义 144（连续证据证书 J_s）** J_s=(π_swept, L 及在线验证残差, t* 证书, BNP 剪枝日志, SCom 窗口日志, SSS 轨迹与 W 成员证明, 监视器日志, 不可控事件账本, collision_log)。继承 J_p 全检。J_p/J_m 证明"证据在点上是真的"，J_s 证明"它在整段时间上没撞、控制状态机没走丢"——纵向证书。

## 2. 关键算法伪代码（完整版见产物区）

```python
def continuous_evidence_verify(plan, e, U, L, dt_min):     # IP-139
    trace = []
    for (t0, t1) in plan.contact_intervals:
        stack = [(t0, t1)]
        while stack:
            a, b = stack.pop()
            if disjoint(ball(e(a), L * (b - a)), U):
                trace.append(('safe', a, b)); continue
            if b - a <= dt_min:                              # 细到极限仍相交
                return Verdict(False, trace + [('tunnel', a, b)])  # 拒绝
            mid = (a + b) / 2; stack += [(mid, b), (a, mid)]
    return Verdict(True, trace)

def tic_certificate(e, U, L, tau_stop, tau_react, tau_cert):  # IP-140
    m0 = signed_dist(e, U)
    if m0 <= 0: return Cert(False, t_star=0.0)
    t_star = m0 / max(L, EPS)
    return Cert(t_star >= tau_stop + tau_react + tau_cert, t_star, m0, L)
```

```python
def supervised_step(s, ev, sup):                          # IP-143
    if ev in sup.Uc:                                      # 不可控：只许更保守
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| CEV | O(Σ Δt/Δt_min · c_b) | O(trace) | L 可靠、细完备（A41） |
| TIC | O(1)/事件（裕度查询 O(1)） | O(1) | t* 保守、stop 可行（A45） |
| BNP | 宽相 O(\|V_env\|)+窄相 O(\|A\|·d) | O(\|V_env\|+\|A\|) | E⁺ 只过近似（A42） |
| SCom | O(1)+定时器 | O(1) | abort 物理可行、窗口有界 |
| SSS | 离线 O(\|S\|·\|T\|)（可组合降维）/在线 O(1)/事件 | O(\|S\|+\|W\|) | 抽象过近似、事件字母完备（A43/A44） |
| J_s | O(trace) | O(trace) | 时间对齐、反例可复现 |

**正确性定理（CCES, Collision-Certified Evidence Soundness 概要）**：在 A33–A40 上加 (A41) 漂移上界 L 是真实信念演化的有效上界且在线残差验证诚实；(A42) 宽相包络 E⁺ 恒为不安全集的过近似；(A43) 状态图抽象 α 只加行为不减行为；(A44) 不可控事件分类与监视器诚实、事件字母表完备；(A45) SCom 的 abort 在 τ_stop 内物理可行。则：(i) **无隧穿**：CEV 通过 ⇒ ∀t∈I, e(t)∉U；(ii) **TIC 可靠**：TIC.ok ⇒ 存在已验证停/撤策略在进入 U 前完成；(iii) **乘积安全**：s0∈W 且运行事件⊆E 建模 ⇒ □Inv，且不可控事件不升险；(iv) **活性**：W 无受控死端，◇(commit∨abort∨stop) 在 k_probes+k_cons+K_scom 界内；(v) 部署界在第 57 轮各项上追加 −P(L 失效)−P(宽相欠近似)−P(模型缝隙)−P(abort 不可行)。

## 5. 风险与缓解

|---|---|---|

## 6. 本轮最大风险

**一句话**：本轮把安全从"采样点证据"扩展到"整条轨迹可证避碰"并交给模型检验过的状态机执行，最大风险是**被证明的模型与真实运行的系统不是同一个**——漂移界 L 的保守性、宽相包络的过近似、状态图抽象与真实事件字母表的缝隙，都会被"已证明安全"的光环掩盖；一旦发生模型外事件（未分类的不可控扰动），若运行时监视器不能立刻降级为安全停，形式化证明反而会制造比没有证明时更强的虚假信心。

### IP-139 CEV（连续证据判定，防隧穿）

```python
def continuous_evidence_verify(plan, e, U, L, dt_min):
    trace = []
    for (t0, t1) in plan.contact_intervals:        # 每个接触/扫掠区间
        stack = [(t0, t1)]
        while stack:
            a, b = stack.pop()
            band = ball(e(a), L * (b - a))         # 保守扫掠证据球
            if disjoint(band, U):
                trace.append(('safe', a, b)); continue
            if b - a <= dt_min:                    # 细到极限仍相交
                trace.append(('tunnel', a, b))     # 不可证 → 拒绝（保守失败）
                return Verdict(False, trace)
            mid = (a + b) / 2                      # 保守推进：自适应细分
            stack += [(mid, b), (a, mid)]
    return Verdict(True, trace)

def online_L_validate(L, residuals):               # A41：漂移界必须被持续验证
    L_hat = percentile(residuals, 1.0 - delta_L)   # 高分位残差
    if L_hat > L:                                  # 界失效 → 立即降级
        return NewBound(L_hat * inflation), 'degrade'
    return L, 'ok'
```

### IP-140 TIC（撞击时刻证书）

```python
def tic_certificate(e, U, L, tau_stop, tau_react, tau_cert):
    m0 = signed_dist(e, U)                         # 到不安全边界的距离
    if m0 <= 0:
        return Cert(ok=False, t_star=0.0, reason='already_unsafe')
    t_star = m0 / max(L, EPS)                      # 最坏漂移下最早穿越
    need = tau_stop + tau_react + tau_cert
    if t_star >= need:
        return Cert(True, t_star, m0, L, margin=t_star - need)
    if t_star >= tau_react:                        # 还来得及撤回
        return Cert(False, t_star, m0, L, mode='speculative')
    return Cert(False, t_star, m0, L, mode='forbidden')  # 不可撤回
```

```python
def broad_narrow_evidence(plan, e, U, coarse_map, L, Lambda):
```

```python
        return commit(plan, 'confirmed')
    if cert.mode == 'speculative':
```

### 正确性定理（CCES, Collision-Certified Evidence Soundness）

假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；新增：

- **(A41) 漂移界诚实**：L 是 ‖ė(t)‖_E 的有效上界，且在线残差验证在 L 失效时立即降级（不允许"静默沿用旧界"）。
- **(A42) 宽相保守**：E⁺(r)⊇U∩Reach(r)，即只过近似、绝不欠近似；宽相"安全/不安全"与窄相一致。
- **(A43) 抽象保守**：α 只加行为不减行为（may-abstraction），故 A 上的证明可下推到真实系统。
- **(A44) 事件完备**：不可控事件分类与运行时监视器诚实，真实事件 ⊆ 建模字母表；模型外事件触发安全停。
- **(A45) 撤回可行**：SCom 的 abort 在 τ_stop 内物理可行，且 Tentative 期间无可逆性破坏。

则：

1. **无隧穿**：CEV(π)=True ⇒ ∀t∈I, e(t)∉U；CEV=False ⇒ 明确拒绝或进入更保守分支，绝不因"两端安全"而放行中间。
2. **TIC 可靠**：TIC.ok ⇒ 存在已验证的停/撤策略在 e(t) 进入 U 前完成；失效贡献 ≤ P(L 失效)+P(stop 失效)。
3. **乘积安全**：s0∈W 且运行事件⊆E 建模 ⇒ □Inv（尤其"不可逆接触 ⇒ 存在 J_s"）；不可控事件只把状态推向更保守集合，不存在升险路径。
4. **活性**：W 无受控死端；◇(commit∨abort∨stop) 在 k_probes+k_cons+K_scom 内成立；SCom 窗口有界排除 Zeno。
5. **纵向部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1])
             − P(L 失效) − P(宽相欠近似) − P(状态图模型缝隙) − P(abort 不可行)·horizon
             − P(𝓜 陈旧未检出) − P(护盾回退失败)
```

**关键解耦**：第 57 轮把"效率"押在元先验上、把"保底"押在共形带上；本轮把"时间维度"押在 **CEV/TOI 的保守推进**上、把"控制维度"押在 **W 上的模型检验 + 运行时监视兜底**上。元先验可以错、L 可以暂时估小、事件字母表可以暂时漏——但每一层失效都被下一层的保守默认（拒绝/回滚/安全停）接住：**形式化证明负责"已知世界里不犯错"，运行时监视负责"未知事件发生时立刻变保守"**。
