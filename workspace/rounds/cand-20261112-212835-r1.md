# 第 62 轮（承接第 61 轮「具身语义进化闭环 ESEC」IP-173~182；新一轮灵感循环第 1 轮；本轮灵感：「场景理解」×「三维感知」）

> 第 61 轮用 USR×MEL×DMS×SRT-Dual×PCE+++++ 把场景、意图、阻抗、证据统一到共享嵌入空间 ℝ^d_us，并以语义-实时双流解耦大模型推理与 1kHz 控制。但回看其「场景」一环，仍有五个根本性缺口：
> 1. **语义悬浮于二维**：MEL 的视觉编码器是 ViT-L/14，scene_emb 本质是「2D 图像块特征的全局池化」，没有显式三维几何——它不知道物体在基座标系中的 SE(3) 位姿、真实尺寸、支撑关系、可接触面，也无法回答「这条缝有多宽」「这个把手能否从右侧扣住」。
> 2. **阻抗先验是全局标量**：Π 输出一组全局 K，而真实接触的刚度、摩擦、可达性随接触点 x_c 剧烈变化；同一个杯子，杯壁、杯口、杯柄的可行阻抗完全不同。全局先验必然在某个接触点上过软或过硬。
> 3. **几何不确定性被静默忽略**：深度噪声与 SLAM 位姿漂移会让「看起来确定」的几何先验系统性偏乐观；一旦 μ 被高估，F_max 就悄悄越过真实摩擦极限——这比第 61 轮的「语义-现实鸿沟」更底层，是「几何幻觉」。
> 4. **场景理解是被动的**：遮挡、反光、透明/黑色材质下，单帧被动感知无法消解歧义；机器人不会「换个角度再看一眼」或「轻碰一下试试」，而人类抓取前几乎总会这样做。
> 5. **语言与三维脱节**：「放到杯子左边」中的「左边」是三维空间关系；第 61 轮 DMS 的 intent_emb 没有落到具体三维区域，导致指代只能靠语义相似度硬猜。

## 0. 直觉与动机

**灵感 1（场景理解 → 几何-语义-物理场景图 GSSG）**
直觉：场景理解的最小可执行单元不是「一个类别标签」，而是「一个带位姿、尺寸、材质、支撑关系与不确定性的物体/表面」。构建 **几何-语义-物理场景图 GSSG**：节点 v=(类别 c、位姿 T∈SE(3)、尺寸 b、物理先验 φ、位姿协方差 Σ_v)；边 e=(u,v,关系 r,度量距离 d,协方差 Σ_e)，关系含 on/support/inside/near/left_of/occludes/reachable。用 **SE(3)-不变图 Transformer** 编码为 scene_emb——把「看到什么」升级为「在哪里、多大、靠什么支撑、从哪边够得着」。场景因此从一张图像变成一个可查询、可审计、可局部更新的三维结构。

**灵感 2（三维感知 → 可供性占据场 AOF）**
直觉：阻抗不是场景的全局属性，而是「接触点邻域」的属性。构建 **可供性占据场 AOF**：在稀疏体素/TSDF 上定义连续场 A(x)=(占据 o、可供性 a、局部物理先验 φ、几何不确定度 u)。EEIS 在预测接触点 x_c 处查询 A(x_c)，得到 **空间变化的阻抗先验 K_prior(x_c)**，而不是第 61 轮的单一全局 K。关键洞见：三维感知的价值不在于多一个模态，而在于让「哪里能碰、怎么碰、碰多大力」变成体素级的可计算量，且实时流只需 O(1) 体素哈希查询。

**灵感 3（三维感知的不确定性 → 几何不确定性传播 GUP）**
直觉：三维几何不是真值，而是带协方差的估计。必须把「深度噪声→点协方差→表面法向协方差→摩擦/刚度不确定度→安全力限」逐级传播。形式化为 **GUP**：用一阶雅可比把深度方差与 SLAM 位姿协方差推到世界系点协方差 Σ_w，再用法向切投影得到 Σ_n，最后给出 **保守下界** μ_lb = μ̂ − z_{1−α}σ_μ，并令 F_max ≤ μ_lb·N·margin。关键洞见：安全不来自「更准的均值」，而来自「正确的尾部」；宁可保守，不可自信地越过摩擦锥。

**灵感 4（主动感知 → 主动三维感知 A3P）**
直觉：当接触相关区域的几何/材质不确定度超过阈值时，机器人应先「看/探」再「动」。构建 **A3P**：动作集 = {换视角、轻触探测、等待}；用体素占据熵的互信息近似信息增益 IG(a)，以 VOI 门控：a* = argmax [IG(a) − λ·cost(a)]，受三维感知预算 B_geom 约束。轻触探测用滑移起始力估 μ、用力-位移斜率估 k。关键洞见：感知不是流水线的固定前置，而是 **由执行风险触发的主动决策**，并且要进入对话（「我先换个角度确认一下」）。

**灵感 5（语言-三维接地 → 指代三维锚定 R3G）**
直觉：「杯子左边的空隙」是一个三维区域查询，不是文本相似度。构建 **R3G**：把指代表达解析为场景图查询（类别选择 + 空间关系约束 + 自由空间约束），在 GSSG/AOF 上求交，输出三维区域 R 与置信度 conf。若 conf < τ，交由 DMS 发起澄清。关键洞见：语言意图必须落到 **同一坐标系下的区域**，否则 intent_emb 再对齐也无法消除歧义。

**灵感 6（合流 → 三维锚定的场景理解闭环 GSUL）**
直觉：把 GSSG、AOF、GUP、A3P、R3G 嵌入第 61 轮的 SRT-Dual，形成 **三维锚定的场景理解闭环 GSUL**：感知流（~10–30Hz）构建 GSSG/AOF 并做 GUP；语义流（~5–30Hz）运行 MEL+DMS+R3G；实时流（~1–10kHz）在接触点查询 AOF 得到局部先验并编译 K_safe。USR 增加几何编码器 E_geom，语义锚点增加 AOF 版本、坐标系、位姿协方差与几何不确定度；预算升级为 PCE++++++（新增 B_geom），证书升级为 J_3d。**核心命题：三维感知不是给语义再加一个输入，而是把「语义先验」改造成「带几何置信度、可被实时控制安全消费的空间场」。**

## 1. 形式化定义（增量：定义 173–184）

**定义 173（几何-语义-物理场景图 GSSG）** 场景图 G_t = (V_t, E_t, X_t, Φ_t, Σ_t)：
- **节点** v_i = (id_i, c_i ∈ C, T_i ∈ SE(3), b_i ∈ ℝ³, φ_i ∈ 𝒫, Σ_i ∈ Sym⁺(6), frame_i)，其中 T_i 为物体位姿，b_i 为有向包围盒尺寸，φ_i=(μ_i,k_i,η_i,σ_i) 为物理先验，Σ_i 为位姿协方差（6×6，含旋转/平移）。
- **边** e_ij = (i,j, r_ij ∈ R, d_ij ∈ ℝ, Σ_ij)，R = {on, support, inside, near, left_of, right_of, above, below, occludes, reachable}；d_ij 为度量距离，Σ_ij 为关系度量协方差。
- **时序**：G_t 由多目标跟踪器维护 track_id，跨帧增量更新；未被观测的节点保留但不确定度随时间增长 Σ_i ← Σ_i + Q·Δt。
- **编码器** E_gssg: G → ℝ^d_us：以「距离、法向夹角、相对方位」等旋转不变量为边特征，用 L 层图 Transformer + attention pooling 得 scene_emb。要求 **置换不变** 且 **全局 SE(3) 不变**：E_gssg(g·G)=E_gssg(G)，∀g∈SE(3)。

**定义 174（可供性占据场 AOF）** A_t: ℝ³ → [0,1]×[0,1]×𝒫×ℝ_+，A_t(x)=(o(x), a(x), φ(x), u(x))：
- o(x)：占据概率，由 TSDF/深度融合得到；
- a(x)：可供性分数（可抓/可推/可支撑/可插入），由 GSSG 语义 + 局部几何（曲率、法向、开口宽度）预测；
- φ(x)=(μ(x),k(x),η(x))：局部物理先验，由材质分类 + 历史触觉校准 + 相似材质迁移融合；
- u(x) ≥ 0：几何不确定度（由定义 175 的 GUP 给出）。
- **构建**：对每个观测体素写入上述四元组；未观测体素取保守默认 A_⊥ = (0, 0, φ_cons, +∞)。
- **查询** Q_AOF(x_c) → (φ(x_c), u(x_c))，用稀疏体素哈希 + 三线性插值，O(1) 期望时间。
- **时序更新**：仅在观测覆盖区域做指数融合 A_t=(1−β)A_{t−1}+βA_new；未观测区不确定度按 u ← u + ν·Δt 增长。

**定义 175（几何不确定性传播 GUP）** 给定深度 z、内参 K、深度方差 σ_z²、像素方差 σ_uv²、SLAM 位姿 (R, Σ_pose)：
- 点协方差：p=zK⁻¹[u,v,1]ᵀ，J=∂p/∂(u,v,z)，Σ_p = J·diag(σ_uv²,σ_uv²,σ_z²)·Jᵀ；
- 世界系协方差：Σ_w = R·Σ_p·Rᵀ + Σ_pose（一阶保守叠加）；
- 法向协方差：n 为局部 PCA 法向，切投影 P=I−nnᵀ，Σ_n = P·Σ_w·Pᵀ；
- 物理先验不确定度：σ_μ = ‖∂μ/∂n‖·√(tr(Σ_n)) + σ_μ,mat；
- **保守安全约束**：
  ```
  μ_lb(x) = μ̂(x) − z_{1−α}·σ_μ(x)
  F_max(x) ≤ max(0, μ_lb(x))·N_normal·margin
  k ∈ [k̂/(1+κ·u), k̂·(1+κ·u)],  η ∈ [η̂/(1+κ·u), η̂·(1+κ·u)]
  K_p ← K_p/(1+κ·u),  K_d ← K_d·(1+κ·u)     # u 越大越软、越阻尼
  ```
- **保守性要求**：Σ_pred ⪰ Σ_true（半正定序），即预测协方差不得小于真实协方差。

**定义 176（主动三维感知 A3P）** A3P = (𝒜_perc, IG, VOI, B_geom)：
- **动作**：𝒜_perc = {move_view(θ,φ), probe(x, f_probe), wait}；probe 力上限 f_probe ≤ F_probe_max。
- **信息增益**：IG(a) = H(A_{R_c}) − 𝔼_{z∼p(z|a)}[H(A_{R_c}|z,a)]，其中 R_c 为接触相关区域，H 为体素占据/材质熵。
- **VOI 门控**：a* = argmax_{a∈𝒜_perc} [IG(a) − λ_move·travel(a) − λ_time·latency(a) − λ_safe·risk(a)]，若 VOI(a*) < τ_voi 或 B_geom 不足则不感知。
- **探测估计**：μ̂ = F_slip/N_normal，k̂ = dF/dx 在初始线性段斜率；探测结果写回 AOF 并降低 u(x)。
- **安全**：探测动作本身必须满足 F_probe ≤ F_probe_max ∧ 不进入已占据体素。

**定义 177（指代三维锚定 R3G）** 指代表达 L 到三维区域 R ⊆ ℝ³ 的映射 Γ(L, G, A) → (R, conf)：
- 解析为查询 Q_L = (C_q, ℛ_q, free_space?)，C_q 为目标类别集合，ℛ_q 为空间关系约束（如 left_of(anchor)、on(anchor)、inside(anchor)）。
- 节点选择：V_q = {v ∈ V : c_v ∈ C_q ∧ satisfies(v, ℛ_q, G)}。
- 自由空间查询：R = {x : o(x) ≤ o_max ∧ clearance(x) ≥ c_min ∧ a(x) ≥ a_min}。
- 区域：R = ⋃_{v∈V_q} box(v)（或自由空间体素集）。
- 置信度：conf = ∏_{v} conf_ground(v) · ∏_{r∈ℛ_q} margin(r)；conf < τ_r3g ⇒ 触发 DMS 澄清。

**定义 178（三维锚定的统一语义空间 USR⁺）** USR⁺ = (E_scene, E_geom, E_intent, E_impedance, E_evidence, Π, Anchor⁺)：
- 场景编码：scene_emb = W_g·E_gssg(G) + W_a·E_aof(A)，W_g,W_a 可学习融合权重；
- 意图编码：intent_emb = E_intent(b_intent, region_emb)，region_emb=E_geom(R)；
- **语义锚点扩展**：Anchor⁺ = (scene_emb, intent_emb, φ_phys, U_mel, aof_version, frame_id, Σ_pose, u_geo, coverage, timestamp, version, checksum)；
- **局部投影**：K_prior(x_c) = Π(scene_emb ⊕ intent_emb ; Q_AOF(x_c))，即投影头同时消费全局语义与接触点局部物理先验。
- **坐标系一致性**：anchor 记录 frame_id 与 T_base_world；若实时流检测到 frame 跳变 ‖ΔT‖ > τ_frame，立即作废该 anchor。

**定义 179（三维锚定的场景理解闭环 GSUL）** 三条异步流水线：
- **感知流**（10–30Hz）：obs → GSSG.update → AOF.build → GUP.inflate → 写 anchor⁺（aof_version++）。
- **语义流**（5–30Hz）：R3G.ground(L) → MEL.infer(V,T,P,L,scene_emb,region) → DMS.step(U,region,conf) → USR⁺.commit。
- **实时流**（1–10kHz）：x_c = EEIS.predict_contact_point → Q_AOF(x_c) → K_prior(x_c) → EEIS.compile_with_geom_prior → ERTC.dispatch → EV_exec → 证据回写。
- **主动感知分支**：若 B_geom 允许且 VOI(a*) ≥ τ_voi，则先执行 move_view/probe，感知流重跑后再进入执行。
- **一致性**：所有版本号单调递增；anchor、AOF、GSSG 版本在 J_3d 中对账；语义流超时则实时流使用「上一有效 anchor + GUP 保守膨胀」。

**定义 180（几何一致性对账 XMC-geo）** 在三维空间校验 2D 语义与 3D 几何是否自洽：
```
D_geo = λ1·e_reproj + λ2·e_depth + λ3·e_normal + λ4·e_free
e_reproj = ‖π_K(T_wc·T_i·0) − bbox2d_i.center‖       # 节点投影 vs 2D 检测
e_depth  = |z_depth(π(T_i·0)) − z_gssg(T_i·0)|
e_normal = 1 − |⟨n_2d, n_3d⟩|
e_free   = 1[存在 3D 自由点落入占据体素 ∨ 占据点落入自由体素]
D_geo > τ_geo ⇒ 触发感知流重算（而非仅 MEL 重推理）
```
同时保留第 61 轮 XMC+++ 的语义对账 D⁺_sem，二者共同构成「语义-几何」双重对账。

**定义 181（七维认知-感知-语义预算 PCE++++++ / B_cog6）** 在第 61 轮 B_cog5（实际含 6 项）上新增 B_geom：
```
B_cog6 = (B_scene, B_intent, B_ros, B_exec, B_mel, B_usr, B_geom)
B_geom = (points_per_frame N_p, voxel_res r_v, nbv_steps, probe_budget, gssg_freq, aof_freq)
cost_geom = λ_p·N_p/N_p,max + λ_v·r_v,min/r_v + λ_nbv·steps/steps_max
          + λ_probe·probes/probe_max + λ_upd·(gssg_freq/aof_freq 超限)
```
- **降级链**（安全项永不降级）：全分辨率 AOF → 粗分辨率 AOF（r_v×2）→ 局部 patch + 全局保守先验 → 冻结 AOF；NBV 关闭；probe 关闭。GUP 的保守膨胀 **始终开启**，即使所有预算耗尽。
- **VOI 扩展**：voi_cog6 = VOI_meta − cost_mel − cost_usr − cost_geom − cost_exec；任一预算耗尽触发对应降级且不得降低安全约束。

**定义 182（三维-语义-执行联合证书 J_3d）** 在第 61 轮 J_sem_exec 上增加几何证明：
```
J_3d = (J_sem_exec, gssg_version, aof_version, frame_id,
        tr(Σ_pose), u_geo_max, e_reproj_p95, coverage(R_contact), r3g_conf)
Valid(J_3d) ⇔ Valid(J_sem_exec)
             ∧ u_geo_max ≤ τ_geo
             ∧ coverage(R_contact) ≥ c_min
             ∧ e_reproj_p95 ≤ τ_reproj
             ∧ frame_consistent
```
其中 coverage(R_contact) 为接触相关区域中被有效观测体素覆盖的比例。

**定义 183（时空占据预测 STOF）** 在 GSSG 的时序边上预测未来接触相关占据：
- O_{t+τ}(x) = 𝔼[o_{t+τ}(x) | G_{t−k:t}]，由常速度模型 + 图神经 ODE 给出；
- 预测不确定度随 τ 单调增长：tr(Σ_O(τ)) ≤ tr(Σ_O(τ+Δ))；
- **预判式阻抗**：x_c^pred = argmax_{x} contact_likelihood(O_{t+τ}, A)，提前用 K_prior(x_c^pred) 预热，减少接触瞬态力超调。

**定义 184（三维场景理解质量度量 SQM）** SQM = (完整度 Comp、正确度 Corr、度量精度 Met、可供性校准 ACal)：
- Comp = 有效观测体素 / 接触相关体素；
- Corr = 场景图节点/关系 F1；
- Met = 位姿误差 (m/rad) 与尺寸误差 (%)；
- ACal = |预测可供性 − 实测可执行性| 的期望校准误差（ECE）。
SQM 作为 GSUL 的可观测质量门控：SQM < τ_sqm ⇒ 禁止高刚度/高力执行，仅允许保守探测。

## 2. 本轮的最大风险（预告）

一句话：三维感知的位姿漂移、深度噪声与遮挡会生成「几何上自洽、物理上错误」的 AOF，而 GUP 若低估协方差或 coverage 门控失效，空间变化的阻抗先验会把机器人推向真实摩擦锥之外——即「几何幻觉 → 接触失效」；必须用保守协方差传播、未观测区高不确定度、coverage/SQM 硬门控与全局安全先验兜底，确保三维感知永不越过执行安全红线。

# 第 62 轮产物 · 创新点清单 v2：GSUL（三维锚定的场景理解闭环：GSSG×AOF×GUP×A3P×R3G，把「看到」变成可安全执行的阻抗先验）

> 承接第 61 轮 IP-173~182（ESEC：USR×MEL×DMS×SRT-Dual×PCE+++++）。本轮把「场景」从 **2D 语义嵌入** 升级为 **三维几何-语义-物理结构**：GSSG 提供带位姿/尺寸/材质/支撑关系的可查询场景图；AOF 提供接触点级的空间变化阻抗先验；GUP 把深度与位姿协方差保守传播到安全力限；A3P 让机器人在高风险歧义下主动换视角/轻触探测；R3G 把语言指代落到三维区域；GSUL 将五者嵌入第 61 轮双流架构，并以 PCE++++++（新增 B_geom）与 J_3d 证书兜底。实现 **「几何可查询、先验可局部化、不确定性可传播、感知可主动、语言可落地、安全可验证」**。

### IP-183 GSSG（几何-语义-物理场景图）

```python
class GeometricSemanticSceneGraph:
    def __init__(self, d_us=256, d_node=128, n_layers=4):
        self.encoder = SE3InvariantGraphTransformer(d_node, n_layers)
        self.node_head = NodeEmbedding(d_node, d_us)
        self.tracker = MultiObjectTracker()
        self.nodes, self.edges = {}, {}
        self.version = 0

    def update(self, rgbd, detections, pointcloud, pose, Sigma_pose):
        # 1) 2D 实例分割 -> 3D 反投影 -> 有向包围盒拟合
        for m in segment_instances(rgbd, detections):
            p_local = backproject(rgbd.depth, m.mask, rgbd.K)
            T_obj, b, Sigma_T = fit_oriented_box(p_local, Sigma_pose)
            phi, Sigma_phi = material_prior(rgbd.crop(m), pointcloud, m.mask)
            # 2) 跨帧数据关联（track_id），未匹配则新建节点
            tid = self.tracker.associate(m.mask, p_local, m.class)
            self._upsert_node(tid, m.class, pose @ T_obj, b,
                              phi, Sigma_T, Sigma_phi)
        # 3) 关系推理：支撑/接触/包含/邻近/遮挡/可达
        self.edges = infer_relations(self.nodes, pointcloud)
        # 4) 未观测节点的协方差随时间增长
        for v in self.nodes.values():
            if not v.observed_this_frame:
                v.Sigma = v.Sigma + PROCESS_NOISE * self.dt
        self.version += 1
        return self

    def encode(self):
        # 边特征仅用旋转不变量：距离、法向夹角、相对方位角
        feats = self.encoder(self.nodes, self.edges)
        scene_emb = self.node_head(attention_pool(feats))
        return scene_emb, self.version
```

### IP-184 AOF（可供性占据场）

```python
class AffordanceOccupancyField:
    def __init__(self, resolution=0.01, default_phi=CONSERVATIVE_PHI):
        self.res = resolution
        self.grid = SparseVoxelGrid(resolution)
        self.default_phi = default_phi
        self.version = 0

    def build(self, gssg, pointcloud, tactile_history, Sigma_pose):
        for v in gssg.nodes:
            o, sigma_o = tsdf_occupancy(pointcloud, v)
            a = affordance_head(v.class, v.geometry, v.edges)          # 可供性
            phi, u_mat = fuse_physics(v.phi, tactile_history.match(v.class))
            u_geo = gup.inflate(sigma_o, Sigma_pose, v.Sigma)          # IP-185
            self.grid.write_box(v.T, v.b, o=o, a=a, phi=phi, u=u_geo + u_mat)
        self.version += 1
        return self

    def query(self, x_world):
        # 稀疏体素哈希 + 三线性插值：O(1) 期望
        vox = self.grid.trilinear(x_world)
        if vox is None or vox.unobserved:
            return self.default_phi, float('inf')       # 未观测：保守 + 高不确定
        return vox.phi, vox.u

    def free_region(self, clearance, a_min):
        # 供 R3G 查询「空隙」：自由 + 净空 + 可供性
        return self.grid.select(lambda v: v.o <= O_MAX
                                and v.clearance >= clearance
                                and v.a >= a_min)
```

### IP-185 GUP（几何不确定性传播）

```python
class GeometricUncertaintyPropagation:
    def __init__(self, alpha=0.05, kappa=1.5, margin=0.8, sigma_uv=0.5):
        self.z_alpha = norm.ppf(1 - alpha)   # 单侧
        self.kappa = kappa
        self.margin = margin
        self.sigma_uv = sigma_uv

    def point_cov(self, depth, K, sigma_z):
        J = backproject_jacobian(depth, K)
        D = np.diag([self.sigma_uv**2, self.sigma_uv**2, sigma_z**2])
        return J @ D @ J.T

    def world_cov(self, Sigma_p, R, Sigma_pose):
        # 一阶保守叠加：Σ_pred ⪰ Σ_true
        return R @ Sigma_p @ R.T + Sigma_pose

    def normal_cov(self, Sigma_w, n):
        P = np.eye(3) - np.outer(n, n)
        return P @ Sigma_w @ P.T

    def friction_lower_bound(self, mu_hat, Sigma_w, n, sigma_mat):
        sigma_n = np.sqrt(np.trace(self.normal_cov(Sigma_w, n)))
        sigma_mu = self.material_sensitivity * sigma_n + sigma_mat
        return mu_hat - self.z_alpha * sigma_mu, sigma_mu

    def force_limit(self, mu_hat, Sigma_w, n, sigma_mat, N_normal):
        mu_lb, _ = self.friction_lower_bound(mu_hat, Sigma_w, n, sigma_mat)
        return max(0.0, mu_lb) * N_normal * self.margin

    def inflate_impedance(self, K, u_geo):
        # u 越大越软、越阻尼；安全项永不关闭
        K = dict(K)
        K['K_p'] /= (1 + self.kappa * u_geo)
        K['K_d'] *= (1 + self.kappa * u_geo)
        K['F_max'] = min(K['F_max'], self._last_force_limit)
        return K
```

### IP-186 A3P（主动三维感知）

```python
class Active3DPerception:
    def __init__(self, budget, tau_voi=0.05, probe_max_force=2.0):
        self.budget = budget
        self.tau_voi = tau_voi
        self.probe_max_force = probe_max_force

    def next_best_action(self, aof, gssg, contact_region):
        candidates = sample_hemisphere_views(gssg) + probe_candidates(contact_region)
        best, best_voi = None, -float('inf')
        for a in candidates:
            ig = mutual_information(aof.entropy(contact_region), a)
            cost = travel_cost(a) + time_cost(a) + safety_risk(a, aof)
            voi = ig - cost
            if voi > best_voi and self.budget.allows(a):
                best, best_voi = a, voi
        return best if best_voi >= self.tau_voi else None

    def probe(self, x, aof):
        # 轻触探测：力斜坡，检测滑移起始力与初始力-位移斜率
        f_slip, slope = tactile_probe(x, f_max=self.probe_max_force)
        mu_est = f_slip / NORMAL_FORCE
        k_est = slope
        aof.update_voxel(x, phi=(mu_est, k_est, aof.query(x)[0][2]),
                         u=PROBE_RESIDUAL)
        self.budget.consume_probe()
        return mu_est, k_est
```

### IP-187 R3G（指代三维锚定）

```python
class Referential3DGrounding:
    def parse(self, text):
        # 解析为：目标类别集合 + 空间关系约束 + 是否自由空间
        return scene_graph_query(text)   # 例: left_of(cup) AND free_space

    def ground(self, query, gssg, aof):
        nodes = gssg.select(query.classes)
        nodes = [v for v in nodes if satisfies_relations(v, query, gssg)]
        if query.free_space:
            region = aof.free_region(query.clearance, query.a_min)
            conf = free_space_confidence(region, aof)
        else:
            region = union_boxes([v.T for v in nodes])
            conf = prod(ground_conf(v) for v in nodes)
            conf *= prod(relation_margin(r, gssg) for r in query.relations)
        return region, conf
```

### IP-188 GSUL（三维锚定场景理解闭环）

```python
def GSUL(robot, obs, L, delta_f_req):
    # ---------- 感知流 10-30Hz ----------
    G, g_ver = robot.gssg.update(obs.rgbd, obs.dets, obs.cloud,
                                 obs.pose, obs.Sigma_pose)
    A, a_ver = robot.aof.build(G, obs.cloud, robot.tactile_hist, obs.Sigma_pose)
    region, r3g_conf = robot.r3g.ground(robot.r3g.parse(L), G, A)
    scene_emb, _ = G.encode()

    # ---------- 语义流 5-30Hz ----------
    phi, z_scene, pi, U = robot.mel.infer(
        obs.V, obs.T, obs.P, L, scene_emb, region)
    a_diag, C_pending, b_intent = robot.dms.step(U, region, r3g_conf)

    # ---------- 主动感知分支（VOI 门控 + B_geom） ----------
    if robot.budget.can_perceive():
        a_perc = robot.a3p.next_best_action(A, G, region)
        if a_perc is not None:
            robot.execute_perception(a_perc)     # move_view / probe
            return None, None, None              # 先感知，下周期再执行

    # ---------- USR⁺ 提交（版本化） ----------
    intent_emb = robot.usr.intent_encoder.encode(b_intent, region)
    anchor = robot.usr.commit_anchor(
        z_scene, intent_emb, phi, U,
        aof_version=a_ver, frame_id=obs.frame_id,
        Sigma_pose=obs.Sigma_pose, u_geo=A.mean_uncertainty(region),
        coverage=A.coverage(region))

    # ---------- 实时流 1-10kHz ----------
    x_c = robot.eeis.predict_contact_point(delta_f_req)
    phi_x, u_geo = A.query(x_c)                      # O(1) 局部先验
    if not A.is_observed(x_c):                       # 未观测接触点
        phi_x, u_geo = CONSERVATIVE_PHI, float('inf')
    K_prior = robot.usr.project_to_impedance(anchor, phi_x, x_c)
    K_safe = robot.eeis.compile_with_geom_prior(
        delta_f_req, K_prior, phi_x, u_geo)
    cert = robot.ertc.dispatch(K_safe)

    EV = robot.wait_contact()
    robot.usr.push_evidence(EV)
    robot.tactile_hist.append(EV.to_tactile())
    J3d = build_J3d(cert, EV, g_ver, a_ver, obs, u_geo, r3g_conf)
    return K_safe, EV, J3d
```

### IP-189 PCE++++++（七维认知-感知-语义预算）

```python
class PCEPlus6(CognitiveSemanticBudget):        # 继承 IP-177
    def __init__(self, geom_points=50000, voxel_res=0.01,
                 nbv_steps=3, probes=2, **kw):
        super().__init__(**kw)
        self.B_geom = GeomBudget(geom_points, voxel_res, nbv_steps, probes)
        self.aof_resolution = voxel_res
        self.aof_frozen = False
        self.use_global_prior = False

    def can_perceive(self):
        return (self.B_geom.steps_left > 0 or self.B_geom.probes_left > 0) \
               and not self.aof_frozen

    def geom_cost(self, a):
        return (LAM_P * a.points / self.B_geom.points_max
                + LAM_V * self.B_geom.voxel_min / self.aof_resolution
                + LAM_NBV * a.steps / self.B_geom.steps_max)

    def degrade_geom(self):
        if not self.B_geom.exhausted:
            return
        if self.aof_resolution < 0.04:
            self.aof_resolution *= 2                 # 粗分辨率 AOF
        elif not self.aof_frozen:
            self.aof_frozen = True                   # 冻结 AOF
        else:
            self.use_global_prior = True             # 全局保守先验
        # 安全项永不降级：GUP 保守膨胀始终开启
        assert self.gup.enabled

    def voi_cog6(self, action):
        return (self.voi_meta_pessimistic(action)
                - self.cost_mel(action) - self.cost_usr(action)
                - self.geom_cost(action) - self.cost_exec(action))
```

### IP-190 XMC-geo（几何一致性对账）

```python
def xmc_geo(gssg, aof, rgbd, detections, T_wc):
    e_rep, e_dep, e_nor = [], [], []
    for v in gssg.nodes:
        c = project(rgbd.K, T_wc @ v.T @ np.array([0, 0, 0, 1]))
        det = match_detection(c, detections, v.class)
        if det is not None:
            e_rep.append(np.linalg.norm(c[:2] - det.center))
            e_dep.append(abs(rgbd.depth[c[1], c[0]] - c[2]))
        n2d = normal_from_depth(rgbd, c)
        e_nor.append(1 - abs(np.dot(n2d, v.normal)))
    e_free = free_space_violation(aof, gssg)
    D_geo = (L1 * np.percentile(e_rep, 95) + L2 * np.mean(e_dep)
             + L3 * np.mean(e_nor) + L4 * e_free)
    return D_geo, D_geo > TAU_GEO      # True => 触发感知流重算
```

### IP-192 STOF（时空占据预测）

```python
class SpatioTemporalOccupancyForecast:
    def __init__(self, gnn_ode, horizon=0.5):
        self.model = gnn_ode
        self.horizon = horizon

    def predict(self, gssg_history):
        O_tau, Sigma_tau = self.model(gssg_history, tau=self.horizon)
        # 不确定度随时域单调增长（硬约束）
        assert np.trace(Sigma_tau) >= np.trace(gssg_history[-1].Sigma)
        return O_tau, Sigma_tau

    def anticipatory_prior(self, O_tau, aof):
        x_pred = argmax_contact_likelihood(O_tau, aof)
        phi_x, u_x = aof.query(x_pred)
        return x_pred, phi_x, u_x + contact_pred_uncertainty(O_tau)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| GSSG | 每层 O((N+E)d²)；增量 O(ΔN) | O(Nd+E) | 节点位姿误差 ≤ ε_T；关系 F1 ≥ 0.9；SE(3) 不变 |
| AOF | 构建 O(V_obs)；查询 O(1) 期望 | 稀疏体素 ~ 数十 MB | 查询 ≤ 0.05ms；未观测区强制保守 |
| GUP | O(N_p) 逐点闭式 | O(1)/点 | 保守：Σ_pred ⪰ Σ_true；P(F>F_max) ≤ α |
| A3P | O(\|𝒜_perc\|·IG) ≤ B_geom | O(1) | 每步 IG ≥ 0；步数 ≤ nbv_steps |
| R3G | O(N+E) 图查询 | O(N) | 低置信 (conf<τ) 必触发澄清 |
| GSUL | 感知 10–30Hz / 语义 5–30Hz / 实时 1–10kHz | 共享内存 | 实时流不阻塞；版本单调；frame 一致 |
| PCE++++++ | O(1) 预算检查 | O(1) | 降级正确；安全项永不降级 |
| STOF | O(H·E) | O(V) | 预测不确定度随时域单调不减 |

**正确性定理（GSUL-Complete）**：
假设第 61 轮 A61–A70 成立，并新增：
- **(A71) GSSG**：图 Transformer 对节点置换不变、对全局 SE(3) 变换不变，Lipschitz 常数 L_g；
- **(A72) AOF**：A(x) 在空间上 L_a-Lipschitz；未观测体素返回 φ_cons 且 u=+∞；
- **(A73) GUP**：一阶协方差传播保守（Σ_pred ⪰ Σ_true），法向估计无偏且方差有界；
- **(A74) A3P**：信息增益非负、探测动作满足 F_probe ≤ F_probe_max 且不进入占据体素；
- **(A75) R3G**：解析器对目标类别/关系召回率 ≥ r_min，置信度校准（ECE ≤ 0.05）；
- **(A76) 一致性**：GSSG/AOF/anchor 版本单调，frame_id 与 T_base_world 原子一致；
- **(A77) 预算**：B_cog6 单调消耗，降级链安全项不变。

则：
1. **几何锚定一致性**：若 anchor 新鲜、frame 一致且 x_c 被 AOF 观测，则 K_safe 与真实接触点局部安全阻抗的偏差 ≤ ε_geo（由 A72 + A76）。
2. **不确定性安全**：若 GUP 保守（A73），则对任意接触点，P(F_contact > F_max(x_c)) ≤ α；即使 MEL/AOF 均值偏差，力限仍以概率 1−α 成立。
3. **坐标系不变性**：改变机器人基座或世界系定义，scene_emb 与 K_prior 不变（A71），保证跨平台部署一致。
4. **主动感知收敛**：每次 A3P 动作的期望不确定度单调下降（IG ≥ 0），且步数被 B_geom 严格限制（A74）；探测结果回写后 u(x) 严格下降。
5. **语言-几何接地**：若 R3G 置信 conf ≥ τ_r3g 且 A75 成立，则指代区域 R 与真实目标区域 IoU ≥ 1−δ；否则 DMS 必发起澄清。
6. **实时性与安全降级**：实时流仅做 O(1) AOF 查询 + 轻量 Π 投影，周期 ≤ 1ms；B_geom 耗尽时 AOF 逐级降级，但 GUP 保守膨胀与全局安全先验始终生效（A77）。

## 5. 本轮最大风险

**一句话**：三维感知的位姿漂移、深度噪声与遮挡会生成「几何上自洽、物理上错误」的 AOF，而 GUP 若低估协方差、coverage/SQM 门控若失效，空间变化的阻抗先验会把机器人推向真实摩擦锥之外——即 **「几何幻觉 → 接触失效」**；必须以「一阶保守协方差传播 + 未观测区 u=+∞ + coverage/SQM 硬门控 + 全局安全先验兜底 + J_3d 几何证书」构建**几何安全护栏**，确保三维感知永不越过执行安全红线。
