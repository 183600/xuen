# 第 56 轮（承接第 55 轮语义-接触层与第 54 轮产物 v31；灵感驱动研究循环第 1 轮；本轮灵感：「自主导航」×「ROS」）

> 第 55 轮把感知标签升级为可执行接触约束，第 54 轮把技能组合升级为动作-鲁棒性双证书。本轮引入两个新灵感：**自主导航**提醒我们，可部署性最终是“在信念与时延下能否到达”，而不是单步可行；**ROS** 提醒我们，任何跨模块保证都必须经过一个显式的**接口契约**（类型、坐标系、时间、QoS、生命周期、版本）。核心矛盾：**H24**：ROS 话题/服务/动作只是传输管道，不传递保证，模块级证书在拼接处会因 frame/QoS/时钟漂移而静默失效；**H25**：导航的可行性不是“几何自由空间里有一条路径”，而是“在信念不确定、时间预算、坐标一致与语义接触约束下，存在一条可执行且可恢复的闭环”；**H26**：恢复行为是导航的护盾，但若它与证书失效模式不对齐，会把系统性契约故障伪装成局部可恢复，掩盖真正的部署风险。

## 0. 直觉与动机

**灵感 1（ROS → 契约化接口图，而非消息总线）**
直觉：ROS 最容易被误用的地方，是把它当成“发消息的管道”。但一个真实导航栈的可靠性，取决于 `tf` 树是否一致、消息时间戳是否同源、QoS 是否会让关键消息静默丢弃、lifecycle 是否在正确状态。把每个 topic/service/action 端点提升为**带假设与保证的契约**：`Γ(e)=(类型, 坐标系, QoS, 速率/延迟包络, 上游假设, 下游保证)`。于是 ROS 图从通信图变成**可检查的契约图** `G_Γ`，部署前可做静态闭合检查，运行时可做漂移监测。这是把“中间件”提升为“可验证的部署前提”。

**灵感 2（自主导航 → 信念-时延生存核，而非几何路径）**
直觉：导航栈常把“局部规划器无碰撞”当成安全，但真正的问题是：定位漂移、地图不确定、动态障碍、控制延迟下，**是否存在一条在截止时间内以足够概率到达的闭环策略**。因此把第 55 轮的全身生存核上推一层：状态不再是关节+接触，而是 `(位姿信念 b, 地图/语义信念, 时延预算 τ)`；可行动集是**导航信念生存核** `K_nav(b,τ)`。这样“地图错一点”“定位慢一点”不是感知指标，而是直接收缩可行动集。

**灵感 3（ROS 的时空语义 → 帧-时契约证书）**
直觉：ROS 里最隐蔽的故障不是“节点崩了”，而是“帧对但时间错”“时间对但 QoS 丢”“QoS 对但版本不兼容”。把 `tf` 树版本、帧链、时钟源、消息年龄、QoS 矩阵一起写成**帧-时契约证书** `FTC`，并定义接口漂移 `δ_intf`。证书不是文档，而是每次部署/每次任务都必须重新闭合的运行时断言。

**灵感 4（Nav2 行为树 → 有活性的恢复护盾）**
直觉：自主导航的恢复行为（清代价地图、旋转、退避、重规划、停车）本质上是“导航级护盾”。但恢复不能只回答“能不能恢复”，还要回答“在多久内恢复、恢复失败是否进入安全停靠、恢复是否掩盖了系统性契约漂移”。因此把行为树恢复叶建模为**恢复护盾**，并给出**恢复活性** `L_R`：在 `τ_r` 内进入安全集或重新进入生存核的概率下界。

**灵感 5（证书携带导航 → 让 ROS 传递“保证”而不只是数据）**
直觉：如果证书只存在论文里，部署时仍会退化成“看日志”。让导航目标、规划路径、控制指令都**携带证书句柄**，由 ROS 2 的 broker 节点在执行前校验：契约是否闭合、证书是否新鲜、地图/语义版本是否匹配。这把第 54 轮的云边协同 `CEC` 与第 55 轮的语义-接触证书 `J_s` 统一到一条 **证书携带导航** 链路上：云端发“带证书的任务”，边端回“带证据的失效”。

## 1. 形式化定义（增量：定义 127–133）

**定义 127（端点契约）**
对 ROS 端点 `e`（topic/service/action），其契约为
`Γ(e) = (T_e, F_e, Q_e, R_e, A_e, G_e)`：
- `T_e`：消息类型、语义版本与类型哈希；
- `F_e`：坐标系族与期望 `tf` 父子链；
- `Q_e = (reliability, durability, deadline, liveliness, depth)`：QoS 元组；
- `R_e = (f_min, f_max, τ_p99)`：发布速率与延迟包络；
- `A_e`：上游假设（如“时钟偏斜 ≤ ε_clock”“map 版本一致”）；
- `G_e`：对下游的保证（如“障碍物点云年龄 ≤ τ_age”）。
发布者 `p` 对订阅者 `s` **契约兼容**记作 `Γ(p) ⊑ Γ(s)`，当且仅当类型/版本可解析、QoS 不会导致关键消息静默丢弃、且 `G_p ⇒ A_s`。

**定义 128（契约化 ROS 图与接口漂移）**
`G_Γ = (V, E, Γ, Φ, C)`：`V` 为节点及 lifecycle 状态，`E` 为端点连接，`Φ` 为 `tf` 树快照（父子链、时间戳源、外参版本），`C` 为时钟域集合。路径 `π=v_1…v_k` **契约可闭合**当且仅当所有相邻边 `Γ(v_i) ⊑ Γ(v_{i+1})`，且 `Φ` 中帧链存在、版本一致、时间源可比较。定义**接口漂移**
`δ_intf = w_t·δ_type + w_f·δ_frame + w_q·δ_qos + w_r·δ_rate + w_v·δ_ver`，
其中各项为相对部署基线的归一化偏差。

**定义 129（帧-时契约证书 FTC）**
`FTC = (tf_version, frame_chain, time_source, skew_p99, age_p99, qos_matrix, δ_intf)`。
`FTC` 可部署当且仅当
`δ_intf ≤ Θ_intf ∧ skew_p99 ≤ ε_clock ∧ age_p99 ≤ ε_age ∧ qos_matrix 无静默丢弃`。
`FTC` 的新鲜度记作 `fresh(FTC,t)=1` 若 `t - t_issue ≤ TTL` 且 `tf_version/map_version` 未变。

**定义 130（导航信念生存核）**
设位姿信念 `b_t`、地图与语义信念 `Σ`、策略 `π`、时延预算 `τ`。导航生存核
`K_nav(b,τ) = { x | ∃π: Pr_{b,Σ}(x_{t+H}∈𝒳_goal ∧ ∀k≤H x_k∈𝒳_free^+ ∧ contact⊆C^+(Σ)) ≥ 1-δ_nav ∧ deadline(x,τ) }`。
其中 `𝒳_free^+` 是含定位不确定性膨胀与语义边界膨胀的自由空间，`C^+(Σ)` 来自第 55 轮保守接触集。`viable_nav(x,τ)=1 ⇔ x∈K_nav`。这把“无碰撞”升级为“在信念、语义扰动与截止时间内以概率 1-δ_nav 可达”。

**定义 131（静默失效与漂移传播）**
若局部证书 `J_i` 的前提 `A_i` 在运行图 `G_Γ` 中不再成立，则称 `J_i` **静默失效**：
`stale(J_i,G_Γ)=1 ⇔ ¬(G_Γ ⊨ A_i) ∨ ¬fresh(FTC_i,t)`。
沿路径的漂移按 `δ_intf(π)=Σ_{e∈π} w_e δ_e` 传播；部署要求 `Σ_i stale(J_i,G_Γ)=0`。关键点：局部证书全为 `ok` 不代表组合后仍 `ok`。

**定义 132（恢复行为护盾与恢复活性）**
导航行为树 `BT` 的叶节点分为 `{控制, 重规划, 清代价地图, 旋转, 退避, 安全停车}`。恢复护盾 `RBS` 在 `FTC` 失效或 `viable_nav=0` 时选择
`r* = argmin_r cost(r) s.t. 执行 r 后在 τ_r 内到达 x_safe 或恢复 viable_nav=1`。
**恢复活性** `L_R = Pr(∃r: 在 τ_r 内进入 x_safe ∪ K_nav)`，要求 `L_R ≥ L_min`。恢复不是无限次重试，而是有截止时间与安全汇点的选择问题。

**定义 133（导航联合部署证书 NDC）**
`J_nav = (FTC, K_margin, ρ_nav, J_s, BT_trace, δ_intf, evidence)`：
- `K_margin = min_{x∈轨迹} dist(x, ∂K_nav)` 信念生存核裕度；
- `ρ_nav(ε) = inf_{||b-b̂||≤ε_b, ||Σ-Σ̂||≤ε_s} P(viable_nav)` 导航鲁棒性谱；
- `J_s` 为第 55 轮语义-接触证书；
- `BT_trace` 记录恢复叶触发与结果。
`J_nav` 可部署当且仅当 `fresh(FTC)=1`、`δ_intf ≤ Θ_intf`、`K_margin ≥ θ_K`、`ρ_nav ≥ ρ_min`、`J_s.status=ok`、`L_R ≥ L_min` 且无 `stale` 证书。

## 2. 关键算法 伪代码

### IP-127 CIG（Contract Interface Graph）

```python
def build_contract_graph(launch_file, tf_tree, clock_domains):
    G = nx.DiGraph()
    for node in discover_nodes(launch_file):
        for ep in endpoints(node):
            gamma = declare_contract(ep)   # type, frame, qos, rate, assumptions
            G.add_node(ep, contract=gamma, lifecycle=node.lifecycle)
    for pub, sub in match_endpoints(G):
        if not contract_le(pub.contract, sub.contract):
            G.add_edge(pub, sub, compatible=False)
        else:
            G.add_edge(pub, sub, compatible=True,
                       qos=intersect_qos(pub.qos, sub.qos))
    G.graph['tf'] = snapshot(tf_tree)
    G.graph['clock'] = clock_domains
    return G

def contract_closure(G, path):
    return all(G[u][v]['compatible'] for u, v in edges(path)) \
           and frame_chain_exists(G.graph['tf'], path) \
           and versions_match(G, path)
```

### IP-128 FTM（Frame-Time Monitor）

```python
def frame_time_monitor(G, tf_buffer, clocks, budgets, period=0.1):
    while running:
        frames = tf_buffer.all_frames_as_yaml()
        skew = max_clock_offset(clocks)          # p99 over sliding window
        age = p99_message_age(G)                 # from header stamps
        qos_drop = detect_qos_mismatch(G)        # deadline/liveliness violations
        delta = weighted_drift(frames, skew, age, qos_drop, G)
        if (delta > budgets.Theta_intf or skew > budgets.eps_clock
                or age > budgets.eps_age or qos_drop):
            yield InvalidEvent(delta, frames, skew, age, qos_drop)
        sleep(period)
```

### IP-129 NBVK（Navigation Belief Viability Kernel）

```python
def nav_belief_kernel(b0, map_sigma, C_plus, tau, delta_nav, horizon):
    K, margins = set(), []
    for b in belief_samples(b0, map_sigma, N=512):
        for pi in policy_candidates(b, horizon, tau):
            ok = chance_reach(b, pi, C_plus,
                              delta=delta_nav, deadline=tau)
            if ok:
                K.add(b)
                margins.append(distance_to_infeasible(b, C_plus, tau))
    return KernelApprox(inner_hull(K),
                        outer_hull(K, eps=belief_eps),
                        margin=min(margins) if margins else 0.0)
```

### IP-130 RBS（Recovery Behavior Shield）

```python
def recovery_shield(u_nom, bt, cert, budgets):
    if fresh(cert.FTC) and viable_nav(cert.b, budgets.tau):
        return bt.tick_nominal(u_nom), 'nominal'
    for r in order_by_cost(bt.recovery_leaves):
        if provably_restores(r, cert, budgets.tau_r, budgets.L_min):
            return r.execute(), ('recovery', r.name)
    return safe_stop(), 'safe_stop'
```

### IP-131 NDC（Navigation Deployment Certificate）

```python
def nav_deployment_certificate(path, G, FTC, K, sem_cert, bt, budgets):
    stale = [j for j in path_certs(path) if not assumptions_hold(j, G)]
    if stale or not fresh(FTC, now()):
        return ('reject', 'stale_contract', stale)
    if FTC.delta_intf > budgets.Theta_intf:
        return ('reject', 'interface_drift', FTC.delta_intf)
    K_margin = min(distance_to_boundary_K(b, K) for b in path.beliefs)
    rho_nav = nav_robustness_spectrum(path, budgets.eps_b, budgets.eps_s)
    if K_margin < budgets.theta_K or rho_nav < budgets.rho_min:
        return ('reject', 'viability_fail', K_margin, rho_nav)
    if sem_cert.status != 'ok':
        return ('reject', 'semantic_contact_fail', sem_cert.reason)
    if not liveness_check(bt, budgets.L_min, budgets.tau_r):
        return ('reject', 'recovery_liveness_fail')
    return ('ok', NavCert(FTC, K_margin, rho_nav, sem_cert, bt.trace(), evidence()))
```

### IP-132 CCB（Certificate-Carrying Broker）

```python
class CertificateBroker(Node):
    def __init__(self):
        self.sub_goal = self.create_subscription(
            PoseStamped, '/goal_pose', self.on_goal, qos_for_goal)
        self.sub_cert = self.create_subscription(
            NavCert, '/nav_certificates', self.on_cert, qos_for_cert)
        self.pub = self.create_publisher(
            CertifiedGoal, '/goal_pose_certified', qos_for_goal)
        self.certs = {}

    def on_goal(self, goal):
        cert = self.certs.get(goal.header.frame_id)
        if cert is None or not verify_nav_cert(cert, self.contract_graph):
            self.get_logger().warn('reject: missing or stale certificate')
            return
        self.pub.publish(attach_certificate(goal, cert))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| CIG | O(|V|+|E|+|Φ|) | O(|V|+|E|) | 契约声明完备、类型/QoS 检查 sound |
| FTM | O(|E|) 每周期 | O(|窗口|) | 时钟/年龄/QoS 监测无漏报 |
| NBVK | O(N_b·|Π|·T·QP) | O(|K|) | 核外近似 sound、信念采样覆盖 |
| RBS | O(|BT 叶|·T) | O(|BT|) | 恢复叶可证明、截止时间可判定 |
| NDC | O(|π|·(|E|+|B|)) | O(|V|+|E|) | stale 检查完备、预算闭合 |
| CCB | O(1) 每消息 | O(|证书库|) | 证书新鲜度/版本不可绕过 |

**正确性定理（Contract-Carrying Navigation Soundness）**
假设第 54 轮 (A26)–(A28) 与第 55 轮 (A29)–(A32) 成立；并新增：
**(A33)** 契约图 `G_Γ` 覆盖所有运行时端点，静态类型/QoS/帧链检查 sound；
**(A34)** 时钟偏斜与消息年龄的监测满足 `P(skew>ε_clock) ≤ p_clock`、`P(age>ε_age) ≤ p_age`；
**(A35)** `K_in ⊆ K_nav ⊆ K_out`，且恢复活性 `L_R ≥ L_min`；
**(A36)** broker 的新鲜度/版本校验无绕过，`P(stale accepted)=0`。
则部署后单任务安全概率：
```
P_safe ≥ 1 - P(δ_intf > Θ_intf) - p_clock - p_age
             - P(||b-b̂|| > ε_b) - P(||Σ-Σ̂|| > ε_s)
             - P(¬L_R) - P(stale accepted)
```
关键：**接口契约进部署前提、信念生存核做保守包含、恢复行为有活性兜底**；三层任一层失守，都不允许把“模块级证书看起来都通过”当作“导航闭环一定安全”。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 契约声明与真实行为不一致 | 高 | 运行时契约监测 + launch 配置模糊测试 + CI 契约测试 |
| `tf`/QoS/时钟静默漂移 | 高 | 漂移预算 + canary topic + 时间同步监测 + 证书 TTL |
| 信念生存核过保守导致“冻结” | 中 | 分层核 + 保守度预算 + 主动探测恢复 |
| 恢复行为掩盖系统性契约故障 | 高 | 恢复遥测 + 根因门控 + stale 证书一票否决 |
| ROS 版本/消息类型不兼容 | 中 | 类型哈希 + 语义版本 + 版本化接口与回滚 |

## 6. 本轮最大风险

**一句话**：契约化 ROS 图与信念生存核把“接口拼接”和“几何可达”升级为可验证的部署前提，但其 soundness **三重依赖契约声明的真实性、帧/时/QoS 漂移监测的无漏报、以及恢复活性的可判定性**；一旦契约在 launch 或版本升级中静默漂移、或恢复行为把系统性故障伪装成局部可恢复，导航器会在“证书仍显示通过”的情况下继续执行，直到撞上动态障碍——因此必须以 **运行时契约监测 + 证书新鲜度一票否决 + 恢复根因门控** 三重护栏，宁可保守停车，绝不把 ROS 的“消息连通”当作导航的“保证连通”。

# 第 56 轮产物 · 创新点清单 v32：NavContract-ROS（CIG×FTM×NBVK×RBS×NDC×CCB）

> 承接第 54 轮产物 v31（ACS×SCOM×CEC×AEC×JTC）与第 55 轮语义-接触层（SCG×WBV×SSF×SCC×SRS×CEB）。本轮把可部署性从“动作-鲁棒性双证书”推进到 **“接口契约 + 信念生存核 + 恢复活性”** 三层闭合：
> - **CIG（Contract Interface Graph）**：把 ROS 端点提升为带假设/保证的契约，静态闭合类型、帧链、QoS、版本；
> - **FTM（Frame-Time Monitor）**：运行时监测 `tf` 版本、时钟偏斜、消息年龄与 QoS 丢包，计算接口漂移 `δ_intf`；
> - **NBVK（Navigation Belief Viability Kernel）**：在信念、语义与截止时间下刻画导航可行集 `K_nav`；
> - **RBS（Recovery Behavior Shield）**：把 Nav2 行为树恢复叶变成有截止时间与安全汇点的护盾；
> - **NDC（Navigation Deployment Certificate）**：把 FTC、K_margin、ρ_nav、语义-接触证书、恢复活性合成一张部署证书；
> - **CCB（Certificate-Carrying Broker）**：ROS 2 节点级证书携带与校验，拒绝陈旧/漂移/版本不符的目标。

## 2. 关键算法 伪代码

### IP-127 CIG：契约图与闭合检查

```python
def build_contract_graph(launch_file, tf_tree, clock_domains):
    G = nx.DiGraph()
    for node in discover_nodes(launch_file):
        for ep in endpoints(node):
            G.add_node(ep, contract=declare_contract(ep),
                       lifecycle=node.lifecycle)
    for pub, sub in match_endpoints(G):
        ok = contract_le(pub.contract, sub.contract)   # type/version/QoS/assumption
        G.add_edge(pub, sub, compatible=ok,
                   qos=intersect_qos(pub.qos, sub.qos))
    G.graph['tf'] = snapshot(tf_tree)
    G.graph['clock'] = clock_domains
    return G

def contract_closure(G, path):
    return (all(G[u][v]['compatible'] for u, v in edges(path))
            and frame_chain_exists(G.graph['tf'], path)
            and versions_match(G, path))

def interface_drift(G, baseline):
    return (w_t * type_drift(G, baseline)
            + w_f * frame_drift(G, baseline)
            + w_q * qos_drift(G, baseline)
            + w_r * rate_drift(G, baseline)
            + w_v * version_drift(G, baseline))
```

### IP-128 FTM：帧-时监测

```python
def frame_time_monitor(G, tf_buffer, clocks, budgets, period=0.1):
    while running:
        frames = tf_buffer.all_frames_as_yaml()
        skew = p99(max_clock_offset(clocks), window=5.0)
        age = p99_message_age(G, window=5.0)
        qos_bad = detect_qos_mismatch(G)   # deadline/liveliness/depth
        delta = interface_drift(G, G.graph['baseline'])
        if (delta > budgets.Theta_intf or skew > budgets.eps_clock
                or age > budgets.eps_age or qos_bad):
            yield InvalidEvent(delta, frames, skew, age, qos_bad)
        sleep(period)
```

**ROS 2 落地要点**：
- `tf2_ros::Buffer::canTransform` 必须带显式 `TimePoint` 与固定 `timeout`，禁止 `TimePointZero` 隐式取最新；
- QoS 用 `rclcpp::QoS` 显式映射 `reliability/durability/deadline/liveliness`，`deadline` 违约直接触发 `InvalidEvent`；
- 时钟使用 `ROS_TIME` 统一域，跨域用 `tf2` 的 `TimePoint` 对齐并记录 `skew_p99`。

### IP-129 NBVK：信念生存核

```python
def nav_belief_kernel(b0, map_sigma, C_plus, tau, delta_nav, horizon):
    K, margins = set(), []
    for b in belief_samples(b0, map_sigma, N=512):
        for pi in policy_candidates(b, horizon, tau):
            if chance_reach(b, pi, C_plus, delta=delta_nav, deadline=tau):
                K.add(b)
                margins.append(distance_to_infeasible(b, C_plus, tau))
    return KernelApprox(inner_hull(K),
                        outer_hull(K, eps=belief_eps),
                        margin=min(margins) if margins else 0.0)

def chance_reach(b, pi, C_plus, delta, deadline):
    # 机会约束：碰撞概率 + 语义接触失效概率 + 超时概率 <= delta
    return (collision_prob(b, pi) + semantic_fail_prob(b, pi, C_plus)
            + timeout_prob(pi, deadline) <= delta)
```

### IP-130 RBS：恢复行为护盾

```python
def recovery_shield(u_nom, bt, cert, budgets):
    if fresh(cert.FTC, now()) and viable_nav(cert.b, budgets.tau):
        return bt.tick_nominal(u_nom), 'nominal'
    for r in order_by_cost(bt.recovery_leaves):   # 清图/旋转/退避/重规划
        if provably_restores(r, cert, budgets.tau_r, budgets.L_min):
            return r.execute(), ('recovery', r.name)
    return safe_stop(), 'safe_stop'

def liveness_check(bt, L_min, tau_r, n=2000):
    successes = simulate_recoveries(bt, n, tau_r)
    return empirical_prob(successes) >= L_min
```

### IP-131 NDC：导航部署证书

```python
def nav_deployment_certificate(path, G, FTC, K, sem_cert, bt, budgets):
    stale = [j for j in path_certs(path) if not assumptions_hold(j, G)]
    if stale or not fresh(FTC, now()):
        return ('reject', 'stale_contract', stale)
    if FTC.delta_intf > budgets.Theta_intf:
        return ('reject', 'interface_drift', FTC.delta_intf)
    K_margin = min(distance_to_boundary_K(b, K) for b in path.beliefs)
    rho_nav = nav_robustness_spectrum(path, budgets.eps_b, budgets.eps_s)
    if K_margin < budgets.theta_K or rho_nav < budgets.rho_min:
        return ('reject', 'viability_fail', K_margin, rho_nav)
    if sem_cert.status != 'ok':
        return ('reject', 'semantic_contact_fail', sem_cert.reason)
    if not liveness_check(bt, budgets.L_min, budgets.tau_r):
        return ('reject', 'recovery_liveness_fail')
    return ('ok', NavCert(FTC, K_margin, rho_nav, sem_cert,
                          bt.trace(), evidence()))
```

### IP-132 CCB：证书携带 Broker

```python
class CertificateBroker(Node):
    def __init__(self):
        self.sub_goal = self.create_subscription(
            PoseStamped, '/goal_pose', self.on_goal, qos_for_goal)
        self.sub_cert = self.create_subscription(
            NavCert, '/nav_certificates', self.on_cert, qos_for_cert)
        self.pub = self.create_publisher(
            CertifiedGoal, '/goal_pose_certified', qos_for_goal)
        self.certs = {}
        self.contract_graph = build_contract_graph(
            '/nav2_bringup/launch/navigation_launch.py', tf_tree, clocks)

    def on_goal(self, goal):
        cert = self.certs.get(cert_key(goal))
        if cert is None or not verify_nav_cert(cert, self.contract_graph):
            self.get_logger().warn('reject: missing or stale certificate')
            return
        self.pub.publish(attach_certificate(goal, cert))

    def verify_nav_cert(self, cert, G):
        return (fresh(cert.FTC, now())
                and cert.FTC.delta_intf <= self.Theta_intf
                and contract_closure(G, cert.path)
                and cert.sem_cert.status == 'ok')
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CIG | O(|V|+|E|+|Φ|) | O(|V|+|E|) | 契约覆盖 ≥ 98%，类型/QoS/帧链检查 sound |
| FTM | O(|E|) 每周期 | O(|窗口|) | 漂移/偏斜/年龄/QoS 监测无漏报 |
| NBVK | O(N_b·|Π|·T·QP) | O(|K|) | 核外近似 sound，信念采样覆盖 |
| RBS | O(|BT 叶|·T) | O(|BT|) | 恢复叶可证明，截止时间可判定 |
| NDC | O(|π|·(|E|+|B|)) | O(|V|+|E|) | stale 完备，预算闭合 |
| CCB | O(1)/消息 | O(|证书库|) | 证书 TTL/版本不可绕过 |

**正确性定理（Contract-Carrying Navigation Soundness）**
在第 54 轮 (A26)–(A28) 与第 55 轮 (A29)–(A32) 基础上增加：
**(A33)** `G_Γ` 覆盖所有运行时端点，静态检查 sound；
**(A34)** `P(skew>ε_clock)≤p_clock`、`P(age>ε_age)≤p_age`；
**(A35)** `K_in ⊆ K_nav ⊆ K_out` 且 `L_R ≥ L_min`；
**(A36)** broker 新鲜度/版本校验无绕过。
则：
```
P_safe ≥ 1 - P(δ_intf > Θ_intf) - p_clock - p_age
             - P(||b-b̂|| > ε_b) - P(||Σ-Σ̂|| > ε_s)
             - P(¬L_R) - P(stale accepted)
```

**失效传播引理**：若存在边 `e` 使 `Γ_p(e) ⋢ Γ_s(e)`，则下游任意依赖 `G_p(e)` 的证书 `J_i` 都有 `stale(J_i)=1`。因此“所有局部证书 ok”不构成组合 soundness；必须显式检查 `contract_closure` 与 `stale` 集合。

3. `nav_belief_kernel`：NBVK 采样/区间包络库 + 可视化；
4. `recovery_shield`：Nav2 行为树插件 + `BT_trace` 记录器；

6. `certificate_broker`：CCB 节点 + 证书 TTL/版本策略；
7. 回归基线：无契约监测、仅局部证书、仅恢复行为三组消融。

## 7. 本轮最大风险

**一句话**：NavContract-ROS 把 ROS 接口、导航信念与恢复行为统一进一张部署证书，但其 soundness **三重依赖契约声明的真实性、帧/时/QoS 漂移监测的无漏报、以及恢复活性的可判定性**；一旦 launch/版本升级造成静默契约漂移、或恢复行为把系统性故障伪装成局部可恢复，导航器会在“证书仍显示通过”时继续执行并撞上动态障碍——因此必须以 **运行时契约监测 + 证书新鲜度一票否决 + 恢复根因门控** 三重护栏，宁可保守停车，绝不把 ROS 的“消息连通”当作导航的“保证连通”。
