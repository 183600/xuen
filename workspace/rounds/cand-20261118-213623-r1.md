# 第 1 轮（新灵感循环起始；本轮灵感：「能耗优化」×「产学研合作」）

> **基线**：第 13 轮 MetricVoiceGauge-NCD-HUTD（定义 583–594；引理 113–121；实验 E627–E646）。
> 本轮纪律：**能量只弱不强 + 双资源单调链 + 联盟证据并集/授权交集**。不推倒 v13：v13 的 AIO/CPD/DDL/RTCR、v12 的 USG/TGC/BAA/GAGP/UC、v11 的 HAS/HCC/HATD/HDT、v10 的 NGE/DSL/CC/CWM/CAE/NCP、v9 的 AC/MW/ID、v8 的 DA/SPR/Cal 与九不变式全部保留。四个新组件——EBA（能量预算代数，含 EAC）、BEL（双资源执行阶梯）、CFC（联盟联邦校准）、CEL（联盟证据账本）——一律以**中立元**接入，失效即严格退回 v13（引理 127），再沿 v13→v12→v11→…→v6 退化链退回。本轮只做三件事：把"能耗"从平均代价改写为**带状态、热与功率约束的可证预算**；把"产学研合作"从共享数据改写为**证据并集、授权交集、可审计护照**；把二者合成一条**时间—能量—证据三维退化链**，使系统在能量低谷与跨机构异构部署下仍能保持 `Exec_v14⊆Exec_v13`。

## 0. 直觉与动机

**灵感 1（能耗优化 → 能量预算代数与能量可容许证书）**
直觉：v13 已经把时间变成逐帧可证的硬预算，但能量仍只是规划器里的正则项或平均功耗统计。真实机器人上，能量不是一个"平均值"：高扭矩接触恢复、快速安全停、谐波抑制都是能量尖峰；电池 SoC、母线电压、关节温度会直接改变可用力矩与带宽，从而**改变安全证书本身的有效性**。如果能耗优化只盯平均焦耳，它会把本该留给安全机动的能量花在任务上；当 SoC 下滑或关节过热时，接触/谐波证书会在"没有报错"的情况下悄悄失效。核心创新：**能量预算代数（Energy Budget Algebra, EBA）+ 能量可容许证书（Energy Admissibility Certificate, EAC）**。能量被建模为**状态化、路径相关、带硬安全预留**的资源；任何依赖力矩/电压的证书必须在**降额后的执行能力** `ρ(η)` 上重新评估；再生能量只能记入任务预算，不能冲抵安全预留。关键反直觉点：**省能不是"少做动作"，而是在证书约束下用更少的焦耳完成同样的授权动作；省能永远不能扩张授权**。

**灵感 2（产学研合作 → 联盟证据并集与授权交集）**
直觉：单一机构无法覆盖家庭、产线、竞赛等长尾场景。产学研合作看起来能"共享数据、共享模型、共享证书"，但真实合作有三件事同时发生：数据不能出域、伙伴的模型/仿真器可能同源同错、责任与审计边界必须可追溯。最常见的错误是把合作方的**授权并集**当成新授权——只要有一个伙伴放宽阈值，系统就多了一份权限；或者把共享仿真器上的多个模型当成独立证据，误以为"多方一致"就等于"独立验证"。核心创新：**联盟联邦校准（Consortium Federated Calibration, CFC）+ 联盟证据账本（Consortium Evidence Ledger, CEL）**。合作可以扩大**证据并集**（更多校准样本、更宽支撑、更小间隙），但部署授权必须取**有效证书的交集** `Acc_∩=∩_p Acc_p`，且每个伙伴的证书都必须是 v13-conformant 的。关键反直觉点：**合作越多，授权不一定越大；合作先让"未知"变少，再由教师重新认证，绝不直接并权限**。一个诚实且 sound 的伙伴就足以保证交集安全；其他伙伴可以乐观甚至恶意，但不能把不安全动作塞进交集。

**灵感 3（能耗×合作 → 双资源阶梯与联盟护照）**
直觉：v13 的阶梯只按毫秒排序，v14 的每一档必须同时声明**时间成本 `w_i` 与能量成本 `e_i`**；只按一个资源排序会在另一个资源上偷偷透支。联盟层则为每一档提供跨站点校准、支撑交集与审计护照。于是"这一帧能跑到哪一档"从一维选档变成**双资源可行域上的单调链选档**；任一预算收缩只能沿链向更保守端移动。核心创新：**双资源执行阶梯（Bi-resource Execution Ladder, BEL）+ 能量—联盟路由器（Energy–Consortium Router, ECR）**。这把"能耗优化"与"产学研合作"合成同一个对象：一条**以（毫秒，焦耳，证据覆盖）为索引的证书族**。路由器只做一件事——在三维预算内选出**授权单调嵌套**的最大可行档，选不到就回到零假设安全回退。

**三者如何统一**
统一为 **v13 之上的能量—联盟实现层**：v13 回答"在毫秒内能安全实现多少"，v14 回答"在毫秒、焦耳与跨机构证据的三重约束下，还能安全实现多少、由谁的证书背书"。共享状态扩展为 `ζ_ec=(B_time,B_energy,B_evidence,η,i*,U_{d,i*},RTIC,EAC,Passport,drift,mode)`。**EBA 回答"还剩多少能量时依然安全"，BEL 回答"这一帧在时间与能量上负担得起哪一档"，CFC/CEL 回答"这一档的证书由哪些伙伴、在什么支撑上、以什么证据背书"**。三者不是三个节能/合作补丁，而是"能量—证据—路由"的实现链。

## 1. 研究问题（轮次升级版）

- **Q1（能量证书的可证语义）**：如何把能量从平均代价改写为逐段、状态相关、带热/功率/SoC 约束的上界？EAC 如何在电池电压跌落、关节热降额、再生能量不确定时保持 sound？能量安全预留 `B_safe^E` 如何与 v13 的时间安全切片 `B_safe^T` 正交而不互相挪用？
- **Q2（双资源阶梯的单调性）**：当时间与能量成本不同向（省时费能、省能费时）时，如何构造仍是**支配链**的学生/技能阶梯？若真实 Pareto 前沿不可链化，交集式选档是否仍能保持安全与活性？双资源退化界如何给出可预算的期望损失？
- **Q3（联盟证据的可证边界）**：如何形式化"证据并集、授权交集"？加权共形在异质站点、数据不出域、支持交集、伙伴贡献加权下如何保持覆盖？当权重由验证表现（含标签）估计时，如何用两折校准避免破坏可交换性？一个诚实伙伴的 soundness 能否独立保证交集安全，活性又由什么保证？
- **Q4（联盟治理与 v13 兼容）**：证书护照、撤销、审计延迟如何进入执行门？恶意伙伴的"否决"或"乐观膨胀"分别造成活性/安全何种后果？四类新组件全失效时能否逐位退回 v13？新增能耗与审计开销能否守住 50Hz/p99≤22ms，并保持 `Exec_v14⊆Exec_v13`？

## 2. 设计原则（在 P22–P24 基础上新增 P25–P28）

**P25 能量只弱不强律（Energy Weakens, Never Strengthens）**
能量优化只能降低实现同一授权动作的焦耳成本，不能新增授权。任何改变力矩/电压/带宽的能量策略，都必须在降额后的能量状态 `ρ(η)` 上重新验证接触、谐波与规范证书。若 EAC 无效或 `B_safe^E` 被触碰，唯一允许的动作是沿阶梯向更保守端移动、`a_ask` 或零假设回退；不得用"平均能耗更低"为理由放宽任何证书。

**P26 双资源单调链律（Bi-resource Monotone Chain）**
部署的阶梯必须同时按 `w_i` 与 `e_i` 非降，且授权集单调嵌套：`w_0≤…≤w_m`、`e_0≤…≤e_m`、`Acc_0⊆…⊆Acc_m⊆Acc_T`。禁止在时间上更便宜、能量上更昂贵的档位之间做无证书的"跨资源套利"；若真实前沿不可链化，只能取所有可行档授权的交集或退回第 0 档，不得任意挑一个不可比档。

**P27 联盟证据并集、授权交集律（Evidence Unions, Authorization Intersects）**
联盟可以并集校准数据、支撑与审计证据以提高覆盖、收紧间隙；但部署授权必须取所有有效伙伴证书的交集 `Acc_∩=∩_{p∈P_valid}Acc_p`，且每个 `Acc_p` 都必须已证明 `⊆Exec_v13`。合作不得直接并权限；任何伙伴都不能通过"更乐观"的单方证书扩大交集。安全上允许最多 `K−1` 个伙伴乐观/恶意，只要至少一个伙伴 sound；活性上必须保留本地 v13 回退，避免被单方否决拖死。

**P28 五预算不可挪用律（Five-Budget Non-Fungibility）**
时间、能量、迁移、蒸馏、证据五类预算各自独立：`B_time=B_safe^T+B_infer`、`B_energy=B_safe^E+B_task^E`、`B_total=B_transfer+B_distill+B_site`、`B_evidence=B_calib+B_audit`。安全子预算硬预留，不得被任务优化、再生能量或联盟证据冲抵；任一预算耗尽时，唯一允许的动作是沿阶梯更保守、触发 `a_ask` 或认证回退。**不存在"用毫秒买焦耳"或"用数据买授权"的汇率**。

## 3. 与基线的接口（如何退化）

- EBA 失效 ⇒ 能量约束中立化：`B_energy≡∞`、`ρ(η)≡1`、EAC 退化为恒真，任务规划忽略能量项，**等价 v13 计算/执行路径**；
- BEL 失效 ⇒ 单资源阶梯：只按 v13 的 `w_i` 选档，`e_i≡0`，无能量塌缩，**等价 v13 DDL/RTCR**；
- CFC 失效 ⇒ 单站点校准：`P={local}`、`Acc_∩=Acc_local`、`U_∩=U_local`，**等价 v13 本地证书**；
- CEL 失效 ⇒ 无护照/无撤销：`Audit≡1`、只用本地签名与本地证书，**等价 v13 本地执行**；
- 四者全失效 ⇒ MetricVoiceGauge-NCD-HUTD v13，再沿 v13 退化链退回 v12/v11/v10/v9/v8/v7/v6；
- **安全继承**：EBA 只收缩能量可行集，BEL 只做双资源嵌套，CFC 只做证据并集与授权交集，CEL 只做审计与撤销。四端口互不相交，均不能新增授权或放宽任何阈值；`Exec_v14⊆Exec_v13` 由引理 127 保证。

## 4. 预期贡献

1. **能量可容许证书**：把"能耗优化"从平均功耗指标改写为逐段、状态相关、带 SoC/热/功率/再生约束的可证预算，解决"能量低谷时证书静默失效"的结构性风险；
2. **双资源单调阶梯**：把 v13 的毫秒阶梯扩展为（时间，能量）支配链，给出无跨资源套利的退化界与不可比前沿的交集式安全选档；
3. **联盟证据—授权分离定理**：形式化"证据并集、授权交集"，给出一个诚实伙伴即可保证交集安全的结果，以及两折加权共形在异质站点上的覆盖保证；
4. **可审计的证书护照与五预算治理**：把产学研责任边界、撤销、审计延迟纳入执行门，并用 E647–E666 覆盖能量 soundness、双资源路由、联盟覆盖/安全、撤销时效、端到端与消融。

## 5. 本轮最大风险

**一句话**：能耗证书与联盟证书都假设"至少一个独立诚实的证据源"，但产学研各方往往共享同一套仿真器、能量模型与校准协议；一旦这个共同前提偏移，授权交集仍会给出一个按时、可审计、看似多方一致的错误放行。

EAC 在 `(η,π)` 上有效当且仅当：
1. `η∈Ω_E`（SoC 高于硬地板、温度低于硬上限、母线电压高于最低工作点）；
2. `E_hi(π;η) ≤ B_energy` 且 `P_hi(π;η) ≤ P_max(η)`；
3. 所有依赖力矩/电压/带宽的 v11/v12/v13 证书都在 `ρ(η)` 降额后的执行能力上重新评估并通过；
4. `B_safe^E` 只能由高于 SoC 地板的存量能量支付；再生能量、外部供电切换与任务余量**只能记入 `B_task^E`**，不得冲抵安全预留。
定义 `Exec_E(η)={a : EAC(a;η) 有效 ∧ a∈Exec_v13}`。EAC 是**能量上界证书**，不是平均功耗统计量。

**定义 596（能量条件执行集与 v14 执行上界）**
```
Exec_v14(η, P_valid) = Exec_v13 ∩ Exec_E(η) ∩ Exec_C(P_valid)
Exec_C(P_valid) = ∩_{p∈P_valid} Acc_p ,   Acc_p ⊆ Exec_v13 于 S_p 上
```
`P_valid` 由定义 600 的账本审计与撤销状态给出。若交集为空或 EAC 无效，只能执行 `P^rtE`（定义 602）中的认证回退或 `a_ask`。

**定义 597（双资源执行阶梯 BEL）**
```
L_E = ( S_0, S_1, …, S_m ; (w_0,e_0) ≤ … ≤ (w_m,e_m) ; θ_0≤…≤θ_m )
Acc_i = {(x,a): m_{S_i}(x,a) ≥ θ_i}
```
要求：
1. **支配链**：`w_0≤…≤w_m`、`e_0≤…≤e_m`；
2. **授权嵌套**：`Acc_0⊆Acc_1⊆…⊆Acc_m⊆Acc_T`；
3. **零假设第 0 档**：`S_0` 为无需学习的物理安全回退（安全保持/柔顺停止/`a_ask`），不依赖任何学习证书；
4. **不可比前沿的保守选档**：若某些档位在 `(w,e)` 上不可比，定义
```
Feas(B,η) = { i : w_i ≤ B_infer , e_i ≤ B_task^E , Ĉ_dis,i 与 EAC 有效 }
Acc_sel(B,η) = ∩_{i∈Feas(B,η)} Acc_i      # 交集式安全选档
```
当 `Feas` 为空或交集为空 ⇒ 第 0 档。这样"不知道哪一维先耗尽"时，返回的是所有可行档都共同授权的动作，仍然只弱不强。
5. **时间—能量不可套利**：禁止用"时间更省"去抵消"能量更费"而选择不可比档；可选档必须被某个可行档在双资源上支配。

**定义 598（联盟证据包与授权交集）**
```
P = {1,…,K}
E_p = (D_p, M_p, C_p, S_p, A_p, τ_p)
Valid_p = Audit(A_p)=1 ∧ hash(M_p) 与护照一致 ∧ C_p 未撤销 ∧ x∈S_p
Acc_∩(x) = ∩_{p∈P_valid, x∈S_p} Acc_p(x)
```
每个伙伴的 `Acc_p` 必须由 v13-conformant 的本地证书给出，并已在 `S_p` 上证明 `Acc_p⊆Exec_v13`。**证据可以并集，授权只能交集**：`D_∪=∪D_p` 只用于校准/收紧间隙；`Acc_∩` 才是部署授权。若 `x∉S_∩`，联盟证书在该点无保证，退回本地 v13 或 `a_ask`。

**定义 599（联盟加权共形与两折校准）**
在支撑交集 `S_∩=∩_p S_p` 上，给校准样本 `i` 赋权
```
w_i ∝ α_{p(i)} / n_{p(i)} ,   Σ_i w_i = 1
U_∩(α_d) = WeightedQuantile_{1−α_d}({g_i}; {w_i})   # 有限样本修正
n_eff = (Σ_i w_i)^2 / Σ_i w_i^2
```
其中 `g_i=m_S(x_i,a_i)−m_T(x_i,a_i)`。**两折纪律**：在折 A 上估计站点权重/贡献权重并冻结；在折 B 上只用冻结权重计算 `U_∩` 与覆盖。若权重在同一折上用标签调参，加权共形的可交换性被破坏，覆盖不再成立。有效条件：(i) 两折独立；(ii) 部署落在 `S_∩` 内；(iii) `U_∩≤B_distill`。覆盖为边际覆盖，不是逐点条件覆盖；支持外无保证。

**定义 600（联盟证据账本 CEL 与证书护照）**
```
Passport_p = (h(M_p), S_p, C_p, expiry_p, revoke_p, ℓ_p)
ℓ_t = (p, t, h(E_p), h(C_p), prev_hash, σ_p, merkle_path)
Ledger L = [ℓ_1,…,ℓ_T]                     # 追加式哈希链
Audit(ℓ)=1 ⇔ 签名有效 ∧ 哈希链连续 ∧ 无早于 t 的撤销 ∧ 未过期
```
`P_valid` 只包含 `Audit=1` 且护照与本地模型哈希一致的伙伴。撤销在审计周期 `Δ_audit` 内生效；撤销前的陈旧证书可能仍被执行，因此安全保证是**审计新鲜度条件化**的。CEL 只做来源与时效，不改变任何证书阈值。

**定义 601（贡献加权与有效样本量）**
```
Δ_p = U_∩(不含 p) − U_∩(含 p)            # 在折 A 上估计的边际覆盖收益
β_p ∝ n_eff,p · Δ_p / cost_p               # 冻结后再用于折 B
```
贡献加权只影响**校准/审计预算分配**，不影响授权；不得把"贡献大"解释为"授权多"。`Δ_p` 在折 A 上估计，折 B 只做覆盖认证，避免用标签自证。

**定义 602（五预算、联合回退与 v14 执行策略）**
```
B_time     = B_safe^T + B_infer
B_energy   = B_safe^E + B_task^E
B_total    = B_transfer + B_distill + B_site
B_evidence = B_calib + B_audit
P^rtE = { π_f : π_f∈P^rt , EAC(π_f;η) 有效 , P_hi(π_f;η)≤P_max(η) ,
                     passport 有效或本地 v13 证书有效 }
i*(B,η) = max{ i : w_i≤B_infer , e_i≤B_task^E , Ĉ_dis,i 与 EAC 有效 }
Acc_sel = Acc_{i*} ∩ Exec_E(η) ∩ Acc_∩ ∩ Exec_v13
π_v14(x;B,η) = argmax_{a∈Acc_sel} [ value(a) − λ_E · Ê(a;η) ]
```
若 `Acc_sel=∅` ⇒ 执行 `P^rtE` 中的零假设回退或 `a_ask`；**不得执行迟到结果或能量上界未验证的动作**。`λ_E` 只在同一 `Acc_sel` 内做节能排序，不能把动作移出可行集。

# IP-375 EnergyBudgetAlgebra / EAC：能量只弱不强
class EnergyBudgetAlgebra:
    def __init__(self, energy_model, thermal_model, U_E, U_P, Omega_E, floor):
        self.E, self.T = energy_model, thermal_model
        self.U_E, self.U_P = U_E, U_P
        self.Omega_E, self.floor = Omega_E, floor

    def derate(self, eta):
        rho_tau = min(1.0, eta.V_bus / self.E.V_nom) * self.T.torque_factor(eta.T)
        rho_V = min(1.0, eta.V_bus / self.E.V_nom)
        rho_P = min(1.0, eta.V_bus * eta.I_max / self.E.P_nom)
        return (rho_tau, rho_V, rho_P)

    def eac(self, plan, eta, B_energy, B_safe_E):
        if not self.Omega_E.contains(eta):                 # SoC/温度/电压硬包络
            return None
        E_hi = self.E.upper(plan, eta) + self.U_E
        P_hi = self.E.power_upper(plan, eta) + self.U_P
        if E_hi > B_energy or P_hi > self.E.P_max(eta):
            return None
        rho = self.derate(eta)
        if not self.recertify_under_derating(plan, rho):   # 接触/谐波/规范重证
            return None
        # 再生能量只能记任务预算；安全预留必须由高于 floor 的存量支付
        if self.E.stored_above_floor(eta) < B_safe_E:
            return None
        return EAC(eta, E_hi, P_hi, self.Omega_E, margin_E=0.0,
                   fallback=zero_hypothesis_fallback(eta))


# IP-376 BiResourceExecutionLadder：双资源单调链
class BiResourceExecutionLadder:
    def __init__(self, students, w, e, theta, teacher):
        self.S, self.w, self.e, self.theta, self.T = students, w, e, theta, teacher

    def feasible(self, B_infer, B_task_E, cert_valid):
        return [i for i in range(len(self.S))
                if self.w[i] <= B_infer and self.e[i] <= B_task_E and cert_valid(i)]

    def select(self, B_infer, B_task_E, cert_valid):
        F = self.feasible(B_infer, B_task_E, cert_valid)
        if not F:
            return 0, self.acc(0)                     # 零假设回退
        # 若阶梯是支配链，直接取最大可行档；否则取共同授权交集
        if self.is_chain(F):
            i = max(F)
            return i, self.acc(i)
        return None, set.intersection(*(self.acc(i) for i in F))

    def acc(self, i):
        return {a for (x, a) in self.support
                if self.S[i].margin(x, a) >= self.theta[i]}


# IP-377 ConsortiumFederatedCalibrator：证据并集、授权交集
class ConsortiumFederatedCalibrator:
    def __init__(self, alpha_d=0.1, local=None):
        self.alpha_d, self.local = alpha_d, local

    def fit(self, partners, fold_A, fold_B):
        # 折 A：估计站点权重与贡献权重并冻结（不得再看折 B 标签）
        weights_A = self.estimate_site_weights(fold_A, partners)
        contrib = self.estimate_contributions(partners, fold_A)
        beta = self.freeze_budget_weights(contrib, partners)
        # 折 B：只用冻结权重做加权共形
        scores_B = [s.margin(x, a) - t.margin(x, a)
                    for (s, t, x, a, p) in fold_B]
        w_B = [weights_A[p] for (_, _, _, _, p) in fold_B]
        U_int = weighted_quantile(scores_B, w_B, 1 - self.alpha_d)
        S_int = set.intersection(*(p.support for p in partners))
        return ConsortiumGap(U_int, S_int, n_eff(w_B), beta)

    def authorize(self, x, partners):
        valid = [p for p in partners if self.audit(p) and p.contains(x)]
        if not valid:
            return self.local.authorize(x)           # 本地 v13 回退
        return set.intersection(*(p.acc(x) for p in valid))

## 4. 推导

**引理 122（能量降额的单调收缩）** 若 `η'` 比 `η` 更耗尽，即 `ρ(η')≤ρ(η)` 逐项成立、`E_hi(·;η')≥E_hi(·;η)`、`B_energy'≤B_energy`，则
```
Exec_E(η') ⊆ Exec_E(η) .
```
证明：降额后可用力矩/电压/功率不高于 `η`，依赖这些量的接触/谐波/规范证书在 `η'` 下更难成立；同时能量上界更高、预算更低，故满足 EAC 的动作集合只会缩小。逐项取交集即得。∎
推论：**能量优化不能把系统从低能量状态"优化"出更多授权**；它只能在同一授权集内减少焦耳，或通过更保守的档位换取安全。能量低谷时的正确反应是降档/回退，不是提高功率去追进度。

**引理 123（双资源阶梯的退化界）** 对支配链阶梯 `(w_i,e_i)` 与定义 602 的 `i*(B,η)`，若 `B_infer` 或 `B_task^E` 收缩，则 `i*` 不增、`Acc_{i*}` 不增。记 `v_i=value(Acc_i)`，则
```
E[v_m − v(B,η)] ≤ Σ_{i=0}^{m-1} P( B_infer < w_{i+1} ∨ B_task^E < e_{i+1}
                                  ∨ Ĉ_dis,i+1 无效 ∨ EAC_{i+1} 无效 ) · (v_{i+1}−v_i) .
```
证明：由支配链，`i*(B,η)` 关于两个预算均单调不增；对 `v_m−v(B,η)` 做伸缩求和，事件 `{i*<i+1}` 包含于"时间不足、能量不足或证书无效"的并集，用联合界放缩。∎
推论：退化是**连续的、可预算的**；只要 `w_0≤B_safe^T` 且 `e_0≤B_safe^E`，最坏情况仍落在零假设回退，不会出现"无档可跑"。

**引理 124（联盟交集的单诚实伙伴安全性）** 设 `Exec_C=∩_{p∈P_valid}Acc_p`，且每个 `Acc_p⊆Exec_v13`。若至少存在一个 `p*∈P_valid` 满足 `Acc_{p*}⊆Safe_true`（sound），则无论其他伙伴的 `Acc_p` 多么乐观、恶意或同源错误，
```
Exec_C ⊆ Safe_true .
```
证明：交集是任一成员的子集，故 `Exec_C⊆Acc_{p*}⊆Safe_true`。其他伙伴只能通过交集**删除**动作，不能添加动作。∎
推论：**授权交集对"乐观膨胀"是鲁棒的**；但它对"否决"不鲁棒——任一伙伴可以把交集压空。因此 `P_valid` 之外必须保留本地 v13 回退（定义 598/602），把联盟失败降级为 v13 而不是降级为更不安全。另注意：若唯一的 sound 伙伴被撤销/过期，保证失效，故 CEL 的审计新鲜度是前提而非装饰。

**引理 125（两折联盟加权共形的覆盖）** 在支撑交集 `S_∩` 上，若折 A 与折 B 独立，站点权重与贡献权重仅在折 A 上估计并冻结，折 B 的分数在给定权重后满足加权可交换性，则
```
P( g_{new} ≤ U_∩(α_d) ) ≥ 1−α_d      （在 S_∩ 上，边际覆盖）
```
若部署分布相对校准分布有有界密度比 `dP_deploy/dP_calib≤C`，则保守下界为 `1−α_d−ε_shift(C)`；若 `x∉S_∩`，无保证，必须回退。证明：标准分裂共形 + 加权共形定理；两折保证权重与折 B 分数独立，故折 B 的条件覆盖成立；支撑外无交换性，故只能声明 `S_∩`。∎
推论：**合作提高活性只能通过 `n_eff` 与支撑覆盖**，不能通过把 `U_∩` 人为调小；`n_eff` 越小，分位越松，假拒绝越多。贡献加权若在同一折上用标签调参，会使分数与权重相关，覆盖保证失效——这是"合作激励"与"统计有效性"之间的硬约束。

**引理 126（迁移—蒸馏—能量—站点联合间隙）** 记
```
Δ_tr = J_real(T)−J_sim(T),  Δ_dis = J_real(S)−J_real(T),
Δ_E  = J_real(S;η)−J_real(S;η̂),  Δ_site = J_real(S;site)−J_real(S;calib) .
```
则在高概率下
```
J_real(S;site,η) − J_sim(T) = Δ_tr+Δ_dis+Δ_E+Δ_site
                            ≤ U_gap+U_dis+U_E+U_site .
```
证明：代数展开；四项分别由 v12 TGC、v13 DGC、EAC 的能量共形上界与 CFC 的站点加权共形覆盖；对四个 `1−α_i` 事件取联合界，得到 `1−Σα_i`。负的 `Δ` 不计入收益，安全界只取 `max(0,Δ)`。∎
推论：**能量间隙不能拿迁移预算冲抵，站点间隙不能拿蒸馏预算冲抵**；新场景可能同时触发四个间隙的同向低估，这是 v14 的根本脆弱点。

**引理 127（中立元退化等价 v13）** 将定义 603 的四个中立元注入 EBA/BEL/CFC/CEL 端口，则：能量约束恒真、阶梯退化为单资源、联盟退化为单站点、账本退化为恒真审计；ECR 退化为 v13 RTCR。主闭环调用序列与 v13 逐位一致，`Exec_v14=Exec_v13`，再沿 v13 链退回 v12/v11/v10/v9/v8/v7/v6。证明：逐端口代入定义 603，并用定义 595–602 的边界条件核对；五端口互不相交且中立元不改变 v13 任何证书检查。∎

**引理 128（五预算不可挪用 / 无套利）** 若某策略在时间、能量、迁移、蒸馏、证据五个预算上都可行，则它可行；若任一硬安全子预算 `B_safe^T` 或 `B_safe^E` 不足，则无论其他预算有多少剩余，该策略都不可行。形式化地，不存在单调交换函数 `Φ` 使
```
(B_time 不足) 可由 (B_energy 剩余) 补偿，
(B_energy 不足) 可由 (B_time 剩余) 补偿，
(授权不足) 可由 (B_evidence 剩余) 补偿。
```
证明：五预算是执行门的合取约束，安全子预算有独立硬下限；定义中没有跨预算的汇率或替代项，故任一约束失败即使整个合取失败。∎
推论：**"用毫秒买焦耳"与"用数据买授权"都是类型错误**；预算耗尽的唯一合法响应是降档、`a_ask` 或认证回退。

**引理 129（审计时效与撤销）** 在签名不可伪造、哈希链连续、至少一个审计者诚实的前提下，任何被 `Audit(ℓ)=1` 接受的证书都有可追溯的追加式来源；若伙伴 `p` 在时刻 `t_r` 写入撤销，则对所有 `t≥t_r+Δ_audit`，`p∉P_valid`。在 `[t_r,t_r+Δ_audit)` 内可能仍执行陈旧证书，故
```
P(执行已撤销证书) ≤ P(审计延迟 > Δ_audit) .
```
证明：签名与哈希链保证来源不可抵赖；撤销记录在账本中，审计周期 `Δ_audit` 内传播；在传播完成前，系统只能依赖本地过期时间与缓存，故产生上述上界。∎
推论：**CEL 把"合作信任"变成"可失效的信任"**；没有撤销时效，联盟证书的安全保证只是静态快照。

**引理 130（能量—联盟相关性失效的下界）** 存在伙伴集合与能量/仿真模型，使所有伙伴共享同一偏差 `δ(x)` 且各自证书都 sound 于同一个错误教师，则
```
P(∩_p Acc_p ⊄ Safe_true) ≥ 1−α_corr ,
```
其中 `α_corr` 由共同偏差在部署分布上的质量决定；即使 `K→∞`，交集也不会自动收敛到真安全。证明：所有 `Acc_p` 都是同一错误教师 `T̂` 的授权子集，交集仍 `⊆Acc_{T̂}`；若 `Acc_{T̂}` 含不安全动作，则任一交集都含该动作。增加同源伙伴只降低方差，不增加独立证据。∎
推论：**"多方一致"不是"独立验证"**；联盟必须包含至少一个与主仿真/能量模型不同源的诚实锚点，否则引理 124 的 sound 前提被相关性掏空。

## 8. 已知风险与失效模式

1. **能量模型与状态估计误差**：SoC、关节温度、母线电压、再生效率的估计偏差会让 `E_hi` 偏低；电池老化与温度相关内阻使离线模型失配。缓解：能量残差共形上界、硬件在环最坏情形、SoC 地板保护、在线参数辨识、EAC 失效即回退。
2. **热降额导致证书静默失效**：任务在名义力矩下被认证，但热降额后接触/谐波证书已不成立。缓解：所有依赖力矩的证书必须在 `ρ(η)` 下重证；热状态进入 `ζ_ec`；降额触发强制降档。
3. **再生能量记账漏洞**：把再生能量记入安全预留，导致安全停时无能量可用。缓解：物理隔离 `B_safe^E`、只允许存量高于地板支付、能量账本审计与对抗测试。
4. **双资源前沿不可链化**：省时费能与省能费时同时存在，任意选档会产生跨资源套利。缓解：强制支配链设计；不可比时取交集或第 0 档；部署前 100% 单调校验。
5. **联盟伙伴同源共错**：产学研各方共享仿真器、能量模型与校准协议，"多方一致"不是独立证据；引理 124 的 sound 前提被相关性掏空。缓解：至少一个异源独立锚点、真实世界抽查、相关性诊断、保留本地 v13 回退。
6. **加权共形被标签调权破坏**：用验证表现估计站点/贡献权重会让权重与分数相关，覆盖失效。缓解：两折校准、折 A 冻结权重、折 B 只认证、拒绝同折调权。
7. **支持交集过小导致活性塌缩**：合作方支撑交集可能非常窄，系统频繁 `a_ask`。缓解：分层支撑、局部重校准、显式报告 `S_∩` 覆盖率、把活性损失计入预算。
8. **撤销与审计延迟**：联盟证书在撤销传播前仍被执行；审计者被攻陷或账本分叉会破坏来源假设。缓解：短 `Δ_audit`、在线吊销列表、多审计者、哈希链检查点、过期即回退。
9. **激励博弈**：伙伴贡献容易样本换取贡献记账，难样本覆盖不足。缓解：留一法/Shapley 审计、独立难例集、贡献与 held-out 覆盖挂钩、预算按 `n_eff` 与边际收益分配。
10. **四间隙同向低估**：迁移、蒸馏、能量、站点间隙在新场景可能同时偏低（引理 126/130）。缓解：联合三角/四角界、五预算加性、双重漂移检测、任一间隙失效即 `a_ask`/最低档。

## 9. 本轮最大风险

**一句话**：能耗证书与联盟证书都假设"至少一个独立诚实的证据源"，但产学研各方往往共享同一套仿真器、能量模型与校准协议；一旦这个共同前提偏移，授权交集仍会给出一个按时、可审计、看似多方一致的错误放行。
