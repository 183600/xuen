# 第 1 轮（新灵感循环第 1 轮；基线 v20；本轮灵感：「语义分割」×「对话管理」）

> **基线**：v20 产出 MetricVoiceGauge-NCD-HUTDH-v20 + IP-420–424（感知层：PCA/CTS/CFC/HPC/CFCtrl；定义 767–820；引理 151–156；实验 E751–E770）。
> 本轮纪律：**语义只扩危险域，对话只撤语义增量，几何底线不可撤**。不推倒 v20：v17 的 CLP/S2C/HCG/PSV/APS/AMC、v19 的 DCM/OGCC/CCV/DRS/OGC、v20 的 PCA/CTS/CFC/HPC/CFCtrl 全部保留。本轮只做一件事：**把语义分割的“区域级危险闭包”与对话管理的“可撤销承诺”注入 v20 碰撞证书，使机器人看得见几何看不见的危险，并通过有限、可审计的对话恢复活性，但永不越过 v20 的几何安全包络**。

## 0. 直觉与动机

### 灵感 1（语义分割 → 分割不是“给像素贴标签”，而是“给危险域做区域化闭包”）

直觉：语义分割通常被当成逐像素分类器：训练时追求 mIoU，部署时取 argmax 当“世界是什么”。但安全关心的从来不是平均 IoU，而是**最坏的那一小块区域**：透明玻璃在深度图里是空洞、薄壁铁丝在 SDF 里被采样漏掉、液体/人/电缆在几何上可能完全合法，却在语义上是不可碰撞的。更反直觉的是：**分割的准确率不是安全指标，分割的“不知道”才是安全指标**——边界带、稀有危险类、开集未知类恰恰是碰撞的高发区，而 argmax 会把它们悄悄压成“背景”。核心创新：**语义分割证书（Semantic Partition Certificate, SPC）**。SPC 不输出一张彩色标签图，而输出一个**区域划分 + 每个区域的标签集合 + 边界不确定带 + 开集拒绝分数 + 时间戳**；危险判定按“标签集合里只要有一个可能是危险类，就算危险”的**最坏标签闭包**进行。关键反直觉点：**语义分割对安全的正确用法是“只加危险、不减危险”**——它把几何看不见的透明/薄壁/液体/人补进危险域；任何“这是草地所以可通行”的语义放行都不能删除几何障碍，只能作为后续对话撤销的候选。

严谨定义（本轮先用，产物区展开）：
- 像素标签集 `L_α(x) = {c : s_c(x) ≥ q_{1-α}}`，其中 `q_{1-α}` 是共形校准阈值；`L_α(x)=∅` 时记为 `UNKNOWN`。
- 区域划分 `R = {R_i}` 为分割图的连通分量；区域标签集取并集 `L(R_i) = ⋃_{x∈R_i} L_α(x)`，区域危险度 `h(R_i) = max_{c∈L(R_i)} Haz(c)`，`Haz(UNKNOWN)=1`。
- 边界带 `B_ε = {x : margin(x) ≤ ε}`，`margin(x)` 为 top-1 与 top-2 分数差；**边界带一律先按危险处理**，因为薄壁与透明物体的漏检几乎总发生在边界。
- 语义危险域 `ColDom_sem(n,o) = Inflate(⋃_{h(R_i)=1} R_i ∪ B_ε, ε_bound + ε_depth + ε_pose)`。
- v21 的碰撞域 `ColDom_v21 = ColDom_v20 ∪ ColDom_sem^active`。注意是**并集**：语义层只能扩大碰撞域，故安全动作集只会缩小。

### 灵感 2（对话管理 → 对话不是“聊天”，而是“带撤销权的证书谈判”）

直觉：对话管理通常研究状态跟踪、意图识别、槽位填充与澄清策略，目标是“把用户想说的搞清楚”。在安全系统里，对话的真正价值不是提高任务成功率，而是**给“撤销一块危险域”这件事建立授权、证据与责任链**：谁提出“这块玻璃其实在几何证书之外”、谁附议、证据是什么、多久过期、谁有权撤回。更反直觉的是：**对话越多不等于越安全**——没有撤销权、没有超时、没有失败关闭的对话，会把安全系统拖入“永远在澄清”的活锁；而**沉默必须是保守的**：没人回答时，危险域保持膨胀，而不是被默认放行。核心创新：**证书对话协议（Certificate Dialogue Protocol, CDP）** 与 **对话信念管理器（Dialogue Belief Manager, DBM）**。把每条“语义去危险化”的请求写成一个**承诺（commitment）**：`κ = (区域 R, 目标类别 c*, 证据 E, 提议者 p, 附议者集合 S, 时间戳 τ, 有效期 TTL, 签名)`；只有满足“目标类别非危险 + 足够附议 + 无未决质疑 + 区域不在边界带 + v20 几何证书仍然安全”时，`κ` 才能把 `R` 从 `ColDom_sem` 中移出。**撤销永远优先于承诺**：任何质疑、信任下降、超时或网络分区，都立即恢复该区域的语义危险。关键反直觉点：**对话管理在这里管理的是“危险域的撤销权”，不是“用户意图”**；它的安全性来自“只能撤语义增量、不能撤几何底线、且撤销可瞬时回滚”。

严谨定义（本轮先用，产物区展开）：
- 对话行为 `a = (type, sender, R, c, E, τ)`，`type ∈ {ASSERT, CHALLENGE, JUSTIFY, COMMIT, REVOKE, CLARIFY, ANSWER, ABSTAIN, TIMEOUT}`。
- 对话状态 `s_t = (phase, open_challenges, K_t, turn, deadline, transcript)`；承诺库 `K_t` 是当前有效承诺的集合。
- 信念状态 `b_t(c|R) = [Bel^-(c|R), Bel^+(c|R)]` 为可信区间；只有 `Bel^-(c*|R) ≥ 1-β` 且 `Bel^+(Haz(c*)|R) ≤ β` 才允许承诺。
- 有效承诺谓词 `Valid(κ,t) = (c* ∉ Hazard) ∧ (|S| ≥ q_sem) ∧ (R ∩ B_ε = ∅) ∧ (no open challenge) ∧ (t-τ ≤ TTL) ∧ (v20 geometric certificate still safe)`。
- 去危险集 `D_t = ⋃_{κ∈K_t, Valid(κ,t)} R_κ`；`ColDom_sem^active = ColDom_sem \ D_t`。
- 因为 `D_t ⊆ ColDom_sem`，恒有 `ColDom_v21 = ColDom_v20 ∪ ColDom_sem^active ⊇ ColDom_v20`，故 `Exec_v21 ⊆ Exec_v20`。

### 灵感 3（两者统一 → 语义定“加什么”，对话定“撤什么”，几何定“不可撤的底”）

直觉：把语义分割与对话管理放在一起，最自然的统一不是“先分割再对话”，而是三层权限的分离：**语义层拥有“扩域权”，对话层拥有“撤域权”，几何层拥有“否决权”**。语义分割说“这里可能是玻璃/人/液体”，于是危险域变大；对话说“这块玻璃是固定隔断、已有几何证书覆盖，可以撤掉语义增量”，于是危险域回到几何底线；几何证书说“这个参数仍然撞墙”，于是对话无论怎么附议都不能放行。三者形成一个**单调的安全格**：语义只能向上加，对话只能在语义增量内向下撤，几何是永不被撤销的下界。核心创新：**语义-对话证书（Semantic-Dialogue Certificate, SDC）**。`SDC = (ColDom_v21, D_t, C_sem, K_t, b_t, τ_sem, τ_dlg, merkle_root, mode_sd)`，其中 `mode_sd ∈ {NORMAL, SEM_FROZEN, DLG_REVOKED, FAIL_CLOSED}`。统一接口：**若 `π ∈ Exec_v20` 且 `π ∩ ColDom_v21 = ∅` 且 `SDC` 新鲜且可审计，则 `π ∈ Exec_v21`；否则保持 v20 的保守执行或直接拒绝**。

关键反直觉点：**语义与对话的联合收益不是“更敢走”，而是“在更保守的语义危险域里，通过可撤销对话把误报的活性还回来”**。也就是说，v21 的净效果是：安全性严格不低于 v20（甚至更高），活性在语义误报处通过对话恢复，但永远不会超过 v20 的几何包络。

### 三个层次如何统一

v20 回答“给定几何与感知快照，节点 n 在参数 θ 下是否零碰撞”（`Exec_v20`）；v21 回答“给定语义危险闭包与可撤销对话承诺，节点 n 在参数 θ 下是否仍零碰撞，且该判断是否可审计”（`Exec_v21`）。SPC 是语义侧（区域划分→危险闭包），ACCA 是碰撞侧（语义危险与几何碰撞的并集代数），DBM/CDP 是对话侧（信念→承诺→撤销），CRC 是策略侧（澄清与否的价值判断），SDTC 是时序侧（新鲜度→冻结→失败关闭）。统一状态 `ζ_sd = (C_sem, ColDom_sem, D_t, K_t, b_t, τ_sem, τ_dlg, mode_sd)`。SPC 回答“哪些区域可能是危险”，ACCA 回答“这些危险如何进入碰撞域”，DBM 回答“对话是否让我们更相信某块区域非危险”，CDP 回答“谁在什么证据下有权撤销”，CRC 回答“值得问吗、问谁、问到什么时候”，SDTC 回答“过期后如何保守回退”。

## 1. 研究问题（轮次升级版）

- **Q1（语义危险闭包的可靠性与紧致性）**：如何用共形预测给出**类条件覆盖**的标签集 `L_α(x)`，使透明/薄壁/液体/人等危险类的漏检率可控？边界带 `B_ε` 的宽度如何随深度噪声、位姿误差与分割模型不确定性自适应？区域级标签并集会不会过度膨胀，导致活性崩塌？开集未知类如何在不引入“背景即安全”假设的前提下失败关闭？

- **Q2（语义-几何碰撞代数的单调性）**：`ColDom_v21 = ColDom_v20 ∪ ColDom_sem^active` 的并集语义如何与 v20 的 `ColDom_fed`、`Θ_n^col`、`margin_col` 精确对齐？当语义危险与几何安全冲突时，如何保证“语义只加不减”？`Inflate` 的膨胀半径如何同时覆盖分割边界误差与 v20 的 `δ_geom`，而不重复计算？

- **Q3（对话承诺的授权、撤销与拜占庭语义）**：`Valid(κ,t)` 的附议阈值 `q_sem`、信任 `Trust(r)`、证据权重 `w_e` 如何设定？如何防止“同一分割模型的多机器人高票附议”把系统性漏检变成共识？撤销如何做到瞬时、单调、可审计？人类权威能否绕过附议，若能，如何仍然受几何底线约束？

- **Q4（澄清策略与控制的时序协调）**：什么时候值得发起澄清（VOI 如何计算）？澄清轮数 `T_max`、回答超时 `TTL`、语义新鲜度 `τ_sem` 与对话新鲜度 `τ_dlg` 如何与 v20 的 APS/CFCtrl 对齐？在“语义过期但对话未完成”时，如何冻结危险域而不是释放危险域？如何保证 50Hz 控制环不被对话阻塞？

## 2. 设计原则（在 P31–P33 基础上新增 P34–P36）

**P34 语义危险闭包律（Semantic Hazard Closure Law）**
语义分割不得输出“裸 argmax”。每个区域必须携带标签集合 `L(R)`、边界带 `B_ε`、类条件覆盖下界 `cov^-_c`、开集分数 `ood` 与时间戳 `τ_sem`。危险判定取最坏标签闭包 `h(R) = max_{c∈L(R)} Haz(c)`，且 `Haz(UNKNOWN)=Haz(边界带)=1`。**语义层只能把区域加入 `ColDom_sem`，不能把区域从 `ColDom_v20` 删除**；任何“可通行/安全”的语义结论都只是对话撤销的候选，不是直接的碰撞豁免。

**P35 对话撤销受限律（Dialogue Revocation Boundedness Law）**
每条去危险化承诺 `κ` 必须满足 `Valid(κ,t)`：目标类别非危险、附议数达到 `q_sem`、区域不在边界带、无未决质疑、未超 TTL、且 v20 几何证书仍然安全。**承诺只能撤销 `ColDom_sem` 中的语义增量，不能撤销 `ColDom_v20` 中的任何几何碰撞**。`REVOKE` 永远优先于 `COMMIT`；撤销、超时、网络分区、信任下降都必须立即恢复该区域的语义危险。**没有有效承诺时，危险域保持膨胀；沉默是保守的，不是放行**。

**P36 语义-对话单调安全律（Semantic-Dialogue Monotonic Safety Law）**
定义 `ColDom_v21 = ColDom_v20 ∪ (ColDom_sem \ D_t)`，其中 `D_t` 只由有效承诺构成。因为 `D_t ⊆ ColDom_sem`，故 `ColDom_v21 ⊇ ColDom_v20`，从而 `Exec_v21 ⊆ Exec_v20`。任何组件失效（分割故障、对话分区、澄清超时、证书过期）只能使 `D_t` 变小、`ColDom_sem^frozen` 变大或 `ColDom_v21` 变大，**绝不能使可执行集扩张**。语义过期时冻结危险域而不是释放危险域；对话失效时撤销全部承诺而不是保留承诺。

## 3. 与基线的接口（如何退化）

- SPC 失效（分割模型不可用/校准失败）⇒ 无语义危险增量，只执行 v20 几何证书 ⇒ 等价 v20；
- SPC 过期（`τ_sem` 超 TTL）⇒ 冻结最后一次 `ColDom_sem^frozen` 并禁止新承诺 ⇒ 比 v20 更保守；
- ACCA 失效（语义-几何并集不可计算）⇒ 拒绝语义层，回退 v20 ⇒ 等价 v20；
- DBM/CDP 失效（对话不可用/分区）⇒ 撤销全部承诺 `D_t=∅`，语义危险全部保留 ⇒ 比 v20 更保守；
- CRC 失效（澄清策略不可用）⇒ 不发起澄清，保持危险域膨胀 ⇒ 比 v20 更保守；
- SDTC 失效（时钟/新鲜度不可用）⇒ 进入 `FAIL_CLOSED`，冻结语义危险并撤销承诺 ⇒ 比 v20 更保守；
- 全部失效 ⇒ 完全回退 v20 的 PCA/CTS/CFC/HPC/CFCtrl + 几何 CCV ⇒ 等价 v20；
- **安全继承**：SPC 只加危险、ACCA 只做并集、DBM 只更新信念、CDP 只撤销语义增量、CRC 只决定是否提问、SDTC 只冻结/撤销；任意失效都使可执行集收缩，`Exec_v21 ⊆ Exec_v20` 由引理 162 保证。

## 4. 预期贡献

1. **语义危险闭包证书**：首次把语义分割从“逐像素 argmax”改写为“区域划分 + 标签集合 + 边界带 + 类条件覆盖 + 开集拒绝”的可审计危险闭包，使透明/薄壁/液体/人等几何盲区第一次以“只加不减”的方式进入碰撞证书；
2. **语义-几何单调碰撞代数**：给出 `ColDom_v21 = ColDom_v20 ∪ ColDom_sem^active` 的并集语义与 `Exec_v21 ⊆ Exec_v20` 的严格包含证明，解决“语义放行是否会偷偷扩大安全域”的核心疑虑；
3. **证书对话协议**：把对话管理从“意图/槽位”升级为“带证据、附议、超时、撤销的证书承诺协议”，使“谁能撤销哪一块危险域”成为可机械检查、可 Merkle 审计的社会-技术合约；
4. **澄清的价值论与失败关闭**：用 VOI、轮数预算与超时给出“问还是不问”的安全判据，保证对话不会成为控制环的活锁，也不会因沉默而默认放行；
5. **语义-对话安全格**：`Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18`，v21 的净收益是在**不降低安全性**的前提下，用可撤销对话把语义误报造成的活性损失还回来，实现“看得更危险、走得更谨慎、问得更少、撤得更快”的闭环。

## 5. 本轮最大风险

**一句话**：若所有机器人共享同一种语义分割模型（或同一套训练数据/校准集），则透明、反光、薄壁、稀有危险类上的**系统性漏检会被对话附议误当成“多方一致的安全证据”**，导致 `ColDom_sem` 系统性偏小、`D_t` 过度撤销，最终“语义证书通过、对话共识通过、几何证书通过，却撞上一致地看不见的东西”——即**相关误差被误读为独立共识**。

# IP-425 Semantic Partition Certificate
@dataclass
class SemanticCertificate:
    regions: list                  # R_i: 区域掩码/连通分量
    label_sets: dict               # R_i -> set(C)
    boundary: Mask                 # B_ε
    coverage_lb: dict              # c -> cov^-_c
    ood: Mask                      # 开集/分布外像素
    tau_sem: float
    model_id: str
    calib_id: str


class SemanticPartitionCertificate:
    def __init__(self, seg_model, conformal, hazard_map,
                 alpha=0.05, eps_bound=2, ttl_sem=0.5):
        self.seg = seg_model
        self.cp = conformal            # 类条件共形校准器
        self.hazard = hazard_map       # Haz(c); UNKNOWN -> 1
        self.alpha = alpha
        self.eps_bound = eps_bound
        self.ttl_sem = ttl_sem

    def certify(self, image, depth, pose, now):
        scores = self.seg.logits(image)                 # {s_c(x)}
        label_sets = self.cp.label_sets(scores, self.alpha)   # L_α(x)
        label_sets = {x: (L if L else {"UNKNOWN"})
                      for x, L in label_sets.items()}
        argmax = self.seg.argmax(scores)
        regions = connected_components(argmax, min_area=self.min_area)
        boundary = boundary_band(scores, eps=self.eps_bound)   # B_ε
        ood = self.seg.ood_score(image) > self.seg.ood_threshold

        region_labels, region_haz = {}, {}
        for r in regions:
            Lr = set().union(*(label_sets[x] for x in r.pixels))
            region_labels[r.id] = Lr
            # 最坏标签闭包：任一可能类别危险，则区域危险
            region_haz[r.id] = max(self.hazard_plus(c) for c in Lr)

        return SemanticCertificate(
            regions=regions,
            label_sets=region_labels,
            boundary=boundary,
            coverage_lb=self.cp.class_coverage_lower(),
            ood=ood,
            tau_sem=now,
            model_id=self.seg.model_id,
            calib_id=self.cp.calib_id,
        )

    def hazard_domain(self, cert, depth, pose):
        seeds = [r.mask for r in cert.regions if cert.hazard[r.id] == 1]
        seeds += [cert.boundary, cert.ood]
        # 边界带、未知类、OOD 一律先按危险处理
        eps = self.eps_bound + depth_error(depth) + pose_error(pose)
        return inflate(union(seeds), eps)

    def hazard_plus(self, c):
        if c == "UNKNOWN":
            return 1
        return max([self.hazard.get(c, 1)]
                   + [self.hazard.get(a, 0) for a in ancestors(c)])


# IP-426 Affordance-Conditioned Collision Algebra
class AffordanceConditionedCollisionAlgebra:
    def __init__(self, v20_cert, cdp):
        self.v20 = v20_cert            # v20 的 ColDom_fed / CCV
        self.cdp = cdp

    def collision_domain(self, node, obj, cert, now):
        geo = self.v20.collision_domain(node, obj)
        sem = cert.hazard_domain(...)  # ColDom_sem
        declassified = self.cdp.active_regions(now)   # D_t
        sem_active = sem.difference(declassified)     # 只能减语义增量
        domain = geo.union(sem_active)                # ColDom_v21
        # 安全不变量：语义层永远不能缩小几何碰撞域
        assert domain.contains(geo), "ACCA monotonicity violated"
        return domain

    def safe(self, node, obj, theta, cert, now):
        # 先过 v20 几何证书，再过 v21 语义并集
        if not self.v20.safe(node, obj, theta):
            return False
        return not self.collision_domain(node, obj, cert, now).intersects(theta)


# IP-427 Dialogue Belief Manager
class DialogueBeliefManager:
    def __init__(self, beta=0.05, trust=None, evidence_weights=None):
        self.beta = beta
        self.trust = trust or {}
        self.w_e = evidence_weights or {}

    def update(self, belief, act):
        """可信区间更新：按 Trust(sender) 与证据权重融合。"""
        w = self.trust.get(act.sender, 0.5) * self.w_e.get(act.type, 1.0)
        b = belief.setdefault((act.R, act.c), [0.5, 0.5])
        if act.type in ("ASSERT", "JUSTIFY", "ANSWER"):
            b[0] = b[0] + w * (1 - b[0])
            b[1] = b[1] + w * (1 - b[1])
        elif act.type in ("CHALLENGE", "REVOKE"):
            b[0] = b[0] * (1 - w)
            b[1] = b[1] * (1 - w)
        return belief

    def lower(self, belief, R, c):
        return belief.get((R, c), [0.0, 1.0])[0]

    def upper_hazard(self, belief, R):
        return max([self.lower(belief, R, h) for h in hazard_classes()]
                   + [self.lower(belief, R, "UNKNOWN")])

    def can_commit(self, belief, R, c):
        return (self.lower(belief, R, c) >= 1 - self.beta
                and self.upper_hazard(belief, R) <= self.beta
                and not conflict(belief, R))


# IP-428 Certificate Dialogue Protocol
class CertificateDialogueProtocol:
    def __init__(self, dbm, acca, q_sem, ttl_dlg):
        self.dbm = dbm
        self.acca = acca
        self.q_sem = q_sem
        self.ttl_dlg = ttl_dlg
        self.state = "IDLE"
        self.K = set()                 # 承诺库 K_t
        self.Chal = defaultdict(set)   # 区域 -> 未决质疑
        self.merkle = MerkleTree()     # Merkle_dlg

    def submit(self, act, now):
        self.merkle.append(act)
        if act.type == "ASSERT":
            self.state = "PROPOSED"
        elif act.type == "CHALLENGE":
            self.Chal[act.R].add(act.sender)
            self.state = "CHALLENGED"
        elif act.type == "JUSTIFY":
            self.state = "JUSTIFIED"
        elif act.type == "COMMIT":
            kappa = self.build_commitment(act, now)
            if self.valid(kappa, now):
                self.K.add(kappa)
                self.state = "COMMITTED"
        elif act.type == "REVOKE":
            # 撤销优先：立即生效，无需附议
            self.K = {k for k in self.K if k.R != act.R}
            self.state = "REVOKED"
        elif act.type == "CLARIFY":
            self.state = "CLARIFYING"
        elif act.type == "TIMEOUT":
            self.revoke_region(act.R)
            self.state = "EXPIRED"
        self.dbm.update(self.dbm.belief, act)

    def valid(self, kappa, now):
        return (kappa.c not in hazard_classes()
                and len(kappa.confirmers) >= self.q_sem
                and not kappa.R.intersects(kappa.boundary)
                and not self.Chal.get(kappa.R)
                and now - kappa.tau <= self.ttl_dlg
                # 几何底线不可撤：v20 证书必须仍然安全
                and self.acca.v20.safe(kappa.node, kappa.obj, kappa.theta))

    def active_regions(self, now):
        return union(k.R for k in self.K if self.valid(k, now))

    def revoke_region(self, R):
        self.K = {k for k in self.K if k.R != R}
        self.merkle.append(("REVOKE_ALL", R))


# IP-429 Clarification & Repair Controller
class ClarificationRepairController:
    def __init__(self, max_turns=3, cost=0.1, latency=0.2,
                 lambda_c=1.0, lambda_t=1.0):
        self.max_turns = max_turns
        self.cost = cost
        self.latency = latency
        self.lambda_c = lambda_c
        self.lambda_t = lambda_t

    def value(self, R, belief, now, deadline):
        # 期望危险域缩减量 - 交互成本 - 延迟风险
        gain = expected_hazard_reduction(R, belief)
        delay_risk = self.lambda_t * max(0.0, self.latency - (deadline - now))
        return (gain - self.lambda_c * self.cost - delay_risk)

    def decide(self, R, belief, now, deadline, turns):
        if turns >= self.max_turns:
            return "KEEP_HAZARD"       # 轮数预算耗尽 -> 失败关闭
        if now + self.latency > deadline:
            return "KEEP_HAZARD"       # 控制截止期不允许提问
        if self.value(R, belief, now, deadline) > 0:
            return "ASK"
        return "KEEP_HAZARD"


# IP-430 Semantic-Dialogue Temporal Controller
class SemanticDialogueTemporalController:
    def __init__(self, ttl_sem=0.5, ttl_dlg=1.0):
        self.ttl_sem = ttl_sem
        self.ttl_dlg = ttl_dlg
        self.frozen_sem = Mask.empty()

    def gate(self, cert, K, now):
        if cert is None:
            # 无语义证书：不回退“释放危险”，而是失败关闭
            return "FAIL_CLOSED", self.frozen_sem, set()

        if now - cert.tau_sem > self.ttl_sem:
            # 语义过期：冻结危险域，撤销全部去危险承诺
            self.frozen_sem = self.frozen_sem.union(
                cert.hazard_domain(...))
            return "SEM_FROZEN", self.frozen_sem, set()

        if any(now - k.tau > self.ttl_dlg for k in K):
            # 对话过期：只保留未过期的有效承诺
            K_valid = {k for k in K if now - k.tau <= self.ttl_dlg}
            return "DLG_REVOKED", cert.hazard_domain(...), K_valid

        return "NORMAL", cert.hazard_domain(...), K

    def build_sdc(self, cert, K, now):
        mode, sem, K_eff = self.gate(cert, K, now)
        d_t = union(k.R for k in K_eff if valid(k, now))
        col_dom_v21 = self.v20.collision_domain(...).union(sem - d_t)
        return SDC(
            col_dom_v21=col_dom_v21,
            D_t=d_t,
            C_sem=cert,
            K_t=K_eff,
            b_t=self.dbm.belief,
            tau_sem=cert.tau_sem if cert else None,
            tau_dlg=now,
            merkle_root=self.merkle.root(),
            mode_sd=mode,
        )

## 2. 符号体系增量（定义 821–880）

见第 0 节符号表。以下只补充三条核心不变式：

- **I1（语义只加）**：`ColDom_sem` 与 `ColDom_v20` 的合成只允许 `∪`，禁止 `\` 作用于 `ColDom_v20`。
- **I2（撤销只减语义）**：`D_t ⊆ ColDom_sem`，且 `Valid(κ,t)` 必须包含 `v20.safe(...)`；因此 `D_t` 永远不能触及几何碰撞。
- **I3（过期只增危险）**：`τ_sem` 过期时 `ColDom_sem^frozen ← ColDom_sem^frozen ∪ ColDom_sem`，`D_t ← ∅`；禁止用过期语义释放危险。

## 3. 推导

**引理 157（语义区域危险闭包的覆盖性）** 设共形校准满足 `P(y(x) ∈ L_α(x)) ≥ 1-α`，且危险判定取最坏标签闭包 `h(R)=max_{c∈L(R)}Haz^+(c)`。则对任意区域 `R`，真实危险类被 `ColDom_sem` 覆盖的概率至少为 `1-α`（对区域内像素做并集界）；边界带 `B_ε` 与开集 `ood` 按危险处理，进一步覆盖分割边界与分布外漏检。故 `TrueHaz ⊆ ColDom_sem` 在覆盖意义下成立。∎

**引理 158（语义-几何单调性）** 由 `ColDom_v21 = ColDom_v20 ∪ ColDom_sem^active` 且 `ColDom_sem^active ⊇ ∅`，得 `ColDom_v21 ⊇ ColDom_v20`。碰撞域扩大等价于安全参数集缩小，故 `Safe_v21 ⊆ Safe_v20`，进而 `Exec_v21 ⊆ Exec_v20`。∎

**引理 159（对话去危险的保守性）** 对任意有效承诺 `κ`，`Valid(κ,t)` 要求 `κ.c ∉ Hazard`、`κ.R ∩ B_ε = ∅`、附议数 `≥ q_sem`、无未决质疑、未超 `TTL`，且 `v20.safe(node,obj,θ)`。因此 `κ` 只能把 `κ.R` 从 `ColDom_sem` 中移除，不能移除 `ColDom_v20` 中的任何碰撞。故 `ColDom_v21 \ {κ} ⊇ ColDom_v20`。撤销或过期立即恢复 `κ.R` 的语义危险，故去危险操作是单调可回滚的。∎

**引理 160（对话承诺的错误预算）** DBM 仅在 `Bel^-(c*|R) ≥ 1-β` 且 `Bel^+(Haz(c*)|R) ≤ β` 时允许提交；在证据条件独立且 `Trust` 校准的前提下，错误去危险概率不超过 `β`。若证据相关（同模型/同数据），独立性假设失效，必须由多样性约束或人类/几何证据补强（见风险 1）。∎

**引理 161（澄清有界与失败关闭）** CRC 在 `turns ≥ T_max`、`now + latency > deadline` 或 `VOI ≤ 0` 时返回 `KEEP_HAZARD`；因此澄清不会无限循环，也不会阻塞控制截止期。若没有形成有效承诺，`D_t` 不增加，`ColDom_sem` 保持膨胀。故澄清策略只能恢复活性，不能降低安全性。∎

**引理 162（v21 整体安全继承）** 在同一几何快照、同一机器人集合下，SPC 只扩 `ColDom_sem`，ACCA 只做并集，DBM 只更新信念，CDP 只撤销 `ColDom_sem` 的增量，CRC 只决定是否提问，SDTC 只冻结/撤销。六者的任意失效都使 `D_t` 变小或 `ColDom_sem^frozen` 变大，故 `ColDom_v21 ⊇ ColDom_v20` 恒成立，`Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18`。∎

**引理 163（语义-对话证书的可审计性）** `SDC.merkle_root` 链接每一条对话行为、承诺、附议、撤销与语义证书摘要；任何独立验证器可重放 `transcript` 重建 `K_t`、`D_t`、`ColDom_v21`。哈希链使事后篡改可检测，故 `SDC` 是可机械复核的。∎

## 7. 已知风险与失效模式

1. **相关语义误差被误读为独立共识**：所有机器人共享同一分割模型/训练数据/校准集时，透明、反光、薄壁、稀有危险类上的漏检高度相关；对话附议会把“同一模型的一致错误”当成“多方证据”。缓解：强制模型/数据/传感器多样性；类条件共形校准；引入几何、触觉、人类证据；相关证据去重；分歧时 `ABSTAIN` 而非多数票。
2. **边界带过度膨胀导致活性崩塌**：`B_ε` 与 `ε_bound+ε_depth+ε_pose` 叠加后可能吞掉大量自由空间，尤其在高分辨率/远距离场景。缓解：自适应半径、距离变换精确膨胀、区域级边界、VOI 驱动的定向去危险。
3. **对话权威伪造/注入/谄媚**：自然语言承诺可能被提示注入、冒充或“顺着说”污染。缓解：结构化签名行为、来源信任、人类认证、禁止纯自然语言直接提交承诺、承诺必须绑定可验证证据。
4. **澄清疲劳与延迟**：频繁提问降低任务效率，长延迟破坏控制节拍。缓解：`T_max`、VOI 阈值、异步澄清、截止期感知、未答即保持危险。
5. **开集未知类过度保守**：把所有未知都当危险可能使系统在开放世界中几乎不可动。缓解：危险先验分级、主动学习、受控探索、人类授权下的语义去危险。
6. **语义-几何膨胀重复计算**：`ε_bound`、`δ_geom`、`margin_col` 若各自独立膨胀，会重复放大。缓解：统一膨胀预算、显式误差预算分配、单调性断言。
7. **语义过期后长期冻结**：`ColDom_sem^frozen` 只增不减可能导致活性持续下降。缓解：定期重观测刷新、人工复核、在几何安全前提下定向去危险；但不得用过期语义释放危险。
8. **类别层级与危险闭包错误**：`Haz^+` 的祖先闭包可能把安全子类误判为危险，或漏掉跨层级危险。缓解：显式危险类表、层级审计、跨类别一致性测试。
9. **多机器人承诺状态不一致**：分区期间不同机器人持有不同 `K_t`，恢复后可能冲突。缓解：分区即撤销（`DLG_REVOKED`）、全局 Merkle 对账、按节点独立承诺库、恢复时重新附议。
10. **对抗性分割攻击**：对抗 patch/光照可使危险类被分成安全类。缓解：OOD/随机平滑、集成分割、跨模态验证、异常区域默认膨胀。

## 8. 本轮最大风险

**一句话**：CFC/对话层的“多方附议”假设证据独立，但若所有机器人共享同一种语义分割模型与校准集，透明/反光/薄壁/稀有危险类的**系统性漏检会高度相关**，附议越一致越危险——最终 `ColDom_sem` 系统性偏小、`D_t` 过度撤销，形成“语义证书、对话共识、几何证书三方都通过，却一致地看不见同一危险”的**相关误差伪共识**。
