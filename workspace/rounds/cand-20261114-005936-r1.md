# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「四足机器人」×「个性化交互」）

> R69 教会闭环「问」：把不确定性拆成 aleatoric / epistemic，用流匹配给出多模态动作，用信息动作（看/问/触）主动消解歧义，并用流似然作为标定不可吸收的第二意见。但它把「问」建在两个从未被审视的前提上：
>
> 第一，**信息通道是一个已知、平稳、非策略性的随机映射** `p(y|g,o)`。R69 的 VoI 直接把这个通道当成会说话的诚实神谕，把可靠度当成总体常数、把成本当成一次性标量。可真实的「问」是对**某个特定的人**问：有人诚实、有人敷衍、有人会看穿机器人想听什么而投其所好；同一个人在被反复盘问后会疲惫、会变得不合作。**信道的可靠度不是一个参数，而是一个会被控制器自己改变的动态状态。**
>
> 第二，**信息动作与任务动作可以干净分离，且近似免费、可逆**。这是「注视 / 提问 / 轻触」的特权。对**四足机器人**这条前提直接崩塌：它唯一的信息来源常常是脚——而脚既是传感器又是执行器。要判断这块地面能不能踩，唯一办法是**把体重压上去**；一旦压上去，就已经承诺、已经承担了滑倒或踩塌的风险。**探询就是承诺，测量就是行动。**
>
> 本轮两个灵感正好补上这两块：
> - **四足机器人**给出「接触即测量」的本体论：足端接触把信息获取与状态转移耦合在同一动作里，同时带来步态这一天然离散多模态与地形这一不可逆代价；它迫使 VoI 从「熵差」变成「含承诺代价与后继风险的信念空间控制价值」。
> - **个性化交互**给出「信道是被共同塑造的」这一层：每个伙伴有一个可学习、非平稳、可能策略性的协作模型；信任是可耗竭/可恢复的资本；而机器人的提问策略是**表演性的（performative）**——它决定了它能收集到什么数据，于是贪心的个性化会把自己关进回音室。
>
> 核心命题：**把 R69 的「信道已知」升级为「信道要被建模、要被辨识、会被自己改变」，把 R69 的「信息动作可逆且与任务分离」升级为「部分探询是不可逆的耦合承诺」；并证明当信道不可辨识、信任耗尽或探询不可逆风险过高时，PACT 逐指令退化为 FLUID，再退化为 R68。** 命名 **PACT-RAS**（Personalized Active Contact-Trust — Risk-Adaptive System）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我面对的是谁、这份信任还够用吗、这一次探询会不会在得到答案之前就已经把代价付掉**」——提问不是免费的熵泵，而是在一段关系与一副身体上做的、可能不可逆的投资。

## 0. 直觉与动机

**灵感 1（四足机器人 → 探询即承诺，测量与行动重合）**
直觉：轮式机器人可以「先看清再走」，因为看清和走是两件事；四足机器人不行。它的脚掌落在哪里、承重多少，既是它获取地面摩擦/软硬/高度信息的唯一手段，也是它把整个机体押上去的下注。人踩到薄冰上前脚已经承重，感知到「要塌」的时刻，恰是风险已经兑现的时刻。R69 的动作空间 `ξ=(a,g)` 假设 `g` 是只读的旁路通道；四足把这个假设撕开一个口子：存在 **耦合探询 `g_coupled ⊆ a`**，它的信息价值只有在承诺之后才兑现，而承诺本身可能致命。于是「值不值得探」不能再用 `H(M|o) − E[H(M|o,y)]` 回答，必须用「执行它之后的最优期望代价相对不执行下降多少」回答——这正是信念空间 Bellman 中**带动作依赖转移**的那一项。R69 的熵 VoI 只是它在「转移与动作无关」时的上界代理。

**灵感 2（个性化交互 → 信任是资本，不是常数）**
直觉：同一个人，第一次被问会认真回答，第十次被问会敷衍，第一百次被问会反感甚至故意误导。R69 的 `c(g)` 是一次性社交成本，捕捉不到这种**存量效应**。把信任想成账户：每次交互支出一点、安静相处时缓慢回血；账户越低，回答越不可靠，而越不可靠就越想多问——一个把账户越问越空的正反馈。个性化不是「给每个人一个不同的可靠度常数」，而是「维护一个会随交互历史演化的信任资本，并把它作为受控状态」。

**灵感 3（个性化交互 → 表演性：贪心的个性化只学到自己的倒影）**
直觉：如果机器人只按自己当前的信念问它最想问的问题，那么它采到的数据分布就依赖它自己的信念；当它「确信」某人不可靠时，它只会去问那些它预期会得到坏答案的问题，于是不断收集到印证「不可靠」的证据。这是**表演性预测 / 自证预言**：估计器决定了它自己将看到的数据。极端情况下，贪心个性化的 Fisher 信息趋近于零——参数不再被数据约束，后验停在初始值上，**机器人学到的不是那个人，而是它自己关于那个人的偏见**。要打破它，必须保留一个非零的**外生探索率**：问一些「与当前信念无关」的问题。这是可辨识性的代价，也是自由意志式提问的最小残留。

**灵感 4（个性化交互 → 诚实不是免费的：策略性伙伴）**
直觉：人会顺着机器人学。如果机器人一被质疑就降速、一听到「危险」就绕路，人很快学会用「危险」来操控它；如果机器人讨厌沉默，人就学会用沉默索取关注。R69 的「k 个正交证据源一致」假定欺骗相关是固定常数，但一个**会观察学习者并调整策略**的伙伴，其欺骗相关是内生的。于是个性化不仅是估计问题，还是**机制设计问题**：提问要激励相容（说真话弱占优），审计要不可预知（让「演给学习者看」无利可图）。

**灵感 5（包含性 → PACT 必须把 FLUID 与 R68 当作边界）**
直觉：本轮最重要的理论姿态延续 R69：**新层必须是旧层的严格泛化**。当没有个性化（用总体先验）、所有探询可逆（ρ=0）、信任满格（T=T_max）、探索率归零时，PACT 必须逐指令等于 FLUID；当再关闭交互时等于 R68。否则个性化就只是又加了一个需要单独信任的黑箱，安全侧反而可能被「更懂人」的自信拖累。链条 `R68 ⊂ FLUID ⊂ PACT` 让风险单调性可传递，也让每一次「更聪明」都能被最保守的底裤兜住。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（PACT-RAS 总览与不变式）** PACT-RAS = (PPM, TCD, LPM, IAV, GSP, PLG, STRAT, TED, RAS-WM‡)。三不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i / R69 定义 293-i）：个性后验 θ̂_p 与信任资本 T_p 只在**慢环**更新，快环只读冻结值；
(ii) **双重预算**：继承 R69 交互预算（≤1 次/单位时间、位移 ≤ ε_g、成本 ≤ c_max），并新增**信任下限** T_p ≥ T_min（紧急审计除外）与**不可逆预算**：一个决策视界内累计承诺风险 Σ ρ(g)R_succ(g) ≤ ε_irr；
(iii) **证据纪律**：信任加权但单源永不定案；有效可靠度必须由**事后被验证的回答**估计，不得用总体均值冒充个体真值。

**定义 311（个性化协作模型 PPM）** 伙伴隐变量 θ_p = (h_p 诚实, κ_p 能力, β_p 帮助成本, τ_p 风格偏好, ν_p 风险容忍)，取分层先验 π_0（总体）与个体后验 p(θ_p | D_p)，D_p 为该伙伴交互史。个性化 = 由 D_p 收缩出的后验。非平稳由变点过程刻画：θ_p(t) 以未知时刻跳变，PPM 检测跳变后回退到 π_0。

**定义 312（信任资本 TCD）** T_p(t) ∈ [0, T_max]，离散动力学
`T_p(t+1) = clip( T_p(t) + r·(1−I_t)·dt − d·I_t·u(g_t), 0, T_max )`，
I_t 为是否交互，u(g) 为社交侵入度，r 为静默恢复率，d 为耗竭率。有效诚实度
`h_p^eff(T) = h_min + (h_p − h_min)·σ((T − T_50)/s)` 随 T 单调上升；被盘问越狠，回答越不可信。

**定义 313（表演性响应模型）** 伙伴回答 `y ~ p(y | g, x, θ_p, ς_t)`，其中 ς_t 是机器人的交互史/策略。若机器人策略是自身估计的函数 `q_{θ̂}(g)`，则数据分布内生。策略性情形：伙伴的响应策略对机器人**未来策略**做最优反应（Stackelberg 互动）。

**定义 314（四足接触探询模型 LPM）** 地形隐变量 ℓ（摩擦、软硬、高度、可承重性）。一次落脚/探足 g 同时包含（a）运动承诺与（b）通过接触后本体感受对 ℓ 的观测；结果 y=(滑移, 下陷, 接触力) 只有在**承重之后**才被观测。定义可逆度 ρ(g) ∈ [0,1]：ρ=0 为纯观测（注视/提问/等待），ρ=1 为完全承重落脚，介于其间为轻触探针。

**定义 315（承诺账本）** 账本 L 记录每次承诺性探询及其后继风险；不可逆性意味着：探询带来的信念更新**发生在风险兑现之后**。故其代价不是瞬时 `c(g)`，而是 `E_y[ΔC(successor; g, y)]`，且失败的样本可能永远无法用于更新（系统已经摔倒）。

**定义 316（伙伴条件增广动作）** `ξ = (a, g, ψ)`：a 任务动作，g 信息动作（区分**可分离** `𝒜_info^⊥`（注视/问句/等待）与**耦合探询** `g_coupled ⊆ a`（落脚）），ψ 为步态/风格参数（步态类别、速度、抬腿高度、跟随距离、平滑度；步态为离散模态）。个性化策略 `π_θ(ξ | o, θ̂_p, T_p)`。

**定义 317（PACT-VoI：含不可逆性与信任的净信息价值）** 对候选 g：
`VoI†(g) = a(θ̂_p, T_p)·E_y[H(M|o) − H(M|o,y)] − c_phys(g) − c_social(g)·(1/T_p − 1/T_max) − λ_irr·ρ(g)·R_succ(g) − c_ident(g)`
其中 a(·) 为有效可靠度，R_succ 为承诺后继风险，c_ident 为占用探索预算的机会成本。选 `g* = argmax VoI† s.t. R_succ(g) ≤ ε_irr` 且预算/信任约束成立；`max VoI† ≤ 0` 则不交互。**归约**：a≡1、ρ≡0、T=T_max、c_ident=0 时逐项等于 R69 定义 298。

**定义 318（步态/风格个性化 GSP）** 把 R69 的流匹配策略条件在 `(o, θ̂_p, T_p)` 上，得到步态与风格的模态分布 `π_gait(·|o,θ̂_p,T_p)`；偏好从显式反馈与隐式线索（舒适度、距离调整、表情）学习，但只在**同意包络** 𝒞_env（安全、舒适、反操纵）内生效，包络外的偏好一律投影回包络。

**定义 319（可辨识性与外生探索）** 问询分布满足探索下界：`q(g) ≥ ε_explore/|G|`（或按 D-最优设计分配）。此时 Fisher 信息 `J(θ_p; q) ≳ ε_explore·min_g J_g(θ_p)`，后验才能以 O(ε_explore·n) 收缩；低于该下界后验停止收缩，θ̂_p 只在弱可辨识流形上漂移。

**定义 320（表演性回路守护 PLG）** 监控三项：(i) 可辨识性缺口（有效样本/Fisher 信息）；(ii) 模型可靠度与**事后验证的有效可靠度**之差；(iii) 信任资本轨迹。任一越界 ⇒ 强制外生探索、冻结个性化（θ̂_p 回退到 π_0）或直接退化为 FLUID。

**定义 321（策略性伙伴与激励相容提问 STRAT）** 伙伴效用 U_p(y, robot 未来策略)。提问附带适当评分规则 s(y, belief)，使**如实报告弱占优**；以不可预知概率 p_audit 施加审计与惩罚 C_a；若检出「响应随机器人策略异常变化」（非机制性操弄），则把该源标记为对抗源，a→a_adv 并退回 R69 保守。

**定义 322（信任感知证据纪律 TED）** 把 R69 的固定「k 个正交源一致」升级为按有效可靠度与正交性加权的融合：源 i 的权重 `w_i ∝ a_i·orth_i`，有效独立源数 `k_eff = 1/Σ w_i²`；仅当 `k_eff ≥ k_min` 或 VoI 增益超过高置信阈值时才允许定案。**单个低信任人类永远不能单独定案，单个高信任源也不得单独裁决高风险模态**（正交性要求不放松）。

**定义 323（三级保守退避）** 若歧义在预算内消解且信任/可辨识/不可逆均通过：`λ = λ_floor(U_ale)`（resolution bonus）。若未消解/超时/预算越界：`λ = λ_floor(U_ale + U_epi)`（= FLUID）。若再叠加慢变故障、PLG 告警、信任低于下限、检出策略性操弄：`λ = λ_floor(U_ale + U_epi) + λ_trust`，并回退 R68 纯保守。λ 在任何检测触发时**单调不降**。

**定义 324（证书 J_PACT）** `J_PACT = (J_FLUID, partner_id_hash, H(θ_p|D_p), T_p, ece_partner, a_eff, ε_explore, k_eff, H(ledger), performative_gap, pact_ver)`。Valid ⇔ Valid(J_FLUID) ∧ 可辨识性达标 ∧ T_p ≥ T_min ∧ 承诺风险 ≤ ε_irr ∧ 审计未标记操纵性交互。

**定义 325（干扰集 AIC-PACT）** `ℰ_PACT = ℰ_FLUID × ℰ_strategic × ℰ_trust × ℰ_terrain × ℰ_style`：谄媚/博弈式回答、信任侵蚀攻击、冒充伙伴、地形陷阱（探足诱发坍塌）、风格偏好漂移或伪造舒适线索、伙伴状态已变但旧答案被回放。

**定义 326（参与式审计 VQAuditor-P）** 审计个性化决策：是否过度盘问、是否操纵、是否存在歧视性适配、是否陷入自证回音室、不可逆承诺与当前信念是否自洽。结论回灌慢环，作为 PLG 与 PPM 的下一轮先验。

```python
# IP-264 PPM：个性化伙伴模型（分层先验 + 变点检测）
class PersonalizedPartnerModel:
    def __init__(self, population_prior, change_point):
        self.prior, self.cp = population_prior, change_point
        self.post = {}                            # pid -> 后验 over (h,kappa,beta,tau,nu)
    def update(self, pid, g, y, validated=None):  # 仅在慢环或事后验证时调用
        if self.cp.shift_detected(pid, y):
            self.post[pid] = self.prior.clone()
        self.post[pid] = bayes_update(self.post[pid], y, weight=validated)
        return self.post[pid]
    def effective_reliability(self, pid, T):
        th = self.post.get(pid, self.prior)
        return th.h * th.kappa * sigmoid((T - T_MIN) / TAU_T)

# IP-265 TCD：信任资本（会耗竭、会恢复）
def trust_step(T, interacted, intrusion, dt):
    return clip(T + RECOVER*(not interacted)*dt - DEPLETE*interacted*intrusion,
                0.0, T_MAX)

# IP-266/267 LPM + IAV：耦合探询的净价值（探即承诺）
def pact_voi(g, modes, w, o, partner, T):
    a = partner.effective_reliability(partner.pid, T)   # 有效可靠度，非人口均值
    info = a * (entropy(w) - expected_entropy(w, g, o))
    if g.reversibility > 0:                             # 落脚：信息动作=任务承诺
        risk = expected_successor_risk(g, o)            # 含滑倒/踩塌等失败后继
        if risk > EPS_IRR:
            return -inf                                  # 不可逆刹车
        irr = LAMBDA_IRR * g.reversibility * risk
    else:
        irr = 0.0
    social = SOCIAL_W * g.intrusion * (1.0/T - 1.0/T_MAX)
    return info - g.phys_cost - social - irr - ident_cost(g)

# IP-268 GSP：步态/风格个性化（复用 R69 流匹配，条件加入伙伴模型）
def gait_style_sample(fmp, o, partner, T, K):
    z = fmp.trunk(o)
    z_p = fuse(z, partner.post.get(partner.pid, partner.prior), T)
    modes = fmp.sample_with(z_p, K)                     # 含步态类别 + 风格参数
    return [project_to_consent_envelope(m, partner) for m in modes]  # 同意包络内

# IP-269 PLG：表演性回路守护（外生探索 + 有效可靠度校验）
class PerformativeLoopGuard:
    def guard(self, g_star, pid):
        if self.identifiability_gap(pid) > GAP_TAU:      # 不可辨识 → 注入外生探索
            return randomized_perturb(g_star, eps=EPS_EXPLORE)
        return g_star
    def audit(self, pid, y, later_verified):             # 用事后验证估计“有效”可靠度
        self.update_effective(pid, y, later_verified)
        return abs(self.effective(pid) - self.model_reliability(pid))

# IP-270 STRAT：策略性伙伴（激励相容 + 不可预知审计）
def ic_elicit(candidate, pid):
    if candidate is None:
        return None
    if rand() < AUDIT_P:
        candidate = attach_proper_scoring_rule(candidate)  # 如实报告弱占优
    return candidate

# IP-274 PACT-RAS 主闭环（继承 R69，插入个性化/信任/不可逆层）
def PACT_RAS_round(M, obs, pid):
    # 1) 继承 R69：模态分解 + 流似然第二意见
    z, o = M.mtm.forward(obs); _, U_cal, _ = M.cof.step(o)
    K = 4 if M.fmp.mode_head(z) > TAU_MODE else 1
    modes, w = M.fmp.decompose(M.fmp.sample(o, K), z)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, obs, o_cal)
    slow_fault = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    # 2) 个性化信道：伙伴后验（慢环冻结）+ 信任资本结算
    th = M.ppm.post_for(pid)                       # 只读
    T  = M.tcd.step(M.T[pid], M.last_interacted, M.last_intrusion, M.dt)
    # 3) 不可逆感知的 VoI：可逆提问 vs 耦合落脚分开定价
    g = None
    if U_epi > TAU_EPI and not slow_fault and T > T_MIN:
        g = M.iav.choose(modes, w, o, th, T, M.budget)   # 内部含 EPS_IRR 刹车
        g = M.plg.guard(g, pid)                          # 不可辨识 → 外生探索
        g = M.strat.ic_elicit(g, pid)                    # 策略性 → 激励相容 + 审计
    # 4) 信任感知证据纪律：低信任/低 k_eff 不得单独定案
    if g is not None:
        y = M.cia.execute(g)
        U_epi = M.ted.update(modes, y, th, T)            # 需要 k_eff>=k_min
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(), lam_floor(U_floor))
    # 5) 个性化步态风格（流匹配生成，受同意包络约束）
    style_modes = M.gsp.sample(M.fmp, o, th, T, K)
    mode = select_mode(style_modes, U_epi, lam, consent_envelope(th))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(mode.a), ..., wm_preds)
    # 6) 任何检测触发 → 单调退避到 R68 纯保守
    if slow_fault or M.plg.alarm(pid) or T <= T_MIN or M.strat.flagged(pid):
        lam = max(lam, 0.8); k = min(k, k_cal_shrink(mode.a, U_cal))
    # 7) 记账 + 证书 + 参与式审计（写操作全部离开快环）
    M.tcd.commit(pid, g, mode)
    M.vqa_p.submit_async(pid, g, y, T, th, a_hat, ledger=M.ledger)
    M.cert.issue(J_PACT(...))
    return k, lam, mode, (U_ale, U_epi)
```

## 3. 推导

**引理 19（耦合探询的不可逆修正）** 在信念空间 MDP 中，纯观测量 g 满足 `T(s'|s,g)=T(s'|s)`，其价值只是「信息 + 瞬时成本」；但耦合探询 g⊆a 的转移依赖动作，其动作价值为
`Q(b,g) = E_{s~b}[R(s,g)] + γ·E_{o'}[V*(τ(b,g,o'))]`，
其中 `E_{o'}` 包含失败事件（滑落、踩塌）。单个灾难结果以概率 `ρ(g)·p_fail` 出现，贡献 `−C_cat·ρ(g)·p_fail`，可压倒信息增益。因此
`VoI_irr(g) = Q(b,g) − Q(b,a_0) = 信息项 − 瞬时成本 − 不可逆承诺代价`，
且**存在风险阈值 ε_irr：超过它，拒绝探询严格优于执行**。系：R69 引理 16 的熵差只在 ρ=0 时是精确价值；四足接触使它退化为上界代理，最优探询不是「信息最大」而是「风险约束下信息最大」。

**引理 20（信任资本双稳态与过度盘问陷阱）** 设有效可靠度 a(T) 单调升、饱和；每次交互耗竭 d、静默恢复 r。一个把可靠度当作总体常数 ā 的短视 VoI 最大化者，忽略了 `a'(T)` 这一**存量外部性**：它把当前问题的最优性建立在「把未来信任花掉」之上。若 ā > a(T*)（高估），则当 T 跌破临界 T* 后，回答已低于「值得停问」的可靠度，但短视者仍以为 ā 可信而继续问，形成稳定低信任均衡 T_low < T*（另一个稳定均衡为高信任 T_high）。二者都由漂移函数在零点处的稳定性给出。修法：用 a(T) 而非 ā 定价，并加信任下限 T_min，则低信任均衡消失、系统被锁定在高信任均衡。系：**「多问总没错」是错的；不加信任账本的个性化会主动把自己问成一个不可信的伙伴。**

**引理 21（表演性不可辨识：贪心个性化只学到自己的倒影）** 设回答 `y~p_{θ_p}(y|g)`，问询 `g~q_{θ̂}(g)`。关于 θ_p 的 Fisher 信息为
`J(θ_p; θ̂) = E_{g~q_{θ̂}} J_g(θ_p)`。
若 q_{θ̂} 退化为贪心单点 g*(θ̂)，而 g* 在 θ̂ 的邻域内局部常值，则 `J ≈ J_{g*}` 可在「无差别点」处趋近于零：该处似然对参数不敏感，数据不再约束后验。此时后验收缩率 → 0，θ̂ 停在初值/先验附近——估计器对任意初值都是稳定不动点，故个性化**自证**。加入 ε 探索后 `J ≥ ε_explore·min_g J_g > 0`，后验以 O(ε_explore·n) 收缩；不探索的偏差上界约为 `C(1−ε_explore)/ε_explore`。系：**回音室不是偶发故障，而是零探索下的均衡**；外生探索不是可选项，是自由意志式提问的最小剂量。

**引理 22（策略性伙伴的诚实激励）** 若伙伴收益依赖机器人未来策略、且报告不可验证，则无机制时如实报告不占优，均衡误报率 δ_s>0。施加适当评分规则并以不可预知概率 p_audit 审计、惩罚 C_a，则如实报告为 Bayes–Nash 均衡当且仅当 `p_audit·C_a > ΔU_lie`（说谎的期望收益）。系：审计概率必须**对伙伴不可预知**，否则会被针对性规避；且该结论依赖理性与已知支付结构，真实人类只是近似，因此该层只能收紧、不能替代保守底裤。

**定理 18（PACT 严格包含 FLUID，从而包含 R68）** 在 A99–A103（A99 经 ε_explore 伙伴模型可辨识；A100 信任资本非退化或走退避；A101 耦合探询风险闸门；A102 激励相容或保守回退；A103 个性化仅在同意包络内）下，任意状态 s 的期望风险满足 `Risk_PACT ≤ Risk_FLUID ≤ Risk_R68`。当 (a) θ̂_p = 总体先验（无个性化）、(b) 所有探询可逆 ρ=0、(c) T_p ≥ T_max、(d) 关闭策略性/探索修正时，PACT 逐指令等于 FLUID；再关闭交互则等于 R68。因此 `R68 ⊂ FLUID ⊂ PACT`，安全侧永不弱于旧层。

**定理 19（共适应安全与无突变）** 风格个性化经同意包络投影后不越出安全/舒适集；PLG、信任下限、不可逆刹车、策略性标记任一触发都只**单调收紧** λ 并收缩认证前缀 k，最终退化为 R68；换装/提交不变式（R68 定理 15）保持，故控制连续、无突变。交互只改变「选哪个模态 / 用哪种风格」，不改变安全包络。

## 6. 本轮最大风险

**一句话**：PACT-RAS 把「问」升级为「带信任账本、会改变对象、且可能不可逆的探询」，但个性化本身是一个**自证循环**——机器人越相信自己关于人或地形的模型，就越只按该模型提问和落脚，于是得到的数据恰好印证了它；一旦初始信任判断偏低，系统会锁死在「低信任—低信息—更少求证」的回音室里，而**不可逆的探脚让它连后悔与重学的机会都没有**——个性化于是从「更懂你」变成「自我实现的偏见」，且无法被证伪。

**次级风险与缓解**：
1. **不可逆探询致命**（探足踩塌/滑落）→ 定义 314–315 承诺账本 + EPS_IRR 刹车 + 定理 19；
2. **回音室/表演性偏置** → ε_explore 下界 + PLG 有效可靠度校验 + 事后验证（引理 21）；
3. **策略性操弄（谄媚/冒充/信任侵蚀）** → 激励相容评分规则 + 不可预知审计 + 对抗源降级（引理 22、ℰ_PACT）；
4. **信任被过度消耗** → 信任资本动力学 + T_min + 过度盘问审计（引理 20）；
5. **个性化越界/操纵与歧视** → 同意包络投影 + VQAuditor-P + J_PACT 拒绝未达标交互。

## 2. 形式化定义（要点版）

**定义 310（总览与不变式）** 三不变式：实时流零学习写（PPM/TCD 只在慢环）；双重预算（R69 交互预算 + 信任下限 T_min + 不可逆预算 ε_irr）；证据纪律（信任加权但单源不定案，有效可靠度须事后验证）。

**定义 311–313（PPM / TCD / 表演性响应）** 伙伴隐变量 θ_p 有分层先验与个体后验、非平稳变点；信任动力学 `T←clip(T+r(1−I)dt−d·I·u(g))`；回答 `y~p(y|g,x,θ_p,ς)`，策略 q_{θ̂}(g) 使数据分布内生；策略性伙伴对机器人未来策略做最优反应。

**定义 314–316（LPM / 承诺账本 / 增广动作）** 地形隐变量 ℓ；落脚同时承诺与观测，y 在承重后才可见；可逆度 ρ、后继风险 R_succ；账本记录不可逆承诺。动作 `ξ=(a,g,ψ)`，区分可分离信息动作 `𝒜_info^⊥` 与耦合探询 `g_coupled⊆a`。

**定义 317（PACT-VoI）** `VoI† = a(θ̂_p,T)·E_y[H(M|o)−H(M|o,y)] − c_phys − c_social(1/T−1/T_max) − λ_irr·ρ·R_succ − c_ident`；`g*=argmax VoI† s.t. R_succ≤ε_irr`；归约到 R69 当 a≡1、ρ≡0、T=T_max、c_ident=0。

**定义 318–319（GSP / 可辨识）** 流匹配条件在 `(o,θ̂_p,T)` 上生成步态/风格模态，偏好只在同意包络内生效；问询分布满足 `q(g)≥ε_explore/|G|`，Fisher 信息 `J≳ε_explore·min_g J_g`。

**定义 320–322（PLG / STRAT / TED）** PLG 监控可辨识缺口、有效-模型可靠度差、信任轨迹，越界强制探索/冻结/退化；STRAT 用适当评分规则 + 不可预知审计使如实弱占优，检出操弄则标对抗源；TED 用 `k_eff=1/Σw_i²` 决定是否定案，低信任单源不定案。

**定义 323–326（三级退避 / 证书 / 干扰集 / 审计）** 通过则 `λ=λ_floor(U_ale)`；未消解则 `λ=λ_floor(U_ale+U_epi)`；再叠加故障/PLG/低信任/操弄则加 `λ_trust` 并回 R68，λ 单调不降。`J_PACT` 并入伙伴后验熵、信任、可辨识、k_eff、账本、表演性缺口；`ℰ_PACT` 覆盖策略性/信任/地形/风格攻击；VQAuditor-P 审过度盘问、操纵、歧视、回音室、承诺失配。

## 3. 关键算法伪代码

```python
# IP-264 PPM：个性化伙伴模型（分层先验 + 变点；慢环）
class PersonalizedPartnerModel:
    def update(self, pid, g, y, validated=None):
        if self.cp.shift_detected(pid, y): self.post[pid] = self.prior.clone()
        self.post[pid] = bayes_update(self.post[pid], y, weight=validated)
    def effective_reliability(self, pid, T):
        th = self.post.get(pid, self.prior)
        return th.h * th.kappa * sigmoid((T - T_MIN)/TAU_T)

# IP-265 TCD：信任资本
def trust_step(T, interacted, intrusion, dt):
    return clip(T + RECOVER*(not interacted)*dt - DEPLETE*interacted*intrusion, 0, T_MAX)

# IP-266/267 LPM+IAV：探即承诺的净 VoI
def pact_voi(g, modes, w, o, partner, T):
    a = partner.effective_reliability(partner.pid, T)
    info = a * (entropy(w) - expected_entropy(w, g, o))
    if g.reversibility > 0:
        risk = expected_successor_risk(g, o)          # 滑倒/踩塌等失败后继
        if risk > EPS_IRR: return -inf                # 不可逆刹车
        irr = LAMBDA_IRR * g.reversibility * risk
    else:
        irr = 0.0
    return info - g.phys_cost - SOCIAL_W*g.intrusion*(1/T - 1/T_MAX) - irr - ident_cost(g)

# IP-268 GSP：步态/风格个性化（复用 R69 FMP）
def gait_style_sample(fmp, o, partner, T, K):
    z_p = fuse(fmp.trunk(o), partner.post_for(partner.pid), T)
    return [project_to_consent_envelope(m, partner) for m in fmp.sample_with(z_p, K)]

# IP-269 PLG：表演性回路守护
class PerformativeLoopGuard:
    def guard(self, g, pid):
        return randomized_perturb(g, EPS_EXPLORE) if self.gap(pid) > GAP_TAU else g
    def alarm(self, pid):
        return self.gap(pid) > GAP_TAU or self.eff_divergence(pid) > DIV_TAU

# IP-270 STRAT：激励相容 + 不可预知审计
def ic_elicit(g, pid):
    return attach_proper_scoring_rule(g) if (g and rand() < AUDIT_P) else g

# IP-274 主闭环（继承 R69）
def PACT_RAS_round(M, obs, pid):
    z, o = M.mtm.forward(obs); _, U_cal, _ = M.cof.step(o)
    K = 4 if M.fmp.mode_head(z) > TAU_MODE else 1
    modes, w = M.fmp.decompose(M.fmp.sample(o, K), z)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, obs, o_cal)
    slow  = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    th = M.ppm.post_for(pid)                                   # 慢环冻结
    T  = M.tcd.step(M.T[pid], M.last_interacted, M.last_intrusion, M.dt)
    g = None
    if U_epi > TAU_EPI and not slow and T > T_MIN:
        g = M.iav.choose(modes, w, o, th, T, M.budget)         # 含 EPS_IRR
        g = M.plg.guard(g, pid)                                # 不可辨识→探索
        g = M.strat.ic_elicit(g, pid)                          # 策略性→IC+审计
    if g is not None:
        U_epi = M.ted.update(modes, M.cia.execute(g), th, T)   # 需 k_eff>=k_min
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(), lam_floor(U_floor))
    style = M.gsp.sample(M.fmp, o, th, T, K)
    mode  = select_mode(style, U_epi, lam, consent_envelope(th))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(mode.a), ..., wm_preds)
    if slow or M.plg.alarm(pid) or T <= T_MIN or M.strat.flagged(pid):
        lam = max(lam, 0.8); k = min(k, k_cal_shrink(mode.a, U_cal))
    M.tcd.commit(pid, g, mode); M.vqa_p.submit_async(pid, g, T, th, a_hat, M.ledger)
    M.cert.issue(J_PACT(...))
    return k, lam, mode, (U_ale, U_epi)
```

## 4. 推导

**引理 19（耦合探询的不可逆修正）** 信念空间 MDP 中耦合探询 g⊆a 的动作价值 `Q(b,g)=E_s R(s,g)+γE_{o'}V*(τ(b,g,o'))`，其 `E_{o'}` 含失败事件，灾难项 `−C_cat·ρ(g)·p_fail` 可压倒信息增益。故 `VoI_irr = 信息项 − 瞬时成本 − 不可逆承诺代价`，存在阈值 ε_irr 使拒绝探询严格更优。系：R69 熵 VoI 只在 ρ=0 时精确，接触使它为上界代理，最优探询是「风险约束下的信息最大」。

**引理 20（信任资本双稳态与过度盘问陷阱）** 短视 VoI 最大化者忽略 `a'(T)` 存量外部性；用总体 ā>a(T) 定价时，T 跌破 T* 后仍继续问，形成稳定低信任均衡 T_low，与高信任均衡 T_high 并存。用真实 a(T) 并加 T_min 后低信任均衡消失。系：「多问总没错」是错的。

**引理 21（表演性不可辨识：贪心个性化只学到自己的倒影）** 关于 θ_p 的 Fisher 信息 `J=E_{g~q_{θ̂}}J_g`。贪心 q 退化为 g*(θ̂) 且在无差别点局部常值时 J→0，后验停止收缩、θ̂ 成为任意初值的稳定不动点（自证）。加入 ε 探索后 `J≥ε_explore·min_g J_g`，偏差上界 `≈C(1−ε_explore)/ε_explore`。系：回音室是零探索下的均衡，外生探索是可辨识的必要代价。

**引理 22（策略性伙伴的诚实激励）** 报告不可验证时无机制则如实不占优（δ_s>0）；适当评分规则 + 不可预知审计满足 `p_audit·C_a>ΔU_lie` 时如实为 Bayes–Nash 均衡。系：审计概率须不可预知；人类只是近似理性，该层只能收紧不能替代保守底裤。

**定理 18（PACT 严格包含 FLUID，从而包含 R68）** A99–A103 下 `Risk_PACT≤Risk_FLUID≤Risk_R68`；当无个性化、全可逆、T=T_max、关闭策略/探索修正时 PACT≡FLUID，再关闭交互则≡R68。故 `R68⊂FLUID⊂PACT`，安全侧不让步。

**定理 19（共适应安全与无突变）** 风格个性化经同意包络投影不越界；PLG/信任下限/不可逆刹车/策略性标记任一触发只单调收紧 λ 与认证前缀 k，最终退 R68；换装不变式保持 ⇒ 控制连续、无突变。

## 7. 本轮最大风险

**一句话**：PACT-RAS 把「问」升级为「带信任账本、会改变对象、且可能不可逆的探询」，但个性化本身是一个**自证循环**——机器人越相信自己关于人或地形的模型，就越只按该模型提问和落脚，数据恰好印证它；一旦初始信任判断偏低，系统会锁死在「低信任—低信息—更少求证」的回音室里，而**不可逆的探脚让它连后悔与重学的机会都没有**——个性化于是从「更懂你」变成「自我实现的偏见」，且无法被证伪。

**次级风险与缓解**：不可逆探询致命（承诺账本 + EPS_IRR 刹车 + 定理 19）；回音室/表演性偏置（ε_explore 下界 + PLG 有效可靠度校验 + 引理 21）；策略性操弄（激励相容 + 不可预知审计 + 对抗源降级 + 引理 22）；信任被过度消耗（信任资本 + T_min + 过度盘问审计 + 引理 20）；个性化越界/操纵与歧视（同意包络投影 + VQAuditor-P + J_PACT 拒绝未达标交互）。
