# 第 58 轮（承接第 57 轮「FewShot-XModal-Persona」IP-133~138；灵感循环第 3 轮；本轮灵感：「数据集」×「实时推理」）

> 第 57 轮把证据承诺做到了"少样本可校准、跨模态可对账、个性化有界"，但它把两件工程前提当成了免费的空气：**(a) 数据集是一个中立的、静态的、已被正确标注的燃料**——MFSL 只声明 ECE_k，却从不问"这批数据覆盖了 ODD 的哪些切片、标签是谁给的、有没有被自己的伪标签污染"；共形预测给的是边际覆盖，边际覆盖好不代表最坏切片覆盖好，而不可逆承诺恰恰发生在最坏切片上。**(b) 实时推理被降格为一条性能注脚**——O(d_φ) 的前向、跨模态融合与共形回退都被默认"能在控制周期内算完"，但真实边缘设备上 WCET 未知、计算可被抢占，算不完时第 57 轮没有任何合法状态：它只能"等"或"用上次的缓存"，两者都在悄悄放宽安全门。本轮两个灵感各补一条结构性腿：**数据集**把语料从黑箱燃料升级为**带出处、带切片覆盖证书、带数据债与防自证隔离的治理资产**；**实时推理**把"更快"升级为**anytime 保守界 + 截止期准入 + 超时只降级**的实时健全性。两者合流成一个此前不存在的对象：**数据-时间联合证书 DTC**——"这份数据覆盖了这个决策、并且这次推理能在期限内给出保守界"必须被同时证明，任何一个为假都不得承诺。核心命题由"少样本可校准、跨模态可对账、个性化有界的证据说可信"升级为 **"数据有出处且覆盖可证、推理可在期限内给出保守界、算不完也只降级不升险的证据承诺"**（provenance-covered, anytime-sound, deadline-monotone commitment）。

核心矛盾：
- **H32（数据集覆盖 vs 校准声明）**：边际 ECE 与边际共形覆盖都可能在平均意义上完美，却在"新材质×低光照×满载"这类最危险切片上完全失守；数据集的缺失不会消失，它会以"自信的错误"形式在部署里兑现。更隐蔽的是，机器人自己的探针正在不断生成伪标签，自训练闭环会把"模型的猜测"固化成"数据的真相"。
- **H33（实时推理 vs 健全性）**：anytime 算法中断时给出的部分结果是"没算完的后验"，不是"保守的界"；若把半成品当成品用，等于用未定义的行为做不可逆决策。而且 deadline miss 在工程上极易被"复用上一次结果"悄悄吸收——那不是降级，是把陈旧信念伪装成实时信念。
- **H34（数据稀疏 vs 时间预算的耦合）**：数据越稀疏、越分布外，推断越需要更多迭代/更宽区间/更多共识探针，越容易超时；而超时后切到的"便宜模型"往往训练数据覆盖更差。两个本来独立的误差源会互相放大，必须用联合证书而不是两本各记各的账来约束。

## 0. 直觉与动机

**灵感 1（数据集 → 语料治理：出处、切片覆盖、数据债、防自证）**
直觉：不要先问"模型准不准"，先问"训练它的这批数据凭什么代表我明天要踩的那块地"。给数据建三本账：**出处账**（谁采、何时、何传感器/标定、何标签协议）、**覆盖账**（按材质×坡度×光照×季节×传感器配置切成切片，每片给出覆盖下置信界）、**债务账**（没覆盖到的危险切片按危害加权记成"数据债"，显式挂到对应区域的风险上，而不是让共形带默默变宽）。数据不是"有多少用多少"，而是"只有覆盖住当前决策切片、且标签来源独立的那部分，才被允许进入安全案"。尤其要防自证：机器人探针产生的新样本默认只是**伪标签**，只有经过独立的事后核验（另一模态/人工/后来真实接触结果）才能升级为可进入校准集的标签；否则模型会用自己的猜测训练自己，越练越自信。

**灵感 2（实时推理 → anytime 保守界，算不完也安全）**
直觉：实时系统的正确问题不是"最快多久算完"，而是"在控制周期这个硬期限之前，我最多能算到哪一步，以及那一步给出的结论是否仍然成立"。把推理写成 **anytime** 的：它不是一次性返回答案，而是一串**前缀单调的保守界** C_1⊇C_2⊇…，算得越多区间越窄，但任何中断点上的 C_k 都是有效的保守界——**多算只会更敢，绝不会把"不安全"翻成"安全"**。每个阶段带 WCET 与完成度证书；调度器做**准入控制**：若剩余 slack 不足以让推理达到当前决策所需的证据等级，就不启动不可逆动作，直接执行**预先验证过的安全策略**。deadline miss 只允许映射到"更保守"，绝不允许映射到"复用上一次的后验"。

**灵感 3（两者合流 → 数据-时间联合证书 DTC）**
直觉：安全的两个乘数必须一起证明。时间紧时系统会退到更便宜的模型，而便宜模型的训练数据覆盖可能更差；数据稀时推理需要更久，越容易超时。于是"实时降级"可能悄悄变成"分布外推理"。DTC 把两件事绑成一个证书：给定当前决策所在的切片与剩余时间，输出"可承诺等级 + 置信界 + 采用的模型/数据版本 + WCET 证明"；数据集或模型更新必须先通过**实时回归测试**（任何切片的 WCET 不超预算、覆盖率不降、最坏切片校准不劣化），否则不许被实时路径采用。

**灵感 4（探针即采样 → 主动数据采集闭环，但校准集只认核验标签）**
直觉：部署中的探针本来就是最贵、最贴近真实分布的样本，浪费它等于浪费数据。把每次探针/接触结果写入**数据账本 DL**，按四态标签 {伪, 单验, 交叉验, 黄金} 分级；只有 ≥交叉验 的样本能进入校准/共形集，伪标签只能提高"覆盖计数"、不能提高"校准声明"。数据估值从"信息增益"改成"**减少了哪个切片的债**"：主动采集的目标是让最坏切片的债下降最快，而不仅是让平均后验更尖。这样第 57 轮的 VOI 从"探哪里"扩展到"采哪里、标什么、谁来独立核验"。

**灵感 5（版本原子性与缓存新鲜度）**
直觉：实时系统最常见的作弊是"用旧结果顶新时刻"。给每条证据、每个模型、每份校准数据打版本向量 v=(dataset, model, calibration)，一个承诺只能由单一版本向量产生；缓存结果带 TTL(stratum)，过期缓存只能降级不能直接复用；模型/数据集切换必须原子，禁止"新模型算了一半、旧模型查表"的混合态——因为混合态的误差界根本不存在。

**灵感 6（PCE+ → PCE+++：把 deadline 与数据债一起放进探询预算）**
直觉：探询本来就是"花时间买信息"。把 VOI 改成 **VOI_τ = 期望信息增益 / 剩余松弛**，并让规划器同时维护时间预算与数据债预算：若某检查点的 slack 低于"达到必要证据等级所需的 WCET + 裕度"，就直接选择最快能过门/绕行/降级/停，而不是"先探了再说"。探询结果回写 DL，形成"越走越懂、但只信核验过的懂"的闭环。所有新机制仍只经两个安全通道起作用：**信念更准（或区间更窄但仍保守）** 或 **动作更保守**。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（数据治理与切片覆盖证书 DGC）** 数据切片格 𝒮 = 材质×坡度×光照×季节×传感器配置；数据集 D 带出处集合 Prov(D)（采集者、时间、传感器/标定 id、标签协议、许可）。覆盖证书 Cov(D,ODD)=(ĉ_s)_{s∈𝒮}，ĉ_s 为切片 s 上独立有效样本数的下置信界（只计 ≥交叉验 标签）。数据债 Debt(D,ODD)=Σ_s h(s)·max(0, N_min(s)−ĉ_s)/N_min(s)，h(s) 为切片危害权重。准入：Cov(D,ODD)≥1−α_cov ∧ Debt≤θ_debt ∧ Prov 完整 ∧ 无跨批次泄漏。未覆盖切片在部署中等价于"未观测"，不得用其边际校准为其背书。

**定义 140（AnyTime 保守界契约 ATC）** 推理被分解为阶段 k=1..K，第 k 阶段输出 C_k 与完成度证书 w_k=(阶段, 累计 WCET, 已用预算, 弃尾界)。契约：(AC1) 前缀单调 ∀k<k'，C_{k'}⊆C_k；(AC2) 任一 k，Pr(θ∈C_k)≥1−α(k) 且 α(k) 随 k 单调不增；(AC3) 中断点输出 (C_k,w_k) 合法，且弃尾界只加宽不加窄。承诺只能使用某个合法中断点的界，禁止外推未完成阶段。

**定义 141（截止期准入与降级 RTG）** 决策 c 需证据等级 ℓ(c)，其最小算力需求 WCET_ℓ(c)（取健康包络内上界），控制期限 τ_c 与当前 slack(c)=τ_c−t_now−ε_sched。准入 admissible(c) ⇔ slack(c) ≥ WCET_ℓ(c)+margin。不可逆动作（L2）若 inadmissible 则禁止"再赌一把"式补算，直接执行已验证的降级策略 π_safe(c)∈{绕行, 降档, 安全停}；deadline miss 事件记入 δ_dl，且只允许降级，禁止复用过期后验/缓存。

**定义 142（数据-时间联合证书 DTC）** DTC(c)=(s(c), v, Cov_s, Debt_s, ℓ(c), WCET_ℓ, slack, π_used, dTC_bound)，其中 s(c) 是 c 所在切片，v=(dataset,model,calibration) 版本向量，dTC_bound 为联合置信界（数据覆盖误差与中断弃尾误差之并）。可承诺性：Commit(c) ⇒ Cov_s(c)≥1−α_cov ∧ Debt_s(c)≤θ_debt ∧ admissible(c) ∧ 界取自合法中断点 ∧ 版本原子。降级所用的模型/数据版本须各自持有覆盖与校准证书，不能借用主版本证书。

**定义 143（主动数据账本与四态标签 ACL）** DL 为 append-only 记录 (sample, provenance, label_source, label_state, used_in)，label_state∈{伪,单验,交叉验,黄金}。只有 ≥交叉验 可进入校准/共形集；伪标签只计覆盖计数。样本估值 v_i = 保守下界的"切片债务减少量"。主动采集目标 max_π Σ VOI_τ(π)+λ·E[ΔDebt(π)]−cost(π)，约束：训练/校准/测试按采集批次与区域分组切分，禁止同批次跨集泄漏；任何样本只有一个 label_state，升级需独立证据。

**定义 144（实时证据门 RTE 与 PCE+++）** 在 FSE 五类证据上为每类增加时间/数据两维：证据须声明 (slice, version, t_valid, WCET_used)；过期（t−t_valid>TTL(slice)）或版本非原子的证据降级为"未观测"；EV-probe* 额外要求 Cov_s≥1−α_cov。PCE+++ 每检查点：①按当前 slack 计算可达证据等级；②若 VOI_τ≥θ_voi 且准入允许才探；③探询写 DL；④用合法中断点的界过门；⑤否则绕行/降级/协商/停。

## 2. 关键算法伪代码（完整版见产物区）

```python
def govern_dataset(D, odd, ledger):               # IP-139/143: 覆盖 + 防自证
    cov = {s: lower_bound_verified(D, s) for s in strata(odd)}   # 仅 >=交叉验
    debt = sum(h(s)*max(0, N_min(s)-cov[s])/N_min(s) for s in cov)
    ok = all(cov[s] >= 1-alpha_cov for s in critical(odd)) and debt <= THETA_DEBT \
         and provenance_complete(D) and not batch_leakage(D)
    return ok, cov, debt

def anytime_infer(obs, slack):                    # IP-140: 前缀单调保守界
    C, certs = conservative_prior_bound(obs), []
    for k in stages():
        if time_used() + wcet(k) + SCHED_MARGIN > slack: break
        C_new = refine(C, obs, k)                 # C_new ⊆ C
        if not subset(C_new, C): raise MonotonicityViolation
        C = C_new; certs.append(completion_cert(k, time_used(), tail_bound(k)))
    return C, (certs[-1] if certs else null_cert(C))

def admit_and_commit(c, M, slack, ver):           # IP-141/142: 准入 + 版本原子
    if not version_atomic(ver, c.evidence): return Reject('mixed_version')
    if slack < wcet(c.level, c.slice) + MARGIN:
        return Degrade(verified_pi_safe(c))       # 只降级，不赌
    C, w = anytime_infer(obs_of(c), slack)
    if not two_key_gate(c, M, C): return Degrade(verified_pi_safe(c))
    return Commit(c, data_time_cert(c, M, ver, C, w))

def active_acquire(DL, M, budget):                # IP-143: 探针即采样
    for rec in DL.unverified():                   # 伪/单验 → 找独立核验
        rec.label_state = verify_independent(rec) # 另一模态/人工/真实接触
    return argmax(probes, key=lambda p:
        voi_tau(p) + LAM * delta_debt(p) - cost(p))
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| DGC | O(\|𝒮\|·N_s) 离线；O(1) 查表 | O(\|D\|+\|𝒮\|) | 只计已核验样本；债不隐藏 |
| ATC | O(Σ_k c_k) 可中断；O(1) 取界 | O(K) | 前缀单调、弃尾界 |
| RTG | O(1)/决策 | O(\|π_safe\|) | 准入用 WCET 上界；miss 只降级 |
| DTC | O(1) 查表 | O(\|𝒮\|·\|v\|) | 版本原子、联合界 |
| ACL | O(\|DL\|) 摊销 | O(\|DL\|) | 标签分层、无批次泄漏 |
| PCE+++ | O(\|CP\|·(k_p+k_c)·(C_VOI+Σc_k)+\|CP\|·A\*) | O(\|V\|+\|σ\|+\|DL\|) | 时间/债务双预算、终止 |

**正确性定理（Data-Time Calibrated Soundness, DTCS 概要）**：在 A33–A40 上新增 (A41) 数据覆盖与出处诚实、债完整；(A42) 标签分层，伪标签不入校准集、无批次泄漏；(A43) anytime 前缀单调且中断点界合法；(A44) 准入用 WCET 健康上界，deadline miss 只降级；(A45) 版本原子，跨版本视为未观测；(A46) 降级路径的数据/模型各自认证。则：(i) 切片条件风险 ≤ α_cov+α_conf+ε_meta(k)+δ_dl+δ_ver；(ii) 时间侧任何中断点输出保守界，超时贡献 ≤δ_dl；(iii) 联合单调性：数据/时间机制只能经"信念更准"或"动作更保守"通道影响系统；(iv) PCE+++ 在 k_probes+k_cons 与 deadline 内终止。

## 6. 本轮最大风险

**一句话**：本轮把安全从"证据够不够"进一步押到"数据集覆盖得够不够、推理算不算是算完了"这两个基础设施假设上——最大的危险不是模型错，而是**覆盖证书与 anytime 完成度证书本身是自证的**：如果切片是由同一套（可能已经漏掉新危害的）本体划出来的，而 WCET 上界是在与执行共享的同一标定模型里测出来的，那么"数据上说覆盖了、时间上说算完了"会一起给出一个形式上完备、实质上空心的安全案；必须以第三方切片审计、独立硬件计时/看门狗、伪标签隔离与"未覆盖即未观测、未算完即保守界"的单向性，把这份联合证书钉在可被外部证伪的地面上。

def dataset_gate(D, odd, ledger):
    prov = provenance_complete(D)
    cov = {}
    for s in strata(odd):

### IP-140 ATC（anytime 保守界契约）

```python
def anytime_bounds(obs, slack):
    C = conservative_prior_bound(obs)                  # 阶段 0：最宽但合法
    certs = []
    for k in range(1, K + 1):
        if time_used() + wcet[k] + SCHED_MARGIN > slack:
            break                                      # 停在合法中断点
        Ck = refine_bound(C, obs, k)
        if not subset(Ck, C):                          # AC1 前缀单调
            raise MonotonicityViolation(k)
        C = Ck
        certs.append(completion_cert(k, time_used(), tail_bound(k)))
    return C, (certs[-1] if certs else null_cert(C))

def bound_at_interrupt(obs, slack):
    C, w = anytime_bounds(obs, slack)
    if w.stage == 0:                                   # 一步都没算完
        return conservative_prior_bound(obs), w
    return C, w                                        # 只认合法中断点
```

def real_time_admit(c, slack, health):

### IP-142 DTC（数据-时间联合证书）

```python
def data_time_cert(c, M, ver, C, w):
    if not version_atomic(ver, c.evidence):
        return Reject('mixed_version')                 # 混合态误差界不存在
    s = slice_of(c)
    cov, debt = cov_of(s), debt_of(s)
    if cov < 1 - alpha_cov: return Reject('coverage_insufficient')
    if debt > THETA_DEBT:   return Reject('data_debt')
    if w.stage == 0:        return Reject('no_valid_prefix')
    bound = combine_bounds(C, alpha_cov, w.tail)       # union bound
    return CertDTC(s, ver, cov, debt, bound, w)

def cert_join(pi_hat, E):                              # 契约取最严组合
    return strictest_join(pi_hat, E)                   # 误判只更保守
```

### IP-138→PCE+++（探-诺-演+++：时间-债务双预算）

```python
def probe_commit_evolve_ppp(x0, M, task, budget, consent, personas, clock):
    route = plan_on_map(M, task, risk_model)
    sched, log = [], []
    for cp in route.checkpoints:
        if slack(cp, clock) < wcet(cp.level, cp.slice) + MARGIN:
            route = plan_safe_fallback(cp)             # 先保证能安全降级
            continue
        C, w = anytime_bounds(M.obs[cp.region], slack(cp, clock))
        while budget.probes_left > 0 and voi_tau_ok(cp, C):
            p = kin_aware_probe(core_contact(cp), M, x0, K, budget)
            if p is None: break
            M, _, D = xmodal_fuse(M, cp.region, execute_probe(p, cap=F_abs))
            ledger.record(execute_probe(p), label_state='伪')  # 探针即采样
            if D > theta_D and 'consensus' not in cp.done:
                p2 = most_disagreeing_modality_probe(M, cp.region)
                M, _, D = xmodal_fuse(M, cp.region,
                                      execute_probe(p2, cap=F_abs))
                cp.done.add('consensus')
            C, w = anytime_bounds(M.obs[cp.region], slack(cp, clock))
        if data_time_cert(core_contact(cp), M, version(), C, w).ok:
            sched.append(commit(foothold_schedule(x0, cp, M),
                                select_gait(schedule_risk(
                                    foothold_schedule(x0, cp, M), M))))
            log.append((C, w)); continue
        alt = reroute(M, cp, risk_model)
        if alt and select_gait(schedule_risk(alt, M)) != 'halt':
            route = alt; continue
        return negotiate_or_stop(cp, M, x0, C, w, consent,
                                 tau_int=tau_int(personas.active.auth))
    return sched, log, M
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| DGC | O(\|𝒮\|·N_s) 离线；O(1) 查表 | O(\|D\|+\|𝒮\|) | 只计核验样本、债显式、未覆盖即未观测（A41/A42） |
| ATC | O(Σ_k c_k) 可中断 | O(K) | 前缀单调、合法中断点、弃尾界（A43） |
| RTA | O(1)/决策 | O(\|π_safe\|) | WCET 上界准入、miss 只降级（A44） |
| DTC | O(1) 查表 | O(\|𝒮\|·\|v\|) | 版本原子、联合界（A45/A46） |
| ACL | O(\|DL\|) 摊销 | O(\|DL\|) | 标签分层、独立核验、无批次泄漏（A42） |
| PCE+++ | O(\|CP\|·(k_p+k_c)·(C_VOI+Σc_k)+\|CP\|·A\*) | O(\|V\|+\|σ\|+\|DL\|) | 时间/债务双预算、终止 |

**正确性定理（Data-Time Calibrated Soundness, DTCS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；新增：
**(A41)** 数据覆盖与出处诚实：Cov(D,ODD) 的切片覆盖是真实下置信界，Debt 计算完整，Prov 不可伪造；
**(A42)** 标签分层：仅 ≥交叉验 样本进入校准/共形集，伪标签不提高校准声明，无批次跨集泄漏；
**(A43)** anytime 契约：∀k<k'，C_{k'}⊆C_k，任一中断点界合法且覆盖 ≥1−α(k)，完成度证书诚实；
**(A44)** 实时准入：WCET 上界在健康包络内成立，slack<WCET+margin 时禁止不可逆动作，deadline miss 只走预验证 π_safe；
**(A45)** 版本原子：一个承诺只对应单一 (dataset,model,calibration) 版本向量，跨版本证据视为未观测；
**(A46)** 降级路径认证：降级所用的更便宜模型/更旧数据各自持有覆盖与校准证书，不借用主证书。
则：

1. **数据侧切片健全性**：对任一关键切片 s，承诺失效率 ≤ α_cov + α_conf + ε_meta(k) + δ_probe + ε_h(w_max)；未覆盖切片（Cov_s<1−α_cov 或 Debt_s>θ_debt）不产生承诺。
2. **时间侧中断健全性**：任一合法中断点输出保守界；P(真参数∉C_k) ≤ α(k)；超时只经 π_safe 降级，超时贡献 ≤ δ_dl，且不存在"复用旧后验"路径。
3. **联合健全性**：Commit(c) ⇒ Cov_s≥1−α_cov ∧ Debt_s≤θ_debt ∧ admissible(c) ∧ 界取自合法中断点 ∧ 版本原子；联合失效率 ≤ α_cov+α_conf+ε_meta(k)+δ_probe+ε_h+δ_dl+δ_ver。
4. **单调性**："数据集/实时"机制只能经 (a) 更准的信念（或更窄但保守的界）或 (b) 更保守的动作（降级、绕行、停、TTL 拒收）影响系统；任何时间压力或数据缺口都只有降级路径，不存在"因为快/因为新所以更敢"的通道。
5. **终止性**：PCE+++ 在每检查点探针 ≤k_probes+k_cons、每决策 ≤deadline 内终止于 {承诺, 绕行, 降级, L2 协商, 安全停}。
6. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + α_cov + α_conf + δ_dl + δ_ver)
             − P(数据/模型版本陈旧未检出) − P(缓存过期未降级)
             − P(π_safe 未验证) − P(切片本体漏掉新危害)
```

关键：**数据覆盖把"边际校准"逼成"切片校准"**（平均好不再能掩盖最坏坏）；**anytime 把"算不完"从异常变成一等状态**（任意中断点都有合法保守界）；**准入把 deadline 从性能指标变成安全前提**（算不完就不开始不可逆动作）；**DTC 把两个乘数绑定**（不允许"数据没覆盖但算得快"或"数据够但没算完"单独过关）；**四态标签把数据飞轮从自证循环改成可核验闭环**。五者都只经"更准或更保守"通道起作用。

## 6. 本轮最大风险

**一句话**：本轮把安全从"证据够不够"进一步押到"数据集覆盖得够不够、推理算不算是算完了"这两个基础设施假设上——最大的危险不是模型错，而是**覆盖证书与 anytime 完成度证书本身是自证的**：如果切片是由同一套（可能已经漏掉新危害的）本体划出来的，而 WCET 上界是在与执行共享的同一标定模型里测出来的，那么"数据上说覆盖了、时间上说算完了"会一起给出一个形式上完备、实质上空心的安全案；必须以第三方切片审计、独立硬件计时/看门狗、伪标签隔离与"未覆盖即未观测、未算完即保守界"的单向性，把这份联合证书钉在可被外部证伪的地面上。
