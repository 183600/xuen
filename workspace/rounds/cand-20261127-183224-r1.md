## 1. 直觉与动机（两个灵感的碰撞）

**灵感 1（智能体 → 在线智能体被封死，离线智能体没有）**
直觉：规则几乎堵死了推理时的能动性——单模型、评测期禁止在线学习/适应、无力触觉无深度、chunk 30 步 + 4 步去噪吃掉延迟余量。多数队伍因此把系统做成「反应式策略」。但智能体的本质不是模块数量，而是**在预算约束下做序列决策**。于是把智能体从推理时搬到训练时：让一个离线智能体决定「吃什么数据、造什么数据、剪什么数据、何时停」。部署时仍是同一个单模型 VLA + guard 栈。核心命题：**把智能体放进数据集，而不是放进推理时。**

**灵感 2（数据集 → 数据集不是静态资产，而是动作空间）**
直觉：v1.1 的数据引擎是**开环**的——孪生表靠语义猜、权重靠人拍、增广剂量靠经验；而第 2 轮自认的最大风险恰是 110 语料的负迁移。把数据集看成**可操作对象**：动作空间 {保留, 删除, 上调, 下调, 去重, 合成(轴,剂量), 重标注, 重排}，奖励是计分函数增益，预算 = 重训算力 + 真机通道。「选数据」因此从拍脑袋变成 bandit/贝叶斯优化/归因的闭环。反直觉点：**数据智能体的第一个动作通常是减法**——剪负迁移 shard、去重近邻、移除捷径，而不是继续加数据。

**统一命题（Agency Amortization，能动性摊销）**
把「规划、纠错、检索、课程」这些本该在线完成的 deliberation，在训练期用**数据操作 + 归因 + 课程**摊销进权重与数据集；推理期只留反应式单模型。三个可检验推论：
- **C1（减法优先）**：负迁移存在时，最优操作是删除/降权，而非增广。
- **C2（归因可代理）**：在 frozen VLM + 小 action head 上，便宜的梯度归因能在**方向上**预测 shard 的边际增益（符号正确优先于幅度正确）。
- **C3（能动性有边界）**：安全停持、实时异常检测必须在环内，不可摊销，留在 guard 栈。

**与 v1.1 的关系**：v1.1 回答「数据从哪来」，本轮回答「**谁来决定用哪些数据、用多少、何时停**」。I10 是编排层，I2/I5/I8/I9 是被它调度的工具。

## 2. 对 v1.1 痛点的增量修订

- P8（示教质量）→ **数据估值**：episode 质量分只是先验，真正看「加入/移除它对验证计分代理的边际影响」。
- 负迁移 → 「家族级 L0 消融」升级为「归因排序 + 小步重训确认 + 减法优先」；消融仍是终审，但不再盲测组合。
- P5（时间压力）→ I4 v2 把 chunk 边界对齐**决策点**（抓取/接触事件），只在真正需要重规划处重规划。
- P7（先手窗口）→ DCA 资产（归因表、数据集卡、失败图谱、代理-真机注册表）随轮次复利。
- 新增 **P9（代理-真机错配）**：DCA 优化离线代理；代理与计分弱相关时会「高效地优化错的东西」。
- 新增 **P10（数据捷径/污染）**：若 110 语料与 32 任务有场景/指令泄漏，模型学任务身份而非技能，泛化轴恰好惩罚这种捷径。

## 3. 研究问题（Q9–Q12；Q6–Q8 保留）

- **Q9（归因的最小充分统计量）**：TracIn / 影响函数 / 表征覆盖 / 短重训，哪种能以可接受成本预测 shard 的边际计分增益？需多少真机锚点校准符号与幅度？
- **Q10（数据操作策略）**：离散操作用 bandit、连续剂量用 BO、还是贪心归因？双预算（重训贵、真机稀缺）下的最优停止条件？
- **Q11（能动性摊销边界）**：哪些能力（纠错、检索、规划、课程）能摊销进数据/权重，哪些必须留在推理时？失效的可观测判据？
- **Q12（捷径检测与去偏）**：如何用反事实配对 + 线性探针 + 归因检测并移除「任务身份」捷径，使 5 条泛化轴不惩罚虚假相关？

## 4. 设计原则（新增 PR6）

- **PR6 能动性摊销律**：任何「智能体能力」优先在训练期用数据/权重摊销；只有延迟与合规允许、且数据无法覆盖时才留在推理时。与 PR2 互补：PR2 管「部署只有一个模型」，PR6 管「能动性尽量不进部署」。
- PR1–PR5 保留（第 2 轮 §4）。

## 6. 本轮最大风险

**一句话**：DCA 的全部收益押在「离线归因/代理能预测真机计分」上——若连符号都测不准（P9），它会用最省的算力高效放大负迁移；因此第一版只允许它在通过已知负迁移对的符号校验后做减法，禁止直接做增广放量。

# UniBot-V1 参赛创新点清单（第 3 轮 v1.2 · 智能体×数据集）

> 检索日期 2026-11-26 / 2026-11-27；承接 v1.1（I1–I9）。本轮新增 I10（数据智能体）、I11（特权仿真教师，探索）；深化 I1/I2/I4/I5/I8/I9；裁撤 I7 推理路径。清单只增改不重置。文中 H20–H24 是待核实假设，未当事实使用。

## 0. 创新点清单（每点：动机 / 与现有差异 / 技术可行性 / 资源 / 落地步骤 / 风险）

### I1 v3 考纲校准增广引擎 ★★★★★
- **动机**：5 条泛化轴公开但训练分布偏离（P2/F2）；BC 会抓捷径（P10）。
- **与现有差异**：v2 按官方考纲校准；v3 增加**反事实配对**去偏——同技能、不同背景/物体/指令的成对样本，让捷径特征失去预测力；增广剂量不再全轴均匀放量，而由 I10 按能力画像选择。
- **技术可行性**：高。反事实配对 = 用 I9 库检索相似技能片段 + 交换背景/物体（分割/inpainting）；单卡可跑。
- **所需资源**：1×24GB；考纲卡约 10 分钟×32。
- **落地步骤**：①32 张考纲卡；②配对挖掘与物理一致性过滤；③DCA 选轴/剂量；④L0 验证「去偏不伤标称」；⑤轴间交互 2 档析因。
- **风险**：配对物理不可行（遮挡/接触错误）→ 几何一致性过滤；去偏过度 → 标称性能门禁。

### I2 v3 数据引擎 3.0：归因加权 + Coreset ★★★★★
- **动机**：静态孪生表是语义猜测（负迁移风险）；算力有限；近邻重复与捷径浪费容量。
- **与现有差异**：①孪生表只作先验，最终权重由 I10 归因决定；②**子模 coreset** 选覆盖考纲分布的高价值片段，用更少数据多训几轮；③去重 + 反事实去偏；④**train-once, reweight-many**：缓存 frozen VLM 特征，只重训 action head。
- **技术可行性**：高（依赖 H20；若 action head 很大则退化为 shard 级梯度）。
- **所需资源**：1×24GB 起步；归因 2–6 GPU·h/轮（缓存特征）；数据 2–4TB。
- **落地步骤**：①特征缓存；②per-shard 梯度/影响分；③子模 coreset；④权重→短重训→L0；⑤注册表回填。
- **风险**：归因非平稳 → 每 N 次重训重算 + 多 checkpoint 集成；coreset 丢长尾 → 每任务至少 k 条 + 长尾配额。

### I3 接触族关键点视觉伺服回退 ★★★★（维持）
- 六要素同 v1.0/v1.1：通用 chunk 负责接近段、几何伺服负责接触段，同一 PolicyService 内混合推理（PR2 边界待确认，最大前提）；`ee` 控制空间 + per-step 调用天然支持；开放词汇检测零训练起步；触发滞回 + 低置信回退。
- 本轮补充：I11 的仿真特权接触标签可作为**训练期辅助监督**，为接触段提供第二条缓解；I3' 降级预案（辅助标签、推理纯端到端）保留。

### I4 v2 干预门控 + 决策点对齐 chunk ★★★★
- **动机**：误差累积与延迟都集中在抓取/接触时刻；固定 chunk 在关键时刻不可控。
- **与现有差异**：从示教挖掘**决策事件**（gripper 开合、EE 速度极小/方向反转、得分点里程碑），chunk 边界对齐到下一事件；稳定段用长 chunk（≤30），决策段用短 chunk（4–8）+ 重评估。与 I10 共用事件挖掘器。
- **技术可行性**：高；纯推理期调度，单模型，零额外训练。
- **所需资源**：1 人周工程。
- **落地步骤**：①事件挖掘器；②chunk 调度器；③L0 离线回放测延迟/动作一致性；④真机抽测。
- **风险**：事件误检导致频繁重规划 → 滞回 + 最小驻留；短 chunk 增加调用次数 → p99 门禁。

### I5 v3 非标称示教合成 + 失败图谱 ★★★★
- **动机**：数据全成功、无失败示教（P8）；步骤分是得分点制（F17）。
- **与现有差异**：v2 扰动重放/跨段缝合/WMA 续写 + 得分点过滤；v3 由**失败图谱**驱动——每个合成操作针对画像最弱轴；合成数据必须过 I10 归因门禁（正边际）才入训；新增「反事实失败对」（同起点成功 vs 偏离）教判别与恢复。
- **技术可行性**：中-高；以数据工程为主；里程碑检测器 = 轻量视觉分类器。
- **所需资源**：1×24GB；2 人周；检测器 1 GPU·日/族。
- **落地步骤**：①得分点逆向（H23）；②3 弱任务试点（PlugCharger/ZipUp/PourOutMedicine）；③失败图谱；④归因门禁；⑤LoRA 增量 + 单任务 A/B。
- **风险**：合成偏离分布失配 → 剂量从考纲卡采样；检测器误差污染标签 → 置信门控 + 5% 抽检。

### I6 确定性低延迟部署 ★★★★（维持）
- 六要素同 v1.1：共享 backend + 每端口独立队列与 episode 状态隔离、fp8/INT8、torch.compile/CUDA Graph、obs 预取、`image_resize`、断线重连 + 健康探针（PR4）。
- 本轮补充：DCA 只在开发期运行，**不进入提交运行时**；I4 决策点 chunk 的额外调用次数计入 p99 预算；目标仍 p99 < 40ms（15Hz 参照，F12）。

### I7 世界模型测试时前瞻 ✂（本轮裁撤）
- **裁撤理由**：4 步去噪 + H=30 已吃掉延迟余量，推理期 lookahead 收益不确定且难合规。
- **资产去向**：WMA-0 仿真模式转 I5 合成数据 / I11 仿真教师，不废弃。裁撤不等于否定，只退出计分路径。

### I8 v3 评测闭环 + 主动实验设计 ★★★★★
- **动机**：真机稀缺 + 组合爆炸（P7）；被动注册表只能事后校准。
- **与现有差异**：v2 是 L0/L1/L2 + 被动注册表；v3 变成**主动实验设计**——用代理均值/方差算 VOI，只把真机预算花在「高不确定 × 决策临界」的候选上；注册表同时训练代理（offline→online 映射），按指标分层维护可信度。
- **技术可行性**：高；VOI 是决策公式，不是新模型。
- **所需资源**：1 人周 + 表格/脚本。
- **落地步骤**：①多指标代理集成；②VOI 规则；③首批：I10 减法候选 vs 基线；④滚动校准 + ε 随机探索。
- **风险**：代理方差估计不准 → bootstrap/ensemble；VOI 过度自信 → 保留随机探索配额。

### I9 v2 reset 期检索类比 ★★★★
- **动机**：未见物品轴（同类不同外观）全面出现；纯参数泛化方差大。
- **与现有差异**：v1 检索「物体→动作参数」；v2 检索库带**归因价值**，检索目标从「最像物体」扩展为「最像且最有价值的技能段/恢复段」；支持 abstain；结果缓存于 episode。
- **技术可行性**：中-高；离线建库，reset 期 <1s，episode 内零额外每步开销。
- **所需资源**：1 GPU·日 + FAISS；1 人周。
- **落地步骤**：①物体/技能段库；②归因加权索引；③软先验注入；④阈值 abstain；⑤L0 + 真机抽测。
- **风险**：误检索伤标称 → 阈值 + 软偏置；嵌入对同类不同外观不敏感 → DINOv2 patch + 几何描述；合规确认（H22）。

### I10 数据智能体（DCA）★★★★★（新增，编排层）
- **动机**：v1.1 数据引擎开环，负迁移是最大风险，真机预算稀缺；需要一个**在双预算下决定数据操作**的离线智能体。
- **一句话定义**：DCA 是一个离线 MDP 策略——状态 = 能力画像 + 数据组成 + 剩余预算 + 代理不确定性；动作 = 数据操作；奖励 = 计分增益/成本；用归因做先验、bandit/BO 做决策、VOI 花真机预算。
- **与现有差异**：不是再加一个推理模块；是把「选数据/造数据/剪数据」从人工规则变成闭环策略。部署仍单模型，无在线学习。
- **技术可行性**：中-高。关键使能是 frozen VLM 特征缓存 + 小 action head 归因（H20）；train-once-reweight-many 让每个候选只需短重训。
- **所需资源**：1×24GB；2–3 人周工程；归因 2–6 GPU·h/轮；短重训 2–4 GPU·h/候选。
- **落地步骤**：①特征缓存 + per-shard 梯度；②已知负迁移对验符号（§2 E0）；③减法优先（剪 bottom-k）；④coreset + 课程；⑤VOI 接 I8；⑥数据集卡/失败图谱。
- **风险**：归因噪声/非平稳 → 符号优先 + 集成 + 定期重算；代理-真机错配（P9）→ 注册表校准 + 保守门禁；奖励黑客 → 动作空间约束 + 留出轴审计；算力 → 缓存 + 只训 action head。

### I11 特权仿真教师蒸馏 ★★★（新增，探索）
- **动机**：真机无深度/力触觉（F8/F20）；接触段（I3）缺监督；官方有 Isaac Lab 仿真（F14）。
- **与现有差异**：在仿真里训练一个**特权教师 agent**（可见物体位姿/接触力/深度），用它生成带特权标签的示教数据集；学生只吃 RGB+本体，用**非对称蒸馏**把教师特权信号作训练期辅助标签（接触预测/深度/物体位姿），推理时去掉辅助头。这是「教师 agent → 数据集 → 单模型学生」。
- **技术可行性**：中。仿真资产/任务需自建，sim-real gap 大；先做一个接触任务族（插拔/拉链）验证。
- **所需资源**：4–8×A100 生成；1 人月；仅当 I10 归因为正才放量。
- **落地步骤**：①1 个接触任务仿真资产；②特权教师（脚本/RL）；③带标签数据；④非对称蒸馏；⑤I10 归因门禁；⑥真机抽测。
- **风险**：sim-real gap → 域随机化 + 只取接触段；成本高 → 严格 gated；负迁移 → 归因不过即裁撤。

## 1. 关键形式化与伪代码

### 1.1 DCA-MDP 形式化

设数据由 m 个 shard 组成，权重 $w\in\mathbb{R}^m$，短重训得到 $\theta(w)$。能力画像为 32 任务 × 5 轴的赤字向量：

$$
d_{t,(i,k)} = J_{i,k}(\theta_t) - J_{i,k}(\theta_{\text{ref}}),
\quad J_{i,k}=\alpha\,\text{success}_{i,k}+(1-\alpha)\,\text{stepscore}_{i,k}.
$$

状态 $s_t=(d_t,w_t,u_t,b_t)$，其中 $u_t$ 是代理后验方差，$b_t=(B_{\text{train}},B_{\text{real}})$。动作 $a_t=(\text{op},i,\delta,w)$：

$$
\text{op}\in\{\text{keep},\text{drop},\text{up},\text{down},\text{dedupe},\text{synth}(k,\delta),\text{relabel},\text{reorder}\}.
$$

奖励与目标：

$$
r_t=\frac{\hat J(w_{t+1})-\hat J(w_t)}{\text{cost}(a_t)}-\lambda\,\text{risk}(a_t),
\qquad
\max_{\pi}\ \mathbb{E}\Big[\sum_{t=0}^{T-1}\gamma^t r_t\Big]
\ \text{s.t.}\ \sum_t \text{cost}(a_t)\le B.
$$

因为短重训昂贵，用注册表数据拟合代理 $\hat J(w)=f_\psi(\phi(w))$：离散操作用 Thompson/UCB bandit，连续剂量用 GP-BO（EI），归因给出未见操作的先验均值。

### 1.2 缓存特征上的数据归因（DCA 的引擎）

frozen VLM $\phi$ 只做一次前向并缓存 $f=\phi(\text{obs},\text{lang})$；动作头 $\varepsilon_\theta$ 的扩散去噪损失：

$$
L(\theta;z)=\mathbb{E}_{t,\epsilon}\big\|\epsilon-\varepsilon_\theta(a_t^z,t,f^z)\big\|^2 .
$$

验证集 $V$ 取「考纲增广后的留出集」，$\theta$ 只含 action head 参数：

$$
g_{\text{val}}=\nabla_\theta L_{\text{val}}(\theta),\qquad
g_i=\frac{1}{|B_i|}\sum_{z\in B_i}\nabla_\theta L(\theta;z).
$$

TracIn 一阶估值（单 checkpoint 版）与 Fisher 归一化影响：

$$
I_i=\eta\, g_{\text{val}}\cdot g_i,
\qquad
\tilde I_i=-\sum_k\frac{g_{\text{val},k}\,g_{i,k}}{F_k+\lambda}.
$$

符号约定：$I_i>0$ 表示该 shard 与验证梯度同向（有益），$I_i<0$ 表示有害（减法候选）。排序用余弦 $\cos(g_{\text{val}},g_i)$ 去规模偏置，幅度用原始内积。

```python
# 一次特征缓存，多轮归因：DCA 便宜的关键
feats = {shard: [phi(obs, lang) for (obs, lang) in sample(shard, K)] for shard in S}

def attribute(theta, val_feats, feats):
    g_val = grad(lambda: diffusion_loss(theta, val_feats))
    score = {}
    for shard, fs in feats.items():
        g_i = grad(lambda: diffusion_loss(theta, fs)) / len(fs)
        score[shard] = {
            "tracin": dot(g_val, g_i),
            "cos":    cosine(g_val, g_i),
            "sign":   +1 if dot(g_val, g_i) > 0 else -1,
        }
    return score
```

**校准（必须先做）**：取 top-k / bottom-k shard 各做一次短重训，计算 $\text{Spearman}(\tilde I_i,\Delta J_i)$ 与符号正确率；只有 $\rho\ge0.5$、符号正确率 $\ge0.7$ 才允许 DCA 用归因做减法。

### 1.3 减法优先 + 子模 Coreset

```python
def dca_step(theta, S, budget):
    d      = profile(theta)                  # L0 画像：32×5 赤字
    score  = attribute(theta, val_feats, feats)
    # C1：先减法，后增广
    drop   = [s for s in S if score[s]["sign"] < 0 and score[s]["cos"] < -TAU]
    S1     = S - set(drop)
    # 去重：近邻重复只留质量最高者
    S2     = dedupe(S1, emb=seg_emb, keep="max_quality")
    # coreset：覆盖考纲目标分布 + 归因正价值
    S3     = greedy_facility_location(
                 anchors=syllabus_anchors, items=S2,
                 weight=lambda j: quality[j] * max(0, 1 + score[j]["cos"]),
                 min_per_task=K, long_tail_quota=Q)
    return S3, {"dropped": drop, "reason": "subtract_first"}
```

子模目标（贪心有 $1-1/e$ 近似）：

$$
\max_{S,|S|\le K}\ \sum_{a\in A}\max_{j\in S}\ \text{sim}(a,e_j)\cdot q_j\cdot\max(0,1+\tilde I_j).
$$

### 1.4 VOI：把真机预算花在「最该测」的候选上

代理集成给出候选 $c$ 的 $(\mu_c,\sigma_c)$，当前最优为 $b$，$\Delta=\mu_c-\mu_b$，$\sigma^2=\sigma_c^2+\sigma_b^2$：

$$
\text{VOI}_c=\underbrace{\Delta\,\Phi\!\Big(\frac{\Delta}{\sigma}\Big)+\sigma\,\varphi\!\Big(\frac{\Delta}{\sigma}\Big)}_{\mathbb{E}[\max(0,J_c-J_b)]}-\text{cost}_{\text{real}}-\text{opportunity}.
$$

```python
def allocate_real(cands, budget_real, eps=0.1):
    voi = {c: expected_improvement(c) - real_cost(c) for c in cands}
    top = sorted(cands, key=voi.get, reverse=True)
    # 只测高 VOI 且代理分歧大的；保留 eps 随机探索
    query = [c for c in top if voi[c] > 0 and disagree(c) > TAU_U][:budget_real]
    query += random.sample(cands, k=int(eps * budget_real))
    return query
```

### 1.5 决策点对齐 chunk（I4 v2）

```python
def decision_points(traj):
    ev = []
    for t in range(1, len(traj)):
        if abs(traj[t].gripper - traj[t-1].gripper) > TAU_G:      # 开合
            ev.append(t)
        if speed(traj[t].ee) < TAU_V and turn(traj[t].ee, traj[t-1].ee):
            ev.append(t)                                          # 速度极小+转向
    ev += milestone_frames(traj)                                  # 得分点里程碑
    return sorted(set(ev))

def next_chunk_len(t, events, H_max=30, H_min=4):
    nxt = min([e for e in events if e > t], default=t + H_max)
    return H_min if nxt - t <= H_min else min(H_max, nxt - t)
```

## 2. 实验设计（先证归因，再谈收益）

| 编号 | 目的 | 级别 | 设计 | 通过判据 / 决策规则 |
|---|---|---|---|---|
| E0 | **归因符号校验（生死线）** | 离线 | 已知反向对 ≥4 组（ZipUp↔Unzip、PlugInEthernet↔Connect_The_Network_Port、DisconnectEthernet↔Connect 等）；预测 $I_i$ 符号 vs 短重训实测 $\Delta J$ | 符号正确 ≥3/4 且 Spearman≥0.5 → DCA 可做减法；否则 DCA 降级为纯人工规则，不进入主线 |
| E1 | 减法优先（C1） | L0 | 剪 bottom-10% by $\tilde I_i$；32 任务留出 + 考纲轴偏移 | ΔJ≥0 于 ≥28/32 任务，且弱任务轴有正增益；否则回 E0 查归因 |
| E2 | Coreset | L0 | 40% coreset vs 全量、等算力 | ΔJ_coreset ≥ ΔJ_full − ε，长尾任务不退化 |
| E3 | VOI 分配 | L1/L2 | VOI vs 随机 vs top-μ，同等真机次数 | VOI 的每查询增益 ≥ 其余两策略 |
| E4 | 决策点 chunk | L0/L2 | 接触/抓取任务，测 p99 与接触成功率 | p99 在预算内，接触成功率↑ |
| E5 | 去偏 | L0 | 反事实配对；任务身份线性探针准确率 | 探针准确率↓，未见轴 ΔJ↑，标称不降 |
| E6 | 仿真教师（I11） | L0 | 1 个接触任务族，带特权标签蒸馏 | I10 归因为正且真机抽测接触成功率↑；否则裁撤 |

**执行顺序**：E0 → E1（减法）→ E2（coreset）→ E3（VOI）→ E4 → E5 → E6。E0 不通过，I10 只保留「人工孪生表 + L0 消融」，不冒险放量。
