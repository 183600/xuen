# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 1 轮；本轮灵感：「移动操作」×「异常检测」）

> R69 教会系统「问」，但它默认提问者**站得住、看得全、测得准**：FMA 的异常通道本质上是「固定基座 + 单视点 + 全局正常流形」的产物。移动操作一上来就把这三个前提全部打破——**底盘一动，观测变化的第一大来源不是世界变了，而是我自己动了**；机械臂一伸，正常流形的形状取决于接触状态、抓取状态与重心；更根本的是，R69 只回答「哪个动作模态对」，却不回答「**这次意外是谁造成的**」：是里程计/标定坏了（self）、是滑了/没抓住（task）、还是世界真的变了（world）？三种归因要求三种完全不同的响应，而 R69 只有一种响应——收紧。
>
> 本轮两个灵感正好补上这两块：
> - **移动操作**说：自运动既是异常检测最大的混淆源，也是**免费的诊断资源**。底盘提供基线（baseline）、视差、跨视角冗余；「动一下再看」本身就是一个可执行的因果干预。会动的机器人不是一台固定相机，而是一台**可以主动改变观测条件的传感器阵列**。
> - **异常检测**说：「正常」不是一个全局密度阈值，而是**分层（stratum）条件化**的：步态相位、接触模式、操作阶段、抓取状态各自有不同的正常流形，异常更多表现为「不该发生的层间转移」与「自运动解释不了的残差」，而不是「离所有数据都远」。
>
> 核心命题：**把异常检测从「事后、单视点、全局阈值」升级为「自运动条件化、分层校准、主动归因、可恢复」的移动操作闭环**：EMN 先把自运动从观测变化里解释掉；SHM/SCC 在分层混合流形上给出逐层校准的异常证据；VAT 用移动带来的跨视角冗余否决单视点伪异常；AAT 用安全且可恢复的诊断动作对 self/task/world 做主动归因；VRS 保证「停下来」本身不会把系统带进不可恢复区。命名 **STRIDE-RAS**（**S**tratified **T**ask-relevant **R**eachability-aware **I**ntervention-based **D**iagnostic **E**stimation）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**这次异常是谁造成的、我该动到哪儿去确认、动过去之后我还回得来吗**」——异常不是一声警报，而是一条需要被归因、被验证、且必须保留退路的因果假设。

## 0. 直觉与动机

**灵感 1（移动操作 → 自运动是混淆源，也是诊断资源）**
直觉：固定基座机器人看到画面变了，基本可以怀疑世界；移动机器人看到画面变了，第一反应必须是「我刚才是不是在动」。传统做法靠里程计做 ego-motion compensation，但里程计本身可能坏、深度可能噪声大、动态物体又混在其中。STRIDE 的姿态是：**不把自运动当成要消除的麻烦，而把它当成实验变量**。同一静态世界点在两个不同底盘位姿下的成像必须满足对极几何与深度一致性；一条只在某个速度/视角下出现的「异常」，更可能是自运动伪影；一条在跨视角下始终存在、且无法被任何合理自运动解释的残差，才更像世界异常。移动因此同时提供两样东西：**一个需要被条件化的混淆因子**，和**一组可以主动采集的对照观测**。

**灵感 2（异常检测 → 正常流形是分层的，不是一团的）**
直觉：把机器人所有数据塞进一个自编码器算重构误差，是把「走路时腿挡住相机」「抓取瞬间接触力突变」「转弯时视觉流爆表」全判成异常。移动操作天然是**混合动力系统**：支撑/摆动、自由/接触、接近/抓取/搬运/放置、稳固抓取/滑动。正常不是一个分布，而是**一族按层（stratum）索引的分布**，外加一个**允许的层间转移文法**。于是异常至少有两类：层内残差异常（连续的、manner anomaly）与层间转移异常（离散的、transition anomaly，例如「自由空间里突然出现接触」「稳固抓取却无外力地滑移」）。把二者混成一个标量，会同时损失灵敏度与可解释性。

**灵感 3（校准 → 全局阈值在非平稳下必然失效，必须逐层 conformal）**
直觉：R69 用 ECE 管模态权重，但异常分数的阈值仍是全局的。移动操作里各层的基础分数分布差异巨大（站立 vs 行走、自由 vs 接触），全局阈值要么对某层过于敏感，要么对某层完全失明。正确做法是 **Mondrian/分层 conformal**：在每层内部分别校准 p 值，样本不足时向父层回退并付惩罚。这样给出的不是「一个可疑分数」，而是「在当前层下，这个观测有多不像正常」——一个**有条件的、可证伪的**统计陈述。

**灵感 4（归因 → 异常是一个因果假设，不是一个标量）**
直觉：R69 的主动交互只用于「选哪个动作模态」。但移动操作里，异常之后真正决定生死的是**归因**：若是 self（标定/里程计/传感器故障），正确响应是降级感知、换通道、慢下来；若是 task（滑移、抓空、碰撞），正确响应是重抓、回退、局部重规划；若是 world（家具被移动、有人闯入、地面变滑），正确响应是停止任务、退到安全视点、重新建图或求助。把三者当同一个「异常」处理，就会用换传感器的办法去处理滑倒，或用重抓的办法去处理一个移动了的人。AAT 把 R69 的 VoI 从「模态身份」升级为「**因果归因**」：选择诊断动作，使 self/task/world 的后验期望熵最小；并且**单次诊断不得定案**（继承 R69 证据纪律）。

**灵感 5（移动性 → 诊断动作有代价、有风险、可能不可恢复）**
直觉：R68/R69 的保守退路是「收紧/减速」，这在固定基座上通常安全；但移动操作里「停下」可能是最危险的动作：坡上急停可能失稳，伸着手臂刹车会让重心前移，贴边停车可能失去退路。更阴险的是，为了看清异常而把底盘开近、把手臂伸向可疑物体，**可能把系统带进不可恢复区**。所以 STRIDE 必须把「诊断」和「可恢复性」绑在一起：诊断动作必须先通过**生存核（viability kernel）**的可容许性检查，回退策略不是「最小速度」，而是「最大化可恢复裕度」。这也正面回应一个 R69 没覆盖的攻击面：**诊断陷阱**——对手制造一个异常，把机器人诱到危险视点。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（STRIDE-RAS 总览）** STRIDE-RAS = (EMN, SHM, SCC, VAT, AAT, VRS, ACR, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **自运动条件化**：任何异常证据必须报告其成立所条件的 (ν_t, s_t)，全局无条件阈值不得单独触发高影响动作；
(iii) **归因纪律**：单个异常分数、单次诊断动作、单视点证据均不得单独定案；高危响应需至少两个正交证据源一致，或归因后验超过高置信阈值；
(iv) **可恢复性优先**：诊断与回退动作必须落在生存核 K_ε 内，且优先增大可恢复裕度 ρ，而不是单纯减小速度。

**定义 311（移动操作状态与混合层）** 状态 x_t = (p_t ∈ SE(3), q_t ∈ Q_arm, ν_t ∈ se(3), C_t, g_t)，其中 C_t 为接触集、g_t 为抓取状态。全身动作 u_t = (u_base, u_arm) ∈ 𝒰，满足非完整约束 A(p_t)ν_t = 0、平衡约束与关节/碰撞约束。层变量 s_t = (c_t, m_t, g_t)：c_t ∈ 𝒞 为运动/接触模式（站立、行走、转向、支撑），m_t ∈ ℳ 为操作阶段（接近、伸展、抓取、搬运、放置），g_t ∈ 𝒢 为抓取状态（free / firm / slip）。层间转移由混合自动机文法 T ⊆ S×S 给出；不允许的转移记 F = (S×S) \ T。

**定义 312（自运动条件化正常流形 EMN）** 给定深度 D_t、本体感觉 ν_t 与前一帧 o_{t-1}，静态世界下的期望视觉流为 Φ_static(D_t, ν_t)。观测流 Φ_obs = Flow(o_{t-1}, o_t)。定义**自运动解释残差**
r_mot = min_{ν' ∈ B(ν_t, ε_ν)} ‖Φ_obs − Φ_static(D_t, ν') − Φ_task‖，
其中 Φ_task 为可由已知任务动作解释的物体运动，B 为里程计置信球。正常流形
ℳ_{ν,s} = { o : r_mot ≤ τ_mot(s), warp(o_{t-1}, o_t; D, ν) ≤ τ_view(s) }。
异常分数 a_emn(o_t) = dist(o_t, ℳ_{ν_t,s_t})，且必须随附条件 (ν_t, s_t)。

**定义 313（异常三元组）** 归因假设 h ∈ ℋ = {h_self, h_task, h_world}：
- h_self：传感器/标定/里程计/编码器故障，或自运动模型失配；
- h_task：抓取失败、滑移、碰撞、接触方式错误、操作阶段错位；
- h_world：物体被移动、遮挡变化、地面属性变化、动态人/对手介入。
证据 e = (a_cont, a_trans, a_emn, W, u_history)。异常不是一个标量，而是后验 p(h | e)（定义 318）。

**定义 314（分层混合正常模型 SHM）** 层内连续异常 a_cont = −log p_θ(o_t, ξ_t | s_t, z_t)；层间转移异常 a_trans = −log p_φ(s_{t+1} | s_t, u_t)；禁止转移质量 π_forbid = Σ_{s'∈F(s)} p_φ(s' | s, u_t)。a_cont 与 a_trans 分通道进入证据，不做简单加和：前者说明「做得像不像」，后者说明「该不该走到这一步」。

**定义 315（跨视角一致性 VAT）** 对两个不同底盘位姿 i, j（基线 b_ij）与同一静态世界假设，warp 后的光度/深度一致性为
c_ij = exp(−‖o_i − warp_{i→j}(o_j; D_j, T_ij)‖² / 2σ²)。
定义视角证据 W = { (i, j, c_ij, b_ij) }。若异常只在单视点出现（∃ 视角使其消失），判为 h_self 候选；若在 ≥2 个具有正基线的独立视角下持续存在，判为 h_world 候选。b_ij 越大，对深度歧义与里程计误差的条件化越强（引理 19）。

**定义 316（任务相关异常）** 令 R_task(x_t, H) 为任务策略在 H 步内可达的状态/区域，consequence(·) 为任务后果权重。任务相关异常
a_rel = a_anom · w(x),  w(x) = E_{x'∼reach(x_t,H)}[consequence(x')]。
远处与任务无关的异常被降权，避免移动操作在大场景中的告警洪水；但安全问题不因「当前任务不关心」而被完全屏蔽（保留一个与任务无关的硬阈值通道）。

**定义 317（分层 conformal 校准 SCC）** 每层 s 维护校准分数集 𝒟_s。测试分数 a 的分层 p 值
p_s(a) = (1 + #{a' ∈ 𝒟_s : a' ≥ a}) / (|𝒟_s| + 1)。
若 |𝒟_s| < n_min，向父层 s↑ 回退并施加惩罚 κ_s，得到 p_s = min(1, p_{s↑} + κ_s)。告警条件为 p_s ≤ α_s，其中 α_s 为层内可接受误报率。全局阈值只是所有层共享同一 α 且忽略条件化的退化情形。

**定义 318（主动异常归因 AAT）** 诊断动作空间 𝒢_diag = { 平移/侧移以获得视差、绕看、换步态、重抓、轻触/ palpation、暂停、退到安全视点 }。对候选 g，期望信息增益
IG(g) = H(h | e) − E_{y∼p(·|g,e)}[H(h | e, y)]。
选择 g* = argmax_g [IG(g) − c(g) − risk(g)]，s.t. g 通过 VRS 可容许性检查、预算未超、且不属于 F 中的危险转移。若 max[IG − c − risk] ≤ 0：不诊断，直接进入归因保守响应。一次诊断只更新后验，不单独定案（继承定义 293-iii）。

**定义 319（生存核与可恢复裕度 VRS）** 安全状态集 X_safe 由平衡、非完整、关节、碰撞、可达与任务时限共同定义。生存核
K = { x ∈ X_safe : ∃π, ∀t≥0, x_t ∈ X_safe }，K_ε 为其 ε-内缩。
可恢复裕度 ρ(x) = dist(x, ∂K)（或等价的「保持安全的最长可行时域」）。动作 g 可容许 ⇔ 执行 g 并随后执行恢复策略 π_rec 后，x' ∈ K_ε 且 ρ(x') ≥ ρ_min。**「急停」只是 g 的一个候选，不天然可容许**。

**定义 320（可恢复性感知回退与响应文法 SRG）** 响应文法把归因后验映射到动作模式：
h_self → 降级感知/切换通道/收回手臂/降速，保留最小任务能力；
h_task → 重抓/局部重试/回退到上一个稳定层；
h_world → 中止任务、退到安全视点、重建局部地图、必要时求助；
h_unknown（后验不集中或预算耗尽）→ 执行最大化 ρ 的「护住—收回—后撤」动作并告警。
回退动作 a_fb = argmax_{a ∈ 𝒰_safe} [ ρ(x_{t+1}(a)) + β·任务保底(a) ]，而不是 argmin 速度。R68/R69 的「收紧」是其在固定基座、ρ 对减速单调时的特例（定理 18）。

**定义 321（异常感知风险缩放）** 风险尺度
λ_anom = λ_floor(U_ale + U_epi) · (1 + γ·â_cal)，
其中 â_cal 为经 SCC 校准后的异常强度（截断到 [0,1]）。当 â_cal 高且归因为 h_world 时，进一步冻结任务动作、只允许诊断/回退动作；当 â_cal 高但归因为 h_self 时，切换到本体感觉优先的降级策略。任何情况下 λ_anom ≥ λ_floor，安全侧不因异常检测而放松。

**定义 322（干预不变异常守卫 IIAG）** 设 do(g) 为执行诊断动作后的观测分布。定义：
- 若异常在「空干预」下消失（同一任务、仅改变视点/速度，且不改变接触），判为自运动伪影候选；
- 若异常在多个空干预下持续、且跨视角一致，判为世界异常候选；
- 若异常在「接触干预」下才出现或消失，判为任务异常候选。
形式化地，比较 a_anom(o | do(g_null))、a_anom(o | do(g_contact)) 与先验异常的对数似然比；归因要求该似然比在至少两个独立干预方向上方向一致，避免把诊断动作自身诱发的变化误判为世界变化。

**定义 323（异常预算与分诊）** 每个异常事件最多 B_a 次诊断动作、每分钟最多 B_t 次；对每层维护 SPRT/CUSUM 统计量区分瞬态与持续异常。预算耗尽或后验仍不集中 ⇒ 不得无限追问，转入 h_unknown 回退并交接。该约束同时抵抗「异常农场」攻击（对手反复制造异常耗尽预算）。

**定义 324（异常证书 ACR）** J_STRIDE = ( J_FLUID, emn_version, s_t, a_cont, a_trans, a_emn, p_s, W_hash, p(h|e), ρ_min, budget_used, expire_at, aic_mobile_version )。Valid ⇔ Valid(J_FLUID) ∧ p_s ≤ α_s ∧ |W| ≥ 2 且含正基线 ∧ 归因秩条件满足（引理 21） ∧ ρ ≥ ρ_min ∧ 未过期。证书是**有条件的、会过期的**：环境漂移超过 δ 或层分布漂移检测触发即失效，必须重测。

**定义 325（移动操作威胁模型 ℰ_mobile）** 对抗贴片/伪装物体、伪造里程计、重放/时延、动态人/遮挡攻击、致滑地面、异常农场（反复触发告警耗尽预算）、诊断陷阱（用异常把机器人诱到危险视点或不可恢复区）、自诱发异常（诊断动作自己制造异常）。并入 AIC：ℰ_STRIDE = ℰ_FLUID × ℰ_mobile × ℰ_attr（归因错误：自因/任务因/世界因混淆）。

**定义 326（STRIDE-RAS 主闭环与严格包含）** 主闭环为「EMN 残差 → SHM/SCC 分层证据 → VAT 视角纪律 → AAT 主动归因 → SRG/VRS 响应 → ACR 证书」。当底盘固定（u_base≡0）、单视点、单层、关闭诊断动作时，STRIDE 逐指令退化为 R69 的 FLUID 闭环（定理 18）。安全侧不做让步，新增的只是「更准的异常」与「更可恢复的退路」。

class EgoMotionNormalizer:
    def residual(self, o_prev, o_t, nu, s):
        D  = self.depth(o_prev)
        f  = self.flow(o_prev, o_t)
        # 在里程计置信球内取「最利于解释」的 nu'：抵消里程计小偏差

    return W

# IP-268 AAT：把「问哪个模态」升级为「异常是谁造成的」
def attribute_and_triage(e, s, budget, vrs):
    if e.p_s > ALPHA[s] or not view_ok(e.W):       # 不显著或单视点
        return Attribution.UNKNOWN, None
    post = bayes_attribution(e)                    # self / task / world
    if max(post) > TAU_ATTR:                       # 证据已足够集中
        return argmax(post), None
    best = None
    for g in diagnostic_primitives(s):             # 平移/绕看/重抓/轻触/等待
        if not budget.allow(g) or not vrs.admissible(g): continue
        score = expected_ig(post, g) - cost(g) - risk(g)
        if best is None or score > best.score: best = (g, score)
    return Attribution.UNKNOWN, (best[0] if best and best.score > 0 else None)

# IP-269/270 VRS + SRG：可恢复性优先的回退
def recoverable_response(post, x, u_safe, rho):
    if post.concentrated:                          # 归因明确 → 对症下药
        mode = GRAMMAR[argmax(post)]               # 降级 / 重抓 / 后撤求助
    else:
        mode = 'BRACE_AND_ALERT'                   # 不赌归因
    a_fb = max(u_safe, key=lambda a: rho(next_state(x, a)) + BETA*task_floor(a))
    return mode, a_fb                              # 注意：不是 min-speed

# IP-274 主闭环（在 R69 FLUID 闭环上插入移动异常层）
def STRIDE_RAS_round(M, obs):
    x, nu, s_prev = M.state.update(obs)
    z, o = M.mtm.forward(obs)                      # R69 一次前向
    s = M.shm.infer(z, o, x, s_prev)               # 复用策略特征，廉价分层
    e = stratified_evidence(o, M.last_action, s, s, z, M.emn)
    e.W = M.vat.view_witness(obs, M.pose_buffer)
    post, g = M.aat.attribute_and_triage(e, s, M.budget, M.vrs)
    if g is not None:                              # 主动诊断：先保证回得来
        e = M.aat.update(e, M.aat.execute(g))
        post = M.attr.posterior(e)
    if e.p_s <= ALPHA[s] and M.vat.world_consistent(e.W):
        # 异常显著且跨视角一致：进入异常响应，不直接跑任务
        mode, a_fb = M.srg.recoverable_response(post, x, M.safe_actions, M.vrs.rho)
        k = M.c_ras_wm.certified_prefix(a_fb, ..., wm_preds)
        M.vqa_m.submit_async(e, post, mode, a_fb)
        return k, mode, e, post
    # 否则走 R69 原路径（异常层只收紧、不放松）
    lam = max(M.efs.risk_scale(...), M.srg.lam_anom(e))
    ...                                            # 与 R69 相同的模态选择与认证
    M.vqa_m.submit_async(e, post, 'NORMAL', None)
    return k, lam, mode, e

## 3. 推导

**引理 19（视差条件化与自运动分离）** 设世界静态、匹配噪声方差 σ²。在两视角 (i,j) 上对自运动 ν 做最大似然拟合，H0（静态世界）下残差只含噪声且 ν 的可辨识性随基线 b_ij 增大而增强；H1（世界变化 δX）下，变化在像平面的投影位移随 b_ij 放大。故判别信噪比满足
SNR(b) ≳ c·b·‖δX‖ / (D²σ)，
即**基线越长，越能把「世界变了」从「我自己动了 + 噪声」里分离出来**。系：移动操作的自运动不是纯负担——在安全前提下主动制造基线，是异常归因的物理基础；固定基座是 b=0 的退化情形（此时只能靠时间基线，分离能力最弱）。

**引理 20（分层 conformal 的条件有效性）** 若每层 s 的校准分数与测试分数在 p(·|s) 下可交换，则 P(p_s ≤ α_s) ≤ α_s，即层内误报受控；当测试分布发生层内漂移且 TV(p_test, p_cal) = δ_s 时，覆盖率退化为 ≥ 1 − α_s − δ_s。若错误地使用全局阈值，则层间分数分布差异会使某些层的实际误报率偏离名义值，偏离量由层权重与各层分数分布的全变差上界给出。系：**非平稳下，全局阈值不是一个「统一标准」，而是一个「随层漂移的随机标准」**。

**引理 21（归因可辨识性）** 设诊断干预 g 对假设 h 的期望证据变化为签名向量 S_{g,h} ∈ ℝ^d，构造设计矩阵 S ∈ ℝ^{m×3}（m 个独立干预，3 个假设）。在加性有界噪声下，若 rank(S) = 3，则归因后验可由最小二乘一致估计，误差 ≤ σ‖S⁺‖；若存在 h≠h' 使 S_{·,h} 与 S_{·,h'} 共线，则任何单次干预都无法区分二者，必须增加一个与其正交的干预。系：**「看/问/触」不是越多越好，而是要覆盖假设空间的秩**；单次诊断永远只提供似然、不单独定案（与 R69 证据纪律同构）。

**引理 22（可恢复性回退的安全性）** 若 x_0 ∈ K_ε，且回退策略每一步都选取使 ρ 不降的动作并满足 x_{t+1} ∈ K_ε，则对所有 t 有 x_t ∈ X_safe，且异常本身不能把系统推出可行域。反之，「最小速度/急停」不保证可行：在斜坡、贴边、手臂外伸等构型下，急停引起的重心前移或轮胎再分布可使 x_{t+1} ∉ K。故**减速是手段，不是安全定义**；安全定义是生存核内的递归可行性。

**定理 18（STRIDE 严格包含 R69/R68）** 当 u_base ≡ 0、单视点（无正基线）、单层（|S|=1）、关闭诊断动作且归因强制为 h_world 时，EMN 的条件退化为 R69 的固定基座异常通道，SCC 退化为全局阈值，VRS 退化为「λ 单调收紧」，STRIDE 与 R69 在安全通道上逐指令相同。因此 STRIDE 是 R69 在「移动 + 分层 + 主动归因」方向的严格泛化：新增能力只在证据支持时启用，安全侧不弱于 R69。

**定理 19（异常感知闭环安全上界）** 在 A99–A102（分层 conformal 有效、跨视角纪律、归因秩条件、生存核回退）下，单步内因异常未被检出、被误归因、或被诊断动作诱发而执行不安全任务动作的概率满足
P(unsafe) ≤ α_s + β_single + δ_attr + δ_diag，
其中 α_s 为层内误报/漏报预算，β_single 为单视点伪异常被纪律拦截后的残余，δ_attr 为归因误差（引理 21），δ_diag 为诊断动作超出可容许集后的残余（按定义 319 为 0）。且任何单次异常分数、单视点证据或单次诊断都不能单独触发高影响动作。系：异常检测的收益不是「更早报警」，而是**把不确定性转成一条有归因、有退路、可审计的行动**。

## 6. 本轮最大风险

**一句话**：STRIDE 的全部收益押在「自运动可以被解释、且诊断动作既安全又可恢复」这一前提上——**若深度/里程计误差与动态物体造成「运动混叠」，自运动残差会把正常运动误判为世界异常；更危险的是，为了看清异常而主动移动/伸手，可能把系统带进不可恢复区，于是「诊断」本身成为事故原因**。一旦归因错误，系统会为了看清危险而驶入危险，或为了消除伪异常而放弃真正该做的保守动作。

**次级风险与缓解**：
1. **运动混叠/视差歧义**（低纹理、透明/反光、动态人）→ 引理 19 的置信球 + 跨视角纪律 + 深度不确定性显式进入残差；
2. **分层样本不足**（新场景某层无校准数据）→ 分层回退 + 惩罚 κ_s + 证书拒绝在未校准层签发；
3. **归因秩不足/单次诊断定案** → 引理 21 秩条件 + 单次只更新后验 + 证据纪律；
4. **诊断动作越界/诊断陷阱** → VRS 可容许性 + 诊断动作过 C-RAS-WM 认证 + E307 对抗评估；
5. **异常农场与预算耗尽** → SPRT/CUSUM 分诊 + 硬预算 + h_unknown 回退与交接；
6. **证书过期/漂移** → ACR 显式 expire_at + 漂移检测触发重测，不允许过期证书继续放行。

## 2. 形式化定义（要点版）

**定义 310–311（总览与混合层）** 四不变式：实时零学习写；自运动条件化；归因纪律（单分数/单动作/单视点不得定案）；可恢复性优先。层变量 `s=(c,m,g)`，层间转移受文法 `T` 约束。

**定义 312（EMN）** `r_mot = min_{ν'∈B(ν,ε)} ‖Φ_obs − Φ_static(D,ν') − Φ_task‖`；正常流形 `ℳ_{ν,s}` 条件于自运动与层；`a_emn = dist(o,ℳ_{ν,s})`。

**定义 313–314（异常三元组与 SHM）** 归因 `h∈{self,task,world}`；`a_cont=−log p(o,ξ|s)`，`a_trans=−log p(s'|s,u)`；禁止转移质量 `π_forbid`；连续/离散分通道。

**定义 315–316（VAT 与任务相关）** 正基线跨视角一致性 `c_ij`；单视点异常 → self 候选，≥2 独立视角持续 → world 候选；`a_rel=a·w(x)` 用可达/后果加权，避免告警洪水。

**定义 317（SCC）** 分层 p 值 `p_s=(1+#{a'≥a})/(|𝒟_s|+1)`；样本不足回退父层并加 `κ_s`；`p_s≤α_s` 才告警。

**定义 318（AAT）** `g*=argmax[IG(g)−c(g)−risk(g)]`，s.t. VRS 可容许、预算未超、不触发禁止转移；无正收益则不诊断。

**定义 319–320（VRS/SRG）** 生存核 `K` 与裕度 `ρ`；动作可容许 ⇔ 执行后 `x'∈K_ε ∧ ρ≥ρ_min`；回退 `argmax[ρ+β·任务保底]`，不是 argmin 速度；按归因选择降级/重抓/后撤/求助。

**定义 321（异常风险缩放）** `λ_anom=λ_floor(U_ale+U_epi)·(1+γ·â_cal) ≥ λ_floor`；`h_world` 冻结任务只留诊断/回退，`h_self` 切本体感觉优先降级。

**定义 322–323（IIAG 与预算）** 空干预 vs 接触干预的似然比方向一致才归因；每事件 `B_a`、每分钟 `B_t` 次诊断硬预算；SPRT/CUSUM 区分瞬态/持续；预算耗尽转 `h_unknown` 回退交接。

**定义 324–325（ACR 与威胁）** 证书含层/条件/视角见证/归因后验/裕度/过期时间；`ε_STRIDE = ε_FLUID × ε_mobile × ε_attr`（伪造里程计、异常农场、诊断陷阱、自诱发异常、归因混淆）。

**定义 326（主闭环与包含）** `u_base≡0`、单视点、单层、关闭诊断时逐指令退化为 R69。

# IP-264 EMN：自运动条件化残差（在里程计置信球内取最优解释）
class EgoMotionNormalizer:
    def residual(self, o_prev, o_t, nu, s):
        D = self.depth(o_prev); f = self.flow(o_prev, o_t)
        return min_norm(f - static_flow(D, nu_p) - self.task_flow(s)
                        for nu_p in ball(nu, EPS_NU))

# IP-265/266 SHM + SCC：分层证据与分层 p 值
def stratified_evidence(o, xi, s, s_next, z, emn):
    a_cont  = -log p_cond(o, xi | s, z)
    a_trans = -log p_trans(s_next | s, xi)
    a_emn   = emn.residual(o.prev, o, xi.nu, s)
    return (a_cont, a_trans, a_emn,
            conformal.p_value((a_cont, a_trans, a_emn), s))

# IP-267 VAT：单视点异常不得升级
def view_witness(obs, poses):
    return [(i, j, photo_warp_consistency(obs[i], obs[j]), baseline(poses[i], poses[j]))
            for i, j in pairs(obs) if baseline(poses[i], poses[j]) > B_MIN]

# IP-268 AAT：对 self/task/world 做主动归因
def attribute_and_triage(e, s, budget, vrs):
    if e.p_s > ALPHA[s] or not view_ok(e.W): return UNKNOWN, None
    post = bayes_attribution(e)
    if max(post) > TAU_ATTR: return argmax(post), None
    best = None
    for g in diagnostic_primitives(s):
        if not budget.allow(g) or not vrs.admissible(g): continue
        score = expected_ig(post, g) - cost(g) - risk(g)
        if best is None or score > best.score: best = (g, score)
    return UNKNOWN, (best[0] if best and best.score > 0 else None)

# IP-269/270 VRS + SRG：可恢复性优先，而非最小速度
def recoverable_response(post, x, u_safe, rho):
    mode = GRAMMAR[argmax(post)] if post.concentrated else 'BRACE_AND_ALERT'
    a_fb = max(u_safe, key=lambda a: rho(next_state(x, a)) + BETA * task_floor(a))
    return mode, a_fb

# IP-274 主闭环（R69 之上插入移动异常层）
def STRIDE_RAS_round(M, obs):

        return k, mode, e, post
    lam = max(M.efs.risk_scale(...), M.srg.lam_anom(e))   # 只收紧，不放松

## 4. 推导

**引理 19（视差条件化与自运动分离）** 静态世界下残差只含噪声，且 ν 的可辨识性随基线 `b` 增强；世界变化 δX 的像平面投影位移随 `b` 放大，故 `SNR(b) ≳ c·b·‖δX‖/(D²σ)`。系：主动制造基线是异常归因的物理基础，固定基座 `b=0` 是最弱情形。

**引理 20（分层 conformal 条件有效性）** 层内可交换 ⇒ `P(p_s≤α_s)≤α_s`；层内漂移 `TV=δ_s` 时覆盖率退化为 `≥1−α_s−δ_s`；全局阈值则给出随层漂移的「随机标准」。系：非平稳下必须逐层校准。

**引理 21（归因可辨识性）** 签名矩阵 `S∈ℝ^{m×3}`，若 `rank(S)=3` 则后验一致估计、误差 `≤σ‖S⁺‖`；若两假设签名共线，任何单次干预都无法区分，必须增加正交干预。系：诊断动作要覆盖假设空间的秩；单次诊断不定案。

**引理 22（可恢复性回退安全性）** `x_0∈K_ε` 且每步取 `ρ` 不降的动作并保持 `x'∈K_ε`，则恒在 `X_safe`；急停在斜坡/贴边/手臂外伸时可使 `x'∉K`。故减速是手段，安全定义是生存核内的递归可行性。

**定理 18（STRIDE 严格包含 R69/R68）** `u_base≡0`、单视点、单层、关闭诊断、归因强制 world 时，EMN 退化为 R69 固定基座异常通道，SCC 退化为全局阈值，VRS 退化为单调收紧，安全通道逐指令相同。R69 是 STRIDE 的「不动、不看、不分层」边界。

**定理 19（异常感知闭环安全上界）** A99–A102 下，`P(unsafe) ≤ α_s + β_single + δ_attr + δ_diag`（`δ_diag=0` 由 VRS 保证）；任何单次异常分数、单视点证据或单次诊断都不能单独触发高影响动作。系：异常检测的收益不是更早报警，而是把不确定性转成有归因、有退路、可审计的行动。

## 7. 本轮最大风险

**一句话**：STRIDE 的全部收益押在「自运动可以被解释、且诊断动作既安全又可恢复」这一前提上——**若深度/里程计误差与动态物体造成「运动混叠」，自运动残差会把正常运动误判为世界异常；更危险的是，为了看清异常而主动移动/伸手，可能把系统带进不可恢复区，于是「诊断」本身成为事故原因**。一旦归因错误，系统会为了看清危险而驶入危险，或为了消除伪异常而放弃真正该做的保守动作。

**次级风险与缓解**：运动混叠/视差歧义（置信球 + 跨视角纪律 + 深度不确定性入残差）；分层样本不足（父层回退 + κ_s 惩罚 + 未校准层拒签证书）；归因秩不足（引理 21 秩条件 + 单次诊断只更新后验）；诊断越界/诊断陷阱（VRS + C-RAS-WM 认证 + E307）；异常农场/预算耗尽（SPRT/CUSUM + 硬预算 + h_unknown 交接）；证书过期/漂移（ACR 显式 expires_at + 漂移触发重测）。
