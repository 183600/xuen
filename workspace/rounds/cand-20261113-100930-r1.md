# 第 66 轮（承接第 65 轮「VISTA 视觉知情安全时序归因」IP-214~223；新一轮灵感循环第 1 轮；本轮灵感：「激光雷达」×「基线复现」）

> 第 65 轮把「几何可证伪」升级为「故障可归因」，其自述的最大风险一针见血：**归因能力依赖「故障属于有限假设集、且视觉与几何的失效相互独立」；真实故障常是未知类型的组合，透明/镜面/对抗 patch 会让视觉与几何共享同一个分布外失效源，FIR 会把未知复合故障强行归入最近假设、只膨胀错误的球——而且系统会因为「已经归因」而更自信地继续执行。** 本轮不增加第 7 个故障假设，而是换一个更接近计量学的问题：第 65 轮问「**谁坏了**」，BRIDGE 问「**产生这张证书的仪器，还是当初被认证的那台仪器吗？它的基线还能被复现吗？**」本轮核心命题是：
>
> **把「故障归因」升级为「基线可复现的计量溯源」：用激光雷达的主动测量与物理基线提供结构不同的几何见证，用「基线三元组」把安全证书变成可在线复现、可审计的条件承诺，用 e-value 开放世界检验替代有限假设集的强行归因，用共失效矩阵替代「视觉与几何独立」的隐藏假设。归因可以错，基线不能假。**

## 0. 直觉与动机

**灵感 1（激光雷达 → 不是一个新模态，而是一台有物理基线的主动仪器）**
直觉：第 65 轮把 LiDAR 当作 LSF 的几何输入，只用了点云。但 LiDAR 真正特殊的不是「又一种深度」，而是**主动测量 + 物理基线**：它自己发光、自己计时；回波强度、多次回波、测距噪声、运动畸变都是仪器状态的一部分；它和相机之间有一个物理杠杆臂 `b`（外参基线），和机械臂之间也有安装基线。透明、镜面、逆反射、黑色、掠射角会让 LiDAR 以**与相机不同的方式**失效——这正是第 65 轮共因故障的解药，但**它不是真值**：镜子会让它收不到回波，逆反射会让它饱和，透明物可能直接漏检。因此 LiDAR 是「**结构不同的可错见证**」，不是新的接地真值。

**灵感 2（基线复现 → 基线不是论文里的一个数，而是安全证书的运行时前提）**
直觉：「基线」在这轮有三个不可分的含义：(i) **几何基线** `b_geo`——传感器之间的杠杆臂、外参、时间偏移；(ii) **统计基线** `b_stat`——健康残差分布，即 null；(iii) **实验基线** `b_exp`——锚点、种子、硬件指纹、代码与评估协议。第 65 轮的 conformal 覆盖与故障先验都默默假设这三条基线不变，但真实部署会因温度、振动、碰撞、固件、灰尘、换传感器而漂移。于是「复现」不是论文里的复现实验，而是**运行时的复现检验**：任何证书只在「基线三元组仍被复现」时有效。这把「可复现性」从元要求变成安全链的一等公民。

**灵感 3（基线 → 可观测性：没有杠杆臂，就没有漂移可辨识性）**
直觉：这是本轮最硬的数学直觉。两个共址传感器（基线 `b=0`）之间的相对旋转误差，无法从对应点位移中看出来，因为旋转不产生杠杆臂位移；深度与基线尺度也会互相混淆。也就是说，**漂移不是「有没有发生」，而是「当前观测几何是否让它可观测」**。这与自适应控制里的持续激励（persistency of excitation）同构：基线必须被持续「激励」（多视角、锚点、不同入射角），漂移才可辨识。若可观测裕度 `κ_b` 低于阈值，系统不是「更保守」，而是**根本没有资格发证书**，只能主动探测或安全停机。第 65 轮从未把「可观测性」写进证书，这是它误归因的另一个根。

**灵感 4（共失效 → 独立乘积是错的，必须测联合失效）**
直觉：第 65 轮的 `α_vis + α_geo` 联合界隐含「视觉与几何独立」。但透明/镜面/对抗 patch 让相机和 LiDAR 同时失效的概率远大于边缘乘积；正相关下乘积会**系统性低估**。正确做法不是假设独立，而是在部署/仿真中用**受控共失效注入**估计联合尾部分布（CFM），证书用联合分位数而不是边缘乘积；估不出来就显式标 `joint_unbounded` 并走最坏联合界，而不是偷偷相乘。

**灵感 5（合流 → BRIDGE：Baseline Reproduction with Instrumented Depth Geometric Evidence）**
闭环：LiDAR 仪器见证（LIV）提供结构不同的几何/回波证据 → 基线复现证书（BRC）检验三元组与可观测性 `κ_b` → 基线锚定 e-value 检验（BAT）做开放世界漂移检测（不强行归因）→ 共失效矩阵（CFM）给联合尾界 → 归因模糊或基线漂移时，主动基线探针（ABP）用非接触多视角/多回波分离「仪器变了」与「世界变了」→ 漂移响应证书（DRC）让证书随漂移衰减/过期 → RSC-B/WCV-B 只膨胀 `r_base` → CSP-B/TSL-anchor 在规划中插入 `anchor_check`/`baseline_probe`/`recalibrate` → AIC-B 认证基线欺骗与共失效 → J_bridge 记录完整计量溯源链。第 65 轮是「故障可归因」，BRIDGE 是「**证书可溯源；归因不确定时，基线先说话**」。

> IP 编号：IP-224~IP-233（共 10 个）；定义 233–248；实验 E241–E250。

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（BRIDGE 闭环）**：BRIDGE = (VISTA, LIV, BRC, BAT, CFM, ABP, DRC, RSC-B, WCV-B, CSP-B, AIC-B, J_bridge)。定位：VISTA 的「计量溯源 + 开放世界检验」升级。不变式：**基线复现、e-value 监控、共失效估计、证书构建只在语义流/低频线程；实时流只做残差采集、预编译 e-process 更新、可观测性/证书过期检查、安全前缀执行与早停，零学习写操作。** 附加不变式：**BRC 不通过时不得签发证书；未知故障不得被强行归因。**
- **定义 234（基线三元组与复现）**：`B=(b_geo,b_stat,b_exp)`。`b_geo` 为传感器内外参、杠杆臂、时间偏移；`b_stat` 为健康残差 null 分布（按技能/场景分层）；`b_exp` 为锚点集、种子、硬件指纹、代码哈希、评估协议。复现检验统计量 `T_geo,T_stat,T_exp`；在水平 `α_B` 下复现 ⇔ `T_geo≤q_geo(α_B/3) ∧ T_stat≤q_stat(α_B/3) ∧ T_exp=0`。
- **定义 235（测量模型与基线可观测性）**：`y_t=h_t(φ,b_geo)+ε_t`，`J_b=Σ_t H_bᵀΣ⁻¹H_b`，`H_b=∂h/∂b`。基线可观测 ⇔ `J_b≻0`；可观测裕度 `κ_b=λ_min(J_b)`。相对旋转外参在零杠杆臂处 `H_b=0`，故共址传感器无法观测相对旋转漂移；`κ_b<κ_min` 时无资格签发证书。
- **定义 236（LiDAR 仪器见证 LIV）**：每条光束返回 `(r,I,echoes,t)`；特征含多次回波比、入射角校正后的强度、测距噪声签名、去畸变残差、与相机/几何的跨通道一致性。证据向量 `e_L`，并显式输出不可观测标志（镜面丢返、逆反射饱和、量程饱和、透明漏检）。**LIV 只提供不同的失效轮廓，不提供真值。**
- **定义 237（共失效矩阵 CFM）**：对通道集合 `𝒞` 与失效原因 `𝒦`，估计联合尾部 `P_joint(α)=Q_{1−α}(‖e_𝒞‖_joint)` 或 `ℳ∈[0,1]^{|𝒦|×|𝒞|}`（原因×通道的失效强度）。证书使用联合分位数或 Clopper-Pearson 上界；**不得用边缘乘积 `∏p_i` 替代正相关联合失效**。估计不足时置 `joint_unbounded`，退回最坏联合界。
- **定义 238（基线锚点与锚点认证）**：锚点集 `𝒜={a_i}`，每个锚点有已知几何/反射率/稳定性，并可从多个基线观测；锚点须满足激励条件（覆盖基线方向与深度）。锚点认证用不可预测的物理特征/随机挑战，防止伪造、重放与静态替换。
- **定义 239（基线复现证书 BRC）**：`BRC=(anchor_set_ver,b̂_geo,κ_b,T_geo,T_stat,T_exp,q_geo,q_stat,repro_manifest_hash,timestamp,drift_estimate)`。Valid(BRC) ⇔ 三元组复现 ∧ `κ_b≥κ_min` ∧ 锚点认证通过 ∧ 清单哈希匹配。BRC 是 J_bridge 的**前置门**，不是事后解释。
- **定义 240（基线锚定 e-value 检验 BAT）**：在复现后的 null `H_0` 下，构造非负 e-process `e_t` 使 `E_{H_0}[e_t|ℱ_{t−1}]≤1`；由 Ville 不等式，`P_{H_0}(sup_t e_t≥1/α)≤α`，无需预设监控时长、对可选停止有效。e-value 超过阈值只报「基线破裂」，**不命名故障**；触发 DRC/ABP，而不是强行归因。
- **定义 241（漂移过程与证书衰减 DRC）**：基线漂移 `d_t` 服从有界过程 `‖d_{t+1}−d_t‖≤δ_d`；证书带有效期 `h_cert` 与漂移预算 `d_max`。当 `‖d_t‖>d_max`、BAT 报警或超过 `h_cert` 时，J_bridge 失效，系统必须重基线或安全降级。证书覆盖随漂移按 TV 距离衰减：`coverage ≥ 1−α−d_TV(P_cal,P_t)`。
- **定义 242（主动基线探针 ABP）**：选择非接触动作 `a`（视角、平移、多回波配置），`a*=argmax_a [I(D_instr;y_{1:T}(a)|B)+λ·κ_b(a)]`，s.t. 力/形变安全、时间预算、`κ_b(a)≥κ_min`。探针必须制造视差或观测已认证锚点；零基线动作对旋转漂移不可辨识，价值为零。
- **定义 243（仪器漂移 vs 场景变化的可辨识性）**：联合雅可比 `H=[∂h/∂φ, ∂h/∂b]` 必须列满秩，仪器漂移 `D_instr` 与场景变化 `D_scene` 才可分；若所有观测共享同一基线且无锚点，两假设在观测上混淆（秩亏）。ABP 的目标就是最大化该差分的 D-最优信息。
- **定义 244（RSC-B / WCV-B）**：几何半径拆为 `r_geo=√(r_scene²+r_base²)`，`r_base` 由 BRC 漂移估计与证书年龄推得；只按被复现的漂移膨胀 `r_base`。搜索域 `B(φ̂,r)∩𝒢∩K∩ℱ∩𝒱∩ℬ`，`ℬ={b:Valid(BRC)∧κ_b≥κ_min}`；`ℬ=∅` 时拒发证书。
- **定义 245（CSP-B / TSL-anchor）**：块边需 `Valid(J_bridge)`；技能绑定基线前置条件与锚点覆盖率。规划器可插入 `anchor_check`（零接触看锚点）、`baseline_probe`（主动视差）、`recalibrate`（重基线）；代价增 `λ_b·age(BRC)+λ_repro·Cost(re-baseline)`。
- **定义 246（AIC-B 基线/对抗认证）**：`ℰ_B=ℰ_V×ℰ_base×ℰ_common`；`ℰ_base` 含 LiDAR 欺骗（逆反射、激光注入、幽灵点）、锚点篡改/重放、时间同步攻击、外参漂移、温漂/灰尘；`ℰ_common` 为同一物理原因同时骗过相机与 LiDAR。`ρ_dir` 在 `ℰ_B` 上重算（n_cert 128→160，32 用于基线/共失效）；J_bridge 增 `baseline_attack_ver`。
- **定义 247（BRIDGE 证书 J_bridge）**：`J_bridge=(J_vista,BRC_hash,e_value,cofailure_bound,κ_b,drift_estimate,cert_expiry,anchor_set_hash,repro_manifest_hash,baseline_attack_ver)`。Valid ⇔ `Valid(J_vista) ∧ Valid(BRC) ∧ BAT 未报警 ∧ (共失效有界 ∨ 已进入最坏联合安全模式) ∧ κ_b≥κ_min ∧ 未过期 ∧ 基线攻击已认证`。
- **定义 248（BRIDGE 闭环算子）**：语义流 `[LiDAR→LIV→LSF→USR/MEL→VISTA→BRC/BAT/CFM→ABP→WCV-B→CSP-B/TSL-anchor→CSC→Shield→执行 k*→EV_exec→DRC→RSC-B→OLP→DIR→AIC-B]`；实时流 `[LiDAR/视觉/力残差采集→LIV 特征→预编译 e-process→κ_b/过期检查→CSC 早停→WCV-B 编译→π_σ 前缀派发→J_bridge 构建]`。

brc = BaselineRepro(anchors, b0, alpha_B)

if not rep.reproduced or rep.kappa_b < KAPPA_MIN:
    J_bridge = None                        # 没资格发证书
    action = abp.choose(...) if rep.observable_miss else safe_idle()

# BAT：开放世界、anytime-valid e-process（实时只更新，语义流解释）
e_t = bat.update(residual_stream)          # E_{H0}[e_t] <= 1
if e_t >= 1.0 / alpha_e:
    drift_alarm = True                     # 只报基线破裂，不命名故障
    trigger_baseline_probe_or_rebaseline()

# CFM：联合尾界，不用边缘乘积
u_joint = cfm.joint_quantile(1 - alpha, skill=sigma)
if cfm.unbounded:
    u_joint = worst_case_union_bound()     # 显式保守，不偷偷相乘

# ABP：非接触、制造视差、认证锚点
a = argmax_a [ mutual_info(D_instr; y(a), D_scene) + lam * kappa_b(a) ]
s.t. f_n(a) <= f_safe, strain(a) <= eps_strain, a is non-contact

# DRC：证书随漂移过期
if norm(drift) > d_max or now > cert_expiry or drift_alarm:
    invalidate(J_bridge); rebaseline_or_degrade()

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（BRC 的尺寸与功效）**：在复现后的 null 下，BRC 误报率 ≤ `α_B`（Bonferroni）；对漂移 `δ`，每个锚点观测的 KL 约 `½δᵀJ_bδ`，故检出力 ≥1−β 所需锚点数 `N≳2log(1/β)/(δᵀJ_bδ)`。`κ_b` 越小，漂移越不可观测、检测越慢——这把「可观测性」与「可复现性」统一在同一 Fisher 信息里。
- **引理 10（BAT 的 anytime 有效性）**：e-process 满足 `E_{H0}[e_t|ℱ_{t−1}]≤1`，Ville 不等式给出 `P(sup_t e_t≥1/α)≤α`，无需预设监控时长；相关通道用联合 null 或算术平均合并 e-value，避免乘积在正相关下失效。
- **引理 11（CFM 优于边缘乘积）**：正相关时 `P(∩F_i)≥max_i P(F_i)≥∏P(F_i)`，乘积系统性低估；CFM 的联合分位数/上置信界是 sound 的，`joint_unbounded` 时退回联合界仍 sound。
- **定理 9（基线条件化的端到端安全）**：在 A94–A99 下，`Valid(J_bridge)` ⇒ VISTA 的安全结论在「基线三元组被复现」条件下成立；未知复合故障要么被 BAT 检出为分布漂移，要么被 CFM 联合包络覆盖，**不再需要强行归因**；BRC 失败时无安全声明，只能重基线/降级。
- **定理 10（ABP 的必要性与近最优性）**：零基线探针对相对旋转漂移秩亏（`H_b=0`），无法区分 `D_instr` 与 `D_scene`；在线性高斯下，D-最优探针最大化 `λ_min(J_b(a))` 或 `λ_min(J_diff(a))`，且信息随有效基线长度单调增；因此「主动制造视差 + 观测认证锚点」不是启发式，而是可辨识性的必要条件。
- **命题（漂移下的证书衰减）**：若标定分布与部署分布的 TV 距离为 `d_TV`，则 conformal 覆盖至少 `1−α−d_TV`；BRC/DRC 用可观测漂移给出 `d_TV` 上界，从而把「证书过期」变成可计算的量，而不是拍脑袋的定时重标定。
- **实时性**：LIV 特征、e-process 更新、κ_b/过期检查、CSC 早停都在实时流；世界模型、CFM 估计、ABP 规划、AIC-B 全在语义流。目标实时路径 ≤2.8ms，零学习写操作。

## 5. 本轮最大风险

**一句话**：BRIDGE 把安全建立在「基线可被独立复现」之上，但基线本身由同一套传感器、同一组锚点和同一批人维护——在无纹理/遮挡/狭小空间里 `κ_b` 可能长期低于阈值而只能保守停机，更糟的是，一个被伪造、重放或静态替换的锚点可以让漂移的仪器通过复现检验，使「可复现」沦为「可被复现地欺骗」；此时基线不再是安全锚点，而是新的单点故障与虚假的计量确定性——这是本轮全部论证共同依赖的隐藏假设（见产物区 A94–A99）。

## 2. 形式化定义（完整版）

**定义 233（BRIDGE 闭环）** BRIDGE 是 VISTA 的「计量溯源 + 开放世界检验」升级：在 VISTA 的语义流/实时流骨架上挂载 LIV（LiDAR 仪器见证）、BRC（基线复现证书）、BAT（基线锚定 e-value 检验）、CFM（共失效矩阵）、ABP（主动基线探针）、DRC（漂移响应证书），并原位升级 RSC-V→RSC-B、WCV-V→WCV-B、CSP-V→CSP-B、AIC-V→AIC-B、J_vista→J_bridge。不变式：**(i) 基线复现、e-value 解释、共失效估计、证书构建只在语义流/低频线程；(ii) 实时流只做残差采集、预编译 e-process 更新、可观测性/证书过期检查、安全前缀执行与早停，零学习写操作；(iii) BRC 不通过时不得签发证书；(iv) 未知故障不得被强行归因。**

**定义 234（基线三元组与复现）** 定义基线 `B=(b_geo,b_stat,b_exp)`：
- `b_geo`：LiDAR-相机外参、LiDAR-末端杠杆臂、各传感器时间偏移、LiDAR 内部光束参数；
- `b_stat`：健康残差 null 分布 `P_0(r_L,r_vis,r_force,r_geo | skill,scene)`；
- `b_exp`：锚点集与布置、随机种子、硬件指纹、固件/代码哈希、评估协议。

复现检验统计量 `T_geo`（锚点重投影/点到面残差的 Mahalanobis 范数）、`T_stat`（当前残差与 `b_stat` 的两样本检验，如 MMD/energy distance）、`T_exp`（清单/指纹/hash 的确定性比对）。在水平 `α_B` 下：
`Reproduced(B) ⇔ T_geo≤q_geo(α_B/3) ∧ T_stat≤q_stat(α_B/3) ∧ T_exp=0`，
其中 `q_geo,q_stat` 由 split-conformal 在可交换标定集上取得。**三元组缺一不可：只看外参复现而不看实验清单，等于用一把校准过但装错程序的尺子。**

**定义 235（测量模型与基线可观测性）** 记传感器观测 `y_t=h_t(φ,b_geo)+ε_t`，`φ` 为场景/物体状态，`b_geo` 为基线参数。基线 Fisher 信息
`J_b=Σ_t H_b(t)ᵀΣ_t⁻¹H_b(t)`，`H_b(t)=∂h_t/∂b_geo`。
基线可观测 ⇔ `J_b≻0`；可观测裕度 `κ_b=λ_min(J_b)`。对相对旋转外参，点位移对旋转的灵敏度 `∂y/∂θ = u×(p−o)` 正比于杠杆臂；当两传感器共址（`b=0`）时旋转子空间 `H_b=0`，漂移不可观测。对深度/尺度，若场景点深度未知且无锚点，`b_geo` 与 `φ` 仅以乘积出现，同样秩亏。因此：
`κ_b<κ_min ⇒ 无资格签发安全证书`，只能 ABP 主动激励或安全停机。这把「可复现」与「可观测」统一为同一个 Fisher 信息条件。

**定义 236（LiDAR 仪器见证 LIV）** 对每条光束的返回 `(r,I,echoes,t)` 提取：
1. **多次回波比** `ρ_echo=#multi-echo/#valid`：透明/边缘/植被易产生多次回波；
2. **入射角校正强度** `Î=I·(r²/cosθ_i)`：材料/反射率的弱代理，但受入射角与增益影响；
3. **测距噪声签名** `σ_r(r,θ_i,Î)`：与标定基线比较，偏大提示时间/增益/温度漂移；
4. **去畸变残差** `e_deskew`：时间同步基线漂移会让静止场景出现「运动畸变」；
5. **跨通道一致性** `e_cross`：LiDAR 点投影到相机/几何面的残差，需与相机-LiDAR 共失效显式区分。

得 `e_L=[ρ_echo,Î,σ_r,e_deskew,e_cross]`，并输出不可观测标志 `u_L∈{specular_dropout,retro_saturation,range_saturation,transparent_miss}`。**LIV 不提供真值，只提供与相机结构不同的失效轮廓；`u_L` 必须进入证书，不能被当作「无异常」。**

**定义 237（共失效矩阵 CFM）** 设通道集合 `𝒞={L,vis,force,geo}`，失效原因 `𝒦={specular,transparent,adversarial,temporal,model}`。CFM 由两部分组成：
- 联合尾部 `P_joint(α)=Q_{1−α}(‖e_𝒞‖_joint | skill,scene)`，其中 `‖·‖_joint` 为按 `b_stat` 白化后的联合范数；
- 原因×通道矩阵 `ℳ_{k,c}∈[0,1]`，表示原因 `k` 导致通道 `c` 失效的概率/强度，由仿真 + 真机受控共失效注入估计。

证书使用 `P_joint(α)` 或 `ℳ` 推得的联合上界；若样本不足以给出 `1−β` 上置信界，置 `joint_unbounded=True`，退回最坏联合界（所有被 `ℳ` 标记的通道同时失效）。**严禁用 `∏_c p_c` 替代 `P_joint`：正相关时乘积系统性低估。**

**定义 238（基线锚点与锚点认证）** 锚点集 `𝒜={a_i}`，每个锚点具备已知几何（平面/球/角点/深度台阶）、已知反射率或已知多次回波特征，且可从多个基线观测。锚点须满足**激励条件**：其观测方向/深度覆盖 `b_geo` 的可辨识子空间（`J_b(𝒜)≻0` 且 `κ_b(𝒜)≥κ_min`）。锚点认证使用不可预测物理特征（随机纹理/随机深度编码/PUF/一次性挑战），防止：
- **静态替换**：把假锚点放在真锚点位置；
- **重放**：回放旧锚点观测；
- **遮挡/隐藏**：让系统看不到真锚点而错误降级。
锚点认证失败 ⇒ BRC 不通过，而不是「假设锚点还在」。

**定义 239（基线复现证书 BRC）**
`BRC=(anchor_set_ver,b̂_geo,κ_b,T_geo,T_stat,T_exp,q_geo,q_stat,repro_manifest_hash,timestamp,drift_estimate)`。
`Valid(BRC) ⇔ Reproduced(B) ∧ κ_b≥κ_min ∧ 锚点认证通过 ∧ repro_manifest_hash=当前清单哈希`。
BRC 是 `J_bridge` 的**前置门**：BRC 不通过时，下游 WCV-B/CSP-B/CSC 不得签发任何安全结论；系统只能进入 `baseline_hold`（保持/退让）或 `baseline_probe`。审计链要能回答：**哪组锚点、哪个基线版本、哪个实验清单、哪个可观测裕度支撑了这张证书。**

**定义 240（基线锚定 e-value 检验 BAT）** 在复现后的 null `H_0` 下，构造非负 e-process：
`e_t = ∫ (p_δ(r_t)/p_0(r_t)) w(dδ)`，
其中 `p_0` 为 `b_stat`，`p_δ` 为漂移/故障幅度 `δ` 下的备择密度，`w` 为备择先验（混合使 e-value 对复合备择有效）。则 `E_{H_0}[e_t|ℱ_{t−1}]≤1`，由 Ville 不等式：
`P_{H_0}(sup_{t≥1} e_t ≥ 1/α_e) ≤ α_e`。
无需预设监控时长，对可选停止与连续监控有效。多通道相关时，用联合 null 的 e-process，或用算术平均合并各通道 e-value（线性性保证仍为 e-value）；**不得在相关通道上直接相乘**。BAT 报警只说明「当前残差不再像复现后的基线」，**不说明是哪一个故障**；因此它触发 DRC/ABP/重基线，而不是强行归因。

**定义 241（漂移过程与证书衰减 DRC）** 基线漂移 `d_t=b_geo(t)−b_geo(0)` 服从有界过程 `‖d_{t+1}−d_t‖≤δ_d`。证书带漂移预算 `d_max` 与有效期 `h_cert`。若 `‖d_t‖>d_max`、BAT 报警、或 `now>cert_expiry`，则 `J_bridge` 失效。证书覆盖随漂移按总变差衰减：
`coverage ≥ 1−α−d_TV(P_cal,P_t)`。
用 BRC 估计的 `d_TV` 上界与漂移过程给出 `h_cert`，使「证书过期」成为可计算量，而不是固定周期重标定。漂移方向若落在 `κ_b` 很小的子空间，DRC 必须显式标 `unobservable_drift`，不能假装「没检出=没漂移」。

**定义 242（主动基线探针 ABP）** 探针动作 `a` 包含视角/平移/多回波配置，要求非接触。选择
`a* = argmax_{a∈A} [ I(D_instr; y_{1:T}(a) | B) + λ·κ_b(a) ]`，
s.t. `f_n(a)≤f_safe`、`strain(a)≤ε_strain`、`T(a)≤T_budget`、`κ_b(a)≥κ_min`。
`I(D_instr;y|B)` 为「仪器漂移 vs 场景变化」的互信息；在线性高斯下等价于对差分雅可比 `H_diff=[∂h/∂b,−∂h/∂φ]` 做 D-最优。探针必须制造视差或观测已认证锚点；**零基线动作对相对旋转漂移秩亏，信息为零**。若 `f_safe` 不允许运动，退化为 `anchor_check`（只观测现有锚点）或 `safe_idle`。

**定义 243（仪器漂移 vs 场景变化的可辨识性）** 联合模型 `y=h(φ,b_geo)+ε`。若 `H=[∂h/∂φ,∂h/∂b]` 列满秩，则 `D_instr`（仅 `b` 变）与 `D_scene`（仅 `φ` 变）在观测上可分；若所有观测共享同一基线且无锚点，`H` 秩亏，两假设混淆。ABP 的目标就是最大化该差分的 D-最优信息：
`a* = argmax_a λ_min( H_diff(a)ᵀΣ⁻¹H_diff(a) )`。
这把「主动看」从经验策略变成可辨识性的必要条件。

**定义 244（RSC-B / WCV-B）** 维护 `r_scene`（真实场景/物体几何不确定度）、`r_base`（基线漂移/标定不确定度）、`r_force`、`r_model`：
`r_geo=√(r_scene²+r_base²)`，`r=√(r_geo²+r_force²+r_model²)`。
只按被 BRC/DRC 复现的漂移膨胀 `r_base`：`r_base(t)=r_base(0)+L_d·‖d_t‖+L_h·age(BRC)`。搜索域
`B(φ̂,r)∩𝒢(g)∩K(μ̂)∩ℱ(f_lim)∩𝒱∩ℬ`，
其中 `ℬ={b:Valid(BRC)∧κ_b≥κ_min}`。`ℬ=∅` 时拒发证书；不得用「更大的 r」掩盖「基线不可复现」。

**定义 245（CSP-B / TSL-anchor）** 在 CSP 的层级 A* 上以块为边：每条块边需 `Valid(J_bridge)` 且 `k*≥1`。技能 σ 绑定基线前置条件 `Pre_σ(B)` 与锚点覆盖率 `cov_σ(𝒜)`；实际锚点覆盖不足或技能所需基线未复现，则该技能不入图。规划器可插入元技能：
- `anchor_check`：零接触观测已认证锚点，更新 BRC；
- `baseline_probe`：主动视差/多回波，最大化 `κ_b` 与 `D_instr/D_scene` 可分性；
- `recalibrate`：漂移超预算后重基线（需要人类授权或已知标定台）；
- `null_test`/`visual_probe`（继承 VISTA）：零力窗与主动视觉。
软约束代价增 `λ_b·age(BRC)+λ_repro·Cost(re-baseline)+λ_u·joint_unbounded`。

**定义 246（AIC-B 基线/对抗认证）** 干扰集
`ℰ_B = ℰ_V × ℰ_base × ℰ_common`，
`ℰ_base` 含：LiDAR 欺骗（逆反射/激光注入/幽灵点/点云注入）、锚点静态替换/重放/遮挡、时间同步攻击、外参漂移、温漂/灰尘/雨雾；`ℰ_common` 为同一物理原因同时骗过相机与 LiDAR（透明、镜面、对抗 patch）。`ρ_dir` 在 `ℰ_B` 上重算（`n_cert` 128→160，其中 32 用于基线/共失效），`J_dir` 增 `baseline_attack_ver`、`anchor_attest_ver`。**共因/基线攻击下不要求归因正确，只要求 BRC 失败或 BAT 报警并安全降级。**

**定义 247（BRIDGE 证书 J_bridge）**
`J_bridge=(J_vista,BRC_hash,e_value,cofailure_bound,κ_b,drift_estimate,cert_expiry,anchor_set_hash,repro_manifest_hash,baseline_attack_ver)`。
验证规则：
`Valid(J_bridge) ⇔ Valid(J_vista) ∧ Valid(BRC) ∧ BAT 未报警 ∧ (共失效有界 ∨ 已进入最坏联合安全模式) ∧ κ_b≥κ_min ∧ now≤cert_expiry ∧ 基线攻击已认证`。
审计链新增：为何相信这台仪器（BRC）、基线还能观测到吗（κ_b）、世界是否变了（BAT e-value）、最坏共失效多大（CFM）、证书何时过期（DRC）、锚点是否被伪造（anchor attest）。

**定义 248（BRIDGE 闭环算子）** 见 IP-233 伪代码。语义流：`[LiDAR→LIV→LSF→USR/MEL→VISTA→BRC/BAT/CFM→ABP→WCV-B→CSP-B/TSL-anchor→CSC→Shield→执行 k*→EV_exec→DRC→RSC-B→OLP→DIR→AIC-B]`；实时流：`[LiDAR/视觉/力残差采集→LIV 特征→预编译 e-process→κ_b/过期检查→CSC 早停→WCV-B 编译→π_σ 前缀派发→J_bridge 构建]`。

**假设 A94–A99（BRIDGE 证书成立的条件，显式列出以便证伪）**
- **A94（基线可复现）**：在证书有效期内，`b_geo,b_stat,b_exp` 三元组可被 BRC 复现；锚点观测在复现条件下可交换，或漂移由 DRC 的有界过程显式建模。
- **A95（conformal 可交换）**：BRC 的标定集与部署集在复现条件下可交换，`q_geo,q_stat` 的覆盖成立；漂移超预算时改用 TV 衰减界。
- **A96（e-value 备择覆盖）**：BAT 的备择混合 `w(dδ)` 覆盖实际漂移方向，或联合 null 在复现后可校准；否则 BAT 只有尺寸控制、没有功效保证。
- **A97（共失效可估）**：CFM 的注入原因集覆盖证书使用的原因集；若不足，`joint_unbounded=True` 时必须采用最坏联合界而非边缘乘积。
- **A98（探针与锚点可信）**：ABP 的非接触约束（力/形变/时间）成立；锚点认证依赖的物理不可克隆性/随机挑战不被攻破。
- **A99（实时流有界）**：LiDAR、相机、力传感器数据流延迟有界；时间同步基线在 BRC 中被显式检验。若 A99 失败，`e_deskew` 会升高并触发 BRC/BAT，而不是被当成几何噪声吸收。

class LiDARInstrumentedWitness:

### IP-225 BRC（基线复现证书 + 可观测性）

```python
class BaselineReproduction:
    def __init__(self, anchors, b0, alpha_B=0.05, kappa_min=0.1):
        self.anchors, self.b0 = anchors, b0
        self.alpha_B, self.kappa_min = alpha_B, kappa_min
        self.q_geo = self.q_stat = None       # split-conformal 分位数，离线标定

    def test(self, obs):
        T_exp = 0.0 if obs.manifest_hash == self.b0.manifest_hash else 1.0
        T_geo = anchor_reprojection_mahalanobis(obs, self.anchors, self.b0)
        T_stat = energy_distance(obs.residual_window, self.b0.stat_samples)
        J_b = baseline_fisher(obs, self.b0)    # Σ H_bᵀ Σ⁻¹ H_b
        kappa_b = np.linalg.eigvalsh(J_b)[0]
        reproduced = (T_geo <= self.q_geo[self.alpha_B / 3]
                      and T_stat <= self.q_stat[self.alpha_B / 3]
                      and T_exp == 0.0)
        return ReproductionResult(
            reproduced=reproduced, kappa_b=float(kappa_b),
            observable_miss=(kappa_b < self.kappa_min),
            T=(T_geo, T_stat, T_exp), anchors_ok=obs.anchor_attest_ok)
```

### IP-226 BAT（anytime-valid e-process）

```python
class BaselineAnchoredTest:
    """e_t = ∫ p_delta(r_t)/p0(r_t) w(ddelta)。相关通道用联合 null 或算术平均。"""
    def __init__(self, p0, alternatives, alpha_e=0.01):
        self.p0, self.alts, self.alpha_e = p0, alternatives, alpha_e
        self.log_e = 0.0

    def update(self, r_t, joint=True):
        if joint:
            log_ratio = logsumexp([np.log(w) + self.alts[d].logpdf(r_t)
                                   for d, w in self.alts.items()]) - self.p0.logpdf(r_t)
            self.log_e += log_ratio               # 单通道/联合 null 的 e-process
        else:
            e_list = [np.exp(self.alts[d].logpdf(r_t) - self.p0.logpdf(r_t))
                      for d in self.alts]
            self.log_e = np.log(np.mean(e_list))  # 相关通道：算术平均仍为 e-value
        return float(np.exp(self.log_e))

    def alarm(self):
        return np.exp(self.log_e) >= 1.0 / self.alpha_e
```

### IP-227 CFM（共失效矩阵）

```python
class CoFailureMatrix:
    def __init__(self, causes, channels):
        self.M = np.zeros((len(causes), len(channels)))   # 原因 × 通道
        self.joint_samples = {}

    def estimate(self, injected_logs):
        for cause, channel, fail in injected_logs:
            self.M[cause, channel] = empirical_rate(fail)
            self.joint_samples.setdefault(cause, []).append(whitened_norm(fail))

    def joint_quantile(self, alpha, skill):
        if skill not in self.joint_samples:
            return None, True                     # joint_unbounded
        q = np.quantile(self.joint_samples[skill], 1 - alpha)
        return float(q), False

    def worst_case_union(self, channels):
        return max(self.M[:, channels].max(axis=1))  # 显式保守，不偷偷相乘
```

### IP-228 ABP（主动基线探针）

```python
class ActiveBaselineProbe:
    def choose(self, b_hat, anchors, f_safe, risk_budget):
        best, best_val = None, -np.inf
        for a in candidate_views_and_echo_modes():
            if not is_non_contact(a):
                continue
            traj = predict_view_motion(a)
            if traj.max_force > f_safe or traj.strain > EPS_STRAIN:
                continue
            H_diff = instrument_scene_jacobian(a, b_hat, anchors)
            if np.linalg.matrix_rank(H_diff) < H_diff.shape[1]:
                continue                          # 零基线/秩亏：无信息
            info = 0.5 * np.log(np.linalg.det(
                np.eye(H_diff.shape[1]) + H_diff.T @ np.linalg.inv(SIGMA) @ H_diff))
            kappa = np.linalg.eigvalsh(baseline_fisher(a, b_hat, anchors))[0]
            val = info + LAMBDA * kappa - risk_budget.cost(a)
            if val > best_val:
                best, best_val = a, val
        return best
```

### IP-233 BRIDGE 闭环算子（整合）

```python
def BRIDGE_round(M, obs, delta_f_req):
    V, T, P, L, P_cloud, W_meas, tactile, img, depth, flow = obs
    # ———— 语义流（10–100Hz）————
    M.lsf.update_geometry(P_cloud)
    e_L, u_L = M.liv.features(P_cloud, M.calib, img)
    x_prime = M.lsf.fuse(M.usr.fuse(V, T, P, L))

    # 1) 基线复现：仪器还是那台仪器吗？
    rep = M.brc.test(obs)
    if not rep.reproduced or rep.kappa_b < M.kappa_min:
        a = M.abp.choose(M.brc.b_hat, M.brc.anchors, M.f_safe, M.risk_budget)
        if a is not None:
            M.execute(a)                       # 非接触视差/多回波探针
            rep = M.brc.test(M.obs_after(a))
        if not rep.reproduced or rep.kappa_b < M.kappa_min:
            return M, None, None, build_j_bridge(None, rep, reason='baseline_hold')

    # 2) VISTA 的视觉/力/几何证据 + 开放世界 e-value
    y_vis = M.f_vis(img, depth, flow)
    phi_hat_geo, *_ = M.mel.infer_by_mode(M.ocb_skill.choose().mel_mode,
                                          V, T, P, L, x_prime)
    A = M.ach.propose(x_prime, H=M.H)
    visual = M.vpg.verify_and_predict(y_vis, A, M.mws.last_contacts)
    f_vis, k_hat, _ = M.vfp.estimate(visual['flow'], M.dt, visual['valid'])
    phases = M.stage.split(M.residual_log, visual)
    e_now = M.bat.update(M.residual_stream, joint=(not M.joint_unbounded))

    # 3) FIR 只作为效率优化；BAT 报警时禁止强行归因
    post, h_star, ambiguous = M.fir.attribute(phases)
    if e_now >= 1.0 / M.alpha_e or ambiguous:
        M.post = post
        M.balls, M.w_vis, M.H = M.fir.conservative_envelope(post, M.balls)
        M.cfm_bound, M.joint_unbounded = M.cfm.joint_quantile(M.alpha_e, M.skill)
    else:
        M.balls, M.w_vis, M.H = M.fir.directed_demote(h_star, M.balls, M.w_vis, M.H)

    # 4) 基线约束下的规划与认证前缀
    goal = M.dms.parse_goal((M.usr.U_ep, M.usr.U_al))
    tau = M.csp_b.plan_chunks(goal, x_prime, phi_hat_geo, M.balls, post, M.brc)
    k_star = M.csc.certified_prefix(tau.A, post, M.m, M.alpha_chunk,
                                    baseline=M.brc, cfm=M.cfm)
    if k_star < 1:
        return M, None, None, build_j_bridge(None, rep, reason='no_certified_prefix')

    # 5) 实时执行 + 早停 + 证书过期检查
    K_safe, EV_exec, cert_exec = realtime_step_bridge(
        M, delta_f_req, tau, k_star, x_prime, f_vis, e_L, rep)

    # 6) 漂移响应与在线更新（纯语义流）
    drift = M.brc.drift_estimate(obs)
    M.drc.update(drift, e_now, M.brc)
    M.olp.online_step(M.olp.fuse_evidence(x_prime, W_meas, tactile, visual, post),
                      execution_loss_grad(K_safe, EV_exec, M.balls))
    M.rsc_b.update(EV_exec, W_meas, phi_hat_geo, post, M.balls, drift)
    M.dir.update(sample_batch_from_history(32))
    M.aic_b.certify(tau, x_prime, phi_hat_geo, M.balls, M.post, M.cfm)

    # 7) 计量溯源证书
    return M, K_safe, EV_exec, build_j_bridge(
        cert_exec, J_vista=M.j_vista, BRC=M.brc, e_value=e_now,
        cofailure_bound=M.cfm_bound, kappa_b=rep.kappa_b, drift=drift,
        anchor_set_hash=M.brc.anchor_set_hash,
        repro_manifest_hash=M.brc.manifest_hash,
        baseline_attack_ver=BASELINE_ATTACK_VERSION)
```

## 4. 推导

**引理 9（BRC 的尺寸控制与检出力）** 设复现后的 null 下 `T_geo,T_stat` 由 split-conformal 给出边缘覆盖，Bonferroni 后 `P(BRC 误报)≤α_B`。对漂移 `δ=b_geo−b_0`，单个锚点观测的对数似然比期望为 `KL(p_δ‖p_0)≈½δᵀJ_bδ`（局部高斯）。用序贯概率比检验/两样本检验，检出力 `≥1−β` 所需样本数 `N≥2log(1/β)/(δᵀJ_bδ)`。由于 `δᵀJ_bδ≥κ_b‖δ‖²`，**在 `κ_b` 很小的方向上，任何有限样本都难以检出漂移**；当 `κ_b=0` 时不可能检出。∎

**引理 10（BAT 的 anytime 有效性）** 由 e-process 构造，`E_{H_0}[e_t|ℱ_{t−1}]≤1`，故 `e_t` 为非负上鞅；Ville 不等式给出 `P_{H_0}(∃t:e_t≥1/α_e)≤α_e`。该界对任意停止时刻成立，因此实时流可以持续监控而无需预设实验时长。若各通道 e-value 相关，直接用联合 null 的 e-process，或取算术平均 `ē=(1/m)Σe_i`（线性性保证 `E[ē]≤1`）；乘积只在独立时有效。∎

**引理 11（CFM 优于边缘乘积）** 设失效事件 `F_c`，`p_c=P(F_c)`。若 `F_c` 正相关（共同原因），则 `P(∩F_c)≥∏p_c`，且可高达 `min_c p_c`；边缘乘积系统性地低估联合失效。CFM 直接估计 `P(∩F_c)` 或原因×通道矩阵，得到 sound 的联合上界；当 `joint_unbounded=True` 时用 `min_c p_c` 或全失效最坏界，仍 sound 但更保守。∎

**定理 9（基线条件化的端到端安全）** 在 A94–A99 下：
1. **证书条件化**：`Valid(J_bridge)` 蕴含 `Valid(J_vista)` 且 BRC 复现、`κ_b≥κ_min`、BAT 未报警、共失效有界/显式最坏、证书未过期；因此 VISTA 的几何/力/滑移/前缀安全结论在「基线三元组被复现」条件下成立。
2. **未知故障不强行归因**：若未知复合故障使残差分布偏离 null，BAT 以 anytime 方式报警；若其效应仍在 CFM 联合包络内，则被包络覆盖；两者都不需要把故障强行塞进有限假设集。归因只在 BAT 未报警且 FIR 后验集中时作为效率优化使用。
3. **共因/基线攻击**：`ℰ_B` 显式包含相机-LiDAR 共失效、LiDAR 欺骗、锚点篡改/重放；认证要求 BRC 失败或 BAT 报警并安全降级，不要求归因正确。
4. **优雅降级**：BRC 失败→`baseline_hold`/ABP；`κ_b<κ_min`→拒绝发证书并主动激励；CFM 不可估→最坏联合界；AIC-B 失败→`safe_idle`/柔顺退让。
5. **可审计**：`J_bridge` 记录基线版本、锚点哈希、实验清单、e-value、共失效界、漂移估计与过期时间，能回答「为什么这张证书此刻仍然成立」。∎

**定理 10（ABP 的必要性与近最优性）** 对相对旋转外参 `θ`，点位移 `∂y/∂θ=u×(p−o)`；当两传感器共址时杠杆臂为零，`H_θ=0`，故零基线观测对 `θ` 的 Fisher 信息为零，`D_instr` 与 `D_scene` 不可分。对线性高斯模型，D-最优探针最大化 `λ_min(H_diffᵀΣ⁻¹H_diff)`，其中 `H_diff=[∂h/∂b,−∂h/∂φ]`；该信息随有效基线长度（视差/杠杆臂）单调增，且需要已知锚点打破尺度混淆。因此在 `κ_b<κ_min` 时，**主动制造视差或观测认证锚点是恢复可辨识性的必要条件**，不是可选启发式。∎

**命题（漂移下的证书衰减）** 设标定分布 `P_cal` 与部署分布 `P_t` 的总变差距离为 `d_TV`。对任意事件 `A`，`P_t(A)≤P_cal(A)+d_TV`；取 `A` 为 conformal 覆盖失效事件，得 `coverage_t≥1−α−d_TV(P_cal,P_t)`。BRC/DRC 通过 `κ_b` 与漂移过程给出 `d_TV` 上界，从而把证书有效期 `h_cert` 变成可计算量：`h_cert≈d_max/(δ_d·L_TV)`。∎

**命题（共失效下的证书收紧）** 设 CFM 给出 `P_joint(α)`，则证书应在联合尾部 `1−α` 上验证，而不是在每个通道的边缘 `1−α_c` 上分别验证后再用 `Σα_c` 联合界。若 `P_joint(α)>α`（正相关强），联合验证会显著收紧可承诺前缀 `k*`；这正是第 65 轮「独立假设」下被低估的风险。∎

## 7. 已知风险

**一句话**：BRIDGE 把安全建立在「基线可被独立复现」之上，但基线本身由同一套传感器、同一组锚点和同一批人维护——在无纹理/遮挡/狭小空间里 `κ_b` 可能长期低于阈值而只能保守停机，更糟的是，一个被伪造、重放或静态替换的锚点可以让漂移的仪器通过复现检验，使「可复现」沦为「可被复现地欺骗」；此时基线不再是安全锚点，而是新的单点故障与虚假的计量确定性（A94）。

**次级风险与缓解**：
1. **基线复现成为新的单点故障**：BRC 是证书前置门，BRC 本身错了会直接放行；缓解：锚点认证（PUF/随机挑战）、多锚点交叉、AIC-B 对抗认证，BRC 失败即 `baseline_hold`。
2. **`κ_b<κ_min` 导致长期弃权**：无纹理/遮挡/狭小空间里无法主动制造视差；缓解：CSP-B 把 `baseline_probe` 作为可达性检查，允许在任务间隙重定位；否则明确降级为接触前保守模式，而不是假装安全。
3. **CFM 需要故障注入覆盖**：未知共因可能不在注入集内；缓解：`joint_unbounded` 显式标记 + 最坏联合界 + 在线 e-value 监控；CFM 只用于收紧，不用于放松安全。
4. **e-value 功效/延迟权衡**：小漂移在低 `κ_b` 方向上检测很慢；缓解：把 `κ_b` 写进证书，低 `κ_b` 时不承诺高置信；用 ABP 提高激励而非无限期监控。
5. **ABP 运动代价与安全**：主动视差需要运动，可能碰撞或耗时；缓解：非接触、力/形变/时间约束，优先 `anchor_check`；探针收益不抵风险时不做。
6. **LiDAR 物理退化**：强度依赖入射角/材料/增益，多次回波并非所有型号都有；缓解：只在可用特征上构建 LIV，缺特征时显式降权，不把强度当材料真值。
7. **实验基线 `b_exp` 过严**：跨硬件清单哈希可能永远不匹配；缓解：分层哈希（代码/固件/硬件/协议），允许已知差异并显式记录，而不是一刀切拒绝。
8. **实时预算**：LIV + BAT + DRC 逼近 2.8ms；缓解：ROI 降采样、预编译 e-process、与 LSF 共享编码，世界模型/CFM/ABP 全部留在语义流。
9. **证书语义被误解**：`Valid(J_bridge)` 只是「基线条件下」的安全，不是绝对安全；缓解：证书显式携带条件、锚点、过期时间与 `joint_unbounded`，审计界面不得简化为一个绿色勾。
10. **分布漂移与 conformal 失效**：BRC/DRC 只能约束可观测漂移；缓解：BAT 监控 + 在线重校准 + 漂移方向分解（`D_instr` vs `D_scene`），无法观测的方向标 `unobservable_drift`。
