# 第 73 轮（承接第 72 轮「EMBODIED-GAUGE-RAS 具身计量审计」IP-287~294；本轮灵感：「少样本学习」×「可靠性」）

> R72 把安全从「认知层计量审计」下沉为「ROS 实时调度 × 意图识别 × 灵巧接触」的**具身**闭环：REG 给时序契约，IRL 给联合后验 b_t(s,z)，DMEM 给接触条件证据与四分量 u_tac，EREFLEX/ERVOI 给三层反作用与有限停止，E-RISK 把物理/意图/接触不确定度**同权**塞进 λ 分母，J_EMB 把上述承诺封成证书。这一整套看起来很完整。但它有一个从未被点名的隐含前提：
>
> **所有产生「不确定度」的估计器，其校准都是在「大样本、同分布、单任务」下估出来的。**
>
> 真实部署恰恰相反——是**少样本、跨分布、多任务**：
> - 新用户只给 3 段示范，意图网要不要在线适应？适应后 ECE_intent 还是原来那个吗？
> - 新物体只摸过 5 次，DMEM 的 u_geom/u_sens 还能直接套旧标定吗？
> - 新本体（Allegro→Shadow）只有 3 个实机标定点，R72 的 S2R-UQ 残差模型该如何估 Δ？
> - 新场景只见过 1 次，AURA 的情感基线还成立吗？
>
> **R72 的答案是含糊的：它假设「有个离线大模型」或「有足够实机数据」。** 但少样本学习告诉我们两件事，恰好击中这个软肋：
> 1. **适应是有代价的**：k 个样本的适应引入的**方差**，可能超过它降低的**偏差**；「适应后更准 ⇒ 更安全」在少样本下是错的。
> 2. **少样本误差是相关的**：k 个样本常来自同一用户/同一会话/同一物体，误差不独立；重复使用**不会**按 1/√k 降低不确定度。
>
> 而「可靠性」告诉我们第三件事，且更致命：
> 3. **可靠性的估计自身也需要可靠性**：R72 报告的 ECE_intent、u_tac、漏检率都是从数据估出来的点估计。**用 5 个样本去估「5 个样本适应得好不好」，方差会爆炸**。于是「谁审计审计者」在少样本下变成一个真正的停机问题——你必须允许系统说「我无法可靠地自证，因此**不学**」。
>
> 核心命题：**R72 问「我的测量链在实时调度、意图模糊、灵巧接触下还能兑现风险界吗」；R73 再问一层——「当我的标定标准器本身只有 k 个样本、且这些样本的误差彼此相关时，我凭什么相信这套『能兑现风险界』的判断？」** 把 R72 的具身计量闭环升级为 **FR-GAUGE-RAS**（Few-shot, Reliable GAUGE for RAS）——**少样本可靠性计量审计闭环**，其精神是：**先测后适、宁可不学、可逆可回滚、相关误差不得假装独立、自审不能自证时弃权。**
>
> 一句话口号：**「少样本不是免费的午餐，可靠性不是一次盖章，而是每隔一段时间仍敢重新盖章。」**

## 0. 直觉与动机

**灵感 1（少样本 = 低分辨率标准器，不是「便宜的训练」）**
直觉：R72 把每个不确定度都当成「可估的量」。但在计量学里，**你用一把刻度很粗的尺去量东西，量多少次都不会比尺本身更准**。k 个支撑样本就是这把粗尺：它给出的是一个**分辨率先验**，k 越小、分辨率越粗，且**同一把尺反复用，误差是相关的**（同一用户的口音、同一物体的材质、同一次标定的温度漂移）。因此少样本适应的不确定度有**不可约下界**，不会随 k→∞ 归零（引理 33）。**把它当「小样本训练」是工程视角；把它当「低分辨率、误差相关的标准器」才是计量视角。**
严谨化：u_fs² = u_est² + u_meta² + u_supp² + u_cal²，其中 u_est ∝ 1/√n_eff（n_eff 为有效样本量，n_eff = k/(1+(k−1)ρ)），而 u_meta、u_cal 与 k 弱相关甚至不相关 ⇒ u_fs(k) ≥ √(u_meta²+u_cal²) > 0。

**灵感 2（可靠性 = 证书在适应后仍成立，而不是模型准确率高）**
直觉：一个 95% 准确的意图分类器，如果在它错的时候**总是 99% 自信**，那它是**不可靠**的。R72 的 ECE 只测「平均」校准，测不到「错误样本上的条件自信」。更要命的是：**适应之后，ECE 会变**。可靠性应该被定义为「**对任务族中任意部署、任意 k-shot 适应，证书声称的风险界以概率 ≥1−δ 成立**」——一个**分布无关、条件于适应**的保证，而不是一个孤立的准确率。这要求把「适应失败」当作证书必须能拒绝的事件，而不是事后诸葛。
严谨化：P_{S_k∼任务族}[ Risk(π_{A_k}) ≤ ε + gap(u_fs(k)) ] ≥ 1−δ。gap 由 PAC-Bayes + MMD + 覆盖 + 校准区间合成。

**灵感 3（可靠性是纵向资产，不是一次性状态）**
直觉：R72 有「反作用预算 B_reflex_total」，但没有「可靠性预算」。可是**每一次少样本适应，都是在拿信任做赌注**：你赌「这 3 个样本能代表后续分布」。赌对了，系统更顺手；赌错了，用户从此不信。**信任是会被透支、也会被积累的**。所以必须有一个**可靠性账本**，把每次适应记成一笔下注，用**随时可停的统计监控**（e-process）观察后续表现，越界即**回滚**并冻结该支撑分布。这让「可靠性」从「部署时的一次性证书」变成「贯穿生命周期的、可被推翻的假设」。
严谨化：每笔部署是一个 e-process，Ville 不等式给 anytime-valid 的假警率 ≤δ；越界触发可逆回滚（定义 372、引理 35）。

**灵感 4（可逆性是可可靠性的前提，不是工程洁癖）**
直觉：如果适应直接覆盖基础模型权重，那么一旦发现适应错了，你**回不到**适应前的行为，R72 的「逐指令退化」就成了空话。可靠性要求「**错了能退**」。所以适应必须是 **base + delta** 的加法结构：保留基础模型，适应只写 delta，回滚 = 丢弃 delta。**不可逆的适应，无论多准，都不允许部署。**
严谨化：若覆盖 θ_base 则回滚无法恢复适应前指令序列 ⇒ 破坏定义 379 的逐指令等价 ⇒ 违反 R72 定理 23 的风险单调性（引理 36）。故 base+delta 是保持严格包含的**必要条件**，不是实现细节。

**灵感 5（可靠性的可靠性：少样本下的自审不可能性与弃权）**
直觉：R72 说「E-IVG 全过 ⇒ 指标在有效域」。但 E-IVG 的阈值比较用的是**估出来的**指标；当 k 很小，**这些指标自己的置信区间宽得能吞下整个阈值**。你用 5 个样本算出的 ECE=0.05，其 95% 区间可能是 [0.01, 0.40]。此时宣称「ECE<0.08，通过」是**自欺**。更深一层：**你无法用同一批样本既拟合参数、又客观评估「拟合得好不好」**——这是一个自指问题。出路只有两条：**要么引入外部锚点（留出的元验证集 SEAL-meta），要么弃权（abstain）**。这不是保守，这是可靠性的**停机条件**。
严谨化：仅由 S_k 导出的校准区间，其覆盖率随 k→0 退化到 0；必须外部锚定或弃权（引理 37、定义 377）。

**灵感 6（few-shot 不是加一个模块，而是给 R72 每个学习件都装上「适应-审计」接口）**
直觉：IRL、DMEM、S2R-UQ、AURA 都是学习件，R73 不是另起炉灶，而是给它们统一套一个 **FSAL 外壳**：任何在线适应都必须走「四分量不确定度 → SST 充分性检验 → 选择性适应（adapt/abstain/escalate）→ 账本登记 → 证书 J_FS」这条流水线。**核心算法零改动，安全侧只增不减。** 这延续了整条研究线「新层是旧层的严格泛化、退化链逐指令等价」的姿态。

## 1. 形式化定义（增量：定义 366–379）

**定义 366（FR-GAUGE-RAS 总览与六不变式）** FR-GAUGE-RAS = (FSAL, SST, HCR, SEL-ADAPT, REL-LEDGER, J_FS, GAUGE-RAS‡)。六不变式：
(i) **先测后适**：任何适应必须先通过 SST；未过则弃权或升级请求样本，**不得静默适应**；
(ii) **不确定度完整**：每次适应携带四分量 u_fs² = u_est²+u_meta²+u_supp²+u_cal²，每项独立追溯链 τ_fs_i；
(iii) **不可补偿入 λ**：u_fs 与 U_ale、U_epi、H_z、u_tac **同权**进入 λ 分母，任一项失控都抬高 λ；
(iv) **可逆性**：适应以 base+delta 结构保存，任何适应可在 O(1) 内逐指令回滚；
(v) **纵向监控**：REL-LEDGER 用依赖稳健 e-process 随时可停地监控，越界即回滚并冻结支撑分布；
(vi) **严格退化**：任一新层失效 ⇒ R72；R72 失效 ⇒ R71；R71 失效 ⇒ R68。**新层只在「支撑充分且可靠」时启用。**

**定义 367（少样本适应算子与适应记录）** 给定元先验 π_meta、支撑集 S_k = {(x_i, y_i)}_{i=1}^k（来自新用户/新物体/新本体/新任务），适应算子
A_k : (π_meta, S_k) → q_k(θ)
输出**分布**而非点估计。适应记录
R_k = (aid, q_k, k, n_eff, h(S_k), τ_k, u_fs, D_k, I⊥, h(θ_base), h(Δ), rollback_ptr)。
其中 Δ = q_k 相对于 θ_base 的增量（参数或低秩/前缀增量），h 为哈希，D_k 为有效域，I⊥ 为抗 Goodhart 反指标。**关键：A_k 是「测量」，R_k 是「测量报告」，不是训练日志。**

**定义 368（少样本不确定度四分量与相关标准器原理）**
u_fs²(k) = u_est²(k) + u_meta²(k) + u_supp²(k) + u_cal²(k)，其中
- u_est：估计不确定度。PAC-Bayes 后验项，∝ 1/√n_eff，n_eff = k/(1+(k−1)ρ)，ρ∈[0,1] 为支撑样本误差的**组内相关**；
- u_meta：元分布偏移。D_MMD(π_task, π_meta) 或到元先验流形的 OOD 距离；
- u_supp：支撑覆盖缺陷。决策关键域 𝒦 中 S_k 未覆盖部分的质量/测度；
- u_cal：**校准不确定度**。用 k 个样本估 ECE/MCE 时，估计量自身的方差。
**相关标准器原理**：当 ρ>0，u_est(k) ≥ σ·√((1+(k−1)ρ)/k) → σ√ρ > 0（k→∞），故
u_fs(k) ≥ √(u_meta² + u_cal²) 存在**不可约下界**。
**推论**：重复使用同一支撑会话不会把 u_fs 压到零；R72「适应后零额外风险」是错误假设。

**定义 369（支撑集充分性检验 SST）** SST(S_k, q_k, π_meta) = (cov, stab, info, cons)：
- **cov（覆盖）**：D_MMD(S_k, π_meta.samples) ≤ τ_cov，或核覆盖/距离到元流形 ≤ τ_cov；
- **stab（稳定）**：对 S_k 做 B 次 bootstrap 重适应，预测/参数方差 ≤ τ_stab/n_eff（用 n_eff 纠正相关样本）；
- **info（信息）**：每样本 Fisher 信息或期望信息增益 ≥ τ_info（防止「样本很多但都在决策边界外」）；
- **cons（一致）**：至少两条**独立**证据通道（跨模态/跨任务/跨时段）对适应方向一致；单源不定案（继承 R72 AIC-EMB 的「单源不定案」精神）。
四项**全过**方获准进入控制/计量环。**SST 是必要非充分条件**（对自适应投毒只降低不消除，见引理 34）。

**定义 370（分层校准与校准区间 HCR）** 不在单任务少样本上单独估 ECE（方差爆炸），而做**层次贝叶斯部分池化**：
θ_cal^(task) ~ N(μ_meta, Σ_meta)，跨任务共享 μ_meta、Σ_meta。
输出 (ECE_hat, [L_ece, U_ece])，满足 P(ECE_true ∈ [L_ece, U_ece]) ≥ 1−δ_cal。
**审计用 U_ece（保守上界），不用点估计。** 定义**校准可靠性** cal_rel := P(ECE_true ≤ U_ece)。**R72 报点估计等价于默认 u_cal = 0，这正是少样本下最先崩的假设。**

**定义 371（选择性适应 SEL-ADAPT）** 决策 d ∈ {adapt, abstain, escalate}：
- **adapt** ⇔ SST 全过 ∧ u_fs ≤ τ_fs；
- **escalate** ⇔ SST 未全过/高风险任务 ∧ 可请求更多支撑（复用 R72 ERVOI 选交互 g = 请求示范/标注/换姿态示范）；
- **abstain** ⇔ 其余情形 ⇒ 保留 R72 元先验，记录原因，**不学新东西**。
**可靠性优先于覆盖率**：宁可不学，不可错学；abstain/escalate 是一等公民，不是失败。

**定义 372（可靠性账本 REL-LEDGER 与依赖稳健 e-process）** 每次部署是一笔「可靠性下注」。账本条目
Entry = (aid, h(S_k), deploy_time, target_risk ε, e_value E_t, status)。
e-process：E_0 = 1，E_t = Π_{i≤t} (1 + λ_i (loss_i − ε))，loss_i ∈ [0,1]，λ_i 可预测（仅依赖 t−1 前信息）。
- **anytime-valid**：在 H0: risk ≤ ε 下，{E_t} 为非负上鞅 ⇒ Ville 不等式 P(sup_t E_t ≥ 1/δ) ≤ δ；
- **依赖稳健**：因相关标准器，loss_t 非独立。采用 (a) 块状/分批 betting，(b) mixingale/ρ-混合假设下的收缩 λ_max(ρ)，或 (c) 粗粒度分批 + union bound；**禁止直接套 iid Hoeffding e-process**；
- **越界** E_t ≥ 1/δ ⇒ **revoke**：回滚到 θ_base，冻结 h(S_k)（同一会话不再自动重用），并在账本留痕。
**可靠性资本** B_rel：adapt 消耗、成功部署归还；耗尽后只允许 abstain/escalate。

**定义 373（少样本可靠性证书 J_FS）**
J_FS = (J_EMB, h(R_k), sst_result, u_fs_breakdown, hcr_interval, eproc_state, rollback_ptr, rel_budget_state, ver)。
Valid ⇔ J_EMB 有效 ∧ SST 全过 ∧ u_fs ≤ τ_fs ∧ e-process 未越界 ∧ rollback 可执行 ∧ 账本一致。
**自动失效语义**：支撑集 provenance 失效（如标注者 ψ 本身不可信）、h(S_k) 被改动、e-process 越界 ⇒ J_FS **立即失效并自动回滚**，无需人工介入。证书是有生命周期的，不是墓碑。

**定义 374（少样本风险缩放 FS-RISK）**
λ = max( M_efs.risk_scale(U_ale, U_epi, H_z, u_tac, u_fs),
         λ_floor(U_ale + U_epi + H_z + u_tac + u_fs) )。
u_fs **不可补偿**：物理/意图/接触再干净，也不能抵消「适应不可信」。
**修正 R72 隐含假设**：适应后参数更准 ≠ 可以更激进；偏差可能降，但方差可能升，且方差对安全更不利（引理 33）。

**定义 375（少样本元威胁模型 AIC-META）** ℰ_meta = ℰ_EMB × ℰ_fs：
ℰ_fs = {支撑集投毒、标签噪声攻击、元先验投毒、覆盖攻击（选让 SST 过但 D_k 假的样本）、过拟合诱导、e-process 操纵（延迟/选择性上报）、回滚路径破坏、**相关攻击**（提供近重复样本，使经验方差与 bootstrap 稳定性被假性压低）}。
**防御锚点**：以**有效样本量** n_eff 替代名义 k；correlation attack 由 n_eff 修正后的 stab 判据拦截；cover attack 由 cov + E-Process 双保险。

**定义 376（可逆适应与 base+delta 分解）** 状态 = (θ_base, Δ)，**永不覆盖 θ_base**。回滚 = 丢弃 Δ。**引理**：不可逆覆盖 ⇒ 无法保证逐指令退化 ⇒ 违反 R72 定理 23。故 base+delta 是保持严格包含的**必要条件**。

**定义 377（元可靠性与自审停机）** 校准区间自身须有覆盖保证 P(ECE_true ∈ [L,U]) ≥ 1−δ_cal。当 u_cal 超阈（k 太小无法估校准），**禁止宣称校准可信**，直接 abstain。形式化自审不可能性：仅用 S_k 同时估 q_k 与「q_k 的校准」，其经验校准误差对真实 ECE 是**乐观有偏**估计，且区间覆盖率随 k→0 退化到 0。出路：**外部锚点 SEAL-meta（留出元验证集）或弃权**。

**定义 378（R72 各学习件的少样本化接口）**
- IRL^fs：意图后验用元先验 + k 段用户示范；
- DMEM^fs：接触四分量用 k 次抓取标定，u_geom/u_sens 由少量接触贝叶斯更新；
- S2R-UQ^fs：残差用**元学习 GP 先验 + k 个实机点**，替代 R72 需较多点的 bayes_linear_residual；
- AURA^fs：情感基线按用户 k 段语音自适应。
**统一约束**：每个 fs 模块的适应都产出 R_k，且都受 SST/J_FS/REL-LEDGER 约束。核心算法（BSE/ACH/EREFLEX）零改动。

**定义 379（严格退化包含链扩展）**
- SST 不过或 u_fs > τ_fs ⇒ abstain ⇒ 逐指令 = R72 EMBODIED；
- R72 失效 ⇒ R71；R71 失效 ⇒ R68；
- 全有效 ⇒ FR-GAUGE 完整形态。
**安全侧只增不减**：λ_FR ≥ λ_R72（因为 u_fs ≥ 0 被加入分母），适应只在「支撑充分且可靠」时带来效率收益。

## 2. 关键算法骨架

```python
# IP-295 FSAL：少样本适应（保留 base+delta，产出四分量不确定度）
@dataclass
class AdaptationRecord:
    aid: str; k: int; n_eff: float; support_hash: str
    base_hash: str; delta_hash: str; q: Dist
    u_fs: float; u_break: Tuple[float, float, float, float]   # est, meta, supp, cal
    domain: ValidityDomain; trace: str; anti: str; rollback_ptr: str

class FewShotAdapter:
    def __init__(self, meta_prior, adapter, sst, hcr, ledger):
        self.meta, self.adapter, self.sst, self.hcr, self.ledger = \
            meta_prior, adapter, sst, hcr, ledger

    def adapt(self, S_k, task_ctx):
        q     = self.adapter(self.meta, S_k)                  # 分布，不覆盖 base
        n_eff = effective_size(S_k, rho_hat(S_k))             # k/(1+(k-1)ρ)
        u_est = pac_bayes_bound(q, self.meta, n_eff, delta=DELTA)
        u_meta = mmd(q.sample(n=256), self.meta.sample(n=256))
        u_supp = coverage_deficit(S_k, task_ctx.critical_region)  # 𝒦 中未覆盖质量
        u_cal  = self.hcr.calibration_uncertainty(S_k)        # ECE 估计量方差
        u_fs   = math.sqrt(u_est**2 + u_meta**2 + u_supp**2 + u_cal**2)
        sst_res = self.sst.check(S_k, q, self.meta, n_eff)
        rec = AdaptationRecord(
            aid=new_aid(), k=len(S_k), n_eff=n_eff, support_hash=h(S_k),
            base_hash=h(self.base), delta_hash=h(delta_of(q, self.base)),
            q=q, u_fs=u_fs, u_break=(u_est, u_meta, u_supp, u_cal),
            domain=task_ctx.domain, trace=make_trace(S_k, q),
            anti=calibration_anti_metric(q), rollback_ptr=new_ptr())
        return select_adapt(sst_res, u_fs, task_ctx.risk, self.ledger), rec


# IP-296 SST：覆盖/稳定/信息/一致 + 有效样本量
class SupportSetSufficiencyTest:
    def check(self, S_k, q, pi_meta, n_eff):

# IP-298 SEL-ADAPT：adapt / abstain / escalate
def select_adapt(sst, u_fs, task_risk, ledger):
    if not ledger.capital_ok():
        return Decision('abstain', reason='reliability_budget')
    if sst.all_pass() and u_fs <= TAU_FS:
        ledger.spend(u_fs)
        return Decision('adapt', detail=sst)
    if task_risk >= TAU_RISK:
        return Decision('escalate', detail=sst)            # 请求更多支撑样本
    return Decision('abstain', detail=sst)


# IP-299 REL-LEDGER：依赖稳健 e-process + 可逆回滚
class ReliabilityLedger:
    def __init__(self, target_eps, delta, rho_max):
        self.target, self.delta, self.rho_max = target_eps, delta, rho_max
        self.entries, self.capital = {}, 1.0

    def deploy(self, rec):
        self.entries[rec.aid] = Entry(E=1.0, target=self.target, rho=rec.rho)

    def observe(self, aid, loss):
        e = self.entries[aid]
        lam = e.bet(self.target, rho=min(e.rho, self.rho_max))  # 按相关收缩
        e.E *= (1.0 + lam * (loss - e.target))
        if e.E >= 1.0 / self.delta:                             # Ville 越界
            self.revoke(aid)

    def revoke(self, aid):
        rec = self.store[aid]
        rollback(rec)                # 丢弃 Δ，恢复 θ_base；逐指令 = 适应前
        freeze_support(rec.support_hash)
        self.capital -= REVOKE_COST


# IP-300 FS-RISK：u_fs 不可补偿入 λ（控制域，O(1)）
def fs_risk_scale(U_ale, U_epi, H_z, u_tac, u_fs, p):
    denom = U_ale + U_epi + H_z + u_tac + u_fs
    return max(p.lam_base * (1 + denom / p.lam_scale),
               p.lam_floor * (1 + denom))
```

## 3. 推导

**引理 33（少样本不确定度的不可约下界 / 相关标准器）** 设 S_k 的误差组内相关为 ρ∈[0,1]，则有效样本量 n_eff = k/(1+(k−1)ρ)，u_est(k) ≳ σ/√n_eff = σ·√((1+(k−1)ρ)/k)。当 k→∞，u_est → σ√ρ；当 ρ>0 时严格为正。又 u_meta、u_cal 与 k 弱相关或无关，故 u_fs(k) ≥ √(u_meta²+u_cal²)。**证明要点**：相关样本的信息量按 n_eff 计；PAC-Bayes 界的复杂度项用 n_eff。**系**：λ_floor 存在**不可约下界**；任何「少样本适应后零额外风险」的声明都与该引理矛盾。**这是 R73 相对 R72 最硬的一条修正。**

**引理 34（SST 必要非充分 / 相关攻击与覆盖攻击）** (a) 相关攻击：攻击者给 k 个近重复样本，使经验方差与 bootstrap 稳定性假性变小；若用名义 k 则 stab 误过，但用 n_eff 修正后 stab 判据可拦截（ρ_hat→1 ⇒ n_eff→1 ⇒ 方差阈值收紧）。(b) 覆盖攻击：攻击者把样本铺在一个「看起来代表、但与真实决策关键域 𝒦 不相交」的子流形上，可同时骗过 cov（与 π_meta 的 MMD 小）、stab、info、cons，但 D_k 不含 𝒦 ⇒ 适应在关键区域失效。故 **SST 只能降低攻击面，不能消除**；REL-LEDGER 的 e-process 是纵向兜底。**系**：不存在「少样本自证可靠」，只有「少样本 + 纵向监控 + 弃权」。

**引理 35（依赖稳健 e-process 的 anytime-valid 回滚与检测延迟）** 在 H0: risk ≤ ε 下，对可预测的 λ_i∈[0, λ_max]，E_t 为非负上鞅（依赖情形需 ρ-混合/mixingale 条件下取 λ_max(ρ)，或粗粒度分批）。Ville ⇒ P(sup_t E_t ≥ 1/δ) ≤ δ。若真实风险 risk > ε，则期望检测时间 E[τ] ≤ log(1/δ)/KL(P_true‖P_ε)（非渐近、无需固定样本量）。**系**：可靠性账本给的是**分布无关、随时可停**的保证；但**前提是依赖结构被正确保守上界**——ρ 估小 = 假警率失控，ρ 估大 = 检测变慢。这把「可靠性」从口号变成可验证的统计命题。

**引理 36（不可逆适应破坏退化链）** 若适应覆盖 θ_base（无 Δ 分离），则 rollback 无法恢复适应前的指令序列；定义 379 的逐指令等价不成立 ⇒ 违反 R72 定理 23 的风险单调性（安全侧只增不减）。故 base+delta 是**必要条件**，而非实现细节。**系**：可逆性是可可靠性的一部分，不是工程洁癖。

**引理 37（自审不可能性 ⇒ 外部锚点或弃权）** 设 S_k 同时用于拟合 q_k 与估计 q_k 的校准误差。经验校准误差对真实 ECE 是**乐观有偏**（样本内过拟合），其方差 ~ ECE(1−ECE)/k。仅由 S_k 导出的区间 [L,U] 的覆盖率随 k→0 退化到 0。**证明要点**：用同一批样本做「拟合+评估」等价于在训练集上评估，偏差不可由自身消除。**系**：元可靠性必须外部锚定（SEAL-meta：与 S_k 不相交的元验证集）或弃权；否则「可靠性的可靠性」无限回退。

**定理 27（J_FS 有效性 ⇒ 条件风险界）** 在 A111–A116（PAC-Bayes 界有效、MMD 估计一致、覆盖可测、HCR 区间覆盖 ≥1−δ_cal、依赖结构 ρ 有保守上界）下，若一次部署通过 J_FS 且 e-process 未越界，则
P( Risk(π_{A_k}) ≤ ε_emb + gap(u_fs(k), k) ) ≥ 1 − δ − δ_cal，
其中 gap 为 u_est/u_meta/u_supp/u_cal 的 Lipschitz 合成。**证明**：PAC-Bayes 管 u_est；MMD 管分布偏移；覆盖管关键域；HCR 管校准估计偏置；Ville 管纵向漂移。**证明重量落在「SST 未被投毒」与「元先验未被投毒」上。** 这与 R72 定理 24 同构：重量落在「契约真实成立、残差未被投毒」。

**定理 28（少样本严格包含与安全单调）** 当 k=0 或 SST 未过（abstain）时，FR-GAUGE 逐指令等于 R72 EMBODIED；且对任意有效执行，λ_FR ≥ λ_R72，故风险界 ≤ R72。**安全单调不减，效率仅在 SST 过且 u_fs 足够小时获益。** 由此 FR-GAUGE ⊒ EMBODIED ⊒ GAUGE ⊒ R68。

**定理 29（可靠性账本的有限回滚与纵向下界）** 每个适应均可逆；回滚精确恢复到适应前状态（引理 36）；e-process 假警率 ≤ δ 且期望撤销时间有限（引理 35）；故在任意长度 T 的生命周期内，系统维持在「R72 安全包络 ∪ 通过 J_FS 的适应」之内，纵向可靠性有下界 1−δ−δ_cal。**系**：可靠性不是一次性盖章，而是被 e-process 持续再验证的假设。

## 6. 本轮最大风险

**一句话**：R73 把「可靠性」从一次盖章变成 **对适应的事后统计赌注**（e-process + 账本 + 弃权），但整条保证的地基是「支撑样本的**相关结构 ρ** 能被保守估出、SST 的四判据不能被**覆盖攻击**骗过、元先验 SEAL-meta 未被投毒」——**如果攻击者或自然分布恰恰让这三点同时轻微失守（样本高度相关使 n_eff 远小于 k、支撑集铺在一个「看起来像关键域」的假流形上、元先验本身来自被污染的历史），那么 u_fs 会被系统性低估、SST 会亮绿灯、e-process 因 ρ 太小而假警率失控却检测极慢，系统就会在「每次适应都有完整四分量不确定度、每个证书都带 e-process、每笔账本都留痕」的表象下，把一次相关的错误标定传播到整个用户群——这不是单个模型错了，而是**整套可靠性审计机制在相关误差下自洽地错，且它越自洽，越没人怀疑。** 这正是「可靠性」这个词最深的陷阱：**可靠的假象，比不可靠更危险。**

## 2. 形式化定义（要点版）

**定义 366（总览与六不变式）** FR = (FSAL,SST,HCR,SEL-ADAPT,REL-LEDGER,J_FS,EMBODIED‡)。六不变式：先测后适、不确定度完整、u_fs 不可补偿入 λ、可逆性、纵向监控、严格退化。

**定义 367（适应算子与记录）** A_k(π_meta,S_k)→q_k(θ)；R_k 携带 aid/k/n_eff/support_hash/u_fs/D_k/I⊥/base+delta/rollback_ptr。**A_k 是测量，R_k 是测量报告。**

**定义 368（四分量与相关标准器）** u_fs² = u_est²+u_meta²+u_supp²+u_cal²；u_est ∝ 1/√n_eff；n_eff=k/(1+(k−1)ρ)。**ρ>0 ⇒ u_fs 有不可约下界 √(u_meta²+u_cal²)。少样本标准器是低分辨率且误差相关的。**

**定义 369（SST）** cov：D_MMD(S_k,π_meta)≤τ_cov；stab：bootstrap 方差≤τ_stab/n_eff；info：每样本 Fisher 信息≥τ_info；cons：≥2 独立通道一致。四项全过方准适应。**必要非充分。**

**定义 370（HCR）** θ_cal^(task)~N(μ_meta,Σ_meta)，部分池化；输出 (ECE_hat, [L,U])，P(ECE_true∈[L,U])≥1−δ_cal；审计用 U_ece。**R72 点估计 ≡ 默认 u_cal=0。**

**定义 371（SEL-ADAPT）** adapt ⇔ SST∧u_fs≤τ_fs；escalate ⇔ 高风险且可请求更多支撑；abstain ⇔ 其余 ⇒ 保留 R72 先验。**可靠性 > 覆盖率。**

**定义 372（REL-LEDGER 与依赖稳健 e-process）** 每部署是下注；E_t=Π(1+λ_i(loss_i−ε))；Ville ⇒ P(sup E_t≥1/δ)≤δ；相关情形用 ρ-混合/mixingale 收缩或分批 union；越界 ⇒ revoke + 回滚 + 冻结 h(S_k)。**禁止套 iid Hoeffding。**

**定义 373（J_FS）** Valid ⇔ J_EMB ∧ SST 全过 ∧ u_fs≤τ_fs ∧ e-process 未越界 ∧ rollback 可执行 ∧ 账本一致。**自动失效语义：provenance 失效 / support 改动 / 越界 ⇒ 立即失效并回滚。**

**定义 374（FS-RISK）** λ = max(risk_scale(U_ale,U_epi,H_z,u_tac,u_fs), λ_floor(Σ+u_fs))。**适应后更准 ≠ 可更激进；方差可能升。**

**定义 375（AIC-META）** ℰ_meta = ℰ_EMB × ℰ_fs；新增支撑集投毒、元先验投毒、覆盖攻击、相关攻击、e-process 操纵、回滚破坏。**防御锚点：用 n_eff 替代 k。**

**定义 376（base+delta 与可逆性）** 状态=(θ_base,Δ)，永不覆盖；回滚=丢 Δ。**不可逆 ⇒ 破坏逐指令退化 ⇒ 违反 R72 定理 23。**

**定义 377（元可靠性与自审停机）** 校准区间自身须覆盖；u_cal 超阈 ⇒ 禁称可信、弃权；自审不可能性 ⇒ 外部锚点 SEAL-meta 或弃权。

**定义 378（R72 学习件的少样本化）** IRL^fs / DMEM^fs / S2R-UQ^fs（元 GP + k 实机点）/ AURA^fs；统一受 SST/J_FS/账本约束，核心算法零改动。

**定义 379（严格退化链扩展）** SST 不过或 u_fs>τ ⇒ abstain ⇒ 逐指令=R72；R72→R71→R68；全有效 ⇒ FR。**λ_FR ≥ λ_R72。**

## 3. 关键算法伪代码

```python
# IP-295 FSAL：适应=测量；base+delta；四分量不确定度
class FewShotAdapter:
    def adapt(self, S_k, task_ctx):
        q      = self.adapter(self.meta, S_k)          # 分布，绝不覆盖 θ_base
        n_eff  = effective_size(S_k, rho_hat(S_k))     # k/(1+(k-1)ρ)
        u_est  = pac_bayes_bound(q, self.meta, n_eff, DELTA)
        u_meta = mmd(q.sample(256), self.meta.sample(256))
        u_supp = coverage_deficit(S_k, task_ctx.critical_region)
        u_cal  = self.hcr.calibration_uncertainty(S_k)
        u_fs   = sqrt(u_est**2 + u_meta**2 + u_supp**2 + u_cal**2)
        sst    = self.sst.check(S_k, q, self.meta, n_eff)
        rec    = AdaptationRecord(aid=..., k=len(S_k), n_eff=n_eff,
                                  support_hash=h(S_k), base_hash=h(self.base),
                                  delta_hash=h(delta_of(q, self.base)), q=q,
                                  u_fs=u_fs, u_break=(u_est,u_meta,u_supp,u_cal),
                                  domain=task_ctx.domain, trace=..., anti=...,
                                  rollback_ptr=new_ptr())
        return select_adapt(sst, u_fs, task_ctx.risk, self.ledger), rec

# IP-296 SST：覆盖/稳定/信息/一致，用 n_eff 纠正相关样本
class SupportSetSufficiencyTest:
    def check(self, S_k, q, pi_meta, n_eff):
        cov  = mmd(S_k, pi_meta.sample()) <= TAU_COV
        stab = bootstrap_var(S_k, q, B=32) <= TAU_STAB / max(n_eff, 1.0)
        info = fisher_information(S_k, q) >= TAU_INFO
        cons = cross_channel_agreement(S_k) >= 2
        return SSTResult(cov, stab, info, cons, n_eff=n_eff, n_nom=len(S_k))

# IP-297 HCR：层次校准 + 区间，审计只用上界
class HierarchicalCalibrator:
    def fit_predict(self, logits, task_id):
        post = self.hier.posterior(task_id, logits)     # 部分池化
        L, U = self.bootstrap_interval(post, B=200, delta=DELTA_CAL)
        return post, (L, U)

# IP-298 SEL-ADAPT：adapt / abstain / escalate
def select_adapt(sst, u_fs, task_risk, ledger):
    if not ledger.capital_ok():            return Decision('abstain','budget')
    if sst.all_pass() and u_fs <= TAU_FS:  ledger.spend(u_fs); return Decision('adapt', sst)
    if task_risk >= TAU_RISK:              return Decision('escalate', sst)
    return Decision('abstain', sst)

# IP-299 REL-LEDGER：依赖稳健 e-process + 可逆回滚
class ReliabilityLedger:
    def observe(self, aid, loss):
        e = self.entries[aid]
        lam = e.bet(e.target, rho=min(e.rho, self.rho_max))   # 按相关收缩
        e.E *= (1.0 + lam * (loss - e.target))
        if e.E >= 1.0 / self.delta:                            # Ville 越界
            self.revoke(aid)

    def revoke(self, aid):
        rec = self.store[aid]
        rollback(rec)                       # 丢弃 Δ，恢复 θ_base（逐指令=适应前）
        freeze_support(rec.support_hash)
        self.capital -= REVOKE_COST

# IP-300 FS-RISK：u_fs 不可补偿入 λ（控制域 O(1)）
def fs_risk_scale(U_ale, U_epi, H_z, u_tac, u_fs, p):
    denom = U_ale + U_epi + H_z + u_tac + u_fs
    return max(p.lam_base*(1+denom/p.lam_scale), p.lam_floor*(1+denom))

# IP-301 J_FS：自动失效 + 可回滚
def jfs_valid(j):
    return (J_EMB_valid(j.j_emb) and j.sst.all_pass()
            and j.u_fs <= TAU_FS and not j.eproc.crossed
            and rollback_executable(j.rollback)
            and provenance_ok(j.adapt_hash))

# IP-302 FR-GAUGE 主闭环：适应只在计量域，控制域只读
def FR_GAUGE_round(M, obs, audio, tac, support_buf):
    snap = M.snapshot.read_latest()                       # 控制域只读
    lam  = fs_risk_scale(snap.U_ale, snap.U_epi, snap.H_z,
                         snap.u_tac, snap.u_fs, M.risk_params)
    k = M.ach.certified_prefix(M.ach.propose_ctrl(...), lam)
    M.ctrl_out.publish(k, lam)

    if M.clock.due_metric():                              # 计量域
        if support_buf.ready():
            decision, rec = M.fsal.adapt(support_buf.take(), M.task_ctx)
            if decision.type == 'adapt':
                M.activate(rec); M.ledger.deploy(rec)
            elif decision.type == 'escalate':
                M.request_more_support(rec)
        b_t  = M.bse.step_full(...)
        gate = M.e_ivg.check(M.registry, b_t, M.z_dist, M.tac_ev,
                             M.seal.latest, M.hcr)        # 用 U_ece
        M.snapshot.write(b_t, M.z_dist, gate, make_jfs(M, M.active_rec),
                         M.psi_hat, M.tac_ev)

    psi_hat, _ = M.aura.update(audio)                     # 感知域
    M.tac_ev   = M.dmem.update(tac, M.last_action)
    M.y_intent_buf.append(extract_intent_obs(obs, audio, M.last_action))
    for aid, loss in M.outcome_buf.take():                # 账本异步观测
        M.ledger.observe(aid, loss)
    return k, lam, make_jfs(M, M.active_rec)
```

## 4. 推导

**引理 33（少样本不确定度的不可约下界）** n_eff=k/(1+(k−1)ρ)，u_est(k)≳σ√((1+(k−1)ρ)/k)→σ√ρ（k→∞，ρ>0）。u_meta、u_cal 与 k 弱相关，故 u_fs(k) ≥ √(u_meta²+u_cal²)。**系**：λ_floor 有不可约下界；「少样本适应后零额外风险」与该引理矛盾。

**引理 34（SST 必要非充分）** (a) 相关攻击：近重复样本使经验方差假性变小，用 n_eff 修正可拦（ρ→1 ⇒ n_eff→1 ⇒ 阈值收紧）；(b) 覆盖攻击：样本铺在「像关键域但不相交」的假流形上，可同时骗过 cov/stab/info/cons，但 D_k 不含 𝒦。故 SST 只降攻击面，e-process 为兜底。**系**：不存在少样本自证可靠。

**引理 35（依赖稳健 e-process）** H0 下 E_t 为非负上鞅（依赖情形取 λ_max(ρ) 或分批 union）；Ville ⇒ 假警率 ≤δ；真风险>ε 时期望检测时间 E[τ] ≤ log(1/δ)/KL(P_true‖P_ε)。**系**：ρ 估小 ⇒ 假警率失控；ρ 估大 ⇒ 检测变慢。

**引理 36（不可逆破坏退化链）** 覆盖 θ_base ⇒ 回滚无法恢复适应前指令序列 ⇒ 违反 R72 定理 23 风险单调性。故 base+delta 是必要条件。

**引理 37（自审不可能性）** 同批样本既拟合又评估 ⇒ 经验校准误差乐观有偏，方差 ~ECE(1−ECE)/k；仅由 S_k 导出的区间覆盖率随 k→0 退化为 0。**系**：需 SEAL-meta 外部锚点或弃权。

**定理 27（J_FS ⇒ 条件风险界）** 在 A111–A116 下，若通过 J_FS 且 e-process 未越界，则 P(Risk ≤ ε_emb + gap(u_fs,k)) ≥ 1−δ−δ_cal。gap 由 u_est/u_meta/u_supp/u_cal 的 Lipschitz 合成；证明重量落在「SST 未被投毒、元先验未被投毒」。

**定理 28（严格包含与安全单调）** k=0 或 abstain ⇒ 逐指令=R72；任意有效执行 λ_FR ≥ λ_R72 ⇒ 风险界 ≤ R72。故 FR ⊒ EMBODIED ⊒ GAUGE ⊒ R68。

**定理 29（账本有限回滚与纵向下界）** 每个适应可逆（引理 36）；回滚精确恢复；e-process 假警率 ≤δ、期望撤销时间有限（引理 35）；故任意长度 T 内系统维持在「R72 安全包络 ∪ 通过 J_FS 的适应」，纵向下界 1−δ−δ_cal。

## 7. 本轮最大风险

**一句话**：R73 把「可靠性」从一次盖章变成 **对适应的事后统计赌注**（e-process + 账本 + 弃权），但整条保证的地基是「支撑样本的**相关结构 ρ** 能被保守估出、SST 四判据不能被**覆盖攻击**骗过、元先验 SEAL-meta 未被投毒」——**如果攻击者或自然分布恰恰让这三点同时轻微失守（样本高度相关使 n_eff 远小于 k、支撑集铺在「看起来像关键域」的假流形上、元先验来自被污染的历史），那么 u_fs 被系统性低估、SST 亮绿灯、e-process 因 ρ 太小而假警率失控却检测极慢，系统就会在「每次适应都有完整四分量不确定度、每个证书都带 e-process、每笔账本都留痕」的表象下，把一次相关的错误标定传播到整个用户群——这不是单个模型错了，而是**整套可靠性审计机制在相关误差下自洽地错，且它越自洽，越没人怀疑。** 这正是「可靠性」最深的陷阱：**可靠的假象，比不可靠更危险。**
