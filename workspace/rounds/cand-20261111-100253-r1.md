# 第 55 轮（承接第 54 轮 v16++；灵感驱动研究循环·新序列第 1 轮；本轮灵感：「奖励设计」×「小样本学习」）

> 第 54 轮把技能组合升级为“动作-鲁棒性双证书”体系，解决了**执行侧**的可行性与对齐问题。本轮转向**目标侧**：奖励不再是一个待调的超参，而是一个可分解、可校准、可被反例证伪的证书对象。核心矛盾：H22：小样本下直接拟合奖励权重会把少样本噪声固化进目标，产生规范投机（reward hacking）；H23：为提升样本效率而加入的稠密塑形会改变最优策略，使第 54 轮的动作-鲁棒性证书在目标层失效。

## 0. 直觉与动机

**灵感 1（奖励谱分解 → 把标量奖励拆成可审计的维度谱）**
直觉：一个奖励 `r(s,a)` 把进度、安全、能耗、稳定性、接触平滑等目标压成一个数，出问题时无法归因。把奖励拆成 **维度特征** `φ_d(s,a)`（`d∈𝔇_R`）与 **权重** `w∈Δ^{|𝔇_R|}`：`r_w = Σ_d w_d φ_d`。于是“奖励设计”变成两个可分离的问题：**基函数 φ 是否正确**（可由物理/任务先验固定，少量数据可查），**权重 w 是否正确**（小样本校准的唯一对象）。奖励谱 `R_S(d)` 记录每个维度的归一化回报，使失败可以像第 53 轮鲁棒性一样被定位到具体维度。

**灵感 2（势函数塑形 → 把少样本知识放进“不改变最优策略”的通道）**
直觉：小样本最宝贵的知识是“往哪走更快”，而不是“目标权重是多少”。若直接用 k 条轨迹去改奖励权重，等于用噪声重写目标。关键观察：**势函数塑形** `r' = r_w + β(γΦ(s') - Φ(s))` 对任意势 `Φ` 都保持最优策略不变（Ng et al., 1999）。因此可以让 `Φ` 吸收少样本的稠密引导，而**只让基奖励 `r_w` 承担正确性责任**。这把“少样本学习”从“改目标”降级为“改探索”，是一个结构性的安全阀：Φ 估错只影响样本效率，不影响最优策略（精确情形）。

**灵感 3（小样本奖励校准 → 只校准少量、结构化的权重）**
直觉：如果只校准 `w` 而不是整个奖励函数，需要的数据量从“覆盖状态-动作空间”降为“覆盖维度响应”。每轮边端试验给出各维度的蒙特卡洛回报 `R̂(d)`，用线性-高斯模型对 `w` 做贝叶斯更新，得到可信椭球 `E_k`。**小样本不再是缺陷，而是被显式量化的不确定度**：`ε_w(k)` 进入证书，样本不足时自动回退到保守权重，而不是悄悄过拟合。

**灵感 4（奖励有效性证书 → 用红队反例证明代理奖励不可被利用）**
直觉：奖励正确不等于奖励安全。代理奖励 `r_w` 与真实目标 `r*` 的差可能落在“探测器看不到、策略却找得到”的缝隙里。奖励有效性证书 `R_cert` 必须同时包含：基函数覆盖、权重可信集、势塑形的“保最优性”检查、以及一组**对抗策略红队**产生的最大可利用度 `exploit_max`。只有 `exploit_max ≤ δ_hack` 才签发证书。这把 reward hacking 从“事后补救”变成“部署前的可证伪条件”。

**灵感 5（云边奖励契约与奖励兼容性 → 奖励也能像动作一样组合）**
直觉：云端持有任务级基函数与已认证权重 `w_cert`，边端用 k 次本地试验拟合 `Φ_e` 并把“哪个维度导致失败”的**奖励归因解释**回传云端。多技能组合时，两技能的塑形势在共享动作区 `A_overlap` 上可能相互抵消或叠加过猛，定义 **奖励兼容性** `rcompat(S_i,S_j)`，与第 54 轮的动作兼容性 `compat` 一起作为组合边的双重门槛。奖励由此获得与动作空间同构的组合语义。

## 1. 形式化定义（增量：定义 121–127）

**定义 121（奖励谱分解）**
设维度集 `𝔇_R`，特征 `φ_d : S×A → [0, B_φ]`，权重 `w ∈ Δ^{|𝔇_R|}`，基奖励 `r_w(s,a) = Σ_d w_d φ_d(s,a)`。技能/策略 `π` 的奖励谱
```
R_π(d) = (1-γ) · E_{π}[ Σ_{t≥0} γ^t φ_d(s_t,a_t) ] / B_φ  ∈ [0,1]
```
**奖励覆盖** `cover_R(π, T)=1` 当且仅当 `∀ d∈𝔇_R^{active}(T), R_π(d) ≥ θ_R`。

**定义 122（势函数小样本塑形）**
给定势 `Φ : S → ℝ`、尺度 `β ≥ 0`、基奖励 `r_w`，塑形奖励
```
r_{w,Φ,β}(s,a,s') = r_w(s,a) + β( γΦ(s') - Φ(s) )
```
**保最优性引理（沿用 Ng et al.）**：当 `γ<1` 且 `Φ` 有界时，`argmax_π J_{r_w}(π) = argmax_π J_{r_{w,Φ,β}}(π)`。故 `Φ` 的估计误差不改变最优策略集合，只改变学习/探索效率。

**定义 123（小样本奖励校准）**
由 k 次边端试验得到维度回报观测 `D_k = {(R̂_i(d))_d}_{i=1..k}`，在线性-高斯模型下后验 `w | D_k ~ N(ŵ_k, Σ_k)`，可信椭球
```
E_k = { w : (w-ŵ_k)^T Σ_k^{-1} (w-ŵ_k) ≤ χ²_{|𝔇_R|}(1-δ) },   ε_w(k) = max_{w∈E_k} ||w-ŵ_k||_1
```
若 `ε_w(k) > ε_w^{max}`，则退回保守权重 `w_0`（任务先验），而不是使用过拟合的 `ŵ_k`。

**定义 124（奖励有效性证书）**
`R_cert = (B_φ, ε_a, w, E_k, Inv, Exploit, δ_hack)`：
- `B_φ` 为基函数族，`ε_a = sup_{s,a}|r*(s,a) - r_w(s,a)|` 为基函数失配上界；
- `Inv ∈ {pass, fail}` 为势塑形保最优性检查；
- `Exploit = max_{π∈Π_hack} (J_{r_w}(π) - J_{r*}(π))` 为红队策略对代理奖励的最大可利用度；
- `δ_hack` 为允许的规范投机预算。
**签发条件**：`Inv=pass ∧ Exploit ≤ δ_hack ∧ ε_w(k) ≤ ε_w^{max} ∧ cover_R ≥ θ_R`。

**定义 125（奖励兼容性）**
两技能在共享动作区 `A_overlap = A_{S_i} ∩ A_{S_j}` 上的塑形势一致性
```
rcompat(S_i,S_j) = 1 - || proj_{A_overlap}(β_iΦ_i - β_jΦ_j) ||_∞ / (2 B_Φ)
```
组合边需同时满足 `compat ≥ θ_a ∧ rcompat ≥ θ_r`。**奖励干扰界**：组合后单步塑形偏差 `≤ (1-rcompat)·2B_Φ`。

**定义 126（云边奖励契约）**
`R_ce = (B_c, w_cert, E_k, Φ_e, ΔΦ, Explain_R)`：
- 云端提供基函数 `B_c` 与已认证权重 `w_cert`；
- 边端由 k 次本地试验拟合 `Φ_e`，`|Φ_e - Φ_c| ≤ ΔΦ`；
- `Explain_R` 为奖励归因回传通道：`Explain_R(sim_e) → (d*, Δw)`，指出哪个维度导致失败及建议权重修正。
契约在 `E_k` 未越界且 `ΔΦ ≤ ΔΦ_max` 时有效，否则边端只能执行保底策略。

**定义 127（奖励-鲁棒性-动作联合证书）**
`J⁺ = (J, R_cert, Φ_cert, rcompat)`，其中 `J` 为第 54 轮联合证书，`Φ_cert = (Φ_e, B_Φ, L_Φ, k)`。部署条件：
```
dom_J(T)=in ∧ δ_a<Θ_a ∧ R_cert.signed ∧ (∀ 相邻技能对) rcompat ≥ θ_r
```
即：动作可对齐、鲁棒性达标、奖励可证伪、技能间奖励不打架，四者同时成立才允许部署。

## 2. 关键算法 伪代码

### IP-121 RSCP（Reward Spectrum Characterization & Probing）

```python
def reward_spectrum(policy, dims, probes, gamma):
    R = {}
    for d in dims:
        vals = [discounted_return(policy, phi[d], probe, gamma) for probe in probes]
        R[d] = (1 - gamma) * mean(vals) / B_phi
    active = {d for d in dims if R[d] > 0.0}
    return R, active

def reward_coverage(R, dims_active, theta_R=0.6):
    return all(R.get(d, 0.0) >= theta_R for d in dims_active)
```

### IP-122 PBFR（Potential-Based Few-Shot Reward）

```python
def fit_potential(demos, basis, lam, B_Phi, L_Phi):
    # 正则化最小二乘拟合 Φ，再投影到有界/Lipschitz 安全集
    phi_hat = ridge_fit(demos, basis, lam)
    phi_hat = project_bounded_lipschitz(phi_hat, B_Phi, L_Phi)
    return phi_hat

def shaped_reward(r_w, phi_hat, beta, s, a, s_next, gamma):
    shaping = beta * (gamma * phi_hat(s_next) - phi_hat(s))
    return r_w(s, a) + shaping
```

### IP-123 RVC（Reward Validity Certificate）

```python
def reward_validity_certificate(r_w, r_star_oracle, phi_hat, E_k, theta_R, delta_hack):
    if not potential_based_check(phi_hat, r_w):          # Inv
        return ('reject', 'not_potential_based')
    exploit = 0.0
    for pi in adversarial_policy_search(r_w, budget=H):   # 红队
        exploit = max(exploit, evaluate(r_w, pi) - evaluate(r_star_oracle, pi))
    cover = reward_coverage(reward_spectrum(r_w, dims, probes, gamma), active_dims)
    if exploit > delta_hack:
        return ('reject', 'reward_hacking', exploit)
    if not cover or radius(E_k) > EPS_W_MAX:
        return ('reject', 'insufficient_calibration', radius(E_k))
    return ('ok', RewardCert(B_phi, eps_a, r_w.weights, E_k, 'pass', exploit))
```

### IP-124 FSAC（Few-Shot Reward Calibration）

```python
def few_shot_calibrate(w_prior, Sigma_prior, D_k, A):
    # D_k: k 次试验的维度回报观测；A: 维度响应矩阵
    Sigma_k = inv(inv(Sigma_prior) + A.T @ A / sigma2)
    w_hat = Sigma_k @ (inv(Sigma_prior) @ w_prior + A.T @ D_k / sigma2)
    if credible_radius(Sigma_k) > EPS_W_MAX:
        return ('fallback', w_prior, Sigma_k)        # 样本不足，保守回退
    return ('ok', w_hat, Sigma_k)
```

### IP-125 RCC（Reward-Compatible Composition）

```python
def reward_compat(s1, s2, beta, B_Phi):
    A_overlap = action_overlap(s1.alpha, s2.alpha)
    if not A_overlap:
        return 0.0
    diff = max_abs(beta * (s1.phi - s2.phi), domain=A_overlap)
    return 1.0 - diff / (2 * B_Phi)

def build_composition_graph_reward_aware(skills, theta_a, theta_r, K):
    G = build_composition_graph(skills, theta_a, tau_e, K)
    for (i, j) in list(G.edges):
        rc = reward_compat(skills[i], skills[j], beta=1.0, B_Phi=B_PHI)
        if rc < theta_r:
            G.remove_edge(i, j)
        else:
            G.edges[i, j]['rcompat'] = rc
    return G
```

### IP-126 CERC（Cloud-Edge Reward Contract）

```python
def cloud_reward_contract(task, w_cert, B_c):
    return RewardContract(B_c, w_cert, E_k=None, phi_e=None)

def edge_adapt(contract, demos_k, sim_model):
    phi_e = fit_potential(demos_k, contract.B_c, lam, B_Phi, L_Phi)
    delta_phi = max_abs(phi_e - contract.phi_c, domain=A_e)
    if delta_phi > DELTA_PHI_MAX:
        return ('reject', 'potential_drift', delta_phi)
    report = explain_reward_failure(sim_model, phi_e, contract.w_cert)
    return ('ok', RewardContract(contract.B_c, contract.w_cert, E_k, phi_e, report))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| RSCP | O(|𝔇_R|·|probes|·H) | O(|𝔇_R|) | 探针覆盖活跃维度 |
| PBFR | O(k·n² + n³) | O(n²) | 势函数有界、Lipschitz 投影 |
| RVC | O(H·|Π_hack|·H_roll) | O(|Π_hack|) | 红队覆盖、oracle 可信 |
| FSAC | O(k·|𝔇_R|² + |𝔇_R|³) | O(|𝔇_R|²) | 后验校准、可信椭球有效 |
| RCC | O(|S|²·|A_overlap|) | O(|S|²) | 兼容阈值 sound |
| CERC | O(k·n² + |A_e|) | O(n²) | ΔΦ 有界、Explain_R 收敛 |

**正确性定理（Certified Few-Shot Reward Transfer Soundness）**
承接第 54 轮 (A26)–(A28)；新增假设：**(A29)** `r*` 落在 `span{φ_d}` 内，失配上界 `ε_a`；**(A30)** 小样本后验以概率 `≥1-δ` 覆盖真实权重，`ε_w(k)` 为可信半径；**(A31)** `Φ̂` 经有界/Lipschitz 投影，`βB_Φ` 为塑形幅度预算；**(A32)** 红队策略族 `Π_hack` 覆盖已知投机模式，漏检概率 `≤ δ_hack`。
则对校准后策略 `π̂`，以概率 `≥ 1-δ-δ_hack`：
```
J_{r*}(π*) - J_{r*}(π̂) ≤ 2/(1-γ) · ( ε_a + B_φ · ε_w(k) ) + Ψ(β, B_Φ, L_Φ)
```
其中 `Ψ` 为塑形近似项：**在精确势塑形下 `Ψ=0`**（保最优性引理）；在函数近似下 `Ψ ≤ 2β(1+γ)B_Φ/(1-γ) + βL_Φ/(1-γ)²`。关键结论：**少样本误差只通过 `ε_w(k)` 与 `Ψ` 进入，且当 `ε_w(k)` 越界时可回退到 `w_0` 使第一项退化为先验误差，而不是无界过拟合。**

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 基函数族失配导致 ε_a 隐式变大 | 高 | 残差探针 + 基函数自动扩张 + 人工审计锚点 |
| 势塑形在函数近似下不再保最优 | 高 | 有界/Lipschitz 投影 + β 预算 + 精确性回归测试 |
| 小样本后验过度自信 | 高 | 校准集 + 可信椭球回退 + k 依赖的保守阈值 |
| 红队覆盖不足，漏掉新型 reward hacking | 高 | 对抗策略搜索 + held-out 漏洞库 + 定期红队更新 |
| 云边奖励契约版本漂移/震荡 | 中 | 证书版本号 + hysteresis + 冷启动锚点 |
| 奖励兼容性与动作兼容性冲突 | 中 | 双门槛联合剪枝 + 冲突时优先动作可行性 |

## 6. 本轮最大风险

**一句话**：本轮把“小样本知识放进保最优性的势函数、只让基奖励权重承担正确性”作为核心安全赌注，但这一赌注在**基函数失配**或**函数近似下势塑形不再精确保最优**时会退化为“看似安全的假保证”——策略通过窄探针能通过的代理奖励，却在真实任务/安全维度上系统性违规，故必须以 **基函数残差探测 + 有界 Lipschitz 势投影 + 持续红队反例** 三重护栏，宁可回退到保守先验，也绝不把“小样本可校准”当作“奖励已正确”的证明。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（RSCP×PBFR×RVC×FSAC×RCC×CERC）

> 承接第 54 轮产物 v31。第 54 轮补齐了动作空间与云边协同，本轮补齐**目标侧（reward layer）**，引入 **奖励谱分解、势函数小样本塑形、奖励有效性证书、小样本权重校准、奖励兼容组合、云边奖励契约** 六件套：
> - **RSCP（Reward Spectrum Characterization & Probing）**：奖励分解为可审计维度谱 `R_π(d)`；
> - **PBFR（Potential-Based Few-Shot Reward）**：少样本知识进入保最优性的势函数 `Φ`；
> - **RVC（Reward Validity Certificate）**：红队反例 + 覆盖 + 可信集，签发 `R_cert`；
> - **FSAC（Few-Shot Reward Calibration）**：只校准权重 `w`，显式量化 `ε_w(k)`；
> - **RCC（Reward-Compatible Composition）**：奖励兼容性 `rcompat` 作为组合第二门槛；
> - **CERC（Cloud-Edge Reward Contract）**：云端认证权重 ↔ 边端少样本势函数的闭环。
>
> IP 编号：IP-121~IP-126（共 6 个新增）；升级 IP-116/118/120，使技能组合图与联合证书纳入奖励维度。
>
> **核心洞见**：小样本学习不该用来“重写目标”，而应放进**不改变最优策略的势函数通道**；真正需要认证的只有低维、结构化的奖励权重。

## 2. 关键算法 伪代码

### IP-121 RSCP

```python
def reward_spectrum(policy, dims, probes, gamma):
    R = {}
    for d in dims:
        vals = [discounted_return(policy, phi[d], probe, gamma) for probe in probes]
        R[d] = (1 - gamma) * mean(vals) / B_phi
    return R, {d for d in dims if R[d] > 0.0}

def reward_coverage(R, dims_active, theta_R=0.6):
    return all(R.get(d, 0.0) >= theta_R for d in dims_active)
```

def fit_potential(demos, basis, lam, B_Phi, L_Phi):

def shaped_reward(r_w, phi_hat, beta, s, a, s_next, gamma):

### IP-123 RVC

```python
def reward_validity_certificate(r_w, r_star_oracle, phi_hat, E_k,
                                dims, probes, theta_R, delta_hack):
    if not potential_based_check(phi_hat, r_w, gamma):
        return ('reject', 'not_potential_based')
    exploit = 0.0
    for pi in adversarial_policy_search(r_w, budget=H):
        exploit = max(exploit, evaluate(r_w, pi) - evaluate(r_star_oracle, pi))
    R, active = reward_spectrum(r_w, dims, probes, gamma)
    if exploit > delta_hack:
        return ('reject', 'reward_hacking', exploit)
    if not reward_coverage(R, active, theta_R):
        return ('reject', 'low_coverage', R)
    if credible_radius(E_k) > EPS_W_MAX:
        return ('reject', 'insufficient_calibration', credible_radius(E_k))
    return ('ok', RewardCert(B_phi, eps_a, r_w.weights, E_k, 'pass', exploit))
```

### IP-124 FSAC

```python
def few_shot_calibrate(w_prior, Sigma_prior, D_k, A, sigma2):
    Sigma_k = inv(inv(Sigma_prior) + A.T @ A / sigma2)
    w_hat = Sigma_k @ (inv(Sigma_prior) @ w_prior + A.T @ D_k / sigma2)
    if credible_radius(Sigma_k) > EPS_W_MAX:
        return ('fallback', w_prior, Sigma_k)
    return ('ok', w_hat, Sigma_k)
```

### IP-125 RCC

```python
def reward_compat(s1, s2, beta, B_Phi):
    A_overlap = action_overlap(s1.alpha, s2.alpha)
    if not A_overlap:
        return 0.0
    diff = max_abs(beta * (s1.phi - s2.phi), domain=A_overlap)
    return 1.0 - diff / (2 * B_Phi)

def upgrade_composition_graph(G, skills, theta_r, beta=1.0):
    for (i, j) in list(G.edges):
        rc = reward_compat(skills[i], skills[j], beta, B_PHI)
        if rc < theta_r:
            G.remove_edge(i, j)
        else:
            G.edges[i, j]['rcompat'] = rc
    return G
```

def joint_plus_certificate(skill_seq, J, R_cert, phi_cert, theta_r):
    pairs_ok = all(reward_compat(a, b, beta=1.0, B_Phi=B_PHI) >= theta_r

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| RSCP | O(|𝔇_R|·|probes|·H) | O(|𝔇_R|) | 探针覆盖活跃维度 |
| PBFR | O(k·n²+n³) | O(n²) | 势函数有界 + Lipschitz 投影 |
| RVC | O(|Π_hack|·H²) | O(|Π_hack|) | 红队覆盖 + oracle 可信 |
| FSAC | O(k·|𝔇_R|²+|𝔇_R|³) | O(|𝔇_R|²) | 后验校准 + 可信回退 |
| RCC | O(|S|²·|A_overlap|) | O(|S|²) | 双门槛 sound |
| CERC | O(k·n²+|A_e|) | O(n²) | ΔΦ 有界 + Explain_R 收敛 |

**正确性定理（Certified Few-Shot Reward Transfer Soundness）**
承接第 54 轮 (A26)–(A28)；新增 **(A29)** `r*` 落在基函数张成内，失配 `≤ε_a`；**(A30)** 小样本后验以概率 `≥1-δ` 覆盖 `w*`，半径 `ε_w(k)`；**(A31)** `Φ̂` 有界 `B_Φ`、`L_Φ`-Lipschitz；**(A32)** 红队漏检概率 `≤δ_hack`。
则对校准策略 `π̂`，以概率 `≥1-δ-δ_hack`：
```
J_{r*}(π*) - J_{r*}(π̂)
  ≤ 2/(1-γ)·( ε_a + B_φ·ε_w(k) ) + Ψ(β,B_Φ,L_Φ)
```
- 精确势塑形下 `Ψ=0`（保最优性引理）；
- 函数近似下 `Ψ ≤ 2β(1+γ)B_Φ/(1-γ) + βL_Φ/(1-γ)²`；
- 若 `ε_w(k)>ε_w^{max}` 则回退 `w_0`，第一项变为先验误差 `2/(1-γ)(ε_a+B_φ·ε_w(0))`，保证误差有界而非随 k 过拟合。

**推论（奖励组合干扰界）**：若所有相邻技能对满足 `rcompat≥θ_r`，则组合策略的单步塑形偏差 `≤ (1-θ_r)·2B_Φ`，奖励层不会放大第 54 轮的动作错位。

## 6. 本轮最大风险

**一句话**：本轮把“小样本知识放进保最优性的势函数、只让基奖励权重承担正确性”作为核心安全赌注，但这一赌注在**基函数失配**或**函数近似下势塑形不再精确保最优**时会退化为“看似安全的假保证”——策略通过窄探针能通过的代理奖励，却在真实任务/安全维度上系统性违规，故必须以 **基函数残差探测 + 有界 Lipschitz 势投影 + 持续红队反例** 三重护栏，宁可回退到保守先验，也绝不把“小样本可校准”当作“奖励已正确”的证明。
