# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「场景理解」×「灵巧手」）

> 第 54 轮把技能组合推进到动作空间剖面 `α_S`、技能组合图 SCOM 与云边联合证书 `J`。本轮转向 **场景理解与灵巧手的接触级耦合**。核心矛盾：H22：现有场景理解以语义/几何对象为中心，输出“是什么、在哪里”，而灵巧手需要“能否接触、以何种接触、接触后是否可控”，语义正确不等于接触可行；H23：场景理解的不确定性在对象层可标定，但经手形、接触力学与 sim-to-real 放大后在接触层不可交换，导致 conformal/证书保证整体失效。

## 0. 直觉与动机

**灵感 1（从语义场景图到可操作场景图 → 场景理解的第一性输出是接触状态）**
直觉：给一段 RGB-D，传统流程输出“杯子在桌上、位姿 `T`、类别 cup”。但灵巧手真正需要的是：杯壁局部曲率、表面摩擦、杯柄是否可穿指、杯内是否有液体、施加多大预紧力会滑。于是场景表示应从 `(object, pose, label)` 升级为 **接触级场景状态 `S_c`**：在哪里能接触、接触面法向与摩擦锥、哪些部件可相对运动、这些量的不确定度是多少。**场景理解是否“够用”，由它能否支撑手 `H` 的接触动作序列来判定，而不是由检测精度判定。**

**灵感 2（手条件可供性场 → 同一场景对不同手呈现不同的可操作面）**
直觉：同一只马克杯，二指夹爪看到的是“杯沿可夹”，多指灵巧手看到的是“杯身可包覆、杯柄可勾、杯口可捏”。可供性不是物体的固有属性，而是 **场景 × 手形 × 抓取模式** 的联合函数。把可供性写成 `A_{H,g}(T)`，其零水平集就是“这只手这种抓法不可行”的边界；灵巧手的价值正体现在它能访问更大的可供性体积。第 54 轮的 `α_S` 在此获得物理来源：`α_S` 不是采样出来的黑箱，而是由 `A_{H,g}` 经技能约束投影而来。

**灵感 3（感知不确定性传到接触 → 从对象级置信度到接触级认证域）**
直觉：对象检测 95% 置信度，并不保证“指尖落点误差 < 3mm”或“摩擦系数估计误差 < 0.1”。接触对局部误差极其敏感，一个语义上正确的杯子，可能因杯壁反光导致深度缺失而不可抓。因此需要把场景不确定性 `U` 经 **手条件可供性场** 传播到接触层，并用 split conformal 给出 **接触级认证域 `R_cert`**：只有落在 `R_cert` 内的接触序列才允许部署，且给出有限样本覆盖保证。这把“场景理解”从感知指标问题变成 **可认证的决策问题**。

**灵感 4（灵巧手作为主动传感器 → 用接触消歧，而非被动等待更好的感知）**
直觉：多指手可以在不移动物体的前提下做指尖轻触、滚动、试探性捏取，这些动作几乎不改变任务状态，却能极大降低材质/摩擦/关节自由度的不确定性。于是 **认知动作（epistemic action）** 应成为技能库的一等公民，其收益是信息增益，其代价是时间与“扰动量”。主动场景理解的最优策略不是“看得更清楚”，而是“用最少的接触把关键不确定性压到认证域可接受的水平”。

**灵感 5（场景-手联合鲁棒性 → 语义漂移与接触漂移必须联合度量）**
直觉：场景侧的遮挡、光照、杂乱、材质歧义，与手侧的触觉噪声、运动学误差、柔顺性误差并非独立；例如弱纹理导致位姿漂移，会直接放大指尖接触力误差。因此把第 53 轮的鲁棒性谱扩展为 `ρ_SH = (ρ_perc, ρ_hand)`，并引入耦合矩阵 `K_sh`，跨场景、跨手形迁移证书时必须同时检查 `ρ_perc`、`ρ_hand` 与 `K_sh` 的漂移。如此形成 **场景理解—可供性—接触认证—主动探测—联合鲁棒性** 的闭环。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（接触级场景状态，CGSS）**
接触级场景状态 `S_c = (𝒪, 𝒳, ℳ, 𝒜, 𝒰)`：
- `𝒪`：物体/部件集合及其位姿分布 `p(T_o)`；
- `𝒳`：局部几何场（SDF 或接触流形），支持查询 `(x → 法向 n(x), 曲率 κ(x))`；
- `ℳ`：材料场 `(μ(x), ν(x), m_o)`，分别为摩擦系数、柔顺度、质量；
- `𝒜`：关节/可动约束（铰链、抽屉、软体自由度）；
- `𝒰`：校准后的逐查询预测集，`𝒰(x) ⊆ ℝ^k`，满足 `P(真值 ∈ 𝒰(x)) ≥ 1-α`。
若场景理解模块只输出 `(𝒪, p(T_o))`，则称为 **语义级场景状态**，它是 `S_c` 的一个投影。

**定义 122（手条件可供性场，HAF）**
给定手模型 `H`（连杆、关节限位、指尖几何、触觉阵列）与抓取模式 `g ∈ G`，可供性场
```
A_{H,g} : SE(3) → [0,1]
A_{H,g}(T) = smin( c_geo(T), c_cont(T), c_wr(T), c_reach(T) )
```
其中 `c_geo` 为无碰撞可行度，`c_cont` 为接触/摩擦锥可行度，`c_wr` 为力封闭（wrench closure）可行度，`c_reach` 为运动学可达度，`smin` 为平滑最小值。**认证可供性体积** `V_cert(H,g,θ) = {T | A_{H,g}(T) ≥ θ}`。

**定义 123（场景充分性）**
表示 `Ŝ` 对手 `H` 与任务接触序列 `A_T` 是 `(ε,δ)`-**操纵充分的**，当且仅当
```
P_{S~D}[ sup_{a∈A_T} |A_{H,g}(a; Ŝ) - A_{H,g}(a; S)| ≤ ε ] ≥ 1-δ
```
且 `A_T ⊆ V_cert(H,g,θ)`。注意充分性以 **任务相关的接触序列** 为量化域，而非全场景，因此允许“对当前任务无关区域”粗糙。

**定义 124（感知-接触证书，PACC）**
`C_pac = (Â_{H,g}, R_cert, α, q, scene_version, evidence)`：
- `Â_{H,g}(T) = Â_{H,g}(T) - q` 为 conformal 下界；
- `R_cert = {T | Â_{H,g}(T) ≥ θ_grasp}` 为认证接触域；
- `q` 为 split-conformal 分位数，满足边际覆盖
  `P(A_{H,g}(T) ≥ Â_{H,g}(T), ∀T∈R_cert) ≥ 1-α`；
- `scene_version` 绑定 `S_c` 的几何/材料快照，防止证书跨场景复用；
- `evidence` 至少包含校准集、偏移检验结果与失败接触记录。
**部署判据**：`A_T ⊆ R_cert` 且 `dom_J(T)=in`，其中 `J` 为第 54 轮联合证书。

**定义 125（认知动作 / 主动场景查询）**
认知动作 `e = (T_probe, g_probe, τ_e)`，其信息增益与代价为
```
IG(e) = H(Φ | b) - E_{z~p(z|b,e)}[ H(Φ | b, e, z) ]
c(e)  = τ_e + λ_d · disturb(e, S_c)
```
其中 `Φ` 为待消歧的场景变量（摩擦、关节、隐藏几何），`b` 为当前信念，`disturb` 度量探测对场景状态的不可逆改变。主动查询选择
`e* = argmax_e IG(e)/c(e)`，且仅当 `IG(e*) ≥ θ_ig` 与 `disturb(e*) ≤ Θ_d` 时执行。灵巧手使 `e` 可包含指尖滚动、非抓取接触、手内重定向等低成本探测。

**定义 126（场景-手联合鲁棒性与耦合）**
联合鲁棒性谱 `ρ_SH = (ρ_perc, ρ_hand)`，维度集 `D_p`（遮挡、光照、杂乱、材质歧义、关节歧义）与 `D_h`（触觉噪声、运动学误差、柔顺误差、抓取模式漂移）。耦合矩阵
```
K_sh[i,j] = ∂ρ_hand[j] / ∂ρ_perc[i]
```
联合证书 `J_SH = (ρ_SH, K_sh, C_pac, domain, evidence)`。部署条件：
```
∀d∈D_p∪D_h: ρ_SH(d) ≥ ρ_min(d) ∧ ||K_sh||_∞ ≤ κ_max ∧ A_T ⊆ R_cert
```
跨手形/跨场景迁移时，还需 `ΔA = ||A^{src}_{H,g} - A^{tgt}_{H',g}||_∞ ≤ δ_a`。

def build_contact_scene(rgbd, tactile_hist, hand_model):
    objs, poses, pose_unc = segment_and_track(rgbd)
    sdf = fuse_local_geometry(rgbd, poses, pose_unc)

### IP-122 HAF（Hand-Conditioned Affordance Field）

```python
def affordance_field(scene, hand, grasp_types, grid):
    A = {}
    for g in grasp_types:
        for T in sample_poses(scene, hand, grid):
            c_geo  = collision_free(hand, T, scene.sdf)
            c_cont = contact_feasible(hand, T, scene.sdf, scene.material)
            c_wr   = wrench_feasible(hand, T, scene, g)
            c_reach= reachable(hand, T, scene)
            A[(g, T)] = smooth_min(c_geo, c_cont, c_wr, c_reach)
    return A
```

### IP-123 PAC（Perception-Action Contact Certificate）

```python
def conformal_certify(A_pred, A_true, theta_grasp, alpha):
    scores = [A_true[a] - A_pred[a] for a in calibration_set]
    q = quantile(scores, 1 - alpha)
    def lower(a):
        return max(0.0, A_pred[a] - q)
    R_cert = {a for a in A_pred if lower(a) >= theta_grasp}
    return Cert(lower, R_cert, q, alpha)
```

### IP-124 ESQ（Embodied Scene Query）

```python
def active_scene_query(belief, hand, theta_ig, theta_d, budget):
    probes = []
    for e in candidate_probes(belief, hand):
        ig = mutual_information(belief.phi, observation_model(e))
        cost = e.tau + lam_d * disturbance(e, belief.scene)
        if ig >= theta_ig and disturbance(e, belief.scene) <= theta_d:
            probes.append((ig / max(cost, EPS), e, ig))
    probes.sort(reverse=True)
    plan, spent = [], 0.0
    for score, e, ig in probes:
        if spent + e.tau > budget:
            break
        plan.append(e)
        spent += e.tau
        belief = bayes_update(belief, simulate_probe(e, belief))
        if belief.max_entropy() <= theta_ig:
            break
    return plan, belief
```

### IP-125 SHCC（Scene-Hand Coupling Certificate）

```python
def scene_hand_certificate(scene, hand, task, alpha, budgets):
    A = affordance_field(scene, hand, task.grasp_types)
    cert = conformal_certify(A, calibration_data(hand), task.theta_grasp, alpha)
    if not set(task.contact_seq) <= cert.R_cert:
        return ('reject', 'contact_not_certified', cert.R_cert)
    rho_p = perception_spectrum(scene, D_p)
    rho_h = hand_spectrum(hand, D_h)
    K_sh  = coupling_matrix(rho_p, rho_h, calibration_data(hand))
    if min_rho(rho_p, rho_h) < budgets.rho_min or norm_inf(K_sh) > budgets.kappa_max:
        return ('reject', 'robustness_fail', rho_p, rho_h, K_sh)
    if not shift_test(scene, calibration_data(hand)):
        return ('reject', 'non_exchangeable')
    return ('ok', JointSHCert(rho_p, rho_h, K_sh, cert, scene.version))
```

### IP-126 AHT（Affordance-Hand Transfer）

```python
def transfer_scene_hand(cert_src, hand_src, hand_tgt, scene_tgt, phi, budget):
    A_tgt = morphology_map(cert_src.A, hand_src, hand_tgt, phi)
    A_fit = affordance_field(scene_tgt, hand_tgt, cert_src.grasp_types)
    delta_a = sup_norm(A_tgt - A_fit)
    rho_tgt = coupled_update(cert_src.rho_SH, cert_src.K_sh, phi)
    if delta_a > budget.delta_a:
        return ('reject', 'affordance_transfer_unsound', delta_a)
    if not shift_test(scene_tgt, calibration_data(hand_tgt)):
        return ('reject', 'non_exchangeable')
    return ('ok', JointSHCert.transfer(cert_src, A_tgt, rho_tgt, phi))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| MSR | O(N_pix + |𝒪|·|𝒳|) | O(|𝒳|) | 预测集校准、局部几何闭合 |
| HAF | O(|G|·|grid|·C_contact) | O(|G|·|grid|) | 接触/力封闭可行性 sound |
| PAC | O(n_calib log n_calib) | O(n_calib) | 可交换性、覆盖边际 |
| ESQ | O(|E_probe|·(|Φ|+τ_sim)) | O(|E_probe|) | 信息增益估计无偏、扰动有界 |
| SHCC | O(|A_T|·(|D_p|+|D_h|)+|D_p|·|D_h|) | O(|D_p|·|D_h|) | 耦合矩阵稳定、偏移检验通过 |
| AHT | O(|grid|·C_contact + |D|²) | O(|grid|+|D|²) | 形态映射 Lipschitz、证书可迁移 |

**正确性定理（Contact-Grounded Scene-Hand Soundness）**
假设承接第 54 轮 (A26)–(A28)，并新增：**(A29)** `S_c` 的预测集由独立校准集构造；**(A30)** `A_{H,g}` 对场景参数满足 Lipschitz 常数 `L_A`；**(A31)** 部署场景与校准场景通过可交换性偏移检验（否则显式拒绝）；**(A32)** 认知动作扰动 `disturb(e) ≤ Θ_d`。则
```
P(success) ≥ 1 - α - β_shift - Σ_{d∈D_p∪D_h}(1-ρ_min(d))
             - L_A·E[||U||] - P(δ_a > Θ_a)
```
其中 `β_shift` 为偏移检验的弃真上界。关键：**认证域先于动作规划**、**可交换性不是默认假设而是显式检验**、**主动探测的扰动被计入预算**。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 语义正确但接触不可行 | 高 | 以接触级任务序列定义充分性 + 认证域先验拒绝 |
| conformal 可交换性破裂 | 高 | 在线偏移检验 + 拒绝部署 + 滑动重校准 |
| 主动探测扰动场景 | 高 | 扰动预算 + 非接触优先 + 可逆探测白名单 |
| 手形/场景迁移失真 | 高 | 形态映射 Lipschitz + 跨手校准集 + 保守迁移 |
| 接触仿真到现实差距 | 高 | 域随机化 + 真实触觉校核 + 不确定性膨胀 |

## 6. 本轮最大风险

**一句话**：场景理解若停留在语义层、其不确定性在接触层又不可交换（新材料、新光照与 sim-to-real 破坏 conformal 假设），则灵巧手的高自由度会把“语义正确”放大为“接触级谬误”，因此必须以 **接触级可交换性检验 + 手内主动探测 + 认证域先验拒绝** 三重护栏，绝不让语义置信度冒充接触可行性。

### IP-122 HAF

```python
def affordance_field(scene, hand, grasp_types, grid):
    A = {}
    for g in grasp_types:
        for T in sample_poses(scene, hand, grid):
            c_geo   = collision_free(hand, T, scene.sdf)
            c_cont  = contact_feasible(hand, T, scene.sdf, scene.material)
            c_wr    = wrench_feasible(hand, T, scene, g)
            c_reach = reachable(hand, T, scene)
            A[(g, T)] = smooth_min(c_geo, c_cont, c_wr, c_reach)
    return A
```

### IP-123 PAC

```python
def conformal_certify(A_pred, A_true, theta_grasp, alpha):
    scores = [A_true[a] - A_pred[a] for a in calibration_set]
    q = quantile(scores, 1 - alpha)
    lower = lambda a: max(0.0, A_pred[a] - q)
    R_cert = {a for a in A_pred if lower(a) >= theta_grasp}
    return Cert(lower, R_cert, q, alpha)
```

### IP-124 ESQ

```python
def active_scene_query(belief, hand, theta_ig, theta_d, budget):
    probes = []
    for e in candidate_probes(belief, hand):
        ig = mutual_information(belief.phi, observation_model(e))
        dist = disturbance(e, belief.scene)
        if ig >= theta_ig and dist <= theta_d:
            cost = e.tau + lam_d * dist
            probes.append((ig / max(cost, EPS), e))
    probes.sort(reverse=True)
    plan, spent = [], 0.0
    for score, e in probes:
        if spent + e.tau > budget:
            break
        plan.append(e)
        spent += e.tau
        belief = bayes_update(belief, simulate_probe(e, belief))
        if belief.max_entropy() <= theta_ig:
            break
    return plan, belief
```

def scene_hand_certificate(scene, hand, task, alpha, budgets):
    A = affordance_field(scene, hand, task.grasp_types)

    if not set(task.contact_seq) <= cert.R_cert:

    if not shift_test(scene, calibration_data(hand)):

    return ('ok', JointSHCert(rho_p, rho_h, K_sh, cert, scene.version))

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| MSR | O(N_pix + |𝒪|·|𝒳|) | O(|𝒳|) | 预测集覆盖、局部几何闭合 |

| SHCC | O(|A_T|·(|D_p|+|D_h|)+|D_p|·|D_h|) | O(|D_p|·|D_h|) | 耦合矩阵稳定、偏移检验 |
| AHT | O(|grid|·C_contact+|D|²) | O(|grid|+|D|²) | 形态映射 Lipschitz、可迁移 |

**正确性定理（Contact-Grounded Scene-Hand Soundness）**
假设第 54 轮 (A26)–(A28) 成立；新增 **(A29)** `S_c` 预测集由独立校准集构造；**(A30)** `A_{H,g}` 对场景参数 Lipschitz 常数 `L_A`；**(A31)** 部署场景通过可交换性偏移检验；**(A32)** 认知动作扰动 `disturb(e) ≤ Θ_d`。则
```
P_success ≥ 1 - α - β_shift - Σ_{d∈D_p∪D_h}(1-ρ_min(d))
            - L_A·E[||U||] - P(δ_a > Θ_a)
```
关键：**认证域先于动作规划**、**可交换性显式检验而非默认**、**主动探测扰动纳入预算**。
