# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「任务规划」×「点云配准」）

> R69 教会系统「不确定时去问」，但它问的是**一个局部动作模态**，且默认整条轨迹都活在一个**已经对齐好的参考系**里。局部消歧再成功，也挡不住一个更高层的失败：系统把计划执行在了一个**错误或漂移的坐标系**里。此时每一步都「看起来对」（局部配准吻合、局部动作似然正常），可整条计划已经系统性偏移——就像在长得一模一样的酒店走廊里，每个路口都能和记忆「对上」，但你其实已经走错了楼层。
>
> R69 的第二意见（FMA，流似然）仍然是**逐观测**的：它比较 o 与 o_cal 下的动作似然，只能发现「这一步不对劲」，发现不了「每一步都对、但整体在漂」。要捕捉这种**跨步累积、局部不可见**的失败，必须换一个观测量：不再是单步动作，而是**计划与配准的全局一致性**。
>
> 本轮两个灵感正好补上这一层：
> - **点云配准**给出 SE(3) 上的多假设结构——对称、部分重叠、无纹理都会让配准同时存在多个「自洽」的解；它天然是概率的、多模态的，而且会**自信地错**（RANSAC 锁死在错误对应集上，fitness 依然很高）。
> - **任务规划**给出「计划即图」的结构——长程计划可以写成一张**任务空间位姿图**（子目标为节点、技能与配准为边）；计划的好坏不只是「可行」，还要看这张图能不能**闭环**。
>
> 核心命题：**把「对齐」从一次估计升级为「计划—配准联合一致性」——计划是带几何承诺的位姿图，配准为它提供相对变换边；两者互相诊断，只有整张任务图可闭环时计划才被认证为可执行；不可闭环时只执行「认证前缀」，并把「补看 / 重访 / 换视角」升级为一个信息采集计划（reconnaissance plan），而不是 R69 的单次信息动作。** 命名 **PACT-RAS**（Plan–Alignment Consistency for Task execution, Risk-Adaptive Safety）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我是不是从一开始就站在了错误的世界里**」——R69 消解一步之内的歧义，R70 消解整条计划所在**参考系**的歧义。

## 0. 直觉与动机

**灵感 1（点云配准 → 不确定性长在 SE(3) 上，而且会自信地错）**
直觉：R69 把歧义看成动作空间里的几个模态；但机器人真正先要面对的是**「世界在哪」**。配准在三类场景里天然多解：对称物体（转 180° 一样）、部分重叠（只看半张桌子）、无纹理平面/长走廊（沿某方向完全退化）。这时配准输出的不是「一个变换」，而是 SE(3) 上的若干假设。更危险的是第三种失败——**错误锁定**：RANSAC / 深度配准在一组错误的对应上收敛，fitness 很高、内点率很高，却与另一路证据矛盾。这与 R69 的「幻影模态」同构，但发生在**几何层**：不是策略幻觉出一个动作，而是配准幻觉出一整个世界的位置。

**灵感 2（任务规划 → 计划就是一张带几何承诺的图）**
直觉：人类做长程任务时，计划不是一句句孤立指令，而是一串「我应该在哪、看到什么、然后去哪」的**空间承诺**。「去厨房拿杯子」隐含了「厨房在我以为的位置」「杯子在台面左端」「从当前朝向走过去不会穿墙」这些几何命题。把这些命题画出来，就是一张**任务空间位姿图**：节点是参考系（地图、机器人各子目标位姿、物体位姿），边是里程计、配准、技能各自给出的相对变换。于是「计划是否可行」被拆成两问——符号上可行吗？**这张图能闭环吗？** 后者正是点云配准的主场。

**灵感 3（互诊 → 单步不可见、全局可判的失败）**
直觉：R69 的 FMA 是「这一步的动作像不像这个观测该有的」。但若错误的参考系从计划一开始就成立，之后每一步的条件观测都会**自洽地**生成「像样」的动作——单步似然永远正常。这就像一直被蒙着眼牵着走：每一步脚下都平，但方向早错了。换一个量才看得见：**把各步的配准边接成环，看它闭不闭合**。局部误差可以逐点通过，全局误差却会在最后一个环上暴露。这是 R70 存在的根本理由：**没有任何逐观测检验能界定全局参考系误差**（引理 19）。

**灵感 4（信息动作 → 信息采集本身要「规划」，不能只「贪心」）**
直觉：R69 的 MINT 是单步贪心 VoI：看一次、问一次。但面对无纹理走廊这类**退化**，同一视角再看一万次也不会更确定（Fisher 信息在该子空间上是奇异的，引理 19/定理 19）——必须**换视角**。换视角不是一步，而是一小段计划：走到侧廊、回望、重访一个已知环路。于是「信息动作」升级为「信息采集计划」：在有限步数、有限绕行预算下最大化对 (计划分支, 参考系) 的联合熵下降。这把 R69 的 MINT 变成了一个**短程任务规划**问题，两个灵感在这里真正咬合。

**灵感 5（自洽可能是共谋 → 本轮必须正面定义的新威胁）**
直觉：一旦用「闭环一致」作为判据，就出现一个比 R69 更阴险的失败：**错误配准 + 错误计划可以互相印证**。地图在对称走廊里「折叠」了（两个不同地点被认成同一个），所有环都完美闭合，残差接近零，系统于是把「一致」当成「正确」，还盖上证书。R69 最怕「问错」；R70 最怕「**对上了**」——**一个全局自洽的错误地图，比一个明显不一致的地图更难发现，也更危险**。这就是本轮的威胁模型与最大风险，必须在定义层就写进去，而不是留到讨论节。

## 1. 形式化定义（增量：定义 310–324）

**定义 310（PACT-RAS 总览）** PACT-RAS = (TPG, MHR, PACC, JPRI, RPP, LECG, CPP, RAS-WM†)。五不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **侦察预算硬约束**：信息采集计划长度 ≤ B_recon、累计绕行位移 ≤ ε_recon、单位时间物理动作仍 ≤ 1，且每个采集动作过 C-RAS-WM 认证（继承 R69 定义 302）；
(iii) **全局一致性门**：绝不执行超过「认证计划前缀」CPP 的指令；未闭环的环不构成证据，只能作假设；
(iv) **环路证据纪律**：一个环要作为证据入图，需至少两个正交线索一致（几何 / 语义 / 时序），并通过反事实稳定性检验；单线索环一律降级为「假设」；
(v) **严格包含**：单步任务且配准单假设时，PACT-RAS 逐指令等价于 FLUID-RAS（故也包含 R68）。

**定义 311（任务空间位姿图 TPG）** 图 𝒢 = (V, E)，节点 V 为参考系（地图系、机器人各子目标位姿、物体位姿），边 E = E_odo ∪ E_reg ∪ E_skill。每条边 (i,j) 携带相对变换 T_ij ∈ SE(3) 与信息矩阵 Ω_ij；计划 π 是 𝒢 的一个有序子图（子目标链 + 支撑边）。任务残差 r_task 衡量子目标可达性与技能前提满足度；几何残差 r_geo 衡量图闭环误差。

**定义 312（多假设配准 MHR）** 对配准查询 q（源点云、目标地图、先验位姿），输出假设集 H(q) = {(T^{(j)}, w_j, fit_j, overlap_j)}_{j=1..K_T}。要求区分三类：
(a) **真歧义**：多个分离模态、重叠充分、模态间可分辨 ⇒ 可通过移动/重观测消解；
(b) **退化**：似然在某个 SE(3) 子空间上平坦（无纹理平面、长走廊、圆柱），Ω 秩亏或条件数爆炸 ⇒ 同视角不可消解，只能换视角；
(c) **错误锁定**：fit 高但对应集错误、与其他线索矛盾 ⇒ 需正交证据与反事实检验。
记模态熵 H_reg、模态最小间距 Δ_SE3、重叠率 o、信息矩阵条件数 κ(Ω)。

**定义 313（计划—配准一致性 PACC）** 在 TPG 上做鲁棒位姿图优化（switchable constraints / max-mixture），对每个环 l 得残差 r_l。计划 π 的一致性 C(π) = max_l ‖r_l‖_{Ω_l}；**π 可采纳 ⇔ 存在一个假设指派使 C(π) ≤ τ_loop**。把 C(π) 按环分解，得到「哪个环最可疑」。

**定义 314（联合计划—配准推断 JPRI）** 对计划分支 b 与变换 {T} 做联合 MAP：
min_{b,{T}} [ Σ_{skill∈b} c_skill + Σ_{reg} ρ(‖r_reg‖_{Ω}) + Σ_{task} ρ(‖r_task‖) ]，
其中 ρ 为鲁棒核。要点：**符号层选哪条计划、几何层选哪组变换，必须一起确定**；分开先规划再配准会把「计划期望」泄漏进配准，造成确认偏置（定义 322）。

**定义 315（侦察计划 RPP）** 信息动作从单个 g 提升为序列 G = (g_1,…,g_m)（侧移换视角 / 回望 / 重访已知环 / 轻触发语义探针），目标：
max_G [ H(π,T | o) − E_{y~p(·|G,o)} H(π,T | o,y) − c(G) ]，s.t. m ≤ B_recon、绕行 ≤ ε_recon。
这是 R69 单步贪心 VoI 的多步版本；在退化情形下（同视角 Fisher 信息奇异），单步 VoI 恒为零，只有 RPP 能产生正收益。

**定义 316（环路证据门 LECG）** 环 l 作为证据需三关：
(a) 几何：fit、overlap、SE(3) 间距达标；
(b) 语义：地标/物体身份独立匹配（不依赖同一配准器）；
(c) 时序：与里程计/上一环的可行性一致。
再加**负证据**：必须验证「按该假设，本应不匹配的区域确实不匹配」，否则判为确认偏置。定义线索独立图与共谋分 ρ_coll；ρ_coll 超阈值 ⇒ 所有环降级为假设。

**定义 317（认证计划前缀 CPP）** CPP(π) = 最长的前缀，使得在**所有合理假设指派**下（最坏情形）该前缀的 TPG 都满足 C ≤ τ_loop。只执行 CPP；CPP 之后一律视为未认证，触发重规划或侦察。这是 R69 两级保守（λ 退避）在**计划粒度**上的对应物。

**定义 318（计划级保守退避与 Horizon Bonus）** 若全局一致性在视界 H 上被认证，则允许在**漂移被环残差界定**的前提下按略小的逐步 λ 执行（Horizon Bonus，对应 R69 的 resolution bonus）；若未认证，则截断到 CPP，且逐步 λ = λ_floor(U_ale + U_epi)（继承 R69 定义 307）。边界：N=1 且 |H(q)|=1 ⇒ 与 R69 逐指令相同。

**定义 319（环路稳定性 / 反事实检验）** 对候选环做扰动重解（删特征、换随机种子、偏移初值、遮挡一部分点云）；若最优指派发生实质翻转，则该环 **fragile**，稳定性分 s_loop 低，不得作为证据。稳定性只在「可扰动且解会变」的意义上可测——它检测的是**脆弱的一致**，不是**正确的一致**（区别见引理 21）。

**定义 320（退化—歧义二维分类）** 按 (动作级 / 参考系级) × (aleatoric / epistemic) 分四格：
| | aleatoric | epistemic |
|---|---|---|
| 动作级 | 执行噪声（R68 的 U_ale） | 动作模态歧义（R69 的 U_epi） |
| 参考系级 | 里程计累积噪声 | **计划/配准的帧级歧义（本轮新增）** |
其中参考系级 epistemic 又分**可辨歧义**（换视角可解 ⇒ RPP）与**退化**（当前视角不可解 ⇒ 必须换视角，否则 CPP 截断）。

**定义 321（证书 J_PACT）** J_PACT = (J_FLUID, plan_graph_residual_p95, loop_stability_min, cpp_len, recon_budget_used, collusion_score, pact_ver)。Valid ⇔ Valid(J_FLUID) ∧ C(π_CPP) ≤ τ_loop ∧ 环路证据纪律满足 ∧ CPP 未被越过。

**定义 322（计划—配准威胁集 ℰ_planreg）** 错误闭环 / 感知混叠（对称走廊、重复房间）/ **计划条件化确认偏置**（配准被期望计划带偏，二者循环印证）/ 地图投毒 / 动态场景假地标 / 规划器幻觉出不可行子图。并入 AIC：ℰ_PLANREG = ℰ_FLUID × ℰ_planreg。

**定义 323（PG-Auditor）** 扩展 VQAuditor-I：审计「环是否单线索被采纳」「配准是否被计划条件化（循环论证）」「CPP 是否被越过」「侦察是否超预算」「共谋分是否越界」，结论回灌 AuditBuf，成为下一轮 LECG 与 RPP 的成本/风险先验。

**定义 324（滚动时序与重规划触发）** 增量维护 TPG（iSAM2 式增量优化）；当 C(π) 越过 τ_loop、最优假设指派改变、或 MHR 报退化时触发重规划/侦察；所有重规划在 CPP 边界内完成，保证控制连续（继承 R68 定理 15）。

# IP-264 TPG：任务空间位姿图（复用 R69 的 z_t 与技能接口）
class TaskPoseGraph:
    def add_node(self, frame): ...
    def add_edge(self, i, j, T, Omega, kind):      # kind ∈ {odo, reg, skill}
        ...
    def optimize(self):                            # 增量（iSAM2 风格），鲁棒核
        return robust_pose_graph(self.V, self.E)
    def loop_residuals(self):                      # 每个环的归一化残差
        return {l: norm(r) for l, r in closed_loops(self.E)}

# IP-265 MHR：多假设配准（不是取 argmax，而是保留 SE(3) 模态）
def register_multi(src, dst, prior, K_T=4):
    hyps = []
    for seed in range(K_T):
        T, fit, overlap, corr = register(src, dst, prior, seed)
        if valid(fit, overlap): hyps.append((T, fit, overlap, corr))
    return filter_modes(hyps)                      # 保留分离模态 + 退化标记

# IP-266 PACC：计划—配准一致性（最坏指派下的最大环残差）
def plan_alignment_consistency(graph, pi, tau_loop):
    best = INF
    for assign in hypothesis_assignments(graph, pi):   # 合理指派（可剪枝）
        G = graph.with_assignment(assign).subgraph(pi)
        best = min(best, max(G.loop_residuals().values()))
    return best                                   # C(pi) = best（越小越一致）

# IP-267 JPRI：计划分支与配准假设联合 MAP（防计划条件化偏置）
def joint_plan_registration(branches, hyps, robust_rho):
    return argmin((b, Ts),
                  task_cost(b) + sum(robust_rho(reg_resid(b, Ts)))
                  for b in branches)

# IP-268 RPP：把「补看」升级为一小段信息采集计划
def reconnaissance_plan(graph, pi, budget, tau_loop):
    best = None
    for G in candidate_recon_sequences(graph, pi, max_len=budget.m):
        if not budget.allow(G):                 continue
        if not all(c_ras_wm.certify_info(g, graph) for g in G): continue
        gain = H_plan_reg(graph, pi) - E_H_after(graph, pi, G)
        score = gain - cost(G)
        if best is None or score > best.score: best = (G, score)
    return best if best and best.score > 0 else None    # 无利可图 → 只用 CPP

# IP-269 LECG：环路证据门（正交线索 + 负证据 + 共谋分）
def loop_evidence_gate(loop):
    cues = [geom_ok(loop), semantic_ok(loop), temporal_ok(loop)]
    neg  = negative_evidence_ok(loop)                   # 本应不匹配处确实不匹配
    rho  = collusion_score(loop)                        # 线索独立性
    stability = counterfactual_stability(loop)
    if sum(cues) >= 2 and neg and rho < TAU_COLL and stability > TAU_STAB:
        return Evidence(loop)
    return Hypothesis(loop)                             # 单线索 → 只作假设

# IP-270 CPP：认证计划前缀（最坏指派下仍闭环的最长前缀）
def certified_prefix(graph, pi, tau_loop):
    k = 0
    for t in range(1, len(pi) + 1):
        if worst_case_consistency(graph, pi[:t]) <= tau_loop:
            k = t
        else:
            break
    return pi[:k]

# IP-275 主闭环（继承 R69，仅在「参考系」层插入 PACT 层）
def PACT_RAS_round(M, obs):
    z, o = M.mtm.forward(...)                     # R69 一次前向
    # 1) 单步：R69 的局部消歧（动作模态）
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    # 2) 帧级：多假设配准 + 入图（不取 argmax）
    hyps = M.mhr.register_multi(o.cloud, M.map, M.prior)
    for h in hyps:
        M.tpg.add_edge(M.last_frame, M.cur_frame, h.T, h.Omega, kind='reg')
    # 3) 计划—配准一致性（全局，R69 没有的观测量）
    pi = M.planner.propose(z, M.tpg)
    C  = M.pacc.consistency(M.tpg, pi)            # 最坏指派下最大环残差
    # 4) 不一致 → 先侦察（换视角）；仍不闭合 → 截断到 CPP + R69 保守
    if C > TAU_LOOP:
        G = M.rpp.reconnaissance_plan(M.tpg, pi, M.budget)   # 多步、可换视角
        if G is not None:
            M.execute_recon(G)                            # 过 C-RAS-WM 认证
            C = M.pacc.consistency(M.tpg, pi)
    cpp = M.cpp.certified_prefix(M.tpg, pi, TAU_LOOP)
    # 5) 执行：只走 CPP；Horizon Bonus 仅在全局一致时生效
    lam = max(M.efs.risk_scale(...),
              lam_floor(U_ale + (U_epi if C > TAU_LOOP else 0.0)))
    if C <= TAU_LOOP:
        lam = lam * M.horizon_bonus(cpp, C)               # 漂移被环残差界定
    mode = select_mode(modes, U_epi, lam)
    k    = M.c_ras_wm.certified_prefix(M.ach.propose(cpp, M.vista.H), ...)
    # 6) 审计 + 证书
    M.pg_auditor.submit_async(cpp, C, M.lecg.last(), M.rpp.last_budget_used)
    return k, lam, mode, cpp, J_PACT(...)

## 3. 推导

**引理 19（局部一致不能界定全局参考系）** 设每步配准误差 ‖δT_t‖ ≤ ε_step，R69 式逐观测检验的阈值 > ε_step。则对任意 N 存在一条任务，使每一步都通过逐观测检验，而参考系误差满足 ‖E_N‖ ≥ c·N·ε_step（系统性偏置）或 ≥ c·√N·ε_step（随机游走）。故**只靠逐观测/逐动作的检验，无法给出全局参考系误差的任何上界**；必须引入跨步的环约束（定义 313）。这是 R70 相对 R69 的必要性，而非风格差异。

**引理 20（正交环路证据抑制错误闭环）** 设单线索错误接受率 δ，线索间欺骗相关 ρ_coll < 1，负证据过滤再排除比例 ε_neg，则「≥2 线索一致 + 负证据 + 稳定性」下的错误闭环率 ≤ δ·ρ_coll + ε_neg；而单线索接受率 ≈ δ。系：RANSAC 的「高 fitness」只说明几何自洽（δ），不说明正确；LECG 把「配上了」从证据降格为假设，除非多路独立确认。

**引理 21（自洽 ≠ 正确 / 折叠不可辨）** 存在两个世界 W 与 W′（感知混叠，如对称走廊把地点 A、B 认成同一处），使同一组配准假设在 W 与 W′ 上诱导出**完全相同**的 TPG 环残差图样；但按该计划执行，终点的物理位置不同。形式地：位姿图残差只约束**成对相容性**，在图的「折叠」（商映射、非单射识别）下保持不变，故 C(π) ≤ τ_loop 是正确性的**必要非充分**条件。要排除折叠，必须引入**单射性/可区分性见证**：独立的语义身份、外源线索，或能观察到「本应不同却相同」的主动侦察。系：任何纯内部的「一致性检验」都有系统盲区——这正是本轮最大风险的形式化。

**定理 18（PACT 严格包含 FLUID/R68）** 在 A99–A101（环残差有界、MHR 假设覆盖真值、侦察动作安全可认证）下：单步任务且配准单假设时，PACT 与 FLUID 逐指令相同；一般情形下 PACT 要么与 FLUID 相同，要么把执行截断到 CPP、并在不一致时并入未消解 epistemic 的 λ_floor，故任意状态期望风险 ≤ FLUID。全局一致且侦察成功时获得 Horizon Bonus（更不保守但**不更低安全**）。

**定理 19（退化下侦察的必要性）** 若配准的信息矩阵在某子空间上奇异（退化），则同一视角重复观测的 Fisher 信息在该子空间上不增加，任何「多看几帧」的策略都无法降低该子空间方差；只有改变视角（RPP 的换视角动作）才引入新信息。若预算内无法换到可解视角，则唯一安全选择是截断到 CPP。⇒ 「信息采集」必须被**规划**，单步贪心 VoI 在退化情形下恒为零（与引理 19 呼应）。

## 6. 本轮最大风险

**一句话**：PACT-RAS 把「闭环一致」当作可执行性的证据，但**自洽不等于正确**——在感知混叠的世界里，错误配准与错误计划可以互相印证、折叠出一张完美闭环的假地图（引理 21），系统于是把「一致」洗白成「已认证」，主动侦察也会因为「地图已经闭合、无处可疑」而不再被触发；**对上，比没对上更危险**。

**次级风险与缓解**：
1. **计划条件化确认偏置**（配准被期望计划带偏，二者循环印证）→ JPRI 联合推断 + LECG 负证据 + 确定性扰动检验；
2. **单线索错误闭环** → 定义 316 三关 + 反事实稳定性（定义 319）+ 引理 20 上界；
3. **退化被误当歧义**（同视角无限重看）→ 定义 312 三分类 + 定理 19 强制换视角或截断；
4. **实时预算被增量图与侦察击穿** → iSAM2 增量 + 候选剪枝 + 侦察一次性预算；
5. **规划器幻觉出不可行子图** → JPRI 拒斥 + CPP 截断 + PG-Auditor 回灌成本先验。

# IP-265 MHR：保留 SE(3) 多假设（不取 argmax）
def register_multi(src, dst, prior, K_T=4):
    hyps = [register(src, dst, prior, seed=s) for s in range(K_T)]
    return filter_modes([h for h in hyps if valid(h.fit, h.overlap)])

# IP-266 PACC：最坏合理指派下的最大环残差
def consistency(graph, pi, tau_loop):
    return min(max(graph.with_assignment(a).subgraph(pi).loop_residuals().values())
               for a in hypothesis_assignments(graph, pi))

# IP-267 JPRI：计划分支 × 配准假设联合 MAP
def joint_plan_registration(branches, hyps, rho):
    return argmin(lambda b, Ts: task_cost(b)
                  + sum(rho(reg_resid(b, Ts))), branches, hyps)

# IP-268 RPP：多步信息采集规划（换视角/重访）
def reconnaissance_plan(graph, pi, budget):
    best = None
    for G in candidate_recon_sequences(graph, pi, max_len=budget.m):
        if not budget.allow(G): continue
        if not all(c_ras_wm.certify_info(g, graph) for g in G): continue
        score = (H_plan_reg(graph, pi) - E_H_after(graph, pi, G)) - cost(G)
        if best is None or score > best.score: best = (G, score)
    return best if best and best.score > 0 else None      # 无利可图 → 只用 CPP

# IP-269 LECG：环路证据门（正交 + 负证据 + 共谋 + 稳定性）
def loop_evidence_gate(loop):
    cues = [geom_ok(loop), semantic_ok(loop), temporal_ok(loop)]
    if (sum(cues) >= 2 and negative_evidence_ok(loop)
            and collusion_score(loop) < TAU_COLL
            and counterfactual_stability(loop) > TAU_STAB):
        return Evidence(loop)
    return Hypothesis(loop)                              # 单线索只作假设

# IP-270 CPP：最坏指派下仍闭环的最长前缀
def certified_prefix(graph, pi, tau_loop):
    k = 0
    for t in range(1, len(pi)+1):
        if worst_case_consistency(graph, pi[:t]) <= tau_loop: k = t
        else: break
    return pi[:k]

## 4. 推导

**引理 19（局部一致不能界定全局参考系）** 每步误差 `≤ε_step`、逐观测检验阈值 `>ε_step` 时，存在任务使每步都通过而参考系误差 `≥c·N·ε_step`（系统偏置）或 `≥c·√N·ε_step`（随机游走）。⇒ 逐观测/逐动作检验无法给出全局误差上界，必须引入跨步环约束。这是 R70 的必要性。

**引理 20（正交环路证据抑制错误闭环）** 单线索错误接受率 δ、线索欺骗相关 `ρ_coll<1`、负证据排除 `ε_neg`，则「≥2 线索 + 负证据 + 稳定性」下错误闭环率 `≤δ·ρ_coll+ε_neg`；单线索接受率 `≈δ`。系：RANSAC 高 fitness 只证几何自洽，不证正确。

**引理 21（自洽 ≠ 正确 / 折叠不可辨）** 存在感知混叠的世界 `W,W′`（对称走廊把 A、B 认成同一处），使同一组配准假设在两者上诱导**完全相同**的 TPG 环残差图样，但执行终点物理位置不同。位姿图残差只约束成对相容性，在图的「折叠」（商映射、非单射识别）下不变 ⇒ `C(π)≤τ_loop` 是正确性的**必要非充分**条件；排除折叠需单射性/可区分性见证（独立语义身份、外源线索，或能观察到「本应不同却相同」的主动侦察）。系：任何纯内部一致性检验都有系统盲区——本轮最大风险的形式化。

**定理 18（PACT 严格包含 FLUID/R68）** A99–A101 下：单步且配准单假设时 PACT ≡ FLUID；一般情形 PACT 要么与 FLUID 相同，要么截断到 CPP 并在不一致时并入未消解 epistemic 的 `λ_floor`，故任意状态期望风险 ≤ FLUID。全局一致且侦察成功时获 Horizon Bonus（更不保守但不更低安全）。

**定理 19（退化下侦察的必要性）** 配准信息矩阵在子空间奇异时，同视角重复观测的 Fisher 信息在该子空间不增加，任何「多看几帧」都无法降方差；只有换视角（RPP）引入新信息。预算内无法换到可解视角 ⇒ 唯一安全选择是截断 CPP。⇒ 信息采集必须被**规划**，单步贪心 VoI 在退化下恒为零。

## 7. 本轮最大风险

**一句话**：PACT-RAS 把「闭环一致」当作可执行性的证据，但**自洽不等于正确**——在感知混叠的世界里，错误配准与错误计划可以互相印证、折叠出一张完美闭环的假地图（引理 21），系统于是把「一致」洗白成「已认证」，主动侦察也会因「地图已经闭合、无处可疑」而不再触发；**对上，比没对上更危险**。

**次级风险与缓解**：计划条件化确认偏置（JPRI 联合推断 + LECG 负证据 + 扰动检验）；单线索错误闭环（三关 + 反事实稳定性 + 引理 20 上界）；退化误当歧义（定义 312 三分类 + 定理 19 强制换视角/截断）；实时预算（iSAM2 增量 + 候选剪枝 + 侦察一次性预算）；规划器幻觉（JPRI 拒斥 + CPP 截断 + PG-Auditor 回灌）。
