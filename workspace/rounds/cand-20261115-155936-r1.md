# 第 8 轮（新灵感循环第 1 轮；本轮灵感：「评测指标」×「全身控制」）

> **基线**：第 7 轮 MetricVoiceGauge-OTL-GC-ER（定义 493–529；引理 73–76；实验 E513–E525）。
> 本轮纪律：**评测指标是仪器，不是记分牌；全身控制是测量基准，不是被优化对象**。v8 新通道只允许“收紧”系统可行集，不允许“放宽”；任一 v8 模块不可用 ⇒ 单跳退回 v7，v7 再不可用 ⇒ 退回 v6。

## 0. 直觉与动机

**灵感 1（评测指标 → 从“记分牌”到“校准证书”）**
直觉：v7 的 OTL 直接拿指标满足率去调阈值 τᵢ，ER 又拿情感去改奖励权重。这在工程上很自然，却正好踩中 Goodhart 定律：**一旦度量变成目标，它就不再是好度量**。一个可信的评测指标至少要通过三道体检：
1. **接地（grounding）**：数值必须由已标定的物理传感量算出，并带不确定度区间，而不是由控制器“自报”；
2. **可追溯（provenance）**：从原始传感器到指标值的整条计算链可审计，任何控制意图变量不得混入；
3. **抗博弈（anti-gaming）**：控制器不能通过改变自身行为“刷高”指标而不改变真实物理状态。
现有具身评测大多只报成功率/步骤分，缺少“这个数字凭什么可信”的证书。核心创新：**指标接地证书（Metric Grounding Certificate, MGC）** 与 **指标诚实性审计（Metric Integrity Auditor, MIA）**。

**灵感 2（全身控制 → 约束求解器自带“体检报告”）**
直觉：全身控制（WBC）在每个控制周期解一个带约束的（分层）二次规划：动力学、接触摩擦锥、关节/力矩限位、自碰撞、支撑多边形。它的**松弛变量与对偶变量**其实已经在回答“离摔倒/打滑/撞到自己还有多远”。这些量由执行动作的同一套动力学/接触模型给出，物理接地、难以事后伪造，天然适合当评测指标的“尺子”。核心创新：**全身可行性证书（Whole-Body Feasibility Certificate, WBFC）**，把 QP 的可行性、活跃约束、各类裕度（ρ_bal, ρ_contact, ρ_limit, ρ_self）对外签发。

**交叉直觉（仪器互校：用 WBC 的可行性证据给指标做校准）**
把两个灵感拧在一起：**MetricCert-WBC（MC-WBC，可证评测的全身控制）**。它把系统拆成四个面：
- **测量面 Π_m**：传感快照 → 带 provenance、不确定度、可接受谓词的指标；
- **认证面 Π_c**：WBC 求解 → 全身可行性证书（含裕度与活跃约束）；
- **控制面 Π_u**：分层全身控制（安全 > 平衡/接触 > 任务 > 姿态 > 风格）；
- **适应面 Π_a**：v7 的 OTL/ER，只能在 Π_m 与 Π_c 同时盖章时开门。
关键在于**双模型互证（Cross-Model Witness, CMW）**：用相互独立的降阶模型（线性倒立摆 + 力传感接触一致性）去复核全阶 WBC 证书。两个模型都同意，才认为“尺子没坏”；不同意就作废证书，退回保守。这样，v7 的最大风险“过度适应导致退化频率不稳”被改写为**证据门控的、只降不升的单调退化管理**：评测不再驱动系统去追分，而是决定“此刻有没有资格自适应”。

## 1. 研究问题（轮次升级版）

- **Q1（指标接地与可信度）**：如何为全身操作定义一组“物理接地 + 不确定度可校准 + provenance 可审计”的评测指标 m = (id, v, unit, U, prov, A)，使每个上报数字都附带可验证的接地证书，且证书覆盖率可预注册？
- **Q2（评测-控制解耦）**：如何形式化保证测量面只读物理状态、控制面无法写入或“刷高”指标，并让评测对系统的影响只表现为对可行集的**交（收紧）**而非并（放宽）？
- **Q3（全身可行性作为指标与门控）**：如何从分层 WBC 的 QP 解中提取平衡/接触/限位/自碰撞裕度，与独立降阶模型互证，并把它们作为 v7 OTL/ER 的适应门控与单调退化阶梯，使任一 v8 模块失效都平滑退回 v7？

## 2. 设计原则（在 P7–P9 基础上升级为 P10–P12）

**P10 指标接地证书（Metric Grounding Certificate, MGC）**
每个指标不是裸数字，而是五元组：
```
m = (id, v, unit, U, prov, A)
C_m = (hash(prov), calibration_version, α, U, A(m), expiry)
```
其中 `prov` 是从传感器通道到指标值的 DAG（禁止出现控制意图/奖励/阈值节点），`U` 是覆盖率 ≥ 1−α 的校准区间（conformal），`A(m)` 是无需知道控制器意图即可计算的可接受谓词。证书过期、标定过期或 provenance 含控制节点 ⇒ 指标记为 untrusted。

**P11 评测-控制解耦（Separation of Evaluation and Control, SEC）**
测量面 `Π_m` 的输入只允许是物理快照 `S = (q, q̇, τ_meas, contacts, perception)`，禁止读入 `A_ctrl`、reward、τᵢ。评测对控制的唯一合法影响是**收缩映射**：
```
A_final = A_ctrl ∩ A_eval(C_m, W)
```
证书越保守，`A_final` 只会越小（单调性）。实现上用独立进程 + 只读共享内存 + 签名，控制器进程无写权限。

**P12 全身可行性阶梯（Whole-Body Feasibility Ladder, WBFL）**
分层 WBC 的每个优先级层都输出裕度向量
```
ρ = (ρ_bal, ρ_contact, ρ_limit, ρ_self, ρ_task)
```
并配一个预注册阈值向量 `ρ^req`。当某层裕度低于阈值，沿阶梯**只降一级**（L4 风格 → L3 姿态/能耗 → L2 操作任务 → L1 接触/限位 → L0 平衡/安全），并加驻留时间（dwell time）与滞回，禁止在两级间抖动。禁止反向升级，除非重新通过全部证书。

## 3. 与基线的接口（如何退化）

- MGC / MIA / WBFC / CMW **不可用**（模块缺失、异常、超时）⇒ 完全旁路 v8，逐字运行 v7；
- 证书**存在但不可信或不可行** ⇒ 冻结 v7 的自适应（τᵢ 保持上一已认证值、β 冻结），并沿 P12 阶梯降级——这比 v7 更保守，属于合法精化；
- v7 的 OTL / GCT / ER 失效 ⇒ 按 v7 声明退回 v6；
- **禁止反向**：评测通道永远不能放宽 v7 已认证的 M₀/M₁，也不能单方面提升任务层级。

## 4. 预期贡献

1. **指标接地证书 MGC**：把“评测指标”从结果数字变成带 provenance、不确定度与可接受谓词的一等对象，给出覆盖率与可审计性判据；
2. **评测-控制解耦 SEC**：形式化“评测只能交、不能并”的单调限制关系，使 Goodhart 式刷分在接口层不可表达；
3. **全身可行性证书 WBFC + 双模型互证 CMW**：把 WBC 的松弛/对偶证据与独立降阶模型交叉校验，产出物理接地的平衡/接触/限位/自碰撞裕度；
4. **指标门控适应 MGA 与评测退化阶梯 EDL**：给 v7 的在线自适应加“证据门”，把退化从“频率不稳”变为“只降不升的阶梯”；
5. 可复现的**评测基准套件 EBS**：E526–E542 覆盖不确定度覆盖、反博弈、证书健全性、跨平台与 sim-to-real。

## 5. 本轮最大风险

**一句话**：WBFC 与 MGC 都建立在“动力学/接触模型 + 传感器标定正确”的前提上——若模型系统性偏差（如支撑多边形过于乐观、摩擦系数高估），系统会以一份自洽、可审计却与真实物理脱节的证书，系统性地“自信地犯错”，而双模型互证也可能因共享同一错误先验而同时失效。

**新增定义 530（全身评测快照 Whole-Body Evaluation Snapshot）**
```
S_t = (q_t, q̇_t, τ_t^meas, c_t, o_t, t)
```
其中 `q ∈ R^n` 为全自由度配置，`c_t` 为接触集（足底开关、腕部 F/T、接触事件），`o_t` 为感知。**禁止**快照包含控制意图 `a_t`、奖励 `r_t`、阈值 `τᵢ`，这是解耦的输入侧约束。

**新增定义 531（物理接地指标 Physically Grounded Metric）**
```
m = (id, v, unit, U, prov, A)
v = f(prov),  prov ⊆ 已标定传感通道
U = [v − u⁻, v + u⁺],  P(v* ∈ U) ≥ 1 − α
g(m) = 1 ⇔ (v 可微/Lipschitz) ∧ (U 覆盖率达标) ∧ (A 仅依赖 m) ∧ (prov 无控制节点)
```
`g(m)=1` 才称为“接地指标”。

**新增定义 532（指标接地证书 Metric Grounding Certificate）**
```
C_m = (h, cal_ver, α, U, A, t_exp, sig),  h = hash(prov)
valid(C_m) ⇔ sig 验签 ∧ t < t_exp ∧ h 与当前 prov 一致
             ∧ calibration(cal_ver) 未过期 ∧ prov ∩ CtrlIntent = ∅
```
任一条件失败 ⇒ `C_m = ⊥`，该指标为 untrusted。

**新增定义 533（评测-控制解耦 Evaluation–Control Separation, SEC）**
测量面与控制面满足：
```
Π_m : S_t ↦ {C_m},          Π_m 不可读 a_t, r_t, τᵢ
A_eval(C) = { a : ∀ m ∈ C, A(m(a)) = true }
A_final   = A_ctrl ∩ A_eval(C)
```
单调性要求：若 `C' ⪯ C`（证书更保守），则 `A_eval(C') ⊆ A_eval(C)`，从而 `A_final(C') ⊆ A_final(C)`。实现上 `Π_m` 为独立进程，只读共享内存，控制器进程无写权限。

**新增定义 534（全身可行性证书 Whole-Body Feasibility Certificate）**
分层 WBC 在第 k 层解
```
x_k* = argmin_x ½ xᵀ H_k x + g_kᵀ x
s.t.   A_j x ≤ b_j  (j ∈ 本层约束)
       A_h x = b_h  (h < k 的高优先级约束已冻结)
```
签发
```
W = (feas, x*, s, λ, Ac, ρ)
s_j = b_j − (A_j x*)_j,   λ_j ≥ 0,   Ac = {j : s_j ≤ ε_active}
feas ⇔ max_j (−s_j) ≤ ε_tol
ρ_j = s_j / ‖A_j‖
```
其中松弛/对偶来自求解器本身，不额外求解；`ρ_j` 是归一化约束裕度。

**新增定义 535（平衡裕度 Balance Margin）**
```
ξ_t = c_t + ċ_t / ω,   ω = √(g / z_c)
P_t^min = P_t ⊖ B(0, r_unc)        # 对支撑多边形做不确定度腐蚀
ρ_bal = sd(ξ_t, P_t^min)           # 有符号距离，内正外负
```
`r_unc` 由足底接触估计与标定给出；腐蚀保证 `ρ_bal` 是真实裕度的保守下界。

**新增定义 536（接触力锥裕度 Contact Wrench Margin）**
对每个接触 i 的力旋量 `w_i = (f_i, m_i)`，线性化摩擦锥/支撑域约束 `F_i w_i ≤ h_i`：
```
ρ_contact,i = min_j (h_ij − F_ij w_i) / ‖F_ij‖
ρ_contact   = min_i ρ_contact,i
```
正的 `ρ_contact` 表示全部接触仍在保守摩擦锥与支撑域内。

**新增定义 537（双模型互证 Cross-Model Witness, CMW）**
```
ρ^a = WBFC 的全阶裕度
ρ^b = 降阶模型裕度（LIPM 的 ρ_bal^b + 力传感接触一致性 ρ_contact^b）
Δ_CMW = max_j |ρ^a_j − ρ^b_j| / scale_j
CMW_ok ⇔ Δ_CMW ≤ δ_CMW
```
两模型使用**不同的建模假设**（全阶 QP vs 倒立摆+实测力）；不一致即吊销 WBFC。

**新增定义 538（指标诚实性 Metric Integrity）**
影子评测器只用 `S_t` 重算指标得 `m'`；反事实重放在固定物理快照下改变控制器内部状态（奖励/意图/阈值）再读取上报值：
```
d_impl = |v − v'| / δ_i
d_leak = max_{a, a'} |Report(a) − Report(a')| / δ_l   (S_t 固定)
I(m) = clip(1 − max(d_impl, d_leak), 0, 1)
honest(m) ⇔ I(m) ≥ 1 − δ_g
```

**新增定义 539（指标门控适应 Metric-Gated Adaptation, MGA）**
```
Gate_m = ∏_{m ∈ M_OTL∪ER} [valid(C_m) ∧ honest(m)]
Gate_w = [W.feas ∧ CMW_ok ∧ ρ_bal ≥ ρ^req_bal ∧ ρ_contact ≥ ρ^req_contact
          ∧ ρ_limit ≥ ρ^req_limit ∧ ρ_self ≥ ρ^req_self]
若 Gate_m ∧ Gate_w：
    τᵢ(t+1), β(t+1) ← v7 的 OTL/ER 正常更新
否则：
    τᵢ(t+1) ← τᵢ(t),  β(t+1) ← β(t)     # 冻结，不重置为基准
    并调用 EDL 只降一级
```
模块**不可用**时不是冻结，而是旁路（见退化声明），以保证与 v7 的逐字等价。

**新增定义 540（评测退化阶梯与闭环不变式 Evaluation Ladder & Invariant）**
层级 `L0 ⊏ L1 ⊏ L2 ⊏ L3 ⊏ L4`：
```
L0 平衡/安全   L1 接触/限位   L2 操作任务   L3 姿态/能耗   L4 风格（含 v7 ER）
```
每个 `L_k` 配预注册阈值 `ρ^req_k`。降级算子 `D` 在 `ρ^L_k < ρ^req_k` 时输出 `L_{k−1}`，并满足驻留 `τ_d` 与滞回 `h`。闭环不变式：
```
Φ_v8 = SEC ∧ (不可用 ⇒ v7 逐字等价) ∧ (降级有限、单调、无 Zeno 振荡)
```

## 2. 形式化定义（要点对照）

**定义 530–540 摘要**：
1. 530 定义“能看什么”（快照不含意图），是解耦的 **输入约束**；

from dataclasses import dataclass
import hashlib

# IP-351/352 MetricProvenanceGraph + GroundingCertificate
@dataclass(frozen=True)
class Metric:
    id: str
    value: float
    unit: str
    interval: tuple          # (lo, hi), conformal
    prov: tuple              # 有序叶节点 (sensor_id, cal_ver, digest)
    predicate: str           # 可接受谓词，仅依赖 measure

class ProvenanceGraph:
    FORBIDDEN = {"ctrl_intent", "reward", "tau_i", "policy_logit"}
    def build(self, sensor_leaves, op_chain):
        names = {n for n, _ in sensor_leaves}
        if names & self.FORBIDDEN:
            raise ValueError("控制意图不得进入指标 provenance")
        return tuple(sorted(sensor_leaves))

    def digest(self, prov):
        h = hashlib.sha256()
        for sensor_id, cal_ver, dg in prov:
            h.update(f"{sensor_id}:{cal_ver}:{dg}".encode())
        return h.hexdigest()

@dataclass(frozen=True)
class GroundingCert:
    h: str
    cal_ver: str
    alpha: float
    interval: tuple
    predicate: str
    expires_at: float
    sig: str

class MetricGroundingAuthority:
    def __init__(self, cal_db, clock, signer):
        self.cal_db, self.clock, self.signer = cal_db, clock, signer
        self.graph = ProvenanceGraph()

    def certify(self, m: Metric, alpha=0.05):
        prov = self.graph.build(m.prov, op_chain=None)
        h = self.graph.digest(prov)
        cal_ok = all(self.cal_db.fresh(s, v) for s, v, _ in prov)
        if not cal_ok:
            return None
        body = (h, m.id, m.interval, m.predicate, self.clock.now() + 1.0)
        return GroundingCert(h=h, cal_ver=str(prov), alpha=alpha,
                             interval=m.interval, predicate=m.predicate,
                             expires_at=body[-1], sig=self.signer.sign(body))

# IP-353 MetricIntegrityAuditor
class MetricIntegrityAuditor:
    def __init__(self, shadow_evaluator, delta_i=0.02, delta_l=0.02, delta_g=0.05):
        self.shadow = shadow_evaluator   # 只读 S_t 的独立实现
        self.delta_i, self.delta_l, self.delta_g = delta_i, delta_l, delta_g

    def audit(self, S_t, reported, controller_view):
        m_shadow = self.shadow.evaluate(S_t)
        d_impl = abs(reported.value - m_shadow.value) / max(self.delta_i, 1e-9)
        # 反事实：固定 S_t，只改控制器内部意图/奖励，观察上报值是否被拉动
        vals = []
        for fake_intent in controller_view.counterfactual_intents():
            vals.append(self.shadow.report_with_intent(S_t, fake_intent))
        d_leak = (max(vals) - min(vals)) / max(self.delta_l, 1e-9) if vals else 0.0
        I = max(0.0, min(1.0, 1.0 - max(d_impl, d_leak)))
        return I, (I >= 1.0 - self.delta_g)

# IP-354/355 WholeBodyFeasibilityCert + CrossModelWitness
@dataclass
class WBCert:
    feasible: bool
    x: object
    slacks: dict
    duals: dict
    active: set
    margins: dict

class WholeBodyFeasibilityCert:
    def __init__(self, eps_tol=1e-4, eps_active=1e-3):
        self.eps_tol, self.eps_active = eps_tol, eps_active

    def extract(self, hqp):
        x, slacks, duals = hqp.solve_hierarchical()
        feasible = max((-s for s in slacks.values()), default=0.0) <= self.eps_tol
        margins = {j: slacks[j] / hqp.norm(j) for j in slacks}
        active = {j for j, s in slacks.items() if s <= self.eps_active}
        return WBCert(feasible, x, slacks, duals, active, margins)

class CrossModelWitness:
    def __init__(self, lipm, contact_checker, delta_cmw=0.15):
        self.lipm, self.contact_checker, self.delta_cmw = lipm, contact_checker, delta_cmw

    def check(self, S_t, wbcert):
        rho_b = {**self.lipm.margins(S_t), **self.contact_checker.margins(S_t)}
        gaps = [abs(wbcert.margins[k] - rho_b[k]) / rho_b["scale_" + k]
                for k in rho_b if not k.startswith("scale_")]
        d = max(gaps, default=0.0)
        return d <= self.delta_cmw, d

# IP-356 EvaluationLadder
class EvaluationLadder:
    LEVELS = ["L0", "L1", "L2", "L3", "L4"]
    def __init__(self, req, dwell=0.3, hysteresis=0.02):
        self.req, self.dwell, self.hyst = req, dwell, hysteresis
        self.level = "L4"
        self.last_change = None

    def descend(self, margins, now):
        for k in reversed(range(len(self.LEVELS))):
            name = self.LEVELS[k]
            if self.level == name:
                if margins[name] < self.req[name]:
                    if self.last_change is None or now - self.last_change >= self.dwell:
                        self.level = self.LEVELS[max(0, k - 1)]
                        self.last_change = now
                return self.level
        return self.level

# IP-357 MetricGatedAdapter
class MetricGatedAdapter:
    def __init__(self, otl, er, gates):
        self.otl, self.er, self.gates = otl, er, gates

    def update(self, metrics, state):
        gm = self.gates.metric_gate_ok(metrics)
        gw = self.gates.wbc_gate_ok(state)
        if gm and gw:
            self.otl.update(metrics)
            self.er.update(state)
            return "adaptive"
        # 冻结：保留上一已认证值，不重置
        return "frozen"

# IP-358 主闭环（关键片段）
def metriccert_wbc_loop(robot, v7, v8):
    S = robot.snapshot()                        # 定义 530
    if not v8.available():                      # 模块不可用 ⇒ 逐字 v7
        return v7.step(robot)

    certs = {m.id: v8.mgc.certify(m) for m in v8.measure(S)}   # 531/532
    I = {mid: v8.mia.audit(S, v8.reported[mid], robot.view)
         for mid in certs}                                      # 538
    wbcert = v8.wbfc.extract(v8.hqp)                             # 534
    cmw_ok, gap = v8.cmw.check(S, wbcert)                        # 537

    gate_m = all(c is not None and I[mid][1] for mid, c in certs.items())
    gate_w = (wbcert.feasible and cmw_ok
              and wbcert.margins["bal"] >= v8.req["bal"]
              and wbcert.margins["contact"] >= v8.req["contact"])
    # 评测只做交，不扩大控制可行集（定义 533）
    A_final = robot.admissible() & v8.eval_admissible(certs, wbcert)

    mode = v8.mga.update(v8.metrics, S) if (gate_m and gate_w) else "frozen"
    if not (gate_m and gate_w):
        v8.ladder.descend(v8.margins_view(wbcert, certs), robot.now)   # 540
    # 交给 v7 执行，v8 只提供门控与降级，不直接写控制量
    return v7.step(robot, admissible=A_final, mode=mode)

## 4. 推导

**引理 77（provenance 不可伪造性）** 若 `prov` 的叶全部是已标定传感通道且不含控制意图节点，则对同一物理快照 `S_t`，接地值 `v = f(prov)` 与控制器所选动作 `a` 无关；任何把 `a` 注入 `prov` 的尝试都会改变 `hash(prov)`，使 `C_m` 验签失败。
*证明要点*：`prov` 是 `S_t` 的函数、`a ∉ prov`，故 `v` 对 `a` 的偏导为 0；证书签名绑定 `h = hash(prov)`，哈希抗碰撞 + 签名不可伪造。

**引理 78（解耦单调性）** 在 SEC 下 `A_final = A_ctrl ∩ A_eval(C)`。若 `C' ⪯ C`，则 `A_eval(C') ⊆ A_eval(C)`，故 `A_final(C') = A_ctrl ∩ A_eval(C') ⊆ A_ctrl ∩ A_eval(C) = A_final(C)`；有限个证书的交仍是交，因此评测只能收紧可行集。
*推论*：Goodhart 式的“刷分以放宽约束”在接口层没有对应的动作——放宽不在 `A_eval` 的像里。

**引理 79（WBFC 相对健全性）** 若分层 QP 返回的 `(x*, s, λ)` 满足原始可行 `s_j ≥ −ε_tol`、对偶可行 `λ ≥ 0` 且平稳性残差 ≤ ε_s，则在**给定模型内** `x*` 是 ε_tol-可容许的，且 `ρ_j = s_j/‖A_j‖` 是归一化裕度的下界（误差 ≤ ε_tol/‖A_j‖）。
*说明*：该引理只保证“相对于模型与求解器容差”的健全性，不保证真实物理；后者由 CMW 与实验 E528 负责。

**引理 80（平衡裕度保守性）** 设真实支撑多边形 `P_true` 与名义 `P_nom` 的 Hausdorff 距离 ≤ `r_unc`，且 `P_true ⊇ P_nom ⊖ B(0, r_unc)`。则对任意 `ξ`，`sd(ξ, P_true) ≥ sd(ξ, P_nom ⊖ B(0, r_unc)) = ρ_bal`，即腐蚀后的 `ρ_bal` 是真实平衡裕度的保守下界。
*证明要点*：`P_true` 更大 ⇒ 其补集更小 ⇒ 到补集的距离不小于到 `P_nom ⊖ B_r` 补集的距离。

**引理 81（CMW 检错力）** 设两模型的裕度误差 `e_a, e_b` 有界且不共线，测量噪声有界为 `η`。若任一被认证裕度的真实模型误差 > `δ_CMW + 2η/scale`，则 `Δ_CMW > δ_CMW` 的概率 ≥ 1 − β（β 由噪声尾部决定），证书被吊销。
*证明要点*：`|ρ^a − ρ^b| ≥ |e_a − e_b| − 2η/scale`；不共线假设排除“两个模型犯同一个错因而互相抵消”。

**引理 82（门控退化等价）** ① 若 MPG/MGC/MIA/WBFC/CMW 任一不可用，`metriccert_wbc_loop` 走 `v7.step`，行为与 v7 逐字相同；② 若证书不可信/不可行（`Gate_m ∧ Gate_w = 0`），OTL/ER 被冻结且 EDL 只降，故适应不会引入新的退化源，系统比 v7 更保守；③ 若再关闭 v7 的 OTL/ER，则 `τᵢ = τᵢ(0)`、`β = 0`，等价于 v6。
*证明要点*：分别由旁路分支、冻结分支与 v7/v6 的定义直接得到。

**引理 83（阶梯终止与无抖动）** 在“只降不升 + 驻留时间 `τ_d` + 滞回 `h`”下，任意有限时间轨迹在每个层级最多进入可数次，且不会在相邻层间 Zeno 振荡；最坏降到 L0 的附加时间为 `O(#levels · τ_d)`。
*证明要点*：层级序号是单调下降的有界势函数；每次下降至少间隔 `τ_d`，故单位时间下降次数有界。

## 8. 本轮最大风险

**一句话**：WBFC 与 MGC 都建立在“动力学/接触模型 + 传感器标定正确”的前提上——若模型存在系统性偏差（支撑多边形过于乐观、摩擦系数高估、质心估计偏移），系统会以一份自洽、可审计却与真实物理脱节的证书，系统性地“自信地犯错”；而双模型互证若与主模型共享同一错误先验（同一批辨识数据、同一标定误差），也会同时失效，使“可证”退化为“自证”。
