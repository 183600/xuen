# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「动力学」×「数据集」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**动力学证书 + 数据集覆盖证书**。v9 的死穴是一条假设：块证书可靠 ⇔「信任域内前向模型误差 ≤ β」，而信任域由滞后 20 帧的 Δ_dom 判定。本轮用两个互补的**几何/动力学历**替换这个统计-滞后判据：动力学给「误差沿块是收缩还是放大」，数据集给「当前状态是否仍在 F̂ 的证据支撑内」。二者都是**前瞻**的，不依赖对分布偏移的检测。

## 0. 直觉与动机

**灵感 1（动力学 → 误差是被收缩还是被放大）**
直觉：v9 把预测误差当成静态常数 β，块越长越怕。但真实闭环是动力系统：在接近抓取、对准、减速这些任务相里，闭环流是**收缩**的——起点的小误差沿轨迹指数衰减，误差不累积反而被"吸"回标称轨迹，于是块可以更长却更安全；反之在自由导航临界相与接触冲击附近，流可能中性或扩张，v9 的"β 常数"其实低估了误差增长。核心创新：**动力学收缩证书器（DynamicsContractionCertifier, DCC）**——用数据集拟合带控 Koopman/DMD 提升线性模型 A_cl，解离散 Lyapunov 方程得度量 M，算 M-范数收缩因子 κ=‖A_cl‖_M；若 κ<1，则块内扰动管径满足 r_k ≤ κ^k r_0 + ε(1−κ^k)/(1−κ)，给出**解析的中块误差上界**（引理 87）。这把"误差会不会超 β"从经验问题变成可计算的动力学问题，并附带给出中块安全的、**不依赖中止点**的充分条件。

**灵感 2（数据集 → 证书的支撑集就是真实边界）**
直觉：β 之所以只是"经验标定"，是因为它隐含假设 F̂ 只在训练数据附近可信。与其用一个全局 β，不如让 β **随状态变化**：β(s)=L_cert·cov_D(s)+ε_train，cov_D(s) 是状态-动作 s 到已验证数据集 D 的最近距离，L_cert 是真实动力学的 Lipschitz 证书。核心创新：**数据集覆盖证书器（CoverageCertifier, CovC）**——维护带 provenance 与版本的安全数据集 D，实时计算 cov_D，把"信任域"重定义为**几何覆盖域** U_cov={s: β(s)≤β_max}。关键洞察：**覆盖是领先指标**——机器人一进陌生状态空间，cov_D 立即增大，**不需要**任何分布偏移检测器、也没有 20 帧滞后；DA-ML 的 Δ_dom 由此从"安全门"降级为"辅助告警"。

**灵感 1×2 合流（前瞻双门控）**
直觉：动力学回答"误差往哪走"，数据集回答"证据在哪"。二者在**候选块的预测轨迹**上逐点求值：沿 ŝ^{1:K} 检查 max_k β(ŝ^k) ≤ β_max 且 tube_k ≤ margin_k，任一不满足即缩短块。这恰好补上 v9 最大风险的空洞：不再靠滞后 Δ_dom，而是在**执行前**就沿预测轨迹看见低覆盖区与扩张相。

**文献锚点**：收缩分析（Lohmiller & Slotine, 1998）；Koopman/DMD 与带控 DMD（Tu et al., 2014；Proctor et al., 2016）；离散 Lyapunov 度量与谱界（Bauer–Fike）；Lipschitz 泛化/覆盖界（von Luxburg & Bousquet, 2004）；核心集选择（Sener & Savarese, 2018）；datasheets for datasets（Gebru et al., 2018）；conformal 作为免 Lipschitz 的备选（Vovk et al.；注：交换性在域偏移下失效，与本轮风险同源）。

## 1. 研究问题（轮次升级版）

- **Q1（动力学期）**：在何种闭环度量 M 与线性化残差 ε_lin 假设下，块内误差管径 r_k 可被 (κ, ε) 解析界定，并给出不依赖中止点的分块安全充分条件？DMD 估计的 A_cl 是否足够准，使 κ 证书保持保守（而非乐观）？
- **Q2（数据覆盖）**：Lipschitz 覆盖界 β(s)=L_cert·cov_D(s)+ε_train 有多保守？"验证后才晋升"的主动采集能否在保证证书可靠的前提下单调降低 β，且不被投毒数据伪造出"变好"？
- **Q3（双门控与不滞后）**：前瞻双门控是否消除 v9 Δ_dom 的 20 帧滞后，并在证书缺席时严格逐位退化回 v9（严格不劣于基线）？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 动力学收缩证书律（Dynamics-Contraction Cert, DCC）**
在数据拟合的闭环提升模型上，若存在度量 M 使 M-范数收缩因子 κ<1，则块内扰动误差按 r_{k+1} ≤ κ r_k + ε 传播。安全充分条件：∀k≤K，认证间隙余量 ≥ d_safe + β + r_k。DCC 缺席 ⇒ 该约束取中性（K_dyn=K_max），安全改由 v9 的 β₀ 常数 + 中止点集承担，行为退回 v9。

**P14 数据集覆盖证书律（Coverage-Certified Generalization, CovC）**
前向模型误差的证书值随查询点到已验证数据集的距离单调增长：β(s)=L_cert·cov_D(s)+ε_train。信任域是**几何覆盖域** U_cov，而非统计检测域。覆盖外的状态一律以更短块或 K=1 处理。CovC 缺席 ⇒ β←β₀（v9/E554 全局标定），U_cov←U_t（v9 信任域）。

**P15 验证后才晋升律（Validate-Before-Promote, CGC）**
主动采集只写**暂存区 D_buffer**；只有通过 M₀ 硬检查/空间证书/看门狗校验、且在冻结金标集 D_gold 上回归"β 不恶化"后，才晋升进 D_cert 并触发 F̂/A_cl 的离线重训与原子替换；失败则回滚。**未晋升数据永不参与证书计算**——数据飞轮不允许靠未验证数据"变好"。

## 3. 与基线的接口（如何退化）

- DCC 失效（A_cl 拟合不通过 / κ≥1 找不到证书度量）⇒ 动力学项取中性（K_dyn=K_max），回退 v9 的 β₀ + 中止点机制；
- CovC 失效（数据集/KD 索引损坏）⇒ β←β₀、U_cov←U_t，等价 v9 门控；
- CGC 失效 ⇒ D 冻结、不采集，β 只可能不降（安全方向），等价无数据飞轮；
- 双门控默认以"**只收紧不放松**"的部署开关运行 ⇒ 门控级逐位等价 v9；仅当 E575 通过后，方可开启"覆盖门取代滞后 Δ_dom 门"的放松模式；
- v9 的 AC/MW/ID 任一失效 ⇒ 沿其原有退化链回 v8；再全员失效 ⇒ 回 v7/v6。

## 4. 预期贡献

1. **动力学收缩证书**：把块内预测误差从"静态 β"升级为可解析的指数管径界，给出中块安全的不依赖中止点的充分条件，并区分"收缩相可长块 / 扩张相须短块"；
2. **数据集覆盖证书**：把信任域从滞后统计检测改为几何覆盖，β 成为空间函数 β(s)，从原理上消除 v9 的 20 帧滞后；
3. **前瞻双门控**：沿预测轨迹逐点求值 (β, r)，在执行前而非执行中暴露风险；
4. **经证实的数据飞轮**：带 provenance/版本/金标回归/回滚的安全数据集与主动采集，使 β 的下降可审计、抗投毒。

## 5. 本轮最大风险

**一句话**：覆盖界与收缩界都以"真实动力学在证书区域内 Lipschitz 常数与线性化残差可控"为前提，而接触/抓取的冲击奇点正是 L 与 ε_lin 爆炸、收缩性反转（冲击是扩张且不连续）之处——恰恰是间隙 d_safe 最关乎安全的时刻，于是「证书最可证的区域」与「安全最需要的区域」发生结构性错配，两个证书可能在最关键时刻同时失效。

**新增定义 540（闭环安全状态与提升模型）** 令 z_t 为上述安全相关状态，闭环流 z_{t+1}=F_cl(z_t)+w_t，w_t 为扰动。用带控 DMD 从 D_cert 拟合提升线性模型 z_{k+1}≈A z_k + B u_k，闭环 u=Kz 得 A_cl=A+BK，提升维数 n_lift 默认 32。

**新增定义 541（动力学收缩证书 ContractionCertificate）** 解离散 Lyapunov 方程 A_cl^T M A_cl − M = −Q（Q≻0），取 κ=‖A_cl‖_M=sqrt(λ_max(A_cl^T M A_cl)/λ_max(M))。证书 CC=(M, κ, ε_lin) 有效 ⇔ κ<1 且线性化残差经验上界 ε_lin 是 D_cert 上的保守估计。

**新增定义 542（误差管径 Tube Bound）** 在证书有效区域内，对块内第 k 步：
```
r_k = κ^k·r_0 + ε·(1−κ^k)/(1−κ),   ε = ε_lin + β
```
其中 r_0 为块起点偏差。中块安全充分条件：∀k≤K，certified_margin(k) ≥ d_safe + β + r_k（certified_margin 用当前 τᵢ(t) 复核）。

**新增定义 543（覆盖函数 Distance-to-Dataset）** cov_D(s)=min_{(z,a,·)∈D_cert} ‖s−(z,a)‖₂；用 KD 树 O(log|D|) 查询。覆盖报告给出 cov_D 在 ODD 上的分位数直方图。

**新增定义 544（覆盖证书 CoverageCertificate）** 设 F 在 Ω 上 L-Lipschitz、F̂ 在 D_cert 上训练误差 ≤ ε_train 且 L̂-Lipschitz。对任意 s，取最近 s'∈D_cert，则
```
‖F̂(s)−F(s)‖ ≤ (L+L̂)·cov_D(s) + ε_train =: β(s)
```
有效 ⇔ s 落在 D_cert 覆盖邻域内（cov_D 有限且有界）；β_max 由可容许间隙误差反推（默认 0.02 m）。

**新增定义 545（几何覆盖信任域）** U_cov={s : β(s)≤β_max}。v9 的 U_t={Δ_dom<τ_dom ∧ risk_SLAM<τ_SLAM} 降级为**辅助告警**：只能进一步缩短 K，不再单独承担安全门。

**新增定义 546（前瞻双门控 DualGate）** 对候选块 ζ 的预测状态-动作序列 ŝ^{1:K}：
```
K_dual(ζ) = max{ k ≤ K_max : ∀j≤k, β(ŝ^j) ≤ β_max ∧ r_j ≤ certified_margin(j) − d_safe − β }
K_eff^{v10}(t) = min( K_eff^{v9}(t), K_dual(ζ) )
```
DCC 缺席 ⇒ r_j 项取中性（不约束）；CovC 缺席 ⇒ β←β₀ 且 U_cov←U_t。故两项皆中性时 K_eff^{v10}=K_eff^{v9}。

**新增定义 547（安全数据集 SafetyDataset）** D_cert 每行 (s, a, s', ŷ, τ, prov)：输入输出、指标标签、时间戳、provenance（机器人 id、任务、传感器配置、数据版本）。三分：D_cert（已验证）、D_buffer（暂存）、D_gold（冻结金标回归集）。维护 datasheet 与语义版本号；核心集用最远点/ε-net 采样控制体积。

**新增定义 548（覆盖门控采集 CoverageGatedCollection）** 当 cov_D(s)>τ_cov·ε 且 K=1 且 M₀/空间证书通过时，把转移写入 D_buffer。晋升流水线：验证器过滤 → 与 D_cert 合并成候选 → 在 D_gold 上回归（β 不恶化且成功率不降）→ 原子替换并升版本；任一步失败 → 回滚（D_cert 不变）。

## 3. 关键算法骨架

```python
# IP-357 DynamicsContractionCertifier：动力学收缩证书器
class DynamicsContractionCertifier:
    def __init__(self, dataset, n_lift=32, Q=None):
        self.D, self.n_lift = dataset, n_lift
        self.Q = Q; self.A_cl = self.M = self.kappa = None; self.eps_lin = None

    def fit(self):
        Z, Znext = self.D.to_closed_loop_pairs()          # (z_k, z_{k+1})
        A = dmd(Z, Znext, r=self.n_lift)                  # 带控 DMD → A_cl
        self.Q = self.Q if self.Q is not None else np.eye(A.shape[0])
        self.M = solve_discrete_lyapunov(A.T, self.Q)     # A^T M A - M = -Q
        self.A_cl = A
        # Bauer-Fike 谱迁移界：真实算子谱 ∈ A 的谱 ± eps_dmd*cond(V)
        self.kappa = np.sqrt(np.linalg.eigvalsh(A.T @ self.M @ A).max()
                             / np.linalg.eigvalsh(self.M).max())
        self.eps_lin = self.D.linearization_residual(A).max()
        return self.kappa < 1.0

    def tube(self, k, r0, eps):
        kappa = self.kappa
        return kappa**k * r0 + eps * (1 - kappa**k) / (1 - kappa)

    def certified_prefix(self, states_pred, eps, margin_fn):
        """返回满足管径安全的最大块前缀长度（不依赖中止点）"""
        if self.kappa is None or self.kappa >= 1.0:
            return len(states_pred)                       # 中性：不约束
        for k, s in enumerate(states_pred):
            if self.tube(k + 1, 0.0, eps) > margin_fn(s) - margin_fn.d_safe:
                return k
        return len(states_pred)


# IP-358 CoverageCertifier：数据集覆盖证书器
class CoverageCertifier:
    def __init__(self, d_cert, L_cert, eps_train, beta_max, tau_cov=1.5):
        self.D = d_cert
        self.L, self.eps_train, self.beta_max = L_cert, eps_train, beta_max
        self.tau_cov = tau_cov
        self.tree = KDTree(d_cert.inputs())
        self.version = d_cert.version

    def cov(self, s_a):
        d, _ = self.tree.query(s_a)
        return d

    def beta(self, s_a):
        return self.L * self.cov(s_a) + self.eps_train

    def certified_prefix(self, state_actions_pred):
        if self.tree is None:
            return len(state_actions_pred)                # 中性：不约束
        for k, sa in enumerate(state_actions_pred):
            if self.beta(sa) > self.beta_max:
                return k
        return len(state_actions_pred)

    def refresh(self, d_cert_new, version_meta):          # 仅接受已晋升数据
        self.D, self.tree = d_cert_new, KDTree(d_cert_new.inputs())
        self.version = version_meta


# IP-359 CoverageGatedCollector：覆盖门控采集器
class CoverageGatedCollector:
    def __init__(self, covc, restorer, gold_gate, d_buffer, thr=1.5):
        self.covc, self.restorer, self.gold = covc, restorer, gold_gate
        self.buf, self.thr = d_buffer, thr

    def maybe_collect(self, s, a, s_next, y, risk_ok):
        if not risk_ok or self.covc.beta((s, a)) <= self.thr * self.covc.beta_max:
            return False                                  # 安全才采；只补低覆盖
        self.buf.add(s, a, s_next, y, prov=provenance())
        return True

    def promote(self):
        staged = [t for t in self.buf if self.restorer.verified(t)]
        cand = merge(self.covc.D, staged)
        if not self.gold.non_worse(cand, self.covc):      # 金标回归：β 不恶化
            return 'rollback'                             # D_cert 保持不变
        self.covc.refresh(cand, bump_version(self.covc.version))
        return 'promote'


# IP-357/358 合流：前瞻双门控（严格 = min(v9, dual)）
def dual_gate(chunker, dcc, covc, s0, K_v9, eps):
    if dcc is None and covc is None:
        return chunker.generate_chunk(s0, K_v9)           # 逐位退化 v9
    for K in range(K_v9, 0, -1):
        cand = chunker.policy.propose(s0, K)
        pred = chunker.F.rollout(s0, cand)
        k_dyn = (dcc.certified_prefix(pred.states, eps, chunker.margin)
                 if dcc is not None else K)               # 中性
        k_cov = (covc.certified_prefix(pred.state_actions)
                 if covc is not None else K)              # 中性
        if min(k_dyn, k_cov) >= K:
            pts = chunker._abort_points(s0, cand, pred)   # v9 中止点仍然保留
            if pts:
                return chunker.assemble(cand, pred, pts)
    return chunker._single_step_fallback(s0)              # K=1 等价 v8 逐步
```

## 4. 推导

**引理 87（收缩管径界与中块安全）** 设证书区域上闭环流满足 M-范数收缩 κ<1，且线性化残差 ‖F_cl(z)−A_cl z−b‖_M ≤ ε_lin；模型误差 ≤ β。则块内偏差 δ_k=z_k−z̄_k 满足 ‖δ_k‖_M ≤ κ^k‖δ_0‖_M + (ε_lin+β)(1−κ^k)/(1−κ)=:r_k。若 ∀k≤K，认证间隙余量 ≥ d_safe+β+r_k，则整块无间隙违背（无需中止点）。证明：对偏差递推用三角不等式与一致收缩，离散 Grönwall 归纳；真实间隙 ≥ 预测间隙 − β − r_k ≥ d_safe。∎

**引理 88（覆盖证书保守性）** 设 F 在 Ω 上 L-Lipschitz，F̂ 在 D_cert 上训练误差 ≤ ε_train 且 L̂-Lipschitz。取 s'∈D_cert 最近邻、d=cov_D(s)，则
‖F̂(s)−F(s)‖ ≤ ‖F̂(s)−F̂(s')‖+‖F̂(s')−F(s')‖+‖F(s')−F(s)‖ ≤ (L+L̂)d+ε_train。
故 β(s)=L_cert·cov_D(s)+ε_train 是有效上界，且对 cov_D 单调非减。∎

**引理 89（无滞后前瞻门控）** 双门控在**执行第 1 步之前**对预测序列 ŝ^{1:K} 求值；任意可达的 j≤K 若 β(ŝ^j)>β_max 或 r_j 吃穿余量，则当周期即得 K_eff^{v10}<j，**完全不依赖 Δ_dom**。故在 E575 的阶跃偏移注入下，反应延迟为 O(1 周期)，而 v9 至少滞后窗口长度 W=20。证明：门控只依赖 s_t 与 F̂ 的前向预测，不需未来观测。∎

**引理 90（飞轮安全性与 β 单调性）** 在 P15 下，新数据只在晋升后进入 D_cert，而晋升要求 D_gold 上 β 不恶化；故跨晋升序列 β 在 D_gold 分布上单调非增。未验证/投毒数据虽可能紧邻查询点，但不进入 D_cert，不参与 cov_D 与 β 计算，故不能伪造"变好"。∎（注：域偏移会把查询推到低覆盖区，β 升高——这是安全方向，不是漏洞。）

**引理 91（退化等价 v9）** DCC 缺席 ⇒ 令 k_dyn≡K（不约束）；CovC 缺席 ⇒ β≡β₀ 且 U_cov≡U_t、k_cov≡K。此时 dual_gate 返回 min(K^{v9},K)=K^{v9}，且中止点构造、生成器、RNG 与 v9 相同，故门控与可观测行为逐位等价 v9。∎

**引理 92（DMD 谱界与证书的承重假设）** 若 DMD 拟合残差 ‖Znext−AZ‖≤ε_dmd 且提升算子谱非退化（特征向量矩阵条件数 cond(V)），则真实算子特征值落在 A 的特征值 ε_dmd·cond(V) 邻域内（Bauer–Fike）。故 κ 的估计误差为 O(ε_dmd·cond(V))；当真实 κ 接近 1 时，估计误差可能使"证书保守性"翻转——这是本方案唯一的承重假设（见 §8）。∎

## 8. 本轮最大风险

**一句话**：覆盖界与收缩界都以"真实动力学在证书区域内 Lipschitz 常数与线性化残差可控"为前提，而接触/抓取的冲击奇点正是 L 与 ε_lin 爆炸、收缩性反转（冲击是扩张且不连续）之处——恰恰是间隙 d_safe 最关乎安全的时刻，于是「证书最可证的区域」与「安全最需要的区域」发生结构性错配，两个证书可能在最关键时刻同时失效。
