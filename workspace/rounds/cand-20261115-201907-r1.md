# 第 70 轮（承接第 69 轮「FLUID-RAS 不确定性二分闭环」IP-253~263；本轮灵感：「UniBot-V1」×「预训练」）

> R69 把不确定性一分为二：aleatoric 沿用 R68 的保守铁律，epistemic 交给「流匹配多模态策略 + 主动多模态交互」去消解。定位从「我的测量还准吗」推进到「我该向谁求证、还能问什么」。但它把全部效率收益押在一个从未被挣得的前提上——**流模型采样出的模态分布可信**。R69 对此只有一个 ECE 校准门（越界就退回 R68）和一组事后实验；它手上没有任何**外部参照**来判断「这个模态是真歧义，还是采样幻觉/模态坍缩」。
>
> 本轮两个灵感正好补上这块外部参照，但同时引入一个更深的陷阱：
> - **UniBot-V1** 是一个在异构具身/任务上预训练的通用机器人基础模型——它把「这类情境通常有哪些模态、通常怎么解」作为一种**借来的经验（先验）**带进来；
> - **预训练** 的价值不只在权重，更在**它的数据出处**：预训练语料是一本可审计的溯源账本（某个模态由哪些具身/任务的数据片支撑），而这本账本同时是新的攻击面与新的系统性偏差来源。
>
> 核心命题：**把预训练先验当作「只能否决、不能认证」的证人，且其权威受溯源约束；先验与在线似然显式因子分解；先验只能加否决、永远不能抬高 R69 的安全下限。** 命名 **PRIOR-RAS**（Provenance-bounded Reference prior, Interactive Online Regulation for Risk-Adaptive Systems；经验锚定、溯源受限的先验否决闭环）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我凭什么相信这份借来的经验、它到底在替谁说话**」——预训练不是证书，是需要出示 provenance 的证人。

## 0. 直觉与动机

**灵感 1（UniBot-V1 → 借来的经验是先验，不是证书）**
直觉：R69 的流策略只在单一具身、有限任务上学，样本一稀疏就会「幻觉出模态」或「把真模态坍缩掉」。而一个在大量异构具身上预训练过的通用模型，见过无数次「这类岔口一般有两条路」「这类模糊表情一般对应两种意图」。这本质上是一个关于**歧义形状的先验** p_pre(M|o)。但先验回答的是「通常怎样」，不是「此刻怎样」；R69 的采样分布把先验与似然混在一起，于是「常见」被误读成「正在发生」。正确姿态是**因子分解**：p(M|o,y) ∝ 先验(M|o) × 在线似然(o|M)，各自校准、各管一段；先验只影响「我是否该怀疑」，不影响「我现在看到了什么」。

**灵感 2（预训练的数据来源 → 溯源账本）**
直觉：预训练最有价值也最危险的东西不是参数，而是**它的出处**。同一个模态，若由与你当前具身高度相似的数据支撑（同构机械臂、同任务族），先验值得听；若只由人形双足或仿真玩具的数据支撑，先验很可能在说别人的话。预训练因此可以被看成一本**溯源账本**：每个先验模态 m 都可以问「哪些数据片 shard 支持你、它们离我多近」。这把「信不信先验」从主观判断变成可计算量——**溯源自带距离，距离给出信任权重**。

**灵感 3（预训练的多头结构 → 自洽审计，但它是同源证人）**
直觉：UniBot-V1 通常有动作头、世界模型头、语言/可供性头。若一个候选模态在动作头里被看好，却被世界模型头判为「物理上接不住」、或被语言头判为「与指令不符」，它很可能是幻觉。多头不一致 = 内部自洽性破绽。**但关键陷阱**：这些头共享同一套预训练权重与同一份数据，它们的错误高度相关（ρ_pre≈1）。所以「先验概率高 + 多头都同意」只能算**一个**证据源，绝不能当作 R69 要求的 k 个正交证据——否则就把「同源复读」误当成「交叉验证」，R69 引理 18 的投毒上界会瞬间失效。

**灵感 4（预训练是双刃剑 → 经验暴政与数据后门）**
直觉：先验一旦被当成证书，就会**洗白置信度**。若预训练数据有系统性偏差（示范里所有人遇岔口都走右），先验会高置信地否决正确但罕见的左模态；若语料被植入后门（触发器让某个错误模态在**所有头**里都自洽），系统会对一个「有据可依」的错误照单全收。R69 的危险是「低置信度的不知道」，R70 的新危险是「高置信度的错误」——信错，比不信更危险。这正是「先验只否决、不认证」的根本理由：**人能伪造一份看起来很权威的简历，但不能靠伪造简历通过面试。**

**灵感 5（微调的遗忘 → 模式空间信赖域）**
直觉：把 UniBot-V1 微调到当前具身时，最容易发生的是**歧义检测能力被遗忘**：模型变得又自信又单峰，原本该说「我不确定」的地方现在直接吐一个动作。因为「何时该不确定」这个元先验恰恰是预训练给的、最容易被小样本微调冲掉的东西。对策不是冻结（那样无法适应），而是在**模式原型空间**上加锚：在有溯源支撑的区域约束微调后分布别离先验太远，在无支撑区域放开——保住「知道自己在借谁的经验」。

**灵感 6（对 R69 的姿态 → 严格包含，且只加否决）**
直觉：R69 已经用「k 个正交证据一致」守住交互投毒。R70 不应推翻它，而应作为**额外的、单调的否决层**：先验可以在它确有权威（有溯源支撑）且与在线证据矛盾时**增加**怀疑/收紧，但永远不能**降低** R69 的 λ 下限、不能单独满足证据纪律、不能把 SILENT 当作「已排除」。这样 R69 是本轮在「先验处处沉默」边界上的逐指令退化——新层是旧层的严格泛化，而不是并列替代。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（PRIOR-RAS 总览）** PRIOR-RAS = (PBP, PLT, PTS, PSC, TRM, RAS-WM‡)。三不变式：
(i) **先验否决单调律**：预训练信息只能提高 λ、只能收缩可执行模态集、只能增加怀疑标记；不得降低 R69 的 λ 下限、不得单独满足 R69 证据纪律（继承并强化定义 293）；
(ii) **溯源受限权威**：先验仅在有溯源支撑的模式区域 𝒯 内拥有否决权；𝒯 外先验沉默，不得以「先验低分」排除候选；
(iii) **实时零预训练写操作**：实时环路只读一个蒸馏先验头与缓存溯源表，完整 UniBot-V1 多头审计与溯源归因异步执行，不进入 P99 环路。

**定义 311（UniBot-V1 先验接口 PBP）** 预训练通用模型 U 提供：(a) 模态先验 p_pre(m|o)；(b) 当前具身嵌入 e_now = φ(o) 与语料片嵌入 {e_j}；(c) 多头输出 {h_act, h_wm, h_lang, h_aff}；(d) 对语料片集合 C={shard_j} 的可查询溯源。实时侧只部署其蒸馏版先验头 p̂_pre（定义 320），U 本体离线。

**定义 312（先验-似然因子分解）** 设在线流策略与预训练先验共享同一模态集 {m_k}。R69 的采样权重 ŵ_k 被视为**未分解的后验代理**。PRIOR 显式写作
p(m_k|o,y) ∝ p_pre(m_k|o)^{α} · L_on(m_k|o,y)，
其中 L_on 由在线编码器似然（R69 定义 301 的流似然）给出，α∈[0,1] 为**先验注入强度**。α=0 即退回 R69 的纯在线后验；α>0 允许借来的经验参与，但不改变似然项。**关键：α 只作用于先验项，不影响 R69 的安全通道（λ、认证、证据纪律）。**

**定义 313（溯源账本与支撑度 PLT）** 对模态 m_k，归因权重 a_j(m_k) ≥ 0（溯源/influence/最近邻检索权重，Σ_j a_j = 1），具身相似度 κ(e_now, e_j) ∈ [0,1]。定义
S(m_k) = Σ_j a_j(m_k) · κ(e_now, e_j)（有效支撑度），
cov(m_k) = (Σ_j a_j)² / Σ_j a_j²（归一化参与率，度量支撑的**广度**）。
权威区 𝒯 := {m : S(m) ≥ s_0 且 cov(m) ≥ c_0}。

**定义 314（先验三态甄别 PTS）** 对每个 m_k 判态：
- **SUPPORTED**：m_k ∈ 𝒯 ∧ p_pre(m_k|o) ≥ p_0 ∧ A(m_k) ≥ a_0（先验、溯源、自洽三者一致）→ 仅作为**一个**与先验同族的证据，可进入 R69 的加权（见定义 318 的相关性折算），**不得单独定案**；
- **CONTRADICTED**：m_k ∈ 𝒯 ∧ (p_pre(m_k|o) < p_0 ∨ A(m_k) < a_0)（先验有权威却不支持 / 多头自相矛盾）→ **否决**：ŵ_k ← 0（或置地板），U_epi 不因移除而下降，转入 R69 兜底或触发交互；
- **SILENT**：m_k ∉ 𝒯（先验对此模式无权威）→ 先验**保持沉默**，R69 行为逐字不变，不得以「先验分低」排除。

**定义 315（自洽审计 PSC 与同源折扣）** A(m) = 1 − c·D̄(m)，D̄ 为多头两两归一化分歧均值。定义**有效独立证据数**
k_eff = 1 + (k_src − 1)(1 − ρ̂_pre)，
其中 ρ̂_pre 为「先验头 + 自洽头」这一族与在线证据之间的估计错误相关。因 ρ̂_pre ≈ 1，**先验族只能计 1 票**；R69 的 k-正交一致中，至多 1 票来自先验族，其余必须来自在线主动交互（定义 298）。

**定义 316（分片刀切稳健性 Jackknife）** 令 j* = argmax_j a_j(m) 为最强支撑片，p_pre^{(-j*)}(m|o) 为剔除 j* 后的先验。**分片脆弱度** F(m) = log p_pre(m|o) − log p_pre^{(-j*)}(m|o)。若 F(m) > φ_0（先验几乎全靠单一一片），则即便其余条件满足也把该模态降级为 SILENT——不许单一出处单独授权否决。这是对「溯源看似广、实则一条腿」的防御。

**定义 317（先验否决单调律）** 对任意状态 s：λ_PRIOR(s) ≥ λ_R69(s)；可执行模态集 ℳ_PRIOR(s) ⊆ ℳ_R69(s)；证据受理统一沿用 R69 的「k 正交一致」纪律（定义 293-iii）。形式化：PRIOR 仅在 CONTRADICTED 上施加否决或 λ 抬升，其余分支委托 R69；故安全通道单调不弱。

**定义 318（相关性折算的证据纪律）** 把证据划分为两个**族**：预训练族 ℱ_pre = {p_pre, PSC, provenance}（内部高相关，共享数据与权重），在线族 ℱ_on = {主动注视/探针/问句回答, 在线流似然, 环一致残差}。定案要求：来自 ℱ_on 的一致源数 ≥ k−1 且总有效独立数 k_eff ≥ k。**即：预训练永远无法凑够证据，只能否决。** 这直接堵住「同源复读冒充交叉验证」。

**定义 319（模式空间信赖域微调 TRM）** 微调目标
L = L_FM + β · Σ_{m∈𝒯} ω(m) · KL(q_ft(m|o) ‖ p_pre(m|o))，
其中 ω(m)=1{S(m)≥s_0}，并在 𝒯 外取 0（放开适应）。β 足够大 ⇒ 在有溯源支撑的模式原型上保留预训练歧义先验，避免「越微调越自信、越单峰」的元先验遗忘。

**定义 320（实时蒸馏先验头）** 部署一个由 U 蒸馏的小先验头 p̂_pre(m|o) 与一张缓存溯源表 (S, cov, F)，实时只读；U 本体的多头审计、jackknife、全量归因在 AuditBuf 异步队列执行，结果回灌下一周期的 s_0/c_0/β 与一个「否决白名单/黑名单」缓存。保证 P99 与 R69 同量级。

**定义 321（先验-在线分桶温度校准）** 对每个溯源桶 b（按 S 分档），拟合仿射/温度标定 p̂_cal = σ(a_b·logit p̂_pre + b_b)，以具身内校准集最小化 ECE。**分桶校准是必需的**：全局单一温度会把「远具身先验系统性过度自信」这一结构性误差抹平成一个平均偏差。

**定义 322（"借来的经验"偏差账本 Bias Ledger）** 维护对先验偏差方向的可审计估计：用**反事实溯源自检**——查询先验在若干虚拟具身 e' 上对同一情境的模态偏好，若偏好随无关具身属性（颜色、品牌、左右手习惯）漂移，则记录该方向为**可疑偏差轴**。偏差轴上的先验在 CONTRADICTED 判定中降权（提高 p_0），防止「多数具身的习惯」压过本具身的证据。

**定义 323（预训练投毒威胁 AIC-PRIOR）** ℰ_PRIOR = ℰ_FLUID × ℰ_pretrain，ℰ_pretrain 含：语料系统性偏差、后门触发器（令错误模态在所有头自洽）、溯源伪造（把低相似度片标成高相似度）、蒸馏投毒（先验头被单独污染）。并入 AIC。

**定义 324（证书 J_PRIOR）** J_PRIOR = (J_FLUID, prior_ece_bucketed, provenance_coverage_p50, veto_false_positive_rate, k_eff, jackknife_fragile_rate, bias_axis_flags, prior_ver)。Valid ⇔ Valid(J_FLUID) ∧ 分桶 ECE ≤ τ_ece ∧ k_eff ≥ k ∧ 证据纪律满足 ∧ 先验否决未越权（定义 317）。

**定义 325（两段式退避与 resolution 的边界）** 若大量模态 SILENT（本具身对预训练是 OOD），α 自动 →0，PRIOR 逐指令退化为 R69；若出现 CONTRADICTED 且无在线证据可交互，λ 至少抬到 R69 的纯保守档；若 SUPPORTED 且在线证据一致，才允许 R69 的 resolution bonus，且 bonus 不因先验而放大。**先验永不制造 bonus，只参与否决。**

**定义 326（跨具身适配的动作令牌边界）** UniBot-V1 的动作在预训练具身空间；部署需经动作令牌重定向 ĝ = R_{e_now←e_pre}。**认证与安全包络始终在当前具身空间计算**（继承 R69 定义 302）；重定向误差 ε_R 计入 λ 的附加项 max(λ, λ_floor(U_ale+U_epi+ε_R))，禁止用「预训练空间的可行性」替代本具身认证。

## 2. 关键算法骨架

```python
# IP-264 PBP：UniBot-V1 先验接口（实时只读蒸馏头 + 异步全量审计）
class PretrainedPrior:
    def __init__(self, unibot, distilled_head, provenance_index, calib):
        self.U, self.p_hat = unibot, distilled_head       # U 离线/异步
        self.prov, self.calib = provenance_index, calib    # 缓存溯源 + 分桶温度
    def support(self, modes, o):                           # 实时：查缓存
        return [(self.prov.S(m, o), self.prov.cov(m, o), self.prov.F(m, o))
                for m in modes]
    def prior(self, modes, o):                              # 实时：蒸馏头 + 分桶校准
        b = self.prov.bucket(o)
        return [self.calib[b].temp(self.p_hat(m, o)) for m in modes]
    def audit_async(self, event):                           # 离线：多头 + jackknife + 归因
        return (self.U.self_consistency(event),
                self.U.jackknife(event), self.U.attribute(event))

# IP-265 PTS：先验三态甄别（只否决，不认证）
def prior_screen(modes, w, o, P, cfg):
    p, sup = P.prior(modes, o), P.support(modes, o)
    state, p_pre = {}, {}
    for k, m in enumerate(modes):
        S, cov, F = sup[k]
        if S < cfg.s0 or cov < cfg.c0:             state[k] = 'SILENT'      # 先验无权威
        elif F > cfg.phi0:                          state[k] = 'SILENT'      # 单一出处，降级
        elif p[k] >= cfg.p0 and P.A(m) >= cfg.a0:   state[k] = 'SUPPORTED'
        else:                                       state[k] = 'CONTRADICTED'
        p_pre[k] = p[k]
    return state, p_pre

# IP-266 主闭环：在 R69 之后插入「单调否决层」
def PRIOR_RAS_round(M, obs):
    # --- 先原样执行 R69，得到保守解（这是天花板，不能被先验抬高）---
    z, o = M.mtm.forward(...);  c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    lam_r69 = max(M.efs.risk_scale(...), lam_floor(U_ale + U_epi))
    # --- PRIOR 否决层：只能收紧（定义 317）---
    alpha = M.prior.inject_strength(o)             # 全 SILENT / OOD → 0，逐字退化 R69
    state = {k: 'SILENT' for k in range(len(modes))}
    if alpha > 0:
        state, p_pre = prior_screen(modes, w, o, M.prior, M.prior.cfg)
        modes, w = apply_veto(modes, w, state)      # CONTRADICTED → 置零；SUPPORTED → 1 票
        if any(s == 'CONTRADICTED' for s in state.values()):
            lam_r69 = max(lam_r69, lam_floor(U_ale + U_epi + conflict_bonus(p_pre)))
            U_epi = max(U_epi, U_epi_conflict)       # 否决不假装消解了歧义
        # 证据纪律：预训练族最多 1 票，其余必须来自在线交互（定义 315/318）
        g = (M.mint.choose_interaction(modes, o, M.budget)
             if U_epi > TAU_EPI else None)
        if g is not None:
            U_epi = M.cia.update_belief(modes, M.cia.execute(g),
                                        k_eff=M.evidence.k_eff(p_pre))
    lam = max(lam_r69, lam_r69)                     # 显式单调，永不低于 R69
    # --- 执行与审计（继承 R69）---
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    mode = select_mode(modes, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_i.submit_async(state, alpha, M.prior.audit_async(...))  # 异步全量审计
    return k, lam, mode, (U_ale, U_epi)
```

## 3. 推导

**引理 19（先验否决的安全单调性）** 在 A95–A99 下，PRIOR 在任意状态上的约束违反期望风险 ≤ R69；λ 单调不降；可执行模态集单调不增。当所有模态 SILENT（α=0）时两者逐指令相同。证明要点：PRIOR 的唯一主动操作是（a）把 CONTRADICTED 模态置零/降权、（b）抬 λ；两者都不放宽 R69 的认证、证据、包络约束，故可行域只被收窄。**代价必须诚实**：否决的假阳性会误杀正确模态、抬高任务误差，其遗憾上界为「假否决率 × 被误杀模态的相对损失」，由 E303 直接测量并压入预算。

**引理 20（溯源可分性）** 设真模态的支撑集中在高相似度片（κ ≥ κ_0）且归因误差有界，幻觉模态的归因要么缺失、要么只落在低相似度片。则 S(m) 对两类有正间隔；在归因噪声 ε_a 下误分率 ≤ ε_a 的函数。系：仅凭先验概率 p_pre 不可分（先验可合法地给一个当前无在线证据的模式高分，例如「此刻相机恰好没看到左路」），**必须结合溯源**——这正是定义 313–314 的必要性。

**引理 21（陌生先验不否决）** 若 m ∉ 𝒯，PTS 判 SILENT，先验不得排除它。设真新颖模态比例为 ν，则安全不受影响，且在 ν 上的任务表现不劣于 R69（因为行为逐字相同）。系：这避免了「预训练没见过 ⇒ 错误地判为幻觉」的**新颖性税**；代价是 OOD 时 PRIOR 自动失去全部优势（α→0）——这恰是安全侧想要的「不知道就别装懂」。

**引理 22（同源证人不降投毒界）** 因 ℱ_pre 内部错误相关 ρ_pre≈1，R69 引理 18 的界 δ_p·ρ^{k−1}+ε_σ 中，把先验族加入并不会使 ρ^{k−1} 有效下降；有效独立数 k_eff = 1 + (k−1)(1−ρ_pre) ≈ 1（若 k 票全来自先验族）。故先验**不能**替代在线正交证据；它只能额外否决，无法把「问错」洗成「问对了」。**反例制度**：后门模态 m† 在所有头自洽、且被投毒片伪装成溯源充分 ⇒ SUPPORTED 但错误；唯一能揭穿它的是在线探针（E309），这就是「先验只否决、不认证」的定量理由。

**定理 18（PRIOR 严格包含 R69）** 在 A95–A99 下：(i) 安全侧 PRIOR 期望风险 ≤ R69 且 λ 单调不降；(ii) 当 U 禁用、全 SILENT、或 e_now 对预训练 OOD 时，PRIOR 与 R69 逐指令相同；(iii) 任务侧 PRIOR ≤ R69 + T_false_veto，T_false_veto 为假否决税。故 R70 是 R69 在「先验处处沉默」边界上的严格退化 + 一个单调否决超集；安全不让步，只在溯源确有权威处换得「能识破幻觉模态」的额外收益。

**定理 19（信赖域防遗忘）** 设模式熵 H_mode 对模式原型分布满足 Lipschitz 常数 L。定义 319 的 TRM 将微调后与预训练模式分布在 𝒯 上的 KL 限制在 ε_tr 内，则歧义检测召回 R = P(正确触发交互) 的下降满足 |R_ft − R_pre| ≤ L·√(2ε_tr)。当 ε_tr→0 时精确恢复预训练歧义先验。故「微调适应本具身」不必以「丢掉何时不确定」为代价。

**假设 A99** 溯源归因估计误差有界；κ(·,·) 是有效的具身/任务相似度度量；分桶校准集覆盖各支撑度档，且校准集本身不被投毒（否则定义 321 被攻破，见最大风险）。

## 6. 本轮最大风险

**一句话**：PRIOR-RAS 的最大风险是「**经验的暴政**」——UniBot-V1 的先验恰恰在最需要谨慎的跨具身场景里**最自信**（近邻溯源被多数具身淹没，S 高但语境最远），而它的自洽与溯源信号又与先验**同源相关**（ρ_pre≈1），无法充当独立第二意见；一旦预训练语料有系统性偏差或后门，系统会把「多数具身都这么做」盖成「有据可依」，用高置信度做错——这比 R69 的低置信度「不知道」更危险。

**次级风险与缓解**：
1. **置信度与适用性反相关**（越远的具身先验越平滑自信）→ 分桶校准（321）+ 溯源三态（314）+ E301/E311 直接测量；
2. **同源证人冒充交叉验证** → 相关性折算（315/318）+ k_eff 门 + E307，先验族最多 1 票；
3. **多数具身体制性偏差 / 经验暴政** → 偏差账本（322）+ 反事实溯源自检 + E308；
4. **预训练后门 / 溯源伪造** → 只否决不认证 + 分片 jackknife（316）+ 在线探针兜底 + E306/E309；
5. **微调遗忘「何时不确定」** → 模式空间信赖域（319）+ E310/E313；
6. **OOD 具身** → α 自动归零、逐指令退化 R69（定理 18-ii），宁可不借用也不乱借用。

## 3. 关键算法伪代码

```python
# IP-264/265 PBP+PLT：先验接口与溯源（实时只读，异步全量）
class PretrainedPrior:
    def support(self, modes, o):                          # 缓存：S, cov, F
        return [(self.prov.S(m,o), self.prov.cov(m,o), self.prov.F(m,o))
                for m in modes]
    def prior(self, modes, o):                            # 蒸馏头 + 分桶温度
        b = self.prov.bucket(o)
        return [self.calib[b].temp(self.p_hat(m,o)) for m in modes]
    def audit_async(self, ev):                            # 多头 + jackknife + 归因
        return (self.U.self_consistency(ev), self.U.jackknife(ev),
                self.U.attribute(ev))

# IP-266 PTS：三态甄别（只否决不认证）
def prior_screen(modes, o, P, cfg):
    p, sup, state = P.prior(modes,o), P.support(modes,o), {}
    for k,m in enumerate(modes):
        S,cov,F = sup[k]
        if S < cfg.s0 or cov < cfg.c0 or F > cfg.phi0:
            state[k] = 'SILENT'                 # 无权威 / 单一出处 → 沉默
        elif p[k] >= cfg.p0 and P.A(m) >= cfg.a0:
            state[k] = 'SUPPORTED'              # 一致：仅 1 票
        else:
            state[k] = 'CONTRADICTED'           # 有权威却矛盾 → 否决
    return state, p

# IP-269/274 主闭环：R69 先算天花板，PRIOR 只做单调否决
def PRIOR_RAS_round(M, obs):
    z, o = M.mtm.forward(...);  c,U_cal,thr = M.cof.step(...)   # R69
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale,U_epi,modes,_ = M.aud.decompose(M.fmp.sample(o,K), z, M.fmp.mode_head)
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + U_epi))  # R69 天花板
    alpha = M.prior.inject_strength(o)                          # OOD/全静默 → 0
    state = {k:'SILENT' for k in range(len(modes))}
    if alpha > 0:
        state, p_pre = prior_screen(modes, o, M.prior, M.prior.cfg)
        modes, w = apply_veto(modes, w, state)                  # CONTRADICTED→置零
        if any(s=='CONTRADICTED' for s in state.values()):
            lam = max(lam, lam_floor(U_ale + U_epi + conflict_bonus(p_pre)))
            U_epi = max(U_epi, U_epi_conflict)                  # 否决不假装消解
        g = (M.mint.choose_interaction(modes,o,M.budget)
             if U_epi > TAU_EPI else None)                      # 仅在线交互能定案
        if g is not None:
            U_epi = M.cia.update_belief(modes, M.cia.execute(g),
                                        k_eff=M.evidence.k_eff(p_pre))
    lam = max(lam, lam)                                         # 显式单调
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    mode = select_mode(modes, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_i.submit_async(state, alpha, M.prior.audit_async(...))
    return k, lam, mode, (U_ale, U_epi)
```

## 4. 推导

**引理 19（先验否决的安全单调性）** A95–A99 下，PRIOR 任意状态约束违反风险 ≤ R69，λ 单调不降，可执行模态集单调不增；全 SILENT（α=0）时逐指令相同。证明：主动操作只有「置零 CONTRADICTED」与「抬 λ」，二者只收窄 R69 的可行域。代价诚实：假否决提高任务误差，遗憾 ≤ 假否决率 × 被误杀模态相对损失（E303 测量）。

**引理 20（溯源可分性）** 真模态支撑集中于高相似度片、幻觉模态归因缺失或落在低相似度片 ⇒ S(m) 有正间隔，误分率受归因噪声 ε_a 控制。系：仅 p_pre 不可分（先验可合法地给「此刻没被看到」的模式高分），必须结合溯源。

**引理 21（陌生先验不否决）** `m∉𝒯 ⇒ SILENT`，先验不得排除；新颖模态比例 ν 下安全不变、ν 上表现不劣于 R69。系：避免「没见过 ⇒ 判为幻觉」的新颖性税；OOD 时 α→0，优势归零但绝不乱借用。

**引理 22（同源证人不降投毒界）** ℱ_pre 内部 ρ_pre≈1 ⇒ R69 引理 18 界 `δ_p·ρ^{k−1}+ε_σ` 不因加入先验而下降，`k_eff≈1`。故先验不能替代在线正交证据。反例：后门模态 m† 全头自洽、被投毒片伪装溯源充分 ⇒ SUPPORTED 却错误，唯有在线探针可揭穿（E309）。

**定理 18（PRIOR 严格包含 R69）** (i) 安全侧期望风险 ≤ R69、λ 单调；(ii) U 禁用 / 全 SILENT / 本具身 OOD 时与 R69 逐指令相同；(iii) 任务侧 ≤ R69 + T_false_veto。R70 = R69 的「先验处处沉默」退化 + 单调否决超集；安全不让步。

**定理 19（信赖域防遗忘）** 模式熵对原型分布 L-Lipschitz，TRM 约束 `KL_𝒯 ≤ ε_tr` ⇒ 歧义检测召回下降 `|R_ft−R_pre| ≤ L√(2ε_tr)`；ε_tr→0 精确恢复预训练歧义先验。

**假设 A99** 归因误差有界；κ 为有效具身度量；分桶校准集覆盖各支撑档且自身未被投毒（否则定义 321 被攻破——见最大风险）。

## 7. 本轮最大风险

**一句话**：PRIOR-RAS 的最大风险是「**经验的暴政**」——UniBot-V1 的先验恰恰在最需要谨慎的跨具身场景里最自信（近邻溯源被多数具身淹没，S 高但语境最远），而它的自洽与溯源信号又与先验**同源相关**（ρ_pre≈1），无法充当独立第二意见；一旦预训练语料有系统性偏差或后门，系统会把「多数具身都这么做」盖成「有据可依」，用高置信度做错——比 R69 的低置信度「不知道」更危险。

**次级风险与缓解**：置信度与适用性反相关（分桶校准 321 + 三态 314 + E301/E311）；同源证人冒充交叉验证（相关性折算 315/318 + k_eff 门 + E307）；多数具身体制性偏差（偏差账本 322 + E308）；预训练后门/溯源伪造（只否决不认证 + jackknife 316 + 在线探针 + E306/E309）；微调遗忘「何时不确定」（信赖域 319 + E310/E313）；OOD 具身（α→0、逐指令退化 R69，定理 18-ii）。
