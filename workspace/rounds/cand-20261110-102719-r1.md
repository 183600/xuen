# 第 43 轮 · JOULE-CERT：把「焦耳」写进证书——能耗-时序-安全三元对偶与单调蒸馏阶梯（四层架构 v8）

> 承接第 42 轮 v19（SCV × CKB × ECR）。第 42 轮自陈最大风险是「仿真偏差累积」与「检索幻觉」。本轮灵感词「能耗优化」「模型蒸馏」看似是上一轮「低成本部署」的延续，但真正的新意在于**视角翻转**：能耗不再只是成本项，而是决定「安全停车是否仍然可行」的**状态变量**；蒸馏不再只是把模型压小的**压缩手段**，而是构造一列**单调保守的证书阶梯**，让运行时可以按剩余焦耳与温度，在任意档位取到一个仍然 sound 的证书。一句话：**上一轮省的是算力，这一轮要省的是「每焦耳的安全裕度」**。

## 0. 直觉与动机

**灵感 1（能耗优化 → 电量不是油表，而是「安全停车预算」）**：传统电量管理把 b 当剩余续航，低电量就减速回家。但对认证自治而言，b 的真正含义是：**在当前位姿、负载、地形、扰动下，我还有没有足够的焦耳把机器人停到一个可证明安全的状态**。上坡、负重、湿滑地面、执行器卡滞都会抬高这个「安全停车能耗」E_stop(x)；而感知、规划、监控本身也在耗电。于是电量守卫应写成 `b ≥ E_stop(x) + ε_E + 未来认证开销`，并与 CAR 的转移守卫同级。更激进的一点：E_stop 不是最短路能耗，而是**扰动集合上的最坏情况能耗**——为了安全，必须按「最倒霉的地形/摩擦/负载」预留。

**灵感 2（能耗优化 → 省电动作会改写证书的时序前提）**：降频、休眠、关核、降低感知帧率都能省电，但它们同时让监控器变慢、让反应变迟。一个在 1.5GHz 下满足 10ms 截止期的证书，在 600MHz + 85°C 热节流下可能直接失效。因此需要一个**认证 DVFS 包络**：只允许运行时选择那些「在当前温度下 WCET 仍满足截止期，且监控自身能耗仍落在预算内」的 (档位, 频率) 对。注意最优频率通常不是最低频率：**race-to-idle**（快跑快睡）与 **slow-and-lean**（慢跑省动态功耗）之间存在一个「每焦耳安全决策数」的极值点。

**灵感 3（模型蒸馏 → 蒸馏的不是模型，是一列「越便宜越保守」的证书）**：第 42 轮的蒸馏是「教师浮点 → 学生 INT8」，只保证单点不低教师。本轮把它升级为**单调证书蒸馏阶梯** S_0 ⊂ S_1 ⊂ … ⊂ S_K：越便宜的学生必须**逐点更保守**（边际下界更小、E_stop 上界更大），于是运行时无论能量多紧，随便降到哪一档都仍然 sound；能量宽裕时再升档换取更激进的性能。教师不是单个网络，而是离线的「证书神谕 + 能量约束 MDP 求解器」；学生学的是 `(x̃) ↦ (j*, f*, 是否停车, 边际下界, E_stop 上界)`。再用 split conformal 给学生的误差做**运行时置信闸门**：区间不足以判定就升级到更贵档位，避免第 42 轮那种「高置信地静默失效」。

**耦合升级**：离线用仿真/RAG 算 E_stop 表与每条证书的「能耗指纹」；在线由 **Joule Governor** 在认证 DVFS 包络内选择 (档位, 频率)，并实时检查电量守卫；低电量或高温时自动降到更保守的学生档，若仍不满足则用预留焦耳执行 SafeStop。蒸馏阶梯、能量包络、安全守卫三者形成 **「离线算焦耳 → 在线花焦耳 → 低电量退回更保守证书」** 的闭环。

## 1. 形式化定义（增量：定义 38–44）

**定义 38（能量增广安全状态与鲁棒安全停车能耗）**：增广状态 x̃ = (x, b, ϑ)，b 为可用能量（J），ϑ 为温度/热状态。给定扰动集合 Δ 与安全停车策略类 Π_stop，定义
`E_stop(x) = max_{δ∈Δ} min_{π∈Π_stop} E[ Σ_t e(u_t, x_t, δ_t) ]`，边界为到达 S_safe 时 E_stop=0。
**能量安全集** K_E = { (x,b) : b ≥ E_stop(x) + ε_E }，其中 ε_E 覆盖模型误差与认证自身能耗。E_stop 满足鲁棒 Bellman 方程
`E_stop(x) = max_δ min_u { e(u,x,δ) + E_stop(f(x,u,δ)) }`，在网格/八叉树上值迭代求解。

**定义 39（能量参数化证书族与单调性）**：对每个能量预算 b 定义证书 C(b) = (K(b), θ(b), T_hold(b), j*(b), F_cert(b))，其中 K(b) 为可行的安全状态集，θ 为守卫阈值，j* 为最小充分档，F_cert 为认证频率集。要求**能量单调性**：b₁ ≥ b₂ ⇒ K(b₁) ⊇ K(b₂)，且 θ(b₁) ≤ θ(b₂)（能量越多，可承受的边际越低）。运行时证书必须带「适用能量区间」标签，超出区间即失效，不允许静默外推。

**定义 40（认证 DVFS 包络与能耗-时序契约）**：档位 j 在频率 f、温度 ϑ 下的 WCET 为 w_j(f,ϑ)，截止期为 D，监控自身能耗为 e_j^mon(f,ϑ)。**认证频率集**
`F_cert(x,b,ϑ) = { f : w_{j*(b)}(f,ϑ) + w_io ≤ D, 且 e_j^mon(f,ϑ)·N_h + e_act ≤ b − E_stop(x) − ε_E }`。
**认证最优频率** `f* = argmin_{f∈F_cert} [ P(f,ϑ)·w_{j*}(f,ϑ) + e_act ]`。证书对象必须同时记录 (f*, ϑ 适用范围, w 上界)；温度越界时证书自动降级或重认证。

**定义 41（单调证书蒸馏阶梯）**：教师 T（精确但昂贵）给出证书泛函 C*。学生阶梯 S_0,…,S_K 满足计算成本 c_0<…<c_K、能耗 e_0<…<e_K，且逐点满足
`m_0(x) ≤ m_1(x) ≤ … ≤ m_K(x) ≤ m_T(x)`，`Ê_0(x) ≥ Ê_1(x) ≥ … ≥ Ê_K(x) ≥ E_stop(x)`，
其中 m_k 为第 k 档输出的边际下界，Ê_k 为安全停车能耗上界。**越便宜越保守**，因此任意档位单独使用时都保 sound。训练损失
`L_MCD = Σ_k [ L_task + λ_c L_cert + λ_o L_order + λ_e L_energy ]`，
`L_order = Σ_k max(0, m_k − m_{k+1}) + max(0, Ê_{k+1} − Ê_k)`；训练后再用保序投影/区间钳制把离散化造成的越序严格压回零。

**定义 42（焦耳策略蒸馏与 conformal 置信闸门）**：教师策略 π* 求解能量约束 MDP：
`min_π E[Σ_t e_t]  s.t.  P(不安全) ≤ δ,  b_t ≥ E_stop(x_t)+ε_E`。
学生 π_φ: x̃ ↦ (j, f, stop_flag, m̂, Ê) 由教师轨迹做策略蒸馏。用 split conformal 在标定集上取非一致性分数 `s = max(0, m_T − m̂, Ê − E_stop)`，得到运行时区间 [m_lo, m_hi] 与 [Ê_lo, Ê_hi]。**闸门规则**：仅当 `m_lo ≥ θ` 且 `Ê_hi ≤ b − ε_E` 才采纳学生决策；否则升档到 k+1，直到教师档或直接 SafeStop。由此得到边际误判率 ≤ α 的概率保证（在可交换性假设下）。

**定义 43（焦耳证书与剩余安全运行时间）**：`τ_safe(x,b,ϑ) = (b − E_stop(x) − ε_E) / P_ub(x,ϑ)`，其中 P_ub 是当前策略在温度 ϑ 下的平均功率上界。τ_safe 是给人类与上层的「剩余安全分钟数」证书；当 `τ_safe < τ_react + τ_stop` 时，CAR 必须提前进入 SafeStop，而不是等到 b < 0。

**定义 44（能耗指纹知识库与能量可行检索）**：KB 记录扩展为 `(φ, ψ, ε, C, Ξ, Π)`，其中能耗指纹 ε = (E_stop 表摘要、各档能耗、热包络、负载敏感度、电池老化因子)。检索器在相似度之外增加**能量可行性过滤**：只返回在目标平台 (b, ϑ, 负载) 下仍可行的模板；组合代数中能量预算按
`E_stop^{A⊗B} ≤ E_stop^A + E_stop^B + E_couple` 预留耦合损耗，守卫取合取、能量预留取「和 + 耦合项」，并检查接口能耗契约是否匹配。

## 2. 三大新增产出 + 既有 IP 升级

### 2.1 IP-57 JOULE-SAFE-KERNEL（JSK，焦耳安全核）
1. **鲁棒 E_stop 值迭代**：在 (x, 负载, 地形类别) 网格上对扰动集合做最坏情况备份，得到 E_stop 表；用 Lipschitz 界做插值并给出上界，保证「表值 ≥ 真实最坏能耗」。
2. **电量守卫进 CAR**：新增转移边 `b < E_stop(x)+ε_E+认证开销 ⇒ SafeStop`，与几何/语义守卫并列，且优先级最高、不可被上层任务覆盖。
3. **焦耳证书**：输出 τ_safe、E_stop 置信上界、当前能量下的证书档位；低电量时自动切换更保守的 C(b)。

### 2.2 IP-58 CERT-DVFS（CDVFS，认证动态调频）
1. **热-时序-能耗三联表**：离线测 w_j(f,ϑ) 与 P(f,ϑ)，在线用温度/电流传感器做保守包络更新；只暴露 F_cert 内的频率。
2. **认证最优频率选择**：按「每焦耳安全决策数」而非最低功耗选 f*，显式处理 race-to-idle vs slow-and-lean 的非单调性。
3. **热节流看门狗**：温度越界或电压跌落时，立即锁到最低认证频率并降档，禁止在未认证频率上继续运行监控器。

### 2.3 IP-59 MONOTONE-DISTILL-LADDER（MDL，单调蒸馏阶梯）
1. **教师**：离线证书神谕 + 能量约束 MDP 求解器，生成 (x̃, j*, f*, stop, m_T, E_stop) 标签。
2. **阶梯训练**：K 个学生共享主干、不同宽度/量化位宽；用 L_MCD 强制逐点保序，训练后做保序钳制与 10 万点验证（越序必须为 0）。
3. **conformal 闸门与升档**：运行时逐档检查区间；不决定就升档，仍不决定就 SafeStop；记录升档率与闸门能耗开销。
4. **量化部署**：每档导出 INT8/INT4 与 WCET/RAM 清单，与 IP-56 ECR 的 L0/L1 运行时对接。

## 3. 四层架构 v8

```
L1: TRI-FUSE(INT8) + IP-49 LIO + 电流/温度/电压采样 → x̃=(x,b,ϑ) + B_t + E_stop 表查询
L2: CTC + VLM + IP-35 仲裁 → R_φ(w) + 几何残差证书 + 能耗指纹 ε + 负载估计
L3: IP-51 CAR(电量守卫 τ_safe) ← IP-56 ECR(L0 查表 + 单调学生阶梯 + Joule Governor)
    → IP-58 CDVFS(认证频率包络) → IP-47 乘积模板(能量预留组合) → IP-39 规划(CBF margin + E_stop)
    → IP-45 总线(焦耳心跳) → IP-48 认证流匹配(N*=查表) + IP-43 韵律调度
L4: IP-55 CKB(能耗指纹检索) ← IP-54 SCV(域随机化 + 负载/地形/电池老化压力测试)
    → IP-57 JSK(鲁棒 E_stop 值迭代) + IP-59 MDL(教师神谕→保序学生阶梯→conformal)
    → IP-53 CMC(能量感知导出) + IP-50 课程(低电量/高温工况) → RCA 重颁含能量区间的证书
运行期：查 E_stop/τ_safe → 选 (j,f) ∈ F_cert → 学生闸门 → 不足则升档/SafeStop → 焦耳心跳回传
```

## 5. 本轮最大风险

**一句话**：低电量、高温与高负载三者叠加时，蒸馏学生恰好进入训练分布最稀疏的尾部，而 DVFS 降频又把监控器 WCET 推近截止期——「越省电越不安全」的自噬螺旋会让电量守卫在最需要它的时候先失效；因此 E87（E_stop 实测）、E90（保序零越序）与 E91（conformal 误安全率）必须作为红线，任一不达标即熔断回退到解析上界 + 固定频率 + 教师档。

## 1. 符号体系（增量：定义 38–44 符号）

| 符号 | 含义 | 定义 |
|---|---|---|
| x̃ = (x, b, ϑ) | 能量增广状态 | 位姿/速度 x、可用能量 b（J）、温度/热状态 ϑ |
| E_stop(x) | 鲁棒安全停车能耗 | 扰动集合上最坏情况的最小停车能耗，鲁棒 Bellman 解 |
| K_E = {(x,b): b ≥ E_stop+ε_E} | 能量安全集 | 剩余能量足以覆盖最坏停车与认证开销 |
| C(b) = (K(b), θ(b), T_hold(b), j*(b), F_cert(b)) | 能量参数化证书 | 随 b 单调：b↑ ⇒ K↑、θ↓ |
| F_cert(x,b,ϑ) | 认证频率集 | WCET 满足截止期且监控能耗在预算内的频率集合 |
| f* | 认证最优频率 | argmin 每焦耳安全决策的总能耗，非单纯最低频率 |
| m_k, Ê_k | 第 k 档学生边际下界/停车能耗上界 | 满足 m_0≤…≤m_K≤m_T，Ê_0≥…≥Ê_K≥E_stop |
| L_MCD | 单调证书蒸馏损失 | L_task+λ_c L_cert+λ_o L_order+λ_e L_energy |
| [m_lo,m_hi], [Ê_lo,Ê_hi] | conformal 运行时区间 | 仅当 m_lo≥θ 且 Ê_hi≤b−ε_E 才采纳学生决策 |
| τ_safe = (b−E_stop−ε_E)/P_ub | 剩余安全运行时间证书 | 当前策略与温度下的保守「安全分钟数」 |
| ε = (E_stop表, 各档能耗, 热包络, 负载敏感度, 老化因子) | 能耗指纹 | KB 检索与组合的能量可行性依据 |

## 2. 关键算法（伪代码）

### IP-57 JSK：鲁棒 E_stop 值迭代与电量守卫
```
def robust_energy_to_stop(X_grid, U, Delta, S_safe, e_fn, f_fn, gamma=0.99):
    E = {x: 0.0 for x in S_safe}
    for x in X_grid - S_safe:
        E[x] = +inf
    repeat until max_change < eps:
        for x in X_grid - S_safe:
            worst = 0.0
            for delta in Delta:                      # 最坏扰动
                best = +inf
                for u in U:
                    x_next = f_fn(x, u, delta)
                    cost = e_fn(u, x, delta) + gamma * lookup_or_inf(E, x_next)
                    best = min(best, cost)
                worst = max(worst, best)             # max-min：鲁棒
            E_new[x] = worst
        E = E_new
    return upper_bound_table(E)                      # 插值后仍取上界，保 sound

def joules_guard(x, b, theta, cert):
    e_stop_ub = lookup_estop_ub(cert.estop_table, x)  # 保守上界
    e_cert = cert.monitor_energy_next_frame          # 本拍认证开销上界
    tau = (b - e_stop_ub - cert.eps_E) / cert.power_ub(x)
    if b < e_stop_ub + cert.eps_E + e_cert or tau < cert.tau_react + cert.tau_stop:
        return 'SAFE_STOP', {'e_stop_ub': e_stop_ub, 'tau': tau}
    return 'OK', {'e_stop_ub': e_stop_ub, 'tau': tau}
```

### IP-58 CDVFS：认证频率包络与最优频率
```
def certified_freq_set(x, b, theta, j, thermal, C):
    feas = []
    for f in C.freq_levels:
        w = C.wcet[j][f].at(thermal.temperature)      # 查热-时序表，取上界
        e_mon = C.power[f].at(thermal.temperature) * w
        e_act = C.act_energy[j]
        if w + C.w_io <= C.deadline and e_mon * C.N_h + e_act <= b - C.e_stop_ub[x] - C.eps_E:
            feas.append((f, e_mon * C.N_h + e_act))
    return feas

def select_certified_frequency(x, b, theta, j, thermal, C):
    feas = certified_freq_set(x, b, theta, j, thermal, C)
    if not feas:
        return None, 'NO_CERTIFIED_FREQ'               # 触发降档或 SafeStop
    # 注意：目标不是最低频率，而是每焦耳完成的安全决策数最大
    f_star = min(feas, key=lambda item: item[1] / max(1e-9, C.throughput[j][item[0]]))[0]
    return f_star, 'OK'

def thermal_watchdog(thermal, C):
    if thermal.temperature > C.t_max_cert or thermal.voltage < C.v_min_cert:
        return 'LOCK_MIN_CERT_FREQ'                   # 立刻锁到最低认证频率并降档
    return 'NOMINAL'
```

### IP-59 MDL：单调学生阶梯、保序投影与 conformal 闸门
```
def train_monotone_ladder(teacher, X_tilde, K, budgets, calib_split=0.2):
    labels = [teacher(x) for x in X_tilde]            # (j*, f*, stop, m_T, E_stop)
    X_tr, X_cal = split(X_tilde, calib_split)
    students = [init_student(k, budgets[k]) for k in range(K)]
    for epoch in range(E):
        for batch in X_tr:
            losses = []
            for k, s in enumerate(students):
                m_k, e_hat_k = s(batch)
                L_task = task_loss(m_k, label_m(batch))
                L_cert = relu(label_theta(batch) - m_k).mean()
                L_energy = (e_hat_k - label_estop(batch)).abs().mean()
                losses.append(L_task + LAMBDA_C*L_cert + LAMBDA_E*L_energy)
            # 保序：便宜档必须更保守
            for k in range(K-1):
                m_k, e_k = students[k](batch)
                m_k1, e_k1 = students[k+1](batch)
                L_order = relu(m_k - m_k1).mean() + relu(e_k1 - e_k).mean()
                losses[k] += LAMBDA_O * L_order
            update_all(students, losses)
    for k, s in enumerate(students):
        s.apply_order_projection(students[k+1] if k+1 < K else None)  # 训练后硬钳制
    conformal = {}
    for k, s in enumerate(students):
        scores = [conformal_score(s(x), teacher(x)) for x in X_cal]
        conformal[k] = quantile(scores, 1-ALPHA)
    return students, conformal

def gate_and_escalate(x_tilde, b, theta, students, conformal, cert):
    for k in range(len(students)):
        m_hat, e_hat = students[k](x_tilde)
        m_lo = m_hat - conformal[k]
        e_hi = e_hat + conformal[k]
        if m_lo >= theta and e_hi <= b - cert.eps_E:
            return {'tier': k, 'm_lo': m_lo, 'e_hi': e_hi, 'status': 'ACCEPT'}
    return {'tier': None, 'status': 'SAFE_STOP'}      # 连教师档都不决定 → 停车
```

### IP-56/51/52 升级：Joule Governor 与能量感知自动机
```
def joule_governor(x_tilde, guards, cert):
    x, b, thermal = x_tilde
    # 1) 能量守卫优先于一切任务
    status, info = joules_guard(x, b, cert.theta, cert)
    if status == 'SAFE_STOP':
        return 'SAFE_STOP', info
    # 2) 选最小证书档 j*，再在认证频率包络内选 f*
    j_star = cert_lookup_L0(x).j_star
    f_star, fs = select_certified_frequency(x, b, cert.theta, j_star, thermal, cert)
    if fs != 'OK':
        j_star, f_star = downgrade_one_tier(j_star, cert)   # 降档再试
        if j_star is None:
            return 'SAFE_STOP', {'reason': 'no_certified_freq'}
    # 3) 学生闸门；不决定则升档
    decision = gate_and_escalate(x_tilde, b, cert.theta, cert.students, cert.conformal, cert)
    if decision['status'] == 'SAFE_STOP':
        return 'SAFE_STOP', decision
    return 'RUN', {'tier': decision['tier'], 'f': f_star, 'm_lo': decision['m_lo']}

# CAR 转移守卫：能量与几何/语义守卫并列，且能量守卫不可被上层覆盖
def car_transition_guard(e, x_tilde, cert_obj):
    x, b, thermal = x_tilde
    if joules_guard(x, b, cert_obj.theta, cert_obj)[0] != 'OK':
        return False
    theta_real = cert_obj.alpha_e[e] * cert_obj.theta_sim[e]
    margin = cert_lookup_L0(x).m_lo[e]
    return margin >= theta_real

# LCS：二维档位 (j,f)，预算包含监控能耗与 SafeStop 预留
def certify_light_v3(x_tilde, guards, budget_us=200, cert=None):
    x, b, thermal = x_tilde
    if joules_guard(x, b, cert.theta, cert)[0] != 'OK':
        return 'SAFE_STOP', -1
    b0 = cert_lookup_L0(x)                            # T-1
    U = undecided_guards(b0, guards)
    if not U:
        return b0, -1
    f_star, fs = select_certified_frequency(x, b, cert.theta, 0, thermal, cert)
    if fs != 'OK' or budget_us < cert.wcet[0][f_star] + cert.w_io:
        return downgrade_monotone(b0), -1
    decision = gate_and_escalate(x_tilde, b, cert.theta, cert.students, cert.conformal, cert)
    return decision, decision['tier']
```

### IP-55/47 升级：能耗指纹检索与组合能量代数
```
def retrieve_energy_feasible(phi, psi, b, thermal, payload, KB, k=5):
    cand = KB.retrieve(phi, psi, k=3*k)               # 先相似度召回
    feasible = []
    for c in cand:
        e_need = c.energy_fingerprint.estop_ub(phi, psi, payload) + c.eps_E
        if e_need <= b - thermal_derate(thermal) and c.thermal_env.contains(thermal):
            feasible.append((c, e_need))
    return sorted(feasible, key=lambda item: item[1])[:k]   # 能量更省的优先

def compose_energy_budget(certA, certB, coupling):
    e_stop = certA.e_stop_ub + certB.e_stop_ub + coupling.e_couple
    e_peak = max(certA.e_peak, certB.e_peak + coupling.e_handoff)
    guards = intersect_guards(certA.guards, certB.guards)   # 守恒：合取
    invariants = intersect_invariants(certA.invariants, certB.invariants)
    return Certificate(
        guards=guards, invariants=invariants,
        e_stop_ub=e_stop, e_peak=e_peak,
        e_reserve=e_stop + coupling.eps_E,
        contracts=check_energy_contracts(certA, certB, coupling)
    )
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性保证 |
|---|---|---|---|
| IP-57 E_stop 值迭代 | 离线 O(iter·|X|·|U|·|Δ|)，仿真并行 | 表 O(|X|) | max-min 鲁棒 Bellman；插值取上界 ⇒ E_stop 表 ≥ 真实最坏能耗，保 sound |
| IP-57 电量守卫 | O(1) 查表 + 比较 | O(1) | b ≥ E_stop_ub+ε_E+认证开销 ⇒ 预留焦耳足以 SafeStop |
| IP-58 认证频率选择 | O(|F|·K) ≈ 常数（≤4 档×8 频率） | O(1) | 仅在 F_cert 内选频；WCET 与能耗均取上界 ⇒ 时序与能量契约同时成立 |
| IP-58 热节流看门狗 | O(1) | O(1) | 温度/电压越界即锁最低认证频率，禁止未认证频率运行 |
| IP-59 阶梯训练 | 离线 O(E·N·Σ_k c_k) | O(Σ_k params_k) | 保序投影 + 10 万点零越序验证 ⇒ 任意档位 sound；conformal 给误判率 ≤ α |
| IP-59 运行时闸门 | O(K·c_k)，K≤4 | O(1) | 仅当 m_lo≥θ 且 Ê_hi≤b−ε_E 采纳；否则升档/停车 ⇒ 无静默误安全 |
| IP-55 能量可行检索 | O(log N + k·d + k·|ε|) | 索引 O(N·d) | 只返回 E_stop_ub+ε_E 可行模板；指纹取保守上界 ⇒ 选出的模板能量可行 |
| IP-47 组合能量代数 | O(|E_A|+|E_B|) | 乘积自动机 O(|Q_A|·|Q_B|) | 守卫合取 + 能量子和 + 耦合预留 ⇒ 组合证书不弱于分量证书 |
| IP-51 CAR 能量守卫 | O(1) + O(|E|) 查表 | 同 L0 | 能量守卫优先级最高且不可抢占 ⇒ 低电量不会被任务逻辑拖过安全点 |
| IP-52 LCS v3 | 通常 T-1/T0 仅 ~110μs | 同 L0+阶梯 | (j,f) 仅取认证对；不足即单调降档/SafeStop ⇒ 决策与全量证书一致 |

## 5. 风险与缓解（增量）

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 低电量-高温-高负载尾部的蒸馏外推失真 | 高 | 训练集按 b、ϑ、负载分层并过采样尾部；conformal 闸门；b < b_crit 时强制切解析 E_stop 上界 + 教师档 |
| DVFS 降频导致监控 WCET 超截止期 | 高 | 只允许 F_cert 内频率；热-时序表取上界并在线更新；温度/电压越界立即锁最低认证频率或 SafeStop |
| 单调阶梯被量化/离散化破坏，出现越序 | 高 | L_order 损失 + 训练后保序投影 + 10 万点零越序验证；任一越序禁止发布 |

| E_stop 模型与真实负载/地形偏差 | 中 | 在线负载估计；能耗指纹含负载敏感度；实机标定修正因子；E_stop 表取上界 |
| 电池老化导致内阻上升、峰值电流下电压跌落复位 | 中 | 电池老化因子进 ε 指纹；电压跌落看门狗；限制峰值频率爬升速率 |
| 组合能量预算的非可加性被低估 | 中 | 耦合项 E_couple 离线标定并留裕度；组合后全量能量重认证；接口契约含峰值功率 |
| 能耗指纹检索到不相似但省电的模板 | 中 | 相似度与能量可行性双阈值；检索后仍走差集补全；人工确认高风险模板 |

## 6. 本轮最大风险

**一句话**：低电量、高温与高负载三者叠加时，蒸馏学生恰好进入训练分布最稀疏的尾部，而 DVFS 降频又把监控器 WCET 推近截止期——「越省电越不安全」的自噬螺旋会让电量守卫在最需要它的时候先失效；因此 E87（E_stop 实测）、E90（保序零越序）与 E91（conformal 误安全率）必须作为红线，任一不达标即熔断回退到解析上界 + 固定频率 + 教师档。
