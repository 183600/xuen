# 第 3 轮（灵感循环第 3 轮；本轮灵感：「数据规模」×「决策规划」）

> **基线继承**：第 2 轮 ToolGauge（IP-315–320；定义 416–431；引理 46–50；实验 E426–E439）。
> **本轮定位**：不新增视觉/语言能力，而是回答两个“元问题”：**要多少数据才够？下一单位数据花在哪一维？**（数据规模）与**在有限预算下按什么顺序、修哪些盲区、何时停？**（决策规划）。
> **命名**：**ScaleGauge**（Scaling-Law-Calibrated, Decision-Focused Metrology）。
> **纪律**：所有新模块必须给出可证伪的定量预测（标度指数、后悔界、证书覆盖率），并保留 ToolGauge 的严格退化链。

## 0. 直觉解释

### 灵感 1（数据规模 → 一条有拐点、会饱和、可能反噬的曲线）

ToolGauge 的 E429 已经观察到“更少回执达到更高精度”，但那是**单点**结论。把预训练语料 M、已修复盲区数 N、工具库大小 K 同时放大时，早期每一项都近似幂律降风险，过了某个拐点后边际收益递减；更隐蔽的是，若把所有回执无差别塞进 AP-Cal 的上下文，低信息量回执会稀释注意力与有效样本量，使误差曲线出现**逆向段**（context dilution）。因此“数据规模”的正确定义不是数据集大小，而是**有效数据量** N_eff = ρ·N，其中 ρ 是由主动回执选择决定的“数据食量比”。由此得到一个可操作的问题：给定总预算，如何在 M / N / K 之间分配使风险最小？这是凸优化里的水位填充（water-filling），最优性可由 KKT 条件直接刻划。

### 灵感 2（决策规划 → 修复盲区是序贯决策，不是逐点贪心）

ToolGauge 的 T-Box 对每个盲区独立做“风险门 + 增益注 + 增益/代价排序”，本质是**近视贪心**。它漏掉了三件事：(i) 多个盲区可能共享一次工具调用（机会成本）；(ii) 先修 A 会改善 B 的先验（信息复用，收益非可加）；(iii) 预测增益 Ĝ 有误差，而“预测最准”不等于“决策最优”——这是 predict-then-optimize 与 decision-focused learning 的经典失配。把修复过程写成有限时域 POMDP 后，“选哪个盲区、下一条探测程序、何时停止”成为同一个策略问题，回报是**全局风险的下降**而非局部预测精度。

### 灵感 3（两条灵感轴在同一处合流：主动采数据本身就是规划）

若把标度律 η(M,N,K) 看作 MDP 的（粗粒化）转移模型，那么“下一单位数据预算花在哪”就是 MDP 的动作；反过来，规划所需的状态之一正是“当前数据是否充分”。于是 ScaleGauge 把 ToolGauge 的 6C 闭环前置一个 S（Scale/Allocate）阶段、并在校准中插入 D（Data diet）阶段：**S → H → C → E → C(D) → V → U**，称为 7C。一个必须一开始就说清的边界：标度律只是**经验插值**，不是物理定律；它的外推必须被守卫约束。

## 1. 形式化定义

### 定义 432（全局计量风险与标度律）

设第 s 个盲区修复后的真实后验协方差为 Σ*(s)，AP-Cal 输出 Σ̂(s)。定义归一化全局风险

R(M,N,K) = E_s[ ‖Σ̂(s;M,N,K) − Σ*(s)‖_F / ‖Σ*(s)‖_F ]。

经验标度律假设

R(M,N,K) = R∞ + a·M^{−α} + b·(ρN)^{−β} + c·K^{−γ} + e·M^{−α}(ρN)^{−β}，   (η)

其中 R∞ ≥ 0 为不可约风险，α,β,γ>0，ρ∈(0,1] 为数据食量比。拟合在 log 域做加权最小二乘，并用 bootstrap 给出 (α,β,γ) 的置信区间。**定义域外推（out-of-support）一律禁用**，除非通过定义 439 的外推/漂移守卫。

### 定义 433（数据预算与水位填充）

令单位预算成本 c_M,c_N,c_K，预算 D=(B_M,B_N,B_K)。记边际收益

g_M = −(1/c_M)·∂R/∂M，g_N = −(1/c_N)·∂R/∂N，g_K = −(1/c_K)·∂R/∂K。

连续松弛下最优分配满足 KKT：活跃维度 g_M=g_N=g_K=μ，非活跃维度 ≤ μ。离散整数分配用“按边际收益排序的贪心 + 边界交换”求近似，并给出整数间隙界（引理 52）。

### 定义 434（修复规划 POMDP）

𝓜 = (𝒮, 𝒜, 𝒪, T, Ω, r, H, γ_d)。状态 x=(信念 {q(u_s)}, 剩余预算, 已修复集合)；动作 a=(选择盲区 s, 选择探测程序 Π_s) 或 STOP；观测为回执流，信念更新用 MP-Φ（定义 420）；单步回报

r(x,a) = Δ_s R（按当前信念估计的全局风险下降） − λ_c·cost(a) − η_risk·1[风险门未过]，

有限时域 H，策略 π。与 ToolGauge 的差异：动作空间跨盲区、回报是全局量、且允许 STOP。

### 定义 435（决策聚焦目标与规划后悔）

设 Ĝ 为代理增益预测器，φ 为规划求解器，V(plan) 为按 𝓜 展开的期望折扣回报。定义规划后悔

Reg(π) = max_{plan∈Φ} V(plan) − V(π(Ĝ))。

决策聚焦训练最小化 L_DF(θ) = E_{Ĝ~p_θ}[ −V(φ(Ĝ)) ]，用 SPO+ / 扰动 top-k 的可微代理实现；对照的 predict-then-optimize (PTO) 先回归 Ĝ 再规划。引理 53 给出两者后悔差的上界。

### 定义 436（决策感知回执选择 / 数据食量）

给定候选回执集 ℛ，选择 𝒮 ⊆ ℛ, |𝒮|≤k，最大化

F(𝒮) = ∑_{s} Δ_s R(𝒮) − κ·redundancy(𝒮)，

其中 Δ_s R 由 AP-Cal 的后验方差收缩估计。F 在独立回执假设下近似子模（引理 54），用惰性贪心；k 由“上下文稀释拐点” k* 决定：∂F/∂k < ε_dilute 即停止。数据食量比 ρ = info(𝒮)/info(ℛ)。

### 定义 437（数据充分性证书）

对目标误差 ε，由定义 426 的解析下界与 (η) 的反解联合给出

N*(ε) = max{ σ_obs²(ε⁻² − σ_0⁻²), η_N^{−1}(ε − R∞ − 其余项) }。

证书 Cert = (N_obs, N*(ε), R̂(ε) ± CI_95)。**若 N_obs < N*(ε) 或外推点落在支撑域外，禁止 AP-Cal 先验升级（hot replace），只允许局部 BP-Cal 更新。** 该约束与 ToolGauge 的 V 阶段独立回执交叉验证正交，二者需同时通过。

### 定义 438（7C 闭环）

S（标度律拟合 + 水位分配）→ H（共形假设）→ C（TCV 编译）→ E（工具执行）→ C（AP-Cal + D 数据食量）→ V（独立回执交叉验证 + 契约回归 + **数据充分性证书**）→ U（热替换 + 证书绑定）。任一步失败 ⇒ 降级到 ToolGauge 对应子步骤。

### 定义 439（外推守卫与漂移检测）

维护拟合支撑域 𝔇 = conv(log M, log N, log K 的观测网格)。请求点 x ∉ 𝔇 时：若距离 d(x,𝔇) ≤ δ_extrap 且 P-Quarantine（定义 428）未触发，则用保守包络 R̂ + z_{0.95}·σ_R 分配；否则回到均匀分配并告警。部署分布与拟合分布的 TV 距离 > η′_max 时，禁用标度律外推。

### 定义 440（严格退化链）

ScaleGauge ⇐ ToolGauge ⇐ LeanGauge ⇐ MODGAUGE：标度律 CI 过宽 / 外推守卫拒绝 / DFL 策略未通过契约回归 / 数据食量 ρ < ρ_min ⇒ 逐级回退；VLA 与规划器均为增强项而非依赖项。

## 2. 关键算法骨架

```python
# IP-321 η-Fit：标度律拟合 + 外推守卫
def fit_scaling(history, boots=200):        # history: [(M, N, K, rho, R)]
    X = log_features(history)               # [log M, log N, log K, ...]
    y = log(history.R - R_inf_est)
    w = irls_fit(X, y)                      # 加权最小二乘（R_inf 联合搜索）
    ci = bootstrap_exponents(history, boots)
    support = convex_hull(X)
    return ScalingLaw(w, ci, support)

def guarded_predict(law, M, N, K, pquar):
    x = log_features([(M, N, K)])
    if x not in law.support:
        if pquar.triggered() or dist(x, law.support) > DELTA_EXTRAP:
            return conservative_envelope(law, x)   # 上包络 + z*sigma
    return law.risk(M, N, K)

# IP-322 WF-Alloc：水位填充（连续 KKT + 整数回退）
def allocate(law, budgets):
    mu = solve_marginal_equalization(law, budgets)  # 二分求 mu
    cont = argmax_allocation(law, budgets, mu)
    return greedy_integer_round(cont, budgets)      # 边界交换

# IP-323 DFP-Box：决策聚焦规划（H 步滚动）
def plan(policy, state, H=3):
    plans = []
    for _ in range(H):
        G = policy.predict_gain(state)              # 代理增益
        a = perturbed_topk_plan(G, state)           # 可微规划层
        plans.append(a)
        state = policy.expected_next(state, a)      # 期望转移
        if state.should_stop(): break
    return plans

def dfl_loss(policy, batch):
    # L_DF = E[-V(phi(Ghat))]；SPO+ 代理
    return mean(-spo_plus_value(policy, b) for b in batch)

# IP-324 DDiet：决策感知回执选择
def select_receipts(receipts, k):
    S, pq = set(), lazy_priority_queue(receipts, delta_gain)
    while len(S) < k:
        r, g = pq.pop_max()
        if g < EPS_DILUTE: break                    # 上下文稀释拐点
        S.add(r); pq.update_marginals(r)
    return S

# IP-326 ScaleGauge 7C
def scalegauge_7c(M, s):
    law = M.eta_fit.current
    alloc = M.wf_alloc.allocate(law, M.budgets)
    H = M.lbox.hypothesize(s, M.dbox.R[s])
    prog = M.tbox.select(H, M.tools, M.tcv, alloc.N)
    receipts = M.tcv.execute(prog, M.env)
    receipts = M.ddiet.select_receipts(receipts, k_star(s))
    mu, Sig = M.apcal.calibrate(receipts, H, s)
    if not M.apcal.cross_validate(mu, Sig, M.cross_receipt(s)):
        return stub_and_red(s, "cross_failed")
    cert = M.scert.certify(s, M.budgets, target_eps=M.eps)
    if not cert.ok:                                  # 数据不充分
        return stub_and_red(s, "insufficient_data")
    new_ec = M.apcal.update_contract(M.dpe, mu, Sig, s)
    if not contract_regression(new_ec): return stub_and_red(s, "regression")
    M.mreg.hot_replace(M.dpe, new_ec); bind_claims(new_ec, H, prog, receipts)
    M.eta_fit.observe(alloc, receipts, s)            # 在线更新标度历史
    return True
```

## 4. 推导

**引理 51（标度律指数的可辨识性）** 若 R 精确服从 (η)，观测噪声 σ_R，且在 log M 上取 n 个点、跨度 L=span(log M)，则指数估计的标准误满足 SE(α̂) ≈ σ_R / (sd(log M)·√n)。要把 α 辨识到 ±0.1，至少需要约 3 个倍增（8×）的 M 跨度与 n≥6；否则 CI 宽度不可接受。⇒ 定义 439 的“外推禁用”不是保守，而是统计上必要。

**引理 52（水位填充最优性与整数间隙）** 当 R 关于 (M,N,K) 凸且边际收益递减时，KKT 等边际解全局最优；整数化贪心（允许一项分数松弛）的风险满足 R_int ≤ R_cont + max_i g_i·Δ_i，其中 Δ_i 为最小预算块。该间隙随预算块变小而线性收敛到 0。

**引理 53（决策聚焦 vs 预测优先的后悔界）** 设 |Ĝ−G|_∞ ≤ ε_Ĝ，V 对增益向量 L-Lipschitz，规划器 φ 的近似间隙为 δ_φ。则
Reg(π_DF) ≤ 2L·ε_Ĝ + δ_φ；
而 PTO 额外承受“在错误增益下选错计划”的优化间隙，当最优与次优计划值接近时（高风险门场景常见），可放大到 𝒪(L·ε_Ĝ·√N)。这解释了为什么“预测更准”不一定“决策更好”。

**引理 54（数据食量的子模性与拐点）** 在回执条件独立、Gaussian 后验下，信息增益 log det(Σ_pre) − log det(Σ_post) 关于选中集合单调子模 ⇒ 贪心达到 (1−1/e) 近似。后验方差收缩存在饱和点 k*；超出 k* 后冗余回执主导，F 的边际下降，故盲目增大 N 会进入 context dilution 逆向段。

**引理 55（证书-热替换安全性）** 若定义 437 的 Cert 以 1−δ 覆盖真实 N*(ε)，则“仅当 Cert.ok 才热替换”使错误先验升级的概率 ≤ δ；该约束与 ToolGauge 的交叉验证约束（错误率 ≤ δ_cross）在给定独立回执时条件独立，联合失败概率 ≤ δ + δ_cross。

**引理 56（严格退化单调性）** 任一 ScaleGauge 模块失效时按定义 440 回退到 ToolGauge，其风险不超过 ToolGauge 基准；即启用全部守卫的 ScaleGauge 是 ToolGauge 的 risk-non-increasing 扩展。

## 5. 本轮最大风险

**一句话**：标度律只在有限的 (M,N,K) 网格上拟合，却被用来外推更大的数据规模与更强的规划器；一旦真实曲线偏离幂律（拐点、逆向段或 sim→real 漂移），水位填充会把预算系统性地错配到“看起来边际收益最高”的维度，而 DFL 策略会主动利用代理增益的误差——外推守卫、bootstrap CI 与逐级回退能限制损失，但无法从原理上消除分布外推风险。

## 0. 核心判断（先直觉后定义）

- **数据规模**：风险对 (M, N, K) 近似“幂律 + 不可约项”，且存在 **context dilution 逆向段**；真正可优化的是有效样本 N_eff=ρN 与“下一单位预算花在哪一维”。经验标度律只能插值，不能无守卫外推。
- **决策规划**：盲区修复是**有限时域 POMDP**；“预测准 ≠ 决策优”，故用决策聚焦学习（DFL）直接优化全局风险的下降；主动选数据本身就是规划动作。
- **合流**：S 阶段（Scale/Allocate）前置，D 阶段（Data diet）嵌入校准，得到 **7C**：S→H→C→E→C(D)→V→U。

## 3. 形式化定义（要点）

**定义 432（η 标度律）** R(M,N,K)=R∞+aM^{−α}+b(ρN)^{−β}+cK^{−γ}+eM^{−α}(ρN)^{−β}；log 域加权拟合，bootstrap CI；定义域外推禁用。
**定义 433（水位填充）** 活跃维度满足 g_M=g_N=g_K=μ；离散整数分配按边际收益贪心 + 边界交换，间隙界见引理 52。
**定义 434（修复规划 POMDP）** 状态含跨盲区信念、剩余预算、已修复集合；动作含“选盲区 / 选程序 / STOP”；回报 = 全局风险下降 − 成本 − 风险惩罚。
**定义 435（DFL 与后悔）** L_DF=E[−V(φ(Ĝ))]，用 SPO+ 可微代理；PTO 为对照。
**定义 436（数据食量）** 选 𝒮 最大化子模 F，k≤k*，ρ=info(𝒮)/info(ℛ)。
**定义 437（充分性证书）** N*(ε)=max{解析下界, 标度反解}；Cert 含 CI；不满足则禁止热替换。
**定义 438（7C）** 在 6C 前置 S、在校准中插入 D；V 阶段增加 Cert 检查。
**定义 439（外推守卫）** 出支撑且距界 > δ_extrap，或 P-Quarantine 触发 ⇒ 保守包络或均匀分配 + 告警。
**定义 440（严格退化）** 逐级回退到 ToolGauge / LeanGauge / MODGAUGE，风险不劣化。
**定义 441（预算转移单调性）** 在 (η) 的凸域内，把预算从边际收益低的维度转移到高的维度，R 不增；这为 WF-Alloc 的“可解释分配”提供依据。
**定义 442（批量机会成本）** 同一工具调用可服务多个盲区时，定义共享代价 c_shared；规划目标改为集合函数，贪心近似比 (1−1/e)（引理 57）。
**定义 443（证书与交叉验证的独立性）** Cert 只用样本量与标度外推；交叉验证只用独立回执。二者输入不重叠时条件独立，联合失败界可加。
**定义 444（DFL 契约回归）** DFL 策略上线前，在预注册的契约测试集上检查：未涉及子图逐指令 diff=0、风险门违规率=0、预算超支=0；任一不满足即回退。
**定义 445（逐级退化条件）** 明确定义每级回退的触发谓词（CI 宽度、外推距离、ρ 阈值、回归失败），并记录回退事件供审计。
**定义 446（k* 在线估计）** 以滑动窗口拟合 F(k) 的边际曲线，取 ∂F/∂k<ε_dilute 的首个 k；窗口内变异系数 > 0.2 时回到保守 k=8。
**定义 447（报告规范）** 所有标度指数必须附带 CI 与外推标记（in-support / extrapolated）；禁止只报点估计。

## 4. 关键算法骨架

```python
# IP-321 η-Fit：标度律拟合 + 守卫
class EtaFit:
    def fit(self, hist, boots=200):
        # hist: [(M, N, K, rho, R)]
        self.R_inf = grid_search_irreducible(hist)         # 联合搜索 R∞
        X, y = log_features(hist, self.R_inf)
        self.w = irls(X, y, self.R_inf)                    # 加权最小二乘
        self.ci = bootstrap(hist, boots)                   # 指数 CI
        self.support = convex_hull(X)
        return self
    def predict(self, M, N, K, pquar):
        x = log_features([(M, N, K)])
        if in_hull(x, self.support):
            return self._risk(M, N, K), "in-support"
        if pquar.triggered() or hull_dist(x, self.support) > DELTA_EXTRAP:
            return conservative_envelope(self, x), "guarded"
        return self._risk(M, N, K) + Z95 * self.sigma_R, "extrapolated"

# IP-322 WF-Alloc：KKT 等边际 + 整数回退
class WFAlloc:
    def allocate(self, law, budgets):
        mu = bisect(lambda m: sum(demand(law, d, m) for d in DIMS) - total(budgets),
                    lo=0.0, hi=1e12)
        cont = {d: demand(law, d, mu) for d in DIMS}
        return self._integer_round(cont, budgets)

# IP-323 DFP-Box：滚动规划 + DFL 训练
class DFPBox:
    def plan(self, state, H=3):
        out = []
        for _ in range(H):
            Ghat = self.gain_net(state)                    # 代理增益（含不确定性）
            action = self.solver.solve(Ghat, state)        # 扰动 top-k，可微
            out.append(action)
            state = self.transition.expect(state, action)
            if state.stop_reason(): break
        return out
    def train_step(self, batch):
        Ghat = self.gain_net(batch.state)
        plans = self.solver.solve(Ghat, batch.state)
        loss = -self.value(batch.state, plans) + self.spo_plus(batch, Ghat)
        self.opt.zero_grad(); loss.backward(); self.opt.step()

# IP-324 DDiet：子模贪心 + 稀释拐点
class DDiet:
    def select(self, receipts, k_max):
        S, pq = set(), LazyHeap(receipts, marginal_info)
        while len(S) < k_max:
            r, g = pq.popmax()
            if g < self.eps_dilute:
                break
            S.add(r); pq.refresh(r)
        rho = info(S) / max(info(receipts), EPS)
        return S, rho

# IP-325 S-Cert：数据充分性
class SCert:
    def certify(self, s, budgets, target_eps):
        n_lb = self.analytic_lower_bound(s, target_eps)   # 定义 426
        n_scaling = self.eta_fit.inverse_N(target_eps, budgets)
        N_star = max(n_lb, n_scaling)
        est, flag = self.eta_fit.predict(budgets.M, budgets.N, budgets.K, self.pquar)
        ci = self.eta_fit.ci_width(budgets)
        ok = (flag == "in-support") and (budgets.N >= N_star) and (est + ci <= target_eps)
        return Cert(ok=ok, N_star=N_star, est=est, ci=ci, flag=flag)

# IP-326 ScaleGauge-7C
def scalegauge_7c(M, s):
    law = M.eta_fit.law
    alloc = M.wf_alloc.allocate(law, M.budgets)
    H = M.lbox.hypothesize(s, M.dbox.R[s])
    prog = M.tbox.select(H, M.tools, M.tcv, alloc.N)
    receipts = M.tcv.execute(prog, M.env)
    receipts, rho = M.ddiet.select(receipts, M.k_star(s))
    if rho < RHO_MIN: return stub_and_red(s, "diet_starved")
    mu, Sig = M.apcal.calibrate(receipts, H, s)
    if not M.apcal.cross_validate(mu, Sig, M.cross_receipt(s)):
        return stub_and_red(s, "cross_failed")
    cert = M.scert.certify(s, M.budgets, M.eps)
    if not cert.ok:
        return stub_and_red(s, "insufficient_data")        # 禁止热替换
    new_ec = M.apcal.update_contract(M.dpe, mu, Sig, s)
    if not contract_regression(new_ec): return stub_and_red(s, "regression")
    M.mreg.hot_replace(M.dpe, new_ec)
    bind_claims(new_ec, H, prog, receipts)
    M.eta_fit.observe(alloc, receipts, s)
    M.pquar.record(M.apcal.last_gain, realized_gain(receipts))
    return True
```

## 5. 推导

**引理 51（标度指数可辨识性）** 在 (η) 下，log 域回归的指数标准误 SE(α̂) ≈ σ_R / (sd(log M)·√n)。要把 α 辨识到 ±0.1，M 至少需约 3 个倍增（8×）跨度、n≥6；否则 CI 过宽，外推必须被禁止。（证明：标准 OLS 斜率方差公式，代入 d log R / d log M = −α 的局部线性化。）

**引理 52（水位填充最优性与整数间隙）** R 关于 (M,N,K) 凸、边际收益递减时，KKT 等边际解全局最优。整数化时允许一个分数松弛项，贪心的风险满足
R_int ≤ R_cont + max_i g_i·Δ_i，
其中 Δ_i 为最小预算块；Δ_i→0 时间隙线性消失。（证明：凸可分优化的标准舍入论证。）

**引理 53（DFL vs PTO 的后悔界）** 设 |Ĝ−G|_∞ ≤ ε_Ĝ，V 对增益 L-Lipschitz，规划器近似间隙 δ_φ，则
Reg(π_DF) ≤ 2L·ε_Ĝ + δ_φ。
PTO 的后悔额外包含“在错误增益下选到次优计划”的优化间隙；当最优/次优值接近时可放大为 𝒪(L·ε_Ĝ·√N)。（证明：三角不等式 + SPO+ 的 regret 分解；PTO 放大项来自 argmax 的不连续性与并列计划数。）

**引理 54（数据食量的子模性与拐点）** Gaussian 后验下，信息增益 I(𝒮)=½[log det Σ_pre − log det Σ_post] 关于 𝒮 单调子模 ⇒ 贪心 (1−1/e)。方差收缩存在饱和 k*；k>k* 后冗余回执主导，F 的边际低于 ε_dilute，故盲目增大 N 会进入 context dilution 逆向段。

**引理 55（证书-热替换安全性）** 若 Cert 以 1−δ 覆盖真实 N*(ε)，则“仅当 Cert.ok 才热替换”使错误先验升级概率 ≤ δ。与交叉验证（错误率 δ_cross）在输入不重叠时条件独立，联合失败 ≤ δ+δ_cross。

**引理 56（严格退化单调性）** 任一 ScaleGauge 模块失效按定义 440/445 回退 ToolGauge，其风险不超过 ToolGauge 基准；启用全部守卫的 ScaleGauge 是 ToolGauge 的 risk-non-increasing 扩展。

**引理 57（共享工具成本的批量规划）** 若一次工具调用可服务盲区集合 𝒞 且代价为 c_shared(𝒞) 的次模函数，则“按边际风险下降/边际成本”贪心的批量规划达到 (1−1/e) 近似；这给出跨盲区机会成本的可证收益。

## 9. 本轮最大风险

**一句话**：ScaleGauge 把“数据越多越好”替换成“标度律 + 水位填充”，但标度律只是有限网格上的经验插值——一旦部署分布使幂律失效（拐点、逆向段或 sim→real 漂移），优化器会把预算精确地投到错误的维度，DFL 又会利用代理模型的误差放大这一错配；外推守卫、CI 门槛、S-Cert 与逐级回退只能保证“不静默失败”，不能保证“外推正确”，因此任何标度结论都必须附带 in-support / extrapolated 标记与真机复核。
