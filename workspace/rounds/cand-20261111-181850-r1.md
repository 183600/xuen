# 第 55 轮（承接第 54 轮 v16+++ GroundEdge-GenSim+++；灵感循环新一轮第 1 轮；本轮灵感：「演示方案」×「双臂协作」）

> 第 54 轮把技能建模为动作空间剖面 `α_S`，并在云边协同下做可判定组合。但该体系隐含一个强假设：动作空间可因子化为 `A = A_c × A_e`，组合在乘积空间上成立。双臂协作直接打破该假设：左右臂通过被抓取物体、共享工作空间与力闭合互相耦合，合法动作不是乘积空间，而是其子流形 `M_Φ`。核心矛盾：**H22**：单臂剖面在乘积空间上“各自可行”并不蕴含双臂“协同可行”，独立组合会产生**协同封闭违背**（内力爆增、滑移、碰撞）；**H23**：演示是协同流形先验最廉价的来源，但原始演示过拟合演示者本体、并系统性欠采样非对称/富接触阶段，直接把演示当证书会把“演示里的协调”误当作“可迁移的协调”。

## 0. 直觉与动机

**灵感 1（演示方案 → 演示即证书，而非一段轨迹）**
直觉：一次双臂演示的价值不在轨迹本身，而在它同时给出三样东西：(i) 协同流形上的采样点 `M_demo`；(ii) 该阶段动作剖面的经验下界 `α_demo`；(iii) 鲁棒性谱先验 `ρ_demo`，外加“谁主谁从”的角色标签。把这些蒸馏成 **演示证书 `D_cert`**，并显式记录演示者本体标签与充分性评分，演示才能被组合规划器当作可信输入。演示因此从“模仿学习的原料”升级为“可审计的一等公民”。

**灵感 2（双臂协作 → 从乘积空间到协同封闭流形）**
直觉：双臂合法动作集合不是 `A_L × A_R`，而是满足封闭约束 `Φ(a_L,a_R)=0` 的子流形 `M_Φ`（刚体闭合、无碰撞、力闭合、关节极限）。两臂各自的 `α` 都很高，整体仍可能落在流形之外——这正是“乘积空间幻觉”。因此组合的第一性约束应从 `compat(S_i,S_j)` 改为**在 `M_Φ` 上度量的协同兼容性**，并引入封闭残差 `d_Φ` 与内力/滑移裕度 `f_margin`。

**灵感 3（演示 × 协作 → 分阶段角色课程）**
直觉：真实双臂任务在对称阶段（双手同步搬运）与非对称阶段（一手固定、一手操作）之间切换，协调约束与角色分配随之改变。用**演示课程**按阶段组织演示：每阶段标注角色 `σ∈{leader,follower}`，并主动挑选能覆盖非对称、富接触阶段的演示。课程的目标不是“演示越多越好”，而是把 `M_Φ` 的覆盖半径压到 `δ*` 以下，同时压低保真度 gap。

**灵感 4（云边协同 × 双臂 → 云端给流形先验，边端守封闭约束）**
直觉：流形学习与演示蒸馏是重计算、可离线，放在云端；封闭约束 `Φ` 的实时残差监控与内力限幅必须在边端高频回路。云端输出协同计划 `P_c` 与 `M_Φ` 先验，边端以 `f_c` 频率校验 `d_Φ` 与 `f_margin`，越界即回传 `Explain` 并触发守卫动作（松开/退让/力限幅）。这复用第 54 轮 CEC，但把“动作对齐误差 `δ_a`”升级为“封闭残差 `δ_Φ`”。

**灵感 5（金字塔扩展 → 协同演示层 `𝔻`）**
直觉：在动作-鲁棒性双证书上再叠加**协同演示层** `𝔻`：`𝔻_0` 物理封闭约束，`𝔻_1` 演示采样流形，`𝔻_2` 角色化协同策略，`𝔻_3` 任务阶段课程。跨层证书须同时携带 `ρ, α_B, M_Φ, D_cert, σ, f_margin`，形成“可解释的协同-演示联合证书”。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（协同封闭约束与可行流形）**
双臂动作 `a=(a_L,a_R)∈A_L×A_R`。封闭约束 `Φ: A_L×A_R→ℝ^k`，可行流形
`M_Φ = { a | Φ(a)=0, σ_min(∇Φ) ≥ ε_Φ }`，封闭残差 `d_Φ(a)=‖Φ(a)‖_{Σ_Φ^{-1}}`。
`M_Φ` 编码刚体闭合、无碰撞、力闭合与关节极限。注意 `M_Φ` 一般不可因子化。

**定义 122（双臂协同动作剖面）**
`α_B: M_Φ→[0,1]`，`α_B(a)` 为在该协同动作上成功概率的置信下界。协同覆盖
`cover_B(B,A_T)=1 ⇔ ∀a∈A_T∩M_Φ, α_B(a) ≥ θ_cov`。
关键：**只对 `a∈M_Φ` 有定义**，乘积空间上的 `α_L·α_R` 不作为替代。

**定义 123（演示证书）**
演示证书 `D_cert=(M_demo, α_demo, ρ_demo, σ_demo, E_d, suff, prov)`：
- `M_demo`：演示在 `M_Φ` 上的对齐采样；
- `α_demo / ρ_demo`：经验剖面与鲁棒性先验；
- `σ_demo`：阶段角色标签（leader/follower）；
- `E_d`：演示者本体标签；
- `suff`：充分性评分（定义 124）；
- `prov`：采集/清洗/对齐的可追溯记录。

**定义 124（演示充分性）**
`sufficient(D,M_Φ) = [covering_radius(D) ≤ δ*] ∧ [embodiment_gap(E_d,E_tgt) ≤ Ε] ∧ [role_coverage(D) ≥ κ_role]`，
其中 `covering_radius(D)=sup_{m∈M_Φ} min_{d∈D} d_Φ(m,d)`，`role_coverage` 度量非对称/主从阶段是否被覆盖。任一不满足即“演示不足”，只能给出保守或弃权证书。

**定义 125（协同兼容性与角色化转换成本）**
`compat_B(B_i,B_j)=|M_i∩M_j|/|M_i∪M_j|`（在 `M_Φ` 上度量）。
`c_trans^B = w_Φ·d_Φ^trans + w_σ·swap(σ_i,σ_j) + w_f·|Δf_margin|`。
组合可判定条件：
```
compat_B(B_i,B_j) ≥ θ_b ∧ c_trans^B ≤ τ_e ∧ d_Φ^plan ≤ δ_Φ
```

**定义 126（双臂-演示联合证书）**
`J_B=(ρ, α_B, M_Φ, D_cert, σ, δ_Φ, f_margin, evidence)`。
部署条件：`cover_B ∧ sufficient(D,M_Φ) ∧ P95(d_Φ) ≤ δ_Φ ∧ f_margin ≥ φ_min ∧ ρ ≥ ρ_min`。任一缺失则 `dom=out`，禁止自主部署。

## 2. 关键算法 伪代码

### IP-121 DDA（Demo Distillation & Attestation）

```python
def distill_demo(raw, embodiment_target):
    traj = align_to_manifold_features(raw)          # 左右臂配对 + 时间对齐
    M_demo = validate_closure(traj.P_L, traj.P_R)   # 仅保留 d_Phi 小样本
    alpha = empirical_profile(M_demo, traj.outcomes)
    rho = robustness_prior(traj.perturbations)
    suff = (coverage_radius(M_demo) <= delta_star
            and embodiment_gap(raw.emb, embodiment_target) <= E
            and role_coverage(traj.roles) >= kappa)
    return DemoCert(M_demo, alpha, rho, traj.roles,
                    raw.emb, suff, traj.provenance)
```

### IP-122 CLM（Coordination Manifold Learning）

```python
def learn_manifold(demo_certs, physics_prior, delta_Phi_budget):
    M = fit_constraint(demo_certs, prior=physics_prior)   # 拟合 Phi_hat
    cal = conformal_residual(M, demo_certs)               # 保形残差上界
    if cal.q95 > delta_Phi_budget or not check_rank(M):
        return ('reject', 'manifold_unsound', cal.q95)
    return ('ok', ManifoldModel(Phi_hat=M, residual=cal, regular=True))
```

### IP-123 BSCG（Bimanual Skill Composition Graph）

```python
def build_bimanual_graph(skills, M, theta_b, tau_e):
    G = nx.DiGraph()
    for i, s1 in enumerate(skills):
        for j, s2 in enumerate(skills):
            if i == j: continue
            compat = jaccard_on_manifold(s1.alpha, s2.alpha, M)
            c = closure_transition(s1, s2, M) + role_swap_cost(s1, s2)
            if compat >= theta_b and c <= tau_e:
                G.add_edge(i, j, compat=compat, cost=c,
                           role=select_role(s1, s2),
                           rho=compose_robustness(s1.rho, s2.rho, K))
    return G
```

### IP-124 DCC（Demo Curriculum Constructor）

```python
def build_curriculum(M, demo_pool, budget, delta_star):
    selected = []
    while covering_radius(selected, M) > delta_star and len(selected) < budget:
        d = argmax_{d in demo_pool} (
            covering_gain(d, selected, M) + lambda_r * asymmetry_gain(d))
        selected.append(d); demo_pool.remove(d)
    return selected, coverage_report(selected, M)
```

### IP-125 CEC-B（Cloud-Edge Bimanual Coordination）

```python
def cloud_bimanual_plan(task, G, M, demo_certs):
    path, cost = a_star(G, start='root', goal=task,
                        heuristic=cost_align_manifold)
    P_c = [(sid, coarse_action(sid), role(sid)) for sid in path]
    return P_c, cost, M

def edge_enforce(P_c, M, sim, f_c, delta_Phi, phi_min):
    for sid, a_c, role in P_c:
        a = map_to_fine(a_c, role)                    # 复用 gamma_ce
        for _ in range(int(horizon * f_c)):           # 高频封闭校验
            r = closure_residual(M, a)
            m = force_margin(sim, a)
            if r > delta_Phi or m < phi_min:
                exp = explain_violation(sim, a, r, m)
                return ('guard', exp, guard(sid, a, exp))  # 松/退/限力
    return ('ok', P_c)
```

### IP-126 BJC（Bimanual Joint Certificate）

```python
def bimanual_certificate(seq, M, demo_certs, rho_min, phi_min, delta_Phi):
    for s in seq:
        if not cover_on_manifold(s.alpha, task_actions(s), M):
            return ('reject', 'coverage_fail', s.id)
    if not all(d.suff for d in supporting_demos(seq, demo_certs)):
        return ('reject', 'demo_insufficient')
    if p95([closure_residual(M, s) for s in seq]) > delta_Phi:
        return ('reject', 'closure_budget')
    rho = compose_robustness_chain([s.rho for s in seq], K)
    if min(rho.values()) < rho_min or min(force_margin_seq(seq)) < phi_min:
        return ('reject', 'robustness_or_force')
    return ('ok', JointCertB(rho, seq.alpha, M, demo_certs, seq.roles,
                             delta_Phi, min(force_margin_seq(seq))))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| DDA | O(\|D\|·T·\|A\|) | O(\|D\|·T) | 对齐单调、封闭过滤 sound |
| CLM | O(\|D\|·T·k) | O(k²) | 残差保形上界、∇Φ 非退化 |
| BSCG | O(\|B\|²·\|M_Φ\|) | O(\|B\|²) | 流形上 compat、角色成本单调 |
| DCC | O(budget·\|D\|·\|M_Φ\|) | O(budget·\|M_Φ\|) | 覆盖半径单调下降 |
| CEC-B | O(\|V\|log\|V\|+\|E\|+\|P\|·f_c) | O(\|V\|+\|E\|) | 高频守卫、Explain 有界延迟 |
| BJC | O(\|seq\|·\|A\|+k) | O(\|A\|+k) | 联合证书 sound、弃权保守 |

**正确性定理（Bimanual Demonstration-Grounded Composition Soundness）**
假设第 54 轮 (A22)–(A28) 成立；新增
**(A29)** `Φ̂` 在 `M_Φ` 上保形残差 `q95 ≤ δ_Φ` 且 `σ_min(∇Φ̂) ≥ ε_Φ`（流形正则）；
**(A30)** 支撑演示满足 `sufficient(·)`，即覆盖半径 `≤δ*`、本体 gap `≤Ε`、角色覆盖 `≥κ_role`；
**(A31)** 边端封闭校验频率 `f_c` 与守卫延迟满足 `d_Φ` 漂移上界，且力限幅为硬约束。
则：

```
P(success_B ∧ safe | deploy)
≥ 1 - Σ_d(1-ρ_min(d)) - P(d_Φ>δ_Φ) - P(f_margin<φ_min) - β_D - β_E
```

其中 `β_D` 为演示分布偏移（本体 + 非对称覆盖）残余，`β_E` 为边端时序/守卫残余。关键：**演示不足时不等式右端不成立，必须弃权**。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 演示欠采样非对称/富接触阶段 | 高 | 主动演示课程 + `role_coverage` 门槛 + 不足即弃权 |
| `Φ̂` 分布外非正则/外推失真 | 高 | 保形残差上界 + 流形正则 + OOD 绊线 |
| 演示者本体差异导致迁移偏差 | 高 | 本体标签 + 特征对齐 + 负迁移绊线 |
| 边端守卫延迟导致内力冲击 | 中 | `f_c≥1kHz` 力限幅硬回路 + 预测性退让 |
| 角色切换瞬态失稳 | 中 | hysteresis + 切换缓冲阶段 + 力闭环 |
| 组合图在流形上规模爆炸 | 中 | manifold-aware 哈希 + 阶段剪枝 |

## 6. 本轮最大风险

**一句话**：演示驱动双臂协同的最大风险，是把**演示覆盖的对称、低接触阶段**误当作整个协同流形已被证据支撑；一旦非对称、富接触、分布外构型出现，`Φ̂` 只是“协调幻觉”，两臂会各自满足剖面却整体漂离 `M_Φ`，导致内力爆增、滑移甚至损坏物体——因此必须以**角色覆盖门槛的主动演示课程 + 保形封闭残差监控 + 力裕度硬限幅**三重护栏，演示不充分时宁可弃权，绝不把“演示里成立”当作“部署时成立”。

def build_bimanual_graph(skills, M, theta_b, tau_e, K):

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| DDA | O(\|D\|·T·\|A\|) | O(\|D\|·T) | 对齐单调、封闭过滤 sound、来源可追溯 |
| CLM | O(\|D\|·T·k) | O(k²) | 保形残差上界 `q95≤δ_Φ`、`σ_min(∇Φ̂)≥ε_Φ` |
| BSCG | O(\|B\|²·\|M_Φ\|) | O(\|B\|²+\|E\|) | 流形上 `compat_B` sound、路径最优 |
| DCC | O(budget·\|D\|·\|M_Φ\|) | O(budget·\|M_Φ\|) | 覆盖半径单调下降、角色覆盖不降 |
| CEC-B | O(\|V\|log\|V\|+\|E\|+\|P\|·f_c) | O(\|V\|+\|E\|) | 高频守卫、Explain 有界延迟、力限幅硬约束 |
| BJC | O(\|seq\|·\|A\|+k) | O(\|A\|+k) | 联合证书 sound、演示不足即弃权 |

**正确性定理（Bimanual Demonstration-Grounded Composition Soundness）**
假设第 54 轮 (A22)–(A28) 成立；新增
**(A29)** `Φ̂` 在 `M_Φ` 上保形残差 `q95 ≤ δ_Φ` 且 `σ_min(∇Φ̂) ≥ ε_Φ`；
**(A30)** 支撑演示满足 `sufficient(·)`：覆盖半径 `≤δ*`、本体 gap `≤Ε`、角色覆盖 `≥κ_role`；
**(A31)** 边端封闭校验频率 `f_c` 与守卫延迟满足 `d_Φ` 漂移上界，力限幅为硬约束。
则部署成功且安全概率：

```
P(success_B ∧ safe | deploy)
≥ 1 - Σ_d(1-ρ_min(d)) - P(d_Φ>δ_Φ) - P(f_margin<φ_min) - β_D - β_E
```

其中 `β_D` 为演示分布偏移（本体 + 非对称覆盖）残余，`β_E` 为边端时序/守卫残余。关键：**证明只在 `sufficient` 成立时有效；演示不足则必须以弃权替代部署**。

## 5. 本轮最大风险

**一句话**：演示驱动双臂协同的最大风险，是把**演示覆盖的对称、低接触阶段**误当作整个协同流形已被证据支撑；一旦非对称、富接触、分布外构型出现，`Φ̂` 只是“协调幻觉”，两臂会各自满足剖面却整体漂离 `M_Φ`，导致内力爆增、滑移甚至损坏物体——因此必须以**角色覆盖门槛的主动演示课程 + 保形封闭残差监控 + 力裕度硬限幅**三重护栏，演示不充分时宁可弃权，绝不把“演示里成立”当作“部署时成立”。
