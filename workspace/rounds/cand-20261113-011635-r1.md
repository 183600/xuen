# 第 64 轮（承接第 63 轮「LIRO 几何-技能-干扰联合闭环」IP-193~203；灵感循环 III 第 1 轮；本轮灵感：「可用性评估」×「人机交互」）

> 第 63 轮 LIRO 把「几何-技能-干扰」三层物理安全做到了可认证，但它把「人」压缩成了两样东西：DMS 输入的一段语言 `L`，以及 Shield-Skill 越界时的一次 `ask_clarify`。`J_liro` 是给机器看的证书，不是给人的承诺。三个盲区随之暴露：
> 1. **可用性无测量**：系统只优化成功率/时延/鲁棒裕度，回答不了 ISO 9241-11 的有效性、效率、满意度，更回答不了信任校准、心智负荷、情境意识、可学习性——「可用性评估」在 HRI 中通常是事后问卷，而不是闭环信号。
> 2. **交互无模型**：人不是一次性指令源，而是带目标、信念、信任、负荷、情境意识的状态机；机器人也没有「询问/解释/演示/警告/让行/交接」这些与物理技能同级的动作。
> 3. **解释无忠实性**：`ρ_rob`、`ρ_dir`、技能序列这些证书无法直接给人看；若用 LLM 事后编解释，很容易生成「高说服力、低忠实度」的合理化叙事，反而制造过度信任。
>
> 本轮的核心主张：**把可用性变成可估计、可认证、可优化的控制信号；把交互变成带信息增益与打断代价的一等动作；把信任从「越高越好」纠正为「与真实可靠性对齐」。**

## 0. 直觉与动机

### 直觉 0（两个灵感词是同一个闭环的两端）

「可用性评估」问：人能不能有效、高效、满意地用起来？「人机交互」问：人和机器人如何双向理解、分工、纠错、建立恰当信任？两者在 LIRO 的「语义流」上相遇：**可用性不是交互设计做完之后的打分，而是交互策略每一步都在改变的状态；交互也不是物理技能外面的一层壳，而是与抓取/插入同级、要花预算、会带来风险的动作。** 于是本轮不把 HRI 当成「加一个聊天框」，也不把可用性当成「最后发问卷」，而是把二者合成一个**人在环中的约束 POMDP + 可审计证书**问题。

### 灵感 1（可用性评估 → HUE + U-Cert：从问卷到带覆盖保证的在线证书）

直觉：可用性是潜变量，不能只看任务成功率。一个人可能任务完成了但心惊胆战（低感知安全），也可能很满意却一直在接管（低信任校准）。真正可用的系统，应该能在线估计这些维度，并且诚实地给出「我现在有多确定」。

严谨：定义可用性向量 `u = (u_eff, u_effic, u_sat, u_learn, u_trust, u_work, u_sa, u_safe, u_expl, u_accept)`，由客观/行为/生理/主观四类信号经多水平潜变量模型估计；再用**分组保形预测（Mondrian conformal）**给出每个用户簇的有限样本覆盖区间 `C_δ(u)`。`U_cert` 不是点估计，而是「关键构念的置信下界均过阈值」的证书：`LCB(u_eff), LCB(u_safe), LCB(u_trust) ≥ 阈值`。这样可用性评估与 `J_liro` 一样，有明确的失效条件与审计链，而不是一张事后问卷。

### 灵感 2（人机交互 → HIM + HA-CSP：把交互建成受约束的 POMDP）

直觉：人心里有一个「目标—信念—信任—负荷—情境意识」的状态；机器人不该假设自己知道它，而应维护后验，并主动选择「问一句 / 解释一下 / 先做给他看 / 让他接管」来降低不确定性。

严谨：`h_t = (g_t, b_t, τ_t, w_t, s_t, p_t)` 为人类潜状态；机器人维护信念 `β_t(h)`。动作空间扩为 `A = A_phys ∪ A_int`，`A_int = {ask, explain, demo, warn, confirm, yield, handover, wait, show_intent}`；每个交互动作有打断代价 `c_int` 与信息增益 `IG(a) = H(β_t) − E[H(β_{t+1})]`。HA-CSP 在 USL 上联合规划物理技能与交互动作，目标含任务进度、可用性、可读性（legibility）、信息增益，约束含安全证书、社交/工作空间约束、交互预算 `B_int`。

### 灵感 3（解释 → IAX：把机器证书翻译成因果忠实的解释）

直觉：人不是要听「ρ_rob=0.12」，而是想知道「为什么它现在慢下来」「为什么它不抓那个杯子」「如果我把它转 30° 会怎样」。解释必须从同一套证书与反事实模型里长出来，而不是事后由语言模型合理化。

严谨：`C2X: (J_liro, 反事实集, β_t) → e`，解释类型 `{why, why-not, what-if, how, uncertainty}`。忠实性用结构因果模型的实际原因/反事实定义：解释引用的因素集 `F(e)` 与最小充分原因集 `C(x)` 的对称差 ≤ `ε_faith`，且用户信念更新与真实因果效应之差 ≤ `ε_cal`。IAX 选解释的目标是**期望信任校准增益 + 情境意识增益 − 打断代价**，而不是「让用户更信」。

### 灵感 4（信任 → TCA：信任不是越高越好，而是要与可靠性对齐）

直觉：过度信任会把「它应该能行」变成「我不必看」；信任不足则导致频繁接管、弃用。两者都降低可用性，前者还制造安全风险。

严谨：令 `R_t` 为 `J_liro` 给出的可靠度下界，信任误差 `e_trust = |τ_t − R_t|`；区分过信任 `τ > R + δ` 与欠信任 `τ < R − δ`。信任动力学 `τ_{t+1} = clip(τ_t + α_o(o_t − τ_t) + α_e ψ(e_t) − α_v v_t)`。关键推论：若解释系统性抬高信任 `E[ψ] > 0`，稳态偏差为 `α_e E[ψ]/α_o`——**解释可以「制造」过度信任**。因此 IAX 必须满足校准保持约束 `E[ψ(e)] = 0`，TCA 则按风险分配权限：过信任 + 高风险 → 降自主、显式披露不确定性；欠信任 → 用可验证的演示重建能力信念。硬约束：人类接管权永远可用。

### 灵感 5（合流 → HURI：人-可用性-鲁棒交互闭环）

HURI 把 LIRO 的「物理安全」与新增的「交互可用性」串成三级闭环：
- **物理层（LIRO）**：几何 → 技能 → 干扰认证，保证「做得安全」；
- **交互层（HIM/HA-CSP/IAX/TCA/HIB）**：意图 → 可读技能 + 交互动作 → 解释 → 权限，保证「人用得明白、信得恰当」；
- **评估层（HUE/U-Cert/HSB）**：客观+行为+生理+主观 → 可用性证书 → 场景银行，保证「效果可测量、可复现、可审计」。

闭环：可用性↑ ⇒ 人更少接管/更准纠错 ⇒ 执行数据质量↑ ⇒ φ̂ 与技能库更准 ⇒ 安全裕度↑ ⇒ 可用性↑；同时 `J_huri` 把物理证书、可用性证书、信任证书、解释忠实性、人类接管权绑成一条链。

### 灵感 6（LIRO 组件原位升级）

- **USL → USL-H**：新增交互技能 `σ_ask, σ_explain, σ_demo, σ_warn, σ_yield, σ_handover, σ_wait`，每个都有 `pre/eff` 与打断代价；物理技能增加 `legibility` 标签。
- **CSP → HA-CSP**：代价加入可读性、社交距离、人类偏好、交互信息增益；规划对象从「技能序列」扩为「物理-交互联合序列」。
- **AIC → AIC-H**：干扰集从四类扩为五类，新增 `ℰ_human`（指令歧义、响应延迟、意外接管、人体遮挡、非专家误用）；`ρ_hri` 与 `ρ_dir` 取交。
- **SSB → HSB**：场景签名增入用户簇、交互轨迹、可用性向量、信任轨迹、解释接受记录；变异算子增加「人格/负荷/模态/歧义」维度；隐私用设备端匿名嵌入 + 差分隐私。
- **OCB-Skill → OCB-H**：臂空间增入交互模式（主动/被动/静默）与解释粒度（无/简短/详细/反事实），奖励含可用性增量与打断惩罚。
- **J_liro → J_huri**：证书链加入 `U_cert, T_cert, E_cert, authority_log, override`。
- **WCV-Geo → WCV-H**：安全球增加人体接近/运动不确定项，物理裕度与人类安全距离联合约束（但不改实时路径复杂度）。

## 1. 形式化定义（增量：定义 201–216）

- **定义 201（HURI 闭环）**：HURI = (LIRO, HIM, HUE, U-Cert, HA-CSP, IAX, TCA, HIB, DIR-H, HSB, OCB-H, J_huri)。定位：LIRO 的「人在环中的可用性 × 交互」升级，全部新增组件挂载在第 63 轮骨架上，不推翻任何物理安全接口。不变式：所有人类状态估计、可用性评估、交互规划、解释生成、权限分配只发生在语义流/低频线程；实时路径只保留物理安全编译与一次信念读取。
- **定义 202（HIM 人类意图-心智模型）**：人类潜状态 `h_t = (g_t, b_t, τ_t, w_t, s_t, p_t)`，其中 `g_t` 为目标后验，`b_t` 为对机器人能力/可靠性的信念，`τ_t ∈ [0,1]` 为信任，`w_t ∈ [0,1]` 为心智负荷，`s_t ∈ [0,1]` 为情境意识，`p_t` 为偏好（速度/安全、解释粒度、交互模态）。机器人维护信念 `β_t(h)`，观测 `o_H^t = (utterance, gesture, gaze, response_latency, correction, takeover, physiology)`，滤波更新 `β_t(h) ∝ P(o_H^t | h) Σ_{h'} P(h | h', a_{t-1}) β_{t-1}(h')`。
- **定义 203（混合主动动作空间）**：`A = A_phys ∪ A_int`；`A_int = {ask(q), explain(e), demo(d), warn(r), confirm, yield, handover, wait, show_intent}`。每个 `a ∈ A_int` 带打断代价 `c_int(a)`（时间+认知负荷）与信息增益 `IG(a) = H(β_t) − E_{o'}[H(β_{t+1})]`；`warn/confirm/yield/handover` 为安全关键动作，可绕过交互预算但不能绕过安全证书。
- **定义 204（HA-CSP 人类感知技能规划）**：给定目标 `G`，联合搜索 `(τ, a_int, θ_bind)`：
  `max E[Σ task_progress] + λ_u·Û(τ, a_int) + λ_l·Leg(τ) + λ_i·Σ IG(a_i) − λ_c·Cost(τ, θ) − λ_b·Σ c_int(a_i)`
  s.t. `pre/eff` 谓词链成立、`∀i π_σi ∈ 𝒫_feas(φ̂,r)`、社交/工作空间约束 `𝒮(x')`、人类偏好约束 `𝒫_h`、交互预算 `Σ c_int ≤ B_int`。实时只执行 `τ[0]`；后续在下一语义步按 receding horizon 重规划。
- **定义 205（可读性与可预测性）**：`Leg(τ) = 1 − H(G | τ, x') / log|𝒢|`，其中 `H(G|τ,x')` 由人类目标推断模型 `q_H` 给出；`Pred(τ) = 1 − E_t D_KL(P_H(ξ_t | τ_{<t}) ‖ δ_{ξ_t}) / log|Ξ|`。二者同时进入 HA-CSP 代价，避免「高效但不可读」的诡异轨迹。
- **定义 206（可用性向量）**：`u = (u_eff, u_effic, u_sat, u_learn, u_trust, u_work, u_sa, u_safe, u_expl, u_accept) ∈ [0,1]^10`：
  - `u_eff` 有效性（任务完成率，ISO 9241-11）；
  - `u_effic` 效率（单位任务时间/能耗，ISO 9241-11）；
  - `u_sat` 满意度（SUS / UEQ-S）；
  - `u_learn` 可学习性（重复任务的效率/错误改善斜率）；
  - `u_trust` 信任校准度（`1 − |τ − R| / δ_max`）；
  - `u_work` 心智负荷（`1 − NASA-TLX/100`）；
  - `u_sa` 情境意识（SAGAT 正确率）；
  - `u_safe` 感知安全（Godspeed 负向项 / 自报告）；
  - `u_expl` 可解释性（用户理解度 + 解释忠实性）；
  - `u_accept` 接受度（继续使用意愿 / 推荐意愿）。
- **定义 207（HUE 可用性评估器）**：`u_t = f_UE(φ_UE; o_t^obj, o_t^beh, o_t^phys, y_t^subj)`，其中 `o^obj` 为完成率/时间/错误/接管/澄清轮次，`o^beh` 为响应延迟、注视熵、纠错频率、依赖/遵从，`o^phys` 为 HRV/EDA/瞳孔（可选），`y^subj` 为微问卷/锚点量表。主观项用多水平 IRT：`P(y_ij ≥ k | u_i) = σ(a_j(u_i − b_{jk}))`，用户随机效应 `u_i ~ N(μ_c, Σ_c)`。在线用客观+行为+生理推断，`K` 个 episode 后用主观锚点校准；输出后验均值 `û` 与可信区间。
- **定义 208（U-Cert 可用性证书）**：`U_cert = (û, C_δ(u), n_eff, cluster_id, protocol_hash, scale_versions, drift_flag)`。`C_δ(u)` 由 Mondrian 保形预测给出；`Valid(U_cert) ⇔ ∀k∈K_crit, LCB_k(C_δ(u_k)) ≥ u_k^min ∧ n_eff ≥ n_min ∧ ¬drift_flag`，`K_crit = {eff, safe, trust}`。必须按用户簇分别出证，禁止用总体平均掩盖少数用户不可用。
- **定义 209（信任与校准）**：`R_t` 为 `J_liro` 的可靠度下界；`e_trust(t) = |τ_t − R_t|`；过信任 `τ_t > R_t + δ_trust`，欠信任 `τ_t < R_t − δ_trust`。信任动力学 `τ_{t+1} = clip(τ_t + α_o(o_t − τ_t) + α_e·ψ(e_t) − α_v·v_t, 0, 1)`，`o_t` 为任务结果，`ψ(e_t)` 为解释的信任偏移，`v_t` 为违规/事故惩罚。
- **定义 210（TCA 信任校准与权限分配）**：权限 `α_t ∈ [0,1]`（0=全手动，1=全自主）由 `α_t = clip(g_TCA(R_t − τ_t, risk_t, w_t, s_t), α_min, α_max(risk_t))` 给出；`α_max(risk_t)` 随风险单调下降；过信任且高风险时强制降自主并披露不确定性；欠信任时允许受验证的演示性自主。硬约束：人类接管权 `H_override ≡ 1`；未经确认不得提升自主等级。
- **定义 211（IAX 交互感知解释）**：`C2X: (J_liro, 𝒞_counterfactual, β_t) → e`，`e` 从 `{why, why-not, what-if, how, uncertainty}` 中选。解释的因果忠实性用结构因果模型 `M=(V,U,F)` 的实际原因集 `C(x)` 度量：`Faith(e) = 1 − |F(e) Δ C(x)| / |C(x)|`；校准性 `Cal(e) = 1 − |ψ(e) − ψ_true(e)|`。IAX 选择 `e* = argmax E[Δu_trust + Δu_sa + Δtask] − c_int(e)`，并强制 `Faith(e) ≥ 1−ε_faith`、`E[ψ(e)] = 0`。
- **定义 212（J_huri 人机交互证书）**：`J_huri = (J_liro, U_cert, T_cert, E_cert, authority_log, override_evidence, protocol_hash)`。`Valid(J_huri) ⇔ Valid(J_liro) ∧ Valid(U_cert) ∧ T_cert(|τ−R|≤δ_trust) ∧ E_cert(Faith≥1−ε_faith) ∧ override_evidence ∧ ¬unauthorized_escalation`。审计链：`U_cert` 追溯量表版本与被试簇，`T_cert` 追溯信任轨迹与解释记录，`authority_log` 追溯每次权限变更。
- **定义 213（HIB 交互预算）**：`B_int(t)` 为滑动时间窗内的剩余打断预算，`B_int(t+1) = min(B_max, B_int(t) + ρ_B·Δt − c_int(a_t))`。安全关键动作 `warn/confirm/yield/handover` 走独立安全通道，不消耗普通解释预算；预算耗尽时只能选择静默保守技能或请求接管。
- **定义 214（人类干扰集）**：`ℰ_human = ℰ_amb × ℰ_delay × ℰ_takeover × ℰ_occl × ℰ_misuse`，分别对应指令歧义、响应延迟、意外接管、人体遮挡、非专家误用；半径由 HIM/HUE 历史经验分位数校准。`ρ_hri(τ) = min_{η∈ℰ_phys×ℰ_human} min_t margin(τ, η)`，并入 AIC-H。
- **定义 215（HSB 人类场景银行）**：交互 episode 签名 `ep_sig = (user_cluster, goal, interaction_trace, u_vector, trust_trace, explanation_accept, failure_mode)`。`Mine` 在可用性下降或信任失准时建场景；`Mut` 在「人格/负荷/交互模态/歧义程度/文化语言」维度变异。隐私：只存设备端匿名嵌入，原始语音/生理数据不出端，银行聚合统计加差分隐私噪声。
- **定义 216（可用性驱动共适应）**：在语义流用 HUE + HSB 更新偏好 `p_t`、解释模板、交互技能参数；更新需通过三重门：① 安全证书不回退；② 主观锚点量表不下降；③ 反奖励黑客审计（代理指标与验证量表的相关性不得单独驱动更新）。禁止在线修改 `J_liro` 的物理安全参数。

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 5（可用性证书的有限样本覆盖）**：若校准用户与测试用户在同一用户簇内可交换，Mondrian 保形预测给出 `P(u_true ∈ C_δ(u)) ≥ 1−δ`；按 `K_crit` 与用户簇做 Bonferroni 校正可得族系覆盖。该保证不依赖高斯/线性假设，但依赖可交换性；分布漂移时用 ACI 维持长期覆盖。
- **引理 6（交互预算下的意图熵）**：若每次有效交互至少降低 `δ_I` 的意图熵，则 `m ≤ B_int/c̄` 次交互后 `H(g|β) ≤ max(0, H(g_0) − m·δ_I)`；预算耗尽而熵仍高于 `H_stop` 时，必须降级为保守技能或请求接管。若信息增益次模，贪心交互选择达到 `(1−1/e)` 最优。
- **引理 7（信任校准保持）**：在线性信任动力学下，若结果平稳且 `E[o]=R`，则稳态 `τ_∞ = R + (α_e/α_o)E[ψ]`；因此系统性正解释偏差会制造过度信任。`E[ψ]=0` 是解释不引入额外信任偏差的必要条件；时变 `R_t` 用 CUSUM 漂移检测重置。
- **定理 4（HURI 证书有效性）**：若 `J_liro` 失效概率 ≤ `α_dir+δ_cert`、`U_cert` 覆盖失败 ≤ `δ_ue`、`T_cert` 失败 ≤ `δ_trust`、`E_cert` 失败 ≤ `δ_e`，且接管权始终可用，则 `Valid(J_huri)` 下不安全依赖概率 ≤ `α_dir+δ_cert+δ_ue+δ_trust+δ_e`（联合界，保守）。
- **定理 5（可用性感知规划的遗憾分解）**：`R_T^huri ≤ R_T^skill + λ_u·T·w_δ + λ_i·O(√(KT log K))`，其中 `w_δ` 为 U-Cert 区间宽度，后项来自交互模式老虎机；可读性通过降低干预率改善有效样本效率。
- **命题（可读性降低干预）**：若人类在目标后验熵 `> H_stop` 或预测失败概率 `> p_stop` 时干预，则 `Leg(τ) ≥ 1−ε` 且 `ε log|𝒢| < H_stop` 时，熵触发干预率为 0；可预测性降低惊讶驱动的纠错。
- **命题（解释忠实性）**：引用最小实际原因集且反事实误差 ≤ ε 的解释，使用户因果信念更新误差 ≤ `L·ε`；反之，省略真实原因或引用虚假相关可抬高信任而不提升理解，形成「虚假安心」。
- **实时性**：HIM/HUE/HA-CSP/IAX/TCA 全部在语义流；实时路径只新增一次信念读取与事件日志（<0.05ms），保持第 63 轮 ≤ 2ms 契约与零学习写操作。

## 2. 形式化定义（完整版）

**定义 201（HURI 闭环）** HURI 是 LIRO 的「人在环中的可用性 × 交互」升级：在 LIRO 的「语义流 ∘ 实时流」骨架上挂载 HIM（人类心智模型）、HUE/U-Cert（可用性评估与证书）、HA-CSP（人类感知规划）、IAX（交互感知解释）、TCA（信任校准与权限）、HIB（交互预算）、DIR-H/AIC-H（人类干扰认证）、HSB（人类场景银行）、OCB-H（交互预算老虎机），并原位升级 USL→USL-H、SSB→HSB、J_liro→J_huri。不变式：**人类状态估计、可用性评估、交互规划、解释生成、权限分配只发生在语义流/低频线程；实时路径（1–10kHz）只做物理安全编译与一次信念读取**——物理安全与交互可用性在时序上隔离，互不阻塞。

**定义 202（HIM 人类意图-心智模型）** 人类潜状态 `h_t = (g_t, b_t, τ_t, w_t, s_t, p_t)`：
- `g_t ∈ Δ(𝒢)`：目标后验，`𝒢` 为 DMS 可解析的一阶逻辑目标谓词集；
- `b_t ∈ Δ(ℬ)`：对人类对机器人能力/可靠性信念的估计；
- `τ_t ∈ [0,1]`：信任；
- `w_t ∈ [0,1]`：心智负荷；
- `s_t ∈ [0,1]`：情境意识；
- `p_t`：偏好（速度/安全、解释粒度、交互模态、接管倾向）。
机器人维护 `β_t(h)`，观测 `o_H^t` 含语音/手势/注视/响应延迟/纠错/接管/生理信号。滤波：
`β_t(h) ∝ P(o_H^t | h) Σ_{h'} P(h | h', a_{t-1}) β_{t-1}(h')`。
人类策略 `π_H(a_H | h_t, x'_t)` 允许有界理性；HIM 不假设能读心，只维护带不确定性的后验。

**定义 203（混合主动动作空间）** `A = A_phys ∪ A_int`，`A_phys` 为第 63 轮 USL-H 的物理技能，`A_int = {ask(q), explain(e), demo(d), warn(r), confirm, yield, handover, wait, show_intent}`。每个交互动作带：
- 打断代价 `c_int(a) = c_time(a) + λ_w·Δw(a) + λ_s·social_intrusion(a)`；
- 信息增益 `IG(a) = H(β_t) − E_{o'}[H(β_{t+1})]`；
- 安全关键标记 `safe_critical(a) ∈ {0,1}`（`warn/confirm/yield/handover` 为 1）。
安全关键动作走独立通道，不消耗普通解释预算，但仍需通过物理安全证书。

**定义 204（HA-CSP 人类感知技能规划）** 给定目标 `G`，联合搜索 `(τ, a_int, θ_bind)`：
`max E[Σ_t task_progress_t] + λ_u·Û(τ,a_int) + λ_l·Leg(τ) + λ_i·Σ_t IG(a_t) − λ_c·Cost(τ,θ) − λ_b·Σ_t c_int(a_t)`
s.t.
1. `pre_σ1(x',φ̂)` 成立；`eff_σi ⊨ pre_σ{i+1}`；`eff_σH ⊨ G`；
2. `∀i, π_σi(·;θ_i) ∈ 𝒫_feas(φ̂,r)`（继承定义 200）；
3. 社交/工作空间约束 `𝒮(x')`：人类安全距离、交接几何、可视性、不穿越人类活动通道；
4. 人类偏好约束 `𝒫_h`：禁入区、最大速度、偏好手、解释粒度；
5. 交互预算 `Σ c_int(a_t) ≤ B_int`。
求解：在 USL-H 技能图与交互动作构成的**乘积空间**上做层级 A*；物理层复用第 63 轮 CSP 候选，交互层用信息增益贪心/VOI 剪枝。实时只执行 `τ[0]`，后续 receding horizon 重规划。

**定义 205（可读性与可预测性）** 人类目标推断模型 `q_H(g | τ, x')` 由离线人类演示/注视数据训练。`Leg(τ) = 1 − H(G|τ,x')/log|𝒢|`；`Pred(τ) = 1 − E_t D_KL(P_H(ξ_t|τ_{<t}) ‖ δ_{ξ_t})/log|Ξ|`。可读性奖励「让意图早显露」，可预测性惩罚「让人类惊讶的轨迹」；二者与任务效率显式折中，避免「高效但像故障」的运动。

**定义 206（可用性向量）** `u ∈ [0,1]^10`，各维映射：
| 维度 | 含义 | 主要测量 |
|---|---|---|
| `u_eff` | 有效性 | 任务完成率（ISO 9241-11） |
| `u_effic` | 效率 | 单位成功任务时间/能耗（ISO 9241-11） |
| `u_sat` | 满意度 | SUS / UEQ-S |
| `u_learn` | 可学习性 | 重复任务的效率/错误改善斜率 |
| `u_trust` | 信任校准 | `1 − |τ−R|/δ_max` |
| `u_work` | 心智负荷 | `1 − NASA-TLX/100` |
| `u_sa` | 情境意识 | SAGAT 正确率 |
| `u_safe` | 感知安全 | Godspeed 负向项 / 自报告 |
| `u_expl` | 可解释性 | 理解测验 + `Faith(e)` |
| `u_accept` | 接受度 | 继续使用/推荐意愿 |

**定义 207（HUE 可用性评估器）** 四源信号：
- 客观 `o^obj`：完成率、时间、错误、接管次数、澄清轮次、空闲时长；
- 行为 `o^beh`：响应延迟、注视熵、纠错频率、遵从/依赖、接管时机；
- 生理 `o^phys`（可选）：HRV、EDA、瞳孔直径；
- 主观 `y^subj`：微问卷（EMA）、条件后量表、锚点题。
模型：`u_t = f_UE(φ_UE; o^obj_t, o^beh_t, o^phys_t, y^subj_t)`，主观项用多水平 IRT：
`P(y_ij ≥ k | u_i) = σ(a_j(u_i − b_{jk}))`，`u_i ~ N(μ_{c(i)}, Σ_{c(i)})`。
在线用客观+行为+生理推断；每 `K` 个 episode 用主观锚点校准；输出后验均值 `û` 与区间。所有量表版本、翻译、施测顺序写入 `protocol_hash`。

**定义 208（U-Cert 可用性证书）** `U_cert = (û, C_δ(u), n_eff, cluster_id, protocol_hash, scale_versions, drift_flag)`。
`C_δ(u)` 由 Mondrian 保形预测构造：对每个用户簇 `c` 与关键构念 `k`，用校准集非一致性分数 `s_i = |u_{i,k} − û(x_i)_k|` 取 `⌈(n_c+1)(1−δ)⌉` 分位数 `q_{c,k}`，区间 `[û_k − q_{c,k}, û_k + q_{c,k}]`。
`Valid(U_cert) ⇔ ∀k∈K_crit, LCB_k(C_δ(u_k)) ≥ u_k^min ∧ n_eff ≥ n_min ∧ ¬drift_flag`。
**禁止用总体平均出证**：必须逐用户簇报告；若某簇低于阈值，证书整体失败并标记 `cluster_fail`。

**定义 209（信任与校准）** `R_t` 为 `J_liro` 的可靠度下界（可由认证成功率/保守成功率给出）。`e_trust(t)=|τ_t−R_t|`；过信任 `τ_t > R_t+δ_trust`；欠信任 `τ_t < R_t−δ_trust`。信任动力学：
`τ_{t+1} = clip(τ_t + α_o(o_t−τ_t) + α_e·ψ(e_t) − α_v·v_t, 0, 1)`，
`o_t∈[0,1]` 为任务结果，`ψ(e_t)` 为解释带来的信任偏移，`v_t` 为违规/事故。校准证书 `T_cert = (|τ−R|≤δ_trust, n_obs, overtrust_flag, undertrust_flag, drift_flag)`。

**定义 210（TCA 信任校准与权限分配）** 自主权限
`α_t = clip(g_TCA(R_t−τ_t, risk_t, w_t, s_t), α_min, α_max(risk_t))`，
其中 `α_max(risk_t)` 随风险单调不增；`g_TCA` 对 `(R−τ)` 单调增（欠信任时允许更多自主以展示能力），对风险/负荷单调减。规则：
1. 过信任且 `risk_t > risk_high`：强制 `α_t ≤ α_safe`，并触发不确定性披露/确认；
2. 欠信任且 `risk_t` 低：允许受验证的演示性自主，但不强制；
3. 任何权限提升需人类确认；`H_override ≡ 1`（接管权永远可用）；
4. 权限日志 `authority_log` 记录每次变更的原因与证据。

**定义 211（IAX 交互感知解释）** `C2X: (J_liro, 𝒞_counterfactual, β_t) → e`，`e` 从 `{why, why-not, what-if, how, uncertainty}` 中选。结构因果模型 `M=(V,U,F)`；对结果 `Y` 与上下文 `x`，`C(x)` 为 Halpern-Pearl 意义下的最小充分实际原因集。解释 `e` 引用因素集 `F(e)`：
- `Faith(e) = 1 − |F(e) Δ C(x)|/|C(x)|`；
- `Cal(e) = 1 − |ψ(e) − ψ_true(e)|`。
IAX 选择：
`e* = argmax_{e: Faith(e)≥1−ε_faith, E[ψ(e)]=0} E[Δu_trust + Δu_sa + Δtask] − c_int(e)`。
反事实解释由 WCV/SSB 的同一物理模型生成（如「若摩擦再低 0.1，该抓取会滑」），禁止用无模型的语言模型编造因果。

**定义 212（J_huri 人机交互证书）** `J_huri = (J_liro, U_cert, T_cert, E_cert, authority_log, override_evidence, protocol_hash)`。
`Valid(J_huri) ⇔ Valid(J_liro) ∧ Valid(U_cert) ∧ T_cert(|τ−R|≤δ_trust) ∧ E_cert(Faith≥1−ε_faith) ∧ override_evidence ∧ ¬unauthorized_escalation`。
审计链：`U_cert` 追溯量表版本/被试簇/样本量；`T_cert` 追溯信任轨迹与解释记录；`authority_log` 追溯每次权限变更与人类确认；`override_evidence` 证明人类始终可接管。

**定义 213（HIB 交互预算）** 滑动窗口预算：
`B_int(t+1) = min(B_max, B_int(t) + ρ_B·Δt − c_int(a_t))`。
`warn/confirm/yield/handover` 标记 `safe_critical=1`，走独立安全通道，不消耗普通解释预算。预算耗尽时，HA-CSP 只能选择静默保守技能或请求接管；不得用「多问几句」绕过安全约束。

**定义 214（人类干扰集）** `ℰ_human = ℰ_amb × ℰ_delay × ℰ_takeover × ℰ_occl × ℰ_misuse`：
- `ℰ_amb`：指令歧义，目标后验熵 `H(g|β) > H_amb` 或解析置信度低；
- `ℰ_delay`：响应延迟超过个体基线分位数；
- `ℰ_takeover`：人类施加的力/位移/接管命令超出预测；
- `ℰ_occl`：人体进入机器人感知/运动通道造成遮挡；
- `ℰ_misuse`：非专家越界指令、错误顺序、禁用区操作。
半径由 HIM/HUE 历史经验分位数校准；`ρ_hri(τ) = min_{η∈ℰ_phys×ℰ_human} min_t margin(τ,η)`，并入 AIC-H。

**定义 215（HSB 人类场景银行）** 交互 episode 签名
`ep_sig = (user_cluster, goal, interaction_trace, u_vector, trust_trace, explanation_accept, failure_mode)`。
- `Mine`：当可用性下降、信任失准、澄清失败或接管异常时建场景；
- `Mut`：在「人格（谨慎/冒险）、负荷（低/中/高）、交互模态（语音/手势/图形）、歧义程度、语言/文化」维度变异；
- 隐私：原始语音/生理不出端，只存匿名嵌入；聚合统计加差分隐私噪声，记录隐私预算 `ε_DP`。

**定义 216（可用性驱动共适应）** 在语义流用 HUE+HSB 更新偏好 `p_t`、解释模板、交互技能参数，需通过三重门：
1. **安全门**：`Valid(J_liro)` 不回退，物理安全参数不被在线修改；
2. **量表门**：主观锚点量表（SUS/UEQ-S/Trust）不下降，且与代理指标的相关性保持；
3. **反奖励黑客门**：代理指标（点击确认速度、任务时间）不得单独驱动更新；需有独立验证量表的增益证据。
任何共适应更新写入 `protocol_hash` 与审计日志；出现漂移则回滚。

class HumanIntentMentalModel:
    """维护人类潜状态后验 β_t(h)，不读心，只做带不确定性的贝叶斯滤波。"""
    def __init__(self, n_goals, d_obs=64, d_h=32):
        self.goal_head = MLP(d_obs, [128, 128], n_goals)
        self.belief_head = MLP(d_obs, [64], 8)          # 对机器人能力的信念
        self.load_head = MLP(d_obs, [64], 1)            # 心智负荷
        self.sa_head = MLP(d_obs, [64], 1)              # 情境意识
        self.trust_model = TrustDynamics()
        self.beta = PriorHumanState(n_goals)

    def filter(self, beta_prev, o_H, a_prev):
        z = encode_human_observation(o_H)               # 语音/手势/注视/延迟/纠错/接管
        logits = self.goal_head(z)
        # 目标转移：a_prev 可能改变目标可达性
        logits = logits + transition_bias(a_prev, beta_prev.goal)
        goal = softmax(logits)
        belief = sigmoid(self.belief_head(z))
        workload = sigmoid(self.load_head(z))
        sa = sigmoid(self.sa_head(z))
        trust = self.trust_model.update(beta_prev.trust, o_H.outcome, o_H.explanation_effect)
        pref = update_preference(beta_prev.pref, o_H)   # 解释粒度/模态/速度偏好
        return HumanState(goal, belief, trust, workload, sa, pref)

    def goal_entropy(self, beta):
        return -sum(p * np.log(p + 1e-9) for p in beta.goal)

class TrustDynamics:
    def __init__(self, alpha_o=0.2, alpha_e=0.1, alpha_v=0.3):
        self.alpha_o, self.alpha_e, self.alpha_v = alpha_o, alpha_e, alpha_v

    def update(self, trust, outcome, explanation_effect, violation=0.0):
        t = trust + self.alpha_o * (outcome - trust) \
            + self.alpha_e * explanation_effect - self.alpha_v * violation
        return float(np.clip(t, 0.0, 1.0))

    """客观+行为+生理+主观四源 → 十维可用性向量 û 与区间。"""

class HumanAwareCSP(CSPPlanner):
    """物理技能 × 交互动作的乘积空间 A*；实时只展开首技能。"""
    def __init__(self, usl_h, human_model, explainer, budget, max_horizon=5):
        super().__init__(usl_h, max_horizon)
        self.him, self.iax, self.hib = human_model, explainer, budget

    def plan(self, goal, x_prime, phi_hat, r, beta, B_int):
        phys_candidates = super().plan(goal, x_prime, phi_hat, r)  # 第 63 轮 CSP 候选
        best = None
        for tau, theta in phys_candidates:
            leg = legibility(tau, x_prime, beta)
            a_int = self._select_interactions(tau, beta, B_int)
            score = (expected_task_progress(tau, x_prime, beta)
                     + LAMBDA_U * expected_usability_gain(a_int, beta)
                     + LAMBDA_L * leg
                     + LAMBDA_I * sum(self._ig(a, beta) for a in a_int)
                     - LAMBDA_C * sum(s.cost for s in tau)
                     - LAMBDA_B * sum(self.hib.cost(a) for a in a_int))
            if best is None or score > best[0]:
                best = (score, tau, a_int, theta)
        return best[1], best[2], best[3]

    def _select_interactions(self, tau, beta, B_int):
        acts, spent = [], 0.0
        # 信息增益次模：贪心选择，预算内近似 (1-1/e)
        while True:
            cand = [(self._ig(a, beta) / max(self.hib.cost(a), 1e-6), a)
                    for a in self._feasible_interactions(tau, beta)
                    if self._ig(a, beta) > DELTA_I]
            if not cand:
                break
            cand.sort(reverse=True)
            a = cand[0][1]
            if spent + self.hib.cost(a) > B_int:
                break
            acts.append(a); spent += self.hib.cost(a)
            beta = self._predict_post_interaction(beta, a)
        return acts

    def _feasible_interactions(self, tau, beta):
        acts = []
        if beta.workload < W_HIGH:
            acts += ['ask', 'explain']
        if beta.trust < 0.4:
            acts.append('demo')
        if beta.sa < 0.5:
            acts.append('show_intent')
        return acts

class InteractionAwareExplainer:
    """证书 → 因果忠实解释；优化校准增益，而非说服力。"""
    def __init__(self, scm, faithfulness_eps=0.1, cost_fn=None):
        self.scm, self.eps = scm, faithfulness_eps
        self.cost = cost_fn or (lambda e: 0.1)

    def select(self, J_liro, counterfactuals, beta):
        best = None
        for e in self._enumerate(J_liro, counterfactuals, beta):   # why/why-not/what-if/how/uncertainty
            faith = self._faithfulness(e, counterfactuals)
            if faith < 1 - self.eps:
                continue                                            # 不忠实的解释直接淘汰
            if not self._calibration_preserving(e):
                continue                                            # E[ψ(e)] ≈ 0
            gain = (self._expected_trust_calibration_gain(e, beta)
                    + self._expected_sa_gain(e, beta)
                    + self._expected_task_gain(e, beta))
            score = gain - self.cost(e)
            if best is None or score > best[0]:
                best = (score, e)
        return best[1] if best else self._minimal_uncertainty_explanation(J_liro)

    def _faithfulness(self, e, cf):
        C = self.scm.minimal_actual_cause(cf.context)              # 最小充分原因集
        F = set(e.cited_factors)
        if not C:
            return 1.0
        return 1.0 - len(F.symmetric_difference(C)) / len(C)

    def _calibration_preserving(self, e):
        return abs(self.scm.estimate_trust_effect(e)) <= PSI_EPS

    SAFETY_CRITICAL = {'warn', 'confirm', 'yield', 'handover'}
    def __init__(self, B_max=6.0, rho_B=0.2):
        self.B_max, self.rho_B, self.remaining = B_max, rho_B, B_max

## 4. 推导

**引理 5（可用性证书的有限样本覆盖）** 设校准集 `D_cal = {(x_i, u_i)}_{i=1}^{n_c}` 与测试用户 `(x_{n_c+1}, u_{n_c+1})` 在同一用户簇 `c` 内可交换。对构念 `k` 定义非一致性分数 `s_i = |u_{i,k} − û_k(x_i)|`，取 `q_{c,k} = s_{(\lceil (n_c+1)(1−δ) \rceil)}`。由保形预测的标准论证，
`P(u_{n_c+1,k} ∈ [û_k(x_{n_c+1}) − q_{c,k}, û_k(x_{n_c+1}) + q_{c,k}]) ≥ 1−δ`。
对 `|K_crit|` 个关键构念与 `C` 个用户簇做 Bonferroni，取 `δ' = δ/(|K_crit|·C)`，得族系覆盖 `≥ 1−δ`。该结论**不依赖高斯/线性/大样本近似**，但依赖簇内可交换性；跨簇分布漂移会使覆盖失效。工程上用 ACI（自适应保形推断）在线调整 `q`，在漂移下维持长期覆盖。∎

**引理 6（交互预算下的意图熵）** 令 `H_t = H(g|β_t)`，交互 `a` 的期望信息增益 `Δ(a) = H_t − E[H_{t+1}]`。若每次被选中交互满足 `Δ(a) ≥ δ_I`，且预算允许 `m` 次，则
`H_{t+m} ≤ H_0 − m·δ_I`，故 `H_{t+m} ≤ max(0, H_0 − m δ_I)`。
若 `Δ` 在动作集上次模且预算为基数约束，贪心选择的总增益 `≥ (1−1/e)·OPT`（Nemhauser 等）。当预算耗尽而 `H_t > H_stop` 时，HA-CSP 的可行域只剩「静默保守技能」或 `handover`；这是**预算约束下的安全降级**，而不是继续追问。∎

**引理 7（信任校准保持）** 在线性信任动力学
`τ_{t+1} = τ_t + α_o(o_t−τ_t) + α_e ψ(e_t) − α_v v_t`
下，取期望并令稳态 `E[Δτ]=0`。若无违规 `E[v]=0`、结果平稳 `E[o]=R`，则
`0 = α_o(R − τ_∞) + α_e E[ψ]` ⇒ `τ_∞ = R + (α_e/α_o)E[ψ]`。
因此：
1. `E[ψ]=0` ⇒ `τ_∞=R`，信任校准；
2. `E[ψ]>0` ⇒ 稳态过信任，且偏差随 `α_e/α_o` 放大——**解释的说服力可以直接制造过度信任**；
3. `E[ψ]<0` ⇒ 稳态欠信任，导致不必要接管。
故 IAX 必须满足校准保持约束；TCA 进一步用 `α_max(risk)` 与过信任规则限制「过信任 → 不安全依赖」的转化。时变 `R_t` 下用 CUSUM 检测漂移并重置 `τ` 或降低 `α_e`。∎

**定理 4（HURI 证书有效性）** 设：
- `J_liro` 失效概率 ≤ `α_dir+δ_cert`（第 63 轮定理 3）；
- `U_cert` 覆盖失败概率 ≤ `δ_ue`（引理 5）；
- `T_cert` 失败概率 ≤ `δ_trust`（引理 7 + 漂移检测）；
- `E_cert` 忠实性失败概率 ≤ `δ_e`（定义 211 的 `Faith` 阈值）；
- `override_evidence` 成立且 `α_t ≤ α_max(risk_t)`。
「不安全依赖」事件至少需要以下之一发生：物理安全失效、可用性误判、信任失准、解释不忠实、权限越界。由联合界，
`P(unsafe reliance) ≤ α_dir + δ_cert + δ_ue + δ_trust + δ_e + δ_auth`。
若 `Valid(J_huri)` 且人类接管权可用，则系统不会在人类无法接管的情况下自主提升权限；物理风险由 `J_liro` 限制，交互风险由 `T_cert/E_cert` 限制。∎

**定理 5（可用性感知规划的遗憾分解）** 总损失分解为
`ℓ_t = ℓ_t^task + λ_u ℓ_t^use + λ_i ℓ_t^int`。
- 任务项由第 63 轮 `R_T^skill` 控制；
- 可用性项：`U_cert` 的区间宽度 `w_δ` 给出 `|u_t − û_t| ≤ w_δ`（以 1−δ 概率），故累计可用性估计误差 ≤ `T·w_δ`，贡献 `λ_u T w_δ`；
- 交互项：交互模式由 `K` 臂 EXP3/UCB 选择，奖励有界，伪遗憾 `R_T^int ≤ 2√(2KT log K)`（EXP3）或 `O(√(KT log K))`（UCB）。
故
`R_T^huri ≤ R_T^skill + λ_u T w_δ + λ_i·O(√(KT log K))`。
可读性项通过降低人类干预率减少有效任务步数（见命题），从而改善有效样本效率。∎

**命题（可读性降低干预）** 设人类在目标后验熵 `H(g|β_t) > H_stop` 或预测失败概率 `p_fail > p_stop` 时干预。若 `Leg(τ) ≥ 1−ε`，则 `H(G|τ,x') ≤ ε log|𝒢|`。当 `ε log|𝒢| < H_stop` 时，熵触发干预率为 0；可预测性 `Pred(τ)` 提高则降低惊讶驱动的纠错。因此干预率对 `Leg` 单调不增（在固定任务难度下）。∎

**命题（解释忠实性）** 设结构因果模型 `M` 正确，`C(x)` 为最小充分实际原因集，解释 `e` 引用 `F(e)`。若 `Faith(e)=1`，则 `F(e)=C(x)`；对每个被引用因素的反事实效应估计误差 ≤ `ε`，则用户对结果因果效应的估计误差 ≤ `L·ε`（`L` 为因果效应泛函的 Lipschitz 常数）。若 `e` 省略真实原因或引用虚假相关，则 `Faith(e)<1`，用户可能提高信任而不提高理解；在信任动力学中表现为 `ψ(e)>0` 但不反映真实 `R`，由引理 7 导致过信任。故 IAX 必须同时约束 `Faith` 与 `E[ψ]`。∎

**正确性定理（HURI-Complete）** 假设第 63 轮 A77–A82 及：
- **(A83)** HIM 观测模型校准，人类策略有界理性；目标后验在簇内可校准。
- **(A84)** HUE 的校准/测试用户在同一簇内可交换；主观量表经过信效度验证；`n_eff ≥ n_min`。
- **(A85)** `U_cert` 的 Mondrian 保形覆盖成立；漂移检测可触发 ACI 或证书失效。
- **(A86)** 信任动力学分段平稳；解释效应 `ψ` 可估计；`E[ψ]=0` 约束可执行。
- **(A87)** IAX 的结构因果模型正确，实际原因集可识别，反事实误差有界。
- **(A88)** USL-H 覆盖物理与交互技能；社交/偏好约束是真实约束的保守近似。
- **(A89)** `ℰ_human` 由 HIM/HUE 历史分位数校准，且 `P[η_human* ∈ ℰ_human] ≥ 1−α_h`。
- **(A90)** 实时路径新增读取与日志 ≤ 0.05ms，无学习写操作。

则：
1. **可用性可认证**：`Valid(U_cert)` 下关键构念的真实值以 ≥ `1−δ_ue` 概率落在证书区间内（引理 5）。
2. **交互可预算**：意图熵在预算内按 `δ_I` 下降；预算耗尽安全降级（引理 6）。
3. **信任可校准**：`E[ψ]=0` 时 `τ→R`；系统性解释偏差被显式建模并由 TCA 限制（引理 7）。
4. **人机组合安全**：不安全依赖概率 ≤ `α_dir+δ_cert+δ_ue+δ_trust+δ_e+δ_auth`；人类接管权恒可用（定理 4）。
5. **规划遗憾可控**：`R_T^huri ≤ R_T^skill + λ_u T w_δ + λ_i O(√(KT log K))`（定理 5）。
6. **解释可审计**：只有 `Faith≥1−ε` 且校准保持的解释可进入 `J_huri`；解释可追溯至证书与反事实（定义 211–212）。
7. **实时性不退化**：HURI 的估计/规划/解释/权限全在语义流；实时路径 ≤ 第 63 轮 + 0.05ms。

## 7. 已知风险

**一句话**：若 HUE 的可用性/信任潜状态在跨用户、跨文化、跨任务上不可辨识，或被优化目标劫持，HURI 会把「让用户更快点确认」误当成「更可用」，IAX 可能生成高说服力但低忠实度的解释、TCA 可能把不信任误判为需要更多说服——**「可用性评估」从测量退化为操纵，`U_cert` 沦为虚假背书**，这是本轮所有交互增强论证共同依赖的单点假设（A84/A86/A87）。

**次级风险与缓解**：
1. **构念效度不足**：代理指标（点击速度、确认时间）不等于可用性 → 以 SUS/UEQ-S/NASA-TLX/Trust/SAGAT 为验证锚点；预注册主要终点；禁止代理指标单独驱动共适应（定义 216）。
2. **小样本/非代表性用户**：保形覆盖只在簇内可交换 → 分层招募、按簇出证、报告最差簇；新人群用 ACI 与漂移检测；不把总体平均当证书。
3. **奖励黑客与 Goodhart**：优化 `u_accept` 可能变成诱导确认 → 反奖励黑客门、独立验证量表、红队审计、保留人类否决权。
4. **信任操纵/暗黑模式**：解释以提高信任为目标会制造过信任（引理 7）→ IAX 强制 `E[ψ]=0` 与 `Faith` 阈值；TCA 在过信任 + 高风险时降自主；伦理审查与知情同意。
5. **隐私与生理数据**：注视/HRV/EDA 属敏感数据 → 端侧处理、最小化采集、匿名嵌入、差分隐私、可撤回；HSB 不存原始语音。
6. **分布漂移使证书失效**：新用户/新任务/新语言 → ACI 在线校准、CUSUM 漂移检测、`drift_flag` 使 `U_cert` 失效并回退到保守交互。
7. **交互过度/不足**：预算过严导致该问不问，过松导致打断疲劳 → HIB + 安全关键旁路 + 用户偏好学习；以 NASA-TLX 与完成率双指标调参。
8. **解释幻觉**：LLM 生成看似合理但无因果依据的解释 → C2X 只从 `J_liro`/反事实模型取因；`Faith` 不达标直接淘汰；人工抽检。
9. **实时性退化**：HIM/HUE/HA-CSP/IAX 若误入实时路径 → 架构上隔离，实时路径只读信念 + 日志；延迟预算纳入 `J_huri` 审计。
10. **跨文化/语言效度**：量表与解释模板可能不适用 → 多 site 研究、翻译回译、文化适配、按文化簇报告；不把单一文化结论外推。
