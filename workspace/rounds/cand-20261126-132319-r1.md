研究循环·灵感三元组（承接 v24；本轮灵感：「强化学习」×「轻量化设计」）

> **基线**：承接 MetricVoiceGauge-NCD-HUTDH-v24 + IP-440–446（PCC/FIA/FPL/SPOC/NEFC/APP/HPC-F），其上承 v23 的 HDL/ACSC/DCSC/HPC-E/CFC++/CESC/FSVC/IPAM/HPC-E+、v20 联邦感知证书（PCA/CTS/CFC/HPC/CFCtrl）、v19 的 DCM/OGCC/CCV/DRS/OGC 与 v17 的 CLP/S2C/HCG/PSV/APS/AMC。
> 本轮纪律：**强化学习负责"在已验证可行域内恢复活性"，轻量化负责"在固定实时预算内证明保守"；二者对偶——RL 决定"把多少已证自由真正用起来"，轻量化决定"每次判定要花多少算力"，共同红线是绝不放松证书的保守方向**。不推倒 v24：PCC/FIA/FPL/SPOC/NEFC/APP 与单调链 `Exec_v24 ⊆ … ⊆ Exec_v18` 全部保留。本轮只做一件事：**把 v24 的"静态·精确·重"盾牌，升级为"可学习·可实时"的轻量盾牌——RL 只在证书壳内做遮蔽式策略优化，轻量化把昂贵证书判定编译为"可证保守的快速代理 + 边界带精确回退 + 预算耗尽失效关闭"，在保持 `Exec_v25 ⊆ Exec_v24` 的前提下同时夺回活性与 50Hz 实时性。**

## 0. 直觉与动机

**灵感 1（强化学习 → 活性不是靠放松证书，而是靠"在证书壳内学会怎么走得更好"）**
直觉：从 v18 到 v24，执行集一路单调收缩；每一轮都用"再保守一点"封堵上一轮的风险，代价是活性（active liveness）被反复侵蚀——过度拦截、频繁 SafeStop、可行却不敢走。v24 的盾牌把"安全"做成了"处处最保守"，但**保守性是可加的错误，而活性是不可加的收益**。强化学习（RL）的正确定位不是去"学习/放宽安全约束"（那会直接破坏证书），而是：证书定义了一个**可行动作集**（shield），RL 只在这个集合内部学习如何最大化任务进度——即 **遮蔽式强化学习 (shielded RL)**。安全由遮蔽按构造保证；RL 只决定"在安全选项里选哪一个"、以及"如何把已经证明可用的自由度真正用起来"。
- **反直觉点 1**：奖励里**不得含任何安全项**。一旦把"安全代理分数"写进 reward，reward hacking 会诱导策略去优化那个代理，而不是优化真实安全；安全只能以**硬遮蔽**的形式进入，绝不进入奖励函数。
- **反直觉点 2**：探索是有边界的。最有信息量的经验恰在最靠近证书边界处（那里可行余量最大、也最接近不可行），于是探索必须被限制在"证书允许 ∧ 动作级遮蔽可恢复"的子空间内——RL 探索的是**余量 (slack)**，不是越界。我们称之为 **证书余量探索 (certificate-slack exploration)**。
- **反直觉点 3（与轻量化耦合）**：RL 为恢复活性会主动把占用分布推向边界（边界处可行余量最大），这会**提高需要精确验证的"模糊带"命中率**，反而放大计算压力——活性优化与实时预算天然互相拉扯，必须联合设计，而不能各自最优。

**灵感 2（轻量化设计 → 不是"算得更糙"，而是"把证明的昂贵部分换成可证保守的快速代理"）**
直觉：v24 的 HPC-F 在 50Hz 边缘上很重——FIA 的最大独立集是组合搜索、DS 融合、SPOC 覆盖栅格、PCC 可达性查询层层叠加。轻量化的诱惑是"近似一下就好"，但那会破坏证书。正确做法是 **两级门控（快-慢路径）**：绝大多数"远离边界"的判定用一个轻量代理前向即可；只有落入"模糊带"的少数样本回退到精确验证。
- **反直觉点 1**：代理**不需要"准"，只需要"保守方向单向"**。代理输出一个区间 `[L,U]`：只有 `L` 越过阈值才承认可行（此时以 ≥1−α 概率保证真值也越过），只有 `U` 低于阈值才拒绝，落在 `[L,U]` 跨界处才回退精确。代理越"宽"只会让更多样本走慢路径（活性/时延代价），**绝不会让它错误地扩大可行集**。
- **反直觉点 2**：量化/蒸馏通常会破坏感知的 conformal 覆盖，但覆盖是**分布的性质而非模型的性质**：对量化后模型在校准集上**重新估计分位数**，并把量化误差（其 conformal 上界）作为一项**保守膨胀**加进去，就能在 int8 上重建 1−α 覆盖——**轻量化不杀死统计保证，只要它愿意把"省下的精度"折算成"更宽的区间"**。
- **反直觉点 3**：实时性不是平均时延问题，而是**最坏时延 + 预算耗尽时的行为**问题：必须 **anytime**（算得越久判得越松、单调）且 **fail-closed**（预算耗尽默认拒绝）。宁可偶尔因算不完而保守拒证，也绝不能在超时后放行。

**二者如何统一（活性—算力对偶）**
- RL 是**纵向（时间维度）**的：在策略空间上，把"每一步都最保守"换成"整条轨迹更少保守"；
- 轻量化是**横向（单步维度）**的：在判定空间上，把"处处精确"换成"远离边界用代理、边界用精确"；
- 二者统一为 **证书壳内的受约束策略优化 + 预算受限的 anytime 门控**：`a_t = argmax_{a∈Shield_B(ζ_t)} Q_θ(s_t,a)`，其中 `Shield_B` 由快慢两级门控在预算 B 内给出，且 `Shield_B ⊆ Shield_∞ ⊆ 精确可行集`。RL 只在这层壳内选动作，轻量化只决定"壳算得多紧、多快"，**二者都不改变证书的保守方向**，故 `Exec_v25 ⊆ Exec_v24`。
- 共享状态扩展为 `ζ_light = ζ_fuse ∪ (θ, σ_slack, g_φ, [L,U], B_t, A(B), α_surr, q̃_α, ε_quant)`。
- 统一准入门 **HPC-G = HPC-F ∧ LCS ∧ ABC ∧ QAC**，策略在 `Shield_B = {a : HPC-G.admits(a; B)}` 内选择；`Exec_v25 = Exec_v24 ∩ Fil_light ∩ Fil_budget ⊆ Exec_v24`。

- **Q18（计算预算与实时性）**：如何在固定预算 `B_t` 下对多个证书谓词按"安全关键度 × 信息增益 / 计算代价"排序，并给出单调的 anytime 下界 `A(B)`？预算耗尽时 fail-closed 退化与活性损失如何权衡？精确路径与代理路径的切换如何避免在边界带附近抖动（thrashing）？
- **Q19（量化/蒸馏后的统计保证）**：int8 量化/蒸馏后，conformal 分位数如何重校准以维持 1−α 覆盖？量化误差与感知分布漂移叠加时覆盖是否仍成立？保守膨胀项 `ε_quant` 如何由 conformal 上界给出，从而保证量化证书的可行集 ⊆ 全精度证书的可行集？轻量代理与量化感知证书如何共享骨干以进一步省算力？

## 2. 设计原则（在 P43–P45 基础上新增 P46–P48）

**P46 盾牌内优化律（Optimize-within-Shield）**
RL 只在证书允许的动作集内选择：`a_t = argmax_{a∈Shield_B(ζ_t)} Q_θ(s_t,a)`，`Shield_B(ζ) ⊆ 精确可行集`；**证书参数对策略梯度冻结**（安全不参与可微优化）；**奖励函数不含任何安全项**（安全只以硬遮蔽进入）。因此 `Exec_v25` 的集合由证书与轻量代理决定，**与策略参数 θ 无关**；策略只影响轨迹占用分布与活性，不影响安全集。`Shield_B = ∅` 时执行**预置安全动作**（让位/停机）并记录不可行事件，绝不因策略而放行。

**P47 可证快速代理单向保守律（Sound Fast-Path Conservatism）**
轻量代理 `g_φ: ζ → [L,U]` 用于快速判定，但**只允许单向保守**：`L ≥ 0 ⇒ 承认`（在 ≥1−α_surr 覆盖下真值亦可行）；`U < 0 ⇒ 拒绝`；否则回退精确验证。代理**不得扩大**精确可行集，只能缩小。边界带宽度由 conformal 校准并经时间一致修正；代理输入分布偏离去极化时（如策略把占用推向边界），必须按占用分布加权重校准或用 ACI 维持长期错误率 ≤ α_surr。代理与精确判定组成 `Shield_B ⊆ Shield_∞`。

**P48 实时预算失效关闭律（Anytime Fail-Closed Budgeting）**
每个控制周期有计算预算 `B_t`；证书谓词按安全关键度优先求值，`A(B)` 关于 B **单调不减**，且 `A(0)=∅`。预算耗尽而未完成正证明 ⇒ **默认拒绝**（fail-closed），绝不超时放行。量化感知证书（QAC）须以保守膨胀 `ε_quant` 保证其可行集 `⊆` 全精度可行集；覆盖跌破阈值即停用轻量路径、回退精确或直接保守停机（向 v24 退化）。

## 3. 与基线的接口（如何退化）

- SPO 失效（策略网络故障/无可用策略）⇒ 退回 HPC-F 的保守默认策略（v24 行为），执行集不变但活性下降；
- CSR 失效（探索调节不可用）⇒ 关闭探索，纯 exploit 最保守策略，仍不越过 Shield；
- LCS 失效（代理不可信/校准失败/覆盖跌破）⇒ 全部走精确验证（预算允许时），否则保守拒绝 ⇔ 退回 v24 精确门（更慢但同安全）；
- ABC 失效（预算不可控/精确路径超时）⇒ 强制 fail-closed，低频保守运行或停机；
- QAC 失效（量化覆盖跌破）⇒ 回退全精度模型（昂贵）或退回 v24 感知；量化证书始终 `⊆` 全精度证书；
- 全失效 ⇒ 回退 v24 ⇒ `Exec_v25 ⊆ Exec_v24 ⊆ … ⊆ Exec_v18`。
- **安全继承**：SPO 只在壳内选动作、不改变壳；LCS 只单向保守、只缩不放；ABC 只 fail-closed；QAC 只保守膨胀。任意失效都向更保守方向退化，取交后单调链保持。

## 4. 预期贡献

1. **遮蔽式活性恢复**：首次把"RL 不碰安全"形式化为 `a_t = argmax_{a∈Shield_B} Q_θ` 的集合约束，证明策略优化与安全集解耦（`Exec_v25` 与 θ 无关），把前几轮累积的活性坍缩从"放松证书"转向"在壳内学好"；
2. **可证轻量代理**：给出"区间代理 + 单向保守判定 + 边界带精确回退"的快慢两级门控，代理只需保守而非精确，从而在保持（概率性）保证的同时把常见路径从组合搜索降到一次前向；
3. **预算受限 anytime 门控**：把实时性建模为"预算 B 上的单调可行集 `A(B)` + 耗尽 fail-closed"，使最坏时延行为可知、可审计，而非赌平均时延；
4. **量化感知 conformal**：给出"重校准分位数 + 量化误差保守膨胀"的 int8/蒸馏证书，使覆盖在量化后仍 ≥1−α，且量化可行集 ⊆ 全精度可行集——轻量化的代价被显式折算进区间宽度而非安全；
5. **活性—算力对偶**：统一 RL（纵向恢复活性）与轻量化（横向压缩判定），并显式刻画二者的耦合风险——RL 把占用推向边界会加剧代理的分布偏移；
6. **HPC-G 统一准入门**：`Exec_v25 ⊆ Exec_v24 ⊆ … ⊆ Exec_v18` 闭环，任意失效向保守退化。

## 5. 本轮最大风险

**一句话**：RL 为恢复活性会主动把状态占用分布推向证书边界（那里可行余量最大），而轻量代理的保守区间恰在边界处最宽、重校准样本最少、conformal 覆盖最脆弱——活性优化与轻量化在此耦合，使系统在"最需要精确验证的边缘"恰好依赖"最不可靠的快速代理"，形成**边缘处的假证**。

## 1. 关键算法骨架（在 IP-440–446 骨架上扩展）

# ============================================================
# IP-447 Shielded Policy Optimizer (SPO) — 遮蔽式活性恢复
# ============================================================
class ShieldedPolicyOptimizer:
    """策略只在证书壳内选动作；证书对梯度冻结；奖励无安全项。"""

    def __init__(self, policy: nn.Module, gate: 'HPCEGate', config):
        self.policy = policy            # π_θ / Q_θ
        self.gate = gate                # 证书门（不做反向传播）
        self.a_safe = config['a_safe']  # Shield 为空时的预置安全动作
        self.gamma = config.get('gamma', 0.99)

    def shield(self, zeta, B_t) -> list:
        """候选动作集由证书门在预算 B_t 内判定；gate 内部走快慢两级路径"""
        return [a for a in self._candidate_actions(zeta)
                if self.gate.admits(a, zeta, B_t)]

    def act(self, s, zeta, B_t, explore: bool = False):
        Sh = self.shield(zeta, B_t)
        if not Sh:                                  # fail-safe，绝不放行
            self._log("EMPTY_SHIELD", zeta)
            return self.a_safe
        q = {a: self.policy.q(s, a) for a in Sh}
        best = max(q, key=q.get)
        if explore:
            # 证书余量探索：只在壳内、按 slack 加权采样，不越界
            w = {a: math.exp(self._slack(zeta, a) / self.tau_explore) for a in Sh}
            return self._sample(Sh, w)
        return best

    def _slack(self, zeta, a):
        return self.gate.signed_margin(a, zeta)     # σ(a,ζ) = y - τ_gate ≥ 0

    def train_step(self, batch):
        # 动作均来自 Shield（行为策略亦被遮蔽）；损失只含任务回报
        # 关键：不回传梯度到 gate / certificate / 任何安全判别量
        loss = self._policy_loss(batch)             # J = E[Σγ^t r_t]，r 无安全项
        loss.backward()
        self.optimizer.step()
        return loss.item()


# ============================================================
# IP-448 Certificate Slack Regulator (CSR) — 余量探索与防蠕动
# ============================================================
class CertificateSlackRegulator:
    def __init__(self, sigma_min=0.05, creep_rate=0.01):
        self.sigma_min = sigma_min        # 探索需保留的最小安全余量
        self.creep_rate = creep_rate      # 边界蠕动检测阈值
        self.history = deque(maxlen=1000)

    def explore_ok(self, zeta, a):
        """只在有余量且可恢复的壳内探索；逼近危险边界的动作被拒绝"""
        s = self.gate.signed_margin(a, zeta)
        return s >= self.sigma_min and self.gate.recoverable(a, zeta)

    def detect_creep(self, sigma_t):
        """若策略持续把占用推向边界（余量单调收缩），收紧探索预算"""
        self.history.append(sigma_t)
        if len(self.history) < 50:
            return False
        trend = self.history[-1] - self.history[0]
        return trend < -self.creep_rate      # 余量在系统性下降

    def tighten(self):
        # 提高 sigma_min / 关闭探索；只影响活性，不影响安全集
        self.sigma_min *= 1.1


# ============================================================
# IP-449 Lightweight Certificate Surrogate (LCS) — 可证保守快速代理
# ============================================================
class Verdict(Enum):
    ADMIT = "admit"       # L ≥ τ ⇒ 真值可行（≥1-α_surr）
    REJECT = "reject"     # U < τ ⇒ 真值不可行
    EXACT = "exact"       # 模糊带，必须回退精确验证

class LightweightCertificateSurrogate:
    def __init__(self, g_phi: nn.Module, alpha_surr=0.005,
                 aci_gamma=0.05, density_ratio=None):
        self.g = g_phi
        self.alpha_surr = alpha_surr
        self.alpha_t = alpha_surr        # ACI 实时显著性
        self.aci_gamma = aci_gamma
        self.dr = density_ratio          # w(ζ)=p_π/p_calib，用于加权
        self.q_lo = self.q_hi = 0.0
        self._calibrate()

    def _calibrate(self, D_calib=None):
        """在（加权）校准集上估计残差区间半宽，取 (1-α) 分位数"""
        D = D_calib or self.D_calib
        resid = [abs(y - self.g(z)) for z, y in D]
        if self.dr is not None:                     # 重要性加权分位数
            resid = self._weighted_quantile_inputs(resid, D)
        self.q_hi = self._quantile(resid, 1 - self.alpha_t)
        self.q_lo = self.q_hi                        # 对称区间

    def interval(self, z):
        yhat = self.g(z)
        return yhat - self.q_lo, yhat + self.q_hi

    def verdict(self, z, tau) -> Verdict:
        L, U = self.interval(z)
        if L >= tau:                                 # 只承认下界越过阈值者
            return Verdict.ADMIT
        if U < tau:
            return Verdict.REJECT
        return Verdict.EXACT                         # 模糊带

    def online_update(self, z, y_true, tau):
        """时间一致 conformal (ACI)：分布漂移下维持长期错误率 ≤ α_surr"""
        L, U = self.interval(z)
        err = 0.0 if L <= y_true <= U else 1.0
        self.alpha_t += self.aci_gamma * (self.alpha_surr - err)
        self.alpha_t = min(max(self.alpha_t, 1e-4), 0.5)
        self._calibrate()


# ============================================================
# IP-450 Anytime Budgeted Certifier (ABC) — 预算受限 fail-closed 门控
# ============================================================
class AnytimeBudgetedCertifier:
    def __init__(self, predicates, time_budget_ms=15.0):
        # predicates: [(name, cost, priority, fn)]，按 priority 降序
        self.preds = sorted(predicates, key=lambda p: p[2], reverse=True)
        self.B = time_budget_ms

    def evaluate(self, zeta, B_t=None):
        """返回 (admitted, A_B, spent)；A(B) 随预算单调增长，A(0)=∅"""
        budget = self.B if B_t is None else B_t
        spent, A_B = 0.0, set()
        for name, cost, _, fn in self.preds:
            if spent + cost > budget:
                return False, A_B, spent          # 预算耗尽 ⇒ fail-closed
            spent += cost
            if not fn(zeta):
                return False, A_B, spent          # 任一已求值谓词失败 ⇒ 拒绝
            A_B.add(name)                          # 已通过的保守子集
        return True, A_B, spent

# IP-451 Quantization-Aware Conformal (QAC) — 量化后仍维持 1-α 覆盖
# ============================================================
class QuantizationAwareConformal:
    def __init__(self, full_model, alpha=0.01, beta=1e-3):
        self.full = full_model
        self.quant = quantize_int8(full_model)     # 骨干/分类头 int8
        self.alpha, self.beta = alpha, beta
        self.eps_quant = 0.0                        # 量化误差 conformal 上界
        self.q_tilde = None                         # 量化后重校准分位数
        self.full_eps = None                        # 全精度定位误差界

    def calibrate(self, D_calib):
        """同时估计全精度界与量化膨胀，保证 ε̃ ≥ ε（保守方向）"""
        self.full_eps = self._conformal_quantile(self.full, D_calib, self.alpha)
        errs = [abs(self._score(self.quant, x) - self._score(self.full, x))
                for x, _ in D_calib]
        self.eps_quant = self._quantile(errs, 1 - self.beta)
        # 在量化输出上重校准（分布是覆盖的对象）
        self.q_tilde = self._conformal_quantile(self.quant, D_calib, self.alpha)
        return self.eps_quant, self.q_tilde

    def certbox(self, x):
        """量化感知 CertBox：保守膨胀 ε̃ = ε_full + ε_quant ≥ ε_full"""
        s_tilde = self._score(self.quant, x)
        eps_tilde = self.full_eps + self.eps_quant
        return inflate(self._box(self.quant, x), eps_tilde)

    def admits_subset_of_full(self) -> bool:
        return self.eps_quant >= 0.0 and self.q_tilde >= self.full_eps


# ============================================================
# IP-452 HPC-G (Guarded-Liveness Gate) — 四层统一准入门
# ============================================================
@dataclass
class HPCG:
    hpc_f: 'HPCF'                 # v24 门：物理/规范/负信息/融合独立性
    lcs: LightweightCertificateSurrogate
    abc: AnytimeBudgetedCertifier
    qac: QuantizationAwareConformal
    tau_gate: float = 0.0
    exact: callable = None        # 精确证书判别量 y_exact(a, ζ)

    def admits(self, a, zeta, B_t) -> bool:
        # 1. v24 门（不变）
        if not self.hpc_f.admits(a, zeta.W, zeta.goal, zeta.mounts,
                                 zeta.R_crit, zeta.evidence, zeta.E_res,
                                 zeta.modules):
            return False
        # 2. 量化感知证书必须是全精度证书的保守子集
        if not self.qac.admits_subset_of_full():
            return False
        # 3. 轻量代理先判（单向保守）
        v = self.lcs.verdict(zeta.features(a), self.tau_gate)
        if v == Verdict.REJECT:
            return False
        # 4. 模糊带内回退精确 + 预算受限 anytime（fail-closed）
        if v == Verdict.EXACT:
            ok, _, _ = self.abc.evaluate(zeta, B_t)
            if not ok:
                return False
            return self.exact(a, zeta) >= self.tau_gate
        # v == ADMIT：已由区间下界保守放行（≥1-α_surr）
        return True

    def signed_margin(self, a, zeta) -> float:
        return self.exact(a, zeta) - self.tau_gate

    def recoverable(self, a, zeta) -> bool:
        return zeta.W.recoverable_to_safe(a)

## 2. 复杂度分析

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 |
|---|---|---|---|

## 3. 正确性论证

### 引理 1（遮蔽不变性与策略-安全解耦）
**陈述**：对任意策略参数 θ，只要执行 `a_t = argmax_{a∈Shield_B} Q_θ`，则实际执行动作始终位于证书可行集内；`Exec_v25` 作为集合**与 θ 无关**，且 `Exec_v25 ⊆ Exec_v24`。

**证明**：`Shield_B` 的每个元素都由 `HPC-G.admits` 判定为可行，故 `a_t ∈ Shield_B ⊆ Shield_∞ ⊆ 精确可行集`。策略只能在 `Shield_B` 内取 argmax，其梯度不进入证书（P46），因此无论 θ 如何训练，都不改变 `HPC-G` 的判定函数与 `Exec_v25` 的集合定义；`Shield_B=∅` 时执行预置 `a_safe`，仍不越界。故集合层面的安全性与 θ 无关，且轻量代理只缩不放（见引理 2）保证 `Exec_v25 ⊆ Exec_v24`。∎

### 引理 2（快速路径的单向保守性）
**陈述**：在 LCS 区间覆盖假设 `P(L ≤ y ≤ U) ≥ 1−α_surr` 下，`LCS.verdict` 返回 `ADMIT` 蕴含 `y ≥ τ` 的概率至少 `1−α_surr`；且当精确判定可用时，快速路径承认的集合是精确可行集的子集。

**证明**：`ADMIT` 条件为 `L ≥ τ`。由覆盖假设，以 ≥1−α_surr 概率 `y ≥ L ≥ τ`，故单次假证率 ≤ α_surr。子集性：`ADMIT` 仅在代理下界越过阈值时触发，而 `Reject` 在 `U<τ`（真值以 ≥1−α_surr 概率不可行），其余一律回退精确——任何快速放行都未使用比精确判定更乐观的信息，故 `Admit_fast ⊆ Admit_exact`（在同一覆盖事件下）。∎

### 引理 3（Time-uniform 覆盖与占用偏移）
**陈述**：若仅用离校准分布的边际 conformal，则在策略诱导的占用分布 `p_π ≠ p_calib` 下存在 `E_{p_π}[1{y∈[L,U]}] < 1−α_surr`；采用重要性加权（密度比 `w`）或 ACI 更新，可将**长期**误判率控制在 `α_surr`（ACI：`(1/T)Σ err_t ≤ α_surr + O(1/√T)` 意义下）。

**证明**：边际覆盖是对 `p_calib` 积分，换到 `p_π` 下的覆盖为 `E_{p_calib}[w·1{cover}]`，当 `w` 无界时该值可低于 1−α；反例（策略集中于校准稀疏的边界带）即构成失效。加权 conformal 以 `w` 重定义分位数可恢复加权边际覆盖；ACI 通过在线更新 `α_t` 使累计不一致率追踪目标，从而在任意（可能对抗的）序列上控制长期错误率。二者均要求占用分布可估或可在线观测（机器人恰好具备遥测）。∎

### 引理 4（Anytime 单调性与 fail-closed）
**陈述**：`A(B)` 关于 B 单调不减，`A(0)=∅`；`ABC.evaluate` 返回 `True` 蕴含所有关键谓词通过；预算耗尽必返回 `False`。

**证明**：`evaluate` 按优先级顺序在预算内累加通过谓词，预算更大时可求值的谓词集合是其超集，故 `A` 单调；`B=0` 时任何 `cost>0` 都无法求值，返回空集；预算耗尽分支直接返回 `False`，故不会出现"未证明却放行"。∎

### 引理 5（量化感知证书的保守子集）
**陈述**：若 `ε_quant` 是 `|s̃−s|` 的 `(1−β)` conformal 上界，且 `ε̃_loc = ε_loc + ε_quant`，则量化证书的 CertBox 至少与全精度 CertBox 一样大，量化可行集 `⊆` 全精度可行集，量化后的定位覆盖仍 ≥1−α（在量化模型的重校准分位数 `q̃_α` 下）。

**证明**：`ε̃_loc = ε_loc + ε_quant ≥ ε_loc`，故膨胀后的 CertBox 只增不减，任何被量化证书判为"无障碍/可行"的结论在全精度下同样成立（对同一空间点，更大的障碍膨胀只会更保守）。覆盖：在量化模型输出上重新估计 `q̃_α` 使残差经验分布的分位数匹配 `1−α`，量化不改变"覆盖是分布性质"这一事实，故覆盖维持（在量化分布的可交换性假设下）。∎

### 定理（HPC-G 的活性-轻量完备性与单调链）
**陈述**：对任意计划/动作 `a`，`HPCG.admits(a,ζ,B)=True` ⟺ `a` 同时满足：(1) v24 的 HPC-F 五条件；(2) 量化感知证书为全精度保守子集；(3) 轻量代理未拒绝（`U≥τ`）；(4) 若落入模糊带则精确验证在预算内通过。且在任意单点/组合失效下 `Exec_v25 ⊆ Exec_v24 ⊆ … ⊆ Exec_v18`。

**证明**：充分性/必要性直接由 `admits` 的分支与连言条件、引理 2–5 得到。单调链：SPO 只在壳内选动作（引理 1，不改集合）；LCS 单向保守（引理 2）；ABC fail-closed（引理 4）；QAC 只保守膨胀（引理 5）；逐项失效均向 v24 更保守方向退化，取交后保持。∎
