# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 1 轮；本轮灵感：「多传感器融合」×「论文创新点」）

> 第 57 轮把证据按模态分账，用"分歧即不确定性下限、一致即新证据类"对账，把安全的赌注从"模型置信"经"证据质量"押到"元先验质量"。但多传感器融合的经典结论指出它隐含三个未检验的前提：**(a) 各模态在观测同一个潜变量**——若任务相关的潜方向根本不在任何传感器的行空间里，融合不会创造信息，跨模态"一致"只是"一致地沉默"，而第 57 轮的 EV-xmodal 会把它误当证据；**(b) 自洽的故障不会被一致性抓到**——卡死/偏置的传感器与自身历史、与同源派生量都自洽，只有解析冗余（奇偶空间）能在承诺前抓住它，事后证伪的 ρ_m 降级太晚；**(c) 时间不是免费的**——把陈旧视觉与新鲜触探当同期观测融合，会把"同一时刻的同一个错误"复制成多次独立观测（时间共谋）。与此同时，项目已积累 138 条定义、144 个 IP，本轮第二个灵感「论文创新点」逼出一个元层问题：**创新点不是 IP 的累积，而是可证伪、可归因、可最小复现的贡献证书**；若归因矩阵的秩小于声称的贡献数，多出来的就是"创新点通胀"。本轮把两个灵感合流为同一件事：**承诺要证据证书，论文主张也要贡献证书——后者是前者在元层的一个实例**。核心命题由"少样本可校准、跨模态可对账、个性化有界的证据说可信"升级为 **"可观测才算证据、自洽故障靠冗余抓、创新点可审计的证据说可信"**。

核心矛盾：
- **H29（可观测性 vs 一致性幻觉）**：一致只有在"可观测且任务相关"的方向上才是证据；但可观测性本身由同一套传感器模型估出，未建模的跨传感器耦合会让不可观测方向看起来可观测——"警察由被监管者自己任命"。
- **H30（在线故障隔离 vs 误报代价）**：奇偶残差能在承诺前抓住自洽故障，但阈值紧则误报导致安全路线被误中止，阈值松则共谋故障漏过；而奇偶模型误差（H 不准）与真实故障在残差上不可区分。
- **H31（创新点 vs 创新点通胀）**：用 novelty/necessity/sufficiency/falsifier 给创新点发证能压缩水分，但归因矩阵来自有限、非平稳基准上的消融，相关指标（同一成功换三种口径）会把 rank(A) 抬高，证书本身也需要证书。

## 0. 直觉与动机

**灵感 1（多传感器融合 → 可观测性门控：一致地沉默不是证据）**
直觉：第 57 轮把"跨模态一致"当成最强证据，但多传感器融合的第一性原理是**融合不创造信息**。如果"承载能力"这个潜方向根本不在任何传感器的行空间里，四个传感器一致地说"看起来没问题"，只是四份"我没看见"，不是四份独立佐证。更危险的是，这种"一致地沉默"在单模态/跨模态体系里都表现为高置信、低分歧，恰好满足 EV-xmodal 的触发条件。修正：把任务风险梯度定义的方向 w 作为"该看哪里"，先算各传感器沿 w 的 Fisher 信息与可观测子空间；只有 w 可观测、且融合相对最佳单传感器的独立信息增益为正，跨模态一致才配叫证据；否则信念沿 w 保持先验/共形宽度，禁止收窄。

**灵感 2（多传感器融合 → 奇偶空间在线故障隔离：自洽故障靠解析冗余抓）**
直觉：一个卡死的激光雷达、一个偏置的 IMU，会与自己过去的历史自洽，也会与同源派生的里程计自洽——第 57 轮的 ρ_m 要等到"事后证伪"才降级，那时已经承诺过了。多传感器 FDI 的经典答案是**解析冗余**：用传感器间的物理约束构造奇偶向量 P（PH=0），无故障时残差应零均值，故障在残差上留下可隔离的签名。它不需要真值、可在承诺前运行；当去故障后仍不可观测时，就降级为保守路径，而不是"大家都说没事所以没事"。

**灵感 3（多传感器融合 → 时间融合视界：防止时间共谋）**
直觉：视觉有延迟、触探是当下的、本体是高频的；把 1.2 秒前的视觉与此刻的触探当作"同期独立观测"融合，等于把同一时刻的同一个错误复制成多次观测。修正：每个传感器有有效性视界 h_m（由漂移率与地形变化率定），只有落在视界内的观测进入当前证据集；陈旧观测只能作为历史证据**降低**承诺，永不增加承诺；用 Kish 有效样本量 n_eff 把"多次观测"折回真实独立度。

**灵感 4（论文创新点 → 贡献证书与归因矩阵：创新点是秩约束不是计数）**
直觉：项目已有 138 条定义、144 个 IP，但论文/竞赛评委不会按 IP 数打分，而会问：哪几条是真正独立的贡献？一个创新点的最小完备描述不是"我们提出了 X"，而是六元组 (claim, novelty, necessity, sufficiency, falsifier, minimal_experiment)：与最近邻工作的可测差异、去掉它必然退化的消融下界、单独它即可最小复现、一个能证伪它的可执行条件、以及区分它与 baseline 的最小实验。把全部机制对全部指标的消融做成归因矩阵 A，**rank(A) 是独立贡献数的上界**；声称的贡献数超过秩，多出来的就是"创新点通胀"（同一成功换三种口径、相关机制被重复计数）。

**灵感 5（合流 → 元层证据经济学：贡献证书就是元层的证据证书）**
直觉：机器人承诺要证据证书（J_p），论文主张要贡献证书（CC）——二者是同一个对象在两个层级：novelty≈新证据类、necessity≈消融下界、sufficiency≈探针预算证书、falsifier≈OOD 门、audit≈日志。于是把 J_p 扩成 J_econ：每份证据带 (来源, 独立信息增益 ΔI, 价格 cost, 可审计性)，承诺当且仅当存在一条"独立来源、总价≤预算、逐项可审计"的证书链。论文创新点因此不是玄学，而是"研究承诺"在元层的可审计实例；反之，若一个机制在机器人层过不了证据门，它在论文层也不该被当成创新点。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（可观测性感知融合 OAF）** 潜变量 θ∈Θ（含 μ,κ,F_bear,ρ_fric 等），风险泛函 Risk(θ)，任务相关方向 w=∇_θRisk(θ̂)/‖∇_θRisk(θ̂)‖。传感器 m 的观测 y_m=H_mθ+n_m，n_m~N(0,R_m)。可观测子空间 O(ℳ)=span{row(H_m):m∈ℳ}；沿 w 的 Fisher 信息 J_m(w)=w^T H_m^T R_m^{-1} H_m w；有效集 ℳ_eff(w)={m:J_m(w)≥J_min}；独立信息增益 ΔI(w)=Σ_{m∈ℳ_eff}J_m(w)−max_m J_m(w)。三规则：(O1) w∉O(ℳ) ⇒ 后验沿 w 不得窄于先验（Var(θ_w|y)≥Var_0(θ_w)），禁止把该方向的一致记为证据；(O2) EV-xmodal 需 w∈O(ℳ) ∧ ΔI(w)>0 ∧ ℳ_eff 中至少两个独立来源；(O3) 不可观测方向只以共形带最坏值进 P_fail。**"一致地沉默"** 定义为 ∃标签 ℓ：所有 m 给出 ℓ 但 w∉O(ℳ)，显式列入禁止证据类。

**定义 140（奇偶空间故障检测与隔离 PS-FDI）** 堆叠观测 y=Hθ+n；奇偶矩阵 P 满足 PH=0（H 的左零空间，秩 p=dim(y)−rank(H)）。残差 r_p=Py，无故障 E[r_p]=0，Cov=P R P^T。故障模型 y=Hθ+Lf+n，L=[L_m]；检测统计量 T=r_p^T(P R P^T)^+r_p，T>χ²_{p,1−α} 报警。隔离 m\*=argmin_m min_f‖r_p−P L_m f‖，得故障签名与排除集 E。模型误差只经 ‖PH‖≤ε_H 进鲁棒阈值；去 E 后若 O(ℳ\E) 不覆盖 w ⇒ 强制保守（禁融合承诺，转绕行/安全停）。隔离时 ρ_m←ρ_min，但**隔离不依赖事后真值**。

**定义 141（时间融合视界 TFH）** 观测 e=(y,t_m,d_m,m)；视界 h_m=min{h_max, c·ε_drift/δ_m, c·ε_terrain/ν_r}（δ_m 漂移率、ν_r 地形变化率）。有效条件 t_now−t_m≤h_m ∧ d_m≤d_max。陈旧权重 s_m(τ)=exp(−λ_mτ)。当前证据集 E_now={e:valid}，历史集 E_hist 只能降低承诺。有效独立样本量 n_eff=(Σ_e s_e)²/Σ_e s_e²（Kish）；校准与置信必须用 n_eff 而非计数 n。**时间共谋** 定义为同一物理事件经不同延迟被计为多次独立观测。

**定义 142（贡献证书 CC 与 NNS 审计）** 贡献证书 c=(claim, novelty, necessity, sufficiency, falsifier, min_exp)。novelty：存在最近邻工作 w\* 与可测差异 Δ（不是"也做了 X"）；necessity：消融机制 i 使某指标退化 ≥δ_abl（下界）；sufficiency：机制 i 单独接 baseline 以预算 ≤B_min 复现 ≥p_rep 的主张；falsifier：可执行条件 F 使 claim∧F 产生可观测矛盾；min_exp：区分 c 与 baseline 的最小实验。NNS 审计通过 ⇔ 四项非空且 falsifier 可执行（有 runnable 定义与判据）。

**定义 143（创新点压缩与归因 ICC）** 贡献映射 g:IP→c；归因矩阵 A∈R^{|metrics|×|mech|}，A_{ji}=∂m_j/∂mech_i（有限差分消融）。先做指标去共线 A_red（QR/主成分截断，消除"同一成功换口径"），再取 r=rank(A_red, tol=ε_rank)。独立贡献数上界 |C_indep|≤r。压缩：若 c_i,c_j 的 falsifier 等价，或 A_red 对应列余弦相似度 >1−ε_cos，则合并。C\*=min{|C|：C 覆盖全部可执行 falsifier 且每条 claim 可归因到唯一机制}；若 |C|>r 判"创新点通胀"，必须合并或补独立实验。

**定义 144（统一证据经济学证书 J_econ）** 证据 e=(src, ΔI, cost, audit, indep_class)。证书链 Ch=(e_1..e_k) 健全 ⇔ 来源两两独立（indep_class 校验）∧ Σcost(e_i)≤B ∧ ∀i audit(e_i)。J_econ=(J_p, O(ℳ), E, TFH_log, CC_log, A_red, r)。元层映射：研究主张=承诺、CC=证据、falsifier=OOD 门、r=独立性校验；因此 J_econ 在对象层与元层同构，论文层不通过的机制不应在机器人层被授权。

## 2. 关键算法伪代码（完整版见产物区）

```python
def observability_gate(M, w):                       # IP-139
    O = observable_subspace(M.sensors)              # span of row(H_m)
    Jm = {m: fisher_along(M.sensors[m], w) for m in M.sensors}
    eff = {m for m, j in Jm.items() if j >= M.J_min}
    if w not in O or not eff:
        return None, 'unobservable'                 # 一致地沉默 != 证据
    gain = sum(Jm[m] for m in eff) - max(Jm.values())
    return eff, ('independent' if gain > 0 else 'redundant_only')

def parity_fdi(M, y, alpha):                        # IP-140
    P = left_null(M.H); rp = P @ y; Sp = P @ M.R @ P.T
    if rp.T @ pinv(Sp) @ rp <= chi2.ppf(1 - alpha, P.shape[0]):
        return M, set(), 'ok'
    m_fault = argmin_m min_f norm(rp - (P @ M.L[m]) * f)   # 签名隔离
    M.E.add(m_fault); M.rho[m_fault] = M.rho_min
    return M, M.E, ('degrade' if not covers(M.H, M.E, w) else 'exclude')

def temporal_gate(obs, t_now):                      # IP-141
    now  = [e for e in obs if t_now - e.t <= H[e.m] and e.d <= D_max]
    hist = [e for e in obs if e not in now]         # 只降承诺，不升承诺
    n_eff = kish_ess([staleness(e, t_now) for e in now])
    return now, hist, n_eff

def contribution_audit(ips, bench):                 # IP-142/143
    C = [cc(ip, bench) for ip in ips]
    A = qr_reduce(ablation_jacobian(bench, mechanisms(ips)))
    r = matrix_rank(A, tol=eps_rank)
    C_star = min_cover(merge_collinear(C, A, eps_cos), all_falsifiers(C))
    return C_star, r, ('ok' if len(C_star) <= r else 'inflation_detected')
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| OAF | O(\|ℳ\|·d_θ²)/区域 | O(\|ℳ\|·d_θ²) | 可观测声明保守、独立增益>0 才计证据 |
| PS-FDI | O(p³+p·dim y)/检查点 | O(dim y·p) | 模型误差 ≤ε_H、隔离后重验可观测性 |
| TFH | O(\|E\|)/检查点 | O(\|E\|) | 视界覆盖变化率、n_eff 校正 |
| CC | O(\|IP\|·\|metrics\|) | O(\|IP\|) | 四项非空、falsifier 可执行 |
| ICC | O(\|mech\|·\|metrics\|·abl + rank) | O(\|metrics\|·\|mech\|) | 去共线后取秩、通胀检测 |
| OCG/PCE× | 继承 PCX + OAF/FDI 增量 | 继承 + A_red | 只增拒绝与探针，不增授权 |

**正确性定理（FOCUS, Fusion-Observability-Contribution Unified Soundness）** 在 A22–A40 之上加 (A41) 可观测模型诚实：H_m,R_m 已知至有界误差，不可观测方向永不作为证据；(A42) FDI：‖PH‖≤ε_H，故障签名对比度 ≥c_min 时检出，误报 ≤α_fdi；(A43) 时钟同步误差 ≤ε_t 且视界覆盖地形变化率；(A44) 贡献审计诚实：指标预注册、消融独立、falsifier 他人可执行。则：

1. **融合健全性**：EV-xmodal 的假证据贡献 ≤δ_xm+ε_H；不可观测方向贡献恒为 0（"一致地沉默"被硬拒）。
2. **故障隔离健全性**：自洽故障在承诺前以 ≥1−β_fdi 被检出/隔离；去故障后不可观测 ⇒ 不产生融合承诺（保守路径）。
3. **时间健全性**：陈旧证据对承诺的贡献 ≤f(h,λ,n_eff)，当前证据有效样本 ≤n_eff。
4. **贡献健全性**：独立贡献数 ≤rank(A_red)；若声称数 > 秩，则以 ≥1−β_rank 判定"创新点通胀"。
5. **部署界**：P_safe ≥ 1−Σ_cp(δ_f+ε_meta+δ_probe+ε_h+δ_xm·1[L1]+δ_ood·α_conf+δ_fdi) − P(模型误差越界) − P(视界失配) − P(护盾/安全停失效)。

关键：**可观测性把"一致"从证据降级为"可观测方向上的一致"；奇偶冗余把"故障"从事后证伪提前到承诺前；时间视界把"多次观测"折回有效样本；贡献证书把"创新点"从计数变成秩约束。**

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 可观测模型 H 本身错（未建模耦合）→ 把不可观测当可观测/把健康当故障 | 高 | 物理不变量锚定（腿运动学/接触约束）+ 外部标定 + 可观测性声明保守（宁可判不可观测） |
| FDI 误报导致安全路线被误中止 | 中高 | 显式 ε_H 预算 + 鲁棒阈值 + 分级（先降权后隔离）+ 误报率进证书 |
| 视界过短导致证据饥饿（liveness） | 中 | 自适应 h_m + 历史证据降级而非丢弃 + 超时保守停 |
| 指标共线抬高 rank，贡献证书自欺 | 中高 | A_red 去共线 + 指标预注册 + falsifier 他人可执行 + 独立复现 |
| 元层证书沦为形式（自己给自己发证） | 中 | 外部审计/盲测 + 最小复现预算 B_min 硬约束 |

## 6. 本轮最大风险

**一句话**：本轮把"什么算证据"的判定权交给一个由同一套传感器估出的可观测模型——若 H 存在未建模的跨传感器耦合，系统会同时犯两个方向相反的错：把"一致地沉默"认证为证据，又把被耦合"解释掉"的健康传感器判为故障；而贡献证书又可能用相关指标的消融在高秩的假象下为这套错误背书，所以必须以物理不变量锚定可观测性、把 FDI 模型误差预算显式化、并要求每条创新 claim 的 falsifier 可由他人执行来兜底。

### IP-139 OAF（可观测性感知融合）

```python
def oaf_gate_and_fuse(M, r, e, w):
    eff, cls = observability_gate(M, w)
    if cls == 'unobservable':
        M.b[r] = keep_prior_width(M.b[r], w)          # O1: 沿 w 不收窄
```

### IP-140 PS-FDI（奇偶空间在线故障检测与隔离）

```python
def parity_fdi(M, y, w, alpha=0.01):
    P = left_null(M.H)                                 # P @ H == 0
    rp = P @ y
    Sp = P @ M.R @ P.T
    T = float(rp.T @ pinv(Sp) @ rp)
    if T <= chi2.ppf(1 - alpha, P.shape[0]):
        return M, 'ok', set()
    # 签名隔离：哪个传感器故障最能解释残差
    scores = {}
    for m, Lm in M.L.items():
        S = P @ Lm
        f_hat = pinv(S) @ rp
        scores[m] = norm(rp - S @ f_hat)
    m_fault = min(scores, key=scores.get)
    M.E.add(m_fault)
    M.rho[m_fault] = M.rho_min
    M.audit.log(('fdi_isolate', m_fault, T, scores))
    if not covers(M.H, M.E, w):                        # 去故障后不可观测
        return M, 'degrade', M.E                       # 禁融合承诺→绕行/停
    return M, 'exclude', M.E
```

### IP-141 TFH（时间融合视界）

```python
def tfh_filter(obs, t_now, w):
    now, hist = [], []
    for e in obs:
        if (t_now - e.t) <= H[e.m] and e.d <= D_max:
            now.append(e)
        else:
            hist.append(e)                             # 只可降低承诺
    s = [exp(-LAM[e.m] * (t_now - e.t)) for e in now]
    n_eff = (sum(s) ** 2) / sum(x * x for x in s) if s else 0.0
    if n_eff < N_MIN:
        return now, hist, n_eff, 'evidence_starved'    # 超时→保守停
    return now, hist, n_eff, 'ok'
```

### IP-142 CC（贡献证书与 NNS 审计）

```python
def make_cc(claim, nearest_work, mechanism, bench):
    return {
        'claim': claim,
        'novelty': measurable_delta(claim, nearest_work),      # Δ 可检验
        'necessity': ablation_lower_bound(mechanism, bench),    # 退化 >= delta_abl
        'sufficiency': minimal_repro(mechanism, bench, B_min),  # >= p_rep
        'falsifier': executable_falsifier(claim),               # 有 runnable 判据
        'min_exp': minimal_discriminating_experiment(claim, bench),
    }

def nns_audit(c):
    return all([c['novelty'], c['necessity'], c['sufficiency'],
                c['falsifier'].runnable, c['min_exp'].valid])
```

### IP-143 ICC（创新点压缩与归因）

```python
def innovation_compress(ips, bench, eps_rank=1e-6, eps_cos=1e-2):
    C = [make_cc(*ip, bench) for ip in ips]
    A = ablation_jacobian(bench, mechanisms(ips))       # 机制×指标
    A_red = qr_reduce(A)                                # 去指标共线
    r = matrix_rank(A_red, tol=eps_rank)                # 独立贡献上界
    groups = union_find(range(len(C)), key=lambda i, j:
                        same_falsifier(C[i], C[j]) or
                        cosine(A_red[:, i], A_red[:, j]) > 1 - eps_cos)
    C_star = min_cover(groups, all_falsifiers(C))
    status = 'ok' if len(C_star) <= r else 'inflation_detected'
    return C_star, r, A_red, status
```

### IP-144 OCG / PCE×ObsCert（可观测认证证据门与探-诺-演×融合）

```python
def obs_certified_gate(c, M, persona, ood_reg, w):
    eff, obs = observability_gate(M, w)
    now, hist, n_eff, tst = tfh_filter(M.obs[c.region], t_now, w)
    if tst != 'ok':
        return ('reject', 'evidence_starved', c)
    M, fdi, E = parity_fdi(M, stack(now), w)
    if fdi == 'degrade':
        return ('reject', 'observability_lost_after_fdi', c)
    if c.ev == 'EV-xmodal':
        ok = (obs == 'independent' and c.level == 'L1'
              and c.modality not in E and agreeing_pair(M.b[c.region], eff))
    elif c.ev == 'EV-probe*':
        ok = c.inf.cls == 'ID' or c.region in ood_reg.certified
    elif c.ev == 'EV-human':
        ok = persona[c.op].auth >= 'A1' and \
             c.corrob >= quarantine_exit(persona[c.op].auth)
    elif c.ev in ('EV-visit', 'EV-margin'):
        ok = round56_checks(c, M)
    else:
        return ('reject', 'no_evidence_class', c)
    if not ok:
        return ('reject', 'evidence_insufficient', c)
    if c.irreversible and c.ev == 'EV-xmodal':
        return ('reject', 'xmodal_on_irreversible', c)
    return ('ok', J_econ(c, O=M.O, E=E, n_eff=n_eff, CC_log=M.cc_log,
                         A_red=M.A_red, r=M.r))
```

### IP-138→PCE×ObsCert（探-诺-演+ 的可观测/故障/时间维度）

```python
def probe_commit_evolve_obs(x0, M, task, budget, consent, personas, w):

            if voi_meta_pessimistic(p, M, inf) < theta_voi:
                break

                    M, cp.region,

           obs_certified_gate(core_contact(cp), M, personas, ood_reg, w)[0] == 'ok':
            sched.append(commit(sigma, select_gait(R))); log.append(tag_evidence_p(sigma, M))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| OAF | O(\|ℳ\|·d_θ²)/区域 | O(\|ℳ\|·d_θ²) | 可观测声明保守、独立增益>0 才计证据（A41） |
| PS-FDI | O(p³+p·dim y)/检查点 | O(dim y·p) | 模型误差 ≤ε_H、隔离后重验可观测性（A42） |
| TFH | O(\|E\|)/检查点 | O(\|E\|) | 视界覆盖变化率、n_eff 校正（A43） |
| CC | O(\|IP\|·\|metrics\|) | O(\|IP\|) | 四项非空、falsifier 可执行（A44） |
| ICC | O(\|mech\|·\|metrics\|·abl+rank) | O(\|metrics\|·\|mech\|) | 去共线后取秩、通胀检测 |
| OCG/PCE× | 继承 PCX + OAF/FDI 增量 | 继承 + A_red | 只增拒绝与探针、不增授权、k_p+k_c 终止 |

**正确性定理（FOCUS, Fusion-Observability-Contribution Unified Soundness）**
在 A22–A40 之上加 **(A41)** 可观测模型诚实：H_m,R_m 已知至有界误差，不可观测方向永不作为证据；**(A42)** FDI：‖PH‖≤ε_H，故障签名对比度 ≥c_min 时检出、误报 ≤α_fdi；**(A43)** 时钟同步误差 ≤ε_t 且视界覆盖地形变化率；**(A44)** 贡献审计诚实：指标预注册、消融独立、falsifier 他人可执行。则：

1. **融合健全性**：EV-xmodal 假证据贡献 ≤δ_xm+ε_H；不可观测方向贡献恒为 0（"一致地沉默"被硬拒）。
2. **故障隔离健全性**：自洽故障在承诺前以 ≥1−β_fdi 检出/隔离；去故障后不可观测 ⇒ 不产生融合承诺。
3. **时间健全性**：陈旧证据贡献 ≤f(h,λ,n_eff)，当前证据有效样本 ≤n_eff。
4. **贡献健全性**：独立贡献数 ≤rank(A_red)；若声称数 > 秩，以 ≥1−β_rank 判"创新点通胀"。
5. **部署界**：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta + δ_probe + ε_h + δ_xm·1[L1] + δ_ood·α_conf + δ_fdi)
             − P(模型误差越界) − P(视界失配) − P(护盾回退失败)
```

关键：**融合不创造信息 → 一致只在可观测方向算证据；自洽故障不会被一致抓到 → 用解析冗余在承诺前隔离；陈旧数据不是独立样本 → 用视界与 n_eff 折回；创新点不是计数 → 用归因秩压缩。**

## 6. 论文主贡献压缩（4 条主 claim + 支撑 IP）

> 归因矩阵的期望结构是**块对角**：理论块（C1）/机制块（C2、C3）/方法学块（C4）。若 C2 与 C3 在指标列上高度共线，则合并为一条"机制"贡献；这是 ICC 的直接应用，也是本轮对"论文创新点"的可执行回答。

| 主 claim | 一句话主张 | 支撑 IP / 定理 | 可执行 falsifier | 最小实验 |
|---|---|---|---|---|
| C1 理论 | 安全 = 每次不可逆承诺都携带一条独立来源、预算受限、可独立审计的证据链（证据经济学） | IP-127~144；CCPS/FOCUS | 找到一条满足证书链却高失效率的承诺路径 | 在证书链审计通过的轨迹上测失效率 |
| C2 机制 | 多传感器融合只在可观测且独立增益>0 的方向上算证据；自洽故障靠奇偶冗余在承诺前隔离；时间视界防共谋 | IP-139/140/141/144；E177–E179 | 注入"一致地沉默"或自洽故障仍被认证为证据 | 一致沉默 + 卡死传感器注入 |
| C3 机制 | 少样本摊销先验 + 跨模态对账 + 个性化单向有界信任，使证据可校准、可对账、可信赖 | IP-133~138；E172–E176 | 元先验盲区 + EV-xmodal 越级导致假承诺 | 语料外新材质 + 授权养成攻击 |
| C4 方法学 | 创新点是可证伪、可归因、可最小复现的贡献证书；独立贡献数 ≤rank(A_red) | IP-142/143；E180 | 给出 |C|>rank(A_red) 却被独立复现的贡献集 | 预注册指标 + 独立消融 + 盲复现 |

**主贡献（one big idea）**：安全与创新共享同一个判据——**不是"我们更准/更多"，而是"每一个不可逆主张都能被独立审计、独立归因、在预算内最小复现"**；C2/C3 是这条判据在机器人对象层的两个机制实例，C4 是它在研究元层的自指实例。

## 7. 本轮最大风险

**一句话**：本轮把"什么算证据"的判定权交给一个由同一套传感器估出的可观测模型——若 H 存在未建模的跨传感器耦合，系统会同时犯两个方向相反的错：把"一致地沉默"认证为证据，又把被耦合"解释掉"的健康传感器判为故障；而贡献证书又可能用相关指标的消融在高秩的假象下为这套错误背书，所以必须以物理不变量锚定可观测性、把 FDI 模型误差预算显式化、并要求每条创新 claim 的 falsifier 可由他人执行来兜底。
