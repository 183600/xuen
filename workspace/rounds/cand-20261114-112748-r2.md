# 第 74 轮（承接第 73 轮「MODGAUGE-RAS 计量契约代数」IP-295~301；灵感循环第 4 轮；本轮灵感：「排行榜」×「竞品分析」）

> R73 把「证据计量」做成可组合契约，解决了换模块 / 加传感器 / 换本体时系统级安全性质的保持。但 R73 只审计了**系统内部**的证据，隐含假设：评价发生在一个中立、静态、无竞争的真空里。真实科研与部署不是这样：
> - **排行榜问题**：论文的主战场往往不是「系统安全吗」，而是「我们的分数有没有排第一」。排行榜把一个高维、异质、带安全约束的系统压成一个可比较的标量次序——但排行榜本身从未被计量：没有不确定度、没有有效域、没有追溯、没有否决语义、没有反作用通道。**一个从未被审计的仪器，被用来给一堆已被严格审计的系统排序**，这是 R71–R73 全部批判的「把测量当真理」的**最外层同型错误**。
> - **竞品分析问题**：comparative claim（「我们优于 X」）比绝对 claim 更脆弱，因为它是**关系性主张**：依赖竞品总体 P、依赖算力/数据/调参预算是否匹配、依赖评测集是否被污染、依赖多重比较与赢家诅咒。竞品不是固定靶子：它会重实现、会针对排行榜优化、会选择性报告。R73 的 CPB 只绑定「组件 → 主张」，却没有绑定「主张 → 比较实验的可比性」。
> - **Goodhart 问题**：排行榜是一个**选择性压力**。一旦排名决定发表/融资/采购，优化压力就反作用于评测本身——指标与真实目标的相关性随优化压力衰减。这正是 R73 ΣREFLEX 的「动作 → 噪声调制」在**评价层**的 L5 反作用：排行榜也有它的 χ_R，只不过过去没人把它写进契约。
>
> 本轮两个灵感正好构成一对：
> - **排行榜** → **LBM（Leaderboard Metrology）/ RANKGAUGE**：把排行榜当成一个**证据模块**，给它写证据契约（总体 P、度量 M、排序规则 δ、有效域 D_L、否决 V、追溯 τ、反作用通道 χ_L、密封引用）；排名不再是标量，而是**带置信集的偏序**（certified dominance poset）。
> - **竞品分析** → **PCC（Pairwise Comparison Certificate）/ CDA（Comparative Dominance Algebra）**：任何「优于」主张必须携带两两比较证书——预算匹配、数据匹配、效果量 + CI、排名分离、污染审计、非补偿安全否决；否则降级为「不可比」。
>
> 核心命题：**不再问「我们排第几」，而问「我们能否证明‘我们优于谁’——一份在排行榜压力、竞品反制、基准污染与分布漂移下仍然成立的比较证书？」** 把 R73 的「计量契约代数」**反射到评价层**，得到 **RANKGAUGE-RAS**——**排行榜计量 × 竞争性主张证书 × 非补偿排名语义**。

## 0. 直觉与动机

**灵感 1（排行榜是仪器，不是真理）**
直觉：排行榜看起来只是一个排序，其实它是一台**测量仪器**的读数：输入是一批系统，输出是一个次序。凡是仪器就有（i）噪声——重跑换种子名次就变；（ii）有效域——换数据集/换算力预算就不适用；（iii）系统偏差——评测集泄露、指标选偏、基准饱和；（iv）反作用——被测量者会针对仪器优化。R71–R73 要求每个证据模块声明不确定度、有效域、追溯、否决与反作用通道；**凭什么排行榜可以豁免？** 排行榜的不确定度不是「分数 ± std」那么简单，而是**名次不确定度**：名次是序统计量（order statistic），服从离散、重尾、强依赖总体的分布；榜首尤其受赢家诅咒（winner's curse）主导。故本轮第一件事，是把排行榜从「外部裁判」降格为「一个必须被审计的证据模块 LBM」。

**灵感 2（竞品分析是因果归因，不是榜单截图）**
直觉：「我们比 baseline X 高 3 个点」这句话里藏着大量未声明的比较条件：同一算力？同数据？同调参预算？同预处理？同评测集？同超参搜索次数？不同则差异的因果归因不成立——分数差可能来自更多 GPU 小时，而不是机制创新。竞品分析的正确形态不是「截一张表」，而是一份**比较实验证书**：把性能差 Δ 分解为 (机制贡献, 预算贡献, 数据贡献, 调参贡献, 噪声贡献)，只有在预算/数据/调参匹配的**可比性域 D_cmp** 内，机制贡献的置信区间才可解释。更麻烦的是竞品会**反制**：重实现你的方法、针对榜单做定向优化、选择性报告对自己有利的种子。故比较必须放在**对抗性总体**下做，而不是假设基线静止善良。

**灵感 3（排名是偏序，不是全序）**
直觉：把异质系统压成一个全序，必然隐含「性能可补偿安全」的假设——多刷几个点就能盖过一次碰撞。这与 R71 的非补偿安全否决、R73 的 VETO 算子直接冲突。正确语义是**认证支配偏序**：i ≻ j 仅在「两两比较证书通过 ∧ 安全否决不触发 ∧ 名次置信集分离」时成立；否则 i ≈ j（统计不可分）或 i ⊥ j（不可比：有效域不相交）。此时 leaderboard 不再是「1,2,3,…」，而是一个**偏序 + 等价类 + Pareto 前沿**。这既更诚实（不制造虚假精度），也更安全（不给补偿开后门）。

**灵感 4（Goodhart 是评价层的 L5 反作用通道）**
直觉：R73 的 ΣREFLEX 把「动作 → 观测模式 → 噪声分布 → 估计 → 动作」统一成模块声明的反作用通道 χ_R，并把层数从系统结构降为模块声明（ψ/z/c/v 四层为当前实例）。排行榜恰好提供一个**最强的外推检验**：在评价层，动作是「提交/优化/重实现」，观测质量是「榜单指标与真实目标的相关性」；优化压力越大，两者越脱钩。这就是 L5 通道 χ_L。若 R73 的抽象是真的，那么新增 L5 应当只需在 LBM 契约里声明 χ_L 并在 ΣREFLEX 预算里加一项 c_opt，**主闭环零改动**。本轮把「排行榜反作用」形式化为**有效度半衰期（validity half-life）**与**优化预算 B_opt**：超过预算，榜单名次自动降级为「未验证」，不得进入任何主张。

**灵感 5（反身性：研究循环自身也是排行榜）**
直觉：本轮是一个「灵感驱动研究循环」，每一轮都要产出一个看起来更好的方案——这本身就是一个**选择压力**，会诱发「概念通胀」（不断换名字、堆 IP、放宽定义以显得进步）。如果不自应用，R74 就会成为它自己批判的对象。故本轮引入 **CCC（Comparative Claim Certificate）** 与**反身审计**：R74 对 R73 的「改进」必须写成可证伪的比较主张（C4/C5），必须声明可比性域，必须允许结论是「与 R73 不可比」而非强行「更好」。

## 1. 形式化定义（增量：定义 383–398）

**定义 383（RANKGAUGE-RAS 总览）** RANKGAUGE-RAS = (MODGAUGE-RAS†, LBM, CDA, CDP, RSU, SEAL-RANK, CCC)。在 R73 五不变式上追加四条：
(vi) **仪器不变式**：任何用于支撑主张的排行榜必须实例化完整 LEC（定义 384），无契约的榜单读数不得进入论证；
(vii) **比较可归因性**：任何「优于」主张必须携带 PCC（定义 386）且落在可比性域 D_cmp（定义 387）内；
(viii) **非补偿排名**：排名语义是偏序 CDP（定义 389），安全否决绝对优先，禁止「用性能补偿安全」；
(ix) **评价反作用闭合**：LBM 必须声明 χ_L 与 B_opt（定义 391），越预算即降级为未验证（定义 396）。

**定义 384（排行榜证据契约 LEC）** LEC = (P, M, δ, 𝒰, D_L, χ_L, τ, V, W, seal_ref)：
- P：**竞品总体**（被比较的系统集合及其采样协议；人口级参数，不是个体属性）；
- M：度量套件（多指标向量，含安全指标，不允许事后挑选）；
- δ：排序规则（允许是偏序/帕累托，而非强制全序）；
- 𝒰：名次不确定度字段（定义 385）；
- D_L：有效域（数据分布、任务族、算力与数据预算区间、训练截止时间）；
- χ_L：**评价反作用通道**——优化/提交压力如何调制指标-目标相关性并收缩 D_L；
- τ：提交追溯链（谁、何时、用何预算、何代码哈希、何随机种子）；
- V：否决指示（污染、泄露、预算不匹配、选择性报告）；
- W：评测成本预算；seal_ref：密封保持集 SEAL-RANK 引用。

**定义 385（名次不确定度与名次置信集）** 对系统 i，其分数 S_i 为随机变量（种子/初始化/数据顺序）。名次 r_i = 1 + #{j ∈ P : S_j > S_i} 是**序统计量**。名次置信集 R_i^{1−α} ⊂ {1,…,|P|} 由总体自助/分层重采样构造，显式建模 P 内两两协方差 Σ_{ij}（共享评测集导致的耦合）。**关键**：r_i 不是 i 的内禀属性，而是 (i, P, D_L, 评测协议) 的联合函数——更换 P 会改变 r_i 的分布。

**定义 386（两两比较证书 PCC）** 对主张「i ≻ j」，PCC(i,j) 成立当且仅当：
(a) **预算匹配**：compute(i,j)、data(i,j)、tuning(i,j) 落入匹配带（定义 395）；
(b) **可比域非空**：D_cmp(i,j) = D_L(i) ∩ D_L(j) ≠ ∅ 且两系统在同一分布上评测；
(c) **效果量 + CI**：Δ = S_i − S_j 的置信下界 > 0（预注册 α），并非仅点估计；
(d) **排名分离**：R_i^{1−α} 与 R_j^{1−α} 不相交（统计上名次可分）；
(e) **污染/泄露审计通过**：SEAL-RANK 无 canary 触发；
(f) **安全否决未触发**：若 j 触发安全 VETO，则 i 无需 Δ>0 即支配（字典序优先）。
任一条件失败 ⇒ 该主张降级为 **INC（不可比）** 或 **EQ（统计不可分）**，不得写成「优于」。

**定义 387（可比性域 D_cmp 与混杂分解）** 定义可比性域 D_cmp = {(i,j) : 预算/数据/调参/预处理在同一匹配带}。对任意比较，把观测性能差分解为
Δ_obs = Δ_mech + Δ_budget + Δ_data + Δ_tuning + Δ_noise，
其中只有 Δ_mech 是「机制创新」的因果贡献。PCC 要求报告 Δ_mech 的可识别区间；若预算项/调参项主导（|Δ_budget|+|Δ_tuning| > |Δ_mech|），则**不得**把差异归因于机制。这是竞品分析的「ceteris paribus 操作化」。

**定义 388（比较支配代数 CDA）** 四算子：
- **DOM**（严格支配）：PCC 全通过且 Δ 下界 > 0；
- **EQ**（统计不可分）：PCC 通过但排名置信集相交；
- **INC**（不可比）：D_cmp = ∅ 或预算不匹配；
- **VETO**（安全否决）：任一系统触发安全否决 ⇒ 安全系统无条件 DOM 之（非补偿）。
CDA 与 R73 的 CCA 同构：DOM 对应 SER+审计，EQ 对应「审计通过但缩窄不合法」，INC 对应有效域交空，VETO 沿用非补偿语义。

**定义 389（认证支配偏序 CDP）** CDP = (P, ≻, ≈, ⊥)：
- i ≻ j ⇔ DOM(i,j) 或 VETO(j) ∧ safe(i)；
- i ≈ j ⇔ EQ(i,j)；i ⊥ j ⇔ INC(i,j)。
**非补偿公理**：若 system 违反安全约束，则对所有安全 system 有 safe ≻ it，**与分数差无关**。CDP 允许并列、允许不可比；发布的是偏序与 Pareto 前沿，不是虚假的全序数字榜。

**定义 390（竞争性威胁面 ℰ_rank）** ℰ_rank = {基准污染/训练-测试泄露，针对性过拟合榜单，预算与调参不对称，选择性报告（只报有利种子/指标），重实现后冒名，评测集投毒，人口选择偏差（只与弱基线比），时间漂移（训练截止后测试）}。防线：SEAL-RANK（定义 392）+ 预算匹配（定义 395）+ 预注册指标 + 多重比较校正（定义 394）+ 单源不定案。

**定义 391（评价反作用通道 χ_L 与有效度半衰期）** χ_L: (优化压力 a) ↦ (指标-目标相关性 ρ(a), 有效域收缩 D_L(a))。设 ρ(a) 为榜单指标与部署潜变量 s 的秩相关，对选择压力 a（提交数/定向优化 FLOPs）单调不增；定义**有效度半衰期** h½ = inf{a : ρ(a) ≤ ρ_0/2}，以及**优化预算** B_opt = min(a_safe, 评测成本上限)。超过 B_opt（或 a > h½）⇒ 名次读数标记「未验证」，LBM 输出 stub（定义 396）。**这是 R73 ΣREFLEX 在 L5 的实例化**：c_opt 计入总反作用预算 B_total。

**定义 392（SEAL-RANK 密封评测集）** 私有保持集 + **canary 项**（唯一可追溯的诱饵样本，用于检出训练数据污染）+ 时间切分（测试项晚于任意参赛方训练截止）+ 提交审计（代码哈希/预算/种子/预处理）。污染检出（canary 命中或时间穿越）⇒ 该提交触发 VETO，名次作废。

**定义 393（排名稳定性 RSU）** 在扰动球 B_ε = {种子、实现、超参、评测子采样、预算 ±δ} 上重算名次；若名次在 B_ε 内不变，称 **ε-稳定**；否则标 **fragile rank**。稳定性证书 = (ε, 观测到的名次翻转率, 最脆弱边界对)。发布名次必须附稳定性等级；fragile top-1 不得作为「SOTA」证据。

**定义 394（多重比较与赢家诅咒校正）** 对总体 P 的 |P| 个系统，家族错误率 FWER ≤ α 由 Holm/Bonferroni 或分层重采样控制；对榜首的向上偏差（winner's curse）用**收缩估计** r̂_i^shrunk 与「留一竞品」重排（leave-one-competitor-out）校正。报告的是校正后名次区间，而非原始 argmax。

**定义 395（预算匹配比较装置 BMC）** 对 (i,j)，匹配带 = {compute ∈ [1/κ, κ]·min，data 同源同规模，tuning 搜索预算同量级，预处理同管线}。κ 预注册（默认 2）。不匹配 ⇒ INC；若无法匹配，则报告**效率调整分数**（性能/FLOP、性能/样本）并显式标注为「跨预算外推，非机制归因」。

**定义 396（L5 预算与排行榜 stub）** 类比 ΣREFLEX：Σ_t c_opt^t ≤ B_opt，其中 c_opt = 定向优化成本。LBM 失效（χ_L 越界 / canary 命中 / D_cmp 空 / |P| < 最小总体）⇒ stub(LBM) =（名次 = ∅，所有比较 = INC，u_rank = ∞）。stub 不产生排名证据，但保留图连通（沿用定义 381 语义）。

**定义 397（比较性主张证书 CCC 与 CPB 扩展）** R73 的 C1–C3 绑定绝对能力主张；本轮追加两条**关系性主张**：
- **C4（排名稳健优越性）**：RANKGAUGE 的 PCC+CDP 在预算匹配、密封评测、竞品总体扰动下，比「点估计榜单排名」给出更高的可复现性与更低的错误宣称率（预注册指标：错误支配率、名次覆盖、复现翻转率）。
- **C5（评价完整性 / 元审计）**：显式计量 χ_L 与 B_opt 的排行榜，比不声明反作用的公开榜单，在同等优化压力下更晚进入「指标-目标脱钩」（预注册指标：有效度半衰期、污染检出率、预算不匹配检出率）。
每个组件必须绑定到 C1–C5 或标记为工程附件；CCC 是「优于」主张的可证伪外壳。

**定义 398（反身研究审计 / 循环级证书）** 把 RANKGAUGE 自应用于本灵感循环：每一轮的「新方案」相对上一轮必须提交一个 CCC（含 D_cmp 与预算匹配：概念复杂度、IP 数、实验数、可证伪主张数须匹配），否则该轮结论只能是「与上轮不可比」，不能自称「更好」。**R74 自身必须通过此审计**：它对 R73 的改进被写成 C4/C5 的可证伪形式，而非修辞上的「升级」。

## 2. 关键算法骨架

```python
# IP-302 LBM：排行榜证据契约（测评域，离线/每次提交）
@dataclass(frozen=True)
class LeaderboardContract:
    population: PopulationSpec                 # P：竞品总体与采样协议
    metrics: Tuple[str, ...]                    # M：预注册多指标（含安全）
    rank_rule: Callable                         # δ：允许偏序/帕累托
    u_fields: Tuple[str, ...]                   # 名次不确定度字段
    domain: Predicate                           # D_L：数据/任务/预算有效域
    chi_L: Callable[[OptimizationPressure], ValidityMod]  # L5 反作用通道
    trace: Callable                             # τ：提交追溯（哈希/预算/种子）
    veto_set: FrozenSet[str]                    # V：污染/泄露/预算不匹配
    opt_budget: float                           # B_opt
    wcet_us: float; seal_ref: str               # 成本预算 + SEAL-RANK

# IP-303 PCC/CDA：两两比较证书与支配代数
def pairwise_certificate(i, j, P, metric_scores, budgets, audit):
    if not audit.budget_matched(i, j):                 # BMC（定义 395）
        return Cmp(i, j, 'INC', reason='BUDGET_MISMATCH')
    if not audit.same_distribution(i, j):              # 可比域非空
        return Cmp(i, j, 'INC', reason='DISJOINT_DOMAIN')
    if audit.contaminated(i) or audit.contaminated(j): # SEAL-RANK
        return Cmp(i, j, 'INC', reason='CONTAMINATION')
    delta, lo, hi = bootstrap_diff(metric_scores[i], metric_scores[j])  # 效果量+CI
    sep = rank_sets_disjoint(i, j, P, metric_scores)   # 名次置信集分离
    if audit.safety_veto(j) and audit.safe(i):         # 非补偿安全否决
        return Cmp(i, j, 'DOM', reason='SAFETY_PRIORITY', delta=delta)
    if delta > 0 and lo > 0 and sep:
        return Cmp(i, j, 'DOM', delta=delta, ci=(lo, hi))
    if sep and delta <= 0:
        return Cmp(i, j, 'EQ', delta=delta)            # 统计不可分
    return Cmp(i, j, 'EQ', delta=delta)

def certified_dominance_poset(P, scores, budgets, audit):
    edges = {}
    for i, j in itertools.combinations(P, 2):          # O(|P|²)
        c1, c2 = pairwise_certificate(i, j, P, scores, budgets, audit), \
                 pairwise_certificate(j, i, P, scores, budgets, audit)
        edges[(i, j)] = resolve(c1, c2)                # 处理循环前先验非补偿
    return Poset(P, edges)                             # 偏序 + 等价类 + Pareto
```

## 3. 推导

**引理 38（名次不确定度不可由分数方差替代）** 名次是序统计量 r_i = 1 + Σ_j 1[S_j > S_i]。即使各 S_i 方差已知且独立，Var(r_i) 仍依赖总体大小 |P| 与相邻系统的间距；当 |P| 增大或相邻间距趋零时，r_i 的方差不可由单个 Var(S_i) 推出。系：**「分数 ± std」不能当作「名次 ± std」**——这是把排行榜当仪器后第一个必须补的计量量。

**引理 39（比较混杂的可识别下界）** 在 Δ_obs = Δ_mech + Δ_budget + Δ_data + Δ_tuning + Δ_noise 分解下，若仅观测 Δ_obs 而无预算/数据/调参记录，则 Δ_mech 的可识别区间宽度 ≥ |Δ_budget| + |Δ_tuning|（不可分离）。系：**预算不匹配时，「机制更好」在信息论上不可识别**，PCC 只能输出 INC。

**引理 40（非补偿排名的单调性）** 设 CDP 按字典序 (安全, 性能)。对安全系统 s 与违反者 v：与分数无关有 s ≻ v。向任意系统追加安全否决只会使其名次不升；撤销否决只会使其不降。⇒ 排名的安全侧单调，符合 R71 非补偿否决。系：**不存在「多刷 3 个点买回一次碰撞」的合法路径**；全序榜的补偿语义违背此引理。

**引理 41（Goodhart 有效度衰减与半衰期存在性）** 设指标 m 与潜变量 s 在某分布上秩相关 ρ_0 > 0，选择压力 a 单调提升被选中系统的 m，且 m 与 s 非完全一致（存在 m 高 s 低的伪相关区域）。在「选择只作用于 m、不作用于 s」的条件下，被选池内 m 与 s 的秩相关 ρ(a) 对 a 单调不增；若存在 a 使 ρ(a) ≤ ρ_0/2，则 h½ 有限。系：**排行榜必须声明优化预算与半衰期，否则名次在压力下会静默失效**——这就是把 Goodhart 定律写成可审计的 L5 通道。

**引理 42（排名稳定性证书的充分条件）** 若对 ∀i, j，两两分数差的波动上界 < 观测间距的 1/2，则在扰动球 B_ε 内 CDP 不变。⇒ 当所有相邻对的 margin > 2(ε_noise + ε_budget) 时，名次 ε-稳定；反之存在翻转。系：**fragile top-1 是统计假象而非能力信号**，SOTA 主张必须先过 RSU。

**定理 30（RANKGAUGE 严格包含 MODGAUGE）** 取 P = {self}（无竞品总体）、δ = 全序退化、χ_L ≡ 平凡（无优化压力）、D_cmp 自动非空、所有 LBM 证据置 stub，则 RANKGAUGE 逐指令退化为 MODGAUGE（R73），再退化为 R72/R71/R68。**安全单调不减，比较能力仅在 LEC 满足时获益。**

**定理 31（认证支配的健全性）** 在 A114–A116（SEAL-RANK 的 canary 与时间切分无漏检、预算匹配带覆盖真实预算、名次置信集的自助校准在总体 P 上覆盖率 ≥ 1−α）下：若 PCC(i,j) = DOM，则「在 D_cmp 与 D_L 上 i 的部署相关表现不劣于 j」以概率 ≥ 1−α 成立；CDP 是一个满足非补偿公理的偏序（可能不完备）。**证明重量落在「D_cmp 是否真的覆盖部署分布」与「canary 是否代表真实污染模式」上。**

**定理 32（排名无免费午餐）** 不存在一条既提升名次又绕过证书的路径：(i) 分数补偿安全被 CDP 字典序禁止（引理 40）；(ii) 预算/数据/调参不匹配使机制归因不可识别（引理 39），只能 INC；(iii) 污染/泄露触发 VETO 使名次作废（定义 392）；(iv) 优化压力超 B_opt 使名次降级为未验证（定义 391/396）。系：**与 R73「组合无免费午餐」同构——排名也无免费午餐；所谓 SOTA 只能是一份证书的结论，不能是一个数字的断言。**

## 6. 本轮最大风险

**一句话**：RANKGAUGE 把「排名可信」的证明负担转移到**外部锚点的存在性**上——如果部署能力 s 与榜单指标 m 之间没有稳定、可观测、非循环的锚点（而 χ_L 的估计本身又依赖 s 的代理），那么无论名次置信集多校准、canary 多灵敏、偏序多严谨，系统都只能在「**当前总体 P + 当前基准 D_L + 当前优化压力 a**」这一自指闭包里证明「我们赢了这场游戏」，却把「**赢得了这场游戏**」悄悄认证成「**真实能力更强**」；审计链越完备，这个自指闭环越显得无懈可击。

次级风险与缓解：
1. **潜在真值不可识别** → 声明 D_cmp 与外部锚点的来源；引入**部署滞后指标**（真实事故率、人工接管率）作为独立锚；无锚时只发布 INC，不发布 SOTA。
2. **χ_L 自举循环**（用一个榜单估有效度，再用有效度解释榜单）→ 有效度必须由**榜单外**的独立测量估计（时间切分 + 部署数据 + 第三方复现），榜单内只做监控。
3. **总体 P 非平稳/对抗性** → 名次证书带时间戳与总体版本号；跨版本名次禁止直接比较；E407 专用检测。
4. **多维指标被压成标量** → δ 强制偏序/帕累托；安全指标独立且字典序优先（引理 40）。
5. **密封评测集成本与饱和** → 滚动密封 + 时间切分 + canary 轮换；饱和时提高任务难度而非放宽指标。
6. **多重比较与赢家诅咒仍被低估** → 强制 FWER 校正 + 收缩 + 留一重排；预注册分析计划。
7. **反身通胀（本循环本身被排行榜化）** → 定义 398 自审计：每轮必须提交 CCC 或诚实声明「不可比」，禁止用「又多了 N 个 IP、N 个定义」冒充进步。

| `h½ = inf{a : ρ(a) ≤ ρ_0/2}` | 有效度半衰期；越界名次标「未验证」 |
| `B_opt` | 优化预算（L5 的 ΣREFLEX 预算项） |
| `SEAL-RANK` | 私有保持集 + canary + 时间切分 + 提交追溯 |
| `RSU(ε)` | 排名稳定性证书（扰动球、翻转率、脆弱边界对） |
| `stub(LBM) = (名次∅, 比较全 INC, u_rank=∞)` | 排行榜降级语义（评测仪器失效） |
| `C4 / C5` | 排名稳健优越性 / 评价完整性（关系性可证伪主张） |

## 2. 形式化定义（要点版）

**定义 383（总览与不变式）** 在 R73 五不变式上追加：仪器不变式（无 LEC 不入论证）、比较可归因性（无 PCC 不称优于）、非补偿排名（CDP 偏序、安全字典序）、评价反作用闭合（χ_L 与 B_opt 必须声明，越界降级）。

**定义 384（LEC）** 见符号表。核心：**排行榜是一个证据模块**，其输出是名次分布与偏序，不是标量真理；其「噪声」是序统计量噪声，其「反作用」是 Goodhart。

**定义 385（名次不确定度）** r_i 是 (i, P, D_L, 评测协议) 的联合函数；名次置信集显式建模总体内两两协方差（共享评测集导致的耦合）。

**定义 386（PCC）** 六条件：预算匹配、D_cmp 非空、效果量 CI 下界 >0、名次置信集分离、SEAL-RANK 无污染、安全否决优先。任一失败 ⇒ 降级 EQ/INC，禁写「优于」。

**定义 387（可比性域与混杂分解）** Δ_obs 分解五项；若预算/调参项主导，则机制归因不可识别（引理 39），只能报 INC 或效率调整分数并标「跨预算外推」。

**定义 388（CDA）** DOM/EQ/INC/VETO 四算子，与 R73 CCA 同构：DOM≈SER+审计、EQ≈审计通过但缩窄不合法、INC≈域交空、VETO≈非补偿。

**定义 389（CDP）** 认证支配偏序；非补偿公理：违反安全者对所有安全系统一律被支配，与分数差无关。发布偏序 + Pareto 前沿，不发布虚假全序。

**定义 390（ℰ_rank）** 八类竞争威胁；防线：SEAL-RANK + 预算匹配 + 预注册指标 + 多重比较校正 + 单源不定案。

**定义 391（χ_L / h½ / B_opt）** 优化压力 a ↦ 相关性衰减与有效域收缩；h½ 有限（引理 41）；超 B_opt 或 a>h½ ⇒ 名次未验证。**这是 R73 ΣREFLEX 的 L5 实例：c_opt 计入 B_total，主闭环零改动。**

**定义 392（SEAL-RANK）** canary 命中/时间穿越/泄露哈希/预算不符 ⇒ VETO，名次作废。

**定义 393（RSU）** ε-稳定 vs fragile rank；fragile top-1 不得作为 SOTA 证据。

**定义 394（多重比较/赢家诅咒）** FWER 控制 + 收缩估计 + 留一竞品重排；报告校正后名次区间。

**定义 395（BMC 预算匹配）** 匹配带 κ；不匹配 ⇒ INC；无法匹配 ⇒ 效率调整分数 + 外推标注。

**定义 396（L5 预算与 stub）** Σ_t c_opt^t ≤ B_opt；仪器失效 ⇒ stub(LBM)（名次∅、比较全 INC、u_rank=∞），保留图连通。

**定义 397（CCC / CPB†）** C1–C3 为绝对主张；C4（排名稳健优越性）、C5（评价完整性）为关系性主张；组件须绑定 C1–C5 或标附录。

**定义 398（反身研究审计）** 每轮对上一轮的「改进」须提交 CCC（概念复杂度/IP/实验/可证伪主张须匹配），否则结论只能是「不可比」。**R74 自身受此约束。**

## 3. 关键算法伪代码

```python
# IP-302 LBM：排行榜证据契约
@dataclass(frozen=True)
class LeaderboardContract:
    population: PopulationSpec                 # P：竞品总体与采样协议
    metrics: Tuple[str, ...]                    # M：预注册多指标（含安全）
    rank_rule: Callable                         # δ：允许偏序/帕累托
    u_fields: Tuple[str, ...]                   # 名次不确定度字段
    domain: Predicate                           # D_L
    chi_L: Callable[[OptimizationPressure], ValidityMod]  # L5 反作用通道
    trace: Callable                             # τ：哈希/预算/种子/预处理
    veto_set: FrozenSet[str]                    # V
    opt_budget: float                           # B_opt
    wcet_us: float; seal_ref: str

# IP-303 PCC/CDA：两两比较证书与支配代数
def pairwise_certificate(i, j, P, scores, budgets, audit):
    if not audit.budget_matched(i, j): return Cmp(i, j, 'INC', 'BUDGET')
    if not audit.same_distribution(i, j): return Cmp(i, j, 'INC', 'DOMAIN')
    if audit.contaminated(i) or audit.contaminated(j): return Cmp(i, j, 'INC', 'CONTAM')
    delta, lo, hi = bootstrap_diff(scores[i], scores[j])
    sep = rank_sets_disjoint(i, j, P, scores)
    if audit.safety_veto(j) and audit.safe(i):        # 非补偿安全否决
        return Cmp(i, j, 'DOM', 'SAFETY', delta)
    if delta > 0 and lo > 0 and sep: return Cmp(i, j, 'DOM', delta=delta, ci=(lo, hi))
    if sep and delta <= 0: return Cmp(i, j, 'EQ', delta=delta)
    return Cmp(i, j, 'EQ', delta=delta)

def certified_dominance_poset(P, scores, budgets, audit):
    edges = {(i, j): resolve(pairwise_certificate(i, j, P, scores, budgets, audit),
                             pairwise_certificate(j, i, P, scores, budgets, audit))
             for i, j in itertools.combinations(P, 2)}
    return Poset(P, edges)                             # 偏序 + 等价类 + Pareto

# IP-304 RSU：排名稳定性
def rank_stability(P, scores, epsilon):
    flips, fragile, ball = {}, [], perturbation_ball(epsilon)
    for seed in ball:
        r = rank_with(P, resample(scores, seed))
        for i in P: flips[i] = flips.get(i, 0) + (r[i] != base_rank[i])
    fragile = [i for i in P if flips[i] / len(ball) > TAU_FLIP]
    return Stability(cert=(epsilon, flips, fragile))

# IP-305 chi_L：Goodhart 有效度半衰期 + L5 预算
def validity_half_life(P, pressure_schedule, latent_proxy):
    rho = [rank_corr(metric(P, a), latent_proxy(P, a)) for a in pressure_schedule]
    return first_a_below(rho, rho[0] / 2)              # h½

def meta_reflex_step(a, lbm, budget):
    chi = lbm.chi_L(a); c_opt = chi.optimization_cost(a)
    if budget.spent + c_opt > lbm.opt_budget or a > lbm.half_life:
        return None, stub(lbm)                         # 越预算 ⇒ 名次未验证
    return chi, budget.spent + c_opt

# IP-306 SEAL-RANK：密封评测
def seal_rank_audit(submission, sealed):
    if submission.code_hash in sealed.leaked_hashes: return VETO('LEAK')
    if submission.train_cutoff >= sealed.test_time: return VETO('TIME_TRAVEL')
    if any(canary_hit(submission.model, c) for c in sealed.canaries): return VETO('CONTAM')
    if not budget_matched(submission, sealed.budget): return VETO('BUDGET')
    return PASS

# IP-307 CDP 发布：偏序榜（非补偿、可不可比、带稳定性）
def publish_leaderboard(P, scores, budgets, audit, stability):
    poset = certified_dominance_poset(P, scores, budgets, audit)
    front = poset.pareto_front(safety_lexicographic=True)
    return LeaderboardView(front=front, relations=poset.relations,
                           stability=stability, unverified=stub_set,
                           note='no scalar total order; INC/EQ preserved')

# IP-308 CCC：比较性主张证书（CPB 扩展）
CLAIM_LEDGER = {
 'C1': dict(kind='absolute', mods=['DPEM','DMEM'], bench='MB1'),
 'C2': dict(kind='absolute', mods=['SIGMAREFLEX','PVOP'], bench='MB2'),
 'C3': dict(kind='absolute', mods=['MMS','CCA','J_MOD'], bench='MB3'),
 'C4': dict(kind='comparative', mods=['LBM','CDA','CDP','RSU'],
            requires=['PCC','D_cmp','SEAL-RANK','MULTI_CORR']),
 'C5': dict(kind='comparative', mods=['chi_L','SEAL-RANK'],
            requires=['validity_half_life','contamination_rate']),
}
def submit_claim(claim, evidence):
    if claim.name in ('C4', 'C5'):
        assert all(k in evidence for k in CLAIM_LEDGER[claim.name]['requires'])
        assert evidence['comparison'] in ('DOM', 'EQ', 'INC')   # 允许 INC，禁伪造 DOM
    return ClaimCertificate(claim, evidence)
```

## 4. 推导

**引理 38（名次不确定度不可由分数方差替代）** r_i 为序统计量；Var(r_i) 依赖 |P| 与相邻间距，不能由单点 Var(S_i) 推出。系：**「分数 ± std」≠「名次 ± std」。**

**引理 39（比较混杂可识别下界）** 仅观测 Δ_obs 而无预算/数据/调参记录时，Δ_mech 可识别区间宽度 ≥ |Δ_budget|+|Δ_tuning|。系：**预算不匹配时机制归因在信息论上不可识别，只能 INC。**

**引理 40（非补偿排名单调性）** 字典序 (安全, 性能) 下，安全系统无条件支配违反者；追加安全否决只使名次不升、撤销只使名次不降。系：**不存在「刷分买回碰撞」的合法补偿路径。**

**引理 41（Goodhart 半衰期存在性）** 选择压力只作用于 m、s 不随选择改变且存在 m 高 s 低的伪相关区域 ⇒ 被选池内 ρ(a) 单调不增；存在 a 使 ρ(a) ≤ ρ_0/2 时 h½ 有限。系：**排行榜必须声明 B_opt 与 h½，否则名次静默失效。**

**引理 42（稳定性充分条件）** 相邻对 margin > 2(ε_noise+ε_budget) ⇒ CDP 在 B_ε 内不变；否则存在翻转。系：**fragile top-1 是统计假象。**

**定理 30（RANKGAUGE 严格包含 MODGAUGE）** P={self}、δ 退化为全序、χ_L≡平凡、LBM 置 stub 时逐指令等于 R73，再退化等于 R72/R71/R68。**安全单调不减；比较能力仅在 LEC 满足时获益。**

**定理 31（认证支配健全性）** 在 A114–A116（canary/时间切分无漏检、匹配带覆盖真实预算、名次置信集覆盖 ≥1−α）下，PCC=DOM ⇒ 在 D_cmp∧D_L 上 i 不劣于 j（概率 ≥1−α）；CDP 为满足非补偿公理的偏序（可不完备）。**证明重量落在「D_cmp 是否覆盖部署分布」与「canary 是否代表真实污染模式」上。**

**定理 32（排名无免费午餐）** 无路径既提升名次又绕过证书：分数补偿安全被字典序禁止；预算不匹配使归因不可识别；污染触发 VETO；超 B_opt 降级未验证。系：**与 R73「组合无免费午餐」同构——SOTA 只能是证书的结论。**

## 7. 本轮最大风险

**一句话**：RANKGAUGE 把「排名可信」的证明负担转移到**外部锚点的存在性**上——如果部署能力 s 与榜单指标 m 之间没有稳定、可观测、非循环的锚点（而 χ_L 估计本身又依赖 s 的代理），那么无论名次置信集多校准、canary 多灵敏、偏序多严谨，系统都只能在「**当前总体 P + 当前基准 D_L + 当前优化压力 a**」这一自指闭包里证明「我们赢了这场游戏」，却把「**赢得了游戏**」悄悄认证成「**真实能力更强**」；审计链越完备，这个自指闭环越显得无懈可击。

次级风险与缓解：
1. **潜在真值不可识别** → 声明 D_cmp 与锚点来源；用部署滞后指标（事故率、人工接管率）作独立锚；无锚只发 INC。
2. **χ_L 自举循环** → 有效度由榜单外独立测量估计（时间切分 + 部署数据 + 第三方复现），榜单内只做监控。
3. **总体 P 非平稳/对抗** → 名次证书带时间戳与总体版本号；跨版本禁直接比较；E407 检测。
4. **多指标被压成标量** → δ 强制偏序/帕累托；安全指标字典序优先。
5. **密封集成本与饱和** → 滚动密封 + 时间切分 + canary 轮换；饱和时提高任务难度而非放宽指标。
6. **赢家诅咒被低估** → 强制 FWER + 收缩 + 留一重排 + 预注册分析计划。
7. **反身通胀（循环被排行榜化）** → 定义 398 自审计：每轮提交 CCC 或声明「不可比」，禁止用「多 N 个 IP/定义」冒充进步。
