# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；灵感循环新循环第 2 轮；本轮灵感：「双臂协调」×「扩散策略」）

> R69 让系统学会了「问」，但它把「消歧」几乎完全押在**外部回答者**身上：看/问/触都只是向人或环境索取一条似然，再用「k 个正交证据源一致」压住投毒。这个抽象有两个未言明的假设：
> - **模态是终态样本给的**：R69 的流匹配只跑 1–2 步，K 个终态样本一聚类就得到模态。可「模态」是否真实，取决于它是不是生成过程里的**稳定吸引盆**；一个只在某一步采样中偶然出现的簇，和真模态在终态看起来可以一模一样。R69 自己承认的最大风险正是「流模型幻觉出不存在的模态，系统自信地追问一个幻影」。
> - **验证者一定是别人**：R69 的独立证据来自人的回答或另一模态传感器的被动读数。可人会累、会撒谎、会共谋；而机器人自己身上其实还有一台**从未被当作仪器使用的差分测量装置**——两条臂。
>
> 本轮两个灵感正好补上这两块：
> - **双臂协调**不是「两条独立胳膊各干各的」，而是**共享同一物体/同一闭环运动链的一对差分执行器**：一臂锚定并测量，另一臂施加已知扰动，两条臂的相对位姿、力平衡、闭环残差构成一个**共模误差可被抵消的物理实验台**。它能把「问别人」变成「问物理」。
> - **扩散策略**不是把 R69 的 1–2 步流匹配换成更多步，而是提供了一个**噪声层级轴**：反向去噪过程中，粒子的分裂发生在不同噪声层；真实模态是跨多个噪声层都稳定的吸引盆，幻影模态往往只在薄薄一层出现。歧义由此从一个「终态样本集合」升级为一棵**分岔树**——它同时告诉我们「有几种可能」和「该先解决哪一层决策」。
>
> 核心命题：**把 epistemic 消歧从「向人求证」升级为「用双臂做一次预注册的物理实验」：扩散策略给出跨噪声层稳定的模态分岔树，持久性过滤 + 耦合可行域过滤先剔除幻影；剩余的持久模态之间，由一臂扰动、一臂见证，设计使物理 VoI 最大的对照实验；实验前把各模态的预测观测冻结哈希，实验后只用共模抑制后的差分证据做证伪。R69 的「问人」保留为无可行实验、差分可辨识秩为零、或预注册失效时的边界。** 命名 **DUET-RAS**（Dual-arm Uncertainty-Elucidating Test）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我能不能让世界自己回答，并且不把自己骗过去**」——双臂不是冗余的执行器，而是一台会做对照实验的仪器。

## 0. 直觉与动机

**灵感 1（双臂协调 → 冗余不是两条胳膊，而是一台差分仪器）**
直觉：单臂拿不准一个杯子是空是满、一个抽屉是松是紧、一个盒子是硬是软时，最自然的动作不是继续盯着看，而是「一手扶住、一手敲一下/推一下/提一下」。双臂协调的真正价值不只是负载分摊或工作空间互补，而是它天然提供**受控实验的三要素**：一个**锚定/见证臂**（保持抓取、测量基座与响应）、一个**扰动臂**（施加已知方向与幅值的力/位移）、以及两者之间**共享的闭环约束**（同一个物体、同一条运动链）。物体的隐藏属性（质量、刚度、摩擦、间隙、是否可动）会在「扰动—响应」中显形；而两条臂的相对测量可以把基座标定误差、相机外参误差、物体模型偏置等**共模误差**抵消掉。双臂因此不是「两个独立投票者」，而是一台**共模抑制的差分测量仪**。
但这里有个反直觉的严格点：两条臂装在同一个基座上、共享同一套标定和相机，它们的误差高度相关。**「两臂都说是 A」并不等于两个独立证据**——如果它们共享同一个标定错误，它们会自信地一起错。所以双臂证据必须经过共模投影，只有两臂之间的差分分量才算独立信息；这一点会成为本轮最重要的安全边界之一。

**灵感 2（扩散策略 → 歧义有「分辨率」，而不是一袋样本）**
直觉：R69 的流匹配从噪声一步跳到动作，K 个终态样本聚类得到模态；但「模态稳不稳」没有定义。扩散策略的反向过程天然有一条**噪声层级轴**：高噪声时所有粒子还挤在粗粒度先验里，某个噪声层上第一次分叉，决定了「去左边还是右边」；更低噪声层上的再次分叉，才决定「用左手还是右手、抓杯柄还是杯身」。真实模态对应**跨多层稳定的吸引盆**（basin），幻影模态则可能只在某一薄层出现、下一层就塌掉。把每个噪声层的粒子聚类、跨层匹配，就得到一棵**分岔树**：每个内部节点是一次决策，节点的分叉深度给出「这是粗决策还是细决策」，叶子的持久性给出「这个模态有多真」。
这把 R69 的 `U_epi = H_mode · g(Δ_min)` 从一个静态标量，升级成**带层次的、可被物理实验逐层证伪的对象**：先解决高深度（粗）分叉，再解决低深度（细）分叉；每一层都可以问「值不值得为它做一次实验」。

**灵感 3（合流 → 把「谁问」与「谁判」分开）**
直觉：R69 最深的隐患不是「模态可能错」，而是**同一个模型既负责产生模态、又负责判断实验是否支持模态**。一个自洽的幻觉完全可以在它自己设计的实验里「预测」出自己想要的观测，然后把自己盖章为「已验证」。R70 的合流给出一个制度性解法：**分权 + 预注册**。扩散策略/任务策略负责「提出候选模态和候选实验」，一个**冻结的、参数独立的物理预测器**负责「在每个模态下预测这次实验会看到什么」，预测在执行前哈希冻结；执行后只允许用**共模抑制后的差分观测**去证伪。选择器和预测器不共享可训练参数，预测不可事后修改。这样，「实验支持了模态」不再是自我指认，而是一次有成本的、可审计的、可能失败的对外承诺。
这套机制也直接回答 R69 的最大风险：**幻影模态可以被物理实验证伪，而不是被同一个模型确认**；人可以被欺骗，但闭环运动链的力—位移响应不会配合幻觉演戏。当然，物理模型本身也可能错——这是本轮新的最大风险，后面会正面处理。

**灵感 4（严格包含 → 物理实验只是 R69 之上的一层，不是替代）**
直觉：R70 必须像 R69 包含 R68 那样包含 R69。把「没有分叉（只有一个持久模态）」「没有可行的信息探针」「差分可辨识秩为零（歧义是纯共模的）」「共模/观察者效应校验失败」「预注册被破坏」这五种情况定义为 R70 的边界；任一成立时，DUET 逐指令退化为 FLUID-RAS：该问人问人，该保守保守。双臂实验只在**能提供独立差分信息**时启用；安全侧单调不降，效率侧才获得「物理 resolution bonus」。

**灵感 5（新的攻击面 → 物理实验也会骗人，只是骗法不同）**
直觉：一旦系统会「做实验」，新的失效模式就出现了：
- **共模盲区**：两臂共享标定误差时，它们会一致地看到一个错误的世界；差分通道秩亏，物理实验对这类参数**零信息**。
- **观察者效应**：探针本身改变了物体状态（压陷、划伤、让抽屉滑开），测到的响应里混入了「自己推出来的偏置」；单次探针无法区分「物体软」与「探针歪」。
- **模型有界证伪**：预注册只能保证「不自我欺骗」，不能保证「物理模型为真」；一次统计显著、流程合规的实验，仍可能在一个错误模型内确认一个错误模态。
- **角色不对称与单臂退化**：一臂标定漂移、负载受限或关节过热时，差分测量会被单臂误差污染；「锚定臂」若失稳，实验本身就不安全。
因此本轮必须同时交付：持久性幻影门、耦合可行域硬过滤、共模抑制与秩检查、反对称/空探针对照、分权预注册、锚定臂安全不变式、以及「单次实验不得单独定案」的证据纪律。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（DUET-RAS 总览）** DUET-RAS = (BDP, TBD, CCF, CAP, PVE, PRC, CMR, OEC, DAR, RAS-WM‡)。三不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **预注册与分权**：实验选择器与结果预测器不共享可训练参数；任何实验的各模态预测观测必须在执行前冻结并哈希；执行中不得修改预测或选择规则；违反即实验作废；
(iii) **共模纪律**：跨臂证据只有经过共模投影后的差分分量才可计入独立证据；共模一致不得降低 `U_epi`；差分可辨识秩为零时禁止用物理实验定案，安全侧始终保留 R69 的 `λ_floor` 兜底。

**定义 311（双臂扩散策略 BDP）** 增广任务动作块 `ξ = (ξ_L, ξ_R) ∈ 𝒜_L × 𝒜_R`，观测 `o_t`，角色令牌 `r_t ∈ {anchor_L, anchor_R, symmetric}`。前向加噪 `x_s = √ᾱ_s x_0 + √(1−ᾱ_s) ε`，`x_0 = ξ`，噪声层 `s = 1, …, J`（`s=J` 为纯噪声，`s=0` 为动作）。训练 `L_DDPM = E‖ε − ε_θ(x_s, s, o_t, r_t)‖²`。反向采样从 `s=J` 到 `0`，每层保留 `K` 条粒子；条件编码复用 R68/R69 的 MTM trunk 得到 `z_t`。训练/推理均可加耦合约束正则，但**硬可行性由定义 314 单独过滤**，避免投影把真实多模态抹平。

**定义 312（去噪分岔树 TBD）** 在第 `j` 层把 `K` 条粒子按动作空间距离阈值 `τ_j` 聚类，得簇 `{C_{j,k}}`、质量 `ŵ_{j,k}`、原型 `x̄_{j,k}`、协方差 `Σ_{j,k}`。用 Hungarian/最优传输把第 `j` 层簇与第 `j−1` 层簇匹配；一个父簇在下一层分裂为 ≥2 个子簇，记为一个**分岔节点** `v`。所有节点构成树 `T`，根在 `s=J`，叶在 `s=0`。定义：
- **分岔深度** `d(v) = s_v`（越大表示越早/越粗的决策）；
- **模态持久性** `π_m = (1/J) Σ_j 1[叶 m 在层 j 有匹配簇，且 ŵ_{j,m} ≥ w_min、‖x̄_{j,m} − x̄_{j+1,m}‖ ≤ δ_j]`；
- **幻影质量** `Φ = Σ_{m: π_m < π_min} ŵ_m`。
持久性不是「模型置信度」，而是「跨噪声层吸引盆稳定性」；这是与 R69 终态聚类最本质的区别。

**定义 313（持久性过滤后的分层不确定性）** 持久模态集 `M_p = {m : π_m ≥ π_min}`，权重 `p_m ∝ ŵ_m π_m`，`Σ_m p_m = 1`。定义
`U_ale = Σ_{m∈M_p} p_m tr(Σ_m)`（模态内不可约）；`H = −Σ p_m log p_m`；`π̄ = Σ p_m π_m`；`U_epi = H · g(Δ_min) · π̄`（模态间可约，且按持久性折减）。
同时保留分层结构：对每个内部节点 `v`（`d(v)` 高于阈值），令 `H_v` 为其子节点质量的熵，得到按深度排序的待消解列表 `L = {(v, H_v, d(v))}`。标量 `U_epi` 进 R69 的两级退避；列表 `L` 进 CAP 的粗到细实验排序。
**幻影门**：若 `Φ > τ_Φ`，判定模态分布不可信，禁用物理实验并直接走 R69 兜底（对应 R69 的 MCG，但门控对象从「权重校准」升级为「跨层持久性」）。

**定义 314（双臂耦合可行域 CCF）** 耦合约束 `C(ξ_L, ξ_R; o_t) = (C_chain, C_coll, C_joint, C_sync, C_force) ≤ 0`，其中 `C_chain` 为共享物体闭环/相对位姿约束，`C_coll` 为双臂自碰撞，`C_sync` 为时序同步，`C_force` 为力闭合/夹持稳定。可行域 `ℱ_t = {ξ : C ≤ 0}`，耦合残差 `r_cpl(ξ) = dist(ξ, ℱ_t)`（用 QP 投影计算）。模态 `m` 可行当且仅当 `E_{ξ~m}[r_cpl] ≤ ε_cpl` 且 `max r_cpl ≤ ε_cpl^max`。
CCF 是**硬否决**：不可行模态在进入后验前直接剔除，而不是降权；因为一个物理上无法由两条臂同时实现的模态，无论统计上多「真」，都不可能是当前身体能执行的解。

**定义 315（跨臂探针 CAP）** 信息动作 `g = (ρ, u_L, u_R, T_g, M_obs)`：`ρ` 为角色分配（anchor-probe / symmetric / handoff），`u_L, u_R` 为两臂的探针指令（推/拉/拧/敲/释放/保持），`T_g` 为有界实验时长，`M_obs` 为观测协议（相对位姿、力/力矩、视觉、触觉）。候选集 `G(M_p, o_t)` 由角色条件化的 BDP 加探针令牌生成，或由脚本化原语构造。对每个候选 `g` 与模态 `m`，一个**冻结的物理预测器** `h_ψ`（与 BDP/策略不共享可训练参数）给出 `p(y | g, m, o_t)`；预测的对象是**共模投影后的观测** `y`（定义 318），不是原始双腕读数。
**锚定不变式**：整个 `T_g` 内，锚定臂保持在已认证的安全构型/力闭合中，且能在 `T_abort` 内中止探针；探针臂始终位于相对锚定臂的认证包络内。实验是快控制环之外的**慢时间尺度有界动作**，不得把 1 kHz 安全环拖入探针逻辑。

**定义 316（物理 VoI 与实验选择 PVE）** 局部线性响应模型 `y = P_cm (J_m θ + b_m(g)) + e`，`θ` 为待消歧的物体/接触参数，`P_cm` 为共模投影（定义 318）。信息增益
`VoI_phys(g) = H(M|o) − E_{y~p(y|g,o)}[H(M|o,y)]`；高斯近似下 `VoI_phys(g) = ½ log det(I + Σ_θ J_eff^T Σ_e^{-1} J_eff)`，`J_eff = P_cm J`。
成本 `c(g) = c_risk(g) + c_time(g) + c_wear(g) + c_anchor(g)`。选择
`g* = argmax_{g∈G} [VoI_phys(g) − c(g)]`，s.t. 耦合 C-RAS-WM 认证、锚定不变式、预算未超、可预注册。
若 `max[VoI_phys − c] ≤ 0`：不做物理实验，走 R69 兜底。若 `L` 中尚有多个节点，按 `d(v)` 从大到小、`H_v` 从大到小排序，先做**最粗且最有信息**的那一层——这是「先决定走哪条走廊，再决定用哪只手」的粗到细原则。

**定义 317（预注册证伪证书 PRC）** 执行前计算承诺
`H = Hash(g*, {p(y|g*,m,o_t)}_{m∈M_p}, predictor_version, calibration_snapshot, t_commit)`，
写入审计日志并冻结。执行后观测 `y`，计算 Bayes 因子 `BF_{m,m'} = p(y|g*,m)/p(y|g*,m')`；模态 `m` 被证伪若 `BF_{m,m_ref} < 1/τ_BF`。证伪集 `F` 用于剪枝，不用于把某模态「确认到 1」。
**证据纪律**：单次实验只提供似然，不得单独定案；需两次正交实验（例如 `+δ` 与 `−δ` 的反对称对，或两个不同观测模态）方向一致，或 VoI 增益超过高置信阈值且严重度低于 `s_crit`，才允许把该模态提升为「已消解」。若 `H` 校验失败、预测在执行后被改动、或实验选择器在提交后换版本，则本次实验作废，`U_epi` 保持未消解。

**定义 318（共模抑制证据 CMR）** 双腕观测 `y = [y_L; y_R]`，共享误差 `e_cm` 的已知敏感子空间为 `range(S_cm)`。投影 `P_cm = I − S_cm(S_cm^T S_cm)^+ S_cm^T`，差分观测 `y_eff = P_cm y`，`J_eff = P_cm J`，**差分可辨识秩** `k_diff = rank(J_eff)`。只有 `y_eff` 进入 BF 与 VoI；共模一致不算独立证据。
**共模告警**：若 `(I − P_cm) y` 持续漂移而 `y_eff` 稳定，判定为共享标定/基座/相机误差，而非物体属性变化；此时不更新物体后验，转 R68 标定流程。若 `k_diff = 0`，物理实验对当前歧义零信息，禁止用它定案。

**定义 319（观察者效应控制 OEC）** 对同一隐藏参数使用反对称探针对 `g^+`、`g^-`（扰动 `+δ`、`−δ`）与空探针 `g^0`（零扰动）。局部响应展开 `y(δ) = y_0 + uδ + hδ² + O(δ³)`，其中奇部 `u` 是物体响应，偶部 `h` 是探针自身偏置/观察者效应。定义 `y_A = (y(+δ) − y(−δ))/2`，`y_B = (y(+δ) + y(−δ))/2 − y(0)`。OEC 有效当 `‖y_B‖ ≤ c_o δ²`（且滞回/塑性检验通过）。无效时该实验不得用于确认，只能降 δ 重试或走 R69 兜底。**单次 `+δ` 探针不足以区分「物体软」与「探针歪」。**

**定义 320（双臂角色与锚定安全 DAR）** 角色分配 `ρ` 必须满足：锚定臂在认证安全集 `S_safe` 内；探针臂位于相对锚定臂的认证包络 `E_probe(ρ)` 内；角色交换必须经过「双臂同时处于 `S_safe`」的认证交接瞬间；锚定臂在 `T_abort` 内可独立中止探针。任何时刻至少一臂处于可中止的安全构型。定义**角色对称性审计**：长期统计两臂的探针/锚定比例、跟踪残差、力残差；若显著不对称，触发单臂退化检查（标定漂移、关节过热、负载受限）。

**定义 321（分层证据纪律）** 证据源 `E1`：BDP/TBD 的统计模态证据；`E2`：CMR 投影后的跨臂物理实验证据（预测器独立、预注册）；`E3`：R69 的人类/外部回答。正交性以共享潜变量上的误差交叉协方差度量；`E2` 还要求 `k_diff ≥ k_req`。对严重度 `s ≥ s_crit` 的 claim，必须至少 `E1+E2` 或 `E2+E3` 方向一致，且任何单源权重被信任天花板截断；否则 `U_epi` 视为未消解，走 R69 兜底。**物理证据不是自动更强**：只有 CMR 与 OEC 都通过时，它才算独立证据。

**定义 322（参与式审计 VQAuditor-D）** 审计对象新增：预注册哈希是否完整、选择器/预测器是否分权、CMR 投影是否用了正确敏感子空间、OEC 是否通过、锚定不变式是否全程成立、幻影门是否触发、探针是否超出预算/力包络、角色是否长期不对称。结论回灌 AuditBuf，成为下一轮 CAP 的成本先验与力上限。

**定义 323（干扰集 ℰ_DUET）** `ℰ_DUET = ℰ_FLUID × ℰ_phantom × ℰ_cm × ℰ_prereg × ℰ_observer × ℰ_coupling × ℰ_role`：持久幻影模态、共模错觉（双腕共享标定错误）、预注册篡改/事后合理化、观察者效应/塑性变形、探针诱发状态改变、闭环约束求解失败、单臂退化/角色不对称、扩散模式坍缩、随机采样发散、以及「选择器与预测器共享数据/参数」导致的自证实验。

**定义 324（证书 J_DUET）** `J_DUET = (J_FLUID, persistence_ECE, phantom_mass Φ, bifurcation_tree_hash, coupling_residual_p95, prereg_hash, bf_p95, k_diff, oec_bias, anchor_safety, duet_ver)`。Valid ⇔ `Valid(J_FLUID)` ∧ `persistence_ECE ≤ τ_p` ∧ `Φ ≤ τ_Φ` ∧ 预注册完整 ∧ `k_diff ≥ k_req`（若用 E2 定案）∧ OEC 通过 ∧ 锚定不变式成立。

**定义 325（自适应去噪与预算）** 默认 `J=4, K=4`；用中间层的熵斜率与簇质量稳定性做**早停**：若某层后 `H` 已低于阈值且主簇质量稳定，则不再向下细分；若 `Φ` 接近门限，则升 `K` 或 `J` 复核。实时路径用一致性蒸馏/缓存 trunk 保证 P99；物理探针在慢时间尺度执行，不计入 1 kHz 环路预算。

**定义 326（严格包含 R69/R68）** 当以下任一成立时，DUET 逐指令退化为 FLUID-RAS：(a) `|M_p| = 1`（无分叉）；(b) 无 `g` 满足 `VoI_phys > c` 或安全/预算约束；(c) `k_diff = 0`；(d) OEC 无效或预注册失败；(e) `Φ > τ_Φ`。而 FLUID-RAS 在 `VoI ≤ c` 时退化为 CALM-RAS。故 `R68 ⊂ R69 ⊂ R70`，安全侧单调不降。

```python
# IP-264 BDP：双臂扩散策略（条件编码复用 R68/R69 的 MTM trunk）
class BimanualDiffusionPolicy:
    def __init__(self, trunk, eps_net, J=4, K=4):
        self.trunk, self.eps = trunk, eps_net      # eps(x_s, s, z, r)

    def sample_tree(self, o_t, r_t, K=4, J=4):
        z  = self.trunk(o_t)                       # 复用 z_t
        xs = randn(K, D_L + D_R)                   # s = J，纯噪声
        tree = BifurcationTree(root=xs)
        for j in reversed(range(J)):               # 反向去噪 J -> 0
            eps = self.eps(xs, j, z, r_t)
            xs  = ddpm_step(xs, eps, j)
            tree.observe(level=j, particles=xs)    # 聚类 + 跨层匹配
        return xs, tree, z

# IP-265 TBD：持久性过滤 + 分层不确定性
def decompose(tree):
    leaves = tree.leaves()
    M_p    = [m for m in leaves if tree.persistence(m) >= PI_MIN]
    phi    = sum(tree.weight(m) for m in leaves if m not in M_p)
    if phi > TAU_PHI:
        return None, None, None, phi               # 幻影门 -> R69 兜底
    p = normalize([tree.weight(m) * tree.persistence(m) for m in M_p])
    U_ale = sum(p[k] * trace(tree.cov(m)) for k, m in enumerate(M_p))
    U_epi = entropy(p) * sep_factor(M_p) * tree.mean_persistence(M_p)
    L = [(v, entropy(tree.child_weights(v)), v.depth)
         for v in tree.internal_nodes() if entropy(tree.child_weights(v)) > TAU_H]
    return U_ale, U_epi, (M_p, p, sorted(L, key=lambda x: (-x[2], -x[1]))), phi

# IP-266 CCF：耦合可行域硬过滤（QP 投影）
def coupling_filter(M_p, o_t, eps):
    feasible = []
    for m in M_p:
        r = qp_distance_to_feasible(mean(m), C=lambda xi: coupling_constraints(xi, o_t))
        if r.mean <= eps and r.max <= eps_max:
            feasible.append(m)
    return feasible                                # 不可行模态直接剔除，不降权

# IP-267/268 PVE + PRC：选实验、预注册、证伪
def design_and_preregister(M_p, p, o_t, phys, budget):
    best = None
    for g in probe_candidates(M_p, o_t):           # 角色/扰动/观测协议
        if not c_ras_wm.certify_coupled(g, o_t):   continue
        if not anchor_invariant(g, o_t):           continue
        score = phys.voi(M_p, p, g) - phys.cost(g) # voi 已用 P_cm/J_eff
        if best is None or score > best.score: best = (g, score)
    if best is None or best.score <= 0: return None
    g = best[0]
    preds = {m: phys.predictor.predict(g, m, o_t) for m in M_p}   # 冻结、独立
    commit = sha256(canon(g, preds, phys.predictor.version, calib_snapshot()))
    audit_log.commit(commit, g, preds)
    return g, commit, preds

def refute(commit, preds, y_eff, g):
    if not audit_log.verify(commit): return None   # 预注册失效
    bf = {m: preds[m].likelihood(y_eff) for m in preds}
    return {m for m in bf if bf[m] < max(bf.values()) / TAU_BF}

# IP-269/270 CMR + OEC：共模抑制与反对称探针
def cmr_project(y, S_cm):
    P = np.eye(len(y)) - S_cm @ np.linalg.pinv(S_cm.T @ S_cm) @ S_cm.T
    return P @ y, P, np.linalg.matrix_rank(P @ J_obs)

def execute_oec(robot, g_plus, g_minus, g_null, delta):
    y0 = robot.execute(g_null)                     # 空探针
    yp = robot.execute(g_plus)                     # +δ
    ym = robot.execute(g_minus)                    # -δ
    yA = (yp - ym) / 2.0                           # 奇部：物体响应
    yB = (yp + ym) / 2.0 - y0                      # 偶部：观察者效应
    return yA, yB, np.linalg.norm(yB) <= C_O * delta**2

# IP-276 主闭环（继承 R69，仅在不确定性处置处插入 DUET 层）
def DUET_RAS_round(M, obs):
    z, o = M.mtm.forward(...)                      # 一次前向
    c, U_cal, thr = M.cof.step(...)                # R68 标定
    # 1) 跨噪声层采样 + 持久性分解
    xs, tree, z = M.bdp.sample_tree(o, r_t=M.roles.current, K=4, J=4)
    U_ale, U_epi, meta, phi = M.tbd.decompose(tree)
    if meta is None:                               # 幻影门
        return M.fluid_fallback(o, U_cal)
    M_p, p, L = meta
    # 2) 物理可行 + 共模秩检查
    M_feas = M.ccf.filter(M_p, o, M.eps_cpl)
    if len(M_feas) <= 1 or M.cmr.rank(o) < M.k_req:
        return M.fluid_fallback(o, U_cal)
    # 3) 选实验 -> 预注册 -> 反对称执行 -> 差分证伪
    plan = M.cap.design_and_preregister(M_feas, p, o, M.phys, M.budget)
    if plan is None:
        return M.fluid_fallback(o, U_cal)          # 无利可图 = R69 边界
    g, commit, preds = plan
    yA, yB, oec_ok = M.oec.execute(g, M.robot)     # 锚定臂全程守护
    if not oec_ok:
        return M.fluid_fallback(o, U_cal)
    y_eff, P, k_diff = M.cmr.project(yA, M.S_cm)
    if k_diff < M.k_req:
        return M.fluid_fallback(o, U_cal)
    falsified = M.prc.refute(commit, preds, y_eff, g)
    if falsified is None:
        return M.fluid_fallback(o, U_cal)
    p_post = M.cia.update_belief(M_feas, p, falsified)   # 只剪枝 + 温和后验
    U_epi_after = entropy(p_post) * sep_factor(M_feas)
    if not M.prc.two_probe_consistent(g, y_eff):
        U_epi_after = U_epi                       # 单次实验不得定案
    # 4) 风险缩放：只对 aleatoric + 未消解 epistemic 收紧
    U_floor = U_ale + (U_epi_after if U_epi_after > TAU_EPI else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    A = M.ach.propose(x_prime, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)   # 双臂耦合认证
    mode = select_mode(M_feas, p_post, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.xi[:k]) * lam
    # 5) 审计 + 证书
    M.vqa_d.submit_async(g, commit, phi, k_diff, oec_ok, U_epi, U_epi_after)
    return k, lam, mode, (U_ale, U_epi_after)
```

## 3. 推导

**引理 19（持久性过滤的幻影上界）** 设 A99：真实模态持久性 `π ≥ π_T`，幻影模态 `π ≤ π_P`，且 `π_T − π_P ≥ 2ε_K`。用 `K` 条粒子、`J` 个噪声层估计持久性，DKW 不等式给出 `|π̂ − π| ≤ ε_K = √(log(2J/δ)/(2K))` 以概率 `≥ 1−δ`。取 `π_min ∈ (π_P + ε_K, π_T − ε_K)`，则以概率 `≥ 1−δ`，所有真模态被保留、所有持久性 `≤ π_P` 的幻影被剔除；残余幻影质量 `≤ Φ · 1[π_P ≥ π_min]`。系：当 `Φ > τ_Φ` 时，正确动作不是「再采样看看」，而是承认模态分布不可信并退回 R69——**幻影门是安全阀，不是调参旋钮**。

**引理 20（共模抑制与不重复计数）** 双腕观测 `y_i = J_i θ + e_cm + e_i`，`e_cm ~ 𝒩(0, Σ_cm)`，`e_i ~ 𝒩(0, Σ_i)`。若把它们当独立源朴素融合，Fisher 信息写成 `Σ_i J_i^T Σ_i^{-1} J_i`，会高估信息；由于 `e_cm` 的存在，真实信息上界是 `J_eff^T Σ_eff^{-1} J_eff`，其中 `J_eff = P_cm [J_1; J_2]`，秩 `k_diff ≤ d`。因此多一条臂带来的置信增益至多 `k_diff/2` nats；当 `k_diff = 0` 时，两臂再一致也不提供任何关于 `θ` 的信息。系：R69 的「立 k 个正交证据源」在双臂场景必须用 `k_eff = k_diff` 计，而不是数胳膊——**同一台机器上的两条臂，可能只是同一个错误的两个副本**。

**引理 21（物理 VoI 的可辨识维数）** 局部线性高斯下，`VoI_phys(g) = ½ log det(I + Σ_θ J_eff^T Σ_e^{-1} J_eff) ≤ ½ Σ_{i=1}^{k_diff} log(1 + σ_i²/σ_e²)`，只有差分可辨识方向贡献信息。若待消歧参数落在 `ker(J_eff)`（纯共模自由度，例如物体在基座坐标系中的绝对位姿），则任意跨臂探针 `VoI_phys = 0`，必须引入外部参考、移动基座或回到 R69 问人。系：**双臂不是万能尺，它只测量「两臂之间」的世界**；对纯共模歧义，最诚实的动作是承认测不到。

**引理 22（分权预注册的防自证）** 设实验选择器 `S` 与结果预测器 `P` 参数独立（`I(θ_S; θ_P) = 0`），且预测在执行前哈希冻结。则选择器偏差无法提高幻影通过 BF 的概率；错误确认率 `≤ α_P + ε_commit`，其中 `α_P` 是预测器的模型错误率，`ε_commit` 是承诺机制失败率。反之若 `S = P`（同一模型既设计又预测），存在自洽幻觉使错误确认概率趋近 1：模型会选择那些「自己的幻觉也能预测对」的实验。系：分权不是流程装饰，而是「实验能够证伪」的可辨识条件——**让提出问题的人和判定答案的人不是同一个头脑**。

**引理 23（反对称探针消去观察者效应）** 设 `y(δ) = y_0 + uδ + hδ² + O(δ³)`，`h` 为偶的探针偏置。则 `y_A = (y(+δ) − y(−δ))/2 = uδ + O(δ³)`，偏置 `≤ cδ³`；若实际不对称度 `η`，残余偏置 `≤ η|y_0| + cδ²`。故 OEC 有效需 `δ` 小、`η` 小。系：预注册必须同时承诺 `+δ` 与 `−δ`；**单次探针无法区分「物体很软」与「探针推歪了」**，正如单次回答无法区分「专家很稳」与「他在迎合你」。

**定理 18（严格包含）** 在 A99–A103 下，DUET 的期望风险 `≤` R69 的 FLUID-RAS；且当定义 326 的任一退化条件成立时，两者逐指令相同；FLUID-RAS 在 `VoI ≤ c` 时又逐指令退化为 CALM-RAS。因此 `R68 ⊂ R69 ⊂ R70`：物理实验只在能提供独立差分信息时启用，安全侧不做任何让步，效率侧获得「物理 resolution bonus」。证明按五种边界情形逐一比对：无分叉、无可行实验、秩亏、OEC/预注册失败、幻影门触发，均直接调用 R69 的 `choose_interaction` 与 `λ_floor`，故逐指令一致。

**定理 19（双臂耦合安全与无突变）** 若每个探针 `g` 通过耦合 C-RAS-WM 认证、锚定不变式成立、探针力/位包络有界，则物理风险 `≤ ε_duet`；实验只改变「选哪个模态」，不改变安全包络；任何失败（OEC 无效、预注册失效、`k_diff` 不足、幻影门触发）时 `λ` 单调不降地退化为 R69；角色交接的不变式保证控制连续、无突变。证明要点：锚定臂始终在 `S_safe` 内且可 `T_abort` 内中止；探针臂相对于锚定臂的包络由认证给出；退化路径只增加 `λ`、只收紧 `k`，不放松任何安全约束。

**定理 20（双重防线下的错误采纳上界）** 在 A99–A103 下，一次实验后错误模态被采纳的概率
`P_err ≤ Φ_rem + ε_cpl + ε_cm + α_P + ε_OEC + e^{−D_BF}`，
其中 `Φ_rem` 为持久性过滤残余幻影质量，`ε_cpl` 为耦合过滤漏检，`ε_cm` 为共模投影误差，`α_P` 为预测器模型错误，`ε_OEC` 为观察者效应残余，`D_BF` 为真/假模态的期望对数 Bayes 因子。特别地，当 `k_diff = 0` 时`P_err` 不因实验而下降——此时唯一正确的策略是退回 R69 或引入外部参考。系：双臂物理证据的安全性不是「物理一定真」，而是「每一条通道都有明确的失效界，且失效时退回旧层」。

**定理 21（分层实验的预算上界）** 设分岔树中高于阈值 `TAU_H` 的内部节点数为 `N`，每个节点被一次成功实验消解后其子熵降至阈值以下。按深度 `d(v)` 从大到小贪心选择，期望实验数 `≤ N`，且通常 `≤ log₂ K`（默认 `K=4` 时最多 2 层粗决策）。若某节点 `VoI_phys ≤ c`，则停止并走 R69，不消耗探针预算。系：**粗到细不仅更省，而且更安全**——先解决高深度、高熵的粗分叉，能避免为细枝末节做危险探针。

## 6. 本轮最大风险

**一句话**：DUET 把 R69 的「问错人」升级为「用双臂做了一个预注册合规、统计显著、却建立在错误物理模型上的实验」——预注册只保证系统不自我欺骗，不保证物理模型为真；证伪只能在模型内否定假设，无法否定模型本身，而一个足够自洽的错误模型会让机器人**自信地用一次严谨实验确认一个错误的世界**。

**次级风险与缓解**：
1. **共模盲区**（双腕共享标定误差，差分秩亏）→ CMR 投影 + `k_diff` 门 + 共模告警 + R69 兜底；
2. **观察者效应/塑性变形**（探针改变物体）→ 反对称探针对 + 空探针 + 小 `δ` + OEC 有效性检验；
3. **持久幻影**（扩散模型本身的稳定错误吸引盆）→ 持久性校准 + 幻影门 + 耦合硬过滤 + 跨周期分岔一致性检查；
4. **自证实验**（选择器/预测器共享数据或参数）→ 分权 + 预注册哈希 + 审计 + 数据泄漏检查；
5. **双臂安全与单臂退化**（探针越界、锚定臂失稳、标定漂移）→ 锚定不变式 + 认证交接 + 角色对称性审计 + 力/位包络；
6. **实时预算被分层采样击穿**→ 早停 + 蒸馏 + 缓存 trunk + 物理探针与快环解耦。

## 2. 形式化定义（要点版）

**定义 310（总览与三不变式）** DUET-RAS = (BDP,TBD,CCF,CAP,PVE,PRC,CMR,OEC,DAR,RAS-WM‡)；零学习写操作继承 R69；预注册与分权（选择器/预测器参数独立、预测执行前冻结哈希）；共模纪律（只有差分投影分量算独立证据，`k_diff=0` 禁止物理定案，安全侧保留 R69 `λ_floor`）。

**定义 311–312（BDP 与分岔树）** 双臂联合动作 `ξ=(ξ_L,ξ_R)`，角色令牌 `r_t`；扩散前向/反向 `x_s=√ᾱ_s x_0+√(1−ᾱ_s)ε`；每层聚类并用 Hungarian 跨层匹配，分裂点构成树；分岔深度 `d(v)=s_v`，持久性 `π_m` 为跨层稳定簇占比，幻影质量 `Φ=Σ_{π_m<π_min} ŵ_m`。

**定义 313（分层不确定性）** `M_p={π_m≥π_min}`，`p_m∝ŵ_mπ_m`；`U_ale=Σ p_m trΣ_m`，`U_epi=H(p)·g(Δ_min)·π̄`；内部节点列表 `L` 按深度与熵排序，供粗到细实验；`Φ>τ_Φ` 触发幻影门并退回 R69。

**定义 314（CCF 耦合硬过滤）** `C=(C_chain,C_coll,C_joint,C_sync,C_force)≤0`；`r_cpl=dist(ξ,ℱ_t)`（QP 投影）；模态不可行则直接剔除，不降权。

**定义 315–316（CAP 与 PVE）** 探针 `g=(ρ,u_L,u_R,T_g,M_obs)`；冻结独立预测器 `h_ψ` 给 `p(y|g,m,o)`；锚定臂全程在 `S_safe`、探针臂在认证包络、`T_abort` 内可中止。`VoI_phys=½logdet(I+Σ_θJ_eff^TΣ_e^{-1}J_eff)`；`g*=argmax[VoI_phys−c]`，≤0 则不实验、走 R69。

**定义 317（PRC 预注册证伪）** 执行前哈希承诺 `H`；执行后算 BF；证伪集 `F` 只剪枝、不单独确认；单次实验只提供似然，需两次正交实验或高 VoI + 低严重度才可定案；哈希失效/事后修改则实验作废。

**定义 318（CMR 共模抑制）** `P_cm=I−S_cm(S_cm^T S_cm)^+S_cm^T`，`y_eff=P_cm y`，`k_diff=rank(P_cm J)`；共模一致不算独立证据；共模漂移而差分稳定 ⇒ 怀疑共享标定，不更新物体后验；`k_diff=0` ⇒ 物理实验零信息。

**定义 319（OEC 观察者效应控制）** `y(δ)=y_0+uδ+hδ²+O(δ³)`；`y_A=(y(+δ)−y(−δ))/2` 取奇部，`y_B=(y(+δ)+y(−δ))/2−y(0)` 取偶部；`‖y_B‖≤c_oδ²` 才有效；单次 `+δ` 不足以区分物体响应与探针偏置。

**定义 320（DAR 角色与锚定安全）** 锚定臂在 `S_safe`、探针臂在 `E_probe(ρ)`、交接瞬间双臂均安全、`T_abort` 内可中止；角色对称性审计检测单臂退化。

**定义 321（分层证据纪律）** `E1` 统计模态、`E2` CMR 物理实验、`E3` 人类回答；`s≥s_crit` 需 `E1+E2` 或 `E2+E3` 一致；单源不得定案；物理证据只有 CMR+OEC 通过才算独立。

**定义 322–326（审计/干扰/证书/预算/包含）** VQAuditor-D 审预注册、分权、CMR/OEC、锚定安全、幻影门、角色对称性；`ℰ_DUET` 并入幻影/共模/预注册/观察者/耦合/角色攻击；`J_DUET` 增加持久性 ECE、`Φ`、`tree_hash`、`prereg_hash`、`k_diff`、`oec_bias`、`anchor_safety`；默认 `J=4,K=4` + 早停 + 蒸馏；五类退化边界下逐指令退回 FLUID-RAS。

```python
# IP-264 BDP：双臂扩散策略（条件编码复用 R68/R69 MTM trunk）
class BimanualDiffusionPolicy:
    def sample_tree(self, o_t, r_t, K=4, J=4):
        z, xs = self.trunk(o_t), randn(K, D_L + D_R)      # s=J 纯噪声
        tree = BifurcationTree(root=xs)
        for j in reversed(range(J)):
            xs = ddpm_step(xs, self.eps(xs, j, z, r_t), j)
            tree.observe(level=j, particles=xs)            # 聚类 + 跨层匹配
        return xs, tree, z

# IP-265 TBD：持久性幻影门 + 分层不确定性
def decompose(tree):
    M_p = [m for m in tree.leaves() if tree.persistence(m) >= PI_MIN]
    phi = sum(tree.weight(m) for m in tree.leaves() if m not in M_p)
    if phi > TAU_PHI: return None, None, None, phi         # 幻影门 -> R69
    p = normalize([tree.weight(m) * tree.persistence(m) for m in M_p])
    U_ale = sum(p[k] * trace(tree.cov(m)) for k, m in enumerate(M_p))
    U_epi = entropy(p) * sep_factor(M_p) * tree.mean_persistence(M_p)
    L = sorted([(v, entropy(tree.child_weights(v)), v.depth)
                for v in tree.internal_nodes()], key=lambda x: (-x[2], -x[1]))
    return U_ale, U_epi, (M_p, p, L), phi

# IP-266 CCF：耦合可行域硬过滤
def coupling_filter(M_p, o_t, eps):
    return [m for m in M_p
            if qp_distance(mean(m), C=lambda xi: coupling(xi, o_t)).max <= eps]

# IP-267/268 PVE + PRC：选实验并冻结预测
def design_and_preregister(M_p, p, o_t, phys, budget):
    best = None
    for g in probe_candidates(M_p, o_t):
        if not c_ras_wm.certify_coupled(g, o_t) or not anchor_invariant(g, o_t):
            continue
        score = phys.voi(M_p, p, g) - phys.cost(g)         # 已用 P_cm/J_eff
        if best is None or score > best.score: best = (g, score)
    if best is None or best.score <= 0: return None
    g = best[0]
    preds = {m: phys.predictor.predict(g, m, o_t) for m in M_p}   # 独立、冻结
    commit = sha256(canon(g, preds, phys.predictor.version, calib_snapshot()))
    audit_log.commit(commit, g, preds)
    return g, commit, preds

def refute(commit, preds, y_eff, g):
    if not audit_log.verify(commit): return None           # 预注册失效
    bf = {m: preds[m].likelihood(y_eff) for m in preds}
    return {m for m in bf if bf[m] < max(bf.values()) / TAU_BF}

# IP-269/270 CMR + OEC
def cmr_project(y, S_cm, J):
    P = np.eye(len(y)) - S_cm @ np.linalg.pinv(S_cm.T @ S_cm) @ S_cm.T
    return P @ y, P, np.linalg.matrix_rank(P @ J)

def execute_oec(robot, g_plus, g_minus, g_null, delta):
    y0, yp, ym = robot.execute(g_null), robot.execute(g_plus), robot.execute(g_minus)
    yA = (yp - ym) / 2.0                                   # 奇部：物体响应
    yB = (yp + ym) / 2.0 - y0                              # 偶部：观察者效应
    return yA, yB, np.linalg.norm(yB) <= C_O * delta**2

# IP-276 主闭环（继承 R69）
def DUET_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    xs, tree, z = M.bdp.sample_tree(o, M.roles.current, K=4, J=4)
    U_ale, U_epi, meta, phi = M.tbd.decompose(tree)
    if meta is None: return M.fluid_fallback(o, U_cal)     # 幻影门
    M_p, p, L = meta
    M_feas = M.ccf.filter(M_p, o, M.eps_cpl)
    if len(M_feas) <= 1 or M.cmr.rank(o) < M.k_req:
        return M.fluid_fallback(o, U_cal)                  # 无实验/秩亏
    plan = M.cap.design_and_preregister(M_feas, p, o, M.phys, M.budget)
    if plan is None: return M.fluid_fallback(o, U_cal)     # VoI<=成本
    g, commit, preds = plan
    yA, yB, oec_ok = M.oec.execute(g, M.robot)
    if not oec_ok: return M.fluid_fallback(o, U_cal)
    y_eff, P, k_diff = M.cmr.project(yA, M.S_cm, M.J_obs)
    if k_diff < M.k_req: return M.fluid_fallback(o, U_cal)
    falsified = M.prc.refute(commit, preds, y_eff, g)
    if falsified is None: return M.fluid_fallback(o, U_cal)
    p_post = M.cia.update_belief(M_feas, p, falsified)     # 只剪枝 + 温和后验
    U_epi_after = entropy(p_post) * sep_factor(M_feas)
    if not M.prc.two_probe_consistent(g, y_eff): U_epi_after = U_epi
    U_floor = U_ale + (U_epi_after if U_epi_after > TAU_EPI else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    mode = select_mode(M_feas, p_post, lam)
    tau = M.pi_sigma.prefix_dispatch(mode.xi[:k]) * lam
    M.vqa_d.submit_async(g, commit, phi, k_diff, oec_ok, U_epi, U_epi_after)
    return k, lam, mode, (U_ale, U_epi_after)
```

## 4. 推导

**引理 19（持久性过滤的幻影上界）** A99：真模态 `π≥π_T`、幻影 `π≤π_P`、`π_T−π_P≥2ε_K`；DKW 给 `|π̂−π|≤ε_K`（概率 `≥1−δ`）。取 `π_min∈(π_P+ε_K, π_T−ε_K)`，则真模态全保留、`π≤π_P` 的幻影全剔除（概率 `≥1−δ`），残余幻影质量 `≤Φ·1[π_P≥π_min]`。`Φ>τ_Φ` 时退回 R69：幻影门是安全阀，不是调参旋钮。

**引理 20（共模抑制与不重复计数）** `y_i=J_iθ+e_cm+e_i`；朴素融合高估 Fisher 信息，真实上界 `J_eff^TΣ_eff^{-1}J_eff`，`J_eff=P_cm[J_1;J_2]`，秩 `k_diff`。多一臂的置信增益至多 `k_diff/2` nats；`k_diff=0` 时两臂一致零信息。系：R69 的 k 源一致必须用 `k_eff=k_diff` 计，不能数胳膊。

**引理 21（物理 VoI 的可辨识维数）** `VoI_phys≤½Σ_{i=1}^{k_diff}log(1+σ_i²/σ_e²)`；若歧义落在 `ker(J_eff)`（纯共模，如基座系绝对位姿），任意跨臂探针 `VoI=0`，必须引入外部参考/移动基座/回到 R69。系：双臂只测量「两臂之间」的世界。

**引理 22（分权预注册的防自证）** `S` 与 `P` 参数独立且预测执行前冻结时，选择器偏差不能提高幻影通过 BF 的概率，错误确认率 `≤α_P+ε_commit`；若 `S=P`，存在自洽幻觉使错误确认概率趋近 1。系：分权是「实验能证伪」的可辨识条件，让提问者与判卷者不是同一个头脑。

**引理 23（反对称探针消去观察者效应）** `y(δ)=y_0+uδ+hδ²+O(δ³)`；`y_A=(y(+δ)−y(−δ))/2=uδ+O(δ³)`，偏置 `≤cδ³`；不对称度 `η` 时残余 `≤η|y_0|+cδ²`。系：预注册必须同时承诺 `±δ`，单探针无法区分「物体软」与「探针歪」。

**定理 18（严格包含）** A99–A103 下，DUET 期望风险 `≤` FLUID-RAS；五类退化边界（无分叉、无可行实验、`k_diff=0`、OEC/预注册失败、幻影门）下逐指令相同；FLUID 在 `VoI≤c` 时退化为 CALM。故 `R68⊂R69⊂R70`，安全侧不让步，效率侧得物理 resolution bonus。

**定理 19（双臂耦合安全与无突变）** 耦合 C-RAS-WM 认证 + 锚定不变式 + 力/位包络 ⇒ 物理风险 `≤ε_duet`；实验只改模态选择，不改安全包络；任一失败 `λ` 单调不降地退回 R69；认证交接保证控制连续、无突变。

**定理 20（双重防线下的错误采纳上界）** `P_err≤Φ_rem+ε_cpl+ε_cm+α_P+ε_OEC+e^{−D_BF}`；`k_diff=0` 时实验不降低 `P_err`，唯一正确动作是退回 R69/引入外部参考。系：物理证据的安全性不是「物理一定真」，而是每条通道都有失效界且失效时退回旧层。

**定理 21（分层实验的预算上界）** 高于阈值 `TAU_H` 的内部节点数为 `N`，按深度降序贪心选择，期望实验数 `≤N`，默认 `K=4` 时通常 `≤log₂K=2`；若节点 `VoI_phys≤c` 则停止并走 R69。系：粗到细不仅更省，而且更安全。

## 7. 本轮最大风险

**一句话**：DUET 把 R69 的「问错人」升级为「用双臂做了一个预注册合规、统计显著、却建立在错误物理模型上的实验」——预注册只保证系统不自我欺骗，不保证物理模型为真；证伪只能在模型内否定假设，无法否定模型本身，而一个足够自洽的错误模型会让机器人**自信地用一次严谨实验确认一个错误的世界**。

**次级风险与缓解**：共模盲区（CMR + `k_diff` 门 + 共模告警 + R69 兜底）；观察者效应/塑性变形（反对称探针对 + 空探针 + 小 `δ` + OEC 检验）；持久幻影（持久性校准 + 幻影门 + 耦合硬过滤 + 跨周期一致性）；自证实验（分权 + 预注册哈希 + 审计 + 泄漏检查）；双臂安全与单臂退化（锚定不变式 + 认证交接 + 角色对称性审计 + 力/位包络）；实时预算（早停 + 蒸馏 + 缓存 trunk + 物理探针与快环解耦）。
