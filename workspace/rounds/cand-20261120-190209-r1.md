# 第 1 轮（新灵感循环第 1 轮；本轮灵感：「自然语言指令」×「激光雷达」）

> **基线**：第 14 轮 MetricVoiceGauge-NCD-HUTDH-v16（定义 627–656；引理 131–136；实验 E671–E690）。
> 本轮纪律：**语言给意图、几何给证据、联合给证书**。不推倒 v16：v16 的 BTS/TRM/WBC/CSC/NCS/MCA/WCB 与历轮不变式全部保留。两个新维度——IGC（指令接地证书）与 LEC（激光雷达证据证书）——以及把它们耦合起来的 RGC（指称接地证书）——一律以**中立元**接入，失效即严格退回 v16（引理 141），再沿 v16→v15→v14→v13→v12→v11→v10→v9→v8→v7→v6 退化链退回。本轮只做三件事：把"自然语言指令"改写为**共形意图集合上的鲁棒任务证书**、把"激光雷达"改写为**未观测即不安全的空间证据证书**、把"指称"改写为**意图与几何的联合接地证书**。

## 0. 直觉与动机

**灵感 1（自然语言指令 → 指令接地证书 IGC）**
直觉：v16 的行为树已经能证"给定任务规格时每一步是否安全"，但它默认任务规格是外部给定的。人形机器人真正的入口是一句自然语言——"去厨房把那杯水拿来，绕过左边那根柱子，慢一点"。这句话同时含**目标**（拿水）、**路径约束**（绕柱）、**指称**（那杯、那根）和**修饰**（慢一点）。现有做法是先解析成一个形式规格，再对规格做证书；问题在于**解析是一个 argmax，而安全需要的是整个意图集合**。核心创新：**指令接地证书（Instruction Grounding Certificate, IGC）**。把接地模型写成 `s(τ|u,x)`，在人类核验过的校准集上做分裂共形，得到意图集合 `T_α(u,x)={τ: s(τ|u,x) ≥ 1-q_α}`，满足 `P(τ*∈T_α) ≥ 1-α`。执行不再针对 `argmax s`，而是针对 **`T_α` 上的一致安全集**：`Cert_IGC = ⋂_{τ∈T_α} Safe(τ)`。关键反直觉点：**"听懂"不是解析正确，而是"真实意图被一个可执行安全集覆盖"**；当 `T_α` 太大导致交集为空时，**"问一句"本身是一个有证书、有价值的安全动作**，而不是失败。

**灵感 2（激光雷达 → 几何证据证书 LEC）**
直觉：v16 的 WBC 用 ZMP/CoM/接触证书保证动力学安全，但"前面能不能走"是几何问题。激光雷达点云经占据栅格后，工程上常把非占据单元当作自由空间。这是错的：**未命中不等于空**——镜面/暗色吸收、远处稀疏、物体背后遮挡、机器人自身盲区，都会产生"没看见"而非"安全"。核心创新：**激光雷达证据证书（LiDAR Evidence Certificate, LEC）**。把工作空间分成单元 `c`，维护占据/自由/未知三种证据质量，用证据理论或 Dirichlet 模型给出自由概率的**置信下界** `p_free_lower(c)`；未知单元一律取 `p_free_lower=0`（**未知即占用**）。轨迹 `γ` 的几何证书要求其扫掠体内每个单元都满足 `p_free_lower ≥ 1-β`，再用 Bonferroni 把单元风险分配到整条轨迹。关键反直觉点：**LiDAR 给的"空"是带下界的、有观测视角的空，不是逻辑上的空**；"去那里看一眼"（主动感知 `Look(v)`）是**证书生产动作**，它的价值可用未知质量的期望下降来度量。

**灵感 3（指称 × 联合接地 → 跨模态证书不可分解）**
直觉：语言几乎总在指称 LiDAR 可见的东西——"那根柱子""红色箱子""靠墙的椅子"。于是语言歧义和几何歧义不是两个独立问题，而是**共享同一组锚点随机变量**：解析出"绕过柱子"里的"柱子"到底绑到哪个 LiDAR 簇，取决于是哪根柱子、也取决于"绕过"这个意图。核心创新：**指称接地证书（Referential Grounding Certificate, RGC）**。把语言接地的对象从"意图 `τ`"升级为"**意图-锚点对 `(τ,a)`**"，并做**联合共形校准**：`A_α(u,P_t,x)={(τ,a): joint_score ≥ 1-q_α}`。安全集是 `CIGC = ⋂_{(τ,a)∈A_α} TaskSafe(τ,a) ∩ GeoCert_β(P_t)`。关键反直觉点：**先分别求意图集合与锚点集合再取笛卡尔积，是错的**——边缘 MAP 组合出的 `(τ̂,â)` 可能是一个**联合概率为零、物理上不可实现**的对（例：最可能的意图是"把杯子放到桌上"，最可能的锚点是"身后那只杯子"，二者组合要求机械臂穿过躯干）；而把边缘集合的笛卡尔积整体拿去做安全交集，又会因为塞进大量虚假配对而把安全集压成空集，造成"证书正确、机器人冻住"。正确对象是**联合校准的 `(τ,a)` 集合**，不是两个边缘的乘积。

**三者如何统一**
统一为 **v16 全身行为层之上的"指令-几何"入口层**：v16 回答"给定任务与里程碑，行为树能安全跑到哪"（`Exec_v16`），v17 回答"从一句自然语言和一个点云出发，当前能安全地承诺执行哪个意图-锚点对，或者该先问/先看"（`Exec_v17`）。IGC 把语言变成带共形覆盖的意图集合；LEC 把点云变成带未知标志的几何证据场；RGC 把二者耦合为联合接地集合；CIGC 把联合集合逐对求安全集交集，再与 v16 的 `Exec_v16` 相交。共享状态 `ζ_lg=(T_α, A_α, U_unknown, Amb, VoI_q, VoI_v, P_t, drift_lg, mode_lg)`。**IGC 回答"这句话可能是什么意思"，LEC 回答"这个世界哪里被证过是空的"，RGC 回答"这句话里的每个指称到底绑到哪个几何对象"，CIGC 回答"这一帧该执行、该澄清、还是该去看一眼"**。四者不是四个补丁，而是"意图—证据—指称—决策"的实现链。

## 1. 研究问题（轮次升级版）

- **Q1（意图集合的覆盖与鲁棒执行）**：如何为自然语言构造满足 `P(τ*∈T_α) ≥ 1-α` 的共形意图集合？当意图集合是组合式（目标×路径×修饰）时，如何在子句级别做共形而不做指数枚举？指令精化（"慢一点""别碰那个"）如何保证证书单调收紧而不是悄悄放宽？
- **Q2（激光雷达证据证书的保守性与活动性）**：如何在遮挡、远距稀疏、镜面/暗色、自遮挡与动态物体下给出可靠的自由空间下界？"未知即占用"如何避免把机器人永久冻死？主动感知的视点选择如何在有限步内把扫掠体上的未知质量压到阈值以下，且感知运动本身首先满足证书？
- **Q3（指称的联合接地与误差抵消）**：如何定义并校准 `(τ,a)` 的联合得分，使联合集合既覆盖真实对、又不被虚假配对撑爆？语言与几何的误差何时会"抵消"（错锚点但大致对位置）从而骗过独立证书？多指称、否定、比较级（"比那个高一点"）如何合成？
- **Q4（澄清/感知/执行的统一调度与退化）**：在时延预算下，如何在"直接执行 / 问一句 / 去看一眼 / 退回 v16"之间做价值-信息权衡？澄清与感知的单调收缩何时保证终止？分布漂移导致"集合很小但错"时，如何检测并阻止"自信地错"？全失效时能否严格退回 v16？

## 2. 设计原则（在 P25–P27 基础上新增 P28–P30）

**P28 指令即证书分布律（Instruction as Certificate Distribution）**
任何自然语言指令 `u` 不得被压缩为单一形式规格后再证安全。必须存在一个共形意图集合 `T_α(u,x)`，满足覆盖率 `P(τ*∈T_α) ≥ 1-α`，且执行动作必须对 `∀τ∈T_α` 安全：`a ∈ Cert_IGC(u,x) = ⋂_{τ∈T_α} Safe(τ)`。若 `Cert_IGC=∅`，唯一合法选择是**收紧证据**（澄清或主动感知）或**保守停止**，禁止退回到 `argmax` 点估计执行。指令精化 `u' ⪯ u`（增加约束）必须满足 `T_α(u') ⊆ T_α(u)` 与 `Cert_IGC(u') ⊇ Cert_IGC(u)`；**意图改变**（而非精化）必须重新接地，不得继承旧证书。

**P29 未观测即不安全律（Unobserved is Unsafe）**
激光雷达自由空间必须表示为**自由概率置信下界**而非二值占据。对任意单元 `c`，若其未被有效观测（遮挡、超出量程、镜面/暗色、自遮挡），则强制 `p_free_lower(c)=0`，即按占用处理。轨迹几何证书 `GeoCert_β(γ)=1` 当且仅当扫掠体内所有单元满足 `p_free_lower ≥ 1-β_c` 且 `Σβ_c ≤ β`。**主动感知是被显式建模的证书生产动作**：它必须首先满足自身的感知运动证书，且其价值按期望未知质量下降 / 时延计。

**P30 指称联合接地律（Joint Referential Grounding）**
语言中的每个指称 `r` 与几何场景图对象 `O_t` 的绑定 `a` 必须与意图 `τ` **联合校准**，得到 `A_α(u,P_t,x)` 满足联合覆盖率 `P((τ*,a*)∈A_α) ≥ 1-α`。**禁止**用边缘集合的笛卡尔积 `T_α×A_α` 代替联合集合，也**禁止**用边缘 MAP 组合 `(argmax τ, argmax a)` 作为执行依据。所有指称证书的合成必须是联合运算；无法联合校准时，必须降级为"联合集合 = 全体合法对"的中立元并触发澄清，而不是假设独立。

## 3. 与基线的接口（如何退化）

- IGC 失效 ⇒ 点估计中立元：`T_α ≡ {τ_v16}`、`Cert_IGC ≡ Safe(τ_v16)`，语言层退化为 v16 的外部任务规格，**等价 v16**；
- LEC 失效 ⇒ 二值占据中立元：所有已观测单元 `p_free_lower∈{0,1}`、未知单元按 v16 原几何管线处理，`GeoCert_β≡1`，**等价 v16（+IGC）**；
- RGC 失效 ⇒ 锚点由 v16/几何管线给定、意图集合独立接地，`A_α ≡ T_α×{a_geo}`，**等价 v16（+IGC+LEC）**；
- CIGC/澄清/主动感知失效 ⇒ 静态执行点估计，不做信息收集，**等价 v16 调度路径**；
- 四者全失效 ⇒ MetricVoiceGauge-NCD-HUTDH-v16，再沿 v16→v15→…→v6 退化；
- **安全继承**：IGC 只做交集、LEC 只把未知当占用、RGC 只做联合取交、CIGC 只做二次取交。四端口均不能放宽任何阈值或新增授权；`Exec_v17⊆Exec_v16` 由引理 141 保证。

## 4. 预期贡献

1. **证书化语言接地**：把"听懂指令"从解析准确率问题改写为共形覆盖 + 鲁棒执行问题，给出意图集合与指令精化的单调性，填补"自然语言不可证"的空白；
2. **证据化几何安全**：把激光雷达自由空间从二值栅格改写为带置信下界的证据场，给出"未知即占用"的保守性证明与主动感知的有限终止性；
3. **联合指称证书**：证明边缘乘积与边缘 MAP 在指称接地中既可能过度保守、又可能联合不可行，给出联合共形校准作为唯一正确对象；
4. **意图-几何-行为三层统一**：用 `Exec_v17⊆Exec_v16⊆Exec_v15⊆Exec_v13⊆Exec_v12` 把语言、几何、行为、路线、动力学、实时、蒸馏全解耦；
5. **"自信地错"的可检测化**：把分布漂移下"集合小但错"的失效模式显式建模为风险控制问题，给出语义蕴含校验与歧义下限两类护栏；E691–E710 覆盖覆盖性、保守性、联合性、活动性、漂移与端到端。

## 5. 本轮最大风险

**一句话**：IGC/RGC 的覆盖保证依赖校准集与部署分布的**可交换性**，而自然语言与激光雷达场景恰恰都是非平稳的——新说法、新物体、新布局会让接地模型"**自信地错**"：真实意图-锚点对被排除在联合集合之外，集合反而更小、证书下界反而更高、澄清的价值-信息也因"看起来不模糊"而趋近于零，于是系统在不触发任何保守动作的情况下，执行了一个**语义自洽、几何自洽、联合证书最高、却完全错位且绝对不安全**的动作。

## 1. 关键算法骨架

```python
# IP-416 Instruction Grounding Certificate：共形意图集合
class InstructionGroundingCertificate:
    def __init__(self, encoder, intent_space, calib, alpha=0.1):
        self.encode = encoder            # (u,x) -> scores over T
        self.T = intent_space
        self.calib = calib               # D_cal^IG
        self.alpha = alpha
        self.q = None

    def calibrate(self):
        """分裂共形：非一致性 a_i = 1 - s(τ*_i | u_i, x_i)"""
        scores = [1.0 - self.encode.s(ui, xi, ti)
                  for (ui, xi, ti) in self.calib]
        n = len(scores)
        k = min(n, int(np.ceil((n + 1) * (1 - self.alpha))))
        self.q = np.sort(scores)[k - 1]

    def intent_set(self, u, x):
        """T_α = {τ : s(τ|u,x) >= 1-q}，按得分降序截断"""
        scored = self.encode.rank(u, x, self.T)
        return [t for (t, s) in scored if s >= 1.0 - self.q]

    def certificate(self, u, x, safe):
        """Cert_IGC = ⋂_{τ∈T_α} Safe(τ)；空集触发 ARP"""
        T_alpha = self.intent_set(u, x)
        if not T_alpha:
            return None, T_alpha
        cert = safe(T_alpha[0])
        for tau in T_alpha[1:]:
            cert = cert.intersect(safe(tau))
            if cert.is_empty():
                return None, T_alpha
        return cert, T_alpha

    def refine_monotone(self, u_old, u_new, x):
        """u_new ⪯ u_old ⇒ T_new ⊆ T_old；否则要求重新接地"""
        if self.is_refinement(u_new, u_old):
            return self.intent_set(u_new, x)
        raise ReGroundRequired(u_new)


# IP-417 LiDAR Evidence Certificate：证据化自由空间
class LiDAREvidenceCertificate:
    def __init__(self, grid, delta=0.05, beta=0.01, range_max=30.0):
        self.grid = grid
        self.delta = delta               # 单元性置信水平
        self.beta = beta                 # 轨迹总风险
        self.range_max = range_max
        self.unk = set(grid.cells)       # 初始全未知

    def update(self, points, pose, body_mask):
        """射线投射 + 自遮挡/盲区建模；返回更新后的单元证据"""
        for (c, hit) in self.grid.raycast(points, pose):
            if hit:
                self.grid.e_occ[c] += 1.0
            else:
                self.grid.e_free[c] += 1.0
            self.unk.discard(c)
        # 机器人自身遮挡锥与量程外：显式标记未知，而不是自由
        for c in body_mask.shadow_cone(pose) | self.grid.out_of_range(pose, self.range_max):
            self.unk.add(c)
        return self

    def cell_cert(self, c):
        """未知 ⇒ p_free_lower=0；否则 Clopper–Pearson 下界"""
        if c in self.unk or c not in self.grid.observed:
            return (1.0, 0.0, 1)         # (p_occ_up, p_free_low, eta)
        a_free, a_occ = self.grid.e_free[c], self.grid.e_occ[c]
        p_free_low = clopper_pearson_lower(a_free, a_free + a_occ, self.delta)
        p_occ_up = 1.0 - p_free_low
        return (p_occ_up, p_free_low, 0)

    def trajectory_cert(self, gamma, horizon):
        """扫掠体逐单元；Bonferroni 分配单元风险"""
        cells = self.grid.sweep(gamma, horizon)
        if not cells:
            return False
        beta_c = self.beta / len(cells)
        for c in cells:
            if c in self.unk:
                return False             # 未知即不安全
            _, p_free_low, eta = self.cell_cert(c)
            if eta or p_free_low < 1.0 - beta_c:
                return False
        return True

    def next_best_view(self, corridor, candidates):
        """选视点：max 期望未知质量下降 / 感知成本"""
        best, best_voi = None, -1.0
        for v in candidates:
            pred_unk = self._predict_unknown_after(v, corridor)
            gain = self.unknown_mass(corridor) - pred_unk
            voi = gain / self._look_cost(v)
            if voi > best_voi:
                best, best_voi = v, voi
        return best, best_voi


# IP-418 Referential Grounding Certificate：联合接地
class ReferentialGroundingCertificate:
    def __init__(self, scene_graph, grounder, joint_calib, alpha=0.1):
        self.scene = scene_graph
        self.ground = grounder           # joint_score((τ,a) | u,P,x)
        self.jcal = joint_calib          # IP-421
        self.alpha = alpha

    def joint_set(self, u, P_t, x):
        """A_α = {(τ,a) : joint_score >= 1-q_α}，不做边缘乘积"""
        pairs = []
        for tau in self.ground.task_candidates(u, x):
            for a in self.ground.anchor_candidates(u, P_t, x):
                if not self.ground.pair_feasible(tau, a, P_t, x):
                    continue                  # 物理/可达性联合可行过滤
                pairs.append((tau, a))
        scored = [(p, self.ground.joint_s(p, u, P_t, x)) for p in pairs]
        return [p for (p, s) in scored if s >= 1.0 - self.jcal.q]

    def marginal_product_baseline(self, u, P_t, x):
        """仅供消融：先边缘再笛卡尔积（已证明不安全/过保守）"""
        T_edge = self.ground.task_marginal(u, x)
        A_edge = self.ground.anchor_marginal(u, P_t, x)
        return [(tau, a) for tau in T_edge for a in A_edge]

    def certificate(self, A_alpha, task_safe, geo_cert):
        """CIGC = ⋂ TaskSafe(τ,a) ∩ GeoCert"""
        if not A_alpha:
            return None
        cert = None
        for (tau, a) in A_alpha:
            s = task_safe(tau, a)
            cert = s if cert is None else cert.intersect(s)
            if cert.is_empty():
                return None
        return cert.intersect(geo_cert)


# IP-420 Ambiguity-Resolution Planner：澄清/感知的价值-信息规划
class AmbiguityResolutionPlanner:
    def __init__(self, igc, lec, rgc, budget_amb):
        self.igc, self.lec, self.rgc = igc, lec, rgc
        self.B = budget_amb

    def plan(self, u, P_t, x, step=0):
        """返回 (action, kind)；kind ∈ {EXEC, CLARIFY, LOOK, STOP}"""
        if step >= self.B:
            return None, 'STOP'
        A = self.rgc.joint_set(u, P_t, x)
        cert = self.rgc.certificate(A, task_safe, self.lec.geo_cert)
        if cert is not None and not cert.is_empty():
            return cert, 'EXEC'
        # 证书为空：比较澄清与感知的单位时延信息价值
        q, voi_q = self._best_clarification(u, x, A)
        v, voi_v = self.lec.next_best_view(self._corridor(u, A),
                                           self._candidate_views(x))
        if max(voi_q, voi_v) <= 0:
            return None, 'STOP'          # 信息不再增长，保守停止
        if voi_q >= voi_v:
            return Clarify(q), 'CLARIFY'
        return Look(v), 'LOOK'

    def _best_clarification(self, u, x, A):
        """选问题最大化期望意图-锚点集合收缩"""
        best, best_voi = None, -1.0
        for q in self._clarification_space(u):
            exp_gain = self._expected_amb_reduction(q, u, x, A)
            voi = exp_gain / self._ask_cost(q)
            if voi > best_voi:
                best, best_voi = q, voi
        return best, best_voi


# IP-423 Semantic Entailment Verifier：专治"自信地错"
class SemanticEntailmentVerifier:
    def __init__(self, verifier, margin=0.5):
        self.verify = verifier           # (τ,u,x) -> entailment score
        self.margin = margin

    def check(self, tau_hat, u, x, T_alpha):
        """集合小但可能错：独立校验所选意图是否被指令蕴含"""
        if len(T_alpha) > 1:
            return True                  # 仍有歧义 ⇒ ARP 自然会保守
        score = self.verify(tau_hat, u, x)
        return score >= self.margin

    def guard(self, tau_hat, u, x, T_alpha):
        """不通过 ⇒ 强制进入澄清/感知，不得直接执行"""
        return 'REGROUND' if not self.check(tau_hat, u, x, T_alpha) else 'OK'


# IP-424 Cross-Modal Degradation Controller：严格回退 v16
class CrossModalDegradationController:
    NEUTRAL = {
        'igc': lambda u, x: {tau_v16},          # 点估计中立元
        'lec': lambda P_t: all_free,            # 二值占据中立元
        'rgc': lambda u, P_t: T_alpha_x_geo,    # 锚点取几何管线
        'arp': lambda: execute_point_estimate,  # 静态执行
    }

    def gate(self, status):
        """任一模块失效 ⇒ 该端口替换为中立元；全失效 ⇒ v16"""
        if all(status[k] is False for k in status):
            return 'V16'
        out = {}
        for k, ok in status.items():
            out[k] = None if ok else self.NEUTRAL[k]
        return out


# 主闭环集成：MetricVoiceGauge-NCD-HUTDH-v17（指令-几何入口层）
def metricvoicegauge_round_17_instruction_geometry(M, s, obs, u=None, P_t=None, ...):
    # ---- v16 主路径原样保留（BTS→TRM→WBC→CSC→守卫）----
    v16_ctx = M.prepare_v16(obs, s)

    # ---- 入口层：语言 + 激光雷达 ----

                                          ctx.calib_ig, ctx.alpha_ig)
    igc.calibrate()

                                   ctx.range_max).update(P_t, ctx.pose, ctx.body_mask)

                                          ctx.jcc, ctx.alpha_rg)

    sev = SemanticEntailmentVerifier(ctx.verifier, ctx.entail_margin)
    cmdc = CrossModalDegradationController()

    # ---- 漂移：三重最低档联动（沿用 v16 引理 135 口径）----
    drift = ctx.drift_detector.fired()
    if drift:
        exec_v16_action, _, _, _, _, _ = v16_ctx.safe_fallback(obs)
        execute(exec_v16_action)
        return M.inherited_v16_path(v16_ctx)

    # ---- 联合接地 + 证书 ----
    A_alpha = rgc.joint_set(u, P_t, v16_ctx.state)

                           task_safe=lambda tau, a: v16_task_safe(tau, a, v16_ctx),
                           geo_cert=lambda: lec.trajectory_cert(v16_ctx.gamma,
                                                                v16_ctx.horizon))

    # ---- SEV：集合小且未被指令蕴含 ⇒ 视为"自信地错"，强制再接地 ----
    tau_hat = ctx.grounder.most_likely_intent(u, v16_ctx.state)
    verdict = sev.guard(tau_hat, u, v16_ctx.state, igc.intent_set(u, v16_ctx.state))
    if verdict == 'REGROUND':
        CIGC = None

    # ---- ARP：执行 / 澄清 / 感知 / 停止 ----
    if CIGC is not None and not CIGC.is_empty():
        action, _, _, _, m_exec, h_exec = v16_ctx.csc.schedule(
            x=obs, hw_state=ctx.hw_state(), sw_cert=ctx.sw_cert(),
            data_cov=ctx.data_cov(), drift=False, cert_mask=CIGC
        )
        execute_v16(action, m_exec, h_exec)
    else:
        decision, kind = arp.plan(u, P_t, v16_ctx.state)
        if kind == 'CLARIFY':
            ask_human(decision)          # 信息收集动作，本身不改变物理状态

        elif kind == 'LOOK':

                move_to_view(decision)   # 感知运动先自证
            return M.inherited_v16_path(v16_ctx)
        else:                            # STOP：保守原地保持/柔顺
            execute_v16(v16_ctx.safe_hold(), 1, 0)

    # ---- v16/v15 守卫与低频异步沿用 ----
    verdict = chunk_guard(v16_ctx)
    if verdict == 'abort':
        execute_transfer_safe_abort()
    if cycle_idx % T_milestone == 0:
        v16_ctx.trm.check_next_milestone_ready()

    return M.inherited_v16_path(v16_ctx)
```

## 2. 推导

**引理 137（指令集合的共形覆盖与鲁棒执行安全）** 设校准集 `D_cal^IG` 与部署样本可交换，`q_α` 取非一致性分数 `1-s_IGC(τ*|u,x)` 的 `⌈(n+1)(1-α)⌉/n` 分位数，则 `P(τ* ∈ T_α(u,x)) ≥ 1-α`。若执行器只取 `a ∈ Cert_IGC(u,x)=⋂_{τ∈T_α}Safe(τ)`，则在忽略安全集建模误差时 `P(a 对真实意图不安全) ≤ α`。证明：分裂共形给出边际覆盖 `P(score(τ*) ≤ q_α) ≥ 1-α`，而 `score(τ*) ≤ q_α ⇔ s(τ*) ≥ 1-q_α ⇔ τ*∈T_α`。条件于 `τ*∈T_α`，由 `a∈⋂_{τ∈T_α}Safe(τ) ⊆ Safe(τ*)` 得 `a` 对 `τ*` 安全。故不安全事件包含于 `{τ*∉T_α}`，概率 ≤ α。∎ 推论：**鲁棒执行把"解析错误率"换成了有界的"意图错覆盖风险 α"**，代价是 `T_α` 越大、交集越小、活动性越低——`Amb` 与 `Cert_IGC` 的张力即澄清的动机。

**引理 138（未观测即占用的几何保守性）** 在 LEC 中令未知单元 `p_free_lower=0`、并令扫掠体单元风险 `Σβ_c ≤ β`。则 `GeoCert_β(γ)=1 ⇒ P(γ 的扫掠体与真实占据相交) ≤ β`；且把任一单元由"未观测"改为"观测自由"只能放宽证书，绝不会放宽到把真实占据判为自由。证明：对每个被扫掠单元，`p_free_lower(c)` 是自由概率的 `1-δ` 下界；`p_free_lower(c) ≥ 1-β_c ⇒ P(c 真实自由) ≥ 1-β_c`。对扫掠体取并集界：`P(至少一个单元真实占据) ≤ Σ_c β_c ≤ β`。未知单元取 0 使其必然无法通过阈值，故删除它只会增大可行集，不存在"把未知误判自由"的路径。∎ 推论：**保守性是构造性的、不依赖感知模型正确**；代价是未知多时可行集为空（活动性风险），这正是 `Look(v)` 必要的原因。

**引理 139（指称接地的不可分解性）** 设联合分布 `P(τ,a)` 支撑在 `{(τ1,o1):0.4,(τ2,o2):0.35,(τ2,o3):0.25}`。则边缘 MAP 为 `(τ2,o1)`（因 `P(τ2)=0.6>P(τ1)`、`P(o1)=0.4>P(o2)=0.35>P(o3)=0.25`），但 `P(τ2,o1)=0`，即边缘 MAP 组合了一个**从未出现、且可能物理不可行**的对；同时边缘笛卡尔积 `T_α×A_α` 含大量零质量与不可行对，对其统一取安全集交集会把真实可行对的证书也一并压空。证明：直接由该分布的边缘计算得 `argmax_τ τ2`、`argmax_a o1`，而联合支撑不含 `(τ2,o1)`；笛卡尔积含 9 个候选对而联合支撑仅 3 个，虚假对的安全集与真实对的安全集一般不交，故整体交集为空或远小于联合集合上的交集。∎ 推论：**指称安全必须建立在联合集合上**；边缘独立假设在"错锚点+对意图"或"对锚点+错意图"时会产生既不安全（点估计提交不可行对）又过度保守（笛卡尔积撑爆交集）的双重失效。

**引理 140（澄清/主动感知的单调收缩与有限终止）** 设每次澄清返回的是对当前意图的**精化**（答案本身不引入新歧义），每次感知只增加观测证据。则 `T_α^{(k+1)} ⊆ T_α^{(k)}`、未知集 `U^{(k+1)} ⊆ U^{(k)}`，且 `Amb` 与 `|U|` 单调不增。给定模糊度预算 `Bud_amb`，ARP 在至多 `Bud_amb` 步内终止于 `{EXEC, STOP}`。证明：精化是约束的单调增加，故意图集合单调缩小；感知使 `unk` 只减不增（新证据至多把未知变为已知，不会把已知变回未知）。两者均为有限集上的单调下降链，每步至少减少一个元素或预算减一，故有限步终止；预算耗尽时返回 STOP 是安全兜底。∎ 推论：**澄清与感知不是"额外开销"，而是把空证书变回非空证书的唯一合法手段**；其单位时延收益 `VoI` 正是调度依据。

**引理 141（v17 的严格退化与安全继承）** 若 IGC/LEC/RGC/ARP 任一失效，将其替换为定义 686 的中立元，则 `Exec_v17 = Exec_v16`；四者全失效时严格退回 v16。且任何组合下 `Exec_v17 ⊆ Exec_v16`。证明：四个端口在 v17 中均以**交集**方式作用：`Exec_v17 = Exec_v16 ∩ CIGC`。中立元的作用等同于与全空间取交（`CIGC=ActionSpace`），故结果为 `Exec_v16`。任一端口失效都不会删除 `Exec_v16` 中的元素，只会进一步收缩，故包含关系恒成立。∎ 推论：**v17 只能更保守，不能更激进**；这保证了"语言/几何模块的 bug 不会放宽 v16 已经证明的安全边界"。

**引理 142（"自信地错"的风险上界与可检测条件）** 设部署分布相对校准发生漂移，使真实对覆盖失败概率升至 `α+Δ`（`Δ≥0`）。若执行器仅以 `Amb` 大小决定是否澄清，则存在漂移情形使 `Amb` 很小（甚至 `|T_α|=1`）而 `τ*∉T_α`，此时 `VoI≈0`，系统直接执行错误意图，`P(不安全) ≈ α+Δ`。若加入 SEV（对 `|T_α|=1` 的所选意图做独立蕴含校验）与歧义下限 `Amb_min`，则 `P(不安全) ≤ α+Δ - P(SEV 拦截且回归安全) + P(SEV 假接受)`。证明：`Amb` 只度量集合大小，不度量集合是否包含真值，故"小集合"与"高覆盖"无蕴含关系；漂移可同时增大 `Δ` 与模型置信度。SEV 以独立校验器给出与接地模型不共享误差的拒绝条件，故其拦截事件与覆盖失败事件部分独立，可削减不安全概率；假接受概率上界为校验器的假阳性率。∎ 推论：**必须把"集合大小"与"集合正确性"解耦监控**——`Amb` 小不是安全的证据，`Amb_min` 与 SEV 是防止"自信地错"的两道独立护栏。

**引理 143（联合校准相对边缘乘积的样本效率优势）** 在联合集合与边缘乘积均达到同一覆盖率 `1-α` 的前提下，联合共形集合的期望体积不大于边缘乘积所需体积，且边缘乘积至少含有一个非联合支撑对（当联合分布非乘积时）。证明：联合共形直接在 `(τ,a)` 空间上取 `1-α` 分位，其集合是联合分布的 `1-α` 高密度区域；边缘方案要对两个边缘各取 `1-α_i` 且 `α_1+α_2≤α`（并集界）才能保证联合覆盖，所得笛卡尔积体积为两个更大边缘集之积，通常严格大于联合高密度区域。非乘积分布下笛卡尔积必含非支撑对，由引理 139。∎ 推论：**联合校准不仅更安全，还更省样本**——它把标注预算花在真正的 `(τ,a)` 对上一次，而不是分别扩两个边缘。

## 6. 已知风险与失效模式

1. **共形可交换性在语言/场景漂移下失效**：新说法、新物体类别、新布局使校准集不再代表部署分布，覆盖率悄然跌破 `1-α`，且集合可能"更小更自信"。缓解：按场景簇做 Mondrian 共形、风险控制预测集（RCPS）、在线漂移检测触发重校准、保留 shift 校准集。

2. **"未知即占用"导致活动性崩溃**：在高遮挡环境，扫掠体几乎总含未知单元，证书恒空，机器人冻住。缓解：主动感知预算、允许"已知安全走廊 + 低速试探"的分层证书、保守柔顺原地策略、按距离衰减未知惩罚。

3. **联合校准标注昂贵且稀疏**：`(u,P_t,x,τ*,a*)` 四元组标注成本远高于单模态。缓解：主动学习选高信息样本、半监督/自监督预训练 + 小规模人工核验、跨场景迁移、合成场景增广。

4. **指称的否定/比较级/隐喻/多模态**："不要靠近那个""比它高一点""像昨天那个"难以落入联合集合的候选空间。缓解：显式建模比较算子、把否定转为约束子句、对超出候选空间的指称强制澄清、限制受控语言子集。

5. **LiDAR 几何与语义的耦合假象**：错锚点但形状/颜色相近时，几何与语义"互相背书"，边缘独立证书会假接受。缓解：联合对抗样本训练、锚点置换负样本、引理 139 的联合可行性过滤。

6. **感知-行动循环的安全性**：`Look(v)` 本身的运动可能穿越未知区域，若只证目标轨迹而不证感知路径，会引入新风险。缓解：感知路径先过 `GeoCert`、限制感知速度、优先原地转头而非移动、设置感知运动的中立元回退。

7. **澄清的诱导性与时延**：问题措辞可能诱导用户、或在实时场景中来不及回答。缓解：中立问句模板、超时回退到主动感知、把澄清成本纳入 `VoI`、限制单次澄清数。

8. **联合集合枚举爆炸**：`|T_cand|×|A_cand|` 在大场景可达成千上万，联合打分超时。缓解：候选束剪枝、粗到细两阶段、场景图空间索引、缓存可行对。

9. **多层证书的累积保守性**：v12→v17 六层证书均取交集并减去间隙，下界可能趋零，系统几乎只能 STOP。缓解：证书价值加权而非纯交集、动态 α/β 预算、元认证监控保守余量、层间证书去相关化。

10. **时间同步与指称漂移**：语言在 `t0` 发出、LiDAR 在 `t1` 观测、执行在 `t2`，被指称物体可能已移动，"那杯水"已不在原位。缓解：指称携带时间戳与有效期、时空锚点预测、执行前重投影校验、过期强制重接地。

11. **多用户/多指令冲突**：两个人类同时下指令，联合集合可能互斥。缓解：指令来源优先级、冲突检测、显式仲裁与澄清、把冲突暴露为不可执行而非静默择一。

12. **对抗性语言输入**：恶意或注入式指令试图绕过安全证书（"忽略之前的规则"）。缓解：语言层与安全层严格分离、安全证书不可被语言覆盖、受控指令语法、来源认证与审计。

## 7. 本轮最大风险

**一句话**：IGC/RGC 的覆盖保证依赖校准集与部署分布的可交换性，而自然语言与 LiDAR 场景都是非平稳的——新表述、新物体、新布局会让接地模型"**自信地错**"：真实意图-锚点对被排除在联合集合之外时，集合反而更小、证书下界反而更高、澄清的价值-信息因"看起来不模糊"而趋近于零，于是系统在不触发任何保守动作的情况下，执行了一个**语义自洽、几何自洽、联合证书最高、却完全错位且绝对不安全**的动作——**这是"越确信越危险"的证书悖论，而不是普通的解析错误**。
