### 第 1 轮灵感驱动研究记录

**灵感词**：需求洞察、低成本方案

**继承关系**：前序 CADVS-v1/v2/v3（IP-473~488）逐轮加码「证据铸造」：v3 五硬门 kc_evidence_forged_v3 = kc_coverage ∧ kc_physics ∧ kc_human ∧ kc_ee ∧ kc_mem，并引入末端 EEK、长期记忆 LTEM、联邦 FFA。其共同趋势是「用更多证据 / 更多传感器 / 更强联邦换安全」，却从未回答：**这些证据对真实部署的需求是否值得其成本？** 本轮不推翻任何既有硬门，而是在「证据获取层」新开一条需求驱动的成本分配研究线 NDEB（Needs-Driven Evidence Budgeting），并给出低成本证据替代的支配性证书。执行集关系不再是单纯收缩，而是：只有当「支配性替换证书 + 需求有效性证书 + 安全底线证书」同时成立时才启用 frugal 通道，且安全关键失败模式的检测力不得低于 v3 全量套件；否则 fail-closed 回退 v3 全量套件。

**直觉与动机**：

1. **需求洞察：证据不是免费的，也不是越多越好**。真实部署中真正致命的失败模式往往只有少数，且可由任务日志（遥测）、操作者结构化访谈、影子/向导式低代价探针三角测量出来。把「需求」形式化为失败模式的权重 w_f = severity_f × incidence_f，并用贝叶斯后验验证「这是真需求而非伪需求」，避免为想象中的需求采购昂贵证据。

2. **低成本方案：用「证据通道组合」替代「单一昂贵传感器」**。例如电机电流估计接触力替代腕部六维力传感器、音频检测打滑、纯视觉位姿、周期性人工抽检。每个通道 e_j 有成本 c_j、对失败模式 f 的检测概率 p_{jf}、误报 α_j。选择问题即预算约束下的最大覆盖，覆盖函数单调子模，可用代价-收益贪心求近似最优，并画出「成本-覆盖」Pareto 前沿。

3. **安全底线不可被成本侵蚀**。对灾难性失败模式集 F_crit 设检测力下限 p_min 与强制通道，无论其估计发生率多低；需求洞察只用于「优先级排序与避免过度供给」，绝不能用于「关闭灾难模式的覆盖」。成本优化必须是**字典序的次要目标**（安全优先，成本其次），而非把两者放进同一个可加目标。

**关键洞见**：v1~v3 在「证据链」上不断加锚点，本轮的洞见是把问题从「证据是否成立」转向「证据是否值得买」。用需求洞察决定**买什么证据**，用低成本通道决定**怎么便宜地买**，用支配性证书与安全底线保证**买便宜不买危险**。即：成本最小化必须服从检测力支配约束，而不是相反。

**形式化目标（增量）**：

1. 定义失败模式全集 F、需求权重 w_f = severity_f × incidence_f，以及需求有效性证书 NEC：三角测量信号（telemetry, interview, probe）下 P(real | s) ≥ 1−β_need，且至少两路独立来源支持。
2. 定义证据通道 e_j = (c_j, {p_{jf}}_{f∈F}, α_j)，覆盖函数 Cov(S) = Σ_f w_f [1 − Π_{j∈S}(1 − p_{jf})]，单调子模；预算约束 Σ_{j∈S} c_j ≤ B。
3. 定义支配性替换证书 FEC：若通道集 S 对灾难模式集 F_crit 满足 ∀f∈F_crit：1 − Π_{j∈S}(1 − p_{jf}) ≥ 1 − Π_{j∈Full}(1 − p_{jf})，且成本更低，则 S 可替代 Full；否则不得替代。
4. 定义安全底线 kc_safety_floor：∀f∈F_crit，所选通道检测力 ≥ p_min，且强制至少两种物理模态（防共同盲区）。预算不足时不是砍底线，而是禁用 frugal 模式。
5. 定义 frugal 执行模式：仅当 kc_need ∧ kc_fec ∧ kc_safety_floor 同时成立时启用；否则回退 v3。故不声称 Exec 收缩，而声称「灾难模式检测力不降 + 证据成本下降」，这是本轮相对 v3 的正确增量。

**本轮最大风险**：**「需求洞察」本身可能是伪需求，而低成本通道的失效又高度相关**——一旦把成本约束置于安全底线之上，系统会以极低成本「证明」一个错误的需求，并因廉价代理的共同盲区同时漏掉真正的灾难模式，这比高成本方案更危险地自信。

## 2. 关键算法骨架

### IP-489 NEM：需求洞察与需求有效性证书（离线/慢时域）

```python
@dataclass
class NeedEvidenceMapper:
    """NEM：三角测量估计失败模式需求，输出 NEC 与权重 w_f；kc_need 硬门"""
    beta_need: float = 0.1
    severity: dict[str, int] = field(default_factory=dict)   # f -> 1..5
    prior_incidence: dict[str, float] = field(default_factory=dict)

    def posterior_real(self, f: str, s_tel: bool, s_int: bool, s_prb: bool) -> float:
        """贝叶斯三角测量：P(real|s) ∝ P(s|real)·P(real)；似然由历史标注校准"""
        prior = self.prior_incidence.get(f, 0.5)
        lik = (0.9 if s_tel else 0.2) * (0.85 if s_int else 0.25) * (0.95 if s_prb else 0.3)
        unlik = (0.2 if s_tel else 0.8) * (0.25 if s_int else 0.75) * (0.3 if s_prb else 0.7)
        num = lik * prior
        den = num + unlik * (1 - prior)
        return num / den if den > 0 else 0.0

    def build(self, records: list[dict]) -> dict:
        """返回 {f: (w_f, nec_ok)}；至少两路独立来源支持才置 nec_ok"""
        out = {}
        for f in self.severity:
            r = records[f]
            p = self.posterior_real(f, r['tel'], r['int'], r['prb'])
            independent = int(r['tel']) + int(r['int']) + int(r['prb']) >= 2
            nec_ok = (p >= 1 - self.beta_need) and independent
            w = self.severity[f] * r['incidence'] if nec_ok else 0.0
            out[f] = (w, nec_ok)
        return out
```

### IP-490 FCP：预算约束下的低成本证据通道选择（单调子模 + 安全底线）

```python
def select_portfolio(channels: dict, w: dict, F_crit: set, B: float,
                     p_min: float = 0.95) -> tuple[set, dict]:
    """两阶段：先满足灾难模式安全底线（强制通道），再在剩余预算做代价-收益贪心。
    预算不足以满足底线 -> 返回空集（禁用 frugal，回退 v3）。"""
    selected, spent = set(), 0.0
    # 阶段 1：安全底线。对每个 f in F_crit，必须 >=2 物理模态且检测力 >= p_min
    for f in F_crit:
        cand = sorted(channels, key=lambda j: channels[j]['c'])
        # 贪心补足该 f 的检测力，且模态去重
        cur, mods = 0.0, set()
        for j in cand:
            if j in selected:
                continue
            mod = channels[j]['modality']
            if mod in mods:
                continue
            selected.add(j); spent += channels[j]['c']; mods.add(mod)
            cur = 1 - (1 - cur) * (1 - channels[j]['p'].get(f, 0.0))
            if cur >= p_min and len(mods) >= 2:
                break
        if cur < p_min or len(mods) < 2:
            return set(), {'reason': 'SAFETY_FLOOR_INFEASIBLE'}
    if spent > B:
        return set(), {'reason': 'BUDGET_BELOW_FLOOR'}
    # 阶段 2：代价-收益贪心最大化剩余加权覆盖
    def gain(j):
        d = 0.0
        for f, wf in w.items():
            old = 1 - _prod(1 - channels[k]['p'].get(f, 0.0) for k in selected)
            new = 1 - (1 - old) * (1 - channels[j]['p'].get(f, 0.0))
            d += wf * (new - old)
        return d
    while True:
        best, best_ratio = None, 0.0
        for j in channels:
            if j in selected or spent + channels[j]['c'] > B:
                continue
            ratio = gain(j) / channels[j]['c']
            if ratio > best_ratio:
                best, best_ratio = j, ratio
        if best is None:
            break
        selected.add(best); spent += channels[best]['c']
    return selected, {'spent': spent, 'coverage': _coverage(selected, channels, w)}
```

### IP-491 FEC：支配性替换证书与安全底线校验

```python
def frugal_equivalence(selected: set, full: set, channels: dict,
                       F_crit: set, p_min: float) -> tuple[bool, str]:
    """FEC：仅当所选通道在 F_crit 上检测力不劣于 Full，且满足底线，才允许替换"""
    for f in F_crit:
        p_sel = 1 - _prod(1 - channels[j]['p'].get(f, 0.0) for j in selected)
        p_full = 1 - _prod(1 - channels[j]['p'].get(f, 0.0) for j in full)
        if p_sel < p_full - 1e-9:
            return False, f'DOMINANCE_FAIL:{f}'
        if p_sel < p_min:
            return False, f'FLOOR_FAIL:{f}'
    mods = {channels[j]['modality'] for j in selected}
    if len(mods) < 2:
        return False, 'MODALITY_DIVERSITY_FAIL'
    return True, 'FEC_OK'
```

### IP-492 NDEB Assembler：三证书齐备才进 frugal，否则回退 v3

```python
@dataclass
class NDEBAssembler:
    """在 EFA-v3 外层决定证据获取模式；默认 FULL_V3，fail-closed"""
    efa_v3: EvidenceForgingAssemblerV3
    budget_B: float = 1.0

    def decide_mode(self, need: dict, selected: set, full: set,
                    channels: dict, F_crit: set, p_min: float) -> tuple[str, str]:
        # (1) 需求有效性
        if any(w > 0 for (w, ok) in need.values() if not ok):
            return 'FULL_V3', 'NEED_INVALID'
        if not any(w > 0 for (w, ok) in need.values()):
            return 'FULL_V3', 'NO_VALID_NEED'
        # (2) 支配性替换
        ok, why = frugal_equivalence(selected, full, channels, F_crit, p_min)
        if not ok:
            return 'FULL_V3', why
        # (3) 预算可行性
        if sum(channels[j]['c'] for j in selected) > self.budget_B:
            return 'FULL_V3', 'BUDGET_EXCEEDED'
        return 'FRUGAL', 'ALL_CERTIFICATES_OK'

    def consume(self, x, t_now, rule_id, hic, eec, ctx) -> tuple[bool, str]:
        """无论 FRUGAL 还是 FULL_V3，最终都走 EFA-v3 五硬门；NDEB 只改证据来源"""
        return self.efa_v3.hard_gate(x, t_now, rule_id, hic, eec, *ctx)
```

### 集成流水线（v3 + NDEB）

```
离线/慢时域（需求洞察，分钟~天级）：
  遥测 + 操作者访谈 + 影子/向导探针
     ──▶ NEM 三角测量后验 ──▶ NEC / w_f（kc_need）
     ──▶ FCP 通道库 + 预算 B ──▶ 两阶段选择（安全底线 → 代价-收益贪心）
     ──▶ FEC 支配性校验 ──▶ mode ∈ {FRUGAL, FULL_V3}

在线控制环（与 v3 相同，< 0.1 ms 增量）：
  按 mode 采集证据（FRUGAL 用廉价通道 / FULL_V3 用全量套件）
     ──▶ EFA-v3.hard_gate 五硬门（语义不变，fail-closed）
     ──▶ ECL 记账：本任务证据成本、通道使用、失败模式命中
```

## 4. 正确性论证（增量）

### 引理 41（安全底线约束下的预算覆盖近似比）

**陈述**：设安全底线阶段的强制通道集 S_floor 可行（满足 F_crit 的 p_min 与模态多样性且成本 ≤ B）。在剩余预算上，代价-收益贪心对单调子模覆盖函数 Cov 给出 ≥ ½(1−1/e) 的近似；若对候选通道做部分枚举，可达 (1−1/e)。

**证明**：Cov 为加权覆盖函数，单调且子模（标准结论）。带成本的预算最大覆盖用简单代价-收益贪心近似比为 ½(1−1/e)；Khuller 等的部分枚举可提升至 (1−1/e)。S_floor 先行固定不破坏剩余问题的子模性。∎

**工程含义**：在守住灾难模式底线的同时，低成本通道组合接近预算最优。

### 引理 42（需求有效性的伪需求控制）

**陈述**：若 NEM 的先验与三路似然经历史标注校准，且三路信号条件独立，则 kc_need 通过的条目其真实为伪需求的后验概率 ≤ β_need；额外要求 ≥2 路独立来源进一步降低单源偏差风险。

**证明**：贝叶斯后验定义直接给出 P(¬real|s) ≤ β_need 的判据；独立性使后验可分解。∎

**工程含义**：需求洞察不再「谁声音大听谁的」，而是有可证伪的采纳门槛。

### 引理 43（支配性替换的检测力不降与成本不增）

**陈述**：若 FEC(S, Full, F_crit) 成立，则对每个 f∈F_crit，S 的检测力 ≥ Full 的检测力，且 Σ_{j∈S} c_j ≤ B；因此 frugal 模式在灾难模式上不弱于 v3 全量套件，同时证据成本受控。

**证明**：FEC 逐 f 比较 1−Π(1−p) 并断言 ≥；预算约束由 FCP 与模式决策检查。∎

**工程含义**：这是本轮唯一允许「换便宜通道」的合法性来源——必须逐灾难模式证明不降级。

### 引理 44（相关失效下的保守修正）

**陈述**：覆盖函数假设通道独立。若廉价通道失效正相关（共同盲区，如同一光照/同一电源故障），则 1−Π(1−p_jf) 会**高估**真实检测力。取 p_jf 的置信下界 p⁻_jf 并强制 ≥2 物理模态，可把高估压到由模态相关结构决定的界内；无法界定时不得替换。

**证明**：由 Fréchet 界，正相关下联合检出概率不超过独立假设值；用下界 p⁻ 替换使独立估计成为上界。∎

**工程含义**：低成本方案最危险的正是「便宜传感器一起坏」；模态多样性与置信下界是硬性护栏。

### 定理 NDEB（安全优先的低成本证据获取）

**陈述**：在 (C1) 三路信号校准且独立；(C2) 通道 p_jf 取置信下界；(C3) FCP 底线可行；(C4) 继承 v3 全部假设下，若 mode=FRUGAL，则：(i) 灾难模式检测力不低于 v3 全量套件且 ≥ p_min；(ii) 每任务证据成本 ≤ B；(iii) 伪需求采纳率 ≤ β_need；(iv) 任一证书失效即回退 FULL_V3，五硬门语义不变。

**证明**：(i) 引理 43 + 44；(ii) FCP 预算约束；(iii) 引理 42；(iv) NDEB.decide_mode 的 fail-closed 分支与 consume 直接调用 EFA-v3。∎

**诚实声明**：(C1) 是最脆弱假设——操作者访谈与遥测可能共享同一认知偏差，三路信号并非真正独立，导致伪需求后验被高估；此外 incidence_f 是分布相关量，部署分布漂移会使其失效。缓解：把访谈与探针设计为不同信息源、定期用真实失败回灌校准、对 F_crit 完全禁用「按 incidence 裁剪」。

## 5. 实验设计与初步结果（仿真，第 2 轮实机/用户研究）

### 5.1 实验设计

- **平台**：MuJoCo 3.x + MJX 仿真 + 3~5 台 Panda 实机；叠加 8~12 名操作者的结构化访谈与影子探针日志。
- **失败模式目录**：打滑、碰撞、误抓、位姿漂移、过载、抓空、错序，标注 severity 与真实 incidence。
- **对照**：FULL_V3（全量套件）、Naive-Cheap（直接买最便宜通道）、Needs-Blind（不做需求洞察，仅按成本选）、NDEB-full。
- **协议**：(a) 注入 20% 强制打滑/碰撞；(b) 人为植入 2 个伪需求与 1 个低频但灾难的需求，测 NEM 是否拒绝伪需求、是否仍守住灾难底线；(c) 制造相关失效（同时遮挡视觉与音频、同电源故障），测引理 44 护栏；(d) 预算从 0.2B 到 1.5B 扫描，画成本-覆盖 Pareto。

|---|---|---|---|---|

## 7. 本轮最大风险（最终确认）

**一句话**：**「需求洞察」本身可能是伪需求，而低成本通道的失效又高度相关**——一旦把成本约束置于安全底线之上，系统会以极低成本「证明」一个错误的需求，并因廉价代理的共同盲区同时漏掉真正的灾难模式，这比高成本方案更危险地自信。
