# 第 69 轮（承接第 68 轮「CALM-RAS 自标定风险自适应闭环」IP-243~252；灵感循环新循环第 2 轮；本轮灵感：「用户画像」×「嵌入式系统」）

> 第 68 轮 CALM-RAS 把「测量可信度」补成了计量层，却仍默认了两件事：**人是一个固定外部观察者**（风险先验 λ、情绪阈值、交互方式对所有人通用），以及**算力是云端级、永远在线、可随时重训的**（500MB 影子流、60s 一次认证提交）。这两个默认恰恰是真实部署中最后两个未被建模的潜变量：**服务对象的画像**，和**承载算法的嵌入式平台**。前者决定「同样的动作对谁更危险」，后者决定「哪些安全承诺在 10W、硬实时、十年寿命、无网、要认证的板子上能兑现」。
>
> 本轮灵感给出的核心命题：
>
> **把「用户」升级为与标定同构的一等公民潜变量，但赋予它单向权威——画像只能调整舒适与交互，绝不允许放宽安全；再用嵌入式「安全岛 / 画像岛」双核隔离把这条纪律变成物理约束（ROM 安全参数 + 单向只紧信箱 + WCET 证明），并让端侧本地化同时成为隐私与可认证性的来源。**
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「**我是为谁在做，以及这块板子到底能保证什么**」——人与平台，是闭环最后两个未被建模的潜变量。

## 0. 直觉与动机

**灵感 1（用户画像 → 风险不是一个标量，而是「谁的风险」）**
直觉：R68 的 λ_risk 是一个全局标量，但同一个「快速伸手」对训练有素的工人、术后康复老人、儿童，风险完全不同；同一句提醒，对焦虑型用户是安抚、对听障用户是无效。画像的价值在于把「人群平均的先验」换成「这个人的后验」。但画像也是双刃剑：一旦它被允许解释异常，它就会变成万能消音器——「他不是没反应，他只是慢性子」「她不是能力下降，她只是偏好慢一点」。因此本轮的关键不是「画像得更准」，而是给画像**限定权力方向**：画像只能让机器人更体贴、更保守，永远不能让它更大胆。这与 R68 对「标定」的处理正好构成镜像：标定被限制为「不能吸收快故障」，画像被限制为「不能吸收危险证据」。

**灵感 2（嵌入式系统 → 部署边界不是云端，而是 10W SoC）**
直觉：R68 的「影子训练 + 五关认证 + 原子换装」在服务器上成立，但在机器人本体上是一套跑不动的方案：没有 500MB 影子显存、没有 60s 可以独占的算力窗口、没有稳定的云连接，还要面对硬实时截止期、结温节流、电池预算、十年生命周期和安全认证（IEC 61508 / ISO 26262 / IEC 62304 一类的证据链）。嵌入式不是「把模型压小」这么简单，它逼出一个正确的架构问题：**哪些东西必须不可变、可证明、放在隔离核上；哪些东西可以学、可以个性化、失败了也不伤人。** 答案是把系统拆成两颗「岛」：安全岛只跑不可写的固定点安全核（λ 下限、硬边界、看门狗、急停），画像岛跑可学习的画像与适配器；两岛之间只有一条**只紧不松**的单向信箱。嵌入式约束因此从「障碍」变成「安全边界的物理实现」。

**灵感 3（两灵感合流 → 画像是最像标定的潜变量，嵌入式是最像认证的约束）**
直觉：R68 用「在线潜变量 + 慢动力学 + 可辨识性 + 反吸收界」驯服了标定；用户画像几乎逐条同构——也是一个缓慢演化、只能间接观测、会与环境难度混淆的潜变量。于是可以复用同一套方法论：双时标（稳定画像 / 瞬时状态）、激励可辨识性（需要多样化的交互去「激励」出画像参数）、不确定度驱动的保守化。区别只在权威方向：标定吸收的是测量偏差，画像吸收的是**人的状态**，而人的状态里可能藏着真实的能力衰退或危险征兆，所以画像必须比标定更「不敢解释」。嵌入式则提供了 R68 缺失的东西：**可执行的可信基座**。R68 的纪律写在论文里，R69 把它烧进 ROM、MPU 和 WCET 报告里。

**灵感 4（对 R68 最大风险的对症下药 → 从「慢故障被标定吸收」到「能力衰退被画像吸收」）**
直觉：R68 的原罪是「标定能力越强，缓变故障越隐形」。画像会复制这个原罪，而且更隐蔽：**画像能力越强，真实的能力衰退/危险情境越容易被解释成「用户偏好」**。本轮显式引入两个对策：(a) 归因层加入第五假设 `H_user^cap`（能力衰退）与独立的 CDD（能力衰退检测器），它不走舒适通道，只走「收紧 + 请求复核」通道；(b) 单调似然比约束（MLR）——画像更新只能抬高危险假设的后验，不能压低，从数学上禁止「因为画像所以没事」。

**灵感 5（合流组件 PERSONA-RAS）** 十个部件：
1. **UPM User Profile Model**：双时标画像 `u_t=(s,q_t)`，稳定画像 s 仅在知情同意下变更，瞬时状态 q_t 在线滤波；
2. **NAB Non-Absorbing Boundary**：舒适参数 / 安全参数硬分离 + 单向权威；
3. **SI/PI 双岛**：安全岛（固定点、无堆、WCET 可证、ROM 参数）+ 画像岛（量化 MTM、TPA、加密画像库）；
4. **TPA Tiny Profile Adapter**：每用户 ≤64KB 的低秩适配器 + 原型库，冻结主干、有界更新；
5. **CDD Capability Decline Detector**：单调趋势检验，检出即抬 λ、请求复核，禁止吸收；
6. **PCA Profile-Conditioned Attribution**：在 R68 CFA 上条件于 u，并施加单调似然比约束；
7. **RES Resource-Elastic Scheduler**：能量/热/截止期驱动的单调降级格，安全核永不降级；
8. **OPS On-device Privacy Shield**：原始数据不出端、DP 遥测、同意账本、可验证遗忘；
9. **CGC Consent & Drift Governor**：稳定画像变更需重新同意、反刻板收缩、画像可解释卡片；
10. **RAS† 继承核**：CALM-RAS 的 MTM/COF/CFA/CAC 全部保留，仅被画像与资源层包裹。

## 1. 形式化定义（增量：定义 293–311）

**定义 293（PERSONA-RAS 总览）** PERSONA-RAS = (UPM, NAB, SI/PI, TPA, CDD, PCA, RES, OPS, CGC, RAS†)。四条不变式：
(i) **安全岛不可写**：安全参数 θ_safety 驻留 ROM/OTP，任何学习或画像进程不可写；画像信号只能经单向信箱进入安全岛；
(ii) **画像非吸收**：画像更新不得使任何危险假设的后验低于无画像后验减去 ε_abs；
(iii) **只调舒适**：画像只能改变 Θ_comfort^cert 内的舒适/沟通参数，不得改变安全阈值、λ 下限与认证动作集，除非是收紧；
(iv) **资源单调降级**：任意资源等级下安全岛代码路径、WCET 与不变式完全不变；降级次序中画像适配先于安全功能被卸载。

**定义 294（双时标用户画像）** u_t = (s, q_t)，s ∈ S ⊂ ℝ^{d_s} 为稳定画像（移动能力、感官敏度、沟通偏好、风险容忍、认知负荷特征），q_t ∈ Q ⊂ ℝ^{d_q} 为瞬时状态（疲劳、注意、压力、情绪、工作负荷）。s 分段常数，仅在注册/重新同意事件更新；q_{t+1} = f_q(q_t, o_t) + w_t，w ~ 𝒩(0, Q_u)，τ_q ∈ [10, 10²] s。画像不确定度 U_u = tr(Σ_s) + tr(Σ_q)。

**定义 295（舒适/安全参数分离）** 策略参数 θ = (θ_s, θ_c) ∈ Θ_safety^cert × Θ_comfort^cert。执行策略
π(a | x, u) = π_base(a | x, θ_s, θ_c + Δθ_c(u))，其中 **θ_s ≡ θ_s^cert 恒真**，Δθ_c(u) ∈ C_cert 为认证舒适包络内的投影 `Proj_{Θ_c}(·)`。任何安全相关变换 T_s 只允许返回更紧的策略：T_s(π) ⪯ π。

**定义 296（单向阀 / 非吸收边界 NAB）** 设 m(u) 为任意由画像导出的消息。安全岛更新规则：
λ_{t+1} = max(λ_t, h_λ(m_t))，τ_{t+1} = min(τ_t, h_τ(m_t))（危险阈值只降不升），
且可行动作集 A_adm(u) ⊆ A_adm(∅)。**唯一复位途径**是认证重注册事件（显式知情同意 + 安全复认证 + 新 J_PERSONA），普通画像更新永不扩大动作集。

**定义 297（SI/PI 双岛与单向信箱）** 安全岛 SI：锁步 MCU/隔离核，固定点，<16KB 代码，无堆、无动态分派，WCET 可证，运行 λ 下限、硬边界、看门狗、急停。画像岛 PI：应用 SoC/NPU，INT8/INT4 MTM + TPA + 画像估计，AES-GCM 加密画像库。信箱：PI→SI 仅允许 {TIGHTEN, HEARTBEAT, FAULT_REPORT}；SI→PI 仅 {STATE, DEGRADE_LEVEL}。MMU/MPU 保证 PI 对 SI 内存零写权限。

**定义 298（能力衰退假设与 CDD）** H_user^cap：用户相对其注册画像出现持续、单调的能力下降。证据 e_cap(t) 为任务成功率、反应时、步态稳定性、语音时延等相对画像预测的残差。CDD 用单调趋势/CUSUM 检验，统计量超过 h_cd 即成立；成立时 λ_floor 抬升至 0.9、请求人工复核、**禁止写入舒适通道**。形式目标：幅度 Δ、时程 T_d 的单调衰退在 T_d 内检出概率 ≥ 1−β，误报 ≤ α_cd。

**定义 299（TPA 微型画像适配器）** 每用户 A_u = (L_u, P_u)：trunk 内低秩 LoRA（r=4，4-bit）+ 隐空间原型库（K 个原型）。存储 ≤ 64KB/用户，推理 O(r·d)。更新仅在资源等级 D0/D1 的空闲窗口进行，满足范数预算 ‖ΔA_u‖ ≤ B_a 与每日变化预算；更新前快照、可回滚；冷启动退化为人群先验 A_0。

**定义 300（画像激励与可辨识性）** 交互设计包含 N_e 个需求等级与独立扰动段，Fisher 信息 I_PE = Σ_t φ_t φ_t^T。若 λ_min(I_PE) ≥ λ_0 则称满足 PE 条件，此时 E‖ŝ − s‖² ≤ C·d_s/(N_e·λ_0)。不满足 PE 时 U_u 按随机游走增长，λ_floor 抬升且画像冻结到人群先验——**冷启动是安全但不定制的**。

**定义 301（PCA 画像条件归因，升级 CFA）** 假设集扩为 H = {H_geo, H_model, H_cal, H_sensor^trans, H_user^cap}：
P(H, E, C | ρ, face, ĉ, u) ∝ p(ρ | H, ĉ, u)·p(face | E, ĉ, u)·P(H)·P(E|H)·P(u)。
**单调似然比约束（MLR，定义 311）** 强制画像只能把概率质量推向危险假设：对 h ∈ H_haz，LR_u(h)/LR_∅(h) ≥ 1；对 H_normal，LR_u(H_normal)/LR_∅(H_normal) ≤ 1。标定解释与画像解释可以竞争，但二者都不能压掉对方背后的危险分支。

**定义 302（RES 资源弹性调度与降级格）** 资源等级 d ∈ {D0,D1,D2,D3,D4}：D0 全功能（画像适配 + MTM + WM + CFA）；D1 冻结画像适配（仅推理）；D2 缩短画像时程/原型数并关闭 WM rollout；D3 关闭画像、退回人群先验 + 基础策略 + 安全；D4 安全停机/跛行。调度的优先级：安全核 > 基础控制 > 画像推理 > 画像适配 > 影子学习。单调性：d 随能量/热/WCET 压力单向增加；**对所有 d，C_SI(d)=C_SI^cert 且截止期满足**。

**定义 303（OPS 端侧隐私盾）** 原始传感数据不出端；画像库经安全元件 AES-GCM 加密；任何上传遥测满足 (ε, δ)-差分隐私；同意账本记录目的/范围/期限/撤回；遗忘请求删除适配器、原型与密钥，并满足 (ε_unl, δ_unl)-不可区分于从未注册。禁止跨用户可链接的稳定标识外泄。

**定义 304（CGC 同意与漂移治理）** 稳定画像变更量 ‖Δs‖ > δ_s 触发重新同意；q_t 漂移做变点检测；反刻板采用分层贝叶斯收缩 ŝ_u = (n_u ŝ_u + κ s_pop)/(n_u + κ)，公平约束：受保护群体间舒适分配差 ≤ δ_fair；向用户提供可检查、可更正的画像卡片。

**定义 305（PERSONA 约束优化目标）** min L_MT + λ_p L_profile + λ_c L_consent + λ_r L_robust，s.t. (i) θ_s = θ_s^cert；(ii) MLR；(iii) ‖ΔA_u‖ ≤ B_a；(iv) (ε,δ)-DP；(v) WCET/内存预算。L_profile 预测 q_t 与用户满意度；L_consent 惩罚越界使用；L_robust 取用户子群最坏情况。

**定义 306（AIC-PERSONA 干扰集）** ℰ_PERSONA = ℰ_CALM × ℰ_prof × ℰ_emb × ℰ_priv；ℰ_prof = {刻板锁定、能力衰退吸收、画像漂移、冷启动误配}；ℰ_emb = {WCET 超限、热节流、内存破坏、优先级反转}；ℰ_priv = {泄露、重识别、同意违背、遗忘失败}。

**定义 307（J_PERSONA 证书）** J_PERSONA = (J_CALM, profile_hash, consent_verdict, U_u, resource_level, wcet_proof, dp_ε, adapter_hash, cdd_state, persona_ver)。Valid ⇔ Valid(J_CALM) ∧ consent_verdict=PASS ∧ wcet_proof 有效 ∧ resource_level ≤ D2 ∧ (U_u < τ_u ∨ 画像已冻结) ∧ 安全红线未越界。

**定义 308（管线）** 离线：人群画像先验 + MTM 自监督预训练 + 安全岛 WCET/认证（SIL/ASIL 证据链）。注册：知情同意 → 稳定画像 → TPA 初始化 → PE 交互。在线：安全岛 + 基础控制固定节拍；画像推理在空闲窗口；CDD 常开；适配仅在 D0/D1 的富余资源内、受能量与范数预算；周期性 CGC 复核；OPS 仅输出 DP 遥测。

**定义 309（嵌入式资源不变式）** 利用率 U = C_SI/T_SI + C_base/T + C_PI/T ≤ 1 − μ；画像库 ≤ M_u/用户；初始化后无堆分配；结温 T_j < T_max − Δ_T，否则降级；日能量 E_day ≤ E_budget，画像适配消耗 ≤ 5% E_day。

**定义 310（画像不确定度与 λ 下限）** λ_floor^P = max(λ_floor^CALM(U_c), 0.8·1[U_u > τ_u], 0.9·1[H_user^cap])。不确定或衰退 → 收紧；与 R68 的 λ_floor 单向纪律完全兼容。

**定义 311（单调似然比 MLR）** 对任意画像更新 u→u′ 与任意观测，危险假设的似然比不得下降：LR_{u′}(h) ≥ LR_u(h)，h ∈ H_haz；正常假设似然比不得上升。等价地，画像更新在危险后验上诱导一个单调非减映射。

```python
def persona_certificate(J_calm, upm, consent, res, wcet, dp_eps, cdd):
    ok = (Valid(J_calm) and consent.PASS and wcet.valid
          and res.level in ('D0','D1','D2')
          and (upm.U_u < TAU_U or upm.frozen)
          and not J_calm.redline_violated)
    return J_PERSONA(J_calm, hash(upm), consent.verdict, upm.U_u,
                     res.level, wcet.proof, dp_eps, upm.A_u.hash,
                     cdd.state, PERSONA_VER), ok


# IP-262 主闭环：PERSONA-RAS round
def PERSONA_RAS_round(M, obs, energy, temp):
    d = M.res.level(energy, temp, M.wcet.slack())
    x_prime = M.lsf.fuse(M.usr.fuse(obs.V, obs.T, obs.P, obs.L))

    # 1) 快速通道：安全岛 + 基础控制（任何降级等级下都不变）
    si_state = M.si.state
    z, o = M.mtm.forward(obs.pack, M.a_prev, M.scene_ctx)   # 画像岛

    # 2) 画像：快状态在线、稳定画像只读
    M.upm.update_state(obs.behavior, obs.sigma_stat)
    u = (M.upm.s, M.upm.q)

    # 3) R68 计量层保留：标定 + 归因 + 前瞻
    r = residuals(x_prime, o, M.wm_residual_cache)
    c, U_c, thr = M.cof.step(o['cal'], r, obs.sigma_stat)
    joint = M.pca(r, o['pi'], c, u, U_c, M.upm.U_u)         # PCA 替代 CFA

    # 4) CDD：能力衰退只收紧
    cdd = M.cdd.step(capability_residual(obs, u))
    lam = max(M.efs.risk_scale(joint), thr['lam_floor'],
              M.nab.lam_from_profile(u, M.upm.U_u), cdd.get('lam_floor', 0.0))

    # 5) 动作：舒适通道个性化；安全通道冻结
    A = M.ach.propose(x_prime, H=max_hyp(joint))
    k = M.c_ras_wm.certified_prefix(A, joint, min(M.vista.m, M.m_emo),
                                    M.alpha_chunk, M.wm_preds)
    if d in ('D2','D3','D4'): k = min(k, k_shrink_by_level(d))
    tau = M.pi_sigma.prefix_dispatch(A[:k]) * lam
    tau = comfort_shaping(tau, u, allow_adapt=(d == 'D0'))  # 只调舒适

    # 6) 单向信箱：PI -> SI 仅 TIGHTEN / HEARTBEAT
    M.si.apply(Tighten(lam=lam, tau=thr['tau_risk']))
    M.mailbox.heartbeat(z)

    # 7) 适配：仅 D0 空闲窗口、预算内、快照可回滚
    if d == 'D0' and M.slack.enough():
        M.tpa.bounded_step(M.ssl_grad(x_prime, joint), M.budget.today())
        M.cgc.maybe_reconsent(M.upm)
    M.ops.emit_dp({'lam': lam, 'level': d, 'u_state': scalarize(u)})  # DP 遥测

    cert, ok = persona_certificate(M.J_calm, M.upm, M.consent, M.res,
                                   M.wcet, M.ops.eps, cdd)
    if not ok: M.si.apply(Tighten(lam=0.9, tau=thr['tau_risk'] * 0.8))
    return k, lam, joint, (c, U_c), cert
```

## 3. 推导

**引理 16（单向量子阀——画像永不放宽安全）** 在 NAB（定义 296）、双岛隔离（定义 297）与 MLR（定义 311）下，对任意画像更新序列，认证安全集不变，且可行动作集非扩张：A_adm(u_{t+1}) ⊆ A_adm(u_t)，除非发生认证重注册。证明要点：PI→SI 信箱只接受 TIGHTEN，SI 的 λ 转移为 max 运算、危险阈值转移为 min 运算，均为单调非扩张；MLR 保证画像更新在危险后验上单调非减；画像只能进入舒适通道（定义 295）。系：错误或对抗性画像最多让机器人**过度保守**（有界 liveness 代价），不会让它更大胆（零安全代价）——这与人因上的"过度信任/依赖"风险恰好相反。

**引理 17（画像可辨识激励界）** 在 PE 条件 λ_min(I_PE) ≥ λ_0 与次高斯噪声下，注册期画像误差 E‖ŝ − s‖² ≤ C·d_s/(N_e·λ_0)。不满足 PE 时，U_u 按随机游走增长，λ_floor^P 抬升且 TPA 冻结到人群先验。系：**冷启动安全但不定制**——系统不会用不可辨识的画像去做安全决策。

**引理 18（资源单调降级安全不变式）** 在 RES 降级格下，对所有 d ∈ {D0,…,D4}，安全岛代码路径、C_SI、阈值与不变式完全相同；卸载次序为 adapt → profile_horizon → wm_rollout → profile_infer → base control，安全核不在卸载列表。因此热节流、能量不足或 WCET 压力不可能通过画像路径导致安全截止期错失；优先级天花板/继承防止反转。

**引理 19（端侧隐私—遗忘界）** 每用户适配器存储 O(r·d + K·d)，DP 遥测 (ε,δ) 下成员推断优势 ≤ e^ε − 1 + δ；认证删除（密钥 + 适配器 + 原型）使删后输出与"从未注册" (ε_unl, δ_unl)-不可区分；低秩近似的画像效用损失随 r 增大以 O(r^{-1/2}) 下降（在特征谱衰减假设下）。

**定理 16（PERSONA-RAS 端到端安全与能力衰退检出）** 在 A87–A94 与 A95–A98（PE、单调衰退、资源界、单向阀）下：
1. P(|τ_cmd − τ*| > ε) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_vqa + α_cal + **α_profile**，其中 α_profile 由引理 16 限制为「只增保守」项；
2. 对所有画像 u 与更新序列，λ ≥ λ_floor^P(u, U_u) 且 λ_floor^P 关于 U_u 与 H_user^cap 单调非减——**画像不确定或能力衰退永远导向收紧**；
3. 幅度 Δ、时程 T_d 的单调能力衰退在 T_d 内以概率 ≥ 1−β 被 CDD 检出，检出后 λ ≥ 0.9 并请求复核，且禁止写入舒适通道；
4. 错误画像的最坏后果是有界的保守化（k 收缩/liveness 损失），而非安全违规。

**定理 17（双岛认证分解与有界伤害）** 安全岛满足：固定点、无堆、无动态分派、代码 <16KB、WCET 可证，可作为 SIL 2 / ASIL B 级安全相关组件取证；画像岛的所有失效模式被归类为 (a) fail-silent（心跳丢失 → 降级）或 (b) only-tighten（信箱约束）；故画像岛不承担安全功能，其失效至多导致个性化丢失。双岛分解使认证范围从「整个学习系统」缩小到「一个小的不可变内核」，而学习系统被排除在安全论证之外——这是嵌入式约束赠予的、R68 无法获得的认证红利。

## 6. 本轮最大风险

**一句话**：PERSONA-RAS 把安全押在「画像与安全参数的硬隔离」上——一旦这条隔离被"个性化体验"的产品压力或嵌入式资源降级绕过，画像就会成为把真实能力衰退/危险情境解释成"用户偏好"的万能消音器，而且由于画像在端侧私有化、失败不可复现，这种侵蚀无法被群体级审计发现。

**次级风险与缓解**：
1. **能力衰退吸收** → CDD 独立于舒适通道 + 单调似然比约束 + 检出即 λ≥0.9 请求复核（定义 298/311、定理 16-3）；
2. **安全岛被"顺手"改宽** → ROM/OTP 参数 + 单向信箱 + 双人签名的重注册流程 + J_PERSONA 版本链；
3. **刻板印象与公平** → 分层收缩 + 公平约束 + 敏感属性不进入 s + E305 审计；
4. **资源降级误伤安全** → 单调降级格 + 安全核不在卸载列表 + WCET/热/能量三看门狗（引理 18）；
5. **端侧遗忘失败/隐私泄露** → 密钥级删除 + DP 遥测 + 认证遗忘审计（引理 19）。

## 2. 形式化定义（要点版）

**定义 293（总览与四不变式）** 安全岛不可写（θ_safety 驻留 ROM/OTP）；画像非吸收（不得压低危险后验）；只调舒适（θ_c ∈ Θ_comfort^cert，安全变换只收紧）；资源单调降级（任意 d 下安全岛路径/WCET/不变式不变，画像适配先被卸载）。

**定义 294（双时标画像）** `s` 分段常数、仅注册/重新同意可写；`q_{t+1}=f_q(q_t,o_t)+w_t`，`w~𝒩(0,Q_u)`，`τ_q∈[10,10²]s`；`U_u=tr(Σ_s)+tr(Σ_q)`。

**定义 295–296（参数分离与单向阀）** `π(a|x,u)=π_base(a|x,θ_s,θ_c+Δθ_c(u))`，`θ_s≡θ_s^cert`；安全岛 `λ←max(λ,h_λ(m))`、危险阈值 `τ←min(τ,h_τ(m))`，普通画像更新永不扩大 `A_adm`；唯一复位是认证重注册。

**定义 297（双岛与信箱）** SI：锁步 MCU/隔离核、固定点、<16KB、无堆、WCET 可证；PI：INT8/INT4 MTM+TPA+加密画像库；MMU/MPU 保证 PI 对 SI 零写权限；信箱只收 TIGHTEN/HEARTBEAT/FAULT_REPORT。

**定义 298（能力衰退与 CDD）** `H_user^cap` 表示相对注册画像的持续单调能力下降；证据为成功率/反应时/步态/语音时延残差；CUSUM 超 `h_cd` 即成立 → `λ≥0.9`、请求复核、禁止舒适吸收；目标 `P_det≥1−β`（T_d 内）、`P_fa≤α_cd`。

**定义 299（TPA）** 冻结 trunk，低秩 LoRA r=4（4-bit）+ K 原型；≤64KB/用户；推理 `O(r·d)`；仅 D0/D1 空闲窗口更新，`‖ΔA_u‖≤B_a`，快照可回滚，冷启动用人群先验。

**定义 300（画像激励）** Fisher 信息 `I_PE=Σ φ_tφ_t^T`；`λ_min(I_PE)≥λ_0` 时 `E‖ŝ−s‖²≤C·d_s/(N_eλ_0)`；不满足 PE → `U_u` 增长、λ 抬升、画像冻结。**冷启动安全但不定制**。

**定义 301 + 311（PCA 与 MLR）** 假设集扩为 `{H_geo,H_model,H_cal,H_sensor^trans,H_user^cap}`；`P(H,E,C|ρ,face,ĉ,u)∝p(ρ|H,ĉ,u)p(face|E,ĉ,u)P(H)P(E|H)P(u)`；MLR：对危险假设 `LR_u/LR_∅≥1`，对正常假设 `≤1`——画像只能推高危险后验。

**定义 302（RES 降级格）** D0 全功能 → D1 冻结适配 → D2 缩短画像时程/关 WM rollout → D3 关画像退人群先验 → D4 安全停机；调度优先级：安全核 > 基础控制 > 画像推理 > 画像适配 > 影子学习；安全核不在卸载列表。

**定义 303（OPS）** 原始数据不出端；画像库 AES-GCM 加密；遥测 (ε,δ)-DP；同意账本记录目的/范围/期限/撤回；遗忘请求删除适配器+原型+密钥，达成 `(ε_unl,δ_unl)`-不可区分于从未注册。

**定义 304（CGC）** `‖Δs‖>δ_s` 触发重新同意；q 漂移变点检测；分层收缩 `ŝ_u=(n_uŝ_u+κs_pop)/(n_u+κ)`；公平约束群体舒适差 `≤δ_fair`；用户可检查/更正画像卡片。

**定义 305–309（目标 / 干扰 / 证书 / 管线 / 资源不变式）** 约束优化 `min L_MT+λ_pL_profile+λ_cL_consent+λ_rL_robust`，s.t. θ_s 冻结、MLR、更新范数、DP、WCET；`ℰ_PERSONA=ℰ_CALM×ℰ_prof×ℰ_emb×ℰ_priv`；J_PERSONA Valid 需同意通过、WCET 有效、`resource≤D2`、`U_u<τ_u∨冻结`、红线未越界；离线人群先验+认证 → 注册同意+PE → 在线快慢通道；`C_SI/T_SI+C_base/T+C_PI/T≤1−μ`、无堆、热/能量双看门狗。

**定义 310（λ 下限扩展）** `λ_floor^P=max(λ_floor^CALM(U_c), 0.8·1[U_u>τ_u], 0.9·1[H_user^cap])`——不确定或衰退永远导向收紧，与 R68 单向纪律完全兼容。

```python
    M.si.apply(Tighten(lam=lam, tau=thr['tau_risk']))
```

## 4. 推导

**引理 16（单向量子阀——画像永不放宽安全）** 在 NAB、双岛隔离与 MLR 下，对任意画像更新序列，认证安全集不变，且 `A_adm(u_{t+1}) ⊆ A_adm(u_t)`，除非发生认证重注册。证明要点：PI→SI 只接受 TIGHTEN；SI 的 λ 转移为 max、危险阈值转移为 min，均单调非扩张；MLR 使画像在危险后验上单调非减；画像只能进入舒适通道。系：错误或对抗画像最多让机器人**过度保守**（有界 liveness 代价），不会让它更大胆（零安全代价）。

**引理 17（画像可辨识激励界）** PE 条件 `λ_min(I_PE)≥λ_0` 与次高斯噪声下，`E‖ŝ−s‖²≤C·d_s/(N_eλ_0)`；不满足 PE 时 `U_u` 随机游走增长、λ 抬升、TPA 冻结人群先验。系：**冷启动安全但不定制**，系统不会拿不可辨识的画像做安全决策。

**引理 18（资源单调降级安全不变式）** 对所有 `d∈{D0…D4}`，安全岛代码路径、`C_SI`、阈值与不变式相同；卸载次序 `adapt→profile_horizon→wm_rollout→profile_infer→base control`，安全核不在卸载列表。故热节流/能量不足/WCET 压力不可能经画像路径导致安全截止期错失；优先级天花板/继承防止反转。

**引理 19（端侧隐私—遗忘界）** 每用户适配器存储 `O(r·d+K·d)`；(ε,δ)-DP 遥测下成员推断优势 `≤e^ε−1+δ`；认证删除（密钥+适配器+原型）使删后输出与「从未注册」`(ε_unl,δ_unl)`-不可区分；低秩近似效用损失在特征谱衰减假设下以 `O(r^{-1/2})` 下降。

**定理 16（PERSONA-RAS 端到端安全与能力衰退检出）** 在 A87–A98 下：
1. `P(|τ_cmd−τ*|>ε) ≤ α_chunk+δ_fi+α_emotion+α_wm+α_vqa+α_cal+α_profile`，`α_profile` 由引理 16 限制为「只增保守」项；
2. 对所有 u 与更新序列，`λ≥λ_floor^P(u,U_u)`，且 `λ_floor^P` 关于 `U_u` 与 `H_user^cap` 单调非减；
3. 幅度 Δ、时程 T_d 的单调能力衰退在 T_d 内以概率 `≥1−β` 被 CDD 检出，检出后 `λ≥0.9` 并请求复核，禁止舒适吸收；
4. 错误画像的最坏后果是有界保守化（k 收缩/liveness 损失），而非安全违规。

**定理 17（双岛认证分解与有界伤害）** 安全岛固定点、无堆、无动态分派、<16KB、WCET 可证，可作为 SIL 2 / ASIL B 安全相关组件取证；画像岛失效被归类为 (a) fail-silent（心跳丢失→降级）或 (b) only-tighten（信箱约束），故不承担安全功能，失效至多个性化丢失。认证范围从「整个学习系统」缩小到「一个小的不可变内核」——这是嵌入式约束赠予的、R68 无法获得的认证红利。

## 7. 本轮最大风险

**一句话**：PERSONA-RAS 把安全押在「画像与安全参数的硬隔离」上——一旦这条隔离被"个性化体验"的产品压力或嵌入式资源降级绕过，画像就会成为把真实能力衰退/危险情境解释成"用户偏好"的万能消音器，而且由于画像在端侧私有化、失败不可复现，这种侵蚀无法被群体级审计发现。

**次级风险与缓解**：
1. **能力衰退吸收** → CDD 独立于舒适通道 + 单调似然比约束 + 检出即 λ≥0.9 请求复核（定义 298/311、定理 16-3）；
2. **安全岛被「顺手」改宽** → ROM/OTP 参数 + 单向信箱 + 双人签名的重注册流程 + J_PERSONA 版本链；
3. **刻板印象与公平** → 分层收缩 + 公平约束 + 敏感属性不进入 s + E305 审计；
4. **资源降级误伤安全** → 单调降级格 + 安全核不在卸载列表 + WCET/热/能量三看门狗（引理 18）；
5. **端侧遗忘失败/隐私泄露** → 密钥级删除 + DP 遥测 + 认证遗忘审计（引理 19）。
