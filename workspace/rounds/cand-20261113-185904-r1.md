# 第 69 轮（承接第 68 轮「CALM-RAS 自标定风险自适应闭环」IP-243~252；灵感循环新循环第 2 轮；本轮灵感：「腕部相机」×「跌倒恢复」）

> 第 68 轮把「标定」升级为在线潜变量 c_t，却在风险自陈里留下一个**结构性缺口**：整个自标定系统是一个**闭环自证（self-referential）**结构——它用被标定的传感器去判断自己是否需要标定。慢变故障只要落在标定带宽 ω_cal 之内，就会被滤波器当作漂移「解释掉」；系统越标定越自信，越自信越看不见自己正在缓慢失效。问题的本质不是 EKF 不够好、canary 不够多，而是**缺乏外部参照（external reference）**：要否定「我的测量还准」，必须存在一个不由这条测量链控制的第二意见。
>
> 本轮两个灵感恰好提供了「第二意见」的两种来源：
> - **腕部相机**给出一个**运动学外部参照**：它看着机器人自己的夹爪，而夹爪位姿由前向运动学（FK）给出——这是一条与被标定外参链**运动学独立**的观测通道。自己看自己，但不是用同一面镜子。
> - **跌倒恢复**给出一个**物理外部参照**：跌倒把系统抛到一个准静态、贴地、受重力约束的构型，此时重力方向与地平面是**物理绝对量**，不随任何标定漂移。跌倒因此不是纯粹的失败，而是一次**免费的计量重置（metrological reset）**——一次强制性的辨识实验。
>
> 核心命题：
> **把「标定」从「闭环自证」升级为「锚定可辨识」——用腕部自观测提供运动学锚，用跌倒重置提供物理锚，把「漂移 vs 故障」从频域不可分的赌局，变成空间可辨识的判决；并让跌倒恢复本身成为一次受认证的重标定。SOMA-RAS（Self-Observing Metrology & Anchoring RAS）。**
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「**我的测量锚在哪里**」——锚在（可辨识）则吸收漂移，锚失（跌倒/共模）则拒绝自信、切恢复模式、重锚定。

## 0. 直觉与动机

**灵感 1（腕部相机 → 传感器看自己：把本体变成计量基准）**
直觉：外部相机标定难，是因为它缺少已知参照物；而腕部相机永远离「已知参照物」最近——夹爪本身。夹爪的几何来自 CAD，位姿来自关节编码器 + FK。于是腕部相机每看一次夹爪，就得到一个形如 `u_i = π(E_w⁻¹ T_bg(q) p_i)` 的约束：未知的只有手眼外参 E_w，观测是稠密的像素。这是经典的 eye-in-hand 自标定，但**在本闭环里它从未被当作计量锚使用**。更关键的是：这条通道的误差来源（夹爪被工件遮挡、快速运动模糊、近场景深）与外部相机/力/触觉的误差来源**正交**，因此它提供的不是「更多同一意见」，而是「一个独立意见」。

**灵感 2（跌倒恢复 → 跌倒是一次免费的计量重置）**
直觉：R68 的标定滤波器有一个连续性先验 c_{t+1}=c_t+w，这个先验正是「吸收」的温床——它假定世界是连续的，于是把突变解释为噪声、把慢变解释为漂移。跌倒是一个**已知的变化点（known change point）**：系统明确知道「刚才发生了一次大冲击，旧标定不再可信」。于是可以合法地**清空先验、冷启动重估**，而不会被连续性先验拖回旧的（已被污染的）标定。更妙的是，跌倒后的准静态贴地构型是一个**计量友好位姿**：加速度≈0 时 IMU 给出的重力方向干净，腕部相机看到地平面，接触点已知——三者在物理上都是绝对参照。跌倒因此把「不可辨识的慢漂移」转化为「可辨识的重置实验」。
> 需要强调：这不是把跌倒当好事，而是**在跌倒不可避免时，把它从纯损失变成带信息的事件**——恢复过程顺便完成一次可辨识性最高的重标定。

**灵感 3（两灵感合流 → SOMA-RAS 六组件）**
1. **WSO（Wrist Self-Observation）**：腕部相机 + 夹爪 CAD + FK，连续估计手眼外参 E_w，并观测接触邻域；
2. **KAN（Kinematic Anchor & Identifiability）**：把 FK 当作锚，实时计算「标定 vs 故障」的可辨识度 κ_id，**门控**哪些残差允许被吸收；
3. **FMR（Fall as Metrological Reset）**：跌倒检测 → 冻结/作废旧标定 → 准静态冷启动重估 → 认证后恢复标称；
4. **GGE（Ground-Gravity Estimator）**：跌倒/恢复期用腕部相机估地平面、用准静态 IMU 估重力，提供抗冲击的重力参照；
5. **CRP（Certified Recovery Policy）**：预认证的恢复原语库 + 模型无关选择器（世界模型在跌倒时不可信），把「不确定就收缩」升级为「不确定就切换受认证动作集」；
6. **AMP（Active Metrological Probing）**：低风险期主动做微小自触/标靶一瞥，最大化标定-故障的可辨识信息增益——「自愿的小跌倒」。
> 继承 CALM-RAS†：MTM/SSG/COF/CFA/CAC 全部保留，但 COF 的吸收动作被 KAN 门控，CAC 增加「跌倒重置一致性」关。

**灵感 4（对 R68 最大风险的对症下药：从频域分离到空间分离）**
R68 的反吸收防线是**频域**的（引理 13：ω_f ≥ 3ω_cal 的快故障不可被吸收）。它的盲区正是慢故障（ω_f ≤ ω_cal）。本轮新增**空间/运动学**分离：故障方向 v_f 若与标定子空间 range(J) 不正交，就仍可被吸收；但腕部锚把 c 的几何分量钉死，使 v_f 在补空间上的投影 κ_id 显著增大。于是：
- 快故障 → R68 频域防线（时间分离）；
- 慢故障 → R69 锚定防线（空间分离）；
- **两者并集覆盖全频谱**——这正是 R68「标定越强、慢故障越隐形」原罪的解药（引理 17 及其系）。

**灵感 5（跌倒恢复与「不确定就收缩」的张力）**
R68 的纪律是「任何不确定性 → λ 下限抬升、前缀收缩、宁可不做」。但跌倒在地时**什么都不做才是危险的**：必须动，才能起来。若把「收缩」无脑套到恢复上，机器人会僵在地上。本轮的正解是**双模安全包络**：
- **标称模**：不确定 → 收缩标称动作空间（继承 R68）；
- **恢复模**：标称动作空间整体**关闭**，只开放一个**预认证恢复原语库**（每个原语出厂即带力矩/自碰撞/能量证书），选择器只依赖本体感觉 + 腕部地平面估计，不依赖可能已失真的世界模型。
即「收缩」作用于标称任务，而「恢复」走另一条已认证的安全通道。这个区分本身是 R69 的形式化贡献之一（定义 303、定理 17）。

## 1. 形式化定义（增量：定义 293–308）

**定义 293（SOMA-RAS 总览）** SOMA-RAS = (WSO, KAN, FMR, GGE, CRP, AMP, CALM-RAS†)。三不变式升级：
(i) **辨识先于吸收**：任何残差在被吸收进 c 之前，必须先通过可辨识性门控（定义 297/298）；不可辨识方向的残差一律按故障处理；
(ii) **跌倒即切换**：检测到跌倒 ⇒ 原子挂起标称策略、作废旧标定、进入恢复模；未完成重锚定不得恢复标称；
(iii) **实时流零学习写操作**（继承 R68）：WSO/KAN 只做推理与滤波，重标定在影子/恢复窗口完成并需认证。

**定义 294（腕部自观测 WSO）** 腕部相机图像 I^w_t，夹爪特征点 {p_i}_{i=1}^{m}（CAD，m≥4 非共面），FK 位姿 T^b_g(q_t)。观测模型 u_i = π(E_w^{-1} T^b_g(q_t) p_i) + ε_i。WSO 输出：
- 手眼外参估计 Ê_w 及其协方差 Σ_w；
- 重投影残差 r_he = Σ_i ρ(‖u_i − π(Ê_w^{-1} T^b_g(q_t) p_i)‖)；
- 接触邻域观测（夹爪-工件/地面的近场几何），供恢复模使用。
> 关键点：Ê_w 由**运动学**（q_t、CAD）锚定，而不是由外部相机链锚定——这就是「第二意见」。

**定义 295（手眼连续可观测性）** WSO 的局部可观测性由 Fisher 信息 J_w^T J_w 决定，其中 J_w = ∂u/∂ξ（ξ 为 E_w 的 6 维扰动）。当且仅当夹爪在观测窗内绕**至少 2 个不平行轴**旋转且存在 **≥3 个方向的平移激励**时，J_w 满秩，E_w 局部唯一可解。正常操作与恢复动作天然满足该激励条件（引理 16）。可观测性不足时 WSO 只输出 r_he 而不更新 Ê_w（避免无锚自信）。

**定义 296（运动学锚 KAN）** 锚集 A_t = {(q_t, T^b_g(q_t), Ê_w, u_t)}。标定参数 c 的**可辨识度**定义为
κ_id(c) = σ_min( J_c^T J_c ) / σ_max( J_c^T J_c )，
其中 J_c = ∂[r_ext; r_wrist; r_kin]/∂c 为全测量链对标定的雅可比；κ_id ∈ [0,1]，越小表示 c 越病态、越容易被故障「冒充」。

**定义 297（故障方向与吸收判据）** 设故障在测量空间的单位方向为 v_f。定义其在标定可达子空间上的投影系数
β = ‖P_{range(J_c)} v_f‖ / ‖v_f‖，可辨识残差系数 κ_id^f = √(1 − β²)。
- 若 κ_id^f ≥ κ_min：故障**可辨识**，其标定后残余 ‖r‖ = κ_id^f·‖f‖；
- 若 κ_id^f < κ_min：故障与某个标定方向**共线**，物理上不可分——此时禁止吸收，按最坏情况（H_sensor^trans）处理。
> 这就是把 R68 的「先标定后归因」升级为「先判可辨识、再决定能否标定」。

**定义 298（辨识门控吸收 IGA）** COF 的更新只在**良态子空间**内进行：
δĉ = argmin_δ ‖r − J_c δ‖² s.t. δ ∈ span{V_well}，其中 V_well 为 J_c^T J_c 的小特征值对应的**补**空间（即条件数良好的方向）；速率限制器（R68 定义 286）在 V_well 内保留，但在跌倒重置窗口内**按方向**放开（定义 300）。不可辨识方向永不吸收——**这是 R68 原罪的直接补丁**。

**定义 299（跌倒事件 FMR）** 跌倒事件 e_f = (t_f, E_impact, Δpose_pre→post, wrist_visible)。检测器 F_t 融合 IMU 冲击、姿态角速度、支撑多边形外移与腕部地平面骤近。事件触发协议：
1. **挂起**：标称策略 π_nom 与 k*RAS 原子挂起（<1 μs 指针切换，继承 CAC 双缓冲）；
2. **作废**：旧标定 c 置为先验宽分布（Σ ← Σ_broad），连续性先验失效——跌倒是一个**已知变化点**；
3. **准静态窗口**：待本体速度 < v_q 且角速度 < ω_q（典型 0.5–2 s），进入定义 300 的计量窗口；
4. **冷启动重估**：在绝对参照约束下重估 c（含 E_w、外参、力零偏、时间同步）；
5. **认证恢复**：重锚定证书通过后，才允许退出恢复模（定理 17）。

**定义 300（准静态计量窗口与绝对参照）** 窗口内可用约束：
- **重力**：加速度≈0 时 IMU 给出 ĝ（误差 ~0.1°），是物理绝对方向；
- **地平面**：腕部相机对地面做单应/法向估计，得 (n_g, d_g)（定义 301）；
- **接触**：支撑点接触力 + 关节力矩给出接触约束；
- **本体**：FK 与编码器给出体段相对构型（注意：编码器零偏是**待估量**，不是参照）。
绝对参照的独立性保证：ĝ 与 n_g 不依赖任何视觉外参，故可用它们来**检验**而非**服从**旧的 c。冷启动问题因此是良态的：c ← argmin ‖r_ext(c)‖² + ‖r_wrist(c)‖² + λ_g‖R(c)ĝ − ĝ‖² + λ_n‖n_g(c) − n̂_g‖²。

**定义 301（地平面/重力估计 GGE）** 腕部相机近场点云 → RANSAC 平面 → 法向 n̂_g^cam 与距离 d̂_g^cam；经 Ê_w 与 T^b_g 变换到体系：n̂_g^b = R_bw n̂_g^cam。与准静态 IMU 重力 ĝ^b 做加权融合，权重按各自残差自适应；冲击期（|a|>a_th）IMU 降权至 0，仅用地平面 + 上一可信重力做陀螺积分。输出 (n̂_g^b, ĝ^b, 置信度)。

**定义 302（认证恢复策略 CRP）** 恢复原语库 Π_rec = {π_1,…,π_P}，每个原语带出厂证书 cert(π_j) = (τ_max ≤ τ_lim, 自碰撞间隙 ≥ d_min, 能量 ≤ E_lim, 终止构型稳定)。恢复模策略：
π_rec = argmax_{π_j ∈ Π_rec} Q_j(s_t), s_t = (本体姿态, 关节角, n̂_g^b, 接触状态)，
其中 Q_j 为**模型无关**的启发式/学习值函数（只用本体感觉 + GGE，不用 WM）。预冲击阶段（检测到不可逆跌倒但未触地）允许一个**支撑原语**：腕部相机预测触地点，伸臂护住要害——这是腕部相机在「跌倒」中的第三个用途（预冲击）。

**定义 303（双模安全包络）** 模式 m ∈ {NOM, REC}：
- m=NOM：λ = max(λ_floor(U), …)，k ≤ k_cert，标称动作空间开放；
- m=REC：π_nom **关闭**，只开放 Π_rec；风险度量从「任务风险」切换为「伤害风险」P_injury ≤ ε_rec；λ 语义变为「原语选择保守度」。
切换 NOM→REC 由 F_t 触发；REC→NOM 需同时满足：姿态稳定、κ_id ≥ κ_min、U(c) < τ_cal、且 J_SOMA 认证通过。**不可逆保护**：一旦进入 REC，禁止任何未认证的标称动作（定理 17）。

**定义 304（主动计量探测 AMP）** 低风险期（σ_stat 高、λ 余量大）调度微探测 a_probe ∈ {自触已知标靶, 对夹爪做小幅多轴转动, 瞥视固定 fiducial}，目标最大化对标定-故障的可辨识信息增益：
a* = argmax_a E_y[ IG(c, f; y | a) ] s.t. Risk(a) ≤ B_probe，
其中 IG 为关于「c 与 f 的可分性」的互信息。AMP 是「自愿的小跌倒」：用可控的小激励换取可辨识性，把被动标定变成主动实验设计。

**定义 305（残差分解与故障可辨识残差）** 全残差 r = r_cal(c) + f + ε。分解：
r_cal = P_{range(J_c)} r（可被标定解释的部分），
r_f = (I − P_{range(J_c)}) r（标定无法解释的部分）。
**故障判决**：‖r_f‖ > τ_det ⇒ 至少存在不可被标定吸收的故障分量，按 H_sensor^trans 处理；即使 ‖r‖ 很小（被吸收），只要 ‖r_f‖ 超阈，仍判故障——**这就是慢故障可见性的来源**。

**定义 306（SOMA 证书 J_SOMA）** J_SOMA = (J_CALM, E_w_hash, κ_id, mode m, reset_epoch, recovery_cert_hash, soma_ver)。Valid ⇔ Valid(J_CALM) ∧ κ_id ≥ κ_min ∧ (m=NOM ∨ recovery_cert 有效) ∧ reset_epoch 与当前一致。

**定义 307（干扰集 ℰ_SOMA）** ℰ_SOMA = ℰ_CALM × ℰ_anchor × ℰ_reset × ℰ_rec；
ℰ_anchor = {锚自身漂移、共线故障、自观测遮挡}；ℰ_reset = {误触发/漏触发跌倒、重置期数据污染、冷启动不收敛}；ℰ_rec = {恢复原语失效、恢复期二次跌倒、模式切换竞态}。

**定义 308（管线）** 离线：CALM-RAS 预训练 + WSO 手眼初标 + Π_rec 出厂认证。在线：WSO/KAN 实时推理（只读）；标称期 AMP 按预算调度微探测；跌倒 → FMR → 准静态 GGE → 冷启动重估 → J_SOMA 认证 → 恢复标称。全程影子流做 CAC 五关（新增「重置一致性」关）。

class WristSelfObservation:
    def __init__(self, gripper_cad, fk):
        self.P = gripper_cad.feature_points      # m>=4 非共面
        self.fk = fk
        self.Ew = None; self.Sw = np.eye(6)*1e-2

    def observe(self, I_w, q):
        Tbg = self.fk(q)
        uv, conf = detect_gripper_features(I_w, self.P)   # 近场检测
        if uv is None or conf < C_MIN:
            return {'r_he': None, 'observable': False}     # 遮挡/模糊：不更新
        J = jacobian_pnp(self.Ew, Tbg, self.P)             # ∂u/∂ξ
        if np.linalg.cond(J.T@J) > COND_MAX:
            return {'r_he': reproj(self.Ew, Tbg, uv), 'observable': False}
        self.Ew, self.Sw = pnp_update(self.Ew, self.Sw, uv, Tbg, self.P)
        return {'r_he': reproj(self.Ew, Tbg, uv), 'observable': True,
                'Ew': self.Ew, 'Sw': self.Sw}


# IP-254 KAN：可辨识性门控（先判可辨识，再决定能否吸收）

    def __init__(self, kappa_min=0.25):
        self.kappa_min = kappa_min

        S = np.where(S > 1e-8, S, 1e-8)

        kappa_f = np.sqrt(max(0.0, 1 - min(1.0, beta**2)))

                'kappa_f': kappa_f, 'absorbable': kappa_f >= self.kappa_min}


# IP-255 FMR + GGE：跌倒计量重置（含准静态重力/地平面参照）

# IP-258 SOMA-RAS 主闭环（继承 CALM_RAS_round）
def SOMA_RAS_round(M, obs):
    # 0) 跌倒优先：一切标称逻辑之前先判 F_t
    if fall_detected(obs.imu, obs.wrist_ground):
        M.fmr.on_impact(obs.imu, obs.wrist_ground, M.t)
        c, U, g_hat, n_hat, ep = M.fmr.reset_and_recalibrate(
            obs.imu_quasi, obs.wrist_ground, M.wso.observe(obs.img_w, obs.q))
        pi = M.crp.select(recovery_state(obs, g_hat, n_hat))   # 模型无关
        tau = dispatch_recovery(pi) * lam_recovery(U, M.mode)  # 双模包络
        M.j_soma = issue_cert(M, c, U, mode='REC', epoch=ep)
        return 'REC', tau, M.j_soma

    # 1) 标称模：WSO 先给第二意见，再走 CALM-RAS
    wso = M.wso.observe(obs.img_w, obs.q)
    z, o = M.mtm.forward(obs_pack, M.a_prev, M.scene_ctx)
    r = residuals(obs.x_prime, o, M.wm_residual_cache)
    J_c = M.kan.jacobian(o, wso)                 # 全链对标定的雅可比
    dec = M.kan.decompose(r, J_c, v_f=M.fault_direction(r))
    # 2) 可辨识性门控吸收（IGA）：只吸收良态方向
    c, U, thr = M.cof.step_gated(o['cal'], dec['r_cal'], J_c, dec)
    # 3) 故障判决用不可辨识残差 r_f（慢故障可见性，定义 305）
    fault_evidence = dec['r_f']
    joint_post = M.cfa(rho=o['fir'], face=o['pi'], c=c, U=U,
                       extra_evidence=fault_evidence)
    # 4) 继承 CALM-RAS 的前瞻/前缀/风险缩放
    wm_preds = M.mtm.rollout(z, M.ach.propose_actions(obs.x_prime, 5))
    wm_drift = kl_div(o['pi'], wm_preds[0]['pi']) > thr['tau_wm']
    A = M.ach.propose(obs.x_prime, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, joint_post, min(M.vista.m, M.m_emo),
                                    M.alpha_chunk, wm_preds)
    if dec['kappa_id'] < M.kan.kappa_min or U > TAU_CAL:
        k = min(k, k_cal_shrink(A, U))           # 锚不可靠 ⇒ 收缩
    lam = max(M.efs.risk_scale(joint_post), thr['lam_floor'],
              0.8 if (o['qual']['face'] < 0.8 or wm_drift) else 0.6)
    tau = emotion_response_shaping_wm(M.pi_sigma.prefix_dispatch(A[:k]) * lam,
                                      joint_post, wm_preds)
    # 5) 主动计量探测（低风险期）
    a_probe = M.amp.maybe_probe(risk_budget=lam - LAM_MIN, kappa_id=dec['kappa_id'])
    if a_probe is not None: M.schedule_probe(a_probe)
    # 6) 异步审计 + 认证提交（新增重置一致性关）
    M.vqa_c.submit_async(wm_preds, {'cal': (c, U), 'kappa': dec, 'wso': wso})
    M.cac.maybe_commit(M.shadow, M.time_since_last_commit)
    M.j_soma = issue_cert(M, c, U, mode='NOM', epoch=M.fmr.epoch)
    return k, lam, joint_post, (c, U), M.j_soma

## 3. 推导

**引理 16（运动学锚的可辨识性）** 在 WSO 观测窗内，若夹爪绕 ≥2 条不平行轴旋转（夹角和 ≥ θ_min）且平移激励覆盖 ≥3 个方向，则手眼雅可比 J_w 满秩，E_w 局部唯一可解，且条件数 κ(J_w) ≤ c_geo / sin(θ_min/2)。系：正常抓取-放置与恢复动作天然满足激励条件，因此手眼外参是**连续可观测**的，而不是一次性离线常数。

**引理 17（慢故障可辨识界——R68 原罪的解药）** 测量模型 r = r_cal(c) + f + ε。经 WSO/KAN 锚定后，c 的几何分量被 J_c 独立约束，故障方向 v_f 的可辨识残差系数 κ_id^f = √(1−β²)（定义 297）。若 κ_id^f ≥ κ_min，则对任意频率（含 ω_f ≤ ω_cal 的慢故障）有
‖r_f‖ = κ_id^f·‖f‖，当 ‖f‖ > τ_det/κ_id^f 时必被检出。
**关键：该界不含 ω_f**——它不依赖时间分离，因此覆盖了 R68 引理 13 的盲区。系（全频谱可见性）：R68 频域防线管快故障（ω_f ≥ 3ω_cal），R69 空间防线管慢故障（κ_id^f ≥ κ_min），两者并集覆盖全部故障频谱；只有在 v_f 与锚定标定子空间共线（κ_id^f < κ_min）时仍不可分，而这恰是「真实故障长得和标定漂移一模一样」的物理退化情形，必须按最坏情况处理。

**引理 18（跌倒重置的信息增益）** 跌倒是一个已知变化点，重置前验为宽分布。准静态窗口的绝对参照（重力 ĝ、地平面 n̂_g）不依赖视觉外参，故对旧 c 提供独立约束。设重置前慢故障 f 已被吸收进 ĉ_old（即 f ≈ J_c δc），则重置后冷启动残差满足
‖r_f^reset‖ ≥ κ_id^f·‖f‖ − O(σ_ĝ + σ_n̂)，
即故障在重置后重新可见。信息增益 IG ≈ ½ log det(Σ_broad / Σ_post) = O(log(1/ε_reset))，其中 ε_reset 为准静态参照的精度。系：**跌倒把「不可辨识的慢漂移」转化为「可辨识的重置实验」**——代价是一次跌倒，收益是一次全链重锚定。

**引理 19（恢复模式的有界风险）** 恢复原语库 Π_rec 中每个原语带出厂证书（力矩/自碰撞/能量/终止稳定界）。选择器只用本体感觉 + GGE，不依赖可能失真的 WM。因此即使 WM 与外部感知完全 OOD，恢复动作仍在认证包络内：P(伤害) ≤ max_j cert_j(risk)，恢复时长 ≤ diam(Π_rec)。假设：触地后准静态可检、地面在腕部相机可达范围内、执行器未饱和。

**定理 16（SOMA-RAS 端到端风险一致性）** 在 A87–A94 与新增 A95（WSO 激励充分）、A96（准静态窗口可达）下：
1. 标称模：P(|τ_cmd − τ*| > ε) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_vqa + α_cal + **α_id**，其中 α_id 由引理 17 的 κ_id^f 界限制；
2. 慢故障可见性：对任意 ω_f，若 κ_id^f ≥ κ_min 且 ‖f‖ > τ_det/κ_id^f，则检出概率 ≥ 1 − δ（**不再要求 ω_f ≥ 3ω_cal**）；
3. 锚不可靠（κ_id < κ_min 或 WSO 遮挡）⇒ 禁止吸收 + λ 下限抬升 + k 收缩，绝不放宽；
4. 跌倒 ⇒ 标称动作概率质量置零，伤害风险 ≤ ε_rec（引理 19）。

**定理 17（跌倒-恢复安全包络的不可逆保护）** 跌倒检测延迟 ≤ T_d（典型 200 ms）；检测后标称策略原子挂起；REC→NOM 必须同时满足姿态稳定、κ_id ≥ κ_min、U(c) < τ_cal、J_SOMA 认证通过，四者缺一不可。因此系统**无法在锚已损坏时自信地恢复标称**——这是对 R68「越标定越自信」的直接制度性约束。回滚/切换竞态落入 ℰ_reset 并保持 REC 兜底（SAFE_FOLD）。

## 6. 本轮最大风险

**一句话**：SOMA-RAS 把全部可辨识性押在「腕部相机能持续看到自己的夹爪」这一运动学锚上——但**跌倒既是重置的触发者，也是最可能摧毁腕部相机的事件**（触地冲击、夹爪先着地），触发者与执行者共模失效；更隐蔽的是，若故障恰好落在锚自身的自由度上（腕相机外参漂移、编码器零偏、连杆柔性形变），锚与被测量共线，系统会以错误的锚完成一次「自信的跌倒后重标定」，把真实故障固化为新常态——**自观测的镜子也会歪，而歪掉的镜子最危险**。

**次级风险与缓解**：
1. **共模失效**：跌倒同时毁掉触发与执行 → 冗余触发（IMU + 支撑多边形 + 电流签名）+ 第二锚（对侧腕/外部 fiducial 一瞥）+ 无腕部相机时的降级恢复原语；
2. **锚共线退化**：κ_id^f < κ_min 时禁止吸收、按最坏情况处理（定义 297）——宁可误报不可漏报；
3. **误/漏触发跌倒**：迟滞 + 多模态投票 + 误触发代价仅是一次保守重标定（有界）；
4. **冷启动不收敛**：准静态窗口超时则保持 REC + SAFE_FOLD，绝不带病恢复标称；
5. **恢复原语库覆盖不足**：未认证构型一律走兜底折叠 + 呼救，不冒险尝试未认证动作。

## 2. 形式化定义（要点版）

**定义 293（总览与三不变式）** 辨识先于吸收（不可辨识方向一律按故障处理）；跌倒即切换（未完成重锚定不得恢复标称）；实时流零学习写操作（继承 R68）。

**定义 294（WSO）** `u_i = π(E_w^{-1} T^b_g(q_t) p_i)`，`p_i` 为 CAD 非共面特征点（m≥4）。输出 `(Ê_w, Σ_w, r_he, 接触邻域观测)`。Ê_w 由运动学锚定，而非外部相机链——这是「第二意见」。

**定义 295（手眼连续可观测性）** 当夹爪绕 ≥2 条不平行轴旋转且平移激励覆盖 ≥3 方向时 `J_w^T J_w` 满秩，E_w 局部唯一可解；激励不足时只输出 `r_he` 不更新 `Ê_w`。

**定义 296–297（KAN 与吸收判据）** `κ_id` 度量标定病态程度；故障方向投影 `β`，`κ_id^f=√(1−β²)`。`κ_id^f ≥ κ_min` 才允许吸收，否则按 `H_sensor^trans` 最坏情况处理。

**定义 298（IGA）** COF 仅在良态子空间 `span{V_well}` 内更新；速率限制在良态方向保留、重置窗口内按方向放开；不可辨识方向永不吸收。

**定义 299–300（FMR 与准静态窗口）** 跌倒协议：挂起标称 → 作废旧标定（Σ←Σ_broad）→ 准静态窗口 → 冷启动重估 → 认证恢复。窗口内用重力 `ĝ`、地平面 `n̂_g`、接触约束、FK 相对构型（编码器零偏是待估量，不作参照）做绝对参照约束。

**定义 301（GGE）** 近场点云 RANSAC 平面 → 法向/距离；经 `Ê_w`、`T^b_g` 变换到体系；与准静态 IMU 重力自适应融合，冲击期 IMU 权重降 0。

**定义 302（CRP）** `π_rec = argmax_j Q_j(s_t)`，`s_t=(姿态,关节角,n̂_g,接触)`，`Q_j` 模型无关。预冲击允许「支撑原语」：腕部相机预测触地点、伸臂护要害。

**定义 303（双模安全包络）** NOM：λ/k 收缩标称动作；REC：π_nom 关闭、只开 Π_rec，风险度量切换为伤害风险。NOM→REC 由 F_t 触发；REC→NOM 需姿态稳定 ∧ κ_id≥κ_min ∧ U<τ_cal ∧ J_SOMA 认证。

**定义 304（AMP）** 低风险期选 `a*=argmax_a E[IG(c,f;y|a)]`，`Risk(a)≤B_probe`；把被动标定变为主动实验设计。

**定义 305（残差分解）** `r_cal=P_{range(J_c)}r`，`r_f=(I−P)r`。判决用 `r_f`：即使 `‖r‖` 小，只要 `‖r_f‖>τ_det` 仍判故障——慢故障可见性的来源。

**定义 306–308（证书/干扰集/管线）** `J_SOMA` 需 `κ_id≥κ_min` 且模式与 `reset_epoch` 一致；`ℰ_SOMA` 四乘积；在线跌倒优先、离线预认证。

# IP-253 WSO：腕部自观测（运动学锚）
class WristSelfObservation:
    def __init__(self, gripper_cad, fk):
        self.P, self.fk = gripper_cad.feature_points, fk
        self.Ew, self.Sw = None, np.eye(6)*1e-2

    def observe(self, I_w, q):
        Tbg = self.fk(q)
        uv, conf = detect_gripper_features(I_w, self.P)
        if uv is None or conf < C_MIN:
            return {'r_he': None, 'observable': False}      # 遮挡/模糊：不更新
        J = jacobian_pnp(self.Ew, Tbg, self.P)
        if np.linalg.cond(J.T@J) > COND_MAX:
            return {'r_he': reproj(self.Ew, Tbg, uv), 'observable': False}
        self.Ew, self.Sw = pnp_update(self.Ew, self.Sw, uv, Tbg, self.P)
        return {'r_he': reproj(self.Ew, Tbg, uv), 'observable': True,
                'Ew': self.Ew, 'Sw': self.Sw}


# IP-254/260 KAN + IGA：先判可辨识，再门控吸收
class IdentifiabilityMonitor:
    def __init__(self, kappa_min=0.25): self.kappa_min = kappa_min

    def decompose(self, r, J_c, v_f):
        S = np.linalg.svd(J_c, compute_uv=False)
        self.kappa_id = S.min() / S.max()                   # 定义 296
        r_cal = J_c @ np.linalg.lstsq(J_c, r, rcond=None)[0]
        r_f = r - r_cal                                      # 定义 305
        beta = np.linalg.norm(pinv(J_c) @ v_f)
        kappa_f = np.sqrt(max(0.0, 1 - min(1.0, beta**2)))
        return {'kappa_id': self.kappa_id, 'r_cal': r_cal, 'r_f': r_f,
                'kappa_f': kappa_f, 'absorbable': kappa_f >= self.kappa_min}


# IP-255/256 FMR + GGE：跌倒计量重置
class FallMetrologicalReset:
    def __init__(self, cof, gge, mode):
        self.cof, self.gge, self.mode, self.epoch = cof, gge, mode, 0

    def on_impact(self, imu, wrist_ground, t):
        if not fall_detected(imu, wrist_ground): return None
        self.mode.set('REC'); self.cof.invalidate_prior(broad=True)
        return 'RESET_TRIGGERED'

    def reset_and_recalibrate(self, imu_quasi, wrist_ground, kin):
        g_hat, n_hat, conf = self.gge.estimate(imu_quasi, wrist_ground, kin)
        c_new, U_new = self.cof.cold_start(None, kin['r_he'], g_hat, n_hat)
        self.epoch += 1
        return c_new, U_new, g_hat, n_hat, self.epoch


# IP-257 CRP：认证恢复策略（模型无关）
class CertifiedRecoveryPolicy:
    def __init__(self, library, certs): self.lib, self.certs = library, certs
    def select(self, s_t):
        feas = [p for p in self.lib if self.certs[p].feasible(s_t)]
        if not feas: return self.lib['SAFE_FOLD']
        return max(feas, key=lambda p: Q_model_free(p, s_t))  # 只用本体+GGE


# IP-259 AMP：主动计量探测
class ActiveProbeScheduler:
    def maybe_probe(self, risk_budget, kappa_id):
        if risk_budget <= 0 or kappa_id >= KAPPA_OK: return None
        a = argmax_expected_IG(PROBES, risk_budget)
        return a if expected_IG(a) > IG_MIN else None


# IP-262 SOMA-RAS 主闭环（继承 CALM_RAS_round）
def SOMA_RAS_round(M, obs):
    if fall_detected(obs.imu, obs.wrist_ground):                # 0) 跌倒优先
        M.fmr.on_impact(obs.imu, obs.wrist_ground, M.t)
        c, U, g_hat, n_hat, ep = M.fmr.reset_and_recalibrate(
            obs.imu_quasi, obs.wrist_ground, M.wso.observe(obs.img_w, obs.q))
        pi = M.crp.select(recovery_state(obs, g_hat, n_hat))
        tau = dispatch_recovery(pi) * lam_recovery(U, M.mode)   # 双模包络
        M.j_soma = issue_cert(M, c, U, mode='REC', epoch=ep)
        return 'REC', tau, M.j_soma

    wso = M.wso.observe(obs.img_w, obs.q)                       # 1) 第二意见
    z, o = M.mtm.forward(obs_pack, M.a_prev, M.scene_ctx)
    r = residuals(obs.x_prime, o, M.wm_residual_cache)
    J_c = M.kan.jacobian(o, wso)
    dec = M.kan.decompose(r, J_c, v_f=M.fault_direction(r))
    c, U, thr = M.cof.step_gated(o['cal'], dec['r_cal'], J_c, dec)  # 2) IGA
    joint_post = M.cfa(rho=o['fir'], face=o['pi'], c=c, U=U,
                       extra_evidence=dec['r_f'])               # 3) 用 r_f 判决
    wm_preds = M.mtm.rollout(z, M.ach.propose_actions(obs.x_prime, 5))
    wm_drift = kl_div(o['pi'], wm_preds[0]['pi']) > thr['tau_wm']
    A = M.ach.propose(obs.x_prime, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, joint_post, min(M.vista.m, M.m_emo),
                                    M.alpha_chunk, wm_preds)    # 4) 继承前缀
    if dec['kappa_id'] < M.kan.kappa_min or U > TAU_CAL:
        k = min(k, k_cal_shrink(A, U))
    lam = max(M.efs.risk_scale(joint_post), thr['lam_floor'],
              0.8 if (o['qual']['face'] < 0.8 or wm_drift) else 0.6)
    tau = emotion_response_shaping_wm(M.pi_sigma.prefix_dispatch(A[:k]) * lam,
                                      joint_post, wm_preds)
    a_probe = M.amp.maybe_probe(lam - LAM_MIN, dec['kappa_id'])  # 5) 主动探测
    if a_probe is not None: M.schedule_probe(a_probe)
    M.vqa_c.submit_async(wm_preds, {'cal': (c, U), 'kappa': dec, 'wso': wso})
    M.cac.maybe_commit(M.shadow, M.time_since_last_commit)      # 6) 异步认证
    M.j_soma = issue_cert(M, c, U, mode='NOM', epoch=M.fmr.epoch)
    return k, lam, joint_post, (c, U), M.j_soma

## 4. 推导

**引理 16（运动学锚的可辨识性）** 夹爪绕 ≥2 条不平行轴旋转且平移激励覆盖 ≥3 方向 ⇒ 手眼雅可比满秩、E_w 局部唯一可解，`κ(J_w) ≤ c_geo/sin(θ_min/2)`。系：手眼外参连续可观测，而非一次性离线常数。

**引理 17（慢故障可辨识界——R68 原罪的解药）** 锚定后故障方向可辨识系数 `κ_id^f=√(1−β²)`；若 `κ_id^f≥κ_min`，则对**任意频率**（含 `ω_f≤ω_cal`）`‖r_f‖=κ_id^f‖f‖`，当 `‖f‖>τ_det/κ_id^f` 必检出。该界不含 ω_f，覆盖 R68 引理 13 的慢故障盲区。系（全频谱可见性）：R68 管快故障（时间分离），R69 管慢故障（空间分离），并集覆盖全频谱；仅当故障与标定子空间共线时仍不可分，按最坏情况处理。

**引理 18（跌倒重置的信息增益）** 已知变化点 ⇒ 宽先验；准静态绝对参照（`ĝ`、`n̂_g`）独立于视觉外参。重置后 `‖r_f^reset‖ ≥ κ_id^f‖f‖ − O(σ_ĝ+σ_n̂)`，被吸收慢故障重新可见；`IG≈½logdet(Σ_broad/Σ_post)=O(log(1/ε_reset))`。系：跌倒把不可辨识慢漂移转化为可辨识重置实验。

**引理 19（恢复模式有界风险）** Π_rec 每原语带出厂证书；选择器只用本体+GGE，不用可能 OOD 的 WM ⇒ 恢复动作始终在认证包络内：`P(伤害)≤max_j cert_j`，恢复时长 `≤diam(Π_rec)`。

**定理 16（端到端风险一致性）** A87–A96 下：(1) 标称误差界新增 `α_id`；(2) 慢故障对任意 ω_f 可见（不再要求 ω_f≥3ω_cal）；(3) 锚不可靠 ⇒ 禁止吸收 + λ 抬升 + k 收缩；(4) 跌倒 ⇒ 标称动作概率质量置零，伤害风险 ≤ ε_rec。

**定理 17（跌倒-恢复不可逆保护）** 检测延迟 ≤ T_d（~200ms）；检测后标称原子挂起；REC→NOM 四条件缺一不可（姿态稳定 ∧ κ_id≥κ_min ∧ U<τ_cal ∧ J_SOMA 认证）。系统无法在锚已损坏时自信恢复标称；竞态落入 ℰ_reset 并保持 SAFE_FOLD。

## 7. 本轮最大风险

**一句话**：SOMA-RAS 把全部可辨识性押在「腕部相机能持续看到自己的夹爪」这一运动学锚上——但**跌倒既是重置的触发者，也是最可能摧毁腕部相机的事件**（触地冲击、夹爪先着地），触发者与执行者共模失效；更隐蔽的是，若故障恰好落在锚自身的自由度上（腕相机外参漂移、编码器零偏、连杆柔性形变），锚与被测量共线，系统会以错误的锚完成一次「自信的跌倒后重标定」，把真实故障固化为新常态——**自观测的镜子也会歪，而歪掉的镜子最危险**。

**次级风险与缓解**：共模失效（冗余触发 + 第二锚 + 无腕相机降级原语）；锚共线退化（κ_id^f<κ_min 禁止吸收、按最坏情况）；误/漏触发跌倒（迟滞 + 多模态投票，误触发仅一次有界保守重标定）；冷启动不收敛（超时保持 REC + SAFE_FOLD）；原语库覆盖不足（未认证构型走兜底折叠 + 呼救）。
