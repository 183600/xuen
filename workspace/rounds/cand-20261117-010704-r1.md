# 第 11 轮（新灵感循环第 3 轮；本轮灵感：「对比实验」×「手势识别」）
> **基线**：第 10 轮 MetricVoiceGauge-LRC（定义 540–549；引理 87–93；实验 E571–E590）。
> **本轮纪律**：**以差代值 + 以对代点 + 以实验代预测**。v10 还剩两笔债：**模型自证债**（RankLedger 的成对比较仍由同一个可能失配的前向模型生成，排序是"模型的意见"而非"世界的证据"）与**人类接口债**（排行榜只在模型内部比较，缺少真实结果与真实偏好）。「对比实验」治模型自证——用配对、随机化、对照、安慰剂把世界与人的结果变成可识别的因果差分；「手势识别」治人类接口——把人的指称与偏好做成**成对**手势（"这个，不是那个"），而不是不可校准的绝对打分。二者合成：**人在环的安全配对对照证据闭环**。所有新增件均为可选增强，任一失效按中立元逐级退回 v10→v9→v8→v7→v6。

## 0. 直觉与动机

**灵感 1（对比实验 → 证书从"绝对预测"变为"配对差分"）**
直觉：v10 的"以序代值"只走了一半。它承认绝对分数不可比，于是改用候选之间的成对比较；但成对比较的**证据**仍来自前向模型 F̂。若 F̂ 在陌生域有一个随上下文缓变的系统偏差 b(s)，所有候选的分数会一起漂移——排序看似稳健，实则只是"偏差的共同模式"。对比实验的第一性原理是**控制变量 + 随机化 + 对照**：与其问"ζ 的间隙是多少"，不如问"在同一初始状态、同一意图、同一随机数下，ζ 相对匹配对照 ζ₀ 的间隙差是多少"。共享的上下文偏差 b(s) 在差分中**相消**，剩下的是可被 Lipschitz 界控制的**差分误差** β_Δ，通常远小于绝对误差 β。更关键的是：当安全允许时，让系统在**已由 L0 硬界认证的可行集内**做平衡 switchback（ABBA/分块随机），用真实执行结果估计"换块"的因果效应；这不是拿模型给自己打分，而是拿世界给模型纠偏。

**灵感 2（手势识别 → 人类的成对偏好与安全旁路）**
直觉：人表达偏好几乎从不是绝对打分，而是**对比**——"这个，不是那个"、"左边那个"、"再往右一点"。单点指称携带的是"我指哪个"，而**成对指称**（先指 A 再指 B，或双手分别指 A/B，配合点头/摇头）携带的是"我相对更喜欢哪个"，恰好是 Bradley–Terry 排行榜需要的成对标签。手势识别因此有两个正交价值：(i) **成对偏好标注**：把人的对比意图变成带噪声的 pairwise label，补上 v10 排行榜缺失的"人类证据"；(ii) **安全旁路**：张开手掌/双手交叉是低延迟的"停"，只做集合交、只收缩可行动作集。误识别只能让系统更保守或更频繁地弃权，绝不能让它"获准"做新动作——**手势只收缩或排序，从不授权**。

**灵感 3（合成：安全 switchback × 成对指称 → 人在环因果证据闭环）**
直觉：把二者接起来，闭环是：模型提出候选对 → 差分证书在共模偏差下判定 → 仅在 L0 可行集内做安全 switchback → 真实结果与人类成对指称共同给出 pairwise 证据 → 证据台账（预注册 + e-value + FDR）决定是否换马。人不再被要求给"0–100 分"（不可校准、跨人不可比），只需在系统主动询问时做一个**对比手势**；系统也不再把模型的自我比较当真理，而是把模型比较降级为**先验**，把真实配对结果作为**似然**。核心创新：**配对差分证书（PTB/DC）**、**安全 switchback（SE）**、**手势成对标注（GPA/ARM）**与**对照证据台账（CEL）**。

## 1. 研究问题（轮次升级版）

- **Q1（差分可靠性）**：在只假设"模型误差可分解为共模项 + 差分项"时，配对差分证书能否给出可验证的保守界？β_Δ 如何由 Lipschitz 常数、切换幅度与 CRN 噪声估计，并在共模假设失效时被检测？
- **Q2（可识别性）**：在非平稳上下文、carryover 与有限真实样本下，安全 switchback 的因果效应估计偏差多大？何种匹配窗口、洗脱期与平衡设计能把偏差压到 δ_switch/3 以下，否则应如何拒绝这段证据？
- **Q3（人类成对标注）**：手势成对指称的噪声、跨人相关性与非传递性如何建模？可靠度加权 + 弃权 + 迟滞能否给出有界的排序错误，并避免"少数标注者绑架排行榜"？
- **Q4（证据治理与退化）**：预注册、e-value、e-BH 与安慰剂对照能否把"多次比较/随时停止/选择性报告"的 FDR 控制在 q 以内？当手势、随机化、差分界、台账逐级失效时，能否严格退回 v10 的 LWC+RL，而不产生行为漂移？

## 2. 设计原则（在 P13–P15 基础上新增 P16–P18）

**P16 差分优先律（Difference-over-Absolute）**
凡是"在两个候选之间做选择"的证书，必须先算同上下文、同意图、同随机数下的配对差分 Δ，并以**差分误差** β_Δ（而非绝对误差 β）给出置信界。共模偏置只能通过差分消去，不能通过重标定假装消失；绝对证书只作为差分不可识别时的退化路径。

**P17 安全随机化律（Randomize-only-within-Certified-Set）**
任何随机化/探索只能发生在 L0 硬界认证的可行集 ℱ^L0 内，且安全关键模块与安全关键主张**永不随机化**。随机化只影响"性能与证据"，不影响"安全性"；50Hz 的 L0 守卫始终拥有中止权。若 L0 可行集为空或匹配失败，则不实验、不换马，退回 v10。

**P18 手势单调律（Gesture-only-Shrinks-or-Ranks）**
手势只有两种合法作用：**排序证据**（成对偏好，进入排行榜的似然）与**收缩**（STOP 只做 A_adm ← A_adm ∩ Stop）。手势永远不能扩大可行动作集、不能单独授权动作、不能替代 L0 证书。手势 STOP 是附加旁路而非安全主证明：漏检不破坏 L0 兜底，误检只损失可用性。

## 3. 与基线的接口（如何退化）

- 手势/标注可靠性不可用 ⇒ 只用真实 switchback 与模型差分，排行榜退回 v10 的模型 pairwise；
- 主动查询不可用 ⇒ 不主动询问，只用被动结果与模型差分；
- switchback 不可用（真实样本不足 / 随机化不安全 / 匹配失败）⇒ 只用模型差分证书，仍不回退绝对分数；
- 差分误差界不可验证（共模假设被安慰剂/守卫否定）⇒ 退回 v10 的 LWC+RL 绝对证书；
- CEL/e-BH 失效 ⇒ 排行榜退回 v10 的模型比较；
- v10 的 LWC/RL/LCC 任一失效 ⇒ 按 v10 定义逐级退回 v9 的 AC / 绝对 score / 运行时 MW；
- v9 的 AC/MW/ID 失效 ⇒ 按 v9 定义 536 注入中立元，退回 v8；
- 全部失效 ⇒ MetricVoiceGauge-PACE v11 → LRC v10 → ACMD v9 → DA-SPR-Cal v8 → OTL-GC-ER v7 → v6。

## 4. 预期贡献

1. **配对差分证书**：把"模型预测的绝对值"换成"同上下文双胞胎的差分"，共模域偏移在一阶上相消，β_Δ 可估、可测、可拒；
2. **安全 switchback**：在 L0 可行集内用平衡随机化获得真实因果证据，给出安全性证明（随机化不增加不安全动作）与非平稳/携带效应下的偏差界；
3. **手势成对标注**：把"这个/不是那个"变成带可靠度权重的 pairwise label，配以弃权、非传递性检测与安全单调 STOP；
4. **对照证据台账**：预注册 + anytime-valid e-value + e-BH + 安慰剂对照，把"显著"从模型自证变成可审计的统计证据；
5. **完整闭环**：E591–E610 覆盖差分有效性、因果识别、手势标注、FDR、公平性/安全性、消融与端到端任务。

## 5. 本轮最大风险

**一句话**：差分证书把 v10 的"模型自证"换成了"配对可识别性"——当上下文非平稳、切换存在 carryover、或手势标注噪声跨人相关时，配对差分不再是共模偏差的无偏消去，而系统会把"在错误配对/错误窗口上的小方差"误当成因果证据，配合 FDR 的"显著"标签做出比 v10 更自信的错误换马。

**新增定义 550（配对对照单元 Paired Comparison Unit）** 对上下文 s_t、意图 ℓ_t、候选块 ζ_t 与对照 ζ_t⁰，定义
```
U_t = (s_t, ℓ_t, ζ_t, ζ_t⁰, ω_t),   ζ_t, ζ_t⁰ ∈ ℱ_t^L0,   |ζ_t| = |ζ_t⁰| = K
ε_match(U_t) = ‖s_t − s_t⁰‖_M + λ_ℓ·d_ℓ(ℓ_t,ℓ_t⁰) + λ_K·|K − K⁰|
```
`U_t` 可入证 ⇔ `ε_match ≤ δ_ctx ∧ ζ_t ≠ ζ_t⁰ ∧ CRN(ζ_t)=CRN(ζ_t⁰)`。对照默认为 v10 的在位块；在位块不可行时取安全基线（停车/最小步）；**没有合格对照就不出证书**，而不是拿绝对预测凑数。CRN 指两臂共享同一随机数序列，用于消去共同随机扰动。

**新增定义 551（差分证书 Differential Certificate）** 对配对单元 U，记
```
Δ(U)  = J(ζ;s) − J(ζ₀;s)
Δ̂(U) = Ĵ(ζ;s) − Ĵ(ζ₀;s)
β_Δ(s) = sup_{ζ,ζ₀∈ℱ^L0} |(Ĵ(ζ)−Ĵ(ζ₀)) − (J(ζ)−J(ζ₀))|
I_Δ(U) = [Δ̂ − β_Δ − ε_ulp,  Δ̂ + β_Δ + ε_ulp]
```
判定为
```
accept     ⇔ L0(ζ) ∧ L0(ζ₀) ∧ I_Δ⁻ ≥ δ_switch
reject     ⇔ I_Δ⁺ < 0
unresolved ⇔ 其余
```
**安全永远由 L0 决定，Δ 只在已认证的块之间决定性能与排序。** 若模型误差可写为 `e(s,a)=b(s)+e_Δ(s,a)`（b 为共模项），则差分只暴露 `e_Δ`，`β_Δ` 通常远小于绝对误差 `β`；最坏情形 `β_Δ ≤ 2β`，故差分不保证更快，只保证在共模偏差下不被"整体漂移"欺骗。

**新增定义 552（安全 switchback Safe Switchback）** 预注册设计 `D = (π, m, w, balance)`：在第 t 个块边界以概率 `e_t(s_t)` 选处理臂，要求
```
A_t ~ Bernoulli(e_t(s_t)),   e_t(s_t) ∈ [ε, 1−ε]
A_t ⨿ (score(ζ), human_id, gesture_prediction) | s_t
∀A_t: 执行臂 ∈ ℱ_t^L0;   安全关键主张 e_t ≡ 0（不随机化）
```
在长度 2m、洗脱 w 的匹配窗口 W 上用 ABBA 配对估计
```
Δ̂_sw(W) = (1/m)·Σ_{j=1}^{m} [ Y(ζ_{t+2j−1}) − Y(ζ_{t+2j}) ]
```
ABBA 抵消一阶 carryover；窗口可用性要求偏差界 `γ_w + L_s·δ_ctx ≤ δ_switch/3`，否则标记为"不可用证据"而不是放宽容差。switchback 只在块边界（5Hz）决策，50Hz 守卫始终可中止。

**新增定义 553（手势成对标注 Gesture Pairwise Annotation）** 成对手势词表
```
G_pair = { point_i·point_j, point_i·nod, point_i·shake,
           two_hand_point(i,j), palm_stop }
```
手势 episode `g_{1:M}` 经语法解析得到候选 `(i,j,y)` 的后验，仅当
```
P(i,j,y | g) ≥ τ_g   ∧   dist(i,j) ≥ r_sep   ∧   min(bind_i,bind_j) ≥ τ_bind
```
才输出成对标签；否则**弃权**。`point_i·point_j` 表示"要 i，不要 j"；`palm_stop` 只做 `A_adm ← A_adm ∩ Stop`。手势只提供排序似然或收缩可行集，**从不直接授权动作**；漏检 STOP 由 L0 兜底，误检只损失可用性。

**新增定义 554（标注者可靠性 Annotator Reliability）** 设第 k 对的潜在真值 `z_k∈{+1,−1,⊥}`，标注者 a 的观测 `y_{a,k}` 服从混淆矩阵 `C_a[ y | z ]`。用带 Dirichlet 先验的 EM 估计 `C_a`，得到 `ρ_a = P(y=z|a)` 与权重
```
w_{a,k} = max(0, 2ρ_a − 1) · 1[ρ_a > 0.5 + η]
```
把成对标签并入 Bradley–Terry 的加权对数似然
```
ℓ_BT(u) = Σ_{a,k} w_{a,k}·log σ( y_{a,k}·(u_{i_k} − u_{j_k}) )
```
`ρ_a ≤ 0.5+η` 的标注者权重归零（含随机/对抗标注者）。若检测到成对偏好环（非传递性），标记该标注者/时段并把环上边的权重减半，而不是把环强行拟合成传递序。

**新增定义 555（对照实验台账 Comparative Evidence Ledger）** 每个换块主张 i 必须在观测前预注册
```
H_i: Δ_i ≤ 0  vs  Δ_i ≥ δ_switch
design_i = (匹配规则, 窗口长度, 洗脱期, 最大样本, 停止规则, 主/次端点)
```
对配对差 `D_{i,1},…,D_{i,n}`（有界 `|D|≤B`），定义 anytime-valid e-value
```
e_{i,n} = Π_{j=1}^{n} exp( λ_i·D_{i,j} − λ_i²·B²/2 ),   0 < λ_i < 2/B
```
审计用 e-BH：把 m 个 e-value 降序排列 `e_(1)≥…≥e_(m)`，取
```
k* = max{ k : e_(k) ≥ m/(q·k) },   拒绝前 k* 个主张
```
在任意依赖下控制 FDR ≤ q。台账**全量记录**所有比较（含负结果与中途停止），模型自带的 pairwise 比较只作为带折扣 `η_model` 的**先验伪计数**，不能冒充 e-value；预注册后不得改端点或事后加样本。

**新增定义 556（主动对比查询 Active Comparative Query）** 对 top-2 候选对 (i,j)，令 `P(sign Δ_ij | D)` 为当前后验，定义
```
EIG(i,j) = H(P(sign Δ_ij | D)) − E_y[ H(P(sign Δ_ij | D,y)) ]     (≤ 1 bit)
query(i,j) ⇔ EIG(i,j)·V_π ≥ c_q + c_h
```
其中 `V_π` 是解决该对可减少的期望遗憾，`c_q` 是计算成本，`c_h` 是打扰人的成本。只询问 top-2 且差分未定的对；每任务限频 `Q_max`；用机器人先指 A 再指 B 的**成对指称展示**提问，人可用对比手势回答，也可用 `palm_stop` 弃权。查询只增加排序证据，不改变安全裁决。

**新增定义 557（差分守卫 Differential Guard）** 50Hz 守卫只维护标量差分残差
```
r_t = Y_t^{obs} − Ŷ_t^{pair}
alarm ⇔ |r_t − r_{t−1}| > β_Δ + ε_ulp
        ∨ ¬L0(incumbent) 在当前观测下失效
        ∨ (pending switch ∧ Δ̂_sw < 0)
```
报警时冻结换马、记录证据、回退 v10 行为；不跑 rollout、不更新归因，故 O(1)。若连续报警超过 `κ_pl` 次，触发一次安慰剂对照审计。

**新增定义 558（证据预算 Evidence Budget）** 每小时真实实验样本/查询预算
```
B_exp(t) ≤ B_exp^max,   b_i ∝ w_i·σ_i·sqrt(V_i)/c_i,   b_i = 0（安全关键主张）
```
按价值密度分配到主张；预算上限与分配规则在实验前写定，观测后不得重分配（除非预注册了中期分析）。预算耗尽时只保留模型差分，不再做真实 switchback。

**新增定义 559（安慰剂对照与证据独立性 Placebo & Independence）** 以概率 `p_pl` 运行**空对照** `ζ₀=ζ`（u=0），走完全相同的证书/台账流程；任何在 q 水平上"显著"的空对照都计入安慰剂假阳性率 `α̂₀`。要求
```
α̂₀ ≤ q + ε_pl
I( evidence ; model_score | s ) ≤ ε_ind
A_t ⨿ (model_score, human_id, gesture_prediction) | s_t
```
并设置一个**负控端点**（例如与块选择无因果联系、但可能被模型泄漏污染的指标）。若安慰剂失败或独立性检验失败 ⇒ 冻结 CEL，整体退回 v10；安全关键主张永远不进入实验。

class DifferentialCertifier:
    def __init__(self, delta_switch=0.05, eps=1e-6):
        self.delta_switch, self.eps = delta_switch, eps

    def certify(self, twin, beta_delta):
        if not (l0(twin.treat) and l0(twin.control)):
            return None                                 # 安全不通过差分越权
        d_hat = model.delta(twin)                       # 同一 s、同一 CRN
        lo, hi = d_hat - beta_delta - self.eps, d_hat + beta_delta + self.eps
        if lo >= self.delta_switch:
            return Cert('accept', lo, hi)
        if hi < 0.0:
            return Cert('reject', lo, hi)
        return Cert('unresolved', lo, hi)

## 3. 推导

**引理 94（共模抵消与差分证书的可靠性）** 设真实效用与模型效用可写为
```
J(ζ;s)  = f(s,ζ) + b(s) + ε_ζ
Ĵ(ζ;s)  = f̂(s,ζ) + b(̂s) + ε̂_ζ
```
其中 `b(s)` 为两臂共享的上下文/域偏差，`ε, ε̂` 为零均值噪声。对同一 U 取差分：
```
Δ̂ − Δ = [(f̂(ζ)−f̂(ζ₀)) − (f(ζ)−f(ζ₀))] + (b̂−b̂) + (ε̂_ζ−ε̂_ζ₀) − (ε_ζ−ε_ζ₀)
       = e_Δ(ζ) − e_Δ(ζ₀) + 配对噪声
```
共模项 `b` 精确相消。若 `|e_Δ(ζ)−e_Δ(ζ₀)| ≤ β_Δ` 且 CRN 使共享随机项相消，则 `|Δ̂−Δ| ≤ β_Δ + ε_CRN`，定义 551 的区间覆盖真实差分。又 `β_Δ ≤ min(2β, L_e‖u‖ + 2ε_CRN)`：绝对偏差很大但缓变时，差分仍可判定；若两臂误差**反相关**（`e_Δ=2β`），差分无收益——这正是本方案的可证伪条件。∎

**引理 95（配对/ switchback 的方差缩减与偏差界）** 设两臂方差均为 σ²、相关系数 ρ，则配对差分估计的方差
```
Var(Δ̂_p) = 2σ²(1−ρ)
```
相对非配对 `2σ²` 的样本量缩减因子为 `(1−ρ)`；ρ→1 时配对几乎免费。对 switchback，ABBA 平衡设计使一阶 carryover 相消，残余偏差满足
```
|Bias(Δ̂_sw)| ≤ γ_w + L_s·δ_ctx
```
故其 MSE 上界 `≤ (1−ρ)σ²/m + (γ_w + L_s·δ_ctx)²`。当偏差界超过 `δ_switch/3` 时，定义 552 判该窗口不可用；因此**不会用高方差的小样本去换一个看似显著的假效应**。∎

**引理 96（安全随机化的安全性）** 对任意分配策略，只要其支撑集包含于 `ℱ_t^L0`，被执行动作必满足 v10 引理 87 的 L0 确定性硬界；随机化只改变"在已认证集合中选哪一个"，不改变"哪些动作被认证"。50Hz 差分/L0 守卫只能进一步中止，不能放宽。故
```
P(执行动作违反 L0 硬界) = 0
```
探索只影响性能与证据，不影响安全性；安全关键主张的分配概率固定为 0，绝不参与随机化。∎

**引理 97（手势成对标注的可靠性界）** 设标注者错误独立、可靠度 `ρ>1/2`，n 个独立成对标签的加权多数错误率由 Chernoff 界
```
P(聚合标签错) ≤ exp( −n·KL(ρ ‖ 1/2) )
```
在 BT + 可靠度权重下，单个翻转标签对对数似然的改变不超过 `log(1/σ(margin))`；结合 v10 的 LCB 排序与 δ_rank 迟滞，选择翻转需要置信区间在 δ_rank 尺度上分离，故
```
P(排序选择错) ≤ exp(−n·KL(ρ‖1/2)) + exp(−c·n·δ_rank²)
```
当 `ρ→1/2` 或检测到偏好环时，权重归零/弃权，退化为"不采纳该标注者"，不会把噪声当成偏好。相关错误（同一人重复标注）由 `C_a` 的标注者级参数吸收，禁止把同一人的 n 条标签当作 n 个独立样本。∎

**引理 98（e-BH 的 FDR 控制与样本复杂度）** 在零假设 `H_i: Δ_i≤0` 下，定义 555 的 `e_{i,n}` 是非负上鞅且 `E[e_{i,n}]≤1`（Hoeffding 引理），故为 anytime-valid e-value。e-BH 在任意依赖下控制 `FDR ≤ q`；预注册与全量记录排除"看结果再选端点/停时"造成的选择性偏差。对固定备择 `δ` 与有界差 `B`，最优 `λ=δ/B²` 给出
```
E[log e_{i,n}] = n(λδ − λ²B²/2) = nδ²/(2B²)
```
故每主张约需 `n ≈ 2B²·log(m/q)/δ²` 个配对样本即可进入拒绝集（常数意义下）。∎

**引理 99（主动查询的收益与退化）** 二值查询的信息增益至多 1 bit；在单调子模的 EIG 目标下，带基数预算的贪心查询达到 `(1−1/e)` 近似。查询门槛 `EIG·V_π ≥ c_q+c_h` 保证每次询问的期望净收益非负；若手势通道不可用，策略严格退化为 v10 的模型 pairwise + LCB/迟滞，安全裁决不变。查询只增加排序证据，`palm_stop` 只收缩 `A_adm`，故不引入新的不安全动作。∎

> 在 2D 导航 + 轻量抓取玩具环境中跑 500 回合；对 20% 回合注入缓变共模偏差 b(s)，对 10% 回合注入反相关差模误差，模拟域偏移与假设破坏。以下为预演占位数据，真值待 E591–E610 验证。

**预演暴露的问题**：在 20% 非平稳回合中，ABBA 窗口的 carryover 偏差达到 `δ_switch` 的 0.42 倍，超过 1/3 可用阈值，导致约 18% 的 switchback 窗口被判为不可用；这直接对应本轮最大风险——**配对差分在小样本、非平稳、携带效应下会给出"方差很小但偏差很大"的假证据**。

## 8. 本轮最大风险

**一句话**：差分证书把 v10 的"模型自证"换成了"配对可识别性"——当上下文非平稳、切换存在 carryover、或手势标注噪声跨人相关时，配对差分不再是共模偏差的无偏消去，而系统会把"在错误配对/错误窗口上的小方差"误当成因果证据，配合 FDR 的"显著"标签做出比 v10 更自信的错误换马。
