# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「多机器人协作」×「视觉编码器」）

> R69 教会系统「问」，但「问」依赖一个从未被检验的前提：**被问的对象与我不共享同一个盲点**。R69 自陈的最大风险正是——模态分布不可信时，主动交互会把「诚实的不知道」升级成「被证实的错误」。单机器人只能靠人、靠环境回答；多机器人协作看似天然提供 N 个证人，然而一旦所有机器人共享同一个**视觉编码器**，它们看到的是同一副「被编码过的世界」：同一块对抗补丁、同一个训练集偏差、同一次镜面反射，会让 N 个机器人给出 N 个完全一致却完全错误的结果。这时的「共识」不是证据，是**回声**。
>
> 本轮两个灵感恰好构成正题与反题：
> - **多机器人协作**把 R69 的「该向谁求证」从一对多扩展到多对多：可以在队友之间互相求证、分工观察、交叉验证；
> - **视觉编码器**既是协作的共享底座，也是相关误差的源头：共享编码器 = 共同盲点；异构编码器 / 异构视角 / 异构模态 = 可制造的独立性。
>
> 核心命题：**协作的货币不是「同意的人数 N」，而是「等价独立证人数 n_eff」。** N 个共享编码器的机器人可能只值 1 个证人；要拿到真正的新信息，必须显式估计误差相关性、把独立性当作可观测、可审计、可主动制造的资源，并在 n_eff 不足时把 N 票降权为 1 票、退回 R69 的保守兜底。命名 **ECHO-RAS**（Effective Corroboration from Heterogeneous Observers：反回声的多机器人证据闭环）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**他们的同意，究竟是几个人的同意**」——共识不是真理，共识的**等价独立人数**才是。

## 0. 直觉与动机

**灵感 0（一个反例先立靶子）**
直觉：100 台机器人、同一个视觉语言模型、同一型号相机，在走廊里同时说「门是开着的」。若那其实是一扇玻璃门，100 票全错且高度一致。再加一台只有激光雷达、没有任何视觉编码器的机器人说「前方 1.2m 处有透明障碍」——这 1 票的价值超过前面 100 票。**名义共识 N=101，有效共识 n_eff≈2。** 这说明多机器人系统的核心问题不是「如何让更多机器人同意」，而是「如何知道这些同意里有多少是同一副眼镜的复读」。

**灵感 1（多机器人协作不是投票，是实验设计）**
直觉：投票假设每个证人独立；但多机器人在同一场景、同一编码器、同一时刻观测，本质上是**一次实验被复制了 N 遍**，不是 N 次独立实验。真正的协作应当像实验设计：主动安排不同的视角、不同的传感器、不同的表示、不同的时间，使每个新证据尽量与已有证据**不相关**。于是「向谁求证」升级为「如何设计下一次观测以最大化新信息 / 通信成本」。这把 R69 的 MINT（单机 VoI 交互）推广成团队级的**主动实验设计**。

**灵感 2（视觉编码器是双面的：共同盲点，也是独立性杠杆）**
直觉：共享视觉编码器把不同机器人的观测压进同一个潜空间；一旦该潜空间对某类刺激有系统性偏差（对抗补丁、透明/反光材质、训练集里稀有的物体），偏差就是**共模**的——它不会因为机器人数量增加而平均掉。反过来，编码器也是制造独立性的最便宜手段：同一张图换一个骨干网络、换深度/热成像/事件相机、换一个视角，就能引入**表示独立**。但必须区分两件事：
- **表示独立**（换编码器）能对抗模型幻觉，却对抗不了「所有相机都没拍到」；
- **观测独立**（换视角/模态/时刻）能对抗遮挡与物理盲区，却对抗不了「所有编码器都有同一先验偏差」。
真正的新信息要求**两轴同时独立**；只换编码器不换视角，或只换视角不换编码器，都可能只得到「半独立」的伪证人。

**灵感 3（相关误差可分解、可观测，因而可计算）**
直觉：误差不是铁板一块。可把它拆成「团队共模 + 同编码器族 + 同观测簇 + 个体噪声」四部分。这样，两台机器人的误差相关度可以由它们的**编码器是否同族、视角是否重叠、是否看到同一批像素**来预测，而视角重叠可以用特征匹配 / 互信息在线估计。于是 n_eff 不是一个玄学概念，而是可由共观测残差与出处标签算出的量。经典调查统计的**设计效应**（design effect）在这里正好适用：n_eff = N / [1+(N−1)ρ̄]。

**灵感 4（独立性是动作，不是属性）**
直觉：人类不会抱怨「我们视角一样所以没办法」，而是会**走过去换个角度看**、**关灯用热成像**、**敲一下听声音**。独立性和 R69 的信息动作一样，是可以被生成、被认证、被审计的：移动、旋转、切换编码器、切换模态、等待光照变化、主动遮挡与敲击。区别只在于 R69 的信息动作是为了「消解模态歧义」，而这里的多样性动作是为了「去相关」——降低 ρ，从而**把 N 票变成真正的 n_eff 票**。

**灵感 5（共享视觉记忆会重复计数）**
直觉：多机器人常共享一张语义地图/视觉记忆。若机器人 A 看到一个疑似目标写入地图，机器人 B 又从地图读到它、并把它当作独立观测再次上报，系统就会把**同一个物理观测**计成多票。这是协作系统里最隐蔽的「回声放大器」：相关性不是来自编码器，而是来自**共享记忆的回环**。因此每条记忆必须带出处，并按物理事件去重。

**灵感 6（独立性估计本身是新的最脆弱点）**
直觉：我们想用 ρ 来给共识打折，但 ρ 只能从数据里估。如果估计 ρ 的数据恰好也来自那个共享编码器，就会形成循环：**用同一副眼镜去证明我们戴的不是同一副眼镜**。更糟的是，攻击者可以「相关洗白」——制造在锚点上看起来独立、在真实分布上高度相关的错误。独立性估计因此必须遵守与 R69 证据纪律同构的规则：**不得用被验证的结论去验证独立性**，且在没有可信锚点时必须默认 ρ=1（n_eff=1），退回单机保守。

## 1. 形式化定义（增量：定义 310–327）

**定义 310（ECHO-RAS 总览）** ECHO-RAS = (CEB, HVE, ICE, NEC, TVoI, DAC, RBA, CHD, SMD, VQAuditor-M, RAS-WM†)。四不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **证据出处强制**：任何跨机器人证据必须携带 `(claim, σ, encoder_id, view_id, t, J_i, h)`，无出处证据权重为 0，只作告警；
(iii) **有效证人数纪律**：确认一个模态需要 `n_eff⁻ ≥ k`（n_eff 的置信下界），而非名义人数 `N ≥ k`；
(iv) **独立性不可自证**：估计独立性所用数据不得同时用于验证被它确认的结论（锚点隔离 / 干预验证 / 留出集）。

**定义 311（团队与共享视觉底座）** 团队 M={1,…,N}。机器人 i 有视觉编码器 Φ_{κ(i)}（κ 为编码器族：骨干/预训练/模态）、观测簇 ν(i)（视角、时段、传感器位置）、策略 π_i、标定误差 ECE_i、通信时延 d_i。共享视觉记忆 𝕄 的每条记录带出处的物理事件 ID。

**定义 312（带出处的证据对象）** 证据 `e = (ĉ, σ, κ, ν, t, J_i, h, id_phys)`：ĉ 为对任务变量/模态身份的声明，σ 为不确定度，κ/ν 为编码器族与观测簇，J_i 为该机器人局部证书，h 为内容哈希，id_phys 为可核验的物理观测 ID（时空邻近 + 特征匹配聚类）。融合只在出处可核验时进行。

**定义 313（误差成分模型）** 设真实变量 y，机器人声明 c_i = y + e_i，误差分解
`e_i = μ(s) + a_{κ(i)}(s) + b_{ν(i)}(s) + ε_i`，
其中 σ_μ² 为团队共模（所有机器人共享）、σ_a² 为同编码器族共享、σ_b² 为同观测簇共享、σ_ε² 为个体噪声。则
`ρ_ij = [σ_μ² + σ_a²·1{κ_i=κ_j} + σ_b²·1{ν_i=ν_j}] / σ_total²`。
两条边界：同编码器同视角 ⇒ ρ→1；全异构 ⇒ ρ→0（最多到 σ_μ²/σ_total² 的地板）。

**定义 314（有效证人数 n_eff）** 对可交换团队，设计效应 `DEFF = 1+(N−1)ρ̄`，
`n_eff = N / DEFF = N / [1+(N−1)ρ̄]`。
可证：均值估计方差 `σ²(1+(N−1)ρ)/N = σ²/n_eff`；Fisher 信息 `I_total ≈ n_eff·I_1`；故置信区间宽度 ∝ `1/√n_eff`。退化：N 个同编码器同视角机器人 `n_eff→1`；全异构 `n_eff→N`；共享视觉记忆重复计票时 ρ̄ 被高估为 1、n_eff 被高估为 N（见定义 320 的去重修正）。

**定义 315（有效佐证纪律 NEC）** 先由锚定共观测给出相关上置信界 `ρ⁺`，再取 `n_eff⁻ = N/[1+(N−1)ρ⁺]`。确认需 `n_eff⁻ ≥ k`（默认 k=2，与 R69 的 k 正交证据一致）。否则记为 **nominal consensus**：证据权重按 `n_eff⁻` 计，**不得触发 R69 的 resolution bonus**，并按 R69 两级退避走保守 `λ=λ_floor(U_ale+U_epi)`。

**定义 316（团队 VoI，TVoI）** 候选查询 `q=(j, 视角, 编码器, 模态)`。对高斯证人，边际信息增益
`I(y; c_j | ℱ) = −½ log(1 − ρ_{j|ℱ}²)`，
其中 `ρ_{j|ℱ}` 是 j 相对当前证据集 ℱ 的**残差相关**（不是原始相关）。选择
`q* = argmax_q [ I(y;c_j|ℱ) − c_comm(q) − c_motion(q) ]`，
s.t. 通信/时延预算与 C-RAS-WM 认证。ρ→1 时增益→0，故「再问一个同款机器人」自动无利可图。

**定义 317（多样性动作 DAC）** 独立性制造动作 `g_div ∈ {移动/旋转视角、切换编码器族、切换传感器模态、延迟到光照变化、主动遮挡/敲击}`。目标 `max E[Δρ(g_div)] / cost(g_div)`。独立性因此是动作的结果，而非系统的静态属性。DAC 必须区分并同时覆盖**表示独立**（κ 变）与**观测独立**（ν 变）；只覆盖一轴时报告为「半独立」，n_eff 取两轴中较小者。

**定义 318（相关拜占庭聚合 RBA）** 攻击者可按编码器族共模注入。按 `(κ,ν)` 分组，**组内视为 1 票**，组间做 Byzantine 多数/中位数。组数 m、容忍 `f < m/3` 个被完全攻陷的组。若全队共享同一编码器，则 m=1、容忍 f=0——共模攻击下名义多数完全失效（引理 22）。

**定义 319（共识幻觉检测 CHD）** 共享编码器可能让全队报告同一不存在目标。检测证据：非视觉通道（深度/激光/触觉/热成像）不一致；因果干预（遮挡、推动、开关灯）后目标不消失；异构编码器系统性分歧；出处哈希显示同一物理观测被重复注入。定义幻觉分
`S_hall = 1 − [Σ_c w_c·agree_c] / [Σ_c w_c]`，
仅对**跨通道且跨编码器**的一致性求和；单一编码器内部的跨机器人一致性不计入分子（那是回声）。

**定义 320（共享记忆去重 SMD）** 共享视觉记忆中同一物理观测被多机器人重复插入不得重复计票。按 `id_phys`（时空邻近 + 特征匹配）聚簇，每簇只贡献 1 个独立观测。定义有效记忆数 `|𝕄|_eff = #clusters`，并把「名义记录数 / 有效记忆数」作为回声比 `ER = |𝕄|/|𝕄|_eff` 纳入审计。

**定义 321（跨机器人标定与信任）** 机器人 i 的声明先过其 ECE_i 门（继承 R69 的 MCG）：`ECE_i > τ_ece` 不参与定案。可靠性用带遗忘因子的 Beta 后验更新，但**更新样本不得包含被该机器人结论验证过的样本**（防自证）；否则信任会随回声自我强化。

**定义 322（通信预算与时延）** 每条证据带时延 d，按信息衰减 `exp(−λ_d·d)` 降权；带宽预算下 TVoI 在「信息增益—时延—成本」三维上取 Pareto。过期证据不得计入 k。

**定义 323（证书 J_ECHO）** `J_ECHO = (J_FLUID, provenance_root, (κ,ν) 分布, ρ⁺, n_eff⁻, nominal_N, S_hall, ER, comm_delay_p95, echo_ver)`。Valid ⇔ Valid(J_FLUID) ∧ 出处可核验 ∧ (`n_eff⁻ ≥ k` 或已显式降级) ∧ 非共识幻觉 ∧ 审计通过。

**定义 324（干扰集 AIC-ECHO）** `ℰ_ECHO = ℰ_FLUID × ℰ_common_mode × ℰ_collusion × ℰ_cascade × ℰ_launder × ℰ_double_count`：共享编码器共模投毒/对抗补丁、多机串供、错误级联与从众、相关洗白（伪装独立）、共享记忆重复计数。

**定义 325（参与式审计 VQAuditor-M）** 审计跨机器人决策：出处是否完整、是否把回声当证据、n_eff 是否被高估、有无相关洗白、共享记忆是否重复计票、是否出现从众级联。结论回灌 AuditBuf。审计器本身必须由与主视觉编码器**正交**的通道抽检，避免审计器成为新的单点共模故障。

**定义 326（对 R69 的严格包含）** 当 N=1，或 ρ→0 且不发起任何跨机查询时，ECHO-RAS ≡ FLUID-RAS（逐指令相同）。协作层只可能增加证据或维持原判；`n_eff⁻ < k` 时绝不发放 resolution bonus，故安全侧永不弱于 R69。

**定义 327（独立性的可辨识性与锚点纪律）** ρ 只能在与被确认结论**无因果共享**的锚点上估计：已验证地标、受控干预（遮挡后应消失）、与主编码器物理正交的通道。若不存在这样的锚点，则 ρ 不可辨识，必须取 `ρ⁺=1`（n_eff=1）并退回 R69 保守。攻击者若能让锚点也只暴露低相关切片，就发生「相关洗白」；因此锚点集本身需随机化与留出，且不得由被审计方选择。

```python
# IP-266 ICE：从锚定共观测估计相关与有效证人数（保守下界）
def estimate_independence(team, co_obs_anchored, alpha=0.05):
    R        = residual_matrix(co_obs_anchored)      # e_i = c_i - c_anchor, 锚点与结论隔离
    rho_hat  = pairwise_corr(R)                      # 误差成分模型（定义 313）可做结构化收缩
    rho_plus = upper_conf_bound(rho_hat, alpha)      # 保守：宁可高估相关
    rho_bar  = mean_offdiag(rho_plus)
    n_eff    = len(team) / (1 + (len(team) - 1) * rho_bar)
    return rho_plus, n_eff                           # ρ⁺ 高 ⇒ n_eff⁻ 低

# IP-267 NEC：有效佐证纪律（名义多数 ≠ 有效多数）
def corroborate(claims, rho_plus, k=2):
    n_eff = effective_n(len(claims), rho_plus)
    status = 'confirmed' if n_eff >= k else 'nominal_only'
    return status, n_eff                             # nominal_only 不发 resolution bonus

# IP-268 TVoI：下一次向谁/从哪/用什么编码器求证（相关折扣后的边际信息）
def team_voi(belief, team, budget):
    best = None
    for q in query_candidates(team):                 # robot × view × encoder × modality
        if not budget.allow(q) or not c_ras_wm.certify_query(q): continue
        rho = residual_corr(q, belief.evidence)      # 相对已有证据的残差相关，而非原始相关
        voi = -0.5 * log(1 - clip(rho, 0, 1 - 1e-6) ** 2)   # 高斯证人边际互信息
        score = voi - comm_cost(q) - motion_cost(q)
        if best is None or score > best.score: best = (q, score)
    return best if best and best.score > 0 else None # 无利可图 → 不协作，走 R69

# IP-269 DAC：主动制造独立性（表示轴 κ + 观测轴 ν 同时变）
def decorrelate(team, belief, budget):
    cands = diversity_actions(team)                  # 换视角/换编码器/换模态/等待/敲击
    scored = []
    for g in cands:
        if not budget.allow(g) or not c_ras_wm.certify_info(g): continue
        drho = expected_drho(g, belief)              # 预期去相关量（两轴取小）
        scored.append((g, drho / (motion_cost(g) + comm_cost(g) + 1e-6)))
    return max(scored, key=lambda x: x[1])[0] if scored else None

# IP-270 RBA：相关拜占庭鲁棒聚合（组内 1 票，组间多数）
def aggregate(claims):
    groups = group_by(claims, key=lambda c: (c.kappa, c.nu))
    if len(groups) == 1:                             # 全队同编码器同视角
        return None                                  # 无法定案，退回 R69 保守
    return byzantine_median([fuse(g) for g in groups.values()])

# IP-271 CHD：共识幻觉检测（只认跨编码器 + 跨通道的一致）
def hallucination_score(claims, cross_channel):
    agree = weighted_agreement(claims, only_cross_encoder=True)
    xchan = weighted_agreement(cross_channel, only_cross_encoder=False)
    return 1.0 - (agree + xchan) / 2.0               # 高 ⇒ 疑似共享编码器幻觉

# IP-272 SMD：共享记忆去重（同一物理事件只计一票）
def dedup_memory(memory):
    clusters = cluster_by_physics(memory, key=lambda r: r.id_phys)
    return [fuse_cluster(c) for c in clusters.values()], len(memory) / len(clusters)

# IP-276 主闭环（继承 R69；仅在「证据是否独立」处插入 ECHO 层）
def ECHO_RAS_round(M, obs, team):
    # 1) 单机 FLUID 步不变
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    # 2) 带出处交换队友证据；共享记忆先去重
    claims = M.ceb.exchange(team, z)                 # 每条带 κ, ν, J_i, id_phys
    claims += M.smd.dedup_memory(M.shared_mem)
    # 3) 从锚定共观测估计独立性（不得用正在确认的结论做锚）
    rho_plus, n_eff = M.ice.estimate(team, M.co_obs_anchored)
    # 4) 若有效共识不足且疑似幻觉/回声 → 主动制造独立性
    if n_eff < K_CONF and (M.chd.hallucination_score(claims, M.cross_channel) > TAU_HALL
                           or M.smd.echo_ratio > TAU_ECHO):
        g_div = M.dac.decorrelate(team, M.belief, M.budget)
        if g_div is not None:
            claims += M.ceb.execute(g_div)
            rho_plus, n_eff = M.ice.estimate(team, M.co_obs_anchored | new_anchor(g_div))
    # 5) 有效佐证 + 相关鲁棒聚合
    status, n_eff = M.nec.corroborate(claims, rho_plus)
    fused = M.rba.aggregate(claims)
    # 6) 风险缩放：只有被有效佐证才拿 resolution bonus
    if status == 'confirmed' and fused is not None and not M.chd.hallucination(claims):
        U_floor = U_ale
    else:
        U_floor = U_ale + U_epi                      # R69 保守地板
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    # 7) 认证前缀 + 审计 + 证书
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    tau = M.pi_sigma.prefix_dispatch(select_mode(modes, U_epi, lam).a[:k]) * lam
    M.vqa_m.submit_async(claims, rho_plus, n_eff, status)
    return k, lam, fused, (n_eff, status)
```

## 3. 推导

**引理 19（设计效应与等价证人数）** 设团队可交换，`c_i=y+e_i`，Var(e_i)=σ²，任意对相关 ρ。则均值估计 `Var(c̄)=σ²/N·[1+(N−1)ρ]=σ²/n_eff`，Fisher 信息 `I_total ≈ n_eff·I_1`，故 n_eff 个独立证人等价于 N 个相关证人。要点：**当 ρ→1，n_eff→1，与 N 无关**；当 ρ=0，n_eff=N。系：增加同款机器人对信息的边际贡献为 `∂n_eff/∂N = (1−ρ)/(1+(N−1)ρ)²`，在 ρ→1 时趋于 0——这正是「回声集群」的数学形态。

**引理 20（独立性估计的可辨识性与相关洗白）** 用 m 个锚点共观测估计 ρ，Fisher-z 变换后 `SE(ρ̂)≈(1−ρ²)/√m`，故保守界 `ρ⁺=ρ̂+z_{1−α}SE`。但若锚点与被确认结论共享同一误差机制（同一编码器、同一被投毒切片），则真实 ρ 不可辨识：攻击者可使锚点上 `ρ̂→0` 而真实 ρ→1。结论：**没有独立锚点时必须令 ρ⁺=1**；锚点必须随机化、留出、且不得由被审计方选择，否则 n_eff⁻ 的置信下界是空洞的。

**引理 21（相关证人的边际信息）** 设 (y,c_j) 联合高斯、相关 ρ，则 `I(y;c_j)=−½log(1−ρ²)`。给定当前证据集 ℱ 后，新增证人 j 的边际增益为 `−½log(1−ρ_{j|ℱ}²)`，关于 `ρ_{j|ℱ}` 单调递减，ρ=1 时为 0。系：**TVoI 自动惩罚同款机器人**——不需要手工设「多样性奖励」，相关折扣就是奖励；这也解释了为何「再加一台同样的机器人」在信息上是零收益。

**引理 22（共模攻击击穿拜占庭容忍）** 若攻击者控制共享编码器族 κ₀，则所有 κ=κ₀ 的机器人可被同时诱导出任意一致的错误声明，与 N 无关。按 (κ,ν) 分组的 RBA 得到 m 组，若 m=1 则容忍 f=0（任意 1 次成功共模注入即定案错误）；要容忍 f 个被攻陷组需 `m ≥ 3f+1` 个独立组。故**异构编码器/异构观测簇不是锦上添花，而是拜占庭容错的前提条件**。

**定理 18（名义多数导致过度自信）** 若系统用 N 而非 n_eff 报告置信区间，则置信区间宽度被低估 `√(N/n_eff)=√(1+(N−1)ρ)` 倍。例：N=100、ρ=0.9 ⇒ 低估约 9.5 倍；N=16、ρ=1 ⇒ 低估 4 倍（此时 n_eff=1）。系：**任何以「N 台机器人一致」为卖点的系统，其真实置信度至多为 `√(1+(N−1)ρ)` 分之一**，必须用 J_ECHO 显式披露 ρ⁺ 与 n_eff⁻。

**定理 19（ECHO 严格包含 R69）** 当 N=1，或 ρ⁺→0 且不发起跨机查询时，定义 315 的 n_eff⁻=1、定义 316 的查询集为空，主闭环逐指令退化为 FLUID-RAS。且当 `n_eff⁻<k`、ECE 越界、或 S_hall 超阈时，ECTHO 不发放 resolution bonus、`λ` 取 R69 保守地板。因此对任意状态，ECHO 的期望风险 ≤ R69，且安全侧逐指令相同。

**定理 20（无有效独立则不定案）** 若 `n_eff⁻ < k`，则一致同意的后验置信不超过 `n_eff⁻` 个独立证人所给的置信；此时若系统仍按 N 定案，其错误概率可由引理 22 的下界放大。故 ECHO 强制在此情形下：证据降权为 n_eff⁻、禁止 resolution bonus、并触发 CHD/DAC 或退回 R69。系：**「有出处、可审计、有效独立」三者同时成立，才允许把队友的同意当作新信息**。

## 6. 本轮最大风险

**一句话**：ECHO-RAS 把整个协作层的可信度押在「独立性估计 ρ̂ 是诚实的」上——但 ρ̂ 只能从数据估，而数据往往正来自那个需要被检验的共享视觉编码器；一旦攻击者或静默共模故障让相关误差在锚点上**看起来独立**（相关洗白），系统就会把 N 个回声当作 N 个独立证人，用一个幻觉出来的共识触发 R69 的 resolution bonus——**多机共识于是从「纠错机制」变成「自信放大器」，比单机问错更危险**。

**次级风险与缓解**：
1. **锚点不可辨识**（无独立锚点 / 锚点被污染）→ 定义 327：无锚点即 ρ⁺=1、n_eff=1，退回 R69；锚点随机化 + 留出 + 不得由被审计方选择；
2. **共享记忆重复计票**（回声比 ER 高）→ SMD 物理事件去重 + ER 纳入证书与审计；
3. **共模编码器投毒**（m=1 时拜占庭容忍为 0）→ HVE 强制 ≥3 个独立编码器/观测簇组 + RBA 组间多数 + E306 对抗训练；
4. **协作开销击穿实时预算** → 增量 ICE + 缓存锚点 + 仅疑似回声时触发 DAC/TVoI；
5. **审计器自身共模** → VQAuditor-M 由与主编码器物理正交的通道抽检，避免审计成为新的单点。

```python
def estimate_independence(team, co_obs_anchored, alpha=0.05):
    R        = residual_matrix(co_obs_anchored)     # 锚点不得来自正在确认的结论
    rho_plus = upper_conf_bound(pairwise_corr(R), alpha)   # 保守：宁可高估相关
    rho_bar  = mean_offdiag(rho_plus)
    return rho_plus, len(team) / (1 + (len(team)-1) * rho_bar)

# IP-267 NEC：名义多数 → 有效多数
def corroborate(claims, rho_plus, k=2):
    n_eff  = effective_n(len(claims), rho_plus)
    status = 'confirmed' if n_eff >= k else 'nominal_only'
    return status, n_eff                            # nominal_only 不发 resolution bonus

# IP-268 TVoI：下一次向谁/从哪/用什么编码器求证
def team_voi(belief, team, budget):
    best = None
    for q in query_candidates(team):                # robot × view × encoder × modality
        if not budget.allow(q) or not c_ras_wm.certify_query(q): continue
        rho   = residual_corr(q, belief.evidence)   # 残差相关，而非原始相关
        voi   = -0.5 * log(1 - clip(rho, 0, 1-1e-6) ** 2)
        score = voi - comm_cost(q) - motion_cost(q)
        if best is None or score > best.score: best = (q, score)
    return best if best and best.score > 0 else None   # 无利可图 → 不协作，走 R69

# IP-269 DAC：主动制造独立性（表示轴 + 观测轴）
def decorrelate(team, belief, budget):
    best = None
    for g in diversity_actions(team):               # 换视角/换编码器/换模态/等待/敲击
        if not budget.allow(g) or not c_ras_wm.certify_info(g): continue
        drho   = min(expected_drho_rep(g), expected_drho_obs(g))
        score  = drho / (motion_cost(g) + comm_cost(g) + 1e-6)
        if best is None or score > best[1]: best = (g, score)
    return best[0] if best else None

# IP-270 RBA：组内 1 票、组间多数
def aggregate(claims):
    groups = group_by(claims, key=lambda c: (c.kappa, c.nu))
    if len(groups) == 1: return None                # 全队同款 → 无法定案，退回 R69
    return byzantine_median([fuse(g) for g in groups.values()])

# IP-276 主闭环（继承 R69；仅在“证据是否独立”处插入 ECHO 层）
def ECHO_RAS_round(M, obs, team):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    claims = M.ceb.exchange(team, z) + M.smd.dedup_memory(M.shared_mem)
    rho_plus, n_eff = M.ice.estimate(team, M.co_obs_anchored)
    if n_eff < K_CONF and (M.chd.hallucination_score(claims, M.cross_channel) > TAU_HALL
                           or M.smd.echo_ratio > TAU_ECHO):
        g = M.dac.decorrelate(team, M.belief, M.budget)
        if g is not None:
            claims += M.ceb.execute(g)
            rho_plus, n_eff = M.ice.estimate(team, M.co_obs_anchored | new_anchor(g))
    status, n_eff = M.nec.corroborate(claims, rho_plus)
    fused = M.rba.aggregate(claims)
    U_floor = U_ale if (status == 'confirmed' and fused is not None
                        and not M.chd.hallucination(claims)) else U_ale + U_epi
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k   = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    tau = M.pi_sigma.prefix_dispatch(select_mode(modes, U_epi, lam).a[:k]) * lam
    M.vqa_m.submit_async(claims, rho_plus, n_eff, status)
    return k, lam, fused, (n_eff, status)
```

## 4. 推导

**引理 19（设计效应）** 可交换团队下 `Var(c̄)=σ²/N·[1+(N−1)ρ]=σ²/n_eff`，`I_total≈n_eff·I_1`。边际贡献 `∂n_eff/∂N=(1−ρ)/[1+(N−1)ρ]²→0`（ρ→1）——回声集群的数学形态。

**引理 20（可辨识性与相关洗白）** `SE(ρ̂)≈(1−ρ²)/√m`，保守界 `ρ⁺=ρ̂+z_{1−α}SE`。若锚点与被确认结论共享同一误差机制，真实 ρ 不可辨识，攻击者可使 `ρ̂→0` 而真实 ρ→1。故无独立锚点必须取 ρ⁺=1；锚点须随机化、留出、不得由被审计方选择。

**引理 21（相关证人的边际信息）** 高斯下 `I(y;c_j)=−½log(1−ρ²)`，关于 ρ 单调递减、ρ=1 时为 0。系：TVoI 的「多样性奖励」就是相关折扣本身；同款机器人信息边际为 0。

**引理 22（共模攻击击穿拜占庭容忍）** 控制编码器族 κ₀ 的攻击者可让所有 κ=κ₀ 机器人给出任意一致错误，与 N 无关。分组聚合得 m 组；m=1 ⇒ f=0；容忍 f 组需 `m≥3f+1` 个独立组。异构编码器/观测簇是拜占庭容错的**前提**，不是附加项。

**定理 18（名义多数 ⇒ 过度自信）** 用 N 而非 n_eff 报置信，区间宽度低估 `√(1+(N−1)ρ)` 倍。N=100、ρ=0.9 ⇒ 低估 9.5×；N=16、ρ=1 ⇒ 低估 4×（n_eff=1）。系：J_ECHO 必须披露 ρ⁺ 与 n_eff⁻。

**定理 19（ECHO 严格包含 R69）** N=1 或 ρ→0 且无跨机查询时逐指令退化为 FLUID-RAS；`n_eff⁻<k` / ECE 越界 / S_hall 超阈时不发 resolution bonus、取 R69 保守地板 ⇒ 任意状态期望风险 ≤ R69，安全侧逐指令相同。

**定理 20（无有效独立则不定案）** `n_eff⁻<k` 时一致同意的后验置信不超过 n_eff⁻ 个独立证人所给置信；按 N 定案会被引理 22 的下界放大错误。故强制降权为 n_eff⁻、禁止 bonus，并触发 CHD/DAC 或退回 R69。系：「有出处 + 可审计 + 有效独立」三者同时成立，队友的同意才算新信息。

## 7. 本轮最大风险

**一句话**：ECHO-RAS 把协作层可信度押在「独立性估计 ρ̂ 诚实」上——但 ρ̂ 只能从数据估，而数据往往正来自那个需要被检验的共享视觉编码器；一旦共模故障或攻击者让相关误差在锚点上**看起来独立**（相关洗白），系统就会把 N 个回声当 N 个独立证人，用幻觉出的共识触发 R69 的 resolution bonus——**多机共识从「纠错机制」变成「自信放大器」，比单机问错更危险**。

**次级风险与缓解**：无独立锚点（定义 327：ρ⁺=1、n_eff=1，退回 R69）；共享记忆重复计票（SMD 物理事件去重 + ER 入证）；共模编码器投毒（HVE 强制 ≥3 独立组 + RBA 组间多数 + E306 对抗训练）；协作开销击穿实时预算（增量 ICE + 锚点缓存 + 仅疑似回声触发 DAC/TVoI）；审计器自身共模（VQAuditor-M 由正交通道抽检）。
