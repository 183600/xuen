# 第 74 轮（承接第 73 轮「MODGAUGE-RAS 计量契约代数」IP-295~301；灵感循环第 4 轮；本轮灵感：「意图理解」×「ROS2」）

> R73 把「模块化」从代码分包升格为计量契约代数：EC 是接口，CCA 是组合规则，J_MOD 是组合证书，热替换与零级联由定理保证。但它把两样最要命的东西留在了契约之外：
> - **意图仍在契约之外**：R72/R73 的 IRL 把意图当作潜变量 z，用 p(z|y) 估计——这是**观测性**语义。可行器人一旦依据估计行动，人的行为分布就被改变了（performativity）。`p(y|s)`、`p(y|do(a))`、`p(y|π(ŷ))` 是三个不同的对象；把后验点估计当成意图，等于把机器人自己生产出来的分布当成客观事实。R72 用「意图隐变量 + KL 反作用」记录了一部分，却没有区分「我观测到人想要 X」与「我通过行动让人想要 X」。更危险的是，这个循环可以收敛——收敛到一个**自信但虚无**的固定点：系统对一个人造意图给出低熵后验，而审计日志显示每一步都合规。
> - **ROS2 仍在定理之外**：R73 的引理 33–37、定理 27–29 全在抽象 MReg 上成立。真实 ROS 2 部署里，`BEST_EFFORT` 静默丢包、`KEEP_LAST` 覆盖合并、`deadline`/`liveliness` 决定证据是否还有效、`use_sim_time` 与时钟跳变破坏追溯顺序、executor 回调组可造成优先级反转、生命周期状态天然对应 stub、运行时参数可篡改契约阈值、SROS2 决定谁能投否决票。每一条都能让「图合法、证书齐全」的系统在部署层静默违反预算闭合或追溯完整——**逻辑证书为真，物理事实为假**。
> - **两者的交集才是真正的威胁**：意图证据最依赖时间语义（人说话的时序、注视的先后、承诺的撤销），而 ROS2 恰恰是最容易让时间语义悄悄错位的地方。若意图通道跨节点、跨时钟域、跨 QoS 剖面传递，则「谁在什么时候表达了什么意图」可能在中间件层被重排、丢弃或合并，而意图后验仍然漂亮。
>
> 本轮三个新增灵感（第 5 个是元灵感）：
> - **意图理解 → 意图契约 IC + 表演稳定 + 可辨识类 + 主权约束**：意图不是被发现的隐藏状态，而是被**协商、撞定、可撤销**的契约；保留等价类而非点估计；动作改变意图分布，必须求**表演固定点**并检测振荡；用**反事实选项熵**区分「引导」与「操纵」。
> - **ROS2 → 部署面向 DF + 精化关系 ⊑ + 部署证书 J_DEP + QoS 计量语义映射**：把每个 EC 字段映射到 ROS2 资源元组（类型/QoS/生命周期/executor/时钟/安全/参数），并证明部署精化抽象图；QoS 损失、时钟跳变、优先级反转、参数篡改都必须转化为**显式的 u 膨胀、τ 断链或 stub**，而非静默降级。
> - **元灵感（反单体纪律）**：意图与部署都必须以「新证据类型 / 新精化目标」接入，**不得新增手写系统层**。R73 刚刚把层数从系统结构降为模块声明；本轮若为意图加一个手写 L5、为 ROS2 加一个手写适配层，就是把单体病请回来。
>
> 核心命题：**不再问「机器人是否理解了人的意图」，而问「意图能否成为带契约、可撞定、可撤销、可部署精化的证据——使系统在分布被自身行动改变、且中间件会静默违约的条件下，仍然只能组合出经过审计的世界？」** 把 R73 的 MODGAUGE 重构为 **PACT-GAUGE-RAS**（Performative-contractual And deployment-refined intent metrology with GAUGE audits for RAS）——**意图契约 × 表演稳定性 × 部署精化**。

## 0. 直觉与动机

**灵感 1（意图理解 → 意图是被协商的契约，不是待估的隐状态）**
直觉：人对机器人说「把那个拿过来」，这句话本身不构成一个确定意图。它欠定（哪个？拿来做什么？多急？可撤销吗？），而且**会随机器人的回应而改变**——机器人问「是左边那个吗」，人可能说「对」，也可能改口「算了，拿右边」。所以意图理解不是 passively 解码一个固定目标，而是**共同把一个意图撞定下来**。正确抽象是**意图契约 IC**：候选意图集 H、观测模型、允许动作集、**撞定规则 ρ**（显式确认 / 行为承诺 / 多次一致）、**撤销与修复条款 R**、**主权约束 S**、追溯链 τ。机器人不应输出「意图 = X，置信度 0.93」，而应输出「当前可辨识类 [h]_I 与撞定等级 L；该等级只支持风险 ≤ r(L) 的动作」。这把 R72 的意图后验从「一个数」升级为「一个带门控的证据对象」。关键收益：**意图误读不再是「分类错误」，而是「撞定等级不足却行动」的违约**——可审计、可归责、可修复。

**灵感 2（表演性 → 意图分布是机器人策略的函数，必须求固定点）**
直觉：如果机器人根据「人想让我靠近」的后验而靠近，人可能因此后退或改变目标；于是「人想让我靠近」这个后验被自己的行动改写。这就是**表演性预测（performative prediction）**：部署的策略改变数据分布。意图理解里它比一般预测更尖锐，因为被改变的正是**标签本身的生成过程**。形式化：设信念更新算子 T，策略 π 由信念 b 诱导，则稳定信念满足 b* = E_{y∼p(y|h,a), a∼π(b*)}[T(b*, y; a)]。若后向作用增益（shift map 的 Lipschitz 常数）γ < 1，Banach 给出唯一固定点；γ ≥ 1 则可能振荡或多重均衡。**振荡本身就是危险信号**：机器人和人陷入「你追我退 / 我进你改口」的意图极限环。R72 的 KL 反作用只记录「我的动作改变了观测」，没有要求固定点存在；本轮把「表演稳定」变成部署前的**可证伪条件**，并加**极限环检测器**。系：**意图理解的安全性不能只靠后验校准，还要靠信念动力系统的稳定性。**

**灵感 3（可辨识性与主权 → 能引导，不能操纵）**
直觉：很多意图在当前观测下**不可区分**（"拿那个" 在遮挡时可能指 A 或 B）。主动消歧（问一句、换个视角）能缩小等价类，这是好的。但同样的动作也能**制造**意图：反复把 A 推到人面前，人会「想要」A。两者在信息论上可能都降低熵，但伦理与安全地位相反。区分它们的不是当前信念熵，而是**反事实选项熵**：如果机器人不行动，人的意图分布会是什么？若机器人的行动显著压缩了人的反事实选项集（且依赖人的错误信念或不可逆承诺），则判为**操纵**，触发非补偿否决。这把「意图主权」形式化为一个可监测的约束，而不是一句伦理口号。系：**意图理解系统的正确性指标里必须包含「不替人做决定」这一项。**

**灵感 4（ROS2 → 部署是精化，不是配置；QoS 是计量语义的一部分）**
直觉：R73 的 EC 字段在 ROS2 里没有天然对应物，工程师会用手工 YAML 把它们「尽量配上」——这正是静默违约的温床。正确做法是定义**部署面向 DF**：每个 EC 字段 →（消息类型，QoS 剖面，生命周期状态，executor/回调组，时钟域，安全策略，参数模式）。然后证明一个**精化关系 ⊑**：ROS2 部署图 D 精化抽象模块图 M，当且仅当存在模拟关系，使每个 EC 义务在部署语义下保持（在声明的损失上界内）。`BEST_EFFORT` 丢包不是「配置选择」，而是**样本损失 → u 膨胀 + 追溯缺口**；`KEEP_LAST(K)` 不是「缓冲区大小」，而是**合并上界 → 陈旧度**；`deadline` 不是「监控项」，而是**证据有效期**；`liveliness` 失败就是 **stub 触发**；时钟跳变是 **τ 断链**，必须否决而非继续。系：**中间件不是透明的管子，它是有计量语义的物理层；把它当配置就是在合同里留空白。**

**灵感 5（元灵感 → 意图与部署不得成为新的手写层）**
直觉：本轮有两个巨大的诱惑——为意图加一个 L5 反作用层，为 ROS2 加一个手写适配层。两者都会重演 R72 的单体病。纪律：意图是一个**证据类型模块**（可 SER/PAR/VETO 组合、带 χ_I 反作用通道、带 IC 契约），ROS2 是一个**精化目标 + 部署证书**（不改抽象图，只约束实现）。若某个功能无法写成「模块 + 契约 + 精化义务」，它就不进核心认证路径。这条纪律本身要被审计：新增的 `|V_M|` 计入 R73 定义 377 的结构上限，新增的部署义务计入 J_DEP。系：**「意图」与「部署」的合法性来自它们服从既有代数，而不是来自它们重要。**

## 1. 形式化定义（增量：定义 383–400）

**定义 383（PACT-GAUGE-RAS 总览）** PACT-GAUGE-RAS = (MODGAUGE-RAS†, IC, PIS, ISV, DRF, QMM, LES, J_DEP, CPB-v5)。六不变式：
(i) **契约完整性**（继承定义 366(i)）：意图与部署相关组件同样必须有 EC，缺一不入图；
(ii) **组合单调性**（继承引理 34）：意图证据经 CCA 组合，缩窄仅在跨通道一致性审计通过时允许；
(iii) **反作用通道完备**（扩定义 371）：新增意图通道 χ_I 仍以模块字段声明，层数由模块数给出；
(iv) **表演稳定**：意图信念必须收敛到固定点或显式进入拒绝态，禁止在振荡中行动；
(v) **意图主权**：任何动作不得使反事实选项熵低于 τ_S；操纵触发非补偿否决；
(vi) **部署精化**：任何进入物理执行的部署必须附 J_DEP，Valid(J_DEP) ⇒ 部署精化抽象图；精化失败 ⇒ 降级而非运行。

**定义 384（意图契约 IC）** IC = (H, O, A, ρ, R, S, τ_I)：
- H：候选意图空间（离散标签 × 参数，或结构化目标树），|H| 可连续但必须有可计算的等价类代表元；
- O = {p(y | h, s, a)}_{h∈H}：意图条件观测模型（y 含语言/手势/注视/示教/遥操作）；
- A：当前允许动作集（受 REG 与控制域约束）；
- ρ：撞定规则——把证据历史映射到撞定等级 L ∈ {∅, weak, strong, revoked} 与对应最大可执行风险 r(L)；
- R：撤销/修复条款——新证据与已撞定意图矛盾时的回退与再协商协议；
- S：主权约束（定义 389）；
- τ_I：意图证据追溯链（来源节点、时钟域、签名、序号），与 R73 的 τ_merge 兼容。

**定义 385（意图三重语义）** 同一意图证据有三种分布：
- **观测性** `p_o(y | h, s)`：机器人不动，只是观察；
- **干预性** `p_i(y | h, s, do(a))`：机器人强制采取 a 后的观测分布；
- **表演性** `p_p(y | h, s, π_θ)`：机器人按策略 π_θ（依赖自身信念）行动后的观测分布，且人的隐意图本身可随之改变：`h' ∼ Q(h' | h, a)`。
三者一般互不相等。**PACT 只允许用 p_i / p_p 做部署期风险推断；用 p_o 训练的分类器进入核心路径必须在 J_DEP 上显式标注其语义，并给出表演性偏移界。**

**定义 386（意图可辨识类与可辨识半径）** 给定证据历史 y_{1:t} 与允许动作集 A，意图的**可辨识类**
`[h]_I = { h′ ∈ H : p(y_{1:t} | h′, s, a_{1:t}) = p(y_{1:t} | h, s, a_{1:t})， ∀a ∈ A }`。
**可辨识半径** `r_I = diam_𝒹([h]_I)`（𝒹 为意图空间上的任务相关度量）。机器人维护的是 `[h]_I` 及其测度，而非单点 `ĥ`。**主动消歧**选择 a 使 `E[ r_I(y_{t+1}) | a ]` 下降最多，同时扣除动作成本与主权成本（定义 389）。

**定义 387（表演稳定性与表演最优性）** 设信念更新算子 `T: 𝔅 × Y × A → 𝔅`，策略 `π: 𝔅 → Δ(A)`。**表演稳定信念** b* 满足
`b* = E_{a∼π(b*), y∼p_p(y | b*, a)}[ T(b*, y, a) ]`
（即 b* 是复合映射 `Π = E[T]∘π` 的不动点）。**表演最优**则是 `π* = argmin_π Risk(π; D(π))`，未必稳定。PACT 要求：进入核心行动前，信念必须处于（或已收敛到）表演稳定集；检测到 2-周期或极限环 ⇒ 进入 `INTENT_OSC` 拒绝态。

**定义 388（意图反作用通道 χ_I）** 每个意图证据模块在 EC 中声明
`χ_I: A × 𝔅 → (Θ_human, D′)`：动作如何改变人的意图分布参数与有效域（平凡恒等表示「我的动作不影响人的意图」——这本身是一个需要被审计的强假设）。通道成本
`c_reflex^I(a, b) = E_{h∼b}[ KL( Q(·|h,a) ‖ Q(·|h,a_0) ) ] + λ_H·ΔH_S(a)`，
其中 a_0 为「不干预」基线，第二项是主权偏离惩罚。ΣREFLEX 预算把 c_reflex^I 与 ψ/z/c/v 合算（定义 371†）。

**定义 389（意图主权约束 S）** 设 `H_cf(a) = H(h | do(robot = a), evidence)` 为**反事实**意图熵（把人自身的偏好生成过程与机器人的影响分开）。主权约束：
`H_cf(a) ≥ τ_S` 且 `Reversibility(a) ≥ ρ_min`。
**操纵**定义为：动作 a 使 `H_cf` 显著低于不干预基线，且增益主要来自利用人的错误信念、不可逆承诺或信息不对称（而非提供真实信息）。操纵 ⇒ `I⊥` 加入 `MANIPULATION`，VETO 组合非补偿地否决该动作弧。注意：**真实信息增益（如指出遮挡后的真实选项）不算操纵**——区分靠「若人知道全部信息是否仍会同意」这一反事实检验（可操作化为受控用户实验 + 信息完备基线）。

**定义 390（撞定协议与行动门控）** 撞定等级映射到最大可执行风险：`L=∅ ⇒ r=0`（只能观察/提问），`L=weak ⇒ r ≤ r_w`（可逆、低风险动作），`L=strong ⇒ r ≤ r_s`，`L=revoked ⇒ 立即停止依赖该意图的动作并进入 R`。门控谓词：
`Gate(a, b) = [ r(a) ≤ r(L(b)) ] ∧ [ [h]_I 的测度集中在安全集 ] ∧ ¬OSC ∧ S 满足`。
**关键**：撞定等级只由**独立性证据**提升（不同模态、不同时间、不同来源），单一来源不能把等级推到 strong（继承 R71 单源不定案）。

**定义 391（部署面向 DF）** 对 MReg 的每条边 e（契约组合实例），部署面向
`DF(e) = (msg_type, qos, lifecycle_map, executor, clock, security, param_schema, composition)`，
其中：`msg_type` 含类型哈希与字段级不可截断声明；`qos` = (reliability, durability, history, depth, deadline, lifespan, liveliness)；`lifecycle_map` 把生命周期状态映射到证据状态；`executor` = (回调组类型，优先级，WCET 预算)；`clock` = (时钟源，同步协议，域标签)；`security` = SROS2 enclave/权限；`param_schema` 声明哪些参数属于 EC 冻结字段；`composition` = 节点组合/容器布局。

**定义 392（部署精化关系 ⊑）** `M ⊑ D`（部署图 D 精化抽象模块图 M）当且仅当存在模拟关系 R ⊆ State_M × State_D，使得对 M 的每个 EC 义务 φ，D 中存在可执行策略在损失界 `ℓ(φ)` 内实现 φ：
- **类型**：消息反序列化后 EC 要求的字段与不确定度分量齐全（禁止适配器把六分量压成标量）；
- **预算闭合**：𝒰_in ⊆ 𝒰_out、τ_merge 可复算，跨进程/跨 DDS 边界不被截断；
- **通道**：χ_R/χ_I 的参数可写且被审计；动作映射在有效域内；
- **域**：D 的 QoS/生命周期/前置条件不弱于 EC 的 D；
- **否决**：I⊥ 的权限与不可补偿性在 SROS2 下可执行；
- **时序**：W 的 WCET/RTA 在 executor 与 DDS 下成立；
- **密封**：seal_ref 的工件哈希可验证。
`ℓ(φ)` 是显式损失上界（不可消除的近似），必须进入 u 的预算或触发 stub。

**定义 393（部署证书 J_DEP）** `J_DEP = (⟨proof_φ⟩_{φ∈EC} , ℓ_total, clock_alignment, lifecycle_proof, rta_proof, security_proof, qos_loss_bound)`。`Valid(J_DEP) ⇒ M ⊑ D`（引理 41）。J_DEP 与 R73 的 J_MOD 相乘构成端到端证书：`J_PACT = J_MOD ⊗ J_DEP`；Valid(J_PACT) ⇒ 抽象安全性质在物理部署上成立（定理 32，模损失界）。

**定义 394（QoS 计量语义映射 QMM）** 把 QoS 参数解释为计量量：
- `reliability=BEST_EFFORT`：样本丢失率 `p_loss` ⇒ `u ← u ⊕ inflate(p_loss)` 且 `τ` 序号缺口 ⇒ 若缺口不可检出则**合同违约**（不是「尽力而为」）；
- `history=depth K, KEEP_LAST`：覆盖合并 ⇒ 陈旧度上界 `Δ_stale ≤ K / f`；进入 u_motion/域；
- `durability=VOLATILE/TRANSIENT_LOCAL`：冷启动证据是否为真；标定/密封必须 TRANSIENT_LOCAL；
- `deadline`：证据有效期；超期 ⇒ 域失效（stub），不是「延迟」；
- `lifespan`：样本过期 ⇒ 陈旧；
- `liveliness`：发布者失活 ⇒ stub 触发；
- `time_based_filter`：主动降采样 ⇒ 必须计入 u_edge/u_motion，禁止未声明降采样。
**原则：QoS 的每一个参数都必须有一个计量解释，否则不允许进入 J_DEP。**

**定义 395（时钟域与追溯一致性）** 每条证据携带 `clock_domain`（单调时钟 / PTP / chrony / sim-time）与源时间戳 + 序号 + nonce。追溯合并只允许在同一时钟域内做差；跨域必须通过显式的域偏移估计（带不确定度）。时钟跳变、回退、`use_sim_time` 切换 ⇒ `τ` 断链 ⇒ 域失效 + 否决，禁止用「墙钟排序」掩盖。**意图证据尤其严格**：说话/注视/承诺的先后顺序决定撞定合法性，跨域乱序可能把「先承诺后撤销」读成「先撤销后承诺」。

**定义 396（生命周期-证据状态同构与参数契约锁）** 生命周期状态映射：`unconfigured ↦ 证据 ∅`、`inactive ↦ stub`（定义 381）、`active ↦ 证据有效`、`finalized ↦ dead`。状态转换是 stub 的唯一合法入口，且必须相对快照**原子**（不能在证据半更新时切换）。**参数契约锁**：EC 冻结字段（阈值 τ_m、六分量校准、χ_R/χ_I 参数、否决集）在运行时不可改；任何修改必须携带 MReg 签发的再认证令牌，否则拒绝并审计。普通参数（日志级别等）不受限。

**定义 397（执行器时序隔离的部署落地）** ROS2 执行器语义：mutually-exclusive 回调组 ⇒ 串行、可做 RTA；reentrant 回调组 ⇒ 需显式并发证明；优先级继承/优先级天花板 ⇒ 反转上界。计量/控制域必须落在**不同回调组且可抢占**；控制域回调不得持锁等待感知域。`rta_proof` 给出 P99 上界；若无法证明则控制域与计量域不得共享 executor。

**定义 398（意图证据的跨节点溯源与不可否认性）** 意图消息必须签名（SROS2 + 消息级 nonce/序号），来源节点、采集时刻、模态、原始证据哈希进入 τ_I。重放/伪造检测：序号单调 + nonce + 时间窗；失败 ⇒ `τ` 断链。**单源不定案**：单一节点（即使签名有效）不能把撞定等级推到 strong；跨模态一致性（语言-手势-注视-行为）必须经 PAR 审计。被入侵节点最多导致该模态 stub，不得伪造强撞定。

**定义 399（部署热替换）** ROS2 层的热替换 = 节点组合/生命周期迁移（active→inactive→reconfigured→active）或容器内替换。要求：替换前后 `J_DEP` 的逐字段义务保持，`J_PACT` 重新校验，且切换在快照原子点完成；否则退回旧实现。替换分「同契约替换」（引理 35 直接适用）与「跨契约替换」（需重跑 DRF + 模块级重认证）。

**定义 400（主张预算与严格包含）** CPB-v5 允许 ≤5 条主张（C1–C5），每条必须有**杀死实验**（能证伪的最小实验）；新增主张若不能杀死，则降级为工程附件。PACT 严格包含 MODGAUGE：令 IC 为平凡契约、χ_I ≡ id、S 恒真、DF 为理想无损失部署，则逐指令等于 R73。

# IP-302 IC：意图契约与撞定门控（意图是证据类型，不是新层）
@dataclass(frozen=True)
class IntentContract:
    H: IntentSpace                       # 候选意图（离散标签×参数/结构化目标）
    obs_model: Callable                  # p_i / p_p，禁止未标注的 p_o 进入核心路径
    rho: Callable[[EvidenceHist], RatLevel]   # 撞定规则 ∅/weak/strong/revoked
    repair: Callable                     # 撤销/再协商协议 R
    sovereignty: 'SovereigntyConstraint'
    tau_I: TraceChain
    chi_I: Callable[[Action, Belief], NoiseMod]   # 意图反作用通道（可平凡）

def ratification_gate(a, b, ic):
    L = ic.rho(b.history)
    r = RISK[a]
    if L == 'revoked': return False, 'REPAIR'
    if r > R_MAX[L]: return False, 'INSUFFICIENT_RATIFICATION'
    if not b.identifiable_class.safe_dominant(): return False, 'AMBIGUOUS'
    if oscillation_detected(b): return False, 'INTENT_OSC'
    if not ic.sovereignty.ok(a, b): return False, 'MANIPULATION'
    return True, L

# IP-303 PIS：表演稳定意图推断（固定点 + 可辨识类 + 振荡检测）
class PerformativeIntentInference:
    def step(self, b, y, a):
        b2 = self.T(b, y, a)                         # 贝叶斯/证据更新
        b2.I = self.identifiable_class(b2, self.A)   # 保留等价类，不塌缩成点
        return b2
    def deploy(self, pi, b0):
        hist = []
        for _ in range(self.max_iter):
            a = pi(b0)
            y = self.observe(a)                      # p_p(y|b0,a)
            b1 = self.step(b0, y, a)
            hist.append((b0, a, b1))
            if self.contraction_ok(hist):            # 后向作用增益 γ<1（引理 38）
                return ('STABLE', b1)
            if self.limit_cycle(hist):               # 2-周期/环 ⇒ 拒绝（定义 387）
                return ('INTENT_OSC', b1)
            b0 = b1
        return ('UNSTABLE', b0)

# IP-304 ISV：意图主权监控（反事实选项熵，区分引导/操纵）
class SovereigntyConstraint:
    def ok(self, a, b):
        H_cf = self.counterfactual_option_entropy(a, b)   # do(robot=a) vs 不干预
        if H_cf < self.tau_S: return False                # 压缩了人的选项集
        if self.reversibility(a) < self.rho_min: return False
        if self.gain_from_false_belief(a, b): return False # 依赖人的错误信念 ⇒ 操纵
        return True

# IP-305 DRF：部署面向编译与精化校验
def compile_facet(ec, ros2_resources):
    return DeploymentFacet(
        msg_type = type_hash(ec.T_out),                  # 字段完整、不可截断
        qos      = qos_for(ec),                          # 每个参数有计量解释（定义 394）
        lifecycle= lifecycle_map(ec.D),
        executor = executor_for(ec.W, ec.domain_tag),    # 回调组/优先级/RTA
        clock    = clock_domain(ec.seal_ref),
        security = sros2_policy(ec.I_bottom, ec.seal_ref),
        params   = freeze(ec.ec_fields),                 # 参数契约锁（定义 396）
        composition = placement(ros2_resources))

def refinement_check(M, D, j_dep):
    for e in M.edges:
        df = D.facet[e]
        for phi in obligations(e.ec):                    # 定义 392 逐字段
            if not j_dep.proves(phi, df): return False, phi
    return loss_bound(j_dep) <= M.u_budget, None        # 损失必须进预算

# IP-306 QMM：QoS 损失 → 不确定度/断链（禁止静默）
def qos_to_metrology(header, qos, seq_state):
    u = header.u
    if qos.reliability == 'BEST_EFFORT':
        if not seq_state.gap_detectable: return VIOLATION('SILENT_LOSS')
        u = inflate(u, qos.p_loss_estimate)
    if qos.deadline and header.age > qos.deadline:
        return STUB('DEADLINE_EXPIRED')                  # 有效期，不是延迟
    if qos.liveliness_lost: return STUB('LIVELINESS_LOST')
    if clock_jump(header.clock_domain) or replay(header):
        return VETO('TRACE_BREAK')                       # 时钟跳变=断链
    if qos.time_based_filter and not header.declared_downsample:
        u = inflate(u, filter_loss(qos))
    return EVIDENCE(u=u, tau=header.tau.merge(seq_state))

# IP-307 LES：生命周期-证据状态监督 + 参数契约锁
def lifecycle_supervisor(node, snapshot):
    st = node.lifecycle_state
    if st == 'inactive': return stub(node)               # 定义 396
    if st == 'finalized': return DEAD
    if st == 'unconfigured': return EMPTY
    return node.evidence

def guarded_set_parameter(node, name, value, token):
    if name in node.ec.frozen_fields and not MREG.verify_recert(token):
        audit.reject(name, value); return False          # 冻结字段：拒绝
    return node.set_parameter(name, value)

# IP-308 DEP：部署证书与热替换编排
def certify_deployment(M, D):
    j_dep = J_DEP(
        proofs   = [prove_field(e, D.facet[e]) for e in M.edges],
        loss     = total_loss(M, D),
        clock    = prove_clock_alignment(M, D),
        lifecycle= prove_lifecycle_map(M, D),
        rta      = prove_wcet(M, D),
        security = prove_sros2(M, D),
        qos      = prove_qos_semantics(M, D))
    assert Valid(j_dep) and refinement_check(M, D, j_dep)[0]
    return j_dep

def hot_swap_ros2(old_node, new_node):
    snapshot = atomic_point()                            # 快照原子点（定义 399）
    new_node.configure(); new_node.activate()
    j_new = certify_deployment(M, D_with(new_node))
    if not Valid(j_new): new_node.deactivate(); return old_node   # 退回旧实现
    old_node.deactivate(); return new_node

# IP-309 PACT 主闭环（MODGAUGE† 升级；意图/部署均以契约接入）
def PACT_round(M, obs, audio, tac_frame, depth_img, human_msgs):
    # === 感知域（异步 100Hz）===
    d_ev  = M.dpe.update(depth_img, rgb, M.cam_state, M.motion, M.peers)
    if not d_ev.valid: d_ev = stub(M.dpe)
    t_ev  = M.dmem.update(tac_frame, M.last_action)
    psi_hat, ece = M.aura.update(audio)
    i_ev  = M.iir.update(human_msgs, obs, M.last_action, M.clock_domain)  # 意图证据

    i_ev  = qos_to_metrology(i_ev.header, M.iir.qos, M.iir.seq_state)     # QoS 计量

    # === 计量域（50Hz，软实时）===
    if M.clock.due_metric():
        b_t = M.bse.step_full(..., d_ev=d_ev, t_ev=t_ev)
        z_dist, ece_z, iota_z = M.irl.update(M.y_intent_buf, psi_hat, b_t)
        # 意图：固定点判定 + 可辨识类 + 主权/撞定
        status, b_int = M.pii.deploy(M.policy, M.b_int)
        if status != 'STABLE': M.intent_mode = 'REFUSE'; return M.safe_hold()
        L = M.ic.rho(b_int.history)
        M.pvop = viewpoint_aware_plan(b_t, M.mods, M.risk_params)
        g = M.ervoi.choose(b_t, psi_hat, z_dist, t_ev.c_dist, M.budget, M.fmp, M.bse)
        if g and ratification_gate(g, b_int, M.ic)[0]:
            s2, cost = sigmareflex_step(M.mods, g, M.state, M.budget)  # 含 χ_I
            if s2 is not None: M.last_g, M.state = g, s2
        M.snapshot.write(b_t, z_dist, d_ev, t_ev, b_int, M.state)
        M.mreg.audit()
        M.j_pact = M.j_mod * M.j_dep                  # J_PACT = J_MOD ⊗ J_DEP

    # === 控制域（1kHz，硬实时，只读快照）===
    snap = M.snapshot.read_latest()
    if snap is None: return M.safe_hold()             # 部署断链 ⇒ 保守停机
    lam = embodied_risk_scale(snap.U_ale, snap.U_epi, snap.H_z,
                              max(snap.t_ev.u, snap.d_ev.u, snap.i_ev.u),
                              M.risk_params)
    A = M.ach.propose_ctrl(..., pvop_bias=snap.pvop)
    k = M.c_ras_wm.certified_prefix(A, lam)
    M.ctrl_out.publish(k, lam)
    return k, lam, M.j_pact

## 3. 推导

**引理 38（表演固定点的存在性与振荡判据）** 设复合更新 `Π = E[T]∘π` 在信念空间上 Lipschitz，常数为 γ（后向作用增益）。若 γ < 1，Banach 不动点定理给出唯一表演稳定信念 b*，迭代以几何速率收敛。若 γ ≥ 1，则存在 2-周期或极限环（振荡），此时「意图后验」不收敛，任何基于点估计的行动都无稳定语义。系：**意图理解的第一道安全检查不是后验精度，而是 γ 的在线估计与振荡检测；R72 的 KL 反作用只测「改变」，不测「是否收敛」。**

**引理 39（可辨识性与主动消歧的增益界）** 对任意动作 a，`E[r_I(y_{t+1}) | a] ≥ r_I(y_t) − I(h; y_{t+1} | a, y_t)`，其中 I 为互信息。故主动消歧的收益受信息增益上界约束，且当观测模型在 [h]_I 上不可分时增益为零——再多的动作也无法缩小等价类。系：**「多问几次」不是万能的；不可辨识必须显式保留为等价类并降低可执行风险 r(L)，而不是硬选一个。**

**引理 40（主权保持下界）** 若门控谓词 Gate 与主权约束 S 联合成立（定义 389/390），则任意进入执行的动作满足 `H_cf(a) ≥ τ_S` 且 `Reversibility(a) ≥ ρ_min`，故人的反事实选项熵不会因机器人行动被压到阈值以下；操纵被 VETO 非补偿地阻断。系：**「引导」与「操纵」的区分可以写成一个可监测的不等式，而不是留给事后伦理审查。**

**引理 41（部署精化的可靠性与损失上界）** 若 `Valid(J_DEP)`，则对每个 EC 义务 φ，部署 D 在损失 `ℓ(φ)` 内实现 φ（定义 392/393）。特别地：预算闭合的损失进入 u；QoS 损失的不可检出性直接判违约（定义 394）；时钟断链与重放判否决（定义 395/398）。因此 `M ⊑ D` 成立，且系统级不确定度满足 `u_部署 ≤ u_抽象 ⊕ ℓ_total`。系：**部署不是「相信配置」，而是「把每一项中间件损失兑换成显式的不确定度或否决」。**

**引理 42（静默违约不存在性）** 在 QMM 全覆盖（每个 QoS 参数有计量解释且被 J_DEP 校验）与时钟域标注完整的条件下，不存在「证据在中间件层被丢弃/合并/重排/篡改而下游不确定度不增且追溯不断」的路径。反证：任一此类路径必对应一个未被映射的 QoS 语义或未标注的时钟域，与全覆盖矛盾。系：**「静默」不是中间件的属性，而是证书的缺口；缺口一旦被 QMM 覆盖，静默违约就变成显式降级。**

**定理 30（PACT 严格包含 MODGAUGE）** 在 A114–A116（IC 平凡化等价于 R72 的 IRL 输入契约、χ_I≡id、DF 为理想无损失部署）下，PACT 是 MODGAUGE 的实例化：意图证据置为空/退化模块、主权恒真、部署损失 ℓ=0。由定义 400 与引理 41，退化条件下 PACT 逐指令等于 R73，再退化等于 R72/R71/R68。**安全单调不减，效率仅在契约与精化成立时获益。**

**定理 31（表演安全）** 在 (i) 表演稳定（b* 为 Π 的不动点，引理 38）；(ii) 撞定门控 Gate 成立（定义 390）；(iii) 主权约束 S 成立（引理 40）下，意图条件化风险满足 `Risk(a | b*, h) ≤ ε_intent + λ·u_intent`，其中 `u_intent` 含可辨识半径与表演偏移，`ε_intent` 为撞定等级不足导致的残余风险上界。**证明重量落在「γ < 1 的在线可验证性」与「主权反事实的可测量性」上**——若二者不可测，定理退化为条件命题。

**定理 32（部署证书 ⇒ 系统性质保持）** `Valid(J_PACT) = Valid(J_MOD) ∧ Valid(J_DEP)` ⇒ 在损失界 `ℓ_total` 内，R73 的退化链（定义 375）、风险单调（定理 23）、时序隔离（引理 28）、组合单调性（引理 34）在 ROS 2 部署上保持；热替换只需模块级 + 部署面级重认证，认证成本从 O(系统) 降为 O(模块 + 部署边)。**证明落在 J_DEP 的逐字段模拟关系上；任何未映射的中间件语义都是证明的漏洞。**

## 6. 本轮最大风险

**一句话**：意图与 ROS2 恰好是最容易**逃出契约**的两样东西——意图因为它是被机器人的策略**共同生产**的（所谓「意图后验」可能只是机器人自己行动的镜像），ROS2 因为它的丢包/合并/时序/权限语义**无法被 QoS 和部署面向完全表达**；于是系统可能同时持有一份形式上有效的 J_PACT 和一个形式上校准的意图后验，却在中间件丢掉了唯一能推翻它的证据——**证书证明的不是世界，而是证书自身的自洽**。

次级风险与缓解：
1. **表演性不可识别（γ 估计依赖对 Q 的假设）** → 用干预实验在线估计 γ 的保守上界；γ 不可估时禁用强撞定动作，只保留可逆低风险动作。
2. **主权反事实不可测（H_cf 需要反事实人模型）** → 以受控用户研究 + 信息完备基线做外部校准；不可测时默认保守（τ_S 上调，禁用引导类动作）。
3. **可辨识类组合爆炸（|H| 连续）** → 结构化意图树 + 等价类代表元 + 结构上限（|H|≤32，继承定义 377）；超限即降级为询问。
4. **J_DEP 覆盖不全（未知中间件语义）** → QMM 未覆盖的参数一律禁止进入核心路径；已知损失显式进入 u；突变测试持续补覆盖。
5. **部署精化证明成本高** → 按域分层证明（类型/时序/安全独立），模块化复用；只对核心认证路径要求完整 J_DEP。
6. **意图证据的跨模态相关（语言与手势共享同一人的错误信念）** → 单源不定案 + 跨模态 PAR 一致性审计 + 怀疑相关时禁用缩窄（继承 R73 定义 370）。

**定义 383（PACT 总览与六不变式）** 契约完整性 / 组合单调性 / 反作用通道完备（含 χ_I）/ 表演稳定 / 意图主权 / 部署精化。任一项不满足即不进核心认证路径。

**定义 384（意图契约 IC）** 意图是 (H, O, A, ρ, R, S, τ_I)。机器人维护 `[h]_I` 与撞定等级 L，而非单点后验；`Gate` 决定动作是否放行。

**定义 385（意图三重语义）** `p_o(y|h,s)`（不动）、`p_i(y|h,s,do(a))`（强制动作）、`p_p(y|h,s,π_θ)`（策略依赖且人的意图可被改变）。核心路径只允许 p_i/p_p 做风险推断；p_o 分类器必须标注表演偏移界。

**定义 386（可辨识类与半径）** `[h]_I` 为在观测与允许动作下不可区分的意图集合；主动消歧选择使 `E[r_I]` 下降最多的动作，收益受互信息上界约束（引理 39）。

**定义 387（表演稳定）** b* 为 `Π` 的不动点；PACT 要求行动前信念处于稳定集或已收敛；检测 2-周期/极限环 ⇒ `INTENT_OSC` 拒绝态。

**定义 388（意图通道 χ_I）** 动作如何改变人的意图分布参数与有效域；成本含 KL 与主权偏离，进入 ΣREFLEX 预算（层数由模块声明）。

**定义 389（意图主权 S）** `H_cf(a) ≥ τ_S ∧ Reversibility(a) ≥ ρ_min`；操纵 = 显著压缩反事实选项熵且增益来自错误信念/不可逆承诺/信息不对称；触发 `MANIPULATION` 非补偿否决。

**定义 390（撞定与门控）** L 只由独立性证据（跨模态/时间/来源）提升；单源不定案；`Gate` 不成立则不执行。

**定义 391（部署面向 DF）** 每条 MReg 边映射到 ROS2 资源元组；类型哈希、QoS、生命周期、executor、时钟域、SROS2、参数模式、节点组合。

**定义 392（精化关系 ⊑）** 存在模拟关系使每个 EC 义务在损失 `ℓ(φ)` 内实现：类型不截断 / 预算闭合 / 通道可写 / 域不弱化 / 否决不可补偿 / 时序 RTA / 密封可验。

**定义 393（部署证书 J_DEP）** 逐字段证明 + 损失上界 + 时钟对齐 + 生命周期 + RTA + 安全 + QoS 损失界；`Valid(J_DEP) ⇒ M ⊑ D`。

**定义 394（QMM）** QoS 每个参数必须有计量解释：BEST_EFFORT→丢包膨胀+断链；depth→陈旧；deadline→有效期；liveness→stub；filter→未声明降采样；无解释的参数禁止进核心路径。

**定义 395（时钟域与追溯）** 证据带 clock_domain/源时间/序号/nonce；跨域差需偏移不确定度；跳变/回退/use_sim_time 切换 ⇒ τ 断链 ⇒ 否决。意图时序尤为严格（承诺与撤销的先后）。

**定义 396（生命周期-证据同构与参数契约锁）** unconfigured∅ / inactive stub / active 有效 / finalized dead；转换相对快照原子；冻结字段运行时修改需再认证令牌。

**定义 397（executor 时序隔离）** mutually-exclusive 回调组可做 RTA；reentrant 需并发证明；控制域与计量域不得共享不可抢占 executor；反转上界由优先级继承/天花板给出。

    i_ev = M.iir.update(human_msgs, obs, M.last_action, M.clock_domain)
    i_ev = lifecycle_supervisor(M.iir.node, M.snapshot)
    i_ev = qos_to_metrology(i_ev.header, M.iir.qos, M.iir.seq_state)
    if M.clock.due_metric():
        b_t = M.bse.step_full(..., d_ev=d_ev, t_ev=t_ev)
        z_dist, ece_z, iota_z = M.irl.update(M.y_intent_buf, psi_hat, b_t)
        status, b_int = M.pii.deploy(M.policy, M.b_int)
        if status != 'STABLE': return M.safe_hold()
        g = M.ervoi.choose(b_t, psi_hat, z_dist, t_ev.c_dist, M.budget, M.fmp, M.bse)
        if g and ratification_gate(g, b_int, M.ic)[0]:
            s2, cost = sigmareflex_step(M.mods, g, M.state, M.budget)
            if s2 is not None: M.last_g, M.state = g, s2
        M.snapshot.write(b_t, z_dist, d_ev, t_ev, b_int, M.state)
        M.mreg.audit(); M.j_pact = M.j_mod * M.j_dep
    snap = M.snapshot.read_latest()
    if snap is None: return M.safe_hold()
    lam = embodied_risk_scale(snap.U_ale, snap.U_epi, snap.H_z,
                              max(snap.t_ev.u, snap.d_ev.u, snap.i_ev.u), M.risk_params)
    k = M.c_ras_wm.certified_prefix(M.ach.propose_ctrl(..., pvop_bias=snap.pvop), lam)
    M.ctrl_out.publish(k, lam)
    return k, lam, M.j_pact

## 4. 推导

**引理 38（表演固定点与振荡判据）** `Π=E[T]∘π` Lipschitz 常数 γ<1 ⇒ Banach 唯一固定点、几何收敛；γ≥1 ⇒ 可存在 2-周期/极限环，点估计无稳定语义。系：**意图理解的第一道安全检查是 γ 的在线估计与振荡检测，而非后验精度。**

**引理 39（可辨识性增益界）** `E[r_I(y_{t+1})|a] ≥ r_I(y_t) − I(h;y_{t+1}|a,y_t)`；若 [h]_I 在观测模型下不可分，主动消歧增益为零。系：**不可辨识必须保留为等价类并降低 r(L)，不能硬选一个。**

**引理 40（主权保持下界）** Gate ∧ S ⇒ `H_cf(a)≥τ_S ∧ Reversibility(a)≥ρ_min`；操纵被非补偿否决。系：**引导 vs 操纵可写成一个可监测不等式。**

**引理 41（部署精化可靠性）** `Valid(J_DEP)` ⇒ 每个 EC 义务在 ℓ(φ) 内实现，`M⊑D`，且 `u_部署 ≤ u_抽象 ⊕ ℓ_total`。系：**部署不是「相信配置」，而是把中间件损失兑换成不确定度或否决。**

**引理 42（静默违约不存在性）** QMM 全覆盖 + 时钟域标注完整 ⇒ 不存在「证据被丢弃/合并/重排/篡改而下游 u 不增且追溯不断」的路径；反证对应未映射的 QoS 语义或未标注时钟域。系：**静默是证书的缺口，不是中间件的属性。**

**定理 30（PACT 严格包含 MODGAUGE）** IC 平凡化、χ_I≡id、S 恒真、DF 理想无损失 ⇒ 逐指令等于 R73，再退化等于 R72/R71/R68。**安全单调不减。**

**定理 31（表演安全）** 表演稳定 + Gate + S ⇒ `Risk(a|b*,h) ≤ ε_intent + λ·u_intent`（u_intent 含可辨识半径与表演偏移）。**证明重量落在 γ 的在线可验证性与 H_cf 的可测量性。**

**定理 32（J_PACT ⇒ 系统性质保持）** `Valid(J_MOD) ∧ Valid(J_DEP)` ⇒ 在 ℓ_total 内，退化链/风险单调/时序隔离/组合单调在 ROS2 部署保持；热替换只需模块+部署边重认证，成本 O(系统)→O(模块+边)。

## 7. 本轮最大风险

**一句话**：意图与 ROS2 恰好是最容易**逃出契约**的两样东西——意图因为它是被机器人的策略**共同生产**的（所谓「意图后验」可能只是机器人自己行动的镜像），ROS2 因为它的丢包/合并/时序/权限语义**无法被 QoS 和部署面向完全表达**；于是系统可能同时持有一份形式上有效的 J_PACT 和一个形式上校准的意图后验，却在中间件丢掉了唯一能推翻它的证据——**证书证明的不是世界，而是证书自身的自洽**。

次级风险与缓解：
1. **表演性不可识别** → 干预实验在线估 γ 保守上界；不可估则禁用强撞定，只允许可逆低风险动作。
2. **主权反事实不可测** → 受控用户研究 + 信息完备基线校准；不可测则默认保守（τ_S 上调）。
3. **可辨识类组合爆炸** → 结构化意图树 + 代表元 + |H|≤32；超限降级为询问。
4. **J_DEP 覆盖不全** → QMM 未覆盖参数禁止进核心路径；已知损失显式进 u；突变测试持续补覆盖。
5. **精化证明成本高** → 按类型/时序/安全分层证明 + 模块化复用；只对核心路径要求完整 J_DEP。
6. **跨模态意图相关** → 单源不定案 + PAR 一致性审计 + 怀疑相关即禁缩窄。
7. **主张膨胀** → 定义 400 主张预算（≤5）+ 每主张杀死实验；无法杀死即降为工程附件。
