# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 1 轮；本轮灵感：「视觉-语言-动作模型」×「参数高效微调」）

> 前 54 轮把鲁棒性谱 ρ、动作剖面 α_S、云边映射 γ_ce 都做成了可传递证书，但技能库始终隐含一个昂贵假设：每个技能是一个独立策略/模型。VLA + PEFT 给出另一条路线：**一个共享视觉-语言-动作骨干 θ₀，技能是低秩适配器 Δ_k**。好处是数据高效、云边只需传增量；代价是证书第一次同时受 **参数空间合并** 与 **语言空间接地** 两个新失效面支配。核心矛盾：H24：单个适配器在自身训练分布上可证安全，但多个适配器在权重空间合并后，其动作行为不等于各自行为的组合，出现“合并间隙”；H25：VLA 先由语言把指令接地到技能、再执行动作，语言接地的微小漂移可以绕过纯动作空间证书，造成“自信地做错事”。

## 0. 直觉与动机

**灵感 1（技能 = 骨干 + 适配器：把技能库从“模型集合”变成“增量集合”）**
直觉：不必为每个技能训练一个完整 VLA。共享骨干 `π0(a|o,ℓ;θ0)` 提供通用视觉-语言-动作先验，技能 `S_k` 只是低秩更新 `Δ_k`。于是“技能库”从 `{模型}` 变成 `{增量}`：存储、云边传输、组合都从整模型粒度降到适配器粒度。但这也意味着技能之间不再天然独立——它们共享同一骨干，任何组合都在同一个参数空间里相互作用。

**灵感 2（参数-动作双空间：动作相容 ≠ 参数不干涉）**
直觉：第 54 轮的 `compat(S_i,S_j)` 只问“动作覆盖是否相交”。PEFT 下还要问“两个增量在同一骨干上是否互相污染”。即使动作区域相容，`Δ_i` 与 `Δ_j` 若落在相近的参数子空间，合并后会在每个子任务上同时激活，导致动作漂移。因此组合可行性必须是 **动作空间 ∩ 参数空间** 的联合判定。

**灵感 3（适配器干涉矩阵：把“合并间隙”变成可测、可约束的量）**
直觉：定义 `I(i,j)` 为“合并执行”与“按子任务路由执行”之间的行为 L1 距离。`I` 小 ⇒ 两个适配器可安全合并；`I` 大 ⇒ 必须顺序加载、正交化或拒绝。干涉矩阵 `M_ij=I(i,j)` 就是第 53 轮鲁棒性耦合矩阵 `K` 在参数空间的对应物。特别地，`Δ_i` 与 `Δ_j` 的主子空间越正交，`I` 越小——这给出了一个可优化目标：正交化 `⊖` 以降低干涉，但要为行为漂移付费。

**灵感 4（语言-动作接地证书：VLA 特有的“错路由”失效面）**
直觉：VLA 的入口是语言。近义改写、否定词、干扰项都可能把指令接地到错误的动作区域；纯动作剖面根本看不到这个错误，因为错误发生在“选中了哪个技能”之前。定义接地裕度 `m_ℓ = d_H(A_ℓ, ∪_{ℓ'∈Neg(ℓ)} A_{ℓ'})`，并用反事实指令探针（同义、否定、交换）检验：若释义邻域内的动作漂移大于 `m_ℓ`，则接地证书作废。

**灵感 5（PEFT 证据密度：小样本带来的“证书通胀”）**
直觉：适配器训练样本少、参数少，名义成功率 `p̂` 很容易刷高，但有效样本 `n_eff` 与动作覆盖体积 `V_k` 决定了它到底“证明了什么”。把证据密度 `e_k=n_eff/(r_k·d·V_k)` 与置信下界 `p_k^LB` 写进证书：**可交易的从来不是 `p̂`，而是 `p^LB`**。若只用 `p̂` 做组合决策，就会系统性地把“没见过的动作”当成“会的动作”，即证书通胀。

**灵感 6（云边只传适配器 + 双证书金字塔）**
直觉：云端持有完整骨干与适配器库，边端只加载一个被压缩/量化的 `Δ̃_k`；此时云边映射 `γ_ce` 从“动作映射”扩展为“适配器压缩 + 动作映射”，量化漂移 `δ_q` 进入联合证书。在第 53 轮鲁棒性金字塔 `𝕃`、第 54 轮动作协同层 `𝔸` 之上叠加 **参数层 `ℙ`**：`ℙ_0` 适配器容量/秩，`ℙ_1` 适配器证书，`ℙ_2` 合并/正交化，`ℙ_3` 云边压缩交付。跨层传递 `(ρ, A_cert, Δ_cert, G_cert, E_cert, δ_q)` 的双空间证书。

## 1. 形式化定义（增量：定义 121–127）

**定义 121（VLA-PEFT 技能）**
共享 VLA 骨干 `π0(a|o,ℓ;θ0)`；技能 `S_k=(θ0, Δ_k, r_k, ℓ_k)`，其中 `Δ_k` 为秩 `r_k` 的低秩更新，`π_k=π0(·;θ0⊕Δ_k)`。技能库 `𝒮={(S_k,ρ_k,α_k,G_k,E_k)}`。技能不独占模型，而是共享骨干上的一个增量。

**定义 122（适配器作用谱与动作剖面）**
适配器对动作维度 `d` 的作用谱 `β_k(d)=E_{o,ℓ}[||∇_{z_d}π0 · Δ_k||]`，度量 `Δ_k` 对输出 logits 的扰动幅度。动作剖面 `α_k(a)=P_{o∼D_a}[π_k 在 a 邻域可达且置信 ≥ θ_cov]`。`α_k` 由 `β_k` 引导的主动采样得到：只在 `β_k` 稳定且非零的动作区做高密度采样，避免盲目遍历 `A_c×A_e`。

**定义 123（适配器干涉矩阵与合并间隙）**
设 `⊕` 为权重合并，`route(i,j)` 表示子任务 i 只激活 `Δ_i`、子任务 j 只激活 `Δ_j`。合并间隙
```
I(i,j) = E_{o,a,ℓ}[ ||π_{i⊕j}(a|o,ℓ) − π_{route(i,j)}(a|o,ℓ)||₁ ]
```
干涉矩阵 `M_ij=I(i,j)`。合并安全条件 `I(i,j) ≤ ε_m`。若 `Δ_i,Δ_j` 作用于相互正交的子空间且门控精确，则 `I(i,j)=0`；一般情形由主子空间夹角与谱范数决定。

**定义 124（语言-动作接地证书）**
指令 `ℓ` 的接地动作集 `A_ℓ={a: π(a|o,ℓ) ≥ θ_g}`。接地裕度
```
m_ℓ = d_H( A_ℓ , ∪_{ℓ'∈Neg(ℓ)} A_ℓ' )
```
其中 `Neg(ℓ)` 为语义邻近但动作意图不同的反事实指令集（同义、否定、干扰项）。接地证书 `G_ℓ=(m_ℓ, ε_ℓ, α_g)`，要求在 `ℓ` 的 `ε_ℓ`-释义邻域内 `Pr[接地漂移 < m_ℓ] ≥ 1−α_g`。

**定义 125（PEFT 证据密度与证书置信下界）**
适配器 k 在 `n_k` 样本、`m_k` 场景上训练，动作覆盖体积 `V_k`，有效自由度 `r_k·d`。有效样本 `n_eff=n_k/(1+ρ_c(m_k−1))`，证据密度 `e_k=n_eff/(r_k·d·V_k)`。置信 `1−δ` 的成功率下界
```
p_k^LB = p̂_k − sqrt( log(1/δ) / (2·n_eff) )
```
**证书通胀**定义为 `I_cert = p̂_k − p_real,k`；可交易值一律取下界 `p^LB`。

**定义 126（适配器组合代数与证书保持）**
组合算子：合并 `⊕`、顺序 `⊗`、正交化 `⊖`（`Δ_j^⊥=Δ_j−P_{Δ_i}Δ_j`）。组合 `S_i∘S_j` 可部署当且仅当五重条件同时成立：
```
compat(A_i,A_j) ≥ θ_a            # 动作相容（第 54 轮）
∧ I(i,j) ≤ ε_m                    # 参数不干涉
∧ m_{ℓ_j} ≥ m_min                 # 语言接地稳
∧ p_i^LB, p_j^LB ≥ ρ_min          # 证据下界够
∧ bytes(r_i+r_j) ≤ B_e            # 边端预算内
```

**定义 127（参数-动作双证书 J_PA）**
```
J_PA = (ρ, A_cert, Δ_cert, G_cert, E_cert, δ_q, evidence)
```
- `ρ`：第 53 轮鲁棒性谱；
- `A_cert`：第 54 轮动作占用证书；
- `Δ_cert=(support, r, I_merge)`：适配器支撑子空间、秩、合并间隙；
- `G_cert=(m_ℓ, α_g)`：语言接地证书；
- `E_cert=(e_k, n_eff, p^LB)`：证据证书；
- `δ_q`：边端量化/压缩适配器的参数相对漂移；
- `evidence`：至少含反事实指令探针、合并对照实验、conformal 校准集。
部署当且仅当 `dom_J(T)=in ∧ I_merge≤ε_m ∧ m_ℓ≥m_min ∧ p^LB≥ρ_min ∧ δ_q≤δ_max`。

## 2. 关键算法 伪代码

### IP-121 PACE（Parameter-Action Certificate Estimator）

```python
def pace(skill, A, probes, alpha=0.05):
    beta = adapter_sensitivity(skill.delta, probes)      # 逐动作维作用谱
    alpha_prof = {}
    for a in guided_sample(A, beta, budget=probes.budget):
        alpha_prof[a] = coverage_estimate(skill, a, n=probes.n)
    rho = robustness_spectrum(skill, dimensions)
    p_hat, n_eff = empirical_success(skill, probes)
    p_lb = p_hat - sqrt(log(1/alpha) / (2 * max(n_eff, 1)))
    e = n_eff / (skill.rank * skill.dim * action_volume(alpha_prof))
    return PACert(alpha_prof, beta, rho, e, p_lb)
```

### IP-122 AIM（Adapter Interference Matrix）

```python
def interference_matrix(skills, pairs, epsilon_m):
    M = {}
    for (i, j) in pairs:
        merged = merge(skills[i].delta, skills[j].delta)
        routed = route(skills[i].delta, skills[j].delta, pairs[(i, j)])
        I = behavior_l1(merged, routed)          # 动作分布 L1 距离
        M[(i, j)] = I
    return M

def safe_merge(i, j, M, epsilon_m):
    return M.get((i, j), INF) <= epsilon_m

def orthogonalize(delta_i, delta_j):
    P = projector(delta_i)
    return delta_j - P @ delta_j               # 降干涉，但需复测行为漂移
```

### IP-123 LAG（Language-Action Grounding）

```python
def grounding_certificate(skill, instr, paraphrase_gen, neg_gen,
                          theta_g, m_min, eps_l):
    A_int = action_set(skill, instr, theta_g)
    A_neg = union(action_set(skill, l, theta_g) for l in neg_gen(instr))
    margin = hausdorff(A_int, A_neg)
    drift = max(grounding_drift(skill, instr, l)
                for l in paraphrase_gen(instr, eps_l))
    ok = (margin >= m_min) and (drift < margin)
    return GroundCert(margin, drift, ok)
```

### IP-124 CAPO（Certificate-Aware PEFT composition）

```python
def capo(library, task, M, budgets, theta):
    G = build_graph(library, M, theta)         # 按五重条件剪枝
    def cost(e):
        return (w_a*(1-e.compat) + w_m*e.I + w_g*(1-e.ground_margin)
                + w_e*(1-e.p_lb) + w_q*e.delta_q)
    path = a_star(G, start=task.root, goal=task.goal, heuristic=cost)
    if path is None:
        return ('reject', 'no_certified_path')
    J = compose_joint_certificate(path)        # 见 IP-126
    if not admissible(J, budgets):
        return ('reject', 'budget_exceeded', J)
    return ('ok', J)
```

### IP-125 ACC（Adapter Cloud-Edge Compression）

```python
def edge_adapter(cloud_delta, bits, L_pi, delta_max):
    q = quantize(cloud_delta, bits)
    delta_q = frobenius(q - cloud_delta) / frobenius(cloud_delta)
    bound = L_pi * delta_q * frobenius(cloud_delta)
    if bound > delta_max:
        return ('reject', 'drift', delta_q, bound)
    return ('ok', q, delta_q, bound)
```

### IP-126 JPC（Joint Parameter-Action Certificate）

```python
def compose_joint_certificate(path):
    rho   = compose_robustness_chain([s.rho for s in path], K)
    A_c   = reduce(intersection, [s.alpha for s in path])
    I_mer = max(M[i, j] for i, j in adjacent(path))
    G_c   = min_ground_margin(path)
    E_c   = min_lower_bound(path)
    delta_q = max_quant_drift(path)
    ok = (I_mer <= eps_m and G_c >= m_min
          and E_c >= rho_min and delta_q <= delta_max)
    return JointPA(rho, A_c, I_mer, G_c, E_c, delta_q, ok)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| PACE | O(|A|·r·d·n_probe) | O(|A|) | 作用谱引导采样覆盖、下界浓度 |
| AIM | O(|P|·r·d + |P|·|A|) | O(|S|²) | 合并/路由对照、行为距离可估 |
| LAG | O(|L_probe|·|A|) | O(|A|) | 反事实探针覆盖释义邻域 |
| CAPO | O(|S|²·|A| + |E| log |V|) | O(|V|+|E|) | 五重剪枝 sound、成本单调 |
| ACC | O(r·d) | O(r·d) | 量化漂移界紧、L_π 有界 |

**正确性定理（PEFT Composition Soundness under VLA Grounding）**
假设第 54 轮 (A26)–(A28) 成立；新增 **(A29)** VLA 策略对适配器隐藏扰动的 Lipschitz 常数 `L_π` 有界；**(A30)** 干涉矩阵 `I` 的估计无偏且浓度可界（Hoeffding）；**(A31)** 反事实指令探针覆盖 `ε_ℓ`-释义邻域，覆盖失败概率 ≤ `α_g`；**(A32)** `p^LB` 与 `δ_q` 的 conformal 校准有效。则部署成功率
```
P_success ≥ 1 − [ Σ_d(1−ρ_min(d)) + P(I>ε_m) + α_g
                  + P(δ_q>δ_max) + β_E ]
```
要求右端 > 0 才允许部署。关键：**先证参数不干涉，再证语言接地，再谈动作组合**；任何一项不可估则拒绝，而不是取默认值。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 适配器干涉高度非线性、估计分布外 | 高 | 多任务配对采样 + 正交化 `⊖` + 保守 `ε_m` |
| 语言否定/组合泛化导致接地漂移 | 高 | 否定/交换对抗探针 + 接地失败回退到动作探针 |
| 小样本下 `p^LB` 空洞、证书通胀 | 高 | conformal + 分层场景采样 + 拒绝部署 |
| 合并与路由语义不一致 | 中 | 统一适配器代数 + 行为对照实验 |
| 云边量化漂移逐层累积 | 中 | 逐层误差预算 + 边端在线校准 |

## 6. 本轮最大风险

**一句话**：参数空间的“低干涉/可正交化”并不蕴含行为空间的安全组合——VLA 的语言路由与非线性合并可能把两个单独持证、但证书都只在同一狭窄训练分布上估计的适配器，拼成一个“高置信度却系统性做错”的复合体。

    beta = adapter_sensitivity(skill.delta, probes)
    alpha_prof = {}
    for a in guided_sample(A, beta, budget=probes.budget):
        alpha_prof[a] = coverage_estimate(skill, a, n=probes.n)
    rho = robustness_spectrum(skill, dimensions)
    p_hat, n_eff = empirical_success(skill, probes)
    p_lb = p_hat - sqrt(log(1/alpha) / (2 * max(n_eff, 1)))
    e = n_eff / (skill.rank * skill.dim * action_volume(alpha_prof))
    return PACert(alpha_prof, beta, rho, e, p_lb)

def capo(library, task, M, budgets, theta):
    G = build_graph(library, M, theta)      # 五重条件剪枝
    def cost(e):

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| PACE | O(|A|·r·d·n_probe) | O(|A|) | 作用谱引导采样覆盖 ≥ 95% |
| AIM | O(|P|·r·d + |P|·|A|) | O(|S|²) | 合并/路由对照，`I` 估计浓度可界 |
| LAG | O(|L_probe|·|A|) | O(|A|) | 释义邻域覆盖，否定对抗 |
| CAPO | O(|S|²·|A| + |E| log |V|) | O(|V|+|E|) | 五重剪枝 sound，路径成本最优 |
| ACC | O(r·d) | O(r·d) | `δ_q` 界紧，`L_π` 有界 |

**正确性定理（PEFT Composition Soundness under VLA Grounding）**
假设第 54 轮 (A26)-(A28) 成立；新增 **(A29)** `π` 对适配器隐藏扰动 Lipschitz 常数 `L_π` 有界；**(A30)** 干涉估计无偏且浓度可界；**(A31)** 反事实探针覆盖 `ε_ℓ`-释义邻域（失败率 ≤ `α_g`）；**(A32)** `p^LB`、`δ_q` 的 conformal 校准有效。则
```
P_success ≥ 1 − [Σ_d(1−ρ_min(d)) + P(I>ε_m) + α_g + P(δ_q>δ_max) + β_E]
```
只有当右端 > 0 且 `J_PA.ok` 为真时才允许部署：**先证参数不干涉，再证语言接地，最后才谈动作组合**。
