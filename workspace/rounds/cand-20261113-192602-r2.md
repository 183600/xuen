# 第 69 轮（承接第 68 轮「CALM-RAS 自标定风险自适应闭环」IP-243~252；灵感循环新循环第 2 轮；本轮灵感：「可重构机构」×「研究空白」）

> 第 68 轮把「测量可信度」升为一等公民，但它自陈的最大风险——缓变故障落在标定带宽内被 COF「标好」——不是一个调参问题，而是一个**结构问题**：在固定构型、被动观测下，加性漂移与乘性/结构故障在信息上根本不可分。R68 无论怎样提高标定精度，都无法从「没有激发」的数据里变出可辨识性。这正是 R65–R68 一路「加层」积累的**架构债**：监控器被当成一副固定连杆机构，每轮焊上新杆，却从未允许它改变拓扑。
>
> 本轮两个灵感恰好是同一枚硬币的两面：
> - **可重构机构**告诉我们：结构本身可以是自由度——改变拓扑/构型能获得新能力；但变胞必须穿过奇异位形，因此重构过程本身必须被安全管理。
> - **研究空白**告诉我们：要先把「缺什么」定义成可计算的量，而不是修辞。这里把研究空白定义为**当前观测结构的信息零空间**——当前构型下不可辨识的参数方向。
>
> 核心命题：
>
> **把监控器从「固定结构的被动观察者」升级为「可重构机构」：结构（计算拓扑 × 物理构型）是一等状态；用可辨识性缺口在运行时定义研究空白，用安全探针把「可激励的缺口」变成可测，用焊接安全核 + 无缝拓扑切换保证重构过程零盲窗、不可激励的缺口被显式声明而非假装消失——MORPH-RAS（Metamorphic Observability via Reconfigurable Probe, Hazard-aware Risk-Adaptive Supervision）。**
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「**我的测量还准吗**」，R69 问「**我能不能改变自己的构型，让本来不可测的东西变得可测**」——不确定时不只是收紧（λ↑），而是在风险预算内主动重构去消除不确定。

## 0. 直觉与动机

### 灵感 1（可重构机构 → 监控器是可重构机构，不是固定连杆）
直觉：机构学里，可重构/变胞机构（metamorphic mechanism）通过锁定/释放关节改变拓扑与自由度，用同一套硬件获得不同任务能力；代价是每次变胞都要穿过奇异位形，控制权会短暂丢失。R65–R68 的监控器恰恰相反：它是一副只增不减的固定连杆——每轮焊上新模块、新阈值、新红线，越来越刚、越来越难维护。本轮把「结构」变成一等状态：监控器持有一个有限的**装配模式族**（标称 / 感知退化 / 缓变故障 / 接触密集 / 低功耗……），模式决定哪些模块在环、假设集、标定带宽、阈值与纪律；模式之间用「焊接的」安全核与「自由的」可重构关节区分开。关键动作不是再叠一层，而是**重新接线**。

### 灵感 2（研究空白 → 空白 = 信息零空间，可在运行时测量）
直觉：「研究空白」常被写成文献综述里的一句套话。若它真是空白，就应能被一个可计算量指出：在当前观测结构下，**哪些参数方向在数据里根本不存在信息**。线性高斯模型给出干净答案：参数 θ 的 Fisher 信息矩阵 FIM_s(θ) 的零空间 null(FIM_s) 就是「当前构型永远看不见的方向」。R68 的静态段自标定把观测固定为 u≡u₀，此时加性零偏 c 与乘性增益误差 ΔG **只在 c + ΔG·u₀ 这个组合上可辨识**，二者的分离落在零空间里——不是精度不够，是信息不存在。于是「研究空白」变成一个**缺口证书** γ_t：γ_t>0 ⇔ 当前结构无法分离某对假设。R69 的整个设计围绕这个可测量量展开。

### 灵感 3（物理可重构 → 激发是打开可辨识性的唯一钥匙）
直觉：测量模型 y_t = c + (G₀+ΔG)u_t + ε_t。加性漂移 c 与激发 u_t 无关；乘性故障 ΔG 只有 u_t **变化**时才显形。静止段（u_t≡u₀）能标定 c，却把 ΔG·u₀ 一并吞进「等效零偏」——这正是 R68 自陈风险的物理根源。要让 ΔG 可见，必须让 u_t 在已知方向上**持续激发**（persistent excitation, PE）。而机器人恰好拥有一个被忽视的执行器：**它自己的构型**。改变夹持姿态、传感器安装角、施加已知载荷的轻触、执行一段已知微运动——都是在给测量系统「做实验」，让漂移（相对传感器系固定）与故障（随载荷/构型变化）在回归中分离。可重构机构在这里不是机械炫技，而是**主动计量的物理前提**。

### 灵感 4（合流 → MORPH-RAS 七组件）
「重构」提供新动作类，「缺口」提供触发信号，「激发」提供可辨识性判据。三者合成带证书的闭环：
1. **RMM Reconfigurable Monitor Mechanism**：监控器 = 拓扑图 G=(V,E) + 有限装配模式族 M + 物理构型 q；变胞状态 s_t=(m_t,q_t) 为一等状态；
2. **SK Safety Kernel**：一组**焊接不变量**（任何模式与任何切换都必须满足），与「自由关节」显式区分——重构只能动自由部分；
3. **GAP Runtime Gap Detector**：FIM/成对可分性 → 缺口证书 γ_t，并把缺口投影到「可激励子空间 / 不可激励零空间」；
4. **PROBE Safe Probe Designer**：在有限个已认证探针原语上做风险预算下的 D-最优实验设计，选「最能把缺口变成可测」且风险可接受的那一个；
5. **MTP Metamorphic Transition Protocol**：重叠见证 + 保守包络 + 有界驻留 + 可逆边，保证变胞过程**至少有一个已认证监控在环、且不比任一端点更乐观**；
6. **RCC Reconfiguration Certificate & Commit**：在 R68 的 CAC 五关之上加拓扑门（安全核不变 / 切换单调 / 可逆 / 缺口正当 / 预算），原子换装；
7. **MORPH-RAS† 继承核**：CALM-RAS 全部保留，只是「结构」从常量升为可配置状态；阈值仍由 R68 的 U(ĉ) 重参数化，重构绝不夺取 λ_floor 的收紧权。

### 灵感 5（对 R65–R68 遗留风险的对症下药）
- R68「缓变乘性故障被标定吸收」：GAP 检出零空间方向，PROBE 用 PE 把 ΔG 与 c 分离——**证明**（引理 16）并**修复**（引理 17 / 定理 17）R68 的盲点；
- R68「标定红线悖论」：红线属 SK，是焊接的；重构只能改变读红线的测量结构，不能改变红线本身，每次变胞在 J_MORPH 留哈希链；
- R67「黑箱前瞻」：物理探针是 WM 的**外部证伪实验**（真实激励 vs 想象 rollout），且探针受风险预算约束；
- R66「情绪/视角欺骗」：可重构视角（换机位/补光）是把「不可观测」变成「可观测」的物理手段，但只在 VOI 为正时调用；
- 总闸不变：**重构与探针都是动作，都必须过认证前缀与 λ_risk；它们只能消除认知不确定，绝不能成为放宽安全阈值的借口。**

**定义 293（MORPH-RAS 总览）** MORPH-RAS = (RMM, SK, GAP, PROBE, MTP, RCC, CALM-RAS†)。新增五条不变式：
(i) **安全核不变**：∀ 模式 m、∀ 切换 e，SK 中每条焊接不变量恒真；

(iii) **无盲窗**：切换全过程至少一个已认证监控在环，且有效参数取保守包络（λ_eff ≥ max、k_eff ≤ min）；

**定义 295（安全核与焊/活关节）** 每条不变量 i 带锁态 ℓ_i ∈ {welded, free}。SK = {i : ℓ_i=welded}，必须包含：λ_risk∈[0.6,1] 且对不确定单调不减；实时流零学习写；无有效证书不得执行；证明递归的基例（标称模式持有出厂证书）。可重构结构只能重写 free 部分。重构合法 ⇔ φ(m,q) 与 φ(m′,q′) 在 SK 投影上逐条相等（哈希相等）。

**定义 296（可辨识性与运行时缺口证书）** 对假设对 (H_i,H_j) 与当前结构 s，可分性 D_ij(s) = min(KL(p_s(r|H_i)‖p_s(r|H_j)), KL(反向)) 或 FIM 成对可辨识度。缺口证书 γ_t = max_{i≠j}(τ_id − D_ij(s_t))，γ_t>0 即「当前结构无法分离该对假设」= 运行时研究空白。带迟滞：入 γ>τ_hi，出 γ<τ_lo（τ_lo<τ_hi）。

**定义 297（Fisher 信息与观测增益）** 测量 y=c+(G₀+ΔG)u+ε。参数 θ=(c,vec(ΔG))，单样本 FIM 块 ∝ [[I, u⊗I],[u^T⊗I,(uu^T)⊗I]]，全局 FIM_s=(1/σ²)Σ_t[I,u_t⊗I]^T[I,u_t⊗I]。观测增益 ΔI(s→s′)=½logdet(FIM_{s′}|_A+I)−½logdet(FIM_s|_A+I)，限制在缺口歧义子空间 A=span(θ_ambiguous)（D-最优）。

**定义 298（可激励子空间与不可激励零空间）** 令 𝒰_s=span{u_t}（当前结构可达的激发方向）。可激励子空间 E={θ 方向 : ∃s, ∂y/∂θ 依赖 𝒰_s 且 FIM_s|_θ≻0}；不可激励零空间 N=∩_s null(FIM_s)。**MORPH-RAS 只能闭合 E，必须显式声明 N**（诚实边界）。

**定义 299（安全探针合成）** 有限探针原语库 Π={静态换位/已知载荷轻触/慢扫/双视角/夹持重配/已知微运动}，每个原语带已认证前缀与中止路径。选择问题：
π* = argmax_{π∈Π, admissible(π)} [ ΔI_π(A) − λ_c·cost(π) − λ_r·risk(π) ]，s.t. λ_risk(π)≤λ_max，T_π≤T_probe，执行后可返回已认证模式。

# IP-253/254 RMM + SK：可重构监控器与焊接安全核
class ReconfigurableMonitor:
    MODES = ('nominal', 'sensor_degraded', 'slow_fault', 'contact_rich', 'low_power')
    FREE  = {'active_heads', 'hypothesis_set', 'omega_cal', 'tau_scale', 'module_wiring'}
    WELD  = {'lam_risk_range', 'live_zero_write', 'no_cert_no_act',
             'factory_base_cert', 'monotone_uncertainty', 'inverse_edge'}

    def topology(self, mode):
        return self.wiring[mode]              # G_m = (V_m, E_m, tau)

    def metamorphic_ok(self, m, q, m2, q2):
        # 只有 free 关节可动；SK 投影必须逐条相等
        return self.sk_projection(m, q) == self.sk_projection(m2, q2)


# IP-255 GAP：运行时缺口证书（研究空白 = 信息零空间）
def gap_certificate(residual_stream, mode, hyp_pairs):
    F = fisher_information(residual_stream, mode)       # 定义 297
    gamma = 0.0; ambiguous = []
    for (Hi, Hj) in hyp_pairs:
        D = pair_separability(F, mode, Hi, Hj)           # 定义 296
        g = TAU_ID - D
        if g > gamma: gamma, ambiguous = g, [(Hi, Hj)]
        elif g == gamma: ambiguous.append((Hi, Hj))
    E_dir, N_dir = split_excitable(F, mode)              # 定义 298
    return gamma, ambiguous, {'excitable': E_dir, 'residual_gap': N_dir}


# IP-256 PROBE：风险预算下的 D-最优安全探针
def choose_probe(gamma, ambiguous, mode, risk_budget):
    best, best_score = None, 0.0
    for pi in PROBE_LIBRARY:                             # |Pi| 有限、已认证
        if not admissible(pi, mode, risk_budget): continue
        if not pi.covers(ambiguous): continue            # 能激励歧义方向才算
        gain = d_optimal_gain(pi, ambiguous)             # 定义 297/299
        score = gain - LAMBDA_C*pi.cost - LAMBDA_R*pi.risk
        if score > best_score: best, best_score = pi, score
    return best if best_score > TAU_GAIN else None       # 无正收益 -> 不探针


# IP-257 MTP：重叠见证 + 保守包络 + 中止
def metamorphic_transition(old, new, q_plan):
    shadow = clone(old); shadow.load_mode(new)           # 影子并行运行
    witness = overlap_witness_set(old, new)
    if kl(witness.p_old, witness.p_new) > TAU_OV: return old, 'REJECT_OVERLAP'
    for q in q_plan:                                     # 已知插值轨迹
        lam_eff = max(old.lam, shadow.lam)               # 保守包络
        k_eff   = min(old.k,   shadow.k)
        if not witness.holds(): return old, 'ABORT_SINGULARITY'
        emit(lam_eff, k_eff)                             # bumpless，无盲窗
    return shadow, 'OK'


# IP-258 RCC：六门 + 原子换装（CAC 升级）
class ReconfigurationCertificate:
    GATES = ['sk_unchanged', 'overlap_witness', 'envelope_monotone',
             'reversible_edge', 'budget', 'gap_justified']

    def maybe_commit(self, old, new, gamma, probe_gain, dt):
        if dt < T_dwell: return None                     # 反振荡驻留
        if not (gamma > TAU_HI and probe_gain > TAU_GAIN):
            return None                                  # 无缺口/无收益不重构
        verdict = {g: getattr(self, g)(old, new) for g in self.GATES}
        if all(verdict.values()):
            atomic_swap(self.live_ptr, new)              # <1us 双缓冲
            return 'PASS'
        log_to_ereconf(verdict); return 'REJECT'


# IP-261 主闭环：MORPH-RAS 一轮（快路径不变，慢路径重构）
def MORPH_RAS_round(M, obs):
    k, lam, joint, (c, U) = CALM_RAS_round(M, obs)       # R68 快路径 <2.6ms
    M.gap_tick += 1
    if M.gap_tick % T_GAP != 0: return k, lam, joint

    gamma, amb, subsp = gap_certificate(M.residual_log, M.mode, M.hyp_pairs)
    if gamma <= TAU_HI: return k, lam, joint             # 无缺口，收敛

    pi = choose_probe(gamma, amb, M.mode, M.risk_budget)
    if pi is None:                                       # 只能声明残余空白
        M.declare_residual_gap(subsp['residual_gap'], gamma)
        return k, max(lam, LAM_FLOOR), joint

    evidence = M.execute_probe(pi)                       # 认证前缀 + 可中止
    M.gap.update(evidence)
    new_mode = M.rcc.propose_mode(gamma, evidence)
    committed, why = M.mtp.metamorphic_transition(M.mode, new_mode, pi.q_plan)
    M.rcc.maybe_commit(M.mode, committed, gamma, pi.gain, M.time_since_last_switch)

    # 重构永远不夺权：λ 下限只增不减
    return k, max(lam, LAM_FLOOR), joint

## 3. 推导

**引理 16（静态段的信息零空间——R68 盲点的证明）** 在 u_t≡u₀ 的静态段，参数 (c,ΔG) 的 FIM 奇异：任取 δG，令 δc=−δG·u₀，则观测分布完全不变，故 (δc,δG) 是零空间方向。结论：静态自标定只能恢复**等效零偏** c_eff=c+ΔG·u₀，无法把乘性故障从漂移中分离；R68 的 H_cal / H_sensor^trans 判别在该方向上不可辨识。这正是 R68 自陈风险的严格表述——不是标定不够准，而是结构不含该信息。

**引理 17（持续激发恢复秩）** 若探针窗内 Σ_{t∈T}u_t u_t^T ⪰ αI（α>0，PE 条件），则 FIM 在 (c,ΔG) 上正定，ΔG 可辨识，且观测增益 ΔI ≥ ½log(1+αT/σ²)>0。系：可激励子空间 E 中的乘性故障，在安全探针后必可被分离，检出概率由 ROC 给出。

**引理 18（无盲窗切换）** 若 MTP 全程成立保守包络（λ_eff≥max、k_eff≤min、τ_eff=min）且至少一个监控已认证，则切换期风险不超过两端点风险的最大值：R(t)≤max(R_m,R_m′)，∀t∈切换窗；且输出无跳变（bumpless），因为包络是两端点的逐点 max/min。故变胞不产生瞬态放宽，也不产生控制突变。

**引理 19（反振荡与可逆）** 迟滞 τ_lo<τ_hi 加驻留 T_dwell ⇒ 任意长 T 内变胞次数 ≤ ⌊T/T_dwell⌋；若模式图强连通且每边有认证逆边，则任意状态可在 ≤diam(𝔊) 步内返回标称模式，且返回路径全程满足 SK。故无死路、无抖动。

**定理 16（MORPH-RAS 端到端）** 在 R68 假设与 A95–A98 下：
1. P(|τ_cmd−τ*|>ε) ≤ [R68 各项] + α_gap + α_probe + α_trans，其中 α_gap 由 γ 的校准 ROC 界定，α_probe 由探针风险预算与中止路径界定，α_trans=0（引理 18 无盲窗）；
2. SK 全程成立（定义 295 + RCC 门 1）；
3. 对 E 中的乘性故障，检出概率 ≥ 同条件被动 R68 基线 + ΔI 对应的 ROC 提升（引理 17）；
4. 对 N 中不可激励故障，系统不谎称可辨识：输出 residual_gap_decl 并强制 λ_floor，检出只能依赖外部冗余（显式降级）。

**定理 17（研究空白闭合与残余声明）** 记 Id(s) 为结构 s 的可辨识参数集。则 Id(MORPH)=Id(R68)∪E，且对乘性故障 E\Id(R68)≠∅（引理 16 构造）；同时 Id(MORPH)∩N=∅ 且 MORPH 显式声明 N。即：**可激励的研究空白被闭合，不可激励的空白被诚实地画成边界，而不是假装填上。** 这既是能力提升，也是可证伪性提升。

**假设 A95–A98** A95：探针窗内测量近似线性时不变 y=c+Gu+ε，非线性项有界；A96：有限探针库 Π 能覆盖任务相关激发方向（PE 可达）；A97：物理变胞在已知安全插值轨迹上执行且可中止；A98：模式图有限、强连通、切换开销有界。

## 7. 本轮最大风险

**一句话**：MORPH-RAS 的全部诚实性押在「缺口证书 + 探针库覆盖」上——**若某类故障对所有可达重构都属于不可激励零空间（例如纯加性缓变漂移与加性故障在信息上同构，或故障响应恰位于 ∩_s null(FIM_s)），则没有探针能激发它；更危险的是 GAP 在有限探针库上算出 γ≈0，系统会把「库的盲区」误判为「世界的可辨识」，在 J_MORPH 里盖上它无权盖的章**——可重构能力越强，越容易把「我没试过的构型」错当成「我已穷尽的观测」。

**次级风险与缓解**：模式抖动 → 迟滞 + T_dwell（引理 19）；切换盲窗 → 保守包络 + 重叠见证（引理 18）；探针诱发失稳 → 认证前缀 + 中止 + 风险预算；安全核被重构侵蚀 → SK 哈希门 + 模糊测试；缺口伪报 → γ 校准 + VQAuditor-M 审计；探针库不完备 → residual_gap_decl 显式声明 + 外部冗余兜底。
