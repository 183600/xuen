## 1. 两个灵感的第一性原理

### 灵感 1 ·「运动控制」→ 策略与本体之间缺失的可行性/柔顺层

**直觉**：VLA 回答「做什么」，本体需要「怎么在关节/力矩/接触约束下可行地动」。上一轮的伺服层（IP-09）方向正确，却留下两个控制学硬伤：

1. U14 的混合式 `a=(1−β)a_VLA+β·u_servo` 是**任务空间里非物理的线性插值**：既可能越过关节速度/加速度/力矩边界，也可能在 β 切换处制造命令不连续——这正是 E621 想检测的抖振来源；
2. 插入/放置的「最后一厘米」本质是**接触/力**问题，不是纯视觉问题：PBVS 能把销钉在视觉上送到孔口，却解决不了最后 1–2mm 的接触啮合；刚性位置控制会卡死（jam），柔顺控制能让销钉借倒角自定心。

运动控制的经典解构正好补齐：

- **参考生成与平滑**：限速/限加速度 + 最小加加速度（minimum-jerk），把离散 chunk 变成连续可执行轨迹；
- **可行性投影**：CBF-QP / 约束 QP，把期望动作投影到「关节位/速/加速度/力矩（可选 CoM 支撑多边形）」可行集，硬约束而非软惩罚；
- **阻抗/导纳调度**：按相位切刚度——transport 刚性、align/insert 低刚度柔顺、release 回刚性；刚度是相位相关的控制变量；
- **全身冗余协调**：G1 是足式平台，够不到时用腰/基座分担（接 IP-05），用 QP 解冗余。

**关键洞见**：视觉伺服与柔顺是**互补而非替代**——视觉负责把误差降到毫米级，柔顺负责吃掉最后亚毫米的接触不确定性。且 QP 投影是凸集投影，具备「可行时零干预、不可行时最小改动、且 1-Lipschitz」的形式性质，可从数学上消除「滤波器自己引入抖振」的担忧（L11）。

### 灵感 2 ·「数据采集」→ 固定观测接口下，可获取的状态远多于原始信号

**直觉**：赛制冻结了观测字段，但「数据采集」不等于「被动收信号」，而是两件事：

1. **从流中重构状态（StateForge）**：标定/对齐/滤波后，估计 EE 速度、接触起始、滑移、相位。夹爪只有 1 维标量，看似没有力觉；但接触/滑移是**可观测**的——由「指令位姿 vs 实测位姿」的跟踪残差、夹爪标量导数、腕部光流、负载下的异常加速度共同反映。于是固定观测被榨成一条稠密、自监督的状态流，恰好是 IP-02/IP-09 的断言器与 IP-13 的柔顺切换都需要的输入。
2. **决定下一步采哪里（ActiveAcquire）**：数据瓶颈不是体量而是**覆盖**——169h 成功演示是体量，缺的是失败/接触/恢复覆盖与稠密标签。用 IP-06 的六因子误差图 + IP-13 的可行性违例作为「哪里弱」的信号，按「预期失败下降 / 采集成本」排序，定向去真机/仿真（IP-10）/扰动回放里采。这把 IP-12 的课程从「训练侧」补上了「采集侧」。

**关键洞见**：**StateForge 让标签密度免费上升，ActiveAcquire 让覆盖效率上升**；二者合起来，等于在「数据是公共品」的赛场上，把公共语料加工成别人没有的**稠密状态 + 定向覆盖**资产（P9 护城河）。

### 综合：执行栈从两层扩到四层

认知（VLA/断言/课程）→ 运动（DynGuard）→ 感知（StateForge）→ 采集（ActiveAcquire）。四层共享同一个实时预算 U12；任何一层超预算都必须可降级（见 §4 退化链）。

## 2. 研究问题（接 Q1–Q9）

- **Q10（可行性投影的无害性）**：CBF-QP 在名义（可行）动作上能否严格 pass-through？在约束边界的最小干预代价多大？会不会引入新的抖振？（E628/E629）
- **Q11（柔顺 vs 伺服的互补域）**：在什么接触状态下阻抗控制优于视觉伺服？相位调度的「伺服→柔顺」切换能否同时优于两者单独使用？（E630）
- **Q12（接触/滑移的可观测性）**：在固定观测接口下，接触起始与滑移能从本体残差里被重构到什么精度/延迟？加入这些通道后抓握确认 AUROC 能提升多少？（E631/E632）
- **Q13（主动采集的样本效率）**：失败因子驱动的定向采集，相对均匀/随机采集能否在固定预算下更快达到目标成功率？增益能否在分布偏移下保持？（E633）

## 3. 设计原则（接 P1–P9）

- **P10（可行性是一等公民）**：离开策略的每个动作都必须过可行性滤波；「不违反物理/接口约束」是硬约束，不是损失里的软惩罚。禁止无约束的朴素混合。
- **P11（接触即柔顺）**：align/insert/place 相位必须在调度柔顺下运行；刚度是相位相关控制变量，不是常量。
- **P12（采集先于训练）**：新增任何能力前，先说明它的状态可观测性（StateForge）与数据来源（ActiveAcquire）；依赖不可观测状态的组件一律不上线（与 P8 同构）。

## 4. 清单处置（深化 / 修剪 / 新增）

- **深化**：IP-09（U14 朴素混合 → **U17 QP 仲裁 + 相位柔顺调度**，E628–E630）；IP-03（chunk 缝合 → 轨迹平滑/限速，与 DynGuard 合并为「执行平滑」单一职责）；IP-02（抓握确认新增接触/滑移通道，E632）；IP-12（课程新增采集侧，IP-15）；IP-05（全身冗余由 IP-13 的 QP 解）。
- **新增**：IP-13 DynGuard（P0·轻量 / P1·完整）、IP-14 StateForge（P0）、IP-15 ActiveAcquire（P1）。
- **修剪**：**U14 的线性混合正式废弃**（保留 β 门控思想，输出改为 QP 投影）；IP-07 DualSpace 进一步弱化（关节/EE 一致性由 DynGuard 的约束统一处理，仅留观察位）；IP-08 继续并入 IP-03。
- **MVP 更新**：MVP = IP-06 + IP-02 + IP-09 + IP-03 + **IP-14 + IP-13（轻量）** + 通用基线。理由：StateForge 是断言器与伺服共同的前置；DynGuard 轻量版（限位+限速+平滑+pass-through）极便宜且直接消灭 ACTION REJECTED。完整柔顺/全身版排 MVP 后。
- **退化链新增**：**Level-2.5**（DynGuard 不可用 → 退回限幅裁剪 + 平滑，无 CBF 保证）；**Level-2.6**（StateForge 不可用 → 退回原始观测，断言器退化为纯视觉）。

## 5. 本轮最大风险（一句话）

**最大的风险是实时预算：QP + 滤波 + 接触估计会给 `get_action` 控制周期加延迟与耦合，一旦超预算就产生「过期动作」，其危害可能大于它要解决的问题——因此必须先测控制周期与端到端延迟，并把每一层都做成可 shed 的降级项。**

（补充：若 G1 实际为固定基座、且代理仿真不含接触/执行器限幅，E628–E631 的收益可能无法迁移——故所有控制层收益都必须真机 A/B 复核。）

## 6. 下一轮迭代计划

- **深化**：测控制周期/延迟预算（先做，决定一切）；DynGuard 轻量原型；StateForge 在仿真上用真值标定接触/滑移检测器；Q11 的相位-刚度调度表。
- **修剪预案**：E628 若名义动作改动 >5% 或延迟超预算 → 只保留限幅裁剪；E631 若接触 AUROC <0.75 → 断言器维持纯视觉；E633 若主动采集无样本效率增益 → 并入 IP-12 均匀 replay。
- **待外部事件**：榜单开放 → F2 复核（τ/oracle）；规则手册 → Q3/Q4/Q9。

## 0. 本轮结论摘要

**一句话路线**：把执行栈从 v2 的「认知两层」扩成 **认知 / 运动 / 感知 / 采集** 四层；运动层用**可行性投影 + 相位柔顺**修正 U14 的物理硬伤，感知层用**本体残差**补出固定观测缺失的接触/滑移状态，采集层用**失败因子驱动**定向补数据。三层共享实时预算 U12，且逐级可降级。

本轮不靠新情报，而靠两条第一性原理——**控制可行性**与**状态可观测性**——给既有清单做「物理地基加固」。其价值主张：对手通常只交付一个策略（policy），我们交付 **策略 + 控制栈 + 状态估计 + 采集回路**；后者需要真机标定与实时工程，天然是 P9 意义上的护城河。

## 1. 竞品差异与护城河更新

通用 VLA 竞品的典型交付是「观测→动作块」的单一通路；运动可行性、接触柔顺、本体接触估计通常不在其栈内。护城河表在 v2 基础上新增三行：

| 资产 | 可抄速度 | 护城河强度 | 对应 IP |
|---|---|---|---|
| 朴素动作裁剪（clip） | 天级 | 无（仅作基线） | —（E629 对照线） |
| 可行性 QP + 相位柔顺（真机标定） | 周–月级 | **强** | IP-13 |
| 本体感觉接触/滑移估计 | 周级 | 中强 | IP-14 |
| 失败因子定向采集 | 月级（依赖 IP-06/10） | 强 | IP-15 |

**判据**：IP-13 的护城河来自「约束建模 + 增益标定 + 实时性」三重工程密度；IP-14 来自对固定观测接口的深度利用（不增加接口字段即可获得接触/滑移）；IP-15 来自已建成的 IP-06/IP-10 先发优势。三者共同点：**不依赖更多数据/更大模型**，与 v2 的「护城河移出数据面」结论一致。

## 3. 新增 IP 详述

### IP-13 · DynGuard 可行性投影 + 相位柔顺 + 平滑（P0·轻量 / P1·完整，新）

- **动机**：v2 的 U14 用 `(1−β)a_VLA+β·u_servo` 直接混合，是任务空间非物理插值，可能越界、可能在切换处不连续；且「最后一厘米」是接触问题，刚性位置控制会卡死。
- **与现有方案差异**：把「混合」从**动作插值**改为**约束投影**——VLA 与伺服只生成**参考** `a_des`，真正执行的是投影到可行集的 `a*`；并按相位调度阻抗。对手一般不做显式可行集建模。
- **机制（三段）**：
  1. **平滑**：限速/限加速度 + 最小加加速度，把离散 chunk 变成连续参考（吸收 IP-03 的缝合职责）；
  2. **可行性投影（U17）**：`a* = argmin (a−a_des)ᵀW(a−a_des) s.t. A_t a ≤ b_t`，约束含关节位/速/加速度/力矩，可选 CoM 支撑多边形；
  3. **柔顺调度（U20）**：align/insert/place 用低刚度阻抗，transport/release 回刚性；刚度按相位分段。
- **可行性**：高。轻量版仅需关节限位/限速/平滑，单卡 CPU 微秒级 QP；完整版需本体动力学参数与真机标定。
- **资源**：无新数据；算力=极小（在线）；真机时段=标定用。

- **资源**：仿真真值（IP-06/IsaacLab ▲）+ 小算力；无新接口字段。

### IP-15 · ActiveAcquire 失败因子定向采集（P1，新）

- **动机**：数据瓶颈是**覆盖**不是体量；169h 成功演示缺失败/接触/恢复覆盖与稠密标签。IP-12 只覆盖「训练侧」，缺「采集侧」。
- **与现有方案差异**：不做「把所有数据混一起训」，而是**主动选择采哪里**：用 IP-06 六因子误差图 + IP-13 可行性违例率估计「哪里弱」，按「预期失败下降/采集成本」排序；来源优先级：真机（若有时段）> 仿真代理 rollout（IP-06）> 世界模型合成（IP-10）> 扰动回放。

- **可行性**：中–高。依赖 IP-06/IP-10 已建成；纯软件调度。
- **资源**：仿真/世界模型算力 + 采集预算；与 IP-12 共享。
- **落地步骤**：①定义因子误差图与成本模型；②实现采集打分与预算分配；③在代理仿真上做「主动 vs 均匀 vs 随机」对照（E633）；④与 IP-12 联训并测分布偏移保持性。

### IP-09 升级说明（U14 → U17）

v2 的 `a=(1−β)a_VLA+β·u_servo` **正式废弃**。保留其 β 门控思想（相位与断言置信度决定伺服权重），但输出改为：`a_des=(1−β)a_VLA+β·u_servo`（仅作参考）→ `a*=Π_{A_feas(s)}(a_des)`（真正执行）→ 接触相位叠加柔顺。这样既保留伺服收益，又获得硬可行性保证（L11）。

## 4. 符号与定义（新增 U16–U20；U1–U15 沿用前两轮）

- **定义 U16（可行动作集）**：`A_feas(s_t) = { a : A_t a ≤ b_t }`。约束行编码：一个控制周期内的关节位置界、速度/加速度界、力矩界，可选 CoM/支撑多边形；单步线性化后为多面体，可写成 QP。
- **定义 U17（安全滤波/仲裁）**：`a*_t = argmin_a (a−a_des)ᵀW(a−a_des) s.t. A_t a ≤ b_t`（等价于 CBF-QP：约束 `h(a) ≥ (1−γ)h(s_t)`）。`a_des` 只是参考，`a*` 才是执行命令。
- **定义 U18（状态采集映射）**：`ŝ_t = F(o_{t−k:t}, θ_cal) = (v̂_EE, p_contact, p_slip, p̂_phase)`，`F` 为标定 + 滤波 + 多通道检测头。
- **定义 U19（采集价值）**：`J(τ,p,f) = Û_f(τ,p)·ΔL̂_f / cost(τ,p,f)`，`Û_f` 为失败因子不确定度，`ΔL̂_f` 为该因子预期损失下降，`cost` 为采集成本；采集策略取 `argmax`。
- **定义 U20（阻抗调度）**：`F_cmd = k(p)(x_des−x) + d(p)(ẋ_des−ẋ)`，刚度 `k(p)` 与阻尼 `d(p)` 按相位分段；`p ∈ {align, insert, place}` 时 `k` 取低值以柔顺自定心。

def dyn_guard(a_des, s, phase):
    a_ref = smooth(a_des, s.prev_a, dt, v_max, a_max)      # 限速/限加速度 + 最小加加速度

## 6. 推导（新增引理 L11–L14；L1–L10 沿用前两轮）

**引理 L11（安全滤波的无害性与抗抖振）** 设 `A_feas(s)` 为闭凸集，`Π` 为按正定度量 `W` 的投影。闭凸集投影是**牢固非扩张**的：`⟨Π(x)−Π(y), x−y⟩_W ≥ ‖Π(x)−Π(y)‖_W²`，故 1-Lipschitz：`‖Π(x)−Π(y)‖_W ≤ ‖x−y‖_W`。推论：(i) 若 `a_des ∈ A_feas`，则 `Π(a_des)=a_des`——**名义可行区零干预**；(ii) 滤波输出不比参考更不连续（Lipschitz）⇒ **滤波器本身不引入新抖振**；(iii) 不可行时改动量为到可行集的最小加权距离。注意：`A_feas(s)` 随状态变化，若 `b(s)` 变化快于命令可响应速度，输出仍可能跳变 ⇒ 需对 `b(s)` 平滑并对输出限速。∎

**引理 L12（柔顺扩大插入吸引域）** 在倒角几何与准静态假设下，销-孔间隙 `c`、倒角角 `α`、摩擦系数 `μ`。刚性位置控制成功需初始横向偏差 `δ<c`（否则几何阻塞）。柔顺控制（横向刚度 `k_c`）在倒角接触产生横向恢复力；当 `μ<tan α`（摩擦锥条件）时销钉可沿倒角滑入，吸引域近似扩为 `δ < c + h·tan α`（`h` 为倒角深度），严格更大。若 `μ ≥ tan α`，柔顺无法自定心（卡死），须先由视觉伺服把 `δ` 降到倒角可捕获范围——**故视觉伺服与柔顺互补**（呼应 L8/L11）。∎

**引理 L13（主动采集的水位填充）** 设状态单元 `s` 上训练后残差 `e(s) ≤ e_0(s)·n(s)^{−α}`（`α>0`），预算 `N=Σn(s)`。最小化 `Σ_s w(s)e_0(s)n(s)^{−α}` 的 KKT 解为 `n*(s) ∝ (w(s)e_0(s))^{1/(1+α)}`：初错越大/权重越高，分配越多。均匀分配仅在 `w(s)e_0(s)` 为常数时最优；当失败因子异质（本项目的工作假设，teaser 已降级）时，主动分配严格降低目标 ⇒ **ActiveAcquire 用 IP-06 因子误差图近似该水位填充**。∎

**引理 L14（接触的可观测性下界）** 令指令位姿 `x_cmd`、实测 `x_meas`、测量噪声标准差 `σ`、控制频率 `f_s`，残差 `r_t=x_cmd,t−x_meas,t`。自由运动时 `r_t≈噪声`；接触时环境力使 `x_meas` 偏离，在 `r_t` 上产生阶跃/斜坡、在 `ẋ_meas` 上产生不连续。对接触致减速 `Δa`、窗口 `m` 个采样，检测 `SNR ≈ Δa·m^{1/2}/(σ f_s)`，故延迟 `τ_d≈m/f_s` 时可在 `Δa > κ σ f_s/m^{1/2}` 下检出。将残差通道与夹爪标量导数、腕部光流（噪声近似独立）融合可提升有效 SNR ⇒ **多通道接触 AUROC 高于任一单通道**。∎
