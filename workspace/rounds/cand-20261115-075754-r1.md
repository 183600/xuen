# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧」IP-253~263；灵感循环第 3 轮；本轮灵感：「并发推理」×「Gazebo」）

> R69 的进步是「不确定就去问」，但它整条消歧流水线是**串行**的：廉价门控 → 贵采样 → 聚类 → VoI → 交互 → 似然第二意见。更重要的是，它对「问」的收益判断压在一条未经检验的假设上——**流模型的模态分布可信**；R69 自己承认的最大风险正是「模态权重未校准 → 自信地追问幻影 / 给误导回答盖章」。
>
> 但在 R69 里还有一层更隐蔽的共模：**策略密度通道（FMA）与传感器标定通道共享同一个表征 z_t**。它们「一致」时，系统以为自己拿到了两个独立确认；实际上可能只是**同一个误差的两个副本**。R69 的所有安全论证都默认「第二条通道是独立的」，却没有度量这条独立性。
>
> 本轮两个灵感正好各补一刀：
> - **并发推理**：不是把同一件事跑得更快，而是**同时悬置多个互不相同的世界假设**（不同标定偏移、接触参数、人类意图先验），让它们在同一个决策时刻相互证伪；并把「投机执行」引入安全环路——贵路径提前并行启动，命中即隐藏延迟，未命中则安全丢弃。并发还会带来真问题：陈旧快照、预算双花、ODE 非确定性、竞态提交。
> - **Gazebo**：一台可批量、可复现、可注入扰动的**物理影子**。它能在真机执行前预演候选动作（含注视/探针）的物理后果与反事实观测，给出第三条证据通道；但它的偏是**系统性**的（sim-real gap），所以它只能**否决**，不能**确认**。
>
> 核心命题：把 R69 的「单世界模型 + 串行消歧」升级为「**多视图 + 并发投机 + 影子否决**」。真实观测、并行假设分支、Gazebo 影子构成**视差（parallax）**：三角测量要求视图误差**不共模**；共模的一致不是证据，而是必须被审计的假象。命名 **PARALLAX-RAS**（Parallel multi-hypothesis inference × Gazebo shadow, Asymmetric trust, Replayable commit, Arbitrated budget, Latent-consistency eXamination）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「该向谁求证」，R70 问「**我凭什么是相信这个答案的**」——从「多问一次」升级到「多视角、可复现、能证伪」，并诚实标注：**相关的一致不是票**。

## 0. 直觉与动机

**灵感 1（并发推理 ≠ 加速：并发是同时持有多个世界假设）**
直觉：R69 的串行流水线有一个致命时序：第一帧就把模态判错，之后所有交互都在**错的先验**上「求证」。并发立起 B 条假设分支，每条条件在不同的 θ_j（标定偏移 / 接触刚度 / 人类意图），错假设无法独占话语权。关键纪律：**重复采样同一条分支不产生新证据**——独立性的来源是假设与数据子集，不是 GPU 并行度。

**灵感 2（投机执行：延迟隐藏在并行里，安全留在提交门）**
直觉：R69 的「廉价门控 → 贵采样 → 交互」是三段串行延迟，P99 被最坏路径决定。并发推理允许把贵路径（B=4, K=4, GSV）在便宜路径同一 tick 投机启动；若便宜路径已达视差共识，直接提交，贵路径被安全丢弃；若未达共识，则等贵路径在 deadline 内补齐。**延迟 = 路径最小完成时间，安全 = 提交门的保守性**，二者解耦。

**灵感 3（并发的真代价是新的故障面）**
直觉：并发的第一性原理在安全环路里不是吞吐，而是「**单一提交者**」。否则会出现：分支读到过期 z_t（陈旧提交）、多个分支同时申请交互（预算双花）、GPU 归约顺序不同导致同一策略给出不同轨迹（不可复现）、某条诚实但慢的分支被快而错的分支饿死。这些都是 R69 没有的故障，必须逐个给出机制，而不是靠「小心一点」。

**灵感 4（Gazebo：批量反事实机器）**
直觉：R69 的 VoI 是纯模型算出来的「如果看到 y 我会多确定」——这是信念里的信念，很容易自我循环。Gazebo 能在物理层预演候选信息动作：注视会不会诱发危险转身、探针会不会越力/位包络、等待会不会撞上时间窗。它还能批量生成反事实观测，把 VoI 从「模型幻想」变成「模型先验 + 物理可行性」。这正好是 R69 定义 294/302 里「看/问/触」的可行性预演。

**灵感 5（仿真有偏，而且偏得系统 → 非对称信任）**
直觉：Gazebo 在接触富集、可形变、人-社交场景最不可信，而且它的偏是**方向一致**的（同一个物理引擎、同一套参数近似）。若把它当「真值」，系统会集体偏到同一个错处。因此采用**非对称信任**：**仿真能否决（收缩可行集），不能确认（不得作为安全正证据）；真实证据必须投票**。这既用上了仿真的批量能力，又不给它发「安全许可证」。

**灵感 6（视差与伪视差：相关的一致不是票）**
直觉：三角测量之所以成立，是因为两个视点的误差正交。但我们的三视图共享 R68 的 trunk、共享同一标定、共享同一状态估计——它们的一致很可能只是「同一个错误的三个副本」。所以必须**显式估计视图间误差相关 ρ**；当 ρ 高时，一致不计入证据（按 (1−ρ) 折扣），并触发「伪视差」报警。这是 R69「k 个正交证据源」纪律在**模型侧**的镜像：R69 防的是人撒谎，R70 防的是自己的模型合谋。

**灵感 7（R69 是本轮的边界，不是被推翻）**
直觉：当 B=1、关闭 GSV 否决、CCC 平凡时，PARALLAX 每一步与 FLUID-RAS 相同；再叠加 VoI≤成本就退化为 R68。安全侧只会因「否决只能删候选」而单调不弱。新层是旧层的严格泛化，而不是并列的第二个黑箱。

## 1. 形式化定义（增量：定义 310–323）

**定义 310（PARALLAX-RAS 总览与四不变式）** PARALLAX-RAS = (FMP, AUD, MINT, CIA, FMA, PEX, GSV, PAR, CCC, GBA, RAS-WM†)。四不变式：
(i) **实时流零学习写**（继承 R68 定义 276-i）；
(ii) **单一提交者**：并发分支对实时安全状态只读，唯一写者是 CCC，提交串行且确定性；
(iii) **非对称信任**：仿真证据只具否决权（V(S)⊆S），任何提交至少需要一个非仿真来源；
(iv) **预算守恒**：交互预算是全局共享资源，任意并发交错下单位时间信息动作 ≤ 1。

**定义 311（并发分支与假设）** 并发度 B；分支 j 携带世界假设 θ_j ∈ Θ（模态先验 / 标定偏移 / 接触参数 / 人类意图），快照纪元 e_j，轨迹 ξ_j=(a_j,g_j)，局部风险 R_j、信息增益 VoI_j，内容哈希 h_j = H(θ_j, ε_{e_j}, ξ_j, seed_j)。独立性来自 θ_j 与所用数据子集，**不来自重复采样**；同 θ_j 的多个样本记为一个分支的样本量，不计为独立分支。

**定义 312（三视图与视差）** V_real：真实观测下的策略密度/FMA 视图；V_branch：分支在模态身份 M 上的后验；V_sim：Gazebo 影子在 Δ_sim 扰动下的结果分布。视差 Π = (δ_rb, δ_rs, δ_bs) ∈ ℝ³，δ_uv 为视图 u,v 在（模态身份 TV / 动作 W₂ / 风险差）上的度量。**视差是向量不是标量**——不同分量指向不同故障。

**定义 313（视差签名与鉴别诊断）** σ = Diagnose(Π)：
- 低/低/低 → `consensus`：可进入提交门（仍需非仿真证据）；
- 高/低/低 → `model_bias`：真实-分支分歧而仿真与分支一致，疑模型/标定；预热 FMA/MCG；
- 低/高/高 → `sim_gap`：仿真偏离而真实/分支一致，降 τ_sim，仿真退为弱先验；
- 高/高/低 → `obs_fault`：真实孤立，走 R68 残差通道；
- 高/高/高 → `all_disagree`：不交互，纯 R68 保守。
共模修正：若 ρ̄ > ρ_crit，则所有「低」分量按 (1−ρ̄) 折扣，`consensus` 改判 `pseudo_parallax`。

**定义 314（Gazebo 影子验证器 GSV）** 对候选 ξ（含物理信息动作 g_phys），从 sim-real gap 分布 Δ_sim 采样 M 组初始/物理扰动，批量并行 rollout；否决若 P_sim(unsafe | ξ; Δ_sim) > τ_veto。**只有否决权**。反事实 VoI：VoI_sim(g) = H_sim(M|o) − E_{y~p_sim(·|g,o)}[H_sim(M|o,y)]，附带不确定性；仅用于排序/剪枝，不单独驱动真实交互。语义/社交类信息动作（g_ask）不被仿真覆盖，仍走 R69 真实交互与证据纪律。

**定义 315（仿真可信域与仿真标定 STC）** 特征 φ(s)（接触复杂度、可形变量、人-社交参与度、材质/光照）；由离线 sim↔real 回放残差标定 τ_sim(φ) ∈ [0,1]。φ 落域外或无标定数据 ⇒ τ_sim→0，GSV 弃权（不否决，只弱先验）。与 R68 传感器标定同构，但被标定的对象是**仿真器本身**。

**定义 316（并发投机调度与否决时域）** 便宜路径（B=1,K=1）与贵路径（B>1,K=4,+GSV）在同一 tick 并行启动。提交条件 = 视差共识 ∧ 非仿真证据 ∧ 预算令牌。贵路径在 deadline 内未达共识 ⇒ 用已到分支做保守合成，不等待。**否决时域**：不可逆/高风险候选必须等 GSV 否决窗结束才可提交；可逆/低风险候选允许延迟否决，迟到否决触发一个**已认证的有界安全停**。影子永不允许阻塞实时提交门（deadline miss = abstain）。

**定义 317（确定性提交与纪元校验）** CCC 只提交满足 e_j = ε_current 且 h_j 可复算的分支；提交是纯函数 Commit(branches, Π, ledger) → a。总序 O = lexicographic(risk_class, −VoI, h)，保证平局可复现；陈旧分支永不提交。复现收据：seed_j 由 (epoch, h) 派生、归约顺序固定；后端不可复现时需双跑一致性 ≤ δ_rep，否则该分支降级为「仅先验」。

**定义 318（全局预算仲裁 GBA）** 令牌桶容量 cap=1/tick；分支提交投标 b_j=(VoI_j−c_j, risk_j)；每 tick 至多兑现一个「最高正收益且安全」的投标，其余释放预留；预留在超时/否决/陈旧时回收。任意交错下 used ≤ cap（定理 20）。

**定义 319（视图去相关与共模审计）** 视图对 (u,v) 的误差相关 ρ_uv 由受控扰动注入在已知真值的回放段上估计（错误共现率）。ρ_uv 高 ⇒ 二者一致不计票，按 (1−ρ_uv) 折扣；定义有效视图数 B_eff = 1 + Σ_{u≠v}(1−ρ_uv) 的折扣计数。三视图一致但 ρ̄>ρ_crit 触发「伪视差」报警（定义 313）。

**定义 320（非对称证据合成）** 来源权重：真实（可投票，随 R69 k-正交一致增长）、分支（受 MCG 校准，仅概率投票）、仿真（仅否决）。合成规则一句话：**仿真能否决，真实必须投票，相关的一致不算票**。

**定义 321（安全包络单调性）** 否决算子 V: 2^𝒜→2^𝒜 满足 V(S)⊆S；CCC 只在 V(候选) 中按 O 序提交。故加入并发/仿真后任一状态可行集是 R69 可行集的子集，安全违规率上界不增；代价只是否决假阳性带来的效率损失。

**定义 322（证书 J_PARALLAX）** J_PARALLAX = (J_FLUID, B, ε, commit_trace_hash, σ, ρ̄_cm, gsv_veto_count, τ_sim, budget_ledger_hash, replay_parity)。Valid ⇔ J_FLUID valid ∧ 无陈旧提交 ∧ 账本守恒 ∧ 否决未被越过 ∧ 复现一致 ∧ 存在非仿真证据。

**定义 323（参与式审计 VQAuditor-P）** 审计并发特有失败：陈旧提交、预算双花、否决被绕过、伪视差（高 ρ 一致被当证据）、分支饿死、诊断-结果错配。结论回灌 Δ_sim、ρ 估计、MCG 与预算先验。

```python
# IP-264 PEX：并发假设分支（对实时安全状态只读）
class ParallelEpistemicExplorer:
    def __init__(self, trunk, v, mode_head, hypotheses):
        self.trunk, self.v, self.mode_head = trunk, v, mode_head
        self.theta = hypotheses           # Θ：标定偏移 / 接触参数 / 意图先验

    def launch(self, o_t, epoch, B):
        z = self.trunk(o_t)               # 只读快照，不写回
        out = []
        for j in range(B):
            seed = derive_seed(epoch, j)
            K    = 1 if B == 1 else 4
            xi   = sample_flow(self.v, z, self.theta[j], seed, K)
            out.append(Branch(j, xi=xi,
                              risk=risk_of(self.theta[j], xi),
                              voi=voi_of(self.theta[j], xi),
                              h=content_hash(self.theta[j], epoch, xi, seed),
                              e=epoch))
        return out                         # 同 theta 的多样本=样本量，不计独立分支

# IP-265 GSV：Gazebo 影子（批量反事实；只有否决权）
def gsv_veto(xi, phi_s, M=32):
    if sim_trust(phi_s) <= TAU_SIM_OFF:
        return False, 0.0                  # 域外：弃权，不否决
    unsafe = 0
    for w in sample_sim_gap(M):            # Δ_sim 物理/初始扰动
        res = gazebo_batch_rollout(xi, w)  # 批量并行物理
        unsafe += int(res.violates_envelope())
    p = unsafe / M
    return p > TAU_VETO, p

def voi_sim(modes, g, o):                  # 反事实 VoI，仅排序用
    return entropy_sim(modes) - expected_entropy_sim(modes, g, o)

# IP-266 PAR：视差签名与鉴别诊断
def parallax(v_real, v_branch, v_sim, rho_bar):
    pi = (tv(v_real, v_branch), tv(v_real, v_sim), tv(v_branch, v_sim))
    sigma = diagnose(pi)                   # 定义 313 决策表
    if rho_bar > RHO_CRIT and sigma == 'consensus':
        sigma = 'pseudo_parallax'          # 共模：一致不算证据
    return sigma, pi

# IP-267 CCC：单一提交者，纪元 + 哈希 + 确定性总序
def commit(branches, sigma, ledger, epoch, epoch_now):
    if sigma == 'all_disagree':
        return None                        # 退 R68 纯保守
    live = [b for b in branches if b.e == epoch_now and verify(b.h)]  # 去陈旧
    live = [b for b in live if not gsv_veto(b.xi, phi(b))[0]]         # 否决只删
    if not any(b.real_evidence for b in live):
        return None                        # 非仿真证据必需（定义 320）
    live.sort(key=lambda b: (b.risk_class, -b.voi, b.h))              # 总序 O
    return live[0] if ledger.claim(live[0].j) else None

# IP-268 GBA：跨分支全局预算仲裁（守恒）
class BudgetLedger:
    def __init__(self, cap=1): self.cap, self.used, self.reserved = cap, 0, {}
    def bid(self, j, b): self.reserved[j] = b
    def claim(self, j):
        if self.used + 1 > self.cap: return False
        self.used += 1; self.reserved.pop(j, None); return True
    def tick(self): self.used = 0; self.reserved.clear()

# IP-269 STC + 共模审计：离线标定仿真可信域与视图相关
def sim_trust(phi_s):
    return tau_sim_table.lookup(phi_s)     # 域外/无数据 -> 0（弃权）

def common_mode_rho(replay_segments):
    errs = {v: errors_of(v, replay_segments) for v in ('real', 'branch', 'sim')}
    return estimate_pairwise_corr(errs)    # ρ̄，用于定义 313/319

# IP-274 主闭环（继承 R69，把串行消歧换成并发投机 + 三视图 + 确定性提交）
def PARALLAX_RAS_round(M, obs, epoch):
    M.ledger.tick()                        # 每 tick 重置预算
    z, o = M.mtm.forward_readonly(obs)     # 只读，不写学习状态
    # 1) 并发投机：便宜 / 贵路径同 tick 启动
    cheap = launch_async(lambda: M.pex.launch(o, epoch, B=1))
    if M.fmp.mode_head(z) >= TAU_MODE:
        rich  = launch_async(lambda: M.pex.launch(o, epoch, B=4))
        branches = cheap.result() + (rich.result(deadline_ms=M.dl) or [])
    else:
        branches = cheap.result()          # 命中：丢弃贵路径
    # 2) R69 的不确定性二分与似然第二意见
    U_ale, U_epi, modes = M.aud.decompose([b.xi for b in branches])
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o_obs, o_calibrated)
    slow  = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    # 3) 三视图 -> 视差 -> 鉴别诊断
    v_real, v_branch = density_view(M.fmp, o), branch_posterior(branches)
    v_sim = M.gsv.voi_sim(modes, candidate_info(branches), o) \
            if sim_trust(phi(o)) > 0 else None
    sigma, pi = parallax(v_real, v_branch, v_sim, M.rho_bar)
    # 4) 单一提交者：纪元/哈希/否决/预算/总序
    bid = M.gba.bid_best(branches) if U_epi > TAU_EPI else None
    commit_b = M.ccc.commit(branches, sigma, M.ledger, epoch, M.epoch_now)
    # 5) 风险缩放：提交成功仅用 U_ale；否则未消解 epistemic 视同 aleatoric
    if commit_b is None or slow:
        U_floor = U_ale + U_epi
        mode, lam = safest_mode(modes), max(lam_floor(U_floor), 0.8 if slow else 0.0)
    else:
        mode, lam = commit_b, lam_floor(U_ale)
    k = M.c_ras_wm.certified_prefix(mode.a[:M.vista.H], ..., wm_preds)
    # 6) 参与式审计 + 证书（含并发特有字段）
    M.vqa_p.submit_async(sigma, pi, M.rho_bar, commit_b, M.ledger.snapshot())
    return k, lam, mode, sigma, pi, (U_ale, U_epi)
```

## 3. 推导

**引理 19（否决的单调性与安全不弱化）** 否决算子 V 满足 V(S)⊆S，CCC 只在 V(候选) 中按 O 序提交，故加入 GSV/并发后任一状态的可行集是 R69 可行集的子集；安全违规率上界不增。系：否决的假阳性（误杀安全动作）只损失效率，不损失安全——**这条非对称性正是允许仿真进入安全环路的前提**。

**引理 20（视差可辨识性与其边界）** 设三视图误差在无故障时条件独立（ρ=0）且两两一致率 ≥ 1−α；在每种单一故障模式下存在一个分量显著偏离（定义 313 决策表互异）。则签名分类器对 {无故障, 标定吸收, sim-real gap, 观测故障, 全面分歧} 的误分率 ≤ f(α, 分离裕度)。系（关键）：当 ρ>ρ_crit 时条件独立假设破裂，可辨识性保证**失效**——这正是「伪视差」风险的来源，定理在此处诚实失效，而不是被掩盖。

**引理 21（Gazebo-VoI 的偏差界）** 反事实 VoI 与真实 VoI 的偏差由 sim-real gap 的 TV 距离界定：|VoI_sim − VoI_real| ≤ L_v·TV(p_sim, p_real)。故仅当 TV 估计小且 τ_sim 在可信域时，VoI_sim 才可与模型 VoI 并列；否则只作排序先验，不得单独驱动真实交互。

**定理 18（嵌套严格泛化）** B=1 且 GSV 关闭（τ_veto=1 或 τ_sim=0）且 CCC 平凡时，PARALLAX 每步输出与 FLUID-RAS 逐指令相同；再叠加 VoI(g*)≤c(g*) 时与 R68 相同。安全侧因引理 19 单调不弱。故 R68 ⊂ FLUID-RAS ⊂ PARALLAX-RAS 是**逐指令的退化链**，而非并列替代。

**定理 19（并发提交的顺序等价）** 在单一提交者 + 纪元校验 + 内容哈希 + 确定性总序 O 下，任意并发交错得到的提交序列，等于把获胜分支按 O 序串行执行的序列；陈旧分支的提交数为 0。故并发不引入新的安全违规（相对「顺序执行同一分支集」）。

**定理 20（预算守恒）** 令牌桶 + 预留回收 + 每 tick 至多兑现一次，在任意交错下不变式 used ≤ cap 成立。故并发度 B 不会使单位时间信息动作超过 1（定义 310-iv、318），预算双花在机制层被排除而非靠约定。

## 6. 本轮最大风险

**一句话**：PARALLAX-RAS 的全部新论证都押在「三视图的误差不共模」这一前提上——**但真实观测、并行分支与 Gazebo 影子共享同一个 trunk、同一套标定、同一个状态估计，它们的一致极可能只是「同一个错误的三个副本」**；一旦如此，视差就退化为伪视差，系统会拿着 J_PARALLAX 这张「三项一致」的干净证书，去执行一个所有视图一起错掉的动作——R69 的「问错」被升级成「**用可复现、可审计、可证书化的方式确信地问错**」，这比不问更危险。

**次级风险与缓解**：
1. **影子误否决拖垮效率**（误杀安全动作）→ 非对称信任 + E303 误否决预算；否决只删候选，安全不受损。
2. **并发预算竞态/双花** → 单一提交者 + 令牌桶 + 定理 20 + E305 对抗交错。
3. **不可复现的 ODE/GPU 非确定性** → 种子派生 + 固定归约 + 双跑 δ_rep + 不可复现即降级（定义 317）。
4. **Gazebo 时延阻塞实时门** → 影子只做边侧异步、miss=abstain、可逆动作延迟否决 + 已认证安全停（定义 316）。
5. **慢而诚实的唯一分支被饿死** → GBA 的投标包含 `risk_class` 与最小保留名额，VQAuditor-P 审计分支饿死（定义 323）。

**定义 319–320（共模审计与证据合成）** 受控扰动估计 ρ_uv，高 ρ 一致按 (1−ρ) 折扣并报伪视差；**仿真能否决，真实必须投票，相关的一致不算票**。

```python
# IP-264 PEX：并发假设分支（只读）
class ParallelEpistemicExplorer:
    def launch(self, o_t, epoch, B):
        z = self.trunk(o_t)                     # 只读快照
        return [Branch(j,
                       xi=sample_flow(self.v, z, self.theta[j],
                                      derive_seed(epoch, j), 1 if B == 1 else 4),
                       risk=risk_of(self.theta[j]), voi=voi_of(self.theta[j]),
                       h=content_hash(self.theta[j], epoch, j), e=epoch)
                for j in range(B)]

# IP-265 GSV：物理影子，只有否决权（域外弃权）
def gsv_veto(xi, phi_s, M=32):
    if sim_trust(phi_s) <= TAU_SIM_OFF: return False
    p = sum(gazebo_batch_rollout(xi, w).violates_envelope()
            for w in sample_sim_gap(M)) / M
    return p > TAU_VETO

def voi_sim(modes, g, o):                        # 仅排序/剪枝
    return entropy_sim(modes) - expected_entropy_sim(modes, g, o)

# IP-266 PAR：视差签名与共模修正
def parallax(v_real, v_branch, v_sim, rho_bar):
    pi = (tv(v_real, v_branch), tv(v_real, v_sim), tv(v_branch, v_sim))
    sigma = diagnose(pi)                         # 定义 313 决策表
    return ('pseudo_parallax' if (rho_bar > RHO_CRIT and sigma == 'consensus')
            else sigma), pi

# IP-267 CCC：单一提交者（纪元 + 哈希 + 总序 O）
def commit(branches, sigma, ledger, epoch_now):
    if sigma == 'all_disagree': return None
    live = [b for b in branches if b.e == epoch_now and verify(b.h)]
    live = [b for b in live if not gsv_veto(b.xi, phi(b))]
    if not any(b.real_evidence for b in live): return None   # 非仿真证据必需
    live.sort(key=lambda b: (b.risk_class, -b.voi, b.h))     # 确定性总序
    return live[0] if ledger.claim(live[0].j) else None

# IP-268 GBA：预算守恒
class BudgetLedger:
    def __init__(self, cap=1): self.cap, self.used, self.reserved = cap, 0, {}
    def claim(self, j):
        if self.used + 1 > self.cap: return False
        self.used += 1; self.reserved.pop(j, None); return True
    def tick(self): self.used = 0; self.reserved.clear()

# IP-269 共模审计：受控扰动估计视图误差相关
def common_mode_rho(replay_segments):
    errs = {v: errors_of(v, replay_segments) for v in ('real', 'branch', 'sim')}
    return estimate_pairwise_corr(errs)

    if M.fmp.mode_head(z) >= TAU_MODE:

        branches = cheap.result() + (rich.result(deadline_ms=M.dl) or [])
    else:

    U_ale, U_epi, modes = M.aud.decompose([b.xi for b in branches])
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o_obs, o_calibrated)
    slow  = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    v_real, v_branch = density_view(M.fmp, o), branch_posterior(branches)
    v_sim = (M.gsv.voi_sim(modes, candidate_info(branches), o)
             if sim_trust(phi(o)) > 0 else None)
    sigma, pi = parallax(v_real, v_branch, v_sim, M.rho_bar)

    k = M.c_ras_wm.certified_prefix(mode.a[:M.vista.H], ..., wm_preds)

```

## 4. 推导

**引理 19（否决单调性 / 安全不弱化）** V(S)⊆S 且 CCC 只在 V(候选) 中提交 ⇒ 加并发/仿真后可行集是 R69 的子集，安全违规率上界不增；否决假阳性只损效率不损安全。这是允许仿真进安全环路的**唯一**正当理由。

**引理 20（视差可辨识性及其边界）** 无故障时三视图条件独立（ρ=0）、两两一致率 ≥1−α，且各故障模式有互异偏离分量 ⇒ 签名误分率 ≤ f(α, 分离裕度)。系：`ρ>ρ_crit` 时独立性破裂，可辨识性**失效**——定理在此诚实失效，伪视差风险由此产生（不是被掩盖）。

**引理 21（Gazebo-VoI 偏差界）** `|VoI_sim − VoI_real| ≤ L_v·TV(p_sim, p_real)`；仅当 TV 小且 τ_sim 在可信域才可与模型 VoI 并列，否则只作排序先验。

**定理 18（嵌套严格泛化）** B=1 且 GSV 关闭且 CCC 平凡 ⇒ 与 FLUID-RAS 逐指令相同；再 `VoI≤c` ⇒ 与 R68 相同。`R68 ⊂ FLUID ⊂ PARALLAX` 为逐指令退化链；安全侧因引理 19 单调不弱。

**定理 19（并发提交顺序等价）** 单一提交者 + 纪元校验 + 内容哈希 + 总序 O ⇒ 任意并发交错的提交序列 = 获胜分支按 O 序串行执行的序列；陈旧提交 = 0。并发相对「顺序执行同一分支集」不引入新违规。

**定理 20（预算守恒）** 令牌桶 + 预留回收 + 每 tick 至多兑现一次 ⇒ `used ≤ cap` 在任意交错下恒成立；并发度 B 不使信息动作超过 1/单位时间，双花在机制层被排除。

| 视差 PAR + 签名 | < 0.05ms | O(B+\|ℰ\|) | 定义 312–313 |

| GSV 影子（M=32，批量） | 边侧异步，非关键路径；miss=abstain | 外置 | 定义 314–316 |

## 7. 本轮最大风险

**一句话**：PARALLAX-RAS 的全部新论证都押在「三视图误差不共模」这一前提上——**但真实观测、并行分支与 Gazebo 影子共享同一个 trunk、同一套标定、同一个状态估计，它们的一致极可能只是「同一个错误的三个副本」**；一旦如此，视差退化为伪视差，系统会拿着 J_PARALLAX 这张「三项一致」的干净证书执行一个所有视图一起错掉的动作——R69 的「问错」被升级成「**用可复现、可审计、可证书化的方式确信地问错**」，比不问更危险。

**次级风险与缓解**：
1. **影子误否决拖垮效率** → 非对称信任 + 误否决预算（E303）；否决只删候选，安全不受损。
2. **并发预算竞态/双花** → 单一提交者 + 令牌桶 + 定理 20 + 对抗交错测试（E305）。
3. **ODE/GPU 非确定性** → 种子派生 + 固定归约 + 双跑 `δ_rep` + 不可复现即降级（定义 317、E306）。
4. **Gazebo 时延阻塞实时门** → 边侧异步 + miss=abstain + 可逆动作延迟否决触发现有认证安全停（定义 316）。
5. **慢而诚实的唯一分支被饿死** → GBA 投标含 `risk_class` 与最小保留名额 + VQAuditor-P 审计分支饿死（定义 323）。
