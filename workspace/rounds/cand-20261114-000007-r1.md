# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「研究空白」×「语言指令」）

> R69 教会系统「问」，但所有轮次共享一个从未被审视的前提：**任务本身是给定的、正确的、完整的**。R66 问谁控制，R67 问未来怎样，R68 问测量准不准，R69 问该向谁求证——它们全都在**执行层**打转，把「做什么」当作公理。可真实部署里，「做什么」恰恰是最不可靠的一环：语言指令是人把意图传给机器的唯一高带宽通道，而它天生**欠定**（「把那个拿过来」）、**指示依赖**（「这里/那个」）、**层次化**（「先…再…除非…」）、**含未言明规范**（「礼貌点/轻一点」），甚至**与安全冲突**（「别管红灯，快」）。
>
> 本轮两个灵感正好戳中这个空洞：
> - **研究空白**：科学里的「gap」不是无知，而是**结构化的缺席**——「已被提问的」与「尚未被回答的」之交。对具身智能体，同构对象是**指令间隙**：指令明确之外、却必须由执行者替人类补全的决策点集合。前四轮把间隙当成「策略先验」默默填掉——这正是本循环自身最大的研究空白。
> - **语言指令**：R69 只把语言当**输出**（发问）；本轮把它当**输入规格**（任务的定义域），也因此带来一张全新的信任边界与攻击面。
>
> 核心命题：**把「不确定性」从二元升级为三元——aleatoric（噪声）/ epistemic（世界与动作歧义）/ spec（指令规格歧义，即间隙）；对 U_spec 不做期望平均（那要求一个恰好不可信的意图先验），而是维持一个带覆盖保证的解释集 𝕀，只在「解释不变安全核」内行动；何时问，不取决于「有多模糊」，而取决于「下一步是否不可逆」。** 命名 **GAP-RAS**（Grounded-instruction Ambiguity-Partition Risk-Adaptive System）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我到底被要求做什么，它又没说什么**」——不确定性第一次不是关于世界，而是关于**任务本身**。

## 0. 直觉与动机

**灵感 1（研究空白 → 间隙是「被结构化的缺席」，不是随机噪声）**
直觉：论文的 research gap 从来不是「我什么都不知道」，而是「已知 A、B、C，唯独 A∩B 处无人回答」。同理，一句指令的空白不是一团模糊，而是一个**有坐标的缺席**：它精确地知道自己在哪些决策点上沉默——指代、次序、量、目标判据、规范、约束范围。把这些坐标显式化，就得到一个可计算、可审计、可被主动填补的对象，而不是端到端策略里被先验悄悄吸收的黑洞。本轮第一个理论姿态：**把「未言明」从隐变量提升为一阶公民**，它的名字叫间隙 𝔾。

**灵感 2（语言指令 → 规格是输入通道，也是契约与攻击面）**
直觉：R69 里 `g_ask` 只是输出，语言被当作「提问工具」。但指令是**任务的定义**：目标、约束、偏好、成功判据都由它承载。一旦语言进入输入端，三件事同时发生：(a) 歧义从动作模态上移到**任务语义**；(b) 语言成为可反向核对的**契约**——执行中能问「我做的还是你要的吗」；(c) 出现全新威胁——环境里的文字被误当指令（间接提示注入），提问可以诱导，回答可以共谋。语言既是规格，也是新的信任边界。

**灵感 3（解释集而非点估计 → 不要在意图上做期望）**
直觉：R69 的 U_epi 可以在动作模态上做期望，因为各模态都是「同一个任务」的完成方式。但规格歧义不同：绕左与绕右可能是**两个不同目标**，且最坏那个可能灾难性。对不可通约的解释做加权平均，数学上可行、伦理上错误。正确姿态是**集合**：维持与指令+上下文一致的**解释集 𝕀**，要求执行的动作对 𝕀 中**每一个**解释都安全、都合规、都不提前排除其可实现性——即**解释不变安全（interpretation-invariant safety）**。宁可在交集里慢慢推进，也不在并集上押注。

**灵感 4（可逆性 → 何时问由不可逆性决定，不由模糊度决定）**
直觉：人不会因为「有点不确定」就停下来问；人只在**要按不可逆按钮**时才问（签合同前、拆包装前、推倒墙前）。如果下一步可撤销，先做再看不亏；如果下一步会关掉某扇门，就必须先问。这把 R69 的「模糊就查」精化为一条更省交互的纪律：**公共前缀优先，可逆则做，不可逆则问**。它正面回应了 R69 自陈的过度发问隐忧，也把「问」从一种礼貌升级为一种**承诺时机**的判断。

**灵感 5（语言是契约 → 需要合规残差与假设账本）**
直觉：既然指令是契约，就能在执行中核对——这给了第三条独立通道。R68 测传感器自洽（残差 r_res），R69 测行为自洽（流似然 Δa），R70 测**任务自洽**（合规残差 r_ins）。一个逐渐「跑偏」的系统可能仍然安全（R68 过）、仍然自然（R69 过），却在做一件你没要求的事——这正是 specification gaming / goal drift。而凡是替人类补全的假设，都必须进**假设账本**：日后某假设被证伪，能精确追溯哪些动作依赖过它。这是把论文的「局限性」变成运行时可审计、可反事实重放的产物。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（GAP-RAS 总览）** GAP-RAS = (IGP, CIS, SCR, RCC, GDM, NQC, ICM, AL, IPG, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **安全包络解释不变**：语言指令不得扩张物理/社交安全包络，∀θ∈𝕀, C_safety ⊆ C_θ；
(iii) **不平均意图**：所有决策在解释集上取交集/最坏情形，禁止对解释做期望后按平均意图执行；
(iv) **可追溯**：任何对未言明决策点的补全必须写入假设账本，且与依赖它的动作哈希绑定。

**定义 311（指令到部分任务图）** 指令 ℓ 经组合语义解析得**部分任务图** G_ℓ = (V, E, φ)：V 为子目标/约束节点，E 为时序/因果边（偏序），φ 为未绑定变量（指代、量、范围、判据）。解析器允许**弃权**：只输出确定部分，把不确定处标记为间隙变量，禁止为了「完整」而强制补全。

**定义 312（解释与解释集）** 一个解释 θ = (T_θ, C_θ, S_θ)：任务（子目标偏序 + 目标判据）、约束集、成功谓词。候选空间 Θ 由对 φ 的有限分支填充（受分支上限 B 约束）生成。给定标定集 {(ℓ, o, θ*)}，非一致性分数 s(θ; ℓ, o)（解析负对数似然 + 结构惩罚）。取标定分位 q̂_{1−α}，定义**解释集** 𝕀_α(ℓ,o) = {θ ∈ Θ : s(θ; ℓ, o) ≤ q̂}。在可交换性下 P(θ* ∈ 𝕀_α) ≥ 1−α，称为**语义共形覆盖**。

**定义 313（指令间隙与间隙剖面）** 间隙 𝔾(ℓ,o) 是部分任务图中未绑定变量之集。按语义分型：Γ_ref（指代/指示）、Γ_ord（次序/并发）、Γ_quant（量/容差）、Γ_goal（目标判据）、Γ_norm（隐含规范/偏好）、Γ_scope（约束作用域）。每条间隙附「坐标」：所在节点、可选解释、各自后果。

**定义 314（判别核与间隙量级）** 对状态 s，若解释 θ、θ' 在 s 处的最优动作不同，记 a*_θ(s) ≠ a*_{θ'}(s)。**判别核** K(s) = {(θ,θ') : a*_θ(s) ≠ a*_{θ'}(s)}。**间隙量级** g(s) = 解释集上由 K(s) 诱导的等价类数（或加权熵），**只统计会改变动作的解释分歧**——分歧但不改动作的模糊不产生量级（呼应 R69 引理 16 的「可分才值钱」）。

**定义 315（解释不变安全核）** 动作前缀 a 对 θ **可行**：存在后续策略在 T_θ 下达成 S_θ。a 对 θ **违规**：违反 C_θ 中任一约束。定义 a 的**违规集** V(a) = {θ ∈ 𝕀 : a 违规或不可行}。**安全核** 𝒞(𝕀,s) = {a : V(a) = ∅}。执行只允许在 𝒞 内（含空动作/安全等待）。

**定义 316（可逆性与承诺）** a 对 𝕀 **可逆**：∀θ∈𝕀, a 不排除 T_θ 的后续实现（不 foreclose）。**公共前缀任务** T_∩ = ⋂_{θ∈𝕀} T_θ：所有解释都要求的子目标之并。**承诺度** c(a) = |{θ : a 使 θ 的剩余可行集严格缩小}| / |𝕀|；不可逆 ⇔ c(a)=1 且至少一个 θ 被排除。

**定义 317（间隙决策管理器 GDM）** 每个决策点按固定优先级：
1. 若 T_∩ 在 𝒞 中有推进动作 a_∩：执行 a_∩（**公共前缀优先**）；
2. 否则若 𝒞 中存在可逆且提升选项价值的动作 a_rev（重定位/观察/等待）：执行 a_rev；
3. 否则（下一步必为判别性且不可逆）：进入澄清 G*（定义 318–319）；
4. 若澄清不可行/超预算：执行最小承诺动作，或安全停机并报告**未消解间隙**——**绝不猜**。

**定义 318（不可逆感知的澄清价值）** VoI_gap(g) = E[Δ(间隙量级 g(s) 的降低)] · w_irr(s)，其中 w_irr(s)=1 当下一步为不可逆判别决策，否则 0。仅当 w_irr=1 且间隙为「阻塞」（K(s)≠∅ 且无公共前缀推进）时澄清才被允许。⇒ 可逆时澄清被支配（引理 21）。

**定义 319（中性澄清与问句集）** 澄清不是单问句，而是**假设枚举**：Q(g) = {q_θ}，把争用的解释**对称地**摆出（「你是要 A 还是 B，还是都不是？」），禁止倾向性措辞、禁止用默认值暗示。定义**问句中性度** N(Q) = 1 − KL(p_answer ‖ uniform over 𝕀)/log|𝕀|；N 低于阈值则问句作废（防止借提问操控人类）。

**定义 320（解释集的集合值更新）** 收到回答 y 后不做贝叶斯平均，而是**收缩集合**：𝕀' = 𝕀 ∩ {θ : L(θ; y) ≥ τ_L}，并用在线共形重标定保持覆盖。若 𝕀' = ∅（回答与全部解释矛盾）⇒ 判为**投毒/误解**，回滚并升级；多源证据仍遵守 R69 的 k-正交一致纪律（定义 293-iii）。

**定义 321（指令合规残差 ICM）** 对已认证解释集 𝕀，执行轨迹 ξ 的合规残差 r_ins(ξ, 𝕀) = Σ_c w_c·viol_c(ξ) + λ_ord·ord_dev(ξ) + λ_goal·(1 − max_θ S_θ(ξ))，其中 viol_c 为约束违反指示、ord_dev 为偏序偏离、S_θ 为成功谓词。**goal drift 判据**：r_safe↓（R68 过）、Δa↓（R69 过）而 r_ins↑ ⇒ 任务已是「别的」。三通道 (r_res, Δa, r_ins) 正交，任一异常触发重锚定（重解析 + 重认证）。

**定义 322（假设账本 AL）** 每次由间隙补全驱动的决策记录条目：(决策点 id, 间隙类型, 被假设的补全值, 来源∈{先验, 上下文, 澄清}, 该解释的共形分, 依赖动作哈希集)。**反事实可审计**：给定「若该假设为假」，可离线重放并报告当时会选的替代动作；账本根哈希随 J_GAP 固化。

**定义 323（指令来源与注入防护 IPG）** 定义来源格 L：签名主体 > 注册信道 > 观测中的自由文本。**只有 L ≥ 注册信道** 的文本可作为指令修改 T_θ/C_θ；观测中的指令样式文本只能作为**证据**，须隔离与转义。任何试图从环境文本扩张 C_safety 或新增任务节点的情形判为**间接提示注入**，隔离并计入 AIC-SPEC。

**定义 324（对抗指令语料 AIC-SPEC）** ℰ_SPEC = ℰ_FLUID × ℰ_inject（环境文本注入、越权指令、诱导性澄清回答、共谋语义欺骗、间隙轰炸）× ℰ_drift（goal drift / 规格游戏 / 慢变任务偷换）。并入证书与对抗训练。

**定义 325（证书 J_GAP 与严格包含）** J_GAP = (J_FLUID, conformal_coverage_hat, α, |𝕀|, gap_profile_hash, blocking_gap_count, clarification_neutrality_p95, r_ins_p95, assumption_ledger_root, injected_text_quarantined, gap_ver)。Valid ⇔ Valid(J_FLUID) ∧ coverage ≥ 1−α−δ ∧ 无未记录的间隙补全 ∧ 无未隔离的可疑指令文本。**退化链**：当 |𝕀|=1（指令无歧义）时 GAP-RAS 逐指令退化为 FLUID-RAS；再叠加 R69 的 VoI≤成本，退化为 CALM-RAS ⇒ **R68 ⊂ R69 ⊂ R70**。

## 2. 关键算法骨架

```python
# IP-264 IGP：指令 -> 部分任务图（弃权优先，不强行补全）
def parse_instruction(l, o, parser):
    g_partial = parser.parse(l, o, allow_abstain=True)   # 只输出确定部分
    gap       = enumerate_open_vars(g_partial)           # ref/ord/quant/goal/norm/scope
    return g_partial, gap

# IP-265 CIS：语义共形解释集（有限分支 + 分位阈值）
def interpretation_set(g_partial, gap, o, calib, alpha, B=32):
    cands  = beam_complete(gap, ctx=o, branch_cap=B)     # 解释候选
    scores = [nonconformity(th, g_partial, o) for th in cands]
    qhat   = conformal_quantile(calib, 1 - alpha)
    return ordered_set(th for th, s in zip(cands, scores) if s <= qhat)

# IP-266 SCR + IP-267 RCC：安全核 / 公共前缀 / 可逆动作
def safe_core_and_plan(I, s, world):
    common = intersect_tasks(I)                          # T_∩
    core   = [a for a in candidate_prefixes(s, world)
              if all(viable(a, th, s, world) and not violates(a, th, s)
                     for th in I)]                       # V(a)=∅
    a_common = argmax_progress(core, common, s) if common else None
    a_rev    = argmax_option_value([a for a in core if reversible(a, I, s)])
    return core, a_common, a_rev

# IP-268 GDM：三路决策（公共前缀 > 可逆 > 澄清 > 停机）
def gap_decide(I, s, budget):
    core, a_common, a_rev = safe_core_and_plan(I, s, world)
    if a_common is not None:                       return ('act', a_common)
    if a_rev is not None and budget.allow_rev():   return ('defer', a_rev)
    if is_blocking(I, s) and budget.allow_ask():
        return ('ask', compose_question(I, s))     # 下一步判别且不可逆
    return ('halt_or_min_commit', min_commitment(core))

# IP-269 NQC：中性澄清（对称枚举假设，禁止诱导）
def compose_question(I, s):
    q = enumerate_symmetric(I)                         # "A / B / 都不是?"
    if neutrality(q, I) < TAU_NEUTRAL: return None      # 诱导则作废
    return certify_language(q)                          # 冻结解码侧安全过滤

# IP-270 ICM：任务自洽的第三通道（goal drift）
def compliance_residual(xi, I):
    return (sum(w_c * violates_c(xi, th) for th in I for c in th.C)
            + lam_ord  * order_deviation(xi, intersect_tasks(I))
            + lam_goal * (1 - max(success(th, xi) for th in I)))

# IP-276 主闭环（继承 R69；规格层是慢时间尺度，内环不变）
def GAP_RAS_round(M, l, obs):
    # 0) 规格层：解析 + 共形解释集（指令是输入，不是假设）
    gp, gap = M.igp.parse(l, obs)
    I       = M.cis.set(gp, gap, obs)
    if M.ipg.has_injected_text(obs): I = M.ipg.sanitize(I, obs)
    # 1) R69 世界/动作不确定性（在固定解释集上）
    z, U_ale, U_epi, modes = M.fluid.perceive(obs)
    # 2) 规格层决策：公共前缀 / 可逆 / 澄清 / 停机
    route, payload = M.gdm.decide(I, obs.state, M.budget)
    if route == 'ask':
        ans = M.nqc.execute(payload)                   # 中性问句，需认证
        I   = M.cis.update_set(I, ans)                 # 集合收缩，不平均
        route, payload = M.gdm.decide(I, obs.state, M.budget)
    # 3) 执行（限安全核内），叠加 R69 风险缩放
    a   = payload.action if route == 'act' else M.rcc.min_commit(payload, I)
    lam = M.fluid.lam_for(U_ale, U_epi, I)             # 未消解间隙视同风险
    k   = M.c_ras_wm.certified_prefix(a, wm_preds)     # 解释不变安全包络
    # 4) 三通道监控 + 假设账本 + 审计
    r_ins = M.icm.residual(M.last_action, I)
    drift = (r_ins > TAU_INS) and (M.last_r_res < TAU_RES) and (M.last_da < TAU_FMA)
    if drift: I = M.igp.reparse_and_reanchor(l, obs)    # goal drift -> 重锚定
    M.al.record(gap, chosen_assumption(I), deps=k)     # 记录未言明的补全
    M.vqa_s.submit_async(route, I, r_ins, M.al.root_hash)
    return k, a, (I, r_ins), route
```

## 3. 推导

**引理 19（U_spec 与世界知识正交）** 即使给系统完美的世界模型与完美的动作似然（U_ale = U_epi = 0），只要 |𝕀| > 1 且 K(s) ≠ ∅，最优动作仍不唯一，U_spec > 0。证明：构造两条指令在观测上等价、目标却相反（「把杯子放左/放右」），世界完全已知仍无法区分意图。故 U_spec 不能被 R68/R69 的任何观测通道看到，只能由语义通道提供。**这解释了为什么前三轮的安全保证对「做错任务」完全无感。**

**引理 20（安全核非空与公共前缀单调）** 在 A99（共享安全包络、安全等待可达、T_∩ 子目标可独立推进）下：空动作/安全等待 ∈ 𝒞(𝕀,s) 对所有 s 成立；且 T_∩ 上的推进动作若在 𝒞 中，则对所有 θ 均不违规、不排除其后续可行集。系：**GAP-RAS 不会因「想同时满足所有解释」而把自己逼进死角**——交集只会越走越窄，但安全侧永不退化。

**引理 21（可逆性支配澄清）** 若在 s 处存在 𝕀-可逆、非负公共推进的动作 a_rev ∈ 𝒞，则「先执行 a_rev、再按需澄清」的期望总成本 ≤「立即澄清」：因 a_rev 不排除任何 θ、不改变 𝕀（除非附带观测），澄清所需信息在 s' 处仍可获得，而 a_rev 已兑现公共进展并可能省去一次交互。故阻塞未成立或存在可逆推进时，最优策略不澄清。⇒ 把 R69 的「模糊就问」降级为「**不可逆才问**」。

**定理 18（共形覆盖 ⇒ 误执行风险 ≤ α）** 若标定与部署可交换、𝕀_α 覆盖率 ≥ 1−α，且策略只执行安全核 𝒞 内动作（对所有 θ∈𝕀 合规且可行），则 P(执行动作违反真实意图 θ*) ≤ α。证明：θ* ∈ 𝕀 时按定义不违规；仅 θ* ∉ 𝕀（概率 ≤ α）时可能被违反。系：这是**分布无关**的意图安全保证，强于任何学习式意图分类器的点精度；代价是集合可能偏大（保守）。

**定理 19（严格包含 FLUID-RAS 与 CALM-RAS）** 当 |𝕀| = 1（指令唯一解释）时，T_∩ = T、公共前缀即完整任务，GDM 退化为 R69 的动作选择，r_ins 仅作监控；再当 R69 的 VoI(g*) ≤ c(g*)，退化为 R68。且因安全包络解释不变（310-ii）与安全核约束（315），R70 在任意状态的执行风险 ≤ R69 ≤ R68。**安全侧无条件不弱，任务侧新增「做对任务」的保证。** 反向不成立（存在 |𝕀|>1 且 R69 必然做错的状态），故严格包含。

**定理 20（注入隔离的包含界）** 在 IPG 的来源格约束下，未认证文本不能扩张 C_safety 或新增任务节点；设可疑文本检出率 ρ_d，则注入导致越权任务扩张的概率 ≤ (1−ρ_d)·p_bypass，且不改变 310-ii，故安全包络不因注入而扩大。**语言作为输入通道的最坏后果被限制在「任务被误导」，而非「安全被击穿」。**

# IP-264/265 IGP + CIS：弃权解析 -> 共形解释集
def interpretation_set(l, o, parser, calib, alpha, B=32):
    gp     = parser.parse(l, o, allow_abstain=True)       # 只给确定部分
    gap    = enumerate_open_vars(gp)                      # 六类间隙
    cands  = beam_complete(gap, ctx=o, branch_cap=B)
    qhat   = conformal_quantile(calib, 1 - alpha)
    I      = [th for th in cands
              if nonconformity(th, gp, o) <= qhat]        # 覆盖 >= 1-alpha
    return I, gap

# IP-266/267/268 SCR + RCC + GDM：公共前缀 > 可逆 > 澄清 > 停机
def gap_decide(I, s, budget):
    common = intersect_tasks(I)                           # T_∩
    core   = [a for a in candidate_prefixes(s)
              if all(viable(a, th) and not violates(a, th) for th in I)]
    a_com  = argmax_progress(core, common) if common else None
    a_rev  = argmax_option_value([a for a in core if reversible(a, I)])
    if a_com is not None:                    return ('act', a_com)
    if a_rev is not None and budget.rev():   return ('defer', a_rev)
    if is_blocking(I, s) and budget.ask():   return ('ask', compose_question(I))
    return ('halt_or_min_commit', min_commitment(core))   # 绝不猜

# IP-269 NQC：中性澄清（对称枚举，诱导即作废）
def compose_question(I):
    q = enumerate_symmetric(I)                            # "A / B / 都不是?"
    return certify_language(q) if neutrality(q, I) >= TAU_NEUTRAL else None

# IP-270 ICM：任务自洽第三通道
def compliance_residual(xi, I):
    return (sum(w_c*violates_c(xi, th) for th in I for c in th.C)
            + lam_ord*order_deviation(xi, intersect_tasks(I))
            + lam_goal*(1 - max(success(th, xi) for th in I)))

# IP-276 主闭环（双时间尺度；内环沿用 R69 的 2.6ms）
def GAP_RAS_round(M, l, obs):

    if M.ipg.has_injected_text(obs): I = M.ipg.sanitize(I, obs)
    z, U_ale, U_epi, modes = M.fluid.perceive(obs)        # R69 内环

    if route == 'ask':

        route, payload = gap_decide(I, obs.state, M.budget)
    a   = payload.action if route == 'act' else M.rcc.min_commit(payload, I)
    lam = M.fluid.lam_for(U_ale, U_epi, I)               # 未消解间隙视同风险

    r_ins = M.icm.residual(M.last_action, I)

    if drift: I = M.igp.reparse_and_reanchor(l, obs)      # goal drift -> 重锚定
    M.al.record(gap, chosen_assumption(I), deps=k)
    M.vqa_s.submit_async(route, I, r_ins, M.al.root_hash)

## 4. 推导

**引理 19（U_spec 与世界知识正交）** 即使 U_ale=U_epi=0，只要 |𝕀|>1 且 K(s)≠∅，最优动作仍不唯一，U_spec>0。构造：「把杯子放左/放右」在观测上等价、目标相反，世界全知亦不可分。故 R68/R69 的观测通道对「做错任务」完全无感——这正是前三轮的研究空白。

**引理 20（安全核非空与公共前缀单调）** A99（共享安全包络、安全等待可达、T_∩ 可独立推进）下，安全等待 ∈ 𝒞；T_∩ 上的推进动作若在 𝒞 内，则对所有解释不违规、不排除后续。系：不会因「同时满足所有解释」而进死角，安全侧永不退化。

**引理 21（可逆性支配澄清）** 若存在 𝕀-可逆、非负公共推进的 `a_rev∈𝒞`，则「先做再按需问」期望成本 ≤「立即问」：a_rev 不排除任何解释、不改变 𝕀，澄清信息在 s' 仍可得，且可能省一次交互。⇒ 把「模糊就问」降为「**不可逆才问**」。

**定理 18（共形覆盖 ⇒ 误执行风险 ≤ α）** 标定-部署可交换、`𝕀_α` 覆盖 ≥1−α、只执行安全核内动作 ⇒ `P(执行违反真实意图 θ*) ≤ α`。系：分布无关的意图安全保证，强于任何学习式意图分类器的点精度（代价是集合偏保守）。

**定理 19（严格包含）** `|𝕀|=1` 时 T_∩=T、公共前缀即完整任务，GDM 退化 R69，r_ins 仅监控；再叠加 `VoI≤成本` 退化 R68。由 310-ii 与 315，任意状态风险 R70 ≤ R69 ≤ R68（安全侧无条件不弱，任务侧新增正确性）。反向不成立 ⇒ 严格包含。

**定理 20（注入隔离的包含界）** 来源格下未认证文本不能扩张 C_safety 或新增任务节点；检出率 ρ_d 时越权扩张概率 ≤ `(1−ρ_d)·p_bypass`，310-ii 不变。语言输入的最坏后果被限在「任务被误导」而非「安全被击穿」。

## 7. 本轮最大风险

**一句话**：GAP-RAS 的全部安全保证建立在「真实意图落在共形解释集 𝕀_α 内」这一可交换性前提上——**一旦部署分布漂移、出现没见过的指令类型（unknown unknowns），θ* 会静默落在 𝕀 之外，系统仍会在一个「自证安全」的集合内执行完全错误的任务：它不是失败得危险，而是「安全地、带证书地做错事」，账本与证书反而给人类虚假的严谨感、压制应有的监督**（研究空白的反噬：你以为补上的那个空白，恰在定义域之外）。

**次级风险与缓解**：过度澄清/交互疲劳（可逆性支配 + 公共前缀 + 预算硬约束）；中性问句泄露先验/诱导（对称枚举 + 中性度门控 + 多源一致）；解析器过度自信藏起间隙（强制弃权正则 + E301）；组合指令解释集爆炸（分支上限 B + 等价类合并 + 尺寸惩罚）；注入绕过/账本篡改（来源格 + 隔离 + 根哈希 + E308）；假设陈旧（账本版本化 + 指令修订触发全量重认证 + E316）。
