# 第 69 轮（承接第 68 轮「CALM-RAS 自标定·自监督·单模型多任务」IP-243~252；灵感循环新循环第 1 轮；本轮灵感：「数据规模」×「指标体系」）

> R68 用在线标定把「测量可信度」纳入闭环，但其自陈风险是一个**认识论**缺口而非算法缺口：缓变故障落入标定带宽后，系统会在「测量越来越准」的假象中失去检出能力。更深的元问题是——R65–R68 的所有安全性数字（误报 −40%、长尾 +15%、拦截 99%、残余 ≥ 2/3）都是**断言的点估计**：没有置信区间、没有有效样本量、没有「这个结论需要多大规模、什么分布的数据才成立」的说明。R68 的风险本质不是方差不够，而是**数据覆盖偏差（bias）伪装成了方差问题（variance）**——「数据里根本没有缓变故障」，再多的同类数据也修不好。
>
> 本轮两个灵感恰好是同一枚硬币的两面：**数据规模**回答「不确定性如何随（有效）样本收缩」；**指标体系**回答「到底该测什么、测的构造对不对」。合流命题：
>
> **把安全性从「点估计断言」升级为「带规模律的分层证书」：用指标格（Safety Metric Lattice）把每个安全主张拆成可证伪的测量节点，用有效样本量代数给出置信上界，用「偏差底 + 规模项 + 漂移项」三分解判定该加数据、该改指标还是该缩运行域，并把数据预算主动分配给当前最约束证书的那一格——SCOPE-RAS（Scale-aware Certification with Outcome-validated Proof Envelopes）。**
>
> 一句话定位：R66 问「谁控制」、R67 问「未来怎样」、R68 问「测量还准吗」，R69 问「**你凭什么相信你测出来的那个数**」——证书只在数据支撑的操作域内有效，域外一律拒绝运行。

## 0. 直觉与动机

**灵感 1（数据规模 → 安全是尾部量，尾部量由「覆盖」决定，不由「数量」决定）**
直觉：安全指标几乎都是尾部量（罕见故障、极端情绪、长尾场景）。i.i.d. 情形下估计误差按 N^{−β} 收缩，但这条定律有两个隐藏前提：样本独立、且支撑集覆盖目标区域。真实闭环的数据高度自相关（同一场景连续帧）、高度重复（同一条演示被回放）、并混入仿真数据（名义规模大、真实尾部覆盖低）。于是 N 会涨，有效样本量 N_eff 却不涨：**规模通胀（scale inflation）**。更致命的是，若某个尾部格子的数据质量为零，则该格上的检出率**不可识别**——任何点估计都不可证伪。数据规模的第一性原理不是「加数据」，而是「先问 N_eff 和覆盖，再谈加数据」。

**灵感 2（指标体系 → 单一 accuracy 是坏指标，指标必须分层、可组合、抗 Goodhart）**
直觉：R65–R68 混用了 KL 散度、检出率、λ_risk、残余比等异质代理量，它们量纲不同、不可比较、不能沿闭环传播，而且都能被优化压力「玩坏」（Goodhart 定律：一个指标被优化得足够狠，就不再衡量它本来要衡量的东西）。正确做法是把安全主张组织成一张**指标格**：可观测量 → 代理指标 → 因果目标量 → 安全泛函，每条边都显式标注有效性假设与该边引入的偏差上界。指标只有在**干预检验**（注入已知严重度的故障，看它是否单调响应）通过后，才配被当作优化目标；否则只能作诊断。指标格让「这一轮改进了多少」第一次变成可累积、可审计的断言。

**灵感 3（合流 → 证书误差 = 偏差底 + 规模项 + 漂移项，绑定项决定行动）**
直觉：任何指标 v 的证书误差可写成三项：`B_v`（偏差底，来自指标构造效度与覆盖缺口，**与 N 无关**）、`C_v·N_eff^{−β_v}`（规模项，可加数据消除）、`Δ_shift`（分布漂移项，来自部署分布偏离标定分布）。三者中最大的那项叫**绑定项**：方差受限 → 收集更多（定向）数据；偏差受限 → 改指标 / 补干预式尾部数据；漂移受限 → 重标定 / 收缩运行域。这把「继续做研究」从口号变成一个**可判定的决策问题**。关键推论：一旦偏差底高于可接受阈值，**存在一个有限的 N\*，超过之后任何 i.i.d. 数据都毫无价值**——R68 的缓变故障正是这种情形。

**灵感 4（对 R68 风险对症 → 频域覆盖图 + 干预式尾部采集）**
直觉：R68 的「缓变故障被标定吸收」翻译成指标语言就是：故障空间按频率分层后，慢故障带 `Ω_blind = {ω_f ≤ ω_cal, severity ≥ τ_det}` 的数据覆盖为零，而系统用「总体检出率」这个把盲带平均掉的指标给自己发了合格证。修法不是「多采数据」，而是（i）新增**频域分辨率检出率**指标，使盲带无法被平均；（ii）用**干预式尾部采集**（主动注入慢故障）把覆盖补上；（iii）在覆盖补上之前，证书直接对该带判「不可识别」，运行域收缩（k=0 或强降级）。这正好把 R68 的原罪变成 R69 可测量、可审计、可强制修补的对象。

**灵感 5（反 Goodhart → 指标级 canary 与因果干预验证）**
直觉：R68 已经有「策略级 canary」（注入真故障、禁止标定把它修好）。R69 把它抬到指标层：每个指标都要过**指标级 canary**——注入已知严重度的故障，指标必须按预期方向与幅度响应；如果某个候选策略让代理指标变好、而干预目标量没变好，就判 `δ_G`（Goodhart 间隙）超标，该指标被降级为诊断量，禁止进入优化目标。这防止「优化证书半径本身」变成新的作弊通道。

**灵感 6（本轮七组件 + 继承核）**
1. **SML Safety Metric Lattice**：把安全主张展开成偏序指标格，每节点带估计量/目标量/假设/偏差上界；
2. **ESSA Effective Sample Size Algebra**：把自相关、重复、分层覆盖、仿真血统折进 N_eff；
3. **SCL Scaling Certificate Law**：拟合规模律指数 β，产出 UCB 与预注册外推检验；
4. **CIV Causal Intervention Validation**：干预单调性 / 幅度 / 特异性三检验，配指标级 canary；
5. **DBA Data Budget Allocator**：按「降低证书半径 / 单位成本」的次模贪心分配数据预算；
6. **FCM + TTA Frequency-Coverage Map & Tail-Targeted Acquisition**：频域—严重度—模态三维覆盖图，对盲带做干预式采集；
7. **SOC Staged Operating Certificate**：分层运行域 T0/T1/T2，绑定项决定档位，档位单调映射到 (k, λ_floor)；
8. **RAS-WM‡ 继承核**：R68 的 CALM-RAS 全保留，只是所有阈值/证书改为证书驱动，且 λ_floor 增加「指标不可识别」触发项。

## 1. 形式化定义（增量：定义 293–308）

**定义 293（SCOPE-RAS 总览与三不变式）** SCOPE-RAS = (SML, ESSA, SCL, CIV, DBA, FCM, TTA, SOC, RAS-WM‡)。三不变式：
(i) **证书域不变式**：系统只声明被数据支撑的操作域 𝒪；任何 x ∉ 𝒪 一律拒绝（k=0），绝不用点估计外推；
(ii) **可优化性不变式**：只有通过 CIV 干预单调性检验的指标才可进入优化目标；未通过者只作诊断，禁止参与安全裁决；
(iii) **UCB 不变式**：一切安全裁决只用置信上界 UCB，点估计不得直接决定放行。

**定义 294（安全指标格 SML）** SML = (𝒱, ℰ, ⪯)。节点 v = (M_v, θ_v, A_v, B_v)：估计量 M_v、目标量 θ_v、有效性假设 A_v、偏差上界 B_v。边 (u→v) ∈ ℰ 表示「u 可支撑 v」，并携带该边的构造效度假设与偏差传递项。⪯ 是「更接近可观测量」的偏序。每个顶层安全主张 s（如「τ_cmd 偏离 τ* 概率 ≤ ε」）对应一个子格 𝒱_s；接受 s ⇔ 该子格每条关键路径上都有 UCB_v(δ) < τ_v。**指标格是「安全主张的可证伪化展开」**。

**定义 295（有效样本量代数 ESSA）** 对指标 v，其相关层（尾部格子/工况）上的有效样本量
`N_eff(v) = N_v · κ_cov(v) · ℓ(v) / (1 + 2Σ_{k=1}^{K_v} ρ_k(v))`，
其中 κ_cov(v) ∈ [0,1] 是该层数据覆盖比例（占目标质量），ℓ(v) ∈ (0,1] 是血统折扣（仿真/合成数据按真实覆盖折算，定义 307），ρ_k 是滞后 k 自相关。**N 是名义规模，N_eff 才是统计规模**；二者可相差数量级。

**定义 296（指标证书界 SCL：偏差—规模—漂移三分解）** 在置信水平 1−δ_v 下
`|R̂_v − R_v| ≤ B_v + C_v·N_eff(v)^{−β_v} + Δ_shift(v)`。
记 `UCB_v(δ) = R̂_v + B_v + C_v·N_eff(v)^{−β_v} + Δ_shift(v)`（δ 常数折入 C_v）。三项语义：B_v 偏差底（构造效度 + 覆盖缺口，**规模不可约**）；规模项（加数据可压）；Δ_shift 漂移项（部署分布偏移，靠重标定/缩域压）。证书有效 ⇔ UCB ≤ τ_v。

**定义 297（规模律指数与预注册外推）** 在规模阶梯 N ∈ {10³, 10⁴, 10⁵, 10⁶, 10⁷} 上测 ε_v(N) = |R̂_v − R_v^proxy|，拟合 `log ε_v = a_v − β_v log N`。证书须**预注册**外推到目标规模 N_target 的误差带，并在留出的更大规模上做外推检验（E286）；外推失败即判 SCL 失效、证书降档。

**定义 298（证书半径与约束指标）** `ρ_cert = max_{v∈𝒱_crit} UCB_v/τ_v`；`v* = argmax_v UCB_v/τ_v` 为**约束指标**。证书有效 ⇔ ρ_cert ≤ 1。ρ_cert 是「最不可信的那一项」的归一化松弛，而非平均——**一个指标不可信，整张证书不可信**（这正是对 R68「盲带被平均值掩盖」的结构性修正）。

**定义 299（数据预算分配 DBA）** 预算 B_data，每个采集动作 a 的边际收益 `Δρ(a) = −max_v ∂ρ_cert/∂N_eff(v) · ∂N_eff(v)/∂n_a`，成本 c_a。分配规则：
- 若 v* 为**方差受限**（B_{v*} + Δ_shift < τ_{v*} − R̂_{v*}）：向最大化 Δρ(a)/c_a 的格子投放（次模贪心，引理 18）；
- 若 v* 为**偏差受限**：停止加 i.i.d. 数据，转 TTA（定义 304）或指标重设计；
- 若 v* 为**漂移受限**：触发重标定 / 收缩运行域（SOC），而非采数据。

**定义 300（频域覆盖图 FCM 与盲带）** 故障空间 ℱ = (severity s, frequency ω_f, modality m)，划成格子 C_j。覆盖 `κ_j = mass(D ∩ C_j)/mass*(C_j)`，缺口 `d_j = max(0, 1 − κ_j)`。**慢故障盲带** `Ω_blind = {ω_f ≤ ω_cal} ∩ {s ≥ τ_det}`。R68 的风险在此定义为 `d(Ω_blind) > 0`：该格检出率不可识别（引理 19），任何「总体检出率」都会把它平均掉。

**定义 301（因果干预验证 CIV）** 对指标 v 的干预族 `{do(s)}`（注入已知严重度 s 的真故障，含慢故障与跨模态故障），要求：
(i) **单调性**：s₁ < s₂ ⇒ M_v(do(s₁)) ⪯ M_v(do(s₂))（风险类指标方向取反）；
(ii) **幅度校准**：|M_v(do(s)) − θ_v(s)| ≤ B_v；
(iii) **特异性**：对与 v 无关的干预不产生显著响应。
裁决 ∈ {PASS, DIAGNOSTIC, FAIL}；FAIL 的指标从 𝒱_crit 移除，并记入 ℰ_scope。

**定义 302（Goodhart 间隙与反作弊）** 令 `π*_v = argmin_π M_v(π)`（代理最优策略）、`π* = argmin_π R_true(π)`。`δ_G(v) = R_true(π*_v) − R_true(π*)`。CIV 用干预数据给出 δ_G 的可识别上界 `δ̂_G`；若 δ̂_G > ε_G，则 v 只能作诊断，不得作优化目标。副产物：若优化使 M_v 改善而干预目标量未改善，判为 **Goodhart 事件**。

**定义 303（指标级 canary）** 在影子评估中周期性注入已知严重度的「指标 canary」：指标必须按 CIV 预期响应；若指标对注入无响应（或响应方向错），该指标立即失效并触发重标定。这是 R68 策略级 canary 在指标层的对偶。

**定义 304（尾部定向采集 TTA）** 采集动作 a ∈ {仿真放大、真机探测、主动故障注入、跨模态重放}，目标函数
`max_a [ λ_cov·Σ_j d_j·1[a∈C_j] + λ_cert·Δρ(a)/c_a ]`，
覆盖增益对格子集合次模，故贪心 (1−1/e) 近似（引理 18）。TTA 与「被动加数据」的区别：它只买**能降低绑定 UCB 的覆盖**，包括直接注入慢故障。

**定义 305（分层运行证书 SOC）** 运行域分层：T0 = {x : ρ_cert(x) ≤ 1}（全功能）；T1 = {1 < ρ_cert ≤ ρ₁ 或 v* 偏差受限}（受限：k 收缩、λ_floor ≥ 0.8）；T2 = {ρ_cert > ρ₁ 或 v* 不可识别}（安全停机 k=0）。映射 `tier(x) ↦ (k, λ_floor)` 对 tier 单调不增（不确定性只收紧，见定理 19）。T1/T2 是「证书域」而非「性能域」，避免证书收紧导致整机瘫痪。

**定义 306（MCR 指标证书记录）** 每指标一条：`MCR_v = (M_v, κ_cov, N_eff, β_v, B_v, C_v, Δ_shift, UCB_v, CIV_verdict, δ̂_G, lineage_hash, refresh_t, scope)`。全量 MCR 集合构成证书哈希，进入 J_SCOPE（定义 308）。**指标本身也被版本化、被审计、可回滚**。

**定义 307（数据血统与规模通胀校验 DLV）** 名义规模 N 与实际统计规模解耦：去重（嵌入近邻）、自相关（时间序列）、仿真血统折扣 `ℓ_sim = κ_cov^real/κ_cov^sim|` 同层 `∈ (0,1]`。`N_eff ≤ N`，且 `N_eff/N` 是**规模通胀比**；若某轮「数据翻倍」但 N_eff/N 下降，判为规模通胀（E288），不得据此放宽任何阈值。

**定义 308（J_SCOPE 合成证书与管线）** `J_SCOPE = (J_CALM, MCR_set_hash, ρ_cert, tier, v*, scale_law_fit, civ_audit, lineage_hash)`；Valid ⇔ Valid(J_CALM) ∧ ρ_cert ≤ 1 ∧ 所有关键指标 CIV ≠ FAIL ∧ 规模律外推检验通过。离线证书循环：建格 → CIV → 测 N_eff → 拟合规模律 → 算 UCB/ρ_cert → 分配预算/TTA/改指标 → 出 SOC+MCR。实时流仍只跑 R68 的 2.6ms 环路，SOC 只提供 `tier ↦ (k, λ_floor)` 两个标量。

## 2. 关键算法骨架

```python
# IP-253 SML：把安全主张展开成指标格
class SafetyMetricLattice:
    def critical_paths(self, claim):
        return paths(self.graph, src=self.observables, dst=claim)  # 每节点带 (M,theta,A,B)

    def accept(self, claim, alpha=0.05):
        # 不是平均，而是最差节点：一个指标不可信 => 整张证书不可信
        return all(self.ucb(v, alpha) < self.tau[v]
                   for p in self.critical_paths(claim) for v in p)


# IP-254 ESSA：名义规模 -> 有效规模
def effective_n(N, kappa_cov, lineage, autocorr):
    rho_sum = sum(autocorr[k] for k in range(1, len(autocorr)))
    return N * kappa_cov * lineage / (1 + 2*rho_sum)


# IP-255/256 SCL + CIV：带规模律的证书界 + 干预检验
class ScalingCertificate:
    def fit(self, ladder):                       # {N_i, eps_i}
        self.beta, self.C = fit_power_law(ladder) # eps ~ C*N^-beta
        self.extrap_err = self.backtest(ladder)

    def ucb(self, v, delta):
        n_eff = effective_n(v.N, v.kappa_cov, v.lineage, v.autocorr)
        return (v.R_hat + v.B + v.C*n_eff**(-v.beta) + v.delta_shift
                + delta_constant(delta)*n_eff**-0.5)

def causal_intervention_validate(metric, do_family, B):
    resp = [metric(do(s)) for s in do_family]
    mono = all(resp[i] <= resp[i+1] for i in range(len(resp)-1))   # 风险类取反
    caliber = all(abs(metric(do(s)) - target(s)) <= B for s in do_family)
    spec = specificity_test(metric, irrelevant_interventions)
    if not (mono and caliber and spec): return 'FAIL'
    return 'PASS'


# IP-257/258 DBA + TTA：约束指标导向的数据预算
def allocate_budget(sml, budget, fcm):
    v_star = sml.binding_metric()
    if bias_limited(v_star):   return tail_targeted_acquisition(fcm, v_star)
    if shift_limited(v_star):  return request_recalibration(v_star)
    alloc = {}
    while budget > 0:
        a = argmax(cell_actions(fcm),
                   key=lambda a: marginal_cert_gain(a, v_star)/cost(a))
        if marginal_cert_gain(a, v_star) <= 0: break
        alloc[a] = alloc.get(a, 0) + 1; budget -= cost(a)
    return alloc


# IP-259/261 FCM + DLV：频域覆盖与规模通胀校验
def coverage_map(data, fault_grid):
    return {cell: observed_mass(data, cell)/required_mass(cell)
            for cell in fault_grid}

def scale_inflation_ratio(N, N_eff):
    return N_eff / N        # 若「加数据」却比值下降 => 规模通胀，禁止放宽阈值


# IP-262 SOC：证书域 -> 实时动作
def operating_tier(rho_cert, v_star, identifiable):
    if not identifiable or rho_cert > RHO_1: return 'T2'   # k=0 安全停机
    if rho_cert > 1:                         return 'T1'   # k 收缩, λ>=0.8
    return 'T0'


# IP-264 主闭环：证书循环（离线/慢环） + R68 实时环
def SCOPE_round(M, claim):
    sml  = M.sml.expand(claim)                       # 1) 建格
    civ  = {v: causal_intervention_validate(v.M, v.do_family, v.B) for v in sml}
    for v in sml:
        v.N_eff = effective_n(v.N, v.kappa_cov, v.lineage, v.autocorr)  # 2) N_eff
    sc   = ScalingCertificate().fit(M.scaling_ladder) # 3) 规模律
    feasible = {v for v in sml if civ[v] != 'FAIL'}
    rho  = max(sc.ucb(v) / v.tau for v in feasible)   # 4) 证书半径
    v_star = max(feasible, key=lambda v: sc.ucb(v)/v.tau)
    if bias_limited(v_star):      plan = TTA(M.fcm, v_star)          # 5) 决策
    elif shift_limited(v_star):   plan = recalibrate(v_star)
    else:                         plan = allocate_budget(sml, M.budget, M.fcm)
    tier = operating_tier(rho, v_star, identifiable(v_star, M.fcm))  # 6) 分层证书
    issue_mcr(sml, sc, civ); return J_SCOPE(...), tier, plan
```

## 3. 推导

**引理 16（规模通胀界）** 设数据存在重复率 d 与滞后自相关 ρ，则 `N_eff/N ≤ (1−d)·ℓ / (1+2Σρ_k)`。系：当 d 或 ρ 上升时，「名义数据翻倍」可对应 N_eff 下降；任何用 N 而非 N_eff 计算的 UCB 都会**过紧**，形成系统性过度自信。这正是把「数据规模」直接当安全论据的错误来源。

**引理 17（偏差底不可由规模消除——N\* 存在性）** 若 `B_v + Δ_shift ≥ τ_v − R̂_v`，则对任意 N 有 `UCB_v(N) ≥ B_v + Δ_shift > τ_v`：**不存在有限 i.i.d. 样本使证书通过**。即使 `B_v < τ_v − R̂_v`，也有 `N*_v = [C_v/(τ_v − R̂_v − B_v − Δ_shift)]^{1/β_v}`，超过 N\* 的 i.i.d. 数据对证书半径的边际收益为 0。系：R68 的缓变故障盲带满足 B ≫ 0，故「多采同类数据」是可证明的浪费，必须转向 TTA/改指标。

**引理 18（分配次模性）** 证书半径下降量 `Δρ(S)` 关于采集格子集合 S 单调次模（覆盖增益次模 + ρ_cert 是 max 型凹泛函的复合）；故 DBA 的贪心分配达到最优的 `(1−1/e)` 近似。系：预算有限时，**按约束指标分配**（`v*` 导向）严格优于均匀分配到所有指标。

**引理 19（零覆盖不可识别）** 若 `κ(Ω_blind)=0`，则盲带上的检出率在观测数据分布下不可识别：任何 `R̂ ∈ [0,1]` 都与数据一致（似然平坦）。系：R68 的「总体检出率 90%」不能对盲带作任何声明；「盲带被平均值掩盖」不是估计噪声，而是**结构性无信息**。这是本轮把 R68 风险形式化的核心。

**定理 16（证书可靠性）** 在 A95–A100 下，UCB 集合以概率 ≥ 1−Σδ_v 同时覆盖各自真值；因此 `Valid(J_SCOPE) ⇒ P(R_true ≤ τ for all critical v) ≥ 1−δ_total`，且 `x ∈ 𝒪(T0) ⇒ 该 x 上安全泛函 ≤ τ`。**证书是「数据支撑的保证」，不是「算法声称的性能」**。

**定理 17（规模—偏差相变）** 证书误差随 N 分段：N < N\* 时规模受限、加（定向）数据有效；N ≥ N\* 时进入偏差受限平台，i.i.d. 数据零收益，只有 TTA（补覆盖）或指标重设计（降 B_v）能降低 ρ_cert。相变点 N\* 可由规模律与 B_v 估计，从而**事前**判断「该不该继续采数据」。

**定理 18（Goodhart 界）** 若指标 v 的 Goodhart 间隙真值为 δ_G(v)，则任何以 M_v 为唯一目标、未过 CIV 的优化，其真实风险改善 ≤ δ_G(v)；CIV + 指标级 canary 给出 `δ̂_G`，当 `δ̂_G > ε_G` 时把 v 降为诊断可将最坏真实风险改善限制在 ε_G。系：**「优化证书半径」本身也必须过 CIV**，否则证书优化会退化为新一轮 Goodhart。

**定理 19（分层证书单调性）** SOC 的映射 `tier ↦ (k, λ_floor)` 满足：tier 越保守（T0→T1→T2），k 越小、λ_floor 越大；且 ρ_cert 上升不会使任何阈值放宽。故「测量/统计不可信」与 R68 的「标定不可信」共享同一条纪律：**不确定性只导向收紧**。合成：`λ_floor = max(0.6, 0.8·1[U > τ_cal ∨ ρ_cert > 1 ∨ v* 不可识别])`。

## 6. 本轮最大风险

**一句话**：整个 SCOPE-RAS 把安全性押在「偏差底 B_v 与漂移项 Δ_shift 的估计是可信的」这一前置上——但 B_v 本身来自指标构造效度与覆盖审计，Δ_shift 来自对部署分布的假设，二者一旦被低估（尤其仿真血统折扣 ℓ_sim 高估、未建模的分布漂移、指标格某条边悄悄失效），系统会得到一张**「置信度很高但系统性错误」的证书**：这不是 R68 那种「假象下的失明」，而是把失明封装进了一个带 UCB 的、看起来最严谨的证书里，且 `max` 型证书半径还允许用「放宽某个最难测指标的 B_v」来换取整体放行——**计量塔建在未计量的地基上，越严谨越危险**。

**次级风险与缓解**：证书瘫痪（最差指标一票否决 → SOC 分层 + 受限运行而非停机）；元层 Goodhart（优化 ρ_cert 本身 → ρ_cert 也纳入 CIV + 指标级 canary + 随机化审计）；规模律外推失效（预注册外推检验 + 留出更大规模实测）；数据采集成本（DBA 显式成本约束 + TTA 只买覆盖）；指标格组合爆炸（只展开关键路径 + 剪枝低影响节点）。

## 2. 形式化定义（要点版）

**定义 293（总览与三不变式）** 证书域不变式（域外 k=0，绝不用点估计外推）；可优化性不变式（只有过 CIV 的指标可进优化目标）；UCB 不变式（只用上界裁决）。

**定义 294（SML）** 节点 `(M_v, θ_v, A_v, B_v)`，边携带构造效度假设与偏差传递；安全主张接受 ⇔ 关键路径上所有 `UCB_v < τ_v`。**最差节点决定整张证书**。

**定义 295（ESSA）** `N_eff = N·κ_cov·ℓ/(1+2Σρ_k)`；N 是买的，N_eff 才是用的。

**定义 296（SCL 三分解）** `|R̂−R| ≤ B + C·N_eff^{−β} + Δ_shift`（1−δ）。偏差底规模不可约；漂移项靠重标定/缩域；规模项加数据可压。

**定义 297（规模律与预注册外推）** 5 点规模阶梯拟合 β；对目标规模外推并留出更大规模检验；外推失败即降档。

**定义 298（证书半径与约束指标）** `ρ_cert = max_v UCB_v/τ_v`，`v* = argmax`；有效 ⇔ ρ_cert ≤ 1。用 max 而非平均，结构性防止 R68 的「盲带被平均掩盖」。

**定义 299（DBA）** 方差受限 → 按 `Δρ/c` 次模贪心投放；偏差受限 → 停采转 TTA/重设计；漂移受限 → 重标定/缩域。

**定义 300（FCM 与盲带）** 故障空间 `(s, ω_f, m)` 覆盖图；`Ω_blind` 覆盖为零即不可识别（引理 19）。

**定义 301（CIV）** do-干预三检验：单调性、幅度校准、特异性；裁决 PASS/DIAGNOSTIC/FAIL。

**定义 302（Goodhart 间隙）** `δ_G(v)=R_true(π*_v)−R_true(π*)`，CIV 给可识别上界；超标则只作诊断。指标 canary（定义 303）周期性注入验证。

**定义 304（TTA）** 只在能降绑定 UCB 的格子采集（含主动注入慢故障）；覆盖增益次模 → 贪心 (1−1/e)。

**定义 305（SOC）** T0（ρ_cert≤1）/ T1（1<ρ≤ρ₁ 或偏差受限：k 收缩、λ≥0.8）/ T2（ρ>ρ₁ 或不可识别：k=0）；映射对 tier 单调收缩。

**定义 306–308（MCR / DLV / J_SCOPE）** 指标级可版本化证书；名义 N 与 N_eff 解耦并设规模通胀闸门；J_SCOPE 需 Valid(J_CALM) ∧ ρ_cert≤1 ∧ CIV≠FAIL ∧ 外推检验通过。

## 3. 关键算法伪代码

```python
# IP-253 SML：安全主张 -> 指标格；最差节点决定接受
class SafetyMetricLattice:
    def accept(self, claim, alpha=0.05):
        return all(self.ucb(v, alpha) < self.tau[v]
                   for p in self.critical_paths(claim) for v in p)

# IP-254 ESSA：名义规模 -> 有效规模（自相关/重复/覆盖/血统）
def effective_n(N, kappa_cov, lineage, autocorr):
    return N * kappa_cov * lineage / (1 + 2*sum(autocorr[1:]))

# IP-255/256 SCL + CIV
class ScalingCertificate:
    def fit(self, ladder):                         # {N_i, eps_i}
        self.beta, self.C = fit_power_law(ladder)  # eps ~ C*N^-beta
        self.extrap_err  = self.backtest(ladder)   # 预注册外推检验
    def ucb(self, v, delta):
        n_eff = effective_n(v.N, v.kappa_cov, v.lineage, v.autocorr)
        return v.R_hat + v.B + v.C*n_eff**(-v.beta) + v.delta_shift \
               + delta_const(delta)*n_eff**-0.5

def causal_intervention_validate(metric, do_family, B):
    resp = [metric(do(s)) for s in do_family]
    mono    = all(resp[i] <= resp[i+1] for i in range(len(resp)-1))  # 风险类取反
    caliber = all(abs(metric(do(s)) - target(s)) <= B for s in do_family)
    spec    = specificity_test(metric, IRRELEVANT_DO)
    return 'PASS' if (mono and caliber and spec) else 'FAIL'

# IP-257/258 DBA + TTA：约束指标导向的预算
def allocate_budget(sml, budget, fcm):
    v_star = sml.binding_metric()
    if bias_limited(v_star):  return tail_targeted_acquisition(fcm, v_star)
    if shift_limited(v_star): return request_recalibration(v_star)
    alloc = {}
    while budget > 0:
        a = max(cell_actions(fcm), key=lambda a: marginal_gain(a, v_star)/cost(a))
        if marginal_gain(a, v_star) <= 0: break
        alloc[a] = alloc.get(a, 0) + 1; budget -= cost(a)
    return alloc

# IP-259/261 FCM + DLV
def coverage_map(data, fault_grid):
    return {c: observed_mass(data, c)/required_mass(c) for c in fault_grid}

def scale_inflation_ratio(N, N_eff):
    return N_eff / N          # 「加数据」却比值下降 => 规模通胀，禁止放宽阈值

# IP-262 SOC：证书域 -> 实时动作（两个标量）
def operating_tier(rho_cert, v_star, identifiable, RHO_1=1.5):
    if (not identifiable) or rho_cert > RHO_1: return 'T2'   # k=0
    if rho_cert > 1:                          return 'T1'   # k 收缩, λ>=0.8
    return 'T0'

# IP-264 主闭环：证书慢环 + 继承 R68 实时环
def SCOPE_round(M, claim):
    sml = M.sml.expand(claim)                                  # 1) 建格
    civ = {v: causal_intervention_validate(v.M, v.do_family, v.B) for v in sml}
    for v in sml:
        v.N_eff = effective_n(v.N, v.kappa_cov, v.lineage, v.autocorr)  # 2) N_eff
    sc  = ScalingCertificate().fit(M.scaling_ladder)          # 3) 规模律
    feas = {v for v in sml if civ[v] != 'FAIL'}
    rho  = max(sc.ucb(v)/v.tau for v in feas)                  # 4) 证书半径
    v_star = max(feas, key=lambda v: sc.ucb(v)/v.tau)
    if bias_limited(v_star):    plan = TTA(M.fcm, v_star)      # 5) 决策
    elif shift_limited(v_star): plan = recalibrate(v_star)
    else:                       plan = allocate_budget(sml, M.budget, M.fcm)
    tier = operating_tier(rho, v_star, identifiable(v_star, M.fcm))  # 6) SOC
    issue_mcr(sml, sc, civ)
    jam = M.calm_ras_round(M, M.obs)                           # 7) R68 实时环（不变）
    k = min(jam.k, K_BY_TIER[tier]); lam = max(jam.lam, LAM_BY_TIER[tier])
    return J_SCOPE(M, sml, sc, rho, tier, v_star, plan), tier, k, lam
```

## 4. 推导

**引理 16（规模通胀界）** 重复率 d、滞后自相关 ρ 下 `N_eff/N ≤ (1−d)·ℓ/(1+2Σρ_k)`。用 N 而非 N_eff 计算的 UCB 系统性过紧 → 过度自信。**数据规模必须换成统计规模才可作安全论据。**

**引理 17（偏差底不可约与 N\*）** 若 `B + Δ_shift ≥ τ − R̂`，任意 N 都无法使证书通过；否则 `N* = [C/(τ − R̂ − B − Δ_shift)]^{1/β}`，超过后 i.i.d. 数据对 ρ_cert 的边际收益为 0。R68 盲带满足 B ≫ 0 ⇒ 加同类数据可证明浪费。

**引理 18（分配次模性）** 证书半径下降量对采集格子集合单调次模（覆盖次模 + max 型凹泛函复合）⇒ 贪心 (1−1/e)。按约束指标分配严格优于均匀分配。

**引理 19（零覆盖不可识别）** `κ(Ω_blind)=0` ⇒ 盲带检出率在数据分布下不可识别（似然平坦，任意 R̂∈[0,1] 都一致）。R68「总体检出率 90%」对盲带零信息——这是结构性无信息，不是估计噪声。

**定理 16（证书可靠性）** A95–A100 下 UCB 联合覆盖真值（概率 ≥ 1−Σδ_v）；`Valid(J_SCOPE) ⇒ P(∀ v∈𝒱_crit, R_v ≤ τ_v) ≥ 1−δ_total`；`x∈𝒪(T0) ⇒ 该 x 上安全泛函 ≤ τ`。

**定理 17（规模—偏差相变）** 证书误差分段：N<N\* 规模受限、定向采集有效；N≥N\* 进入偏差平台，i.i.d. 数据零收益，只有 TTA（补覆盖）或指标重设计（降 B）能降 ρ_cert。N\* 可事前估计 ⇒ 「该不该继续采数据」成为可判定问题。

**定理 18（Goodhart 界）** 未过 CIV 的代理优化，真实风险改善 ≤ δ_G(v)；CIV + 指标 canary 给出 `δ̂_G`，`δ̂_G>ε_G` 时降为诊断可把最坏真实改善限制在 ε_G。**「优化 ρ_cert」本身也必须过 CIV**，否则证书优化退化为元层 Goodhart。

**定理 19（分层证书单调性）** `tier↦(k,λ_floor)` 满足 T0→T1→T2 时 k 不增、λ_floor 不减；ρ_cert 上升不放宽任何阈值。统一纪律 `λ_floor = max(0.6, 0.8·1[U>τ_cal ∨ ρ_cert>1 ∨ v* 不可识别])`：R68 的「标定不可信」与 R69 的「统计不可信」共享同一条只收紧通道。

## 7. 本轮最大风险

**一句话**：SCOPE-RAS 把安全性押在「偏差底 B_v 与漂移项 Δ_shift 的估计可信」这一前置上——但 B_v 来自指标构造效度与覆盖审计、Δ_shift 来自对部署分布的假设，二者一旦被低估（仿真血统折扣 ℓ_sim 高估、未建模漂移、指标格某条边悄悄失效），系统会得到一张**「置信度很高但系统性错误」的证书**：失明被封装进一个带 UCB、看起来最严谨的证书里，而 `max` 型证书半径还允许通过「放宽某个最难测指标的 B_v」换取整体放行——计量塔建在未计量的地基上，越严谨越危险。

**次级风险与缓解**：证书瘫痪（最差指标一票否决 → SOC 分层 + 受限运行而非停机）；元层 Goodhart（优化 ρ_cert → 将 ρ_cert 纳入 CIV + 指标 canary + 随机化审计）；规模律外推失效（预注册外推检验 + 留出更大规模实测）；采集成本（DBA 显式成本约束，TTA 只买覆盖）；指标格组合爆炸（只展开关键路径 + 剪枝）。
