### 第 1 轮灵感驱动研究记录

**灵感词**：遥操作、专利布局

**直觉与动机**：

先给直觉。v29 的安全论证像一枚「单件专利」：它试图用十二张证书把整条执行轨迹一次性圈进一个受保护范围，且默认这枚证书永久有效。但真实产业里没人靠一件专利保护整条产品线——他们布的是「专利组合」（portfolio）：宽而弱的基础权利要求 + 窄而强的从属权利要求，各自带优先权日（priority date）与审查历史（prosecution history），并在环境变化时用「续案/部分续案」（continuation / CIP）保住旧优先权、只为新主题申请新日期。这个类比直接击中 v29 的两个结构性弱点：(a) 十二证是「全或无」的合取，缺乏分层覆盖与强度梯度；(b) 证书一旦签发就被默认为永久有效，没有优先权、失效窗口与「禁止反悔」的概念。

再看遥操作。遥操作员是整个系统里「最强但最窄」的一层：有人的判断，所以保证最强；受通信延迟、注意力、可用性限制，所以覆盖最窄。把遥操作放进证书组合，它就不是一个应急开关，而是组合里「优先权最新、范围最窄、强度最高」的那件权利要求；而每一次人工接管，恰恰是「现有技术」（prior art）——它证明某张证书的权利要求在该状态上过宽，应当被「缩小」（narrowing）甚至「无效」（invalidation）。反过来，若接管稀疏或归因错误，组合会误以为宽权利要求仍然成立，这正是本轮要防的失效。

**严谨定义（承接 v29）**：

- 证书权利要求：C_i = (S_i, g_i, t_i, ρ_i, par_i)，其中 S_i ⊆ Cells 为覆盖范围、g_i ∈ [0,1] 为范围内违规率上界（越小越强）、t_i 为优先权时间戳、ρ_i = H(D_i ‖ 检查器版本 ‖ 校准参数) 为证据指纹、par_i 为父权利要求。
- 组合：P = (C, E) 为以从属关系为边的 DAG。点覆盖 Cov_P(x) = ∃i: x ∈ S_i；点保证 Guar_P(x) = min_{i: x∈S_i 且 t_now−t_i ≤ τ_valid} g_i；自由实施集 F_θ(P) = {x : Guar_P(x) ≤ θ}。
- 无效事件：e = (x, u_h, u_sys, type, conf, t)，type ∈ {safety, preference}，conf 为归因置信。缩小算子 N(C,e)：S_C ← S_C \ B(x, r_n)，仅安全型且 conf ≥ conf_min 时自动执行。
- 续案：CIP 对旧 cell 继承 t_old 与旧保证，对新 cell 取 t_new 且保证暂置 1（未验证）；「禁止反悔」（estoppel）要求已缩小剔除的区域在无新证据时不得重新放宽。

**关键洞见**：把「证书」从一次性签发的合取门，改造成「带范围、优先权、失效窗口、可缩小、可续案」的组合 DAG；遥操作接管作为组合的「无效宣告证据」持续收紧宽权利要求，而续案/CIP 机制保证环境漂移时旧证据不被误当作新覆盖。系统目标因此从「证明一次」变为「持续维持一组互相覆盖的安全权利要求」，安全性的时间维度第一次被显式建模。

**形式化目标（增量）**：

1. 定义权利要求五元组与组合 DAG，给出 Cov_P / Guar_P / F_θ(P) 的点态语义。
2. 定义遥操作无效采集与缩小算子 N(C,e)，区分安全型（必须缩小）与偏好型（不缩小、转 HVPM）。
3. 定义 CIP 优先权分离与禁止反悔检查，杜绝「新主题继承旧保证」的洗白路径。
4. 定义分层路由：在有效覆盖权利要求上按保证强度选 student → teacher → teleop，显式延迟预算，无覆盖则安全停而非放行。
5. 证明 Exec_v30 ⊆ Exec_v29（v29 十二证作为基础权利要求被原样复用）。
6. 实验：遥操作延迟 50–200ms 下，相比 v29 固定兜底，FTO 覆盖率提升、无效接管率下降、过度保守拒绝率不升。

**本轮最大风险**：**遥操作稀疏性使「最强权利要求」恰在最需要的尾部状态缺席，而续案的优先权继承又可能把旧证据洗成新覆盖**——组合看起来覆盖更广、保证更强，实际在最危险的分布外状态上既无强权利要求可用，又因优先权洗白而未被判为「未覆盖」，是一种比 v29 自证循环更难在线归因的「组合级虚假覆盖」。

## 2. 关键算法骨架（在 IP-467~472 骨架上扩展）

### IP-473 Certificate Claim Model (CCM)

```python
@dataclass(frozen=True)
class CertificateClaim:
    """CCM：证书即权利要求，不可变快照；缩小产生子权利要求"""
    cid: str
    scope: frozenset          # S_i：覆盖的 cell 集合
    guarantee: float          # g_i：违规率上界（越小越强）
    priority: float           # t_i：优先权时间戳
    evidence: str             # ρ_i：数据/检查器/校准指纹
    parent: Optional[str] = None
    r_n: float = 0.05         # 缩小邻域半径

    def valid(self, t_now: float, tau_valid: float) -> bool:
        return (t_now - self.priority) <= tau_valid

    def covers(self, x, cell_fn) -> bool:
        return cell_fn(x) in self.scope
```

### IP-474 Certificate Portfolio Manager (CPM)

```python
class CertificatePortfolioManager:
    """CPM：组合 DAG 的签发/缩小/失效/续案与 FTO 计算"""
    def __init__(self, tau_valid=1e5, theta=0.05, red_max=3.0):
        self.claims: dict[str, CertificateClaim] = {}
        self.edges: dict[str, set[str]] = defaultdict(set)
        self.tau_valid, self.theta, self.red_max = tau_valid, theta, red_max

    def file(self, claim: CertificateClaim):
        self.claims[claim.cid] = claim
        if claim.parent:
            self.edges[claim.parent].add(claim.cid)

    def narrow(self, cid, x, cell_fn):
        """缩小：保留父优先权，只剔除 x 的 r_n 邻域；返回子权利要求"""
        p = self.claims[cid]
        c0 = cell_fn(x)
        child = CertificateClaim(
            cid=f"{cid}#n{len(self.edges[cid])}",
            scope=frozenset(c for c in p.scope if _cell_dist(c, c0) > p.r_n),
            guarantee=p.guarantee, priority=p.priority,   # 优先权不变
            evidence=p.evidence, parent=cid, r_n=p.r_n)
        self.file(child)
        return child

    def point_guarantee(self, x, cell_fn, t_now):
        gs = [c.guarantee for c in self.claims.values()
              if c.covers(x, cell_fn) and c.valid(t_now, self.tau_valid)]
        return min(gs) if gs else math.inf

    def fto(self, cells, cell_fn, t_now):
        return {k for k in cells
                if self.point_guarantee(_cell_rep(k), cell_fn, t_now) <= self.theta}

    def thicket_index(self, cells, cell_fn, t_now):
        counts = [sum(1 for c in self.claims.values()
                      if c.covers(_cell_rep(k), cell_fn)
                      and c.valid(t_now, self.tau_valid))
                  for k in cells]
        return float(np.mean(counts)) if counts else 0.0

    def expire(self, t_now):
        """过期权利要求失效；返回新产生的未覆盖缺口，交 CPA 续案"""
        for cid in [c.cid for c in self.claims.values()
                    if not c.valid(t_now, self.tau_valid)]:
            del self.claims[cid]
```

### IP-476 Claim-Scoped Routing Gate (CSRG)

```python
class ClaimScopedRoutingGate:
    """CSRG：在有效覆盖权利要求上按保证强度选层，显式延迟预算"""
    TIERS = ("student", "teacher", "teleop")
    TIER_LATENCY = {"student": 0.001, "teacher": 0.02, "teleop": 0.20}

    def route(self, x, cpm, cell_fn, t_now, latency_budget, tier_claims):
        for tier in self.TIERS:
            c = tier_claims.get(tier)
            if c is None or c.cid not in cpm.claims:
                continue
            if not c.covers(x, cell_fn) or not c.valid(t_now, cpm.tau_valid):
                continue
            if latency_budget.remaining < self.TIER_LATENCY[tier]:
                continue
            return tier, c
        return None, None      # 无覆盖/无可用层 → 安全停，而非放行
```

### IP-477 Continuation & Priority Auditor (CPA)

```python
class ContinuationPriorityAuditor:
    """CPA：漂移触发续案；CIP 新旧主题优先权分离；禁止反悔"""
    def __init__(self, eps_drift=0.1, W_d=200):
        self.eps_drift, self.W_d = eps_drift, W_d
        self.narrowed_away: dict[str, set] = defaultdict(set)

    def detect_drift(self, density_ratio_hist):
        return max(density_ratio_hist[-self.W_d:]) > 1.0 + self.eps_drift

    def file_cip(self, cpm, base_cid, old_cells, new_cells, t_now):
        """旧主题继承 t_old 与旧保证；新主题取 t_new 且 g=1，绝不继承旧保证"""
        base = cpm.claims[base_cid]
        old_claim = replace(base, cid=f"{base_cid}#cip{t_now:.0f}",
                            scope=frozenset(old_cells), parent=base_cid)
        cpm.file(old_claim)
        new_claim = CertificateClaim(
            cid=f"{base_cid}#new{t_now:.0f}", scope=frozenset(new_cells),
            guarantee=1.0, priority=t_now,            # 冷启动：无保证
            evidence=f"new@{t_now:.0f}", parent=old_claim.cid)
        cpm.file(new_claim)
        return old_claim, new_claim

    def check_estoppel(self, cid, requested_scope, new_evidence=False):
        """禁止反悔：已缩小剔除的区域，无新证据不得重新放宽"""
        if new_evidence:
            return True
        return not (requested_scope & self.narrowed_away[cid])
```

### IP-478 Portfolio Cert Gate (P-KTCG)

```python
class PortfolioCertGate:
    """P-KTCG：v29 十二证 = 基础权利要求；组合层加 SCC/PVC/RTC"""
    def __init__(self, base_gate, cpm, csrg, tih, cpa, cell_fn, tier_claims):
        self.base_gate, self.cpm, self.csrg = base_gate, cpm, csrg
        self.tih, self.cpa, self.cell_fn = tih, cpa, cell_fn
        self.tier_claims = tier_claims

    def admits(self, plan, sensor, t_now, latency_budget):
        x = plan.init_state
        # 0) 基础权利要求：v29 十二证（原样复用）
        base_ok = self.base_gate.admits(plan, sensor)
        # 1) SCC：存在有效权利要求覆盖 x；否则拒绝（未覆盖 ≠ 安全）
        if self.cpm.point_guarantee(x, self.cell_fn, t_now) == math.inf:
            return False, None, "uncovered"
        # 2) RTC：按保证强度路由 student → teacher → teleop
        tier, claim = self.csrg.route(
            x, self.cpm, self.cell_fn, t_now, latency_budget, self.tier_claims)
        if tier is None:
            return False, None, "no-valid-claim"
        # 3) PVC：优先权/指纹/有效期/禁止反悔
        if not self._priority_ok(claim, t_now):
            return False, None, "priority-invalid"
        # 4) 执行该层；teacher/teleop 路径复用 base_gate 的轨迹级检查
        ok, u = self._execute(tier, plan, sensor, base_ok)
        # 5) 遥操作安全型接管 → 缩小宽权利要求（组合在线更新）
        if tier == "teleop" and self.tih.last_event is not None:
            e = self.tih.last_event
            if e.type == "safety" and e.conf >= self.tih.conf_min:
                self.cpm.narrow(claim.cid, e.x, self.cell_fn)
                self.cpa.narrowed_away[claim.cid].add(self.cell_fn(e.x))
        return ok, u, f"{tier}:{'ok' if ok else 'fallback'}"

    def _priority_ok(self, claim, t_now):
        return (claim.valid(t_now, self.cpm.tau_valid)
                and self.cpa.check_estoppel(claim.cid, claim.scope))
```

**与 v29 的接口约定**：`base_gate.admits` 语义不变；P-KTCG 只读复用其十二证，并在其上叠加 SCC/PVC/RTC。遥操作接管事件由 TIH 采集，低置信事件进入 `review_queue` 人工复核，绝不自动缩小。组合更新只发生在离线或安全停窗口内，避免在线改证书引发竞态。

## 3. 复杂度分析（增量更新）

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 |
|---|---|---|---|
| CCM 签发/缩小 | O(\|S\|)（复制范围） | O(\|S\|) | 每 cell 一个位 |
| CPM 点保证查询 | O(\|C\|)（可索引至 O(log\|C\|)） | O(\|C\|·\|S\|) | \|C\| 权利要求数 |
| FTO 重算 | O(\|Cells\|·\|C\|) | O(\|Cells\|) | 离线/轮 |
| 丛林指数 | O(\|Cells\|·\|C\|) | O(\|Cells\|) | red_max=3.0 |
| TIH 单次接管 | O(1)+归因打分 | O(1) | conf_min=0.7 |
| CSRG 路由 | O(\|tiers\|) = O(3) | O(1) | 延迟预算在线可读 |

| CPA 续案 | O(\|old\|+\|new\|) | O(\|S\|) | 离线触发 |

**实时性**：组合查询与路由为微秒级，不改变 v29 的实时性量级；缩小/续案/失效全部在离线或安全停窗口执行，在线只读。

## 4. 正确性论证（增量更新）

### 引理 29（组合点保证不劣于基础权利要求）

**陈述**：设基础权利要求 C_b 在 t_now 有效且覆盖 x，则 Guar_P(x) ≤ g_b；若另有更强从属权利要求覆盖 x，则 Guar_P(x) 严格更小。

**证明**：Guar_P(x) 取所有有效覆盖权利要求保证的最小值，集合包含 C_b，故 min ≤ g_b。∎

**工程含义**：组合不会比单件更弱；但它也可能因过期或缩小而在某些 x 上变为 ∞——这些缺口必须由 SCC 检出并交续案补齐，绝不能把 ∞ 误读成「无风险」。

### 引理 30（缩小算子的健全性与覆盖代价）

**陈述**：N(C,e) 产生子权利要求 C'，S' = S \ B(x,r_n)。对任意 y ∈ S'，C' 仍覆盖且保证不变；对 y ∈ B(x,r_n)，C' 不再提供保证。故缩小不产生错误覆盖，但覆盖损失 L_narrow = |B(x,r_n) ∩ S|（以 cell 计）。

**证明**：由集合差定义直接得；保证字段未改，剩余部分仍满足原上界。∎

**工程含义**：r_n 是「安全 vs 覆盖」的旋钮：r_n 大 → 更安全但 FTO 收缩更快、更依赖续案；r_n 小 → 保留覆盖但可能对同一区域反复触发无效事件。

### 引理 31（CIP 优先权一致性）

**陈述**：若新主题权利要求取 t_new 且 g=1，则在 t < t_new 时该权利要求不存在或保证为 1，故 Guar_P(x_new) 不会因旧优先权被错误降低。

**证明**：旧权利要求范围仅含 old_cells，不含 new_cells；新权利要求在 t_new 之前不存在，之后其保证恒为 1。因此新 cell 在旧时间轴上不被任何低保证权利要求覆盖。∎

**工程含义**：把「新证据」与「旧证据」在时间轴上物理隔离，是防止优先权洗白的最小机制；任何试图让新 cell 继承旧保证的实现都应被 PVC 拒绝。

### 定理（P-KTCG 十五证准入门的执行集收缩）

**陈述**：Exec_v30 ⊆ Exec_v29。

**证明**：P-KTCG.admits 第 0 步原样调用 v29 基础门（十二证），其后每一步（SCC/PVC/RTC）都是附加合取项。合取只会收缩执行集，故 Exec_v30 ⊆ Exec_v29。∎

**诚实声明（组合证书的边界）**：SCC/PVC/RTC 依赖 cell 划分、归因置信 conf、漂移统计 ε_drift，均为估计量；「覆盖」是离散 cell 级近似，边界 cell 上的保证存在量化误差；遥操作接管本身带人因噪声。组合证书仍是概率性/统计性证书，不是绝对安全证明。

## 5. 实验设计（增量）

**平台**：双足 MuJoCo 仿真，三轴变量——地形（平/坡/湿滑/碎石）、负载（0/10/25kg）、遥操作通信延迟（50/100/200ms，含 5% 丢包）；操作员可用性建模为间歇可达（可接管的步占比 20%–100%）。

**对照**：A) v29（无组合）；B) v29 + 固定遥操作兜底（当前实践）；C) v30 组合（本方案）。

**指标**：
1. 安全违规率 ε_viol（越界/跌倒/超力）；
2. FTO 覆盖率 |F_θ(P)| / |Cells|，及尾部未覆盖质量 m_0；
3. 遥操作接管率（次/千步）与「无效接管率」（接管后系统本可安全通过的比例）；
4. 过度保守拒绝率（安全可达却被判未覆盖而停）；
5. 误缩小率（由偏好型/低置信事件错误触发的缩小占比）。

**假设**：
- H1：v30 的 FTO 覆盖率相对 A 提升 ≥10%，且尾部 m_0 ≤ 0.05；
- H2：v30 的 ε_viol 不劣于 A，且显著优于 B 在延迟 200ms 下的表现；
- H3：v30 的无效接管率相对 B 下降 ≥30%，过度保守拒绝率不升超过 2 个百分点；
- H4：TIH 归因置信阈值使误缩小率 < 5%。

**消融**：去掉 TIH（只做固定兜底）、去掉 CIP（续案退化为全量重签）、去掉 estoppel（允许无限放宽）、去掉丛林上限 red_max。

## 7. 本轮最大风险（最终确认）

**一句话**：**组合级虚假覆盖**——遥操作是组合里最强但最窄的权利要求，而它恰在最需要的分布外尾部状态最可能缺席；与此同时，续案的优先权继承若校验不严，会把旧证据洗成新覆盖，使 SCC/PVC 一致放行一片实际没有强保证可用的区域；相比 v29「多组件共因失效」，这是把「覆盖的时间有效性」交给稀疏人因事件后出现的**组合级盲区**，更隐蔽、更难在线归因。
