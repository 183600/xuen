# 第 56 轮（承接第 55 轮 v31 Semantic-Contact；灵感循环第 1 轮；本轮灵感：「论文发表」×「全身控制」）

> 第 55 轮把“语义-接触”写进了全身生存核与可部署证书。本轮换一个更“元”的视角：**论文发表**并不是“把结果写出来”，而是一套把 **主张** 变成 **可被独立证伪、可复现、可撤稿** 的社会-技术闭环。全身控制恰恰缺这一层：现有证书是“自证”，摔倒不可逆、无法“撤稿”。核心矛盾：**H24**：全身控制的证书天然是自我声明，缺少独立攻击面，存在系统性自证偏差；**H25**：论文失败可撤稿，而身体失败不可逆，因此必须把不可逆失败前移到可撤销的“预印本/影子”阶段；**H26**：单一审稿人（单一扰动分布）会被过拟合，评审本身也需要被覆盖度约束。

## 0. 直觉与动机

**灵感 1（论文发表 → 可证伪部署声明，而非性能指标）**
直觉：论文中最有力的不是“我们更好”，而是“若 X 不成立，则 Y 必然失败”的可证伪声明。给每个全身技能配一个声明 `φ=(P,Q,W,τ)`：`P` 是可观测前提（摩擦下界、载荷上界、感知噪声界、时延界），`Q` 是在时间窗 `τ` 内的安全谓词（生存核内 + 跟踪误差界），`W` 是反例见证。部署不是“相信策略”，而是“相信这份声明在审稿预算内没被攻破”。

**灵感 2（同行评审 → 对抗审稿人集成，主动寻找反例）**
直觉：审稿人从理论、实验、统计、边界四个角度攻击。全身控制需要审稿人集成 `R={r_i}`，每个 `r_i` 是针对一类失败模式的对抗搜索器（摩擦/接触、时延、负载、地形、感知噪声）。他们的目标函数是 **证伪** 而不是确认；接受条件是 `∀r_i`，在攻击预算 `b_i` 内找不到见证。

**灵感 3（rebuttal → 主动证据补采，而非被动挨打）**
直觉：论文有 rebuttal，作者可补实验。全身控制对应 **主动反驳**：审稿人给出见证 `w` 后，先判定 `w` 是否落在部署分布 `supp(D_deploy)` 内。若在，则定向采样/微调并重新提交；若不在，则把 **适用域边界** 朝 `w` 收缩。把“失败”变成一次可撤销的声明修订，而不是一次摔倒。

**灵感 4（预印本/相机稿 → 影子部署与分级发布）**
直觉：论文先 arXiv 再 camera-ready。全身控制对应 `sim → twin → restricted → full` 四级发布：影子阶段只观察不执行，失败可撤销；只有连续 `k` 轮审稿通过且复现率达标才进入受限物理部署。把不可逆的物理摔倒前移到可撤销的仿真/孪生阶段。

**灵感 5（撤稿/勘误 → 运行时撤稿与证书失效）**
直觉：论文有 retraction/errata。全身控制必须有运行时撤稿：在线证据（力反馈、IMU、跟踪误差、接触失败）一旦与声明前提冲突，证书立即 `valid→degraded→revoked`，切到 `u_stop∈𝒳_safe`，并把见证写入撤稿日志供离线重审。铁律：宁可撤稿，不可摔倒。

## 1. 形式化定义（增量：定义 127–132）

**定义 127（可证伪部署声明）**
`φ = (P, Q, W, τ)`：前提集 `P = {p_1,...,p_n}` 为可观测条件的合取（如 `μ≥μ_0`、`载荷≤m_0`、`感知噪声≤ε_0`、`时延≤τ_0`）；断言 `Q` 为窗口 `τ` 内的安全-任务谓词 `x_t∈K(Σ) ∧ ‖e_t‖≤ε_e ∧ 未摔倒`；`W` 为反例见证集合（轨迹/状态/参数）。在证据 `E` 下“未被证伪”记 `E ⊬ ¬φ`。

**定义 128（对抗审稿人集成）**
审稿人 `r_i: Φ → {accept} ∪ Falsify`，`Falsify = {(w,b_i) | w⊨P ∧ w⊭Q}`，`b_i` 为攻击预算（样本数/搜索步）。集成 `R={r_i}_{i=1}^m`：
`Review_R(φ,E) = falsified(w*)` 若某 `r_i` 在 `b_i` 内找到见证，否则 `accept`。
**审稿覆盖** `cov(R) = Pr_{f∼D_fail}[∃i: r_i reproduces f]`，按失败模式分层（接触失效/时延/负载/地形/感知）。

**定义 129（反驳算子）**
`reb(φ, w) = (φ', E')`：
- 若 `w ∈ supp(D_deploy)`：修订 `φ'`（收紧 `P` 或修正 `Q`）+ 定向补采 `E'`；
- 若 `w ∉ supp(D_deploy)`：`φ' = φ`，但适用域 `dom(φ') = dom(φ) \ N_ε(w)`，`δ_dom` 记录收缩量。
反例见证不直接否决声明，而是驱动 **声明或适用域的单调修订**；修订后必须重新过审。

**定义 130（分级发布 / 影子部署）**
阶段 `s ∈ {sim, twin, restricted, full}`。转移 `s→s'`（仅相邻升阶）当且仅当：最近 `k` 轮 `Review_R(φ)=accept`、`Rep(φ,s) ≥ ρ_rep` 且 `cov(R) ≥ θ_cov`。影子阶段 `s∈{sim,twin}` 只观察不执行，失败代价可撤销；物理阶段 `s∈{restricted,full}` 失败不可逆，故门槛单调严格。

**定义 131（运行时撤稿）**
证书状态 `cert_t ∈ {valid, degraded, revoked}`。撤稿触发器
`ψ_t = 1 ⇔ (在线证据违反 P) ∨ (Q 首次违背)`。
`cert_{t+1} = revoke(cert_t)` 且 `u_{t+1} = u_stop ∈ 𝒳_safe`。撤稿日志 `L = {(t, w_t, which p_i violated)}`。

**定义 132（审稿-部署联合证书）**
`J_r = (φ, R, Rep, cov(R), dom(φ), δ_dom, L_retract)`。可部署条件：
`∀r_i: r_i(φ)=accept ∧ cov(R) ≥ θ_cov ∧ Rep ≥ ρ_rep ∧ δ_dom ≤ Θ_dom ∧ cert=valid`。

## 2. 关键算法 伪代码

### IP-127 FDC（Falsifiable Deployment Claim）

```python
def falsifiable_claim(policy, cert, history):
    P = infer_operating_envelope(policy, cert, history)   # mu_0, m_0, eps_0, tau_0
    Q = lambda x, e, t: in_viability_kernel(x, cert) and norm(e) <= cert.eps_e
    W = mine_counterexamples(policy, history)             # seed witnesses
    return Claim(P=P, Q=Q, W=W, tau=cert.horizon)
```

### IP-128 ARE（Adversarial Reviewer Ensemble）

```python
def adversarial_review(claim, reviewers, budget):
    witnesses = []
    for r in reviewers:                       # contact / latency / payload / terrain / perception
        w = r.search(claim, budget[r.kind])   # worst-case falsification search
        if w is not None and satisfies(w, claim.P) and not claim.Q(w):
            witnesses.append((r.kind, w))
    return ('falsified', witnesses) if witnesses else ('accept', [])
```

### IP-129 RBT（Rebuttal Operator）

```python
def rebuttal(claim, witness, D_deploy, policy, sampler):
    if in_support(witness, D_deploy):
        claim2 = tighten_premise_or_fix(claim, witness)   # monotone revision of P/Q
        E2 = sampler.targeted(witness, policy)            # active data collection
        return claim2, E2
    dom2 = shrink_domain(claim.dom, witness)              # monotone domain shrink
    return claim.with_domain(dom2), []
```

### IP-130 SDP（Staged Deployment Protocol）

```python
def staged_deploy(claim, reviewers, stages, k, rho_rep, theta_cov):
    s, streak = 'sim', 0
    while s != 'full':
        ok, ws = adversarial_review(claim, reviewers, stages[s].budget)
        rep = reproduce_rate(claim, s)
        if ok == 'accept' and rep >= rho_rep and cov(reviewers) >= theta_cov:
            streak += 1
            if streak >= k:
                s, streak = next_stage(s), 0
        else:
            claim, E = handle_witnesses(claim, ws, s)     # rebuttal loop
            streak = 0
    return claim, s
```

### IP-131 RTR（Runtime Retraction）

```python
def runtime_retraction(claim, obs, cert_state):
    if violates_premise(obs, claim.P) or first_violation(obs, claim.Q):
        log(obs.t, obs.witness)
        return 'revoked', safe_brake(obs.x)
    if near_boundary(obs, claim.P):
        return 'degraded', conservative_ctrl(obs.x)
    return cert_state, None
```

### IP-132 RJC（Review-Joint Certificate）

```python
def review_joint_certificate(policy, claim, reviewers, records):
    ok, ws = adversarial_review(claim, reviewers, records.budget)
    if ok != 'accept':               return ('reject', 'falsified', ws)
    if cov(reviewers) < theta_cov:   return ('reject', 'review_coverage_low')
    if reproduce_rate(claim, records.stage) < rho_rep:
        return ('reject', 'not_reproducible')
    if domain_drift(claim.dom, records.online) > Theta_dom:
        return ('reject', 'domain_drift')
    return ('ok', ReviewCert(claim, reviewers, cov(reviewers), records, L_retract))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| FDC | O(|历史|·|P|) | O(|W|) | 前提可观测、断言可判定 |
| ARE | O(Σ_i b_i·C_r) | O(|W|) | 审稿人分层覆盖、搜索 sound |
| RBT | O(|D_deploy|·|W|) | O(|W|) | 域内/域外判定、修订单调 |
| SDP | O(k·|stages|·Q_review) | O(|stages|) | 升阶单调、复现率无偏 |
| RTR | O(1) 每步 | O(1) | 触发完备、安全切换可行 |
| RJC | O(Q_review + |records|) | O(|records|) | 四条件合取、日志可审计 |

**正确性定理（Reviewable Deployment Soundness）**
假设第 55 轮 (A29)–(A32) 成立；**(A33)** `cov(R) ≥ 1-β_rev`（真实失败模式被审稿人重现的比例）；**(A34)** `Rep` 的经验估计与真实复现概率偏差 `≤ ε_rep`（有限样本集中不等式）；**(A35)** 域漂移 `δ_dom` 可在线检测，检测延迟 `≤ τ_det`；**(A36)** 撤稿触发到安全切换的延迟 `≤ τ_stop`，且 `u_stop∈𝒳_safe` 始终可行。
则部署后失败概率：
```
P_fail ≤ (1 - cov(R)) + ε_rep + P(δ_dom > Θ_dom) + P(τ_det + τ_stop > τ_crit)
```
关键：**未覆盖的失败模式 + 复现噪声 + 域漂移 + 撤稿来不及**；任一项都不能被“审稿通过”这一结论掩盖。

## 4. 实验设计 E167–E171

| 实验 | 指标 | 目标 |
|---|---|---|
| E167 声明可证伪性 | 反例见证生成率 / 见证有效率 | ≥ 0.85 / ≥ 0.90 |

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 审稿人覆盖度自证（评审无限回归） | 高 | 外部留出失败分类 + 覆盖度元审计 |
| 审稿人过拟合单一扰动分布 | 高 | 分层审稿人 + 每轮重采样 + 无梯度黑盒搜索 |
| rebuttal 收紧过度导致策略“无域可用” | 中 | 域收缩预算 + 分阶段放宽 + 人工复核 |
| 影子/孪生与真实物理的 sim-to-real 差距 | 高 | 差异感知门槛 + 受限物理先行 + 力反馈校准 |
| 撤稿误触发导致频繁急停 | 中 | 迟滞 + 多证据确认 + degraded 中间态 |

## 6. 本轮最大风险

**一句话**：把“论文发表”的 claim→review→rebuttal→retraction 机制移植为全身控制的部署门禁，其 soundness **最终卡在“评审的评审”这一无限回归上**——审稿人集成的覆盖度无法由自身证明，一旦 `R` 的失败模式分布与真实分布错配，策略就会“通过一场虚假的同行评审”被放行到不可逆的物理阶段；因此必须以 **影子阶段不可绕过 + 覆盖度的外部留出审计 + 域漂移在线撤稿** 三重护栏兜底，绝不能把“审稿通过”当作“真实安全”。

# 第 56 轮产物 · 创新点清单 v32：ReviewWB（FDC×ARE×RBT×SDP×RTR×RJC）

> 承接第 55 轮产物 v31（Semantic-Contact Grounding）。本轮把“论文发表”的 **claim → evidence → adversarial review → rebuttal → staged release → retraction** 闭环移植到全身控制的可部署性判定：把“自证式证书”升级为 **可证伪、可复现、可撤稿** 的审稿式部署体系。
>
> - **FDC（Falsifiable Deployment Claim）**：技能携带可被独立证伪的部署声明 `φ=(P,Q,W,τ)`；
> - **ARE（Adversarial Reviewer Ensemble）**：分层对抗审稿人集成，主动生成反例见证；
> - **RBT（Rebuttal Operator）**：把见证转成声明修订或适用域收缩，并触发定向补采；
> - **SDP（Staged Deployment Protocol）**：`sim→twin→restricted→full` 分级放行，失败前移；
> - **RTR（Runtime Retraction）**：在线证据冲突时撤稿并安全切换；
> - **RJC（Review-Joint Certificate）**：审稿-部署联合证书。
>
> IP 编号：IP-127~IP-132（共 6 个新增）。承接并升级 IP-118（AEC 联合证书）与 IP-124（SCC 语义-接触证书）。

```
P_fail ≤ (1 - cov(R)) + ε_rep + P(δ_dom > Θ_dom) + P(τ_det + τ_stop > τ_crit)
```
关键：**组合声明的可证伪性、审稿覆盖、分级放行、运行时撤稿** 四层共同把“自证”变成“可被独立攻击且可撤回”。
