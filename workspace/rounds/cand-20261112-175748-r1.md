# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC IP-153~160；新灵感循环第 1 轮；本轮灵感：「灵巧操作」×「机械臂抓取」）

> 第 60 轮 SGEC 把「场景→意图→约束→阻抗→执行→证据」串成闭环，但它仍然把机器人默认抽象成**单个阻抗执行器**：安全的定义是「执行参数 K_safe 落在约束域内」。一旦进入抓取与灵巧操作，这个抽象出现三个结构性缺口：
> 1. **阻抗安全 ≠ 抓取安全**：K_safe 合规只说明「动作柔顺」，完全不保证**力闭合（force closure）**。一个完美柔顺的抓握照样可以在抬升瞬间滑落；一个从不越界的执行轨迹照样可以把鸡蛋捏碎。抓取的安全性首先取决于**离散接触结构**，而不是连续阻抗参数。
> 2. **接触模式被抹平**：灵巧操作的核心事件是接触模式的切换（接触/粘滞/滑移/滚动/指尖换位），它们是非光滑、离散、带迟滞的。SGEC 的连续闭环没有「模式」这个状态量，只能靠执行下滑后再回退，缺失**接触级的前置判断**。
> 3. **证据粒度不足**：第 60 轮 EV-exec 证明「命令被执行」，但不证明「哪个指节、多大面积、以什么模式接触、是否正在滑移」。没有**接触分辨的证据**，J_exec 无法回答「物体为什么掉了」。

## 0. 直觉与动机

**灵感 1（机械臂抓取 → 接触图抽象 CGAM）**
直觉：一次抓取不是一组关节角，而是一张**接触图**——节点是「哪根手指压在物体哪个面片」，边是相邻接触之间的运动学耦合，每个节点带一个离散模式：未接触 / 粘滞 / 滑移 / 滚动 / 枢转。抓取过程就是这张图上的**混合自动机**：模式内部连续演化，模式之间由事件（接触建立、滑移起始、滚动越界、接触丢失）触发跳转。关键洞见：**先把「抓取」从连续参数提升为「接触拓扑 + 接触模式」，才谈得上灵巧**；阻抗只是某个模式内的控制律，不能替代模式本身。

**灵感 2（灵巧操作 → 力闭合证书 FCC）**
直觉：抓得好不好，有一个可计算的物理判据：在摩擦锥内能否找到一组接触力平衡外力，并且还留有裕度。把这件事做成**结构证书**：摩擦锥裕度 ε_fc、滑移裕度 s_slip、模式置信度 γ_mode、力平衡残差 r_w。关键洞见：**证书必须对不确定性取最坏情况**（外力 tube、摩擦系数区间、物体位姿误差），否则「线性化摩擦锥 + 名义外力」会给出乐观的假 PASS；而假 PASS 在抓取里等价于掉物或捏碎。

**灵感 3（滑移 → 滑移约束调节 SCR）**
直觉：掉落不是突然发生的，它有一个前兆——**初始滑移（incipient slip）**。触觉能看见它。于是把「不滑」写成控制障碍函数 h(x)=s_slip−s_min≥0，用 QP 在每一个控制周期强制 ḣ+αh≥0，通过增大法向内力或减小切向加速度把状态推回安全集。但法向力不能无限大：脆弱物体有压碎上界。关键洞见：**抓取可行性本质是一个区间非空条件**——[滑移下界 f_slip^min, 压碎上界 f_crush^max]；区间为空时，再多控制也救不了，必须换接触图/换抓取位，而不是硬调参数。

**灵感 4（灵巧操作 → 灵巧接触路由 DCR）**
直觉：手内操作、换指、重抓，本质是接触模式图上的一条**受证书约束的路径**。每条模式迁移边都有前置条件（迁移前必须已力闭合、运动学可达、预算充足）和后置条件（迁移后模式可被观测确认）。关键洞见：**抓取规划不是选一个静态抓取位，而是选一条「每一跳都可被证书初始化」的接触模式路径**；不可初始化的一跳必须被剪掉。

**灵感 5（四灵感合流 → 抓取闭环 GCL + 抓取预算 PCE++++++）**
把 CGAM/FCC/SCR/DCR 嵌回第 60 轮 SERC：场景与物体 → 抓取候选接触图 → 鲁棒力闭合证书 → 接触模式路径规划 → 模式感知阻抗 + 滑移 CBF 执行 → 接触分辨证据 → 证书重算/重规划。新增抓取预算 B_grasp=(B_search,B_contact,B_slip,B_exec)，任一耗尽即显式降级（缓存抓取位 / 保守均匀接触 / 固定安全系数 / 回退第 60 轮）。

整体命名为 **GRACE（Grasp Reliability Assurance via Contact Evolution，通过接触演化的抓取可靠性保证）**：
`CGAM × FCC × SCR × DCR × GCL × CEC × PCE++++++ × GSI`。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（接触图抽象 CGAM）** 抓取的混合接触状态为 \(\mathcal{G}_c=(V_c,E_c,\mu_c)\)：
- **接触节点**：\(v=(f,\sigma)\in V_c\)，表示手指 \(f\) 与物体表面面片 \(\sigma\) 的接触；携带接触系 \((n,t_1,t_2)\)、接触点 \(p_v\)、面积 \(A_v\)、法向力 \(f_{n,v}\)、切向力 \(f_{t,v}\)。
- **离散模式**：\(m_v\in M=\{N,S,L,R,P\}\)（未接触、粘滞、滑移、滚动、枢转），整体模式 \(m=(m_v)_{v\in V_c}\in M^{|V_c|}\)。
- **耦合边**：\(E_c\) 编码相邻接触的滚动/运动学约束（如相邻指节的相对面片速度约束）。
- **力平衡**：外力旋量 \(w_{ext}=\sum_v G_v f_v=Gf\)，\(G=[G_1\cdots G_n]\in\mathbb{R}^{6\times 3n}\)。
- **混合自动机**：\(\mathcal{H}=(M^{|V_c|},\Sigma,\delta,\mathrm{Inv})\)，事件集 \(\Sigma\) 至少含四种守卫：
  - \(N\to S\)：\(f_{n,v}>\epsilon_f\) 且触觉接触成立；
  - \(S\to L\)：\(s_{slip,v}<\tau_{slip}\) 或触觉滑移信号触发；
  - \(S\leftrightarrow R\)：沿面片相对位移进入滚动约束域；
  - \(*\to N\)：\(f_{n,v}<\epsilon_f\) 或接触丢失。
  每个模式带不变式 \(\mathrm{Inv}(m)\)（如 S 模式要求力平衡残差 \(r_w\le r_{max}\)）。关键：**模式是状态，阻抗是模式内的控制律** \(K(m)\)，不是全局抽象。

**定义 162（鲁棒力闭合证书 FCC）** 对接触图 \(\mathcal{G}_c\)、外力不确定集 \(\mathcal{W}\)、摩擦系数区间 \([\mu_{\min},\mu_{\max}]\)、法向上界 \(f_n^{max}\)，定义：
- **摩擦锥裕度**（线性化后为 LP）：
  \[
  \epsilon_{fc}(w)=\max_{f}\ \min_{v}\Big(\mu_v f_{n,v}-\|f_{t,v}\|\Big)
  \quad \text{s.t. } Gf=-w,\ 0\le f_{n,v}\le f_{n,v}^{max}.
  \]
- **鲁棒裕度**：\(\epsilon_{fc}^{rob}=\min_{w\in\mathcal{W},\mu\in[\mu_{\min},\mu_{\max}]}\epsilon_{fc}(w,\mu)\)。
- **滑移裕度**：\(s_{slip}=1-\max_v \|f_{t,v}\|/(\mu_v f_{n,v})\)。
- **证书**：\(J_{grasp}=(\epsilon_{fc}^{rob}, s_{slip}, \gamma_{mode}, r_w)\)，其中 \(\gamma_{mode}=\prod_v \Pr(m_v\mid \text{tactile})\)。
- **三态判定**：
  - PASS：\(\epsilon_{fc}^{rob}\ge\epsilon_{\min}\wedge s_{slip}\ge s_{\min}\wedge \gamma_{mode}\ge\tau_{mode}\wedge r_w\le r_{max}\)；
  - REPAIR：存在 \(f_n\in[f_{slip}^{\min},f_{crush}^{max}]\) 可恢复裕度；
  - REJECT：区间为空或加力会压碎物体。
  关键：**PASS 只能由实测接触证据签发**（定义 166），名义模型/世界模型不得签发 PASS。

**定义 163（滑移约束调节 SCR）** 状态 \(x=(q,\dot q,f_c)\)，滑移安全函数 \(h(x)=s_{slip}(x)-s_{\min}\ge0\)。控制输入 \(u=(f_n,\ddot p_t,K)\) 由下述 QP 给出：
\[
\min_u \|u-u_{nom}\|_Q^2\quad \text{s.t. }
\dot h(x,u)+\alpha h(x)\ge0,\quad
f_n\le f_{crush}^{max}(o),\quad \tau\le\tau_{max},\quad u\in\mathcal{U}_{budget}.
\]
- **模式感知阻抗**：\(K(m)=\) S→(高刚度、限幅内力)；L→(增阻尼、降切向刚度)；R/P→(沿滚动/枢转方向的低阻抗)；N→(自由空间轨迹阻抗)。
- **可行内力区间**：\(I_{grasp}=[f_{slip}^{\min},f_{crush}^{max}]\)；\(I_{grasp}=\varnothing\Rightarrow\) 立即转 DCR 重规划或 REJECT，禁止原地加力。压碎上界来自场景/材料先验（复用第 60 轮 SSM 的场景先验）。

**定义 164（灵巧接触路由 DCR）** 模式迁移图 \(\mathcal{T}=(M^{|V_c|},\mathcal{E})\)，边 \(e=(m,m')\) 携带：
- 前置 \(\mathrm{Pre}(e)\)：FCC 可达 PASS、运动学可达、预算充足；
- 后置 \(\mathrm{Post}(e)\)：目标模式可在 \(\Delta t_m\) 内被触觉确认；
- 代价 \(c(e)=\lambda_t\mathrm{time}(e)+\lambda_r\mathrm{risk}(e)\)。
路径 \(\pi_c=m_0\xrightarrow{e_1}m_1\cdots\)。要求**每个前缀都可证书初始化**：
\[
\forall k,\ \mathrm{Pre}(e_k)\ \text{在 } m_{k-1} \text{ 的实测状态下成立}.
\]
搜索用 A*（启发式取模式距离下界 + 抓取质量缺口），以 B_search 与束宽 \(W_{beam}\) 截断，保证最坏情形有界。

**定义 165（抓取闭环 GCL）** 算子 GCL(M, task, intent, δf_req)：
```
① 场景/物体：z ← SSM.update(obs)；o ← Perception.object_state()      # 复用第60轮
② 候选接触图：C ← GraspProposer.propose(o, z, intent, π_scene)
③ 证书筛选：for c in C: J ← FCC.certify_robust(c, W_unc, f_crush_max(o))
             保留 J.epsilon_fc^rob ≥ ε_min 的候选，按裕度降序
④ 接触路由：π_c ← DCR.plan(c, task, B_grasp)；无可行 π_c ⇒ REPAIR/REJECT
⑤ 逐模式执行：for e=(m,m') in π_c:
                 K ← EEIS.compile_mode_aware(m, z, δf_req, J)
                 while not Guard(m'): u ← SCR.qp(f_nom,K,CBF,B_grasp)；dispatch(u)
                                     EV_c ← read_tactile(); if not GSI(EV_c): recover/replan
⑥ 证据与重算：EV_c 追加 EPIR；J_grasp ← FCC.recompute(EV_c)
⑦ 返回：(z, π_c, K, J_grasp, EV_c, Cert)
```

**定义 166（接触分辨证据 CEC / EV-contact）** 接触证据为
\[
EV_c=\{(\tau_v,p_v,f_{n,v},f_{t,v},m_v,\gamma_v,A_v)\}_{v\in V_c},
\]
并与第 60 轮 EPIR 消息头 (timestamp, seq_id, hash) 链接成哈希链。证书一致性检查：
- **覆盖一致性**：计划要求的接触节点集合 \(\subseteq\) 实测接触节点集合；
- **模式一致性**：\(m_v^{plan}=m_v^{meas}\) 的比例 ≥ τ_agree；
- **力一致性**：\(\|f^{cmd}-f^{meas}\|\le \Delta_f\)；
- **滑移时间线**：记录 slip 事件起止，作为「掉落归因」证据。
关键：证据必须**逐接触、逐模式**，否则无法区分「没接触」与「接触了但滑了」。

**定义 167（抓取预算 PCE++++++ / B_grasp）** \(B_{grasp}=(B_{search},B_{contact},B_{slip},B_{exec})\)：
```
voi_grasp = VOI_cog − cost_grasp − cost_exec
cost_grasp = λ_s·GraspSearch_cost + λ_c·ContactEst_cost + λ_l·SlipEst_cost
```
显式降级：
- B_search 耗尽 → 用缓存/对跖点（antipodal）抓取位，关闭 DCR（不可换指）；
- B_contact 耗尽 → 退化为保守均匀接触模型，摩擦系数取 \(\mu_{\min}\) 并膨胀不确定集；
- B_slip 耗尽 → 固定安全系数加内力（worst-case μ），禁用高加速度轨迹；
- B_exec 耗尽 → 回退第 60 轮 SERC 降级。

**定义 168（抓取安全不变式 GSI）** 安全集
\[
\mathcal{I}=\{x:\ \epsilon_{fc}^{rob}\ge\epsilon_{\min}\ \wedge\ s_{slip}\ge s_{\min}\ \wedge\ \gamma_{mode}\ge\tau_{mode}\ \wedge\ f_n\le f_{crush}^{max}(o)\}.
\]
GCL 必须在整个轨迹上保持 \(x(t)\in\mathcal{I}\)。若预测将离开 \(\mathcal{I}\)，按严重度升级：
```
if 可加内力恢复（I_grasp 非空且预算足）: REPAIR（SCR）
elif DCR 存在可行迁移:                    REPLAN（换接触图/换指）
else:                                     SAFE_ABORT（先减速卸载再释放，绝不硬撑）
```
关键：**GSI 是第 60 轮 SIC 的「结构安全」对应物**——SIC 管「参数可信」，GSI 管「接触结构可维持」。

### IP-161 CGAM（接触图与模式估计）

```python
class ContactGraphModel:
    def __init__(self, n_fingers=5):
        self.modes = {}            # (finger, patch) -> mode in {N,S,L,R,P}
        self.conf = {}             # mode confidence
        self.frames = {}           # contact frames (n,t1,t2), centroid, area
        self.edges = []            # kinematic coupling edges

    def update(self, tactile, kin):
        for v, tax in tactile.patches.items():
            m_prev = self.modes.get(v, 'N')
            f_n, f_t = tax.normal_force, tax.tangential_force
            slip_sig = tax.vibration_energy / (f_n + 1e-6)
            m = 'N' if f_n < EPS_F else (
                'L' if (np.linalg.norm(f_t) >= MU_MIN * f_n or slip_sig > TAU_SLIP)
                else 'S')
            if m_prev in ('S', 'R') and m == 'S':
                m = self._check_roll_or_pivot(v, kin) or 'S'
            self.modes[v] = self._hysteresis(m_prev, m)   # 迟滞抑制抖动
            self.conf[v] = self._mode_confidence(tax, m)
        return self.modes, self.conf
```

### IP-162 FCC（鲁棒力闭合证书）

```python
def certify_robust(cg, W_unc, f_crush, mu_range, eps_min=0.05, s_min=0.1):
    # 对不确定集取最坏情形：外力 tube 的顶点 + mu_min
    worst = (np.inf, np.inf, np.inf)
    for w in W_unc.vertices():                      # 小集合，可枚举
        eps, f = solve_cone_lp(cg.G, -w, mu=mu_range.min, f_max=f_crush)
        s = slip_margin(f, mu=mu_range.min)
        worst = (min(worst[0], eps), min(worst[1], s), min(worst[2], np.linalg.norm(cg.G @ f + w)))
    eps, s, r = worst
    gamma = float(np.prod(list(cg.conf.values())))
    if eps >= eps_min and s >= s_min and gamma >= TAU_MODE and r <= R_MAX:
        return Cert('PASS', eps, s, gamma, r)
    lo, hi = slip_min_force(cg, W_unc, mu_range.min), f_crush
    if lo <= hi:
        return Cert('REPAIR', eps, s, gamma, r)     # 区间非空 → 可加内力修复
    return Cert('REJECT', eps, s, gamma, r)         # 区间为空 → 必须换抓取
```

### IP-163 SCR（滑移 CBF 与模式感知阻抗）

```python
def scr_qp(x, K_nom, f_nom, f_crush, budget):
    h = slip_margin_est(x) - S_MIN
    if h < 0:
        return SAFE_ABORT()                          # 已越过安全集，先卸载
    # 最小扰动 QP：满足 h_dot + alpha*h >= 0, f_n <= f_crush
    u = solve_qp(H=Q, g=-Q @ np.r_[f_nom, K_nom],
                 A_ineq=[slip_cbf_grad(x)], b_ineq=[-ALPHA * h],
                 bounds=(0.0, f_crush), budget=budget)
    if u is None:
        return REPLAN()                              # 不可行 → 交给 DCR
    return u

def compile_mode_aware(mode, z, df, cert):
    return {'S': lambda: K_stiff(cert), 'L': lambda: K_damped(cert),
            'R': lambda: K_roll(cert),  'P': lambda: K_pivot(cert),
            'N': lambda: K_free(z)}[mode]()
```

### IP-164 DCR（证书约束的接触路由）

```python
def plan_contact_route(cg, goal, budget):
    frontier = [(heuristic(cg.mode), cg.mode, [])]
    while frontier and budget.search > 0:
        _, m, path = heappop(frontier)
        if satisfies(m, goal):
            return ContactPlan(path)
        for e in transitions(m):
            budget.search -= 1
            if not certifiable_pre(e, m):            # 前置必须可证书初始化
                continue
            if not kinematic_reachable(e) or not budget.ok():
                continue
            heappush(frontier, (cost(path) + heuristic(e.dst), e.dst, path + [e]))
    return None                                      # 无可行路由 → REPAIR/REJECT
```

### IP-165 GCL（抓取闭环）

```python
def grasp_centric_loop(M, task, intent, df_req):
    z = M.scene_model.update(M.telem_force, M.telem_pos)
    o = M.perception.object_state()
    cands = sorted(M.grasp_proposer.propose(o, z, intent),
                   key=lambda c: M.fcc.estimate(c), reverse=True)
    for cg in cands:
        J = M.fcc.certify_robust(cg, M.W_unc, M.f_crush(o))
        if J.state == 'REJECT':
            continue
        plan = M.dcr.plan(cg, task.goal, M.b_grasp)
        if plan is None:
            continue
        for e in plan.edges:
            K = M.eeis.compile_mode_aware(e.src_mode, z, df_req, J)
            while not M.guard(e.dst_mode):
                u = M.scr.qp(e.src_mode, K, M.b_grasp)
                if u is None:
                    plan = M.dcr.replan(cg, task.goal, M.b_grasp)
                    break
                M.dispatch(u)
                EV_c = M.tactile.read()
                if not M.gsi.check(EV_c):
                    return M.recover_or_replan(cg, plan, EV_c)
            else:
                continue
            break
        M.epir.append(EV_c)
        J = M.fcc.recompute(EV_c)
        return M, z, plan, K, J, EV_c
    return M, z, None, None, None, M.reject('no_certifiable_grasp')
```

### IP-167 PCE++++++（抓取预算）

```python
class GraspBudget:
    def __init__(self, search=200, contact=50, slip=100, exec_budget=None):
        self.search, self.contact, self.slip = search, contact, slip
        self.exec = exec_budget or ExecBudget()

    def degrade(self):
        if self.search <= 0:   return 'cached_antipodal_grasp_no_regrasp'
        if self.contact <= 0:  return 'uniform_contact_mu_min'
        if self.slip <= 0:     return 'fixed_internal_force_safety_factor'
        if self.exec.exhausted(): return 'round60_serC_degrade'
        return 'normal'
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CGAM | O(\|V_c\|) 模式更新/周期 | O(\|V_c\|+\|E_c\|) | 模式分类准确率 ≥ 90%，切换延迟 ≤ 20ms |
| FCC | O(n³) LP/SOCP（n≤5 触点，热启动） | O(n²) | 鲁棒假 PASS ≤ 0.5%，过保守拒绝 ≤ 15% |
| SCR | O(n²) QP/周期 | O(n²) | CBF 可行时保持 s_slip ≥ s_min，压碎违规 = 0 |
| DCR | O(\|E\| log\|E\|) 有界 A*（B_search/束宽截断） | O(\|M\|^{W_beam}) | 每个前缀可证书初始化；最坏搜索有界 |

**正确性定理（GRACE）**：
假设 A66–A70 成立：
- **(A66) CGAM**：模式估计误差有界 δ_mode，事件检测时延 ≤ Δt_m；迟滞消除 Zeno 抖动。
- **(A67) FCC**：鲁棒证书对 \(\mathcal{W}\times[\mu_{\min},\mu_{\max}]\) 取最坏情形，包含真实证书（soundness），线性化摩擦锥的近似误差由 ε_min 吸收。
- **(A68) SCR**：只要 \(\mathcal{I}_{grasp}\neq\varnothing\)，CBF-QP 可行；控制时延 ≤ Δt_c。
- **(A69) DCR**：只输出前置可证书初始化的迁移，路径深度受 B_search/束宽约束。
- **(A70) GCL/GSI**：若 \(x\) 将离开 \(\mathcal{I}\)，在 Δt_abort 内触发 REPAIR/REPLAN/SAFE_ABORT，且 SAFE_ABORT 先卸载后释放。

则：
1. **结构安全**：\(x(t)\in\mathcal{I}\Rightarrow\) 在裕度内不滑移、不压碎；抓取安全不再依赖阻抗参数是否「看起来合规」。
2. **证书可靠性**：PASS 只由实测 EV-contact 签发；名义模型不得伪造 PASS，假 PASS 率受 A67 约束。
3. **证据可归因**：EV-contact 逐接触、逐模式、哈希链化，掉落可定位到「哪个接触、哪种模式、何时滑移」。
4. **预算安全**：B_grasp 任一维耗尽即进入显式降级，不允许隐式拖垮执行闭环。

### IP-161 CGAM（接触图与模式估计）

```python
class ContactGraphModel:
    def __init__(self, n_fingers=5):
        self.modes = {}            # (finger, patch) -> mode in {N,S,L,R,P}
        self.conf = {}             # mode confidence
        self.frames = {}           # contact frames (n,t1,t2), centroid, area
        self.edges = []            # kinematic coupling edges

    def update(self, tactile, kin):
        for v, tax in tactile.patches.items():
            m_prev = self.modes.get(v, 'N')
            f_n, f_t = tax.normal_force, tax.tangential_force
            slip_sig = tax.vibration_energy / (f_n + 1e-6)
            m = 'N' if f_n < EPS_F else (
                'L' if (np.linalg.norm(f_t) >= MU_MIN * f_n or slip_sig > TAU_SLIP)
                else 'S')
            if m_prev in ('S', 'R') and m == 'S':
                m = self._check_roll_or_pivot(v, kin) or 'S'
            self.modes[v] = self._hysteresis(m_prev, m)   # 迟滞抑制 Zeno 抖动
            self.conf[v] = self._mode_confidence(tax, m)
        return self.modes, self.conf
```

### IP-162 FCC（鲁棒力闭合证书）

```python
def certify_robust(cg, W_unc, f_crush, mu_range, eps_min=0.05, s_min=0.1):
    worst = (np.inf, np.inf, np.inf)
    for w in W_unc.vertices():                      # 外力 tube 顶点，可枚举
        eps, f = solve_cone_lp(cg.G, -w, mu=mu_range.min, f_max=f_crush)
        s = slip_margin(f, mu=mu_range.min)
        worst = (min(worst[0], eps), min(worst[1], s),
                 min(worst[2], np.linalg.norm(cg.G @ f + w)))
    eps, s, r = worst
    gamma = float(np.prod(list(cg.conf.values())))
    if eps >= eps_min and s >= s_min and gamma >= TAU_MODE and r <= R_MAX:
        return Cert('PASS', eps, s, gamma, r)
    lo, hi = slip_min_force(cg, W_unc, mu_range.min), f_crush
    if lo <= hi:
        return Cert('REPAIR', eps, s, gamma, r)     # 区间非空 → 可加内力修复
    return Cert('REJECT', eps, s, gamma, r)         # 区间为空 → 必须换抓取
```

```python
def plan_contact_route(cg, goal, budget):
    frontier = [(heuristic(cg.mode), cg.mode, [])]
    while frontier and budget.search > 0:
        _, m, path = heappop(frontier)
        if satisfies(m, goal):
            return ContactPlan(path)
        for e in transitions(m):
            budget.search -= 1
            if not certifiable_pre(e, m):            # 前置必须可证书初始化
                continue
            if not kinematic_reachable(e) or not budget.ok():
                continue
            heappush(frontier, (cost(path) + heuristic(e.dst), e.dst, path + [e]))
    return None                                      # 无可行路由 → REPAIR/REJECT
```

### IP-165 GCL（抓取闭环）

```python
def grasp_centric_loop(M, task, intent, df_req):
    z = M.scene_model.update(M.telem_force, M.telem_pos)
    o = M.perception.object_state()
    cands = sorted(M.grasp_proposer.propose(o, z, intent),
                   key=lambda c: M.fcc.estimate(c), reverse=True)
    for cg in cands:
        J = M.fcc.certify_robust(cg, M.W_unc, M.f_crush(o))
        if J.state == 'REJECT':
            continue
        plan = M.dcr.plan(cg, task.goal, M.b_grasp)
        if plan is None:
            continue
        for e in plan.edges:
            K = M.eeis.compile_mode_aware(e.src_mode, z, df_req, J)
            while not M.guard(e.dst_mode):
                u = M.scr.qp(e.src_mode, K, M.b_grasp)
                if u is None:
                    plan = M.dcr.replan(cg, task.goal, M.b_grasp)
                    break
                M.dispatch(u)
                EV_c = M.tactile.read()
                if not M.gsi.check(EV_c):
                    return M.recover_or_replan(cg, plan, EV_c)
            else:
                continue
            break
        M.epir.append(EV_c)
        J = M.fcc.recompute(EV_c)
        return M, z, plan, K, J, EV_c
    return M, z, None, None, None, M.reject('no_certifiable_grasp')
```
