# 第 5 轮（灵感循环第 5 轮；本轮灵感：「目标检测」×「关节空间控制」）

> **基线**：第 4 轮 InstructGauge-WR（IP-328–333；定义 448–467；引理 59–62；实验 E457–E472）。第 3 轮 InstructGauge 与更早 LeanGauge / ToolGauge 骨架继续继承不变。
> 本轮纪律：**证据升级 + 控制下沉 + 严格退化**。目标检测只提升「看到什么」的证据质量，关节空间控制只提升「怎么安全地动」的可行性；两者都是可选增强，任一环节不可用都必须逐级退回，而不是互相依赖。

## 0. 直觉与动机

**灵感 1（目标检测 → 把检测当作「有覆盖率的证据」，而不是「世界真值」）**
直觉：人不会因为一帧画面里出现一个框就相信那里真有一个可抓的物体；人会多看几帧、换个角度、确认类别，并对「没见过的东西」保持怀疑。检测器输出的 confidence 并不是校准概率，单帧框还可能幻觉、漏检、抖动。检测真正的安全价值不在于「给出一个位置」，而在于四件事：①可校准的**类别集合**（而不是单一 top-1），②**时间持续性**（这条 track 活了多少帧），③**视角质量**（当前视角能否支撑可靠的 6D 位姿与抓取），④对**开集未知类别**的显式拒绝。因此检测不应直接驱动执行器，而应以 `DetectionCert` 的形式进入接地映射 Γ：只有「落在共形检测集内 ∧ 被时间确认 ∧ 与任务期望的空间支撑重叠 ∧ 指代唯一」的目标才允许被绑定，否则一律输出 ⊥。于是检测的三类错误被分别路由：假阳 → 拒绝绑定；漏检 → 关节层保守减速；定位抖动 → 扩大不确定度、缩短块长。

**灵感 2（关节空间控制 → 任务空间合法 ≠ 关节空间安全）**
直觉：末端执行器的笛卡尔轨迹再漂亮，解算到关节上也可能越限、超速、超扭矩、擦过奇异点，甚至在两个 IK 分支之间跳变。第 4 轮的 Kinematic-Loop 只检查「末端到哪」，不检查「电机能不能、结构稳不稳、构型连不连续」。把控制下沉到关节空间后，约束变成**构造性的**（`q ∈ Q_lim`、`|q̇| ≤ v_max`、`|τ| ≤ τ_max`、奇异裕度 `σ_min ≥ σ₀`、构型连续），并且可以利用机械臂的**冗余零空间**做副作用很小的次级目标——例如让腕部相机持续看向目标、主动增加视差以降低检测不确定度。代价是：关节空间直线不等于任务空间直线，漂移与证据陈旧性必须在关节构型空间重新度量。

**灵感 3（两者耦合 → 不确定度驱动的「看—动」联合闭环）**
直觉：检测不确定度高时，正确反应不是硬抓，而是「先看清楚」：用零空间微动改变视角（不破坏任务位姿），同时把块长 K 调短，让下一次检测更早介入。反过来，关节接近奇异或限位时，检测视角会退化、位姿协方差变大，控制器应主动减速。两者共享同一个**不确定度预算** `U_det` 与同一个**证据陈旧窗口**，于是「检测何时可信」与「动作能走多远」被统一成一个联合块长规则；这正是把第 3 轮的「语义—时间放大」进一步压成「感知—控制放大」并加上可检查的上界。

## 1. 研究问题（本轮要回答什么）

- **Q1（检测可信）**：如何把检测输出变成可校准、可审计、可拒绝的证据，而不引入假阳 / 漏检 / 开集幻觉？
- **Q2（关节安全）**：为什么任务空间验证不足？关节空间可采纳性如何形式化，并在动作分块下保持前缀封闭？
- **Q3（耦合）**：检测不确定度与关节冗余能否互为资源——用零空间主动降低不确定度、再用不确定度反过来约束块长，且不破坏主任务？

## 2. 三条设计原则（雏形，正式化见产物区定义 468–487）

**P4 检测证据化（Detection-as-Evidence）**
单帧检测永不直接绑定指代。检测以「共形类别集 + 时间确认 + 空间支撑 + 开集拒绝」四元组进入接地；任一条件不满足或存在多义候选 ⇒ 输出 ⊥，退回默认目标 ι₀。这给出「检测错误不会直接变成执行错误」的类型级隔离。

**P5 关节优先可行性（Joint-Space-First Admissibility）**
任何块先过关节层检查（限位 / 速度 / 加速度 / 扭矩 / 奇异裕度 / 构型连续），再过任务层检查；且任意前缀在关节空间也必须合法。任务空间合法只是必要条件，不是充分条件。

**P6 不确定度导向零空间（Uncertainty-Directed Null Space）**
在任务约束的零空间内优化观测目标（look-at、视差、曝光/距离），以检测不确定度 `U_det` 触发减速、缩短块长与主动重观测；零空间运动必须在关节约束内且不改变主任务。

## 3. 与基线的接口（如何退化）

- 检测器不可用 / 未校准 ⇒ 退回 v4 腕部相机单帧漂移 + `SpatialCert`；
- 共形检测集为空 / 类别未知 / 指代不唯一 ⇒ ⊥ ⇒ 默认 ι₀（等价 v4 接地）；
- 关节模型不可用 / 扭矩估计失效 ⇒ 退回 v4 的 Cartesian `Kinematic-Loop`；
- 零空间观测超预算或逼近奇异 ⇒ 关闭次级目标，只保留主任务；
- 关节层失效 ⇒ 强制 K=1；检测层失效 ⇒ 纯 v4 路径；全部失效 ⇒ InstructGauge v3 ⇒ ToolGauge。

## 4. 预期贡献

1. 一个 `DetectionCert` + 共形类别集 + 跟踪级校准的检测证据口径，把检测假阳压到可声明的覆盖率之下；
2. 一个关节空间可采纳块与前缀封闭截断机制，给出「任务空间 → 关节空间」的安全下降路径；
3. 一个不确定度驱动的零空间主动感知与联合块长规则，把「看」和「动」统一到同一预算；
4. 一条完整可证伪路径：E473–E488 覆盖检测校准、时间确认、开集拒绝、关节约束、奇异裕度、零空间收益、联合块长、退化等价与 50Hz 时序。

## 5. 本轮最大风险

**一句话**：主动感知为了让目标「看得更清」而移动相机，恰好破坏了共形检测所依赖的可交换性 / 同分布假设，使覆盖率可能在最需要时失效；而关节层的扭矩与奇异裕度又依赖不精确的动力学模型，两层保证可能同时出现「名义成立、实际失守」的共振失效。

## 2. 形式化定义（要点）

**定义 468（检测证书 DetectionCert）**
```
DetectionCert_t = (id_t, B_t, M_t, C_α(B_t), s_t^cal, τ_t, q_t^view, Σ_t^pose)
```
其中 `Σ_t^pose` 为位姿协方差估计。约定：`DetectionCert` 只是**证据**，不是绑定结果；任何直接消费 `B_t` 的执行路径都视为违反 P4。

**定义 469（共形检测集）** 给定校准集 `{(B_i, c_i)}` 与非一致性分数 `s(B, c)`：
```
C_α(B) = { c ∈ 𝒴 : s(B, c) ≤ q̂_{1−α} },   q̂_{1−α} = ⌈(n+1)(1−α)⌉/n 分位数
```
在其可交换性成立时 `P(c_true ∈ C_α(B)) ≥ 1−α`。对开集，额外定义 `C_α^open(B) = C_α(B) ∪ {UNKNOWN}`，且 `UNKNOWN ∈ C_α^open` 时禁止绑定。

**定义 470（跟踪级共形校准）** 由于 track 确认使用多帧，样本不再可交换，按 track 状态 `h ∈ {new, confirmed, occluded}` 分层校准：
```
C_α^track(B; h) = { c : s_h(B, c) ≤ q̂_{1−α}^{(h)} }
```
并以 `τ_t ≥ τ_min` 作为「confirmed」的充要条件；`new` 状态禁止绑定。

**定义 471（检测接地 Γ_det）**
```
Γ_det(ℓ, t) = o*  iff  ∃! o : o ∈ C_α^track(B_t^o; h_o) ∧ τ_t^o ≥ τ_min
                     ∧ IoU(B_t^o, Supp(ℓ)) ≥ ε_iou
                     ∧ conf_set_size(o) = 1
             = ⊥   otherwise
```
「唯一性」是硬条件：两个及以上候选即使都高置信也输出 ⊥，避免在歧义下赌一把。

**定义 472（关节空间可采纳块 JA）**
```
JA(C = (q_1…q_K)) ⇔ ∀j:
    q_j ∈ Q_lim
  ∧ |q̇_j| ≤ v_max ∧ |q̈_j| ≤ a_max ∧ |τ_j(q_j, q̇_j, q̈_j)| ≤ τ_max
  ∧ σ_min(q_j) ≥ σ₀
  ∧ ||q_j − q_{j−1}||_∞ ≤ δ_step
```
**定义 473（关节空间前缀封闭）**
```
PrefixClosed_J(C) ⇔ ∀ j ≤ K, JA((q_1…q_j))
```
只有前缀封闭，块才能在奇异 / 限位 / 扭矩告警时二分截断到最后安全前缀，而不是整块盲执行。

**定义 474（检测不确定度场）**
```
U_det(q) = Σ_{o∈Tracked} tr(W_o · Σ_o^pose(q)),   Σ_o^pose(q) = f(q_t^view(q), 视差, 遮挡)
```
`W_o` 为任务相关权重（如被指定为抓取目标的物体权重更高）。视角越差、视差越小、遮挡越重，`U_det` 越大。

**定义 475（零空间观测运动）**
```
q̇ = J⁺(q) ẋ_task + N(q) · k · ∇_q g_view(q),   N(q) = I − J⁺J
```
一阶意义下 `J q̇ = ẋ_task`，次级运动不改变主任务；但二阶漂移与关节限位仍需 `JA` 复核（见引理 65 的边界）。

**定义 476（联合块长规则 K*）**
```
K* = min( K_max,
          ⌊δ_J / (v_max·Δt)⌋,
          ⌊T_stale / Δt⌋,
          ⌊(U_budget − U_det(q_now)) / max(U̇_det, ε)⌋ )
```
四项分别对应关节漂移、证据陈旧、不确定度预算；任一项退化到 1 即退回 v4 的逐步执行。

**定义 477（检测-关节联合证书 DJCert）**
```
DJCert(C) = ( {DetectionCert_t}, q_{1:K}, SpatialCert(C), JViol, DViol )
```
`JViol` 为关节约束违背帧索引，`DViol` 为检测覆盖 / 开集 / 接地失效帧索引；证书可独立重放校验。

```python
# IP-334 DetCert-Builder
class DetCertBuilder:
    def __init__(self, detector, conformal, tracker, alpha=0.1, tau_min=3):
        self.det = detector
        self.cp = conformal          # 分层共形校准表
        self.trk = tracker
        self.alpha = alpha
        self.tau_min = tau_min

    def build(self, frame):
        dets = self.det(frame)                       # 原始检测
        certs = []
        for d in dets:
            track = self.trk.update(d)               # 关联/新建 track
            h = "new" if track.age < self.tau_min else (
                "occluded" if track.occluded else "confirmed")
            cset = self.cp.set(d, h, self.alpha)     # 定义 470：分层共形集
            if "UNKNOWN" in cset:
                cset = set(cset) | {"UNKNOWN"}       # 开集：禁止绑定
            certs.append(DetectionCert(
                id=track.id, box=d.box, mask=d.mask,
                class_set=cset, score=self.cp.calibrate(d),
                age=track.age, view_quality=self._view_quality(d),
                pose_cov=track.pose_cov))
        return certs

# IP-335/336 Track-Conformal + DetGround
def det_ground(ell, certs, alpha, tau_min, eps_iou):
    support = scene_support(ell)                     # 指令期望的空间支撑
    cand = [c for c in certs
            if "UNKNOWN" not in c.class_set
            and c.age >= tau_min
            and len(c.class_set) == 1
            and iou(c.box, support) >= eps_iou]
    if len(cand) != 1:                               # 0 或多义 ⇒ ⊥
        return BOTTOM
    return cand[0].id

# IP-337 JointAdmit
class JointAdmitter:
    def __init__(self, model, q_lim, v_max, a_max, tau_max, sigma0, dstep):
        self.model = model
        self.q_lim, self.v, self.a = q_lim, v_max, a_max
        self.tau_max, self.sigma0, self.dstep = tau_max, sigma0, dstep

    def joint_ok(self, q, qd, qdd):
        if not in_box(q, self.q_lim):            return False
        if max_abs(qd) > self.v:                 return False
        if max_abs(qdd) > self.a:                return False
        if max_abs(self.model.torque(q, qd, qdd)) > self.tau_max: return False
        if self.model.sigma_min(q) < self.sigma0: return False
        return True

    def admissible(self, C):
        q_prev = self.model.q_now()
        for j, q in enumerate(C.q):
            qd  = (q - q_prev) / self.dt
            qdd = (qd - self.qd_prev) / self.dt
            if not self.joint_ok(q, qd, qdd): return False, j
            if norm_inf(q - q_prev) > self.dstep: return False, j
            q_prev, self.qd_prev = q, qd
        return True, len(C.q)                     # 定义 472/473

    def truncate(self, C, j):
        return C.q[:j]                            # 前缀封闭 ⇒ 安全截断

# IP-338 NullSpacePerception
class NullSpacePerception:
    def __init__(self, model, look_at_fn, k=0.2):
        self.model, self.look_at, self.k = model, look_at_fn, k

    def step(self, xdot_task, target):
        J = self.model.jacobian()
        Jpinv = pinv(J)
        g = self.look_at.gradient(target)         # ∂g_view/∂q
        N = np.eye(J.shape[1]) - Jpinv @ J
        return Jpinv @ xdot_task + N @ (self.k * g)

# IP-339 CoupledChunkRule
def coupled_K(K_max, delta_J, v_max, dt, T_stale, U_budget, U_now, Udot):
    return max(1, min(K_max,
                      int(delta_J / (v_max * dt)),
                      int(T_stale / dt),
                      int((U_budget - U_now) / max(Udot, 1e-9))))

# IP-340/341 主闭环（仅盲区异步路径启用增强）
def detectgauge_js(M, s, ell=None):
    # 1) 检测证据
    certs = M.detcert.build(M.wristcam.latest_frame())
    # 2) 接地（失败 ⇒ ⊥ ⇒ 默认目标，等价 v4）
    oid = det_ground(ell, certs, M.alpha, M.tau_min, M.eps_iou)
    iota = M.default_iota if oid is BOTTOM else M.nlib.bind(oid, ell)
    # 3) 联合块长
    K = coupled_K(M.K_max, M.delta_J, M.v_max, M.dt,
                  M.T_stale, M.U_budget,
                  U_det(M.env.q(), certs), M.Udot)
    # 4) 关节空间规划 + 可采纳性
    C = M.iplan.plan_joint(iota, K, M.env.q())
    ok, j = M.jadmit.admissible(C)
    if not ok:
        C = M.iplan.plan_joint(iota, 1, M.env.q())      # 退化 K=1
    # 5) 执行 + 双监控
    jviol, dviol = [], []
    for t, q in enumerate(C.q):
        if not M.cvc.joint_pre(q) or not still_grounded(iota, M.env):
            break
        # 零空间主动感知（仅当 U_det 超阈值且不越界）
        if U_det(M.env.q(), certs) > M.U_soft and M.jadmit.joint_ok(*M.nsp_preview(q)):
            q = M.nsp.step(np.zeros(6), iota.target)
            if not M.jadmit.joint_ok(q, M.env.qd(), M.env.qdd()):
                q = C.q[t]                              # 关次级目标
        M.env.apply_joint(q)
        if not M.jadmit.joint_ok(q, M.env.qd(), M.env.qdd()):
            jviol.append(t)
        frame = M.wristcam.latest_frame()
        if not det_still_valid(oid, frame, M.detcert, M.alpha):
            dviol.append(t)
        if len(jviol) > M.viol_thr or len(dviol) > M.viol_thr:
            C = C.truncate(t)                       # 前缀封闭截断
            break
    # 6) 证书与发布
    dj = DJCert(certs, C.q, generate_spatial_cert(C, M.tf_seq(), M.eps_vis),
                jviol, dviol)
    M.ros_cvc.publish_cvc(C.id, len(C.q), C.q, dj)
    return C, dj
```

## 4. 推导

**引理 63（检测覆盖率 → 接地安全性）** 若 `Γ_det` 仅绑定 `C_α^track` 中唯一且 `τ ≥ τ_min` 的候选，则在校准集与测试样本按 track 状态可交换时，误绑定到假阳指代的概率不超过 α。证明：直接由共形覆盖 `P(c_true ∈ C_α) ≥ 1−α` 与唯一性条件取补；多义时输出 ⊥ 只会降低误绑定率。**注意**：该保证在跟踪确认与主动视角变化下不再自动成立，需定义 470 的分层校准，否则 α 失效（见引理 68 的边界）。

**引理 64（关节严格强于任务空间）** `JA(C) ⇒ FK(C.q)` 是任务空间合法位姿序列；反之不成立。反例：两个 IK 分支给出同一末端位姿，但关节构型在分支间跳变，末端无位移而关节速度越限。证明：`FK` 是连续映射，`JA` 逐点约束经 `FK` 传递；反向由 IK 非唯一性与限位约束直接构造。

**引理 65（零空间观测的一阶任务保持）** 在 `N = I − J⁺J` 下，任意次级运动 `N k ∇g` 满足 `J(N k ∇g) = 0`，故一阶 `J q̇ = ẋ_task`。证明：`JN = J − JJ⁺J = 0`（`J⁺` 为 Moore–Penrose 伪逆）。**边界**：二阶项、离散积分误差与关节限位仍需 `JA` 复核，不能只靠一阶结论。

**引理 66（联合块长界）** 若 `|q̇| ≤ v_max`、`U̇_det ≤ U̇_max`，取 `K = K*`（定义 476），则块内关节漂移 ≤ `δ_J`、证据年龄 ≤ `T_stale`、不确定度 ≤ `U_budget`。证明：三项分别由 `K·v_max·Δt ≤ δ_J`、`K·Δt ≤ T_stale`、`U_now + K·U̇_det·Δt ≤ U_budget` 得到；取最小即同时成立。误差随 K 线性累积，这是相对第 3 轮「无界放大」的关键改进。

**引理 67（退化等价性）** 关闭检测增强时，`Γ_det ≡` v4 的单帧漂移接地；关闭关节增强时，`JA ≡` v4 的 Cartesian `Kinematic-Loop`；两者都关闭时 `DJCert` 退化为 v4 `SpatialCert`。证明：逐项核对定义 471/472/477 在增强项置空后的表达式。

**引理 68（校准失效边界）** 若主动感知改变视角分布使测试与校准不再同分布，则 `C_α^track` 的名义覆盖可能低于 `1−α`；覆盖缺口上界为两分布间 TV 距离。证明：共形覆盖依赖可交换性，分布偏移下覆盖误差由总变差距离控制（标准结果）。这解释了为何需要「不确定度预算 + 在线接受检验」而不能只信离线校准。

## 8. 本轮最大风险

**一句话**：主动感知为降低检测不确定度而有意改变相机视角，正是对共形校准「可交换性」的主动破坏——覆盖率可能在我们最依赖它的闭环阶段悄悄下滑；同时关节层的扭矩与奇异裕度依赖辨识模型，模型误差会让「名义可采纳」的块在实际执行中越界，两层保证可能在同一次「看—动」耦合中同时失守。缓解手段是在线接受检验、双模型（解析 + 学习）扭矩包络与保守 `σ₀`，但都会削弱本轮的时序与灵活度收益。
