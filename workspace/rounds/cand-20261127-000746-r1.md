## 1. 直觉与动机

**灵感 1（自监督学习 → 3.2 万条轨迹不只是示范，更是一个无标注的物理世界语料）**
直觉：行为克隆只用了 `(o,a)` 的监督信号；但 4 路相机、32 任务、169 小时里还藏着三类无标注结构——(a) 哪些视觉变化与任务无关（背景/杂物/外观），(b) 任务进行到哪一步，(c) 给定动作世界会怎么变。这三类结构恰好对应五轴泛化的干扰轴、步骤分和接触预测。SSL 让我们在**表征层**学到「任务相关 vs 干扰」的不变性，而不是在第 1 轮那样直接在像素层赌增广不破坏语义——**把风险从数据域转移到损失函数域**。
核心反直觉点：**泛化不是「见更多数据」，而是「学会忽略什么」；不变性是对比出来的，不是增广出来的。**

**灵感 2（力矩控制 → 没有力传感器，但力矩是「命令与现实的差」）**
直觉：接口不给力矩，可力矩并不神秘——它就是「我让关节去哪」与「关节实际在哪」之间的差所对应的广义力。位置控制下，跟踪误差 × 控制器刚度 ≈ 外部接触力；这个残差每一步都在观测流里，免费。于是「力矩控制」落成两件事：(i) 用跟踪误差 + 逆动力学（或数据驱动 ARX）做**无传感器接触/扰动估计**；(ii) 用估计出的接触**整形下发的目标位置**（接触时让目标"软"下来、顶住时停止推进），在只能发位置的前提下等效出变阻抗/导纳。
核心反直觉点：**在只能发位置的接口上，"力矩控制"不是去要力矩指令，而是控制"目标位置如何被现实修正"——刚度是参考轨迹的属性，不是增益参数。**

**两者统一**：SSL 给出两个「惊奇通道」——视觉潜空间预测残差（世界在视觉上被改写）与本体力矩/接触残差（世界在物理上顶回来）；力矩残差又反过来作为视觉接触预判的**自监督标签**（V2C）。于是第 1 轮散落的 I3/I4/I5/I7 被同一条主线收束：**免费物理信号 → 自监督表征 → 接触/干预事件 → 参考整形与 chunk 规划**。

## 2. 本轮核心洞察：两个免费信号 + 一个闭环

- 信号 A（视觉惊奇）：`s_A = || z_{t+1} - f_af(z_t, a_t) ||_Σ`，由动作条件潜空间前向模型给出。对「物体被移动/滑落」敏感，但会被背景/杂物干扰（由 I1 不变性 SSL 压制）。
- 信号 B（物理惊奇）：`s_B = || ε_t ||_Σ` 或 `|| τ_ext_hat ||`，由数据驱动 ARX 残差 / 跟踪误差 + 逆动力学给出。对「顶住/卡死/人手推」敏感，但不知道"是什么变了"。
- 融合判据：接触起点看 B 在预期阶段上升；人为干预看 A 突增 ∧ B 突变 ∧（可选）手部检测；卡死看 B 持续高 ∧ 进度导数≈0。**三分类（正常/接触/干预）比第 1 轮单靠手部检测更稳。**
- 闭环：B 提供接触标签 → 训练视觉接触预判（V2C）→ 提前预判接触 → 在接触前就降刚度、在 chunk 规划阶段把尾部换成柔顺推进。**这是「自监督学习 × 力矩控制」的乘性收益，而非两者相加。**

## 3. 严谨定义与推导

### 3.1 五轴不变性 SSL（I1 的新内核）
设轨迹 `τ={(o_t,s_t,a_t)}`，`o_t` 为 4 视角图像，`s_t` 为本体状态，`a_t` 为目标关节位置；编码器 `z_t = E(o_t,s_t)`。四个目标：
1. **跨视角预测** `L_cv`：以头部双目预测双腕视角潜变量（InfoNCE），迫使表征 3D 一致，并为接触点定位提供物体中心线索；
2. **干扰不变性** `L_ni`：同一底层轨迹施加不同背景/杂物/外观（仅图像、动作不变）作为正样本，不同任务/阶段为负样本——直接对准泛化轴 2/3/4；
3. **时序进度** `L_tp`：预测时间差/阶段序号/剩余时间，得到进度头（I5）与阶段分类器（也是干预判据里的「Δphase 异常」）；
4. **动作条件前向** `L_af`：`z_{t+1} ≈ f_af(z_t,a_t)`，残差即信号 A。
总损失 `L = Σ λ_i L_i`；**位置泛化（轴 1）仍用第 1 轮的 ee 刚体变换增广**，但在表征层加「相对位姿条件」增强等变性。关键约束：`L_ni` 的负样本必须含「同任务不同阶段」与「相似外观不同任务」，防止把任务相关线索一起抹掉（过度不变）。

### 3.2 无传感器力矩/接触估计（I3 的新内核）
关节动力学：`M(q)q̈ + C(q,q̇)q̇ + g(q) + τ_f(q̇) = τ_act + τ_ext`。
位置控制器（典型 PD）：`τ_act = Kp(q_cmd−q) + Kd(q̇_cmd−q̇)`，`q̇_cmd≈0`。
故 `τ_ext = M q̈ + C q̇ + g + τ_f − Kp(q_cmd−q) + Kd q̇`。
- **物理路线**：用 G1 URDF（pinocchio）算 `M,C,g`；在数据集自由空间段（`τ_ext≈0`）最小二乘辨识 `(Kp,Kd,τ_f)`；速度/加速度由历史栈差分 + Savitzky–Golay 平滑。
- **数据驱动路线（主）**：拟合闭环 ARX/小 MLP `q_{t+1} = f_arx(q_t, a_t) + ε_t`，`ε_t` 即「状态被外力改写的残差」；`s_B = ||ε_t||_{Σ^{-1}}`（马氏距离）。**不需要 URDF 与增益，鲁棒且便宜。**
- **部署近似**：笛卡尔接触代理 `f̂ = J^{-T} τ̂_ext`（或直接由 `q_cmd−q` 经 J 映射），沿运动方向分量 `f_∥ = (f̂·v)/||v||` 为接触力代理；接触分数 `c_t = σ(||f̂||)`。
- **合法性**：仅读取已有观测、仅用公开数据标定，不涉及评测期在线适应（伦理红线内）。

### 3.3 位置级变阻抗/导纳（在只有位置接口时的"力矩控制"）
设 VLA 给出参考 `x_ref(t)`（ee 模式直接是位姿；joint 模式经 IK）。虚拟导纳：
`M_d ẍ + D_d ẋ + K_d (x − x_ref) = f̂`
半隐式离散积分得 `x_cmd`，下发 `x_cmd` 而非 `x_ref`。自由空间 `f̂≈0` → 精确跟踪；接触/顶住 → 目标自动"退让"，等效刚度下降，避免插装卡死。**这是参考轨迹整形（reference governor），不新增模型、不改低层增益，因此对 PR2 最友好。**
稳定性：需 `D_d > 2√(M_d K_d)` 且留延迟裕度；因反应粒度是 `T_a`（F13），导纳带宽必须显著低于 `1/(T_a·33ms)`，否则会自激。

### 3.4 双通道惊奇融合与固定 chunk（I4/I5 的新内核）
`intervene = Hysteresis( s_A>θ_A ∧ s_B>θ_B ∧ (hand ∨ Δphase异常) )`。
- 人手移动物体：`s_A` 突增、`s_B` 可能不变 → 视觉通道单独即可判干预；
- 物体卡住：`s_B` 高、`s_A` 低 → 判接触/卡死而非干预；
- 人手推机器人：`s_A` 与 `s_B` 同时高 → 判干预并让位。
**F13 修正**：不能在一个 chunk 内逐步截断，也不能运行时改 `T_a`。因此 I5 改为「规划时用 V2C 预测接触点，把返回 chunk 的尾部替换为柔顺推进/安全保持」，并全局选小 `T_a`（2–4）；反应粒度 = `T_a` 是硬约束。

## 2. 关键推导

### 2.1 无传感器力矩/接触估计
关节动力学与 PD 控制：
```
M(q)q̈ + C(q,q̇)q̇ + g(q) + τ_f(q̇) = τ_act + τ_ext
τ_act = Kp(q_cmd − q) + Kd(q̇_cmd − q̇),  q̇_cmd ≈ 0
⇒ τ_ext = M q̈ + C q̇ + g + τ_f − Kp(q_cmd − q) + Kd q̇
```
数据驱动主路线（无需 URDF/增益）：
```
q_{t+1} = f_arx(q_t, a_t) + ε_t
s_B(t) = ||ε_t||_{Σ^{-1}}          # 马氏距离，物理惊奇
c_t     = σ(||J^{-T} τ̂_ext||)       # 接触分数（物理路线）
f_∥(t)  = (f̂ · v_t) / ||v_t||       # 沿运动方向的接触力代理
```
标定：自由空间段 `τ_ext≈0`，最小二乘拟合 `(Kp,Kd,τ_f)`；ARX 在自由段残差应显著低于接触段（双路线一致性检查）。

### 2.2 位置级导纳（参考整形）
```
M_d ẍ + D_d ẋ + K_d (x − x_ref) = f̂
离散（半隐式）:
  ẍ_k = (f̂_k − D_d ẋ_k − K_d (x_k − x_ref,k)) / M_d
  ẋ_{k+1} = ẋ_k + dt·ẍ_k
  x_{k+1} = x_k + dt·ẋ_{k+1}
下发 x_{k+1}（ee 模式直接是位姿；joint 模式 IK 后下发关节目标）
```
稳定性：`D_d > 2√(M_d K_d)`；且导纳带宽 `≪ 1/(T_a·33ms)`，否则固定 `T_a` 下会自激。

### 2.3 双通道惊奇判据（带滞回）
```
s_A(t) = || z_{t+1} − f_af(z_t, a_t) ||_{Σ_A^{-1}}     # 视觉惊奇
s_B(t) = || ε_t ||_{Σ_B^{-1}}                          # 物理惊奇
hand(t) = HandDetector(last_frame)
intervene  ⇐  s_A>θ_A ∧ s_B>θ_B ∧ (hand ∨ Δphase异常)
contact    ⇐  s_B>θ_B ∧ s_A≤θ_A   (或 V2C 预测 c_{t+k}>θ_c)
jam        ⇐  s_B>θ_B ∧ |dProgress/dt|≈0 持续 k 步
正常       ⇐  其余
状态迁移带滞回与 TTL；YIELD 返回全 T_a 步安全保持 chunk。
```

### 2.4 SSL 目标
```
L_cv = −log  exp(sim(z_head, z_wrist)/τ) / Σ_j exp(sim(z_head, z_wrist^j)/τ)
L_ni = InfoNCE(正:同轨迹不同背景/杂物/外观; 负:跨任务/跨阶段/相似外观不同任务)
L_tp = CE(phase_bin(z_t)) + ||τ̂_remaining − (T−t)||²
L_af = || z_{t+1} − f_af(z_t, a_t) ||²
L_cs = || g(z_t, s_t) − c_{t+k} ||²                    # V2C
L = λ1 L_ni + λ2 L_cv + λ3 L_tp + λ4 L_af + λ5 L_cs
```

## 3. 关键伪代码

### 3.1 接触观测器（I3）
```python
class SensorlessContact:
    def __init__(self, urdf=None, dt=1/30):
        self.dyn = PinocchioDynamics(urdf) if urdf else None
        self.arx = ARXModel()          # q_{t+1}=f(q_t,a_t)+eps
        self.Kp = self.Kd = self.fric = None

    def calibrate(self, free_eps):
        X, y = [], []
        for q, qd, qdd, qcmd in free_eps:
            tau_id = self.dyn.inverse_dynamics(q, qd, qdd)
            X.append([qcmd - q, -qd, *friction_basis(qd)])
            y.append(tau_id)
        self.Kp, self.Kd, self.fric = lstsq(X, y)

    def estimate(self, q_hist, qcmd_prev):
        q   = q_hist[-1]
        qd  = savgol(q_hist, dt=1/30, deriv=1)
        qdd = savgol(q_hist, dt=1/30, deriv=2)
        eps = self.arx.residual(q_hist, qcmd_prev)          # 主信号
        tau_ext = self.dyn.inverse_dynamics(q, qd, qdd) \
                - (self.Kp*(qcmd_prev-q) - self.Kd*qd + self.fric(qd))
        J = self.dyn.jacobian(q)
        f_hat = pinv(J.T) @ tau_ext
        return eps, tau_ext, f_hat                          # 双路线一致性检查
```

### 3.2 导纳 governor（I3）
```python
class AdmittanceGovernor:
    def __init__(self, Md, Dd, Kd, dt):
        assert Dd > 2*np.sqrt(Md*Kd)
        self.Md, self.Dd, self.Kd, self.dt = Md, Dd, Kd, dt
        self.x = self.xd = None

    def step(self, x_ref, f_hat):
        if self.x is None:
            self.x, self.xd = x_ref.copy(), np.zeros_like(x_ref)
        xdd = (f_hat - self.Dd*self.xd - self.Kd*(self.x - x_ref)) / self.Md
        self.xd = self.xd + self.dt*xdd
        self.x  = self.x  + self.dt*self.xd
        return self.x          # ee 模式直接下发；joint 模式 IK 后下发
```

### 3.3 单服务外层（固定 T_a，I3+I4+I5+I9）
```python
class GuardedPolicy:               # 唯一参赛实体：一个 PolicyService
    def __init__(self, T_a):
        self.T_a   = T_a            # 握手固定，不可运行时改（F13）
        self.vla   = load_wla_lora()
        self.enc   = self.vla.encoder
        self.contact = SensorlessContact()
        self.adm   = AdmittanceGovernor(Md, Dd, Kd, dt=T_a/30)
        self.v2c   = ContactPredictor(self.enc)
        self.prog  = ProgressHead(self.enc)
        self.state = FSM("NORMAL")

    def get_action(self, obs):
        s_A = self.visual_surprise(obs)      # I1 L_af 残差
        eps, tau_ext, f_hat = self.contact.estimate(obs.q_hist, obs.qcmd_prev)
        s_B = mahalanobis(eps)
        if self.state == "YIELD":
            if self.hand.clear(obs) and self.rescan(obs):
                self.state = "NORMAL"
            else:
                return self.safe_hold_chunk()   # 全 T_a 步保持 + 小阻尼
        if intervene(s_A, s_B, obs): self.state = "YIELD"
        x_ref = self.vla.propose_chunk(obs, k=self.T_a)   # 参考轨迹
        c_hat = self.v2c(obs, k=2)                          # 预测接触
        if c_hat > θ_c:                                    # 预烘焙柔顺
            x_ref = self.adm.step(x_ref, f_hat)
        if self.prog.stuck(obs):                           # I5 卡滞
            x_ref = self.safe_recover_tail(x_ref)
        return clip_smooth(x_ref)                          # 动作健康度门禁
```

| 0 接触标定 | ARX 残差 vs URDF 力矩估计；自由段 vs 接触段分离度；增益/摩擦辨识 | 离线数据 + 单任务通道 | 接触段 `s_B` 显著高于自由段（AUC > 0.85）；双路线相关性 > 0.6 |
| 1 SSL 探针 | 逐轴线性探针：背景/杂物/外观分类应掉点，任务/阶段应保持；对比纯像素增广 | 离线 | 干扰轴不变性提升且任务/阶段准确率下降 <5pp |
| 2 V2C 预判 | 接触起点检测 F1、提前量 k 与误报率 | 离线 + 单任务通道 | 接触起点 F1 > 0.8；k=2 时提前 ≥2 步 |
| 3 柔顺 A/B | PlugCharger / ZipUp：硬跟踪 vs 导纳整形；卡死率、成功率、步骤分 | 单任务通道 | 族内成功率 +15pp 或卡死率下降 >30% |
| 4 干预 A/B | 人为移动/推机器人：三分类状态机 vs 仅手部检测 | 单任务通道 | 误检冻结率 <2%，恢复成功率 >60% |
| 5 提交门禁 | `T_a × resize × 历史 × 量化` 联合扫描；p99、动作健康度回归 | 本地 stub | 0 拒绝动作；p99 在 `T_a·33ms` 预算内 |

**核心指标**：32 任务平均成功率、平均步骤分、接触段 `s_B` AUC、V2C F1/提前量、柔顺族成功率、误检冻结率、p99 单步延迟、动作健康度。
