# 第 8 轮（本灵感循环第 1 轮）· POSE-ANCHOR：末端位姿是跨真机/仿真的第一性表示

> 检索/复核日期：2026-10-27（UTC）。赛事身份不变：宇树科技 **UniBot 世界挑战赛**（`unibot.unitree.com`），G1 + Dex1、32 项桌面任务、通才单模型赛道、选手自部署 + 官方远程真机 API 评测。按状态文件连续计数是第 8 轮；按这次灵感循环是第 1 轮。本轮三个词是「末端位姿」「机器人」「仿真到现实迁移」。我先说结论：**这三个词指向同一条链——末端位姿是唯一同时充当动作接口、数据标签、跨机器人/跨仿真不变量、失败校验量和数据锚点的量；机器人提供运动学、腕部视角和双腕协调；sim-to-real 最稳的载体不是像素策略，而是位姿标签/位姿漏斗/位姿重放。因此本轮把第 7 轮的"放置优先"从技能层推进到表示层，并把 sim-to-real 从"训 sim 策略"改成"用 sim 产位姿标签 + 用真机 EE 轨迹做标签精确的重放"。**

**本轮最硬的新证据（我现场算的）**：HangCup 的终局右 EE 位姿不是一个单峰分布——单中位数 2cm 覆盖只有 12.9%，但 1-NN 检索 2cm 覆盖 98.7%；留一簇（模拟位置 OOD）1-NN 中位数 1.6cm、p90 3.2cm、5cm 覆盖 99.2%，旋转中位数 6.8°。StackBowls 复现同一模式（单中位数 11.7%、1-NN 98.1%、留一簇 1.6cm/2.9cm、旋转 9.0°）。**终局位姿是一个稠密但多峰的流形；单中位数/单回归不够，检索/几何条件化 + 腕部近场伺服 + 位姿校验才是正确机制。** 这直接决定了本轮的主方法。

## 0. 先复核事实（只写会改变判断的）

### 0.1 规则：320 次真机试次，成功优先、步骤分只做 tie-break

官方手册（[S31][S32]）本轮再次确认：

- 32 个任务，每任务 **10 次**；5 个泛化轴（位置、干扰物、背景、未见物体、人类干扰）每轴 **2 次**；合计 **320 次**真机试次。
- 单次 **180 秒**；超时终止。
- **通才单模型**：一个模型跑全部任务；不允许按任务切模型/切权重。
- 排名：**总平均成功率**第一；成功率相同看**平均步骤分**；再相同看**更早提交**。
- 远程 API：选手自部署推理服务，官方评测机调用；不是把模型交上去。

**含义**：目标是"整条 episode 成功"，不是"多拿步骤分"。步骤分只在成功率打平时才起作用，所以 SSG/谓词/恢复的价值是"提高成功率 + 诊断"，不是"为了步骤分牺牲成功率"。320 次试次的标准误：p≈0.3 时 SE≈2.56pp，95% CI≈±5.0pp；任何小于 ~5pp 的排名差异都可能只是噪声。

### 0.2 数据集：位姿是一等标签，离线重放/重建可行

`unitreerobotics/unibot-v1-challenge-dataset`（[S3]，2026-10-27 复核）：

- 32 个数据集，每个 969–1,530 条，合计约 **33k episodes / 169 小时**；30fps、480×640。
- 四路相机：`head_stereo_left/right`、`wrist_left/right`。
- 字段包含：`observation.state.*_ee_pose_gripper_base`、`*_ee_pose_gripper_torso`、`action.*_ee_pose_gripper_base/torso`（**绝对目标 EE 位姿**）、`state_d435`（头部相机位姿）、`state_torso`、`lower_body` 15 维、夹爪 5.5（开）→0.0（闭）。
- 每条指令 5 条英文复述（`@` 分隔）；HangCup 1,043 条 / 194,564 帧，`lastModified` 2026-10-14。

**含义**：官方数据里同时有"指令目标位姿（action）"和"实际到达位姿（next state）"，可以做动作-状态残差、终局位姿流形、离线重放和 3DGS 重建；这是本轮所有离线实验的基础。

### 0.6 本轮离线小实验：终局位姿是稠密多峰流形（中心证据）

我在官方数据上做了两个任务、四个量的计算（[S3][S33][S34]；脚本为临时分析，不依赖外部数据）。HangCup 的"活跃手"按终局夹爪判断：右 3.36、左 4.49（范围 5.5 开→0 闭），右腕更像持杯/释放手；StackBowls 双手终局夹爪 4.08/3.93（都接近开），表中取右手。

怎么读这张表：

1. **单中位数不够**：只覆盖 12–13% 的终局位姿（2cm 内）；终局位姿不是一个"平均点"，而是随杯/碗/杯架位置变化的多峰流形。
2. **检索够密**：同分布 1-NN 覆盖 98–99%（2cm 内），说明演示库对终局位姿流形覆盖得很密；K 近邻漏斗是可行的。
3. **留一簇是位置 OOD 的粗代理**：把终局位姿聚成 8 簇、整簇留出，再用其余簇做 1-NN；中位 1.6cm、p90 2.9–3.2cm、5cm 覆盖 99%。也就是说，**即使新位置落在演示没覆盖的簇，最近的演示通常也在 2–3cm 内**；腕部近场伺服可以补最后 2–3cm。
4. **旋转仍需伺服**：留一簇 1-NN 的旋转中位 6.8–9.0°、p90 12.9–17.2°；10° 内只有 59–78%。检索给的是"接近正确"的初始位姿，最后的朝向必须靠腕部视觉伺服/接触修正。
5. **控制残差真实存在**：action 是目标、next state 是到达；z 轴 MAE 1.1–1.4cm，rpy 2.3–4.6°。终局放置不能开环发一个目标就完事；需要 PRC（位姿残差校准）/PAV（位姿校验）。
6. **头部视角视差小**：HangCup 的 D435 位姿标准差只有 ~6.7/3/2mm，单 episode 头部相机几乎不动；3DGS 不能指望单 episode 的头部视差，必须用立体基线 + 腕部相机 + 多 episode 场景多样性。躯干 xyz 不动，base 系已经够用；RSEA 的价值在"相对动作不变性"，不是 torso 归一化。

**结论**：终局位姿是闸门，但"单点回归/单中位数"是错的表示；正确表示是"检索/几何条件化的多峰漏斗 + 腕部近场伺服 + 位姿校验 + 控制残差校准"。这正是本轮 POSE-ANCHOR 的核心。

### 0.7 仿真到现实的证据：位姿载体比像素策略稳

- VIRAL：G1 上视觉 sim-to-real 零样本（[S18]）；GR00T 有 G1 sim-first 工作流（[S21]）；说明 G1 的仿真链路可用，但都是"仿真训策略"路线，不是本赛的 32 任务。
- RoboSplat：3DGS 新视角演示，one-shot 87.8% vs 真实+2D 57.2%（[S16]）；RoboSimGS：3DGS+mesh 的 Real2Sim2Real 混合表示（[S17]）。说明 3DGS 可以做数据放大器，但视觉保真不等于行为保真。
- OASIS：SE(3) 末端轨迹预测对齐观测-动作，OOD 增益（[S12]）；"Rethinking VLA Scaling"：EEF 相对动作空间优于绝对（[S13]）；"Translation as a Bridging Action"：相对 6D EEF 对相机位姿不变（[S14]）；Rho：chunk 相对 delta EEF（[S15]）。说明相对位姿表示是跨相机/跨机器人不变性的正解。
- 结论：**sim-to-real 的主载体选位姿，不选像素策略**；仿真用来产位姿标签/漏斗/重放，不用来训一个 sim 策略再赌迁移。

## 1. 三个词各自指什么

### 1.1 末端位姿（EE pose）：动作、标签、不变量、校验量、锚点、检索键

末端位姿在本赛有六个身份，缺一不可：

1. **动作接口**：API 的 `ee` 动作空间就是绝对目标 EE 位姿（base 系）；`joint` 与 `ee` 互斥。选 `ee` 可以把"动作"直接放在任务空间，避开 7-DoF 关节冗余和左右臂差异。
2. **数据标签**：官方数据同时有 `action.*_ee_pose_*`（目标）和 `observation.state.*_ee_pose_*`（到达）；终局位姿是成功/失败的直接证据。
3. **跨机器人/跨相机不变量**：相对 SE(3)（当前 EE 系下的 delta）对基座/相机外参变化不敏感；绝对位姿只在 base 系里有意义。OASIS/Relative EEF/Translation as Bridging Action/Rho 都指向这一点（[S12][S13][S14][S15]）。
4. **失败校验量**：终局是否到位、是否稳定、夹爪是否释放，都可以用位姿 + 夹爪 + 短时稳定性判定；不需要像素世界模型。
5. **数据锚点**：PR2S 重放真机 EE 轨迹时，动作和标签是精确的；sim 只换外观/几何，不改行为。
6. **检索键**：终局位姿流形 + 场景几何码可以做 K 近邻；本轮离线实验证明 1-NN 覆盖 98–99%（同分布）、留一簇 1.6cm 中位（OOD 代理）。

**为什么不是关节**：关节动作要跨 7-DoF 冗余、左右臂、腰部姿态；绝对关节角对初始构型敏感；EE 动作直接对齐任务空间，且官方数据有绝对 EE 标签。
**为什么不是像素**：像素世界模型（DreamZero 14B/7Hz，[S19]）推理慢、像素误差不等于米制误差；本赛 180s/任务、远程 API，主策略要快、要米制。
**为什么是相对**：相对 SE(3) 让"抓-移-放"的局部几何在相机/基座变化下保持；绝对位姿只作为输出层的锚。

### 1.2 机器人（G1 + Dex1）：运动学、腕部视角、双腕协调、控制残差

- G1 双臂 7-DoF、Dex1 1-DoF 夹爪、腰部/头部；桌面任务、基座固定、180s。EE 动作空间是 6D 位姿 + 夹爪；`pivot` 共享。
- **腕部相机是近场精度的来源**：腕左/腕右随臂运动，给终局 2–3cm 的近距离视角；头部 D435 在 HangCup 里几乎不动（std ~6.7mm），不能单靠头部视差。WCP（腕部近场伺服）就是用腕部相机做末端-目标对齐。
- **运动学孪生**：URDF + 关节状态 → 正运动学/IK/可达性/碰撞过滤；不需要高保真渲染。它把"检索到的终局位姿"过滤成"G1 真能到的位姿"，并给 WCP 提供相机外参（腰部/头部）。
- **双腕协调**：按任务语义/视频初判，约 7 个任务可能需要双手或明显受益于双腕（T18/T23/T27/T28/T29/T31/T32；需真机确认）；BSCP 用相对 SE(3) 约束双手，而不是让两只手各自回归。
- **控制残差**：action→next state 的 z 误差 1.1–1.4cm、rpy 2–5°；PRC 用数据学一个小残差模型，在输出层补偿。
- **安全**：可达性/碰撞过滤 + 保守速度；远程 API 下不能撞坏设备。

### 1.3 仿真到现实迁移：位姿载体、三层策略、合规开关

本轮的 sim-to-real 不是"在 sim 里训一个策略再迁移"，而是三层：

- **Tier 1（位姿标签/漏斗，无像素）**：用 G1 URDF + 物体尺寸 + 任务几何，在 sim 里算可达性、碰撞、终局位姿漏斗、抓取候选。低风险；不训练像素策略；即使外部数据受限也可用（作为确定性先验/代码）。
- **Tier 2（PR2S：位姿重放 Real2Sim2Real）**：把真机 episode 的 EE 轨迹在 sim 里重放；3DGS/网格只换背景/物体外观；动作/标签精确；用于扩背景/位置/未见物体。中高风险；默认关，合规开关后开。
- **Tier 3（系统辨识/PRC）**：用真机 action-state 残差校准控制/接触参数；只用官方数据。低风险。

**为什么不是 sim RL**：32 任务的接触/柔性/透明物体差异大；sim 的行为保真度不够；sim RL 的样本成本高；本赛要的是"单模型 + 快推理 + 米制精度"，不是 sim 里的最优策略。**为什么 3DGS 只做放大器**：RoboSplat/RoboSimGS 证明新视角有效（[S16][S17]），但视觉保真≠行为保真；PR2S 用真机轨迹保行为，3DGS 只保外观。**合规**：手册没有明确外部数据/仿真数据条款（我抓到的 §2.1 被截断）；默认 PR2S 只做离线分析/不训练，除非确认允许。

## 2. 主判断：POSE-ANCHOR + Easy/Medium 收割

### 2.1 一句话判断

**终局位姿是总闸门；单中位数/单回归不是答案，检索/几何条件化的多峰漏斗 + 腕部近场伺服 + 位姿校验 + 控制残差校准才是答案；sim-to-real 的正确用法是产位姿标签/漏斗/重放，而不是训一个 sim 策略。** 这条判断同时吃了三个灵感词：位姿是表示，机器人是运动学/腕部，sim-to-real 是数据/标签桥。

### 2.2 分数算术：为什么先打 Easy/Medium

| 杠杆 | 算术 | 全局收益 |
|---|---|---:|
| Easy 12/32 = 37.5% | +10pp Easy | **+3.75pp** |
| 任一泛化轴 2/10 × 32 = 64 trials | +10pp 该轴 | **+2.0pp** |
| 终局步（占 39.8% 步骤分，成功闸门） | +10pp 终局 × q（到达率 0.5–0.7） | **+5–7pp** |
| 320 trials 噪声 | p=0.3：SE 2.56pp，95% CI ±5.0pp | 小于 5pp 的差异不可轻信 |
| 占位榜 29.7% 的示意分解 | Easy 56% / Medium 20% / Hard 5% | 6.72+2.4+0.4=9.52 → 29.75% |
| 同上，Easy 提到 70% | 8.4+2.4+0.4=11.2 | **35.0%** |
| 同上，Medium 也提到 30% | 8.4+3.6+0.4=12.4 | **38.75%** |

"56/20/5"只是算术示意，不是真实剖面；它的用途是说明**Easy 的边际收益最大**。在真实榜单未知的情况下，先做"Easy 稳、Medium 终局稳"是风险最低的策略。

### 2.3 头部方案的瓶颈（占位榜的正确读法）

榜是占位的，但模型族是真实的；可以提出可检验的假设：

| 占位名（真实模型族） | 占位成功/步骤 | 已知强项 | 在本赛最可能丢分的地方 | 我们的对策 |
|---|---:|---|---|---|
| MolmoAct2 | 29.7 / 39.0 | 空间动作推理 | 终局米制放置/释放 | GPF + WCP |
| WALL-OSS-0.5 | 28.5 / 38.9 | 4B VLA、20+ 本体、任务进度 | 整条成功/最后一步 | GPF + PAV |
| DreamZero | 27.9 / 37.9 | WAM、零样本动力学 | 14B/7Hz、像素空间、米制位姿 | 混合 VLA + SE(3) 头，不做主策略 |
| Spirit-v1.5 | 25.9 / 34.4 | VLA | 终局放置 | GPF |
| DM0 | 23.5 / 31.7 | 策略学习 | 长程/恢复 | SSG + NRB |
| PI-0.5 | 22.8 / 30.6 | 通才 VLA | 精确 3D | GPF + WCP |
| GigaBrain-0 | 22.6 / 29.5 | 通才 | 放置 | GPF |
| GR00T N1.5 | 20.5 / 28.1 | 人形 VLA | 桌面精度 | 运动学孪生 + WCP |

**假设**：头部模型的语义/泛化不弱，弱在"最后 3cm 的米制放置 + 释放 + 校验"；这正好是位姿表示/漏斗/伺服/校验的战场。**可证伪**：真实榜单发布后，若头部在 Easy 放置任务上已经 >80%，则我们的边际变小，应转向 Medium/Hard 的 insertion/zip；若头部在 Easy 上也只有 50–60%，则收割逻辑成立。

### 2.4 为什么不是"再做一个更大的 VLA"

- 14B WAM 7Hz（DreamZero，[S19]）在 180s/任务、远程 API 下有延迟风险；本赛的瓶颈是米制精度，不是语义。
- 单模型 + 32 任务 + 5 轴，数据/算力有限；6B WLA + LoRA + 位姿头 + 确定性漏斗/伺服/校验，性价比更高。
- 位姿漏斗/伺服/校验是可解释、可调试、可合规开关的；大模型端到端很难定位"为什么最后 3cm 失败"。
- 我们的差异化不是"更大的模型"，是"位姿表示 + 数据锚点 + 近场闭环 + 校验"。

### 2.5 不做什么（本轮明确砍掉）

- 全 32 任务高保真孪生（成本高、保真度不够）。
- 仿真 RL（行为 gap、样本成本）。
- 自由仿真数据（合规未知、视觉 gap）。
- 每任务 LoRA（单模型规则 + 过拟合）。
- 14B WAM 作主策略（延迟/算力）。
- 运行时仿真/MPC（延迟）。
- 布料/拉链/透明物体的全物理仿真（先做几何/位姿近似）。
- 把步骤分当与成功率并列的目标（步骤分是 tie-break）。

### 2.6 与第 7 轮的关系

| 关系 | 内容 |
|---|---|
| 保留 | SSG、ICR-P（原 ICR）、NRB、SVL-P（原 SVL）、GPR-VLA + WLA 底座、TLE/ACP/GF、DebugLoop、运动学孪生 |
| 升级 | PGL → **GPF**（几何条件化多峰漏斗）；SVL → **WCP + PAV**；OPT → **ICR-P 的位姿轨迹检索**；RB → NRB；TCLB → 离线比较；FLEET → 降级 |
| 新增 | **RSEA**（相对 SE(3) 内部动作 + 绝对 EE 输出）、**PR2S**（位姿重放 Real2Sim2Real）、**BSCP**（双腕 SE(3) 协调）、**PRC**（位姿残差校准） |
| 修正 | 步骤分只做 tie-break；占位榜不是真实排名；L2L 降级（外部数据合规未知）；"补最弱轴"改为"终局位姿跨轴" |
| 砍掉 | 全孪生、sim RL、自由 sim 数据、每任务 LoRA、14B WAM 主策略、运行时 MPC、布料/拉链/透明全物理 |

## 3. 失败模型：P1–P7 与位姿空间对策

| 失败模式 | 机制 | 位姿空间对策 |
|---|---|---|
| P1 目标落地错 | 语言/图像→错误槽位/错误物体 | GPF：几何条件化漏斗；2D 锚点/容器系；检索 |
| P2 接近碰撞 | 末端路径撞杯架/桌面/另一臂 | 运动学孪生：可达性/碰撞过滤；先抬后放 |
| P3 朝向错 | 杯柄/插头/拉链朝向不对 | RSEA 相对 SE(3) + WCP 腕部伺服 |
| P4 释放不稳 | 松手太早/太晚、回弹 | GPF 释放位姿 + settle verify + PAV |
| P5 插入/堆叠失败 | 最后 1–3cm 的接触/对准 | WCP 近场伺服 + 接触代理 + 漏斗 |
| P6 无校验 | 假完成、跳步、对象掉落后继续 | PAV：位姿+夹爪+短时稳定+谓词 |
| P7 控制残差（新） | 目标到了但实际差 1–1.4cm（z） | PRC：action-state 残差模型；PAV 复检 |

**关键**：P3/P5 是"最后 3cm/最后 10°"的问题，不是语义问题；P7 是本轮从数据里新发现的"控制层"问题。四者都可以用位姿空间的方法处理，不需要重训一个更大的 VLA。

## 4. 架构：一个 checkpoint + 一个确定性位姿回路

```
语言/多视角 → WLA/GPR-VLA（6B, LoRA）
   ├─ 相对 SE(3) 动作头（RSEA）→ 绝对 EE 位姿 chunk（base 系）
   ├─ 目标/槽位/几何头（GPF）→ 多峰终局位姿 + 2D 锚点 + 不确定度
   └─ 双腕相对位姿头（BSCP，7 个双手任务）
        ↓
运动学孪生（URDF+关节）→ 可达性/碰撞过滤
        ↓
ICR-P：位姿轨迹/几何码检索（K 近邻，缓存）
        ↓
WCP：腕部近场伺服（2–3cm / 5–10°）
        ↓
PAV：位姿+夹爪+短时稳定+谓词校验
   ├─ 通过 → 释放/下一步
   └─ 失败 → 微调/重抓/重试（SSG）
        ↓
PRC：action-state 残差补偿（输出层）
```

**一个 checkpoint**：WLA/GPR-VLA + RSEA/GPF/BSCP 头 + LoRA，全部在同一个权重文件里；ICR-P/运动学孪生/WCP/PAV/PRC 是确定性代码，不是第二个模型。**合规**：训练数据只来自官方 + 允许的 PR2S（开关）；审计时一个 checkpoint + 代码清单。

**推理循环**（每步）：
1. 观测 → 语言/几何码 → ICR-P 取 K 条相似演示的终局位姿/轨迹。
2. VLA 出相对 SE(3) chunk + 目标漏斗 + 不确定度。
3. 运动学孪生过滤不可达/碰撞目标。
4. WCP 用腕部相机把末端伺服到目标（近场）。
5. PAV 校验；通过则释放/下一步，失败则 SSG 重试。
6. PRC 在输出层补偿控制残差。

**为什么这是"系统"而不是"模型"**：本赛的分数来自"整条 episode 成功"，而成功取决于目标、路径、朝向、释放、校验的串联；单靠一个 VLA 的端到端回归很难同时保证米制精度和可恢复性。位姿回路把"语义"和"米制"分开：VLA 负责语义/泛化，几何/伺服/校验负责最后 3cm。

## 5. 仿真到现实：三层，默认保守

### 5.1 Tier 1：位姿标签/漏斗（无像素，低风险）
- G1 URDF + 物体尺寸 + 任务几何 → 终局位姿漏斗、抓取候选、可达性/碰撞。
- 不训练像素策略；只作为确定性先验/代码；即使外部数据受限也可用。
- 风险：物体尺寸/摩擦/质量未知；用官方数据估计/保守参数。

### 5.2 Tier 2：PR2S（位姿重放 Real2Sim2Real，中高风险）
- 真机 episode 的 EE 轨迹在 sim 里重放；3DGS/网格只换背景/物体外观；动作/标签精确。
- 只做 8 个刚性任务（HangCup、StackBowls、FruitCollection、PlacePhotoFrame、PlugCharger、StoreCups、PackBag、OrganizeTools）；不做布料/拉链/透明。
- 先 background-only + mesh 物体；再 3DGS 物体；对齐门（PSNR/SSIM/LPIPS/特征）不过就跳过。
- 数据预算：每任务 2–5k 帧；总 2–4 万帧；与真机 1:0.2–0.3 混合；真实锚定。
- 合规：默认关；确认允许后开；审计时能一键关。

### 5.3 Tier 3：系统辨识/PRC（低风险）
- 用官方 action-state 残差估计控制偏差/延迟；PRC 在输出层补偿；PAV 复检。
- 只用官方数据；不需要 sim。

### 5.4 为什么不是 sim RL
- 行为 gap：接触/摩擦/柔性/透明在 sim 里不准；sim RL 学到的是 sim 的最优，不是真机的最优。
- 样本成本：32 任务 × 5 轴 × 域随机化，算力/时间不够。
- 本赛要的是"单模型 + 快推理 + 米制精度"；位姿标签/重放比 sim RL 更直接。

### 5.5 合规开关
- `external_lab_data`（默认 false）、`sim_training_data`（默认 false）、`pose_prior`（默认 true，确定性先验）、`pr2s_train`（默认 false）、`icr_p_runtime`（默认 true，只读官方数据缓存）。
- 审计输出：一个 checkpoint、数据清单、代码清单、开关状态。

## 6. 风险与未知

| 风险/未知 | 概率/影响 | 缓解 | 停止条件 |
|---|---|---|---|
| 终局位姿漏斗 OOD 间隙 >5cm | 中/高 | WCP 近场伺服；几何条件化；调试槽 | 调试 <5pp 则回退 |
| 腕部手眼标定误差 | 中/高 | 标定 + IBVS；头部 fallback | 伺服误差 >2cm 则关 WCP |
| 控制 z 残差 >2cm | 中/中 | PRC + PAV；慢放 | 残差 >2cm 则重标定 |
| PR2S 视觉 gap/负迁移 | 高/高 | 对齐门；真实锚定；小权重 | 下游 <0 则关 |
| 外部数据/仿真数据被禁 | 中/高 | 默认关；Tier 1 无像素 | 禁用则 PR2S 只离线 |
| 3DGS 重建失败 | 高/中 | background-only + mesh；多 episode | 对齐门不过则跳过 |
| 延迟 p99 >100ms | 中/高 | chunk 4–8；蒸馏；缓存 | >150ms 则减模型 |
| 单模型审计 | 中/高 | 一个 checkpoint；确定性代码 | 不过则砍 ICR/PR2S |
| 统计噪声 | 高/中 | 320 trials；bootstrap；两跑 | CI 跨 0 则不算 |
| 安全/碰撞 | 低/高 | 运动学孪生；保守速度 | 碰撞则停 |

**未知（必须保持）**：
- 外部数据/仿真数据政策（手册 §2.1 截断；未确认）。
- 相机内参/手眼标定是否在评测环境提供（数据集只有 `state_d435`，没有内参）。
- 调试槽的次数/费用/提前期。
- 真实榜单/真实头部瓶颈。
- 官方 reset 分布、测试物体尺寸/摩擦。
- 32 任务的终局位姿是否都像 HangCup/StackBowls 一样稠密（我只验证了 2 个）。

### 0.3 预期收益（可证伪）

- 终局放置成功率 +Δ ⇒ 全局成功率约 +Δ×q（q=到达终局步的通过率，估计 0.5–0.7），且跨 5 个泛化轴同时受益；对照"单轴 +Δ ⇒ +Δ/5"。
- 目标：终局 +10pp ⇒ 全局 +5–7pp；保守目标 +3–5pp。320 trials、p≈0.3 时 SE≈2.56pp，+5pp 约 2 SE，可在计分跑中检出。
- 可证伪点 1：若 T27/T10 调试槽里终局步提升 <5pp，则 GPF/WCP 假设不成立，回退到 SSG+SVL-P。
- 可证伪点 2：若留一簇 1-NN 在更多任务上中位 >5cm，则"检索 + 腕部伺服"不足以覆盖位置 OOD，需回到几何外推/仿真。
- 可证伪点 3：若 PR2S 下游 <0，则视觉 gap/负迁移成立，PR2S 关闭，只保留 Tier 1/3。

### 0.4 与第 7 轮的关系

## 2. 分数算术

### 2.1 目标函数

官方排名是字典序：`成功率` → `平均步骤分` → `提交时间`。因此优化目标是：

```
maximize  E[1(all terminal predicates satisfied)]
subject to  one checkpoint, deterministic code, latency budget
```

步骤分只作为诊断/恢复信号；不为了步骤分牺牲成功。SSG 的谓词/恢复是"提高成功率"的手段，不是"刷步骤分"的手段。

### 2.2 Easy/Medium 收割

| 杠杆 | 算术 | 全局收益 |
|---|---|---:|
| Easy 12/32 = 37.5% | +10pp Easy | **+3.75pp** |
| Medium 12/32 = 37.5% | +10pp Medium | **+3.75pp** |
| 任一泛化轴（64 trials） | +10pp 该轴 | **+2.0pp** |
| 终局步（成功闸门，步骤分 39.8%） | +10pp × q（0.5–0.7） | **+5–7pp** |
| 320 trials 噪声 | p=0.3：SE 2.56pp，95% CI ±5.0pp | <5pp 不可轻信 |
| 占位 29.7% 示意分解 | Easy 56% / Medium 20% / Hard 5% | 29.75% |
| 同上，Easy 70% | 8.4+2.4+0.4=11.2 | **35.0%** |
| 同上，Medium 30% | 8.4+3.6+0.4=12.4 | **38.75%** |

"56/20/5"是算术示意，不是真实剖面；用途是说明 Easy 的边际收益最大、Medium 次之、Hard 最小。真实策略：**先把 12 个 Easy 的终局做稳，再把 12 个 Medium 的终局做稳；8 个 Hard 只做"高价值 + 可迁移"的 T10/T19/T28/T29，不做 T16/T14/T12 的柔性/透明/翻转全物理。**

### 2.3 轴杠杆

- 单轴 +10pp = +2.0pp 全局；终局 +10pp = +5–7pp 全局。**终局跨轴，单轴不跨轴**；这是选择终局位姿的数学理由。
- 5 轴均分意味着"只补一个轴"的边际有限；终局位姿同时改善位置/干扰物/背景/未见物体/人类干扰（因为所有轴最终都要到位）。
- 但终局位姿不能替代"目标识别/语言理解"；P1 仍然是前置。GPF 的几何条件化就是把 P1 和 P4/P5 连起来。

### 2.4 噪声

- 320 trials、p≈0.3：SE=2.56pp；95% CI≈±5.0pp。
- 若要检出 +3pp，需要约 2 跑/更多 trials；若预算只有 320，先追求 +5pp 以上的机制性改进。
- 任务内 10 次、轴内 2 次：单任务/单轴的方差更大；不要用单任务 A/B 下结论。

### 2.5 时间预算

- 180s/任务；HangCup 中位 177 帧 ≈5.9s，StackBowls 281 帧 ≈9.4s；最大 411/584 帧 ≈13.7/19.5s。180s 足够"慢放置 + 2–3 次重试"，但不能做长 deliberation。
- 真实评测含 reset/通讯/视觉；策略本身应 <2s/步、<30s/任务，给 WCP/PAV/重试留余量。

## 3. POSE-ANCHOR 架构

### 3.1 总览

```
语言/多视角 → WLA/GPR-VLA（6B, LoRA）
   ├─ RSEA 相对 SE(3) 动作头 → 绝对 EE 位姿 chunk（base 系）
   ├─ GPF 几何条件化位姿头 → 多峰终局位姿 + 2D 锚点 + 不确定度
   └─ BSCP 双腕相对位姿头（约 7 个双手/双腕受益任务）
        ↓
运动学孪生（URDF + 关节）→ 可达性/碰撞/IK 过滤
        ↓
ICR-P 位姿轨迹检索（几何码 + 相位 + 位姿；K 近邻；缓存）
        ↓
WCP 腕部近场伺服（2–3cm / 5–10°；力/接触代理）
        ↓
PAV 位姿锚定校验（位姿 + 夹爪 + 短时稳定 + 谓词）
   ├─ 通过 → 释放/下一步
   └─ 失败 → 微调/重抓/重试（SSG）
        ↓
PRC 位姿残差校准（action→state 残差；输出层）
```

**一个 checkpoint**：WLA/GPR-VLA + RSEA/GPF/BSCP 头 + LoRA；ICR-P/运动学孪生/WCP/PAV/PRC 是确定性代码/小查表，不是第二个学习模型。单模型合规。

### 3.2 RSEA：相对 SE(3) 动作表示

**动机**：绝对 EE 位姿在 base 系里对初始构型/相机外参/左右臂差异敏感；相对 SE(3) 让局部几何在变换下保持。OASIS/Relative EEF/Translation as Bridging Action/Rho 都支持相对表示（[S12][S13][S14][S15]）。

**表示**：
- 当前 EE 位姿 `T_t = (R_t, p_t)`；
- 动作 `a_t = (Δp_t, ΔR_t, g_t)`，`Δp_t = R_t^T (p_{t+1} - p_t)`，`ΔR_t = R_t^T R_{t+1}`；`g_t` 夹爪；
- 输出层：`T_{t+1} = T_t · ΔT_t`，再转成 API 的绝对 EE 位姿（base 系）；
- 训练：同时监督 `ΔT`（相对）和 `T_{t+1}`（绝对），加一致性损失 `||T_t·ΔT_t - T_{t+1}||`；
- 跨本体/跨相机：相对动作不依赖 base/相机外参；这是 OOD 鲁棒性的来源。

**为什么不是纯绝对**：绝对回归要记住每个场景的 base 坐标；位置/背景轴一变就漂。**为什么不是纯相对**：API 要绝对目标；纯相对会累积漂移；输出层必须锚到绝对。**为什么不是关节**：7-DoF 冗余 + 左右臂差异 + 腰；EE 任务空间更直接。

**风险**：相对动作的误差会累积；用绝对输出 + PAV 复检 + chunk 重置；训练时加绝对锚损失。

### 3.3 GPF：几何条件化位姿漏斗

**动机**：终局位姿是多峰流形（§1.6）；单中位数 2cm 覆盖仅 12–13%，1-NN 98–99%。GPF 用"槽位/容器系/几何码"条件化，输出多峰分布，而不是单点。

**数据**：每条成功 episode 的终局 `T_i = (p_i, R_i)`，夹爪 `g_i`，物体/容器几何码 `c_i`，任务 `τ_i`，阶段 `φ_i`。

**模型**：
```
p(T | c, o, τ) = Σ_i w_i(c, o, τ) · N(T; T_i, Σ_i)
w_i = softmax_i( -||g(c,o,τ) - g_i||^2 / σ^2 ) · 1[τ_i=τ] · 1[φ_i=final]
```
- `g(·)` 是几何码（物体/容器尺寸、槽位、相对位置、2D 锚点）；`o` 是观测特征；
- 输出 top-K 模式 `{T_k, π_k}` + 不确定度 `u = 1 - Σπ_k`；
- 用 `u` 触发"多候选尝试/腕部搜索/重试"；
- 用运动学孪生过滤不可达/碰撞模式；
- 用 `τ`（成功 episode 的稳定时间/释放后位移）过滤"到位但不稳"的模式。

**训练**：混合密度头/扩散头/锚点分类；`L_gpf = -log Σ π_k N(T*; T_k, Σ_k) + λ_u u`；与 RSEA 共享 backbone；只用官方成功 episode（失败 episode 的终局不作为正样本）。

**推理**：
1. 语言/图像 → 任务/物体/容器；
2. 几何码 + ICR-P top-K → 候选终局位姿；
3. GPF 头 refine + 不确定度；
4. 运动学过滤；
5. WCP 伺服到 top-1；失败则 top-2/微调。

**与第 7 轮 PGL 的区别**：PGL 是"槽位→2D 锚点→6D 目标"的阶梯；GPF 是"几何条件化的多峰分布 + 不确定度 + 检索"，显式处理多模态和 OOD。**与 OPT 的区别**：OPT 是 K 条演示的稳健统计；GPF 是学习条件分布 + 检索 + 不确定度。

**风险**：几何码在真实场景难估计；用 2D 锚点/容器系/语言槽位做粗条件，不要求精确 3D 物体位姿；不确定时回退到 WCP 搜索。

### 3.4 WCP：腕部近场伺服

**动机**：检索/GPF 给的是 2–3cm / 5–10° 的初始位姿；最后 2–3cm 需要腕部相机的近场视觉伺服。头部 D435 在 HangCup 几乎不动（std 6.7mm），不能靠头部视差。

**方法**：
- 腕部相机图像 + 目标 2D 锚点/轮廓/杯柄/插头关键点；
- 视觉伺服：`e = (u_c - u*, v_c - v*)`；`ΔT = -λ J^+ e`；`J` 用交互矩阵/学习的光流-位姿雅可比；
- 粗到细：先对齐 2D 中心/尺度，再对齐朝向/边缘，再慢速插入/释放；
- 力/接触代理：电流/关节力矩/夹爪开度；接触后降速/微调；
- 失败检测：误差不收敛/超时/滑移 → 回退 GPF top-2/重抓；
- 头部 fallback：腕部遮挡/标定失败时用头部 + 运动学。

**标定**：手眼标定（腕部相机→EE）；数据集没有内参，需在调试槽/自采数据标定；或用无标定的 2D 对齐（图像空间）先跑通，再升级 3D 伺服。

**为什么不是纯 VLA 端到端**：VLA 的 2D/语义强，但米制 3D 精度弱；WCP 是"最后的 2–3cm"的专用闭环。**为什么不是纯传统 IBVS**：目标关键点/轮廓需要学习/分割；用 VLA 的 2D 锚点 + 传统伺服，分工明确。

**风险**：腕部相机遮挡/光照/标定；用多视图/头部 fallback；伺服增益保守；失败回退。

### 3.5 PAV：位姿锚定校验

**动机**：假完成/跳步/对象掉落后继续是常见失败；终局位姿 + 夹爪 + 短时稳定 + 谓词是最便宜的校验。

**校验**：
```
s = w1·1[||p - p*|| < ε_p] + w2·1[angle(R, R*) < ε_R]
  + w3·1[g in [g_open, g_closed]] + w4·1[stable(Δp, Δg, N frames)]
  + w5·1[predicate(object, container, relation)]
pass if s > θ
```
- `stable`：释放后 N 帧（0.3–0.5s）内末端/物体位移小于阈值；用腕部/头部图像 + EE 位姿；
- `predicate`：SSG 的符号谓词（在槽内/在杯架上/盖子闭合/拉链闭合）；
- 失败动作：微调（WCP 小步）/重抓/重试/放弃；
- 误报/漏报：用调试槽标注校准阈值；PAV 只做"是否继续"，不做"成功"的最终判定（最终由官方）。

**为什么不是像素世界模型**：PAV 只需要位姿/夹爪/短时稳定/谓词；像素世界模型慢、误差不等于米制误差。**为什么不是纯步骤分**：步骤分是 tie-break；PAV 的目标是成功率。

**风险**：物体遮挡/位姿估计误差；用多视图/夹爪/电流；阈值保守；失败时重试而不是硬判成功。

### 3.6 PR2S：位姿重放 Real2Sim2Real

**动机**：sim-to-real 的行为 gap 主要来自"用 sim 训策略"；如果只把 sim 当"换外观/几何的渲染器"，行为由真机 EE 轨迹决定，标签精确，gap 小。3DGS/RoboSimGS/RoboSplat 证明新视角/真实感数据有效（[S16][S17]），但视觉保真≠行为保真；PR2S 把二者分开。

**流水线**：
1. 选 8 个刚性任务：HangCup、StackBowls、FruitCollection、PlacePhotoFrame、PlugCharger、StoreCups、PackBag、OrganizeTools；
2. 每个任务重建 2–3 个场景：真机 episode 的首帧/多帧 → 3DGS 背景；物体用 mesh/3DGS；
3. 在 sim 里重放真机 EE 轨迹（`action.*_ee_pose_*` + 夹爪）；物体按轨迹被"脚本化附着/释放"；动作/终局标签精确；
4. 渲染新视角：背景替换、物体位置/颜色/纹理扰动、光照/相机扰动；不改变轨迹/接触时序；
5. 对齐门：渲染 vs 真机的 PSNR/SSIM/LPIPS/特征距离；不过则跳过该场景；
6. 数据配比：真机 1 : PR2S 0.2–0.3；真实锚定；小学习率/低权重；
7. 下游评测：只加背景/位置/未见物体轴；不做人类干扰（NRB 负责）；
8. 合规开关：默认关；确认允许后开；审计时可一键关。

**为什么只做 8 个刚性任务**：布料/拉链/透明/柔性物体的物理/渲染误差大；先做"位姿+刚体"最稳的场景。**为什么不是自由 sim 数据**：随机场景的视觉 gap/标签噪声大；PR2S 用真机轨迹保行为。**为什么不是 3DGS 全身/全场景**：单 episode 头部视差小（§1.6）；先 background-only + mesh，逐步加 3DGS 物体。

**风险**：3DGS 重建失败/视觉 gap/负迁移；对齐门 + 小权重 + 真实锚定 + 下游 A/B；不过则关。

### 3.7 BSCP：双腕 SE(3) 协调

**动机**：约 7 个任务可能需要双手/双腕（T18/T23/T27/T28/T29/T31/T32；需真机确认）；两手各自回归容易"各做各的"。

**表示**：
- 相对位姿 `T_rel = T_left^{-1} T_right`；动作同时预测 `ΔT_left, ΔT_right, ΔT_rel`；
- 约束 `||T_left·ΔT_left · (T_rel·ΔT_rel)^{-1} - T_right·ΔT_right||`；
- 共享夹爪/阶段 token；一只手稳定/另一只手操作的角色由任务头预测；
- 训练数据：双手任务的同步帧；单臂任务不启用 BSCP（mask）。

**风险**：双手任务少/标注少；用相对约束 + 单臂预训练 + 少量双手微调；不过则回退独立双臂。

### 3.8 PRC：位姿残差校准

**动机**：action 是目标、next state 是到达；HangCup z 差 1.1–1.4cm、rpy 差 2–5°；终局开环会偏。

**方法**：
- 残差 `δ = T_target^{-1} T_next`（SE(3)）；按任务/手/高度/负载统计；
- 小模型 `δ_hat = f(state, target, hand, gripper)`（MLP/查表）；训练用官方 action-state 对；
- 推理：`T_cmd = T_target · δ_hat^{-1}`；clip 到安全范围；PAV 复检；
- 延迟补偿：估计 action→state 的延迟（1–2 帧），对齐；chunk 内用同一残差；
- 只做输出层校准，不改 VLA；可与 WCP 叠加（WCP 闭环为主，PRC 前馈为辅）。

**风险**：残差随负载/接触变化；用本体感知/夹爪/高度条件；保守 clip；PAV 兜底。

### 3.9 集成：SSG / ICR-P / SVL-P / NRB

- **SSG**：官方 `score_steps` → 谓词状态机；每步的进入/完成谓词；防跳步/假完成；与 PAV 共享谓词。
- **ICR-P**：键 = `(task, geometry code, phase, pose)`；缓存视觉/几何编码；HNSW top-K；延迟 <10ms；只读官方数据缓存（合规）。
- **SVL-P**：settle-verify：伺服→缓放→稳定性校验→微调/重抓/重试；与 PAV 合并实现。
- **NRB**：官方 `human_1_note`/`human_4_note` → 破坏/恢复对；训练恢复策略；推理用 PAV 触发恢复。
- **DebugLoop**：平台不计分单任务调试槽（T27/T10/T07/T21/T01）；A/B；日志；发布门。
- **TCLB**：离线相对比较（仿真/回放），不作为真机替代。

### 3.10 模型架构比较：VLA / WAM / 混合

| 架构 | 强项 | 本赛弱项 | 我们的用法 |
|---|---|---|---|
| VLA（WALL-OSS/PI/GR00T/WLA） | 语义、泛化、快、多任务 | 米制 3D/最后 3cm | 主干（WLA/GPR-VLA） |
| WAM（DreamZero 14B/7Hz） | 动力学、零样本 | 延迟/算力/像素空间 | 离线评估/数据，不做主策略 |
| 混合（本方案） | VLA + SE(3) 头 + 位姿回路 | 集成复杂度 | 主方案 |
| 位姿世界模型（可选） | 预测 EE/物体位姿 | 需要标签/数据 | PAV/GPF 的辅助，不做像素世界模型 |

**结论**：本赛的瓶颈是"米制精度 + 整条成功 + 延迟"，不是"语义世界知识"；混合架构比纯 WAM 更匹配。

## 4. 数据引擎

### 4.1 TLE：任务-语言-几何标签

- 相位分割：抓取/移动/对准/释放/恢复；用夹爪/EE/物体状态/步骤谓词；
- 位姿标签：每帧 EE 位姿、终局位姿、相对动作、action-state 残差；
- 接触/稳定：夹爪开度、EE 速度、物体位移、释放后稳定窗口；
- 几何码：物体/容器尺寸、槽位、相对位置、2D 锚点、任务阶段；
- 语言：5 条复述 + 步骤文本 + 官方 human/unseen 备注；
- 输出：训练样本（相对动作、终局位姿、几何码、阶段、谓词、恢复对）。

### 4.2 GPF 库

- 每任务成功 episode 的终局位姿 + 夹爪 + 几何码 + 稳定时间；
- 按任务/物体/容器/位置聚类；每簇的均值/协方差/权重；
- 真实库 + PR2S 库（可选，权重小）；ICR-P 的键/缓存；
- 质量门：只收成功/稳定/无碰撞的终局；失败终局不进正样本。

### 4.3 PR2S 数据预算与 QA

| 项 | 预算/门 |
|---|---|
| 任务数 | 8 个刚性任务 |
| 场景/任务 | 2–3 个（background-only + mesh；可选 3DGS 物体） |
| 帧/任务 | 2–5k；总 2–4 万帧 |
| 与真机配比 | 1 : 0.2–0.3 |
| 对齐门 | PSNR/SSIM/LPIPS/特征距离；不过则跳过 |
| 标签 | 来自真机轨迹；不重新规划 |
| 下游门 | 背景/位置/未见物体轴 +2pp 才保留 |
| 合规 | 默认关；确认后开；审计可关 |

### 4.4 ICR-P

- 键：任务 + 几何码 + 相位 + 当前 EE 位姿；值：终局位姿/轨迹片段/恢复动作；
- 编码：视觉/几何编码缓存；HNSW/FAISS；top-K=5–10；
- 延迟：<10ms；CPU/GPU 均可；失败回退 GPF 先验；
- 合规：只读官方数据缓存；不做跨选手数据共享。

### 4.5 NRB

- 官方 human 备注：`human_1_note`、`human_4_note`；unseen 备注；
- 构造：破坏（移动/撤销/遮挡）→ 恢复（重抓/重放/重试）；
- 训练：恢复策略/PAV 触发；不追求完美物理，只追求"能恢复"；
- 评测：人类干扰轴 2 次/任务；用官方备注忠实回放。

### 4.6 数据配比与合规

- 真机官方数据：100%（基础）；
- PR2S：0–30%（开关；默认 0）；
- NRB：5–10%（恢复对）；
- 每任务/每轴平衡；Easy/Medium 加权；Hard 不超配；
- 单模型：所有数据进同一个 checkpoint；不按任务切 LoRA；
- 审计：数据清单/来源/开关/权重。

## 5. 训练配方

### 5.1 底座与 LoRA

- 底座：WLA-1.0-Base 6B（Apache-2.0，24GB 可微调）（[S25]）；
- LoRA：rank 64/alpha 128（视觉/语言/动作层）；动作头/GPF 头/BSCP 头全参；
- 视觉编码器：冻结或低秩；动作头：新初始化；
- 单 checkpoint：合并 LoRA + 头；导出 TorchScript/ONNX（如需要）。

### 5.2 损失

```
L = L_flow/action + λ1 L_se3 + λ2 L_abs + λ3 L_gpf
  + λ4 L_rel + λ5 L_dom + λ6 L_ctx + λ7 L_anchor + λ8 L_bimanual + λ9 L_residual
```

- `L_flow/action`：动作 chunk（相对 SE(3) + 夹爪）；
- `L_se3`：未来 EE 轨迹预测（OASIS 式，[S12]）；
- `L_abs`：绝对 EE 输出一致性（`T_t·ΔT_t` vs `T_{t+1}`）；
- `L_gpf`：混合密度/扩散终局位姿 NLL + 不确定度校准；
- `L_rel`：相对动作一致性（相机/基座扰动下的不变性）；
- `L_dom`：真实/PR2S 特征对齐/域分类（小权重）；
- `L_ctx`：ICR-P 检索上下文的一致性（同任务/同几何码）；
- `L_anchor`：2D 锚点/槽位辅助；
- `L_bimanual`：双腕相对位姿约束；
- `L_residual`：PRC 残差回归（可单独训练）。

### 5.3 课程

1. 官方数据 baseline（WLA/GPR-VLA + RSEA）；
2. 加 GPF 头 + 终局位姿监督；
3. 加 ICR-P/几何码 + 不确定度；
4. 加 WCP/PAV（先仿真/回放，再真机调试槽）；
5. 加 PR2S（开关；8 任务；小权重）；
6. 加 NRB（恢复对）；
7. 加 BSCP（双手任务）；
8. 蒸馏/量化/缓存（延迟）。

### 5.4 算力

| 项 | 估计 |
|---|---|
| 底座微调 | 8×H100，2–3 周（6B + LoRA + 动作头） |
| GPF/头 | 2–3 天 |
| PR2S 重建/渲染 | 3–5 天（8 任务 × 2–3 场景） |
| WCP 标定/调试 | 3–5 天（调试槽） |
| 消融/重训 | 2–3 周 |

### 5.5 超参（起始值）

- LoRA r=64, α=128, dropout 0.05；lr 1e-4（头）/2e-5（LoRA）；
- batch 64–128；bf16；chunk 4–8；horizon 1–2s；
- GPF：K=8–16 模式；σ 初值 1–2cm；不确定度阈值 0.3；
- WCP：λ 0.1–0.5；停止 ε=2mm/1°；最大 2s；
- PAV：ε_p=1–2cm；ε_R=5–10°；稳定 0.3–0.5s；θ 由调试槽校准；
- PRC：MLP 2×256；残差 clip ±2cm/±5°。

## 6. 实验设计

### 6.1 离线

1. **终局位姿漏斗**：单中位数 vs 1-NN vs 留一簇；平移/旋转覆盖；32 任务（先 8 个刚体）；目标：留一簇 1-NN 中位 ≤2cm、5cm 覆盖 ≥95%。
2. **action-state 残差**：按任务/手/轴；PRC 的均值/方差/增益；目标：z 残差降低 ≥30%。
3. **WCP 回放**：在仿真/回放里测伺服收敛；目标：2–3cm 内收敛率 ≥90%，时间 ≤2s。
4. **PAV**：失败检测 F1；目标 ≥0.7；误报 ≤10%。
5. **PR2S 对齐**：PSNR/SSIM/LPIPS/特征；目标 ≥90% 场景过门。
6. **ICR-P 检索**：top-K 命中率/延迟；目标 top-5 命中 ≥90%，<10ms。

### 6.2 仿真

- 8 个刚性任务；每任务 50–100 trials；成功/终局稳定/时间；
- 与真机调试槽的相关性；只做相对比较，不做绝对排名；
- PR2S 数据训练 vs 真机数据训练的 A/B；目标：背景/位置轴 +2pp。

### 6.3 真机调试槽

- 任务：T27 StackBowls、T10 PlugCharger、T07 PlacePhotoFrame、T21 ArrangePlates、T01 HangCup；
- A/B：baseline（WLA+GPR-VLA）vs +GPF vs +GPF+WCP vs +GPF+WCP+PAV vs +PRC；
- 每任务 5–10 次；记录终局位姿/夹爪/成功/时间/失败模式；
- 目标：终局步 +10pp；无回归；延迟 p99 <100ms。

### 6.4 计分跑

- 320 trials；两跑（如预算允许）；bootstrap 95% CI；
- 记录每任务/每轴/每步骤；失败模式分类；
- 目标：+3–5pp 全局；Easy/Medium 优先；Hard 不回归。

### 6.5 消融

| 消融 | 变量 | 预期 |
|---|---|---|
| 动作表示 | 绝对 EE vs 相对 SE(3) | 相对 +2–4pp OOD |
| 终局表示 | 单点/均值 vs GPF vs GPF+ICR-P | GPF+ICR-P +3–5pp 终端 |
| 伺服 | 无 WCP vs WCP | WCP +5–8pp 终端 |
| 校验 | 无 PAV vs PAV | PAV +2–4pp 成功 |
| 残差 | 无 PRC vs PRC | PRC +1–2pp 终端 |
| PR2S | 0% vs 20–30% | +1–3pp 背景/位置（或负迁移） |
| BSCP | 独立双臂 vs BSCP | +2–5pp 双手任务 |
| SE(3) 辅助 | 无 vs 有 | +1–3pp OOD |
| chunk | 4 vs 8 vs 16 | 延迟/成功率权衡 |
| 分辨率 | 480×640 vs 下采样 | 延迟/精度权衡 |

### 6.6 Go/No-Go

| 门 | 条件 | 不过怎么办 |
|---|---|---|
| G1 漏斗 | 8 任务留一簇 1-NN 中位 ≤2cm、5cm ≥95% | 扩大检索/几何条件；否则回退 |
| G2 WCP | 终局误差 -30% | 回退头部/2D 对齐 |
| G3 PR2S | 对齐 ≥90%、下游 +2pp | 关闭 PR2S |
| G4 PAV | F1 ≥0.7 | 只用谓词 |
| G5 BSCP | 双手任务 +5pp | 回退独立双臂 |
| G6 调试 | 终局 +10pp | 转 Medium/Hard 或回退 |

| W4 | PR2S v0（8 任务）；对齐门；数据配比 | PR2S 数据；对齐报告 |
| W5 | 训练 E1–E3；调试 #3；PR2S 下游 | 模型 E3；A/B |
| W6 | BSCP + NRB；训练 E4–E6；调试 #4；计分 #1 | 模型 E6；计分 #1 |
| W7 | 迭代；全量数据；计分 #2 | 最终模型；计分 #2 |
| W8 | 冻结；模型卡；审计包；提交 | 提交 |

### 7.2 里程碑

- M1（W2）：GPF 漏斗离线达标；否则改表示。
- M2（W3）：WCP/PAV 在调试槽有效；否则回退。
- M3（W5）：PR2S 下游非负；否则关。
- M4（W7）：计分 +3–5pp；否则保 baseline。
- M5（W8）：冻结/提交。

### 7.3 压缩

- 若赛程 <8 周：W1–W3 必做；PR2S 降为"离线可行性"；BSCP 降为"双手任务微调"；NRB 只做官方备注回放。
- 若调试槽不可用：用离线回放 + 仿真相对比较；降低对 WCP/PAV 的承诺。

## 8. 风险、合规、审计

### 8.1 风险表

| 风险 | 概率/影响 | 缓解 | 停止条件 |
|---|---|---|---|
| 终局漏斗 OOD 间隙 >5cm | 中/高 | WCP；几何条件；调试槽 | 调试 <5pp 回退 |
| 腕部标定误差 | 中/高 | 标定/IBVS；头部 fallback | 伺服 >2cm 关 |
| 控制 z 残差 >2cm | 中/中 | PRC + PAV；慢放 | >2cm 重标定 |
| PR2S 负迁移 | 高/高 | 对齐门；真实锚定；小权重 | 下游 <0 关 |
| 外部数据被禁 | 中/高 | 默认关；Tier 1 无像素 | 禁用则只离线 |
| 3DGS 失败 | 高/中 | background+mesh；多 episode | 对齐门不过跳过 |
| 延迟 p99 >100ms | 中/高 | chunk 4–8；蒸馏；缓存 | >150ms 减模型 |
| 单模型审计 | 中/高 | 一 checkpoint；确定性代码 | 不过砍 ICR/PR2S |
| 统计噪声 | 高/中 | 320 trials；bootstrap；两跑 | CI 跨 0 不算 |
| 安全/碰撞 | 低/高 | 运动学孪生；保守速度 | 碰撞停 |

### 8.2 合规 YAML

```yaml
compliance:
  external_lab_data: false      # 外部实验室数据：默认关
  sim_training_data: false      # 仿真训练数据：默认关
  pose_prior: true              # 确定性位姿先验/几何：默认开
  pr2s_train: false             # PR2S 训练：默认关
  icr_p_runtime: true           # 只读官方数据缓存：默认开
  single_checkpoint: true       # 单模型：必须
  deterministic_code: true      # 代码清单：必须
  audit_packet: true            # 审计包：必须
```

### 8.3 审计包

- 一个 checkpoint（SHA256）+ 配置文件；
- 数据清单：官方数据集版本/路径/字段；PR2S 开关/权重/帧数；NRB 来源；
- 代码清单：ICR-P/WCP/PAV/PRC/运动学孪生；版本/依赖；
- 训练日志：数据配比/超参/随机种子；
- 评测日志：调试槽/计分跑；失败模式；
- 合规声明：外部数据/仿真数据/单模型/安全。

### 8.4 停止条件

- 调试槽终局 <5pp：GPF/WCP 假设不成立，回退 SSG+SVL-P。
- PR2S 下游 <0：立即关闭。
- WCP 伺服误差 >2cm：关闭，回退头部/2D。
- 延迟 p99 >150ms：减模型/减 chunk/蒸馏。
- 碰撞/安全：停止真机，检查运动学/速度。

## 9. 创新点清单

> 每个点给出：动机、与已有工作的差异、可行性、资源、落地步骤、风险。状态：保留/升级/新增/降级/砍。

### I1 POSE-ANCHOR 核心（押注，新增）
- **动机**：终局位姿是成功闸门（39.8% 步骤分，跨 5 轴）；本轮数据显示它是稠密多峰流形，单点/均值不够。
- **差异**：不是"更大的 VLA"，而是"位姿表示 + 检索/几何漏斗 + 腕部伺服 + 校验 + 残差校准"的系统；把语义和米制分开。
- **可行性**：数据有绝对 EE 位姿/动作/相机位姿；底座 6B 可 LoRA；WCP/PAV 是确定性代码。
- **资源**：8×H100 2–3 周；调试槽 3–5 次；无外部数据也能跑（Tier 1/3）。
- **步骤**：1) 漏斗离线；2) GPF 头；3) WCP/PAV 调试槽；4) PRC；5) 计分。
- **风险**：OOD 间隙/标定/延迟；用门控和回退。

### I2 RSEA 相对 SE(3) 动作表示（升级，新增到动作层）
- **动机**：绝对 EE/关节对相机/基座/初始构型敏感；相对 SE(3) 是跨本体/相机不变量。
- **差异**：OASIS/Relative EEF/Rho 多在通用 VLA/机器人；本赛把它与 GPF/WCP/PAV 组合，输出层锚绝对 EE。
- **可行性**：官方数据有绝对 EE 动作；相对动作可由相邻帧算；WLA 动作头可改。
- **资源**：训练 2–3 周；无额外数据。
- **步骤**：1) 数据转换；2) 相对头 + 绝对锚；3) 一致性损失；4) OOD 消融。
- **风险**：误差累积；绝对锚 + PAV + chunk 重置。

### I3 GPF 几何条件化位姿漏斗（升级 PGL）
- **动机**：终局位姿多峰；单中位数 12–13%（2cm），1-NN 98–99%；需要条件化 + 多峰 + 不确定度。
- **差异**：PGL 是槽位/2D/6D 阶梯；GPF 是学习条件分布 + 检索 + 不确定度 + 运动学过滤。
- **可行性**：官方成功 episode 的终局位姿；几何码可从 2D/语言/容器系粗估；不要求精确物体 3D。
- **资源**：GPF 头 2–3 天；ICR-P 2 天；无外部数据。
- **步骤**：1) 终局库；2) 混合密度/扩散头；3) 几何码/检索；4) 不确定度/过滤；5) 调试槽。
- **风险**：几何码噪声；用 2D 锚点/语言槽位/容器系；不确定时 WCP 搜索。

### I4 WCP 腕部近场伺服（升级 SVL）
- **动机**：检索/GPF 给 2–3cm/5–10° 初始；最后 2–3cm 需要腕部近场；头部 D435 几乎不动。
- **差异**：不是纯 VLA 端到端，也不是纯 IBVS；VLA 出 2D 锚点，传统伺服做米制闭环。
- **可行性**：腕部相机 + EE 位姿 + 夹爪；手眼标定可在调试槽做；无标定可先 2D 对齐。
- **资源**：标定 3–5 天；调试槽 2–3 次；控制代码。
- **步骤**：1) 标定；2) 2D 对齐；3) 3D 伺服；4) 接触/失败检测；5) 调试槽。
- **风险**：遮挡/标定/增益；多视图/头部 fallback/保守增益。

### I5 PAV 位姿锚定校验（升级 SVL-P）
- **动机**：假完成/跳步/掉落后继续；终局位姿+夹爪+稳定+谓词是最便宜的校验。
- **差异**：不是像素世界模型；不是纯步骤分；用位姿/夹爪/短时稳定/谓词做"是否继续"。
- **可行性**：EE 位姿/夹爪/图像/步骤谓词都有；阈值可在调试槽校准。
- **资源**：1–2 天代码；调试槽 1–2 次。
- **步骤**：1) 谓词；2) 稳定窗口；3) 阈值；4) 失败动作；5) 调试槽。
- **风险**：遮挡/位姿误差；多视图/夹爪/电流；保守阈值。

### I6 PR2S 位姿重放 Real2Sim2Real（新增）
- **动机**：sim-to-real 的行为 gap 来自"sim 训策略"；位姿重放把行为交给真机轨迹，sim 只换外观/几何。
- **差异**：不是 sim RL，不是自由 sim 数据；是"真机 EE 轨迹 + 3DGS/mesh 外观"的标签精确数据；只做 8 个刚性任务。
- **可行性**：官方 EE 轨迹/相机位姿/多视角；3DGS/RoboSimGS 工具；单 episode 头部视差小，需多 episode/stereo/wrist。
- **资源**：3–5 天重建/渲染；2–4 万帧；GPU。
- **步骤**：1) 8 任务重建；2) 轨迹重放；3) 外观扰动；4) 对齐门；5) 下游 A/B。
- **风险**：视觉 gap/负迁移；对齐门/小权重/真实锚定/可关。

### I7 BSCP 双腕 SE(3) 协调（新增）
- **动机**：约 7 个任务可能需要双手/双腕；独立回归容易不协调。
- **差异**：相对 SE(3) 约束 + 角色 token；不是简单双手拼接。
- **可行性**：双手任务同步帧；单臂预训练 + 少量双手微调。
- **资源**：2–3 天头 + 微调；无额外数据。
- **步骤**：1) 相对位姿；2) 约束损失；3) 角色 token；4) 双手任务 A/B。
- **风险**：双手数据少；mask/回退独立双臂。

### I8 PRC 位姿残差校准（新增）
- **动机**：action→state z 差 1.1–1.4cm、rpy 2–5°；终局开环会偏。
- **差异**：不是系统辨识全模型；是输出层小残差 + PAV 兜底；只用官方数据。
- **可行性**：官方 action-state 对；MLP/查表；易实现。
- **资源**：1–2 天；CPU/GPU 均可。
- **步骤**：1) 残差统计；2) 小模型；3) 前馈补偿；4) PAV 复检。
- **风险**：负载/接触变化；本体感知/高度条件；保守 clip。

### I9 SSG 评分步骤图门控（保留）
- **动机**：官方步骤/权重公开；终局是成功闸门；防跳步/假完成。
- **差异**：把 `score_steps` 变成谓词状态机；与 PAV 共享谓词。
- **可行性**：32 任务 `info.json`；手写/半自动谓词；调试槽校准。
- **资源**：2–3 天；无额外数据。
- **步骤**：1) 解析步骤；2) 谓词；3) 状态机；4) 防跳步；5) 调试。
- **风险**：谓词误判；PAV 多信号；保守推进。

### I10 ICR-P 位姿轨迹检索（升级 ICR）
- **动机**：终局流形稠密；1-NN 98–99%（2cm）；检索比单回归更稳。
- **差异**：键加入位姿/相位/几何码；值用终局位姿/轨迹片段；缓存/HNSW。
- **可行性**：官方数据；视觉/几何编码；CPU 可跑。
- **资源**：2 天；内存/缓存。
- **步骤**：1) 键设计；2) 建库；3) top-K；4) 延迟；5) 合规。
- **风险**：OOD 键不匹配；GPF 先验/WCP 搜索；只读官方数据。

### I11 NRB 官方备注恢复库（升级 RB）
- **动机**：human 备注给出逐任务破坏剧本；恢复是成功率的一部分。
- **差异**：忠实回放官方备注；不是自造干扰。
- **可行性**：`human_1_note`/`human_4_note`；仿真/真机回放；PAV 触发。
- **资源**：2–3 天；少量数据。
- **步骤**：1) 解析备注；2) 破坏/恢复对；3) 训练；4) 评测。
- **风险**：备注歧义；人工核对；小权重。

### I12 SVL-P 落点稳定校验（保留）
- **动机**：释放后回弹/滑移；短时稳定是最直接的信号。
- **差异**：与 PAV 合并；位姿+夹爪+图像+时间。
- **可行性**：EE/夹爪/图像；阈值调试槽。
- **资源**：1 天。
- **步骤**：1) 稳定窗口；2) 阈值；3) 失败动作。
- **风险**：遮挡；多视图；保守。

### I13 TLE/ACP/GF 数据引擎（保留）
- **动机**：相位/位姿/接触/几何/语言标签是 GPF/ICR-P/WCP/PAV 的燃料。
- **差异**：从第 5/7 轮延续；本轮加入终局位姿/残差/几何码。
- **可行性**：官方数据；脚本；无需外部。
- **资源**：3–5 天。
- **步骤**：1) 相位；2) 位姿；3) 几何；4) 语言；5) QA。
- **风险**：标签噪声；抽检/可视化。

### I14 DebugLoop/TCLB（降级/保留）
- **动机**：真机反馈是唯一可信的；调试槽是不计分单任务。
- **差异**：TCLB 只做离线相对比较；DebugLoop 做发布门。
- **可行性**：平台调试槽；预约。
- **资源**：3–5 次；流程。
- **步骤**：1) 预约；2) A/B；3) 日志；4) 发布门。
- **风险**：槽位不足；离线回放/仿真相对比较。

## 10. 与已有工作的差异

### 10.1 相对 EEF 动作
- OASIS：SE(3) 末端轨迹预测 + 观测-动作对齐（[S12]）；Relative EEF：相对动作空间更鲁棒（[S13]）；Translation as Bridging Action：相对 6D EEF 对相机位姿不变（[S14]）；Rho：chunk 相对 delta EEF（[S15]）。
- 我们的差异：把相对动作与**绝对 EE 输出 + GPF 多峰漏斗 + WCP 腕部伺服 + PAV 校验 + PRC 残差**组合，针对 32 任务/5 轴/180s/单模型；不是单一表示消融。

### 10.2 位姿漏斗/检索
- 第 7 轮 PGL/OPT：槽位/2D/6D + K 演示统计；本轮 GPF/ICR-P：条件分布 + 多峰 + 不确定度 + 运动学过滤 + 位姿轨迹检索。
- 与 distributional relative placement/SE(3)-equivariant ICLR 2024 的区别：我们不用物体 6D 位姿（难估），用 2D 锚点/容器系/几何码 + 终局位姿库；更工程化、可合规。

### 10.3 Real2Sim2Real
- RoboSplat：3DGS 新视角演示（[S16]）；RoboSimGS：3DGS+mesh 混合（[S17]）；VIRAL：G1 视觉 sim-to-real 零样本（[S18]）。
- 我们的差异：**不训 sim 策略**；PR2S 重放真机 EE 轨迹，sim 只换外观/几何；标签精确；只做 8 个刚性任务；对齐门 + 小权重 + 可关。

### 10.4 校验/恢复
- 常见 VLA 无显式终局校验；我们 PAV 用位姿/夹爪/稳定/谓词；NRB 用官方备注恢复；SSG 用步骤图防跳步。
- 差异：不是像素世界模型；不是纯步骤分；以成功率为目标。

### 10.5 对比表

| 方向 | 代表工作 | 我们 |
|---|---|---|
| 相对动作 | OASIS/Relative EEF/Rho | RSEA + 绝对输出 + GPF/WCP/PAV |
| 位姿漏斗 | 第 7 轮 PGL/OPT | GPF + ICR-P + 不确定度 + 运动学过滤 |
| sim-to-real | RoboSplat/RoboSimGS/VIRAL | PR2S 位姿重放（不训 sim 策略） |
| 校验 | 无/像素世界模型 | PAV（位姿+夹爪+稳定+谓词） |
| 数据 | 官方/自由 sim | 官方 + PR2S（开关）+ NRB |
