# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互的不确定性二分闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「语义分割」×「域随机化」）

> R69 把不确定性拆成 aleatoric / epistemic，并让系统学会用「看/问/触」去消解后者。但 R69 有两条**从未写进前提的假设**，它们一旦被击穿，整个 VoI 与校准机制就会悄悄失效：
> - **(A) 不确定性估计在分布内有效**：R69 的模态权重、ECE、流似然、VoI，只在测试观测被训练分布（含域随机化）覆盖时才有意义。它从没问：「我有没有资格计算这个不确定性？」——**一个模型可以先验自信地错在分布外。**
> - **(B) 域随机化是全局、同质、独立的**：DR 通常对纹理、光照、质量、摩擦逐维独立撒点，并假设「覆盖了每个因素」就等于「覆盖了场景」。但真实域差是**语义局部化**的（某个类别、某种材质、某一类接触），且**组合爆炸**（零件都见过，组合没见过）。
>
> 本轮两个灵感正好各击穿一条假设：
> - **语义分割**把「域覆盖」从一张全图 OOD 分数，变成一张**有支撑集的语义覆盖场**：不是「这个场景我熟不熟」，而是「这个段、这条关系、这个组合我熟不熟」；缝隙恰好落在接触、遮挡、支撑这些安全最在意的边界上。
> - **域随机化**把「覆盖」从形容词变成**可测的支撑半径**：它给出的是**有条件的保证**——在校准半径内，R69 的不确定性可信；出了半径，所有保证作废。DR 不是「到处都稳」，而是「知道自己从哪儿开始不稳」。
>
> 核心命题：**把 R69 的 epistemic 再拆成「可解 epistemic」与「无资格 epistemic」；前者才允许交互，后者必须显式降级/拒绝。用语义分割把覆盖测度定位到段与关系（含组合空洞），用域随机化给出有限样本的覆盖证书；覆盖只作否决、不作授权，覆盖债只离线结算。** 命名 **SCOPE-RAS**（Semantic-Compositional Coverage-gated Policy Epistemic-risk）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**这个问题，我到底有没有资格回答**」——不是所有不知道都能靠再问一句解决；有些不知道，只能诚实地说「不在我的世界里」。

## 0. 直觉与动机

**灵感 1（语义分割 → 域覆盖是段与关系的场，不是一张全局分数）**
直觉：R69 的 U_epi 是动作模态级的整体歧义；但机器人出事故，常常不是「要不要抓」选错，而是**在某个局部把「已见过的杯子」放进了一个「没见过的支撑关系」**——杯子本身在 DR 覆盖内，湿玻璃杯放在倾斜光滑桌面上这个**组合**却从未被随机化过。全局 OOD 分数会被大量已覆盖的背景稀释掉，看起来一切正常。语义分割把观测分解为段 V={R_i} 与关系 E={contact, support, containment, adjacency}，覆盖第一次可以被写成 **C(R_i) 与 C(R_i,R_j)**：不是「我熟不熟这个画面」，而是「我熟不熟这个零件、这条关系、这个组合」。而覆盖缺口的最大风险权重，几乎总落在接触/支撑/遮挡边界上——也就是分割最该被信任、却最容易出错的地方。

**灵感 2（域随机化 → 覆盖是一个带半径的条件保证，而不是鲁棒性）**
直觉：DR 常被当成「见过足够多变化 → 部署鲁棒」。更准确的理解是：DR 定义了一个训练支撑 μ_DR；任何统计保证（ECE 校准、流似然、VoI 的后验）都只在测试分布相对 μ_DR 有**有界密度比**时成立。于是 DR 的真正产物不是「鲁棒策略」，而是一张**保证的有效范围**。这把 R69 的姿态反转过来：R69 假设不确定性可算，SCOPE 先检查**算不确定性的资格**。覆盖在支持内是「允许计算」，出了支持是「一切保证作废」——**覆盖天然是安全侧的否决权，而不是行动侧的许可证。**

**灵感 3（组合覆盖 → 独立随机化会把覆盖率吹成指数级虚高）**
直觉：若 DR 对 n 个因素独立撒点、每个因素覆盖概率 1−ε，那么含 m 条独立关系的场景被完整覆盖的概率约 (1−ε)^m。每个零件都「见过」，不代表「零件组合」见过。这是一条简单但致命的算术：**逐因素覆盖率高 ≠ 场景覆盖率高，且差距随关系数指数放大。** 语义分割给出场景图，正是为了把这条乘法显式算出来，并定义「组合空洞」——段都 covered、关系不 covered 的那种最危险状态。R69 的 FMA 第二意见（r_res, Δa）测的是「传感器/行为自洽」，这里补上第三条独立通道 ρ（覆盖密度比），三者联合才能区分「支持内真漂移」「支持外域偏移」「标定被吸收」。

**灵感 4（缺口分型 → 不是所有不知道都能问）**
直觉：把覆盖缺口粗分成四类，处置完全不同：
- **N（nuisance）**：只是纹理/光照/噪声变了，语义和动力学没变。本应被 DR 覆盖；没覆盖是 DR 空洞，可离线补，实时先保守。
- **S（semantic）**：物体类别在本体之外，模型连「表示这个假设」的能力都没有。此时**再问一百次也不会更确定**——后验熵有表示下界 H_min>0；唯一正确的动作是显式说「未知类别，请人类接管」，而不是用最接近的已知类别硬猜。
- **P（physical）**：质量/摩擦/柔顺等动力学参数出了随机化范围。可以用 R69 的安全探针去辨识，**前提是探针本身在安全支持内**。
- **C（compositional）**：段单看都 covered，关系/组合没 covered。只在关系级探针安全时允许交互，否则保守。
「不知道」不是一种状态，而是四种；把它们混成同一个 U_epi 去「问」，正是 R69 最大风险的来源。

**灵感 5（覆盖债 → 把交互日志变成离线 DR 课程，而不是在线学习）**
直觉：R69 的交互日志只用于当轮消歧，用完即弃。SCOPE 把每次遇到的未覆盖段/关系记成**覆盖债**：频率 × 风险权重 × 缺口类型。回合结束后，用这笔债去**重设计域随机化**（在预算下做最大覆盖：优先补高频、高风险的洞）。这形成一个跨训练的闭环：部署发现洞 → 离线补随机化 → 下一轮覆盖更厚；而**实时环路坚决不写任何学习参数**（继承 R68 的零学习写操作）。这样「进化」发生在安全边界之外，而不是拿在线策略做实验。

**灵感 6（覆盖只可否决 → 正面防止 Goodhart 与「认证洗白」）**
直觉：覆盖一旦被当成「可以行动」的许可证，就会被优化成 KPI：随机化无关维度、挑简单验证集、喂容易的分割样本，都能把覆盖数字做漂亮（coverage theater / DR 投毒）。所以必须立一条与 R69「情感只可否决」同构的铁律：**覆盖只可否决，不可授权**。C 高只意味着「不确定性估计可校准」，不意味着「策略正确」；执行仍然必须过 J_FLUID 与 C-RAS-WM。更关键的是证书的偏序性：低覆盖的结论永远不能被洗成高覆盖结论。覆盖不是新的真理来源，而是新的**证伪工具**。

## 1. 形式化定义（增量：定义 310–323）

**定义 310（SCOPE-RAS 总览）** SCOPE-RAS = (SDS, DCM, GTT, SCM, CVO, CLC, CDL, DDL, AIC-SCOPE, RAS-WM§)。五不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **覆盖条件合法性**：R69 的任何不确定性估计与交互决策，只有在其覆盖证书 C_safe(G) ≥ c_min 时才被许可；
(iii) **语义定位与缺口分型**：域差必须被定位到段/关系，并归入 N/S/P/C 四类；S 类不得用模型内交互消解；
(iv) **覆盖只作否决、不作授权**：覆盖高不降低 λ_floor 下界、不替代 J_FLUID/C-RAS-WM 认证；覆盖只决定「能否相信不确定性估计」；
(v) **覆盖债只离线结算**：新 DR 分布只能在回合间/离线生成；实时环路绝不改写覆盖模型、分类器或策略。

**定义 311（语义域分割 SDS）** 分割后验给出段集 V={R_i} 及场景图 G=(V,E)。每段带语义标签 ℓ_i、材质/可操作属性 m_i、风险权重 w_safe(R_i)；边 e=(i,j,τ) 表示关系 τ ∈ {contact, support, containment, adjacency, occlusion}。安全关键段/关系由 C-RAS-WM 的碰撞与接触包络标注。

**定义 312（域覆盖测度 DCM）** 训练随机化分布 μ_DR 作用于参数 θ（纹理、光照、质量、摩擦、柔顺、传感器噪声…），诱导观测分布 p_DR(o)。密度比 ρ(o)=p_test(o)/p_DR(o)（两类分类器/能量模型估计）。段/关系覆盖率用**加权保形预测**给有限样本下界：c_i = P_{o'~p_test|R_i}[ρ(o')≤ρ_max]，c_e 同理。全局覆盖 C(G)=F({c_i},{c_e})：安全关键项取 min（AND），其余取风险加权平均。

**定义 313（风险加权覆盖场）** C(x)=c_{R(x)}；C_safe = ∫ w_safe(x)c(x)dx / ∫ w_safe(x)dx。低覆盖 × 高 w_safe = 最危险区；覆盖预算应优先解释这里的密度比，而不是均匀监控全图。

**定义 314（缺口分型 GTT）** 对每个低覆盖段/关系赋类型：
- N（nuisance）：语义与动力学不变，仅外观/噪声偏移；可由更多观测或离线扩 DR 修补；
- S（semantic）：标签落在闭集本体之外，或开词表置信极低；模型无表示能力；
- P（physical）：动力学参数超出随机化范围，可由安全探针辨识；
- C（compositional）：各段单独覆盖但关系/组合未覆盖。
分型证据：分割-几何-动力学残差、覆盖分类器、开词表本体置信。类型决定后续可交互性（定义 317）。

**定义 315（组合覆盖 SCM）** 对场景图 G，组合覆盖 c_comp(G) = ⊗_{e∈E} c_e（关键边 AND/min，非关键边风险加权）。**组合空洞指示** Hole(G) = 1[ min_{i} c_i ≥ c_min ∧ c_comp(G) < c_min ]：每个零件都熟悉、组合却陌生。组合覆盖是安全相关的下界，而非平均。

**定义 316（覆盖合法性证书 CLC）** J_SCOPE = (J_FLUID, coverage_map, gap_types, ρ_p95, conformal_p, composition_hole, coverage_debt_id, scope_ver)。Valid_SCOPE ⇔ Valid(J_FLUID) ∧ C_safe ≥ c_min ∧ 无未处置 S 类缺口。语义：**「在覆盖集内，R69 的不确定性结论有效」**；覆盖按偏序单调，低覆盖结论不可推出高覆盖结论（不可洗白，定理 19）。

**定义 317（覆盖折扣 VoI CVO）** R69 的 VoI 在模型 p_θ 下计算；设真实期望信息增益与模型值之差有界 |VoI_true − VoI_model| ≤ Δ_cov(ρ_max)（有界密度比时）。定义下界 VoI_LB = VoI_model − Δ_cov，决策 g* = argmax[VoI_LB − c(g)]，且仅在「缺口可解」时允许交互：
- N：可用观测修补，但若 ρ 越界则只保守、不交互；
- P：仅在探针本身落在安全支持内时允许；
- C：仅在关系级探针安全时允许；
- S：**禁用交互**，直接走升级/拒绝路径。
若覆盖失效（ρ 无界），令 Δ_cov=∞ ⇒ VoI_LB=−∞ ⇒ 不交互。R69 的定义 298 是「覆盖恒有效、缺口恒可解」的特例。

**定义 318（覆盖债账本 CDL）** 记录每次遭遇的未覆盖段/关系、频率、w_safe 与缺口类型，形成覆盖债 D = E[Σ w_safe·1(ρ>ρ_max)]。离线 DR 重设计 = 在预算 B_DR 下最大化 ΔD 的**最大覆盖/集合覆盖**问题；每轮只更新 DR 生成器与覆盖模型，不触碰在线策略。

**定义 319（域退化阶梯 DDL）** L0 全 SCOPE；L1 N/C 类覆盖不足 → 保守 + 禁用该区交互 + 记账；L2 P 类且探针不安全 → 退回 R68 保守；L3 S 类 → 显式拒绝/人类接管（「未知类别」，不猜）；L4 覆盖估计器自身不可信（无有效保形证书/对抗告警）→ 硬停或最保守。每一级安全侧风险单调不增，切换无控制突变（继承 R68 定理 15）。

**定义 320（覆盖欺骗威胁 AIC-SCOPE）** ℰ_SCOPE = ℰ_FLUID × ℰ_COV。ℰ_COV：对抗样本伪装 in-support、分割边界/关系篡改、DR 数据投毒（喂简单样本抬高覆盖）、覆盖估计器规避、coverage theater（用无关维度换漂亮覆盖数字）。并入 AIC。

**定义 321（覆盖否决约束 CVC）** 形式化不变式 (iv)：即使 C_safe=1 且所有缺口为 N，执行仍须通过 J_FLUID 与 C-RAS-WM 前缀认证；覆盖不得进入 λ_floor 的下界计算以外，不得把「in-support」兑换成「可执行」。⇒ 覆盖是「允许计算不确定性」的许可，不是「允许行动」的许可。

**定义 322（语义缺口的表示下界）** 对 S 类缺口，存在 H_min>0 使任意有限次模型内证据 y_1..y_n 满足 H(M|o,y_1..y_n) ≥ H_min；H_min 由假设类 H 对真实类别的表示能力决定，与交互次数无关。故 S 类只能通过**升级到假设类之外**（人类给出新类别/新任务）来消解，不能靠「再问一次」。

**定义 323（覆盖-标定三通道对偶）** 在 R69 的 (r_res, Δa) 之外加入 ρ：支持内缓变真漂移 → (r_res≈0, Δa 中等, ρ 有界)；支持外域偏移 → (r_res≈0, Δa↑, ρ↑)；被标定吸收的故障 → (r_res↓, Δa↑, ρ 依故障方向)。三通道联合可分离 R68/R69 无法单靠残差或似然分开的情形。

```python
# IP-264 SDS：语义域分割 -> 段 + 场景图 + 风险权重
class SemanticDomainSegmenter:
    def parse(self, o):
        seg  = self.seg(o)                       # 段/标签/材质
        G    = self.graph(seg, self.geom(o))     # 关系边 E
        w    = self.c_ras_wm.risk_weights(G)     # 安全关键段/关系
        return G, w

# IP-265 DCM：密度比 + 加权保形 -> 有限样本覆盖下界
class DomainCoverageMeasure:
    def coverage(self, G, o):
        rho = self.ratio_model(o)                # p_test / p_DR
        c_i = weighted_conformal(self.calib, rho, alpha=self.alpha)
        c_e = {e: min(c_i[e.i], c_i[e.j], self.ratio_ok(o, e)) for e in G.E}
        return CoverageMap(c_i, c_e, rho)

# IP-266/267 GTT + SCM：缺口分型 + 组合覆盖
def triage_gap(G, cov, residual):
    gap = {}
    for R in G.V:
        if cov.c[R] < C_MIN:
            gap[R] = "S" if self.ontology.ood(R) else \
                     "P" if residual.dynamics(R) > TAU_P else \
                     "N" if residual.semantics(R) < TAU_S else "S"
    for e in G.E:                                 # 组合空洞
        if cov.c[e] < C_MIN and all(cov.c[i] >= C_MIN for i in (e.i, e.j)):
            gap[e] = "C"
    return gap

def compositional_coverage(G, cov, w):
    return and_min(cov.c[e] for e in G.E if w[e] >= W_CRIT)  # 关键关系 AND

# IP-268 CVO：覆盖折扣 VoI（覆盖失效即禁交互）
def coverage_discounted_voi(modes, G, cov, gaps, budget, c_ras_wm):
    if not cov.valid:                              # 无有效覆盖证书
        return None                                # VoI_LB = -inf -> 不交互
    best = None
    for g in info_action_candidates(modes):
        if not budget.allow(g) or not c_ras_wm.certify_info(g, G): continue
        if gaps.get(g.target) == "S":              # 语义缺口：问了也白问
            continue
        if gaps.get(g.target) == "P" and not c_ras_wm.probe_safe(g, G):
            continue
        voi_lb = model_voi(modes, g) - discrepancy_bound(cov.rho)
        score  = voi_lb - cost(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None

# IP-269 CLC：覆盖合法性证书
def scope_certificate(J_fluid, cov, gaps):
    ok = J_fluid.valid and cov.C_safe >= C_MIN and not any(t == "S" for t in gaps.values())
    return J_SCOPE(J_fluid, cov, gaps, valid=ok)

# IP-270 CDL：覆盖债 -> 离线 DR 重设计（不在实时环路）
def settle_coverage_debt(ledger, dr_budget):
    holes = ledger.rank_by(freq_weight=1.0, risk_weight=1.0)
    return max_coverage_redesign(holes, budget=dr_budget)   # 新 DR 生成器

    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes = M.aud.decompose(samples, z)
    g = M.cvo.choose(modes, G, cov, gaps, M.budget, M.c_ras_wm)
    if g is not None:
        ev = M.cia.execute(g)
        resolved = M.cia.update_belief(modes, ev, discipline="k_orthogonal")
        M.cdl.observe_resolution(G, g, ev, resolved)
    else:
        resolved = False
    # D) 继承 R69 的两级退避；覆盖只否决不授权
    U_floor = U_ale + (0.0 if resolved else U_epi)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    if slow: lam = max(lam, 0.8)
    mode = select_mode(modes, U_epi, lam)
    M.vqa_i.submit(G, cov, gaps, g, U_epi)
    return k, lam, mode, M.clc.certificate(J_fluid=..., cov=cov, gaps=gaps)
```

## 3. 推导

**引理 23（覆盖门控的 VoI 有效性）** 设测试分布相对 μ_DR 的密度比满足 ρ ≤ ρ_max，且覆盖用加权保形预测校准；则模型 VoI 与真实 VoI 之差有界 Δ_cov(ρ_max)，且该界随 ρ_max 单调增；当 ρ 无界（支持破坏）时不存在有限界。于是用 VoI_LB=VoI_model−Δ_cov 决策不会高估交互价值。系：**支持外「再问一句」的期望信息增益可以 ≤ 0**——R69 的「问错比不问更危险」在此被证明为「问的价值本身不可定义」，而不只是「可能被骗」。

**引理 24（组合覆盖的指数稀释）** 若 DR 对因素独立随机化、每个段被覆盖概率 1−ε，含 m 条独立关键关系的场景被完整覆盖概率 ≤ (1−ε)^m；组合空洞率 ≥ 1−(1−ε)^m。故逐段覆盖率会以指数级高估场景覆盖率，且关系越多、高估越严重。系：**独立的 DR 越「均匀」，组合空洞越隐蔽**——这正是 SCM 必须显式算关系覆盖、而不能只看全局 OOD 的原因。

**引理 25（语义缺口的表示下界）** 对落在假设类 H 之外的类别，任意有限次模型内证据后的后验熵 ≥ H_min>0，H_min 由 H 的表示能力决定。故 S 类缺口的 U_epi 不可由交互降低，只能升级。系：R69 对 S 类缺口做「问」是在消耗预算换一个**看似更新实则仍是模型偏见的答案**；正确动作是拒绝。

**引理 26（三通道覆盖-标定可分性）** 在 A95–A99 与定义 323 下，联合统计量 (r_res, Δa, ρ) 对「支持内真漂移 / 支持外域偏移 / 被标定吸收故障」三类至少两两可分（存在判别阈值），且任何单通道都不能单独分开这三类。故覆盖通道严格增强 R69 的缓变故障第二意见。

**定理 18（SCOPE 严格包含 FLUID / CALM）** 在 A95–A100 下，若覆盖恒有效、无 S 类缺口且缺口恒可解，SCOPE 逐指令退化为 FLUID-RAS；再令「永不交互」退化为 CALM-RAS。任意状态期望风险 SCOPE ≤ FLUID ≤ CALM（安全侧）；仅在覆盖有效、缺口可解且证据纪律满足时才获得组合覆盖红利。任一覆盖失守沿 DDL 单调退化。

**定理 19（覆盖证书单调、不可洗白、不可授权）** J_SCOPE 在覆盖偏序上单调：可由高覆盖推出低覆盖结论，不可由低覆盖推出高覆盖结论；且对任意 C_safe，执行仍需 J_FLUID 与 C-RAS-WM（定义 321）。因此覆盖既不能被用来把低覆盖结论「洗」成高覆盖，也不能把「in-support」兑换成「安全」。系：coverage theater 与 DR 投毒最多骗过监控数字，不能绕过执行认证。

**定理 20（覆盖债的离线单调收敛）** 设遭遇分布平稳、离线 DR 每轮覆盖按覆盖债排序的前 k 个洞，且被覆盖洞的残余债按固定比例下降；则覆盖债序列 D_t 非增，且收敛到「未被遭遇 / 不可安全覆盖」的残余债 D_∞，D_∞ ≤ D_0 且受 DR 预算 B_DR 与安全可覆盖集限制。系：SCOPE 的「部署发现洞 → 离线补随机化」是可收敛的课程，而不是无限补丁；实时策略从不被这些更新触碰。

```python
# IP-264 SDS：语义域分割 -> 段 + 场景图 + 风险权重
class SemanticDomainSegmenter:
    def parse(self, o):
        seg = self.seg(o)                        # 段/标签/材质
        G   = self.graph(seg, self.geom(o))      # 关系边 E
        w   = self.c_ras_wm.risk_weights(G)      # 安全关键段/关系
        return G, w

# IP-265 DCM：密度比 + 加权保形 -> 有限样本覆盖下界
class DomainCoverageMeasure:
    def coverage(self, G, o):
        rho = self.ratio_model(o)                # p_test / p_DR
        c_i = weighted_conformal(self.calib, rho, alpha=self.alpha)
        c_e = {e: min(c_i[e.i], c_i[e.j], self.ratio_ok(o, e)) for e in G.E}
        return CoverageMap(c_i, c_e, rho)        # valid 由 conformal 证书决定

# IP-266/267 GTT + SCM：缺口分型 + 组合覆盖
def triage_gap(G, cov, residual, ontology):
    gap = {}
    for R in G.V:
        if cov.c[R] < C_MIN:
            gap[R] = ("S" if ontology.ood(R) else
                      "P" if residual.dynamics(R) > TAU_P else "N")
    for e in G.E:                                # 组合空洞：段都熟、关系不熟
        if cov.c[e] < C_MIN and all(cov.c[i] >= C_MIN for i in (e.i, e.j)):
            gap[e] = "C"
    return gap

def compositional_coverage(G, cov, w):
    return and_min(cov.c[e] for e in G.E if w[e] >= W_CRIT)  # 关键关系 AND

# IP-268 CVO：覆盖折扣 VoI（覆盖失效即禁交互）
def coverage_discounted_voi(modes, G, cov, gaps, budget, c_ras_wm):
    if not cov.valid:                            # 无有效覆盖证书
        return None                              # VoI_LB = -inf -> 不交互
    best = None
    for g in info_action_candidates(modes):
        if not budget.allow(g) or not c_ras_wm.certify_info(g, G): continue
        if gaps.get(g.target) == "S":            # 语义缺口：问了也白问
            continue
        if gaps.get(g.target) == "P" and not c_ras_wm.probe_safe(g, G):
            continue
        voi_lb = model_voi(modes, g) - discrepancy_bound(cov.rho)
        score  = voi_lb - cost(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None

# IP-269 CLC：覆盖合法性证书

          and not any(t == "S" for t in gaps.values()))
    return J_SCOPE(J_fluid, cov, gaps, valid=ok)

    slow = (M.fma.flow_anomaly(M.fmp, M.last_action, o, o_cal) > TAU_FMA
            and M.last_r_res < TAU_RES)
    if not cov.valid or cov.C_safe < C_MIN or any(t == "S" for t in gaps.values()):
        M.cdl.record(G, cov, gaps)               # 记覆盖债
        return M.ddl.degrade(cov, gaps, M, o)    # L1~L4，安全单调
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes = M.aud.decompose(samples, z)
    g = M.cvo.choose(modes, G, cov, gaps, M.budget, M.c_ras_wm)
    resolved = False
    if g is not None:
        ev = M.cia.execute(g)
        resolved = M.cia.update_belief(modes, ev, discipline="k_orthogonal")
        M.cdl.observe_resolution(G, g, ev, resolved)
    U_floor = U_ale + (0.0 if resolved else U_epi)          # 覆盖只否决不授权
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    if slow: lam = max(lam, 0.8)
    mode = select_mode(modes, U_epi, lam)
    M.vqa_i.submit(G, cov, gaps, g, U_epi)
    return k, lam, mode, M.clc.certificate(J_fluid=..., cov=cov, gaps=gaps)
```

## 4. 推导

**引理 23（覆盖门控的 VoI 有效性）** 有界密度比 `ρ≤ρ_max` 且加权保形校准时，`|VoI_true−VoI_model| ≤ Δ_cov(ρ_max)`，且界随 `ρ_max` 单调增；`ρ` 无界时无有限界。故 `VoI_LB=VoI_model−Δ_cov` 不高估交互价值。系：支持外「再问一句」的期望信息增益可 ≤ 0——把 R69 的「问错更危险」从经验风险升格为「价值不可定义」。

**引理 24（组合覆盖的指数稀释）** 独立随机化下，每段覆盖概率 `1−ε`，含 `m` 条独立关键关系的场景全覆概率 ≤ `(1−ε)^m`，组合空洞率 ≥ `1−(1−ε)^m`。逐段覆盖率以指数级高估场景覆盖率；关系越多越严重。系：越是「均匀独立」的 DR，组合空洞越隐蔽，必须由 SCM 显式计算关系覆盖。

**引理 25（语义缺口的表示下界）** 对落在假设类 H 之外的类别，任意有限次模型内证据后 `H(M|o,y_1..y_n) ≥ H_min>0`，`H_min` 由 H 的表示能力决定。故 S 类 U_epi 不可由交互降低，只能升级。系：对 S 类「问」是在花预算换模型偏见；正确动作是拒绝并请求新假设类。

**引理 26（三通道覆盖-标定可分性）** A95–A99、定义 323 下，`(r_res,Δa,ρ)` 对「支持内真漂移 / 支持外域偏移 / 被标定吸收故障」至少两两可分，任单通道不可单独区分。故覆盖通道严格增强 R69 的缓变故障第二意见。

**定理 18（SCOPE 严格包含 FLUID / CALM）** A95–A100 下，覆盖恒有效、无 S 类且缺口恒可解时，SCOPE 逐指令退化为 FLUID；再令永不交互退化为 CALM。任意状态期望风险 `SCOPE ≤ FLUID ≤ CALM`（安全侧）；仅当覆盖有效、缺口可解、证据纪律满足时获组合覆盖红利。任一覆盖失守沿 DDL 单调退化。

**定理 19（覆盖证书单调、不可洗白、不可授权）** `J_SCOPE` 在覆盖偏序上单调：高覆盖可推出低覆盖结论，反之不成立；且对任意 `C_safe`，执行仍需 J_FLUID 与 C-RAS-WM。故低覆盖结论不能被洗成高覆盖，「in-support」不能被兑换成「安全」。系：coverage theater 与 DR 投毒最多骗监控数字，不能绕过执行认证。

**定理 20（覆盖债的离线单调收敛）** 遭遇平稳、离线 DR 每轮覆盖按债排序的前 k 个洞、覆盖后残余债按固定比例下降，则 `D_t` 非增，收敛到「未遭遇/不可安全覆盖」的残余债 `D_∞ ≤ D_0`，受预算 `B_DR` 与安全可覆盖集限制。系：SCOPE 的「部署发现洞 → 离线补随机化」是可收敛课程，且实时策略从不被更新触碰。

## 7. 本轮最大风险

**一句话**：SCOPE 把「我该问什么」升级为「我有没有资格回答」，却把资格判断押在**覆盖估计器**这一新的黑箱上——高维感知空间的密度比极难校准，DR 又可能被对抗性或「coverage theater」做成漂亮的假象；覆盖一旦被高估，域外失败会被盖上一张「已认证」的章，一旦被低估，系统又会陷入什么都不敢做的瘫痪——**覆盖证书只保证「可校准」，从不保证「正确」，把 in-support 当成正确性是本轮最危险的范畴错误。**
