# 灵感驱动研究循环 · UniBot 创新点研究 第 2 轮；本轮灵感：「抓取规划」×「共享控制」

> 承接 v1.1（I1–I9）。本轮把「抓取」从 VLA 的隐变量提升为可检查的接触契约，把「共享控制」从干扰抑制提升为权威分配。纪律不变：先核实赛事事实再立论；每个创新点过「计分轴对齐、单模型边界、部署预算」三道闸；清单只做增量深化与修剪。

第 1/2 轮 F1–F19 复核保留；本轮针对抓取与共享控制补 4 条硬事实：

一条重要的概念澄清：**共享 backend ≠ 共享控制**。前者是 N 个端口的服务并发（I6），后者是"人—策略—几何守卫"之间的权威分配（本轮 I11）。二者只在"每端口状态隔离"这一点上相交（F21）。

## 1. 直觉（先给画面，再给定义）

**直觉 1 · 抓取规划：VLA 把"抓"当隐变量，比赛却把"抓"当计分点。**
32 个任务里，绝大多数步骤分要等第一次成功抓取之后才打开；但 VLA 的抓取是端到端涌现的——它不告诉你"准备在哪一帧、以什么角度、多宽闭合"，失败也无法归因。抓取规划的价值不是替策略生成整条轨迹，而是给它一个**可检查的关键帧承诺**：接触点 `(u,v)`、夹爪投影偏航 `θ`、目标开度 `w`、距接触剩余步数 `τ`。反直觉点：**没有深度反而更适合"图像平面关键帧 + 自运动三角化"**——机器人自己的已知位移就是缺失的尺度；抓取不该在 `reset()` 一次预测，而应在接近过程中随基线增长逐步三角化。

**直觉 2 · 共享控制：正确的反应不是"停"，而是"让权—观察—交还"。**
评测中人会进入工作空间（干扰轴）。把人的接触当扰动的策略会僵硬对抗，既危险又丢分。共享控制理论说：人的接管不是故障，是**权威转移**。没有力/触觉也能感知接管——机器人自己的身体就是传感器：比较"上一 chunk 的期望动作"与"实际达到的本体位移"，自由空间残差小、规划接触残差可建模、人的外扰产生无法解释的残差。反直觉点：**让权不是失败；对抗才是。**

**直觉 3 · 两者统一：抓取是"建立耦合"，共享控制是"治理耦合"。**
抓取前，权威问题是"往哪走"；抓取瞬间，权威问题变成"谁在接触、契约是否仍然有效"。于是二者可统一为一个对象：**接触契约（contact contract）**——目标物、抓取关键帧、进入接触窗的相位、权威分配策略、失效判据。抓取成败、人的接管、滑移后的再抓，都是契约的签署 / 违约 / 重签。**本轮结论：中期胜负手从"数据引擎"再往前推一格——是"接触契约引擎"；它不换大模型，只在最贵的 2–3 厘米上把隐变量变成可检查的承诺。**

## 2. 严谨定义（把直觉钉死）

记第 `t` 步观测 `o_t=(I_t^{LH},I_t^{RH},I_t^{LW},I_t^{RW},s_t,ℓ)`，`s_t=(T_t,w_t)` 为 EE 位姿与夹爪开度，`ℓ` 为语言；EE 动作 `u_t=(ΔT_t,Δw_t)` 或目标 `T_t^cmd`。

**定义 1（抓取关键帧）** 在腕相机图像平面，
`g=(u,v,θ,w,τ) ∈ ℝ²×S¹×[w_min,w_max]×ℕ`，
`(u,v)` 为接触点像素，`θ` 为夹爪投影偏航，`w` 为目标开度，`τ` 为距接触的剩余控制步。`g` 不承诺度量深度，只承诺"图像平面可伺服 + 时机可检查"；它由示教自动挖掘（产物区 §1.1），不是人工标注。

**定义 2（接触契约）** `C=(o,g,φ_c,π_a,V)`：
`o` 目标物，`g` 抓取关键帧，`φ_c` 进入接触窗的相位阈值，`π_a` 权威分配策略，`V` 失效谓词。契约在 `φ_t≥φ_c` 时生效，在 `V` 触发或 episode 结束时终止。**契约是可检查承诺**：每个官方得分点（F17）至少对应契约的一个里程碑。

**定义 3（动作-状态残差与接管）** 令 `Δs_t=s_{t+1}⊖s_t`，`Δŝ_t(u_t)` 为无外扰预测，`Σ_φ` 为相位 `φ` 的条件协方差。残差
`r_t=||Δs_t−Δŝ_t(u_t)||_{Σ_φ}+λ|Δw_t−Δŵ_t|`，
`z_t=(r_t−μ_φ)/σ_φ`，`S_t=max(0,S_{t−1}+z_t−k)`，接管 `H_t=1[S_t>h]∨V_t^{hand}`，`V_t^{hand}` 为视觉手检测。**单靠残差会把"规划接触"误判为"人"**，故 `H_t` 用 log-odds 融合两通道，并要求连续 2 步一致（迟滞），宁可慢一拍也不误让权。

**定义 4（权威层级）** `α_t∈{0,1,2}`，`2>1>0`：0 = VLA 策略，1 = 抓取守卫（仅接触窗），2 = 人。守卫的动作集 `A_1` 只含 veto（延后闭合）与 width-clamp（把 `w` 夹到 `[w_min,w_max]`），**不能生成自由空间轨迹**。权威只按 `2→1→0` 单向让渡，绝不抢占。一句话：**权威是借来的，不是抢来的。**

**定义 5（契约失效与重签）** `V_t=1[视觉相对漂移>ε_d]∨1[开度异常]∨1[滑移速度>ε_s]∨1[H_t=2 且物体状态改变]`。`V_t=1` 时丢弃旧 chunk，从当前状态重签契约；episode 内缓存可复用，`reset()` 清空（F23）。

**命题 1（共享控制的响应带宽）** 若评测器每 `T_a` 步调用一次 `get_action`，控制频率 `f_c`，则基于新观测的接管响应延迟下界约 `T_a/f_c + 推理延迟`。15Hz、`T_a=16` 时约 1.07s，人已经改变了场景；`T_a=2–4` 时约 133–267ms。**故接触窗短 chunk 不是效率选项，而是权威带宽。**（若评测器逐步调用，则 `T_a` 只影响平滑性；短 chunk 仍不劣。）

**命题 2（单目抓取的可观测性）** 腕相机对静态物点两次观测的基线 `b`、焦距 `f`、像素误差 `δ`，深度相对误差约 `δZ/Z≈(Z/(f b))δ`。**结论：3D 关键帧不应在 reset 一次性回归，而应在接近过程中随基线增长逐步三角化；`b<b_min` 时退回 2D 伺服。** 这把"抓取规划"从一次性预测变成过程性估计，天然适配流式接口。

## 3. 对 v1.1 痛点的增量修订

- **P2（泛化缺口）**：未见物体轴的最脆弱处是抓取点，而非语义；I10 的图像平面关键帧 + I9 的语义先验组合，使"新杯子"共享"旧杯子的抓法"。
- **P4（无触觉）**：无触觉下，滑移只能靠视觉相对位移与开度异常推断；I12 把"接触失败"变成可检测事件，而不是等终局失败。
- **P5（时间压力）**：抓取关键帧给出"距接触 τ"，短 chunk 只花在接触窗；自由空间仍用长 chunk 省延迟。
- **P8（示教质量）**：示教全成功但抓取段并非全干净；按关键帧对齐后，可把"闭合后物体不动"的段自动降权。
- **新增 P9（抓取不可归因）**：VLA 的抓取是隐变量，失败无法定位到"点/角/宽度/时机"中的哪一项，恢复只能靠运气。
- **新增 P10（权威带宽）**：长 chunk 与人的接管响应直接冲突；现有 I4 只做视觉手检测，未把"本体残差"作为第二通道，也未定义让权/交还协议。
- **新增 P11（无深度病态）**：任何在 RGB 上直接回归 6D 抓取位姿的方案，在未见物体上误差不可控；必须先承认病态，再用自运动三角化或图像伺服绕开。

## 4. 研究问题（本轮立项 Q9–Q11，Q1–Q8 保留）

- **Q9（抓取表示的最小充分性）**：在无深度、无触觉、无相机外参的接口下，哪种抓取表示既可示教自监督又可在线伺服——图像平面关键帧 `(u,v,θ,w,τ)`、自运动三角化 3D 点、还是二者级联？其可观测性边界（基线、遮挡、物体运动）如何量化？
- **Q10（共享权威的判别与分配）**：动作-状态残差 + 视觉手检测能否在 <300ms、误让权 <5% 的约束下识别人的接管？最优仲裁不是"最大化顺从"，而是"最大化计分步数"——让权/交还的切换代价如何进入目标函数？
- **Q11（净增益与合规边界）**：抓取关键帧与共享仲裁在抓取密集任务上是否提升步骤分，而不伤标称任务与延迟？训练期辅助头（单模型）与推理期守卫（可能越界）两条路径的增益差是否值得合规风险？

## 5. 设计原则（新增 PR6，其余保留）

- **PR6 接触契约最小充分性**：任何抓取/共享控制模块只在接触窗生效；守卫只能否决或收紧，不得生成新的自由空间轨迹；权威按 `2→1→0` 单向让渡。与 PR1（决策）、PR5（数据）互补：PR6 管"接触时刻的权限"。
- **PR1–PR5 保留**（第 1/2 轮 §4）。

# UniBot-V1 参赛创新点清单（第 2 轮 v1.2）

> 检索日期：2026-11-26 / 2026-11-27；本轮新增接口事实 F20–F23 见想法区 §0。承接 v1.1：I1–I9 全部保留，新增 I10/I11/I12；I2/I3/I4/I5/I6/I8/I9 做接触契约相关深化。清单只增改不重置。

## 0. 创新点清单（每点：动机 / 与现有方案差异 / 技术可行性 / 所需资源 / 落地步骤 / 风险）

### I10 接触契约抓取关键帧（新）★★★★★

- **动机**：32 任务绝大多数步骤分在第一次成功抓取之后才打开；但 VLA 的抓取是隐变量，失败无法归因到接触点、角度、宽度或时机（P9）。观测无深度（F20），一次性 6D 抓取回归在未见物体上不可控（P11）。
- **核心（两条路径，A 为默认合规路径）**：
  - **I10-A · 训练期抓取关键帧头**：在 VLA action expert 上加一个轻量辅助头，从示教自动挖掘的 `g=(u,v,θ,w,τ)` 做稠密监督。推理时它是**同一个模型的一部分**，不引入第二个模型，PR2 合规。监督量为：剩余步数回归、腕图像 2D 接触点热图、夹爪偏航 cos 损失、目标开度回归。
  - **I10-B · 推理期抓取守卫（可选，需合规确认）**：把关键帧在腕相机图像平面做伺服；接近段用已知 EE 位移做**自运动三角化**（命题 2）恢复相对深度；三角化条件不足时退回 2D 图像伺服。守卫只允许 **veto（延后闭合）** 与 **width-clamp（限制开度）**，不生成自由空间轨迹（PR6）。
- **与现有方案差异**：纯 VLA 队伍让抓取涌现；键点伺服队伍（v1.0 I3）只在接触段做几何回退，没有"何时闭合、闭合多宽"的可检查承诺。I10 把抓取变成**图像平面关键帧 + 过程性三角化 + 守卫否决**，且默认版本不增加模型。
- **技术可行性**：
  - A：高。示教里有夹爪开度与指令，闭合事件可自动定位；辅助头复用 VLA 特征，单卡可训（F11）。
  - B：中。需要腕相机内参/手眼外参（官方目录未给，F20，必须先核实）；三角化需要基线，静止悬停时不可用；遮挡与物体运动是硬边界。
- **所需资源**：A 需 1×24GB GPU、1 人周数据挖掘 + 1 人周训练；B 另需手眼标定 1–2 天、1 人周几何伺服；不需要新传感器。
- **落地步骤**：①在 32 任务示教上挖关键帧并统计"抓取关键帧依赖度"；②训练 A 的辅助头，L0 验证关键帧误差；③在 L0 回放上测守卫误否决率；④核实手眼参数与三角化基线；⑤B 通过组委会书面确认后才进入计分通道；⑥单任务通道 A/B。
- **风险**：A 的关键帧标签受"示教闭合抖动"影响（缓解：多帧投票 + 只取接触前稳定段）；B 的误否决会伤标称任务（缓解：只在接触窗、只在置信高时 veto、L0 误否决率 <2% 才放行）；手眼外参缺失（缓解：先做 A，B 仅作研究备份）；单模型边界（缓解：默认 A，B 需书面确认）。

### I11 动作-状态残差共享权威仲裁（新）★★★★

- **动机**：评测有人的干预 / 共享工作空间轴；把人的接触当扰动会僵硬对抗，既危险又丢分（P10）。无任何力/触觉通道（F8/F18），不能靠力传感器检测接管。
- **核心**：
  1. **双通道接管检测**：通道一为动作-状态残差 `z_t`（定义 3）的 CUSUM；通道二为视觉手检测 `V_t^{hand}`（I4 已有）。log-odds 融合并要求连续 2 步一致，降低"规划接触"被误判为"人"。
  2. **权威层级 `α∈{0,1,2}`**（定义 4）：人 2 > 抓取守卫 1 > VLA 0；只单向让渡。`α=2` 时切换到**合规保持**：每步把目标 EE 位姿设为观测到的当前位姿（零加速度保持），不抵抗外力。
  3. **交还协议**：残差回到基线连续 `K` 步且物体/EE 稳定后，丢弃旧 chunk，从当前状态重签契约（定义 5），而不是恢复旧计划。
  4. **合法边界**：episode 内可缓存"人修正后的新状态"用于重签；`reset()` 清空。**这是状态适应，不是在线学习**，不更新任何参数（PR4/合规红线）。
- **与现有方案差异**：I4 只做视觉手检测 + 停持；I11 把"本体残差"变成第二通道，并显式定义让权/保持/交还，目标是**最大化计分步数**而不是最大化顺从。
- **技术可行性**：高。残差检测是 O(1) 本体计算，无额外模型；视觉手检测复用 I4；状态机是纯工程。
- **所需资源**：1 人周实现 + 1 人周 L0 注入实验；无需额外 GPU。
- **落地步骤**：①从示教统计自由/接触相位的残差基线；②做"合成接管注入"（动作偏置、物体瞬移、模拟外力）得到 ROC；③实现状态机与合规保持；④融合视觉手检测；⑤L2 用脚本化人干预协议验证；⑥记录交还延迟与误让权。
- **风险**：接触本身产生大残差（缓解：相位条件化 + 视觉通道融合 + 迟滞）；误让权导致任务停摆（缓解：只让权到"保持"，不作负动作；连续证据才升级）；人干预是否计入评分未知（缓解：先按安全与不丢步设计，不假设有额外奖励）。

### I12 契约失效与视觉滑移再抓取（新）★★★

- **动机**：无触觉时，抓取失败通常表现为"闭合后物体相对夹爪移动"，但策略要到终局才知道。I12 把接触失败变成在线可检测事件（P4/P9）。
- **核心**：在腕相机跟踪物体与夹爪的相对位移 `d_t` 与夹爪开度 `w_t`；契约失效谓词 `V_t`（定义 5）融合：相对漂移 > `ε_d`、开度异常、滑移速度 > `ε_s`、人接管且物体状态改变。`V_t=1` 时立即停止当前 chunk，重签契约（可复用 I9 检索先验与 I10 关键帧），从当前状态再抓。
- **与现有方案差异**：v1.0 I5 的脚本恢复是"回退—重接近—重抓"的固定原语；I12 的恢复由**契约失效信号**触发，触发条件与得分点对齐，避免无谓重抓。
- **技术可行性**：中。腕相机相对位移在接触时会被夹爪遮挡；需要短窗口视觉跟踪 + 开度通道兜底。
- **所需资源**：1 人周视觉跟踪 + 复用 I10 关键帧；1 GPU 日调阈值。
- **落地步骤**：①腕相机物体/夹爪相对位移提取；②在示教上标定"闭合后稳定"分布；③失效阈值 L0 扫描；④接入 I11 状态机；⑤3 个易滑任务试点（PourOutMedicine / PickOutBatteries / StackBowls）。
- **风险**：遮挡导致滑移误报（缓解：开度 + 相对位移双证据；短窗口 + 迟滞）；重抓次数增加拖慢时间（缓解：每任务重抓上限 + 失效置信门控）。

### 升级既有创新点

- **I2 v3（数据引擎）**：新增**抓取段挖掘**——把每条示教按 `t_g` 切成接近段 / 接触段 / 搬运段；接触窗帧过采样 2–3 倍；构造难负样本（接近但未接触的帧），训练 I10-A 的关键帧头。质量分增加"闭合后物体稳定裕度"，自动降权"闭合后物体不动"的坏段。

## 1. 严谨推导

### 1.1 从示教自动挖掘抓取关键帧

对每条示教 episode，取夹爪开度状态 `w_t` 与夹爪指令 `u_t`（归一化，开=1，闭=0）：

1. **闭合起点** `t_close = min{t : u_t < τ_close 且此后连续 H 帧保持}`；
2. **接触点** `t_g = argmin_{t∈[t_close, t_close+W]} w_t`，若 `w_t` 在闭合后出现"先降后升"（物体抵抗闭合），取局部极小；
3. **关键帧标签**：`τ = t_g − t`（对 `t<t_g` 稠密监督），`w* = median(w_{t_g−2..t_g})`，`θ* = 夹爪投影偏航`，`(u*,v*) = 接触点像素`（用接近段与接触帧的物体区域差异 + 开放词汇检测定位）；
4. **难负样本**：`|t−t_g| > 2W` 的帧标为"远离抓取"，`τ` 不监督，只监督 `φ_t≈0`；
5. **质量门**：若闭合后 `H` 帧内物体相对夹爪位移 > `ε_q`，该段标为"抓取失败示教"，不进入 A 的正样本，转入 I5 的恢复数据池。

关键帧头的监督（只在 action expert 侧，VLM 冻结）：

```
L_kf = λ_τ · SmoothL1(τ̂_t, τ_t)
     + λ_h · CE(Heatmap(û_t, v̂_t), (u*, v*))
     + λ_w · SmoothL1(ŵ_t, w*)
     + λ_θ · (1 − cos(θ̂_t − θ*))
     + λ_φ · BCE(φ̂_t, 1[t ≥ t_g − H_pre])
```

其中 `φ̂_t` 是"已进入抓取窗"的相位概率，直接用于推理期的 chunk 调度与守卫开关。

### 1.2 自运动三角化与可观测性

腕相机在 `t1,t2` 的相机中心为 `C1,C2`（由 EE 位姿 + 手眼外参得到），同一静态物点的归一化像点为 `x1,x2`。三角化得 `X`；深度相对误差近似

```
δZ/Z ≈ (Z / (f·b)) · δ,     b = ||C2 − C1||
```

因此给定目标精度 `ε_Z`，所需基线

```
b ≥ Z·δ / (f·ε_Z).
```

**设计后果**：

- 不在 `reset()` 做一次性 3D 抓取回归；在接近过程中每 `k` 步更新一次三角化；
- 当 `b < b_min` 或重投影残差 `> ε_rep` 时，拒绝 3D 结果，退回图像平面 2D 伺服；
- 物体在接触前移动会破坏静态假设 → 用最近 `W` 帧的一致性检验，不一致就重置三角化。

### 1.3 动作-状态残差的统计模型

自由空间与接触空间的残差分布不同，故用相位条件化：

```
μ_φ, σ_φ = robust_stats({r_t : phase(t)=φ})     # 从示教离线估计
z_t = (r_t − μ_φ) / σ_φ
S_t = max(0, S_{t−1} + z_t − k)                  # CUSUM
```

接管证据用 log-odds 融合：

```
logit P(H_t=1) = logit P_H(S_t > h) + logit P_H(V_t^{hand}=1) + logit P_0
```

要求连续 2 步 `P(H_t=1) > 0.5` 才进入 `α=2`，退出则要求连续 `K` 步低于 `0.3`。**单靠残差不可信**：规划接触也会产生残差；融合视觉手检测是准确性来源，残差是遮挡时的兜底。

### 1.4 权威状态机

状态：`AUTO(0) → GUARD(1) → HUMAN(2) → RECOVER`。

- `AUTO → GUARD`：`φ̂_t ≥ φ_c` 且存在有效关键帧；
- `GUARD → AUTO`：离开接触窗或契约完成；
- 任意 `→ HUMAN`：`P(H_t=1)` 连续 2 步 > 0.5；
- `HUMAN → RECOVER`：连续 `K` 步低于 0.3，且 EE 速度 < `ε_v`；
- `RECOVER → AUTO`：从当前状态重签契约成功；
- `RECOVER → HUMAN`：重签失败或人仍在场。

**单向让渡**：`GUARD` 不能把 `HUMAN` 抢回来；人离开后必须先经过 `RECOVER`，避免"旧 chunk 突然复活"。

### 2.2 单服务推理：守卫 + 仲裁

```python
class ContactContractPolicy:                 # one PolicyService, per-port state
    def reset(self):
        self.C = None                        # contact contract
        self.mode = "AUTO"                   # AUTO/GUARD/HUMAN/RECOVER
        self.alpha = 0                       # authority: 0=VLA,1=guard,2=human
        self.S = 0.0                         # CUSUM
        self.tri = Triangulator()            # self-motion SfM buffer

    def get_action(self, obs):
        s = obs["state"]; phi = self.kf_head(obs).phi
        if self.C is None and phi > PHI_SIGN:
            self.C = self.sign_contract(obs, self.kf_head(obs))

        # --- authority: human preempts everything ---
        p_h = self.human_logodds(obs)        # residual CUSUM + hand detector
        self.mode, self.alpha = self.arbitrate(self.mode, p_h, s, phi)

        if self.mode == "HUMAN":             # compliant hold: don't fight
            return self.hold_current_pose(s)
        if self.mode == "RECOVER":           # re-sign from current state
            self.C = self.sign_contract(obs, self.kf_head(obs))
            self.mode = "AUTO"

        # --- grasp guard: veto/clamp only, contact window only ---
        if self.C and phi >= PHI_C:
            g = self.C.g
            g3 = self.tri.update(obs, g) if self.tri.ready(obs) else None
            if g3 is not None and (g3.reproj_err > EPS_REP
                                   or g3.depth_err > EPS_Z):
                g3 = None
            if not self.guard_ok(obs, g, g3, phi):   # false-veto budget
                return self.delay_closure(obs)       # veto, no new trajectory
            obs = self.clamp_width(obs, g.w)         # width clamp only

        a = self.vla.propose_chunk(obs, contract=self.C)
        return self.short_chunk_if_contact(a, phi)   # Probl. 1: bandwidth
```

### 2.3 仲裁

```python
def arbitrate(self, mode, p_h, s, phi):
    if p_h > 0.5 and self.p_h_prev > 0.5:            # 2 consecutive
        return "HUMAN", 2
    if mode == "HUMAN":
        if p_h < 0.3 and norm(s.ee_vel) < EPS_V:
            return "RECOVER", 0
        return "HUMAN", 2
    if mode == "RECOVER":
        return ("AUTO", 0) if self.contract_valid(s) else ("RECOVER", 0)
    return ("GUARD", 1) if phi >= PHI_C else ("AUTO", 0)
```

## 3. 实验设计（分级消融协议 v3）

| 级别 | 内容 | 通道/成本 | 通过判据 |
|---|---|---|---|
| L0-a | I10-A 关键帧头：留出示教 / 留出物体上的 `τ` 误差、2D 点误差、开度误差 | 离线（免费） | `τ` MAE ≤ 2 步、2D 点 ≤ 12px、开度 ≤ 10% |
| L0-b | I10-B 三角化：误差-基线曲线、重投影拒绝率 | 离线回放 | 在 `b≥b_min` 时深度相对误差 ≤ 8%；`b<b_min` 正确退回 2D |
| L0-c | I11 接管检测：合成外扰注入 ROC、误让权率、交还延迟 | 离线（免费） | AUC ≥ 0.9、误让权 ≤ 5%、交还 ≤ 5 步 |
| L0-d | I10 守卫误否决：标称示教上的 veto 比例 | 离线（免费） | 误否决 < 2%，否则不放行 |
| L0-e | I12 滑移检测：闭合后扰动重放 | 离线（免费） | 漏报 ≤ 10%、误报 ≤ 10% |
| L1 | 2^(k−p)：{关键帧头 on/off} × {守卫 on/off} × {仲裁 on/off} × {短 chunk on/off} | 离线 + 少量真机 | 主效应显著的 ≤ 3 个组合进 L2 |
| L2 | top 组合真机确认：按"抓取关键帧依赖度"分层的 ≥ 2 任务 × 各 2 次 | 单任务通道 | 步骤分增益 ≥ 离线预测的 50%；无标称任务退步 |
| 门禁 | PR4：run_client 全流程 + p99 + 动作健康度 | 本地 stub | 0 拒绝动作、p99 < 40ms、无异常动作 |

**分层原则**：不按任务名拍脑袋分层，先对每个任务计算"首次成功抓取前 / 后的步骤分占比"与"抓取关键帧依赖度"（关键帧头预测误差与真实步骤分的相关性），把任务分成抓取密集 / 接触轻两类，再分配真机预算。

**人干预协议（L2）**：脚本化三档——①轻触（外部力 1–2N 等效，持续 0.5s）；②引导（把人手放在 EE 上改变轨迹 1–2s）；③夺物（在闭合后把物体移走 3–5cm）。每档记录接管 F1、交还延迟、任务步骤分损失；所有试验在安全员在场、急停可达的条件下进行。

**注册表新增字段**：`false_veto_rate`、`takeover_f1`、`handback_latency`、`kf_error`、`real_step_gain`、`real_success_gain`。只有当某代理指标与真机步骤分增益的 Spearman > 0.6 时，才允许单独作为 L2 准入依据（沿用 I8 v2 规则）。

- [ ] 单模型边界：I10-B 推理期守卫与 I3' 的混合推理路径均需组委会书面确认；确认前只启用 I10-A（训练期辅助头）
- [ ] 数据使用：只用官方发布数据集（32 任务 + 110 语料 + DiverseManip，apache-2.0）；关键帧标签由官方示教自动挖掘，不引入外部数据
- [ ] 动作健康度：守卫只 veto / clamp，不产生越界、跳变或统计异常动作（F22）
- [ ] 人干预数据只记录运动学，不记录身份信息；试验安全员在场、急停可达
- [ ] N 端口：每个端口独立 `reset()` 与历史，共享 backend 时不做跨端口状态共享（F21）
