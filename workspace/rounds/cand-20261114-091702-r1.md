# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「技术路线图」×「技能学习」）

> R69 让系统学会了「问」：把不确定性拆成 aleatoric 与 epistemic，用流匹配策略显式表示动作模态，再用注视、探针、问句去主动消歧。但「问」有一个隐藏前提——**答案必须落在系统已有技能的可执行范围内**。如果答案要求一个系统根本不会的技能，信息动作再多，VoI 也会归零：不是因为没有信息，而是因为**没有能力把信息变成动作**。R69 会把这种「能力缺口」误判为「不可约噪声」，于是永久保守、永远不学；更糟的是，它会把每一次失败都记成「世界太模糊」，而不是「我还不会」。
>
> 本轮两个灵感正好补上这块缺失：
> - **技术路线图**给出一种「面向未来的能力治理结构」：能力缺口不是待办清单，而是一张带依赖、成熟度、预算、关卡、终止条件与版本的能力图；它决定「先学什么、学到什么程度、什么时候放弃」，并对抗局部贪婪与沉没成本。
> - **技能学习**给出把「缺口」变成「可复用能力」的机制：技能是带前置/后置条件、终止条件、安全包络与证书的 option，可组合、可迁移、可遗忘、可回滚；学习发生在离线/影子环境，运行时只做认证后调度。
>
> 核心命题：**在 R69 的实时闭环之外，增加一个慢时间尺度的「能力层」：运行时只登记「技能债」而不学习；路线图按学习价值 VoL 做依赖感知的预算调度；离线学习候选技能；候选技能经分级门重新认证后原子换装。任何时刻运行时只执行已认证技能；没有可用技能时，显式选择「问（R69）/学（离线）/退（R68）」三响应，而不是把能力缺口伪装成 aleatoric 噪声。** 命名 **SKILLMAP-RAS**（Skill-Learning roadMap for Risk-Adaptive Systems）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**明天要会什么、先学哪一样、学不成怎么退**」——不确定性不只是刹车和提问，也可以是一张有预算、有关卡、有终止条件的能力路线图。

## 0. 直觉与动机

**灵感 1（R69 的能力盲区：VoI 归零不等于世界不可知）**
直觉：R69 的 VoI 是在「当前策略的模态集合」上算熵减。信息动作能改变的是**信念**，不能改变**技能集合**。当任务需要的动作根本不在策略支撑集内时，任何观察都无法让正确动作变得可执行；此时对所有 g 都有 VoI(g)=0，但 U_comp>0。R69 的规则「VoI≤成本 ⇒ 不交互 ⇒ λ_floor(U_ale+U_epi)」会把「我还不会」永久写成「世界就是这样」。这不是安全，而是**把无能固化成世界观**。R69 缺的不是信息，而是一个把「反复问不明白」转化为「该学了」的通道。

**灵感 2（技术路线图 → 能力债的资本市场）**
直觉：技术路线图不是愿望清单，而是一种在不确定下的**投资决策架构**：能力目标与任务绑定；能力之间有依赖（不会抓取就学不会装配）；每个能力有成熟度等级（TRL 式 L0–L5）；每个阶段有证据门槛与「继续/终止/扩大」决策；预算和时间盒硬约束；路线图本身有版本、有复审、有日落。把「能力缺口」记成**技能债**（competence debt），未偿还会产生「利息」——更多人工接管、更多保守停机、更多错过任务。路线图就是还债顺序：不是「什么最急学什么」，而是按依赖、按学习价值/成本、按风险组合来排。它还必须内置**反沉没成本**的 kill criteria：学到一半发现 VoL 不成立，要能停。

**灵感 3（技能学习 → 带合同的模块，而不是黑箱策略）**
直觉：技能不是一段神经网络，而是一个**带合同的 option**：前置条件 φ、后置条件 ψ、策略 π、终止条件 β、安全包络 E、证书 κ、版本 v、成熟度 ℓ。技能之间用接口合同组合；组合的风险往往不在单个技能内部，而在**接缝**（前置/后置不匹配、包络交集为空、时序耦合）。技能学习因此不是「多训一个策略」，而是「产出一个可以被认证、被组合、被回滚的模块」。学习必须在离线/影子环境完成，否则会直接撕毁 R68/R69 签发的安全证书。运行时零学习写操作不是保守，而是让证书链条成立的前提。

**灵感 4（三响应：问 / 学 / 退，而不是二选一）**
直觉：面对一个能力缺口，至少有三种响应：能问到就用 R69 的信息动作（ask）；问不到但可学，就把债排进路线图，离线学（learn）；既不值得问也不值得学，就显式避让/重谈任务（retreat/avoid）。R69 只有 ask 与 retreat，缺少 learn；R70 补上 learn，并把三者放进同一个成本-收益比较：VoI 是**短期信息收益**，VoL 是**长期能力收益**，retreat 是**当下的生存成本**。这样「保守」不再是唯一兜底，而是三种响应中成本最低的一种。

**灵感 5（严格包含：学习层永远不在实时关键路径上）**
直觉：任何「边跑边学」的方案都会让安全证书失效：你认证的是旧策略，执行的是新策略。SKILLMAP 的理论姿态必须是：**运行时与 R69 逐指令一致，除非一个经完整分级门认证的新技能已经原子换装**。路线图为空、预算为零、所有关卡关闭时，系统必须严格退化为 FLUID-RAS。学习只扩展**能力集**，不放松**安全包络**；新技能上线要经过影子/金丝雀与回滚，任何包络越界都可解除认证。这样 R70 不是给 R69 加一个不可信的黑箱，而是给 R69 加一个**有审计轨迹的能力外设**。

**灵感 6（新风险：能力剧场与路线图捕获）**
直觉：技能学习最危险的失败不是「学不会」，而是**学会了错的东西还被盖章**。VoL 与 U_comp 的估计本身可能未校准；路线图可能被「好看但无用的指标」捕获（Goodhart）；分级门可能用与训练同源的偏差数据评估，形成「证书洗白」；技能债可能膨胀成永远还不完的 backlog，或反过来被系统性低估。R69 的风险是「问错比不问更危险」；R70 的风险升级为「**学错并认证，比不学更危险**」——因为它花掉了预算、替换了原本安全的保守行为，还制造了虚假的能力信心。

## 1. 形式化定义（增量：定义 310–328）

**定义 310（SKILLMAP-RAS 总览）** SKILLMAP-RAS = (FLUID-RAS, CDL, SRO, SLP, SGL, RDA, RAS-WM‡)。其中 CDL 为能力债账本、SRO 为技能路线图调度器、SLP 为离线技能学习管线、SGL 为分级门阶梯、RDA 为路线图审计器。四条不变式：
(i) **运行时零学习写操作**（继承 R68 定义 276-i / R69 定义 293-i）；
(ii) **未认证技能零执行**：运行时只能调度 Σ_cert 中的技能；学习只发生在离线/影子环境；
(iii) **路线图硬约束**：预算、依赖先序、成熟度门槛与安全风险上限不可被学习器绕过；每笔技能债必须有证据、责任节点、复审时间与过期条件；
(iv) **证书链与可回滚**：技能升级必须保持 J_FLUID 链完整；解除认证/回滚是原子操作，回滚后运行时行为回到上一已认证版本。

**定义 311（能力缺口与技能债）** 设任务分布 D、任务成功谓词 φ_task、已认证技能闭包 Π_{Σ_cert}。能力缺口区域为
Gap(Σ_cert) = { s ~ D : 不存在 π ∈ Π_{Σ_cert} 使 φ_task 在 s 上以规定成本成立 }。
技能债 d = (D_d, f_d, E_d, sev_d, rec_d, Û_comp(d), C_d, Dep_d, exp_d)，其中 D_d 为缺口上下文分布、f_d 为可观测失败谓词、E_d 为证据集（失败轨迹、人工接管、VoI 耗尽记录、FMA 异常、审计结论）、sev_d 为严重度、rec_d 为复现率、Û_comp 为能力缺口估计、C_d 为学习成本分布、Dep_d 为依赖债/技能、exp_d 为过期条件。登记规则采用**三源证据**：重复任务失败 ∧ 无适用已认证技能 ∧ 信息动作已耗尽（或 VoI 上界低于成本），三者同时成立才登记，避免把普通 epistemic 歧义误记成能力债。

**定义 312（三类不确定性）** U = (U_ale, U_epi, U_comp)。U_ale 为技能内部不可约噪声；U_epi 为当前技能支撑集内可由信息动作消解的歧义；U_comp 为只有获得新技能才能消解的能力缺口。形式化地，U_comp(s) = 1[s ∈ Gap(Σ_cert)]，并按 D 加权；需要连续版本时用相对参考策略的代价差截断到非负。三者语义不同，不做简单加和：U_ale → R68 的 λ_floor；U_epi → R69 的 VoI 交互；U_comp → CDL/SRO 的离线学习。

**定义 313（技能对象与证书包络）** 技能 σ = (φ_σ, ψ_σ, π_σ, β_σ, E_σ, κ_σ, v_σ, ℓ_σ)：φ 前置条件、ψ 后置条件、π 策略（可为流匹配/选项策略）、β 终止条件、E 安全包络（状态-动作-力/时域约束）、κ 证书（证据根、统计保证、有效期）、v 版本哈希、ℓ 成熟度。技能只有在 s ∈ E_σ 且 φ_σ(s) 成立时才可被调度；执行后必须验证 ψ_σ，否则触发回滚与能力债登记。

**定义 314（技能库、闭包与组合合同）** 技能库 Σ = {σ_i}；深度 ≤ H 的组合闭包 Π_Σ 由序列/并行组合生成。组合 σ_1 ∘ σ_2 有定义当且仅当接口合同 C(σ_1, σ_2) 成立：ψ_{σ_1} ⇒ φ_{σ_2}，且 E_{σ_1∘σ_2} = E_{σ_1} ∩ pre^{-1}(E_{σ_2}) 非空，且接缝时序/资源约束满足。组合技能必须携带**接缝证书**；单个技能认证不能自动外推到组合。

**定义 315（技能路线图）** 路线图 R = (N, D, ℓ, C, μ, ρ, G, B, τ, ver)。N 为技能/债节点；D 为依赖边（先序 DAG）；ℓ ∈ {L−1, L0, …, L5} 为成熟度（L−1 已解除认证、L0 缺口登记、L1 规格与合同、L2 沙箱原型、L3 仿真认证、L4 影子/金丝雀、L5 发布）；C 为学习与认证成本分布；μ 为期望 VoL；ρ 为学习风险（负迁移、干扰、数据投毒）；G 为关卡证据；B 为预算；τ 为时间盒与复审周期；ver 为路线图版本。路线图是**元策略**：它的动作是「投资/暂停/终止/发布某技能」，状态是 (债账本, 技能库, 预算, 证据)。

**定义 316（学习价值 VoL）** 对债 d 与候选技能 σ：
VoL(d, σ) = [ E_{s~D_d}(U_comp(s) − U_comp^{σ}(s)) + β·ΔDebt_downstream(d, σ) ] · P_gate(σ) / (C_learn(σ) + C_gate(σ)) − λ_i·I_interf(σ) − λ_r·ρ_learn(σ)。
第一项是能力缺口缩减与下游债务缩减，P_gate 是候选通过全部门控的估计概率，分母是总投入，后两项惩罚负迁移与学习过程风险。VoI 与 VoL 的分工：VoI 是**信念熵的短期下降**，VoL 是**能力集与长期代价的改善**；二者不可互相替代（引理 19）。

**定义 317（路线图调度器 SRO）** 给定债账本、技能库、预算 B 与依赖 DAG，SRO 求解
max_{x∈{0,1}^N} Σ_n x_n μ_n − λ_ρ Σ_n x_n ρ_n，s.t. x_n ≤ x_parent (∀(parent,n)∈D)，Σ_n x_n C_n ≤ B，ℓ_n 的晋升路径合法。
这是带先序约束的随机背包/项目组合选择，一般 NP-hard。SRO 不追求全局最优，而采用可审计的**依赖感知密度贪心 + 分位数上界 + 人工复核**：每轮按 VoL/C 排序，跳过依赖未满足或预算不足的节点；在关卡事件、债到期、分布漂移时重规划。每次重规划记录「为何选它、为何不选它、放弃了什么」，供 RDA 审计。

**定义 318（技能学习管线 SLP）** 离线学习算子 Learn: (d, Σ) → σ_candidate。练习分布
p_practice = mixture(D_d, boundary(D_d), adversarial(D_d), poison_suite)，
其中 boundary 覆盖前置/后置边界与包络边缘，adversarial 覆盖扰动与组合接缝，poison_suite 覆盖投毒/共谋/幻觉。学习器可用演示、仿真自博弈、离线 RL 或流匹配技能蒸馏；输出必须包含 φ/ψ/β/E 与训练证据，不得直接写运行时。学习目标不是「在 D_d 上拟合」，而是「产出可通过分级门且不破坏已认证套件的模块」。

**定义 319（分级门 SGL）** 关卡阶梯 G0–G5：
G0 规格与合同（φ/ψ/β/E 完整、可测）；G1 沙箱功能（单元/边界/接缝）；G2 仿真分布（名义 + 对抗 + 投毒 + OOD）；G3 影子回放（日志数据上的反事实风险与包络检查）；G4 金丝雀（受限运行时、监控、自动回滚）；G5 发布（证书、监控、有效期）。
每级只升不跳；通过条件为性能下置信界 ≥ τ_perf、风险上置信界 ≤ ε_gate、已认证套件回退 ≤ ε_forget、接缝测试通过。学习器与评估器必须数据隔离/职责分离；失败退回上一级并记录沉没成本；连续失败触发终止/重设计。

**定义 320（证书 J_SKILLMAP）** J_SKILLMAP = (J_FLUID, roadmap_hash, skill_versions, gate_evidence_root, U_comp_before/after, debt_ledger_hash, interference_score, envelope_hash, expiry, skillmap_ver)。Valid ⇔ Valid(J_FLUID) ∧ 运行时技能全在 Σ_cert ∧ 关卡链完整未过期 ∧ 组合接缝证书有效 ∧ 无未处理的解除认证事件。

**定义 321（干扰与遗忘护栏 IFG）** 对已认证套件 Σ_cert 定义后向迁移 BT(σ) = max_{σ'∈Σ_cert} [J_{σ'}(发布后) − J_{σ'}(发布前)]_+。发布规则拒绝任何 BT(σ) > ε_forget 的更新；使用技能隔离（按技能适配器/参数分区）、回放缓冲与组合接缝回归。护栏把「新技能变强」约束为「旧技能不变差」。

**定义 322（迁移与仿真-现实差 TSM）** 候选技能在 p_practice 上认证，但部署分布 p_deploy 可能不同。定义迁移裕度 δ_transfer = W_1(p_practice, p_deploy)·L_loss + 统计置信项；关卡要求风险上界加 δ_transfer 后仍 ≤ ε_gate。发布后持续监控协变量/残差漂移；漂移超阈值即降级、解除认证或回滚。该定义把 R68 的「测量还准吗」升级为「**我学到的技能在真实分布里还成立吗**」。

**定义 323（运行时能力感知调度与三响应）** 每步运行时：
(1) 执行 R69，得 (U_ale, U_epi) 与候选交互 g；
(2) 从 CDL/技能库估计 Û_comp，并检查是否存在适用且已认证的技能/组合；
(3) 若存在适用已认证技能 → 正常调度（R69 路径 + 技能选择）；
(4) 若 Û_comp 高且 VoI 未耗尽 → 走 R69 的 ask；
(5) 若 VoI 耗尽或不可交互 → 登记/更新技能债，执行 retreat（R68 最保守或任务重谈），**绝不在线学习、绝不执行未认证技能**。
三响应的优先级由成本比较决定：ask 若 VoI>c；否则 learn 若 VoL>τ_VoL 且路线图可排；否则 retreat/avoid。

**定义 324（路线图审计 RDA / VQAuditor-R）** 审计对象从「单步决策」升级到「能力投资决策」：VoL/U_comp 估计是否校准、关卡是否独立、债是否被系统性低估/膨胀、是否被单一指标捕获、是否存在沉没成本偏置、组合是否过度集中、人类否决是否被绕过。审计结论回灌预算先验、关卡阈值与路线图版本；RDA 对路线图本身拥有**冻结/降级/要求复审**的权力。

**定义 325（技能债经济学）** 债的优先级 p_d = rec_d · sev_d · recency_d · strategic_weight_d，并带「利息」：未偿还债会以人工接管率、保守停机时间、任务失败率的形式累积成本。若利息 > 学习成本且 VoL 为正，则升级；若上下文消失或任务退役，则债过期/注销。该定义防止 backlog 无限膨胀，也防止「永远学最紧急的」局部贪婪。

**定义 326（版本化换装、回滚与解除认证）** 技能以版本化适配器/覆盖层部署，发布是原子交换；旧版本保留快照。运行时监控前置/后置条件、包络、接缝与证书有效期；任一越界触发解除认证（ℓ→L−1）与回滚，CDL 记录事故债。解除认证不得被学习器自动撤销，必须重新走关卡。

**定义 327（人机共治与预算）** 高风险技能（不可逆动作、强人机耦合、社会/伦理敏感）与超阈值预算必须经人类签核；人类可在任意关卡否决/暂停/改变路线图优先级。共治不是形式审批：RDA 向人类提供「能力债、VoL 分布、关卡证据、放弃选项」的可读摘要，确保否决是知情否决。

**定义 328（快慢环解耦与能力层时序）** 快环（R68/R69 实时控制）周期为毫秒级，只读技能库与证书；慢环（CDL/SRO/SLP/SGL/RDA）周期为小时–周级，只写离线产物与路线图版本。两环通过**版本化发布事件**耦合：慢环不能直接改快环参数；快环不能触发在线学习，只能登记债。若快环检测到证书过期/包络越界，立即回退到上一已认证版本或 R68 保守。

## 3. 推导

**引理 19（VoI 的能力盲区）** 设状态 s 的任务需要动作 a*，而 a* 不在当前策略 π_θ 的支撑集内；信息动作 g 只更新对模态 M 的信念，不扩展支撑集。则对任意 g，H(M|o,y)=H(M|o)，故 VoI(g)=0，但 U_comp(s)=1。系：R69 的「VoI≤c ⇒ 不交互 ⇒ λ_floor(U_ale+U_epi)」会把能力缺口误判为不可约不确定性；**VoI 归零是能力债的必要信号之一，而不是世界不可知的证明**。

**引理 20（三源技能债登记的上界）** 若「重复失败」「无适用认证技能」「VoI 耗尽」三源在给定非能力缺口条件下条件独立，误登记率 p_fp ≤ p_1 p_2 p_3；若三源相关，则用 union bound p_fp ≤ min_i p_i。系：三源规则把「一次失败」升级为「可复现、可执行性缺失、信息已尽力」的能力主张；漏登记率取决于证据覆盖，需 RDA 定期抽样人工复核。

**引理 21（分级门的安全保持）** 若每级门控在独立留出数据上使用有效的 (1−δ) 风险上置信界，且仅当 UCB + δ_transfer ≤ ε_gate 时晋升；金丝雀监控在包络越界时以概率 ≥ 1−γ 触发回滚；则在 p_deploy 与 p_practice 的 W_1 距离为 Δ 时，已发布技能部署风险 ≤ ε_gate + δ + L·Δ + γ（L 为损失对分布的 Lipschitz 常数）。系：**证书不是「训练集通过」，而是「带迁移裕度与回滚概率的部署风险上界」**；分布漂移越大，门控越保守，必要时拒绝发布。

**引理 22（遗忘护栏的套件单调性）** 若每次发布都拒绝 BT(σ)>ε_forget 的候选，并对技能做隔离/回放，则在任务分布平稳时，已认证套件的最大单项性能回退 ≤ ε_forget·(#releases)，组合接缝回退 ≤ ε_forget_seam；若分布漂移，则单调性失效，必须依赖定义 322 的漂移监控与解除认证。系：护栏保证「学新不毁旧」，但不能保证「旧技能仍适用于新世界」。

**引理 23（路线图调度的可证近似与不可证情形）** 在无依赖、单位成本、基数预算且 VoL 单调子模时，按 VoL 排序的贪心达到 1−1/e 近似；在一般先序 DAG 与异构成本下，问题是 NP-hard，不存在无条件常数近似，故 SRO 必须用「可审计启发式 + 分位数上界 + 人工复核」。系：**路线图的价值不在于求出最优顺序，而在于让「放弃什么、为什么放弃」可被审计**；这正是技术路线图相对于局部贪心的制度优势。

**定理 18（SKILLMAP 严格包含 FLUID-RAS）** 若路线图为空、预算 B=0、所有关卡关闭或没有候选达到 G5，则 Σ_cert 不新增技能，运行时在每步与 R69 逐指令相同；学习层只读/写离线状态，不改变快环动作。一般情形下，运行时只执行 Σ_cert 技能，且由引理 21 每个新技能的部署风险 ≤ ε_gate + δ + L·Δ + γ，故整体风险 ≤ max(R69 风险, ε_gate + δ + L·Δ + γ)（按使用频率加权）；当门控关闭时严格等于 R69。**因此 R70 是 R69 在「永不上路线图」边界上的严格退化：安全侧不做让步，能力侧只做受认证的扩展。**

**定理 19（能力单调性及其漂移反例）** 在任务分布平稳、门控单调、无解除认证、债登记无误的条件下，每次发布使覆盖上下文上的 U_comp 非增，故能力集单调扩展；但在分布漂移下，已发布技能可能落入 E_σ 之外或违反 φ/ψ，U_comp 可反弹，甚至高于学习前。故 SKILLMAP 的「能力只增不减」只在稳态成立；**漂移检测、证书过期与解除认证不是可选项，而是定理成立的前提**。

## 6. 本轮最大风险

**一句话**：SKILLMAP-RAS 的最大风险不是「学不会」，而是**把「路线图上的能力」误当成「真实世界的能力」——用未校准的 Û_comp/VoL 学会错误的技能，再用被同一偏差污染的仿真、影子与金丝雀关卡给它盖章；于是系统花掉预算、替换掉 R69 原本诚实的保守，却获得了虚假的能力信心，学错并被认证比不学更危险**。

4. **技能债膨胀或系统性低估** → 利息/过期机制、三源登记、RDA 抽样复核（定义 311、325）；
5. **路线图捕获/Goodhart** → 多目标证据、审计路线图本身、人类知情否决、保留「不学」选项（定义 324、327）；
6. **组合接缝风险** → 接口合同、接缝证书、组合级门控（定义 314、319）；

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** SKILLMAP-RAS = (FLUID-RAS, CDL, SRO, SLP, SGL, RDA, RAS-WM‡)；运行时零学习写；未认证技能零执行；路线图预算/依赖/风险硬约束；证书链完整且可原子回滚。

**定义 311–312（技能债与三类不确定性）** 三源登记：重复任务失败 ∧ 无适用已认证技能 ∧ 信息动作耗尽（或 VoI 上界低于成本）。`U=(U_ale,U_epi,U_comp)`；`U_ale→λ_floor`、`U_epi→VoI 交互`、`U_comp→CDL/SRO 离线学习`；三者不简单加和。

**定义 313–314（技能对象/库/组合）** `σ=(φ,ψ,π,β,E,κ,v,ℓ)`；只有 `s∈E_σ ∧ φ_σ(s)` 可调度；执行后验 `ψ_σ`。组合 `σ1∘σ2` 需 `ψ1⇒φ2`、包络交集非空、接缝时序满足，并携带接缝证书；单技能认证不外推到组合。

**定义 315–317（路线图与调度）** `R=(N,D,ℓ,C,μ,ρ,G,B,τ,ver)`；成熟度 L−1~L5；SRO 解带先序约束的随机背包：`max Σx_nμ_n−λΣx_nρ_n` s.t. 先序、预算、晋升合法。一般 NP-hard；采用依赖感知 VoL/C 贪心 + 分位数上界 + 人工复核，记录「放弃什么、为什么」。

**定义 318–319（学习与分级门）** 练习分布 = 债上下文 + 边界 + 对抗 + 投毒；离线产出带合同的候选，不写运行时。G0 规格→G1 沙箱→G2 仿真分布→G3 影子→G4 金丝雀→G5 发布；每级要求性能 LCB、风险 UCB、遗忘回退 ≤ ε_forget、接缝测试通过；学习器/评估器隔离。

**定义 320–322（证书/遗忘/迁移）** `J_SKILLMAP` 并入路线图哈希、技能版本、关卡证据根、`U_comp_before/after`、干扰分、包络哈希、有效期。`BT(σ)=max_{σ'∈Σ_cert}[J_{σ'}(后)−J_{σ'}(前)]_+`，拒绝 `BT>ε_forget`。部署风险加迁移裕度 `δ_transfer=W_1(p_practice,p_deploy)·L+置信项`；漂移超阈值即降级/解除认证。

**定义 323（运行时三响应）** 执行 R69 得 `(U_ale,U_epi)`；若存在适用已认证技能→正常调度；若 `Û_comp` 高且 VoI 未耗尽→ask；若 VoI 耗尽→登记债并 retreat（R68/任务重谈）；**绝不在线学习、绝不执行未认证技能**。`ask` 若 `VoI>c`；否则 `learn` 若 `VoL>τ_VoL` 且可排；否则 `retreat/avoid`。

**定义 324–328（审计/经济/回滚/共治/时序）** RDA 审计路线图本身（VoL 校准、债偏差、指标捕获、沉没成本、组合集中）并可冻结/降级；债有利息、复现率与过期；技能版本化原子换装，包络越界即解除认证与回滚；高风险技能与超阈值预算需人类知情签核；快环毫秒级只读技能库，慢环小时–周级只写离线产物，两环通过版本化发布事件耦合。

## 3. 关键算法伪代码

```python
# IP-264 CDL：能力债账本（只记账，不学习）
class CompetenceDebtLedger:
    def observe(self, s, outcome):
        self.evidence.append((s, outcome))
        if outcome.failed and not self.has_certified_plan(s) and outcome.voi_exhausted:
            self.upsert(self.make_debt(s, outcome))      # 三源证据

    def estimate_comp(self, s, library):
        return 0.0 if library.has_applicable(s) else self.regressor.predict(s)

# IP-265/317 SRO：依赖感知路线图调度（离线）
def plan_roadmap(ledger, library, budget, gates):
    nodes = feasible_nodes(ledger, library, gates)
    chosen, spent, log = [], 0.0, []
    for n in sorted(nodes, key=lambda n: n.voi_per_cost, reverse=True):
        if deps_satisfied(n, chosen) and spent + n.cost_ucb <= budget:
            chosen.append(n); spent += n.cost_ucb
            log.append((n, "selected", n.voi_lcb))
        else:
            log.append((n, "skipped", reason(n)))
    return Roadmap(chosen, gates, budget, log)            # 版本化 + 可审计

# IP-266 SLP：离线技能学习（产出带合同的候选）
def learn_skill(debt, library):
    D = debt.contexts
    practice = mixture(D, boundary(D), adversarial(D), poison_suite)
    sigma = train_option(practice, init=library.nearest(debt))
    sigma.phi, sigma.psi, sigma.beta = infer_contract(sigma, practice)
    sigma.E = estimate_envelope(sigma, practice, safety_margin=EPS_ENV)
    return sigma                                          # 不写运行时

# IP-267 SGL：分级门（学习器/评估器隔离）
def run_gates(sigma, library):
    for level in [G0, G1, G2, G3, G4, G5]:
        ev = eval_heldout(sigma, level, suite=level_suite(level))
        if ev.perf_lcb < TAU_PERF[level]:                       return reject(sigma, level, ev)
        if ev.risk_ucb + ev.transfer_margin > EPS_GATE[level]:  return reject(sigma, level, ev)
        if backward_regression(sigma, library.certified) > EPS_FORGET:
                                                                return reject(sigma, level, ev)
        if not seam_tests_pass(sigma, library, level):          return reject(sigma, level, ev)
        sigma = promote(sigma, level, ev)
    return sigma                                          # 只有 G5 可发布

# IP-269/326 原子发布 + 回滚
def release_atomic(sigma, library):
    snap = library.snapshot()
    library.add_certified(sigma)                          # 版本化适配器，非覆盖写
    if not monitor_ok(sigma, warmup=W):
        library.rollback(snap); sigma.maturity = L_MINUS_1
    return sigma

# IP-273 快环：R69 + 三响应（运行时零学习）
def SKILLMAP_round(M, obs):
    k, lam, mode, (U_ale, U_epi) = M.fluid.round(obs)     # R69 完全不变
    U_comp = M.cdl.estimate_comp(obs, M.library.certified)
    applicable = M.library.applicable_plan(obs)           # 已认证 + 包络内
    if U_comp <= TAU_COMP or applicable is not None:
        return k, lam, mode
    if not M.fluid.voi_exhausted(obs):
        return M.fluid.ask(obs)                           # ask
    M.cdl.observe(obs, Failure(voi_exhausted=True))       # learn（仅登记）
    return M.retreat(obs)                                 # retreat（R68）

# IP-276 慢环（与快环完全解耦）
def offline_tick(M):
    R = M.sro.plan(M.cdl, M.library, M.budget, M.sgl)
    for node in R.ready():
        sigma = M.sgl.run_gates(M.slp.learn(node), M.library)
        if sigma.maturity == G5: M.release_atomic(sigma, M.library)
    M.rda.audit(M.sro, M.sgl, M.cdl)                      # 审路线图本身
```

## 4. 推导

**引理 19（VoI 的能力盲区）** 若任务所需动作 a* 不在当前策略支撑集内，信息动作只更新信念、不扩展支撑集，则对所有 g 有 `VoI(g)=0`，但 `U_comp>0`。系：R69 的「VoI≤成本 ⇒ 保守」会把能力缺口误判为不可约不确定性；VoI 归零是能力债的必要信号之一，不是世界不可知的证明。

**引理 20（三源债登记上界）** 「重复失败」「无适用认证技能」「VoI 耗尽」在非能力缺口条件下条件独立时，误登记率 `p_fp≤p1p2p3`；相关时用 `p_fp≤min p_i`。系：三源规则把一次失败升级为可复现、可执行性缺失、信息已尽力的能力主张。

**引理 21（分级门安全保持）** 若每级门控用独立留出数据上的有效 (1−δ) 风险 UCB，且仅当 `UCB+δ_transfer≤ε_gate` 时晋升；金丝雀包络越界回滚概率 ≥1−γ；则部署风险 `≤ε_gate+δ+L·Δ+γ`（Δ 为练习/部署 W_1 距离，L 为损失 Lipschitz 常数）。系：证书不是「训练集通过」，而是「带迁移裕度与回滚概率的部署风险上界」。

**引理 22（遗忘护栏套件单调性）** 若每次发布拒绝 `BT>ε_forget` 的候选并做隔离/回放，则平稳分布下已认证套件最大单项回退 `≤ε_forget·(#releases)`，接缝回退 `≤ε_forget_seam`；分布漂移时单调性失效，必须依赖漂移监控与解除认证。系：护栏保证「学新不毁旧」，不保证「旧技能仍适用于新世界」。

**引理 23（路线图调度的可证近似与不可证情形）** 无依赖、单位成本、基数预算且 VoL 单调子模时，按 VoL 贪心达 `1−1/e` 近似；一般先序 DAG + 异构成本下 NP-hard，无无条件常数近似，故 SRO 必须用可审计启发式 + 分位数上界 + 人工复核。系：路线图的价值不在于求出最优顺序，而在于让「放弃什么、为什么放弃」可审计。

**定理 18（SKILLMAP 严格包含 FLUID-RAS）** 路线图为空、B=0、关卡关闭或无候选达 G5 时，`Σ_cert` 不新增技能，运行时每步与 R69 逐指令相同；学习层只读写离线状态。一般情形运行时只执行 `Σ_cert`，由引理 21 新技能风险 `≤ε_gate+δ+L·Δ+γ`，整体风险 ≤ max(R69 风险, 该界)（按使用频率加权）；门控关闭时严格等于 R69。安全不让步，能力只做受认证扩展。

**定理 19（能力单调性及漂移反例）** 平稳任务分布、门控单调、无解除认证、债登记无误时，每次发布使覆盖上下文 `U_comp` 非增，能力集单调扩展；但分布漂移下已发布技能可能越出 `E_σ` 或违反 φ/ψ，`U_comp` 可反弹甚至高于学习前。故「能力只增不减」只在稳态成立；漂移检测、证书过期、解除认证是定理成立的前提，不是可选项。

## 5. 复杂度分析

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| 运行时 Û_comp + 技能适用性检查 | < 0.05ms | O(|Σ_cert|) 索引 | 定义 311–313；只读 |
| 债登记（异步摊销） | < 0.05ms/步 | O(债数) | 定义 311；三源规则 |
| 三响应决策 | < 0.02ms | O(1) | 定义 323 |
| **快环总延迟** | **≤ 2.7ms**（R69 2.6ms + 0.1ms） | — | 定理 18；学习不在快环 |
| SRO 重规划 | 10–100ms/次（离线） | O(N·B) | 定义 317 |
| SLP 技能学习 | 小时–天（离线/沙箱） | 技能库 + 证据 | 定义 318；零运行时写 |
| SGL 分级门 | 分钟–小时/候选（离线） | 版本化证据 | 定义 319；引理 21 |
| RDA 路线图审计 | 分钟级/周期 | 审计日志 | 定义 324；可冻结/降级 |

**结论**：学习与门控成本全在慢环，不进入实时预算；快环只增加一次能力查询与一次债登记，P99 与 R69 同一量级。真正的成本是离线算力与人类评审时间，必须用 VoL/成本与预算硬约束治理。

## 7. 本轮最大风险

**一句话**：SKILLMAP-RAS 的最大风险不是「学不会」，而是**把「路线图上的能力」误当成「真实世界的能力」——用未校准的 Û_comp/VoL 学会错误的技能，再用被同一偏差污染的仿真、影子与金丝雀关卡给它盖章；系统花掉预算、替换掉 R69 原本诚实的保守，却获得虚假的能力信心，学错并被认证比不学更危险**。

**次级风险与缓解**：关卡假接受/评估器泄漏（数据隔离 + 独立留出 + 红队 + 自动回滚）；技能干扰/遗忘（IFG 后向迁移护栏 + 隔离 + 回放 + 接缝回归）；仿真-现实漂移（δ_transfer + 漂移监控 + 证书过期 + 解除认证）；技能债膨胀/低估（利息/过期 + 三源登记 + RDA 复核）；路线图捕获/Goodhart（多目标证据 + 审计路线图本身 + 人类知情否决 + 保留「不学」）；组合接缝（接口合同 + 接缝证书 + 组合级门控）；预算机会成本（显式记录放弃选项与沉没成本 + kill criteria）。
