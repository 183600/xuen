### 第 1 轮灵感驱动研究记录（新循环）

**灵感词**：轻量化设计、谐波减速器

**直觉与动机**：
前几轮把「常识/语义」做成了证书链（KC → IEKC → CTKTP → AKWA），但整条链共享一个从未被审视的地基：所有证书都是在**名义动力学模型**上验证的。本轮两个灵感词并非「再挂一个硬件模块」，而是同时从两个方向侵蚀这个地基。

1. **谐波减速器不是理想减速比 N**。它有三类非理想性：(a) 空程/迟滞（lost motion / hysteresis），在小扭矩区形成「死区」，指令角变化而输出角不动；(b) 扭转柔度（torsional compliance），输出角随负载弹性滞后 τ/K_h；(c) 运动学误差（波发生器椭圆化引起的周期性误差 ε_k）。合起来 θ_l = θ_m/N + δ(τ, θ_m)，δ 有界但**非 Lipschitz**（死区处是集值映射），直接破坏 MPC 的平滑性与证书采样所依赖的可微假设。

2. **轻量化设计降低质量/惯量，却往往同时降低结构刚度**。第一阶柔性模态 ω_1 = sqrt(k_1/m_eff) 可能落入控制带宽附近（ρ_mode = ω_1/ω_c 变小）。轻量化的本意是「更灵巧」，实际却让刚体假设失效：同一扭矩误差在低惯量下产生更大加速度误差，且未建模的柔性模态以残差振动形式污染轨迹。

**关键洞见**：前几轮证书回答「计划是否合乎常识」，本轮证书必须回答「我们凭什么相信用来验证计划的模型」。即把**物理保真度（physical fidelity）**提升为一等证书维度：谐波减速器给出执行器级误差上界 E_t，轻量化结构给出模态级误差上界 E_flex；两者合成一个「误差管（error tube）」半径 E_model。常识后置条件不再在名义轨迹上验证，而必须在**膨胀后的管**上验证（tube-based robust tightening）。这样证书才从「名义安全」升级为「物理可实现安全」，也把机械设计（质量/刚度）与控制证书第一次真正闭环。

**形式化目标（增量）**：
1. TFC：|e_t| ≤ b_lost + τ_max/K_h + ε_k =: E_t，其中 e_t = θ_l − θ_m/N。
2. LSFC：模态分离比 ρ_mode = ω_1/ω_c ≥ ρ_min，且残差模态挠度上界 E_flex ≤ d_max。
3. 误差管：E_model = ||J||·E_t + E_flex，J 为关节角→任务空间雅可比。
4. 保真度收紧：Q_i^fid = { x : dist(x, ∂Q_i) ≥ E_model }。
5. FA-KEMPC：在 Q_i^fid 上做知识惩罚与验证，而非 Q_i。
6. CALD：在 φ_fid ≥ φ_min、ρ_mode ≥ ρ_min 约束下最小化总质量，得到「证书可行轻量化设计域」。
7. 健全性：若 TFC、LSFC 成立且单步模型误差有界 E_model，则名义计划满足 Q_i^fid ⇒ 实际硬件满足 Q_i。

**本轮最大风险**：**保真度自证悖论**——E_model 本身来自一个被简化的模型（单模态、常值 K_h/b），若它被低估（漏掉二阶柔性模态、负载相关空程、温漂），误差管就过窄，证书在「轻量化 + 高带宽」工况下恰恰变得不可靠；此时证书链用未被证书验证的保真度去验证一切，形成自我指涉的盲区。

## 2. 关键算法骨架（在 IP-462~466 骨架上扩展）

### IP-467 Transmission Fidelity Certificate (TFC)

```python
@dataclass
class TransmissionFidelityCertificate:
    """TFC：谐波减速器执行器保真度证书"""
    N_h: float                  # 减速比
    b_lost: float               # 空程半宽（输出端 rad）
    K_h: float                  # 扭转刚度 N·m/rad
    eps_kin: float              # 运动学误差幅值 rad
    tau_max: float              # 时域内峰值负载扭矩 N·m
    H: int = 20                 # 验证时域
    margin: float = 0.1         # 安全裕度比例

    def transmission_error_bound(self) -> float:
        """E_t = 空程 + 弹性绕曲 + 运动学误差（三角不等式）"""
        return self.b_lost + self.tau_max / self.K_h + self.eps_kin

    def transmission_error(self, theta_m: float, tau: float) -> float:
        """e_t = θ_l − θ_m/N_h；死区处取保守符号近似"""
        tau_dead = self.K_h * self.b_lost
        if abs(tau) < tau_dead:
            lost = self.b_lost * math.tanh(tau / max(tau_dead, 1e-9))
        else:
            lost = self.b_lost * math.copysign(1.0, tau)
        windup = tau / self.K_h
        kin = self.eps_kin * math.sin(theta_m / self.N_h)
        return -(lost + windup) + kin

    def lipschitz_envelope(self) -> float:
        """死区非 Lipschitz；给出保守全局 Lipschitz 常数，
        用于误差管传播（空程项在死区内斜率被 tanh 平滑为 b_lost/tau_dead）"""
        return 1.0 / self.K_h + self.b_lost / max(self.K_h * self.b_lost, 1e-9)

    def verify(self, tau_seq, theta_m_seq) -> tuple[bool, float]:
        bound = self.transmission_error_bound() * (1.0 + self.margin)
        errs = [abs(self.transmission_error(th, ta))
                for th, ta in zip(theta_m_seq, tau_seq)]
        e_max = max(errs) if errs else 0.0
        return e_max <= bound, e_max
```

### IP-468 Lightweight Structural Fidelity Certificate (LSFC)

```python
@dataclass
class LightweightStructuralFidelityCertificate:
    """LSFC：轻量化结构保真度证书（单模态 + 残差界）"""
    m_eff: float                # 一阶模态有效质量 kg
    k_1: float                  # 一阶模态刚度 N/m
    zeta_1: float               # 一阶模态阻尼比
    omega_c: float              # 控制闭环带宽 rad/s
    rho_min: float = 3.0        # 最小模态分离比
    d_max: float = 1e-3         # 允许残差挠度 m
    H: int = 20

    def omega_1(self) -> float:
        return math.sqrt(self.k_1 / self.m_eff)

    def modal_separation(self) -> float:
        return self.omega_1() / self.omega_c

    def residual_deflection_bound(self, a_max: float) -> float:
        """二阶模态对加速度激励的响应上界：静态柔度 × 谐振放大"""
        q_static = self.m_eff * a_max / self.k_1
        Q_amp = 1.0 / (2.0 * max(self.zeta_1, 1e-6))
        return q_static * Q_amp

    def verify(self, a_max: float) -> tuple[bool, dict]:
        rho = self.modal_separation()
        e_flex = self.residual_deflection_bound(a_max)
        ok = (rho >= self.rho_min) and (e_flex <= self.d_max)
        return ok, {"rho_mode": rho, "E_flex": e_flex}
```

### IP-469 Fidelity-Aware KEMPC (FA-KEMPC)

```python
@dataclass
class FidelityAwareKEMPC:
    """FA-KEMPC：带误差管收紧的知识增强 MPC"""
    dynamics: Callable
    kc_list: list                    # IEKC/KC 列表（含后置条件 Q_i）
    tfc: TransmissionFidelityCertificate
    lsfc: LightweightStructuralFidelityCertificate
    jacobian: Callable               # J(q): 关节角 → 任务空间
    horizon: int = 20
    dt: float = 0.01
    weights: dict = field(default_factory=dict)
    phi_min: float = 0.3
    E_budget: float = 0.02           # m，证书允许的最大模型偏差

    def error_tube_radius(self, a_max: float) -> float:
        E_t = self.tfc.transmission_error_bound()
        _, info = self.lsfc.verify(a_max)
        E_flex = info["E_flex"]
        Jn = self._jacobian_norm_max()
        return Jn * E_t + E_flex

    def fidelity_margin(self, a_max: float) -> float:
        E_model = self.error_tube_radius(a_max)
        return max(0.0, min(1.0, 1.0 - E_model / max(self.E_budget, 1e-9)))

    def tighten_postcondition(self, Q: Callable, gamma: float) -> Callable:
        """Q_i^fid：后置条件成立且到边界距离 ≥ gamma"""
        return lambda x: Q(x) and self._boundary_margin(x) >= gamma

    def solve(self, x0: Tensor, a_max: float) -> tuple[Tensor, dict]:
        gamma = self.error_tube_radius(a_max)
        phi = self.fidelity_margin(a_max)
        if phi < self.phi_min:
            # 保真度不足：不允许用知识证书背书，降级为保守回退
            return self._conservative_fallback(x0), {"phi_fid": phi, "gamma": gamma,
                                                     "mode": "fidelity_fallback"}
        tightened = [(kc, self.tighten_postcondition(kc.postcond, gamma))
                     for kc in self.kc_list]
        # 复用 KT-MPC 的 QP，但惩罚/约束均作用在 tightened 后置条件上
        u = self._solve_tube_qp(x0, tightened)
        return u, {"phi_fid": phi, "gamma": gamma, "mode": "tube_tightened"}
```

### IP-470 Physical Fidelity Gate (PFG，并入 KTCG)

```python
def admits(self, robot_plan: 'RobotPlan', sensor_data: dict) -> bool:
    """在 KTCG 九证基础上追加两证：十证/十一证联合准入"""
    # ... 原有 1~9 项 KTCG 检查 ...

    # 10. TFC：谐波减速器传输误差在界内
    ok_t, e_max = self.tfc.verify(robot_plan.tau_seq, robot_plan.theta_m_seq)
    if not ok_t:
        return False

    # 11. LSFC + FA-KEMPC：结构保真度与误差管收紧
    ok_s, info = self.lsfc.verify(robot_plan.a_max)
    if not ok_s:
        return False
    phi = self.fakempc.fidelity_margin(robot_plan.a_max)
    if phi < self.fakempc.phi_min:
        return False

    # 12. 证书一致性：实际跟踪误差必须落在误差管内
    E_model = self.fakempc.error_tube_radius(robot_plan.a_max)
    if robot_plan.tracking_error_norm > E_model:
        return False

    return True
```

### IP-471 Certificate-Aware Lightweight Design (CALD)

```python
def certificate_aware_lightweight_design(
        mass_candidates, stiffness_candidates, omega_c, a_max,
        rho_min=3.0, phi_min=0.3, E_budget=0.02, d_max=1e-3):
    """在保真度约束下最小化总质量，返回证书可行设计域中的最轻解"""
    feasible, best = [], None
    for m in mass_candidates:
        for k in stiffness_candidates:
            lsfc = LightweightStructuralFidelityCertificate(
                m_eff=m, k_1=k, zeta_1=0.05, omega_c=omega_c,
                rho_min=rho_min, d_max=d_max)
            ok, info = lsfc.verify(a_max)
            if not ok:
                continue
            phi = 1.0 - info["E_flex"] / E_budget
            if phi < phi_min:
                continue
            feasible.append((m, k, phi, info))
            if best is None or m < best[0]:
                best = (m, k, phi, info)
    return best, feasible
```

## 3. 复杂度分析（增量更新）

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 |
|---|---|---|---|
| TFC 验证 | O(H) | O(1) | H≤20 |
| LSFC 模态分析 | O(1) 闭式 | O(1) | 单模态 + 残差界 |
| FA-KEMPC 误差管收紧 | O(N·n_x·N_rule) | O(N·N_rule) | N=20, N_rule≤50 |

**实时性**：TFC/LSFC 均为 O(1)~O(H) 闭式计算（<0.5ms）；FA-KEMPC 的收紧只增加约 8–12% 约束构造开销，主瓶颈仍是 QP 求解（5–15ms）。CALD 完全离线，用于设计阶段。

## 4. 正确性论证（增量更新）

### 引理 26（TFC 传输误差上界性）
**陈述**：对任意 θ_m、τ，|e_t(θ_m,τ)| ≤ b_lost + τ_max/K_h + ε_k = E_t。
**证明**：e_t = −(lost(τ) + τ/K_h) + ε_k·sin(θ_m/N_h)。由 |lost| ≤ b_lost、|τ| ≤ τ_max 得 |τ/K_h| ≤ τ_max/K_h、|ε_k sin| ≤ ε_k，三角不等式即得。∎

### 引理 27（LSFC 模态分离的刚体近似误差界）
**陈述**：若 ρ_mode = ω_1/ω_c ≥ ρ_min，则刚体模型相对含一阶柔性模态的真实系统，其轨迹偏差被 E_flex = (m_eff·a_max/k_1)·(1/2ζ_1) 上界约束。
**证明**：柔性模态满足 q̈ + 2ζ_1ω_1 q̇ + ω_1² q = f/m_eff。对加速度型激励，稳态响应幅值 ≤ (m_eff a_max/k_1)·(1/2ζ_1)。由奇异摄动理论，当 ω_1 ≫ ω_c 时慢流形即刚体动力学，其偏差为 O(1/ρ_mode²)；取一阶保守界即 E_flex。∎

### 引理 28（误差管不变性）
**陈述**：若单步模型误差 ≤ E_model，且 x_k ∈ T(x_k^nom, E_model)，则 x_{k+1} ∈ T(x_{k+1}^nom, E_model)，∀k ≤ H。
**证明**：对动力学做 Lipschitz 假设（死区用 TFC.lipschitz_envelope 的保守包络替代集值映射），由三角不等式与归纳法即得。∎

### 定理（FA-KEMPC 的物理健全性）
**陈述**：若 TFC 与 LSFC 均成立（故 ||x_true − x_nom|| ≤ E_model），且 FA-KEMPC 找到满足所有收紧后置条件 Q_i^fid（γ_fid = E_model）的计划，则实际硬件轨迹满足所有原始后置条件 Q_i。
**证明**：对任意 x_true 满足 ||x_true − x_nom|| ≤ E_model，且 x_nom ∈ Q_i^fid（即 dist(x_nom, ∂Q_i) ≥ E_model），由距离三角不等式得 x_true ∈ Q_i。对所有 i 与所有 k 成立。∎

### 推论（CALD 可行设计域）
**陈述**：满足 LSFC、TFC 且 φ_fid ≥ φ_min 的 (m,k) 集合即「证书可行轻量化设计域」；在其上最小化总质量，得到最轻的可证书化设计。
**证明**：由引理 26、27 与 φ_fid 定义直接可得约束闭集；目标函数为质量线性/单调，故最优点位于可行域边界。∎

## 5. 已知风险与缓解（增量更新）

| 风险编号 | 描述 | 严重度 | 缓解措施 | 剩余风险 |
|---|---|---|---|---|
| R25 | 空程死区非 Lipschitz，误差管传播可能不健全 | 高 | 1) tanh 平滑 + 保守 Lipschitz 包络；2) 换向点附近加密采样；3) 死区内强制低速 | 高频往复运动时保守界可能过宽或漏检 |
| R26 | 轻量化结构高阶柔性模态未建模，E_model 被低估 | 高 | 1) 多模态残差界叠加；2) 模态试验标定；3) 在线残差监测触发降级 | 高阶模态与一阶耦合时单模态界不成立 |
| R27 | K_h、b_lost 随温漂/磨损漂移，TFC 失效 | 中 | 1) 在线集员估计参数区间；2) 周期性辨识；3) 参数越界即降级 | 快速温变下估计滞后 |
| R28 | 证书约束过强导致轻量化目标不可行或过重 | 中 | 1) 分层放松 ρ_min/φ_min；2) 多目标 Pareto 前沿；3) 允许局部加强而非全局加重 | 与轻量化初衷冲突，需设计权衡 |
| R29 | 误差管收紧导致性能下降或 QP 不可行 | 中 | 1) 软约束 + 松弛变量；2) 自适应 γ_fid；3) 不可行时保守回退 | 极端工况下频繁回退，损失机动性 |
| **R30** | **保真度自证悖论：E_model 由未验证的简化模型给出** | **高** | **1) 独立在线残差监测（set-membership）交叉校验 E_model；2) E_model 取多模型包络；3) 保真度证书本身附带不确定度上界并参与准入** | **当真实模型误差超出估计上界时，证书链整体失去健全性，且难以在线察觉** |

## 6. 本轮最大风险（最终确认）

**一句话**：**保真度自证悖论**——TFC/LSFC 给出的误差管半径 E_model 本身来自被简化的模型（单模态、常值 K_h/b），一旦它被低估（漏掉高阶柔性模态、负载相关空程、温漂），误差管就过窄，证书在「轻量化 + 高带宽」工况下恰恰最不可靠；此时证书链用一个未被证书验证的保真度去验证一切，形成自我指涉的盲区，比前几轮的「迁移负外部性」更根本，因为它动摇了所有证书共同依赖的动力学地基。
