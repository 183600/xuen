# 第 3 轮（灵感循环第 3 轮；本轮灵感：「VLA」×「末端位姿」）

> **基线继承**：第 2 轮 **ToolGauge**（IP-315–320；定义 416–431；引理 46–50；实验 E426–E439）。
> 本轮纪律：**只加一层几何条件，不改内核**——ToolGauge 的 6C 闭环、MTC/TCV、AP-Cal、P-Quarantine、
> 语言审计层与 MODGAUGE 五不变式全部保留；本轮把「盲区 / 探测 / 校准 / 修复」四个对象统一提升到
> **SE(3) 末端位姿条件**下，新增 P-Box / Pose-TCV / NBP / PN-Cal / Equi-AP-Cal / O-Quarantine。
>
> **基线审计先行（本轮不追认空洞编号）**：
> 1. 第 2 轮产物头部声称实验增量 E426–E440，正文只定义到 E439，**E440 是空洞**；本轮从 **E441** 起，
>    不替第 2 轮补写 E440。
> 2. ToolGauge 的盲区 `s=(d,m,i)` 与位姿无关：**访问即覆盖**——从一个信息量近零的位姿看一眼，
>    格子就被记为已修复。这是第 2 轮 §5 六类缺陷之外的第 7 类，也是本轮全部设计的起点。
> 3. MP-Φ 的上下文 `featurize_ctx(receipts,H,s)` 不含 `g`；同一物体在不同位姿下的回执被当作同分布样本，
>    位姿异方差被平均掉，后验因此**过度自信**。
> 4. 第 2 轮断言「语言永不进入数值通道」，但**位姿是数值**：只要 VLA 能提议一个具体位姿，
>    语言就通过空间侧间接进入了数值通道。本轮把 VLA 的空间提议权降格为「符号位姿约束提议」，
>    数值位姿由几何求解器产生、由验证器签署。
>
> 新增定义 **432–447**、引理 **51–57**、IP **321–326**、实验 **E441–E457**。

## 三位一体映射（升级而非重写）

| 灵感词 | 第 2 轮对象 | 升级为 | 一句话动机 |
|---|---|---|---|
| 视觉-语言-动作模型（VLA） | L-Box：VLA 生成**语义**假设，只被审计「说了什么」 | **G-Box**：VLA 生成**位姿条件假设 + 符号位姿约束**，并接受几何接地审计 | 第 2 轮审计了 VLA 的「词」，没审计 VLA 的「哪里」；而「哪里」才是动作模型真正输出的东西 |
| 末端位姿 | MTC/TCV：工具 = 抽象契约，回执 = 数值观测 | **MTC^pose / Pose-TCV / P-Box**：工具契约、盲区覆盖、回执有效性全部以 SE(3) 位姿为条件 | 一次测量不是「用了什么工具」的函数，而是「从哪个位姿测」的函数；位姿决定可观测性、噪声与可达性 |
| 合成 | ToolGauge 6C：H→C→E→C→V→U | **PoseGauge 6C+**：H(g)→C(g)→E(g)→C(g)→V(g)→U(g)，修复在物体坐标系表示、沿 SE(3) 轨道传输 | 位姿既是探测的输入，也是修复的作用域；不把「作用域」写进证书，修复就不可审计 |

**核心命题**：把 ToolGauge 的「语义假设 → 契约化工具调用 → 摊销校准 → 交叉验证后局部热替换」升级为
「**位姿接地假设 → 位姿契约化探测路径 → 可观测性加权校准 → 等变传输 + 位姿分层验证后轨道级热替换**」。
VLA 只做两件被审计的事（提位姿条件假设、提符号位姿约束），数值位姿由几何求解器与 Pose-TCV 产生并签署；
数值真值仍由计量层独占。位姿不再是一个隐含的执行细节，而是与 `(d,m,i)` 同等的**一等计量变量**。

**不变式保持声明**：
- MODGAUGE 五不变式全部保留；
- 主张绑定不变式的**位姿扩展**：语言中出现的方位/路径/接触点主张必须引用有效位姿回执（定义 444），
  否则在契约序列化时剥离；
- **严格退化链延长**：PoseGauge 失效（位姿估计不可用 / 可达性失败 / 位姿分层共形失效 / 可观测性隔离触发 /
  预算耗尽）⇒ 退回 ToolGauge 的位姿无关路径 ⇒ 再退回 LeanGauge ⇒ 再退回 MODGAUGE。
  VLA 与位姿层都是增强项，不是依赖项。

## 0. 直觉与动机

**灵感 1（末端位姿 → 测量是「站在哪里」的函数）**
直觉：ToolGauge 把盲区写成 `(d,m,i)`，隐含假设「这个格子只要被访问过，就被观测过」。这在计量学里是
基本错误：**可观测性依赖观测位姿**。镜面反射在掠射角饱和、透明体在逆光下无对比、深孔在正面被遮挡、
柔性表面在侧向才露出形变；同一个物体从位姿 `g₁` 看是清晰的，从 `g₂` 看可能信息量为零。
更隐蔽的是：无信息位姿的观测往往**看起来很精确**（传感器噪声很小），于是系统会自信地把它当作
「该格子已覆盖」。因此盲区必须先升格为 `s̃=(s,g)`，覆盖必须按**可观测性加权**计量，
而不是按「访问次数」计量。

**灵感 2（位姿误差是 nuisance，不是 sensor noise）**
直觉：末端位姿从来不是精确已知的：正运动学误差、关节回差、连杆柔度、抓取滑移、物体位姿估计误差，
都会让「实际观测位姿」偏离「指令位姿」。这些误差经过观测雅可比 `J_g` 传播进观测，
与传感器噪声混在一起。危险之处在于：**位姿误差与物体属性在某些方向上共线**——物体表面稍微鼓起
可以被解释为「物体属性变了」，也可以被解释为「末端位姿偏了 2mm」。若不做可辨识性分析，
校准层会把位姿误差吸收进物体参数，得到一个**局部精确、跨位姿错误**的模型。
所以本轮把观测协方差显式分解为 `J_g Σ_g J_gᵀ + Σ_sensor + Σ_model(g)`，
并引入位姿可辨识性（Schur 补）判据：不可辨识的位姿是**退化位姿**，贡献零覆盖。

**灵感 3（VLA → 会提「从哪里看」，但必须先接地再相信）**
直觉：VLA 最擅长的恰恰是「语义 + 空间」的联合提议：它可以说「从把手左上方 30° 接近」，
但这句话既可能来自真正的场景理解，也可能来自训练集里的常见构图，甚至来自对抗纹理。
第 2 轮已经用 SNC 和输入白名单审计了「词」，但位姿提议仍然是一条**语言 → 数值**的暗道：
只要 VLA 直接输出 `g=(x,y,z,roll,pitch,yaw)`，语言就进入了数值通道。
本轮的处理不是禁止 VLA 提位姿，而是把提议降格为**符号位姿约束**（部件 + 关系 + 方向 + 容差），
由预注册的位姿词典接地到约束集，再由几何求解器求可行位姿，最后由 Pose-TCV 验证可达、无碰、
非奇异、非退化、路径安全。VLA 的提议只有通过验证才有资格变成回执。

**灵感 4（等变是双刃剑：一次修复覆盖整条轨道，一次错误也覆盖整条轨道）**
直觉：如果世界模型与观测模型对刚体变换等变，那么在物体坐标系里学到的修复，应当可以通过共轭作用
传输到同一物体的其他位姿——这正是「修一次、用一条轨道」的样本效率来源。
但等变同样是误差放大器：如果修复本身有等变缺陷 `ε_eq`，传输误差会随轨道长度累积；
更糟的是，若位姿条件可观测性模型错了，等变先验会让系统**在整条轨道上同时过度自信**。
因此等变必须与三个审计器一起使用：等变缺陷估计（定义 441）、位姿分层共形（定义 442）、
可观测性隔离（定义 445）。

## 1. 形式化定义（增量：定义 432–447）

**定义 432（位姿条件盲区与有效覆盖 ECov）** 设物体坐标系为 `B`，末端执行器相对物体的位姿
`g ∈ SE(3)`。位姿条件盲区 `s̃=(s,g)`。对格子 `s`，令可观测性权重
`w_s(g) = ½·log det(I + Σ_u^{1/2} H_s(g)ᵀ Σ_obs(g)⁻¹ H_s(g) Σ_u^{1/2}) ≥ 0`
（`H_s(g)=∂h_s/∂u`，`Σ_obs` 见定义 438；退化位姿按定义 439 置 `w_s(g)=0`）。
**有效覆盖**定义为
`ECov(s) = Σ_{g∈V(s)} w_s(g)·vol(cap(g)) / Σ_{g∈G_feas} w_s(g)·vol(cap(g))`，
其中 `V(s)` 是已访问位姿胶囊（定义 433），`vol` 为胶囊体积。
`R̃[s] = covered` **当且仅当** `ECov(s) ≥ θ_cov` 且 `max_{g∈V(s)} w_s(g) ≥ w_min`；
否则 `s` 仍是盲区，并额外记录「已访问但无效」位姿集 `D(s)`。
本定义直接替换 ToolGauge 的「访问即覆盖」语义；它是第 2 轮 D-Box 覆盖矩阵的严格细化，
令 `g` 唯一、`w_s(g)∈{0,1}` 时退化为第 2 轮定义 398。

**定义 433（位姿胶囊与对称商）** 用半径 `Δ_g` 的球覆盖可行位姿流形 `G_feas ⊆ SE(3)`：
`G_feas ⊆ ⋃_k B(g_k, Δ_g)`。选 `Δ_g = ε_H / L_H`，其中 `L_H` 是观测雅可比 `H_s(g)` 的 Lipschitz 常数，
保证同一胶囊内 `‖H_s(g)−H_s(g_k)‖ ≤ ε_H`（胶囊内可观测性近似常值）。
若物体有对称群 `G_sym`（例如圆柱绕轴 `SO(2)`、方块含 90° 旋转），在商空间 `SE(3)/G_sym` 上记录轨道；
覆盖与修复证书以**轨道代表元 + 轨道作用域**描述，而不是枚举整个世界位姿。

**定义 434（位姿增强工具契约 MTC^pose，推广定义 416）**
`t = (Schema^pose_t, Pre^pose_t, Post^pose_t, c_t(g), τ_t(g), Ĝ_t(h;g))`：
- `Schema^pose_t` 包含位姿参数 `g`、路径 `γ`、工具参数；
- `Pre^pose_t` 在定义 416 的力/温/时序包络之外，新增：① 逆运动学可达；② 无碰路径存在；
  ③ 可操作度 `μ(g) ≥ μ_min`；④ 非奇异（`σ_min(J(g)) ≥ σ_min^0`）；⑤ 路径证书 `PathCert(γ)` 通过；
- `Post^pose_t` 的回执必须含实际位姿 `g_actual`、位姿协方差 `Σ_g` 与路径哈希（定义 435）；
- `c_t(g)`、`τ_t(g)` 随位姿变化（远距离/绕障/低速区更贵）。
工具库 `T₀^pose = T₀ × G_feas`，即「工具 × 可行位姿」；仍然完全预注册，VLA 不能发明新工具或新位姿原语。

**定义 435（位姿回执与位姿有效性，推广定义 417）**
`r = (t, args, g_cmd, g_actual, Σ_g, obs=(μ,σ_decl), path_hash, sig, ts, seq)`。
`valid(r) ⇔ Schema^pose_t ∧ Pre^pose_t(执行时刻) ∧ Post^pose_t ∧ Verify(sig) ∧ seq 单调
∧ ‖g_actual ⊖ g_cmd‖²_{Σ_g} ≤ χ²_{d_g,1−β_pose}`。
最后一项是**位姿偏差检验**：实际位姿偏离指令位姿超过统计包络时，回执作废。
作废回执永不进入校准样本集；但「位姿偏差作废」与「传感器故障作废」分开计数，供 O-Quarantine 使用。

**定义 436（位姿程序与路径证书，推广定义 418）**
`Π_s = ((t₁,a₁,γ₁),…,(t_L,a_L,γ_L))`，`γ_i:[0,1]→SE(3)` 为连续路径（不仅是路点）。
`PoseTCV(Π_s)` 在 TCV 四查之外增加：
① 每段路径的碰撞走廊证书（基于预注册几何/点云下界）；
② 关节限位与速度/加速度包络；
③ 控制屏障函数（CBF）安全裕度 `h_CBF(γ(t)) ≥ 0`；
④ 区间算术给出的位姿跟踪误差上界 `‖g_actual(t)⊖γ(t)‖ ≤ Δ_track`。
任一条实测失败 ⇒ 该调用 `void`，程序以完成前缀收尾（零副作用），与定义 418 相同。

**定义 437（位姿条件信息增益与下一最佳位姿 NBP，推广定义 419）**
在线性高斯下，于位姿 `g` 观测 `y` 对隐变量 `u` 的互信息为
`Ĝ_t(h;g) = ½·log det(I + Σ_u^{1/2} H_t(g)ᵀ Σ_obs(g)⁻¹ H_t(g) Σ_u^{1/2})`（nats）；
非线性情形由 MP-Φ 查询，但必须输出保守下界（`Ĝ ≤ 真实增益`）。
**增益注** `β_t(g) = Ĝ_t(h;g) − c_t(g)`；**下一最佳位姿**
`g* = argmax_{g∈G_feas} β_t(g)`，`s.t.` 定义 434 的五条 `Pre^pose` 全部通过。
两门同过（风险门 `λ` + 增益注 `β`）才执行；任一门失败不产生物理副作用。
当 `H_t(g)=1`、`Σ_obs(g)=σ_obs²`、`Σ_u=σ_u²` 时退化为第 2 轮 `½·log(1+σ_u²/σ_obs²)`。

**定义 438（位姿噪声分解与传播；替代第 2 轮定义 426 的异方差盲点）**
`Σ_obs(g) = J_g(g) Σ_g J_g(g)ᵀ + Σ_sensor + Σ_model(g)`，
其中 `J_g=∂h/∂g` 为观测对位姿的雅可比，`Σ_g` 为位姿估计/跟踪协方差，`Σ_model(g)` 为模型误差。
`Σ_g` 由在线自标定维护（正运动学残差 + 视觉/力觉互检），并按定义 420 做保守性夹紧。
位姿异方差下的**有效样本量**为 Kish 形式
`n_eff = (Σ_j w_j)² / Σ_j w_j²`，`w_j = λ_min(Λ_u|g_j)`（定义 439）；
第 2 轮定义 426 的 `n` 替换为 `n_eff`。当 `J_g Σ_g J_gᵀ ≻ Σ_sensor` 时，
系统必须选择「先改善位姿标定」或「换一个 `J_g` 更小的位姿」，不允许把位姿噪声当传感器噪声吸收进 `u`。

**定义 439（位姿可辨识性与退化位姿）** 令 `J_u=∂h/∂u`、`J_g=∂h/∂g`，
`Λ_u|g = J_uᵀ Σ_obs⁻¹ J_u − J_uᵀ Σ_obs⁻¹ J_g (J_gᵀ Σ_obs⁻¹ J_g)⁻¹ J_gᵀ Σ_obs⁻¹ J_u`
（对 nuisance `g` 取 Schur 补后的 Fisher 信息）。若 `λ_min(Λ_u|g) < κ_id`，
则位姿 `g` 对格子 `s` **退化**：该位姿的观测不能把 `u` 与位姿误差分离，
`w_s(g):=0`、不产生覆盖信用，并写入 `D(s)`。这排除「镜面高光/逆光/遮挡位姿看起来很准」的假覆盖。

**定义 440（SE(3) 等变修复场）** 修复不再表示在世界坐标，而表示为物体坐标系上的场
`δ_θ: B → T B`（或对偶量）。对刚体变换 `T∈SE(3)`，要求
`δ_θ(T·x) = ρ(T)·δ_θ(x)`，观测模型满足 `h(T·x, T·g) = ρ_obs(T)·h(x,g)`，
其中 `ρ, ρ_obs` 为相应表示。实现上采用规范化（canonicalization）：
`δ_θ(x,g) = T_c·φ_θ(T_c⁻¹·x)`，`T_c` 为把物体搬到规范位姿的变换。
于是位姿 `g'` 处的修复可由 `g` 处修复经共轭传输得到，而不必在该位姿重新采样。

**定义 441（等变缺陷与传输误差）** 定义等变缺陷
`ε_eq = sup_{T∈G_sym, x} ‖δ_θ(T·x) − ρ(T)·δ_θ(x)‖`。
`ε_eq` 由预注册的等变测试集估计（含未见物体与未见位姿），并作为字段写进修复证书；
`ε_eq` 超阈值 ⇒ 禁止轨道级传输，退化为逐位姿校准（ToolGauge 路径）。

**定义 442（位姿分层共形覆盖，推广定义 422）** 校准集按位姿胶囊/轨道分层：
`C_cal = ⋃_k C_cal^{(k)}`。每个层独立取 `1−α` 共形分位数 `τ_h^{(k)}`；
若某层样本数 `n_k < n_cal_min`，该层**没有覆盖保证**，标记为 `unverified`，
不得用于对外主张。跨层同时覆盖用 Bonferroni：`P(∀k: h*∈H_s^{(k)}) ≥ 1−Sα`，
或按需使用加权共形处理校准-部署位姿分布偏移。

**定义 443（VLA 位姿提议的接地审计，推广定义 429）** VLA 只允许输出
`PoseHint = (part, relation, direction, tolerance)` 形式的**符号位姿约束**，
经预注册位姿词典 `L_pose` 接地为约束集 `C(PoseHint) ⊆ G_feas`；
数值位姿由几何求解器在 `C(PoseHint)` 内求解，VLA 不得直接输出数值 `g`。
提议必须依次通过：① 可达性；② 无碰路径；③ 非奇异；④ 退化位姿检查（定义 439）；
⑤ 位姿一致性（预测观测与实测回执在 `ε_cross` 内，定义 421.V 的位姿版）。
任一失败 ⇒ 提议丢弃，不产生物理副作用；连续失败计数进入 O-Quarantine（定义 445）。

**定义 444（位姿主张-回执绑定与位姿修复证书，推广定义 423/427）**
`PoseRepairCert(s) = (H_s, Π_s, PathCert, {r_j}, orbit_scope, ε_eq, n_eff, 文字解说)`。
语言主张中出现的任何方位、路径、接触点、可达性陈述，必须逐条引用有效位姿回执；
无数值回执支持的位姿主张在序列化时整条剥离（纯投影，不改变数值行为）。
`orbit_scope` 明确写出证书覆盖的轨道/位姿胶囊；**未写入作用域的主张不得外推**。

**定义 445（位姿可观测性隔离 O-Quarantine）** 维护最近 `K_o` 次探测的
`(预测增益 Ĝ_t(h;g), 实际增益 I_realized(r))` 残差符号序列。若连续 `≥ q_o` 次同向偏差，
判定位姿条件可观测性模型出现**系统性误标定**：暂停 Equi-AP-Cal 的轨道传输，
回退位姿无关的 ToolGauge 校准；直到重标定/重训练完成。
这是对「等变先验把局部可观测性错误放大到整条轨道」的在线断路器；
与第 2 轮 P-Quarantine（定义 428）正交：P-Quarantine 管先验均值，O-Quarantine 管观测模型。

**定义 446（位姿预算契约 PB-Contract 与退化链，细化定义 424）**
`PB = (B_path, L_path, τ_pose, τ_track, recovery)`：路径总长度/时间预算、路径段数上限、
位姿规划时延上限、允许的跟踪误差上限、恢复条件（位姿估计失效 / 可达性连续失败 /
O-Quarantine 触发 / 预算耗尽 ⇒ 退化）。退化链：
`PoseGauge ⇒ ToolGauge（位姿无关）⇒ LeanGauge ⇒ MODGAUGE`。

**定义 447（继承与编号约定）** 未被本轮重定义的第 1/2 轮记号沿用定义 398–431。
本文所有增量以 ToolGauge 为退化特例：令 `G_feas={g₀}`、`Σ_g=0`、`w_s(g₀)=1`、`ε_eq=0`、
`L_pose=∅`，则 PoseGauge ≡ ToolGauge；再令 `VLA=∅`、`T₀={被动观测}`、`MP-Φ=物理先验 GP`
则 ToolGauge ≡ LeanGauge。

# IP-321 P-Box：位姿条件盲区与有效覆盖
class PBox:
    def __init__(self, dbox, capsules, theta_cov=0.8, w_min=0.1):
        self.dbox, self.caps = dbox, capsules
        self.visited = defaultdict(set)          # s -> {capsule_id}
        self.degenerate = defaultdict(set)       # s -> {capsule_id}

    def weight(self, s, cap):                    # 定义 432/439
        if cap.id in self.degenerate[s]: return 0.0
        return info_gain_scalar(cap.H[s], cap.Sigma_obs)

    def coverage(self, s):                       # 定义 432
        den = sum(self.weight(s, c) * c.vol for c in self.caps)
        if den <= 0: return 0.0
        num = sum(self.weight(s, c) * c.vol
                  for c in self.caps if c.id in self.visited[s])
        return num / den

    def blind_spots(self):
        return [s for s in self.dbox.cells
                if self.coverage(s) < self.theta_cov
                or max((self.weight(s, self.caps[k]) for k in self.visited[s]),
                       default=0.0) < self.w_min]

# IP-322 Pose-TCV：位姿契约 + 连续路径证书
class PoseTCV(TCV):
    def verify(self, prog, budget):
        ok, why = super().verify([(t, a) for (t, a, _) in prog], budget)
        if not ok: return ok, why
        for (t, args, path) in prog:
            if not ik_reachable(path.start):        return False, "reach"
            if not collision_corridor(path):        return False, "collision"
            if min_manipulability(path) < MU_MIN:   return False, "singular"
            if not cbf_margin(path) >= 0:           return False, "cbf"
            if not interval_track_bound(path) <= DT:return False, "track"
        return True, "ok"

    def execute(self, prog, env):
        receipts = []
        for (t, args, path) in prog:
            if not t.pre(env.snapshot()): break       # void，零副作用
            g_cmd = path.waypoints[0]
            raw   = env.invoke_pose(t, args, path)
            r     = t.post(raw)
            if r is None or not verify_sig(r): self.fail += 1; continue
            if not pose_deviation_ok(r):                  # 定义 435
                self.pose_fail += 1; continue
            receipts.append(r)
        return receipts

# IP-323 NBP：下一最佳位姿（增益注的位姿版）
def next_best_pose(H_s, t, feasible_caps, mp_phi, lam_gate):
    best = None
    for g in feasible_caps:
        if not pose_pre_ok(t, g): continue            # 定义 434
        if not lam_gate(g): continue                  # 风险门
        gain = mp_phi.info_gain_lower(H_s, t, g)      # 定义 437，保守下界
        beta = gain - t.cost(g)
        if beta >= GAMMA_B and (best is None or beta > best[1]):
            best = (g, beta)
    return best

# IP-324 PN-Cal：位姿噪声分解 + 可辨识性
class PNCal:
    def obs_cov(self, t, g, Sigma_g):                 # 定义 438
        Jg = t.jacobian_pose(g)
        return Jg @ Sigma_g @ Jg.T + t.Sigma_sensor + t.Sigma_model(g)

    def partial_info(self, t, g, u_dim):              # 定义 439（Schur 补）
        Ju, Jg = t.jacobian_u(g), t.jacobian_pose(g)
        S = inv(self.obs_cov(t, g, self.Sigma_g))
        A = Ju.T @ S @ Ju
        B = Ju.T @ S @ Jg
        C = Jg.T @ S @ Jg
        return A - B @ pinv(C) @ B.T

    def effective_n(self, weights):                   # 定义 438（Kish）
        w = np.asarray(weights)
        return (w.sum() ** 2) / max((w ** 2).sum(), eps)

# IP-325 Equi-AP-Cal：物体坐标系摊销 + 等变传输
class EquiAPCal(APCal):
    def calibrate(self, receipts, H, s):
        Tc = canonicalize(receipts)                   # 定义 440
        ctx = featurize_ctx([Tc.inv().act(r) for r in receipts], H, s)
        mu, Sig = self.mp_phi(ctx)
        return Tc.act(mu), Tc.act_cov(Sig)

    def cross_pose_validate(self, mu, Sig, receipts_indep):
        # 至少两个不同位姿胶囊的独立回执；定义 421.V 的位姿版
        zs = [(r.mu - mu) / sqrt(Sig + r.var) for r in receipts_indep]
        return all(abs(z) <= self.eps_cross for z in zs)

# IP-326 PoseGauge 6C+ 闭环（含 O-Quarantine）

    M.mreg.hot_replace(M.dpe, new_ec)                      # U：轨道级热替换

## 3. 推导

**引理 51（位姿条件增益的单调性与 NBP 近似比）** 对线性高斯观测，
`Ĝ_t(h;g)` 非负；对相互独立的观测集合 `S`，`Ĝ(S)` 关于 `S` 单调且次模（由链式法则与
条件独立的 Fisher 信息可加性得到）。因此单步 NBP 在可行位姿上精确最优；
多步位姿选择在次模条件下，贪心 NBP 达到 `(1−1/e)` 近似。
若 `Ĝ` 由 MP-Φ 以保守下界给出（定义 437），则近似比按下界损失项 `ξ_g` 折减。
系：当 `|G_feas|` 仅覆盖一个位姿胶囊时，引理 51 退化为第 2 轮引理 46 的增益注形式。

**引理 52（位姿噪声传播与可辨识性下界）** 设观测映射 `h(u,g)` 对 `g` 为 `L_g`-Lipschitz，
位姿跟踪误差 `‖δg‖ ≤ Δ_g`，则观测偏差 `‖h(u,g⊕δg)−h(u,g)‖ ≤ L_g·Δ_g`；
若 `δg` 为零均值高斯且 `Σ_obs` 如定义 438，则任意无偏估计器对 `u` 的协方差满足
`Cov(û) ≽ Λ_u|g⁻¹`（含 nuisance 的 Cramér-Rao 下界）。当 `λ_min(Λ_u|g) < κ_id` 时，
置信区间半宽下界 `≥ κ_id^{-1/2}`，该位姿不能用于认证修复；故定义 439 的置零不是保守选择，
而是**可证的必需条件**。

**引理 53（等变修复传输界）** 若 `δ_θ` 精确等变（`ε_eq=0`），则对任意 `T∈G_sym`，
在 `T` 处传输的修复与在该处重新校准得到的修复在期望风险上相同。
若 `ε_eq>0` 且风险对修复为 `L_δ`-Lipschitz，则传输修复的期望风险满足
`R(g') ≤ R(g) + L_δ·ε_eq + δ_transport`，其中 `δ_transport` 为规范化的数值误差。
系：`ε_eq` 必须作为证书字段（定义 441）并进入 `orbit_scope` 的有效性判断；
`ε_eq` 超阈值 ⇒ 禁止轨道传输。

**引理 54（位姿分层共形覆盖）** 在每个位姿层内，若校准与部署样本可交换，则
`P(h*∈H_s^{(k)}) ≥ 1−α`；对 `S` 个层同时主张时，Bonferroni 给出
`P(∀k: h*∈H_s^{(k)}) ≥ 1−Sα`。若某层 `n_k < n_cal_min`，则该层覆盖概率**无下界**
（共形分位数不可定义），必须标记 `unverified`；这解释了为什么「在容易的位姿上校准、
在困难的位姿上主张」是不可接受的。

**引理 55（有效覆盖的可靠性）** 若 `w_s(g)` 是真实信息量的已校准下界，
则 `ECov(s) = θ` 蕴含后验方差至少按 `θ·∫w_s` 的比例收缩。
若可观测性模型有相对误差 `δ_w`（即 `ŵ ≤ (1+δ_w)w`），则真实有效覆盖
`ECov_true ≥ ECov_est − δ_w/(1+δ_w)`。当右端低于 `θ_cov` 时，不得给覆盖信用。
系：O-Quarantine 的残差序列正是 `δ_w` 的在线估计器。

**引理 56（VLA 位姿提议不破坏数值等价性）** 只要 VLA 的输出仅经定义 443 的符号约束 →
几何求解器 → Pose-TCV 验证这条链进入执行，且语言主张必须引用位姿回执（定义 444），
则数值路径与「不使用 VLA」的 PoseGauge 在通过验证的程序上逐指令相同；
被拒绝的提议不产生物理副作用（Pose-TCV 的前置失败零副作用语义）。
因此第 2 轮引理 49 的数值等价性论断在空间维度上仍然成立。

**引理 57（时序与路径证书开销）** 位姿规划、路径证书生成、等变校准与 O-Quarantine 全部位于
50Hz 计量路径之外（异步事件驱动）；50Hz 周期内新增开销仅为位姿回执有效性检查
`O(1)+O(d_g²)`（`d_g≤6`）`< 0.3ms`。单盲区修复时延
`≤ L_path·(τ_pose+τ_cert+τ_track) + τ_VLA + τ_equi ≤ τ_pose`（PB-Contract 界定）。
预算耗尽由 PB-Contract 强制降级 ⇒ 第 2 轮引理 50 的硬实时与预算不变式保持。

## 6. 本轮最大风险（一句话）

**一句话**：PoseGauge 的最大风险是**位姿条件可观测性模型 `H(g), Σ_g` 在某个位姿轨道上被系统性误标定**——
VLA 会把探测引向「看起来合理但信息量近零」的位姿，等变修复又把一次错误的局部修正沿整个 `SE(3)` 轨道

O-Quarantine（定义 445）与位姿分层共形（定义 442）为在线兜底。

1. **等变缺陷被低估** → 定义 441 强制 `ε_eq` 进入证书；超阈值禁止轨道传输；
2. **退化位姿假精确**（低噪声、低灵敏度）→ 定义 439 Schur 补判据 + 零覆盖信用；
3. **位姿分层样本不足** → 定义 442 标记 `unverified`，禁止跨层外推；
4. **VLA 位姿提示注入**（对抗纹理/布局诱导错误位姿）→ 定义 443 符号约束 + 五重验证；
5. **路径证书与真实动力学不符** → CBF 裕度 + 区间跟踪上界 + PROBING 状态与力矩硬限；
6. **位姿估计漂移** → 定义 438 在线自标定 + 保守性夹紧 + PB-Contract 退化；
7. **计算/预算膨胀**（位姿搜索 + 路径证书）→ NBP 缓存、异步、PB-Contract 硬顶。

## 2. 形式化定义（要点）

**定义 432（位姿条件盲区与 ECov）** `w_s(g)=½log det(I+Σ_u^{½}H_s(g)ᵀΣ_obs(g)⁻¹H_s(g)Σ_u^{½})`；
`ECov(s)=Σ_{visited}w·vol / Σ_{feas}w·vol`；`covered ⇔ ECov≥θ_cov ∧ max w≥w_min`。
访问但不满足阈值 ⇒ 仍是盲区，另记无效位姿集 `D(s)`。`g` 唯一且 `w∈{0,1}` 时退化为 D-Box。

**定义 433（位姿胶囊/对称商）** `G_feas⊆⋃B(g_k,Δ_g)`，`Δ_g=ε_H/L_H`；同胶囊内 `‖H(g)−H(g_k)‖≤ε_H`；
按 `SE(3)/G_sym` 记轨道，证书写作用域而非世界位姿枚举。

**定义 434（MTC^pose）** 工具 = 位姿 schema + 物理前置（力/温/时序/可达/无碰/可操作度/非奇异/路径证书）
+ 位姿回执谓词 + 位姿相关代价/时延 + `Ĝ_t(h;g)`；工具库 `T₀×G_feas` 仍完全预注册。

**定义 435（位姿回执）** 新增 `g_cmd,g_actual,Σ_g,path_hash`；
`valid(r)` 还要求位姿偏差 `‖g_actual⊖g_cmd‖²_{Σ_g}≤χ²_{d_g,1−β_pose}`；
位姿偏差作废与传感器故障作废分开计数（供 O-Quarantine）。

**定义 436（位姿程序/路径证书）** 连续路径 `γ_i`；Pose-TCV 在四查之外验证碰撞走廊、关节限位、
CBF 裕度、区间跟踪误差上界；任一条实测失败 ⇒ `void`、前缀完成、零副作用。

**定义 437（NBP）** `Ĝ_t(h;g)=½log det(I+Σ_u^{½}H_t(g)ᵀΣ_obs(g)⁻¹H_t(g)Σ_u^{½})`；
`β_t(g)=Ĝ−c_t(g)`；`g*=argmax β_t(g)` 且五条位姿前置全过；MP-Φ 查询必须给保守下界。
标量情形退化为第 2 轮 `½log(1+σ_u²/σ_obs²)`。

**定义 438（位姿噪声分解）** `Σ_obs(g)=J_gΣ_gJ_gᵀ+Σ_sensor+Σ_model(g)`；
`Σ_g` 在线自标定并保守夹紧；`n_eff=(Σw)²/Σw²`，`w_j=λ_min(Λ_u|g_j)`；
`J_gΣ_gJ_gᵀ≻Σ_sensor` 时必须先改善位姿标定或换位姿，禁止把位姿噪声吸收进物体参数。

**定义 439（退化位姿）** `Λ_u|g=J_uᵀΣ⁻¹J_u−J_uᵀΣ⁻¹J_g(J_gᵀΣ⁻¹J_g)⁻¹J_gᵀΣ⁻¹J_u`；
`λ_min(Λ_u|g)<κ_id` ⇒ `w_s(g)=0`、零覆盖信用、写入 `D(s)`；排除镜面高光/逆光/遮挡的假精确。

**定义 440（等变修复场）** `δ_θ(Tx)=ρ(T)δ_θ(x)`，`h(Tx,Tg)=ρ_obs(T)h(x,g)`；
用规范化 `δ_θ(x,g)=T_cφ_θ(T_c⁻¹x)` 实现，支持轨道级传输。

**定义 441（等变缺陷）** `ε_eq=sup‖δ_θ(Tx)−ρ(T)δ_θ(x)‖`；由预注册等变测试集估计并写入证书；
超阈值 ⇒ 禁止轨道传输，退回逐位姿校准。

**定义 442（位姿分层共形）** 校准集按胶囊/轨道分层；每层独立 `1−α` 分位数；`n_k<n_cal_min`
⇒ `unverified`、无覆盖保证；跨层用 Bonferroni `≥1−Sα` 或加权共形处理位姿分布偏移。

**定义 443（VLA 位姿接地）** VLA 只能输出 `PoseHint=(part,relation,direction,tolerance)`；
经 `L_pose` 接地为约束集，几何求解器求数值 `g`；提议必须过可达/无碰/非奇异/非退化/位姿一致性五关；
失败即丢弃、零副作用。

**定义 444（位姿主张-回执绑定/证书）** `PoseRepairCert=(H_s,Π_s,PathCert,{r_j},orbit_scope,ε_eq,n_eff,解说)`；
方位/路径/接触点/可达性主张必须引用有效位姿回执，否则序列化时整条剥离（纯投影）；
未写入 `orbit_scope` 的主张禁止外推。

**定义 445（O-Quarantine）** 最近 `K_o` 次 `(预测增益,实际增益)` 残差连续 `≥q_o` 次同向 ⇒
判定位姿可观测性模型系统性误标定：暂停 Equi-AP-Cal 轨道传输，回退位姿无关 ToolGauge。
与 P-Quarantine 正交：P 管先验均值，O 管观测模型。

**定义 446（PB-Contract/退化链）** `(B_path,L_path,τ_pose,τ_track,recovery)`；
位姿估计失效/可达连续失败/O-Quarantine/预算耗尽 ⇒
`PoseGauge⇒ToolGauge⇒LeanGauge⇒MODGAUGE`。

**定义 447（继承）** 沿用定义 398–431；令 `G_feas={g₀},Σ_g=0,w=1,ε_eq=0,L_pose=∅` ⇒
PoseGauge≡ToolGauge；再令 `VLA=∅,T₀={被动观测},MP-Φ=物理先验` ⇒ ToolGauge≡LeanGauge。

# IP-321 P-Box：可观测性加权有效覆盖
class PBox:
    def weight(self, s, cap):
        if cap.id in self.degenerate[s]: return 0.0
        return info_gain_scalar(cap.H[s], cap.Sigma_obs)       # 定义 432/439
    def coverage(self, s):
        den = sum(self.weight(s,c)*c.vol for c in self.caps)
        num = sum(self.weight(s,c)*c.vol for c in self.caps if c.id in self.visited[s])
        return num/den if den > 0 else 0.0
    def blind_spots(self):
        return [s for s in self.dbox.cells
                if self.coverage(s) < THETA_COV
                or max((self.weight(s,self.caps[k]) for k in self.visited[s]),
                       default=0.0) < W_MIN]

# IP-322 Pose-TCV：位姿契约 + 连续路径证书
class PoseTCV(TCV):
    def verify(self, prog, budget):
        ok, why = super().verify([(t,a) for (t,a,_) in prog], budget)
        if not ok: return ok, why
        for (t,args,path) in prog:
            if not ik_reachable(path.start):        return False, "reach"
            if not collision_corridor(path):        return False, "collision"
            if min_manipulability(path) < MU_MIN:   return False, "singular"
            if cbf_margin(path) < 0:                return False, "cbf"
            if interval_track_bound(path) > DT:     return False, "track"
        return True, "ok"
    def execute(self, prog, env):
        receipts = []
        for (t,args,path) in prog:
            if not t.pre(env.snapshot()): break                 # void，零副作用
            r = t.post(env.invoke_pose(t, args, path))
            if r is None or not verify_sig(r): self.fail += 1; continue
            if not pose_deviation_ok(r): self.pose_fail += 1; continue  # 定义 435
            receipts.append(r)
        return receipts

# IP-323 NBP：位姿条件增益注
def next_best_pose(H_s, t, feasible_caps, mp_phi, risk_gate):
    best = None
    for g in feasible_caps:
        if not pose_pre_ok(t, g) or not risk_gate(g): continue
        gain = mp_phi.info_gain_lower(H_s, t, g)                # 定义 437，保守下界
        beta = gain - t.cost(g)
        if beta >= GAMMA_B and (best is None or beta > best[1]):
            best = (g, beta)
    return best

# IP-324 PN-Cal：噪声分解 + Schur 补可辨识性
class PNCal:
    def obs_cov(self, t, g, Sigma_g):                           # 定义 438
        Jg = t.jacobian_pose(g)
        return Jg @ Sigma_g @ Jg.T + t.Sigma_sensor + t.Sigma_model(g)
    def partial_info(self, t, g):                               # 定义 439
        Ju, Jg = t.jacobian_u(g), t.jacobian_pose(g)
        S = inv(self.obs_cov(t, g, self.Sigma_g))
        A, B, C = Ju.T@S@Ju, Ju.T@S@Jg, Jg.T@S@Jg
        return A - B @ pinv(C) @ B.T
    def effective_n(self, weights):                             # 定义 438（Kish）
        w = np.asarray(weights); return (w.sum()**2)/max((w**2).sum(), EPS)

# IP-325 Equi-AP-Cal：物体坐标系摊销 + 等变传输
class EquiAPCal(APCal):
    def calibrate(self, receipts, H, s):
        Tc = canonicalize(receipts)                             # 定义 440
        ctx = featurize_ctx([Tc.inv().act(r) for r in receipts], H, s)
        mu, Sig = self.mp_phi(ctx)
        return Tc.act(mu), Tc.act_cov(Sig)                      # 轨道传输
    def cross_pose_validate(self, mu, Sig, receipts_indep):
        zs = [(r.mu-mu)/sqrt(Sig+r.var) for r in receipts_indep] # ≥2 个位姿胶囊
        return all(abs(z) <= self.eps_cross for z in zs)

# IP-326 PoseGauge 6C+ 闭环
def posegauge_6c(M, s):
    caps = M.pbox.blind_capsules(s)
    H    = M.gbox.hypothesize(s, caps, M.pbox)                  # H（VLA 只提符号位姿约束）
    prog = M.gbox.plan_pose_probes(H, M.tools, M.ptcv)          # C（路径 + 证书）
    ok, why = M.ptcv.verify(prog, M.budget_left(s))
    if not ok: return degrade_to_toolgauge(s, why)              # 定义 446
    receipts = M.ptcv.execute(prog, M.env)                      # E（PROBING）
    if len(receipts) < n_min(s): return stub_and_red(s, "insufficient")
    weights = [M.pncal.partial_info_eig(r) for r in receipts]
    if M.pncal.effective_n(weights) < N_EFF_MIN: return stub_and_red(s, "degenerate")
    mu, Sig = M.equi_apcal.calibrate(receipts, H, s)            # C
    if not M.equi_apcal.cross_pose_validate(mu, Sig, M.cross_receipts(s)):   # V
        mu, Sig = M.equi_apcal.calibrate(receipts, ["UNKNOWN"], s)
        if not M.equi_apcal.cross_pose_validate(mu, Sig, M.cross_receipts(s)):
            return stub_and_red(s, "cross_pose_failed")
    new_ec = M.equi_apcal.update_contract(M.dpe, mu, Sig, s, orbit_scope=caps)
    if not contract_regression(new_ec): return stub_and_red(s, "regression")
    M.mreg.hot_replace(M.dpe, new_ec)                           # U：轨道级热替换
    M.pbox.mark_covered(s, caps, M.pncal.effective_n(weights))
    bind_pose_claims(new_ec, H, prog, receipts)                 # 定义 444
    M.oquar.record(M.nbp.last_pred_gain, realized_gain(receipts))
    return True

# IP-326 主闭环
def PoseGauge_round(M, obs, audio, tac, depth, det):
    for s in M.pbox.blind_spots():
        if s not in M.inflight:
            M.inflight.add(s); submit_async(posegauge_6c, M, s)
    if M.oquar.triggered():
        M.equi_apcal.pause(); M.pose_agnostic_fallback = True
    return ToolGauge_round(M, obs, audio, tac, depth, det)

## 4. 推导

**引理 51（位姿增益单调性与 NBP 近似比）** 线性高斯下 `Ĝ_t(h;g)≥0`；对独立观测集合，
`Ĝ` 单调且次模（Fisher 信息可加），单步 NBP 精确最优；多步贪心达 `(1−1/e)` 近似；
MP-Φ 保守下界损失 `ξ_g` 直接折减近似比。`|G_feas|=1` 时退化为第 2 轮引理 46 的增益注。
**引理 52（位姿噪声传播与可辨识性下界）** `‖h(u,g⊕δg)−h(u,g)‖≤L_g·Δ_g`；
含 nuisance 的 Cramér-Rao 给出 `Cov(û)≽Λ_u|g⁻¹`；`λ_min(Λ_u|g)<κ_id` ⇒ 置信半宽下界
`≥κ_id^{-1/2}`，故定义 439 的零覆盖是**可证必需**，不是保守偏好。
**引理 53（等变传输界）** 精确等变 ⇒ 传输与重校准同风险；`ε_eq>0` 时
`R(g')≤R(g)+L_δ·ε_eq+δ_transport`；故 `ε_eq` 必须进证书并限制 `orbit_scope`。
**引理 54（位姿分层共形）** 层内可交换 ⇒ `P(h*∈H_s^{(k)})≥1−α`；跨层 Bonferroni `≥1−Sα`；
`n_k<n_cal_min` ⇒ 该层无下界，必须 `unverified`（禁止「易位姿校准、难位姿主张」）。
**引理 55（ECov 可靠性）** 已校准下界 `w` 下 `ECov=θ` ⇒ 后验方差按 `θ∫w` 收缩；
模型相对误差 `δ_w` 使 `ECov_true≥ECov_est−δ_w/(1+δ_w)`；低于阈值不得给覆盖信用。
O-Quarantine 的残差序列即 `δ_w` 的在线估计器。
**引理 56（VLA 位姿提议数值等价）** 符号约束 → 几何求解 → Pose-TCV 验证链下，
数值路径与「不用 VLA」逐指令相同；被拒提议零副作用；第 2 轮引理 49 在空间维度仍成立。
**引理 57（时序预算保持）** 位姿规划/证书/等变校准/O-Quarantine 全在 50Hz 外；
周期新增 `<0.3ms`（`d_g≤6`）；修复时延 `≤τ_pose`（PB-Contract）；退化由 PB-Contract 强制。
第 2 轮引理 50 的硬实时与预算不变式保持。

## 8. 本轮最大风险

**一句话**：PoseGauge 的最大风险是**位姿条件可观测性模型 `H(g), Σ_g` 在某个位姿轨道上被系统性误标定**——
VLA 把探测引向「看起来合理但信息量近零」的位姿，等变修复又把一次错误的局部修正沿整个 `SE(3)` 轨道
自信地复制，最终系统在「已覆盖」的标记下对整类位姿失明；以 E445/E446/E454 证伪，
O-Quarantine（定义 445）与位姿分层共形（定义 442）在线兜底。
