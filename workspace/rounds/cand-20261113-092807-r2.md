# 第 66 轮（承接第 65 轮「VISTA 故障可归因闭环」IP-214~223；灵感循环第 3 轮；本轮灵感：「零样本泛化」×「动力学」）

> 第 65 轮把「几何可证伪」升级为「故障可归因」，其自述的最大风险一针见血：**归因能力建立在「故障属于有限假设集、且视觉与几何的失效相互独立」之上；真实故障常是未知类型的组合，透明/镜面/对抗 patch 又会让视觉与几何共享同一个分布外失效源，于是 FIR 会把未知复合故障强行归入最近假设、只膨胀错误的球——系统因为「已经归因」而更自信地继续执行。** 本轮不再增加传感器，也不再扩充故障类别表，而是更换保证对象：第 65 轮问「这是哪一类已知故障」，ZODIAC 问「**它是否已经破坏了系统必须遵守的动力学不变量；若已破坏，伤害是否被一条与故障身份无关的安全通道兜住**」。本轮核心命题是：
>
> **把「有监督的故障分类」升级为「零样本的动力学不变量检测 + 结构性定位 + 与身份无关的安全兜底」：用能量/动量/本构/运动学不变量构成跨物体、跨任务共享的健康基线，用残差的符号与能量流向做结构（而非统计）分离，用被动态/能量罐保证「即使不知道是什么坏了，也不会造成不可逆伤害」。**

## 0. 直觉与动机

**灵感 1（零样本泛化 → 先把「要泛化的对象」换掉）**
直觉：第 65 轮想泛化的是「故障类别」，可故障类别是开放的、长尾的、甚至对抗的，靠离线注入永远追不上。零样本泛化的关键不是「用已知类别的特征去外推新类别」（那仍是闭集思维），而是**换一个只需见过「健康」就能定义的目标**：学习健康动力学的可行域，任何离开该可行域的轨迹都算异常，不管它是什么新故障。类比：我们不必见过每一种病，只要知道健康指标的正常范围。诚实地说，零样本检测只能告诉你「不健康」，不能告诉你「是什么病」——所以本轮把**检测**与**归因**彻底拆开：检测负责安全，归因只负责效率。

**灵感 2（动力学 → 不变量给出「结构性」而非「统计性」的分离）**
直觉：第 65 轮用阶段签名 + 高斯似然做归因，本质是统计分离：谁的签名像，就归给谁。动力学给了更好的东西——**守恒律与被动态**。健康系统必须满足能量平衡（执行器注入 = 存储增量 + 耗散 + 接触功率）、动量-冲量关系、接触本构、运动学一致性。更关键的是，这些不变量对故障的响应**符号不同、耦合结构不同**：感知类故障（几何幻觉、视觉错）会让运动学/本构失配，却不会凭空创造或消灭真实能量；物理类故障（执行器增益错、F/T 偏置）会破坏能量账本，却不一定违反运动学。于是「物理坏了」还是「看见的坏了」第一次有了**与故障类别无关**的判据：看能量账本对不对得上。

**灵感 3（动力学 → 健康基线天然跨物体/跨任务）**
直觉：质量、摩擦、刚度变了，动力学方程的**形式**不变，只是参数变。所以「能量平衡 / 被动态」这类不变量是**任务与物体无关**的，天然具备零样本泛化所需的共享结构；需要学习的只是软通道（运动学、本构）里与物体身份相关的残差嵌入，且可用域对抗/对比学习把它压成与物体无关的表示。相比「为每个故障类别收集数据」，标定成本从 O(故障数) 降到 O(1)（只需健康数据 + 有界模型误差）。

**灵感 4（三灵感合流 → ZODIAC：Zero-shot Dynamics-Invariant Attribution & Certification，零样本动力学不变量归因与认证）**
闭环：动力学不变量库（DIB）→ 端口哈密顿监控（PHM）生成带符号残差 → 零样本不变量检测（ZID，conformal 健康管）→ 结构性定位（SLoc，信号到子系统的结构矩阵，输出**子集**而非单类）→ 未知故障 conformal 与 CUSUM 时延界（UFC）→ 不变量保持探针（IPP）→ 动力学感知认证前缀（DPC，可达集/CBF 而非静态裕度）→ 不变量安全回退（ISF，被动态能量罐兜底）→ 对抗动力学认证（ADC，把未建模动力学当有界扰动）。第 65 轮是「归因 → 定向膨胀 → 短执行」；ZODIAC 把「归因」降级为可选加速项，把「安全」上移到一条**不依赖故障身份**的能量/被动态通道。

**灵感 5（VISTA 组件的原位升级）**
- **FIR → ZID + SLoc**：从「6 类后验」改为「健康管外检测 + 结构矩阵定位到子系统子集」，未知故障不再被强行塞进最近类。
- **VCV → 保留但降级为软通道**：视觉只进运动学不变量，不再承担几何否决的最终裁决；能量通道独立裁决「物理 vs 感知」。
- **AFA → IPP**：探针目标从「故障假设互信息」改为「在安全集内最大化不变量通道的可检测性（可观测性 Gram 的谱）」，未知故障也可设计。
- **CSC → DPC**：块级认证从「逐假设验裕度」改为「沿不变量动力学做可达集/CBF 验证」，不再需要枚举假设。
- **RSC-V → RSC-Z**：膨胀量由「定位子集」决定；不知道时就膨胀**能量安全界**而非几何球。
- **WCV-V → WCV-Z**：搜索域加「不变量可行域」与「被动态功率预算」。
- **CSP-V → CSP-Z**：技能绑定「不变量激励签名」，只在可观测不变量充足的区域规划。
- **AIC-V → ADC**：干扰集显式含未建模动力学、参数漂移、传感器动态。
- **J_vista → J_zodiac**：证书增 invariant_residual、detection_margin、localization_set、time_to_detect、passivity_cert、zero_shot_calib_ver。

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（ZODIAC 闭环）**：ZODIAC = (VISTA, DIB, PHM, ZID, SLoc, UFC, IPP, DPC, ISF, ADC, RSC-Z, WCV-Z, CSP-Z, J_zodiac)。定位：VISTA 的「零样本化 + 动力学安全兜底」升级。不变式：**不变量残差生成、CUSUM 检测、ISF 切换只在实时流；不变量辨识、SLoc、IPP、DPC、ADC 只在语义流；实时流零学习写操作。**
- **定义 234（端口哈密顿动力学与能量平衡）**：状态 x=(q,p)，H(x)=½pᵀM⁻¹(q)p+V(q)。名义动力学 ẋ=(J(x)−R(x))∇H+G(x)u+B(x)f_c+d。经过 [t₀,t₁] 的能量账本残差
  r_E = [H(t₁)−H(t₀)] − ∫uᵀy dt + ∫∇HᵀR∇H dt − ∫f_cᵀv_c dt，
  健康时 |r_E| ≤ δ_model（有界未建模动力学）。y=Gᵀ∇H 取**本体感觉**（关节速度/力矩/电流），**不依赖视觉**，这是物理通道独立性的来源。
- **定义 235（动力学不变量残差向量）**：r=(r_E, r_P, r_C, r_K, r_Π, r_Θ)：
  r_P 动量-冲量残差（自由飞行 p(t₁)−p(t₀)−∫f_ext dt；接触段含 ∫f_c dt）；
  r_C 本构残差 f_n−g(δ)（δ 由几何/视觉给出）；
  r_K 运动学一致性（视觉位姿 vs 正运动学 vs LiDAR 几何）；
  r_Π 被动性违背（窗口内 dH/dt>uᵀy+δ_model 的积分，即「无源能量生成」）；
  r_Θ **慢不变量**：辨识参数 θ̂=(m̂,μ̂,k̂) 的平稳性漂移（递归最小二乘残差），用于捕捉磨损/刚度退化这类不破坏瞬时守恒律的慢故障。
- **定义 236（健康不变量管与零样本检测 ZID）**：在健康数据上按运行体制（自由/轻触/承载/冲击）分层估计残差分布，定义非一致性分数 s(r)=‖r−μ_r‖²_{Σ_r⁻¹}，用 Mondrian split-conformal 得 q(α,regime)。检测规则：s(r)>q(α,regime) 或 CUSUM 越界。**标定只用健康数据，从不使用故障标签**；因此对未见故障也成立（分布无关覆盖）。
- **定义 237（结构定位矩阵 SLoc）**：先验物理结构矩阵 Λ∈{0,1}^{6×6}（行：残差通道；列：执行器/力矩传感、F/T、几何-视觉、接触模型、环境-未建模、策略），由「哪些故障会污染哪些守恒律」决定。观测到活跃残差集 A={i:s_i>q_i} 后，定位为**集合**
  L = { j : Λ_{A,j} 与 A 的预期模式一致 }，并按结构匹配分数排序；
  用集合值 conformal 给覆盖保证 P(true j ∈ L) ≥ 1−α_loc。**输出子集，不强迫单类。**
- **定义 238（ε-可检测性与不可检测无害化）**：若故障在视界内使某不变量偏离超过 q(α)，称 ε-可检测；不可检测故障必须 (i) 落在健康管切空间内，或 (ii) 被 r_Θ 慢漂移通道捕获。对 (i)，在任务映射 L_task-Lipschitz 下伤害 ≤ L_task·q(α)；对 (ii) 走参数漂移阈值。**这是本轮唯一敢下的「无害」承诺，且只对瞬时守恒律不可见者成立。**
- **定义 239（未知故障 conformal 与时延 UFC）**：对带符号残差做非参数 CUSUM，阈值由 conformal 定；给出检测时延界
  E[τ_det] ≤ (h + 1)/(KL(μ₁‖μ₀))（Page-Lorden 型），并在分布漂移下用自适应 conformal（ACI）在线校正 α_t，维持长期覆盖。
- **定义 240（不变量保持探针 IPP）**：探针 a* = argmax_a λ_min(W(a))，W(a)=∫ΦᵀΛᵀΛΦdt 为**不变量可观测性 Gram**（Φ 为故障方向到残差的敏感度），约束：预测功率 ≤ P_max、预测形变 ≤ ε_strain、预测力 ≤ f_safe、且始终留在 DPC 安全集内。与第 65 轮「对已知假设求互信息」不同，IPP 对**未知故障方向张成空间**做 D-最优，因此零样本可用；易损物体上退化为「零功率/纯观测」探针。
- **定义 241（动力学感知认证前缀 DPC）**：给定块 A 与前缀 k，用控制屏障函数 h(x)≥0 编码安全集（力限/无碰撞/能量界），在 ADC 的不确定集上做区间/椭球可达集验证：∀s≤k、∀d∈𝒟_ADC，h(x_s)≥0；最小 k* 取满足可达集不出安全集的最大前缀，且 k*≤m（不可逆视界）。用不变量残差管给模型误差上界，从而**一次验证覆盖所有故障假设**，不再枚举 ℋ。
- **定义 242（不变量安全回退 ISF）**：一旦检测到不变量违背（无论能否定位），切换到「被动态阻抗 + 能量罐」控制：虚拟能量 E_tank≥0，提取功率 ≤ E_tank 的耗散率，超出即降增益/注入阻尼。定理级保证：对任意**无源**环境与满足功率约束的执行器，闭环存储能量 H_cl ≤ H_cl(0)+E_tank(0)，与故障身份无关。这是「不知道是什么坏了也不会造成不可逆伤害」的物理基础。
- **定义 243（对抗动力学认证 ADC）**：不确定集 𝒟_ADC = 未建模摩擦/间隙/柔性模态（有界）+ 参数漂移（有界）+ 传感器动态/延迟（有界）。认证规则：把 δ_model(𝒟_ADC) 计入 q(α) 与 h 的鲁棒裕度；若 δ_model 大到使不变量不可辨识（信噪比 <τ_snr），则该通道**降级不用于检测**，只保留 ISF。ADC 输出每个通道的「可检测信噪比」与鲁棒阈值。
- **定义 244（复合故障与共因失效的结构处理）**：复合故障残差近似可加 r≈Σr^{(k)}，定位取各分量定位并集 L=∪L_k；共因失效（视觉+几何同源）由**物理通道独立性**化解：r_E/r_Π 只用本体感觉，与视觉无关，因此物理分量仍可检测；若本体感觉自身被污染，则无独立通道，判 `no_independent_channel` 并直接 ISF + safe_idle。
- **定义 245（零样本泛化间隙与组合泛化）**：以健康数据标定、在未见故障分布 𝒟_fault 上测检测率 R_det(𝒟_fault)。零样本间隙 Gap=R_det(𝒟_cal)−R_det(𝒟_fault)，其上界由不变量维数、conformal 交换性违背量与 δ_model 决定。组合泛化：故障叠加的定位为并集，覆盖保证按 Bonferroni/联合界扣减。
- **定义 246（动力学不变量库 DIB 与体制切换）**：DIB={r_E,r_P,r_C,r_K,r_Π,r_Θ}，每个不变量带适用谓词（自由飞行/单点接触/多点接触/冲击）；体制由实时接触状态与力阈值判定并切换对应不变量子集与 conformal 分层，避免「用自由飞行的能量账本解释冲击」这类体制错配。
- **定义 247（ZODIAC 证书 J_zodiac）**：J_zodiac=(J_vista, invariant_residual, detection_margin, localization_set, time_to_detect_bound, passivity_cert, model_error_bound, zero_shot_calib_ver, adc_ver)。Valid ⇔ Valid(J_vista) ∧ (无违背 ∨ ISF 已激活 ∨ 真子系统 ∈ L) ∧ 被动性证书成立 ∧ δ_model≤认证界 ∧ 版本匹配。
- **定义 248（ZODIAC 闭环算子）**：语义流 [LiDAR→LSF→USR/MEL→VPG→ACH→DIB 辨识/PHM 建模→ZID 标定→SLoc→UFC→IPP→DPC→CSP-Z→Shield→执行 k*→EV_exec→ADC/RSC-Z→OLP→DIR]。实时流 [锚点读→本体感觉采集→不变量残差 r→CUSUM/ZID 检测→（违背则）ISF 切换→DPC 早停→π_σ 前缀派发→J_zodiac]。

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（零样本检测的分布无关性）**：健康标定集与在线健康样本可交换时，P[s>q(α)]≤α；若故障使残差漂移到 q(α) 之外且信噪比≥τ_snr，则在时延界内以 ≥1−β 被检出。**检测不需要故障标签。**
- **引理 10（结构性定位的集合覆盖）**：若 Λ 的列在符号与通道支撑上可区分，则未知故障（含复合）的真实子系统以 ≥1−α_loc 落在 L 中；L 的基数随 δ_model/τ_snr 退化而增大，但**不会退化为错误的单点断言**——这是与 FIR 强行归类的本质区别。
- **定理 9（ZODIAC 端到端零样本安全）**：在 A94–A98 下，任意故障（已知/未知/复合）满足二选一：被不变量通道在 τ_det 内检出并触发 ISF（闭环能量有界，与身份无关），或残差始终在健康管内且任务伤害 ≤L_task·q(α)；Valid(J_zodiac) ⇒ 不会出现「未知故障被静默放行且高置信执行」。证书链从「归因」上移到「能量/被动性」。
- **定理 10（零样本与组合泛化界）**：检测间隙 Gap ≤ c·√(d_inv·log(1/α)/n_cal)+L_Λ·δ_model；复合故障 L=∪L_k，误覆盖概率 ≤Σα_loc^{(k)}。**泛化成本从「故障类数」变成「不变量维数 + 模型误差」。**
- **命题（动力学分离优于统计分类）**：对落在 ℋ 支撑之外的未知故障，FIR 的最坏风险随到最近假设的距离增长且无上界；ZODIAC 的安全保证与故障身份无关（ISF），检测保证只依赖不变量信噪比。**这把第 65 轮的「归因错误即危险」切断。**
- **实时性**：本体感觉残差与 CUSUM 在实时流（<0.2ms），ISF 功率限制为常数时间；ZID 标定、SLoc、IPP、DPC、ADC 全在语义流。

| E250 压力测试 | 分布漂移/新体制/慢漂移/延迟 | 安全降级，恢复 ≤2s |

## 5. 本轮最大风险

**一句话**：ZODIAC 的全部保证都压在「动力学不变量在真实系统上确实成立、且未建模动力学可被一个有界 δ_model 兜住」这一假设上——一旦摩擦/间隙/柔性模态/冲击让某条不变量长期不可辨识（信噪比过低），系统要么因抬高阈值而**漏掉真实故障**，要么因残差地板过高而**持续误报并退化为永久保守**；更阴险的是「瞬时守恒律看不见的慢故障」（磨损、渐进刚度退化）即使被 r_Θ 部分捕获，也可能在跨越安全边界前始终落在噪声带内，被定理 9 判成「无害」——**用一个可交换性假设下的健康管去承诺「未知故障无害」，本质上仍有把『没见过』误当成『不存在』的残余风险。**

## 2. 形式化定义（完整版）

**定义 233（ZODIAC 闭环）** ZODIAC 是 VISTA 的「零样本化 + 动力学安全兜底」升级：保留 VISTA 的语义流/实时流骨架与 VPG/ACH/VCV，新增 DIB（不变量库）、PHM（端口哈密顿监控）、ZID（零样本检测）、SLoc（结构定位）、UFC（未知故障 conformal）、IPP（不变量保持探针）、DPC（动力学感知认证前缀）、ISF（不变量安全回退）、ADC（对抗动力学认证），并把 RSC-V→RSC-Z、WCV-V→WCV-Z、CSP-V→CSP-Z、J_vista→J_zodiac 原位升级。不变式：**不变量残差生成、CUSUM 检测、ISF 功率限制与切换、DPC 早停只在实时流；不变量辨识、SLoc/UFC、IPP、DPC 规划、ADC 只在语义流；实时流零学习写操作。** 与第 65 轮的核心差异：安全不再以「归因正确」为前提。

**定义 234（端口哈密顿动力学与能量平衡）** 取状态 x=(q,p)，存储函数 H(x)=½pᵀM⁻¹(q)p+V(q)。名义端口哈密顿动力学
ẋ = (J(x)−R(x))∇H(x) + G(x)u + B(x)f_c + d(x,t)，
y = Gᵀ(x)∇H(x)，
其中 J=−Jᵀ（结构矩阵）、R=Rᵀ⪰0（耗散）、u 为执行器输入、f_c 为接触力、d 为未建模项。对区间 [t₀,t₁]，能量账本残差
r_E = [H(t₁)−H(t₀)] − ∫_{t₀}^{t₁} uᵀy dt + ∫_{t₀}^{t₁} ∇HᵀR∇H dt − ∫_{t₀}^{t₁} f_cᵀv_c dt。
健康时 |r_E|≤δ_model；δ_model 由 ADC 给出的未建模动力学界决定。**关键设计**：u、y、H 只取自本体感觉（电机电流、关节速度/力矩），f_c 优先由关节力矩估计而非 F/T 或视觉——使 r_E 与视觉/几何**物理独立**。

**定义 235（动力学不变量残差向量）** 定义六通道残差 r=(r_E,r_P,r_C,r_K,r_Π,r_Θ)：
1. `r_E`：能量账本残差（定义 234）。
2. `r_P`：动量-冲量残差。自由飞行段 p(t₁)−p(t₀)−∫f_ext dt；接触段再减 ∫f_c dt。接触点歧义、冲量估计错、执行器冲量偏差都会进入此通道。
3. `r_C`：接触本构残差 f_n−g(δ)，g 为 Hertz/线性/软接触模型，δ 由几何 + 视觉给出。几何幻觉、软接触模型错、F/T 偏置都污染此通道。
4. `r_K`：运动学一致性残差 = 视觉 6D 位姿 vs 正运动学 vs LiDAR 几何的加权残差。
5. `r_Π`：被动性违背，`∫_window max(0, dH/dt − uᵀy − δ̇_model) dt`，即窗口内**无法由输入解释的能量生成**；主动故障、能量注入型对抗、执行器增益错会触发。
6. `r_Θ`：慢不变量——辨识参数 θ̂=(m̂,μ̂,k̂) 的平稳性漂移，`r_Θ(t)=‖θ̂(t)−θ̂(t−W)‖²_{Σ_θ⁻¹}`；用于捕捉磨损、渐进刚度退化、摩擦系数漂移这类不破坏瞬时守恒律的**慢故障**。

**定义 236（健康不变量管与零样本检测 ZID）** 在健康数据上按运行体制 reg∈{free,touch,load,impact} 分层估计残差均值 μ_r[reg] 与协方差 Σ_r[reg]（稳健估计，抗离群）。非一致性分数 s(r)=‖r−μ_r[reg]‖²_{Σ_r⁻¹}。用 Mondrian split-conformal：对每个体制，取健康标定样本分数的 ⌈(n+1)(1−α)⌉/n 分位数 q(α,reg)。在线检测：s(r_t)>q(α,reg_t) 或带符号 CUSUM 越界即报警。**标定集只含健康样本，从不使用故障标签**，故对任意未见故障的边际覆盖在可交换性下成立。为应对分布漂移（新物体/新任务），实时维护自适应 conformal（ACI）：α_{t+1}=α_t+γ(α−1[报警])，保证长期误报率趋近目标而无需知道故障分布。

**定义 237（结构定位矩阵 SLoc）** 由物理先验构造结构矩阵 Λ∈{0,1}^{6×6}，行对应六类残差通道，列对应六类子系统/故障源：
- 列 1 执行器（增益/饱和/死区）
- 列 2 力矩/F-T 传感（偏置/漂移/标定）
- 列 3 几何-视觉（几何幻觉/视觉错/标定）
- 列 4 接触模型（软接触/未建模动力学/接触点歧义）
- 列 5 环境-未建模（摩擦/间隙/柔性/负载变化）
- 列 6 策略（OOD 动作分布）

健康时 Λ 的各列由「哪些守恒律会被该故障污染」给出，例如：感知类（列 3）只在 r_C、r_K 置 1，**在 r_E、r_Π 置 0**（感知错误不创造真实能量）；执行器/传感/环境（列 1/2/5）在 r_E 或 r_Π 置 1。观测到活跃集 A={i:s_i>q_i} 后，定义结构匹配分数
score(j)=⟨Λ_{:,j}, 1_A⟩ / (‖Λ_{:,j}‖₁ + ε)，
候选集 L=top-κ(score) 直到累计结构解释度 ≥1−α_loc；用集合值 conformal 校准 κ 与阈值，保证 P(true j∈L)≥1−α_loc（在健康/故障混合标定集上）。**L 是子集，可为多元素；当残差只指向物理 vs 感知两类时，L 同时含两端而不强行二选一。**

**定义 238（ε-可检测性与不可检测无害化）** 设视界 T 内故障对某不变量造成的偏移为 Δ。若 Δ>q(α,reg)，称该故障 ε-可检测。对不可检测故障，要求满足以下之一：
(i) 其状态轨迹始终落在健康管切空间内（残差未越界），则在任务映射 L_task-Lipschitz 下，任务伤害
damage ≤ L_task·q(α,reg)；
(ii) 其效应表现为参数慢漂移，被 r_Θ 以阈值 τ_drift 捕获（E241 单独评估慢故障）。
**「无害」承诺仅对 (i) 在给定 Lipschitz 常数与健康管下成立，且需显式报告 q 与 L_task。**

**定义 239（未知故障 conformal 与时延 UFC）** 对带符号残差构造非参数 CUSUM：
g_t = max(0, g_{t−1} + (s_t − k_cusum))，(单侧) 检测当 g_t>h；
阈值 h 由健康数据的分位数给出，避免高斯假设。检测时延（Page-Lorden）在漂移 μ₁、基线 μ₀ 下
E[τ_det] ≤ (h+1)/(KL(μ₁‖μ₀))（近似），并在分布漂移下用 ACI 在线更新 α_t。UFC 的职责是给出「多久必须发现」的可审计界，而不是「这是哪类故障」。

**定义 240（不变量保持探针 IPP）** 探针集 A={visual_probe, null_test, low_power_press, tap, rub, lift}。对候选探针 a，令 Φ(a)=∂r/∂θ 为故障方向 θ 到残差通道的敏感度，定义不变量可观测 Gram
W(a)=∫ Φ(a)ᵀ ΛᵀΛ Φ(a) dt。
选择 a*=argmax_{a∈A} λ_min(W(a))，约束：预测功率 ≤ P_max、预测形变 ≤ ε_strain、预测法向力 ≤ f_safe、且整段轨迹满足 DPC 安全集 h(x)≥0。与第 65 轮 AFA 的 `argmax I(ℋ;ρ)` 的本质区别：**不依赖有限假设集 ℋ**，而是对「所有可能故障方向张成的空间」做 D-最优激励，因此对未知故障也可设计；在易损物体上退化为 `null_test`/`visual_probe`（零功率或纯观测）。

**定义 241（动力学感知认证前缀 DPC）** 设安全集 𝒮={x:h(x)≥0}（h 编码力限、无碰撞、能量界、速度界）。给定动作块 A 与前缀 k，在 ADC 不确定集 𝒟_ADC 上做鲁棒可达集递推：
X₀={x_t}，X_{s+1}=Reach(X_s, A_s, 𝒟_ADC)，要求 X_s⊆𝒮 对所有 s≤k。
最小安全前缀 k* 取满足上式且 k*≤m 的最大值；若 k=0 即不安全，则拒绝该块（k*=0）。用不变量残差管把模型误差并入 𝒟_ADC 的鲁棒裕度。**与第 65 轮 CSC 的差异**：CSC 需要枚举后验支持集里的每个假设分别验裕度（top-2 + 组合爆炸），DPC 用一次可达集验证覆盖整个不确定集，天然免枚举，且对未知故障成立（只要落在 𝒟_ADC 内）。

**定义 242（不变量安全回退 ISF）** 一旦 ZID/CUSUM 报警，无论 SLoc 是否收敛，立即切换到「被动态阻抗 + 能量罐」控制：
u = u_ff + u_es + u_di + u_tank，
其中 u_es 为能量整形（期望势能）、u_di 为阻尼注入（耗散）、u_tank 只在 E_tank>0 时允许提取功率，且提取功率 ≤ −dE_tank/dt。保证：对任意**无源**环境（f_cᵀv_c≥0 的环境端口）与满足功率约束的执行器，
H_cl(t) ≤ H_cl(t₀) + E_tank(t₀) + ∫ P_in dt，
与故障身份无关。当 E_tank→0 或力/速度触顶时，进入 powered safe-stop（限力回撤到安全位形）。这是定理 9 的物理基础。

**定义 243（对抗动力学认证 ADC）** 不确定集
𝒟_ADC = 𝒟_unmodeled × 𝒟_param × 𝒟_sensor，
其中 𝒟_unmodeled 含库仑摩擦、间隙/背隙、柔性模态（增益与相位有界）；𝒟_param 含 m、μ、k 的有界漂移；𝒟_sensor 含传感动态、量化、延迟（≤d_max）。认证：把 δ_model(𝒟_ADC) 计入 q(α,reg) 与 h 的鲁棒裕度；对每个不变量通道计算可检测信噪比
SNR_i = Δ_i / (2δ_model,i)，
若 SNR_i<τ_snr 则该通道标记 `uninformative`，从 A 中剔除、不参与定位，只保留 ISF。ADC 还认证 DPC 的鲁棒 CBF 条件在 𝒟_ADC 上可行。J_zodiac 记录每个通道的 SNR 与可用性，避免「阈值被模型误差悄悄抬高却仍宣称可检测」。

**定义 244（复合故障与共因失效的结构处理）** 复合故障 θ=Σ_k θ^{(k)} 在小扰动下残差近似可加：r≈Σ_k r^{(k)}。定位取并集 L=∪_k L_k；覆盖错误率按 Bonferroni 扣减 Σ_k α_loc^{(k)}。共因失效（如透明/对抗 patch 同时骗过视觉与几何）由**通道物理独立性**处理：
- r_E/r_Π 只依赖本体感觉，与视觉无关，故物理分量仍可检测；
- 若本体感觉自身被污染（执行器/力矩传感故障），则不存在独立物理通道，判 `no_independent_channel`，直接 ISF + safe_idle，不做任何归因；
- 若所有不变量通道都 `uninformative`，等效同上。
**这条设计直接回应第 65 轮「共享 OOD 失效源」风险：不要求分离共因，只要求至少保留一个物理独立通道，否则无条件下调安全等级。**

**定义 245（零样本泛化间隙与组合泛化）** 以健康数据标定、在未见故障分布 𝒟_fault 上测检出率 R_det。零样本间隙
Gap = R_det(𝒟_cal) − R_det(𝒟_fault)。
在交换性下 R_det(𝒟_cal)≥1−β；对 𝒟_fault，Gap 的上界由不变量维数 d_inv、标定样本数 n_cal、交换性违背量（用 ACI 跟踪）与 δ_model 决定，经验形式
Gap ≤ c·√(d_inv·log(1/α)/n_cal) + L_Λ·δ_model。
组合泛化：复合故障定位为并集，覆盖按并集界。**泛化的成本变量从「故障类数 |ℋ|」变为「不变量维数 d_inv + 模型误差 δ_model」。**

```python
class InvariantBank:
    """六通道带符号残差；r_E/r_Pi 只用本体感觉，保证与视觉物理独立。"""
    def residuals(self, x, u, y_prop, f_c, v_c, theta_hat, theta_hist, reg):
        r = {}
        if 'free' in reg:
            r['r_E'] = (energy(x[1]) - energy(x[0])
                        - integrate(u * y_prop) + diss_est(x))
            r['r_P'] = momentum_delta(x) - impulse_ext(u, reg)
        if 'contact' in reg:
            r['r_E'] = (energy(x[1]) - energy(x[0])
                        - integrate(u * y_prop) + diss_est(x)
                        - integrate(f_c * v_c))
            r['r_P'] = momentum_delta(x) - impulse_ext(u, reg) - impulse_contact(f_c)
            r['r_C'] = f_c.normal - constitutive(delta_from_geometry(x), reg)
        r['r_K'] = kinematic_mismatch(vis_pose, fk(q), lidar_geometry)
        r['r_Pi'] = integrate(max(0.0, dHdt(x) - u*y_prop - d_delta_model))
        r['r_Theta'] = param_drift(theta_hat, theta_hist)
        return r
```

### IP-226 ZID（零样本健康管 + ACI）

```python
class ZeroShotInvariantDetector:
    def __init__(self, alpha=0.05, gamma=0.01):
        self.alpha, self.gamma = alpha, gamma
        self.mu, self.Sigma, self.q = {}, {}, {}      # 每 regime 只由健康数据估计
        self.alpha_t = alpha

    def calibrate_healthy(self, healthy_by_regime):
        for reg, scores in healthy_by_regime.items():
            self.mu[reg] = robust_mean(scores)
            self.Sigma[reg] = robust_cov(scores)
            s = [maha(x - self.mu[reg], self.Sigma[reg]) for x in scores]
            self.q[reg] = conformal_quantile(s, self.alpha_t)

    def score(self, r, reg):
        return maha(r - self.mu[reg], self.Sigma[reg])

    def step(self, r, reg):
        s = self.score(r, reg)
        alarm = s > self.q[reg]
        self.alpha_t += self.gamma * (self.alpha - float(alarm))   # ACI
        return alarm, s, self.q[reg]
```

```python
def structural_localize(active, Lambda, alpha_loc, calib):
```

```python
class DynamicsPrefixCertificate:
    def certified_prefix(self, A, x0, h_safe, D_ADC, m, delta_model):
```

```python
class InvariantSafeFallback:
    def __init__(self, E_tank0=1.0, P_max=5.0):
        self.E_tank, self.P_max = E_tank0, P_max

    def activate(self):
        self.active = True

    def power_limited_control(self, x, x_des, dt):
        u = impedance_with_energy_shaping(x, x_des)
        u += damping_injection(x)
        P_req = max(0.0, u @ velocity(x))               # 提取功率
        if P_req > min(self.P_max, self.E_tank / max(dt, 1e-6)):
            u *= min(self.P_max, self.E_tank / max(dt, 1e-6)) / max(P_req, 1e-9)
        self.E_tank = max(0.0, self.E_tank - (u @ velocity(x)) * dt)
        if self.E_tank <= 0:
            u = powered_safe_stop(x)                    # 限力回撤
        return u
```

## 4. 推导

**引理 9（零样本检测的分布无关性）** 设健康标定样本 Z₁,…,Z_n 与在线健康样本 Z 可交换，非一致性分数 s 可测。由 split-conformal 的经典结论，
P[s(Z) ≤ q(α)] ≥ 1−α，
其中 q(α) 为标定分数的 ⌈(n+1)(1−α)⌉/n 分位数；按体制分层（Mondrian）时该式对每个 regime 成立。故健康误报率 ≤α，且**推导未使用任何故障标签**。若故障使残差均值漂移到 μ₁，偏移 Δ=‖μ₁−μ₀‖_{Σ⁻¹}，则单次检出概率随 Δ 增大；用 CUSUM 累积时，Page-Lorden 给出 E[τ_det]≤(h+1)/KL(μ₁‖μ₀)（近似），即检测时延可控。∎

**引理 10（结构性定位的集合覆盖）** 设真实故障子系统 j*，其残差模式 p_j=Λ_{:,j}。若 A 与 p_{j*} 的结构匹配分数严格高于非真列，则 j* 进入排序前 κ；用故障标定集做集合值 conformal，取最小 κ 使经验覆盖 ≥1−α_loc，则
P[j* ∈ L] ≥ 1−α_loc
（可交换性下）。当 δ_model 增大或某通道 SNR<τ_snr 被剔除时，A 的信息量下降，κ 增大（集合变宽），但**报告的是集合而非错误的单点**；复合故障 p_{j*}=Σ_k p_{j_k} 的匹配分数对应并集，覆盖按 Bonferroni 扣减。∎

**定理 9（ZODIAC 端到端零样本安全）** 在 A94–A98（体征残差有界、ADC 不确定集覆盖真实未建模项、ISF 能量罐功率约束成立、DPC 鲁棒可达集正确、conformal 交换性/ACI 收敛）下，对任意故障（已知/未知/复合）：
1. **检测或无害**：若存在不变量通道 SNR≥τ_snr 且偏移 >q(α)，则在 τ_det 内报警（引理 9）；否则残差在健康管内，任务伤害 ≤L_task·q(α)（定义 238）。
2. **报警即安全**：报警触发 ISF，闭环能量 H_cl≤H_cl(0)+E_tank(0)+∫P_in dt，对任意无源环境与满足功率约束的执行器成立（定义 242），**与故障身份无关**；因此不存在「归因错误 → 膨胀错误球 → 更自信执行」这一第 65 轮的失效链。
3. **定位只影响效率**：L 的覆盖由引理 10 保证；即使 L 错误，安全仍由 ISF 兜底，只是保守度上升（k* 变小、成功率下降）。
4. **证书完整性**：Valid(J_zodiac) 要求报警状态、ISF 证书、定位集合、SNR、模型误差界一致；缺失任一即拒绝执行。
故 ZODIAC 把「安全」与「归因」解耦：安全由动力学/被动态保证，归因只用于减少保守。∎

**定理 10（零样本与组合泛化界）** 由引理 9，健康误报 ≤α；对未见故障分布 𝒟_fault，检出率的下降来自 (i) 标定-测试的交换性违背，(ii) 残差偏移相对模型误差信噪比不足。用 ACI 跟踪 (i)，用 ADC 报告 (ii)，得
Gap ≤ c·√(d_inv·log(1/α)/n_cal) + L_Λ·δ_model + O(√(γ))，
其中最后项为 ACI 的漂移跟踪误差。组合故障因残差可加，定位为并集，误覆盖 ≤Σα_loc^{(k)}；检出概率 ≥max_k(单故障检出概率)（联合界给出下界）。**关键的定性结论：泛化成本随不变量维数与模型误差增长，而不是随故障类别数增长。** ∎

**命题（动力学分离优于统计分类）** 第 65 轮 FIR 对未知故障 θ∉supp(ℋ) 的归因风险随 dist(θ,ℋ) 增长且无界，因为其只输出 argmax 后验；ZODIAC 对同一 θ 的安全保证（ISF 能量界）与 θ 无关，检测保证只要求不变量 SNR≥τ_snr。因此第 65 轮的「归因错误即物理伤害」被切断。代价是：当 δ_model 过大导致全通道 uninformative 时，系统只能永久 ISF（安全但低效）——这是明确、可审计的降级，而非静默的错误自信。∎

## 7. 已知风险

**一句话**：ZODIAC 的全部保证都压在「动力学不变量在真实系统上确实成立、且未建模动力学可被一个有界 δ_model 兜住」这一假设上——一旦摩擦/间隙/柔性模态/冲击让某条不变量长期不可辨识（SNR<τ_snr），系统要么因抬高阈值而**漏掉真实故障**，要么因残差地板过高而**持续误报并退化为永久保守**；更阴险的是「瞬时守恒律看不见的慢故障」（磨损、渐进刚度退化）即使被 r_Θ 部分捕获，也可能在跨越安全边界前始终落在噪声带内，被定理 9 判成「无害」——**用一个交换性假设下的健康管去承诺「未知故障无害」，本质上仍有把『没见过』误当成『不存在』的残余风险。**

**次级风险与缓解**：
1. **模型误差抬高残差地板 → 漏报/误报**：ADC 显式估计 δ_model 并对每个通道报告 SNR；SNR<τ_snr 时该通道降级为 `uninformative`、只保留 ISF；持续误报则触发在线重标定而非静默放行。
2. **不变量被系统性建模错（守恒律本身写错）**：如接触功率符号错、坐标系约定错，会导致系统性误报；缓解：用健康数据做「零残差自检」（健康段若 r_E 长期显著非零，先怀疑监控器自己），并保留第 65 轮 VISTA 的归因通道做交叉。
3. **慢故障落在噪声带内（最危险）**：瞬时守恒律与参数漂移都可能迟钝；缓解：引入趋势检验（r_Θ 的 CUSUM on slope）、维护周期离线标定、把「慢故障不可检测」作为显式安全假设写入证书，而非默认安全。
4. **被动性假设失效（环境/执行器有源）**：ISF 的能量界只对无源环境成立；对抗性有源环境可能持续泵能；缓解：功率上限 + 能量罐 + 速度/力硬限幅，并在 ADC 中把有源环境作为最坏情形认证，退出任务。
5. **集合定位过宽导致保守**：覆盖保证以集合大小为代价；缓解：允许「用探针换精度」（IPP），并把集合大小作为效率指标而非安全指标报告。
6. **conformal 交换性在分布漂移下失效**：ACI 长期覆盖成立但短期可能失准；缓解：漂移检测（残差分位数漂移即重标定）+ 分层更细的运行体制。
7. **复合故障可加性近似失效（强非线性耦合）**：两个故障互相放大时 r≈Σr^{(k)} 不成立；缓解：交集非空即升级为 `composite_uncertain`、直接 ISF，不做精细定位。
8. **实时预算**：不变量积分与 CUSUM 很轻，但 ISF 切换与 DPC 查表需与第 65 轮实时路径共享；缓解：能量罐与 CBF 查表化、可达集离线预计算。
