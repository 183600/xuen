# 第 47 轮（承接第 46 轮产物 v23；本轮灵感：安全对齐 × 本体感知） · Proprio-Align：本体感知锚定的跨模态一致性证书与对齐式安全治理（五层架构 v11）

> 承接 v23 的 MVR/VAD/SAB 全局决策。v23 把安全收敛为“姿态证书 P_t 有效 + 指令-姿态绑定 B(v_t,P_t)≥θ_safe”，但隐含假设 H5：P_t 是自我位姿的充分证据，且“安全”只由外感定义。H5 有两个漏洞：(1) P_t 完全依赖 RGB/深度外感，一旦能量租约 ℓ_e 迫使深度关闭、或透明/空洞层使外感退化，P_t 会静默失效；(2) 即便 P_t 正确，系统只保证“不执行不安全指令”，却不保证执行动作落在人类意图的安全集内——这是“安全”而非“对齐”。本轮两个灵感精确命中：**本体感知**提供一条 1kHz、近零能耗、与外感独立的内部观测通道（关节编码器、IMU、足底力/力矩），可用漂移预算桥接外感空窗；**安全对齐**要求把“证书正确”升级为“执行动作可证地落在意图安全集内，且失效时以可监督方式分级降级”。二者耦合的新问题：**如何用一个会漂移、且无法自证的内部通道去锚定外部证书，并在能量约束下调度再锚定，既不陷入自证陷阱，又不过度保守导致系统不可用**。

## 0. 直觉与动机

**灵感 1（本体感知 → 会漂移的独立证据通道）**
直觉：机器人对自己关节角、角速度、足底接触与力矩有直接测量，这是任何深度相机都给不了的。外感回答“我在世界的哪里”，本体感知回答“我的身体此刻是什么构型”。前者会被遮挡/高光/能量打断，后者在短时窗内连续、廉价、1kHz。但本体感知不是真值：编码器偏置、运动学标定误差、足底打滑、IMU 零偏都会让积分漂移。正确做法不是“相信本体”，而是**给本体感知一个随时间与打滑事件增长的漂移预算 δ_Q，并在预算耗尽前强制再锚定**。

**灵感 2（安全对齐 → 从“证书有效”到“动作在意图安全集内”）**
直觉：证书有效只说明“我知道自己在哪”，不说明“我要做的事是用户允许的”。安全对齐把问题改成：由语音/任务上下文得到意图安全集 S_intent，执行动作的可达集 A_t 必须被证明包含于 S_intent；若无法证明，就投影动作、减速或受控停在最后一次已认证的安全包络里，而不是直接硬急停。对齐还意味着**失效必须可监督**：分级响应（EXECUTE → PROJECT → SAFE_STOP → FAIL_CLOSED），每级都留有可解释的对齐残差 ε_align。

**灵感 3（两灵感耦合 → 交集证书与自证陷阱）**
直觉：若外感证书 P_t 与本体证书 Q_t^δ 各自以 1-α 覆盖真值，则交集 C_t=P_t∩Q_t^δ 仍覆盖真值（并集界）。交集是“保守但 sound”的融合：外感负责绝对锚定，本体负责桥接外感空窗。反面风险是**本体感知自证陷阱**：若外感失效时单独信任 Q_t，系统会用“自己说自己在哪”给自己发安全证书；一旦本体漂移或打滑，证书与真值同时错且毫无察觉。因此本体感知永远不能单独作为 soundness 来源，只能作为“有期限的桥”，桥的尽头必须是再锚定或 fail-closed。

**架构升级**：在 v10 四层之上新增 **对齐治理层**（第五层/横切）。PAS 维护本体状态与漂移预算；XAC 生成跨模态交集证书与一致性残差；SAG 做意图安全集投影与分级响应，并把“再锚定”作为带能量成本的调度动作交给 ECPS。v11 仍保持“根信任 + 几何 + 上下文 + 安全 + 数据”骨架，只是根信任从“姿态租约 + 能量租约”扩展为“姿态租约 + 能量租约 + 本体锚定租约 ℓ_q”。

## 1. 形式化定义（增量：定义 59–63）

**定义 59（本体感知状态与漂移预算）**
本体状态 Q_t=(q_t, q̇_t, f_t, a_t)（关节角/速度、足底接触力、IMU）。锚定时刻 t_a 后，漂移预算
δ_Q(t)=δ_0 + κ_kin·(t−t_a) + Σ_{i∈slip} κ_s·s_i，
其中 s_i 为第 i 次打滑/冲击强度，κ 为标定系数。置信集 Q_t^δ={x: ||x−Q̂_t|| ≤ δ_Q(t)}。
**锚定租约** ℓ_q=(t_a, δ_max, κ_kin, κ_s)：当 δ_Q(t)≥δ_max 时 ℓ_q 过期，所有仅由本体支撑的证书失效。

**定义 60（跨模态对齐证书）**
设外感证书 P_t 以概率 ≥1−α_p 覆盖真值 X_t，本体置信集 Q_t^δ 以概率 ≥1−α_q 覆盖 X_t。定义交集证书
C_t = P_t ∩ Q_t^δ，
则 P(X_t∈C_t) ≥ 1−α_p−α_q。**一致性残差** ρ_t=d_H(P_t, Q_t^δ)（Hausdorff 距离）。当 C_t=∅ 时记“通道分歧”，不得直接信任任一通道——此时 P_t 与 Q_t 必有一个偏离真值。

**定义 61（意图安全集与对齐误差）**
意图安全集 S_intent(v_t,c_t) ⊆ SE(3)，由语音槽位、任务上下文与预置安全规则给出（保守外包）。给定动作 a_t、时域 H，认证可达集 A_t=Reach(C_t, a_t, H)。
**对齐**：A_t ⊆ S_intent 且 C_t sound 且 ℓ_q 有效。**对齐误差** ε_align=dist(A_t, S_intent)（A_t 到安全集外部的距离，内部为 0）。

**定义 62（锚定调度问题）**
在能量租约 ℓ_e 与漂移租约 ℓ_q 下选择再锚定时刻 t_a' 与锚定模态 m_a（低功耗地标/IMU-里程计/深度帧），
min P_{m_a}·(t_a'−t_a)，s.t. P(δ_Q(t)≤δ_max, ∀t∈[t_a,t_a']) ≥ 1−β 且 E(t_a')≥E_min。
若不存在可行 t_a'，则必须在 ℓ_q 过期前进入分段 fail-closed。

**定义 63（对齐式安全治理策略）**
π_align(C_t, ε_align, ℓ_q, ℓ_e) ∈ {EXECUTE, PROJECT, SAFE_STOP, FAIL_CLOSED}：
- EXECUTE：对齐成立；
- PROJECT：A_t⊄S_intent 但投影非空，执行 argmin_{a∈S_intent} ||a−a_t||；
- SAFE_STOP：C_t=∅ 或 ε_align>ε_stop，在最后认证包络内受控停止并发起再锚定；
- FAIL_CLOSED：ℓ_q 过期且无法再锚定，或能量不足以完成受控停止。
**分级不变式**：任一级别的停止终点 ∈ 最后一次认证安全包络，即不会在未认证区域内急停。

## 2. 新增产出与既有 IP 升级

**IP-69 PAS（Proprioceptive Anchor State）** 本体状态与漂移预算
- 编码器 + IMU 互补滤波；足底力/电机电流打滑检测
- 漂移预算在线标定：按接触事件累积 κ_s，按运动学残差更新 κ_kin
- 发布锚定租约 ℓ_q 与过期广播

**IP-70 XAC（Cross-modal Alignment Certificate）** 跨模态对齐证书
- 外感 P_t 与本体 Q_t^δ 的区间/置信集求交
- 一致性残差 ρ_t、空交集检测、并集界 soundness 记账
- 通道分歧时“冻结最后认证包络”，而非采信任一方

**IP-71 SAG（Safety Alignment Governor）** 对齐式安全治理器
- 意图安全集 S_intent 的保守外包与投影算子
- 认证可达集 A_t=Reach(C_t,a,H) 与包含性检查
- 四级分级响应与“停止终点在包络内”不变式
- 再锚定请求 → ECPS 能量调度

**既有 IP 升级**
IP-51 CAR：守卫从“姿态 + 能量”扩展为“姿态 + 能量 + 锚定租约 ℓ_q”；急停改为包络内 SAFE_STOP。
IP-63 ECPS：模态集合加入 anchor（低功耗地标/IMU-里程计/深度帧），再锚定能耗计入 ℓ_e。
IP-68 SAB：绑定函数使用 C_t 与接触力通道；出现未预期接触（预测自由空间却测到力）立即 SAFE_STOP。
IP-61 DCL：采集任务加入本体漂移/打滑标定样本，覆盖 κ 参数不确定区。
IP-62 CCA：新增“自证陷阱”红队（注入编码器偏置、打滑、共同标定误差）。
IP-45 总线：新增 proprio-state / anchor-lease / alignment-residual / anchor-schedule 话题。

## 3. 算法骨架

每控制周期：
1. PAS 更新 Q_t、δ_Q(t)、ℓ_q，并检测打滑/未预期接触。
2. XAC 取 P_t 与 Q_t^δ 求交得 C_t 与 ρ_t；空交集 → 冻结最后认证包络。
3. SAG 计算 S_intent、A_t=Reach(C_t,a,H)，判包含。
4. 对齐 → EXECUTE；否则 PROJECT/SAFE_STOP；ℓ_q 过期且无可行锚定 → FAIL_CLOSED。
5. δ_Q 接近 δ_max 时向 ECPS 发再锚定请求，ECPS 在能量约束下选 m_a 与 t_a'。
6. 接触力异常 → SAFE_STOP（本体通道 1kHz，快于视觉）。

## 4. 本轮最大风险

**一句话**：把本体感知当作可信锚点会形成“自证陷阱”——若漂移预算被低估（未建模打滑/共同标定误差），系统会在外感失效时用错误本体状态给自己签发 sound 证书，证书与真值同时偏离且无从察觉；因此本体感知只能在漂移租约内作为桥接、必须由独立外感/地标周期性再锚定，且 δ_Q 标定不足时默认降级为 SAFE_STOP 而非 EXECUTE。

## 2. 关键算法 伪代码

### IP-69 PAS
```
def proprio_update(enc, imu, ft, prev, t, cfg, slip_model):
    q  = complementary_fuse(enc.q, imu, prev.q, cfg.dt)
    qd = enc.qd if enc.valid else imu_integrate(imu, cfg.dt)
    slip_p = slip_model(ft, imu, qd, enc)          # 0..1 打滑/冲击概率
    slip_acc = prev.slip_acc + slip_p * cfg.k_s
    drift = cfg.delta0 + cfg.k_kin * (t - prev.t_anchor) + slip_acc
    Q = ProprioState(q=q, qd=qd, f=ft, slip_p=slip_p,
                     t_anchor=prev.t_anchor, drift=drift,
                     slip_acc=slip_acc)
    lease_q = AnchorLease(t_a=prev.t_anchor, delta_max=cfg.delta_max,
                          valid=(drift < cfg.delta_max))
    return Q, lease_q
```

### IP-70 XAC
```
def cross_modal_cert(P, Q, alpha_p, alpha_q, t):
    if not P.valid:                                # 外感不可用
        return Cert(valid=False, reason='extero_down',
                    last_envelope=P.last_safe_envelope)
    Qball = ball(Q.q, Q.drift)
    C = intersect(P.region, Qball)
    rho = hausdorff(P.region, Qball)
    if empty(C):                                   # 通道分歧
        return Cert(valid=False, reason='disagree', rho=rho,
                    last_envelope=P.last_safe_envelope)
    return Cert(region=C, valid=True, rho=rho,
                sound=1.0 - alpha_p - alpha_q,
                anchor_age=t - Q.t_anchor, bridge=False)

def bridge_cert(P, Q, alpha_q, t):
    # 外感失效时的“有期限桥”：只用上一次外感包络 ∩ 本体球，避免自证
    if not Q.t_anchor == P.anchor_t:              # 桥必须锚在真实外感上
        return Cert(valid=False, reason='no_anchor')
    C = intersect(P.last_safe_envelope, ball(Q.q, Q.drift))
    if empty(C):
        return Cert(valid=False, reason='disagree')
    return Cert(region=C, valid=True, sound=1.0 - alpha_q,
                anchor_age=t - Q.t_anchor, bridge=True)
```

### IP-71 SAG
```
def align_govern(v, c, action, P, Q, lease_q, H, cfg):
    C = cross_modal_cert(P, Q, cfg.alpha_p, cfg.alpha_q, t)
    if not C.valid:
        if C.reason == 'disagree':
            return SAFE_STOP, freeze(C.last_envelope), request_anchor('high')
        # 外感失效：仅在漂移租约内走 bridge，且 bridge 不得升级为 EXECUTE
        if lease_q.valid:
            C = bridge_cert(P, Q, cfg.alpha_q, t)
            if not C.valid:
                return SAFE_STOP, freeze(P.last_safe_envelope), request_anchor('high')
        else:
            return FAIL_CLOSED, None, request_anchor('urgent')

    S = intent_safe_set(v, c)                      # 保守外包
    A = reachable(C.region, action, H)
    eps = dist_to_outside(A, S)
    if (not C.bridge) and A <= S and C.sound >= 1 - cfg.alpha_req:
        return EXECUTE, action, None
    if eps <= cfg.eps_stop and project(action, S) is not None:
        return PROJECT, project(action, S), request_anchor('normal')
    return SAFE_STOP, freeze(C.region), request_anchor('high')
```

```
def schedule_anchor(Q, lease_e, cfg, t):
    rate = cfg.k_kin + cfg.slip_rate_est
    deadline = t + (cfg.delta_max - Q.drift) / max(rate, cfg.eps_rate)
    # 按能耗从低到高尝试：IMU-地标 < 立体帧 < 深度帧
    for m_a in ['imu_landmark', 'stereo_frame', 'depth_frame']:
        if energy_lease_ok(lease_e, m_a, deadline, cfg.E_min):
            return m_a, deadline
    return None, deadline          # 无可行锚定 → SAG 在 ℓ_q 过期前分段 fail-closed
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| PAS 更新 | O(n_joint) | O(n_joint) | 漂移预算随时间/打滑单调增长，ℓ_q 过期即撤销本体 soundness |
| XAC 求交 | O(k)（区间/凸集） | O(k) | 两通道各 sound ⇒ 交集 sound（并集界 1−α_p−α_q） |
| SAG 可达检查 | O(H·n_dof) | O(H) | EXECUTE ⇒ A_t⊆S_intent 且 C_t sound 且非 bridge |
| 锚定调度 | O(|M_a|) | O(1) | 存在可行锚定则 ℓ_q 永不过期；否则提前进入 fail-closed |
| 全局决策 | O(|M|+H·n_dof) | O(|M|+H) | 分级不变式：停止终点 ∈ 最后认证包络 |

**正确性定理（Proprio-Align Soundness）**
若 (i) 每次外感证书 P_t 以 ≥1−α_p 覆盖真值，(ii) 本体置信集 Q_t^δ 以 ≥1−α_q 覆盖真值，(iii) δ_Q 的标定覆盖未建模打滑，(iv) bridge 证书仅取 P.last_safe_envelope ∩ Q_t^δ 且不得触发 EXECUTE，则 XAC 输出的 C_t 以 ≥1−α_p−α_q 覆盖真值；SAG 输出 EXECUTE 时 A_t⊆S_intent 且 C_t sound；任何 SAFE_STOP 的停止终点落在最后一次认证包络内；若外感失效且 ℓ_q 过期，系统不输出 EXECUTE。

**推论（自证陷阱隔离）**：由于 bridge 证书 sound 上界为 1−α_q 且被禁止进入 EXECUTE 分支，本体感知无法单独为执行动作背书；即便本体漂移，最坏结果是 SAFE_STOP/FAIL_CLOSED，而非“错误执行”。

## 4. 实验设计 E115–E120

| 实验 | 指标 | 门槛 |
|---|---|---|
| E115 本体漂移标定 | δ_Q 覆盖率、漂移低估率 | 覆盖率 ≥ 99%；低估率 ≤ 1% |
| E116 跨模态一致性 | 交集非空率、ρ_t 分布、实测 soundness | 分歧检测延迟 ≤ 50ms；实测 soundness ≥ 标称 |
| E117 自证陷阱红队 | 注入编码器偏置/打滑/共同标定误差下的误认证率 | 误认证率 = 0；必触发 SAFE_STOP/FAIL_CLOSED |
| E118 对齐误差与分级 | ε_align 分布、PROJECT/SAFE_STOP 频次、意图违例 | 意图违例 0；误停率 ≤ 5% |
| E119 能量-锚定联合 | 锚定能耗、ℓ_q 过期次数、deadline 失约 | 过期 0 起；锚定能耗 ≤ 总能耗 8% |
| E120 100h 全局闭环 | 安全违例、任务成功率、平均再锚定间隔 | 安全违例 0；可用率 ≥ 97% |

回退策略：
- E115 漂移低估率 > 1% → 收紧 κ_kin/κ_s，再锚定间隔减半；
- E117 出现任何误认证 → 关闭 bridge，EXECUTE 必须由真实外感证书支撑；
- E118 误停率 > 5% → 放宽 ε_stop 或加入人工确认，但不放松 EXECUTE 条件；
- E119 锚定能耗 > 8% → 切 IMU-地标锚定，降低锚定频率并预留硬锚定能量预算。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 本体漂移预算低估（自证陷阱） | 高 | 保守 κ；打滑/冲击事件检测；强制周期再锚定；bridge 仅用 last_envelope∩Qball 且禁止 EXECUTE |
| 交集过保守致可用性下降 | 中 | 四级分级响应；PROJECT 保持任务连续；自适应 α_req |
| 意图安全集 S_intent 形式化错误 | 高 | 保守外包 + 独立规则引擎 + 高风险动作人工确认 |
| 外感与本体共同失效（共同标定误差） | 高 | 独立审计集；已知 fiduciary 地标；异源交叉校验 |
| 能量不足以再锚定导致停机 | 中 | 预留硬锚定能量预算；优先低功耗 IMU-地标锚定 |
| 接触检测误报导致频繁 SAFE_STOP | 中 | 力矩阈值 + 短时窗确认；区分负载与环境接触 |

## 6. 本轮最大风险

**一句话**：若本体漂移预算 δ_Q 被低估或“共同标定误差”让外感与本体同时偏移，交集 C_t 会以高置信度收敛到错误区域，系统可能把错误位姿当成对齐并持续执行；因此必须以独立审计集校准 δ_Q、强制周期性异源再锚定，并将“外感-本体一致性残差 ρ_t 长期偏大”本身作为触发 SAFE_STOP 的一等安全信号，而不是只看交集是否非空。
