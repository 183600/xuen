# 第 57 轮（承接第 56 轮「MapProbe-Negotiate」IP-127~132；灵感循环第 2 轮；本轮灵感：「竞赛策略」×「模型蒸馏」）

> 第 56 轮把"感知标签"升级为"证据承诺"：持久地图 𝓜、探-诺-演 PCE、协商护盾 ISE 把语义不确定性挡在不可逆接触之前。但它仍默认两件事：其一，**只有一个目标——安全**，探测的时间/分数代价、比赛的多轮性与"输了就出局"的破产约束没有进入决策；其二，**产生置信的模型就是部署的模型**，而边缘端为了实时性必须把大模型蒸馏成小模型，蒸馏会把教师的"自信"连同"盲区"一起压进学生。本轮两个灵感正好拆这两个默认：**竞赛策略**给风险一个"银行家"（可分配、不可增发、带破产约束），**模型蒸馏**给能力一个"继承契约"（继承的是先验，不是证据）。核心命题：**蒸馏只能转移能力，不能转移证据；竞赛只能分配风险，不能创造风险。**

核心矛盾：
- **H29**：第 56 轮的可行性判定是"逐接触安全"的，没有比赛目标。真实竞赛是多轮、限时、有排行榜、单次不可逆失败可能直接出局的**重复决策**：探针要花时间与分数，"落后"又提供最动听的加险理由。缺少风险银行家时，系统要么保守到赢不了，要么在追赶时把安全预算悄悄花穿。
- **H30**：第 56 轮的证据门假设"产生置信的模型 = 部署的模型"。蒸馏后，学生的置信是**继承来的**，不是观察来的；教师的系统性盲区会被软标签原样复制，压缩还会让校准退化。于是学生可能恰好在教师最自信的错误处最自信，而证据门会"诚实地"为这份继承的自信放行——这是**置信洗白**。
- **H31**：两个压力同向叠加：比赛要求快，蒸馏提供快，而快的那份能力恰恰带着未经验证的继承误差；排行榜又给"把风险预算重新解释成授权"提供了社会可接受的叙事。最危险的时刻，正是系统最想赢的时刻。

## 0. 直觉与动机

**灵感 1（竞赛策略 → 风险是银行家，不是开关）**
直觉：比赛不是"每次接触都尽量安全"，而是**在破产约束下最大化期望得分**。把总风险预算 `δ_tour` 看成一家银行的本金：每个任务/轮次分到一笔额度 `δ_k`，探针是投资（用时间买信息），承诺是下注，不可逆失败是破产。关键不是更敢赌，而是三条纪律：**总预算不可增发**；排行榜只能改变额度在轮次间的**分配**，不能改变总额；**不追亏损**——落后时可以调整下注结构，不能把未来的安全额度提前抵押。这样"落后时该不该更激进"第一次有了可审计的答案：可以更激进地**分配**，不可以更激进地**透支**。

**灵感 2（模型蒸馏 → 蒸馏的是规则，不是信念）**
直觉：蒸馏真正可迁移的是**不变式**——几何约束、接触裕度、安全包络、标定过的动作偏好；不可迁移的是**此地的证据**——这块冰今天能不能承重、这个坡昨天是否融过。把两者混在一起蒸馏，等于把"曾经观察到的世界"伪装成"学生此刻观察到的世界"。因此本轮把蒸馏拆成两层：**可证不变式下沉到学生**（带范围、带误差界），**情境证据留在教师/地图并按需查询或现场探针**。学生继承的是一个有作用域的先验，不是一个无条件的通行证。

**灵感 3（蒸馏税 + 教师联盟 → 不一致就是免费的探针）**
直觉：学生可以少探，但不能不探。把"验证继承知识的探针开销"显式记为**蒸馏税**：证书范围内、且已获独立佐证的 `EV-distill` 可以抵扣探针数量，但**不可逆/高风险接触不得以 `EV-distill` 为唯一证据**。更妙的是，教师联盟之间的分歧、教师与学生的分歧本身就是**认知信号**：不要平均掉，不要多数表决，直接当成"这里有未知"的探针触发器。共识只在**校准过的区域**才算先验，分歧就是免费的 VOI。

**灵感 4（安全蒸馏界 → 学生永远不比教师更冒险）**
直觉：蒸馏不该被当作"复制教师"，而应当被当作"给教师加一层保守包装"。用可证界 `p̄_S = p̄_T + ε_TD + ε_cal^S + ε_cov` 包住学生：只有当上界仍满足 `p̄_S ≤ δ_f(g)` 才允许承诺；否则回退教师、加探针、降档或停。于是压缩可以损失能力、可以变慢，但**不能损失保守性**——学生可以比教师更胆小，绝不能比教师更大胆。

**灵感 5（竞赛证据证书 → 冠军不是最激进的，是没破产且分最高的）**
直觉：把地图证据、蒸馏证书、风险银行家账本、分数账本、审计日志合成一张 `J_t`。冠军策略的定义不是"单轮最高分"，而是"多轮结束时总分高且从未触发不可逆失败"。证书让"赢"与"没输掉"同时可审计：任何一次承诺都能追溯到它用的是现场观察、地图证据，还是一份仍在有效期内且获佐证的蒸馏先验。

## 1. 形式化定义（增量：定义 133–138）

**定义 133（竞赛契约与策略目标）** `𝒞 = (K, {T_k}, S, τ_max, R_irr, δ_tour, ℓ)`：`K` 个任务/轮次；计分 `S(τ)=Σ_k [w_k·s_k(τ_k) − λ_t·τ_k]`；时间上限 `τ_max`；不可逆失败集 `R_irr`；破产约束 `P(∃k: R_irr) ≤ δ_tour`；排行榜状态 `ℓ`。策略目标：

```
max_π  E[ S(τ) ]
s.t.   P(∃ 不可逆失败) ≤ δ_tour,
       ∀ 接触: P_fail ≤ δ_f(g),
       Σ_k τ_k ≤ τ_max,
       Σ_k δ_k ≤ δ_tour.
```

风险银行家把 `δ_tour` 分成 `{δ_k}`（默认用联合界，`Σδ_k ≤ δ_tour`）；每个接触还受 `δ_f(g)` 与轮次额度 `δ_k` 的双重约束：`P_fail ≤ min(δ_f(g), δ_k)`。

**定义 134（安全蒸馏界 SDB）** 教师 `T`、学生 `S`、验证分布 `D_val`；转移间隙 `ε_TD = sup_{x∈X_val} |p̄_T(x) − p_fail^S(x)|`，学生校准误差 `ε_cal^S`，覆盖误差 `ε_cov`。学生风险上界与承诺条件：

```
p̄_S(x) = min(1, p̄_T(x) + ε_TD + ε_cal^S + ε_cov)
commit_S(x) 允许 ⇔ p̄_S(x) ≤ δ_f(g) ∧ x ∈ scope(cert)
```

`p̄_T` 已含第 56 轮教师侧的校准上界。**保守蒸馏公理**：`p̄_S ≥ p̄_T`，即学生只能更保守；任何蒸馏更新不得降低未观测点的风险下界。

**定义 135（可证蒸馏证据 CDE）** 新增证据类 `EV-distill@(φ, val, cert)`，证书 `cert=(coverage, ε_TD, ε_cal^S, league_agreement, blindspot_audit, ver, expiry)`。有效性：

```
val(cert) = {x : d(x, X_val) ≤ ρ_cert ∧ now ≤ expiry}
w_d(x)    = w_d_max · 1[x∈val(cert)] · (1 − ε_TD/ε_TD_max)_+
```

三条硬规则：(i) `EV-distill` 只是**先验**，不是观察；(ii) 不可逆/高风险/L2 接触**不得**以 `EV-distill` 为唯一证据，必须由 `EV-probe/visit/margin/human` 之一佐证；(iii) 教师联盟分歧或师生分歧超过阈值时，`EV-distill` 权重降为零并触发探针。证书过期、OOD 检出、审计失败均立即撤销。

**定义 136（自适应风险银行家 ABM）** 状态 `(B_k, score_gap, rounds_left, ℓ)`，`B_0=δ_tour`。分配：

```
δ_k = clip( base_k + κ·score_gap·base_k, δ_min, δ_max )
s.t. δ_k ≤ B_k,  B_{k+1} = B_k − δ_k,  Σ_{j≥k} δ_j ≤ B_k.
```

**排行榜单调性**：`ℓ` 变化只允许重排未来 `{δ_j}`，不允许改变 `Σδ_j`；`score_gap` 再大也不得突破 `B_k`。**不追亏损**：落后超过 `θ_chase` 时，只能改变下注结构（更快的同级方案、更多探针换确定性），不得预支未来额度。

**定义 137（蒸馏洗白审计 DLA）** 教师盲区 `B_T(β)={x: conf_T(x)≥θ_high ∧ err_T(x)}`，`P(B_T)≤β`；洗白分

```
L = P( err_T ∧ err_S ∧ conf_S ≥ θ_high | B_T )
```

独立物理探针集 `A_probe` 上估计。若 `L > θ_L`、盲区覆盖率超过 `β`、或教师联盟分歧 `D_T(x)>θ_dis` 且学生仍高置信，则证书撤销/缩域。审计还包括：(a) 师生在 `A_probe` 上的错误相关性；(b) 压缩前后校准漂移；(c) 证书范围外的 OOD 检出。

**定义 138（竞赛证据证书 TEC）** `J_t = (J_m, TDP_plan, bankroll_ledger, transfer_certs, audit_log, score_ledger, risk_ledger, evidence_ledger, ruin_bound)`。检查项：每个承诺接触有证据类；`EV-distill` 有效且非不可逆接触的唯一证据；`p̄_S ≤ min(δ_f(g),δ_k)`；`Σδ_k ≤ δ_tour`；排行榜变化只重排不增发；审计未撤销证书；分数账本与规则一致；无未决分歧被当作同意。

## 2. 关键算法伪代码（完整版见产物区）

### IP-133 TDP（Tournament Decision Policy）

```python
def tournament_commit_evolve(x0, tasks, C, M, T, S, bankroll):
    plan = schedule_tasks(tasks, C, score_model)
    for k, task in enumerate(plan):
        delta_k = bankroll.allocate(k, score_gap, rounds_left, leaderboard)  # 只重排
        for cp in route(task):
            R_T = teacher_risk_upper(T, cp, M)            # 教师侧上界
            R_S = student_risk_upper(S, cp, cert, M)      # 含 eps_TD/eps_cal/eps_cov
            R   = merge_conservative(R_T, R_S)            # 只取上界，分歧抬高
            while not committable(R, delta_k) and budget.left > 0:
                p = argmax(admissible_probes(cp, M, F_abs),
                           key=lambda q: voi_tourn(q, M, R, score_gap, rounds_left))
                if voi_tourn(p, ...) < theta_voi: break
                M = map_fuse(M, execute_probe(p, cap=F_abs)); R = reestimate(...)
            g = select_gait(R, delta_k)                   # R ≤ min(delta_f(g), delta_k)
            if g != 'halt' and evidence_ok(cp, M, cert):
                commit_and_log(cp, g, M, cert, bankroll); continue
            return negotiate_or_stop(cp, M, R, C)         # 第 56 轮 ISE 兜底
    return plan, bankroll.ledger
```

### IP-134/135 SDB + CDE（学生风险上界与证据门）

```python
def student_risk_upper(S, cp, cert, M):
    if cert.revoked or not in_scope(cert, cp) or now > cert.expiry:
        return 1.0                                    # 失效即拒绝，不是"打一点折"
    if league_disagreement(cert, cp) > theta_dis:
        return 1.0                                    # 分歧 → 视为未知 → 探针
    return min(1.0, teacher_risk_upper(M, cp)
               + cert.eps_TD + cert.eps_cal + cert.eps_cov)

def ev_distill_ok(c, cert, corroborated):
    if c.risk_class == 'irreversible' and not corroborated: return False
    if c.ev != 'EV-distill': return True
    return in_scope(cert, c) and not cert.revoked and cert.audit_passed
```

### IP-136 ABM（风险银行家）

```python
def bankroll_allocate(B, k, score_gap, rounds_left, leaderboard):
    base = B / max(1, rounds_left)
    tilt = clip(kappa * score_gap, 0, tilt_max) * base
    delta = clip(base + tilt, delta_min, delta_max)
    return min(delta, B)                             # 永不透支总预算
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| TDP | O(\|CP\|·k_p·(C_VOI+\|E\|)+\|CP\|·A*) | O(\|V\|+\|σ\|) | 分数感知 VOI、银行家上限、四态完备 |
| SDB | O(1) 查表 + O(\|X_val\|) 离线证书 | O(\|X_val\|) | 上界单调、学生不比教师更冒险 |
| CDE | O(\|val\|) 作用域查询 | O(\|cert\|) | 非唯一证据、过期撤销、分歧归零 |
| ABM | O(K) 分配 | O(K) | `Σδ_k≤δ_tour`、排行榜只重排 |
| DLA | O(\|A_probe\|·H_T) | O(\|B_T\|) | 盲区覆盖、洗白分、独立探针 |
| TEC | O(\|σ\|+\|logs\|) | O(\|σ\|) | 证据/蒸馏/银行家/分数四账合一 |

**正确性定理（Tournament-Distilled Evidence Soundness, TDES）**：在 A22–A36 基础上加 **(A43)** 银行家记账健全且 `Σδ_k≤δ_tour`；(A44) 分数模型误差 `≤ε_score` 且规则可审计；**(A45)** 蒸馏证书覆盖 `≥1−α`、`ε_TD` 为真上界、学生校准 `ECE≤ε_cal^S`；**(A46)** 保守蒸馏 `p̄_S≥p̄_T`，分歧只触发探针/保守动作；**(A47)** 洗白审计对 `B_T` 的漏检 `≤β_L`；**(A48)** `EV-distill` 不为不可逆接触的唯一证据。则：

1. **承诺健全性**：学生承诺接触 `P(fail) ≤ δ_f + ε_TD + ε_cal^S + ε_cov + ε_T`；
2. **破产约束**：`P(∃不可逆失败) ≤ Σ_k δ_k ≤ δ_tour`；
3. **蒸馏单调性**：`EV-distill` 只可在证书范围内、且经独立佐证时抵扣探针；任何师生/联盟分歧只触发探针或更保守动作，不存在"蒸馏直接放宽证据门"的路径；
4. **竞赛单调性**：排行榜/分数压力只重排 `{δ_k}`，不改变 `Σδ_k`，故"追赶"不能突破破产约束；不追亏损由 `θ_chase` 硬门保证；
5. **终止性**：每检查点 `k_probes` 上限 + 有限轮次，终止于 {承诺, 绕行, 降档, 协商, 安全停}；
6. **部署界**：`P_safe ≥ 1 − Σ_k δ_k − P(证书失效未检出) − P(洗白审计漏检) − P(教师不可用且回退失败) − P(分数模型失准导致误分配)`。

## 6. 本轮最大风险

**一句话**：本轮最大风险是"蒸馏洗白"与"竞赛风险蠕变"同向叠加——学生在教师最自信的错误处最自信，排行榜又为"把风险预算重新解释成授权"提供了最动听的叙事；必须把 `EV-distill` 永远降级为先验、把总风险银行家设为不可增发，否则系统会在最想赢的时刻输掉不可逆的那一局。

## 2. 关键算法伪代码

### IP-133 TDP（Tournament Decision Policy）

```python
def score_aware_voi(pi, M, R, score_gap, rounds_left, C):
    # 信息价值 = 当前风险降幅 + 未来轮次期权价值 - 时间/分数机会成本
    risk_gain   = expected_risk_reduction(pi, M, R)
    option_val  = future_round_value(pi, M, rounds_left, C)   # 学到的东西还能用几次
    time_cost   = score_cost(pi.tau, C)                      # λ_t·τ
    probe_cost  = pi.energy_cost
    return risk_gain + option_val - time_cost - probe_cost

def evidence_ok(cp, M, cert):
    ev = evidence_classes(cp, M, cert)          # EV-probe/visit/margin/human/distill
    if not ev: return False
    if cp.risk_class == 'irreversible':
        # A48: 不可逆接触不得以 EV-distill 为唯一证据
        return any(e != 'EV-distill' for e in ev) and distill_ok_if_used(ev, cert, cp)
    return True

def tournament_commit_evolve(x0, tasks, C, M, teachers, student, bankroll):
    plan = schedule_tasks(tasks, C, score_model)          # 分数/时间/风险感知排序
    sched, log = [], []
    for k, task in enumerate(plan):
        score_gap = leaderboard_gap(C, k)
        delta_k = bankroll.allocate(k, score_gap,
                                    rounds_left=C.K - k,
                                    leaderboard=C.ell)     # A43: 只重排，不增发
        for cp in route_on_map(task, M):
            R_T = teacher_risk_upper(teachers, cp, M)      # 教师联盟上界
            R_S = student_risk_upper(student, cp, cert, M) # 含 eps_TD/eps_cal/eps_cov
            R   = merge_conservative(R_T, R_S)             # 只取上界；分歧抬高 R
            while not committable(R, delta_k) and bankroll.probes_left > 0:
                cands = admissible_probes(cp, M, F_abs)    # 第 56 轮非破坏性过滤
                if not cands: break
                p = argmax(cands, key=lambda q: score_aware_voi(
                           q, M, R, score_gap, C.K - k, C))
                if score_aware_voi(p, M, R, score_gap, C.K - k, C) < theta_voi:
                    break
                M, _ = map_fuse(M, [execute_probe(p, cap=F_abs)])
                R = merge_conservative(teacher_risk_upper(teachers, cp, M),
                                       student_risk_upper(student, cp, cert, M))
                bankroll.spend_probe(p)
            g = select_gait_tournament(R, delta_k)
            if g != 'halt' and evidence_ok(cp, M, cert):
                sched.append(commit(cp, g))
                log.append(tag_evidence(cp, M, cert))
                bankroll.charge(delta_k)                   # 风险额度入账
                continue
            alt = reroute(M, cp, risk_model)
            if alt and select_gait_tournament(schedule_risk(alt, M), delta_k) != 'halt':
                task = alt; continue
            return negotiate_or_stop(cp, M, R, C)          # 第 56 轮 ISE / L2 兜底
    return sched, log, bankroll.ledger
```

### IP-134 SDB（Safety Distillation Bound）

```python
def certified_student_risk(student, teachers, cp, cert, M):
    if cert.revoked or cert.expired(now):
        return 1.0                                    # 失效即拒绝，不是"打一点折"
    if not in_scope(cert, cp):
        return 1.0                                    # 范围外 == 无证书
    if league_disagreement(teachers, cp) > theta_dis:
        return 1.0                                    # 教师都不确定 → 学生更不确定
    pT = teacher_risk_upper(teachers, cp, M)          # 教师校准上界
    return min(1.0, pT + cert.eps_TD + cert.eps_cal + cert.eps_cov)

def select_gait_tournament(R, delta_k):
    for g in ['trot', 'pace', 'crawl']:               # 由快到慢
        if R <= min(delta_f_of_gait(g), delta_k):     # A43: 双重预算
            return g
    return 'halt'

def merge_conservative(R_T, R_S):
    return max(R_T, R_S)                              # A46: 只取更保守者
```

### IP-135 CDE（Certified Distillation Evidence）

```python
def distill_evidence(cp, cert, teachers, student):
    if not in_scope(cert, cp) or cert.expired(now) or cert.revoked:
        return None                                   # 不产生证据
    if league_disagreement(teachers, cp) > theta_dis:
        return None                                   # 分歧 → 触发探针
    return Evidence(type='EV-distill', weight=w_d(cp, cert), cert=cert)

def distill_ok_if_used(ev_classes, cert, cp):
    if 'EV-distill' not in ev_classes: return True
    return cert.audit_passed and in_scope(cert, cp) and not cert.revoked

def corroborate(cp, M, cert):
    # 独立观察（探针/到访/裕度/经校准标注）为蒸馏先验作证
    return any(e in {'EV-probe', 'EV-visit', 'EV-margin', 'EV-human'}
               for e in evidence_classes(cp, M, cert))
```

### IP-136 ABM（Adaptive Bankroll Manager）

```python
def allocate(B, k, score_gap, rounds_left, leaderboard, theta_chase):
    base = B / max(1, rounds_left)
    if score_gap > theta_chase:                        # 落后：可以调整结构，不可追亏损
        tilt = tilt_max * base                         # 用同级更快方案/更多探针，而非透支
    else:
        tilt = clip(kappa * score_gap, 0, tilt_max) * base
    delta = clip(base + tilt, delta_min, delta_max)
    return min(delta, B)                               # A43: 永不透支 B_k

def charge(self, delta_k):
    self.B -= delta_k
    assert self.B >= -1e-12                            # 总预算不增发
```

### IP-137 DLA（Distillation Laundering Auditor）

```python
def audit_distillation(teachers, student, A_probe, cert):
    # (a) 教师盲区：高置信且错
    blind = [x for x in A_probe
             if teacher_conf(teachers, x) >= theta_high and teacher_error(teachers, x)]
    if len(blind) < n_min:
        cert.shrink_scope()                            # 审计样本不足 → 缩域
    # (b) 洗白分：盲区内师生同错且学生仍高置信
    L = fraction([x for x in blind
                  if student_error(student, x) and student_conf(student, x) >= theta_high])
    if L > theta_L:
        cert.revoke(reason='laundering')
    # (c) 教师联盟分歧：只在一致处蒸馏
    if max(league_disagreement(teachers, x) for x in A_probe) > theta_dis:
        cert.shrink_scope(reason='teacher_disagreement')
    # (d) 压缩前后校准漂移 & OOD
    if calibration_drift(student, cert) > theta_drift: cert.require_recert()
    if ood_rate(student, cert.scope) > theta_ood:      cert.shrink_scope(reason='ood')
    return cert
```

### IP-138 TEC（Tournament Evidence Certificate）

```python
def tournament_evidence_certificate(plan, sched, M, certs, bankroll,
                                    score_ledger, consent_log, budgets):
    # 1. 证据门（继承第 56 轮 MEC + 新增 EV-distill 规则）
    for c in contacts(sched):
        ev = c.evidence
        if not ev: return ('reject', 'no_evidence_class', c)
        if c.risk_class == 'irreversible' and ev == {'EV-distill'}:
            return ('reject', 'distill_sole_evidence_on_irreversible', c)
        if 'EV-distill' in ev:
            cert = certs[c.cert_id]
            if not (cert.audit_passed and in_scope(cert, c) and not cert.revoked):
                return ('reject', 'distill_cert_invalid', c)
        # 2. 学生风险上界与双重预算
        if c.p_bar_S > min(delta_f_of_gait(c.g), bankroll.delta_of(c.round)):
            return ('reject', 'student_risk_bound_exceeded', c)
        # 3. 非破坏性 / 校准（第 56 轮继承）
        if not c.evidence.nondestructive: return ('reject', 'probe_destructive', c)
    # 4. 银行家：总预算不增发；排行榜只重排
    if bankroll.total_allocated > budgets.delta_tour + 1e-9:
        return ('reject', 'bankroll_inflated')
    if not bankroll.monotone_under_leaderboard(budgets.leaderboard_trace):
        return ('reject', 'leaderboard_inflated_risk')
    # 5. 洗白审计未撤销、证书未过期
    if any(cert.revoked or cert.expired(now) for cert in certs.values()):
        return ('reject', 'distill_cert_revoked_or_expired')
    # 6. 分数账本与规则一致
    if not score_ledger.consistent_with(budgets.rules):
        return ('reject', 'score_ledger_mismatch')
    # 7. 第 56 轮继承检查
    if min(x.K_margin for x in sched) < budgets.theta_K: return ('reject', 'K_margin')
    if rho_sem(sched, M) < budgets.rho_min:              return ('reject', 'rho_sem')
    if not all(l2.resolved for l2 in consent_log):       return ('reject', 'consent_open')
    return ('ok', TECert(plan, sched, bankroll.ledger, certs,
                         score_ledger, evidence_ledger(sched)))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| TDP | O(\|CP\|·k_p·(C_VOI+\|E\|)+\|CP\|·A*) | O(\|V\|+\|σ\|) | 分数感知 VOI、双重预算、四态完备（A43） |
| SDB | O(1) 查表 + O(\|X_val\|) 离线 | O(\|X_val\|) | 上界单调、保守蒸馏（A45/A46） |
| CDE | O(\|val\|) 查询 | O(\|cert\|) | 非唯一证据、过期撤销、分歧归零（A48） |
| ABM | O(K) 分配 + O(1) 记账 | O(K) | `Σδ_k≤δ_tour`、排行榜只重排（A43） |
| DLA | O(\|A_probe\|·H_T) | O(\|B_T\|) | 盲区覆盖、洗白分、独立探针（A47） |
| TEC | O(\|σ\|+\|logs\|) | O(\|σ\|) | 四账合一、四态完备 |

**正确性定理（Tournament-Distilled Evidence Soundness, TDES）**
假设 A22–A28（第 53/54 轮）、A29–A32（第 55 轮）、A33–A36（第 56 轮）成立；新增：
**(A43)** 银行家记账健全、`Σ_k δ_k ≤ δ_tour`，排行榜变化只重排不增发；
**(A44)** 分数模型误差 `≤ε_score` 且规则可审计；
**(A45)** 蒸馏证书覆盖 `≥1−α`、`ε_TD` 为真上界、学生 `ECE≤ε_cal^S`；
**(A46)** 保守蒸馏 `p̄_S≥p̄_T`，师生/联盟分歧只触发探针或保守动作；
**(A47)** 洗白审计对教师盲区 `B_T` 的漏检 `≤β_L`；
**(A48)** `EV-distill` 不为不可逆/高风险接触的唯一证据。则：

1. **承诺健全性**：学生承诺接触 `P(fail) ≤ δ_f + ε_TD + ε_cal^S + ε_cov + ε_T`；
2. **破产约束**：`P(∃不可逆失败) ≤ Σ_k δ_k ≤ δ_tour`（联合界）；
3. **蒸馏单调性**：`EV-distill` 只可在证书范围内、且经独立佐证时抵扣探针；分歧只触发探针或更保守动作，不存在"蒸馏直接放宽证据门"的路径；
4. **竞赛单调性**：排行榜/分数压力只重排 `{δ_k}`，不改变 `Σδ_k`；`θ_chase` 硬门禁止追亏损，故追赶不能突破破产约束；
5. **终止性**：每检查点 `k_probes` 上限 + 有限轮次，终止于 {承诺, 绕行, 降档, 协商, 安全停}；
6. **部署界**：

```
P_safe ≥ 1 − Σ_k δ_k
             − P(蒸馏证书失效/过期未检出)
             − P(教师盲区审计漏检)
             − P(教师不可用 ∧ 学生回退失败)
             − P(分数模型失准导致风险预算误分配)
```

关键：**蒸馏把"能力"从教师搬到学生，但不把"观察"搬过去**——学生置信只是有作用域、会过期、需佐证先验；**竞赛把"风险"在轮次间搬来搬去，但不把"总预算"变大**——排行榜可以改变战术，不能改变破产约束；**审计把"内部洗白"变成证书拒绝**——教师盲区、师生同错、联盟分歧都被显式记账。

## 6. 本轮最大风险

**一句话**：本轮最大风险是"蒸馏洗白"与"竞赛风险蠕变"同向叠加——学生在教师最自信的错误处最自信，排行榜又为"把风险预算重新解释成授权"提供了最动听的叙事；必须以 **EV-distill 永远降级为先验、总风险银行家不可增发、不可逆接触必须现场佐证** 三重硬门守住，否则系统会在最想赢的时刻输掉不可逆的那一局。
