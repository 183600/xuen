# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「强化学习」×「数据标注」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**统计标定 + 屏蔽策略**。两个灵感分别治理 v9 的两笔暗债：**标定债**（块证书的 β 是 E554 标定的经验上界 ×1.2 工程系数，不是有限样本覆盖率保证；"信任域内误差 ≤ β"只是一个假设，而 DA-ML 恰恰在假设失效时可能给出低 Δ_dom）与**探索债**（v9 冻结前向模型 + MPC 采样，日志中的真实失败/近失事件从未被用于改进策略；但直接在线 RL 又会把安全关键系统变成探索试验场）。
> 本轮核心判断：**标注是证书的证据源，RL 是安全集内的策略搜索器；两者都不能被允许"自己证明自己"**。所有新组件仍经中立元严格退化回 v9（引理 91），且必须区分"行为等价"与"统计保证等价"。

## 0. 直觉与动机

**灵感 1（数据标注 → 共形证书：把 β 从工程系数变成可审计的统计契约）**
直觉：v9 说"信任域内前向模型误差 ≤ β"，但 β 从哪来？E554 用经验误差上界乘 1.2。这在统计上是一个没有覆盖率语义的点估计：换一个域、换一批场景、换一个标注者，β 就可能失效，而系统仍然"按证书"执行。数据标注的本体不是"更多数据"，而是**证书的证词**。核心创新：**标注台账（AnnotationLedger, AL）** + **共形证书校准器（ConformalCertificateCalibrator, C3）**。把每个块的真实指标作为一条带来源、标注者、质量分与域标签的标注原子；用块级非一致性分数在标注集上取共形分位数，得到有限样本、分布无关的边际覆盖率；用 DA-ML 估计的密度比做**加权共形**，把协变量偏移显式计入 β；用标注一致性给出**单侧噪声膨胀** η⁺，保证标注噪声只会让证书更保守、不会更乐观。β 从此是一个四元契约 (β, α_eff, n_eff, ϵ_w)，而不是一个拍出来的数。

**灵感 2（强化学习 → 屏蔽式分块策略：策略提议、证书否决）**
直觉：v9 的块生成是"采样 64 条候选 + 手写评分"，日志里的大量近失、绕行、失败恢复从未被学习。RL 本可以在这里显著提升任务效率与块长自适应；但直接在线 RL 在安全关键机器人上有两个不可接受的风险：探索会制造真实碰撞；奖励设计会诱导"刷安全指标"的策略。核心创新：**屏蔽式分块策略（ShieldedChunkPolicy, SCP）**：离线/保守 RL 只在历史标注日志上训练，输出候选块与 K_eff 偏好；**屏蔽算子**把候选投影到共形证书认证的安全集 S_t（证书有效 ∧ 前向模型支持域内 ∧ 中止点非空 ∧ K_eff 约束），RL 只能在安全集内排序，不能扩大动作集。于是安全性不再依赖 RL 策略是否正确，而只依赖证书的统计健全性与守卫实现；RL 再差也只损失任务效用，不损失安全。这把"约束 MDP"化成了"安全集上的普通 MDP"，避免奖励黑客。

**灵感 3（两者的耦合 → 主动标注：把标注预算花在证书最薄的地方）**
直觉：标注是稀缺资源。均匀标注会把预算浪费在证书已经很准的常见场景，而真正决定 β 的是尾部：高残差、高集成 disagreement、陌生域、近失事件、以及"策略正在主动回避"的分层。核心创新：**主动标注调度器（ActiveAnnotationScheduler, AAS）**：以证书残差、模型不确定性、域新颖度与分层覆盖缺口为获取函数，在标注预算与每层最小样本约束下做分层贪心/上下文 bandit；**盲见证集 + 自确认审计器（SCA）** 则用一批永不参与训练/校准/选择的标注样本，独立检验覆盖率下界，发现"策略自己选数据、又用这些数据证明自己安全"的自确认回路，必要时冻结 RL、提高 β、收缩 K_eff。

## 1. 研究问题（轮次升级版）

- **Q1（共形证书的有限样本健全性）**：在块级可交换性、密度比有界、标注噪声单侧有界的假设下，加权共形分位数能否给出可审计的覆盖率下界？DA-ML 的密度比估计误差如何进入该下界？分层共形能否把"边际覆盖"升级为"最差分层覆盖"？
- **Q2（屏蔽 RL 的安全解耦）**：当 RL 策略任意（包括对抗性错误）时，屏蔽算子能否保证执行动作始终落在认证安全集内，使碰撞概率只由证书失败率与守卫失败率决定，而与策略次优性无关？离线训练 + 无在线探索是否足以获得可用的任务收益？
- **Q3（标注不自证）**：当标注选择策略与证书评估共享同一批结果时，如何用盲见证集、分层配额与选择独立性约束防止覆盖率被"刷"出来？主动标注在什么条件下能收紧 β 而不破坏覆盖率语义？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 共形标定律（Conformal Calibration, CC）**
块证书的误差余量 β 必须来自标注集上的共形分位数，而非工程系数：β_t = WeightedQuantile_{1−α}({r_i + η⁺}, {w_i})，其中 r_i 为块级非一致性分数，w_i 为 DA-ML 估计的测试/校准密度比，η⁺ 为标注噪声单侧上界。证书必须携带 (β_t, α_eff, n_eff, ϵ_w) 四元契约；分层场景用 Bonferroni 分配 α_s = α/S，报告最差分层覆盖率而非仅边际覆盖率。

**P14 屏蔽策略律（Shielded Policy, SP）**
RL 只能提议，不能放行：执行块 ζ_exec 必须属于认证安全集 S_t = {ζ: Ĉ_t(β_t) valid ∧ support(ζ) ≤ τ_sup ∧ P_t ≠ ∅ ∧ K_eff 约束}；若 S_t ∩ 候选 = ∅，退回 v9 MPC 或安全停驻。RL 离线训练、禁止在线探索；奖励只塑造安全集内的偏好，安全约束由集合本身硬编码，故安全性与策略质量解耦。

**P15 标注不自证律（No Self-Confirmation, NSC）**
标注选择、证书校准、覆盖率审计三者必须使用互不重叠的数据角色：训练集 / 校准集 / 盲见证集。盲见证集一旦封存，永不参与选择或调参，只用于覆盖率审计；每层至少 b_min 个标注配额，禁止"只标容易的样本"；审计发现覆盖率下界跌破 1−α−δ 时，立即冻结 RL、提高 β、收缩 K_eff，并在失败分层追加标注。

## 3. 与基线的接口（如何退化）

- C3/AL 失效 ⇒ β 退回 v9 固定标定值（E554 经验上界 ×1.2），证书语义退回 v9，**行为等价、统计保证不等价**；
- SCP 失效或屏蔽不可用 ⇒ 块生成退回 v9 MPC 采样 + 手写评分，等价 v9；
- AAS 失效 ⇒ 均匀/随机标注，仍保留分层配额与盲见证集，覆盖率语义不变但 β 收紧更慢；
- SCA 失效 ⇒ 采用保守固定 α_min 与 K_eff 上限（保守子集），不声称覆盖率；
- 盲见证集污染或不可用 ⇒ 禁止 RL 上线，退回 v9 全链路；
- 其余层级沿 v9：AC 失效⇒K=1（v8）；MW 失效⇒手写网关（v8）；ID 失效⇒全激活（v8）；DA/SPR/Cal 失效⇒v7；全失效⇒v7→v6。

## 4. 预期贡献

1. **标注锚定的共形证书**：把 v9 的工程 β 升级为有限样本、分布无关、可审计的覆盖率契约；加权共形显式处理 DA-ML 域偏移，标注噪声只增保守性；
2. **屏蔽式 RL**：策略提议、证书否决，安全性不依赖 RL 正确性；离线训练 + 无在线探索，把约束 MDP 化为安全集上的普通 MDP；
3. **安全导向的主动标注**：以证书残差与分层覆盖缺口为获取函数，把标注预算花在尾部；盲见证集与自确认审计堵住"数据自证"回路；
4. **E571–E590** 覆盖共形覆盖率、偏移/噪声鲁棒性、屏蔽安全、离线 RL 收益、主动标注、审计功效、分层覆盖、长跑漂移与端到端任务。

## 5. 本轮最大风险

**一句话**：策略自己选择要标注的数据，又用这些数据校准并证明自己安全的证书；一旦 SCP 的部署分布与标注池的采样分布共同漂移，共形覆盖率所依赖的可交换性就被策略自己破坏，而盲见证集只能审计它已经覆盖的分层，无法看见策略刻意回避的尾部——系统会在"数据支持的安全"与"真实安全"之间留下系统性缺口。

## 1. 符号体系增量（定义 540–549）

| 符号 | 含义 |

**新增定义 540（标注原子与台账 Annotation Atom & Ledger）** 一条标注原子 a=(x, ζ, y, m, ρ, d, t, h)，其中 x 为块起始状态，ζ 为动作块，y 为真实块内指标（clearance/effort/grasp 等），m 为标注来源（人工/仿真/自动），ρ∈[0,1] 为标注质量分（多标注者一致性或自动标注置信度），d 为域/分层标签，t 为时刻，h 为来源哈希。台账 L 追加写入、不可原地修改；按角色划分为 L_train / L_cal / W，三者互不重叠。

**新增定义 541（标注质量与单侧噪声界 Annotation Quality）** 对分层 s，用 Krippendorff's α 或成对一致率 ρ_s 估计标注质量；令 ε_i=y_i−y_i^* 为标注误差，定义单侧高估界 η_s⁺ = sup_{i∈s, ρ_i≥ρ_min} ε_i（对 clearance 类指标）。若 ρ_s < ρ_min，该层标注只进入 L_train，不进入 L_cal 与 W。η⁺ 的保守估计取 η_s⁺ 的 (1−δ_ann) 分位数。

**新增定义 542（块级非一致性分数 Block Nonconformity）** 对块 ζ，前向模型预测最坏界为 ĝ_min=F̂_min(ζ)，真实最坏界为 g_min。定义
```
r(ζ) = max(0, ĝ_min − g_min) + λ_e·max(0, ê_max − e_true,max)
```
即"模型把安全性说得比真实更好"的单侧正误差；effort 项同理。r 越小，证书越紧；r=0 表示证书在该块上保守有效。

**新增定义 543（加权共形分位数 Weighted Conformal Quantile）** 给定校准分数 {r_i+η⁺} 与权重 {w_i=w(x_i)}，以及测试权重 w_test=w(x_test)，定义
```
β_t = inf{ b : Σ_{i: r_i+η⁺ ≤ b} w_i / (Σ_i w_i + w_test) ≥ 1−α }
```
并做有限样本修正：若使用未加权共形，取第 ⌈(n+1)(1−α)⌉ 个次序统计量；加权情形按归一化权重累加。α_eff = α + ϵ_w，其中 ϵ_w 为密度比估计误差（总变差或加权分位数的扰动界）。

**新增定义 544（共形证书契约 Conformal Certificate Contract）** 块证书的误差字段升级为四元契约 C_α=(β_t, α_eff, n_eff, ϵ_w)，其中 n_eff=(Σw_i)²/Σw_i² 为加权有效样本量。证书有效 ⇔ ĝ_min−β_t ≥ d_safe ∧ ê_max+β_t ≤ τ_eff ∧ γ̂_grasp valid ∧ 支持域检查通过。分层场景对每层 s 取 α_s=α/S，报告最差分覆盖 min_s coverage_s，而非仅边际覆盖。

**新增定义 545（认证安全集与屏蔽算子 Certified Safe Set & Shield）**
```
S_t = { ζ : C_α(ζ) valid ∧ w(x_ζ) ≤ w_max ∧ P_t(ζ) ≠ ∅ ∧ K_eff(ζ) ≤ K_max }
Π_shield(ζ) = ζ 若 ζ∈S_t；否则 ⊥（拒绝）
```
支持域检查 w(x_ζ) ≤ w_max 防止 RL 把候选推到前向模型训练分布之外；⊥ 表示拒绝，不是中立元；候选全被拒绝时执行 v9 MPC 或安全停驻。

**新增定义 546（离线屏蔽策略 Offline Shielded Chunk Policy）** π_θ 在 L_train 上离线训练（IQL/CQL 等保守离线 RL），输入状态与 K_eff，输出候选块分布；执行时
```
ζ_exec = argmax_{ζ∈S_t ∩ supp(π_θ)} π_θ(ζ)
```
若交集为空，ζ_exec ← v9 MPC。训练目标为任务进展奖励，安全约束由 S_t 硬编码，故不进入奖励项。禁止在线探索；策略更新只在离线批次上进行。

**新增定义 547（主动标注获取函数 Acquisition Function）**
```
A(a) = w_r·r̂(a) + w_u·u(a) + w_n·novelty(a) + w_c·coverage_gap(stratum(a))
```
其中 r̂ 为预测残差（用集成模型或最近邻），u 为集成 disagreement，novelty 为域新颖度（DA-ML 密度比或嵌入距离），coverage_gap 为该分层当前覆盖下界与目标的缺口。权重 w 由有限预算的上下文 bandit 调整；每层至少选 b_min 条，W 永不入选。

**新增定义 548（分层标注预算 Stratified Annotation Budget）** 预算 B 条/单位时间，分层 s=1..S；分配 b_s 满足 Σ b_s ≤ B、b_s ≥ b_min，且优先满足 coverage_gap 最大的层。若需同时估计 S 个分层的覆盖率，误差 ε、置信度 1−δ 下每层至少 n_s ≥ ln(2S/δ)/(2ε²) 条（引理 92）。

**新增定义 549（盲见证集与自确认审计 Blind Witness & Self-Confirmation Audit）** W 为封存标注集，只用于审计；审计统计量为 W 上的经验覆盖率 ĉ，Wilson 下界 LCB(ĉ, |W|, δ)。若 LCB < 1−α−δ_cov，则判定覆盖率失败：冻结 π_θ、将 β_t 乘以保守因子 κ_β>1、K_eff ← min(K_eff, K_audit)，并把失败分层加入下一轮标注配额。W 的刷新必须由预注册规则触发，且刷新后旧 W 永久退役。

# IP-358 ConformalCertificateCalibrator：共形证书校准器
class ConformalCertificateCalibrator:
    def __init__(self, ledger, forward_model, alpha=0.01,
                 eta_plus=0.0, eps_w=0.0, w_max=10.0, lambda_e=0.5):
        self.L, self.F = ledger, forward_model
        self.alpha, self.eta_plus, self.eps_w = alpha, eta_plus, eps_w
        self.w_max, self.lambda_e = w_max, lambda_e

    def score(self, a):
        pred = self.F.predict(a.x, a.chunk)            # v9 冻结前向模型
        r_c = max(0.0, pred.min_clearance - a.y.min_clearance)
        r_e = max(0.0, a.y.max_effort - pred.max_effort)
        return r_c + self.lambda_e * r_e               # 定义 542

    def weighted_quantile(self, scores, weights, q, w_test=1.0):
        order = sorted(range(len(scores)), key=lambda i: scores[i])
        total = sum(weights) + w_test
        cum = 0.0
        for i in order:
            cum += weights[i]
            if cum / total >= q:                       # 定义 543
                return scores[i]
        return max(scores)                             # 保守兜底

    def calibrate(self, stratum=None, w_fn=None, alpha=None):
        a = alpha or self.alpha
        cal = [x for x in self.L.cal
               if stratum is None or x.domain == stratum]
        scores = [self.score(x) + self.eta_plus for x in cal]
        weights = [1.0 if w_fn is None
                   else min(self.w_max, w_fn(x.x)) for x in cal]
        w_test = 1.0 if w_fn is None else min(self.w_max, w_fn(self.last_x))
        beta = self.weighted_quantile(scores, weights, 1.0 - a, w_test)
        n_eff = (sum(weights) ** 2) / sum(w * w for w in weights) \
                if weights else 0.0
        return CertificateContract(beta=beta, alpha_eff=a + self.eps_w,
                                   n_eff=n_eff, eps_w=self.eps_w)

    def calibrate_stratified(self, strata, w_fn=None):
        S = len(strata)
        return {s: self.calibrate(s, w_fn, alpha=self.alpha / S)
                for s in strata}                       # 引理 87：最差分覆盖


# IP-359 ShieldedChunkPolicy：屏蔽式分块策略
class ShieldedChunkPolicy:
    def __init__(self, policy_net, fallback_mpc, calibrator, w_max=10.0):
        self.pi, self.fallback = policy_net, fallback_mpc
        self.cal, self.w_max = calibrator, w_max

    def certified(self, state, chunk, contract):
        pred = self.cal.F.rollout(state, chunk.actions)
        if pred.min_clearance - contract.beta < state.d_safe:
            return False
        if pred.max_effort + contract.beta > state.tau_eff:
            return False
        if not chunk.abort_points:                     # 定义 534
            return False
        if self.cal.w_fn(state.x) > self.w_max:        # 支持域外
            return False
        return True                                    # 定义 545

    def act(self, state, contract, k_max):
        cands = self.pi.sample(state, k_max, n=64)     # 离线策略提议
        safe = [c for c in cands
                if self.certified(state, c, contract)]
        if not safe:
            return self.fallback(state)                # 等价 v9 MPC / 安全停驻
        return max(safe, key=self.pi.score)            # 屏蔽内排序


# IP-360 ActiveAnnotationScheduler：主动标注调度器
class ActiveAnnotationScheduler:
    def __init__(self, ledger, budget=20, b_min=2, strata=None):
        self.L, self.B, self.b_min = ledger, budget, b_min
        self.strata = strata or []
        self.bandit = ContextualBandit(n_arms=4)
        self.w_r, self.w_u, self.w_n, self.w_c = 1.0, 0.8, 0.6, 1.2

    def acquisition(self, a, contract):
        return (self.w_r * self.residual(a)
                + self.w_u * self.uncertainty(a.x, a.chunk)
                + self.w_n * self.novelty(a.x)
                + self.w_c * self.coverage_gap(a.domain, contract))

    def select(self, pool, contract):
        chosen, per = [], defaultdict(int)
        for s in self.strata:                          # 分层保底
            cand = [a for a in pool if a.domain == s
                    and a not in self.L.witness]
            for a in sorted(cand,
                            key=lambda z: -self.acquisition(z, contract)
                            )[:self.b_min]:
                chosen.append(a); per[s] += 1
        rest = [a for a in pool
                if a not in chosen and a not in self.L.witness]
        while len(chosen) < self.B and rest:           # 预算内贪心
            a = max(rest, key=lambda z: self.acquisition(z, contract))
            chosen.append(a); rest.remove(a)
        self.bandit.update(reward=self.beta_reduction(chosen))
        return chosen


# IP-361 SelfConfirmationAuditor：自确认审计器
class SelfConfirmationAuditor:
    def __init__(self, ledger, alpha, delta=0.01,
                 delta_cov=0.01, kappa_beta=1.5):
        self.L, self.alpha, self.delta = ledger, alpha, delta
        self.delta_cov, self.kappa_beta = delta_cov, kappa_beta

    def audit(self, contract, calibrator, policy):
        W = self.L.witness()
        if len(W) < self.n_min:
            return 'insufficient'                      # 不声称覆盖率
        cov = empirical_coverage(W, contract, calibrator.F)
        lcb = wilson_lower(cov, len(W), self.delta)
        if lcb < 1.0 - self.alpha - self.delta_cov:
            policy.freeze()                            # 冻结 RL
            contract.beta *= self.kappa_beta           # 保守回退
            contract.k_eff_cap = min(contract.k_eff_cap, self.k_audit)
            self.request_annotations(failing_strata(W, contract))
            return 'fail'
        return 'pass'

## 4. 推导

**引理 87（加权共形覆盖率）** 设同一分层内校准块与测试块分别来自 P_cal 与 P_test，密度比 w(x)=dP_test/dP_cal 有界且估计误差为 ϵ_w；块级分数在层内可交换。则按定义 543 取 β_t 后
```
P( r_test + η⁺ ≤ β_t ) ≥ 1 − α − ϵ_w
```
从而 `P(g_true,min ≥ ĝ_min − β_t) ≥ 1 − α − ϵ_w`。证明：加权共形分位数把测试权重 w_test 计入总权重，满足加权可交换性下的分位数覆盖引理；由 r 的单侧定义，r+η⁺ ≤ β_t 蕴含 ĝ_min−β_t ≤ g_min。权重扰动 ϵ_w 对加权经验分布的总变差扰动至多 ϵ_w，故覆盖率最多损失 ϵ_w。分层取 α_s=α/S 后由并集界得最差分覆盖 ≥ 1−α−ϵ_w。∎

**引理 88（标注噪声保守性）** 设标注满足 y=y^*+ε 且对 clearance 类指标 ε ≤ η⁺（标注只会高估间隙）。则 r^*(ζ)=ĝ−g^* = r(ζ)+ε ≤ r(ζ)+η⁺。用膨胀后的分数 {r_i+η⁺} 校准得到的 β^η 满足 `P(r^*_test ≤ β^η) ≥ 1−α−ϵ_w`；若测试真值精确，则覆盖率只会更高。证明：分位数对分数逐点增大是单调的；把 η⁺ 同时加入校准分数即可把最坏高估吸收进余量。若标注误差为双侧，则需分别估计 η⁺ 与 η⁻，且证书只对 η⁺ 方向作保守膨胀。∎

**引理 89（屏蔽安全解耦）** 设屏蔽算子是全函数（每个执行块要么属于 S_t，要么走 v9 fallback/安全停驻），无旁路，且 v9 中块守卫正确。则对任意策略 π_θ（包括对抗性错误）
```
P(块内碰撞) ≤ P(证书不健全) + P(守卫失效)
```
特别地，若证书覆盖率为 1−α_eff 且守卫失效率可忽略，则碰撞概率 ≤ α_eff + o(1)，与 π_θ 的次优性无关。证明：执行块 ζ∈S_t 时，若证书健全则块内指标满足安全界；唯一可能碰撞的情形是证书不健全（r_test 超过 β_t）或守卫失效。若 ζ∉S_t，系统执行 v9 fallback/安全停驻，其安全性由 v9 引理 80–82 传递。RL 只改变 S_t 内选哪个 ζ，不改变 S_t 本身。∎

**引理 90（自确认回路不可能性）** 存在一种数据选择策略，使得对任意 α，所选校准集上的经验覆盖率为 1，而部署分布上的真实覆盖率为 0。构造：把状态空间分为 E（证书总正确）与 H（证书总失败）。若选择器只标注 E（例如只选低残差样本），则 L_cal 上 r_i=0，β=0，经验覆盖率 1；但 H 上覆盖率 0。故没有盲见证集或结果独立的选择机制时，共形保证不能自动迁移到部署分布。∎

**引理 91（v10→v9 退化等价）** (i) 关闭 C3 ⇒ β 取 v9 固定值，证书与 v9 逐位一致；(ii) 关闭 SCP ⇒ 块生成退回 v9 MPC 采样与评分，候选分布与选择规则一致；(iii) 关闭 AAS ⇒ 均匀/随机标注，但保留分层配额与盲见证集，覆盖率语义不变，仅 β 收紧速度下降；(iv) 关闭 SCA ⇒ 采用 α_min 与 K_eff 上限的保守子集，行为是 v10 的子集且不声称覆盖率；(v) 全部关闭 ⇒ 完整 v9。证明：每个模块关闭后要么返回 v9 对应值，要么把动作集限制为保守子集；v9 的 MW/AC/ID/DA/SPR/Cal 路径不变，故可观测行为等价或保守子集。∎

**引理 92（盲见证审计样本复杂度）** 若真实覆盖率比目标低 ε，即 coverage ≤ 1−α−ε，用 W 上的经验覆盖率与 Wilson 下界在置信度 1−δ 下检测该缺口，最坏情形需 |W| ≥ ln(2/δ)/(2ε²)；分层 S 层时每层需 |W_s| ≥ ln(2S/δ)/(2ε²)。证明：Hoeffding 不等式给出单层尾界，并对 S 层取并集界。注：该样本量是审计功效要求，不是共形覆盖本身的要求；共形覆盖对任意 n 成立，n 只影响 β 的紧致度。∎

## 8. 本轮最大风险

**一句话**：策略自己选择要标注的数据，又用这些数据校准并证明自己安全的证书；一旦 SCP 的部署分布与标注池的采样分布共同漂移，共形覆盖率所依赖的可交换性就被策略自己破坏，而盲见证集只能审计它已经覆盖的分层，无法看见策略刻意回避的尾部——系统会在"数据支持的安全"与"真实安全"之间留下系统性缺口。
