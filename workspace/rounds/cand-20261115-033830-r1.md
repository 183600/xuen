# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「多传感器融合」×「技能学习」）

> R69 的 FLUID-RAS 教会系统「问」：把不确定性拆成 aleatoric 与 epistemic，用流匹配生成多模态动作，用注视/探针/问句去主动消歧。但它有一个从未被触碰的前提：**技能库是固定的，融合是全局的、被动的**。它只能问「我已知的几种做法里，哪一种对」，不能问「**我根本不会，能不能学一个**」；它的多传感器融合只是把各模态残差拼进一个全局标定层，而不是「这项手艺到底该信哪几种感官」。
>
> 本轮两个灵感正好补上这两块：
> - **多传感器融合**不是把所有模态平均，而是**按技能组织证据**：外科医生信触觉+视觉，品酒师信嗅觉，舞者信本体感觉；融合图（用哪些模态、如何对齐、如何互相校验）本身就是技能的一部分，而不是一个全局共享的预处理层。
> - **技能学习**不是拟合一段策略，而是获得一份**传感器运动契约**：知道该看什么、该怎么融合、在什么条件下有效、做错了长什么样。学会的可证伪标志不是训练损失，而是**跨模态不变性 + 能力域覆盖 + 来源可审计**。
>
> 核心命题：**把「技能」提升为一等公民——技能 = (策略, 技能条件融合图, 能力域, 失效签名, 证据账本, 版本)；融合按技能索引；技能学习是预算受限、影子执行、证书释放的「最后一种信息动作」；只有通过跨模态不变性、能力域覆盖与来源纪律的技能，才能进入实时库。** 命名 **ARTISAN-RAS**（Attested, Reliability-Tested, Invariance-Supervised Acquisition of New skills for Risk-Aware Systems）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我不会的能不能学会；学来的，凭什么信**」。

## 0. 直觉与动机

**灵感 1（多传感器融合 → 融合不是平均，而是按技能组织证据）**
直觉：没有一种全局融合权重对所有任务都最优。手术缝合时，视觉负责定位、力觉负责组织软硬、本体感觉负责手腕姿态；端咖啡时，视觉和触觉的权重又完全不同；跳舞时本体感觉占主导，视觉只是外部锚点。如果强行学一组全局权重，本质是在所有技能之间做折中——对每个技能都不最优，而且一个技能的噪声会污染另一个技能的融合。人不是这样做的：人按「当前在做什么」动态地选择证据，甚至知道「这个技能里，某个传感器是诊断性的，另一个只是安全监视器」。因此，融合图应当是**技能的一部分**，由技能携带、被技能认证、随技能版本化。
严谨地说，设技能分布为 $p_s$、融合权重为 $w$、风险为 $R_s(w)$。全局融合解 $\min_w \sum_s p_s R_s(w)$，技能条件融合解 $\sum_s p_s \min_w R_s(w)$；后者由逐项最小化立即得 $\le$ 前者，等号只在「存在一组权重同时最小化所有技能风险」时成立。技能间融合偏好冲突越强，技能条件融合的收益越大；这就是**负迁移的融合版**。但技能条件融合也有统计代价：每个技能单独估计融合图会过拟合，所以真正的设计不是「每个技能都独立」，而是「**在可共享处共享、在冲突处分离，并只保留通过证书的分离**」。

**灵感 2（技能学习 → 技能不是策略，而是一份手艺契约）**
直觉：学徒学一门手艺，学的绝不只是动作序列。他学的是：该注意什么线索、哪些感官更可信、做到什么程度算好、失手时是什么感觉、什么条件下这门手艺根本不适用。一个只在「所有传感器都正常、标定都准确、光照都理想」时才能工作的策略，不是技能，而是一段脆弱脚本。真正的技能必须能回答四个问题：**我该信谁（融合图）、我在哪儿会（能力域）、我做错了长什么样（失效签名）、我凭什么被信（证据与版本）**。因此，本轮把技能定义成一个七元组，而不是一个策略网络；「学会」的判据也从训练集准确率，升级为**跨模态不变性 + 能力域覆盖 + 来源纪律**三件事同时成立。
跨模态不变性是关键：如果一个技能真的抓住了任务的因果结构，那么它在「声明的可接受模态子集」上应当保持能力——去掉视觉、替换触觉阵列、遮挡一半视野、传感器降采样，性能只允许有界下降；反过来，如果一个技能其实靠的是一个虚假线索（例如某个特定背景纹理、某个只在一个老师演示里出现的标记），那么换一个模态子集，它就会崩。这个「换感官还认不认得这门手艺」的测试，就是技能学习的可证伪证书。

**灵感 3（R69 的边界 → 学习是最后一种信息动作）**
直觉：R69 的 VoI 控制器在「注视、探针、问句」之间选，选不到正收益就退回 R68 的保守。但它漏掉了第三种选择：**去学一门新技能**。学习当然比问一句贵得多、慢得多、风险大得多，所以它不该是默认选项；它应当是**最后一种信息动作**——当且仅当：当前没有任何已认证技能覆盖这个状态，且所有即时信息动作的 VoI 都不划算，且未来任务分布中这个缺口会反复出现，且存在安全的影子练习协议时，才值得学。这样，学习不是对 R69 的替代，而是 R69 动作空间的一个**延迟、随机、不可逆的扩展**：R69 仍然是「不学习」边界上的精确退化。
学习的信息价值是**期权价值**，不是当下收益：它改变的是未来可用的技能集合。因此本轮用 $\mathrm{VoL}$（value-of-learning）而不是 VoI 来做决策，并要求用置信下界（LCB）而不是点估计，避免「为了学而学」和「用未来幻觉给自己发许可证」。

**灵感 4（安全 → 学习绝不能进实时环）**
直觉：在安全关键系统里，最危险的不是「不会」，而是「边执行边改自己的大脑」。所以 ARTISAN 的第一条工程铁律是：**实时环零学习写操作**。学习只发生在影子道场（shadow dojo）里：演示先隔离，练习在安全包络与盾牌内进行，候选技能在隔离副本上训练；实时控制器在执行期间只读冻结的技能库。只有通过发布门（release gate）的技能，才允许以**不可变、带版本、可回滚**的形式加入实时库。
这带来一个结构性的安全结论：学习行为本身不改变当前策略，因此不可能在学习的瞬间增加执行风险；风险只可能来自「发布后被执行的新技能」，而新技能又被能力域门和风险预算调度器限制。换句话说，**学习是离线的手艺，执行是线上的合同**。R68 的零学习写、R69 的交互预算与证据纪律，在本轮全部保留，只是把「学习」放到它们之外的安全侧。

**灵感 5（威胁 → 演示是断言，技能是主张）**
直觉：一旦系统会「学」，新的攻击面就出现了：老师可以教错；演示可以被投毒；一个技能可以被训练成「只在某个触发模态出现时才正常」的后门；自我练习可以在仿真器里找到奖励漏洞；新技能可以悄悄拖垮旧技能（灾难性遗忘/负迁移）。更隐蔽的是「模态依赖后门」：技能在认证时所有传感器都在，看起来完美，但部署时那个关键传感器被拆掉，技能立刻变成危险动作。
所以本轮必须同时交付：演示来源账本（谁教的、何时、何种传感器配置、可否撤回）、$k$ 个正交来源一致纪律（单一老师永远不能单独认证一个技能）、反事实模态消融测试（声明不用的模态被 shuffle 时行为不得改变；声明要用的模态被移除时退化必须与融合图一致）、以及技能库回归测试（新技能不得静默让旧技能失效）。这和 R69 的「问错比不问更危险」是同一个结构：**教错，比不会更危险**。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（ARTISAN-RAS 总览）** ARTISAN-RAS = (SL, SFG, CMIC, CRG, SVL, SDL, SRG, SKD, DPL, RAS-WM‡)。六条不变式：
(i) **实时环零学习写**（继承 R68 定义 276-i / R69 定义 293-i）：控制环内不执行任何优化器步骤，只做前向查询；
(ii) **技能索引融合**：每个可执行技能携带自己的融合图 $F_S$ 与可接受模态族 $\mathcal{M}_S$，不存在可以覆盖技能证据契约的全局融合；
(iii) **发布单调性**：未通过 SRG 的技能不得进入实时库；发布失败对库是**位级无操作**；所有发布带版本、可回滚；
(iv) **能力域门控**：只有当 $(o, \text{可用模态}, \text{标定状态}) \in C_S$ 时才允许执行 $S$，否则走 L1/L2/L3 退避；
(v) **来源纪律**：单一演示来源不得单独认证技能；至少需要 $k$ 个正交来源（老师/传感器/自练习）一致，并通过反事实测试；
(vi) **库级回归**：加入新技能不得静默使旧技能证书失效；若失效，必须显式重新认证并升版本，否则拒绝发布。

**定义 311（技能模式）** 技能 $S = (\pi_S, F_S, \mathcal{M}_S, C_S, \Psi_S, E_S, v_S)$：
- $\pi_S$：技能策略（可直接复用 R69 的 FMP，也可为解析控制器/MPC）；
- $F_S$：技能条件融合图（定义 312）；
- $\mathcal{M}_S \subseteq 2^{\mathcal{M}}$：可接受模态子集/传感器配置族（含降采样、遮挡、标定漂移范围）；
- $C_S$：能力域（定义 314）；
- $\Psi_S$：失效签名与在线监视器（把 R69 的 AUD/FMA 作为技能内监视器）；
- $E_S$：证据账本（演示、影子 rollout、反事实测试、来源与哈希）；
- $v_S$：不可变版本号。
**一个策略网络不是技能；技能是一份可执行、可检验、可追责的契约。**

**定义 312（技能条件融合图 SFG）** $F_S = (V_S, E_S^F, w_S, A_S)$：节点 $V_S$ 为模态/特征（视觉、深度、LiDAR、IMU、关节编码器、力/触觉、音频……），边 $E_S^F$ 为时间对齐与跨模态一致性约束，$w_S(m,o)$ 为技能条件权重/门控，$A_S$ 为聚合算子（可为可学习的注意力、卡尔曼、或带一致性惩罚的优化）。输出为任务相关潜变量的后验 $q_S(z\mid o)$。若所有技能共享同一个 $F$，则退化为全局融合；因此全局融合是本定义在「所有技能共享一个融合图」时的特例。

**定义 313（三层不确定性）** 不确定性按技能层级分为三层，每层再做 aleatoric/epistemic 二分：
- $U_{\text{exec}}$：技能内执行/动作模态不确定性，直接继承 R69 的 AUD：$(U_{\text{exec}}^{ale}, U_{\text{exec}}^{epi})$；
- $U_{\text{apply}}$：技能适用性不确定性，$H(S\mid o)$ 的信息分解：$(U_{\text{apply}}^{ale}, U_{\text{apply}}^{epi})$，其中 $U_{\text{apply}}^{epi} = I(S;Y\mid o)$ 可由额外证据降低；
- $U_{\text{comp}}$：能力域不确定性，即「选中的技能在当前状态下是否会失败」：$(U_{\text{comp}}^{ale}, U_{\text{comp}}^{epi})$，前者是域内固有波动，后者是可由更多数据/学习/交互降低的模型误差。
分通道处置：所有 aleatoric 部分进 R68 的 $\lambda_{\text{floor}}$；$U_{\text{exec}}^{epi}$ 进 R69 的 MINT 交互；$U_{\text{apply}}^{epi}$ 与 $U_{\text{comp}}^{epi}$ 先走 R69 交互，若仍不可解且满足定义 316 的触发条件，才走技能学习；未消解的 epistemic 一律按 aleatoric 兜底。三层**不做简单加和**，而是按层级顺序门控：技能选错的风险高于技能内选错，技能内选错又高于执行噪声。

**定义 314（能力域与共形门 CRG）** 对每个技能 $S$，定义非一致性分数 $r_S(o)\in\mathbb{R}$（预测失败概率、预测后悔、或风险上界）。在**声明的部署族** $\mathcal{D}_S$ 上取校准集（显式包含模态缺失、降采样、遮挡、标定漂移、光照/负载变化），用共形风险控制取分位数 $\hat q_\delta$（有限样本修正），令
$$C_S = \{o : r_S(o) \le \hat q_\delta\}.$$
则在可交换性下 $P(\text{failure}\mid o\in C_S, S)\le \delta+\varepsilon_{\text{cc}}$。$o$ 中显式包含「哪些模态可用、标定处于什么状态」，因此**能力域是传感器配置的函数**，不是纯几何状态集。

**定义 315（跨模态不变性证书 CMIC）** 对技能 $S$ 与可接受模态族 $\mathcal{M}_S$，定义不变性间隙
$$\Delta_{\text{inv}}(S)=\max_{m\in\mathcal{M}_S}\left\{\left[R_S(m)-R_S(m_{\text{full}})\right]_+ + \lambda\,D\big(\pi_S(\cdot\mid o_m)\,\|\,\pi_S(\cdot\mid o_{\text{full}})\big)\right\}+\mu\,\mathrm{Abl}(S),$$
其中 $R_S(m)$ 为在模态配置 $m$ 下的风险，$D$ 为行为分布散度，$\mathrm{Abl}(S)$ 为「声明的模态敏感度」与「实测消融敏感度」之间的失配：
$$\mathrm{Abl}(S)=\max_{j}\left|\mathrm{Sens}^{\text{emp}}_S(j)-\mathrm{Sens}^{\text{decl}}_S(j)\right|.$$
$\mathrm{Abl}$ 同时抓两类作弊：声明不用但实际偷偷依赖（shuffle 后行为改变），以及声明要用但实际没用（移除后性能不降）。**CMIC 通过**当且仅当 $\Delta_{\text{inv}}(S)\le\varepsilon_{\text{inv}}$，且对每个 $m\in\mathcal{M}_S$，CRG 的覆盖都成立。

**定义 316（技能学习价值 SVL）** 设当前技能库为 $L$，$R_L(x)=\min_{S\in L}R_S(x)$（若无技能覆盖则取 R68 兜底风险）。未来任务分布 $p_{\text{future}}$ 由审计缓冲与部署日志估计，并带支撑约束。候选技能 $S$ 的学习价值为
$$\mathrm{VoL}(S)=\mathbb{E}_{x\sim p_{\text{future}}}\left[R_L(x)-R_{L\cup\{S\}}(x)\right]-C_{\text{learn}}(S)-C_{\text{shadow}}(S)-R_{\text{explore}}(S)-C_{\text{reg}}(S).$$
学习触发条件（全部满足）：
(a) 当前状态不被任何已认证技能的能力域覆盖；
(b) 所有即时信息动作满足 $\max_g[\mathrm{VoI}(g)-c(g)]\le 0$（R69 已无便宜可占）；
(c) $\mathrm{LCB}[\mathrm{VoL}(S)]>0$（用置信下界，不用点估计）；
(d) 存在满足定义 317 的安全影子协议。
**学习是最后一种信息动作，不是默认动作。**

**定义 317（影子道场 SDL）** $\mathrm{SDL}=(Q_{\text{demo}}, E_{\text{safe}}, \mathcal{R}_{\text{shield}}, B_{\text{learn}}, K_{\text{reg}})$：$Q_{\text{demo}}$ 为隔离演示队列；$E_{\text{safe}}$ 为继承自 C-RAS-WM 的安全包络；$\mathcal{R}_{\text{shield}}$ 为风险有界探索盾（CBF/安全滤波器/仿真约束）；$B_{\text{learn}}=(\text{时间},\text{算力},\text{演示数},\text{真实 rollout 数})$ 为学习预算；$K_{\text{reg}}$ 为旧技能回归套件。道场内可以做离线强化学习、模仿学习、自练习或仿真训练，但**任何梯度步骤都不得触碰实时策略**；只有冻结后的推理权重可在发布后导出。

**定义 318（发布门与技能证书 SRG）** 技能证书
$$J_{\text{SKILL}}=(S_{\text{hash}}, F_{\text{hash}}, \text{prov}_{\text{root}}, \Delta_{\text{inv}}, \{\text{cov}_S(m)\}_{m\in\mathcal{M}_S}, \Psi_{\text{tests}}, \Delta R_{\text{old}}, B_{\text{used}}, \text{SRG}_{\text{verdict}}).$$
发布当且仅当：$\Delta_{\text{inv}}\le\varepsilon_{\text{inv}}$；每个 $m\in\mathcal{M}_S$ 的 CRG 覆盖 $\ge 1-\delta$；来源纪律通过；失效签名测试通过；$\Delta R_{\text{old}}\le\varepsilon_{\text{nt}}$（定义 326）；预算未越界。发布是原子的：加入冻结权重、写版本、保留旧版本、失败则位级无操作。

**定义 319（技能调度与组合 SKD）** 可用集 $A(o)=\{S\in L: o\in C_S,\ \text{provenance 有效},\ v_S\ \text{active}\}$。若 $A(o)=\varnothing$，走 R69 交互或 L2/L3 退避。否则选择
$$S^*=\arg\max_{S\in A(o)}\ \mathbb{E}[U_S(o)]\quad\text{s.t.}\quad \overline R_S(o)\le \min_{S'\in L\cup\{\text{fallback}\}}\overline R_{S'}(o)+\varepsilon_{\text{improve}},$$
其中 $\overline R$ 为证书风险上界。组合通过技能图上的前驱/后继边执行，切换必须连续：在安全滤波器的零空间内插值，或在短时域内混合两个技能的 certified 中间状态；任何 handoff 都必须带「前一技能已退出其能力域、后一技能已进入其能力域」的交接证书。

**定义 320（技能库图 SL）** $L=(V=S,\ E_{\text{comp}},\ E_{\text{interf}},\ \text{versions},\ \text{regression matrix})$：$E_{\text{comp}}$ 为可组合/先后关系，$E_{\text{interf}}$ 为干扰关系（共享融合编码器、竞争同一执行器、数据分布重叠）。库只追加新版本，不静默覆盖旧版本；加入/更新技能触发邻居与回归套件的再验证；支持回滚。

**定义 321（演示来源账本 DPL）** 每条演示 $d=(\text{source},\text{time},\text{sensor config},\text{calibration snapshot},\text{consent},\text{hash},\text{parent skill},\text{trust})$。账本只追加，撤回显式记录。老师信任分只做门控，不冒充概率；技能认证需要 $k$ 个正交来源（两两欺骗相关 $<\rho_{\max}$）一致，且至少包含一次在声明模态族内的自练习 rollout。**单一老师永远不能单独认证技能。**

**定义 322（技能威胁模型 AIC-SKILL）** $\mathcal{E}_{\text{SKILL}}=\mathcal{E}_{\text{FLUID}}\times\mathcal{E}_{\text{demo}}\times\mathcal{E}_{\text{skill}}$：

**定义 326（库一致性与负迁移上界）** 加入新技能 $S_{\text{new}}$ 后，对旧技能集 $L_{\text{old}}$ 定义

## 3. 推导

**引理 19（技能条件融合的弱占优）** 设技能分布为 $p_s$，技能 $s$ 在融合权重 $w$ 下的风险为 $R_s(w)$，全局融合 $w_g=\arg\min_w\sum_s p_s R_s(w)$，技能条件融合 $w_s^*=\arg\min_w R_s(w)$。则
$$\sum_s p_s R_s(w_s^*)\ \le\ \sum_s p_s R_s(w_g).$$
等号成立当且仅当存在一组权重同时最小化所有 $p_s>0$ 的技能风险。**系**：技能间融合偏好冲突越强，分离收益越大；这就是负迁移的融合版。**但统计代价不可忽略**：每个技能独立估计 $w_s^*$ 需要更多样本，因此只有当估计收益超过置信下界上的统计成本时，才把某个子集从共享融合图中拆出；否则宁可共享。

**引理 20（跨模态不变性能检出虚假线索）** 设技能 $S$ 依赖一个只在模态 $m$ 中出现、在 $m'\in\mathcal{M}_S$ 中缺失或反相关的虚假线索；令换到 $m'$ 后成功率下降 $\Delta_{\text{succ}}$。则 $\Delta_{\text{inv}}(S)\ge\Delta_{\text{succ}}-2\eta$（$\eta$ 为有限样本估计噪声）。故当 $\Delta_{\text{succ}}>\varepsilon_{\text{inv}}+2\eta$ 时 CMIC 必然拒绝。反之，若 $\Delta_{\text{inv}}\le\varepsilon_{\text{inv}}$，则对每个声明模态 $m$，相对全模态的额外风险 $\le\varepsilon_{\text{inv}}$，且行为散度被 $\lambda$ 项约束；于是部署在任意声明模态子集上的退化有界。**这把「学会」从训练损失变成了可检验的跨模态鲁棒性。**

**引理 21（学习是有界的延迟动作）** 若实时策略在学习期间冻结、候选技能只在隔离副本上训练、发布必须通过 SRG 与 CRG，则任何学习事件都不改变当前控制策略；唯一的风险变化来自发布后被调度器选中的新技能，而调度器只在其能力域内、且风险上界不超过当前最优兜底 $+\varepsilon_{\text{improve}}$ 时才选它。故单次学习的即时风险变化为 $0$，发布后的期望风险变化被「被选中区域的测度 × 该区域的证书风险」界定；学习本身不可能在实时环内制造突变。

**定理 18（ARTISAN 严格包含 R69/R68）** 在「不触发学习」（$\mathrm{LCB}[\mathrm{VoL}]\le0$ 或无安全 SDL）且技能库中只有一个技能（即 R69 的 FMP）时，ARTISAN 的调度、融合与交互逐指令退化为 R69；若再满足 R69 的「无正收益交互」条件，则逐指令退化为 R68。因此 R69 是 ARTISAN 在「无学习」边界上的精确退化，R68 是 R69 在「无交互」边界上的精确退化；安全侧不做任何让步，效率侧获得「技能条件融合 + 新技能」的扩展收益。

**定理 19（发布技能的风险上界）** 在 A99–A102 下：
- A99：CRG 校准数据与部署数据在声明的模态族内可交换；
- A100：影子到真实的差距有界，$|R^{\text{real}}-R^{\text{shadow}}|\le\varepsilon_{\text{gap}}$；
- A101：CRG 的有限样本覆盖 $P(\text{failure}\mid o\in C_S)\le\delta+\varepsilon_{\text{cc}}$；
- A102：调度器绝不在 $C_S$ 外选择 $S$，且兜底至少与 R69 一样安全。
则对已发布技能 $S$ 与 $o\in C_S$，
$$R_S^{\text{real}}(o)\ \le\ R_S^{\text{shadow}}(o)+\varepsilon_{\text{gap}}+\delta+\varepsilon_{\text{cc}}+\varepsilon_{\text{inv}}.$$
对 $o\notin C_S$，调度器拒绝执行。因此发布后的库级风险上界为 $\min\{R_{\text{before}}, R_S^{\text{real}}\}$；在风险预算调度下，发布不会抬高当前证书上界。

**定理 20（技能库的单调非退化）** 若 (i) 候选训练使用隔离副本，(ii) 发布只追加冻结权重与版本，(iii) 回归检查 $\Delta R_{\text{old}}\le\varepsilon_{\text{nt}}$，(iv) 调度器使用风险预算与单调退避，则对任意旧技能与任意状态，可用证书集只增不减，所选技能的证书风险上界不增；发布失败对库是位级无操作。**系**：负迁移被转化为显式的发布拒绝或显式的重新认证，而不是运行时的静默退化。

## 6. 本轮最大风险

**一句话**：ARTISAN 的全部安全收益押在「影子道场与真实部署同分布、且演示不可被投毒」这一前提上——**若影子世界系统性偏离真实，跨模态不变性与能力域覆盖会在一个自洽的错误世界里全部通过，系统将带着「已认证」的自信执行一个从未真正学会的技能；学错，比不会更危险。**

**次级风险与缓解**：
1. **影子到真实的差距**（仿真偏差、演示偏差）→ 成对 shadow/real 校准、$\varepsilon_{\text{gap}}$ 保守上界、OOD 拒绝、E312；
2. **投毒演示与模态依赖后门** → DPL 来源账本 + $k$ 源一致 + CMIC 反事实消融 + E306/E307；
3. **负迁移/灾难性遗忘** → 隔离训练 + 冻结发布 + 库回归 + 版本化回滚 + E308；
4. **技能爆炸与库治理** → 版本化、退役、审计、调度器预算；技能不是越多越好；
5. **能力域过保守导致「学了不用」** → SVL 与 CRG 联合调参、E303/E304 的 Pareto 分析；
6. **实时预算被技能层击穿** → 共享 trunk + 粗路由 top-k + 仅对候选做精门控 + E310。

## 2. 形式化定义（要点版）

**定义 310（总览与六不变式）** `ARTISAN-RAS = (SL, SFG, CMIC, CRG, SVL, SDL, SRG, SKD, DPL, RAS-WM‡)`。继承 R68 零学习写、R69 交互预算与证据纪律；新增：(i) 技能索引融合——每个技能携带自己的 $F_S,\mathcal{M}_S$，不存在覆盖技能证据契约的全局融合；(ii) 发布单调性——未过 SRG 不得入实时库，失败是位级无操作，发布可回滚；(iii) 能力域门控——只在 $C_S$ 内执行；(iv) 来源纪律——单源不得单独认证，需 $k$ 正交来源 + 自练习；(v) 库级回归——新技能不得静默使旧证书失效。

**定义 311（技能模式）** $S=(\pi_S,F_S,\mathcal{M}_S,C_S,\Psi_S,E_S,v_S)$。策略可复用 R69 FMP；$\Psi_S$ 把 R69 的 AUD/FMA 作为技能内监视器；证据账本记录演示、影子 rollout、反事实测试与来源哈希。**策略网络不是技能；技能是可执行、可检验、可追责的契约。**

**定义 312（SFG）** $F_S=(V_S,E_S^F,w_S,A_S)$：节点为异构模态/特征，边为时间对齐与跨模态一致性约束，权重/门控条件于当前观测，聚合可为注意力/卡尔曼/带一致性惩罚的优化。输出 $q_S(z\mid o)$。所有技能共享同一 $F$ 时退化为全局融合。

**定义 313（三层不确定性）** $U_{\text{exec}}$ 继承 R69 的 AUD；$U_{\text{apply}}=H(S\mid o)$ 并做信息分解；$U_{\text{comp}}$ 为能力域失败风险及其可约部分。每层分开 aleatoric/epistemic：aleatoric 进 $\lambda_{\text{floor}}$；$U_{\text{exec}}^{epi}$ 进 R69 MINT；$U_{\text{apply}}^{epi},U_{\text{comp}}^{epi}$ 先交互，仍不可解且满足 SVL 触发条件才学习；未消解一律按 aleatoric 兜底。三层不做简单加和，按「技能选错 > 技能内选错 > 执行噪声」的层级门控。

**定义 314（CRG）** $r_S(o)$ 为非一致性分数；在声明的部署族（含模态缺失/漂移/遮挡）上取共形分位数 $\hat q_\delta$，$C_S=\{o:r_S(o)\le\hat q_\delta\}$，则 $P(\text{failure}\mid o\in C_S,S)\le\delta+\varepsilon_{\text{cc}}$。**能力域是传感器配置的函数**。

**定义 315（CMIC）** $\Delta_{\text{inv}}(S)=\max_{m\in\mathcal{M}_S}\{[R_S(m)-R_S(m_{\text{full}})]_++\lambda D(\pi_S(\cdot\mid o_m)\|\pi_S(\cdot\mid o_{\text{full}}))\}+\mu\,\mathrm{Abl}(S)$，其中 $\mathrm{Abl}(S)=\max_j|\mathrm{Sens}^{\text{emp}}_S(j)-\mathrm{Sens}^{\text{decl}}_S(j)|$。通过当且仅当 $\Delta_{\text{inv}}\le\varepsilon_{\text{inv}}$ 且每个声明模态的 CRG 覆盖达标。它同时抓「声明不用却偷偷依赖」与「声明要用却其实没用」。

**定义 316（SVL）** $\mathrm{VoL}(S)=\mathbb{E}_{x\sim p_{\text{future}}}[R_L(x)-R_{L\cup\{S\}}(x)]-C_{\text{learn}}-C_{\text{shadow}}-R_{\text{explore}}-C_{\text{reg}}$。学习触发需同时满足：无已认证技能覆盖当前状态；$\max_g[\mathrm{VoI}(g)-c(g)]\le0$；$\mathrm{LCB}[\mathrm{VoL}]>0$；存在安全 SDL。**学习是最后一种信息动作。**

**定义 317（SDL）** $(Q_{\text{demo}},E_{\text{safe}},\mathcal{R}_{\text{shield}},B_{\text{learn}},K_{\text{reg}})$：演示隔离、安全包络、风险有界探索盾、预算、旧技能回归套件。可在道场内做模仿/离线 RL/自练习/仿真，但**任何梯度步骤不得触碰实时策略**；只有冻结权重可在发布后导出。

**定义 318（SRG/J_SKILL）** 发布条件：$\Delta_{\text{inv}}\le\varepsilon_{\text{inv}}$；每个声明模态的 CRG 覆盖 $\ge1-\delta$；来源纪律通过；失效签名测试通过；$\Delta R_{\text{old}}\le\varepsilon_{\text{nt}}$；预算未越界。发布原子化：加冻结权重、写版本、保留旧版本；失败位级无操作。

**定义 319（SKD）** $A(o)=\{S\in L:o\in C_S,\text{provenance 有效},v_S\text{ active}\}$；空则走 R69/L2/L3。选择 $S^*=\arg\max_{S\in A(o)}\mathbb{E}[U_S(o)]$，约束 $\overline R_S(o)\le\min_{S'\in L\cup\{\text{fallback}\}}\overline R_{S'}(o)+\varepsilon_{\text{improve}}$。组合走技能图，切换在安全滤波器零空间插值或短时域混合，handoff 需交接证书。

**定义 320（SL）** 库图 $L=(S,E_{\text{comp}},E_{\text{interf}},\text{versions},\text{regression matrix})$；只追加新版本，不静默覆盖；加入/更新触发邻居与回归再验证；支持回滚。

**定义 321（DPL）** 演示 $d=(\text{source},\text{time},\text{sensor config},\text{calibration snapshot},\text{consent},\text{hash},\text{parent skill},\text{trust})$；只追加、撤回显式。信任分只做门控；认证需 $k$ 个两两欺骗相关 $<\rho_{\max}$ 的正交来源，且至少一次声明模态族内的自练习。**单源永不单独认证。**

**定义 322（AIC-SKILL）** $\mathcal{E}_{\text{SKILL}}=\mathcal{E}_{\text{FLUID}}\times\mathcal{E}_{\text{demo}}\times\mathcal{E}_{\text{skill}}$：投毒演示/后门触发器/老师共谋/选择性示范/来源伪造；模态依赖后门/技能冒充/负迁移/灾难性遗忘/自练习奖励黑客/仿真器漏洞/库污染/回滚攻击；继承 R69 的流采样故障、模态坍缩、ODE 发散。

**定义 323（VQAuditor-S）** 审计演示来源与撤回、CMIC 反事实测试、发布/拒绝、能力域越界、调度选择、handoff 连续性、负迁移与回滚；结论回灌 DPL 信任先验、SVL 成本与回归套件；只追加不可删。

**定义 324（分层退避格）** L0 完整；L1 不学习（精确 R69）；L2 不交互（精确 R68）；L3 最小风险机动/停机。安全集逐层收缩，$\lambda$ 单调不降，切换连续。

**定义 325（J_ARTISAN）** 见符号表；Valid 当且仅当 $J_{\text{FLUID}}$ 有效、$\Delta_{\text{inv}}\le\varepsilon_{\text{inv}}$、逐模态覆盖达标、来源纪律满足、$\Delta R_{\text{old}}\le\varepsilon_{\text{nt}}$、预算未越界。

**定义 326（库一致性与负迁移上界）** $\Delta R_{\text{old}}=\max_{S\in L_{\text{old}}}[R_S^{\text{after}}(C_S)-R_S^{\text{before}}(C_S)]_+\le\varepsilon_{\text{nt}}$；否则拒绝或显式重新认证升版本。干扰矩阵 $I_{ij}$ 供调度器避免冲突组合。**负迁移从静默退化变成显式发布拒绝。**

## 3. 关键算法伪代码

```python
# IP-264/265 技能契约与技能条件融合
@dataclass(frozen=True)
class Skill:
    pi: Policy                    # 可为 R69 FMP
    fusion: FusionGraph           # F_S
    modalities: ModalityFamily    # M_S（含缺失/降采样/漂移）
    competence: CompetenceRegion  # C_S
    failure_sig: FailureSignature # Ψ_S（R69 AUD/FMA）
    evidence: EvidenceLedger      # E_S
    version: str

def fuse(S, o):
    m = available_modalities(o)
    return S.fusion.aggregate(o, m), m

# IP-266/267 跨模态不变性与能力域
def cmic_gap(S, calib):
    full = risk(S, calib, m_full)
    gaps = [max(risk(S, calib, m) - full, 0) + LAM * behavior_div(S, calib, m)
            for m in S.modalities]
    return max(gaps) + MU * ablation_mismatch(S, calib)

def crg_calibrate(S, calib):
    q_hat = conformal_quantile([r_S(o) for o in calib.family(S.modalities)], DELTA)
    return CompetenceRegion(S, q_hat)

# IP-268 技能学习价值：最后一种信息动作
def value_of_learning(L, o, future, candidate):
    if any(o in S.competence for S in L):  return -inf
    if max_info_voi(o) > 0:                return -inf   # R69 还有便宜可占
    gain = expected_future_risk(L, future) - expected_future_risk(L + [candidate], future)
    cost = c_learn(candidate) + c_shadow(candidate) + r_explore(candidate) + c_reg(candidate)
    return lcb(gain - cost)

# IP-269/270 影子道场与发布门
def shadow_dojo(candidate, demos, shield, budget):
    with quarantine(demos), frozen(real_policy):
        train(candidate, demos, shield, budget)   # 绝不写实时策略
    return candidate

def release_gate(S, dojo, reg_suite):
    inv  = cmic_gap(S, dojo.calib)
    cov  = [coverage(S, m, dojo.calib) for m in S.modalities]
    prov = provenance_ok(S.evidence, k=K_SRC, rho=RHO_MAX)
    dR   = regression_delta(S, reg_suite)
    ok   = (inv <= EPS_INV and min(cov) >= 1 - DELTA
            and prov and dR <= EPS_NT and budget_ok(S))
    return ok, SkillCert(S, inv, cov, prov, dR)

# IP-271 风险预算调度
def dispatch(o, L, r69):
    A = [S for S in L if competence_gate(S, o)]
    if not A: return r69.interact_or_fallback(o)
    best = argmax(A, key=lambda S: expected_utility(S, o))
    if risk_upper(best, o) > current_risk_upper(L, o) + EPS_IMPROVE:
        return r69.interact_or_fallback(o)
    return best

# IP-276 主闭环：学习异步，实时环零写
def ARTISAN_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, _ = M.cof.step(...)
    A = [S for S in M.library if M.crg.gate(S, o)]
    samples = M.fmp.sample(o, K=M.k_sched(z))
    U_exec_ale, U_exec_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    U_apply, U_comp = M.sl.skill_uncertainty(M.library, o)
    S = M.skd.dispatch(o, M.library, M.r69) if A else M.r69.interact_or_fallback(o)
    if not A and max_info_voi(o) <= 0:
        M.dojo.request(candidate_from_audit(o))   # 只入队，本拍不训练
    M.vqa_s.submit_async(S, U_apply, U_comp, U_exec_epi)
    return M.safe_execute(S, o, lam=lam_floor(U_exec_ale + unresolved(U_apply, U_comp)))
```

## 4. 推导

**引理 19（技能条件融合的弱占优）** $w_g=\arg\min_w\sum_s p_sR_s(w)$，$w_s^*=\arg\min_wR_s(w)$，则 $\sum_s p_sR_s(w_s^*)\le\sum_s p_sR_s(w_g)$；等号当且仅当存在同时最小化所有 $p_s>0$ 技能风险的权重。系：技能间融合偏好冲突越强，分离收益越大（负迁移的融合版）；但每个技能独立估计有统计代价，只在估计收益超过置信下界上的成本时才拆分子集。

**引理 20（跨模态不变性检出虚假线索）** 若技能依赖只在 $m$ 出现、在 $m'$ 缺失/反相关的虚假线索，换到 $m'$ 后成功率降 $\Delta_{\text{succ}}$，则 $\Delta_{\text{inv}}\ge\Delta_{\text{succ}}-2\eta$；当 $\Delta_{\text{succ}}>\varepsilon_{\text{inv}}+2\eta$ 时 CMIC 必然拒绝。反之 $\Delta_{\text{inv}}\le\varepsilon_{\text{inv}}$ 给出声明模态子集上的有界退化。**这把「学会」从训练损失变成可检验的跨模态鲁棒性。**

**引理 21（学习是有界的延迟动作）** 实时策略冻结、候选只在隔离副本训练、发布必须过 SRG/CRG，则学习事件不改变当前策略；唯一风险变化来自发布后被调度器在能力域内选中、且风险上界不超过当前兜底 $+\varepsilon_{\text{improve}}$ 的新技能。故单次学习的即时风险变化为 0，发布后的期望变化由「被选中区域测度 × 证书风险」界定；学习不可能在实时环内制造突变。

**定理 18（严格包含 R69/R68）** 无学习触发且库中只有 R69 的 FMP 时，ARTISAN 逐指令退化为 R69；再无正收益交互时逐指令退化为 R68。R69 = 「无学习」边界，R68 = R69 的「无交互」边界；安全侧不让步。

**定理 19（发布技能风险上界）** 在 A99–A102 下（CRG 校准可交换、影子-真实差距 $\varepsilon_{\text{gap}}$、CRG 覆盖 $\delta+\varepsilon_{\text{cc}}$、调度器域外拒绝且兜底不弱于 R69），对 $o\in C_S$：$R_S^{\text{real}}(o)\le R_S^{\text{shadow}}(o)+\varepsilon_{\text{gap}}+\delta+\varepsilon_{\text{cc}}+\varepsilon_{\text{inv}}$；对 $o\notin C_S$ 拒绝执行。库级风险上界为 $\min\{R_{\text{before}},R_S^{\text{real}}\}$，风险预算调度下发布不抬高证书上界。

**定理 20（技能库单调非退化）** 隔离训练 + 只追加冻结权重 + 回归 $\Delta R_{\text{old}}\le\varepsilon_{\text{nt}}$ + 风险预算/单调退避 ⇒ 可用证书集只增不减、所选技能证书风险上界不增；发布失败为位级无操作。系：负迁移被转化为显式发布拒绝或显式重新认证，而非运行时静默退化。

## 7. 本轮最大风险

**一句话**：ARTISAN 的全部安全收益押在「影子道场与真实部署同分布、且演示不可被投毒」这一前提上——**若影子世界系统性偏离真实，跨模态不变性与能力域覆盖会在一个自洽的错误世界里全部通过，系统将带着「已认证」的自信执行一个从未真正学会的技能；学错，比不会更危险。**

**次级风险与缓解**：影子-真实差距（成对校准 + 保守 $\varepsilon_{\text{gap}}$ + OOD 拒绝 + E312）；投毒演示/模态依赖后门（DPL + $k$ 源 + CMIC 反事实消融 + E306/E307）；负迁移/遗忘（隔离训练 + 冻结发布 + 库回归 + 版本回滚 + E308）；技能爆炸（版本/退役/审计/调度预算）；能力域过保守（SVL×CRG 联合调参 + E303/E304 Pareto）；实时预算（共享 trunk + 粗路由 + 仅候选精门控 + E310）。
