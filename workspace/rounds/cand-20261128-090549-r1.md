### 第 6 轮灵感驱动研究记录

**灵感词**：伦理审查、低延迟推理

**继承关系**：第 5 轮 CADVS-v5（IP-493~496）把提议升级为条件流匹配、记忆升级为嵌入固化、人因升级为情感调制，并用定理 6（证书不变性）把框架从「规则系统」推广为「任意生成器 + 认证边界」。但 v5 留下两个未答的结构性问题：(a) **谁授权边界与阈值？** 七硬门只证明「技术上安全」，并不等于「规范上正当」——阈值 τ^4 从何而来、谁对其负责、如何撤销，v5 未触及；(b) **认证机制越来越贵**，若把审慎的规范判断塞进 1 kHz 控制环，实时性必然崩塌。两个灵感词合成主题「可审查的低延迟认证」（Auditable Low-Latency Certification, ALLC），形成 CADVS-v6（IP-497~500）。本轮自律：**轨迹硬门仍为七道，不增门**；伦理审查是**慢时域的元层（meta-layer）**，不是第八道轨迹门——它只做三件事：授权阈值、收窄适用范围、编码少数道义不变量；执行集嵌套升级为 Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ … ⊆ Exec_v29（全局层面；任何局部放松必须用范围收缩来「支付」，见定理 9 推论 9′）。

**直觉与动机**：

1. **伦理审查 → 从「一次性安全证明」升级为「可撤销、可争议、可追溯的规范证书」**。直觉：安全证书回答「会不会伤到人」，伦理审查回答「这样做是否被授权、是否尊重人、出了事谁负责」。前者是工程谓词，后者是**制度过程**，不能被完全形式化。我们不假装能证明伦理，而是形式化其**程序属性**：范围（scope）、授权（authorization）、有效期（expiry）、撤销（revocation）、可争议（contestability）、残余风险知情（residual-risk ledger）。慢层由人类审查会（IRB 式）产出签名 **NPB（Normative Policy Bundle）**；关键红线：**编译不是批准，批准永远由人签署**——编译器只把已批准条款翻译成可执行守卫，每条守卫带 provenance 指回规范条款，防止形式化过程偷偷替换价值。

2. **低延迟推理 → 把审慎编译到慢时域，把执行压到 O(1)**。直觉：伦理审查若每周期都跑一遍，系统就瘫了；正确做法是「**慢层深思、快层轻守**」。NPB 编译为：(a) 范围守卫 ĝ_scope（蒸馏小模型 + split conformal，弃权即 fail-closed）；(b) 阈值授权校验（签名 + epoch，O(1) 缓存）；(c) 少数道义不变量（人类接管通道存活、来源标签/反欺骗、数据最小化）编译为 O(1) 架构守卫。用**推测式验证**（快草案先判，仅模糊带调慢验证器）+ **epoch 前缀缓存** + **速率限制的慢路径**，使最坏执行时间（WCET）确定有界；延迟预算用次模背包分配，伦理能力「按预算增量上线」。

3. **闭环 → 审查→编译→执行→审计→再审查**。运行时把 (context hash, cert id, guard version, decision, margin) 写入**哈希链审计**；争议时人类可重放；撤销以 epoch++ 广播；残余风险账本回流到下一轮审查。这把 v5 的「自指固化博弈」风险（R57）用**外部人类权威 + 可争议通道**部分对冲——但只对冲治理，不对冲价值本身。

**关键洞见**：v4 问「提议=规则时七门够不够」；v5 问「提议=任意生成器时边界能否不动」；v6 问「**边界由谁授权、如何既守边界又守规范且不牺牲实时性、出错后如何被追责与纠正**」。核心是**三权分立**：规范权威（人）／形式化编译（ERC）／实时执行（LCG）分离，任何一层都不能自证——直接针对 v5 的「铸证→学习→再铸证」自指回路。理论主轴是**定理 9（编译可靠性）**与**推论 9′（范围-松弛对偶）**：全局只紧不松；任何局部放松必须用范围收缩来「支付」，不允许无代价的全局放松。

**形式化目标（增量）**：
1. NPB = (S_scope, Γ_auth, D_deontic, R_ledger, C_contest, σ_sig, t_exp, epoch_rev)。
2. 编译可靠性：ĝ 是规范允许集的欠近似 + 运行时 fail-closed + 证书新鲜 ⇒ Exec_v6 ⊆ 规范允许集，且 ⊆ Exec_v5。
3. 范围-松弛对偶：放松 Δτ<0 必须伴随范围收缩 ΔS，使有效风险质量不增（∫_S r ≤ ∫_{S'} r，S'⊂S）。
4. 预算化编译：延迟-合法性 Pareto 前沿，次模贪心 (1−1/e)；慢路径速率限制保证确定性 WCET。
5. Conformal 范围守卫 + 弃权 fail-closed；推测式验证降低期望延迟而不破坏最坏界。
6. 撤销/过期传播窗口界；审计「可重构」严格区别于「可辩护」。
7. Exec_CADVS-v6 = {x ∈ supp(π_FM) ∩ S_scope : ∧_i kc_i(x,c; γ_i·τ_i^6)=1 ∧ D_deontic(x,c) ∧ auth(τ^6,epoch)=1}。

**本轮最大风险**：**合规剧场叠加规范-形式化鸿沟**——慢层把无法形式化的价值差异掩盖为一张「已批准」的签名证书，快层又忠实地执行被编译错的规范，审计链再把二者包装成可追溯的正当性；系统因此获得「伦理已审」的光环却实质偏离人类价值，而审查俘获与证书过期会放大这一偏差，且形式化定理对此结构性无能为力。

## 2. 关键算法骨架

### IP-497 ERC：伦理审查编译器（慢时域，离线；人类签署）

```python
@dataclass
class EthicalReviewCompiler:
    """ERC：把人类批准的规范条款翻译为可执行 NPB。
    红线：compile ≠ approve；approve 必须由人签名，编译器无权自批"""
    template_bank: Any                 # 结构化条款模板（范围/理由/反例/失效条件）
    risk_fn: Callable                  # 风险质量函数 r(x,c)，用于范围-松弛对偶

    def compile(self, clauses, domain, ledger, reviewer_keys) -> NPB:
        scope = compile_scope(clauses, domain)           # → S_scope + ĝ_scope 规格
        gamma = authorize_thresholds(clauses, TAU_V5)    # 默认只紧：τ^6 ≥ τ^5
        deontic = encode_deontic(clauses.deontic)        # 少数不可交易不变量
        npb = NPB(scope=scope, gamma=gamma, deontic=deontic, ledger=ledger,
                  contest=clauses.contest, t_exp=clauses.expiry,
                  epoch_rev=0)
        for guard in npb.iter_guards():                  # provenance 完整性
            assert guard.clause_id in clauses.ids       # 每条守卫可指回规范条款
        assert quorum_sign(npb, reviewer_keys)           # 无人类签名 → 不可用
        return npb

    def scope_relaxation_dual(self, relax, scope_old):
        """推论 9′：局部放松 Δτ<0 必须用范围收缩支付，风险质量不增"""
        scope_new = contract_scope(scope_old, relax, self.risk_fn)
        assert risk_mass(scope_new, relax) <= risk_mass(scope_old, static=0)
        return scope_new        # 不允许「全局放松」；放松只换取更窄的适用范围
```

### IP-498 LCG：低延迟编译守卫（快时域，每周期；O(1)/O(d)，确定性 WCET）

```python
@dataclass
class LowLatencyCompiledGuard:
    """LCG：快层只守边界，不做审慎判断；不确定即弃权 → fail-closed"""
    fast_guard: Any                    # 决策表/线性草案，O(d)
    slow_model: Any                    # 蒸馏大模型，仅模糊带调用
    q_hat: float                       # conformal 分位数（1−α 覆盖）
    band: tuple = (0.35, 0.65)         # 模糊带
    cache: dict = field(default_factory=dict)
    tokens: float = 1.0                # 慢路径令牌桶（速率限制）
    L_budget_us: float = 50.0

    def check_scope(self, x, c, epoch, policy_h) -> Decision:
        key = (epoch, policy_h, bucket(c))          # epoch 前缀键：撤销即逻辑失效
        if key in self.cache:
            return self.cache[key]                  # O(1) 命中
        s = self.fast_guard.score(x, c)             # 草案：O(d)
        if s <= self.band[0]:
            d = IN_SCOPE
        elif s >= self.band[1]:
            d = ABSTAIN                             # 模糊带外 → 弃权
        elif self.tokens <= 0:
            d = ABSTAIN                             # 慢预算耗尽 → fail-closed
        else:
            self.tokens -= 1
            d = IN_SCOPE if self.slow_model(x, c) <= self.q_hat else ABSTAIN
        self.cache[key] = d
        return d

    def check_auth(self, npb, now) -> bool:
        # O(1)（epoch 缓存）：签名 + 未过期 + 纪元新鲜 + 授权只紧
        return (verify_sig(npb) and now < npb.t_exp
                and npb.epoch_rev == current_epoch()
                and all(npb.gamma >= TAU_V5))       # 全局不允许放松

    def deontic_ok(self, x, c) -> bool:
        # 道义不变量：人类接管通道存活 + 来源标签 + 数据最小化标记
        return (watchdog_alive() and has_provenance(x)
                and data_min_flag(c) and override_channel_live())

    def refill(self, dt):
        self.tokens = min(1.0, self.tokens + dt / T_REFILL)   # 确定性令牌补充
```

### IP-499 ACK：审计与争议核（哈希链；撤销广播；人类重放）

```python
@dataclass
class AuditContestationKernel:
    chain: list = field(default_factory=list)
    epoch: int = 0

    def log_decision(self, ctx_h, cert_id, guard_v, decision, margin):
        prev = self.chain[-1].h if self.chain else GENESIS
        rec = Record(prev=prev, ctx_h=ctx_h, cert_id=cert_id, guard_v=guard_v,
                     decision=decision, margin=margin, t=now())
        rec.h = H(prev || rec.body)             # 防篡改哈希链
        self.chain.append(rec)                  # O(1) 追加；Merkle 根 O(log n) 证明

    def revoke(self, cert_id, reason):
        self.epoch += 1                         # epoch++ → 所有缓存逻辑失效
        broadcast_epoch(self.epoch)             # 推 + 拉双通道

    def contest(self, rec_id):
        """人类申诉：重放决策，返回可复核证据包（redact PII，仅哈希/聚合）"""
        return replay(self.chain, rec_id, redact_pii=True)

    def ledger_feedback(self, npb, stats):
        """残余风险账本回流下一轮审查；统计经 DP 处理"""
        npb.ledger.update(dp_aggregate(stats))
```

# 定理 9：编译可靠性 + 推论 9′：范围-松弛对偶
def theorem_compilation_soundness() -> str:
    """

    诚实边界：本定理只对「已形式化的 A_norm」成立；规范-形式化鸿沟 δ_norm 不在覆盖内。
    """
    return "Proven (relative to formalized A_norm); delta_norm uncovered"

# 定理 10：延迟-合法性 Pareto（预算化编译）
def theorem_latency_legitimacy_pareto() -> str:
    """
    定理 10：设可编译条款项 {u_j}，收益 w_j（覆盖的规范质量），延迟成本 l_j；
    在预算 L_budget 下最大化 Σ w_j x_j s.t. Σ l_j x_j ≤ L_budget。

    证明：次模最大覆盖标准结论；背包 DP 标准。∎
    工程含义：伦理能力可按预算增量上线，先编译高收益低成本项。
    """
    return "Proven"

# 定理 11：撤销/过期传播界
def theorem_revocation_window() -> str:
    """
    定理 11：若运行时每周期校验 epoch（O(1) 缓存）且撤销走推+拉双通道，

    诚实边界：离线/网络分区时只能 fail-closed 停机，可用性受损（拒绝服务式安全）。
    """
    return "Proven (window); availability cost under partition"

# 定理 12：审计可重构 ≠ 可辩护
def theorem_audit_reconstruct_not_justify() -> str:
    """
    定理 12：哈希链 A_chain 在抗碰撞假设下防篡改且可重构（任何人可重放决策路径）；
    但「可重构」不蕴含「可辩护」——规范正当性不能从审计记录推出。
    证明：哈希链抗篡改是标准假设；正当性是规范判断，非形式蕴含。∎
    意义：刻意把 technical auditability 与 normative justification 分离，
    防止用「有审计链」冒充「伦理正确」。
    """
    return "Proven (reconstruct); justification NOT implied"

### IP-500 EFA-v6：七硬门 + 授权阈值 + 范围/道义守卫

```python
@dataclass
class EvidenceForgingAssemblerV6:
    """EFA-v6：七硬门不变（阈值须被 NPB 授权）+ LCG 三关 + v5 级联"""
    v5: EvidenceForgingAssemblerV5
    lcg: LowLatencyCompiledGuard
    ack: AuditContestationKernel
    npb: NPB

    def select(self, x0_state, t_now, rule_id, context):
        if not self.lcg.check_auth(self.npb, t_now):
            return False, None, 'CERT_INVALID_OR_STALE'      # 证书失效 → fail-closed
        if not self.lcg.deontic_ok(x0_state, context):
            return False, None, 'DEONTIC_VIOLATION'          # 道义不变量破 → 拒绝
        d = self.lcg.check_scope(x0_state, context,
                                 self.npb.epoch_rev, policy_hash(self.npb))
        if d is ABSTAIN:
            self.ack.log_decision(ctx_hash(context), self.npb.id,
                                  guard_v(self.lcg), 'ABSTAIN', None)
            return ask_human(x0_state, context)              # 越界/不确定 → 问人/停机
        ok, traj, why = self.v5.select(x0_state, t_now, rule_id, context)
        self.ack.log_decision(ctx_hash(context), self.npb.id,
                              guard_v(self.lcg), why,
                              certified_margin(traj) if traj else None)
        return ok, traj, why
```

### 集成流水线（v5 → v6，三权分立 + 双时域）

```
慢时域（小时~天，离线）：
  人类审查会 ──批准条款(含理由/反例/失效条件)──▶ ERC.compile
     ├─ 编译 scope/auth/deontic（provenance 逐条校验）
     ├─ 范围-松弛对偶检查（放松必须用范围收缩支付）
     └─ 法定人数人类签名 ──▶ 签名 NPB ──▶ 分发（策略权重/证书同链签名）
  残余风险账本 R_ledger + 争议结论 ──▶ 下一轮审查（闭环）

快时域（每周期，1 kHz 控制环，预算 ≤ L_budget）：
  LCG.check_auth   O(1)（epoch 缓存：签名/过期/新鲜/只紧）
  LCG.deontic_ok   O(1)（接管通道心跳/来源标签/数据最小化）
  LCG.check_scope  O(1) 命中缓存；未命中 → g_fast O(d)
        ├─ 明确 in-scope ──▶ 放行至 v5 级联
        ├─ 明确 out-of-scope ──▶ ask_human/安全停机
        └─ 模糊带 ──▶ 令牌桶有余额？g_slow : ABSTAIN
  通过 ──▶ v5.select（FMPP→廉价门→VACK→BCK）──▶ 执行
  审计 ──▶ ACK.log_decision（哈希链 O(1)）

撤销/争议（事件驱动）：
  撤销 ──▶ epoch++ ──▶ 推+拉广播 ──▶ 全端缓存逻辑失效 ──▶ 窗口 ≤ Δ_rev+1 周期
  争议 ──▶ ACK.contest ──▶ 重放（redact PII）──▶ 人类复议 ──▶ 账本回流
```

## 3. 复杂度分析（增量更新）

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 | 实时性指标 |
|---|---|---|---|---|
| ERC.compile | 离线 O(\|clauses\|·d) | O(\|NPB\|) | 条款数 ~10² | 分钟~小时，人工签署 |
| LCG.check_auth | O(1) 均摊（epoch 缓存） | O(1) | 每 epoch 一次验签 | < 5 µs 命中，~40 µs 冷验签 |
| LCG.check_scope（快路径） | O(d) 或 O(depth) | O(1) | g_fast 决策表 | < 3 µs |
| LCG.check_scope（慢路径） | O(f_slow) | O(1) | 模糊带 p_amb | 仅 p_amb 概率触发，速率受限 |
| LCG.deontic_ok | O(1) | O(1) | 4 个不变量 | < 1 µs |
| 缓存命中 | O(1) | O(#ctx·epoch) | epoch 前缀失效 | 命中率 ~85% |
| ACK.log_decision | O(1) 追加 | O(#records) | 哈希链 | < 2 µs |
| ACK.revoke | O(#stations) 广播 | O(1) | 推+拉双通道 | 窗口 ≤ Δ_rev+1 周期 |
| **LCG 端到端增量** | — | — | 预算 50 µs | **P99 ~18 µs（远低于预算）** |
| **控制环总 P99（v6）** | — | — | 继承 v5 0.55 ms | **~0.57 ms** |

**通信开销**：NPB 签名包 ~2–4 KB/部署；epoch 广播 ~32 B；审计仅上报哈希/聚合（DP），原始上下文不出端；争议证据包按需拉取且 redact PII。

**确定性 WCET**：快路径全为 O(1)/O(d) 有界；慢路径被令牌桶硬限速，令牌耗尽即弃权 fail-closed——因此最坏执行时间 = 快路径 + 单次慢路径上限，可静态分析。这与 v5「准入异步、无硬 WCET」形成互补。

## 4. 正确性论证（增量更新）

### 引理 45（Conformal 范围守卫的边际覆盖与弃权率）

**陈述**：设校准样本 (x_i,c_i), i=1..n 与测试样本可交换，非一致性分数 s_i 取 q̂ = ⌈(n+1)(1−α)⌉/n 经验分位数，则对测试点 P(s ≤ q̂) ≥ 1−α（边际覆盖）；弃权率 ≈ α + P(OOD)。∎

**证明**：split conformal 标准秩论证。**诚实边界**：可交换性在分布漂移下失效；故与 v5 的 n_flow OOD 检测串联，漂移时由 OOD 判据优先 fail-closed。

### 引理 46（推测式守卫的期望延迟与最坏界）

**陈述**：若快分落入模糊带概率为 p_amb，则期望延迟 E[L] = L_fast + p_amb·L_slow；令牌桶速率 R_slow 保证单位时间慢调用 ≤ R_slow，故最坏每周期延迟 ≤ L_fast + L_slow（单次），且慢调用长期频率被 R_slow 约束。∎

**证明**：期望线性；令牌桶计数不变量。**工程含义**：用期望换吞吐，但最坏界仍硬。

### 引理 47（epoch 缓存失效的正确性）

**陈述**：缓存键含 epoch 前缀，撤销 epoch++ 后旧键不再命中；故撤销后首次查询必然走完整校验，不存在「撤销后仍命中旧许可」的窗口（除广播延迟 Δ_rev）。∎

**证明**：键空间按 epoch 分区，旧分区不可达。

### 定理 v6（可审查低延迟认证，总装）

**陈述**：在 v5 假设 (B1)~(B7) 及新增 (B8) 人类签署合法且签名不可伪造、(B9) 校准集与部署分布可交换（或 OOD 由 n_flow 兜底）下：
(i) **编译可靠性**：有效期内 Exec_v6 ⊆ A_norm ∩ Exec_v5（定理 9）；
(ii) **全局单调**：τ^6 ≥ τ^5 且 scope 只缩 ⇒ Exec_v6 ⊆ Exec_v5 ⊆ … ⊆ Exec_v29；局部放松仅经推论 9′ 以范围收缩支付，不破坏全局嵌套；
(iii) **实时性**：LCG 增量延迟 P99 ≤ L_budget，WCET 确定有界（引理 46 + 令牌桶）；
(iv) **撤销正确**：不合规窗口 ≤ Δ_rev + 1 周期（定理 11 + 引理 47）；
(v) **审计可重构**：哈希链防篡改、可重放（定理 12），但不推出规范正当性；
(vi) **七锚完备性保持**：门集合不变（v5 定理 8），LCG 是门外的范围/授权/道义包裹，非新轨迹门。

**证明**：(i)(ii) 由定理 9/推论 9′；(iii) 引理 46；(iv) 定理 11/引理 47；(v) 定理 12；(vi) 锚集不变 + 只紧。∎

**诚实声明**：(B8) 审查俘获/橡皮图章会使「合法签名」失真，形式化不可救；(ii) δ_norm（规范-形式化鸿沟）原理性不可测，定理只覆盖 A_norm；(iii) 弃权 fail-closed 在分布漂移时会显著降低可用性；(iv) 审计链只证明「发生过什么」，不证明「应当发生什么」；(v) 多辖区法规冲突时 NPB 可能无法同时满足，需人工裁决。

## 5. 实验设计与初步结果（仿真，单机；舰队/实机列入第 7 轮）

### 5.1 实验设计

- **平台**：MuJoCo 3.x + MJX 复用 v5 场景；新增「规范沙盒」：把规范条款写成结构化模板（范围/阈值/道义/失效），模拟审查会签署与撤销；范围守卫用蒸馏小模型 + split conformal；审计链用 SHA-256 哈希链。

- **指标**：规范条款覆盖率 ρ_scope、编译保守度 δ_comp（误拒合法）、conformal 覆盖/弃权率、LCG 增量延迟 P50/P99、WCET、撤销窗口 P99、审计重构成功率、争议解决时延、合规剧场未检出率（δ_norm 代理）、越界执行率、DP 预算。

## 7. 本轮最大风险（最终确认）

**一句话**：**合规剧场叠加规范-形式化鸿沟**——慢层把无法形式化的价值差异掩盖为一张「已批准」的签名证书，快层又忠实地执行被编译错的规范，审计链再把二者包装成可追溯的正当性；系统因此获得「伦理已审」的光环却实质偏离人类价值，而审查俘获与证书过期会放大这一偏差，且形式化定理对此结构性无能为力。
