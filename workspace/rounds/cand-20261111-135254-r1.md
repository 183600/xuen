# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感驱动循环·新一轮第 1 轮；本轮灵感：「模型蒸馏」×「实时性」）· RealDistill：把云端证书蒸馏成边端可实时租用的证书

> 第 54 轮已把技能组合推进为动作剖面 `α_S`、组合图 `G_S`、云边映射 `γ_ce` 与联合证书 `J`。但它默认了两个隐含前提：(i) 证书由云端离线评估，边端只做映射与查表；(ii) 证书一旦签发就长期有效。**模型蒸馏**打破 (i)：教师（云端仿真器 / 大规划器 / 鲁棒性评估器）保真但慢，学生（边端轻量网络）快但会丢能力；**实时性**打破 (ii)：执行有硬期限，证书是带失效时间的租约，而不是永恒真值。核心矛盾：**H22（保真度-时延失配）** 平均意义下蒸馏很准，但证书要求动作空间长尾上的**下界**；**H23（证书-时效失配）** 边端可能在证书过期或分布漂移后，仍以“实时”为由继续执行。

## 0. 直觉与动机

### 0.1 本轮思考轨迹

1. 回看第 54 轮：`α_S` 与 `ρ` 由结构化仿真在云端标定，`J` 的 soundness 依赖“边端查表即可”。但 UniBot 的闭环控制通常只有几十毫秒预算；边端既跑不动完整教师，也跑不动全动作空间的覆盖检查。证书的**计算成本**从未进入可行域。
2. 引入蒸馏的第一个诱惑是“把教师策略压成学生策略”。但第 54 轮的证书不只是一个策略：它包含动作剖面 `α`、鲁棒性谱 `ρ`、反向解释 `Explain`。所以要蒸馏的是**能力剖面与鲁棒性排序**，而不是单点动作；蒸馏产物必须带逐动作的保真度预算。
3. 实时性也不只是“更快”。真正的约束是**期限 + 新鲜度**：证书在 `t_issue` 签发，只能活 `h_valid`；执行必须在此窗口内完成；否则证书即便“算得对”也已经“说得旧”。这把证书从静态谓词变成**租约（lease）**。
4. 找到缺口：第 54 轮回答“组合在规划时刻是否 sound”；本轮要回答“边端能否在期限前完成认证，并在执行全程保持证书有效；若不能，如何优雅降级”。于是在 `J` 之外增加**蒸馏-实时联合证书 `J_RT`**。
5. 先做玩具推导：设学生用计算预算 `τ` 给出的鲁棒性区间半宽为 `w(τ)=w_0+c/τ`，期限 `D` 只允许 `τ_D`。若 `w(τ_D)>Θ_r`，则无论搜索多聪明，该技能都不可实时认证，只能回退或问云。可见实时性约束的是**证书分辨率**，不是单纯的推理速度。
6. 决策：把“蒸馏保真度”“随时证书”“租约时效”“期限感知组合”“漂移触发刷新”做成一条链，最后汇成 `J_RT`。这样，速度、保真、时效三者不再是事后指标，而是部署前的联合预算。

## 1. 六个直觉

**灵感 1（蒸馏证书，而不是蒸馏动作）**
直觉：普通 KD 对齐 logits / 动作，学生学到“教师此刻怎么做”，却学不到“教师为何在扰动下仍稳”。把第 53–54 轮的 `ρ` 与 `α` 当作**暗知识**一起蒸馏：学生要在动作空间上复现教师的覆盖剖面，在扰动维度上复现鲁棒性排序。蒸馏产物不是一条策略，而是一张**带保真度下界的能力证书**。

**灵感 2（随时证书 → 计算预算换分辨率）**
直觉：实时系统里最贵的不是“算一次”，而是“在期限内算到足够可信”。让学生具备**早退 / 多分辨率**结构：算得少时返回较宽的鲁棒性区间，算得多时区间收窄。证书因此是 `C_S(τ)`，分辨率 `r(τ)` 随预算单调下降。期限到来时，系统永远能拿到一个“当前最好且诚实”的答案，而不是超时崩溃。这把 anytime 算法从工程技巧提升为**证书语义**。

**灵感 3（证书是租约 → 时效与漂移必须显式入证）**
直觉：云端签发的证书描述的是“签发时分布下的能力”。边端执行期间分布会漂移、器件会发热、场景会换。证书应像租约：有签发时刻、有效期、漂移容忍度、违约回退链。执行窗口若超出有效期，或者在线漂移估计超过阈值，就必须续租、重蒸馏或回退。**“实时”不是拒绝过期的理由，而是要求更早发现过期。**

**灵感 4（期限感知组合 → 组合图要带时间维）**
直觉：第 54 轮的 `G_S` 只问动作兼容，不问“这条边能否在剩余期限内完成认证与执行”。给每条边加三元权重 `(ℓ_exec, ℓ_cert, h_lease)` 后，组合规划变成**时变最短路**：一条路径不仅总成本要低，还要在每个技能执行的时刻都落在该边证书的租约内。原先可部署的路径，可能因为中间某张证书到期而整体不可行；这解释了许多“离线最优、线上崩”的现象。

**灵感 5（漂移触发刷新 → 用期限余量调度重蒸馏）**
直觉：在线刷新不能拍脑袋。每个控制周期都有剩余余量 `σ(t)=D-elapsed-remaining`。余量大时，可以问云、局部重蒸馏或收紧区间；余量小时，只能复用或回退保守控制器。把刷新策略定义为在 `(保真度风险, 超时风险)` 上的调度问题，就能避免“为了刷新而错过期限”，也避免“为了赶期限而带着过期证书硬跑”。

**灵感 6（金字塔扩展 → 蒸馏层 𝔻 与实时层 ℝ）**
直觉：在第 54 轮的动作-鲁棒性金字塔 `𝕃×𝔸` 上再叠两层：`𝔻` 描述教师到学生的能力压缩（保真度剖面、区间证书），`ℝ` 描述证书从签发到执行的时间演化（租约、余量、回退）。跨层传递的联合证书 `J_RT` 必须同时携带 `ρ_lo, φ_lo, r, lease, latency, fallback_chain`，否则“云端 sound”与“边端实时”之间仍有一条无人负责的缝。

## 2. 形式化定义（增量：定义 121–126）

**定义 121（蒸馏保真度剖面，DFP）**
教师 `T=(π_T,α_T,ρ_T,E_T)`，学生 `S=(π_S,α_S,ρ_S,E_S)`。在核心动作集 `A_core`（来自第 54 轮 `A_cert`）上定义逐动作保真度
`φ_{T→S}(a)=1-d_A(α_T(a),α_S(a))`，其中 `d_A` 归一化到 `[0,1]`；鲁棒性保持 `κ_ρ(d)=ρ_S^{lo}(d)/max(ρ_T(d),ε)`。证书取**逐动作下界** `φ_lo=inf_{a∈A_core} φ_{T→S}(a)`，而不是平均值。`Φ=(φ_{T→S},φ_lo,κ_ρ)` 称为保真度剖面。

**定义 122（随时证书，ACR）**
给定计算预算 `τ`，学生证书
`C_S(τ)=({[ρ_S^{lo}(τ,d),ρ_S^{hi}(τ,d)]}_d, φ_lo(τ), A_cert)`，
分辨率 `r(τ)=max_d (ρ_S^{hi}(τ,d)-ρ_S^{lo}(τ,d))`。要求**单调性**：`τ_1≤τ_2 ⇒ r(τ_1)≥r(τ_2)` 且 `φ_lo(τ_1)≤φ_lo(τ_2)`。实时系统在期限 `D` 内只能选 `τ≤τ_D`。

**定义 123（实时证书租约，RTCL）**
租约 `L=(C_S(τ), t_issue, h_valid, ε_drift, D, owner)`。在时刻 `t` 有效当且仅当
```
t_issue ≤ t ≤ t_issue + h_valid  ∧  drift(t) ≤ ε_drift
```
且 `min_d ρ_S^{lo}(τ,d) ≥ ρ_min`、`r(τ) ≤ Θ_r`。执行窗口 `[t_start, t_start+D]` 必须被租约覆盖，否则必须续租或回退。

**定义 124（期限感知可行组合，DAF）**
时变技能图 `G_S^t=(V,E,w_t)`，边权 `w_t(i,j)=(ℓ_exec, ℓ_cert, w_fid, h_lease)`。路径 `P=⟨e_1,...,e_k⟩` **期限可行**当且仅当
```
Σ_k ℓ_exec(e_k) + Σ_k ℓ_cert(e_k) ≤ D
∧ ∀k: t_k + ℓ_exec(e_k) ≤ t_issue(e_k) + h_valid(e_k)
∧ min_k φ_lo(e_k) ≥ Θ_φ
```
其中 `t_k` 为第 k 个技能的实际开始时刻。注意第二式使问题不再可交换：**先做谁**会改变证书是否过期。

**定义 125（漂移触发重蒸馏，DTR）**
在线不一致 `δ_disagree(x)=d_A(π_S(x),π_T^{shadow}(x))`，期限余量 `σ(t)=D-elapsed(t)-remaining_p50(t)`。触发条件
`δ_disagree>τ_D ∨ drift(t)>ε_drift ∨ σ(t)<σ_min`。
动作集 `{reuse, refine(τ), query_teacher, fallback_conservative}`；策略最小化
`risk = P(unsound) + λ·P(miss_deadline)`，约束为 `latency(action) ≤ σ(t)`。

**定义 126（蒸馏-实时联合证书，DRT-J）**
`J_RT=(ρ_lo, A_cert, φ_lo, r, L, latency, Ω, evidence)`，其中 `Ω` 为回退链 `⟨student, teacher_shadow, conservative⟩`。部署条件：
```
dom_J(T)=in ∧ φ_lo ≥ Θ_φ ∧ r ≤ Θ_r
∧ L 覆盖整个执行窗口 ∧ latency ≤ D
```
`evidence` 至少包含：长尾动作采样日志、conformal 覆盖报告、租约到期/漂移反例、端到端时延分布。**`J_RT` 与第 54 轮 `J` 合取使用：`J` 保证规划时刻 sound，`J_RT` 保证边端执行时刻 still sound。**

## 3. 关键算法 伪代码

### IP-121 DAC（Distilled Action-profile Certificate）

```python
def distill_certificate(T, A_core, conformal_delta):
    # 动作空间加权：长尾 + 安全关键动作上采样
    S = train_student(T, loss=weighted_KD + fidelity_penalty + robustness_rank)
    F = {}
    for a in sample(A_core, mode='risk_weighted'):
        F[a] = 1.0 - d_A(T.alpha(a), S.alpha(a))
    phi_lo = conformal_lower_bound(F.values(), delta=conformal_delta)
    region_err = {cell: max(F[a] for a in cell) for cell in partition(A_core)}
    return S, DFPCert(alpha_T=T.alpha, alpha_S=S.alpha,
                      phi_lo=phi_lo, region_err=region_err)
```

### IP-122 ACD（Anytime Certified Distillation）

```python
def certify_anytime(S, x, deadline):
    best = None
    for exit_k in S.exits_by_cost():          # τ 递增
        tau = exit_k.cost
        if tau > deadline: break
        rho_lo, rho_hi = exit_k.interval(x)
        r = max(rho_hi[d] - rho_lo[d] for d in rho_lo)
        best = (rho_lo, rho_hi, r, tau)
        if r <= Theta_r:                       # 分辨率达标即停
            return ('ok', best)
    return ('degrade', best)                   # 最快但最宽，交回退链
```

### IP-123 RTCL（Real-Time Certificate Lease）

```python
def lease_check(L, t, drift_est):
    if t > L.t_issue + L.h_valid:      return ('expired',)
    if drift_est > L.epsilon_drift:    return ('drifted',)
    if L.r > Theta_r:                  return ('resolution',)
    if min(L.rho_lo.values()) < rho_min: return ('robustness',)
    return ('ok',)
```

### IP-124 DAF（Deadline-Aware Feasibility）

```python
def plan_deadline(G, task, t0, D):
    # 状态=(skill, t, lease_state)，优先级=风险 + 剩余时间
    pq = [(heuristic(task, t0), (root, t0, 'fresh'))]
    while pq:
        _, (i, t, ls) = heappop(pq)
        if i == task.goal: return ('ok', reconstruct(i))
        for j, w in G.neighbors_time_dependent(i, t):
            t_arr = t + w.exec
            if t_arr + w.cert > D:            continue
            if not lease_covers(w.lease, t, t_arr): continue
            if w.phi_lo < Theta_phi:          continue
            heappush(pq, (risk(w) + heuristic(task, t_arr), (j, t_arr, 'fresh')))
    return ('infeasible', 'deadline_or_lease')
```

### IP-125 DTR（Drift-Triggered Refresh）

```python
def refresh_policy(state, D):
    sigma = D - state.elapsed - state.remaining_p50
    if state.drift > eps or sigma < sigma_min:
        if sigma > tau_query:   return query_teacher()
        if sigma > tau_refine:  return refine(state.skill)
        return fallback_conservative()
    if state.disagree > tau_D:  return refine(state.skill)
    return reuse()
```

### IP-126 DRTJ（Joint Real-Time Certificate）

```python
def joint_rt_certificate(seq, distiller, D, Theta_phi, Theta_r):
    t, parts = 0.0, []
    for s in seq:
        S, F = distiller[s]
        tau = min(D - t, s.tau_max)
        status, C = certify_anytime(S, s.context, tau)
        if status != 'ok':
            return ('reject', 'resolution', C)
        L = issue_lease(C, drift_bound=s.drift, D=D - t)
        if lease_check(L, t, s.drift)[0] != 'ok':
            return ('reject', 'lease', L)
        parts.append((s, C, L))
        t += C.latency + s.exec_cost
    phi = min(F.phi_lo for s in seq)
    if phi < Theta_phi:
        return ('reject', 'fidelity', phi)
    return ('ok', DRTJoint(parts, phi, Omega=['student','shadow','conservative']))
```

## 4. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| DAC | O(N·|A_core| + calibration) | O(|A_core|) | conformal 覆盖、尾部上采样 |
| ACD | O(K_exit·|A|) | O(|A|) | 分辨率单调、预算可截断 |
| RTCL | O(1) | O(1) | 租约窗口、漂移阈值 |
| DAF | O(|V| log |V| + |E|)（时变边） | O(|V|+|E|) | 时间维展开、不可交换性 |
| DTR | O(1)/控制周期 | O(1) | 余量非负、回退阶梯 |
| DRTJ | O(|seq|·|A|) | O(|seq|·|A|) | 联合预算闭合 |

**正确性定理（Distilled Real-Time Certificate Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** conformal 给出 `P(∀a∈A_core, φ_{T→S}(a)≥φ_lo) ≥ 1-α`；**(A30)** 在租约期 `h_valid` 内真实漂移不超过 `ε_drift`，或漂移检测器以概率 `≥1-β` 触发；**(A31)** 调度器满足 `P(ℓ_cert+ℓ_exec+ℓ_fallback ≤ D) ≥ 1-γ`。
则
```
P(success ∧ on_time) ≥ 1 - Σ_d(1-ρ_min(d)) - α - β - γ
                         - P(r(τ_D) > Θ_r) - P(lease 在执行中途过期)
```
关键：`α` 来自保真度下界，`β` 来自租约/漂移监控，`γ` 来自实时调度；每一项都可独立测量，而不是被“平均精度”掩盖。

## 6. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 平均保真掩盖尾部失效 | 高 | 风险加权采样 + conformal 下界 + 尾部红队 |
| 期限压力导致低分辨率证书被误用 | 高 | `r≤Θ_r` 硬门槛 + 回退阶梯 + 审计日志 |
| 租约续期抖动 / 频繁问云 | 中 | 余量调度 + hysteresis + 冷启动锚点 |
| 漂移检测漏报 | 高 | 影子教师 + 分布外探针 + 保守默认 |
| 时变组合搜索爆炸 | 中 | 时间分层剪枝 + 证书窗口哈希 |

## 7. 本轮最大风险

**一句话**：把证书蒸馏成边端“随时证书 + 租约”能把云端 sound 延伸到实时执行，但其 soundness **三重依赖保真度下界的尾部覆盖、漂移检测的及时性、以及期限压力下不回退到低分辨率证书**；一旦尾部欠采样使 `φ_lo` 虚高、或为了赶期限系统性使用过期/过宽证书，系统会在“实时通过”的假象里执行一张早已失效的能力承诺，故必须以 **conformal 尾部下界 + 租约硬过期 + 期限余量回退阶梯** 三重护栏，宁可降级，绝不把“算得快”当作“仍然 sound”。

# 第 55 轮产物 · 创新点清单 v32：RealDistill（DAC×ACD×RTCL×DAF×DTR×DRTJ）

> 承接第 54 轮产物 v31。v31 解决了「技能组合在动作空间与云边协同下是否 sound」；v32 追问「**这张证书能否被边端在期限前算出来，并在执行全程保持有效**」。本轮把「模型蒸馏」落成**证书蒸馏与保真度下界**，把「实时性」落成**随时证书、租约与期限感知组合**：
> - **DAC（Distilled Action-profile Certificate）**：蒸馏 `α,ρ,Explain`，产出逐动作保真度下界 `φ_lo`；
> - **ACD（Anytime Certified Distillation）**：计算预算 `τ` 换证书分辨率 `r(τ)`，期限到则返回最诚实的当前解；
> - **RTCL（Real-Time Certificate Lease）**：证书带签发时刻、有效期与漂移容忍度；
> - **DAF（Deadline-Aware Feasibility）**：时变技能图上的期限 + 租约可行路径；
> - **DTR（Drift-Triggered Refresh）**：用期限余量调度重蒸馏 / 问云 / 回退；
> - **DRTJ（Joint Real-Time Certificate）**：把保真、分辨率、租约、时延、回退链合成一张联合证书。
>
> IP 编号：IP-121~IP-126（共 6 个新增）；升级 IP-115/116/117/118/120，使动作剖面、组合图、云边协同与联合证书都携带蒸馏保真度与时效字段。

## 0. 核心 IP 设计

| 编号 | 名称 | 类型 | 关键改进 |
|---|---|---|---|

## 2. 关键算法 伪代码

### IP-121 DAC

```python
def distill_certificate(T, A_core, conformal_delta):
    S = train_student(T, loss=weighted_KD + fidelity_penalty + robustness_rank)
    F = {a: 1.0 - d_A(T.alpha(a), S.alpha(a))
         for a in sample(A_core, mode='risk_weighted')}
    phi_lo = conformal_lower_bound(F.values(), delta=conformal_delta)
    region_err = {cell: max(F[a] for a in cell) for cell in partition(A_core)}
    return S, DFPCert(T.alpha, S.alpha, phi_lo, region_err)
```

### IP-122 ACD

```python
def certify_anytime(S, x, deadline):
    best = None
    for exit_k in S.exits_by_cost():
        tau = exit_k.cost
        if tau > deadline: break
        rho_lo, rho_hi = exit_k.interval(x)
        r = max(rho_hi[d] - rho_lo[d] for d in rho_lo)
        best = (rho_lo, rho_hi, r, tau)
        if r <= Theta_r: return ('ok', best)
    return ('degrade', best)
```

### IP-123 RTCL

```python
def lease_check(L, t, drift_est):
    if t > L.t_issue + L.h_valid:        return ('expired',)
    if drift_est > L.epsilon_drift:      return ('drifted',)
    if L.r > Theta_r:                    return ('resolution',)
    if min(L.rho_lo.values()) < rho_min: return ('robustness',)
    return ('ok',)
```

### IP-124 DAF

```python
def plan_deadline(G, task, t0, D):
    pq = [(heuristic(task, t0), (root, t0, 'fresh'))]
    while pq:
        _, (i, t, _) = heappop(pq)
        if i == task.goal: return ('ok', reconstruct(i))
        for j, w in G.neighbors_time_dependent(i, t):
            t_arr = t + w.exec
            if t_arr + w.cert > D:                    continue
            if not lease_covers(w.lease, t, t_arr):   continue
            if w.phi_lo < Theta_phi:                  continue
            heappush(pq, (risk(w) + heuristic(task, t_arr),
                          (j, t_arr, 'fresh')))
    return ('infeasible', 'deadline_or_lease')
```

### IP-125 DTR

```python
def refresh_policy(state, D):
    sigma = D - state.elapsed - state.remaining_p50
    if state.drift > eps or sigma < sigma_min:
        if sigma > tau_query:  return query_teacher()
        if sigma > tau_refine: return refine(state.skill)
        return fallback_conservative()
    if state.disagree > tau_D: return refine(state.skill)
    return reuse()
```

### IP-126 DRTJ

```python
def joint_rt_certificate(seq, distiller, D, Theta_phi, Theta_r):
    t, parts = 0.0, []
    for s in seq:
        S, F = distiller[s]
        status, C = certify_anytime(S, s.context, min(D - t, s.tau_max))
        if status != 'ok':
            return ('reject', 'resolution', C)
        L = issue_lease(C, drift_bound=s.drift, D=D - t)
        if lease_check(L, t, s.drift)[0] != 'ok':
            return ('reject', 'lease', L)
        parts.append((s, C, L))
        t += C.latency + s.exec_cost
    phi = min(F.phi_lo for s in seq)
    if phi < Theta_phi:
        return ('reject', 'fidelity', phi)
    return ('ok', DRTJoint(parts, phi,
                           Omega=['student', 'shadow', 'conservative']))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| DAC | O(N·|A_core| + calibration) | O(|A_core|) | conformal 覆盖、尾部上采样 |
| ACD | O(K_exit·|A|) | O(|A|) | 分辨率单调、预算可截断 |
| RTCL | O(1) | O(1) | 租约窗口、漂移阈值 |
| DAF | O(|V| log |V| + |E|)（时变边） | O(|V|+|E|) | 时间维展开、不可交换性 |
| DTR | O(1)/控制周期 | O(1) | 余量非负、回退阶梯 |
| DRTJ | O(|seq|·|A|) | O(|seq|·|A|) | 联合预算闭合 |

**正确性定理（Distilled Real-Time Certificate Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** conformal 给出 `P(∀a∈A_core, φ_{T→S}(a)≥φ_lo) ≥ 1-α`；**(A30)** 在租约期 `h_valid` 内真实漂移不超过 `ε_drift`，或漂移检测器以概率 `≥1-β` 触发；**(A31)** 调度器满足 `P(ℓ_cert+ℓ_exec+ℓ_fallback ≤ D) ≥ 1-γ`。
则部署成功且按时的下界为：
```
P(success ∧ on_time) ≥ 1 - Σ_d(1-ρ_min(d)) - α - β - γ
                         - P(r(τ_D) > Θ_r) - P(lease 在执行中途过期)
```
关键：**保真度下界可测**、**租约时效可查**、**实时调度可审计**；三者不允许互相“借用”可信度。

**与第 54 轮的关系**：
- `J`（规划时刻 sound）与 `J_RT`（执行时刻 still sound）必须**合取**；
- `A_cert` 中的 `A_core` 必须同时满足教师覆盖与学生可达：`A_core ⊆ A_c ∩ A_e ∩ A_S`；
- 第 54 轮的 `γ_ce` 映射后，先做 `certify_anytime`，再做 `lease_check`，最后才进入 `J_RT`。

## 5. 本轮最大风险

**一句话**：把证书蒸馏成边端“随时证书 + 租约”能把云端 sound 延伸到实时执行，但其 soundness **三重依赖保真度下界的尾部覆盖、漂移检测的及时性、以及期限压力下不回退到低分辨率证书**；一旦尾部欠采样使 `φ_lo` 虚高、或为了赶期限系统性使用过期/过宽证书，系统会在“实时通过”的假象里执行一张早已失效的能力承诺，故必须以 **conformal 尾部下界 + 租约硬过期 + 期限余量回退阶梯** 三重护栏，宁可降级，绝不把“算得快”当作“仍然 sound”。
