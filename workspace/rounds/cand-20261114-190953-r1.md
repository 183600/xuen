# 第 75 轮（承接第 74 轮「SENTGAUGE-RAS 哨兵审计闭环」IP-303~309；灵感循环第 1 轮；本轮灵感：「低成本方案」×「语义建图」）

> R74 把审计做成 anytime-valid 哨兵，把 R73 的「自信地组合一个错误世界」改造成「诚实地发现并退出错误世界」。但 R71–R74 有一条从未被写进定义的隐含前提：**审计本身是昂贵的**。SEAL 校准、conformal 覆盖、逐模块证书、每帧 e-process、第 0 层物理包络、车队级三方复现——每加一层可信度，就加一层成本。于是体系出现一个反讽：**越可信越难部署，越部署越难维护**；在实验室里它证明了「安全侧只增不减」，在真实机器人队列与低成本平台上，它很可能先死于成本，而不是死于不安全。R74 的 C4 甚至把「SEAL 校准集是否代表真实部署分布」重新变成隐式地基——这正是「昂贵假设」的典型：用一次性的、不可摊销的校准，去买无限时程的可信。
>
> 本轮两个灵感正好从两个方向补同一个缺口：
> - **低成本方案** → 把「成本」提升为与不确定度**并列的一等公民**，引入**节俭计量（frugal metrology）**：不是「先保证安全再优化成本」，而是「在固定审计预算下最大化可审计的安全」。核心机制是**摊销**——昂贵的一次性核验摊到多次复用上，运行时只花廉价的对账；以及**贷款式先验**——现在支取不确定度缩减，但必须带着可审计的债务与还款计划。
> - **语义建图** → 语义地图是机器人界最典型的低成本先验：一次 RGB-D 扫描 / 众包 / 仿真即可产出可跨回合、跨本体复用的离散标签地图，并且能在**未观测区域**降低不确定度——这是任何纯在线感知都做不到的。但它也能在**错误的地方静默地降低不确定度**：**先验诱导的认知坍塌（prior-induced epistemic collapse）**。更阴险的是，先验会引导机器人**去看先验说重要的地方**，于是观测与先验相关、核验被先验污染——**自确认先验（self-confirming prior）**。
>
> 核心命题：**不再问「系统可信吗」，而问「可信性能否被摊销——使先验像贷款一样被使用：现在支取不确定度缩减，但每笔支取都带来源/时效/分类/分歧四重账，且必须在有限时程内以独立观测还款；未背书的支取在结构上被禁止」？** 把 SENTGAUGE 重构为 **SEMGAUGE-RAS**（SEMantic-prior, amortized, GAuged evidence metrology for RAS）——**先验摊销计量代数**。
>
> IP 编号：IP-310~316。理论姿态延续：**先验 = 外部证据模块，成本 = 单调记账轴**；新层是旧层的严格泛化（无先验 + 零成本审计退化为 SENTGAUGE），安全侧只增不减，退化链逐指令等价。

## 0. 直觉与动机

**灵感 1（语义地图 = 被压缩、可复用、跨本体的「外部证据」，不是地面真值）**
直觉：一张语义地图本质上是**过去观测的有损压缩**：它把「某个格子曾是什么、哪里可通行、哪个物体可抓」压成离散标签，从而让未来的机器人不必重新观测就能行动。压缩带来两个直接后果：(a) **低成本**——构建一次，复用无数次，Omni 级摊销；(b) **信息丢失**——它丢掉了「这条标签有多可信、什么时候观测的、由谁观测的、在什么分类体系下观测的」。现有语义建图把 (b) 当成实现细节，但计量学必须把 (b) 变成一等公民。关键洞察：**地图的价值恰好在它无法被验证的地方最高**——已观测区域可直接用实时感知覆盖，未观测区域才需要先验；而未观测区域恰恰没有观测来核验先验。这是**先验价值-可验证性悖论**，也是本轮全部困难的结构根源。出路只有一条：**信任不能就地核验，只能跨格转移**——在同一语义类、同一来源的「块（block）」内，用少量抽样核验的结果，凭**交换性假设**把信任转移给同块所有格子。转移是便宜的（抽样 O(1) 摊到 O(|B|)），但它把风险从「单格未核验」换成了「整块交换性假设失效」——这正是必须被显式计量与哨兵化的东西。

**灵感 2（低成本 = 先验是贷款，不是礼物）**
直觉：金融里没有免费的钱，只有利息不同的钱。先验也一样。任何「凭空降低不确定度」的先验，都是在向未来借可信度：它现在让你更自信，但这份自信需要在未来被观测兑付。于是定义**先验债务（prior debt）**与**信任储库（trust reservoir）**：每个语义块有一笔有限的信任额度 T(B)，支取一次就消耗一次；只有后续观测与先验对账成功才**还款**、额度回升；对账持续失败则**整块违约**，额度清零、整块回退为「未知」（而不是回退为先验标签）。这条规则把 R74「检不出检不出」升级为「**借得起但还不上就必须破产**」：系统不能靠一直使用先验来维持自信，必须先有还款能力。低成本的正确含义由此变为：**用抽样核验 + 块级转移，把「逐格核验」的 O(|M|) 成本压到 O(|B|·n_sample)，同时用破产机制兜住交换性失效**。

**灵感 3（成本轴：从「性能-安全」二维权衡，升为「成本-安全」帕累托）**
直觉：R73/R74 的组合代数只有不确定度轴 u 与有效域 D、否决 I⊥；成本只以 WCET 出现，而且被当作硬约束而不是优化对象。可部署性要求把成本作为**与 u 并列的偏序轴**：一个组合方案 A 节俭支配（frugally dominate）B，当且仅当 u_A ≤ u_B 且 cost_A ≤ cost_B。有了这条轴，(i) 「引入先验是否值得」不再是哲学问题而是**帕累托改进判定**；(ii) 「热替换」不只看等价性还要看成本是否退化；(iii) 组合定理要加一条**成本单调性**：组合不得凭空降低总成本（否则审计可被「假装便宜」绕过）。这把 R74 的 C3（认证成本 O(系统)→O(模块)）从单点主张扩展为一条贯穿全体系的**成本守恒律**。

**灵感 4（车队摊销 = 复利与共模：摊销放大收益，也放大同一笔坏账）**
直觉：一张语义地图被 N 台机器人共享时，核验成本摊到每台是 c/N——复利。但同一块错误也被 N 台同时继承：如果先验是坏的，N 台会在同一时刻、同一地点、以同一方式「自信地」犯错，这就是**共模失效（common-mode failure）**。更糟的是，如果车队用「多数机器人观测与地图一致」来给地图投票，那么一个被投毒的初始种子会通过共识自我放大成「事实」。因此车队摊销必须显式区分**独立来源根（independent provenance roots）**与**相关来源**：共模风险的界不能随 N 消失，只能随独立根数 k 改善。低成本不是把风险除以 N，而是把成本除以 N、**同时把风险按 k 记账**。

**灵感 5（节俭主动感知：核验预算的 ROI 分配，且必须留独立探针）**
直觉：既然核验是抽样，就必须决定「抽哪里」。朴素做法是抽「最不确定 / 最影响任务」的地方——但先验恰好会影响「哪里看起来重要」，于是机器人会去抽先验自己指出的地方，观测被先验选择性地确认，形成**自确认回路**。正确做法是像审计员一样**分层抽样**：大部分预算按 ROI（Δu/成本）分配给高风险块，但强制保留一个与先验无关的**独立探针配额 ρ**（随机 / 覆盖率驱动，而非显著性驱动）。ρ 的作用不是提高平均精度，而是给「交换性假设本身」提供一个不被先验污染的检验通道——这是整套低成本方案里唯一不能省的那笔钱。这直接给出可证伪主张 C5：**带独立探针的节俭先验审计，在同等成本下安全显著优于「总是全量核验」「朴素先验复用」「先验引导核验」。**

**灵感 6（分类学是新的标定：语义标签本身会漂移）**
直觉：语义地图的「语义」依赖一个分类体系（ontology）。训练时的类别（椅子/桌子/门）与部署现场的类别（手术台/病床/隔离门）可能不同；同一个词在不同机构、不同文化下含义不同（与 R74 的 NCM 约定同构）。因此语义先验除了来源/时效/分歧，还必须有一个 **u_onto（分类学错配）** 分量：开放词表下的未知类必须**保守化**（回退为几何/占据先验，而非强行套用最相似标签）。这把 R74「约定 κ 是第三类先验」推广为「**本体映射 φ 是第四类先验**」，且同样需要版本化、预算化、可回滚。

## 1. 形式化定义（增量：定义 398–413）

**定义 398（SEMGAUGE-RAS 总览与七不变式）** SEMGAUGE-RAS = (SMP, TPM, CPA, FAP, FAM, J_FRUGAL, SENTGAUGE†)。七不变式：
(i) **契约完整性**：先验亦为模块，实例化完整 EC（继承 R73 定义 367）；
(ii) **组合单调性**：u 轴经 CPA 校验，无「凭空变好」（继承引理 34）；
(iii) **反作用通道完备**：先验模块必须声明 χ_R（可为平凡），融入 ΣREFLEX（继承）；
(iv) **主张绑定**：组件 ∈ {C1,…,C5, 工程附件}，附件不进核心认证路径；
(v) **严格退化链**：先验失效 → 先验块撤销 → 系统逐指令退化到无先验版本（继承 R74 定理 29）；
(vi) **成本单调性**：任何组合路径的成本按可加/上界传播，不允许「审计后成本为负」或「组合凭空降成本」；
(vii) **先验债务闭合**：任何被先验缩窄的决策，其信任要么来自已核验样本、要么来自未违约的交换性块、要么不被允许（默认「未知」，非补偿）。

**定义 399（语义先验模块 SMP）** M_sem = (C, O, A, φ, prov, t0, onto)：
- C：离散空间单元（格子/房间/物体节点）集合；
- O：每单元的离散先验 p(o | c)（占据、类别、可通行性、可抓性）；**负证据** n(c) = P(空/不可达) 亦为输出；
- A：可供性标签（抓/推/坐/穿越）；
- φ：本体映射（部署现场词表 → 训练词表，含 unknown）；
- prov：来源树（传感器/日期/算法/标定链哈希），支持多源合并；
- t0：构建时刻（用于时效衰减）；
- onto：分类体系版本。
SMP 作为离散证据类型进入 MReg，输出 (prior, u_sem, prov, D_sem)，其中 D_sem 声明「哪些区域/类别/时段这张图被允许参与缩窄」。

**定义 400（先验不确定度五分量 u_sem）**
u_sem² = u_prov² + u_stale² + u_change² + u_onto² + u_disagree²；
- u_prov：来源可信度（传感器质量、标定链完整性、构建算法证书）；
- u_stale：时效项（t − t0 的衰减 + 环境变化率估计）；
- u_change：活体对账残差（当前观测 vs 先验在同一格/同类块上的差异）；
- u_onto：本体错配（φ 落在 unknown 或低置信映射）；
- u_disagree：车队跨源分歧（同一块不同来源标签的冲突度）。
五分量各有独立追溯链 τ_i；与 DPEM 六分量、DMEM 四分量、OEM 五分量同构：**先验不是「一个标签」，而是「一组条件化的物理/统计失效机制」**。

**定义 401（信任储库与先验债务 TPM）** 每个语义块 B（= 同一来源、同一本体类、空间连通的单元集合）维护信任质量 T(B) ∈ [0,1] 与债务 D(B)：
- **支取（cash-in）**：使用先验缩窄某格的 u，消耗 trust_cost(c) = w(c)·Δu；
- **还款（repay）**：后续独立观测与先验一致，按对账证据回填 T(B)；
- **违约（default）**：块级 e-process（复用 R74 CAS）在对账残差上越界 ⇒ T(B) ← 0，整块回退为「未知」（u = u_null，即从几何/占据先验重新起步），并记入撤销日志。
规则：**T(B) 是块级有限资源；不允许跨块挪用，不允许无债务的支取**。这把「先验复用」变成有借有还的会计过程，而不是无限透支的信念。

**定义 402（先验支取规则与先验单调性）** 对格 c ∈ B，仅当
T(B) ≥ τ_T ∧ u_sem(c) ≤ τ_sem ∧ c ∈ D_sem ∧ 对账 audit 通过
时允许支取：
u_cash = max(u_live ∧ u_0, f(u_0, T(B), α_block))，
即缩窄受块级 conformal 覆盖约束；任何条件不满足 ⇒ **null prior**：先验不提供信息（不是提供错误信息）。关键非对称：**先验只能安全地缩窄「被背书」的格，未背书格一律保守化**。

**定义 403（成本感知组合代数 CPA）** 证据对象扩展为 Ev = (u, cost, D, I⊥, T)：
- **SER（A∘B）**：u_out ≥ u_A + L_B·u_A；cost_out ≥ cost_A + cost_B（成本只增）；
- **PAR（A⊕B）**：一致审计通过且缩窄时 u_out = fuse，cost_out ≥ cost_A + cost_B + c_audit（审计成本显式计入）；
- **VETO（A⊠B）**：任一否决 ⇒ 整体否决；cost_out ≥ max 分支成本。
**成本单调引理**：不存在由 SER/PAR/VETO 构成的路径使 cost_out < Σ 分支成本（同 R73 引理 34 的对偶）。

**定义 404（节俭支配与节俭前沿）** A ≽_f B ⇔ u_A ≤ u_B ∧ cost_A ≤ cost_B（Pareto 偏序）。**节俭前沿（Frugal Front）** = 不可被支配的方案集。先验引入是一次**帕累托改进**当且仅当新方案落在前沿内侧；否则必须显式声明「用安全换成本」还是「用成本换安全」，不得静默。

**定义 405（先验单调性 / 安全单向）** 将 SMP 插入一个已合法的 MReg：
- 若 SMP 处于「null / 违约」态，系统逐指令等价于无先验系统（安全不减）；
- 若 SMP 处于「背书」态，仅当定义 402 条件满足时缩窄，否则保持 u_0（安全不减）。
⇒ 任何先验插入都不增加最坏情形风险；先验只可能在期望意义下获益。**证明见引理 43。**

**定义 406（节俭主动感知 FAP）** 在核验预算 b 下分配抽样：
max_{x} Σ_B x_B·(Δu_B / cost_B)
s.t. Σ_B x_B·cost_B ≤ b，Σ_B x_B ≥ ρ·(b / cost_unit)（独立探针配额），x_B ∈ {0,1,…}。
- ROI 项负责效率；**独立探针 ρ** 负责防止「先验选择观测 → 观测确认先验」的自确认；
- 求解为 0/1 背包 + 分层抽样，可 anytime 中断（下一轮预算继续）。
**关键**：ρ 是与先验无关的审计通道，不是普通探索；它检验的不是「标签对不对」，而是「块交换性还成不成立」。

**定义 407（车队摊销与共模 FAM）** N 台机器人共享 SMP。每台摊销成本 c_robot = c_build/N + c_verify/N + c_runtime；但共模风险按**独立来源根数 k** 记账：
P_common ≤ p_bad/k + p_shared，
其中 p_shared 为所有根共享的隐变量（同一传感器批次、同一构建算法、同一投毒源）导致的不可约共模概率。规则：**共识只能由独立根投票，相关来源合并计一票**（防止共识俘获；见定义 409）。

**定义 408（本体计量 OM）** 本体映射 φ: K_deploy → K_train ∪ {unknown} 版本化；u_onto = H(φ(k)) + 1[φ(k)=unknown]·c_unknown。未知类不得强行映射为最相似类；必须回退到几何/占据先验，并触发 C5 的保守处置分支。

**定义 409（先验威胁面 AIC-PRIOR）** 六类威胁：
① 地图投毒（注入假障碍/假空区）；② 陈旧地图（布局已变）；③ 重放攻击（旧版本冒充新版本）；④ 分类学伪装（把危险物件映射为无害类）；⑤ 共识俘获（相关来源冒充独立多数）；⑥ **自确认致盲**（先验引导观测，观测只去核验先验指向处，未覆盖处永远不被检验）。
防线：来源签名 + 时效 e-process + 独立根投票 + 独立探针配额 ρ + 块级撤销 + 单源不定案（继承 R74 身份否决）。

**定义 410（节俭证书 J_FRUGAL）** J_FRUGAL = J_SENT ⊗ CostLedger ⊗ DebtLedger ⊗ RevokeLog：
- CostLedger：每模块成本、核验成本、摊销后每机成本；
- DebtLedger：每块 T(B)、未还债务、还款记录；
- RevokeLog：每次撤销的时间、块、触发残差、恢复链。
Valid(J_FRUGAL) ⇒ (i) J_SENT 有效；(ii) 成本账闭合（Σ 支取成本 ≤ 预算）；(iii) 债务账闭合（无未背书支取）；(iv) 撤销链完整可重放。

**定义 411（MB5 最小基准）** 成本-安全帕累托最小基准：3 个场景（静态办公室 / 变动仓库 / 跨本体迁移），对比 5 组基线（无先验 / 朴素先验 / 全量核验 / ROI 核验无独立探针 / SEMGAUGE），≤3h 单卡复现，预注册脚本 + 固定种子 + 密封集 SEAL-MB5。

## 3. 推导

**引理 42（u_sem 的条件叠加性与块内可分离）** 给定 (prov, t−t0, 对账残差, φ, 车队分歧) 条件下，五分量由独立机制产生（来源链、时间衰减、变化检测、本体映射、跨源投票），条件近似不相关；且在同一块 B 内，u_prov/u_onto/u_disagree 为块常量、u_stale/u_change 为格变量。系：**块级抽样之所以可行，是因为五分量里三项是块常数、两项可由少量格样本估计**——这是低成本转移的结构前提，不是工程近似。

**引理 43（先验单调性：插入先验不增加最坏风险）** 对任意合法 MReg，插入 SMP 后：(i) 若 SMP 为 null/违约，定义 402 使其输出 u_null = u_0 且 D 不扩张，逐指令等价于无先验系统；(ii) 若背书，缩窄仅在 u_cash = max(u_live∧u_0, f(·)) ≥ u_live∧u_0 且审计通过时发生，故 u 不增；(iii) 块撤销是 (u↑, D↓, I⊥↑) 的单调保守变换。⇒ 最坏情形安全不减。系：**先验只能改善期望，不能恶化最坏界——这把「用先验」从信念问题变成有偏序保证的设计选择。**

**引理 44（信任储库无免费午餐）** 由定义 401，任何未背书支取在结构上不可发生；每单位支取消耗 T(B)，T(B) 仅由独立核验回填，且块级违约使 T(B)=0。⇒ 在整个时程内，未被核验抵消的先验缩窄总量 ≤ 初始信任质量 + 还款总量；不存在「无限透支先验」的合法轨迹。系：**低成本来自摊销与转移，不来自免除还款**。

**引理 45（成本单调性与节俭支配传递）** CPA 三种算子的 cost_out ≥ Σ 分支 cost（含审计成本）；≽_f 为偏序且对 SER/PAR/VETO 组合封闭（组合的 cost 与 u 均单调）。⇒ 节俭前沿在组合下向上闭合：不存在「组合后同时更便宜更不可信却仍被支配」的合法路径。系：**成本审计与不确定度审计同构，可复用同一套组合校验**。

**引理 46（独立探针下界：自确认偏差有界）** 设核验预算中独立探针比例为 ρ，先验引导的显著性抽样与块真实错误率的相关为 c ∈ [0,1]。则块级错误率估计的偏差 ≤ (1−ρ)·c + o(1)；当 ρ>0 时偏差严格小于全显著性抽样（ρ=0）。系：**ρ 是整套低成本方案里唯一不能省的审计成本——它买的是「检验通道不被待检验对象污染」。**

**定理 32（SEMGAUGE 严格包含）** 在 A111–A119 下：SENTGAUGE = SEMGAUGE 的「SMP=∅ + cost 轴忽略 + ρ 不启用」实例化；由定义 405 与引理 43，退化条件下逐指令等于 R74，再退化等于 R73/R72/R71/R68。安全单调不减，成本轴在忽略时退化为 WCET 硬约束。

**定理 33（先验安全界）** 设块级 conformal 误覆盖率为 α，块使用率 r，撤销延迟上界 L(δ)（引理 39 的块级版本），独立探针比例 ρ，自确认相关 c。则期望不安全先验支取次数
E[U_bad] ≤ α·U_use + r·L(δ) + (1−ρ)·c·U_use + o(U_use)，
其中 U_use 为总支取次数。**证明重量落在 A117（块内交换性）与 A118（对账可下注）**：前者保证抽样覆盖可转移，后者保证块违约可 anytime 检出；而 (1−ρ)c 项显式暴露「省掉独立探针」的代价。系：**C5 可证伪——α、L(δ)、ρ、c 都可注入测量（MB5/AB5）。**

**定理 34（车队共模界：摊销不消除风险）** 由定义 407，P_common ≤ p_bad/k + p_shared，其中 k 为独立来源根数、p_shared 为共享隐变量概率。⇒ 当 N→∞ 时每机成本 → c_runtime，但共模风险地板为 p_shared > 0；只有在增加独立根 k 或显式审计共享隐变量（传感器批次/构建算法/投毒源）时风险才下降。系：**「低成本车队」的可持续性取决于来源多样性，而不是车队规模。**

## 6. 本轮最大风险

**一句话**：SEMGAUGE 把「低成本先验」建立在**块内交换性**这一不可就地验证的假设上——而先验的价值恰好在无法验证的未观测区域最高，于是系统只能把「少量抽样核验 + 共模投票」当成信任的转移凭证；一旦先验通过规划**选择性地决定去哪里核验**（自确认），观测与先验相关、还款被污染、信任储库在错误的地方被回填，系统就会在所有账目（成本账、债务账、撤销日志）都闭合、所有证书都有效的状态下，**用一张便宜、共享、看起来经过审计的地图，稳定地、可复现地、跨车队一致地看不见同一个真实障碍**——这比 R74 的「检不出检不出」更危险，因为它把不可检验性从「先验选择」下移到了「核验过程本身的独立性」，而后者恰恰被低成本诉求系统性地侵蚀。

次级风险与缓解：
1. **交换性假设失效（块内非同分布）** → 块按来源/本体/连通性细分到最小可信粒度；块级 conformal 校准 + 违约即整块撤销；SEAL-MB5 显式做交换性破坏注入（E412/E413）。
2. **自确认回路** → 强制独立探针配额 ρ（引理 46），探针由覆盖/随机驱动、禁止显著性驱动；E414/E424 量化 ρ 敏感性。
3. **车队共模 / 共识俘获** → 独立来源根投票（相关源合并计一票）+ 共享隐变量显式记账 + 只承认 p_shared 地板，不假装 N 能消除它（定理 34、E419）。
4. **本体漂移（分类学错配）** → unknown 保守回退 + φ 版本化 + 回滚；本体更新视为 NCM 同型的预算化适应（E417）。
5. **先验债务会计被绕过** → 债务闭合作为 J_FRUGAL 的必要条件，无背书支取在代码路径上不可达（定义 401/402、E420）。
6. **摊销收益高估（把未来还款成本藏进「未来」）** → 成本账强制计入核验摊销与撤销恢复成本，报告「全生命周期每机成本」而非「部署时成本」（定理 34、E415/E419）。
7. **MB5 与真实部署分布偏差** → SEAL-MB5 密封保持集 + 三方复现 + 只认预注册指标（E422/E425）。

## 2. 形式化定义（要点版）

**定义 398（七不变式）** R74 六类不变式（契约完整性、组合单调性、反作用通道完备、主张绑定、严格退化、哨兵完备）+ **成本单调性**与**先验债务闭合**；后者要求任何被先验缩窄的决策必有已核验样本或未违约块作背书，否则默认未知。

**定义 399（SMP）** 语义地图 = 过去观测的有损压缩；输出离散先验 p(o|c)、负证据 n(c)、可供性 A、来源树 prov、本体 φ。作为离散证据类型进入 MReg，与 DPEM/DMEM/OEM 同构。

**定义 400（u_sem 五分量）** 来源/时效/变化/本体/分歧；块内三项（来源、本体、分歧）为块常量，两项（时效、变化）为格变量——这是「少量样本估计 → 整块转移」的结构前提（引理 42）。

**定义 401（TPM）** 信任储库 + 债务账 + 块级违约。支取消耗 T(B)，还款回填 T(B)，块级 e-process 越界 ⇒ T(B)=0、整块撤销回未知。**不存在无限透支先验的合法轨迹**（引理 44）。

**定义 402（支取规则）** 仅当 T(B)≥τ_T ∧ u_sem≤τ_sem ∧ 域内 ∧ 对账通过时缩窄；否则 null prior。**先验只能安全缩窄被背书的格，未背书格一律保守化**。

**定义 403（CPA）** 三种组合的成本传播：SER 成本加和、PAR 计入审计成本、VETO 取分支上界；**成本单调引理**对偶于 R73 引理 34 的不确定度单调性。

**定义 404（节俭支配）** ≽_f 为偏序，对组合封闭。先验引入是帕累托改进当且仅当新方案落在前沿内侧；否则必须显式声明「安全换成本」或「成本换安全」，不得静默。

**定义 405（先验单调性）** 先验插入不增加最坏风险：null/违约 ⇒ 逐指令等价无先验；背书 ⇒ 缩窄受 conformal 下界与审计约束；撤销是 (u↑,D↓,I⊥↑) 单调保守变换。

**定义 406（FAP）** ROI 背包 + 独立探针配额 ρ，anytime 中断；探针检验的不是标签正确性，而是「交换性假设是否仍成立」。

**定义 407（FAM）** 成本 /N 摊销，风险按 /k 记账；p_shared 地板不可约；共识只由独立根投票，相关源合并一票。

**定义 408（本体计量）** 未知类保守回退，禁止强行映射最相似类；本体更新视为 NCM 同型预算化适应。

**定义 409（AIC-PRIOR）** 六类威胁与防线：来源签名/时效 e-process/独立根投票/独立探针/块级撤销/单源不定案。

**定义 410（J_FRUGAL）** 成本账 + 债务账 + 撤销日志；Valid ⇒ J_SENT 有效 ∧ 成本闭合 ∧ 无未背书支取 ∧ 撤销链完整。

**定义 411（MB5）** 静态办公室 / 变动仓库 / 跨本体迁移；5 基线（无先验/朴素先验/全量核验/ROI 无探针/SEMGAUGE）；预注册 + 固定种子 + SEAL-MB5。

**定义 412（C5 与绑定）** C5 ← (SMP,TPM,CPA,FAP,FAM) ← MB5 ← AB5 ←（成本-安全帕累托面积、碰撞率、误抓率、撤销延迟、探针覆盖率）；C1–C4 不变。

**定义 413（假设 A117–A119）** 块内交换性 / 对账残差可预测下注 / 存在与先验无关的抽样机制且成本入账。

## 3. 关键算法伪代码

```python
# IP-310 SMP：语义先验证据（离散类型 + 来源树 + 本体版本）
class SemanticMapPrior:
    def evidence(self, pose_guess):
        cells = self.frustum_query(pose_guess)             # 视野相关格
        return PriorEv(prior={c: self.p(o|c) for c in cells},
                       neg={c: self.n(c) for c in cells},
                       u={c: self.u_sem(c) for c in cells},
                       blocks=self.block_index(cells),
                       prov=self.prov, onto=self.phi.version)

# IP-311 TPM：支取 / 还款 / 块级违约
class TrustPriorMetrology:
    def cash_in_cells(self, p_ev, d_ev, o_ev):
        out, saved = {}, 0.0
        for c, u0 in p_ev.u.items():
            b = self.block_of(c)
            if self.T[b] < TAU_T or self.sent[b].red or not self.audit(p_ev, c):
                out[c] = u0                              # null prior
                continue
            u = max(u0, conformal_floor(u0, self.T[b], self.alpha))
            self.debt[b] += (u0 - u); out[c] = u; saved += (u0 - u)
        return out, saved
    def repay(self, b, obs, resid):
        st, _ = self.sent[b].step(resid)                 # 复用 IP-303 CAS
        if st == 'RED': self.T[b] = 0.0; self.revoke(b)  # 整块破产
        else: self.T[b] = min(1.0, self.T[b] + ETA*consistency(obs, b))

# IP-312 CPA：成本感知组合
def cpa_compose(a, b, op, audit):
    base = a.cost + b.cost
    if op == 'SER':
        return Ev(u=a.u + lipschitz(b, a.u), cost=base, D=a.D & b.D,
                  veto=a.veto | b.veto, T=min(a.T, b.T))
    if op == 'PAR':
        c = base + audit.cost                            # 审计成本必须入账
        if audit.covers(resid(a, b)) and min(a.T, b.T) >= TAU_T:
            return Ev(u=fuse(a, b, audit.rho), cost=c, D=a.D & b.D,
                      veto=a.veto | b.veto, T=min(a.T, b.T))
        return Ev(u=max(a.u, b.u), cost=c, D=a.D & b.D,
                  veto=a.veto | b.veto | {'FRUGAL_AUDIT_FAIL'}, T=min(a.T, b.T))
    if op == 'VETO':
        return Ev(valid=not (a.veto or b.veto), cost=base, D=a.D & b.D,
                  veto=a.veto | b.veto, T=min(a.T, b.T))

# IP-313 FAP：ROI 抽样 + 独立探针（防自确认）
def frugal_verify(smp, tpm, budget, rho=0.15):
    blocks = tpm.active_blocks()
    roi = {b: tpm.delta_u(b) / tpm.verify_cost(b) for b in blocks}
    x = knapsack(roi, budget*(1-rho))                    # 效率分配
    probe = independent_probe(budget*rho,               # 随机/覆盖驱动
                              exclude=smp.saliency_scores)  # 不被先验引导
    return x, probe

# IP-314 FAM：车队摊销 + 共模记账
def fleet_account(N, roots, p_bad, c_build, c_verify, c_runtime, p_shared):
    return dict(c_each=(c_build+c_verify)/N + c_runtime,
                p_common=p_bad/max(1, len(roots)) + p_shared,
                k=len(roots))                        # 风险按独立根，不按 N

# IP-315 J_FRUGAL
def write_frugal_cert(M):
    return J_FRUGAL(J_SENT=M.sent_cert,
                    cost=M.cost_ledger.snapshot(),
                    debt={b:(M.tpm.T[b], M.tpm.debt[b]) for b in M.tpm.T},
                    revoke=M.tpm.log, probe=M.fap.probe_stats)

# IP-316 SEMGAUGE 主闭环（复用 R74 三域）
def SEMGAUGE_round(M, obs, audio, tac_frame, depth_img, det_set, tracks):
    d_ev = M.dpe.update(...); o_ev = M.oem.update(...)
    for ev, mod in ((d_ev, M.dpe), (o_ev, M.oem)):
        st, _ = mod.sent.step(ev.resid, M.hist)
        if st == 'RED': ev = stub(mod)
    p_ev = M.smp.evidence(M.pose_guess)
    p_ev.u, saved = M.tpm.cash_in_cells(p_ev, d_ev, o_ev)
    if M.clock.due_metric():
        M.kappa = M.ncm.adapt(M.interact_window)
        b_t = M.bse.step_full(..., d_ev=d_ev, o_ev=o_ev, t_ev=t_ev, p_ev=p_ev)
        M.fap.run(M.tpm)                                 # 预算化核验+探针
        g = M.ervoi.choose(...)
        s2, cost = sent_reflex_step(M.mods, g, M.state, M.budget)
        if s2 is not None: M.last_g, M.state = g, s2
        M.mreg.audit(); M.cert = write_frugal_cert(M)
    snap = M.snapshot.read_latest()
    lam = embodied_risk_scale(..., max(snap.t_ev.u, snap.d_ev.u,
                                       snap.o_ev.u, snap.p_ev.u), M.risk_params)
    k = M.c_ras_wm.certified_prefix(M.ach.propose_ctrl(...), lam)
    M.envelope.check0(k, lam)
    return k, lam, M.cert
```

## 4. 推导

**引理 42（u_sem 块内可分离）** 在 (prov, t−t0, 对账残差, φ, 分歧) 条件下五分量近似独立；块内 u_prov/u_onto/u_disagree 为块常量，u_stale/u_change 为格变量 ⇒ 少量格样本可估计块级量，转移有结构依据。

**引理 43（先验单调性）** null/违约 ⇒ 逐指令等价无先验；背书 ⇒ u_cash≥u_0 且审计通过才缩窄；撤销单调保守 ⇒ 最坏安全不减。

**引理 44（无免费午餐）** 未背书支取不可达 ⇒ 未被核验抵消的缩窄总量 ≤ 初始 T + 还款总量 ⇒ 不存在无限透支轨迹。

**引理 45（成本单调与支配传递）** CPA 三算子 cost_out ≥ Σ分支（含审计）；≽_f 对组合封闭 ⇒ 节俭前沿向上闭合。

**引理 46（独立探针偏差界）** 探针比例 ρ、自确认相关 c ⇒ 块错误率估计偏差 ≤ (1−ρ)c + o(1)；ρ>0 严格优于 ρ=0。

**定理 32（SEMGAUGE 严格包含）** A111–A119 下，SENTGAUGE = 「SMP=∅ + 忽略 cost 轴 + ρ 不启用」实例化；退化链逐指令等于 R74→R73→R72→R71→R68；安全单调不减。

**定理 33（先验安全界）** E[U_bad] ≤ α·U_use + r·L(δ) + (1−ρ)·c·U_use + o(U_use)。证明重量落在 A117（块内交换性）与 A118（对账可下注）；(1−ρ)c 显式暴露省掉独立探针的代价。

**定理 34（车队共模界）** P_common ≤ p_bad/k + p_shared；N→∞ 时每机成本→c_runtime，但风险地板 p_shared>0 不可由规模消除，需增加独立根或显式审计共享隐变量。

## 7. 本轮最大风险

**一句话**：SEMGAUGE 把「低成本先验」建立在**块内交换性**这一不可就地验证的假设上，而先验的价值恰在无法验证的未观测区域最高；一旦先验通过规划**选择性地决定去哪里核验**（自确认），观测与先验相关、还款被污染、信任储库在错误处被回填，系统就会在所有账目闭合、所有证书有效的状态下，**用一张便宜、共享、看似经过审计的地图，稳定而可复现地跨车队一致看不见同一个真实障碍**——这比 R74 的「检不出检不出」更隐蔽，因为它把不可检验性下移到了「核验过程本身的独立性」，而后者正被低成本诉求系统性侵蚀。

次级风险与缓解：
1. **交换性失效** → 块按来源/本体/连通性细分到最小可信粒度 + 块级 conformal + 违约整块撤销；SEAL-MB5 做交换性破坏注入（E412/E413）。
2. **自确认回路** → 强制独立探针 ρ（引理 46），覆盖/随机驱动，禁止显著性驱动；E414/E424 量化。
3. **车队共模/共识俘获** → 独立根投票（相关源合并一票）+ 共享隐变量显式记账，只承认 p_shared 地板（定理 34、E419）。
4. **本体漂移** → unknown 保守回退 + φ 版本化/回滚，本体更新按 NCM 同型预算化适应（E417）。
5. **债务会计被绕过** → 债务闭合为 J_FRUGAL 必要条件，无背书支取在代码路径不可达（E420）。
6. **摊销收益高估** → 成本账强制计入核验摊销与撤销恢复，报告全生命周期每机成本（定理 34、E415/E419）。
7. **MB5 分布偏差** → SEAL-MB5 密封集 + 三方复现 + 只认预注册指标（E422/E425）。
