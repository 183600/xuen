（灵感驱动研究循环·第 2 轮；本轮灵感：「实时性」×「视觉语言动作模型」）

> **基线**：v23 = MetricVoiceGauge-NCD-HUTDH-v23（HPC-E+ 四证门：HPC-E ∪ CESC ∪ FSVC ∪ IPAttest；上承 v22 分层 PGEV/ACSC/DCSC、v21 语义-规范层、v20 联邦感知证书）。
> **本轮纪律**：**证书不是永恒事实，而是一张有到期时间的租约；VLA 不是执行者，而是低关键度的"提议者"**。不推倒 v23：几何/规范/能量/云边/少样本/IP 模块全部保留。本轮只做一件事：**给 v23 的每张证书补上"时间维"与"语义提议维"，用混合关键度实时调度把安全内核与 VLA 彻底解耦，使系统在 VLA 任意慢、任意错的情况下仍守住几何安全，同时让 VLA 只贡献活性**。

## 0. 直觉与动机

**灵感 1（实时性 → 证书是租约，不是快照）**
直觉：前几轮把证书当成"某一瞬间为真"的命题，但真实机器人里"真"会过期。避障证书在机器人移动 50ms 后可能已经失效；联邦共识票在 200ms 后可能不再代表任何机器人的现状；conformal 校准在分布漂移后会退化。实时性视角的核心转变是：**每张证书都带一个租约 (lease)**——签发时刻 `t_issue`、有效期 `τ_lease`、以及一组必须在租约内持续成立的假设 `A`。租约不是拍脑袋的 TTL，而是由三件事取最小：**物理**（世界多快能变得不安全）、**统计**（校准多快会失真）、**调度**（下一次刷新最晚何时必须完成）。关键反直觉点：**过期不是"降级为不确定"，而是直接退化为"假设最坏情况"**——租约一旦到期而未被续签，证书不保留任何乐观内容，执行域随时间**单调收缩**。这把 v20–v23 的"快照安全"升级为"时序安全"。

严谨地说，把证书定义为四元组 `C = (payload, t_issue, τ_lease, A)`，其有效性为
`Valid(C,t) ≜ (t_issue ≤ t < t_issue + τ_lease) ∧ A(t)`，
其中租约长度 `τ_lease = min(τ_phys, τ_stat, τ_sched)`。`τ_phys` 由最坏相对接近速度/加速度导出（见产物区二次方程），`τ_stat` 由漂移监测器估计"覆盖跌到 1-α 以下"的时间，`τ_sched` 由刷新任务的截止期减 WCET 导出。三者取最小保证了**物理上没过期、统计上没过期、调度上还来得及续签**。

**灵感 2（VLA → 语义提议者，而非安全授权者）**
直觉：VLA（视觉-语言-动作模型）能把"把桌上的蓝色杯子递给那位戴帽子的先生"直接变成动作序列，极大扩展任务空间——但它慢（数百 ms 到数秒）、非确定、会幻觉、会指称错对象。若让 VLA 进入安全关键路径，实时性与安全性同时崩塌。核心架构判断：**VLA 只能提议，不能授权**。它输出的是带指称（grounding）的语义子目标序列，必须被编译成"语义提议证书"，再逐段交给 v23 的快速几何内核去认证/细化；几何内核有权拒绝、裁剪、降级任何一段。关键反直觉点：**VLA 的价值不在于它给出的动作，而在于它给出的"子目标"**——子目标变化慢（语义时钟 ~1–2Hz），可以持**长租约**；几何事实变化快（几何时钟 50Hz），必须持**短租约**。两个时钟一分离，VLA 的慢不再威胁实时性，VLA 的错也不再直接变成碰撞。

严谨地说，VLA 输出 `P = ({g_1,…,g_k}, {r_1,…,r_m}, u)`：子目标序列、指称集合、置信度。每个子目标必须通过**指称落地证书** `Ground(r)`：在 SDC 中唯一匹配到类别相容、嵌入相似度 ≥ θ_g、且区域落在覆盖图 `Cov_t` 内的物体；否则判为"缺失/歧义/覆盖外"，拒绝该提议（可退化为"搜索"子目标，但绝不执行原动作）。

**灵感 3（实时性 × VLA 的合流 → 混合关键度 + 双时钟 + 安全护盾）**
直觉：安全内核是**高关键度 (hi-criticality)** 任务，必须有 WCET 上界与截止期保证；VLA 是**低关键度 (lo-criticality)** 任务，慢甚至超时都只损失活性。用混合关键度实时调度（Vestal/AMC 模型）：正常模式下两者共存；一旦 VLA 负载越界，系统切到 hi 模式，**先丢 VLA、后降级感知**，而 hi 任务预算不变。配合"投机执行 + 安全护盾"：VLA 的语义租约允许机器人预先进入某个"准备姿态"（投机），但真正的动作必须等快速内核签发短租约几何证书；证书没来就停在安全护盾内。**安全从不等待 VLA，活性才等待 VLA**。

**三者如何统一**
统一为 **时序-语义分离层 (Temporal-Semantic Separation, TSS)**：TCK 给所有证书加租约，MCS 用混合关键度保证 hi 任务不被 VLA 挤占，VLAPG/GAC 把 VLA 约束成"带落地证据的提议者"，CFC-T 让联邦共识只认时间窗内的新鲜票。统一状态 `ζ_tss = ζ_ce ∪ (leases, clocks, vla_proposals, grounding_proofs, crit_modes)`；统一准入门 **HPC-T = HPC-E+ ∧ 全证书租约有效 ∧ 指称落地 ∧ hi 模式可调度**。安全继承升级为**逐时刻包含**：`∀t, Exec_v24(t) ⊆ Exec_v23(t) ⊆ … ⊆ Exec_v18(t)`，且两次刷新之间 `Exec_v24` 单调不增。

## 1. 研究问题（轮次升级版）

- **Q1（租约的可靠导出与续签）**：如何由相对速度/加速度界、漂移监测器与刷新任务响应时间三方导出 `τ_lease`，使"过期即最保守"在物理、统计、调度三个意义上同时成立？当 `τ_sched < τ_phys`（刷新来不及）时，系统应如何提前进入保守态而不是先出现"租约空窗"？多次续签的租约能否拼接成一条不产生乐观缝隙的覆盖链？

- **Q2（VLA 提议的落地与幻觉封堵）**：指称落地 `Ground(r)` 的唯一性条件在遮挡、同类多物体、开放词表下如何可靠判定？当指称落在 `Cov_t` 之外（还没看见）时，应拒绝还是转为"探索子目标"，而探索本身如何仍受几何证书约束？VLA 的语义租约 `τ_sem` 如何由子目标前置条件的可观测性导出，并支持事件驱动的提前撤销？

- **Q3（混合关键度下的可调度性与模式切换）**：hi 任务（证书刷新、几何内核、护盾）与 lo 任务（VLA 推理、语义重规划）如何分配预算，使 `U_hi + U_reserve ≤ 1` 且 hi 响应时间恒小于其租约？AMC 模式切换的滞回阈值如何设计，既避免 VLA 超载拖垮安全，又避免在边界反复切换造成活性振荡？VLA 推理时间无上界时，"投机前缀"应多长才既有用又可回滚？

- **Q4（时序联邦共识与新鲜度）**：投票带时间戳后，法定人数如何改为"时间窗内 ≥ N-F 且 ≥2 模态"的新鲜法定人数？新鲜窗 `Δ_fresh` 与各机器人通信延迟、时钟偏斜如何联合标定？当新鲜法定人数不足时，如何保证系统退回保守（CI）而不是错误采信旧票，同时不把正常网络抖动误判为故障？

## 2. 设计原则（在 P41–P42 基础上新增 P43–P45）

**P43 证书租约律（Certificate Lease Monotonicity）**
每张证书 `C = (payload, t_issue, τ_lease, A)` 的有效性为 `Valid(C,t) ≜ t_issue ≤ t < t_issue+τ_lease ∧ A(t)`，且 `τ_lease = min(τ_phys, τ_stat, τ_sched)`。**过期即最保守**：`¬Valid(C,t)` 时不得使用 `C.payload` 的任何乐观结论，而应替换为"最坏假设"证书 `C_⊥`（例如"该区域可能有人/有障碍"）。因此两次刷新之间执行域单调不增：`t_1 < t_2 ∧ 无刷新 ⇒ Exec_v24(t_2) ⊆ Exec_v24(t_1)`。续签只能通过重新签发（重新验证假设）恢复，不能"续期"旧 payload。

**P44 提议-授权分离律（Proposal–Authorization Separation）**
VLA 只产生候选语义提议，永不直接写入执行域。任何源自 VLA 的计划 `π` 必须满足：`π ∈ Exec_v23`（通过 v23 全部几何/规范/能量/云边/IP 证书）∧ 每个指称 `Ground(r)` 成立 ∧ 子目标处于语义租约内。形式化：`Adm_v24(π) ⇒ Adm_v23(π)`，即 **VLA 只改变候选分布（活性），不改变安全准入集（安全性）**。VLA 不可用时，系统回落到预置安全技能库，活性下降而安全不变。

**P45 混合关键度单调律（Mixed-Criticality Monotonicity）**
任务分两级：hi = {证书刷新, 几何内核, 安全护盾}，lo = {VLA 推理, 语义重规划, 日志外传}。hi 任务在两种模式下使用同一 WCET 预算并须满足 `R_i^hi ≤ min(D_i, τ_lease,i)`；lo 任务仅在 `U_hi + U_lo + U_reserve ≤ 1` 时准入。模式切换规则：lo 超预算 → 立即切 hi（丢弃 lo），hi 恢复且留有滞回裕度 → 才切回 lo。由此 **hi 的可调度性独立于 lo 的实际执行时间**，VLA 再慢也不会让安全内核错过截止期。

## 3. 与基线的接口（如何退化）

- TCK 失效（时钟/租约模块崩溃）⇒ 所有证书视为已过期 ⇒ 进入最大限制模式（共享区停机、非共享区静态人距上限）⇒ 比 v23 更保守；
- MCS 失效（调度器不可用）⇒ 冻结 lo 任务、只跑 hi 任务 ⇒ 安全保持、VLA 活性归零 ⇒ 等价 v23 + 保守；
- VLAPG/GAC 失效（VLA 不可用或落地不可信）⇒ 禁用 VLA 提议，回落到安全技能库 ⇒ `Exec_v24 ⊆ Exec_v23` 仍成立；
- CFC-T 失效（时间戳不可信）⇒ 退回 v23 的 CFC++ 新鲜度阶梯，并把法定人数收紧为全体 ⇒ 子集；
- 所有新模块失效 ⇒ 完全回退 v23 ⇒ `Exec_v24(t) ⊆ Exec_v23(t) ⊆ … ⊆ Exec_v18(t)`（逐时刻包含）。
- **安全继承**：租约只收缩不扩张、VLA 只提议不授权、调度只丢 lo 不丢 hi；任意失效都向更保守方向退化。

## 4. 预期贡献

1. **时序证书 / 租约演算**：首次把 v20–v23 的快照证书统一为带物理/统计/调度三重导出的租约，给出"过期即最保守"与逐时刻单调收缩的形式化；
2. **双时钟架构**：语义时钟（VLA，长租约）与几何时钟（快速内核，短租约）分离，证明 VLA 的延迟与错误在结构上无法侵入安全关键路径；
3. **VLA 提议-授权分离与指称落地证书**：把开放词表指称唯一性、覆盖约束、语义租约撤销编译成可审计证书，封堵"幻觉物体被直接执行"；
4. **混合关键度安全内核**：用 AMC 实时调度给出 hi 任务独立于 VLA 的可调度性条件，并配以投机执行 + 安全护盾，使安全不等待 VLA、活性才等待 VLA；
5. **时序联邦共识**：以新鲜法定人数拒绝陈旧 SAFE 票，把 v20 的"相关性误判共识"风险进一步推进到"时间维"；
6. **HPC-T 时序统一门**：`HPC-E+ ∧ 租约有效 ∧ 指称落地 ∧ hi 可调度`，闭合 `Exec_v24(t) ⊆ Exec_v23(t)` 的逐时刻安全链。

## 5. 本轮最大风险

**一句话**：两时钟架构把"语义"放到长租约、把"几何"放到短租约，但语义事实可以**突变**（人撤销交接意图、物体被调包、指称漂移），而快速几何内核在结构上无法观测这种突变——机器人可能持有一张尚未过期、几何上完全合规、语义上已经作废的"语义租约"，执行一次**可审计的语义错误**。

## 1. 关键算法骨架（在 IP-436–439 骨架上扩展）

```python
# ============================================================
# IP-440 Temporal Certificate Kernel (TCK) — 租约演算
# ============================================================
@dataclass
class TimedCertificate:
    payload: Any
    t_issue: float
    tau_lease: float
    assumptions: Callable[[float], bool]
    crit: str = "hi"

    def valid(self, t: float) -> bool:
        return (self.t_issue <= t < self.t_issue + self.tau_lease
                and self.assumptions(t))

    def remaining(self, t: float) -> float:
        return max(0.0, self.t_issue + self.tau_lease - t)


def lease_from_physics(m_safe: float, v_max: float,
                       a_max: float, t_react: float) -> float:
    """在 m(t)=m_safe - v*t - 0.5*a*t^2 下求 m=0 的时刻。
    先扣除反应延迟内已消耗的间隙，保守取正根。"""
    m = max(0.0, m_safe - v_max * t_react)
    if m <= 0.0:
        return 0.0
    if a_max <= 1e-9:
        return m / max(v_max, 1e-9)
    return (-v_max + math.sqrt(v_max ** 2 + 2.0 * a_max * m)) / a_max


class TemporalCertificateKernel:
    def __init__(self, alpha: float = 0.01):
        self.alpha = alpha
        self.certs: dict[str, TimedCertificate] = {}

    def derive_lease(self, ctx) -> float:
        tau_phys = lease_from_physics(
            ctx.m_safe, ctx.v_max, ctx.a_max, ctx.t_react)
        tau_stat = ctx.drift_monitor.time_to_coverage_below(1.0 - self.alpha)
        tau_sched = max(0.0, ctx.refresh_deadline - ctx.refresh_wcet)
        return max(0.0, min(tau_phys, tau_stat, tau_sched))

    def issue(self, key: str, payload: Any, ctx) -> TimedCertificate:
        c = TimedCertificate(payload, ctx.now, self.derive_lease(ctx),
                             ctx.assumptions, ctx.crit)
        self.certs[key] = c
        return c

    def lookup_or_bottom(self, key: str, t: float) -> TimedCertificate:
        """过期或缺失 → 返回最坏假设证书，绝不返回旧乐观载荷。"""
        c = self.certs.get(key)
        if c is not None and c.valid(t):
            return c
        return TimedCertificate(payload=BOTTOM_ASSUMPTION,
                                t_issue=t, tau_lease=0.0,
                                assumptions=lambda _t: True, crit="hi")

    def valid_keys(self, t: float) -> set[str]:
        return {k for k, c in self.certs.items() if c.valid(t)}


# ============================================================
# IP-442 Grounding Attestation Certificate (GAC) — 指称落地
# ============================================================
@dataclass
class GroundingResult:
    ok: bool
    object_id: Optional[str] = None
    reason: str = ""
    proof_hash: bytes = b""


class GroundingAttestation:
    def __init__(self, theta_g: float = 0.85):
        self.theta_g = theta_g

    def attest(self, ref, sdc_t: list, cov_t) -> GroundingResult:
        cands = [o for o in sdc_t
                 if o.cls == ref.cls
                 and cosine(ref.emb, o.emb) >= self.theta_g]
        if not cands:
            return GroundingResult(False, reason="absent")
        if len(cands) > 1:
            return GroundingResult(False, reason="ambiguous")
        o = cands[0]
        if not cov_t.contains(o.region):
            return GroundingResult(False, reason="outside_coverage")
        return GroundingResult(True, o.id, "unique",
                               proof_hash=sha256(o.sdc_payload))

# IP-441 VLA Proposal Gate (VLAPG) — 提议而非授权
# ============================================================
@dataclass
class SemanticProposal:
    subgoals: list
    referents: list
    confidence: float
    t_created: float
    tau_sem: float


class VLAProposalGate:
    def __init__(self, vla_model, gac: GroundingAttestation,
                 semantic_hz: float = 1.0):
        self.vla = vla_model
        self.gac = gac
        self.period = 1.0 / semantic_hz
        self.latest: Optional[SemanticProposal] = None

    def propose(self, obs, instruction) -> Optional[SemanticProposal]:
        """lo 关键度路径：超时/异常只返回 None，绝阻塞 hi 路径。"""
        try:
            raw = self.vla.infer(obs, instruction)   # 无 WCET 上界
        except (TimeoutError, RuntimeError):
            return None
        if raw is None or raw.confidence < self.vla.min_conf:
            return None
        return SemanticProposal(raw.subgoals, raw.referents, raw.confidence,
                                time.now(), raw.tau_sem)

    def compile(self, prop: SemanticProposal, sdc_t: list, cov_t) -> list:
        """逐指称落地；任一失败 → 整个提议拒绝（不部分执行）。"""
        for r in prop.referents:
            g = self.gac.attest(r, sdc_t, cov_t)
            if not g.ok:
                return []
        return [refine(g_sub, prop) for g_sub in prop.subgoals]


# ============================================================
# IP-443 Mixed-Criticality Scheduler (MCS) — AMC 调度
# ============================================================
@dataclass
class RTCTask:
    name: str
    C_hi: float
    C_lo: float
    T: float
    D: float
    crit: str          # "hi" / "lo"


class MixedCriticalityScheduler:
    def __init__(self, hi_tasks: list, lo_tasks: list,
                 reserve: float = 0.20):
        self.hi = hi_tasks
        self.lo = lo_tasks
        self.U_reserve = reserve
        self.mode = "lo"

    def _rtb(self, task: RTCTask, tasks: list, c_key: str) -> float:
        R = getattr(task, c_key)
        while True:
            R_new = getattr(task, c_key) + sum(
                math.ceil(R / j.T) * getattr(j, c_key)
                for j in tasks if j.T < task.T)
            if abs(R_new - R) < 1e-9:
                return R
            R = R_new

    def hi_schedulable(self) -> bool:
        """AMC-rtb：hi 任务仅与 hi 任务竞争，独立于 lo 实际执行。"""
        for t in self.hi:
            R = self._rtb(t, self.hi, "C_hi")
            if R > min(t.D, getattr(t, "tau_lease", t.D)):
                return False
        return True

    def lo_admissible(self, task: RTCTask) -> bool:
        U_hi = sum(t.C_hi / t.T for t in self.hi)
        U_lo = sum(t.C_lo / t.T for t in self.lo) + task.C_lo / task.T
        return U_hi + U_lo + self.U_reserve <= 1.0

    def tick(self, lo_overrun: bool, hi_slack_ok: bool):
        if lo_overrun:
            self.mode = "hi"          # 丢 lo，保 hi
        elif self.mode == "hi" and hi_slack_ok:
            self.mode = "lo"          # 带滞回才切回
        return self.mode


# ============================================================
# IP-444 Temporal Federated Consensus (CFC-T) — 新鲜法定人数
# ============================================================
class TemporalFederatedConsensus:
    def __init__(self, N: int, F: int, delta_fresh: float = 0.1,
                 m_min: int = 2):
        self.N, self.F = N, F
        self.delta_fresh = delta_fresh
        self.m_min = m_min
        self.votes: dict = {}

    def consensus_round(self, now: float):
        fresh = {k: v for k, v in self.votes.items()
                 if now - v.t_cast <= self.delta_fresh}
        if len(fresh) < self.N - self.F:
            return "CI"                       # 新鲜法定人数不足
        if len({v.modality for v in fresh.values()}) < self.m_min:
            return "CI"                       # 模态不足
        if len({v.version for v in fresh.values()}) != 1:
            return "CI"                       # 版本不一致
        return self._majority(fresh)


# ============================================================
# IP-445 HPC-T 时序统一准入门
# ============================================================
@dataclass
class HPCTGate:
    hpc_e_plus: 'HPCEPlus'
    tck: TemporalCertificateKernel
    vla_gate: VLAProposalGate
    gac: GroundingAttestation
    mcs: MixedCriticalityScheduler
    cfc_t: TemporalFederatedConsensus

    def admits(self, plan, now: float, sensor_data: dict,
               modules: list[str]) -> bool:
        # 1. hi 模式必须可调度（安全内核不能被 VLA 挤垮）
        if not self.mcs.hi_schedulable():
            return False
        # 2. v23 四证门（几何/规范/能量/云边/少样本/IP）
        if not self.hpc_e_plus.admits(
                plan, sensor_data['x'], sensor_data['v'], sensor_data['z'],
                sensor_data['E_res'], sensor_data['margin_req'], modules):
            return False
        # 3. 计划所需证书必须全部租约有效（过期→拒证）
        for key in plan.required_certs:
            if key not in self.tck.valid_keys(now):
                return False
        # 4. 若计划源自 VLA：指称落地 + 语义租约
        if plan.origin == "vla":
            if not plan.grounding_ok:
                return False
            if now >= plan.t_created + plan.tau_sem:
                return False
        return True
```

## 2. 实时性与复杂度分析

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 / 实时预算 |
|---|---|---|---|
| TCK `derive_lease` | O(1) | O(1) | 二次方程求根 |
| TCK `valid_keys` | O(\|certs\|) | O(\|certs\|) | \|certs\| ≈ 32 |
| GAC `attest` | 平均 O(1)（哈希索引）/ 最坏 O(\|SDC\|) | O(\|SDC\|) | \|SDC\| ≤ 64，θ_g=0.85 |
| VLAPG `compile` | O(\|refs\|·\|SDC\|) | O(\|refs\|) | 仅 lo 路径，不进 hi 关键路径 |
| MCS `hi_schedulable` | 离线 O(n²·k) / 在线 O(1) | O(n) | n = hi 任务数 ≤ 8 |
| MCS `tick` | O(1) | O(1) | 模式切换 + 滞回 |
| CFC-T 共识轮 | O(N) | O(N) | N = 机器人数，Δ_fresh=100ms |
| HPC-T 准入 | O(\|certs\|+\|modules\|+log\|rules\|) | O(1) 增量 | hi 路径 P99 < 2ms |
| VLA 推理 | O(τ_vla)，**无上界** | — | lo 关键度，超时即丢弃，绝阻塞 hi |

**实时性论证**：hi 路径（TCK 查询 + HPC-E+ + HPC-T 连言）不包含任何 VLA 调用或阻塞 I/O，最坏为 O(|certs|+|modules|)，在 32 张证书、20 个模块下 P99 < 2ms，远小于 50Hz 的 20ms 预算。VLA 完全位于 lo 路径，其推理时间不进入 hi 的响应时间分析；AMC-rtb 只用 `C_hi` 计算 hi 任务响应时间，故 VLA 的任意长尾延迟都不会使 hi 截止期失效。MCS 预留 `U_reserve = 0.20` 给中断、日志与最坏抖动。

## 3. 正确性论证

### 引理 1（租约单调收缩）
**陈述**：若区间 `(t_1, t_2)` 内没有发生任何续签，则 `Exec_v24(t_2) ⊆ Exec_v24(t_1)`。

**证明**：`Valid(C,t)` 对固定 `t_issue, τ_lease` 在 `t ≥ t_issue+τ_lease` 后恒假；假设谓词 `A(t)` 按设计只可能由真变假（障碍只增、覆盖只减、意图 TTL 只过期）。故证书有效集合随 t 单调不增。HPC-T 的准入是这些有效集合与固定谓词的连言，连言条件单调减少 ⇒ 可准入计划集合单调收缩。∎

### 引理 2（VLA 不可扩权）
**陈述**：`Adm_v24(π) ⇒ Adm_v23(π)`；VLA 只改变候选分布，不扩大安全执行集。

**证明**：`HPCTGate.admits` 的第一、二条分别要求 `hi_schedulable` 与 `hpc_e_plus.admits`，后者即 v23 的完整四证门。因此任何被 v24 准入的 π 必然也通过 v23 门。VLA 提议仅通过 `propose/compile` 影响 `_plan_from_consensus` 产生哪些候选，而候选仍须走同一 `admits`。故安全集只能缩小或不变。∎

### 引理 3（hi 任务截止期独立于 VLA）
**陈述**：若对所有 hi 任务 `R_i^hi ≤ min(D_i, τ_lease,i)`，则无论 lo 任务（含 VLA）执行多久，hi 任务均满足截止期。

**证明**：AMC 的 hi 模式只调度 hi 任务，响应时间上界 `R_i^hi = C_i^hi + Σ_{j∈hp(i)∩hi} ⌈R_i^hi/T_j⌉ C_j^hi` 不含任何 lo 项。模式切换在 lo 超预算时立即丢弃 lo，故 lo 的执行不占用 hi 模式的时间线。条件成立即得。∎

### 引理 4（时序共识拒绝陈旧票）
**陈述**：若 `CFC-T` 返回 SAFE，则所有计入的投票满足 `now − t_cast ≤ Δ_fresh` 且版本一致；任一早于 `Δ_fresh` 的票不参与共识。

**证明**：`consensus_round` 先以 `now − v.t_cast ≤ delta_fresh` 过滤，再检查人数、模态、版本。被过滤的票不进入 `_majority`。故 SAFE 结论只能由新鲜且同版本票形成。剩余风险是"状态在 Δ_fresh 内变化而未被观测"，其影响被 `Δ_fresh` 显式限界。∎

### 定理（双时钟安全：安全不等待 VLA）
**陈述**：在 (i) `hi_schedulable` 成立、(ii) 计划所需证书租约有效、(iii) VLA 计划指称落地且语义租约有效 的条件下，系统安全性只依赖 hi 路径，与 VLA 的延迟、超时、错误无关；且 `∀t, Exec_v24(t) ⊆ Exec_v23(t)`。

**证明**：由引理 2 得逐时刻包含。由引理 3，hi 路径的截止期与 VLA 无关；由引理 1，证书过期只会使执行域收缩到最坏假设。VLA 的唯一入口 `compile` 受 GAC 与语义租约约束，失败即返回空提议，系统回落到预置安全技能库。因此 VLA 的任意行为只能影响"能否提出新计划"（活性），不能影响"已准入计划是否安全"（安全性）。∎

## 4. 已知风险与缓解

| 编号 | 描述 | 严重度 | 缓解措施 | 剩余风险 |
|---|---|---|---|---|
| R1 | `τ_phys` 标定过于乐观（低估相对加速度/反应延迟），租约在物理上已失效却仍被判有效 | 最高 | 1) 用在线相对速度/加速度上界而非额定值；2) 认证间隙扣除反应距离；3) 租约到期前强制预刷新（提前 `τ_sched` 裕度） | 突发外力/传感器延迟尖峰可能超出上界 |
| R2 | VLA 指称落地幻觉 + 长语义租约：几何内核无法观测语义突变，执行"几何合规但语义错误"的动作 | 最高 | 1) 唯一匹配 + 覆盖约束，歧义即拒；2) 语义租约事件驱动撤销（新观测矛盾即作废）；3) 高风险语义动作强制第二模态确认 | 无新观测到达时，语义租约仍可能"静默过期" |
| R3 | 混合关键度模式切换抖动（频繁 hi/lo）导致活性坍缩 | 高 | 1) 滞回阈值 `U_hi + U_reserve + h`；2) 最小驻留时间；3) VLA 负载整形与降采样 | 极端突发下仍可能长时间停留 hi 模式 |
| R4 | `Δ_fresh` 过紧导致法定人数饥饿（频繁 CI），过松则采信陈旧票 | 中 | 1) 由通信延迟分布 P99 标定；2) 时钟偏斜校正；3) 动态窗口但设上下界 | 网络分区与状态突变同时发生时难以两全 |
| R5 | 投机执行前缀过长，回滚代价高或护盾切换不平滑 | 中 | 1) 前缀长度受最短租约约束；2) 护盾内只允许可逆准备动作；3) 平滑回滚轨迹预计算 | 高速运动下回滚可能触发急停 |
