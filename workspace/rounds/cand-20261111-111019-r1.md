# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 1 轮；本轮灵感：「状态隔离」×「轨迹优化」）

> 第 54 轮把技能组合提升为「动作空间剖面 α_S + 动作兼容图 G_S + 云边映射 γ_ce + 动作-鲁棒性联合证书 J」，但隐含了两个强假设：**状态是全局共享、可由执行器隐式复位的**；**组合可行性可由逐点动作覆盖与边级兼容性判定**。本轮用「状态隔离」拆掉第一个假设，用「轨迹优化」拆掉第二个假设，把技能组合从「动作空间的点集匹配」推进到「状态所有权受限下的轨迹级可行性」。核心矛盾为 H22/H23。
>
> H22：**动作兼容不等于状态兼容**。组合边界处 S_i 的控制器内部状态、记忆、标定偏置与任务上下文会泄漏进 S_j，导致逐点动作覆盖成立、执行时却系统性漂移。
> H23：**全局状态耦合使云边轨迹规划不可解、证书不可组合**；且逐点 `min_d ρ(d)` 只保证某一时刻的鲁棒性，无法保证整条轨迹，轨迹中段的短暂低裕度会被端点证书掩盖。

## 0. 直觉与动机

**灵感 1（状态所有权，而非全局状态）**
直觉：技能不是「在整个状态空间上随意读写」，而是拥有一个**状态所有权分区**。把状态空间拆成三块：`X_own(S)`（只有 S 可写）、`X_read(S)`（S 可读不可写）、`X_forbid(S)`（S 禁止进入）。两个技能组合时，唯一合法的状态传递通道是显式声明的**接口变量 I_{ij}**。这样，「谁的状态」从隐含约定变成可检查的一阶约束——**动作空间回答“能怎么动”，状态所有权回答“能碰谁”**。

**灵感 2（状态泄漏 → 可度量的隔离指数）**
直觉：即使接口声明了，隐式耦合仍会通过共享变量、未复位积分器、标定漂移发生。定义**泄漏 λ(S_i,S_j)**：S_j 执行时对 S_i 私有状态的、超出接口的最大扰动放大率。`λ≈0` 表示强隔离，`λ` 大表示状态污染。于是组合可行性从二值的「兼容/不兼容」升级为**带泄漏预算的连续判据**：`λ ≤ δ_s` 才允许拼接，并给出隔离证书而不是口头保证。

**灵感 3（轨迹优化从全局耦合到块对角）**
直觉：既然状态被隔离成若干块，整条轨迹也应沿块边界切开：`τ = τ_1 ⊕ ... ⊕ τ_K`，每块在自己的 `B_k` 上独立优化，块之间只通过交接契约 `H_k` 耦合。这天然是**块对角最优控制 + 边界一致性约束**，可用 ADMM/iLQR 分解：各块并行解局部 OCP，主问题只对齐边界状态。全局最优性 gap 由边界对偶残差控制；当交接映射是收缩的（L_h<1），gap 随轨迹块数几何衰减。这把「云边协同优化一条全局轨迹」变成「分块可证、边界可查」。

**灵感 4（轨迹鲁棒性谱 + 隔离屏障，而非终点鲁棒性）**
直觉：证书不应只记终点 `ρ`，而应记整条轨迹的**最小裕度** `M(τ)=min_t min_d ρ_τ(t,d)`，并把状态泄漏与交接误差折算成裕度扣减：`M(τ)=min_t min_d [ρ_{S(t)}(d) - c_h·δ_h(t) - c_s·λ(t)]`。执行时用**控制屏障函数（CBF）** `h_{ij}(x)≥0` 强制不进入他人 `X_forbid`，把“隔离”从规划期约定变成运行期硬约束。规划器可以乐观，屏障负责兜底，二者共同构成轨迹级证书。

**灵感 5（云边状态隔离协同与反向重划分）**
直觉：云端拥有粗状态块 `B_c`，边端拥有细状态块 `B_e`，只有接口 `I_ce` 跨域同步；云端规划粗轨迹，边端在 `B_e` 内做细化轨迹优化并校验 `M(τ)`。若边端 Monitor 发现 `λ>δ_s` 或 `M(τ)<ρ_min`，`Explain_iso` 回传的不是“哪个动作失败”，而是**哪个状态变量被越权改写、属于谁、在哪个交接点**；云端据此执行**状态所有权重划分**（把变量提升为共享接口 / 新建状态块 / 收缩 forbid 集）并重优化。这形成 **状态隔离 → 分块轨迹优化 → 边界校验 → 泄漏根因回传 → 重划分** 的闭环，比第 54 轮的动作重剖分更接近故障本体。

## 1. 形式化定义（增量：定义 121–128）

**定义 121（状态所有权划分）**
状态空间 `X` 上，技能 `S` 的所有权划分为三元组 `σ_S = (X_own(S), X_read(S), X_forbid(S))`，满足 `X = X_own(S) ⊔ X_read(S) ⊔ X_forbid(S)`，且写集 `W(S) ⊆ X_own(S)`。并发技能 `S_i,S_j` 的状态隔离条件为 `X_own(S_i) ∩ X_own(S_j) = ∅`。组合后的块划分记为 `π: X → {B_1,...,B_K}`，`B_k` 为某技能独占的状态块。

**定义 122（状态交接契约）**
组合边界 `S_i → S_j` 的交接契约 `H_{ij} = (I_{ij}, ψ_{ij}, δ_h, τ_h)`：
- `I_{ij} ⊆ X_read(S_j)` 为唯一允许跨越的接口变量集；
- `ψ_{ij}: X|_{I_{ij}} → X|_{I_{ij}}` 为复位/坐标变换/观测重初始化映射；
- 交接失配 `δ_h(x) = ||ψ_{ij}(x|_{I_{ij}}) - x^+|_{I_{ij}}||`，预算 `δ_h ≤ Θ_h`；
- `τ_h` 为交接允许的时间窗。

**定义 123（状态泄漏与隔离指数）**
`S_j` 对 `S_i` 的状态泄漏
```
λ(S_i,S_j) = sup_{x∈X, 0<||δx||≤ε} || P_{own(S_i)\I_{ij}} ( Φ_{S_j}(x+δx) - Φ_{S_j}(x) ) || / ||δx||
```
其中 `Φ_{S_j}` 为 S_j 的执行算子，`P` 为到集合的投影。隔离指数 `iso(S_i,S_j)=exp(-λ)`；`λ ≤ δ_s` 时称**状态隔离成立**，并记 `iso ≥ iso_min`。

**定义 124（状态隔离轨迹优化 SITO）**
沿 `π` 把轨迹切为 `τ = τ_1 ⊕ ... ⊕ τ_K`，`τ_k = {(x_t,u_t)}_{t∈[t_{k-1},t_k]}`。SITO 求解
```
min_{τ} Σ_k [ Σ_{t∈[t_{k-1},t_k]} ℓ_k(x_t,u_t) + Φ_k(x_{t_k}) ]
s.t.  x_{t+1}=f_k(x_t,u_t)              (块内动力学)
      ψ_k(x_{t_k}) = z_k                (交接一致性, z_k 为边界变量)
      h_{ij}(x_t) ≥ 0                   (状态隔离屏障)
      x_{t_k} ∈ H_k,  u_t ∈ U_k
```
块间只通过 `z_k` 耦合，因此是**块对角 OCP**，可用 ADMM 分解为并行局部问题。

**定义 125（轨迹鲁棒性剖面与裕度）**
轨迹在时刻 t、维度 d 的鲁棒性 `ρ_τ(t,d) = ρ_{S(t)}(d) - c_h·δ_h(t) - c_s·λ(t)`。轨迹裕度
```
M(τ) = min_{t} min_{d∈𝔇} ρ_τ(t,d)
```
轨迹鲁棒性证书 `R_τ = (τ, M(τ), argmin_{t,d}, 敏感度 ∂M/∂λ, 置信度 β_T)`。

**定义 126（状态隔离轨迹证书）**
```
C_T = (σ, π, H, τ, M(τ), λ_max, δ_h, barrier_evidence, β_T)
```
其中 `λ_max = max_{i,j} λ(S_i,S_j)`。若 `M(τ) ≥ ρ_min ∧ λ_max ≤ δ_s ∧ δ_h ≤ Θ_h ∧ ∀t: h_{ij}(x_t) ≥ 0`，则 `C_T` 判定为**可部署**，记 `dom(C_T)=in`。

**定义 127（双轴可组合判据）**
技能组合 `S_i ⊗ S_j` 可采纳当且仅当
```
Adm(S_i,S_j) = [compat_a(S_i,S_j) ≥ θ_a]          (动作轴, 第54轮)
             ∧ [c_trans ≤ τ_e]                      (动作轴)
             ∧ [λ(S_i,S_j) ≤ δ_s]                   (状态轴)
             ∧ [δ_h ≤ Θ_h]                          (状态轴)
             ∧ [M(τ_{ij}) ≥ ρ_min]                  (轨迹轴)
```
第三条与第四条是本轮新增：**动作兼容只是必要条件，状态隔离与轨迹裕度才是充分性所在**。

**定义 128（云边状态隔离协同契约）**
`C_ce^iso = (B_c, B_e, γ_ce, H_ce, C_T, Explain_iso, π_remap)`：
- `B_c/B_e` 云端粗 / 边端细状态块，`B_c ∩ B_e = I_ce`；
- `γ_ce: B_c → B_e` 为第 54 轮动作映射，`H_ce` 为状态交接契约；
- `Explain_iso` 返回泄漏根因 `(x*, owner(x*), 交接点)`；
- `π_remap` 为所有权重划分算子，`π' = π_remap(π, Explain_iso)`。
闭环为 `规划 → 分块优化 → 边界校验 → 泄漏回传 → π_remap → 重优化`。

## 2. 关键算法伪代码

### IP-121 SOP（State Ownership Profiling）

```python
def state_ownership_profile(skill, X, probes):
    own, read, forbid = set(), set(), set()
    for x in X:
        for var in X.vars:
            effect = counterfactual_grad(skill, x, var, probes)  # ∂Φ/∂var
            if effect > eps_write:
                own.add(var)
            elif effect > eps_read:
                read.add(var)
    forbid = X.vars - own - read
    return Ownership(own, read, forbid)

def ownership_consistent(pi, skills):
    # 并发写作状态块不得重叠；组合链只在接口处共享
    for Si in skills:
        for Sj in skills:
            if Si is not Sj and pi.overlap(Si, Sj) - interface(Si, Sj):
                return False
    return True
```

### IP-122 SHC（State Handoff Contract Synthesis）

```python
def synthesize_handoff(Si, Sj, pi, delta_h_budget):
    I = pi.boundary(Si, Sj) | pi.shared(Si, Sj)
    psi = fit_reset_map(Si.exit_samples, Sj.entry_samples, I)  # 复位/坐标变换
    d_h = max_handoff_mismatch(psi, I, Si.exit_samples)
    if d_h > delta_h_budget:
        return ('reject', 'handoff_mismatch', d_h)
    return ('ok', Handoff(I=I, psi=psi, delta_h=d_h, tau_h=estimate_window(psi)))
```

### IP-123 SITO（State-Isolated Trajectory Optimization）

```python
def sito(blocks, handoffs, rho_min, iters=50):
    z = {k: init_boundary(blocks[k]) for k in blocks}       # 边界变量
    lam = {k: zeros_like(z[k]) for k in blocks}             # 对偶
    for _ in range(iters):
        tau = {}
        for k, blk in blocks.items():                       # 各块并行
            tau[k] = ilqr_local_ocp(
                blk, extra_cost=lambda x: (RHO/2)*norm(handoffs[k].psi(x) - z[k] + lam[k])**2,
                barrier=lambda x: isolation_barrier(x, blk))
        for k in blocks:                                    # 边界一致 + 对偶上升
            z[k] = project_H(handoffs[k].psi(tau[k][-1]) + lam[k])
            lam[k] += handoffs[k].psi(tau[k][-1]) - z[k]
        if dual_residual(lam) < tol and primal_residual(tau, z) < tol:
            break
    M = trajectory_margin(tau, blocks, handoffs)
    C_T = StateIsolatedCert(pi=blocks.partition, H=handoffs, tau=tau,
                            M=M, lam_max=measure_leakage(blocks),
                            delta_h=max_handoff(tau, handoffs), beta_T=confidence(M))
    return ('ok' if cert_deployable(C_T, rho_min) else 'reject', C_T)
```

### IP-124 TRC-T（Trajectory Robustness Certificate）

```python
def trajectory_margin(tau, blocks, handoffs, dims):
    M, worst = +inf, None
    for t, (x, u) in enumerate(tau):
        s = blocks.skill_at(t)
        d_h = handoffs.mismatch_at(t)
        leak = leakage_monitor(s, x)
        for d in dims:
            r = s.rho[d] - C_H*d_h - C_S*leak
            if r < M:
                M, worst = r, (t, d)
    return Margin(value=M, argmin=worst, dM_dlam=-C_S)
```

### IP-125 SIC（State Isolation Certificate）

```python
def isolation_certificate(skill_seq, pi, delta_s, probes):
    lam = {}
    for Si, Sj in pairwise(skill_seq):
        lam[(Si,Sj)] = sup_perturbation(
            Sj.execute, x0=pi.sample(Si), eps=PROBE_EPS,
            project=pi.own(Si) - pi.interface(Si,Sj))
    lam_max = max(lam.values())
    violations = [(k, v) for k, v in lam.items() if v > delta_s]
    return IsolationCert(lam=lam, lam_max=lam_max, iso=exp(-lam_max),
                         violations=violations, sound=(not violations))
```

### IP-126 CE-RIO（Cloud-Edge Repartition & Isolation Optimization）

```python
def cloud_edge_isolated_loop(T, B_c, B_e, pi, max_rounds=5):
    for r in range(max_rounds):
        P_c, C_T = sito(cloud_blocks(B_c, pi), handoffs=H_ce, rho_min=RHO_MIN)
        ok, reports = edge_verify(P_c, B_e, pi, C_T)          # 边端细轨迹 + SIC
        if ok:
            return ('deploy', C_T, P_c)
        exp = explain_iso(reports)                            # 泄漏根因
        pi_new = pi_remap(pi, exp, hysteresis=True)
        if pi_new == pi and r > 0:
            return ('abort', 'repartition_stalled', exp)
        pi = pi_new
    return ('abort', 'max_rounds', pi)
```

### IP-127 SITC（State-Isolated Transfer Certificate）

```python
def state_isolated_transfer_cert(src, tgt, phi, budgets):
    pi_t = push_forward_partition(src.pi, phi)                # 所有权映射
    if not ownership_consistent(pi_t, tgt.skills):
        return ('reject', 'ownership_collision')
    d_lam = {k: max(0, src.lam[k] - tgt.lam.get(k, 0)) for k in src.lam}
    d_M   = src.M - tgt.M
    d_h   = handoff_drift(src.H, tgt.H, phi)
    if sum(d_lam.values()) > budgets.lam or d_M > budgets.rho or d_h > budgets.h:
        return ('reject', 'isolation_budget', d_lam, d_M, d_h)
    return ('ok', SITCert(src, tgt, pi_t, phi, d_lam, d_M, d_h, src.evidence))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| SOP | O(|X|·|S|·n_probe) | O(|X|·|S|) | 反事实探测覆盖私有写集 |
| SHC | O(|I|²·n_sample) | O(|I|²) | 复位映射 Lipschitz、失配可测 |
| SITO | O(m·Σ_k(n_x,k³+n_u,k³)) | O(Σ_k n_x,k²) | 块对角化等价、对偶残差收敛 |
| TRC-T | O(T·|𝔇|·|S|) | O(T·|𝔇|) | 裕度下界 sound、泄漏上界保守 |
| SIC | O(|S|²·|X|·n_probe) | O(|S|²) | 探测扰动覆盖 forbid 集 |
| CE-RIO | O(r·(SITO + SIC)) | O(r·|π|) | π_remap 单调、hysteresis 收敛 |

**等价性命题（Block-Diagonal Exactness）**
若 `λ_max=0` 且 `δ_h=0`，则 SITO 的块对角问题与原全局 OCP 等价，其解拼接即为全局可行解；若 `L_h<1`（交接映射收缩），ADMM 的边界对偶残差随迭代几何收敛，全局次优 gap 满足
```
J(τ) - J* ≤ (1/(2ρ)) Σ_k ||λ_k - λ_k*||² + (L_h/(1-L_h))·Σ_k ||z_k - ψ_k(x_{t_k})||²
```
即**隔离越强、交接越收缩，分块优化的最优性损失越小**。

**正确性定理（State-Isolated Composition Soundness）**
假设承接第 54 轮 (A26)–(A28)，并新增：**(A29)** 所有权划分保守，`X_forbid` 覆盖所有未声明的跨技能写；**(A30)** `ψ_{ij}` 为 Lipschitz 收缩映射，常数 `L_h<1`；**(A31)** 轨迹裕度估计 `M(τ)` 的置信度为 `1-β_T`；**(A32)** 屏障 `h_{ij}` 对隔离集是有效 CBF。则
```
P(success ∧ isolation_preserved)
  ≥ 1 - Σ_d (1-ρ_min(d)) - P(M(τ)<ρ_min) - P(λ_max>δ_s)
      - P(δ_h>Θ_h) - β_E - β_T
```
直觉：失败概率被拆成**轨迹鲁棒性赤字 + 隔离违背 + 交接失配 + 仿真-现实偏差 + 估计置信度**五份，每一项都有独立证书与监控，因而可在部署前逐项否决，而不是笼统地相信“组合兼容”。

## 6. 本轮最大风险

## 2. 关键算法 伪代码

### IP-121 SOP

```python
def state_ownership_profile(skill, X, probes):
    own, read = set(), set()
    for x in X:
        for var in X.vars:
            effect = counterfactual_grad(skill, x, var, probes)  # ∂Φ/∂var
            if effect > eps_write:
                own.add(var)
            elif effect > eps_read:
                read.add(var)
    forbid = X.vars - own - read
    return Ownership(own, read, forbid)

def ownership_consistent(pi, skills):
    for Si in skills:
        for Sj in skills:
            if Si is not Sj and (pi.overlap(Si, Sj) - interface(Si, Sj)):
                return False
    return True
```

def synthesize_handoff(Si, Sj, pi, delta_h_budget):
    I = pi.boundary(Si, Sj) | pi.shared(Si, Sj)
    psi = fit_reset_map(Si.exit_samples, Sj.entry_samples, I)

### IP-123 SITO（ADMM 块对角）

```python
def sito(blocks, handoffs, rho_min, iters=50):
    z = {k: init_boundary(blocks[k]) for k in blocks}
    lam = {k: zeros_like(z[k]) for k in blocks}
    for _ in range(iters):
        tau = {}
        for k, blk in blocks.items():                       # 块内并行
            tau[k] = ilqr_local_ocp(
                blk,
                extra_cost=lambda x: (RHO/2)*norm(handoffs[k].psi(x) - z[k] + lam[k])**2,
                barrier=lambda x: isolation_barrier(x, blk))
        for k in blocks:                                    # 边界一致 + 对偶上升
            z[k] = project_H(handoffs[k].psi(tau[k][-1]) + lam[k])
            lam[k] += handoffs[k].psi(tau[k][-1]) - z[k]
        if dual_residual(lam) < tol and primal_residual(tau, z) < tol:
            break
    M = trajectory_margin(tau, blocks, handoffs, DIMS)
    C_T = StateIsolatedCert(pi=blocks.partition, H=handoffs, tau=tau,
                            M=M, lam_max=measure_leakage(blocks),
                            delta_h=max_handoff(tau, handoffs),
                            beta_T=confidence(M))
    return ('ok' if cert_deployable(C_T, rho_min) else 'reject', C_T)
```

### IP-124 TRC-T

```python
def trajectory_margin(tau, blocks, handoffs, dims):
    M, worst = +inf, None
    for t, (x, u) in enumerate(tau):
        s = blocks.skill_at(t)
        d_h = handoffs.mismatch_at(t)
        leak = leakage_monitor(s, x)
        for d in dims:
            r = s.rho[d] - C_H*d_h - C_S*leak
            if r < M:
                M, worst = r, (t, d)
    return Margin(value=M, argmin=worst, dM_dlam=-C_S)
```

### IP-125 SIC

```python
def isolation_certificate(skill_seq, pi, delta_s, probes):
    lam = {}
    for Si, Sj in pairwise(skill_seq):
        lam[(Si,Sj)] = sup_perturbation(
            Sj.execute, x0=pi.sample(Si), eps=PROBE_EPS,
            project=pi.own(Si) - pi.interface(Si,Sj))
    lam_max = max(lam.values())
    violations = [(k, v) for k, v in lam.items() if v > delta_s]
    return IsolationCert(lam=lam, lam_max=lam_max, iso=exp(-lam_max),
                         violations=violations, sound=(not violations))
```

def cloud_edge_isolated_loop(T, B_c, B_e, pi, max_rounds=5):

        P_c, C_T = sito(cloud_blocks(B_c, pi), handoffs=H_ce, rho_min=RHO_MIN)

def state_isolated_transfer_cert(src, tgt, phi, budgets):

    if not ownership_consistent(pi_t, tgt.skills):
        return ('reject', 'ownership_collision')

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SOP | O(\|X\|·\|S\|·n_probe) | O(\|X\|·\|S\|) | 反事实探测覆盖私有写集 |
| SHC | O(\|I\|²·n_sample) | O(\|I\|²) | ψ Lipschitz、失配可测 |
| SITO | O(m·Σ_k(n_x,k³+n_u,k³)) | O(Σ_k n_x,k²) | 块对角等价、对偶残差收敛 |

| SITC | O(\|X\|·\|π\| + \|H\|) | O(\|X\|+\|π\|) | 所有权映射无碰撞、三预算闭合 |

**等价性命题（Block-Diagonal Exactness）**
若 `λ_max=0 ∧ δ_h=0`，SITO 的块对角问题与原全局 OCP 等价，块解拼接即全局可行解。若交接映射收缩 `L_h<1`，ADMM 边界对偶残差几何收敛，且
```
J(τ) - J* ≤ (1/(2ρ))·Σ_k ||λ_k-λ_k*||² + (L_h/(1-L_h))·Σ_k ||z_k-ψ_k(x_{t_k})||²
```
即**隔离越强、交接越收缩，分块优化的最优性损失越小**。

**正确性定理（State-Isolated Composition Soundness）**
承接第 54 轮 (A26)–(A28)，新增：**(A29)** 所有权划分保守，`X_forbid` 覆盖所有未声明跨写；**(A30)** `ψ_{ij}` 为 Lipschitz 收缩 `L_h<1`；**(A31)** `M(τ)` 置信度 `1-β_T`；**(A32)** `h_{ij}` 为有效 CBF。则
```
P(success ∧ isolation_preserved)
  ≥ 1 - Σ_d(1-ρ_min(d)) - P(M(τ)<ρ_min) - P(λ_max>δ_s)
      - P(δ_h>Θ_h) - β_E - β_T
```
关键：**动作兼容先验 → 状态隔离把关 → 轨迹裕度裁决 → 屏障运行兜底**，四项独立证书逐级否决。
