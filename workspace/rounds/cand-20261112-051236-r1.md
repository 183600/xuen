# 第 60 轮（承接第 59 轮「执行接地层」IP-145~151；灵感循环第 1 轮；本轮灵感：「鲁棒性」×「意图识别」）

> 第 59 轮把「证据—执行」的双向契约做到了物理层：BUQ 辨识电机结构性不确定性、ERTC 把嵌入式时序变成硬契约、EEIS 把 δ_f 编译成阻抗证书、CLEP 让执行实测成为第 5 模态。但它仍有一个未声明的最高前提：**高层意图 i 是正确的**。所有安全证书都是「条件于 i」的——机器人完全可以「极其安全地执行一个错误意图」。本轮两个灵感精准命中这条**意图层抽象泄漏**：**鲁棒性**揭示意图识别不是对高斯噪声的鲁棒分类，而是对**语义扰动、分布偏移、恶意注入、非平稳人类策略**的最坏情况决策；**意图识别**揭示意图不是一个标签，而是**带来源、授权、歧义、时效的隐变量**，必须像物理执行一样被证据接地、被证书约束。核心命题：**「把意图从不可质疑的输入，降格为需要证据接地、且在最小扰动球内保持的隐变量；把鲁棒性从执行层提升到意图层，形成意图—证据—执行的双证书闭环」**。

核心矛盾：
- **H32（意图接地缺失·安全证书的条件前提）**：v59 的部署界写满了 δ_exec、δ_ertc、δ_eeis，却没有一项「意图错误概率 δ_intent」。事实上 `P_safe = P(安全 | i 正确)·P(i 正确) + P(安全 | i 错误)·P(i 错误)`，而第二项可能因为「正确执行了错误目标」而变成灾难。**执行层的成功不能补偿意图层的错误**；一个稳定、精确、力限幅完美的接触，如果把「轻触」识别成「按压」，仍然是失败。
- **H33（语义鲁棒性·非高斯扰动）**：意图观测是自然语言、手势、注视、演示与上下文。扰动不是像素级高斯噪声，而是**否定、量词辖域、指代、省略、反讽、口音、同义改写、手势幅度差异、跨文化语用**，以及恶意的**指令注入/越权诱导**。干净测试集上的准确率越高，越可能掩盖最坏情况下的系统性错误；「平均鲁棒」不等于「安全鲁棒」。
- **H34（歧义—交互成本·提问悖论）**：意图天然欠定。正确动作往往是「问一句」，但提问消耗人的**注意力、耐心与信任预算 B_H**；过度提问导致信任崩塌与自动化偏见反向，过少提问导致「自信地做错」。鲁棒意图识别必须把「何时问、问谁、怎么问」纳入决策，而不是只优化分类准确率。
- **H35（意图漂移与来源可信·时效与权威）**：人的意图非平稳，可能因疲劳、环境变化、新信息而改变；旧意图会过期。更危险的是意图**来源不可信**：环境中的文本、语音、屏幕内容都可能是注入的攻击指令，或低权限者冒充高权限者。鲁棒性必须包含**意图鲜度 τ_intent** 与**来源权威格 A_σ**，否则执行层越精确，越可能成为越权/被诱导的「高保真执行器」。

## 0. 直觉与动机

**灵感 1（鲁棒性 → 意图识别即最坏情况逆问题 RIR）**
直觉：意图识别是从「行为/话语」反推「目标」的**逆问题**，天然病态。鲁棒性意味着不追求「在平均分布上猜得准」，而是追求「在语义扰动球 B_ε 与人类策略不确定性集 𝒫_ρ 内不犯致命错」。技术上对应三条线：**分布鲁棒优化（DRO）**把人类策略的不确定性写成 KL/Wasserstein 球，求最坏意图风险；**保形预测**输出一个覆盖真实意图的集合 C_α，而不是一个点标签；**随机平滑/改写增强**给出语义球内的认证半径。关键洞见：**意图识别的输出不应该是 `î`，而应该是 `(C_α, b^rob, R^rob)`——一个集合、一个鲁棒后验、一个最坏风险上界**。只有集合足够小、最坏风险足够低、且集合内所有意图都接受同一动作时，才允许承诺。

**灵感 2（意图识别 → 意图是带来源与授权的隐变量 IRU）**
直觉：把意图想成 `(目标 g, 硬约束 C, 偏好 P, 授权范围 A, 来源 σ)` 五元组，而不是一个类别。例如「把杯子放到桌上」隐含 `g=放置`、`C=不洒出/不碰倒其他物`、`P=轻放`、`A=允许移动该杯`、`σ=主人语音/访客手势/环境屏幕文本`。同一个词「放」在不同 `C/P/A` 下是完全不同的任务。鲁棒识别必须同时更新这五者；尤其 `A` 与 `σ` 决定「即使意图对，是否允许做」。这直接催生**意图证据门 IEG**：动作不仅要「符合意图」，还要「在来源权威与同意范围内」。

**灵感 3（鲁棒性 × 意图识别 → 双证书：Cert_intent ∧ Cert_eeis）**
直觉：v59 已经有物理安全证书 `Cert_eeis`，但它是对「给定意图」的编译。本轮补上**意图安全证书** `Cert_intent`：它声明「在扰动半径 ε、人类模型球 ρ、置信水平 1−α 下，意图集合 C_α 与最坏风险 R^rob ≤ δ_intent」。承诺动作必须同时通过两本证书：意图证书回答「做的是不是对的事、有没有权限」，执行证书回答「做的方式是否物理安全」。任一本为空 ⇒ 降级/询问/停止。**双证书不可互相替代**：物理证书再漂亮也不能证明意图正确；意图再确定也不能证明阻抗稳定。

**灵感 4（提问即探针 → 意图消歧探针 IDP）**
直觉：既然歧义是常态，「问一句」应被视为与视觉探针、触觉探针同等的**信息获取动作**，有 VOI、有成本、有预算。问「你是指 A 还是 B？」的 VOI 等于「问完后最坏意图风险下降的期望」减去人的注意力成本与执行延迟成本。关键：**人的信任是有限且不可逆消耗的资源**，错误提问/重复提问的边际成本递增；当信任预算低于阈值时，正确策略不是继续问，而是**转交人类接管或选择对所有意图都安全的保守动作**。这把 v59 的 PCE+++ 四预算扩展为**五预算**（探针/微调/解释/执行/人际交互）。

**灵感 5（漂移与来源 → 意图鲜度与权威格 IDR）**
直觉：意图和牛奶一样有保质期。`τ_intent > T_intent_renewal` 时，旧意图必须被视为无效证据；人的行为残差出现系统性偏移（CUSUM/贝叶斯变点）即触发**意图漂移**，自动加宽 `C_α` 并要求重新确认。来源可信则用一个**权威格** `A0<A1<A2<A3`：A0=环境文本/屏幕/未知语音，A1=已认证访客，A2=已认证主人，A3=安全官。动作要求的权限不得超过来源权威；来自 A0 的「打开阀门」永远不能被当作 A3 指令。鲁棒性在这里变成**抗语义注入的系统安全性质**，而不是模型准确率。

**灵感 6（合流 → 意图—鲁棒闭环 IRCL）**
直觉：把上述五者接进 v59 的 CLEP：观测 `o` → 意图后验 `b_I` → 鲁棒集合 `C_α` → 意图证据门 → 若歧义则 IDP 选探针（问人/物理探针/演示）→ 意图风险编译 `A_safe` → 物理安全编译 `K_safe` → 双证书下发 → 执行 → 收集 `EV-exec` 与 `EV-intent`（人的事后确认/纠正）→ 更新意图后验与信任预算 → 漂移检测。**EV-exec 只能通过「预测感官后果」辅助排序意图，绝不能替代人的确认，也不能因为「执行成功」而降低意图歧义**——这是本轮的「单向性」核心。

## 1. 形式化定义（增量：定义 153–160）

**定义 153（意图假设空间 IS）** 意图 `i=(g,C,P,A,σ) ∈ ℐ`：`g∈𝒢` 为目标；`C` 为硬约束集合（安全、法律、任务不变量）；`P` 为偏好/权重；`A` 为授权与同意范围（可执行动作子集）；`σ` 为来源及可信度（`A0<A1<A2<A3`）。观测 `o=(u,gh,gz,k,h,a_hist)` 分别表示话语、手势、注视、上下文、历史与既有动作。人类策略 `π_H(i|o)` 未知且非平稳。开集项 `i_∅` 表示「未知意图」，`ℐ⁺=ℐ∪{i_∅}`。

**定义 154（意图后验与歧义 IRU）** 后验 `b_I(i|o) ∝ p(o|i)·p(i|ctx)·p(σ)`，`i∈ℐ⁺`。歧义度三件套：
```
H_I(o) = −Σ_i b_I(i|o) log b_I(i|o)          # 熵
m_I(o) = b_(1)(o) − b_(2)(o)                 # 首选—次选间隔
C_α(o) = { i : s(o,i) ≤ q_{1−α} },  s(o,i)=1−b_I(i|o)   # 保形意图集
```
其中 `q_{1−α}` 为校准集非 conformity 分数的 `1−α` 分位数。`|C_α|=0` 判未知意图；`|C_α|>1` 判歧义；`m_I<θ_m` 判「不可承诺」。漂移与来源作为元状态附于 `i` 上（定义 159）。

**定义 155（语义扰动球与鲁棒意图识别 RIR）** 语义扰动球 `B_ε(o)={o' : d_ψ(o,o')≤ε}`，`d_ψ` 由语义嵌入距离、否定一致性、实体/辖域不变量、手势轨迹 DTW 组合而成。似然比不确定性球 `ℒ_κ(o)={L̃ : L̃_i/L_i∈[1/κ,κ], ∀i}`。由此得后验区间：
```
b⁻_i = (L_i/κ)·p_i / Σ_j (κ L_j)·p_j ,   b⁺_i = (κ L_i)·p_i / Σ_j (L_j/κ)·p_j
B_κ(o) = { b : Σ_i b_i=1, b⁻_i ≤ b_i ≤ b⁺_i }
```
鲁棒风险与鲁棒决策：
```
R^rob(a|o) = max_{b∈B_κ(o)} Σ_i b_i·R(a|i)
a* = argmin_{a∈A_act} R^rob(a|o) − λ_u·U(a|i)      # U 为任务效用
```
可选的语义随机平滑认证：`f_smooth(o)=argmax_i P_{η~q}[f(o+η)=i]`，在改写分布 `q` 下给出半径 `ε_cert`；但该半径**只对 q 定义的扰动族有效**，不得声称为任意语义攻击下的鲁棒性。

**定义 156（意图证据门 IEG）** 意图证据 `EV-intent=(C_α,m_I,H_I,R^rob,σ,A,τ_intent,attack_score,human_confirm)`。动作 `a` 通过意图门当且仅当：
```
(I1) C_α(o) ≠ ∅ 且 ∀i∈C_α(o): a ∈ A_compat(i)          # 所有可信意图都接受
(I2) R^rob(a|o) ≤ δ_intent^req                         # 最坏意图风险上界
(I3) (|C_α|=1 ∧ m_I≥θ_m) ∨ human_confirm(a, C_α)        # 唯一或已确认
(I4) A_req(a) ≤ min_{i∈C_α} σ_i                         # 权限不超过来源权威
(I5) τ_intent ≤ T_intent_renewal                        # 意图鲜度
(I6) irreversible/destructive ⇒ |C_α|=1 ∧ human_confirm  # 不可逆额外硬约束
```
**单向性**：`EV-exec` 不得用于满足 (I3)/(I6)，也不得通过「执行成功」缩小 `C_α` 或提高 `σ`。

**定义 157（意图风险编译器 IRC）** 给定 `δ_intent^req` 与物理可行性，编译安全动作集：
```
A_safe(o,δ) = { a : ∀i∈C_α(o), R(a|i) ≤ δ_i^req,
                    a ∈ A_compat(i), A_req(a) ≤ σ_i,
                    PhysicallyFeasible(a) = true }
a† = argmax_{a∈A_safe} U(a; b^rob)      s.t.  Σ_{i∈C_α} δ_i^req ≤ δ_intent^req
```
若 `A_safe=∅` ⇒ 升级（询问/转交/绕行/停止），绝不回退到「最可能意图」的贪心动作。输出 `Cert_intent=(C_α, α, m_I, H_I, R^rob, δ_intent^req, σ_min, τ_intent, probe_log, version)`；承诺要求 `Cert_intent ∧ Cert_eeis`。

**定义 158（意图消歧探针 IDP）** 探针集 `P_int={clarify, demo, physical_probe, show_alternative, defer}`。意图信息价值：
```
VOI_int(p) = E_{o'~p(o'|o,p)}[ min_a R^rob(a|o') ] − min_a R^rob(a|o)
             − λ_H·cost_H(p) − λ_E·cost_exec(p)
```
其中 `cost_H` 包含注意力、时间与信任消耗；人类交互预算 `B_H=(B_attn,B_time,B_trust)` 单调消耗且**信任不可完全恢复**。仅当 `VOI_int(p)>θ_voi` 且 `B_H` 足够时提问；否则选择保守动作或升级。问题选择还须满足「最小充分性」：只问能改变 `A_safe` 的问题，不问「为问而问」。

**定义 159（意图漂移与来源可信 IDR）** 漂移检测用 CUSUM：`S_t=max(0,S_{t−1}+log[p(o_t|i_alt)/p(o_t|i_nom)]−ν)`，`S_t>h` 判漂移。漂移 ⇒ `α←α'<α`（加宽 `C_α`）、`τ_intent` 失效、要求重新确认。来源权威格 `A0<A1<A2<A3` 与注入评分 `attack_score(o)∈[0,1]`：`σ_eff=σ·(1−attack_score)`；来自 A0 的文本/屏幕内容不得提升意图权威，不得触发不可逆动作。意图鲜度 `τ_intent=now−t_last_confirm`。

**定义 160（意图—鲁棒闭环 IRCL 与 J_intent）** 算子 `IRCL(M, o, δ_f^req, B)`：
```
① Observe: o_t ← (utterance, gesture, gaze, context, history)
② IRU: b_I ← intent_posterior_update(b_I, o_t);  (H_I,m_I,C_α) ← ambiguity(b_I)
③ IDR: if drift_detected(o_t) ∨ τ_intent>T_intent_renewal:
          α←α'; C_α←recompute; require_reconfirm=True
④ RIR: B_κ←likelihood_ratio_ball(κ); b^rob,R^rob←robust_posterior(b_I,B_κ)
⑤ IEG: if not intent_gate(C_α,b^rob,R^rob,σ,τ): 
          if ambiguity: p*←IDP.select(C_α,b^rob,B); return ASK_OR_DEFER(p*)
⑥ IRC: A_safe,Cert_intent←compile_intent(C_α,b^rob,δ_intent^req,σ)
          if A_safe=∅: return ESCALATE
⑦ CLEP: (M,·,·,EV_exec,Cert_eeis) ← closed_loop_exec_probe(M, cp(a†), δ_f^req, B)
          if Cert_eeis=∅: return DEGRADE_EXEC
⑧ Dual Gate: if ¬(Cert_intent ∧ Cert_eeis): return ASK_OR_STOP
⑨ Execute & Collect: EV-exec, EV-intent(human_feedback)
⑩ Update: b_I←posterior_update(EV-intent, EV-exec_predicted_consequence)
           B_H←spend(B_H, probes); τ_intent←now; J_intent.append(...)
⑪ Return (M, a†, Cert_intent, Cert_eeis, EV-exec, EV-intent, J_intent)
```
`J_intent=(b_I 轨迹, C_α, H_I/m_I, R^rob, probe_log, consent_log, drift_state, provenance/authority, Cert_intent 链, version, timestamp)`。

## 2. 关键算法伪代码（核心片段）

### IP-153 RIR（鲁棒意图识别）

```python
class RobustIntentRecognizer:
    def __init__(self, encoder, calibrator, kappa=2.0, alpha=0.05):
        self.encoder = encoder
        self.calibrator = calibrator      # conformal 校准集
        self.kappa = kappa                # 似然比不确定性半径
        self.alpha = alpha

    def predict(self, o):
        b = self.intent_posterior(o)                    # b_I(i|o)
        C = self.conformal_set(b, self.alpha)           # C_α
        b_lo, b_hi = self.likelihood_ratio_bounds(b, self.kappa)
        R_rob = self.robust_risk(C, b_lo, b_hi)         # LP / 顶点枚举
        return IntentBelief(b=b, C=C, b_lo=b_lo, b_hi=b_hi, R_rob=R_rob,
                            H=entropy(b), m=top1_minus_top2(b),
                            unknown=(len(C) == 0))

    def conformal_set(self, b, alpha):
        # 非 conformity: s(o,i)=1-b_I(i|o)；q 为校准集 1-alpha 分位数
        q = self.calibrator.quantile(alpha)
        return [i for i, p in enumerate(b) if 1 - p <= q]

    def likelihood_ratio_bounds(self, b, kappa):
        # 由 b ∝ L_i p_i 反推区间；边界解为顶点，鲁棒风险在顶点取到
        prior = self.prior
        lo = (b / kappa) / np.sum(b / kappa + (1 - b) * kappa)  # 简化形式
        hi = (b * kappa) / np.sum(b * kappa + (1 - b) / kappa)
        return lo, hi

    def robust_risk(self, C, b_lo, b_hi):
        # max_{b∈B} Σ b_i R(a|i)，B 为盒约束+单纯形；LP 顶点枚举或 linprog
        best = -np.inf
        for a in self.actions:
            worst = linprog(c=-self.risk_vector(a), A_eq=[np.ones(len(b_lo))],
                            b_eq=[1], bounds=list(zip(b_lo, b_hi)))
            best = max(best, -worst.fun)
        return best
```

### IP-157 IRCL（意图—鲁棒闭环）

```python
def intent_robust_closed_loop(M, o_t, delta_f_req, budget):
    # ① IRU
    M.b_I = update_intent_posterior(M.b_I, o_t, M.meta.intent_prior)
    H, m, C = ambiguity(M.b_I)
    # ② IDR：漂移/鲜度/来源
    if M.drift_detector.update(o_t) or M.tau_intent > T_INTENT_RENEWAL:
        C = recompute_conformal(M.b_I, alpha_prime=ALPHA_WIDE)
        M.require_reconfirm = True
    sigma_min = min_source_authority(C, o_t)
    # ③ RIR
    b_rob, R_rob = robust_posterior(M.b_I, kappa=KAPPA)
    # ④ IEG
    if not intent_gate(C, m, R_rob, sigma_min, M.tau_intent, M.require_reconfirm):
        if ambiguous(C, m):
            p = M.idp.select(C, b_rob, budget, M.B_H)
            if p is None:
                return escalate(M, "intent_ambiguous_no_budget")
            return ask_or_defer(M, p)
        return escalate(M, "intent_gate_reject")
    # ⑤ IRC
    A_safe, cert_int = M.irc.compile(C, b_rob, delta_f_req, sigma_min, M)
    if not A_safe:
        return escalate(M, "intent_infeasible")
    a = argmax_utility(A_safe, b_rob)
    # ⑥ CLEP 物理闭环
    M, fused, D, ev_exec, cert_eeis = closed_loop_exec_probe(M, cp_for(a), delta_f_req, budget)
    # ⑦ 双证书
    if cert_eeis is None or not dual_certificate_valid(cert_int, cert_eeis):
        return ask_or_stop(M, "dual_cert_failed")
    # ⑧ 执行证据与意图证据
    ev_int = build_intent_evidence(C, m, R_rob, sigma_min, M.tau_intent,
                                   M.probe_log, M.consent_log)
    M.B_H = spend_human_budget(M.B_H, M.probe_log)
    M.tau_intent = now()
    M.J_intent.append(make_intent_certificate(cert_int, ev_int))
    return M, a, cert_int, cert_eeis, ev_exec, ev_int
```

| 组件 | 时间 | 空间 | 正确性保证 |

**正确性定理（Robust Intent-Grounded Safety, RIGS）** 假设 A22–A55（v53–v59）成立；**(A56)** 校准集与测试意图在 `α` 水平上可交换，或分布偏移落在 `𝒫_shift` 内且加权保形覆盖成立；**(A57)** 人类策略真实分布落在似然比球 `ℒ_κ`/DRO 球内；**(A58)** `R(a|i)` 是真实任务失败概率的诚实上界；**(A59)** 意图来源权威格与注入评分音完备；**(A60)** 人类确认真实反映意图且不可被环境文本伪造；**(A61)** `A_safe` 编译器音完备。则：

1. **鲁棒意图覆盖**：`P(i∈C_α(o)) ≥ 1−α−δ_shift−δ_κ`；`|C_α|=0` 时系统不承诺，未知意图不会被强行归类。
2. **意图条件安全**：若动作通过 IEG 与 IRC，则真实 `P(failure|a) ≤ δ_f^req + δ_intent^req + δ_model`，其中 `δ_model` 来自 `R^rob` 的模型误差界。
3. **双证书健全性**：任何承诺满足 `Cert_intent ∧ Cert_eeis`；任一证书为空 ⇒ 系统只能询问、升级或停止。
4. **非替代性（单向性）**：`EV-exec` 只能通过「预测感官后果」加宽/重排意图后验，不能替代人类确认、不能缩小 `C_α`、不能提升来源权威；执行成功不能降低意图歧义。
5. **单调保守性**：`ε↑`、`κ↑`、`ρ↑`、`τ_intent↑`、`attack_score↑` 只会使 `A_safe` 单调收缩（或不变），绝不扩大；`B_H` 耗尽只会更保守。
6. **终止性**：IRCL 在有限探针/询问次数内终止于 {承诺（双证书）, 询问, 绕行, 降级, 转交, 停止}。

### IP-153 RIR（鲁棒意图识别）

```python
class RobustIntentRecognizer:
    def __init__(self, model, calibrator, kappa=2.0, alpha=0.05, sigma_smooth=0.05):
        self.model = model
        self.calibrator = calibrator
        self.kappa = kappa
        self.alpha = alpha
        self.sigma_smooth = sigma_smooth

    def predict(self, o, actions, risk_fn):
        b = self.model(o)                                  # b_I(i|o)
        C = self.calibrator.conformal_set(b, self.alpha)
        lo, hi = self.likelihood_ratio_bounds(b, self.kappa)
        # 鲁棒风险：在盒约束 + 单纯形上取最坏；线性规划，最坏解在顶点
        R_rob = {}
        for a in actions:
            r = np.array([risk_fn(a, i) for i in range(len(b))])
            R_rob[a] = max_linear_over_simplex(r, lo, hi)
        return b, C, lo, hi, R_rob

    def likelihood_ratio_bounds(self, b, kappa):
        # b_i ∝ L_i p_i；真实 L̃_i/L_i ∈ [1/κ,κ]
        # 上界：本类似然放大 κ、其余缩小 κ；下界反之
        n = len(b)
        hi = np.minimum(1.0, kappa * b / (kappa * b + (1 - b) / kappa + 1e-12))
        lo = np.maximum(0.0, (b / kappa) / (b / kappa + (1 - b) * kappa + 1e-12))
        # 数值归一化到可行单纯形盒
        return project_to_box_simplex(lo), project_to_box_simplex(hi)

    def robust_decision(self, R_rob, utility):
        # 最小化最坏风险，效用只作同风险下的次级排序
        return min(R_rob, key=lambda a: (R_rob[a], -utility(a)))

    def certified_semantic_radius(self, o, paraphrase_sampler, n=1000):
        # 改写随机平滑：只对 paraphrase_sampler 定义的扰动族有效
        votes = defaultdict(int)
        for _ in range(n):
            o2 = paraphrase_sampler(o)
            votes[self.model.argmax(o2)] += 1
        top = max(votes.values()) / n
        # 二项下界 (Clopper-Pearson) 转认证半径
        return smoothed_radius(top, n, self.sigma_smooth)

def max_linear_over_simplex(r, lo, hi):
    """max r·b s.t. Σb=1, lo≤b≤hi。线性规划：最坏解在顶点（贪心填充）。"""
    b = lo.copy()
    remaining = 1.0 - b.sum()
    order = np.argsort(-r)                # 风险大的维度优先填到上界
    for i in order:
        add = min(hi[i] - b[i], remaining)
        b[i] += add
        remaining -= add
        if remaining <= 1e-12:
            break
    return float(r @ b)
```

### IP-154 IEG（意图证据门）

```python
def intent_gate(C, margin, R_rob, sigma_min, tau_intent, attack_score,
                require_reconfirm, action, irreversibility):
    if not C:
        return False, "intent_unknown"
    # (I1) 所有可信意图都接受该动作
    if not all(action in intent_compat(i) for i in C):
        return False, "not_compatible_with_all_intents"
    # (I2) 最坏意图风险
    if R_rob[action] > delta_intent_req(action):
        return False, "robust_intent_risk"
    # (I3) 唯一且 margin 足够，或已人类确认
    if not ((len(C) == 1 and margin >= THETA_M) or human_confirmed(action, C)):
        return False, "ambiguous_or_unconfirmed"
    # (I4) 权限不超过来源权威
    if required_authority(action) > sigma_min:
        return False, "authority_insufficient"
    # (I5) 意图鲜度
    if tau_intent > T_INTENT_RENEWAL or require_reconfirm:
        return False, "intent_stale"
    # (I6) 不可逆/破坏性动作额外硬约束
    if irreversibility(action) and not (len(C) == 1 and human_confirmed(action, C)):
        return False, "irreversible_needs_singleton_and_consent"
    return True, "ok"
```

### IP-155 IRC（意图风险编译器）

```python
class IntentRiskCompiler:
    def compile(self, C, b_rob, delta_intent_req, sigma_min, M, action_space):
        # Boole 风险分配：δ_intent → 每个可信意图的风险预算
        delta_per_intent = delta_intent_req / max(1, len(C))
        A_safe = []
        for a in action_space:
            ok = True
            for i in C:
                r = M.risk_model.task_failure_prob(a, i, M.b_r, M.xi_exec)
                if r > delta_per_intent:
                    ok = False; break
                if a not in intent_compat(i):
                    ok = False; break
                if required_authority(a) > min(i.sigma for i in C):
                    ok = False; break
                if not M.eeis.is_physically_feasible(a):
                    ok = False; break
            if ok:
                A_safe.append(a)
        if not A_safe:
            return None, None

        return a_star, cert
```

### IP-158 IDR（意图漂移与来源可信）

```python
class IntentDriftDetector:
    def __init__(self, nu=0.5, h=5.0):
        self.S = 0.0
        self.nu, self.h = nu, h

    def update(self, o_t, b):
        # CUSUM：名义意图 vs 最佳替代意图的似然比
        i_nom = int(np.argmax(b))
        i_alt = int(np.argsort(b)[-2])
        llr = np.log(self.likelihood(o_t, i_alt) + 1e-12) \
            - np.log(self.likelihood(o_t, i_nom) + 1e-12)
        self.S = max(0.0, self.S + llr - self.nu)
        if self.S > self.h:
            self.S = 0.0
            return True
        return False

def source_weight(o, i):
    # 来源权威格与注入评分；环境文本/屏幕内容不得抬升权威
    base = {0: 0.1, 1: 0.5, 2: 0.9, 3: 1.0}[i.sigma]
    return base * (1.0 - o.attack_score)

def provenance_check(action, source):
    # 动作所需权威 ≤ 来源权威；不可逆动作要求 A2+ 且人工确认
    if required_authority(action) > source.sigma:
        return False, "authority_violation"
    if irreversibility(action) and source.sigma < 2:
        return False, "irreversible_low_authority"
    return True, "ok"
```

## 3. 推导与正确性

### 3.1 最坏意图风险是盒约束单纯形上的线性规划

给定动作 `a`，令 `r_i=R(a|i)`，`B_κ={b:Σb_i=1, b⁻_i≤b_i≤b⁺_i}`。则
```
R^rob(a|o) = max_{b∈B_κ} rᵀb
```
是线性目标在紧凸多面体上的最大化，**最优解必在顶点**。顶点结构为：每个 `b_i∈{b⁻_i,b⁺_i}`，且至多一个分量处于区间内部以补齐 `Σb=1`。因此贪心「按 `r_i` 从大到小填到上界」在 `O(|ℐ| log|ℐ|)` 内得到精确最坏值（若 `Σb⁺≥1≥Σb⁻`，可行域非空）。这避免了每次调用通用 LP 求解器，适合嵌入式在线执行。

### 3.2 保形覆盖与分布偏移

在可交换性下，`P(i∈C_α)≥1−α`。若测试分布 `P_test` 与校准分布 `P_cal` 的 TV 距离为 `δ_shift`，则加权保形（权重 `w=dP_test/dP_cal`）的覆盖下界退化为 `1−α−δ_shift`；若只用无权重保形，则偏移会直接破坏覆盖。因此 `Cert_intent` 必须记录 `α`、校准集版本与 `δ_shift` 估计，**不得跨重大分布变化复用同一保形阈值**。这也是 `τ_intent` 与漂移检测存在的理由：意图分布变化时，旧 `C_α` 的覆盖保证失效。

### 3.3 双证书的联合安全界

设 `F` 为任务失败事件。若动作通过双证书，则
```
P(F) ≤ P(F | i∈C_α, 物理安全) + P(i∉C_α)
     ≤ δ_f^req + δ_intent^req + δ_model + δ_shift
```
其中 `δ_f^req` 来自 v59 的 `Cert_eeis`，`δ_intent^req` 来自 `R^rob` 与 `A_safe` 的风险分配，`δ_shift` 来自保形偏移，`δ_model` 来自 `R(a|i)` 的模型误差。**关键**：`δ_f^req` 无法吸收 `δ_intent^req`；物理上再安全，也不能把意图错误项归零。因此部署界必须显式并列两项。

### 3.4 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| IRU | O(\|ℐ\|·d_o)/更新 | O(\|ℐ\|) | 后验归一、开集 `i_∅`、歧义三件套 |
| RIR | 保形 O(\|ℐ\|)；鲁棒风险 O(\|𝒜\|·\|ℐ\| log\|ℐ\|) | O(\|ℐ\|²) | 覆盖 ≥1−α−δ_shift；`R^rob` 为 `B_κ` 内精确最坏（线性规划顶点解） |
| IEG | O(\|C_α\|·\|𝒜\|) | O(\|𝒜\|) | 六条规则；执行证据不可替代确认 |
| IRC | O(\|𝒜\|·\|C_α\|) | O(\|𝒜\|) | `A_safe=∅` ⇔ 无动作满足全部可信意图 + 权限 + 物理可行 |
| IDP | O(\|P_int\|·\|𝒜\|·\|C_α\|) | O(\|P_int\|) | VOI 诚实；信任预算单调；最小充分性 |
| IRCL | O(IRU+RIR+IRC+CLEP)/检查点 | 复用 v59 | 双证书；终止于 {承诺,询问,绕行,降级,转交,停止} |
| IDR | CUSUM O(1)/观测 | O(1) | 漂移检测延迟/误报由 `(ν,h)` 控制 |
| J_intent | O(1)/检查点追加 | O(检查点数) | 版本单增、风险≤预算、集合非空、时戳对齐 |

**正确性定理（Robust Intent-Grounded Safety, RIGS）** 假设 A22–A55（v53–v59）成立；**(A56)** 保形校准在 `α` 水平可交换，或偏移落在 `𝒫_shift` 内且加权覆盖成立；**(A57)** 真实人类策略落在似然比球 `ℒ_κ` / DRO 球内；**(A58)** `R(a|i)` 是真实任务失败概率的诚实上界；**(A59)** 来源权威格与注入评分音完备；**(A60)** 人类确认真实且不可被环境文本伪造；**(A61)** `A_safe` 编译器音完备。则：

1. **鲁棒意图覆盖**：`P(i∈C_α)≥1−α−δ_shift−δ_κ`；`C_α=∅` 时系统不承诺。
2. **意图条件安全**：通过 IEG/IRC 的动作满足真实 `P(failure|a)≤δ_f^req+δ_intent^req+δ_model`。
3. **双证书健全性**：任何承诺满足 `Cert_intent∧Cert_eeis`；任一为空只能询问/升级/停止。
4. **非替代性（单向性）**：`EV-exec` 只能作为「预测后果」加宽或重排意图后验，不能替代人类确认、不能缩小 `C_α`、不能提升来源权威；执行成功不能降低意图歧义。
5. **单调保守性**：`ε↑`、`κ↑`、`ρ↑`、`τ_intent↑`、`attack_score↑`、`B_H↓` 只会使 `A_safe` 单调收缩，绝不扩大。
6. **终止性**：IRCL 在有限探针/询问次数内终止于 {承诺（双证书）, 询问, 绕行, 降级, 转交, 停止}。

**部署界（v59 的扩展）**：
```
P_safe ≥ 1 − Σ_cp ( δ_f·1[i正确] + δ_intent + δ_shift + δ_ambig + δ_drift + δ_auth
                    + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1]
                    + δ_ft·1[回滚窗口] + δ_kg·1[检索失败] + δ_ux·1[μ_mis>θ_mis]
                    + δ_exec·1[ξ_exec漂移] + δ_ξ_ood·1[执行OOD] + δ_ertc·1[契约违例]
                    + δ_eeis·1[μ分析漏报] )
         − P(意图注入未被来源权威拦截) − P(人类确认被伪造)
```
**与 v59 的本质差别**：v59 的 `δ_f` 是「意图正确时的物理失效率」；本轮的 `δ_intent` 是「意图错误/歧义/漂移/越权」的独立项，不能被任何执行层改进吸收。
