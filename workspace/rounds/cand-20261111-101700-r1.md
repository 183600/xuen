# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「结构优化」×「意图理解」）

> 第 54 轮把技能组合推进到动作空间剖面与云边协同，形成动作-鲁棒性联合证书 J，但仍隐含两个假设：**任务动作序列 A_T 是给定的点**、**技能组合图 G_S 是给定的结构**。本轮同时翻转这两点：把 A_T 还原为观测背后的**意图隐变量**，把 G_S 从“最大兼容图”改为“意图保持的最小商图”。核心矛盾：H22：点式 A_T 使证书只对一个意图切片 sound，意图歧义与漂移会让 J 在真实用户上系统性失效；H23：结构“越全越好”造成过参数化与虚假兼容，而结构“越简越好”会抹掉意图必需的动作区分——**结构复杂度与意图分辨力必须联合优化，而不是分别调参**。

## 0. 直觉与动机

**灵感 1（意图不是点，而是信念分布）**
直觉：用户说“把桌面收拾一下”时，真正决定成败的是“整理到什么程度、哪些物体可动、是否允许堆叠”等一组隐意图，而不是某条固定动作序列。应把意图 `I` 建模为隐变量，观测 `o`（语音/上下文/历史）给出信念 `b(I)=P(I|o)`，每个意图诱导任务动作序列分布 `P(A_T|I)`。证书不该只对某个 `A_T` 成立，而应在 `b` 的 α-分位上成立：`ρ_α(d)=Quantile_α{ρ(I,d): I~b}`。这把“任务给定”升级为“**意图覆盖**”：不是保证一个任务，而是保证信念支撑上的高概率意图。

**灵感 2（结构优化 = 意图保持的商图，而非最大兼容图）**
直觉：第 54 轮的 `compat ≥ θ_a` 把所有动作相容的技能都连边，本质是“结构最大化”。但真实需要的结构，是**恰好保留会改变计划所需区分**的最小商图。若两技能对所有高概率意图产生不可区分的成功概率、覆盖判定与证书判定，则可在 `~_{b,ε}` 下合并。结构优化因此不是剪枝技巧，而是**意图保持的粗化（coarsening）**：`G* = G_S / ~_{b,ε}`。复杂度可以大幅下降，但**不允许丢失任何会改变计划的意图区分**。这把“结构优化”从实现层提升为语义层的第一性定义。

**灵感 3（意图-结构信息瓶颈 / 率失真）**
直觉：结构 `G` 是意图空间到计划空间的压缩映射 `φ_G(I)=plan_G(I)`。`C(G)=|V_q|+λ|E_q|+μ·cost` 是结构的“描述长度”，`H(φ_G(I))` 是被结构保留下来的意图区分度。目标写成
`max_G H(plan_G(I)) - β·C(G)`。
这不是普通正则，而是率失真/信息瓶颈：保留区分不同计划所需的最小结构。超过 `β` 的结构是“意图冗余结构”，不足则“意图欠分辨”。`β` 把工程复杂度与意图分辨力放到同一条可绘制的曲线上，便于做消融与部署决策。

**灵感 4（主动意图消歧 → 只问会改变结构的查询）**
直觉：歧义不该一律澄清。若两个意图在 `G*` 下落到同一计划，则它们是**结构惰性意图（structurally inert intents）**，询问不改变任何动作，只会增加打扰与延迟。定义结构信息增益
`SIG(q)=E_z[H(plan_{G*_b}(I)) - H(plan_{G*_{b'}}(I)|z)] - ν·cost(q)`，
只执行 `SIG(q)>0` 的查询，并取 `argmax`。这把“意图理解”从“多问”变为“问对问题”，且与第 54 轮的云边往返预算直接耦合：查询成本就是一次 `τ_loop`。

**灵感 5（意图漂移与双证书的意图化）**
直觉：长程任务中意图会漂移（`b_t` 缓慢移动）。第 54 轮的 Explain 回传只能修动作，修不了“意图已变”。需要**意图漂移检测 + 商图重优化**：当 `||b_{t+1}-b_t||_TV > δ_I`，或计划的 α-分位鲁棒性跌破 `ρ_min`，触发 `QSO.reoptimize`。证书升级为 `J_b=(ρ_α,A_cert_α,γ_ce,δ_a,Res,evidence)`，形成 **意图推断 → 结构优化 → 动作执行 → 反例回传 → 重优化** 的双闭环，而不是第 54 轮的单动作闭环。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（意图空间、意图信念与意图覆盖）**
意图空间为 `𝕀`，隐意图 `I~b`，`b(I)=P(I|o)` 为给定观测 `o` 的后验信念。每个意图诱导任务动作序列分布 `P(A_T|I)`。结构 `G` 对意图的计划为
`plan_G(I) = argmin_{p ∈ Paths(G)} E_{A_T~P(·|I)}[cost_align(p, A_T)]`。
**意图覆盖** `Cov_b(G) = P_{I~b}(plan_G(I) 存在 ∧ J_b(I)=ok)`。α-分位鲁棒性 `ρ_α(d) = Quantile_α{ ρ(plan_G(I), d) : I~b }`。

**定义 122（意图保持 ε-互模拟）**
给定阈值 `ε>0`、`β>0`，记高概率意图集 `𝕀_hi = {I : b(I) ≥ β}`。两技能 `S_i ~_{b,ε} S_j` 当且仅当 `∀ I ∈ 𝕀_hi, ∀ d`：
```
|ρ_{S_i}(I,d) - ρ_{S_j}(I,d)| ≤ ε
cover(S_i, A_T(I)) = cover(S_j, A_T(I))
cert(S_i,I) = cert(S_j,I) ∈ {in, out}
∀ S_k : |compat(S_i,S_k) - compat(S_j,S_k)| ≤ ε      （同余性预检）
```
`~_{b,ε}` 在 (A29) 下是等价关系且为组合同余：`S_i ~ S_j ⇒ S_i⊗S_k ~_{ε'} S_j⊗S_k`。

**定义 123（意图分辨力 Res）**
在完整图 `G_S` 上定义**必需区分关系**
`D_{b,β} = {(I,I') : b(I),b(I') ≥ β, plan_{G_S}(I) ≠ plan_{G_S}(I')}`。
结构 `G` 的意图分辨力
`Res(G,b) = 1 - P_{I,I'~b}[ (I,I') ∈ D_{b,β} ∧ plan_G(I)=plan_G(I') ]`。
即：随机抽一对“本来就该用不同计划”的意图，被 `G` 错误合并的概率之补。`Res` 是结构优化的**硬约束**，不是软惩罚。

**定义 124（意图保持结构优化 QSO）**
`G*_{b,ε} = argmin_{G ⊑ G_S} C(G) = |V_q| + λ|E_q| + μ·max_{e∈E_q} cost_align(e)`
约束为：
```
G 是 ~_{b,ε} 的商图或商图的细化（只允许合并同类）
Res(G,b) ≥ 1 - ε_res
ρ_α(d) ≥ ρ_min  ∀ d
δ_a = max_alignment_error(γ_ce, A_core_α) ≤ Θ_a
```
其中 `⊑` 表示“商化 + 保序删边”；删边额外要求最优意图成本上升不超过 `δ`。

**定义 125（意图条件联合证书）**
`J_b = (ρ_α, A_cert_α, γ_ce, δ_a, Res, evidence)`：
- `ρ_α(d)=Quantile_α{ρ(I,d)}` 为意图分位鲁棒性；
- `A_cert_α = (A_core_α, A_buffer_α, δ_a)`，`A_core_α = ⋂_{I∈𝕀_hi} A_core(I)`；
- `Res` 为定义 123 的意图分辨力；
- `evidence` 至少含：α-分位意图的边端反例、商化见证（哪些技能被合并及理由）。
可部署条件：`ρ_α ≥ ρ_min`、`δ_a ≤ Θ_a`、`Res ≥ 1-ε_res`。

**定义 126（结构信息增益与主动意图消歧）**
查询 `q ∈ 𝕈` 带结果 `z`，后验 `b'(I)=P(I|o,q,z)`。结构信息增益
`SIG(q) = E_z[ H(plan_{G*_b}(I)) - H(plan_{G*_{b'}}(I)|z) ] - ν·cost(q)`。
选择 `q* = argmax_q SIG(q)`，仅在 `SIG(q*)>0` 时询问。若某对意图在 `G*` 下不可分且不改变计划划分，则 `H` 不变，`SIG=-ν·cost<0`，自然不问——**结构惰性意图不需要澄清**。

## 2. 关键算法 伪代码

### IP-121 IUG（Intent Uncertainty Grounding）

```python
def update_belief(b_prior, obs, intent_model):
    lik = {I: intent_model.P(obs | I) for I in b_prior}
    z = sum(b_prior[I]*lik[I] for I in b_prior)
    return {I: b_prior[I]*lik[I]/z for I in b_prior}

def alpha_quantile_rho(b, rho_by_intent, alpha=0.9):
    # 越靠近最坏意图越保守：取信念分布的 alpha 分位
    return {d: quantile([rho_by_intent[I][d] for I in b], alpha)
            for d in DIMENSIONS}

def plan_entropy(plans, b):
    p = defaultdict(float)
    for I, w in b.items():
        p[plans[I]] += w
    return -sum(v*log(v) for v in p.values() if v > 0)
```

### IP-122 IPB（Intent-Preserving Bisimulation）

```python
def intent_preserving_bisim(skills, b, eps, beta=0.05):
    H = [I for I in b if b[I] >= beta]
    uf = UnionFind(skills)
    for s_i, s_j in pairs(skills):
        ok = True
        for I in H:
            if abs(s_i.rho[I] - s_j.rho[I]) > eps: ok = False; break
            if s_i.cert(I) != s_j.cert(I):          ok = False; break
            if abs(s_i.cover(I) - s_j.cover(I)) > eps: ok = False; break
        if not ok: continue
        for s_k in skills:                       # 组合同余性预检
            if abs(compat(s_i,s_k) - compat(s_j,s_k)) > eps:
                ok = False; break
        if ok: uf.union(s_i, s_j)
    return uf.classes(), uf.witness()            # witness 供反例审计
```

### IP-123 QSO（Quotient Structural Optimization）

```python
def quotient_optimize(G_S, b, eps, eps_res, rho_min, theta_a, delta):
    classes, witness = intent_preserving_bisim(G_S.nodes, b, eps)
    Gq = contract(G_S, classes)                  # 意图保持商图
    # 按成本从大到小删边：只有 Res、rho、成本增量同时不越界才删
    for e in sorted(Gq.edges, key=lambda e: Gq[e]['cost'], reverse=True):
        G_try = Gq.without_edge(e)
        d_cost = best_cost(G_try, b) - best_cost(Gq, b)
        rho_try = alpha_quantile_rho(b, rho_of(G_try))
        if (Res(G_try, b) >= 1 - eps_res
                and min(rho_try.values()) >= rho_min
                and d_cost <= delta):
            Gq = G_try
    return Gq, witness
```

### IP-124 IAC（Intent-Aware Certificate）

```python
def intent_conditioned_certificate(G_star, b, alpha=0.9,
                                   eps_res=0.05, rho_min=None, theta_a=None):
    rho_alpha = alpha_quantile_rho(
        b, {I: rho_of_plan(G_star, I) for I in b}, alpha)
    H = [I for I in b if b[I] >= BETA]
    A_core_alpha = intersect([A_core(G_star, I) for I in H])
    delta_a = max_alignment_error(gamma_ce, A_core_alpha)
    res = Res(G_star, b)
    if min(rho_alpha.values()) < rho_min:
        return ('reject', 'robustness_quantile', rho_alpha)
    if delta_a > theta_a:
        return ('reject', 'action_alignment', delta_a)
    if res < 1 - eps_res:
        return ('reject', 'intent_resolution', res)
    return ('ok', IntentJointCert(
        rho_alpha, (A_core_alpha, buffer_zone(A_core_alpha, delta_a)),
        gamma_ce, delta_a, res, witness=WITNESS_TABLE))
```

### IP-125 AID（Active Intent Disambiguation）

```python
def active_disambiguate(b, queries, G_star, budget, H_min=0.2, nu=1.0):
    asked = []
    h0 = plan_entropy(plans_of(G_star, b), b)
    while h0 > H_min and budget > 0:
        best, best_sig = None, 0.0
        for q in queries:
            sig = 0.0
            for z, pz in outcome_distribution(q, b):
                b_z = update_belief(b, q.observed(z), intent_model)
                G_z, _ = quotient_optimize(G_star, b_z, eps, eps_res, rho_min, theta_a, delta)
                h_z = plan_entropy(plans_of(G_z, b_z), b_z)
                sig += pz * (h0 - h_z)
            sig -= nu * q.cost
            if sig > best_sig:
                best, best_sig = q, sig
        if best is None:               # 结构惰性：没有查询能改变计划划分
            break
        z = best.execute()
        b = update_belief(b, best.observed(z), intent_model)
        asked.append((best, z)); budget -= best.cost
        h0 = plan_entropy(plans_of(G_star, b), b)
    return b, asked
```

### IP-126 ISL（Intent-Structure Loop）

```python
def intent_structure_loop(b_t, G_star, obs, delta_I, cooldown):
    b_next = update_belief(b_t, obs, intent_model)
    drift = total_variation(b_next, b_t)
    rho_alpha = alpha_quantile_rho(b_next, rho_of(G_star))
    need = (drift > delta_I) or (min(rho_alpha.values()) < rho_min)
    if need and cooldown.expired():         # 滞回，避免意图抖动引发重优化震荡
        G_star, witness = quotient_optimize(G_S, b_next, eps, eps_res,
                                             rho_min, theta_a, delta)
        cooldown.reset()
        return ('reoptimize', G_star, b_next, drift, witness)
    return ('hold', G_star, b_next, drift, None)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| IUG | O(|𝕀|·|o| + |𝕀|·|𝔇_ρ|) | O(|𝕀|) | 观测模型校准、分位估计误差 |
| IPB | O(|S|²·|𝕀_hi|·|A|) | O(|S|) | ε-互模拟可判定、同余性 |
| QSO | O((|V|+|E|)log|V| + |S|²·|𝕀_hi|) | O(|V|+|E|) | Res 单调、删边保序 |
| IAC | O(|𝕀|·|𝔇_ρ| + |A|) | O(|A|+|𝕀|) | α-分位保守、见证可审计 |
| AID | O(|𝕀|·|𝕈|·|A_T|) 每轮 | O(|𝕀|·|𝕈|) | SIG>0 才问、熵单调不增 |

**正确性定理（Intent-Preserving Structural Optimization Soundness）**
假设第 54 轮 (A22)–(A28) 成立，并新增：
**(A29)** `~_{b,ε}` 为组合同余，单步组合失真 `≤ L_comp·ε`；
**(A30)** 信念 `b` 已校准（`ECE ≤ η`），且 `𝕀_hi` 覆盖概率质量 `≥ 1-β`。
则对任意 `I ∈ 𝕀_hi`：
```
P(success | I, G*_{b,ε}) ≥ 1 - Σ_d (1-ρ_α(d)) - P(δ_a > Θ_a)
                          - (1 - Res(G*,b)) - β_E - L_comp·ε·|path| - η
```
各项含义：`ρ_α` 覆盖意图尾部；`Res` 覆盖“意图区分被错并”；`L_comp·ε·|path|` 是粗化误差沿组合路径的累积；`η` 是信念校准误差。**关键**：整体 soundness 不是对单一 `A_T`，而是对信念高概率集；结构优化的合法性由 `Res` 硬约束与同余性共同保证。

**结构目标的等价推导（率失真视角）**
由 `plan_G(I)` 对给定 `G,I` 是确定性的，有 `I(I;plan_G(I)) = H(plan_G(I)) - H(plan_G(I)|I) = H(plan_G(I))`。于是
`max_G I(I;plan_G(I)) - β·C(G)  ≡  max_G H(plan_G(I)) - β·C(G)`。
即：结构是意图的“有损压缩”，`H(plan)` 是保留下来的区分度，`C(G)` 是描述长度；`Res` 约束防止把“该区分的意图对”压掉。该式可直接用于绘制 `β`-压缩率-成功率的三维消融曲线。

## 4. 实验设计 E162–E167

| 实验 | 指标 | 目标 |
|---|---|---|

| E163 意图保持商化 | 压缩率 vs soundness 保持 | 压缩 ≥ 40%，成功率下降 ≤ 2% |

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 意图信念失准（尤其长尾） | 高 | 温度/集成校准 + 在线 ECE 监控 + 分位覆盖率回退 |
| ε-互模拟错误合并 | 高 | 反例驱动验证 + 保守 ε + 合并黑名单 + witness 审计 |
| 商化过度导致意图欠分辨 | 高 | `Res` 硬约束 + 意图覆盖红线 + 合并前后计划对比 |
| 主动查询惹恼用户 | 中 | `SIG` 阈值 + 查询预算 + 优先非侵入视觉线索 |
| 意图漂移引发重优化震荡 | 中 | 滞回 + 最小重优化间隔 + 变化点检测 |
| 结构优化计算爆炸 | 中 | 增量商化 + 局部重算 + 等价类缓存 |

## 6. 本轮最大风险

**一句话**：把“任务给定”升级为“意图信念覆盖”、把“最大兼容图”升级为“意图保持商图”，使方案同时获得意图鲁棒性与结构压缩，但其 soundness **双重依赖意图信念的校准与 ε-互模拟的正确性**；一旦 `b(I)` 在长尾意图上失准，或 `~_{b,ε}` 把“本应区分”的意图对错误合并，QSO 会以极低的成本产出**看起来证书完备、实则系统性抹掉用户真实意图**的计划——这是比第 54 轮动作错位更隐蔽的失败，故必须以 **α-分位覆盖 + Res 硬约束 + 反例驱动的合并审计** 三重护栏，宁可结构保守，也不拿“合并后的优雅”冒充“意图被理解”。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（IUG×IPB×QSO×IAC×AID×ISL）

> 承接第 54 轮产物 v31。本轮把“任务动作序列给定”翻转为“**意图信念分布**”，把“技能组合图给定”翻转为“**意图保持的结构优化**”，新增六大算子：

> - **QSO（Quotient Structural Optimization）**：意图保持商图 `G*_{b,ε}` 与保序删边；
> - **IAC（Intent-Aware Certificate）**：意图条件联合证书 `J_b`，含 `Res` 硬约束；
> - **AID（Active Intent Disambiguation）**：结构信息增益 `SIG(q)` 驱动的“只问会改结构的查询”；
> - **ISL（Intent-Structure Loop）**：意图漂移检测 ↔ 商图重优化的第二闭环。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-115/116/118/120 以纳入意图维度。

## 0. 核心 IP 设计

## 2. 关键算法 伪代码

### IP-121 IUG

```python
def update_belief(b_prior, obs, intent_model):
    lik = {I: intent_model.P(obs | I) for I in b_prior}
    z = sum(b_prior[I]*lik[I] for I in b_prior)
    return {I: b_prior[I]*lik[I]/z for I in b_prior}

def alpha_quantile_rho(b, rho_by_intent, alpha=0.9):
    return {d: quantile([rho_by_intent[I][d] for I in b], alpha)
            for d in DIMENSIONS}

def intent_coverage(G, b, cert_fn):
    return sum(w for I, w in b.items()
               if plan_exists(G, I) and cert_fn(G, I) == 'ok')

def plan_entropy(plans, b):
    p = defaultdict(float)
    for I, w in b.items(): p[plans[I]] += w
    return -sum(v*log(v) for v in p.values() if v > 0)
```

### IP-122 IPB

```python
def intent_preserving_bisim(skills, b, eps, beta=0.05):
    H = [I for I in b if b[I] >= beta]
    uf, witness = UnionFind(skills), []
    for s_i, s_j in pairs(skills):
        ok, why = True, []
        for I in H:
            if abs(s_i.rho[I] - s_j.rho[I]) > eps: ok=False; why.append(('rho',I)); break
            if s_i.cert(I) != s_j.cert(I):          ok=False; why.append(('cert',I)); break
            if abs(s_i.cover(I) - s_j.cover(I)) > eps: ok=False; why.append(('cover',I)); break
        if ok:
            for s_k in skills:
                if abs(compat(s_i,s_k) - compat(s_j,s_k)) > eps:
                    ok=False; why.append(('congruence',s_k)); break
        if ok:
            uf.union(s_i, s_j); witness.append(('merge', s_i, s_j))
        else:
            witness.append(('keep', s_i, s_j, why))
    return uf.classes(), witness
```

### IP-123 QSO

```python
def quotient_optimize(G_S, b, eps, eps_res, rho_min, theta_a, delta):
    classes, witness = intent_preserving_bisim(G_S.nodes, b, eps)
    Gq = contract(G_S, classes)
    for e in sorted(Gq.edges, key=lambda e: Gq[e]['cost'], reverse=True):
        G_try = Gq.without_edge(e)
        d_cost = best_cost(G_try, b) - best_cost(Gq, b)
        rho_try = alpha_quantile_rho(b, rho_of(G_try))
        if (Res(G_try, b) >= 1-eps_res
                and min(rho_try.values()) >= rho_min
                and d_cost <= delta):
            Gq = G_try
    return Gq, witness

def res(G, b, D_required):
    total = fail = 0.0
    for (I, I2), w in joint_mass(b).items():
        total += w
        if (I, I2) in D_required and plans_equal(G, I, I2):
            fail += w
    return 1 - fail/total
```

### IP-124 IAC

```python
def intent_conditioned_certificate(G_star, b, alpha=0.9,
                                   eps_res=0.05, rho_min=None, theta_a=None):
    rho_alpha = alpha_quantile_rho(
        b, {I: rho_of_plan(G_star, I) for I in b}, alpha)
    H = [I for I in b if b[I] >= BETA]
    A_core_alpha = intersect([A_core(G_star, I) for I in H])
    delta_a = max_alignment_error(gamma_ce, A_core_alpha)
    r = res(G_star, b, REQUIRED_DISTINCTIONS)
    if min(rho_alpha.values()) < rho_min: return ('reject','robustness_quantile',rho_alpha)
    if delta_a > theta_a:                 return ('reject','action_alignment',delta_a)
    if r < 1-eps_res:                     return ('reject','intent_resolution',r)
    return ('ok', IntentJointCert(rho_alpha, (A_core_alpha,
             buffer_zone(A_core_alpha, delta_a)), gamma_ce, delta_a, r,
             witness=WITNESS_TABLE))
```

### IP-125 AID

```python
def active_disambiguate(b, queries, G_star, budget, H_min=0.2, nu=1.0):
    asked, h0 = [], plan_entropy(plans_of(G_star, b), b)
    while h0 > H_min and budget > 0:
        best, best_sig = None, 0.0
        for q in queries:
            sig = 0.0
            for z, pz in outcome_distribution(q, b):
                b_z = update_belief(b, q.observed(z), intent_model)
                G_z, _ = quotient_optimize(G_star, b_z, eps, eps_res, rho_min, theta_a, delta)
                sig += pz * (h0 - plan_entropy(plans_of(G_z, b_z), b_z))
            sig -= nu * q.cost
            if sig > best_sig: best, best_sig = q, sig
        if best is None: break        # 结构惰性意图：问了也不改计划
        z = best.execute()
        b = update_belief(b, best.observed(z), intent_model)
        asked.append((best, z)); budget -= best.cost
        h0 = plan_entropy(plans_of(G_star, b), b)
    return b, asked
```

### IP-126 ISL

```python
def intent_structure_loop(b_t, G_star, obs, delta_I, cooldown):
    b_next = update_belief(b_t, obs, intent_model)
    drift = total_variation(b_next, b_t)
    rho_alpha = alpha_quantile_rho(b_next, rho_of(G_star))
    need = (drift > delta_I) or (min(rho_alpha.values()) < rho_min)
    if need and cooldown.expired():
        G_star, witness = quotient_optimize(G_S, b_next, eps, eps_res,
                                             rho_min, theta_a, delta)
        cooldown.reset()
        return ('reoptimize', G_star, b_next, drift, witness)
    return ('hold', G_star, b_next, drift, None)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| IUG | O(|𝕀|·|o| + |𝕀|·|𝔇_ρ|) | O(|𝕀|) | 信念校准 ECE≤η，分位覆盖 |
| IPB | O(|S|²·|𝕀_hi|·|A|) | O(|S|) | ε-互模拟可判定，组合同余 |
| QSO | O((|V|+|E|)log|V|+|S|²·|𝕀_hi|) | O(|V|+|E|) | Res 硬约束，删边保序 |
| IAC | O(|𝕀|·|𝔇_ρ|+|A|) | O(|A|+|𝕀|) | α-分位保守，见证可审计 |
| AID | O(|𝕀|·|𝕈|·|A_T|)/轮 | O(|𝕀|·|𝕈|) | SIG>0 才问，熵不增 |
| ISL | O(|𝕀|·|o| + QSO) | O(|V|+|E|) | 滞回收敛，漂移有界 |

**正确性定理（Intent-Preserving Structural Optimization Soundness, IPSO-Soundness）**
假设第 54 轮 (A22)–(A28) 成立，新增：
**(A29)** `~_{b,ε}` 为组合同余，单步组合失真 `≤ L_comp·ε`；
**(A30)** 信念 `b` 已校准（`ECE ≤ η`），`𝕀_hi` 覆盖概率质量 `≥ 1-β`。
则对任意 `I ∈ 𝕀_hi`：
```
P_success(I | G*_{b,ε}) ≥ 1 - Σ_d(1-ρ_α(d)) - P(δ_a > Θ_a)
                         - (1 - Res(G*,b)) - β_E - L_comp·ε·|path| - η
```
工程解读：
- `ρ_α` 把鲁棒性从“单意图”扩到“信念分位”；
- `Res` 是**结构优化的合法性闸门**，防止用压缩率换掉意图区分；
- `L_comp·ε·|path|` 给出“允许粗化的总预算”，路径越长 ε 必须越小；
- `η` 是信念失准的直接代价，故 E162 的校准是前置条件而非可选项。

## 4. 结构目标的率失真刻画

结构 `G` 视为意图空间到计划空间的压缩映射 `φ_G: 𝕀→Plans`。因 `plan_G(I)` 对给定 `G,I` 确定性：
```
I(I; plan_G(I)) = H(plan_G(I)) - H(plan_G(I)|I) = H(plan_G(I))
```
于是优化目标等价于
```
max_G  H(plan_G(I)) - β·C(G)        s.t. Res(G,b) ≥ 1-ε_res, ρ_α ≥ ρ_min
```
`H(plan_G(I))` = 结构保留的意图区分度；`C(G)` = 结构描述长度；`β` = 复杂度价格。`Res` 约束是“率失真函数上的可行性边界”，不是软惩罚。**由此可绘制 `β`-压缩率-成功率三维消融图**：E163 扫描 `β`，E164 报告同一 `β` 下的误并率。

| 风险 | 等级 | 缓解 |

## 9. 本轮最大风险

**一句话**：把“任务给定”升级为“意图信念覆盖”、把“最大兼容图”升级为“意图保持商图”，使方案同时获得意图鲁棒性与结构压缩，但其 soundness **双重依赖意图信念的校准与 ε-互模拟的正确性**；一旦 `b(I)` 在长尾意图上失准，或 `~_{b,ε}` 把“本应区分”的意图对错误合并，QSO 会以极低成本产出**证书完备却系统性抹掉用户真实意图**的计划——这是比第 54 轮动作错位更隐蔽的失败，故必须以 **α-分位覆盖 + Res 硬约束 + 反例驱动的合并审计** 三重护栏，宁可结构保守，也不拿“合并后的优雅”冒充“意图被理解”。
