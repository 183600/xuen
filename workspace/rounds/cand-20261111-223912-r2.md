# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「场景理解」×「鲁棒性」）

> 第 54 轮把鲁棒性谱 ρ 绑定到动作剖面 α_S 与云边联合证书 J，但 ρ 与 α_S 都是在某个隐含场景总体上的**边缘化量**。本轮把这一隐含前提显式化：**鲁棒性只在它被测量的场景货币中有效**。核心矛盾：H25：场景理解不是鲁棒性的外挂模块，而是鲁棒性证书的**定义域生成器**——场景语义漂移会让 ρ 从“略低”突变为“无定义”；H26：鲁棒性证书只约束执行、不约束理解，感知管线可以在“平均精度很高”的同时把部署场景映射到证书域外，形成**精度-有效性错觉**。

## 0. 直觉与动机

**灵感 1（鲁棒性有“场景汇率”）**
直觉：说“这个策略鲁棒性 0.92”就像说“这笔钱值 100”，却没说币种。ρ(d) 是在场景总体 Σ 上测出来的；一旦部署场景 G* 离开 Σ，ρ(d) 不是变小，而是**失去意义**。所以必须先把“测量场景”写成证书的显式字段。定义**场景条件鲁棒性场** `ρ_S(d|h)`；第 54 轮的 ρ 只是它在场景分布下的期望，而期望会系统性地抹平“少数场景灾难”。

**灵感 2（场景理解 = 生成证书域，而非输出标签）**
直觉：场景理解真正要交付的不是“杯子在桌上”，而是一个**场景假设集 H(o)**，以及“这个集合是否整体落在鲁棒成功域内”的判定。把感知的“错误率视角”换成**集合覆盖视角**：只要真场景在 H(o) 内、且 H(o) 不碰场景脆弱集 F，部署就是有保证的。这一步补上了“感知精度很高”与“任务失败”之间缺失的因果环节。

**灵感 3（决策保持等价 → 只理解到证书能分辨的粒度）**
直觉：不必理解整个场景，只需理解到“证书无法区分”的粒度。定义场景等价 `h ~_cert h'` 当且仅当两者给出相同的动作覆盖与鲁棒性判定。场景理解的任务于是变成在商空间 `ℋ/~_cert` 上估计等价类，而不是重建完整世界。这把“任务充分场景统计”变成可定义、可压缩、可评测的对象。

**灵感 4（两种鲁棒性：理解的鲁棒 + 依赖理解的鲁棒）**
直觉：必须区分 **感知鲁棒性**（输入扰动下场景理解仍落在同一证书等价类）与 **控制鲁棒性**（给定正确场景，动作仍然成功）。二者近似相乘/耦合：任一接近零，总成功率就接近零。第 53/54 轮的 ρ 只覆盖后者。定义**感知鲁棒性谱** `ρ^perc(e|h)`，与 `ρ` 构成双谱 `(ρ^perc, ρ)`——这解释了“仿真里很鲁棒、真机上场景一换就崩”的常见现象。

**灵感 5（歧义 → 鲁棒预算；主动消歧而非被动保守）**
直觉：场景歧义 H(o) 越大，最坏情况鲁棒性越低，这是一笔**鲁棒性税**。税后仍达标就部署；不达标时，不应一律保守拒绝，而应执行安全的**探针动作**（多看一眼、轻触、换视角）来收缩 H(o)。探针动作本身属于第 54 轮的动作空间 A，因此消歧天然是动作规划的一部分，而不是外挂流程。

**灵感 6（场景-鲁棒联合证书与金字塔）**
直觉：在第 54 轮的动作-鲁棒双证书 J 上再加场景假设集、场景有效性裕度、感知鲁棒谱与消歧预算，形成**场景-鲁棒联合证书 J_SR**。跨层传递时，ρ 与 H(o) 必须成对传递，否则“在 A 场景测得的鲁棒性”会被错误地当成“对 B 场景的承诺”。

## 1. 形式化定义（增量：定义 121–127）

**定义 121（场景假设与共形场景集）**
场景假设 `h = (G, Σ_G, ξ)`：`G` 为场景图（物体、位姿、关系），`Σ_G` 为几何不确定性，`ξ` 为语义/可供性标注。观测 `o` 诱导**共形场景集** `H_α(o)`，满足
```
P(h_true ∈ H_α(o)) ≥ 1 - α
```
只依赖校准集与测试样本的可交换性，不依赖场景先验形式。`H_α(o)` 是后续所有证书的**域生成器**。

**定义 122（场景条件鲁棒性场）**
对鲁棒维度 `d ∈ 𝔇`，`ρ_S(d|h) ∈ [0,1]`。部署时的**最坏情况鲁棒性**
```
ρ_S^rob(d|o) = inf_{h ∈ H_α(o)} ρ_S(d|h)
```
若 `H_α(o)` 为空或无界，则 `ρ_S^rob` 未定义，直接拒绝。第 54 轮的 `ρ(d) = E_{h~D}[ρ_S(d|h)]` 是本场的边缘化，会隐藏场景尾部。

**定义 123（场景脆弱集与场景鲁棒半径）**
```
F_d(ρ_min) = { h : ρ_S(d|h) < ρ_min(d) },   F = ⋃_d F_d
r_scene(o) = dist( H_α(o), F )
```
`dist` 为场景度量下两集合间距离。部署合法仅当 `r_scene(o) ≥ r_0 > 0`，即 `H_α(o)` 整体位于成功域内部且留正裕度。注意 `r_scene` 是**集合到集合**的距离，不是单点估计到阈值的距离——这使它能在场景集很大时自动收紧证书。

**定义 124（证书等价与任务充分统计）**
```
h ~_cert h'  ⇔  cover(S,A_T|h)=cover(S,A_T|h') ∧ ρ_S(d|h)=ρ_S(d|h') ∀d
```
商空间 `ℋ_cert = ℋ / ~_cert`。统计量 `φ_cert : O → Z` 称为**任务充分场景统计**，若
```
φ_cert(h)=φ_cert(h')  ⇒  h ~_cert h'
```
则仅凭 `φ_cert(o)` 即可判定证书。其所需信息量 `I_cert` 一般远小于完整场景重建——这是“为证书而理解”的压缩依据。

**定义 125（感知鲁棒性谱）**
扰动族 `ℰ = {遮挡, 视角, 光照, 杂乱, 语义歧义}`。感知鲁棒性
```
ρ^perc(e|h) = P_{o~P_e(·|h)}[ ∃ h' ∈ H_α(o) : h' ~_cert h ]
```
即扰动 `e` 下场景管线仍输出与 `h` 证书等价的假设的概率。双谱 `(ρ^perc, ρ)` 共同决定端到端鲁棒性。

**定义 126（场景-鲁棒联合证书）**
```
J_SR = (ρ^rob, H_α(o), r_scene, φ_cert, ρ^perc, A_disamb, δ_a, evidence)
```
部署谓词：
```
h_true ∈ H_α(o)
∧ r_scene(o) ≥ r_0
∧ min_{e∈ℰ} ρ^perc(e|h_true) ≥ ρ^perc_min
∧ δ_a < Θ_a
∧ ρ^rob(d) ≥ ρ_min(d)  ∀ d∈𝔇
```
任一不满足则输出 `uncommitted`，并触发消歧或保守回退；**域外不等于失败，而是未承诺**。

**定义 127（主动消歧策略）**
安全探针动作集 `A_probe ⊆ A`（第 54 轮动作空间）。探针选择最大化单位代价的鲁棒裕度增益：
```
a_p* = argmax_{a ∈ A_probe}  [ E_{o'~P(·|o,a)} r_scene(o') - r_scene(o) ]
                            / ( λ_c·cost(a) + λ_t·τ(a) )
s.t.  r_scene(o') ≥ 0   （探针本身不得把系统推入脆弱集）
```
消歧持续到 `r_scene ≥ r_0` 或消歧预算耗尽；预算耗尽时返回 `uncommitted` 而非伪造成功。

## 2. 关键算法 伪代码

### IP-121 SCB（Scene-Conformal Belief）

```python
def conformal_scene_set(o, calib, alpha):
    scores = [nonconformity(h, o) for h in calib]
    q = quantile(scores, 1 - alpha, method='higher')
    H = {h for h in scene_hypotheses(o) if nonconformity(h, o) <= q}
    return H if H else None        # None => 未承诺，不部署
```

### IP-122 SRC（Scene-conditioned Robustness Certificate）

```python
def robust_scene_certificate(skill, H, dims, rho_min, grid, L_rho):
    if H is None or not bounded(H):
        return ('reject', 'undefined_scene_domain')
    rho_rob = {}
    for d in dims:
        # ε-net 采样 + Lipschitz 下界，避免只取有限样本的乐观偏差
        sample_min = min(skill.rho(d, h) for h in sample_extremes(H, grid))
        rho_rob[d] = max(0.0, sample_min - L_rho * mesh(H, grid))
    F = {h for h in grid if any(skill.rho(d, h) < rho_min[d] for d in dims)}
    r = distance(H, F)
    if any(rho_rob[d] < rho_min[d] for d in dims) or r < r0:
        return ('disambiguate', rho_rob, r)
    return ('ok', rho_rob, r)
```

### IP-123 PRS（Perceptual Robustness Spectrum）

```python
def perceptual_robustness(pipe, h, perturbations, alpha, N):
    out = {}
    for e in perturbations:
        hits = 0
        for _ in range(N):
            o = render(h, e)
            H = pipe.conformal_set(o, alpha)
            hits += any(same_cert_class(h2, h) for h2 in H)
        out[e] = hits / N
    return out
```

### IP-124 TSS（Task-Sufficient Scene Statistics）

```python
def select_sufficient_stats(cert_predicate, scenes, budget, eps_cert):
    feats, phi = all_scene_features(), []
    while len(phi) < budget:
        f = argmax(feats, key=lambda f: MI(cert_predicate; phi + [f]))
        phi.append(f); feats.remove(f)
        if cert_error(phi, scenes) <= eps_cert:   # 证书判定误差已饱和
            break
    return phi
```

### IP-125 ADR（Active Disambiguation for Robustness）

```python
def active_disambiguate(o, skill, r_scene, r0, A_probe, budget):
    trace = []
    while r_scene < r0 and budget > 0:
        candidates = [a for a in A_probe if safe_probe(a, o, skill)]
        if not candidates:
            break
        a = max(candidates,
                key=lambda a: expected_margin_gain(o, a, skill) / cost(a))
        o = execute_probe(a, o); budget -= cost(a)
        H = conformal_scene_set(o, calib, alpha)
        r_scene = scene_radius(H, skill.rho, rho_min)
        trace.append((a, r_scene))
    return ('ok' if r_scene >= r0 else 'uncommitted', r_scene, trace)
```

### IP-126 SJRC（Scene-Robustness Joint Certificate）

```python
def scene_robust_certificate(S, o, dims, r0, rho_perc_min, delta_a):
    H = conformal_scene_set(o, calib, alpha)
    rho_rob, r = robust_scene_certificate(S, H, dims, rho_min, grid, L_rho)
    if r < r0:
        return ('uncommitted', 'scene_margin', r)
    rho_perc = perceptual_robustness(pipe, h_ref=argmax_belief(H),
                                     perturbations=EPS, alpha=alpha, N=N)
    if min(rho_perc.values()) < rho_perc_min:
        return ('reject', 'perceptual_instability', rho_perc)
    return ('ok', J_SR(rho_rob, H, r, phi_cert, rho_perc, A_disamb, delta_a))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| SCB | O(|calib|·|ℋ|) | O(|calib|) | 可交换性、共形分位数 |
| SRC | O(|𝔇|·|grid|·|H|) | O(|grid|+|H|) | ε-net 覆盖 + L_ρ 下界 |
| PRS | O(|ℰ|·N·|ℋ|) | O(|ℰ|) | 扰动族覆盖、N 次采样 |
| TSS | O(|F|²·|scenes|) | O(|F|) | 互信息单调、证书误差饱和 |
| ADR | O(B·|A_probe|·|ℋ|) | O(|A_probe|) | 探针安全、增益估计无偏 |
| SJRC | O(SRC + PRS) | O(|H|+|ℰ|) | 联合谓词 sound、域外即未承诺 |

**引理 1（场景理解单调性）**
若 `H' ⊆ H`，则 `ρ^rob(d|H') ≥ ρ^rob(d|H)` 且 `r_scene(H') ≥ r_scene(H)`。即更精确、更正确的场景理解只会提高**证书下界**；但它可能降低**盲目乐观的名义估计**（因为暴露了此前被忽略的脆弱场景）。这解释了为什么“感知更强反而成绩更差”常常其实是估计变诚实了。

**正确性定理（Scene-Robust Deployment Soundness）**
承接第 54 轮 (A26)–(A28)；新增：
**(A29)** 共形覆盖 `P(h_true ∈ H_α(o)) ≥ 1-α`；
**(A30)** `ρ_S(d|·)` 关于场景度量满足 `L_ρ`-Lipschitz，故 `inf_{h∈H} ρ_S ≥ min_{ε-net} ρ_S − L_ρ·mesh`；
**(A31)** 感知管线在扰动 `e` 下保持证书等价的概率 `≥ ρ^perc(e)`。
则部署成功率
```
P_success ≥ (1-α)·[ 1 - Σ_d (1 - ρ^rob(d)) ]
            - (1 - ρ^perc_min)
            - P(消歧预算耗尽)
            - β_E
```
读法：先保证真场景在集内（`1-α`），再保证集内最坏鲁棒达标（括号项），再扣掉“理解把等价类弄错”的感知风险与消歧失败风险。三项缺一，证书 soundness 都会漏。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 共形覆盖在分布漂移下失效 | 高 | 在线可交换性检验 + 滑动校准 + 漂移检测触发失效 |
| 场景脆弱集估计欠采样 | 高 | 对抗场景生成 + 主动学习补点 + Lipschitz 保守下界 |
| 最坏情况过保守导致“鲁棒性瘫痪” | 高 | 分级承诺 + 主动消歧优先于直接拒绝 |
| 探针动作本身不安全 | 中 | 安全域约束 + 探针白名单 + 力矩/速度上限 |
| 感知鲁棒谱扰动族不完备 | 中 | 红队扰动搜索 + 真实失败画廊回灌 |
| 任务充分统计选错导致漏判 | 中 | 证书误差审计 + 统计必要性反例测试 |

## 6. 本轮最大风险

**一句话**：把场景理解变成鲁棒性证书的域生成器，使证书从“无条件标量”升级为“带场景假设集与正裕度的条件承诺”，但其 soundness 首先押在**共形场景集在真实分布漂移下仍能覆盖真场景**这一前提上；一旦部署分布破坏可交换性，`H_α(o)` 会以“集很小、裕度为正”的假象给出虚假安全，故必须以 **在线覆盖审计 + 漂移触发降级 + 探针优先** 作为硬护栏，宁可输出 `uncommitted`，也绝不把“在错误场景集上算出的正裕度”当成部署许可。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++SR（SCB×SRC×PRS×TSS×ADR×SJRC）

> 承接第 54 轮产物 v31。本轮把第 54 轮中被隐含边缘化的“场景”显式抬升为鲁棒性证书的**定义域生成器**，新增六个算子：
> - **SCB（Scene-Conformal Belief）**：用共形预测生成带覆盖保证的场景假设集 `H_α(o)`；
> - **SRC（Scene-conditioned Robustness Certificate）**：在 `H_α(o)` 上取最坏情况鲁棒性 `ρ^rob`，并计算场景脆弱集距离 `r_scene`；
> - **PRS（Perceptual Robustness Spectrum）**：度量“理解的鲁棒”，与控制鲁棒谱 `ρ` 构成双谱；
> - **TSS（Task-Sufficient Scene Statistics）**：以证书等价类为目标，只保留任务充分场景统计 `φ_cert`；
> - **ADR（Active Disambiguation for Robustness）**：用安全探针动作把场景歧义转成可消解的鲁棒预算；
> - **SJRC（Scene-Robustness Joint Certificate）**：场景-鲁棒联合证书 `J_SR`，域外输出 `uncommitted`。
>
> IP 编号：IP-121~IP-126（共 6 个新增）；升级 IP-115/118/120，把 `α_S` 与 `J` 从“场景边缘化”改为“场景条件化”。

## 0. 核心 IP 设计

| IP-122 | SRC Scene-conditioned Robustness Certificate | 新增 | `ρ^rob=inf_{H_α}ρ`，场景脆弱集距离 `r_scene` |

## 1. 符号体系增量（新增定义 121–127）

| 符号 | 含义 |
|---|---|
| `h=(G,Σ_G,ξ)` | 场景假设：场景图 × 几何不确定度 × 语义/可供性 |
| `H_α(o)` | 观测 `o` 诱导的共形场景集，`P(h_true∈H_α)≥1-α` |
| `ρ_S(d|h)` | 场景条件鲁棒性场 |
| `ρ^rob(d|o)` | `inf_{h∈H_α(o)} ρ_S(d|h)`，可部署最坏鲁棒性 |
| `F` | 场景脆弱集 `{h: ∃d, ρ_S(d|h)<ρ_min(d)}` |
| `r_scene(o)` | `dist(H_α(o), F)`，场景鲁棒半径（集合到集合） |
| `~_cert` | 证书等价：动作覆盖与鲁棒判定完全相同 |
| `φ_cert` | 任务充分场景统计 |
| `ρ^perc(e|h)` | 感知鲁棒性谱（扰动 `e` 下证书等价保持率） |
| `A_probe` | 安全探针动作集 `⊆ A` |
| `J_SR` | 场景-鲁棒联合证书 |

## 2. 关键算法 伪代码

### IP-121 SCB

```python
def conformal_scene_set(o, calib, alpha):
    scores = [nonconformity(h, o) for h in calib]
    q = quantile(scores, 1 - alpha, method='higher')
    H = {h for h in scene_hypotheses(o) if nonconformity(h, o) <= q}
    return H if H else None            # None => uncommitted
```

### IP-122 SRC

```python
def robust_scene_certificate(skill, H, dims, rho_min, grid, L_rho, r0):
    if H is None or not bounded(H):
        return ('reject', 'undefined_scene_domain')
    rho_rob = {}
    for d in dims:
        sample_min = min(skill.rho(d, h) for h in sample_extremes(H, grid))
        rho_rob[d] = max(0.0, sample_min - L_rho * mesh(H, grid))
    F = {h for h in grid if any(skill.rho(d, h) < rho_min[d] for d in dims)}
    r = distance(H, F)
    if any(rho_rob[d] < rho_min[d] for d in dims) or r < r0:
        return ('disambiguate', rho_rob, r)
    return ('ok', rho_rob, r)
```

### IP-123 PRS

```python
def perceptual_robustness(pipe, h, perturbations, alpha, N):
    out = {}
    for e in perturbations:
        hits = 0
        for _ in range(N):
            o = render(h, e)
            H = pipe.conformal_set(o, alpha)
            hits += any(same_cert_class(h2, h) for h2 in H)
        out[e] = hits / N
    return out
```

### IP-124 TSS

```python
def select_sufficient_stats(cert_predicate, scenes, budget, eps_cert):
    feats, phi = all_scene_features(), []
    while len(phi) < budget:
        f = argmax(feats, key=lambda f: MI(cert_predicate; phi + [f]))
        phi.append(f); feats.remove(f)
        if cert_error(phi, scenes) <= eps_cert:
            break
    return phi
```

### IP-125 ADR

```python
def active_disambiguate(o, skill, r_scene, r0, A_probe, budget):
    trace = []
    while r_scene < r0 and budget > 0:
        cand = [a for a in A_probe if safe_probe(a, o, skill)]
        if not cand:
            break
        a = max(cand, key=lambda a: expected_margin_gain(o, a, skill) / cost(a))
        o = execute_probe(a, o); budget -= cost(a)
        H = conformal_scene_set(o, calib, alpha)
        r_scene = scene_radius(H, skill.rho, rho_min)
        trace.append((a, r_scene))
    return ('ok' if r_scene >= r0 else 'uncommitted', r_scene, trace)
```

### IP-126 SJRC

```python
def scene_robust_certificate(S, o, dims, r0, rho_perc_min, delta_a):
    H = conformal_scene_set(o, calib, alpha)
    rho_rob, r = robust_scene_certificate(S, H, dims, rho_min, grid, L_rho, r0)
    if r < r0:
        return ('uncommitted', 'scene_margin', r)
    rho_perc = perceptual_robustness(pipe, argmax_belief(H), EPS, alpha, N)
    if min(rho_perc.values()) < rho_perc_min:
        return ('reject', 'perceptual_instability', rho_perc)
    return ('ok', J_SR(rho_rob, H, r, phi_cert, rho_perc, A_disamb, delta_a))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SCB | O(|calib|·|ℋ|) | O(|calib|) | 共形分位数、可交换性 |
| SRC | O(|𝔇|·|grid|·|H|) | O(|grid|+|H|) | ε-net 覆盖 + `L_ρ` 保守下界 |
| PRS | O(|ℰ|·N·|ℋ|) | O(|ℰ|) | 扰动族覆盖、证书等价判定 |
| TSS | O(|F|²·|scenes|) | O(|F|) | 证书误差饱和、互信息单调 |
| ADR | O(B·|A_probe|·|ℋ|) | O(|A_probe|) | 探针安全约束、增益无偏估计 |
| SJRC | O(SRC+PRS) | O(|H|+|ℰ|) | 联合谓词 sound、域外即未承诺 |

**引理 1（场景理解单调性）**
`H'⊆H ⇒ ρ^rob(d|H') ≥ ρ^rob(d|H)` 且 `r_scene(H') ≥ r_scene(H)`。更好的场景理解只会抬高证书**下界**，但可能压低此前虚高的名义估计。

**引理 2（TSS 充分性）**
若 `φ_cert` 满足证书等价保持，则对任意 `h,h'`，`φ_cert(h)=φ_cert(h') ⇒ J_SR(h)=J_SR(h')`。因此场景理解在 `φ_cert` 上达到饱和后继续重建场景，不会改变部署判定，只会增加成本。

**正确性定理（Scene-Robust Deployment Soundness）**
假设第 54 轮 (A26)–(A28) 成立；新增 **(A29)** 共形覆盖 `P(h_true∈H_α(o))≥1-α`；**(A30)** `ρ_S(d|·)` 满足 `L_ρ`-Lipschitz；**(A31)** 感知管线证书等价保持率 `≥ρ^perc(e)`。则
```
P_success ≥ (1-α)·[1 - Σ_d(1 - ρ^rob(d))]
            - (1 - ρ^perc_min)
            - P(消歧预算耗尽)
            - β_E
```
关键：**真场景在集内 → 集内最坏鲁棒达标 → 感知不跨等价类**，三者串联才算 sound；任何一环只在平均意义成立，整体保证即失效。

## 6. 本轮最大风险

**一句话**：`J_SR` 的 soundness 首先押在“共形场景集在真实分布漂移下仍覆盖真场景”这一可交换性前提上；一旦部署分布破坏可交换性，`H_α(o)` 会以“集很小、裕度为正”的假象给出虚假安全，故必须以 **在线覆盖审计 + 漂移触发降级 + 探针优先** 作为硬护栏，宁可输出 `uncommitted`，也绝不把“在错误场景集上算出的正裕度”当成部署许可。
