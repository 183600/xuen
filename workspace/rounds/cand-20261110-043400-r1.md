# 第 41 轮 · 双侧夹击 v8：证书的证据对偶 × 规范伦理证书 × 预注册证据孪生（四层架构 v6）

> 承接第 40 轮（v17：可认证流匹配执行 × 度量语义几何锚定 × 证书驱动课程引擎，四层架构 v5）。第 40 轮自陈的最大风险是「装饰性证书」——证书若比真值松 10~100 倍、若无法被数据证伪、若不覆盖规范约束、若第三方无法复算，则整套「可认证」只是文档。本轮灵感词「评测指标、伦理审查」恰好从两侧夹击这一软肋：**评测指标**把证书变成可被在线数据证伪的统计断言（证书的证据对偶），**伦理审查**把证书从「能力/安全」扩展到「规范/问责」并引入不可折中的词典序（证书的规范上界）；二者的交集自然生长出第三个产物——**可复现、预注册、反事实的审计孪生**。一句话：本轮把「证书」从「可认证 (certifiable)」推进到「可证伪、可审计、可问责 (falsifiable, auditable, accountable)」。

## 0. 直觉与动机

**灵感 1（评测指标 → 证书的证据对偶）**：第 40 轮新增了 {L_v, κ, ε_ode, N*, B_t, ValidRegion, D(τ)} 等字段，但这些字段的检验仍是「离线固定样本 + 拍阈值」。这在三处失守：a) RCA 是流式的，固定样本 p 值在反复观察下会膨胀第一类错误（「看太多次就必然显著」）；b) 「认证值/实测值」的紧致性从未成为一等指标，证书松弛无法在接纳那一刻被发现；c) 指标一旦被当成优化目标就会被 Goodhart 化（指标成为目标就不再是好指标）。评测指标的正确出场方式不是「再挂几个 KPI」，而是与证书构成**对偶**：每个证书字段 c 都是一个方向性断言（m ≥ c 或 m ≤ c），每条评测证据序列都对应一个**检验鞅 / e-process** E_t，其构造只依赖零假设 H_c 下的超鞅性，于是 **Ville 不等式**给出「任意时刻」第一类错误 ≤ α 的全时间保证——这正是流式 RCA 所需的「随时可看、看多少次都不膨胀」。进一步，用**共形预测**把 ValidRegion 从启发式阈值升级为分布无关的覆盖保证，用**紧致性 τ_c = c/m̂** 把「是否装饰」变成可测数字。评测指标由此从「报告」变成「准入 (admission)」：证书只有在其对偶 e-process 从未越界时才被 Registry 接纳。

**灵感 2（伦理审查 → 规范证书与词典序优先格）**：第 40 轮的证书几乎全是「能力/安全」类，伦理被默认外包给人类流程。但具身系统在物理世界行动，伦理不是附录而是**一等约束**：它会看人（隐私）、会靠近人（人身安全）、可能来不及让人接管（自主性）、可能对不同人群表现不公（公正）。伦理审查的经典框架（Belmont 报告、Beauchamp–Childress 四原则）恰好可以**逐条翻译成证书字段**：自主 ↦ 接管时延与知情状态；不伤害 ↦ 人体净空 h_human；行善 ↦ 任务收益；公正 ↦ 公平差与差分隐私预算。关键的形式化不是「加一个伦理标签」，而是引入**词典序优先格**：伦理/安全字段是「吸收元」，任何性能收益都不能补偿伦理违约，于是 D(τ)=∞ 当伦理违约，策略无法用高成功率「抵消」伦理代价。这把伦理从「事后审查」变成「写入证书代数的硬约束」，也让伦理审查变成**可机检的合规证明**（哈希链审计账本 + e-values + 隐私账本）。

**灵感 3（评测 × 伦理 = 审计孪生）**：评测要防「事后挑指标」，伦理要防「合规表演」，两者的公共解是**第三方可复现的审计**。临床试点的历史经验给出模板：**预注册**（先锁死指标集、阈值与分析计划，再做实验）+ **盲测** + **可复现重放**。我们把它工程化为**证据孪生**：由仿真状态、传感器日志、证书账本三者构成确定性重放环境，支持**反事实审计**——把某个证书字段从 c 改成 c'，重放并重算 e-process，测量「接纳结论是否翻转」。反事实脆弱度 F(c) 成为「证书质量」的元指标：F 高说明证书只是勉强接纳，应重训或收紧。审计报告（每字段 τ_c、sup_t E_t、共形覆盖、隐私支出、Merkle 根、预注册哈希）既是评测产物，也是伦理审查的呈堂证供。

**三者的耦合**：评测指标给出「可证伪」，伦理审查给出「不可折中」，审计孪生给出「可复现的第三方检验」——三者共同回应第 40 轮的「装饰性证书」风险：装饰之所以可怕，正因为它既不可证伪、又不覆盖规范、还无法被第三方复算；本轮逐条封堵。与上一轮的衔接也清晰：v17 的证书是「断言」，v18 为每个断言配上了「证伪协议、规范边界、审计回放」三件套。

## 1. 形式化定义

**定义 27（证书的证据对偶与 e-process 守门）**：
- 证书字段统一写成方向性断言 H_c：m ≥ c（m 为实测边际，如 Lipschitz 下界、clearance、1/drift、success_rate）。
- 证据序列 m_1, m_2, … 来自任务分布与传感器日志；可预测下注 λ_s ∈ [0, 1/(c − m_min))。
- **e-process**：E_0 = 1，E_t = ∏_{s≤t}(1 + λ_s·(c − m_s))。在 H_c 下 (E_t) 为非负超鞅。
- **Ville 守门**：P_{H_c}(∃t: E_t ≥ 1/α) ≤ α（全时间第一类错误 ≤ α）。
- **接纳规则**：C ∈ Registry ⟺ 对每个字段 c，sup_t E_t^c < 1/α_c，且全局 α 通过 e-merging（E_总 = ∏ E_c）或 Bonferroni 控制。
- **紧致性**：τ_c = c/m̂（上界类）或 m̂/c（下界类）；τ_c ∈ (0,1]，越接近 1 越紧。
- **共形 ValidRegion**：在可交换性下用 conformal p-value 校准，使 P(x ∈ ValidRegion(C)) ≥ 1−α，且分布无关。
- **定理（守门正确性）**：若所有字段均通过 e-process 接纳，则「接纳了不成立证书」的概率 ≤ α（全时间、全字段，经 e-merging/union bound）。

**定义 28（规范证书 CertEth 与词典序优先格）**：
- 四原则 → 字段映射：自主 ↦ (consent_state, T_override)；不伤害 ↦ h_human；行善 ↦ benefit；公正 ↦ (fairness_gap, ε_dp, δ_dp)。
- CertEth = (h_human, (ε_dp, δ_dp), T_override, consent_state, fairness_gap, provenance_root)。
- **优先格** ⪯_lex：伦理 ≻ 安全 ≻ 性能；伦理/安全字段为吸收元 ⊥，任何性能不可补偿。
- 组合：h_human = min_i（空间重叠区取 min）；consent = ∧；T_override 串行 Σ、并行 min；ε_dp 用 RDP 矩会计组合（≤ Σε_i）；provenance_root 为证书链 + 决策链的 Merkle 根。
- **定理（非补偿性）**：词典序下 combine(性能, 伦理违约) = ⊥ 恒成立，故 D(τ)=∞ 当任一伦理字段违约——从机制上阻断 reward hacking 与「伦理换性能」的折中。
- 人体感知 CBF：h_human(x) = clearance_human(x) − margin − B_human − B_t；B_human 由点云聚类 + VLM 人体先验保守估计。
- DP 语义图：语义/占用发布走 Laplace/Gaussian 机制，隐私会计统一记账；日志按同意状态脱敏。
- 伦理审查 = 离线验证 {Merkle 链完整、每字段 e-value 未越界、DP 账本不超预算、consent 记录齐全}。

**定义 29（预注册评测与证据孪生）**：
- **预注册**：评测前提交 commit = H(M₀, 阈值, C, 分析计划)；评测后 reveal；偏离 M₀ 的结果只能标 exploratory，不得用于接纳证书。
- **证据孪生** Twin = (sim_state, sensor_log, cert_ledger)，要求确定性重放；支持反事实 c → c'。
- **审计报告** AuditReport = {c, m̂, τ_c, sup_t E_t, 1/α, 共形覆盖, DP 支出, provenance_root, prereg_hash, 反事实脆弱度 F(c)}。
- **反事实脆弱度** F(c) = P(接纳结论在 c 的 δ-邻域内翻转)；F 高 → 证书只是勉强接纳，应重训或收紧。

## 2. 三大产出设计

### 2.1 IP-51 CERT-EVIDENCE-DUAL（证书证据对偶与 e-process 守门）
1. 每字段配一个 e-process（hedged betting 与共形 p-value 双通道；上界类/下界类分别构造）。
2. anytime-valid RCA：在线监测 sup_t E_t，越界即触发重颁；e-merging 合并多字段而全局 α 不膨胀。
3. 紧致性一等化：τ_c 进入证书包与路由决策；τ_c < 1/3 的字段标红（对接 E67/E74）。
4. 共形 ValidRegion：分布无关覆盖校准，替换拍脑袋阈值。
5. 预注册钩子：接纳只在预注册指标集下生效，exploratory 指标不得用于准入。

### 2.2 IP-52 ETHICAL-CONTRACT（规范证书与词典序优先格）
1. CertEth 六元组（定义 28）+ 四原则映射；伦理字段与能力字段共享同一证书包结构。
2. 人体感知：点云聚类 + VLM 先验 → h_human + B_human；与 ESDF 合并进 CBF。
3. 隐私：DP 语义图 + 隐私会计；同意状态驱动日志脱敏。
4. 接管：T_override 与 IP-48 的 N*、流式发射耦合——接管时延证书 = 停止积分 + 切换策略的可证上界。
5. 词典序总线：伦理吸收元路由；伦理熔断为第五触发器；不可补偿。

### 2.3 IP-53 CERT-AUDIT-TWIN（预注册证据孪生与反事实审计）
1. 确定性重放：仿真 / 日志 / 账本三源对齐，随机种子与时钟锁步。
2. 预注册：commit-reveal 锁定 M₀、阈值、C 与分析计划，防指标购物。
3. 反事实审计：字段扰动重放，计算 F(c)，生成脆弱度谱。
4. 审计报告：面向伦理审查的机检报告（Merkle 根 + e-values + DP 账本 + 共形覆盖）。
5. 与 IP-50 闭环：脆弱字段 → 课程采样加权（证据硬样本）。

## 5. 本轮最大风险

**一句话**：本轮的严谨性全部条件于两个假设——e-process 的超鞅性依赖零假设 H_c 与证据序列的可预测/平稳性，伦理证书的有效性依赖规范编码与真实利益相关者价值一致；一旦真实世界的非平稳漂移或价值错配打破其一，证据守门会「要么恒拒不接纳、要么假接纳」，伦理证书会退化为合规表演，「证据化 + 伦理化」反而给装饰性证书披上更硬的外壳。

## 2. 关键算法

### IP-51 证书证据对偶（伪代码）
```
def e_process_gate(streams, cert, alpha):
    E = {c: 1.0 for c in cert.fields}
    for m_s in streams:                          # 在线边际观测
        for c in cert.fields:
            lam = predictable_bet(history[c], c) # 保证因子非负且可预测
            E[c] *= (1 + lam * (c - m_s[c]))     # 上界类；下界类取反向
            if E[c] >= 1/alpha[c]:
                RCA.recertify(c); Registry.revoke(c)   # anytime-valid
    return E

def tightness(c, m_hat):
    return c/m_hat if is_upper(c) else m_hat/c    # ∈(0,1]

def conformal_valid_region(cal_scores, x, alpha):
    p = (1 + sum(cal_scores >= score(x))) / (len(cal_scores) + 1)
    return p > alpha                              # 分布无关覆盖 ≥1−α
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 正确性保证 |
|---|---|---|
| e-process 守门 | O(|fields|)/步 | **定理**：Ville，全时间 Type-I ≤ α；e-merging 保全局 α |
| 共形 ValidRegion | O(n_cal) 校准，O(1) 查询 | 分布无关覆盖 ≥1−α（可交换假设） |
| 紧致性 τ_c | O(1) | 非装饰性可量化；τ→1 越紧 |
| CertEth 人体 | O(M log M)/帧 | h_human−B_t−B_human ≥0 ⟹ 真实净空 ≥0 |
| DP 会计 | O(1)/发布（RDP 组合） | (ε,δ)-DP 组合界；日志脱敏 |
| 词典序组合/路由 | O(|V|+|E|) | 非补偿性：combine(性能,伦理违约)=⊥ |
| 证据孪生重放 | O(episode) | 确定性重放；反事实 F(c) 稳健性度量 |
| 预注册校验 | O(1) | 指标选择偏差被排除于准入之外 |

## 5. 风险与缓解

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| e-process 零假设错配 / 非平稳 → 恒拒或假接纳 | 高 | 稳健 betting + 变化点检测；漂移时主动重设 H_c 并重校；E73 第一守门 |
| 伦理编码与真实价值不匹配（伦理表演） | 高 | 利益相关者共设计 + 预注册 + 第三方审计账本；E75/E77 守门 |
| 词典序过保守 → 任务不可行 | 中 | 伦理字段分层（硬/软）+ 有据可申诉的证人复核 |
| 共形交换性破缺 | 中 | 加权共形/在线共形；漂移下重标定 |
| 审计孪生浮点/日志不同步 | 中 | 确定性种子 + 时钟锁步；位一致门槛 |
| DP 预算过快耗尽 | 中 | 预算调度 + 语义图分层发布 |
| 证据孪生算力成本 | 低 | 离线批处理 + 采样回放 |

## 6. 本轮最大风险

**一句话**：整套「证据化 + 伦理化」的严谨性都条件于「零假设正确 + 规范编码与真实价值一致」——一旦真实世界的非平稳漂移打破 e-process 的超鞅性、或伦理证书脱离利益相关者校验，守门会恒拒或假接纳、伦理会沦为合规表演，装饰性证书反而被披上更硬的外壳，故 E73（守门有效性）与 E75/E77（伦理可机检与可审计）为本轮成败判据。
