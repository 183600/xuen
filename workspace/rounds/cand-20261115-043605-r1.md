# 第 4 轮（灵感循环第 4 轮；本轮灵感：「多机评测」×「预测性维护」）

> **基线**：第 3 轮 InstructGauge（IP-321–327；定义 432–447；引理 51–58；实验 E441–E456）。第 2 轮 ToolGauge、第 1 轮 LeanGauge / MODGAUGE 骨架继续继承不变。
> 本轮纪律：**增量升级 + 严格退化**。多机与预测性维护都是可选增强；任一环节不可用都必须能一键退回 InstructGauge，再退回 ToolGauge / LeanGauge / MODGAUGE。

## 0. 直觉与动机

**灵感 1（多机评测 → 证据的「单元局部性」，而不是把多台机器平均成一台）**
直觉：同一套算法在 A 机上 92%、在 B 机上 71%，平均成 81.5% 是一句没有工程意义的话。多机评测的价值不是把 n 台机器的数字平均掉，而是回答三个不同的问题：(i) 这台机器自己是否可信（单元内覆盖）；(ii) 换一台机器后证书是否还成立（可迁移性）；(iii) 机群的最坏单元是否达标（worst-unit）。平均会掩盖最坏单元，而安全恰恰由最坏单元决定。更根本地，证书是「关于某个测量单元」的，不是「关于某个算法」的；没有 unit_id 的证书在跨机复用时不是弱保证，而是**无保证**。

**灵感 2（预测性维护 → 预测只能让证书更早失效，不能让它更晚失效）**
直觉：预测性维护最诱人的地方是「把固定校准周期拉长」：既然模型说还能跑 200 小时，为什么还要 100 小时就校准？危险也正在这里——预测模型本身是在会退化的机器上训练的，它最自信的时候可能正是它最不可信的时候。正确的安全分工是：**预测是加速器，硬 TTL 是保证**。RUL 的共形下界只能把有效 TTL 缩短，永远不能超过硬校准周期；预测失效时退回固定 TTL，而不是退回「相信模型」。

**灵感 3（两者耦合 → 机群冗余可能是假冗余，维护会污染评测）**
直觉：多机最诱人的地方是「三台机器交叉验证，总比一台可靠」。但如果三台机器同批次、同维护流程、同环境振动，它们的错误是**共模**的——交叉验证的独立性是借来的，不是免费的。更隐蔽的是：预测性维护会改变被评测的机器状态，维护后的分布与维护前不同；如果评测集和维护策略共享同一批机器或同一时间段，评测就在为自己的维护策略打分。多机评测 × 预测性维护的真正风险不是单机失准，而是**机群级的共同失效 + 评测污染**：一个机群级模型同时决定「谁该维护」和「谁表现良好」，而这两个判断共享同一组被污染的证据。

**为什么这不是简单加两个模块**
多机不是把 n 台机器并联，预测性维护也不是给 TTL 加一个回归器；它们都要求把证书的**适用域**显式写进类型：证书不再只关于分布 `P`，而关于三元组 `(u, h, P)`——单元、健康、分布。只有把这三者写进证书，跨机复用才有「有迁移证书」与「无迁移证书」之分，预测也才有「缩短 TTL」与「延长 TTL」之分。

## 1. 研究问题（本轮要回答什么）

- **Q1（多机证据的局部性）**：证书如何携带单元身份与健康范围，使得跨机复用要么有显式迁移证书、要么 fail-closed？多机评测的最小可识别设计是什么？
- **Q2（预测的安全边界）**：RUL 预测在什么统计假设下可以合法地缩短 TTL？如何保证预测永不延长硬 TTL、且预测失效时优雅退回固定周期？
- **Q3（机群耦合的风险）**：交叉验证的独立性如何被共模失效击穿？维护诱导的分布漂移如何污染评测？能否用结构（单元分层、共模审计、维护后重认证）把机群级风险压回可界？

## 2. 设计原则（雏形，正式化见产物区定义 448–464）

**P1 单元局部性（Unit Locality）**
每张证书携带 `U_scope, H_scope, prov`；跨机复用必须有迁移证书，否则视为无效。禁止「静默平均」，也禁止把机群均值当作机群保证。形式化方向：`Valid(Cert | u,h,P)` 是三元组的合取，不是单点的断言。

**P2 有检验的池化（Test-Gated Pooling）**
分层部分池化只在异质性检验未拒绝时启用；拒绝则逐单元校准。池化降低阈值估计的方差，但不能降低最坏单元的覆盖下界。评测必须同时报告 `mean_u` 与 `min_u`。

**P3 预测只缩短（Prognosis Shrinks Only）**
`TTL_eff = min(T_hard, RUL_LCB − lead, T_health)`。预测不能延长任何硬边界；模型出域或假设不成立时，`TTL_eff` 直接退回 `T_hard`。这把「预测性维护」从「延期许可」降级为「提前预警」。

**P4 维护是证据动作（Maintenance Is Evidence）**
维护后必须通过独立 PMV 与再校准，才允许重置证书；维护本身不产生信用。维护会改变 `P_u`，因此「健康恢复」不等于「证书恢复」。

**P5 共模审计（Common-Mode Audit）**
跨机陪审团使用 `n_eff` 而非 `n`；共模相关超阈则禁用陪审团，升级为人工或停线。多机冗余的收益必须扣除共模折减，不能把「同一故障模式的三份拷贝」当成三个独立证据。

## 3. 与基线的接口（如何退化）

- 无单元注册表 / 指纹 ⇒ 单机证书，等价 InstructGauge；
- 异质性检验不可用或被拒绝 ⇒ 逐单元校准（无池化），仍保留多机评测报告；
- 无健康遥测或 RUL 模型 ⇒ 固定 `T_hard`（InstructGauge 的 TTL）；
- 无 PMV ⇒ 维护后不重置 TTL（fail-closed）；
- 共模审计失败 ⇒ 陪审团降级为单机 + 升级；
- InstructGauge 失效 ⇒ ToolGauge；ToolGauge 失效 ⇒ LeanGauge；LeanGauge 失效 ⇒ MODGAUGE 原样。

## 4. 预期贡献

1. 一个「证书 = 单元 × 健康 × 分布」的 scoped-certificate 口径，把跨机复用从隐含假设变成显式迁移证书；
2. 一个带异质性检验的分层部分池化共形校准，给出逐单元覆盖与最坏单元覆盖；
3. 一个「预测只缩短 TTL」的健康感知证书时效，配 RUL 共形下界与固定 TTL 兜底；
4. 一个共模感知的跨机陪审团与配对多机评测协议，显式报告 `min_u` 与 `n_eff`；
5. 一条可证伪路径：E457–E472 覆盖身份绑定、异质性、最坏单元、RUL 覆盖、维护闭合、共模、时序与 sim→real。

## 5. 本轮最大风险

**一句话**：机群级预测性维护最危险的不是某台机器预测错，而是**多机证据的独立性与评测的干净性同时被共模失效和维护诱导漂移破坏**——模型用被自己维护策略污染的数据证明自己有效，并在最需要报警的共模故障前给出「一切正常」的假冗余。

## 2. 形式化定义（要点）

**定义 448（单元作用域证书 Cert 与有效性）** `Cert = (θ, P_cert, U_scope, H_scope, T_hard, source, prov, trans)`。
`Valid(Cert | u,h,P,t) ⇔ u ∈ U_scope ∧ h ∈ H_scope ∧ P ∈ P_cert ∧ t−t_0 ≤ T_hard ∧ (u = source ∨ trans_{source→u} 覆盖误差膨胀)`。
`U_scope` 非单点时必须同时由池化校准与异质性检验支撑；否则只允许单点。**核心语义：证书不是「算法的性质」，而是「算法 × 单元 × 健康 × 分布」的性质。**

**定义 449（单元指纹与机群注册表）** `F_u = Hash(hardware, sensor, firmware, calibration_artifacts, maintenance_lineage)`；注册表 `R = (U, {F_u}, G_prov)` 是只追加的谱系 DAG。`Merge(Cert_a, Cert_b)` 合法当且仅当 `F_a = F_b`，或存在迁移证书 `T_{a→b}` 证明误差膨胀 `Δε_{a→b}` 被 `θ` 吸收。禁止无 `trans` 的静默池化。

**定义 450（健康状态与遥测观测）** `h_u(t) ∈ [0,1]`（0 = 新机，1 = 失效），`z_u(t) = g(h_u(t)) + η_t`，`ĥ_u(t) = filter(z_{1:t})`。健康估计误差满足 `|ĥ − h| ≤ e_h`（概率 `1−β_h`）。所有下游只使用上置信 `h^+ = ĥ + e_h`，保证保守。

**定义 451（健康条件误差界与健康失效时刻）** `ε_u: H → R_{≥0}` 非降、`L_ε`-Lipschitz，满足 `P(|e_meas| ≤ ε_u(h)) ≥ 1−α`。`T_health(u,t) = inf{s ≥ t: ε_u(h^+(s)) > ε_budget}`。直观：健康不是「另一条指标」，它直接进入测量不确定度。

**定义 452（RUL 与共形下界）** `T_u = inf{t ≥ 0: h_u(t) ≥ 1}`。预测器输出 `L_α^RUL(t)`，在预注册的轨迹可交换 / 有界漂移模型下满足 `P(T_u ≥ t + L_α^RUL(t) | F_t) ≥ 1−α`。`L_α` 取保守下界、非增、截断于 0。**若假设不成立或模型出域，`L_α := 0`，立即退回硬 TTL。**

**定义 453（有效 TTL 与「预测只缩短」）** `TTL_eff(u,t) = max(0, min(T_hard(u), L_α^RUL(t) − τ_lead, T_health(u,t) − t))`。恒有 `TTL_eff ≤ T_hard`；`τ_lead` 是维护提前量，`T_health` 是绝对失效时刻。`TTL_eff ≤ 0` ⇒ 立即降级或停线，不允许「负 TTL 继续跑」。

**定义 454（维护动作与维护后验证 PMV）** `m = (type, cost, downtime, ρ, PMV)`；`h_u(t^+) = ρ_u h_u(t^-) + (1−ρ_u) h_new`，`ρ ∈ [0,1]` 为恢复因子。`PMV` 是独立于维护动作的验证程序（独立基准件、独立操作者、独立时段）。**只有 PMV 通过且 `P_u^+ ∈ P_cert`（或完成再校准）才允许重置 TTL；维护动作本身不产生证书信用。**

**定义 455（维护诱导分布漂移）** `d_m = d(P_u^-, P_u^+)`；`d_m > δ_m` ⇒ 单元进入「维护后未校准」状态，证书无效直到再校准。维护重置的是健康，不是分布；`P_u^+` 必须重新进入认证域。

**定义 456（分层部分池化共形校准 HPC）** 单元阈值 `q_u(λ) = λ_u q_u^local + (1−λ_u) q_fleet`，`λ_u = n_u / (n_u + κ)`；`q_fleet` 由机群校准集给出。**门控**：异质性检验拒绝 ⇒ `λ_u = 1`（逐单元）。池化只降低阈值估计方差，不改变最坏单元覆盖的下界。

**定义 457（异质性 / 可交换性检验）** `H_0: P_1 = … = P_n`（校准分布可交换）。用 kernel MMD、e-process 或分层 bootstrap，拒绝阈 `1/α_h`。拒绝 ⇒ 禁止池化；同时输出共模相关估计 `ρ̄` 供定义 460 使用。

**定义 458（配对多机评测设计 FMX）** `D = {(u,o,c)}`，`o` 为同一被测对象，`c` 为条件。重叠图 `G_D`：两单元共享至少一个 `(o,c)` 则连边。估计量 `τ = E[Y_{u,o,c} − Y_{u',o,c}]`；方差分解 `σ² = σ²_U + σ²_O + σ²_{U×O} + σ²_ε`。**`G_D` 不连通 ⇒ 单元效应不可识别**；评测必须报告 `min_u Cov_u` 与方差分量，而不是只报机群均值。

**定义 459（跨机陪审团 XJury）** `Jury_{k,n}(C) = 1[Σ_u 1{verify_u(C)} ≥ k]`；参与单元按独立性挑选（不同批次、位置、维护史）。**分歧 ⇒ 隔离并升级，不做多数平均**——安全决策不是参数估计，不能用平均消掉异常。

**定义 460（共模因子与有效独立单元数）** `π_c = P(共模错误)`，`ρ̄` 为单元错误事件平均两两相关；`n_eff = n / (1 + (n−1)ρ̄)`。陪审团错误上界 `≤ π_c + (1−π_c)·BinomCDF(k−1; ⌊n_eff⌋, p)`（或 Poisson-binomial 界）。`ρ̄ > ρ_max` 或 `π_c > π_c,max` ⇒ 禁用陪审团，降级为单机 + 人工 / 停线。

**定义 461（机群维护调度）** `π_maint: (h, L_α, cost, capacity) → 维护集合`；目标 `max E[有效运行时间] − λ_c·cost − λ_r·risk`，约束 `P(任一单元在维护前失效) ≤ β`、维护容量、`TTL_eff`。采用 RUL-LCB 阈值策略：`L_α(t) ≤ τ_lead` 即排程。

**定义 462（机群证书 FleetCert）** `FleetCert = (U_scope, {Cert_u}, {PMV_m}, {L_α,u}, {Cov_u}, n_eff, common_mode_audit, prov)`。人类审计可沿「单元 → 健康 → RUL → 维护 → 证书」五级链复现一次机群决策；机群级修复解释证书记为 `RepairCert″`。

**定义 463（评测污染与 fit/eval 分离）** 若用于拟合预后模型的单元同时是唯一评测单元，或维护策略改变了评测窗口分布，则评测被污染。要求：fit/eval 单元分离或留出单元；评测窗口预注册并冻结；维护动作不得触碰评测集。违反 ⇒ 该评测结论作废，不进入判据。

**定义 464（降级格 L0–L7）** `L0` 全机群 + 陪审团 + 预测；`L1` 禁陪审团；`L2` 逐单元校准（禁池化）；`L3` 单机固定 `T_hard`；`L4` InstructGauge；`L5` ToolGauge；`L6` LeanGauge；`L7` MODGAUGE。降级单调、禁止跳级恢复：`Lk → Lj (j < k)` 必须经过重校准 / PMV 与重新认证，不能靠「指标恢复正常」直接跳回。

# IP-328 UnitCard：证书绑定与跨机复用
class UnitCard:
    def bind(self, cert, unit, registry):
        if cert.U_scope == {unit.id}:
            return cert
        if registry.fingerprint(cert.source) == unit.fingerprint:
            return cert.scope(unit)
        trans = registry.transfer(cert.source, unit.id)
        if trans is None or not covers(trans, cert.theta):
            return None                                  # fail-closed
        return cert.scope(unit).inflate(trans.delta_eps)

# IP-329 HEC：健康滤波与健康条件误差界
class HEC:
    def update(self, z, dt):
        self.h_hat = self.filter.predict_update(self.h_hat, z, dt)
        self.h_plus = min(1.0, self.h_hat + self.e_h)
        return self.h_plus

    def error_bound(self, h_plus):
        return self.eps(h_plus)                          # 非降、Lipschitz

    def health_expiry(self, t, h_plus):
        return self.first_crossing(t, h_plus, self.eps_budget)

# IP-330 PCal-RUL：共形 RUL 下界与有效 TTL
class PCalRUL:
    def lower_bound(self, traj, t, alpha):
        if not self.in_domain(traj):
            return 0.0                                   # 出域 ⇒ 立即失效
        return self.conformal_quantile(traj, t, alpha)   # 轨迹可交换假设

    def ttl(self, t, hard_ttl, lcb, lead, health_expiry):
        expiry = min(t + hard_ttl,
                     t + lcb - lead,
                     health_expiry)
        return max(0.0, expiry - t)

# IP-331 HPC：异质性门控的分层部分池化
class HPC:
    def threshold(self, unit, cal):
        if not self.exchangeable(cal, unit):
            return self.per_unit_quantile(cal[unit])     # λ = 1
        lam = len(cal[unit]) / (len(cal[unit]) + self.kappa)
        return (lam * self.per_unit_quantile(cal[unit])
                + (1 - lam) * self.fleet_quantile(cal))

# IP-332 XJury：共模感知陪审团
class XJury:
    def decide(self, claim, receipts, units):
        if not self.common_mode_ok(units):
            return ESCALATE                              # 假冗余 ⇒ 不用陪审团
        n_eff = self.effective_n(units)                  # 由 ρ̄ 给出
        votes = sum(self.verify(u, claim, receipts[u]) for u in units)
        k = self.required_k(n_eff, self.error_budget)
        return votes >= k, (votes, n_eff)

# IP-333 FMX：配对多机评测
def fleet_eval(units, objects, conditions, policy):
    D = paired_design(units, objects, conditions)        # 必须有重叠
    if not connected(overlap_graph(D)):
        return UNIDENTIFIABLE                            # 无重叠 ⇒ 不可识别
    y = run(D, policy)
    comp = variance_decomposition(y)                     # U / O / U×O / ε
    cov = {u: conformal_coverage(y, u) for u in units}
    return FleetReport(comp, cov, worst_unit=min(cov, key=cov.get))

# IP-334 FleetGauge-8C 闭环
def fleetgauge_8c(M, s, ell=None):
    out = M.ig.instructgauge_7c(M, s, ell)               # 沿用第 3 轮闭环
    if not out:
        return out
    u = M.registry.unit(s)
    h = M.hec.update(M.telemetry(s), M.dt)
    if M.hec.error_bound(h) > M.eps_budget:
        return degrade(M, u, "health")
    lcb = M.rul.lower_bound(M.traj[u], M.t, M.alpha)
    ttl = M.rul.ttl(M.t, M.hard_ttl(u), lcb, M.lead,
                    M.hec.health_expiry(M.t, h))
    if ttl <= 0:
        return degrade(M, u, "ttl")
    if M.clock.at_quiesce(s):                            # 维护/热替换只在静默点
        m = M.sched.next(M.h, M.rul, M.cost, M.capacity)
        if m and M.pmv.run(m, unit=u):
            M.registry.reset_ttl(u, M.t)                 # 只有 PMV 通过才重置
    if M.jury.required(s):                               # 高危决策才用陪审团
        ok, stat = M.jury.decide(s.claim, M.receipts,
                                 M.independent_units(u))
        if not ok:
            return quarantine_and_red(s, stat)
    return out

# IP-334 主闭环：50Hz 路径不变
def FleetGauge_round(M, obs, audio, tac, depth, det, ell=None):
    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight:
            M.inflight.add(s)

    return MODGAUGE_round(M, obs, audio, tac, depth, det)

## 4. 推导

**引理 59（单元局部性与静默混用无效）** 若 `Cert` 的 `U_scope = {u}` 且无 `trans_{u→u'}`，则 `Valid(Cert | u', ·) = False`；且存在校准分布 `P_{u'}` 使测量误差超过 `θ`，故跨机复用不是「弱保证」而是「无保证」。
*证明骨架*：定义 448 的合取失败。构造 `P_{u'}`：把系统偏置放在 `u'` 指纹差异方向上（不同镜头、不同臂长、不同批次编码器）；证书从未观测该方向，任何只依赖 `Cert` 的界都可被该偏置击穿。迁移证书是唯一补上该方向信息的对象。∎

**引理 60（健康单调性与保守失效）** `ε` 非降 ⇒ 失效集 `{h: ε(h) > ε_budget}` 是上闭集；用 `h^+ ≥ h` 检查只会提前失效，不会漏失效。
*证明*：若 `h_1 ≤ h_2`，则 `ε(h_1) ≤ ε(h_2)`；故 `h` 越坏越早越界。`h^+ = ĥ + e_h ≥ h` 以概率 `1−β_h` 成立，所以 `T_health(h^+) ≤ T_health(h)`，保守。∎

**引理 61（RUL 共形下界给出保守 TTL）** 若 `L_α^RUL(t)` 满足 `P(T_u ≥ t + L_α | F_t) ≥ 1−α`，则 `P(T_u ≥ t + TTL_eff) ≥ 1−α`，且 `TTL_eff ≤ T_hard` 恒成立。
*证明*：由 `TTL_eff ≤ L_α − τ_lead ≤ L_α` 得 `{T_u ≥ t + L_α} ⊆ {T_u ≥ t + TTL_eff}`；取概率即得。`TTL_eff` 是 `T_hard`、RUL 项、`T_health − t` 三者之 min，故 `TTL_eff ≤ T_hard`。预测项与健康项都只能减小 TTL。若 `L_α` 不可用，`TTL_eff = T_hard`，回到第 3 轮已认证的硬周期。∎

**引理 62（部分池化的逐单元覆盖与最坏单元）** 在可交换性下，`q_u(λ)` 对每个单元覆盖 `≥ 1−α`；在异质性下，`Cov_u(λ) ≥ 1−α − TV(P_u, P_fleet)`。检验拒绝时 `λ_u = 1`，覆盖回到逐单元保证。故池化只能降低阈值估计方差，不能把 `min_u Cov_u` 提高到超过逐单元校准的下界；最坏单元必须单独报告。
*证明*：conformal 在分布偏移下的标准 TV 界；`λ_u = 1` 是定义 456 的门控分支。`min_u` 对平均不敏感，故机群均值不能替代最坏单元。∎

**引理 63（共模下限）** 设共模事件 `C` 以概率 `π_c` 发生；在 `C^c` 下各单元独立犯错概率为 `p`。则
`P(Jury_{k,n} 错) ≤ π_c + (1−π_c) Σ_{j=0}^{k−1} C(n,j) p^j (1−p)^{n−j}`。
特别地，任何 `n` 都不能把错误率压到 `π_c` 以下；`n_eff` 版本把 `n` 替换为 `n / (1 + (n−1)ρ̄)`。
*证明*：全概率公式 + 条件独立。共模事件下所有单元同时错，陪审团必错，贡献 `π_c`；其余情形按二项尾界。共模是加性下限，增加机器数量只降低第二项，碰不到第一项。∎

**引理 64（Simpson / 无免费机群泛化）** 存在两个单元 A、B 与两个对象层 E、H，使得 A 在每一层都优于 B，但机群平均 A 劣于 B。构造：A 在 E 上 95/100，在 H 上 100/1000；B 在 E 上 900/1000，在 H 上 4/50。A 逐层为 95% > 90%、10% > 8%，总体 195/1100 = 17.7% < B 904/1050 = 86.1%。故机群均值可以被对象配比反向操纵；多机评测必须报告逐层 / 配对结果与 `min_u`。
*证明*：直接计算。差异来自对象配比（A 承担了更多 H 层），不是单元能力。∎

**引理 65（维护闭合：无 PMV 不重置）** 维护动作 `m` 只改变 `h`，不改变证书有效性；`Valid` 在维护后仍为假，除非 PMV 通过且 `P_u^+ ∈ P_cert`。若 PMV 失败，单元保持降级；若 `ρ < 1`，`h^+ > h_new`，误差界不会优于新机。故不存在「维护信用」的免费重置。
*证明*：由定义 454/455 的合取条件直接得到。反例：维护后未校准但健康指标好看，证书仍无效；「看起来修好了」不是证据。∎

**引理 66（配对设计的可识别性）** 对加性模型 `Y_{u,o} = μ + α_u + β_o + γ_{uo} + ε`，若重叠图 `G_D` 不连通，则对任一连通分量同时作 `α_u → α_u + c`、`β_o → β_o − c` 不改变任何预测，故 `α_u` 不可识别。`G_D` 连通且设计矩阵满秩是单元效应可识别的充要条件（在加性模型内）。
*证明*：分量变换保持 `α_u + β_o` 不变；预测只依赖该和。连通性使该变换只能取 `c = 0`。∎

**引理 67（异步健康 / 维护不破坏 50Hz）** 健康滤波、RUL 共形、HPC 校准与维护调度均在异步域运行；50Hz 主路径只读缓存的 `h^+`、`TTL_eff`、`U_scope`，为 `O(1)` 查表。维护 / 热替换只在 `q_quiesce`；新增周期 `< 0.2ms`。
*证明*：与第 3 轮引理 58 同构；新路径不进入内联循环；维护是屏障，等价于 `K = 1` 的块，故不引入块内混合契约。∎
