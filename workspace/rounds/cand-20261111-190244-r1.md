# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「模型量化」×「开放词汇」）

> 第 54 轮把技能组合推进到动作空间剖面与云边协同。本轮转向 **表征精度与语义开放域**：量化压缩数值分辨率，开放词汇扩张语义支撑，二者在“低 margin × 高新颖度”的前沿区域正面相撞。核心矛盾：H22：量化在闭集上的精度损失可测，但开放词汇决策依赖 embedding 相对距离，量化畸变会在未见概念处放大为语义混叠；H23：云端全精度大模型掌握开放词表，边端低比特模型只能安全执行量化鲁棒词表，二者需要显式的“精度-词表契约”而非原始 prompt 复制。

## 0. 直觉与动机

**灵感 1（量化 = 表征空间度量的离散化，而非单纯压缩）**
直觉：把量化看作在 embedding 空间上铺一层步长为 Δ_b 的网格。开放词汇分类不是绝对打分，而是“正确概念与最近混淆概念之间的 margin 比较”。只要 margin > 量化畸变，排序稳定；一旦 margin < Δ_b，两个概念就可能被量化“折叠”到同一格。于是量化风险不是平均精度下降，而是 **小 margin 区域的局部拓扑改变**。

**灵感 2（开放词汇的危险区 = 低 margin × 高新颖度）**
直觉：闭集评测覆盖的是已知概念，margin 通常较大；真正开放的任务落在校准支撑之外，新颖度 ν(c) 高、语言锚点稀疏、margin 天然小。量化误差与开放域新颖度在此叠加，形成 **前沿风险区** `R_frontier = {m_0 ≤ θ_m + λν}`。因此“量化后在闭集上掉点多少”不能回答“开放词汇是否安全”。例如边端 4-bit 模型面对“把没见过的蓝色工具递给我”时，概念“蓝色工具”既新颖又低 margin，最容易被量化推到错误锚点附近。

**灵感 3（词表级证书与显式拒绝）**
直觉：不要再给整个模型发一张“量化可用”证书，而是给概念发证书：`QOV(c;b)` 记录该概念在 b-bit 下的 margin、畸变、新颖度和混叠关系。证书只在有效域内 sound；域外概念必须回退云端或拒绝执行。这把开放词汇从“模型能力”变成“可判定的概念集合”。

**灵感 4（云边精度-词表契约 → 边端只执行可证词表）**
直觉：云端全精度模型维护开放前沿，边端量化模型执行 `V_e`（量化鲁棒词表）；`V_c` 交给云端实时判定，`V_r` 直接拒绝/询问。边端不是“小一号的云”，而是 **带证书的执行器**。可用比特预算与回退延迟共同决定词表分区，形成 `V = V_e ⊔ V_c ⊔ V_r` 的契约。

**灵感 5（保证金量化与按概念分配比特）**
直觉：既然风险集中在低 margin 概念，就不该对所有权重、所有概念一视同仁。用 **margin-preserving QAT** 把 margin 作为正则项，并做 **按概念簇的混合精度比特分配**：高 margin 概念用 4-bit，低 margin 新概念保留 8-bit 或回退云端。这把量化从“全局一刀切”变为“按语义风险分配数值分辨率”。

**灵感 6（金字塔再扩展：精度-词表层 ℚ）**
直觉：在第 54 轮 `𝕃`（鲁棒性）与 `𝔸`（动作协同）之上叠加 `ℚ`：`ℚ_0` 数值精度，`ℚ_1` embedding 度量畸变，`ℚ_2` 词表前沿与混叠，`ℚ_3` 云边精度-词表契约。跨层证书需同时携带 `ρ`、`A_cert`、`QOV` 与比特预算 `b*`。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（量化语义算子与度量畸变）**
全精度编码器 `φ^0=(φ_V^0,φ_T^0)`，输出单位球归一化 embedding。b-bit 量化编码器 `φ^b = Q_b ∘ φ^0`。在校准集 `D_cal` 上定义
```
ε_b^V = sup_{x∈D_cal} ||φ_V^b(x) - φ_V^0(x)||
ε_b^T = sup_{c∈C_cal} ||φ_T^b(c) - φ_T^0(c)||
```
并令 **度量畸变半径** `Δ_b = ε_b^V + ε_b^T`。对任意单位向量 `u,v`，余弦相似度满足 `|s_b(x,c)-s_0(x,c)| ≤ Δ_b`。

**定义 122（开放词汇前沿与新颖度）**
开放词表 `V` 可动态增长。已知概念支撑 `S_known = ⋃_{c∈V_cal} B(φ_T^0(c), r_c)`。概念新颖度 `ν(c)=dist(φ_T^0(c),S_known)`。给定阈值 `ν_0`，**开放前沿** `∂V={c:ν(c)≥ν_0}`。概念的 **量化条件 margin** 为
```
m_b(x,c)=min_{c'≠c}[s_b(x,c)-s_b(x,c')],   m_b(c)=inf_{x∈D_c} m_b(x,c)
```
其中 `D_c` 为该概念的查询/仿真样本集。前沿风险区 `R_frontier={(x,c): m_0(x,c) ≤ θ_m+λν(c)}`。

**定义 123（量化语义混叠）**
若 `||φ_T^0(c_i)-φ_T^0(c_j)|| ≤ 2Δ_b`，称 `(c_i,c_j)` 在 b-bit 下 **Δ_b-可混叠**。混叠图 `G_alias^b=(V,E_alias)`，`E_alias` 为可混叠概念对。若两概念在 `G_alias^b` 中连通，则存在量化后不可区分的风险；每个概念的混叠邻域记为 `Alias_b(c)`。

**定义 124（量化-开放词汇联合证书 QOV）**
`QOV(c;b) = (c,b,m_b(c),Δ_b,ν(c),Alias_b(c),evidence)`。证书在 **有效域** 内成立：
```
m_b(c) ≥ θ_m + λν(c) + Δ_b   ∧   Alias_b(c) = ∅
```
并按风险分级：`edge`（可边端执行）、`cloud`（边端不可证但云端可判定）、`reject`（混叠或新颖度过高，不自动执行）。证书只对满足条件的 `c` 有效，域外不继承。

**定义 125（云边精度-词表分区契约）**
`C_QV=(V_e,V_c,V_r,ψ,τ_cloud,β_c,β_r)`：
- `V_e`：边端可证词表，`∀c∈V_e, QOV(c;b_e)=edge`；
- `V_c`：云端回退词表，`QOV(c;b_e)=cloud`，由云端全精度模型实时判定；
- `V_r`：拒绝/询问词表，`QOV(c;b_e)=reject`；
- `ψ:E_cloud→E_edge` 为跨模型锚点对齐映射，误差 `||ψ(e_c)-e_c^edge||≤δ_ψ`；
- `τ_cloud` 回退时限，`β_c,β_r` 为云端回退与拒绝的比例预算。
约束：`V_e⊔V_c⊔V_r=V`，且 `V_e∩{c:Alias_b(c)≠∅}=∅`。

**定义 126（量化-动作-鲁棒联合证书 QJ）**
`QJ=(J,QOV,b*,V_e,V_c,V_r,ψ,evidence)`，其中 `J` 为第 54 轮动作-鲁棒联合证书，`b*` 为概念簇比特分配。部署条件：
```
J 可部署 ∧ ∀c∈V_e: QOV(c;b*(c))=edge
         ∧ δ_ψ≤Θ_ψ ∧ |V_c|/|V|≤β_c ∧ |V_r|/|V|≤β_r
```
若任一不满足，任务只能降级为“云端主导的监督执行”，不得标记为全自动可部署。

## 2. 关键算法 伪代码

### IP-121 QSP（Quantization Semantic Profiling）

```python
def quant_semantic_profile(model, D_cal, C_cal, bits_grid):
    prof = {}
    for b in bits_grid:
        enc_b = quantize(model.enc, b)
        eps_v = max(norm(enc_b.visual(x) - model.enc.visual(x)) for x in D_cal)
        eps_t = max(norm(enc_b.text(c)   - model.enc.text(c))   for c in C_cal)
        delta = eps_v + eps_t
        prof[b] = dict(eps_v=eps_v, eps_t=eps_t, delta=delta,
                       ece=expected_calibration_error(enc_b, D_cal))
    return prof
```

### IP-122 OVF（Open-Vocabulary Frontier）

```python
def frontier_profile(concepts, text_enc, known_support, lam, theta_m, margin_0):
    out = {}
    for c in concepts:
        e = text_enc(c)
        nu = distance(e, known_support)
        risky = (margin_0[c] <= theta_m + lam * nu)
        out[c] = dict(nu=nu, risky=risky, frontier=(nu >= NU_0))
    return out
```

### IP-123 QOVC（Quantization-Open-Vocabulary Certificate）

```python
def issue_qov(c, b, prof, margin_b, nu, alias_neighbors, theta_m, lam):
    delta = prof[b].delta
    if len(alias_neighbors(c)) > 0:
        return ('reject', 'alias', QOV(c, b, margin_b, delta, nu, alias_neighbors(c)))
    if margin_b < theta_m + lam * nu + delta:
        status = 'cloud' if nu < NU_REJECT else 'reject'
        return (status, 'insufficient_margin', QOV(c, b, margin_b, delta, nu, set()))
    return ('edge', 'ok', QOV(c, b, margin_b, delta, nu, set()))
```

### IP-124 QBA（Quantization Bit Allocation）

```python
def allocate_bits(concepts, prof, margin_0, nu, theta_m, lam,
                  bits=(2, 4, 8, 16)):
    b_star = {}
    for c in concepts:
        need = margin_0[c] - theta_m - lam * nu[c]
        feasible = [b for b in bits if prof[b].delta <= need]
        b_star[c] = min(feasible) if feasible else None   # None -> cloud/reject
    return b_star
```
按 margin 分位数把概念聚成若干簇，可把 `|V|` 次决策降为 `K` 次，簇内共享比特；目标是在总比特预算 `B_e` 下最大化 `|V_e|`。

### IP-125 CVP（Cloud-Edge Vocabulary Partition + Anchor Distillation）

```python
def partition_vocabulary(V, qov, beta_c, beta_r):
    V_e = [c for c in V if qov[c].status == 'edge']
    V_c = [c for c in V if qov[c].status == 'cloud']
    V_r = [c for c in V if qov[c].status == 'reject']
    if len(V_c)/len(V) > beta_c or len(V_r)/len(V) > beta_r:
        return ('degrade', V_e, V_c, V_r)
    return ('ok', V_e, V_c, V_r)

def margin_preserving_qat(cloud_enc, edge_model, V_e, b, lam_m, lam_a, theta_m):
    # L = L_task + lam_m*mean(relu(theta_m - margin_b(c)))
    #              + lam_a*mean(||phi_b(c) - psi(phi_0(c))||^2)
    for c in V_e:
        anchor_b = edge_model.text(c)
        loss_m = relu(theta_m - margin_b(c)).mean()
        loss_a = norm(anchor_b - psi(cloud_enc.text(c))).pow(2).mean()
        loss = task_loss + lam_m * loss_m + lam_a * loss_a
        update(edge_model, loss)
    return edge_model
```

### IP-126 QJ（Quantization-Joint Certificate）

```python
def joint_quant_certificate(J, V, b_star, prof, margin_b, nu,
                            alias_graph, psi_err, budgets):
    qov = {c: issue_qov(c, b_star[c], prof, margin_b[c], nu[c],
                        lambda x: alias_graph.neighbors(x),
                        budgets.theta_m, budgets.lam) for c in V}
    status, V_e, V_c, V_r = partition_vocabulary(V, qov,
                                                 budgets.beta_c, budgets.beta_r)
    if status != 'ok':
        return ('reject', 'vocabulary_budget', V_r)
    if psi_err > budgets.Theta_psi:
        return ('reject', 'anchor_transfer', psi_err)
    if not J.deployable:
        return ('reject', 'action_robustness', J)
    return ('ok', QJ(J, qov, b_star, V_e, V_c, V_r, psi_err, evidence=()))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| QSP | O(|D_cal|·|B|·d) | O(|B|) | 漂移上界覆盖实测 |
| OVF | O(|V|·|V_cal|·d) | O(|V|) | 新颖度估计可校准 |
| QOVC | O(|V|·d + |E_alias|) | O(|V|+|E_alias|) | margin 下界 sound、混叠不漏 |
| QBA | O(|V|·|B|) | O(|V|) | 比特-畸变单调、预算闭合 |
| CVP | O(|V| + |V_e|·d + QAT) | O(|V|+d) | ψ 有界、分区互斥完备 |
| QJ | O(QOVC + CVP) | O(|V|+|E_alias|) | 证书联动、降级可判定 |

**命题 55.1（闭集校准不足以证明开放前沿）**
若 `D_cal` 的支撑与开放前沿 `∂V` 不相交，则任何仅依赖 `D_cal` 上 `ε_b` 的证书都无法约束 `∂V` 上的 `m_b`；存在 `c∈∂V` 使 `m_b(c) < m_0(c) - Δ_b`。因此必须引入前沿采样/共形校准与显式拒绝，不能把闭集量化曲线外推为开放词汇保证。

**命题 55.2（精度-词表预算守恒）**
在总边端比特预算 `B_e` 下，边端可证词表容量满足 `Σ_{c∈V_e} b*(c) ≤ B_e`。若所有边端概念至少需 `b_min(θ_m,ν)` 比特，则 `|V_e| ≤ B_e / b_min`；开放词表扩大时，超出部分只能进入 `V_c`（云端回退）或 `V_r`（拒绝）。这把“开放词汇能力”与“量化比特预算”显式耦合。

**正确性定理（Quantization-Aware Open-Vocabulary Soundness）**
假设第 54 轮 (A22)–(A28) 成立；**(A29)** 对前沿分布，量化畸变上界 `Δ_b^frontier` 由共形校准给出，覆盖概率 `≥1-α`；**(A30)** 新颖度估计满足 `ν̂(c) ≥ ν(c)-η_ν`；**(A31)** 云回退满足 `P(τ_cloud≤τ_max)≥1-β_cloud`，跨模型锚点误差 `δ_ψ≤Θ_ψ`。
则对需要概念集 `C_T⊆V` 的任务：
```
P_success ≥ 1 - α - β_cloud - β_E - Σ_d(1-ρ_min(d))
              - |C_T ∩ V_r|/|C_T| - η_alias
```
其中 `η_alias` 为混叠漏检概率。要点：**边端只执行可证词表**，**前沿概念由云端兜底**，**混叠概念显式拒绝**；证书 soundness 不再假设闭集=开集。

## 6. 本轮最大风险

**一句话**：量化-开放词汇联合证书把“模型能不能跑”升级为“哪些概念在何种比特下可被安全判定”，但其 soundness **根本依赖前沿 `∂V` 上的畸变校准与新颖度估计**；而开放前沿恰恰是校准数据最稀疏、margin 最小、量化混叠最易发生的地方——一旦把闭集量化曲线外推为开放词汇保证，证书会在未见概念上“假 sound”，因此必须以 **共形前沿校准 + 混叠显式拒绝 + 云端兜底** 三重护栏，宁可把新概念判为不可自动执行，也不发一张覆盖未知的证书。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-OpenQuant（QSP×OVF×QOVC×QBA×CVP×QJ）

> 承接第 54 轮产物 v31。本轮在动作-鲁棒-云边体系之上，增加 **量化语义剖面、开放词汇前沿、概念级证书、按概念比特分配、精度-词表分区契约、量化联合证书** 六个算子：
> - **QSP（Quantization Semantic Profiling）**：比特-语义曲线 `ε_b, Δ_b`，把量化误差映射到 embedding 度量；
> - **OVF（Open-Vocabulary Frontier）**：新颖度 `ν(c)` 与开放前沿 `∂V`，定位真正危险的概念区域；
> - **QOVC（Quantization-Open-Vocabulary Certificate）**：概念级三态证书 `edge/cloud/reject`；
> - **QBA（Quantization Bit Allocation）**：按 margin 预算分配 `b*(c)`，实现语义风险驱动的混合精度；
> - **CVP（Cloud-Edge Vocabulary Partition）**：`V=V_e⊔V_c⊔V_r` 契约 + 保证金 QAT + 锚点对齐 `ψ`；
> - **QJ（Quantization-Joint Certificate）**：把 QOV 与第 54 轮 `J` 合并为量化-动作-鲁棒联合证书。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-118/120 以纳入 `QOV`、`b*` 与词表分区。

| `ν(c)` | 概念新颖度（到已知概念支撑的距离） |
| `∂V` | 开放词汇前沿 |

| `QOV(c;b)` | 概念级量化-开放词汇证书 |
| `b*(c)` | 概念/概念簇比特分配 |
| `V_e, V_c, V_r` | 边端可证 / 云端回退 / 拒绝词表 |

## 2. 关键算法 伪代码

### IP-121 QSP

```python
def quant_semantic_profile(model, D_cal, C_cal, bits_grid):
    prof = {}
    for b in bits_grid:
        enc_b = quantize(model.enc, b)
        eps_v = max(norm(enc_b.visual(x) - model.enc.visual(x)) for x in D_cal)
        eps_t = max(norm(enc_b.text(c)   - model.enc.text(c))   for c in C_cal)
        delta = eps_v + eps_t
        prof[b] = dict(eps_v=eps_v, eps_t=eps_t, delta=delta,
                       ece=expected_calibration_error(enc_b, D_cal))
    return prof
```

### IP-122 OVF

```python
def frontier_profile(concepts, text_enc, known_support, lam, theta_m, margin_0):
    out = {}
    for c in concepts:
        e = text_enc(c)
        nu = distance(e, known_support)
        out[c] = dict(nu=nu,
                      risky=(margin_0[c] <= theta_m + lam * nu),
                      frontier=(nu >= NU_0))
    return out
```

### IP-123 QOVC

```python
def issue_qov(c, b, prof, margin_b, nu, alias_neighbors, theta_m, lam):
    delta = prof[b].delta
    if len(alias_neighbors(c)) > 0:
        return ('reject', 'alias',
                QOV(c, b, margin_b, delta, nu, alias_neighbors(c)))
    if margin_b < theta_m + lam * nu + delta:
        status = 'cloud' if nu < NU_REJECT else 'reject'
        return (status, 'insufficient_margin',
                QOV(c, b, margin_b, delta, nu, set()))
    return ('edge', 'ok', QOV(c, b, margin_b, delta, nu, set()))
```

### IP-124 QBA

```python
def allocate_bits(concepts, prof, margin_0, nu, theta_m, lam,
                  bits=(2, 4, 8, 16)):
    b_star = {}
    for c in concepts:
        need = margin_0[c] - theta_m - lam * nu[c]
        feasible = [b for b in bits if prof[b].delta <= need]
        b_star[c] = min(feasible) if feasible else None
    return b_star

def allocate_bits_clustered(concepts, prof, margin_0, nu, K, B_e):
    clusters = kmeans_by_margin(concepts, K)
    b_cluster = {k: allocate_bits(clusters[k], prof, margin_0, nu,
                                  theta_m, lam) for k in clusters}
    return b_cluster   # 在 sum(b) <= B_e 下最大化被 edge 认证的簇数
```

### IP-125 CVP

```python
def partition_vocabulary(V, qov, beta_c, beta_r):
    V_e = [c for c in V if qov[c].status == 'edge']
    V_c = [c for c in V if qov[c].status == 'cloud']
    V_r = [c for c in V if qov[c].status == 'reject']
    if len(V_c)/len(V) > beta_c or len(V_r)/len(V) > beta_r:
        return ('degrade', V_e, V_c, V_r)
    return ('ok', V_e, V_c, V_r)

def margin_preserving_qat(cloud_enc, edge_model, V_e, b, lam_m, lam_a, theta_m):
    # L = L_task + lam_m*mean(relu(theta_m - margin_b(c)))
    #              + lam_a*mean(||phi_b(c) - psi(phi_0(c))||^2)
    for c in V_e:
        anchor_b = edge_model.text(c)
        loss_m = relu(theta_m - margin_b(c)).mean()
        loss_a = norm(anchor_b - psi(cloud_enc.text(c))).pow(2).mean()
        loss = task_loss + lam_m * loss_m + lam_a * loss_a
        update(edge_model, loss)
    return edge_model
```

### IP-126 QJ

```python
def joint_quant_certificate(J, V, b_star, prof, margin_b, nu,
                            alias_graph, psi_err, budgets):
    qov = {c: issue_qov(c, b_star[c], prof, margin_b[c], nu[c],
                        lambda x: alias_graph.neighbors(x),
                        budgets.theta_m, budgets.lam) for c in V}
    status, V_e, V_c, V_r = partition_vocabulary(V, qov,
                                                 budgets.beta_c, budgets.beta_r)
    if status != 'ok':
        return ('reject', 'vocabulary_budget', V_r)
    if psi_err > budgets.Theta_psi:
        return ('reject', 'anchor_transfer', psi_err)
    if not J.deployable:
        return ('reject', 'action_robustness', J)
    return ('ok', QJ(J, qov, b_star, V_e, V_c, V_r, psi_err, evidence=()))
```

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| QSP | O(|D_cal|·|B|·d) | O(|B|) | 漂移上界覆盖实测，ECE 可校准 |
| OVF | O(|V|·|V_cal|·d) | O(|V|) | 新颖度估计可共形校准 |
| QOVC | O(|V|·d + |E_alias|) | O(|V|+|E_alias|) | margin 下界 sound，混叠不漏 |
| QBA | O(|V|·|B|) | O(|V|) | 比特-畸变单调，`Σb*(c)≤B_e` |
| CVP | O(|V| + |V_e|·d + QAT) | O(|V|+d) | `ψ` 有界，分区互斥完备 |
| QJ | O(QOVC + CVP) | O(|V|+|E_alias|) | 证书联动，降级可判定 |

**命题 55.1（闭集校准不足以证明开放前沿）**
若校准集支撑与 `∂V` 不相交，则仅依赖校准集 `ε_b` 的证书无法约束前沿 margin；必须引入前沿采样/共形校准与显式拒绝。

**命题 55.2（精度-词表预算守恒）**
固定 `B_e` 时，`Σ_{c∈V_e} b*(c) ≤ B_e`，故 `|V_e| ≤ B_e / b_min(θ_m,ν)`；开放词表扩张的溢出只能进入 `V_c` 或 `V_r`。这把开放词汇能力直接绑定到量化比特预算。

**正确性定理（Quantization-Aware Open-Vocabulary Soundness）**
假设第 54 轮 (A22)–(A28) 成立；**(A29)** 前沿畸变上界 `Δ_b^frontier` 由共形校准给出，覆盖概率 `≥1-α`；**(A30)** `ν̂(c) ≥ ν(c)-η_ν`；**(A31)** `P(τ_cloud≤τ_max)≥1-β_cloud` 且 `δ_ψ≤Θ_ψ`。
则对需要概念集 `C_T⊆V` 的任务：
```
P_success ≥ 1 - α - β_cloud - β_E - Σ_d(1-ρ_min(d))
              - |C_T ∩ V_r|/|C_T| - η_alias
```
关键：**边端只执行 QOV=edge 的词表**，**前沿词表由云端兜底**，**混叠概念显式拒绝**；证书不再把闭集量化曲线外推为开放域保证。

## 6. 本轮最大风险

**一句话**：量化-开放词汇联合证书把“模型能不能跑”升级为“哪些概念在何种比特下可被安全判定”，但其 soundness **根本依赖前沿 `∂V` 上的畸变校准与新颖度估计**；而开放前沿恰恰是校准数据最稀疏、margin 最小、量化混叠最易发生的地方——一旦把闭集量化曲线外推为开放词汇保证，证书会在未见概念上“假 sound”，因此必须以 **共形前沿校准 + 混叠显式拒绝 + 云端兜底** 三重护栏，宁可把新概念判为不可自动执行，也不发一张覆盖未知的证书。
