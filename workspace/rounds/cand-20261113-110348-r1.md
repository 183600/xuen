# 第 67 轮（承接第 66 轮「RAS 意图闭环」IP-224~233；灵感循环第 1 轮；本轮灵感：「机械臂抓取」×「无刷电机」）

> 第 66 轮 RAS 把闭环从「故障响应」推进到「意图感知」，用面部表情捕获人的风险态度。但 RAS 仍停留在**任务层/社会层**：它知道「谁可能害怕」，却不知道「**物体是否还在手里**」。真正的抓取闭环发生在**接触层**——在毫秒尺度上，一次抓取要穿过 `自由→接触→稳定握持→微滑→宏观滑移→掉落` 的相变；而这个相变在视觉与关节编码器上几乎不可见，却会在**无刷电机的相电流与反电动势里留下高频指纹**。
>
> 本轮核心命题：
>
> **把「无刷电机」从纯执行器升级为「内生触觉传感器」：利用其相电流、反电动势与齿槽转矩指纹，在接触层估计抓取状态与滑移前兆，并纳入 VISTA/RAS 的认证闭环，构成「抓取-机体电机闭环（GEM: Grasp-Embodied Motor closure）」。**
>
> GEM 问的不是「该不该抓」，而是「**此刻还抓得住吗；电机自己知不知道自己抓得住**」。

## 0. 直觉与动机

**灵感 1（机械臂抓取 → 接触层相变，而非轨迹层插值）**
直觉：抓取不是一个"把末端执行器移动到物体上"的轨迹问题，而是一个**接触相变问题**。夹爪闭合的瞬间，系统从"位置控制"切到"力/阻抗控制"；随后在 `G2 稳定握持` 内部还藏着一个肉眼不可见的 `G3 微滑` 阶段。微滑阶段物体尚未掉落，但接触已从静摩擦转入局部动摩擦，此时**夹持力矩会出现 50~300Hz 的微小扭转振荡**。这正好落在无刷电机的电气带宽内，却低于大多数商用指尖触觉传感器的采样带宽。抓取安全的真正前哨，不在视觉，也不在力传感器，而在电机。

**灵感 2（无刷电机 → 一台自带编码的力/触觉传感器）**
直觉：无刷电机的电磁转矩与交轴电流近似成正比：`τ_m ≈ k_t·i_q`；而齿槽转矩 `τ_cog(θ_e)` 是**转子电角度的确定性周期函数**，与负载无关。把这两件事放在一起，就有了一个"双通道观测"：
- **通道 A（角同步）**：齿槽/换相纹波，锁定在 `θ_e` 上，反映**电机自身健康**（退磁、相损、编码器偏置、温漂）；
- **通道 B（非角同步）**：负载与接触对电流的调制，不锁定在电角度上，反映**外部抓取**（接触刚度、法向力、滑移）。
于是，无刷电机天然具备**把"我自己的病"与"外部世界的力"分离**的潜力。这是一个比"再装一个力传感器"更优雅的物理事实：执行器自身就是传感器，且带宽高一个数量级。

**灵感 3（抓取-电机联合推断 → 自遮蔽问题）**
直觉：但上述分离有一个致命的自我指涉：**同一个电流通道既是传感器，又可能是故障源**。若电机缓慢退磁、绕组温升导致 `R_s` 漂移，或编码器零点偏置，这些变化**也**是角同步的，会被错误的基线与"健康"吸收。此时系统会自信地把"外部滑移"读成"电机漂移"，或把"电机退化"读成"抓取稳定"。这不是普通的噪声问题，而是**自遮蔽（self-occlusion）**：观测装置与被观测对象共享同一物理通道时，可辨识性会在某个流形上坍缩。必须显式地把"可分离性"做成一个可计算的判据，而不是默认成立。

**灵感 4（合流 → GEM 六层）**
GEM 沿用 VISTA/RAS 的时序骨架，但把"意图"落到"接触"：
1. **MCS Motor Current Sensing**：20kHz 相电流 + 转子角度 + 母线电压，构成电机-接触观测量；
2. **ASA Angle-Synchronous Analysis**：角同步平均提取齿槽指纹 `Ī_q(θ_e)`，残差 `r_t` 交给外部负载；
3. **GHI Grasp Hypothesis Inference**：在 `G={G0..G5}` 与电机故障集 `F={F0..F4}` 上做联合后验；
4. **SPC Slip Precursor Classifier**：对残差做带通/短时谱，捕捉微滑前兆，给出**超前于力下降**的告警；
5. **MFC Motor Fault Classifier**：用角锁指数 `κ_G` 与反电动势常数漂移分离滑移与电机故障；
6. **GCA/GCC/MTC**：抓取认证权限（力上限 `F*_max` + 认证前缀 `k*_G`）、抓取闭环控制、抓取-电机证书 `J_GEM`。

**灵感 5（对既有组件的升级）**
- **ACH-RAS → ACH-G**：动作块中加入"夹持块"，块边界由 `G2→G3` 相变触发，而非固定时间；
- **EFS → GFS（Grasp-Fault Synthesis）**：在联合后验里新增抓取状态与电机故障两个维度；
- **C-RAS → C-GCC**：认证前缀 `k*_G = min(k_RAS, k_slip, m_G)`，`k_slip` 由预测的滑移裕度违约时刻给出；
- **J_RAS → J_GEM**：证书新增 `cogging_hash、k̂_e、motor_health、M̂_s、K̂_c、grasp_post`；
- **AIC-RAS → AIC-GEM**：干扰集新增 `ℰ_thermal、ℰ_cogging_drift、ℰ_low_speed`（低速反电动势不可观测）。

## 1. 形式化定义（增量：定义 245–256）

- **定义 245（GEM 总览）**：`GEM = (MCS, ASA, GHI, SPC, MFC, GCA, GCC, MTC)`。定位：把 RAS 的「意图闭环」下沉为「接触闭环」。不变式：20kHz 采样、角同步平均与滑移前兆在实时流完成；抓取-电机联合后验、认证、证书构建在语义流完成；实时流零学习写操作，只允许查表与阈值早停。
- **定义 246（电机-接触观测量）**：`m_t = (i_d, i_q, v_dc, θ_e, ω, T_w) ∈ ℝ^6`，采样率 `f_s = 20 kHz`；其中 `i_d/i_q` 为 Park 变换后的交直轴电流，`θ_e` 为电角度，`T_w` 为绕组温度估计。
- **定义 247（电磁转矩分解）**：
  ```
  τ_m(t) = k_t(θ_e, T_w)·i_q(t) + τ_cog(θ_e) + τ_rip(θ_e, i) + η_t
  τ_ext(t) = τ_m(t) - J·θ̈ - B·ω - τ_f(ω) - τ_g(q)
  ```
  `τ_ext` 为外部接触/负载力矩，`τ_g` 为重力项，`η_t` 为未建模项。
- **定义 248（角同步平均与齿槽指纹）**：以核 `K_h` 在电角度上做角同步平均
  ```
  Ī_q(θ) = Σ_n K_h(θ - θ_e(t_n))·i_q(t_n) / Σ_n K_h(θ - θ_e(t_n))
  r_t    = i_q(t) - Ī_q(θ_e(t))
  ```
  `Ī_q` 的量化哈希 `h_cog = H(Ī_q)` 称为**齿槽指纹**；`r_t` 为外部负载残差。
- **定义 249（接触刚度与抓取状态假设集）**：接触刚度 `K_c = -∂τ_ext/∂θ`；抓取状态
  ```
  G = {G0 自由, G1 接触, G2 稳定握持, G3 微滑, G4 宏观滑移, G5 掉落}
  ```
  电机故障集 `F = {F0 健康, F1 退磁, F2 相损, F3 编码器偏置, F4 齿槽漂移}`。
- **定义 250（滑移前兆信号）**：对残差导数做接触共振带 `[f_c-Δ, f_c+Δ]`（典型 50~300 Hz）带通：
  ```
  s_t = || BPF_{[f_c-Δ, f_c+Δ]}( d r_t / dt ) ||_2
  ```
  当 `s_t > τ_s` 且 `G2` 后验占优时，判为 `G3`。滑移裕度 `M_s = μ̂·F_n - F_t`，`F_n/F_t` 由 `τ_ext` 与夹爪传动比估计；`Q_g = M_s / (||F_t|| + ε)`。
- **定义 251（抓取-电机联合后验）**：
  ```
  P(G, F | m_{t-k:t}, θ) ∝ p(m | G, F)·p(θ | F3)·P(G | G_{t-1})·P(F)
  ```
  转移先验 `P(G|G_{t-1})` 只允许相邻状态跳转，禁止 `G2→G5` 直接跳变（必须经过 `G3/G4`），以此抑制"稳定→掉落"的误报。
- **定义 252（角锁分离算子与可辨识条件）**：对残差做电角度阶次投影
  ```
  Λ_m = |(1/T)·∫_0^T r_t·e^{-j m θ_e(t)} dt|
  Λ_int = Σ_{m∈M_cog} Λ_m ,   Λ_ext = Σ_{m∉M_cog} Λ_m
  κ_G = Λ_ext / (Λ_int + ε)
  ```
  `M_cog` 为槽极配合决定的齿槽/换相阶次集合。**可分离判据**：`κ_G ≥ κ_0` 且 `cond_ω = R_s|i_q|/(k_e|ω|+ε_R) ≤ c_0` 时，才允许把 `r_t` 归因为外部接触；否则强制进入"低可观测"分支。
- **定义 253（抓取认证权限）**：认证力上限与前缀
  ```
  F*_max = max{ F : P(G4 ∪ G5 | m_{t-k:t}, F) ≤ ε_g
                    ∧ τ_m(F) ≤ τ_max ∧ M̂_s(F) ≥ M_min }
  k*_G  = min(k_RAS, k_slip, m_G)
  ```
  其中 `k_slip` 为预测滑移裕度首次违约前的步数，`m_G` 为齿槽指纹有效视界。
- **定义 254（抓取闭环控制律）**：
  ```
  F_cmd ← clip( F_cmd + η(M_min - M̂_s)
                    - κ_s·1[s_t > τ_s] - κ_d·max(0, ds_t/dt),
                F_min, F*_max )
  ```
  `η/κ_s/κ_d` 为标定增益；`F*_max` 每 `k*_G` 步重认证一次。
- **定义 255（J_GEM 抓取-电机证书）**：
  ```
  J_GEM = (J_RAS, h_cog, k̂_e, T_w, motor_health, M̂_s, K̂_c, grasp_post, aic_gem_ver)
  ```
  `Valid ⇔ Valid(J_RAS) ∧ motor_health = F0 ∧ M̂_s ≥ M_min ∧ κ_G ≥ κ_0`；否则降级为"仅位置保持 + 减速停抓"。
- **定义 256（共因故障与自遮蔽判据）**：若电机内在漂移流形 `ℳ_F = span{∂τ_cog/∂T, ∂τ_cog/∂k_e, ∂τ_cog/∂θ_bias}` 与齿槽标定基 `C(θ)` 的并集秩亏，则称系统处于**自遮蔽态**：存在非零方向 `(δτ_ext, δτ_cog)` 使 `(m_t, θ_t)` 边缘分布完全相同。此时 `κ_G` 不可信，证书必须置为 `unobservable`，而非 `F0`。

# MCS + ASA：把无刷电机变成"角同步触觉"
class MotorContactSensor:
    def __init__(self, fs=20000, f_slip=(50, 300), tau_s=0.15):
        self.fs, self.f_slip, self.tau_s = fs, f_slip, tau_s
        self.Iq_bar = {}                      # 齿槽指纹查表
        self.h_cog = None

    def observe(self, phase_curr, theta_e, vdc, temp):
        idq = park(phase_curr, theta_e)
        iq, id_ = idq[1], idq[0]
        Iq_base = self.Iq_bar.get(bin_theta(theta_e), 0.0)
        r = iq - Iq_base                   # 外部负载残差
        s = bandpass_energy(derivative(r), self.f_slip, self.fs)
        return {'iq': iq, 'id': id_, 'theta_e': theta_e,
                'vdc': vdc, 'temp': temp, 'residual': r, 'slip': s}

    def calibrate_cogging(self, sweeps):
        acc = defaultdict(list)
        for phase_curr, theta_e in sweeps:          # 自由空间、无接触
            iq = park(phase_curr, theta_e)[1]
            acc[bin_theta(theta_e)].append(iq)
        self.Iq_bar = {k: mean(v) for k, v in acc.items()}
        self.h_cog = stable_hash(quantize(self.Iq_bar))


# ASA 分离：滑移 vs 电机故障
class AngleSynchronousSeparator:
    def __init__(self, M_cog, kappa0=2.0, c0=8.0):
        self.M_cog, self.kappa0, self.c0 = M_cog, kappa0, c0

    def separate(self, residual, theta_e, Rs, iq, ke, omega):
        orders = fft_order_projection(residual, theta_e)
        L_int = sum(abs(orders.get(m, 0.0)) for m in self.M_cog)
        L_ext = sum(abs(v) for m, v in orders.items() if m not in self.M_cog)
        kappa = L_ext / (L_int + 1e-9)
        cond_w = Rs * abs(iq) / (ke * abs(omega) + 1e-6)
        separable = (kappa >= self.kappa0) and (cond_w <= self.c0)
        return {'kappa_G': kappa, 'cond_w': cond_w,
                'separable': separable, 'locked': L_int, 'free': L_ext}


# GHI + MFC：抓取状态与电机健康联合推断
class GraspMotorInference:
    G_PRIOR = {'G0': .1, 'G1': .15, 'G2': .45, 'G3': .15, 'G4': .1, 'G5': .05}
    F_PRIOR = {'F0': .9, 'F1': .03, 'F2': .02, 'F3': .03, 'F4': .02}

    def posterior(self, obs, sep, prev_G='G2'):
        post = {}
        for g, pg in self.G_PRIOR.items():
            if not self._adjacent(prev_G, g):
                pg *= 0.05
            for f, pf in self.F_PRIOR.items():
                if not sep['separable'] and f != 'F0':
                    pf = max(pf, 0.25)      # 不可分离时不许默认健康
                post[(g, f)] = self._lik(obs, g, f, sep) * pg * pf
        return normalize(post)

    def _lik(self, obs, g, f, sep):
        l = 1.0
        if g == 'G3': l *= gauss(obs['slip'], 0.6, 0.15)      # 前兆能量高
        if g in ('G4', 'G5'): l *= gauss(obs['slip'], 1.2, 0.3)
        if g == 'G2': l *= gauss(obs['slip'], 0.1, 0.08)
        if f == 'F1': l *= 1.0 + 2.0 * abs(sep['locked'] - sep.get('locked0', 0))
        if f == 'F3': l *= 1.0 + 2.0 * abs(obs.get('encoder_drift', 0))
        if not sep['separable']: l *= 0.5
        return max(l, 1e-6)

    def _adjacent(self, a, b):
        order = ['G0', 'G1', 'G2', 'G3', 'G4', 'G5']
        return abs(order.index(a) - order.index(b)) <= 1


# GCA + GCC：认证力上限与滑移闭环
class GraspCertifiedAuthority:
    def __init__(self, mu, M_min=0.2, eps_g=1e-3, m_G=5):
        self.mu, self.M_min, self.eps_g, self.m_G = mu, M_min, eps_g, m_G

    def certify(self, post, k_ras, F_limits):
        risk = sum(p for (g, f), p in post.items() if g in ('G4', 'G5'))
        okF = [F for F in F_limits if self._slip_ok(F) and
               self._motor_ok(post, F)]
        F_max = max(okF) if (okF and risk <= self.eps_g) else min(F_limits)
        k_slip = self._time_to_violation(post)
        k_g = min(k_ras, k_slip, self.m_G)
        return {'F_max': F_max, 'k_g': k_g, 'slip_risk': risk}

    def _slip_ok(self, F):
        return self.mu * F * normal_ratio() - tangential_load() >= self.M_min

    def _motor_ok(self, post, F):
        return sum(p for (g, f), p in post.items() if f == 'F0') >= 0.95

    def _time_to_violation(self, post):
        p3 = sum(p for (g, f), p in post.items() if g == 'G3')
        return max(1, int(self.m_G * (1.0 - p3)))


def GEM_round(M, obs):
    # 1) 既有 VISTA/RAS 前向
    x_prime = M.lsf.fuse(M.usr.fuse(*obs.vis))
    face_gate = M.er.recognize(obs.img)

    # 2) MCS：20kHz 电机-接触观测
    m = M.mcs.observe(obs.phase_curr, obs.theta_e, obs.vdc, obs.temp)

    # 3) ASA：角同步分离
    sep = M.asa.separate(m['residual'], m['theta_e'],
                         obs.Rs, m['iq'], M.ke_hat, obs.omega)

    # 4) GHI/MFC：抓取-电机联合后验
    post = M.ghi.posterior(m, sep, M.prev_G)
    M.prev_G = argmax_g(post)

    # 5) GCA：认证力上限 + 前缀
    auth = M.gca.certify(post, M.ras.last_k, M.F_limits)

    # 6) GCC：滑移闭环
    F_cmd = M.gcc.update(m['slip'], auth['F_max'], M.finger_target)

    # 7) MTC：证书
    J = M.mtc.build(M.ras.last_J, M.mcs.h_cog, M.ke_hat, m['temp'],
                    post, sep, auth)
    return auth['k_g'], F_cmd, post, J

## 3. 推导

**引理 11（角同步平均的残差误差界）**
设每角度分箱样本数为 `N`，电流噪声方差 `σ²`，齿槽基频 Lipschitz 常数 `L`，分箱宽度 `Δθ`。则
```
E||Ī_q - I_q*||² ≤ σ²/N + L²Δθ²/12
```
即齿槽指纹的收敛误差由"样本量"与"角分辨率"两项共同决定；取 `N=200/箱、Δθ=0.5°` 时，残差误差可压到 0.02 A 量级，低于微滑前兆的 0.05 A 门限。

**引理 12（微滑前兆的超前量）**
设微滑在接触共振 `f_c` 处激发能量比 `ρ` 的扭转振荡，品质因数 `Q`，检测门限 `τ_s`。在 `ρ > τ_s` 时，从微滑起始到宏观力下降的期望超前量满足
```
E[Δt] ≥ (Q / (π·f_c)) · ln(ρ / τ_s)
```
物理含义：`f_c` 越高、`Q` 越大，电机电流越早"听见"滑移；这正是把检测放到电气域而非力域的收益——同一事件在电机端比在力传感器端提前数十毫秒。

**定理 11（GEM 抓取安全一致性）**
在 (A) `κ_G ≥ κ_0` 且 `cond_ω ≤ c_0`（可分离）；(B) `M̂_s ≥ M_min`；(C) 齿槽标定残差 ≤ `δ_cal` 下，若执行 `F_cmd ≤ F*_max`，则
```
P(掉落) ≤ α_g + δ_cal + δ_sep
```
且一旦 `P(G3) > 0.5`，控制器在 `k*_G` 步内把 `F_cmd` 单调抬向 `F*_max`，期间力不越上限。证明要点：`G2→G4/G5` 被转移先验禁止直接跳变，故掉落必须经过 `G3`；`G3` 一旦出现，`SPC` 的告警与 `GCC` 的增力项在 `k_slip` 内闭合。

**定理 12（自遮蔽的不可辨识性）**
设电机内在漂移方向 `v = (∂τ_cog/∂T, ∂τ_cog/∂k_e)` 落在角锁子空间 `span(C(θ))` 内，且标定基 `C(θ)` 不含温度/`k_e` 维度。则存在 `ε>0`，使得对任意 `|δ|<ε`，观测分布满足
```
p(m_t, θ_t | τ_ext + δτ_ext, F0) = p(m_t, θ_t | τ_ext, F1)
```
即在 `(m_t, θ_t)` 上滑移与退磁**严格不可分**，`κ_G` 退化到 `1` 附近的伪"可分离"区，Fisher 信息矩阵在 `(δτ_ext, δτ_cog)` 方向秩亏。**推论**：必须显式引入独立温度通道或在线辨识 `k̂_e`，把 `C(θ)` 扩成 `[C(θ), ∂C/∂T, ∂C/∂k_e]` 并验证满秩，否则 `J_GEM` 不得签发 `F0`。

**定理 13（低速可观测性下界）**
当 `|ω| → 0`，反电动势 `e = k_e·ω → 0`，转矩估计退化为 `τ̂ = k_t·i_q`，其相对误差由 `R_s(T)` 主导：
```
∂τ̂/τ̂ ≈ ∂k_t/k_t + ∂i_q/i_q ≈ -α_T·ΔT / (1 + k_eω/(R_s i_q))
```
故存在临界转速 `ω_c = R_s i_q α_T ΔT / (k_e·ε_τ)`；`|ω| < ω_c` 时证书必须叠加 `cond_ω` 惩罚或注入高频抖动激励（HFI），把"静止握持"这一最关键的抓取阶段从不可观测区拉回可观测区。

## 6. 本轮最大风险

**一句话**：GEM 把无刷电机的**角同步分量**当作"电机自身健康基线"，但退磁、温漂与编码器偏置同样角同步，可能被齿槽指纹吸收，导致系统把真实的外部滑移误判为电机漂移、或把电机退化误判为抓取稳定——**自遮蔽**使 `J_GEM` 在电机缓慢退化时系统性偏乐观，这正是整套理论唯一不可回避的物理前提：**角同步分量只属于电机、非角同步分量只属于接触**。

**次级风险与缓解**：
1. **自遮蔽**：新增独立温度通道与在线 `k̂_e` 辨识，验证 `[C(θ), ∂C/∂T, ∂C/∂k_e]` 满秩；秩亏即置 `unobservable`；
2. **低速失效**：静止握持时反电动势消失 → 用 `cond_ω` 惩罚 + 高频抖动激励（HFI）或直接降额认证；
3. **标定成本**：每台电机需自由空间往返标定 → 用出厂齿槽指纹 + 在线增量更新，把 `h_cog` 纳入证书可追溯；
4. **机械共振污染**：夹爪/减速器的共振会伪造 `s_t` → 用双通道（电流 + 关节编码器高频分量）互相关，剔除纯机械模态；
5. **对抗注入**：恶意电流扰动可伪造"稳定" → 证书绑定 `h_cog` 与温度链，异常电流纹波触发 `F2` 相损假设。

## 2. 形式化定义（完整版）

**定义 245（GEM 总览）** GEM 把 RAS 的「意图闭环」下沉为「接触闭环」：
```
GEM = (MCS, ASA, GHI, SPC, MFC, GCA, GCC, MTC)
```
不变式：20kHz 采样、角同步平均、滑移前兆在实时流完成；联合后验、认证、证书构建在语义流完成；实时流零学习写操作，只允许查表、阈值早停与力裁剪。

**定义 246（电机-接触观测量）** `m_t = (i_d, i_q, v_dc, θ_e, ω, T_w) ∈ ℝ^6`，`f_s = 20 kHz`；`i_d/i_q` 为 Park 变换后的直/交轴电流，`T_w` 为绕组温度估计。

**定义 247（电磁转矩分解）**
```
τ_m(t) = k_t(θ_e, T_w)·i_q(t) + τ_cog(θ_e) + τ_rip(θ_e, i) + η_t
τ_ext(t) = τ_m(t) - J·θ̈ - B·ω - τ_f(ω) - τ_g(q)
```
`τ_cog` 为槽极配合决定的齿槽转矩（电角度周期函数，与负载无关），`τ_ext` 为外部接触/负载力矩。

**定义 248（角同步平均与齿槽指纹）**
```
Ī_q(θ) = Σ_n K_h(θ - θ_e(t_n))·i_q(t_n) / Σ_n K_h(θ - θ_e(t_n))
r_t    = i_q(t) - Ī_q(θ_e(t))
h_cog  = H(quantize(Ī_q))
```
`Ī_q` 在自由空间、无接触往返中学习；`r_t` 为不能由电机自身解释的外部负载残差。

**定义 249（接触刚度与抓取状态假设集）**
```
K_c = -∂τ_ext/∂θ
G   = {G0 自由, G1 接触, G2 稳定握持, G3 微滑, G4 宏观滑移, G5 掉落}
F   = {F0 健康, F1 退磁, F2 相损, F3 编码器偏置, F4 齿槽漂移}
```
`K_c` 由 `τ_ext` 对关节角的局部斜率估计；`G` 只允许相邻转移，禁止 `G2→G5` 直跳。

**定义 250（滑移前兆与抓取质量）**
```
s_t = || BPF_{[f_c-Δ, f_c+Δ]}( d r_t / dt ) ||_2
M_s = μ̂·F_n - F_t ,   Q_g = M_s / (||F_t|| + ε)
```
`f_c` 为接触扭转共振频率（典型 50~300Hz）；`s_t > τ_s` 且 `G2` 占优时判 `G3`。

**定义 251（抓取-电机联合后验）**
```
P(G, F | m_{t-k:t}, θ) ∝ p(m | G, F)·p(θ | F3)·P(G | G_{t-1})·P(F)
```
`P(G|G_{t-1})` 仅允许相邻状态，`G2→G3` 与 `G3→G4` 转移概率高于 `G2→G4`，以此把"稳定→掉落"的瞬跳抑制为不可能事件。

**定义 252（角锁分离算子与可辨识条件）**
```
Λ_m   = |(1/T)∫_0^T r_t·e^{-j m θ_e(t)} dt|
Λ_int = Σ_{m∈M_cog} Λ_m ,   Λ_ext = Σ_{m∉M_cog} Λ_m
κ_G   = Λ_ext / (Λ_int + ε)
```
可分离判据：
```
κ_G ≥ κ_0  ∧  cond_ω = R_s|i_q|/(k_e|ω|+ε_R) ≤ c_0
```
不满足时，`r_t` 不得归因为外部接触，必须进入"低可观测"分支并降额。

**定义 253（抓取认证权限）**
```
F*_max = max{ F : P(G4 ∪ G5 | m_{t-k:t}, F) ≤ ε_g
                   ∧ τ_m(F) ≤ τ_max ∧ M̂_s(F) ≥ M_min }
k*_G  = min(k_RAS, k_slip, m_G)
```
`k_slip` 为预测滑移裕度首次违约前的步数，`m_G` 为齿槽指纹有效视界。

**定义 254（抓取闭环控制律）**
```
F_cmd ← clip( F_cmd + η(M_min - M̂_s)
                   - κ_s·1[s_t > τ_s] - κ_d·max(0, ds_t/dt),
               F_min, F*_max )
```
`F*_max` 每 `k*_G` 步重认证一次；重认证失败立即切换到"位置保持 + 减速停抓"。

**定义 255（J_GEM 抓取-电机证书）**
```
J_GEM = (J_RAS, h_cog, k̂_e, T_w, motor_health, M̂_s, K̂_c, grasp_post, aic_gem_ver)
```
`Valid ⇔ Valid(J_RAS) ∧ motor_health = F0 ∧ M̂_s ≥ M_min ∧ κ_G ≥ κ_0`；否则证书降级为 `unobservable`，不得签发 `F0`。

**定义 256（共因故障与自遮蔽判据）** 令电机内在漂移流形
```
ℳ_F = span{ ∂τ_cog/∂T, ∂τ_cog/∂k_e, ∂τ_cog/∂θ_bias }
```
若 `rank([C(θ), ℳ_F]) < dim(C(θ)) + dim(ℳ_F)`，则系统处于**自遮蔽态**：存在非零 `(δτ_ext, δτ_cog)` 使 `(m_t, θ_t)` 的观测分布完全相同。此时 `κ_G` 不可信，`motor_health` 必须置 `unobservable`。

class AngleSynchronousSeparator:
    def __init__(self, M_cog, kappa0=2.0, c0=8.0):
        self.M_cog, self.kappa0, self.c0 = M_cog, kappa0, c0

    def separate(self, residual, theta_e, Rs, iq, ke, omega):
        orders = fft_order_projection(residual, theta_e)
        L_int = sum(abs(orders.get(m, 0.0)) for m in self.M_cog)
        L_ext = sum(abs(v) for m, v in orders.items() if m not in self.M_cog)
        kappa = L_ext / (L_int + 1e-9)
        cond_w = Rs * abs(iq) / (ke * abs(omega) + 1e-6)
        return {'kappa_G': kappa, 'cond_w': cond_w, 'locked': L_int,
                'free': L_ext,
                'separable': kappa >= self.kappa0 and cond_w <= self.c0}

class GraspMotorInference:
    G_PRIOR = {'G0': .10, 'G1': .15, 'G2': .45, 'G3': .15, 'G4': .10, 'G5': .05}
    F_PRIOR = {'F0': .90, 'F1': .03, 'F2': .02, 'F3': .03, 'F4': .02}

    def posterior(self, obs, sep, prev_G='G2'):
        post = {}
        for g, pg in self.G_PRIOR.items():
            if not self._adjacent(prev_G, g):
                pg *= 0.05
            for f, pf in self.F_PRIOR.items():
                if not sep['separable'] and f != 'F0':
                    pf = max(pf, 0.25)          # 不可分离时禁止默认健康
                post[(g, f)] = self._lik(obs, g, f, sep) * pg * pf
        return normalize(post)

    def _lik(self, obs, g, f, sep):
        l = 1.0
        if g == 'G3': l *= gauss(obs['slip'], 0.6, 0.15)
        if g in ('G4', 'G5'): l *= gauss(obs['slip'], 1.2, 0.3)
        if g == 'G2': l *= gauss(obs['slip'], 0.1, 0.08)
        if f == 'F1': l *= 1.0 + 2.0 * abs(sep['locked'] - sep.get('locked0', 0.0))
        if f == 'F3': l *= 1.0 + 2.0 * abs(obs.get('encoder_drift', 0.0))
        if not sep['separable']: l *= 0.5
        return max(l, 1e-6)

    def _adjacent(self, a, b):
        order = ['G0', 'G1', 'G2', 'G3', 'G4', 'G5']
        return abs(order.index(a) - order.index(b)) <= 1

# IP-241 GCA：认证力上限与前缀
class GraspCertifiedAuthority:
    def __init__(self, mu, M_min=0.2, eps_g=1e-3, m_G=5):
        self.mu, self.M_min, self.eps_g, self.m_G = mu, M_min, eps_g, m_G

    def certify(self, post, k_ras, F_limits):
        risk = sum(p for (g, f), p in post.items() if g in ('G4', 'G5'))
        okF = [F for F in F_limits if self._slip_ok(F) and self._motor_ok(post, F)]
        F_max = max(okF) if (okF and risk <= self.eps_g) else min(F_limits)
        k_slip = max(1, int(self.m_G * (1.0 - self._p3(post))))
        return {'F_max': F_max, 'k_g': min(k_ras, k_slip, self.m_G),
                'slip_risk': risk, 'unobservable': not self._separable(post)}

    def _slip_ok(self, F):
        return self.mu * F * normal_ratio() - tangential_load() >= self.M_min

    def _motor_ok(self, post, F):
        return sum(p for (g, f), p in post.items() if f == 'F0') >= 0.95

    def _p3(self, post):
        return sum(p for (g, f), p in post.items() if g == 'G3')

    def _separable(self, post):
        return sum(p for (g, f), p in post.items() if f != 'F0') < 0.5


# IP-242 GCC：滑移闭环
def grasp_closure_step(F_cmd, M_s_hat, s_t, ds_dt, F_max, eta=1.0,
                       kappa_s=0.5, kappa_d=0.1, F_min=0.0, M_min=0.2):
    F = F_cmd + eta * (M_min - M_s_hat)
    F -= kappa_s * (1.0 if s_t > TAU_S else 0.0) + kappa_d * max(0.0, ds_dt)
    return min(max(F, F_min), F_max)


# IP-243/244 GEM 闭环
def GEM_round(M, obs):
    x_prime = M.lsf.fuse(M.usr.fuse(*obs.vis))
    face_gate = M.er.recognize(obs.img)          # RAS 仍在线

    m = M.mcs.observe(obs.phase_curr, obs.theta_e, obs.vdc, obs.temp)
    sep = M.asa.separate(m['residual'], m['theta_e'],
                         obs.Rs, m['iq'], M.ke_hat, obs.omega)
    post = M.ghi.posterior(m, sep, M.prev_G)
    M.prev_G = argmax_g(post)

    auth = M.gca.certify(post, M.ras.last_k, M.F_limits)
    F_cmd = grasp_closure_step(M.F_cmd, M.estimate_slip_margin(post),
                               m['slip'], derive(m['slip']), auth['F_max'])
    M.F_cmd = F_cmd

    J = M.mtc.build(M.ras.last_J, M.mcs.h_cog, M.ke_hat, m['temp'],
                    post, sep, auth)
    return auth['k_g'], F_cmd, post, J

## 4. 推导

**引理 11（角同步平均残差误差界）** 设每角度分箱样本数 `N`，电流噪声方差 `σ²`，齿槽基频 Lipschitz 常数 `L`，分箱宽度 `Δθ`，则
```
E||Ī_q - I_q*||² ≤ σ²/N + L²Δθ²/12
```
取 `N = 200/箱、Δθ = 0.5°` 时误差可压至 0.02A 量级，低于微滑前兆 0.05A 门限。

**引理 12（微滑前兆超前量）** 设微滑在接触共振 `f_c` 处激发能量比 `ρ`、品质因数 `Q` 的扭转振荡，检测门限 `τ_s`，则自微滑起始到宏观力下降的期望超前量
```
E[Δt] ≥ (Q / (π·f_c)) · ln(ρ / τ_s)
```
同一物理事件在电机电流端比在力传感器端提前数十毫秒，这正是把检测放到电气域的收益。

**定理 11（GEM 抓取安全一致性）** 在 (A) `κ_G ≥ κ_0 ∧ cond_ω ≤ c_0`；(B) `M̂_s ≥ M_min`；(C) 齿槽标定残差 ≤ `δ_cal` 下，若执行 `F_cmd ≤ F*_max`，则
```
P(掉落) ≤ α_g + δ_cal + δ_sep
```
且 `P(G3) > 0.5` 后，控制器在 `k*_G` 步内单调增力至 `F*_max`，期间不越力上限。证明要点：转移先验禁止 `G2→G5` 直跳，掉落必经 `G3`；`SPC` 告警与 `GCC` 增力项在 `k_slip` 内闭合。

**定理 12（自遮蔽不可辨识性）** 若电机内在漂移方向 `v = (∂τ_cog/∂T, ∂τ_cog/∂k_e)` 落在角锁子空间 `span(C(θ))` 且标定基不含温度/`k_e` 维度，则存在 `ε>0`，对任意 `|δ|<ε`：
```
p(m_t, θ_t | τ_ext + δτ_ext, F0) = p(m_t, θ_t | τ_ext, F1)
```
即滑移与退磁在 `(m_t, θ_t)` 上严格不可分，Fisher 信息矩阵在 `(δτ_ext, δτ_cog)` 方向秩亏。**推论**：必须引入独立温度通道或在线辨识 `k̂_e`，并验证 `[C(θ), ∂C/∂T, ∂C/∂k_e]` 满秩，否则 `J_GEM` 不得签发 `F0`。

**定理 13（低速可观测性下界）** 当 `|ω|→0`，反电动势 `e = k_eω→0`，转矩估计退化为 `τ̂ = k_t i_q`，相对误差由 `R_s(T)` 主导：
```
∂τ̂/τ̂ ≈ ∂k_t/k_t + ∂i_q/i_q ≈ -α_T ΔT / (1 + k_eω/(R_s i_q))
```
故存在临界转速 `ω_c = R_s i_q α_T ΔT / (k_e ε_τ)`；`|ω| < ω_c` 时证书须叠加 `cond_ω` 惩罚或注入高频抖动激励（HFI），把静止握持从不可观测区拉回可观测区。

## 7. 本轮最大风险

**一句话**：GEM 把无刷电机的**角同步分量**当作"电机自身健康基线"，但退磁、温漂与编码器偏置同样角同步，可能被齿槽指纹吸收，导致系统把真实的外部滑移误判为电机漂移、或把电机退化误判为抓取稳定——**自遮蔽**使 `J_GEM` 在电机缓慢退化时系统性偏乐观，这正是整套理论唯一不可回避的物理前提：**角同步分量只属于电机、非角同步分量只属于接触**。

**次级风险与缓解**：
1. **自遮蔽**：新增独立温度通道与在线 `k̂_e` 辨识，验证 `[C(θ), ∂C/∂T, ∂C/∂k_e]` 满秩；秩亏即置 `unobservable`；
2. **低速失效**：静止握持时反电动势消失 → 用 `cond_ω` 惩罚 + 高频抖动激励（HFI）或直接降额认证；
3. **标定成本**：每台电机需自由空间往返标定 → 出厂齿槽指纹 + 在线增量更新，`h_cog` 入证书可追溯；
4. **机械共振污染**：夹爪/减速器共振会伪造 `s_t` → 电流与关节编码器高频分量互相关，剔除纯机械模态；
5. **对抗注入**：恶意电流扰动可伪造"稳定" → 证书绑定 `h_cog` 与温度链，异常纹波触发 `F2` 相损假设。
