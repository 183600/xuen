# 第 1 轮（新灵感循环第 1 轮；本轮灵感：「意图识别」×「激光雷达」）

> **基线**：承接产物区第 3 轮 InstructGauge（IP-321–327；定义 432–447；引理 51–58；实验 E441–E456）。第 1/2 轮 MODGAUGE / LeanGauge / ToolGauge 骨架继续原样继承。
> 本轮纪律：**意图只选目标，不造能力；激光只量几何，不度人心**。两个灵感各沿一条轴升级，且任一环节不可用都必须一键退回：LiDAR 不可用 ⇒ 退回语言接地（InstructGauge）；意图不可辨识 ⇒ 弃权/澄清，绝不猜；InstructGauge 失效 ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE。

## 0. 直觉与动机

**灵感 1（意图识别 → 意图是反问题，不是分类标签）**
直觉：人说「把左边那个反光的修一下」时，「修什么」（目标）、「修到什么程度」（容差）、「先保安全还是先保效率」（偏好）、「愿意花多少」（预算）是四个不同的隐变量。语言和行为只是它们的**有噪投影**；从投影反推隐变量，是一个欠定反问题。把它当分类器训练，会在训练分布外自信地给出错误标签——这正是意图识别最危险的地方。严谨的接口因此不是 `ℓ → label`，而是 `ℓ → 后验候选集合 Ψ̂`，并显式回答「这组观测是否足以区分候选意图」。

**灵感 2（激光雷达 → 不是「更清楚的相机」，而是一把可主动控制的几何尺）**
直觉：LiDAR 的价值不在角分辨率，而在三件事：(i) 每个回波带绝对距离，**几何与外观解耦**；(ii) 扫描方向可编程，是**主动查询**而非被动曝光；(iii) 回波强度、多回波与「缺失回波」本身携带材质与遮挡信息（镜面、透明物体常直接消失）。这三点恰好是指代接地（「那个」）最需要的：一个指向手势定义一条射线，LiDAR 的深度与遮挡顺序把「射线穿过谁、先碰到谁」变成可测事件。但 LiDAR 也有自己的物理盲区——镜面、透明、雨雾、多机互扰——它会把「看不见」伪装成「不存在」。

**灵感 3（两者相乘 → 用主动激光去「照亮」意图盲区，而不是用更强的分类器去猜）**
直觉：把「意图不可辨识」定义为一个**意图盲区**：存在两个候选意图 ψ、ψ′，在当前扫描策略下产生几乎相同的观测分布。于是意图识别就变成一个**主动实验设计**问题：选下一束/下一组扫描，使 ψ 与 ψ′ 的观测分布分离（KL 上升）。这同时给出三件事：(a) 何时继续扫描；(b) 何时停下来问人（弃权）；(c) 何时拒绝执行（观测与语言矛盾）。更深一层的对称性是：LiDAR 照亮**物理**盲区，主动意图识别照亮**语义**盲区，两者共用同一套「可辨识性—信息增益—弃权」的形式化。**这就是本轮把两个词接在一起的地方：不是比喻，而是同一数学结构在不同对象上的两次实例化。**

再叠加一个双向性：机器人的扫描模式本身是**可被人观察**的；人从「机器人把激光指向哪里」推断机器人想修什么。于是意图识别变成双向的——机器人识别人意，人识别机器人意；当二者错位，人的纠正性指认就是最好的监督信号。这给出一条闭环，而不是单向分类。

## 1. 研究问题（本轮要回答什么）

- **Q1（可辨识性）**：在什么条件下，语言 + LiDAR 观测**足以**唯一确定意图？不可辨识时，正确行为是什么（弃权、主动扫描、还是澄清）？
- **Q2（主动性）**：主动扫描能把意图辨识所需样本量/时间降低多少？收益与「打扰人、眼安全、隐私」的代价如何权衡？
- **Q3（一致性与安全）**：当语言、几何、回执三方冲突时，系统能否**不静默覆盖**地暴露矛盾？推断出的意图是否可能扩权（造出新工具/新物理量）？
- **Q4（对抗与迁移）**：LiDAR 可被欺骗（回射器、注入、多径），意图可被操纵；哪些欺骗在物理层可检测，哪些原则上不可检测（诚实边界）？

## 2. 五条设计原则（雏形，正式化见产物区定义 448–463）

**P1 意图只选择，不创造（Intent Selects, Never Creates）**
推断出的意图 ψ 经能力闭包投影为指令 ι，`Plan(ψ) ⊆ Plan_ToolGauge`。语言/意图不能命名新工具、不能超出物理包线 `M_phys`。这是把第 3 轮定义 432 的能力闭包原样接到意图层：**意图推断最多选错目标，不能创造越权动作。**

**P2 不可辨识即弃权（Abstain on Unidentifiability）**
若候选意图在当前观测下的最大 KL 低于阈值 `ε_id`，输出候选集合 `Ψ̂` 与弃权标记，绝不塌缩成单一标签。弃权不是失败，而是可审计的正确行为；它把「我不知道你要什么」从隐性错误变成显式状态。

**P3 矛盾不静默（No Silent Override）**
语言指代与几何指代冲突时，输出**不一致证书**并要求澄清；系统不得自行选择「更可信」的一方。因为一旦允许静默选择，攻击者只需污染单一通道即可诱导错误归因。

**P4 扫描是受约束的实验（Constrained Active Sensing）**
扫描受眼安全（class-1、MPE、驻留上限）、隐私/打扰预算、机械可达与遮挡约束；信息增益必须减去这些代价。**激光不是免费的传感器，它是一次物理动作**，必须与工具动作共用同一套安全盾。

**P5 双向可读（Bidirectional Legibility）**
扫描模式要同时利于机器人辨识人、利于人辨识机器人；错位由人的纠正行为检测。只优化「机器人看懂人」会得到不可解释的扫描，只优化「人看懂机器人」会得到无信息的扫描——二者存在真实的权衡（引理 64）。

## 3. 与基线的接口（如何退化）

- 无 LiDAR / 点云质量不达标 / 回波证明失败 ⇒ 退回 InstructGauge 的语言接地 `Γ`，仅保留弃权阈值；
- 意图后验单峰且 KL 足够 ⇒ 退化为单一 `ι`，逐指令等价于 InstructGauge；
- 扫描预算为 0 / 触达眼安全边界 ⇒ 只做被动识别，不主动查询；
- 主动扫描不可用但语言可用 ⇒ 用语言先验 + 弃权，不猜；
- 意图推断请求越权能力 ⇒ `clamp_CC` 拒绝并回退默认 `ι₀`（= ToolGauge 目标）；
- InstructGauge 失效 ⇒ ToolGauge；ToolGauge 失效 ⇒ LeanGauge；LeanGauge 失效 ⇒ MODGAUGE 原样。

## 4. 预期贡献

1. 一个「意图 = 可辨识性受限的反问题」的口径，把意图识别从**分类置信度**改为**候选集合 + 弃权 + 决策风险**；
2. 一个主动 LiDAR 意图消歧器：以期望信息增益选扫描，并给出样本复杂度下界、次模近似保证与停止规则；
3. 一个语言—几何—回执三方**一致性证书**，保证矛盾不被静默覆盖，并明确其「共模错误」残余边界；
4. 一个把「意图盲区」与「物理盲区」统一到同一可辨识性框架的形式化，并严格证明 LiDAR=∅ 时退化为 InstructGauge；
5. 一条完整可证伪路径：E457–E472 覆盖可辨识性、指代接地、主动增益、矛盾检测、弃权校准、可读性、对抗注入与 50Hz 时序保全。

## 5. 本轮最大风险

**一句话**：LiDAR 的高几何精度会制造「我看清了位置，所以我看懂了意图」的错觉——而几何可辨识并不等于意图可辨识，主动扫描又可能被对抗性回波欺骗，最终把一次**自信但错误的意图归因**变成一串合法却错误的修复动作。

## 2. 形式化定义（要点）

**定义 448（意图隐变量与意图空间 Ψ）** 令
`ψ = (g_fam, θ_tol, π_pref, β_budget, ρ_ref)`，
分别表示目标族、容差要求、安全—效率偏好、预算与指代对象；取值受预注册类型系统约束：`g_fam ∈ G_onto`、`θ_tol ∈ Θ_tol`、`π_pref ∈ Π_pref`、`ρ_ref ∈ O_onto`。意图不是指令：指令 `ι` 是**一次措辞的规约**，意图 `ψ` 是其**潜在成因**；存在多对一映射 `ψ ↦ ι = Γ(ℓ)`，因此 `ι` 通常不足以反推唯一 `ψ`（别名现象）。意图识别即求 `q(ψ) = P(ψ | ℓ, z_{1:T}, g_{1:T}, D)`。

**定义 449（LiDAR 观测模型）** 单回波 `z = (r, φ, θ, I, n_echo, t, id)`；扫描序列的似然分解为
`P(z_{1:T} | ψ, g_{1:T}) = ∫ P(z_{1:T} | scene, pose_{1:T}, g_{1:T}) · P(pose_{1:T} | ψ) · P(scene) d(scene, pose)`。
关键：**LiDAR 不直接观测意图**，它观测的是意图的物理相关量——指向手势、头/身朝向、接近轨迹、驻留区域。`P(pose | ψ)` 是意图到可观测行为的桥梁，也是本方案最容易被误用的假设（见定义 453 与引理 63）。

**定义 450（扫描动作、代价与预算）** `g ∈ G_scan` 指定感兴趣区域、角分辨率、驻留时间与波束等级；`c(g) = c_time + c_energy + c_intrusion`；仅在 `Σ c(g_i) ≤ B_scan` 内允许主动扫描。扫描是**物理动作**，不是被动读取：它消耗时间、可能打扰人、并受人眼安全约束（定义 459）。

**定义 451（指向接地：射线、锥与指代分布）** 指向手势 `h(t)` 给出射线 `Ray(h)`；由关节/手部噪声 `σ_p` 展宽为锥 `Cone(h, σ_p)`。几何指代分布定义为
`R_LiDAR(o) ∝ ∫_{Cone(h,σ_p)} w(σ) · 1[o = FirstHit(ray(σ); scene)] dσ`，
其中 `FirstHit` 由 LiDAR 深度与遮挡顺序计算。语言指代分布 `R_ℓ(o) ∝ P(o | ℓ, ι)`。指向只能消除**横向**歧义到 `~ r·σ_p` 的尺度；沿射线的**深度**歧义由 LiDAR 首碰面消解；被遮挡物体需换视角（引理 63）。

**定义 452（意图后验与候选集合）**
`q(ψ) ∝ p₀(ψ) · P(ℓ | ψ) · P(z_{1:T} | ψ, g_{1:T})`；候选集合 `Ψ̂_ε = {ψ : q(ψ) ≥ ε_post}`。输出永远是 `(Ψ̂_ε, q)` 二元组而非单点标签；若 `|Ψ̂_ε| > 1`，同时输出弃权标记与需澄清的自由度。

**定义 453（意图可辨识性与等价类）** 称 `ψ` 与 `ψ′` 在扫描类 `G_scan` 下 `ε`-不可区分，记 `ψ ~_ε ψ′`，当且仅当
`sup_{g ∈ G_scan} D_KL( P(z|ψ,g) ‖ P(z|ψ′,g) ) < ε_id`。
等价类 `[ψ]_ε` 的类数 `N_ε` 就是当前传感能力下**最多可分辨的意图数**。若两个意图的物理相关量分布完全相同（例如两人以同样轨迹指向同一物体但想修不同缺陷），则任何扫描都无法分辨——这是**原则性不可辨识**，只能靠询问，不能靠更强的模型。

**定义 454（主动意图消歧 AID）**
`g* = argmax_{g ∈ G_scan, c(g) ≤ B_left, g ∈ G_safe} [ IG(g) − λ_c·c(g) − λ_r·R_act(Ψ̂ | g) ]`，
其中 `IG(g) = H(q) − E_{z~P(·|g)}[ H(q(·|z,g)) ]`。停止规则：若 `max_g IG(g) ≤ τ_stop`，停止扫描并转入弃权/澄清；若某次扫描的 `Attest(z)=0`，中止并告警。

**定义 455（意图盲区与登记表 IBR）** 意图盲区是一个对 `(ψ, ψ′, g_witness, t)`，满足 `ψ ~_ε ψ′`。登记表 `Δ` 记录所有此类对及其见证扫描。**决策相关性** `DR(ψ,ψ′) = 1[a*(ψ) ≠ a*(ψ′)]`，其中 `a*(·)` 是最优动作。只有 `DR=1` 的盲区才必须解决；`DR=0` 的盲区可安全忽略——这把「不可辨识」从全局恐慌收窄到「只解决影响动作的那部分」。

**定义 456（意图一致性证书 ICC）** 三方证据为语言指代 `R_ℓ`、几何指代 `R_LiDAR`、历史回执 `R_rec`。定义
`χ_ICC = 1[ TV(R_ℓ, R_LiDAR) ≤ τ_tv ] ∧ 1[ supp(R_ℓ) ∩ supp(R_LiDAR) ≠ ∅ ] ∧ 1[ R_rec 不与二者矛盾 ]`。
`χ_ICC=0` 时输出 `Clarify(问题, 候选集)`；**禁止**系统自行选择一方。注意区分**冲突**（支撑集不相交）与**歧义**（支撑集相交但都低集中度）：前者必须澄清，后者可主动扫描。

**定义 457（意图能力限幅 ICL）** 令 `clamp_CC(ψ) = ι` 当且仅当
`tools(Γ(ψ)) ⊆ T₀ ∧ mag(ι) ⊆ M_phys ∧ ≻(ι) ⊇ ≻_safe`；
否则输出 `⊥` 并回退默认 `ι₀`。这把第 3 轮定义 432 的能力闭包从「语言槽位」推广到「意图后验」：即使模型以 0.99 相信人想「用激光切开它」，只要切割超出 `T₀`/`M_phys`，也一律拒绝。**高置信度不是越权许可证。**

**定义 458（可读扫描与双向意图）** 可读性 `Leg(g) = P_{human}(target = o* | observe g)`，即人观察到扫描模式 `g` 后能正确猜出机器人目标 `o*` 的概率。机器人选择
`g* = argmax_{g ∈ G_scan} [ IG(g) + w_leg·Leg(g) ]`。
人的纠正性指认 `h′` 作为新观测反馈进 `q(ψ)`；若 `h′` 与预测指代持续背离，则判定**双向意图错位**并触发澄清。这构成 `人意图 → 机器扫描 → 人推断机器意图 → 人的纠正 → 更新` 的闭环。

**定义 459（眼安全与非侵入包络）** 允许扫描集
`G_safe = {g : class-1 ∧ MPE(t) ≤ MPE_max ∧ t_dwell ≤ t_dwell^max ∧ FOV ∩ Sensitive ≤ 预算}`。
LiDAR 与工具动作共用安全盾：当人处于扫描视场内时，需降低功率/驻留或改用非直射模式。**主动感知不能以安全为代价。**

**定义 460（物理层回波证明 Attest）**
`Attest(z) = 1[ 多回波自洽 ∧ ToF 物理可行 ∧ 几何连续 ∧ 跨传感器一致 ]`。
用于检测回射器欺骗、注入攻击与多径伪目标。其**诚实边界**：一个「物理上真实存在、放在正确位置的假手」与真手具有几乎相同的观测分布，LiDAR 无法分辨；此时只能靠语言/回执交叉或人确认（引理 65）。

**定义 461（意图审计证书 IntentCert 与回执绑定）** 扩展第 3 轮 NCB：
`IntentCert = (ℓ, g_{1:T}, q, Ψ̂, ε_id, ICC, Attest, policy_version)`；
每条意图主张必须绑定 `(intent_cert_id, receipt_id, chunk_cert_id)`，无法绑定者剥离为纯解释。审计链变为「**意图 → 指令 → 块 → 逐条回执 → 主张**」五级，使人类可复现「为什么我认为他想修这个」。

**定义 462（决策风险、弃权与意图—行动放大因子）** 对候选集 `Ψ̂` 定义
`R_act(Ψ̂) = Σ_{ψ∈Ψ̂} q(ψ)·L(a*(Ψ̂), ψ)`，仅当 `R_act ≤ R_max` 且 `P(ψ* ∈ Ψ̂_ε) ≥ 1−α` 时执行，否则弃权/澄清。定义
`κ_int = R_act(Ψ̂) / R_act({ψ*})`，
即「用集合代替真值」造成的风险放大比。`κ_int` 把「意图不确定性」与「物理后果」显式相乘，是本轮对 InstructGauge `κ_sem` 的意图层对应物。

**定义 463（退化与等价）** 令 `G_scan=∅` 且 `LiDAR=⊥` ⇒ `q` 退化为语言先验，`Ψ̂` 只用于弃权，系统逐指令等价于 InstructGauge；令 `|Ψ|=1` ⇒ `κ_int=1`，退化为单一 `ι`。令 `T₀`、`M_phys`、`≻_safe` 与第 3 轮相同，故所有结论以 InstructGauge/ToolGauge 为退化特例。未重定义记号沿用定义 398–447。

## 3. 关键算法骨架

```python
# IP-328 LIG：语言 + 点云 + 指向手势 -> 意图后验集合（先一致性，后贝叶斯）
class LIG:
    def infer(self, ell, cloud, gesture, prior):
        R_lang = self.lang_referents(ell)                 # 语言指代分布 R_ell
        R_geo  = self.cone_referents(gesture, cloud)      # 几何指代分布 R_LiDAR (定义451)
        if tv(R_lang, R_geo) > TAU_TV or disjoint(R_lang, R_geo):
            return Clarify(R_lang, R_geo)                 # 定义456：不静默覆盖
        q = self.bayes_update(prior, ell, cloud, gesture) # 定义452
        Psi_hat = {psi for psi in q if q[psi] >= EPS_POST}
        if self.identifiable(Psi_hat, ell, cloud):        # 定义453
            return PointIntent(argmax(q)), q, Psi_hat
        return Ambiguous(Psi_hat), q, Psi_hat             # 弃权：返回集合而非标签

# IP-329 AID：主动扫描选择（信息增益 - 代价 - 决策风险）
class AID:
    def next_scan(self, Psi_hat, q, budget, safe_env):
        best, best_val = None, -INF
        for g in self.G_scan(safe_env):                   # 只在 G_safe 内
            if g.cost > budget:
                continue
            ig   = mutual_info(q, g)                      # I(psi; z | D, g)
            risk = decision_risk(Psi_hat, g)              # 定义462
            val  = ig - LAMBDA_C * g.cost - LAMBDA_R * risk
            if val > best_val:
                best, best_val = g, val
        if best_val <= TAU_STOP:                          # 停止规则
            return None
        return best

# IP-330 + IP-333：一致性证书 + 能力限幅（顺序不可交换）
def certify_and_clamp(psi, ell, cloud, receipts):
    if not consistent(ell, cloud, receipts):              # 定义456
        return Clarify(...)                               # 澄清优先于执行
    iota = clamp_capability(psi)                          # 定义457
    if iota is None:
        return Reject("capability_closure")               # 意图不得扩权
    return iota

# IP-332 LGP：可读扫描（信息增益 + 可读性）
def legible_scan(G_safe, q, human_model):
    return max(G_safe,
               key=lambda g: mutual_info(q, g) + W_LEG * legibility(g, human_model))

# IP-334 IntentGauge-8C：I->G->A->H->C->E->V->U
def intentgauge_8c(M, s, ell):
    cloud, gesture = M.lidar.snapshot(), M.lidar.human_pose()
    out = M.lig.infer(ell, cloud, gesture, M.prior)       # I：意图观测
    if isinstance(out, Clarify):
        return ask_human(out)                             # 不静默覆盖
    Psi_hat, q, _ = out
    while decision_risk(Psi_hat, q) > R_MAX:              # A：主动消歧
        g = M.aid.next_scan(Psi_hat, q, M.budget_left(s), M.safe_env)
        if g is None:
            return abstain_and_red(s, "unidentifiable")   # 弃权而非猜
        z = M.lidar.execute(g)                            # 受眼安全约束的物理动作
        if not Attest(z):                                 # 定义460
            return abstain_and_red(s, "spoof_suspected")
        q = bayes_update(q, z, g)
        Psi_hat = {psi for psi in q if q[psi] >= EPS_POST}
    iota = M.icl.clamp(Psi_hat)                           # G：能力闭包投影
    if iota is None:
        return abstain_and_red(s, "capability")
    H  = M.lbox.hypothesize(s, M.dbox.R[s], iota)         # 继承 7C
    C  = M.iac.plan_chunk(iota, H, M.tools, M.budget_left(s), M.drift_bound(s))
    cert = M.cvc.commit(C, M.env, iota)                   # E：执行 + 块证书
    receipts = cert.receipts
    if len(receipts) < n_min(s):
        return stub_and_red(s, "insufficient")
    if not M.apcal.cross_validate(*M.apcal.calibrate(receipts, H, s),
                                  M.cross_receipt(s)):
        return stub_and_red(s, "cross_failed")            # V：独立回执验证
    M.mreg.hot_replace_at_quiescence(M.dpe, M.apcal.last_ec, cert.boundary)
    M.lgp.observe_correction(gesture, iota)               # 双向可读反馈
    return IntentCert(ell, q, Psi_hat, cert, receipts)    # U：审计闭包

# IP-334 主闭环：50Hz 路径完全不变
def IntentGauge_round(M, obs, audio, tac, depth, det, ell=None):
    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight:
            M.inflight.add(s)
            submit_async(intentgauge_8c, M, s, ell)
    return MODGAUGE_round(M, obs, audio, tac, depth, det)
```

## 4. 推导

**引理 59（意图限幅的能力闭包保持）** 在类型系统与 `clamp_CC` 下，对任意意图后验 `q`，被执行计划的并集满足
`∪_{ψ ∈ supp q} Plan(ψ) ⊆ Plan_ToolGauge`。
*证明*：每个 `ψ` 经 `Γ` 与能力闭包得到 `ι`，由第 3 轮引理 51 有 `Plan(ι) ⊆ Plan_ToolGauge`；`supp q` 为有限/可数集合时并集仍为子集；`clamp_CC=⊥` 的情形回退 `ι₀`，亦在 `Plan_ToolGauge` 内。**推论**：意图识别的错误上界是「在合法计划集里选错目标」，而不是「越权执行」。

**引理 60（可辨识性的样本复杂度下界）** 设意图先验熵 `H(ψ)`、单次扫描最大信息增益 `IG* = max_g IG(g)`、允许错误率 `δ`，则任何策略区分 `ψ` 所需扫描次数的期望满足
`E[N] ≥ H(ψ) / IG*`，
且当 `N` 次后仍满足 `sup_g D_KL < ε_id` 时，错误率下界由 Fano 不等式给出 `P_e ≥ 1 − (IG*·N + 1)/H(ψ)`。**含义**：主动扫描的收益有硬上界；若某对意图的 KL 在**所有** `g` 下都低于 `ε_id`，则 `N → ∞` 也不能区分——这就是「原则性不可辨识」，只能询问（引理 65 的对偶）。

**引理 61（贪心扫描的近似保证与失效条件）** 若各扫描通道在给定 `ψ` 下条件独立，或扫描集合上的条件熵是**自适应次模**的，则期望信息增益单调次模，贪心达到最优的 `(1−1/e)`。若通道高度相关（重叠 FOV、同一遮挡结构），次模性可被破坏，贪心可能高估增益；此时退回对 `G_scan` 的精确枚举或加入「去相关惩罚」`−λ_ρ·corr(g, g_已选)`。*证明骨架*：标准自适应次模贪心界（Golovin–Krause）；相关性反例用两束完全重叠的激光构造。

**引理 62（一致性证书的可靠性与共模边界）** 若最多一个通道出错（语言或几何），则 `χ_ICC=0` 时系统绝不基于错误指代执行，澄清请求是可靠的。但若语言与几何发生**共模错误**（同时指向同一错误物体），`χ_ICC=1` 仍可能成立——此时错误不可被 ICC 检测。*证明*：单通道错误时 TV 至少为真实分布与错误分布之差，超过 `τ_tv`；共模错误使两分布同向偏移，TV 低于阈值。**这是本方案最重要的诚实边界**，与第 2 轮 TrustGauge 的共模污染同构。

**引理 63（指向接地的误差界）** 指向角噪声 `σ_p`、目标距离 `r` 下，横向定位误差约 `r·σ_p`；两物体角间距小于 `σ_p` 时指向无法区分，概率
`P(误指) ≈ Φ(−Δ_ang/(√2 σ_p))`，随角间距单调下降。LiDAR 首碰面可消解**沿射线**的遮挡顺序，但不能消解**横向**近邻；换视角可增大角间距（主动扫描的几何理由）。*推论*：`κ_int` 中由指代引起的部分应在 `Δ_ang ≲ σ_p` 时置为高弃权，而非强行选取。

**引理 64（可读性—信息增益的权衡）** 在扫描时间预算 `T` 与有限动作集下，可达的 `(IG, Leg)` 集合存在 Pareto 前沿；一般**不存在**同时最大化二者的扫描。理由：信息增益高的扫描常指向人难以解读的窄区域，而人易读的扫描（慢速、大范围、跟随人）单位时间信息量低。形式上存在常数 `C_T` 使 `IG(g) + w·Leg(g) ≤ C_T·T`。*推论*：`w_leg` 必须显式配置，不能声称「既最优又可读」。

**引理 65（回波欺骗的可检测与不可检测边界）** `Attest` 能检测一切**物理不一致**的欺骗（多回波矛盾、ToF 不可行、几何断裂、跨传感器冲突），误检率随回波数趋于 0。但若攻击者在物理上放置真实物体，使观测分布与「真实意图」完全相同，则两个世界的 `TV=0`，**任何传感器都无法区分**；此时只能依赖语言/回执交叉验证或人确认。*证明*：若两假设诱导的 `P(z|·)` 相同，任何检验的功效不超过随机猜测。**边界**：安全不能只靠感知，必须保留「问人」这一物理外通道。

**引理 66（退化等价与 50Hz 保全）** 令 `G_scan=∅`、`LiDAR=⊥`，则 `q` 退化为语言先验、`AID` 不执行、`ICC` 只余语言一致性检查，逐指令等价于 InstructGauge；令 `|Ψ|=1`，则 `κ_int=1`、`R_act` 退化为单点风险，亦等价。主动扫描、后验更新与一致性检查全在异步路径；50Hz 内联路径仅增加 `O(|Ψ|)` 查表与 `O(1)` 证书检查，新增周期 `< 0.2ms`，继承第 3 轮引理 58 与第 2 轮引理 50。

## 8. 本轮最大风险

**一句话**：`LIG` 的几何接地与 `AID` 的主动扫描在接口处形成**精度—语义错配**——LiDAR 能把「指向哪个物体」测得很准，却无法证明「这就是他真正想修的东西」；一次被物理上真实假目标或共模指代错误诱导的、高置信度的意图归因，会被能力闭包判定为「完全合法」，从而绕过所有安全盾，把错误直接放大成一串合法却错误的修复动作。
