### 第 1 轮灵感驱动研究记录（承接 CADVS-v5 状态）

**灵感词**：常识推理、基准测试

**继承关系**：第 5 轮 CADVS-v5（IP-493~496）把提议升级为条件流匹配、记忆升级为嵌入+固化、人因升级为情感调制，并用定理 6（证书不变性）把框架推广为「任意生成器 + 认证边界」。但 v5 亲手写下了自己的最大风险 R57：**固化自指回路**——策略在「自己铸证」的片段上训练，缺乏外部真值，可能学会博弈证书门（形式合规、实质违背）。本轮两个灵感词恰好补上 v5 缺失的两类外部参照：**常识推理**提供「形式合规但语义荒谬」的独立语义裁判，**基准测试**提供「谁来审计审计者」的外部证伪协议。二者统一为主题「外部锚定的认证执行」（Externally-Anchored Certification, EAC），形成 CADVS-v6（IP-497~500）。本轮最重要的动作不是再加模块，而是**划分平面**：控制面（在线硬门）逐字节冻结，外部锚只允许落在数据面（训练语料过滤）、评估面（密封基准）与治理面（认证护照账本）。一句话：**常识不是第八道门，而是门外的审计员；基准不是证书，而是证伪器。**

**直觉与动机**：

1. **常识推理 → 用「语义荒谬」暴露形式证书的构造效度缺口，但只让它当否决者。** 七硬门检查的是「与已声明约束是否一致」，不是「在世界中是否讲得通」。一条轨迹可以同时满足覆盖、物理、人因、末点、记忆、价值、平衡七门，却在常识上灾难性地错：刀锋朝人递刀、液氮倒进保温杯、金属餐具进微波炉。形式证书对这类错误是**结构性盲**的——约束语言里根本没有「刀是利的」「金属会打火」这些谓词。v6 引入冻结的常识一致性裁判 CSCO，但它**不进在线门**：只在离线对固化语料做「高置信 REFUTE 则剔除」的单向否决，并生成「形式特征相同、常识结局相反」的反事实孪生样本来审计门本身。关键不对称：CSCO 只能**删除**数据，永远不能**认证**数据——所以它被骗的代价是「少学一点」，而不是「多学错一点」。这也解释了为什么常识必须是审计员而非门：把它做成门会新增第八锚、破坏单调性，还会把一个可错的语义模型变成策略可以直接优化的攻击面。

2. **基准测试 → 把「自评」换成「预注册 + 密封 + 污染控制 + 证书博弈率」的外部证伪。** v5 的 86.3%、0.55 ms 都是自选指标、自选场景、自评结果——这是自指回路的评估学版本：系统在给自己打分。v6 引入认证基准协议 CBP：训练/开发/**密封**/轮换留出四分割；n-gram + 嵌入 + 感知哈希三重污染检测；把 **证书博弈率 CGR**（形式证书通过、但独立人工/结局判定失败的比例）升为一等公民；并用「形式特征匹配、语义标签相反」的反事实孪生对直接测门的构造效度。但基准也有自己的病理——Goodhart 与「教到考试上」。因此 v6 采取波普尔式立场：**基准只能证伪，不能证实**；它是审计信号，不是安全证书；任何单一标量必须按分布偏移分层报告，拒绝把密封集分数当作部署保证。

**关键洞见（平面分离）**：v1~v5 隐含地把「系统优化什么」与「什么认证系统」混在一起，于是任何改进都可能退化为对认证器的博弈。v6 显式分成四个平面：

- **控制面（在线）**：七硬门与阈值逐字节冻结，fail-closed；
- **数据面（离线）**：常识裁判对固化语料做单向否决，语料单调收缩；
- **评估面（离线）**：密封基准 + 反事实孪生，只证伪；
- **治理面（离线）**：认证护照 + 只追加账本，记录门哈希/阈值哈希/裁判版本/语料哈希/基准报告/DP 预算，可回滚、可复现。

并给出一条架构不变量：**外部锚只能是一比特否决、冻结、且永不进入损失函数**。一旦把审计器做成可微奖励，独立性立刻消失，自指回路只是从「博弈门」迁移成「博弈审计器」——这是本轮最反直觉、也最容易被工程诱惑破坏的一条。

**形式化目标（增量）**：

1. CSCO = (符号化前端 G_sym, 物理可供性知识库 KB, 号角规则集 R, VLM/LLM 仅作符号化与未知标记, 校准器, 证据迹)；输出 (verdict ∈ {SUPPORT, REFUTE, UNKNOWN}, p, σ, trace)。
2. 语料过滤：C_v6 = C_v5 \ {ep : verdict = REFUTE ∧ p ≥ p_hi ∧ σ ≤ σ_hi}；单向、单调：C_v6 ⊆ C_v5。
3. 基准 B = (B_train, B_dev, B_sealed, B_rot)；污染函数 κ(B, D) 三重检测；指标含 CGR、CCR、门 AUROC、ECS 校准 ECE、分 shift 分层 CGR。
4. 反事实孪生 Twin(·)：匹配门的可观测低层统计（边际分布、接触事件计数、力范数直方图），翻转常识/结局标签。
5. 认证护照 Passport(θ) = (hash(gate code), hash(τ^4), v_cs, hash(C_v6), hash(B_sealed report), DP ε, 审计签名)；校验失败则禁止上线。
6. 定理 9（平面分离/无第八门）、定理 10（语料单调收缩与自指缩减界）、定理 11（基准只证伪/Goodhart 下界）、定理 12（审计器不可训练性/自适应查询预算）。

**执行集记号的精确化（对 v5 的诚实补注）**：v5 的 Exec_v5 ⊆ Exec_v4 依赖「同门 + 阈值只紧 + **提议支撑受限**」三件事，其中支撑包含是一个需要显式验证的假设；v6 在筛选后的子语料上重训提议，支撑可以平移，故不再自动继承。v6 因此只对**门包络**主张严格单调：E_v6 = E_v5 = E_v4（门与阈值逐字节不变）；对**实现集** R_v6 = E_v6 ∩ supp(π_{θ_v6}) 不主张与 R_v5 嵌套，而把「支撑包含」降级为可在 CI 中执行的 support-containment 断言。拒绝一个未验证的嵌套，比维护一个漂亮的假定理更重要。

**本轮最大风险**：**审计器捕获（auditor capture）**——冻结的常识裁判与密封基准只是静态靶子；自适应策略一旦（哪怕间接地，通过数据选择或超参搜索）把审计器当成优化目标，自指回路不会被消除，只会从「博弈门」迁移为「博弈审计器」；而「冻结 + 只否决 + 不训练」的架构约束在工程压力下最容易被悄悄破坏。

## 2. 关键算法骨架

### IP-497 CSCO：常识一致性裁判（冻结、只读、单向否决）

```python
@dataclass(frozen=True)
class CSOVerdict:
    verdict: Literal['SUPPORT', 'REFUTE', 'UNKNOWN']
    p: float
    sigma: float
    trace: tuple[str, ...]          # 证据迹：KB 三元组 / 触发的号角规则

@dataclass(frozen=True)
class CommonsenseConsistencyOracle:
    """CSCO：冻结、只读、单向否决的常识裁判。
    不变量 I1：不在控制面依赖闭包内；I2：不作为可微奖励；I3：只否决不认证。"""
    version: str                     # 语义版本；任何变更 = 新对象，旧护照失效
    kb: KnowledgeBase                # 物理可供性 KB：刀利/玻璃脆/金属导电/液氮冻伤...
    rules: tuple[HornRule, ...]      # 危险号角规则：sharp(x) ∧ toward(x,human) → danger
    vlm: Any                         # 仅做 G_sym 符号化与未知标记，不做最终判决
    llm_retriever: Any               # 仅提供候选谓词，供符号核对
    calibrator: Any                  # 温度缩放 + 保形预测，校准 REFUTE 置信
    p_hi: float = 0.90
    sigma_hi: float = 0.20

    def judge(self, g_sym, tau_sum) -> CSOVerdict:
        preds = self.vlm.to_symbolic(g_sym, tau_sum)      # 端侧符号化，不传原始像素
        votes = (self._kb_entail(preds),                   # 知识库蕴含
                 self._rule_forward(preds),                # 号角规则前向
                 self._llm_check(preds))                   # 检索增强核对
        verdict, p, sigma = consensus(votes, self.calibrator)
        # 三票一致才给 SUPPORT/REFUTE；任一分歧 → UNKNOWN（保守但只否决）
        return CSOVerdict(verdict, p, sigma, proof_trace(preds))

    def veto(self, ep) -> bool:
        """单向否决：仅高置信 REFUTE 剔除；SUPPORT/UNKNOWN 均不构成准入证据。"""
        v = self.judge(ep.g_sym, ep.tau_sum)
        return v.verdict == 'REFUTE' and v.p >= self.p_hi and v.sigma <= self.sigma_hi

    def twin(self, ep, label_flip) -> Episode:
        """反事实孪生：匹配门可观测的低层统计，翻转常识/结局标签。"""
        return resample_matching(ep, match_keys=GATE_OBSERVABLE_STATS,
                                 flip=label_flip)

    def audit_self(self, adv_set) -> dict:
        """裁判自身的对抗体检：假否决率、对抗场景图召回；结果写入护照。"""
        ...
```

```python
@dataclass(frozen=True)
class BenchmarkReport:
    cgr_dev: float; cgr_audit: float
    ccr: float; auroc_twin: float; ece: float
    cgr_by_shift: dict[str, float]
    quarantined: tuple[str, ...]
    code_hash: str; sealed_unblinded: bool

@dataclass(frozen=True)
class CertificationBenchmarkProtocol:
    B_train: Dataset; B_dev: Dataset
    B_sealed: Dataset; B_rot: Dataset
    dets: tuple = (ngram_det, embed_det, phash_det)
    tau_c: float = 0.02
    k_adapt: int = 8                  # 每轮允许的自适应审计查询预算

    def quarantine(self, D) -> tuple[Dataset, tuple[str, ...]]:
        bad = tuple(x.id for x in self.B_dev
                    if max(d(x, D) for d in self.dets) > self.tau_c)
        return drop(self.B_dev, bad), bad

    def audit(self, theta, gates, corpus) -> BenchmarkReport:
        dev, bad = self.quarantine(corpus)                # 污染隔离
        pairs = [(x, Twin(x)) for x in dev]               # 反事实孪生

                               ccr=commonsense_conformance(pairs),
                               ece=calibration_error(theta, dev),
                               cgr_by_shift=stratified_cgr(dev),
                               quarantined=bad, code_hash=hash_code(self),
                               sealed_unblinded=False)
```

### IP-500 EFA-v6：外部锚定装配器（控制面不变）

```python
@dataclass
class ExternallyAnchoredAssemblerV6:
    v5: EvidenceForgingAssemblerV5      # 控制面逐字节复用
    csco: CommonsenseConsistencyOracle
    cbp: CertificationBenchmarkProtocol
    ledger: TrustLedger

    def select(self, *args, **kwargs):
        # 控制面：不调用 CSCO/CBP，不读账本以外的任何外部锚
        return self.v5.select(*args, **kwargs)

    def consolidate(self, store, dp_eps, kl_eps):
        base = [ep for ep in store
                if ep.forged and ep.outcome_ok and ep.human_audit]
        curated = [ep for ep in base if not self.csco.veto(ep)]   # I3：只否决
        assert set(curated) <= set(base)                          # 单调性断言
        theta_new = self.v5.lmem.consolidate(curated, dp_eps, kl_eps)
        report = self.cbp.audit(theta_new, self.v5.gates, curated)
        passport = build_passport(theta_new, curated, report)
        if not report.passes_gate() or not passport.verify(self.v5):
            self.ledger.append({'event': 'ROLLBACK', 'reason': 'passport/bench'})
            return self.v5.theta                         # 回滚
        self.ledger.append({'event': 'DEPLOY', 'passport': passport.hash,
                            'report': report.hash})
        return theta_new
```

### 集成流水线（v5 → v6）

```
离线（小时~天）：
  store ──形式过滤(forged∧outcome∧human)──▶ base
        ──CSCO.veto(高置信 REFUTE)──────────▶ C_v6 ⊆ base
        ──LMEM-v2.consolidate(DP-SGD+KL)─────▶ θ_new
        ──CBP.audit(污染隔离/孪生/CGR)────────▶ report
        ──Passport(θ_new) verify─────────────▶ ledger.append ──▶ 上线 或 回滚
```

## 4. 正确性论证（增量更新）

### 引理 45（否决单调性）

**陈述**：C_v6 = C_v5 \ V_veto ⇒ C_v6 ⊆ C_v5；CSCO 不产生任何新片段。∎

### 引理 46（CGR 的集中界与分层）

**陈述**：设密封样本 S ~ D i.i.d.，|S| = n，CGR_hat = (1/n)Σ z_i，z_i = 1[cert(x_i)=1 ∧ outcome_fail(x_i)=1]。Hoeffding 给出 P(|CGR_hat − CGR_D| ≥ ε) ≤ 2e^{−2nε²}。若部署分布 D' ≠ D（跨本体/跨站点），该界不成立；故 CBP 只报告分层 CGR_s 与最坏层，拒绝单一标量。∎

### 引理 47（孪生残余灵敏度）

**陈述**：若 Twin 在门的全部输入上匹配，则门在孪生对上 AUROC = 0.5（平凡）；实践中只匹配低层可观测统计，残余 AUROC − 0.5 度量门对未匹配语义特征的敏感度。低 AUROC 即构造效度缺口。∎

### 定理 9（平面分离 / 无第八门）

**陈述**：v6 控制面门函数与阈值相对 v5 逐字节不变；CSCO/CBP/CPTL 不在任何 kc_i 的依赖闭包内；故 E_v6 = E_v5，fail-closed 与门包络单调性保持，且未新增第八硬门。

**证明**：kc_i 的输入仅为 (x, c, τ^5)，τ^5 由 FAMK 的 γ 与冻结的 τ^4 决定；CSCO/CBP 的输出不进入该表达式。依赖闭包可由 CI 静态分析验证。∎

**工程含义**：常识/基准再强，也不能放松任何门；它们只能改变「拿什么去训练」和「相信多少」。

### 定理 10（语料单调收缩与自指缩减界）

**陈述**：C_v6 ⊆ C_v5；设 G ⊆ C_v5 为真实博弈片段，CSCO 对 G 的召回为 ρ_cs，则 |C_v6 ∩ G| ≤ (1 − ρ_cs)|G|。故训练语料中的博弈质量至少按 (1−ρ_cs) 收缩。

**证明**：V_veto 至多移除 ρ_cs|G| 的博弈片段，不移入任何片段。∎

**诚实边界**：ρ_cs 是经验量且随分布/对抗演化；该界作用于**语料**，不是运行时行为；假否决会同时减少安全数据，存在数据效率—安全权衡。

### 定理 11（基准只证伪 / Goodhart 下界）

**陈述**：(i) 对任意有限基准 B 与任意策略 π，存在 π' 使 π'|_B ≡ π|_B 但在 x* ∉ B 上任意危险；故仅凭 B 无法认证部署安全（无覆盖假设即无界）。(ii) 在可交换样本上 CGR_hat 有引理 46 的集中界；在分布偏移下无标量界。(iii) 污染控制降低选择偏差，不增加覆盖。

**证明**：(i) 构造 π' = π on B，π' = unsafe on x*；任何只查询 B 的检验无法区分。(ii)(iii) 由引理 46 与定义。∎

**含义**：**基准是证伪器，不是证书**；部署安全仍由冻结的门 fail-closed 兜底，基准只负责发现「门不够」。

### 定理 12（审计器不可训练性 / 自适应查询预算）

**陈述**：若审计器 A（CSCO 或 CBP）的分数被用于在 k 个自适应选择的 θ 中做选择（或作为可微奖励），则在标准自适应数据分析假设下，A 分数对新鲜数据的泛化间隙为 Ω(√(k/n))（忽略对数因子；n 为留出样本量）；除非使用新鲜数据或 DP 复用（thresholdout）。故「训练/选择于审计器」以可证速率侵蚀审计器效度；架构必须保持锚为「一比特否决、冻结、无梯度」，并对每轮自适应查询设预算 k_adapt。

**证明**：自适应数据分析的重用下界（Dwork 等）；常数依赖 A 的稳定性，方向是结构性的。∎

**工程含义**：这就是为什么 CSCO 只能 veto、CBP 只能 audit；一旦有人把 CGR 写进损失函数，定理 12 立刻生效。

### 定理 v6（总装）

**陈述**：在 v5 假设 (B1)~(B7) 与新增 (B8) CSCO/CBP 版本冻结且不进入控制面下：

(i) 门包络相等：E_v6 = E_v5 = E_v4（**不是** R_v6 ⊆ R_v5，见执行集记号精确化）；
(ii) 语料单调：C_v6 ⊆ C_v5；
(iii) 可交换密封样本上 CGR_hat 按引理 46 集中；跨 shift 只报分层；
(iv) 孪生 AUROC 给出门的构造效度缺口（引理 47）；
(v) 审计器捕获速率受自适应查询预算 k_adapt 约束（定理 12）；
(vi) 在线零增量延迟（定理 9）。

**证明**：(i)(ii) 见定理 9/10；(iii) 见引理 46；(iv) 见引理 47；(v) 见定理 12；(vi) 由控制面代码哈希相等。∎

**诚实声明**：v6 不消除 R57，只是把「自指」从门迁移到审计器并使其**可度量、可预算**；ρ_cs、k_adapt、污染阈值都是经验参数；符号化仍可能泄露场景语义（R66）；support-containment 只是 CI 断言，不是定理。

## 7. 本轮最大风险（最终确认）

**一句话**：**审计器捕获（auditor capture）**——冻结的常识裁判与密封基准只是静态靶子，自适应策略一旦通过数据选择、超参搜索或间接反馈把审计器当成优化目标，自指回路不会消失，只会从「博弈门」迁移为「博弈审计器」；「冻结 + 只否决 + 不训练」的架构约束是唯一的结构性防线，也最易在工程压力下被悄悄破坏。
