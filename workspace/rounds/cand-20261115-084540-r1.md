# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「任务规划」×「多模态融合」）

> R69 把不确定性一分为二（aleatoric / epistemic），并让系统学会「问」：看、触、追问。但它对 epistemic 的整个处置仍压在一个未经检验的假设上——**歧义的价值是当下、局部的、与计划无关的**。`U_epi = H_mode·g(Δ_min)` 衡量的是「世界的模糊度」，逐指令的 `argmax[VoI−c]` 则默认「此刻熵大就值得问」。真实任务并非如此：同一个 50/50 歧义，在岔口之前是一个可保留的**期权**，在不可逆一步之后是一个**沉没成本**；而一个高熵歧义若两条模态最终导向同一个动作，其决策价值为零。R69 优化的是「模糊」，不是「后悔」。
>
> 本轮两个灵感正好补上两块缺失：
> - **任务规划**给出歧义真正被「结算」的地方——**承诺点**。计划是一台把歧义兑换成不可逆承诺的机器；歧义只在即将被承诺点结算时才值钱，且一旦可以「绕开」，就根本不必问。
> - **多模态融合**给出「承诺点上被计划需要的变量」如何被证据充分覆盖——融合的单位不是特征向量，而是**计划变量**；且必须扣除共模相关，否则「多源一致」只是同一个错误被数了两遍。
>
> 核心命题：**把 R69 的「是否提问」从熵驱动的逐指令决策，升级为计划条件、结果锚定、承诺截止期感知的序贯信息分配；并把二元仲裁（问/保守）扩为三元仲裁（问/规划绕开/保守）。多模态融合由计划反向驱动：只融合承诺点需要、且赶得上 deadline 的证据。** 命名 **COMPASS-RAS**（Commitment-aware, Outcome-grounded, Multimodal, Plan-conditioned, Active-Sensing Scheduler）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**这个歧义到底在计划的哪一步才真的咬人；我该现在问、绕开它，还是索性不问**」。

## 0. 直觉与动机

**灵感 1（任务规划 → 歧义只在承诺点被「结算」）**
直觉：人过马路时不会在出发前把所有不确定性都问清。他会在「迈步之前」看一眼，因为迈步是不可逆承诺；一旦已经走到路中央，再看也改不了「已经暴露」这个事实。计划由一串承诺点组成：抓起（承诺了对象身份）、落步（承诺了落脚点与地形）、倒水（承诺了容器与水量）、说「好的」（承诺了意图）。**在承诺点之前，歧义是一个可以被信息动作缩小的期权；在承诺点之后，它是一个只能被承担的结果。** R69 的逐指令 VoI 对这个时间结构完全无感：它可能把预算烧在一个「以后反正会绕开」的歧义上，也可能在一个「三秒后就要落步」的致命歧义上因为当下熵不够大而选择不问。

**灵感 2（多模态融合 → 融合的单位是「承诺点上的计划变量」）**
直觉：融合不该是「把能拿到的模态都拼起来」，而应是**按需融合（need-to-know）**：视觉回答「是哪个物体」，力/触觉回答「接触是否成立」，语言回答「用户到底要哪个」，本体感觉回答「我还能不能恢复」。计划变量决定该问哪个模态；承诺点的 deadline 决定该在什么时候融合完。更关键的是，多个模态常常共享同一个骨干/标定/检测器——它们的一致并不等于独立佐证。R69 的「k 个正交证据源一致」纪律从未估计相关性 ρ，因此在**共模误差**面前会被系统性地骗过：三个模态一起错，看起来像三个证人一致。

**灵感 3（DREU → R69 的熵是「世界模糊度」，不是「决策后悔度」）**
直觉：歧义有两种「大」：一种很模糊但无所谓（两个模态都通向同一个安全动作），一种只差一点点但很要命（差 1cm 就撞）。R69 的 `H_mode` 对前者给高分、对后者可能给低分。真正该问的是信息经济学里的 **EVPI（期望完美信息价值）**：知道答案之后，我的最优动作能好多少。把 `U_epi` 从熵代理换成 `EVPI`，就得到**决策相关认知不确定性 DREU**。R69 的熵是 DREU 的一个上界代理（在 Q 有界 Lipschitz 时），但不是等价物——存在「高熵、零后悔」的构造反例。这一步把「问得勤」改成「问得准」。

**灵感 4（三元仲裁 → 除了问和保守，还有「绕开」）**
直觉：面对歧义，人还有第三条路——**选一个对两种可能都成立的动作/计划**。不确定对面是不是熟人，就先点个头而不是直呼其名；不确定物体是杯子还是瓶子，就用能同时抓住两者的包络式抓取。任务规划让「绕开歧义」变成一个可搜索的对象：在计划空间里找一条**在每个承诺点上对当前模态都鲁棒**的路径。它的代价是可能更高的任务成本 `Δ_plan`，但换来零交互、零社交打扰、零信息延迟。于是仲裁变成三者取最小：`问（花信息成本）`、`绕开（花任务成本）`、`保守（花时间/效率成本）`。R69 只有后两者中的「问/保守」，因为它没有计划这个对象，无法表达「绕开」。

**灵感 5（新威胁 → 计划与相关性矩阵会「自信地撒谎」）**
直觉：COMPASS 把「该不该问」的裁判权从「歧义多大」交给了「计划说这歧义重不重要」。这引入一个更隐蔽的攻击面：**如果计划 DAG 或证据—计划关联矩阵本身错了**，系统会因为「计划说这里不重要」而理直气壮地不问。更糟的是，规划器与策略常常共享同一个世界模型——当世界模型整体偏移时，二者的错误是**自洽**的：计划给所有分支算出的 Q 都同样错，于是 EVPI 被算成 0，系统「因为看不见后悔而更加自信」。这是 R69「追问幻影」的镜像失败：**R69 问了一个不存在的问题，R70 可能不问那个真正存在的问题；不问，比问错更隐蔽。** 因此本轮必须同时交付：相关性默认开放（未知不得当作无关）、共模相关折扣、承诺点冲突即重规划/停机、以及计划归因审计。

## 1. 形式化定义（增量：定义 310–324）

**定义 310（计划 DAG 与承诺点）** 任务计划为有向无环图 𝒢 = (V, E)。节点 v ∈ V 是子目标/技能（可对应 R69 的一个动作块 ξ_{t:t+H}），带：前置条件 Pre(v)、模式相关可行性 Feas(v, m)、截止期 d_v、承诺级 c_v ∈ {可逆, 高代价, 不可逆}、以及模式相关代价 J_v(m)。承诺点 𝒞 ⊆ V 是 c_v = 不可逆的节点。计划 π 是 𝒢 中从根到目标的一条可行路径；J(π; m) = Σ_{v∈π} J_v(m)。**关键结构**：一旦执行 v ∈ 𝒞，其它分支在 v 之后不再可达——这就是「歧义被结算」的时刻。

**定义 311（计划变量与证据—计划关联矩阵）** 计划变量集 𝒳 = {x_1,…,x_n}（对象身份、相对位姿、接触状态、人的意图、地形类别…）。每个节点 v 声明其依赖变量 Dep(v) ⊆ 𝒳。模态 i ∈ ℳ（视觉/语言/力触觉/本体/音频…）。关联矩阵 **R** ∈ [0,1]^{|ℳ|×|𝒳|}，R_{i,x} 表示模态 i 对变量 x 的约束能力。R 由数据估计（消融、条件互信息、反事实梯度），不是先验拍脑袋。

**定义 312（决策相关认知不确定性 DREU / EVPI）** 给定当前观测 o 上的模态后验 p(m|o)、节点 v 的动作集 A_v 与动作价值 Q_v(a,m)：
`DREU(v) = EVPI(v) = E_{m~p}[max_{a∈A_v} Q_v(a,m)] − max_{a∈A_v} E_{m~p}[Q_v(a,m)]`。
（用代价表示时取负号；下文统一用「价值」。）它度量「知道 m 之后能好多少」，单位是任务代价，而非比特。分解：
`U_epi = U_epi^act + U_epi^moot`，其中 `U_epi^act` 只统计**在承诺截止期 d_v 之前、且变量被计划真正依赖**的部分；`U_epi^moot` 是已过承诺点或计划根本不依赖的部分，其 EVPI 恒为 0（定义 310 的不可达性）。
关系：在 Q 对模式 L-Lipschitz、值域 [0,Q_max] 的假设 A99 下 `0 ≤ DREU ≤ Q_max·√(H(M)/2)`，故 R69 的 `H_mode·g(Δ_min)` 是 DREU 的上界代理；但存在「H 高、DREU=0」的构造反例（两模态最优动作相同）。**R69 是 DREU 的熵代理退化，不是等价。**

**定义 313（歧义鲁棒计划）** 对计划 π 定义鲁棒代价 `J_rob(π) = E_m[J(π;m)] + ρ·CVaR_β(J(π;m))`（或 max_m）。`π_robust = argmin_π J_rob(π)` s.t. 子目标满足且通过 C-RAS-WM 认证。称 π_robust 在承诺点 v 上**模式不变**，若 `argmax_a E_m[Q_v(a,m)]` 对 p(m|o) 的支撑集不随 m 改变。`Δ_plan = J(π_robust) − J(π*) ≥ 0` 是「绕开歧义」的任务成本溢价。

**定义 314（三元仲裁 TAA）** 每个决策 epoch 在三个**已认证**选项中取期望代价最小者：
(a) **问**：R69 MINT 选 `g*`，代价 `C_ask = c(g*) + E[残余风险 | 交互后] + E[任务代价 | 交互后]`；
(b) **绕开**：切到 π_robust，代价 `C_plan = J(π_robust) = J(π*) + Δ_plan`（无信息成本、无交互延迟）；
(c) **保守**：R68 的 `λ_floor`，代价 `C_cons = 期望风险 + 时间/效率损失`。
`option* = argmin{C_ask, C_plan, C_cons}`，s.t. 所选计划/动作过 C-RAS-WM。若 `C_ask` 与 `C_plan` 因模型不可信被 MCG/RCM 门控禁用，则退 (c)。**R69 是 `Δ_plan = +∞`（无鲁棒计划可用）时的边界情形。**

**定义 315（及时融合 JITF 与充分性）** 证据原子 `e = (i, x, ℓ_i(x), conf_i, t, prov)`。融合只在满足「及时性」时发生：目标变量 x 门控某承诺节点 v，且 `t + lead_time ≤ d_v`，且延迟到 d_v 之后证据将失去价值（定义 312 的 moot）。节点 v 的**证据充分性**用 noisy-OR 覆盖：
`S(v) = 1 − Π_{x∈Dep(v)} Π_{i} (1 − R_{i,x}·conf_i·obs_i(x))`，
其中 obs_i(x) 指示模态 i 是否已对 x 提供本轮观测。`S(v) ≥ S_min` 才允许在 v 上做不可逆承诺；否则必须先问、绕开或停。

**定义 316（共模相关折扣 CDF）** 设模态间误差相关矩阵 Σ_ε，`ρ̄ = mean_{i≠j} ρ_{ij}`。朴素独立融合把 k 个源当作 k 份信息；有效独立源数
`k_eff = 1 / (1 + (k−1)·ρ̄)`。
融合采用退火乘积（tempered product）：
`p(x|e) ∝ p(x) · Π_i ℓ_i(x)^{w_i}`，`w_i = R_{i,x}·conf_i / (1 + Σ_{j≠i} ρ_{ij}·R_{j,x}·conf_j)`。
当 ρ̄=0 时退化为 R69 的（加权）k 源乘积；R69 的「k 个正交源一致」是 ρ=0 的特例。ρ 由跨模态残差在线估计，并写入证书。

**定义 317（承诺冲突与重规划 PCR）** 对门控承诺节点 v 的关键变量 x，若两个高充分性、低相关模态给出 `JS(p_i(x), p_j(x)) > τ_conf` 或 `max_m p(m|o) < 1 − τ_conf`（后验分裂），则冲突位 `conflict(v)=1`。处置纪律：
(i) 若存在第三独立源（k_eff ≥ 2）可裁决 → 再取一次证据；
(ii) 否则不得在 v 上执行不可逆承诺 → 触发**计划修复**：切到不依赖 x 的鲁棒计划，或安全停机。
禁止把冲突的多个高充分性模态「平均成一个中庸后验」——那是把「不确定」伪装成「确定」。

**定义 318（序贯预算分配 SBA，含预算期权价值）** 预算 B 为整段时域的信息/交互成本上限。对计划中每个未结算的承诺节点 v 与候选信息动作 g，定义边际收益率
`score(v,g) = [DREU(v) − E_{y|g}DREU(v|y) − c(g)] / c(g)`，
并要求 `t_now + lead(g) ≤ d_v`（deadline 可行）。按 score 惰性贪心序贯分配；当 `max score ≤ 0` 停止。**预算期权价值**：保留预算给未来更高 DREU 节点的价值 `V_opt(B,t) = E[max_{v'>t} score]`；仅当即时收益 > `V_opt` 时才花掉，避免「把预算烧在第一个看到的歧义上」。R69 的逐指令贪心是本定义在 `V_opt=0`、单节点计划下的退化。

**定义 319（相关性默认开放 RCM）** 关联矩阵 R 的每个条目必须来自有支撑的标定（A100：置信区间非空）。**未被数据覆盖的 (i,x) 一律取 R=1（默认相关/默认需要）**，即「无知不得被解释为无关」。同时用反事实消融持续标定 R：禁用模态 i 后若某承诺节点的错误率显著上升，则 R_{i,x} 上调；若长期无影响，才允许在**有覆盖证书**的前提下下调。这使「不问」必须由**正证据**支持，而非由「没有证据」默认。

**定义 320（计划条件失效归因 PCA）** 计划失败后，按证据—计划结构归因到四类：模式错误（m 估计错）、相关性错误（R/ρ 错）、标定错误（conf/传感器偏置）、执行错误。归因结果回灌 R、Σ_ε 与 MINT 成本先验；若归因为「计划模型错误」（Q/Dep 与真实不符），则冻结该计划的 EVPI 决策资格并重规划。

**定义 321（威胁模型 ℰ_PLAN）** 在 R69 的 ℰ_CALM × ℰ_poison × ℰ_flow 上新增 ℰ_plan：过时/错误计划 DAG、被污染的关联矩阵 R（把关键变量标为无关）、伪承诺点（诱导系统过早不可逆）、共模证据共谋（多模态共享同一错误源）、以及 deadline 欺骗（伪造充足 lead time）。`ℰ_COMPASS = ℰ_FLUID × ℰ_plan`。

**定义 322（证书 J_COMPASS）** `J_COMPASS = (J_FLUID, plan_dag_hash, dep_graph_hash, dREU_before, dREU_after, evpi_ratio, sufficiency_min, corr_rho_hat, k_eff_min, commitment_margin, conflict_flags, plan_repair_count, relevance_coverage, compass_ver)`。
Valid ⇔ `Valid(J_FLUID)` ∧ `dREU_after ≤ dREU_before`（单调不增）∧ 每个被执行的承诺节点 `S(v) ≥ S_min` 或走认证鲁棒/保守兜底 ∧ 冲突已裁决或安全停机 ∧ R 覆盖满足默认开放纪律。

**定义 323（anytime DREU 与 WCET）** 精确 DREU 需在全 DAG 上做 rollout，代价高。默认只对**前 k_crit=3 条关键路径**做区间界：`[DREU_lo, DREU_hi]`，用廉价的模式头预测与价值上界构造。仅当区间跨过决策阈值（`DREU_lo ≤ τ_ask ≤ DREU_hi`）时细化；否则直接用端点决策。整层带 WCET 认证，超时降级为「仅用 R69 代理 + 保守」。

**定义 324（退化链与严格包含）** 当 (i) 计划退化为单节点且全部可逆、(ii) R 全 1（全相关）、(iii) ρ̄=0、(iv) 无认证鲁棒计划（Δ_plan=+∞）、(v) DREU 用熵代理时，COMPASS ≡ FLUID 逐指令一致；再叠加 R69 的 `VoI ≤ c` 边界即 ≡ R68。故 **R68 ⊂ R69 ⊂ R70**；且所有新选项均以 C-RAS-WM 认证为前提，安全侧不做让步。

```python
# IP-264 PDC：计划 DAG 与承诺点（离线构建 + 在线缓存）
def build_plan_dag(task, skills, world_model):
    G = compose(task, skills)                     # 子目标/技能 DAG
    for v in G.nodes:
        v.dep    = infer_dep(v, skills)           # Dep(v) ⊆ 𝒳
        v.commit = classify_commitment(v)         # 可逆/高代价/不可逆
        v.deadline = schedule_deadline(v, G)      # d_v
    return G                                       # hash 后写入证书

# IP-265/266 DREU：结果锚定的 EVPI（anytime 区间界）
def dREU(plan, v, belief, Q, k_paths=3, budget_ms=0.5):
    paths = top_critical_paths(plan, k_paths)      # 只算会改变承诺的分支
    lo = hi = 0.0
    for p in paths:
        Qm = [Q(v.a, m) for m in belief.support]
        hi += E_m(belief, max(Qm)) - max_a(E_m(belief, Q(v.a, m)))
        lo += max(0.0, hi_bound_sharp(Qm, belief))  # 保守下界
        if time_exceeded(budget_ms): break           # WCET：返回区间，不阻塞
    return clamp_interval(lo, hi)                   # 区间跨阈值才细化

# IP-269/270 JITF + CDF：只在承诺点、按需、扣相关地融合
def just_in_time_fuse(v, evidence, R, rho, now):
    if not any(critical(plan, x) for x in Dep(v)): return None
    if now + lead_time > v.deadline:               return None   # 来不及 → moot
    x_need = Dep(v)
    used = [e for e in evidence if e.x in x_need and R[e.i, e.x] > 0]
    pis  = {e.i: tempered_weight(e, R, rho) for e in used}     # k_eff 折扣
    post = temper_product(prior(v), used, pis)                 # 定义 316
    S    = sufficiency(v, used, R)                              # noisy-OR
    conflict = js_divergence(used, x_need) > TAU_CONF
    return post, S, conflict

# IP-267/268 IAP + TAA：问 / 绕开 / 保守 三元仲裁
def choose_option(plan, modes, belief, budget, evidence, R, rho):
    # (a) 问：R69 MINT 的 deadline 感知版本
    g_best = mint_deadline_aware(plan, modes, belief, budget, evidence, R, rho)
    C_ask  = cost_ask(g_best, belief)
    # (b) 绕开：在认证计划集中找最小 Δ_plan 的鲁棒计划
    pi_rob = best_robust_plan(plan, belief, certify=c_ras_wm)
    C_plan = J(pi_rob) if pi_rob and plan_is_certified(pi_rob) else INF
    # (c) 保守：R68 边界
    C_cons = cost_conservative(belief, plan)
    return argmin_certified({"ask": C_ask, "plan": C_plan, "conserve": C_cons})

# IP-271/272 RCM + SBA：默认开放的相关性 + 序贯预算
def allocate_budget(plan, belief, evidence, R, budget):
    frontier = unsettled_commitments(plan)
    while budget.remaining > 0:
        scores = []
        for v in frontier:
            for g in info_candidates(v):
                if not deadline_feasible(g, v): continue
                scores.append((score(v, g, belief, evidence, R), v, g))
        if not scores: break
        s, v, g = max(scores)
        if s <= option_value_of_budget(plan, v, budget): break  # 留预算给更值钱的
        budget.spend(g); evidence += execute(g)                 # 过认证后执行
        frontier = update_frontier(plan, evidence)
    return evidence, budget
```

## 3. 推导

**引理 19（DREU 严格细于熵代理）** 在 A99（Q 对模式 L-Lipschitz、值域 [0,Q_max]）下 `DREU(v) ≤ Q_max·√(H(M)/2)`，故 R69 的 `H_mode·g(Δ_min)` 是 DREU 的上界代理；但存在反例使 `H(M)=log 2` 而 `DREU=0`（两模态的最优动作相同、Q 值相同）。系：**高熵不代表高后悔**；R69 在「模糊但无关」处系统性过度提问，COMPASS 把这类预算释放给「低熵但要命」的承诺点。

**引理 20（承诺单调性 → 迟到的信息无价值）** 设 v ∈ 𝒞 为不可逆承诺点。执行 v 后，任何在 v 处分歧的模式分支在 v 之后不可达，故对已承诺分支的价值函数与 m 无关。于是 `U_epi^act(t)` 在跨过每个承诺点时非增；在 d_v 之后获取关于 x∈Dep(v) 的信息，其 EVPI 恒为 0。系：**及时融合是最优的**——在不考虑 lead time 时，越靠近 d_v 获取（在 d_v 前）弱占优于更早获取：信息更新鲜、预算更省、且不改变可行集；有 lead time 时最优获取点为 `d_v − lead_time`。

**引理 21（绕开的支配区域）** 令 `Δ_info(g) = DREU_before − E[DREU_after|g] − c(g)` 为提问的净收益，`Δ_plan` 为鲁棒计划溢价。则绕开支配提问当且仅当 `Δ_plan ≤ Δ_info(g*)`（对所有可行 g*）。R69 中 `Δ_plan=+∞`，故只有问/保守两选项；COMPASS 的选项集严格包含 R69。系：当歧义模态数增多、但存在一个「对多模态都成立」的鲁棒计划时，`Δ_info` 随模态数上升而 `Δ_plan` 有界，**绕开在高歧义/低代价区必然胜出**——这是 R69 结构上无法表达的效率来源。

**引理 22（共模相关下的过度自信上界）** 若 k 个模态共享潜误差源且两两相关 ρ̄，朴素独立融合的后验把有效信息量高估为 k；相对真实后验的 KL 过量 ≤ `(k−1)·ρ̄·Ī`（Ī 为单源平均信息）。采用定义 316 的退火权重后有效源数回到 `k_eff=1/(1+(k−1)ρ̄)`。系：R69 的「k 个正交源一致」是 ρ̄=0 的特例；**未估计 ρ 时，证据纪律可被共模误差整体击穿**（所有模态共享同一检测器/标定）。

**定理 18（退化链 R68 ⊂ R69 ⊂ R70，安全不退）** 在 A95–A100 与定义 324 的退化条件下，COMPASS 的仲裁、融合、分配分别退化为 R69 的 MINT、CIA、逐指令贪心，故逐指令一致；再叠加 `VoI≤c` 则退化为 R68。安全侧：绕开只在 C-RAS-WM 认证的鲁棒计划中进行，冲突强制裁决或停机，λ 单调不降，故任意状态期望风险 ≤ FLUID ≤ R68。

**定理 19（序贯分配的近似保证）** 在 A101（给定模式时证据条件独立；DREU 削减函数自适应子模）下，定义 318 的 deadline 感知惰性贪心在预算 B 内取得最优总 DREU 削减的 `≥ (1−1/e)`；引入预算期权价值等价于对远期收益加一个折扣，折扣后的目标仍子模，保证保持（常数随折扣因子调整）。系：**R69 的逐指令贪心是「预算期权价值=0、单节点」的退化**，因此在多承诺点任务上可被序贯分配严格改进。

**定理 20（承诺冲突不静默 → 错误承诺上界）** 若关键变量上 `conflict=1` 时强制执行「第三独立源裁决或不停机」，则错误承诺率 ≤ `δ_p·ρ̄^{k_eff−1} + ε_σ`（k_eff 为估计的有效独立源数），且任何「高充分性模态的平均」都不能把冲突藏起来。结合引理 22，即使 ρ 被低估，k_eff 的显式估计也把过度自信限制在可审计范围。故 COMPASS 不会因融合而**静默地**在错误对象/意图上做出不可逆承诺。

## 6. 本轮最大风险

**一句话**：COMPASS 把「该不该问」的裁判权从「歧义有多大」交给了「计划说这歧义重不重要」——**一旦计划 DAG 或证据—计划关联矩阵本身错了（尤其当规划器与策略共享同一个错误的世界模型，使 EVPI 被自洽地算成 0），系统会因为「计划说这里不重要」而理直气壮地不问；R69 的危险是追问一个幻影，R70 的危险是把该问的真问题判成无关，而不问比问错更隐蔽。**

**次级风险与缓解**：
1. **相关性矩阵误标「无关」** → 定义 319 默认开放（未知即相关）+ 反事实消融标定 + 覆盖证书，使「不问」必须有正证据；
2. **共模误差伪装成多源一致** → 定义 316 的 k_eff 估计与退火融合 + E305；
3. **承诺点冲突被平均掉** → 定义 317 冲突纪律（裁决或停机）+ 定理 20；
4. **EVPI 计算过贵击穿实时** → 定义 323 anytime 区间界 + 关键路径裁剪 + WCET 降级；
5. **绕开计划自身不安全** → 只在 C-RAS-WM 认证的鲁棒计划中切换 + 定理 18 安全不退；
6. **计划/价值模型自洽盲区** → 定义 320 的计划条件归因 + 定义 321 的 ℰ_plan 对抗测试 + E310；归因为「计划错误」时冻结 EVPI 决策资格并重规划。

## 2. 形式化定义（要点版）

**定义 310（计划 DAG 与承诺点）** 节点 v 带前置、模式相关可行性/代价、截止期 d_v、承诺级 c_v；承诺点 𝒞 为不可逆节点。执行 v∈𝒞 后其它分支不可达 ⇒ 歧义在此被结算。

**定义 311–312（计划变量与 DREU）** `R_{i,x}` 为证据—计划关联；`DREU(v)=E_m[max_a Q_v(a,m)]−max_a E_m[Q_v(a,m)]`。拆 `U_epi^act`（截止期前、被计划依赖）与 `U_epi^moot`（已过承诺点/计划不依赖，EVPI=0）。A99 下 DREU ≤ `Q_max·√(H/2)`，R69 熵是上界代理；存在「H 高、DREU=0」反例。

**定义 313–314（鲁棒计划与三元仲裁）** `J_rob(π)=E[J]+ρ·CVaR_β(J)`，`Δ_plan=J(π_robust)−J(π*)`。仲裁取 `argmin{C_ask, C_plan, C_cons}`，全部须过 C-RAS-WM。R69 是 `Δ_plan=+∞` 边界。

**定义 315–316（及时融合与相关折扣）** 仅在「门控承诺点、且 `t+lead≤d_v`」时融合；充分性 `S(v)=1−Π(1−R·conf·obs)`。融合 `p(x|e)∝p(x)Πℓ_i^{w_i}`，`w_i=R·conf/(1+ΣρR·conf)`；`k_eff=1/(1+(k−1)ρ̄)`。

**定义 317–318（冲突与序贯预算）** 关键变量 `JS>τ_conf` 或后验分裂 ⇒ 冲突；纪律：独立源裁决或不停机，禁止平均。SBA 按 `score=[ΔDREU−c]/c` 惰性贪心，deadline 可行，且仅当即时收益 > `V_opt` 时才花预算。

**定义 319–321（默认开放 / 归因 / 威胁）** R 的未覆盖条目一律取 1（无知≠无关），反事实消融标定；失败归因到模式/相关/标定/执行/计划模型五类；`ℰ_COMPASS=ℰ_FLUID×ℰ_plan`（错误 DAG、污染 R、伪承诺、共模共谋、deadline 欺骗）。

**定义 322–324（证书 / anytime / 退化链）** J_COMPASS 增 `plan_dag_hash、dREU_before/after、sufficiency_min、corr_rho_hat、k_eff_min、commitment_margin、conflict_flags、plan_repair_count、relevance_coverage`；DREU 用关键路径区间界 + WCET 降级；退化条件成立时 COMPASS≡FLUID≡（进一步）R68。

## 3. 关键算法伪代码

```python
# IP-264 PDC：计划 DAG 与承诺点
def build_plan_dag(task, skills, world_model):
    G = compose(task, skills)
    for v in G.nodes:
        v.dep, v.commit = infer_dep(v), classify_commitment(v)
        v.deadline = schedule_deadline(v, G)
    return G                                       # hash 入证书

# IP-265/266 DREU：结果锚定的 EVPI（anytime 区间界）
def dREU(plan, v, belief, Q, k_paths=3, budget_ms=0.5):
    lo = hi = 0.0
    for p in top_critical_paths(plan, k_paths):
        hi += E_m(belief, max(Q(v.a, m))) - max_a(E_m(belief, Q(v.a, m)))
        lo += max(0.0, hi_bound_sharp(Q, belief))
        if time_exceeded(budget_ms): break
    return clamp_interval(lo, hi)                  # 跨阈值才细化

# IP-269/270 JITF + CDF：按需、及时、扣相关地融合
def just_in_time_fuse(v, evidence, R, rho, now):
    if now + lead_time > v.deadline: return None           # 来不及 → moot
    used = [e for e in evidence if e.x in Dep(v) and R[e.i, e.x] > 0]
    pis  = {e.i: tempered_weight(e, R, rho) for e in used}  # k_eff 折扣
    post = temper_product(prior(v), used, pis)
    S    = sufficiency(v, used, R)                          # noisy-OR
    return post, S, js_divergence(used, Dep(v)) > TAU_CONF

# IP-267/268 IAP + TAA：问 / 绕开 / 保守
def choose_option(plan, modes, belief, budget, evidence, R, rho):
    g = mint_deadline_aware(plan, modes, belief, budget, evidence, R, rho)
    C_ask  = cost_ask(g, belief)
    pi_rob = best_robust_plan(plan, belief, certify=c_ras_wm)
    C_plan = J(pi_rob) if pi_rob and plan_is_certified(pi_rob) else INF
    C_cons = cost_conservative(belief, plan)
    return argmin_certified({"ask": C_ask, "plan": C_plan, "conserve": C_cons})

# IP-271/272 RCM + SBA：默认开放 + 序贯预算（含期权价值）
def allocate_budget(plan, belief, evidence, R, budget):
    while budget.remaining > 0:
        cands = [(score(v, g, belief, evidence, R), v, g)
                 for v in unsettled_commitments(plan)
                 for g in info_candidates(v) if deadline_feasible(g, v)]
        if not cands: break
        s, v, g = max(cands)
        if s <= option_value_of_budget(plan, v, budget): break
        budget.spend(g); evidence += execute(g)
    return evidence, budget

# IP-276 主闭环（继承 R69，在「是否交互」处插入计划层）
def COMPASS_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi_proxy, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    belief = mode_posterior(modes)
    v = next_commitment(M.plan, belief)
    d_iv = M.dreu.estimate(M.plan, v, belief, M.Q)           # 区间界
    fused = M.jitf.fuse(v, M.evidence, M.R, M.rho, now)
    if fused and fused.conflict and v.commit == "irreversible":
        M.pcr.repair_or_stop(v); return M.safe_hold()        # 冲突 → 不停留于平均
    opt = M.taa.choose(M.plan, modes, belief, M.budget, M.evidence, M.R, M.rho)
    if opt == "ask":
        g = M.sba.allocate(M.plan, belief, M.evidence, M.R, M.budget)
        belief = M.cia.update_belief(modes, M.cia.execute(g))
        d_after = M.dreu.estimate(M.plan, v, belief, M.Q)
    elif opt == "plan":
        M.plan = M.iap.switch_to_robust(M.plan, belief); d_after = 0.0
    else:
        d_after = d_iv.hi
    U_floor = U_ale + (0.0 if opt != "conserve" else U_epi_proxy)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    if opt == "conserve": lam = max(lam, 0.8)
    A = M.ach.propose(x_prime, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    mode = select_mode(modes, d_after, lam)
    M.vqa_ii.submit_async(opt, g if opt == "ask" else None, d_iv, d_after, M.R, M.rho)
    return k, lam, mode, (U_ale, d_after)
```

## 4. 推导

**引理 19（DREU 严格细于熵代理）** A99 下 `DREU ≤ Q_max·√(H/2)`；存在 `H=log2` 而 `DREU=0` 的反例（两模态最优动作/价值相同）。系：高熵 ≠ 高后悔；R69 在「模糊但无关」处过度提问。

**引理 20（承诺单调性）** 执行不可逆 v 后，v 处分歧的分支不可达，价值函数与 m 无关 ⇒ `U_epi^act` 跨承诺点非增，且 d_v 后关于 Dep(v) 的信息 EVPI=0。系：及时融合最优；有 lead time 时最优获取点为 `d_v−lead`。

**引理 21（绕开支配区）** 令 `Δ_info(g)=DREU_before−E[DREU_after|g]−c(g)`。绕开支配提问 ⇔ `Δ_plan ≤ Δ_info(g*)`。R69 的 `Δ_plan=+∞` 只有问/保守；COMPASS 严格扩选项集。系：模态数上升时 `Δ_info` 涨而 `Δ_plan` 有界 ⇒ 高歧义/低代价区绕开必胜。

**引理 22（共模过度自信上界）** k 源共享潜误差、两两相关 ρ̄ 时，朴素融合的有效源数被高估至 k，KL 过量 ≤ `(k−1)ρ̄·Ī`；退火权重重置 `k_eff=1/(1+(k−1)ρ̄)`。R69 的「k 正交源」是 ρ̄=0 特例；未估 ρ 时证据纪律被共模误差整体击穿。

**定理 18（退化链与安全不退）** 定义 324 条件下 COMPASS→FLUID→（VoI≤c）R68，逐指令一致；绕开仅限 C-RAS-WM 认证计划、冲突裁决或停机、λ 单调不降 ⇒ 期望风险 ≤ FLUID ≤ R68。

**定理 19（序贯分配近似）** A101（条件独立 + DREU 削减自适应子模）下，deadline 感知惰性贪心达最优总削减的 `≥(1−1/e)`；预算期权价值等价于远期收益折扣，折扣目标仍子模，保证保持。R69 逐指令贪心是 `V_opt=0`、单节点退化。

**定理 20（冲突安全）** 关键变量 `conflict=1` 时强制「独立源裁决或不停机」，则错误承诺率 ≤ `δ_p·ρ̄^{k_eff−1}+ε_σ`，且高充分性模态的平均不能掩盖冲突 ⇒ 不会静默地在错误对象/意图上做不可逆承诺。

## 7. 本轮最大风险

**一句话**：COMPASS 把「该不该问」的裁判权从「歧义有多大」交给「计划说这歧义重不重要」——**一旦计划 DAG 或证据—计划关联矩阵本身错了（尤其当规划器与策略共享同一个错误世界模型，使 EVPI 被自洽地算成 0），系统会因为「计划说这里不重要」而理直气壮地不问；R69 的危险是追问幻影，R70 的危险是把该问的真问题判成无关，而不问比问错更隐蔽。**

**次级风险与缓解**：R 误标无关（定义 319 默认开放 + 反事实标定 + 覆盖证书）；共模误差伪装多源一致（定义 316 k_eff + E305）；承诺冲突被平均（定义 317 裁决/停机 + 定理 20）；EVPI 过贵（定义 323 anytime + WCET 降级）；绕开计划不安全（只在 C-RAS-WM 认证计划中切换 + 定理 18）；计划/价值模型自洽盲区（定义 320 归因 + ℰ_plan + E310，归因为计划错误即冻结 EVPI 资格并重规划）。
