### 第 4 轮灵感驱动研究记录

**灵感词**：移动底盘、触觉感知

**继承关系**：第 3 轮 CADVS-v3（IP-485~488）在 v2 三锚点（3DCF/MSRG/HICK）上追加末点锚 EEK 与记忆锚 LTEM，并用联邦聚合 FFA 做舰队级校准，形成五硬门 kc_evidence_forged_v3 = kc_coverage ∧ kc_physics ∧ kc_human ∧ kc_ee ∧ kc_mem，执行集 Exec_CADVS-v3 ⊆ Exec_CADVS-v2 ⊆ Exec_CADVS-v1 ⊆ Exec_v29。本轮不推翻 v3，而是针对「基座会动」与「接触可被空间分辨」两个新事实补强，形成 CADVS-v4（IP-489~492），执行集嵌套升级为 Exec_CADVS-v4 ⊆ Exec_CADVS-v3 ⊆ Exec_CADVS-v2 ⊆ Exec_CADVS-v1 ⊆ Exec_v29。

**直觉与动机**：

1. **移动底盘：把「空间锚」从静止世界系变成移动靶**。v3 的 Γ_3D 以世界体素表达，所有覆盖证书都隐含一个未写出的前提——「签发证书时与消费证书时，基座位姿相同且已知」。一旦底盘移动，里程计漂移、SLAM 跳变、轮地打滑、TF 时间戳过期都会让同一张证书在不同位姿下指向不同的物理空间；证书字节没变，但它所断言的空间已经不是原来的空间。更危险的是「证书重锚定」本身：把旧证书从签发位姿 T0 变换到当前位姿 T1，若漂移超出预算，变换后的证据就是伪证。引入基座保真证书 BPC 与基座硬门 kc_base，并给每张空间证书加「frame stamp + 漂移预算」，消费前必须通过重锚定检查。

2. **触觉感知：把「末点接触」从单点力阈值升级为空间分辨的接触模式**。v3 的 kc_ee 只有力/力矩阈值加一个二值 slip 标志，本质是「打滑已经发生才拒绝」。触觉阵列（如 GelSight/压阻阵列）可测接触斑几何、法向压力分布、切向/法向比 ρ、微振动前兆，从而在宏观打滑之前识别「滑动前兆」。引入触觉接触证书 TCC 与 kc_tactile，把安全边界从「滑后拦截」前移到「滑前拦截」，并给抓取稳定性一个可微的摩擦锥裕度 m_slip = 1 − ρ。

3. **移动 + 触觉的耦合：动基座在接触中运动会向末点注入惯性扰动**。一张在静止时通过 EEK/TCK 的接触，在基座加速、转弯、越障时可能瞬时超出摩擦锥或关节力矩上限。这不是把两个门简单相加能覆盖的：需要基座加速度、机械臂构型、接触 wrench 的联合动力学可行性证书 WCC，回答「此刻的基座运动下，任务所需接触是否仍在可行域内」。

**关键洞见**：v3 五锚回答「证据在哪 / 规则是否物理成立 / 谁背书 / 末点接触是否真实 / 这类情况历史上是否可靠」；v4 追加移动锚回答「此刻参考系是否还成立」（BPIK）、触觉锚回答「此刻接触模式是否仍可维持」（TCK），并用全身耦合锚回答「基座在动时接触是否仍可行」（WCC）。八硬门 kc_evidence_forged_v4 = kc_coverage ∧ kc_physics ∧ kc_human ∧ kc_ee ∧ kc_mem ∧ kc_base ∧ kc_tactile ∧ kc_wbc，fail-closed；软评分 ECS_v4 仅用于回退分级与仪表盘，不参与安全决策。

**形式化目标（增量）**：
1. 定义基座保真证书 BPC = (T_wb, Σ_b, v_b, ω_b, slip_wheel, tf_age, m_stab, t)，其中 T_wb ∈ SE(3) 为基座位姿估计、Σ_b 为其协方差、m_stab 为 ZMP 到支撑多边形的稳定裕度；硬门 kc_base = (tr(Σ_b^{pos}) ≤ σ_p,tol² ∧ σ_yaw² ≤ σ_ψ,tol² ∧ slip_wheel ≤ s_tol ∧ tf_age ≤ τ_tf ∧ m_stab ≥ m_stab,min)。
2. 定义证书重锚定算子 ReAnchor(C, T̂_wb(t0), T̂_wb(t), Σ_b)：把签发时的基座系证据变换到当前基座系，漂移 δ_drift = ‖log(T̂_wb(t0)⁻¹T̂_wb(t))‖ 超过 δ_tol 则证书作废（返回 ⊥），否则返回带误差界的重锚定证据。
3. 定义触觉接触证书 TCC = (c_patch, A_patch, p_n(·), τ_t, ρ_shear, incipient_slip, t)，ρ_shear = ‖τ_t‖/(μ·p̄_n)；硬门 kc_tactile = (‖c_patch − c_des‖ ≤ c_tol ∧ A_min ≤ A_patch ≤ A_max ∧ ρ_shear ≤ 1 − m_req ∧ ¬incipient_slip)。
4. 定义全身耦合证书 WCC = (w_req, W_feasible(x_b, q, q̇, a_b, q̈), m_w)，W_feasible 为摩擦锥线性化 ∧ 单边接触 ∧ 关节力矩上限 ∧ ZMP 约束的凸多面体；硬门 kc_wbc = dist(w_req, ∂W_feasible) ≥ m_w。
5. 定义 EFA-v4 八硬门与软评分 ECS_v4(x,t,r) = ECS_v3(x,t,r) · η_base · η_tactile，其中 η_base = exp(−δ_drift/δ_tol)、η_tactile = 1 − ρ_shear（冷启动/无触觉时取中性值，且此时 kc_tactile 不可被绕过）。
6. 定义 Exec_CADVS-v4 ⊆ Exec_CADVS-v3：在 v3 每条路径上追加 kc_base（每控制周期，因基座可能移动）、kc_tactile（每控制周期）与 kc_wbc（基座-臂协同运动时），故只缩不涨。

**本轮最大风险**：**移动参考系与接触状态的「双漂移」**——基座定位漂移让旧证书在新位姿下看似仍有效，触觉标定漂移让接触看似仍稳定，二者叠加时机器人会以高置信度消费一张参考系与接触事实都已失效的证书，而这种失效在证书日志里表现为「全门通过」。

## 2. 关键算法骨架

### IP-489 BPIK：基座保真证书与重锚定（控制环内，O(1)）

```python
@dataclass
class BasePoseIntegrityKernel:
    """BPIK：基座位姿/稳定完整性；kc_base 硬门，每控制周期 O(1)"""
    sigma_p_tol: float = 0.01      # m，位置估计标准差容忍
    sigma_psi_tol: float = 0.02    # rad，航向估计标准差容忍
    slip_tol: float = 0.05         # m/s，轮地滑移容忍
    tf_age_tol: float = 0.02       # s，TF 最大时鲜
    stab_margin_min: float = 0.03  # m，ZMP 到支撑边界最小裕度
    delta_drift_tol: float = 0.02  # m，证书签发后允许漂移

    def observe(self, T_wb: np.ndarray, Sigma_b: np.ndarray,
                v_b: np.ndarray, omega_b: np.ndarray,
                slip_wheel: float, tf_age: float,
                zmp: np.ndarray, support_poly: np.ndarray,
                t_now: float) -> BPC:
        """T_wb/Σ_b 来自里程计+IMU+SLAM 融合；zmp/support 来自足轮力分配"""
        m_stab = signed_dist_to_polygon(zmp, support_poly)
        return BPC(T_wb=T_wb, Sigma_b=Sigma_b, v_b=v_b, omega_b=omega_b,
                   slip_wheel=slip_wheel, tf_age=tf_age,
                   m_stab=m_stab, t=t_now)

    def kc_base(self, bpc: BPC) -> bool:
        """引理 41：通过 ⟹ 位姿不确定度、滑移、时鲜、稳定裕度均在容忍内"""
        return (np.trace(bpc.Sigma_b[:3, :3]) <= self.sigma_p_tol**2
                and bpc.Sigma_b[2, 2] <= self.sigma_psi_tol**2
                and bpc.slip_wheel <= self.slip_tol
                and bpc.tf_age <= self.tf_age_tol
                and bpc.m_stab >= self.stab_margin_min)

    def reanchor(self, cert, T0: np.ndarray, T1: np.ndarray,
                 Sigma_b: np.ndarray, t_now: float):
        """空间证书重锚定：T0 为签发位姿，T1 为当前位姿；漂移超预算返回 None"""
        drift = se3_log(inv(T0) @ T1)
        delta = float(np.linalg.norm(drift[:3]))
        if delta > self.delta_drift_tol:
            return None                     # 证书作废，fail-closed
        return cert.transformed(inv(T0) @ T1,
                                cov=Sigma_b + cert.cov)  # 协方差传播
```

### IP-490 TCK：触觉接触证书与滑动前兆（控制环内，O(1) 特征提取）

```python
@dataclass
class TactileContactKernel:
    """TCK：触觉阵列接触模式；kc_tactile 硬门，滑前拦截"""
    c_tol: float = 0.01        # m，接触斑质心偏移容忍
    A_min: float = 50.0        # mm²，最小有效接触面积
    A_max: float = 400.0       # mm²，最大有效接触面积
    m_req: float = 0.2         # 安全裕度：ρ_shear ≤ 1 − m_req
    incipient_thr: float = 0.9 # 滑动前兆剪切比阈值

    def features(self, tactile: np.ndarray, mu: float) -> TCC:
        """tactile: H×W 法向压力 + 2 通道切向；输出接触斑与剪切比"""
        p_n = tactile[..., 0]
        tau = tactile[..., 1:3]
        mask = p_n > 0.05 * p_n.max()
        c_patch = centroid(mask)
        A_patch = mask.sum() * taxel_area
        p_bar = p_n[mask].mean()
        tau_t = tau[mask].sum(axis=0)
        rho = float(np.linalg.norm(tau_t) / (mu * p_bar + 1e-9))
        incipient = rho >= self.incipient_thr or has_micro_vibration(tactile)
        return TCC(c_patch=c_patch, A_patch=A_patch, p_n=p_n, tau_t=tau_t,
                   rho_shear=rho, incipient_slip=incipient, t=t_now)

    def kc_tactile(self, tcc: TCC) -> bool:
        """引理 42：通过 ⟹ 接触斑/面积合法、剪切比留裕度、无滑动前兆"""
        return (np.linalg.norm(tcc.c_patch - tcc.c_des) <= self.c_tol
                and self.A_min <= tcc.A_patch <= self.A_max
                and tcc.rho_shear <= 1.0 - self.m_req
                and not tcc.incipient_slip)

    def slip_margin(self, tcc: TCC) -> float:
        return max(0.0, 1.0 - tcc.rho_shear)
```

### IP-491 WCC：全身耦合可行性（协同运动时，O(|W|) 多面体判定）

```python
@dataclass
class WholeBodyCouplingCertifier:
    """WCC：基座-臂-接触联合动力学；kc_wbc 硬门，防脱接触/防倾覆"""
    mu: float = 0.6
    tau_max: np.ndarray = field(default_factory=lambda: np.array([...]))
    zmp_poly: np.ndarray = field(default_factory=lambda: ...)
    margin: float = 0.05

    def feasible_wrench(self, x_b, q, qd, a_b, qdd) -> ConvexPolytope:
        """摩擦锥线性化 + 单边接触 + 关节力矩上限 + ZMP 约束 → 凸多面体"""
        A, b = [], []
        for k in friction_cone_facets(self.mu):          # |τ_t| ≤ μ p_n 的线性化
            A.append(k); b.append(0.0)
        A.append(-unilateral_row()); b.append(0.0)        # p_n ≥ 0
        A.append(torque_limit_rows(q, qd, a_b, qdd, self.tau_max))
        b.extend(torque_limit_bounds(q, qd, a_b, qdd, self.tau_max))
        A.append(zmp_rows(x_b, q, a_b)); b.extend(zmp_bounds(self.zmp_poly))
        return ConvexPolytope(np.vstack(A), np.concatenate(b))

    def kc_wbc(self, w_req: np.ndarray, W: ConvexPolytope) -> bool:
        """引理 43：通过 ⟹ 所需接触 wrench 距可行域边界 ≥ margin"""
        return W.signed_distance(w_req) >= self.margin
```

### IP-492 EFA-v4：八硬门 + 软评分 + 证据铸造流水线 v4

```python
@dataclass
class EvidenceForgingAssemblerV4:
    """EFA-v4：八硬门 fail-closed；软评分仅分级，不参与安全决策"""
    scf: SpatialCoverageFieldKernel
    msrg_cache: dict
    hic: HumanIntentCertificateKernel
    eek: EndEffectorFidelityKernel
    ltem: LongTermEpisodicMemory
    bpik: BasePoseIntegrityKernel
    tck: TactileContactKernel
    wcc: WholeBodyCouplingCertifier

    def hard_gate(self, x, t_now, rule_id, hic, eec: EEC, tcc: TCC,
                  bpc: BPC, w_req, W, cert, T0, T1,
                  object_class, geo_sig, theta_domain_fp) -> tuple[bool, str]:
        if self.hic.veto_active(hic):                 return False, 'HIC_STOP'
        if not self.bpik.kc_base(bpc):                return False, 'BASE_DRIFT'
        cert2 = self.bpik.reanchor(cert, T0, T1, bpc.Sigma_b, t_now)
        if cert2 is None:                             return False, 'CERT_STALE'
        if not self.scf.kc_coverage(x, t_now):        return False, 'COVERAGE_BLIND'
        s2rc = self.msrg_cache.get(rule_id)
        if s2rc is None or s2rc.verdict != 'accept' or s2rc.mu_pass < self.mu_S:
            return False, 'PHYSICS_UNPROVEN'
        if not self.eek.kc_ee(eec):                   return False, 'EE_UNPROVEN'
        if not self.tck.kc_tactile(tcc):              return False, 'TACTILE_UNSTABLE'
        if not self.wcc.kc_wbc(w_req, W):             return False, 'WBC_INFEASIBLE'
        pass_mem, eta_mem, novelty = self.ltem.query(
            object_class, geo_sig, theta_domain_fp, rule_id)
        if not pass_mem:                              return False, 'MEMORY_REJECT'
        return True, 'FORGED' + ('|NOVELTY' if novelty else '')

    def ecs_v4(self, x, t_now, rule_id, delta_drift, rho_shear,
               A_att=0.0, eta_mem=0.5) -> float:
        eta_base = float(np.exp(-delta_drift / self.bpik.delta_drift_tol))
        eta_tac = max(0.0, 1.0 - rho_shear)
        return self.ecs_v3(x, t_now, rule_id, A_att, eta_mem) * eta_base * eta_tac
```

### 集成流水线（v3 → v4）


## 4. 正确性论证（增量更新）

### 引理 41（移动参考系下的证书重锚定误差界）

**陈述**：设证书 C 在 t0 签发，其空间断言在世界系下对应点 p_w；签发与消费时的基座位姿估计分别为 T̂0、T̂1，真实位姿为 T0、T1，估计误差 e_i = T̂_i⁻¹T_i。经 ReAnchor 消费后，世界系位置误差满足
‖p̂_w − p_w‖ ≤ (‖e_0‖ + ‖e_1‖)·‖p_w‖ + δ_sensor，
其中 δ_sensor 为证书自身观测噪声。若 δ_drift = ‖log(T̂0⁻¹T̂1)‖ ≤ δ_tol 且 kc_base 通过，则误差被 δ_tol 与 Σ_b 界约束；否则 ReAnchor 返回 ⊥，证书不可被消费。

**证明**：p̂_w = T̂1 T̂0⁻¹ p_w = (T̂1T̂0⁻¹T0T1⁻¹) p_w。由 SE(3) 左不变度量与三角不等式，‖T̂1T̂0⁻¹T0T1⁻¹‖ ≤ ‖e_0‖ + ‖e_1‖；对点作用再乘 ‖p_w‖，叠加证书噪声得界。δ_drift > δ_tol 时直接拒证，故不存在「漂移超界仍被消费」的路径。∎

**工程含义**：把 v3 中「空间证书永久有效」改为「空间证书带参考系时效与漂移预算」，消除了「基座移动后旧覆盖证书被误用」的失效模式。

### 引理 42（触觉滑动前兆的提前量界）

**陈述**：设 Coulomb 摩擦下宏观打滑判据为 ‖τ_t‖ ≥ μ p_n，定义 ρ = ‖τ_t‖/(μ p_n)。若 kc_tactile 在 ρ ≥ 1 − m_req 或检测到微振动前兆时即拒绝，则在切向载荷增长率有界（‖dτ_t/dt‖ ≤ L_τ）的条件下，拒绝时刻比宏观打滑至少提前
Δt ≥ m_req·μ·p_n / L_τ。
触觉测量噪声为零均值、方差 σ_t 时，误报率由 ρ 估计的集中不等式控制，随采样数增加而指数下降。

**证明**：宏观打滑发生在 ρ = 1；由 ρ 的单调增长（dρ/dt = (d‖τ_t‖/dt)/(μp_n) ≤ L_τ/(μp_n)），从 ρ = 1−m_req 到 1 所需时间下界即上式。噪声部分由次高斯集中给出。∎

**工程含义**：v3 的 kc_ee 只能在 slip=1 后拒绝（滑后拦截），TCK 将边界前移到滑前，为「松爪重抓 / 降低切向载荷」争取到毫秒~数十毫秒级反应窗口。

### 引理 43（全身耦合可行域的动态保持界）

**陈述**：若在控制周期 Δt 内 kc_wbc 通过，即 dist(w_req, ∂W_feasible) ≥ m_w，且基座加速度 ‖a_b‖ ≤ a_max、关节力矩 ‖τ‖ ≤ τ_max、W_feasible 对状态变化的 Hausdorff 变化率有界为 L_W，则在整个周期内接触 wrench 不越出摩擦锥、ZMP 不越出支撑多边形，前提为 L_W·Δt ≤ m_w。

**证明**：W_feasible 为凸多面体，其到 w_req 的有符号距离对参数是 1-Lipschitz 的；一个周期内可行域最多移动 L_W·Δt，小于裕度 m_w 时 w_req 仍在可行域内。摩擦锥与 ZMP 约束均已线性化进 W_feasible，故两类越界均被同一距离界覆盖。∎

**工程含义**：把「静止时接触可行」升级为「基座加速/转弯时接触仍可行」，覆盖移动操作中惯性扰动导致脱接触与倾覆的失效模式。

### 定理 v4（执行集收缩与八锚点补全）

**陈述**：在以下假设下：(B1) v3 的末端传感器噪声模型成立；(B2) LTEM 表忠实反映历史执行结果；(B3) 基座位姿误差模型（协方差）与轮地滑移模型准确；(B4) 触觉标定与摩擦系数 μ 的估计在允许漂移内；(B5) 全身动力学模型对 W_feasible 的刻画误差有界（L_W·Δt ≤ m_w）；(B6) 继承 v3 的 (A1′)~(A3′)。则：
(i) Exec_CADVS-v4 ⊆ Exec_CADVS-v3 ⊆ Exec_CADVS-v2 ⊆ Exec_CADVS-v1 ⊆ Exec_v29（严格收缩）；
(ii) 漂移超界的旧空间证书被消费的概率为 0（引理 41 的 fail-closed 分支）；
(iii) 宏观打滑被提前至少 Δt ≥ m_req·μ·p_n/L_τ 拦截（引理 42）；
(iv) 基座协同运动下的脱接触/倾覆由 m_w 界约束（引理 43）；
(v) 八硬门 fail-closed，任一不通过即拒，仅 HIC veto 旁路至 S_stop。

**证明**：(i) v4 在 v3 每条路径上追加 kc_base（每周期）、kc_tactile（每周期）与 kc_wbc（协同运动时），故只缩不涨；严格性由「v3 通过但基座漂移/触觉前兆/全身不可行」的非空失效集保证。(ii) 由 ReAnchor 的 δ_drift > δ_tol → ⊥ 分支。(iii)~(iv) 分由引理 42、43。(v) 由 EFA-v4 hard_gate 的合取结构与短路顺序。∎

**诚实声明**：(B3)~(B5) 是本轮最脆弱假设。基座位姿协方差常被滤波器低估（过度自信），导致 kc_base 误放；触觉标定随磨损/温漂缓慢失效，使 ρ_shear 被系统性低估；全身模型忽略未建模柔顺与地面不平，使 W_feasible 偏乐观。缓解：协方差膨胀与卡方一致性检验、触觉在线自校准与交叉模态（力/力矩 vs 触觉）仲裁、W_feasible 保守膨胀（m_w 取离线标定的下分位）、高风险移动操作强制停靠后再执行。

## 7. 本轮最大风险（最终确认）

**一句话**：**移动参考系与接触状态的「双漂移」**——基座定位漂移让旧证书在新位姿下看似仍有效，触觉标定漂移让接触看似仍稳定，二者叠加时机器人会以高置信度消费一张参考系与接触事实都已失效的证书，而这种失效在证书日志里表现为「全门通过」。
