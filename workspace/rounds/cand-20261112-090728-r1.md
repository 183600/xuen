# 第 60 轮（承接第 59 轮「执行接地层」IP-145~151；灵感循环第 1 轮；本轮灵感：「技术路线图」×「数据质量」）

> 第 59 轮把「证据承诺」一路下沉到执行物理层：BUQ 在线辨识电机结构性不确定性、ERTC 把嵌入式时序变成硬契约、EEIS 把 δ_f 编译成带证书的阻抗参数、CLEP 让执行实测回传为第 5 模态。但它（以及此前 58 轮）仍默认了两个更深的元假设：**(i)「已实现 = 已就绪」**——六十轮的 IP 像不断加高的纸牌塔，却没有一张真正的「就绪度地图」：哪些能力可部署、依赖谁、接口保证什么、从影子模式到自主该按什么顺序解锁；**(ii)「数据 = 无前提的真值」**——共形覆盖、后验校准、KG 记忆、安全微调、执行辨识，全部建立在「校准/评估数据是可交换、有代表性、时鲜、标签正确、无重复、可溯源、无泄漏」之上，而这些恰恰是**数据质量**的各个维度。只要其中任一维度静默失效，所有统计保证都会在**没有任何运行时告警**的情况下退化——这是「证书级的 GIGO」。本轮两个灵感精准击中这两个元假设：**技术路线图**要求把能力堆叠还原为「能力依赖 DAG × 成熟度阶梯 × 门控谓词 × 分叉点」；**数据质量**要求把数据从「原料」升级为「带不确定度的被测量」。核心命题：**「把『能力是否可部署』从工程直觉升级为『证据成熟度 × 数据成熟度』的双门链；让技术路线图成为可审计的能力图谱，让数据质量成为可测量、可传播、可证书化的第一等不确定性来源——路线图里程碑只能由『数据质量证书背书的证据』解锁，而数据采集本身也必须被路线图规划（数据飞轮 + 数据负债）。」**

核心矛盾：

- **H35（路线图幻觉·能力成熟度 ≠ 已实现）**：系统已累积 60 轮、上百个 IP，但它们之间只有口头依赖：没有显式 CRL（能力就绪等级）、没有依赖 DAG、没有接口契约、没有门控谓词、没有分叉/回退路径。于是「系统就绪」等于「所有部件都写了」，集成风险无上界；更糟的是，能力组合既不满足**最弱链路律**（组合就绪 ≤ 最不就绪的依赖），也不满足**风险求和律**（组合 δ ≤ 各子能力 δ 之和）。没有路线图，就既无法证明「整体安全」，也无法决定「下一个该做什么」。
- **H36（数据质量传导·保证建立在未言明的前提上）**：共形预测的覆盖保证依赖**可交换性**；校准依赖**标签正确**与**分布一致**；KG 记忆依赖**去重与溯源**；操作剖面覆盖依赖**代表性**；证据鲜度依赖**时鲜**；再认证依赖**无泄漏**。这些全都是数据质量维度，却被当作「清洗一下就好」的预处理。实际上每一个维度缺陷都会映射为一条**可量化的保证退化**（n_eff 缩水、覆盖损失 ε_shift、ECE 膨胀、OOD 假阴性升高）。不测量、不传播、不门控，就等于把安全证明建在流沙上。
- **H37（路线图×数据质量耦合·飞轮、负债与投资配置）**：造能力与造数据是两条耦合的投资流。CRL3 影子部署不只是安全阶梯，更是一台**数据生产机**（飞轮）；而用低质量数据抢过某个门，则是在向未来借安全（**数据负债**），且负债会沿 DAG 扇出复利。因此路线图规划本质是「带数据生产边的、带债务利息的、依赖优先的联合投资组合优化」——顺序错了，数据永远补不上；质量欠了，量子再大也认证不了。

## 0. 直觉与动机

**灵感 1（技术路线图 → 能力路线图图谱 CRG）**
直觉：真正的技术路线图不是甘特图，而是**依赖图 + 成熟度阶梯 + 门控谓词 + 分叉点**。映射到本系统：能力是节点 c∈C；依赖/组合是边 E⊆C×C（必须是 DAG，否则循环认证）；每个节点带成熟度 ℓ(c)∈{0..6}（类比 TRL：0 规格→1 单元测试→2 仿真集成→3 影子→4 有人监督→5 受限 ODD 自主→6 全剖面自主）；每次升级由「更强证据 + 更真实操作剖面 + 更高质量数据」共同守卫；每个节点还带**接口契约** Γ(c)=(输入、输出、保证 δ_c、假设 A_c、数据质量证书)。关键洞见：**就绪度按最弱链路组合、风险按求和组合**——所以路线图的 DAG 同时是一个风险放大器，必须在图上做风险预算分配，而不是在系统顶层拍一个 δ。

**灵感 2（数据质量 → 数据质量表达式 DQX 与效应传播 DQE）**
直觉：数据不是原料，而是**带不确定度的被测量**。数据质量至少有十个可操作维度：完整性、准确性、一致性、时鲜性、唯一性（去重）、有效性、代表性（操作剖面覆盖）、可溯源性、标签质量、无泄漏性。每一个维度都能翻译成一条统计后果：重复样本 → 有效样本量 n_eff 与共形分位数方差膨胀（设计效应 DEFF）；非可交换/分布漂移 → 覆盖损失 ε_shift；标签噪声 → ECE 膨胀；陈旧 → 漂移；非代表 → 分层覆盖缺口；溯源断裂 → 该部分样本只能按最坏情况计入；泄漏 → 直接**否决认证**。关键洞见：**质量压倒数量**——低于某个「认证地板」时，无论样本量多大，有效证据都趋于零（E_eff→0），因此不能靠堆量来洗白脏数据。

**灵感 3（技术路线图 × 数据质量 → 路线图-数据联合投资 RDP）**
直觉：CRL3 影子阶段的价值被严重低估——它既是安全阀，也是**数据工厂**。把「能力 c 在影子阶段产生数据 → 喂给依赖它的下游能力 c′」建成**数据生产边**，路线图就从「串行开发」变成「带内部供应的增值链」。反之，为了赶里程碑而用低质量数据过门，就是**数据负债**：负债额 = 未解决的 DQ 赤字 × 依赖扇出 × 年龄；利息 = 下游重认证成本随时间增长。于是规划问题变成：在依赖优先、预算、数据生产边、认证地板约束下，同时选择**能力建设顺序**与**数据投资配置**，最大化带风险惩罚与债务惩罚的「已就绪能力价值」。

**灵感 4（合流 → 路线图-数据闭环 RDC 与双门）**
直觉：每个里程碑跑同一个闭环——**能力门（证据成熟度）× 数据门（数据质量证书）→ CRL 升级/降级**。数据门失败 ⇒ 进入**数据补救**（采集/标注/去重/补溯源/重采样），而不是静默降级；能力门失败 ⇒ 进入**设计反馈**（降 ODD、加冗余、改接口、分叉或缩减范围）。任何 DQC 过期都触发**自动再认证**（数据会「变旧」）。关键纪律：路线图证据 `EV-road` 与数据证据 `EV-dq` **只用于部署范围与就绪度决策，绝不替代任何单次接触的安全证据**——这是一条新的「时间尺度证据层级」，防止用「过去数据很好、整体很成熟」为「此刻这次高风险接触」背书。

**灵感 5（路线图证书 J_road → JCPS++++ 扩展）**
直觉：整个路线图状态应是一份可审计的证书：能力 DAG 快照、CRL 向量、门控决策日志、DQC 证书链、数据负债账本、投资组合计划、再认证日程、分叉日志。云端下发「能力模板 / CRL 评分卡 / DQ 测量协议 / 组合求解器配置 / 评估数据集」，边端回传「DQC / 门控结果 / 负债账本 / 飞轮数据」，经隔离区校验后才允许晋升——把「组织级技术治理」编译进机器人自身的证据体系。

## 1. 形式化定义（增量：定义 153–160）

**定义 153（能力路线图图谱 CRG）** CRG=(C, E, ℓ, Γ)，C 为能力节点集，E⊆C×C 为依赖/组合边且构成 DAG，ℓ:C→{0,…,6} 为能力就绪等级 CRL，Γ(c)=(In_c, Out_c, δ_c, A_c, dqc_id_c) 为接口契约（含保证与前提假设、所依数据质量证书）。**依赖可达性不变式（RRI）**：∀c，ℓ(c) ≤ 1 + min_{d∈pred(c)} ℓ(d)。直觉：集成到第 l 级至少要求直接前置能力已在第 l−1 级，故最多领先最不就绪前置一级。**组合律**：若 c=compose(c_1,…,c_k)，则（弱链路）ℓ(c) ≤ min_i ℓ(c_i)，（风险求和）δ_c ≤ Σ_i δ_{c_i}，且接口兼容谓词 Compat(Out_{c_i}, In_{c_j})=true。**分叉点** f∈F：当某能力在预算/风险内不可达时，路线图须显式记录降级目标、替代路径或缩减 ODD，而非隐式放弃。

**定义 154（能力成熟度门 CMG）** 升级谓词 Promote(c, l→l+1) 成立当且仅当四门同时通过：
```
(G-ev) 存在证据集合，其类别强度 ≥ E_req(c,l+1)，且各证据自身证据门通过；
(G-dq) 该证据所用每个数据集 DQC 未过期，且有效证据强度 E_eff ≥ E_min(c,l+1)；
(G-dep) ∀d∈pred(c): ℓ(d) ≥ l，且接口兼容 + 集成回归套件通过；
(G-risk) 在当前数据质量下 δ_c ≤ δ_budget(c,l+1)。
```
**降级（级联）**：回归失败 / DQC 过期 / 事故 / 任一前置降级 ⇒ ℓ(c):=min(ℓ(c), l−1)，并沿 E 的后继传播。每次决策产出 `Cert_crl(c,l,evidence_ids,dqc_ids,δ_c,version,timestamp)`。禁止跳级：Promote 只能 l→l+1。

**定义 155（数据质量表达式 DQX）** 数据集 D（按操作剖面分层）的数据质量向量 Q(D)=(Q_comp, Q_acc, Q_cons, Q_time, Q_uniq, Q_valid, Q_rep, Q_prov, Q_label, Q_leak)∈[0,1]^10，各维测量协议：
```
Q_comp  = 1 − Σ_f w_f·missing_f               （完整性，按字段关键度加权）
Q_acc   = Beta⁻¹(α; a_ok, a_bad+1)             （准确性，审计样本上对真值的下置信界）
Q_cons  = 1 − contradiction_rate              （一致性，跨源/跨模态矛盾率）
Q_time  = exp(−τ_age/τ_half)                  （时鲜性，或 1[τ_age≤τ_max]）
Q_uniq  = 1 − dup_ratio                       （唯一性，MinHash/嵌入近重复检测）
Q_valid = valid_fraction                      （有效性，schema+物理 plausibility）
Q_rep   = 1 − max_s |p_D(s) − q_target(s)|    （代表性，操作剖面上界 TV）
Q_prov  = prov_complete_fraction              （可溯源性，完整可验证血缘链占比）
Q_label = label_accuracy_lb                   （标签质量，审计/共识下界）
Q_leak  = 1 − leakage_score                   （无泄漏性，训练-评估重叠/时序/自适应选择）
```
**不做标量平均**（避免一个维度极差被其余维度掩盖），保留向量并定义**盖门偏序** Q≽Q′ ⇔ ∀dim Q_dim≥Q′_dim；以及**认证地板** Q_min(l)（按 CRL 分级）。

**定义 156（数据质量效应传播 DQE）** 把 DQ 缺陷映射为统计保证的退化：
```
设计效应（重复样本）：DEFF = 1 + (m̄−1)·ρ_intra，n_eff = n·Q_uniq/DEFF；
分布漂移（非可交换/非代表/陈旧）：ε_shift = C_rep·(1−Q_rep) + C_age·(1−Q_time)；
标签噪声：δ_label = L_lip·(1−Q_label)；
溯源缺口：δ_prov = (1−Q_prov)·δ_max（未溯源部分按最坏情况计入）；
有效性/完整性缺口：缺失层直接判 OOD（不得声明该层覆盖）；
泄漏：若 Q_leak < Q_leak_min ⇒ DQC 直接无效（硬否决，非可补偿）。
Δ_dq = clip(ε_shift + δ_label + δ_prov + δ_dup(n_eff), 0, 1)
E_eff = E_raw·(1 − Δ_dq)                       （有效证据强度）
```
**数据诚实的共形界**：在 DQ 缺陷下，覆盖率 cov ≥ 1 − α − Δ_dq（对可交换性缺陷只能给出上界损失，不能「修复」；补救只能靠再加权共形且权重有界）。**质量压倒数量定理（非正式）**：若任一维 Q_dim < Q_min,dim(l)，则 E_eff:=0，与 n 无关——低于认证地板，样本量再大也无法解锁下一级。

**定义 157（数据质量证书 DQC）** DQC=(dataset_id, version, provenance_chain_hash, Q 向量及置信, n, n_eff, DEFF, shift_bounds, label_audit, leakage_audit, split_manifest, expiry T_exp, signature)。内容寻址、不可篡改；**派生数据集必须带血缘边并重算 DQ**（禁止「继承信任」）。任一维低于对应地板或已过期 ⇒ 该 DQC 对所有依赖它的证据失效。

**定义 158（路线图-数据联合投资 RDP）** 决策变量：能力建设序 π（拓扑序+分级推进）、数据投资 x（各剖面层的采集/标注/清洗/补溯源投入）、目标 CRL 向量。优化：
```
maximize  Σ_c w_c·u(ℓ(c)) − λ_risk·Σ_c δ_c − λ_debt·Debt
s.t.      π 尊重 DAG 依赖优先
          Σ_c cost_cap(c; π) + Σ_stratum x·cost_data ≤ B_cap + B_data
          ℓ(c) 可由 E_eff(x) 解锁，且 Q(x) ≽ Q_min(ℓ(c))
          数据生产边：capability c 在 CRL3 影子阶段产出数据，供其后继能力使用
          Debt = Σ_{未解决赤字 i} deficit_i · fanout_i · age_i（沿 DAG 扇出与账龄）
```
这是「依赖优先调度 + 带内部供应的背包」问题，NP-hard；按 DAG 分层后做拉格朗日/价值密度贪心或小规模 MILP。输出 `Plan_road=(π, x, CRL 目标, 门控日程, 再认证日程, 债务偿还计划)`。

**定义 159（路线图-数据闭环 RDC）** 每个里程碑执行：
```
① 目标前沿 ← 下一批候选能力；检查 RRI 与接口兼容
② DQC 审计所有评估/校准数据 → Q, Δ_dq, E_eff（必要时触发补救）
③ 跑双门：能力门（证据强度）+ 数据门（DQC）；CRL3 影子试验产数据
④ 决策：晋升 / 保持 / 级联降级 / 数据补救 / 设计反馈（降 ODD/加冗余/分叉/缩减）
⑤ 若因数据失败 ⇒ 排补救计划；若因能力失败 ⇒ 进设计反馈集
⑥ 更新负债账本、DQC 过期时刻、重规划 π
⑦ 产出 EV-road、EV-dq、Cert_crl
```
**单调保守性**：数据/证据变差 ⇒ CRL 不升、部署范围不扩；任何放宽须走再认证。闭环在有限里程碑内终止于 {晋升、保持、级联降级、数据补救、设计反馈、缩减范围}。

**定义 160（路线图证书 J_road 与 JCPS++++）** J_road=(CRG 快照, CRL 向量, 门控决策日志, DQC 链, 负债账本, Plan_road, 再认证日程, 分叉日志, version, signature)。JCPS 输出在 JCPS++ 后追加：
```
(..., ξ_exec, C_rt, Cert_eeis, EV_exec_latest, B_exec_snapshot, M_rt_status,
 CRL_vector, Cert_crl, DQC_latest, Δ_dq_vector, E_eff_vector,
 roadmap_plan_id, debt_balance, J_road_id)
```
云边协议 CEB++++++：云端下发能力模板/CRL 评分卡/DQ 测量协议/组合求解器配置/评估数据集 → 边端影子运行并回传 DQC/门控结果/负债账本/飞轮数据 → 隔离区校验「RRI 成立 ∧ 双门通过 ∧ Q≽Q_min ∧ 无泄漏」→ 通过才晋升，失败即回滚并进设计反馈。

## 2. 本轮的关键洞见（为什么这不是又一次「加一层」）

1. **路线图是风险放大器，不是装饰**：δ_c ≤ Σ δ_children、ℓ_c ≤ min ℓ_deps。这意味着系统级风险可以**从 DAG 自上而下精确分解**，也意味着一个低就绪的前置能力会拖垮所有后继——因此风险预算必须在图上分配，而不是在顶层拍脑袋。
2. **数据质量是「证据的乘性折扣」，不是预处理**：E_eff=E_raw·(1−Δ_dq)。所有证据门改用 E_eff 与 Q_min 地板后，数据质量被纳入证据演算本身，而不是外挂的清洗步骤。
3. **质量压倒数量**：认证地板以下 E_eff≡0——这条定理直接击碎了「多采点数据就能过」的工程惯性，也为「何时必须停下来补数据」提供了硬判据。
4. **飞轮与负债是同一枚硬币**：影子部署同时生产数据（资产）与积累未验证假设（负债）；路线图必须同时安排「增值」和「还债」。
5. **证据的时间尺度分层**：EV-road/EV-dq 管「能不能部署到这一级」，EV-probe/EV-xmodal/EV-exec 管「这一次接触安不安全」。两者不可互相顶替——过去的数据成熟不等于此刻的接触安全。

## 3. 本轮最大风险

**一句话**：本轮把「能力路线图」与「数据质量」接进安全论证链，但**整个方案的地基是「DQ 可被诚实测量」**——一旦 DQ 指标被 Goodhart 化（为过门而优化指标本身）、或 DQE→Δ_dq 映射偏乐观（漂移界低估、标签审计样本过小、泄漏检测漏报、近重复漏检），「数据门」就会退化成橡皮章，并被依赖 DAG 的扇出效应放大成整条下游路线图的系统性虚假认证；因此必须以「独立 DQ 审计与隔离区、Δ_dq 保守上界、泄漏硬否决、认证地板、DQC 过期强制再认证、EV-road/EV-dq 绝不替代单次接触证据、负债账本公开可审计」为护栏，宁可路线图推进慢，也绝不把「脏数据 + 大样本」认证成「就绪」。

```python
from dataclasses import dataclass, field

CRL_NAMES = {0: "SPEC", 1: "UNIT", 2: "SIM_INTEGRATED", 3: "SHADOW",
             4: "SUPERVISED", 5: "RESTRICTED_AUTONOMY", 6: "FIELD_AUTONOMY"}

@dataclass
class CapabilityNode:
    name: str
    level: int = 0
    deps: list = field(default_factory=list)
    contract: dict = field(default_factory=dict)   # In/Out/delta/A/dqc_id
    crl_history: list = field(default_factory=list)

class CapabilityRoadmapGraph:
    def __init__(self):
        self.nodes = {}
        self.edges = set()
        self.forks = []          # 分叉点：能力不可达时的显式替代/缩减记录

    def add_capability(self, node, deps=()):
        self.nodes[node.name] = node
        for d in deps:
            assert d in self.nodes, f"unknown dependency {d}"
            self.edges.add((d, node.name))
            node.deps.append(d)
        assert self._is_dag(), "dependency graph must remain a DAG"

    def _is_dag(self):
        indeg = {n: 0 for n in self.nodes}
        for _, v in self.edges: indeg[v] += 1
        q = [n for n, d in indeg.items() if d == 0]; seen = 0
        while q:
            u = q.pop(); seen += 1
            for a, b in self.edges:
                if a == u:
                    indeg[b] -= 1
                    if indeg[b] == 0: q.append(b)
        return seen == len(self.nodes)

    def check_rri(self):
        """依赖可达性不变式：ℓ(c) ≤ 1 + min_dep ℓ(d)"""
        for c in self.nodes.values():
            if c.deps:
                min_dep = min(self.nodes[d].level for d in c.deps)
                if c.level > min_dep + 1:
                    return False, (c.name, c.level, min_dep)
        return True, None

    def composed_contract(self, comp_name, parts):
        """组合律：弱链路就绪 + 风险求和 + 接口兼容"""
        for a, b in zip(parts, parts[1:]):
            assert self._compatible(self.nodes[a], self.nodes[b]), \
                   f"interface mismatch {a}->{b}"
        level = min(self.nodes[p].level for p in parts)
        delta = sum(self.nodes[p].contract["delta"] for p in parts)
        return {"level": level, "delta": delta,
                "assumptions": set().union(*(self.nodes[p].contract["A"] for p in parts))}

    def _compatible(self, n1, n2):
        return set(n1.contract.get("Out", [])) >= set(n2.contract.get("In", []))
```

```python
class CapabilityMaturityGate:
    def __init__(self, crg, evidence_gate, dq_engine):
        self.crg = crg
        self.ev_gate = evidence_gate      # 复用第 59 轮七/八类证据门
        self.dqe = dq_engine

    def promote(self, cname, evidence_set, delta_budget):
        c = self.crg.nodes[cname]
        l = c.level + 1
        if l > 6:
            return False, "already_max_level", None
        # G-ev：证据类别强度
        if not all(self.ev_gate.passes(e, level=l) for e in evidence_set):
            return False, "G-ev_insufficient", None
        # G-dq：DQC 有效 + 有效证据强度达标
        dqcs = [e.dqc for e in evidence_set]
        if any(d is None or d.expired() for d in dqcs):
            return False, "G-dq_expired_or_missing", None
        e_eff = min(self.dqe.effective_strength(e.raw_strength, d) for e, d in zip(evidence_set, dqcs))
        if e_eff < self.ev_gate.E_min(cname, l):
            return False, f"G-dq_low_Eeff:{e_eff:.3f}", None
        # G-dep：RRI + 接口兼容 + 回归套件
        if any(self.crg.nodes[d].level < l - 1 for d in c.deps):
            return False, "G-dep_prereq_low", None
        if not self._regression_passed(cname):
            return False, "G-dep_regression_fail", None
        # G-risk：当前数据质量下风险预算
        delta_c = self._composed_delta(cname)
        if delta_c > delta_budget(l):
            return False, f"G-risk_delta:{delta_c:.2e}", None
        # 通过：晋升 + 记录证书
        c.level = l
        cert = CertCRL(cname, l, [e.id for e in evidence_set],
                       [d.id for d in dqcs], delta_c, version=self._next_version(cname))
        c.crl_history.append(cert)
        return True, "promoted", cert

    def demote_cascade(self, cname, reason):
        """任一前置/自身降级 ⇒ 沿后继传播，保证 RRI 恢复"""
        changed = []
        stack = [cname]
        while stack:
            n = stack.pop()
            c = self.crg.nodes[n]
            if c.level == 0:
                continue
            c.level -= 1
            changed.append((n, c.level, reason))
            for a, b in self.crg.edges:
                if a == n:
                    stack.append(b)
        return changed

    def _composed_delta(self, cname):
        c = self.crg.nodes[cname]
        return c.contract["delta"] if not c.deps else \
               max(c.contract["delta"], sum(self._composed_delta(d) for d in c.deps))
```

```python
class DataQualityExpression:
    def __init__(self, protocol):
        self.p = protocol    # 每维的测量协议与置信参数

    def measure(self, dataset, target_profile):
        q = {}
        q["Q_comp"]  = self._completeness(dataset)
        q["Q_acc"]   = self._accuracy_lb(dataset)        # Beta 下界
        q["Q_cons"]  = 1.0 - self._contradiction_rate(dataset)
        q["Q_time"]  = self._timeliness(dataset)
        q["Q_uniq"]  = 1.0 - self._dup_ratio(dataset)    # MinHash/embedding 近重复
        q["Q_valid"] = self._valid_fraction(dataset)
        q["Q_rep"]   = 1.0 - self._profile_tv(dataset, target_profile)
        q["Q_prov"]  = self._provenance_complete_frac(dataset)
        q["Q_label"] = self._label_quality_lb(dataset)   # 审计/共识
        q["Q_leak"]  = 1.0 - self._leakage_score(dataset) # 训练-评估重叠/时序/选择偏差
        n, deff, rho = self._duplication_stats(dataset)
        return DQVector(q=q, n=n, DEFF=deff, rho_intra=rho,
                        strata=self._strata(dataset),
                        shift_bounds=self._shift_bounds(dataset, target_profile))

    def dominates(self, q, q_min):
        """盖门偏序：逐维不低于地板"""
        return all(q[k] >= q_min[k] for k in q_min)

    def _profile_tv(self, dataset, target_profile):
        # 操作剖面 TV：按层做 |p_D(s)-q(s)|，取最大层
        return max(abs(dataset.stratum_frac(s) - target_profile.frac(s))
                   for s in target_profile.strata)
```

### IP-155 DQE（数据质量效应传播）

```python
class DataQualityEffect:
    def __init__(self, constants):
        self.C = constants   # C_rep, C_age, L_lip, delta_max, Q_leak_min, Q_min table

    def propagate(self, dq):
        deff = dq.DEFF
        n_eff = dq.n * dq.q["Q_uniq"] / deff
        eps_shift = self.C.C_rep * (1 - dq.q["Q_rep"]) \
                  + self.C.C_age * (1 - dq.q["Q_time"])
        delta_label = self.C.L_lip * (1 - dq.q["Q_label"])
        delta_prov  = (1 - dq.q["Q_prov"]) * self.C.delta_max
        # 重复样本导致共形分位数方差膨胀的保守附加项 ∝ 1/sqrt(n_eff)
        delta_dup = self.C.C_dup / max(np.sqrt(n_eff), 1.0)
        delta_dq = float(np.clip(eps_shift + delta_label + delta_prov + delta_dup, 0, 1))
        leak_veto = dq.q["Q_leak"] < self.C.Q_leak_min
        return DQEffect(n_eff=n_eff, delta_dq=delta_dq, eps_shift=eps_shift,
                        delta_label=delta_label, delta_prov=delta_prov,
                        delta_dup=delta_dup, leak_veto=leak_veto)

    def effective_strength(self, raw_strength, dqc):
        eff = self.propagate(dqc.dq)
        if eff.leak_veto or not self._above_floor(dqc.dq, dqc.target_level):
            return 0.0     # 质量压倒数量：地板以下 E_eff≡0
        return raw_strength * (1.0 - eff.delta_dq)

    def conformal_guarantee(self, alpha, dqc):
        """数据诚实的覆盖下界：cov ≥ 1 − α − Δ_dq"""
        eff = self.propagate(dqc.dq)
        if eff.leak_veto:
            return None    # 不可认证
        return max(0.0, 1.0 - alpha - eff.delta_dq)

    def conformal_quantile_index(self, n, alpha):
        """用 n_eff 而非 n 取分位数索引，避免重复样本伪造样本量"""
        ne = max(int(n), 1)
        return int(np.ceil((ne + 1) * (1 - alpha)))

    def _above_floor(self, q, level):
        return all(q[k] >= self.C.Q_min[level].get(k, 0.0) for k in q)
```

```python
class RoadmapDataPortfolio:
    def __init__(self, crg, dqe, cost_model):
        self.crg, self.dqe, self.cost = crg, dqe, cost_model

    def optimize(self, targets, budget_cap, budget_data, risk_model):
        layers = self._topological_layers(self.crg)        # DAG 分层
        # 每层内：按 (能力价值密度 / 数据缺口成本) 做贪心；层间严格依赖优先
        plan = []
        remaining_cap, remaining_data = budget_cap, budget_data
        debt = 0.0
        for layer in layers:
            candidates = self._rank_by_value_density(layer, targets, remaining_data)
            for cname in candidates:
                if self.crg.nodes[cname].level >= targets.get(cname, 0):
                    continue
                cost_c = self.cost.capability_cost(cname)
                data_need = self._data_investment_need(cname, targets[cname])
                if cost_c > remaining_cap:
                    plan.append(("hold", cname, "cap_budget")); continue
                if data_need > remaining_data:
                    # 预算不足：要么延期补数据，要么显式缩减目标（分叉）
                    plan.append(("defer_data", cname, data_need))
                    debt += self._debt_of(cname)     # 记录负债，不静默过门
                    continue
                remaining_cap -= cost_c
                remaining_data -= data_need
                plan.append(("build", cname, {"cap": cost_c, "data": data_need}))
                # 数据生产边：影子阶段为后继供数
                for succ in self._successors(cname):
                    self._credit_flywheel(succ, cname)
        if debt > risk_model.debt_limit:
            return None, "debt_infeasible"     # 诚实不可行，而非硬凑
        return PlanRoad(plan, remaining_cap, remaining_data, debt), "ok"

    def _topological_layers(self, crg):
        indeg = {n: 0 for n in crg.nodes}
        for _, v in crg.edges: indeg[v] += 1
        layers, frontier = [], [n for n, d in indeg.items() if d == 0]
        while frontier:
            layers.append(frontier)
            nxt = []
            for u in frontier:
                for a, b in crg.edges:
                    if a == u:
                        indeg[b] -= 1
                        if indeg[b] == 0: nxt.append(b)
            frontier = nxt
        return layers

    def _debt_of(self, cname):
        return self._dq_deficit(cname) * self._fanout(cname) * self._age(cname)
```

```python
def roadmap_data_closed_loop(crg, cmg, dqe, portfolio, targets, B_cap, B_data, risk_model):
    """每个里程碑：能力门 × 数据门 → 晋升/保持/降级/补救/设计反馈"""
    plan, status = portfolio.optimize(targets, B_cap, B_data, risk_model)
    if plan is None:
        return crg, [], f"roadmap_infeasible:{status}"

    log = []
    for action, cname, meta in plan.actions:
        if action != "build":
            log.append(("skip", cname, meta)); continue
        l = crg.nodes[cname].level + 1

        # ② 数据门：审计评估/校准数据
        evidence = collect_evidence_for(cname, level=l, profile=targets.profile)
        dqcs = [e.dqc for e in evidence]
        effects = [dqe.propagate(d.dq) for d in dqcs]

        # 数据不合格 ⇒ 数据补救（不是静默降级）
        if any(d.expired() or dqe.propagate(d.dq).leak_veto for d in dqcs):
            remediation = schedule_data_remediation(cname, dqcs)
            log.append(("data_veto", cname, remediation)); continue
        if any(eff.delta_dq > risk_model.dq_tolerance for eff in effects):
            remediation = schedule_data_remediation(cname, dqcs)
            log.append(("data_remediate", cname, remediation)); continue

        # ③ 能力门 + ④ 决策
        ok, reason, cert = cmg.promote(cname, evidence, risk_model.delta_budget(l))
        if ok:
            log.append(("promote", cname, cert))
        elif reason.startswith("G-dep"):
            crg.nodes[cname].crl_history.append(("hold", reason))
            log.append(("hold", cname, reason))
        else:
            # 能力不可达 ⇒ 设计反馈 / 分叉 / 缩减 ODD
            fork = design_feedback(cname, reason, targets)
            crg.forks.append(fork)
            log.append(("fork", cname, fork))

    # ⑥ DQC 过期扫描 ⇒ 自动再认证（数据会变旧）
    for c in crg.nodes.values():
        if c.level > 0 and any_certificate_expired(c):
            cmg.demote_cascade(c.name, reason="dqc_expiry")

    # ⑦ 产出路线图证据
    ev_road = build_roadmap_evidence(crg, log)
    ev_dq = build_data_evidence([d for e in log for d in getattr(e[-1], "dqcs", [])])
    return crg, log, ev_road, ev_dq
```

```python
            if g["decision"] == "promote":
                if any(d["expired"] for d in g["dqcs"]): return False
                if g["delta_dq"] > g["dq_tolerance"]: return False
        # 3) 不存在「低质量过门」：所有 gate 的 Q≽Q_min
        if any(not self.dq_dominates(g["Q"], g["Q_min"]) for g in self.gate_decision_log):
            return False
        # 4) 负债已登记且未超限
        if sum(d["amount"] for d in self.debt_ledger) > self.plan.debt_limit:
            return False
        return True
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CRG | 构图 O(\|C\|+\|E\|)；RRI/组合检查 O(\|C\|+\|E\|) | O(\|C\|+\|E\|) | DAG 无环、RRI 成立、弱链路/风险求和组合律 |
| CMG | O(证据数·\|C\|)/升级；级联降级 O(后继闭包) | O(\|C\|·历史) | 禁止跳级、四门联合、级联恢复 RRI |
| DQX | O(N·d) 测量/数据集（近重复含 MinHash 近似） | O(N·d) | 十维逐项下置信界、盖门偏序、分层测量 |
| DQE | O(1)/数据集 | O(1) | Δ_dq 保守上界、E_eff 乘性折扣、地板以下 E_eff≡0 |
| DQC | O(1) 校验；签名 O(N) | O(1) | 内容寻址、血缘不可继承、泄漏硬否决、过期失效 |
| RDP | DAG 分层 O(\|C\|+\|E\|) + 层内贪心 O(\|C\|log\|C\|)；MILP 可选 | O(\|C\|+\|E\|) | 依赖优先、预算约束、债务超限即判不可行 |
| RDC | O(里程碑·(DQX+CMG+级联)) | 复用 | 单调保守、有限终止、数据/能力失败分流 |
| J_road | O(1)/决策追加 | O(里程碑数) | DAG/RRI/门日志/DQC/负债五重可验证 |

**正确性定理（Roadmap-Data Grounded Readiness, RDGR）**
假设 A22–A55（第 53–59 轮）成立；**(A56)** CRG 依赖图为 DAG，接口契约音完备（组合时接口兼容可判定）；**(A57)** CMG 四门谓词音完备且禁止跳级，级联降级沿全部后继传播；**(A58)** DQX 各维测量给出真实值的置信下界（测量协议无系统性乐观偏差）；**(A59)** DQE 的 Δ_dq 为真实保证退化的**保守上界**（漂移/标签/溯源/重复各项的常数取上界），泄漏否决无漏报；**(A60)** DQC 内容寻址、签名不可伪造、派生强制重算、过期即失效；**(A61)** RDP 尊重依赖优先与预算，债务超限时如实返回不可行；**(A62)** RDC 的 EV-road/EV-dq 只用于就绪与部署范围决策，不替代单次接触证据；**(A63)** 数据生产边与负债账本诚实记录影子产数与未解决赤字。则：

1. **就绪度组合健全性**：任意 c，若其所有 gate 决策 sound，则 ℓ(c) ≤ 1 + min_{d∈pred(c)} ℓ(d)，且 δ_c ≤ Σ_{子能力} δ；系统级风险可由 CRG 自上而下精确上界。
2. **数据诚实的有效性**：对任何用于认证的数据集，共形覆盖率下界 cov ≥ 1−α−Δ_dq；ECE_true ≤ ECE_obs + L_lip·(1−Q_label) + O(Δ_dq)；当 Δ_dq 增大时保证单调不升。
3. **质量压倒数量**：若任意维 Q_dim < Q_min,dim(ℓ)，则 E_eff≡0，任何 CRL 晋升被拒——堆量无法认证脏数据。
4. **路线图单调保守性**：数据/证据退化只会导致 CRL 不升、部署范围不扩、债务不减记；任何放宽必须走再认证（Q≽Q_min ∧ 双门重过）。
5. **无跳级/无越权**：CRL 只能逐级晋升；EV-road/EV-dq 不能替代 EV-probe*/EV-xmodal/EV-exec 用于单次接触放行；低就绪前置必然拖住后继（RRI）。
6. **规划诚实性**：RDP 返回 ok ⇒ 计划满足依赖/预算/地板；返回 infeasible ⇒ 目标在预算下确实不可达（不得硬凑里程碑）。
7. **终止性**：RDC 在有限里程碑内终止于 {晋升、保持、级联降级、数据补救、设计反馈、缩减范围、规划不可行}。
8. **部署界**（对检查点取联合界，新增数据/路线图项）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1]
                   + δ_ft·1[回滚窗口] + δ_kg·1[检索失败] + δ_ux·1[μ_mis>θ_mis]
                   + δ_exec·1[ξ_exec漂移] + δ_ξ_ood·1[执行OOD]
                   + δ_ertc·1[契约违例] + δ_eeis·1[μ分析漏报]
                   + Δ_dq·1[证据所用数据有缺陷] + δ_leak·1[泄漏漏报]
                   + δ_debt·1[负债未在期偿还])
         − P(𝒢结构性错误未检出) − P(护盾回退失败) − P(τ_int超时 ∧ 安全停失效)
         − P(固件回滚失败) − P(DQC 伪造/签名失效) − P(RDP 规划错误)
```

关键：**CRG 把「技术路线图」从甘特图变成可证明的依赖 DAG 与成熟度阶梯**——弱链路就绪、风险求和、无跳级、级联降级；**DQX/DQE 把「数据质量」变成证据的乘性折扣**——十维可测、Δ_dq 可传播、E_eff 进入证据门、地板以下质量压倒数量；**RDP/RDC 把「造能力」与「造数据」耦合**——影子部署既产数据（飞轮）也积负债（复利），债务超限即诚实判不可行；**J_road 让整条路线图可审计、可再认证、可回滚**。三条安全单向通道延续并上移：**信念更准（高质量证据）、不确定性更大（Δ_dq 折扣/债务）、动作更保守（不晋升/不扩域/不越权）**。

## 6. 本轮最大风险
