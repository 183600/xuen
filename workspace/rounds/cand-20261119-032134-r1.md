# 第 1 轮（UniBot 线 · 本轮灵感：「世界模型」×「抓取位姿估计」）

> **连续性声明**：本线沿用上一版 UniBot-SAGE 的四条硬结论与工程骨架，**不推倒重来**：①终态成功是唯一计分货币（teaser 上 step≈1.337·succ+0.09，R²=0.9955）；②跨任务专长准正交，单 checkpoint 内技能路由有 +4.26 的 oracle 上界；③断点在最后的对齐/插入/释放；④「做得快」没有红利。
> 本轮把两个新透镜装到同一个骨架上：
> - **「抓取位姿估计」**把上一版的二值抓握隐变量 `g_t` 升级为**任务条件化的抓取位姿分布** `p(g|o,ℓ)`：不仅问"抓住了没有"，更问"抓哪里、以什么接近方向抓、抓完还保留哪些可动自由度"；
> - **「世界模型」**不再只做像素级未来生成，而是做**接触尺度的反事实评分器**：在不真机试错的前提下，对 K 个候选抓取位姿做短程 latent rollout，预测滑移/碰撞/下游可行性。
>
> 编号继续累加：定义 **U13–U22**、引理 **L8–L13**、实验 **E619–E630**；上一版 U1–U12 / L1–L7 / E601–E618 保留引用，不重复展开。情报基线沿用 2026-11-17 的核实结果，**本轮不新增对外事实断言**。

## 0. 先给直觉：三个画面

**画面 1 · "抓稳"与"抓对"是两件事。**
一个杯子，抓手可以从侧面抓杯身、从上方抓杯口、也可以抓杯柄。三种都"抓得稳"，但只有抓杯柄的那一次，才给后面的"挂到钩子上"留下了正确的朝向。上一版把抓取压缩成"抓住/没抓住"的二值隐变量，等于把"抓哪里"这个 6 自由度决策扔给端到端策略去隐式承担——而策略恰恰在最后一厘米系统性失败。

**画面 2 · 单自由度夹爪把"可行抓取流形"压成一条细带。**
Dex1 只有开合一个自由度，没有对指、没有触觉、没有腕部力矩。于是"能形成力闭合"的位姿本来就少；再叠加任务约束（插网线要让插头尖端露出来、拧瓶盖要让旋转轴与手指闭合方向正交、倒水要让杯口朝向可控），可行集进一步缩成一个**低维、任务相关的流形**。抓取位姿估计在这里不是"锦上添花的三维视觉模块"，而是**把连续控制问题降维成流形上的选择问题**。

**画面 3 · 世界模型最值钱的地方，是"不试就能比较"。**
真机时段稀缺、episode 40+ 秒、失败还要重来。如果有一个只在**接触尺度、相对坐标系**里滚几帧的世界模型，就能在夹爪真正闭合前，对 K 个候选抓取问一句"如果我这样抓，半秒后物体还在我手里吗？它挡住后面的插入轴了吗？"——这把"抓取"从开环赌注变成**可比较的候选选择**。

**合成的一句话直觉**：让**抓取位姿估计提供候选空间**（生成式先验 + 任务契约），让**世界模型提供反事实评分**（短程 rollout + 不确定性），再用**保守门控**决定要不要偏离基线。三者缺一：没有先验就无从采样；没有世界模型就无法在候选间排序；没有门控就会把世界模型的错变成新的硬失败。

## 1. 量化的落脚点（承接 teaser 结构性分析，n=8×32）

上一版已确认：终态成功是唯一货币；技能准正交；断点在最后一厘米。本轮只补一条与"功能性抓取"直接相关的结构观察。

**分析方法（假设生成，不是因果）**：按"成功是否要求抓取后仍保留特定轴向或区域"这一单一判据，把 32 个任务手工分成 10 个**功能性抓取敏感（FGS）**任务与 22 个其余任务。FGS = {Plug In Ethernet, Disconnect Ethernet, Unlock, Open Pill Bottle, Plug Charger, Syringe Water Transfer, Zip Up, Hang the Cup, Arrange Test Tubes, Pick Out Battery}。

| 分组 | 每任务跨模型均值（再对任务取均值） | 每任务 oracle 间隙（best−mean） |
|---|---|---|
| FGS（n=10） | **23.13** | 9.17 |
| 其余（n=22） | **26.10** | 8.61 |
| 差 | **−2.97** | +0.56 |

**读法**：FGS 任务整体低约 3 分，而 oracle 间隙并不更小——说明"抓取契约"类差异既是难度来源，也是**模型间专长差异**的来源。若一个模型恰好学会了某种功能性抓法，它在这些任务上的相对优势会被保留，正好可被技能路由兑现（承接 L2）。

**必须标注的保留意见**：teaser 表由 `gen_leaderboard.py` 随机生成且被"排行榜即将公开"遮罩，分组是人工定义。因此上表只用于**生成假设**，不用于宣称因果；真正的判据在 E619–E630。

## 2. 从直觉到严格命题

### 2.1 抓取位姿的严格定义

在末端执行器坐标系 `E` 中，把一次抓取写成

```
g = (p, R, d, w) ∈ R^3 × SO(3) × S^2 × [w_min, w_max]
```

其中 `(p,R)` 是接触瞬间夹爪基座相对"物体任务相关坐标系" `O_τ` 的位姿，`d` 是接近方向（预抓取沿 `−d` 回退），`w` 是指令开口宽度。评测端只给 1 维开合标量，所以 `w` 是我们唯一能直接控制的"手型"。

**关键升级**：任务 τ 给抓取位姿附加一个**契约**

```
C_τ(g) = 1  ⇔  g 满足 { 保留区 R_free(τ) 未被夹爪占据,
                        接触区 R_contact(τ) 被覆盖,
                        目标轴 a_τ 与夹爪闭合轴 b(g) 的夹角 ≤ ε,
                        最小间隙 ≥ c_min }.
```

例如：插网线要求插头尖端与前向空间不被夹爪遮挡；拧瓶盖要求瓶盖旋转轴 `a_τ` 与夹爪闭合轴正交（否则只能夹不能拧）；叠杯要求杯口外沿可接触且杯内空间不被挤压。

### 2.2 把"抓取成功率"拆成稳定性 × 功能性

```
S_τ(g) = P_stab(g) · P_func(g | stab, τ)
```

`P_stab`：从闭合到搬运结束物体始终随臂运动；`P_func`：在"物体没掉"的条件下，下游对齐/插入/旋转/叠放能完成。上一版只优化 `P_stab`（"抓住没有"），这正是它和最后一厘米失败之间的缝隙：**最稳的抓法常常不是最功能性的抓法**（引理 L8 给出反例）。

### 2.3 世界模型作为反事实评分器

学一个接触尺度隐动力学

```
z_{t+1} = f_ψ(z_t, a_t),   ŷ = h_ψ(z_{t+H})
```

`z_t` 由冻结视觉主干 + 本体状态编码，`a_t` 是末端**相对**动作（不是关节绝对角），预测头给出 `{slip, collision, clearance, task_progress}`。对候选 `g` 构造一段"预抓取→闭合→抬升→朝目标移动"的想象动作，得到评分

```
Ŝ_τ(g) = E[ h_ψ(z_{t+H}) | o, g ].
```

**为什么必须带不确定性**：训练数据里只有"成功抓取"的 demo，候选 `g` 一旦偏离 demo 流形就是 off-support。定义支持度

```
u(g) = α·Disagreement(f_ψ^{1..M}) + β·Novelty(z(g), D_demo),
```

并要求"只在 `u(g) ≤ u_max` 时相信 `Ŝ`，否则退回解析几何评分"（P12 / U20 / 引理 L10–L11）。

### 2.4 四个可反驳的预测（预注册）

- **H4（功能性缺口）**：在 FGS 任务上，"稳定性最优"抓法与"功能性最优"抓法的选择分歧率显著高于其余任务；分歧越大，下游失败率越高。
- **H5（生成先验的覆盖）**：在留出物体上，demo 训练的生成式抓取先验的 top-k 覆盖率随 k 增长而饱和；饱和值可作为"是否需要几何回退"的判据。
- **H6（反事实评分的增量）**：在世界模型支持域内，`Ŝ` 对候选抓取的排序 AUC 显著高于解析稳定性评分；在支持域外则显著更差——即增益与风险都由 `u(g)` 分层。
- **H7（保守门控的安全性）**：按 L11 的切换准则，真机 A/B 中"因介入而变差"的比例有可证上界，且总成功率不低于基线。

## 3. 研究问题（本轮版）

- **Q11（抓取位姿标签从哪来）**：只有成功 demo、没有物体 6D 位姿真值，能否从"夹爪闭合瞬间的 EE 位姿 + 腕部帧 + 物体随动"反推出足够干净的抓取位姿标签？噪声如何进入下游？
- **Q12（生成式先验能否覆盖未见物体）**：`p(g|o,ℓ)` 在留出物体/背景/位置上的 top-k 覆盖率与模式坍塌如何？
- **Q13（稳定性 vs 功能性）**：在最后一厘米任务上，把目标从 `P_stab` 换成 `S_τ=P_stab·P_func`，能解释/挽回多少失败？
- **Q14（世界模型的支持域边界）**：`u(g)` 能否可靠地把"可评分的候选"与"不可评分的候选"分开？误信 off-support 评分的代价有多大？
- **Q15（合规与延迟）**：生成先验 + K 候选 rollout + 门控，能否塞进单 checkpoint / 单 API / p99≤105 ms？多端口共享后端时如何隔离？
- **Q16（契约的可迁移性）**：`C_τ` 能否从语言 + 几何在线推断，而不是按 32 个任务名硬编码？（这直接决定是否踩 P5 红线。）

## 4. 设计原则（在 P1–P6 上新增）

- **P11 功能优先（functional-first）**：抓取的目标函数是"下游可行"，不是"抓得稳"。稳定性只作为约束。
- **P12 支持域优先（support-aware）**：世界模型的评分只在支持域内被信任；`u(g)>u_max` 一律退回解析/几何评分或 demo 先验众数。
- **P13 先生成再验证（generate-then-verify）**：先验负责召回，世界模型负责排序，门控负责安全。三者职责不重叠。
- **P14 契约即技能描述**：`C_τ` 作为任务 token 的结构化补充（"保留哪段自由、对齐哪根轴"），而不是任务名分支；每个契约必须至少跨 2 个任务复用（沿用 P3）。
- **P15 可反事实归因**：每个抓取决策落一条 `(o, g_base, g_chosen, Ŝ, u, 触发原因)` 事件，供六因子分解与审计复用。
- **P16 优雅退化**：先验不可用→解析抓取；世界模型不可用→先验众数 + 几何排序；门控不可用→纯基线。任何一级失效都不得使行为漂移。

## 5. 本轮的核心机制（一句话各一条）

1. **GGP（Generative Grasp Prior）**：语言 + 四路 RGB 条件化的 SE(3) 生成先验，从 32k demo 的"成功抓取"里学"在哪里抓"的分布，输出 top-K 候选。
2. **GraspWM（World-Model Critic）**：接触尺度 latent 动力学 + 多任务预测头，对每个候选做短程想象 rollout，输出 `Ŝ_τ(g)` 与 `u(g)`。
3. **ContractGate（契约门控）**：用 `C_τ` 做几何硬约束、用 `u(g)` 做统计软约束、用 `δ` 做保守切换，三者共同决定"是否偏离基线"。

## 6. 与现有工作的差异

- 与"把世界模型当视频生成器"的路线相比：我们只在**接触尺度相对 SE(3)** 上建模，训练目标是**用于排序的判别目标**，推理期是**选择器**而非增广器。
- 与经典抓取位姿估计相比：目标是**任务条件化的功能性抓取**，受 1 自由度夹爪的可行流形约束，且评测期没有触觉/手指关节。
- 与端到端 VLA 相比：把"抓哪里"从隐式策略里**显式提出来**，在夹爪闭合前做一次可审计的选择，而不是让一个自回归块把抓取和下游揉在一起。

## 8. 下一轮迭代计划

- **深化**：把 `P_func` 再分解成"轴对齐 / 间隙 / 保留区"三个可测因子，和六因子分解对齐；把世界模型的想象力从"物体随动"扩展到"接触力/滑移"的隐变量。
- **修剪预案**：若 E622 显示世界模型在支持域内的排序 AUC 不能显著超过几何评分（例如 ΔAUC<0.05），则**砍掉世界模型评分器**，只保留生成先验 + 契约几何门控；若 E620 覆盖率在留出物体上饱和于低值，则**砍掉生成先验**，退回解析抓取。
- **保留项**：E619（标签管线）、E624（功能性 vs 稳定性）、E630（合规审计）在任何情况下不砍。

## 9. 本轮最大风险

**一句话**：世界模型只见过"成功的抓取"，因此它对候选抓取的反事实评分在**最需要它的未见物体上恰恰是 off-support 的外推**——它会以高置信度偏爱"像 demo 的坏抓法"，而把真正可行的新抓法判低，于是抓取位姿估计与世界模型这两个"聪明部件"会以乘法方式放大同一个偏差。

## 0. 本轮结论摘要

**一句话路线**：把抓取从"抓住没有"改写为"**在 1 自由度夹爪的可行流形上，选一个让下游仍可行的位姿**"：

**GGP 生成候选（抓取位姿先验）→ GraspWM 反事实排序（世界模型）→ ContractGate 保守门控（契约 + 支持度）→ 失败回退（解析抓取 / v1 GraspVerify）**。

**三条设计依据**：

| 依据 | 数值/事实 | 推出的设计 |
|---|---|---|
| 最稳 ≠ 最功能（L8 的反例） | `S=P_stab·P_func`，稳定性最优可导致 `P_func=0` | 目标函数改为功能性成功，稳定性降为约束（P11） |
| demo 只有成功抓取，反事实是 off-support | 世界模型误差随新奇度增长；`u(g)` 可分层 | 只在支持域内相信 `Ŝ`，域外回退几何（P12，L10–L11） |
| FGS 任务整体低约 3 分（teaser 结构，假设生成） | FGS 23.13 vs 其余 26.10；oracle 间隙 9.17 vs 8.61 | 抓取位姿是可兑现的专长差；接回技能路由（IP-01） |

**合规红线（延续 P5/P6）**：单一 checkpoint、单一策略服务；`C_τ` 由语言 + 几何在线推断，**不按任务名硬编码**；所有新增计算在策略内部，不新增接口字段；世界模型只在 grasp 相位触发，且可整体关闭退化到 v1。

## 2. 创新点详述

### IP-09 · GGP 生成式抓取位姿先验（P0）

- **动机**：1 自由度夹爪的可行抓取是一个低维流形；端到端 VLA 把"抓哪里"与下游动作揉在一个自回归块里，在最后一厘米最易崩。显式的抓取位姿分布能把连续控制降维成"流形上的选择"。
- **与现有方案的差异**：经典抓取位姿估计多为"点云 → 6-DoF 抓取"的判别式回归，目标是稳定抓取且通常假设多指/触觉；本方案是**任务条件化的生成式先验**，在 `(p,R,d,w)` 上建模多模态，且部署时不需要触觉/手指关节。
- **技术可行性**：中–高。标签可从 demo 的"夹爪闭合瞬间 EE 位姿 + 物体随动"反推（U19/E619）；四路相机里两路腕部相机提供近距离几何。生成器可用条件 flow matching（SE(3) 上做 `R` 的切空间参数化 + `p` 的高斯混合 + `w` 的分类/回归）。
- **所需资源**：数据 = 官方 32 数据集 + 自动抓取位姿标注；算力 = 单卡数小时～1 天（小模型，输入 4×240×320）；接口 = 无新增字段。
- **落地步骤**：①E619 建抓取位姿标签；②训练条件 flow 先验，先只预测 `(p,w)` 再解锁 `R,d`；③top-k 采样 + 去重（NMS on SE(3)）；④与解析抓取候选做并集，保证先验失效时仍有可行候选；⑤按任务簇/阶段评估覆盖率。
- **风险**：①未见物体上模式坍塌 ⇒ 解析候选并集兜底；②标签来自成功 demo，可能继承"单一抓法偏好" ⇒ 在留出物体上报告覆盖率而非仅精度；③`R` 的流形参数化不稳 ⇒ 先预测接近方向 `d` 与闭合轴 `b`，再重建 `R`。

### IP-10 · GraspWM 世界模型反事实评分器（P0）

- **动机**：候选抓取不能靠真机逐个试。需要一个能在**夹爪闭合前**回答"这样抓，半秒后物体还在手里吗？下游轴被挡住没有？"的评分器。
- **与现有方案的差异**：官方参考 WMA 把世界模型兼作仿真/策略增强，通常生成像素/视频；本方案只在**相对 SE(3) + 夹爪开合**的低维接触状态上建模，训练目标是**用于排序的判别目标**，推理期是**选择器**。
- **技术可行性**：中。相对状态 `(Δp,ΔR,g,σ)` 可由腕部帧几何 + 正运动学得到；滑移标签用"夹爪闭合后物体相对腕部位移"间接标注；多任务头共享 trunk，集成分歧提供认知不确定性。
- **所需资源**：数据 = 官方数据 + 扰动抓取（负例由扰动 + 物理/几何可行性伪标）；算力 = 4×A100 × 1–2 天；推理 = 复用 GGP 编码器，latent rollout 每步 ≤1.5 ms（目标值，E627 实测）。
- **落地步骤**：①E621 训练并验证不同 horizon 的相对位姿预测；②加 `slip/collision/clearance/progress` 多头 + 集成；③E622 做支持域分层排序评估（关键实验）；④实现 `u(g)` 与门控；⑤E623 真机 A/B 验证介入安全。
- **风险**：①**off-support 乐观**（本轮最大风险见 §9）⇒ 不确定性门控 + 几何回退；②滑移伪标噪声 ⇒ 双标注器一致性检查；③latent 误差累积 ⇒ 只滚短 horizon（H≤8）且只在 grasp 相位用。

### IP-11 · ContractGate 功能性契约门控（P0）

- **动机**：把"功能性"落成可执行约束，并保证任何模型错误都不会让系统比基线更差。
- **与现有方案的差异**：不是"任务名 → 固定抓法"的规则表，而是从语言 + 几何推断的**结构化契约**（保留区/接触区/目标轴/间隙），并且每个契约至少跨 2 个任务复用（P3/P14）。
- **技术可行性**：高。几何部分（间隙、轴向夹角、保留区占位）是解析可算的；语言部分用 VLM 把指令映射到"需要保留的自由度"模板。
- **落地步骤**：①定义有限契约模板族（如 `keep_tip_free`、`align_axis`、`rim_grasp`、`handle_grasp`、`generic_pinch`）；②VLM 分类 + 几何校验；③E625 在留出物体上测契约推断一致性；④实现门控选择与审计事件（P15）。
- **风险**：①契约族本身变成隐性硬编码 ⇒ 用"跨任务复用 + 留出物体"审计；②契约推断错 ⇒ 门控只影响"是否切换"，不改变基线动作，避免硬失败。

### IP-02′ · GraspVerify 升级（P0）

- **动机**：v1 只判"抓住了没有"，且只在高置信"未抓住"时介入。抓取位姿选对之后，仍需在**闭合后**监测滑移，才能把"选错"或"扰动"救回来。
- **升级点**：①把 v1 的 `g_t` 与 U17 世界模型的 `slip` 头共享时序特征；②滑移检测用"物体相对腕部位移 > 阈值且不随臂刚性运动"的时序判据；③非抓取原语（推/扫/倾倒/钩）保留为最后退路。
- **可验收**：滑移检出 AUROC ≥0.85；重抓救回率 ≥20%；不降低基线成功率。

### IP-12 · Counterfactual Grasp Replay 反事实回放（P1）

- **动机**：只有成功 demo 时，critic 没有"坏抓法"的标签。用扰动 + 反事实回放造 `(o,g,y)` 标签，把"评估"与"训练信号"合并。
- **做法**：在 demo 的抓取前时刻 `t`，对 `g` 做受控扰动（位置 ±2 cm、接近方向 ±20°、开口 ±2 mm、轴向翻转），得到候选对；用 GraspWM 评分，少量真机时段做锚点校准。成对设计把真机样本量按 `(1−ρ)` 缩减（L12）。
- **风险**：世界模型自标自评会强化偏差 ⇒ 必须保留真实标签锚点，并做 E629 的"模型标签 vs 真机标签排序相关"检验。

### IP-01′ · 技能 token 吸收抓取契约（P1）

- **动机**：v1 的技能路由按任务 token 选专家；FGS 任务里"专家差异"很可能就是"抓法差异"。把 `C_τ` 作为 token 的附加字段，让专家按"保留区/目标轴"分工，而不是按任务名过拟合。
- **可验收**：FGS 任务相对 v1 技能路由 ≥+1.0 分；专家仍满足"每个至少服务 2 个任务"。

### IP-06′ · 代理评测增加抓取位姿指标（P0）

- **新增指标**：①GGP top-k 覆盖率（按留出物体/位置/背景分层）；②GraspWM 支持域内/外的排序 AUC；③功能性-稳定性分歧率；④抓取位姿标签一致性。
- **可验收**：与真机成功率 Spearman \|r\| ≥0.5；若 <0.3 触发 v1 的剪枝预案（一切依赖代理指标的微调砍掉，只保留机制正确性驱动的 IP-02′/IP-11）。

| 符号 | 含义 |
|---|---|
| `E` | 末端执行器坐标系 |
| `O_τ` | 任务 τ 的物体任务相关坐标系 |
| `g` | 抓取位姿 `(p,R,d,w)` |
| `C_τ` | 任务抓取契约（保留区/接触区/目标轴/间隙） |

| `P_func` | 给定抓稳时下游功能性成功概率 |

| `p_θ(g\|o,ℓ)` | 生成式抓取位姿先验 |

**定义 U13（抓取位姿）** `g=(p,R,d,w) ∈ R³×SO(3)×S²×[w_min,w_max]`；`(p,R)` 为 `O_τ→E` 的接触位姿，`d` 为接近方向，`w` 为指令开口。
**定义 U14（任务抓取契约）** `C_τ=(R_free,R_contact,a_τ,ε,c_min)`，`C_τ(g)∈{0,1}` 当且仅当保留区未被占、接触区被覆盖、`∠(a_τ,b(g))≤ε`、最小间隙 `≥c_min`。
**定义 U15（功能性抓取成功）** `S_τ(g)=P_stab(g)·P_func(g|stab,τ)`；`P_stab` 为闭合到搬运结束物体随动的概率，`P_func` 为下游完成概率。
**定义 U16（抓取位姿先验）** `p_θ(g|o,ℓ)`：语言 + 多视角条件下的 SE(3) 生成分布；`G_K ~ p_θ` 取 top-K。
**定义 U17（世界模型）** `z_{t+1}=f_ψ(z_t,a_t)`，`h_ψ(z_{t+H})→(slip,collision,clearance,progress)`；`Ŝ_τ(g)=E[h_ψ^{progress}|o,g]`。
**定义 U18（支持度）** `u(g)=α·Var_{m=1..M}(Ŝ^{(m)}(g)) + β·d_Maha(z(g),D_demo)`。
**定义 U19（反事实回放集）** `D_cf={(o_i,g_i,g_i^0,y_i)}`，`y_i` 来自世界模型或少量真机锚点；用于成对校准。
**定义 U20（选择性抓取选择）** 选 `g*=argmax_{g∈G_K∪G_geo} Ŝ(g)`，当且仅当 `C_τ(g*)=1`、`u(g*)≤u_max`、`Ŝ(g*)−Ŝ(g_base)≥δ`；否则 `g*=g_base`。
**定义 U21（契约在线推断）** `Ĉ_τ=Φ_VLM(ℓ,o)` 映射到契约模板族，并用几何校验修正；禁止以任务 ID/任务名作为分支键。
**定义 U22（抓取—姿态耦合）** 给定 `g` 的手部目标，可达性评分 `R(g)=P(pivot/lower_body 可支撑 | g)`；仅作为 `C_τ` 的可达性约束项，不单独优化。

# ===== IP-09：条件 SE(3) 生成先验 =====
class GraspPrior:
    def __init__(self, ckpt):
        self.enc  = load(ckpt).encoder          # 冻结视觉-语言主干 + 轻量适配
        self.flow = load(ckpt).flow             # SE(3) flow matching

    def sample(self, obs, K):
        z = self.enc(multi_view(obs), obs["observation.language"])
        return self.flow.sample(z, K)           # [(p,R,d,w), ...]

    def mode(self, obs):
        return self.flow.mode(self.enc(multi_view(obs), obs["observation.language"]))


# ===== IP-10：世界模型反事实评分 + 支持度 =====
class WorldModelCritic:
    def __init__(self, ckpt, M=5):
        self.enc      = load(ckpt).encoder
        self.ensemble = [load(ckpt).dyn for _ in range(M)]
        self.heads    = load(ckpt).heads        # slip/collision/clearance/progress
        self.demo_mu, self.demo_cov = load(ckpt).demo_manifold

    def score(self, obs, g, H):
        z = self.enc(obs)
        z = self.rollout(z, self.imagine(obs, g, H), model=self.ensemble[0])
        return self.heads(z)["progress"]

    def uncertainty(self, obs, g):
        z = self.enc(obs)
        preds = [self.heads(self.rollout(z, self.imagine(obs, g, 2), m))["progress"]
                 for m in self.ensemble]
        dis = float(np.var(preds))
        nov = mahalanobis(z, self.demo_mu, self.demo_cov)
        return self.alpha * dis + self.beta * nov

    @staticmethod
    def imagine(obs, g, H):
        # 预抓取 → 闭合 → 抬升 → 朝目标移动；均为末端相对动作
        return build_relative_actions(obs, g, H)


# ===== IP-11：契约门控 =====
class ContractGate:
    def __init__(self, u_max, delta):
        self.u_max, self.delta = u_max, delta

    def contract_ok(self, g, obs, C):
        return C.check(g)          # 保留区/接触区/轴角/间隙，解析可算

    def select(self, g0, cand, scores, us):
        base = score_of(g0, cand, scores)
        order = sorted(range(len(cand)), key=lambda i: -scores[i])
        for i in order:
            if us[i] > self.u_max:          # 支持域外：不信任
                continue
            if scores[i] - base >= self.delta:
                return cand[i], "switch"
        return g0, "keep_base"

## 5. 推导（引理 L8–L13）

**引理 L8（稳定性最优 ≠ 功能性最优）** 设可行抓取集 `G`，下游成功要求目标轴 `a_τ` 所在区域保持自由。若 `g1` 通过最大化接触面积获得 `P_stab(g1)=0.9`，但夹爪占据该区域使 `P_func(g1)=0`；`g2` 接触较少 `P_stab(g2)=0.7` 但保留目标轴使 `P_func(g2)=0.8`。则 `S(g1)=0`、`S(g2)=0.56`，`argmax S ≠ argmax P_stab`。故只优化抓握稳定性会被功能性抓法严格支配。∎

**引理 L9（生成先验的覆盖饱和）** 若 `p_θ(g|o)` 的支撑集被限制在 demo 流形 `M` 的 ε 邻域内，而未见物体的功能性抓取集 `G*` 到 `M` 的距离 `>ε`，则 `sup_{g∈G*} p_θ(g|o)=0`，任意 top-k 覆盖率上界为 0。故生成先验必须与**不依赖 demo 流形的解析候选**并集使用。∎

**引理 L10（支持域门控的后悔上界）** 设世界模型误差满足 `|Ŝ(g)−S(g)| ≤ e_0 + e_1·u(g)`。令 `g*=argmax_{u(g)≤u_max} Ŝ(g)`，`g†=argmax S(g)`。因 `g*` 最大化 `Ŝ`，有 `Ŝ(g*) ≥ Ŝ(g†)`。于是

```
S(g†) − S(g*) ≤ [Ŝ(g†)+e_0+e_1u(g†)] − [Ŝ(g*)−e_0−e_1u(g*)]
             ≤ 2(e_0 + e_1·u_max).
```

即**门控阈值 `u_max` 直接给出后悔上界**；把域外候选排除，等于把 `e_1·u_max` 这一项钉住。∎

**引理 L11（保守切换不伤真机成功率）** 若只在 `Ŝ(g)−Ŝ(g_base) ≥ δ` 且 `u(g)≤u_max` 时切换，且误差上界 `e_max=e_0+e_1u_max`，则真实优势

```
S(g) − S(g_base) ≥ (Ŝ(g)−e_max) − (Ŝ(g_base)+e_max)
                  ≥ δ − 2e_max.
```

取 `δ ≥ 2e_max` 即保证切换不降低真实成功率；`δ` 可由 E623 的真机锚点估出。∎

**引理 L12（成对回放的样本量缩减）** 对同一初始状态、同一候选对，治疗/对照结果 `Y_T,Y_C` 的差方差

```
Var(Δ̂) = (σ_T² + σ_C² − 2ρσ_Tσ_C)/N.
```

抓取候选对共享场景与随机数流时 `ρ` 通常较高，所需样本量按 `(1−ρ)` 缩减；这正是 IP-12 用反事实回放替代大量真机试错的依据。∎

**引理 L13（延迟预算下的候选数上界）** 每个抓取决策的耗时为

```
T = T_enc + T_prior + max(0, K·(T_rollout·H)) + T_gate  ≤  τ.
```

故 `K ≤ floor((τ − T_enc − T_prior − T_gate)/(T_rollout·H))`。以 `τ=105 ms`、`T_enc=25`、`T_prior=20`、`T_gate=2`、`T_rollout=1.5 ms/步`、`H=6` 为例，`K ≤ 6.4` ⇒ `K=6`。该组常数是**待 E627 实测替换**的占位值；若实测超预算，优先降 `K` 而非降 `H`（短 horizon 是支持域估计的前提）。∎

## 9. 风险登记册与剪枝预案

| 风险 | 概率 | 影响 | 对冲 |
|---|---|---|---|
| **off-support 乐观**（本轮最大） | 高 | 高（世界模型自信地选坏抓法） | 支持度门控 + 解析候选并集 + 域外一律回退；E622 明确报告域外表现 |
| 抓取位姿标签噪声 | 中高 | 中高（先验学偏） | 多信号一致性 + 人工抽检 + 只在高置信帧训练 |
| 生成先验模式坍塌/覆盖不足 | 中 | 中 | 解析候选并集兜底；覆盖率而非精度作主指标 |
| 契约隐性硬编码 | 中 | 高（合规/不可信） | 契约模板族跨任务复用 + 留出物体一致性 + 行为审计（E625/E630） |
| 延迟超预算 | 中 | 中 | 只在 grasp 相位触发；降 K 优先；世界模型可整体关闭 |
| 多端口状态串扰 | 中 | 高（直接判失败） | 每端口 Session 隔离 + 8 h 压测（E627） |
| 两部件偏差相乘 | 中 | 高 | 门控只决定"是否偏离基线"；任何一级失效回退 v1 |

**剪枝预案**：
- **必保**：E619（标签）、E624（功能性 vs 稳定性）、E630（合规）。
- **优先深化**：IP-10（唯一能把"候选比较"兑现的部件，但必须先过 E622）。
- **条件推进**：IP-12（依赖 E629）、IP-01′（依赖 E626）。
- **可砍**：GGP（若 E620 覆盖不足）、GraspWM（若 E622 不支持域内增益）；砍掉后仍保留"解析抓取 + 契约几何门控"的轻量版本。
