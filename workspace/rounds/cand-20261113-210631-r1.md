# 第 69 轮（承接第 68 轮「CALM-RAS」IP-243~252；灵感循环新一轮第 1 轮；本轮灵感：「手眼标定」×「小样本学习」）

> 第 68 轮 CALM-RAS 把「标定」提升为一等在线潜变量，用静态段自监督持续更新，并用速率限制器（ω_cal ≈ 0.1 Hz）把快变故障挡在标定带宽之外。但它在 §6 自陈了原罪：**只要真实退化足够慢、落在标定带宽之内，就会被「标好」而不是被检出；标定越准，缓变故障越隐形。**
>
> 这不是参数没调好，而是**方法论选错了轴**：R68 用「时间尺度」区分标定与故障（慢=漂移，快=故障）。但慢故障（相机支架蠕变、连杆热伸长、云台缓松、力传感缓慢零漂）在时域上就是慢的，频谱法在原理上无法救它。
>
> 本轮两个灵感恰好指向另一根轴：
> - **手眼标定（AX=XB）**：标定不是「观察出来的」，是「运动出来的」；静止的机器人对外参标定是**秩亏**的。更关键的是，标定在观测空间是一个**低维群作用**——凡能被这个群解释的残差是标定，凡落在其法空间里的残差才是故障。**用结构可辨识替代频率可辨识。**
> - **小样本学习**：新传感器与新型故障都是长尾的，不可能每次都做完整标定、更不可能重新训练；元学习让「k 次探测动作完成标定」「k 个 canary 识别新故障」成为可能，并给出诚实的少样本不确定度。
>
> 核心命题：
> **把标定从「慢变量滤波」重构为「主动手眼实验 + 群结构投影 + 元摊销少样本推断」——HEXA-RAS（Hand-Eye eXcitation & few-shot Adaptive metrology for RAS）。**
>
> 一句话定位：R68 问「我的测量还准吗」，R69 问「**我凭什么知道它准，以及哪些不准是我永远无法知道的**」——后者划出的不可辨识边界，才是安全证书真正该写的东西。

## 0. 直觉与动机

**灵感 1（手眼标定 → 静止是标定最坏的姿态）**
经典手眼标定解 AX=XB：A 是机械臂两姿态间的相对运动，B 是相机观测到的相对运动，X 是待求手眼变换。它揭示两件事：(a) 标定信息全部来自**运动**，单帧或纯静止段对 X 无信息；(b) 解的存在性取决于运动的**激励秩**——绕平行轴转多少次都无济于事，必须有多轴、非退化的旋转与平移。R68 的静态段自标定在「力零偏」上有效（静止时力应为零），但对**外参/焦距/时间同步**是结构性秩亏的；它把外参漂移硬塞进滤波器，只能靠慢速先验去猜，猜错时就把慢故障一起吸收。HEXA-RAS 的第一个动作因此不是滤波，而是**安排一段安全的微运动，把 X 的信息激励出来**。

**灵感 2（标定是一个群，不是一条频带 → 结构可辨识）**
直觉：漂移与故障的区别不是「快慢」，而是「像不像一个标定变换」。把一个刚体支架缓慢拧歪 1°，观测上等价于外参漂移；而缓慢漏气的夹爪、缓慢退化的力矩传感器，观测上是**非刚体、非尺度、非时移**的畸变。前者落在标定群的轨道上，后者落在其法空间里。于是定义：残差 r 分解为 r_∥（标定切空间内，可吸收）与 r_⊥（法空间，故障证据）。**一个慢故障只要 r_⊥ ≠ 0，就与速度无关地被检出**——这正好补上 R68 引理 13 只覆盖 ω_f ≥ 3ω_cal 的漏洞。
代价是一个必须承认的边界：若故障本身就是群元素（缓松的相机支架、热伸长的连杆在运动学上等价于外参变化），它在物理上就**不可与标定区分**。这不是算法缺陷，而是不可辨识性下界（命题 1）。

**灵感 3（小样本学习 → 元摊销标定 + 少样本故障原型，双用）**
直觉：工程上不可能为每个新相机/新夹爪跑一次完整标定，也不可能为每种新故障收几百个样本。元学习给两件事：
- **元摊销标定（MAC）**：在大量「合成传感器实例 × 已知标定」上元训练 q_φ(c | k 段探测)，测试时 k=3~5 段微运动即可给出 ĉ 与协方差（再叠 2 步 Gauss-Newton 精修）。这把 R68 EKF 的「2 秒收敛」升级为「几次主动探测 + 一次前向」，且协方差经 conformal 校准后是**诚实**的。
- **少样本故障原型（FPN）**：episodic N-way K-shot，且每一幕把标定变换当作 nuisance 增广，于是原型天然落在**标定商空间**里——对「换了标定」不变，对「真故障」敏感；新故障只需 K 个 canary 即可入 H 集。
两者共享同一个操作次序：**先把标定群除掉，再谈分类。**

**灵感 4（主动实验 → 歧义不是用来赌的，是用来探测的）**
直觉：当后验在 H_cal 与 H_fault 之间接近 50/50，继续被动观测的期望信息可能为零（两者的慢变签名几乎重合）。此时正确动作是**主动消歧（ADC）**：选一段信息价值（VOI）最高、且落在安全探测流形内的微动作，用「运动激励下的响应是否仍能被同一个 X 解释」把二者分开。探测有安全预算（幅度/力/工作空间/人机距离），预算耗尽或异常即退回保守纪律（λ ≥ 0.95、k = k_min）。这把「主动学习」第一次接进安全闭环——也正是本轮新风险的来源。

**灵感 5（合流 HEXA-RAS 七组件 + 对 R68 风险对症）**
1. **AXB-Probe**：D-最优主动手眼激励，秩条件驱动；安全流形 + 看门狗。
2. **SEG Structural Equivariance Guard**：标定切空间投影，r = r_∥ + r_⊥，输出结构吸收比 κ_struct。
3. **MAC Meta-Amortized Calibrator**：q_φ(c|k probes) + GN 精修 + conformal 协方差。
4. **QSpace Calibration-Quotient Observation**：商空间特征，对标定群不变。
5. **FPN Few-shot Fault Prototype**：episodic K-shot，动态扩充故障原型。
6. **MCG Meta-Canary Generator**：从故障流形采样「非标定方向」的合成 canary，补 R68 CAC 的覆盖漏洞。
7. **ADC Active Disambiguation Controller**：VOI 触发探测；失败即保守回退。
继承 RAS-WM†（ACH/EFS/C-RAS-WM/ERS-WM）；R68 的 MTM/SSG/COF 降级为「基线路径」——探测未触发时仍用 COF 做高频维持。

对症：
- R68 最大风险（慢故障被吸收）→ SEG 结构投影 + ADC 主动消歧（覆盖非轨道慢故障）；
- R68 次级风险（CAC 金标未覆盖慢故障）→ MCG 生成结构性 canary；
- R68「表征坍缩/负迁移」→ FPN 在商空间做原型，MAC 与 FPN 解耦训练；
- 「不确定却放宽」→ λ 总纪律扩展到探测失败与元先验 OOD。

## 1. 形式化定义（增量：定义 293–307）

**定义 293（HEXA-RAS 总览）** HEXA-RAS = (AXB, SEG, MAC, QSpace, FPN, MCG, ADC, RAS†)。不变式升级：
(i) **实时流零学习写操作**（继承 R68）：实时流只做前向推理、SEG 投影、ADC 决策；MAC/FPN 参数更新只在影子流，经 CAC 认证后原子换装；
(ii) **结构吸收红线**：标定只允许吸收 r_∥；物理红线（|b_F| ≤ 5% FS、‖δR_ext‖ ≤ 2°、|Δt_sync| ≤ 20 ms、δ_exposure ≤ 1 stop）超界即判 H_sensor^trans；
(iii) **主动探测安全预算**：每 T_probe = 30 s 至多一次，探测位移 ≤ 2 cm、速度 ≤ 5 cm/s、接触力 ≤ 5 N、人机距离 ≥ 0.5 m；残差/力突变超 τ_abort 立即中止——探测是控制，不是学习，更不是冒险。

**定义 294（标定群与群作用）** 标定参数 c ∈ 𝒞 = SE(3)_ext × ℝ_+ × ℝ³ × ℝ × ℝ²（外参、焦距尺度、力零偏、时间同步、曝光/情绪阈值），单位元 c = 0。群作用 Ψ: 𝒞 × 𝒴 → 𝒴，满足 Ψ(0, y) = y、Ψ(c₁, Ψ(c₂, y)) = Ψ(c₁ ⊕ c₂, y)。轨道 O(y) = {Ψ(c, y) : c ∈ 𝒞}。**标定误差是沿轨道移动，故障是离开轨道。**

**定义 295（手眼约束与运动可辨识性）** 对第 i 段探测，机械臂相对运动 A_i ∈ SE(3)，相机相对运动 B_i ∈ SE(3)，手眼变换 X 满足 A_i X = X B_i。堆叠 m 段得约束系统，可观测矩阵 O_mot(c) 由各段 twist (ξ_i^A, ξ_i^B) 张成。**可辨识 ⇔ rank(O_mot) = d_c。** 静止（m = 0，或纯平移/绕平行轴旋转）⇒ 秩亏 ⇒ 外参不可辨识——这是对 R68 静态段标定盲区的形式化刻画（引理 16）。

**定义 296（AXB-Probe 主动激励）** 探测动作序列 u_{1:k} 由 D-最优实验设计给出：
u* = argmax_{u ∈ 𝒰_safe} log det(F(c; u) + Λ_prior)，
其中 F 为 Fisher 信息，Λ_prior 为 MAC 先验精度，𝒰_safe 为定义 293-iii 的安全流形。若信息增益 Δlogdet < τ_info，则不探测，退回 COF 基线路径。

**定义 297（SEG 结构可辨识分解）** 在当前估计 ĉ 处取标定群李代数的生成元 {g_j}_{j=1}^{d_c}，构造切空间投影 P_cal = G(GᵀG)^{-1}Gᵀ（G = [g_1, …, g_{d_c}]）。残差分解：
r = r_∥ + r_⊥，r_∥ = P_cal r，r_⊥ = (I − P_cal) r。
**结构吸收比** κ_struct = ‖r_∥‖ / (‖r‖ + ε)。可吸收部分仅 r_∥；r_⊥ 进入故障证据。该判别**与频率无关**：慢故障只要 r_⊥ 足够大，照样检出（引理 17）。

**定义 298（标定商观测 QSpace）** 商映射 q(y) = y mod O(y)，即取与轨道横截的规范坐标；故障特征 φ_fault = h(q(y)) 对标定群不变：φ_fault(Ψ(c, y)) = φ_fault(y)。实现上取「先按 ĉ 对标定做逆作用，再拼接残差的法向分量与原始高阶结构特征」。

**定义 299（MAC 元摊销标定器）** q_φ(c | y_{1:k}) = 𝒩(μ_φ, Σ_φ)（异方差头）。元训练目标：
L_meta = E_{s~p(s), c_s} [ −log q_φ(c_s | probes_s) + λ_axb·‖A X̂ − X̂ B‖² + λ_cal·ECE ]，
传感器实例 s 含随机外参/焦距/时延/零偏；测试时用 amortized 估计 + 2 步 Gauss-Newton 精修。Σ_φ 经 split-conformal 校准，保证边际覆盖率 ≥ 1−α（分布无关）。

**定义 300（少样本标定误差界）** 在元分布相似性假设 A95 且探测激励满秩下：
E‖ĉ − c‖² ≤ (d_c σ²)/(k·λ_min(F)) + D_meta + ε_GN，
其中 D_meta 为测试实例到元分布的偏移，ε_GN 为精修残差。k=5、d_c=12 时目标 ‖δR_ext‖ < 0.5°、|b_F| < 1% FS（实验 E289）。

**定义 301（FPN 少样本故障原型）** Episode = N-way K-shot，支撑集作标定 nuisance 增广。原型 p_n = (1/K)Σ_i φ_fault(q(Ψ(c_i, y_i)))。后验 P(H_n | y) = softmax(−d(φ_fault, p_n)/τ_fpn)。新故障以 K 个 canary 追加原型，无需改网络；H 集可动态扩张，覆盖 R68 的长尾缺口。

**定义 302（MCG 元 canary 生成器）** 故障解码器 D_ψ: z ↦ 合成故障签名。从故障流形采样 z，仅接受满足「结构非标定」条件 ‖r_⊥(D_ψ(z))‖ ≥ κ_min、且对现有 canary 新颖（嵌入距离 > τ_nov）的样本，作为 CAC 的候选 canary。**禁止**生成 r_⊥ ≈ 0 的样本充当 canary（那会把标定误判为故障）。

**定义 303（ADC 主动消歧控制器）** 歧义度 A = 1 − |P(H_cal) − P(H_fault)| ∈ [0,1]。信息价值 VOI = H_risk(prior) − E[H_risk(posterior after probe)]。决策：
probe ⇔ (A > τ_amb) ∧ (VOI > c_probe) ∧ (𝒰_safe ≠ ∅)；
否则 conservative：λ ≥ 0.95、k = k_min、冻结标定提交。探测失败或看门狗触发 ⇒ 记入 ℰ_probe 并强制 conservative。

**定义 304（不确定性总纪律升级）** λ_floor(U, A, ood) = max(0.6, 0.8·1[U > τ_cal ∨ A > τ_amb], 0.95·1[ood ∨ probe_failed])。语义不变：**任何不确定性来源只导向收紧，绝不导向放宽。**

**定义 305（结构可辨识边界与慢故障条件）** 故障 f 结构可检出 ⇔ ‖r_⊥(f)‖ ≥ τ_det。定义结构不可见集 I_struct = {f : r_⊥(f) = 0}，即故障签名完全落在标定轨道切空间内。对 f ∉ I_struct，检出与频率无关；对 f ∈ I_struct，任何仅依赖观测的算法都不可能区分（命题 1），必须引入外部计量。

**定义 306（干扰集与证书）** ℰ_HEXA = ℰ_CALM × ℰ_probe × ℰ_meta × ℰ_fewshot：
- ℰ_probe = {探测诱发故障、探测把人逼入危险、看门狗漏报}；
- ℰ_meta = {元先验 OOD、摊销过度自信、conformal 覆盖失效}；
- ℰ_fewshot = {原型被标定污染、K-shot 过拟合、原型漂移}。
J_HEXA = (J_CALM, rank(O_mot), κ_struct, meta_prior_id, k_shot, conformal_α, probe_budget_used, fewshot_verdict, hexa_ver)。Valid ⇔ rank(O_mot) = d_c ∧ κ_struct < κ_max（无故障时）∧ 红线未越界 ∧ meta_prior 在分布内 ∧ commit PASS。

**定义 307（管线）** 离线：在合成传感器实例 × 故障族上元训练 MAC/FPN，构建 QSpace 特征与 MCG；出厂做一次满秩手眼标定得 X_0 与红线。在线：常态 COF 基线高频更新 → 每 T_probe = 30 s 触发 AXB 微探测 → MAC 估 (ĉ, Σ) → SEG 分解 → FPN 商空间后验 → 若 A > τ_amb 且安全则 ADC 追加探测 → 风险缩放与 C-RAS-WM 前缀 → CAC（canary 由 MCG 扩充）。

```python
# IP-253/255 AXB-Probe + MAC：主动手眼激励与元摊销少样本标定
class ActiveHandEyeCalibrator:
    def plan_probe(self, c_hat, Sigma, budget):
        best, best_info = None, -np.inf
        for u in self.safe_candidate_twists():          # 定义 293-iii 安全流形
            F = self.fisher_info(u, c_hat)              # 定义 296
            info = np.log(np.linalg.det(F + self.Lambda_prior))
            if info > best_info:
                best, best_info = u, info
        return best if best_info > self.tau_info else None

    def solve_axxb(self, A_seq, B_seq, X0):
        X = X0                                          # 定义 295：A_i X = X B_i
        for _ in range(2):                              # GN 精修
            J, res = self.axxb_jacobian(A_seq, B_seq, X)
            X = self.retract(X, -np.linalg.lstsq(J, res, rcond=None)[0])
        return X


# IP-255 MAC 元摊销推断（前向，无学习写操作）
class MetaAmortizedCalibrator:
    def infer(self, probe_buffer):
        mu, logvar = self.net(probe_buffer)             # k 段探测 -> 定义 299
        Sigma = self.conformal_scale(softplus(logvar))
        return mu, Sigma


# IP-254/256 SEG + QSpace：结构投影 + 标定商特征
class StructuralEquivarianceGuard:
    def project(self, r, c_hat):
        G = self.generators(c_hat)                      # 李代数生成元 g_j
        P = G @ np.linalg.pinv(G.T @ G) @ G.T           # 定义 297
        r_par = P @ r
        r_perp = r - r_par
        kappa = np.linalg.norm(r_par) / (np.linalg.norm(r) + 1e-9)
        return r_par, r_perp, kappa

    def quotient_features(self, y, c_hat):
        y_cal = self.unapply(y, c_hat)                  # 定义 298：对群作用取逆
        r = self.residual(y_cal)
        _, r_perp, _ = self.project(r, c_hat)
        return np.concatenate([r_perp, self.high_order(y_cal)])


# IP-257/258 FPN + MCG：少样本故障原型 + 元 canary 生成
class FewShotFaultPrototype:
    def posterior(self, phi):
        if not self.prototypes:
            return {'H_cal': 0.5, 'H_fault': 0.5}
        d = {n: np.linalg.norm(phi - p) for n, p in self.prototypes.items()}
        z = np.array([-v / self.tau_fpn for v in d.values()])
        w = np.exp(z - z.max()); w /= w.sum()
        return dict(zip(d.keys(), w))


class MetaCanaryGenerator:
    def propose(self, existing):
        z = self.sample_fault_manifold()
        sig = self.decoder(z)
        if self.normal_energy(sig) >= self.kappa_min and self.novel(sig, existing):
            return sig                               # 定义 302：只收非标定方向
        return None


# IP-259 ADC：主动消歧（VOI 触发，安全预算约束）
class ActiveDisambiguationController:
    def decide(self, post, safe):
        A = 1 - abs(post.get('H_cal', 0) - post.get('H_fault', 0))
        if A > self.tau_amb and safe and self.voi(post) > self.c_probe:
            return 'PROBE'
        return 'CONSERVATIVE'


# IP-262 主闭环：HEXA-RAS round
def HEXA_RAS_round(M, obs):
    y = obs
    # 1) 常态基线：COF 高频维持（探测未触发时）
    r0 = residuals(y)
    c0, U0 = M.cof.step(M.mtm.heads['cal'](y), r0, sigma_stat(M))

    # 2) 周期主动手眼激励（AXB-Probe）
    c_hat, Sigma = c0, M.mac.prior_cov
    if M.schedule.due(M.t, T_probe=30.0):
        u = M.axb.plan_probe(c0, U0, M.probe_budget)
        if u is not None:
            A_seq, B_seq = M.execute_probe(u, watchdog=M.abort_on_anomaly)
            c_hat, Sigma = M.mac.infer(M.probe_buffer)
            c_hat = M.axb.solve_axxb(A_seq, B_seq, c_hat)
            U = np.trace(Sigma)
        else:
            M.log('probe_skipped_low_info')
    else:
        U = U0

    # 3) 结构分解 + 标定商特征（SEG / QSpace）
    r = residuals(y)
    r_par, r_perp, kappa = M.seg.project(r, c_hat)
    phi = M.seg.quotient_features(y, c_hat)

    # 4) 少样本故障后验（FPN，商空间内）
    post = M.fpn.posterior(phi)

    # 5) 主动消歧（ADC）：歧义且安全才探测，否则保守
    decision = M.adc.decide(post, safe=M.probe_safe())
    if decision == 'PROBE':
        u = M.axb.plan_probe(c_hat, U, M.probe_budget)
        A_seq, B_seq = M.execute_probe(u, watchdog=M.abort_on_anomaly)
        c_hat, Sigma = M.mac.infer(M.probe_buffer)
        c_hat = M.axb.solve_axxb(A_seq, B_seq, c_hat)
        phi = M.seg.quotient_features(y, c_hat)
        post = M.fpn.posterior(phi)

    # 6) 不确定性总纪律 + 风险缩放（继承 RAS-WM†）
    lam = max(M.efs.risk_scale(post),
              M.lambda_floor(U, M.adc.ambiguity(post), M.meta_ood(phi)))
    if decision == 'CONSERVATIVE' or M.probe_failed:
        lam = max(lam, 0.95)

    A = M.ach.propose(M.lsf.fuse(M.usr.fuse(y[:4])), H=post)
    k = M.c_ras_wm.certified_prefix(A, post, min(M.vista.m, M.m_emo), M.alpha_chunk)
    tau = M.pi_sigma.prefix_dispatch(A[:k]) * lam

    # 7) 异步：canary 扩充 + 认证提交
    canary = M.mcg.propose(M.cac.canaries)
    M.cac.maybe_commit(M.shadow, dt=M.time_since_last_commit, extra_canaries=[canary])
    M.vqa_h.submit_async(post, {'c': c_hat, 'U': U, 'kappa': kappa, 'probe': decision})
    return k, lam, post, (c_hat, U, kappa)
```

## 3. 推导

**引理 16（运动可辨识秩条件；R68 盲区的形式化）** 对静止段 B_i = I，约束 A_i X = X 只对 A_i 的不动点集有解，外参方向上的 Fisher 信息为零，故 rank(O_mot) < d_c。存在 d_c − rank(O_mot) 维方向上的标定误差与慢姿态漂移**不可区分**。取 m 段绕至少两个非平行轴的旋转（实践 m = 5），可使 rank(O_mot) = d_c，外参在有限噪声下可辨识。系：R68 仅用静态段标定外参/焦距/时延，是本引理意义下的秩亏问题，其「标定吸收慢故障」不是调参失误而是结构必然后果。

**引理 17（结构分离界；慢故障的频域无关检出）** 对任意残差 r，标定只能吸收 r_∥ = P_cal r，法向分量 r_⊥ 在标定更新下不变。设故障 f 的签名满足 ‖r_⊥(f)‖ ≥ τ_det，则检出统计量 s = ‖r_⊥‖ 与 f 的频谱 ω_f 无关。对比 R68 引理 13：那里只保证 ω_f ≥ 3ω_cal 的故障残余 ≥ (2/3)‖r_f‖；本引理把条件从「快」换成「离轨」，因此**任意慢速的非轨道故障均可检出**。注意部分吸收仍会发生：故障若同时含有轨道分量，该分量被标定吃掉、法向分量保留——检出只需法向分量，故不损失功效，但故障幅值估计会有偏（需在 E288 中量化）。

**引理 18（少样本标定误差界）** 在 A95（测试实例到元分布的偏移 D_meta 有界）与探测激励满秩下，Gauss-Newton 精修后的均方误差满足定义 300 之界。直观：k 段探测提供 k·rank(F) 的等效观测，元先验把有效样本量抬为 k_eff = k + tr(Λ_prior F^{-1})；当 k=5、d_c=12 且探测覆盖 3 个旋转轴时，k_eff ≥ 12，误差进入亚度/亚百分比量级。conformal 校准只保证覆盖率，不改变点估计精度。

**引理 19（少样本故障原型的商空间不变性）** 若 φ_fault 对标定群不变（定义 298），且 episodic 训练把标定变换作为 nuisance 增广，则标定误差对原型距离的贡献为零；泛化误差 ≤ O(√(d_feat/(N·K))) + β_novel。这消除了 R68「漂移污染故障签名、阈值需随标定漂移重调」的耦合，是少样本原型能在在线 H 集扩张的前提。

**命题 1（结构不可辨识下界）** 对 f ∈ I_struct（故障签名落在标定轨道切空间内），存在 c_f 使 Ψ(c_f, y_0) 与 y_f 同分布，故对任意仅依赖观测的检验，KL(P(y|f) ‖ P(y|f=0)) = 0，功效为零。**任何算法（包括本方案）都无法把此类故障与标定分开**；唯一出路是外部计量（已知基准件、独立传感器、机械限位、出厂计量溯源）。因此 J_HEXA 必须显式记录「本次任务覆盖的故障子空间 \ I_struct」——证书只对可辨识子空间作承诺。

**定理 16（HEXA-RAS 端到端风险一致性）** 在 A87–A95 下，输出 τ_cmd 满足：
1. P(|τ_cmd − τ*| > ε) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_vqa + α_cal + α_mac + α_fpn + α_probe；
2. **非轨道慢故障**（f ∉ I_struct）的检出概率与故障时频无关，≥ 1 − δ_det（引理 17）；
3. **歧义处理完备**：A > τ_amb 时，若存在安全探测则执行 AXB/ADC 探测，否则 λ ≥ 0.95 ∧ k = k_min（定义 303–304）；两条分支都不放宽；
4. **元先验 OOD** 时自适应退回非摊销 GN 标定并抬高 λ 下限，禁止摊销网络的过度自信直接进入风险缩放；
5. **诚实排除**：对 f ∈ I_struct 不作检出承诺，证书标注不可辨识子空间（命题 1）。

**定理 17（主动探测安全性）** 在安全流形 𝒰_safe、预算约束与看门狗（残差/力突变 > τ_abort 中止）下，单次探测导致安全违规的概率 ≤ δ_probe；探测不改变 λ 的单调性（任何探测失败都抬升 λ）；仅在 VOI > c_probe 且 A > τ_amb 时触发，故探测的期望净收益（信息收益 − 安全成本）非负。系：探测不会因「想知道更多」而突破 R68 的实时安全不变式；最坏情况退化为不探测的 CALM-RAS 基线。

## 3. 关键算法伪代码

```python
# IP-253/255：主动手眼激励 + 元摊销少样本标定 + GN 精修
class ActiveHandEyeCalibrator:
    def plan_probe(self, c_hat, Sigma, budget):        # 定义 296
        best, best_info = None, -np.inf
        for u in self.safe_candidate_twists():         # 定义 293-iii
            F = self.fisher_info(u, c_hat)
            info = np.log(np.linalg.det(F + self.Lambda_prior))
            if info > best_info: best, best_info = u, info
        return best if best_info > self.tau_info else None

    def solve_axxb(self, A_seq, B_seq, X0):            # 定义 295
        X = X0
        for _ in range(2):
            J, res = self.axxb_jacobian(A_seq, B_seq, X)
            X = self.retract(X, -np.linalg.lstsq(J, res, rcond=None)[0])
        return X

class MetaAmortizedCalibrator:                          # 定义 299
    def infer(self, probe_buffer):
        mu, logvar = self.net(probe_buffer)
        return mu, self.conformal_scale(softplus(logvar))

# IP-254/256：结构投影 + 标定商特征
class StructuralEquivarianceGuard:
    def project(self, r, c_hat):                        # 定义 297
        G = self.generators(c_hat)
        P = G @ np.linalg.pinv(G.T @ G) @ G.T
        r_par, r_perp = P @ r, r - P @ r
        return r_par, r_perp, np.linalg.norm(r_par) / (np.linalg.norm(r) + 1e-9)

    def quotient_features(self, y, c_hat):              # 定义 298
        y_cal = self.unapply(y, c_hat)
        _, r_perp, _ = self.project(self.residual(y_cal), c_hat)
        return np.concatenate([r_perp, self.high_order(y_cal)])

# IP-257/258：少样本故障原型 + 元 canary
class FewShotFaultPrototype:                            # 定义 301
    def posterior(self, phi):
        if not self.prototypes: return {'H_cal': .5, 'H_fault': .5}
        d = {n: np.linalg.norm(phi - p) for n, p in self.prototypes.items()}
        z = np.array([-v / self.tau_fpn for v in d.values()])
        w = np.exp(z - z.max()); w /= w.sum()
        return dict(zip(d.keys(), w))

class MetaCanaryGenerator:                              # 定义 302
    def propose(self, existing):
        sig = self.decoder(self.sample_fault_manifold())
        return sig if (self.normal_energy(sig) >= self.kappa_min
                       and self.novel(sig, existing)) else None

# IP-259：主动消歧
class ActiveDisambiguationController:                   # 定义 303
    def decide(self, post, safe):
        A = 1 - abs(post.get('H_cal', 0) - post.get('H_fault', 0))
        return 'PROBE' if (A > self.tau_amb and safe
                           and self.voi(post) > self.c_probe) else 'CONSERVATIVE'

# IP-262：主闭环
def HEXA_RAS_round(M, obs):
    y = obs
    r0 = residuals(y)                                             # 1) COF 基线
    c0, U0 = M.cof.step(M.mtm.heads['cal'](y), r0, sigma_stat(M))

    c_hat, Sigma = c0, M.mac.prior_cov                              # 2) 周期 AXB 探测
    if M.schedule.due(M.t, T_probe=30.0):
        u = M.axb.plan_probe(c0, U0, M.probe_budget)
        if u is not None:
            A_seq, B_seq = M.execute_probe(u, watchdog=M.abort_on_anomaly)
            c_hat, Sigma = M.mac.infer(M.probe_buffer)
            c_hat = M.axb.solve_axxb(A_seq, B_seq, c_hat)
    U = np.trace(Sigma)

    r = residuals(y)                                               # 3) SEG / QSpace
    r_par, r_perp, kappa = M.seg.project(r, c_hat)
    phi = M.seg.quotient_features(y, c_hat)

    post = M.fpn.posterior(phi)                                    # 4) 少样本故障后验

    decision = M.adc.decide(post, safe=M.probe_safe())             # 5) ADC 消歧
    if decision == 'PROBE':
        u = M.axb.plan_probe(c_hat, U, M.probe_budget)
        A_seq, B_seq = M.execute_probe(u, watchdog=M.abort_on_anomaly)
        c_hat, Sigma = M.mac.infer(M.probe_buffer)
        c_hat = M.axb.solve_axxb(A_seq, B_seq, c_hat)
        phi = M.seg.quotient_features(y, c_hat)
        post = M.fpn.posterior(phi)

    lam = max(M.efs.risk_scale(post),                              # 6) 总纪律
              M.lambda_floor(np.trace(Sigma), M.adc.ambiguity(post), M.meta_ood(phi)))
    if decision == 'CONSERVATIVE' or M.probe_failed:
        lam = max(lam, 0.95)

    A = M.ach.propose(M.lsf.fuse(M.usr.fuse(y[:4])), H=post)       # 7) 认证前缀
    k = M.c_ras_wm.certified_prefix(A, post, min(M.vista.m, M.m_emo), M.alpha_chunk)
    tau = M.pi_sigma.prefix_dispatch(A[:k]) * lam

    canary = M.mcg.propose(M.cac.canaries)                         # 8) 异步
    M.cac.maybe_commit(M.shadow, dt=M.time_since_last_commit, extra_canaries=[canary])
    M.vqa_h.submit_async(post, {'c': c_hat, 'U': U, 'kappa': kappa, 'probe': decision})
    return k, lam, post, (c_hat, U, kappa)
```

## 4. 推导

**引理 16（运动可辨识秩条件；R68 盲区）** 静止段 B_i = I 时 Fisher 信息在外参方向为零，rank(O_mot) < d_c，标定误差与慢姿态漂移不可区分。m 段绕至少两个非平行轴的旋转（实践 m=5）可使 rank = d_c。系：R68 仅用静态段标定外参/焦距/时延，是结构性秩亏，「慢故障被吸收」是必然后果而非调参问题。

**引理 17（结构分离界；慢故障频域无关检出）** 标定只吸收 r_∥，r_⊥ 在标定更新下不变。若故障满足 ‖r_⊥(f)‖ ≥ τ_det，则检出与 ω_f 无关。这补上 R68 引理 13 仅覆盖 ω_f ≥ 3ω_cal 的漏洞：判别条件由「快」变为「离轨」。故障的轨道分量仍会被吸收，故幅值估计有偏，但检出功效不损（法向分量保留）。

**引理 18（少样本标定界）** 元先验使有效样本量 k_eff = k + tr(Λ_prior F^{-1})；k=5、d_c=12、覆盖 3 个旋转轴时 k_eff ≥ 12，误差进入亚度/亚百分比量级（定义 300）。conformal 只保证覆盖率。

**引理 19（少样本原型的商空间不变性）** 若 φ_fault 对标定群不变且 episodic 训练含标定 nuisance 增广，则标定误差对原型距离贡献为零；泛化误差 ≤ O(√(d_feat/(N·K))) + β_novel。由此摆脱 R68「阈值需随标定漂移重调」的耦合。

**命题 1（结构不可辨识下界）** 对 f ∈ I_struct，存在 c_f 使 Ψ(c_f,y_0) 与 y_f 同分布，任何仅依赖观测的检验功效为零；必须引入外部计量。J_HEXA 因此只对「可辨识子空间 \ I_struct」作承诺。

**定理 16（端到端风险一致性）** 在 A87–A95 下：(1) 误差 ≤ α_chunk + δ_fi + α_emotion + α_wm + α_vqa + α_cal + α_mac + α_fpn + α_probe；(2) 非轨道慢故障检出概率与频率无关，≥ 1−δ_det；(3) A > τ_amb 时「安全则探测、否则 λ≥0.95 ∧ k=k_min」，两分支都不放宽；(4) 元先验 OOD 退回非摊销 GN 并抬高 λ；(5) f ∈ I_struct 不作检出承诺，证书显式标注。

**定理 17（主动探测安全性）** 在 𝒰_safe、预算与看门狗下，单次探测违规概率 ≤ δ_probe；探测失败只抬升 λ（单调性不变）；仅当 A>τ_amb ∧ VOI>c_probe 才触发，故期望净收益非负。最坏情况退化为不探测的 CALM-RAS 基线。

## 7. 本轮最大风险

**一句话**：HEXA-RAS 把安全押在「真故障不在标定群轨道上」这一结构假设上——**若退化本身就是一个群元素（相机支架缓松、连杆热伸长、云台蠕变），它在观测上与标定完全同构，主动激励越充分、标定越精确，这种结构性退化就越被合法吸收，甚至被探测动作加速；而它恰好是本方案唯一不承诺检出的 I_struct。**

**次级风险与缓解**：
1. **元先验 OOD / 摊销过度自信** → conformal 校准 + OOD 检测 + 退回非摊销 GN + λ 抬升（定义 303–304、定理 16-4）；
2. **探测诱发危险或诱发故障（松关节只在激励下暴露）** → 安全流形 + 力/位/速三重看门狗 + E294/E298 专项；失败即 conservative；
3. **标定群模型误设**（非刚体畸变、温度-焦距耦合）→ 残差法向分量会误报为故障；用 E299 不变性检验 + 群模型的版本化与残差审计；
4. **FPN 原型被少数脏 canary 污染** → MCG 只收非轨道样本 + 鲁棒原型（截尾均值）+ 原型版本链；
5. **主动探测占用时间/能耗** → T_probe 30 s 且仅 VOI 触发，开销 < 3%（E293）；探测不在实时关键路径。
