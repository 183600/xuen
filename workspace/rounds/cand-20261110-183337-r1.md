# 第 44 轮（灵感驱动新循环第 1 轮） · Contact-Cert × MPC-Cert：把「接触模式」与「滚动优化」纳入可验证证书闭环（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 把「人」与「并发」纳入证书，但它仍压着两个未言明的连续性假设：**(H3) 动力学分段光滑、无接触跳变**——所以租约衰减 λ=L_m·v_max、CBF 边际、几何证书都默认状态连续演化；**(H4) 证书要么在查表里、要么离线可合成，规划与认证是两件事**——所以从未处理「在线求不出可行解」这一最常见故障。本轮灵感词「抓取」「模型预测控制」精确命中这两个假设：**抓取**是接触富集操作，冲击使速度瞬时跳变、摩擦锥在粘/滑之间切换，令 λ 与几何分离裕度同时失真；**模型预测控制**既是滚动时域控制器，也应被当作**在线证书合成器**：一次可行求解天然产出「候选轨迹 + 扰动管 + 终端不变集 + 有效期」，而递归可行性就是它的时序 sound 性定理。二者耦合处是本轮真正的新问题：**接触事件会使在途证书与租约集体失效**，而 MPC 的可行域又依赖接触模式假设——模式错，则优化「可行」但物理不安全。

## 0. 直觉与动机

**灵感 1（抓取 → 接触是「证书的断点」，不是噪声）**：直觉上，抓取最危险的瞬间不是稳定夹持，而是**接触建立 / 断开 / 滑移**的几毫秒：速度不连续、库仑锥临界、恢复系数未知。v20 的租约假设 ||x(t)−x(τ)|| ≤ v_max·(t−τ)，在冲击下被一个跳跃直接击穿——租约仍显示「新鲜」，物理已进入新模式。因此把接触提升为一等公民：定义**接触模式 q**（自由、接触建立、粘、滑、滚、断开）、互补条件与冲击复位映射；每个模式携带自己的不变集 I_q 与守卫；每次接触事件递增 **contact epoch**，**原子地撤销所有在途租约与派生证书**，强制在下一次动作前重新认证。一句话：**连续时用租约，跳变时用 epoch**。

**灵感 2（MPC → 可行性就是安全，求解失败必须降级而非降安全）**：直觉上，MPC 每拍解一个带约束的有限时域问题，只要终端集是受控不变的，就能「一拍可行、步步可行」。所以 MPC 不只是控制器，而是**携带证书的证书合成器**：证书 C=(候选轨迹, 扰动管 Z, 终端不变集 Ω, 有效期 T_valid, 对偶裕度)。工程三件套：**(a) tube MPC** 把约束按 Z 收紧，使名义轨迹在真实扰动下仍可行；**(b) plan lease** 把「上一拍解的后半段」当作可执行尾巴，求解超时也不至于无动作可执行；**(c) 安全兜底策略 π_safe**（CBF/CAR 给的不变集 S）保证任一时刻「要么新证书有效、要么 x∈S」，从而**超时＝降级到兜底，而非降级到不安全**。一句话：**MPC 负责扩张可行域，兜底负责守住下界**。

**灵感 3（耦合 → 接触调度 × 模式条件 MPC × 抓取证书格）**：抓取同时含离散（用哪几个接触、粘还是滑）与连续（力/位）两层决策，接触隐式 MPC 是组合爆炸的混合整数问题。因此解耦：**CMCA**（接触模式自动机）提出接触调度与模式守卫；**CC-MPC** 在固定调度下优化连续输入并出证书；**GCM**（抓取证书模块）用鲁棒力闭合裕度 ρ 验证该调度在 μ、e 不确定域内仍成立。三者以 IP-47 组合契约求交：证书 a* 仅在「模式守卫 ∧ MPC 证书 ∧ 力闭合证书 ∧ persona 力上限」全通过时可选；任一失败则切到同模式的兜底（限力回撤/安全释放）。物理滑移一旦被监控发现，epoch 跳变使该调度证书作废，只能在新模式重规划或兜底——**绝不把「优化可行」误当作「物理安全」**。

**耦合升级**：CMCA 把连续控制离散化为可审计的模式图；CC-MPC 把优化可行性变成可携带、可过期、可兜底的证书；GCM 把抓取质量从启发式打分变成对 μ/e 鲁棒的力闭合证明。四层架构由 v8 的「人格契约层 + 并发证书层」升级为 v9 的「＋接触模式层 ＋滚动证书合成层」。

## 1. 形式化定义（增量：定义 44–50）

**定义 44（接触模式混合系统与接触纪元）**：H=(X,Q,U,F,Guard,Reset,Θ)。模式 q∈Q，连续流 ẋ=f_q(x,u,w)；守卫 Guard_{q→q'}；冲击复位 R_{q→q'}(x,θ) 带恢复系数；接触满足互补 0≤λ_n ⊥ φ(x)≥0，粘/滑由 |f_t|≤μ f_n 判定；不确定参数 θ=(μ,e)∈Θ=[μ_lo,μ_hi]×[e_lo,e_hi]。**接触纪元** E(t)∈ℕ 在每次接触建立/断开/滑移/冲击时 +1。**撤销规则**：epoch 变化使所有 τ<E(t) 签发的租约与派生证书立即失效。

**定义 45（鲁棒接触转移证书）**：转移 q→q' 的证书 φ_{q→q'} 成立，当且仅当 ∀x∈I_q∩Guard_{q→q'}、∀θ∈Θ：R_{q→q'}(x,θ)∈I_{q'}，且新模式守卫与不变集在 Θ 下成立。**命题（接触-混合 sound 性）**：若 ∀q，I_q 在模式内受控不变；∀转移，φ_{q→q'} 成立；则对任意有限交错与任意 θ∈Θ，混合执行始终停留在 ∪_q(I_q×{q})。**推论**：接触安全不需要枚举无限模式序列，只需逐转移验证 + 模式图上的可达性剪枝。

**定义 46（携带证书的 MPC，CC-MPC）**：证书 C=(x_0,{u_k}_{k=0}^{N−1},Z,Ω,κ_f,T_valid,d)，满足：(i) 名义轨迹在收紧约束 X⊖Z、U⊖KZ 内；(ii) 终端 x_N∈Ω，Ω 在终端控制器 κ_f 下鲁棒不变；(iii) 扰动 w∈W⊆Z 的管包含；(iv) 有效期 T_valid 步。**命题（证书 sound 性）**：若在 T_valid 内执行同一候选（或其可行尾段），则真实状态 ∀k≤T_valid 落在 X 内且不越过任何守卫。

**定义 47（递归可行性与兜底定理）**：设 π_safe 为兜底策略，其证书不变集 S⊆X（由 CBF/CAR 给出）在任意模式内受控不变。**定理**：若任一时刻 t 满足「C_t 有效 ∨ x_t∈S」，且策略在 C_t 失效时切换 π_safe，则无限时域安全成立。**推论**：求解超时、不可行、数值失败都只降低性能，不破坏安全性；**求解失败 ≠ 安全失败**。

**定义 48（对偶证书、margin 与接触感知衰减）**：对凸 QP-MPC，最优处 KKT 影子价格 y_j≥0、约束松驰 s_j≥0。定义**对偶裕度** m_dual = min_j s_j/||∇h_j||（或由对偶下界给出），作为租约测量值 m。**命题**：在 Z 管内的任意扰动下，m_dual 是真实约束裕度的下界。**接触修正**：模式内 λ=L_m·v_max；**跨 epoch 不平移**，冲击事件强制撤销租约，重新测量 m_dual 后签发新租约。

**定义 49（鲁棒抓取证书与力闭合裕度）**：接触集给出力旋量可达集 W_c(θ)=Σ_k cone(f_k; C_{μ_k})；**鲁棒力闭合裕度** ρ = min_{θ∈Θ} dist(0, ∂W_c(θ))（到可达旋量凸包边界的距离）。**滑移守卫**：|f_t| ≤ μ_lo·f_n − ρ 且 ρ>ρ_min 才允许执行。**证书格**按 (ρ, 接触数, 模式稳定性) 偏序，选择只在「ρ 最大且证书有效」的调度上做，而非启发式打分。

**定义 50（接触事件触发的证书撤销与重认证）**：监控器检测到滑移/异常冲击/接触丢失 → E+1 → 撤销租约与 CC-MPC 证书 → 状态置为「未认证」→ 若 ∈S 则执行 π_safe；否则进入**受控接触恢复**（限力回撤/安全释放）并重规划。**命题**：撤销是原子的（epoch 单调 + seqlock 快照），不存在「半撤销」窗口；重认证前的任何守卫查询都返回不安全。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 CONTACT-MODE CERTIFICATE AUTOMATON（接触模式证书自动机 CMCA）
1. **模式图与互补守卫**：自由/建立/粘/滑/滚/断开六类模式；守卫用互补条件与摩擦锥边界，模式内不变集 I_q。
2. **鲁棒冲击证书**：对 θ∈Θ 的区间复位，验证 R(x,θ)∈I_{q'}；重冲击用保守 e 上界、滑移用 μ 下界。
3. **接触纪元与撤销**：每次接触事件 E+1，原子撤销在途租约/证书；与 IP-58 的 epoch/seqlock 共用一致性机制。
4. **模式图剪枝**：只沿「可达 ∧ 证书可证」的模式探索，用支配关系删去被更保守模式支配的节点，避免组合爆炸。

### 2.2 IP-61 CERTIFICATE-CARRYING MPC（携带证书的 MPC，CC-MPC）
1. **Tube MPC + 终端不变集**：按扰动管 Z 收紧约束；终端集 Ω 与 κ_f 离线认证；在线只做可行性检查。
2. **对偶证书提取**：从 QP 对偶变量取 m_dual 与敏感度，喂给 IP-58 租约与 IP-51 守卫。
3. **Plan lease（计划租约）**：缓存上一拍后半段作为可执行尾巴；新解失败时执行尾巴或兜底，保证「永远有动作」。
4. **兜底契约**：π_safe 的不变集 S 由 CBF/CAR 保证；任一模式内 S 受控不变；切换只删不增。

### 2.3 IP-62 GRASP-CERTIFICATE MODULE（抓取证书模块 GCM）
1. **鲁棒力闭合**：对 μ 区间做摩擦锥外逼近（sound 外近似，绝不内逼近放行），算 ρ。
2. **滑移守卫与接触力上限**：|f_t|≤μ_lo·f_n−ρ；persona 力上限作为硬约束进入 MPC。
3. **抓取调度选择格**：按 (ρ, 接触数, 模式稳定) 偏序选择；只用证书有效调度。
4. **模板检索**：从 IP-55 CKB 检索抓取模板与接触模式指纹，Sim 验证后入库。

        → 力闭合与 persona 求交 → 守卫(mode∧lease∧cert) → 执行 + 力/滑移监控

## 5. 本轮最大风险

**一句话**：接触证书所依赖的 μ/e 区间在运行期本质不可观测，单次未建模冲击或滑移即可在两个监控周期之间同时击穿模式不变集与 MPC 扰动管——若兜底不变集 S 本身建立在错误接触模型上，「可认证抓取」会退化为乐观仿真——故 E95/E97 设为红线，并默认保留一条**不依赖任何学习接触模型**的硬件级限力「回撤/释放」兜底。

## 2. 关键算法（伪代码）

### IP-60 CMCA：模式转移证书、纪元撤销与剪枝
```
def on_contact_event(evt, E):
    if evt in {SLIP, CONTACT_LOSS, ABNORMAL_IMPACT}:
        atomic_increment(E)                   # seqlock：E 单调
        revoke_leases(older_than=E)           # 旧租约/派生证书整批失效
        invalidate_mpc_certs()
        return UNCERTIFIED
    return CERTIFIED if evt is NONE else UNCERTIFIED

def transition_certified(q, qn, I_q, I_qn, Theta):
    for x in boundary(intersect(I_q, Guard[q][qn])):
        for theta in box_partition(Theta):    # μ∈[lo,hi], e∈[lo,hi]
            if reset_map(q, qn, x, theta) not in I_qn:
                return False                  # 逐转移反例
    return True

def prune_modes(Q, Theta):
    # 只保留「局部不变 ∧ 逐转移可证」的模式；被更保守模式支配者删除
    ok = [q for q in Q if locally_invariant(q)]
    return prune_dominated([q for q in ok
                            if all(transition_certified(q, qn, I[q], I[qn], Theta)
                                   for qn in successors(q))])
```

### IP-61 CC-MPC：tube、对偶证书、plan lease 与兜底
```
def cc_mpc_step(x, mode, E, Z, Omega, kappa_f, t_max):
    if mode.epoch != E: return fallback(x, mode)          # 接触事件后未认证
    prob = build_tube_mpc(x, mode, tighten(X, Z), tighten(U, KZ), Omega)
    sol  = solve_with_deadline(prob, t_max)
    if not sol.feasible:
        return plan_lease_or_fallback(x, mode)            # 用上一拍尾段或兜底
    C = Cert(x0=x, plan=sol.u, Z=Z, Omega=Omega,
             T_valid=sol.horizon, dual=extract_kkt(sol))
    if not audit(C, mode):                                # 独立区间审计
        return plan_lease_or_fallback(x, mode)
    store_plan_lease(C, mode, E)
    return C

def extract_kkt(sol):
    return DualCert(m_dual=min(s_j / norm(grad_j) for j in active(sol)),
                    sensitivity=sol.multipliers)          # 影子价格 ≥ 0

def execute_with_backup(C, pi_safe, S, mode, E):
    if C is not None and C.valid and mode.epoch == E and mode.valid \
       and C.contains(current_state()):
        return C.plan[0]
    if current_state() in S:
        return pi_safe(current_state())                   # 不变集内降级
    return certified_recovery(mode)                       # 受控恢复

def plan_lease_or_fallback(x, mode):
    tail = shift_plan_lease(x, mode)                      # 可执行尾段
    return tail if tail is not None and audit(tail, mode) \
           else certified_recovery(mode)
```

### IP-62 GCM：鲁棒力闭合、滑移守卫与证书格选择
```
def robust_force_closure(contacts, Theta):
    rho = +inf
    for theta in box_partition(Theta):
        W = wrench_polytope_outer(contacts, mu=theta.mu)  # sound 外近似
        rho = min(rho, dist_to_boundary(0, W))            # 绝不用内近似放行
    return rho

def slip_guard(fn, ft, mu_lo, rho, rho_min):
    return abs(ft) <= mu_lo * fn - rho and rho >= rho_min

def select_grasp_schedule(cands, persona, Theta):
    scored = [(c, robust_force_closure(c.contacts, Theta)) for c in cands]
    valid  = [(c, r) for c, r in scored
              if r >= rho_min and c.force_cap <= persona.force_cap]
    if not valid:
        return safe_release_or_negotiate()                # 空集绝不静默执行
    return max(valid, key=lambda cr: cr[1])               # 按 ρ 偏序
```

### IP-39/51/56 升级：接触-优化感知的守卫与降级
```
def guard_query(e, x, mode, cert, lease, persona, E):
    if mode.epoch != E or not mode.valid:                 # 接触事件撤销
        return UNSAFE
    m = min(cert.dual.m_dual,
            lease.m - lease.lam * (now() - lease.tau),    # 模式内衰减
            persona.cap[e])                               # 人格力上限收缩
    return (m >= theta[e]) and (lease.epoch == E) and cert.valid

def certified_recovery(mode):
    # 硬件级限力兜底：不依赖任何学习接触模型 / 不确定 μ,e
    return force_limited_retract_or_release(max_force=HARD_FMAX,
                                            max_rate=HARD_VMAX)
```

| 风险 | 等级 | 缓解措施 |

| 一次未建模冲击在两个监控周期之间击穿模式不变集与 MPC 扰动管 | 高 | 接触事件 epoch 原子撤销；监控最高关键级；硬件级限力兜底不依赖模型 |

## 6. 本轮最大风险

**一句话**：接触证书所依赖的 μ/e 区间在运行期本质不可观测，单次未建模冲击或滑移即可在两个监控周期之间同时击穿模式不变集与 MPC 扰动管——若兜底不变集 S 本身建立在错误接触模型上，「可认证抓取」会退化为乐观仿真——故 E95/E97 设为红线，并默认保留一条**不依赖任何学习接触模型**的硬件级限力「回撤/释放」兜底。
