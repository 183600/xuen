# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC IP-153~160；灵感循环第 7 轮；本轮灵感：「自主导航」×「物体泛化」）

> 第 60 轮把「场景」建模为阻抗先验 π_scene(K|z)，并用 SERC 打通「场景→意图→约束→阻抗→执行→EV-exec→场景更新」。但**四个与「物体」相关的核心局限**仍未解决：
> 1. **场景内物体方差被平均掉**：SSM 只有场景 z，没有物体 o。同一「桌面场景」下陶瓷杯、塑料杯、纸箱的接触阻抗差异极大，却共享同一场景先验 μ_scene(z)——「场景对了，物体错了」的执行失效无法解释。
> 2. **物体泛化仍是离散查表**：未见物体只能回退 `unknown` 通用先验，泛化=失败后回退，**没有连续性**；「物体有多像」无法量化，更无法给出泛化误差界。
> 3. **探测是被动的**：`closed_loop_exec_probe` 只在当前接触点闭环，缺少「导航级」决策——**去哪里摸、从哪个方向接近、用多大速度**，即自主导航的「去哪里」从未进入接触信息获取。
> 4. **证据链按时间而非身份组织**：EPIR 用 `seq_id` 保序，但跨物体经验无法按「物体身份」检索/迁移；换一个物体，此前的 EV-exec 全部不可复用。

## 0. 直觉与动机

**灵感 1（物体泛化 → 物体阻抗泛化场 OIGF）**
直觉：把「物体」从**离散类别标签**变成**接触动力学流形上的一个点**。两个物体「像不像」不由视觉类别决定，而由「摸上去的力-位移曲线像不像」决定。在接触嵌入空间做核回归/GP，未见物体 = 邻近已知物体阻抗的**连续插值**，而不是查表命中或失败回退。关键洞见：**泛化能力 = 阻抗场在嵌入空间上的 Lipschitz 光滑度**。

**灵感 2（自主导航 → 信息性探测路径规划 IPPP）**
直觉：导航的「去哪」与操作的「摸哪」应统一。机器人应选择一条探测轨迹（接触点序列 + 接近方向 + 速度 + 力上限），使**单位成本的信息增益**最大：`VOI_probe = E[IG(K; y)] / cost`。把「物体泛化」重构为「**主动减少泛化不确定性的导航**」，而不是被动观测。关键洞见：**摸哪里本身就是泛化的一部分**。

**灵感 3（泛化 → 保形阻抗预测集 CIPS）**
直觉：泛化必须自带「知道自己不知道」的证书。用保形预测为未见物体的阻抗给出**有限样本、分布无关**的覆盖集 C_α(o)，而非点估计：可交换性下 `P(K(o) ∈ C_α(o)) ≥ 1-α`。这把第 59/60 轮的「执行证书 Cert_eeis / 证据链」升级为「**泛化可信证书**」。关键洞见：**点估计会撒谎，集合不会**。

**灵感 4（导航×操作 → 可供性-阻抗地图 AIM）**
直觉：把导航栅格/可接近表面挂上**可供性向量 + 阻抗后验**。路径规划不仅避障，还选「接近哪个面、从哪个方向接近」，以同时匹配夹爪可行性与阻抗不确定性。关键洞见：**接近方向是阻抗自由度，不只是几何自由度**。

**灵感 5（跨轮合流 → 阻抗图谱 Z-Atlas + 导航-泛化闭环 NIGL）**
直觉：把 EPIR 按 `seq_id` 的时序证据链，重构为按**物体嵌入索引**的「阻抗图谱」。每个 EV-exec 成为图谱上一个观测，用 GP 后验更新；新物体的保形集由图谱的局部后验校准。闭环：**导航到候选物体 → 主动探测 → 保形预测 → 与场景安全集求交 → 执行 → 证据入图谱 → 重校准**。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（物体阻抗泛化场 OIGF）** 物体阻抗泛化场 Z = (O, d_O, Z, L)。其中：
- **物体空间**：O 为可接触物体集合；d_O 由接触嵌入 e: O→R^d 诱导，`d_O(o,o') = ||e(o)−e(o')||₂`
- **阻抗场**：Z: O → P(K)，把物体映射为阻抗参数上的分布（均值函数 μ_Z(o)、协方差函数 Σ_Z(o)）
- **Lipschitz 假设**：`W₂(Z(o), Z(o')) ≤ L·d_O(o,o')`，L 为泛化光滑常数
- **泛化误差界**：若 o_NN 为 o 在已知集中的最近邻，则 `W₂(Z(o), Ẑ(o)) ≤ L·d_O(o,o_NN) + O(1/√k)`，k 为近邻数
- 场景先验作为**边界约束**：`Z(o)|_{scene=z} ⊆ π_scene(K|z)`，即物体先验必须与当前场景先验相容，否则触发「场景-物体冲突」降级

**定义 162（接触嵌入 e）** 自监督对比嵌入 e: O→R^d，满足：
- **正样本对**：同一物体不同接触位置/速度/力上限下的力-位移响应片段
- **负样本对**：不同物体的响应片段
- **训练目标**：`L_triplet = Σ max(0, d(e(o),e(o⁺)) − d(e(o),e(o⁻)) + m)`，使**接触动力学相似者距离近**（而非视觉相似者）
- **一致性约束**：`|Ẑ(o) − Ẑ(o')| ≤ L·d_O(o,o')`，泛化界由此闭合

**定义 163（保形阻抗预测集 CIPS）** 给定校准集 `D_cal = {(o_i, K_i)}_{i=1..n}`（可交换采样）、非一致性分数 `s(o,K) = W₂(δ_K, Ẑ(o))`（或 Mahalanobis 距离）：
- **分位数**：`q = Quantile_{⌈(n+1)(1−α)⌉/n}({s(o_i,K_i)})`
- **预测集**：`C_α(o) = {K : s(o,K) ≤ q}`
- **覆盖定理**：若 `(o_i,K_i)` 与测试点 `(o,K)` 可交换，则 `P(K ∈ C_α(o)) ≥ 1−α`（有限样本、分布无关）
- **自适应半径**：结合定义 161 的 Lipschitz 界，`C_α(o)` 的半径随 `d_O(o, o_NN)` 增大而增大——**越不熟悉越保守**，这正是泛化应有的姿态

**定义 164（信息性探测路径规划 IPPP）** 探测动作 `a = (p_contact, n_approach, v, F_max)`；探测路径 `π = (a₁,...,a_m)`。定义：
- **信息增益**：`IG(a | D) = H(K | D) − E_{y~p(y|a)}[H(K | D ∪ {(a,y)})]`（GP 后验熵减）
- **探测成本**：`cost(a) = λ_move·||p−p_cur|| + λ_time·t_contact(a) + λ_risk·R_contact(a)`
- **预算约束**：`Σ cost(a_i) ≤ B_probe`（B_probe 为第 60 轮 PCE++++ 预算的执行子预算）
- **决策**：`π* = argmax_{π: Σcost ≤ B_probe} IG(π)/cost(π)`
- **次模性假设**：若 `IG(·)` 关于探测集合次模，则贪心达到 `(1−1/e)` 的 OPT 近似

**定义 165（可供性-阻抗地图 AIM）** 分层地图 `M_AIM = (X, A, Z)`：
- **空间层** X：导航栅格或可接近表面集合（来自自主导航的度量/拓扑地图）
- **可供性层** A: X → {抓取, 推, 放置, 不可触} × 可行接近方向锥
- **阻抗层** Z: X → 阻抗后验（定义 161 在空间上的投影）
- **路径代价**：`J(path) = Σ_i [w_d·dist(x_i,x_{i+1}) + w_r·risk(Z(x_i)) + w_u·uncertainty(Z(x_i))]`
- 规划目标同时最小化「走多远」「碰多险」「摸多不确定」——**导航即泛化前的采样设计**

**定义 166（阻抗图谱 Z-Atlas）** 图谱 `G_Z = {(o_j, e_j, K_j, EV-exec_j)}`，以 GP 后验组织：
- **先验**：`Z ~ GP(μ₀, k_Matérn(e(o), e(o')))`
- **后验**：给定观测 `{(e_j, K_j)}`，`Z(o) | obs ~ N(μ_Z(o), σ²_Z(o))`
- **与 EPIR 的分工**：EPIR 保证**时序完整性**（seq_id + hash），Z-Atlas 保证**身份可检索性**（按 e(o) 索引）；二者用 EV-exec 的 `(object_id, embedding)` 字段关联
- **冷启动**：图谱为空时退化为第 60 轮 π_scene 场景先验（保证不会比旧方案更差）

**定义 167（泛化有效域与 OOD 判定）** 有效域 `D_ε = {o : σ_Z(o) ≤ ε ∧ ρ(e(o)) ≥ ρ_min}`，其中 ρ 为嵌入空间局部密度估计。判定规则：
```
if o ∉ D_ε:            # OOD / 外推
    status ← OOD
    K_exec ← K_conservative          # 强制保守，禁止外推
    must_probe ← True                # 先探测后执行
else:
    status ← IN_DOMAIN
    K_exec ← argmin_{K ∈ C_α(o) ∩ K_safe^scene} J(K)
```
**安全不变式**：任何 `K_exec` 若来自外推（o ∉ D_ε）则一律拒绝下发——**泛化可以失败，但外推不许上线**。

**定义 168（导航-泛化闭环 NIGL）** 算子 `NIGL(M, goal, B_probe)`：
```
① AIM: 在 M_AIM 上定位候选物体集 O_cand = {o : A(o) 支持 goal}
② Nav: 选择目标 o* 与接近方向 n*，满足 J(path) 最小
③ Embed: e(o*) ← e.encode(感官观测)
④ OOD:  if o* ∉ D_ε: π* ← IPPP.plan(o*, B_probe)；执行探测，观测入 Z-Atlas
⑤ CIPS: C_α(o*) ← Conformal.predict(e(o*))
⑥ Fuse: K_cand ← C_α(o*) ∩ K_safe^scene(z) ∩ K_safe_base   # 泛化×场景×执行三方求交
⑦ Guard: if K_cand = ∅: return CONSERVATIVE_OR_DEGRADE
⑧ Exec: K* ← EEIS.compile(δ_f_req, K_cand)；ERTC.lock()；execute(K*)
⑨ Evi:  EV-exec ← build_exec_evidence(...)；EPIR.append(EV-exec)
⑩ Atlas: Z-Atlas.update(e(o*), EV-exec.K)；CIPS.recalibrate()
⑪ Cert: Cert_gen ← (C_α, D_ε, OOD_flag, coverage_level)；return (K*, EV-exec, Cert_gen)
```

## 2. 关键算法伪代码

### IP-161 OIGF（物体阻抗泛化场）

```python
class ObjectImpedanceField:
    def __init__(self, embedder, atlas, L=1.0, k=5):
        self.e = embedder          # 定义 162 的接触嵌入
        self.atlas = atlas         # 定义 166 的 Z-Atlas
        self.L = L                 # Lipschitz 常数（可在线估计）
        self.k = k

    def predict(self, obj_obs):
        z = self.e.encode(obj_obs)
        nn = self.atlas.knearest(z, k=self.k)
        d = np.array([dist(z, n.e) for n in nn])
        w = softmax(-d / max(self.L, 1e-6))
        mu = sum(wi * n.K_mean for wi, n in zip(w, nn))
        cov = sum(wi * (n.K_cov + np.outer(n.K_mean - mu, n.K_mean - mu))
                  for wi, n in zip(w, nn))
        radius = self.L * d.min()          # 泛化误差半径（定义 161）
        return ImpedancePosterior(mu, cov, radius, d.min())
```

### IP-162 接触嵌入（自监督对比）

```python
class ContactEmbedder:
    def __init__(self, dim=32, margin=0.2):
        self.enc = ForceDisplacementEncoder(out_dim=dim)
        self.m = margin

    def triplet_loss(self, anchor, pos, neg):
        da = torch.norm(self.enc(anchor) - self.enc(pos), dim=-1)
        dn = torch.norm(self.enc(anchor) - self.enc(neg), dim=-1)
        return torch.relu(da - dn + self.m).mean()

    def encode(self, obj_obs):
        return self.enc(force_displacement_signature(obj_obs)).detach().numpy()
```

### IP-163 CIPS（保形阻抗预测集）

```python
class ConformalImpedanceSet:
    def __init__(self, field, alpha=0.1):
        self.field, self.alpha = field, alpha
        self.q = float('inf')

    def _score(self, o, K):
        return w2_distance(delta(K), self.field.predict(o).mu)

    def calibrate(self, calib):                      # calib: [(o_i, K_i)]
        scores = sorted(self._score(o, K) for o, K in calib)
        n = len(scores)
        k = math.ceil((n + 1) * (1 - self.alpha))
        self.q = scores[min(k, n) - 1]               # 覆盖定理的阈值

    def contains(self, o, K):
        return self._score(o, K) <= self.q

    def set(self, o):
        post = self.field.predict(o)
        return ImpedanceBall(center=post.mu, radius=self.q)   # C_α(o)
```

### IP-164 IPPP（信息性探测路径规划）

```python
def plan_informative_probe(field, o, budget, candidates):
    best, best_voi = None, -1.0
    for path in candidates:                       # 接触点×方向×速度 的组合
        ig = expected_information_gain(field, o, path)   # GP 熵减
        c = probe_cost(path)
        if c > budget:
            continue
        voi = ig / max(c, 1e-6)
        if voi > best_voi:
            best, best_voi = path, voi
    return best                                   # 次模时贪心 ≈ (1-1/e)OPT
```

### IP-165 AIM（可供性-阻抗地图）

```python
class AffordanceImpedanceMap:
    def __init__(self, grid_res=0.02):
        self.X = {}          # cell -> accessible surface
        self.A = {}          # cell -> affordance + approach cone
        self.Z = {}          # cell -> impedance posterior

    def path_cost(self, path, w=(1.0, 1.0, 0.5)):
        wd, wr, wu = w
        total = 0.0
        for a, b in zip(path[:-1], path[1:]):
            zp = self.Z[b]
            total += (wd * dist(a, b) + wr * risk(zp)
                      + wu * uncertainty(zp))
        return total

    def candidates_for(self, goal):
        return [c for c in self.X if supports(self.A[c], goal)]
```

### IP-166 Z-Atlas（阻抗图谱）

```python
class ImpedanceAtlas:
    def __init__(self, kernel='matern52'):
        self.E, self.K = np.empty((0, 32)), np.empty((0, len(K_dim)))
        self.gp = GaussianProcess(kernel=kernel)

    def update(self, e_o, K_obs, ev_exec):
        self.E = np.vstack([self.E, e_o[None, :]])
        self.K = np.vstack([self.K, K_obs[None, :]])
        self.gp.fit(self.E, self.K)

    def knearest(self, e_o, k=5):
        d = np.linalg.norm(self.E - e_o, axis=1)
        idx = np.argsort(d)[:k]
        return [AtlasHit(self.E[i], self.gp.mean(self.E[i]), d[i]) for i in idx]

    def posterior(self, e_o):
        return self.gp.predict(e_o)     # μ_Z(o), σ²_Z(o)
```

### IP-167 OOD 判定 + IP-168 NIGL（闭环）

```python
def navigation_integrated_generalization_loop(M, goal, B_probe):
    o_star, n_star = M.aim.select_target(goal)
    e_o = M.embedder.encode(M.observe(o_star))

    ood = (M.atlas.posterior(e_o).var > M.eps) or (M.density(e_o) < M.rho_min)
    if ood:                                      # 先探测后执行（定义 167）
        path = plan_informative_probe(M.field, o_star, B_probe, M.probe_candidates)
        for a in path:
            y = M.contact_probe(a)
            M.atlas.update(e_o, y.K, y.ev_exec)
        M.cips.calibrate(M.recent_calib)         # 重校准

    C_alpha = M.cips.set(e_o)
    K_cand = intersect(C_alpha, M.scene_safe_set(M.scene), M.k_safe_base)
    if K_cand.is_empty():
        return M.conservative_or_degrade(goal)

    K_star = M.eeis.compile(M.delta_f_req, K_cand)
    M.ertc.lock(K_star)
    ev_exec = M.execute_and_evidence(K_star)

    M.epir.append(ev_exec)
    M.atlas.update(e_o, ev_exec.K, ev_exec)
    M.cips.calibrate(M.recent_calib)

    cert = GenCertificate(C_alpha, in_domain=not ood,
                          coverage=1 - M.cips.alpha, env=ev_exec.env)
    return K_star, ev_exec, cert
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| OIGF | O(k·d) 预测/物体 | O(k) 近邻缓存 | Lipschitz 泛化界 `W₂ ≤ L·d_NN + O(1/√k)` |
| 接触嵌入 e | O(d) 编码 | O(d) 参数 | 接触动力学相似性 top-k 检索召回 ≥ 80% |
| CIPS | O(1) 判定 / O(n log n) 校准 | O(n) 分数 | 有限样本覆盖 `P(K∈C) ≥ 1−α`（可交换） |
| IPPP | O(|A|^m) 朴素 / O(|A|·m) 贪心 | O(m) | 次模下 `(1−1/e)` 近似 |
| AIM | O(N_cell) 建图 / O(path) 规划 | O(N_cell) | 规划代价一致（分辨率 δ 内） |
| Z-Atlas | O(n³) 拟合 / O(n²) 预测 | O(n²) | GP 后验一致，冷启动退化不劣于场景先验 |
| NIGL | O(闭环 + 探测) | 复用 | 覆盖 + OOD 安全不变式 + 三方求交 |

**正确性定理（NIGL）**：假设 A22–A65 与新增 A66–A71 成立：
- **(A66)** 接触嵌入连续：`|Ẑ(o)−Ẑ(o')| ≤ L·d_O(o,o')`；
- **(A67)** 校准集与测试物体可交换（同分布采样）；
- **(A68)** Z-Atlas 的 GP 核 Matérn-5/2，后验均方连续；
- **(A69)** 信息增益 `IG(·)` 关于探测集合次模；
- **(A70)** AIM 分辨率 δ 下风险/不确定性场一致；
- **(A71)** 嵌入密度估计 ρ(e) 一致收敛。

则：
1. **泛化覆盖性**：`P(K(o) ∈ C_α(o)) ≥ 1−α`（有限样本、分布无关，由 A67 + 保形分位构造）；
2. **泛化误差界**：`W₂(Z(o), Ẑ(o)) ≤ L·d_O(o,o_NN) + O(1/√k)`（由 A66 + A68），即**未见物体误差由嵌入距离控制**；
3. **探测近似最优**：贪心 IPPP 的期望信息增益 `≥ (1−1/e)·OPT`（由 A69）；
4. **外推安全不变式**：`o ∉ D_ε ⇒ K_exec` 必来自保守集，永不下发外推参数（由定义 167 直接得）；
5. **三方求交安全性**：`K_exec ∈ C_α(o) ∩ K_safe^scene ∩ K_safe_base`，泛化、场景、执行三层约束同时成立；空集则降级，绝不越界。

## 2. 关键算法伪代码

### IP-161 OIGF（物体阻抗泛化场）

```python
class ObjectImpedanceField:
    def __init__(self, embedder, atlas, L=1.0, k=5):
        self.e = embedder
        self.atlas = atlas
        self.L = L
        self.k = k

    def predict(self, obj_obs):
        z = self.e.encode(obj_obs)
        nn = self.atlas.knearest(z, k=self.k)
        d = np.array([dist(z, n.e) for n in nn])
        w = softmax(-d / max(self.L, 1e-6))
        mu = sum(wi * n.K_mean for wi, n in zip(w, nn))
        cov = sum(wi * (n.K_cov + np.outer(n.K_mean - mu, n.K_mean - mu))
                  for wi, n in zip(w, nn))
        radius = self.L * d.min()
        return ImpedancePosterior(mu, cov, radius, d.min())
```

### IP-162 接触嵌入（自监督对比）

```python
class ContactEmbedder:
    def __init__(self, dim=32, margin=0.2):
        self.enc = ForceDisplacementEncoder(out_dim=dim)
        self.m = margin

    def triplet_loss(self, anchor, pos, neg):
        da = torch.norm(self.enc(anchor) - self.enc(pos), dim=-1)
        dn = torch.norm(self.enc(anchor) - self.enc(neg), dim=-1)
        return torch.relu(da - dn + self.m).mean()

    def encode(self, obj_obs):
        return self.enc(force_displacement_signature(obj_obs)).detach().numpy()
```

### IP-163 CIPS（保形阻抗预测集）

```python
class ConformalImpedanceSet:
    def __init__(self, field, alpha=0.1):
        self.field, self.alpha = field, alpha
        self.q = float('inf')

    def _score(self, o, K):
        return w2_distance(delta(K), self.field.predict(o).mu)

    def calibrate(self, calib):
        scores = sorted(self._score(o, K) for o, K in calib)
        n = len(scores)
        k = math.ceil((n + 1) * (1 - self.alpha))
        self.q = scores[min(k, n) - 1]

    def contains(self, o, K):
        return self._score(o, K) <= self.q

    def set(self, o):
        post = self.field.predict(o)
        return ImpedanceBall(center=post.mu, radius=self.q)
```

### IP-164 IPPP（信息性探测路径规划）

```python
def plan_informative_probe(field, o, budget, candidates):
    best, best_voi = None, -1.0
    for path in candidates:
        ig = expected_information_gain(field, o, path)
        c = probe_cost(path)
        if c > budget:
            continue
        voi = ig / max(c, 1e-6)
        if voi > best_voi:
            best, best_voi = path, voi
    return best
```

class AffordanceImpedanceMap:
    def __init__(self, grid_res=0.02):
        self.X, self.A, self.Z = {}, {}, {}

    def path_cost(self, path, w=(1.0, 1.0, 0.5)):
        wd, wr, wu = w
        total = 0.0
        for a, b in zip(path[:-1], path[1:]):
            zp = self.Z[b]
            total += (wd * dist(a, b) + wr * risk(zp) + wu * uncertainty(zp))

class ImpedanceAtlas:
    def __init__(self, kernel='matern52'):
        self.E, self.K = np.empty((0, 32)), np.empty((0, len(K_dim)))
        self.gp = GaussianProcess(kernel=kernel)

    def posterior(self, e_o):
