# 第 2 轮（灵感循环第 2 轮；本轮灵感：「数据增强」×「隐私保护」）

> **基线继承**：上一轮 **ToolGauge**（IP-315–320；定义 416–431；引理 46–50；实验 E426–E440），
> 上承 **LeanGauge**（IP-310–314；定义 398–415）与 **MODGAUGE** 五不变式。
> 本轮纪律：**不推倒重来**——ToolGauge 的 6C 闭环（H→C→E→C→V→U）、工具契约 MTC/TCV、
> 摊销校准 AP-Cal、独立回执交叉验证、P-Quarantine 与严格退化链全部保留；两条新灵感只升级**证据层**：
> 把「什么算证据」从「计数」升级为「来源 + 独立性 + 披露」的**证据台账**。

## 三位一体映射（两条灵感轴 + 一个统一抽象）

| 灵感词 | 基线对象 | 升级为 | 一句话动机 |
|---|---|---|---|
| 数据增强 | ToolGauge 的 E 阶段只有真实工具调用，样本昂贵、稀疏、有物理风险 | **A-Box 认证增强**：对称性/数字孪生生成虚拟回执，只进先验、假设覆盖与审计集 | 合成数据能扩上下文、降方差、做压力测试，但**不能创造关于 u\* 的新信息**；把它当证据就是自证 |
| 隐私保护 | AP-Cal/MP-Φ 直接消费原始回执；RepairCert 直接引用原始数值 | **P-Box 隐私账簿 + DP 摊销校准 + 披露受证语言** | 隐私不是事后加密，而是证据变换：DP 噪声必须进 Σ，隐私预算必须进契约 |
| （统一抽象） | 上一轮最大风险：跨盲区相关先验偏差被语言证书放大 | **证据台账 EL**：独立性秩、有效样本量、隐私成本、披露证书 | 只有把「来源与可见性」显式记账，才能防止合成证据与隐私噪声互相掩护 |

**核心命题**：把 ToolGauge 的「真实回执 → 摊销校准」升级为
「**来源分型证据 → 认证增强（只入先验）→ 隐私受控校准 → 真实独立回执交叉验证 → 披露受证热替换**」。
一句话：**增强买方差，隐私买合规；二者都买不到独立证据。**

**不变式保持声明**：
- MODGAUGE 五不变式全部保留；
- 主张绑定不变式扩展为**披露受证**：语言主张必须引用「回执承诺 + DP 摘要证书」，原始回执不进入语言层（定义 439）；
- **严格退化链再延长**：LedgerGauge（增强 + 隐私）失效 ⇒ ToolGauge（关闭增强与 DP 共享）⇒ LeanGauge（纯数值探测）⇒ MODGAUGE。
  新失效触发器：增强证书失效 / 隐私预算耗尽 / DP 方差越过安全线 / 泄露或掩蔽哨兵触发 / 台账不一致。

## 0. 直觉与动机

### 直觉 1（数据增强）：「合成样本」不是免费证据，而是用先验换方差

第一反应是显然的：真实计量探测又慢又贵还有物理风险（敲击、变光、机械臂移动），
如果能用数字孪生、域随机化、对称变换批量生成「虚拟回执」，盲区的校准样本就会从几条变成几千条，
样本复杂度危机似乎一夜解决。**这正是本轮最危险的直觉。**

设真实回执集为 `R`，合成集为 `S = f(R, W)`，其中 `W` 是增强的随机种子/仿真参数；
只要 `W` 在给定 `R` 下与真实契约参数 `u*` 独立，就有条件独立性 `u* ⊥ S | R`，
于是 `I(u*; S | R) = 0`（引理 51）。**合成数据对 `u*` 的信息增量是零**。
如果校准器把 `S` 当成新样本，让后验方差从 `σ₀²` 收缩到远低于真实不确定性，
那不是「学得更多」，而是「把同一个祖先数了很多遍」——上一轮「迭代采样被误判为已覆盖」的自证陷阱，
会在增强层以更隐蔽的方式重演。

那增强还有什么用？有三件**不被证据秩承认、但真实有用**的事：
1. **抵消 nuisance**：视角、光照、姿态、温度是 nuisance 变量 `b(x)`；认证的对称轨道平均可以把 `b` 的方差压下去，
   让有限真实样本更有效地估计 `u*`（引理 52）；
2. **改进先验**：把增强/仿真数据用于 MP-Φ 预训练，只在 `KL(p_aug ‖ p_phys) ≤ B_aug` 内改变先验 `σ₀`；
3. **扩大审计集与难负样本**：用增强生成 SNC 指纹、共形分数压力测试与对抗样本，服务于**证伪**，不服务于**证实**。

因此 A-Box 的设计原则是「三证一禁」：**标签不变证 + 物理等变证 + 包络合法证；禁止进入 V 阶段与 n_min 计数**。
一个没有证书的「旋转一下图像」不是数据增强，只是把同一个误差换了件衣服。

### 直觉 2（隐私保护）：DP 噪声不是外挂，而是必须进 Σ 的证据变换

第二反应也很自然：回执里有场景几何、材质、操作者影像，跨盲区、跨机器人、上云预训练都会泄露；
那就加密、脱敏、加噪。但隐私一旦进入计量闭环，就不再是「发布前遮一遮」的工程问题，
而是**证据变换**：DP 机制把充分统计量 `z` 变成 `z̃ = z + η`，`η` 的协方差必须进入后验协方差；
隐私预算必须进入契约；预算不够时必须**降级**，而不是用更漂亮的先验把噪声盖过去。

关键的工程区分是两种模式：
- **F-mode（远端/联邦）**：校准只拿到 DP 充分统计量，DP 噪声直接降低可声称精度；
- **L-mode（本地可信飞地）**：原始回执不出飞地，本地校准可用原始数据；DP 只约束**离开飞地的一切**
  （共享先验、跨盲区摘要、语言主张）。本地安全不被噪声降级，但跨盲区复用必须付隐私成本。

隐私还改变了「谁有资格说话」：上一轮的语言修复证书直接引用原始数值，这是泄露面。
本轮把语言层降到与 VLA 同级的**被审计角色**：它只能看 DP 摘要，主张必须携带披露证书；
原始回执只以 Merkle 承诺 + 加密审计仓存在。DP 的后处理免疫保证「语言主张是 DP 摘要的确定性函数 ⇒ 主张仍满足 DP」，
但这只有在语言层**真的看不到原始值**时才成立（定义 439、引理 54）。

最后是一个容易被忽略的失败模式：**隐私噪声会给建模误差提供不在场证明**。
增强先验引入的系统性偏差 + DP 噪声，在观测上可能无法区分；系统会把偏差归因于「隐私预算太紧」，
于是 P-Quarantine 不触发，热替换照常发生。定义 445 的掩蔽哨兵就是为这个失败模式准备的。

### 直觉 3（统一抽象）：证据台账——把「来源」和「可见性」变成一等公民

两条灵感看似无关，实际上都在问同一个问题：**这条观测凭什么算证据？**
数据增强问的是「它从哪来、和谁共享祖先」；隐私保护问的是「谁能看见、看见多少」。
统一抽象是一个**证据台账 EL**：每个证据项带 `(prov, indep, priv, parents, cert)`，
台账同时维护独立性秩 `ρ`、有效样本量 `n_eff = 1ᵀC⁻¹1`、主体级隐私预算与披露证书。
校准器不再问「我有多少条样本」，而是问「我有多少条**真实独立**样本、多少**认证先验**、多少**剩余隐私预算**」。

这个抽象直接接住上一轮的最大风险：跨盲区相关先验偏差在台账里表现为**共享祖先**，
P-Quarantine 可以沿来源 DAG 一次性隔离所有后代子图；合成数据若想伪装成证据，
会在 `ρ(RI ∪ SYNTH) = ρ(RI)` 处被拦下；DP 噪声若想掩盖偏差，会在掩蔽哨兵的无噪声残差序列里暴露。
**台账不是又一个模块，而是把「证据」从计数器变成可审计对象。**

## 1. 形式化定义（增量：定义 432–446）

**定义 432（证据项与来源 DAG）**
证据项 `e = (id, y, Σ, prov, indep, priv, parents, cert)`：
- `y = (μ, σ_decl)` 是回执或统计量；`Σ` 是其协方差（若可估计）；
- `prov ∈ {REAL, SYNTH}`；`indep ∈ [0,1]` 是相对于同盲区其他证据的独立性系数（1 = 独立，0 = 父项的确定性复制）；
- `priv = (ε, δ, mode)` 或 `⊥`，表示该项作为「发布」的隐私成本与模式（L/F）；
- `parents ⊆ IDs` 构成来源 DAG；REAL 项的父项只能是传感器/工具回执，SYNTH 项必须至少有一个 REAL 祖先；
- `cert` 是类型证书：REAL 的独立性证书、SYNTH 的增强证书（定义 434）、DP 的机制证书。
证据集 `E` 的**独立性秩** `ρ(E)` 定义为来源 DAG 中互不共享 REAL 祖先且相关性低于 `ρ₀` 的极大项数（拟阵秩）。
台账支持 `shared_ancestor(s₁, s₂)` 查询：两个盲区的证据是否共享 REAL 祖先/预训练环境/校准源。

**定义 433（有效样本量与增强折扣）**
对同盲区的 `k` 个标量观测 `y_i = u* + b_i + ε_i`，设噪声相关矩阵为 `C`，定义
`n_eff(E) = 1ᵀ C⁻¹ 1`。
性质：iid 时 `n_eff = k`；完全相关时 `n_eff → 1`；等相关 `ρ` 时 `n_eff = k / (1 + (k−1)ρ)`。
**增强折扣** `δ_aug(E) = n_eff(E) / |E|`。SYNTH 项不增加 `ρ(E)`，只通过抵消 nuisance、改进先验、扩大审计集起作用。
台账在样本复杂度门槛中一律使用 `n_eff`，不使用 `|E|`。

**定义 434（认证增强算子 AugCert）**
增强算子 `g ∈ G` 对盲区 `s` 与假设 `h` 认证，当且仅当：
1. **标签不变**：`∀x ∈ A_s`，`SNC(h, g·x) = SNC(h, x)`；
2. **物理等变**：存在表示 `T_g`，使 `sup_{x∈A_s} ‖M(g·x) − T_g M(x)‖ ≤ ε_eq`；
3. **包络合法**：`g·x` 落在工具 `t` 的 `Pre_t` 物理包络内，虚拟回执的 `σ` 不低于工具噪声底；
4. **审计独立**：`A_s` 是预注册的真实留出集，不参与本轮校准，也不参与 V。
通过则生成虚拟回执 `r^g = (T_g r, prov=SYNTH, parent=r, cert=AugCert(g))`。

**定义 435（增强预算与无免费证据上限）**
对盲区 `s`，增强只允许改变先验，不允许改变证据秩：
- **KL 上限**：`KL(p_aug(u_s) ‖ p_phys(u_s)) ≤ B_aug(s)`；
- **秩上限**：`ρ(E_RI ∪ E_SYNTH) = ρ(E_RI)`；
- **样本下限**：`n_eff(E_RI) ≥ n_min(s, σ₀^cert, ε_c)`，其中 `σ₀^cert` 是计入增强先验后的认证先验标准差，`n_min` 由定义 426 给出；SYNTH 不计入 `E_RI`。
若违反任一，A-Box 回滚该增强并记录 `aug_violation`。

**定义 436（隐私账簿与主体级组合）**
隐私按**数据主体**（场景/操作者/可识别对象）记账，而非按盲区。对主体 `p`，预算 `(ε_p, δ_p)` 全局共享；
每次发布 `m`（向 VLA、跨盲区共享、云训练、语言主张）消耗 `(ε_m, δ_m)`，按 RDP/基本组合累计 `ε_spent(p)`。
发布合法当且仅当 `ε_spent(p) + ε_m ≤ ε_p` 且 `δ` 同理。
跨盲区/跨轮共享同一主体时必须组合，禁止「换一个盲区重新计数」的预算洗白。

**定义 437（DP 摊销校准与两种模式）**
- **F-mode（远端/联邦）**：校准只使用 DP 充分统计量 `z̃ = z + N(0, σ_n² I)`，
  `σ_n = Δ√(2 ln(1.25/δ)) / ε`（Gaussian mechanism）；后验协方差
  `Σ_post = (Σ_phys⁻¹ + Σ_aug⁻¹ + n_eff(Σ_obs + σ_n² I)⁻¹)⁻¹`。
- **L-mode（本地可信飞地）**：原始回执留在飞地内，本地校准可用原始数据；DP 只作用于**发布**。
  本地安全不被 DP 噪声降级，但任何离开飞地的量都必须过隐私账簿。
模式由 AP-Contract 指定；两种模式的安全结论分别由引理 53/56 给出。

**定义 438（隐私-效用-安全边界与决策稳定性）**
给定安全精度 `ε_c`（要求 `λ_max(Σ_post) ≤ ε_c²`）：
- **标量可行性**：`σ_n,max² = n / (ε_c⁻² − σ₀⁻²) − σ_obs²`；若 `≤ 0`，则当前 `n` 在任意 `ε` 下都无法达标，必须拒绝；
- **最小预算**：`ε_min = Δ√(2 ln(1.25/δ)) / σ_n,max`；若 `ε_p < ε_min`，F-mode 不可行；
- **决策稳定性**：令 `D(q) ∈ {0,1}` 为契约满足指示，要求 `P_noise[D(q^DP)=1] ≥ 1−β`（默认 `β=0.05`）；
  否则视为「靠噪声碰巧通过」，不热替换。
**隐私噪声下限原则**：DP 噪声给出的方差是「可声称精度」的下界；任何低于它的收缩都必须由真实独立证据解释，否则视为自证。

**定义 439（披露受证语言主张）**
语言层只能接收 DP 摘要 `z̃`（或飞地内生成、已计入预算的摘要），不得接收原始回执。主张 `c` 必须满足
`c = h(z̃₁,…,z̃_m)`，且携带 `DisclosureCert(c) = (ε_c, δ_c, 依赖摘要 ID, 回执承诺 root)`；
由 DP 后处理免疫，`c` 自动满足 `(Σ ε_c, Σ δ_c)-DP`。
原始回执只以加密审计仓 + Merkle 承诺存在；审计员持密钥可重放，语言层不可见。
定义 423 的「主张-回执绑定」升级为「主张-承诺-披露证书」三绑定。

**定义 440（联邦私有元先验 FMP-Φ）**
MP-Φ 的跨站点预训练使用 DP-SGD + 安全聚合；每个站点的贡献先做 `ℓ₂` 裁剪，隐私成本按站点主体记账。
允许用 DP 生成的合成环境预训练（合成数据只作先验，符合定义 435），其 sim-to-real 间隙 `η_twin` 计入引理 57。
共享的只有元先验参数，不共享原始回执。

**定义 441（认证增强共形）**
共形校准的交换性不能被合成样本直接扩大。A-Box 对共形的合法用途只有两种：
(a) 若分数函数在 `G` 下不变（有 AugCert 证明），轨道内增强不改变分数分布，只用于降低分位数估计的蒙特卡洛方差；
(b) 若分数函数不变性不成立，增强点只能进入**加权共形**，权重 `w(g·x)` 由密度比给出，覆盖松弛 `≥ η_aug`（增强分布与部署分布的 TV）。
严禁把 SYNTH 点直接计入 `1−α` 经验分位数的样本数；违者由 `n_eff` 审计拒绝。

**定义 442（7C 证据台账闭环）**
在 ToolGauge 的 6C 上插入 A（认证增强），并把隐私门 `G_P` 作为每个阶段的横切门：
`H（假设）→ C（编译）→ E（真实执行）→ A（认证增强，只入先验/审计）→ C（台账校准）→ V（真实独立回执交叉验证）→ U（披露受证热替换）`。
每阶段更新 EL；`G_P` 检查发布预算；V 的独立回执必须 `prov=REAL` 且 `indep ≥ ρ₀`，禁止 SYNTH/DP 回执参与 V。

**定义 443（严格退化链）**
`LedgerGauge →（增强证书失效 / 隐私预算耗尽 / DP 方差越线 / 泄露或掩蔽哨兵触发 / 台账不一致）→ ToolGauge`（关闭 A-Box 与 DP 共享，保留 6C）
`→（VLA 不可用 / 预算耗尽 / 假设全被 SNC 剔除）→ LeanGauge`（纯数值探测）
`→（数值路径失效）→ MODGAUGE`。
每一级退化都保留上一级的隐私约束：ToolGauge 仍需遵守已花隐私预算与已有披露证书；**退化不是隐私豁免**。

**定义 444（增强-隐私契约 AP-Contract）**
`AP = (B_tools, L_max, B_aug, ε_p, δ_p, λ_p, ε_min, n_RI_min, τ_repair, mode, recovery)`。
它是 TB-Contract（定义 424）的细化：`B_tools/L_max/τ_repair` 继承；新增增强 KL 预算、主体隐私预算、
隐私影子价格 `λ_p`、最小隐私预算、真实独立样本下限、F/L 模式与恢复条件。
**隐私调整增益注**：`β^π_t = Ĝ_t − c_t − λ_p·ε_t ≥ γ_B`；`λ_p` 把预算耗尽前移到探测选择阶段，
使系统优先修复「信息增益高、隐私成本低」的盲区。

**定义 445（隐私哨兵：泄露与掩蔽双检）**
- **泄露检**：对每次发布做成员推断/重建攻击的在线估计；若攻击优势 `> τ_leak`，立即停止发布、清除合成缓存、触发退化；
- **掩蔽检**：在本地飞地内计算无噪声估计 `q_local`，并维护其跨盲区残差符号序列；
  若 `q_local` 出现连续同向偏差，而 DP 估计因噪声「看起来正常」，判定为「隐私噪声掩蔽建模误差」，
  触发 P-Quarantine，并禁止用 DP 噪声为该偏差背书。
掩蔽检只看符号与低敏感统计量，其自身发布也计入隐私预算。

**定义 446（继承与编号约定）**
未重定义的第 1/2 轮记号（`R, s, λ, γ, M_ver, N_bl, EC, MReg, MTC/TCV, AP-Cal, P-Quarantine, SNC, RepairCert` 等）
沿用定义 398–431。退化特例：关闭 A-Box（`G=∅`）、令隐私预算 `ε=∞` 且不共享、EL 只含 RI ⇒ `LedgerGauge ≡ ToolGauge`。

## 2. 关键推导

**引理 51（无免费证据）**
设 `R` 为真实回执集，`S = f(R, W)`，且 `W ⊥ u* | R`（增强的随机种子/仿真参数在给定真实回执下不含 `u*` 的新信息）。
则 `I(u*; S | R) = 0`，且 `p(u* | R, S) = p(u* | R)`。
因此合成数据引起的任何“后验收缩”都只能来自 `f` 编码的先验/不变性假设，而不是证据。
**推论 51.1**：`SYNTH` 样本数不能直接进入 `n_min`；它只能通过认证先验 `σ₀^cert` 降低 `n_min`，
且每一分降低都必须由 `B_aug` 内的 KL 与 AugCert 解释。
**证伪实验**：E441（augment-only 校准在真实留出真值上不应显著优于 real-only；若显著更优，说明增强过程偷偷用了独立真实信息）。

**引理 52（增强的有效样本量分解）**
观测模型 `y = J u* + b(x) + ε`，其中 `b` 是 nuisance、`ε` 是独立噪声。
认证轨道平均把 nuisance 协方差 `Σ_b` 投影为 `Σ_b^G`；`u*` 的 Fisher 信息为
`I_aug(u*) = Jᵀ (Σ_ε + Σ_b^G)⁻¹ J`。
在标量等相关模型下，`u*` 方向的有效样本量为
`n_eff = k / (1 + (k−1)ρ_u)`，其中 `ρ_u` 是 `u*` 方向的残差相关。
完全相关的合成副本（`ρ_u = 1`）给出 `n_eff → 1`，不增加参数信息；增强的真实收益是 `Σ_b^G ≪ Σ_b` 带来的 nuisance 方差下降。
**推论 52.1**：台账必须用 `n_eff(u*)` 而不是 `|E|` 进入定义 426 的门槛；这堵住了“把同一祖先数很多遍”的漏洞。

**引理 53（隐私-效用-安全三难）**
F-mode 下，Gaussian mechanism 的噪声方差 `σ_n²` 进入观测噪声。标量后验满足
`σ_post² = (σ₀⁻² + n / (σ_obs² + σ_n²))⁻¹`。
给定 `ε_c < σ₀`，要 certify `σ_post ≤ ε_c` 必须
`n ≥ (σ_obs² + σ_n²)(ε_c⁻² − σ₀⁻²)`，
即 `σ_n,max² = n/(ε_c⁻² − σ₀⁻²) − σ_obs²`。
若 `σ_n,max² ≤ 0`，任意 `ε` 都无法达标；若 `ε_p < ε_min = Δ√(2 ln(1.25/δ))/σ_n,max`，F-mode 不可行。
此时唯一安全动作是 `stub + RED`（或切到 L-mode 本地计算），而不是用增强先验把噪声“补”回去。
**推论 53.1**：隐私不是可以事后用更强先验抵消的常数；先验改进受 `B_aug` 与 AugCert 双重约束（引理 51）。

**引理 54（披露受证主张的数值等价与后处理免疫）**
语言主张是 DP 摘要的确定性后处理；由 DP 后处理免疫，主张满足摘要的隐私保证，
且不引入额外隐私成本。主张不在任何数值计算路径上；以承诺替代原始数值是纯投影，
不改变热替换的数值等价性（继承引理 49）。
若主张需要原始数值才能成立，则它不是披露受证的，必须在序列化时剥离；
审计员可在加密仓内用密钥重放，但该重放不进入语言层。

**引理 55（认证增强共形的覆盖）**
若 AugCert 精确成立且分数函数 `G`-不变，则轨道增强不改变分数分布，真实校准集上的共形覆盖仍为 `≥ 1−α`（可交换性下）。
若不变性近似成立，增强分布与部署分布 TV 为 `η_aug`，加权共形覆盖 `≥ 1−α−η_aug`（或 `1−α−η_aug·L′`）。
若 AugCert 失效，A-Box 禁用增强，覆盖保证回落到引理 48。
**系**：增强不能把 `SYNTH` 点当作独立校准点；它只能降低分位数估计的蒙特卡洛方差或扩大审计覆盖。

**引理 56（台账闭环的时序、预算与安全保持）**
台账的 admit/计数更新是 `O(1)` 每回执，位于 50Hz 路径；相关矩阵/`n_eff`/隐私组合/增强证书审计全部异步或离线；
DP-SGD 预训练完全离线。50Hz 周期新增开销仅为台账标签检查与计数器更新 `O(1) < 0.2ms`。
所有失败触发器都调用严格退化链，且不做部分热替换；隐私预算单调不增，退化不会多花预算。
因此硬实时（引理 45/50）与五不变式保持。

**引理 57（联邦私有元先验的泛化界）**
在引理 47 的元泛化界上追加隐私项：
`R̄(q_θ^DP) − R̄(q*) ≤ 2η + O(√((C(Θ)+log(1/δ))/M)) + O(√((d_u+log(1/δ))/N_bl)) + P_priv(ε, δ, n_priv)`，
其中 `P_priv` 是 DP-SGD 的超额风险项（标准假设下常写作 `O(√(d log(1/δ))/(n_priv ε))`；本文只依赖它对 `ε`、`n_priv` 单调递减）。
安全聚合不增加超出各站点预算的隐私成本；`η` 包含 DP 合成预训练的 `η_twin`。
**推论 57.1**：收紧 `ε` 会减慢 `M` 项收敛，形成「隐私-泛化前沿」；该前沿由 E448 实测并写入风险账本。

## 3. 对基线 ToolGauge 的缺陷审计与修复

| # | ToolGauge 遗留问题 | 本轮处置 |
|---|---|---|
| 1 | V 阶段的「独立回执」可能只是同一传感器/同一校准下的相关副本，名义独立、实际不独立 | EL 的独立性秩与 `n_eff` 识别；V 强制 `prov=REAL, indep≥ρ₀`，并用 `n_eff` 而非计数进入门槛 |

| 3 | RepairCert 直接引用原始数值，泄露场景/操作者/几何 | 披露受证 + Merkle 承诺 + 加密审计仓；语言层只见 DP 摘要（定义 439） |

| 5 | P-Quarantine 只看增益残差符号，DP 噪声或合成方差可使其失效 | 掩蔽哨兵：无噪声本地残差 + 跨盲区符号序列 + 决策稳定性检验（定义 445） |
| 6 | 跨盲区/跨轮共享无隐私预算组合，存在预算洗白 | 主体级隐私账簿 + 全局组合 + AP-Contract 硬预算（定义 436/444） |
| 7 | 增强/隐私若接在 50Hz 路径上会破坏硬实时 | 台账 `O(1)` 内联，其余全异步/离线；引理 56 |

## 4. 本轮最大风险（一句话）

**一句话**：认证增强引入的先验偏差与 DP 噪声在观测上不可分辨——系统会把跨盲区的系统性偏差误归因于「隐私预算太紧」，
从而在「7C 全通过、披露证书齐全」的表象下，以看似合规的精度热替换一个错误的契约；语言层只看到受证摘要，
进一步掩盖了偏差的真实来源。

**次级风险与缓解**：
1. **假不变性**（AugCert 把错误对称性当真理）→ 预注册真实审计集 + E442 证伪 + 失败即禁用增强；
2. **隐私预算耗尽导致「合规但不可用」** → `λ_p` 影子价格 + 预算感知修复排序 + 必要时切 L-mode；
3. **DP 合成预训练污染先验**（sim-to-real gap）→ `B_aug` KL 上限 + `η_twin` 计入引理 57 + P-Quarantine；
4. **低维 DP 摘要仍可被重建** → 泄露哨兵 + 更小 `ε` + 承诺审计；
5. **主体级预算被跨盲区绕过** → 全局主体账本 + 跨轮组合（定义 436）；
6. **增强/隐私与实时性冲突** → 全异步 + 50Hz 仅 `O(1)` 台账更新（引理 56）；
7. **退化链被当作隐私豁免** → 退化不豁免既有预算与披露义务（定义 443）。

# 第 2 轮产物 · 创新点清单 v2：**LedgerGauge**（Provenance-Ledgered, Privacy-Preserving Gauge with Certified Augmentation）

> 背景：上一轮 **ToolGauge**（IP-315–320）用「VLA 假设 → 工具契约 → 摊销校准 → 独立回执交叉验证 → 局部热替换」
> 解决了 LeanGauge 的「探测无接口约束 / 先验不可审计 / 逐盲区从零校准」三个弱点，但留下四个结构性缺口：
> (i) 真实探测昂贵，却没有安全利用合成数据的机制；(ii) V 阶段的“独立”回执可能只是相关副本；
> (iii) 原始回执与语言证书存在隐私泄露面；(iv) 跨盲区共享无来源与隐私预算记录，无法阻止相关先验偏差。
>
> 本轮以「**数据增强 × 隐私保护**」为灵感，在 ToolGauge 之上新增**证据台账 EL**、**A-Box 认证增强**、
> **P-Box 隐私账簿/DP 校准**与**披露受证语言层**，并把 6C 扩成 **7C**。五不变式与严格退化链全部保留并延长。
>
> IP 编号：**IP-321–326**；定义增量 **432–446**；引理增量 **51–57**；实验增量 **E441–E455**。
> 理论姿态：不改变「数值真值由计量层独占」；新增「证据来源」与「披露可见性」两维审计。
> 一句话：**增强买方差，隐私买合规；二者都买不到独立证据。**

## 2. 形式化定义（要点）

**定义 432（证据项与来源 DAG）**
每个回执/统计量带 `prov`（REAL/SYNTH）、`indep`、`priv`、`parents`、`cert`。
`parents` 构成来源 DAG；SYNTH 必须至少有一个 REAL 祖先；`ρ(E)` 是互不共享 REAL 祖先且相关性 `< ρ₀` 的极大项数。
台账支持跨盲区 `shared_ancestor` 查询，用于相关先验偏差的溯源。

**定义 433（有效样本量与增强折扣）**
相关矩阵 `C` 下 `n_eff = 1ᵀC⁻¹1`；iid 时等于 `k`，完全相关时趋于 1，等相关时为 `k/(1+(k−1)ρ)`。
台账的样本复杂度门槛一律用 `n_eff`，不用 `|E|`。

**定义 434（认证增强 AugCert）**
`g` 对 `(s,h)` 认证需同时满足：标签不变（SNC 在审计集上不变）、物理等变（`M(g·x)=T_gM(x)+O(ε_eq)`）、
包络合法（不越出 `Pre_t`，`σ` 不低于工具噪声底）、审计集独立（真实留出、不复用）。
通过后 `r^g` 标为 SYNTH，父项为 `r`。

**定义 435（增强预算与无免费证据上限）**
`KL(p_aug‖p_phys) ≤ B_aug`；`ρ(RI ∪ SYNTH) = ρ(RI)`；`n_eff(E_RI) ≥ n_min(s, σ₀^cert, ε_c)`。任一违反即回滚。

**定义 436（主体级隐私账簿）**
隐私按数据主体而非盲区记账；跨盲区/跨轮共享同一主体必须组合，禁止预算洗白。
发布合法当且仅当 `ε_spent(p)+ε_m ≤ ε_p` 且 `δ` 同理。

**定义 437（DP 摊销校准，F/L 双模式）**
F-mode：`Σ_post = (Σ_phys⁻¹ + Σ_aug⁻¹ + n_eff(Σ_obs + σ_n²I)⁻¹)⁻¹`，`σ_n` 由 Gaussian mechanism 给出。
L-mode：原始回执不出飞地，DP 只约束发布；本地校准不被噪声降级，但跨盲区共享与语言主张必须过账簿。

**定义 438（隐私-效用-安全边界 + 决策稳定性）**
`σ_n,max² = n/(ε_c⁻² − σ₀⁻²) − σ_obs²`；`ε_min = Δ√(2ln(1.25/δ))/σ_n,max`；
要求 `ε_p ≥ ε_min` 且 `P_noise[D(q^DP)=1] ≥ 1−β`，否则 `stub + RED`。
**隐私噪声下限原则**：低于 DP 噪声方差的收缩必须由真实独立证据解释，否则是自证。

**定义 439（披露受证语言）**
`c = h(z̃₁,…,z̃_m)`，携带 `(ε_c, δ_c, 摘要 ID, 回执承诺 root)`；DP 后处理免疫 ⇒ 主张仍是 DP。
原始回执只以加密审计仓 + Merkle 承诺存在；审计员可重放，语言层不可见。

**定义 440（联邦私有元先验 FMP-Φ）**
DP-SGD + 安全聚合；站点贡献 `ℓ₂` 裁剪；隐私按站点主体记账；允许 DP 合成环境预训练，`η_twin` 进引理 57。

**定义 441（认证增强共形）**
分数 `G`-不变 ⇒ 轨道增强不改变分数分布，只降蒙特卡洛方差；近似不变 ⇒ 加权共形，覆盖松弛 `η_aug`；
禁止把 SYNTH 点直接计入 `1−α` 经验分位数的样本数。

**定义 442（7C 台账闭环）**
`H → C → E → A → C → V → U`；隐私门 `G_P` 横切每个阶段；V 只接受 `prov=REAL, indep≥ρ₀` 的回执。

**定义 443（严格退化链）**
`LedgerGauge → ToolGauge → LeanGauge → MODGAUGE`；五类新触发器；退化不豁免隐私预算与披露义务。

**定义 444（AP-Contract）**
`(B_tools, L_max, B_aug, ε_p, δ_p, λ_p, ε_min, n_RI_min, τ_repair, mode, recovery)`；
隐私调整增益注 `β^π_t = Ĝ_t − c_t − λ_p·ε_t ≥ γ_B`。

**定义 445（隐私哨兵）**
泄露检：成员推断/重建攻击优势 `> τ_leak` ⇒ 停发、清缓存、退化。
掩蔽检：无噪声本地估计 `q_local` 的跨盲区残差连续同向，而 DP 估计“正常” ⇒ 判为噪声掩蔽建模误差，触发 P-Quarantine。

**定义 446（继承）**
关闭 A-Box、`ε=∞`、EL 只含 RI ⇒ `LedgerGauge ≡ ToolGauge`。

# ---------- IP-321 A-Box：认证增强 ----------
@dataclass
class AugCert:
    g: Transform
    eps_eq: float          # 物理等变误差（审计集上界）
    label_inv: bool        # SNC 标签不变
    tv_aug: float          # 增强分布 vs 部署分布 TV
    kl_prior: float        # 允许注入的先验 KL
    valid: bool

class ABox:
    def __init__(self, audit_set, twin, budget):
        self.audit = audit_set     # 预注册真实留出集，永不复用为校准
        self.twin = twin
        self.budget = budget

    def certify(self, s, h):
        out = {}
        for g in self.twin.group(s):
            label_inv = all(SNC(h, g * x) == SNC(h, x) for x in self.audit[s])
            eps_eq = max(norm(M(g * x) - T(g, M(x))) for x in self.audit[s])
            ok = (label_inv and eps_eq <= EPS_EQ
                  and self.twin.in_envelope(g, s))
            out[g] = AugCert(g, eps_eq, label_inv,
                             self.twin.tv(g), self.twin.kl(g), ok)
        return out

    def augment(self, s, receipts, certs):
        aug = []
        for g, c in certs.items():
            if not c.valid: continue
            if self.budget.kl_left(s) < c.kl_prior: continue
            for r in receipts:
                if r.prov != "REAL": continue
                aug.append(virtual_receipt(g, r, c))   # prov=SYNTH, parent=r
        return self.budget.charge(s, aug)              # 记账；SYNTH 不增秩

# ---------- IP-322 EL：来源台账 ----------
class EvidenceLedger:
    def __init__(self, rho0=0.5):
        self.items, self.corr = {}, defaultdict(dict)
        self.rho0 = rho0

    def admit(self, e):
        self.items[e.id] = e
        for p in e.parents:
            self.corr[e.id][p] = estimate_corr(e, self.items[p])
        return e

    def real_independent(self, s):
        return [e for e in self.items.values()
                if e.blind == s and e.prov == "REAL"
                and e.indep >= self.rho0]

    def n_eff(self, s, only_real=False):
        es = [e for e in self.items.values()
              if e.blind == s and (not only_real or e.prov == "REAL")]
        ids = [e.id for e in es]
        C = corr_matrix(ids, self.corr)
        return float(ones(len(ids)) @ pinv(C) @ ones(len(ids)))

    def n_min(self, sigma0, eps_c):
        return SIGMA_OBS**2 * (eps_c**-2 - sigma0**-2)

    def can_calibrate(self, s, sigma0_cert, eps_c, priv_ok):
        return (self.n_eff(s, only_real=True) >= self.n_min(sigma0_cert, eps_c)
                and self.rank_invariant(s)      # ρ(RI ∪ SYNTH) = ρ(RI)
                and self.kl_ok(s)
                and priv_ok(s))

    def shared_ancestor(self, s1, s2):
        return bool(real_ancestors(s1) & real_ancestors(s2))

# ---------- IP-323 P-Box：隐私账簿与 DP 校准 ----------
class PrivacyLedger:
    def __init__(self, eps_budget, delta_budget):
        self.eps, self.delta = defaultdict(float), defaultdict(float)
        self.budget = (eps_budget, delta_budget)

    def spend(self, subject, eps, delta):
        if self.eps[subject] + eps > self.budget[0]: return False
        if self.delta[subject] + delta > self.budget[1]: return False
        self.eps[subject] += eps
        self.delta[subject] += delta
        return True

class DPAPCal(APCal):
    def __init__(self, mode, eps, delta, clip, priv):
        self.mode, self.eps, self.delta = mode, eps, delta
        self.clip, self.priv = clip, priv

    def gaussian_sigma(self, sensitivity):
        return sensitivity * sqrt(2 * log(1.25 / self.delta)) / self.eps

    def calibrate(self, receipts, aug, H, s, subject):
        z = sufficient_stats(receipts, self.clip)      # clipped, bounded
        if self.mode == "F":
            sigma_n = self.gaussian_sigma(l2_sensitivity(self.clip))
            if not self.priv.spend(subject, self.eps, self.delta):
                raise PrivacyBudgetExhausted
            z = z + normal(0, sigma_n, size=z.shape)
            noise_var = sigma_n**2
        else:
            noise_var = 0.0                            # raw stays in enclave
        mu, Sig = self.mp_phi(featurize_ctx(z, aug, H, s))
        Sig = Sig + noise_var * I
        return mu, clamp_min(Sig, KAPPA_PHYS)

    def cross_validate(self, mu, Sig, r_indep):
        assert r_indep.prov == "REAL" and r_indep.indep >= RHO0
        return abs((r_indep.mu - mu) / sqrt(Sig + r_indep.var)) <= self.eps_cross

# ---------- IP-324 DP-Claims：披露受证语言 ----------
def bind_claims_dp(ec, H, prog, receipts, privacy, subject):
    summaries = {}
    for name, stat in language_stats(prog, receipts):
        eps_c, delta_c = privacy.price(stat, subject)
        if not privacy.spend(subject, eps_c, delta_c):
            continue
        summaries[name] = dp_release(stat, eps_c, delta_c)
    for c in language_claims(summaries):
        if not disclosure_ok(c, summaries):            # 只依赖已发布摘要
            continue
        ec.claims.append(Claim(c, commit=merkle_root(receipts),
                               dp_ids=c.deps,
                               cert=DisclosureCert(c.deps)))

# ---------- IP-325 7C 台账闭环 ----------
def ledgergauge_7c(M, s):
    H = M.lbox.hypothesize(s, M.dbox.R[s])                        # H
    prog = M.tbox.select(H, M.tools, M.tcv, M.budget_left(s))     # C
    receipts = M.tcv.execute(prog, M.env)                         # E (PROBING)
    M.ledger.admit_real(s, receipts)

    certs = M.abox.certify(s, H)
    aug = M.abox.augment(s, receipts, certs)                      # A
    M.ledger.admit_synth(s, aug)

    if not M.ledger.can_calibrate(s, M.prior_sigma(s), EPS_C,
                                  M.priv.affordable(s)):
        return stub_and_red(s, "evidence_or_privacy")

    mu, Sig = M.dpapcal.calibrate(receipts, aug, H, s, M.subject(s))   # C
    if not M.dpapcal.cross_validate(mu, Sig, M.cross_receipt(s)):     # V: REAL only
        mu, Sig = M.dpapcal.calibrate(receipts, ["UNKNOWN"], s, M.subject(s))
        if not M.dpapcal.cross_validate(mu, Sig, M.cross_receipt(s)):
            return stub_and_red(s, "cross_failed")

    if not decision_stable(mu, Sig, EPS_C, beta=0.05):                # 定义 438
        return stub_and_red(s, "privacy_decision_unstable")

    new_ec = M.dpapcal.update_contract(M.dpe, mu, Sig, s)             # U
    if not contract_regression(new_ec):
        return stub_and_red(s, "regression")

    M.mreg.hot_replace(M.dpe, new_ec)
    M.dbox.update_from_posterior(s, mu, Sig)
    bind_claims_dp(new_ec, H, prog, receipts, M.priv, M.subject(s))
    M.pquar.record(M.dpapcal.last_gain, realized_gain(receipts))
    M.sentinel.check(s)                                               # 泄露/掩蔽
    return True

# ---------- IP-326 主闭环 ----------
def LedgerGauge_round(M, obs, audio, tac, depth, det):
    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight:
            M.inflight.add(s)
            submit_async(ledgergauge_7c, M, s)       # 偏离 50Hz 路径
    if M.pquar.triggered() or M.sentinel.triggered():
        M.abox.disable()
        M.dpapcal.pause()
        M.use_toolgauge_fallback = True              # 退化链第 1 级
    return MODGAUGE_round(M, obs, audio, tac, depth, det)

## 4. 推导

**引理 51（无免费证据）** 设 `S = f(R,W)` 且 `W ⊥ u* | R`，则 `I(u*;S|R)=0`、`p(u*|R,S)=p(u*|R)`。
合成数据造成的后验收缩只能来自 `f` 编码的先验/不变性，不是证据。
推论：`SYNTH` 不直接进 `n_min`；只能通过认证先验 `σ₀^cert` 降低 `n_min`，且受 `B_aug` 与 AugCert 约束。
证伪：E441。

**引理 52（增强的有效样本量分解）** `y = J u* + b(x) + ε`；认证轨道平均把 nuisance 协方差投影为 `Σ_b^G`；
`I_aug(u*) = Jᵀ(Σ_ε+Σ_b^G)⁻¹J`。标量等相关下 `n_eff = k/(1+(k−1)ρ_u)`；`ρ_u=1` 时 `n_eff→1`。
增强的真实收益是 `Σ_b^G ≪ Σ_b` 的 nuisance 方差下降，不是 `u*` 信息增加。

**引理 53（隐私-效用-安全三难）** F-mode 下
`σ_post² = (σ₀⁻² + n/(σ_obs²+σ_n²))⁻¹`，
`n ≥ (σ_obs²+σ_n²)(ε_c⁻²−σ₀⁻²)`，
`σ_n,max² = n/(ε_c⁻²−σ₀⁻²) − σ_obs²`，
`ε_min = Δ√(2ln(1.25/δ))/σ_n,max`。
`σ_n,max² ≤ 0` 或 `ε_p < ε_min` ⇒ 不可行 ⇒ `stub+RED` / L-mode；不能用增强先验把噪声“补”回去。
推论 53.1：隐私不是事后可抵消的常数。

**引理 54（披露受证主张）** 主张是 DP 摘要的确定性后处理 ⇒ 后处理免疫；主张不在数值路径 ⇒ 数值等价性继承引理 49；
原始数值以承诺替代 ⇒ 可审计但不可见。需要原始值才能成立的主张必须剥离。

**引理 55（认证增强共形）** 精确 `G`-不变 ⇒ 轨道增强不改变分数分布，覆盖仍 `≥1−α`；
近似不变（TV=`η_aug`）⇒ 加权共形覆盖 `≥1−α−η_aug`；AugCert 失效 ⇒ 回落到引理 48。
禁止 SYNTH 点直接进入经验分位数计数。

**引理 56（台账闭环时序/预算/安全）** admit/计数 `O(1)` 内联；相关/`n_eff`/隐私组合/证书审计异步或离线；
DP-SGD 离线；50Hz 新增 `<0.2ms`；所有失败触发器走严格退化链且无部分热替换；隐私预算单调不增。
硬实时（引理 45/50）与五不变式保持。

**引理 57（联邦私有元先验）**
`R̄(q_θ^DP) − R̄(q*) ≤ 2η + O(√((C(Θ)+log(1/δ))/M)) + O(√((d_u+log(1/δ))/N_bl)) + P_priv(ε,δ,n_priv)`。
`P_priv` 对 `ε`、`n_priv` 单调递减；安全聚合不增加超出站点预算的隐私成本；`η` 含 `η_twin`。
推论 57.1：存在「隐私-泛化前沿」，由 E448 实测。

## 8. 本轮最大风险

**一句话**：认证增强引入的先验偏差与 DP 噪声在观测上不可分辨——系统会把跨盲区的系统性偏差误归因于「隐私预算太紧」，
从而在「7C 全通过、披露证书齐全」的表象下，以看似合规的精度热替换一个错误的契约；语言层只看到受证摘要，
进一步掩盖了偏差的真实来源。

**三重兜底**：
1. **真实独立 V**：V 只接受 `prov=REAL, indep≥ρ₀` 且未参与拟合的回执，合成/DP 回执永不参与；
2. **掩蔽哨兵**：在本地飞地内维护无噪声残差符号序列，连续同向偏差直接触发 P-Quarantine，不允许 DP 噪声为其背书；
3. **台账硬约束**：`ρ(RI∪SYNTH)=ρ(RI)`、`KL≤B_aug`、`n_eff(E_RI)≥n_min`、`ε_spent≤ε_p` 四条硬门，
   任一不满足即退化，而不是“带病热替换”。

**次级风险**：假不变性（E442）、隐私预算耗尽导致不可用（`λ_p` + L-mode）、DP 合成预训练污染先验（`η_twin` + 引理 57）、
低维摘要重建（泄露哨兵）、跨盲区预算绕过（主体级台账）、实时性冲突（异步 + `O(1)` 内联）、退化被当隐私豁免（定义 443）。
