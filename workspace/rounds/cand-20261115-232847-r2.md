# 第 10 轮（灵感循环第 2 轮；本轮灵感：「力控」×「路径规划」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**用"集合值证书"替代"点预测证书"，用"被动力学"替代"预测置信"**。v9 自陈的最大风险是块证书以 ‖F̂−F‖∞≤β 为赌注，而域偏移让这个赌注在最需要安全时最不可靠。本轮两个灵感给出两条正交治理路径：**路径规划**把"单条预测轨迹的证书"升级为"一族可行轨迹的管道证书"——不确定性使管道变窄，而不是使整张安全论证作废；**力控**把安全从预测转移到无源性与力/能量界——只要留在管道内，接触安全与 F̂ 无关。新增一律为可选增强：力层缺失注入中立元严格退回 v9；管道规划不可用时 T 退化为单路径，等价 v9 AC。

## 0. 直觉与动机

**灵感 1（路径规划 → 从点证书到管道证书）**
直觉：v9 的 AC 每 200ms 选一条预测最优轨迹并给它发一张点证书；这张证书的"真值"全押在前向模型上。路径规划的本体论不同：规划器输出的从来不是一条轨迹，而是**可行域**（走廊、漏斗、同伦类）。把 v9 的块升级为**力域管道（ForceTube）**：沿路径每个弧长截面不再是单点，而是"位姿走廊 × 容许扳量集 × 剩余能量"的三元组。测量的角色从"验证预测对不对"变成"检查是否还在管道里"；模型误差的处置从"证书作废"变成"管道按 β 腐蚀"——不确定性单调地让管道变窄，而不是让安全论证瞬间归零。核心创新：**力域管道规划器（ForceTubePlanner, FTP）**。

**灵感 2（力控 → 与预测无关的接触安全）**
直觉：力控的安全性来自被动力学，不来自"猜得准"。若 (i) 指令力被投影进力上限与摩擦锥，(ii) 阻抗执行器经能量罐保持无源性，(iii) 接近速度受动能预算约束，则任何未预见接触向环境转移的能量都有一个与 F̂ 无关的上界。于是 v9 的"预测失效即安全失效"被替换为"预测失效 ⇒ 退入被动力包络"。核心创新：**路径能量预算无源执行器（PathEnergyBudgetedAdmittance, PBA）**：能量罐不再是全局标量，而是**沿路径弧长分配**的预算 E(s)——规划期把总预算切成段，执行期每段只允许花该段吸收+储备的能量，重规划必须结转剩余预算，杜绝"重规划洗掉能量债"。

**灵感 1×2 的耦合（本轮真正的创新点）**
管道与力控不是并列的两个安全层，而是同一张证书的两面：**管道给出"允许到达哪里、允许施加多大的力"，无源性给出"到达与施力的过程本身不制造能量"**。我们称之为**力域管道证书（TubeCertificate, TC）**：有效 ⇔ 测量状态 ∈ 腐蚀后的管道 ∧ 测量扳量 ∈ 容许扳量集 ∧ 能量罐 ≥ ε_E ∧ 时间戳新鲜。它与 v9 位置证书组成"位置点证 + 力域管证"，且**管证的有效性不含前向模型误差 β**（只含传感标定误差 β_τ，量级小一个数量级）。这使 v9 的"最坏时刻单证失效"变成"至少一证仍可能与预测无关地成立"。

## 1. 研究问题（轮次升级版）

- **Q1（管道可靠性）**：在传感误差有界 ‖e‖≤β_τ 与接触模型不确定性下，如何构造腐蚀管道 T^cert，使"测量在管内"可推出"真状态在安全集内"？管道可行性（存在连续扳量调度）如何判定，代价多少？
- **Q2（能量的路径化）**：如何定义沿弧长的能量预算 E(s)，使其在 5Hz 重规划、50Hz 执行、1kHz 力环三层之间守恒？"重规划结转"能否形式化为"能量债不可洗白"的不变式？
- **Q3（接触模式序列）**：何时把"绕开障碍"改为"接触并通过"？有限接触模式图上的可行模式序列是否存在可判定判据？模式切换守卫如何保证非 Zeno？
- **Q4（退化兼容）**：力层缺失（无 F/T）时注入中立元，是否逐位回到 v9 位置证书路径？管道规划不可用时是否严格等于 v9 AC？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 力域管道律（Force-Tube Viability, FTP）**
规划输出不是单轨迹而是管道 T={ (s, C_s, W_{c(s)}, E_s) }：位姿走廊 C_s、按接触模式 c(s) 索引的容许扳量集 W、剩余能量 E_s。管证以传感误差 β_τ 腐蚀：测量 (x,w) ∈ (C_s ⊖ B_{βx}) × (W_s ⊖ B_{βw}) 才判 valid。不确定性只收窄管道，不作废整张安全论证。

**P14 路径能量预算律（Path Energy Budget, PEB）**
能量罐沿弧长分段：E(s)=E_0+∫_0^s P_abs − ∫_0^s P_cmd^+，不变式 E(s)≥0 且 E 单调可审计；执行只允许花到当前段上限，重规划必须结转 E_remaining 与未偿能量债 D_E≥0。任何未预见接触的转移能量 ≤ E_safe（该界与 F̂ 无关）。

**P15 接触模式守卫律（Contact-Mode Guard, CMG）**
模式切换只允许发生在规划图的边上；守卫用 θ_off<θ_on 双阈 + 驻留时 T_dwell 防抖；未规划接触（free 模式测到 f_n>θ_contact）不触发模式切换，而是判管证失效并沿管道最近安全截面回退。域陌生（Δ_dom≥τ_dom）时禁用"接触通过"边，只保留无接触管道。

## 3. 与基线的接口（如何退化）

- 管道规划不可用/超时/无可行管 ⇒ T 退化为单条名义路径（W=全场、C=单点邻域）⇒ 等价 v9 AC 点证书；
- 无 F/T 或力通道失效 ⇒ 注入中立元 v_τ^⊥=(w≡0, E_tank≡∞, K_d≡K_d^pos) ⇒ 纯位置控制，逐位等价 v9；
- 管证失效（离管/扳量越界/能量罐空/时间戳旧）⇒ 回退到最近安全截面并被动停驻，不执行新块；Δ_dom 越阈时删去接触边；
- v9 的 AC/MW/ID 失效 ⇒ 按 v9 五级退化链；v8 的 DA/SPR/Cal 失效 ⇒ 中立元注入，等价 v7；最终退回 v6。

## 4. 预期贡献

1. **管道证书范式**：把分块证书从"点预测的置信"改写为"集合值可行域的成员检验"，给出 β 腐蚀下的可靠性定理；
2. **能量路径化**：沿弧长分配的能量预算 + 结转规则，使三层控制速率的能量会计闭合，重规划不能洗白能量债；
3. **力域路径规划**：混合接触模式图上的可行性判据，把"绕行 vs 接触通过"变成可判定的规划选择；
4. **退化格点完整**：力层/管层/规划层任一失效均落入 v9 行为格点（引理 91）；
5. **E571–E592** 覆盖管道可靠性、腐蚀保守性、域偏移下管证 vs 点证、能量界、模式切换防抖、三层时限与接触丰富任务。

## 5. 本轮最大风险

**一句话**：管道可行性建立在"接触是准静态且摩擦锥参数已知"的假设上，而动态撞击会让真实力在传感器带宽之外瞬时越界、可变形/粘性接触会让真实可行域滑出规划时枚举的模式图——此时"测量仍在管内"可以与"真实接触已失稳"同时成立，集合值证书会以一种比点预测更体面的方式自信地错。

**新增定义 540（力域状态与接触模式 ForceState）** 力域状态 μ_t=(q_t,q̇_t,c_t,w_t,E_tank,t)，c_t∈{free,contact,slip}。力域安全集
```
M_τ = { μ : 0 ≤ f_n ≤ f_n^max,  ‖f_t‖ ≤ μ_s·f_n,  |τ_z| ≤ τ_z^max,  J=∫f_n dt ≤ J_max,  E_tank ≥ ε_E }
```
其中 μ_s 为（保守）摩擦系数下界。M_τ 是**准静态**安全集：定义 542 的管道可行性显式带此前提，动态撞击另由 P14 的能量界兜底。

**新增定义 541（力域管道 ForceTube）** 管道 T={ (s,C_s,W_{c(s)},E_s,t_s) : s∈[0,L] }。C_s⊆SE(3) 为截面走廊（含位置与姿态容差）；W_{c(s)}⊆R^3 为该模式下的容许扳量集，由摩擦锥、关节力矩限与抓取稳定域交叠而成：
```
W_contact = { (f_n,f_t,τ_z) : 0≤f_n≤f_n^max, ‖f_t‖≤μ_s f_n, |τ_z|≤τ_z^max }
W_free    = {0}
```
不确定性按传感误差腐蚀（而非膨胀）：
```
T^cert(β_τ) = { (s, C_s⊖B_{βx}, W_{c(s)}⊖B_{βw}, E_s, t_s) }
```

**新增定义 542（管道可行性 β-Viable）** T 为 β-可行 ⇔ 存在分段连续的 c(s) 与 w(s)∈W_{c(s)}(s)，使
(i) 沿动力学积分满足关节力矩/速度限；(ii) 每个模式切换点 s_j 存在满足定义 547 的守卫；(iii) 能量会计 E(s)≥0 且 E(L)≥ε_E；(iv) 走廊内任一点可停：clearance(C_s,O) ≥ d_safe + v_max^2/(2a_brake)。判定用"模式图区间传播 + 每边 SOS/线性规划"，不可行则该接触边降级（见 IP-357）。

**新增定义 543（力域管证 TubeCertificate）** Ĉ^tube=(T^cert,β_τ,t_stamp,h_hash)。有效性：
```
valid ⇔ ∃s: μ_t ∈ T^cert(s) ∧ E_tank ≥ ε_E ∧ (t_now − t_stamp) ≤ Δ_fresh
```
注意：**不含 β（前向模型误差）项**，只含 β_τ。管证与 v9 点证并列，δ_trigger 的证书项改为"点证 ∨ 管证"。

**新增定义 544（混合接触模式图 HybridContactModeGraph）** G=(V,E)，V=(cell(q),c)，cell 为位姿离散格；边 π=(Δpose, ŵ_π, dur_π, e_π, φ_π, mode_π)，ŵ_π 为期望扳量特征，e_π 为能量代价，φ_π 为可行谓词。路径为边序列，须满足模式连续性（contact 边两端必须是 contact 或经守卫的 free→contact 切换）。域陌生时删去 mode=contact 的边，仅在 free 子图上搜索。

**新增定义 545（路径能量预算 PathEnergyBudget）** 沿弧长定义
```
E(s) = E_0 + ∫_0^s P_abs(σ)dσ − ∫_0^s P_cmd^+(σ)dσ ,   P_cmd^+ = max(P_cmd,0)
```
不变式 E(s)≥0。重规划在 s0 处结转 E_remaining=E(s0) 与 D_E=max(0,−E(s0))；新路径以 E_new(0)=E_remaining 起算，总预算 E_cap。**能量债不可洗白律**：任何重规划不得令 D_E 减小，除非用离线标定的实际耗散核销。执行期无源缩放 λ=min(1, E_tank/E_req)。

**新增定义 546（阻抗调度 ImpedanceSchedule）** K_d(s),D_d(s) 按接触模式分段：free 段高刚度/低阻尼（跟踪），contact 段低刚度/高阻尼（柔顺）；safety 段刚度下限 K_min 防"过软失控"。调度须满足采样离散无源性（能量罐吸收），否则回退上一组 (K_d,D_d)。

**新增定义 547（接触模式守卫 ContactModeGuard）** free→contact 当 f_n≥θ_on 且驻留 ≥T_dwell；contact→free 当 f_n≤θ_off；slip 当 ‖f_t‖≥μ_s f_n（危险）触发回退。双阈保证 θ_off<θ_on 的迟滞；未规划接触（free 下 f_n>θ_contact 但无 contact 边）不切换模式，直接判管证失效。

## 2. 形式化定义（要点与升级）

# IP-357 ForceTubePlanner：力域管道规划器
class ForceTubePlanner:
    def __init__(self, hcmg, clearance_fn, friction,
                 beta_x=0.01, beta_w=0.5, w_e=0.3, w_r=1.0,
                 m_min=0.05, T_plan_ms=200):
        self.g, self.clear, self.mu_s = hcmg, clearance_fn, friction
        self.bx, self.bw, self.w_e, self.w_r = beta_x, beta_w, w_e, w_r
        self.m_min, self.T_plan = m_min, T_plan_ms

    def plan(self, state, goal, delta_dom, tau_dom):
        # 1) 域陌生 ⇒ 删去接触通过边，仅 free 子图
        edges = self.g.free_edges() if delta_dom >= tau_dom else self.g.edges
        # 2) anytime A*：代价 = 时间 + 能量 + 风险
        path = astar(self.g, state, goal, edges,
                     cost=lambda e: e.dur + self.w_e * e.energy
                                    + self.w_r * e.risk)
        if path is None:
            return None                                  # → Level-1
        # 3) 逐边区间传播，构造走廊 / 扳量集 / 能量前缀
        tube = []
        E = state.E_tank
        for edge in path.edges:
            C = self.corridor(edge)                      # 位姿走廊
            W = self.wrench_set(edge.mode)               # 摩擦锥∩力矩限
            E = E + edge.absorbed - edge.energy_cost     # 定义 545
            tube.append(TubeSection(edge.s0, C, W, edge.mode, E))
        # 4) 按传感误差腐蚀 —— 注意是 erosion 不是 inflation
        cert = [sec.erode(self.bx, self.bw) for sec in tube]
        # 5) β-可行复核；不可行则该接触边降级后重规划一次
        if not tube_viable(cert, self.clear, self.mu_s):
            self.g.demote_contact_edges(path)
            return self.plan(state, goal, delta_dom, tau_dom)
        return Tube(cert, beta=(self.bx, self.bw), t=now_ms(),
                    margin=min(sec.margin for sec in cert))


# IP-358 PathEnergyBudgetedAdmittance：路径能量预算无源执行器
class PathEnergyBudgetedAdmittance:
    def __init__(self, tank_init=1.0, eps_E=0.05, E_safe=2.0,
                 m_max=8.0, dt=0.02):
        self.E, self.eps_E, self.E_safe = tank_init, eps_E, E_safe
        self.m_max, self.dt = m_max, dt

    def command(self, desired_wrench, section):
        E_req = max(energy_required(desired_wrench, self.dt), 1e-9)
        lam = min(1.0, self.E / E_req)                   # 无源缩放
        w_cmd = project_cone(lam * desired_wrench, self.mu_s,
                             f_n_max=section.f_n_max)     # 力/摩擦锥投影
        self.E += absorbed_power() * self.dt
        self.E -= power(w_cmd) * self.dt                 # 定义 545
        self.E = max(0.0, self.E)
        if self.E < self.eps_E:
            return self.retreat(section)                 # 能量债 → 回退
        return w_cmd, lam

    def velocity_cap(self):
        # 与预测无关的碰撞能量界：½ m_max v² ≤ E_safe
        return (2.0 * min(self.E, self.E_safe) / self.m_max) ** 0.5


# IP-359 TubeCertificateMonitor：力域管证监视器
class TubeCertificateMonitor:
    def __init__(self, eps_E=0.05, fresh_ms=50):
        self.eps_E, self.fresh_ms = eps_E, fresh_ms

    def check(self, mu, tube, s_est):
        sec = tube.at(s_est)
        if sec is None:                     return False
        if not sec.contains_pose(mu.q):     return False
        if not sec.contains_wrench(mu.w):   return False
        if mu.E_tank < self.eps_E:          return False
        if now_ms() - tube.t > self.fresh_ms: return False
        return True

    def nearest_safe_section(self, tube, s_now):
        return max((s for s in tube.sections if s <= s_now), default=0)

## 4. 推导

**引理 87（腐蚀管道在传感误差下的可靠性）** 设位姿与扳量测量误差分别满足 ‖x̂−x‖≤β_x、‖ŵ−w‖≤β_w，且 T^cert=T⊖B_{β} 为按定义 541 腐蚀的管道。若测量 (x̂,ŵ)∈T^cert(s)，则真状态 (x,w)∈T(s)⊆Safe。证明：T^cert={m : m⊕B_β⊆T}；m∈T^cert ⇒ B_β(m)⊆T；由误差界 z∈B_β(m) ⇒ z∈T。又定义 540/542 保证 T⊆M_τ∩可行域，故真状态在安全集内。单调性：β_1≤β_2 ⇒ T^cert(β_2)⊆T^cert(β_1)，即不确定性增加只会让管道更窄。∎

**引理 88（路径能量预算的无源性与碰撞能量界）** 在 P14 的缩放 λ≤E_tank/E_req 与不变式 E(s)≥0 下，任意前缀注入能量 ∫P_cmd^+ ≤ E_0+∫P_abs；能量罐不为负；任一无规划接触处转移能量 ≤ E_safe，且该界不引用 F̂。证明：由 λ 截断，指令功率不超过罐内可用+本周期吸收；对 s 积分得会计不等式，取 max(0,·) 保号；速度由 velocity_cap 约束 ½m_max v²≤min(E,E_safe)≤E_safe，碰撞动能上界即 E_safe。全过程只用到能量/质量界，不出现前向模型。∎

**引理 89（管道证书对 v9 点证的支配/无回退）** 若管道构造取 W_s⊇{v9 候选动作在 s 处可实现的扳量}、C_s⊇{v9 预测 rollout 的位姿}，则 v9 点证有效 ⇒ 管证有效（同一测量、同一时间戳）。故 Level-1 回退不会把"原本安全"的块误判为不安全；反之域偏移使点证因 β 失效时，管证仍可因 β_τ≪β 而有效。证明：由集合包含关系逐截面成立，成员检验是单调的。∎（反向不成立：管道通常更保守，这是可接受的方向。）

**引理 90（接触守卫非 Zeno 与回退有界）** 守卫 θ_off<θ_on 且每次切换需驻留 T_dwell，故相邻切换间隔 ≥T_dwell，有限时间切换次数 ≤⌈t/T_dwell⌉；回退到最近安全截面 s* 只需有限步（≤⌈(s−s*)/Δs⌉），随后被动停驻，无无限回退。证明：迟滞排除阈值抖动；回退单调减小弧长，严格良序，故终止。∎

**引理 91（力层中立元退化与 v9 逐位等价）** 注入 v_τ^⊥ 后：w≡0 ⇒ project_cone 输出 0；E_tank≡∞ ⇒ λ≡1；K_d≡K_d^pos ⇒ 阻抗调度退化为位置控制；W≡R^3、C_s=B_δ ⇒ 管证成员检验等价 v9 位姿点证（同 δ）；PEB 无缩放；规划器不生成 T ⇒ 使用 v9 AC 候选块。故可观测指令序列与 v9 对应退化分支逐位一致。∎

**引理 92（三层时限与管证检验代价）** HCMG 规模 |V|≤4096、|E|≤4|V|；A* 复杂度 O(|E|log|V|)，区间传播 O(|path|·d)，5Hz 下典型规划 ≤15ms，摊销 ≤3ms/cycle；管证检验按 s 二分定位 O(log|path|) 且每截面常数次比较，50Hz 下 ≤0.05ms；与 v9 决策路径合计仍 ≤20ms，50Hz 保持。证明：图规模与边数上界给复杂度；检验只做几何/扳量/能量/时间戳四类 O(1) 谓词 + 一次二分；相加即预算。∎

## 8. 本轮最大风险

**一句话**：管道可行性建立在"接触是准静态且摩擦锥参数已知"的假设上，而动态撞击会让真实力在传感器带宽之外瞬时越界、可变形/粘性接触会让真实可行域滑出规划时枚举的模式图——此时"测量仍在管内"可以与"真实接触已失稳"同时成立，集合值证书会以一种比点预测更体面的方式自信地错。
