# 第 56 轮（承接第 55 轮 v32 语义-接触生存核；灵感循环第 2 轮；本轮灵感：「末端执行器控制」×「谐波减速器」）

> 第 55 轮把“动作覆盖”推进到“语义-接触生存核”：接触是否可信、全身是否可行。本轮把视角从“接触是否被语义允许”下探到 **“接触力/位姿是否真的能被末端执行器实现”**。核心矛盾：**H24**：第 55 轮的 `C^+(Σ)` 只判定了“语义上可接触”，却默认所需 wrench 能被关节直接产生；而谐波减速器的扭转柔度、迟滞、传动误差与摩擦，使“指令 wrench”与“末端实际 wrench”之间存在状态相关缺口；**H25**：该缺口是历史依赖的（加载/卸载路径不同）、慢时变的（温升、磨损），一次静态标定的证书会在任务中途悄悄失效，而全身控制会把这一缺口经接触力放大为失衡。

## 0. 直觉与动机

**灵感 1（谐波减速器 → 不是减速比，而是带记忆的柔顺传动算子）**
直觉：把谐波减速器看成 `(q_m, τ_m) → (q_j, τ_j)` 的**状态相关迟滞算子** `H_s`，其状态 `s=(迟滞内变量 h, 温度 T, 磨损 w)`。同一电机指令，加载沿与卸载沿的输出不同；柔度使输出力矩随挠曲非线性变化；传动误差使关节角与电机角非仿射。末端执行器控制的精度上限由这个算子决定，而不是由关节伺服带宽决定。

**灵感 2（末端执行器控制 → wrench 可实现集，而非 wrench 指令）**
直觉：末端控制真正能许诺的不是“我要 20N”，而是“在传动状态 `s` 下，我能在摩擦锥与电机限幅内实现的 wrench 集合 `W(x,s)`”。于是第 55 轮的语义接触约束应升级为 `C^T(Σ,s)=C^+(Σ) ∩ {所需 wrench ∈ W(x,s)}`：语义允许但传动实现不了的接触，必须提前判死，而不是到接触时才发现力上不去。

**灵感 3（迟滞 → 方向性裕度与双沿证书）**
直觉：迟滞让误差有方向。加载沿的力跟踪误差与卸载沿不同，抓取“越抓越紧”和“松手”是两个不同的可实现性问题。证书不能只记标量 `ε_w`，要记 `(ε_w^+, ε_w^-)` 与迟滞环宽 `κ_h`；控制律也应对加载/卸载采用不同刚度，而不是一个固定阻抗。

**灵感 4（末端执行器控制 → 传动观测器 + 外层操作空间阻抗的双环）**
直觉：内环用电机侧编码器、关节输出编码器与末端力/力矩传感器估计迟滞状态与输出力矩；外环在操作空间做阻抗/导纳控制，用**估计的**而非指令的 wrench 做反馈。证书携带观测器置信域 `S_t(δ)` 与 wrench 跟踪误差上界，使“控制精度”成为可审计量。

**灵感 5（磨损/温升 → 证书有效期与云边重标定）**
直觉：谐波减速器的柔度与空程会随磨损、温升漂移。证书必须有**有效期视界** `H_valid`（按负载循环、温升、估计磨损折算），边端监测残差超阈即触发局部重辨识，云端用机队先验做迁移初始化。这把第 55 轮的“边界重分割”扩展为“传动状态重标定”。

## 1. 形式化定义（增量：定义 127–132）

**定义 127（谐波传动迟滞算子）**
设电机角/力矩 `(q_m,τ_m)`，关节输出角/力矩 `(q_j,τ_j)`，传动状态 `s=(h,T,w)`。传动算子
`(q_j,τ_j) = H_s(q_m,τ_m)`，其分解为
`q_j = q_m/N + e_t(q_m,τ_j,s) + δ_h(s)`，
`τ_j = K_t(s)·(q_m/N - q_j - δ_h(s)) + τ_f(q̇,τ_j,s) + η`，
其中 `e_t` 为传动误差，`δ_h` 为迟滞内变量（Preisach 型记忆），`K_t` 为扭转刚度，`τ_f` 为摩擦，`η` 为噪声。关键：`H_s` 对 `q_m` 不满足叠加性，且同一 `(q_m,τ_m)` 在加载/卸载沿给出不同 `τ_j`。

**定义 128（末端 wrench 可实现集）**
给定末端位形 `x`、雅可比 `J`、接触雅可比 `J_c`、传动状态 `s`、电机力矩限幅 `T_max`、摩擦锥 `FC(μ)`：
`W(x,s) = { w | ∃ τ_m, λ : w = J^{-T}(τ_j + J_c^T λ), τ_j = H_s(q_m,τ_m)_τ, τ_m∈T_max, λ∈FC(μ) }`。
其内/外近似记为 `W_in ⊆ W ⊆ W_out`。同时定义位姿可实现集 `P(x,s) = {x' | ∃ τ_m : x' = FK(H_s(q_m,τ_m)_q)}`。

**定义 129（传动感知接触集）**
对第 55 轮语义接触 `(p,c)`，设该接触类型所需 wrench 为 `w_req(p,c)`。则
`C^T(Σ,s) = {(p,c) ∈ C^+(Σ) | w_req(p,c) ∈ W(x(p),s) ∧ m_s(p) ≥ θ_m}`。
语义允许、传动可实现、边界裕度三者同时成立，接触才进入控制器。

**定义 130（传动状态观测器与置信域）**
以测量 `y=(q_m,q_j,τ_m,τ_j^meas)` 估计 `ŝ_t=(ĥ,T̂,ŵ)`，给出置信域 `S_t(δ)={s | d(s,ŝ_t) ≤ r_δ}`，覆盖概率 `P(s∈S_t(δ)) ≥ 1-δ`。迟滞内变量 `h` 不可直接测，只能由加载历史与残差推断。

**定义 131（方向性 wrench 跟踪保证）**
对指令 `w_cmd` 与实际 `w_out`，定义加载/卸载方向误差 `ε_w^+(s)=sup_{沿加载}||w_out-w_cmd||`、`ε_w^-(s)`。若 `s∈S_t(δ)`，要求
`P(||w_out-w_cmd|| ≤ ε_w(s)) ≥ 1-δ_w`，且 `ε_w(s) ≥ (1/2)·κ_h(s)`（迟滞环宽给出误差下界）。

**定义 132（传动-末端联合证书）**
`J_t = (W_core, S_core, ε_w^±, κ_h, H_valid, evidence)`：
- `W_core` 轨迹实际使用的核心 wrench 集；
- `S_core` 核心传动状态置信域；
- `ε_w^±` 加载/卸载 wrench 误差上界；`κ_h` 迟滞环宽裕度；
- `H_valid` 证书有效期（负载循环/温升/磨损折算）；
- `evidence` 含迟滞环实测、温升与残差日志。
可部署条件：`W_core ⊆ W_in(x,s), ∀s∈S_core`，`ε_w^± ≤ ε_max`，`κ_h ≥ κ_min`，且 `H_valid ≥ 任务时长`。

### IP-127 THO（Transmission Hysteresis Observer）

```python
def transmission_observer(y, s_prev, P_prev, model):
    # state s = (h, T, w); h: hysteresis internal variable
    s_pred, P_pred = model.predict(s_prev, P_prev, y)
    s_hat, P_hat = model.update(s_pred, P_pred, y)   # EKF / particle filter
    r_delta = chi2_radius(P_hat, delta)
    return s_hat, P_hat, S_t(s_hat, r_delta)
```

### IP-128 RWS（Realizable Wrench Set）

```python
def realizable_wrench_set(x, s_box, T_max, mu, n_samples):
    W_in, W_out = [], []
    for s in s_box.samples(n_samples):
        for tau_m in grid(T_max):
            tau_j = harmonic_operator(tau_m, s)
            w = operational_wrench(tau_j, x)      # J^{-T} tau_j
            W_in.append(w - error_bound(s))
            W_out.append(w + error_bound(s))
    return inner_hull(W_in), outer_hull(W_out)    # polytope / ellipsoid
```

### IP-129 TCF（Transmission-aware Contact Filter）

```python
def transmission_contact_filter(Sigma, s_box, required_wrench):
    C_plus = conservative_contacts(semantic_contact_map(Sigma), ...)
    W_in, _ = realizable_wrench_set(x, s_box, T_max, mu, n)
    return {(p,c) for (p,c) in C_plus
            if required_wrench(p,c) in W_in
            and boundary_margin(p) >= theta_m}
```

### IP-130 HAC（Hysteresis-Aware Compliance）

```python
def hysteresis_aware_compliance(w_cmd, w_hat, loading, K_up, K_down, W_in):
    # directional stiffness: different gain on loading vs unloading
    K = K_up if loading else K_down
    w_des = project_to(W_in, w_cmd)
    w_ref = w_hat + K @ (w_des - w_hat)
    return operational_space_impedance(w_ref, K)
```

### IP-131 WVC（Wrench-Validity Certificate）

```python
def transmission_certificate(traj, W_in, S_t, budgets):
    W_core = wrenches_used(traj)
    if not subset(W_core, W_in):
        return ('reject', 'wrench_unrealizable', W_core - W_in)
    eps_p, eps_m = directional_error(traj)
    kappa_h = hysteresis_loop_width(traj)
    if eps_p > budgets.eps_max or eps_m > budgets.eps_max:
        return ('reject', 'wrench_error_exceeded', eps_p, eps_m)
    if kappa_h < budgets.kappa_min:
        return ('reject', 'hysteresis_margin_low', kappa_h)
    H_valid = validity_horizon(S_t, budgets.load_profile)
    if H_valid < budgets.mission_horizon:
        return ('reject', 'certificate_expires', H_valid)
    return ('ok', TransCert(W_core, S_t, (eps_p, eps_m), kappa_h, H_valid))
```

### IP-132 RHT（Recalibration Horizon Trigger）

```python
def recalibration_trigger(edge_residual, wear_est, cloud_prior):
    score = cusum(edge_residual) + lambda_w * wear_rate(wear_est)
    if score > theta_recal:
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| THO | O(N_p·d) / O(d³) | O(N_p·d) | 观测器覆盖、迟滞可观测性 |
| RWS | O(N_s·|T_max|·QP) | O(N_s) | 内近似 sound、误差界有效 |
| TCF | O(|C^+|·|W_in|) | O(|C^+|) | 所需 wrench 建模、交集完备 |
| HAC | O(QP) 每次 | O(|W|) | 方向刚度稳定、投影有界 |
| WVC | O(|轨迹|·|W_core|) | O(|W_core|) | 方向误差界闭合、有效期折算 |
| RHT | O(1) 每次 | O(1) | 残差漂移检测、云边先验一致 |

**正确性定理（Transmission-Aware End-Effector Soundness）**
假设第 55 轮 (A29)–(A32) 成立；**(A33)** 传动状态观测器满足 `P(s∈S_t(δ)) ≥ 1-δ`；**(A34)** 迟滞算子 `H_s` 在 `S_t` 上 Lipschitz 且摩擦/传动误差界有效；**(A35)** `W_in ⊆ W(x,s) ⊆ W_out` 且 `C^T` 只用 `W_in`；**(A36)** 证书有效期 `H_valid` 未被超出，磨损模型误差有界。
则部署后单步安全概率：
```
P_safe ≥ 1 - P(s∉S_t(δ)) - P(W_out\W_in ≠ ∅) - P(ε_w > ε_max) - P(H_valid expired)
```
关键：**语义允许不等于传动可实现，传动可实现不等于误差可控，误差可控不等于证书未过期**；三者必须同时进证书。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 迟滞内变量不可观 | 高 | 多测点融合（电机/输出/力矩）+ 加载历史先验 |
| 温升导致刚度漂移 | 高 | 温度分层辨识 + 在线残差校正 |
| 磨损使证书静默过期 | 高 | 有效期视界 + 云边重标定触发 |
| wrench 集过保守导致抓取失败 | 中 | 分层可实现集 + 方向性松弛 + 主动探查 |
| 末端力传感器噪声/漂移 | 中 | 观测器鲁棒化 + 无传感器力矩估计融合 |

## 6. 本轮最大风险

**一句话**：把谐波减速器显式建模为带迟滞的传动算子、并把“语义允许的接触”收紧为“传动可实现的 wrench”，能让末端力控从“指令可信”变成“实现可审计”，但其 soundness **三重依赖迟滞状态的可观性、wrench 可实现集内近似的紧致性、以及证书有效期与磨损漂移的匹配**；一旦迟滞状态估偏或有效期被任务时长悄悄越过，控制器会在“自认为可实现”的 wrench 集里持续加压，把柔顺传动推向饱和/打滑，造成不可逆的抓取失败或关节过载——因此必须以 **多测点迟滞观测 + 保守内近似 + 云边重标定视界** 三重护栏，宁可提前降额，绝不把“指令 wrench”当作“已实现 wrench”。

## 2. 关键算法 伪代码

### IP-121 SCG

```python
def semantic_contact_map(rgbd, seg_model, kappa, theta_k, theta_conf):
    Sigma = seg_model.predict_soft(rgbd)
    C = set()
    for p in grid(rgbd):
        l = argmax(Sigma[p])
        if confidence(Sigma[p]) < theta_conf:
            continue
        for c in CONTACT_TYPES:
            if kappa[l][c] >= theta_k:
                C.add((p, c))
    M = boundary_margin(Sigma)
    return Sigma, C, M
```

### IP-122 WBV

```python
def viability_kernel(Sigma, C_plus, x0, horizon, eps):
    K, margins = set(), []
    for x in sample_state_space(x0, horizon):
        feas, u, lam = solve_contact_dynamics(x, C_plus, friction_cone=mu)
        if feas:

            margins.append(distance_to_infeasible(x, C_plus))
    return KernelApprox(K_in=inner_hull(K),
                        K_out=outer_hull(K, eps),
                        margin=min(margins) if margins else 0.0)
```

```python
    delta_s = semantic_perturbation(Sigma_core, calibrated_eps)
    if K_margin < budgets.theta_K or delta_s > budgets.Theta_s:
        return ('reject', 'semantic_budget_exceeded', K_margin, delta_s)
    if rho_sem(delta_s) < budgets.rho_min:
        return ('reject', 'semantic_robustness_fail')
    return ('ok', SemanticCert(
        Sigma_core, C_core, K_margin, rho_sem, delta_s))
```

**正确性定理（Whole-Body Semantic-Contact Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** `Σ` 经温度/分位数校准，ECE ≤ ε_cal；**(A30)** `K_in⊆K(Σ)⊆K_out` 且护盾回退 `u_stop∈𝒳_safe`；**(A31)** 真实语义扰动 `||Σ-Σ̂||_∞≤ε_s`；**(A32)** 云边边界回传延迟 ≤ τ_sem 且重分割收敛。
则部署后单步安全概率：
```
P_safe ≥ 1 - P(||Σ-Σ̂||_∞ > ε_s) - P(κ miscalibrated)
           - P(K_out \ K_in ≠ ∅) - P(shield fallback fails)
```
关键：**语义不确定性进证书、生存核保守包含、护盾兜底**；任一层失守都不允许把“分割看起来很确定”当作“接触一定成立”。

## 6. 本轮最大风险

**一句话**：语义-接触接地与全身生存核把“感知标签”升级为“可执行的接触约束”，但其 soundness **三重依赖分割置信的校准、接触可供性的跨域迁移、以及生存核外近似的紧致性**；一旦边界处置信过度自信、或可供性在未见材质上系统偏移，护盾会在“自认为可行”的伪生存核内放行动作，让全身控制器把所有肢体压上虚假支撑面，造成不可逆的跌倒——因此必须以 **边界校准 + 在线 κ 更新 + 核保守度预算** 三重护栏，宁可保守制动，绝不把语义的“高置信”当作接触的“已证实”。
