# 第 1 轮：物体泛化 × 动态避障

## 1. 直觉解释（先讲人话）

**「物体泛化」的直觉。**
训练集里没有的东西——陌生物种、掉落零件、儿童玩具、轮椅、反光/透明材质——机器人还能不能安全应对？真正的危险不是"分错类"，而是"因为分不出来，就把那块空间当成空的"。现有 SDC / DCSC 把安全性押在语义识别上：一旦遇到分布外（OOD）物体，识别器低置信度或给出错误类别，而 CAC 的"缺席证书"可能据此把未知物体判为自由空间——这是最致命的假阴性。

因此本轮的**关键转向**是：

> **语义泛化是可选的，几何安全是强制的。**

我们不再要求"认识它"，而要求"不认识它也不能撞它"。任意物体（已知/未知）统一降维成"占据 / 非占据"的几何命题；语义层只负责提高效率（绕行、让行、可通行性判断），**不负责签发"这里安全"的许可**。这样"物体泛化"被转化为两个可机械复核的子问题：开放集弃权（不认识就承认不认识）+ 类别无关占据证书（无论是什么，都按几何占据处理）。

**「动态避障」的直觉。**
障碍物在动，而且可能是没见过的运动模式（滚动的球、奔跑的宠物、被风吹动的纸箱）。危险在于：用点预测（预测一条轨迹）去规划，预测误差随时域累积，几秒后误差可能大于安全间距。正解不是"预测得更准"，而是"给出**带同时覆盖保证的轨迹管（tube）**，并要求机器人的可达集与轨迹管在**整个时域内**不相交"。

**两者相乘：未知动态物体。**
既不认识、又不知道它会怎么动。此时唯一可靠的做法是退回**最坏情况**：用物理上限或共形上界约束其速度，构造以初始位置为心、半径随时间线性增长的"可达球"，要求机器人计划轨迹的可达集在整个时域内避开该球。代价是保守（可能冻结），收益是**安全性完全不依赖识别正确性和预测正确性**。

## 2. 严谨定义（承接 v23，符号续编号 1000+）

### 2.1 物体泛化层

- 已见原型集 `P_seen = {μ_c}_{c∈C_seen}`，`φ(x) ∈ ℝ^d` 为冻结骨干特征。
- **泛化半径** `r_gen`：已见样本到最近原型的距离的 `(1−α_gen)` 共形分位数，可离线机械复核。
- **在分布指示** `Γ_in(x) ≜ 1[ min_{c∈C_seen} ‖φ(x) − μ_c‖ ≤ r_gen ]`。
- **开放集泛化谓词**：

  `OSGC(x) ≜ ( Γ_in(x) ∧ Coverage(θ) ≥ 1−α ) ∨ ( ¬Γ_in(x) ∧ f_θ(x) = ⊥ )`

  即：在分布内则给出带覆盖保证的标签；分布外必须弃权为 `⊥`，禁止"硬猜"。
- **类别无关占据**：`Ô_t ⊆ ℝ³` 为保守占据点集（传感器回波按 `ε_sensor` 膨胀）。
- **认证自由集**：

  `F_t ≜ { y ∈ ℝ³ : Cov_t(y)=1 ∧ ¬Return_t(y) ∧ y ∉ Ô_t }`

  其中 `Cov_t` 来自 CAC 覆盖图，`Return_t` 表示该点有几何回波。
- **占据证书谓词**：

  `OAOC_t ≜ P( O_t ∩ F_t = ∅ ) ≥ 1−β`

  注意：该谓词**只引用几何量**，不引用任何类别标签。

### 2.2 动态避障层

- 障碍物 `i` 的真实位置 `p_i(t)`，预测器输出**轨迹管** `T_i(t) = [l_i(t), u_i(t)]`（逐维区间或球）。
- **同时覆盖保证**：`P( ∀t∈[0,H]: p_i(t) ∈ T_i(t) ) ≥ 1−α_i`（用 max-score 共形，而非逐时刻独立校准）。
- **速度上界** `v_i^ub`：观测速度的 `(1−α_v)` 共形上界；若物体未知/未观测到运动，则取物理上限 `v_max`。
- **扫掠体** `Sweep_i([a,b]) ≜ ⋃_{t∈[a,b]} T_i(t)`。
- **机器人鲁棒可达集** `R_π(τ)`：在计划 `π` 与有界扰动下，时刻 `τ` 可达的位置集合。
- **无碰撞谓词**：

  `RSCF(π) ≜ ∀τ∈[0,H]: R_π(τ) ∩ ⋃_i Sweep_i([τ, τ+δ_react]) = ∅`

  并要求 `TTC_lb(π,i) ≥ δ_react`（碰撞时间下界不小于反应延迟）。

### 2.3 未知动态物体层

- 对语义弃权 `⊥` 且速度未建模的物体，构造**最坏速度球**：

  `B_i(τ) ≜ Ball( p_i(0), v_i^ub·τ + ε_sensor )`，其中 `v_i^ub = v_max`。
- **未知动态物体谓词**：

  `UDOC(π) ≜ ∀τ∈[0,H], ∀i∈UnknownDynamic: R_π(τ) ∩ B_i(τ) = ∅`

### 2.4 统一准入门

`Exec_v24 = Exec_v23 ∩ { π : OSGC ∧ OAOC ∧ DQTC ∧ RSCF ∧ UDOC }`

并保持单调链 `Exec_v24 ⊆ Exec_v23 ⊆ … ⊆ Exec_v18`。

## 3. 研究问题与可证伪假设

- **Q1（解耦）**：把语义识别完全弃权后，几何安全是否可保持？——假设：只要 OAOC 不依赖标签，弃权只会缩小提议计划集，不会扩大已准入的不安全计划集。
- **Q2（同时覆盖）**：轨迹管的同时覆盖能否转化为时域鲁棒无碰撞？——假设：能，代价是对障碍物数做并集界 `Σα_i`。
- **Q3（开放世界安全-可用性）**：最坏速度球在拥挤场景是否导致可行计划集为空（冻结）？——假设：会；需要分层退让（减速→绕行→停车）而非二元拒绝。

## 4. 与既有 v23 的衔接

- SDC/DCSC 从"安全签发者"降级为"效率建议者"；安全许可改由 OAOC 签发。
- FSVC 的少样本原型继续用于 `Γ_in` 的距离计算，但**不再**用于决定自由空间。
- CAC 的缺席证书增加一条硬约束：任何"缺席"都必须扣除 OOD 假阴性上界 `β`。
- DCL 增加义务：`Unknown ⇒ Hazard`，未知物体默认按最危险处理。

## 5. 本轮最大风险（一句话）

**对未知动态物体采用最坏速度球虽可证安全，却会在拥挤/高速场景把可行计划集压缩到空集导致机器人长期冻结；而一旦为恢复可用性放宽速度上界或缩短时域，又会在共形交换性失效时让"无碰撞"承诺失去统计依据——即开放世界下安全性与可用性的不可调和张力。**

```python
# ============================================================
# IP-441 Open-Set Generalization Certificate (OSGC)
# ============================================================
@dataclass
class OpenSetGeneralizationCertificate:
    backbone: 'Backbone'
    prototypes: dict[int, Tensor]      # 已见类别原型
    alpha_gen: float = 0.01
    alpha: float = 0.01
    r_gen: float = None                # 共形分位数，fit 后得到

    def fit(self, calib_seen: list[tuple[Tensor, int]]):
        """用已见校准集标定泛化半径 r_gen"""
        dists = []
        for x, _ in calib_seen:
            phi = self.backbone.extract_features(x)
            d = min(torch.norm(phi - mu) for mu in self.prototypes.values())
            dists.append(d.item())
        # 有限样本共形分位数（向上取整阶统计量）
        n = len(dists)
        k = math.ceil((n + 1) * (1 - self.alpha_gen))
        self.r_gen = sorted(dists)[min(k, n) - 1]

    def in_distribution(self, x: Tensor) -> tuple[bool, float]:
        phi = self.backbone.extract_features(x)
        d = min(torch.norm(phi - mu) for mu in self.prototypes.values()).item()
        return d <= self.r_gen, d

    def predict(self, x: Tensor) -> tuple[int | None, float, bool]:
        """返回 (标签或 None, 距离, 是否在分布)。None 表示强制弃权 ⊥"""
        in_dist, d = self.in_distribution(x)
        if not in_dist:
            return None, d, False          # OOD → ⊥，交由 UDOC 走最坏情况
        logits = self.backbone.classify(self.backbone.extract_features(x))
        return int(logits.argmax()), d, True

# IP-440 Object-Agnostic Occupancy Certificate (OAOC)
# ============================================================
class ObjectAgnosticOccupancyCertificate:
    def __init__(self, beta_max: float = 1e-4, eps_sensor: float = 0.08):
        self.beta_max = beta_max
        self.eps_sensor = eps_sensor
        self.fn_scores: list[float] = []   # 假阴性校准分数

    def calibrate_false_negative(self, calib: list[tuple['Scan', 'OccupancyGT']]):
        """在含已知障碍的校准集上估计自由空间假阴性上界"""
        for scan, gt in calib:
            free = self._raw_free(scan)
            # 分数 = 落入自由集内的真实占据体积占比
            leak = (gt.occupied & free).sum() / max(gt.occupied.sum(), 1)
            self.fn_scores.append(float(leak))
        self.beta_hat = conformal_upper_quantile(self.fn_scores, self.beta_max)

    def _raw_free(self, scan: 'Scan') -> Tensor:
        """只依赖几何：覆盖 ∧ 无回波 ∧ 不在膨胀占据内"""
        cov = scan.coverage_mask()                      # 来自 CAC
        returns = scan.depth_returns()                  # 任意几何回波
        occ = dilate(returns, self.eps_sensor)          # 保守占据
        return cov & (~occ)

    def certified_free(self, scan: 'Scan') -> Tensor:
        """OAOC_t：假阴性上界超限时返回空自由集（拒绝签发）"""
        if getattr(self, 'beta_hat', 1.0) > self.beta_max:
            return torch.zeros_like(scan.coverage_mask(), dtype=torch.bool)
        return self._raw_free(scan)

    def predicate(self, scan: 'Scan') -> bool:
        """OAOC_t：签发自由集即视为谓词成立（覆盖由校准保证）"""
        free = self.certified_free(scan)
        return bool(free.any()) or getattr(self, 'beta_hat', 1.0) <= self.beta_max

# IP-442 Dynamic Quantile Trajectory Certificate (DQTC)
# ============================================================
class DynamicQuantileTrajectoryCertificate:
    def __init__(self, predictor: 'TrajPredictor', alpha: float = 0.01,
                 horizon: float = 2.0, dt: float = 0.05):
        self.predictor = predictor
        self.alpha = alpha
        self.H = horizon
        self.dt = dt
        self.q_hat = None                  # max-score 共形分位数

    def _nonconformity(self, traj_gt: Tensor, lo: Tensor, hi: Tensor) -> float:
        """max-score：整条轨迹上逐点超出区间量的最大值"""
        over = torch.maximum(lo - traj_gt, traj_gt - hi)
        return over.clamp(min=0).max().item()

    def fit(self, calib: list[tuple['History', Tensor]]):
        scores = []
        for hist, traj_gt in calib:
            lo, hi = self.predictor.quantile_bounds(hist, self.H, self.dt)
            scores.append(self._nonconformity(traj_gt, lo, hi))
        # 同时覆盖：对 max-score 取 (1−α) 共形分位数
        n = len(scores)
        k = math.ceil((n + 1) * (1 - self.alpha))
        self.q_hat = sorted(scores)[min(k, n) - 1]

    def tubes(self, history: 'History') -> dict[int, tuple[Tensor, Tensor]]:
        """返回每个障碍物的膨胀后轨迹管 T_i(t)"""
        raw = self.predictor.quantile_bounds(history, self.H, self.dt)
        return {i: (lo - self.q_hat, hi + self.q_hat)
                for i, (lo, hi) in raw.items()}

    def predicate(self) -> bool:
        return self.q_hat is not None

# IP-443 Robust Swept Collision-Freedom Certificate (RSCF)
# ============================================================
class RobustSweptCollisionFreedomCertificate:
    def __init__(self, d_safe: float = 0.35, delta_react: float = 0.12,
                 horizon: float = 2.0, dt: float = 0.05):
        self.d_safe = d_safe
        self.delta_react = delta_react
        self.H = horizon
        self.dt = dt

    def reachable_set(self, plan: 'Plan', tau: float) -> 'Region':
        """鲁棒前向可达集：计划名义位置 ⊗ 有界扰动球"""
        p = plan.nominal_position(tau)
        r = plan.tracking_error_bound(tau) + plan.localization_error(tau)
        return Ball(p, r)

    def ttc_lower_bound(self, plan: 'Plan', tubes, tau: float) -> float:
        """基于管边界的碰撞时间下界"""
        p = plan.nominal_position(tau)
        best = math.inf
        for lo, hi in tubes.values():
            gap = box_distance(p, lo[tau_idx(tau)], hi[tau_idx(tau)])
            closing = max(plan.speed(tau), 1e-6)
            best = min(best, max(gap - self.d_safe, 0.0) / closing)
        return best

    def predicate(self, plan: 'Plan', tubes) -> bool:
        for tau in frange(0.0, self.H, self.dt):
            R = self.reachable_set(plan, tau)
            swept = union(
                box_at(lo, hi, t)
                for lo, hi in tubes.values()
                for t in frange(tau, tau + self.delta_react, self.dt)
            )
            if distance(R, swept) < self.d_safe:
                return False
            if self.ttc_lower_bound(plan, tubes, tau) < self.delta_react:
                return False
        return True

# IP-444 Unknown Dynamic Object Certificate (UDOC)
# ============================================================
class UnknownDynamicObjectCertificate:
    def __init__(self, v_max: float = 1.5, eps_sensor: float = 0.08,
                 d_safe: float = 0.35, horizon: float = 2.0, dt: float = 0.05):
        self.v_max = v_max
        self.eps_sensor = eps_sensor
        self.d_safe = d_safe
        self.H = horizon
        self.dt = dt

    def worst_case_ball(self, p0: Tensor, tau: float) -> 'Ball':
        return Ball(p0, self.v_max * tau + self.eps_sensor)

    def predicate(self, plan: 'Plan', unknown: dict[int, Tensor]) -> bool:
        """unknown: {obj_id: 初始位置 p0}；对每个未知动态物体做最坏球检查"""
        for p0 in unknown.values():
            for tau in frange(0.0, self.H, self.dt):
                R = reachable_set_of(plan, tau)
                if distance(R, self.worst_case_ball(p0, tau)) < self.d_safe:
                    return False
        return True

# IP-445 HPC-E++ Unified Open-World Gate
# ============================================================
@dataclass
class HPCEPlusPlus:
    hpc_e_plus: 'HPCEPlus'          # v23 四证门
    oaoc: ObjectAgnosticOccupancyCertificate
    osgc: OpenSetGeneralizationCertificate
    dqtc: DynamicQuantileTrajectoryCertificate
    rscf: RobustSweptCollisionFreedomCertificate
    udoc: UnknownDynamicObjectCertificate

    def admits(self, plan, scan, history, modules, unknown_objs) -> bool:
        # 1. v23 四证门（物理/云边/少样本/IP）
        if not self.hpc_e_plus.admits(plan, scan.x, scan.v, scan.z,
                                      scan.E_res, scan.margin_req, modules):
            return False
        # 2. 类别无关占据证书（不依赖语义）
        if not self.oaoc.predicate(scan):
            return False
        # 3. 开放集泛化：OOD 一律弃权，不进入安全许可
        for det in scan.detections:
            _, _, in_dist = self.osgc.predict(det.crop)
            if not in_dist and det.claimed_free:
                return False            # 禁止用 OOD 结果声称自由
        # 4. 动态轨迹管 + 鲁棒无碰撞
        tubes = self.dqtc.tubes(history)
        if not self.rscf.predicate(plan, tubes):
            return False
        # 5. 未知动态物体：最坏速度球
        if not self.udoc.predicate(plan, unknown_objs):
            return False
        return True

# 分层退让控制器（缓解"冻结"）
# ============================================================
class LayeredYieldingController:
    """当 HPC-E++ 拒绝时，按代价从低到高尝试，而非直接停车"""
    def __init__(self, gate: HPCEPlusPlus, v_scale=(1.0, 0.6, 0.3, 0.0)):
        self.gate = gate
        self.v_scale = v_scale

    def select(self, base_plan, scan, history, modules, unknown):
        for s in self.v_scale:
            plan = base_plan.scaled_speed(s)
            if self.gate.admits(plan, scan, history, modules, unknown):
                return plan
        return STOP_PLAN              # 最后才停车（安全兜底）
```

## 2. 复杂度分析

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 |
|---|---|---|---|
| OSGC 标定 | O(n·\|P_seen\|·d) 离线 | O(n) | n≤5000, d=256 |
| OSGC 单帧推断 | O(\|P_seen\|·d) | O(1) | \|P_seen\|≤200 |
| OAOC 自由集 | O(\|Voxel\|) | O(\|Voxel\|) | 体素 5cm, 局部 20m³ |
| DQTC 标定 | O(n·H/dt) 离线 | O(n·H/dt) | H=2s, dt=50ms → 40 步 |
| DQTC 轨迹管 | O(\|obs\|·H/dt) | O(\|obs\|·H/dt) | \|obs\|≤30 |
| RSCF 检查 | O((H/dt)·(δ_react/dt)·\|obs\|) | O(1) | ≈40·3·30≈3600 次距离 |
| UDOC 检查 | O((H/dt)·\|unknown\|) | O(1) | \|unknown\|≤10 |

**实时性**：OAOC 在降采样体素上执行；DQTC 与 RSCF 在 `H/dt=40` 步上向量化；UDOC 只对少量未知物体执行。整体目标 P99 <20ms，与 v23 持平。

## 3. 正确性论证

### 引理 1（语义-几何解耦：弃权不降低安全性）
**陈述**：若安全谓词 `S(π)` 只引用认证自由集 `F_t` 与障碍轨迹管 `T_i`，不引用任何类别标签，则把语义分类器替换为恒弃权 `⊥` 不会增大碰撞概率。

**证明**：
1. 准入只接受满足 `S(π)` 的计划；`S` 是几何量的函数，与标签无关，故标签变化不改变 `S` 的真值。
2. 语义层只影响**提议**哪些计划进入候选集（例如是否选择绕行某类物体）。候选集缩小不会使原本被 `S` 拒绝的不安全计划变成被接受。
3. 因此 `{π : S(π)=true}` 不变，安全保证不因弃权而削弱；最坏情况只是可用性下降（提议变少）。
∎

### 引理 2（同时覆盖 ⇒ 时域鲁棒无碰撞）
**陈述**：若对每个障碍物 `i`，`P(∀t∈[0,H]: p_i(t)∈T_i(t)) ≥ 1−α_i`，且 `RSCF(π)` 以间距 `d_safe` 成立，则 `P([0,H] 内无碰撞) ≥ 1 − Σ_i α_i`。

**证明**：
1. 令 `E_i` 为"障碍物 `i` 全程落在其轨迹管内"的事件，`P(E_i) ≥ 1−α_i`。
2. 由并集界，`P(⋂_i E_i) ≥ 1 − Σ_i α_i`。
3. 在 `⋂_i E_i` 上，`p_i(t)∈T_i(t)`；而机器人实际位置落在鲁棒可达集 `R_π(t)`（由可达集定义与有界扰动包含关系）。
4. `RSCF` 保证 `R_π(τ)` 与所有 `Sweep_i([τ,τ+δ_react])` 距离 ≥ `d_safe`，故机器人实际位置与障碍实际位置在时域内始终分离。
∎

### 引理 3（未知动态物体的最坏情况安全）
**陈述**：若对物体 `i` 有 `‖v_i(t)‖ ≤ v_max`，且 `UDOC` 用球 `B_i(τ)=Ball(p_i(0), v_max·τ+ε_sensor)` 检查通过，则无论其真实轨迹与类别如何，`[0,H]` 内均不与机器人碰撞。

**证明**：
1. 由三角不等式与速度上界：`‖p_i(t)−p_i(0)‖ ≤ ∫_0^t‖v_i‖ ds ≤ v_max·t ≤ v_max·t+ε_sensor`，故 `p_i(t) ∈ B_i(t)`。
2. `UDOC` 保证 `R_π(t) ∩ B_i(t) = ∅`（间距 `d_safe`）。
3. 机器人实际位置 ∈ `R_π(t)`，故与 `p_i(t)` 分离。该推导不使用任何识别结果或运动模型。
∎

### 引理 4（开放集弃权的覆盖保证）
**陈述**：`OSGC` 仅在 `Γ_in(x)=1` 时输出标签，且此时选择性共形覆盖 `≥1−α`；`Γ_in(x)=0` 时输出 `⊥` 并由引理 3 兜底。

**证明**：在分布内分支直接由选择性共形预测（risk-controlling prediction sets）给出覆盖；分布外分支不签发任何语义安全声明，其安全性完全由 `OAOC`（引理 1）与 `UDOC`（引理 3）承担。∎

### 定理（HPC-E++ 开放世界五证完备性）
**陈述**：`HPCEPlusPlus.admits(π)=true` ⟺ `π` 同时满足：
(1) 物理接地安全（v23 四证），
(2) 类别无关几何占据安全，
(3) 开放集泛化（OOD 不签发自由空间），
(4) 动态轨迹管同时覆盖下的鲁棒无碰撞，
(5) 未知动态物体的最坏情况无碰撞。

且 `Exec_v24 ⊆ Exec_v23 ⊆ … ⊆ Exec_v18`。

**证明**：充分性由 `admits` 的五个连言条件与引理 1–4 直接得到；必要性由任一条件缺失即拒证。单调性由 `Exec_v24 = Exec_v23 ∩ (…)` 的交集定义直接得到。∎

## 4. 已知风险与缓解

| 编号 | 描述 | 严重度 | 缓解措施 | 剩余风险 |
|---|---|---|---|---|
| R1 | 最坏速度球过于保守 → 拥挤/高速场景可行计划集为空，机器人冻结（livelock） | 最高 | 分层退让 `LayeredYieldingController`（减速→绕行→停车）；只在最后才停 | 狭窄通道 + 多个未知快速物体时仍可能长时间停车 |
| R2 | 非平稳动态场景破坏共形交换性 → 同时覆盖承诺失效 | 最高 | 在线/块状共形 + 漂移检测；交换性检验失败即增大 `α_i` 或退回 UDOC | 突变式分布漂移（突然加速）在检测前存在窗口 |
| R3 | 高维特征空间中 `r_gen` 标定失真（维度灾难）→ OOD 检测漏报 | 高 | 特征归一化 + 每类多半径 + 降维后再算距离；用 conformal p-value 而非单一阈值 | 近分布但语义危险的物体可能被判为 in-dist |
| R4 | 轨迹管宽度随时域增长 → 长时域全部计划不可行 | 高 | 滚动时域（receding horizon）+ 制动保证下的时域截断；速度随管宽自适应下降 | 高速场景有效时域被压缩，可能只能急停 |
| R5 | 未知物体出现在制动距离内 → 物理上不可避免的碰撞 | 中 | 运动学安全包络 `v ≤ (d_free−d_safe)/δ_react`；全向感知覆盖 | 遮挡后突然出现的快速物体仍可能突破包络 |
