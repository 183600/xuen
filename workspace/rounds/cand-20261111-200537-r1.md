# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；新灵感循环第 1 轮；本轮灵感：「灵巧手」×「四足机器人」）

> 第 54 轮把技能组合落到动作空间剖面与云边协同。本轮从两个高自由度、接触密集的具身形态出发：灵巧手（手指步态、重抓、抓取力闭合）与四足机器人（足端步态、落脚重规划、支撑力闭合）。核心矛盾：H22：现有动作空间剖面 α_S 是「关节/末端动作」视角，无法表达「接触在何时、以何模式建立与断开」，而抓取成败与步态成败恰恰由接触调度决定；H23：灵巧手与四足在语义上几乎无交集，却在「用一组可切换接触去操纵一个自由体」上结构同构，缺乏承载跨形态迁移的接触级证书，导致 JTC 只能在同形态内传递。

## 0. 直觉与动机

**灵感 1（自由体二元性 → 手与足是同一个问题的两面）**
直觉：灵巧手固定手部、手指在物体上切换接触点来操纵自由体（物体）；四足固定地面、足端在地面上切换接触来操纵自由体（躯干）。两者的自由体不同、接触施力方向相反，但都在做同一件事：**用一个可切换的接触集合，对自由体施加满足 w_req 的力旋量**。因此迁移单位不应是「手」或「腿」，而应是 **自由体 + 接触调度**。这正是 H23 的破题点。

**灵感 2（接触调度作为一等公民 → 从动作剖面到接触剖面）**
直觉：动作剖面 α_S 描述「能做哪些动作」，但动作是否有效取决于「此刻哪些接触在起作用」。引入接触剖面 `β_S(c)`（c 为接触状态），动作空间到接触空间存在多对一投影 `π: A → C`：同一条末端轨迹可由不同接触调度实现，而不同调度对应完全不同的力闭合与失败模式。于是技能 = 接触调度的语法句子，而非动作序列。

**灵感 3（力旋量包络统一抓取与步态稳定性）**
直觉：抓取稳定性（力闭合/形闭合）与四足稳定性（支撑多边形/ZMP/捕获点）看似两套理论，实为同一件事的两个特例：**接触能产生的力旋量集合 W(σ) 是否包住所需旋量 w_req**。灵巧手要求 W 覆盖物体重力+操作旋量；四足要求 W 覆盖躯干重力+惯性旋量。统一为 **接触力旋量包络 CWE** 与 **接触稳定裕度 ρ_c**，让第 54 轮鲁棒性谱多出一个「接触维」。

**灵感 4（接触切换是负迁移的真正来源）**
直觉：手在手指步态（finger gaiting）时、四足在小跑腾空相时，都会经历「接触数减少/瞬态失控」的脆弱窗口。轨迹相似不代表切换窗口同样可控。定义 **接触切换脆弱性 V(τ)**：切换窗口内 w_req 不可满足的时间占比 + 裕度跳变。跨形态迁移应以 V 为准入门槛，而非轨迹相似度。

**灵感 5（接触语法 + 形态桥 → 可判定的跨形态迁移）**
直觉：把接触基元与合法切换写成语法 G_C，技能组合就变成语法可推导性；再用 **形态桥 μ**（角色保持地映射固定方/自由方/接触模式）判断手技能与足技能是否接触同构。这样第 54 轮 JTC 被升级为 **接触调度迁移证书 CSTC**，迁移从「同形态参数共享」扩展到「跨形态接触结构共享」。

## 1. 形式化定义（增量：定义 121–127）

**定义 121（接触状态与接触调度）**
接触状态 `c = (B, E, M)`：`B` 为机器人接触部件，`E` 为环境或被操作物，`M: B×E → {stick, slip, free, impact}` 为接触模式。接触调度
```
σ = ⟨(c_0, Δ_0), (c_1, Δ_1), ..., (c_{k-1}, Δ_{k-1})⟩
```
在 `t_i` 处发生切换 `τ_i = c_i → c_{i+1}`。技能 S 的 **接触剖面** `β_S(c) = (1/T)∫ 1[c(t)=c] dt`，与第 54 轮动作剖面通过投影 `β_S = π_* α_S` 相容（`π: A → C` 多对一）。

**定义 122（自由体与接触对偶）**
技能的自由体 `fb(S)`：灵巧手取被操作物 O，四足取躯干 B。**接触对偶** `dual(c)` 交换固定方与自由方角色、保持接触模式。称两个接触状态**对偶同构**，若 `dual(c_h) ≅ c_q`（在定义 126 的 μ 意义下）。自由体所需旋量记为 `w_req`（含重力、惯性、操作/扰动）。

**定义 123（接触力旋量包络 CWE 与稳定裕度）**
给定调度 σ，`W(σ) = ⊕_{c∈σ} ⊕_{(b,e)∈c} J_{b,e}^T · FC(M(b,e))`，即经摩擦锥 FC 与单侧约束、由接触雅可比 J 映射到自由体后的力旋量 Minkowski 和。**接触可行**：`w_req ∈ W(σ)`。**接触稳定裕度**
```
ρ_c(σ) = dist(w_req, ∂W(σ)) / ||w_req||
```
灵巧手的力闭合与四足的动态支撑均为 `ρ_c > 0` 的特例。

**定义 124（接触切换脆弱性 CTV）**
对切换 `τ: σ→σ'`，
```
V(τ) = (1/|Δ_τ|) ∫_{Δ_τ} 1[w_req ∉ W(σ_t)] dt + λ·|ρ_c(σ) - ρ_c(σ')|
```
第一项为切换窗口内「所需旋量不可满足」的时间占比，第二项为裕度跳变。迁移门槛：`max_i V(τ_i) ≤ Θ_V`。

**定义 125（接触调度语法 CSG）**
`G_C = (N, Σ, P, S)`：终端 Σ 为接触基元（模式+部件+时长区间），非终端 N 为调度片段，产生式 P 编码合法切换（受摩擦、运动学可达、时序/单侧约束）。技能组合 = G_C 可推导的句子；组合可判定性 = Earley/GLR 解析是否成功。与第 54 轮 SCOM 图搜索结构同构，但边是**接触可切换性**而非动作兼容性。

**定义 126（形态桥 CMB）**
角色保持映射 `μ: C_hand → C_quad` 需同时满足：
1. 自由体对应：`fb` 保持（物体 ↦ 躯干，而非按部件名映射）；
2. 接触模式保持：`M(μ(c)) = M(c)`；
3. 旋量变换：`w_req^quad = Ad_g · w_req^hand`，g 为形态变换，Ad 为伴随；
4. 脆弱性一致：`|V(τ) - V(μ(τ))| ≤ δ_V`。
存在满足 1–4 的 μ，称两技能**接触同构**。

**定义 127（接触调度迁移证书 CSTC）**
`CSTC = (σ, W(σ), ρ_c, {V(τ_i)}, μ, J, evidence)`，在第 54 轮联合证书 J 上增加接触维。若
```
ρ_c ≥ ρ_c^min ∧ max_i V(τ_i) ≤ Θ_V ∧ μ 存在 ∧ ||w_req^quad - Ad_g w_req^hand|| ≤ δ_w
```
则跨形态迁移可部署。

## 2. 关键算法 伪代码

### IP-121 CPF（Contact Primitive Factorization）
```python
def factorize_contacts(skill, tactile_segments, dt=0.01):
    schedule = []
    for seg in tactile_segments:
        c = ContactState(bodies=seg.bodies, env=seg.env,
                         modes=classify_mode(seg.force, seg.slip, seg.jerk))
        schedule.append((c, seg.duration))
    return ContactSchedule(schedule)

def contact_profile(schedule):
    T = sum(dt for _, dt in schedule)
    beta = defaultdict(float)
    for c, dt in schedule:
        beta[c] += dt / T
    return beta
```

### IP-122 CSG（Contact Schedule Grammar）
```python
def build_contact_grammar(primitives, transition_rules):
    G = Grammar(start='S')
    for p in primitives:
        G.add_terminal(p)
    for (a, b, guard) in transition_rules:
        # guard = friction_ok ∧ kinematic_reach ∧ timing_ok
        G.add_production(f'{a} -> {b}', guard)
    return G

def schedule_derivable(G, sigma, horizon):
    return earley_parse(G, sigma, max_len=horizon)  # None 或推导树
```

### IP-123 CWE（Contact Wrench Envelope）
```python
def wrench_envelope(schedule, mu_friction, kinematics):
    W = ConvexHull([wrench_zero])
    for c, _ in schedule:
        for (b, e) in c.contacts:
            J = contact_jacobian(b, e, kinematics)         # 到自由体的雅可比
            FC = friction_cone(c.mode(b, e), mu_friction)  # 保守内近似
            W = minkowski_sum(W, linear_map(J.T, FC))
    return W

def stability_margin(W, w_req):
    if w_req not in W:
        return -distance_to_boundary(W, w_req) / norm(w_req)
    return distance_to_boundary(W, w_req) / norm(w_req)
```

### IP-124 CTV（Contact Transition Vulnerability）
```python
def transition_vulnerability(sigma, i, w_req, lam=0.5):
    c0, c1 = sigma[i][0], sigma[i+1][0]
    window = blend_window(c0, c1)  # 切换窗口内的中间接触状态
    fail = sum(not satisfies(wrench_envelope([ct]), w_req) for ct in window)
    return fail/len(window) + lam*abs(margin(c0, w_req) - margin(c1, w_req))
```

### IP-125 CMB（Contact-Morphology Bridge）
```python
def morphology_bridge(sigma_h, g, delta_V):
    mapping = {}
    for c, dt in sigma_h:
        c_q = role_preserving_map(c, g)  # 固定方<->固定方, 自由体<->自由体, 模式保持
        if c_q is None or c_q.modes != c.modes:
            return ('reject', 'no_role_preserving_map', c)
        mapping[c] = c_q
    for tau in transitions(sigma_h):
        if abs(V(tau) - V(mapping[tau])) > delta_V:
            return ('reject', 'transition_mismatch', tau)
    return ('ok', mapping)
```

### IP-126 CSTC（Contact Schedule Transfer Certificate）
```python
def contact_transfer_certify(sigma, J_source, g, delta_w, delta_V):
    W = wrench_envelope(sigma, mu_friction, kinematics)
    rho_c = stability_margin(W, w_req_of(J_source))
    Vs = [transition_vulnerability(sigma, i, w_req_of(J_source))
          for i in range(len(sigma)-1)]
    if rho_c < RHO_C_MIN or max(Vs) > THETA_V:
        return ('reject', 'contact_fragile', rho_c, Vs)
    ok, mu = morphology_bridge(sigma, g, delta_V)
    if not ok:
        return ('reject', 'bridge_fail', mu)
    if norm(w_req_of(J_source, target=True) - Ad(g) @ w_req_of(J_source)) > delta_w:
        return ('reject', 'wrench_mismatch')
    return ('ok', CSTC(sigma, W, rho_c, Vs, mu, J_source))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| CPF | O(|Σ_seg|·|B|·|E|) | O(|Σ|) | 接触分段完备、模式可辨识 |
| CSG | O(|P|·|σ|³)（Earley） | O(|N|·|σ|²) | 产生式 guard 保守 sound |
| CWE | O(|σ|·|contacts|·|FC|) | O(V_H) | 摩擦锥内近似、单侧约束 |
| CTV | O((|Δ_τ|/dt)·|contacts|) | O(|Δ_τ|) | 切换窗口充分采样 |
| CMB | O(|σ|·|c| + |τ|) | O(|σ|) | 角色保持、模式保持 |
| CSTC | O(CWE + CTV + CMB) | O(V_H + |σ|) | 预算闭合、旋量变换有界 |

**正确性定理（Contact-Schedule Transfer Soundness）**
在第 54 轮 (A26)–(A28) 与 J sound 的前提下，新增：
**(A29)** 接触分段完备且接触模式可由本体/触觉观测辨识，误判率 ≤ ε_m；
**(A30)** 摩擦锥使用保守内近似，单侧约束与冲击建模为区间；
**(A31)** 形态桥 μ 保持自由体对偶与接触模式，且伴随变换误差有界；
**(A32)** 切换窗口采样步长 dt 足够小，V 估计误差 ≤ ε_V。
则跨形态部署成功概率
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - P(δ_a>Θ_a) - P(ρ_c<ρ_c^min) - P(max V>Θ_V)
              - P(μ 不存在) - P(||w_req 变换误差||>δ_w) - ε_m - ε_V
```
关键：**接触可行先于动作可行，切换脆弱性先于轨迹相似性，自由体对偶是迁移的语义前提**。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 接触模式辨识噪声导致 σ 错分 | 高 | 多模态触觉融合 + 置信区间 + 保守合并相邻接触态 |
| 摩擦锥保守近似导致过度拒绝 | 中 | 内/外近似双跑 + 在线摩擦辨识 + 阈值自适应 |
| 形态桥角色映射语义歧义（如掌↔躯干） | 高 | 以自由体/固定方角色而非部件名定义 μ + 人工校验锚点 |
| 快速冲击落在采样窗口之间 | 高 | 对抗性密集采样 + 事件触发采样 + 冲击专用基元 |
| 对偶在「运动中的操作」下失效 | 中 | 限定准静态/周期步态子域，动态域单独建模 |

## 6. 本轮最大风险

**一句话**：接触调度迁移把「手抓取」与「足步态」统一为「自由体 + 可切换接触 + 力旋量包络」，但其 soundness 依赖**接触模式辨识的完备性、摩擦锥保守近似的松紧、以及自由体对偶在动态场景下不失效**；一旦接触态错分或快速冲击落在采样窗口之间，CWE 会给出虚假的可行裕度、CTV 会低估切换脆弱性，μ 便会把「轨迹相似但力不可行」的抓取/步态调度当成可迁移，造成系统性负迁移，故必须以**多模态接触辨识 + 对抗性切换采样 + 自由体对偶可证伪**三重护栏，把「接触同构」当作待证伪假设，而非迁移许可证。

### IP-123 CWE
```python
def envelope(sigma, mu, kin):
    W = {wrench_zero}
    for c, _ in sigma:
        for (b, e) in c.contacts:
            # 手: 抓取矩阵 G；足: 支撑映射 G_sup，均映射到自由体
            J = contact_jacobian(b, e, kin, frame=free_body(sigma))
            W = minkowski(W, image(J.T, friction_cone(c.mode(b,e), mu)))
    return W

def rho_c(sigma, w_req, mu, kin):
    W = envelope(sigma, mu, kin)
    return signed_distance(w_req, W) / norm(w_req)
```

### IP-124 CTV
```python
def V(sigma, i, w_req, mu, kin, dt=0.002, lam=0.5):
    a, b = sigma[i][0], sigma[i+1][0]
    win = blend(a, b, dt)                     # 切换窗口内的中间接触态
    fail = sum(1 for c in win
               if not contains(envelope([(c, dt)], mu, kin), w_req))
    return fail/len(win) + lam*abs(
        rho_c([(a,1)], w_req, mu, kin) - rho_c([(b,1)], w_req, mu, kin))
```

### IP-125 CMB
```python
def bridge(sigma_h, g, delta_V):
    mp = {}
    for c, _ in sigma_h:
        c_q = role_map(c, g)   # 固定方<->固定方, 自由体<->自由体, 模式保持
        if c_q is None or c_q.modes != c.modes:
            return None
        mp[c] = c_q
    for tau in transitions(sigma_h):
        if abs(V(tau) - V(mp[tau])) > delta_V:
            return None
    return mp
```

### IP-126 CSTC
```python
def certify(sigma, J, g, d_w, d_V, rho_min, theta_V):
    W  = envelope(sigma, mu, kin)
    rc = signed_distance(w_req(J), W) / norm(w_req(J))
    Vs = [V(sigma, i, w_req(J), mu, kin) for i in range(len(sigma)-1)]
    if rc < rho_min or max(Vs) > theta_V:
        return Reject('contact_fragile', rc, Vs)
    mp = bridge(sigma, g, d_V)
    if mp is None:
        return Reject('bridge_fail')
    if norm(w_req(J, target=True) - Adjoint(g) @ w_req(J)) > d_w:
        return Reject('wrench_mismatch')
    return Accept(CSTC(sigma, W, rc, Vs, mp, J))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CPF | O(|Σ_seg|·|B|·|E|) | O(|Σ|) | 接触分段完备、模式可辨识 |
| CSG | O(|P|·|σ|³) | O(|N|·|σ|²) | 产生式 guard 保守 sound |
| CWE | O(|σ|·|contacts|·|FC|) | O(V_H) | 摩擦锥内近似、单侧约束 |
| CTV | O((|Δ_τ|/dt)·|contacts|) | O(|Δ_τ|) | 切换窗口充分采样 |
| CMB | O(|σ|·|c| + |τ|) | O(|σ|) | 角色保持、模式保持 |
| CSTC | O(CWE+CTV+CMB) | O(V_H+|σ|) | 预算闭合、旋量变换有界 |

**正确性定理（Contact-Schedule Transfer Soundness）**
第 54 轮 (A26)–(A28) 与 `J` sound 成立；新增 **(A29)** 接触分段完备、接触模式辨识误判率 ≤ ε_m；**(A30)** 摩擦锥保守内近似，单侧约束与冲击区间化；**(A31)** `μ` 保持自由体对偶与接触模式且伴随误差有界；**(A32)** 切换窗口采样充分，`V` 估计误差 ≤ ε_V。则
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - P(δ_a>Θ_a) - P(ρ_c<ρ_c^min) - P(max V>Θ_V)
              - P(μ 不存在) - P(||w_req 变换误差||>δ_w) - ε_m - ε_V
```
关键：**接触可行先于动作可行，切换脆弱性先于轨迹相似性，自由体对偶是迁移的语义前提**。

## 5. 本轮最大风险

**一句话**：接触调度迁移把「手抓取」与「足步态」统一为「自由体 + 可切换接触 + 力旋量包络」，但其 soundness 依赖**接触模式辨识的完备性、摩擦锥保守近似的松紧、以及自由体对偶在动态场景下不失效**；一旦接触态错分或快速冲击落在采样窗口之间，CWE 会给出虚假的可行裕度、CTV 会低估切换脆弱性，μ 便会把「轨迹相似但力不可行」的抓取/步态调度当成可迁移，造成系统性负迁移，故必须以**多模态接触辨识 + 对抗性切换采样 + 自由体对偶可证伪**三重护栏，把「接触同构」当作待证伪假设，而非迁移许可证。
