### 第 6 轮灵感驱动研究记录

**灵感词**：状态估计、情感语音

**继承关系**：第 5 轮 CADVS-v5（IP-493~496）把提议从离散规则升级为条件流匹配（定理 6 证书不变性/提议无关性），把记忆升级为检索增强 + 铸证固化（定理 7），把人因从「意图 veto」升级为面部情感的非对称阈值调制（定理 5，γ≥1 只紧不松），执行集 Exec_CADVS-v5 ⊆ Exec_CADVS-v4 ⊆ … ⊆ Exec_v29。但 v5 有一个被它自己的「诚实声明」点破、却始终未解决的结构性盲点：**七门与证书全部建立在「状态已知」的点估计之上**——几何、接触拓扑、wrench、人类情感都被当作精确量；FER 的不确定度 σ_emo 只被用来「不确定就不调制」（σ_emo > σ_max ⇒ γ=1），而这在人因安全通道上恰恰是 **fail-open**：越看不清越不收紧。本轮两个灵感词在此汇合：**状态估计**给出「把门建在信念集而非点估计上」的一般理论，**情感语音**给出面部之外的第二个人因观测模态，并顺手修掉上面的 fail-open。统一主题为「认证的状态估计执行」（Certified Estimation-Aware Execution, CEAE），形成 CADVS-v6（IP-497~500）。自律延续：**硬门仍为七**，新增的只有一条横切的「认知松弛」通道 δ_i^SE ≥ 0（与 v5 的 γ_i ≥ 1 同构：非负、只紧不松），执行集升级为 Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ … ⊆ Exec_v29。

**直觉与动机**：

1. **状态估计 → 把每个门从「点估计谓词」升级为「信念集上的鲁棒谓词」，且不确定度只能收紧**。直觉：证书说「ZMP 落在支撑多边形内」，如果机器人对自己质心/接触位置的估计有 ±2 cm 误差，那这张证书在真实世界可能根本是假的——v5 的「已铸证」严格说只是「在估计值上铸证」。严谨化：估计器给出信念集 B_δ（集合式椭球或 conformal 预测集，覆盖真实状态的概率 ≥ 1−δ）；门 i 有带符号边际 s_i(x,s)（越大越安全）；鲁棒门要求 inf_{s∈B_δ} s_i(x,s) ≥ τ_i。若 s_i 对 s 是 L_i-Lipschitz、B_δ 半径为 r_δ，则 inf ≥ s_i(x,ŝ) − L_i r_δ，于是等价于把阈值抬高一个**认知松弛** δ_i^SE = L_i r_δ ≥ 0：τ_i^6 = γ_i·τ_i^4 + δ_i^SE。关键结构：δ_i^SE 与 v5 的 γ_i 同构——非负、只紧不松、r_δ=0 时精确退化为 v5。**定理 9（估计单调性）**：信念集越大 ⇒ 执行集越小；Exec_v6(B_δ) ⊆ Exec_v6(B_δ') ⊆ Exec_v5（当 B_δ ⊇ B_δ'）。这把 v5 的「证书不变性（对提议）」补成「证书鲁棒性（对状态估计）」——v5 说换提议不改边界，v6 说估计有误差边界只会更保守。

2. **情感语音 → 人因锚从「单模态点估计」升级为「多模态滤波信念 + 最坏情况融合」，并修掉 v5 的 fail-open**。直觉：口罩/逆光/背对时面部看不到，但声音里的颤抖、音高/能量突变、急促语速、以及「停/疼/别」这类词仍能透露痛苦；反过来，单看脸也常被「强忍」骗过。严谨化：引入 AVMK（视听多模态）与 AEIF（情感状态滤波，HMM/EKF 维护 h_t=(v,a,p_d) 的后验）。**红线修复**：不再用 σ_emo > σ_max ⇒ γ=1（这是 fail-open），而是一律取痛苦概率的**上可信界** p_d^+ = Quantile_{1−α}(p_d | o_{1:t})，多模态用**最坏情况 OR 融合** p_d^+ = max_m p_d^{+,m}（或 noisy-OR）。缺失/遮挡/低置信 ⇒ 后验变宽 ⇒ p_d^+ 变大 ⇒ **更收紧**而非放松。**定理 10（最坏情况融合单调性）**：p_d^+ ≥ 任一单模态上界，且 ≥ 任何凸平均融合；增加一个「痛苦」模态只能增大 p_d^+，模态冲突永不降低收紧。这把 v5 用于新颖度的 OR 合成推广到人因融合。

3. **两者合流 → 一条「信念层」横切七门，而不是第八个门**。SEBK 不是新锚，它是给每个门声明「我依赖哪些估计量、各自误差界与 Lipschitz 常数」的元数据层；AEIF/AVMK 是 HICK 人因锚内部的观测升级。**定理 12**：七锚完备性保持、执行集嵌套保持。工程上，1 kHz 环只用标量松弛 δ_i^SE（O(1)，保守但便宜），10 Hz 准入才用精确椭球支撑函数求 inf（O(dim²)）以求紧——与 v5 的「控制环只消费预计算阈值与缓存证书」一脉相承。

**关键洞见**：v4 回答「提议=规则时七门够不够」；v5 回答「提议=任意生成器时边界是否不变」；v6 回答「**当连状态都只能估计时，证书还剩下什么保证**」。答案：证书的保证从「在真实状态上成立」退化为「在信念集覆盖真实状态的前提下、以 ≥1−δ 的概率成立」，且这个退化是**单向的**——不确定度只让执行集更小。七硬门 kc_evidence_forged_v4 与 v5 的 γ 调制原样复用；本轮新增的只有：信念层 SEBK、视听情感 AVMK、情感滤波 AEIF、认知松弛 δ_i^SE，以及软评分 ECS_v6 = ECS_v5 · η_est。

**形式化目标（增量）**：
1. 信念集：B_δ(s) = {s' : ‖s'−ŝ‖_M ≤ r_δ}（集合式）或 conformal 预测集 C_δ(o)，覆盖 P(s∈B_δ) ≥ 1−δ。
2. 鲁棒门：kc_i^rob = 1[inf_{s∈B_δ} s_i(x,s) ≥ τ_i^5]；等价的保守快路径 1[s_i(x,ŝ) ≥ τ_i^6]，τ_i^6 = γ_i·τ_i^4 + δ_i^SE，δ_i^SE = L_i r_δ。
3. 情感滤波：h_t=(v,a,p_d)，h_{t+1}=f(h_t)+w；后验 p(h_t|o_{1:t})；p_d^+ = Q_{1−α}；AVMK 观测 o=(face, prosody, keyword)。
4. 最坏情况融合：p_d^+ = max_m UB_m；γ_i = 1 + κ_i·p_d^+（替换 v5 的 p_distress 点估计）。
5. 定理 9（估计单调性）、定理 10（最坏情况融合）、定理 11（估计误差→证书失效率界）、定理 12（七锚完备性保持）。
6. Exec_CADVS-v6 = {x : ∧_i kc_i^rob(x,B_δ)=1} ⊆ Exec_CADVS-v5 ⊆ Exec_CADVS-v4。

**本轮最大风险**：**信念集失配的静默相关失效**——v6 的全部保证都以「真实状态 ∈ B_δ」为前提；一旦估计器的误差模型本身是错的（非平稳接触、传感器欺骗、情感动态漂移），证书就在一个不含真实世界的集合上「形式正确」地铸出，且因为七个门共享同一信念层，单点估计失效会同时污染全部七门（相关失效）；这是 v5 没有的新单点故障，且无法从控制环内部自检发现。

## 2. 关键算法骨架

### IP-497 SEBK：状态估计信念核（1 kHz 用标量松弛；10 Hz 准入用精确支撑函数）

```python
@dataclass
class StateEstimationBeliefKernel:
    """SEBK：把七门建在信念集 B_δ 上。
    定理 9：不确定度只收紧（δ_i^SE ≥ 0）；r_δ=0 时精确退化 v5"""
    gate_deps: dict          # gate_id -> GateDep(dims, L_i, tau_i5)
    r_delta: float           # 集合式信念半径（或 conformal 集半径）
    exact_at_admission: bool = True

    def robust_margin(self, gate_id, x, s_hat) -> float:
        dep = self.gate_deps[gate_id]
        if self.exact_at_admission:
            # 椭球支撑函数：inf_{||s-s_hat||_M<=r} s_i(x,s)
            return support_inf(dep.s_i, x, s_hat, self.r_delta)   # O(dim^2)
        # 保守快路径（1 kHz）：inf >= s_i(s_hat) - L_i*r
        return dep.s_i(x, s_hat) - dep.L_i * self.r_delta          # O(1)

    def epistemic_slack(self, gate_id) -> float:
        dep = self.gate_deps[gate_id]
        return dep.L_i * self.r_delta                              # δ_i^SE >= 0

    def tau_v6(self, gate_id, gamma_i: float, tau4: float) -> float:
        return gamma_i * tau4 + self.epistemic_slack(gate_id)       # τ^6 = γτ^4 + δ^SE

    def kc_robust(self, gate_id, x, s_hat, gamma_i, tau4) -> bool:
        # 精确式与保守快路径给出相同通过集（L_i 紧时）；快路径更保守
        if self.exact_at_admission:
            return self.robust_margin(gate_id, x, s_hat) >= gamma_i * tau4
        return self.gate_deps[gate_id].s_i(x, s_hat) >= self.tau_v6(gate_id, gamma_i, tau4)
```

### IP-498 AVMK：视听多模态人因核（端侧，10–30 Hz，与控制环解耦）

```python
@dataclass
class AudioVisualMultimodalHumanKernel:
    """AVMK：面部 + 情感语音 + 端侧关键词，输出各模态痛苦上界。
    定理 10：最坏情况融合；冲突/缺失只会更收紧（修复 v5 fail-open）"""
    fer: Any            # v5 FAMK 的 face 分支
    speech: Any         # 端侧韵律模型：F0/能量/jitter/shimmer/语速/停顿
    kws: Any            # 端侧关键词 spotting（"停/疼/别/help"），音频不出端
    alpha: float = 0.1  # 上可信界分位数（1-alpha）

    def observe(self, face, audio, t) -> list[ModalityBound]:
        bounds = []
        if face is not None:
            v, a, p_d, sig = calibrated_fer(self.fer, face)
            bounds.append(ModalityBound('face', ub=clip(p_d + z(1-self.alpha)*sig)))
        if audio is not None:
            pros = self.speech.prosody(audio)          # 韵律特征
            v, a, p_d, sig = self.speech.affect(pros)   # 情感语音识别（温度校准）
            kw = self.kws.distress_score(audio)         # [0,1]，端侧
            bounds.append(ModalityBound('voice', ub=max(clip(p_d + z(1-self.alpha)*sig), kw)))
        return bounds   # 缺失模态不补 0，直接缺席（交给 AEIF 预测扩散）

    def fuse(self, bounds) -> float | None:
        if not bounds:
            return None                    # 无观测：由 AEIF 先验上界接管
        return max(b.ub for b in bounds)   # OR / max 融合：冲突取大者
    # 隐私：原始音频/人脸永不出端；语音含身份与内容，端侧即用即弃；
    # 任何上报统计过 DP；提供显式同意与关闭开关（关闭 = 精确退化 v5）
```

### IP-499 AEIF：情感状态估计滤波（O(|H|²) HMM 或 O(dim²) EKF，离线于 1 kHz 环）

```python
@dataclass
class AffectStateEstimationFilter:
    """AEIF：h_t=(v,a,p_d) 动态滤波，提供后验上界。
    引理 47：缺失观测仅预测，P 在 Loewner 序下不减 ⇒ p_d^+ 单调增 ⇒ 更收紧"""
    A: np.ndarray; Q: np.ndarray
    H: np.ndarray; R: np.ndarray
    state: np.ndarray; P: np.ndarray
    alpha: float = 0.1
    t_last: float = 0.0

    def predict(self):
        self.state = self.A @ self.state
        self.P = self.A @ self.P @ self.A.T + self.Q     # 方差增长

    def update(self, bounds: list[ModalityBound]):
        # 只做一次贝叶斯更新；缺失模态跳过，绝不伪造成 0（0 会虚假降低痛苦）
        obs = [b.ub for b in bounds]
        if not obs:
            return                                       # 仅预测
        y = np.array([max(obs)])                         # 融合观测（保守）
        S = self.H @ self.P @ self.H.T + self.R
        K = self.P @ self.H.T @ np.linalg.inv(S)
        self.state = self.state + K @ (y - self.H @ self.state)
        self.P = (np.eye(len(self.state)) - K @ self.H) @ self.P

    def distress_upper(self) -> float:
        mu = self.state[2]; sd = float(np.sqrt(max(self.P[2, 2], 1e-12)))
        return float(np.clip(mu + z(1 - self.alpha) * sd, 0.0, 1.0))

    def step(self, bounds, t):
        dt = max(t - self.t_last, 0.0)
        self.predict(); self.update(bounds); self.t_last = t
        return self.distress_upper()
```

### IP-491 扩展 CERTCALC-v6：新增定理 9~12 与引理 45~47（离线理论）

# 定理 10：最坏情况多模态融合

    """
    return "Proven"

# 定理 11：估计误差 → 证书失效率界
def theorem_estimation_failure_bound() -> str:
    """
    定理 11：若 B_δ 满足 P(s∈B_δ) >= 1-δ（集合式=确定界；conformal=边际覆盖），

    """EFA-v6：七门不变；阈值 τ^6=γ·τ^4+δ^SE；门在 B_δ 上鲁棒求值"""

        p_d_plus = self.aeif.step(bounds, t_now)              # ∈ [0,1]，单调只增

        # 2) 机器人状态信念：r_delta 来自 SEBK（由估计器协方差/conformal 集给出）

        cands = self.v5.fmpp.propose(build_ctx(context, p_d_plus, self.v5.lmem), self.v5.fmpp.K)
        surv = [x for x in cands if self._cheap_robust_gates(x, context, gamma, r_delta)]
        if not surv:
            return self._fallback_rule_proposal(gamma)         # fail-closed 回退 v5 规则提议
        surv.sort(key=lambda x: self._prefilter_score(x), reverse=True)
        finals = [x for x in surv[:3] if self._vack_robust(x, context, gamma, r_delta)]
        ok = [x for x in finals if self._bck_robust_preview(x, context, gamma, r_delta)]
        if not ok:
            return False, None, 'ALL_CANDIDATES_REJECTED'
        best = max(ok, key=certified_margin)
        return True, best, 'FORGED_CEAE'

    def _cheap_robust_gates(self, x, ctx, gamma, r_delta) -> bool:
        for gid in ('coverage', 'physics', 'memory', 'novelty'):
            tau5 = gamma.get(gid, 1.0) * TAU4[gid]
            if not self.sebk.kc_robust(gid, x, ctx.s_hat, gamma.get(gid, 1.0), TAU4[gid]):
                return False
        return True

    def ecs_v6(self, base_ecs5: float, r_delta: float, p_d_plus: float) -> float:
        delta_bar = r_delta / (r_delta + r_ref)                # 归一化总松弛
        eta_est = sigmoid(b_est - delta_bar)                    # 认知置信 ∈ [0,1]

## 4. 正确性论证（增量更新）

### 引理 45（Lipschitz 边际下界）

**陈述**：若 |s_i(x,s) − s_i(x,s')| ≤ L_i‖s−s'‖ 且 B_δ 满足 sup_{s∈B_δ}‖s−ŝ‖ ≤ r_δ，则 inf_{s∈B_δ} s_i(x,s) ≥ s_i(x,ŝ) − L_i r_δ。

**证明**：对任意 s∈B_δ，s_i(x,s) ≥ s_i(x,ŝ) − L_i‖s−ŝ‖ ≥ s_i(x,ŝ) − L_i r_δ，对 s 取下确界即得。∎

**推论**：鲁棒门 1[inf ≥ τ^5] 被保守快路径 1[s_i(ŝ) ≥ τ^5 + L_i r_δ] = 1[s_i(ŝ) ≥ τ^6] 所蕴含；L_i 紧时两者等价。

### 引理 46（conformal 鲁棒门失效率界）

**陈述**：若 C_δ 为状态 s 的 conformal 预测集，满足可交换性下 P(s∈C_δ) ≥ 1−δ，则对任意门 i，P(kc_i^rob=1 ∧ kc_i(x;s)=0) ≤ δ。

**证明**：若 s∈C_δ 且 ∀s'∈C_δ kc_i(x;s')=1，则 kc_i(x;s)=1；故事件 {鲁棒通过 ∧ 真值违规} ⊆ {s∉C_δ}，概率 ≤ δ。∎

**诚实边界**：conformal 是边际覆盖、非条件覆盖；分布漂移破坏可交换性。集合式 B_δ 则依赖误差界真实成立。两者都只是「条件保证」，不消除模型失配。

### 引理 47（缺失观测下情感上界单调）

**陈述**：AEIF 在无观测时仅执行预测步，P ← A P Aᵀ + Q ⪰ P（Loewner 序），故 p_d^+ = μ_d + z_{1−α}√P_{dd} 单调不减；从而 γ_i 单调不减、执行集单调不增。

**证明**：Q ⪰ 0 ⇒ A P Aᵀ + Q ⪰ A P Aᵀ；结合 P ⪰ 0 得方差项不减；上界关于方差单调增。∎

**意义**：这正是对 v5 fail-open 的结构性修复——v5 在 σ_emo 大时令 γ=1（放松），v6 在观测缺失/不确定时让 p_d^+ 增大（收紧），方向与安全一致。

### 定理 v6（信念鲁棒收缩与估计可靠性，总装）

**陈述**：在 v5 假设 (B1)~(B6)、v5 定理 5~8 及新增 (B8)「B_δ 覆盖真实状态（集合式确定界或 conformal 覆盖 ≥1−δ）」下：
(i) Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ … ⊆ Exec_v29；
(ii) 估计单调性：B_δ 越大执行集越小；r_δ=0 时 Exec_v6=Exec_v5（定理 9）；
(iii) 人因只紧：p_d^+ ≥ p_d，最坏情况融合 ≥ 平均融合，缺失/冲突只增不减压（定理 10、引理 47）；
(iv) 证书可靠性：真值违反 v5 标称门的概率 ≤ δ（定理 11、引理 46）；
(v) 七锚完备性保持（定理 12）；
(vi) 失败模式：若 (B8) 失效（模型失配/漂移/欺骗），保证退化为名义，且七门相关失效。

**证明**：(i) τ^6 ≥ τ^5 且 inf ≤ 点边际 ⇒ 各门通过集缩 ⇒ 交集缩。(ii) 引理 45 + 阈值单调。(iii) 定理 10 + 引理 47。(iv) 引理 46。(v) 定理 12。(vi) 引理 46 的条件性 + 共享信念层。∎

**诚实声明**：(B8) 是全框架新的「命门」——所有可靠性都条件于信念集覆盖真值；协方差/误差界标定、conformal 可交换性、情感语音跨语言/文化校准都只能在受控条件下近似成立。Lipschitz 常数低估会静默破坏保守性。语音含身份与内容，隐私风险高于 v5 的人脸。

## 7. 本轮最大风险（最终确认）

**一句话**：**信念集失配的静默相关失效**——v6 的全部保证都以「真实状态 ∈ B_δ」为前提；一旦估计器的误差模型本身是错的（非平稳接触、传感器欺骗、情感动态漂移），证书就在一个不含真实世界的集合上「形式正确」地铸出，且因为七个门共享同一信念层，单点估计失效会同时污染全部七门（相关失效）；这是 v5 没有的新单点故障，且无法从控制环内部自检发现。
