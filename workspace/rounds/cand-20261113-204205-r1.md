## 0. 直觉与动机

**灵感 1（末端位姿 → 标量安全的天花板）**
直觉：接触场景里「停住」往往比「退开 / 柔顺」更危险——僵硬的急停会把动能变成冲击力。R68 的 λ 只能把所有动作等比缩小，却没有「方向」这一维。安全交互的正确状态变量是**相对位姿 X = T_h⁻¹T_ee 及其相对速度**，因为碰撞只取决于相对几何，不取决于世界系怎么选。
严谨：安全集 𝒮 = {X : d(X, ℋ) ≥ r_contact} 定义在 SE(3) 上；用控制障碍函数（CBF）保证 𝒮 的前向不变，而不是用标量 λ 事后缩放。

**灵感 2（末端位姿 → 不确定性的公共货币）**
直觉：感知误差、标定漂移、世界模型偏差、人类意图不确定性，虽然出生在不同坐标系，但最终都要在同一个问题上兑现——**末端会到哪、人会在哪**。与其在各模块里各说各话，不如全部前推到「末端位姿 tube」与「人类可达 tube」这两个几何对象上。
严谨：用 SE(3) 右不变误差 ξ ~ 𝒩(0, Σ_ξ)，经杠杆臂雅可比 J(p) = [R̂, −R̂[p]_×] 传播到位置协方差 Σ_x(p) = JΣ_ξJᵀ；管道半径沿分离方向 n 由椭球支持函数 r(n) = k_σ√(nᵀΣ_x n) 给出。

**灵感 3（安全交互 → 刚性共模偏差会自动抵消，真正的杀手是非刚性共模）**
直觉（反直觉但重要）：外参平移/旋转若**同时**作用于机器人和人，相对位姿 X = T_h⁻¹T_ee 完全不变——所以 R68 花大力气估的 δp_ext、δR_ext，对「相对安全」其实**无关**。真正致命的是不满足刚性规范变换的误差：**深度尺度偏差**（距离被整体缩放）与**差分时延**（人和机器人在不同时刻被采样），它们在相对位姿里无法抵消。
严谨：X 对左乘任意刚性 G 不变（规范不变性）；但深度尺度 s 使 d̂ = (1+s)d，差分时延 τ_d 使相对位移偏 ‖v_rel‖τ_d。二者构成非刚性共模偏差 b_nr，必须由独立锚与预算单独约束。

**灵感 4（安全交互 → 双管分离是统一判据）**
直觉：机器人有自己的位姿 tube（来自自标定、本体、控制），人也有可达 tube（来自运动预测、意图、情绪）。**安全交互 = 两条 tube 不相交**。R66 的情绪不再只是一个风险标量，而是用来调节人的 tube 半径与接近速度：越激动/越不可预测 → 保护包络越大、允许接近速度越低。
严谨：交互安全裕度 M_t = d(𝓟_t, 𝓗_t) − r_contact；认证前缀 k_pose 需对所有 j ≤ k_pose 满足 h_{t+j} ≥ (1−α)^j h_t ∧ h_{t+j} ≥ 0。

**灵感 5（末端位姿 × 安全交互 → 安全动作格 + 度量锚）**
直觉：既然安全是几何问题，安全动作也应当是几何的：**收缩**（沿用旧 λ）、**柔顺**（沿接触法向降刚度）、**后退**（沿 h 的负梯度）、**让行**（对人施加的力做有界导纳）。同时，几何证书以「米」为单位，纯自洽的标定可以整体偏掉——必须引入不依赖学习的**度量锚**（重力定滚转/俯仰、已知夹具定位移、触觉定局部几何），并把共模偏差预算写进证书。
严谨：𝒜_safe 四动作在连续性与可行性约束下择优；MAP 锚健康度 a 与锚协方差 Σ_anchor 进入 PIC；证书仅在 M ≥ b_nr + ‖b_anchor‖ 时有效。

## 1. 形式化定义（增量：定义 293–310）

**定义 293（EPIC-RAS 总览）** EPIC-RAS = (RPM, PUT, ISC, CAS, HIM, MAP, PIC, CALM-RAS†)。三不变式升级：
(i) **规范不变安全**：证书只依赖相对位姿 X = T_h⁻¹T_ee，对共同世界系的任意刚性左乘 G 不变；
(ii) **最坏情况前向不变**：认证前缀内对两条 tube 的任意实现，安全裕度非负；
(iii) **安全动作连续性**：任何模式切换（nominal→comply→retreat）都需阻抗/速度连续，防止切换本身诱发冲击。

**定义 294（相对位姿交互状态）** s_t = (X_t, Ẋ_t) ∈ SE(3) × se(3)，X_t = T_h(t)⁻¹T_ee(t)。人的保护体用胶囊/凸体 ℋ_t 近似。安全集 𝒮 = {X : d(X, ℋ) ≥ r_contact}，d 为最小点距。位置部分 x = trans(X)。

**定义 295（右不变位姿误差）** 真实位姿 T = T̂ exp(ξ^)，ξ = (ρ, φ) ∈ ℝ⁶ ~ 𝒩(0, Σ_ξ)。对末端点 p，一阶位置误差 δx = J(p)ξ，J(p) = [R̂, −R̂[p]_×] ∈ ℝ^{3×6}，Σ_x(p) = J(p)Σ_ξJ(p)ᵀ。相对位姿协方差由伴随传播：Σ_X ≈ Ad_{T_h⁻¹}Σ_ee Ad_{T_h⁻¹}ᵀ + Σ_h。

**定义 296（对偶不确定性管道 PUT/HUT）** 机器人管道 𝓟_t = {T : ‖log(T̂⁻¹T)‖_{Σ_ξ} ≤ k_σ} ⊕ ℬ_r；人类可达管道 𝓗_t = ℋ_t ⊕ (v_h Δ ⊕ Ell(Σ_h))。二者均为同一度量下的凸体。沿单位分离方向 n 的投影半径：r_r(n) = k_σ√(nᵀΣ_x n) + b_r，r_h(n) = k_σ√(nᵀΣ_h n) + b_h，其中 b_· 收纳非高斯/非刚性预算。

**定义 297（交互安全裕度与证书 ISC）** 保守下界 M_t = d(T̂_ee, ℋ_t) − r_r(n_t) − r_h(n_t) − r_contact。证书 ISC_t = (M_t, k_pose, r_r, r_h, a_anchor, b_nr, mode)。**有效 ⇔ M_t ≥ b_nr + ‖b_anchor‖ ∧ a_anchor > a_min**。

**定义 298（鲁棒离散 CBF 与前缀认证）** h_t = M_t。对动作前缀 A = (a_t, …, a_{t+k−1})，用 WM  rollout + 管道传播得 h_{t+j}。k_pose = max k 使 ∀j ≤ k：h_{t+j} ≥ (1−α)^j h_t 且 h_{t+j} ≥ 0；若无 k ≥ 1 满足，则 k_pose = 0 并交给 CAS（而不是直接急停）。

**定义 299（杠杆臂各向异性裕度）** 朝向不确定 σ_φ 在力臂 L 处放大为位置不确定 L·σ_φ，故必须用方向性半径 r(n) 而非各向同性半径。系：接触前 L 越大、姿态误差越主导；近接触区应额外压低朝向误差或提高位姿更新率。

**定义 300（人类交互模型 HIM）** 人的保护胶囊 ℋ_t、速度 v_h、可达集不确定 Σ_h；预测时域内 𝓗_t = ℋ_t ⊕ (v_hΔ) ⊕ Ell(Σ_h)。提供 d(·, ℋ_t) 与分离方向 n_t。

**定义 301（情绪条件化包络）** r_ps(E) = r_ps⁰(1 + κ_E·risk_emo(E))，v_max(E) = v_max⁰(1 − κ_v·risk_emo(E))，人类管道膨胀 β(E) = β⁰(1 + κ_β·risk_emo(E))。情绪只改「人的包络与可预测性」，不直接改 λ；由双管几何统一吸收。

**定义 302（安全动作格 CAS）** 𝒜_safe = {a_shrink, a_comply, a_retreat, a_yield}：
- a_shrink：v ← λv（继承 R66–R68 的标量收缩）；
- a_comply：K_x ← K_x ⊙ (I − β_n n nᵀ)，D_x 同步调为临界阻尼，沿分离法向降刚度；
- a_retreat：v_cmd = −v_r·∇_x h（沿裕度增长方向后退，而非任意方向急停）；
- a_yield：沿人施加力 f 做有界导纳，|f| ≤ f_max，功率流 ≤ P_max。
选择规则：优先保持 k_pose > 0；否则选使 h_{t+1} 最大且满足连续性（阻抗/速度插值 T_blend）的动作。

**定义 303（度量锚 MAP）** 锚观测 = {重力方向 g（绝对滚转/俯仰 2 DOF）、已知夹具/接触（绝对平移）、触觉局部曲面}。输出 T_anchor、Σ_anchor、健康度 a ∈ [0,1]。锚不经过学习主干，用于打破「自洽但整体偏移」的循环依赖。

**定义 304（共模偏差预算与规范破缺）** 刚性共模 G 在 X 中精确抵消；非刚性共模只余两项：尺度 s 与差分时延 τ_d，b_nr = |s|·d_ref + ‖v_rel‖·τ_d。证书有效性要求 M_t ≥ b_nr + ‖b_anchor‖，并在线监测 b_nr 的上界。

**定义 305（位姿完整性证书 PIC）** PIC = (J_CALM, hash(T̂_ee), Σ_ξ, r_r, r_h, M_t, k_pose, a_anchor, b_nr, cas_mode, epic_ver)。Valid ⇔ Valid(J_CALM) ∧ a_anchor > a_min ∧ b_nr < b_max ∧ M_t ≥ 0。

**定义 306（与 CALM-RAS 的继承关系）** CALM-RAS† 全部保留；λ_floor（定义 285）降级为兜底下限，主安全门变为 ISC。控制指令 τ_cmd = CAS(A[:k_pose], lam_calm) 且幅值不超过 λ_calm·λ_nominal；CAS 只能降低权限或增加柔顺，不能放大动作。

**定义 307（双管分离的保守判据）** 对凸管，用 GJK/支持函数计算 d(𝓟, 𝓗)；证书采用保守下界 d ≥ d(T̂_ee, ℋ) − r_r(n) − r_h(n)。当且仅当下界 ≥ r_contact 时判为安全；下界是充分条件，故不产生假安全。

**定义 308（接触相状态机）** 相位 ∈ {FREE, PRE_CONTACT, CONTACT, RETREAT}。FREE/PRE_CONTACT 用位置 CBF；CONTACT 用法向力/功率 CBF：|f_n| ≤ f_max 且 f·v ≤ P_max；RETREAT 用速度 CBF。保证「安全交互」不仅是「避免接触」，也包括「接触时可控」。

**定义 309（干扰集 ℰ_EPIC）** ℰ_EPIC = ℰ_CALM × ℰ_pose × ℰ_inter × ℰ_anchor；ℰ_pose = {杠杆臂放大、深度尺度偏差、差分时延}；ℰ_inter = {对抗性快速接近、柔顺被利用、CBF 不可行}；ℰ_anchor = {锚失效、锚欺骗、重力漂移}。

**定义 310（管线）** 在线：估计 (T_ee, T_h) → MAP 锚校正 → 双管传播 → ISC/鲁棒 CBF 认证 k_pose → CAS 选动作 → 下发阻抗/速度 → 写 PIC 并异步审计。离线：训练 HIM、标定锚、用回放验证 tube 覆盖率与保守性。

# IP-253 RPM：相对位姿交互状态（规范不变）
def relative_state(T_ee, T_h, v_ee, v_h):
    X = inv(T_h) @ T_ee                 # 世界系刚性左乘 G 自动抵消
    Xdot = inv(T_h) @ (v_ee - v_h)      # 相对 twist（近似）
    return X, Xdot


# IP-254 PUT：SE(3) 右不变协方差传播 + 杠杆臂
class PoseUncertaintyTube:
    def __init__(self, k_sigma=2.0):
        self.k_sigma = k_sigma

    def pos_cov(self, Sigma_xi, R_hat, p):
        J = np.hstack([R_hat, -R_hat @ skew(p)])   # δx = J ξ
        return J @ Sigma_xi @ J.T

    def radius_along(self, Sigma_x, n, bias=0.0):
        return self.k_sigma * np.sqrt(max(n @ Sigma_x @ n, 0.0)) + bias

    def propagate(self, T_hat, Sigma_xi, p, k):
        # 沿 WM 前缀传播；返回每个 j 的 (center, Sigma_x)
        out = []
        for j in range(k):
            out.append((T_hat, self.pos_cov(Sigma_xi, T_hat.R, p)))
        return out


# IP-255 ISC：双管分离 + 鲁棒离散 CBF
class InteractionSafetyCertificate:
    def __init__(self, alpha=0.3, r_contact=0.05):
        self.alpha, self.r_contact = alpha, r_contact

    def margin(self, T_ee_hat, human_tube, robot_tube, Sigma_x, Sigma_h, b_nr, b_anchor):
        d_hat, n = human_tube.distance_and_normal(T_ee_hat)
        r_r = robot_tube.radius_along(Sigma_x, n, b_nr)
        r_h = human_tube.radius_along(Sigma_h, n, b_anchor)
        return d_hat - r_r - r_h - self.r_contact, n

    def certified_prefix(self, preds, h0, robot_tube, human_tube, Sigma_h, b_nr, b_anchor):
        if h0 < b_nr + b_anchor:
            return 0
        k = 0
        for j, (T_j, Sigma_j) in enumerate(preds, start=1):
            h_j, _ = self.margin(T_j, human_tube, robot_tube, Sigma_j, Sigma_h, b_nr, b_anchor)
            if h_j < (1 - self.alpha) ** j * h0 or h_j < 0:
                break
            k = j
        return k


# IP-256 CAS：安全动作格（几何动作，而非单标量）
def select_safe_action(mode, h, n, grad_h, v_rel, f_contact, K_x, D_x):
    if h >= h_nominal:
        return {'mode': 'NOMINAL', 'v': v_rel, 'K_x': K_x, 'D_x': D_x}
    if h < 0.0:                                   # 已越界：沿裕度增长方向后退
        return {'mode': 'RETREAT', 'v': -v_r * grad_h, 'K_x': K_soft, 'D_x': D_crit}
    if h < h_comply:                              # 薄裕度：法向柔顺，阻尼临界
        return {'mode': 'COMPLY',
                'v': v_rel,
                'K_x': K_x @ (np.eye(3) - beta_n * np.outer(n, n)),
                'D_x': critical_damping(K_x)}
    if np.linalg.norm(f_contact) > 0:             # 接触中被推：有界导纳
        return {'mode': 'YIELD', 'v': clamp_admittance(f_contact, f_max, P_max),
                'K_x': K_soft, 'D_x': D_crit}
    return {'mode': 'SHRINK', 'v': lam * v_rel, 'K_x': K_x, 'D_x': D_x}


# IP-258 MAP：非学习度量锚（重力/夹具/触觉）
class MetricAnchor:
    def update(self, g_imu, fixture_obs, tactile_obs):
        T_g, S_g = gravity_align(g_imu)            # 绝对 roll/pitch
        T_f, S_f = fixture_localize(fixture_obs)   # 绝对平移（若可见）
        T_t, S_t = tactile_register(tactile_obs)   # 局部曲面
        T_a, S_a = fuse_anchor([(T_g, S_g), (T_f, S_f), (T_t, S_t)])
        health = anchor_health(S_a, observability=[T_g is not None, T_f is not None])
        return T_a, S_a, health


# IP-262 主闭环：EPIC-RAS round
def EPIC_RAS_round(M, obs):
    x_prime = M.lsf.fuse(M.usr.fuse(*obs[:4]))
    z, o = M.mtm.forward(obs_pack, M.a_prev, M.scene_ctx)        # 继承 R68

    # 1) 位姿估计 + 度量锚（打破自洽循环）
    T_ee, Sigma_ee = M.pose.estimate(z, M.proprio)
    T_h,  Sigma_h  = M.him.estimate(o, emotion=o['pi'])
    T_a, S_a, a = M.anchor.update(M.imu, M.fixture, M.tactile)
    T_ee, Sigma_ee = M.anchor.correct(T_ee, Sigma_ee, T_a, S_a)

    # 2) 相对状态 + 双管（规范不变）
    X, Xdot = relative_state(T_ee, T_h, M.v_ee, M.v_h)
    b_nr = M.budget.scale_latency(M.depth_scale_hat, M.dt_sync, Xdot)
    r_r = M.put.radius_along(M.put.pos_cov(Sigma_ee, T_ee.R, M.p_tool), n=M.n_prev, bias=b_nr)
    r_h = M.him.tube_radius(T_h, Sigma_h, emotion=o['pi'])

    # 3) ISC + 鲁棒 CBF 认证前缀
    A = M.ach.propose_actions(x_prime, steps=5)
    preds = M.mtm.rollout_pose(z, A, k=5)
    h0, n = M.isc.margin(T_ee, M.him.tube(T_h, Sigma_h), M.put, Sigma_ee, Sigma_h, b_nr, S_a)
    k_pose = M.isc.certified_prefix(preds, h0, M.put, M.him.tube(T_h, Sigma_h), Sigma_h, b_nr, S_a)

    # 4) CAS：k_pose=0 时用几何安全动作兜底（非急停）
    mode = 'NOMINAL' if k_pose > 0 else 'SAFE_ACTION'
    act = select_safe_action(mode, h0, n, M.isc.grad_h(T_ee, T_h), M.v_rel, M.f_contact, M.K_x, M.D_x)

    # 5) 标定兜底（R68 λ_floor 保留，但只作为下界）
    lam = max(M.efs.risk_scale(o, M.cfa), M.cof.lam_floor(M.U))
    tau = M.pi_sigma.prefix_dispatch(A[:max(k_pose, 0)]) * lam
    tau = apply_impedance(tau, act, M.jacobian)

    # 6) 证书 + 异步审计
    pic = M.pic.make(T_ee, Sigma_ee, r_r, r_h, h0, k_pose, a, b_nr, act['mode'])
    M.vqa_p.submit_async(A, preds, {'pic': pic, 'dual_tube': (r_r, r_h)})
    M.cac.maybe_commit(M.shadow, M.time_since_last_commit)       # 继承 R68
    return k_pose, act['mode'], pic

## 3. 推导

**引理 16（杠杆臂放大界）** 由 δx = [R, −R[p]_×]ξ，朝向误差 φ 的贡献满足 ‖−R[p]_×φ‖ ≤ ‖p‖·‖φ‖；故沿任意方向 n 的投影半径 r(n) = k_σ√(nᵀΣ_x n) ≤ k_σ(σ_p + L·σ_φ)，L = ‖p‖。取 L = 1 m、σ_φ = 0.5° ≈ 8.7×10⁻³ rad，则朝向项即贡献 ~8.7 mm；对 5 cm 安全裕度已占 17%。系：远距离/长工具时必须压低朝向误差，否则标量安全会被几何放大吃掉。

**引理 17（规范不变性与非刚性破缺）** 对任意刚性 G，X' = (GT_h)⁻¹(GT_ee) = T_h⁻¹G⁻¹GT_ee = X，故平移/旋转型共模外参误差在相对位姿中**精确抵消**——ISC 天然免疫世界系与刚体外参漂移。但深度尺度 s 使 d̂ = (1+s)d，差分时延 τ_d 使相对位移偏 v_rel·τ_d，二者不满足刚性左乘，故 |δX| ≥ |s|·d + ‖v_rel‖·τ_d = b_nr。系：R68 的 δp_ext/δR_ext 估计对相对安全不是关键；**尺度锚与同步锚才是**。

**引理 18（双管前向不变性）** 若 h_t ≥ b_nr + ‖b_anchor‖、且对前缀内每条 tube 实现满足 h_{t+j} ≥ (1−α)^j h_t，则真实安全裕度在 [t, t+k_pose] 内保持非负。证明要点：定义 307 的下界对 tube 内所有实现成立（支持函数取最大投影），故 h 是真实裕度的下界；离散 CBF 保证下界不穿越 0。

**定理 16（EPIC-RAS 端到端安全）** 在 A87–A94 与新增 A95–A98（管凸性、锚可观测、时延有界、HIM 校准）下：
1. P(不安全接触) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_vqa + α_cal + **α_pose + α_inter**，其中 α_pose 由引理 16/17 的放大与偏差预算约束；
2. **任何不确定性升高（Σ_ee↑、Σ_h↑、a_anchor↓、b_nr↑）只会使 r_r、r_h 增大、k_pose 减小、CAS 更保守**——测量不可信永远导向收缩，且是**方向性**收缩，绝不放宽；
3. 当 k_pose > 0 时，控制作用满足离散鲁棒 CBF；当 k_pose = 0 时，CAS 至少给出 h_{t+1} ≥ h_t 的动作或进入 RETREAT，而非无方向急停。

**定理 17（CAS 切换连续性）** 阻抗与速度在 T_blend 内线性插值、刚度矩阵谱范数单调不增、阻尼按临界阻尼重算，则模式切换瞬间无控制突变（‖Δτ‖ ≤ L_blend·T_blend）；若连续化不可行，则先 RETREAT 再冻结。系：把「安全」从「瞬间停机」变成「连续可执行的几何动作」。

## 6. 本轮最大风险

**一句话**：EPIC-RAS 的全部安全性押在「双管处于同一公制、同一时间基准」这个前提上，而**深度尺度偏差与差分时延这两类非刚性共模误差，会在两条 tube 各自都“内部自洽”的情况下同时偷走真实裕度**——它们的杀伤力被 CAS 放大：一旦估计裕度虚假为正，系统不仅不收缩，还会沿“安全”方向主动柔顺/接近，把机器人推入真实的人体包络；这是标量 λ 时代不存在的失效模式：**几何证书越自信，共模偏差制造的假安全越致命**。

**次级风险与缓解**：
1. **过度柔顺被利用 / 瘫痪**：CAS 可被持续外力导向危险区 → 功率流上界 + 强制 RETREAT + 任务级超时升级；
2. **CBF 不可行**：接触中约束冲突 → 优先级松弛（力界 > 位姿界）+ 安全冻结；
3. **锚欺骗/失效**：锚被遮挡或伪造 → 多锚交叉校验 + a 阈值 + 无锚即降级；
4. **HIM 误设**：人运动模型偏差 → 可达 tube 膨胀 + 对抗性测试（E296）；
5. **计算抖动**：SE(3) 传播在 worst-case 超时 → 固定预算降采样 + 保守半径预分配。

def relative_state(T_ee, T_h, v_ee, v_h):
    return inv(T_h) @ T_ee, inv(T_h) @ (v_ee - v_h)

# IP-254 PUT：SE(3) 右不变协方差 + 杠杆臂 + 方向半径
class PoseUncertaintyTube:
    def pos_cov(self, Sigma_xi, R_hat, p):
        J = np.hstack([R_hat, -R_hat @ skew(p)])
        return J @ Sigma_xi @ J.T
    def radius_along(self, Sigma_x, n, bias=0.0):
        return self.k_sigma * np.sqrt(max(n @ Sigma_x @ n, 0.0)) + bias

# IP-255 ISC：双管分离 + 鲁棒离散 CBF
class InteractionSafetyCertificate:
    def margin(self, T_ee_hat, H_tube, P_tube, Sig_x, Sig_h, b_nr, b_a):
        d_hat, n = H_tube.distance_and_normal(T_ee_hat)
        return d_hat - P_tube.radius_along(Sig_x, n, b_nr) \
                      - H_tube.radius_along(Sig_h, n, b_a) - self.r_contact, n

        k = 0

            if h_j < (1 - self.alpha) ** j * h0 or h_j < 0: break
            k = j
        return k

## 4. 推导

**引理 16（杠杆臂放大）** δx=[R,−R[p]_×]ξ ⇒ 朝向项 ‖R[p]_×φ‖ ≤ L‖φ‖；故 r(n) ≤ k_σ(σ_p + Lσ_φ)。L=1m、σ_φ=0.5° ⇒ 朝向贡献 ≈8.7mm，占 5cm 裕度的 17%。系：长工具必须压低朝向误差。

**引理 17（规范不变与非刚性破缺）** X=(GT_h)⁻¹(GT_ee)=T_h⁻¹T_ee，刚性共模外参误差精确抵消；但 d̂=(1+s)d、差分时延使相对位移偏 v_rel·τ_d，故 |δX| ≥ |s|d + ‖v_rel‖τ_d = b_nr。系：相对安全不依赖绝对外参，**依赖尺度锚与同步锚**。

**引理 18（双管前向不变）** 若 h_t ≥ b_nr + ‖b_anchor‖ 且前缀内每条 tube 实现满足 h_{t+j} ≥ (1−α)^j h_t，则真实裕度在 [t,t+k_pose] 内非负。因定义 307 的下界对所有实现成立，故 h 为真实裕度下界；离散 CBF 保证下界不穿零。

**定理 16（端到端安全）** A87–A98 下：
1. P(不安全接触) ≤ α_chunk+δ_fi+α_emotion+α_wm+α_vqa+α_cal+α_pose+α_inter；
2. 任何不确定性升高（Σ_ee↑、Σ_h↑、a↓、b_nr↑）只会使管道增粗、k_pose 减小、CAS 更保守——**方向性收缩，绝不放宽**；
3. k_pose>0 ⇒ 离散鲁棒 CBF；k_pose=0 ⇒ CAS 给出 h_{t+1}≥h_t 的动作或 RETREAT，而非无方向急停。

**定理 17（CAS 切换连续性）** T_blend 内阻抗/速度线性插值、刚度谱范数单调不增、阻尼按临界阻尼重算 ⇒ 切换瞬间 ‖Δτ‖ ≤ L_blend·T_blend；连续化不可行则先 RETREAT 再冻结。系：安全从「瞬间停机」变为「连续可执行的几何动作」。

## 7. 本轮最大风险

**一句话**：EPIC-RAS 的全部安全性押在「双管处于同一公制、同一时间基准」这个前提上，而**深度尺度偏差与差分时延这两类非刚性共模误差，会在两条 tube 各自都“内部自洽”的情况下同时偷走真实裕度**——杀伤力被 CAS 放大：一旦估计裕度虚假为正，系统不仅不收缩，还会沿“安全”方向主动柔顺/接近，把机器人推入真实的人体包络；这是标量 λ 时代不存在的失效模式：**几何证书越自信，共模偏差制造的假安全越致命**。

**次级风险与缓解**：过度柔顺被利用/瘫痪（功率流上界 + 强制 RETREAT + 任务超时升级）；CBF 不可行（优先级松弛：力界 > 位姿界 + 安全冻结）；锚欺骗/失效（多锚交叉校验 + a 阈值 + 无锚即降级）；HIM 误设（可达 tube 膨胀 + E296 对抗测试）；计算抖动（固定预算降采样 + 保守半径预分配）。
