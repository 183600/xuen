# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「LoRA」×「评测指标」）

> R69 把不确定性一分为二：aleatoric 交给 λ_floor 收紧，epistemic 交给「看/问/触」的主动交互去消解，并用流似然给出一条标定不可吸收的第二意见。它问出了「我该向谁求证、还能问什么」。但 R69 有两个从未写进证书的隐含前提：
> - **（H1）评估器在系统之外，且静止不动。** ECE、VoI、模态熵、流似然、证据纪律，全都由系统自己计算、自己解释、自己引用。系统可以学会「看起来更确定」，却没有任何外部仲裁者能保证它「真的更对」。R69 自陈的最大风险——模态权重不可信、问错比不问更危险——本质上是**一个封闭的自我确认循环**：用系统自己的模态分布去评估系统自己的提问。
> - **（H2）系统不会从交互中学习。** R68/R69 都规定实时流零学习写操作，这是正确的；但 R69 没有回答「离线时允不允许学、学多少、学完证书还算不算数」。于是同一类歧义会被反复付费消解，系统永远停在「问一次、忘一次」的水平；而一旦允许学习，又没有任何机制能说明**这次学习改变了什么、评测是否还有效、出错能否撤回**。
>
> 本轮两个灵感正好补上两块缺失：
> - **LoRA** 把「一次学习」变成**可审计的最小增量**：基座冻结，只学一个低秩/稀疏的适配器；每个适配器有来源、支撑域、有效期、证书和回滚指针。低秩不只是省算力，它是一种**认知预算**：模型被允许改变的自由度是有上界的。
> - **评测指标** 把「评估」从排行榜变成一个**有管辖范围的测量契约**：指标有总体、有支撑域、有分辨率、有功效、有独立性要求，而且会被优化行为本身改变。**评测不是观测，评测是一次动作**——选择测什么、在谁身上测、测多少次，都会改变系统下一步的行为。
>
> 核心命题：**可审计的学习容量不能超过评测的秩容量。** 设适配器在认证基下只用 r 个原子（LoRA 的秩预算），评测套件对适配器系数的响应矩阵为 Φ；若 `spark(Φ) ≤ r`，就存在一个「在所有评测上零响应、却在未测方向上改变行为」的适配器。反之，若评测满足 r-RIP，则任何 r-稀疏适配器都会留下可测签名。于是「评测指标」第一次成为**学习的安全预算**，而不只是事后打分。命名 **LEDGER-RAS**（Low-rank Epistemic Delta with Governed Evaluation & Rollback：低秩认知增量 × 受治理评测 × 可回滚账本）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我可以学什么，谁来审计这堂课**」——学习不是把梯度倒进模型，而是往账本里记一笔可验证、可撤回的债。

## 0. 直觉与动机

**灵感 1（LoRA → 学习的最小可审计单位）**
直觉：全参数微调像把整栋楼重新装修，事后只能看总体验收；LoRA 像只换一扇门，门有型号、有安装记录、有保修期，坏了还能拆下来。机器人安全系统真正需要的不是「能不能学」，而是「**这次学的是哪一课、证据是什么、有效范围多大、什么时候失效、怎么撤回**」。把每次事故复盘产生的一个 LoRA 适配器当作一条账本条目，学习就从「黑箱漂移」变成「有借有还的认知账务」。
但低秩也是**藏身处**：一个秩为 r 的改动可以只在一个 r 维子空间里改变行为，而所有 d < r 个评测探针都看不见它。低秩本身不产生安全，**已知的低秩基 + 覆盖该基的评测**才产生安全。

**灵感 2（评测指标 → 有管辖范围的测量契约）**
直觉：一把尺子不是「真理」，它只在某个量程、某个温度、某个对象上有效。指标也一样：成功率只在某个场景分布上有效，ECE 只在某个置信区间上有分辨率，VoI 只在回答者真的回答「系统以为在问的问题」时有效。R69 把这些指标当成无条件的真值，于是可能在一个指标已经失效的分布上继续用它做安全决策。
更危险的是 Goodhart：**一旦用指标来选择适配器，指标就变成了被优化的对象，而不再是对能力的测量**。因此评测必须分三件事：选择用什么（预注册）、在什么数据上选（交叉拟合）、在什么数据上报（独立留出）。把三者混在一起，报出的提升就是「选择偏差」而不是「学习效果」。

**灵感 3（评测也是一种交互 → RAP）**
直觉：R69 的 MINT 用 VoI 选择「看/问/触」这些物理信息动作；R70 把同一个逻辑搬到离线评测：**选下一个探针，使「适配器真实效用为正」这件事的后验熵下降最多**。评测不是把固定 benchmark 跑一遍，而是一个主动实验设计问题：先测最可能推翻适配器的方向，再测最贵但最有判别力的方向。区别只在于——R69 的交互发生在部署中，R70 的评测发生在部署前/停机窗口。**评测是离线交互，交互是在线评测。**

**灵感 4（安全是不变子空间 → NSG）**
直觉：安全层不应该和任务层在同一个可编辑空间里「商量」。若安全约束只依赖某些敏感输入/输出方向，就要求所有适配器在这些方向上**零响应**：`P_s Δ = 0`、`Δ P_{X_s} = 0`。这样无论任务适配器怎么组合，安全函数值都不变。进一步，把安全适配器「钉死」在账本里，任何合并都不能覆盖它。否则一个任务适配器可以恰好抵消安全适配器的系数——**低秩改动可以精准地拆掉安全层，而聚合指标看起来毫无变化**。

**灵感 5（回滚使学习变得可冒险 → Ledger）**
直觉：如果每一次学习都能在 O(1) 时间内精确回滚，那么系统可以在认证包络内更积极地试错；反之，若学习不可逆，任何一次错误适配都会永久污染证书。R68/R69 的「零实时写操作」保留，但离线学习被允许，前提是**账本可回滚、基座不改写、适配器可组合**。可逆性不是工程便利，而是**允许学习的前提**。

**灵感 6（评测-学习秩守恒 → ELRC）**
直觉：如果系统允许自己在一个 16 维子空间里改变行为，却只有 4 个独立评测探针，那么剩下 12 维的变化就是**不可审计的**。你不能声称「评测通过所以安全」，因为评测根本没有覆盖那些维度。反过来，若评测的响应矩阵在适配器基上满足 r-RIP，那么任何 r-稀疏改动都会留下签名。于是得到一条守恒律：
> **可审计学习容量 ≤ 评测秩容量。**
这不是工程调参，而是证书有效性的必要条件。**评测指标由此从「事后打分」升级为「学习的安全预算」：你想学多少维，就必须先有能力测多少维。**

**灵感 7（两个时间尺度 → R69 是快回路，R70 是慢回路）**
直觉：R69 在秒级做「要不要问、问谁、信多少」；R70 在天级做「这次事故暴露了哪类系统性缺陷、要不要写进账本、写完还能不能认证」。快回路必须保持零学习写操作；慢回路可以学习，但只能通过受治理的账本。两层用同一套证书语言连接：R69 的交互日志是 R70 的适配器证据，R70 的适配器又反过来改变 R69 的先验与成本模型。**学习不是替代安全，而是把安全证书的适用范围往前推一格。**

## 1. 形式化定义（增量：定义 310–325）

**定义 310（LEDGER-RAS 总览）** LEDGER-RAS = (LAT, DDE, MEG, RAP, NSG, SAM, ARM, GCM, RAS-WM††)。六条不变式：
(i) **实时零学习写操作**：控制回路内基座 θ0 与已提交适配器只读；任何学习发生在离线窗口（继承 R68 定义 276-i、R69 定义 293-i）。
(ii) **认证基约束**：所有适配器只能落在认证适配基 ℬ 的张成内，且有效秩/稀疏度 ≤ r_max；不在基内的更新一律拒绝，而不是「先合进去再解释」。
(iii) **ELRC 守恒**：被接受的适配器必须满足 `r(β) ≤ r_eval(Φ)` 且评测覆盖率 `ρ_r(Φ) ≥ ρ_min`；安全敏感子空间必须被 NSG 覆盖。
(iv) **证据纪律**：适配器选择数据与评测数据不相交；指标预注册；单次离线实验不得单独定案，需至少两个独立折（cross-fitting）一致。
(v) **可回滚**：每个账本条目带来源、数据哈希、支撑域、有效期、父节点与回滚指针；任何 ARM/GCM 失败都能在 O(1) 指针切换内恢复前一状态。
(vi) **失败即退化**：任一条件不满足，退回 R69 的 FLUID-RAS 基座策略；学习侧永远不能让安全侧比 R69 更差。

**定义 311（认证适配基与 LoRA 账本）** 认证基 ℬ = {P_j}_{j=1}^R 是一组在 Frobenius 内积下正交的秩-1 原子（例如特定层、特定方向的 `u_j v_j^T`）。适配器写成
`Δ(β) = Σ_{j=1}^R β_j P_j`，`r(β) = ||β||_0 ≤ r_max`。
策略参数为 `θ(β) = θ0 + Δ(β)`（基座 θ0 永久冻结）。账本条目
`ℓ_i = (id_i, β_i, basis_ver, data_hash_i, cert_i, S_i, T_i, parent_i, rollback_i)`，
其中 S_i 为支撑域（适配器被训练/验证覆盖的状态分布），T_i 为有效期。账本状态 L_t 是已提交条目的有向无环图；策略由 L_t 的合并系数唯一决定。

**定义 312（适配秩与行为签名）** 对评测套件（探针集 X 与读出函数 R），定义**评测算子** `Φ ∈ ℝ^{d×R}`：`Φ_{k,j}` 是「只启用第 j 个原子」时第 k 个评测探针的（线性化）响应。对适配器 β，行为签名 `y(β) = Φβ + ε`。`r(β)=||β||_0` 是适配秩，d 是评测自由度。这里的关键不是把非线性模型强行线性化，而是：**认证基与评测算子都在离线构建，适配器只允许沿这些已知方向改变**；非线性残余进入 ε，并由 DDE 的有限差分/局部雅可比复核（假设 A99）。

**定义 313（评测覆盖率与 spark）** 对评测算子 Φ，定义
`spark(Φ) = min{ ||β||_0 : β ≠ 0, Φβ = 0 }`；
`ρ_r(Φ) = min_{||β||_0 ≤ r, ||β||_2 = 1} ||Φβ||_2`。
**评测容量** `r_eval(Φ) = max{ r : spark(Φ) > r }`。若 `r ≥ spark(Φ)`，存在非零 r-稀疏适配器在全部评测上零响应（不可见适配器）；若 Φ 满足 r-RIP（`(1−δ_r)||β||² ≤ ||Φβ||² ≤ (1+δ_r)||β||²`，δ_r<1），则任何非零 r-稀疏适配器都有可测签名。**评测的 spark 必须大于适配秩**，这是定义 322 的硬条件。

**定义 314（Delta 域评测 DDE）** 不评测整个 θ，而评测增量 β：DDE 在留出数据上计算 `(CDV(β), Risk(β), Safety(β), Coverage(β))`，其中 CDV 见定义 315，Coverage 由定义 313 的 ρ 与支撑域覆盖率共同给出。DDE 的输出不是单点分数，而是**带置信区间的四元组**；任何一项不可估，就返回「不合格」而不是默认通过。

**定义 315（反事实决策价值 CDV）** 设留出决策日志 D_hold 与任务效用 U（含交互成本、时延、风险惩罚），
`CDV(β) = E_{s∼D_hold}[ U(π_{θ0+Δ(β)}(s)) − U(π_{θ0}(s)) ]`。
允许用三种估计：成对反事实回放（同随机种子）、基于 R68 世界模型的数字孪生、以及带倾向权重的日志重加权。要求 A100–A102（重叠性/无未测混淆/世界模型保真度在容差内）。报告单侧下界 `CDV_lb`；**只有 `CDV_lb > 0` 才允许接受适配器**。CDV 是决策价值，不是代理指标：它把「问得更多」与「真的更好」分开，直接堵住 R69 的「交互通货膨胀」风险。

**定义 316（评测契约与 MEG）** 一个指标不是标量，而是契约
`M = (endpoint, population, support, properness, power, independence, multiplicity, version)`。
**指标资格门 MEG** 要求：
(a) 端点是 proper scoring rule 或决策效用，而不是可被单调变换刷分的代理；
(b) 报告支撑域与覆盖率，不允许用全局均值掩盖局部失效；
(c) 在最小可检测效应 δ 下功效 ≥ 1−β；
(d) 选择集与报告集不相交（交叉拟合/预注册）；
(e) 多重比较已校正（FWER 或 FDR）；
(f) 通过污染/复用检查。
任一不满足 ⇒ 指标**不合格**，不得用于适配器接受决策。**指标只在它的管辖域内有效**。

**定义 317（秩感知主动探针 RAP）** 评测探针的选择也是一个 VoI 问题：
`g* = argmax_{g∈𝒢_eval} [ H(sign CDV | D) − E_{y∼p(·|g)} H(sign CDV | D,y) − c(g) ]`，
并加两项约束：(i) 新探针必须提高对适配器支撑子空间的覆盖（降低 ρ 缺口）；(ii) 采用序贯检验与 alpha spending，防止「一直测到显著」的 p-hacking。停止条件：`CDV_lb > 0`（接受）、`CDV_ub < 0`（拒绝）或评测预算耗尽（拒绝）。R69 的 MINT 是部署中的信息动作，RAP 是离线评测的信息动作，二者共享同一套 VoI 数学。

**定义 318（零空间安全护栏 NSG）** 设安全函数族 ℱ = {f_k}（CBF、动作限幅、认证前缀不变式等），其敏感输入子空间为 X_s、敏感输出/特征子空间为 U_s。可采纳系数集
`B_adm = { β : P_{U_s} Δ(β) = 0, Δ(β) P_{X_s} = 0 }`，
即适配器在安全敏感方向上零响应。投影算子 `Π_adm` 把任意 β 投到 B_adm。钉死安全适配器 β_safe 是账本中的保留项，任何任务适配器不得修改其张成；否则存在 `β_task` 使 `Δ(β_task) = −Δ(β_safe)` 在安全探针上，从而**精准拆掉安全层而聚合指标不变**。

**定义 319（安全合并 SAM）** 多个适配器的合并系数
`β_merge = Π_adm( Σ_i α_i β_i )`。
合并冲突 `κ = ||(I−Π_adm)(Σ_i α_i β_i)||_2`；若 κ > ε_κ、合并后 `r(β_merge) > r_max`、或 ℱ 中任一安全函数在探针集上变化超过 ε_s，则拒绝合并或先做**适配器固化**（consolidation：把多个小适配器蒸馏为一个重新认证的低秩适配器，再入账）。由于认证基固定、约束线性，合并后的行为在基坐标中可精确审计，且投影后与合并顺序无关。

**定义 320（运行时支撑门 ARM）** 每个适配器有支撑域 S_i 与有效期 T_i。运行时用 R69 的条件编码 z_t 计算 `d_i(o_t) = dist(z_t, S_i)`（Mahalanobis / kNN / 密度分位）。若 `d_i > τ_s`、`t > T_i`、或「预测增量 vs 实际增量」的 CUSUM 超阈，则禁用该适配器并回滚到父账本状态；同时把该事件写入审计缓冲，作为下一轮适配器提议的负样本。**适配器只在它被证明有效的分布内有管辖权。**

**定义 321（Goodhart / 污染监测 GCM）** 三类检查：
(i) **安慰剂对照**：在打乱标签/随机化动作的安慰剂任务上训练同构适配器，其 CDV 应统计上为零；若显著为正，说明评测泄漏或指标可刷。
(ii) **代理-CDV 间隙**：`gap = M_proxy − CDV` 随适配器秩/训练步数上升而扩大，则触发 Goodhart 警报。
(iii) **不变性测试**：对视角、语言、用户群体、传感器替换等 nuisance 变换，指标应保持构念不变；若指标随 nuisance 大幅变化，则该指标不具备跨域管辖权。
任一失败 ⇒ 冻结学习侧，直到重新预注册或重建评测契约。

**定义 322（ELRC 可采纳条件）** 适配器 β 可被接受，当且仅当：
(a) `r(β) ≤ r_eval(Φ)` 且 `ρ_{r(β)}(Φ) ≥ ρ_min`；
(b) NSG 覆盖全部安全敏感方向，且 SAM 冲突 κ ≤ ε_κ；
(c) `CDV_lb(β) > 0`，且 MEG 全部指标合格；
(d) GCM 通过，ARM 的支撑覆盖率 ≥ γ；
(e) 账本回滚路径存在且可验证。
若 (a) 不满足，DDE 将 β 投影到最大的可审计稀疏度 `r_aud`（可能为 0，即拒绝学习）。定义**可审计容量** `C_aud = r_eval(Φ)`，**请求容量** `C_req = r(β)`；不变式 `C_req ≤ C_aud` 即 ELRC。

**定义 323（证书 J_LEDGER）** J_LEDGER = (J_FLUID, basis_ver, ledger_root, C_req, C_aud, ρ_r, CDV_lb, MEG_status, NSG_invariants, merge_conflict, support_coverage, GCM_report, rollback_hash, ledger_ver)。
Valid ⇔ Valid(J_FLUID) ∧ ELRC 满足 ∧ MEG 全合格 ∧ NSG 不变式保持 ∧ GCM 通过 ∧ 回滚路径可验证。证书的每一条都指向一个可复现的实验/日志哈希；证书不声称「模型安全」，只声称「在基 ℬ、评测 Φ、支撑域 S 与有效期 T 内，这次增量可被审计且可撤回」。

## 3. 推导

**引理 18（评测覆盖与不可见适配）** 设认证基有 R 个原子，评测算子 Φ ∈ ℝ^{d×R}。
(i) 若 `spark(Φ) ≤ r`，存在非零 r-稀疏 β 使 `Φβ=0`：该适配器在全部评测探针上零响应，却可在 `span(ℬ)` 中未被探针覆盖的方向改变行为。
(ii) 若 Φ 满足 r-RIP（δ_r<1），则对任意 r-稀疏 β，`||Φβ||₂ ≥ sqrt(1−δ_r)·||β||₂`；任何非零 r-稀疏适配器都留下可测签名。
证明：(i) 由 spark 定义直接得；(ii) 是压缩感知的标准 RIP 推论。系：**评测的 spark 必须大于适配秩**；低秩不是安全来源，**已知基 + 覆盖基的评测**才是。

**引理 19（代理指标的乐观偏差）** 设 N 个候选适配器按代理指标 M 选择，真实效用为 CDV，且 `M_i − CDV_i` 是 σ-次高斯的。则
`E[max_i (M_i − CDV_i)] ≤ σ·sqrt(2 log N)`。
因此「从 N 个里挑最好的」天然带来乐观偏差；用同一批数据选择并报告，会把选择偏差误报成学习收益。交叉拟合 + 预注册 + 独立留出把一阶乐观偏差消除，只剩可估的泛化间隙。系：**评测不是免费的**；候选越多、适配秩越大，评测预算必须越高。

**引理 20（零空间安全不变性）** 若安全函数 f_k 只依赖 `P_{U_s}Δ` 与 `ΔP_{X_s}`，且所有可采纳适配器满足 `P_{U_s}Δ=0`、`ΔP_{X_s}=0`，则对任意线性组合 `Σα_iΔ_i`，`f_k(θ0+Σα_iΔ_i)=f_k(θ0)`。若不加该约束，则存在任务适配器在安全探针上精确抵消 β_safe，使安全函数回到基座值甚至更差，而聚合任务指标不变。证明：前者由线性性与零响应直接得；后者取 `β_task = −β_safe` 在安全子空间的分量即可。系：**安全必须是不变子空间，不能只是损失项里的软惩罚**。

**引理 21（合并的秩预算与冲突）** 若 β_1、β_2 的支撑大小分别为 r_1、r_2，则 `r(β_1+β_2) ≤ r_1+r_2`；重复合并会使适配秩单调上升，最终越过 `r_eval(Φ)`。若两适配器在安全子空间上的投影非零且方向相反，则合并冲突 κ 可任意大。因此必须：(a) 设总秩预算 R_max；(b) 每次合并后重新做 ELRC 检查；(c) 预算将尽时执行**固化**：把多个小适配器蒸馏成一个重新认证的低秩条目，淘汰冗余方向。系：**持续学习不是无限叠加，而是有借有还的账本**。

**定理 18（无免费学习 / ELRC 定理）** 在 A99–A104 下：
(i) 若接受一个 `C_req > C_aud` 的适配器，则 J_LEDGER 不完备：存在另一个适配器 β'，在所有已测指标上与 β 相同，但在未测方向上的真实 CDV 与 β 不同；因此证书无法区分「学到了」与「躲过了评测」。
(ii) 若 `C_req ≤ C_aud`、NSG 覆盖安全方向、CDV 用独立留出数据估计且 MEG 合格，则任何真实 `CDV ≥ δ` 的适配器被接受的概率 ≥ 1−β（功效），且被接受适配器的 `CDV_lb > 0`。
(iii) 因此任何声称「评测通过 ⇒ 可安全学习」的证书，必须把 `C_req ≤ C_aud` 写成硬约束；否则评测越少、学习越多，证书越像一张**超出管辖范围的逮捕令**。
证明：由引理 18 的不可见适配器构造 (i)；由 RIP 的签名下界与 CDV 单侧置信下界得 (ii)； (iii) 是 (i) 的逆否命题。

**定理 19（LEDGER 严格包含 R69）** 在「永不学习」边界（无合格适配器、或 `C_aud=0`、或 ARM/GCM/MEG 任一失败）上，LEDGER-RAS 的控制输出与 R69 逐指令相同；在允许学习时，只有 `CDV_lb>0` 且 NSG 保持的适配器才会改变策略，且任何失败都回滚到 R69 基座。因此安全侧不弱于 R69，效率侧获得「可撤回的学习增益」。R69 是 LEDGER 在「零适配预算」处的退化。

**定理 20（回滚连续性与无突变）** 基座冻结、适配器加法合并、账本指针切换，使回滚能在 O(1) 内恢复精确的前一策略；若切换只发生在认证边界（或经 C-RAS-WM 前缀认证），则 R68 的提交/换装不变式（定理 15）保持，控制连续、无突变。特别地，**离线学习不会把在线回路变成一个边跑边改参数的在线学习系统**。

## 6. 本轮最大风险

**一句话**：LEDGER-RAS 把「可审计」当成「安全」：它保证**评测所张成的秩内**的变化可被看见、可被回滚，却无法保证**真实世界的危险方向**落在评测的秩内；一旦风险位于未测方向或分布漂移后的新方向，证书的权威就超过了它的管辖范围——**评测的秩覆盖不是世界的秩覆盖**。

**次级风险与缓解**：
1. **认证基覆盖不全**（真实需要的修正不在 ℬ 内）→ 要么拒绝学习（能力停滞），要么被迫用扭曲的基拟合（行为失真）；缓解：基刷新协议 + 重新认证 + 把「无法在基内表达」本身作为事故类型记录；
2. **CDV 的因果假设不成立**（无反事实、混淆、世界模型失真）→ 评测退化为相关性；缓解：数字孪生敏感性分析、倾向重加权、只报告可识别下界，不可识别即拒绝；
3. **Goodhart / 指标污染** → 代理指标被刷、benchmark 泄漏；缓解：预注册、交叉拟合、安慰剂对照、GCM、E315；
4. **低秩后门** → 恶意适配器只在罕见触发下改变行为；缓解：秩子空间扫描、激活聚类、数据来源与训练过程可复现、NSG 钉死安全项；
5. **合并冲突/秩预算耗尽** → 适配器互相抵消或越过评测容量；缓解：线性基坐标审计、安全投影、固化与淘汰；
6. **安全护栏过窄**（零空间约束把有用学习也挡掉）→ 能力-安全 Pareto 变差；缓解：只对认证过的安全函数加约束，报告「安全-效用」曲线，而不是把所有行为都钉死。

## 2. 形式化定义（要点版）

**定义 310（总览与六不变式）** 实时零学习写；认证基约束；ELRC 守恒 `C_req≤C_aud`；选择/评测数据不相交且指标预注册；每个适配器可回滚；任一失败退回 R69。

**定义 311–312（认证基、账本、行为签名）** 适配器只沿 ℬ 的少量原子改变；账本记录来源、数据哈希、证书、支撑域、有效期、父节点、回滚指针；行为签名 `y(β)=Φβ+ε`，适配秩 `r(β)=‖β‖₀`。

**定义 313（评测覆盖与 spark）** `spark(Φ)=min{‖β‖₀:β≠0,Φβ=0}`；`r_eval(Φ)=max{r:spark(Φ)>r}`；若 `r≥spark(Φ)` 存在不可见适配器；若 Φ 满足 r-RIP，则所有 r-稀疏适配器都留下签名。

**定义 314–315（DDE 与 CDV）** Delta 域评测输出带置信区间的 (CDV, Risk, Safety, Coverage)；`CDV(β)=E[U(π_{θ0+Δ(β)})−U(π_{θ0})]`，用配对反事实回放/数字孪生/倾向重加权估计，报告单侧下界，`CDV_lb>0` 才接受。

**定义 316（评测契约与 MEG）** 指标须 proper / 有支撑域 / 有功效 / 选择与报告分离 / 多重比较校正 / 通过污染检查；否则不合格，不得用于接受决策。

**定义 317（RAP）** 以 sign(CDV) 的后验熵为目标做离线 VoI 选探针；同时最大化对适配器支撑子空间的覆盖；序贯检验 + alpha spending；预算耗尽即拒绝。

**定义 318（NSG）** 安全函数只依赖敏感子空间；可采纳适配器在 `P_{U_s}` 与 `P_{X_s}` 上零响应；安全适配器钉死；否则任务适配器可在安全探针上抵消安全层而聚合指标不变。

**定义 319（SAM）** `β_merge=Π_adm(Σα_iβ_i)`；冲突 `κ=‖(I−Π_adm)(Σα_iβ_i)‖`；κ 超阈/秩超预算/安全函数变化超阈 ⇒ 拒绝或固化再认证。

**定义 320（ARM）** 运行时用 z_t 到支撑域 S_i 的距离、有效期、预测-实际增量 CUSUM 做门控；越界即禁用并回滚。

**定义 321（GCM）** 安慰剂对照应零效应；代理-CDV 间隙随秩/步数扩大即 Goodhart 警报；指标对 nuisance 变换应构念不变；污染/复用检查失败即冻结学习。

**定义 322（ELRC 可采纳条件）** `r(β)≤r_eval(Φ)`、`ρ_r≥ρ_min`、NSG 覆盖、SAM 冲突 ≤ε_κ、`CDV_lb>0`、MEG 全合格、GCM 通过、ARM 覆盖 ≥γ、回滚路径可验证。不满足则投影到最大可审计稀疏度或拒绝。

**定义 323–325（证书、离线协议、双时间尺度）** J_LEDGER 把上述所有证据哈希化；学习只在离线窗口通过账本提交；在线只读账本、跑门控、必要时 O(1) 回滚。R69 快回路永不学习，R70 慢回路永远可回滚。

## 3. 关键算法伪代码

```python
# IP-264 LAT：认证基 + LoRA 账本（基座冻结、加法合并、O(1) 回滚）
class AdapterLedger:
    def commit(self, beta, cert):
        assert beta_sparsity(beta) <= self.r_max and cert.C_req <= cert.C_aud
        self.entries[cert.id] = (beta, cert, cert.support, cert.expiry, self.head)
        self.head = cert.id
    def rollback(self, entry_id):
        self.head = entry_id                      # 指针切换，不改基座
    def effective_beta(self):
        return sum_along_parents(self.entries, self.head)

# IP-265/266：评测算子 + 秩覆盖 + 主动探针
def build_eval_operator(atoms, probe_suite):
    return stack([linearized_response(atom, probe) for atom in atoms for probe in probe_suite])

def rank_coverage(phi, r):
    return min_restricted_singular_value(phi, r)   # 近似 r-RIP / spark 下界

def choose_eval_probes(phi, beta_prior, budget):
    probes = []
    while budget.remaining() and not cert_conclusive(probes):
        g = argmax_g expected_info_gain_sign_cdv(g) - cost(g)
        if coverage_gain(g, phi, beta_prior) <= 0: break
        probes.append(g); budget.spend(g)
    return probes

# IP-267/268：交叉拟合 CDV + 指标资格门
def cdv_lower_bound(beta, holdout, alpha=0.05):
    diffs = paired_counterfactual_utility(base_policy, beta, holdout)
    return one_sided_lower_ci(diffs, alpha)

def meg_eligible(metric, split):
    return (metric.proper and metric.support_covers(split) and
            metric.power_at(delta) >= 0.8 and
            split.selection.isdisjoint(split.report) and
            metric.multiplicity_corrected and not contaminated(metric, split))

# IP-269/270：零空间护栏 + 安全合并
def admissible(beta):
    return project_out(beta, safety_input_subspace, safety_output_subspace)

def safe_merge(betas, weights):
    raw = sum(w * b for w, b in zip(weights, betas))
    merged = admissible(raw)
    if norm(raw - merged) > EPS_KAPPA: return None
    if beta_sparsity(merged) > r_max: return consolidate(betas, weights)
    return merged

# IP-271：运行时支撑门
def runtime_gate(beta, cert, z_t, t):
    return (t <= cert.expiry and
            distance(z_t, cert.support) <= TAU_SUPPORT and
            cusum_drift(beta, z_t) <= TAU_DRIFT)

# IP-274：离线适配 + 在线闭环（双时间尺度）
def offline_adapt_round(M, incident_logs):
    candidates = propose_from_clusters(incident_logs, basis=M.basis)
    probes = M.rap.choose_eval_probes(M.phi, candidates, M.eval_budget)
    for beta in candidates:
        if not M.meg.eligible(M.metrics, M.splits): continue
        if M.elrc.requested(beta) > M.elrc.auditable(M.phi): beta = M.elrc.project(beta)
        cert = M.dde.certify(beta, probes, M.splits)
        if cert.CDV_lb <= 0 or not cert.nsg_ok or not cert.gcm_ok: continue
        M.ledger.commit(beta, cert)
        if not M.sam.check(M.ledger.effective_beta()): M.ledger.rollback(cert.parent)

def LEDGER_RAS_round(M, obs):
    if not M.arm.gate(M.ledger.effective_beta(), M.mtm.encode(obs), time.now()):
        M.ledger.rollback(M.ledger.parent_of_head())
    return M.fluid_ras_round(obs)                  # R69 原闭环，零学习写
```

## 4. 推导

**引理 18（评测覆盖与不可见适配）** 设认证基有 R 个原子，评测算子 Φ ∈ ℝ^{d×R}。
(i) 若 `spark(Φ) ≤ r`，存在非零 r-稀疏 β 使 `Φβ=0`：该适配器在所有评测探针上零响应，却可在 `span(ℬ)` 的未覆盖方向改变行为；
(ii) 若 Φ 满足 r-RIP（δ_r<1），则对任意 r-稀疏 β，`‖Φβ‖₂ ≥ sqrt(1−δ_r)·‖β‖₂`，任何非零 r-稀疏适配器都留下可测签名。
系：**评测的 spark 必须大于适配秩；低秩不是安全来源，已知基 + 覆盖基的评测才是。**

**引理 19（代理指标的乐观偏差）** 设 N 个候选按代理指标 M 选择、真实效用 CDV，`M_i−CDV_i` 为 σ-次高斯，则 `E[max_i(M_i−CDV_i)] ≤ σ·sqrt(2 log N)`。同一批数据选择并报告会把选择偏差误报为学习收益；交叉拟合 + 预注册 + 独立留出消除一阶乐观偏差。系：**评测不是免费的**；候选越多、适配秩越大，评测预算必须越高。

**引理 20（零空间安全不变性）** 若安全函数只依赖敏感子空间，且所有可采纳适配器在 `P_{U_s}`、`P_{X_s}` 上零响应，则任意线性组合都保持安全函数值不变。否则存在任务适配器在安全探针上精确抵消 β_safe，使安全函数退化而聚合任务指标不变。系：**安全必须是不变子空间，不能只是损失项里的软惩罚**。

**引理 21（合并秩预算与冲突）** `r(β_1+β_2) ≤ r_1+r_2`；重复合并使适配秩单调上升，最终越过 `r_eval(Φ)`。若两适配器在安全子空间上的投影非零且方向相反，合并冲突 κ 可任意大。因此必须设总秩预算、每次合并后重做 ELRC、预算将尽时固化淘汰。系：**持续学习不是无限叠加，而是有借有还的账本**。

**定理 18（无免费学习 / ELRC 定理）** 在 A99–A104 下：
(i) 若接受 `C_req > C_aud` 的适配器，J_LEDGER 不完备：存在 β' 在所有已测指标上与 β 相同、但在未测方向的真实 CDV 不同，证书无法区分「学到了」与「躲过了评测」；
(ii) 若 `C_req ≤ C_aud`、NSG 覆盖安全方向、CDV 用独立留出估计且 MEG 合格，则真实 `CDV≥δ` 的适配器被接受的概率 ≥1−β，且被接受者 `CDV_lb>0`；
(iii) 因此任何「评测通过 ⇒ 可安全学习」的证书，必须把 `C_req≤C_aud` 写成硬约束；否则评测越少、学习越多，证书越像**超出管辖范围的逮捕令**。

**定理 19（LEDGER 严格包含 R69）** 在「永不学习」边界（无合格适配器 / `C_aud=0` / ARM-GCM-MEG 任一失败）上，LEDGER-RAS 与 R69 逐指令相同；允许学习时，只有 `CDV_lb>0` 且 NSG 保持的适配器才改变策略，任何失败都回滚到 R69 基座。安全侧不弱于 R69，效率侧获得「可撤回的学习增益」。R69 = 「零适配预算」退化。

**定理 20（回滚连续性与无突变）** 基座冻结、适配器加法合并、账本指针切换，使回滚在 O(1) 内恢复精确的前一策略；若切换只发生在认证边界或经 C-RAS-WM 前缀认证，则 R68 定理 15 的提交/换装不变式保持，控制连续、无突变。离线学习不会把在线回路变成边跑边改参数的在线学习系统。

## 8. 本轮最大风险

**一句话**：LEDGER-RAS 把「可审计」当成「安全」：它保证**评测所张成的秩内**的变化可被看见、可被回滚，却无法保证**真实世界的危险方向**落在评测的秩内；一旦风险位于未测方向或分布漂移后的新方向，证书的权威就超过了它的管辖范围——**评测的秩覆盖不是世界的秩覆盖**。

**次级风险与缓解**：认证基覆盖不全（基刷新协议 + 重新认证 + 记录「无法在基内表达」的事故类型）；CDV 因果假设不成立（数字孪生敏感性分析 + 倾向重加权 + 只报告可识别下界）；Goodhart/指标污染（预注册 + 交叉拟合 + 安慰剂对照 + GCM + E315）；低秩后门（秩子空间扫描 + 激活聚类 + 来源可复现 + 安全项钉死）；合并冲突/秩预算耗尽（线性基坐标审计 + 安全投影 + 固化淘汰）；安全护栏过窄（只约束认证过的安全函数，报告安全-效用 Pareto 曲线）。
