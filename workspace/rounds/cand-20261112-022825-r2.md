# 第 58 轮（承接第 57 轮「少样本元推断×跨模态对账×个性化有界信任」IP-133~138；灵感循环第 2 轮；本轮灵感：「通用机器人」×「机械臂」）

> 第 57 轮把承诺建立在"世界信念"的证据质量上：少样本可校准、跨模态可对账、个性化有界。但它默认了三个未被审视的**单体静观**前提：任务以移动为主（失败≈摔倒）；能力被当作一个与构型无关的标量标签（"这技能我会"）；承诺只问"下一步会不会失败"，不问"失败后能不能退出"。本轮两个灵感从两端拆掉这些前提：**通用机器人**把"一部身体、一套策略要覆盖无数任务/物体/工具/场景"摆上桌——它最危险的错误不是不知道世界，而是不知道**自己在这个构型、这个工具、这个物体上到底能不能**；通用性用平均成功率掩盖了配置空间尾部的失败。**机械臂**把"接触即改变世界"摆上桌——抓取让物体成为身体的一部分，插入会让系统卡死，停止对一个已负载的臂未必安全；不可逆的不是"走错一步"，而是"进去以后出不来"。于是本轮把安全对象从"世界证据"升级为**能力契约**：前向可信（ECC）、后向可退（RCC）、跨体保守（CET）、全身耦合（WCC）、组合不漏（SCA），由通用承诺引擎（GCE）统一编排。核心命题：**"契约说这一步可承诺、可退出、可迁移、可组合"**。

核心矛盾：
- **H29（通用 ≠ 每个能力都通用）**：通用机器人的广度靠单个能力的浅度换来；"我会这个任务"是对构型/物体/工具/负载的平均，而不是对**此刻这个构型**的证书。平均成功率把奇异位形、关节极限、负载上限、长工具力矩臂这些尾部失败藏在均值里；机器人越通用，越容易把"任务级成功过一次"误当"能力级证书已获得"。
- **H30（机械臂承诺 vs 可退出）**：操作接触制造**附着**——抓取后物体成为身体的一部分。一个动作可以前向安全、却在后向上是不可逆陷阱（抓了放不下、插了拔不出、物体挡住退路）；而对已负载的臂，"停"本身可能就是危险动作（停在空中耗能、松手摔物、僵持卡死）。前几轮只界定了前向失败，从未界定"我能不能出来"。
- **H31（单模块裕度 vs 全身耦合）**：移动操作里基座与臂各自过裕度，联合却失败：臂外伸改变质心、反力矩掀翻基座；基座一动，臂的接触坐标系整体失效。把独立裕度做合取是不可靠的，耦合要么被保守上界住，要么被**时序分解**（先锁基座再动臂 / 先收臂再动基座）拆开。
- **H32（单技能可信 vs 组合泄漏）**：通用机器人靠长程技能链工作；每个技能的契约都以其前置条件为前提，但组合序列可以在"没有任何单个技能失败"的情况下，让下一个技能的前置条件静默失效（抓取成功但物体已损/已空，下一步的"物体完好"为假）。逐技能门看不见契约泄漏。

## 0. 直觉与动机

**灵感 1（通用机器人 → 能力不是属性，而是配置条件化的契约）**
直觉：把"能力"存成一个"会/不会"的标签，是单体机器人时代的习惯。通用机器人面对的是连续的能力空间：同一技能在可达域中心成立，在接近奇异、接近关节极限、负载接近额定、工具力矩臂变长时就不成立。于是能力必须写成一份**带前/后置条件、带配置裕度、带失效概率上界的契约** C_σ(e,c)，只在当前构型落在可行域内才生效。通用性的正确用法不是"我知道很多技能"，而是"我知道每个技能在什么条件下才作数，且能随时退到已验证的更窄模式"。

**灵感 2（机械臂 → 承诺必须是双向的，且有承诺深度）**
直觉：移动机器人"走错一步"通常还能停下重规划；机械臂一旦抓牢/插入/旋紧，世界状态已被改写，简单的"不做"不再可用。所以接触动作的承诺要有**后向证书**：存在一个已验证的退出策略 r，能在故障包络内把系统带回安全可弃状态，且这不依赖"停下来就安全"这一未经证明的假设。更进一步，连续承诺会累积——定义**承诺深度** d_c：距离上次"可弃状态"已经连做了几个不可逆原语；深度到顶必须插入 reset checkpoint（放下/松开/重新观测），把长程任务切成有退路的段。

**灵感 3（跨体迁移 → 能力比较必须单向保守）**
直觉：通用机器人天然想复用"我在 A 臂/夹爪/工具上学到的能力"到 B 臂/灵巧手/长工具。但实施例不变性从来不是免费假设。把实施例组织成一个偏序 e'≼e（e' 更受限、传感更全、限幅更低）：**向下继承免费，向上重挣收费**——较弱身体继承较强身体的契约总是安全的；反过来必须用转移债务 d(e,e') 折算现场重验样本，且债务只能靠实测偿还，不能靠论证抹掉。工具是实施例的一部分：换工具就是换身体。

**灵感 4（全身耦合 → 合取不安全，必须显式耦合上界或时序分解）**
直觉：基座裕度与臂裕度是两个不同坐标系、不同时间尺度上的量，独立计算后做 AND 是"两个都对，所以整体对"的错觉。正确做法是给出耦合上界 M_wb ≥ M_b + M_a − κ_couple·‖load‖（保守），或干脆分解时序：协调模式做不到就退锁基座模式，再不行退收臂模式。**降级阶梯**本身是通用性的安全表达：能力可以少，退路必须真。

**灵感 5（合流 → 契约门与通用承诺引擎 GCE）**
直觉：第 57 轮证据门 EV-probe*/visit/margin/xmodal/human 在本轮各挂两个新维度：前向挂**能力契约**、后向挂**退出证书**；跨体复用挂**转移债务**，长程任务挂**组合泄漏界**。承诺条件从"∃g: R≤δ_f(g) ∧ 证据门过"升级为"∃g: 前向契约 ∧ 后向契约 ∧ 耦合裕度 ∧ 链契约"，任一缺失就进入 探询→模式降级→绕行→人机交接→安全停。所有新机制仍只经"信念更保守/动作更保守"两条通道起作用。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（实施例条件化能力契约 ECC）** 实施例 e=(𝒦,u_max,𝒮,τ_tool,π_ctrl,m_pay)（运动学类/执行器限幅/传感集/工具/控制器版本/额定负载）。技能 σ、上下文 c=(物体类 o,位姿不确定度 Σ_o,支撑面,人机距离,任务目标)。能力契约 C_σ(e,c)=(Pre,Post,Inv,m,δ_fwd,J_c)，其中配置裕度 m=(m_manip,m_joint,m_force,m_pay,m_fric)，可行域 Φ_σ(e,c)={q:manip(q)≥m_manip ∧ dist(q,∂Q)≥m_joint ∧ 力/负载/摩擦约束成立}。前向语义：∀x∈Pre、位姿误差≤Σ_o，在 e 上执行 σ 保持 Inv、以 ≥1−δ_fwd 到达 Post，且全程 q(t)∈Φ_σ。**契约只在当前构型落入 Φ_σ 时生效**；对任务成功率取平均不得替代对当前构型的检查（尾部分离条款）。

**定义 140（保守实施例迁移 CET）** 偏序 e'≼e ⇔ e' 的力/速限幅不高于 e、传感集不小于 e、控制器为 e 的安全子集、额定负载不大于 e（逐项可验证）。**向下自由**：C_σ(e,c) ∧ e'≼e ⇒ C_σ(e',c)（较弱身体继承较强保证）。**向上收费**：e⋠e' 时定义转移债务 d(e,e')，需现场重验样本 n_re≥N(d,δ) 才能把契约挂到 e'；债务只被实测失败率下调，不被论证下调。工具随 e 变化即视为换体。**负迁移监测**：转移后实测失败率 > δ_fwd+slack 即撤销迁移、回溯标记依赖证书、d 上调。

**定义 141（可退出承诺契约 RCC）** 对原语 a 在状态 x 执行，后继包络 Post(a,x) 含扰动；退出策略 r，可弃安全集 E⊆SafeInv。退出证书 J_x=(r,p_exit,L_exit,E,assumptions)，语义：∀x'∈Post(a,x)∪FaultEnv，r 在 L_exit 步内以 ≥p_exit 到达 E 且不违反硬不变量。**双向门**：承诺 a ⇔ 前向 C_σ 成立 ∧ p_exit≥1−δ_x ∧ 前向/后向失效不独立叠加后 P_trap≤δ_fwd·(1−p_exit)+δ_ind ≤ δ_trap。**承诺深度** d_c(x)=距上次 x∈E 的连续不可逆原语数，硬上限 B_rev(e)；到顶必须 reset checkpoint。**停止不是默认安全**：r 的候选集含"保持抓握待援/受控放下/松手"等，须逐个认证，禁止把 halt 当免检恢复。

**定义 142（全身耦合证书 WCC）** 移动操作状态 x=(x_b,q_arm)，基座动作 u_b、臂轨迹 τ_a。单模块裕度 M_b(x_b,u_b)、M_a(q_arm,τ_a)。耦合算子给出**保守上界** M_wb ≥ M_b + M_a − κ_couple·‖load(τ_a,u_b)‖，其中 load 含反力旋量、质心偏移、功率/热、悬挂激励。耦合认证要求沿整条联合轨迹 M_wb≥θ_wb。**禁止合取替代**：不认证 M_b≥θ ∧ M_a≥θ，只认证 M_wb≥θ。耦合不可界定时按**耦合阶梯**降级：协调 > 锁基座动臂 > 收臂动基座 > 安全停；每次降级写审计并计入 VOI。

**定义 143（技能契约代数 SCA）** 技能链 σ_1;…;σ_n，各带 (Pre_i,Post_i,Inv_i,δ_i)。可组合 ⇔ ∀i，Post_i⊆Pre_{i+1}（容差内）或插入适配技能 σ_g 做桥接；否则在边界插入 **contract checkpoint**（重观测下一技能前置条件）。泄漏界：δ(链)≤Σδ_i+δ_link，δ_link=P(Post_i 未能建立 Pre_{i+1})。不变量保全：∩Inv_i 且任一 Post 不得破坏后续 Inv。**开环契约漂移**：距上次重新接地（观测世界以确认前置条件）的技能数 ≤L_step，超限必须 reground。

**定义 144（通用承诺引擎 GCE / PCE++）** 每检查点：①世界推断（第 57 轮）+ 能力推断（ECC：当前 q 是否在 Φ_σ）；②链组合（SCA：检查 Post→Pre、插入桥接/边界检查、累积 δ_link 与开环步数）；③移动操作先算耦合裕度并选耦合阶梯（WCC）；④接触原语算退出证书与承诺深度（RCC）；⑤跨体/跨工具复用先过 CET（无证书→现场重验或拒）；⑥承诺 ⇔ 前向 ∧ 后向 ∧ 耦合 ∧ 链契约；否则按 VOI_元悲观 探询→模式降级→绕行→人机交接→安全停。VOI 计入"退出价值"与"重新接地成本"。

## 2. 关键算法伪代码（完整版见产物区）

```python
def capability_contract(e, sigma, c, q):            # IP-139: 配置条件化
    Phi = feasible_set(e, sigma, c)                 # manipulability/关节/力/负载/摩擦
    if not inside(q, Phi): return None              # 构型不在可行域 → 无契约
    return Contract(pre=pre(sigma, c), post=post(sigma, c), inv=inv(sigma),
                    margins=phi_margins(q, Phi), delta=delta_fwd(e, sigma, c))

def transfer_contract(C, e_src, e_dst):             # IP-140: 单向保守
    if leq(e_dst, e_src):                           # 更受限 → 免费向下继承
        return C.with_embodiment(e_dst)
    debt = transfer_debt(e_src, e_dst, C.sigma)
    if debt.d > D_MAX: return None                  # 差异过大：拒
    return C.with_debt(debt, n_re=debt.sample_budget)  # 向上：现场重挣

def two_sided_gate(a, x, e, c):                     # IP-141: 前向 ∧ 后向
    Cf = capability_contract(e, a.skill, c, x.q)
    Cx = exit_certificate(a, x, e, c)               # 含 fault envelope 与 halt 候选
    if Cf is None or Cx is None: return 'reject'
    if commitment_depth(x) >= B_rev(e):             # 深度到顶
        return 'need_reset_checkpoint'
    ok = Cf.delta + (1 - Cx.p_exit) <= DELTA_F
    return 'commit' if ok else 'probe_or_degrade'

def coupled_margin(x_b, q_arm, u_b, tau_a):         # IP-142: 禁止合取
    return (base_margin(x_b, u_b) + arm_margin(q_arm, tau_a)
            - kappa_couple * norm(reaction_load(tau_a, u_b)))

def generalist_commit(x, task, e, M, personas, budget):   # IP-144
    for cp in task.checkpoints:
        Cw = world_infer(M, cp)                     # 第 57 轮元推断
        for skill in cp.skills:
            if skill.is_new(e):                     # 跨体/跨工具
                C = transfer_contract(skill.C, skill.source_e, e)
                if C is None or C.debt.remaining > 0:
                    probe_or_reearn(skill, budget)
            if cp.mobile_manip:
                M_wb = coupled_margin(x.b, x.q_arm, cp.u_b, skill.tau)
                if M_wb < THETA_WB: apply_coupling_ladder(cp)   # 协调→锁→收→停
            if skill.level >= L1:                   # 接触/不可逆候选
                r = two_sided_gate(skill, x, e, cp.c)
                if r == 'need_reset_checkpoint': do_reset(skill); continue
                if r != 'commit': probe_or_degrade(skill); continue
        if compose(cp.skills).leak > DELTA_LINK:    # IP-143
            insert_boundary_check(cp)
        if not chain_certified(cp): route = reroute_or_handover(cp); continue
        commit(cp)
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| ECC | O(d_q·|Φ|) 每构型 | O(|Σ_σ|) | 尾部分离、裕度区间保守、δ_fwd 诚实 |
| CET | O(d_e) 判定 + O(n_re) 重验 | O(|契约库|) | 偏序健全、债务只降不升、负迁移检测 |
| RCC | O(|Post|·L_exit) | O(|E|) | 故障包络完备、halt 也须认证 |
| WCC | O(d_load) 每轨迹点 | O(|τ|) | 耦合上界成立、阶梯降级保序 |
| SCA | O(n·|Pre|) | O(|链|) | Post⊆Pre 或桥接、泄漏界诚实 |
| GCE | PCE+ + O(n·(C_ECC+C_RCC+C_WCC)) | PCE+ + O(|链|) | 四条契约全过才承诺、深度上限 |

**正确性定理（GECS 概要）**：在 A33–A40 上加 (A41) 能力契约诚实（裕度区间、配置条件化、尾部分离）；(A42) 实施例偏序健全、转移债务诚实、负迁移一周期内检出；(A43) 退出证书在故障包络上成立、p_exit 为下界、"停"不是免检恢复；(A44) 耦合上界成立、时序分解保安全、组合泄漏界 δ_link 诚实。则：(i) 单步承诺失败 ≤δ_fwd+δ_link+δ_couple，陷阱概率 ≤δ_fwd·(1−p_exit)+δ_ind，沿链按承诺深度上限取联合界；(ii) 交互单调性再强化：迁移只降不升、退出只增退路、耦合只降档、组合只加检查，无升险通道；(iii) GCE 在 k_probes+k_reset+k_reground 内终止于 {承诺, 降级, 绕行, 交接, 安全停}。

## 6. 本轮最大风险

**一句话**：本轮把安全从"世界信念"推进到"能力契约"，最大风险是**契约的假设集本身无人担保**——实施例偏序若判错、故障包络若漏掉一种失效模式、退出策略若只在标称扰动下被验证，那么"前向通过 ∧ 可退出 ∧ 更保守继承"会在一个从未被枚举的失效模式上同时失效；通用机器人越通用，需要枚举的（实施例×工具×物体×接触模式×故障模式）组合越接近无穷，因此契约体系必须坚持"不可逆接触只认本机实挣 + 现场重验 + 承诺深度硬上限"，宁可退回标称已验证的窄契约，绝不把"没见过的失效"当作"不会发生"。

### IP-139 ECC（配置条件化能力契约）

```python
def capability_contract(e, sigma, c, q):
    """能力不是标量，而是当前构型 q 处才生效的契约。"""
    Phi = feasible_set(e, sigma, c)        # manipulability/关节极限/力/负载/摩擦
    if not inside(q, Phi):
        return None                        # 构型越界：该技能此刻不成立
    return Contract(
        pre=pre(sigma, c), post=post(sigma, c), inv=inv(sigma),
        margins=phi_margins(q, Phi),       # 到各约束边界的距离
        delta=delta_fwd(e, sigma, c),      # 前向失败概率上界（配置条件化）
        src=e.fp)

def phi_margins(q, Phi):
    # 全部用区间/下界计算，禁止用任务平均成功率替代尾部分离检查
    return dict(
        m_manip=yoshikawa(q) - PHI_MIN,
        m_joint=min_joint_clearance(q),
        m_force=force_ceiling(e) - worst_contact_force(q, c),
        m_pay=e.m_pay - payload_estimate(c),
        m_fric=friction_cone_margin(q, c))

def tail_guard(Cs, q):
    """任务级均值证书不得替代当前构型：任何 m<0 即拒。"""
    return all(m >= 0 for m in Cs.at(q).margins.values())
```

### IP-140 CET（保守实施例迁移与转移债务）

```python
def leq(e_dst, e_src):
    """e_dst ≼ e_src：更受限/传感更全/控制器更保守/负载更小。"""
    return (e_dst.u_max <= e_src.u_max and e_dst.m_pay <= e_src.m_pay
            and e_src.𝒮 <= e_dst.𝒮
            and controller_is_safe_subset(e_dst.π_ctrl, e_src.π_ctrl))

def transfer_contract(C, e_src, e_dst):
    if leq(e_dst, e_src):
        return ('free_downgrade', C.with_embodiment(e_dst))   # 向下免费继承
    debt = transfer_debt(e_src, e_dst, C.sigma)              # 能力差异→债务
    if debt.d > D_MAX:
        return ('reject', 'embodiment_too_far')              # 差异过大：不迁
    return ('reearn', C.with_debt(debt, n_re=debt.sample_budget))

def settle_debt(C, realized):
    """债务只被实测下调，不被论证下调。"""
    if realized.fail_rate > C.delta + SLACK:
        revoke(C); raise_debt(C); flag_negative_transfer(C)  # 负迁移回溯
    else:
        C.debt = max(0, C.debt - realized.information_gain)
    return C

def tool_change(e, new_tool):
    e2 = e.with_tool(new_tool)   # 工具是实施例的一部分：换工具=换身体
    return e2, transfer_contract_for_all(e, e2)
```

### IP-141 RCC（可退出承诺、承诺深度）

```python
def exit_certificate(a, x, e, c):
    """后向契约：不是"能不能做"，而是"做坏了能不能出来"。"""
    succ = bounded_successors(a, x, disturbance=c.sigma)   # 含扰动包络
    candidates = [hold_and_call, controlled_lower, release, undo, retreat]
    best = None
    for r in candidates:                                   # halt 不是免检恢复
        p, L, E = certify_recovery(r, succ, hard_inv(e), fault_env=c.fault_env)
        if E is not None and (best is None or p > best.p_exit):
            best = Exit(r=r, p_exit=p, L_exit=L, E=E)
    return best if best and best.p_exit >= 1 - DELTA_X else None

def commitment_depth(x):
    return x.steps_since_last_disposable        # 上次 x∈E 以来连做的不可逆原语数

def two_sided_gate(a, x, e, c):
    Cf = capability_contract(e, a.skill, c, x.q)
    if Cf is None: return ('reject', 'capability_not_in_config')
    Cx = exit_certificate(a, x, e, c)
    if Cx is None: return ('reject', 'no_exit_certificate')
    if commitment_depth(x) >= B_rev(e):
        return ('need_reset_checkpoint', do_reset(a.skill))
    p_trap = Cf.delta * (1 - Cx.p_exit) + DELTA_IND   # 前向失败∧无处可退
    if Cf.delta + p_trap > DELTA_F:
        return ('probe_or_degrade', better_mode(a, Cx))
    return ('commit', Cf, Cx)

def do_reset(skill):
    """到顶强制回到可弃状态：放下/松开/重新观测，再继续。"""
    return reset_sequence(place_or_release=skill.object, reobserve=True)
```

### IP-142 WCC（全身耦合证书与耦合阶梯）

```python
def coupled_margin(x_b, q_arm, u_b, tau_a):
    """禁止 M_b≥θ ∧ M_a≥θ 的合取；只认显式耦合上界。"""
    load = reaction_load(tau_a, x_b, u_b)   # 反力旋量+质心偏移+功率/热+悬挂激励
    return base_margin(x_b, u_b) + arm_margin(q_arm, tau_a) \
           - kappa_couple * norm(load)

def coupling_ladder(cp, x):
    """能力可以少，退路必须真：逐级降级直到耦合可界。"""
    for mode in ('coordinated', 'base_locked_arm_move',
                 'arm_stowed_base_move', 'safe_stop'):
        apply_mode(mode)
        if all(coupled_margin(*state_of(x, mode)) >= THETA_WB
               for _ in trajectory(cp, mode)):
            audit.log(('coupling_degrade', mode)); return mode
    return 'safe_stop'
```

### IP-143 SCA（技能契约代数与组合泄漏）

```python
def compose(chain):
    total_delta, leak, horizon = 0.0, 0.0, 0
    for s1, s2 in zip(chain, chain[1:]):
        if not subset(s1.post, s2.pre, tol=EPS_PRE):
            g = adapter(s1, s2)                       # Post_i ⊄ Pre_{i+1}
            if g is None:
                leak += leak_bound(s1, s2)            # 无法桥接：泄漏入证书
                chain = insert(chain, boundary_check(s2))
            else:
                chain = insert(chain, g)
        total_delta += s1.delta
        horizon += 1
        if horizon > L_STEP:
            chain = insert(chain, reground(s2.pre))   # 开环契约漂移上限
            horizon = 0
    return ChainCert(delta=total_delta + leak, leak=leak,
                     invariants=intersect_invariants(chain),
                     chain=chain)

def boundary_check(skill):
    """在技能边界重观测下一技能的前置条件，抓静默前置违反。"""
    return Observe(skill.pre, must_hold=True)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| ECC | O(d_q·\|Φ\|)/构型 | O(\|Σ_σ\|) | 尾部分离、裕度区间保守、δ_fwd 诚实（A41） |
| CET | O(d_e)+O(n_re) | O(\|契约库\|) | 偏序健全、债务只降、负迁移检出（A42） |
| RCC | O(\|Post\|·L_exit·\|r\|) | O(\|E\|) | 故障包络完备、p_exit 下界、halt 也认证（A43） |
| WCC | O(d_load·\|τ\|) | O(\|τ\|) | 耦合上界成立、阶梯保序（A44） |
| SCA | O(n·\|Pre\|+n·L_STEP) | O(\|链\|) | Post⊆Pre/桥接、δ_link 诚实（A44） |
| GCE | PCE+ + O(n·(C_ECC+C_RCC+C_WCC)) | PCE+ + O(\|链\|) | 四契约全过才承诺、深度上限 |

**正确性定理（Generalist Embodiment Contract Soundness, GECS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 能力契约诚实：裕度以区间/下界计算，契约按当前构型生效，任务均值不得替代尾部分离，δ_fwd 为配置条件化上界；**(A42)** 实施例偏序健全：e'≼e 的逐项判定可验证，转移债务估计诚实且只被实测下调，负迁移在一个任务周期内检出并回溯；**(A43)** 退出证书诚实：r 在故障包络 FaultEnv 上以 ≥p_exit 到达 E，"停"作为候选恢复动作同样需认证，承诺深度硬上限 B_rev 不可放宽；**(A44)** 耦合上界 M_wb≥M_b+M_a−κ_couple‖load‖ 成立，时序分解（锁基座/收臂）保安全，组合泄漏界 δ_link 与重接地上限 L_step 诚实。则：

1. **契约承诺健全性**：单步前向失败 ≤δ_fwd；组合链失败 ≤Σδ_fwd+δ_link；陷阱概率 ≤δ_fwd·(1−p_exit)+δ_ind；全身失败 ≤P(耦合上界失效)+θ_wb；沿链按承诺深度与重接地上限取联合界。
2. **交互单调性再强化**：CET 只允许向下免费、向上收费（从不降低要求）；RCC 只增加退路（从不减少检查）；WCC 只降档（协调→锁基座→收臂→停）；SCA 只增加边界检查/重接地；不存在"因为更通用/更灵活所以更敢赌"的通道。
3. **终止性**：GCE 在 k_probes+k_reset+k_reground 内终止于 {承诺, 模式降级, 绕行, 人机交接, 安全停}。
4. **部署界**（对检查点与技能链取联合界）：

```
P_safe ≥ 1 − Σ_cp [ δ_fwd + δ_link + δ_couple + δ_fwd·(1−p_exit) + δ_ind ]
             − P(能力契约假设漏项) − P(实施例偏序判错)
             − P(故障包络漏失效模式) − P(耦合上界失效) − P(重接地超时)
```

关键：**通用性不等于能力普遍**——ECC 把能力钉在当前构型与当前实施例上，均值证书不能替代尾部检查；**承诺必须是双向的**——RCC 用退出证书与承诺深度把"走进去出不来"变成可拒绝的契约；**跨体复用必须单向保守**——CET 让弱体免费继承、强体重挣，负迁移回溯；**全身必须显式耦合**——WCC 用耦合上界与阶梯替代合取；**长程必须能重新接地**——SCA 用泄漏界与边界检查抓静默前置违反。六者只经"信念更保守/动作更保守"两条通道起作用。

云边协议 CEB++ → **CEB+++**：云端下发**能力契约库、实施例偏序表与故障包络分层样本**（带版本与适用域）；边端回传构型裕度直方图、退出失败事件、耦合违约与组合泄漏统计，作为云端契约收紧与偏序修正的依据。与第 57 轮一致，**契约库与偏序表的更新同样走隔离区**：先在影子模式跑尾部分离回归（边界假承诺不升 ∧ 向下继承零失效 ∧ 负迁移检出率不降），通过后才接管承诺判定。第 57 轮"一切判定器走隔离"在本轮推广为"**一切能力声明都要挂配置条件、退出条件与实施例偏序**"。

## 6. 本轮最大风险

**一句话**：本轮把安全从"世界信念"推进到"能力契约"，最大风险是**契约的假设集本身无人担保**——实施例偏序若判错、故障包络若漏掉一种失效模式、退出策略若只在标称扰动下被验证，那么"前向通过 ∧ 可退出 ∧ 更保守继承"会在一个从未被枚举的失效模式上同时失效；通用机器人越通用，需要枚举的（实施例×工具×物体×接触模式×故障模式）组合越接近无穷，因此契约体系必须坚持"不可逆接触只认本机实挣 + 现场重验 + 承诺深度硬上限"，宁可退回标称已验证的窄契约，绝不把"没见过的失效"当作"不会发生"。
