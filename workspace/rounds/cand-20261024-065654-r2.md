# 第 8 轮 · CATCH：最后 3 厘米是力控问题，世界模型只当裁判，自主导航先剪掉

> 检索/复核日期：2026-10-24（UTC）。状态文件延续第 7 轮 PILOT；本轮是外部灵感循环第 2 轮，三个词是「力控」「世界模型」「自主导航」。我先各自钉到本轮核实到的官方事实，再给主判断：**评测的瓶颈已经从"放哪里"（几何）转到"怎么接触、怎么确认"（接触动力学）；接口没有力/触觉通道，但有三个免费力代理（运动停滞、夹爪孔径残差、视觉滑移），足够做一层 30Hz 的接触反射；世界模型不该当演员，应该当 30Hz 的潜在空间裁判；自主导航在桌面任务里没有得分杠杆，只保留桌面坐标系锚定和传送带目标预测。**

## 0. 本轮先纠四个错（比新增一个点子更重要）

### 0.1 排名是"成功率优先、步骤分只做 tiebreak"

参赛手册原文（中英文一致）：*"实时榜单按 32 个任务的总平均成功率进行排序，成功率相同时按总平均步骤分排序，若仍相同，则提交日期较早的模型排序靠前。"*（[S2][S3]）

第 7 轮把"成功率与步骤分综合排序"当成第二主目标，方向没错但权重错了：**步骤分只在并列时有用，平时是诊断量**。这直接淘汰"部分分 farming"：一个 episode 做完 90% 步骤但终局失败，对成功率是 0，对排名只在极端并列时有用。所有资源应压到"让 episode 完整成功"，而不是"多拿几步分"。

### 0.2 占位榜不能证明"失败发生在最后一步"

我拉了 `leaderboard_data.json`（[S9]）：`generated_from: gen_leaderboard.py`，8 个模型 × 32 任务，任务级 success 与 step 的相关系数 = **1.000**——脚本按线性关系生成。第 7 轮用"步骤分平均比成功率高 8.6pp"推断"大部分失败发生在后段/最后一步"，这个证据不成立，**撤回**。终局假设改由三件事支撑：(a) 成功=所有步骤完成的评分结构；(b) 复利算术（§3）；(c) 32 个终局步骤里 20 个是接触密集型（§2）。占位榜只保留一个用途：任务难度排序的弱先验，且必须标注"生成数据"。

### 0.3 时间预算比第 7 轮说的宽得多

第 7 轮用 HangCup 的 5.9s 代表全部任务；实际按 HF collection 的 `totalEpisodes` 与 `numRows` 算（[S5]）：

- 32 任务平均 episode **18.4s（554 帧）**；最短 HangCup 6.2s（186.5 帧），最长 ToolboxStorage 37.6s（1,127 帧）。
- 180s 限时是最长演示的 **4.8×**、平均的 **9.8×**、HangCup 的 **29×**。

这意味着接触重试、缓放、settle 校验、甚至 1–2 次重抓都在预算内；第 7 轮的"SVL 每点多花 1–3s"完全可承受。反过来，**不要**把 180s 当成"可以慢慢做"：评测是 32 任务 ×10 次，超时一次就是一次失败，守卫仍要保留。

### 0.4 "力控"在这个接口里没有力通道

提交接口（[S4]）的观测只有：四路 RGB（左右高位 + 左右腕部，480×640）、双臂 7 维关节、双臂 EE 位姿（base 系，xyz+rpy）、左右夹爪开度、15 维下半身、语言字符串。动作只有：关节或 EE 位姿（二选一）、左右夹爪目标、`action.pivot`（7 维下半身/ pivot 目标）。

Dex1-1 夹爪本身有 **5–120N 可调夹持力、90mm 行程、0.1mm 分辨率、电机力矩反馈**（[S12]），但评测接口**不暴露力矩、电流、触觉**。所以"力控"不能写成"读六维力/触觉做阻抗控制"，只能是**隐式力控**：从" commanded vs achieved "的差异里反推接触。这既是约束，也是本轮的创新入口。

（数据规模精确值：**33,276 episodes / 18,282,246 帧 / 169.3h**；32 个数据集 `lastModified` 均为 2026-10-14。不是"约 33k"，也不是"每个任务只有几百条"。）

## 1. 三个词，各自钉到事实上

### 1.1 力控：没有力传感器，但有三个免费力代理

我把 HangCup 与 StackBowls 的第一个 parquet 文件拉下来做了动作-状态对齐分析（各 10 万+ 帧；[S6][S7]），得到三个可用信号：

| 信号 | 定义 | 实测（HangCup / StackBowls） | 用途 |
|---|---|---|---|
| **运动停滞** MDCD | 指令仍在运动，但观测 EE 速度塌到阈值以下 | 夹爪闭合期间停滞帧占 16.2% / 4.1–4.7%；最长连续停滞 55 帧（1.8s）/ 27–32 帧（0.9–1.1s） | 接触、卡住、插入到位、抓取稳定 |
| **夹爪孔径残差** | `g_cmd − g_obs`，闭合指令下实际开口停在物体宽度 | `g_cmd<0.5` 时实际开口：HangCup 0.13（细杯柄）；StackBowls 0.25–0.31（碗沿），p10–p90 0.14–0.39 | 物体宽度、夹持预载、是否夹到 |
| **视觉滑移** | 腕相机中物体相对夹爪的位移 | 需在腕部图上跟踪；数据里可离线挖 | 夹持力不足、掉落前兆 |

**反例（重要）**：EE 位置误差 `||x_cmd − x_obs||` 均值 1.2–1.9cm、p95 1.7–4.0cm，看起来很大，但它主要来自"动作是下一帧目标"的滞后与平滑，不是接触力。**不要把绝对位置误差当力用**；要用"速度亏损/停滞"和"孔径残差"，这两个对滞后不敏感。这个负结果能帮我们省掉一条错误路线。

### 1.2 世界模型：别当演员，当裁判

2026 年的证据已经把世界模型的角色分得很清楚：

- **当数据引擎**：GigaBrain-0 用 Real2Real、view transfer、human transfer 生成数据，50 条真机演示 + 外观迁移把叠衣成功率推到 80%+；GigaBrain-0.7 是 Apache-2.0、3.5B/4B、37k 小时预训练（[S16][S17]）。这条线**已被证明**，但对 UniBot 的背景轴是"高射炮打蚊子"：背景轴只是换桌布颜色/纹理，分割+色彩/纹理替换就够了，不值得训一个视频世界模型。
- **当运行时裁判**：Foresight 用 action-conditioned WM latent 做长程失败检测（LIBERO-Long 0.94 balanced accuracy，真机验证）；ContactGuard 在接触前用预测的 post-contact latent 做 abort；FARM 用冻结 WM 的 predictive state + 33,985 参数 readout，AUROC 85.68、延迟 0.2256ms；MAIA 用 vision-action-force WM 做异常预判，异常感知动作选择把成功率 52.6%→61.5%（不重训策略）；FoMo-FD 只用成功演示 + conformal calibration，96.6% FDR @1.3% FAR（[S18]–[S22]）。这条线**便宜、策略无关、直接命中人为干扰与假完成**。

所以本轮的选择是**非对称混合**：**VLA 当演员（慢），接触反射当脊髓（快），潜在世界模型当裁判（30Hz）**。世界模型不生成动作、不生成数据，只回答"刚才这一下，物理上对不对"。

### 1.3 自主导航：先剪掉

我查了 HangCup 的 `action.pivot` / `action.base_command` 统计（[S6]）：`vx/vy` 的 q99 ≈ 0，`height` 恒为 0.7384m，`angle_z` 的 q99 ≈ 0.002 rad/s——**演示里基座是静止的**。32 个任务全是桌面操作，没有导航任务；唯一"动"的是 T24 传送带上的食物（移动目标拦截），不是机器人导航。

第 7 轮把"FLEET 第六轴"降级为工程检查单是对的；本轮进一步把"自主导航"从研究轴里剪掉，只保留三个残片：

1. **TFA 桌面坐标系锚定**：用桌面平面 + 桌沿/角点估计 table frame，把目标从 table frame 转到 base frame；基座/腰部有小漂移或人碰了桌子时，重新锚定即可。演示基座静止，所以这是安全网，不是主攻。
2. **MTP 移动目标预测**：T24 用光流/常速度模型预测 0.3–0.5s 后的位置，在拦截点抓；这是"预测"，不是"导航"。
3. **主动腕部重观察**：目标被遮挡/深度无效时，腕部侧移 10cm、俯仰 20° 再看一眼；不需要动基座。

如果官方 human 备注里的"动底座"真的是移动机器人基座（T11 的备注有歧义），正确响应也是**检测基座位姿突变 → 暂停 → 重估 table frame → 继续**，而不是"自主导航到别处"。这条判断能省下大量时间。

## 2. 主判断：最后 3 厘米是接触动力学，不是几何

第 7 轮解决的是"放哪里"：槽位→锚点→6D 位姿→落点闭环。本轮解决的是"怎么接触、怎么确认"：

- 32 个终局步骤里，**20 个是接触密集型**（插入/拔出/闭合/拉链/拧盖/倾倒/按压/折叠），只有 12 个是纯放置/堆叠（§3.2 表）。
- 纯视觉策略能看见"插头在插座上方"，但看不见"插头是否插到底"；能看见"盖子合上"，但看不见"卡扣是否咬住"；能看见"拉链拉到头"，但看不见"齿是否啮合"；能看见"碗放上去了"，但看不见"0.5s 后会不会滑"。
- 接口没有力/触觉，所以这些"看不见"只能靠**运动/孔径/滑移的接触代理 + 潜在世界模型的惊讶度**来补。

一句话：**第 7 轮是"几何的最后一公里"，本轮是"接触的最后一毫米"。** 两者不是替代，是串联：PGL/OPT 给出目标，CATCH 负责接触与确认。

## 3. 复利算术：<30% 不是"某个轴弱"，是每步 p 不够

### 3.1 步骤数分布与复利

32 任务共 **94 个评分步骤**，平均 **2.94 步/任务**（2 步 11 个、3 步 14 个、4 步 5 个、5 步 2 个；步骤权重来自第 7 轮抓取的 `info.json`，任务语义本轮用 challenges.html 复核）。若每步独立、成功率 p：

| p | 2 步 | 3 步 | 4 步 | 5 步 | 按任务数加权 |
|---:|---:|---:|---:|---:|---:|
| 0.65 | 42.3% | 27.5% | 17.9% | 11.6% | **30.1%** |
| 0.70 | 49.0% | 34.3% | 24.0% | 16.8% | **36.7%** |
| 0.75 | 56.3% | 42.2% | 31.6% | 23.7% | **44.7%** |

**榜首 <30% 对应 p≈0.65–0.67**；要上 40%，p 要到 0.72–0.74。p 每 +5pp，总分约 +6.6pp；p 每 +10pp，总分约 +14.6pp。这比"单轴 +10pp"（总分 +2pp，因为 5 轴各 20%）高一个量级——**接触层跨任务、跨轴、跨步骤起作用**。

### 3.2 接触密集型终局步骤：20/32

| 类型 | 任务 | 数量 |
|---|---|---:|
| 插入/插接 | T10 插头、T13 试管、T21 盘子、T25 纸杯、T26 网线、T12 钥匙/锁环 | 6 |
| 拔出/取出 | T05 拔网线、T11 挑电池、T30 拔图钉（前置） | 3 |
| 闭合/卡扣/拉链 | T09 锁箱、T17 文具盒、T18 书包、T19 拉链、T23 球拍套、T28 耳机盒、T29 手机盒、T31 文具袋 | 8 |
| 拧盖/倾倒/注射 | T14 药瓶、T32 针管 | 2 |
| 按压/铰链/折叠 | T07 相框支架、T16 毛巾 | 2 |
| **合计** | | **20** |

纯放置/堆叠 12 个：T02、T03、T04、T06、T08、T15、T20、T22、T24、T27、T01（挂钩，归放置）、T30（终局是放回盒子；拔钉算前置）。

**增益上界（可证伪）**：

- 若接触层只提升终局一步：`(20/32) × Δ_c × p^(n−1)`；在 p=0.65、n≈3、Δ_c=15pp 时约 **+3.3pp**。
- 若接触层提升每个接触相位（抓取、插入、闭合、释放），每任务 2–4 步受益：约 **+6–9pp**。
- 加上 ALSM 对 20% 人为干扰的恢复（假设恢复 25% 的原本失败）：**+3–5pp**。
- 加上 SNL 对背景/干扰物轴的归一化：**+2–4pp**。
- 合计目标 **+6–10pp**，保守 **+3–5pp**；若调试槽实测终局步 <5pp，回退到"SSG+SNL+ALSM"三件套。

### 3.3 为什么不是"再补一个泛化轴"

五轴各占每任务 10 次中的 2 次（20%）。单轴 +10pp 只值总分 +2pp；而接触层是 32 任务共用、五轴共用的资产。**同样的 10pp，放在接触层是 3–5 倍杠杆。** 背景轴/干扰物轴用 SNL 的便宜手段补，不用世界模型视频生成；人为干扰轴用 ALSM + SSG 回滚补；未见物品轴用几何 affordance 补。预算按杠杆排序，而不是按轴平均。

## 4. 方案：CATCH 三层 + SNL + TFA/MTP

```text
语言(160 条复述) → SSG 步骤图（含接触相位/谓词/回滚）
                         │
        ┌────────────────▼────────────────┐
        │ 慢：VLA（WLA-1.0-Base + LoRA）   │  4 路 RGB + SNL 归一化视图 + 锚点
        │     输出接近轨迹 + 终局目标       │
        └────────────────┬────────────────┘
                         │ 进入接触区（<3cm）
        ┌────────────────▼────────────────┐
        │ 快：接触反射（30Hz）              │
        │  SEC 停滞/孔径/滑移 → 接触状态机  │
        │  SAG 孔径预载 + 滑移自适应        │
        │  CIP 插入/拔出/拧盖/倾倒/拉链/落放 │
        └────────────────┬────────────────┘
                         │ 每步/终局
        ┌────────────────▼────────────────┐
        │ 裁判：ALSM 潜在惊讶 + TSC 终局分类 │
        │  惊讶/停滞/谓词回退 → 暂停/重观察  │
        │  → SSG 回滚 → 重试（≤2 次）        │
        └────────────────┬────────────────┘
                         │
        TFA 桌面锚定（基座/桌子漂移）  MTP 传送带拦截（T24）
```

**与现有方案的区别**：纯 VLA 没有力通道，接触失败不可见；纯世界模型没有 30Hz 反应，且像素预测慢；纯脚本控制不会泛化。CATCH 把三者放到各自最强的时间尺度：VLA 3.75–7.5Hz（chunk 8–16）、反射 30Hz、裁判 30Hz。**不是更大的模型，是更对的闭环。**

## 6. 风险与合规（先立后破）

- **接触代理误报**：停滞也可能是策略故意停。用"指令仍在动 + 夹爪闭合 + 腕部视觉"三条件与滞回，阈值按任务从演示校准；误报率 >10% 就只保留孔径残差。
- **孔径预载的力不可控**：接口只给目标开口，内部力限未知。δ 从小往大试，滑移才加；单任务上限 8mm；调试槽先验证不夹碎药瓶。
- **ALSM 域差/误报**：潜在惊讶可能被背景/光照主导。用物体/容器为中心的 crop latent，per-task conformal，阈值保守；误报只触发"重观察"不触发"终止"。
- **立体深度标定**：头 stereo 已 rectified，但 baseline/焦距未公开；用桌面平面 + EE 高度自标定尺度，深度只用于相对量（宽度/插入深度），不用于绝对米制。
- **调试槽稀缺**：每个大版本最多 1 槽；T10（插入）、T27（落放）、T19（拉链）三选一，按假设的杠杆排序。
- **单模型审计**：学习组件只有 WLA + 辅助头 + ALSM；SEC/SAG/CIP/SSG/SNL/TFA/MTP 都是确定性代码，全部写进模型卡披露。
- **外部数据**：手册 2.2 之后未公开；L2L 默认 OFF，邮件确认后再开。
- **统计噪声**：320 trials，p=0.25 时 SE≈2.4pp；+5pp 才敢说有效；用配对种子/bootstrap，不用单次调试槽的 10 次结果下全局结论。
- **占位数据**：不用于方案选择；只用于任务难度排序的弱先验。

## 7. 一句话押注

**把"最后 3 厘米"当成接触动力学问题：用停滞/孔径/滑移三个免费力代理做 30Hz 接触反射（SEC+SAG+CIP），用成功演示训练的行动条件潜在世界模型做 30Hz 惊讶裁判（ALSM+TSV），用 SNL 打背景/干扰物/未见物品三轴；自主导航剪掉，只留桌面锚定与传送带拦截——这是在"成功率优先"的排名规则下，跨 32 任务、跨 5 轴、单位算力回报最高的一注。**

## 2. 评分算术：为什么是"接触"而不是"更多数据"

### 2.1 成功率的复利

32 任务共 94 个评分步骤（第 7 轮抓取的 `info.json` `score_steps`；任务语义本轮用 challenges.html 复核）：

| 步骤数 | 任务数 | 任务 |
|---|---:|---|
| 2 | 11 | T01,T02,T03,T05,T08,T14,T19,T23,T24,T30,T32 |
| 3 | 14 | T04,T06,T07,T10,T11,T12,T13,T20,T21,T25,T26,T27,T29,T31 |
| 4 | 5 | T09,T15,T18,T22,T28 |
| 5 | 2 | T16,T17 |
| **合计** | **32** | **94 步，平均 2.94** |

若每步独立、成功率 p，按任务数加权：

| p | 2 步 | 3 步 | 4 步 | 5 步 | 加权 |
|---:|---:|---:|---:|---:|---:|
| 0.60 | 36.0% | 21.6% | 13.0% | 7.8% | **24.4%** |
| 0.65 | 42.3% | 27.5% | 17.9% | 11.6% | **30.1%** |
| 0.70 | 49.0% | 34.3% | 24.0% | 16.8% | **36.7%** |
| 0.75 | 56.3% | 42.2% | 31.6% | 23.7% | **44.7%** |
| 0.80 | 64.0% | 51.2% | 41.0% | 32.8% | **52.5%** |

**读法**：<30% 对应 p≈0.65；40% 对应 p≈0.72–0.74。p 每 +5pp，总分约 +6.6pp；每 +10pp，约 +14.6pp。**单轴 +10pp 只值 +2pp**（五轴各 20%），所以接触层的杠杆是单轴改造的 3–5 倍。

### 2.2 终局权重只是诊断量

第 7 轮算出终局步骤合计 **1,275/3,200 = 39.8%**。在"成功率优先"的规则下，这个数字**不再是资源分配依据**（步骤分只做 tiebreak），但仍是诊断量：它告诉我们"如果只看步骤分，钱丢在哪一步"；真正的资源依据是"这一步是否卡住整个 episode 的成功"。

### 2.3 20/32 个终局步骤是接触密集型

### 2.4 增益上界（可证伪）

```text
终局-only：  (20/32) × Δ_c × p^(n−1)
             p=0.65, n=3, Δ_c=0.15 → 0.625×0.15×0.4225 ≈ 3.96pp
全接触相位： 每任务 2–4 步受益；Δ_c=0.15, n=3, 2.5 步 → 0.625×0.15×2.5×0.4225 ≈ 9.9pp（上界）
ALSM 恢复：  0.20 × 0.70 × 0.25 ≈ 3.5pp（人为干扰失败率 70%、恢复 25%）
SNL：        0.40 × 0.30 × 0.20 ≈ 2.4pp（背景+干扰物，失败率 30%、恢复 20%）
合计目标：   +6–10pp；保守 +3–5pp
```

**注意**：这些上界不可直接相加（同一 trial 可能同时受益/重叠）；用消融和调试槽验证边际增益。

320 trials；p=0.25 时二项 SE≈2.42pp，p=0.30 时≈2.56pp。但 32 个任务各自 10 次，任务级聚类会放大方差；**不要用单任务 10 次的结果下全局结论**。用配对种子、按任务分层 bootstrap；调试槽只做"方向性"判断（+10pp 才敢进计分跑），计分跑才做"排位性"判断。

## 4. 接触层：SEC + SAG + CIP

### 4.1 SEC：三个免费力代理 → 接触状态机

**输入**：`x_cmd(t)`（我们刚发的 EE 目标/上一 chunk 的当前步）、`x_obs(t)`（观测 EE 位姿）、`g_cmd(t)`、`g_obs(t)`、腕部图 `I_w(t)`。

**信号**：

```text
v_cmd = ||x_cmd(t) − x_cmd(t−1)|| / dt
v_obs = ||x_obs(t) − x_obs(t−1)|| / dt
deficit = max(0, (v_cmd − v_obs) / (v_cmd + ε))          # 速度亏损
stall   = (v_cmd > 0.01 m/frame) and (deficit > 0.6)      # 指令在动、实际不动
r_grip  = g_cmd − g_obs                                   # 孔径残差（闭合时>0）
slip    = ||flow_object(I_w) − flow_gripper(I_w)|| > τ_s  # 腕图中物体相对夹爪滑移
```

**状态机**（30Hz，滞回 2–3 帧）：

```text
FREE     : 无接触
CONTACT  : r_grip > 0.05 或 (stall and g_obs < 1.5)
JAM      : stall 连续 ≥3 帧，且 v_cmd 指向障碍
SLIP     : slip 连续 ≥2 帧，且 g_obs 接近物体宽度
SEATED   : 插入方向 v_obs→0 且深度/视觉显示到位；或 TSC 判真
LOST     : 物体不在夹爪（滑移后脱离）
```

**校准**：从演示里按任务统计 `deficit`、`r_grip` 的分布；取 95 分位做阈值；用夹爪闭合事件与"物体随动"做弱标签。**离线可做**：在 33k 演示上回放状态机，测接触段/自由段的分离度（AUC）、误报率、提前量。

**为什么不用绝对位置误差**：实测 EE 位置误差 1.2–1.9cm 主要来自动作滞后；把它当力会把"正常运动"误判为"接触"。速度亏损对滞后不敏感。

### 4.2 SAG：孔径预载 + 滑移自适应

**原理**：Dex1-1 的夹持力不可直接指令，但"目标开口 < 物体宽度"会让夹爪在物体上产生预载；预载越大，夹持力越大（直到内部力限）。用物体宽度 `w`（立体深度/分割）与 δ 控制：

```python
def grasp_with_preload(obj, task):
    w = stereo_width(obj)                  # 米/厘米，按标定
    deltas = task.delta_ladder            # e.g. [2,3,5,8] mm
    for d in deltas:
        cmd_grip(w - d)
        close_until_stall(timeout=0.6s)
        if not slip_detected(window=0.3s):
            return True
        # 滑移 → 加 δ（更用力）；到上限仍滑 → 重抓/换抓点
    return False
```

**δ  ladder（建议初值，待调试槽校准）**：

| 物体 | δ 初值 | 上限 | 备注 |
|---|---:|---:|---|
| 刚性工具/书/盒子 | 3mm | 8mm | 重、摩擦大 |
| 纸杯/塑料碗 | 2mm | 5mm | 易变形，别夹扁 |
| 药瓶/试管 | 1.5mm | 3mm | 易碎/易滑 |
| 插头/网线 | 2mm | 5mm | 小、滑 |
| 毛巾/布料 | 4mm | 10mm | 变形大，靠视觉滑移 |

**滑移检测**：腕部图中目标物体关键点相对夹爪的位移；或用 EE 与物体 6D 位姿的相对变化。没有力传感器时，这是"夹持力够不够"的唯一直接证据。

### 4.3 CIP：接触原语库（30Hz，确定性）

#### 4.3.1 插入（T10/T13/T21/T25/T26/T12/T32）

```python
def insert_until_seated(axis, hole_pose, max_retry=3):
    align(hole_pose)                         # 视觉/深度对齐插入轴
    for r in [0.002, 0.004, 0.006]:          # 螺旋搜索半径（米）
        for p in spiral(r, n=8):
            move_delta(p)                    # 平面内微移
            if sec.state == JAM:
                back_off(0.003); break
        push_along(axis, 0.0015)             # 轴向 1.5mm
        if sec.state == SEATED or tsc.seated():
            return verify_pull(axis, 0.002)  # 轻拉验证
    return False
```

- **对齐**：深度图拟合孔/槽平面 + 腕图边缘；插头/网线用"插头前端—孔口"相对位姿。
- **搜索**：螺旋/锯齿；每步 1–2mm；JAM 就退 3mm 再对齐。
- **到位**：深度/视觉显示插头齐平；或轴向推进后 `v_obs→0` 且轻拉不脱。
- **失败**：重抓（换夹持点/角度），最多 3 次；仍失败则回 SSG 上一步。

#### 4.3.2 拔出（T05/T11/T30 图钉）

```python
def extract_along(axis, max_force_proxy=0.8):
    grasp_with_preload(obj)
    for step in range(0, 40):
        move_along(axis, 0.5mm)              # 逐步拉
        if sec.state == LOST: return False
        if sec.state == FREE:                # 突然松脱
            return verify_in_gripper(obj)
        if sec.deficit > max_force_proxy:    # 卡住
            wiggle(perp=0.5mm); back_off(0.2mm)
    return False
```

- 拔网线：先按住网口（另一只手/同手固定），再沿轴拉；检测"啪"一声的突然加速（松脱）。
- 挑电池：薄边夹取，先横向松动再向上；孔径预载防滑。
- 拔图钉：夹住钉帽，先旋转再拔；TSC 检查钉子是否在夹爪里。

#### 4.3.3 拧盖/倾倒（T14/T32）

```python
def unscrew_until_free(cap, max_turns=2.5):
    grasp_with_preload(cap, delta=1.5mm)
    for turn in range(int(max_turns*12)):
        rotate_wrist(yaw=30deg); push_down(0.5mm)
        if cap_rotates_in_wrist_image(): pass
        else: increase_preload()
        if cap_lifted(): return True
    return False
```

- 拧盖：腕部 yaw 旋转 + 下压；腕图检测盖子相对瓶身的旋转；1–2 圈后上提。
- 倾倒：倾斜到 60–90°，腕/头图检测药片流出；不下则轻敲；按目标数量停。
- 注射：针管插入小杯 → 拉/推活塞（如果夹爪能夹住活塞）；用视觉液面/水流验证。

#### 4.3.4 拉链（T18/T19/T23/T31）

```python
def zip_until_closed(tab, track):
    grasp(tab)
    for step in range(0, 60):
        pull_along(track, 2mm)
        if sec.state == JAM:
            wiggle(perp=1mm); back_off(1mm)
        if tsc.zipper_closed(): return True
        if sec.state == LOST: regrasp(tab)
    return False
```

- 拉链是"齿啮合 + 拉力"的接触问题；纯视觉只能看到"拉头到没到头"，看不到"齿有没有咬住"。
- 用 TSC 的"闭合"分类 + 拉头位置 + 拉力代理（停滞/亏损）三重判断。
- 失败时退 2cm 重拉，而不是原地猛拉。

#### 4.3.5 落放/堆叠/按压（T20/T27/T03/T29/T28/T09/T17）

```python
def settle_until_stable(target_pose, budget=0.8s):
    move_to(target_pose + approach_offset)
    slow_descend(0.5mm/step)
    if sec.state == CONTACT: back_off(0.2mm)
    open_gripper(slow=True)
    wait(0.5s)
    if tsc.stable(window=0.5s) and tsv.predicate():
        return True
    if repairable(): nudge(target_pose)
    else: regrasp()
    return False
```

- 落放：先接触再松爪（避免高抛）；松爪后 0.5s 稳定性检测；不稳则推正/重抓。
- 堆叠：碗/杯的落点用容器系相对位姿（OPT 统计）；TSC 判"叠上"而不是"碰到"。
- 按压/卡扣：缓慢下压直到停滞 + 齐平；不要用冲击。

## 5. 世界模型裁判：ALSM + TSC + TSV

### 5.1 ALSM：action-conditioned latent surprise

**架构**：

```text
z_t = Encoder(I_head_left, I_wrist_left, I_wrist_right)     # 冻结 DINOv2/VC-1，224×224
a_t = ActionEncoder(EE delta 6 + gripper 1, chunk=8)         # MLP
ẑ_{t+1} = Predictor(z_{t-7:t}, a_{t:t+1})                    # 6 层 causal transformer
s_t = 1 − cos(z_{t+1}, ẑ_{t+1})                              # 惊讶分数
```

- **训练**：只用成功演示（33k），采样 1–2M clips；BYOL/stop-grad 防塌缩；8×H100 1–2 天。
- **校准**：按 episode 切分；在 held-out 成功演示上算 `s_t` 的 95/99 分位；per-task conformal 阈值 `τ_task`；滞回 2–3 帧。
- **异常分数**：`surprise` + `progress`（latent 变化量 vs 期望；动作在动但 latent 不变 = 停滞）。
- **触发**：`s_t > τ_task` 连续 2 帧，或 progress 停滞 0.5s → `ANOMALY`。
- **动作**：暂停 → 腕部重观察 → 重新分割/定位 → SSG 回滚/重试；**不直接终止 episode**（避免误报杀死成功）。

**为什么不是像素级视频世界模型**：像素预测慢、复合误差大、容易被背景/光照主导；Foresight/ContactGuard/FARM/FoMo-FD 已经证明 latent surprise 足够做失败监控（[S18]–[S22]）。**为什么不是世界模型当演员**：32 任务、33k 演示，VLA 的模仿学习先验更强；世界模型当演员需要大量 rollout/规划，180s 和真机调试槽都不允许。

### 5.2 TSC：终局状态分类器

- **输入**：目标/容器周围的 RGB crop（头 + 腕），可加深度/掩码。
- **正例**：成功演示的末帧（以及末帧前 0.5s 的稳定帧）。
- **负例**：早期帧（未完成）、末帧的扰动（物体移开/旋转/替换）、失败合成（把物体从容器拿掉）。
- **输出**：`p(success)` + 校准（temperature scaling）。
- **用途**：终局判据、SSG 谓词、拉链/盒盖/插入到位。
- **离线指标**：held-out 任务/背景上的 accuracy、AUROC、ECE；目标 >85% accuracy、ECE<0.05。

### 5.3 TSV：终局验证

```python
def terminal_verify(step, obs):
    p = tsc.predict(step, obs)
    stable = object_pose_delta(obs, window=0.5s) < eps
    surprise = alsm.score(obs)
    pred = ssg.predicate(step, obs)
    if p > 0.8 and stable and surprise < tau and pred:
        return SUCCESS
    if pred and not stable:
        return REPAIR            # 推正/重放
    if not pred and surprise > tau:
        return RECOVER           # 人干扰/滑落
    return RETRY                 # ≤2 次
```

### 5.4 人为干扰的恢复协议

官方备注（第 7 轮表 B）大多是"平移物体"或"撤销已完成步骤"：T27 叠了第二个后拿走、T19 拉上后拉开、T14 拧开后拧回、T17 合上后打开、T24 食物快到了放回起点、T10 插头拔起、T12 中途拿走锁。

```text
1. ALSM 检测到惊讶（物体位置/状态突变）
2. 暂停 0.3s；若检测到人手/物体仍在动 → 等到静止（latent 变化 < ε 持续 0.5s）
3. 重新分割/定位目标与容器；更新 SSG 谓词
4. 若谓词从 1→0：s_t ← s_{t-1}，执行 NRB 恢复（重放/重抓/重放）
5. 若谓词仍为 1：从当前步继续
6. 重试预算：普通任务 ≤2；长任务（T16/T17/T31）≤1；总时长守卫兜底
```

### 5.5 离线扰动基准（不需要真机）

在 held-out 成功演示上合成异常：

- **物体平移**：把目标物体 copy-paste 到旁边 5–10cm（带阴影/深度一致）。
- **物体移除**：用背景 inpainting 抹掉目标。
- **物体替换**：换成同任务其他 episode 的同类物体。
- **动作时间扭曲**：把 action 序列加速/减速/延迟 3–5 帧。
- **手部遮挡**：在图像上合成移动的手/手臂（可选）。
- **指标**：AUROC、FPR@95TPR、检测延迟（帧）、恢复后成功率（在仿真/回放里）。
- **目标**：AUROC>0.8、FPR<5%、延迟<0.3s；达不到就只保留 TSC/TSV，不用 ALSM 做恢复。

## 6. SNL：场景归一化（背景/干扰物/未见物品）

### 6.1 立体深度与尺度

- 头 stereo 已 rectified（[S6]）；用 SGBM（快）或 RAFT-Stereo（准）算视差；深度 `Z = f·B/d`。
- **尺度自标定**：焦距/基线未公开；用桌面平面 + EE 高度（机器人运动学已知）估 `f·B`：桌面在 base 系的高度已知，拟合平面距离，解出尺度。深度只用于相对量（物体宽度、插入深度、平面法向），不追求绝对米制。
- **质量检查**：视差有效像素 <30% 或平面拟合残差 >1cm → 退回单目深度/几何先验。

### 6.2 开放词表分割

- GroundingDINO + SAM 2：用语言指令 + 160 条复述里的名词短语，检测 `target`、`container`、`distractor`。
- 深度抬升到 3D：目标/容器的 6D 位姿、宽度、插入轴、桌面支撑面。
- **affordance-first**：未见物品不靠语义类别，靠几何 affordance（柄=圆柱抓、沿=平行夹、槽=插入、凸缘=拉、盖=压/拧）；用深度/法向/曲率做规则 + 小分类器。

### 6.3 BNV 去背景/去干扰物视图

```text
raw head/wrist → 分割 target/container/distractor
BNV = 保留 target+container，背景替换为中性灰/桌面均值，distractor 置灰
anchor overlay = 目标 6D 位姿投影 + 十字/朝向/容差圈
```

- **训练/推理同分布**：WLA 微调时同步用 BNV + anchor overlay；否则推理第一次见到会崩。
- **视图分配**：4 路相机保留 raw；BNV/anchor 作为模型的额外输入（adapter/通道），不改 API。
- **轴覆盖**：

| 轴 | SNL 手段 | 预期 |
|---|---|---|
| 位置 | 深度 + 桌面坐标系 + 锚点 | 目标偏移不迷路 |
| 干扰物 | 分割 + distractor 置灰 | 不被杂物带偏 |
| 背景 | BNV 去背景/中性化 | 桌布颜色/纹理不敏感 |
| 未见物品 | 几何 affordance + 语言角色 | 不靠颜色/类别 |
| 人为干扰 | ALSM + SSG 回滚 | 变化可检测/可恢复 |

### 6.4 训练增广（替代视频世界模型）

- **背景**：分割桌面/背景，替换为随机纯色/纹理/其他 episode 的桌面（保持光照/阴影大致一致）。
- **位置**：目标/容器 copy-paste 平移 ±5–15cm，深度一致缩放，补阴影。
- **干扰物**：从其他帧/其他任务 copy-paste 2–5 个杂物，随机位置。
- **未见物品**：用其他任务的同类几何物体替换（杯→不同杯、盒→不同盒），保留语言角色。
- **规模**：每任务 100–200 个增广 episode；只对刚体/容器任务；布料/拉链/透明不做物理增广。

**为什么不用 GigaBrain 的 Real2Real**：背景轴只需要"颜色/纹理"变化，分割+色彩替换就够；Real2Real 的算力和工程成本高，且会引入视频生成伪影。把世界模型预算留给 ALSM 裁判，而不是数据引擎。

## 7. 导航残片：TFA + MTP + 主动腕部

### 7.1 为什么剪掉自主导航

- 演示基座静止（§1.5）；32 任务没有导航；评测没有导航分。
- 动基座会带来 OOD、碰撞、时间开销；收益为 0。
- 人为干扰若移动基座（备注歧义），正确响应是"检测→暂停→重锚定"，不是"导航到别处"。

### 7.2 TFA：桌面坐标系锚定

```text
1. 深度图 RANSAC 拟合桌面平面（法向 n、距离 d）
2. 用桌沿/角点/已知标记定桌面 x/y 轴
3. T_base_table = [R|t]（从平面法向 + 桌沿方向 + 机器人基座高度）
4. 所有目标位姿在 table frame 里定义；执行前转 base frame
5. 每 0.5s 重估；T_base_table 突变 >2cm/2° → 暂停/重锚定
```

**用途**：基座/腰部小漂移、人碰桌子、不同评测机位的轻微差异；不是导航。

### 7.3 MTP：T24 传送带拦截

- 检测食物 item（分割/颜色/语言），光流/Kalman 跟踪，常速度预测 0.3–0.5s。
- 选拦截点：在可达工作空间内、传送带下游 10–20cm；提前 0.2s 闭合夹爪（速度匹配）。
- 失败：等下一个 item；不要追到传送带外。

### 7.4 主动腕部重观察

- 触发：目标被遮挡、深度无效、ALSM 惊讶、TSC 置信度低。
- 动作：腕部侧移 10cm + 俯仰 20°，停 0.3s，重分割；不移动基座。
- 预算：每 episode ≤3 次；避免"反复看"耗尽 180s。
