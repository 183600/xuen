# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「力控」×「知识图谱」）

> R69 给闭环装上了嘴和眼睛：看不清就看、拿不准就问、质感不明就触。但它把「问」和「触」放进了同一个信息动作预算里——这是一个**范畴错误**：
> - **语言/视觉回答可以被怀疑、被重问、被降权**，它们是**可逆证据**；
> - **接触不可逆**：捏碎的鸡蛋不会复原，划伤的表面不会愈合，被惊到的人不会回到交互前的状态。力控既是**最物理、最难空口伪造的接地通道**，又是**唯一一个「错了就回不去」的通道**。
>
> 更尖锐的是 R69 自陈的最大风险：模态权重不可信 ⇒ 追问一个幻影 / 给一个误导性回答盖上「已验证」的章。R69 用「k 个正交证据源一致」救场，但实践中这些源常常是同一个人的脸、声音、姿态与回答——它们高度相关，且都能被**语言层**共同欺骗（共谋演戏）。R69 缺一条真正独立、且能被审计的接地通道。
>
> 本轮的两个灵感正好补上这两块：
> - **力控**把接触从一个离散「探针动作」升级为**受控阻抗/能量预算下的连续信息通道**：用可调刚度/阻尼去「轻触」，把物体力学属性（刚度、摩擦、质量、脆性）读成信息，同时用**无源性（passivity）+ 力/能量包络**保证这次读数是安全的；
> - **知识图谱**提供三件 R69 没有的东西：**先验**（能不碰就不碰——最便宜的探针是省掉的那个）、**溯源**（这条事实是谁、走哪条通道、何时写入）、**一致性**（物理约束与新事实能否共存；冲突时按信念等级修订而非静默覆盖）。
>
> 核心命题：**按「可逆性」重新切分信息动作；接触只在「可逆性贴现后的信息价值 > 预期不可逆损伤」且通过力/能量/无源性认证时允许；接触得到的事实必须经物理一致性门，才可作为高信念边写入带溯源的知识图谱；语言/视觉不得越过证据纪律覆盖力接地事实；冲突按 AGM 等级修订并被隔离，防止级联污染。** 命名 **FORGE-RAS**（Force-grounded Ontology with Relational Graph Evidence）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我允不允许碰、碰完这一下之后，什么从此为真、而我又永远失去了什么**」。

## 0. 直觉与动机

**灵感 1（力控 → 接触是双刃剑：最硬的接地，最贵的错误）**
直觉：R69 把 `g_probe` 当成一个普通信息动作，给它一个静态成本 `c(g)`。但接触的代价不是「花掉一点预算」，而是**不可逆的状态改变**。力控的正确用法不是「戳一下看看」，而是**在受控阻抗下让接触本身成为一个可计算的信息通道**：给定法向力包络 `F_max` 与能量预算 `E_max`，调整刚度/阻尼，使测得的位移/力最大程度地区分物体的力学属性，同时保证接触能量有界、系统无源（不向环境注入能量、不发散）。于是「碰」不再是一个一次性的信息动作，而是**一条带安全证书的连续信道**。
关键的不对称：**接触的收益是可约的（可以少碰），损伤是不可约的（碰了就是碰了）**。这决定了决策必须对不可逆动作采取严格得多的门槛。

**灵感 2（知识图谱 → 先验、溯源、一致性，三件事一次到位）**
直觉：人类不会对每个物体都上手摸。我们有一本「常识账本」：杯子通常脆、门把手通常能转、湿的表面摩擦小。知识图谱就是这本账本的可计算版本，而且它比向量先验多了三样要命的东西：
（a）**先验**：已知的就不必去碰，接触只用于消解**残余**歧义——最便宜的探针是根本不做的那个；
（b）**溯源**：每条边记录来源（先验 / 视觉 / 语言 / 力接地 / 推导）、时间、置信、验证状态。于是「谁说的」和「可不可信」是同一个查询；
（c）**一致性**：把牛顿第三定律、摩擦锥、准静态平衡、能量平衡编码成约束。一条与物理约束冲突的边**不能**以高信念写入——这正好给「力是接地通道」装上了闸门。
知识图谱的黑暗面同样明显：它会**陈旧**、会被**投毒**。所以本轮必须同时给出图谱的版本/时效纪律与冲突修订规则，否则「先验」会变成「偏见的放大器」。

**灵感 3（可逆性二分 → R69 的预算是把两类东西混在一起）**
直觉：R69 的 `interaction budget` 用一个标量管住频率、位移、社交成本。但真正决定「能不能做」的不是频率，而是**可逆性**。问一句问错了，下一句可以纠正；碰一下碰错了，物理世界不会给你撤回。把信息动作分成 `𝒜_rev` 与 `𝒜_irr`，并让 VoI 对不可逆动作扣除**预期不可逆损伤** `E[D(g)]`，就能把「问」的激进和「碰」的克制同时做对。R69 的 `VoI − c` 由此成为 `ρ=0` 的退化特例。

**灵感 4（接触不是免费的 → 力通道有自己的信任模型）**
直觉：力看起来最诚实，但并非不可欺骗：外部作动器可以推动物体、拉动末端，机械地「演出」一种并不存在的柔顺。不过欺骗有代价：**要让测得的力/位移关系偏离真实接触，就必须向系统注入或抽取能量**。而无源性/能量罐监视器跟踪的正是能量收支。于是得到一个漂亮的对偶：**能骗过物理验证的欺骗一定很弱（改变不了多少信念）；能显著改变信念的欺骗一定会露出能量异常**。这把「信任力」从信仰变成了可量化的检测—收益权衡——也是 R69 的 FMA（行为似然）在物理侧的镜像。

**灵感 5（严格包含 → 新层必须是旧层的边界退化）**
直觉：任何新增的「触觉—图谱」层都会引入新的黑箱与新的攻击面。避免「每加一层就多一个需要独立信任的系统」的唯一办法，是让新层在**关闭时逐指令退化为旧层**：令不可逆预算 `B_irr = 0`（禁止接触）、图谱只含 R69 已有的先验，则 FORGE 的所有决策路径必须与 FLUID-RAS 完全一致；再叠加 R69 的 `VoI≤成本` 与 ECE 门，则退化为 R68。安全侧永不弱于旧层，收益只来自「允许且值得接触」的那部分。

**定义 319（不可逆性贴现的 VoI，RVOI）** 对候选信息动作 `g`：
`VoI_ρ(g) = H(M|G,o) − E_{y~p(·|g,G,o)}[H(M|G,o,y)]`，

**定义 321（图引导探针选择 GCI）** 在「验证哪条边」与「在哪一点探」上联合优化：
`(e*, g_imp*) = argmax_{e∈G.unverified, g_imp} [IG(e | g_imp) − ρ·E[D(g_imp)]]`，
s.t. `certify(g_imp)`、`ℒ` 未超、可达。`IG(e)` 以该边对下游决策的影响加权（图谱的价值-of-information），优先验证「不确定且影响大且碰得起」的边。相对 R69 的 CIA（选模态对），GCI 选的是**物理可验证的图事实**。

**定义 325（力接地异常 FGA）** 力残差 `r_F = ‖w_meas − w_pred(x, model)‖ / σ_w`，能量异常 `a_E = |work_meas − work_cmd| / E_ref`，合成分 `a_F = r_F + λ_E·a_E`。判据：`r_F↑` 且 `a_E↑` ⇒ 机械欺骗/接触丧失/模型失配。FGA 是 R69 FMA（行为似然）在物理侧的镜像：**FMA 测「行为自洽」，FGA 测「物理自洽」**。

# IP-264 CFC：合规力控制器（阻抗/导纳 + 能量罐 + 接触状态机）
class ComplianceForceController:
    def __init__(self, F_safe, E_budget):
        self.F_safe, self.E_budget = F_safe, E_budget
        self.energy_used, self.tank_ok = 0.0, True
    def certify(self, g):                     # 力/能量/无源性/ISO 15066/retreat
        return (g.F_max <= self.F_safe and
                self.energy_used + g.E_max <= self.E_budget and
                self.tank_ok and iso15066_ok(g) and retreat_feasible(g))
    def probe(self, g):
        if not self.certify(g): raise ContactRejected(g)
        w, x = self._impedance_step(g)        # τ = Jᵀ(K_c Δx + D_c Δẋ + F_ff)
        self.energy_used += self._energy(w, x)
        self.tank_ok = (self._tank() >= 0)    # 无源性守卫
        return w, x, self.energy_used

# IP-266 PGE：物理一致性门（牛顿三定律/摩擦锥/准静态/能量/运动学）
def physics_gate(w, x, g, G, C):
    return all(c.residual(w, x, g, G) <= c.tol for c in C)

    damage = 0.0 if g.reversible else expected_damage(g, G, o)

## 3. 推导

**引理 19（接触信息–损伤权衡）** 在定义 315 的准静态线性化下，刚度估计的 Fisher 信息 `I(k)=(Δx/σ_w)²` 随位移单调上升；位移受 `Δx ≤ F_max/k` 与 `Δx ≤ 2E_budget/F` 双重约束。设损伤 `D(F)` 在 `F ≤ F_safe` 时近零、在 `F > F_safe` 后超线性增长，则最优探针必位于**安全边界** `F = min(F_max, F_safe)`、`Δx` 取该力下可行最大值；任何越过 `F_safe` 的调度满足 `∂D/∂F > ∂I/∂F`，是严格劣解。系：**信息可以买，但只能在安全包络内买；包络外「多碰一点」是净亏**——这正是不可逆性贴现（定义 319）的物理来源。

**引理 20（机械欺骗的能量可见性）** 设测量力 `w_m = w_true + w_spoof`。在机器人/物体其余部分静止时，虚假力若在位移 `δx` 上做虚功，则必有外界能量 `|W_sp| = |∫ w_spoof·dx|` 注入或抽取；能量罐残差满足 `|ΔE_tank − ΔE_expected| ≥ |W_sp| − ε_diss`。故当 `|W_sp| > τ_E` 时、由定义 314 的无源性守卫可检出。系：**欺骗幅度与可检测性同向**（定义 326）——把 `w_spoof` 压到 `τ_E` 以下，其对刚度后验的可改动量 `≤ O(τ_E/(kΔx))`，即「骗得过就改不动，改得动就藏不住」。

**引理 21（隔离下的修订级联有界）** 设依赖图最大出度 `d`、隔离深度 `D_max`，则隔离一条 `FORCE` 边会影响的派生边数 `≤ d^{D_max}`；取 `D_max=1` 时 `≤ d`。若每次重新验证后才恢复派生边，则全局信念的错误传播被限制在该闭包内。系：**一次局部物理错误不会变成全局认知崩塌**——这是对「知识图谱放大单点错误」的直接防御。

**引理 22（图谱先验减少接触次数）** 设目标属性 `Y`，先验提供互信息 `I(Y;G_P0)`，单次探针提供信息 `I_probe`。则期望探针数 `E[N] ≥ (H(Y) − I(Y;G_P0))/I_probe`，相对无先验情形下降约 `I(Y;G_P0)/I_probe`。系：**最便宜的接触是省掉的那个**；先验越强，越应少碰——这为「能不碰就不碰」提供了信息论依据。

**定理 18（FORGE 严格包含 FLUID 与 R68）** 在 A101–A104 下：令 `B_irr = 0`（禁止接触）且图谱只含 R69 已有的先验边，则 FORGE 的决策路径与 FLUID-RAS **逐指令相同**；再叠加 R69 的 `VoI≤成本` 与 ECE 门，则与 R68 逐指令相同。故 `FORGE ⊇ FLUID ⊇ R68`，安全侧在生产指令上不作任何让步，全部收益来自「允许且值得接触」的严格子集。

**定理 19（接触安全与无突变）** `g_imp` 经定义 327 认证且 CFC 无源（定义 314）后，其物理风险 `≤ ε_contact`；接触只改变「验证哪条边/选哪个模态」，不改变安全包络；接触失败、能量异常、`retreat` 不可行或预算耗尽时，λ 单调不降地退化为 FLUID/R68；R69 的换装/提交不变式（定理 15）保持 ⇒ 控制连续、无突变。

**定理 20（能量监视下的接地可靠性）** 若物理门通过且能量残差 `a_E < τ_E`，则写入的 `FORCE` 边为假的概率 `≤ δ_sensor + δ_gate(τ_E)`，其中 `δ_gate` 随 `τ_E` 单调下降；结合引理 21，单条假边造成的派生污染被限制在 `≤ d^{D_max}` 内。故力接地事实是**有界误差下的可靠**，而非「不可错」；`τ_E` 是可靠性与可探信息之间的显式旋钮。

## 6. 本轮最大风险

**一句话**：接触是唯一不可逆的通道——一次合规探针既可能**物理上毁掉被测对象**，又可能把一个「物理上自洽、但语义上错误」的力事实以最高信念写进知识图谱，并经推导边**级联污染全局信念**；而知识图谱会把这种局部物理错误放大成系统性偏见，**碰错，比不碰更不可挽回**。

**次级风险与缓解**：
1. **机械欺骗**（外部作动器伪造柔顺）→ 能量罐/无源性残差（引理 20）+ FGA，欺骗强度与可检测性同向；
2. **图谱陈旧/投毒** → 版本/时效纪律（定义 322）+ 不得覆盖 `FORCE`（定义 317–318）+ E311；
3. **级联污染** → 依赖闭包 + 一级隔离（定义 324、引理 21、E309）；
4. **不可逆预算被低估** → 单向门账本 + 严格裕度 `η_irr` + `D_budget` 硬上限，耗尽即退 FLUID；
5. **物理门本身失配**（模型误差被误判为欺骗或反之）→ 门与能量双通道 + E306/E305 联合标定，宁可判为「不可信」也不写入。

**定义 323–324（TMS-BR 与级联遏制）** 最小冲突集 + 按等级收缩，弱证据不覆盖强证据、只隔离；依赖闭包 + 一级隔离，修订影响 `≤ d^{D_max}`。

**定义 325–327（FGA 与接触安全）** `a_F=r_F+λ_E·a_E`；机械欺骗虚功 `W_sp` 能量可见；`certify(g_imp)` 覆盖力/能量/无源性/碰撞包络/ISO 15066/retreat。

**定义 328–329（退避与证书）** 接触失败→FLUID（仅可逆），FLUID `VoI≤成本`/ECE 越界→R68；`FORGE ⊇ FLUID ⊇ R68`；`J_FORGE` 并入接触能量、预算余量、溯源/修订哈希、物理门通过率、能量异常分位。

def choose_probe(modes, G, o, ieg):

## 4. 推导

**引理 19（接触信息–损伤权衡）** `I(k)=(Δx/σ_w)²` 随位移单调上升，受 `Δx≤F_max/k`、`Δx≤2E_budget/F` 约束；损伤在 `F>F_safe` 后超线性。故最优探针位于安全边界 `F=min(F_max,F_safe)`、位移取该力下可行最大；越界调度满足 `∂D/∂F>∂I/∂F`，是严格劣解。系：信息只能在安全包络内买，包络外「多碰一点」净亏——即 RVOI 的物理来源。

**引理 20（机械欺骗能量可见性）** `w_m=w_true+w_spoof`；虚假力在位移上做虚功必有外界能量 `|W_sp|=|∫w_spoof·dx|` 注入/抽取，能量罐残差 `≥|W_sp|−ε_diss`。故 `|W_sp|>τ_E` 时可检出。系：欺骗幅度与可检测性同向——压到 `τ_E` 以下则对后验改动量 `≤O(τ_E/(kΔx))`，即「骗得过就改不动，改得动就藏不住」。

**引理 21（隔离下修订级联有界）** 依赖图出度 `d`、隔离深度 `D_max` ⇒ 受影响派生边 `≤d^{D_max}`；`D_max=1` 时 `≤d`。系：一次局部物理错误不会变成全局认知崩塌。

**引理 22（图谱先验减少接触）** `E[N] ≥ (H(Y)−I(Y;G_P0))/I_probe`，相对无先验下降约 `I(Y;G_P0)/I_probe`。系：最便宜的接触是省掉的那个。

**定理 18（FORGE 严格包含 FLUID 与 R68）** `B_irr=0` 且图谱仅含 R69 先验时，FORGE 与 FLUID 逐指令相同；再叠加 `VoI≤成本`/ECE 门则与 R68 逐指令相同。故 `FORGE ⊇ FLUID ⊇ R68`，安全侧不让步。

**定理 19（接触安全与无突变）** 认证 + 无源 ⇒ 物理风险 `≤ε_contact`；接触只改「验证哪条边/选哪个模态」，不改安全包络；失败/异常/预算耗尽时 λ 单调不降退化为 FLUID/R68；换装不变式保持 ⇒ 控制连续、无突变。

**定理 20（能量监视下接地可靠性）** 物理门通过且 `a_E<τ_E` ⇒ `FORCE` 边为假概率 `≤δ_sensor+δ_gate(τ_E)`，`δ_gate` 随 `τ_E` 单调下降；结合引理 21，派生污染 `≤d^{D_max}`。故力接地是**有界误差下的可靠**，`τ_E` 是可调旋钮。

## 7. 本轮最大风险

**一句话**：接触是唯一不可逆的通道——一次合规探针既可能**物理上毁掉被测对象**，又可能把一个「物理上自洽、但语义上错误」的力事实以最高信念写进知识图谱，并经推导边**级联污染全局信念**；知识图谱会把局部物理错误放大成系统性偏见，**碰错，比不碰更不可挽回**。

**次级风险与缓解**：机械欺骗（能量罐/无源性残差 + FGA，引理 20）；图谱陈旧/投毒（版本时效 + 禁止覆盖 `FORCE` + E311）；级联污染（依赖闭包 + 一级隔离 + E309）；不可逆预算低估（单向门账本 + `η_irr` + `D_budget` 硬上限，耗尽退 FLUID）；物理门模型失配（门与能量双通道联合标定，宁可判「不可信」也不写入）。
