# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感驱动研究循环第 2 轮；本轮灵感：「LoRA」×「点云配准」）

> 第 57 轮把安全的赌注从"证据质量"推进到"少样本可校准、跨模态可对账、个性化有界"，但它的风险自陈暴露了一个更深的结构性问题：**元推断器 q_φ 是一个容量不受限的黑箱**。一个容量足够大的模型可以把任何观测（包括被欺骗的观测）"解释掉"，于是唯一防线是二值的 OOD 门；而"语料里没有的世界"恰恰落在 OOD 门学会识别的模式之外。本轮两个灵感分别从"容量"和"出处"两端补洞：**LoRA** 把适配从黑箱摊销变成 **冻结底座 + 有界低秩残差**——适配所消耗的秩/核范数是可计量、可审计的"新颖度证书"，**有界容量本身就是一条安全假设**（模型不能凭空制造它没见过的证据）；**点云配准**把证据归属从"默认正确"变成**几何操作**——每条证据必须被配准到它声称的区域，配准的协方差与退化结构给出**沿决策方向推导出来的**不确定性，而非手工宽度。核心命题由"证据说可信"升级为 **"适配有预算、证据有出处、退化可度量的证据说可信"**。

核心矛盾：
- **H29（适配容量 vs 认证）**：低秩瓶颈既省参数又能防止"解释掉异常"，但秩上限 r_max 与核范数预算 ρ_cap 是手设的；ρ_cap 太小欠拟合（浪费探针、频繁退回共形），太大则足以拟合欺骗数据——容量本身必须被认证，且容量不能随时间膨胀。
- **H30（对齐 vs 证据归属）**：证据只有在被正确配准到它所声称的区域时才是"该区域"的证据；错误回环、几何混叠、退化会让证据张冠李戴，而跨模态一致无法挽救——两个模态可能一起配错。
- **H31（低秩个性化 vs 博弈）**：低秩适配器能便宜地建模操作者并用"偏离流形"检测异常，但操纵者可以长期停留在低秩流形内伪装、再突然越界；秩预算若可增，就是信任通胀。

## 0. 直觉与动机

**灵感 1（LoRA → 有界低秩适配 = 可计量的新颖度）**
直觉：第 57 轮的元模型像一位"博览群书却从不承认自己没读过"的专家——它的知识容量没有刻度，你无法知道它为了解释这个新区域"编"了多少。LoRA 给它装一个刻度盘：**冻结一个跨区域共享的底座 W0，每个区域只学一个低秩残差 Δ_r=B_rA_r（rank≤r_max，||Δ_r||_*≤ρ_cap）**。于是"这个区域有多新"变成一个可测量——**适配能量**（达到目标似然所需的最小核范数）与**有效秩**：新区域像见过的表面，一点点低秩微调就够；不像，则无论怎么在预算内弯折都解释不好，此时**自然退回共形保底**。关键安全洞察：**限制适配容量 = 禁止"解释掉异常"**。全秩适配器可以拟合任何东西（包括欺骗），有界核范数的适配器不能；因此"低秩"不只是省参数，它是一条可写进定理的**反过拟合/反欺骗假设**。容量与校准之间是一条前沿曲线（秩-校准前沿 RCF），r* 由"在 ECE≤ε 与预算 ρ_cap 下最小化探针成本"选出，而非手拍。

**灵感 2（点云配准 → 证据的空间出处与决策相关退化）**
直觉：第 57 轮默认"这条观测属于区域 r"——但机器人凭什么知道？每次到访都是一次点云配准：把新扫描对齐到持久地图 𝓜，输出位姿 T̂、内点共识集 I、协方差 Σ_T。**内点率 η 是证据质量的天然度量，Σ_T 是手工信念宽度的天然替代**。更关键的是**退化**：在对称走廊、平面坡、长直通道里，配准在某些方向上信息不足（信息矩阵 Λ=J^TΩJ 的小特征值方向），此时"内点很多、看起来一致"却仍可能在该方向上完全不确定。把风险对位姿的敏感方向 a 投影到信息矩阵上，得到**决策相关退化** D_R=1/(a^TΣ_T a)：**若退化方向恰是决定踩不踩的方向，再多的共识也不构成证据**。这把第 57 轮手设的 θ_K/宽度换成了从几何推导的量。同时，**回环一致性**（A→B→A 的复合位姿≈单位）是配准版的"条件独立佐证"：它能挡住"看起来像同一个地方"的假回环——对称结构造成的几何混叠是最阴险的证据污染，因为它让 EV-visit 在错误的地方点亮。

**灵感 3（个性化低秩 → 行为流形与单向秩预算）**
直觉：把第 57 轮的信任状态机 s_o 换成一个"底座行为 π0 + 低秩行为残差 Δ_o(rank≤r_op)"。正常操作者的个体差异是低秩的（确认快慢、对某类地形的谨慎程度），**偏离这个低秩流形 = 异常行为 = 降级**。这比"静态权重 + 阈值"更细：它承认个体差异，却不给操纵者无限自由度。反博弈的关键是**秩预算单调不增**：一个想"先装严谨攒授权、再滥用"的操纵者，要么一直待在低秩流形内（那就没有自由度作恶），要么越界（被 off-manifold 残差抓到）；而授权只参数化流形内的佐证数与时延，永远不能购买额外秩。

**灵感 4（合流 → 证据门从五类到六类，且先过"出处"再过"分类"）**
直觉：第 57 轮证据门 EV-probe*/visit/margin/xmodal/human 之上，本轮加两道前置：**(P) 出处绑定**——任何证据先过配准出处测试（内点率、重叠度、回环一致、退化证书），不过则不进入分类；**(C) 容量证书**——EV-probe* 必须挂秩证书或共形带；新增 **EV-reg**（配准共识证据：多会话/多视角配准的内点共识，仅限 L1 非不可逆接触的加强，不替代不可逆必要证据）。EV-visit 升级为"配准验证过的同一性"（防假回环）。不可逆接触必要证据集 = {EV-probe* ∨ EV-margin ∨ EV-reg} ∪ 佐证，明确不含 EV-xmodal。

**灵感 5（PCE++ → 退化感知的探询与配准阶梯）**
直觉：VOI 不再只问"哪次探针最降熵"，而问"哪次探针最能增加**决策相关方向**的信息"——沿最大退化方向（Λ 最小特征向量投影到风险敏感方向）探测，而不是在已经信息充足的方向上重复。配准阶梯 L0（局部 ICP，跟踪）/L1（全局鲁棒 + 协方差 + 退化检查）/L2（全局 + 回环一致 + 跨会话一致性）按承诺等级选"最便宜且满足误差预算"的档。云边协议再进一步：云端下发的 LoRA 适配器也要过隔离——影子模式跑探针流，**秩-校准回归 + 合并干扰审计**通过才接管。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（LoRA 认证适配 LCA）** 冻结底座 q_{φ0}（权重 W0），区域适配器 Δ_r=B_rA_r，rank(Δ_r)≤r_max、||Δ_r||_*≤ρ_cap。适配能量 E_r=min_{||Δ||_*≤ρ_cap} NLL(o_{1:k}; W0+Δ)。新颖度分数 n_LoRA(r)=E_r/E_ref(z_r)，n_LoRA>θ_nov ⇒ 判分布外，退共形带 C_cf（继承定义 133）。秩-校准前沿 RCF(r)={(ECE_r, cov_r, cost_r)}；r*(r)=argmin cost s.t. ECE_r≤ε_meta(k) ∧ ||Δ_r||_*≤ρ_cap。秩证书 cert_r=(r_eff, ||Δ_r||_*, ECE_r, held-out NLL) 入账；**容量账本 cap_ledger 只减不增**。

**定义 140（配准证据绑定 REB）** 配准算子 Reg(S,𝓜)→(T̂, I, η=|I|/|S|, Σ_T, Λ=J^TΩJ, overlap)。出处测试 π_bind(e,r)=[η≥η0]∧[overlap≥o0]∧[cyc(T_{r→s}∘T_{s→r})≤θ_cyc]∧[D_R(r)≤θ_deg]。未绑定的证据一律拒收，且此判定**先于**证据分类。

**定义 141（决策相关退化 DRD）** 设风险泛函 R(g,T) 对位姿的敏感 twist 为 a_r=∂R/∂T；信息矩阵 Λ、协方差 Σ_T≈Λ^{-1}。决策相关退化 D_R(r)=1/(a_r^TΣ_T a_r+ε)，等价于风险敏感方向上的后验方差倒数。D_R>θ_deg ⇒ 该方向证据不足，与内点共识多少无关。风险宽度与 θ_K 由 a_r^TΣ_T a_r 推导，不再手设。

**定义 142（配准阶梯 RGL 与风险传播）** 阶梯档 {L0,L1,L2}，误差预算 ε0<ε1<ε2（宽松→严格），成本单调增。选档规则：取满足承诺等级误差预算的最便宜档。风险传播 R≈N(R̂, a^TΣ_T a)，P_fail≤尾界(a^TΣ_T a, δ_f)。跨会话一致性作为 L2 的额外出处条件。

**定义 143（秩预算个性化 RBP，升级 IP-135）** 操作者行为 π_o=π0+Δ_o，rank(Δ_o)≤r_op，r_op 会话内单调不增。off-manifold 残差 δ_o=min_{rank≤r_op}||behavior−π_o||；δ_o>θ_mani ⇒ 冻结/降级。auth 只参数化流形内 corrob*(auth)、w_h、τ_int(auth)；授权永远不能购买额外秩。

**定义 144（适配器治理 AMA）** 云端适配器 Δ_c 与边端底座合并 cand=compose(W0,Δ_c)。影子评估 report=shadow_eval(cand, 边端探针流)；合并干扰界 inter=||Δ_merged−Δ_target||_F≤Σ_{i<j}inter_{ij}。接管条件：report.ECE≤base.ECE+ε_reg ∧ report.OOD率≥base.OOD率−ε_reg ∧ inter≤θ_interf；否则拒绝并可版本回滚。

> FSE+（IP-137 升级）与 PCE++（IP-138 升级）在定义 139–144 之上整合：证据门六类且先过 π_bind；探询用退化感知 VOI。完整形式见产物区。

## 2. 关键算法伪代码（完整版见产物区）

```python
def lora_certified_infer(M, r, obs, base):          # IP-139 / 定义 139
    z = region_context(r, M)
    delta = fit_lowrank(base.W0, obs, rank_max=base.r_max, nuc_max=base.rho_cap)
    E_r, r_eff = nll(base.W0 + delta, obs), stable_rank(delta)
    if E_r / base.E_ref(z) > base.theta_nov or r_eff > base.r_max:
        return Inf(cls='OOD', belt=conformal_belt(base.residuals, z))  # 共形保底
    return Inf(cls='ID', post=base.q_phi(obs, z, delta), rank_cert=cert(delta, obs))

def register_bind(scan, M, r, level):               # IP-140/141/142
    rung = pick_rung(level, error_budget(level))     # L0/L1/L2 最便宜且达标
    T, I, eta, Sig, Lam = reg_ladder(scan, M, r, rung)
    a = dR_dT(r, M)                                  # 风险敏感 twist
    D_R = 1.0 / (a @ Sig @ a + EPS)                  # 决策相关退化
    ok = (eta >= eta0) and (overlap(scan, M, T) >= o0) \
         and (cycle_consistency(M, r, T) <= theta_cyc) and (D_R <= theta_deg)
    return Bind(ok=ok, T=T, Sigma=Sig, D_R=D_R, risk_width=gaussian_tail(a@Sig@a, delta_f))
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| LCA | 适配 O(d·r·k)+SVD O(d·r²) | O(d·r) 适配器 | 核范数约束诚实、ECE 声明诚实 |
| REB | 配准 O(N·iter) + 协方差 O(N·d²) | O(N+Σ_T) | 内点/重叠/回环估计诚实 |
| DRD | O(d²) 投影 | O(d²) | Λ 与 a 的估计诚实、θ_deg 保守 |
| RGL | 按档 O(L0)<O(L1)<O(L2) | O(N) | 选档不越过承诺等级误差预算 |
| RBP | O(H_op·r) | O(r_op) | 秩预算只减不增、off-manifold 检测 |
| AMA | O(shadow·N) | O(适配器版本) | 影子回归 + 干扰界 + 可回滚 |
| PCE++ | O(\|CP\|·(k_p+k_c)·(C_VOI+d²)+A\*) | O(\|V\|+\|σ\|) | 退化感知 VOI、k_p+k_c 终止 |

**正确性定理（LCPR 概要）**：在 A33–A40 上加 (A41) 容量诚实：ID 区域秩证书 ECE≤ε_meta(k)，容量账本强制 ||Δ||_*≤ρ_cap 且不随时间膨胀，OOD 漏检 ≤δ_ood；(A42) 配准诚实：η/overlap/Σ_T 估计诚实，真关联回环一致概率 ≥1−δ_cyc，假关联率 ≤δ_fa；(A43) 退化诚实：D_R 为决策方向不确定性的有效下界，θ_deg 取保守；(A44) 个性化容量：r_op 单调不增、off-manifold 检测、auth 不可购买容量。则：(i) **出处健全**：π_bind 失败即拒，假关联进入承诺的贡献 ≤δ_fa；(ii) **容量健全**：任何数据上 ||Δ||_*≤ρ_cap 限定似然提升 ≤ρ_cap·L_max，故"用高容量解释掉异常"不可行，假 ID 率 ≤δ_ood+ε_meta(k)；(iii) **退化健全**：D_R>θ_deg 即拒，退化方向风险被排除出承诺界，残余 ≤δ_deg；(iv) 交互单调性：新机制只经"信念更准/更宽"或"动作更保守"起作用；(v) PCE++ 在 k_probes+k_cons 内终止于 {承诺, 绕行, L2, 安全停}。

## 6. 本轮最大风险

**一句话**：本轮把安全赌注押在"适配容量"与"空间出处"两张新证书上，但两张证书都由同一批（可能被欺骗的）观测**自证**——秩证书用探针拟合、配准协方差用对应点估计，若相关误差同时污染探针与对应点，系统会得到"低秩且良态"的假清白；最大风险是**自证清白（self-certifying evidence）**，必须用留出探针、跨会话配准与保守联合界把"自证"变成"他证"。

```python
def fit_lowrank(W0, obs, rank_max, nuc_max):
    # 在核范数球内最小化负对数似然；等价于对残差梯度做截断 SVD
    G = grad_nll(W0, obs)
    U, S, Vt = svd(G)
    S = project_nuclear(S, nuc_max)          # 投影到 ||Δ||_* <= nuc_max
    S[rank_max:] = 0.0                       # 硬秩上限
    return (U * S) @ Vt                      # Δ = B A 的低秩形式

def lora_certified_infer(M, r, obs, base):
    z = region_context(r, M)
    delta = fit_lowrank(base.W0, obs, base.r_max, base.rho_cap)
    E_r = nll(base.W0 + delta, obs)
    n_nov = E_r / base.E_ref(z)              # 新颖度：需要多少适配能量
    r_eff = stable_rank(delta)               # 有效秩
    if n_nov > base.theta_nov or r_eff > base.r_max:
        belt = conformal_belt(base.residuals, sim=csim(z, base.Z), alpha=alpha_conf)
        return Inf(cls='OOD', belt=belt, rank_cert=None)   # 只以带内最坏值进 P_fail
    r_star = base.rcf_argmin(cost=True, ece_max=eps_meta(len(obs)),
                             nuc_max=base.rho_cap)
    post = base.q_phi(obs, z, delta=delta)
    cert = (r_star, nuclear(delta), base.rcf_ece(r_star),
            heldout_nll(delta, M.heldout[r]))
    base.cap_ledger.charge(r, nuclear(delta))  # 容量账本只减不增
    return Inf(cls='ID', post=post, rank_cert=cert)

def merge_adapters(deltas, W0):
    merged = sum(deltas)
    inter = sum(pairwise_frob(deltas[i], deltas[j])
                for i in range(len(deltas)) for j in range(i + 1, len(deltas)))
    return merged, inter
```

```python
def reg_ladder(scan, M, r, rung):
    if rung == 'L0':                                   # 跟踪：局部 ICP
        T0 = M.prior_pose(r)
        T, I, Sig = icp(scan, M, T0, max_iter=lo)
    elif rung == 'L1':                                 # 验证：全局鲁棒
        T, I, Sig = gnc_teaser(scan, M, noise_bound=b1)
    else:                                              # 承诺：全局 + 跨会话
        T, I, Sig = gnc_teaser(scan, M, noise_bound=b2)
        T = refine_multisession(T, M.sessions[r])
    Lam = information_matrix(scan, M, T, I)            # J^T Ω J
    eta = len(I) / len(scan)
    return T, I, eta, Sig, Lam

def register_bind(scan, M, r, level):
    rung = pick_rung(level, error_budget(level))       # 最便宜且满足误差预算
    T, I, eta, Sig, Lam = reg_ladder(scan, M, r, rung)
    a = dR_dT(r, M)                                    # 风险对位姿的敏感 twist
    D_R = 1.0 / (a @ Sig @ a + EPS)                    # 决策相关退化
    cyc = cycle_consistency(M, r, T)                   # A->B->A 复合位姿偏差
    ov = overlap_ratio(scan, M, T)
    risk_w = gaussian_tail(a @ Sig @ a, delta_f)       # 推导的风险宽度

    M.prov_log.append((r, rung, eta, ov, cyc, D_R))    # 出处账本

                cyc=cyc, risk_width=risk_w, rung=rung)
```

```python
def voi_deg(p, M, inf, bind):

def probe_along_degeneracy(M, r, bind):

    v = min_eigvec(bind.Lambda)

def probe_commit_evolve_plus_plus(x0, M, task, budget, consent, personas):
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| LCA | O(d·r·k + d·r²)/探针；回退 O(N_cal) | O(d·r) 适配器 | 核范数/秩约束诚实、ECE 声明诚实（A41） |
| REB | O(N·iter + N·d²) | O(N+Σ_T) | 内点/重叠/回环估计诚实、假关联 ≤δ_fa（A42） |
| DRD | O(d²) 投影 | O(d²) | Λ、a 估计诚实、θ_deg 保守（A43） |

| RBP | O(H_op·r) | O(r_op) | 秩预算只减不增、off-manifold 检测（A44） |
| AMA | O(shadow·N) | O(适配器版本) | 影子回归 + 干扰界 + 可回滚 |

| PCE++ | O(\|CP\|·(k_p+k_c)·(C_VOI+d²)+A\*) | O(\|V\|+\|σ\|) | 退化感知 VOI、k_p+k_c 终止、四态完备 |

**正确性定理（LCPR — Low-rank Certified Provenance Registration soundness）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 容量诚实：ID 区域秩证书 ECE_k≤ε_meta(k)，容量账本强制 ||Δ||_*≤ρ_cap、r_eff≤r_max 且不随时间膨胀，OOD 漏检 ≤δ_ood；**(A42)** 配准诚实：η/overlap/Σ_T 估计诚实，真关联回环一致概率 ≥1−δ_cyc，假关联率 ≤δ_fa；**(A43)** 退化诚实：D_R=1/(a^TΣ_T a+ε) 为决策方向不确定性的有效下界，θ_deg 取保守；**(A44)** 个性化容量：r_op 单调不增、off-manifold 检测、auth 不可购买额外秩。则：

1. **出处健全性**：π_bind 失败即拒收，任何假关联证据不能进入承诺，故假回环/几何混叠对 P(fail) 的贡献 ≤δ_fa。
2. **容量健全性**：对任意观测，||Δ||_*≤ρ_cap 限定似然提升 ≤ρ_cap·L_max，故"用高容量适配器解释掉异常/欺骗"不可行；假 ID 率 ≤δ_ood+ε_meta(k)。
3. **退化健全性**：D_R>θ_deg 即拒，退化方向的风险被排除出承诺界，残余贡献 ≤δ_deg。
4. **交互单调性强化**：低秩适配、出处绑定、退化证书、个性化秩预算只能经 (a) 校准信念更新（含强制加宽）或 (b) 更保守的动作参数（配准升档、探针增加、步态降档、τ_int↓、佐证数↑）影响系统，不存在升险路径。
5. **终止性**：每检查点共识探针 ≤k_cons，PCE++ 在 k_probes+k_cons 内终止于 {承诺, 绕行, L2 协商, 安全停}。
6. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + δ_h + δ_ood + δ_fa + δ_cyc + δ_deg
                   + δ_xm·1[L1])
             − P(𝓜 陈旧未检出) − P(护盾回退失败) − P(τ_int ∧ τ_mm 超时 ∧ 安全停失效)
```

关键：**低秩给效率、核范数给反欺骗**（容量有界 ⇒ 不能解释掉异常）；**配准给出处、协方差给宽度**（证据必须绑定到它声称的区域）；**退化给否决权**（共识再多也救不了决策方向的信息缺失）；三者全部经"信念更准/更宽"或"动作更保守"两个安全通道起作用。

云边协议 CEB++ → **CEB+++**：云端可下发 LoRA 适配器增量，但适配器本身也要过隔离区——先以影子模式在边端探针流上运行，**秩-校准回归（ECE 不劣化 ∧ OOD 检出率不降 ∧ 退化触发率不降）+ 合并干扰审计（inter≤θ_interf）** 通过后才接管承诺判定；不通过则版本回滚。边端回传配准残差、回环一致性与证伪事件，作为云端元训练与语料补盲的校准集。第 57 轮"一切判定器走隔离"在本轮推广为"**适配容量与空间出处本身也是被认证的对象**"。

## 6. 本轮最大风险

**一句话**：本轮把安全赌注押在"适配容量"与"空间出处"两张新证书上，但两张证书都由同一批（可能被欺骗的）观测**自证**——秩证书用探针拟合、配准协方差用对应点估计，若相关误差同时污染探针与对应点，系统会得到"低秩且良态"的假清白；最大风险是**自证清白（self-certifying evidence）**，必须以留出探针、跨会话配准、独立外观验证与保守联合界把"自证"变成"他证"，宁可退回又宽又慢的共形区间，也绝不采信"自己证明自己正确"的证据。
