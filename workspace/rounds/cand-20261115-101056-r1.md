# 第 1 轮（本灵感循环第 1 轮；承接第 4 轮 InstructGauge-WR 基线；本轮灵感：「奖励设计」×「上下文理解」）

> **基线**：第 4 轮 InstructGauge-WR（IP-328–333；定义 448–467；引理 59–62；实验 E457–E472）。InstructGauge v3 / ToolGauge / LeanGauge / MODGAUGE 的退化链继续继承不变。
> 本轮纪律：**增量升级 + 严格退化**。奖励与上下文各沿一条轴升级基线；任一环节不可用都必须能退回 InstructGauge-WR，奖励与上下文是增强项、不是依赖项。

## 0. 直觉与动机

**灵感 1（奖励设计 → 可审计的「奖励契约」，而不是一个标量分数）**
直觉：盲区修复里真正稀缺的不是奖励，而是「知道该奖励什么」。信息增益、碰撞风险、时间成本、不可逆性彼此冲突，压成一个标量必然给捷径留门：例如反复盯着同一个已确认的物体可以刷「信息量」。正确的接口不是 `R: S×A→R`，而是**带类型与字典序的奖励契约** `R_contract = ⟨r_safe, r_risk, r_info, r_cost; ≻_lex⟩`：硬安全约束永远优先，风险次之，信息增益再次，成本最后；奖励只能在 `KinematicAdmissibleSet` 内重排候选，**不扩大物理可行域**。势函数塑形（potential-based shaping）用来加速信用分配，但必须保证策略不变性；奖励审计用来识别 Goodhart——这是把「目标设计」从调参问题变成契约问题。

**灵感 2（上下文理解 → 带证书的「隐上下文」，而不是自由文本场景描述）**
直觉：同一句「先看左边金属件」在不同任务阶段、不同操作者意图、不同前序失败下含义不同。上下文理解的价值不是生成一段漂亮的场景描述，而是推断一个低维、可校准的隐上下文 `c`（任务阶段、目标可供性、风险制度、操作者偏好），并让接地、奖励与块长条件化于它。但上下文推断会错；错上下文会让接地、奖励和分块**同时**错。因此每个上下文估计必须携带**上下文证书**：后验、充分性（熵/互信息）、相对校准分布的漂移分；证书不过就退回上下文无关的稳健奖励。上下文只能条件化**偏好与阈值**，不能条件化**能力与安全约束**。

**灵感 3（耦合 → 上下文条件奖励会同时放大 Goodhart 与误识别）**
直觉：奖励设计回答「什么叫好」，上下文理解回答「对哪个情境好」。错误耦合时，一个自信但错误的上下文会产生一个**内部一致却整体错误**的奖励，长块再把它沿时间轴执行 K 步。这比单组件错误更危险：上下文误差是系统性的，奖励优化会主动放大它。解法不是禁用二者，而是三根结构支柱：**奖励可采纳性**（奖励不能改可行域）、**切换安全势函数**（上下文切换处势函数连续，避免塑形泄漏）、**上下文门控回退**（证书失效即退稳健奖励并缩短块长），再叠加**上下文分层共形校准**与**反事实奖励审计**。

## 1. 研究问题（本轮要回答什么）

- **Q1（奖励的安全性）**：奖励能否被写成可类型检查、可审计、抗 Goodhart 的契约，而不是新的捷径入口？
- **Q2（上下文的可用性）**：要让上下文真正改善接地、奖励与分块，上下文需要满足什么可检验条件？证书如何给出「可用/不可用」的二值判断？
- **Q3（耦合的放大效应）**：上下文条件奖励把误识别变成系统性偏差；能否用奖励可采纳性、切换安全塑形与门控回退，把遗憾与安全风险压回线性、可界，并在失效时严格退回基线？

## 2. 三条设计原则（正式化见产物区定义 468–483）

**P1 奖励可采纳性（Reward Admissibility）**
奖励只能在硬约束与运动学可采纳集内重排候选；任何越权项（新工具、超包线幅值、不可逆动作）一律输出 `⊥` 并回退基线目标。形式化方向：`argmax_{a∈A} R_contract ⊆ A_adm(s)`，且 `scope(R_contract) ⊆ T_0 × A_adm`。这给出「奖励不会扩权」的类型级保证。

**P2 切换安全势函数（Switch-Safe Shaping）**
上下文条件塑形 `F_c = γΦ_c(s') − Φ_c(s)` 在每个上下文段内保持策略不变性；上下文切换处要求势函数连续 `Φ_{c'}(s_switch)=Φ_c(s_switch)`，否则关闭塑形。只有段内策略不变，奖励塑形才不会把「上下文切换」变成隐形的奖励漏洞。

**P3 上下文充分性与门控（Context Sufficiency & Gate）**
只有后验熵低、漂移分低、共形预测集唯一的上下文才允许进入规划；否则 `c=c_⊥`，使用最坏情况稳健奖励，并保守化块长。上下文证书不是置信度装饰，而是**开关**：宁可退回基线，也不让错误上下文条件化执行。

## 3. 与基线的接口（如何退化）

- 上下文证书失效 / 歧义 / OOD ⇒ `c=c_⊥`，使用 `R_robust`，等价于 InstructGauge-WR 的目标与块规划；
- 奖励契约审计失败 / 越权项 ⇒ 冻结塑形并回退基线字典序目标；
- 势函数在切换处不连续 ⇒ `F=0`，关闭塑形，退回无塑形奖励；
- 上下文分层校准样本不足 ⇒ 回退全局共形阈值；
- InstructGauge-WR 失效 ⇒ InstructGauge v3；InstructGauge 失效 ⇒ ToolGauge；LeanGauge 失效 ⇒ MODGAUGE 原样。

## 4. 预期贡献

1. 一个「奖励只重排、不改能力」的可采纳契约，把奖励注入面压到可类型检查与可审计的范围内；
2. 一个带**上下文证书**与**门控回退**的上下文理解接口，把「上下文错了怎么办」从口头假设变成可检验开关；
3. 一个**切换安全势函数**与**上下文分层共形校准**方案，修正条件化塑形破坏策略不变性、条件化校准破坏可交换性的问题；
4. 一条完整可证伪路径：E473–E487 覆盖证书校准、奖励可采纳、塑形不变性、误识别稳健性、Goodhart 检测、分层覆盖、退化等价与 50Hz 时序保全。

## 5. 本轮最大风险

**一句话**：上下文误识别会把一个内部自洽但整体错误的奖励「合法化」，而奖励优化与长块执行会主动放大这种系统性偏差；真正的残余风险在「上下文证书的错误自信」，而不是奖励函数或上下文模型本身。

## 2. 形式化定义

**定义 468（上下文变量与上下文估计器）**
设有限上下文类集合 `C={c₁,…,c_m}`，交互历史 `h_t=(o_{1:t}, a_{1:t-1}, ℓ, ρ_{1:t-1})`。上下文估计器 `E_ctx: H→Δ(C)` 输出后验 `b_t=E_ctx(h_t)`，点估计 `ĉ_t=argmax_c b_t(c)`，上下文指纹 `z_t=φ_ctx(h_t)∈ℝ^d`。上下文只允许影响奖励项、风险模型、校准桶与块长上界，**不允许影响** `A`、`T₀` 或安全约束集合。

**定义 469（上下文证书 ContextCert）**
```
ContextCert_t = (z_t, b_t, H_t, s_t, valid_t)
H_t = -Σ_{c∈C} b_t(c) log b_t(c)
s_t = MMD(Ẑ_t, Z_cal)                 # 或 Mahalanobis 距离
valid_t = (H_t ≤ ε_H) ∧ (s_t ≤ ε_shift) ∧ (OOD(z_t)=0)
```
`ContextCert` 是上下文进入闭环的准入证；`valid_t=false` 时不得用 `ĉ_t` 条件化奖励或块长。

**定义 470（上下文条件约束 MDP）**
`M_c=(S,A,P,R_c,{C_i}_{i=1}^m,γ,μ_c,d_i)`，策略优化为
```
max_π E_{π,μ_c}[Σ_t γ^t R_c(s_t,a_t)]
s.t.  E_{π,μ_c}[Σ_t γ^t C_i(s_t,a_t)] ≤ d_i,  ∀i
```
上下文只改变 `μ_c`、奖励项权重与风险估计，不改变 `A` 与 `d_i`。因此上下文是「偏好条件」，不是「能力条件」。

**定义 471（奖励契约 RewardContract）**
```
R_contract = ⟨r_safe, r_risk, r_info, r_cost ; ≻_lex ; F_c⟩
r_safe(s,a) = -∞  若 a∉A_adm(s)，否则 0
r_risk(s,a) = P_irr(a) + λ_v·1[a∉A_safe(s)]
r_info(s,a) = H(b_{t+1}|b_t) − H(b_{t+1}|a,b_t)
r_cost(s,a) = Δt + λ_e·ΔE
```
排序按字典序 `r_safe ≻ r_risk ≻ r_info ≻ r_cost`。`F_c` 为定义 473 的上下文塑形。奖励契约是**带硬约束的排序器**，不是可被任意标量化的目标。

**定义 472（奖励可采纳性 Reward Admissibility）**
`R_contract` 可采纳当且仅当：
1. `∀s, argmax_{a∈A} R_contract(s,a) ⊆ A_adm(s)`；
2. 对每一项做正仿射归一化后，候选排序不变；
3. `scope(R_contract) ⊆ T₀ × A_adm`，不得引用新工具、新物理量或不可逆动作；
4. 每一项可分解为独立回执 `ρ` 上的可核验统计量。

任一条件失败输出 `⊥`，回退基线目标 `R₀`。

**定义 473（上下文势函数）**
对每个 `c∈C`，`Φ_c:S→ℝ`，`Φ_c(s_term)=0`。塑形奖励为
```
F_c(s,a,s') = γΦ_c(s') − Φ_c(s)
```

**定义 474（切换安全势函数族）**
势函数族 `{Φ_c}` 切换安全，若对任意上下文切换 `c_t≠c_{t+1}` 有
```
Φ_{c_{t+1}}(s_{t+1}) = Φ_{c_t}(s_{t+1})
```
并假设上下文切换时刻由外生事件（任务阶段推进、操作者指令、已观测事件）决定，不由当前块内动作决定。否则关闭塑形 `F=0`。

**定义 475（上下文分层共形校准）**
对每个有效上下文 `c`，校准集 `D_c`，非一致性分数
```
A_c(s,a) = |r̂_c(s,a) − u(s,a)|
q_c = Quantile_{1−α_c}({A_c(s,a) : (s,a)∈D_c})
C_α(h_t) = { c∈C : A_c(s,a) ≤ q_c }
```
若 `|D_c|<N_min` 或桶内交换性检验失败，使用全局阈值 `q₀`。只有 `|C_α(h_t)|=1` 时才允许上下文条件化。

**定义 476（奖励审计与 Goodhart 分数）**
```
HackScore_t = max_{δ∈B_ε(R_contract)} [ D_TV(π_{R+δ}, π_R) − κ·Δu_t(δ) ]
```
其中 `Δu_t(δ)` 是用独立回执核验的真实效用变化。若 `HackScore_t>ε_hack`，触发奖励冻结 `freeze(R)` 或回滚到最后一个通过 CVC 的检查点，并令 `Φ=0` 直到审计通过。

**定义 477（上下文误识别与稳健回退）**
若 `valid_t=false` 或 `|C_α(h_t)|≠1`，令 `c_t=c_⊥`，使用
```
R_robust(s,a) = min_{c∈C} R_c(s,a)       # 字典序最坏情况
```
`R_robust` 在单上下文退化时等于 InstructGauge-WR 的目标；上下文门控只收缩奖励与块长，不扩张任何安全约束。

**定义 478（上下文条件遗憾）**
```
Regret(T) = Σ_{t=1}^T [ J_{c*}(π*) − J_{c*}(π_t) ]
```
在证书有效、上下文桶可交换、误识别概率 `p_err`、漂移上界 `ε_shift` 下，目标界为
```
O( √(T·|C|·log|A|) + T·p_err·L + T·ε_shift )
```
其中 `L` 为奖励/效用的 Lipschitz 常数。

**定义 479（上下文门控 Context Gate）**
```
gate_t = valid_t ∧ (H_t≤ε_H) ∧ (s_t≤ε_shift) ∧ (|C_α(h_t)|=1)
```
`gate_t=false` 时：`R←R_robust`，`K←min(K,K_robust)`，且跨不可逆动作强制 `K=1`。门控是**单向下行**：只能从条件化退回稳健，不允许在块内重新打开。

**定义 480（奖励冻结与回滚）**
`freeze(R)` 停止奖励参数与势函数更新；`rollback(π, checkpoint)` 恢复最后一个通过 `SpatialCert` 的块，并将 `Φ` 置零直到 `HackScore≤ε_hack`。回滚后必须重新生成 `ContextCert`，不得复用旧上下文后验。

**定义 481（CR-7C 闭环接口）**
```
CR-7C = Ctx → Ground → Hyp → Reward → Plan → Execute(CVC+TF) → Audit → Bind
```
`Ctx` 输出 `ContextCert`；`Reward` 构造可采纳契约；`Plan` 只能在 `A_adm` 内搜索；`Execute` 继承 WRC-ROS-7C 的前缀封闭与不可逆屏障；`Audit` 在块边界复核 `HackScore`。

**定义 482（上下文—奖励证书组合）**
```
ContextCert ⊕ RewardCert ⊕ SpatialCert valid
iff 每个分证书 valid ∧ compat(ĉ, R_contract) ∧ gate_t
```
`compat(ĉ,R_contract)` 要求奖励的所有条件项都位于该上下文允许的项集合内；否则组合为 `⊥`，回退 `R_robust`。

**定义 483（严格退化等价）**
关闭上下文（`c=c_⊥`）与塑形（`F=0`）后，`R_contract` 退化为 InstructGauge-WR 的字典序目标；关闭奖励契约后退化为基线目标；关闭 CR-7C 全部新组件后退化为 WRC-ROS-7C；再退化到 InstructGauge v3、ToolGauge、LeanGauge、MODGAUGE。

## 3. 关键算法骨架

```python
class ContextFingerprint:
    def __init__(self, encoder, classifier, shift_detector,
                 eps_H=0.35, eps_shift=0.10):
        self.encoder = encoder
        self.classifier = classifier
        self.shift = shift_detector
        self.eps_H = eps_H
        self.eps_shift = eps_shift

    def infer(self, h, calibration_stats):
        z = self.encoder(h)
        b = softmax(self.classifier(z))
        H = -sum(p * log(p + 1e-12) for p in b)
        s = self.shift(z, calibration_stats)
        valid = (H <= self.eps_H) and (s <= self.eps_shift) \
                and not self.shift.is_ood(z)
        return ContextCert(z=z, b=b, entropy=H, shift=s, valid=valid)


class RewardContract:
    def __init__(self, terms, lex_order, kloop, cvc):
        self.terms = terms
        self.lex_order = lex_order
        self.kloop = kloop
        self.cvc = cvc

    def admissible(self, s, actions):
        return [a for a in actions
                if self.kloop.is_kinematically_valid(a, s)
                and self.cvc.feasible(a, s)]

    def rank(self, c, s, a):
        info = self.terms["info"](c, s, a)
        risk = self.terms["risk"](c, s, a)
        cost = self.terms["cost"](s, a)
        return (0 if a in self.admissible(s, [a]) else 1,
                risk, -info, cost)

    def robust_rank(self, s, a):
        return max(self.rank(c, s, a) for c in self.terms["contexts"])


def switch_compatible(phi, c_prev, c, s_next):
    return abs(phi[c](s_next) - phi[c_prev](s_next)) < 1e-9


def shaped_reward(phi, c_prev, c, s, a, s_next, gamma):
    if c != c_prev and not switch_compatible(phi, c_prev, c, s_next):
        return 0.0
    return gamma * phi[c](s_next) - phi[c](s)


def reward_audit(policy, contract, receipts,
                 eps=0.05, kappa=1.0, n_perturb=8):
    base = policy.distribution()
    base_u = verified_utility(receipts, base)
    worst = -float("inf")
    for _ in range(n_perturb):
        delta = contract.sample_perturbation(eps)
        alt = policy.replan(contract + delta).distribution()
        tv = total_variation(base, alt)
        du = verified_utility(receipts, alt) - base_u
        worst = max(worst, tv - kappa * du)
    return worst


def contextgauge_rc(M, s, ell=None):
    cert = M.ctx.infer(M.history, M.ctx_calibration)
    if not cert.valid or len(M.conformal.set(cert)) != 1:
        return instructgauge_wr(M, s, ell, reward=M.reward.robust)

    c = cert.point
    iota = M.nlib.ground(ell, M.scene, M.ontology)
    H = M.lbox.hypothesize(s, M.dbox.R[s], iota, c)
    A = M.reward.admissible(s, M.tools)

    C = M.iac.plan_chunk(iota, H, A, M.budget_left(s),
                         M.drift_bound(s), c)
    C = M.iac.enforce_irreversible_barrier(C)

    if M.audit.precheck(C, c) > M.eps_hack:
        C = M.iac.plan_chunk(iota, H, A, 1,
                             M.drift_bound(s), c)

    C, spatial_cert, claims = M.wrc.execute(M, s, iota, C)

    hack = M.audit.postcheck(C, c, M.receipts)
    if hack > M.eps_hack:
        M.audit.freeze()
        M.audit.rollback(C.last_safe_checkpoint)
        M.phi.reset()

    return C, cert, spatial_cert, hack, claims
```

## 4. 推导

**引理 63（切换安全塑形的策略不变性）**
在外生上下文切换假设与定义 474 的连续性条件下，对任意上下文段 `[t_start,t_end]`，塑形后的最优策略与未塑形 CMDP 的最优策略相同；塑形只改变值函数的势差，不改变动作排序。证明：段内塑形项望远镜求和，
```
Σ_{t=t_start}^{t_end} γ^t F_{c_t}(s_t,a_t,s_{t+1})
= γ^{t_end+1}Φ_{c_{t_end}}(s_{t_end+1}) − Φ_{c_{t_start}}(s_{t_start})
```
该式与动作无关；切换处连续性保证跨段求和仍只剩端点势差，因此 `Q` 值只差一个状态势，`argmax` 不变。

**引理 64（奖励可采纳性保持可行域）**
若 `R_contract` 可采纳，则任何对其贪心的策略都选择 `A_adm(s)` 内动作，且 `A_adm` 与安全约束 `C_i≤d_i` 未被奖励修改。证明：定义 472 的条件 1 直接限制 `argmax` 的支撑集；条件 3 限制奖励作用域，排除新工具与新物理量；条件 4 要求每项可由回执核验，排除不可观测代理项。因此奖励只能重排，不能扩权。

**引理 65（上下文门控的无害性）**
当 `gate_t=false` 时，`R_robust` 与 `A_adm` 均不依赖 `ĉ_t`，执行策略对错误上下文不可利用；其安全约束集合与 InstructGauge-WR 完全相同。若 `|C|=1`，`R_robust` 逐项等于基线目标。证明：由定义 477 与 479，门控失败只收缩奖励与块长；`A_adm`、`T₀` 与 `d_i` 从未被上下文修改，故不可能引入新的安全违背。

**引理 66（上下文分层共形覆盖）**
在桶内可交换性成立且样本充足时，`P(u_t ≤ r̂_t + q_c) ≥ 1−α_c`；当桶样本不足回退全局阈值 `q₀` 时，覆盖率至少为 `1−α−δ`，其中 `δ` 为桶分布与全局分布的 TV 距离。证明：Mondrian 共形把每个上下文桶分别视为可交换序列；桶内分位数保证边际覆盖；全局回退用三角不等式吸收分布差。

**引理 67（Goodhart 检测的块边界充分性）**
若 `HackScore_t>ε_hack`，则存在奖励扰动 `δ` 使策略分布发生显著偏移，而该偏移无法由回执核验的真实效用增益解释；审计在块边界触发冻结/回滚。若跨不可逆动作强制 `K=1`，检测前最多执行一个不可逆动作，损害被限制在单步。证明：由定义 476 的 `D_TV−κΔu` 构造，反证若所有显著偏移都有等比例真实增益，则 `HackScore≤0`；不可逆屏障由定义 479 与继承的前缀封闭分块保证。

**引理 68（误识别的线性放大界）**
在奖励可采纳、上下文门控、前缀封闭分块与不可逆屏障共同作用下，上下文误识别导致的期望性能损失满足
```
E[ΔJ] ≤ K·L·p_err + ε_vis
```
且当 `gate_t=false` 时 `K≤K_robust`、跨不可逆动作 `K=1`；不会出现超线性放大。证明：奖励可采纳性把动作限制在 `A_adm`，塑形不改变段内排序，门控把错误上下文隔离在稳健奖励之外；剩余误差只能沿块内 K 步线性累积，前缀封闭确保可在任意安全前缀截断。

**引理 69（严格退化等价）**
依次关闭上下文、塑形、奖励契约、CR-7C 新组件，闭环分别退化为 InstructGauge-WR 目标、无塑形奖励、基线字典序目标、WRC-ROS-7C；继续关闭腕部相机/ROS/刚体闭环退化为 InstructGauge v3、ToolGauge、LeanGauge、MODGAUGE。证明：逐项对照定义 477、483 与第 4 轮退化链；每个关闭操作只移除一个增强项，不改变底层 `A_adm`、CVC 与前缀封闭分块，故退化是精确的组件替换而非近似。

## 8. 本轮最大风险

**一句话**：上下文证书的「错误自信」会把错误奖励合法化，而奖励审计只能在块边界事后发现；真正的风险是分布外上下文被高置信地误分类，而保守回退与缩短块长可能吞掉大部分预期收益。
