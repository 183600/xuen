# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧」IP-253~263；灵感：「路径规划」×「分布外泛化」）

> R69 给闭环装上了一张嘴：它不再只会「不确定就刹车」，而会看、会问、会触、会等。但 R69 的消歧是**局部且短视**的——它问的是「这个动作块里绕左还是绕右」，隐含两个未经审查的前提：
> 1. **模态没有全局拓扑**。流匹配采样出的是平滑动作轨迹，平滑不等于可行。在训练分布里它从未见过「墙」，就可能自信地生成一条穿墙的模态；而 R69 用来校验模态的仍是**学习出来的流似然**——让嫌疑人自己作证。
> 2. **世界模型默认还在分布内**。R69 的 epistemic 不确定性只关心「哪个模态」，不关心「我脚下的地图/动力学是否仍然作数」。一旦发生分布外漂移，流似然、模态权重、标定全部条件在一个**错的世界**上，R69 的「resolution bonus」就可能是一场自信的骗局。
>
> 本轮两个灵感正好补上这两块：
> - **路径规划**提供与网络参数无关的**几何/拓扑见证者**：同伦类、roadmap、走廊、可达性。每个流模态可被提升到某个同伦类；若该类里不存在无碰撞、动力学可行的路径，该模态是**幻影**，可被非学习地否决。
> - **分布外泛化**提供对见证者自身的审查：conformal 覆盖依赖**可交换性**，而这正是 OOD 破坏的东西。于是「鲁棒可行」必须被诚实表述为**条件于歧义集 ℳ**的命题，并用交换性监控决定它是否仍然配得上证书。
>
> 核心命题：**把「消歧」从局部动作模态提升到全局同伦类/路线，把「世界模型是否仍可信」升为一等公民；用非学习的几何规划器给学习策略当第二意见，再用分布外泛化给几何规划器本身当第二意见；只有当独立通道一致、且交换性未破时，才签发「可证」；否则沿降级阶梯退回分布无关的安全兜底。** 命名 **ROAM-RAS**（Robust Out-of-distribution Ambiguity-aware Motion planning）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我脚下的地图还作数吗？这条在分布外还安全的路线，凭什么？**」——路径不只是一串动作，它是一条需要被拓扑与分布双重背书的承诺。

## 0. 直觉与动机

**灵感 1（路径规划 → 模式有拓扑，见证者可以不学习）**
直觉：流策略的 K 个模态在一张地图上不是「K 个数字」，而是「绕障碍的哪一侧」。自由空间的路径被**同伦类**划分；「从左边绕」和「从右边绕」不是同一个类，不能靠插值弥合。路径规划给出 roadmap、同伦类代表元、可行走廊——这些都是**几何/组合对象**，不依赖策略网络的权重。把每个流模态的轨迹投影到工作空间、判定它属于哪个同伦类（或 ⊥，不可行），就得到一个独立于学习的硬校验：**穿墙的模态会被几何否决，而不是被另一个网络「觉得还行」**。这把 R69 的「模态可信吗」从自证升级为**他证**。

**灵感 2（分布外泛化 → 保证是带条件的，没监控的 conformal 是空头支票）**
直觉：几何见证者只说「给定地图 m，这条路可行」。但地图从哪来？来自带噪声、会过时、可能被投毒的感知。我们真正能拥有的不是一张真地图，而是一个**歧义集 ℳ**（与观测一致、且在某个置信半径内的一族地图/动力学）。鲁棒规划在这个集合上求最坏情况。关键洞察：conformal 的 1−α 覆盖**只在可交换性下成立**；OOD 的定义就是可交换性被破坏。所以「鲁棒可行」不是无条件定理，而是**条件命题**：ℳ 的覆盖率有承诺 ⟺ 交换性监控未报警。报警时，任何基于 ℳ 的证书必须**作废**，系统退回**分布无关**的兜底（从任意状态都能刹停/进入已知安全集的可达域，即「安全门廊」）。这是比 R69 更成熟的诚实：**不是宣称有证明，而是精确知道证明的适用边界与失效后的退路**。

**灵感 3（交互 → 从「消歧动作」升级为「识别世界模型」）**
直觉：R69 的看/问/触/等，是为了分辨动作模态；在 R70 里它们获得更强的用途——**缩小世界模型的歧义集**：看拐角消解遮挡、探地面估计摩擦、问人确认路线偏好、等动态障碍通过。更进一步，交互可以**主动做分布检验**：选一个「canary」动作，使「世界仍可交换」与「世界已偏移」两种假设下的期望证据比最大（e-process 期望增长最大）。于是交互不仅消解 epistemic 地图不确定性，还能把「地图不清」与「世界真的变了」区分开。VoI 相应地从「哪个模态」上升为「哪条同伦类 / 哪个世界假设」。

**灵感 4（严格包含 → 新层必须是旧层的边界退化）**
直觉：R69 的教训是「别每加一层就多一个独立黑箱」。R70 必须能退：当 ℳ 是单点、只有一个同伦类、交换性成立时，ROAM 的路线选择必须**逐指令**退回 FLUID 的模态选择与 MINT；再退到 L4 即 R68。安全侧永不更松，效率侧才谈收益。整篇用一个**降级阶梯**把「证书强度」与「保守程度」显式绑定，避免"要么全信要么全停"的二元跳变。

**灵感 5（拓扑 OOD → 感知相似而拓扑不同，是纯似然检测的盲区）**
直觉：一扇门开着还是关着，像素分布可能几乎一样，但自由空间的同伦结构完全不同（一个连通分量变成两个，或 H₁ 换了一个环）。任何只看特征密度/似然的 OOD 检测器，在「感知几乎相同、拓扑已变」的场景下可以毫无告警。这既是 R69 流似然通道的盲区，也是本轮必须补的：需要**拓扑签名**（持久同调 / roadmap 连通图）与**主动探询**共同兜底。这也给出一个诚实的负面结论：**在有限感知下，单靠被动感知无法可靠检测同伦级变化**，所以交互不是锦上添花，而是拓扑 OOD 的必要条件。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（ROAM-RAS 总览）** ROAM-RAS = (HPP, ODA, DRC, TVC, ICS, RAS-WM‡)。在继承 R69 三条不变式（实时零学习写、交互预算硬约束、证据纪律）之外，新增两条：
(iv) **分布诚实性**：任何「可证」声明都必须附带其歧义集 ℳ 与交换性状态；交换性监控报警时，基于 ℳ 的证书立即作废，只能签发分布无关的兜底证书；
(v) **几何可验证性**：任何被提交的路线必须通过一个不依赖策略权重的几何/拓扑规划器认证；学习策略不得为自己作证。

**定义 311（环境歧义集 ℳ）** 设 m 为环境模型（占据栅格 + 动力学参数），o_{0:t} 为观测历史。ℳ_t = { m ∈ 𝔐 : m ⊨ o_{0:t}, D_𝒵(m, m̂_t) ≤ ρ_t }，其中 m̂_t 为当前地图估计，D_𝒵 为占据集 Hausdorff 距离与动力学参数范数的组合差异，ρ_t 为标定分位 Q_{1−α}。**关键标注**：ρ_t 的覆盖解释仅在可交换性成立时有效（定义 315）。

**定义 312（同伦类与路线）** 给定 m、起点 s_t、目标 g，自由空间 F(m) 中的路径按同伦划分为类 [γ]。每类取代表元 γ*_[γ]（最短/最平滑），并构造可行走廊 T_[γ] = { x : d(x, γ*_[γ]) ≤ w(x) }。

**定义 313（同伦提升与几何可采纳）** 流模态 ξ_k 的工作空间轨迹为 τ_k。若 τ_k ⊂ F(m̂)，其同伦提升为 [γ_k]；否则为 ⊥。称 ξ_k **几何可采纳**当且仅当 [γ_k] ≠ ⊥ 且在 ℳ 上鲁棒可行（定义 314）。不可采纳的模态为**幻影模态**，TVC 直接否决。

**定义 314（鲁棒可行性与走廊）** 类 [γ] 在 ℳ 上 **（ε, δ)-鲁棒可行**，若以概率 ≥ 1−δ（对 ℳ 的场景采样/或对 ∀m∈ℳ 的管道界）存在一条同伦意义下属于 [γ] 的动力学可行路径，其障碍净空 ≥ ε、控制量在包络内。管道版判据：若 Hausdorff(m, m̂) ≤ ρ 且代表元净空 ≥ ρ + e_tr（e_tr 为跟踪误差界），则鲁棒可行；场景版由 N 个一致场景给出 P(违反) ≤ O(log(1/δ)/N)。

**定义 315（OOD 分数与交换性监控）** 一致性非符合度 s_OOD(o)；交换性用**随时有效**的 e-process E_t = ∏_{i≤t}(1 + λ_i (s_i − μ_0))（或测试鞅）监控，E_t ≥ 1/α 即报警。位移类型显式分类：协变量位移、动力学位移、**拓扑位移**（定义 316）、目标/意图位移。报警即撤销 ℳ 的覆盖承诺。

**定义 316（拓扑签名与拓扑 OOD）** 自由空间的持久同调条形码（或 roadmap 连通图）签名 Σ(m)。拓扑 OOD 判据：d_B(Σ(m̂), Σ_train) > τ_top，或出现训练支撑中不存在的同调类（通道开/闭、环数变化）。**与特征密度 OOD 正交**：存在感知几乎相同、Σ 不同的场景（定义 316 引理见引理 21）。

**定义 317（分布鲁棒路线规划 DRC）** π* = argmin_{[γ] 鲁棒可行} sup_{m∈ℳ} J([γ], m) + β·Risk([γ], m)，其中 J 为路程/能耗/时耗，Risk 为碰撞/违约风险；等价于对 ℳ 求 CVaR_α。当空可行集时 DRC 返回 ∅，触发降级阶梯。

**定义 318（安全门廊与分布无关兜底）** 安全门廊 K_safe 为从该状态集出发存在**分布无关**不变安全控制（如在已知刹车距离内刹停）的状态集合。要求所选路线的前缀满足**安全可达屏障** B(x) ≥ 0（对 ∀m∈ℳ 与有界扰动，K_safe 仍可鲁棒到达）。B 是控制障碍函数在「可达性」上的类比：不保证永不碰撞某物，而保证**永远有退路**。

**定义 319（路线级 VoI）** VoI(g) = H([Γ]|o) − E_{y~p(·|g,o)}[H([Γ]|o,y)] − c_geo(g) − c_risk(g)，其中 [Γ] 为同伦类后验。信息动作不仅更新模态，还更新 ℳ，从而改变可行类集合。VoI−成本 ≤ 0 则不交互，退 R69。

**定义 320（主动分布检验 / canary 动作）** 选择 g 最大化交换性判定的期望证据增长：g* = argmax_g E[log(E_{t+1}/E_t) | g] − c(g)，即选最能区分「可交换」与「已位移」的观测。目的：把「地图不清（epistemic，可问）」与「世界已变（shift，问了也可能无效）」分开。

**定义 321（降级阶梯 DLG）** 五级：
- **L0**：L0 证书齐全（鲁棒可行 ∧ 交换性未报警 ∧ R69 证据纪律满足），执行鲁棒路线；
- **L1**：可约歧义（VoI>0 且预算内），先交互缩小 ℳ；
- **L2**：仅在已验证子集/放大裕度上鲁棒可行，或选「安全门廊裕度最大」的类；
- **L3**：退回 K_safe 的分布无关兜底，不再声称任何学习/覆盖保证；
- **L4**：R68 纯保守（λ_floor、最小风险刹停）。
阶梯单调：沿级别上升 λ 单调不降、速度上界单调不增；切换带迟滞，禁止抖动。

**定义 322（走廊安全盾 TVC-Shield）** 运行时若预测自车状态离开已认证走廊 T_[γ] 或 B(x)<0，则制动/投影回走廊并同级重规划；若该类被新观测证伪（幻影或新障碍改变同伦），立即跳到 L2 及以上。**任何动作都不得逃出几何证书**。

**定义 323（三源证据纪律）** 路线提交需三源中至少两源一致且第三源不反对：几何见证（TVC 可行）、行为见证（R69 的 FMA 流似然/AUD 模态）、分布见证（ODA 交换性/拓扑签名）。单一来源永不单独定案。R69 的 k 正交证据纪律成为其在固定地图、单类情形下的特例。

**定义 324（证书 J_ROAM）** J_ROAM = (J_FLUID, homotopy_id, robust_feasible, min_clearance, ℳ_coverage, exchangeability_p, ood_score, topo_sig_dist, porch_margin, fallback_level, degradation_hash, roam_ver)。Valid ⇔ Valid(J_FLUID) ∧ 三源纪律 ∧ 阶梯级别与证书强度一致 ∧ 分布诚实性成立。

**定义 325（威胁模型 ℰ_ROAM）** ℰ_ROAM = ℰ_FLUID × ℰ_shift(协变量/动力学/拓扑) × ℰ_map(地图过时、地标伪造) × ℰ_corridor(对抗性障碍摆放专门破坏鲁棒裕度) × ℰ_ladder(诱导错误降级/升级)。

**定义 326（参与式审计 VQAuditor-O 与时序耦合）** 审计对象新增：OOD 声明是否有据、ℳ 覆盖是否被诚实撤销、阶梯切换是否必要、路线同伦是否被正确提升、门廊裕度是否被真实计算。结论回灌 AuditBuf，成为下一轮 ℳ 先验与交互成本先验。

class OODAmbiguityMonitor:
    def update(self, o_t, m_hat):

        self.s  = nonconformity(o_t)

        self.sig = persistent_homology(free_space(m_hat))

# IP-266 DRC：分布鲁棒选路（对 ℳ 求最坏情况/CVaR）
def choose_route(classes, M, beta):
    best = None
    for rep, T in classes:
        if not robust_feasible(rep, M, eps=EPS): continue
        worst = max(cost(rep, m) + beta*risk(rep, m) for m in scenario(M))
        if best is None or worst < best.worst: best = (rep, T, worst)
    return best                                   # None → 触发降级

def verify_modes(modes, classes, M):

        if cls is None or not robust_feasible(cls.rep, M, EPS): continue  # 幻影↑

## 3. 推导

**引理 19（几何见证的健全性与幻影否决）** 若真实模型 m ∈ ℳ 且几何规划器完备，则被 TVC 否决的模态在执行时要么碰撞、要么离开观测到的自由空间；即否决不会误杀一个在 m 下真正可行的模态。推论：把 R69 的幻影模态接受率从「流似然阈值决定」压到「几何不可行的模态一律 0 接受」——R69 最脆弱处的直接封堵。

**引理 20（歧义集上的管道鲁棒性）** 若 Hausdorff(m, m̂) ≤ ρ_t 且代表元净空 ≥ ρ_t + e_tr，则 [γ] 在 ℳ 上鲁棒可行；场景优化版：N 个 i.i.d. 场景下最坏违反概率 ≤ O(log(1/δ)/N)。故鲁棒性是（覆盖半径, 净空裕度, 跟踪误差）三者的显式函数，可被监控。

**引理 21（感知-拓扑盲区）** 存在环境对 (m, m′) 使感知分布距离任意小，而同调签名不同（门开/闭、通道开/闭）；因此任何仅依赖特征密度/似然的 OOD 检测器在阈值 τ 下都无法区分。系：拓扑 OOD 必须依赖拓扑签名或主动探询——交互是必要条件，不是装饰。

**定理 18（ROAM 严格包含 FLUID 与 R68）** 当 ℳ 为单点、只有单一同伦类、交换性成立时，DRC 的可行集唯一，鲁棒代价退化为 FLUID 的模态代价，路线选择逐指令等于 R69 的模态选择；L4 等于 R68。故任意状态下 ROAM 的期望风险 ≤ FLUID ≤ R68，且在三项退化条件同时成立时逐指令相同。安全侧不做任何让步。

**定理 19（分布诚实性 / 不发空头证书）** 交换性监控未报警期间，基于 ℳ 的 conformal 覆盖以 ≥1−α 成立（随时有效 e-process）；一旦报警，J_ROAM 撤销覆盖字段且只允许签发 L3/L4 的分布无关证书。因此系统**永远不会给出它无法背书的保证**——这是比「有一个证明」更强的工程性质。

**定理 20（阶梯单调与有限切换）** 在迟滞与 (λ↑, v_max↓) 单调约束下，降级阶梯构成一个格；每次切换都携带证书且状态单调，故在有限时间内切换次数有限、控制连续、切换点有界加加速度（jerk）。L0↔L2 的抖动被迟滞消除。

## 6. 本轮最大风险

**一句话**：ROAM-RAS 把安全押在「歧义集 ℳ 与几何规划器的模型足够覆盖真实环境」上——但 OOD 恰恰可以表现为**地图本身不可见地失真**（未知未知、拓扑在感知盲区内改变、地图被投毒）：此时「鲁棒可行」的证书是**空洞的**，系统会因为手里握着一份「几何证明」而比 R69 更自信，从而**自信地认证一条并不存在的走廊**。几何上的确定性不等于分布上的有效性——**被证明得越漂亮，越可能是在错误的世界上证明的**。

## 4. 推导

**引理 19（几何见证健全性与幻影否决）** 若真实模型 m ∈ ℳ 且几何规划器完备，则被 TVC 否决的模态在 m 下执行必然碰撞或离开观测自由空间，故否决不误杀真可行模态；把 R69 的幻影接受从「流似然阈值」压到「几何不可行一律 0 接受」，直接封堵 R69 最脆弱处。

**引理 20（歧义集上的管道鲁棒性）** 若 `Hausdorff(m,m̂) ≤ ρ_t` 且代表元净空 `≥ ρ_t + e_tr`，则 `[γ]` 鲁棒可行；场景优化版最坏违反概率 `≤ O(log(1/δ)/N)`。鲁棒性因此是（覆盖半径, 净空裕度, 跟踪误差）的显式可监控函数。

**引理 21（感知-拓扑盲区）** 存在环境对 `(m,m′)` 使感知分布距离任意小但同调签名不同（门/通道开闭）；任何仅依赖特征密度/似然的 OOD 检测器在固定阈值下无法区分。系：拓扑 OOD 必须依赖拓扑签名或主动探询——交互是必要条件。

**定理 18（ROAM 严格包含 FLUID 与 R68）** 单点 ℳ、单一同伦类、交换性成立时，DRC 可行集唯一、鲁棒代价退化为 FLUID 模态代价，路线选择逐指令等于 R69；L4 等于 R68。故任意状态期望风险 `ROAM ≤ FLUID ≤ R68`，退化条件下逐指令相同——安全不让步，效率取拓扑/分布认证的收益。

**定理 19（分布诚实性 / 不发空头证书）** 交换性未报警时，基于 ℳ 的覆盖以 `≥1−α` 成立（任意时有效 e-process）；报警后 J_ROAM 撤销覆盖字段，只允许签发 L3/L4 的分布无关证书。系统永不给出无法背书的保证——比「有一个证明」更强的工程性质。

**定理 20（阶梯单调与有限切换）** 迟滞 + `(λ↑, v_max↓)` 单调约束下，降级阶梯构成格；每次切换携带证书且状态单调，故有限时间切换次数有限、控制连续、切换点 jerk 有界；L0↔L2 抖动被迟滞消除。

## 7. 本轮最大风险

**一句话**：ROAM-RAS 把安全押在「歧义集 ℳ 与几何规划器模型足够覆盖真实环境」上——但 OOD 恰恰可以表现为**地图本身不可见地失真**（未知未知、拓扑在感知盲区内改变、地图被投毒）：此时「鲁棒可行」证书是**空洞的**，系统会因手握「几何证明」而比 R69 更自信，**自信地认证一条并不存在的走廊**。几何上的确定性不等于分布上的有效性——**被证明得越漂亮，越可能是在错误的世界上证明的**。

**次级风险与缓解**：鲁棒过保守 → 死锁/冻结（门廊裕度 + L2 增益调度 + VoI/成本拐点 E-类研究）；拓扑 OOD 计算开销（增量持久同调 + 可疑时才全量重算）；交互预算不足缩小 ℳ（VoI 门槛 + 退化 R69）；分布鲁棒优化样本复杂度（场景数上限 + 管道解析判据兜底）；阶梯切换抖动（迟滞 + 定理 20）；地图投毒（ℰ_map 对抗训练 + 三源证据纪律 + VQAuditor-O）。
