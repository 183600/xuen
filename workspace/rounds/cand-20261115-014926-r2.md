# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「通用机器人」×「事件相机」）

> R69 把「不确定」一分为二：aleatoric 收紧、epistemic 去问，并用一条 k-正交证据纪律约束「问」。但它仍有两个未言明的前提：**(P1) 身体是常量**——策略、动作空间、标定都在同一台机器上闭合；**(P2) 感知是绝对量**——帧相机测的是外观（DC），标定残差也活在这个 DC 世界里，所以 R69 的 FMA 只能用「策略似然」做第二意见，而似然本身可以被一个学会了偏置的策略吸收。R69 自陈的最大风险（问错比不问更危险）只是表层；更深的一层是：**它问的是别人，却从未问过自己的身体，也从未用一条不测绝对量、只测变化的通道来核对世界。**
>
> 本轮两个灵感正好拆掉这两个前提：
> - **通用机器人**把「身体」从常量变成变量：一个策略要跨形态、跨传感器、跨工具迁移，模块还能热插拔。此时最深的不确定性不是「选哪个动作模态」，而是「**我还是我以为的那个身体吗？这套动作在这个身体上还是这个意思吗？**」——命名 **U_emb（embodiment uncertainty）**。
> - **事件相机**测的不是亮度，而是亮度变化：微秒级、HDR、无运动模糊、低带宽。关键性质不是「更快的图像」，而是 **AC 耦合**——**静态的加性标定漂移不产生事件，真实运动才产生事件**。于是它天然是一条「标定不可吸收」的 DC 盲见证，正好补在 R68/R69 最脆弱的地方；同时它与帧相机、IMU、关节编码器构成真正正交的证据三角。
>
> 核心命题：**把「本体不确定性」从 epistemic 中单独拎出，交给「事件驱动的自运动分解 + 认证过的主动本体探针」去消解；把事件通道当作 AC 耦合的见证者，用于慢变故障判别、跨本体实现校验和亚毫秒反射；并立一条铁律：事件只提案、不单独定案——不可逆动作必须由事件 + 帧/IMU/力矩中的至少一个正交源确认。** 命名 **NERVE-RAS**（Neuromorphic Event-driven Reflex & Verification for Embodied systems）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我还是这个身体吗，是世界在动还是我在动**」——从「向他人提问」走到「向自己的身体提问」。

## 0. 直觉与动机

**灵感 1（通用机器人 → 身体是变量，不是常量）**
直觉：单机策略把「本体」当成一个隐式常量写进了权重里；通用机器人要求同一个意图在不同身体上兑现。换轮距、换臂长、换夹爪、换相机安装、加一个负载，动作的**语义**没变、**实现**变了。人不会因为换了一副手套就不会拿杯子，因为人区分「意图」和「实现」，并有一份实时更新的**身体图式（body schema）**。R69 的流策略只生成一个动作块 ξ=(a,g)，把意图和实现焊死在一起；一旦身体变了，多模态分布会静默地系统性偏移——这不是 aleatoric 噪声，也不是「选哪个模态」的 epistemic 歧义，而是**模型所条件的那个身体已经不存在了**。这类不确定性可约（探一下就知道），但**不能靠问人**，只能靠**自己动一下、看结果**。这是 R69 交互空间里缺失的一类：**零社交成本的本体探针**。

**灵感 2（事件相机 → AC 耦合的见证）**
直觉：帧相机记录「现在多亮」，事件相机记录「哪里刚刚变了」。加性慢变偏置 b(t) 对时间导数几乎无贡献，所以**静态标定漂移在事件流里是隐形的**；反过来，一个真实运动的物体在事件流里必然留下极性脉冲。这不是又一路冗余传感器，而是一路**结构上不同的问题提法**：DC 通道问「它看起来是什么」，AC 通道问「它刚刚怎么动」。R68/R69 的缓变故障之所以能被标定吸收，是因为残差和标定都在 DC 世界里；事件通道把核对搬到了 AC 世界，**标定层没有可以拿来吸收它的参数**。同时，事件流没有绝对亮度，因此**静止的世界对它是黑的**——这份「盲」不是缺陷，而是必须被显式建模的边界（引理 22）。

**灵感 3（自运动分解 → 把「身体」变成可测量的量）**
直觉：事件流里的像素运动 = 自运动场（由身体图式、关节速度、IMU 决定）+ 独立物体运动。给定标称身体，可以预测自运动场；实测减预测，残差 r_emb 就是「**身体不是我以为什么**」的直接证据：外参偏了、轮子打滑、负载变了、相机被碰歪了、夹爪没夹住。于是本体标定不再是部署前的一次性离线工序，而是**可主动激发、可在线认证、可写进证书**的运行时行为。探针本身要小、要安全、要有信息量——这正好复用 R69 的 VoI 框架，只是把「问人」换成「问身体」。

**灵感 4（意图—实现因子化 → 跨本体迁移的可认证接口）**
直觉：通用机器人要的不是「一个模型适配所有身体」的神话，而是**共享意图 + 每身体认证实现**。把 R69 的流策略拆成两层：流模型生成形态无关的任务空间意图 u（去哪里、抓什么、施加多大扳手），实现适配器 φ_B 把 u 兑现成具体关节/轮/夹爪指令。跨本体迁移的风险由此变成一个可度量的量：**实现失配**，而不是一个不可解释的端到端掉点。一个来自别的身体的技能，只有在它的实现适配器通过身体证书（BSC）与效应残差门时，才被准入。

**灵感 5（双刃剑 → AC 见证的三种死法）**
直觉：把事件相机当「不可腐坏的见证」是危险的。它至少三种死法：(a) **静态盲**——静止障碍、静止的人、缓慢漂移都不发事件，恰恰是安全最需要绝对状态的时刻；(b) **噪声触发**——热像素、闪烁、振动、对抗性事件注入会伪造「有东西在动」，若直接驱动反射层，就会把「更安全」变成「更会急刹」；(c) **时间戳欺骗/错位**——事件异步、帧同步，若同步边界被破坏，跨模态「一致」可以是被制造出来的一致。因此 NERVE 的纪律必须比 R69 更硬：**事件只能提案（propose），不能单独定案（decide）**；反射层只允许「收缩型」动作（减速、回撤、顺应），不允许发起新任务运动。否则我们只是给 R69 的「会撒谎的嘴」又装了一双「会幻动的眼」。

## 1. 形式化定义（增量：定义 310–325）

A99（事件见证假设）：事件相机内参在标定有效期内可信；其外参不是根信任，而是与关节/IMU 联合辨识的身体图式的一部分，且必须接受交叉见证。
A100（DC 小漂移假设）：帧侧慢变标定误差可写成加性偏置 b(t)，|ḃ| ≤ β；在标定窗口内 β 足够小，使事件生成条件的一阶变化有界（引理 19）。
A101（持续激励假设）：认证探针在观测窗口内提供足够的视差与关节激励，使身体参数在对称群下可辨识（引理 20）。
A102（实现 Lipschitz 假设）：任务空间意图到身体实现的映射对意图局部 Lipschitz，常数 L_φ 有界。

**定义 310（NERVE-RAS 总览）** NERVE-RAS = (EBP, EMD, BSP, BSC, ART, ECR, RCB, RAS-WM‡)。四条不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **事件只提案**：事件通道不得成为任何不可逆动作的唯一授权源；至少一个正交源（帧/IMU/关节力矩）确认；
(iii) **身体—策略绑定**：高自由度动作执行前，必须持有与当前身体图、传感器图和时间戳匹配的 BSC（定义 316）；
(iv) **反射有界权**：事件反射只允许收缩型动作（定义 319），不得扩张安全包络。

**定义 311（身体图与本体不确定性）** 身体图 B = (V_L 连杆, E_J 关节, S 传感器集, T 工具集, 安装关系)。身体图式参数 θ_B ∈ Θ（连杆偏置、关节零点、相机外参、轮半径、工具 TCP）。本体不确定性
U_emb = D_KL(p(θ_B|o) ‖ p_0(θ_B)) + H(θ_B|o)，
其中 p_0 为出厂/上次认证先验。与 U_ale（噪声）、U_epi（动作模态歧义）不同：U_emb 的条件变量是**身体本身**。

**定义 312（事件流与事件帧）** 事件流 E = {(x_i, y_i, t_i, p_i)}，p_i∈{−1,+1}；事件生成近似
e(t) = 1[ |∂_t log I(x,t)| ≥ C ]（C 为对比阈值，含不应期与噪声）。时间表面 S_t(x) = Σ_i p_i exp(−(t−t_i)/τ) 在像素邻域聚合；事件帧以固定事件数或固定时窗切分，禁止用帧时钟硬切（避免时间戳错位）。

**定义 313（AC/DC 分解与 DC 盲投影）** 对数亮度 L = log I 分解为缓慢的 DC 分量 L_DC（含加性标定偏置 b(t)）与 AC 分量 L_AC（场景相对变化）。事件生成只依赖 ∂_t L = ∂_t L_AC + ∂_t b，且 ∂_t b 在 A100 下有界。定义 DC 盲投影 Π_DC：丢弃所有不随时间变化的分量；事件见证 w_E = Π_DC(o_event) 对常数 b 严格不变，对慢变 b 只有 O(β) 敏感度。

**定义 314（事件自运动分解 EMD）** 由 θ_B、关节速度 q̇、IMU 得到预测自运动场 F_ego(x; θ_B, q̇, ω, v)；事件流估计的观测流为 F_ev。本体残差
r_emb = ‖F_ev − F_ego‖_{robust}，
并按视差/深度分层归一化。独立物体运动记为 F_ind = F_ev − F_ego 的高残差分量。r_emb 高而 r_res（R68 传感器残差）低 ⇒ **身体图式漂移**而非传感器噪声。

**定义 315（认证本体探针 BSP）** 探针是短时、闭环、在安全包络内的全身微激励 ξ_probe（关节小幅正弦/轮子差速/腕部平移/相机轻摆），其信息增益
VoI_B(ξ_probe) = H(θ_B|o) − E_{y~p(·|ξ_probe,o)}[H(θ_B|o,y)]，
选择 ξ* = argmax [VoI_B − c_probe − λ_safe·risk(ξ_probe)]，s.t. ξ_probe ∈ 𝒮_cert（C-RAS-WM 认证包络）且不改变任务进度（可插入任务间隙/等待期）。VoI_B ≤ 成本则**不探**，U_emb 保持未消解（不得假装已标定）。

**定义 316（身体图证书 BSC）** BSC = (body_hash, sensor_graph_hash, θ̂_B, Σ_B, excitation_log_hash, sync_ledger_hash, issue_time, expiry, nerve_ver)。Valid ⇔ r_emb ≤ τ_emb ∧ Σ_B 的迹 ≤ τ_Σ ∧ 探针在有效期内 ∧ 同步账本完整（定义 320）。**策略版本 p 与身体图 B 的配对 (p, B) 才是可执行单元**；换体/换工具即令 BSC 失效，必须先重认证或降级到意图层。

**定义 317（意图—实现因子化 ART）** 策略输出 ξ = (u, φ_B(u))：u ∈ 𝒰 为形态无关意图（末端位姿增量、抓取力、速度旋量、接触期望），φ_B: 𝒰→𝒜_B 为当前身体的实现适配器（逆运动学/轮式控制器/夹爪映射）。流模型只生成 u（R69 的 FMP 被保留为意图生成器）；φ_B 由 BSC 认证。跨本体共享 u 的分布，不共享 φ。

**定义 318（跨本体不变事件表示）** 用内参 K 与自运动补偿把事件投影到规范身体坐标系，得到 E_norm = Rect_{K,θ_B}(S_t)。要求表示对相机安装位姿、尺度、外观纹理不变：d(E_norm^A, E_norm^B) 仅依赖相对运动与场景几何。跨本体迁移时用它作为共享感知底座，避免「换个相机就换一套特征」。

**定义 319（事件触发反射层 ECR）** 事件特征 f_E（事件率突增、极性一致的运动前沿、时间表面梯度）在 <1ms 内触发候选反射 r ∈ {slow_down, retract, comply, hold}。两键规则：r 需要 f_E 与至少一个正交源（IMU 冲击、关节力矩突变、帧/RGB-D 近距确认）同向；单键只能触发**最保守收缩**（限速到 v_floor），不得触发方向性动作。反射权限受限于认证安全集的收缩子集：r ∈ Contract(𝒮_cert)，永不扩张。

**定义 320（时间同步与延迟账本）** 定义事件—帧—IMU 的同步裕度 δ_sync = max pairwise |t_a − t_b − Δ̂_ab|，其中 Δ̂ 为在线估计的固定延迟。若 δ_sync > τ_sync，跨模态证据判为**无效**（不是弱证据），并记入延迟账本；证书携带 sync_p99。禁止把不同步的「一致」当作证据纪律的 k 源。

**定义 321（不确定性四分）** 每轮分解为
U_ale（模态内噪声）→ R68 λ_floor；
U_epi（动作模态歧义）→ R69 MINT 交互；
U_emb（身体图式不确定）→ 定义 315 本体探针；

**定义 322（事件证据纪律与 ℰ_event）** 事件证据不得单源定案。干扰集

**定义 323（证书 J_NERVE）** J_NERVE = (J_FLUID, body_hash, BSC_valid, U_emb_before, U_emb_after, r_emb_p95, sync_p99, event_witness_ratio, reflex_authority_log_hash, nerve_ver)。Valid ⇔ Valid(J_FLUID) ∧ BSC_valid ∧ sync_p99 ≤ τ_sync ∧ 反射日志可审计。

**定义 324（三级退避）** (1) 健康：事件 + 帧 + 本体一致 ⇒ 享 R69 的 resolution bonus，并可开启反射层；
(2) 本体不确定（r_emb 高/BSC 过期）⇒ 冻结高自由度实现，只执行**意图层**已认证技能（低维、慢速、可回退），并安排探针；

```python
# IP-264 EBP：事件预处理（时间表面 + 同步账本 + 噪声抑制）
class EventBackbone:
    def __init__(self, K, tau=5e-3, refractory=1e-3):
        self.K, self.tau, self.refr = K, tau, refractory
    def time_surface(self, events, t_now):
        # 热像素/不应期过滤；按事件数切帧，不按帧时钟硬切
        ev = denoise(events, self.refr)
        return sum(p * exp(-(t_now - t)/self.tau) for x, y, t, p in ev)
    def sync(self, t_ev, t_frame, t_imu):
        d = max_pairwise_skew(t_ev, t_frame, t_imu, self.delay_hat)
        return d, d <= TAU_SYNC

# IP-265 EMD：事件自运动分解 → 本体残差
def embodiment_residual(ev_surface, theta_B, qdot, imu):
    F_ego = predict_ego_flow(theta_B, qdot, imu)     # 由身体图式预测
    F_ev  = estimate_event_flow(ev_surface)          # 法向流 + 视差分层
    r_emb = robust_norm(F_ev - F_ego)
    F_ind = high_residual_component(F_ev, F_ego)     # 独立物体运动
    return r_emb, F_ind

# IP-266 BSP：认证本体探针（VoI，仅在不改变任务时插入）
def body_probe(theta_prior, safety_env, budget):
    best = None
    for xi in probe_candidates(theta_prior):         # 关节微激/差速/腕摆
        if not c_ras_wm.certify(xi, safety_env): continue
        if not budget.allows(xi): continue
        voi = entropy(theta_prior) - expected_entropy(theta_prior, xi)
        score = voi - cost(xi) - LAMBDA_SAFE * risk(xi)
        if best is None or score > best.score: best = (xi, score)
    return best if best and best.score > 0 else None  # 无收益 → 不探，U_emb 不消解

# IP-267 BSC：身体图证书签发（绑定策略版本、身体、时间）

    return BSC(body_hash(B), sensor_graph_hash(S), theta_hat, Sigma,

# IP-269 ECR：事件反射（两键 + 收缩型权限）
def event_reflex(f_E, imu, torque, near, reported):

    keys = int(imu.shock) + int(torque.jump) + int(near.close)
```

## 3. 推导

**引理 19（AC 盲性与 DC 不可吸收）** 在 A100 下，设帧侧标定误差为加性偏置 b(t)，事件生成条件为 |∂_t log I| ≥ C。常数 b 对 ∂_t log I 无贡献，故事件时序对 b 严格不变；慢变 b 使事件率的一阶改变量 ≤ κ·β/I_min（κ 为对比阈值常数）。因此事件见证 w_E 对 DC 漂移的敏感度是 O(β)，而帧残差 r_res 的一阶敏感度是 O(‖b‖)——**两者对「缓变故障」的敏感阶数不同**。系：把 (r_res, Δa, r_emb/w_E) 三联起来，可把「真漂移（三通道同向）」「标定吸收（r_res↓, Δa↑, w_E 不变）」「本体漂移（r_emb↑, w_E 与运动一致）」分开。注意边界：若 b 大到改变局部对比度，事件率仍会下降——事件不是绝对免疫，只是**不吸收静态偏置**。

**引理 20（本体可辨识性）** 在 A101 下，认证探针提供的观测方程 y = h(θ_B) + n 在对称群 G（整体刚体变换/尺度，若无可观测锚点）下局部可辨识；参数误差满足 ‖θ̂_B − θ_B‖ ≤ cond(J_probe)·σ_n + ε_model。若激励不足（cond→∞，如纯平移无视差、静止不动），则 U_emb 不可辨识——**此时系统必须承认不知道，而不是签发 BSC**。系：探针的价值等于把 cond(J_probe) 降下来的量，这正是 VoI_B 的几何含义。

**引理 21（跨本体负迁移上界）** 在 A102 下，若意图分布相同、实现适配器失配为 ε_φ，则身体 B 上的期望风险 ≤ 源身体风险 + L_φ·ε_φ + L_task·W_1(p_u^A, p_u^B)。系：跨本体迁移应尽量共享 u（第二项小），并把 ε_φ 纳入 BSC 准入门——**不能通过证书的实现，不上身体**。

**引理 22（静态盲区）** 事件率随场景运动幅度单调趋零：‖F_ev‖ → 0 ⇒ 事件率 → 0。因此对任意静止障碍/静止人，基于事件的检测概率在无主动激励时 → 0。系：事件通道必须与帧/深度/ToF **并联**；「事件没响」不能推出「安全」，只能推出「无变化」。这条引理是定义 310-ii 与 319 的理论根据。

**定理 18（NERVE 严格包含 FLUID）** 在 A99–A102 下，固定身体（B 不变、BSC 恒有效）、事件通道健康且被禁用、同步裕度充足时，NERVE 的意图生成、交互决策与风险缩放逐指令等价于 FLUID（R69）；若事件不可信或静态盲，则按定义 324 退回 FLUID/R68，安全侧不降。故 R69 是 NERVE 在「身体固定 + 事件关闭」边界上的退化。

**定理 19（反射安全与有界权）** ECR 的反射动作 r ∈ Contract(𝒮_cert)，且两键规则要求正交源同向；单键只允许限速。则对任意触发（含误触发/事件注入），r 不扩张认证安全集，最坏后果是**有界减速/回撤**而非新碰撞；若误触发率有上界 p_fp，则任务完成时间的期望增加 ≤ p_fp·T_retract。系：把「更安全」与「更会急刹」分开——反射可以保守，但不能危险，也不能无限保守。

## 6. 本轮最大风险

**一句话**：NERVE 把「不可吸收的见证」押在事件通道的 AC 性质上，但事件相机本质上只会说「**刚刚变了**」，不会说「**现在有什么**」——**在静止障碍、静止的人、缓慢漂移这些最需要绝对状态的时刻，它恰好是盲的；而它的稀疏与噪声又足以伪造「有东西在动」，如果系统把「事件没响」当成安全、或把「事件响了」当成真相，就会在最该看见的时候自信地失明，或把一次热像素/闪烁/注入变成一次急刹甚至错误回撤**。一句话：**用「变化」证明「存在」，是 NERVE 的根，也是它的病。**

**定义 322–323（干扰与证书）** `ℰ_NERVE=ℰ_FLUID×ℰ_event`；命中即降权为提案。`J_NERVE` 并入 body_hash、BSC、U_emb、r_emb、sync、witness、reflex 日志。

**定义 324–325（三级退避与事件门控）** 健康→享 R69 resolution bonus + 反射；本体不确定→冻结高自由度、只走意图层并安排探针；事件不可信/静态盲/同步失效→关闭事件授权、退回 R69/R68。事件门控按动态与 DC 分歧开门，并审计开关本身。

## 3. 关键算法伪代码

```python
# IP-264 EBP：事件预处理 + 同步账本
class EventBackbone:
    def time_surface(self, events, t_now):
        ev = denoise(events, self.refr)                 # 热像素/不应期过滤
        return sum(p * exp(-(t_now - t)/self.tau) for x, y, t, p in ev)
    def sync(self, t_ev, t_frame, t_imu):
        d = max_pairwise_skew(t_ev, t_frame, t_imu, self.delay_hat)
        return d, d <= TAU_SYNC                         # 越界=证据无效，不是弱证据

# IP-265 EMD：事件自运动分解
def embodiment_residual(ev_surface, theta_B, qdot, imu):
    F_ego = predict_ego_flow(theta_B, qdot, imu)
    F_ev  = estimate_event_flow(ev_surface)
    return robust_norm(F_ev - F_ego), high_residual_component(F_ev, F_ego)

# IP-266 BSP：VoI 本体探针
def body_probe(theta_prior, safety_env, budget):
    best = None
    for xi in probe_candidates(theta_prior):
        if not c_ras_wm.certify(xi, safety_env) or not budget.allows(xi): continue
        score = (entropy(theta_prior) - expected_entropy(theta_prior, xi)) \
                - cost(xi) - LAMBDA_SAFE * risk(xi)
        if best is None or score > best.score: best = (xi, score)
    return best if best and best.score > 0 else None   # 无收益→不探，U_emb 不消解

# IP-267 BSC：身体—策略绑定证书
def issue_bsc(theta_hat, Sigma, probe_log, sync_ledger):
    if trace(Sigma) > TAU_SIGMA or sync_ledger.p99 > TAU_SYNC: return None
    return BSC(body_hash(B), sensor_graph_hash(S), theta_hat, Sigma,
               hash(probe_log), hash(sync_ledger), now(), now() + TTL, NERVE_VER)

# IP-268 ART：意图—实现因子化
def act(self, o, body):
    u = self.flow.sample_intent(o)                     # R69 FMP 复用，形态无关
    if not body.bsc.valid_for(self.policy_version):
        return self.degraded_intent_skill(u)           # 只执行低维已认证技能
    return self.adapters[body.id].realize(u, body.theta_hat)

# IP-269 ECR：事件反射（两键 + 收缩权限）
def event_reflex(f_E, imu, torque, near, reported):
    r = propose_reflex(f_E)
    keys = int(imu.shock) + int(torque.jump) + int(near.close)
    if keys >= 1 and same_direction(r, imu, torque, near):
        return restrict_to_contract(r, reported)       # 只收缩，不扩张
    return restrict_to_contract(slow_down(), reported) # 单键只允许限速

# IP-276 NERVE 主闭环（继承 R69，在其前加身体层）
def NERVE_round(M, obs):
    ok_sync, _ = M.ebp.sync(obs.t_ev, obs.t_frame, obs.t_imu)
    r_emb, F_ind = M.emd.embodiment_residual(
        M.ebp.time_surface(obs.events, obs.t_now), M.bsc.theta_hat, obs.qdot, obs.imu)
    body_ok = M.bsc.valid_for(M.policy_version) and r_emb <= TAU_EMB
    if not body_ok and M.bsp.triggerable(obs):
        xi = M.bsp.body_probe(M.bsc.posterior, M.safety_env, M.budget)
        if xi is not None:
            M.execute_certified(xi); M.bsc.update(M.bsp.observe(xi))
    if M.event_gate(obs) and ok_sync:
        w_E = M.ebp.witness(obs.events); M.aud.attach_event_witness(w_E)
        M.ecr.arm(f_E=w_E.features, authority='contract_only')
    else:
        w_E = None                                    # 静态盲：显式记录
    U_ale, U_epi, modes = M.fluid.decompose_intent(obs)
    g = M.mint.choose_interaction(modes, obs, M.budget) if U_epi > TAU_EPI else None
    if g is not None: U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    u = M.art.select_intent(modes, U_epi) if body_ok else M.art.degraded_intent(modes)
    a = M.art.adapters[M.body.id].realize(u, M.bsc.theta_hat) if body_ok else u
    lam = max(M.efs.risk_scale(...),
              lam_floor(U_ale + (U_epi if g is None else 0.0)
                        + (0.0 if body_ok else U_emb_uncert(M.bsc))))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(a, M.vista.H), ..., wm_preds)
    if not ok_sync or w_E is None: M.aud.record_event_blind()
    M.vqa_n.submit_async(body_ok, r_emb, U_epi, w_E, M.ecr.log)
    return k, lam, a, (U_ale, U_epi, U_emb_uncert(M.bsc)), body_ok
```

## 4. 推导

**引理 19（AC 盲性与 DC 不可吸收）** A100 下，帧侧加性偏置 b(t) 对 `∂_t log I` 无贡献，常数 b 对事件时序严格不可见；慢变 b 使事件率一阶改变量 ≤ `κ·β/I_min`。故 `w_E` 对 DC 漂移敏感度 O(β)，`r_res` 对 `‖b‖` 敏感度 O(‖b‖)，二者阶数不同。系：`(r_res, Δa, r_emb/w_E)` 三联可分离「真漂移 / 标定吸收 / 本体漂移」。边界：b 大到改变局部对比度时事件率仍降——事件非绝对免疫，只是不吸收静态偏置。

**引理 20（本体可辨识性）** A101 下 `y=h(θ_B)+n` 在对称群 G 下局部可辨识，`‖θ̂_B−θ_B‖ ≤ cond(J_probe)·σ_n + ε_model`；激励不足（纯平移无视差、静止）则 `cond→∞`、U_emb 不可辨识——**必须承认不知道，不得签发 BSC**。系：探针价值 = 降低 cond(J_probe) 的量，即 VoI_B 的几何含义。

**引理 21（跨本体负迁移上界）** A102 下，`R_B ≤ R_A + L_φ·ε_φ + L_task·W_1(p_u^A,p_u^B)`。系：共享 u 使第二项小，实现失配 ε_φ 必须进 BSC 准入门——不能通过证书的实现不上身体。

**引理 22（静态盲区）** `‖F_ev‖→0 ⇒ 事件率→0`，静止障碍/静止人的事件检测概率在无主动激励时 →0。系：事件必须与帧/深度/ToF 并联；「没响」只推出「无变化」，推不出「安全」。这是定义 310-ii 与 319 的根据。

**定理 18（NERVE 严格包含 FLUID）** A99–A102 下，固定身体、BSC 恒有效、事件禁用且同步充足时，意图生成/交互决策/风险缩放逐指令等价于 R69；事件不可信或静态盲时按定义 324 退回 FLUID/R68，安全侧不降。R69 = 「身体固定 + 事件关闭」边界。

**定理 19（反射安全与有界权）** `r∈Contract(𝒮_cert)` 且两键要求正交源同向、单键只限速 ⇒ 任意触发（含误触发/注入）不扩张认证安全集，最坏为有界减速/回撤而非新碰撞；误触发率 `p_fp` 时完成时间期望增加 ≤ `p_fp·T_retract`。系：把「更安全」与「更会急刹」分开。

## 7. 本轮最大风险

**一句话**：NERVE 把「不可吸收的见证」押在事件通道的 AC 性质上，但事件相机只会说「**刚刚变了**」，不会说「**现在有什么**」——**在静止障碍、静止的人、缓慢漂移这些最需要绝对状态的时刻，它恰好是盲的；而它的稀疏与噪声又足以伪造「有东西在动」，若把「事件没响」当安全、把「事件响了」当真相，就会在最该看见时自信地失明，或把一次热像素/闪烁/注入变成急刹甚至错误回撤**。一句话：**用「变化」证明「存在」，是 NERVE 的根，也是它的病。**

**次级风险与缓解**：单一事件源成为新根信任（交叉见证三角 + BSC 不设根 + E302）；静态盲区被误读为安全（引理 22 + 多模态并联 + 显式记录盲区）；事件注入/闪烁伪造运动（两键规则 + 收缩权限 + ℰ_event 对抗训练 + E307）；时间戳错位制造假一致（δ_sync 越界即无效 + 延迟账本 + E306）；跨本体负迁移（ART 因子化 + 实现失配门 + 引理 21 + E301/E313）。
