# 第 1 轮（新灵感循环第 1 轮）· COM-IMP：常识引导的自适应阻抗控制

## 0. 先给直觉：为什么阻抗控制需要常识推理？

从现有研究的空白出发：
> **阻抗控制能稳定接触，却不懂物理常识**——K/D 调参依赖工程师经验或数据驱动，无法显式表达「物体不可穿透」「推门需沿铰链轴」「刚度突变需先降阻」等常识约束，导致泛化差、调参脆弱、OOD 时不安全。

常识推理正是对这一根本空白的回应：
- **阻抗控制** → 提供低层力-位合规性
- **常识推理** → 提供高层的物理可实现性约束
- **研究空白** → 二者长期脱耦，缺乏闭环的符号-数值接口

核心灵魂：**用常识约束把「纯数值阻抗」升级为「物理可解释阻抗」**。

一句话押注：
> **本轮提出 COM-IMP：为每个接触原语维护符号常识库 K，实时推理得到线性约束 A_t θ ≤ b_t，阻抗参数 θ_t = {K_t, D_t} 通过带常识约束的 QP 在线求解，实现「推理-调参-执行」的闭环；常识违反度直接作为安全信号，与传统阻抗稳定条件形成双保险。**

## 1. 研究日志：从数据驱动调参到常识约束调参

### 1.1 现有系统的三个症状
```text
G1. 研究空白：阻抗参数与任务语义脱钩，K/D 调整缺乏可解释的物理依据；
G2. 调参脆弱：数据驱动阻抗对材质/几何 OOD 敏感，刚度误估计导致冲击或迟滞；
G3. 安全滞后：阻抗超调后才靠力传感器触发保护，无法先验规避不等式约束违反。
```

### 1.2 三个新判断
1. **常识是阻抗的先验安全集**：物体 affordance、接触法线、运动学可行域可形式化为 θ 的凸不等式；
2. **推理可实时**：轻量符号推理器在 100Hz 内完成约束生成，QP 求解 <2ms；
3. **闭环增益**：常识约束减少可探索参数空间，降低数据需求，填补「经验调参」的研究空白。

### 1.3 与 PRISM-NAV 的关系
本轮与前轮 PRISM-NAV 不冲突而是互补：PRISM 提供想象式规划，本轮提供执行层常识安全。保留统一阻抗 L1，新增常识约束层 C0。

## 2. 直觉深化：常识为何比纯数据更可靠？

| 场景 | 纯数据阻抗 | COM-IMP |
|---|---|---|
| 推开未知弹簧门 k 变化 | 需重新采集数据估计 K | 常识「弹性物体需先低刚度探查」→ K_t ≤ K_max(spring) 自动约束 |
| 推箱子碰墙 | 力突增后才降速 | 常识「不可穿透」→ 法向 K 提前上界，阻尼下界 |
| 托举易碎杯 | 依赖示范数据 | 常识「脆弱物体力上限」→ f_des 约束映射为 K_t 上界 |

## 3. 正式化：COM-IMP 算法定义

### 3.1 符号
- 状态 s = (q, qdot, f_ext, o) , o = {geometry, material, affordance}
- 阻抗参数 θ = [k1..kn, d1..dn] ∈ Θ ⊂ ℝ^{2n}
- 常识库 K = {规则 r_i : pre_i(s) → A_i θ ≤ b_i}
- 阻抗动力学： M_d xddot + D(θ) xdot + K(θ)(x - x0) = f_ext

### 3.2 常识推理器 R_K
R_K(s) = { (A_i, b_i) | pre_i(s) 真 }
推理为一阶逻辑匹配，复杂度 O(|K|)

### 3.3 自适应阻抗 QP
θ_t^* = argmin_θ ||x_t - x_des||^2_Q + ||θ - θ_{t-1}||^2_R
s.t. A_t θ ≤ b_t
     θ_min ≤ θ ≤ θ_max
     D ≥ 2 sqrt(M K)  # 阻尼比可行

损失可分解为二次规划，实时求解。

### 3.4 安全融合
安全度 ρ_c = 1 - max(0, max_i (A_i θ^* - b_i) / margin )
与阻抗稳定信号 min 融合。

## 4. 性质与复杂度
**命题1**：若 K 中规则为真，QP 可行则闭环被动。
**命题2**：常识约束为凸，则 θ^*  Lipschitz 连续于 s。

复杂度：推理 O(|K|)，QP O(n^3) n≤12 可接受 <2ms。

## 5. 风险
**本轮最大风险**：常识库不完备导致过度约束或约束冲突，QP 不可行或导致过度保守的阻抗使任务无法完成。

## 6. 下一轮展望
若下轮灵感指向「研究空白+阻抗控制+常识推理」的延伸，可加入学习式常识补全或多智能体常识共享。

# 第 1 轮产物 · COM-IMP 技术报告：常识引导的自适应阻抗控制

## 0. 结论：用常识填补阻抗控制的研究空白

COM-IMP 在现有统一阻抗 L1 基础上做功能增强：
- **常识库 K**：符号化物理规则集合
- **推理器 R_K**：实时生成参数约束 A_t θ ≤ b_t
- **QP 调参器**：在线求解带约束阻抗参数
- **安全融合**：常识违反度 ρ_c 与阻抗稳定信号联合

## 1. 算法完整流程

### 1.1 离线构建
```
构建常识库 K:
  - affordance 规则: pushable → K_n ≤ K_max
  - fragility 规则: fragile → f_des ≤ f_max → K_t ≤ ...
  - collision 规则: in_contact → D_n ≥ D_min
  编译为线性模板 (A_i, b_i, pre_i)
```

### 1.2 在线循环 100Hz
```
def com_imp_step(s, x_des):
    C = []
    for r in K:
        if eval_pre(r.pre, s):
            A_i, b_i = instantiate(r, s)
            C.append((A_i, b_i))
    A_t = stack([A for A,_ in C])
    b_t = stack([b for _,b in C])
    θ_star = solve_qp(Q, R, A_t, b_t, θ_prev)
    τ = impedance_control(s, θ_star, x_des)
    ρ_c = commonsense_violation(A_t, b_t, θ_star)
    return τ, ρ_c, θ_star
```

## 2. Python 核心实现

```python
import numpy as np
from scipy.optimize import linprog

class CommonsenseRule:
    def __init__(self, name, pre_fn, A_fn, b_fn):
        self.name = name
        self.pre_fn = pre_fn
        self.A_fn = A_fn
        self.b_fn = b_fn

class CommonsenseKB:
    def __init__(self):
        self.rules = []
    def add(self, rule): self.rules.append(rule)
    def infer(self, s):
        A_list, b_list = [], []
        for r in self.rules:
            if r.pre_fn(s):
                A_list.append(r.A_fn(s))
                b_list.append(r.b_fn(s))
        if A_list:
            return np.vstack(A_list), np.concatenate(b_list)
        return np.empty((0,0)), np.empty(0)

class AdaptiveImpedanceController:
    def __init__(self, n_dof=6, Q=None, R=None):
        self.n = 2*n_dof
        self.Q = Q if Q is not None else np.eye(n_dof)
        self.R = R if R is not None else 0.1*np.eye(self.n)
        self.theta_prev = np.ones(self.n)*10.0

    def solve_qp(self, A, b, x_des, x_cur):
        # 简化：二次项通过投影梯度近似，先求无约束解再投影
        # 实际使用 OSQP
        error = x_cur - x_des
        grad = 2*self.Q @ error[:self.n//2]  # 简化
        theta_nom = self.theta_prev - 0.01*grad
        # 投影到可行域 via linprog 近似
        if A.shape[0] > 0:
            # 约束 A theta <= b
            c = self.R @ (theta_nom - self.theta_prev)
            res = linprog(c, A_ub=A, b_ub=b, bounds=[(0,None)]*self.n)
            if res.success:
                theta = res.x
            else:
                theta = self.theta_prev
        else:
            theta = theta_nom
        self.theta_prev = theta
        return theta

    def step(self, s, x_des, x_cur, kb):
        A, b = kb.infer(s)
        theta = self.solve_qp(A, b, x_des, x_cur)
        k = theta[:self.n//2]
        d = theta[self.n//2:]
        # 阻抗力
        e = x_des - x_cur
        v = s.get('v', np.zeros_like(e))
        f_imp = k*e + d*v
        rho_c = 0.0
        if A.shape[0]>0:
            viol = A @ theta - b
            rho_c = float(np.maximum(0, viol.max()))
        return f_imp, theta, rho_c
```

## 4. 正确性论证

**引理1**：若 A_t θ ≤ b_t 包含阻尼比约束 D ≥ 2√(M K)，则阻抗系统被动。
**定理1**：在规则 K 完备且推理正确时，COM-IMP 保持李雅普诺夫函数 V = ½ e^T K e + ½ v^T M v 单调递减，且常识违反度 ρ_c ≡ 0。
证明概要：QP 可行域包含被动集，目标包含正则项保证 θ 连续，标准阻抗稳定性成立。
