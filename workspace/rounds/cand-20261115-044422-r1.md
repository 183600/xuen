# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「研究空白」×「泛化能力」）

> R69 把不确定性一分为二（aleatoric / epistemic），给闭环装上了「会提问的嘴」：流匹配策略给出多模态动作分布，VoI 决定看不看、问不问、摸不摸，FMA 用动作似然做标定不可吸收的第二意见。它自陈的最大风险是「模态分布不可信 → 问错比不问更危险」，并给出 MCG 校准门作为缓解。
>
> 但这里有一个更深、也更隐蔽的洞：**R69 把不确定性分成了两层，却把「验证器」留在一层。** 定理 16 的「FLUID 严格包含 R68」是写在 A95–A98 成立的前提下的；A95（模态可分）、A98（策略密度对条件 Lipschitz）从未在运行时被检验；判断「模态权重可不可信」的 ECE，又只在同分布校准集上估计。于是我们面对一个**二阶缺口**：用来衡量泛化能力的尺子，本身没有泛化保证。**用一把会随温度变长的尺子去量另一把尺子**——这正是本轮两个灵感交汇处的研究空白。
>
> 核心命题：**要泛化的不是策略，而是「保证」本身。** 把 R69 的每条静态假设改写为可在线检验的零假设，把每个点估计（ECE、VoI、模态召回）替换为**分布无关、有限样本、任意时刻有效**的界，并显式给出一个「泛化包络」——包络之内才发放 resolution bonus，包络之外按已知的漂移半径加收安全附加费。命名 **GEM-RAS**（Generalization-Envelope-Monitored Risk-Adaptive System）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我的求证方式本身，还成立吗**」——从「验证世界」升级为「验证验证器」。

## 0. 直觉与动机

**灵感 1（研究空白 → 空白不在「再加一个模块」，而在「验证器的适用域」）**
直觉：初学者找空白，常找「没人做过 X」；成熟研究者找空白，找「所有人都默认、却从未被检验的前提」。R69 的 E286–E300 全是在固定基准上度量任务表现，没有一条实验度量**不确定性层自身的泛化**。它把「模态分布可信」写进定义 306 的 ECE 门，却没人问：部署分布一旦漂移，这个 ECE 门本身还成立吗？这就是空白：**系统的保证是有条件的，而条件是不可观测的。** 补这个空白不是再叠一个模块，而是把「条件」变成一等公民——可测、可审计、可触发退避。

**灵感 2（泛化能力 → 要泛化的对象是「证书」，不是「策略」）**
直觉：一个在训练分布上 ECE=0.03 的模态头，在光照/材质/体型漂移下可能 ECE=0.3，而它自己毫不知情；更糟的是，它会继续用旧的自信去算 VoI，于是「自信地问错」。泛化能力在这里的正确用法，不是让网络更鲁棒（那是策略泛化），而是让**关于网络的断言**在分布漂移下仍然为真：用分布无关的有限样本上界（change-of-measure / PAC 风格），把「我猜它准」换成「我能证明它在包络内准；包络多大，我诚实地报出来」。

**灵感 3（假设即假设检验 → e-process 把静态前提变成在线可证伪对象）**
直觉：A95–A98 现在只是纸面条件。若把每条假设映射成一个零假设 H0，并构造一个在 H0 下是非负上鞅的 e-process，则 Ville 不等式立刻给出**任意停止时刻**都成立的误报率 ≤ α——这恰好是固定阈值 ECE 做不到的（你每看一次就多一次误报机会）。于是「假设是否还成立」从一个哲学问题变成一个带 Type-I 保证的统计判决，而且不需要知道漂移后的分布形式。**这是本轮最重要的方法论姿态：把定理的前提搬到运行时，让它们自己去报警。**

**灵感 4（不变性 → 模态应由不变结构定义，而非环境相关捷径）**
直觉：R69 的 mode_head 在混合数据上训练，容易把「雨天=绕左」这类环境相关捷径当成模态结构；在训练环境内 ECE 很好，换环境就崩。泛化的经典答案是不变性：多个环境上做 group-DRO / 不变风险，要求**最差环境**的模态召回与校准都可接受。模态由此被锚定在跨环境稳定的物理/因果结构上，而不是某个数据集的统计巧合。注意：IMA 只用于**收紧证书**，不改变运行时拓扑，这样才不会破坏「严格包含」的干净性。

**灵感 5（交互的另一面 → 交互不只是消歧，也是漂移探针）**
直觉：R69 只把回答当作「关于世界」的证据。但若人/环境的回答**系统性地与模态后验矛盾**（总是选到 top-k 之外、总在同一个方向上纠正你），这其实不是世界的噪声，而是**你的模态模型错了**的证据。于是同一次交互获得双重用途：既降低 U_epi，又给 SAM 喂一个「模型自洽性」的 e-value。这让交互从「消耗预算的动作」升级为「同时做实验和做体检的动作」——也是 R70 对 R69「问错更危险」的正面回应：**问错若可被检测，就不再是静默的危险，而是可计费的证据。**

## 1. 形式化定义（增量：定义 310–325）

**定义 310（GEM-RAS 总览与四不变式）** GEM-RAS = (SAM, RCE, GCB, IMA, AVG, GRB, RAS-WM‡)，包裹在 FLUID-RAS 之外。四不变式：
(i) **三级嵌套包含**：GEM ⊇ FLUID ⊇ R68，安全侧永不更弱（定义 317、定理 18）；
(ii) **任意时刻有效**：所有报警与证书在任意停止时刻的 Type-I 错误 ≤ α，且不假设部署分布形式（定义 312、引理 19）；
(iii) **证书诚实**：任何 resolution bonus 的发放都必须附带一个分布无关上界，其真实覆盖率受元审计（定义 314、320、定理 20）；
(iv) **实时读路径冻结**：监控器只是只读统计累加器，不引入学习写操作（继承 R69 定义 293-i）。

**定义 311（可检验假设族）** 把 R69 的 A95–A98 与定义 306 的 MCG 前提映射为四个零假设：
H0^(1)：模态可分，Δ_min ≥ 3σ_in；
H0^(2)：模态后验校准良好，sup_x |P(M=m|·) − ŵ_m| ≤ ε_ece；
H0^(3)：策略密度对条件 Lipschitz，局部敏感度 L_z ≤ L_max；
H0^(4)：交互可信，单源回答与真实模态的一致率 ≥ 1 − δ_p。
每条 H0^(i) 只陈述「旧保证仍有效」，**拒绝**即意味着进入更高退避层级。

**定义 312（SAM：e-process 假设监控器）** 对每条 H0^(i) 取有界检验统计量 T_i(s)∈[0,1] 与均值上界 κ_i（H0 成立时 E[T_i|F_{s−1}]≤κ_i），用可预测投注 λ_s∈[0,1/(1−κ_i)] 构造
E_t^(i) = ∏_{s=1}^t (1 + λ_s (T_i(s) − κ_i))。
H0 下 E_t^(i) 为非负上鞅。报警规则：sup_{t} E_t^(i) ≥ 1/α。任意时刻误报率 ≤ α（Ville）。

**定义 313（泛化包络）** 以校准分布 P_cal 为中心、KL 半径 ρ 的包络 ℬ_ρ = {Q : D_KL(Q‖P_cal) ≤ ρ}。用无标签目标样本经分类器两样本检验（或 MMD）估得半径上置信界 ρ_up（置信 1−α），估计误差经并合界并入 ρ_up。**包络是显式的：系统必须报告自己在多大的漂移半径内仍然成立。**

**定义 314（GCB：分布无关泛化证书）** 对有界损失 ℓ∈[0,1]，以 1−α 概率对**所有** Q∈ℬ_{ρ_up} 成立
E_Q[ℓ] ≤ Ê_P[ℓ] + √(ρ_up/2) + √(log(2/α)/(2n))。
（change-of-measure + Hoeffding。）用 GCB 替换 R69 的点 ECE：证书认证 ⇔ 该上界 ≤ τ_cert；若上界 ≥ 1 则视为空证书，永不授予 bonus。

**定义 315（IMA：不变模态抽象）** 给定环境集 ℰ_train，在冻结 trunk 的 z 上训练轻量适配器 φ 与 mode_head，目标为 group-DRO：min_φ max_{e∈ℰ_train} R_e(φ)。输出最差组召回界 1−β_wg。IMA 仅用于**收紧 GCB 的 Ê 与最差组项**；关闭 IMA 时 GEM 严格退化为 FLUID 的运行时行为（保证嵌套干净）。

**定义 316（AVG：认证 VoI 门）** 对信息动作 g 计算单侧下置信界
LCB_α[VoI(g)] = V̂oI(g) − β_conc(n,α) − β_shift(ρ_up)，
其中 β_conc 为有限样本集中项，β_shift 为包络漂移项。交互当且仅当 LCB_α[VoI(g)] > c(g) 且 Tier 允许。**用下界而非点估计做决策**，因为点估计在漂移下可以任意乐观。

**定义 317（三级退避与泛化附加费）** 令 0<ρ_0<ρ_1。
- Tier 0（ρ_up≤ρ_0、所有 e-process 静默、GCB 认证）：λ = λ_floor(U_ale)，获得 resolution bonus（= FLUID）。
- Tier 1（ρ_0<ρ_up≤ρ_1 或 GCB 未认证）：λ = λ_floor(U_ale+U_epi)，禁止交互（= R68）。
- Tier 2（ρ_up>ρ_1 或任一 e-process 报警）：λ = λ_floor(U_ale+U_epi) + δ_gen(ρ_up)，δ_gen≥0 且随 ρ_up 单调，同时收缩时域 H；**严格比 R68 更保守**。
单调性：λ_Tier0 ≤ λ_Tier1 ≤ λ_Tier2。

**定义 318（DUS：交互作为漂移证据）** 每次交互产生三元组 (g, prior w, answer y)。定义矛盾残差
c_t = 1[y ∉ top-k(w)] + KL(w ‖ w_after) 的错配项。
c_t 作为 SAM 的第五条 e-process 输入。语义：**当回答持续与模态后验矛盾时，先怀疑自己的模态模型，而不是继续加码提问。**

**定义 319（证书 J_GEM）** J_GEM = (J_FLUID, ρ_up, e_values[1..5], tier, lcb_voi, worst_group_recall, gcb_bound, gen_ver)。Valid ⇔ Valid(J_FLUID) ∧ 所声明 Tier 的全部监控与界均满足（Tier 0 额外要求 GCB 认证且 e_values<1/α）。

**定义 320（VQAuditor-G：元审计）** 审计「证书是否诚实」：延迟标签到达后比较认证上界与实际风险，维护 over-claim 曲线。若滑动窗内实际风险 > 认证上界的频率显著超过 α（用 e-process 检验），判定 over-claim，**永久降级到 Tier 2 直到重新校准**。审计对象从「动作/交互」上升到「保证本身」。

**定义 321（泛化干扰集 ℰ_gen）** 协变量漂移（光照/材质/体型/传感器）、标签先验漂移（意图分布变化）、概念漂移（同一观测对应不同正确模态）、模态身份漂移（出现新的信息动作类型）、针对 mode_head 的对抗漂移。并入 AIC：ℰ_GEM = ℰ_FLUID × ℰ_gen。注意：R69 的 ℰ_FLUID 只覆盖同分布内的故障，ℰ_gen 覆盖「假设失效」。

**定义 322（漂移分型）** 依据「哪条假设先报警 + 哪类残差先移动」分型：协变量型（H0^(3) 先动）、校准型（H0^(2) 先动）、结构型（H0^(1) 先动）、欺骗型（H0^(4) 先动）。不同分型映射不同 Tier 响应与不同再校准策略，避免「一报警就全保守」的粗暴退化。

**定义 323（包络在线更新）** ρ_up 只能由延迟标签审计或被接受的交互结果更新；更新是低频、离线的，实时路径只读。包络扩大立即生效（收紧），包络缩小需连续 k 次审计通过（防抖动/防投毒）。

**定义 324（计算预算）** SAM 每条 e-process 每步 O(1)；RCE 离线 O(n²) 仅周期执行；GCB O(n) 离线；AVG O(K|𝒢|)。实时增量目标 < 0.25ms，总延迟仍守 R69 的 P99 < 2.6ms（Tier 2 可牺牲时域换安全）。

**定义 325（与 R69 的嵌套边界）** 当 ρ_up=0、所有 e-process 静默、样本量 n→∞（β_conc→0）且 IMA 关闭时，GEM 的每条指令与 FLUID 相同；当 VoI 不可认证或假设被拒时，GEM 的 Tier 1 与 R68 逐指令相同。故 GEM ⊇ FLUID ⊇ R68 是**三层严格包含**，而非并列替换。

## 2. 关键算法骨架

```python
# IP-264 SAM：任意时刻有效的假设监控（Ville 界）
class EProcessMonitor:
    def __init__(self, stat_fn, kappa, alpha, lam=0.5):
        self.stat_fn, self.kappa, self.alpha, self.lam = stat_fn, kappa, alpha, lam
        self.e, self.sup = 1.0, 1.0
    def update(self, batch):
        t = clip(self.stat_fn(batch), 0.0, 1.0)          # 有界检验统计量
        self.e *= (1.0 + self.lam * (t - self.kappa))     # 非负上鞅（H0 下）
        self.sup = max(self.sup, self.e)
        return self.sup >= 1.0 / self.alpha               # 任意时刻报警

# IP-273 RCE：从无标签目标样本估包络半径上界（分类器两样本检验）
def estimate_radius_upper(source, target, alpha):
    rho_hat = classifier_two_sample_divergence(source, target)   # KL/Proxy-A
    return rho_hat + radius_concentration(len(target), alpha)    # 并入估计误差

# IP-265 GCB：分布无关上界，替换点 ECE
def gcb_bound(risk_hat, n, rho_up, alpha):
    return risk_hat + sqrt(rho_up / 2.0) + sqrt(log(2.0 / alpha) / (2.0 * n))

# IP-267 AVG：认证 VoI 门（用下界，不用点估计）
def choose_if_certified(modes, o_t, budget, rho_up, alpha):
    if not gcb_bound(...) <= TAU_CERT:      # 空证书不授权
        return None
    best = None
    for g in info_action_candidates(modes):
        if not budget.allow(g) or not c_ras_wm.certify_info(g, o_t):
            continue
        lcb = voi_hat(g, modes, o_t) - conc_term(len(batch), alpha) - shift_term(rho_up)
        if lcb > cost(g) and (best is None or lcb - cost(g) > best.score):
            best = (g, lcb - cost(g))
    return best[0] if best else None

# IP-274 主闭环：FLUID 外层加「监控 → 分型 → 分级 → 认证」
def GEM_RAS_round(M, obs):
    # 1) FLUID 路径原样执行（零重复）
    z, o = M.mtm.forward(...)
    U_ale, U_epi, modes = M.aud.decompose(M.fmp.sample(o, M.fmp.adaptive_K(z)), z)
    # 2) 读路径监控：假设是否仍成立 + 包络有多大
    alarms = {k: mon.update(batch) for k, mon in M.sam.items()}
    rho_up  = M.rce.estimate_upper(obs, alpha=M.alpha)
    tier    = (2 if (any(alarms.values()) or rho_up > RHO1)
               else 1 if (rho_up > RHO0 or not M.gcb.certified(rho_up)) else 0)
    # 3) 只有 Tier 0 才允许用认证 VoI 去交互
    g = M.avg.choose_if_certified(modes, o, M.budget, rho_up, M.alpha) if tier == 0 else None
    if g is not None:
        answer = M.cia.execute(g)
        U_epi  = M.cia.update_belief(modes, answer)
        M.sam['interaction'].update(contradiction_residual(modes, answer))  # IP-269 双重用途
    # 4) 三级退避 + 泛化附加费
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = lam_floor(U_floor)
    if tier == 2:
        lam = max(lam, lam_floor(U_ale + U_epi) + delta_gen(rho_up))
    H = M.vista.H if tier < 2 else int(M.vista.H * shrink(rho_up))
    A = M.ach.propose(x_prime, H=H)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    # 5) 元审计 + 证书
    M.vqa_g.submit_async(rho_up, alarms, tier, g, U_epi)
    return k, lam, select_mode(modes, U_epi, lam), (rho_up, tier)
```

## 3. 推导

**引理 19（任意时刻有效的假设检验）** 在 H0^(i) 下 E_t^(i) 为非负上鞅，由 Ville 不等式，对任意停止时刻 τ，P(sup_{t≤τ} E_t^(i) ≥ 1/α) ≤ α。要点：**监控可以每步都看而不会累积误报**，这是固定阈值 ECE 门（每查一次多一次机会）不具备的；若违例幅度为 δ 且持续，log E_t 以 O(t·δ²) 增长，检出延迟 O(log(1/α)/δ²)。

**引理 20（认证 VoI 门不乐观过度交互）** 若真实 VoI(g) ≤ c(g)，则因 LCB_α 是单侧 (1−α) 下界，P(LCB_α[VoI] > c) ≤ α；故「无利可图却仍交互」的概率 ≤ α，且在漂移下由 β_shift(ρ_up) 自动吃掉乐观偏差。对照 R69：点估计 VoI 在漂移下可任意乐观，无此保证。系：**交互预算不会被一个自信的错误模型挥霍**。

**引理 21（最差组模态校准）** 对 ℰ_train 做 group-DRO，得 max_{e} ECE_e ≤ τ_wg；对落在 ℰ_train 凸包内的新环境，ECE ≤ max_e ECE_e + O(max_{i,j} D_f(P_i‖P_j))。**诚实边界**：IMA 只把泛化性扩到训练环境的凸包，凸包之外必须靠 RCE 报出的 ρ_up 兜底——不假装能泛化到任意分布。

**定理 18（三级嵌套严格包含）** 在 A99–A104 下：Tier 0 的 GEM 与 FLUID 逐指令相同；Tier 1 与 R68 逐指令相同；Tier 2 的 λ 比 R68 多一个非负附加费 δ_gen，风险不高于 R68。故 **GEM ⊇ FLUID ⊇ R68**，且每一层都在明确边界上退化为下一层；安全侧不做任何让步。

**定理 19（包络内的风险界）** 以 1−α 概率，对所有 Q∈ℬ_{ρ_up}，所声明 Tier 的实际选择性风险 ≤ GCB 上界。系：resolution bonus 只在**上界本身**能认证时才发放；若上界空（≥1），Tier 0 永不发放——**不会用一张空证书换取效率**。

**定理 20（证书诚实性与自纠正）** 若 over-claim（实际风险 > 认证上界）的长期频率 > α，VQAuditor-G 的 e-process 以概率 1 检出并降级至 Tier 2；在审计标签最终可得的条件下，系统不能长期维持一个错误的泛化声明。要点：**把「我说我能泛化」变成一个会被数据打脸的承诺。**

## 4. 复杂度分析

# 第 70 轮产物 · 创新点清单 v1：GEM-RAS（Generalization-Envelope-Monitored Risk-Adaptive System：把「不确定性二分」升级为「保证的泛化」——可在线证伪的假设监控 × 分布无关泛化证书 × 三级嵌套退避）

class EProcessMonitor:                                  # IP-264
    def update(self, batch):
        t = clip(self.stat_fn(batch), 0.0, 1.0)
        self.e *= (1.0 + self.lam * (t - self.kappa))   # H0 下非负上鞅
        self.sup = max(self.sup, self.e)
        return self.sup >= 1.0 / self.alpha

def gcb_bound(risk_hat, n, rho_up, alpha):              # IP-265
    return risk_hat + sqrt(rho_up/2) + sqrt(log(2/alpha)/(2*n))

## 4. 推导

**引理 19（任意时刻有效的假设检验）** H0 下 e-process 为非负上鞅，Ville ⇒ 对任意停止时刻 τ，P(sup_{t≤τ}E_t ≥ 1/α) ≤ α。监控可每步检查而不累积误报；持续违例 δ 时检出延迟 O(log(1/α)/δ²)。这是固定阈值 ECE 门不具备的。

**引理 20（认证 VoI 不乐观过度交互）** 若真实 VoI≤c，则 LCB 为单侧 (1−α) 下界 ⇒ P(LCB>c)≤α；漂移乐观偏差由 β_shift(ρ_up) 自动扣除。对照 R69：点估计在漂移下可任意乐观。

**引理 21（最差组模态校准）** group-DRO 得 max_e ECE_e ≤ τ_wg；对 ℰ_train 凸包内新环境，ECE ≤ max_e ECE_e + O(最大环境间散度)。诚实边界：凸包外只能靠 RCE 的 ρ_up 兜底。

**定理 18（三级嵌套严格包含）** A99–A104 下，Tier 0≡FLUID、Tier 1≡R68、Tier 2 风险 ≤ R68（附加费非负）。故 GEM ⊇ FLUID ⊇ R68，每层在明确边界退化为下一层，安全侧不让步。

**定理 19（包络内风险界）** 以 1−α 概率对所有 Q∈ℬ_{ρ_up}，所声明 Tier 的实际选择性风险 ≤ GCB 上界。系：bonus 只在界能认证时发放；空证书（≥1）永不授权。

**定理 20（证书诚实性与自纠正）** 若 over-claim 频率 > α，VQAuditor-G 的 e-process 以概率 1 检出并降级 Tier 2；在审计标签最终可得的条件下，系统不能长期维持错误的泛化声明。

**次级风险与缓解**：环境标签缺失使 IMA 不可用（单环境自动关闭，退回 FLUID 运行时，定义 315/325）；e-process 对极缓漂移功效低（DUS 第五通道 + 多统计量并合，E311/E312）；交互污染监控（矛盾残差与协变量残差分开建模，定义 322）；Tier 抖动破坏连续控制（包络迟滞：降级即时、升级需 k 次通过，定义 323）；审计标签延迟长（弱标签/抽检代理，未审计期显式标为「证书暂定」，定义 319–320）。
