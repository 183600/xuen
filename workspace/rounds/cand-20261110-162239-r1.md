# 第 44 轮（新一轮灵感循环首轮） · Wire-Cert × Xfer-Cert：把「通信延迟」与「跨任务泛化」纳入可验证证书闭环（四层架构 v9 + 传输-迁移平面 TTP）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 自陈最大风险是「共形边际覆盖被欺骗 + 多用户契约求交为空」，但它的租约与证书模型仍压着两个从未写进不变式的单点假设：**(H1) 证据与使用者在同一时空**——租约 τ 被默认为「本机刚测」，网络只是「延迟越大越保守」的一个减项，源时间、乱序、分区、时钟偏斜、溯源都不在语义里；**(H2) 每个任务/本体/环境都从零独立认证**——CKB 只是检索索引，跨任务知识不能降低认证成本，也没有任何规则规定「什么绝对不能借」。本轮灵感词精确命中这两个假设：**通信延迟**迫使我们把「源时间、路径延迟、乱序、分区、时钟误差、溯源」提升为证书的语义坐标；**跨任务泛化**迫使我们回答「跨任务到底能迁移什么、绝不能迁移什么」。二者耦合出一个真正的新问题：**当证据既跨任务又跨链路时，它的有效性还成立吗？** 本轮主张：**安全要延迟不变，有效性要域内重签；可以搬骨架与先验，绝不搬有效性。**

## 0. 直觉与动机

**灵感 1（通信延迟 → 延迟是证书的坐标，不是裕度的减项）**：直觉上，v20 的 `m − λ(t−τ)` 只回答「离测量时刻过了多久」，默认 τ 是本机刚测。真实部署里，一条远端证书的寿命由观测上传、远端计算、指令下发三段组成，还可能乱序、重复、丢失，甚至在网络分区时根本到不了；更糟的是时钟不同步——用「到达时间减源时间」会把新鲜度高估或低估。因此延迟不是一个可以塞进 λ 的标量噪声，而是证书的一个**坐标轴**：同一份结论在不同到达时刻、不同来源、不同路径下含义完全不同。正确处理有两步：**(a) 用源时间戳 + 有界时钟误差判定新鲜度，路径延迟按最坏值保守合成，未知即无穷（直接退纯本地）；(b) 尽量把安全做成延迟不变**——证书携带一个与网络无关的「安全核心」（本地控制不变集 Ω、可恢复域 R、fallback κ_f、恢复策略 κ_rec），延迟只影响「计划还能不能用」（性能/可用性），不影响「此刻安不安全」（soundness）。一句话：**延迟吃掉裕度，核心把裕度买回来。**

**灵感 2（跨任务泛化 → 迁移骨架，不迁移有效性）**：传统迁移学习搬的是权重/表示，默认源域知识在目标域仍有统计效力。证书不同：证书是**带 soundness 承诺的断言**，源域的承诺对目标域没有任何逻辑约束。若直接把源证书搬到新任务，域差会静默吃掉 margin，制造「看起来有证、实际失效」这种最坏的故障形态。于是把迁移拆成三层：**骨架可迁移**（守卫结构、不变式模板、搜索树摘要、反例集）；**先验可迁移**（margin 热启动、采样分布）；**有效性不可迁移**（margin 与有效域必须在目标域重签）。迁移的收益不是「免于重签」，而是「重签所需样本复杂度下降」。这把迁移学习从「赌域相关」降级为「只借结构、不借承诺」。

**灵感 3（耦合 → 传输-迁移三分类与联合预算）**：两者相乘时，最危险的不是「借来的证书错了」，而是「借来的先验让验证者只盯着错误区域，留下先验自认为安全的验证盲区」。必须显式规定三分类：**本地 + 同任务** → 完整有效性；**远端 + 同任务** → 带源时间衰减的有效性；**远端 + 跨任务** → 只能当骨架/先验，有效性必须本地重签。任何「远端 + 跨任务」的证书若被当成有效性直接使用，即为 unsound，且事后无法补救。进一步地，域差与延迟可以写进**同一个预算不等式**：越远离源任务，能容忍的链路延迟越短；链路越慢，越应该在目标域重新取证。

**耦合升级**：WCE（传输证书引擎）把延迟契约、源时间、序号/纪元、溯源、分区写成可审计的传输语义，并提供「延迟不变核心 + 延迟敏感外壳」两级证书；XCE（迁移证书引擎）提供有效域代数、骨架抽取、目标域重签与负迁移闸门；TTV（传输-迁移验证器）在仿真里把延迟 × 域漂移 × Byzantine 溯源 × 负迁移对抗联合注入，把反例回灌 CKB 与 SCV。四层架构由 v8 的「人格契约 + 并发证书」升级为 v9：**新增贯穿式『证书传输-迁移平面 TTP』**，让 v20 的并发证书学会「跨链路怎么送、跨任务怎么借」。

## 1. 形式化定义（增量：定义 44–50）

**定义 44（证书有效域与强度偏序）**：证书 `c = (φ, D(c), m_c, θ_c, S(c), prov(c))`，其中 φ 为断言语义（守卫谓词/规划约束），`D(c) ⊆ Θ` 为**有效域**（任务、环境、本体、硬件参数的集合），`m_c: D(c) → ℝ≥0` 为 margin 函数，`θ_c` 为安全阈值，`S(c)` 为骨架（定义 45），`prov(c)` 为溯源。c 在 `θ ∈ D(c)` 上 sound 当且仅当 `m_c(θ) ≥ θ_c`。**强度偏序**：`c₁ ⪰ c₂` 当且仅当 `D(c₁) ⊇ D(c₂)` 且 `∀θ∈D(c₂), m_{c₁}(θ) ≥ m_{c₂}(θ)`。**命题**：弱证书不能推出强证书；扩大有效域或降低 margin 都只会削弱证书。**推论**：任何「跨域直接沿用」都等价于把 `c_s` 在 `D_t \ D(c_s)` 上非法外推。

**定义 45（证书骨架、重签算子与样本复杂度收益）**：骨架 `S(c) = (φ, 不变式模板, 守卫结构, 搜索树摘要, 反例集)`，只保留与域无关的结构。迁移算子 `T_{s→t}: c_s ↦ (S(c_s), D_t)`，随后**必须**执行目标域重签 `c_t = ReSign(S(c_s), D_t, Data_t)`。**重签定理**：若 `D_t` 被目标域数据覆盖，且重签在目标数据上满足校准/覆盖/不变式条件，则 `c_t` 的 soundness 与 `c_s` 的 margin 无关，**源域错误不传递**。**命题（样本复杂度收益）**：以骨架为先验达到 margin ε 所需目标样本数满足 `N_t ≤ N_0 / (1 + ρ(S))`，ρ(S) 为骨架带来的信息增益；`ρ(S) ≤ 0` 时迁移无收益，必须退回独立认证。

**定义 46（负迁移风险证书与行动前闸门）**：迁移假设 `H_{s→t}` 断言目标分布 `P_t` 与源分布 `P_s` 的差异被 `δ_dom` 界定。风险证书 `r(H)` 给出上界 `P(m_t < θ_safe | H) ≤ ε` 的**置信上界**（重要性加权 + 两样本检验 + 共形校准，全部取上界而非点估计）。**负迁移闸门**：若 `r` 的置信上界 `> ε_neg`，则拒绝把 `c_s` 当有效性使用。**关键性质**：负迁移一旦以「未重签的源证书」形式进入行动即属 unsound，任何事后证书都无法补救——因此闸门必须在行动之前。

**定义 47（端到端延迟契约与源时间可用判据）**：有向链路 `e=(i→j)` 的延迟契约 `δ_e = (δ_max, δ_p99, J, γ, s)`：硬上界、高分位、抖动、违约概率、时钟同步误差。路径 P 的契约保守合成：`δ_max(P)=Σ_e δ_max(e)`，`J(P)=Σ_e J(e)`，`γ(P)=1−Π_e(1−γ(e))`，`s(P)=Σ_e s(e)`。证书样本携带 `(τ_src, s_seq, e_epoch, prov)`。**有效年龄** `A(t) = (t − τ_src) + s(P)`（最坏情形，时钟偏斜按上界累加）。**源时间可用判据**：在时刻 t 可用于守卫，当且仅当
(1) 序号 `s_seq` 无缺口、无回退；
(2) `A(t) ≤ δ_max(P) + L_lease`；
(3) `m_c − λ·A(t) ≥ θ_c`；
(4) 溯源链验证通过且 `e_epoch` 单调不回退。
**未知即无穷**：给不出有限 `δ_max(P)` 或 `s(P)` 时记为 `∞`，禁止任何跨网证书授权，退回纯本地核心。**注**：`δ_p99` 只用于性能与前瞻选型，soundness 只用 `δ_max`。

**定义 48（延迟不变核心与延迟敏感外壳）**：证书分解为 `c = (c_core, c_shell)`。`c_core = (Ω, κ_f, R, κ_rec)` 为**延迟不变安全核心**：Ω 为本地控制不变安全集，R 为可恢复域，`κ_f`/`κ_rec` 为不依赖网络的 fallback/恢复策略，且 `Ω ∪ R ⊆ X_safe`。`c_shell = (π, z, N, deadline)` 为延迟敏感的计划/性能外壳。**延迟不变安全定理**：若 `c_core` 声（Ω 对 κ_f 不变、R 对 κ_rec 有限步可恢复、Ω∪R⊆X_safe），则对任意到达延迟 δ 与实际状态：只要 `x ∈ Ω` 执行 κ_f 保持 X_safe，`x ∈ R` 执行 κ_rec 保持 X_safe 并有限步入 Ω；计划外壳仅在 `x` 落入其漏斗时使用。**推论（安全/性能解耦）**：δ 只改变外壳的可用性，不改变核心的 soundness；**安全性对 δ 不变，性能/可用性随 δ 单调不增**。

**定义 49（传输-迁移三分类与联合预算）**：对目标任务 t、源任务 s、路径 P：
- **L1 本地-同任务**：`δ_max(P)=0` 且 `D_t ⊆ D(c_s)` → `c_s` 可作为完整有效性（仍受本地新鲜度约束）。
- **L2 远端-同任务**：`D_t ⊆ D(c_s)` 且 `δ_max(P) < ∞` → 可作为有效性，但必须按定义 47 扣减源时间与路径延迟。
- **L3 远端-跨任务**：`D_t ⊄ D(c_s)` 或存在不可忽略域差 → **只能作为骨架/先验**，有效性必须 `c_t = ReSign(...)`。
**联合预算（transported-transfer inequality）**：若要把远端源证书当作目标有效性证据，必须同时满足
`D_t ⊆ D(c_s)` ∧ `prov OK` ∧ `m_s − λ_t·(δ_max(P)+s(P)) − L_dom·d̂(D_s,D_t) ≥ θ_t + ε_neg`，
其中 `d̂(D_s,D_t)` 为域差的**置信上界**，`L_dom` 为 margin 对任务/分布漂移的 Lipschitz 常数。**命题**：若 `d̂`、`λ_t`、`L_dom` 均为真上界且前提成立，则使用该证据 sound；**反之，若把 L3 误判为 L2（跳过重签），则 unsound 且不可事后补救**。**注**：当只能得到分布层面的包含而非集合包含时，用 `d̂>0` 承保残余域差；精确集合包含时取 `d̂=0`。

**定义 50（传输-迁移溯源 DAG、信任半环与级联撤销）**：溯源图 `G=(V,E)`，节点为证书/骨架/反例/传输事件，边类型 `dep ∈ {validity, skeleton, transport}` 并带衰减。信任在半环 `(⊕=max, ⊗=min)` 上传播：`trust(v)=min(直接证据(v), max_{u→v} trust(u)⊗decay(e))`。**撤销规则**：撤销 `c_s` 时，`validity`/`transport` 依赖的后代做可达闭包撤销；`skeleton` 依赖的后代只标记 `reverify-suggested`，不得误撤。**命题**：若依赖类型声明正确，则级联撤销在 `O(|V|+|E|)` 内同时满足**完备性**（validity 后代零遗漏）与**最小性**（skeleton-only 零误撤）。**bundle 一致性规则（重叠取最小）**：同一批次到达的证书集合 B 在 θ 处合并 margin 为 `m_B(θ)=min_{c∈B: θ∈D(c)} m_c(θ)`；若存在重叠域给出矛盾安全判定，必须取最小并标记不一致，绝不按最大值放行。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 WIRE-CERT-ENGINE（传输证书引擎 WCE）
1. **延迟契约编译器**：把网络拓扑、QoS、时钟同步能力编译成逐边 `δ_e` 与路径保守合成；`δ_max` 取硬上界，未知即 `∞`，直接进纯本地模式。
2. **源时间租约验证器**：以 `τ_src`、`s_seq`、`e_epoch`、`prov` 判定可用性；强制序号连续性、防回退、防重放、防撕裂，拒绝用到达时间冒充源时间。
3. **两级证书**：`c_core`（Ω、R、κ_f、κ_rec，不经网络也成立）与 `c_shell`（计划 π、名义轨迹 z、horizon N、deadline）；核心永远本地优先。
4. **分区与降级**：`δ=∞` 或溯源失败时，只保留核心 fallback + 本地 heartbeat，禁止远端语义授权；恢复后需重新验证再升级。
5. **端到端预算令牌**：把 `δ_e2e` 拆成传感、推理、DDS/桥、网络、执行五段，逐段给上界；超预算只降速/保持，不继续消费陈旧语义证书。

### 2.2 IP-61 TRANSFER-CERT-ENGINE（迁移证书引擎 XCE）
1. **有效域代数**：域表示（参数盒 + 分布约束）、包含/交判定、域差 `d̂` 估计（重要性加权 + 两样本检验 + MMD 上界），全部取置信上界。
2. **骨架抽取与检索**：从 CKB 取最近骨架并估计信息增益 ρ；`ρ ≤ 0` 直接拒绝迁移，杜绝「为迁移而迁移」。
3. **目标域主动重签**：以骨架先验初始化采样，按 margin 不确定性选点，迭代至覆盖/校准/不变式达标；输出 `c_t`，重算 `D_t` 与 margin；**有效性从头重签**。
4. **负迁移闸门**：风险证书置信上界 `≤ ε_neg` 才允许把骨架当先验；否则独立认证。域差不可证时默认关闭迁移。
5. **有效性数据表（validity datasheet）**：随证书传输，记录已验证任务集、已知失效域、样本量、重签日期与依赖版本，禁止「只传结论不传适用条件」。

### 2.3 IP-62 TRANSFER-TRANSPORT-VALIDATOR（传输-迁移验证器 TTV）
1. **延迟 × 域漂移联合注入**：延迟分布、乱序、重复、分区、时钟偏斜 × 跨地形/跨本体/跨负载/跨任务，专测「单独都过、联合失效」的组合。
2. **溯源 Byzantine 注入**：伪造延迟上界、投毒骨架、重放旧证书、篡改 epoch/序号，测污染传播深度、覆盖面与恢复率。
3. **负迁移对抗**：非平稳漂移、标签投毒、域分类器规避，检验闸门在对抗下的假阴性。
4. **bundle 一致性检查**：重叠域矛盾检出、min-margin 合并、误报率与漏报率。
5. **UniBot 32 任务长时程**：远程模型接入 + 多任务切换 + 链路降级，实测跨任务迁移收益、安全事件与恢复时延。

## 3. 四层架构 v9

```
L1: TRI-FUSE(INT8) + IP-49 LIO → C_ms + B_t + L_m(经验分位)
    本地核心 c_core(Ω, R, κ_f, κ_rec) 常驻，独占最高关键级，不经网络
L2: CTC + VLM + IP-35 仲裁 → R_φ(w) 分支池(b 候选)
    分支证书带有效域 D(c) 与骨架 S(c)，可跨任务检索但不得跨域授权
```

## 2. 关键算法（伪代码）

### IP-60 WCE：延迟契约、源时间判据与两级证书
```
def compose_delay(path_edges):
    # 保守合成；未知即无穷 => 禁止跨网授权
    if any(e.delta_max is None for e in path_edges):
        return DelayContract.infty()
    return DelayContract(
        delta_max = sum(e.delta_max for e in path_edges),
        jitter    = sum(e.jitter    for e in path_edges),
        gamma     = 1 - prod(1 - e.gamma for e in path_edges),
        skew      = sum(e.skew      for e in path_edges))

def cert_usable(c, t, path, last_seq, last_epoch):
    # 源时间 + 序号 + 纪元 + 溯源；任一失败即不可用
    if c.seq <= last_seq or c.epoch < last_epoch: return False   # 回退/重放
    if not verify_provenance(c.prov, trust_threshold=beta): return False
    age = (t - c.tau_src) + path.skew
    if age > path.delta_max + L_lease: return False
    if c.m - c.lam * age < c.theta: return False
    return True

def guard_with_two_levels(x, c, t, path):
    # 安全只依赖 core；shell 只在漏斗内使用
    if c_core_available(c) and x in c.core.Omega:
        return c.core.kappa_f
    if c_core_available(c) and x in c.core.R:
        return c.core.kappa_rec
    if cert_usable(c, t, path, c.seq - 1, c.epoch):
        k = funnel_index(c.shell, x, t)
        if k is not None and (c.shell.N - k) >= c.shell.N_use:
            return c.shell.pi[k]
    return local_safe_hold_or_stop()     # 分区/过期/漏斗外：纯本地
```

### IP-61 XCE：域代数、重签与负迁移闸门
```
def transfer(source_cert, target_task, data_t, eps_neg):
    # 永远先问：是 L1/L2 还是 L3？跨任务一律 L3
    if not domain_subset(target_task.D, source_cert.D):
        skeleton = extract_skeleton(source_cert)
        d_hat = domain_gap_upper(source_cert.D, target_task.D, data_t)
        risk  = negative_transfer_risk(skeleton, d_hat, target_task)
        if risk.upper > eps_neg:
            return independent_certify(target_task, data_t)   # 拒绝借先验
        return resign(skeleton, target_task.D, data_t)        # L3: 借骨架重签
    # 同任务远端证据：L2，走联合预算
    if source_cert.m - lam_t * (path.delta_max + path.skew) \
       - L_dom * 0.0 >= target_task.theta + eps_neg:
        return use_as_validity(source_cert)                   # L2
    return resign(extract_skeleton(source_cert), target_task.D, data_t)

def resign(skeleton, D_t, data_t, max_samples=N_max):
    # 以骨架为先验的主动认证：只借结构，不借 margin
    prior = margin_warm_start(skeleton)
    c_t   = certify_from_prior(prior, D_t, data_t)
    while not (coverage_ok(c_t) and invariant_ok(c_t)) and used < max_samples:
        x = acquire(max_uncertainty(c_t), data_t)   # 主动选点
        c_t = update(c_t, x)
    return attach_datasheet(c_t, source=skeleton.source,
                            verified_tasks=..., excluded_domains=...)

def merge_bundle(bundle, theta):
    # 重叠域取最小；矛盾即标记，绝不按最大值放行
    overlapping = [c for c in bundle if theta in c.D]
    if not overlapping:
        return None, "no-cert"
    m = min(c.m for c in overlapping)
    inconsistent = any((c.m >= theta) != (overlapping[0].m >= theta)
                       for c in overlapping)
    return m, ("inconsistent" if inconsistent else "ok")
```

```
def car_guard_v9(e, x, cert, persona, t, path):
```

## 5. UniBot 落地路径

1. **形态匹配**：UniBot 是「选手模型远程接入 + 标准化 API + 32 项任务」的评测形态，天然同时具备**通信延迟**（远程推理主机 → DDS/桥 → 机器人）与**跨任务泛化**（多任务切换、少样本新任务）两个痛点，正好对应本轮两个灵感词。
2. **本地核心优先**：把 Ω/R/κ_f/κ_rec 做成机器人侧常驻的 `ros2_control` 安全内核（最高关键级、零堆分配、不经网络）；远端 VLM/规划只产生 `c_shell`，到达时先过源时间/序号/纪元/溯源四关。
3. **延迟预算分段**：把 `δ_e2e` 拆成传感、推理、DDS/桥、网络、执行五段，每段给硬上界；`δ_max` 未知时直接进核心 fallback，绝不用「大概率没超时」赌安全。
4. **跨任务只借骨架**：32 任务之间通过 CKB 共享不变式模板/守卫结构/反例集，但每个新任务必须在目标域重签 margin 与有效域；有效性数据表随证书一起入库，明确写出「已知失效域」。
5. **最小可行版本（先做窄的）**：只实现「源时间租约 + 序号/纪元 + 两级证书 + 目标域重签 + bundle 取 min」五项，不引入骨架主动采样与自动撤销；先在 Isaac Sim + rosbag2/MCAP 重放上过 E95/E96/E97/E100，再上实机。

| 骨架借来的先验把验证者引向错误区域（负迁移盲区） | 高 | 负迁移闸门在行动前；独立抽检目标域全域；ρ≤0 拒绝迁移 |
| 路径延迟上界 `δ_max` 低估或时钟偏斜累积，导致陈旧证书被当新鲜 | 高 | E95 红线；源时间 + skew 上界 + 序号/纪元；未知即 ∞ 退纯本地 |
| 远端跨任务证书被误当同任务有效性（L3 误判为 L2） | 高 | 强制域包含判定 + 有效性数据表；E99 联合实验；跨任务只走 ReSign |
| Byzantine 节点投毒骨架并沿溯源边扩散 | 中-高 | E100 注入测试；信任半环 + 级联撤销；骨架可污染但有效性强制重签 |
| bundle 中重叠域给出矛盾安全判定，被最大值放行 | 中 | 重叠取 min + 显式不一致标记；E101 检测率 ≥99% |
| 两级证书的核心过度保守，任务不可达 | 中 | 核心只保证安全、尽力保留可恢复域 R；E96 监控可用性；扩 R 需重证 |
| 端到端预算分段后某段无上界，整体退化为纯本地 | 中 | 预算令牌显式缺失即拒；关键段硬件时间戳；恢复后重新验证再升级 |
| 有效性数据表遗漏失效域，形成「有证但没说不能用」 | 中 | 数据表随证书签名入库；CKB 按域签名去重；审计强制要求 excluded_domains |

## 8. 本轮最大风险

**一句话**：域差 `d̂`、漂移率 `L_dom` 与路径延迟上界 `δ_max` 本身都来自有限、延迟、且可能被对抗操纵的数据——一旦把乐观估计当成真上界，联合预算就会给一个实际 unsound 的「跨任务远端证书」发证，而骨架回退又会把负迁移藏进验证盲区；因此 E98/E99 必须设为红线，默认底线是「目标域重签，或干脆不迁移，只跑本地核心」。
