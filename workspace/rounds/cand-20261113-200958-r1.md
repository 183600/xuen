# 第 69 轮（承接第 68 轮「CALM-RAS 自标定·自监督·单模型多任务」IP-243~252；灵感循环新循环第 2 轮；本轮灵感：「意图理解」×「示教学习」）

> 第 68 轮用计量层回答了「**我的测量还准吗**」，把标定升级为一等公民潜变量，并留下了一句谶语：**标定能力越强，缓变故障越隐形**。这句风险的真正病根在于——标定层没有任何外部的「应该是什么」的参照，它只能让测量更精确，却无法判断「精确的测量」服务的目标对不对。回看 R65–R68，整条闭环一直在精确测量**世界怎么样**（感知→标定→预测→审计），却从未建模**人想要什么**。R65 的传感器混淆、R66 的情绪欺骗、R67 的前瞻黑箱、R68 的漂移吸收，都是「无意图参照」的四个投影：没有意图，一切「不一致」就只能在故障/不确定性假设里赌后验。
>
> 本轮两块灵感恰好补上这个缺失：**意图理解**给出「人想要什么」的潜变量与后验；**示教学习**给出在线测量这一潜变量的**信道**——人的示范。核心命题：
>
> **把「示教」从一次性离线数据集升级为意图的在线测量信道，并为这条信道建立与传感器同构的计量学：示教有可信度、意图有后验、歧义要主动查询、安全不可被示教放宽——TILT-RAS（Teaching-Intent Latent Tracking RAS）。**
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「**我懂你要什么吗，还是我在替你做主**」。

## 0. 直觉与动机

**灵感 1（意图理解 → 「不一致」的第一解释不该是故障，而该是「我没懂你」）**
直觉：现有闭环看到「人的行为与机器人预期不符」就进入 EFS 的 H_emotion/H_sensor 归因，本质是把人的偏离当异常。但人偏离机器人预期的最常见原因既不是故障也不是欺骗，而是**机器人的意图模型错了**。意图是目标/偏好/时域上的潜变量 θ，只能通过行为、语言、示教间接观测；把 θ 边缘化掉再谈故障，等于存在未观测混杂因子时做因果归因。所以第一原则是「**先懂意图，再判异常**」，与 R68「先标定，后归因」构成同一方法论的两级。

**灵感 2（示教学习 → 示范不是标签，而是带测量误差的观测）**
直觉：LfD 习惯把示范当 ground truth 去做行为克隆，这是把**仪器读数当成真值**。但示范由人产生：人会疲劳、会犹豫、会教错、会故意教错，也只在某些状态下示范。示范是意图的**有噪、有偏、可被污染**的测量。R68 教会我们：任何测量都必须有可信度和标定。于是示范也需要「计量」——教师能力、自洽性、时效性、可观测性、非对抗性，构成教师信道可信度 κ_D。**没有 κ_D 的示教学习，是把 R66 的情绪欺骗升级成了示范投毒。**

**灵感 3（示教学习 → 教学是交互，不是一次性数据收集）**
直觉：经典 DAgger 已指出，行为克隆的分布偏移只能靠「查询」修补。放进风险闭环，查询本身是有代价、有风险的动作（暂停、打断、暴露）。所以查询必须是**风险加权的最优实验设计**：只在意图后验多峰且高风险处，花一次示范把 U_int 打下来。示教于是从「离线数据集」变成「在线、预算受限、由信息价值驱动的主动测量」——人也成为闭环里一个可被调度的传感器。

**灵感 4（三灵感合流 → TILT-RAS 六组件）**
1. **MIM Multi-hypothesis Intent Model**：在 R68 的 MTM 上新增第六头 int_head，输出意图假设集上的后验 b_t(θ)；多假设而非单标签，杜绝过早收敛；
2. **DCL Demonstration Credibility Layer**：示教信道的「标定层」，五分量可信度 κ_D 的滤波与红线；
3. **IFA Intent-First Attribution**：把 R68 的「先标定后归因」升级为「先标定 → 再懂意图 → 后判异常」，把异常三分解为 H_intΔ（人改主意）/ H_teach（教师不可信或意图误读）/ H_fault（R68 的真实故障）；
4. **ICR Intent-Conditioned Risk**：风险相对于意图定义，对意图后验做 CVaR 最坏集成，U_int 与 U_cal 一起并入多源 λ 下限；
5. **ACT Active Correction Teaching**：EVOI 门控的主动纠错示教，预算受限、可安全暂停；
6. **CTC Certified Teaching Commit**：把 R68 的 CAC 五关扩为六关，新增「意图忠实 canary」与「安全不可示教」，示教适配器只能改变「理解」不能改变「红线」。

**灵感 5（对 R68 遗留风险的对症下药与反噬）**
R68 的缓变故障被标定带宽吸收。示教原则上提供一个**宽带外部参照**：故障发生时人会持续纠正，纠正流是宽带信号，恰好落在标定带宽之外。但——纠正流同样可以被意图层吸收成「人改主意了」。于是 R68 的「吸收」在 R69 升维重演：**每一层新的潜变量解释器，都能把上一层失败的证据解释掉。** 这是本轮必须正面建模的「解释吸收回归」（定义 309、定理 18），也正是最大风险所在。

## 1. 形式化定义（增量：定义 293–309）

**定义 293（TILT-RAS 总览与四不变式）** TILT-RAS = (MIM, DCL, IFA, ICR, ACT, CTC, RAS-WM†)。四条不变式：
(i) **实时流零学习写操作**（继承 R68 强化版：更新只在影子流，经 CTC 认证原子换装）；
(ii) **意图不是标签而是分布**：控制对 b_t 做风险敏感集成，任何单点意图不得直接下发；
(iii) **示教不得绕过 DCL**：无 κ_D 的示范不入训练、不入归因；
(iv) **安全不可示教**：示教更新只能改变机器人对目标的「理解」，绝不降低 λ 下限、绝不扩张安全动作集——人能教你「要什么」，不能教你「可以不安全」。

**定义 294（意图潜变量与假设空间）** 意图 θ = (x*_θ, w_θ, h_θ) ∈ Θ：目标区域/物体 x*、偏好权重 w（等价于奖励参数）、时域 h。Θ 取离散候选格 ∪ 连续局部细化；b_t ∈ Δ(Θ) 为意图信念。意图演化为稀疏跳变：θ_{t+1}=θ_t 以概率 1−ε_int，以概率 ε_int 跳到邻近假设（人改主意是跳变，不是连续漂移）。

**定义 295（示教似然/意图观测信道）** 一条示范 D = {(s_j, a_j)}_{j=1..N}。在 MaxEnt 逆规划下
p(D | θ, τ) ∝ exp(β·Σ_j R_θ(s_j, a_j)) · p(a_j | s_j, τ)，
其中 τ 为教师执行潜变量（能力/延迟/疲劳）。θ 与 τ 解耦估计：θ 解释「为什么这样做」，τ 解释「做得有多好」。

**定义 296（DCL 示教可信度层）** 每条示范携带 κ_D = (κ_comp, κ_cons, κ_rec, κ_obs, κ_adv) ∈ [0,1]^5：能力（示范回报相对可达回报）、自洽（同一意图重复示范的 test-retest 一致性）、时效（exp(−Δt/τ_stale)）、可观测（教师视野/手部遮挡比例）、非对抗（canary 探针通过率）。κ_D = Π κ_i^{γ_i}，并按 R68 COF 同构做滤波 + 速率限制 + 红线（κ_D < κ_min 直接拒收，不得进入 IFA/CTC）。

**定义 297（意图信念滤波 IBF）** b_t 的更新 = predict（ε_int 跳变核）+ likelihood（在线行为 + 已认证示范，按 κ_D 加权）。意图不确定度
U_int = H(b_t) + λ_mm·(1 − max_θ b_t(θ))（熵 + 多峰惩罚），故多峰即便熵不高也被判为高不确定。

**定义 298（意图残差与相干性）** r_int = D_KL(π_robot(·|b_t) ‖ π_demo(·|D)) 加行为-意图边际似然残差；r_int 与 R68 的五元组 r 拼成六元组喂给 IFA。注意：r_int 大**既可能**是机器人没懂（模型错），**也可能**是人偏离（意图变/教错/故障）——这正是必须归因而非直接惩罚的原因。

**定义 299（IFA 意图优先归因，三分解）** 异常证据 e = (r, r_int, κ_D, ĉ) 下
P(H | e) ∝ p(r, r_int | H, ĉ, κ_D) · P(H)，H ∈ {H_intΔ, H_teach, H_fault}。
顺序语义：先用 DCL 算 κ_D（测量教师），再用 MIM 得 b_t（测量意图），只有「标定后残差 + 意图解释后残差」双残余才升 H_fault。禁止把 H_teach 当「人错了」的垃圾桶：κ_D 高时 H_teach 后验必须被压制。

**定义 300（ICR 意图条件风险与多源下限）** 风险相对意图定义：对每个 θ 计算 λ_risk(θ|H)，下发
λ = CVaR_α{λ_risk(θ) : θ ~ b_t}，λ_floor = max(0.6, 0.8·1[U_cal > τ_cal ∨ U_int > τ_int ∨ min_i κ_D,i < κ_min])。
语义：不只「测量不准要收紧」，**「不知道你想要什么」也要收紧**；意图歧义与传感器歧义共用同一根总闸，方向永远只朝向保守。

**定义 301（ACT 主动纠错示教）** 查询集 Q = {纠正示范, 偏好比较, 是/否确认}。信息价值
EVOI(q) = E_{o∼q}[H(b_t) − H(b_{t+1})]·ρ_risk(θ) − c_q，
ρ_risk 让高风险区域的意图歧义更「值钱」。仅当 EVOI(q) > τ_evoi 且安全可暂停（暂停动作本身在安全集内）才查询；预算 B_q/分钟 + 冷却时间，避免「教育式骚扰」。

**定义 302（示教安全不变式 SASI）** 设 Safe(·) 为安全动作集。任何由示教产生的更新（信念、适配器、阈值）满足
Act(π_θ′) ⊆ Act(π_θ) ∪ {a : a 满足未修改的硬约束}，且 λ_floor(θ′) ≥ λ_floor(θ)。
即：**示教可改变目标，不可改变红线**——示教更新对安全集「单调不扩张」。

**定义 303（CTC 认证式示教提交，六关）** 在 R68 CAC 五关基础上：
1. 金标回归（继承，衰减 ≤ 1%）；
2. AuditBuf 回放（继承）；
3. 分布界 KL(P_θ′‖P_θ) < 0.05（继承）；
4. 风险界 worst-case λ ≤ 1.05×（继承）；
5. **canary 不可修复性**（继承，防标定吸收）；
6. **意图忠实 + 安全不可示教**：已知意图 canary 示范须被复现（意图忠实 ≥ 0.95），对抗性「教我违章」示范须被拒（安全集零扩张，一票否决）。
任一不过 → 丢弃并记 ℰ_tilt。

**定义 304（对抗教师威胁模型）** 教师可能：投毒（示范隐含危险意图）、伪装（表面合规的假示范，类比 R66 假笑）、间歇可靠（多数对、关键处错）、共谋（针对 canary 过拟合）。DCL 的 κ_adv 由留一教师交叉验证 + canary 探针 + 反事实示范（「不要这样做」）联合估计。

**定义 305（J_TILT 证书）** J_TILT = (J_CALM, intent_belief_hash, U_int, κ_D_vec, evoi_log, teach_verdict, tilt_ver)。Valid ⇔ Valid(J_CALM) ∧ U_int < τ_int^hard ∧ teach_verdict = PASS ∧ SASI（定义 302）。

**定义 306（干扰集）** ℰ_TILT = ℰ_CALM × ℰ_int × ℰ_demo × ℰ_teach；ℰ_int = {意图误读, 意图过拟合, 过早收敛到单峰}；ℰ_demo = {示范投毒, 假示范, 示范分布偏移}；ℰ_teach = {教育式骚扰, 查询诱发的安全暴露, 查询预算耗尽}。

**定义 307（管线）** 离线：D_demo 上按 κ_D 加权预训练 int_head + 意图政策适配器 → CTC 首次认证。在线：MIM 信念滤波 → DCL 持续标定 κ_D → IFA 三分解 → ICR 下发 → ACT 触发查询 → 影子适配器 60s 一轮 → CTC 六关原子换装。

**定义 308（与 CALM 的同源性）** int_head 是 MTM 的第六头，与 emo/fault/wm/cal/qual 共享 z_t。因此意图噪声与测量噪声、WM 噪声同源，引理 15 的共模抵消同样适用于 r_int 与 r_wm 的一致性检验——**意图理解不需要新模型，只需要新头**。

**定义 309（解释吸收回归 / 层级可解释性预算）** 设第 ℓ 层潜变量 Z_ℓ（ℓ=1 传感器, 2 标定, 3 意图, …）各自可解释一部分异常质量 A_ℓ。定义吸收系数 η_ℓ = E[异常被 Z_ℓ 解释掉的比例]。层级系统满足 **η_1 + η_2 + η_3 + (未被解释部分) = 1**（异常质量守恒）。**没有外部锚（canary/探针/真值）时，提高 η_ℓ 必然降低其余各层可用的异常质量**——这就是「解释吸收回归」：新层让系统「更懂事」，同时让旧层的问题「更隐形」。

# IP-253/254 MIM：MTM 第六头 + 意图信念滤波
class MultiHypothesisIntentModel:
    def __init__(self, mtm, thetas, eps_int=0.02):
        self.mtm, self.Theta, self.eps = mtm, thetas, eps_int
        self.b = uniform(self.Theta)                  # b_t ∈ Δ(Θ)

    def predict(self):                                # 稀疏跳变核
        self.b = (1 - self.eps) * self.b + self.eps * neighbor_kernel(self.b)

    def update(self, z, demo=None, kappa=1.0):
        ll = array([self.likelihood(z, th) for th in self.Theta])   # 行为似然
        if demo is not None:                                        # 示范似然 × 可信度
            ll *= array([max(kappa, 1e-6) ** maxent_score(demo, th)
                         for th in self.Theta])
        self.b = normalize(self.b * ll)
        U_int = entropy(self.b) + LAM_MM * (1 - self.b.max())
        return self.b, U_int


# IP-255 DCL：示教可信度五分量 + 红线
def demo_credibility(demo, demo_hist, teacher_reach, canary_pass, occl, staleness):
    k_comp = clip(return_of(demo) / max(teacher_reach, 1e-6), 0, 1)
    k_cons = test_retest(demo, demo_hist)              # 同意图重复一致性
    k_rec  = exp(-staleness / TAU_STALE)
    k_obs  = 1 - occl
    k_adv  = canary_pass
    kappa  = prod([k_comp**G_COMP, k_cons**G_CONS, k_rec**G_REC,
                   k_obs**G_OBS, k_adv**G_ADV])
    return 0.0 if kappa < K_MIN else kappa             # 红线：拒收


# IP-256 IFA：先标定 → 懂意图 → 判异常（三分解）
def intent_first_attribution(r, r_int, b, U_int, kappa, c, U_cal):
    if U_cal > TAU_CAL:
        c, U_cal = cof_freeze_worst(c)                 # 继承 R68 超时最坏情况
    res_after_cal = residual_after_calibration(r, c)
    res_after_int = residual_after_intent(res_after_cal, b)   # 意图能解释吗
    p_intD  = intent_change_likelihood(res_after_int, r_int)
    p_teach = teach_unreliable_likelihood(kappa, U_int)
    p_fault = fault_likelihood(res_after_int, U_cal)          # 双残余才升
    return normalize({'intD': p_intD, 'teach': p_teach, 'fault': p_fault})


# IP-257 ICR：意图条件风险 + CVaR + 多源 λ 下限
def intent_conditioned_risk(b, H, U_cal, U_int, kappa):
    lam_theta = [risk_scale(intent_theta(th)) for th in b.support()]
    lam = cvar(lam_theta, b, alpha=0.9)
    lam_floor = max(0.6, 0.8 if (U_cal > TAU_CAL or
                   U_int > TAU_INT or kappa < K_MIN) else 0.6)
    return max(lam, lam_floor)


# IP-258 ACT：EVOI 门控主动纠错示教
def maybe_query(b, U_int, risk_map, budget):
    if budget <= 0:
        return None
    best, best_v = None, TAU_EVOI
    for q in QUERIES:
        evoi = expected_entropy_reduction(b, q) * risk_weight(risk_map) - cost(q)
        if evoi > best_v and can_pause_safely():
            best, best_v = q, evoi
    return best

class CertifiedTeachingCommit:

    def maybe_commit(self, shadow_adapter, dt):

# IP-262 主闭环
def TILT_RAS_round(M, obs):
    V, T, P, L, P_cloud, W, tactile, img, depth, flow = obs
    x_prime = M.lsf.fuse(M.usr.fuse(V, T, P, L))
    z, o = M.mtm.forward(obs_pack, M.a_prev, M.scene_ctx)  # 含 int_head 第六头

    # 1) 意图信念 + 不确定度
    b, U_int = M.mim.update(z, demo=M.pending_demo, kappa=M.dcl.kappa)

    # 2) R68 标定层保留
    r = residuals(x_prime, o, M.wm_residual_cache)
    c, U_cal, thr = M.cof.step(o['cal'], r, sigma_stat(M))

    # 3) 意图残差 + 意图优先归因
    r_int = intent_residual(b, M.demo_buffer, o['pi'])
    H = M.ifa(r, r_int, b, U_int, M.dcl.kappa, c, U_cal)

    # 4) 意图条件风险（CVaR + 多源下限）
    lam = M.icr(b, H, U_cal, U_int, M.dcl.kappa)

    # 5) WM 前瞻 + 认证前缀
    wm_preds = M.mtm.rollout(z, M.ach.propose_actions(x_prime, 5))
    A = M.ach.propose(x_prime, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, H, min(M.vista.m, M.m_emo),
                                    M.alpha_chunk, wm_preds)
    if U_int > TAU_INT:
        k = min(k, k_int_shrink(b))                    # 意图歧义收缩前缀

    # 6) 控制 + 主动示教
    tau = M.pi_sigma.prefix_dispatch(A[:k]) * lam
    q = M.act.maybe_query(b, U_int, risk_map(x_prime), M.query_budget)
    if q is not None:
        M.demo_request(q)                              # 异步请求示教

    # 7) 异步认证提交
    M.ctc.maybe_commit(M.shadow_adapter, M.time_since_last_commit)
    return k, lam, H, (b, U_int, M.dcl.kappa)

## 3. 推导

**引理 16（意图可辨识与样本界）** 在 MaxEnt 逆规划与假设空间分离度 δ_θ 下，κ 加权示教后意图后验误差满足
E[1 − b_t(θ*)] ≤ exp(−N_eff·δ_θ²/2) + |Θ|·exp(−c·N_eff)，其中 N_eff = Σ κ_D。
即**低可信度示范等效于更少的样本**——不是不学，而是按 κ 折算地学。系：κ_D 是示教的「有效样本倍率」。

**引理 17（意图歧义单调保守）** 若 U_int > τ_int，则 λ ≥ λ_floor ≥ 0.8 且 k ≤ k_int_shrink；且对任意 θ ∈ supp(b)，下发动作仍属 Safe(θ)。故意图不确定只会收紧，不会放宽（与 R68 定理 14-2 同构）。

**引理 18（示教影响界/投毒界）** 单条可信度 κ 的示范对 b 的对数后验改动 ≤ κ·Δ_max；对适配器参数的梯度贡献被 κ 缩放。故投毒示范最大影响 ∝ (1 − κ_adv)，κ_adv = 0 时被 DCL 红线直接拒收——**可信度是投毒的阻尼器**。

**引理 19（EVOI 查询效率）** 若风险加权歧义集中在少数区域，EVOI 门控查询达到目标 U_int 所需示范数 ≤ 随机 DAgger 的 O(1/|A_amb|) 倍（A_amb 为歧义区域占比）。系：查询预算随歧义稀疏度下降，而非随时长增长。

**定理 16（TILT 端到端风险一致性）** 在 A87–A95 下：
1. P(|τ_cmd − τ*| > ε) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_vqa + α_cal + **α_int + α_teach**；
2. U_int > τ_int ⇒ λ ≥ 0.8 ∧ k 收缩 ∧ 若仍在歧义则请求示教（有界延迟）；
3. ω_f ≥ 3ω_cal 的快变故障检出与 CALM 相同（引理 13 保留）；
4. 示教更新满足 SASI，安全动作集单调不扩张（定理 17）。

**定理 17（安全不可示教）** 由 SASI（定义 302）与 CTC 第 6 关，任何经认证的示教适配器满足 Act(π_θ′) ⊆ Act(π_θ)、λ_floor(θ′) ≥ λ_floor(θ)。故 TILT-RAS 的安全集 ⊆ CALM-RAS 的安全集——**增加意图层不引入新的不安全动作**，只可能更保守。

**定理 18（解释吸收不可能性/三难）** 设异常质量守恒（定义 309），无外部锚时，三类漏检率满足
miss_int + miss_teach + miss_fault ≥ 1 − η_anchor，
其中 η_anchor 为 canary/探针/真值提供的独立信息占比。系：**要同时降低三者，必须增加外部锚，而不能只增加解释层**；纯靠加潜变量只会把误差在层间搬运。这是对 R68「标定吸收」与 R69「意图吸收」的统一刻画。

## 6. 本轮最大风险

**一句话**：TILT-RAS 把「人为什么会偏离预期」的最终解释权交给了一个**不可证伪**的意图潜变量——当机器人越懂意图，它就越有理由把人的纠正解释为「你没懂/你改主意了」，而不是「我错了/世界坏了」；由于意图没有真值、只有后验，**每一层新增的解释器（标定 → 意图）都能把上一层失败的证据吸收掉（定义 309 / 定理 18），系统于是越解释越自信、越自信越敢替人做主**，最终以「为你好」的善意家长主义形式越过人类，而所有审计指标都显示一切正常——这是 R68「标定越强、慢故障越隐形」在意图层的升维复发：**示教能力越强，人的异议越隐形。**

**次级风险与缓解**：意图过拟合/过早收敛（多假设 + 熵/多峰惩罚 + 温度校准）；假示范与投毒（DCL 五分量 + canary + 留一教师）；家长主义越权（定理 17 安全不扩张 + E294 独立审计 + 人可否决）；查询骚扰（EVOI 门限 + 预算 + 冷却）；解释吸收（定理 18 → 强制外部锚：canary、反事实探针、周期性真值抽检）；跨教师负迁移（κ 加权 + CTC 认证）。

**定义 293（总览与四不变式）** 实时流零学习写操作（继承）；意图是分布不是标签；示教不得绕过 DCL；**安全不可示教**（示教可改目标、不可改红线）。

**定义 294（意图潜变量）** `θ = (x*, w, h) ∈ Θ`；`b_t ∈ Δ(Θ)`；`θ_{t+1}=θ_t` 以概率 `1−ε_int`，否则跳到邻近假设（人改主意 = 稀疏跳变）。

**定义 295（示教似然）** `p(D|θ,τ) ∝ exp(β·Σ R_θ(s_j,a_j))·p(a_j|s_j,τ)`；θ 解释「为什么」，τ 解释「做得多好」，解耦估计。

**定义 297（IBF）** predict（跳变核）+ likelihood（行为 + κ 加权示范）；`U_int = H(b_t) + λ_mm·(1−max b_t)`，多峰即高不确定。

**定义 298（意图残差）** `r_int = KL(π_robot(·|b_t) ‖ π_demo(·|D))`；与 R68 五元组拼成六元组。r_int 大既可能是没懂，也可能是人偏离——必须归因。

**定义 299（IFA 三分解）** `P(H|e) ∝ p(r,r_int|H,ĉ,κ_D)·P(H)`，`H ∈ {H_intΔ, H_teach, H_fault}`；先测量教师、再测量意图、双残余才升故障；κ_D 高时压制 H_teach。

**定义 300（ICR）** `λ = CVaR_α{λ_risk(θ)}`；`λ_floor = max(0.6, 0.8·1[U_cal>τ_cal ∨ U_int>τ_int ∨ κ_D<κ_min])`——测量不准与意图不清共用一根总闸。

**定义 301（ACT）** `EVOI(q)=E[H(b_t)−H(b_{t+1})]·ρ_risk−c_q`；仅 `EVOI>τ_evoi` 且可安全暂停时查询；预算 + 冷却。

**定义 302（SASI）** `Act(π_θ′) ⊆ Act(π_θ)` 且 `λ_floor(θ′) ≥ λ_floor(θ)`——示教对安全集单调不扩张。

**定义 303（CTC 六关）** 金标回归 / 审计回放 / 分布界 / 风险界 / canary 不可修复性 / **意图忠实 + 安全不可示教**；双缓冲 <1μs 原子换装。

**定义 304–306（威胁 / 证书 / 干扰集）** 教师可投毒、伪装、间歇可靠、共谋；`J_TILT` 需 SASI 与 U_int 硬界；`ℰ_TILT = ℰ_CALM × ℰ_int × ℰ_demo × ℰ_teach`。

**定义 307–308（管线 / 同源性）** 离线 κ 加权示教预训练 → 在线主动教学闭环；int_head 与五头共享 z_t，引理 15 共模抵消同样适用于 r_int 与 r_wm。

# IP-253/254 MIM + IBF：第六头 + 多假设信念滤波
class MultiHypothesisIntentModel:
    def __init__(self, mtm, thetas, eps_int=0.02):
        self.mtm, self.Theta, self.eps = mtm, thetas, eps_int
        self.b = uniform(self.Theta)

    def predict(self):                                 # 稀疏跳变核
        self.b = (1-self.eps)*self.b + self.eps*neighbor_kernel(self.b)

    def update(self, z, demo=None, kappa=1.0):
        ll = array([self.likelihood(z, th) for th in self.Theta])
        if demo is not None:
            ll *= array([max(kappa,1e-6)**maxent_score(demo, th)
                         for th in self.Theta])
        self.b = normalize(self.b * ll)
        return self.b, entropy(self.b) + LAM_MM*(1-self.b.max())

# IP-255 DCL：五分量可信度 + 红线拒收
def demo_credibility(demo, hist, reach, canary, occl, stale):
    k = [clip(return_of(demo)/max(reach,1e-6),0,1),
         test_retest(demo, hist), exp(-stale/TAU_STALE), 1-occl, canary]
    kappa = prod([k[i]**G[i] for i in range(5)])
    return 0.0 if kappa < K_MIN else kappa

# IP-256 IFA：先标定 → 懂意图 → 判异常
def intent_first_attribution(r, r_int, b, U_int, kappa, c, U_cal):
    if U_cal > TAU_CAL: c, U_cal = cof_freeze_worst(c)
    res = residual_after_intent(residual_after_calibration(r, c), b)
    return normalize({'intD': intent_change_likelihood(res, r_int),
                      'teach': teach_unreliable_likelihood(kappa, U_int),
                      'fault': fault_likelihood(res, U_cal)})

# IP-257 ICR：意图条件风险 + 多源下限
def intent_conditioned_risk(b, H, U_cal, U_int, kappa):

    floor = max(0.6, 0.8 if (U_cal>TAU_CAL or U_int>TAU_INT
                             or kappa<K_MIN) else 0.6)
    return max(lam, floor)

## 4. 推导

**引理 16（意图可辨识与样本界）** MaxEnt 逆规划下 `E[1−b_t(θ*)] ≤ exp(−N_eff·δ_θ²/2)+|Θ|exp(−c·N_eff)`，`N_eff=Σκ_D`——低可信度示范等效于更少样本，κ_D 是有效样本倍率。

**引理 17（意图歧义单调保守）** `U_int>τ_int ⇒ λ≥0.8 ∧ k≤k_int_shrink`，且任意 θ∈supp(b) 下动作仍属 Safe(θ)；意图不确定只收紧不放宽。

**引理 18（示教影响界/投毒界）** 单条 κ 示范对后验改动 ≤ κ·Δ_max；对适配器梯度贡献被 κ 缩放；投毒影响 ∝ (1−κ_adv)，κ_adv=0 被 DCL 红线拒收。

**引理 19（EVOI 查询效率）** 歧义集中于少数区域时，EVOI 门控达到目标 U_int 的示范数 ≤ 随机 DAgger 的 `O(1/|A_amb|)` 倍。

**定理 16（端到端风险一致性）** A87–A95 下：
1. `P(|τ_cmd−τ*|>ε) ≤ α_chunk+δ_fi+α_emotion+α_wm+α_vqa+α_cal+α_int+α_teach`；
2. `U_int>τ_int ⇒ λ≥0.8 ∧ k 收缩 ∧ 有界延迟内请求示教`；
3. 快变故障（ω_f≥3ω_cal）检出与 CALM 相同（引理 13 保留）；
4. 示教更新满足 SASI（定理 17）。

**定理 17（安全不可示教）** SASI + CTC 第 6 关 ⇒ `Act(π_θ′)⊆Act(π_θ)`、`λ_floor(θ′)≥λ_floor(θ)`；故 TILT-RAS 安全集 ⊆ CALM-RAS 安全集——加意图层不引入新不安全动作，只可能更保守。

**定理 18（解释吸收不可能性/三难）** 异常质量守恒下无外部锚时 `miss_int+miss_teach+miss_fault ≥ 1−η_anchor`；要同时降低三者必须增加外部锚（canary/反事实探针/真值抽检），纯加解释层只会把误差在层间搬运——统一刻画 R68「标定吸收」与 R69「意图吸收」。

## 7. 本轮最大风险

**一句话**：TILT-RAS 把「人为什么会偏离预期」的最终解释权交给了一个**不可证伪**的意图潜变量——当机器人越懂意图，它就越有理由把人的纠正解释为「你没懂/你改主意了」，而不是「我错了/世界坏了」；由于意图没有真值、只有后验，**每一层新增的解释器（标定 → 意图）都能把上一层失败的证据吸收掉（定义 309 / 定理 18），系统于是越解释越自信、越自信越敢替人做主**，最终以「为你好」的善意家长主义形式越过人类，而所有审计指标都显示一切正常——这是 R68「标定越强、慢故障越隐形」在意图层的升维复发：**示教能力越强，人的异议越隐形。**

**次级风险与缓解**：意图过拟合/过早收敛（多假设 + 熵/多峰惩罚 + 温度校准）；假示范与投毒（DCL 五分量 + canary + 留一教师）；家长主义越权（定理 17 安全不扩张 + E294 独立审计 + 人可否决）；查询骚扰（EVOI 门限 + 预算 + 冷却）；解释吸收（定理 18 → 强制外部锚：canary、反事实探针、周期性真值抽检）；跨教师负迁移（κ 加权 + CTC 认证）。
