### 第 6 轮灵感驱动研究记录（新循环第 1 轮 · 感知认证轮，承接 CADVS-v5）

**灵感词**：6D 位姿估计、视觉定位

**继承关系**：第 5 轮 CADVS-v5（IP-493~496）用「定理 6 证书不变性」把框架推广为「任意生成器 + 冻结认证边界」，执行集 Exec_v5 ⊆ Exec_v4 ⊆ … ⊆ Exec_v29。但 v5 有一个从未被审视的隐含前提：七硬门作用在**世界坐标系中已知的**候选轨迹 x=(pose,wrench) 上，而物体 6D 位姿与机器人定位被当作可信输入。这个前提在真实部署中最先破裂——位姿估计有对称歧义、遮挡、感知混叠，视觉定位有绑架（kidnapping）/动态场景。于是 v5 的证书可能是「形式有效、前提错误」的证书。本轮不新增硬门（继续偿还 R52 锚点维护负债），而是把**信任边界从执行层上移到感知输入层**：用集合值位姿信念 B_α 取代点估计，让七门在 B_α 上取最坏情况，形成 CADVS-v6「感知认证执行」（Perception-Certified Execution, PCE），Exec_v6(B_α) ⊆ Exec_v5(ξ̂) ⊆ Exec_v4 ⊆ …。

**直觉与动机**：

1. **6D 位姿估计 → 位姿不是一个点，而是一个带覆盖保证的集合；把不确定性变成阈值通胀，而不是新门**。直觉：若证书对真实位姿成立，而真实位姿只在 B_α 内以 1−α 概率，那么只要门在 B_α 的**每个**元素上都成立，证书就以 ≥1−α 概率对真实世界成立。严谨化：门规范形 kc_i(x;ξ)=1[s_i(T_ξ x) ≥ τ_i]，定义鲁棒门 kc_i^rob(x;B_α)=1[min_{ξ∈B_α} s_i(T_ξ x) ≥ τ_i]。若 s_i 对位姿度量 L_i-Lipschitz、且 B_α ⊆ Ball(ξ̂,r)，则 min s_i ≥ s_i(ξ̂) − L_i·r，鲁棒门等价于**阈值通胀** τ_i^6 = τ_i^5 + L_i·r(B_α)。于是位姿不确定性像 v5 的情感调制 γ 一样，是第三个「只紧不松」的旋钮——无需第八道门。对称物体用**任务相关对称商** SE(3)/G_sym 处理：抓取任务里对称等价位姿不算错误，避免把无害歧义误判为高风险；但精密插入等非对称任务不做商化（只向安全方向取整）。

2. **视觉定位 → 定位器是另一个提议器，验证谓词才是边界；并引入跨模态完整性通道**。直觉：换一个定位算法（视觉 SLAM、结构定位、FoundationPose、触觉探测）不该改变「什么被认证」，只该改变信念集合。严谨化：定理 12（感知—提议分离）——位姿估计器是提议，认证边界是**可验证的信念谓词**：共形覆盖 + 跨模态残差（视觉 vs 本体/IMU vs 触觉）+ 时序一致性。跨模态残差超共形阈值 → 判为 OOD，膨胀 B_α 或弃权（fail-closed）。这把 v5 的 n_flow 新颖度通道复用为「感知完整性」通道，仍然只收紧。

3. **主动感知 → 歧义无法靠现有视角消解时，不要猜，去「认证地看」**。直觉：位姿集合太大导致鲁棒门交集为空，正确反应不是放行也不是死等，而是执行一个**自身也通过七门**的信息增益动作（换视角、移动底盘、触觉探针）。严谨化：APCF 仅在动作 a ∈ Exec_v6(B_α) 且预测信息增益 IG(a) > θ_ig 时才执行；若不存在被认证的信息动作 → 弃权/人类接管。定理 11：主动感知对安全无新增风险（动作被同一冻结门认证），但**不保证**信息一定增加（IG 预测可能错）——这是诚实边界，不是安全边界。

**关键洞见**：v5 回答「提议是任意生成器时证书边界是否不变」；v6 回答「**连输入位姿都是不确定的生成结果时，证书还意味着什么**」。答案：把「世界状态」也纳入 fail-closed 的集合语义——证书从「对 ξ̂ 成立」升级为「对 B_α 一致成立，故以 ≥1−α 概率对真值成立」。执行集收缩升级为四重：Exec_v6(B_α) ⊆ Exec_v6(B')（当 B' ⊇ B_α）⊆ Exec_v5(ξ̂) ⊆ …。新增模块只有四个：集合值信念 CPBK、鲁棒门 URGE（阈值通胀）、认证主动感知 APCF、感知—提议分离 PPSL；硬门仍为七。

**形式化目标（增量）**：
1. CPBK：B_α = Conformal(ξ̂, score, calibration) ∩ {跨模态一致}，覆盖 P(ξ_true ∈ B_α) ≥ 1−α；输出半径 r(B_α)、多模态/对称标志、OOD 标志。
2. URGE：kc_i^rob(x;B_α)=1[min_{ξ∈B_α} s_i(T_ξ x) ≥ τ_i]；Lipschitz 界 ⇒ τ_i^6 = τ_i^5 + L_i·r；执行集 Exec_v6(B_α)={x ∈ supp(π) : ∧_i kc_i^rob(x;B_α)=1}。
3. APCF：信息增益动作集 A_info，仅执行 a ∈ Exec_v6(B_α) 且 IG(a) > θ_ig；空集 → 弃权。
4. 定理 9（位姿鲁棒单调/感知棘轮）、定理 10（覆盖 ⇒ 概率可靠执行）、定理 11（主动感知安全无增害）、定理 12（感知—提议分离）。
5. 引理 45（Lipschitz 阈值通胀等价性）、引理 46（任务相关对称商不放大风险）。
6. 复杂度：鲁棒门 O(1)（阈值预通胀，控制环）；精确 min 仅慢时域 O(|B_α|·cost)。

**本轮最大风险**：**共形覆盖的交换性假设恰好在开放世界部署时失效**——新物体/新光照/动态场景/对抗贴片会让 1−α 保证在系统最需要它的分布外场景里静默归零，而系统仍「看起来校准良好」（在标定集上有限样本有效），这种虚假的可靠性比诚实的点估计更危险。

## 2. 关键算法骨架

### IP-497 CPBK：认证位姿信念核（慢时域 10–30 Hz，与控制环解耦）

```python
@dataclass
class CertifiedPoseBeliefKernel:
    """CPBK：任意位姿/定位器 → 共形集合值信念 B_α。
    红线：估计器只是提议器；认证边界是 V(B) 谓词（定理 12）"""
    pose_est: Any                 # FoundationPose / PnP / 学习模型（可替换）
    loc_est: Any                  # 视觉 SLAM / 结构定位（可替换）
    calib: ConformalCalibrator    # 离线标定：score(ξ, obs)
    sym: Any                      # 任务相关对称群 G_sym（含"非对称"空群）
    alpha: float = 0.05
    r_max: float = 0.02           # 超过则必须主动感知

    def belief(self, obs) -> PoseBelief:
        xi = self.pose_est(obs.rgbd)                       # 点估计（中心）
        xi_loc = self.loc_est(obs.rgbd, obs.imu)           # 视觉定位
        q = self.calib.nonconformity(xi, obs)              # 共形分
        B = self.calib.set(xi, q, alpha=self.alpha)        # {ξ: score ≤ q_{1-α}}
        if task_is_symmetry_invariant(self.sym):           # 引理 46
            B = quotient(B, self.sym)                      # 任务相关对称商
        r_cm = d(xi, xi_loc)                               # 跨模态残差
        ood = (r_cm > self.calib.tau_cm) or (n_flow(obs) > self.tau_novel)
        if ood:
            B = inflate(B, delta_ood)                      # 膨胀（保守），或弃权
        return PoseBelief(B=B, center=xi, radius=radius(B),
                          multimodal=is_multimodal(B), ood=ood,
                          r_cm=r_cm, valid=self.verify(B, obs))

    def verify(self, B, obs) -> bool:
        """V(B)：覆盖可计算 ∧ 跨模态一致 ∧ 时序一致（不通过 → fail-closed）"""
        return (not B.ood) and temporal_consistent(obs, B) and radius(B) <= R_HARD
```

### IP-498 URGE：不确定性鲁棒门评估（控制环 O(1)）

```python
def robust_gate(kc_point, score_fn, B, tau5, L):
    """引理 45：Lipschitz 界 ⇒ min_{ξ∈B} s ≥ s(ξ̂) − L·r。
    控制环只做阈值通胀，O(1)；精确 min 仅在慢时域/多模态时启用。"""
    r = B.radius
    tau6 = tau5 + L * r                    # 只增不减（r ≥ 0, L ≥ 0）
    return kc_point(score_fn(B.center), tau6)

def robust_gate_exact(score_fn, B, tau, eps=1e-3):
    """慢时域：B 非凸/多模态时，对 B 的顶点或采样集做 min（分支定界）。"""
    return min(score_fn(xi) for xi in vertices_or_samples(B)) >= tau
```

### IP-499 APCF：认证主动感知回退（慢时域，事件触发）

```python
@dataclass
class ActivePerceptionCertifiedFallback:
    """APCF：歧义未消解时，执行一个自身过七门的信息增益动作。
    定理 11：动作被同一冻结门认证 ⇒ 安全无增害；但不保证 IG 实现。"""
    efa: EvidenceForgingAssemblerV6
    theta_ig: float = 0.2
    r_max: float = 0.02

    def act(self, B, context):
        if (not B.multimodal) and B.radius <= self.r_max and not B.ood:
            return None                                # 无需主动感知
        A = generate_info_actions(B, context)          # 换视角/移动/触觉
        certified = []
        for a in A:
            ok, _, _ = self.efa.select_info(a, context)  # 与任务动作同一套七门
            if ok and predict_info_gain(a, B) > self.theta_ig:
                certified.append(a)
        if not certified:
            return ABSTAIN                             # fail-closed：弃权/接管
        return max(certified, key=lambda a: predict_info_gain(a, B))
```

## 3. 引理与定理（CERTCALC-v6）

### 引理 45（Lipschitz 阈值通胀等价性）

**陈述**：设 s_i 对位姿度量 d 满足 L_i-Lipschitz，B ⊆ Ball(ξ̂, r)。则
min_{ξ∈B} s_i(x;ξ) ≥ s_i(x;ξ̂) − L_i·r。
因此 kc_i^rob(x;B)=1 等价于 kc_i(x;ξ̂) 在阈值 τ_i + L_i·r 下为 1。
**证明**：对任意 ξ∈B，s_i(ξ̂) ≤ s_i(ξ)+L_i d(ξ,ξ̂) ≤ s_i(ξ)+L_i r，取 min 即得。∎
**工程含义**：位姿不确定性被完全吸收为阈值通胀，与 v5 的 γ 同构，控制环零额外代价。

### 引理 46（任务相关对称商不放大风险）

**陈述**：设任务泛函 Φ 在 G_sym 下不变。则对任意候选 x，Φ(x) 在 B 与 B/G_sym 上取最坏结果相同；且 r(B/G_sym) ≤ r(B)。
若 Φ 非 G_sym-不变（如精密插入），则不商化，退回完整 B（保守方向）。
**证明**：不变性给出 Φ(T_g x)=Φ(x) ∀g∈G_sym，故最坏值只在轨道代表元上取；商集是 B 的像，直径不增。∎
**诚实边界**：对称群标注错误（把非对称物体当对称）会**放大**风险，因此对称标注本身必须是冻结、人工核验的配置，不可在线学习。

### 定理 9（感知棘轮 / 位姿鲁棒单调性）

**陈述**：设 B_α ⊆ B'，则 Exec_v6(B') ⊆ Exec_v6(B_α)。若 ξ̂ ∈ B_α（信念以点估计为中心），则 Exec_v6(B_α) ⊆ Exec_v5(ξ̂)。
**证明**：min 在更大集合上更小 ⇒ 鲁棒门通过集随 B 增大而缩；又 min_{ξ∈B_α} s_i ≤ s_i(ξ̂) ⇒ 鲁棒通过 ⇒ 点通过。∎
**含义**：不确定性是第三个单调收紧旋钮（情感 γ、记忆新颖度、位姿半径 r），系统不存在感知层的扩张算子。

### 定理 10（覆盖 ⇒ 概率可靠执行）

**陈述**：在 (B8) 标定集与测试样本可交换、共形有效的前提下，P(ξ_true ∈ B_α) ≥ 1−α。若 x ∈ Exec_v6(B_α)，则
P(∃i: kc_i(x;ξ_true)=0) ≤ P(ξ_true ∉ B_α) ≤ α。
更精确地，接受轨迹因位姿误差导致的真实违例率 ≤ α + δ_spec（δ_spec 为七门自身的规格鸿沟）。
**证明**：x ∈ Exec_v6 ⇒ 对所有 ξ∈B_α 七门皆过；事件「真实违例」蕴含 ξ_true∉B_α。并集界 + 覆盖定义。∎
**诚实边界**：(i) 该 α 是**边际**保证（对随机标定+测试平均），不是对每个 x 的条件保证；(ii) 交换性在开放世界失效时界不成立（见 R60）；(iii) 不消除 δ_spec。

### 定理 11（主动感知安全无增害）

**陈述**：APCF 执行的任意信息动作 a 满足 a ∈ Exec_v6(B_α)（与任务动作同一冻结门集）。因此在定理 10 意义下，a 引入的真实违例率 ≤ α + δ_spec；若 A_info ∩ Exec_v6(B_α)=∅，则任务执行集置空并弃权（fail-closed）。
**证明**：APCF 的筛选条件即 a∈Exec_v6；空集分支直接返回弃权。∎
**诚实边界**：本定理只保证**安全无增害**，不保证 IG>0 真的实现（预测可能错，主动感知可能白动）；也不保证信息动作在时延预算内完成。

### 定理 12（感知—提议分离）

**陈述**：对任意两个估计器 E,E'，其有效信念为 B,B'。验证谓词 V(·) 与门代码只依赖 (B, x)，不依赖估计器内部结构。因此更换估计器只改变 B，不改变 τ^5 与门谓词；Exec_v6(B) 由 (B, 冻结门) 唯一决定。
**推论**：估计器可以自由替换/升级，安全边界不随之漂移。
**诚实边界**：分离性**不**保护「有效性已被破坏」的估计器——一个自信地给出过小 B 的对抗估计器仍会使覆盖失效、使 Exec_v6 变大。因此 PPSL 必须包含独立的有效性审计（共形覆盖、跨模态、红队），且 V(B) 不通过时 fail-closed。这把风险显式归因到「估计器有效性」，而不是假装被分离性消除。

### 定理 v6（总装：四重收缩与感知认证）

**陈述**：在 v5 假设 (B1)~(B7) 及新增 (B8) 共形可交换性、(B9) ξ̂∈B_α 下：
(i) Exec_v6(B_α) ⊆ Exec_v5(ξ̂) ⊆ Exec_v4 ⊆ …（定理 9 + 点估计含于信念）；
(ii) 鲁棒门等价于阈值通胀 τ^6=τ^5+L·r（引理 45），控制环 O(1)；
(iii) 接受轨迹真实违例率 ≤ α + δ_spec（定理 10，边际意义）；
(iv) 主动感知不新增安全风险，空集弃权（定理 11）；
(v) 换估计器不改变认证边界（定理 12），但估计器有效性需独立审计；
(vi) 对称商仅在任务不变量成立时启用，否则保守退回（引理 46）。

## 4. 集成流水线（v5 → v6）

```
离线/慢时域：
  共形标定：多场景 (obs, ξ_gt) ──▶ 非一致性分位数 q_{1-α}、τ_cm ──▶ CPBK.calib
  Lipschitz 估计：每门 s_i 在位姿扰动下的局部 Lipschitz 常数 L_i（含安全上界）
  对称群核验：人工确认 G_sym + 任务不变性 ──▶ 冻结配置（禁止在线学习）
  感知有效性红队：对抗贴片/遮挡/动态场景 ──▶ 覆盖率塌缩报告（必须公开）
  联邦：Δ_i(共形分位数/L_i/对称群摘要, DP) ──▶ Φ_global 下发

在线慢时域（10–30 Hz，与 1 kHz 控制环解耦）：
  CPBK.belief(obs) ──▶ B_α, r, ood
     ├─ V(B)=false 或 ood ──▶ APCF.act()（认证信息动作 / 弃权）
     └─ 否则 ──▶ 阈值预计算 τ^6 = γ·τ^4 + L·r

在线准入（异步）：
  FMPP.propose(K=8, c 含 B_α 摘要) ──▶ 鲁棒廉价门（URGE）──▶ VACK ──▶ BCK 预览
     └─ 全灭 ──▶ fail-closed 回退规则提议（v4 规则，仍用 τ^6）

在线控制环（目标 < 0.6 ms）：
  EEK + BCK（事件触发）；阈值 τ^6 已预计算，鲁棒门退化为 O(1) 比较
```

## 8. 本轮最大风险（最终确认）

**一句话**：**共形覆盖的交换性假设恰好在开放世界部署时失效**——新物体/新光照/动态场景/对抗贴片会让 1−α 保证在系统最需要它的分布外场景里静默归零，而系统仍「看起来校准良好」（在标定集上有限样本有效），这种虚假的可靠性比诚实的点估计更危险。
