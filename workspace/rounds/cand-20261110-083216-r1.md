# 第 43 轮（新循环第 3 轮） · 认证动作空间课程（CAC）：把证书从「状态守卫」变成「安全动作掩码」，用课程学习有序扩张可行动作集（四层架构 v8）

> 承接第 42 轮 v19（Sim-Cert-RAG 飞轮）。第 42 轮把证书做成可进化的资产，但它的证书对象始终是**状态**：守卫 g(x)、有效域 C_sim、偏移统计 S_t。它留下两个未解张力：(1) **保守性**——W_1 迁移界必须按「全域动作 + 全域状态」估计，越全局越松，Nominal 占比上不去；(2) **静默失效**——仿真偏差与检索幻觉都发生在「状态看起来安全」的地方。本轮灵感词「课程学习」「动作空间」给出的解不是再加一个验证器，而是**换一个证书载体**：证书不再只回答「这个状态安全吗」，而回答「**在这个状态下，哪些动作被允许**」，即动作条件证书 m(x,a) 与认证动作集 A_cert(x)。课程学习则负责回答「先允许哪些、后允许哪些、何时扩权」——把动作空间的有序扩张变成一条可证明、可回滚、可观测的课程。由此，第 42 轮的全局迁移界被切成**逐相位的局部迁移界**（相位内动作分布更同质，W_1 更小、α_e 更紧），而「静默失效」被改造成「相位升降级」这类**响亮失败**。

## 0. 直觉与动机

**灵感 1（课程学习 → 给「证书」排课，而不是只给策略排课）**：常规课程学习排的是任务难度：先易后难、先少后多。我们的直觉是把它**上移一层**：排的是「**可行动作集 × 证书有效域**」的难度。第 κ 课 =（动作空间 A_κ，证书 C_κ，任务分布 D_κ），且 A_κ ⊆ A_{κ+1}、C_κ 对 A_κ 成立。只有当 C_κ 在当前课被验证、且保守间隙收窄到预算内，才升到 κ+1；出现违例则回退到上一课。关键反直觉点：课程的首要收益不是「策略学得快」，而是「**每一课内的 sim-to-real 分布更同质**」——动作被限制在 A_κ，实机数据与仿真数据的支撑集都变窄，W_1 估计的方差与偏差同时下降，迁移界更紧，证书更愿意放行。课程于是同时治好了第 42 轮的两个病：保守性与静默失效。

**灵感 2（动作空间 → 证书的载体从「状态集合」换成「动作集合」）**：第 41/42 轮的守卫是 g(x) ≥ θ，隐含假设「策略动作固定、只查状态」。但机器人真正的安全旋钮是**动作**：同一个状态，减速通过安全、全速通过不安全；轻触安全、硬撞不安全。于是定义动作条件边际 m(x,a) 与**认证动作集** A_cert(x) = {a ∈ A : m(x,a) ≥ θ}，运行时它就是一个**安全动作掩码（shield）**：策略输出 a，若 a ∉ A_cert(x) 就投影到最近的认证动作。动作空间本身有结构（原始动作 → 参数包络 → 接触模式 → 宏动作/选项 → 双臂协同），天然构成一个**格（lattice）**，可以用生长算子 G 逐层扩张。这样「扩张动作空间」不再是一次性把所有自由度交给策略，而是沿着格的边、在证书覆盖得住的方向上逐格放开。

**灵感 3（二者耦合 → 相位即平稳窗口，动作前沿即可加性证明义务）**：把课程相位当作飞轮的「平稳窗口」：同一相位内动作分布固定，W_1 与 α_e 只需在该窗口标定；换相位时重标定。于是第 42 轮的「全域 W_1」被分解成一组「相位局部 W_1」。更漂亮的是证明侧的**动作可加性**：对固定的候选不变式 I，若 I 对 A_κ 归纳、且对前沿 F_κ = A_{κ+1} \ A_κ 归纳，则 I 对 A_κ ∪ F_κ 归纳——证明义务精确地只在 F_κ 上新增，旧课的证明可缓存复用。课程因此有严格的形式收益：**增量验证成本 ∝ 前沿动作数 × 当前相位可达状态数**，而非全动作 × 全状态。动作空间课程不是启发式调参，而是「把一个大证明拆成一串小证明」的证明工程。

**与既有飞轮的耦合**：IP-57（课程引擎）决定「下一课是什么」；IP-58（动作条件盾）决定「当前哪些动作允许」；IP-59（相位运行时）决定「何时降级/升级」。三者把第 42 轮的「状态守卫 + 全局证书」升级为「**动作掩码 + 相位租约证书**」：降级不再是一刀切 SafeStop，而是逐级收回动作空间（A^κ → A^{κ-1} → … → 安全核 A^0），可用性显著提升。

## 1. 形式化定义（增量：定义 38–44）

**定义 38（动作条件证书与认证动作集）**：给定状态 x、动作 a、扰动 ξ∼D_sim 下的鲁棒边际 m(x,a;ξ)。**动作条件证书边际** m(x,a) = inf_{ξ∼D_sim} m(x,a;ξ)。给定阈值 θ_κ（相位相关），**认证动作集** A_cert^κ(x) = {a ∈ A_κ : m(x,a) ≥ θ_κ}。**掩码级安全定理**：若对每个时刻 t 执行 a_t ∈ A_cert^κ(x_t)，且 m 的下界在转移模型 T 下是归纳的（m(x,a) ≥ θ ⟹ m(T(x,a)) ≥ θ，或进入终止安全集），则闭环无安全违例。

**定义 39（动作空间格、生长算子与可认证秩）**：动作空间格 (𝒜, ⊆) 上定义生长算子族 G = {G_add（加原始动作）、G_env（扩大速度/力包络）、G_macro（原始动作序列化为选项）、G_coord（加协同维度）}。A_{κ+1} = A_κ ⊕_ρ G(A_κ)，其中 ⊕_ρ 表示**预算受限生长**：动作空间 ε-覆盖数增长 N(A_{κ+1}, ε) / N(A_κ, ε) ≤ ρ。**可认证秩** r_κ = dim(A_κ)（有效自由度），初始 r_0 = 0（安全核：停止/回退/柔顺保持），逐步增长到 r_max。

**定义 40（动作可加性定理）**：固定候选不变式 I ⊆ X 与状态域 X_I ⊆ I。若 (a) I 在 X_I 上对 A_κ 归纳（∀x∈X_I, ∀a∈A_κ: T(x,a)∈I），且 (b) I 在 X_I 上对前沿 F_κ = A_{κ+1}\A_κ 归纳，则 I 在 X_I 上对 A_{κ+1} 归纳；且新增证明义务**仅有** (b)。证明按 a ∈ A_κ ∪ F_κ 分类即得。**推论（增量成本）**：若 A_κ 的证明已缓存，扩张到 A_{κ+1} 的验证成本 ∝ |F_κ|·|X_I|，而非 |A_{κ+1}|·|X_I|。注：若新动作使可达状态集扩张到 X_I' ⊃ X_I，则还需在「壳层」X_I'\X_I 上对 A_{κ+1} 复核——课程应以 ρ 限制壳层体积，使增量优势成立。

**定义 41（相位自动机与升降级谓词、无静默失效定理）**：相位自动机 P = (K, →)，状态 κ = (动作空间 A_κ, 证书 C_κ, 阈值 θ_κ, 租约 T_lease)。**升级谓词** Promote(κ) = [Coverage(F_κ) ≥ 1−δ] ∧ [Slack_κ ≤ s_hi] ∧ [Ŵ_1^κ ≤ ε_κ] ∧ [样本量 n_κ ≥ n_min]。**降级谓词** Demote(κ) = [运行时掩码未命中 ∨ 相位漂移 Ŝ_t^κ > τ_κ ∨ 租约过期]。**无静默失效定理**：若 (i) 每次升级前 Promote 被真实求值，(ii) 运行时对每次掩码未命中/漂移超阈都触发 Demote，则任何不安全事件必然伴随一次可观测的「升级门失败」或「相位降级」事件。即课程把第 42 轮「自信地静默失效」转化为「响亮地降级」。残余静默风险只剩「m 在未采样动作上估计错误」，正是定义 42 要管的部分。

**定义 42（动作维覆盖与相位局部迁移界）**：动作维 Lipschitz 假设：|m(x,a) − m(x,a')| ≤ L_a‖a−a'‖。动作空间采样前沿 F_κ 的 ε-网保证：真实 inf_{a∈F_κ} m ≥ 网点最小边际 − L_a·ε。**相位局部迁移界**：在相位 κ 内，W_1(D_real^κ, D_sim^κ) ≤ ε_w^κ，且 α_e^κ = 1 + L_m·ε_w^κ/θ_κ；经验假设 ε_w^κ 随 A_κ 的支撑直径单调增（由 E90 检验）。于是「先小动作空间」不仅好学，而且**迁移界更紧、证书更不保守**。

**定义 43（课程难度与自步调度）**：难度 d(κ) = α·log N(F_κ, ε) + β·ContactRichness(F_κ) + γ·EnergyEnvelope(F_κ) + δ·(1 − Slack_κ) + η·FailRate_hist(F_κ)。自步调度：Coverage ≥ c_hi 且 FailRate ≤ f_lo ⟹ 升一课（d 递增）；FailRate ≥ f_hi 或 Slack 越界 ⟹ 降一课并在 F_κ 上做「补救课」（针对性仿真 + 反例入库）。调度须满足 d(κ+1) − d(κ) ∈ (0, Δd_max]，避免跳课。

**定义 44（课程感知成本与增量再认证）**：COT_cac = Σ_κ C_verify(F_κ, X_κ) + C_sim^κ + C_edge·T_life + C_human·N_confirm。相对第 42 轮 COT_flat = C_verify(A_full, X) 的核心差异不在首轮总量，而在**漂移后的再认证成本**：偏移只影响当前相位，重验 ∝ |F_κ|·|X_κ| ≪ |A_full|·|X|；且早期相位动作空间小，首达安全可用的时间更短（实验以 time-to-first-safe-operation 计）。

## 2. 三大新增 IP（IP-57/58/59）+ 既有 IP 升级

### 2.1 IP-57 CERT-ACTION-CURRICULUM（CACE，认证动作空间课程引擎）
1. **动作空间格构建**：把 UniBot 动作参数化拆成「原始动作（stop/retreat/hold/reach/grasp/push/place）× 参数包络（v、F、接触模式）× 宏动作（选项）」；人工先验给出偏序，自动补全可组合边。
2. **难度估计**：用覆盖数、接触复杂度、能量包络、历史失败率与保守间隙计算 d(κ)；用「证书敏感度热力图」估计前沿 F_κ 的验证难度。
3. **自步调度 + 补救课**：升级门（定义 41）通过才升课；失败动作自动生成「补救课」——定向域随机化 + 对抗初始状态 + 反例入 CKB，而不是全局重训。
4. **多课程序集成**：维护 2–3 条不同序（按能量/按接触/按协同），在仿真里比 time-to-safe-usable，择优；避免单一课程序过拟合。

### 2.2 IP-58 ACTION-CERT-SHIELD（ACS，动作条件证书盾）
1. **动作条件边际**：m(x,a) 用三路融合——解析区间界（接触前）、仿真经验分位（接触中）、学习代理 m̂_φ(x,a)（高维动作）；用 L_a 与 L_x 给出融合误差上界。
2. **认证动作集的高效表示**：动作低维参数化 a = ψ(z), z ∈ Z（如 3-DoF 位置 + 1-DoF 夹爪 + 1 维力），在 Z 上用单调性/区间表示 A_cert(x)，查询退化为区间求交 + 二分，避免逐动作枚举。
3. **运行时投影**：策略动作越界时投影到最近认证动作 a' = Π_{A_cert(x)}(a)，带滞回（hysteresis）与最小停留时间，避免掩码抖动；投影优先从「安全核 + 退让」中选，保证可执行。
4. **动作维覆盖保证**：每个相位维护 F_κ 的 ε-网与 L_a 估计；网外动作一律视为未认证（保守拒绝），把「网外请求率」作为课程升级的观测指标。

### 2.3 IP-59 PHASE-CERT-RUNTIME（PCR，相位证书运行时）
1. **相位标签与租约**：自动机状态携带 κ；证书带租约 T_lease（时间/漂移/版本），过期即降级，杜绝陈旧证书。
2. **降级梯**：A^κ → A^{κ-1} → … → A^0（停止/回退/柔顺）→ SafeStop；每级只收回动作维度，不直接停机，最大化 Nominal 占比。
3. **相位漂移监控**：每相位独立基线 D_sim^κ，滑窗估计 Ŝ_t^κ；跨相位不混算，降低误触发与漏检。
4. **升级门离线执行**：Promote 在仿真 + 少量实机标定上求值；运行时只做「租约校验 + 掩码查询 + 漂移监控」，保持 < 100μs。

## 4. 实验设计（E87–E94 硬门槛，承接 E79–E86）

| 实验 | 指标 | 门槛 |

| E88 课程样本效率 | time-to-first-safe-operation、样本量 vs 平稳动作空间 | 加速 ≥ 1.5x；样本降 ≥ 30% |

| E93 动作掩码运行时 | 7-DoF 动作查询+投影 p99；MCU RAM | < 10μs；< 4KB；可跑 STM32H7 |
| E94 长时程联合 | 100h：不安全事件、Nominal、相位降级次数 | 0 起；Nominal ≥ 85%；降级 < 3 次/天 |

回退：E87 掩码失败 → 退回状态守卫 + 粗动作包络；E88 课程无加速 → 用固定动作空间，仅保留掩码；E89 可加性失效（不变式需大幅扩张）→ 每相位全量重验；E90 相位 W_1 不降 → 关闭课程收益叙事，仅保留安全收益；E91 投影抖动 → 加大滞回/直接安全核 + 规划重规划；E92 迁移失败 → 手写课程。

## 5. 本轮最大风险

**一句话**：认证动作掩码把安全责任从「状态」转移到「动作」，若 m(x,a) 在动作维上的覆盖/Lipschitz 界在**接触模式切换处**失效，掩码会在「状态看起来完全安全」的未见动作上放行致命动作——这比状态守卫失效更隐蔽；因此 E87（掩码级安全性）与动作维 ε-网 + 接触边界采样必须作为红线，任一不达标即回退到「状态守卫 + 粗动作包络」。

# 第 43 轮产物 · 创新点清单 v20：认证动作空间课程（CAC）× 动作条件证书掩码（四层架构 v8）

> 承接第 42 轮产物 v19。本轮**换证书载体**而非叠加验证器：把「状态守卫 g(x)」升级为「动作条件掩码 a ∈ A_cert(x)」，并用课程学习有序扩张动作空间。**新增** IP-57/58/59；**升级** IP-50/51/52/53/55/56/49/47/45。核心定理：对固定候选不变式，归纳性对动作集合可加，故增量验证只落在动作前沿 F_κ 上。

### 2.1 IP-57 CACE：动作空间格、难度与自步调度
```
def build_action_lattice(base_primitives, max_rank=r_max, rho=2.0):
    A = {0: safe_kernel()}   # stop / retreat / compliant_hold，r_0 = 0
    k = 0
    while A[k].rank < max_rank:
        cands = []
        for G in (G_add, G_env, G_macro, G_coord):
            for A_next in G(A[k]):
                if covering_ratio(A_next, A[k]) <= rho:   # 预算受限生长
                    cands.append(A_next)
        # 优先低难度、且满足偏序（不跳课）的候选
        A[k+1] = argmin([c for c in cands if is_cover(A[k], c)], key=lambda c: difficulty(A[k], c.diff, c.cert))
        k += 1
    return A

def difficulty(A_k, F_k, cert_k):
    return (alpha*log(covering_number(F_k, eps_a))
            + beta*contact_richness(F_k)
            + gamma*energy_envelope(F_k)
            + delta*(1 - slack(cert_k))
            + eta*historical_fail_rate(F_k))

def self_paced_step(k, A, certs, stats):
    F = A[k+1].diff if (k+1) in A else A[k].frontier
    cov, fail, sl, n = stats.coverage(F), stats.fail_rate(F), stats.slack, stats.n
    if cov >= c_hi and fail <= f_lo and sl <= s_hi and n >= n_min:
        return 'PROMOTE', k+1          # Promote 谓词（定义 41）
    if fail >= f_hi or sl > 1.5*s_hi:
        return 'DEMOTE', max(k-1, 0)   # 降级 + 补救课
    return 'HOLD', k                   # 补样本 / 加密 ε-网

def remedial_lesson(F_k, counterexamples):
    return {
        'action_frontier': F_k,
        'domain': restrict_domain(D_sim, F_k) + adversarial_init(counterexamples),
        'init': counterexamples,
        'target': 'close_frontier_gap'
    }
```

### 2.2 IP-58 ACS：动作条件边际、认证动作集与投影
```
def action_conditioned_margin(x, a, cert, sim_stats):
    # 三路融合，取保守下界；动作维网外保守扣减
    m_ana   = interval_bound(x, a)                 # 接触前解析区间
    m_sim   = sim_stats.quantile(x, a, 0.01)       # 接触中仿真经验分位
    m_learn = surrogate(x, a) - surrogate_err_bound(x, a)   # 高维学习代理
    return min(m_ana, m_sim, m_learn) - cert.L_a * cert.eps_a_net

def certified_action_set(x, A_k, theta_k, cert):
    # 低维参数化 a = psi(z)；在 Z 上保序/保 Lipschitz
    Z_cert = []
    for interval in partition_Z(A_k):
        if monotone_lower_bound(interval, x, cert, theta_k):
            Z_cert.append(interval)                 # 整段可认证
        elif not upper_bound_below_theta(interval, x, cert, theta_k):
            Z_cert += bisect_refine(interval, x, cert, theta_k)
    return [psi(z) for z in Z_cert]

def shield_project(a, x, phase, cert, last_a):
    if action_conditioned_margin(x, a, cert, phase.sim_stats) >= phase.theta:
        return a, 'PASS'
    A_cert = certified_action_set(x, phase.A_k, phase.theta, cert)
    if not A_cert:
        return kernel_action(x), 'KERNEL'           # 安全核兜底
    a_proj = nearest(A_cert, a, warm_start=last_a)
    if osa_distance(a, a_proj) > d_max:
        return kernel_action(x), 'TRIP'             # 投影过远视为掩码未命中
    return a_proj, 'PROJECT'
```

### 2.3 前沿增量证书（可加性定理的落地）

def certify_action_phase(I, A_k, F_k, X_I, eps_a):
    # 旧课证明已缓存：O(1) 命中，不再重跑
    assert certify_inductive_cached(I, A_k, X_I)

### 2.4 IP-59 PCR：相位运行时与优雅降级梯
```
def phase_runtime_step(x, a_policy, phase, cert, monitor):
    # 1) 租约校验 O(1)
    if cert.lease_expired(phase, now=monitor.t):
        return demote(phase), kernel_action(x), 'LEASE_EXPIRED'
    # 2) 掩码查询 + 投影（< 10us）
    a_exec, status = shield_project(a_policy, x, phase, cert, monitor.last_a)
    # 3) 相位局部漂移（不跨相位混算）
    if monitor.drift(phase, x) > phase.tau:
        return demote(phase), a_exec, 'DRIFT'
    if status == 'TRIP':
        return demote(phase), a_exec, 'MASK_MISS'
    if status == 'KERNEL' and phase.k > 0:
        return demote(phase), a_exec, 'NO_CERTIFIED_ACTION'
    return phase, a_exec, status

def demote(phase):
    # A^kappa -> A^{kappa-1} -> ... -> A^0 -> SafeStop
    return max(phase.k - 1, 0)

def promote_gate(phase_next, stats, sim):
    # 升级门离线执行：覆盖、保守间隙、相位局部 W_1、样本量
    return (stats.coverage(phase_next.F) >= 1 - delta
            and stats.slack <= s_hi
            and sim.W1_phase(phase_next) <= phase_next.eps_w
            and stats.n >= n_min)
```

## 3. 定理与推导

### 3.1 动作可加性定理（定义 40）
**命题**：固定 I ⊆ X、X_I ⊆ I。若 I 对 A_κ 归纳且对 F_κ 归纳，则 I 对 A_{κ+1}=A_κ∪F_κ 归纳。
**证明**：任取 x∈X_I、a∈A_{κ+1}。若 a∈A_κ，由 (a) 得 T(x,a)∈I；若 a∈F_κ\A_κ，由 (b) 得 T(x,a)∈I。两情形覆盖 A_{κ+1}，故归纳成立。∎
**代价**：旧课对 A_κ 的证明可缓存，新增义务恰为 `{(x,a): x∈ε-net(X_I), a∈ε-net(F_κ)}`，规模 |F_κ|·|X_I| / (ε_x ε_a)。
**边界**：若新动作使可达集扩张到 X_I'，需在壳层 X_I'\X_I 上对所有 A_{κ+1} 复核；课程用 ρ 限制壳层，否则退化为全量重验。

### 3.2 无静默失效定理（定义 41）
设不安全事件 E = 「某时刻执行了 a∉A_cert^κ(x) 或证书已过期」。由运行时逻辑，E 必先触发 `MASK_MISS / TRIP / DRIFT / LEASE_EXPIRED` 之一 → Demote（可观测）；若升级前存在未覆盖前沿，则 Promote 求值为假 → 不升级（可观测）。因此 E 不可能在无任何相位事件的情况下发生；唯一残余是「m 在未采样动作上高估」，由 3.3 的覆盖界控制。∎

### 3.3 动作维覆盖界（定义 42）
若 |m(x,a)−m(x,a')| ≤ L_a‖a−a'‖ 且 F_κ 有 ε_a-网 {a_i}，则
inf_{a∈F_κ} m(x,a) ≥ min_i m(x,a_i) − L_a·ε_a。
故自动化验证只需在网点上执行，并对结果扣减 L_a·ε_a；网外动作在运行时一律拒绝。**红线**：接触模式切换处 L_a 可能突变，须按接触模式分段估计 L_a，并对每段单独建网。

### 3.4 相位局部迁移界（定义 42）
α_e^κ = 1 + L_m·ε_w^κ/θ_κ。若 ε_w^κ ≤ ε_w^global（经验假设，E90 检验），则 α_e^κ ≤ α_e^global，证书更紧，A_cert 更大，Nominal 占比更高。这给出「课程 → 更紧迁移界 → 更高可用性」的因果链。

## 7. 本轮最大风险

**一句话**：认证动作掩码把安全责任从「状态」转移到「动作」，若 m(x,a) 在动作维上的覆盖/Lipschitz 界在**接触模式切换处**失效，掩码会在「状态看起来完全安全」的未见动作上放行致命动作——这比状态守卫失效更隐蔽；因此 E87（掩码级安全性）与动作维 ε-网 + 接触边界采样必须作为红线，任一不达标即回退到「状态守卫 + 粗动作包络」。
