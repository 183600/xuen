# 第 60 轮（承接第 59 轮「执行接地层」IP-145~151；灵感循环第 1 轮；本轮灵感：「UniBot」×「MuJoCo」）

> 第 59 轮把「证据承诺」下沉到执行层：BUQ 在线辨识无刷电机的结构性不确定性、ERTC 把嵌入式时序契约化、EEIS 把高层 δ_f 编译成阻抗参数与证书、CLEP 把执行实测回传成第 5 个模态。它解决的是「**这一次**探针/承诺执行得可不可信」。但 UniBot 世界挑战赛考的不是单点执行，而是「**一个模型在没见过的物体/任务/构型/扰动分布上还能不能成**」——抓取、放置、双手协调，真机、统一、规模化评测，按平均成功率与步骤分排序。于是第 59 轮之后仍有一个更大的抽象泄漏：**执行接地 ≠ 泛化接地**。其证据链只覆盖「已访问的检查点」，而泛化命题是「未访问单元的分布风险」。MuJoCo 恰好提供了唯一可行的规模化反事实引擎，但仿真本身是一个**有模型偏差的模型**；把它当独立证据，就是把第 59 轮批判过的「证据自洽幻觉」原样搬到仿真域，形成更隐蔽的**仿真自证**。本轮核心命题：**「仿真只买假设，真机才买证据；把 MuJoCo 降格为反证生成器 + 难度先验 + 采样分配器，把真机升格为覆盖分层校准器；δ_sim 不是常数，而是随情境在线标定的隐状态」**。

核心矛盾：
- **H32（覆盖幻觉：点证据冒充分布证据）**：第 59 轮证明了「走过的格子是安全的」，但 UniBot 的分数由**未走过的格子**决定。平均成功率是风险泛函的一个均值，最坏单元（长尾物体、湿滑桌面、反光/透明材质、双手遮挡、单臂失效）才是失败集中处。没有单元级覆盖证书，单模型多任务的「泛化」只是**对评测分布的过拟合**。
- **H33（仿真自证：sim-real gap 被当成噪声而非隐状态）**：MuJoCo 的接触参数（摩擦系数、接触柔度 solref/solimp、恢复系数）、执行器延迟/饱和、传感器噪声与真机存在系统偏差，且偏差**随接触丰富度、物体材质、双臂协同模式而变**。若把 sim 成功率并入证据，或把 sim 与 real 当作同分布样本池，则会得到「仿真里完美、真机上崩溃」的过度自信。必须把 δ_sim(c) 建成**按单元条件化、可持续标定**的状态。
- **H34（单模型多任务的统计陷阱：平均分掩盖最坏单元 + 排行榜过拟合）**：一个策略、多个任务、反复提交、公开榜单排序。平均成功率 + 步骤分是**单一标量**，可被「只刷易任务」策略刷高；多次提交与榜单比较引入**多重比较**与**评测集过拟合**。需要最坏单元风险、干扰不变性、anytime-valid 多重性控制与 held-out 物体/构型划分。

## 0. 直觉与动机

**灵感 1（UniBot → 覆盖流形与能力单元 UCCM）**
直觉：UniBot 的排行榜其实是「在某个任务-物体-构型-扰动分布上的风险统计量」。把评测对象从「策略在检查点上的后验」提升为「策略在**能力覆盖流形**上的风险剖面」。流形 U = O × T × E × P（物体实例/类别、任务、机器人构型/双臂配置、扰动），划分成能力单元 c；每个单元有风险 R_c(π)（失败概率 + 步骤成本）。泛化目标不是平均成功率，而是**最坏单元风险** R_worst = max_c R_c 与 **CVaR**：一个模型只有在每个单元上都被真机证据覆盖，才算「通用」。仿真提供单元的**难度先验与覆盖候选**，真机提供单元的**校准证据**。

**灵感 2（MuJoCo → 可微反事实证伪 MIDF）**
直觉：MuJoCo/MJX 的可微接触让「找失败」从随机域随机化变成**有方向的对抗搜索**：在物理可行参数集 Θ_phys（摩擦、质量、质心、恢复系数、执行器延迟、传感噪声、接触柔度）内最大化策略风险 r(π; θ)。输出的是**失败见证** w=(θ*, rollout, 失败模式)，不是成功证据。关键纪律：见证必须过 `Realize(w)` 三态判定——真机可复现（real-verified）、仿真伪影（sim-artifact）、物理不可行（inadmissible）；只有 real-verified 见证才允许用于加固策略，且必须留出**held-out adversary** 防止「对仿真对手过拟合」。

**灵感 3（Sim-Real 迁移契约 SRDC）**
直觉：仿真的合法用途应当被**契约化分级**，而不是「信/不信」二元。D0 发现（永远允许：生成假设/失败模式）；D1 排序剪枝（仅当仿真与真机对候选策略的排序保真 ρ_c ≥ ρ_min）；D2 先验（仿真似然权重 w_sim ≤ w_max(b_c)，b_c 是偏差界）；D3 认证（**禁止**，除非该单元真机样本 n_c^real ≥ n_min 且共形覆盖成立）；D4 安全承诺（**绝对禁止**，只认真机 + 第 59 轮 J_exec）。这样仿真永远不会「自证」，只能在被真机标定过的范围内加速。

**灵感 4（覆盖分层主动校准 CSAC）**
直觉：真机 rollout 是最贵的资源，不能均匀撒。仿真给出每个单元的**难度与方差先验**，用 Neyman 式分配 n_c ∝ sqrt(σ_c²/cost_c) 把真机预算压到「最坏单元上界下降最快」的地方；真机做**单元条件共形**，再用 Bonferroni/e-value 权重做**同时覆盖**，得到 P(∀c: R_c ≤ UCB_c) ≥ 1−α。最坏单元上界超阈值 ⇒ 加固、绕行、降级或弃权。

**灵感 5（双臂接触协同裕度 BCSM）**
直觉：UniBot 有双手协调任务，而双手失败的物理前兆几乎总是**接触协同裕度**不足：某一指/掌的切向力逼近摩擦锥边界，或双臂相对内力落出抓取映射零空间，导致「夹不住/打滑/拧转」。MuJoCo 给出接触力与摩擦锥参数，可计算 ρ_syn = min_i(1 − ‖f_t,i‖/(μ_i f_n,i)) 与力闭合裕度，并用 ∂r/∂μ_f、∂r/∂m 的仿真敏感度决定真机该测哪个参数。它把第 59 轮的力限幅 F_max 与力跟踪分位数接到**泛化失败前兆**上。

**灵感 6（排行榜完整性 UGAB + 泛化证书 J_gen）**
直觉：单模型多任务 + 公开榜单 = 评测过拟合的温床。需要 held-out 物体实例/类别/构型划分、**成对反事实干扰不变性**（同一任务只改光照/纹理/相机位姿/桌面高度，测策略翻转率）、以及 anytime-valid 的**多重性校正**（e-process，允许持续看榜而不虚高显著性）。最终输出 J_gen：覆盖图、迁移契约、真机校准日志、反证见证、最坏单元风险、不变性审计、多重性审计——让「通用」从口号变成**可审计的证书**。

## 1. 形式化定义（增量：定义 153–160）

**定义 153（能力覆盖流形 UCCM）** 覆盖流形 U = O × T × E × P，O 为物体实例/类别（几何、质量、摩擦、材质、可变形性），T 为任务（抓取/放置/双手协调/长程组合），E 为具身构型（臂长、自由度、夹爪/灵巧手、相机布置），P 为扰动（光照、遮挡、桌面摩擦、初始位姿抖动、单臂退化）。取可测划分 𝒞 = {c_1,…,c_M}。策略 π 在单元 c 上的风险
```
R_c(π) = E_{u~μ(·|c)} [ ℓ(π;u) ],   ℓ = 1[失败] + λ_step · ŝtep_cost  （步骤分归一化）
```
泛化泛函：R_worst(π)=max_c R_c(π)，R_cvar(π)=CVaR_β({R_c})。覆盖证书
```
C_cov = { (c, n_c, R̂_c, UCB_c, support_c) }_{c∈𝒞},  support_c ∈ {in-support, extrapolation, empty}
```
健全性目标：P(∀c∈𝒞: R_c(π) ≤ UCB_c) ≥ 1−α（**同时**覆盖，非逐单元）。

**定义 154（物理可行对抗集 PAAS 与可微反事实证伪 MIDF）** 物理可行参数集
```
Θ_phys = { θ=(μ_f, m, com, e, τ_act, σ_sensor, k_contact) |
           μ_f∈[μ_min,μ_max], m∈[m_min,m_max], com∈ℬ_com,
           e∈[e_min,e_max], τ_act∈[0,τ_max], σ_sensor∈[0,σ_max],
           k_contact∈[k_min,k_max] }
```
证伪算子：θ* ∈ argmax_{θ∈Θ_phys} r(π;θ)，用 MJX 梯度（接触处用平滑/直通估计）+ 进化搜索混合；见证 w=(θ*, rollout, failure_mode, severity)。实现判定 Realize(w) ∈ {real-verified, sim-artifact, inadmissible}。**加固只允许用 real-verified 见证**构造 Θ_adv ⊆ Θ_phys，并保留 held-out 对抗集 Θ_ho 评估加固是否只是「对仿真对手过拟合」。加固问题 π' = argmin_π max_{θ∈Θ_adv} r(π;θ)。

**定义 155（Sim-Real 偏差状态与迁移契约 SRDC）** 单元偏差状态
```
δ_sim(c) = (bias_c, tv_c, rank_c, support_c)
```
其中 bias_c = |R̂_real,c − R̂_sim,c| 的置信上界（成对 rollout）；tv_c 为失败模式标签分布的总变差；rank_c 为候选策略集 Π_0 上 sim/real 风险的 Spearman 保真；support_c 为真机样本落在仿真支持集内的比例。迁移契约
```
T_cert(c) = (support_ok, density_ratio_bound W_c, rank_fidelity ρ_c, bias_bound b_c, n_c^real)
```
合法用途格：
```
D0 发现/生成假设      : 永远允许
D1 排序/剪枝          : 允许 ⟺ ρ_c ≥ ρ_min
D2 作为先验           : 允许 ⟺ w_sim ≤ w_max(b_c), 0 < w_sim < 1
D3 认证成功概率        : 允许 ⟺ n_c^real ≥ n_min ∧ support_ok ∧ 共形覆盖成立
D4 安全关键承诺        : 禁止（只认真机 + J_exec，见第 59 轮）
```
**D3 是唯一能把仿真结果写进证据的入口，且必须由真机共形覆盖盖章；D4 永不对仿真开放。**

**定义 156（覆盖分层主动校准 CSAC 与同时共形界）** 真机预算 B_real。单元条件共形分位数
```
q_c = Quantile_{1−α_c}( { ℓ(π;u_i) − R̂_c : i∈真机样本, u_i∈c } )
UCB_c = min(1, R̂_c + q_c + b_c · 1[extrapolation])
```
同时覆盖用权重 {w_c}（Σ w_c = 1）取 α_c = α·w_c，得到 P(∀c: R_c ≤ UCB_c) ≥ 1−α。分配规则（仿真给先验 σ_c^sim、cost_c）：
```
n_c ∝ sqrt( (σ_c^sim)² / cost_c ) · 1[UCB_c 距阈值 δ_req 最近或最不确定]
```
即把真机预算优先投给「最坏单元上界最可能超 δ_req」的单元，而非均匀撒点。若 max_c UCB_c > δ_req ⇒ 加固 / 绕行 / 降级 / 弃权（L2 协商），不得凭仿真成功放行。

**定义 157（双臂接触协同裕度 BCSM）** 接触集 {i}，抓取映射 G(q)，接触力 f_i=(f_n,i, f_t,i)，摩擦锥 ‖f_t,i‖ ≤ μ_i f_n,i，内力子空间 N(G)。协同裕度
```
ρ_syn = min_i ( 1 − ‖f_t,i‖ / (μ_i f_n,i) )
ρ_closure = 力闭合裕度（外部 wrench 到 wrench 空间边界的最小缩放）
ρ_bimanual = min(ρ_syn, ρ_closure) − λ_ext · max(0, ‖f_ext‖ − F_max) / F_max
```
仿真敏感度 s_μ = ∂r/∂μ_f、s_m = ∂r/∂m 用于选择真机标定参数。失败前兆规则：ρ_bimanual < τ_syn ⇒ 触发保守（降速/降刚度/换抓取/请求重规划），并与第 59 轮 EEIS 的 F_max、力跟踪 q99 联动。

**定义 158（UniBot 排行榜完整性审计 UGAB）** 三件事：
1. **held-out 划分**：按物体实例、类别、具身构型、桌面条件分层留出，公开榜只看 public fleet，审计看 held-out fleet；
2. **成对反事实不变性**：同一任务只改 nuisance（纹理/光照/相机位姿/桌面高度/背景），定义翻转率 Φ = P[π 在成对样本上成功性不一致]，要求 Φ ≤ φ_max；
3. **anytime-valid 多重性控制**：对「策略 A 优于基线 B」构造 e-process E_t，拒绝阈值 1/α，允许持续查看排行榜而不虚高；榜单发布同时报告最坏单元 UCB 与覆盖率，而非只报平均分。

**定义 159（泛化闭环算子 SGGC）** 单轮泛化接地闭环：
```
SGGC(π, 𝒞, B_real, δ_req):
 ① UCCM: 由任务规格 + 部署日志构建 𝒞 与单元先验
 ② MIDF: 在 Θ_phys 上找失败见证 W，Realize 三态判定
 ③ SRDC: 若 (c) 需用仿真 ⇒ 检查 T_cert(c)；不合法 ⇒ 降级仿真用途
 ④ CSAC: 分配真机预算、执行 rollout、更新 R̂_c、q_c、δ_sim(c)
 ⑤ 判定: if max_c UCB_c > δ_req:
            return HARDEN(Θ_adv) | FALLBACK(round59 DEGRADE_EXEC) | ABSTAIN/L2
 ⑥ 若加固后仍超界 ⇒ 不得声称该单元「通用」，标记 coverage gap
 ⑦ 输出 J_gen（覆盖图 + 契约 + 见证 + 校准 + 不变性 + 多重性审计）
```

**定义 160（泛化证书 J_gen）** J_gen=(C_cov, {T_cert(c)}, W_verified, calibration_log, R_worst, R_cvar, invariance_audit, multiplicity_audit, coverage_gap_set, version, timestamp)。不可篡改、版本单增；`coverage_gap_set` 显式列出「未被真机覆盖或上界超阈值」的单元——**承认不知道，比假装通用更重要**。

### IP-152 UCCM（能力覆盖流形构建）

```python
@dataclass
class CapabilityCell:
    key: tuple          # (object_class, task, embodiment, perturbation)
    n_real: int
    n_sim: int
    risk_real: float    # R̂_c
    risk_sim: float
    ucb: float
    support: str        # in-support / extrapolation / empty

class CoverageManifold:
    def __init__(self, task_spec, deployment_log):
        self.cells = self._build_cells(task_spec, deployment_log)
        self.mu = self._fit_task_measure(deployment_log)

    def _build_cells(self, spec, log):
        cells = {}
        for rec in log:
            key = discretize(rec.object, rec.task, rec.embodiment, rec.perturbation)
            cells.setdefault(key, CapabilityCell(key, 0, 0, 0.0, 0.0, 1.0, "empty"))
        return cells

    def risk_functional(self, risk="worst", beta=0.1):
        if risk == "worst":
            return max(c.ucb for c in self.cells.values())
        return cvar([c.ucb for c in self.cells.values()], beta)
```

### IP-153 MIDF（可微反事实证伪）

```python
class MuJoCoFalsifier:
    def __init__(self, mjcf, theta_phys, heldout_ratio=0.2):
        self.model = load_mjcf(mjcf)
        self.theta_phys = theta_phys
        self.theta_adv, self.theta_ho = split(self.theta_phys, heldout_ratio)

    def find_witnesses(self, policy, n_steps=200, pop=64):
        # 混合：MJX 梯度上升 + 进化搜索，避开接触不可微/局部极小
        theta = init_population(self.theta_adv, pop)
        for _ in range(n_steps):
            grads = mjx_grad_risk(self.model, policy, theta)      # 直通/平滑接触
            theta = project(theta + lr * grads, self.theta_adv)
            theta = evolve_mutate(theta, self.theta_adv)
        witnesses = []
        for th in topk(theta, k=16):
            rollout = mujoco_rollout(self.model, policy, th)
            if rollout.failed:
                witnesses.append(Witness(th, rollout, classify_failure(rollout)))
        return witnesses

    def realize(self, witness, real_harness):
        if not is_physically_admissible(witness.theta):
            return "inadmissible"
        ok = real_harness.reproduce(witness, n_trials=3)
        if ok.rate >= 0.66:
            return "real-verified"
        return "sim-artifact"          # 记录到 delta_sim，反哺模型修复

    def harden(self, policy, verified_witnesses):
        # 只用真机可复现见证；held-out adversary 评估是否过拟合
        theta_adv = hull([w.theta for w in verified_witnesses])
        policy_h = adversarial_domain_randomize(policy, theta_adv)
        gap = eval_on(policy_h, self.theta_ho) - eval_on(policy, self.theta_ho)
        return policy_h, gap
```

### IP-154 SRDC（仿真-真机偏差标定与迁移契约）

```python
class TransferContract:
    def __init__(self, rho_min=0.8, w_max=0.5):
        self.rho_min, self.w_max = rho_min, w_max
        self.delta = {}   # cell -> (bias, tv, rank, support)

    def calibrate(self, cell, paired_rollouts):
        real = [r.real for r in paired_rollouts]
        sim = [r.sim for r in paired_rollouts]
        bias = conformal_upper(abs(np.mean(real) - np.mean(sim)), paired_rollouts)
        tv = total_variation(failure_modes(real), failure_modes(sim))
        rank = spearman(real, sim)
        support = frac_in_support(paired_rollouts)
        self.delta[cell] = (bias, tv, rank, support)
        return self.delta[cell]

    def allowed_use(self, cell, use, n_real):
        if cell not in self.delta: return use == "D0"
        bias, tv, rank, support = self.delta[cell]
        if use == "D0": return True
        if use == "D1": return rank >= self.rho_min
        if use == "D2": return self.w_max(bias) > 0 and support > 0.5
        if use == "D3": return n_real >= N_MIN and support > 0.95 and self.conformal_ok(cell)
        return False   # D4 / unknown
```

### IP-155 CSAC（覆盖分层主动校准与同时共形）

```python
class CoverageCalibrator:
    def __init__(self, manifold, alpha=0.1):
        self.M, self.alpha = manifold, alpha

    def allocate(self, budget, delta_req):
        cells = list(self.M.cells.values())
        score = []
        for c in cells:
            sigma = sqrt(max(c.risk_real*(1-c.risk_real), 1e-4)) / sqrt(max(c.n_real,1))
            gap = abs(c.ucb - delta_req)
            score.append((gap, sigma, c.key, max(c.n_real,1)))
        w = np.array([s[1] for s in score]) / np.sum([s[1] for s in score])
        n = np.maximum(1, np.floor(budget * w)).astype(int)
        return dict(zip([s[2] for s in score], n))

    def update(self, cell, losses):
        c = self.M.cells[cell]
        c.n_real += len(losses)
        c.risk_real = np.mean(losses)
        # 单元条件共形
        q = conformal_quantile(losses - c.risk_real, 1 - self.alpha_cell(cell))
        c.ucb = min(1.0, c.risk_real + q + self.M.bias(cell))

    def definitive(self, delta_req):
        return max(c.ucb for c in self.M.cells.values()) <= delta_req
```

```python
def bimanual_synergy_margin(contact_forces, friction, G, F_max):
    margins = []
    for f in contact_forces:
        fn, ft = f.normal, norm(f.tangential)
        margins.append(1 - ft / max(friction * fn, 1e-9))
    rho_syn = min(margins) if margins else 1.0
    rho_closure = force_closure_margin(G, contact_forces, friction)
```

```python
class LeaderboardAudit:
    def __init__(self, alpha=0.05):
        self.e = {}; self.alpha = alpha

    def observe(self, pair, delta):
        # pair=(policy, baseline)，delta=held-out 上成对差
        self.e[pair] = (self.e.get(pair, 1.0) *
                        exp(self.alpha * delta))       # e-value 乘法更新

    def reject(self, pair):
        return self.e.get(pair, 1.0) >= 1.0 / self.alpha

    def invariance_flip_rate(self, policy, counterfactual_pairs):
        flips = [policy.run(a).success != policy.run(b).success
                 for a, b in counterfactual_pairs]
        return np.mean(flips)

    def public_vs_heldout_gap(self, policy, public_fleet, heldout_fleet):
        return abs(policy.success(public_fleet) - policy.success(heldout_fleet))
```

```python
    def __init__(self, manifold, alpha=0.1):
        self.M, self.alpha = manifold, alpha

    def allocate(self, budget, delta_req):
        cells = list(self.M.cells.values())
        sigma = np.array([sqrt(max(c.risk_real*(1-c.risk_real),1e-4)) /
                          sqrt(max(c.n_real,1)) for c in cells])
        gap = np.array([abs(c.ucb - delta_req) for c in cells])
        w = (sigma / sigma.sum()) * (gap / (gap.sum()+1e-9))
        w = w / w.sum()
        return {c.key: max(1, int(np.floor(budget*x))) for c, x in zip(cells, w)}

    def update(self, key, losses):
        c = self.M.cells[key]; c.n_real += len(losses)
        c.risk_real = float(np.mean(losses))
        q = conformal_quantile(losses - c.risk_real, 1 - self.alpha_cell(key))
        c.ucb = min(1.0, c.risk_real + q + self.M.bias(key))
        c.support = "in-support" if self.M.in_support(key) else "extrapolation"

    def certified(self, delta_req):
        return self.M.risk_functional("worst") <= delta_req
```

### IP-156 BCSM（双臂协同裕度）

```python
def bimanual_synergy_margin(contacts, mu, G, F_max, lam=1.0):
    rho_syn = min(1 - norm(f.tangential) / max(mu*f.normal, 1e-9) for f in contacts)
    rho_closure = force_closure_margin(G, contacts, mu)
    f_ext = norm(external_wrench(G, contacts))
    return min(rho_syn, rho_closure) - lam * max(0.0, f_ext - F_max)/F_max

def bcs_guard(rho, tau_syn, eeis):
    return eeis.degrade(conservative=True) if rho < tau_syn else None
```

### IP-157 UGAB（排行榜完整性审计）

```python
class LeaderboardAudit:
    def __init__(self, alpha=0.05):
        self.alpha, self.E = alpha, {}

    def observe(self, pair, delta_heldout):
        self.E[pair] = self.E.get(pair, 1.0) * exp(self.alpha * delta_heldout)

    def reject(self, pair):
        return self.E.get(pair, 1.0) >= 1.0/self.alpha

    def flip_rate(self, policy, pairs):
        return np.mean([policy.success(a) != policy.success(b) for a, b in pairs])

    def public_heldout_gap(self, policy, public, heldout):
        return abs(policy.success(public) - policy.success(heldout))
```

### IP-158 SGGC + J_gen（泛化闭环与证书）

```python
def sim_grounded_generalization(pi, manifold, budget, delta_req,
                                falsifier, contract, real_harness):
    witnesses = falsifier.find_witnesses(pi)
    verified = [w for w in witnesses
                if falsifier.realize(w, real_harness) == "real-verified"]
    for c in manifold.cells:
        if not contract.allowed_use(c, "D3", manifold.cells[c].n_real):
            manifold.cells[c].support = "extrapolation"
    calib = CoverageCalibrator(manifold)
    for key, n in calib.allocate(budget, delta_req).items():
        calib.update(key, real_harness.rollout(pi, key, n))
    if manifold.risk_functional("worst") > delta_req:
        pi, overfit_gap = falsifier.harden(pi, verified, real_harness.heldout)
        if manifold.risk_functional("worst") > delta_req:
            action = FALLBACK_OR_ABSTAIN(argmax_ucb(manifold))
            return action, build_J_gen(manifold, contract, verified, overfit_gap)
    return pi, build_J_gen(manifold, contract, verified, 0.0)

def build_J_gen(manifold, contract, verified, overfit_gap):

        W_verified=verified,
        calibration_log=manifold.log,
        R_worst=manifold.risk_functional("worst"),
        R_cvar=manifold.risk_functional("cvar"),
        invariance_audit=manifold.flip_rate,
        multiplicity_audit=manifold.evalues,
        coverage_gap_set=manifold.coverage_gap_set(),
        overfit_gap=overfit_gap,
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| UCCM | O(\|𝒞\|+日志) | O(\|𝒞\|) | 单元可测、最坏单元/CVaR 可审计、coverage gap 显式 |
| MIDF | O(T·pop·rollout) | O(pop·\|θ\|) | 见证三态判定、加固仅 real-verified、held-out 对抗 |
| SRDC | O(\|𝒞\|·n_pair) | O(\|𝒞\|) | D0⊇D1⊇D2 单调、D3 需真机盖章、D4 封闭 |
| CSAC | O(B_real+\|𝒞\|) | O(\|𝒞\|) | 单元共形 + 同时覆盖（Σα_c=α） |
| BCSM | O(\|contact\|) | O(\|contact\|) | 摩擦锥/力闭合裕度 + 失败前兆阈值 |
| UGAB | O(\|Π\|·\|fleet\|) | O(\|Π\|) | anytime-valid 假阳性 ≤α、翻转率/公开-留出差距 |
| SGGC/J_gen | O(单轮闭环) | O(\|𝒞\|+见证) | 版本单增、coverage gap 诚实、不可篡改 |

**正确性定理（Sim-Grounded Generalization Soundness, SGGS）** 在 A22–A55 与 A56–A62（见想法区）下：

1. **覆盖健全性**：P(∀c: R_c(π) ≤ UCB_c) ≥ 1−α−max_c b_c·1[extrapolation]；未覆盖单元进入 `coverage_gap_set`，不得声称通用。
2. **仿真使用健全性**：写入证据的 sim 结果必须满足 D3（真机样本充分 + 支持 + 共形）；D4 只认真机 + J_exec。
3. **反证有效性**：real-verified 见证确证失败；加固后 held-out 对抗集仍有 real-verified 失败 ⇒ 不得宣称该方向鲁棒。
4. **双臂单调性**：ρ_bimanual 下降 ⇒ 保守动作触发概率单调上升；低于 τ_syn 的单元后续失败率显著更高。
5. **排行榜完整性**：任意停时 e-process 假阳性 ≤α；public/held-out 差距超 φ_gap ⇒ 标记评测过拟合。
6. **部署界**：
```
P_safe_gen ≥ 1 − Σ_c ( δ_f + ε_meta(k) + δ_probe + δ_exec + δ_sim(c)·1[extrap]
                        + δ_rank·1[D1] + δ_conformal·1[覆盖失败] + δ_syn·1[ρ<τ_syn] )
             − P(𝒞 划分错误) − P(Θ_phys 未覆盖真机) − P(held-out 泄漏)
```

## 7. 本轮最大风险

**一句话**：最大风险是**把随情境漂移的 sim-real gap 当成一个可标定标量**——在接触丰富、透明/可变形物体、双手强耦合的长尾单元上，MuJoCo 可能既排错序又漏掉真实失败模式；一旦迁移契约被几次真机成功「蒙混过关」，覆盖证书就退化为「仿真覆盖证书」，系统会在排行榜平均分上漂亮、在真机长尾上系统性崩溃。护栏：D3 必须真机盖章、D4 永不放行仿真、coverage_gap 显式公开、held-out 对抗与 held-out 物体双隔离、以最坏单元而非平均分作为放行依据。
