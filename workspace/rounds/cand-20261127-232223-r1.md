**本轮事实对方案的结构性影响**：动作是位姿目标而非力矩，所以经典阻抗控制（直接调力矩）不可用；能做的是**导纳**（把估计到的外力翻译成平衡点位移），而「外力」只能从**指令位姿与实测位姿之差**里挖。动作分块又把闭环带宽压到 1/T_a。两者共同决定了本轮的方向。

## 1. 直觉与动机（三个灵感的碰撞）

**灵感 1（机器人 → 这是一台“只会跟踪位姿”的人形机器人，接触任务的失败模式是刚性）**
直觉：G1 + Dex1 是位置/位姿跟踪接口（F20），底层控制器把目标位姿当“硬约束”去追。自由空间没问题；一旦进入插拔、拉链、开锁、倒药、堆叠这些接触段，目标位姿与真实几何稍有偏差，位置控制器就会把误差变成力：轻则卡住、重则把物体顶飞或把插头压弯。32 任务里至少 6–8 个是接触主导（PlugCharger、PlugInEthernet、DisconnectEthernet、ZipUp、Unlock、PourOutMedicine、PaperCupStacking、StackBowls），而示教数据全是“成功且干净”的（P8），策略没学过“接触后该软下来”。核心反直觉点：**接触任务缺的不是更大的模型，而是“把位置误差翻译成合规力”的那一层；而这一层在接口里没有，必须自己造。**

**灵感 2（阻抗控制 → 没有力传感器，但有“伺服误差”这个免费的力代理）**
直觉：经典阻抗控制要力/力矩传感；本赛题没有（F21）。但接口给了两个关键量：**我们下发的目标位姿 x_cmd，和下一帧观测到的实测位姿 x_meas**。如果底层是刚性位置跟踪，接触阻力会表现为持续跟踪误差 e = x_cmd − x_meas；这正是**扰动观测器（DOB）**的输入。于是可以把“力”用 F̂ ≈ K̂·r + D̂·ṙ 估出来（r 为扣掉自由空间滞后后的残差），再跑一个虚拟质量-弹簧-阻尼的导纳律，把平衡点从 x_d 移到 x_r = x_d + Δx(F̂)。核心反直觉点：**在这场比赛里，力传感器不是必需的；伺服误差就是最便宜、零延迟的六维力代理——前提是先把“自由空间滞后”从误差里减掉。**

**灵感 3（动作分块 → 阻抗的第一性约束不是传感器，而是闭环带宽）**
直觉：上面那套导纳律要每步更新才有用；但接口规定一次返回 T_a 步、执行完才再调用（F22）——chunk 内开环。T_a=16 @15Hz ≈ 1.07s 的反馈周期，对接触段太慢；T_a=1 才有 66ms 的闭环。这直接改写优先级：**先决定 T_a（执行策略），再谈阻抗增益**。T_a 在 metadata 里全局固定，不能按任务切换；只能“内部规划长、外部执行短”（predict-16 / execute-1）或全局取小。核心反直觉点：**动作分块是为吞吐量设计的，接触任务却要为反馈带宽付费；这场比赛的“阻抗控制”首先是一个 chunk-size 选择问题。**

**三者统一**：机器人给出失效模式（刚性位姿跟踪），阻抗控制给出修复原理（用误差估计力、用导纳改平衡点），动作分块给出约束（反馈带宽 = 1/T_a）。本轮结论：**接触任务的胜负手是“执行层”而非“表征层”——SADO 导纳层 + 短执行 chunk，二者都必须塞进单模型服务与 66ms 预算内。**

## 2. 严谨定义（把直觉写成可检验的式子）

设末端位姿 x ∈ R^6（xyz+rpy），策略第 t 步下发 a_t = x_cmd,t，观测到 x_meas,t。

1. **经典阻抗**：M_d(ẍ − ẍ_d) + D_d(ẋ − ẋ_d) + K_d(x − x_d) = F_ext。它规定“运动→力”的因果。
2. **本赛题的可用形式是导纳**（因果反过来）：给定 F_ext，解出 x。因为接口只收位姿目标，策略只能做**外层导纳**，底层控制器是内层阻抗。
3. **伺服误差**：e_t = x_cmd,t−1 − x_meas,t。它混合了自由空间滞后与接触阻力。
4. **残差力代理**：先用示教数据拟合名义自由空间模型 ê_t = g_θ(history)，定义 r_t = e_t − ê_t；再令 F̂_t = K̂ r_t + D̂ ṙ_t。K̂/D̂ 优先在官方 Isaac Lab 仿真（F14）里标定（那里有力标签），真机只要求 F̂ 的**相对序**可靠，不追求绝对牛顿值。
5. **导纳律**：M_d ẍ_r + D_d ẋ_r + K_d(x_r − x_d) = F̂，离散化后输出 x_r 作为动作。约束 ||x_r − x_d|| ≤ δ_max，并加能量槽（energy tank）保证无源性。
6. **接触判定**：c_t = 1[|r_t| > τ_c]，带滞回；τ_c 由自由空间残差的分位数定，目标误报 <5%。

这个定义的可证伪点很明确：若在仿真/真机上 r_t 与真实接触力相关性 <0.5，或 SADO 在 L0 回放中发散，则整条路线降级为“开环合规轨迹整形”（只保留形状，不闭环）。

## 3. 对第 2 轮痛点的增量修订

- P4（无触觉）**升级**：除 I3 关键点视觉伺服外，新增第二条路径——伺服误差 DOB 提供“力代理”，把“无触觉”从“无法感知接触”降级为“接触信息需标定”。
- P5（时间压力）**新增张力**：短 chunk 提升反馈带宽但增加推理调用次数；T_a=1 时 15 次/秒，必须 p99 < 66ms。时间预算从“单次推理”变成“单次推理 × 调用频率”。
- P8（示教质量）补充：示教全是刚性成功轨迹，缺少“接触后软化”的负样本；需要阻抗失配合成示教（I5 v3）。
- **新增 P9（分块-带宽矛盾）**：动作分块是为吞吐量设计的，接触任务需要短执行；metadata 的 T_a 全局固定，无法按任务切换。
- **新增 P10（底层控制器未知）**：我们不知道内环是纯位置、带前馈、还是已有柔顺/限力；SADO 的 K̂/D̂ 必须从数据与仿真中辨识，不能假设。
- **新增 P11（动作边界自持）**：本地 stub 不校验位姿边界（F23），生产评测可能有额外检查；所有导纳输出必须自钳位、限速、平滑。

## 4. 研究问题（本轮立项 Q9–Q11，Q1–Q8 保留）

- **Q9（无传感器接触估计）**：伺服误差残差 r_t 能否在 15Hz 下可靠估计接触状态/力序？自由空间滞后与接触阻力如何解耦？接触检测的延迟与误报率是多少？
- **Q10（分块 vs 反馈带宽）**：在 66ms 单步预算下，T_a ∈ {1,2,4,8,16} 对接触任务成功率、步骤分、p99 的影响？“内部规划 16、外部执行 1”能否兼得长时程与短反馈？
- **Q11（阻抗感知增广）**：在训练中注入接触动力学变化（质量/摩擦/柔顺/间隙）与“刚性失败→柔顺修正”示教，能否提升接触任务零样本成功率而不伤自由空间？剂量-响应如何？

## 5. 设计原则（新增 PR6/PR7/PR8，其余保留）

- **PR6 接触带宽守恒律**：任何“阻抗/柔顺”方案必须同时声明 T_a 与反馈周期；T_a 越大，允许的导纳增益越小。不能只谈增益不谈带宽。
- **PR7 力代理只信残差**：F̂ 只能来自扣掉名义自由空间模型后的残差；未标定的原始跟踪误差不得直接当力用。
- **PR8 安全边界自持**：位姿钳位、速度限幅、能量槽、平滑滤波由策略自己保证；不依赖评测端裁剪（F23）。
- PR1–PR5 保留（第 1/2 轮 §4）。

## 7. 本轮最大风险

**一句话**：SADO 的整条路线建立在“底层是近似刚性的位置跟踪器、且跟踪残差可辨识为接触力”这一假设上；若内环本身已有柔顺/限力，或残差主要来自未建模的延迟与动力学，那么力代理就是噪声，导纳层会变成正反馈并把接触任务推得更糟——这是清单里第一个必须先用 L0 回放 + 仿真标定证伪、再上真机的点。

## 0. 创新点清单（每点：动机 / 与现有方案差异 / 技术可行性 / 所需资源 / 落地步骤 / 风险）

### I1 v3 考纲校准六轴增广引擎 ★★★★★
- **动机**：（v1.0/v2 保留）计分的 320 次真机评测每次都在 5 轴上偏离训练分布（P2/F2）；本轮补第 6 轴——**接触动力学**（P4）。
- **本轮深化（机器人 × 阻抗控制）**：新增第 6 轴“接触动力学”，含 4 个子轴：物体质量/惯量、表面摩擦、接触柔顺（软/硬）、装配间隙/台面高度。前 3 个在真实示教里无法改，**用官方 Isaac Lab 仿真（F14）生成变体**；间隙/台面高度可用图像空间 + 位姿重放做小范围增广。剂量 3 档（标称/考纲边缘/考纲外），先做 L0 剂量-响应，找饱和点。
- **与现有方案差异**：多数队伍只做视觉增广（背景/光照/位置），不碰接触物理；本点把“刚性成功示教”扩成“不同接触刚度下的成功示教”，直接服务 I10/I11 的接触段。
- **技术可行性**：高（视觉轴）/ 中（物理轴，依赖 sim 与真机的动作-状态对齐）。仿真增广只用于训练，不改变推理路径，单模型边界无争议。
- **所需资源**：1×24GB GPU（视觉增广）；Isaac Lab 仿真 1×A100 周（物理变体）。
- **落地步骤**：①第 6 轴考纲卡（每任务接触类型/材质/间隙范围）；②sim 变体生成 + 与真机示教的域对齐抽检；③剂量-响应 L0；④与 I10 联合训练（接触段加权）；⑤轴间交互（接触动力学 × 背景）2 档析因。
- **风险**：sim 接触参数与真机不一致（缓解：只用 sim 做**相对**增广，不做绝对物理标定；真机抽测 3 个接触任务校准）；物理增广把动作分布拉偏（缓解：L0 监控“不可行动作占比”，>5% 降级为仅视觉轴）。

### I2 v2 数据引擎 2.0：110 语料孪生迁移 + 加权共训 ★★★★★（维持，微调）
- **动机**：单模型平均分被最弱任务支配（P1）；示教语料与质量双重浪费（P8）。
- **本轮微调**：在 v1.1 的族级权重上，给**接触段占比高**的孪生任务（Connect_The_Network_Port、Open_Bottle_Cap、Pour_From_Bottle、Unzip）再乘 1.2–1.5 的接触段采样权重；因为 I10 需要“接触时的动作分布”，这些段的边际价值高于自由空间段。
- **落地与风险**：同 v1.1（孪生表 → loader patch → 质量加权 → 族级 L0 消融）。新增风险：接触段加权可能放大孪生任务的力学差异（如 ZipUp 与 Unzip 的受力方向相反），仍由家族级 L0 先验止损。

### I3 v2 混合位置/阻抗接触回退 ★★★★（升级）
- **动机**：v1.0/v1.1 的关键点视觉伺服只解决“几何对准”，不解决“接触后过硬”；本轮把它升级为两段式。
- **本轮深化**：接近段用关键点视觉伺服（位置控制，快而准）；接触段切到 SADO（I10，导纳控制，软而稳）。切换判据 = 残差 r_t 超阈 + 关键点距离 < δ；带滞回，避免抖动。关键点仍用开放词汇检测零训练起步。
- **与现有方案差异**：纯端到端策略在接触段容易“顶死”；纯几何伺服没有力感知。本点把“几何”和“柔顺”拆成两个可独立验证的组件，但仍在同一 PolicyService 内。
- **降级预案 I3'**：若组委会裁定“混合推理路径”违反单模型边界，改为**训练时辅助监督**——关键点/接触残差作辅助标签训练接触段注意力，推理纯端到端；SADO 若也被判违规，则蒸馏进动作头（见 I10 降级）。
- **风险**：切换抖动；缓解：滞回 + 最短驻留时间 + L0 回放验证切换次数 <3 次/episode。

### I4 v2 人手干预感知门控 + 顺从让位 ★★★★（升级）
- **动机**：v1.0/v1.1 的干预处理是“停持→重估→续做”（PR3），安全但不自然；阻抗控制给了更好的答案——**顺从让位**。
- **本轮深化**：手部检测 + `obs_delta_indices` 历史栈判别干预（<50ms）；检测到人手推力后，切到低刚度/低阻尼（K_d↓、D_d↓），沿残差 r_t 的方向让位（而不是硬停），保持末端在人力方向上的“可推动”；人手离开后，用关键点/进度头重估目标并重接近。若推力来自底座（`action.pivot` 可用），同步降低 pivot 刚度。
- **与现有方案差异**：停持会让任务中断、可能丢分；顺从让位既满足安全（PR3），又保留任务连续性。
- **风险**：让位方向误判导致远离目标；缓解：只在残差持续 >τ 且手部检测置信 >0.7 时让位，限幅 δ_yield，退出后强制重接近。

### I5 v3 非标称示教合成 + 得分点对齐恢复 ★★★★（升级）
- **动机**：步骤分 = 官方得分点制（F17）；超时仍按进度计步骤分（F3）；数据集全成功、无失败示教（P8）。
- **本轮深化（阻抗控制核心产出）**：在 v1.1 的“扰动重放/跨段缝合/世界模型续写”之上，新增**阻抗失配恢复示教**：
  1. 取成功 eps，把接触段的“刚性跟踪”重放成“柔顺跟踪”（用 SADO 的导纳律重新生成动作），得到同一任务的“软版本”；
  2. 构造“刚性失败→柔顺修正”配对：刚性版本在接触点卡住/顶飞，柔顺版本完成；用官方得分点做里程碑，只保留“下一得分点达成”的修正段；
  3. 把配对段作为偏好数据（preference）或辅助监督，训练策略在接触段“学会变软”。
- **与现有方案差异**：v1.0 手工恢复原语、v1.1 合成恢复示教，都没有显式教“刚度”；v3 把“刚度/柔顺”作为可学习的隐变量。
- **技术可行性**：中-高。阻抗失配重放需要内环模型（与 I10 共用系统辨识）；里程碑检测器同 v1.1。

- **落地步骤**：①3 个接触任务试点（PlugCharger、ZipUp、PourOutMedicine）；②刚性/柔顺配对生成；③得分点过滤；④LoRA 增量训练；⑤单任务通道 A/B（接触成功率、步骤分、峰值力代理）。
- **风险**：合成的“柔顺”与真机内环不匹配（缓解：只用相对柔顺、真机标定 3 档；L0 先验证）；偏好数据噪声（缓解：得分点门禁 + 5% 人工抽检）。

### I6 v2 确定性低延迟部署服务 ★★★★（升级）

- **风险**：T_a=1 时网络往返 + 推理超 66ms（缓解：双频推理、CUDA Graph、obs 预取；若仍超，回退 T_a=2–4）；双频缓存导致视觉滞后（缓解：关键帧刷新 + 腕部相机高频）。

### I10 SADO：伺服误差扰动观测的无传感器导纳层（新） ★★★★★
- **动机**：接触任务（6–8 个）失败的主因是刚性位姿跟踪（P4）；接口无力/力矩通道（F20/F21），但有“指令位姿 vs 实测位姿”的伺服误差。
- **与现有方案差异**：
  - 经典阻抗控制需要力传感器；纯 VLA 只输出位姿，不会“变软”；
  - 本点用**扰动观测器**从伺服误差里估力，用**导纳律**改平衡点，零额外传感器、零在线学习、推理期确定性计算；
  - 与 I3 分工：I3 给几何（关键点伺服），I10 给柔顺（导纳）；与 I5 分工：I5 造“变软”的训练数据，I10 在推理时执行“变软”。
- **技术可行性**：中-高。
  - **系统辨识**：32k 示教含 action（目标位姿）与 state（实测位姿）对，可拟合自由空间名义模型 g_θ；接触段残差用 Isaac Lab 标定 K̂/D̂（仿真有力标签）。
  - **计算**：6 维导纳律 + 一阶滤波 <0.1ms，完全在 66ms 预算内。
  - **无源性**：能量槽 + 增益上限，保证 15Hz 离散稳定性。
- **所需资源**：系统辨识 1 GPU 日；sim 标定 1×A100 周；工程 1 人周。
- **落地步骤**：①从示教拟合 g_θ（动作-状态闭环响应）；②Isaac Lab 标定 K̂/D̂ 与残差-力映射；③实现 SADO（导纳 + 能量槽 + 钳位/限速）；④L0 虚拟力回放（稳定性 + 不发散）；⑤L1 与 I3/T_a 析因；⑥L2 6 个接触任务 A/B。
- **风险**：
  - 内环本身已有柔顺/限力 → 残差不再线性反映接触；缓解：先做内环辨识实验（阶跃/正弦位姿指令），若辨识不出则降级为开环合规轨迹整形；
  - 自由空间滞后被误判为接触 → 误软化、任务变慢；缓解：g_θ 扣掉名义滞后 + 滞回 + 最短驻留；
  - 导纳正反馈导致振荡；缓解：能量槽 + 增益上限 + 低通 + L0 扫频；
  - 单模型边界：SADO 是控制器层，可能被判“多模块”；缓解：**SADO 作教师蒸馏进动作头**（训练时用 SADO 生成目标动作，推理时动作头直接输出合规动作），或向组委会书面确认控制层合规。

### I11 CARH：接触感知执行分块（新） ★★★★
- **动机**：动作分块把闭环带宽压到 1/T_a（F22）；接触任务需要短反馈，自由空间需要长 chunk 省算力。
- **与现有方案差异**：默认方案用固定 T_a=8–16 开环执行；本点系统研究 T_a，并用“内部规划 16、外部执行 1–2”的解耦，把长时程先验与短反馈结合起来。
- **技术可行性**：高。`action_chunk_size` 是 metadata 字段，提交前定档；内部规划长度不受限。双频推理（I6 v2）保证 T_a=1 的算力。
- **所需资源**：延迟剖析 + L0 回放 1 人周；无需新硬件。
- **落地步骤**：①L0 在留出接触 eps 上扫 T_a ∈ {1,2,4,8,16}，画“成功率代理–步骤分代理–p99”Pareto；②实现 predict-16/execute-T_a；③双频推理；④L1 与 SADO 析因（T_a × SADO on/off）；⑤L2 top 2 档。
- **风险**：T_a=1 推理太慢/太贵（缓解：双频 + 蒸馏小动作头；仍超则 T_a=2）；短 chunk 让动作抖动（缓解：动作头输出平滑 + 重叠执行/时序集成）；步骤分因慢而下降（缓解：自由空间用长 chunk，只在接触段用短 chunk——但 T_a 全局固定，需用“接触段在 chunk 内软化”折中）。

### 1.1 SADO：伺服误差 DOB + 导纳（I10）

```python
class SADO:
    """Sensorless Admittance via Disturbance Observer.
    输入：期望位姿 x_d、上一步指令 x_cmd_prev、当前实测 x_meas、历史。
    输出：合规平衡点 x_r（直接作为 action 的 ee 位姿目标）。"""
    def __init__(self, nominal, K_hat, D_hat, Md, Dd, Kd, dt=1/15,
                 delta_max=0.02, F_max=40.0):
        self.g = nominal          # 自由空间名义模型 g_theta(history)
        self.K_hat, self.D_hat = K_hat, D_hat
        self.Md, self.Dd, self.Kd = Md, Dd, Kd
        self.dt, self.delta_max, self.F_max = dt, delta_max, F_max
        self.r_prev = np.zeros(6)
        self.v_r = np.zeros(6)
        self.tank = 1.0           # 能量槽 [0,1]

    def step(self, x_d, x_cmd_prev, x_meas, history):
        e = x_cmd_prev - x_meas                      # 6D 伺服误差
        e_hat = self.g.predict(history)              # 名义自由空间滞后
        r = e - e_hat                                # 接触残差
        r_dot = (r - self.r_prev) / self.dt
        F_hat = self.K_hat @ r + self.D_hat @ r_dot  # 力代理
        F_hat = np.clip(F_hat, -self.F_max, self.F_max)

        # 导纳：Md*x¨ + Dd*x˙ + Kd*(x - x_d) = F_hat（半隐式欧拉）
        a_r = (F_hat - self.Dd @ self.v_r - self.Kd @ (self._x_r - x_d)) / self.Md
        self.v_r = self.v_r + a_r * self.dt
        self._x_r = self._x_r + self.v_r * self.dt

        # 安全：位移钳位 + 速度限幅 + 能量槽（无源性）
        dx = np.clip(self._x_r - x_d, -self.delta_max, self.delta_max)
        x_r = x_d + dx
        self.tank = max(0.0, min(1.0, self.tank - abs(F_hat @ self.v_r) * self.dt))
        if self.tank < 0.05:                          # 能量不足 → 退化为纯位置
            x_r, self.v_r = x_d, np.zeros(6)
        self.r_prev = r
        return x_r, F_hat, r
```

### 1.2 双频 CARH：内部规划 16、外部执行 T_a（I11）

```python
class DualRatePolicy:
    """metadata.action_chunk_size = T_a (提交前定档，建议 1–2 接触档)。"""
    def __init__(self, vlm, action_head, T_a, vlm_period=4):
        self.vlm, self.head, self.T_a = vlm, action_head, T_a
        self.vlm_period = vlm_period
        self._feat = None

    def get_action(self, obs):
        if self._step % self.vlm_period == 0 or self._feat is None:
            self._feat = self.vlm.encode(obs)          # 低频视觉/语言
        plan = self.head.predict(self._feat, obs, horizon=16)  # 高频动作头
        # 接触段：plan 的后半段已由 SADO/合规先验软化；执行前 T_a 步
        return plan[:self.T_a]
```
