# 第 1 轮（灵感循环第 1 轮；本轮灵感：「排行榜」×「抗干扰」）

> 承接：R73 的 MODGAUGE 给出了「计量契约代数」，上一版 **LeanGauge** 在其上加了 D-Box（需求盲区检测）→ I-Box（可预测自助下注）→ BP-Cal（少样本局部校准）→ 4CV 闭环。但 LeanGauge 留下两个未解问题：
> **(i)** D-Box 输出的只是一个**盲区集合**，不是**优先级**。当验证预算 B_iter 远小于盲区数量时，「先修哪一个、先信哪一个」缺乏原则，4CV 只能用 `for spot in blind_spots: break` 这种近似任取的策略。
> **(ii)** 上一轮自己识别的头号风险正是「盲区注入攻击」：攻击者进入模型训练分布外、又不触发下注阈值，让 I-Box 误以为「需求已覆盖」。这本质上是一个「谁值得被审计」的**排序被操纵**问题。
>
> 本轮灵感「排行榜」×「抗干扰」是同一枚硬币的两面：**排行榜**回答「先修谁、先信谁」；而任何排行榜一旦成为资源分配依据，就必然成为被刷榜的目标——这正是**抗干扰**要守住的东西。

## 0. 直觉与动机

**灵感 1（排行榜 → 计量排行榜 MetroBoard：把隐式优先级显式化、可认证化）**
直觉：人类科研中排行榜（Leaderboard）之所以有力量，是因为它把「多维、含噪、彼此不可比」的证据压成一个全序，从而让有限资源（算力 / 预算 / 注意力）可以集中投放。LeanGauge 的 D-Box 其实已经攒下了这些证据（`n_verify`、`σ_conf`、`cost_risk`），却只做了 `n_verify ≤ τ_n` 的阈值筛选，没做排序。

于是引入 **计量排行榜 MetroBoard**：对每个候选对象（盲区子空间 s，或待热替换模块 m）计算一个**认证分数**，并给出**排名区间**，而不是点估计名次。关键不是「排个序」，而是**排到可认证**：既然 R73 要求每个量都携带不确定度、并沿契约传播，那么「名次」也必须携带不确定度。MetroBoard 的输出是一个**认证偏序**：只有统计上可分离的对象之间才给出确定的先后；不可分离的给出「并列区间」。这样，排名本身也成了一个受契约约束的计量对象，而不是拍脑袋的启发式。

**灵感 2（抗干扰 → 双通道干扰与反作用回执的「自证」）**
直觉：排行榜一出现，理性行为者就开始「刷榜」（Goodhart 定律）。在 RAS 计量场景里，干扰有两条完全不同的通道：
- **测量干扰（data interference）**：离群样本、传感器漂移、对抗扰动污染分数——这是鲁棒统计的经典战场（trimmed mean、median-of-means、Huber M-estimator）。
- **策略干扰（strategic interference）**：模块/子系统**少报**自己的不确定度（σ_decl ↓），从而在「越安全名次越高」的榜上刷分——这正是上一轮「盲区注入」在排行榜语境下的化身。

这里 R73 有一个被低估的资产：**反作用通道完备性（reaction-channel completeness）**。契约要求声明量 σ_decl 与真实可观测的反作用量 σ_obs 通过 χ_R 通道绑定，那么「少报」就不是免费的——它会让 λ = σ_pred − σ_decl 异常增大，触发 LeanGauge 的自助下注；随后真实观测 σ_obs 会揭穿它。于是**策略干扰是自证式的（self-revealing）**：想刷榜，就必须先制造一条会被审计抓到的反作用残差。这是本方案与通用「鲁棒排行榜」最本质的区别——抗干扰不靠外部信誉或历史先验，而靠物理/计量的**内部一致性**。

**灵感 3（合成：预算受限下的抗干扰排行榜闭环）**
直觉：把 MetroBoard 插到 LeanGauge 的 D-Box 与 I-Box 之间：
```
D-Box 产出盲区集合 → MetroBoard 认证排序 → Board-Alloc 按名次分配 B_iter → I-Box 定向采样
      ↑                                                        │
      └────────── I-Sentinel 以 λ / σ_obs 反作用回执惩罚刷榜 ←──┘
```
排行榜既是**预算分配器**，也是**攻击面**；抗干扰机制既保护排序，又反过来给 I-Box 提供「该重点检查谁」的线索——干扰检测与盲区检测在此合流。核心命题：**把「盲区集合」升级为「带稳定性证书的审计优先级」，并让刷榜行为在计量契约内部自我暴露**。

## 1. 形式化定义（增量：定义 409–421）

**定义 409（证据样本族与污染模型）** 对候选对象 o（盲区 s 或模块 m），其证据样本族 E_o = {e_j}_{j=1..N}，每个样本 e_j = (σ_obs^{(j)}, σ_decl^{(j)}, u^{(j)}, cost^{(j)})。采用 ε-污染模型：至多 ⌊εN⌋ 个样本来自任意（含对抗）分布，其余来自名义分布 P_o。

**定义 410（认证分数 R-Score）** 取样本效用 ψ(e) = cost(e) · width(σ_conf(e))（风险越高、置信区间越宽 → 越该被审计）。定义
```
s_R(o) = ρ_ε( {ψ(e_j)} ) − λ_pen · [ g(o) ]_+
g(o)   = max_j (σ_obs^{(j)} − σ_decl^{(j)})_+ / max(σ_decl^{(j)}, ε₀)
```
其中 ρ_ε 为 ε-截尾均值（或 median-of-means）鲁棒聚合，g(o) 为「观测劣于声明」的相对残差（刷榜指纹），λ_pen 为证书惩罚系数。排名方向：**分数越高，审计优先级越高**。

**定义 411（计量排行榜 MetroBoard）**
```
MB = { (o, s_R(o), [s_lo(o), s_hi(o)], [r_lo(o), r_hi(o)], cert(o)) }
```
分别记录认证分数点估计、分数区间、名次区间与稳定性证书。

**定义 412（认证偏序与名次区间）** 对象 o 严格优于 o′ 当且仅当 `s_lo(o) > s_hi(o′)`，记 o ≻_cert o′；否则判为「不可分离」。认证偏序 ≻_cert* 取传递闭包。名次区间定义为
```
r_lo(o) = 1 + #{o′ : o′ ≻_cert o}
r_hi(o) = K − #{o′ : o ≻_cert o′}
```
名次区间越窄，榜单越「敢用」。

**定义 413（两类排名干扰）** 干扰预算为二元组 (ε, δ_g)：
- **测量干扰**：ε-污染（定义 409）；
- **策略干扰**：存在对象压低声明 δ_g，即 σ_decl ← σ_decl − δ_g 而 σ_obs 不变，使 g(o) ≥ δ_g/σ_decl。

**定义 414（排名稳定性证书 Rank-Stability Certificate）** 对目标 top-k 集合 T_k，MetroBoard 为 (ε, δ_g, η)-稳定，当且仅当对任意容许干扰，(真 top-k 与认证 top-k 不一致) 的概率 ≤ η。可操作判据：若第 k 名与第 k+1 名的认证分数间隙 ≥ 2·rad(ε, δ_g)，则稳定，其中 rad 为鲁棒分数半径。

**定义 415（排名后悔 Rank Regret）** 以排行榜顺序 π 分配预算 B 与以 oracle 顺序 π* 分配的差距：
```
Regret(π) = Σ_{i=1..⌊B⌋} ( risk(π*(i)) − risk(π(i)) )_+
```
目标是在认证半径内给出 Regret 的上界。

**定义 416（干扰哨兵 I-Sentinel）** 对对象 o 维护反作用回执 r(o) = σ_obs − σ_decl。若鲁棒聚合 mean_robust(r(o)) > ζ，则置 FLAG：
1. 以 λ_pen·g(o) 下调其分数（惩罚刷榜）；
2. 向 Board-Alloc 追加定向审计份额（把「可疑」转成「优先检查」）。

**定义 417（排行榜驱动预算分配 Board-Alloc）** 给定认证顺序 π 与预算 B_iter：
```
b_i ∝ s_R(o_i) / cost(o_i),   Σ b_i ≤ B_iter,
且预留比例 β·B_iter 给 I-Sentinel 标记对象（预算内的定向审计）。
```
这是一个风险加权的鲁棒背包/预算分配问题。

**定义 418（MetroBoard 总览）** MetroBoard = (R-Score, Rank-Cert, I-Sentinel, Board-Alloc)。集成系统记为 **LeanGauge+ = (MODGAUGE, D-Box, MetroBoard, I-Box, BP-Cal, 4CV)**。

**定义 419（排行榜契约 RB-Contract）** RB-Contract = (k, η, ε, δ_g, τ_board, refresh_condition)：
- k：目标 top-k 审计集合；
- η：允许的排序翻转率；
- (ε, δ_g)：假定的干扰预算上界；
- τ_board：榜单刷新最长时延；
- refresh_condition：何时必须重算（新盲区出现 / 证据数翻倍 / FLAG 触发）。

**定义 420（不可认证排序与安全退化）** 若不存在稳定 top-k（分数区间全部交叠或证书失败），MetroBoard 必须显式输出「不可认证排序」，并回退到保守策略（均匀审计或 R68 式降级），**严禁静默使用点估计名次**。这条与 R73 的严格退化链对齐。

**定义 421（反作用回执 Reaction Receipt）** 每次审计记录不可变四元组 (σ_pred, σ_decl, σ_obs, verdict)，既作为 R-Score 的证据，又作为刷榜的见证（witness）。回执是 I-Sentinel 与引理 48 的物理依据。

## 2. 关键算法骨架

```python
# IP-315 R-Score：鲁棒认证分数
class RScore:
    def __init__(self, eps=0.1, lam_pen=1.0, eps0=1e-9):
        self.eps, self.lam_pen, self.eps0 = eps, lam_pen, eps0

    def _robust_mean(self, xs):
        xs = sorted(xs)
        k = int(len(xs) * self.eps)
        core = xs[k:len(xs) - k] if k else xs
        return sum(core) / max(len(core), 1)

    def score(self, evidence):
        psi = [e.cost * (e.sigma_hi - e.sigma_lo) for e in evidence]
        base = self._robust_mean(psi)
        g = max(((e.sigma_obs - e.sigma_decl) / max(e.sigma_decl, self.eps0))
                for e in evidence)
        return base - self.lam_pen * max(0.0, g)


# IP-316 Rank-Cert：分数区间与名次区间
class RankCert:
    def __init__(self, delta=0.05):
        self.delta = delta

    def score_interval(self, evidence, rscore):
        # 逐折自助法给出分数区间（对污染稳健）
        vals = []
        for _ in range(self.B):
            boot = resample(evidence)
            vals.append(rscore.score(boot))
        lo, hi = quantile(vals, [self.delta / 2, 1 - self.delta / 2])
        return lo, hi

    def rank_intervals(self, objects):
        obj = sorted(objects, key=lambda o: -o.s_lo)   # 悲观序
        for o in objects:
            o.r_lo = 1 + sum(1 for p in objects if p.s_lo > o.s_hi)
            o.r_hi = len(objects) - sum(1 for p in objects if o.s_lo > p.s_hi)
        return objects

    def certified_topk(self, objects, k, eta):
        gap = objects[k - 1].s_lo - objects[k].s_hi
        rad = max(o.s_hi - o.s_lo for o in objects) / 2
        return gap >= 2 * rad          # 定义 414 的可操作判据


# IP-317 I-Sentinel：双通道干扰哨兵
class InterferenceSentinel:
    def __init__(self, zeta=0.2, lam_pen=1.0):
        self.zeta, self.lam_pen = zeta, lam_pen

    def inspect(self, receipts_o):
        r = [rec.sigma_obs - rec.sigma_decl for rec in receipts_o]
        if robust_mean(r) > self.zeta:
            return FLAG, self.lam_pen * robust_mean(r)   # 惩罚项
        return OK, 0.0


# IP-318 Board-Alloc：预算分配 + 定向审计
class BoardAlloc:
    def __init__(self, beta=0.3):
        self.beta = beta

    def allocate(self, board, budget):
        alloc, audit = {}, {}
        normal = [(o, o.s_R, o.cost) for o in board if not o.flagged]
        flagged = [(o, o.s_R, o.cost) for o in board if o.flagged]
        for group, share in ((normal, 1 - self.beta), (flagged, self.beta)):
            targets = {o: s / c for (o, s, c) in group}
            total = sum(targets.values()) or 1.0
            for o, w in targets.items():
                alloc[o] = share * budget * w / total
        return alloc


# IP-319 MetroBoard 主闭环（嵌入 LeanGauge）
def MetroBoard_round(M, budget):
    spots = DBox.detect_blind_spot()
    board = build_board(spots, M.receipts)
    for o in board:
        o.s_R, (o.s_lo, o.s_hi) = rscore.score(o.evidence), rankcert.score_interval(o.evidence, rscore)
        o.flagged, pen = sentinel.inspect(o.receipts)
        o.s_R -= pen
    rankcert.rank_intervals(board)
    if not rankcert.certified_topk(board, k=RBC.k, eta=RBC.eta):
        return DEGRADE(M, reason="不可认证排序")     # 定义 420
    alloc = BoardAlloc().allocate(board, budget)
    for o, b in sorted(alloc.items(), key=lambda kv: -kv[0].s_R):
        IBox.execute_validation(o, budget=b)         # 定向采样，而非任取
    return MODGAUGE_round(M, ...)
```

## 3. 推导

**引理 46（污染下的分数集中性）** 设名义样本次高斯、污染比例 ≤ ε，则取 m 个大小为 ⌈N/m⌉ 的块做 median-of-mean，存在常数 C 使
```
P( |ρ_ε − E[ψ]| ≥ C·(σ·sqrt(log(1/δ)/N) + ε·B_ψ) ) ≤ δ。
```
系：区间宽度随 N 以 O(1/√N) 收缩，但**被 ε·B_ψ 的常数地板卡住**——污染不会随样本增多而消失，只会被压到地板。这直接决定排名区间宽度的下限。

**引理 47（排名稳定性 ⇔ 名次间隙条件）** 认证 top-k 稳定 ⇔ 第 k 与第 k+1 名的分数间隙 ≥ 2·rad(ε, δ_g)。充分性由定义 414 直接得到；必要性来自构造：当间隙 < 2·rad 时，总存在一个容许的策略干扰把两者翻转（把两对象分数同时推向区间端点）。故证书是**紧的**，不是充分不必要。

**引理 48（策略干扰自证，非盈利）** 若对象把 σ_decl 压低 δ_g，则要么 (a) λ = σ_pred − σ_decl 越过下注阈值 γ，触发 I-Box 定向审计；要么 (b) 反作用残差 σ_obs − σ_decl 越过 ζ，触发 I-Sentinel。两种情况下 R-Score 的惩罚 λ_pen·g(o) 满足
```
λ_pen · δ_g / σ_decl ≥ Δscore_from_underdeclaration
```
当 λ_pen ≥ ∂(apparent risk)/∂σ_decl 时成立。于是「刷榜的净收益 ≤ 0」。**这是把抗干扰扎根在 R73 反作用通道上、而非外加信誉系统的关键一步。**

**引理 49（预算分配的排名后悔上界）** 在证书稳定时，风险加权分配满足
```
Regret(π) ≤ B · Δ_max · (width / gap)_+ ，
```
其中 Δ_max 为单对象风险上界。证书失败时回退均匀审计，Regret ≤ B·Δ_max（最坏但有界），满足定义 420 的严格退化。

**引理 50（与 LeanGauge 4CV 的组合单调性）** MetroBoard 只改变「审计顺序与预算分配」，不改变任何契约的安全判定：其输入 (σ_pred, σ_decl, σ_obs) 全部已在 MODGAUGE 的计量契约内被界定。因此 R73 五不变式（契约完整性、组合单调性、反作用通道完备、主张绑定、严格退化链）保持；唯一新增失败模式是「预算饥饿」，由定义 420 显式降级兜底。

## 4. 复杂度分析

| 组件 | 域 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|---|
| R-Score 聚合 | 计量域 1Hz | O(N log N) < 2ms | O(N) | 定义 410、引理 46 |
| Rank-Cert 区间 | 计量域 0.2Hz | O(B·N log N + K log K) < 20ms | O(B·N) | 定义 412/414、引理 47 |
| I-Sentinel 检查 | 计量域 50Hz | O(1)/回执 < 0.1ms | O(#receipts) | 定义 416、引理 48 |
| Board-Alloc | 计量域 0.2Hz | O(K log K) < 1ms | O(K) | 定义 417、引理 49 |
| MetroBoard 闭环 | 计量域（事件触发） | O(K·B) < 25ms | O(K·B) | 定义 418、引理 50 |

**总增开销**：相对 MODGAUGE-RAS 的 3.5ms/周期，榜单刷新是低频事件（新盲区出现时才重算），平均 < 0.5ms/周期，峰值 < 25ms，且与 LeanGauge 的稀疏事件预算相容。

## 6. 本轮最大风险

**一句话**：MetroBoard 的稳定性证书以「干扰有界 (ε, δ_g) + 名义证据可交换」为前提；一旦攻击者**自适应地针对证书本身**做无界操纵（先探测再分批注入、或利用证书的紧性做边界翻转），或证据稀缺使名次区间宽到「可认证但不可用」，排行榜就会退化为「认证了不可排序」的合规摆设，而现场操作者仍会默认点估计名次行动——证书沦为例行表演。

次级风险与缓解：
1. **自适应无界干扰** → 采用**随机化审计种子** + 证书中的 (ε, δ_g) 在线估计；若残差分布尾部变厚则收紧并降级（定义 420）。
2. **区间过宽导致不可用** → Board-Alloc 在不可分离时执行「成对比较采样」以主动拉开间隙，而非被动等待。
3. **λ_pen 选择不当** → 由引理 48 反解 λ_pen 下界，并在 E435 中做攻击者最优反应校验。
4. **排行榜诱发局部过拟合（刷榜的良性版本）** → 定期重采样证据、加入未上榜对象的「探索配额」。
5. **I-Sentinel 误报拖垮预算** → ζ 按任务风险动态调节，并对 FLAG 设冷却期。
6. **榜单与热替换耦合死锁** → refresh_condition 设强制超时，超时按 R68 降级。
7. **数值/自助法在少样本下失真** → 少样本时改用精确有限总体界（Hoeffding/DKW），不用渐近自助法。

# 第 1 轮产物 · 创新点清单 v2：**MetroBoard**（Metrology Leaderboard with Interference-Resistant Ranking for RAS）

> 承接：R73 的 MODGAUGE 提供「计量契约代数」，上一版 LeanGauge 增加了「需求盲区发现 + 迭代修复」。但 LeanGauge 的 D-Box 只输出**集合**、不输出**优先级**，且其头号风险「盲区注入」本质上是**审计排序被操纵**。MetroBoard 把「盲区集合」升级为「带稳定性证书的审计优先级」，并让刷榜在计量契约内部自我暴露。
>
> IP 编号：IP-315~319（共 5 个）。理论姿态：**在 LeanGauge 与 MODGAUGE 之间插入一个可认证的排序/预算层**——不改变 R73 的五不变式，只新增一个受契约约束的「排名」计量对象，并以严格退化兜底「不可认证排序」。

## 0. 核心 IP 设计

| 编号 | 名称 | 类型 | 关键改进（相对 LeanGauge / MODGAUGE） |
|---|---|---|---|
| IP-315 | R-Score 鲁棒认证分数 | 核心模块 | ε-截尾聚合 + 反作用残差惩罚，分数本身抗污染、抗刷榜 |
| IP-316 | Rank-Cert 名次认证 | 核心模块 | 分数区间 → 名次区间 → 认证偏序 + top-k 稳定性证书 |
| IP-317 | I-Sentinel 双通道干扰哨兵 | 核心模块 | 以 (σ_pred, σ_decl, σ_obs) 反作用回执识别测量/策略干扰 |
| IP-318 | Board-Alloc 榜单预算分配 | 核心模块 | 风险加权预算 + 定向审计预留，给出排名后悔上界 |
| IP-319 | MetroBoard 主闭环 | 集成 | D-Box → MetroBoard → I-Box 的认证优先级闭环 |

**与通用「鲁棒排行榜」的本质区别**：抗干扰不依赖外部信誉或历史先验，而依赖 R73 的反作用通道完备性——少报 σ_decl 必然在 σ_obs 上留下可审计的残差，使刷榜**自证且非盈利**（引理 48）。

## 1. 符号体系增量（定义 409–421）

## 2. 形式化定义（要点）

**定义 410（认证分数 R-Score）**
```
s_R(o) = ρ_ε({ψ(e_j)}) − λ_pen · [g(o)]_+
g(o)   = max_j (σ_obs^{(j)} − σ_decl^{(j)})_+ / max(σ_decl^{(j)}, ε₀)
```
方向：**分数越高，审计优先级越高**。

**定义 412（认证偏序与名次区间）** `o ≻_cert o′ ⇔ s_lo(o) > s_hi(o′)`；否则不可分离。
```
r_lo(o) = 1 + #{o′ : o′ ≻_cert o}
r_hi(o) = K − #{o′ : o ≻_cert o′}
```

**定义 413（两类排名干扰）** 预算 `(ε, δ_g)`：ε-污染（测量）+ 压低声明 `σ_decl ← σ_decl − δ_g`（策略）。

**定义 414（排名稳定性证书）** 对目标 top-k，若第 k 与 k+1 名分数间隙 `≥ 2·rad(ε, δ_g)`，则 `(ε, δ_g, η)`-稳定；该判据是**紧的**（引理 47）。

**定义 416（干扰哨兵 I-Sentinel）** `mean_robust(σ_obs − σ_decl) > ζ` ⇒ FLAG：① 以 `λ_pen·g(o)` 下调分数；② 追加定向审计份额。

**定义 417（Board-Alloc）** `b_i ∝ s_R(o_i)/cost(o_i)`，`Σ b_i ≤ B_iter`，且 `β·B_iter` 预留给 FLAG 对象。

**定义 420（不可认证排序与安全退化）** 不存在稳定 top-k 时，**必须显式输出「不可认证排序」并回退均匀审计 / R68 降级，严禁静默使用点估计**。

## 3. 关键算法骨架

```python
# IP-315 R-Score
class RScore:
    def score(self, evidence, eps=0.1, lam_pen=1.0):
        psi = [e.cost * (e.sigma_hi - e.sigma_lo) for e in evidence]
        base = trimmed_mean(psi, eps)                       # 抗测量干扰
        g = max((e.sigma_obs - e.sigma_decl) / max(e.sigma_decl, 1e-9)
                for e in evidence)                          # 刷榜指纹
        return base - lam_pen * max(0.0, g)

# IP-316 Rank-Cert
class RankCert:
    def score_interval(self, evidence, rscore, delta=0.05):
        vals = [rscore.score(resample(evidence)) for _ in range(self.B)]
        return quantile(vals, [delta/2, 1 - delta/2])

    def rank_intervals(self, objects):
        for o in objects:
            o.r_lo = 1 + sum(1 for p in objects if p.s_lo > o.s_hi)
            o.r_hi = len(objects) - sum(1 for p in objects if o.s_lo > p.s_hi)

    def certified_topk(self, objects, k):
        gap = objects[k-1].s_lo - objects[k].s_hi
        rad = max(o.s_hi - o.s_lo for o in objects) / 2
        return gap >= 2 * rad                               # 定义 414

# IP-317 I-Sentinel
class InterferenceSentinel:
    def inspect(self, receipts):
        r = [rec.sigma_obs - rec.sigma_decl for rec in receipts]
        if robust_mean(r) > self.zeta:
            return FLAG, self.lam_pen * robust_mean(r)      # 定义 416
        return OK, 0.0

# IP-318 Board-Alloc
class BoardAlloc:
    def allocate(self, board, budget, beta=0.3):
        out = {}
        for flagged, share in ((False, 1 - beta), (True, beta)):
            grp = {o: o.s_R / o.cost for o in board if o.flagged == flagged}
            tot = sum(grp.values()) or 1.0
            out.update({o: share * budget * w / tot for o, w in grp.items()})
        return out

# IP-319 MetroBoard 主闭环
def MetroBoard_round(M, budget):
    board = build_board(DBox.detect_blind_spot(), M.receipts)
    for o in board:
        o.s_R, (o.s_lo, o.s_hi) = rscore.score(o.evidence), \
                                  rankcert.score_interval(o.evidence, rscore)
        o.flagged, pen = sentinel.inspect(o.receipts)
        o.s_R -= pen
    rankcert.rank_intervals(board)
    if not rankcert.certified_topk(board, k=RBC.k):
        return DEGRADE(M, reason="不可认证排序")            # 定义 420
    for o, b in BoardAlloc().allocate(board, budget).items():
        IBox.execute_validation(o, budget=b)               # 定向采样
    return MODGAUGE_round(M, ...)
```

## 4. 推导

**引理 46（污染下分数集中性）** 名义次高斯 + ε-污染下，median-of-means 满足
`P(|ρ_ε − E[ψ]| ≥ C(σ√(log(1/δ)/N) + εB_ψ)) ≤ δ`。区间以 `O(1/√N)` 收缩，但被 `εB_ψ` 常数地板卡住。

**引理 47（稳定性 ⇔ 名次间隙）** 认证 top-k 稳定 ⇔ 第 k、k+1 名间隙 `≥ 2·rad`。必要性由构造边界翻转给出，故证书紧。

**引理 48（策略干扰自证且非盈利）** 低报 `δ_g` 必然触发 λ 越阈（I-Box 审计）或残差越阈（I-Sentinel）；当 `λ_pen ≥ ∂risk/∂σ_decl` 时，惩罚 `λ_pen·δ_g/σ_decl` 覆盖刷榜收益，净收益 ≤ 0。

**引理 49（排名后悔上界）** 证书稳定时 `Regret(π) ≤ B·Δ_max·(width/gap)_+`；证书失败回退均匀审计，`Regret ≤ B·Δ_max`，严格退化有界。

**引理 50（组合单调性）** MetroBoard 仅重排/分配审计，不改变任何契约的安全判定；输入均在 MODGAUGE 契约内，五不变式保持，新增失败模式「预算饥饿」由定义 420 兜底。

## 5. 复杂度分析

| 组件 | 域 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|---|
| R-Score 聚合 | 计量域 1Hz | O(N log N) < 2ms | O(N) | 定义 410、引理 46 |
| Rank-Cert 区间 | 计量域 0.2Hz | O(B·N log N + K log K) < 20ms | O(B·N) | 定义 412/414、引理 47 |
| I-Sentinel | 计量域 50Hz | O(1)/回执 < 0.1ms | O(#receipts) | 定义 416、引理 48 |
| Board-Alloc | 计量域 0.2Hz | O(K log K) < 1ms | O(K) | 定义 417、引理 49 |
| MetroBoard 闭环 | 计量域（事件触发） | O(K·B) < 25ms | O(K·B) | 定义 418、引理 50 |

## 7. 本轮最大风险

**一句话**：MetroBoard 的稳定性证书以「干扰有界 `(ε, δ_g)` + 名义证据可交换」为前提；一旦攻击者自适应地针对证书本身做无界操纵（先探测再分批注入、利用证书紧性做边界翻转），或证据稀缺使名次区间宽到「可认证但不可用」，排行榜就会退化为「认证了不可排序」的合规摆设，而现场操作者仍会默认点估计名次行动——证书沦为例行表演。
