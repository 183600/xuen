## 1. 两个灵感的第一性原理

### 灵感 1 ·「可扩展性」→ 不是「能加」，而是「加了还值」

**直觉解释**：可扩展性常被误解为「系统能接入更多任务/数据/机器人」。但这场比赛按「平均成功率 + 步骤分」综合排序，延迟与步数本身就是被计分的成本——每加一个能力若线性加延迟，就是在给总分交税。所以真正的可扩展性是：**能力随资源增长的速度，快于成本随资源增长的速度**。第 3 轮的 U12 延迟预算不只是工程约束，它是目标函数的一部分。

**严谨定义（U19，可扩展性 profile）**：以资源 `R ∈ {数据 N、算力、具身 E、任务 T}` 为自变量，定义能力曲线 `Cap(R)=(success, step_score)` 与成本曲线 `Cost(R)=(P99 延迟, 步数, 评测运行数)`；折算标量效用 `U(R)`（成功率 × 步骤分）与归一化成本 `C(R)`（延迟/预算 + 步数开销）。记 `β_U = d ln U / d ln R`、`β_C = d ln C / d ln R`。系统**有利可扩展** ⇔ `β_U > β_C`（效用弹性大于成本弹性）。三个可扩展轴：

- **任务/物体轴**：新任务族（叠衣/做三明治/装配）能否复用旧技能与先验，而非重训；
- **具身轴**：Dex1 ↔ Brainco ↔ Dex3 ↔ Z1 之间，核心策略/先验能否共享，只换薄适配器（U22）；
- **评测轴**：6 因子 × 5 轴 × 32 任务的全因子组合是组合爆炸，诊断评测本身也必须可扩展（IP-18）。

**为什么上一轮不够**：第 3 轮的状态层/物体档案都是「单具身、单 episode」，且加入能力（检测、滑移、干扰）都是**串行叠加**，`β_C` 很可能 ≥ `β_U`。本轮把它改成**条件计算**：能力按需激活，昂贵部分摊销或事件触发。

### 灵感 2 ·「常识推理」→ 把慢思考编译成快先验，只在新异处重新慢思考

**直觉解释**：机器人在没见过的物体/任务上「看起来笨」，缺的不是像素分辨率，而是三类先验：**可供性**（杯子该抓把手、布该从边角提）、**物理**（不能悬空、叠放会倒、容器开口朝上）、**任务语义**（做三明治先面包后馅、叠衣有固定折叠序）。最直接的做法是运行时问大 VLM——但那是全场最贵的一步，直接违反灵感 1 的成本约束。可扩展的解法是：**把慢思考（deliberation）离线编译成结构化先验，运行时只在「先验不可信」的新异处重新慢思考**。

**严谨定义（U20，常识先验）**：`P = (S, A, R)`：

- `S`（任务图式）：子任务偏序 `(V, ≺)`，每节点带前置/后置条件与物体绑定，诱导一条路标骨架；
- `A: (object, grasp) → [0,1]`（可供性先验）；
- `R: (o_i, o_j) → {support, contain, stack, none}`（物理关系先验）；
- 每条事实带来源 `src ∈ {VLM 离线, 数据, 人工}` 与可校准置信度。

**严谨定义（U21，常识预算 / deliberation VoI）**：一次推理请求 d 的成本 `c_d`（折算为分数当量），期望收益 `E[ΔU|d]`；当且仅当 `VoI(d)=E[ΔU|d]−c_d > 0` 且 Tier-A 延迟预算允许时才调用；成功推理的结论写回 `P`，同上下文后续成本为 0（摊销）。

**合流**：两个灵感互为约束而非并列——常识推理是最贵的可扩展性威胁；可扩展性的正确解法不是「少推理」，而是「把常识摊销 + 只在值得时推理」。一句话：**常识要编译，不要常问**（P13）。

## 3. 设计原则（新增 P13–P15，接第 1–3 轮 P1–P12）

- **P13（先编译后查询）**：常识只以「带来源与置信度的编译先验」进入运行时；在线推理是 VoI 门控的例外，绝不成为逐步依赖。
- **P14（可扩展性约束）**：任何新能力必须使 Tier-A 逐步延迟留在 U12 预算内；昂贵推理只能离线摊销或事件触发，否则只许离线存在。
- **P15（具身无关核心）**：任务图式与物体先验必须具身无关；具身差异隔离在薄适配器 `π_e` 内（U22）。

## 5. 本轮最大风险

**常识先验在分布外被高置信地用错**：编译先验恰好编码了教师 VLM 对未见物体/新具身的偏见，而先验越强越难被少量数据推翻——这是「地图毒化」的认知版，会比无先验更糟。对冲：先验置信封顶 + 双来源交叉校验 + 新异检测器召回率单独评估（E640），并保留 Level-1.7 退化。

- **动机**：新任务族（叠衣/做三明治/装配）与未见物体上的失败，主因是缺可供性/物理/任务序三类先验，而非像素不足；在线问 VLM 太贵（违反 P14）。离线编译把「一次昂贵推理」摊成「多次免费查表」。

- **动机**：常识推理是全场最贵操作；「常开 VLM」直接摧毁步骤分与延迟。需要一个运行时门，把昂贵推理限制在**值得**的少数决策点，并把结论摊销回 `P`。
- **与现有方案差异**：v3 的 P12/L13 只对「探测 vs rollout」记账；本 IP 把 probe / rollout / deliberation 三类信息获取统一到同一 VoI 账（U21），并以「连续失败次数 k」「新异度」「图式死锁」为触发信号（L15）。
- **技术可行性**：高。门控本身是轻量规则/小分类器（O(1) 每步）；触发信号已有（IP-13 复读检测、IP-04 不确定度、IP-14 滑移）。难点在 VoI 标定与阈值 k*。

## 5. 符号与定义（新增 U19–U22；U1–U18 沿用第 1–3 轮）

- **定义 U19（可扩展性 profile）**：`Cap(R)=(success, step_score)`、`Cost(R)=(P99 延迟, 步数, 评测运行数)`；`β_U=d ln U/d ln R`、`β_C=d ln C/d ln R`；**有利可扩展** ⇔ `β_U>β_C`。

## 7. 推导（新增引理 L14–L17；L1–L13 沿用第 1–3 轮）

**引理 L14（常识摊销界）** 设编译先验在比例 `1−ε` 的决策上下文上正确（分布内），在 `ε` 的 OOD 上下文上可能错误；新异检测器对 OOD 的召回为 `ρ`。则在线审议调用率 ≤ `ε`，每 episode 期望在线成本 ≤ `ε·N·c_d`（常开 VLM 为 `N·c_d`，成本乘 `ε`）；期望遗憾 ≤ `(1−ε)δ_ID + ε[(1−ρ)Δ_max + ρ·δ_delib]`。⇒ **摊销把成本乘 ε，代价是 OOD 残余遗憾；ε 与新异召回 ρ 决定一切**——可扩展的常识 = 好的新异检测器。∎

**引理 L15（失败触发 VoI 单调性）** 设某路标单次成功率 `p ~ Beta(α,β)`，连续失败 k 次后后验均值 `E[p|k]=α/(α+β+k)` 随 k 递减。切换/审议的期望收益 `G(k)=(1−E[p|k])·r − c_d`（r 为挽回价值）随 k 单调递增，故存在阈值 `k* = min{k : G(k)>0}`。⇒ **连续失败次数是 VoI 的充分统计量**；`k*` 由步数账确定，与 IP-13 的复读检测共享信号，无需单独调参。∎

**引理 L16（可扩展评测的无偏性）** 在效应稀疏假设下（≥3 阶交互可忽略），分辨率 V 的分数因子设计（或多水平下的 strength-2 覆盖阵）可无偏估计全部主效应与二阶交互；二水平 k 因子用 `2^{k-p}` 设计（k=6 时 `2^5=32` vs 全因子 64），多水平用规模 `O(k·L²·log k)` 的覆盖阵（vs `L^k`）。⇒ **评测成本次乘性下降，代价是≥3 阶交互不可辨识**（本项目显式接受此假设）。∎

**引理 L17（跨具身共享先验的样本复杂度）** 若策略分解为 `π_e = π_shared ∘ φ_e`，且 `P` 覆盖任务/物体语义，则新具身适配所需的样本复杂度随 `φ_e` 的复杂度（动作空间内在维数 `d_e`）而非联合任务分布增长：`O(d_e log(1/δ))`（忽略任务无关常数），而非从零训练的 `O(|S|·N)`。⇒ **共享常识核心把「每换一只手重训」变成「训一个薄适配器」**（此为本轮建模假设，需 E636 验证）。∎
