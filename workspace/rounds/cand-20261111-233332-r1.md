# 第 57 轮（承接第 56 轮「证据地图×主动探询×信任协商」IP-127~132；灵感循环第 1 轮；本轮灵感：「力矩传感」×「力觉传感」）

> 第 56 轮把"单帧置信"升级为"证据承诺"，并给证据一个持久的家（𝓜）；但它对证据的分级仍停留在**来源类型**（探针/到访/裕度/人工），且把探针的"非破坏性"当作开环假设。问题在于：接触失效的定义本身就是一个**力旋量约束被违反**的事件——语义分割只是"看见"表面，只有真正经过接触的力/力矩才"走过"失效点。本轮用「力矩传感」补上**因果证据**（力在失效因果链上，而非旁证），用「力觉传感」补上**可执行的非破坏性**（屏障控制的力伺服，而不是力帽祈祷），并把"探针"重构为"带安全约束的实验设计"。核心命题由"证据说可信"升级为 **"经过失效点的证据，才算证据"**。

核心矛盾：

- **H28**：第 56 轮证据门按来源类型计票，没有"物理参与度"概念——视觉、云端先验、探针、人工标注被当作可比较的票；但只有真正承担接触载荷的证据才处在失效因果链上。更糟的是非破坏公理 `F_probe ≤ F_abs` 是**开环计划**：薄冰上轻点可能已经塌了，系统只是"事后"才知道探针破坏了世界。
- **H29**：力矩/力觉是最强证据，也是最强共模失效点——它同时是地图证据、控制反馈、护盾输入与证书依据。一次标定偏置或传感器故障会同时污染四者；而因为它权重最高，污染速度比任何语义错误都快。

## 0. 直觉与动机

**灵感 1（力矩传感 → 力是"经过"而非"看见"的证据）**
直觉：语义分割回答"这里像什么"，力觉回答"这里实际承受了什么"。接触失效不是"看起来不安全"，而是"摩擦力/承载/CoP 被真实突破"——所以力旋量不是失效的代理变量，它就是失效变量本身。由此可给证据一个**物理偏序**：定义载荷路径参与度 `ℓ(e)` 为"该证据所观测的广义力占失效相关广义力的比例"，视觉 `ℓ≈0`，足端力/关节力矩（经雅可比）`ℓ→1`。这取代第 56 轮的来源标签，把"证据够不够硬"变成可度量、可审计的量。但必须警惕：**直接 ≠ 可信**，力矩测量本身带标定与模型。

**灵感 2（力觉传感 → 非破坏性必须是控制不变式，不是先验假设）**
直觉：第 56 轮的 `tap` 是开环的——设定力帽然后祈祷。力觉让探针变成闭环：在**力域安全集** `C_w`（法向力帽、摩擦锥下界、CoP 支撑域、力变化率上界）内做导纳伺服，用控制屏障函数保证实测力旋量轨迹不越界；一旦检测到滑移前兆（切向蠕动、微振动、力矩比逼近下界）立即卸载退出。于是"非破坏"从"计划时相信"变成"执行时保证"，其残余风险由屏障违例概率 `δ_bar` 显式给出。**探针不是在薄冰上碰运气，而是在力域安全集里走钢丝，绳子一松就退。**

**灵感 3（持续激励 → 探询是辨识，辨识要激励）**
直觉：不激励的探针等于没探——只看法向力永远学不到 `μ`，只看位置永远分不开 `k` 与 `F_bear`。真正的探询是**带安全约束的实验设计**：选择能最大化 Fisher 信息 `I_π(θ)`（`θ=(μ,k,F_bear,bias)`）的加载方向，同时满足 `C_w`。这里有一个诚实的张力：**最有信息量的实验往往最靠近边界**（要逼近承载极限才能测 `F_bear`）。因此 VOI 必须同时计信息增益与边界风险，且激励不足时 VOI 记 0，禁止"假装探过"。

**灵感 4（自指诊断 → 传感器也在回路里，必须被同一套物理审问）**
直觉：力矩/力觉同时是证据、控制反馈与护盾输入，它一旦偏差或卡死，三者一起失守。所以不能"因为它是力所以无条件信"；要用**解析冗余**交叉盘问：关节力矩传感器、电机电流×力矩常数、足端六维力、动量观测器、运动学/惯性推算，构成奇偶空间 `p=V^T y`，给出力矩证据可信度 `τ_t`。`τ_t` 低则先收缩生存核、禁止不可逆承诺，而不是"降权后继续冲"。**身体是自己的证人，但证人也要被交叉盘问。**

**灵感 5（力证对账 → 地图不是纪念碑，是账本）**
直觉：每一步支撑相都产生一条力证，每一步都在和地图的预测力对账。若实测力与地图预测力的马氏距离超过阈值，说明地图在说谎——立刻标记 `contested`、`κ` 取下界、稳健重标定，而不是等陈旧半衰期慢慢衰减。这正面击中第 56 轮最大风险（坏证据长寿）：力证高频、难伪造、且在因果链上，是地图最忠实的审计员。**宁可当场认错重标定，也不让旧证据在衰减前继续放行。**

## 1. 形式化定义（增量：定义 133–138）

**定义 133（力证与载荷路径参与度）** 力证 `e=(c, w_e, τ_e, ℓ_e, Σ_e, t, cal_ver)`：`w_e` 为接触力旋量（或经雅可比映射的关节力矩），`ℓ_e ∈ [0,1]` 为载荷路径参与度，`Σ_e` 为测量协方差。证据权重 `w_e = w_0·ℓ_e·τ_t(e)·g(Σ_e)`，其中 `τ_t` 为定义 136 的力矩可信度。偏序 `e_i ⪰ e_j ⇔ ℓ_i ≥ ℓ_j ∧ Σ_i ⪯ Σ_j ∧ τ_{t,i} ≥ τ_{t,j}`。**不可逆承诺至少需一条 `ℓ ≥ ℓ_min` 的证据**；视觉 `ℓ=0` 只能作旁证。

**定义 134（力域安全集与屏障探询）** 对接触 `c`：
`C_w(c) = { (f,τ) : 0 < f_n ≤ F_abs, ||f_t|| ≤ (1−m_f)·μ_lo·f_n, CoP(f,τ) ∈ P_sup ⊖ d_m, |ḟ_n| ≤ ρ_max }`，
`μ_lo` 为摩擦系数下置信界。探针控制**屏障可容许**当存在 `h_w ≥ 0` 使 `h_w(k+1) ≥ (1−αΔ)h_w(k)` 沿实测轨迹成立。探针致失效概率 `P(fail_probe) ≤ P(h_w < 0) ≤ δ_bar`。**非破坏性由不变式保证，而非由计划假设。**

**定义 135（持续激励与可辨识探询）** 参数 `θ=(μ,k,F_bear,b)`（`b` 为力/力矩偏置）。敏感度 `S_π=∂w/∂θ`，Fisher 信息 `I_π=S_π^T Σ_w^{-1} S_π`。可辨识条件 `λ_min(I_π) ≥ θ_exc`。激励感知信息价值
`VOI_exc(π) = ½·log det(I_π+I_0)/det(I_0) − λ_e·cost(π) − λ_s·risk_upper(π)`，
仅在 `π` 屏障可容许时计入；不可辨识探针 `VOI_exc ≡ 0`。

**定义 136（自指动力学残差与力矩可信度）** 残差 `r_dyn = M(q)q̈ + C(q,q̇)q̇ + g(q) − J^T f_meas − τ_meas`；解析冗余通道 `y=(τ_sensor, τ_current, f_foot, τ_mo, τ_kin)`（统一映射到广义力矩坐标）；奇偶向量 `p=V^T y`，`τ_t = 1 − P(fault_torque | p)`。若 `τ_t < τ_min`：`μ_lo ← μ_lo − Δ_deg`、`K_B` 收缩、禁止不可逆承诺。**降级只能变保守。**

**定义 137（力证否证与地图重标定）** 预测力 `ŵ=g(b_r,σ)`，检验 `Λ=(w_meas−ŵ)^T Σ_w^{-1}(w_meas−ŵ)`。若 `Λ > χ²_{1−α}`：`b_r ← contested(b_r, κ_lo)`、记 `falsify_log`、用可信力证稳健重标定；否则按 `like_w` 融合并更新 `prov`。**每步对账，永不允许陈旧证据静默放行。**

**定义 138（力证证书 J_w）** `J_w=(𝓜_core, WEL, C_w 记录, τ_t, excitation_log, falsify_log, consent_log)`；不可逆接触须带 `EV-wrench`（`ℓ≥ℓ_min` 且屏障未违例）或 `EV-slip`（前兆实测且安全中止）；`τ_t ≥ τ_min`；`Λ` 在容差内；否则拒绝。

### IP-133 WEL（Wrench Evidence Ledger）

```python
def wel_record(L, c, w_traj, tau_traj, ell, cal_ver, r_dyn):
    e = Evidence(contact=c, w=w_traj, tau=tau_traj, ell=ell,
                 cal=cal_ver, dyn_res=r_dyn, t=now())
    e.trust  = torque_trust(e.dyn_res)          # IP-136
    e.weight = w0 * e.ell * e.trust * g(e.cov)
    L.append(e, causal_parent=c.last_evidence)  # 因果父边，可溯源
    return L
```

```python
def force_barrier_probe(c, target, M, F_abs):
```

### IP-135 PEI（Persistent-Excitation Identifiability）

```python
def select_probe_exc(c, M, L, budget):
    best = None
    for p in admissible_probes(c, M, F_abs):               # 屏障可容许
        I = fisher_information(p, M.b[c.region], L)        # S^T Σ^-1 S
        if lambda_min(I) < theta_exc: continue             # 不可辨识即 0
        v = 0.5*logdet(I + M.I0) - 0.5*logdet(M.I0) \
            - lam_e*cost(p) - lam_s*risk_upper(p)
        best = max(best, (v, p))
    return best[1] if best and best[0] >= theta_voi else None
```

### IP-136 SRD（Self-Referential Dynamics Diagnosis）

```python
def dynamics_diagnosis(q, qd, qdd, tau_meas, f_meas, L):
    r = M(q)@qdd + C(q, qd)@qd + g(q) - J(q).T@f_meas - tau_meas
    y = [tau_meas, tau_from_current(), f_meas,
         momentum_observer(q, qd, tau_meas), f_from_kinematics()]

def trust_gate(M, tau_t):
    if tau_t < tau_min:
        M = shrink_kernel(M, d_mu=Delta_deg)       # 降级只收缩
        M.flag['torque_degraded'] = True
```

### IP-137 WFR（Wrench Falsification & Recalibration）

```python
def wrench_falsify(M, c, e_w, alpha=0.01):
    w_hat = predict_wrench(M.b[c.region], c.schedule)
    Lam = (e_w.w-w_hat).T @ inv(e_w.cov) @ (e_w.w-w_hat)
    if Lam > chi2_ppf(1-alpha, df=len(e_w.w)):
        M.b[c.region] = contested(M.b[c.region], kappa_lo(M))
        M.falsify_log.append((c, e_w.t, Lam))
        M.b[c.region] = robust_recalibrate(M.b[c.region], e_w, e_w.trust)
    else:
        M.b[c.region] = bayes_update(M.b[c.region], like_w(e_w), e_w.weight)
    M.prov[c.region].touch(e_w); M.ver.bump(c.region)
    return M
```

```python
def wrench_certificate(sched, L, M, consent_log, budgets):
    for c in contacts(sched):
        e = best_evidence(L, c, key=load_path)             # ℓ 最大的一条
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| WEL | O(1) 记录 / O(\|L\|) 存储 | O(\|L\|) | 载荷参与度诚实、因果父边可溯 |
| WCB | O(N_u·QP) 每探针 | O(1) | `h_w` sound、力硬饱和、前兆中止 |
| PEI | O(\|cands\|·(d_θ³+\|L\|)) | O(d_θ²) | 不可辨识即 0、激励不越 `C_w` |
| SRD | O(d_o³+d²) 每拍 | O(d²) | 奇偶空间可观测、降级只收缩 |
| WFR | O(d_w²+d_θ) 每支撑相 | O(d_w²) | 检验水平 α、重标定保校准 |
| WEC | O(\|σ\|·\|L_c\|) | O(\|σ\|) | 不可逆无物理见证即拒绝 |

**正确性定理（Force-Grounded Commitment Soundness, FGCS）**：在 A29–A36 基础上加 **(A41)** 力/力矩测量经标定、偏置界已知且由 SRD 监测；**(A42)** 屏障证书在测量噪声下 sound，`P(h_w<0) ≤ δ_bar`；**(A43)** 持续激励使参数可辨识，辨识误差 `≤ ε_id`；**(A44)** 故障在 `τ_d` 内检出，漏检 `≤ δ_fd`，降级只收缩核；**(A45)** 力证否证检验水平为 `α`，重标定保校准；**(A46)** 滑移前兆在 `τ_s` 内检出并卸载。则：

1. 承诺接触失效率 `≤ δ_f + δ_bar + ε_id + δ_fd + ε_cal`；
2. **非破坏不变式**：每次探针以概率 `≥1−δ_bar` 留在 `C_w`，探针致损 `≤ δ_bar`；
3. **共模单调性**：任何力矩通道故障/不确定只降低 `ℓ,τ_t` 并收缩 `K_B`，不存在升险路径；
4. PCE+PEI 在 `k_probes` 与能量预算内终止于 {承诺, 绕行, 协商, 安全停}。

部署界：

```
P_safe ≥ 1 − Σ_cp(δ_f + δ_bar + ε_id + δ_fd)
             − P(Λ 检验漏检) − P(滑移前兆漏检) − P(护盾回退失败)
```

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |

## 6. 本轮最大风险

**一句话**：本轮把最高证据权重交给"经过失效点"的力/力矩，但同一条力通道同时驱动证据、控制与护盾，一次未检出的标定偏置或力矩故障就是四重共模失效——它会以比任何语义错误都快的速度毒化账本、地图与证书；因此必须以解析冗余+在线偏置辨识+对抗性故障注入+力域硬饱和四重护栏，并坚持"力越强，越要先证明这条力可信"。

### IP-133 WEL（Wrench Evidence Ledger）

```python
def load_path_participation(src, c):
    if src == 'foot_ft':      return 1.0
    if src == 'joint_torque':                                # 经雅可比投影
        u = unit(c.fail_wrench)
        return norm(J(c).T @ u) / norm(u)
    if src == 'view':         return 0.0                     # 未经过接触
    return channel_engagement(src)

def wel_record(L, c, w_traj, tau_traj, src, cal_ver, r_dyn):
    e = Evidence(id=next_id(), contact=c, w=w_traj, tau=tau_traj,
                 ell=load_path_participation(src, c), cal=cal_ver,
                 dyn_res=r_dyn, src=src, t=now())
    e.trust  = torque_trust(e.dyn_res, channel=src)          # IP-136
    e.cov    = measurement_cov(src, cal_ver)
    e.weight = w0 * e.ell * e.trust * g(e.cov)               # A41
    e.causal_parent = c.last_evidence                        # 失效因果链父边
    L.append(e)
    return L
```

### IP-134 WCB（Wrench-Constrained Barrier Probing）

```python
def cbf_wrench(f, mu_lo, F_abs, m_f, P_sup, d_m, rho_max):
    h1 = F_abs - f.n
    h2 = (1 - m_f) * mu_lo * f.n - norm(f.t)
    h3 = signed_distance(CoP(f), P_sup) - d_m
    h4 = rho_max - abs(f.n_dot)
    return min(h1, h2, h3, h4)                               # 任一越界即不安全

def force_barrier_probe(c, target, M, F_abs, alpha=0.3):
    mu_lo = lower_conf(M.b[c.region].mu) - deg_margin(M)     # IP-136
    traj = []
    for k in range(N_probe):
        h = cbf_wrench(f_meas, mu_lo, F_abs, m_f, P_sup, d_m, rho_max)
        u = admittance_ctrl(target, f_meas, tau_meas)
        u = project_to_cbf(u, h, alpha)                      # QP：不离开 C_w
        f_meas, tau_meas = apply(u)
        traj.append((f_meas, tau_meas))
        if slip_precursor(f_meas, tau_meas, tau_s):          # 切向蠕动/微振动
            unload_smoothly()
            return ProbeResult('slip_abort', record(traj, ell=1.0))
        if h < h_min:
            unload_smoothly()
            return ProbeResult('barrier_abort', record(traj, ell=1.0))
        if identifiability_ok(c, M, traj):                   # IP-135
            break
    return ProbeResult('ok', record(traj, ell=1.0))
```

### IP-135 PEI（Persistent-Excitation Identifiability）

```python
def fisher_information(p, b_r, L):
    S = numeric_sensitivity(p, b_r, theta=['mu', 'k', 'F_bear', 'bias'])
    Sigma = measurement_cov(p.src) + process_cov(p)
    return S.T @ inv(Sigma) @ S

def select_probe_exc(c, M, L, budget):
    best, best_v = None, -inf
    for p in admissible_probes(c, M, F_abs):                 # 屏障可容许
        I = fisher_information(p, M.b[c.region], L)
        if lambda_min(I) < theta_exc:                        # A43：不可辨识
            continue
        gain = 0.5 * logdet(I + M.I0) - 0.5 * logdet(M.I0)   # D-最优
        v = gain - lam_e * cost(p) - lam_s * risk_upper(p)
        if v > best_v:
            best, best_v = p, v
    return best if best is not None and best_v >= theta_voi else None
```

```python
def dynamics_diagnosis(q, qd, qdd, tau_meas, f_meas, L):
    r = M(q) @ qdd + C(q, qd) @ qd + g(q) - J(q).T @ f_meas - tau_meas
    y = {
        'tau_sensor' : tau_meas,
        'tau_current': kt * i_meas,
        'f_foot'     : J(q).T @ f_meas,                       # 统一到广义力矩
```

```python
def wrench_falsify_recalibrate(M, c, e_w, alpha=0.01):
    w_hat = predict_wrench(M.b[c.region], c.schedule)
    Lam = (e_w.w - w_hat).T @ inv(e_w.cov) @ (e_w.w - w_hat)
    if Lam > chi2_ppf(1 - alpha, df=len(e_w.w)):
        M.b[c.region] = contested(M.b[c.region], kappa_lo(M))
        M.falsify_log.append((c.id, e_w.t, Lam))
        M.b[c.region] = robust_recalibrate(M.b[c.region], e_w,
                                           e_w.trust, huber=True)
    else:
        M.b[c.region] = bayes_update(M.b[c.region], like_w(e_w), e_w.weight)
    M.prov[c.region] = touch(M.prov[c.region], e_w)
    M.ver.bump(c.region)
    return M, Lam
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| WEL | O(1) 记录 / O(\|L\|) 存储 | O(\|L\|) | `ℓ` 诚实、因果父边可溯（A41） |
| WCB | O(N_u·QP) 每探针 | O(1) | `h_w` sound、力硬饱和、前兆中止（A42/A46） |
| PEI | O(\|cands\|·(d_θ³+\|L\|)) | O(d_θ²) | 不可辨识即 0、激励不越 `C_w`（A43） |
| SRD | O(d_o³+d²) 每拍 | O(d²) | 奇偶空间可观测、降级只收缩（A44） |
| WFR | O(d_w²+d_θ) 每支撑相 | O(d_w²) | 检验水平 α、重标定保校准（A45） |
| WEC | O(\|σ\|·\|L_c\|) | O(\|σ\|) | 不可逆无物理见证即拒绝 |

**正确性定理（Force-Grounded Commitment Soundness, FGCS）**
假设 A22–A28（第 53/54 轮）、A29–A36（第 55/56 轮）成立；**(A41)** 力/力矩测量经标定、偏置界已知且由 SRD 在线监测；**(A42)** 力域屏障证书在测量噪声下 sound，屏障违例 `P(h_w<0) ≤ δ_bar`；**(A43)** 持续激励使 `θ` 可辨识，辨识误差 `≤ ε_id`；**(A44)** 力矩通道故障在 `τ_d` 内检出（漏检 `≤ δ_fd`），降级路径只收缩生存核；**(A45)** 力证否证检验水平为 `α`，稳健重标定保校准；**(A46)** 滑移前兆在 `τ_s` 内检出并完成卸载。则：

1. **承诺健全性**：承诺接触失效率 `≤ δ_f + δ_bar + ε_id + δ_fd + ε_cal`；
2. **非破坏不变式**：任意被执行探针以概率 `≥1−δ_bar` 留在 `C_w`，探针致损 `≤ δ_bar`，不再依赖开环力帽假设；
3. **共模单调性**：任何力矩通道故障/不确定只降低 `ℓ` 与 `τ_t`、收缩 `K_B` 并禁止不可逆承诺，不存在升险路径；
4. **对账完备性**：每次支撑相必产生一条力证并更新 `prov`；`Λ` 拒绝即先 `contested` 再重标定，未经重标定的区域不得发出不可逆承诺；
5. **终止性**：PCE+PEI 在 `k_probes` 与能量预算内终止于 {承诺, 绕行, L2 协商, 安全停}。

**部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + δ_bar + ε_id + δ_fd + ε_cal)
             − P(Λ 检验漏检) − P(滑移前兆漏检)
             − P(护盾回退失败) − P(τ_int 超时 ∧ 安全停失效)
```

关键：**证据强度由物理参与度而非来源标签决定**；**非破坏性由屏障不变式而非计划假设保证**；**力既是最高证据，又必须被解析冗余交叉盘问**——三者共同把"薄冰轻点即塌"与"坏证据长寿"两个旧风险，转成可测、可审计、可降级的工程约束。

## 6. 本轮最大风险

**一句话**：本轮把最高证据权重交给"经过失效点"的力/力矩，但同一条力通道同时驱动证据、控制与护盾，一次未检出的标定偏置或力矩故障就是四重共模失效——它会以比任何语义错误都快的速度毒化账本、地图与证书；因此必须以解析冗余+在线偏置辨识+对抗性故障注入+力域硬饱和四重护栏，并坚持"力越强，越要先证明这条力可信"。
