# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 1 轮；本轮灵感：「语音交互」×「姿态估计」）

> 第 54 轮把技能组合提升为「动作-鲁棒性双证书」。本轮引入 **语音交互 + 姿态估计**：语音是低带宽、离散、易歧义的意图通道，姿态是连续、高维、带遮挡不确定性的指代与动作通道。核心矛盾：**H22** 语音指代与手势锚点在时间上错位，单帧姿态或单句 ASR 都会让接地漂移；**H23** 语音后验与关键点置信度不在同一概率空间，朴素相乘会系统性高估接地正确率，产生“接地幻觉”并驱动错误动作。核心主张：把语音-姿态接地从**点估计**升级为**带覆盖保证的集合值证书**，并让“不确定就澄清”成为一等动作。

## 0. 直觉与动机

**灵感 1（语音给粗意图，姿态给细指代 → 与 A_c/A_e 同构）**
直觉：语音命令天然是粗粒度的（“拿那个”“往左一点”），姿态/手势天然是细粒度的（关键点、指向向量、抓取姿态）。于是第 54 轮的粗-细动作分解获得新的语义来源：`u` 提供粗意图空间 `U`，`P`（姿态流）提供细指代/动作空间 `P`。云边协同不再只是“粗规划-细执行”，而是“语音意图-姿态锚定”的跨模态落地。

**灵感 2（指代是集合而不是点 → 集合值接地）**
直觉：指示词“那个”本身不指定对象，它把候选集交给上下文。正确的输出不是一个对象，而是一个**歧义集** `Amb_α(u,P)`：在置信水平 `1-α` 下真实指代必在其中的对象集合。只有当整个集合都落在安全动作域内才允许执行；这比“取 argmax 再执行”在原理上更安全，也直接对上第 54 轮的 `A_core ⊆ A_c` 契约。

**灵感 3（语音-手势时序错位 → 共语窗口与偏移估计）**
直觉：指点手势的 apex 常出现在指示词前后数百毫秒。用单帧最近邻会错配。应显式建模**共语窗口** `T_align(u)=[t_u-Δ_pre, t_u+Δ_post]`，并用动态时间规整（DTW）在“手势轨迹速度剖面”与“指示词/韵律突出点”之间估计偏移 `δ_t`。偏移一旦超过预算 `Θ_t`，接地证书直接拒绝，而不是硬对齐。

**灵感 4（置信度不可比 → 风险校准而非概率相乘）**
直觉：`q_asr·c_pose` 看似合理，实则假设两者独立且同标定，几乎总不成立（同音词、遮挡、反光会让二者相关失效）。正确做法是把所有可用信号拼成打分 `s(h)`，用**分割 conformal / RCPS** 校准一个阈值，使“错误接地被执行”的风险被显式控制在 `α`。这把 fusion 从启发式变成有覆盖保证的统计决策。

**灵感 5（澄清即动作 → 语音交互是双向闭环）**
直觉：当 `|Amb_α|>1` 或歧义裕度 `κ_g` 过小，最优动作可能不是执行也不是静默拒绝，而是**问一句**（“你指的是左手边的杯子吗？”）。澄清有成本、有信息增益，应作为动作空间里的一个动作，用期望风险下降减去打扰成本来选择。这把第 54 轮的单向“规划-执行”扩展为“规划-澄清-执行”的协商闭环。

**灵感 6（互相消歧 → 语音与姿态互证）**
直觉：姿态可消解同音词（“左手” vs 手指向左），语音可消解姿态歧义（“是杯子不是瓶子”）。因此接地不应一次性完成，而应做**互消歧迭代**：用当前 `Amb` 生成澄清问题，用回答收缩候选集，直到集合可执行或预算耗尽。

**灵感 7（金字塔再叠一层 → 接地层 𝔾）**
直觉：在第 53 轮鲁棒性层 `𝕃`、第 54 轮动作协同层 `𝔸` 之上，叠加 **跨模态接地层 `𝔾`**：`𝔾_0` 感知原始置信度，`𝔾_1` 单模态指代，`𝔾_2` 语音-姿态集合接地，`𝔾_3` 澄清协商后的可执行接地。跨层证书必须同时携带 `ρ`、`A_cert`、`Amb_α`、`δ_t`。

## 1. 形式化定义（增量：定义 121–128）

**定义 121（指代槽与手势锚点）**
给定语音 `u`，解析出指代槽 `R(u)={r_1,...,r_m}`（名词短语、指示词“这个/那个/左边那个”等）。姿态流 `P={p_t=(K_t,c_t)}`，`K_t` 为关键点/指向向量，`c_t` 为逐关键点置信度。锚点映射 `anchor: R(u) → (O ∪ {⊥}) × T`，`O` 为候选对象/区域集合，`T` 为时间轴。接地假设 `g(r)=(o,t*)` 表示 `r` 指向 `o` 且时间锚为 `t*`。

**定义 122（语音-姿态接地假设空间与共语窗口）**
接地假设空间 `H = R(u) × O × T_align(u)`，其中 `T_align(u)=[t_u-Δ_pre, t_u+Δ_post]` 为共语手势窗口，`t_u` 为指示词的语音时间戳。打分函数 `s: H → ℝ`。接地映射 `G_θ: (u,P) → 2^H`，`G_θ(u,P)={h∈H | s(h) ≥ θ}`。

**定义 123（接地歧义集与风险控制）**
给定校准集 `D_cal`，用分割 conformal 取阈值 `θ_α`（或 RCPS 取风险控制阈值），定义
```
Amb_α(u,P) = { h∈H : s(h) ≥ θ_α }
```
满足（可交换性下）`P(h* ∈ Amb_α) ≥ 1-α`。若用 RCPS，则直接控制“错误接地被部署”的风险 `R̂ ≤ α`。**执行前提**：`Amb_α` 非空且整体可执行，而非 argmax 可执行。

**定义 124（手势-语音时序偏移）**
偏移估计 `δ_t(u,P) = argmin_{δ∈[-Δ_pre,Δ_post]} DTW(v_gesture, e_speech; δ)`，其中 `v_gesture` 为手势速度/指向变化剖面，`e_speech` 为指示词与韵律突出序列。偏移分布记为 `D_t`。若 `P_{δ~D_t}(|δ| > Θ_t) > ε_t`，证书拒绝。

**定义 125（风险校准融合分数）**
```
s(h) = ⟨w, φ(q_asr(r), c_pose(o,t), δ_t, prior(o|场景), 语义-几何一致性)⟩
```
`q_asr` 为 ASR n-best 对指代槽的后验，`c_pose` 为对象/锚点聚合置信度，`prior` 为场景先验，一致性项度量“语言描述的空间关系”与“姿态指向的空间关系”是否吻合。权重 `w` 与阈值由校准集确定；**禁止**把 `q_asr·c_pose` 直接当概率使用。

**定义 126（接地证书）**
接地证书 `C_g = (Amb_α, ĝ, 1-α, δ_t, κ_g, provenance)`：
- `Amb_α` 为歧义集；
- `ĝ` 为当前最优接地（仅用于澄清提问，不直接执行）；
- `1-α` 为覆盖水平；
- `δ_t` 为时序偏移；
- `κ_g = s(ĝ) - max_{h≠ĝ} s(h)` 为歧义裕度；
- `provenance` 至少含 ASR n-best、关键点来源、遮挡标记。

**定义 127（澄清即动作）**
澄清动作集合 `Q`（如“是左边那个杯子吗？”）。澄清效用
```
EU(q) = E[ R(执行|Amb) - R(执行|Amb⊕answer(q)) ] - λ_c·cost(q)
```
当 `|Amb_α|>1` 或 `κ_g < m_min` 时，若 `max_q EU(q) > 0` 则选择澄清；否则拒绝执行或降级为安全默认动作。`Amb⊕answer(q)` 表示用人类回答收缩候选集。

**定义 128（语音-姿态动作契约 VAC 与联合证书 J+）**
语音-姿态动作契约 `VAC = (C_ce, C_g, T_policy)`，其中 `C_ce` 为第 54 轮云边契约。**部署判据**：
```
Amb_α ⊆ A_core ∧ δ_t ≤ Θ_t ∧ (1-α) ≥ (1-α_min)
∧ ρ(A_core) ≥ ρ_min ∧ 澄清预算未耗尽（无未决歧义）
```
联合证书 `J+ = (J, C_g, Amb_α, δ_t, κ_g, q_used)`，其中 `J` 为第 54 轮动作-鲁棒性联合证书。仅当 `dom_{J+}(T)=in` 且风险上界 `R̂+ = α + P(δ_t>Θ_t) + β_E + β_c ≤ Θ_risk` 时允许部署。

## 2. 关键算法 伪代码

### IP-121 VPG（Voice-Pose Grounding，集合值接地）

```python
def voice_pose_grounding(u, P, scene, calib, alpha):
    slots = parse_reference_slots(u)          # R(u)
    H = []
    for r in slots:
        T_win = com_speech_window(r.t_u, dp=0.8, dpost=0.8)
        dt = estimate_temporal_offset(P, r, T_win)   # IP-122
        for o in scene.candidates:
            for t in T_win:
                h = (r, o, t)
                s = score(h, q_asr(r), c_pose(P,o,t), dt,
                          scene.prior(o), semantic_geometric_consistency(r,o,P))
                H.append((h, s, dt))
    theta = conformal_threshold(calib, H, alpha)      # IP-123
    Amb = [(h,s,dt) for (h,s,dt) in H if s >= theta]
    if not Amb:
        return ('reject', 'empty_grounding')
    ghat = max(Amb, key=lambda x: x[1])
    kappa = ghat[1] - max((x[1] for x in Amb if x[0] != ghat[0]), default=float('-inf'))
    cert = GroundingCert(Amb, ghat[0], 1-alpha, ghat[2], kappa, provenance(u,P))
    return ('ok', cert)
```

### IP-122 TGA（Temporal Gesture Alignment）

```python
def estimate_temporal_offset(P, r, T_win):
    best = (inf, 0.0)
    for delta in grid(T_win, step=0.02):
        cost = dtw(gesture_velocity_profile(P),
                   speech_deictic_profile(r),
                   offset=delta)
        if cost < best[0]:
            best = (cost, delta)
    return best[1]

def within_offset_budget(delta, D_t, Theta_t, eps_t):
    return prob_mass(D_t, lambda d: abs(d) > Theta_t) <= eps_t
```

### IP-123 RCPS-G（风险校准集合接地）

```python
def conformal_threshold(calib, H_factory, alpha):
    scores_true, scores_all = [], []
    for (u,P,gt) in calib:
        Hs = H_factory(u,P)
        scores_true.append(score_of(gt, Hs))
        scores_all.extend(s for (_, s, _) in Hs)
    # split conformal：取真实接地分数的 (1-alpha) 分位
    return quantile(scores_true, 1-alpha)

def rcps_threshold(calib, H_factory, target_risk, delta=0.05):
    # 用 RCPS 选择满足 UCB(R) <= target_risk 的最大阈值（更保守）
    return select_threshold_upper_confidence_bound(calib, H_factory,
                                                   target_risk, delta)
```

### IP-124 CAP（Clarification-as-Action Policy）

```python
def clarification_policy(cert, budget, Q, risk_model, lambda_c):
    if len(cert.Amb) <= 1 and cert.kappa >= m_min:
        return ('execute', cert.Amb[0])
    best_q, best_eu = None, 0.0
    for q in Q:
        eu = expected_risk_drop(cert, q, risk_model) - lambda_c * cost(q)
        if eu > best_eu:
            best_q, best_eu = q, eu
    if budget > 0 and best_q is not None:
        return ('clarify', best_q)
    return ('defer', safe_default())     # 拒绝或安全降级
```

### IP-125 MDR（Mutual Disambiguation Refinement）

```python
def mutual_disambiguation(u, P, scene, cert, budget):
    while budget > 0:
        if cert_can_execute(cert):
            return ('ok', cert)
        action = clarification_policy(cert, budget, question_set(cert), risk_model, lambda_c)
        if action[0] != 'clarify':
            return action
        answer = ask_human(action[1])
        cert = refine_grounding(cert, answer)     # 收缩 Amb，更新 s
        budget -= 1
    return ('reject', 'ambiguity_budget_exhausted')
```

### IP-126 VAC（Voice-Action Consistency）

```python
def certify_voice_action(J, cert, A_core, rho_min, alpha_min,
                         Theta_t, Theta_risk, beta_E, beta_c):
    if not subset(cert.Amb, A_core):
        return ('reject', 'ambiguity_outside_core')
    if cert.delta_t > Theta_t:
        return ('reject', 'temporal_offset')
    if (1 - cert.alpha) < (1 - alpha_min):
        return ('reject', 'coverage_too_low')
    if min(J.rho.values()) < rho_min:
        return ('reject', 'robustness_fail')
    risk = cert.alpha + prob_offset_exceed(Theta_t) + beta_E + beta_c
    if risk > Theta_risk:
        return ('reject', 'risk_budget')
    return ('ok', JointPlusCert(J, cert, risk))
```

### IP-127 CMA（Cross-Modal Misalignment Audit）

```python
def audit_cross_modal(scored_pairs, calib):
    # 检测 q_asr*c_pose 与真实正确率之间的系统性偏离
    naive = [(q*c) for (q,c,_,_) in scored_pairs]
    truth = [y for (_,_,y,_) in scored_pairs]
    gap = calibration_gap(naive, truth)       # ECE-like
    if gap > tau_gap:
        return ('alarm', 'confidence_product_miscalibrated', gap)
    return ('ok', gap)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| VPG | O(\|R\|·\|O\|·\|T_win\|) | O(\|H\|) | 打分校准、窗口覆盖 |
| TGA | O(\|P\|·\|T_win\|/Δ) | O(\|P\|) | 偏移有界、DTW 代价单调 |
| RCPS-G | O(n log n) | O(n) | 校准集可交换、风险上界有效 |
| CAP | O(\|Q\|) | O(1) | 期望风险估计无偏、成本可测 |
| MDR | O(budget·\|Q\|) | O(\|Amb\|) | 回答可信、集合单调收缩 |
| VAC | O(\|Amb\|·\|A\|) | O(\|A\|) | 集合包含可判定、风险预算闭合 |

**正确性定理（Set-Valued Grounding Soundness）**
假设承接第 54 轮 (A22)–(A28)；新增 **(A29)** 校准集与部署分布可交换（exchangeability），或经 Mondrian 分组后条件可交换；**(A30)** 手势-语音偏移 `δ_t` 有界且 `P(|δ_t|>Θ_t) ≤ ε_t`；**(A31)** 人类澄清回答以概率 `≥ 1-β_c` 忠实。则对任一通过 VAC 的部署：
```
P(执行了错误指代) ≤ α + P(δ_t>Θ_t) + β_E + β_c ≤ Θ_risk
```
关键：**执行的是集合而非单点**，只要 `Amb_α ⊆ A_core` 且真实接地落在 `Amb_α` 内，动作必落在核心安全域；错误只能来自覆盖失效、时序偏移、执行噪声或澄清不忠实。

> 注意：conformal 覆盖是**边际**保证，不是逐样本保证；在用户/视角/口音分布漂移下会静默失效。这是本轮最深的隐患（见第 6 节）。

## 4. 实验设计 E162–E166

| 实验 | 指标 | 目标 |
|---|---|---|
| E162 接地覆盖校准 | 名义 `1-α` vs 经验覆盖率，coverage-ECE | ECE ≤ 0.03 |
| E163 时序偏移鲁棒性 | `δ_t` 扫描下的接地准确率 | `\|δ_t\|≤300ms` 时 ≥ 92% |
| E164 澄清收益 | 错误执行率 vs 澄清频率 | 错误执行率 ↓ ≥ 50%，澄清率 ≤ 25% |
| E165 朴素融合 vs 校准融合 | 错误接地率、ECE | 校准版错误率相对 ↓ ≥ 40% |
| E166 UniBot 端到端 | 语音+手势指令任务成功率 | 较仅语音/仅姿态基线 ↑ ≥ 15% |

**消融**：去掉 TGA、去掉集合值证书（改 argmax）、去掉 CAP、去掉 CMA，分别度量错误执行率与成功率。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 校准分布与部署分布不可交换 | 高 | Mondrian 分组 conformal + 在线漂移检测 + 周期重校准 |
| 手势-语音异步导致错配 | 高 | DTW 多窗口 + 偏移预算 + 超预算即澄清 |
| 遮挡导致关键点置信度虚高 | 高 | 遮挡感知打分 + 多视角/深度融合 + 显式遮挡标记 |
| 澄清打扰与延迟 | 中 | 成本感知策略 + 澄清次数上限 + 安全默认动作 |
| 同音词/方言/口音 | 中 | ASR n-best + 语音澄清 + 用户自适应校准 |
| 集合过大导致频繁拒绝 | 中 | 主动视角调整（移动/重看）+ 缩小候选集 |

## 6. 本轮最大风险

**一句话**：集合值接地的覆盖保证依赖校准集与部署分布的可交换性，一旦新用户、新视角、新口音造成分布漂移，conformal 阈值会静默失效、`Amb_α` 收缩成错误单点，机器人将以“持证上岗”的姿态执行错误指代——因此必须以 **Mondrian 分组校准 + 在线漂移检测 + 澄清兜底** 三重护栏，宁可多问一句，也不把统计覆盖的“名义保证”当作真实安全前提。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（VPG×TGA×RCPS-G×CAP×MDR×VAC×CMA×J+）

> 承接第 54 轮产物 v31。本轮在「动作-鲁棒性双证书」之上，引入 **语音交互 × 姿态估计**，新增 **集合值跨模态接地、时序对齐、风险校准集合、澄清即动作** 四大算子：
> - **VPG（Voice-Pose Grounding）**：语音指代槽 ↔ 姿态锚点的集合值接地；
> - **TGA（Temporal Gesture Alignment）**：手势-语音时序偏移的 DTW 估计与预算；
> - **RCPS-G（Risk-Calibrated Prediction Sets for Grounding）**：conformal/RCPS 风险可控歧义集；
> - **CAP（Clarification-as-Action Policy）**：澄清作为一等动作的期望效用决策；
> - **MDR（Mutual Disambiguation Refinement）**：语音-姿态互消歧迭代；
> - **VAC（Voice-Action Consistency）**：语音-姿态-动作联合契约；
> - **CMA（Cross-Modal Misalignment Audit）**：检测 `q_asr·c_pose` 类朴素融合的校准缺陷；
> - **J+（Joint Grounding-Robustness Certificate）**：接地层与动作-鲁棒性层的联合证书。
>
> IP 编号：IP-121~IP-128（共 8 个新增），升级 IP-115/117/118/120 以纳入接地面。

### IP-121 VPG

```python
def voice_pose_grounding(u, P, scene, calib, alpha):
    slots = parse_reference_slots(u)
    H = []
    for r in slots:
        T_win = com_speech_window(r.t_u, dp=0.8, dpost=0.8)
        dt = estimate_temporal_offset(P, r, T_win)      # IP-122
        for o in scene.candidates:
            for t in T_win:
                h = (r, o, t)
                s = score(h, q_asr(r), c_pose(P,o,t), dt,
                          scene.prior(o),
                          semantic_geometric_consistency(r,o,P))
                H.append((h, s, dt))
    theta = conformal_threshold(calib, H, alpha)        # IP-123
    Amb = [(h,s,dt) for (h,s,dt) in H if s >= theta]
    if not Amb:
        return ('reject', 'empty_grounding')
    ghat = max(Amb, key=lambda x: x[1])
    kappa = ghat[1] - max((x[1] for x in Amb if x[0] != ghat[0]),
                          default=float('-inf'))
    return ('ok', GroundingCert(Amb, ghat[0], 1-alpha, ghat[2],
                                kappa, provenance(u,P)))
```

```python
def estimate_temporal_offset(P, r, T_win, step=0.02):
    best_cost, best_delta = float('inf'), 0.0
    for delta in grid(T_win, step):
        cost = dtw(gesture_velocity_profile(P),
                   speech_deictic_profile(r),

        if cost < best_cost:
```

### IP-123 RCPS-G

```python
def conformal_threshold(calib, H_builder, alpha):
    true_scores = []
    for (u,P,gt) in calib:
        H = H_builder(u,P)
        true_scores.append(score_of(gt, H))
    return quantile(true_scores, 1 - alpha)

def rcps_threshold(calib, H_builder, target_risk, delta=0.05):
    # 保守版：取满足风险上界 UCB(R) <= target_risk 的最大阈值
    return select_threshold_ucb(calib, H_builder, target_risk, delta)

def mondrian_threshold(calib, H_builder, alpha, group_key):
    # 按用户/视角/手势类别分组，缓解条件覆盖失效
    return {g: conformal_threshold(calib[g], H_builder, alpha)
            for g in groups(calib, group_key)}
```

### IP-124 CAP

```python
def clarification_policy(cert, budget, Q, risk_model, lambda_c):
    if len(cert.Amb) <= 1 and cert.kappa >= m_min:
        return ('execute', cert.Amb[0])
    best_q, best_eu = None, 0.0
    for q in Q:
        eu = expected_risk_drop(cert, q, risk_model) - lambda_c*cost(q)
        if eu > best_eu:
            best_q, best_eu = q, eu
    if budget > 0 and best_q is not None:
        return ('clarify', best_q)
    return ('defer', safe_default())
```

```python
def mutual_disambiguation(u, P, scene, cert, budget):
```

### IP-126 VAC

```python
def certify_voice_action(J, cert, A_core, rho_min, alpha_min,
                         Theta_t, Theta_risk, beta_E, beta_c):
    if not subset(cert.Amb, A_core):
        return ('reject', 'ambiguity_outside_core')
    if cert.delta_t > Theta_t:
        return ('reject', 'temporal_offset')
    if (1 - cert.alpha) < (1 - alpha_min):
        return ('reject', 'coverage_too_low')
    if min(J.rho.values()) < rho_min:
        return ('reject', 'robustness_fail')
    risk = cert.alpha + prob_offset_exceed(Theta_t) + beta_E + beta_c
    if risk > Theta_risk:
        return ('reject', 'risk_budget')
    return ('ok', JointPlusCert(J, cert, risk))
```

### IP-127 CMA

```python
def audit_cross_modal(scored_pairs, tau_gap):
    naive = [q*c for (q,c,_,_) in scored_pairs]
    truth = [y for (_,_,y,_) in scored_pairs]
    gap = calibration_gap(naive, truth)       # ECE / Brier 分解
    if gap > tau_gap:
        return ('alarm', 'confidence_product_miscalibrated', gap)
    return ('ok', gap)
```

```python
def joint_plus_certificate(J, cert, rho_min, Theta_t,
                           Theta_risk, beta_E, beta_c):
    status, payload = certify_voice_action(
        J, cert, J.A_cert.A_core, rho_min, alpha_min=0.05,

                                risk=risk))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| VPG | O(\|R\|·\|O\|·\|T_win\|) | O(\|H\|) | 窗口覆盖；分数可校准 |
| TGA | O(\|P\|·\|T_win\|/Δ) | O(\|P\|) | 偏移有界；DTW 代价单调 |
| RCPS-G | O(n log n) | O(n) | 可交换/分组可交换下覆盖有效 |
| CAP | O(\|Q\|) | O(1) | 期望风险估计无偏、成本可测 |
| MDR | O(budget·\|Q\|) | O(\|Amb\|) | 回答可信；集合单调收缩 |
| VAC | O(\|Amb\|·\|A\|) | O(\|A\|) | 集合包含可判定、风险预算闭合 |
| J+ | O(\|Amb\|·\|A\|+\|𝔇_ρ\|) | O(\|A\|+\|𝔇_ρ\|) | 联合证书 sound |

**正确性定理（Set-Valued Grounding Soundness）**
假设第 54 轮 (A22)–(A28) 成立；新增 **(A29)** 校准集与部署分布可交换，或经 Mondrian 分组后条件可交换；**(A30)** `P(|δ_t|>Θ_t) ≤ ε_t`；**(A31)** 澄清回答以概率 `≥ 1-β_c` 忠实。则任一通过 VAC 的部署满足：
```
P(执行错误指代) ≤ α + P(δ_t>Θ_t) + β_E + β_c ≤ Θ_risk
```
证明要点：VAC 要求 `Amb_α ⊆ A_core`；若 `h* ∈ Amb_α`，则所选动作必在核心安全域；覆盖失效概率 ≤ α，时序/执行/澄清分别贡献 `P(δ_t>Θ_t)`、`β_E`、`β_c`。故仅在四类失败同时不发生时才可能错误执行。

**条件覆盖警告**：标准 conformal 只保证边际覆盖。跨用户/视角/口音时，`P(h*∈Amb | group)` 可能远低于 `1-α`；必须用 Mondrian 分组或 RCPS 的 UCB 版本，并以 CMA 监控实际 gap。

## 6. 本轮最大风险

**一句话**：集合值接地的覆盖保证依赖校准集与部署分布的可交换性，一旦新用户、新视角、新口音造成分布漂移，conformal 阈值会静默失效、`Amb_α` 收缩成错误单点，机器人将以“持证上岗”的姿态执行错误指代——因此必须以 **Mondrian 分组校准 + 在线漂移检测 + 澄清兜底** 三重护栏，宁可多问一句，也不把统计覆盖的“名义保证”当作真实安全前提。
