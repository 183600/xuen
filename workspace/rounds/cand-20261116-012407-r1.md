# 第 12 轮（灵感循环第 1 轮；本轮灵感：「位姿估计」×「UniBot-V1」）
> **基线**：第 11 轮 MetricVoiceGauge-GSCF-SRA-JSSE（定义 549–561；引理 92–96；实验 E591–E610）。
> 本轮纪律：**共同模式隔离 + 位姿预算 + 接口即契约**。两个灵感分别处理 v11 留下的两种债：**结构债**（v11 引理 96 用“三重守护失效模式正交”做并集界，但三者共享同一位姿前提——正交性是假设不是事实）、**部署债**（v11 在理想深度/点云上论证几何一致性，而真实目标 UniBot-V1 Challenge 只给多视角 RGB + 关节状态 + ee 位姿，深度不保证、位姿本身还是估计量）。必须保持铁律：新增模块失效 ⇒ 注入声明中立元，行为**等价**或**支配**于 v11，不得行为漂移。

## 0. 直觉与动机

**灵感 1（位姿估计 → 把共同模式前提摆上台面）**
直觉：v11 把 GSCF/SRA/JSSE 当“正交三保险”，但三者吃的是同一个位姿估计。GSCF 的几何残差 γ_ℓ 以位姿为参考系；SRA 的问题模板把 `{pose}` 直接写进 VQA；JSSE 的 Q_abort 依赖 FK/标定。位姿一错，三者同帧、同向、同因失效——这不是“三个小概率相乘”，而是“一个前提坏、三处一起坏”。更尖锐的是自指盲区：γ_ℓ 度量的是“观测与位姿假设是否自洽”，一个自洽但系统偏差的位姿会让 γ_ℓ 很高；它无法检测自己的参考系错误。v11 的最大风险（三重守护同时触发、无优雅退化）不是偶然，而是共同模式前提的结构性必然后果。核心创新：**位姿不确定性传播器（Pose-Uncertainty Propagator, PUP）**——把位姿从“隐含真值”降格为带可信集 P_t^ε 的隐变量，按 Lipschitz 常数把位姿误差传进证书余量 β_v12 = β_GSCF + β_pose，并把守卫判据从“点估计下成立”改为“对 P_t^ε 取最坏情况成立”。共同模式从“假设不存在”变成“显式预算、可测、可审计”。

**灵感 2（UniBot-V1 → 分集冗余与统一接口的双刃）**
直觉：UniBot-V1 Challenge 的观测目录恰给了两条**失效模式不同**的位姿信道：本体感受链（关节状态 + 标定运动学 FK，或 `ee_pose_gripper_base`）与视觉链（`cam_left_high`/`cam_right_high` 多视角三角化、腕相机手内位姿）。前者怕标定漂移/编码器量化，后者怕遮挡/反光/弱纹理——同向同幅失效需要极强物理相关，因此**跨信道分歧 d_pose 是共同模式的直接观测量**。核心创新：**位姿分集审计器（Pose-Diversity Auditor, PDR）**——SE(3) 分歧 + conformal 校准阈值 τ_cm；分歧超限 ⇒ 共模可疑 ⇒ 收缩 K_eff、抬高 β_v12、必要时退回位姿无关的保守路径。但 UniBot-V1 的另一面是“单模型 + 多端口”的统一化：一个权重同时供所有端口、所有模块，会**加剧**共模。故需要**统一具身隔离层（UniBot-V1 Embodiment Fence, UEF）**：统一接口可以，统一“未验证前提”不行——*统一而不共模*。UEF 把观测键、控制空间（joint/ee）、chunk 长度、端口数都当安全契约，任何接口转换（IK、chunk 对齐、权重复制）都必须携带误差预算。

三者咬合：PUP 出可测共模预算，PDR 出共模检出与证据，UEF 把二者钉进 UniBot-V1 的真实接口；共同把 v11 的“正交并集证书”升级为**共模隔离证书 Ĉ_t^† = (ĝ_min, ê_max, γ̂_grasp, β_v12, ρ_t^cm, έ_pose, n_t^pose, Q_abort^robust)**。

## 1. 研究问题（轮次升级版）

- **Q1（共同模式下的有效证书）**：在不假设失效正交的前提下，如何用位姿可信集 + Lipschitz 传播 + 最坏情况守卫，给出不弱于 v11 保守性、且不再把共模错误地乘成小概率的证书？
- **Q2（共模的可检性）**：仅用 UniBot-V1 提供的多视角 RGB + 关节状态 + ee 位姿，如何构造两条失效独立（或至少可标定相关）的位姿信道，并用 conformal 把分歧转为可证检出率/误报率？
- **Q3（接口即契约）**：如何把 v12 证书与守卫映射到 UniBot-V1 的 joint/ee 控制、chunk 长度、多端口服务，证明接口转换与统一化不引入新的未隔离共模？

## 2. 设计原则（在 P13–P15 基础上新增 P16–P18）

**P16 共同模式隔离律（Common-Mode Isolation）**
任何被 ≥2 个守卫共享的前提（位姿、标定、时钟、基础模型权重）必须满足二选一：(a) 带校准不确定度并传播进证书；(b) 由失效独立的第二信道交叉校验。二者皆无则不许共享；统一化不豁免此律（统一而不共模）。

**P17 位姿预算律（Pose Budget）**
位姿误差必须显式进入 β_v12 与守卫阈值；块长 K 受位姿时程预算约束——位姿不确定度随 K 增长，K 上限由最坏情况漂移反解，而非仅由吞吐决定。

**P18 接口可证律（Interface-as-Contract）**
部署接口（观测键、控制空间、chunk 长度、端口数/权重共享方式）是安全契约的一部分；接口转换必须携带等价性或误差预算（ε_ik、ε_chunk、ε_port），否则降级。

## 3. 与基线的接口（如何退化）

- PUP 失效（协方差不可得/失真）⇒ ε_pose ← ε_pose^max（标定上界）、β_v12 抬至最大：保守但不激进，行为 ⊆ v11；
- PDR 失效/仅单信道 ⇒ ρ_t^cm ← 1（视为共模可疑）、K_eff←2、β_v12 抬升；物理行为 ⊆ v11（更强收缩，支配性）；
- UEF 失效 ⇒ 退回 v11 原始接口映射；若由 ee 控制且 IK 预算不可证 ⇒ 降级至 v11 JSSE 急停保持（Level-3）；
- v11 各模块失效沿 v11 退化链；新增安全守卫 PUP/PDR/UEF 一律 φ^elig=false，仅“视觉位姿通道的标定维护”可在严格预算下蒸馏；
- 全链：v12 → v11 → v10 → … → v6，任一层均不产生新物理行为。

## 4. 预期贡献

1. **反例与定理**：证明 v11 “三重守护正交”在共享位姿前提下不成立，并给出共同模式失效下界（引理 97）；
2. **共模预算化**：PUP 把位姿可信集按 Lipschitz 传播进 β_v12 与鲁棒守卫，证书不再依赖不可证的正交假设（引理 98）；
3. **共模可检**：PDR 用本体感受 vs 多视角视觉双信道 + conformal 把 d_pose 转为检出率，并诚实刻画其盲区（分歧零空间）（引理 99）；
4. **部署可证**：UEF 把 joint/ee、chunk、多端口统一化为可预算契约（引理 100–101），并重构联合保守性（引理 102）；
5. **E611–E630** 覆盖位姿标定、共模注入、分集 ROC、chunk 时程、UniBot-V1 接口一致性、对抗位姿投毒、长跑与竞赛。

## 5. 本轮最大风险

**一句话**：PDR 的两个“独立”信道可能共享更深层的共模——同一相机标定链、同一时钟、同一基础模型权重（UniBot-V1 多端口尤其会复制权重）；此时 d_pose 小会被误读为“两票一致”，把同源错误洗白成可信；而 PUP 的 Lipschitz 常数与可信集本身也依赖标定，标定若漂移，预算会系统性低估——即“共模隔离器自身可能共模”。

**新增定义 562（位姿隐变量与可信集）** 系统不再把 π̂_t 当真实位姿，而维护 (π̂_t, Σ_pose)。可信集 P_t^ε 由校准集 split-conformal 或 Mahalanobis 椭球构造，满足 P(π_t ∈ P_t^ε) ≥ 1−ε_pose（E611）。每个消费位姿的模块 m 必须声明位姿源 s_m ∈ {proprio, visual, fused} 与置信半径 r_m；未声明者默认 r_m = ε_pose^max。

**新增定义 563（PUP 位姿不确定性传播）** 设模块判据/余量 θ(π) 在 P_t^ε 上 L_θ-Lipschitz。PUP 输出鲁棒界 θ^rob(π̂) = min_{π∈P_t^ε} θ(π) ≥ θ(π̂) − L_θ·έ_pose，并令 β_pose = L_c·έ_pose，证书余量 β_v12 = β_GSCF + β_pose + β_cal。**全部守卫判据改用 θ^rob，不用 θ(π̂)。** 单调性：P_t^ε 越大（或 L_θ 越大）⇒ β_v12 越大、判据越保守，绝不更激进。

**新增定义 564（共模暴露度）** ρ_t^cm = clip(d_pose(t)/τ_cm, 0, 1)。ρ=0 表双信道一致（无共模证据），ρ=1 表达阈值或单信道。ρ 进入 K_eff 门控与台账，但不直接叠加进 β（避免与 έ_pose 重复计费）；ρ>0 时 έ_pose 取保守 max。

**新增定义 565（PDR 双信道与 SE(3) 分歧）** 信道 A（本体感受）：T_A = FK(q)，q 来自关节编码器与标定运动学；若观测直接给 `ee_pose_gripper_base`，则将其作为 A 的冗余子信道并单列协方差。信道 B（视觉）：T_B = Triangulate/PnP(cam_left_high, cam_right_high, wrist)，用相机外参统一到 base 系。d_pose 取 SE(3) 对数映射的加权范数。**登记要求**：两链的标定来源、时钟源、学习型权重版本必须登记；共享项在共模矩阵中计为同源，不得重复计为独立证据。

**新增定义 566（conformal 共模阈值）** 在健康标定校准集上计算非一致性分数 s_i = d_pose^{(i)}/σ_i（σ_i 为当帧估计不确定度），取 τ_cm = Quantile_{1−ε_cm}({s_i})。在可交换性假设下，健康条件误报率 ≤ ε_cm（分布无关，E614）；故障 b 的检出率由信道分离矩阵 J_A−J_B 决定（定义 567）。

**新增定义 567（共模可检性与零空间盲区）** 小故障 b 引起 d_pose ≈ ‖(J_A−J_B)b‖。若 b ∈ ker(J_A−J_B)，则 PDR 不可见——这是共同模式的**零空间盲区**。深度分集（不同物理原理/标定链/训练数据）增大 σ_min(J_A−J_B)、缩小盲区；UEF 强制登记共享权重，避免把同源复制误当独立分集。**本定义显式承认而非隐藏 PDR 的残余风险。**

**新增定义 568（共模隔离证书）** Ĉ_t^† = (ĝ_min, ê_max, γ̂_grasp, β_v12, ρ_t^cm, έ_pose, n_t^pose, n_t, n_t^reason, Q_abort^robust)。有效 ⇔ v11 定义 552 条件（含 U_t^geo、n_t^reason 全 1、Q_abort 非空）+ U_t^pose + Q_abort^robust 非空。ĝ_min = min_k F̂_q,clearance − β_v12。

**新增定义 569（位姿信任域与 K_eff 升级）**
```
U_t^pose = (π_t ∈ P_t^ε w.p. ≥ 1−ε_pose) ∧ (d_pose ≤ τ_cm) ∧ freshness ≤ T_fresh

K_eff(t) = 1   若 ¬U_t^sem 或 ¬U_t^geo 或 ¬U_t^pose 或 Ĉ_t^† 不可得
         = 2   若 NRB 失效 或 SRA 失效 或 PDR 失效（Π_r^pose 级）
         = max(1, ⌊K_max·(1 − max(Δ_dom/τ_dom, sup T/τ_sem,
                                  sup(1−Γ)/τ_sem, ρ_t^cm,
                                  β_pose/β_pose^max))⌋)   否则
且 K_eff ← min(K_eff, K_pose)。
```

**新增定义 570（UEF 接口契约）** κ_UniBot = (obs_keys, control_space, chunk_len, n_ports, weight_sharing, ε_ik, ε_chunk, ε_port)。UEF 每周期校验：必需观测键齐全（含多视角与关节/ee 位姿）、控制空间与 JSSE 一致、chunk_len ≤ K_pose、端口权重共享方式已登记。任一不满足 ⇒ 对应误差预算取标定上界或降级（Level-3）。

**新增定义 571（位姿时程预算与块长上限）** 设位姿不确定度增长率有界：έ_pose(k+1) ≤ έ_pose(k) + λ_pose·Δt。执行完 K 步后的最坏位姿误差 ≤ έ_pose(0) + λ_pose·K·Δt。若证书要求 L_c·έ_pose(K) ≤ β_pose^max，则
```
K_pose = ⌊(β_pose^max/L_c − έ_pose(0)) / (λ_pose·Δt)⌋。
```
块长是安全预算，不是吞吐旋钮；chunk 越长，β_pose 越大或 K 必须越小。

**新增定义 572（六检守卫）** 50Hz 六检（O(k)，k≤8）：(i) 证书有效性；(ii) 停车不变式（用 β_v12 鲁棒净空）；(iii) 语义创新度；(iv) 快规范；(v) 几何一致性（用 P_t^ε 最坏 γ）；(vi) **位姿一致性/鲁棒性**：d_pose ≤ τ_cm ∧ β_pose ≤ β_pose^max。任一失败 ⇒ JSSE 执行鲁棒中止。总预算 ≤0.75ms。

超预算 ⇒ K_eff←2，或退回 joint 控制，或急停保持（Level-3）。

**新增定义 574（位姿审计台账）** Λ_pose 追加记录：H(prev‖t‖π̂‖Σ_pose‖s_A‖s_B‖d_pose‖ρ^cm‖weight_version‖verdict)。哈希链 κ_h=256 不变；台账缺口 ⇒ U_t^pose=false（共模不可审计即视为可疑）。

```python
# IP-365 PoseUncertaintyPropagator：位姿可信集 → 证书余量/鲁棒判据
class PoseUncertaintyPropagator:
    def __init__(self, l_gamma, l_clearance, l_sra, l_abort,
                 beta_pose_max, eps_pose_max, eps_cal, lam_pose, d=6):
        self.l_gamma, self.l_c = l_gamma, l_clearance
        self.l_sra, self.l_abort = l_sra, l_abort
        self.beta_pose_max, self.eps_pose_max = beta_pose_max, eps_pose_max
        self.eps_cal, self.lam_pose, self.d = eps_cal, lam_pose, d

    def credible_set(self, pose_hat, Sigma, eps):
        lam = max_eig(Sigma)
        r = math.sqrt(chi2.ppf(1.0 - eps, self.d)) * math.sqrt(max(lam, 0.0))
        return PoseSet(pose_hat, r + self.eps_cal)

    def propagate(self, pose_hat, Sigma, eps_pose):
        P = self.credible_set(pose_hat, Sigma, eps_pose)
        eps_eff = min(P.radius, self.eps_pose_max)
        return PoseBound(P, eps_eff, beta_pose=self.l_c * eps_eff)

    def robust_lower(self, theta_hat, eps_eff, L):
        # 定义 563：对 P_t^ε 的最坏情况下界
        return theta_hat - L * eps_eff

    def robust_abort_set(self, p_star_of, P, jsse, eps_eff):
        # 对可信集顶点/采样取交集；空集 ⇒ 中止不可证 ⇒ 收缩/急停
        Qs = [jsse.map_abort(p_star_of(pi)) for pi in P.vertices_and_samples()]
        return intersect_within(Qs, tol=jsse.eps_fk + self.l_abort * eps_eff)


# IP-366 PoseDiversityAuditor：本体感受 vs 多视角视觉，共模可检
class PoseDiversityAuditor:
    def __init__(self, tau_cm, eps_pose_max, eps_cm, Wt, Wr, ema=0.2):
        self.tau_cm, self.eps_pose_max, self.eps_cm = tau_cm, eps_pose_max, eps_cm
        self.Wt, self.Wr, self.ema = Wt, Wr, ema
        self.rho_bar = 0.0

    def audit(self, T_proprio, r_proprio, T_visual, r_visual, sigma_scale):
        d = self._se3_dist(T_proprio, T_visual)
        s = d / max(sigma_scale, 1e-9)
        rho = min(1.0, s / self.tau_cm)
        self.rho_bar = self.ema * rho + (1 - self.ema) * self.rho_bar
        ok = (s <= self.tau_cm)
        # 一致时两信道互为证据：有效误差取 max(r_A, r_B, d/2)
        eps_eff = (min(self.eps_pose_max, max(r_proprio, r_visual, d / 2.0))
                   if ok else self.eps_pose_max)
        n_pose = (int(r_proprio <= self.eps_pose_max),
                  int(r_visual <= self.eps_pose_max))
        return PoseAudit(ok, d, self.rho_bar, eps_eff, n_pose)

    def _se3_dist(self, A, B):
        xi = log_se3(inv(A) @ B)                  # xi = [rho; phi]
        return math.sqrt(xi[:3] @ self.Wt @ xi[:3]
                         + xi[3:] @ self.Wr @ xi[3:])

# IP-354（升级）：共模隔离证书分块执行器
class CommonModeFencedCertifier(StructuredChunkCertifier):
    def __init__(self, *a, pup, pdr, uef, **kw):
        super().__init__(*a, **kw)
        self.pup, self.pdr, self.uef = pup, pdr, uef

    def generate_chunk(self, state, ctx, stf, gscf, sra, nrb,
                       pose_hat, Sigma_pose, T_A, T_B):
        pose = self.pup.propagate(pose_hat, Sigma_pose, ctx.eps_pose)
        audit = self.pdr.audit(T_A, self.uef.rA, T_B, self.uef.rB, ctx.sigma_scale)
        eps_eff, beta_pose = audit.eps_eff, self.pup.l_c * audit.eps_eff
        K = self.effective_K_v12(ctx, stf, gscf, audit, beta_pose)   # 定义 569
        K = min(K, self.uef.fence_chunk_len(self._chunk_cap(eps_eff)))
        if K == 1:
            return self._single_step_fallback(state)
        best = None
        for cand in self.policy.sample_sequences(state, K, n=64):
            pred = self.Fq.rollout(state, cand)
            beta_v12 = (self.beta_base
                        + self.lam * gscf.field_on_footprint(pred.corridor)
                        + beta_pose + self.beta_cal)
            g_min = pred.min_clearance - beta_v12
            e_max = pred.max_effort + beta_v12
            if g_min < self.d_safe or e_max > state.tau_eff:
                continue
            pts = self._abort_points(state, cand, pred)
            q_abort = self.pup.robust_abort_set(
                lambda pi: self._p_star(pi, cand, pred), pose.P, self.jsse, eps_eff)
            if not pts or not q_abort:
                continue
            chunk = Chunk(cand, CommonModeCert(
                g_min, e_max, beta_v12, audit.rho_bar, eps_eff,
                audit.n_pose, pts, q_abort), pts)
            chunk, _ = nrb.review_chunk(chunk, stf, ctx)
            if chunk is None:
                continue
            n_reason, _ = sra.reason_on_chunk(chunk, stf, gscf, ctx)
            chunk.cert.n_reason = n_reason
            if not all(n_reason):
                continue
            score = self.policy.score(chunk, pred)
            if best is None or score > best.score:
                best = chunk
        return best or self._single_step_fallback(state)

    def _chunk_cap(self, eps_eff):
        # 定义 571：由位姿预算反解块长上限
        return max(1, int((self.pup.beta_pose_max / self.pup.l_c - eps_eff)
                          / (self.pup.lam_pose * self.uef.dt)))

    def effective_K_v12(self, ctx, stf, gscf, audit, beta_pose):
        if not (stf.trust_ok(ctx) and gscf.geo_ok(ctx) and audit.ok):
            return 1
        if (getattr(ctx, 'nrb_failed', False) or getattr(ctx, 'sra_failed', False)
                or getattr(ctx, 'pdr_failed', False)):
            return 2
        r = max(ctx.delta_dom / ctx.tau_dom,
                stf.sup_field(ctx) / stf.tau_sem,
                gscf.sup_field(ctx) / gscf.tau_sem,
                audit.rho_bar,
                beta_pose / self.pup.beta_pose_max)
        return max(1, int(self.K_max * (1.0 - min(1.0, r))))

    def midchunk_guard(self, chunk, k_exec, live_obs, stf, gscf, nrb, jsse,
                       audit, beta_pose):
        """50Hz 六检 ≤0.75ms"""
        if not chunk.cert_still_valid(live_obs):
            return self._abort(chunk, k_exec, jsse)
        stop_inv = (live_obs.nearest_clearance
                    - self.d_brake(live_obs.speed) - self.d_safe)
        if stop_inv < chunk.remaining_len(k_exec) + chunk.cert.beta_v12:
            return self._abort(chunk, k_exec, jsse)
        if stf.surprise_near(live_obs.pose) > stf.tau_sem:
            return self._abort(chunk, k_exec, jsse)
        if nrb.fast_norms(live_obs).violated:
            return self._abort(chunk, k_exec, jsse)
        if not gscf.geo_ok_near_robust(live_obs.pose, chunk.cert.eps_pose):
            return self._abort(chunk, k_exec, jsse)
        if (not audit.ok) or (beta_pose > self.pup.beta_pose_max):
            return self._abort(chunk, k_exec, jsse)          # 检 6：位姿一致性/鲁棒性
        return ('continue', k_exec + 1)

    def _abort(self, chunk, k_exec, jsse):
        p_star = chunk.nearest_abort_point(k_exec)
        return ('abort', chunk.cert.Q_abort_robust[p_star])
```

## 4. 推导

**引理 97（共同模式失效定理——v11 引理 96 的正交假设不成立）**
设三个守卫的判据都消费同一位姿估计 π̂_t，且真实位姿 π_t 以正概率落在 v11 未建模的误差域 E_π = {π_t ∉ P_t^ε} 之外。则：
(i) v11 的并集界 P(unsafe) ≤ ε_geo+ε_sra+ε_jsse+ε_β 依赖失效事件正交/独立，而当共享前提 π 失效时，三个守卫的失效事件正相关；
(ii) 存在一个刚性偏差 b（‖b‖ 在 v11 未建模误差内）使三处同时失效：GSCF 的 γ_ℓ 在“随物体一起偏移的参考系”下仍自洽（残差小，但参考系错）；SRA 把带偏置的 {pose} 当事实注入，VQA 无法看见偏置；JSSE 的 Q_abort 满足 FK(q)=p*(π̂) 而真实中止点 p*(π)=T_b·p*(π̂)，偏差 ≥L_abort‖b‖；
(iii) 因此 P(unsafe) ≥ P(E_π) =: p_cm，而 v11 的 Σε 界可远小于 p_cm。故 v11 引理 96 在共享位姿下无效。∎
**要点**：这不是“参数没调好”，而是证书结构把共同模式错误地当成了独立小概率。

**引理 98（PUP 的保守性与不弱于 v11）**
设 (A5) P(π_t ∈ P_t^ε) ≥ 1−ε_pose（定义 562，E611）；(A6) 判据 θ 在 P_t^ε 上 L_θ-Lipschitz。则对任意 π ∈ P_t^ε，θ(π) ≥ θ(π̂) − L_θ·d(π,π̂) ≥ θ^rob(π̂)。于是：(i) 若守卫接受 θ^rob ≥ 0，则真实 π 下 θ(π) ≥ 0，安全，除 π∉P_t^ε 的概率 ≤ε_pose；(ii) β_v12 ≥ β_GSCF + 真实位姿引起的净空误差 + β_cal，故证书保守；(iii) 当 έ_pose=0 时 β_v12=β_GSCF、θ^rob=θ(π̂)，严格退化为 v11。**代价是保守性（β 增大、K 上限下降），收益是消除了“把共模当期独立事件”的结构错误。**∎

**引理 99（PDR 的共模检出与零空间盲区）**
设 (A7) 健康标定下 d_pose ≤ τ_cm 以概率 ≥1−ε_cm（定义 566，E614）；(A8) 故障 b 的一阶响应 d_pose ≈ ‖M b‖，M = J_A−J_B。则：(i) 误报率 ≤ε_cm（conformal）；(ii) 检出条件为 ‖M b‖ > τ_cm，检出率随 σ_min(M) 增大；(iii) 若 b ∈ ker(M)，检出率 = 0——这是不可消除的零空间盲区（定义 567）。深度分集（不同物理原理、不同标定链、不同训练数据）增大 σ_min(M)；共享权重/共享标定只增加 M 的零空间。**本引理把“分集”从口号变成可测的矩阵条件。**∎

**引理 100（位姿时程与块长的单调耦合）**
设 έ_pose(k+1) ≤ έ_pose(k)+λ_pose·Δt。则 K 步后的最坏误差 έ_pose(K) ≤ έ_pose(0)+λ_pose·K·Δt，β_pose(K)=L_c·έ_pose(K) 对 K 单调不减；由 L_c·έ_pose(K) ≤ β_pose^max 反解得 K_pose=⌊(β_pose^max/L_c−έ_pose(0))/(λ_pose·Δt)⌋。故 K_pose 关于 λ_pose、έ_pose(0)、L_c 单调不增。**分块执行的吞吐必须以位姿时程预算为上限，不能只按 F̂ 的算力摊销取 K。**∎

**引理 101（UEF 接口等价性与支配性）**
(i) joint 控制且 q 相同时，UEF 为恒等映射，行为 = v11；
(ii) ee 控制时，中止等价性为 ‖FK(q_abort)−p*(π)‖ ≤ ε_fk+ε_ik+L_abort·έ_pose；预算超限则 K_eff←2 或退回 joint/急停，行为 ⊆ v11；
(iii) chunk 对齐：实际执行步数取 min(chunk_len, K_pose, K_max)；超出认证视界的动作一律不执行，故是可行集限制（支配性）；
(iv) 多端口：若 n_ports 共享权重/标定/传感器，独立位姿信道数不是 n_ports，而是不同 (权重, 标定, 传感器) 元组数；把复制当独立样本会低估共模，UEF 显式去重。**统一化本身不产生安全信用，只有分集才产生。**∎

**引理 102（v12 联合保守性重构）**
在 (A5)–(A8) 与 v11 假设下，
```
P(unsafe) ≤ ε_pose + ε_cm + ε_β + P(fault ∈ ker(J_A−J_B))。
```
前三项分别是位姿可信集失配、PDR 误报（保守计入）、基础证书失配；第四项是 PDR 零空间残余风险，**不可由 PDR 自身消除**，只能靠深度分集或先验上界压缩。并且：PUP/PDR/UEF 任一失效 ⇒ K_eff 收缩、β 抬升或退回 v11 接口，故所有退化路径的物理行为 ⊆ v11。∎

## 8. 本轮最大风险

**一句话**：PDR 的两个“独立”信道可能共享更深层的共模——同一相机标定链、同一时钟、同一基础模型权重（UniBot-V1 多端口尤其会复制权重）；此时 d_pose 小会被误读为“两票一致”，把同源错误洗白成可信；而 PUP 的 Lipschitz 常数与可信集本身也依赖标定，标定若漂移，预算会系统性低估——即“共模隔离器自身可能共模”，引理 102 的 ker(J_A−J_B) 残余项正是这一风险的形式化位置。
