# 第 62 轮（承接第 61 轮「具身语义进化闭环」ESEC/IP-173~182；灵感循环第 1 轮；本轮灵感：「自适应控制」×「移动操作」）

> 第 61 轮构建了 ESEC：USR 统一语义表征、MEL 零样本物理先验、DMS 多轮对话接地、SRT-Dual 语义-实时双流、PCE+++++ 六维预算。但**四个核心局限**在本轮暴露：
> 1. **语义先验是「开环」的**：USR/MEL 给出的 φ_phys、K_prior 在一个锚点周期内静态不变，无法应对负载变化、接触刚度漂移、地面摩擦突变。MEL 的慢推理（~200ms）与真实参数快变化（~0.1-1s）之间存在「先验保鲜期」缺口，缺少**在线参数辨识与自适应修正**。
> 2. **安全与自适应未耦合**：EEIS 只在编译时做一次安全投影；若自适应在线改阻抗，可能把系统推出证书包络。缺少「**适应过程本身可证明安全**」的机制（参数投影集、CBF、证书管束）。
> 3. **固定基座假设**：ESEC 的 fused/Z_env/EEIS 均隐含「机械臂基座静止」。移动操作中基座运动引入惯性耦合、非完整约束、轮地滑移、CoM/倾覆风险，末端阻抗会被基座加速度「污染」，串行「先移动再操作」会丢失接触连续性。
> 4. **探索没有预算**：参数辨识需要持续激励（persistent excitation），激励与任务性能、安全、能耗冲突。缺少「**信息增益 vs 控制代价**」的双重控制（dual control）预算与降级策略。

## 0. 直觉与动机

**灵感 1（自适应控制 → 语义先验引导的自适应阻抗 SPAC）**
直觉：MEL 的 φ_phys 是「慢而广」的先验，自适应控制是「快而准」的在线估计器。二者不是替代关系，而是「先验给初值与安全边界，自适应在边界内做快速修正」。关键洞见：令 θ̂(0)=θ_prior(φ_phys)，把先验不确定性 U_mel 映射为自适应增益 Γ(U_mel) 与参数集 Θ_safe(U_mel)——**先验越不确定，适应越慢、集合越宽；先验越确定，适应越快、集合越窄**。大模型先验第一次成为自适应律的「结构性组成」而非外挂。

**灵感 2（安全自适应 → 带证书的自适应管束 SAT）**
直觉：自适应最危险的不是「估不准」，而是「估不准时仍然自信地改控制」。必须把自适应限制在一个「证书管束」内：参数投影到 Θ_safe、CBF 约束保证力/CoM/奇异裕度、管束半径 ρ 由参数误差上界推出。关键洞见：**自适应不是无约束在线学习，而是「带证书的受限优化」**——每次参数更新都要通过 J_adapt 验证，否则回退到语义先验的鲁棒固定增益。

**灵感 3（双重控制 → 信息-性能权衡的自适应 ADP）**
直觉：参数辨识需要激励，但激励会牺牲任务精度与安全裕度。Feldbaum 双重控制告诉我们：控制动作应同时「控制」和「探测」。关键洞见：把阻抗选择写成受限优化 `min J_task - λ_I·I(θ;y|K)`，在 CBF 安全集内选择既完成任务、又能降低参数不确定性的阻抗；当信息价值 VOI 低于激励代价时主动「冻结适应」，避免为学习而学习。

**灵感 4（移动操作 → 全身协同阻抗 WBMM）**
直觉：移动机械臂的基座是「大惯量、非完整、慢响应」的阻抗源，机械臂是「小惯量、全驱动、快响应」的阻抗源，末端接触力同时受两者影响。关键洞见：不做「先移动再操作」的串行分解，而做**全身任务空间阻抗**——在浮动基动力学下用动态一致雅可比把末端期望阻抗映射为「臂关节力矩 + 基座前馈/稳定约束」，用零空间投影满足非完整约束与 CoM/倾覆裕度，用基座扰动观测器补偿轮地滑移与加减速惯性耦合。

**灵感 5（三时间尺度 → 语义-适应-实时三层架构 TLA）**
直觉：第 61 轮是「语义流—实时流」双流；但自适应控制需要独立的「中间时间尺度」（100-1000Hz）——比语义快、比力矩环慢。关键洞见：升级为三层：语义层（10-100Hz，MEL/DMS/USR，产出先验与安全集）→ 适应层（100-1000Hz，RLS/MRAC/扰动观测器，产出 θ̂、d̂、管束 ρ）→ 实时层（1-10kHz，WBMM/CBF-QP/ERTC，产出力矩）。三层通过**版本化契约**握手；任一层超时，下游降级到上一层缓存并保守扩展。

**灵感 6（闭环反哺 → 语义-适应互证 SAG）**
直觉：自适应估计出的 θ̂ 是「真实物理参数的地面证据」，可反哺 MEL/USR 修正先验偏差；反过来语义先验又约束自适应。关键洞见：构建「先验→适应→证据→先验」的互证闭环——θ̂ 收敛后写入 USR 的 evidence_emb，成为下一轮 MEL 的物理弱标签；若 θ̂ 与 θ_prior 持续冲突且 C_sem 下降，则触发「先验失效」告警并扩大 Θ_prior 重推理。

## 1. 形式化定义（增量：定义 173–184）

**定义 173（自适应阻抗控制 AIC）** 任务空间植物与期望阻抗：
```
M(x)ẍ + C(x,ẋ)ẋ + G(x) = F_c + F_ext
M_d(ẍ - ẍ_r) + D_d(ẋ - ẋ_r) + K_d(x - x_r) = -F_ext
```
未知参数 θ = (m_p, k_c, d_c, μ, τ_b)（负载质量、接触刚度、接触阻尼、摩擦、基座扰动）。控制律与自适应律：
```
F_c = Ŷ(x, ẋ, ẍ_r)·θ̂ + τ_imp(e, ė) - F̂_ext,   e = x - x_m, ė = ẋ - ẋ_m
θ̂̇ = Proj_Θ( -Γ [ Φ^T e + Σ_i Φ_i^T (ẏ_i - Φ_i θ̂) ] )   # MRAC + 并发学习
V = ½ e^T P e + ½ θ̃^T Γ^{-1} θ̃,   θ̃ = θ̂ - θ
```
结论：在 A71–A73 下，(e, θ̃) 一致最终有界（UUB），界随 ‖θ̇‖ 与噪声上界单调。

### IP-183 AIC（自适应阻抗控制）

```python
class AdaptiveImpedanceController:
    def __init__(self, prior=None, Gamma0=1e-2, forget=0.999):
        self.theta_hat = np.zeros(5) if prior is None else prior.copy()
        self.P = np.eye(5) * 1e3
        self.Gamma = np.eye(5) * Gamma0
        self.lam = forget
        self.x_m = None; self.dx_m = None

    def reference_model(self, x_r, dx_r, F_ext, M_d, D_d, K_d, dt):
        if self.x_m is None:
            self.x_m, self.dx_m = x_r.copy(), dx_r.copy()
        ddx_m = np.linalg.solve(M_d, F_ext - D_d @ (self.dx_m - dx_r)
                                - K_d @ (self.x_m - x_r))
        self.dx_m = self.dx_m + dt * ddx_m
        self.x_m = self.x_m + dt * self.dx_m
        return self.x_m, self.dx_m, ddx_m

    def update(self, x, dx, Phi, y):
        e = x - self.x_m
        de = dx - self.dx_m
        pred_err = y - Phi @ self.theta_hat
        # 复合自适应：跟踪误差 + 预测误差（并发学习）
        grad = Phi.T @ (0.5 * e + de) + Phi.T @ pred_err
        K = self.P @ Phi / (self.lam + Phi @ self.P @ Phi + 1e-9)
        self.theta_hat = self.theta_hat + K @ pred_err
        self.P = (self.P - np.outer(K, Phi @ self.P)) / self.lam
        return self.theta_hat, self.P, grad

    def command(self, x, dx, ddx_r, x_r, dx_r, F_ext, M_d, D_d, K_d):
        e, de = x - x_r, dx - dx_r
        F_imp = M_d @ ddx_r + D_d @ de + K_d @ e - F_ext
        F_c = self.Y(x, dx, ddx_r) @ self.theta_hat + F_imp
        return F_c
```

### IP-184 SAT（安全自适应管束）

```python
class SafeAdaptiveTube:
    def __init__(self, cbf_list, rho_max=0.10, gamma_min=0.05, kappa=1.2):
        self.cbf = cbf_list
        self.rho_max = rho_max
        self.gamma_min = gamma_min
        self.kappa = kappa
        self.frozen = False

    def prior_box(self, theta_prior, U_mel):
        sigma = 0.1 + 0.5 * U_mel[0]          # epistemic 越大，盒越宽
        return theta_prior - 3*sigma, theta_prior + 3*sigma

    def project(self, theta_hat, theta_prior, U_mel):
        lo, hi = self.prior_box(theta_prior, U_mel)
        return np.clip(theta_hat, lo, hi)

    def tube_radius(self, P_theta, U_mel, Phi):
        return self.kappa * np.linalg.norm(self.sqrtm(P_theta)) \
               * np.linalg.norm(Phi, 'fro') + 0.05 * U_mel[0]

    def admissible(self, P_theta, U_mel, state, Phi, gamma):
        rho = self.tube_radius(P_theta, U_mel, Phi)
        h_min = min(h(state) for h in self.cbf)
        ok = (rho <= self.rho_max) and (h_min >= 0) \
             and (gamma >= self.gamma_min or self.frozen)
        return ok, rho, h_min

    def cbf_qp(self, F_cmd, state):
        # min ||F-F_cmd||^2  s.t. h_i(F)>=0
        F = solve_qp(F_cmd, self.cbf, state)
        if F is None:                          # 不可行：松弛 + 可行性恢复
            F = self.fallback_conservative(F_cmd, state)
            self.frozen = True
        return F

    def fallback_conservative(self, F_cmd, state):
        F = F_cmd * 0.6                        # 力收缩
        F = self.project_force_limits(F, state)
        return F
```

### IP-185 WBMM（全身移动操作阻抗）

```python
class WholeBodyMobileManipulator:
    def __init__(self, robot, bmdo, ertc):
        self.robot, self.bmdo, self.ertc = robot, bmdo, ertc

    def compute(self, x_r, dx_r, ddx_r, F_ext, theta_hat, M_d, D_d, K_d):
        q, dq = self.robot.state()
        M, C, G, J, Jd = self.robot.dynamics(q, dq)
        A = self.robot.nonholonomic_matrix(q)
        Minv = np.linalg.inv(M)

        # 动态一致雅可比 + 非完整零空间
        Jbar = Minv @ J.T @ np.linalg.inv(J @ Minv @ J.T)
        Nc = np.eye(len(q)) - A.T @ np.linalg.inv(A @ Minv @ A.T) @ A @ Minv

        # 基座扰动补偿
        d_hat = self.bmdo.estimate(q, dq)
        # 任务阻抗（含 J̇q̇ 与基座加速度前馈）
        e, de = x_r - self.robot.ee_pose(), dx_r - J @ dq
        F_cmd = M_d @ (ddx_r - Jd @ dq) + D_d @ de + K_d @ e + F_ext - d_hat

        # CoM / 倾覆 CBF 产生的稳定力
        F_stab = self.com_cbf(q, dq)
        tau = self.robot.S.T @ (Nc.T @ (Jbar.T @ F_cmd)
                                + self.robot.J_stab.T @ F_stab)
        return tau
```

### IP-186 PCE++++++（七维认知-适应预算）

```python
class CognitiveAdaptiveBudget:
    def __init__(self, base_budget, exc_energy=1.0, adapt_rate=500,
                 param_dim=5, cert_freq=100, tube_max=0.1):
        self.base = base_budget
        self.B_exc = exc_energy
        self.B_rate = adapt_rate
        self.B_dim = param_dim
        self.B_cert = cert_freq
        self.B_tube = tube_max
        self.mode = 'full_adapt'
        self.exc_used = 0.0

    def info_value(self, P_theta, sigma_y=1e-2):
        return 0.5 * np.log(np.linalg.det(np.eye(len(P_theta))
                                          + P_theta / sigma_y**2))

    def adapt_allowed(self, P_theta, U_mel, gamma):
        voi = self.info_value(P_theta)
        cost = 0.2 * self.exc_used / max(self.B_exc, 1e-6) \
             + 0.1 * self.B_cert / 1000.0
        if voi < cost:
            self.mode = 'prior_guided'
        if self.exc_used >= self.B_exc:
            self.mode = 'robust_fixed'
        if self.mode == 'robust_fixed' and gamma < 0.02:
            self.mode = 'pure_conservative'
        return self.mode in ('full_adapt', 'prior_guided')

    def consume_excitation(self, energy):
        self.exc_used += energy
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| AIC | O(n_θ²) RLS 更新 | O(n_θ²) 协方差 | (e, θ̃) UUB；先验初值使收敛时间 ∝ log(1/‖θ̃(0)‖) |
| SAT | O(n_c³) QP | O(n_c²) | CBF 满足 h≥0；ρ≤ρ_max；不可行时降级且冻结适应 |
| WBMM | O(n³)（可结构化降为 O(n·n_b²)） | O(n²) | 末端阻抗误差 ≤ ε_M；基座耦合前馈消除力纹波 |
| BMDO | O(n_b²) | O(n_b) | 滑移估计误差 ≤ δ_s；带宽满足分离 |
| TLA | 语义 O(T_sem) / 适应 O(T_adp) / 实时 O(T_rt) | 共享内存 ~16MB | 任一层不阻塞下层；超时保守扩展 |
| PCE++++++ | O(1) 预算检查 | O(1) | 任一预算耗尽触发降级，安全不退化 |

**正确性定理（AMEC-Complete）**：假设 A61–A70 及
**(A71)** 参数慢时变，`‖θ̇‖ ≤ δ_θ`，且真实 θ 以概率 ≥ 1-α 落在 Θ_prior ⊕ E_unc；
**(A72)** 回归量满足区间持续激励，或并发学习数据满足秩条件，使 λ_min(ΣΦ^TΦ) ≥ γ_min；
**(A73)** CBF-QP 的可行域非空，或松弛后的可行性恢复在有限步内完成；
**(A74)** 时间尺度分离 T_sem ≥ 10T_adp ≥ 100T_rt，且 τ_θ ≥ 10T_adp；

**(A76)** 语义-适应互证中，θ̂ 收敛前不写入 evidence，避免污染先验；
**(A77)** 基座扰动观测器稳定，观测误差有界 `‖d̂_b - d_b‖ ≤ δ_d`。
则：
1. **自适应稳定性**：跟踪误差 e 与参数误差 θ̃ 一致最终有界，界随 δ_θ、噪声、δ_d 单调。
2. **过程安全**：CBF 保证力/CoM/奇异/倾覆约束在适应过程中不被突破；参数投影保证 θ̂∈Θ_safe。
3. **先验加速**：`θ̂(0)=θ_prior` 使参数收敛时间从 O(1/γ) 降至 O(log(1/‖θ̃(0)‖)/γ)，且先验越确定加速越显著。

5. **预算安全**：B_adapt 任一维度耗尽，按 full→prior-guided→robust-fixed→conservative 降级，安全不退化。

### IP-183 AIC（自适应阻抗控制）

```python
class AdaptiveImpedanceController:
    def __init__(self, prior=None, Gamma0=1e-2, forget=0.999):
        self.theta_hat = np.zeros(5) if prior is None else prior.copy()
        self.P = np.eye(5) * 1e3
        self.Gamma = np.eye(5) * Gamma0
        self.lam = forget
        self.x_m = None; self.dx_m = None

    def reference_model(self, x_r, dx_r, F_ext, M_d, D_d, K_d, dt):
        if self.x_m is None:
            self.x_m, self.dx_m = x_r.copy(), dx_r.copy()
        ddx_m = np.linalg.solve(M_d, F_ext - D_d @ (self.dx_m - dx_r)
                                - K_d @ (self.x_m - x_r))
        self.dx_m = self.dx_m + dt * ddx_m
        self.x_m = self.x_m + dt * self.dx_m
        return self.x_m, self.dx_m, ddx_m

    def update(self, x, dx, Phi, y):
        e = x - self.x_m
        de = dx - self.dx_m
        pred_err = y - Phi @ self.theta_hat
        # 复合自适应：跟踪误差 + 预测误差（并发学习，无需持续激励）
        grad = Phi.T @ (0.5 * e + de) + Phi.T @ pred_err
        K = self.P @ Phi / (self.lam + Phi @ self.P @ Phi + 1e-9)
        self.theta_hat = self.theta_hat + K @ pred_err
        self.P = (self.P - np.outer(K, Phi @ self.P)) / self.lam
        return self.theta_hat, self.P, grad

    def command(self, x, dx, ddx_r, x_r, dx_r, F_ext, M_d, D_d, K_d):
        e, de = x - x_r, dx - dx_r
        F_imp = M_d @ ddx_r + D_d @ de + K_d @ e - F_ext
        return self.Y(x, dx, ddx_r) @ self.theta_hat + F_imp
```

### IP-184 SAT（安全自适应管束）

```python
class SafeAdaptiveTube:
    def __init__(self, cbf_list, rho_max=0.10, gamma_min=0.05, kappa=1.2):
        self.cbf = cbf_list
        self.rho_max = rho_max
        self.gamma_min = gamma_min
        self.kappa = kappa
        self.frozen = False

    def prior_box(self, theta_prior, U_mel):
        sigma = 0.1 + 0.5 * U_mel[0]           # epistemic 越大，盒越宽
        return theta_prior - 3*sigma, theta_prior + 3*sigma

    def project(self, theta_hat, theta_prior, U_mel):
        lo, hi = self.prior_box(theta_prior, U_mel)
        return np.clip(theta_hat, lo, hi)       # 参数投影，保证 θ̂∈Θ_safe

    def tube_radius(self, P_theta, U_mel, Phi):
        return self.kappa * np.linalg.norm(self.sqrtm(P_theta)) \
               * np.linalg.norm(Phi, 'fro') + 0.05 * U_mel[0]

    def admissible(self, P_theta, U_mel, state, Phi, gamma):
        rho = self.tube_radius(P_theta, U_mel, Phi)
        h_min = min(h(state) for h in self.cbf)
        ok = (rho <= self.rho_max) and (h_min >= 0) \
             and (gamma >= self.gamma_min or self.frozen)
        return ok, rho, h_min

    def cbf_qp(self, F_cmd, state):
        F = solve_qp(F_cmd, self.cbf, state)
        if F is None:                           # 不可行：松弛 + 可行性恢复
            F = self.fallback_conservative(F_cmd, state)
            self.frozen = True
        return F

    def fallback_conservative(self, F_cmd, state):
        F = F_cmd * 0.6                         # 力收缩
        return self.project_force_limits(F, state)
```

```python
class SemanticPriorGuidedAdaptive:
    def __init__(self, mel, usr, aic, sat, beta=1.0, tau_pa=0.5):
        self.mel, self.usr, self.aic, self.sat = mel, usr, aic, sat
        self.beta, self.tau_pa = beta, tau_pa

    def initialize(self):
        phi = self.usr.anchor.phys_prior
        theta_prior = np.array([phi.m_p, phi.k_stiff, phi.eta_damp,
                                phi.mu_fric, 0.0])
        U = self.usr.anchor.U_epistemic
        self.aic.theta_hat = theta_prior.copy()
        self.aic.Gamma = self.aic.Gamma * np.exp(-self.beta * U)
        return theta_prior

    def consistency(self, theta_hat, theta_prior, sigma_prior):
        return np.exp(-np.linalg.norm(theta_hat - theta_prior)**2
                      / (2 * sigma_prior**2))

    def check_prior_failure(self, C_pa, U_epistemic):
        if C_pa < self.tau_pa and U_epistemic < 0.3:
            return True                          # 先验失效，扩容 Θ_prior
        return False
```

### IP-186 WBMM（全身移动操作阻抗）

```python
class WholeBodyMobileManipulator:
    def __init__(self, robot, bmdo, ertc):
        self.robot, self.bmdo, self.ertc = robot, bmdo, ertc

    def compute(self, x_r, dx_r, ddx_r, F_ext, theta_hat, M_d, D_d, K_d):
        q, dq = self.robot.state()
        M, C, G, J, Jd = self.robot.dynamics(q, dq)
        A = self.robot.nonholonomic_matrix(q)
        Minv = np.linalg.inv(M)

        # 动态一致雅可比 + 非完整零空间投影
        Jbar = Minv @ J.T @ np.linalg.inv(J @ Minv @ J.T)
        Nc = np.eye(len(q)) - A.T @ np.linalg.inv(A @ Minv @ A.T) @ A @ Minv

        # 基座扰动补偿
        d_hat = self.bmdo.estimate(q, dq)

        # 任务空间阻抗（含 J̇q̇ 与基座加速度前馈）
        e = x_r - self.robot.ee_pose()
        de = dx_r - J @ dq
        F_cmd = M_d @ (ddx_r - Jd @ dq) + D_d @ de + K_d @ e + F_ext - d_hat

        # CoM / 倾覆 CBF 稳定力
        F_stab = self.com_cbf(q, dq)
        tau = self.robot.S.T @ (Nc.T @ (Jbar.T @ F_cmd)
                                + self.robot.J_stab.T @ F_stab)
        return tau
```

```python
class CognitiveAdaptiveBudget:
    def __init__(self, base_budget, exc_energy=1.0, adapt_rate=500,
                 param_dim=5, cert_freq=100, tube_max=0.1):
        self.base = base_budget
        self.B_exc = exc_energy

        self.B_dim = param_dim
        self.B_cert = cert_freq
        self.B_tube = tube_max
        self.mode = 'full_adapt'
        self.exc_used = 0.0

        return 0.5 * np.log(np.linalg.det(np.eye(len(P_theta))
                                          + P_theta / sigma_y**2))

    def adapt_allowed(self, P_theta, U_mel, gamma):

        cost = 0.2 * self.exc_used / max(self.B_exc, 1e-6) \

            self.mode = 'robust_fixed'
        if self.mode == 'robust_fixed' and gamma < 0.02:
            self.mode = 'pure_conservative'
        return self.mode in ('full_adapt', 'prior_guided')

    def consume_excitation(self, energy):
```

```python
class ThreeLayerArchitecture:
    def __init__(self, mel, dms, usr, aic, sat, wbmm, budget):
        self.sem = SemanticLoop(mel, dms, usr)
        self.adp = AdaptationLoop(aic, sat, self.sem)

        self.cache = {}

        if prior is not None:
            self.versions['prior'] += 1
            self.cache['prior'] = (prior, Theta_safe, x_r, time.time())

        prior, Theta_safe, x_r, ts = self.cache['prior']

            self.cache['adapt'] = (theta_hat, P, rho, time.time())
        return theta_hat, P, rho

    def realtime_tick(self, x_r, dx_r, ddx_r, F_ext):
        if time.time() - self.cache.get('adapt', (0,0,0,0))[3] > 0.05:
            theta_hat, rho = self._conservative_expand(self.cache['adapt'])
        else:
            theta_hat, P, rho, _ = self.cache['adapt']
        tau = self.rt.step(x_r, dx_r, ddx_r, F_ext, theta_hat)
        self.versions['rt'] += 1
        return tau
```
