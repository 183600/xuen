# 第 11 轮（新灵感循环第 2 轮；本轮灵感：「共情表达」×「强化学习训练」）
> **基线**：第 10 轮 MetricVoiceGauge-STF-NRB-LS（定义 540–548；引理 87–91；实验 E571–E590）。
> 本轮纪律：**可校准共情 + 可证学习**。两个灵感分别治理 v10 的两笔债：**表达债**（系统能披露规范、能报告证书，却不建模人的内部状态；"语音披露"是单向广播，不是共情；上轮最大风险里"对抗语义欺骗"之所以难，恰恰因为根本没有一个可校准的人模）与**学习债**（策略仍是 MPC/手写 + OTL 调阈，没有原则性的策略改进；更隐蔽的是——证书里的 β 是**策略相关**的，一旦持续学习改变 π，旧校准会静默失效，而现有六个守卫没有一个能发现"证书对旧策略有效、对部署策略已失效"）。必须保持 v10 铁律：任一新模块失效 ⇒ 注入声明中立元，行为严格**等价**（控制面/表达面）或**支配**（安全面）于 v10，而非行为漂移。

## 0. 直觉与动机

**灵感 1（共情表达 → 把"懂人"从修辞变成校准通信）**
直觉：共情的对立面不是冷漠，而是**假装懂**。机器人无法真正感受；若把共情实现为固定话术（"我理解您的感受"），它既不可证、又极易滑向操纵。可工程化的其实是三件事：**（i）一个带不确定度的人内状态信念 b_t；（ii）一个只在该信念可蕴涵时才允许说出口的表达集合；（iii）一个目标不是"让人更信任"而是"让人对机器的信任 τ 与机器真实可靠度 r 对齐"的校准目标。** 关键翻转：**共情不是提高信任，而是校准信任**——过度信任（over-trust）本身就是安全危害（人放松监督、把超出机器人能力的事交出去、忽略告警）。于是表达被形式化为"在真话约束下最小化 |τ−r| 的通信策略"：与 NRB 的规范表同构（新增 ν-EMP 规范），与 STF 的地标图天然衔接（人是带语义与同意标志的特殊地标）。并且**表达面与控制面隔离**：共情只通过改变人的行为分布产生一个有界扰动 ε_d，绝不进入控制增益；失效即静默，严格退回 v10。

**灵感 2（强化学习训练 → 把"变强"从冒险试错变成带证书的策略改进）**
直觉：v10 证书藏着一个**策略相关性**：β_STF 是在 π_v10 的 rollout 分布上标定的；RL 一旦更新 π，状态访问分布与模型误差都变，旧 β 对新 π 的覆盖不再自动成立。所以"训练"不能只是"多跑梯度"，而必须是**证书相对策略**的：训练只在仿真/离线进行并用安全屏蔽（shield），部署前用高置信下界（HCOPE）证明任务改进、用上置信界证明安全代价不升，并显式度量策略行为距离 d_beh 与状态分布漂移 δ_shift；二者任一越界就重标定或回滚。共情奖励必须**字典序从属于**安全与任务（安全 ≻ 任务 ≻ 共情），否则必然被 Goodhart——学出"最会安慰人但最不安全"的策略。核心创新是**认证策略改进（CPI）**与**校准–策略联合版本（CPCV）**：策略、β、人模、规范阈值原子化同版本；混合版本本身即失效。

**两者咬合**：EBM 给"人现在怎样"的可校准信念，EEP/TNM 把它变成真实且不操纵的表达，RTM 监控"人被影响后是否过度信任"，CRT 在证书屏蔽下改进策略，CPCV 保证策略一变证书随之重证。合起来把 v10 的**结构化信任证书**升级为**可归因、可学习、可回滚的闭环证书** Ĉ_t^∘ = (ĝ_min, ê_max, γ̂_grasp, β_STF(π)+ε_d, n_t, b_t, v_π)。

## 1. 研究问题（轮次升级版）

- **Q1（可校准共情）**：如何把共情表达形式化为"带不确定度的人内信念 + 真话蕴涵门 + 信任校准目标"，使 |τ−r| 下降、表达不进入物理控制（只留 ε_d 扰动）、失效即静默，且可证不产生操纵（引理 92–93）？
- **Q2（可证学习）**：在证书依赖策略 β(π) 的前提下，如何用屏蔽训练 + HCOPE + 行为/漂移预算，使部署策略的失效率 PAC 支配于 v10（≤ v10 + ε_s），并让策略/校准/人模原子同版本（引理 94–95）？
- **Q3（共适应）**：共情改变人、RL 改变机，二者的联合漂移如何检测与界定？RTM + 原子回滚能否把共适应回路的稳态风险压在 v10 包络内（引理 96）？

## 2. 设计原则（在 P13–P15 基础上新增 P16–P18）

**P16 共情可校准律（Calibrated Empathy, EBM/EEP）**
共情 = 信念外化，不是情绪表演；任一句表达必须被 b_t 蕴涵（真值蕴涵门）；优化目标是信任校准 |τ−r| 而非信任 τ；表达面与控制面隔离，对控制只允许有界扰动 ε_d，绝不作控制增益。

**P17 真话不操纵律（Truthfulness & Non-Manipulation, TNM）**
禁止无根据的内部状态断言（如"我感受到你的痛苦"）；信念熵 H_t 超阈必须强制披露不确定；禁止利用情绪促成服从；违反即阻断表达（静默是安全中立元）。"共情失败"的首选退化是沉默，而不是更热情的话术。

**P18 证书相对策略律（Certificate-Relative-to-Policy, CPCV）**
β、τ_sem、人模均以策略 π 为参数（β = β(π)）；策略/人模变更必须落在行为距离 d_π 与漂移 δ_shift 预算内（Lipschitz 继承），否则重标定或回滚；安全永远字典序优先，绝不进入 RL 目标函数，只能作为屏蔽与约束。

## 3. 与基线的接口（如何退化）

- EBM 失效（信念超时/校准失败/人模不可用）⇒ b≡均匀（unknown）、H=∞ ⇒ 仅 inform-only 模板（等价 v10 语音披露），控制等价 v10；
- EEP 失效 ⇒ 静默（无共情），等价 v10；TNM 失效（过滤器不可用/超时）⇒ 阻断全部表达，等价 v10；
- RTM 失效 ⇒ 关闭共情，等价 v10；CRT 失效 ⇒ 保持 π_v10、不更新，等价 v10；
- CPCV 失配（策略/β/人模哈希不一致）⇒ 回滚至上一认证原子版本；无认证版本 ⇒ v10；
- STF/NRB/AC/ID/MW/v8 失效 ⇒ 完全沿用 v10 六级退化链（K=1、Π_r、中立元注入等原样）。

## 4. 预期贡献

1. **可校准共情**：信念–表达–校准三分，真话门 + 不操纵目标，把"共情"从不可证话术变成可审计通信（引理 92–93）；首次把 over-trust 定义为安全对象而非体验指标；
2. **可证学习**：屏蔽训练 + HCOPE + 校准继承 + 原子版本，使持续 RL 不静默破坏证书（引理 94–95）；
3. **共适应治理**：RTM 检测过度信任 + 原子回滚，界定"人–机联合漂移"的安全包络（引理 96）；
4. **E591–E610** 覆盖信念校准、真话审计、信任校准、过度信任、屏蔽训练、认证改进、校准继承、共适应长跑、对抗情绪欺骗与综合竞赛。

## 5. 本轮最大风险

**一句话**：共情诱导的人行为改变与 RL 诱导的策略改变会合成一个**共适应正反馈**——每一方都只检验自己那半边的假设（信念仍校准、表达仍真话、策略对自己的人模仍在改进），却没有人检验"被自己的共情塑造过的人 + 为这种人优化的策略"这个联合不动点是否仍在 v10 的物理安全包络内；于是系统在"更懂人、更聪明"的表象下，把 v10 已收敛的隐性失效升级为闭环共适应失效。

## 1. 符号体系增量（定义 549–558）

**新增定义 549（人内状态信念）** b_t 由 EBM 在观测特征 z_t（STF 人类地标、面部/语调/姿态/上下文/任务结果/历史）上做贝叶斯更新；S_H 六维如符号表。校准要求 ECE(b) ≤ ε_cal = 0.05（E591）。EBM 输出 (b_t, H_t)；H_t 高时不禁止理解，但禁止**断言式**表达。

**新增定义 550（共情行为与表达）** 每个 a∈A_E 有模式 (intent_a, proposition_a, tone_a)。表达 e_t=(a,u_t)，u_t 为语音/副语言/手势。区分**断言式**（claims about world）与**仪式式**（apologize/ack 的语用行为）：断言式须 ent≥1−δ_ent；仪式式须有真实事件接地（确实发生失败/伤害）且不得携带不受支持的内部状态断言（禁止"I feel your pain"式话术）。

**新增定义 551（真值蕴涵与非操纵谓词）** ent(a,b_t) = P_{b_t}(proposition_a)。Manipulative(a; b_t, r_t) ⇔ 该表达的顺从增益**经由**把 τ 抬到 r 之上实现，即 Δτ>0 ∧ Δr≤0 ∧ Δ|τ−r|>0。TNM 只放行 ¬Manipulative 的行为；{disclose_unc, defer} 恒可放行（它们只能降低过度信任）。硬禁止：无接地内部状态断言、伪装确定性、以情绪换取服从。

**新增定义 552（信任校准目标）** J_cal(π_E)=E[|τ_{t+1}−r_t|]，实现上以人类可靠性预测的 Brier 分数评分（严格 proper，信息只会改善期望分数，不会被"多说话"刷分）。π_E 选择使期望 J_cal 下降最大的行为，约束为 TNM 与 NRB（含 ν-EMP：不欺骗、不操纵、熵高必披露、不情绪胁迫）。**目标绝不含"提高参与度/好感度"项。**

**新增定义 553（表达–控制隔离与扰动界）** 设人策略 π_H 在表达 e 与无表达 ∅ 下的 TV 距离 ∀s: TV(π_H(·|s,e),π_H(·|s,∅)) ≤ ε_emp。则表达诱导的约束违背概率变化 ≤ L_H·ε_emp =: ε_d。证书统一使用 β^∘ = β_STF + ε_d。表达**不是**机器人策略的输入；它只通过 ε_d 进入风险预算。RTM 若判定 ε_emp 假设被突破，立即关闭共情（回到 ε_d=0 的 v10 包络）。

**新增定义 554（安全屏蔽训练）** 训练对象为 CMDP (S,A,P,r_task,c_s,γ)。Sh(s,a)=1 ⇔ 该动作通过 v10 证书检查与 hard 规范检查（与中块守卫同源）。训练中 Sh=0 的动作被替换为安全停驻/defer 并掩码（不学习为"安全"）；真机永不探索，只执行认证后的 π'。共情奖励 r_E 仅进入表达策略训练，且字典序低于 c_s 与 r_task。

**新增定义 555（认证策略改进 CPI）** π' 相对 π 认证，当且仅当同时满足：
(i) HCOPE 的性能改进下界 LCB_α(ΔJ) ≥ 0（α=0.05）；
(ii) 或 d_beh(π',π) ≤ d_π=0.1（TV），或完成全量重标定且 β 覆盖 ≥1−ε_β；
(iii) 状态漂移 Δ_SH ≤ δ_shift=0.2（T 场与密度比联合度量）；
(iv) 安全 PAC：UCB_α(unsafe(π')) ≤ unsafe(π) + ε_s，ε_s=0.01。
四条全过才部署；否则保持 π。

**新增定义 556（校准–策略联合版本 CPCV）** v=(h_π,h_β,h_H,h_N) 为策略、校准、人模、规范表的内容哈希。版本在块边界**原子切换**；任一活跃组件哈希不一致 ⇒ 回滚上一认证 v 并记 Λ。禁止"新策略 + 旧 β"的混合版本上线。

class EmpathicExpressionPolicy:
    def __init__(self, acts=A_E, delta_ent=0.1):
        self.acts, self.delta_ent = acts, delta_ent

    def choose(self, b, H, r, tau_hat, ctx, nrb):

        feasible = [a for a in self.acts
                    if self.tnm_ok(a, b, H, ctx)]

            j = abs(t_next - r) + 0.1 * (-agency(a, ctx))
            scored.append((j, a))

# IP-364 CertifiedRLTrainer：离线/仿真屏蔽训练 + 认证改进
class CertifiedRLTrainer:
    def __init__(self, shield, d_pi=0.1, delta_shift=0.2, eps_s=0.01):
        self.shield, self.d_pi = shield, d_pi
        self.delta_shift, self.eps_s = delta_shift, eps_s

    def train(self, env_sim, pi_init):
        pi = pi_init
        for batch in env_sim:
            # 定义 554：Sh=0 → 安全停驻掩码，绝不学习"违规也安全"
            safe_actions = [a for a in batch.actions if self.shield(batch.s, a)]
            pi = constrained_update(pi, batch, safe_actions,
                                    safety_priority_before_task_and_empathy=True)
        return pi

    def certify(self, pi_new, pi_old, evaluator):
        # 定义 555：四条全过才部署
        lcb = hcope_lower_bound(evaluator, pi_new, pi_old, alpha=0.05)
        beh = behavioral_distance(pi_new, pi_old)
        shift = state_shift_budget(evaluator, pi_new)
        ucb = safety_upper_bound(evaluator, pi_new, alpha=0.05)
        if lcb < 0:                       return None, 'no_improvement'
        if beh > self.d_pi and not recalibrate_full(pi_new):
                                          return None, 'behavior_shift'
        if shift > self.delta_shift:      return None, 'distribution_shift'
        if ucb > evaluator.unsafe(pi_old) + self.eps_s:
                                          return None, 'safety_budget'
        return pi_new, 'certified'

class ReciprocalTrustMonitor:

        self.tau_ot, self.n_ot, self.bad = tau_ot, n_ot, 0

## 4. 推导

**引理 92（真话共情的校准改进与表达–控制隔离）** 设 (A1) b_t 经 E591 校准，ECE≤ε_cal；(A2) TNM 放行集满足 ent(a,b_t)≥1−δ_ent，且高熵表达必披露不确定；(A3) 人策略漂移 TV≤ε_emp，风险 Lipschitz 常数 L_H。则任一放行共情行为：(i) 其断言的可靠性命题与 b_t 的偏差 ≤δ_ent（不产生无根据确定性）；(ii) 以 Brier 分数计，期望校准损失不升（信息增益对 proper scoring 单调），即 E[J_cal] 非增；(iii) 对物理证书的影响 ≤ε_d=L_H·ε_emp，加入 β^∘ 后 v10 引理 82/87 的停车不变式原样成立。证明：(i) 由 ent 定义与门；(ii) proper scoring 的信息不等式；(iii) 表达不在动作路径，唯一耦合是人策略漂移，TV→风险由 L_H Lipschitz 给界。∎

**引理 93（不操纵）** 在 TNM 下，任何放行的断言式表达都无 `Δτ>0 ∧ Δr≤0` 的顺从增益；{disclose_unc, defer} 只可能降低 τ 或提高 r 的可知性。因此 J_cal 的最优行为在放行集内不含操纵：若最优行为靠抬高 τ 越过 r 获益，则 |τ−r| 上升、目标变差，矛盾；若靠真实提高 r 的可知性获益，则是校准而非操纵。∎

**引理 94（认证策略改进的安全支配）** 设 π' 通过定义 555 四条件。则 unsafe(π') ≤ unsafe(π_v10) + ε_est + L_beh·d_beh + L_s·δ_shift ≤ unsafe(π_v10)+ε_s，其中 ε_est 由 HCOPE/UCB 的 PAC 项吸收。证明：三角形分解"旧策略风险 + 估计误差 + 行为差 + 分布差"；四条件逐项给界。故部署策略失效率 PAC 支配 v10。∎

**引理 95（策略漂移下的校准继承）** 若前向模型误差对状态访问分布 L_f-Lipschitz、T 场有界，则 |β(π')−β(π)| ≤ L_β·d_beh(π',π) + L_s·δ_shift。故当 d_beh、δ_shift 落在预算内且右侧 ≤ 证书余量时，旧校准以加性松弛继承、无需重标；否则必须全量重标定（定义 555(ii)）。证明：β=β_base+λ·sup T 对 rollout 分布的依赖经误差 Lipschitz 与三角不等式给界。∎

**引理 96（共适应回滚的安全包络）** 检测延迟 ≤N_ot 帧内，人策略累计漂移 ≤N_ot·ε_emp（每步 TV 界），因此瞬时风险 ≤unsafe(v10)+ε_d+N_ot·δ_OT；RTM 触发后表达强度单调下降（放行集只减不增），持续超阈则关共情并回滚 v10，人策略恢复平稳，稳态风险回到 ≤unsafe(v10)+ε_d。证明：由定义 557 的单调降级与 CPCV 原子回滚；累计项用 TV 的次可加性。∎

## 8. 本轮最大风险

**一句话**：共情诱导的人行为改变与 RL 诱导的策略改变会合成一个**共适应正反馈**——EBM 只保证"我对人的信念仍校准"、TNM 只保证"我说的话仍真"、CPI 只保证"新策略对我训练时的人模仍在改进"，三者都成立，却没有人检验"被自己的共情塑造过的人 + 为这种被塑造的人优化的策略"这个**联合不动点**是否仍在 v10 的物理安全包络内；一旦人因过度信任而放松监督、策略又恰好针对这种放松优化，各模块的局部证书全部通过，系统却在"更懂人、更聪明"的表象下把 v10 已收敛的隐性失效升级为闭环共适应失效，且比 v10 更难归因（责任分散在表达、学习、人模三处）。
