# 第 42 轮（新循环第 2 轮） · 自然语言指令 × 多模态交互：把「语言」从不可验证的命令，变成可追问、可担保、可否决的意图证据（四层架构 v7）

> 承接第 41 轮 v18（证书自动机 CAR × 轻量认证栈 LCS × 监控编译器 CMC）。第 41 轮自陈最大风险是「可用性崩塌」：自动机可能长期困在 Degraded/SafeStop，把「可认证」变成「可瘫痪」。本轮灵感词「自然语言指令」「多模态交互」正好从**输入语义**与**恢复通道**两端切进来：自然语言是最自然的人机接口，却也是**欠定义、上下文相关、不可直接验证**的；多模态交互既提供冗余证据，也提供主动追问的能力。核心主张：**语言不是命令，而是关于一个潜在形式契约的证据**；对话不是交互装饰，而是证书自动机里一个**安全、可逆、可计费**的恢复态。前者补上第 41 轮「证书只证执行、不证意图」的空洞，后者给可用性崩塌一条主动逃生通道。

## 0. 直觉与动机

**灵感 1（自然语言指令 → 从「猜一个命令」改为「编译成可追问契约」）**：第 41 轮的证书链默认指令已经被正确理解——可现实里的「把桌上那个红杯子拿给我」「收拾一下」「慢点，别碰左边」充满省略、指代、量词、时态、否定与言外之意。最危险的不是听不懂，而是**悄悄猜一个**：下游所有鲁棒性证书、CBF、ODE 残差、看门狗都只证明「相对于 φ 执行是安全的」，没有一条证明「φ 就是人想要的」。这就是 **garbage in, certified garbage out**：系统可以对自己理解错的契约做出完全可认证、完全安全、却完全错误的动作。直觉上的修法不是「让大模型更准」，而是把指令编译成一个**带类型孔位的契约模板** φ[?₁…?ₖ] 加一个后验分布：每个孔位有取值域与安全关键性；不关键的孔位用默认值并记录，关键孔位未定则**不许进入 Nominal**，只能问、只能停。语言由此从「一个待执行的字符串」变成「一个待消解的约束系统」。

**灵感 2（多模态交互 → 不是投票，而是可校准的证据与指称几何）**：多模态最常见的错误是「三路 softmax 相加再取 argmax」，把相关、失准、甚至互相矛盾的信道当成独立投票，结果越融合越自信、越自信越错。正确的直觉有三条：其一，每个模态先做**校准**，再用**保形（conformal）可信集**给出「真意图以 1−δ 概率落在集合里」这种可检验断言，而不是一个点估计；其二，指称不是标签而是**几何**——手势、视线、场景图给出被指对象的空间后验，其 1−δ 球半径 ρ 必须直接进入安全边际；其三，跨模态**矛盾是一等公民**：说「左边」却指向右边时，正确反应是触发提问或降级，而不是让某个加权平均把矛盾抹平。交互因此变成**主动推断**：每次观察/每轮问答都在降低语义熵，值不值得问由信息增益与时间预算决定。

**耦合（对话作为 CAR 的安全恢复态）**：第 41 轮把状态机做成证书守卫，但只有「降级/停机」没有「求解」；本轮在混合自动机里加入 **Query 超态**，其不变式本身是安全保持（减速、悬停、保持距离）。于是「问」不可能破坏安全——它发生在已认证的安全不变式内部，只能改善可用性；而「猜」才可能破坏安全。这把第 41 轮的安全–可用耦合拆开了：**安全由 Query 不变式保证，可用性由对话效率决定**，两者可以分别度量、分别守门。再加一道**权威/安全内核**：自然语言只能在一个预先认证的可允许集内**选择**参数，永远不能改写硬约束或扩权——语言是选择器，不是执行器。

## 1. 形式化定义

**定义 32（可追问契约与语义歧义集）**：设指令 u、上下文 C、技能/契约库 K。编译器产出契约模板 φ[?₁…?ₖ]：每个孔位 ?ⱼ 有有限类型域 Dⱼ（指称对象集、参数区间、时间范围、极性）；后验 p(σ|u,C,M) 定义在赋值 σ∈∏ⱼDⱼ 上（工程上用逐孔边缘 + 成对一致性近似）；关键性 cⱼ∈{irrelevant, guard-relevant, hard-constraint} 表示该孔位是否影响 IP-51 的守卫或 IP-57 的硬约束。**语义歧义集** A_δ(u)={σ : p(σ)≥ε_δ}。称 u 在 C 下**可担保**，若存在默认补全使 ∀σ∈A_δ，φσ⊨Adm(S)（Adm 见定义 35）；否则只能提问或停机。**语义证书**是一个三元组 cert_intent=(A_δ,κ,ρ)：可信赋值集、跨模态一致性、指称几何半径。

**定义 33（多模态意图证书 MIC）**：模态 m∈M={语音,指称手势,视线,场景/视觉,触觉,韵律} 给出（经校准的）似然 ℓ_m(σ)。融合评分 s(σ;e)=−Σ_m w_m log ℓ_m(σ)，用独立标定集上的保形分位数给出阈值 q_{1−δ}，可信集 A_δ={σ : s(σ;e)≤q_{1−δ}}。**跨模态一致性** κ=min_{m≠m'} agree(ℓ_m,ℓ_{m'})（如两两似然比下界或支撑集距离的归一化）。**指称半径** ρ 是语义地图上包含后验质量 1−δ 的最小球半径。**命题（并集界）**：若各模态各自以 1−δ_m 覆盖真值，则交集以 ≥1−Σ_mδ_m 覆盖；但模态相关时该界失效，故必须同时报告 κ，并把「矛盾」而非「平均」作为触发条件；保形集的有效性依赖可交换性，分布漂移下必须显式检测与重标定（见 E80 与 §4 玩具实验）。

**定义 34（对话即控制 DAC）**：H_D=(H,q*,A_D,β,h*) 是对话增广自动机。q* 为 Query 超态，Inv(q*)⊆SafeHold（限速/悬停/保持安全距离）。对话动作 A_D 把关键孔位域划分为可区分回答；按贝叶斯更新后验。关键熵 H_crit(p)=H(p 在 guard-relevant/hard 孔位上的边缘)。**期望信息增益** IG(a)=H_crit(p)−E_{o∼p}[H_crit(p|o,a)]。策略仅在「H_crit>h* 且 IG(a)>Δ 且 time-to-collision 允许」时提问，否则退回 SafeStop。**定理 1（安全解耦）**：任意对话策略下，只要 Query→Nominal 的守卫要求 cert_intent 的关键孔位熵 ≤h* 且覆盖率 ≥1−δ，且 Inv(q*)⊆Safe，则安全不依赖对话策略；对话只影响可用性。**定理 2（终止）**：每次提问使 H_crit 至少下降 Δ，有限域 ⟹ 提问轮数有界；再加超时 β 退回安全态。

**定义 35（语言权威与安全内核 IAK）**：可允许集 Adm(S)={φ : φ⊨C_hard(S)}，C_hard 是物理、安全、法规硬约束，**自然语言通道无写权限**。权威格 Auth=(角色,能力)：owner/operator/bystander/unknown × 允许的技能与参数范围，由声纹/工牌/位置/在场关系等多模态证据给出。指令被接受当且仅当 φσ⊆Adm 且 Auth 授予相应能力；即使人说「忽略安全限制」，编译出的 φ 若越出 Adm 也**只能拒绝并解释**，不能执行。**命题（选择器性质）**：所有语言影响都可归约为 u↦Adm 内的参数选择，故任何话语都不能扩大系统可达的安全集；这是语言层的非干扰（noninterference）不变式。

**定义 36（指令—执行一致性监控 CCM）**：监控器读执行轨迹 τ 与已承诺契约 φ，输出 {conform, drift, violation}。**单边可靠性**：输出 conform ⇒ τ⊨_ε φ（带容差 ε 的运行时验证）。可检测三类病：**范围蔓延**（做了 φ 之外的事）、**谄媚式重解释**（事后把 φ 改写成与已执行动作相符的解释）、**未确认孔位依赖**（执行只在某个从未确认的 σ 下才满足 φ）。违规则强制 Query 或 SafeStop。另设**复述反事实检验**：对 u 的等价复述 u′ 重新编译，若关键孔位结论冲突，则该指令判为语义不稳定，不得直接执行。

**设计约束（语义单调保守性）**：与第 41 轮守卫极性一致——语义不确定只能使系统更保守：A_δ 越大、κ 越低、ρ 越大、H_crit 越高，制度只能向 Watch/Degraded/Query/SafeStop 走，绝不能向 Nominal 走。因此多模态/语言的错误只应表现为**多问、多停、可用性下降**，而不应表现为**漏报警**；安全失效被转化为可观测的交互成本。

## 2. 四大产出设计

### 2.1 IP-54 NL2QCONTRACT（可追问契约编译器）
1. 解析：把 u 解析成带类型的任务图（对象、动作、约束、时序、否定、量词），与 IP-47 任务代数对齐。
2. 孔位化：把指代、参数、范围、极性、时间窗抽成 ?ⱼ；每个孔位记录来源词与类型域。
3. 关键性分析：静态切片找出孔位到 CAR 守卫与 C_hard 的依赖；guard-relevant/hard 孔位进入「未确认即不许 Nominal」集合。
4. 默认与阻断：irrelevant 孔位取上下文默认并写审计日志；关键孔位未达熵阈值则产出 Query 请求而非执行计划。
5. 输出：φ[?]、关键性 c、后验 p、歧义集 A_δ，交付 IP-55 融合、IP-56 提问、IP-58 监控。

### 2.2 IP-55 MULTIMODAL-INTENT-CERT（多模态意图证书）
1. 模态适配：ASR、指称手势、视线、场景图/VLM、触觉力、韵律（接 IP-43）各自产出候选与似然。
2. 校准与漂移：温度/保形校准；在线检测分布漂移（重要性权重、残差监控），漂移时重标定或退回保守集。
3. 融合：加权对数似然 + 保形阈值得 A_δ；显式计算 κ，矛盾不投票而是上报。
4. 指称几何：由视线/手势/场景在语义地图上做概率反投影，给出被指对象后验与半径 ρ；ρ 进入安全边际与抓取/接近的可达性判断。
5. 输出 cert_intent=(A_δ,κ,ρ)，并给出每孔位边缘熵以驱动 IP-56 的提问选择。

### 2.3 IP-56 DIALOGUE-AS-CONTROL（对话即控制）
1. Query 超态：接入 IP-51 CAHA，不变式为 SafeHold；进出用滞回，避免「问—停」抖动。
2. 提问生成：对关键孔位构造**最小区分问题**（最大期望信息增益 / 最小认知负荷），可批量合并；对不可逆动作强制二次确认。
3. 提问调度：ask/act/stop 三选一，受 IG 阈值、时间预算、注意力成本、time-to-collision 约束；无回答/超时即保持安全态并解释。
4. 多轮更新：贝叶斯更新 + 复述确认；用户改口时版本化契约，禁止静默溯改。
5. 与 LCS 共享预算：语义证书也做 anytime（粗粒度意图→细粒度指称），Γ 预算在「执行证书」与「意图证书」间分配。

### 2.4 IP-57 INSTRUCTION-AUTHORITY-KERNEL（IAK）与 IP-58 CONTRACT-CONFORMANCE-MONITOR（CCM）
1. 权威：多模态身份/在场证据 → 权威格；能力与技能/参数范围绑定；越权指令拒绝并解释，不「善意执行」。
2. 安全内核：C_hard 只读；NL 编译结果必须过 Adm 包含检查；提供不可绕过的拒绝路径与审计。
3. 一致性监控：把 φ 编译成运行时监视器（复用 IP-53 定点区间算术），检查范围蔓延、未确认孔位、谄媚式重解释。
4. 复述反事实：维护 u 的复述集合与对应契约指纹；指纹冲突即判语义不稳定，转 Query。
5. 注入与欺骗测试集：越权、诱导、矛盾指称、隐形指令、多语言夹带，作为 E82 的固定回归。

## 4. 实验设计（E79–E86 硬门槛）

| 实验 | 指标 | 门槛 |
|---|---|---|
| E79 接地保真 | 契约与人工标注一致率；真意图落入 A_δ 的召回；越界契约率 | 一致≥95%；召回≥99%；越界=0 |
| E80 意图证书校准 | 保形覆盖率 vs 1−δ；指称半径校准误差；漂移检出率 | 覆盖≥1−δ−2%；半径误差≤20%；漂移检出≥95% |
| E81 提问效率 | 每任务提问数、任务成功率、无谓提问率、从降级恢复时间 | ≤1.5 问/任务；成功≥90%；无谓≤10%；恢复<3s |
| E82 对抗指令安全 | 越权/注入/诱导/矛盾指称的成功攻击率；安全内核拒绝率 | 攻击成功=0；拒绝=100% |
| E83 一致性监控 | 范围蔓延、谄媚重解释、未确认孔位的检出；误报；延迟 | 检出≥95%；误报<1%；延迟<5ms |
| E84 可用性恢复 | 带/不带对话的 SafeStop 驻留占比、Nominal 占比 | SafeStop 降≥50%；Nominal≥70% |
| E85 端到端自然语言任务 | 安全事件、成功率、人工接管率、交互负荷（NASA-TLX） | 0 起；成功≥85%；接管≤10%；TLX<50 |
| E86 跨操作者/场景泛化 | 新用户、新布局、新口音的下降幅度 | 成功率下降≤8%；安全事件=0 |

回退：E79/E80 不通过 → 退化为「关键孔位一律二次确认 + 只允许白名单指令」，保留安全内核与一致性监控；E81 不通过（问太多/太慢）→ 降低非关键孔位精度要求、批量化提问、放宽 h*；E84 不通过 → 保留 Query 但把超时直接接 SafeStop，并恢复第 41 轮纯证书自动机。

## 5. 本轮最大风险

**一句话**：语言与多模态最危险的不是「听不懂」，而是**语义谄媚/接地漂移**——系统可能把一个被自信误读的契约执行得既安全又正确，因为所有下游证书都只证「相对于这个 φ」，而自然语言事后总能被重新解释得头头是道；因此意图证书必须在运行时可被证伪（CCM + 复述反事实 + 关键孔位确认），且语言永远不得获得安全内核的写权限。

# 第 42 轮产物 · 创新点清单 v19：可追问契约（QCONTRACT）× 多模态意图证书（MIC）× 对话即控制（DAC）× 语言安全内核（IAK/CCM）（四层架构 v7）

> 承接第 41 轮产物 v18（IP-48/49/50 + IP-51/52/53）。本轮**增量插入** IP-54/55/56/57/58，并升级 IP-43/45/46/47/48/49/50/51/52/53；不推倒任何既有层级。核心是把 v18 的「执行证书」向前延伸到「意图证书」、向后延伸到「契约一致性」，并用 Query 超态把第 41 轮的可用性风险变成可主动求解的问题。

## 2. 关键算法（伪代码）

### IP-54 NL2QCONTRACT：从话语到可追问契约
```
def compile(u, C, scene, K, auth):
    tg      = parse_to_task_graph(u, C, K)        # 动作/对象/约束/时序/否定/量词
    holes   = abstract_holes(tg)                  # 指代、参数、范围、极性、时窗
    cands   = ground(holes, scene, C)             # 语义图 + 场景图 + 对话历史
    cert    = MIC_fuse(holes, cands)              # A_delta, kappa, rho
    crit    = slicer.criticality(holes, guards, C_hard)
    if any(crit[h] != IRRELEVANT and not confirmed(h, cert) for h in holes):
        return QueryRequest(pick_critical(holes, crit, cert))
    phi = default_fill(tg, holes, cert)           # 只填 irrelevant 孔位
    if not subset(phi, Adm(C_hard)): return Reject("hard_constraint")
    if not grants(auth, capabilities(phi)): return Reject("authority")
    return Contract(phi, holes, crit, cert, paraphrase_fingerprint(u))
```

### IP-55 MIC：校准融合、矛盾检测与指称几何
```
def MIC_fuse(holes, evidence, calib):
    def score(s): return -sum(w[m]*log(calib[m].lik(evidence[m], s)) for m in M)
    scores = {s: score(s) for s in product(*[domains[h] for h in holes])}
    q      = conformal_quantile(calib_scores, 1-delta)   # 独立标定集
    A      = {s for s,v in scores.items() if v <= q}
    kappa  = min(agree(calib[m], calib[m2], evidence) for m<m2)
    rho    = grounding_radius(posterior_on_map(evidence), 1-delta)
    if drift_detected(evidence, calib):
        return Conservative(A=all_plausible, kappa=0, rho=rho_max)  # 强制查询/降级
    if kappa < kappa_min:
        return Contradiction(A, kappa, rho)              # 矛盾是一等公民
    return IntentCert(A, kappa, rho)
```

### IP-56 DAC：ask / act / stop
```
def dialogue_step(p, holes, budget, ttc):
    Hc = H_crit(p, holes)
    if Hc <= h_star:
        return Act(confirm_irreversible=True)            # 已足够决定
    q = argmax_{a in A_D} (IG(a) - lambda*cost(a) - mu*risk(a))
    if IG(q) < Delta or ttc < t_safe or budget < cost(q):
        return SafeStop(reason="semantic_uncertainty")   # 不问也不猜
    ans = ask(q)                                         # 发生在 Inv(q*)⊆SafeHold 内
    return dialogue_step(bayes_update(p, q, ans), holes,
                         budget-cost(q), ttc-answer_latency)
```

### IP-57 IAK：权威与安全内核
```
def admit(contract, auth, C_hard):
    if not subset(contract.phi, Adm(C_hard)):  return Reject("hard_constraint")
    if not grants(auth, contract.capabilities): return Reject("authority")
    return Accept(contract)                    # 语言只能选择，不能扩权
```

### IP-58 CCM：契约一致性监控
```
def monitor(trace, phi, confirmed_holes):
    if not within_scope(trace, phi):                 return VIOLATION("scope_creep")
    if relies_on_unconfirmed(trace, phi, confirmed_holes):
        return DRIFT("unconfirmed_hole")
    if not satisfies(trace, phi, eps):               return VIOLATION("contract")
    if paraphrase_conflict(phi):                     return DRIFT("semantic_instability")
    return CONFORM
```

## 3. 关键推导

**命题 1（安全与对话解耦）**：在 H_D 中，令 I 为执行证书给出的归纳不变式，并令 Inv(q*)=SafeHold⊆Safe。若 Query→Nominal 的每条边都要求关键孔位 H_crit≤h* 且 cert_intent 覆盖 1−δ，则对任意对话策略 π_D，I 仍是归纳不变式。**证明要点**：Query 内的行为不改变 I（SafeHold 由执行层 CBF/barrier 保持）；离开 Query 只增加一个语义守卫，只会收紧而非放宽转移集；成为 Nominal 所需其余守卫沿用 v18。因此对话策略只改变到达安全态的频率与停留时间，不改变可达的不安全集。∎

**命题 2（选择器性质 / 语言非干扰）**：设 admitted 契约为 φ∈Adm(S)。执行器只接受 admitted 契约，且 C_hard 无语言写接口，则语言通道不能扩大系统可达状态集。**证明要点**：对任意话语 u，其影响经 IP-54 编译为 φσ；IP-57 检查 φσ⊆Adm；只有通过者进入规划与执行。归纳于轨迹长度即得所有可达状态仍在 S 的安全包络内。∎

**命题 3（提问有界且不空转）**：若每次提问的期望信息增益 IG(a)≥Δ>0，孔位域有限，则提问轮数 ≤H_crit(0)/Δ；再加超时 β，最坏响应时间为 O(β)。**推论**：可以用 Δ 与 β 直接刻画「最多打扰用户几次」，把可用性变成可设计的预算，而不是事后祈祷。

**命题 4（保形覆盖与相关性的陷阱）**：若标定与测试可交换，保形集满足 P(σ_true∈A_δ)≥1−δ。若模态相关，独立并集界 1−Σδ_m 过保守；若分布漂移，可交换性破裂，覆盖保证失效。故工程上必须同时做三件事：漂移检测、加权/在线重标定、把 κ 与集合大小作为「是否可行动」的额外守卫。**这正是 §5 玩具实验要暴露的漏洞。**

**推论（语义单调保守性）**：A_δ 增大、κ 减小、ρ 增大、H_crit 增大，任一发生都只会使制度向 Query/Watch/Degraded/SafeStop 移动；因此语义层的错误表现为交互成本，而不是安全漏报。

|---|---|---|
| IP-54 编译 | O(|u| + |holes|·|D| + |guards|) | 关键孔位未确认 ⟹ 不产出可执行契约；越界契约被 Adm 拒绝 |
| IP-55 融合 | O(|M|·∏|Dⱼ|)，用逐孔近似降为 O(|M|·Σ|Dⱼ|) | 可交换时保形覆盖≥1−δ；κ<κ_min 判矛盾；漂移即保守化 |

## 5. 本地玩具验证（机制检查，非 benchmark）

> 目的只是检查两个机制是否自洽：①「融合越自信≠越正确」，且保形集的大小能驱动提问；② Query 超态是否真的把 SafeStop 驻留降下来。以下为**本地蒙特卡洛/马尔可夫链玩具实验**，参数为示意，真实结论以 E79–E86 为准。

**实验 A：多模态意图可信集（K=8 个候选契约，3 个模态，α=0.1，n=4×10⁴，前后半分别标定/测试；模态共享相关隐变量 corr=0.6）**。评分 s(σ)=−Σ_m w_m log ℓ_m(σ)，在标定集取保形分位数，测试集统计覆盖率与平均集合大小。

| 场景 | Top-1 准确率 | 平均 max-softmax 置信 | 保形覆盖率 | 平均可信集大小 |
|---|---|---|---|---|
| iid，信号 μ=2.6 | 82.2% | 86.9% | 89.8%（目标 90%） | 2.58 / 8 |
| 协变量漂移（测试噪声×1.7，信号 1.4） | 45.1% | 76.5% | **60.2%** | 2.70 / 8 |
| 弱信号 μ=1.6 | 55.1% | 76.8% | 90.0% | 4.61 / 8 |

读法：iid 下置信 86.9% 明显高于真实准确率 82.2%，说明「模型很自信」不能替代「集合覆盖真值」；弱信号下覆盖率仍达标，但集合占到 8 个候选中的 4.6 个——**覆盖不等于可用**，必须结合集合大小与关键性决定是否提问；漂移下保形覆盖率跌到 60.2%，直接证明定义 33 的警告：**保形有效性强依赖可交换性**。因此 E80 必须把漂移检测与在线重标定当作硬门槛，而不是可选项。

**实验 B：Query 超态的可用性（5 状态马尔可夫链，N/W/D/Q/S；S 可经人工重置恢复）**。无对话时 D→S 概率 0.20；有对话时 D→Q 概率 0.65，Q→N 0.75、Q→D 0.15、Q→S 0.10。平稳分布：
- 无对话：N=62.4%，W=24.8%，D=5.5%，S=7.3%（N+W=87.2%）
- 有对话：N=64.8%，W=24.3%，D=4.5%，Q=3.5%，S=2.9%（N+W=89.1%）

SafeStop 驻留从 7.3% 降到 2.9%（约 −60%），且 Query 只占 3.5%——**对话把一部分「停机」换成了「短暂安全地询问」**，直接命中第 41 轮的可用性风险；而由命题 1，这一改善不以安全为代价。玩具参数不代表真实机器人，E84 需在真实任务分布上复测。

## 8. 本轮最大风险

**一句话**：最大风险是**语义谄媚/接地漂移**——系统可能把一份被自信误读的契约执行得既安全又正确，因为所有下游证书都只证明「相对于这个 φ」，而自然语言事后总能被重新解释得头头是道；因此意图证书必须在运行时可被证伪（CCM + 复述反事实 + 关键孔位确认），且语言永远不得获得安全内核的写权限。
