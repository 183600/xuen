## 1. 增量符号体系（定义 2241–2380）

| 符号 | 含义 |
|---|---|
| τ_cmd, q, q̇ | 关节指令力矩、关节位置、关节速度 |
| P_supplied(t) = τ_cmd^T q̇ | 驱动器注入功率（可正可负） |
| P_dissipated(t) | 阻尼/摩擦耗散功率 ≥ 0 |

| E_tank_max | 能量罐容量上限（防过充） |
| ξ_pass(x) = min_{t∈[0,T]} E_tank(t) | 候选轨迹的无源裕度（模型预览） |

## 2. 关键算法骨架

### IP-497 PGCC：无源接地柔顺控制核（1 kHz 环内 O(n_dof)；预览在准入时域）

```python
@dataclass
class PassivityGroundedCompliantControlKernel:
    """PGCC：能量罐柔顺控制。无源不变量由物理传感器实测，策略不可伪造。
    红线：无源只认证安全，不认证任务效用（见定理 9 诚实边界）"""
    K_imp: np.ndarray          # 阻抗刚度
    D_imp: np.ndarray          # 阻抗阻尼
    E_tank_max: float = 10.0   # 能量罐容量（J）
    tau_pass: float = 0.0      # 无源裕度门限

    def preview_margin(self, traj: Trajectory, robot_model) -> float:
        """模型预览：沿候选轨迹积分能量罐，返回 min_t E_tank(t)（准入时域）"""
        E = self.E_tank_max * 0.5
        e_min = E
        for t in range(len(traj)):
            P_in = actuator_power(traj.tau[t], traj.qdot[t], robot_model)
            P_dis = damping_power(traj.qdot[t], self.D_imp)
            E = min(self.E_tank_max, E + (P_in - P_dis) * DT)
            e_min = min(e_min, E)
        return e_min

    def energy_tank_control(self, tau_nom: np.ndarray, qdot: np.ndarray) -> np.ndarray:
        """运行时 PO/PC：能量罐将 ≤ 0 时削减注入能量（无源化），否则放行"""
        E = self.E_tank + tau_nom @ qdot * DT
        if E < 0.0:
            scale = max(0.0, -self.E_tank) / max(1e-9, abs(tau_nom @ qdot) * DT)
            tau_nom = (1.0 - scale) * tau_nom          # 仅削减注入能量的分量
            E = 0.0
        self.E_tank = min(self.E_tank_max, E)
        return tau_nom

    def kc_pass(self, traj: Trajectory) -> bool:
        return self.preview_margin(traj, self.robot_model) >= self.tau_pass
```

### IP-498 MVA：指标有效性审计核（离线/周期，非控制环）

```python
@dataclass
class MetricValidityAuditor:

        return M_anchor, M_leak

    def goodhart_gap(self, records) -> float:
        """G = |mean(M) − mean(M_anchor)|，跨固化轮次在线监测"""
        ...

    def certify(self, metric, holdout) -> MetricValidity:
        """四要件：
        proper     —— 激励相容检验：策略无法在不改善锚的情况下抬高 M（置换/博弈测试）
        robust     —— 分布偏移下的灵敏度 ≤ 界（对抗/协变量偏移测试）
        independent—— 泄漏检验：M 对策略输出参数的偏相关 ≤ 界
        powered    —— bootstrap 置信区间半宽 ≤ delta_ci"""
        ...

    def gate_learning(self, mv: MetricValidity, gap: float) -> bool:
        """固化闸门：MV 全 valid 且 gap ≤ eps_m 才允许固化（fail-closed）"""
        return mv.all_valid and gap <= self.eps_m
```

### IP-499 CEP：认证评测协议（「证书的证书」）

```python
@dataclass
class CertifiedEvaluationProtocol:
    """CEP：接受一条评测结论，需同时满足 独立锚 + 有效 MV + 统计功效"""
    anchor: Any
    mva: MetricValidityAuditor

    def evaluate(self, policy, holdout, claim: Claim) -> Verdict:
        anchor_vals = self.anchor.measure(policy, holdout)      # 独立测量通道
        mv = self.mva.certify(claim.metric, holdout)
        ci = bootstrap_ci(anchor_vals, alpha=self.mva.alpha)
        if not mv.all_valid:
            return Verdict(False, 'METRIC_INVALID', ci)
        if (ci.hi - ci.lo) / 2.0 > self.mva.delta_ci:
            return Verdict(False, 'UNDERPOWERED', ci)
        ok = ci.lo >= claim.u
        return Verdict(ok, 'CERTIFIED' if ok else 'REFUTED', ci)
```

### IP-500 EFA-v6：七门 + 无源强化 + 指标审计

```python
@dataclass
class EvidenceForgingAssemblerV6:
    """EFA-v6：七硬门不变；BCK 增补无源裕度；学习受 MVA/CEP 审计"""
    pgcc: PassivityGroundedCompliantControlKernel
    mva: MetricValidityAuditor
    cep: CertifiedEvaluationProtocol
    v5: EvidenceForgingAssemblerV5

    def select(self, x0_state, t_now, rule_id, context):
        ok, x, why = self.v5.select(x0_state, t_now, rule_id, context)
        if not ok:
            return False, None, why
        if not self.pgcc.kc_pass(x):                 # 无源预览（合取进 BCK）
            return self.v5._fallback_rule_proposal(gamma_of(context))
        return True, x, 'FORGED_CECE'

    def ecs_v6(self, xi_pass: float, mv_valid: bool, *args, **kw) -> float:
        eta_pass = sigmoid(xi_pass - B_PASS)
        eta_mv = 1.0 if mv_valid else 0.0            # 指标失效 ⇒ 分数归零（fail-closed）
        return self.v5.ecs_v5(*args, **kw) * eta_pass * eta_mv
```

### CERTCALC-v6：新增定理 9~12（离线理论）

```python
def theorem_passivity_nonforgeability() -> str:
    """
    定理 9（无源不可伪造性）：设无源裕度由独立传感器通道在物理系统上实测（功率流由关节力矩/速度传感给出），
    则证书 ξ_pass 是「已执行行为」的函数而非「计划/声明」的函数：策略无法在不真实执行无源行为的前提下
    获得正的实测裕度；伪造等价于无中生有能量，违反 E_tank ≥ 0。
    诚实边界：(i) 仅对「策略操纵」不可伪造，不防传感器欺骗与模型误差；
    (ii) 无源是安全必要条件而非任务充分条件——完全被动的策略同样无源。
    证明：能量守恒 + 实测功率流；伪造需无中生有能量。∎
    """
    return "Proven (policy-level); sensor integrity separate"

def theorem_goodhart_gap_bound() -> str:
    """
    定理 10（审计下的 Goodhart 间隙界）：设 M = M_anchor + M_leak，M_leak 可依赖 π_θ。
    若审计在评测分布上强制 |M − M_anchor| ≤ ε_m，则对任意策略，在锚可观测的目标分量 U_anchor 上
    |M − U_anchor| ≤ ε_m + δ_anchor，其中 δ_anchor 为锚自身测量误差；若无审计约束，
    M_leak 可被优化驱动至任意大，间隙无界。
    证明：三角不等式；泄漏项无约束时 sup_π M_leak = ∞。∎
    工程含义：Goodhart 定律是「无约束优化泄漏分量」的必然，审计即给泄漏加 Lipschitz 约束。
    诚实边界：U_anchor 之外的任务效用不受此界约束（锚定盲区，R60）。
    """
    return "Proven (bounded under audit); U_anchor coverage is empirical"

def theorem_evaluation_validity() -> str:
    """
    定理 11（评测有效性）：CEP 接受「效用 ≥ u」仅当 (a) 独立锚测量、(b) MV 全 valid、(c) CI 半宽 ≤ δ；
    则在锚对效用无偏（评测分布上）且 MV 诚实的前提下，P(效用 ≥ u − δ) ≥ 1−α。
    证明：标准置信区间 + 独立性消除自评偏差 + MV 排除泄漏。∎
    诚实边界：锚无偏性不可由数据自证，只能靠外部标定与交叉验证。
    """
    return "Proven (conditional on anchor unbiasedness)"

def theorem_nesting_invariance_preserved() -> str:
    """
    定理 12（嵌套与证书不变性保持）：Exec_v6 = {x ∈ Exec_v5 : ξ_pass(x) ≥ τ_pass} ⊆ Exec_v5 ⊆ … ⊆ Exec_v29；
    MVA/CEP 仅作用于学习（提议/固化），不进入门谓词，故 v5 定理 6（证书不变性）在 v6 成立。
    证明：合取只收紧 BCK；元层不改变门集合与阈值谓词。∎
    """
    return "Proven"
```

```

  认证评测：候选策略 ──▶ CEP(独立锚 + MV + bootstrap CI) ──▶ 接受/拒绝 claim

在线准入（异步）：
  FMPP.propose (K=8) ──▶ 廉价门 ──▶ VACK ──▶ BCK 预览

在线控制环（目标 < 0.6 ms）：
  每周期：EEK + BCK + PGCC.energy_tank_control（O(n_dof)，能量罐 PO/PC）
  实测能量罐 E_tank(t) ≥ 0 是运行时安全锚；越界触发安全停（fail-closed）
```

## 4. 正确性论证（增量更新）

### 引理 45（能量罐在 PO/PC 下的不变量）

**陈述**：若 E_tank(0) ≥ 0，且每个控制周期执行 PO/PC（E<0 时按比例削减注入能量分量），则对任意 t，E_tank(t) ≥ 0。∎（标准 time-domain passivity 结果）

### 引理 46（Goodhart 间隙估计的集中界）

**陈述**：设记录独立同分布，经验间隙 Ĝ_n 满足 P(|Ĝ_n − G| ≥ ε) ≤ 2exp(−2nε²/range²)（Hoeffding）；据此构造审计的单边检验。∎

### 定理 v6（可证评测的柔顺执行，总装）

**陈述**：在 v5 假设 (B1)~(B7) 及新增 (B8) 锚测量在评测分布上对效用无偏下：
(i) Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ … ⊆ Exec_v29（无源合取 + 元层不改门）；
(ii) 证书不变性（v5 定理 6）在 v6 保持；
(iii) 无源性对策略不可伪造（定理 9），前提是传感器完整；
(iv) 学习 Goodhart 间隙在审计下 ≤ ε_m + δ_anchor（定理 10），无审计则无界；
(v) 评测结论在 CEP 三条件下有效（定理 11）；
(vi) 七锚完备性保持（v5 定理 8），BCK 仅合取加强。

**证明**：(i)(ii)(vi) 由合取收紧 + 元层不入门 + v5 定理 6/8；(iii) 定理 9；(iv) 定理 10；(v) 定理 11。∎

**诚实声明**：(B8) 锚无偏性不可自证，只能外部标定；(iii) 不防传感器欺骗/模型误差；(iv) 只约束「可测泄漏」，不可测泄漏仍可博弈；(v) 效用侧锚可能不存在（任务质量难有物理守恒量），此时 Goodhart 间隙仅被代理锚弱约束。继承 v5 的 (B4) 加性价值假设未解。

### 第 6 轮灵感驱动研究记录

**灵感词**：评测指标、柔顺控制

**继承关系**：第 5 轮 CADVS-v5（IP-493~496）以「认证的生成式执行」（CGE）把提议升级为条件流匹配、记忆升级为嵌入+固化、人因升级为情感调制，并用定理 5~8 证明执行集三重收缩（Exec_v5 ⊆ Exec_v4 ⊆ … ⊆ Exec_v29）与证书不变性；其最大未解风险 R57 是**记忆固化自指回路**——策略在自己铸证的片段上训练，证书同时充当优化目标与度量，退化为自洽但失真的自我背书。本轮不推翻 v5，而是正面回答 R57 的根问题：**如何知道证书是真的，而不是自我背书**。两个灵感词合流为主题「可证评测的柔顺执行」（Certifiable-Evaluation Compliant Execution, CECE），形成 CADVS-v6（IP-497~500）。本轮自律：**硬门数量不增**（仍七门，BCK 以合取方式被物理强化），评测作为元层（审计/协议）而非新门，执行集嵌套升级为 Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ … ⊆ Exec_v29。

**直觉与动机**：

1. **柔顺控制 → 物理接地锚，打破自指回路**。R57 本质是**度量问题**：证书既被优化又被测量，缺少独立真值。柔顺控制提供了一条独立测量通道——**无源性（passivity）/能量守恒**。能量罐（energy tank，PO/PC）保证 E_tank(t) ≥ 0，且它由关节/力传感器在物理系统上实测，不是策略的自我声明。要伪造更高的无源裕度，就必须真的向系统注入能量，而注入能量恰恰违反该不变量——因此**无源性对策略不可伪造**（注意：不可伪造 ≠ 充分；一个「什么都不做」的策略同样无源）。于是把 BCK 从「准静态力锥/ZMP」强化为「力锥/ZMP ∧ 无源裕度」，用合取加强而非新增门，既保持七锚又补上物理接地。

2. **评测指标 → 元评测（指标审计）与 Goodhart 定理**。所有被用于学习的分数（ECS、FER 校准、价值模型、流新颖度阈值）都是「测量」。Goodhart 定律可形式化：若学习目标 M 含一个依赖策略自身输出的泄漏分量 M_leak（M = M_anchor + M_leak），优化可无限抬高 M 而不改善真实效用。指标审计（MVA）把每个指标拆成锚分量与泄漏分量，约束 |M − M_anchor| ≤ ε_m；一旦超界或有效性证书失效，**冻结固化**（对学习 fail-closed），回退 v5。这把「信任证书」换成「审计测量」。

3. **合流 → 评测协议本身被认证（CECE）**。评测结论只在同时满足 (a) 独立锚测量、(b) 指标有效性证书有效、(c) 统计功效充分（置信区间半宽 ≤ δ）时才被接受——这是「证书的证书」。R57 回路由此被打破：不是更相信证书，而是要求一个独立于策略的测量通道。诚实边界：物理锚只认证能量安全，对任务效用沉默；效用侧的 Goodhart 间隙仍存，且过度优化无源性会把系统推向「松软」（高顺应、低任务性能）。

**关键洞见**：v5 回答「提议/记忆/人因变化时证书边界能否不变」；v6 回答「如何知道证书是真的」。答案是把认证从「自证」转为「独立物理锚 + 受审指标」：无源性提供不可伪造的安全锚，指标审计约束可被博弈的效用侧。七门原样复用；BCK 以合取方式增补无源裕度；新模块均为元层（审计/协议），不进入门谓词，故 v5 定理 6（证书不变性）与执行集嵌套保持。ECS_v6 = ECS_v5 · η_pass · η_mv，Exec_v6 = {x ∈ Exec_v5 : ξ_pass(x) ≥ τ_pass}。

**形式化目标（增量）**：
1. 无源能量罐：E_tank(t) = E_tank(0) + ∫(P_supplied − P_dissipated)dt ≥ 0；无源裕度 ξ_pass(x) = min_t E_tank(t)；BCK 强化 kc_BCK^6 = kc_BCK^5 ∧ 1[ξ_pass ≥ τ_pass]。
2. 指标分解 M = M_anchor + M_leak；Goodhart 间隙 G = |E[M] − E[M_anchor]|，审计约束 G ≤ ε_m。
3. 指标有效性证书 MV = (proper, robust, independent, powered)，各带量化阈值；MV 失效或 G > ε_m ⇒ 冻结固化。
4. 定理 9（无源不可伪造性）、定理 10（审计下的 Goodhart 间隙界）、定理 11（评测有效性下置信界）、定理 12（嵌套与证书不变性保持）。

```python
    v4: EvidenceForgingAssemblerV4        # 复用 scf/msrg/hic/eek/vack/bck 全套

    def select(self, x0_state, t_now, rule_id, context) -> tuple[bool, Trajectory | None, str]:
        s_emo = self.famk.observe(context.face, t_now)
        gamma = self.famk.gamma(s_emo)                   # 全 1.0 = 精确退化 v4
        c = build_ctx(context, s_emo, self.lmem)         # 含 Top-k 记忆 token
        cands = self.fmpp.propose(c, self.fmpp.K)        # K=8，~5–20 ms，异步准入时域
        # 级联第 1 层：廉价门（coverage/physics/memory/novelty，O(1)~O(log|M|)）
        surv = [x for x in cands if self._cheap_gates(x, gamma)]
        if not surv:
            return self._fallback_rule_proposal(gamma)   # fail-closed：回退 v4 规则提议
        # 级联第 2 层：VACK 仅评估 ≤3 幸存者（~50 ms 级，异步；预筛省 ~60% 昂贵调用）
        surv.sort(key=lambda x: self._prefilter_score(x), reverse=True)
        finals = []
        for x in surv[:3]:
            vac = self.v4.vack.evaluate(x, context_with(s_emo), t_now)
            if self.v4.vack.kc_val(vac, tau=gamma['val'] * TAU_VAL4):
                finals.append(x)
        # 级联第 3 层：BCK 轨迹预览（事件触发 QP + 缓存证书内插）
        ok = [x for x in finals if self._bck_preview(x, gamma)]
        if not ok:
            return False, None, 'ALL_CANDIDATES_REJECTED'
        best = max(ok, key=certified_margin)             # 通过者中取边际最大者
        return True, best, 'FORGED_CGE'

    def ecs_v5(self, ..., n_flow: float, s_emo: SHomo | None) -> float:
        eta_flow = sigmoid(n_flow_to_ll(n_flow) - b_flow)
        eta_emo = (1.0 - self.famk.lam_emo * s_emo.p_distress
                   if s_emo is not None and s_emo.sigma <= self.famk.sigma_max else 1.0)
        return self.v4.ecs_v4(...) * eta_flow * eta_emo
```
