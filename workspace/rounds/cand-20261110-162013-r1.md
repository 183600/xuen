# 第 47 轮（灵感循环第 1 轮；承接第 46 轮 v23；本轮灵感：预训练 × 应用落地） · PreDeploy-Cert：预训练先验的可迁移证书与落地租约（四层架构 v11）

> 承接第 46 轮 v23 Memory-Safety-Voice。v23 把记忆检索、语音指令、安全绑定纳入全局决策 Π，但隐含假设 H5：记忆嵌入、ASR、上下文预测器与姿态特征骨干所依赖的预训练先验，在目标场景的校准与源域一致；且“上线”被当作一次性工程动作。两个灵感词精确命中 H5：**预训练**把系统能力规模化，却把风险从“训练不足”转移到“迁移未验证”——强先验在分布漂移下会以高置信度给出错误决策；**应用落地**要求的不只是跑通 demo，而是可验收、可监控、可回滚、可续期的现场保证。二者耦合出新问题：**如何把预训练先验编译成带来源与迁移误差预算的证书，并只在“落地租约”有效时允许其参与姿态/能量/安全联合保证；若迁移误差被低估，高置信先验会使记忆检索、语音绑定与姿态证书同时静默失效**。

## 0. 直觉与动机

**灵感 1（预训练 → 先验是待验证资产，不是保证）**
直觉：预训练模型在源域上“很准”，但证书要的是目标域上的覆盖概率。模型越大，先验越强，越容易在漂移场景中自信地错。于是把每个预训练组件（VLM 上下文预测器、ASR、记忆嵌入、姿态特征骨干）视为一件带“护照”的资产：记录源分布、源风险、参数哈希、校准集与失效条件。先验可以被复用，但必须先通过迁移审计。

**灵感 2（应用落地 → 落地是持续续期的租约，不是一次性上线）**
直觉：现场不是测试集。落地需要影子模式、灰度、遥测、回滚和证书续期。把部署状态建模为部署租约 ℓ_d=(目标域指纹, 迁移差距估计, 校准样本量, 有效期 τ_d, 风险预算 α_d)。租约有效时预训练先验可参与保证；过期、漂移超预算或现场违例时自动降级/回滚，而不是继续“带病运行”。

**灵感 3（耦合 → 迁移误差沿记忆-语音-姿态-安全链级联）**
直觉：记忆检索复用源域经验、ASR 迁移到新口音、上下文预测进入新材质场景，任一环节的先验迁移误差都会改变姿态证书宽度与安全绑定概率。因此需要**来源感知的记忆加权**+**目标域加权共形校准**+**落地状态机**三者联动：源域记忆只在护照有效时低权重复用，语音槽位置信按目标域重标定，上下文预测器输出附带漂移告警，CAR 守卫同时检查 ℓ_p、ℓ_e、ℓ_d。

**框架升级**：在 v10 能量-上下文-深度四层上增加“预训练-落地信任层”。根信任由两腿（姿态租约 ℓ_p、能量租约 ℓ_e）扩展为三腿（+ 部署租约 ℓ_d）；L1 几何层记录特征骨干的来源与迁移误差；L2 上下文/记忆层做来源感知检索与漂移检测；L3 CAR 守卫加入 ℓ_d 有效性；L4 DCL 主动采集目标域校准样本并按迁移差距排序。PreDeploy-Cert = PPC（护照编译）× SCL（漂移校准租约）× LRR（落地滚动与回滚）。

## 1. 形式化定义（增量：定义 59–63）

**定义 59（预训练先验护照）**
预训练组件 f 的护照
Ω_pre(f) = (h_f, D_src, R_src(f), n_src, Cal_src, prov_f, ∂f)
其中 h_f 为参数/权重哈希，D_src 为源分布指纹，R_src(f) 为源域风险（如预测误差或 1-覆盖率），Cal_src 为源域校准产物，prov_f 为数据与许可来源，∂f 为声明的适用范围与失效条件。护照是组件参与任何证书的前置条件。

**定义 60（源-目标迁移差距与迁移风险上界）**
设目标分布 D_tgt，假设类 H，对称差假设类 HΔH。迁移差距
d_HΔH(D_src,D_tgt) = 2 sup_{h∈HΔH} |Pr_src(h=1)-Pr_tgt(h=1)|。
对任意 h∈H，以至少 1-δ 的概率
R_tgt(h) ≤ R_src(h) + ½ d_HΔH(D_src,D_tgt) + λ* + ε_cal + √(log(1/δ)/(2n_cal))
其中 λ* = min_{h∈H}[R_src(h)+R_tgt(h)] 为联合理想风险，ε_cal 为目标域重校准误差。称右端为**迁移风险上界** U_trans(f)。当 U_trans(f) ≤ α_d 时称 f 在预算 α_d 下可迁移。

**定义 61（部署租约）**
部署租约
ℓ_d = (fp(D_tgt), d̂_HΔH, n_cal, τ_d, α_d, ε_d, ε_drift)。
有效性判据：
Valid(ℓ_d,t) ⇔ t ≤ τ_d ∧ d̂_HΔH ≤ ε_d ∧ n_cal ≥ n_min ∧ drift_t ≤ ε_drift ∧ U_trans ≤ α_d。
任一条件失效则所有引用预训练先验的证书降级：ℓ_d 失效 ⇒ 相关 P_t 与记忆命中失效 ⇒ CAR fail-closed 或回退到目标域专用保守路径。

**定义 62（漂移加权共形证书）**
对非一致性分数 s(x,y)，源样本权重 w(x)=p_tgt(x)/p_src(x)（截断到 [w_min,w_max] 并归一化）。取加权分位数
q̂ = Quantile_{1-α}({s_i : weight w_i})
则目标域覆盖率至少 1-α-Δ_w，其中 Δ_w 为权重估计误差引起的修正项（由 total variation 控制）。由此签发迁移感知姿态证书
T_t = (P_t, ℓ_p, ℓ_e, ℓ_d, m_t, {Ω_pre})
并要求 ℓ_p、ℓ_e、ℓ_d 同时有效。

**定义 63（落地状态机与验收函数）**
落地状态 z_t ∈ {offline, shadow, canary, full, rollback}。验收函数
A(ℓ_d, telemetry_t) = Promote 若 覆盖率 ≥ 1-α_d ∧ 安全违例 = 0 ∧ 承诺延迟/能耗满足；否则 Hold 或 Rollback。
状态转移：offline→shadow→canary→full，任一安全谓词违例或 ℓ_d 过期则 full→rollback；rollback 后仅允许目标域专用保守策略重新进入 shadow。

## 2. 三大新增产出与既有 IP 升级

**IP-69 PPC（Pretrain Prior Passport Compiler）**
- 为每个预训练组件生成护照：参数哈希、源分布指纹、源风险、数据/许可来源、适用范围
- 源域校准产物固化（温度缩放、共形分位数、阈值），禁止无护照复用
- 护照与模型版本绑定，任何微调/量化触发重编译与重新审计

**IP-70 SCL（Shift-Calibrated Lease）**
- 目标域迁移差距在线估计：域分类器代理 A-distance + 嵌入漂移 + 预测分歧
- 漂移加权共形校准：重要性权重截断、加权分位数、覆盖率回读校验
- 部署租约签发/续期/撤销：n_cal 不足时拒绝签发，漂移超限自动撤销

**IP-71 LRR（Landing Rollout & Rollback）**
- 落地状态机 offline→shadow→canary→full→rollback
- 影子模式仅记录不执行，与目标域保守基线对比分歧与覆盖率
- 遥测触发自动回滚；回滚目标为最近一次租约有效的保守策略，回滚时延纳入 SLA

**既有 IP 升级**
IP-66 MVR：记忆元组增加来源标签 s_i∈{src,tgt,field} 与护照引用，源域记忆按迁移置信加权并设上限
IP-67 VAD：ASR 槽位置信按目标域口音/语言重标定，未重标定则强制二次确认
IP-65 CONTEXT PREDICTOR：输出附带漂移告警与护照有效性，漂移超限降级为保守先验
IP-63 ECPS：模态效用加入预训练模型算力/热成本，并检查 ℓ_d
IP-61 DCL：按迁移差距与预测分歧优先采集目标域校准样本，采集成本计入 ℓ_e
IP-62 CCA：新增迁移误差红队、来源污染测试、回滚演练
IP-51 CAR：守卫加入 Valid(ℓ_d,t)，三租约任一失效即 fail-closed
IP-45 总线：新增 passport / deployment-lease / drift-alert / rollout-state 话题

## 3. 算法骨架

PreDeploy-Cert 运行分两阶段：

**落地前（编译与验收）**
1. 枚举预训练组件，生成护照 Ω_pre
2. 在目标域校准集上估计 d̂ 与加权共形分位数，计算 U_trans
3. 若 U_trans>α_d 或 n_cal<n_min → 拒绝签发 ℓ_d，组件仅可离线使用
4. 通过则签发 ℓ_d，进入 shadow，记录与保守基线的分歧

**运行期（续期与回滚）**
1. 每控制周期更新 telemetry（预测分歧、嵌入漂移、现场覆盖回读）
2. 重估 drift_t 与 U_trans；若超限则撤销 ℓ_d
3. CAR 同时检查 ℓ_p、ℓ_e、ℓ_d；任一失效则记忆命中作废、语音绑定降级或 fail-closed
4. 满足验收函数则 canary→full；安全违例或租约过期则 full→rollback

## 4. 本轮最大风险

**一句话**：迁移风险上界依赖联合理想风险 λ* 与漂移估计，若目标域与源域支持集几乎不重叠，λ* 会很大却难以估计，加权共形也会因权重失真而给出虚假覆盖率，导致系统在“护照齐全、租约有效”的假象下把高置信错误先验落地；因此必须把支持重叠审计与权重截断作为硬门槛，支持不足时拒绝签发 ℓ_d，而不是仅靠调大 α_d。

```
def compile_passport(f, D_src, cal_src, prov, scope):
    h = hash_params(f)
    R_src = estimate_risk(f, D_src)
    D_src_fp = fingerprint(D_src)
    return Passport(
        h=h, D_src=D_src_fp, R_src=R_src, n_src=len(D_src),
        Cal_src=cal_src,          # 温度缩放 / 共形分位数 / 阈值
        prov=prov,                # 数据与许可来源
        scope=scope,              # 声明适用边界与失效条件
        valid=True,
    )

def invalidate_on_change(passport, f_new):
    # 任何微调/量化/蒸馏都使护照失效，强制重新审计
    if hash_params(f_new) != passport.h:
        passport.valid = False
    return passport
```

### IP-70 SCL 迁移差距与加权共形
```
def estimate_discrepancy(D_src, D_tgt, H):
    # 域分类器代理 d_HΔH；err 为平衡准确率误差
    g = train_domain_classifier(D_src, D_tgt)
    a_dist = 2.0 * (1.0 - 2.0 * err(g))
    return clip(a_dist, 0.0, 2.0)

def weighted_quantile(scores, weights, alpha):
    order = argsort(scores)
    s = scores[order]
    w = weights[order] / weights.sum()
    cw = cumsum(w)
    return s[searchsorted(cw, 1.0 - alpha, side='left')]

def estimate_lambda_star(passport, D_tgt_cal, H):
    # 仅在支持重叠区域估计；低重叠区返回 +inf 触发拒签
    overlap = support_overlap(passport.D_src, D_tgt_cal)
    if overlap < rho_min:
        return inf, overlap
    h_joint = fit_joint_risk_minimizer(passport, D_tgt_cal)
    return risk_src(h_joint) + risk_tgt(h_joint), overlap

def issue_deployment_lease(f, passport, D_tgt_cal, D_tgt_audit,
                            alpha_d, tau_d):
    if not passport.valid:
        return Lease(valid=False), None
    d_hat = estimate_discrepancy(passport.D_src, D_tgt_cal, H)
    lam, overlap = estimate_lambda_star(passport, D_tgt_cal, H)
    if not isfinite(lam):
        return Lease(valid=False, reason='no_support_overlap'), None

    w = clip(density_ratio(D_tgt_cal, passport.D_src), w_min, w_max)
    q = weighted_quantile(conformity(f, D_tgt_cal), w, alpha_d)
    cov = empirical_coverage(f, D_tgt_audit, q)      # 独立审计集回读

    U_trans = (passport.R_src + 0.5 * d_hat + lam
               + calib_error(f, D_tgt_cal)
               + sqrt(log(1.0 / delta) / (2.0 * len(D_tgt_cal))))
    ok = (U_trans <= alpha_d and cov >= 1.0 - alpha_d - eps_cov
          and len(D_tgt_cal) >= n_min)
    return Lease(
        fp=fingerprint(D_tgt_cal), d_hat=d_hat, n_cal=len(D_tgt_cal),
        tau_d=now() + tau_d, alpha_d=alpha_d, U_trans=U_trans,
        valid=ok, q=q,
    ), (q if ok else None)

def lease_valid(lease, t, drift_t, eps_d, eps_drift):
    return (lease.valid
            and t <= lease.tau_d
            and lease.d_hat <= eps_d
            and lease.n_cal >= n_min
            and drift_t <= eps_drift
            and lease.U_trans <= lease.alpha_d)
```

### IP-66 来源感知记忆检索
```
def memory_lookup_prov(v_t, c_t, B_t, M, tau_hit=0.7,
                       lambda_b=0.1, lambda_c=0.2, lambda_p=0.3):
    best = None
    for rec in M:
        d = 1.0 - cosine(encode(v_t), encode(rec.c))
        d += lambda_b * max(0.0, B_t - rec.B)
        d += lambda_c * kl_div(c_t, rec.c)
        if rec.source != 'field':
            # 源域经验仅在护照有效时可用，并按迁移置信降权
            if not rec.passport_valid:
                continue
            d += lambda_p * (1.0 - rec.transfer_conf)
        if best is None or d < best.d:
            best = (rec, d)
    if best is not None and best[1] < tau_hit:
        return best
    return None
```

### IP-71 落地状态机
```
def landing_step(state, lease, telemetry, alpha_d):
    if not lease_valid(lease, now(), telemetry.drift, eps_d, eps_drift):
        return 'rollback', 'lease_invalid'

    if state == 'offline':
        if lease.U_trans <= alpha_d:
            return 'shadow', 'enter_shadow'
        return 'offline', 'hold'

    if state == 'shadow':
        if (telemetry.safety_violations == 0
                and telemetry.disagreement <= eps_dis
                and telemetry.coverage >= 1.0 - alpha_d):
            return 'canary', 'promote_canary'
        return 'offline', 'shadow_reject'

    if state == 'canary':
        if telemetry.safety_violations == 0 and telemetry.sla_ok:
            return 'full', 'promote_full'
        return 'rollback', 'canary_fail'

    if state == 'full':
        if (telemetry.safety_violations > 0
                or telemetry.drift > eps_drift):
            return 'rollback', 'field_violation'
        return 'full', 'stay'

    if state == 'rollback':
        # 回滚后只允许目标域专用保守策略重新进入 shadow
        if telemetry.conservative_ready:
            return 'shadow', 'recover'
        return 'rollback', 'hold'

    return state, 'hold'
```

```
        return 'fail-closed', 'energy_lease'
    if not lease_valid(lease_d, t, drift_t, eps_d, eps_drift):
        # 预训练先验降级，记忆命中作废，走目标域保守路径
        return 'fail-closed', 'deploy_lease'
    return 'pass', None
```

## 3. 推导：迁移风险界与联合 soundness

**定理 1（迁移风险上界）**
设 H 的对称差 VC 维有限，d_HΔH 为定义 60 的迁移差距，λ* 为联合理想风险，ε_cal 为目标域重校准误差。则以至少 1-δ 的概率，对任意 h∈H：
R_tgt(h) ≤ R_src(h) + ½ d_HΔH + λ* + ε_cal + √(log(1/δ)/(2n_cal))。

证明要点：对任意 h,h'，
|R_src(h,h') - R_tgt(h,h')| ≤ ½ d_HΔH，
故 R_tgt(h) ≤ R_tgt(h*) + R_tgt(h,h*)
≤ [R_src(h)+½d+…] + [R_src(h*)+R_tgt(h*)+½d+…]
= R_src(h)+d+λ*+…；把 d 的系数按标准界收紧为 ½ d 并合并有限样本项即得。λ* 无法由单侧数据消除，必须用支持重叠审计估计，这是本方案与普通域适应最大的区别。

**定理 2（加权共形覆盖率）**
若重要性权重精确且满足协变量漂移假设，漂移加权共形给出目标域覆盖率 ≥ 1-α。若使用估计权重 ŵ，则覆盖率 ≥ 1-α-Δ_w，其中 Δ_w 由 E|ŵ-w| 与权重截断区间控制；截断过窄会引入偏差，过宽会放大方差。

**推论（联合 soundness）**
姿态证书覆盖率为 1-α_p，部署租约风险预算 α_d，权重误差修正 Δ_w。若 ℓ_p、ℓ_e、ℓ_d 同时有效，则联合证书 T_t 的 soundness 满足
P(X_t∈P_t | ω_t,m_t,T_t 有效) ≥ 1-α_p-α_d-Δ_w。
工程上要求 α_p+α_d+Δ_w ≤ α_total（如 0.05），否则拒绝签发 ℓ_d 或收紧姿态保守盒。

## 4. 实验设计 E115–E120

| 实验 | 指标 | 门槛 |
|---|---|---|
| E115 迁移差距估计 | d̂ 与真值偏差；支持重叠率 ρ | 偏差 ≤ 0.10；ρ < 0.3 必须拒签 |
| E116 加权共形覆盖 | 目标域实测覆盖率；Δ_w | 覆盖率 ≥ 1-α-0.02；Δ_w ≤ 0.01 |
| E117 来源感知记忆 | 源域记忆复用率；安全违例 | 复用率 ≤ 30%；0 违例 |
| E118 shadow→canary 验收 | 与保守基线分歧率；安全违例 | 分歧 ≤ 15%；canary 0 违例 |
| E119 漂移检测与回滚 | 检测时延；回滚时延 | 检测 ≤ 2s；回滚 ≤ 1s |
| E120 100h 落地闭环 | 任务成功率；安全违例；能耗 | 成功率 ≥ 95%；0 违例；能耗 ≤ 基线 +10% |

回退策略：E115 支持重叠 < 0.3 → 拒绝签发 ℓ_d，仅保留目标域专用模型；E116 覆盖率回读不达标 → 缩短 τ_d 并提高权重截断保守度；E117 源记忆违例 → 禁止 src 记忆参与；E118 分歧 > 20% → 退回 offline 重标定；E119 回滚超时 → 预置硬实时看门狗；E120 能耗超预算 → 关闭预训练大模型实时分支，改蒸馏小模型。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| λ* 不可估 / 源目标支持几乎不重叠 | 高 | 支持重叠审计 + 硬性拒签；低重叠区不做任何迁移声明 |
| 重要性权重失真导致虚假覆盖率 | 高 | 权重截断 + 独立审计集回读 + Δ_w 显式扣除 |
| 源域记忆污染并复制历史错误 | 高 | 来源标签 + 护照有效性 + 复用上限 + field 样本回灌 |
| 遥测漂移误报导致频繁回滚 | 中 | 滞回阈值 + 最小驻留时间 + 分级告警 |
| 护照与模型版本脱节 | 中 | 参数哈希绑定，微调/量化即失效重审计 |
| 回滚目标本身不安全 | 高 | 回滚基线必须独立认证并定期演练，禁止回滚到未认证版本 |

## 6. 本轮最大风险

**一句话**：若把 λ* 当作可忽略的小量、并用加权共形在低支持重叠区强行签发 ℓ_d，系统就会在“护照齐全、租约有效”的假象下让高置信预训练先验直接接管记忆、语音与姿态决策，一旦现场分布偏移超出源域支持，安全违例将同时穿透三份租约；因此必须把支持重叠审计与权重误差扣除设为拒签硬门槛，宁可不落地也不签发不可信的部署租约。
