# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「目标检测」×「抓取规划」）

> R69 把不确定性一分为二，并给 epistemic 装上了「嘴」：看不清就凑近、拿不准就问、质感不明就摸。但它有一个从未说出口的隐含前提——**所有信息动作都廉价、可逆，且证据总在决策之前到达**。真实具身任务里有一个 R69 没有建模的时刻：**承诺点（commitment）**——手指合拢、抬离桌面、把整条机械臂的分量押在一个假设上的那一瞬。两个本轮灵感恰好把这个时刻暴露出来：
> - **目标检测**产出的不是「世界是什么」，而是「哪里有可作用的东西」。但检测器给的 (类别, 框) 是**为二维识别优化的抽象**，它恰好丢掉了抓取真正需要的三维接触几何（深度、法向、摩擦、柔顺）；更要命的是，**检测置信度与抓取可行性是两种不同的置信度**，把前者当后者用，是「检测→定位→抓取」整条流水线的原罪。
> - **抓取规划**是把感知不确定性翻译成物理后果的算子：位姿的一个小角度误差，会在**力臂末端**放大成接触点的大位移；而一旦合拢，错误就**不可逆**。抓取还是少数「**必须承诺才能取得证据**」的动作——摩擦、质量、柔顺、是否打滑，只有碰上才知道。
>
> 核心命题：**R69 的「不确定就问」只在前承诺区成立。R70 把不可逆性提升为一等公民，沿「承诺边界」把闭环切成三段：前承诺区（可逆、VoI 驱动，沿用 R69）→ 承诺门（必须物理互证，或用「软承诺」以受限风险换取接触证据）→ 后承诺区（epistemic 已转化为 aleatoric，交给 R68 保守底线与恢复策略）；并把感知货币从「检测置信度」换成「经力臂放大后的抓取成功率与接触风险」。** 命名 **GRASP-RAS**（Geometry-grounded, Reversible-to-irreversible Affordance Selection and Pre-commitment for Risk-Adaptive Systems）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我什么时候必须停止求证、把身体押上去**」——不确定性最终要被结算成一次不可撤回的物理下注。

## 0. 直觉与动机

**灵感 1（目标检测 → 检测应当为抓取服务，而不是为 mAP 服务）**
直觉：R69 的所有 Modal 都是「动作模态」，但机器人在杂乱桌面上的第一个歧义往往不是「怎么动」，而是「**那是哪一个东西、它的可作用表面在哪**」。检测器吐出的是一个集合 {(类别, 框, 分数)}，而抓取需要的是「在哪个 SE(3) 位姿上、用这个夹爪、能产生多大夹持力、会不会碰」。一个框是两个坐标轴上的区间，它把深度、遮挡边界、法向、可变形性全部丢弃了。**信息一旦在检测层被丢掉，后面再精巧的规划也补不回来**。所以本轮第一件事不是加模块，而是换表示：检测的输出应当是**抓取充分（grasp-sufficient）的接触假设**，其效用由它把 p_succ（抓取成功率）改变了多少来衡量，而不是由它在像素上的 AP 衡量。

**灵感 2（抓取规划 → 承诺把「不确定性」结算成「不可逆后果」）**
直觉：R69 里「问一句」「摸一下」默认可以反悔；抓取的核心却是**一个不可逆的力臂**。pose 的角度误差 σ_θ 在离抓取坐标系原点距离 r 处的接触点上诱导出约 r·σ_θ 的位移——**同一份位姿不确定性，抓远处（或抓长柄工具末端）时是致命的，抓近处时却无害**。这就是「不确定性放大」：它不是一个标量，而是一个随几何而变的场。更关键的是，合拢夹爪、抬升负载之后，错误不再是「可以再问一次」的认知问题，而是打滑、掉落、碰撞的物理问题。

**灵感 3（不可逆 → 承诺是消耗期权，R69 只是「永不承诺」的退化）**
直觉：R69 的交互判据是 `VoI(g) > c(g)`，本质上假设「不交互」与「先看一眼再交互」之间没有不可挽回的代价。一旦引入承诺，**现在承诺 = 销毁「等一等」这个期权（real option）**。所以正确的判据应为：`VoI − c + (1−α)·E[L_wrong] > 0`，其中 α∈[0,1] 是错误承诺可恢复的比例。当 α=1（完全可逆）时，逐项退化为 R69；当 α=0（不可逆）时，前承诺区必须**更积极**地求证——因为在门口犹豫比在门后后悔便宜。**R69 是 R70 在 α=1、且检测抓取充分时的严格边界情形。**

**灵感 4（软承诺 → 接触本身是一次测量，证据可以「分期付款」）**
直觉：完全可逆与完全不可逆之间不是二元的。力限位、慢速接近、半合拢、顺应控制、轻触—回退，都是「**用一点不可逆性换一点证据**」：把位姿假设押一点点上去，用接触/力/阻抗去证伪它，再决定是否全押。于是「抓取」不再是一个原子动作，而是一条**承诺强度 β 连续可调**的曲线：β 越大，证据越硬，可逆性越差。这直接对应抓取规划里的 guarded move 与力阈值中止。R69 的「看/问/触」由此获得第三种形态——**「触」不是探针，而是抓取本身的前半程**。

**灵感 5（物理可以被伪造 → R69 的「问错」升级为「抓错并盖章」）**
直觉：R69 最大的恐惧是「追问一个幻影、把误导答案盖上已验证的章」。物理世界看似是最终裁判，但它同样会撒谎：透明/反光物体给出**假表面**，柔性/可压缩物体给出**假稳固**（碰到了、但一抬就滑），遮挡导致的 amodal 补全给出**假边缘**，旋转对称物体让位姿误差在数学上不可辨。如果「物理互证」只是「有没有接触」，系统就会用一次真实接触为一次幻觉检测背书。所以本轮的威胁模型必须显式包含 **phantom grasp（幻影抓取）**：不是没看到，而是**看到、碰到、却抓错了**。

**灵感 6（对应歧义 → 抓错对象是一种独立的 epistemic 模态）**
直觉：杂乱场景里，两个相似的杯子、一个被遮挡的把手，会让「检测↔物理对象」的对应关系本身成为歧义。R69 的模态是「动作怎么走」，R70 多了一类模态是「**这个假设对应的是哪一个物理实体**」。这类歧义恰恰可以用接触来判别——碰一下，才知道刚才规划的是不是它。检测的集合预测（set prediction / Hungarian matching）天然给出对应假设，而抓取给了它一个物理的证伪通道。

## 1. 形式化定义（增量：定义 310–323）

**定义 310（GRASP-RAS 总览）** GRASP-RAS = (TCD, IFR, UAM, GSF, CCG, SGC, DEL, PGR, GRASP-WM†)。四不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i / R68 定义 276-i）；
(ii) **承诺守恒（commitment conservation）**：在承诺门及其之后，安全下限逐点不弱于 R69 与 R68；任何承诺动作不得降低既有安全包络；
(iii) **闭合前证据纪律**：完全闭合/抬升前须有 ≥2 个正交证据源（几何/接触/力/语义）一致，或一个风险受界、且带认证回退路径的**软承诺**；单源（尤其单语义源）不得闭合；
(iv) **放大感知预算**：前承诺区的求证预算随「位姿不确定性 × 力臂」增大而增大，不允许在放大区沿用平均预算。

**定义 311（抓取充分检测 TCD 与抓取成功场 GSF）** 检测输出不再是框，而是接触假设集合 𝒟 = {(T̂_i, Σ_i, S_i, φ_i)}：T̂_i ∈ SE(3) 为物体/表面位姿，Σ_i 为其协方差，S_i 为表面/法向/可变形性描述，φ_i 为检测↔物体对应权重。抓取成功场 p_succ(h | 𝒟) 定义在抓取假设 h = (i, g, gripper) 上，g ∈ SE(3) 为夹爪位姿。**抓取充分性**：表示 𝒟 是抓取充分的，若对任意决策损失 L，min_π E[L | 𝒟] ≈ min_π E[L | o_full]（差异 ≤ ε_suff）；框表示在需要深度/法向/摩擦时通常不充分。定义**对应歧义** H_corr = −Σ_i φ_i log φ_i 与**几何歧义** H_geo。

**定义 312（不可逆前沿 IFR 与反转代价）** 对动作 a，反转代价 R(a) = 使系统回到执行 a 之前可行集所需的期望代价（时间 + 能量 + 安全裕度损失）。承诺动作 c（闭合/抬升/释放）满足 R(c) ≫ R(a_task)。前沿 F = {s : R(π(s)) 越过 R_max}，把状态分为可逆区 Z_rev、门前区 Z_front、不可逆区 Z_irr。承诺是**消耗期权**：一旦越过 F，{等一等再查} 这个动作从可行集中被删除。

**定义 313（不确定性放大 UAM 与放大裕度）** 接触映射 p_c = J(p) T，J = [I₃, −[r]_×]（r 为接触点相对位姿原点/质心的力臂）。接触协方差 Σ_c = J Σ_T Jᵀ，于是
tr Σ_c = tr Σ_t + rᵀΣ_θr + tr(Σ_θ)(‖r‖² − 1) ≤ tr Σ_t + r² tr Σ_θ。
**放大因子** κ(r) = √(tr Σ_c / tr Σ_T) ≥ 1，随 ‖r‖ 近似线性增长；纯旋转近似下接触点位移 ≤ ‖r‖·σ_θ。定义**放大裕度** m(h) = 有符号接触间隙 / √(tr Σ_c)：m ≥ τ_m 才允许硬承诺。

**定义 314（风险加权抓取假设）** Q(h) = p_succ(h) − λ_risk·r_coll(h) − λ_slip·r_slip(h)，s.t. r_coll ≤ ε_g、m(h) ≥ τ_m；选 h* = argmax Q。另定义**置信错配** Δ_c = conf_sem(𝒟) − conf_geo(𝒟)（语义置信 vs 几何/功能置信），高 Δ_c 表示「检测很确定但位置/可抓性不可信」。

**定义 315（承诺证书 CCG）** 证据源集合 𝒮 = {s_geo（位姿/深度）, s_contact（接触起始）, s_force（力/阻抗轮廓）, s_sem（检测/对应）, s_tact（纹理/滑移）}。闭合合格 ⇔ (a) 至少两个**正交**源一致；(b) p_succ(h*) ≥ τ_p；(c) 放大裕度 m(h*) ≥ τ_m；(d) 存在经认证的回退路径（open/retreat）；(e) 信源相关性 ρ < 1 且不被单语义源支配。

**定义 316（软承诺 SGC）** 以强度 β ∈ [0,1] 参数化承诺（力上限 F(β)、接近速度 v(β)、闭合比例、顺应刚度）。反转代价 R(β) 递增、证据产出 ν(β) 递增、物理风险 ρ(β) ≤ ε_c 且随 β 受界。选择 β* = argmax_β [ν(β)·VoI_contact − c(β)]，s.t. R(β) ≤ 反转窗口允许、ρ(β) ≤ ε_c。β=0 即 R69 的纯信息动作，β=1 即硬承诺。

**定义 317（延迟证据账本 DEL）** 证据 e 带时延 τ_e 到达（接触后才有摩擦/质量/滑移）。反转窗口 w_rev = 在不超过 R_max 前可撤销的时间。若 τ_e ≤ w_rev：**追溯审计**，错误假设自动 retreat 并回灌 R69 后验；若 τ_e > w_rev：进入恢复。账本 L 记录 (h, 承诺时刻 t_c, 承诺强度 β, 证据, 判定, 延迟)，供下一轮成本先验使用。

**定义 318（接触后 aleatoric 转化）** 越过 F 后，物体位姿的 epistemic 不确定性 **转化为**接触/滑移的 aleatoric 不确定性：U_post = Var(slip) + Var(compliance) + Var(friction)。此时「再问」无效，只能走 R68 的 λ_floor(U_post) 与恢复；这是 R69 二分在时间轴上的**类型迁移**。

**定义 319（置信错配门 CMD）** 监视 Δ_c 与校准曲线：若 conf_sem 高而 conf_geo/p_succ 低（Δ_c > τ_c 或 ECE_geo 越界），则**禁止**把语义置信用于 VoI 与承诺排序，退化为仅几何/接触证据的保守模式；不得用「检测很确定」为「抓得稳」背书。

**定义 320（幻影抓取干扰集 ℰ_phantom）** 幻觉物体、透明/反光假表面、柔性/可压缩假稳固、遮挡 amodal 补全假边缘、旋转对称位姿不可辨、对抗纹理、抓取可供性对抗样本；以及 ℰ_commit = {过早闭合、力越界、滑移未及时释放}。总干扰集 ℰ_GRASP = ℰ_FLUID × ℰ_phantom × ℰ_commit。

**定义 321（证书 J_GRASP）** J_GRASP = (J_FLUID, p_succ_ece, amplification_margin_p05, reversal_budget_used, delayed_evidence_verdicts, phantom_grasp_rate, grasp_ver)。Valid ⇔ Valid(J_FLUID) ∧ p_succ_ece ≤ τ_p_ece ∧ 承诺守恒满足 ∧ 延迟证据账本闭合。

**定义 322（反转预算与恢复 PGR）** 全局反转预算 B_rev（执行/回退的次数与能量）；每次软承诺消耗之；耗尽即冻结并退回 R68 最保守。恢复策略 PGR 在 τ_e > w_rev 时执行 place/release/regrasp，且每次恢复本身受 B_rev 约束，保证单调不恶化。

**定义 323（严格包含）** 当 R(a)≡0（完全可逆，α=1）且检测抓取充分（𝒟 无 deficiency）时，GRASP-RAS 逐指令退化为 FLUID-RAS；当再关闭交互时退化为 CALM-RAS/R68；当再无可约歧义时退化为更早轮次。安全侧永不因新增承诺层而下降。

## 2. 关键算法骨架

```python
# IP-264 TCD/GSF：抓取充分检测 + 抓取成功场（按需聚焦，不重跑全图）
class GraspSufficientDetector:
    def detect(self, o_t, task_ctx):
        D = self.foveated_detector(o_t, roi=task_ctx.roi)   # 先粗提案
        return [self.attach_geometry(d, o_t) for d in D]    # 深度/法向/可变形性
    def p_succ(self, h, D):                                  # 抓取成功场
        return self.field(h, D)                              # 已校准，给 ECE
    def sufficient(self, D, need):                           # 定义 311 的充分性检查
        return info_retained(D, need) >= 1 - self.eps_suff

# IP-266 UAM：力臂放大与放大裕度（决定前承诺预算与 τ_m）
def amplify(pose_cov, contact_pts):
    out = []
    for r in contact_pts:                                    # r = 接触点力臂
        J = np.hstack([np.eye(3), -skew(r)])                 # 定义 313
        Sig_c = J @ pose_cov @ J.T
        out.append((np.sqrt(np.trace(Sig_c) / np.trace(pose_cov)), r, Sig_c))
    return out

def amp_margin(h, D, o_t):
    Sig_c = amplify(D[h.i].Sigma, [h.contact_r])[0][2]
    clearance = signed_clearance(h, D, o_t)
    return clearance / np.sqrt(np.trace(Sig_c) + 1e-9)       # ≥ τ_m 才允许硬承诺

# IP-269 SGC：软承诺——用力限位/半合拢换取接触证据
def soft_commit(h, D, budget):
    best = None
    for beta in np.linspace(0, 1, 6):                        # 承诺强度
        if budget.rev_left < R(beta):        continue        # 反转预算
        if rho(beta) > EPS_C:                continue        # 物理风险上界
        score = nu(beta) * contact_voi(h, D) - cost(beta)
        if best is None or score > best.score: best = (beta, score)
    return best if best and best.score > 0 else None          # 否则纯信息动作/等待

# IP-268 CCG：闭合前三方互证（语义/几何/接触-力），单源不得闭合
def can_close(h, D, o_t, ledger):
    ev = {'geo':  geo_consistent(h, D),
          'sem':  sem_consistent(h, D),
          'con':  contact_onset(o_t, h),
          'frc':  force_profile_ok(o_t, h)}
    ortho = orthogonal_agree(ev, min_sources=2, rho_max=0.9)
    return (ortho and GSF.p_succ(h, D) >= TAU_P
            and amp_margin(h, D, o_t) >= TAU_M
            and retreat_path_certified(h, D))

# IP-275 主闭环：R69 闭环 + 承诺边界三段化
def GRASP_RAS_round(M, obs):
    D  = M.tcd.detect(obs, M.task_ctx)                      # IP-264
    z  = M.mtm.forward(obs)                                 # R69 trunk
    U_ale, U_epi, modes = M.aud.decompose(M.fmp.sample(obs), z)   # R69
    # --- 前承诺区：R69 的 VoI，但阈值被不可逆性抬高 ---
    alpha = M.ifr.reversibility(modes)                      # 1 可逆，0 不可逆
    L_wrong = M.ifr.expected_loss(modes)
    g = (M.mint.choose_interaction(modes, obs, M.budget, option_bonus=(1-alpha)*L_wrong)
         if M.ifr.zone(obs) is Zone.REV else None)
    if g: U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    # --- 门前区：选风险加权假设，算放大裕度 ---
    hs = [h for h in M.gsf.candidates(D, modes) if amp_margin(h, D, obs) >= TAU_M]
    h_star = max(hs, key=lambda h: M.gsf.Q(h), default=None)
    if h_star is None or M.cmd.mismatch(D) > TAU_C:         # 置信错配 → 保守
        return M.fallback_R68(U_ale + U_epi)
    # --- 承诺门：先软承诺取证，再决定硬承诺 ---
    if M.ifr.zone(obs) is Zone.FRONT:
        beta = M.sgc.soft_commit(h_star, D, M.budget)       # IP-269
        if beta is not None:
            M.del.record(h_star, beta, t=now())
            if not M.ccg.can_close(h_star, D, obs, M.del):  # 物理互证失败
                return M.fallback_R68(U_ale + U_epi)        # 不闭合，退回求证
    k = M.grasp_wm.certified_prefix(M.ifr.commit(h_star), H=1)
    # --- 后承诺区：epistemic→aleatoric，交给 R68 底线 + 恢复 ---
    U_post = M.pgr.post_contact_uncertainty(obs)            # IP-272
    lam = max(M.efs.risk_scale(...), M.efs.lam_floor(U_ale + U_post))
    M.del.audit_async(h_star, M.pgr)                         # IP-270 追溯审计
    return k, lam, h_star, (U_ale, U_epi, U_post)

## 3. 推导

**引理 19（力臂放大界与求证价值的几何标度）** 设位姿误差 (δt, δθ)，接触点力臂 r，则接触误差 ‖δp_c‖ ≤ ‖δt‖ + ‖r‖‖δθ‖ + O(δθ²)，且 tr Σ_c ≤ tr Σ_t + r² tr Σ_θ。于是放大因子 κ(r) 随 ‖r‖ 单调增。若 p_succ 对接触位置的 Lipschitz 常数为 L_p，则前承诺求证的边际价值满足 ∂VoI/∂‖r‖ ≥ L_p·σ_θ·(1 − o(1))。**系**：同一份位姿不确定性，在长力臂抓取上更值得先求证；「无差别地都慢下来」在短力臂上是浪费、在长力臂上仍不足——预算必须随 r 伸缩，而不是一个全局 λ。

**引理 20（不可逆性抬高求证阈值，R69 为 α=1 的退化）** 设错误承诺的期望损失 E[L_wrong]，错误可恢复比例 α∈[0,1]。承诺销毁「再等一等」的期权，其价值为 (1−α)·E[L_wrong]。故前承诺区的最优求证判据为
VoI(g) − c(g) + (1−α)·E[L_wrong] > 0。
当 α=1 时逐项等于 R69 的 VoI>c；当 α=0 时阈值最高，必须在门前更积极地求证。**系**：R69 不是被取代，而是被识别为「完全可逆」这一边界；越接近不可逆前沿，越应把预算前移。

**引理 21（软承诺的证据产出界）** 设承诺强度 β 的证据产出概率 ν(β)、物理风险 ρ(β)，且在力限位下 ρ(β) ≤ ε_c。则一次 β-软承诺以期望代价 E[R(β)] ≤ R_max 换取 ν(β) 的接触证据；当 τ_e ≤ w_rev 时，该证据可在闭合前证伪假设。若 ν、ρ 对 β 单调，则存在 β* 使「单位可逆性损失换取的证据增益」最大。**系**：不需要在「完全不碰」与「完全闭合」之间二选一——可以在前承诺区**分期付款**地买证据。

**定理 18（GRASP-RAS 对 FLUID-RAS/R68 的严格包含与单调安全）** 在 R69 A95–A98 与本轮 A99–A101 下，任意状态上 GRASP-RAS 的期望风险 ≤ FLUID-RAS ≤ CALM-RAS；且当 R≡0 且检测抓取充分时三者逐指令相同；当 Δ_c>τ_c、ECE 越界或 B_rev 耗尽时，GRASP-RAS 单调退化为 R69/R68 的最保守行为。承诺守恒（定义 310-ii）保证安全侧不因新增承诺层而下降，效率侧仅从「放大感知的前承诺求证」获得收益。

**定理 19（幻影抓取上界）** 若闭合必须满足 CCG 的 ≥2 个正交源一致且 ρ<1、p_succ 与放大裕度达标，则幻影抓取率 ≤ δ_phys·ρ^{k−1} + ε_slip + ε_ece，其中 δ_phys 为单物理源的伪造成功率，ε_slip 为难检滑移。**系**：把「检测置信」当成「抓取可行」是唯一能绕过该界的方式（单源），故 CMD（定义 319）是上界成立的必要条件，而非可选优化。

**定理 20（延迟证据的有界遗憾与单调恢复）** 若证据时延 τ_e ≤ w_rev，追溯审计可在反转窗口内撤销错误承诺，遗憾 ≤ c_rev；若 τ_e > w_rev，则遗憾 ≤ E[L_wrong] + c_recover，且恢复受 B_rev 约束、每次恢复后系统状态不劣于承诺前的最保守基线 ⇒ 长时程上无累积恶化（恢复本身不会制造更差的状态）。

## 6. 本轮最大风险

**一句话**：GRASP-RAS 把 R69 的「问错」升级为「**抓错并盖章**」——它的全部承诺门保证都建立在「抓取成功场 p_succ 与位姿放大模型是校准的」这一前提上；一旦在透明/反光、柔性/可压缩、旋转对称或遮挡严重的物体上，几何置信被系统性高估（或者物理互证被物体本身伪造：假表面给出真接触、软物给出假稳固），**系统就会用一次真实接触为一次幻觉检测背书**，把本可撤销的犹豫结算成带安全证书的不可逆失败。

**次级风险与缓解**：
1. **检测—抓取表示不匹配**（框 → 接触几何丢失）→ TCD 使用抓取充分表示 + E301 充分性度量；
2. **放大模型低估**（杠杆、对称、遮挡）→ UAM 保守上界 + 群等变位姿假设 + E302/E307；
3. **软承诺被当成硬证据** → CCG 要求 ≥2 正交源 + 力/滑移轮廓 + 定理 19 上界；
4. **延迟证据超过反转窗口** → DEL 账本 + 恢复策略 + B_rev 单调约束（定理 20）；
5. **语义置信污染几何判断** → CMD 硬门，Δ_c 越界即只用几何/接触证据，绝不「检测很确定所以抓得稳」。

    D = M.tcd.detect(obs, M.task_ctx)                             # IP-264
    z = M.mtm.forward(obs)
    U_ale, U_epi, modes = M.aud.decompose(M.fmp.sample(obs), z)   # R69
    # 前承诺区：R69 的 VoI，阈值被不可逆性抬高（引理 20）
    alpha, L_wrong = M.ifr.reversibility(modes), M.ifr.expected_loss(modes)
    g = (M.mint.choose_interaction(modes, obs, M.budget,
                                   option_bonus=(1 - alpha) * L_wrong)
         if M.ifr.zone(obs) is Zone.REV else None)
    if g: U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    # 门前区：选风险加权假设 + 放大裕度门
    hs = [h for h in M.gsf.candidates(D, modes) if amp_margin(h, D, obs) >= TAU_M]
    h_star = max(hs, key=M.gsf.Q, default=None)
    if h_star is None or M.cmd.mismatch(D) > TAU_C:               # 置信错配 → 保守
        return M.fallback_R68(U_ale + U_epi)
    # 承诺门：先软承诺取证，再决定硬承诺
    if M.ifr.zone(obs) is Zone.FRONT:
        beta = M.sgc.soft_commit(h_star, D, M.budget)             # IP-269
        if beta is not None:
            M.del.record(h_star, beta, t=now())
            if not M.ccg.can_close(h_star, D, obs):               # 物理互证失败
                return M.fallback_R68(U_ale + U_epi)
    k = M.grasp_wm.certified_prefix(M.ifr.commit(h_star), H=1)
    # 后承诺区：epistemic→aleatoric，交给 R68 底线 + 恢复
    U_post = M.pgr.post_contact_uncertainty(obs)                  # IP-272
    lam = max(M.efs.risk_scale(...), M.efs.lam_floor(U_ale + U_post))
    M.del.audit_async(h_star, M.pgr)                              # IP-270
    return k, lam, h_star, (U_ale, U_epi, U_post)
```

## 4. 推导

**引理 19（力臂放大界与求证价值的几何标度）** `‖δp_c‖ ≤ ‖δt‖ + ‖r‖‖δθ‖`，`trΣ_c ≤ trΣ_t + r²trΣ_θ`，故 `κ(r)` 随 `‖r‖` 单调增；若 `p_succ` 对接触位置 Lipschitz 常数为 `L_p`，则 `∂VoI/∂‖r‖ ≥ L_p·σ_θ`。系：同一份 pose 不确定性，长力臂抓取更值得先求证；预算须随 r 伸缩，而非全局固定 λ。

**引理 20（不可逆性抬高求证阈值，R69 为 α=1 退化）** 承诺销毁「等一等」期权，价值 `(1−α)·E[L_wrong]`；前承诺区最优判据为 `VoI(g) − c(g) + (1−α)·E[L_wrong] > 0`。α=1 时逐项等于 R69 的 `VoI>c`；α=0 时阈值最高。系：R69 是「完全可逆」边界；越近不可逆前沿，越应把预算前移。

**引理 21（软承诺证据产出界）** 力限位下 `ρ(β)≤ε_c`；β-软承诺以 `E[R(β)]≤R_max` 换 `ν(β)` 的接触证据，`τ_e≤w_rev` 时可在闭合前证伪假设。ν、ρ 对 β 单调 ⇒ 存在 β* 使单位可逆性损失换取的证据增益最大。系：可在「不碰」与「全闭合」之间**分期付款买证据**。

**引理 22（抓取充分性的信息下界）** 若表示 𝒟 对抓取所需变量（接触点、法向、摩擦、可变形性）的条件互信息低于阈值 `I_min`，则任意下游规划器在 𝒟 上的最小期望损失至少比 `o_full` 高 `ΔL(I_min)`。系：框表示的 deficiency 不能被规划器「补回来」——必须改检测表示（TCD），这是上游结构性问题。

**定理 18（GRASP-RAS 严格包含且单调安全）** A99–A101 下，任意状态期望风险 `GRASP ≤ FLUID ≤ CALM`；`R≡0` 且检测抓取充分时逐指令相同；`Δ_c>τ_c`、ECE 越界或 `B_rev` 耗尽时单调退化为 R69/R68 最保守行为。承诺守恒保证安全侧不降，效率仅来自放大感知的前承诺求证。

**定理 19（幻影抓取上界）** CCG 要求 ≥2 正交源一致且 ρ<1、p_succ 与放大裕度达标，则幻影抓取率 `≤ δ_phys·ρ^{k−1} + ε_slip + ε_ece`。系：把「检测置信」当「抓取可行」是唯一绕过该界的单源路径 ⇒ CMD 为上界成立的必要条件。

**定理 20（延迟证据有界遗憾与单调恢复）** `τ_e≤w_rev` 时追溯审计可撤销错误承诺，遗憾 `≤c_rev`；`τ_e>w_rev` 时遗憾 `≤E[L_wrong]+c_recover`，恢复受 `B_rev` 约束且每次恢复后状态不劣于承诺前最保守基线 ⇒ 长时程无累积恶化。

## 7. 本轮最大风险

**一句话**：GRASP-RAS 把 R69 的「问错」升级为「**抓错并盖章**」——承诺门的全部保证都押在「抓取成功场与位姿放大模型已校准」这一前提上；在透明/反光、柔性/可压缩、旋转对称或遮挡严重的物体上，几何置信会被系统性高估，物理互证甚至会被物体本身伪造（假表面给出真接触、软物给出假稳固），于是系统用一次真实接触为一次幻觉检测背书，把本可撤销的犹豫结算成带安全证书的不可逆失败。

**次级风险与缓解**：检测—抓取表示不匹配（TCD + E301 充分性度量）；放大模型低估（UAM 保守上界 + 群等变 + E302/E307）；软承诺被当硬证据（CCG ≥2 正交源 + 力/滑移轮廓 + 定理 19）；延迟证据超反转窗口（DEL + PGR + B_rev 单调约束，定理 20）；语义置信污染几何判断（CMD 硬门，Δ_c 越界即只用几何/接触证据）。
