# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「专利布局」×「人机协作」）

> 第 54 轮把动作空间变成技能组合的第一性约束，并用云边联合证书保证部署。本轮引入两个看似“非技术”的灵感词，却都能被严格形式化：**专利布局 = 在特征空间上用权利要求区域做覆盖与白空间搜索**；**人机协作 = 在共享动作空间上做可验证的权威分配与交接**。核心矛盾：H22：人机各自有动作剖面，权威却常由惯例固定，导致过度信任（机器在自身 α_M 低的区域仍掌权）与信任不足（人在高负荷下被迫掌权），协作在交接边界处系统性失效；H23：已有 120+ 个 IP 却无“专利地图”，新想法可能与旧主张重叠（新颖性风险）或落在覆盖之外，且主张的有效性谱 ν 与鲁棒性谱 ρ 一样是不确定的。

## 0. 直觉与动机

**灵感 1（专利 = 设计空间里的权利区域，而非法律文书）**
直觉：一条权利要求本质上是特征空间 `F` 中的一个“受保护区域”。全部要素规则（all-elements rule）给出区域的核心约束；等同原则（doctrine of equivalents）给出一个容差半径 `ε`。于是单条权利要求 `C` 可以写成区域 `R(C)`，一个专利组合就是一个区域并集，**白空间 = 设计空间减去并集**。专利布局由此从“写文书”变成 **集合覆盖 + 空白发现** 问题。更进一步，权利要求的有效性不是布尔值：面对新颖性、非显而易见性、充分公开、清楚性等攻击维度，它有一条 **有效性谱 `ν_C`**，与第 53 轮的鲁棒性谱 `ρ` 在数学上同构。

**灵感 2（人机协作 = 共享动作空间上的权威分配，而非“人监督机器”）**
直觉：把第 54 轮的动作剖面扩展到人：人 `α_H`、机器 `α_M`，二者定义在共享动作空间 `A_HM = A_H × A_M` 上。协作不是单一的主从关系，而是一个随状态变化的 **权威函数 `auth(s) ∈ Δ({H, M, SH})`**。协作失败的两端是 **过度信任**（在 `α_M` 低的区域仍把权威给机器）与 **信任不足**（在 `α_H` 低且负荷高的区域仍由人掌权）。可验证的协作要求：在任意状态，权威持有者的动作剖面必须以裕度覆盖任务动作。

**灵感 3（交接证书 = “何时该放手/接手”的形式化）**
直觉：人在回路的关键风险发生在交接瞬间。上一轮的云边映射 `γ_ce : A_c→A_e` 可以平移为 **人机映射 `γ_HM`**，但目标端的“带宽”是人的认知容量而非网络带宽。交接契约 `HOC` 以信任 `τ`、工作负荷 `ω`、态势感知 `σ`、人机意图对齐误差 `δ_h` 为前置条件，把“能不能交接”变成可判定的守卫，而不是驾驶舱里的口头确认。

**灵感 4（信任谱与鲁棒性谱同构，且需耦合修正）**
直觉：信任是多维的（能力、可预测性、透明度、善意、及时性），并在分布漂移下退化，因此可写成 **信任谱 `τ_HM : D_trust → [0,1]`**。团队鲁棒性不是 `min(ρ_H, ρ_M)`：人能在机器失效时补偿（compensation），机器也能诱发人的自满（complacency / 能力退化）。因此需要 **耦合矩阵 `K_HM`** 对 `ρ_H, ρ_M` 做带符号合成——这与上一轮技能组合的耦合矩阵 `K` 是同一套机制。

**灵感 5（把白空间接入研究循环：专利感知的元循环）**
直觉：我们积累的 120+ IP 已有“技术分层”，却没有“权利覆盖”视图。把组合形式化后，**未被覆盖的白空间** 与 **有效性下界低的薄弱主张** 就指明了下一轮该往哪里推。于是灵感循环本身可被白空间搜索引导：在候选方向中最大化 `新颖性 × 可复用性 × 主张强度下界`，从“随机灵感”升级为 **专利感知的研究元循环**。这把“专利布局”从成果保护手段变成 **创新方向的导航器**。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（权利要求区域与有效性谱）**
设特征空间 `F` 带度量 `d_F`。权利要求 `C = (E_C, f_C, ε_C, ν_C)`，其中 `E_C` 为必要要素集，`f_C` 为标准特征向量，`ε_C` 为等同容差半径。其区域
```
R(C) = { x ∈ F | E_C ⊆ feat(x) } ∪ { x ∈ F | d_F(f_C, x) ≤ ε_C }
```
即“字面侵权区 ∪ 等同侵权区”。**有效性谱** `ν_C : D_prior → [0,1]`，`D_prior = {新颖性, 非显而易见性, 充分公开, 清楚性, 支持性}`，`ν_C(d)` 为在第 `d` 类现有技术攻击下主张存活的概率。

**定义 122（专利组合覆盖、白空间与稳健覆盖）**
组合 `P = {C_1,...,C_m}`，目标设计域 `D`：
```
cov(P,D) = |(∪_i R(C_i)) ∩ D| / |D|
W(P,D)   = D \ ∪_i R(C_i)                # 白空间
block(P,x)= 1[ x ∈ ∪_i R(C_i) ]          # 对竞品 x 的阻断力
```
**稳健覆盖** `cov_robust(P,D) = min_{d∈D_prior} ∫_D ν_P(d,x) dx / |D|`，其中 `ν_P(d,x)=max_{i: x∈R(C_i)} ν_{C_i}(d)`。只有 `cov_robust` 才是可对外承诺的覆盖，普通 `cov` 是乐观上界。

**定义 123（人机共享动作空间与权威剖面）**
`A_HM = A_H × A_M`；人动作剖面 `α_H,A_M→[0,1]`，机器 `α_M`（沿用定义 115 的语义）。**权威函数** `auth : S → Δ({H, M, SH})`，`SH` 为共享/协同模式。有效覆盖：
```
cover_HM(s,a) = Σ_{h∈{H,M,SH}} auth(s)[h] · α_h^{eff}(s,a)
```
要求 `cover_HM(s, A_T(s)) ≥ θ_cov` 且存在裕度 `m_cov`。其中 `α_SH^{eff}` 由 `min(α_H, α_M)` 经协同增益修正。

**定义 124（人机交接契约）**
`HOC = (Modes, auth, τ_min, ω_max, σ_min, Θ_h, evidence)`。`H→M` 交接允许当且仅当
```
τ_HM(s) ≥ τ_min ∧ ω_H(s) ≤ ω_max ∧ σ_H(s) ≥ σ_min ∧ δ_h(s) ≤ Θ_h
```
`M→H` 交接额外要求 `explain_ready(s)`（机器能在 `τ_exp` 内生成可理解解释）。`δ_h(s) = W_1(intent_H(s), intent_M(s))`，即人意图分布与机器推断意图分布的一阶 Wasserstein 距离。

**定义 125（信任谱与协作鲁棒性）**
信任谱 `τ_HM : D_trust → [0,1]`，`D_trust = {能力, 可预测性, 透明度, 善意, 及时性}`。团队鲁棒性：
```
ρ_HM(d) = compose(ρ_H(d), ρ_M(d), K_HM, τ_HM)
```
`K_HM[i,j] ∈ [-1,1]`：正元表示补偿（一方失效被另一方接住），负元表示放大（自满、误校准）。`compose` 在 `ρ_H=ρ_M=1` 时返回 1，且对 `K_HM` 单调。

**定义 126（专利-协作联合证书）**
```
K = (ρ_HM, α_H, α_M, auth, HOC, ν_P, cov_robust(P,D), W(P,D), δ_h, δ_p, evidence)
```
其中 `δ_p` 为主张区域解析保真度误差。**可部署** 当且仅当
```
dom(ρ_HM)=in ∧ δ_h ≤ Θ_h ∧ cov_robust(P,D) ≥ Cov_min ∧ FTO(x)=1 ∧ δ_p ≤ Θ_p
```
即团队同时在“动作空间安全”与“权利空间清晰”两个意义下可辩护。

## 2. 关键算法 伪代码

### IP-121 HAC（Human Action Characterization）

```python
def human_action_profile(operator, states, actions, sim, n_probe, tau_h):
    alpha_H = {}
    for s in states:
        load = operator.cognitive_load(s)
        for a in actions:
            succ, t, conf = sim.probe_human(operator, s, a, n_probe)
            alpha_H[(s, a)] = succ * conf * time_gate(t, tau_h) * load_gate(load)
    return calibrate(alpha_H, operator.calibration_data)
```

### IP-122 HOC（Handover Guard）

```python
def handover_guard(src, dst, s, tau_HM, omega_H, sigma_H, delta_h, HOC):
    if src == 'H' and dst == 'M':
        ok = (tau_HM[s] >= HOC.tau_min and omega_H[s] <= HOC.omega_max
              and sigma_H[s] >= HOC.sigma_min and delta_h[s] <= HOC.Theta_h)
    elif src == 'M' and dst == 'H':
        ok = (sigma_H[s] >= HOC.sigma_min
              and omega_H[s] <= HOC.omega_takeover_max
              and explain_ready(s, HOC.tau_exp))
    else:
        ok = delta_h[s] <= HOC.Theta_h
    return ('allow' if ok else 'hold', HOC.evidence(s))
```

### IP-123 CPC（Collaboration Policy Certification）

```python
def synthesize_authority(MDP, alpha_H, alpha_M, HOC, theta_cov, margin):
    policy = {}
    for s in MDP.states:
        feasible = []
        for holder in ['H', 'M', 'SH']:
            cov = cover_HM(s, MDP.task_actions(s), holder,
                           alpha_H, alpha_M)
            if cov >= theta_cov + margin:
                feasible.append((authority_cost(holder, s), holder))
        if feasible:
            _, h = min(feasible)
            if handover_guard(policy.get(prev(s), 'H'), h, s, ...)[0] == 'allow':
                policy[s] = h
            else:
                policy[s] = policy.get(prev(s), 'H')   # 保持，不冒险切换
        else:
            policy[s] = 'H'                            # 保守回退到人
    return policy
```

### IP-124 PPM（Patent Portfolio Mapper）

```python
def build_patent_map(claims, D, sampler, n=20000):
    regions = {c.id: claim_region(c) for c in claims}      # 解析 E_C, f_C, ε_C
    xs = sampler(D, n)
    covered = [any(in_region(x, regions[c.id]) for c in claims) for x in xs]
    coverage = sum(covered) / len(xs)
    white = [x for x, m in zip(xs, covered) if not m]
    block = {cid: volume(regions[cid]) for cid in regions}
    return PatentMap(regions, coverage, white, block)
```

### IP-125 VRS（Validity Robustness Spectrum）

```python
def validity_spectrum(claim, prior_art, attack_dims, n_perturb):
    nu = {}
    for d in attack_dims:
        surv = []
        for _ in range(n_perturb):
            pert = perturb_claim(claim, d, prior_art)       # 现有技术邻域扰动
            surv.append(survives(pert, prior_art))
        nu[d] = lower_confidence_bound(surv, alpha=0.95)
    return nu
```

### IP-126 WSS（White-Space Search，元循环导航）

```python
def white_space_search(P, IP_lib, candidate_dirs, min_score):
    best = None
    for cand in candidate_dirs:
        novelty = distance_to_portfolio(cand, P)            # 离既有主张越远越高
        feasibility = reuse_score(cand, IP_lib)             # 可复用已有 IP 的程度
        nu_lb = min(validity_spectrum(cand.claim, P.prior_art,
                                      D_prior).values())
        score = novelty * feasibility * nu_lb
        if score >= min_score and (best is None or score > best[1]):
            best = (cand, score, novelty, feasibility, nu_lb)
    return best
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| HAC | O(|S|·|A|·n_probe) | O(|S|·|A|) | 人因探针覆盖、负荷门控 |
| HOC | O(|S|) per guard | O(|Modes|) | 条件可判定、解释就绪 |
| CPC | O(|S|·|A|·|Modes|) | O(|S|) | 覆盖裕度、保守回退 |
| PPM | O(n·|P|·|E_C|) | O(n) | 区域解析保真 δ_p |
| VRS | O(|D_prior|·n_perturb·cost_survive) | O(|D_prior|) | 下置信界 sound |
| WSS | O(|cand|·|D_prior|·n_perturb) | O(|cand|) | 三项分数单调、可复算 |

**正确性定理（Human-Machine Teaming + Portfolio Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** `α_H, α_M` 由人因探针与结构化仿真校准，覆盖 ≥95%；**(A30)** 信任谱由行为探针测量且单回合内稳定；**(A31)** 交接延迟 ≤ `τ_hand` 且 `M→H` 时解释就绪；**(A32)** 权利要求区域解析保真 `δ_p ≤ Θ_p` 且有效性下界 sound。则：
```
P_success ≥ 1 - Σ_d (1-ρ_HM(d)) - P(δ_h > Θ_h) - P(over-trust) - P(under-trust)
clearance ≥ min_d ν_P(d)   对 x ∈ ∪R(C_i)；白空间按定义暴露为未覆盖
```
关键：**权威持有者的动作覆盖是安全前提，交接守卫切断过度/不足信任，ν 下界保证覆盖不是“纸面覆盖”**。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 人因探针不具代表性、α_H 偏差 | 高 | 多操作者分层采样 + 在线校准 + 保守门控 |
| 信任谱测的是“自报信任”而非行为信任 | 高 | 行为探针（依赖率/接管时延/覆写率）+ 反事实对比 |
| 交接时解释过载反而增加负荷 | 中 | 分级解释 + 负荷自适应摘要 |
| 权利要求解析失真导致 δ_p 超标 | 高 | 双人标注 + 形式化要素本体 + 保真度审计 |
| 有效性下界过于乐观（纸面覆盖） | 高 | 红队现有技术检索 + 下置信界 + 保守 Cov_min |
| 白空间搜索诱导“为专利而专利” | 中 | 可复用性/可实现性约束 + 伦理与安全审查 |

## 6. 本轮最大风险

**一句话**：把“专利布局”与“人机协作”统一为动作覆盖与权利覆盖的双证书，理论闭环优雅，但其 soundness **同时押注于人因探针的真实性、信任谱的行为可测性、以及权利要求解析与有效性下界的保真**；一旦把人自报的信任当行为信任、或把乐观的 `cov` 当 `cov_robust`，系统就会在最危险的过度信任区间给出“安全且已保护”的假保证，故必须以 **行为信任探针 + 解析保真审计 + 有效性下置信界** 三重护栏，并默认回退到保守权威与未覆盖假设。

```python
        ok = (sigma_H[s] >= HOC.sigma_min
              and omega_H[s] <= HOC.omega_takeover_max
              and explain_ready(s, HOC.tau_exp))
    else:
        ok = delta_h[s] <= HOC.Theta_h
    return ('allow' if ok else 'hold', HOC.evidence(s))
```

### IP-123 CPC

```python
def synthesize_authority(MDP, alpha_H, alpha_M, HOC, theta_cov, margin):
    policy, prev = {}, None
    for s in MDP.states:
        feasible = []
        for holder in ['H', 'M', 'SH']:
            cov = cover_HM(s, MDP.task_actions(s), holder, alpha_H, alpha_M)
            if cov >= theta_cov + margin:
                feasible.append((authority_cost(holder, s), holder))
        if feasible:
            _, h = min(feasible)
            if handover_guard(prev or 'H', h, s, ...)[0] == 'allow':
                policy[s] = h
            else:
                policy[s] = prev or 'H'
        else:
            policy[s] = 'H'          # 无人满足覆盖裕度 → 回退到人并降级任务
        prev = policy[s]
    return policy
```

### IP-125 VRS

```python
def validity_spectrum(claim, prior_art, attack_dims, n_perturb):
    nu = {}
    for d in attack_dims:
        surv = []
        for _ in range(n_perturb):
            pert = perturb_claim(claim, d, prior_art)
            surv.append(survives(pert, prior_art))
        nu[d] = lower_confidence_bound(surv, alpha=0.95)
    return nu

def robust_coverage(P, D, nu_by_claim, sampler, n=20000):
    xs = sampler(D, n)
    vals = []
    for x in xs:
        hit = [nu_by_claim[c.id] for c in P.claims if x in P.regions[c.id]]
        vals.append(max((min(v.values()) for v in hit), default=0.0))
    return sum(vals) / len(vals)
```

### IP-126 WSS

```python
def white_space_search(P, IP_lib, candidate_dirs, min_score):
    best = None
    for cand in candidate_dirs:
        novelty = distance_to_portfolio(cand, P)
        feasibility = reuse_score(cand, IP_lib)
        nu_lb = min(validity_spectrum(cand.claim, P.prior_art, D_prior).values())
        score = novelty * feasibility * nu_lb
        if score >= min_score and (best is None or score > best[1]):
            best = (cand, score, novelty, feasibility, nu_lb)
    return best
```

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| HAC | O(|S|·|A|·n_probe) | O(|S|·|A|) | 人因探针覆盖 ≥95%，负荷门控 |
| HOC | O(|S|) per guard | O(|Modes|) | 条件可判定，解释就绪可验证 |
| CPC | O(|S|·|A|·|Modes|) | O(|S|) | 覆盖裕度 + 保守回退，策略 sound |
| PPM | O(n·|P|·|E_C|) | O(n) | 区域解析保真 `δ_p`，采样式覆盖无偏 |
| VRS | O(|D_prior|·n_perturb·c_surv) | O(|D_prior|) | 下置信界 sound，抗乐观偏差 |
| WSS | O(|cand|·|D_prior|·n_perturb) | O(|cand|) | 分数可复算、方向可审计 |

**正确性定理（Human-Machine Teaming + Portfolio Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** `α_H, α_M` 由人因探针与结构化仿真校准，覆盖 ≥95%；**(A30)** 信任谱由行为探针测量且单回合内稳定；**(A31)** 交接延迟 ≤ `τ_hand` 且 `M→H` 时解释就绪；**(A32)** 权利要求区域解析保真 `δ_p ≤ Θ_p` 且有效性下界 sound。则：
```
P_success ≥ 1 - Σ_d(1-ρ_HM(d)) - P(δ_h > Θ_h) - P(over-trust) - P(under-trust)
clearance ≥ min_d ν_P(d)   对 x ∈ ∪R(C_i)
```
关键：**覆盖是安全前提，交接守卫切断过度/不足信任，ν 下界保证覆盖不是纸面覆盖**。

## 6. 本轮最大风险

**一句话**：把“专利布局”与“人机协作”统一为动作覆盖与权利覆盖的双证书，理论闭环优雅，但其 soundness **同时押注于人因探针的真实性、信任谱的行为可测性、以及权利要求解析与有效性下界的保真**；一旦把人自报的信任当行为信任、或把乐观的 `cov` 当 `cov_robust`，系统就会在最危险的过度信任区间给出“安全且已保护”的假保证，故必须以 **行为信任探针 + 解析保真审计 + 有效性下置信界** 三重护栏，并默认回退到保守权威与未覆盖假设。
