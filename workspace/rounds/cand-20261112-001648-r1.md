# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「跨物体泛化」×「腕部相机」）

> 第 54 轮把技能组合提升为「动作空间剖面 α_S + 云边协同 γ_ce + 动作-鲁棒性双证书 J」。本轮转向**物体维度**：策略在训练物体上鲁棒，并不等于在新物体上鲁棒；而腕部相机既是跨物体泛化最敏感的传感器，也是它最脆弱的环节。核心矛盾 **H22**：腕部观测与物体身份强耦合——同一相对位姿下不同物体产生完全不同的像素统计，模型容易学到「认物体」的身份捷径，而非可迁移的抓取几何；**H23**：跨物体泛化不能被平均成功率证明，必须在物体流形上给出**最坏情况**证书，而第 53–54 轮的 ρ(d) 是物体无关的平均量。

## 0. 直觉与动机

**灵感 1（腕部相机是跨物体泛化的双刃剑 → 视角-物体解耦）**
直觉：腕部相机贴近物体，能看到高分辨率局部几何、边缘与接触前微结构，这是跨物体泛化的信息源；但它同时把物体身份（颜色、纹理、反光、透明）直接编码进观测，且相机-物体相对位姿每变一点，像素分布就剧烈变化。于是模型很容易「认物体」而不是「认抓取」。关键不是换更大的模型，而是把腕部观测显式分解为 **物体本征表示 S_o** 与 **相对位姿算子 R_ξ**：`I_w = R_ξ(S_o) + n`。若能估计 ξ（本体感知前向运动学 + 物体位姿估计），就把腕部图归一化到**物体中心规范帧**，让「跨物体」变成「同一规范表示上的度量问题」，而不是像素分布匹配问题。

**灵感 2（跨物体泛化 = 物体流形上的最坏情况，而非平均）**
直觉：在训练分布上平均成功率高，可能只是在「容易物体」上刷分；真正的泛化是「在物体流形 O 的一个邻域内，最坏物体也过得去」。所以把 ρ(d) 升级为 **物体条件鲁棒性谱 ρ(o,d)**，泛化定义为 `gen(O_R) = min_{o∈O_R} min_d ρ(o,d)`。这把「泛化」从口号变成可验证的区域 B(o₀,ε)：证书只对落在球内的目标物体背书。

**灵感 3（腕部相机是主动探针 → 信息增益视角选择）**
直觉：腕部相机装在手上，天然可以绕物体移动。与其被动接受单一视角，不如主动选视角，最大信息增益地降低物体参数（尺寸、曲率、摩擦、软硬、透明度）的不确定性。视角是动作，必须落在可达且不被自遮挡的**视角流形 V_w ⊆ A_e** 内，并与第 54 轮的动作剖面 α_S 对齐：`α_S(v) ≥ θ_cov` 才允许作为探测视角。

**灵感 4（物体级失败签名 → 课程回传而非盲目扰动）**
直觉：边端腕部相机失败时，不应只回传「失败」，而应回传**物体级根因**：是几何（太薄/太宽/曲率突变）、外观（透明/高反光/低纹理）还是物理（太滑/太软/太重）。云端据此扩增物体课程并重加权域随机化，而不是盲目加大扰动幅度。这把第 53 轮的 Explain 从「扰动维度归因」扩展到「物体参数归因」。

**灵感 5（泛化风险金字塔 𝕆）**
直觉：在 𝕃（鲁棒性）与 𝔸（动作空间）之上叠加 **𝕆 层**：`𝕆_0` 物体物理参数、`𝕆_1` 腕部视角归一化、`𝕆_2` 物体条件鲁棒性、`𝕆_3` 跨物体证书迁移。跨层证书必须同时携带 `ρ(o,d)`、规范表示 `S_o`、归一化误差 `Δ_view` 与失败签名 `σ_fail`，形成**物体-动作-鲁棒性三证书**。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（物体流形）**
物体流形 `O = G × T × P`，其中 `g∈G` 为几何（尺寸、曲率、拓扑、对称性），`t∈T` 为外观（albedo、纹理、BRDF、透明度），`p∈P` 为物理（质量、摩擦、柔顺性）。度量
```
d_O(o,o') = ( w_g‖g-g'‖²_G + w_t‖t-t'‖²_T + w_p‖p-p'‖²_P )^{1/2}
```
物体球 `B(o₀,ε) = {o : d_O(o,o₀) ≤ ε}`；物体课程 `O_cur ⊆ O` 为仿真/真机覆盖集。

**定义 122（物体条件鲁棒性谱与泛化泛函）**
`ρ : O × D → [0,1]` 为在物体 o、扰动 d 下的任务成功概率（或归一化带符号裕度）。物体无关旧谱 `ρ_old(d) = E_{o~p_train}[ρ(o,d)]`。跨物体泛化泛函
```
gen(P, O_R) = min_{o∈O_R} min_{d∈D} ρ(o,d),     gen_ε(o₀) = min_{o∈B(o₀,ε)} min_d ρ(o,d)
```
采用 **min 而非平均**，是为了可证明的最坏情况保证；平均只作为报告指标。

**定义 123（腕部视角分解与归一化）**
腕部观测 `I_w = R_ξ(S_o) + n`，`ξ = T_obj⁻¹ T_cam ∈ SE(3)` 为相机-物体相对位姿（本体感知前向运动学 + 物体位姿估计），`S_o` 为物体规范表示，`n` 为遮挡/运动模糊/噪声。编码器 `E=(E_obj,E_pose)` 需同时满足：
- **物体不变性**：`∀ξ,ξ'∈V_w, ‖E_obj(R_ξ S_o) - E_obj(R_ξ' S_o)‖ ≤ Δ_view`；
- **物体可分辨性**：若 `d_O(o,o') ≥ ε`，则 `d(E_obj(S_o),E_obj(S_o')) ≥ δ_obj`；
- **位姿可重构性**：`E_pose(R_ξ S_o)` 可解码出 ξ（保留控制所需的相对几何）。
`Δ_view` 取上式上确界，称为归一化误差。

**定义 124（跨物体泛化证书）**
`GC = (o₀, ε, D, ρ_min, ρ̂_ε, Δ_view, O_cover, evidence)`，其中 `ρ̂_ε = min_{o∈B(o₀,ε)} min_d ρ̂(o,d)`。证书有效当且仅当：
```
(i)  B(o₀,ε) ⊆ O_cover                  （覆盖）
(ii) ρ̂_ε ≥ ρ_min                        （最坏情况鲁棒）
(iii) Δ_view ≤ Δ_max                    （视角归一化可信）
(iv) evidence 含留出物体反例 + 位姿估计置信度
```
**部署门**：仅当 `d_O(ô_t, o₀) ≤ ε` 且 `pose_conf ≥ c_min` 时，才允许部署到目标物体估计 `ô_t`。

**定义 125（主动腕部探测）**
视角流形 `V_w = {v ∈ SE(3) : reachable(v) ∧ ¬self_occluded(v)} ⊆ A_e`，且须满足第 54 轮动作剖面 `α_S(v) ≥ θ_cov`。给定历史 `h_t` 与物体后验 `b_t(o)`，选
```
a*_w = argmax_{v∈V_w} I(o ; I_w(v) | h_t)   s.t. cost(v) ≤ B_probe
```
当 `H(b_t) ≤ H_min` 或预算耗尽时停止。信息增益对视角集是次模的，故贪心策略有 `(1-1/e)` 近似保证。

**定义 126（物体失败签名）**
`σ_fail = (ô, cause ∈ {G,T,P}, d*, Δ_o, conf)`：`cause` 为边端 Explain 对失败反例的物体参数归因，`Δ_o` 为参数偏差估计。云端更新
```
O_cur ← O_cur ∪ B(ô, r_cause)
q(o) ∝ q₀(o) · exp( λ · 1[cause(o)=cause] )
```

## 2. 关键算法 伪代码

### IP-121 OCM（Object-Conditioned Manifold）

```python
def object_conditional_spectrum(policy, O_region, D, n_samples, rollouts):
    rho = {}
    for o in sample_manifold(O_region, n_samples):
        for d in D:
            succ = sum(rollout(policy, o, d).success for _ in range(rollouts))
            rho[(o, d)] = succ / rollouts
    return rho

def worst_case_ball(rho, o0, eps, metric):
    return min((rho[(o, d)] for (o, d) in rho if metric(o, o0) <= eps), default=0.0)
```

### IP-122 WNC（Wrist-view Normalization & Canonicalization）

```python
def wrist_factorize(I_w, xi, enc_obj, enc_pose):
    z_obj = pose_debias(enc_obj(I_w), xi)   # 对抗式不变性头，用 xi 去偏
    z_pose = enc_pose(I_w)
    return z_obj, z_pose

def wrist_loss(enc_obj, enc_pose, batch, w):
    # batch: (I1,I2) 同物体不同位姿； (I1,I3) 不同物体
    L_inv  = mean(‖enc_obj(I1) - enc_obj(I2)‖²)
    L_disc = mean(relu(margin - ‖enc_obj(I1) - enc_obj(I3)‖)²)
    L_pose = mean(‖decode_pose(enc_pose(I1)) - xi1‖²)
    return L_inv + w[0]*L_disc + w[1]*L_pose
```

### IP-123 OGC（Object Generalization Certificate）

```python
def object_generalization_certificate(policy, o0, eps, D, metric,
                                      coverage, delta_view, cfg):
    rho = object_conditional_spectrum(policy, B(o0, eps), D, cfg.n, cfg.rollouts)
    rho_eps = worst_case_ball(rho, o0, eps, metric)
    if not subset_ball(o0, eps, coverage):     return Reject('uncovered')
    if rho_eps < cfg.rho_min:                  return Reject('robustness')
    if delta_view > cfg.delta_max:             return Reject('view_shift')
    return Accept(GC(o0, eps, D, cfg.rho_min, rho_eps, delta_view, coverage, rho))
```

### IP-124 APW（Active Probing via Wrist）

```python
def active_probe(belief, V_w, alpha_S, budget, theta_cov, H_min):
    traj = []
    while entropy(belief) > H_min and budget > 0:
        cands = [v for v in V_w if alpha_S(v) >= theta_cov and reachable(v)]
        if not cands: break
        v_star = max(cands, key=lambda v: expected_info_gain(belief, v))
        if cost(v_star) > budget: break
        I_w = observe(v_star)
        belief = bayes_update(belief, I_w)
        budget -= cost(v_star)
        traj.append((v_star, belief))
    return belief, traj
```

### IP-125 OFS（Object Failure Signature）

```python
def object_failure_signature(sim, obs_w, action, o_est, explain):
    exp = explain(sim.run(action), sim)
    cause = argmax_c sim.counterfactual_attribution(exp, dim=c)  # c in {G,T,P}
    return FailureSig(o_est, cause, exp.dim, exp.delta, exp.conf)

def update_object_curriculum(O_cur, sig, r_cause, lam):
    O_cur.add_ball(sig.o_hat, r_cause)
    sampler.reweight(lambda o: exp(lam * (cause_of(o) == sig.cause)))
    return O_cur
```

### IP-126 OXT（Object-Conditioned Transfer）

```python
def object_transfer_certify(GC_src, o_t, metric, L_O, rho_min_t):
    dist = metric(o_t, GC_src.o0)
    if dist > GC_src.eps: return Reject('out_of_ball')
    rho_lb = {d: max(0.0, GC_src.rho_worst[d] - L_O * dist) for d in GC_src.D}
    if min(rho_lb.values()) < rho_min_t: return Reject('lipschitz_slack')
    return Accept(OCT(GC_src, o_t, dist, rho_lb))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| OCM | O(N_o·|D|·M) | O(N_o·|D|) | 流形采样覆盖、滚动评估无偏 |
| WNC | O(N·H·W) 每批 | O(1) 推理 | 不变性与可分辨性不冲突、ξ 可估 |
| OGC | O(|B|·|D|) 校验 | O(|B|·|D|) | 球覆盖完备、最坏情况下界 sound |
| APW | O(|V_w|·T_probe) | O(|V_w|) | 视角可达、信息增益次模 |
| OFS | O(|D|+|O|) | O(1) | 归因可辨、Explain sound |
| OXT | O(|D|) | O(1) | ρ 关于 o 的 Lipschitz 常数有效 |

**正确性定理（Cross-Object Generalization Soundness）**
假设 (A29) `ρ(·,d)` 在 O 上关于 `d_O` 为 `L_O`-Lipschitz；**(A30)** 腕部归一化误差 `≤ Δ_view` 且位姿估计误差 `≤ δ_ξ`；**(A31)** 部署前主动探测达到 `H(b) ≤ H_min`，或目标 `o_t ∈ B(o₀,ε)`；**(A32)** 物体失败签名归因正确率 `≥ 1-β_sig`。则对目标物体 `o_t`：
```
P_success(o_t) ≥ 1 - Σ_{d∈D}(1-ρ_min(d)) - L_O·d_O(o_t,o₀) - c·Δ_view - β_sig - P(o_t ∉ B(o₀,ε))
```
其中 `c` 为视角误差到成功率的一阶敏感系数。关键：**最坏情况球保证 + Lipschitz 迁移松弛 + 视角归一化误差预算** 三者共同构成可传递下界。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 新物体位姿估计失败 → 归一化失效 | 高 | 多视角 PnP + 不确定性门控 + 探测回退 |
| 物体流形上 ρ 非 Lipschitz（抓取阈值跳变） | 高 | 局部 Lipschitz 估计 + 分段证书 + 保守 ε |
| 透明/高反光/可变形物体的 sim-real 鸿沟 | 高 | 真实腕部数据校准 + 材质课程 + 不确定性标注 |
| 过度不变性丢弃抓取几何 | 中 | 保留 E_pose、信息瓶颈、几何辅助损失 |
| 主动探测延迟与运动模糊 | 中 | 单步最优 + 视角预算 + 去模糊 |
| 腕部自遮挡/物体遮挡 | 中 | 可达视角流形 + 遮挡感知增益 |
| 证书过保守导致拒绝率过高 | 中 | 自适应 ε、分区域证书、回退到平均谱报告 |

## 6. 本轮最大风险

**一句话**：把跨物体泛化写成物体流形上的最坏情况证书，其 soundness 同时押注于**新物体位姿估计的可靠、ρ 关于物体参数的 Lipschitz 性、以及最坏情况球采样覆盖**；一旦透明/可变形物体让位姿估计与仿真同时失真，或抓取成功率在某个宽度/摩擦阈值处发生跳变使 Lipschitz 常数爆炸，`ρ̂_ε` 下界将变得空洞而给出「已泛化」的假保证，故必须以**位姿不确定性门控 + 局部 Lipschitz 探测 + 球外强制拒绝**为三道绊线，宁可缩小背书球，绝不把「平均成功率」伪装成「跨物体泛化证书」。

```python
def active_probe(belief, V_w, alpha_S, budget, theta_cov, H_min):
    traj = []
    while entropy(belief) > H_min and budget > 0:
        cands = [v for v in V_w if alpha_S(v) >= theta_cov and reachable(v)]
        if not cands: break
        v_star = max(cands, key=lambda v: expected_info_gain(belief, v))
        if cost(v_star) > budget: break
        belief = bayes_update(belief, observe(v_star))
        budget -= cost(v_star)
        traj.append((v_star, belief))
    return belief, traj
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| OCM | O(N_o·|D|·M) | O(N_o·|D|) | 流形采样覆盖 ≥ 95%，滚动无偏 |
| WNC | O(N·H·W) 训练 / O(1) 推理 | O(1) 推理 | 不变性与可分辨性同时成立 |
| OGC | O(|B|·|D|) | O(|B|·|D|) | 球覆盖完备、最坏情况下界 sound |
| APW | O(|V_w|·T_probe) | O(|V_w|) | 次模信息增益 → (1-1/e) 近似 |
| OFS | O(|D|+|O|) | O(1) | 归因可辨，Explain sound |
| OXT | O(|D|) | O(1) | `L_O` 有效、球外强制拒绝 |

**正确性定理（Cross-Object Generalization Soundness）**
假设第 54 轮 (A26)-(A28) 成立；**(A29)** `ρ(·,d)` 在 O 上 `L_O`-Lipschitz；**(A30)** 腕部归一化误差 `≤Δ_view`、位姿估计误差 `≤δ_ξ`；**(A31)** 部署前主动探测达到 `H(b)≤H_min` 或 `o_t∈B(o₀,ε)`；**(A32)** 失败签名归因正确率 `≥1-β_sig`。则
```
P_success(o_t) ≥ 1 - Σ_{d∈D}(1-ρ_min(d)) - L_O·d_O(o_t,o₀) - c·Δ_view - β_sig - P(o_t∉B(o₀,ε))
```
关键：**最坏情况球 + Lipschitz 松弛 + 视角误差预算** 三者共同给出可传递下界；平均成功率不再作为泛化依据。

## 7. 本轮最大风险

**一句话**：跨物体泛化证书的 soundness 同时押注于**新物体位姿估计的可靠、ρ 关于物体参数的 Lipschitz 性、以及最坏情况球采样覆盖**；一旦透明/可变形物体让位姿估计与仿真同时失真，或抓取成功率在某个宽度/摩擦阈值处跳变使 `L_O` 爆炸，`ρ̂_ε` 下界将空洞化并给出「已泛化」的假保证，故必须以**位姿不确定性门控 + 局部 Lipschitz 探测 + 球外强制拒绝**为三道绊线，宁可缩小背书球，绝不把平均成功率伪装成跨物体泛化证书。
