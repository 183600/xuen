# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「动力学」×「专利布局」）

> R69 教会系统「问」，但它的保证仍然是一张**点状、静态、单张**的判决书：`J_FLUID` 只对「此刻这个动作/这个模态」盖章，它不说这张保证**管多大一片状态**、能**管多久**、由**哪些证据**支撑、以及当世界漂移或被投毒时**谁来撤销它**。于是 R69 最锋利的进步（主动消歧）也继承了最古老的脆弱：**一次正确的判定，不等于一片被覆盖的未来**。
>
> 本轮两个灵感补上这块结构性缺失：
> - **动力学**说：策略本身就是一条 ODE，闭环本身就是另一个动力系统。安全不是点，是**轨迹管、吸引域与可达集**；而同一速度场的散度既给出 R69 的似然，又给出局部稳定性与**分岔**信号——结构歧义会在熵上升之前先临界。交互闭环也会振荡，需要**收缩性**来判定「问了会不会越问越乱」。
> - **专利布局**说：任何保证都是一条**有范围（scope）、有强度（strength）、有先例（prior art）、有期限（expiry）、可被无效（invalidation）的 claim**。单条 claim 再漂亮也不能覆盖整个产品；你需要的是一份**组合（portfolio）**——在有限验证预算下，最大化对「未来会被走到的那片状态」的覆盖，同时避免空隙（gap）与丛林（thicket），并为失效相关性买保险。
>
> 核心命题：**把证书从「点判决」升级为「动力学需求管上的 claim 组合」：由 DRA 用内外动力学算出下一时域的可达需求，由 PLO 以专利布局式的预算化最大覆盖来编排 claim，由 FTO 在实时环只做一次「运行自由」成员判定，由 CBO/CLC 分别把「结构歧义」与「交互振荡」变成可计算的保守触发器；覆盖不足、claim 过期或被污染时，逐指令退回 R69。** 命名 **PATENT-RAS**（Portfolio of Assurance claims with Temporal Expiry and Novelty Tracking）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我凭什么说这片未来已被覆盖、这份保证还能撑多久、又由谁来推翻它**」——保证不是一句判决，而是一组有边界、有期限、可被无效的「专利」。

## 0. 直觉与动机

**灵感 1（动力学 → 安全是「管」，不是「点」）**
直觉：R69 在 `o_t` 处算一个 `λ`、选一个 `mode`、认证一个前缀 `k`，然后就把这一步交出去。可机器人交出去之后会到达一个新状态，新状态又会生成新动作，如此滚动 H 步。真正该问的是：**这 H 步里，系统可能走到的整片状态，是不是都在我拥有有效证据的地方？** 这是可达性（reachability）问题，不是单点分类问题。动力学提供两套时间尺度：**内动力学**是采样 ODE `dx/ds = v_θ`，决定动作模态与它们的稳定性；**外动力学**是闭环 `x_{t+1} = F(x_t, ξ_t, w_t)`，决定状态会漂到哪。安全与覆盖是对外动力学的陈述，稳定性与歧义信号来自内动力学，二者通过策略分布耦合。把这两层混为一谈，是 R69 只敢做点证书的根源。

**灵感 2（散度的三读 → 似然、稳定性、分岔是同一条通道）**
直觉：R69 的 FMA 已经用 `∫∇·v ds` 算动作似然，但只把它当「异常分」用。其实同一散度还告诉你两件事：沿路径的 `d log p/ds = −∇·v =: σ`，所以**似然上升 = 体积收缩 = 趋向模态**；`σ<0` 的「模态」只是过路结构，不是吸引子。更妙的是，当两个模态将要合并/分裂（分岔）时，流场雅可比的特征值会先碰撞，`β = 特征值间隙/‖J‖` 以 `√(μ_c−μ)` 的标度趋于 0——**结构歧义是超前的，R69 的模态熵是滞后的**。于是 CBO 几乎免费：它复用 FMA 已经在算的 JVP，把「异常通道」升级成「稳定性 + 分岔预警通道」。

**灵感 3（交互闭环是动力系统 → 收缩性决定「问了会不会更乱」）**
直觉：R69 把交互次数写进预算，却假定「问一次就单调变好」。真实的信念更新是一个反馈算子：问 A → 回答把信念推向 B → 再问 B → 回答又推回 A，于是系统在两个人为的模态之间来回横跳，把预算烧光还自以为在收敛。动力学给了一个干净的判据：**若信念更新算子在总变差/Hilbert 度量下是模 κ<1 的收缩，则多步交互几何收敛、VoI 可和、次数有界；若 κ≥1，则存在使后验振荡的观测序列，此时正确的动作不是更努力地问，而是停止提问、退回保守。** 这把 R69 的「问错比不问更危险」从一句风险警告，变成一个可计算的停止条件。

**灵感 4（专利布局 → 证书是有范围、有期限、可被无效的 claim）**
直觉：一条专利不是「一个发明」，而是「一片被权利要求划出的区域 + 一份可被挑战的有效性」。把证书写成同样结构，会立刻暴露 R69 说不出的东西：`J_FLUID` 的**范围**是什么？它只在当前观测邻域内被验证过；**强度**是什么？它依赖某个标定集上的 ECE；**先例**是什么？训练数据与交互日志；**期限**是什么？世界漂移多久后它就不再描述当前世界。专利布局的数学内核是：**在有限预算下，用一组有成本的 claim 去覆盖一片会变化的需求集合，并管理失效相关性**。这与安全认证的内核是同一个结构，而不是修辞巧合。

**灵感 5（空隙 vs 丛林 → 覆盖不是越多越好）**
直觉：专利组合有两种病：**空隙**（关键技术点没被任何 claim 保护）与**丛林**（大量重叠 claim，互相阻挡、抬高诉讼与维护成本）。证书组合完全对应：**空隙**是「可达管里有一段没有任何有效保证」，**丛林**是「同一片状态叠了十张证书，FTO 每次要查十遍」。R69 只关心「有没有证书」，从不关心「证书之间的覆盖拓扑」。本轮把 `Cov / Gap / Thk` 三个测度显式写进目标，并把「家族多样性」作为鲁棒性来源：**同一份先例（同一数据源）上叠十张 claim，不增加任何保证，只增加被同一攻击一锅端的风险。**

**灵感 6（FTO → 运行时的「自由实施」判定）**
直觉：专利里最实用的一句话是 freedom-to-operate：**我能不能现在就把产品做出来卖**。对应到闭环：**我能不能现在就把这条动作管执行下去**。FTO 门只做一件极轻的事：检查拟执行管 `T(ξ)` 是否落在「有效 claim 的并集且谓词为真」之内。通过则保留 R69 的 resolution bonus；不通过则不是硬闯，而是退回 R69 保守。注意 claim 的编译、布局、续期都是**离线/安全点**的重活，实时环只读不可变 claim 快照，因此整层几乎不改 R69 的 2.6ms 预算。

**灵感 7（专利战 → 认证账本本身是新攻击面）**
直觉：只要系统开始「持有证书」，就有人会攻击证书系统：**claim flooding**（灌入大量宽泛假 claim，让覆盖率虚高）、**scope creep**（验证时很窄，之后静默扩边界）、**prior-art poisoning**（污染支撑数据，让强度虚高）、**maintenance fraud**（到期不重验仍标 valid）、**submarine claim**（休眠 claim 在关键状态突然激活）。这些不是工程 bug，而是「把保证当作可交易资产」必然长出的攻击面。若不建模，PATENT-RAS 会把 R69 的「诚实的不知道」升级成「有产权证的错误」——**一张假专利，比没有专利更危险**。

**灵感 8（严格包含 → 专利层可以整个关掉，R69 必须原样活着）**
直觉：每加一层就多一个要独立信任的黑箱。因此本轮的理论姿态仍是**严格包含**：当可达管缩成一点（H→0）、组合只剩一张点 claim、漂移为零、分岔远离、交互收缩时，PATENT-RAS 必须与 R69 逐指令相同；当 FTO 失败、覆盖不足、claim 失效/过期/被污染、β 临界或 κ≥1 时，单调退到 R69 的 `λ_floor(U_ale+U_epi)` 与 `k_cal_shrink`。最坏情况我们只损失覆盖带来的效率红利，绝不损失 R69 已经拿到的安全保证。

**灵感 9（类比映射：结构同构，不是比喻）**

| 专利概念 | 本方案的技术对应 |
|---|---|
| claim scope | 受证区域 `S_C`（可判定集合） |
| claim 有效性 / 强度 | 谓词 `φ_C` / 统计置信 `s_C` |

## 1. 形式化定义（增量：定义 310–327）

**定义 310（PATENT-RAS 总览）** PATENT-RAS = (PCL, DRA, CBO, CLC, PLO, FTO, CRN, IPR, RAS-WM§)。继承 R69 定义 293 的三不变式（实时零学习写操作、交互预算、证据纪律），并新增三条：
(i) **断言最小化**：任何被提交执行的动作管必须落在某个「有效 claim」的声明范围与谓词内，且该 membership oracle 在运行时可在预算内求值；不可验证的 claim 一律无效；
(ii) **时效性**：每条 claim 钉住 `(D_hash, model_ver, world_ver, e_C)`，任一改变即失效，禁止用过期 claim 覆盖新世界；
(iii) **组合覆盖**：对下一时域的决策相关可达需求 `D_H`，有效 claim 并集必须覆盖之；覆盖不足则拒绝该动作并退回 R69。

**定义 311（claim 元组）** `C = (S_C, φ_C, s_C, D_C, e_C, f_C, ℓ_C)`：`S_C ⊆ 𝒳` 为 scope（zonotope/椭球/区间/半代数集等可判定集合）；`φ_C: 𝒳×𝒜_+ → {0,1}` 为受证性质（动作管 ⊂ 安全集、风险 ≤ ε_C）；`s_C ∈ [0,1]` 为 strength；`D_C` 为 support（数据/先例出处）；`e_C` 为有效期；`f_C` 为家族 id（共享数据源/模型/环境）；`ℓ_C` 为维护日志哈希。定义「有效」：
`Valid(C,t) ⇔ s_C ≥ τ_s ∧ t ≤ e_C ∧ D_hash 匹配 ∧ novelty_ok(S_C,D_C) ∧ construction_ok(C)`。

**定义 312（可验证范围 / claim construction）** scope 必须由一个 membership oracle `in_C(x)` 表示，且在部署硬件上 O(1) 或 O(#半空间) 可判定；若 `S_C` 只能以自然语言或不可判定集合描述，则视为无效。定义 `construction_ambiguity(C)=0` 为有效性的必要条件。这把专利法里的「权利要求解释」翻译成「运行时谓词可判定性」：**说不清边界的保证，等于没有边界。**

**定义 313（内动力学与外动力学）** 内动力学：采样 ODE `dx/ds = v_θ(x,s|o)`，`s∈[0,1]`，`J_v = ∂v/∂x`。外动力学：闭环 `x_{t+1} = F(x_t, ξ_t, w_t)`，`w_t ∈ 𝒲`。安全/覆盖是对外动力学的陈述；稳定性、歧义、分岔信号来自内动力学；二者通过 `p_θ(ξ|o)` 耦合。实时环只做外动力学的轻量外近似与 FTO，重活离线。

**定义 314（散度-稳定性对偶）** 令 `σ(x,s) = −∇·v_θ(x,s|o)`。沿路径连续方程给出 `d log p_s(x_s)/ds = σ(x_s,s)`。于是 (i) R69 FMA 的 `a_score = −log p_θ(ξ|o)` 正是 `∫σ ds` 的另一种读法；(ii) `σ>0` 表示局部体积收缩、趋向模态（稳定），`σ<0` 表示扩张、远离（瞬态）。定义模态稳定指数 `stab_k = (1/|path_k|)∫_{path_k} σ ds`。**只有 `stab_k > 0` 的模态才可进入 claim**；否则它不是一个可靠吸引子，认证它等于认证一阵风。

**定义 315（分岔邻近度与结构歧义 CBO）** 沿流场求 `J_v` 特征值，定义相对谱隙 `β(x) = min_{i<j}|λ_i−λ_j| / max(‖J_v‖_F, ε)`，并取路径上的 `β_min`。在鞍结/叉式分岔附近 `Δ_min ≈ c√(μ_c−μ)` 且 `β → 0`。定义结构歧义 `U_struct = g(β_min)`。它与 R69 的 `U_epi`（后验熵）独立：**熵还没涨，结构已经临界**。`β_min < τ_β` 持续出现 ⇒ 升高 K 并禁止交互（问了也分不开），直接走 R69 保守。

**定义 316（需求管 DRA）** 给定 `x_t`、策略支持（K 模态之并）与扰动集 `𝒲`，外动力学 H 步可达集
`R_H(x_t) = Reach_F^H({x_t} × supp π_θ(·|o_t) × 𝒲)`。
决策相关需求 `D_H = R_H ∩ 𝒳_dec`，其中 `𝒳_dec` 是「会改变动作/风险/证书」的状态集（承接 R69「只建会改变动作的地图」）。DRA 输出可判定外近似 `R̂_H ⊇ R_H`（zonotope / 区间 / 采样 + 保形外扩），并记录保守率 `tight = vol(R_H)/vol(R̂_H)`。

**定义 317（覆盖 / 空隙 / 丛林）** 对需求测度 `μ`（可达概率 × 决策敏感度）：
`Cov = μ(D_H ∩ ∪_{C∈𝒫} S_C)/μ(D_H)`；`Gap = 1−Cov`；`Thk = μ(∪ pairwise overlaps)/μ(∪ S_C)`。布局目标：`max Cov − α·Thk − γ·Σ cost(C)`，s.t. 运行时 FTO 延迟 ≤ τ_FTO。

**定义 318（FTO 门）** 对拟执行动作管 `T(ξ)`，运行时检查 `T(ξ) ⊆ ∪_{C valid} S_C` 且 `∀x∈T(ξ), φ_C(x)=1`。不通过 ⇒ 拒绝并回退 R69：`λ=λ_floor(U_ale+U_epi)`，`k=k_cal_shrink`。FTO 复杂度 `O(|𝒫_active| × cost(predicate))`，靠空间索引与预编译把常数压到极小。

**定义 319（组合布局优化 PLO）** 将 `D_H` 离散为原子 `{a_i}`（测度 `μ_i`），候选 claim 有成本 `c_C` 与覆盖原子集 `A_C`。求解
`max_{𝒫} Σ_{i∈∪_{C∈𝒫} A_C} μ_i − Σ_{C∈𝒫} c_C`，s.t. `Σ c_C ≤ B` 且 FTO 延迟 ≤ τ_FTO。
固定候选时这是**预算化最大覆盖**，目标单调子模 ⇒ 贪心达 `1−1/e`。若允许「设计 scope」（扩/缩 `S_C`），扩张动作的边际收益递减，仍可用子模贪心 + 局部搜索给出近似界。

**定义 320（组合失效与独立性 IPR）** claim 按家族 `f` 分组，家族内共享数据/模型 ⇒ 失效相关 `ρ_f`。若需求原子 `i` 只被单 claim 覆盖，失效率为 `δ`；若被 `k` 个互异家族覆盖，则
`P(i 未被有效覆盖) ≤ δ·ρ^{k−1} + ε_σ`（与 R69 引理 18 同构，但对象从「回答」升级为「claim」）。定义组合风险 `Risk_P = Σ_i μ_i · P(atom i uncovered at t)`。布局加入多样性罚：高风险原子应尽量 `k≥2`。

**定义 321（时效与续期动力学 CRN）** 设漂移速度上界 `‖ẋ_drift‖ ≤ v_d`、`F` Lipschitz 常数 `L_F`、strength 对数据 Lipschitz `L_s`，claim 归一化裕度 `η_C = min(dist(S_C^valid, ∂S_C), (s_C−τ_s)/L_s)`。则 `time-to-invalid τ_C ≥ η_C/(L_F v_d)`。CRN 预测到期并调度重验证，续期成本计入预算。**禁止自动续期**（maintenance fraud）：续期必须重跑证据纪律，否则 claim 降级为「未验证」。

**定义 322（交互闭环收缩 CLC）** 信念更新算子 `T` 在总变差/Hilbert 度量下模 `κ<1` ⇒ 多步交互几何收敛，VoI 序列可和，交互次数期望 `O(log(1/ε)/(1−κ))`。以 Hellinger 亲和 `H²(P_i,P_j)=1−∫√(P_iP_j)` 给出界：`κ ≤ 1 − min_{i≠j}H²(P_i,P_j)/2`。`H²→0` ⇒ `κ→1`：回答不可分、交互无信息且可振荡，此时上限 1 次交互并直接保守。

**定义 323（对抗性布局 ℰ_patent）** 新增攻击面：claim flooding（宽泛假 claim 灌入使 `Cov` 虚高）、scope creep（验证后静默扩边界）、prior-art poisoning（支撑数据被污染使 `s_C` 虚高）、maintenance fraud（过期不重验仍标 valid）、submarine claim（休眠 claim 在关键状态被激活）。并入 `ℰ_PATENT = ℰ_FLUID × ℰ_patent`。

**定义 324（审计 VQAuditor-P）** 审计对象升级为 claim 生命周期：scope 是否被扩、强度是否由独立证据支撑、续期是否重验、高风险原子是否被单一家族覆盖、是否存在纸面覆盖。结论回灌 claim 信誉与 PLO 成本。

**定义 325（证书 J_PATENT）** `J_PATENT = (J_FLUID, portfolio_hash, coverage, gap, thicket, fto_pass, min_family_multiplicity, risk_P, claim_expiry_min, patent_ver)`。`Valid ⇔ Valid(J_FLUID) ∧ Cov ≥ τ_cov ∧ Gap ≤ τ_gap ∧ FTO pass ∧ Risk_P ≤ τ_risk ∧ 无过期/被污染 claim 参与覆盖`。

**定义 326（两级退避与严格包含）** 若 FTO 通过且覆盖充分：`λ = λ_floor(U_ale)`（保留 R69 resolution bonus）；若覆盖不足 / claim 失效 / 过期 / 被投毒 / `β_min<τ_β` / `κ≥1`：逐级退到 R69 的 `λ_floor(U_ale+U_epi)` 与 `k_cal_shrink`。当 `H→0, R_H={x_t}, 𝒫={单点 claim}, drift=0, β>τ_β, κ<1` 时，PATENT-RAS 与 R69 逐指令相同。

**定义 327（实时-离线分层）** PCL/DRA/PLO/CRN/IPR 在**安全点的离线/异步**相位运行（编译 claim、布局、续期）；实时环只做 CBO（复用 FMA 的 JVP）、CLC（查表）、FTO（成员判定）。因此实时预算 ≈ R69 + `O(|𝒫_active|)`，且写操作永远不在实时环。

```python
# IP-264 PCL：claim 元组与有效性（不可变快照，实时只读）
@dataclass(frozen=True)
class Claim:
    scope: Callable[[State], bool]      # in_C(x)，O(1)/O(#halfspaces)
    phi:   Callable[[State, Action], bool]
    strength: float; support: str; expiry: float
    family: int; log_hash: str
    def valid(self, now, D_hash, model_ver):
        return (self.strength >= TAU_S and now <= self.expiry
                and self.support == D_hash and self.family_ok(model_ver)
                and self.construction_ok())

# IP-265 DRA：可达需求管（离线/安全点，输出可判定外近似）
def reachable_demand(F, policy, x0, W, H, X_dec):
    S = {x0}
    for _ in range(H):
        S = overapprox_next(F, S, support(policy), W)  # zonotope/interval/采样+保形
    return S, (S & X_dec), tightness(S)

# IP-266 CBO：分岔/结构歧义预警（复用 FMA 的 JVP，几乎免费）
def bifurcation_proximity(v, x, s, z):
    J = jacobian_jvp(v, x, s, z)        # 与 FMA 共享 Hutchinson/JVP 机制
    lam = eigvals(J)
    return min_pair_gap(lam) / max(norm_fro(J), EPS)

# IP-267 CLC：交互闭环收缩模（证据家族级预计算，实时查表）
def contraction_modulus(evidence_families):
    h2 = min_pairwise_hellinger_sq(evidence_families)
    return 1.0 - h2 / 2.0               # >=1 => 停止交互，走 R69 保守

# IP-268 PLO：预算化最大覆盖（离线，子模贪心 + 局部搜索）
def layout_claims(atoms, candidates, budget, alpha, gamma):
    chosen, covered, spent = [], set(), 0.0
    while True:
        best = max(candidates, key=lambda C: (
            (coverage_gain(C, covered) - alpha*thicket_gain(C, chosen)
             - gamma*C.cost) / max(C.cost, EPS)))
        if best is None or coverage_gain(best, covered) <= best.cost: break
        chosen.append(best); covered |= best.atoms; spent += best.cost
        if spent > budget: break
    return local_search(chosen, atoms, budget)   # (1-1/e) 近似

# IP-269 FTO：运行时自由实施门（只做成员判定与时效检查）
def fto_gate(tube, claims, now, D_hash):
    for x in tube.boundary_samples():            # 预编译稀疏边界采样
        if not any(C.valid(now, D_hash) and C.scope(x) and C.phi(x)
                   for C in claims.active):
            return False, "GAP"
    return True, "OK"

# IP-270 CRN：到期预测与续期（离线；禁止自动续期）
def time_to_invalid(C, drift_rate, L_F):
    eta = min(dist_to_boundary(C), (C.strength - TAU_S) / L_s)
    return eta / max(L_F * drift_rate, EPS)
def renew(C, fresh_evidence):
    if not evidence_discipline(fresh_evidence): return C.degrade()
    return C.with_evidence(fresh_evidence)

# IP-271 IPR：相关失效下的组合风险
def portfolio_risk(atoms, claims, delta, rho):
    risk = 0.0
    for a in atoms:
        fams = independent_families_covering(a, claims)
        k = len(fams)
        if k == 0: return 1.0
        risk += a.mu * (delta * rho**(k - 1) + EPS_SIGMA)
    return risk

# IP-275 PATENT-RAS 主闭环（R69 核心不动，只在处置处插动力学与 FTO）
def PATENT_RAS_round(M, obs):

    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4                    # R69

    beta  = M.cbo.bifurcation_proximity(M.fmp.v, M.last_action, z)
    kappa = M.clc.modulus(M.last_evidence_families)
    # 交互仅在 R69 想做、且动力学判定「问得动」时进行
    g = None

    U_epi_after = M.cia.update_belief(modes, M.cia.execute(g)) if g else U_epi
    lam = max(M.efs.risk_scale(...),
```

## 3. 推导

**引理 19（散度三读等价）** 对连续流 ODE，`d log p_s(x_s)/ds = −∇·v(x_s,s|o) = σ(x_s,s)`。因此 R69 FMA 的 `a_score = −log p_θ(ξ|o)` 与沿路径的 `∫σ ds` 是同一量的两种读数；`stab_k = mean σ` 判定模态是否为收缩吸引子。系：**似然高但 `stab_k<0` 的「模态」只是过路结构，不能进入 claim**——这把 R69 的异常通道免费升级为稳定性门。

**引理 20（分岔的平方根标度与超前预警）** 以一维鞍结 `ẋ=μ−x²` 为例，平衡点 `x*=±√μ`，间距 `Δ_min=2√μ`，雅可比特征值 `λ=∓2√μ`；`μ→0` 时 `λ→0`、`Δ_min→0`。故 `β ∝ √(μ_c−μ)`，CBO 以 `√` 标度在模态真正合并之前告警。系：**结构歧义是超前的、熵是滞后的**；R69 等 `H_mode` 上升才升 K，往往已经错过最佳保守点。

**引理 21（信念更新收缩与停止条件）** 设两模态回答分布 `P_i,P_j`，Hellinger 亲和 `H²=1−∫√(P_iP_j)`。单次更新的对数似然比是鞅，后验绝对差期望按 `≤(1−H²/2)` 收缩；`k` 次条件独立观测收缩 `≤(1−H²/2)^k`。故 `κ ≤ 1−min_{i≠j}H²/2`。`H²→0` ⇒ `κ→1`：回答不可分，交互无信息且可振荡。系：**κ≈1 时应停止提问，而不是更努力提问**。

**引理 22（覆盖的子模性与布局近似界）** 固定原子与候选 claim 时，`Cov(𝒫)=Σ_{i∈∪A_C}μ_i` 单调子模；预算约束下贪心达 `1−1/e` 最优。若允许连续扩张 scope，扩张的边际收益递减，`Cov` 对扩张动作仍子模；thicket 与 claim 成本作为可加成本进入，不破坏子模性。系：**证书布局不是拍脑袋，而是一个有近似保证的集合覆盖问题。**

**引理 23（相关失效下的组合界）** 若原子 `i` 被 `k` 个互异家族覆盖，家族间失效相关 `ρ<1`、单 claim 失效率 `δ`，则 `P(i 未被有效覆盖) ≤ δ ρ^{k−1} + ε_σ`。系：**覆盖的鲁棒性来自家族多样性，而非 claim 数量**；同一 prior art 上叠十张 claim 不增加任何保证，只增加同时失效的风险。

**引理 24（到期时间下界与预测性续期）** 在 A103 下，claim 从当前到失效的时间 `τ_C ≥ η_C/(L_F v_d)`，`η_C` 为 scope 边界裕度与 strength 裕度的归一化最小。系：续期可以按预测调度，而不是周期性「交年费」；且到期必须重验，否则就是 maintenance fraud。

**定理 18（严格包含 R69）** 当 `H→0`（需求退化为当前点）、`𝒫` 退化为单点 claim、`drift=0`、`β>τ_β`、`κ<1`、FTO 恒真时，PATENT-RAS 的 `k、λ、mode` 与 R69 逐指令相同；且任一 FTO 失败 / 覆盖不足 / claim 失效 / 过期 / 被投毒都单调退化为 R69 保守。因此 R69 = PATENT-RAS 的「单点、静态、单 claim」边界，安全侧不做任何让步。

**定理 19（覆盖-风险分解 / 闭环安全性）** 对下一时域，未受证状态发生概率满足
`P(escape) ≤ Gap + (1−Gap)·Risk_P + P(model-error outside R̂_H)`。
FTO 门保证 `Gap=0` 或回退；IPR 使 `Risk_P` 随家族多样性指数下降；DRA 的外近似在 A99 下保证 `R_H ⊆ R̂_H`。故闭环安全 = **覆盖 × claim 有效性 × 可达性模型可靠性**；三者任一不可信即退 R69。

**定理 20（问-证-覆盖的联合稳定性）** 在 `κ<1` 且 `β>τ_β` 时，交互闭环以期望 `O(log(1/ε)/(1−κ))` 步收敛，后验熵下降、可达需求收缩，形成「问—证—覆盖」正循环；当 `κ≥1` 或 `β<τ_β` 时交互被截断并保守，杜绝振荡与「被证实的错误」。配合引理 24 的预测性续期，若取 `V = Gap + H(M|o) + (τ_exp−now)^{-1}`，则在可行步上 `E[V_{t+1}] ≤ V_t + b`。⇒ **问得越准，证书越省；提不出好问题，就诚实地退回保守。**

**假设 A99–A104**：A99 DRA 外近似 sound（区间/zonotope 保守包含；采样+保形以置信度成立）；A100 速度场足够光滑，`J_v` 与 `∇·v` 可由 JVP/VJP 在预算内估计；A101 membership oracle 与真实谓词在验证集上一致；A102 证据条件独立、家族间 `ρ<1`；A103 漂移速度、`F`、strength 的 Lipschitz 常数有界；A104 `|𝒫_active| ≤ N_max`，FTO 延迟有上界。

## 6. 本轮最大风险

**一句话**：PATENT-RAS 把安全押在「需求管被有效 claim 覆盖」上，而覆盖本质上是一条**关于动力学的模型断言**——一旦 DRA 低估可达集（外近似不 sound、模型失配，或真实扰动超出 `𝒲`），系统就会持有一份「纸面覆盖率 100%」的证书，在真实轨迹已经逃出受证区域的瞬间仍然自信，这比 R69 诚实的「未覆盖」更危险：**证错，比不证更危险。**

**次级风险与缓解**：(1) 认证账本被攻击（claim flooding / scope creep / prior-art poisoning / maintenance fraud）→ 定义 323 + IPR 家族独立性 + VQAuditor-P 审计，高风险原子强制 `k≥2`；(2) 可达管过松导致 FTO 频繁失败、退回过多 → PLO 以 `tight` 与 `Gap` 联合优化，DRA 采用保形外扩而非无限膨胀；(3) 离线重活阻塞安全点 → 定义 327 分层，实时环零写、只读快照；(4) `β` 估计噪声导致误触发 → 谱隙做时间平滑与置信带，仅持续越界才保守；(5) 交互与布局争预算 → 安全相关 FTO/续期优先，交互与布局只在剩余预算内执行。

## 2. 形式化定义（要点版）

**定义 310（总览与六不变式）** 继承 R69 的实时零学习写、交互预算、证据纪律；新增断言最小化（执行管必须落在有效 claim 内且谓词可判定）、时效性（钉住 `D_hash/model_ver/world_ver/expiry`）、组合覆盖（有效 claim 并集覆盖 `D_H`，否则拒绝并退 R69）。

**定义 311–312（claim 与可验证范围）** claim 七元组；`Valid(C,t) ⇔ s_C≥τ_s ∧ t≤e_C ∧ D_hash 匹配 ∧ novelty_ok ∧ construction_ok`。scope 必须有运行时 membership oracle；只能自然语言描述的 claim 一律无效——**说不清边界的保证等于没有边界**。

**定义 313–314（内外动力学与散度对偶）** 内动力学是采样 ODE，外动力学是闭环状态演化；`σ=−∇·v` 同时给出 `d log p/ds`（R69 FMA 的似然）与局部稳定性。`stab_k>0` 是模态可认证的必要条件：似然高但 `stab_k<0` 的「模态」只是过路结构。

**定义 315（分岔预警 CBO）** `β` 为流场雅可比相对谱隙；鞍结/叉式分岔附近 `Δ_min ≈ c√(μ_c−μ)`、`β→0`。`β_min<τ_β` ⇒ 升 K、禁交互、走 R69 保守。要点：**结构歧义超前，熵滞后。**

**定义 316–317（需求管与覆盖拓扑）** `R_H` 为策略支持 × 扰动集下的 H 步可达；`D_H = R_H ∩ 𝒳_dec`；`Cov/Gap/Thk` 分别为覆盖、空隙、重叠冗余。布局目标 `max Cov − α·Thk − γ·Σcost`，s.t. FTO 延迟。

**定义 318–319（FTO 与 PLO）** FTO 运行时判 `T(ξ) ⊆ ∪_{valid} S_C` 且 `φ_C` 真；不通过即回 R69。PLO 是预算化最大覆盖：固定候选时单调子模 ⇒ 贪心 `1−1/e`；允许设计 scope 时子模贪心 + 局部搜索。

**定义 320（IPR）** 家族内失效相关 `ρ`；原子被 `k` 个互异家族覆盖时失效概率 `≤ δρ^{k−1}+ε_σ`。**十张同源 claim 不如两张异源 claim。**

**定义 321（CRN）** `τ_C ≥ η_C/(L_F v_d)`；到期预测调度重验证；禁止自动续期（maintenance fraud）。

**定义 322（CLC）** 信念更新收缩模 `κ ≤ 1−min H²/2`；`κ<1` 几何收敛、`κ≥1` 停问。把 R69「问错更危险」变成可计算停止条件。

**定义 323–327（攻击面、审计、证书、退避、分层）** `ℰ_patent` 五类账本攻击；VQAuditor-P 审 claim 生命周期；`J_PATENT` 并入覆盖与组合风险；FTO 失败/覆盖不足/失效/过期/`β` 临界/`κ≥1` 逐级退 R69；DRA/PLO/CRN/IPR 离线、实时环零写只读快照。

## 3. 关键算法伪代码

```python
# IP-264 PCL：claim 不可变快照；实时只读
@dataclass(frozen=True)
class Claim:
    scope: Callable[[State], bool]; phi: Callable[[State, Action], bool]
    strength: float; support: str; expiry: float; family: int; log_hash: str
    def valid(self, now, D_hash, model_ver):
        return (self.strength >= TAU_S and now <= self.expiry
                and self.support == D_hash and self.family_ok(model_ver)
                and self.construction_ok())

# IP-265 DRA：可达需求管（离线/安全点）
def reachable_demand(F, policy, x0, W, H, X_dec):
    S = {x0}
    for _ in range(H):
        S = overapprox_next(F, S, support(policy), W)   # zonotope/区间/采样+保形
    return S, (S & X_dec), tightness(S)

# IP-266 CBO：分岔邻近度（复用 FMA 的 JVP）
def bifurcation_proximity(v, x, s, z):
    J = jacobian_jvp(v, x, s, z); lam = eigvals(J)
    return min_pair_gap(lam) / max(norm_fro(J), EPS)

# IP-267 CLC：交互收缩模
def contraction_modulus(evidence_families):
    return 1.0 - min_pairwise_hellinger_sq(evidence_families) / 2.0

# IP-268 PLO：预算化最大覆盖（子模贪心 + 局部搜索）
def layout_claims(atoms, candidates, budget, alpha, gamma):
    chosen, covered, spent = [], set(), 0.0
    while True:
        best = max(candidates, key=lambda C: (
            (coverage_gain(C, covered) - alpha*thicket_gain(C, chosen)
             - gamma*C.cost) / max(C.cost, EPS)))
        if best is None or coverage_gain(best, covered) <= best.cost: break
        chosen.append(best); covered |= best.atoms; spent += best.cost
        if spent > budget: break
    return local_search(chosen, atoms, budget)          # (1-1/e) 近似

# IP-269 FTO：运行时自由实施门
def fto_gate(tube, claims, now, D_hash):
    for x in tube.boundary_samples():
        if not any(C.valid(now, D_hash) and C.scope(x) and C.phi(x)
                   for C in claims.active):
            return False, "GAP"
    return True, "OK"

# IP-270 CRN：到期预测与重验续期
def time_to_invalid(C, drift_rate, L_F):
    eta = min(dist_to_boundary(C), (C.strength - TAU_S) / L_s)
    return eta / max(L_F * drift_rate, EPS)

# IP-271 IPR：家族相关失效下的组合风险
def portfolio_risk(atoms, claims, delta, rho):
    risk = 0.0
    for a in atoms:
        k = len(independent_families_covering(a, claims))
        if k == 0: return 1.0
        risk += a.mu * (delta * rho**(k - 1) + EPS_SIGMA)
    return risk

# IP-275 主闭环（R69 核心不动，只插入动力学门控与 FTO）
def PATENT_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o, o_calibrated)
    slow  = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    beta  = M.cbo.bifurcation_proximity(M.fmp.v, M.last_action, z)
    kappa = M.clc.modulus(M.last_evidence_families)
    g = (M.mint.choose_interaction(modes, o, M.budget)
         if (U_epi > TAU_EPI and not slow and beta > TAU_BETA and kappa < 1.0)
         else None)
    U_epi = M.cia.update_belief(modes, M.cia.execute(g)) if g else U_epi
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    A = M.ach.propose(x_prime, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    if slow or beta < TAU_BETA or kappa >= 1.0:
        lam = max(lam, 0.8); k = min(k, k_cal_shrink(A, U_cal))
    tube = action_tube(modes, k, H=M.vista.H)
    ok, why = M.fto.fto_gate(tube, M.pcl.active, now=M.clock, D_hash=M.dss.hash)
    if not ok:
        lam = max(lam, LAM_FTO); k = min(k, k_cal_shrink(A, U_cal))
    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.crn.submit(M.pcl, M.dra.demand_cache, M.ipr.risk_cache)   # 异步、零实时写
    M.vqa_p.submit_async(tube, why, beta, kappa)
    return k, lam, mode, (U_ale, U_epi), (beta, kappa, ok)
```

## 4. 推导

**引理 19（散度三读等价）** `d log p_s(x_s)/ds = −∇·v = σ`。R69 FMA 的 `a_score` 与 `∫σ ds` 是同一量；`stab_k = mean σ` 判吸引子。系：`stab_k<0` 的「模态」不得入 claim。

**引理 20（分岔平方根标度）** 鞍结 `ẋ=μ−x²` 有 `x*=±√μ`、`Δ_min=2√μ`、`λ=∓2√μ`；`μ→0` 时 `β ∝ √(μ_c−μ)`。故 CBO 以 √ 标度超前告警。系：结构歧义超前、熵滞后。

**引理 21（信念更新收缩）** 单次更新后验差按 `≤1−H²/2` 收缩，`k` 次独立观测为 `(1−H²/2)^k`；`κ ≤ 1−min H²/2`。系：`κ≈1` 应停问，而非更努力问。

**引理 22（覆盖子模性）** 固定原子与候选时 `Cov` 单调子模，预算化贪心达 `1−1/e`；连续 scope 扩张边际递减，仍可用子模贪心 + 局部搜索。

**引理 23（相关失效界）** `k` 个互异家族覆盖时 `P(uncovered) ≤ δρ^{k−1}+ε_σ`。系：鲁棒性来自家族多样性。

**引理 24（到期下界）** `τ_C ≥ η_C/(L_F v_d)`。系：预测性续期，而非周期「交年费」。

**定理 18（严格包含 R69）** `H→0`、单点 claim、`drift=0`、`β>τ_β`、`κ<1`、FTO 恒真时，`k/λ/mode` 与 R69 逐指令相同；任一 FTO 失败/覆盖不足/失效/过期/投毒，单调退化到 R69 保守。

**定理 19（覆盖-风险分解）** `P(escape) ≤ Gap + (1−Gap)Risk_P + P(model-error outside R̂_H)`；FTO 保证 `Gap=0` 或回退；IPR 指数压低 `Risk_P`；A99 保证 `R_H⊆R̂_H`。闭环安全 = 覆盖 × claim 有效性 × 可达模型可靠性。

**定理 20（问-证-覆盖联合稳定）** `κ<1 ∧ β>τ_β` 时交互期望 `O(log(1/ε)/(1−κ))` 步收敛，需求收缩、形成正循环；`κ≥1 ∨ β<τ_β` 时截断并保守。取 `V=Gap+H(M|o)+(τ_exp−now)^{-1}`，可行步上 `E[V_{t+1}] ≤ V_t + b`。

## 7. 本轮最大风险

**一句话**：PATENT-RAS 把安全押在「需求管被有效 claim 覆盖」上，而覆盖是一条关于动力学的模型断言——一旦 DRA 低估可达集或真实扰动超出 `𝒲`，系统会持有一份「纸面覆盖率 100%」的证书，在轨迹已经逃出受证区域时仍然自信；**证错，比不证更危险。**

**次级风险与缓解**：认证账本被攻击（claim flooding / scope creep / prior-art poisoning / maintenance fraud / submarine claim）→ 定义 323 + IPR 家族独立性 + VQAuditor-P，高风险原子强制 `k≥2`；可达管过松致 FTO 频繁失败 → PLO 联调 `tight/Gap`，DRA 用保形外扩而非无限膨胀；离线重活阻塞安全点 → 定义 327 分层、实时零写；`β` 噪声误触发 → 谱隙时间平滑 + 置信带；交互与布局争预算 → FTO/续期优先，其余只在剩余预算内执行。
