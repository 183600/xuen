### 第 1 轮灵感驱动研究记录

**灵感词**：状态估计、机器人

**直觉与动机**：
v25 的七证体系有一个未言明的前提：被验证的「状态 x」是可信的。但机器人从来拿不到真实的 x，只拿到估计器输出的信念 b_t=(x̂_t, Σ_t)。状态估计误差不是简单的加性噪声，它会改变证书的语义：一个被系统性低估的定位协方差，会让碰撞证书在真实距离已侵入安全包络时仍然通过；一个 IMU 漂移或接触力观测滞后，会让力控无源性证书在能量已注入后才判定安全；长廊、玻璃、隧道、纹理缺失会让 LiDAR/视觉可观测性退化，此时滤波器给出的「高置信」恰恰是最危险的伪置信。受「状态估计」启发，核心洞见是：**证书不应是对状态点的证明，而应是对状态信念集的证明；估计器既是证书链的第一个生产者，也是第一个消费者**。受「机器人」启发，估计也不是纯滤波问题：它与可观测性、执行器/传感时延、接触物理、多机相对定位与时钟同步强耦合。因此本轮把「点证书」升级为「信念证书」：先证书化估计器本身（SEC），再证书化退化与故障（EDC），最后把所有下游谓词提升为在置信集上一致成立的鲁棒谓词（BRC）。

**形式化目标**：
1. 定义状态估计证书（SEC）：可观测性下界 λ_min(W_o) ≥ w_min；NEES/ANEES 双侧卡方一致性；置信集覆盖 ℙ(x_t ∈ C_t) ≥ 1-α_est（离线 conformal + 在线 ACI 自适应）；估计时延/信息年龄 Δ_t ≤ Δ_max，且协方差按过程噪声速率膨胀。
2. 定义估计退化证书（EDC）：Fisher 信息/可观测 Hessian 的最小特征值低于 λ_deg 时输出退化子空间 𝒟_t 与膨胀因子 κ_t；新息 NIS 卡方检验与一阶白化检验；故障签名矩阵的可隔离性检验。
3. 定义信念-鲁棒证书（BRC）：把 USMC/SMC/RMC/MCC 的点谓词 P(x̂) ≥ 0 提升为鲁棒余量 m_t = min_{x∈C_t} P(x) ≥ 0；用 Lipschitz 界 m_t ≥ P(x̂) − L_P·rad(C_t) 实现可复核、可实时计算的下界。
4. 构建估计感知统一准入门（E-SRC-USC）：v25 ∪ SEC ∪ EDC ∪ BRC 十证一体，Exec_v26 = Exec_v25 ∩ Fil_est ⊆ Exec_v25。
5. 证明「估计失效 / 可观测性退化 / 时延超限」三类新增退化路径下单调链保持，且鲁棒证书不会产生伪安全。

## 1. 关键算法骨架（在 IP-447 骨架上扩展）

```python
# ============================================================
# IP-448 State Estimation Certificate (SEC) — 状态估计证书
# ============================================================
@dataclass
class Estimate:
    x: Tensor          # 真值（仿真/离线平滑参考）
    x_hat: Tensor      # 估计
    Sigma: Tensor      # 估计协方差
    tau: float         # 时间戳

@dataclass
class ConfidenceSet:
    """C = {x : (x-x̂)ᵀ A (x-x̂) ≤ q²} 或 conformal 球"""
    center: Tensor
    shape: Tensor
    kind: str = "ellipsoid"          # ellipsoid | conformal
    q: float = 1.0

    def radius(self) -> float:
        if self.kind == "ellipsoid":
            return self.q * torch.sqrt(torch.linalg.eigvalsh(self.shape).max()).item()
        return self.q

    def contains(self, x: Tensor) -> bool:
        d = x - self.center
        if self.kind == "ellipsoid":
            return (d @ torch.linalg.solve(self.shape, d) <= self.q ** 2).item()
        return torch.norm(d).item() <= self.q

@dataclass
class StateEstimationCertificate:
    x_hat: Tensor
    Sigma: Tensor
    window: list[Estimate]           # 最近 N 步，用于 NEES/覆盖
    W_o: Tensor                      # 可观测 Gramian（解析或经验）
    age: float = 0.0                 # Δ_t
    w_min: float = 1e-3
    alpha_est: float = 0.05
    delta_max: float = 0.02          # s
    q_conf: Optional[float] = None   # 离线校准得到的非共形分位
    alpha_aci: float = 0.05
    gamma_aci: float = 0.005
    q_aci: float = 1.0               # 在线 ACI 阈值

    def verify_observability(self) -> bool:
        """局部弱可观测：λ_min(W_o) ≥ w_min"""
        W = 0.5 * (self.W_o + self.W_o.T)
        return torch.linalg.eigvalsh(W).min().item() >= self.w_min

    def _nees(self) -> Tensor:
        vals = []
        for e in self.window:
            d = e.x - e.x_hat
            vals.append((d @ torch.linalg.solve(e.Sigma, d)).item())
        return torch.tensor(vals)

    def verify_consistency(self) -> bool:
        """N·mean(NEES) ∈ [χ²_{Nn,α/2}, χ²_{Nn,1-α/2}]（双侧，过置信/欠置信都拒）"""
        N = len(self.window)
        if N < 10:
            return False
        n = self.x_hat.numel()
        stat = N * self._nees().mean().item()
        lo = chi2.ppf(self.alpha_est / 2.0, N * n)
        hi = chi2.ppf(1.0 - self.alpha_est / 2.0, N * n)
        return lo <= stat <= hi

    def _score(self, e: Estimate) -> float:
        d = e.x - e.x_hat
        return torch.sqrt(torch.clamp(d @ torch.linalg.solve(e.Sigma, d), min=0)).item()

    def verify_coverage(self) -> bool:
        """离线 conformal 分位 + 在线 ACI 维持长程覆盖 ≥ 1-α_est"""
        if self.q_conf is None:
            return False
        scores = [self._score(e) for e in self.window]
        err = sum(1 for s in scores if s > self.q_aci) / max(1, len(scores))
        # ACI 更新：阈值随累计错覆盖率自适应
        self.alpha_aci = min(1.0, max(0.0,
            self.alpha_aci + self.gamma_aci * (self.alpha_est - err)))
        self.q_aci = self.q_conf * (1.0 + 2.0 * abs(self.alpha_aci - self.alpha_est))
        return err <= self.alpha_est + 0.01

    def verify_latency(self) -> bool:
        return self.age <= self.delta_max

    def inflated_covariance(self, Q_rate: Tensor) -> Tensor:
        return self.Sigma + Q_rate * self.age

    def confidence_set(self, Q_rate: Tensor) -> ConfidenceSet:
        return ConfidenceSet(self.x_hat, self.inflated_covariance(Q_rate),
                             "ellipsoid", self.q_aci)

    def verify_all(self, Q_rate: Tensor) -> bool:
        return (self.verify_observability() and
                self.verify_consistency() and
                self.verify_coverage() and
                self.verify_latency())


# ============================================================
# IP-449 Estimation Degeneracy Certificate (EDC) — 估计退化证书
# ============================================================
@dataclass
class EstimationDegeneracyCertificate:
    fisher: Tensor                   # F_t = Σ HᵀR⁻¹H
    innovations: list[Tensor]        # ν_t
    innovation_covs: list[Tensor]    # S_t
    fault_signatures: Tensor         # 𝔽 ∈ ℝ^{m×F}
    lambda_deg: float = 1e-2
    nis_alpha: float = 0.01
    kappa_max: float = 10.0

    def degeneracy_directions(self) -> tuple[Tensor, Tensor]:
        """返回 (退化特征值, 退化方向矩阵 V_𝒟)"""
        F = 0.5 * (self.fisher + self.fisher.T)
        lam, V = torch.linalg.eigh(F)
        mask = lam < self.lambda_deg
        return lam[mask], V[:, mask]

    def inflation_factor(self) -> float:
        lam, _ = self.degeneracy_directions()
        if lam.numel() == 0:
            return 1.0
        return min(self.kappa_max, 1.0 + 1.0 / (lam.min().item() + 1e-9))

    def verify_innovation_whiteness(self) -> bool:
        """NIS 卡方上界 + 一阶自相关白化"""
        norm_nu = []
        for nu, S in zip(self.innovations, self.innovation_covs):
            nis = (nu @ torch.linalg.solve(S, nu)).item()
            if nis > chi2.ppf(1.0 - self.nis_alpha, nu.numel()):
                return False
            norm_nu.append((nu / torch.sqrt(torch.diag(S))).flatten())
        if len(norm_nu) >= 2:
            a = torch.cat(norm_nu[:-1])
            b = torch.cat(norm_nu[1:])
            ac1 = torch.corrcoef(torch.stack([a, b]))[0, 1].item()
            if abs(ac1) > 0.1:
                return False
        return True

    def verify_fault_isolability(self) -> bool:
        """故障签名列满秩，故障模式可区分"""
        return torch.linalg.matrix_rank(self.fault_signatures).item() == \
               self.fault_signatures.shape[1]

    def verify_all(self) -> bool:
        return (self.verify_innovation_whiteness() and
                self.verify_fault_isolability())


# ============================================================
# IP-450 Belief-Robust Certificate (BRC) — 信念鲁棒证书
# ============================================================
@dataclass
class BeliefRobustCertificate:
    """把点谓词提升为置信集上的鲁棒谓词；L_P 需可验证（解析/区间界）"""
    lipschitz: dict[str, float] = field(default_factory=dict)

    def robust_margin(self, name: str, pred: Callable[[Tensor], float],
                      C: ConfidenceSet, kappa: float = 1.0) -> float:
        L = self.lipschitz.get(name, 1.0) * kappa
        return pred(C.center) - L * C.radius()

    def lift_all(self, predicates: dict[str, Callable[[Tensor], float]],
                 C: ConfidenceSet, kappa: float = 1.0) -> dict[str, float]:
        return {k: self.robust_margin(k, p, C, kappa)
                for k, p in predicates.items()}

    def verify_all(self, predicates: dict[str, Callable[[Tensor], float]],
                   C: ConfidenceSet, kappa: float = 1.0) -> bool:
        return all(m >= 0.0 for m in self.lift_all(predicates, C, kappa).values())


# 与 v25 证书的谓词映射（示例 Lipschitz 常数）
def lift_v25_predicates(sensor_data: dict) -> dict[str, Callable[[Tensor], float]]:
    return {
        # 结构：应力/能量余量（对位姿的梯度有界）
        "soc_stress": lambda x: sensor_data['sigma_yield'] / sensor_data['gamma_s']
                                  - sensor_data['sigma_vm'](x),
        "soc_energy": lambda x: sensor_data['E_max'] - sensor_data['E_req'](x),
        # 力控：无源性储能下界
        "fcc_passivity": lambda x: sensor_data['E_0'] + sensor_data['W_ext'](x),
        # 轻量化：屈曲/刚度余量
        "lsc_buckling": lambda x: sensor_data['lambda_buck'] - sensor_data['lambda_req'](x),
        # 语义：几何一致性余量
        "smc_geo": lambda x: sensor_data['eps_sem'] - sensor_data['d_H_est'](x),
        # 重构：动力学残差余量
        "rmc_dyn": lambda x: sensor_data['delta_dyn'] - sensor_data['residual'](x),
        # 协同：碰撞与一致性余量（L_P=1）
        "mcc_collision": lambda x: sensor_data['min_pair_dist'](x),
        "mcc_consensus": lambda x: sensor_data['eps_cons'] - sensor_data['max_cons_err'](x),
    }


# ============================================================
# IP-451 Estimation-Aware SRC-USC (E-SRC-USC) — 统一准入门 v26
# ============================================================
@dataclass
class EstimationAwareUnifiedCertificate:
    sec: StateEstimationCertificate
    edc: EstimationDegeneracyCertificate
    brc: BeliefRobustCertificate
    src_usc: 'SemanticReconfigCoordUnifiedCertificate'   # v25 七证
    Q_rate: Tensor

    def admits(self, multi_plan, sensor_data, predicates) -> bool:
        # 1. 估计器本身可信
        if not self.sec.verify_all(self.Q_rate):
            return False
        # 2. 退化/故障可检测且可隔离
        if not self.edc.verify_all():
            return False
        # 3. 信念-鲁棒余量（覆盖所有下游证书谓词）
        C = self.sec.confidence_set(self.Q_rate)
        kappa = self.edc.inflation_factor()
        if not self.brc.verify_all(predicates, C, kappa):
            return False
        # 4. 名义 v25 七证仍须成立（保证 Exec_v26 ⊆ Exec_v25）
        return self.src_usc.admits(multi_plan, sensor_data,
                                   gt_entities=sensor_data.get('gt_entities'),
                                   queries=sensor_data.get('queries'),
                                   retrieved=sensor_data.get('retrieved'))


# ============================================================
# 端到端流水线：在 SRC-USC 更新后加入估计证书层
# ============================================================
class EstimationAwarePerceptionPipeline:
    def __init__(self, config: dict, src_pipeline):
        self.src_pipeline = src_pipeline
        self.e_src = EstimationAwareUnifiedCertificate(
            sec=config['sec'], edc=config['edc'], brc=config['brc'],
            src_usc=src_pipeline.src_usc, Q_rate=config['Q_rate'],
        )

    def step(self, multi_sensor_data: dict, cloud_update=None):
        # 1. 名义 v25 多机流水线（七证）
        admitted_v25, info_v25 = self.src_pipeline.step(multi_sensor_data, cloud_update)
        if not admitted_v25:
            return False, {'stage': 'v25', 'details': info_v25}

        # 2. 估计证书更新：滑窗、Fisher、新息、故障签名
        self._update_estimation_state(multi_sensor_data)

        # 3. 谓词提升 + 十证准入
        predicates = lift_v25_predicates(multi_sensor_data)
        admitted = self.e_src.admits(
            info_v25['multi_plan'], multi_sensor_data, predicates)

        return admitted, {
            'stage': 'e_src_usc' if admitted else 'estimation_reject',
            'margins': self.e_src.brc.lift_all(
                predicates, self.e_src.sec.confidence_set(self.e_src.Q_rate),
                self.e_src.edc.inflation_factor()),
            'sec': {
                'observability_ok': self.e_src.sec.verify_observability(),
                'consistency_ok': self.e_src.sec.verify_consistency(),
                'coverage_ok': self.e_src.sec.verify_coverage(),
                'latency_ok': self.e_src.sec.verify_latency(),
            },
            'edc': {
                'degeneracy_dirs': self.e_src.edc.degeneracy_directions()[1].shape[1],
                'inflation': self.e_src.edc.inflation_factor(),
                'whiteness_ok': self.e_src.edc.verify_innovation_whiteness(),
                'isolability_ok': self.e_src.edc.verify_fault_isolability(),
            },
            'v25': info_v25,
        }

    def _update_estimation_state(self, data: dict):
        self.e_src.sec.window = data['estimate_window']
        self.e_src.sec.W_o = data['observability_gramian']
        self.e_src.sec.age = data['estimation_age']
        self.e_src.edc.fisher = data['fisher_information']
        self.e_src.edc.innovations = data['innovations']
        self.e_src.edc.innovation_covs = data['innovation_covs']
        self.e_src.edc.fault_signatures = data['fault_signatures']
```

## 2. 复杂度分析（增量）

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 |
|---|---|---|---|
| SEC 可观测性 | O(n³) 特征分解（经验 Gramian 另加 O(Tn³)） | O(n²) | n≤30 |
| SEC NEES 一致性 | O(N·n²) 线性求解 | O(N·n²) | N≤200 |
| SEC conformal/ACI 覆盖 | O(N) 打分 + O(1) 更新 | O(N) 分数缓冲 | N≤200 |
| SEC 时延与协方差膨胀 | O(n²) | O(n²) | Δ≤20ms |
| EDC Fisher 退化 | O(n³) 特征分解 | O(n²) | n≤30 |
| EDC 新息白化 | O(M·m³) NIS + O(M·m) 自相关 | O(M·m) | M≤200, m≤12 |
| EDC 故障隔离 | O(m·F·min(m,F)) 秩检验 | O(m·F) | F≤20 |
| BRC 单谓词鲁棒余量 | O(1)（Lipschitz 界） | O(1) | 7 个证书谓词 |
| BRC 采样精化（可选） | O(S·n) | O(S·n) | S=64 sigma 点 |
| E-SRC-USC 准入 | v25 关键路径 + O(n³+N·n²+N²) | O(n²+N·n²) | 估计层增量 <3ms |

**实时性保证**：SEC/EDC 的 O(n³) 特征分解在 n≤30 时可缓存并低频更新（如 10Hz），NEES/白化按滑窗增量更新；BRC 采用 Lipschitz 常数替代在线 min 优化，单谓词为 O(1)，七谓词合计 <0.1ms；时延仅在 Δ>Δ_max 时触发协方差膨胀重算。E-SRC-USC 的关键路径仍由 v25 的 MCC 成对碰撞检查主导，估计层不改变 20ms 多机协调环的量级。

## 3. 正确性论证（增量）

### 引理 13（SEC 的可观测-一致-覆盖-时延四重保证）
**陈述**：`SEC.verify_all = True` ⇒ 在给定模型与校准假设下，同时满足：
(1) 局部弱可观测：λ_min(W_o) ≥ w_min > 0；
(2) 估计一致性：N·mean(NEES) 落在 χ²_{Nn} 的双侧接受域内；
(3) 信念覆盖：滑窗经验覆盖率不超过 α_est（ACI 维持长程覆盖）；
(4) 信息年龄：Δ_t ≤ Δ_max，且 Σ_inf = Σ + Q(Δ) 覆盖时延期间的不确定性增长。

**证明**：
1. 可观测 Gramian 的最小特征值是有限窗口内最弱可观测方向的能量下界；λ_min>0 等价于该窗口内无完全不可观测方向，保证误差不会沿该方向无界增长（非线性系统取经验 Gramian 的局部线性化近似）。
2. 在线性高斯/局部线性化且 Σ_t 正确标定时，NEES 的期望为 n，N 步均值满足 χ²_{Nn}/N；双侧检验同时拒绝「过置信」（NEES 偏大）与「欠置信」（NEES 偏小）。过置信是安全关键方向，故后续 BRC 还会用 κ_t 额外膨胀。
3. 离线 conformal 分位 q_conf 在可交换性下给出边际覆盖 ≥1−α_est；ACI 将阈值按累计错覆盖率自适应，分布漂移下仍保持长程覆盖（误差 O(γ_aci)）。
4. 时延期间状态按过程模型漂移，Σ+Q(Δ) 是漂移协方差的保守上界；要求 Δ≤Δ_max 保证膨胀有界且可被 BRC 吸收。
∎

### 引理 14（EDC 的退化-白化-隔离三重保证）
**陈述**：`EDC.verify_all = True` 且退化方向被显式膨胀 ⇒ 估计器在退化/故障下不会静默输出伪置信。
**证明**：
1. Fisher 信息 F_t 的最小特征值刻画最弱可观测方向；λ_i<λ_deg 的特征向量张成退化子空间 𝒟_t，κ_t=1+1/(λ_min+ε) 对退化方向做显式保守膨胀（上限 κ_max 防止无界）。
2. 新息白化：NIS_t=ν_tᵀS_t⁻¹ν_t 在模型正确时服从 χ²_m，超过 1−α 分位说明模型/协方差失配；一阶自相关检验排除有色新息（未建模的动态）。
3. 故障签名矩阵 𝔽 列满秩 ⇒ 不同故障模式在残差空间可区分，故障可隔离；不可隔离即拒绝，避免「检测到异常但不知何因」的盲目降级。
∎

### 引理 15（BRC 的可靠性与保守性）
**陈述**：设 C_t 满足 ℙ(x_t∈C_t)≥1−α_est，P 为连续谓词。若 min_{x∈C_t}P(x) ≥ 0，则 ℙ(P(x_t)≥0) ≥ 1−α_est。进一步，若 C_t⊆B(x̂,rad(C_t)) 且 P 的 Lipschitz 常数为 L_P，则 min_{x∈C_t}P(x) ≥ P(x̂) − L_P·rad(C_t)。
**证明**：
1. 事件 {P(x_t)<0} ⊆ {x_t∉C_t}（因为 C_t 上 P≥0），故 ℙ(P(x_t)<0) ≤ ℙ(x_t∉C_t) ≤ α_est，取补即得。
2. 对任意 x∈C_t，‖x−x̂‖≤rad(C_t)，由 Lipschitz 性 P(x) ≥ P(x̂)−L_P‖x−x̂‖ ≥ P(x̂)−L_P·rad(C_t)；对 x 取下确界即得。
3. 该界是保守下界：若 P(x̂)−L_P·rad(C_t)≥0，则真实鲁棒余量必 ≥0；反之不成立，故 BRC 可能拒绝本可接受的计划（保守性），但不会把不安全计划误判为安全（可靠性）。
∎

### 引理 16（估计感知单调退化链）
**陈述**：Exec_v26 = Exec_v25 ∩ Fil_est ⊆ Exec_v25；且估计失效/退化/时延超限三类路径均严格退化到 Exec_v25 的子集。
**证明**：
1. `E-SRC-USC.admits` 的最后一步仍要求 `src_usc.admits`，故任何 v26 计划必属 v25；再与 Fil_est 取交，子集关系显然。
2. 可观测性退化：EDC 输出 𝒟_t，κ_t 膨胀使 BRC 余量收紧；若仍不足则拒证，退回 v25 中不依赖退化自由度的保守计划（或安全停机），该子集仍须通过 v25 名义检查。
3. 一致性/覆盖失效：SEC 拒证，禁止使用当前信念做任何新任务规划，退回固定膨胀/死推算的 v25 保守子集；一旦 SEC 恢复，才重新开放 v26。
4. 时延超限：以 Σ+Q(Δ) 膨胀后重验；若 Δ>Δ_max 或膨胀导致 BRC 失败，则拒证并退回 v25。三类路径取交集，单调性保持。
∎

### 定理（E-SRC-USC 十证准入门）
**陈述**：对任意多机计划 Π，`E-SRC-USC.admits(Π)=True` ⇒ Π 同时满足：
(1) HPC-E+ 感知-合规-能量接地；(2) SOC 结构应力/能量/可制造；(3) FCC 力控无源性/带宽/稳定；(4) LSC 轻量刚度/质量/屈曲；(5) SMC 语义覆盖/几何一致/开放词汇；(6) RMC 重构动力学/接口/证书传递；(7) MCC 协同一致/避障/纳什；(8) SEC 可观测/一致/覆盖/时延；(9) EDC 退化可检/新息白化/故障可隔离；(10) BRC 对上述所有谓词的信念-鲁棒余量非负。
**证明**：必要性由 `admits` 的连言结构与引理 1–16 直接得到；充分性方面，在模型正确、置信集校准、Lipschitz 常数可验证的理想条件下，十条件同时成立即对应 v25 完备性与引理 15 的覆盖传递，构成「单机物理→结构力学→语义/重构/协同→估计信念」的闭环。需注意 (1)–(10) 的实际强度依赖校准与 Lipschitz 界，故这是相对完备性而非无条件完备性。
∎
