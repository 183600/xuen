# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 4 轮；本轮灵感：「机器人基础模型」×「协同控制」）

> 第 57 轮把安全的赌注从"模型置信"换到"证据质量"，用 MFSL 摊销先验、XMC 分账对账、PTM 单向有界信任补上三条腿，却在自陈里留下"坏先验普遍"的尾巴：语料存在系统性盲区时，元模型会在 OOD 门学会识别的模式之外给出高度自信的错误后验，而跨模态一致加成与个性化加速会把错误更快送进承诺。本轮两个灵感把这条尾巴**上升到系统层**：**机器人基础模型（RFM）** 用互联网级语义先验把"语义盲区"廉价填满（解药），**协同控制**让多台机器人共享计划、分担任务、互相补位（效率）；但二者合流制造了更深的病——**多智能体往往共享同一个 RFM 主干、同一套仿真器与同一批校准，它们的"一致"不是两个独立证人，而是同一个盲区被数了 N 遍（毒药）**，协同共识的正反馈还会把这种共享错误固化成联合承诺。本轮把安全赌注由"元先验质量"转成 **"语义可接地 + 证据血缘可独立 + 局部否决不可剥夺"**，核心命题升级为 **"基础模型只许提议、协同只许聚合独立证据、现实对每个智能体单独保留否决权"的证据承诺**。

核心矛盾：
- **H29（语义先验 vs 物理可证）**：RFM 给出谓词级语义先验（可通行/可承重/可抓取/危险/角色），廉价填补语义盲区；但它不透明、未校准，且会幻觉出"本机传感器根本不可观测"的属性（语义信息落差 δ_sem）——为每个声明强制接地会毁掉效率，不接地则让自信幻觉获得授权资格。
- **H30（协同共识 vs 证据相关）**：一致（consensus）是最自然的置信放大器，但当智能体共享 RFM 主干/仿真器/校准批次时，一致由共享训练制造而非现实制造；**N 个同源证人 ≤ 1 个独立证人**，共识正反馈甚至把错误放大；且联合风险 ≠ 个体风险取 max（对撞、死锁、共享载荷、队形耦合都在缝里）。
- **H31（局部否决 vs 全局任务）**：给每个智能体不可剥夺的局部否决能保证安全，却可能让协同任务活锁/死锁；为任务进度放开否决，就等于允许投票剥夺红线。否决必须在"不可逆动作"上绝对、在"可逆动作"上有结构地协商，且活跃性不得用不可逆风险购买。

## 0. 直觉与动机

**灵感 1（机器人基础模型 → 只提议的语义先验 + 谓词共形 + 语义接地）**
直觉：RFM 像一个读遍互联网却从未下过田的顾问——它能一眼说出"那是玻璃桌面，别踩"和"这趟任务应分成三段"，但它的话不能直接当证据：它没摸过、没压过，还可能把训练集里的视觉套路硬套到眼前的坡面。正确用法是**给 RFM 换一个动词**：不是"作证"，而是"**提议**"。RFM 产出语义声明（谓词、指代、提议分、来源），先进入**谓词级共形阈值**（保证"被接受且为假"的比例 ≤α_sem），再过**语义接地门**——凡是会影响承诺的声明，必须找到一条本体的物理/几何/触觉/语言确认（带误差模型）；找不到就只能走保守通道（加宽、降档、绕行、生成探针），永不进入必要证据集。特别地，若声明依赖本机不可观测的属性，就用 δ_sem 标为"不透明"，不许拿"模型看起来很确定"冒充"我们知道"。

**灵感 2（协同控制 → 只聚合独立证据 + 联合耦合证书 + 局部否决）**
直觉：多机协同最诱人的地方是"互相印证"——A 说前面能走，B 也说过，好像就稳了。可如果 A 与 B 跑的是同一个 VLA、同一个蒸馏学生、同一套标定，它们的同意只是**同一个盲区被复述**。因此协同层的第一原则是 **"共享承诺，不共享信念"**：智能体之间交换的是带接口的承诺契约与证据**血缘哈希**，不是原始信念；聚合时按**有效独立度** κ 折扣，`N_eff=(Σw)²/ΣΣw_iw_jρ_ij` 才是真正的"证人数"，而不是成员数。第二原则是**联合风险显式化**：`R_joint=G_couple·max_iR_i`，只有 `G_couple=1`（耦合被证伪）的子域才允许分离论证。第三原则是**局部否决不可投票剥夺**：任一智能体对不可逆动作说"不"，共识无法翻盘；它退出联合计划、保守停，其余成员如要续跑必须重新签发耦合证书。通信陈旧则邻居退化为"膨胀后的最后足迹"，绝不把"没收到坏消息"当好消息。

**灵感 3（合流 → 提案-接地-对账-耦合-承诺五段式）**
直觉：RFM 负责"把可能性摊开"，协同负责"把可能性分给谁"，证据门负责"哪些可能性真的能落地"。三者顺序不能乱：先提议（便宜、宽、可错），再接地（贵、窄、可审计），再对账（血缘、独立度、耦合），最后才承诺。RFM 的价值被严格限定为**让探针更准、让保守动作更早**，绝不支付为"更敢赌"；协同的价值被限定为**减少重复探针与提高任务并行度**，绝不被允许用成员数量替代证据数量。

**灵感 4（证据门从五类到七类、从单机到联合）**
直觉：在 IP-137 的五类证据上只加两类，且都带单边性——**EV-sem**（限接地且限 L1，可顶替一次佐证，禁不可逆）与 **EV-coop**（仅当 `N_eff≥κ_0` ∧ 新鲜度 ∧ J_cc，且限 L1）。不可逆接触的必要证据集仍是 `{真实 EV-probe* ∨ EV-margin} ∪ 佐证`，额外要求 `J_cc`；**EV-sem/EV-coop/EV-xmodal/EV-sim 一律不得入集**。这样"模型说行"与"队友说行"永远只能省探针，不能免探针。

**灵感 5（RCP → 探询预算里的协同项）**
直觉：把 VOI 的候选探针分成"自探"与"请队友探"两类；请队友探的收益要按血缘独立度打折、按通信时延扣成本；当 `N_eff<κ_0` 时，最优动作不是"再问一遍同源队友"，而是**换一条独立血缘**（换模态、换轨迹、换校准批次）或退回单机保守策略。协同因此不是"多问几个人"，而是"多找几条互不共享祖先的证据链"。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（语义基础模型提议器 RFM-G）** 基础模型 ℱ_ψ 以观测 o 与语言 ℓ 输出语义声明集 `𝒜={(p,x,c,prov,obs)}`：谓词 `p∈𝒫`（可通行/可承重/可抓取/危险/角色/队形约束），指代 x∈区域∪物体∪智能体，提议分 c∈[0,1]（**非概率**），来源 prov=(模型版本,训练族,输入轨迹 id)，obs∈{0,1} 表示声明是否依赖本体不可观测属性。**提议语义（硬约束）**：ℱ 只可写"探针候选/绕行候选/警告/角色草案"，不得直接写证据门、不得直接授权。谓词级共形校准：对每个 p，用校准集求阈值 τ_p 使选择性风险 `P(p 错 ∧ c≥τ_p)≤α_sem`；`C_p(x)={y:p(x,y) 在 1−α_sem 覆盖内}`。语义信息落差 `δ_sem(p)=E[TV(ℱ_p(·|z_full),ℱ_p(·|o_onboard))]`；`δ_sem>θ_sem` 或 obs=1 ⇒ 声明标记 **opaque**。

**定义 140（语义接地门 SGG 与语义残差账本）** 声明 α 接地 ⇔ 存在至少一条**本体可观测**的确认记录 g(α)（几何/深度分割/触探/本体接触/语言确认，各带误差模型）。**EV-sem(α)** 可用 ⇔ α∈C_p ∧ grounded(α)≥1 ∧ δ_sem(p)≤θ_sem ∧ level=L1 ∧ 非不可逆；可顶替一次 L1 佐证，不得入不可逆必要证据集。未接地声明只允许产生保守动作（加宽/降档/绕行/生成探针）。**语义残差账本**：每个谓词头维护 `(res_p,ρ_p)`；观测与声明矛盾 ⇒ `ρ_p←max(ρ_min,γ_down·ρ_p)` 并回溯标记该头全部历史 EV-sem，证实则 `ρ_p` 有界恢复；ρ_p<ρ_min 的谓词头禁用，退纯物理路径。

**定义 141（协同承诺与耦合证书 CCC）** 智能体集 A，联合计划 π={π_i}，局部承诺 c_i，局部风险 R_i。联合风险 `R_joint=G_couple·max_i R_i`，其中耦合增益 `G_couple∈[1,G_max]` 编码共享空间/共享资源/时序耦合/共享载荷/队形约束。联合承诺可行 ⇔ 每个 c_i 过局部证据门 ∧ `R_joint≤δ_f^joint` ∧ 证书 J_cc 过；**分离论证仅在 G_couple=1 的子域成立**，否则必须显式计入耦合放大。**局部否决不可剥夺**：对不可逆动作，任一 i 的本地否决不受任何加权/投票/领导者命令影响；触发即从联合计划退出并执行局部安全停，其余成员续跑须重签 J_cc。

**定义 142（证据血缘与有效独立性 EIL）** 每条证据 e 带血缘 `𝓛(e)=(sensor_id,traj_id,rfm_ver,distill_ver,calib_batch,sim_seed,agent_id,ancestor_hash)`。相关性 `ρ(e,e')=CorrDep(𝓛(e),𝓛(e'))∈[0,1]` 由共享祖先与共享校准估计，有效独立度 `κ=1−ρ`。聚合有效样本量 `N_eff=(Σ_i w_i)²/(Σ_{i,j} w_iw_jρ_ij)`；协同一致产生的证据量按 `N_eff` 计，不按成员数计。**血缘审计**：伪造/隐瞒共享祖先按"证据洗钱"处理（拒绝聚合并记入 J_c）；共享 RFM 主干或同一蒸馏学生的成员，其 κ 自动置 0，直到出现独立血缘。

**定义 143（协同-基础模型证据门 CFG 与证书 J_c）** 证据类七类：`EV-probe*/EV-visit/EV-margin/EV-xmodal/EV-human`（第 57 轮）+ **EV-sem**（限接地∧L1）+ **EV-coop**（限 `N_eff≥κ_0` ∧ `age≤T_fresh` ∧ J_cc ∧ L1）。不可逆接触必要证据集 `={真实 EV-probe*∨EV-margin}∪佐证∧J_cc`；EV-sem/EV-coop/EV-xmodal 均不得入集。`J_c=(SemCalLog,GroundingLog,lineage_hashes,N_eff,J_cc,freshness_log,veto_log,rfm_ver,ρ_p)`，继承 J_p 全检。

**定义 144（RFM-协同探-诺-演算子 RCP）** 每检查点：①RFM 提议（语义先验/角色草案/探针候选）；②接地检查（opaque 或未接地 ⇒ 仅保守通道）；③协同对账：交换承诺契约与血缘哈希，算 `R_joint/G_couple/N_eff/age`；`N_eff<κ_0` 或 `age>T_fresh` ⇒ 不聚合、退局部证据、邻居按膨胀足迹处理；④局部证据门（IP-137 FSE）；⑤耦合证书 J_cc；⑥承诺 ⇔ 局部门∧J_cc∧新鲜度∧（κ 条件）；否则元悲观 VOI 选探（"自探/请队友探"按 κ 与通信成本定价）→换独立血缘→绕行→降档→L2 协商（τ_int(auth)）→局部安全停。**活跃性**：死锁解决只用 L0/L1 可逆动作，预算 B_live 用尽即退化到各机独立保守停（任务失败但安全）。

## 2. 关键算法伪代码（完整版见产物区）

```python
def rfm_propose_and_ground(F, o, l, r, ledger):        # IP-139/140
    A = F.propose(o, l, z=ctx(r))
    out = []
    for (p, x, c, prov, obs) in A:
        if c < tau[p] or delta_sem[p] > theta_sem or obs:
            out.append((p, x, 'opaque', prov)); continue     # 只许保守通道
        g = ground(p, x, o)                                  # 几何/触觉/本体/语言
        out.append((p, x, 'grounded' if g else 'ungrounded', prov))
    return out

def coop_reconcile(plans, lineage, t_now):             # IP-141/142
    rho = {e: corr_dep(lineage[e]) for e in lineage}
    Neff = (sum(w.values()))**2 / sum(w[a]*w[b]*rho.get((a,b),1)
                                       for a in w for b in w)
    G = coupling_gain(plans)                             # 1 = 可分离
    R = G * max(plan.R for plan in plans)
    fresh = all(t_now - plan.t <= T_FRESH for plan in plans)
    return Neff, R, G, fresh

def commit_joint(c, plans, M, persona, t_now):          # IP-144
    Neff, Rj, G, fresh = coop_reconcile(plans, lineage_of(plans), t_now)
    if c.irreversible and any(plan.local_veto for plan in plans):
        return ('local_safe_stop', c)                    # 局部否决不可投票
    if not fresh: return ('stale_default_inflate', c)    # 陈旧默认膨胀
    if c.ev == 'EV-sem' and not grounded(c): return ('reject','ungrounded',c)
    if c.ev == 'EV-coop' and (Neff < K0 or not fresh):
        return ('reject','not_independent',c)
    if Rj > delta_f_joint: return ('reject','joint_coupling',c)
    return ('ok', c) if local_gate(c, M, persona) else ('reject','local',c)
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| RFM-G | 前向 O(d_F)（可预取）；提议只读 | O(\|ψ\|) 静态 | 提议边界、谓词共形 τ_p、δ_sem 诚实 |
| SGG | O(1)+O(\|g\|) 接地 | O(\|𝒜\|·\|𝒫\|) | 未接地不入证据集、残差回溯完整 |
| CCC | O(\|A\|²·d_plan) | O(\|A\|·\|π\|) | G_couple 保守、J_cc 完备 |
| EIL | O(\|e\|²) 或增量 O(\|e\|) | O(\|e\|²)/稀疏图 | κ 计算诚实、反洗钱 |
| CFG | O(\|σ\|·\|A\|) | O(\|σ\|) | 七类边界、局部否决 |
| RCP | O(\|CP\|·(k_p+k_c)·(C_VOI+d_F+d_ground)+\|CP\|·\|A\|²) | O(\|V\|+\|σ\|+\|A\|) | 五段序、B_live 终止 |

**正确性定理（SCGS：Semantic-Cooperative Grounded Soundness 概要）**：在 A33–A40 上加 (A41) 语义提议边界与谓词校准（ℱ 只写提议通道；选择风险 ≤α_sem；δ_sem 诚实；opaque/未接地声明不入必要证据集）；(A42) 血缘独立与联合耦合诚实（κ/ρ 计算与共享祖先折扣完整；`EV-coop` 仅在 `N_eff≥κ_0`∧新鲜度∧J_cc 且限 L1 使用；G_couple 完整覆盖耦合）；(A43) 局部否决不可剥夺（不可逆动作的本地否决不受共识影响；通信陈旧必膨胀；B_live 下死锁解决只用可逆动作）。则：

(i) **语义健全性**：RFM 对承诺失效率的贡献 ≤ `α_sem+δ_sem·1[grounded∧L1]`；opaque/未接地路径对授权的贡献恒为 0。
(ii) **相关证据不放大**：N 个同源成员的"一致"最多计 1 个独立证人（`N_eff≤Σκ`），故共享 RFM/蒸馏/仿真的共谋不能缩短探针下限，也不能把联合假承诺概率降到单证人水平以下。
(iii) **局部否决与联合安全**：任一智能体不会被投票带入不可逆风险；`P(joint fail)≤δ_f^joint+Σ_i(局部项)`，且 `G_couple` 漏检由 J_cc 显式吸收。
(iv) **交互单调性**：RFM/协同只能经 (a) 更接地/更准的信念或 (b) 更保守的动作参数（加宽、降档、分离、膨胀足迹、局部停）影响系统，不存在升险通道；RFM 提议永不进入授权通道。
(v) **终止性**：每检查点自探+请队友探 ≤k_p+k_c，死锁解决 ≤B_live，RCP 终止于 {联合承诺, 单机承诺, 绕行, L2 协商, 局部安全停}。

关键：**提议与作证解耦、承诺与信念解耦、安全与活跃性解耦**——RFM 只把世界摊开，协同只把证据按血缘去重，局部否决保证没有任何智能体会被"多数"送进不可逆风险。

## 6. 本轮最大风险

**一句话**：多智能体共享同一个 RFM 主干、仿真器与校准批次时，协同共识会把"同一个盲区"重复计数成"多方一致"，而合作任务的正反馈（互相借道/让行/共享载荷）会把这种共享错误固化成联合承诺；必须以**有效独立度 κ 折扣 + RFM 仅提议 + 局部否决不可剥夺 + 通信陈旧默认膨胀**四重护栏，坚决不让"一致"冒充"独立"、不让"多数"冒充"证据"。

def semantic_grounding(decl, o, M):

def semantic_evidence_ok(decl, g, level, irreversible, ledger):
    if g.cls != 'grounded':                return False
    if level != 'L1' or irreversible:      return False   # EV-sem 硬禁令

def semantic_residual_update(ledger, p, verdict):
    if verdict == 'falsified':
        ledger.rho[p] = max(RHO_MIN, GAMMA_DOWN * ledger.rho[p])
        ledger.backtrace(p)                              # 回溯标记历史 EV-sem
    elif verdict == 'confirmed':
        ledger.rho[p] = min(1.0, ledger.rho[p] + GAMMA_UP)

### IP-141 CCC（协同承诺与耦合证书，局部否决不可剥夺）

def coupling_gain(plans, world):
    G = 1.0
    for a, b in pairs(plans):
        if share_workspace(a, b, world):   G = max(G, GAIN_SPACE)
        if share_resource(a, b, world):    G = max(G, GAIN_RES)
        if temporally_coupled(a, b):       G = max(G, GAIN_TIME)
        if share_payload(a, b):            G = max(G, GAIN_LOAD)
        if formation_constraint(a, b):     G = max(G, GAIN_FORM)
    return clamp(G, 1.0, G_MAX)

def cooperative_commit(plans, world, level, budget):
    if level == 'irreversible' and any(p.local_veto for p in plans):
        return Verdict('LOCAL_SAFE_STOP')                # 否决不可投票剥夺（A43）

### IP-142 EIL（证据血缘与有效独立性，反洗钱）

def lineage(e):
    return (e.sensor_id, e.traj_id, e.rfm_ver, e.distill_ver,
            e.calib_batch, e.sim_seed, e.agent_id, e.ancestor_hash)

def corr_dep(L1, L2, ledger):
    # 共享传感器/轨迹/模型版本/校准批次/种子/祖先任一 ⇒ 视为相关
    shared = len(set(L1) & set(L2))
    return ledger.rho_table.get((L1, L2), min(1.0, shared / 4.0))

def effective_n(evidence, weights, ledger):
    rho = {(i, j): corr_dep(lineage(ei), lineage(ej), ledger)
           for i, ei in enumerate(evidence) for j, ej in enumerate(evidence)}
    num = sum(weights.values()) ** 2
    den = sum(weights[i] * weights[j] * rho[(i, j)]
              for i in range(len(evidence)) for j in range(len(evidence)))
    return num / max(den, EPS)                           # N_eff（Kish）

def audit_laundering(members):

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| RFM-G | 前向 O(d_F)（可预取）；提议只读 | O(\|ψ\|) 静态 | 提议边界、τ_p/α_sem、δ_sem 诚实（A41） |
| SGG | O(1)+O(\|g\|) 接地 | O(\|𝒜\|·\|𝒫\|) | 未接地/opaque 不入证据集、回溯完整（A41） |
| CCC | O(\|A\|²·d_plan) | O(\|A\|·\|π\|) | G_couple 保守、J_cc 完备、局部否决（A42/A43） |
| EIL | O(\|e\|²) 或增量 O(\|e\|) | O(\|e\|²)/稀疏 | κ/ρ 诚实、反洗钱（A42） |
| CFG | O(\|σ\|·\|A\|) | O(\|σ\|) | 七类边界、软证据限 L1、J_cc 入不可逆 |
| RCP | O(\|CP\|·(k_p+k_c)·(C_VOI+d_F+d_ground)+\|CP\|·\|A\|²) | O(\|V\|+\|σ\|+\|A\|) | 五段序、B_live 终止 |

**正确性定理（Semantic-Cooperative Grounded Soundness, SCGS）**
假设 A22–A40 成立；**(A41)** 语义提议边界与谓词校准：ℱ_ψ 只写入提议通道（探针先验/候选路线/警告/角色草案），谓词级选择风险 `P(p 错∧c≥τ_p)≤α_sem`，δ_sem 声明诚实，opaque/未接地声明不得进入任何必要证据集；**(A42)** 血缘独立与联合耦合诚实：κ/ρ 计算与共享祖先折扣完整，`EV-coop` 仅在 `N_eff≥κ_0`∧`age≤T_fresh`∧J_cc 且限 L1 使用，`G_couple` 完整覆盖共享空间/资源/时序/载荷/队形，分离论证仅限 `G_couple=1` 子域；**(A43)** 局部否决与活跃性：不可逆动作的本地否决不受任何共识/加权/领导命令影响，通信陈旧必膨胀为保守足迹，死锁解决只用 L0/L1 可逆动作且 ≤B_live。则：

1. **语义健全性**：承诺中 RFM 路径的失效贡献 ≤ `α_sem + δ_sem·1[grounded∧L1]`；opaque/未接地路径对授权的贡献恒为 0；`ρ_p<RHO_MIN` 的谓词头禁用，历史 EV-sem 全部回溯失效。
2. **相关证据不放大**：N 个同源成员的"一致"最多计 1 个独立证人（`N_eff≤Σκ`）；共享 RFM/蒸馏/仿真的共谋不能缩短探针下限，也不能把联合假承诺概率压到单证人水平以下。反洗钱审计拒绝隐瞒共享祖先的聚合。
3. **局部否决与联合安全**：任一智能体不会被投票带入不可逆风险；`P(joint fail) ≤ δ_f^joint + Σ_i(δ_f+α_sem+δ_probe+ε_h+δ_ood·α_conf)`；`G_couple` 漏检由 J_cc 的保守增益显式吸收（乘性放大，不取 max 掩盖）。
4. **交互单调性**：RFM 提议与协同一致只能经 (a) 更接地/更准的信念或 (b) 更保守的动作参数（加宽、降档、分离、膨胀足迹、局部停）影响系统，不存在升险通道；RFM 提议与共识计数永不直接进入授权集。
5. **终止性与部署界**：每检查点自探+请队友探 ≤k_p+k_c，死锁解决 ≤B_live；对检查点取联合界

```
P_safe ≥ 1 − Σ_cp Σ_i (δ_f + α_sem + δ_sem·1[L1] + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1])
             − P(κ 高估 ∧ 共享先验伪独立) − P(G_couple 漏检 ∧ 联合耦合)
             − P(局部否决失效) − P(通信陈旧未膨胀)
```

关键：**提议与作证解耦、承诺与信念解耦、安全与活跃性解耦**；一致只在"血缘独立"时才算证据，成员数永远不等于证人数。RFM 的价值被限定为"让探针更准、让保守动作更早"，协同的价值被限定为"减少重复探针、提高任务并行度"，二者都不支付为"更敢赌"。

## 6. 本轮最大风险

**一句话**：多智能体共享同一个 RFM 主干、仿真器与校准批次时，协同共识会把"同一个盲区"重复计数成"多方一致"，而合作任务的正反馈（互相借道/让行/共享载荷）会把这种共享错误固化成联合承诺；必须以**有效独立度 κ 折扣 + RFM 仅提议 + 局部否决不可剥夺 + 通信陈旧默认膨胀**四重护栏，坚决不让"一致"冒充"独立"、不让"多数"冒充"证据"。
