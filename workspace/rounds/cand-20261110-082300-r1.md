# 第 43 轮（新循环第 1 轮） · Interrogative-Cert VLA：把 VLA 当「提议者」、把 VQA 当「审讯式证书验证器」，构建语义 × 几何双层证书（四层架构 v8）

> 承接第 42 轮 v19（SCV × CKB × ECR）。第 42 轮自陈最大风险是「仿真偏差累积 + 检索幻觉 → 证书静默失效」。本轮灵感词「视觉问答」「视觉-语言-动作模型」切中的是另一个同构命门：第 42 轮的所有证书都只回答「动作做得安不安全」（几何/动力学边际），却从不回答「做的是不是**这件**事」。VLA 让机器人第一次能泛化地理解语言指令，但它是黑箱、会幻觉、且没有任何 soundness 保证；VQA 则提供了一个**可审讯的语义接口**——把「它到底看见了什么、理解成了什么」拆成一串可验证的原子问答。于是本轮的核心迁移是：**VLA 只当提议者（proposer），VQA 当审讯式验证器（interrogator）**，语义证书负责「规格一致性」，几何证书负责「动力学安全性」，两者在 CAR 的转移边上做保守合取，得到语义 × 几何双层证书。

## 0. 直觉与动机

**灵感 1（VQA → 从「一个答案」到「可审讯的语义证书」）**：传统 VQA 输出 answer + softmax 置信度，置信度不可校准、不能当安全证据。VQA 真正的研究价值不在「答对」，而在它把感知暴露成一个**谓词神谕（predicate oracle）**：任意原子命题「红杯子是否在左前方」「抓取器是否闭合」「路径是否被人占据」都能被提问。直觉上，这就像把定理证明器接到感知上——我们不是要它「感觉安全」，而是要求它对一组**关键命题**给出可审计的回答。用 conformal prediction 把每个答案变成带覆盖保证的预测集（yes / no / {yes,no}），再用「问题格」上的逻辑一致性（可见 vs 被遮挡、左 vs 右、数量守恒）和**反事实提问**（若移除遮挡物答案是否改变）过滤「顺口胡说」。语义证书 = 关键问题集上无矛盾且单值的预测集 + 反事实稳定答案。

**灵感 2（VLA → 提议者 + 可审计 rationale，而非可信执行者）**：RT-2/OpenVLA/π0 这类 VLA 把 (图像, 指令) 映射为动作 token，泛化强但不可解释、会在长尾场景「自信地做错事」。直觉是双过程（System 1 / System 2）：VLA 快速给出**动作块 + 自然语言 rationale**（「抓左边红杯子，绕开桌上电线」），其中 rationale 不是装饰，而是一组**可被 VQA 逐条核验的声明**（claims）。审讯器做「动作条件提问」：执行该动作会占据哪些空间？目标物体是否真的可抓？指令里的颜色/方位/数量是否被满足？rationale 中任一声明与语义证书矛盾 → 拒绝/降级/让 VLA 带着「哪个子目标未被验证」重新规划，而不是继续执行。

**灵感 3（融合 → 语义 guard 调制几何 guard，但只在预认证语境里）**：第 42 轮的几何证书只保证「别撞、别失稳」，对「指令说去红箱却去了蓝箱」完全无感；而 VQA 证书对「会不会撞」又只给语义级判断、给不出连续动力学保证。两者必须**正交合取**：CAR 转移边开启 iff `m_geo ≥ θ_e AND m_sem ≥ τ_e AND 无矛盾`。进一步，语义可以缓解第 41/42 轮的过度保守：当 VQA 以高置信认证「工作区内无人类、指令明确允许靠近」时，切换到 **SCV 离线预认证过的语境阈值档 θ_e(σ)**（σ = 语义语境标签），而不是在线任意放松——在线只允许在「已认证档位」之间**选择**，不允许连续放宽，从而既降过度保守又不破坏 soundness。反过来，若 VQA 认证「有儿童/易碎物」，立即切到最保守档并降级。

**耦合升级**：VLA 提议 → rationale 解析为 claims → VQA 问题调度器按「信息增益/风险/时延」选问 → 语义证书 + 几何证书在乘积自动机上合取 → 执行 → 语义反例/物理反例都写入 CKB → 反哺问题格模板、语境阈值档、VLA 提示与课程。飞轮由第 42 轮的 "Sim→RAG→Edge→Sim" 扩为 **Propose→Interrogate→Fuse→Audit→Propose** 的语义-物理双闭环。

## 1. 形式化定义（增量：定义 38–44）

**定义 38（语义谓词与问题格）**：设有限谓词集 Π，每个谓词 π: (I, L) → {0,1}，I 为图像/观测，L 为语言指令。**问题格** Q = (Π, ⪯, ⊗)，⪯ 为逻辑细化偏序，⊗ 为合取/否定的部分闭包。VQA 审讯器 g: Q×(I,L) → Δ({yes,no,abstain})，对问题 q_π 输出答案 a_q ∈ {yes,no,unknown}。**关键问题集** Q_crit ⊆ Q 由三处交叠确定：CAR 转移边的语义前提、动作 a 的前提 Pre(a)、指令指称的唯一性约束（如 referent 唯一、目标存在、路径无碰撞、抓取可行、符号约束满足）。

**定义 39（语义证书与 conformal 语义边际）**：给定校准集 D_cal 与显著性 α，对每个 q 得预测集 Γ_q ⊆ {yes,no}，满足边际覆盖 Pr(π_q ∈ Γ_q) ≥ 1−α（可交换性假设下）。**语义证书** C_sem = {(q, Γ_q) : q ∈ Q_crit, |Γ_q| = 1 且 在 Q 上无逻辑矛盾}；若 |Γ_q| = 2 或与逻辑相关题矛盾，则 q 标为 open。**语义边际** m_sem = min_{q∈Q_crit} m_q，m_q 为「certify yes」方向的一致化余量（由 conformal p-value 经单调映射到 [0,1]）。签发条件 m_sem ≥ τ_e，其中 τ_e 是该转移边的语义阈值。

**定义 40（动作条件问题与 rationale 审计）**：VLA 输出 (a, ρ)，a 为动作块，ρ 为声明集（每个 ρ_j 是 Π 上的原子命题或其否定）。动作 a 的前提集合 Pre(a) ⊆ Π（自由空间、目标可达、抓取闭合、无遮挡等）。审计函数
`Audit(a, ρ) = 1` iff `∀φ ∈ ρ ∪ Pre(a): φ 被 C_sem 以 margin ≥ τ_e 单值认证` 且 `¬∃φ ∈ ρ: ¬φ 被认证`。
失败时返回**未认证子集** U(a) ⊆ ρ ∪ Pre(a)，作为结构性反馈交给重规划，而非笼统的「再试一次」。

**定义 41（语义-几何乘积证书）**：C = (C_geo, C_sem, θ(σ), τ)。对转移边 e、状态 x、动作 a 与语义语境 σ（由 C_sem 中一组决定性命题诱导的等价类）：
`Enabled(e, x, a) = [m_geo(x) ≥ θ_e(σ)] ∧ [m_sem(a) ≥ τ_e] ∧ [Audit(a, ρ) = 1] ∧ [σ ∈ Σ_cert]`。
其中 Σ_cert 是 SCV（IP-54）离线用**语境化压力测试**认证过的语境标签集合，θ_e(σ) 为预认证阈值档。**单调性约束**：θ_e(σ) 只能取离散预认证值，在线禁止连续外推。**命题（保守合取 sound）**：若 C_geo 对动力学 sound、C_sem 对关键命题 sound、且 σ 识别正确，则 Enabled ⟹ 动作在「语义规格」与「动力学」两方向均安全。

**定义 42（问题调度 anytime）**：预算 B 下选择问题子集 Q_act，最大化 `E[ΔH(certificate)] / (c_q + λ·risk_q)`，其中 ΔH 为对关键命题不确定性的熵减，risk_q 为问题本身的分布外暴露风险（如依赖细粒度属性的问题更易幻觉）。停止准则：m_sem 的置信下界 ≥ τ（签发）、上界 < τ（拒绝）、或预算耗尽（降级/弃权）。与 IP-52 分档对齐：T-1 语义查表（缓存常见问题答案）、T0 小模型 VQA、T1 全量 VQA + 反事实、T2 人类审计。

**定义 43（语义反例与 CKB 迁移）**：语义反例 `ξ_sem = (I, L, a, ρ, Q_asked, {Γ_q}, U(a), gt_label)`。CKB 检索键新增语义指纹 φ_sem（指令类型、指称结构、场景图拓扑、关键谓词签名），检索结果提供：关键问题格模板 Q_crit、语境阈值档 θ(σ)、VLA 提示补丁、常见幻觉模式。新场景合成语义证书的成本 ∝ 未覆盖问题数，而非全问题格。

**定义 44（验证器独立性 / 共谋幻觉）**：设策略模型 M_p 与验证模型 M_v。定义错误共现率 `ρ_err = P(M_p 错 ∧ M_v 认证错 | 同一输入)`，独立基线 `ρ_ind = P(M_p 错)·P(M_v 错)`。**独立性证书**要求 (i) `ρ_err ≤ ρ_ind + δ_ind`；(ii) 在一份人类标注、且对 M_p/M_v 均不可见的**留出审计集**上，`M_v` 的关键命题错误率 ≤ ε_v。若独立性不成立，语义证书降级为「仅建议（advisory）」，签发依赖几何证书 + 传统感知冗余；这正是把「自信的静默失效」转成「显式的降级/弃权」的闸门。

## 2. 产出设计（新增 IP-57/58/59 + 升级 IP-54/55/56/51/52/53/50/47/45）

### 2.1 IP-57 SEMANTIC-CERT-INTERROGATOR（语义证书审讯器 SCI）
1. **问题格构造**：从指令做指称解析、从场景图做关系抽取、从 CAR 边与动作前提抽取关键命题，合并成 Q_crit（存在性 / 唯一性 / 属性 / 空间关系 / 可供性 / 安全语境）。
2. **Conformal 校准**：在按场景/指令分层的校准集上，对每类问题单独校准，得到带覆盖保证的预测集；漂移时用加权 conformal 并输出弃权。
3. **反事实稳定化**：对高风险命题做 `do(遮挡/移除/替换)` 提问，答案不稳定的命题一律降为 open，防止单帧「顺口胡说」。
4. **矛盾检测**：在问题格上做局部一致性传播（可见 vs 被遮挡、左 vs 右、数量守恒、同义改写一致）。

### 2.2 IP-58 VLA-PROPOSE-AUDIT（双过程提议-审计 VPA）
1. **结构化 rationale**：约束 VLA 输出 JSON 式 claims（子目标、目标物体、方位、避让对象），便于逐条核验。
2. **动作条件提问**：把 a 的 Pre(a) 与 ρ 一起送到 SCI，做「执行 a 后/前提是否成立」的提问。
3. **未认证反馈重规划**：把 U(a) 作为结构化提示送回 VLA（有界重试），或切换经典规划器在已验证区域内找替代动作。
4. **独立性设计**：验证器与策略尽量异构（不同骨干/数据/模态），并挂载留出审计集与共谋检测（定义 44）。

### 2.3 IP-59 SEM-GEO-CERT-FUSION（语义-几何证书融合 SGCF）
1. **乘积守卫**：在 IP-51 CAR 的每条转移边上并联语义守卫，联合判定 Enabled。
2. **语境阈值档**：由 IP-54 离线认证 θ_e(σ) 的离散档位，在线只做语境识别 + 档位选择，禁止连续放宽。
3. **联合证书对象**：打包 (m_geo, m_sem, σ, θ_e(σ), τ_e, 证据 provenance, 审计状态)，供 RCA 与认证回溯。
4. **保守回退链**：语义拒签 → 降档；语境识别不确定 → 最保守档；独立性失效 → 语义仅建议 + 几何兜底 + SafeStop。

## 5. 本轮最大风险

**一句话**：VLA 与 VQA 很可能共享同一套 VLM 先验，二者幻觉**相关**，验证器会替策略「背书」出一张假证书——而假证书比没有证书更危险，因为它会关闭几何安全回退；因此 E88（幻觉检测）与 E91（独立性审计）必须是红线，独立性不达标即把 VQA 降级为「仅建议」，由几何证书 + SafeStop 兜底。

# 第 43 轮产物 · 创新点清单 v20：Interrogative-Cert VLA（SCI × VPA × SGCF）× 语义-几何双层证书（四层架构 v8）

> 承接第 42 轮产物 v19。本轮**增量插入** IP-57/58/59，并升级 IP-54/55/56/51/52/53/50/47/45；不推倒任何既有层级。核心是把 v19 的「仿真验证→知识沉淀→边缘低成本→持续进化」从**纯几何/动力学证书**扩展为**语义规格证书 × 几何安全证书**的双层体系：VLA 只提议，VQA 审讯签发语义证书，二者在 CAR 转移边上保守合取。

### IP-57 SCI：问题格构造与语义证书签发
```
def build_question_lattice(instruction, scene_graph, car):
    refs   = parse_referring_expressions(instruction, scene_graph)
    q_exist   = [exists(r) for r in refs]                 # 目标存在
    q_unique  = [unique_referent(r) for r in refs]         # 指称唯一（颜色/方位/数量消歧）
    q_attr    = [has_attr(r, a) for r, a in attrs(refs)]   # 属性一致
    q_spatial = [rel(r1, r2, d) for r1, r2, d in relations(instruction)]
    q_afford  = [graspable(r) for r in refs] + [path_clear(r) for r in refs]
    q_safety  = [no_human(workspace), no_fragile(workspace)]
    return Lattice(q_exist + q_unique + q_attr + q_spatial + q_afford + q_safety)

def certify_semantics(I, L, Q_crit, calib, alpha, tau, budget_ms=200):
    C, asked, t0 = {}, [], now()
    for q in schedule_by_value(Q_crit, t0, budget_ms):   # anytime，见下
        Gamma_q = conformal_answer(vqa, q, I, L, calib, alpha)  # split-conformal
        C[q] = Gamma_q; asked.append(q)
        if has_contradiction(C, Q_crit):
            return Cert(m_sem=0.0, status='REJECT', open=contradictions(C))
        if lower_bound(C, Q_crit) >= tau:                 # 已可签发
            break
        if upper_bound(C, Q_crit) < tau:                  # 已可拒绝
            return Cert(m_sem=0.0, status='REJECT', open=open_questions(C))
        if now() - t0 > budget_ms:
            return Cert(m_sem=lower_bound(C, Q_crit), status='TIMEOUT', open=asked)
    # 反事实稳定化：高风险命题做 do(遮挡/移除/替换)，不稳定即降为 open
    C = counterfactual_stabilize(C, I, L, top_k=3)
    status = 'CERT' if lower_bound(C, Q_crit) >= tau else 'OPEN'
    return Cert(m_sem=lower_bound(C, Q_crit), status=status,
                asked=asked, evidence=fingerprint(C))

def schedule_by_value(Q_crit, t0, budget_ms):
    # 价值 = 期望熵减 / (时延 + λ·OOD风险)；贪心 + 预算截断
    while now() - t0 < budget_ms and unasked(Q_crit):
        q = argmax(Q_crit, key=lambda q: EIG(q) / (cost(q) + LAMBDA * ood_risk(q)))
        yield q

def has_contradiction(C, Q):
    # 局部一致性传播：可见 vs 被遮挡、左 vs 右、数量守恒、同义改写一致
    for rule in [MUTEX_VISIBLE_OCCLUDED, MUTEX_LEFT_RIGHT, COUNT_CONSERVATION,
                 PARAPHRASE_AGREEMENT]:
        if violates(C, rule): return True
    return False
```

### IP-58 VPA：双过程提议-审计-重规划
```
def propose_and_audit(I, L, sci, vla, planner, max_replan=2):
    a, rho = vla.propose(I, L)                  # 动作块 + 结构化 rationale
    claims = parse_claims(rho)                  # [{pred, polarity, args}]
    for attempt in range(max_replan + 1):
        Q_act = action_conditioned(claims, a)   # 前提 + 后果命题
        cert  = sci.certify_semantics(I, L, Q_act, tau=TAU[edge(a)])
        U     = audit(claims, cert)             # 未认证/被否证的声明
        if cert.status == 'CERT' and not U:
            return a, cert                      # 语义证书签发
        if cert.status == 'REJECT' or U:
            # 结构化反馈：告诉 VLA「哪个子目标/前提未被认证」
            a2 = vla.replan(I, L, feedback=U)
            if a2 is None:
                a2 = planner.plan_verified(I, L, cert)   # 经典规划在已验证区域内
            if a2 is None:
                return None, cert               # 交回上层降级/SafeStop
            a, claims = a2
    return None, cert                            # 有界重试耗尽 → 弃权

def audit(claims, cert):
    bad = set()
    for c in claims:
        if not cert.certifies(c.pred, c.polarity, margin=TAU):
            bad.add(c)
        if cert.certifies(c.pred, not c.polarity, margin=TAU):
            bad.add(c)                           # 被否证
    return bad

def independence_audit(M_p, M_v, heldout_human):
    # 定义 44：共谋幻觉检测
    rho_err = corr_error_rate(M_p, M_v, heldout_human)
    rho_ind = err_rate(M_p, heldout_human) * err_rate(M_v, heldout_human)
    ok = (rho_err <= rho_ind + DELTA_IND) and \
         (key_prop_error(M_v, heldout_human) <= EPS_V)
    return {'rho_err': rho_err, 'rho_ind': rho_ind, 'independent': ok}
```

### IP-59 SGCF：语义×几何乘积守卫与语境阈值档
```
def fused_guard(e, x, a, cert_geo, cert_sem, theta_profile, tau_e):
    sigma = recognize_context(cert_sem)          # 决定性命题 → 语境标签
    if sigma not in theta_profile.certified_contexts:
        sigma = 'SAFE_DEFAULT'                   # 语境不确定 → 最保守档
    geo_ok = cert_geo.lookup(x).m_lo[e] >= theta_profile.theta[e][sigma]
    sem_ok = cert_sem.m_sem >= tau_e and cert_sem.status == 'CERT'
    itg_ok = cert_sem.audit_ok                   # rationale 审计通过
    return geo_ok and sem_ok and itg_ok, sigma

def build_context_profiles(scv_results):
    # 离线：IP-54 对每个候选语境 σ 重跑语境化压力测试，认证 θ_e(σ)
    profiles = {}
    for sigma in ENUMERATED_CONTEXTS:            # 如 空旷/有人/易碎/低光/拥挤
        stats = scv_results.stress_test(context=sigma)
        profiles[sigma] = {e: stats[e]['margin_p01'] * ALPHA_SAFE for e in EDGES}
    return ContextProfile(profiles, certified_contexts=set(profiles))

def select_mode(cert_sem, cert_geo, independence):
    if not independence['independent']:
        return Mode.SEM_ADVISORY             # 语义仅建议，几何兜底
    if cert_sem.status == 'CERT' and cert_geo.ok:
        return Mode.CERTIFIED
    if cert_sem.status == 'OPEN':
        return Mode.DOWNGRADE               # 降档并请求人类
    return Mode.SAFE_STOP
```

## 6. 本轮最大风险

**一句话**：VLA 与 VQA 很可能共享同一套 VLM 先验，二者幻觉**相关**，验证器会替策略「背书」出一张假证书——而假证书比没有证书更危险，因为它会关闭几何安全回退；因此 E88（幻觉检测）与 E91（独立性审计）必须是红线，独立性不达标即把 VQA 降级为「仅建议」，由几何证书 + SafeStop 兜底。
