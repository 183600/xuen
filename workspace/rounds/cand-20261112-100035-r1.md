# 第 58 轮（承接第 57 轮「少样本元推断×跨模态对账×个性化信任」IP-133~138；灵感循环第 4 轮；本轮灵感：「双臂协作」×「模型量化」）

> 第 57 轮把安全的赌注从"模型置信"换到"证据质量"，再用元先验、跨模态对账、个性化信任把证据质量本身管起来。但它建立在一个从未被检验的前提上：**被组合的证据单元彼此独立，且判定器可以按声明精度运行**。双臂协作与模型量化恰好从两个方向击穿这个前提：**(a)** 两条手臂共享同一基座、同一质心、同一工件——一条臂的接触力会经共享体耦合到另一条臂，"两臂都说安全"很可能只是"同一个身体说了两遍"；但反过来，双臂闭合又是单臂拿不到的**真实力学约束**（闭合把欠约束位姿变成过约束），耦合既可能是共模失效，也可能是新证据源，区别只在于是否显式建模；**(b)** 边缘部署必须量化神经网络，第 57 轮的摊销后验 q_φ、OOD 门、风险头都要被压到 INT8/INT4——而量化误差不是零均值噪声，它是**输入相关的确定性偏差**：同一个输入每次错得一模一样，重复探针、多次推理、两个量化副本的"一致"都不是独立证据，反而会伪造一致性；量化还会让 ECE 与 OOD 检出率在特定输入区域悄悄塌陷。本轮把"独立"从默认假设降级为**需要证书的属性**（共模证据账本 CAEL），把"精度"从实现细节升级为**需要证书的安全参数**（量化判定器证书 QAC），并新增一个只有双臂才有的正收益证据类（双臂闭合 EV-biclosure）。核心命题由"少样本可校准、跨模态可对账、个性化有界的证据承诺"升级为 **"共模可追溯、耦合可建模、精度可认证的联合承诺"**。

核心矛盾：
- **H29（双臂耦合 vs 独立佐证）**：两臂经共享基座/质心/工件耦合，把两次接触当两票独立佐证是重复计数；但若把耦合一律当噪声，就丢掉了闭合约束这一单臂不存在的真实证据。耦合必须显式建模，且"耦合"既有害（共模失效）又有利（闭合观测）。
- **H30（量化误差 vs 校准）**：量化偏差是输入相关、确定性的，不会在重复观测中平均掉；它同时改变 ECE 与 OOD 分数——一个被量化破坏的 OOD 门会把分布外输入判成高置信分布内，而"两个量化副本都这么说"只是同一舍入网格的自我确认。
- **H31（联合承诺 vs 责任与释放）**：双臂承诺是联合的，不是逐臂的；一条臂承诺时另一条臂可能是其支撑，也可能是其扰动源；支撑（brace）本身是一种带持续时间的承诺，必须可界定地释放，单臂故障时另一臂要有 hold-or-retreat 安全态；人的同意也必须针对联合动作而非单臂。

## 0. 直觉与动机

**灵感 1（双臂协作 → 共享体耦合模型 + 闭合即证据）**
直觉：把双臂想成"两个绑在同一张桌子上的探针"。左臂按下去，桌子会晃，右臂的接触点跟着动——这就是耦合增益 Γ；如果只按单臂模型算安全，右臂的余量可能是虚的。但换一个角度：当两臂夹住同一块工件，工件位姿从"单接触的欠约束"变成"双接触的过约束"，多出来的约束不是冗余，而是真实的观测信息。于是双臂协作给两样东西：**一个必须建模的共模通道**（共享体），**一个可以主动争取的新证据类**（闭合）。关键设计：耦合模型必须带误差界 ‖Γ−Γ̂‖≤ε_Γ，闭合证据必须验证"秩增益≥1 且内力维持"，否则退回鲁棒最坏耦合与普通单臂证据。

**灵感 2（模型量化 → 判定器误差包络 + 量化感知共形）**
直觉：量化不是"给模型加一点随机噪声"，更像"把尺子的刻度整体挪了半格"——同一把尺子量十次，结果一样地偏。所以第 57 轮"N 次一致即更强证据"在量化面前直接失效：量化模型的确定性偏差会伪装成稳定一致。正确做法是给每个量化判定器发证书：用了多少 bit、校准集上 ECE 偏移多少、对每个输入的输出误差包络 ε_q(x) 多大、OOD 分数退化多少；共形带用**量化模型实际输出**的残差来构造，于是量化误差被显式并进带宽，而不是被忽略。安全关键的三个头（证据门、风险头、OOD 门）设最低精度地板，宁可多算几 bit，也不让"判决器"本身被压坏。

**灵感 3（两灵感合流 → 伪独立性是共同敌人）**
直觉：双臂的"同一个身体"和量化的"同一个舍入网格"是同一类东西——**共模失效通道**。第 57 轮用条件独立把跨模态一致变成证据，本轮把这个逻辑一般化：每条证据标注它依赖的共享资源（共享基座/工件/语料/量化网格/传感器/操作者），只有失败通道不相交的证据才允许互相佐证，同一通道的重复观测一律去重为一条。这样，"两臂一致"、"两次推理一致"、"两个量化副本一致"都被正确地降级为"同一票"，而真正的双臂闭合、真正独立的跨模态一致仍然被承认。

**灵感 4（合流 → 证据门与联合证书）**
直觉：第 57 轮证据门五类（EV-probe*/visit/margin/xmodal/human）在本轮获得两个维度：所有证据先过 **CAEL 去重**（共模键），EV-biclosure 作为新类进入 L1 佐证/L2 前置稳定证据但禁止与单臂证据独立相加；所有由量化模型产生的证据必须挂 **QAC 证书**，否则视同未校准证据。击穿联合安全需要：共模键漏声明 ∧ 耦合模型失配未检出 ∧ 量化证书失效 ∧ 闭合秩增益误报 ∧ 无裕度 ∧ 人也错——纵深从五层到七层。

**灵感 5（PCE-BI → 承诺、支撑、释放成为联合算子）**
直觉：单臂的"承诺"升级为联合承诺（joint commit），新增支撑原语 brace 与有界释放 release：支撑把两臂变成"一个更稳的系统"，但它也是一种随时间持续的承诺，必须能界定地撤回。联合算子在每个检查点先做联合推断与耦合对账，再决定"用哪只臂探、用哪只臂撑、是否值得闭合、闭合后能否安全释放"。所有新机制仍只经两个安全通道起作用：**信念更准（含强制加宽/去重）** 或 **动作更保守（更宽共形带、更低步态、更强佐证、更慢释放）**。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（双臂耦合体 BCM）** 直觉：双臂不是两个独立机器人，而是长在同一基座上的两个探针。联合状态 x_bi=(x_L,x_R,q_b,G)，q_b=(COM,支撑多边形,基座位姿)，G 为共享工件模型。单臂动作 u_L 经共享体在另一臂接触点诱导扰动 Δp_R=Γ_{L→R}(q_b,G)u_L，Γ∈R^{6×6} 一般非对角。耦合模型 Γ̂ 须声明界 ‖Γ−Γ̂‖≤ε_Γ，否则采用鲁棒最坏耦合 Γ_worst=argmax_{‖Γ−Γ̂‖≤ε_Γ}R_bi。联合可行域 F_bi(q_b,G)={Σf+mg=0, Στ=0, COM 投影∈supp(q_b), 内力 f_int∈[f_min,f_max]∩FC(μ), 无自碰撞, 关节力矩余量≥0}。联合风险 R_bi=max_{联合时序}(耦合动力学下的 P_fail)，**明确不等于** Σ_arm R_arm。

**定义 140（共模证据账本 CAEL）** 直觉：佐证像投票，但同一个利益集团的票只能算一票。每条证据 e 带共模键 κ(e)⊆𝒦，𝒦={body,base,object,corpus,quant_grid,sensor,operator,…}。机制独立 indep(e_i,e_j) ⇔ κ(e_i)∩κ(e_j)=∅ ∧ 声明独立。佐证计数 corrob(S)=|S/∼_κ|（按共模键去重，同一键簇只计一条）；P(fail|S) 对每个最大共模集 MCM 只取最坏单点，**不做独立相乘**。CAEL 是 A38 条件独立的推广："独立"从默认假设变为需证书的属性；量化模型、双臂、云端元模型共享的网格/语料/体一律入键。

**定义 141（双臂闭合证据 BCE）** 直觉：闭合不是"两票"，而是"换了一个约束更强的观测模型"。双接触 i,j 在 G 下的可观测矩阵 O_{ij}，闭合秩增益 ρ_cl=rank(O_{ij})−max(rank(O_i),rank(O_j))。EV-biclosure ⇔ 耦合模型已校验(‖Γ−Γ̂‖≤ε_Γ) ∧ ρ_cl≥1 ∧ 内力 f_int∈FC ∧ 保持时长≥τ_hold ∧ CAEL 判定双接触共享 body 键故不与单臂证据独立相加。EV-biclosure 可作为 L1 佐证与 L2 前置稳定证据（夹持后操作），但不得替代不可逆接触的 EV-probe；秩增益与内力须事后复核，误报即回溯降权。

**定义 142（量化判定器证书 QAC）** 直觉：量化像挪了刻度的尺子，量得越多不会越准。量化判定器 f_b（b bit）证书 Q=(b,scheme,ΔECE_b,ε_q(x),δ_ood^b,det=True,cal_ver)。误差包络 |f_b(x)−f(x)|≤ε_q(x)，须同时覆盖校准集与 OOD 集。量化感知共形：C_cf^b 用 f_b 的**实际**残差集构造，且 |C_cf^b|≥|C_cf|+2ε_q(x)，覆盖 ≥1−α_conf。OOD 门须单独通过 δ_ood^b≤δ_ood 复核，否则 OOD 门保持高精度。安全关键模块精度地板 b≥b_min^dec（证据门/风险头/OOD 门）。关键：det=True 意味着同输入同错，量化副本/重复推理不产生独立样本，统一记 shared_quant_grid 键。

**定义 143（安全感知精度分配 SAPA）** 直觉：精度预算是把钱花在刀刃上，判决器不能省。预算 B（bit·MAC 或能耗），模块 m∈M，精度 b_m∈B_m：max_b Σ_m U_m(b_m) s.t. Σ_m cost_m(b_m)≤B ∧ P_safe(b)≥1−δ_deploy ∧ b_m≥b_min(m)（安全关键）。对安全关键模块降精度只允许"更保守"映射（共形带更宽、步态更低、佐证更多），**禁止"降精度→更快承诺"**。当 OOD 注册表变化/分布漂移，必须重新认证，否则整体回退到高精度基线。

**定义 144（联合承诺算子 PCE-BI）** 直觉：承诺从单臂升级为"承诺+支撑+释放"的联合动作。每检查点：①联合推断（量化 q_φ + QAC；ID→摊销后验，OOD→量化感知共形带）；②耦合对账（校验 Γ̂；CAEL 去重；判定是否可形成 EV-biclosure）；③联合可行性 F_bi；④联合承诺 ⇔ ∃g_bi: R_bi≤δ_f(g_bi) ∧ 证据门过（CAEL 独立计数） ∧ 耦合证书有效；否则按联合 VOI 选"换臂/换夹持/探询/绕行/降档"，或 L2 联合协商。支撑原语 brace(L,R,τ_hold) 承诺维持内力≥τ_hold，释放有界 τ_release；单臂故障触发 hold-or-retreat。联合同意以动作区间为单位，授权沿 PTM 单向有界。

## 2. 关键算法伪代码（完整版见产物区）

```python
def qac_conformal(q_model, cal_obs, alpha_conf, eps_q):   # IP-142
    res = [abs(q_model.f(x) - y) for x, y in cal_obs]     # 用真实量化模型
    C = conformal(res, alpha_conf)
    return widen(C, lambda x: 2 * eps_q(x))               # 量化误差并入带宽

def cael_add(ledger, e):                                  # IP-140
    for f in ledger:
        if kappa(e) & kappa(f):                           # 共享失效通道
            f.obs += 1; e.redundant = True; break         # 去重，不加票
    ledger.append(e); return ledger

def bimanual_closure(cL, cR, G, Gamma, f_int):            # IP-141
    return (norm(Gamma_err(Gamma)) <= eps_Gamma and
            rank_gain(cL, cR, G) >= 1 and
            f_int in friction_cone(G, mu) and
            hold_time >= tau_hold and
            not double_counts(cL, cR))                    # 共享 body 键

def pce_bi(x_bi, M, task, budget, consent, personas, qac):
    route = plan_joint_on_map(M, task, risk_model)
    sched, ledger = [], []
    for cp in route.checkpoints:
        inf = meta_q.q_phi(obs, z=ctx) if meta_q.ood(obs) <= theta_ood \
              and qac.ood_ok else qac_conformal(qac, meta_q.cal, alpha_conf)
        sigma, brace = select_joint_foothold_brace(x_bi, cp, M)
        R = joint_risk(sigma, brace, M)                   # R_bi，非逐臂相加
        while select_gait(R) == 'halt' and budget.probes_left > 0:
            p = argmax(admissible_joint_probes(cp, M),
                       key=lambda q: voi_joint(q, M, inf) - cost(q))
            if voi_joint(p, M, inf) < theta_voi: break
            ledger = cael_add(ledger, execute_joint_probe(p, cap=F_abs))
            sigma, brace = reselect_joint_footholds(x_bi, cp, M)
            R = joint_risk(sigma, brace, M); budget.spend(p)
        ok = (select_gait(R) != 'halt' and coupling_cert_ok() and
              joint_evidence(x_bi, [e for e in ledger if not e.redundant], qac))
        if ok:
            sched.append(commit_joint(sigma, brace, g=select_gait(R))); continue
        alt = reroute_joint(M, cp, risk_model)
        if alt and select_gait(joint_risk(alt, M)) != 'halt': route = alt; continue
        return negotiate_or_stop_joint(cp, x_bi, sigma, brace, consent,
                                       tau_int=tau_int(personas.active.auth))
    return sched, ledger, M
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| BCM | O(d_bi) 每联合时序评估 | O(\|𝒦\|·L) | Γ 误差界声明、F_bi 全检、R_bi 非加和 |
| CAEL | O(k²) 去重/检查点 | O(\|evidence\|) | κ 完整、共享键保守合并 |
| BCE | O(d³) 秩计算/候选对 | O(\|C_L\|·\|C_R\|) | ρ_cl≥1、内力维持、事后复核 |
| QAC | O(N_cal·d_φ) 认证；O(d_φ) 推理 | O(\|Q\|) | 误差包络诚实、覆盖≥1−α、OOD 单独复核 |
| SAPA | O(\|M\|·\|B\|) 离线分配 | O(\|M\|) | 精度地板、P_safe 约束、漂移复认 |
| PCE-BI | O(\|CP\|·(k_p)·(C_VOI+d_φ)+\|CP\|·A_bi) | O(\|V\|+\|σ\|+\|ledger\|) | 联合 VOI、k_p 终止、brace/release 有界 |

**正确性定理（Coupled-Body Quantized Soundness, CBQS 概要）**：在 A33–A40 上加 (A41) 耦合模型误差有界 ‖Γ−Γ̂‖≤ε_Γ，否则用 Γ_worst；(A42) 共模键完整诚实、机制独立是证书而非假设；(A43) QAC 声明诚实（|f_b−f|≤ε_q(x)、ΔECE_b、δ_ood^b），量化感知共形覆盖≥1−α_conf，决策头 b≥b_min；(A44) SAPA 不降低安全关键精度地板，漂移必复认或回退。则：

(i) **联合承诺健全性**：P(fail) ≤ δ_f+ε_meta+δ_probe+ε_h+δ_ood·α_conf+ε_Γ·L_Γ+ε_q+δ_bc·1[biclosure]，其中 L_Γ 为耦合放大因子；共享通道只取最坏单点，故该界不会因伪独立而低估。
(ii) **去重正确性**：若 κ 完整，则 CAEL 后 corrob(S) 不超过真实机制独立证据数；任何共享通道的重复观测不增加有效佐证，P_fail 估计保持保守。
(iii) **精度-安全单调性**：降低任一安全关键模块精度只能使动作更保守（带更宽/步态更低/佐证更多/释放更慢），不存在"降精度→更快承诺"路径。
(iv) **闭合健全性**：EV-biclosure 仅在 ρ_cl≥1 ∧ f_int∈FC ∧ Γ 校验通过时计数，误报经事后复核回溯降权，贡献≤δ_bc。
(v) **终止性**：每检查点探询≤k_p，PCE-BI 在有限步内终止于 {联合承诺, 换臂/换夹持, 绕行, L2 联合协商, 安全停}。

def joint_feasible(x_bi, G, mu, eps_Gamma):
    q_b = x_bi.q_b
    force_bal  = (sum_contacts(x_bi) + m * g == 0)
    torque_bal = (sum_torques(x_bi) == 0)
    com_ok     = in_support_polygon(q_b.COM, q_b.support)
    f_int_ok   = x_bi.f_int in friction_cone(G, mu)
    no_self    = not self_collision(x_bi.xL, x_bi.xR)
    margin_ok  = all(tau_remain(j) >= 0 for j in joints(x_bi))
    return force_bal and torque_bal and com_ok and f_int_ok \
           and no_self and margin_ok

def joint_risk(sigma, brace, M, Gamma_hat, eps_Gamma):
    if norm(Gamma_err(Gamma_hat)) > eps_Gamma:
        G_use = Gamma_worst(Gamma_hat, eps_Gamma)    # 鲁棒最坏耦合
    else:
        G_use = Gamma_hat
    # 用耦合动力学评估，禁止把单臂风险相加
    return max(risk_coupled(g, brace, M, G_use) for g in sigma)

### IP-140 CAEL（共模证据账本：去重而非加票）

```python
def cael_add(ledger, e):
    e.redundant = False
    for f in ledger:
        if kappa(e) & kappa(f):                       # 共享失效通道
            f.obs += 1
            e.redundant = True                        # 同通道重复 = 同一票
            break
    ledger.append(e)
    return ledger

def cael_corroborate(ledger):
    groups, seen = {}, set()
    for e in ledger:
        if e.redundant: continue
        key = frozenset(kappa(e))
        if key in seen: continue
        seen.add(key); groups[key] = e
    return len(groups)                                # 机制独立票数

def cael_risk_bound(ledger, base_pfail):
    pf = base_pfail
    for key in maximal_common_mode_sets(ledger):      # 每个共模簇取最坏
        pf = max(pf, max(pfail(e) for e in clump(key)))
    return pf                                         # 不做独立相乘
```

def certify_quantized(f_b, f_fp, cal_obs, ood_obs, alpha_conf):
    eps_q = fit_envelope(f_b, f_fp, cal_obs + ood_obs)   # 输入相关误差包络
    res_q = [abs(f_b(x) - y) for x, y in cal_obs]        # 用实际量化模型残差

    d_ece = ece(f_b.predict_proba, cal_obs) - ece(f_fp.predict_proba, cal_obs)

def qac_conformal(qac, x, alpha_conf):

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| BCM | O(d_bi) 每联合时序评估 | O(\|𝒦\|·L) | Γ 误差界、F_bi 全检、R_bi 非加和（A41） |
| CAEL | O(k²)/检查点去重 | O(\|evidence\|) | κ 完整、共享键保守、独立需证书（A42） |
| BCE | O(d³) 秩计算/候选对 | O(\|C_L\|·\|C_R\|) | ρ_cl≥1、内力维持、事后复核 |
| QAC | O(N_cal·d_φ) 认证；O(d_φ) 推理 | O(\|Q\|) | 误差包络诚实、覆盖≥1−α、OOD 单独复核（A43） |
| SAPA | O(\|M\|·\|B\|) 离线 | O(\|M\|) | 精度地板、P_safe 约束、漂移复认（A44） |
| PCE-BI | O(\|CP\|·k_p·(C_VOI+d_φ)+\|CP\|·A_bi) | O(\|V\|+\|σ\|+\|ledger\|) | 联合 VOI、k_p 终止、brace/release 有界 |

**正确性定理（Coupled-Body Quantized Soundness, CBQS）**
假设 A22–A32（第 53–55 轮）、A33–A36（第 56 轮）、A37–A40（第 57 轮）成立；**(A41)** 耦合模型误差有界 ‖Γ−Γ̂‖≤ε_Γ，否则用 Γ_worst；联合动力学模型误差有界。**(A42)** 共模键完整诚实：无未声明的共享通道，"机制独立"是证书而非默认假设。**(A43)** QAC 证书诚实：|f_b−f|≤ε_q(x) 覆盖校准与 OOD 集，ΔECE_b、δ_ood^b 声明，量化感知共形覆盖 ≥1−α_conf，决策头 b≥b_min^dec。**(A44)** SAPA 不降低安全关键模块精度地板，分布漂移必复认或回退高精度。则：

1. **联合承诺健全性**：P(fail) ≤ δ_f + ε_meta(k) + δ_probe + ε_h(w_max) + δ_ood·α_conf + ε_Γ·L_Γ + ε_q(x) + δ_bc·1[biclosure]，其中 L_Γ 为耦合放大因子；共享通道只取最坏单点，故该界不因伪独立而低估。
2. **去重正确性（保守性）**：若 κ 完整，则 CAEL 后有效佐证数不超过真实机制独立证据数；因此 P_fail 估计不会低于真实风险，重复观测/量化副本/同体双接触不会制造"证据通胀"。
3. **闭合健全性**：EV-biclosure 仅在 ρ_cl≥1 ∧ f_int∈FC ∧ ‖Γ−Γ̂‖≤ε_Γ 时被计数；误报经事后复核回溯降权，其贡献 ≤δ_bc。
4. **精度-安全单调性**：SAPA 对安全关键模块的任意降精度只映射到更保守的动作参数（共形带更宽、步态更低、佐证更多、释放更慢），不存在"降精度→更快承诺"路径。
5. **终止性**：每检查点联合探询 ≤k_p，PCE-BI 在有限步内终止于 {联合承诺, 换臂/换夹持, 绕行, L2 联合协商, 安全停}。
6. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp [ δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf
                   + ε_Γ·L_Γ + ε_q + δ_bc·1[biclosure] ]
             − P(κ 漏声明) − P(Γ 失配未检出)
             − P(QAC 失效/漂移未复认) − P(𝓜 陈旧未检出)
             − P(护盾回退失败)
```

关键：**耦合既有害也有利**——同一套 Γ 既用于识别"两臂只是同一票"的共模失效，也用于兑现"闭合把欠约束变过约束"的新证据；**量化误差被并入共形带宽而不是被忽略**，安全关键判决器设精度地板；**"独立"与"精度"都从默认假设升级为需审计的证书**；所有新机制仍只经"信念更准（含加宽/去重）"或"动作更保守"两个安全通道起作用。

## 6. 本轮最大风险

**一句话**：本轮最大风险是"共模通道漏声明"——双臂共享基座与工件、量化模型与地图共享语料和舍入网格，系统会误以为自己握有多路独立证据，实则押在同一个失效源上，而闭合证据与量化确定性会让这个错误看起来高度自洽；必须以显式 κ 账本、Γ 误差界与 QAC 精度地板三重证书把关，宁可承认只有一票，也不把同一票数成三票。
