# 第 66 轮（承接第 65 轮「VISTA 视觉知情安全时序归因」IP-214~223；灵感循环第 3 轮；本轮灵感：「人机交互」×「模仿学习」）

> 第 65 轮把「几何可证伪」升级为「故障可归因」，其最大风险是**闭世界假设**：故障必须落在有限假设集 ℋ 内，且视觉与几何的失效相互独立；真实故障常是未知类型的组合，透明/镜面/对抗 patch 会让视觉与几何共享同一个分布外失效源，此时 FIR 会把未知复合故障强行归入最近假设、只膨胀错误的球，系统还会因为「已经归因」而更自信地继续执行。本轮不继续增加传感器，而是换一个提问方式：第 65 轮问「**谁坏了**」，MENTOR 问「**这个故障在我们的假设库里吗？不在的话，人能不能用一个动作把它变成可检验的证据？人给的动作安全吗？如果人要接管，来得及吗？**」
>
> 本轮核心命题：
>
> **把「故障可归因」升级为「故障可学习、可质询、可接管」：用模仿学习把人类示范/纠正变成开世界的故障证据与行为先验，用人机交互把被动归因变成有注意力预算的主动提问与安全接管，并把人本身作为可能出错的证据源与共同原因写进假设集和证书。**

## 0. 直觉与动机

**灵感 1（模仿学习 → 示范不只是策略，也是世界模型的「反事实探针」）**
直觉：第 65 轮的故障证据全部来自机器人自己的传感器，所有证据都被同一个潜在原因（比如透明物体、反光、遮挡）污染。人类示范提供了一条**不同动作轨迹下的结果**：同一状态 s，人做 a_H，机器人做 a_R，两者结果不同。若世界模型能很好解释人类的 a_H 却解释不了机器人的 a_R，问题更可能在策略（机器人选了模型支持域外的动作）；若两者都解释不了，问题更可能在模型。**示范的价值不止「教动作」，还在于它是对世界模型的一次 off-policy 反事实检验。**

**灵感 2（人机交互 → 归因可以主动提问，但人的注意力是稀缺且有代价的）**
直觉：第 65 轮的 AFA 只会做物理探针，探针可能压坏物体；而人是一个可以「问」的证据源。但人不是免费 oracle：会延迟、会疲劳、会误解、会被同一个透明物体骗、甚至会给错指令。因此 HRI 的正确问题不是「要不要信人」，而是「**在什么时刻、问什么、以什么形式问、问完如何验证**」。把提问本身当作一个有成本、有风险、可被拒绝的动作，纳入信息增益与安全约束。

**灵感 3（人机交互 → 人类接管必须进入安全前缀的时间预算）**
直觉：如果安全论证依赖「出事后人接管」，那么 k\* 不能只看不可逆视界 m，还要看人的反应时间 τ_H。若 k\*·Δt > τ_H，人根本来不及接管，证书就是假的。**把人因反应时间写进 CSC 的约束，是 HRI 对安全证书最硬核的贡献，而不是 UI 层的装饰。**

**灵感 4（模仿学习 → 开世界故障假设由人类纠正驱动）**
直觉：第 65 轮的 ℋ 是离线固定的。模仿学习中的纠正数据（DAgger 式 on-policy 纠正）恰好会不断产生「现有假设解释不了的残差」。把人类纠正后的反事实残差做聚类/非参数贝叶斯，新增 H_new；在未验证前，系统必须输出 `novel` 而不是强行归到最近假设。**人类不是标签机，而是新故障类的提案者；提案必须经过安全验证才能进入假设库。**

**灵感 5（三灵感合流 → MENTOR：Mixed-initiative Evidence from Novel-fault Teaching, Oversight and Repair，混合主动的故障教学-监督-修复闭环）**
闭环：模仿行为先验（IBP）→ 人类纠正作为干预证据（ICE）→ 共享潜在原因 + 人类可错性的归因（FIA-cf）→ 新故障发现（NHD）→ 混合主动提问（MIQ）→ 人类指令安全盾与权限仲裁（HSC）→ 共因感知的联合球（RSC-M/WCV-M）→ 带接管视界的前缀（CSC-M）→ 示范驱动技能库（CSP-M/ISL）→ 人类/时序/共因对抗认证（AIC-M）→ J_mentor。第 65 轮是「几何-技能-干扰-接触-归因」五层，MENTOR 把「归因」这一层再拆成「**已知故障 / 未知故障 / 共因故障 / 人类自身故障**」四类，并让每一类都对应一种可交互的处置。

**灵感 6（VISTA 组件的原位升级）**
- **FIR → FIA-cf**：加 H_human、H_novel、共享潜在原因 L；不再假设视觉/几何独立。
- **AFA → MIQ**：探针集增 ask_label/ask_demo/ask_preference/ask_takeover；目标从互信息改为「单位人类注意力与风险下的信息增益」。
- **APP/VSP → HSC**：人类指令先过安全盾；机器人可拒绝不安全的人类指令并解释。
- **RSC-V → RSC-M**：共因时膨胀联合球而不是单个球；维护人类信任权重 w_H。
- **CSC → CSC-M**：k\* ≤ min(m, τ_H/Δt)（若安全论证依赖人类接管）。
- **CSP-V → CSP-M/ISL**：示范生成技能与前置条件；规划可插入 ask 元动作。
- **OLP → OLP-M**：人类数据只进语义流，做 off-policy 校正与可靠性重估。
- **AIC-V → AIC-M**：干扰集增人类延迟/不一致/恶意/被同一共因欺骗。
- **J_vista → J_mentor**：证书增 hypothesis_version、novelty_mass、co_cause_score、human_reliability、intervention_hash、query_budget、takeover_margin、authority_log。

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（MENTOR 闭环）**：MENTOR = (VISTA, ICE, IBP, NHD, MIQ, HSC, FIA-cf, RSC-M/WCV-M, CSC-M, CSP-M/ISL, AIC-M, J_mentor)。定位：VISTA 的「开世界故障学习 + 人机共享权限」升级。不变式：**人类示范/纠正、故障假设发现、可靠性估计、证书更新只在语义流；实时流只做安全盾、接管检测、阶段化残差采集与前缀执行，零学习写操作。**
- **定义 234（人类纠正作为干预与反事实残差）**：示范数据 D_H={(s_i,a_i^H,y_{i+1},c_i)}，把示范视为对动作的干预 do(A=a^H)，定义 r_cf(s,a)=y_{next}−ĝ(s,a) 与 Δ_cf(s)=r_cf(s,a_R)−r_cf(s,a_H)。a_H 在模型支持域内且 Δ_cf 显著 → 倾向 H_policy；r_cf(s,a_H) 也大 → 倾向 H_model。人类示范只提供「另一动作下的结果证据」，不是物理真值。
- **定义 235（交互式模仿协议）**：DAgger 式 on-policy 纠正；人类有延迟 τ_H、可用性 A_H(t)、注意力预算 B_H、可靠性 β_H。协议目标从「最大化模仿精度」改为「最大化故障可辨识性 + 任务收益 − 人类成本」，并记录纠正率、纠正幅度、纠正一致性。
- **定义 236（模仿行为先验与对应映射）**：学习 π_H(a|ψ(s))，ψ 为体现无关/任务空间对应映射（末端位姿、物体相对位姿、接触模式、力上限），吸收 embodiment gap。行为偏离 d_H(s)=D(π_R(·|s),π_H(·|ψ(s))) 只作 H_policy/H_model 证据；π_H 同时为 φ、f_safe 提供先验。
- **定义 237（开世界故障假设过程）**：假设库 ℋ_t 随时间增长；用 Dirichlet process mixture 给签名密度 p(ρ)=Σ_k π_k p_k(ρ)+π_new p_0(ρ)，π_new=γp_0(ρ)/(γp_0(ρ)+Σ_k n_k p_k(ρ))。若 novelty(ρ)=π_new>δ_nov，输出 `novel`，不强行归因；新残差经独立验证与安全盾验证后才加入 ℋ_{t+1}。novelty_mass γ 与假设库版本写入证书。
- **定义 238（共享潜在原因模型）**：引入潜在上下文 L（材质、透明度、光照、遮挡、人类知识状态），联合似然 p(ρ,y_vis,c|F,L)，不假设 p(ρ|F)p(y_vis|F)。归因时对 L 边缘化；若 co_cause_score=P(L≠∅|E)>δ_cc，标记 `co_cause_suspected`，不输出单一模块归因，转而膨胀联合球。
- **定义 239（人类可错性模型）**：可靠性 β(c|F,L,q)=P(c 正确|F,L,q)，依赖查询类型 q、可用性、延迟、专业度、以及人是否与机器人共享同一感知盲区。假设集增 H_human={misperception, delay, inconsistency, adversarial}；人类证据按 β 加权，与机器人共享共因 L 时不得视为独立。human_trust w_H=f(β,corr(c,L),历史一致性)。
- **定义 240（反事实干预归因 FIA-cf）**：在匹配上下文 (s,L) 下比较 do(A=a_H) 与 a_R 的残差表：机器人残差大、人类残差小 → H_policy；两者都大 → H_model；机器人小、人类大 → H_human 或支持域外；两者都小但结果不安全 → H_force/H_geo。可辨识条件：a_H 与 a_R 在模型支持域内有重叠、且至少一个上下文 L 被固定/匹配；否则只能输出 ambiguous。定义干预辨识矩阵 S_cf 与 κ_cf。
- **定义 241（混合主动查询策略 MIQ）**：q∈{none,label,demo,preference,takeover,explanation}，选择 q\*=argmax_q [I(F,L;Z_q|E)−λ_c cost_H(q)−λ_t τ_H(q)−λ_r risk(q)]，s.t. q 可理解/可执行、预测物理风险≤ε_q、人类注意力预算未耗尽。若最大净值<δ_q，不提问，走安全回退。查询必须可读：用任务空间语言解释为何问、问什么、期望得到什么。
- **定义 242（人类指令安全盾与权限仲裁 HSC）**：a_H 先经安全盾 a_H^safe=argmin_{a∈A_safe}‖a−a_H‖；若 ‖a_H−a_H^safe‖>τ_shield 或预测越界，拒绝执行并返回解释与安全替代。人类可随时 veto/e-stop，但不可覆盖物理安全约束。权限状态 Auth∈{autonomous,shared,human_override,safe_idle}，切换必须通过 J_mentor 有效性检查。
- **定义 243（共因感知 RSC-M / WCV-M）**：维护 r_geo,r_force,r_model,r_vis,r_H 与共因半径 r_cc。若 co_cause_suspected，r=√(r_geo²+r_force²+r_model²+r_vis²+r_cc²) 且不允许只膨胀单个球；否则按归因定向膨胀。WCV-M 搜索域增人类意图约束 ℐ(a_H) 与行为支撑约束 ℬ(π_H)；归因模糊时按 P(F,L) 加权做边缘化尾部；交集为空则回退保守联合球并置 `attribution_conflict=True`。
- **定义 244（带接管视界的认证前缀 CSC-M）**：对块 A_t、前缀 k、后验与人类可用性 A_H，验证 ∀F∈supp_δ,∀s≤k: ρ_safe(s)≥0，且若 Auth∈{shared,human_override}，则 k·Δt≤τ_H^cert（τ_H 的 1−α_H 分位）；若人类不可用或 τ_H 不可信，则必须 k·Δt≤m 且自主安全成立。输出 k\* 与 takeover_margin；块内越界概率 ≤ α_chunk+δ_fi+α_vis+α_H。
- **定义 245（示范驱动技能库 CSP-M / ISL）**：从人类示范抽取技能 σ=(pre,post,π_σ,chunk_sig,f_lim,aff_prior)，其中 pre/post 为符号前置/效果，chunk_sig 为块签名分布，f_lim 为示范中观察到的力上限，aff_prior 为可供性先验。只有通过安全验证与回放一致的技能才入 CSP 图；规划边可含 ask 元动作，其代价含人类注意力与延迟；实际块签名与 𝒟_σ 的 Mahalanobis 距离>τ_chunk 判 OOD 并触发 MIQ。
- **定义 246（AIC-M 人类/时序/共因对抗认证）**：干扰集 ℰ_M=ℰ_V×ℰ_H×ℰ_cc，ℰ_H 含人类延迟、疲劳、不一致、恶意指令、错误示范、共享感知盲区；ℰ_cc 含同一材质/对抗 patch 同时骗过几何、视觉与人类。ρ_dir 在 ℰ_M 上重算（n_cert 128→160，其中 32 给人类/共因），ρ_force 在最坏人类指令与最坏共因下取最坏；J_dir 增 human_model_ver、intervention_log_ver、co_cause_ver。共因下不要求归因正确，只要求判 `co_cause_suspected` 并安全降级/请求人类帮助。
- **定义 247（MENTOR 证书 J_mentor）**：J_mentor=(J_vista,h_ver,novelty_mass,co_cause_score,human_reliability,intervention_hash,query_budget_used,takeover_margin,authority_log,explanation_hash)。Valid ⇔ Valid(J_vista) ∧ (归因确定 ∨ novel 已标记 ∨ co_cause 已标记 ∨ 已执行 MIQ) ∧ 人类指令经 HSC 验证 ∧ k\* 满足 CSC-M ∧ 人类可靠性/共因状态已记录 ∧ 解释与权限切换可审计。

if nov > delta_nov:
    state = "novel"; ask_or_safe_idle()
else:

        if q is None:
            state = "ambiguous"; safe_idle_or_conservative()

            execute_query(q)                 # label/demo/preference/takeover

# CSC-M：安全前缀同时受不可逆视界与人类接管视界约束
A = policy.propose_chunk(obs, H)

for a in A[:k_star]:
    if not hsc.shield(a): break

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（共因下的被动不可辨识与干预可辨识性）**：若 L 同时影响 ρ 与 y_vis，被动 Fisher 矩阵存在对应「几何 vs 视觉」互换的零方向，单一模块归因不可辨识；一次满足支持域重叠的干预 do(A=a_H) 若其响应在故障对比方向上有非零投影，则新增一行可打破零方向，使 H_model 与 H_policy 可分离，κ_cf>0；否则必须保持 ambiguous。
- **引理 10（新奇度受控的未知故障处理）**：在 Dirichlet process 新奇度阈值 δ_nov 下，novelty>δ_nov 的签名不分配给现有假设；未知故障被强行归入最近已知类的概率 ≤ δ_nov（加上密度估计误差）。这把第 65 轮的闭世界误归因换成开世界的「显式弃权」保证。
- **引理 11（含接管视界的前缀安全）**：若 k\*·Δt≤τ_H^{1−α_H} 且人类反应模型已校准，则不可逆点前未接管的概率 ≤α_H；与 α_chunk、α_vis、δ_fi 联合界得块内越界概率上界。若人类不可用，则必须退回 k\*·Δt≤m 的纯自主安全。
- **定理 9（MENTOR 端到端归因-交互-安全）**：在 A94–A100 下，Valid(J_mentor) ⇒ 故障被正确归因，或显式标记 novel/co_cause/ambiguous 并安全回退；只膨胀正确的球（或共因联合球）；人类指令经安全盾；k\* 同时尊重不可逆视界与接管视界；未知道具不被强行归类；证书包含开世界与人类证据。
- **定理 10（交互式模仿的查询效率与人不确定性折扣）**：主动 MIQ 的期望查询次数为 O((1/κ_cf)log(|ℋ|/ε))，优于被动枚举；但当人类可靠性 β 低或与 L 相关时，有效信息增益按 (1−β) 折扣，最优策略可能转为自主探针或安全回退——**这给出「不能因为有人就过度依赖人」的形式化理由**。

## 5. 本轮最大风险

**一句话**：MENTOR 的安全与归因现在依赖「人类在需要时可用、其干预信息量足够、且人类不与被感知对象共享同一个共因失效」；一旦人掉线、延迟、过度自信或也被透明/对抗物体欺骗，开世界新奇度机制会把「人的错误」当成「新故障」学习，或让系统在等待人类时越过不可逆点——**人机交互由此从安全补丁变成新的单点故障与错误学习源**。

## 2. 形式化定义（完整版）

**定义 233（MENTOR 闭环）** MENTOR 是 VISTA 的「开世界故障学习 + 人机共享权限」升级：在 VISTA 的「语义流 ∘ 实时流」骨架上挂载 ICE（干预证据）、IBP（模仿行为先验）、NHD（新故障发现）、MIQ（混合主动查询）、HSC（人类指令安全盾与权限仲裁）、FIA-cf（反事实故障归因），并原位升级 RSC-V→RSC-M、WCV-V→WCV-M、CSC→CSC-M、CSP-V/TSL→CSP-M/ISL、AIC-V→AIC-M、J_vista→J_mentor。不变式：**人类示范/纠正、故障假设发现、可靠性估计、证书更新只发生在语义流与低频线程；实时路径只做安全盾、接管检测、阶段化残差采集、认证前缀执行与早停，零学习写操作。**

**定义 234（人类纠正作为干预与反事实残差）** 人类示范数据 D_H={(s_i,a_i^H,y_{i+1},c_i)}，其中 c_i 可为语义标签、偏好或接管记录。与被动观测不同，示范被建模为对动作的干预 do(A=a^H)。定义世界模型反事实残差
r_cf(s,a)=y_{next}−ĝ(s,a)，
以及机器人-人类残差差
Δ_cf(s)=r_cf(s,a_R)−r_cf(s,a_H)。
在匹配的 s 与同一潜在上下文 L 下：
- a_H 落在模型支持域内、r_cf(s,a_H) 小、而 r_cf(s,a_R) 大 ⇒ 更支持 H_policy（机器人选了模型不支持的动作）；
- 两者都大 ⇒ 更支持 H_model（世界/接触模型错，与动作选择无关）；
- 机器人小、人类大 ⇒ 更支持 H_human 或人类动作落在支持域外；
- 两者都小但结果不安全 ⇒ 更支持 H_force/H_geo 等传感器/几何故障。
人类示范只提供「在另一动作下的结果证据」，不提供物理真值；Δ_cf 是证据，不是判决。

**定义 235（交互式模仿协议）** 采用 DAgger 式 on-policy 纠正：策略 π_R 执行，得到机器人自身状态分布；人类在部分状态给纠正 a_H；机器人把 (s,a_H) 加入 D_H，并在语义流更新行为先验与故障证据。人类响应有延迟 τ_H、可用性 A_H(t)∈{0,1}、注意力预算 B_H、可靠性 β_H。协议目标不是最大化模仿精度，而是
max E[故障可辨识性 + 任务收益 − λ_c·人类注意力 − λ_t·延迟 − λ_r·风险]。
记录纠正率 c_rate、纠正幅度 ‖a_H−a_R‖、纠正一致性（同一上下文多次纠正的方差）；后三者进入阶段签名。

**定义 236（模仿行为先验与对应映射）** 从 D_H 学习人类策略 π_H(a|ψ(s))，其中 ψ 是体现无关/任务空间对应映射（末端位姿、物体相对位姿、接触模式、力上限、运动基元），用于吸收 embodiment gap。定义行为支撑分数
b_H(s,a)=log π_H(a|ψ(s)) + log p_support(ψ(s))
与行为偏离
d_H(s)=D(π_R(·|s), π_H(·|ψ(s)))。
d_H 只作为 H_policy/H_model 的证据，绝不当作正确动作；π_H 同时为几何先验 φ、安全力上限 f_safe 与可供性提供先验。对高维动作，只用任务空间低维投影，避免把人类的具体运动学差异误判为策略故障。

**定义 237（开世界故障假设过程）** 假设库 ℋ_t 随时间增长，不再固定。对阶段签名 ρ 用 Dirichlet process mixture 建模：
p(ρ)=Σ_{k=1}^{K_t} π_k p_k(ρ) + π_new p_0(ρ)，
π_new=γ p_0(ρ) / (γ p_0(ρ) + Σ_k n_k p_k(ρ))，
其中 n_k 为第 k 个假设的累计证据数，p_0 为基分布（宽尾高斯/归一化流），γ 为 novelty_mass。若 novelty(ρ)=π_new>δ_nov，输出 `novel` 并**不分配给任何现有假设**；人类纠正或安全探针产生的新残差若与现有簇距离>τ_nov，则提案 H_new，经独立验证集与安全盾验证后才加入 ℋ_{t+1}。假设库版本 h_ver 与新假设的证据数写入 J_mentor。

**定义 238（共享潜在原因模型）** 引入潜在上下文 L（材质、透明度、镜面/反光、光照、遮挡、人类知识状态），联合似然
p(ρ, y_vis, c | F, L)，
显式允许 F 与 L 的交互项，**不假设** p(ρ,y_vis|F)=p(ρ|F)p(y_vis|F)。归因时对 L 边缘化：
P(F|E) ∝ Σ_L p(E|F,L)P(F)P(L)。
定义共因分数 co_cause_score=P(L≠∅|E)。若 co_cause_score>δ_cc，标记 `co_cause_suspected`，不输出单一模块归因；RSC-M 转而膨胀联合球，MIQ 可请求人类提供 L 的语义信息（如「这是玻璃」），但人类也可能被骗，故人类证据同样进入 L 的后验而非直接当真值。

**定义 239（人类可错性模型）** 人类证据 c 的可靠性
β(c|F,L,q)=P(c 正确 | F,L,q)，
依赖查询类型 q、人的可用性、延迟、专业度、疲劳度，以及人是否与机器人共享同一感知盲区。假设集增
H_human={misperception（误看/误判）, delay（来不及）, inconsistency（前后矛盾）, adversarial（恶意/被诱导）}。
人类证据进入后验时按 β 加权；若人类与机器人共享共因 L（例如人也在看同一块透明玻璃），其证据不得视为独立通道。定义人类信任
w_H=f(β, corr(c,L), 历史一致性, 当前负载)，
并限制 w_H 的上界，防止「有人在场」被误当成「有了真值」。

**定义 240（反事实干预归因 FIA-cf）** 给定干预 do(A=a_H) 与机器人动作 a_R，在匹配上下文 (s,L) 下比较反事实残差，构造 2×2 残差表：
| | 人类动作残差小 | 人类动作残差大 |
|---|---|---|
| 机器人残差大 | H_policy | H_model |
| 机器人残差小 | H0/传感器故障 | H_human/支持域外 |
可辨识性条件：(i) a_H 与 a_R 在模型支持域内有重叠；(ii) 至少一个上下文 L 被固定或匹配；(iii) 干预响应对故障对比方向有非零投影。定义干预辨识矩阵 S_cf 与 κ_cf=λ_min(S_cfᵀΣ⁻¹S_cf)/λ_max(·)。若 κ_cf 低于阈值，只能输出 ambiguous；此时 MIQ 选择能最大化 κ_cf 的查询，而不是强行归因。

**定义 241（混合主动查询策略 MIQ）** 查询 q∈{none,label,demo,preference,takeover,explanation}。选择
q*=argmax_{q} [ I(F,L; Z_q | E) − λ_c cost_H(q) − λ_t τ_H(q) − λ_r risk(q) ]，
s.t. q 可被当前人类理解/执行、预测物理风险≤ε_q、人类注意力预算 B_H 未耗尽。若最大净值<δ_q，不提问，走安全回退（safe_idle / 保守联合球 / VISTA 自动探针）。查询必须可读：用任务空间语言解释为何问、问什么、期望得到什么；解释本身也计入人类成本。若人类不可用，退化为 VISTA 的自动归因/物理探针，但物理探针仍受易损物体约束。

**定义 242（人类指令安全盾与权限仲裁 HSC）** 人类指令 a_H 先经安全盾：
a_H^safe=argmin_{a∈A_safe} ‖a−a_H‖。
若 ‖a_H−a_H^safe‖>τ_shield 或预测力/滑移/几何越界，则拒绝执行，返回解释与安全替代；人类可随时 veto/e-stop，但不可覆盖物理安全约束。权限状态 Auth∈{autonomous, shared, human_override, safe_idle}；切换必须通过 J_mentor 有效性检查，并记录 authority_log。若安全论证依赖人类接管，则必须同时满足定义 244 的接管视界约束；否则只能声明纯自主安全。

**定义 243（共因感知 RSC-M / WCV-M）** 维护 r_geo（几何先验）、r_force（F/T 标定）、r_model（接触模型）、r_vis（视觉）、r_H（人类证据）与 r_cc（共因）。若 `co_cause_suspected`，融合半径
r=√(r_geo²+r_force²+r_model²+r_vis²+r_cc²)
且**不允许只膨胀单个球**；否则按归因定向膨胀被归因者。WCV-M 搜索域
B(φ̂,r) ∩ 𝒢(g) ∩ K(μ̂) ∩ ℱ(f_lim) ∩ 𝒱 ∩ ℐ(a_H) ∩ ℬ(π_H)，
其中 𝒱 为视觉可观测性、ℐ 为人类意图约束、ℬ 为行为支撑约束。CVaR 尾部 n_worst=8；归因模糊时按 P(F,L) 加权做边缘化尾部；交集为空则回退保守联合球并置 `attribution_conflict=True`。

**定义 244（带接管视界的认证前缀 CSC-M）** 对块 A_t、执行前缀 k、归因后验与人类可用性 A_H，验证：
∀F∈supp_δ(post), ∀s≤k: ρ_safe(s)≥0，
且若 Auth∈{shared, human_override}，要求
k·Δt ≤ τ_H^cert，
其中 τ_H^cert 为人类反应时间分布的 1−α_H 分位数；若人类不可用或 τ_H 不可信，则必须
k·Δt ≤ m
且自主安全成立。输出 k* 与 takeover_margin=τ_H^cert−k*·Δt。块内越界概率由联合界控制：
P[越界] ≤ α_chunk + δ_fi + α_vis + α_H。
执行器只执行 k* 步即强制重规划、重新归因与重新评估人类可用性。

**定义 245（示范驱动技能库 CSP-M / ISL）** 从人类示范抽取技能
σ=(pre, post, π_σ, chunk_sig, f_lim, aff_prior)，
其中 pre/post 为符号前置/效果，π_σ 为技能策略（可用行为克隆/扩散策略初始化），chunk_sig 为块签名分布 𝒟_σ，f_lim 为示范中观察到的安全力上限，aff_prior 为可供性先验。只有通过安全验证与回放一致的技能才入 CSP 图。规划边可包含 ask 元动作（ask_demo/ask_label/ask_takeover），其代价含人类注意力与延迟；实际块签名与 𝒟_σ 的 Mahalanobis 距离>τ_chunk 判 OOD，并触发 MIQ 而非强行执行。软约束代价增 λ_fi·H(P(F,L|ρ))、λ_nov·novelty(ρ)、λ_H·cost_H(q)。

**定义 246（AIC-M 人类/时序/共因对抗认证）** 干扰集
ℰ_M=ℰ_V×ℰ_H×ℰ_cc，
ℰ_H 含人类延迟、疲劳、不一致、恶意指令、错误示范、共享感知盲区、查询误导；ℰ_cc 含同一材质/对抗 patch 同时骗过几何、视觉与人类。ρ_dir 在 ℰ_M 上重算（n_cert 128→160，其中 32 给人类/共因），ρ_force 在最坏人类指令与最坏共因下取最坏；J_dir 增 human_model_ver、intervention_log_ver、co_cause_ver。**共因下不要求归因正确，只要求判 `co_cause_suspected` 并安全降级/请求人类帮助；人类恶意时要求 HSC 能拒绝不安全指令。**

**定义 247（MENTOR 证书 J_mentor）** 
J_mentor=(J_vista, h_ver, novelty_mass, co_cause_score, human_reliability, intervention_hash, query_budget_used, takeover_margin, authority_log, explanation_hash)。
验证规则：
Valid(J_mentor) ⇔ Valid(J_vista)
∧ (max_F P(F|ρ)≥1−δ_fi ∨ novelty(ρ)>δ_nov ∨ co_cause_score>δ_cc ∨ 已执行 MIQ)
∧ 人类指令经 HSC 验证
∧ k* 满足 CSC-M（含接管视界）
∧ 人类可靠性/共因状态已记录
∧ 解释与权限切换可审计。
审计链新增：为何认为这是新故障（novelty_mass）、为何怀疑共因（co_cause_score）、为何问人/问了什么（query_budget、explanation_hash）、为何接受/拒绝人类指令（authority_log）、人是否来得及接管（takeover_margin）。

```python
class CounterfactualFaultIsolation:
    """阶段签名 + 干预证据 + 共享潜在原因；未知故障显式弃权。"""
    HYP = ('H0', 'H_geo', 'H_force', 'H_model', 'H_vis', 'H_policy',
           'H_human', 'H_novel')

    def __init__(self, lik_joint, prior, delta_fi=0.15, delta_cc=0.2):
        self.lik_joint = lik_joint          # p(rho, y_vis, c | F, L)，离线注入+标定
        self.prior = prior
        self.delta_fi, self.delta_cc = delta_fi, delta_cc

    def attribute(self, phases, human_features, demo_batch=None):
        rho = signature(phases, human_features)
        # 对共享潜在原因 L 边缘化，不假设视觉/几何独立
        post_F, post_L = {}, {}
        for F in self.HYP:
            post_F[F] = sum(
                self.lik_joint(F, L, rho) * self.prior[F] * self.prior_L[L]
                for L in self.LATENTS)
        post_F = normalize(post_F)
        co_cause = 1.0 - post_L.get('L_none', 0.0)
        if co_cause > self.delta_cc:
            return post_F, post_L, 'co_cause'
        h_star = max(post_F, key=post_F.get)
        if post_F[h_star] < 1.0 - self.delta_fi:
            return post_F, post_L, 'ambiguous'
        return post_F, post_L, h_star

    def counterfactual_update(self, demo_batch, model):
        """人类示范 = 对动作的干预；比较机器人与人类动作的残差。"""
        evidence = []
        for (s, a_H, y_next, a_R) in demo_batch:
            r_H = y_next - model.predict(s, a_H)
            r_R = y_next - model.predict(s, a_R)
            evidence.append((r_H, r_R, model.support(s, a_H)))
        return evidence                        # 进入 H_model/H_policy 的似然

    def directed_demote(self, h_star, balls, w_H, H):
        if h_star == 'H_geo':
            balls['r_geo'] = min(R_MAX, K_INFL * balls['r_geo'])
        elif h_star == 'H_force':
            balls['r_force'] = min(R_MAX, K_INFL * balls['r_force'])
            request_null_window_recalibration()
        elif h_star == 'H_model':
            balls['r_model'] = min(R_MAX, K_INFL * balls['r_model'])
            switch_compliant_control()
        elif h_star == 'H_vis':
            balls['r_vis'] = min(R_MAX, K_INFL * balls['r_vis'])
        elif h_star == 'H_human':
            w_H = max(0.0, K_HUMAN * w_H)
        elif h_star == 'H_policy':
            H = max(H_MIN, H // 2)
        elif h_star == 'H_novel':
            return balls, w_H, H, 'safe_idle_or_query'
        return balls, w_H, H, 'continue'
```

### IP-227 NHD（开世界新故障发现）

```python
class NovelHypothesisDiscovery:
    def __init__(self, base=p0, gamma=0.1, delta_nov=0.2, tau_nov=3.0):
        self.base, self.gamma = base, gamma
        self.delta_nov, self.tau_nov = delta_nov, tau_nov
        self.clusters = []                  # 已有假设的签名簇

    def novelty(self, rho):
        num = self.gamma * self.base.pdf(rho)
        den = num + sum(c.n * c.pdf(rho) for c in self.clusters)
        return num / (den + 1e-12)

    def propose(self, rho, verified_safe):
        if self.novelty(rho) <= self.delta_nov:
            return None
        if not verified_safe:
            return 'novel_unverified'       # 只标记，不入库
        h_new = fit_local_model(rho)
        h_new.n = 1
        self.clusters.append(h_new)
        return h_new
```

class MixedInitiativeQuery:
    QUERIES = ('none', 'label', 'demo', 'preference', 'takeover', 'explanation')

    def choose(self, post_F, post_L, budget, availability, tau_H):
        best, best_value = 'none', 0.0
        for q in self.QUERIES:
            if q == 'none':
                continue
            if not availability(q) or budget[q] <= 0:
                continue
            ig = expected_info_gain(post_F, post_L, q)
            value = ig - LAMBDA_C * cost_H(q) - LAMBDA_T * tau_H(q) \
                    - LAMBDA_R * risk(q)
            if risk(q) > EPS_Q:
                continue
            if value > best_value:
                best, best_value = q, value
        return (best if best_value > DELTA_Q else None), best_value

    def explain(self, q, post_F, post_L):
        return render_task_space(
            why=entropy(post_F) + entropy(post_L),
            what=q, expected_gain=expected_info_gain(post_F, post_L, q))

## 4. 推导

**引理 9（共因下的被动不可辨识与干预可辨识性）** 设观测 E=(ρ,y_vis)，故障 F=(F_geo,F_vis,F_model,F_policy)，共享潜在原因 L。当 L 同时影响 ρ 与 y_vis 时，被动 Fisher 信息
J_pass=S_FᵀΣ_E⁻¹S_F
存在零方向：F_geo 增大与 F_vis 减小可在观测上相互抵消（或同向增强），因此单一模块归因不可辨识。人类干预 do(A=a_H) 在固定 L 下改变动作，若其响应矩阵 S_cf 在故障对比方向 v 上有非零投影（vᵀS_cfᵀΣ⁻¹S_cf v>0），则新增一行打破零方向，κ_cf>0，H_model 与 H_policy 可分离；若人类动作落在模型支持域外或人类也被 L 欺骗，S_cf 的投影为 0，系统必须保持 ambiguous。∎

**引理 10（新奇度受控的未知故障处理）** 在 Dirichlet process 先验下，给定签名 ρ，其分配给新类的后验概率为 π_new=γp_0(ρ)/(γp_0(ρ)+Σ_k n_k p_k(ρ))。若 π_new>δ_nov，则按定义 237 不将 ρ 分配给任何现有假设。因此未知故障被强行归入最近已知类的概率至多 δ_nov（加上 p_k 的密度估计误差 ε_est）。与第 65 轮「总是 argmax 最近假设」相比，MENTOR 把闭世界的误归因风险换成了开世界的显式弃权风险；弃权后由 MIQ/safe_idle 处理，不产生「已归因」的虚假自信。∎

**引理 11（含接管视界的前缀安全）** 设认证前缀 k* 满足 ∀F∈supp_δ,∀s≤k*: ρ_safe(s)≥0，且若依赖人类接管，k*·Δt≤τ_H^{1−α_H}。人类反应时间模型已校准，则不可逆点前未接管的概率≤α_H；视觉 conformal 覆盖失败概率≤α_vis；归因支持集外质量≤δ_fi；块级 conformal 越界≤α_chunk。由联合界，
P[块内越界或接管失败]≤α_chunk+δ_fi+α_vis+α_H。
若人类不可用，则 k*·Δt≤m 且自主安全成立，退化为第 65 轮的引理 8。∎

**定理 9（MENTOR 端到端归因-交互-安全）** 在 A94–A100 下：
1. **开世界故障处理**：若真实故障不在 ℋ_t，NHD 以高概率标记 novel（引理 10），FIA-cf 不强行归因；新假设只有经安全验证才入 ℋ_{t+1}。
2. **共因不误归因**：若 co_cause_score>δ_cc，系统标记共因并膨胀联合球，不输出单一模块归因；人类语义信息进入 L 的后验而非直接当真值。
3. **干预分离模型/策略**：满足引理 9 条件时，H_model 与 H_policy 可分离；不满足时保持 ambiguous 并触发 MIQ。
4. **人类证据可错**：H_human 与 β 模型使人类证据按可靠性加权；HSC 拒绝不安全人类指令；w_H 有上界，避免「有人在场=有真值」。
5. **时序安全**：CSC-M 同时尊重不可逆视界 m 与接管视界 τ_H/Δt；人类掉线即降级为纯自主安全或 safe_idle。
6. **证书六层链**：Valid(J_mentor) ⇒ VISTA 有效 ∧ 归因/novel/共因/已查询四者之一 ∧ 人类指令经安全盾 ∧ k* 满足 CSC-M ∧ 人类可靠性与共因已记录 ∧ 解释与权限切换可审计。
7. **优雅降级**：人类不可用→退化为 VISTA；人类不可靠→w_H↓、H_human↑；共因→联合球+safe_idle/ask；未知故障→novel+ask；一切失败→safe_idle + 柔顺撤退。
∎

**定理 10（交互式模仿的查询效率与人不确定性折扣）** 设现有假设数 |ℋ|，每次 MIQ 查询在故障对比方向上带来至少 κ_cf 的 Fisher 信息，目标后验熵 ε。主动选择最大信息增益查询的期望查询次数为 O((1/κ_cf)log(|ℋ|/ε))；被动枚举最坏为 O(|ℋ|/κ_cf)。但当人类可靠性 β<1 或人类证据与 L 相关时，有效信息增益按 (1−β)（或更小的偏相关系数）折扣，最优策略可能转为自主探针或安全回退。故「有人的交互」并不自动优于「无人自主」；MIQ 必须显式比较两者净值。∎

**命题（人类信任权重的安全上界）** 若把人类证据当作独立真值，等价于设 w_H=1、β=1；当真实 β<1 且 corr(c,L)>0 时，归因后验会被系统性拉向人类错误。设人类证据的协方差与机器人证据的相关系数 ρ_HL，则安全权重满足
w_H ≤ β(1−ρ_HL²)/(1−β+β(1−ρ_HL²))。
因此 MENTOR 将 w_H 限制在该上界内，并在 β 估计不可信时进一步下调；这直接对冲「人机交互把人变成新单点故障」的风险。∎

## 7. 已知风险

**一句话**：MENTOR 的安全与归因现在依赖「人类在需要时可用、其干预信息量足够、且人类不与被感知对象共享同一个共因失效」；一旦人掉线、延迟、过度自信或也被透明/对抗物体欺骗，开世界新奇度机制会把「人的错误」当成「新故障」学习，或让系统在等待人类时越过不可逆点——**人机交互由此从安全补丁变成新的单点故障与错误学习源**。

**次级风险与缓解**：
1. **人类不可用/掉线**：安全论证若依赖接管则失效；缓解：CSC-M 强制 k\*·Δt≤τ_H，人类掉线立即降级为纯自主 m 或 safe_idle；关键场景要求自主安全不依赖人。
2. **人类与机器人共享共因**：透明/对抗物体同时骗过两者；缓解：H_human 与 L 联合建模、w_H 上界、要求人类提供独立物理证据（触摸/敲击/换视角）而非仅口头标签。
3. **人类恶意/被诱导**：HSC 拒绝不安全指令；AIC-M 显式认证恶意/误导查询与错误示范；人类不能覆盖物理安全约束。
4. **新奇度被噪声/分布漂移触发**：频繁 novel 导致任务停滞；缓解：δ_nov 校准、novelty 需多证据确认、把「novel 但低风险」与「novel 且高风险」分开处置。
5. **错误学习新故障类**：把人类错误或传感器瞬态当成新故障写入 ℋ；缓解：新假设必须经独立验证集、安全盾与回放一致；默认只提案不入库。
6. **模仿行为先验的体现差异**：人类动作与机器人运动学不匹配导致 d_H 误报；缓解：只用任务空间/物体相对低维投影，学习显式对应映射，把 d_H 仅作弱证据。
7. **查询成本与延迟**：频繁问人造成任务中断、注意力耗尽；缓解：MIQ 显式成本/延迟/风险项；设置每轮预算与「不提问」阈值；解释也要低成本。
8. **接管视界估计不准**：τ_H 分布随人/任务/疲劳变化；缓解：在线校准、按 1−α_H 分位取保守值、人类状态监测、必要时拒绝依赖接管的安全论证。
9. **实时预算**：HSC + 接管检测 + CSC 早停逼近 2.8ms；缓解：安全盾查表/低维投影、ROI 降采样、语义流卸载世界模型与 MIQ。
10. **公平性与可审计性**：人类信任权重可能对特定操作者产生系统性偏差；缓解：按可靠性而非身份加权、记录 authority_log、定期审计拒绝率与查询分布。
