# 第 71 轮（承接第 70 轮「BELIEF-RAS」IP-264~274；灵感：「工具调用」×「长程任务」）

> R70 给闭环装上了显式世界信念 b_t，问出「我现在信什么」，并承诺「后验熵 H[b_t] 是 epistemic 唯一真身」。但 R70 有两个隐含前提：任务只看**下一步**，动作只发生在**自己的本体**上。真实任务往往是**长程**的——几百次决策、多个子目标、跨小时甚至跨天；而且智能体越来越多地通过**工具**（API、检索、求解器、执行器、子代理）改变世界。长程把两个问题同时放大：
> - **误差复利**：每步 1% 的残余错误，100 步后成功率只剩 ~37%。R70 的「每步收紧」会让系统慢到根本完不成任务，而「不收紧」会让误差指数放大。
> - **承诺不可逆**：工具调用有副作用（下单、删除、写库、驱动执行器），不是 R69 那种「看一眼、问一句」就可以反悔的信息动作。一旦在错误的信念上下了一个不可逆的调用，长程任务没有「重来一次」。
>
> 本轮把 R70 的「状态信念」升级为**任务级进度信念**，把 R69 的「信息动作」升级为**带契约的工具调用**，并交付一个核心机制：**在不可逆承诺之前消歧、在可逆边界设检查点、把误差预算沿长程重新分配**。
>
> 核心命题：**长程任务的安全不靠「每步更保守」，而靠「承诺分层」——可逆处快速试错，不可逆处先查后做；用带契约的工具调用把每一步的副作用、可逆性、时鲜度和失败语义显式化，用进度信念与误差预算把 H 步任务拆成可认证、可回滚的段。** 命名 **TELOS-RAS**（Tool-contract, Epistemic Long-horizon Option Scheduling）。
>
> 一句话定位：R69 问「我该向谁求证」，R70 问「我现在信什么」，R71 问「**这条路我能承诺到哪一步、哪一步绝不反悔**」。

## 0. 直觉与动机

**灵感 1（长程任务 → 误差是复利，不是加法）**
直觉：假设每步有 1% 的概率因残余 epistemic 而走错，100 步的成功率不是 99%，而是 0.99^100 ≈ 37%。R70 的保守铁律在每个单步上是对的，但它把整个任务当成 H 个独立的保守决策，结果要么慢得错过时间窗，要么在某个不可逆步骤上一次性失败。长程要求一种**预算视角**：把总失败预算 δ 分配到 H 个段，而不是每段都要求同一个 ε。更关键的是，**可恢复的段可以花更少预算**（错了能回滚），**不可逆的段必须花更多预算**——这正是分层的经济学。

**灵感 2（工具调用 → 带副作用的承诺）**
直觉：R69 的「信息动作」（看/问/触）本质上是无损的：问错了，无非浪费一次预算。但工具调用不一样：它写数据库、下单、启动电机、调用外部服务、触发子代理。它有 **precondition（能不能调）**、**postcondition（调完世界变成什么样）**、**可逆性（κ）**、**时鲜度（返回值多久失效）**、**失败语义（静默失败/部分成功）**。工具调用把「动作」从「轨迹点」升级为「**契约 + 承诺**」。长程任务 = 一串承诺的复合；任何一个承诺的错误都会成为后一个承诺的前提。

**灵感 3（近视 VoI 的失效 → 需要「到期」而非「即期」的信息价值）**
直觉：R69/R70 的 VoI 是单步的：这次交互能把 H[b_t] 降多少。但长程里，一个查询的价值可能很久以后才兑现（现在就问清楚交付地址，价值在最后一公里才体现）；反过来，一个当前 VoI 很小的检查，可能因为后面紧跟一个不可逆调用而价值巨大。所以需要**到期 VoI（deadline-aware VoI）**：信息动作有「最晚可执行时刻」，由它所服务的第一个不可逆承诺决定；越接近截止，同样的信息越值钱。这给出可执行的排序规则：**对不可逆动作 resolve-early，对可逆动作 trial-and-error**。

**灵感 4（误差控制 → 检查点、回滚、证据链，而非全局 λ）**
直觉：R68–R70 控制不确定性的统一手段是「收紧 λ」。在长程里这是错配：全局收紧会让系统永远走不完；放开又会复利。正确手段是**把长程切成带认证的原子段（options）**，在可逆边界（承诺可撤销处）落检查点；一旦 postcondition 核验失败或证据链断裂，回滚到最近认证快照、重规划，而不是把整条链的 λ 拉满。这把「风险管理」从标量缩放升级为**拓扑结构**：在哪里切、切多细、回滚代价多大。

**灵感 5（长程记忆与缓存 → 陈旧与投毒会沿链传播并被洗白）**
直觉：长程任务必然复用工具结果（缓存、检索、子代理、之前的世界模型）。R69 已警告「问错比不问更危险」；长程把它放大为「**一次污染沿证据链传播，越走越像真的**」。缓存会陈旧（freshness 过期），外部工具会返回被注入的内容，子代理会幻觉。必须给每个工具结果打上**出处（provenance）+ 时鲜度（freshness）+ 置信（calibration）**，并禁止单源结果在长程中「转正」为承诺前提。否则长程任务会把一次早期的投毒，经过 50 步「一致证据」的反复引用，变成审计上无懈可击的错误。

**灵感 6（对 R70 的姿态 → 严格包含）**
直觉：R70 是本轮在 H=1、无工具、无检查点边界上的退化情形。任何新机制一旦不可信（进度信念未校准、工具契约缺失、预算耗尽），都必须**单调退化**回 R70 的逐指令行为。R71 不能是「另起一个更大的黑箱」，而必须是「在旧层外面的、每一层都可单独关闭的壳」。

## 1. 形式化定义（增量：定义 331–350）

**定义 331（TELOS-RAS 总览）** TELOS-RAS = (MBP, TCL, TPG, LH-VoI, IRR, CPR, ECC, TCM, VQAuditor-III, AIC-HORIZON, J_HORIZON, RAS-WM‡)。五不变式：
(i) **零学习写操作**（继承 R68 定义 276-i）；
(ii) **承诺安全**：任何 effectful 工具调用必须通过 TCL 认证，且其副作用写入承诺账本；
(iii) **证据纪律**（继承）+ **长程出处纪律**：承诺前提不得来自单一、未过期、未交叉验证的工具结果；
(iv) **预算硬约束**：工具调用次数 / 延迟 / token / 回滚次数上限；
(v) **严格退化**：进度信念不可信 / 工具契约缺失 / 预算耗尽 ⇒ 逐指令退化为 BELIEF-RAS。

**定义 332（工具空间与契约）** 工具 τ = (Σ_in, Σ_out, pre_τ, post_τ, κ_τ, fresh_τ, c_τ, fail_τ)。κ_τ ∈ [0,1] 为不可逆性（1 = 完全不可逆，如删除/下单/驱动执行器）；fresh_τ 为结果有效期；fail_τ 为失败语义（fail-stop / silent / partial）。调用 u = (τ, args)，args 须过 schema 类型、量纲、单位检查。

**定义 333（工具程序与选项）** 工具程序 p = (u_1, …, u_L) 带分支与回退，编译为选项 o = (pre, π_cont, β, post, fallback)。连续参数由 FMP† 生成，符号骨架由冻结 LLM 生成；程序须通过类型检查与控制流安全分析（禁止在未认证 effect 前跳转、禁止无界循环）。

**定义 334（进度信念 MBP）** 任务进度状态 m_t = (j, φ, C, K)：子目标索引 j、连续进度 φ ∈ [0,1]^d、承诺账本 C、检查点集 K。任务/状态联合后验 b_t^M(s, m) = p(s, m | o_{1:t}, u_{1:t−1}, y_{1:t−1})；**U_epi^M = H[m_t]**（进度假设熵），U_ale 沿用 R70 的 E_{b}[trΣ_obs]。MBP 在 BSE 上加一层离散进度转移。

**定义 335（承诺账本）** C 为 append-only、hash-chained 的承诺记录 {(u_i, τ_i, κ_i, t_i, undo_cost_i, evidence_ref_i)}；不可撤销或 undo_cost > c_max 的承诺标为「锁死」，任何后续计划必须与之相容（不得计划一个与之矛盾的动作）。

**定义 336（长程 VoI 与到期）** LH-VoI_H(g | b_t^M) = E[L_terminal(π) − L_terminal(π | do(g))]，在剩余 H 步上积分。信息动作 g 的**到期** D(g) = 其所服务的最早不可逆承诺时刻（若无则 +∞）；可执行窗口 [now, D(g)]，越界则价值清零（信息迟到 = 无用）。

**定义 337（不可逆性排序与 resolve-early）** 对依赖同一歧义的候选动作按 κ / undo_cost 排序。规则：若 κ(g_effect) ≥ κ_thresh 或 undo_cost ≥ c_thresh，则必须先执行能降低该歧义的 info 动作（或插入 checkpoint），否则该 effect 动作不可认证。可逆动作允许「先做后纠」，不可逆动作必须「先查后做」。

**定义 338（检查点与回滚 CPR）** 在可逆边界（所有活动承诺均可撤销或 κ ≤ κ_cp）处冻结认证快照 K_i = (b^M, C, 环境可回滚状态哈希, 程序指针)。回滚 = 恢复到 K_i 并重规划；回滚代价 r_i 与恢复成功概率 ρ_i 计入预算。

**定义 339（误差复利控制器 ECC）** 维护剩余失败预算 δ_rem；按「段数 × 不可逆性 × 回滚可达性」分配 δ_seg = δ_rem · w(κ,ρ) / Σw。每段执行后 δ_rem ← δ_rem − ε_obs；若某段预测 ε > δ_seg 则强制插入 info 动作或 checkpoint；若 δ_rem < δ_min 则触发安全停止/交接（定义 343）。这把 R68 的标量 λ 变成**沿时间的预算调度**。

**定义 340（工具结果时鲜度与出处 TCM）** 每个结果 r 附 provenance 图 G_r（来源工具、时间、父结果、签名）、age a_r、staleness 概率 s(a_r) = 1 − e^{−λ_τ a_r}。缓存准入要求 s(a_r) < τ_stale 且 provenance 无环、无未验证外部注入。**承诺前提**要求 ≥2 个 provenance 不相交的结果一致（强化 R69 证据纪律）。

**定义 341（工具调用认证 TCL-Cert）** 调用 u 认证 ⇔ schema/单位/量纲通过 ∧ pre_τ 在当前 b_t^M 下成立概率 ≥ 1−ε_pre ∧ 副作用在安全包络内（C-RAS-WM‡ 对宏动作做前缀认证）∧ 预算允许 ∧ 若 κ 高则存在匹配的消歧证据或 checkpoint。

**定义 342（postcondition 核验与静默失败）** 执行后以观测/回读核验 post_τ；若返回「成功」但 post 不成立（silent failure），视为失败并回滚；若部分成功（partial），把未完成部分作为新子目标写回 m_t，而不当作完成。

**定义 343（安全停止与交接）** 当预算耗尽、δ_rem < δ_min、进度信念长期无提升（spinning）或证据链无法重建时，执行**有证据的优雅交接**：冻结承诺账本、输出未决假设与已完成/未完成段、退回 R70/R68 最保守或人工接管；绝不「硬着头皮继续」。

**定义 344（参与式审计 VQAuditor-III）** 审计长程决策：工具是否幻觉/参数是否接地、缓存出处是否可信、进度声明是否有证据、回滚是否被滥用（反复回滚 = 隐性不收敛）、承诺账本是否与证书一致。

**定义 345（干扰集 AIC-HORIZON）** ℰ_HORIZON = ℰ_BELIEF × ℰ_tool × ℰ_long：幻觉工具 / 错误 schema、参数单位错误、陈旧缓存、注入投毒沿链传播、静默失败、部分成功伪装、目标漂移（long-horizon goal drift）、回滚风暴。

**定义 346（证书 J_HORIZON）** J_HORIZON = (J_BELIEF, progress_ECE, commitment_ledger_hash, tool_cert_rate, stale_rate, rollback_count, horizon_budget_used, telos_ver)。Valid ⇔ J_BELIEF Valid ∧ progress_ECE ≤ τ_ece ∧ 出处纪律满足 ∧ 预算未越界 ∧ 无未认证 effectful 调用。

**定义 347（四级严格包含）** TELOS 在 H=1、𝒯=∅（无工具）、K=∅（无检查点）、κ≡0 时逐指令退化为 BELIEF；BELIEF 再退化为 FLUID；FLUID 再退化为 R68。安全侧层层不让步。

**定义 348（进度单调性与反 spinning）** 在信念下，每段执行后 E[φ] 必须不减（或 H[m_t] 必须下降），否则判定 spinning；连续 spinning 超阈值 → 重规划 → 仍失败则交接。防止「用工具调用制造忙碌的假进度」。

**定义 349（预算自适应调度）** 工具 / 延迟 / token / 回滚四类预算由 LH-VoI 与 ECC 共同分配，随剩余 H 与置信动态调整。

## 2. 关键算法骨架

```python
# IP-275 TCL：工具契约与认证（把 effectful call 变成可审计承诺）
@dataclass
class ToolContract:
    sigma_in: TypeSpec; sigma_out: TypeSpec
    pre: Callable; post: Callable
    kappa: float            # 不可逆性 0..1
    fresh_s: float          # 结果有效期
    cost: Cost; fail_mode: str   # stop|silent|partial

def certify_call(u, bM, budget, c_ras_wm, evidence):
    if not schema_ok(u, u.tau.sigma_in): return False, "schema"
    if p_pre(u, bM) < 1 - EPS_PRE:       return False, "precondition"
    if u.tau.kappa > KAPPA_HI and not resolve_evidence(u, evidence, bM):
        return False, "unresolved_high_irreversible"   # resolve-early 铁律
    if not c_ras_wm.certify_macro(u, bM): return False, "safety_envelope"
    if not budget.allow(u):              return False, "budget"
    return True, "ok"

# IP-276 TPG：LLM 出符号骨架，FMP† 填连续参数，类型系统兜底
def generate_program(llm, fmp, bM, H):
    skeleton = llm.propose_program(bM.goal, tools=registered_tools(), H=H)
    p = typecheck_and_repair(skeleton)          # 拒绝幻觉工具/非法控制流
    for u in p.tool_calls:
        u.args_cont = fmp.sample_args(u, bM)    # 连续量由流策略生成
        u.args = project_to_schema(u.args_cont, u.tau.sigma_in)  # 单位/量纲投影
    return p

# IP-277 LH-VoI：到期感知的长程信息价值
def horizon_voi(g, bM, H, deadline):
    if now() > deadline: return 0.0             # 迟到信息 = 无用
    lo = terminal_loss(bM, policy="current", H=H)
    hi = expectation_answer(g, lambda y: terminal_loss(step(bM, g, y), "current", H))
    return lo - hi - cost(g)

# IP-278 IRR：不可逆性排序 → 先查后做 / 先做后纠
def schedule(program, bM):
    for effect in program.effect_calls_sorted_by_kappa_desc():
        if effect.tau.kappa >= KAPPA_THRESH:
            info = best_info_action_for(effect.ambiguity, bM)
            if info and horizon_voi(info, bM, H, deadline=effect.t) > 0:
                program.insert_before(effect, info)      # resolve-early
            else:
                program.insert_before(effect, checkpoint())  # 至少可回滚
    return program

# IP-279 CPR：可逆边界检查点 / 回滚重规划
def execute_segment(o, bM, budget):
    cp = snapshot(bM)                            # 仅当所有活动承诺可撤销
    u  = commit(o)
    ok, post = verify_post(u)
    if not ok:                                   # 含 silent failure
        bM = rollback(cp); budget.charge(cp.cost)
        return REPLAN, bM
    bM = update_progress(bM, post)
    return DONE, bM

# IP-280 ECC：误差预算沿时间分配（取代全局 λ 拉满）
def alloc_budget(bM, program, delta_rem):
    weights = [seg_weight(seg.kappa, seg.recovery_rho) for seg in program]
    for seg, w in zip(program, normalize(weights)):
        seg.risk_budget = delta_rem * w
    return program

# IP-281 TCM：缓存出处/时鲜度，承诺前提须 provenance 不相交
def admit_cache(r, now):
    if staleness(r, now) >= TAU_STALE: return False
    if has_cycle(r.provenance) or untrusted_inject(r.provenance): return False
    return True

def evidence_ok(refs, commitment):
    return provenance_disjoint_pairs(refs) >= 2 and freshest(refs) >= commitment.t

# IP-282 TELOS 主闭环（继承 BELIEF，插入长程层；任何门失败即退化）
def TELOS_round(M, obs, H_remaining):
    bM = M.mbp.predict_update(M.bM_prev, obs)            # R70 BSE + 进度层
    if not M.mcg_s.trusted(bM):                          # 进度后验不可信
        return BELIEF_RAS_round(M, obs)                  # 逐指令退化
    delta = M.ecc.remaining(H_remaining)
    if delta < M.cfg.delta_min:                          # 预算耗尽
        return M.handoff.graceful(bM)                    # 有证据交接
    prog = M.tpg.generate(M.llm, M.fmp, bM, H_remaining)
    prog = M.irr.schedule(prog, bM)                      # 先查后做
    prog = M.ecc.alloc_budget(bM, prog, delta)
    for seg in prog:
        ok, bM = M.cpr.execute_segment(seg, bM, M.budget)
        if ok == REPLAN:
            if M.spin.detected(bM): return M.handoff.graceful(bM)
            break
    M.ecc.update(bM, obs)
    if not M.progress.monotone(bM): return M.handoff.graceful(bM)
    M.vqa_iii.submit_async(prog, bM, M.commits)
    M.bM_prev = bM
    return M.decide(bM, prog)
```

## 3. 推导

**引理 23（长程误差复利与预算分配）** 设任务分 H 段，段 i 的永久失败概率 ≤ ε_i(1−ρ_i)（ε_i 为出错概率，ρ_i 为回滚恢复概率）。则 P(成功) ≥ 1 − Σ_i ε_i(1−ρ_i)。要在 H 步内保证 ≥ 1−δ，需 Σ_i ε_i(1−ρ_i) ≤ δ。系：(a) 无检查点（ρ=0）时需每段 ε ≤ δ/H，随 H 线性收紧；(b) 有高恢复率检查点时，可把预算向不可逆段集中，可逆段用大 ε 换取速度——**长程的效率来自 ρ，而不是来自放宽安全**。

**引理 24（近视 VoI 的退化与鸿沟）** 存在任务族，使得信息动作 g 的单步 VoI（R69/R70）≤ 0，但其 H 步 LH-VoI > 0（g 的答案只影响第 H 步）。故近视策略会跳过 g，最终损失 ≥ L* + Ω(Δ)；而到期感知策略达到 L*。鸿沟随 H 增长无界。系：R70 的 VoI 是 LH-VoI 在 H=1 的投影，长程必须显式积分剩余视野。

**引理 25（不可逆性排序 / resolve-early）** 设某歧义两假设下 effect 动作的损失差为 Δ，后验最短假设概率 p*。若在 effect 前消歧，期望额外损失 ≤ (1−p*)·Δ_info + c(g)；若在 effect 后才发现（κ=1 不可逆），损失 = Δ，无补救。故当 κ·Δ > c(g) + (1−p*)·Δ_info 时，先查后做严格占优；且信息动作在 effect 之后价值归零（定义 336 的到期 D(g)）。系：κ 越大、Δ 越大，越应提前消歧；可逆动作（κ≈0）则应「先做后纠」。

**引理 26（长程陈旧/投毒传播上界）** 单源结果沿长度 L 的引用链传播时，若每跳重新引用而不重验，则污染存活率 ≥ (1−s)^L（s 为每跳被判定陈旧/污染的概率）；若每跳独立检出率 ρ，则穿透率 ≤ δ_p·ρ^{L−1}。在**承诺边界**强制「provenance 不相交 + 新鲜度」双源一致，可把穿透率压到 ≤ δ_p·ρ + ε_σ，与 L 无关。系：不需要每一步都双源，但**不可逆承诺前必须双源**——这正是长程出处纪律的落点。

**定理 20（TELOS 严格包含 BELIEF 严格包含 FLUID 严格包含 R68）** 在 A99–A103（R70 假设 + 工具契约可核验 + 检查点可恢复）下，TELOS 的四级策略期望风险 ≤ BELIEF ≤ FLUID ≤ R68；且当 H=1、无 effectful 工具、无检查点、或进度信念 ECE 越界、或预算耗尽时，逐指令相同。TELOS 只在「可逆、可验证、有预算」的区域加速，安全侧不让步。

**定理 21（承诺安全、回滚无突变与有界终止）** effectful 调用经 TCL 认证且回滚只到认证快照 ⇒ 每步副作用都在安全包络内、控制连续无突变（继承 R68 定理 15）；在有限检查点与有限预算下，每段要么使 E[φ] 严格增加、要么回滚使已承诺错误减少，故不会无限 spinning，最终到达 DONE 或**有证据的安全交接**（定义 343、348），终止步数有上界。

```python
def mbp_step(bM_prev, obs, last_u, last_y):
    b_s   = bse_step(bM_prev.s, obs, last_u, last_y)      # R70 BSE
    m     = progress_transition(bM_prev.m, last_u, last_y)  # 离散进度链

def certify_call(u, bM, budget, c_ras_wm, evidence):

    if p_pre(u, bM) < 1 - EPS_PRE:                       return False, "precondition"

def horizon_voi(g, bM, H, deadline):

    lo = terminal_loss(bM, "current", H)
    hi = expectation_answer(g, lambda y: terminal_loss(step(bM, g, y), "current", H))
    return lo - hi - cost(g)

# IP-279 IRR：κ 排序 → 先查后做 / 先做后纠
def schedule(program, bM, H):
    for effect in program.effects_sorted_by_kappa_desc():

            if info and horizon_voi(info, bM, H, deadline=effect.t) > 0:
                program.insert_before(effect, info)
            else:
                program.insert_before(effect, checkpoint())
    return program

# IP-280 CPR：检查点 / 回滚 / 重规划
def execute_segment(o, bM, budget):
    cp = snapshot(bM)                                    # 仅当活动承诺均可撤销
    u  = commit(o)
    ok, post = verify_post(u)                            # 含 silent failure
    if not ok:
        bM = rollback(cp); budget.charge(cp.cost)
        return REPLAN, bM
    return DONE, update_progress(bM, post)

# IP-281 ECC：失败预算沿时间分配
def alloc_budget(bM, program, delta_rem):
    w = [seg_weight(s.kappa, s.recovery_rho) for s in program]
    for s, wi in zip(program, normalize(w)):
        s.risk_budget = delta_rem * wi
    return program

# IP-282 TCM：缓存准入与承诺前置证据
def admit_cache(r, now):
    if staleness(r, now) >= TAU_STALE:                     return False
    if has_cycle(r.provenance) or untrusted_inject(r.provenance): return False
    return True

def evidence_ok(refs, commitment):
    return provenance_disjoint_pairs(refs) >= 2 and freshest(refs) >= commitment.t

# IP-288 TELOS 主闭环
def TELOS_round(M, obs, H):
    bM = M.mbp.mbp_step(M.bM_prev, obs, M.last_u, M.last_y)
    if not M.mcg_s.trusted(bM):                            # 进度后验不可信
        return BELIEF_RAS_round(M, obs)                    # 逐指令退化
    delta = M.ecc.remaining(H)
    if delta < M.cfg.delta_min:
        return M.handoff.graceful(bM)                      # 有证据交接
    prog = M.tpg.generate(M.llm, M.fmp, bM, H)
    prog = M.irr.schedule(prog, bM, H)                     # 先查后做
    prog = M.ecc.alloc_budget(bM, prog, delta)
    for seg in prog:
        ok, bM = M.cpr.execute_segment(seg, bM, M.budget)
        if ok == REPLAN:
            if M.spin.detected(bM): return M.handoff.graceful(bM)
            break
    M.ecc.update(bM, obs)
    if not M.progress.monotone(bM): return M.handoff.graceful(bM)
    M.vqa_iii.submit_async(prog, bM, M.commits)
    M.bM_prev = bM
    return M.decide(bM, prog)
```

## 4. 推导

**引理 23（长程误差复利与预算分配）** P(成功) ≥ 1 − Σ_i ε_i(1−ρ_i)。保证 ≥1−δ 需 Σ ε_i(1−ρ_i) ≤ δ。系：无检查点时每段 ε ≤ δ/H（随 H 线性收紧）；有高恢复率检查点时可把预算向不可逆段集中。**长程效率来自 ρ，不来自放宽安全。**

**引理 24（近视 VoI 鸿沟）** 存在任务族使单步 VoI(g) ≤ 0 而 LH-VoI_H(g) > 0，近视策略终局损失 ≥ L* + Ω(Δ)，鸿沟随 H 无界。R70 的 VoI 为 H=1 投影。

**引理 25（resolve-early）** κ·Δ > c(g) + (1−p*)Δ_info 时，先查后做严格占优；effect 之后信息价值归零。κ 越大越该提前消歧。

**引理 26（长程陈旧/投毒传播）** 单源沿链 L 跳的污染存活率 ≥ (1−s)^L；承诺边界双源 provenance 不相交 + 新鲜度可把穿透率压到 ≤ δ_p·ρ + ε_σ，且与 L 无关。**不必每步双源，但不可逆承诺前必须双源。**

**定理 20（四级严格包含）** A99–A103 下 TELOS ≤ BELIEF ≤ FLUID ≤ R68；H=1/无工具/无检查点/ECE 越界/预算耗尽时逐指令相同。

**定理 21（承诺安全、回滚无突变、有界终止）** 认证 effect + 回滚仅到认证快照 ⇒ 副作用在安全包络内、控制连续（继承 R68 定理 15）；有限检查点与预算下每段要么 E[φ] 严格增、要么回滚减少已承诺错误，故无无限 spinning，终达 DONE 或安全交接，步数有界。

## 7. 本轮最大风险
