# 第 2 轮（UniBot 线 · 第 2 轮；本轮灵感：「用户测试」×「场景泛化」）

> **基线**：第 1 轮 UniBot-SAGE v1（定义 U1–U12 / 引理 L1–L7 / 实验 E601–E618），继续有效，不推倒重来。本轮做「深化 + 修剪」：新增 U13–U24 / L8–L14 / E619–E638；**IP-01 从 P0 降为 P1**，**IP-02 升格为「主动 + 有保证」形态（IP-02′）**，**新增 IP-10（场景阶梯）为 P0**，并新增 IP-09（演示者审计）与 IP-11（红队用户测试）。
> **数据纪律**：第 1 轮的 teaser 表结论继续保留；本轮新增的「路由泛化边界测试」同样只作用于 teaser 结构（本地转录快照 2026-11-02）。它证明的是**检验方法可用**与**IP-01 红利尚未被证明**，不是真实世界的泛化证据。

## 0. 本轮的一句话转向

第 1 轮把「泛化」当成一个标量（分布偏移），把「技能」当成任务身份（`z_task`）。本轮的两个灵感把这两件事都拆开了：

- **场景泛化不是一个东西**：不变性（nuisance）、等变性（目标位姿）、鲁棒性（人为干扰）、组合性（未见物品）需要四种不同的数学承诺；用同一种域随机化一锅炖，会在一半的轴上产生「训练越狠、泛化越差」的抵消。
- **用户测试不是一种人**：演示者（operator）、红队用户、人类判读者、评测端（grader）是四类不同的「用户」，各自给出一条独立的验证轴。

由此得到比第 1 轮更锋利的命题——**从「任务泛化」转向「失效泛化」（from task generalization to failure generalization）**：不要只问「这是哪个任务」，要问「这一步最可能以哪种方式失败」；不要只问「在场景 B 上分数多少」，要问「场景 B 相对场景 A 的哪一条因果轴变差了」。

## 1. 直觉解释（先直觉，后定义；严格定义见产物区 §3）

### 1.1 灵感 1 ·「用户测试」：四个用户，四条验证轴

第一性原理：一次「用户测试」之所以有价值，不是因为它「像真实用户」，而是因为它引入了**训练者不可见的分布**。在 UniBot 里至少有四种不可见分布：

| 用户 | 他/她/它改变了什么 | 能回答的问题 | 对应第 1 轮的盲点 |
|---|---|---|---|
| **演示者（teleoperator）** | 同一任务的动作风格（速度 / 平滑度 / 抓握时机 / 双臂偏置） | 策略学到的是「任务」，还是「某个人的手感」？ | IP-06 只按物体 / 背景 / 位置切分，没有按「人」切分 |
| **红队用户** | 主动构造让策略失败的情境 | 我们的代理评测漏掉了哪些真实失效？ | IP-06 的「代理 ↔ 真机」相关性风险 |
| **人类判读者** | 只看与策略相同的观测，判断「抓住没有 / 会不会成功」 | 这个信息在观测里到底可不可读？ | IP-02 的抓握隐变量可识别性 |
| **评测端（grader）** | 端口数 / 顺序 / 延迟 / 重置 / token 的敌意组合 | 服务在真实评测协议下会不会「非战斗减员」？ | IP-08 只有正向压测，没有故障注入 |

这张表的锋芒在于：第 1 轮几乎把「用户」当成「评测器」的同义词，只做了 IP-08（grader）这一种用户测试；而另外三种用户，恰好对应第 1 轮最痛的三处不确定性。

三个可直接落地的推论：

1. **演示者留一法（LODO）**：把「人」当作域，做 leave-one-demonstrator-out；若留出演示者后成功率显著下降，说明策略记忆了操作风格，而不是任务。这是比「留出物体 / 背景」更少被做、也更贴近「未见用户」的一条轴。
2. **人类判读上限**：人类看同样的腕部帧 + 1 维夹爪标量，判断抓握成功的 AUC 记为 `AUC_h`。若 `AUC_h` 也不高，则「被动观测下抓握可识别」这一前提本身可疑，必须改为**主动微抬探测**；若 `AUC_h` 很高，则学一个接近人类的验证器是合理的。
3. **红队覆盖**：让非开发者用户主动「把策略弄失败」，把失效编码进六因子；代理评测对红队失效的复现比例 `C` 就是它的覆盖下界。`C` 低，则代理评测只能做相对排序，不能报绝对成功率。

### 1.2 灵感 2 ·「场景泛化」：一根梯子，四层不同的数学

第一性原理：官方的 5 类泛化场景看起来是「5 种扰动」，其实是**4 种不同的变换群**，对策略提出的要求互相冲突：

| 场景类型 | 数学对象 | 正确要求 | 错误做法 | 典型失败 |
|---|---|---|---|---|
| 位置变化 | 任务相关状态 `s` 上的平移 / 旋转群 `G_t` | **等变**：`π(g·o)=g·π(o)` | 把位置也当噪声做「不变」增强 | 目标定位被抹平，动作「平均化」 |
| 背景 / 光照 | nuisance `x` 上的外观群 `G_n` | **不变**：`π(g·o)=π(o)` | 把背景当任务信号学进去（捷径） | 换背景即崩 |
| 干扰物 | nuisance 的**组合**（数量 / 位置 / 语义） | 不变 + 正确指代 | 只做像素级随机粘贴 | 抓错物体 / 被干扰物带偏 |
| 未见物品 | 语义 / 几何的组合外推 | **组合泛化**（object-centric） | 把「未见」当「没见够」继续堆数据 | 形状 / 材质一变就抓空 |
| 人为干扰 | 动态系统上的扰动 `d` | **鲁棒 / 恢复**：风险球内有界 | 用静态遮挡近似动态人 | 被碰一下就无法恢复 |

一个直接推论：**域随机化不是越多越好**。对 nuisance 随机化是「去捷径」；对目标位姿随机化如果不配等变约束，则是在「教策略忽略目标位置」。第 1 轮的 IP-04 把 5 类场景统一成「上下文向量 `c` + FiLM 调制」，方向对但粒度太粗；本轮把它拆成 **不变性损失 / 等变性损失 / 鲁棒性约束** 三项，分开训练、分开评估。

### 1.3 合成：从「任务泛化」到「失效泛化」

> **泛化的最小单位不是任务，也不是场景，而是「失效因子在变换群下的行为」。**

于是第 1 轮的 `z_task`（语言检索的任务 token）被降级为**先验**，真正用于路由与验证的条件变量换成 `z_fail`（预测的六因子失效签名）。第 1 轮的「任务 oracle +4.26」也被重新审视：它是**上界**，必须用不含目标信息的特征重新测一遍，才配叫「红利」。

## 2. 本轮关键量化发现：路由泛化的「上下夹逼」（teaser 结构，非真实证据）

第 1 轮的 IP-01 建立在一个数字上：per-task oracle 33.96 vs best single 29.70（+4.26）。但那个数字回答的是「如果每个任务都事后知道谁最好」，不是「一个可部署的路由器能拿到多少」。本轮用同一张 teaser 表做了路由泛化的边界测试（脚本见 `exp/r2_unibot_v2/route_boundary_test.py`，结果见 `route_boundary_results.json`）：

- **可部署下界**（只用测试时可得的信息：任务文本相似度；留一任务 LOTO）：1-NN 文本路由 = **25.67**（比 best single 低 **4.03**）；3-NN = 28.71（低 0.99）；字符 3-gram 1-NN = 28.29（低 1.41）。⇒ **语义相似 ≠ 失效相似；按任务名路由会亏钱。**
- **含泄漏上界**（用留出任务自己的跨模型表现画像算相似度；不可部署，只作上界）：1-NN = 31.28（捕获 oracle 红利的 37.0%，bootstrap 95% CI [0.29, 2.88]）；3-NN = 32.71（捕获 70.8%，CI [1.75, 4.29]）。⇒ 若存在「完美失效画像预言机」，路由红利确实可观。
- **粗粒度失效族上界**（K-means 聚类 + 已知簇归属 + 留一任务选专家）：K=2 = 30.81（捕获 26.1%）；K=3 = 27.98（**负**）；K=6 = 30.57（20.5%）；K=8 = 30.66（22.5%）。⇒ 粗粒度「任务家族」几乎拿不到 oracle 红利；红利是**任务级特异**的。

**读法（三条）**：

1. **T4（路由红利未被证明）**：+4.26 是上界，不是可达值；在 teaser 结构上，唯一可部署的特征（文本）是负收益，唯一正收益来自「偷看目标任务的失效画像」。⇒ IP-01 从 P0 降为 P1，并预注册「若真实数据上可部署 LOTO 路由捕获 <25% oracle，则退回单专家」。
2. **T5（条件变量选错了）**：语言语义与「该用哪个专家」几乎无关；真正相关的是**失效模式画像**（每个模型在 32 任务上的相对强弱向量；任务画像两两相关均值仅约 0.25，跨模型两两 Kendall τ 均值约 0.06，见第 1 轮）。⇒ 把 `z_task` 换成 `z_fail`，并把 IP-06 的六因子从「诊断指标」升级为「路由 / 验证的条件变量」。
3. **T6（红利弥散）**：32 个任务上 oracle 相对 best single 的增益全部 ≥0（总和 136.3pp），12 个任务 >5pp，最大 17.7pp（Place Photo Frames）；没有任何「一个任务吃掉全部红利」的捷径。⇒ 路由器必须在**多数任务**上都对，不能靠少数长尾；这也解释了为什么粗粒度分族会亏。

> **数据边界**：以上全部来自 `unibot.unitree.com/leaderboard_data.json` 的 teaser 快照（页面脚本自承 randomly-generated）。它只能证明「这套检验方法可用」以及「IP-01 的红利尚未被证明」，不能证明真实榜单也如此。第 1 轮已声明过这一点，本轮把这条纪律写进预注册。

## 3. 研究问题（第 2 轮版）

- **Q6（路由泛化的可检验性）**：在不用目标任务表现信息的条件下，任何路由器的 LOTO 增益能否 ≥25% oracle？若不能，IP-01 是否应永久降级为「单专家 + 相位条件化」？
- **Q7（失效签名可否预测）**：`z_fail` 能否从观测（腕部 / 头部帧 + 语言）在线预测，且其预测误差与「路由后悔值」单调相关？
- **Q8（抓握验证的可保证性）**：在只有 1 维夹爪标量、无触觉、且存在场景偏移的条件下，能否给出「误判抓稳率 ≤ α」的**有限样本保证**？主动微抬探测在什么条件下值得做？
- **Q9（人类可辨识度）**：只看与策略相同的观测，人类判断「抓住没有 / 会不会成功」的 AUC 是多少？若人类也低，是否说明被动验证的信息上限已到，必须主动探测？
- **Q10（泛化的轴归因）**：能否用匹配对反事实把「场景 B 比 A 差多少」分解到不变性 / 等变性 / 鲁棒性 / 组合性四条轴上，并给出各轴排序的稳定性？
- **Q11（用户测试的覆盖面）**：红队用户发现的失效模式，有多大比例能被代理评测复现或预测（覆盖率 `C`）？LODO（留一演示者）与真机泛化是否相关？

## 4. 设计原则（v2：P1–P8）

- **P1 单一计分货币**（继承）：一切改动必须能翻译成终态成功率。
- **P2 隐状态显式化**（继承）：抓握 / 接触 / 相位带置信度。
- **P3′ 失效条件化而非任务条件化**（修订）：条件变量以「能否用可部署特征预测」为准；`z_task` 只作先验，`z_fail` 才是路由与验证的主变量。每个专家必须在 ≥2 个任务或 ≥2 个失效因子上复用。
- **P4 推理期吸收偏移**（继承，收窄）：只保留 episode 内、只作用于小适配器；跨 episode 更新需书面合规确认。
- **P5 合规优先**（继承）。
- **P6 单模型、单 checkpoint、单 API**（继承）。
- **P7 用户测试四轴**（新增）：演示者 / 红队 / 人类判读 / 评测端，四条轴各自有独立验收指标；缺任一条，泛化结论不成立。
- **P8 变换群分离**（新增）：nuisance 用不变性、task pose 用等变性、disturbance 用鲁棒性、unseen object 用组合性；不允许同一种增强同时承担两种承诺。

## 5. MVP v2 与退化链

**MVP v2 = IP-06′（六因子 + 红队覆盖） + IP-02′（主动抓握验证 + conformal 风险控制） + IP-10（场景阶梯 + 匹配对归因） + IP-03（chunk 缝合，保留） + 通用 VLA 基线。**

变化：IP-01 移出 MVP（P0→P1）；IP-02 升级为主动形态；新增 IP-10。理由：本轮证据表明 IP-01 的红利未被证明，而 IP-02 的误判风险第一次可以被「有保证」地压住。

**退化链 v2（在第 1 轮基础上新增两级）**：

- Level-0 场景轴分类器不可用 ⇒ 退回「按官方 5 类粗分」；
- Level-1 conformal 校准集不足 / 权重有效样本量 `< n_min` ⇒ 退回固定 `τ_conf`（第 1 轮形态）并标记 `no_guarantee`；
- Level-2 主动探测 `EVoI ≤ 0` 或探测预算耗尽 ⇒ 退回被动验证；
- Level-3 红队覆盖不达标 ⇒ 代理评测只作相对排序，不作绝对成功率预测；
- Level-4 路由泛化不达标 ⇒ 单专家 + 相位条件化（IP-01 的合规下界）；
- Level-5 整条新链路失效 ⇒ 纯基线（安全网）。

## 6. 预期贡献 v2

1. **一个否证性结果**：给出「任务 oracle 红利 ≠ 可部署路由红利」的可复现检验（可部署下界 / 泄漏上界的夹逼），并把 IP-01 的 +4.26 从「卖点」降级为「未验证上界」。
2. **一个有保证的抓握验证器**：把抓握误判从「调阈值」变成「分布无关风险控制」，并给出主动微抬探测的 EVoI 判据。
3. **一套场景泛化的轴分解**：不变性 / 等变性 / 鲁棒性 / 组合性的分离训练目标 + 匹配对归因估计量，替代「5 类场景一锅炖」。
4. **一套用户测试协议**：演示者 LODO、红队覆盖、人类判读 AUC、评测端故障注入四条轴的指标与操作定义。
5. **可复用的代理评测 v2**：把第 1 轮的六因子诊断升级为「预测 + 覆盖 + 与真机锚定」三件套。

## 7. 下一轮迭代计划

- **深化**：把 IP-02′ 的 conformal 阈值从「单阈值」升级为「按失效因子分层阈值」（grasp / align / insert 各自 `α`）；把 IP-10 的匹配对从图像级升级到「仿真复现 + 真机配对」。
- **验证**：优先做 Q9（人类判读 AUC）与 Q6（有效路由），这两个实验最便宜、最能决定其余投入。
- **修剪**：若 LODO 与真机泛化无关（`|r|<0.3`），把 LODO 从主评估降为数据卫生检查；若红队覆盖 `<0.5`，代理评测只保留相对排序功能。

## 8. 本轮最大风险（一句话）

**最大风险是：本轮把「IP-01 降级」和「conformal 有保证」两个大动作都建立在 teaser 表与可交换性假设上——若真实榜单结构不同，或未见场景落在校准支撑之外（密度比权重有效样本量趋零），我们就会在最需要保证的地方得到一张空保证，同时错误地砍掉唯一有量化上界的红利。**

# 第 2 轮产物 · UniBot-SAGE v2：从「任务泛化」到「失效泛化」

> **基线**：第 1 轮 UniBot-SAGE v1（IP-01…IP-08；定义 U1–U12；引理 L1–L7；实验 E601–E618）。本轮为 v2，**不重开基线**。
> **变更一句话**：把「任务 token 路由」降级为未验证上界，把「场景泛化」拆成不变性 / 等变性 / 鲁棒性 / 组合性四条轴，把「用户测试」拆成演示者 / 红队 / 人类判读 / 评测端四条轴，并把抓握验证升级为「主动探测 + 共形风险控制」。
> **数据纪律**：所有榜单数字来自 `unibot.unitree.com/leaderboard_data.json` 的 **teaser / 占位表**（页面脚本自承由 `gen_leaderboard.py` randomly-generated；本地转录快照 2026-11-02，见 `exp/r16/lb_data.py`）。本轮新增实验同样只作用于该 teaser 结构；它们是**方法学证据**，不是真实世界证据。

## 0. 本轮结论摘要

**一句话路线**：v1 的三层栈（接地 / 技能 / 适应）保留，但把「技能层」的条件变量从 `z_task` 换成 `z_fail`，把「适应层」的单一上下文向量拆成四个变换群，把「接地层」的抓握判定从固定阈值换成**有分布无关风险保证的主动验证**。

**四条结论**：

| 结论 | 证据 | 动作 |
|---|---|---|
| **路由红利 ≠ 可部署红利** | teaser 上可部署文本 LOTO 路由 −4.03；含泄漏画像上界 +3.02；粗粒度失效族最多 +1.11 | IP-01 P0→P1；预注册 <25% oracle 即永久降级 |
| **语义相似 ≠ 失效相似** | 文本 1-NN 25.67 vs 画像 3-NN 32.71 | 条件变量改为 `z_fail`；语言只作先验 |
| **抓握误判可以被「保证」压住** | 共形风险控制 + 主动微抬；EVoI 闭式判据 | IP-02 升级为 IP-02′（P0） |
| **场景泛化必须按群分开** | 位置需等变、背景需不变、人扰需鲁棒、未见物需组合 | 新增 IP-10（P0）；IP-04 收窄并入 |

**保留的合规红线（P5/P6）**：单 checkpoint、单 API；不用评测侧私有信息；不做读题硬编码；跨 episode 在线更新未经书面确认不启用。

## 1. 变更总表（v1 → v2）

## 2. 创新点详述

### IP-02′ · ActiveGrasp-CRC：主动抓握验证 + 共形风险控制（P0，升级）

- **动机**：v1 的最大风险是抓握误判的不对称成本——「没抓住却以为抓住」会把可救失败变成硬超时；而 v1 只有一个手工阈值 `τ_conf`，在未见物品上必然漂移。本轮把这个问题改写成**带风险约束的决策问题**：我们要控制的是 `P(声明已抓稳 ∧ 实际未抓稳) ≤ α`，而不是「分类准确率」。
- **与现有方案的差异**：现有做法是训一个抓握分类器再拍阈值；我们做三件事：①用**划分式共形风险控制**选阈值，使误判抓稳率在可交换性下有有限样本保证；②用**密度比加权**把校准集从训练分布搬到测试分布，并显式报告有效样本量 `n_eff`；③当被动后验落在「不确定带」时，执行一次**微抬探测**（2–5 mm 抬升，作为普通动作块下发），用物体是否随臂运动获得近似真值。
- **技术可行性**：高。三信号（腕部帧 / 夹爪标量 / EE 速度）都在观测里；微抬是动作空间内的合法动作；共形校准只需要一个小的带标签校准集（可用数据中的间接真值 + 少量真机/仿真标注）。
- **所需资源**：检测器单卡数小时；校准集离线可做；在线开销 <6 ms。
- **落地步骤**：
  1. 生成抓握伪标签：夹爪闭合后「物体相对腕部位移与 EE 位移一致」→ `y=1`；否则 `y=0`；在 3 个难任务上人工抽检 300 例。
  2. 训练得分器 `s_t`（ResNet18/ViT-S 级）；输出校准前的 `P(grasped)`。
  3. 划分校准集 / 测试集；用共形风险控制选 `τ̂`，目标 `α=0.02`；画可靠性图。
  4. 在 OOD 变体（换背景/换物体/加干扰）上估计密度比 `w(o)`（域分类器 + 权重截断），做加权校准；报告 `n_eff`；`n_eff < n_min` 时标记 `no_guarantee` 并退回固定阈值。
  5. 实现 EVoI 探测判据（见 L11）；只在 `EVoI > c + δ·p·L_dislodge` 时微抬；每 episode 探测次数上限 3。
  6. 失败响应：重抓（≤3 次）→ 换抓法 → 非抓取原语（push/sweep/tilt/topple/hook）。
- **风险**：①未见物品可能落在校准支撑之外，导致加权保证退化（见 L10/R1）；②微抬可能把「勉强抓住」抖掉（`δ` 必须按任务实测）；③伪标签噪声会让共形保证作用于「伪标签真值」而非物理真值——必须在真机上做一次小规模一致性校验（E623）。

### IP-10 · ScenarioLadder：群分离的场景泛化（P0，新）

- **动机**：官方 5 类泛化场景不是 5 个同质扰动，而是 4 种不同的数学承诺（位置=等变、背景/干扰物=不变、未见物=组合、人扰=鲁棒）。v1 的 IP-04 用一个上下文向量 `c` 统一调制，会把「该忽略的」和「该跟踪的」混在一起。
- **与现有方案的差异**：常见做法是「把所有增强混在一起做域随机化」；我们把增强按群分开，并给每一类配一个**对应的损失**与**对应的评估轴**：
  - 不变性：`L_inv = ‖π(g_n·o) − π(o)‖²`（只对 nuisance 群 `G_n`）；
  - 等变性：`L_eq = ‖π(g_t·o) − g_t·π(o)‖²`（只对任务相关群 `G_t`）；
  - 鲁棒性：`L_rob = max_{‖d‖≤ε} ℓ(π, o+d)`（人扰/动态扰动，可用 PGD 或对抗扰动近似）；
  - 组合性：object-centric 表示 + 未见物留出（不做「不变」也不做「等变」，而是要求可重组）。
- **评估协议（两层，避免把「视觉敏感」误当「闭环成功」）**：
  - **Tier A（离线，便宜）**：匹配对**视觉敏感度**测试——只改图像、不改动力学。它的作用是**否证捷径**（例如改背景后动作大变 ⇒ 背景泄漏），不是预测成功率。
  - **Tier B（闭环，贵）**：在仿真或真机上做**匹配对反事实**——同一初始配置，只变一条轴，测成功率差 `Δ_a`。只有在 Tier B 上，`Δ_a` 才能被解释为该轴的因果效应（L13）。
- **技术可行性**：中。Tier A 用分割/修复/粘贴即可；Tier B 需要仿真复现或真机配对，成本高但可通过「每轮 2–3 个真机时段」摊薄。
- **所需资源**：Tier A 单卡；Tier B 仿真中等算力 + 少量真机。
- **落地步骤**：
  1. 建立 4 轴增强器与 4 个独立评估集；严禁跨轴混用。
  2. 训练四个消融组：baseline / +inv / +eq / +inv+eq；确认「位置轴靠等变、背景轴靠不变」。
  3. 实现匹配对生成器与 `Δ_a` 估计（bootstrap 置信区间）。
  4. 在 5 类官方场景上给出**阶梯排序**（哪条轴最弱），并与 IP-06′ 的六因子对齐。
  5. 把上下文向量 `c` 降级为「轴分类器的辅助输入」，不再单独承担调制。
- **风险**：①Tier A 的视觉敏感度与 Tier B 成功率可能不相关（这正是 v1 的代理失真风险）；②等变约束若过强，会限制策略使用「非几何」线索（如摩擦/材质），需用软约束；③人扰的对抗训练可能降低正常任务成功率，必须设"正常集不降"闸门。

### IP-09 · DemoAudit：演示者留一法（P1，新）

- **动机**：训练数据是人遥操的；「用户」首先是演示者。若策略学到的是某个操作员的手感（速度、平滑度、抓握时机、双臂偏置），那么在自主评测中就会暴露。v1 的 IP-06 只按物体/背景/位置切分，缺了「按人切分」。
- **与现有方案的差异**：把「人」显式当作域：从动作轨迹提**风格指纹** `φ_op`，聚类成演示者簇，做 leave-one-demonstrator-out（LODO）；定义**演示者泄漏缺口** `LG`；若 `LG` 大，则用风格对抗/风格增广去偏。
- **技术可行性**：中。LeRobot 元数据未必有 operator id；需要从动作统计推断，并用「时间连续性 / 录制会话」做外部校验。若官方能提供 operator/session 字段，成本大幅下降（建议向组委会申请）。
- **所需资源**：离线，单卡数小时；无需真机。
- **落地步骤**：
  1. 指纹：jerk 均值/方差、路径长度、最大速度、抓握闭合相对到达顶点的时间、双臂对称性、停顿分布。
  2. 聚类：GMM + BIC 选 K；用 split-half ARI 与「相邻 episode 同簇率」验证稳定性；若稳定性和时间连续性都差，则判定「无法可靠恢复演示者」，LODO 降级为「按录制会话留出」。
  3. LODO：留一簇训练/评估，测 `LG`；同时测「留一物体」「留一背景」作为对照，看 `LG` 是否独立于已知轴。
  4. 去偏：风格对抗头（梯度反转）或风格增广（重采样速度/平滑度）；用 E627 验证 `LG` 是否下降且正常集不降。
- **风险**：①聚类可能是「任务阶段」而非「人」（用任务内聚类与时间连续性排除）；②LODO 与真机泛化的相关性未知——这是 P1 而非 P0 的原因；③去偏可能损害动作多样性，需保留策略固有随机性（与 IP-08 的「不过度规律」一致）。

### IP-11 · RedTeam：红队用户测试 + 人类判读（P1，新）

- **动机**：「用户测试」的第二种用户是**对抗性用户**，第三种是**人类判读者**。前者发现代理评测漏掉的失效，后者给出「信息在观测里到底可不可读」的上限。
- **与现有方案的差异**：多数队伍只做「自测通过」；我们把用户测试做成**可计量的协议**：
  - 红队：非开发者用户按任务清单主动制造失败；双人编码进六因子（+other）；计算代理评测对红队失效的**覆盖率 `C`**；用 `C` 修正绝对成功率或降级为相对排序。
  - 人类判读：给人类看与策略相同的腕部帧 + 夹爪标量（不含触觉），判断「抓住没有 / 会不会成功」；记 `AUC_h`；与 IP-02′ 的验证器 AUC 对比。
  - 评测端：故障注入矩阵（端口数变化 / 乱序 / token 错 / reset 重入 / 延迟尖峰 / 重复 get）——这是 IP-08 的扩展。
- **技术可行性**：高（协议与统计，不需要大算力）。人类判读可用小规模内部用户（n≥5，每人 ≥30 段）完成。
- **所需资源**：人力为主；红队需要真机或高保真仿真时段。
- **落地步骤**：
  1. 预注册红队任务与编码手册；双人编码 20% 样本，Cohen's κ ≥0.7 才继续。
  2. 计算 `C` 与「代理评测漏检率」；把红队场景回灌到 IP-10 的 OOD 集。
  3. 人类判读实验：平衡成功/失败片段；报告 `AUC_h`、置信区间、以及「人类一致但模型错」的子集。
  4. 若 `AUC_h` 显著高于验证器，说明验证器还有上限空间；若两者都低，则把预算转向主动探测（IP-02′）。
- **风险**：①小样本用户研究的 external validity 有限；②红队失效分布与官方评测分布可能不同（用 `C` 的置信区间与场景覆盖来约束结论）；③人类判读受「视频剪辑偏差」影响（用随机顺序、双盲）。

### IP-01′ · Failure-Conditioned Experts（P1，降级 + 重定义）

- **动机**：teaser 的 +4.26 是 per-task oracle，不是可部署红利。本轮边界测试表明：可部署的文本相似度路由是负收益，含泄漏的画像路由才有正收益，粗粒度失效族最多拿到 +1.11。因此 v1 的「任务 token 路由」必须降级。
- **新形态**：专家不再按「32 个任务」划分，而按「失效因子」划分（reach / grasp / transport / align / insert / release）；条件变量 `z_fail = h(o,ℓ)` 预测当前最可能失败的因子；专家选择 `e = argmax_k score_k(z_fail)`，且当 `max_k z_fail < τ_fail` 时退回通用专家。
- **与现有方案的差异**：不是「任务分类器 + 多模型」，而是「失效预测器 + 单 checkpoint 内的技能头」；这让专家可以在任务间复用（P3′），也把「路由」变成「预测下一步最可能坏在哪」。
- **可行性**：中。需要可靠的失效伪标签（IP-06′ 提供）；若 `z_fail` 预测不准，退回单专家。
- **预注册杀点**：若真实数据上可部署 LOTO 路由的 oracle 捕获 <25%，或 `z_fail` 预测与路由后悔值的 Spearman `|ρ| <0.3`，则**永久降级**为「单专家 + 相位条件化」，不再投入 MoE。
- **风险**：①专家退化（用 P3′ 的「≥2 任务复用」与专家间输出坍缩度监控）；②合规（多专家是否算单模型，需书面确认；预备单专家降级形态 E634）；③失效标签噪声（双标注器一致性）。

### IP-06′ · FailureBench：六因子 + 失效预测 + 红队覆盖（P0，升级）

- **动机**：v1 的六因子只是「事后诊断」；v2 要求它同时供给三件事：①路由条件 `z_fail`；②验证器的分层阈值；③代理评测的覆盖修正。
- **与现有方案的差异**：从「分解成功率」升级为「预测失效 + 覆盖真实失效 + 与真机锚定」三件套：
  - 六因子阶段标注（继承 v1：规则 + VLM + 人工抽检）；
  - 训练 `z_fail` 预测器（输入观测 + 语言，输出六因子概率）；
  - 红队覆盖 `C`（IP-11）；
  - 真机锚定：每轮 2–3 个时段，估计「代理指标 ↔ 真机成功率」的 Spearman `|r|`，并报告 `C` 修正后的绝对误差。
- **落地步骤**：继承 v1 的 E601–E602，新增 `z_fail` 预测（E620）、红队覆盖（E629）、覆盖修正后的绝对校准（E640）。
- **风险**：六因子在「未见物」上的标注漂移；覆盖 `C` 的估计依赖红队采样分布；若 `|r|<0.3` 或 `C<0.5`，退回「只作相对排序」。

### IP-03 · ChunkStitch（P0，保留）

- 不变。新增一项交叉验证：在 IP-10 的匹配对评估中，把「chunk 边界失配」作为一个协变量，确认它不是 `Δ_a` 的混杂因素（尤其位置轴，chunk 边界抖动会伪装成等变性差）。

### IP-04′ · ContextAdapter（P1，收窄）

- 不再单独做「5 类场景 → 一个 c」；只保留：episode 前 1–3 s 估计 `c`，作为 IP-10 轴分类器的**辅助输入**；FiLM 调制量受 `ρ` 约束（继承 L6）；跨 episode 更新不启用。其价值由 E612 重估：若在轴分离后 `c` 的边际贡献 <0.5 分，则并入 IP-10，不再单列。

### IP-05 / IP-07 / IP-08

- IP-05 暂存（pivot 语义零成本探测后再定）。
- IP-07 暂存（无新证据）。
- IP-08 微扩：在原有延迟/jerk/端口隔离之外，增加**评测端故障注入矩阵**（端口数 1/2/4/8、乱序、token 错、reset 重入、重复 get、延迟尖峰 100/200/500 ms），并输出「降级策略触发率」报告。

## 3. 符号与定义（U13–U24，续 U1–U12）

| 符号 | 含义 |
|---|---|
| `φ_op(e)` | 演示者风格指纹：episode `e` 的动作统计描述子 |
| `R_train, R_test` | 训练 / 留出的演示者簇集合 |
| `LG` | 演示者泄漏缺口（LODO gap） |
| `G_n, G_t` | nuisance 群 / 任务相关变换群 |
| `B_ε` | 扰动球 `{d : ‖d‖ ≤ ε}` |
| `Δ_a` | 场景轴 `a` 的匹配对成功率差 |
| `z_fail` | 六因子失效签名（预测向量） |
| `s_t` | 抓握得分（校准前） |
| `R(τ)` | 抓握误判风险 `P(y=0, s≥τ)` |
| `τ̂` | 共形选出的阈值 |
| `w(o), n_eff` | 密度比 / 有效样本量 |
| `u_probe` | 微抬探测动作 |
| `EVoI` | 探测的期望信息价值 |
| `AUC_h` | 人类判读 AUC |
| `F_rt, C` | 红队失效集 / 代理覆盖率 |
| `G_deploy, G_leaky` | 可部署路由增益 / 泄漏上界增益 |
| `Λ` | 场景轴的阶梯排序 |

**定义 U13（演示者指纹）** `φ_op(e) = ψ({a_t}_{t=1}^T)`，其中 `ψ` 取 jerk 均值/方差、路径长度、最大速度、抓握闭合相对到达顶点的时间、双臂对称性、停顿分布的拼接。
**定义 U14（演示者泄漏缺口）** `LG = E_{r∈R_train}[Succ(π)] − E_{r∈R_test}[Succ(π)]`，`R_test ∩ R_train = ∅`。
**定义 U15（场景轴与群）** `A = {inv, eq, rob, comp}`；`inv` 对应 `G_n`（外观/背景/干扰物），`eq` 对应 `G_t`（目标位姿的平移/旋转），`rob` 对应 `B_ε`（动态扰动），`comp` 对应未见物体的组合外推。
**定义 U16（匹配对归因）** `Δ_a = E[Y(o)] − E[Y(g_a·o)]`，`g_a` 只作用于轴 `a`；归因向量 `Δ = (Δ_inv, Δ_eq, Δ_rob, Δ_comp)`。
**定义 U17（失效签名）** `z_fail = h(o, ℓ) ∈ [0,1]^6`，分量为 reach/grasp/transport/align/insert/release 的失效概率；`ẑ_fail` 为在线预测。
**定义 U18（抓握风险与阈值）** `R(τ) = P(y=0, s ≥ τ)`；`τ̂` 由划分式共形风险控制在置信水平 `1−α` 下选出。
**定义 U19（密度比与有效样本量）** `w(o) = p_T(o) / p_C(o)`；`n_eff = (Σ_i w_i)² / Σ_i w_i²`；`w` 截断于 `w_max`。
**定义 U20（主动探测与 EVoI）** `u_probe` 为微抬动作；`EVoI(p) = R_0(p) − E_Y[R_1(p|Y)]`，其中 `R_0` 为不探测的 Bayes 风险，`R_1` 为观测探测结果后的 Bayes 风险。
**定义 U21（人类可辨识度）** `AUC_h`：人类在「只看腕部帧 + 夹爪标量」条件下判断抓握成功的 ROC 曲线下面积。
**定义 U22（红队覆盖）** `C = Σ_{f∈S} p(f)`，`S` 是代理评测能复现/预测的红队失效子集，`p` 为红队失效频率分布。
**定义 U23（路由泛化上下界）** `G_deploy` 为只用可部署特征的 LOTO 增益；`G_leaky` 为用留出任务自身画像的 LOTO 增益；捕获率 `= G_deploy / (oracle − best_single)`。
**定义 U24（场景阶梯）** `Λ` 为四轴 `Δ_a` 的降序排列，用于定位「当前最弱轴」。

# ===== IP-02′：共形校准 + EVoI 主动探测 =====
class GraspRiskController:
    def __init__(self, alpha=0.02, n_min=50, w_max=20.0, probe_budget=3):
        self.alpha, self.n_min, self.w_max = alpha, n_min, w_max
        self.probe_budget = probe_budget
        self.scores, self.labels, self.weights = [], [], []
        self.tau = 0.5            # 未校准时的安全默认（高精度）

    def score(self, obs):
        # 三信号：腕部几何贴合 / EE 随动 / 夹爪开合差分
        return self.net(obs)      # 校准前的 P(grasped)

    def calibrate(self):
        """划分式共形风险控制：选最小的 τ 使加权误判率 ≤ α。
        R(τ) = Σ w_i·1{y_i=0, s_i≥τ} / Σ w_i
        τ̂ = inf{τ : n_eff/(n_eff+1)·R̂(τ) + 1/(n_eff+1) ≤ α}
        n_eff = (Σw)²/Σw²；n_eff < n_min ⇒ 标记 no_guarantee，退回固定阈值。
        """
        if effective_n(self.weights) < self.n_min:
            self.tau = FIXED_TAU
            self.mode = "no_guarantee"
            return
        self.tau = conformal_risk_threshold(self.scores, self.labels,
                                            self.weights, self.alpha)
        self.mode = "guaranteed"

    def decide(self, obs, p, cost):
        s = p
        # 1) 先看被动后验是否落在不确定带
        evoi = exp_value_of_info(p, cost.L_FN, cost.L_FP,
                                 cost.q_sens, cost.q_spec)
        if (self.probe_budget > 0 and
                evoi > cost.c_probe + cost.delta * p * cost.L_dislodge):
            self.probe_budget -= 1
            return ("PROBE_MICRO_LIFT", None)      # 2–5 mm 抬升动作
        # 2) 未探测：按共形阈值决策（s 低 ⇒ 认为未抓住 ⇒ 重抓）
        if s < self.tau:
            return ("REGRASP", s)
        return ("CONTINUE", s)

    def observe_probe(self, moved_with_arm, s):
        """探测结果只用于下一次抓握的保守再校准，不反悔当前决策；
        同一条数据的自适应复用会破坏可交换性，故不宣称当前决策的保证。"""
        self.labels.append(1.0 if moved_with_arm else 0.0)
        self.scores.append(s)
        self.calibrate()


# ===== IP-10：群分离训练（四个损失分开） =====
def group_separated_loss(pi, batch):
    o, a, lang = batch.o, batch.a, batch.lang
    loss_bc = bc_loss(pi(o, lang), a)
    g_n = sample_nuisance_transform()            # 背景/光照/干扰物
    g_t = sample_task_transform()                # 目标位姿平移/旋转
    loss_inv = mse(pi(g_n(o), lang), pi(o, lang))
    loss_eq  = mse(pi(g_t(o), lang), apply_group(g_t, pi(o, lang)))
    loss_rob = worst_case_loss(pi, o, lang, eps=batch.eps)   # PGD / 对抗扰动
    return (loss_bc + lam_inv * loss_inv + lam_eq * loss_eq
            + lam_rob * loss_rob)

def failure_route(pi, obs, lang, tau_fail=0.4, single_expert=False):

## 5. 推导（L8–L14，续 L1–L7）

**引理 L8（演示者缺口的分解）** 设演示者 `r` 的条件分布为 `p_r(o,a)`，训练/留出演示者集合为 `R_in, R_out`。则
`R_in(π) − R_out(π) = ∫ ℓ(o,a,π) [Σ_{r∈R_in} w_r p_r − Σ_{r∈R_out} w_r p_r]`。
若风格只改变 nuisance（标签保持），则 Bayes 风险相同，缺口完全由有限样本与风格过拟合构成；若风格与标签相关（例如某演示者总从上方抓而成功率更高），则缺口还包含**伪相关项**。故 `LG` 是有效的审计量，但**不能**直接解释为「真机成功率一定会掉」——真机上没有演示者，只有策略。∎

**引理 L9（不变/等变的不可互换）** 设表示 `Φ` 对任务相关群 `G_t` 不变：`Φ(g·o)=Φ(o), ∀g∈G_t`。则对任意只依赖 `Φ` 的策略，`π(g·o)=π(o)`；若成功集 `S_g` 随 `g` 变化且 `⋂_g S_g` 在连续位姿空间上测度为零，则期望成功率 ≤ `P(a(o) ∈ ⋂_g S_g) = 0`。反之，若对外观群 `G_n` 要求等变而非不变，则背景变化会无谓地改变动作。⇒ 正确的约束由群决定，不能一律「不变」或一律「域随机化」。∎

**引理 L10（共形风险控制的保证与失效）** 在可交换性下，划分式共形风险控制取
`τ̂ = inf{τ : n/(n+1)·R̂_n(τ) + 1/(n+1) ≤ α}`
则 `E[R(τ̂)] ≤ α`。在协变量偏移下，用密度比 `w(o)=p_T/p_C` 加权，令 `R̂_w(τ)=Σ w_i ℓ_i / Σ w_i`，有限样本修正以 `n_eff=(Σw)²/Σw²` 代替 `n`。若 `p_T` 的支撑不被 `p_C` 覆盖（未见物品最可能如此），或 `n_eff < n_min`，则保证变为空（vacuous）。⇒ 必须显式报告 `n_eff` 并准备 `no_guarantee` 降级。∎

**引理 L11（探测的 EVoI 与闭式阈值）** 记 `p=P(G=1|o)`，`A=L_FN`（未抓住却继续的损失），`B=L_FP`（抓住却重抓的损失），`A>B`。不探测的 Bayes 风险 `R_0(p)=min{(1−p)A, pB}`，决策阈值 `p*=A/(A+B)`。对称探测（灵敏度=特异度=`q`）下，`EVoI(p)=R_0(p)−E_Y[R_1(p|Y)]`。特别地，在最大不确定点 `p=1/2`：
`EVoI(1/2) = max{0, (A+B)(q − p*)/2}`。
⇒ 探测只有在「探测准确率 `q` 超过成本比阈值 `p*`」时才值得；否则再准的探测也改变不了决策。一般 `p` 下，探测有值区间是一条围绕 `p*` 的带；例：`A/B=5, q=0.9` 时带宽约 `0.615`（`p∈[0.36, 0.975]`）。计入探测成本 `c` 与抖落风险 `δ` 后，条件是 `EVoI > c + δ·p·L_dislodge`。∎

**引理 L12（路由的可部署性判据）** 设专家 `e` 在任务 `t` 上的优势为 `Δ_e(t)`，路由器用可部署特征 `x(t)` 选 `e(t)`。若 `Cov(Δ_e(t), x(t)) = 0, ∀e`，则对任意只依赖 `x` 的路由器，
`E[Δ_{e(t)}(t)] ≤ max_e E[Δ_e(t)]`，
即路由不优于「永远选一个最好的常量专家」，且额外引入方差。⇒ 可部署路由的必要条件是「失效优势与可部署特征相关」；teaser 上文本特征给出负收益，正是这一判据的反例。∎

**引理 L13（匹配对归因的可识别性）** 在 SUTVA 与「只改一条轴且动力学正确」的前提下，`Δ_a = E[Y(o)] − E[Y(g_a·o)]` 是轴 `a` 的平均因果效应，且可用配对设计无偏估计。若只改图像而不改动力学（Tier A），则观测到的是「视觉敏感度」而非成功率差；二者只有在策略对视觉变化完全敏感且动力学不变时才一致。⇒ Tier A 只能用于否证捷径，Tier B 才能用于归因。∎

**引理 L14（红队覆盖对绝对估计的约束）** 设红队失效集在部署失效分布下的频率为 `p(F_rt)`，代理能复现的子集为 `S`，覆盖率 `C=p(S)`。若被忽略的失效在部署中必然失败，则代理高估的成功率至少为 `(1−C)·p(F_rt)`（忽略被忽略失效在代理中也被判成功的部分）。⇒ `C<0.5` 时代理只能报相对排序；报绝对成功率必须做覆盖修正并给出区间。∎

## 9. 本轮实验结果：路由泛化的上下夹逼（teaser 结构）

**问题**：v1 的 `oracle − best_single = +4.26` 是否可被一个只用测试时可得信息的路由器兑现？

**方法**：在同一张 teaser 表（8 模型 × 32 任务）上做留一任务（LOTO）路由，比较三类信息：
1. **可部署**：任务名文本相似度（token Jaccard / 字符 3-gram Jaccard），选最近任务上的最优模型；
2. **泄漏上界**：用留出任务自身的跨模型表现画像算相似度（使用目标信息，仅作上界）；
3. **粗粒度失效族**：K-means 聚类任务画像，已知簇归属，簇内留一任务选专家。

**读法**：
1. **可部署文本路由是负收益** ⇒ 语义相似不是失效相似；IP-01 的任务 token 假设在 teaser 上不成立。
2. **泄漏画像路由捕获 37%–71%** ⇒ 若有一个好的失效画像预言机，路由红利存在；但它必须用可部署特征预测，不能偷看目标表现。
3. **粗粒度失效族最多 26%** ⇒ 红利的来源是任务级特异，不是「两三个通用技能族」；这也解释了为什么 K=3 反而变负（聚类把互补的专家混在一起）。
4. **红利弥散** ⇒ 路由器要在多数任务上正确，不能只修长尾；E633 的 25% 捕获门槛是保守但有意义的杀点。
