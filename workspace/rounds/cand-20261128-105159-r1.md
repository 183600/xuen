### 第 8 轮灵感驱动研究记录

**灵感词**：三维感知、多模态大模型

**继承关系**：第 7 轮 CADVS-v7（IP-501~IP-504）以 DIM/DRC/DAC 把系统从「指令响应」推进到「需求推导」，EFA-v7 在七硬门与 kc_demand 上叠加软因子链。但 v7 的两个核心模块都活在「符号/嵌入空间」：DRC 用自由文本推理链，STM 把语言映射为查询向量，却从不检验指令与推理里提到的物体、关系、区域在**度量三维世界**里是否真的存在、位置是否吻合。结果是：一段流畅但臆造的空间前提，可以因为「轨迹本身几何合法」而穿过七硬门——硬门检查的是轨迹的几何，不是前提的锚定。本轮聚焦「**语言-三维锚定桥**」：用三维感知把 MLLM 的每一条空间断言变成**可证伪的三维锚点**，再用 MLLM 把三维场景图变成**可用语言查询的词典**。不新增硬门，只把「证据必须可三维锚定」写进既有 kc_val 的完备性语义。

**直觉与动机**：

1. **三维感知 → 从「几何否决器」到「可查询的语义-几何词典」**。v7 的 GGC/MCTM 是在候选轨迹生成之后做几何否决：能挡掉「撞墙」，挡不掉「抓一个不存在的杯子」。关键洞见是：**感知的第一性作用不是 veto，而是 grounding**——它应把指令中的每个名词、关系、区域绑定到一个可度量的三维支撑集（点云、位姿协方差、关系置信度）。于是「杯子在桌上」不再是一句话，而是一个带真值、带证据出处的三维查询。设计「度量-语义三维场景图」(MS3G)：节点带 SE(3) 位姿、协方差、包围盒、开放词表语义嵌入与可供性；边带 support/contain/occlude/reachable 等类型与置信度；并随视角增量维护。

2. **多模态大模型 → 从「自由文本推理链」到「可锚定的类型化空间程序」**。v7 的 DRC 用 CoT + token 熵衡量置信度，这把「说得顺」误当成「说得对」。关键洞见是：**幻觉应当表现为绑定失败，而不是藏在散文里**。强制 MLLM 输出类型化的空间程序（DSL）：每个符号要么绑定到场景图节点/区域，要么显式标记为 unknown；谓词的类型与元数必须可检查。设计「空间锚定绑定器」(SGB)：把每条断言绑定到 Top-k 锚点，计算语义支撑 s_sem、几何支撑 s_geo、关系支撑 s_rel，并统计「无锚质量」u。这样幻觉从「不可观测的语义错误」降级为「可审计的绑定空洞」。

3. **二者交汇 → 多视角一致性作为「无需标签的幻觉检测器」**。一个只在某一个视角成立的空间解释很可能是臆造。关键洞见是：**多视角三维一致性是一个内在的、免标注的「语义 vs 物理」判别信号**——纯文本侧永远给不出。设计「多视角一致性审计器」(MVC)：把重建场景与候选轨迹从 K 个视角渲染，检查锚点在各视角的语义一致性、重投影几何误差与遮挡违反；若一致性不足且还有预算，触发有界「下一最佳视角」(NBV) 主动补看，预算耗尽仍不足则 fail-closed。

4. **修补 v7 的单调性缺口**。v7 同时声称「软因子只收紧」又定义 η_affect ∈ [2/3, 4/3]，可小于 1 而放松阈值。本轮统一改用「质量因子 φ ∈ [0,1] + 保守乘子 m = 1+ε(1-φ) ∈ [1, 1+ε]」的对偶表示：φ 越低，m 越大，阈值只升不降，fail-closed 第一次可被严格证明。

**关键洞见**：第 7 轮回答「如何推导用户真正要什么」；第 8 轮回答「如何确保这份推导所谈的物体、关系与空间，在三维世界里真的存在，并且证书可追溯」。七硬门 kc_evidence_forged_v5 + kc_demand 原样复用，**不新增硬门**；本轮新增仅为感知-锚定层：
- IP-505 MS3G（度量-语义三维场景图），
- IP-506 SGB（空间锚定绑定器），
- IP-507 MVC（多视角一致性审计器 + 有界 NBV），
- IP-508 EFA-v8（三维锚定证书装配器）。

**形式化目标（增量）**：

1. **MS3G（Metric-Semantic 3D Scene Graph）**：<br>
   - G_t = (V_t, E_t, O_t)，节点 v=(id, μ_v∈SE(3), Σ_v, e_v, f_v, a_v)，边 e=(u, ρ, v, w)；<br>
   - O_t 为带可见性的点/面元/3DGS 重建；<br>
   - 增量更新：新帧到达时按体素哈希做数据关联，位姿用马氏门限匹配，未观测区域标记为 unobserved。

2. **SGB（Spatial Grounding Binder）**：<br>
   - MLLM 输出类型化空间程序 P=(c_1,...,c_n)，c_j=(x_j, pred_j, ρ_j, τ_j)；<br>
   - 绑定 B: c_j ↦ (v*_j, A_j, b_j)，A_j 为三维锚点集，b_j 为证据出处（像素/点/帧）；<br>
   - 断言支撑 s_j = min(s_sem,j, s_geo,j, s_rel,j)；<br>
   - 无锚质量 u = (1/n)Σ_j 1[s_j < τ_anchor]；<br>
   - 锚定质量 φ_gnd = (1-u)·(1/n)Σ_j s_j，经保序回归校准。

3. **MVC（Multi-View Consistency Auditor）**：<br>
   - K 个视角渲染 {I_k, D_k}，对每条断言计算语义分歧 d_k、重投影误差 e_k、遮挡违反 o_k；<br>
   - φ_view = clip(1 - Σ_k n_k(λ_d d_k+λ_e e_k+λ_o o_k)/Σ_k n_k, 0, 1)；<br>
   - 若 φ_view < τ_view 或 u > u_max，且 NBV 预算 B 未耗尽：选取最大化信息增益的视角补看；否则 fail-closed。

4. **EFA-v8（只收紧的三维锚定证书装配器）**：<br>
   - 质量因子 φ_j∈[0,1] → 保守乘子 m_j = 1+ε(1-φ_j)∈[1, 1+ε]，ε=0.3；<br>
   - τ_i^v8 = γ_i·τ_i^v7·m_gnd·m_view，全局上限 Π m_j ≤ T_max=1.3，超限即 fail-closed；<br>
   - 采纳只用阈值侧乘子；分数侧 ECS_v8 = ECS_v7·φ_gnd·φ_view 仅用于排序，避免重复惩罚；<br>
   - 证据完备性：kc_val 只接受带完整绑定证书 b_j 的断言；「assumed」类断言不得单独支撑硬门相关结论。

5. **形式化定义**：给定指令 L、场景图 G_t、候选轨迹 x：<br>
   - P = MLLM(L, G_t)，B = SGB(P, G_t)；<br>
   - 若 u > u_max 或 φ_gnd < τ_gnd：先 NBV，预算耗尽仍不满足则回退到 v7 需求导向路径；<br>
   - 否则按 τ^v8 运行 EFA-v7 七硬门 + kc_demand，接受需同时满足 φ_view ≥ τ_view 与证书完整。

**本轮最大风险**：**三维感知的「所见即所得」假设**：MS3G 只能锚定被观测到的三维证据，对遮挡、反光、透明、未探索区域在结构上是盲的——系统要么对「看不见但真实存在」的指称过度保守（回退风暴），要么默许 MLLM 先验填补空缺（幻觉回流）；证书恰恰可能在感知最弱的地方显得最自信。

## 2. 关键算法骨架

### IP-505 MS3G：度量-语义三维场景图

```python
@dataclass
class MetricSemantic3DSceneGraph:
    """MS3G：可语言查询、可增量维护的度量-语义三维场景图。"""
    encoder_txt: nn.Module          # 短语 -> 语义嵌入
    open_vocab_segmenter: nn.Module # 开放词表实例分割（可用 VLM 蒸馏）
    voxel_size: float = 0.02
    mahalanobis_gate: float = 3.0

    def update(self, frame: RGBDFrame, pose: SE3) -> None:
        pts = backproject(frame.rgb, frame.depth, frame.K, pose)
        self.O_t = self.fuse_points(self.O_t, pts)          # 体素哈希融合
        inst = self.open_vocab_segmenter(frame.rgb)
        for x in inst:
            v = self.associate(x, pts, pose)                # 马氏门限数据关联
            if v is None:
                v = self._new_node(x, pts, pose)
                self.V_t.add(v)
            self._update_node(v, x, pts, pose)              # μ,Σ,e,f,a 更新
        self._refresh_edges()                               # support/contain/occlude/reachable
        self._mark_unobserved(pose, frame)                  # 可见性反投影 -> unobserved

    def query(self, phrase: str, k: int = 5) -> list[Anchor]:
        q = self.encoder_txt(phrase)
        sims = [cos(q, v.f_v) for v in self.V_t]
        idx = np.argsort(sims)[-k:][::-1]
        return [Anchor(node=self.V_t[i], sim=float(sims[i])) for i in idx]

    def relation(self, u: Node, rho: str, v: Node) -> float:
        return self.E_t.get((u.id, rho, v.id), 0.0)

    def is_unobserved(self, region: Region) -> bool:
        return self.visibility_mass(region) < self.vis_min
```

### IP-506 SGB：空间锚定绑定器

```python
@dataclass
class SpatialGroundingBinder:
    """SGB：把类型化空间程序逐条绑定到三维锚点，输出 φ_gnd 与证据证书。"""
    llm: MultimodalLLM
    tau_anchor: float = 0.5
    calibrator: IsotonicCalibrator

    def parse_program(self, L: str, G: MS3G) -> SpatialProgram:
        """强制 MLLM 输出类型化 DSL；解析或类型检查失败 = 不可锚定。"""
        raw = self.llm.generate(L, schema=SPATIAL_DSL, scene_tokens=G.tokenize())
        prog = SPATIAL_DSL.parse(raw)
        typecheck(prog)                  # 谓词元数/类型/单位检查
        return prog

    def bind_claim(self, c: Claim, G: MS3G) -> Binding:
        cands = G.query(c.x)
        if not cands:
            return Binding(v=None, A=set(), s=0.0, kind='ASSUMED')
        v = cands[0].node
        s_sem = max(a.sim for a in cands)
        R = c.region if c.region is not None else v.extent_world()
        s_geo = (occupancy_iou(R, G.O_t) *
                 G.visibility_ratio(R))
        s_rel = G.relation(c.subject, c.pred, v) if c.subject else 1.0
        s = min(s_sem, s_geo, s_rel)
        if s_geo > 0 and G.visibility_mass(R) > 0:
            kind = 'OBSERVED'
        elif s_rel > 0:
            kind = 'INFERRED'
        else:
            kind = 'ASSUMED'
        return Binding(v=v, A=anchor_points(R, G.O_t), s=s, kind=kind)

    def score(self, prog: SpatialProgram, G: MS3G) -> GroundingResult:
        bs = [self.bind_claim(c, G) for c in prog.claims]
        n = max(1, len(bs))
        u = sum(1.0 for b in bs if b.s < self.tau_anchor) / n
        phi = (1.0 - u) * (sum(b.s for b in bs) / n)
        return GroundingResult(bindings=bs, u=u,
                               phi_gnd=self.calibrator.predict(phi))
```

### IP-507 MVC：多视角一致性审计器 + 有界 NBV

```python
@dataclass
class MultiViewConsistencyAuditor:
    """MVC：多视角语义/几何/遮挡一致性；不足时触发有界 NBV。"""
    renderer: GaussianRenderer
    mllm: MultimodalLLM
    tau_view: float = 0.6
    nbv_budget: int = 2
    lam_d: float = 0.5
    lam_e: float = 0.3
    lam_o: float = 0.2

    def audit(self, G: MS3G, prog, bindings, views: list[SE3]) -> ViewResult:
        num = den = 0.0
        per_view = []
        for xi in views:
            I, D = self.renderer.render(G.O_t, xi)
            for b, c in zip(bindings, prog.claims):
                if not visible(b, xi):
                    continue
                n_k = max(1, len(b.A))
                d_k = self.semantic_disagreement(I, b, c, xi)   # VLM/开放词表重描述
                e_k = self.reprojection_error(D, b, G.O_t, xi)   # 渲染深度 vs 观测深度
                o_k = self.occlusion_violation(I, D, b, xi)
                num += n_k * (self.lam_d*d_k + self.lam_e*e_k + self.lam_o*o_k)
                den += n_k
            per_view.append((xi, I, D))
        phi = 1.0 - (num/den if den > 0 else 1.0)
        return ViewResult(phi_view=max(0.0, min(1.0, phi)), views=per_view)

    def next_best_view(self, G, bindings, used: list[SE3]) -> SE3 | None:
        """在候选视角中最大化期望信息增益（降遮挡/降歧义）。"""
        cands = [x for x in self.candidate_views(G) if x not in used]
        if not cands:
            return None
        gains = [expected_info_gain(x, G, bindings) for x in cands]
        return cands[int(np.argmax(gains))]
```

### IP-508 EFA-v8：只收紧的三维锚定证书装配器

```python
@dataclass
class EvidenceForgingAssemblerV8:
    """EFA-v8：三维锚定 + 只收紧阈值；不新增硬门。"""
    v7: EvidenceForgingAssemblerV7
    ms3g: MetricSemantic3DSceneGraph
    sgb: SpatialGroundingBinder
    mvc: MultiViewConsistencyAuditor
    epsilon: float = 0.3
    T_max: float = 1.3
    tau_gnd: float = 0.6
    tau_view: float = 0.6
    u_max: float = 0.2

    def multiplier(self, phi: float) -> float:
        return 1.0 + self.epsilon * (1.0 - clamp(phi, 0.0, 1.0))

    def select(self, L: str, t_now, context):
        # 1) 类型化空间程序 + 三维绑定
        prog = self.sgb.parse_program(L, self.ms3g)
        g = self.sgb.score(prog, self.ms3g)

        # 2) 锚定不足 -> 有界 NBV；预算耗尽 -> fail-closed 回退 v7
        used = []
        while (g.u > self.u_max or g.phi_gnd < self.tau_gnd) and len(used) < self.mvc.nbv_budget:
            xi = self.mvc.next_best_view(self.ms3g, g.bindings, used)
            if xi is None:
                break
            self.ms3g.update(self.acquire(xi), xi)
            used.append(xi)
            g = self.sgb.score(prog, self.ms3g)
        if g.u > self.u_max or g.phi_gnd < self.tau_gnd:
            return self.v7.select(None, t_now, context)

        # 3) 多视角一致性
        v = self.mvc.audit(self.ms3g, prog, g.bindings,
                           self.mvc.views_for(context))
        if v.phi_view < self.tau_view:
            return self.v7.select(None, t_now, context)

        # 4) 证据完备性：critical 断言不得仅由 ASSUMED 支撑
        if any(b.kind == 'ASSUMED' for b, c in zip(g.bindings, prog.claims) if c.critical):
            return self.v7.select(None, t_now, context)

        # 5) 保守乘子只收紧阈值
        m = self.multiplier(g.phi_gnd) * self.multiplier(v.phi_view)
        if m > self.T_max:
            return self.v7.select(None, t_now, context)
        ok, x, tag = self.v7.select_with_tightening(L, t_now, context, m)
        if not ok:
            return ok, x, tag

        # 6) 分数侧仅用于排序，不参与可行性
        return True, x, f'{tag}+3D_GMC(phi_g={g.phi_gnd:.2f},phi_v={v.phi_view:.2f})'
```

### 集成流水线（v7 → v8）

```
离线/慢时域：
  MS3G 构建：RGB-D/LiDAR + 开放词表分割 -> 增量场景图（秒级）
  φ 校准：验证集上保序回归校准 φ_gnd / φ_view，冻结 τ_gnd / τ_view
  DSL 版本化：Schema + 类型检查器 + 回归测试；红队构造「空间幻觉陷阱」指令集

在线准入（快路径，目标 < 1.5 ms）：
  SGB.parse -> typecheck -> bind -> φ_gnd, u
  若 u > u_max 或 φ_gnd < τ_gnd：NBV（最多 B_nbv 次，异步补看）
  MVC 快路径：仅几何重投影 + 遮挡检查（不调用 MLLM），约 1~3 ms
  MVC 慢路径：MLLM 重描述，异步缓存，不阻塞控制环
  m = m_gnd · m_view；τ^v8 = τ^v7 · m；EFA-v7 七硬门 + kc_demand

在线控制环（目标维持 < 0.8 ms）：
  硬门链路不变；只消费预计算的 φ_gnd、φ_view、m
```

## 3. 复杂度分析（增量更新）

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 | 实时性指标 |
|---|---|---|---|---|
| MS3G.update | O(N_pts + N_inst·k) | O(|V|·d_sem + |O_t|) | N_pts≈2×10^5/帧 | 5~20 ms（异步） |
| MS3G.query | O(log|V| + k·d_sem)（ANN） | O(|V|·d_sem) | |V|≈10^2~10^3, d_sem=512 | < 0.1 ms |
| SGB.parse+typecheck | O(T_MM) | O(n) | n≤10 条断言 | 20~100 ms（可缓存/异步） |
| SGB.bind+score | O(n·k·d_sem + n·|A|) | O(Σ|A_j|) | k=5, n≤10 | < 0.5 ms |
| MVC 快路径 | O(K·(H·W + n·|A|)) | O(K·H·W) | K=4, 640×480 | 1~3 ms（GPU） |
| MVC 慢路径 | O(K·T_MM) | O(K·H·W) | K=4 | 40~100 ms（异步） |
| NBV | O(B_nbv·(T_render+T_update)) | O(B_nbv·H·W) | B_nbv=2 | 10~50 ms/次 |

**端到端在线增量**：快路径（绑定 + 几何 MVC）约 1~3 ms，其中 φ_gnd 与 m 计算 < 0.5 ms；MLLM 重描述与 NBV 走异步慢路径，不进入 0.8 ms 控制环。相比 v7，快路径 P99 由 0.8 ms 升至约 1.3 ms，代价换来「前提可证伪」。

## 4. 正确性论证（增量更新）

### 定理 13（只收紧与执行集包含）

**陈述**：设 φ_j∈[0,1]、ε≥0、m_j=1+ε(1−φ_j)≥1。若 v8 的采纳条件为「七硬门在 τ_i^v8=τ_i^v7·m_gnd·m_view 下通过 ∧ 证据完备 ∧ φ_gnd≥τ_gnd ∧ φ_view≥τ_view ∧ Π m_j≤T_max」，则 Exec(CADVS-v8) ⊆ Exec(CADVS-v7)，且软因子不会造成任何放松。

**证明**：m_j≥1 ⇒ τ_i^v8≥τ_i^v7；对每个硬门，1[s≥τ^v8] ≤ 1[s≥τ^v7]，故硬门集合单调收缩。证据完备、φ 阈值与 T_max 守卫均为额外合取项，只能删除候选。v7 中可小于 1 的 η 被 φ 的对偶表示替代，阈值侧不再出现 <1 的乘子。∎

### 定理 14（绑定可靠性 / 无无锚证据）

**陈述**：若断言 c_j 无候选锚点（C_j=∅）或 s_geo,j=0 且证据类别为 ASSUMED，则 s_j=0，故 u≥1/n、φ_gnd≤1−1/n。若 τ_gnd>0 或 u_max<1/n，则该程序不能进入硬门；且 ASSUMED 断言不能作为任何 critical 结论的唯一支撑。

**证明**：由 s_j=min(s_sem,s_geo,s_rel) 与无锚条件得 s_j=0；u 与 φ_gnd 的定义给出下界；完备性检查拒绝「critical 且 ASSUMED」的绑定。∎

### 定理 15（多视角分离，条件性）

**陈述**：设真断言在每视角的分歧 d_k≤δ，幻觉断言的期望分歧 E[d_k]≥Δ，且几何/遮挡项有界。若 1−Δ < τ_view < 1−δ（等价 Δ>δ），则阈值 τ_view 在期望意义上分离真/幻觉断言。

**证明**：E[φ_view]=1−E[penalty]；真断言 penalty≤δ ⇒ E[φ_view]≥1−δ；幻觉断言 penalty≥Δ ⇒ E[φ_view]≤1−Δ；取 τ_view 介于二者。∎

**诚实声明**：定理 15 依赖「幻觉在视角间不一致」这一强假设。若 MLLM 对同一幻觉在各视角稳定复述（view-consistent hallucination），或 3DGS 重建把 MLLM 的语义先验「渲染进」场景，则 Δ 可接近 δ，检测失效。这是本方案无法在结构上根除的残余风险。

### 其它诚实声明

- **遮挡/未观测盲区**：MS3G 对 unobserved 区域没有直接证据；NBV 只能缓解，不能消除。若 τ_gnd 设得高，会对「看不见但真实存在」的指称过度保守，引发回退风暴。
- **透明/反光/细长物体**：深度与 3DGS 重建易失败，导致 s_geo 假阴性；此时系统会误判为「未锚定」。
- **语义漂移**：开放词表嵌入对近义、文化差异与视角相关外观敏感，s_sem 需领域校准。
- **校准漂移**：φ 的保序回归假设验证集与部署同分布；分布漂移会使 τ 失效（静默）。
- **自洽幻觉**：多视角一致性使用同一 MLLM 做重描述，系统性偏差可能「一致地骗过」审计器。
- **计算成本**：MVC 慢路径是新的延迟瓶颈，必须异步/缓存，否则会侵蚀 0.8 ms 控制环预算。

## 5. 实验设计与验证计划（仿真 → 实机）

### 5.1 实验设计

- **平台**：UR10e（6DOF）+ 2DOF 移动底盘 + RealSense D455 + LiDAR；MuJoCo 3.x/MJX 做操作，Replica/ScanNet++ 做场景图与多视角渲染，3DGS 做重建。
- **MLLM**：本地部署开源 VLM（Qwen2.5-VL / InternVL2.5 / LLaVA-OneVision），隐私优先；另用闭源 API 模型做性能上限对照。
- **数据**：
  - MS3G：ScanNet++ / Replica / ARKitScenes 重建 1k 个场景图；
  - 指令集：2k 条，覆盖指称、关系、区域、否定；
  - 幻觉陷阱：不存在物体 300 条、错误关系 300 条、遮挡目标 300 条、歧义指称 300 条、对抗性流畅幻觉 200 条。
- **对照**：v7-full、v8-full、A21（无 MS3G，仅 2D 检测）、A22（无 SGB，回退自由文本 DRC）、A23（无 MVC）、A24（无 NBV）、A25（oracle grounding，上限）、A26（φ 不校准）。
- **场景**：
  - (a) 不存在指称：「把桌上的红杯子拿来」（无红杯）→ 应 fail-closed/询问，而非抓最近的杯子；
  - (b) 错误关系：「杯子在抽屉里」（实际在桌上）→ s_rel 低，NBV 或拒绝；
  - (c) 遮挡目标：「把柜子后面的盒子拿来」→ NBV 补看或显式报告不确定性；
  - (d) 歧义指称：两个杯子 → NBV/主动澄清；
  - (e) 对抗幻觉：MLLM 自信编造空间前提 → 绑定失败被拦截。
- **指标**：锚定精确率/召回、空间幻觉检测 AUROC、误拒率 FRR、NBV 使用次数、任务成功率、七硬门通过率、证书完备率、快路径 P99、慢路径 MVC 延迟。

## 7. 本轮最大风险（最终确认）

**一句话**：**三维感知的「所见即所得」假设**：MS3G 只能锚定被观测到的三维证据，对遮挡、反光、透明、未探索区域在结构上是盲的——系统要么对「看不见但真实存在」的指称过度保守（回退风暴），要么默许 MLLM 先验填补空缺（幻觉回流）；证书恰恰可能在感知最弱的地方显得最自信。
