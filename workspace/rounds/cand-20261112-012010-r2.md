# 第 58 轮（承接第 57 轮「少样本×多模态×个性化」IP-133~138；灵感循环第 2 轮；本轮灵感：「视觉语言动作模型」×「机器人操作系统」）

> 第 57 轮把安全的赌注从"证据质量"推进到"少样本可校准、跨模态可对账、个性化有界的证据承诺"，但它仍把两件事当作理所当然：**(a) 任务从哪来**——整条证据链只审查"这一脚接触是否有证据支持"，从不审查"这一脚是否正确地理解了指令"；自然语言目标被默默假设为已经结构化的约束。**(b) 数据从哪来**——观测被当成凭空出现的向量，忽略了它们经过的是一张分布式计算图：节点会死、时钟会漂、TF 会跳、QoS 会静默丢包、第三方推理节点可能就是攻击者。于是威胁模型漏掉两个新盲区：**语义盲区**（VLA 可以有证据地执行一个被误解的目标）与**底座盲区**（物理世界完好，证据却在管道里已经变质）。本轮两个灵感各补一根承重梁：**视觉语言动作模型（VLA）**把开放词汇的语义提议降格为"可编译规约"，并强制其从"承诺者"退到"提议者"；**机器人操作系统（ROS）**把"证据"从一条数据升级为一条运行时溯源链，用能力-权限分离在操作系统层把"提议总线 / 提交总线"焊死。核心命题由"证据承诺"升级为 **"语义可编译、运行时可信、证据可回放的语言-证据承诺"**。

核心矛盾：
- **H32（开放语义 vs 可验证约束）**：VLA 的力量来自开放词汇，安全的底座要求闭集、可测、可校准的谓词。语言越开放，不可接地的原子越多；强行接地会摧毁泛化，拒绝接地会摧毁安全。系统只能在"编译成功"与"请求澄清"之间选择，绝不允许"靠猜接地"这第三条路。
- **H33（运行时溯源 vs 管道攻击面）**：证据不只被世界欺骗，也会被管道欺骗——stale cache、QoS 不匹配、时钟偏斜、死节点、topic 伪造、被投毒的 VLA 节点。溯源能提升可信度，但它自己也引入新的攻击面（令牌伪造、密钥泄露、图重构）与延迟；"可溯源"不等于"为真"。
- **H34（回放可复现 vs 现实不可复制）**：回放假设确定性，但真实机器人有隐藏状态（执行器磨损、控制器内部模式、未记录参数）；bag 也可能被选择性记录（只记成功时段）而制造"文档安全"。回放既能审计证据，也能制造一种比没有审计更危险的假安全感。

## 0. 直觉与动机

**灵感 1（VLA → 语言不是命令，是可编译的规约）**
直觉：把 VLA 直接接到执行器，就是把一个随机、开放词汇、不可验证的函数放进安全回路；但若因为不可验证而拒绝 VLA，机器人就失去处理"把蓝色箱子搬到冰面左边，避开那块看起来湿的板"这类开放任务的能力。中间道路不是"更信任 VLA"，而是**改变 VLA 在系统中的语法位置**：它不再输出命令，而是输出一份**语言任务规约 LTS**（原子命题 + 时序公式 + 欠定集），由接地编译器编译成可测谓词上的 STL 公式与证据义务。VLA 的语义先验给效率，接地编译器与第 57 轮证据门给安全；编译不通过就说"我不懂"，而不是"我猜着做"。

**灵感 2（VLA → 证词不是证据，语言通道是新的欺骗面）**
直觉：第 57 轮已经知道"同一模态问五遍只是把同一个错误问五遍"；语言通道把这个教训放大——**同一个模型换五种说法自我复述，也只是同一个错误换了五种说法**。因此任何自然语言断言（来自 VLA 或人）都只能算**证词**：可以影响候选生成，不能改变证据义务集；必须由一条来源独立的物理观测蕴含，才算被佐证。提示注入、幻觉 affordance（"这块冰可以走"）、以及"要求绕过证据门"的指令，都在这里被识别为 SSTOP，而不是被当作新证据。

**灵感 3（ROS → 观测的溯源闭包成为证据的前置条件）**
直觉：ROS 的图不是实现细节，而是**证据的因果骨架**。一条观测来自哪个节点、经过哪些 topic 与 TF、创建于何时、序列号是否单调、QoS 的 deadline 是否满足、节点是否还活着——这些决定了它能不能算"此刻的证据"。第 57 轮把"陈旧地图"当成一种风险；本轮把它变成一条**一等的证据失败类型**：`EV-provenance` 是任何证据入门的必要条件，而不是可以互相替代的第六类证据。物理不确定性与管道不确定性从此分账。

**灵感 4（ROS → 能力-权限分离，在 OS 层强制"提议/提交"分离）**
直觉：第 57 轮说"一切判定器走隔离"，但那还是架构口号；ROS 2 的 SROS2/DDS 安全策略、生命周期节点、topic 访问控制让它可以变成**不可绕过的图不变式**：VLA 节点没有 command topic 的写权限，只能写 proposal topic；执行器只订阅 commit topic；提交节点是唯一持有 commit 写权限的 ACTIVE 节点。这样"VLA 幻觉"最多污染提议池，物理上无法直接驱动电机——这是把"提议 vs 承诺"从设计约定升级为**操作系统强制**。

**灵感 5（ROS bag → 可回放证据与反事实灵敏度）**
直觉：ROS bag 让"证据"第一次可被离线重放：每次承诺绑定一段 bag 窗口、消息哈希、TF 快照与配置哈希，形成可挑战、可复算的证书 REC。更进一步，可以做**反事实灵敏度**：把最可疑的输入做物理上合理的小扰动再重放，如果承诺轻易翻转，说明这份证据是"脆"的，应补证/降级/澄清，而不是因为离线能复现就放心。只有通过 REC 与反事实审计的时间窗，才允许进入长期语料；选择性记录本身成为审计对象。

**灵感 6（VLA×ROS 合流 → 六段式 SVCR 与证据门的第六类前置）**
直觉：把两灵感合流成一条不可越级的流水线：**提议（VLA）→ 编译（接地）→ 溯源（ROS 图）→ 核验（第 57 轮证据门）→ 提交（唯一 verifier 节点）→ 回放（REC+反事实）**。任一段只能否决、收窄或要求澄清，不能放宽后一段；VLA 只能增加候选计划，不能减少证据义务；溯源失败优先于物理判断，回放脆弱只能降级。纵深从第 57 轮的五层再加"语义层"与"运行时层"，形成七层。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（语言任务规约 LTS 与接地编译 GC）** 设 VLA 推断器 `π_ψ:(I_t,ℓ,H)→(a_t,r_t,LTS)`，其中 `I_t` 视觉/本体观测、`ℓ` 语言指令、`H` 会话历史、`a_t` 动作草案、`r_t` 理由文本。`LTS=(𝒫,φ,𝒜)`：`𝒫` 为原子命题集，`φ` 为定义在 `𝒫` 上的 STL 公式，`𝒜` 为欠定原子集。接地映射 `γ:𝒫→(pred,dom,g,cal)`，`g∈[0,1]` 为接地置信，`cal` 为校准记录。编译器 `GC(LTS)=(φ̂,𝓞_ev,U)`：仅当 `p∈dom(γ)` 且 `g(p)≥θ_g` 时 `p` 替换为可测谓词并进入 `φ̂`，否则 `p∈U`。接纳条件：`U=∅`，或每个 `u∈U` 都获得**澄清令牌**（人类澄清或显式保守默认）。接地共形契约：`P(γ 真值正确)≥1−α_g`。硬规则：VLA 永不直接产生 commit；无接地即无义务，无义务即无承诺。
- 直觉：`φ` 是"人话里的目标"，`φ̂` 是"机器人能测的目标"；`U` 是两者之间不可消除的裂缝。系统可以问，可以退，但不能替人类把裂缝补上。

**定义 140（证词代数 TA）** 任何自然语言断言 `c`（VLA 或人）是**证词**而非证据，携带来源 `σ(c)=(model_id,prompt_hash,session,t)`。`c` 被佐证 ⇔ 存在一条来自独立物理证据类 `o` 的观测，使 `grounded(c)` 被 `o` 蕴含，且 `src(o)∩src(c)=∅`（**禁止自佐证**：同模型、同人、同提示换说法的重复不算独立）。未佐证证词可以改变候选排序，不得改变证据义务集。语义注入判定：若 `c` 的接地义务与当前证据矛盾、或要求绕过证据门/权限边界/不可逆接触限制，则触发 `SSTOP`（拒绝并请求澄清），不得以"語言指令"为由放宽任何门。

**定义 141（运行时溯源图 RTPG 与证据闭包）** `𝒢_rt=(N,T,E,Q)`：节点、topic、边、QoS 契约。每条观测 `o` 携带溯源令牌 `tok(o)=(origin,path,TF_chain,t_create,t_recv,seq,sig,config_hash)`。四性判定：
- 新鲜性：`t_now−t_create≤deadline(QoS)`；
- 活性：路径上所有节点心跳在 `period` 内；
- 完整性：路径无环、节点经 SROS2 认证、`sig` 有效、`seq` 单调（防重放/重复）；
- 一致性：`TF_chain` 可复合且无跳变，`config_hash` 与当前配置一致。

证据闭包 `PC(o)=⊤` ⇔ 四性全过。`EV-provenance`：`o` 可进入第 57 轮证据门 ⇔ `PC(o)=⊤`；它是**前置必要条件**，不可被任何其他证据类替代。图级冗余：同一物理量由 ≥2 条边不相交路径估计，残差超阈即**管道级分歧** `D_rt(r)`，与物理跨模态分歧 `D(r)` 分账。

**定义 142（能力-权限分离 CSP）** 每个节点 `n` 有写权限 `cap(n)⊆Topics∪Params`。能力格要求：
- `cap(VLA_node)∩CmdTopics=∅`，只允许写 `ProposalTopics`；
- `cap(Verifier_node)⊇CommitTopics`，且 `Verifier∈ACTIVE` 时才允许提交；
- 执行器只订阅 `CommitTopics`，不订阅任何 `ProposalTopics`；
- 图不变式 `Inv(G)`：不存在从 `cap` 不含 `CommitTopics` 的节点到执行器的有向路径绕开 `Verifier`。

`Inv(G)` 由 SROS2 访问控制策略文件、DDS 域隔离与生命周期状态机共同执行；它不是"建议"，是可被静态检查的硬约束。

**定义 143（可回放证据证书 REC 与反事实灵敏度）** 每次承诺产出
`REC=(bag_id,[t0,t1],H(msgs),H(TF),H(config),verdict,replay_hash)`。
在 A43 下重放同一 bag 得到 `verdict'`，且 `|verdict−verdict'|≤ε_rep`。反事实灵敏度
`FS(c)=max_{δ∈Δ_plaus}|verdict(Replay(bag,perturb(bad_input,δ)))−verdict|`；
`FS(c)>θ_frag` ⇒ 证据脆弱，必须补证/降级/请求澄清。只有 `REC` 通过且 `FS≤θ_frag`、记录覆盖率 `≥cov_min` 的时间窗，才允许进入长期语料 `𝒟_meta∪𝒟_mem`。选择性记录（只记好时段）是显式审计对象：哈希链 + 覆盖率下界 + 独立时间源交叉校验。

**定义 144（语义-核验-承诺-回放算子 SVCR，升级 PCE+）** 每检查点六段：
1. **提议**：VLA 生成 `LTS` 与理由，写入 `ProposalTopics`；
2. **编译**：`GC(LTS)` 产出 `φ̂,𝓞_ev,U`；`U≠∅` 且无澄清 ⇒ 澄清/拒绝；
3. **溯源**：对 `𝓞_ev` 所需观测做 `PC(o)` 全检；任一失败优先于物理结论；
4. **核验**：第 57 轮 FSE 证据门 + `EV-provenance` 前置；不足则探询/绕行/降档/协商；
5. **提交**：只有 `Verifier` 节点可发 commit，VLA 节点无权限；
6. **回放**：生成 `REC`，做 `FS` 反事实审计；脆弱证据降级并记入审计。

SVCR 的**单调性**：新增的每一段只能缩小可承诺集；VLA 不能减少义务，溯源失败不能靠物理置信抵消，回放脆弱不能靠"离线能复现"洗白。

## 2. 关键算法伪代码（完整版见产物区）

```python
def ground_and_compile(lts, gamma, ctx, alpha_g):
    grounded, ungrounded = [], []
    for p in lts.atoms:                              # 接地：能测才编译
        g = gamma.lookup(p, ctx)                     # (pred, dom, score, calib)
        if g is None or g.score < theta_g or not g.in_domain:
            ungrounded.append(p)                     # 不可接地 → 澄清，不猜
        else:
            grounded.append(g)
    phi_hat = substitute(lts.phi, {g.atom: g.pred for g in grounded})
    obligations = evidence_obligations(phi_hat, ungrounded)
    if ungrounded and not all(clarified(u, ctx) for u in ungrounded):
        return Compile('NEED_CLARIFY', ungrounded=ungrounded,
                       cert=conformal_grounding(grounded, alpha_g))
    return Compile('OK', phi=phi_hat, obligations=obligations,
                   cert=conformal_grounding(grounded, alpha_g))

def admit_testimony(c, pool, ctx):                   # 证词 ≠ 证据
    if c.source in ctx.blocked_sources: return 'reject'
    g = ground_claim(c)
    if g is None: return 'testimony_only'            # 只影响候选，不改义务
    for o in pool.entailing(g):
        if disjoint_sources(o, c) and PC(o, ctx.G_rt):
            return 'corroborated'                    # 独立物理证据蕴含
    if contradicts(c, pool) or asks_bypass(c):
        return 'SSTOP'                               # 注入/矛盾 → 拒绝+澄清
    return 'testimony_only'

def provenance_closure(o, G, sk, now):               # ROS 图上的证据闭包
    if not sig_ok(o.token, sk):                  return False, 'sig'
    if now - o.token.t_create > deadline(o.qos): return False, 'stale'
    if any(not node_alive(n, now) for n in ancestors(G, o.token.origin)):
                                                 return False, 'silent'
    if not tf_chain_consistent(o.tf):            return False, 'tf'
    if not seq_monotone(o.token):                return False, 'dup_or_replay'
    return True, 'ok'

def svcr_checkpoint(x0, M, G, lang, budget, personas):
    lts = vla_propose(lang, M, x0)                   # ① 只写 proposal
    cmp = ground_and_compile(lts, gamma, ctx(M), alpha_g)   # ② 编译
    if cmp.cls == 'NEED_CLARIFY':
        return clarify_or_stop(lts, cmp, personas.active)
    for o in observations_for(cmp.obligations):
        ok, why = provenance_closure(o, G, sk, now())     # ③ 溯源优先
        if not ok: return refetch_or_degrade(o, why)
    st = few_shot_evidence_gate_vr(cmp.obligations, M, personas, ood_reg)
    if st[0] != 'ok':                                 # ④ 证据门（含前置）
        return probe_or_reroute_or_negotiate(st, budget)
    publish(verifier_node, 'cmd', build_commit(cmp.phi))  # ⑤ 唯一可提交者
    rec = replayable_certificate(active_bag, window(), config_hash, 'commit')
    fs, cls = counterfactual_fragility(rec, suspect=min_evidence(cmp),
                                       delta_set=DELTA_PLAUS)  # ⑥ 回放审计
    if cls == 'fragile': audit.mark('fragile_evidence', rec)
    return rec
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| LGC | O(\|𝒫\|·d_γ) + 编译 O(\|φ\|) | O(\|𝒫\|) | 接地缺口不猜、共形覆盖 ≥1−α_g |
| TA | O(\|c\|·\|pool\|) | O(\|σ\|) | 禁止自佐证、注入必 SSTOP |
| RTPG | O(\|ancestors\|) / 观测 | O(\|N\|+\|E\|) | 四性全过才算证据、图冗余分账 |
| CSP | 静态 O(\|N\|+\|E\|)；发布 O(1) | O(\|cap\|) | `Inv(G)` 不可绕过、最小权限 |
| REC | O(\|bag 窗口\|) 回放 | O(窗口) | 哈希链 + 覆盖率下界、脆弱即降级 |
| SVCR | O(LGC+PC+证据门+REC) | O(同上) | 六段单调、只收窄不放宽 |

**正确性定理（SPARC: Semantic-Physical Attested Replayable Commitment，概要）**
在 A33–A40（第 56–57 轮）之上增加：**(A41)** 接地健全性：接地谓词可测、校准误差以共形覆盖 `≥1−α_g` 声明，`U` 中原子不被静默丢弃；**(A42)** 溯源完整性：SROS2 认证、TF 链一致、时钟偏斜在有界范围内、QoS 契约被履行、无未认证写者进入 commit 总线；**(A43)** 回放确定性与完整性：bag 捕获影响决策的全部输入，重放差异 `≤ε_rep`，隐藏状态影响有界；**(A44)** 能力约束：`Inv(G)` 由 SROS2/DDS 策略强制，VLA 节点无 CmdTopics 写权限、Verifier 是唯一提交者。则：

1. **语义健全性**：任何承诺若 `U≠∅` 且无澄清则不可发生；`U=∅` 路径的误接地贡献 `≤ε_g`。VLA 只能改变候选，不能改变义务集。
2. **运行时健全性**：`PC(o)=⊤` 是证据入门必要条件；溯源失败贡献 `≤δ_prov`；在 A44 下，未授权节点提交的执行概率为 0（图不变式，非概率假设）。
3. **回放可审计性**：A43 下 `REC` 可复现裁决；`FS>θ_frag` 只能降级；选择性记录被覆盖率下界与哈希链约束，单独不能制造假安全。
4. **交互单调性与终止性**：SVCR 六段全部只收窄可承诺集；探询预算继承第 57 轮，在 `k_probes+k_cons` 内终止于 {提交, 澄清, 绕行, L2 协商, 安全停}。

部署界（对检查点取联合界）：
```
P_safe ≥ 1 − Σ_cp [ δ_f + ε_meta(k) + ε_g + δ_probe + ε_h + δ_ood·α_conf
                    + δ_xm·1[L1] + δ_prov + δ_rt + δ_rep·1[回放] ]
          − P(Inv(G) 被违反) − P(地面真值不可回放且未被检出)
```
关键：**VLA 给效率、编译给语义边界、ROS 给运行时出处、回放给可挑战性**；四者都不被允许"增加授权"，只能否决、收窄或要求澄清。

### IP-139 LGC（语言任务规约 → 接地编译）

```python
def ground_and_compile(lts, gamma, ctx, alpha_g):
    grounded, ungrounded = [], []
    for p in lts.atoms:
        g = gamma.lookup(p, ctx)                     # (pred, dom, score, calib)
        if g is None or g.score < theta_g or not g.in_domain:
            ungrounded.append(p)                     # 不可接地 → 澄清，绝不猜
        else:
            grounded.append(g)
    phi_hat = substitute(lts.phi, {g.atom: g.pred for g in grounded})
    obligations = evidence_obligations(phi_hat, ungrounded)
    cert = conformal_grounding(grounded, alpha_g)   # 覆盖 ≥1-α_g
    if ungrounded and not all(clarified(u, ctx) for u in ungrounded):
        return Compile('NEED_CLARIFY', ungrounded=ungrounded, cert=cert)
    return Compile('OK', phi=phi_hat, obligations=obligations, cert=cert)

def stl_from_lts(lts, grounded):                    # 只替换已接地原子
    phi = lts.phi
    for atom, g in grounded.items():
        phi = phi.substitute(atom, g.pred)
    return phi                                      # 未接地原子不进入 φ̂
```

def provenance_closure(o, G, sk, now):
    t = o.token
    if not sig_ok(t, sk):                    return False, 'sig'
    if now - t.t_create > deadline(o.qos):   return False, 'stale'

def graph_disagreement(G, quantity):
    paths = edge_disjoint_paths(G, quantity)        # 图级冗余

def check_invariant(G, cap, cmd_topics, verifier):
    assert cap[verifier] >= set(cmd_topics)
    for n in G.nodes:
        if n == verifier: continue
        if any(reachable(G, n, t) for t in cmd_topics):

def replayable_certificate(bag, window, config, verdict):
    return REC(bag.id, window,
               hash_msgs(bag, window), hash_tf(bag, window),
               hash(config), verdict,
               replay_hash=digest(bag, window, config, verdict))

def counterfactual_fragility(rec, suspect, delta_set):
    base = rec.verdict
    flips = [replay(rec, perturb(suspect, d)) != base for d in delta_set]
    fs = mean(flips)
    return fs, ('fragile' if fs > theta_frag else 'stable')

def admit_to_corpus(rec, fs, coverage):
    return rec.verified and fs <= theta_frag and coverage >= cov_min

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| LGC | O(\|𝒫\|·d_γ)+O(\|φ\|) | O(\|𝒫\|) | 接地缺口不猜、共形覆盖 ≥1−α_g（A41） |
| TA | O(\|c\|·\|pool\|) | O(\|σ\|) | 禁止自佐证、注入必 SSTOP（A41） |
| RTPG | O(\|anc\|)/观测 | O(\|N\|+\|E\|) | 四性全过、图冗余分账（A42） |
| CSP | O(\|N\|+\|E\|) 静态；O(1) 发布 | O(\|cap\|) | `Inv(G)` 不可绕过、最小权限（A44） |
| REC | O(\|bag 窗口\|) | O(窗口) | 哈希链+覆盖率、脆弱即降级（A43） |
| SVCR | O(LGC+PC+FSE+REC) | 同上 | 六段单调、继承 `k_p+k_c` 终止 |

**正确性定理（SPARC: Semantic-Physical Attested Replayable Commitment）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立，并增加：
**(A41)** 接地健全性：接地谓词可测，校准误差以共形覆盖 `≥1−α_g` 声明，`U` 不被静默丢弃，证词来源可审计；
**(A42)** 溯源完整性：SROS2 认证、TF 链一致、时钟偏斜有界、QoS 契约履行、无未认证写者进入 commit 总线、溯源令牌不可伪造；
**(A43)** 回放确定性与完整性：bag 捕获影响决策的全部输入，重放差异 `≤ε_rep`，隐藏状态影响有界，记录覆盖率 `≥cov_min`；
**(A44)** 能力约束：`Inv(G)` 由 SROS2/DDS 策略与生命周期门强制，VLA 节点无 CmdTopics 写权限，Verifier 是唯一提交者。则：

1. **语义健全性**：`U≠∅` 且无澄清 ⇒ 不承诺；`U=∅` 路径误接地贡献 `≤ε_g`；VLA 只能改候选，不能改证据义务集。
2. **运行时健全性**：`PC(o)=⊤` 是证据入门必要条件；溯源失败贡献 `≤δ_prov`；在 A44 下未授权提交的执行概率为 0（图不变式，不是概率让步）。
3. **回放可审计性**：A43 下 `REC` 复现裁决；`FS>θ_frag` 只能降级；选择性记录受覆盖率与哈希链约束，不能单独制造假安全。
4. **单调性与终止性**：六段全部只收窄可承诺集；预算继承第 57 轮，在 `k_probes+k_cons` 内终止于 {提交, 澄清, 绕行, L2 协商, 安全停}。

**部署界**（对检查点取联合界）：
```
P_safe ≥ 1 − Σ_cp [ δ_f + ε_meta(k) + ε_g + δ_probe + ε_h + δ_ood·α_conf
                    + δ_xm·1[L1] + δ_prov + δ_rt + δ_rep·1[回放] ]
          − P(Inv(G) 被违反) − P(地面真值不可回放且未被检出)
```

关键：**VLA 给效率、接地给语义边界、ROS 给运行时出处、回放给可挑战性**；四者都只能否决、收窄或要求澄清，不能增加授权。第 57 轮"一切判定器走隔离"在本轮落成 **"一切判定器必须有过得去的出处、可回放的经历、以及不可绕过的权限边界"**。

- 边端回传 `REC` 摘要、`U` 统计、溯源失败事件与 `FS` 脆弱窗口，作为云端接地语料与运行时补盲依据；含未认证或选择性记录的窗口禁止进入训练集。

## 6. 本轮最大风险

**一句话**：本轮最大的风险是"**可追溯被误当成可理解**"——VLA 可能把一个人话里通顺、时序上良构、证据链完整、回放可复现的目标接地到错误的物理谓词上，而 ROS 的溯源与 bag 审计会一丝不苟地为一趟去往错误目标的旅程出具完美证书；必须坚持"不可接地就澄清、证词不等于证据、回放脆弱即降级"，并让语义正确性始终由独立物理佐证与人类澄清共同兜底，绝不允许审计能力冒充语义正确性。
