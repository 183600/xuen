## 1. 直觉与动机（两个灵感的碰撞）

### 灵感 1（地形适应 → 桌面不是平面，而是「可操作地形」）

**直觉**：腿足机器人讲地形适应，指的是脚下支撑面未知、必须在线估计几何与可通行性，再调整步态与姿态。桌面操作赛里没有山丘，但有三种同构的「地形」：

1. **支撑面地形**：桌面高度、倾角、边缘、桌面上的凹槽/容器/架子——决定「手能不能够到、会不会撞桌」；
2. **物体高度场地形**：碗、杯子、瓶子、书架、工具箱本身构成高低起伏的「地形」，决定接近方向与抓取构型；
3. **可达性景观**：把基座/腰部构型 c 映射到「可达、可见、无碰撞、平衡」的标量场 A(c)，它才是机器人真正要「走」的地形。

大多数基线把 `action.pivot` 输出零（F20），等于假设「地形是平的、工作空间是固定的」。但 F21 显示 22/32 任务的基座高度会低于 0.70 m，18/32 任务高度跨度 >5 cm，7/32 任务有 >0.1 的基座平移；F22 又显示这些通道在 episode 内几乎不动。核心反直觉点：**桌面操作的「地形适应」不是长距离行走，而是在 reset 期把身体摆到任务地形的「可操作盆地」里；一次 2–5 cm 的高度/腰部调整，可能比换一个更大的模型更能救回边缘位置的物体。**

**严谨定义**：把支撑地形记为

`S = (π, h(x,y), κ)`

其中 π 是支撑平面参数（法向与截距，基座系），h(x,y) 是物体/支撑面的高度场，κ 是接触/摩擦类别（无触觉时只做视觉先验，不进入硬约束）。对构型

`c = (b, h_b, q_w) ∈ C = SE(2) × [h_min,h_max] × Q_waist`

定义可操作地形图

`A(c) = (r(c), v(c), d(c), β(c), ρ(c))`

分别为 IK 可达残差、目标可见性、桌面/自碰撞净空、准静态平衡裕度、回到标称构型 c0 的可逆代价。地形适应就是

`c* = argmin_{c∈C_safe} J(c),  J = w_r r + w_v(1-v) + w_c·hinge(d_safe-d) + w_b·hinge(β_safe-β) + w_ρ ρ - w_p log p(c | l, o_0)`

其中 `p(c | l, o_0)` 是从 32 任务 + 110 语料检索到的**地形签名先验**（同类任务/同类物体在示教里常用的基座高度与腰部姿态），`l` 是语言指令，`o_0` 是 reset 首帧。只有 `J(c*) < J(c0) - δ` 且硬约束全过才移动；否则保持标称。**地形签名**把「零样本泛化」变成「检索到最像的地形，再在它的邻域里微调」，与 I9 的物体级检索互补。

### 灵感 2（全身控制 → 不是「手臂够不到就放弃」，而是「用身体把工作空间搬过去」）

**直觉**：G1 是冗余系统：腿/基座、腰、双臂、双手。全身控制（WBC）的本意就是在约束（平衡、关节限位、自碰撞、接触）下协调这些冗余自由度。但 F22 的审计很刺眼：示教里腰部运动只有手臂的 1.7%，基座平移只在 7/32 任务明显出现。也就是说，数据几乎没教策略「用身体帮忙」；而评测的泛化轴（物体位置偏移、遮挡、不同高度物体）恰恰最需要身体帮忙。核心反直觉点：**在手臂接近奇异/边缘时，最便宜的自由度不是再训练一个更大的动作头，而是把基座降低 3 cm、把腰转 5°；但前提是这些动作必须被硬约束投影保护，且可逆。**

**严谨定义**：把全身状态记为

`q = (b, h_b, q_w, q_a, g)`

（基座平面位姿、基座高度、腰部 3 自由度、双臂 14 维、双手开合）。策略输出名义动作

`a_t = (Δb, Δh_b, Δq_w, Δq_a, Δg)`

（对应 `action.pivot` 的已验证维度 + 手臂/手部动作；`p3–p5` 未验证，默认置零，不主动命令）。定义硬约束集

`K = {关节限位, 速度/加速度限位, 自碰撞, 桌面净空, 准静态平衡, 视线可见}`

全身投影是一个**确定性的安全滤波器**，不是第二个学习策略：

`P(a) = argmin_{a'∈K} ||a' - a||_W^2`

盒子约束（关节/速度）用逐维裁剪；平衡用 CoM 在支撑多边形内的裕度；碰撞用 MJCF 的前向运动学与胶囊体检测；投影后若 `||P(a)-a|| > ε`，触发「构型风险」回退：冻结基座/腰部，只保留手臂动作。这样单模型边界（PR2）不被破坏：唯一的学习模型仍是 VLA，地形估计是预处理，投影是后处理。

### 两者统一：地形适应回答「身体该摆在哪」，全身控制回答「怎么安全地摆过去」

合成一个执行侧闭环：**reset 期一次性地形签名检索 + 构型选择 → episode 内低增益腰部微调 + 硬约束投影 → 偏离时小步可逆恢复**。它不替代 v1.1 的数据引擎，而是把数据引擎学到的「任务签名」在评测时兑现成「够得到、看得见、不撞桌」。本轮结论：**v1.1 解决「策略知道什么」，本轮解决「策略把自己摆在哪里」；两者相乘，才是单模型在 320 个 trial 上的稳定得分。**

## 2. 对第 2 轮痛点的增量修订

- **P2（泛化缺口）**：新增「支撑面/工作空间边界」子轴。物体位置偏移轴的失败不全是外观泛化，很多是「边缘不可达/被遮挡」；TS-WBC 把这类失败从「模型没见过」降级为「构型没摆对」。
- **P4（无触觉）**：地形估计只做几何（平面、高度场、净空），不假装估计摩擦/柔顺；接触段仍由 I3 的视觉伺服兜底。
- **P5（时间压力）**：地形估计只在 reset 做一次（<1 s），构型调整用低增益、限幅、可逆；不引入连续基座规划的高延迟。
- **P8（示教质量）**：F23 修正「全成功无失败」；成功轨迹内部的空抓/重抓可作为 I5 恢复示教的天然种子，也可作为「构型失败→重试」的标签。
- **新增 P9（全身通道欠监督）**：F22 显示全身运动仅占手臂的 1.7%，策略没有足够监督学会用基座/腰部；直接放开全身通道会放大失稳/碰撞风险，必须先有「可逆构型闸 + 硬约束投影」。
- **新增 P10（接口语义未定）**：`p3–p5` 语义未公开，`example_policy.py` 全零；任何依赖未验证维度的方案都可能被接口语义反噬。本轮用「已验证维度优先、未验证维度隔离」的原则处理。

## 3. 研究问题（本轮立项 Q9–Q11，Q1–Q8 保留）

- **Q9（地形表示的最小充分性）**：在只有 4 路 RGB、无深度、无触觉的接口下，用什么地形表示（单目深度平面 + 物体高度场 / VLM 特征 / 机器人运动学 + 任务签名）能以 <1 s 的 reset 成本给出可靠的 `A(c)`？误差如何传播到构型选择？
- **Q10（构型收益的可辨识性）**：高度、腰部、基座平移三类自由度的收益/风险如何排序？在 320 trial、每轴 64 trial 的统计分辨率下，什么样的 L0 代理指标能在真机前识别「值得动」的构型？
- **Q11（安全投影与单模型边界）**：确定性全身投影、地形估计器、姿态检索器是否被组委会视为「单模型」的一部分？若不允许，训练时重定向（I11）能否作为不依赖推理期额外模块的降级路径？

## 4. 设计原则（新增 PR6/PR7，PR1–PR5 保留）

- **PR6 可逆构型闸**：任何基座/腰部调整必须满足「存在一条回到 c0 的安全路径，且代价 ρ(c) 有界」；不满足则不执行。可逆性优先于最优性。
- **PR7 未验证维度隔离**：`action.pivot` 的 `p3–p5` 在语义被官方确认前一律置零/透传标称；只使用 `vx, vy, angle_z, height` 与有数据支撑的腰部通道。
- **PR5 数据杠杆律**（v1.1）：每条新增数据必须回答「它教策略什么 eval 分布内的行为」；全身重定向数据必须带「地形变化 → 构型变化」的因果标签，否则低权重。
- PR1–PR4 保留（第 1 轮 §4）。

## 6. 本轮最大风险

**一句话**：全身通道在示教里只占手臂运动幅度的约 1.7%（F22），策略几乎没被教过怎么用基座/腰部；若把未验证的 `pivot` 维度或连续基座运动直接上计分通道，可达性收益很可能被失稳、碰撞与延迟尖峰吞掉——所以本轮坚持「高度优先、腰部次之、平移最后，且一次一移、可逆、硬约束投影」。

### I10 地形签名 + 一次性全身构型适应（新） ★★★★

- **动机**：F21/F22 显示执行侧有两块被浪费的分数：(a) 基座高度在 22/32 任务中低于 0.70 m，18/32 任务高度跨度 >5 cm，7/32 任务基座平移 >0.1，但 episode 内腰部运动仅为手臂的约 1.7%；(b) 物体位置偏移/遮挡/不同高度物体这些泛化轴，很多失败不是「没见过物体」，而是「构型没摆到可操作盆地」。I10 在 `reset()` 期做一次地形估计与构型选择，把身体摆到任务签名附近，再用硬约束投影兜底。

### 1.1 地形签名与构型选择（I10）

```python
from dataclasses import dataclass

@dataclass
class Terrain:
    plane: tuple          # (n, d) in base frame
    height: object        # h(x, y) height field
    prior: tuple          # (mu, Sigma, weight) from posture library

def build_posture_library(tasks):
    lib = []
    for task in tasks:
        for ep in task.episodes:
            # 只取 episode 前 10% 的稳定构型，避免把操作中段当成地形先验
            c = mean_posture(ep, t in [0, 0.1 * T])
            sig = terrain_features(ep, t=0)   # 桌面高度/物体高度场/布局
            lib.append((task.name, object_labels(ep), sig, c))
    return FAISS_index(lib)

def estimate_terrain(obs, task, lib):
    D = monocular_depth(obs["cam_head"])              # reset 期一次
    table = open_vocab_segment(obs["cam_head"],
                               ["table", "desk", "shelf", "surface"])
    pi = ransac_plane(D, table)                        # n·x + d = 0
    h = height_field(D, object_masks(obs))
    q = embed_scene(obs, h)
    hit = lib.search(q, k=5)
    mu, Sigma = weighted_gaussian(hit)                 # 地形签名先验
    return Terrain(pi, h, (mu, Sigma))

def choose_posture(terrain, obs, c0):
    # 高度优先、腰部次之、平移默认关闭（PR6/PR7）
    C = candidate_set(terrain.prior, c0,
                      dh=[0, .02, .04], dq_w=[0, .035, .087], db=[0])
    best = (c0, cost(c0, terrain, obs, c0))
    for c in C:
        if not reversible(c, c0):
            continue
        J = cost(c, terrain, obs, c0)
        if J < best[1]:
            best = (c, J)
    return best[0] if best[1] < cost(c0, terrain, obs, c0) - DELTA else c0

def cost(c, terrain, obs, c0):
    r   = ik_residual(c, target_grasp_pose(obs))
    v   = visibility(c, obs)
    d   = clearance(c, terrain)
    b   = balance_margin(c)
    rho = return_cost(c, c0)
    lp  = -log_prob(c, terrain.prior)
    return (w_r * r + w_v * (1 - v)
            + w_c * max(0, d_safe - d)
            + w_b * max(0, b_safe - b)
            + w_rho * rho + w_p * lp)
```

### 1.2 全身投影（I10，推理期安全滤波）

```python
def whole_body_project(a, q, c0, terrain, prev_a):
    a = dict(a)
    for k in ("p3", "p4", "p5"):
        a[k] = 0.0                     # PR7：未验证维度隔离
    a = clamp_joint_limits(a, q)
    a = clamp_velocity(a, q)
    q1 = integrate(q, a)

    if not balance_ok(q1):
        a = damp(a, base=0.5, waist=0.5)
        q1 = integrate(q, a)
    if self_collision(q1) or table_penetration(q1, terrain):
        a = backtrack(a, q, terrain)   # 沿动作方向回退到最近可行点
        q1 = integrate(q, a)

    a = lowpass(a, prev_a)
    if action_delta(a, nominal_action(q)) > EPS_RISK:
        a = freeze_base_waist(a)       # 只保留手臂，避免构型风险
    return a
```

## 2. 实验设计（分级消融协议 v3）

| 级别 | 内容 | 通道/成本 | 通过判据 |
|---|---|---|---|
| L0-T | 地形扰动：12 任务 × 10 held-out eps × 高度 {0, ±2, ±4 cm} × 倾角 {0, 2, 4°} × 边缘/遮挡位置；比较 baseline / 高度-only / 高度+腰 / 全基座 | 离线（免费） | 标称场景 Δprog≥-1%、动作变化 <5%；边缘场景 IK 残差 ↓≥30%、可见性 ↑≥10%、0 碰撞/失衡 |
| L0-C | 构型消融：有/无先验、有/无投影、有/无重定向、候选集大小 | 离线（免费） | 投影消除全部硬约束违规；先验在未见布局上 Δprog>0 |
| L1 | 2^(5-1) 部分析因：地形估计、高度、腰部、投影、重定向；主效应优先 | 离线 + 少量真机 | 主效应显著的 ≤3 个组合进入 L2 |
| L2 | top 组合真机确认：2–3 任务（OrganizeTools / StackBowls / PackPhone）× {标称, 边缘} × 各 2 次 | 单任务通道 | 标称不回归；边缘至少 1 次成功增益；p99 <40 ms；0 动作健康度拒绝 |
| 门禁 | PR4：run_client 全流程 + p99 + 动作健康度回归 | 本地 stub | 0 拒绝动作、p99 <40 ms、无关节限位/自碰撞 |

**首批 L2 排队计划**：①I10 高度-only（最低风险）→ ②I10 高度+腰 → ③I11 重定向共训（离线先行）→ ④I5 全身恢复。平移通道只有在 ①② 显示明确边缘收益且组委会确认后才进入 L2。

**统计纪律**：每轴每任务仅 2 次，轴级结论必须跨任务聚合（每轴 64 trial，SE≈5.7pp）；任何单任务 A/B 只作方向性证据，不单独宣布显著。

## 6. 本轮最值得押注（一句话）

**押「地形签名 + 一次性全身构型适应」：在 reset 期用一次低成本地形估计，把基座高度/腰部摆到任务签名附近，再用硬约束投影兜底；它把 I1/I2/I9 的数据优势兑现成评测时的「够得到、看得见、不撞桌」，同时用「高度优先、可逆、低增益」避开连续基座运动的失稳风险。**

**本轮最大风险**：全身通道的示教占比仅约 1.7%（F22），数据几乎没教过策略怎么用基座/腰部；若把未验证的 `pivot` 维度或连续基座运动直接上计分通道，可达性收益可能被失稳、碰撞与延迟尖峰吞掉。
