# 第 60 轮（承接第 59 轮「执行接地层」IP-145~151；灵感循环第 6 轮；本轮灵感：「实时推理」×「关节空间控制」）

> 第 59 轮把证据层一路接地到执行层：BUQ 辨识电机结构性不确定性、ERTC 契约化嵌入式时限、EEIS 把 δ_f 编译成末端阻抗证书、CLEP 让执行实测回传为第 5 模态。但它仍然隐含两个**终局假设**：其一，「证据层与元认知的计算是瞬时且免费的」——UKF、共形校准、XMC 融合、μ 分析、Pareto 投影全都当作零耗时神谕，忽略了它们本身就是有截止期、会截断、会降精度的**实时推理过程**；其二，「末端阻抗参数可以直接下发即执行」——EEIS 产出的是**任务空间**的 (K_x, D_x, F_max, ω_traj)，而真实冗余机械臂必须在**关节空间**经由 J^T、零空间、关节限位、力矩饱和、奇异位形才能兑现它。本轮两个灵感正好击中这两个「最后一毫米」的抽象泄漏：**实时推理**要求把「推理精度」变成**可调度、可截断、可定价**的资源；**关节空间控制**要求把「任务空间安全证书」继续编译成**构型相关的关节可实现性证书**。本轮核心命题：**「安全证书必须同时通过两重编译——沿时间轴编译到截止期（时限可调度），沿运动学链编译到关节力矩（构型可实现）；任一维不可兑现，证书即作废并降级」**——即**时空一致的安全编译**。

核心矛盾：
- **H32（推理时限泄漏·计算致过自信）**：第 59 轮的证据层在 1~10 Hz 决策，但其中的元推理（结构化似然、跨模态对账、共形校准、μ 验证、Pareto 投影）在负载下可能无法在周期内收敛。若在截止期强行取「半成品后验」，其误差不是经典观测噪声，而是**计算截断偏差**；不建模就等于在错误似然上再做一次「自洽幻觉」。更隐蔽的是：**anytime 算法越早返回越保守**这一性质并不自动成立，许多迭代推理（MCMC、UKF 迭代、共形重校准）早停会**系统性偏乐观**。
- **H33（任务-关节空间不可兑现）**：EEIS 的 K_safe 是任务空间阻抗，但真实下发的是关节力矩 τ=J^T(K_x e+D_x ė)+τ_null+τ_g。**奇异位形**处 σ_min(J)→0，某些任务方向的位移权威丧失；**关节力矩上限** |τ_i|≤τ_max 使高刚度不可兑现；**冗余零空间**与**关节限位**又要求姿态分配。于是完全可能出现：**Cert_eeis 说「鲁棒稳定、力约束满足」，而 J^T K_x J 早已超出关节力矩预算**——证书合格、执行崩溃。
- **H34（构型鲜度·时间的运动学化）**：第 59 轮用墙钟 τ_evidence 定义证据鲜度，但阻抗证书的有效性其实依赖于**构型**：同一个 K_x，在 q0 处合法，机械臂运动 50 ms 后经过奇异位形，J(q) 变了，证书就失效。**证据不是随时间陈旧，而是随构型漂移陈旧**；只看时间会造成「时戳很新、构型已死」的漏检。

## 0. 直觉与动机

**灵感 1（实时推理 → 任意时间推理契约 AIC）**
直觉：把推理流水线看成一条**有截止期的实时任务链**，每一级算法 A_s 都有**精度-时延曲线** ε_s(d)：给的算力/时间越多，误差越小（单调不增，直到收敛）。与其祈求「总能算完」，不如**显式契约化**：C_inf=(D_inf, {d_s^min,d_s^max}, {ε_s^req}, fallback_s, priority)。调度器在总截止期 D_inf 内按**每毫秒 VOI** 分配时间片，优先保证「安全关键级」（如 μ 可行性、力矩可行性）达到 ε_s^req，非关键级（如精细类别后验）允许早停。关键洞见：**早停不是失败，而是一种带已知精度损失的合法输出**——前提是损失必须被量化并注入下一级。

**灵感 2（计算致不确定性 → CIU）**
直觉：截断推理的后验 p_d(θ) 与收敛后验 p_∞(θ) 之间有一个**TV 距离上界** Δ_s(d)，它由精度-时延曲线给出。于是「计算」变成一种新的**似然污染源**：用温度化/协方差膨胀把 p_d 校正为 p_d^{cal}=p_d ⊗ N(0, Σ_CIU(d))，其中 Σ_CIU(d)=J_s Δ_s(d) J_s^T。等价地，在证据代数里给每次推理记一笔**推理债**（inference debt）：算得越少，债越多，后验越宽、动作越保守。只有当 d≥d_converge 时债务归零。这样 anytime 推理的「快」不再免费，而被**定价**进安全预算。

**灵感 3（关节空间控制 → 关节可实现性证书 JRC）**
直觉：任务空间证书到关节空间之间隔着**雅可比的谱**。令 J=UΣV^T。要沿任务方向 u_i 产生力 F，所需关节力矩为 σ_i v_i F；要维持任务刚度 k_i，需 k_i·δ_x ≤ τ_max/σ_i 且位移权威 σ_i≥σ_min^req。更本质地：K_q=J^T K_x J 才是关节真正「感到」的刚度；K_x 在 range(J) 的正交补上**不可实现**（无任何关节力矩能产生该方向力）。再叠加零空间姿态力矩与关节限位，得到**构型相关**的可实现集 K_x^reach(q,τ_max,κ_max)。在线编译变成**二次投影**：K_x^safe = K_safe^{EEIS} ∩ K_x^reach(q)；若交集为空，先试零空间换姿态（不改任务力）、再试软化 K_x、最后降级停。证书 Cert_jrc 记录 σ_min、κ、μ_J、K_q、力矩余量、限位余量，**任务空间合格不再等于安全**。

**灵感 4（时空合流 → 构型鲜度 CSF 与时-运动学共契约 TKC）**
直觉：证书是与构型绑定的局部对象。定义**构型球** B(q0,δq)={q | κ(J(q))≤κ_max ∧ σ_min(J(q))≥σ_min^req ∧ JRC 余量仍成立}；证据鲜度条件从「墙钟未过期」升级为「q(t)∈B(q0,δq)」。更进一步，推理要花 D_inf 才返回，返回后关节环还要执行 T_j；因此必须保证 **[dispatch, dispatch+D_inf+T_j] 内构型不出球**——用轨迹预测做**前瞻守卫**：预测出球则减速/冻结/预编译。时间契约与运动学契约由此**耦合**：推理越快，允许的运动越快；运动越快，构型球越小、需要更频繁重编译——形成可计算的**速度-精度-稳定性三角**。

**灵感 5（预算扩展 → PCE++++：推理预算 × 关节权威预算）**
直觉：第 59 轮有 B_probe/B_ft/B_ux/B_exec。本轮新增 **B_inf=(latency_slack, energy_slack, accuracy_slack)** 与 **B_kin=(torque_margin, manipulability_margin, singularity_margin, joint_limit_margin)**。VOI 扩展为 voi = VOI_meta_pessimistic − cost_exec − cost_inf − cost_kin：一个「更有信息量但更慢/更费算力/更逼近奇异」的探针，可能在推理预算或关节权威上破产。预算耗尽只能导致**更保守**：降推理精度（并记推理债）、软化阻抗、减速、绕行或停。六预算硬隔离、互不挪用。

## 1. 形式化定义（增量：定义 153–160）

**定义 153（任意时间推理契约 AIC）** 推理流水线为阶段 DAG 𝒮，每级 s∈𝒮 的 anytime 算法 A_s 具有精度-时延曲线 ε_s(d):ℝ_{≥0}→[0,ε_s^max]，单调不增，且在 d≥d_s^conv 后达到 ε_s^∞。契约 C_inf=(D_inf, {d_s^min,d_s^max}_{s∈𝒮}, {ε_s^req}, {fallback_s}, π_prio)。可行调度 σ:𝒮→ℝ_{≥0} 满足 Σ_s σ(s)≤D_inf、d_s^min≤σ(s)≤d_s^max、且关键级 ε_s(σ(s))≤ε_s^req。调度目标：
```
σ* = argmax_σ  Σ_s VOI_s(ε_s(σ(s)))      s.t.  Σ_s σ(s) ≤ D_inf,  硬约束如上
```
fallback_s 必须是**显式保守输出**（加宽共形带/返回「不可判定」），禁止静默返回点估计。违约（关键级未达 ε_s^req 或 Σσ>D_inf）⇒ 推理降级 INF_DEGRADE，并强制注入 CIU。

**定义 154（计算致不确定性 CIU 与推理债）** 对每级 s，若在 d<d_s^conv 截断，定义截断偏差上界 Δ_s(d)=sup_θ TV(p_s^d(·), p_s^∞(·))≤ε_s(d)。计算致协方差膨胀：
```
Σ_CIU(d) = Σ_s J_s · Δ_s(d)^2 · J_s^T ,   J_s = ∂g/∂(stage output)
```
校正后验 p_cal(θ) ∝ p_trunc(θ) · N(0,Σ_CIU(d))。推理债 debt_s(d)=Δ_s(d)/ε_s^req。**任意时间校准契约**：对每个截止期分位 d，校准误差 ECE(d)≤ε_meta+δ_CIU(d) 必须成立（不是只在 d=d_conv 成立）。执行 OOD：若 d_s<d_s^min 或 debt_s>1 ⇒ 判「推理不可信」，回退保底带。

**定义 155（关节可实现性证书 JRC）** 构型 q∈ℝ^n，雅可比 J(q)∈ℝ^{6×n}，SVD J=UΣV^T，奇异值 σ_1≥…≥σ_r>0，σ_min=σ_r，κ=σ_1/σ_min，可操作度 μ_J=√det(JJ^T)=∏_{i≤r}σ_i。任务阻抗 K_x,D_x 的关节映射 K_q=J^T K_x J。可实现集：
```
K_x^reach(q) = { K_x ⪰ 0 |
    λ_max(J^T K_x J) ≤ K_q^max = τ_max^eff / δ_q ,              # 力矩可兑现
    ‖K_x (I − U_r U_r^T)‖_F = 0 ,                               # 不可驱动方向无刚度
    σ_min(J(q)) ≥ σ_min^req ∧ κ(J(q)) ≤ κ_max ,                # 位移权威/非奇异
    |τ_i| = |(J^T K_x e + τ_null + τ_g)_i| ≤ τ_max,i − ε_τ ,   # 逐关节力矩余量
    q + J^+ Δx + N q̇_0 ∈ [q_min, q_max] ,                       # 零空间不越限
    μ_J(q) ≥ μ_min }                                            # 可操作度门
```
在线二次编译：K_x^safe = K_safe^{EEIS} ∩ K_x^reach(q)。若为空：① 零空间姿态搜索 q'∈N(J) 使 K_x^safe 非空；② 沿「柔顺优先」方向软化 K_x；③ 仍空 ⇒ DEGRADE_EXEC。输出 Cert_jrc=(q,J,σ_min,κ,μ_J,K_q,τ_task,τ_null,τ_g,τ_margin,q̇_margin,feasible,version)。

**定义 156（构型鲜度 CSF）** 证书在 q0 处的有效构型球：
```
B(q0,δq) = { q | ‖q−q0‖_M ≤ δq_max(q0),
                 κ(J(q)) ≤ κ_max, σ_min(J(q)) ≥ σ_min^req, μ_J(q) ≥ μ_min,
                 JRC(q) 的力矩/限位余量 ≥ 0 }
```
证据鲜度从墙钟升级为**运动学鲜度**：证书可用 ⇔ q(t)∈B(q0,δq)。定义构型漂移 τ_kin=inf{t: q(t)∉B}。若 τ_kin 将早于「证书计划使用终点」，必须在越界前**重编译 JRC/EEIS** 或减速/冻结。概率版：轨迹预测误差 e_q~N(0,Σ_q) ⇒ 出球概率 P_exit=Pr[q(t)+e_q∉B]≤δ_kin。

**定义 157（时-运动学共契约 TKC）** C_tk=(D_inf, T_j, L_jrc, δq_max, κ_max, σ_min^req, π_dual)。联合可行性条件：
```
∀t∈[t_disp, t_disp+D_inf+T_j+L_jrc]:  q(t) ∈ B(q0,δq)  (高概率 1−δ_kin)
```
π_dual 为双优先级：关节环（1~2 kHz）硬实时、最高优先级；推理任务在截止期下尽力而为，**超时必须让出**并返回 CIU 加权的 anytime 结果，禁止优先级反转。若联合不可行 ⇒ 减速（压缩 q(t) 变化）或冻结等待推理，二者只能使动作更保守。

**定义 158（时空闭环 CLEP+）** 在 CLEP 上扩展：

```
① AIC: (inf, σ, debt, Σ_CIU) ← anytime_schedule(obs, M, D_inf)
② ERTC: contract_ok ← M_rt.check()                  # 第59轮
```

**定义 159（B_inf/B_kin 与 PCE++++）** B_inf=(latency_slack, energy_slack, accuracy_slack)，B_kin=(τ_margin, μ_margin, σ_margin, q_margin)。VOI：
```
voi(π) = VOI_meta_pessimistic(π) − cost_exec(π) − cost_inf(π) − cost_kin(π)
cost_inf = λ_lat·max(0, T_inf(π)−latency_slack) + λ_E·max(0, E_inf(π)−energy_slack)
         + λ_acc·max(0, ε_ach(π)−accuracy_slack)
```

## 2. 关键算法伪代码

### IP-152 AIC（任意时间推理调度）

```python
def anytime_schedule(stages, D_inf, eps_req):
    # 逐级精度-时延曲线由离线验证得到：eps_s(d) 单调不增
    # 关键级先满足硬下限，再用剩余预算做 VOI/ms 的贪心分配
    t = {s: s.d_min for s in stages}
    rem = D_inf - sum(t.values())
    if rem < 0:
        return None, "infeasible_min_time"
    for s in critical_stages(stages):
        need = s.d_for(eps_req[s])
        if t[s] < need:
            if rem < need - t[s]:
                return None, f"critical_stage_unmet:{s.name}"
            rem -= need - t[s]; t[s] = need
    while rem > 1e-6:
        gains = [(voi_per_ms(s, t[s]), s) for s in stages
                 if t[s] < s.d_max]
        if not gains: break
        g, s = max(gains)
        dt = min(s.dt_quantum, rem, s.d_max - t[s])
        if g * dt <= THETA_VOI_MS: break
        t[s] += dt; rem -= dt
    return t, "ok"

def run_anytime(stages, t):
    out = {}
    for s in stages:
        out[s] = s.run(deadline=t[s])          # 可能早停
        s.debt = s.eps(t[s]) / max(s.eps_req, 1e-12)
        s.sigma_ciu = s.jac() @ (s.eps(t[s])**2) @ s.jac().T
    return out
```

### IP-153 CIU（计算致不确定性注入）

```python
def inject_compute_uncertainty(posterior, stages):
    Sigma_ciu = sum((s.sigma_ciu for s in stages), zeros(d))
    debt = max(s.debt for s in stages)
    if debt > 1.0:
        return widen_conformal(posterior, factor=DEBT_WIDEN), "INF_DEGRADE"
    # 温度化：截断后验按债务升温，避免系统性过自信
    temper = 1.0 + KAPPA_CIU * debt**2
    posterior = temper_posterior(posterior, temper)
    posterior.cov += Sigma_ciu
    return posterior, "ok"
```

### IP-154 JRC（关节可实现性编译）

```python
def joint_realize(K_safe, q, tau_max, q_min, q_max, opts):
    J = jacobian(q); U, S, Vt = svd(J)
    sigma_min, kappa = S[-1], S[0]/max(S[-1], 1e-12)
    mu_J = float(np.prod(S[S > 1e-9]))
    if sigma_min < opts.sigma_min_req or kappa > opts.kappa_max or mu_J < opts.mu_min:
        return None, None, "kinematic_margin"
    # 任务空间候选集由 EEIS 给出；逐点核验关节可实现性
    feasible = []
    for Kx in K_safe:
        Kq = J.T @ Kx @ J
        if np.linalg.eigvalsh(Kq).max() > opts.Kq_max:      continue
        # 不可驱动方向：要求 Kx 在 range(J) 正交补上无刚度
        if np.linalg.norm(Kx @ (np.eye(6) - U[:, :rank(J)] @ U[:, :rank(J)].T)) > 1e-6:
            continue
        # 最坏位移方向上的关节力矩
        dx = worst_case_disp(Kx, opts.delta_x)
        tau_task = J.T @ (Kx @ dx)
        tau_g = gravity(q)
        # 零空间姿态：解 QP 使力矩/限位余量最大，且不改变任务力
        tau_null = solve_null_qp(J, tau_task + tau_g, tau_max, q, q_min, q_max)
        tau = tau_task + tau_null + tau_g
        if np.any(np.abs(tau) > tau_max - opts.eps_tau):    continue
        dq = np.linalg.pinv(J) @ dx + null_basis(J) @ tau_null
        if np.any(q + dq < q_min) or np.any(q + dq > q_max): continue
        feasible.append((Kx, Kq, tau, tau_task, tau_null,
                         tau_max - np.abs(tau), mu_J, sigma_min, kappa))
    if not feasible:
        return None, None, "no_jointly_realizable"
    best = max(feasible, key=lambda f: (task_speed(f), compliance(f)))
    cert = JRCertificate(q=q, J=J, Kx=best[0], Kq=best[1],
```

### IP-152 AIC（任意时间推理契约与调度）

```python
from dataclasses import dataclass, field

@dataclass
class InferenceContract:
    D_inf: float
    d_min: dict          # stage -> minimum time
    d_max: dict          # stage -> max useful time (convergence)
    eps_req: dict        # stage -> required accuracy
    critical: set        # safety-critical stages
    fallback: dict       # stage -> conservative fallback fn
    quantum: float = 0.1e-3   # 100 us 时间片

class AnytimeScheduler:
    def __init__(self, stages, C_inf):
        self.stages = stages
        self.C = C_inf
        self.log = []

    def schedule(self):
        t = {s.name: self.C.d_min[s.name] for s in self.stages}
        rem = self.C.D_inf - sum(t.values())
        if rem < 0:
            return None, "infeasible_min_time"
        # 1) 关键级硬下限：安全相关阶段必须先达标
        for s in self.stages:
            if s.name not in self.C.critical: continue
            need = s.d_for(self.C.eps_req[s.name])
            if t[s.name] < need:
                delta = need - t[s.name]
                if rem < delta:
                    return None, f"critical_unmet:{s.name}"
                t[s.name] += delta; rem -= delta
        # 2) 剩余预算按 VOI/ms 贪心分配
        while rem > 1e-9:
            cands = []
            for s in self.stages:
                if t[s.name] >= self.C.d_max[s.name]: continue
                g = self.voi_per_ms(s, t[s.name])
                cands.append((g, s))
            if not cands: break
            g, s = max(cands, key=lambda x: x[0])
            dt = min(self.C.quantum, rem, self.C.d_max[s.name] - t[s.name])
            if g * dt <= THETA_VOI_MS: break
            t[s.name] += dt; rem -= dt
        self.log.append({"t": dict(t), "rem": rem, "at": time.monotonic()})
        return t, "ok"

    def voi_per_ms(self, s, t):
        # 用精度-时延曲线的边际收益 × 下游任务权重近似
        d_eps = s.eps(t) - s.eps(min(t + self.C.quantum, s.d_conv))
        return s.task_weight * d_eps / (self.C.quantum * 1e3)

    def run(self, t):
        out = {}
        for s in self.stages:
            out[s.name] = s.run(deadline=t[s.name])   # 允许早停
            s.last_eps = s.eps(t[s.name])
            s.last_debt = s.last_eps / max(self.C.eps_req[s.name], 1e-12)
            s.last_ciu = s.jac() @ (s.last_eps ** 2) @ s.jac().T
        return out
```

```python
class ComputeInducedUncertainty:
    def __init__(self, kappa=1.0, widen_factor=3.0):
        self.kappa = kappa
        self.widen_factor = widen_factor

    def inject(self, posterior, stages):
        debt = max(s.last_debt for s in stages)
        Sigma = sum((s.last_ciu for s in stages), np.zeros_like(posterior.cov))
        if debt > 1.0:
            # 推理不可信：回退保底带（只加宽，不收缩）
            return widen(posterior, self.widen_factor), debt, "INF_DEGRADE"
        temper = 1.0 + self.kappa * debt ** 2
        p = temper_posterior(posterior, temper)   # 防止早停系统性过自信
        p.cov = p.cov + Sigma
        return p, debt, "ok"

    def calibrate_anytime(self, validation_set, deadlines):
        # 逐截止期分位校准：不允许只在 d_conv 处校准
        report = {}
        for d in deadlines:
            ece = expected_calibration_error(validation_set, deadline=d)
            report[d] = ece
            if ece > EPS_META + 0.03:
                raise AnyTimeCalibrationError(f"ECE({d})={ece} too high")
        return report
```

```python
@dataclass
class JRCertificate:
    q: np.ndarray
    J: np.ndarray
    Kx: np.ndarray
    Kq: np.ndarray
    tau_task: np.ndarray
    tau_null: np.ndarray
    tau_g: np.ndarray
    tau_margin: float
    q_margin: float
    sigma_min: float
    kappa: float
    mu_J: float
    version: int
    timestamp: float

class JointRealizabilityCompiler:
    def __init__(self, robot, opts):
        self.robot = robot
        self.opts = opts
        self.version = 0

    def compile(self, K_candidates, q):
        J = self.robot.jacobian(q)
        U, S, Vt = np.linalg.svd(J, full_matrices=True)
        r = int(np.sum(S > 1e-9))
        sigma_min = float(S[r-1]) if r > 0 else 0.0
        kappa = float(S[0] / max(sigma_min, 1e-12))
        mu_J = float(np.prod(S[:r])) if r > 0 else 0.0
        if (sigma_min < self.opts.sigma_min_req or
                kappa > self.opts.kappa_max or mu_J < self.opts.mu_min):
            return None, None, "kinematic_margin"

        Ur = U[:, :r]
        null_task = np.eye(6) - Ur @ Ur.T
        feasible = []
        for Kx in K_candidates:
            Kq = J.T @ Kx @ J
            if np.linalg.eigvalsh(Kq).max() > self.opts.Kq_max:
                continue
            if np.linalg.norm(Kx @ null_task) > 1e-6:
                continue                      # 不可驱动方向不得有刚度
            dx = self.worst_case_disp(Kx, self.opts.delta_x)
            tau_task = J.T @ (Kx @ dx)
            tau_g = self.robot.gravity(q)
            tau_null, ok = self.solve_null_qp(J, tau_task + tau_g, q)
            if not ok: continue
            tau = tau_task + tau_null + tau_g
            if np.any(np.abs(tau) > self.robot.tau_max - self.opts.eps_tau):
                continue
            N = self.robot.null_basis(J)
            dq = np.linalg.pinv(J) @ dx + N @ tau_null
            if np.any(q + dq < self.robot.q_min) or np.any(q + dq > self.robot.q_max):
                continue
            feasible.append((Kx, Kq, tau, tau_task, tau_null, tau_g,
                             float(np.min(self.robot.tau_max - np.abs(tau))),
                             mu_J, sigma_min, kappa))
        if not feasible:
            return None, None, "no_jointly_realizable"
        best = max(feasible, key=lambda f: (self.speed_score(f), self.compliance_score(f)))
        self.version += 1
        cert = JRCertificate(q=q, J=J, Kx=best[0], Kq=best[1],
                             tau_task=best[3], tau_null=best[4], tau_g=best[5],
                             tau_margin=best[6], q_margin=self.q_margin(q),
                             sigma_min=best[8], kappa=best[9], mu_J=best[7],
                             version=self.version, timestamp=time.monotonic())
        return best[0], cert, "ok"

    def solve_null_qp(self, J, tau_required, q):
        # min ||tau_null||^2  s.t.  J^T tau_null = 0（不改变任务力）, 力矩/限位余量
        # 实际用一个小 QP：变量 tau_null，约束 tau_required+tau_null 在界内
        N = self.robot.null_basis(J)                 # n x (n-r)
        z = solve_qp_limits(N, tau_required, self.robot.tau_max,
                            self.robot.q_min - q, self.robot.q_max - q)
        return N @ z, z is not None

    def score(self, f):
        return self.speed_score(f) + self.compliance_score(f)
```

```python
class ConfigFreshnessGuard:
    def __init__(self, kin_params, delta_kin=1e-3):
        self.p = kin_params
        self.delta_kin = delta_kin

    def in_ball(self, q, q0):
        J = self.p.robot.jacobian(q)
        S = np.linalg.svd(J, compute_uv=False)
        r = int(np.sum(S > 1e-9))
        if r == 0: return False
        sigma_min, kappa = S[r-1], S[0]/max(S[r-1], 1e-12)
        mu_J = float(np.prod(S[:r]))
        if sigma_min < self.p.sigma_min_req: return False
        if kappa > self.p.kappa_max: return False
        if mu_J < self.p.mu_min: return False
        if np.linalg.norm(q - q0, ord=np.inf) > self.p.delta_q_max: return False
        return True

    def guard(self, q0, q_pred, Sigma_q):
        for t, q in enumerate(q_pred):
            if not self.in_ball(q, q0):
                return False, t, "config_left_ball"
            if self.exit_prob(q, Sigma_q) > self.delta_kin:
                return False, t, "prob_exit_exceeds_delta_kin"
        return True, len(q_pred), "ok"

    def exit_prob(self, q, Sigma_q):
        # 用一阶/采样近似构型球边界穿越概率
        return monte_carlo_exit_prob(q, Sigma_q, self.in_ball_boundary)
```

**正确性定理（Temporal-Kinematic Grounded Evidence Soundness, TKGES）**
假设 A22–A55（第 53–59 轮）成立；**(A56)** AIC：各级 anytime 精度-时延曲线在**每个截止期分位**经离线验证校准，ε_s(d) 是截断 TV 偏差的诚实上界；关键级未达 ε_s^req 必触发 INF_DEGRADE。**(A57)** CIU：Σ_CIU(d) 覆盖截断后验与收敛后验之差，债务>1 必回退保底带；任意时间校准 ECE(d) 成立。**(A58)** JRC：雅可比/重力/惯量模型误差有界，K_q=J^T K_x J 精确；不可驱动方向刚度为零；零空间 QP 不改变任务力；力矩、限位、奇异、可操作度门无漏报。**(A59)** CSF/TKC：构型球定义单调；轨迹预测误差上界与 δ_kin 诚实；越界前必重编译/减速；关节环不被推理抢占。**(A60)** PCE++++：六预算单调消耗、互不挪用；cost_inf/cost_kin 诚实上界；任一耗尽只导致更保守动作。则：

1. **任意时间校准健全性**：截断推理下 ECE_k≤ε_meta(k)+δ_exec+δ_CIU(d)，覆盖率≥1−α_conf−δ_CIU(d)−δ_ξ_ood。
2. **关节可实现安全性**：下发 τ 在 q 处满足逐关节力矩、限位、σ_min、κ、μ_J 硬约束，且 K_q=J^T K_x^safe J；K_x^safe=∅ ⇒ 换姿态/软化/降级，不伪造可实现性。
3. **构型鲜度安全性**：证书仅在 B(q0,δq) 内使用；P(越球使用)≤δ_kin；越界 ≤1 重编译周期感知。
4. **实时隔离性**：推理超时不使关节环抖动超 Jitter_bound；额外抖动≤δ_tk，违约即降级。
5. **单调保守性**：CIU 注入、推理债、JRC 不可行、CSF 越界、预算耗尽只能加宽/软化/减速/停。
6. **终止性与部署界**：PCE++++ 在 k_probes+k_cons+k_ft+k_ux+k_exec+k_inf 内终止于 {承诺(双证书), 绕行, 降档, L2 协商, 安全停, 推理降级停, 运动学降级停}。

## 6. 本轮最大风险

**一句话**：本轮把证书从任务空间一路编译到关节力矩，并给推理加上截止期与推理债，但**若精度-时延曲线只在收敛点校准、JRC 使用标称雅可比而忽略关节柔顺/背隙/负载依赖传动、或 CSF 的构型球用了乐观的轨迹预测误差界，就会在奇异位形附近给出「证书合格但力矩爆炸」或「时戳很新但证书已失效」的致命假阳性**；必须以「逐截止期分位校准 + 债务>1 硬回退」「区间/鲁棒雅可比 + 力矩/限位/奇异硬门」「构型球零越球门 + 越界前重编译」「推理与关节环双优先级硬隔离」四重护栏封死，宁可频繁降级「又慢又笨」，绝不允许任何一次「证书通过但物理不可兑现」。
