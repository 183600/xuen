# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「少样本学习」×「仿真到现实迁移」）

> R69 让系统学会了「问」：把不确定性拆成 aleatoric / epistemic，用流匹配多模态策略 + 主动多模态交互去消解后者。但 R69 有一个隐含假设——**策略所在的分布就是部署所在的分布**。它把「模态权重是否可信」交给 MCG（ECE 门控），把「行为是否异常」交给 FMA（流似然），而这两者都只在**仿真/训练分布内**有意义。真实部署里，流策略是仿真里训出来的，真实世界只给得起 k 条（常常 k≤5）轨迹；此时：
> - 模态权重是**仿真先验的产物**，不是真实世界的校准结果；
> - 高流似然可能只是「仿真器喜欢这个动作」，低流似然可能只是「真实世界有仿真里没有的摩擦」——R69 的第二意见会把**域差**误报成**故障**，或者更糟，把仿真器特有的失败模式当成正常；
> - R69 的 MINT 只会「问人/看场景」，但有些不确定性根本不在人那里——「真实摩擦是 0.3 还是 0.5」「执行器延迟是 20ms 还是 60ms」问人是问不出来的，只能**问真实世界**。
>
> 本轮两个灵感正好补上这两块：
> - **仿真到现实迁移**告诉我们：部署是一个**域参数后验**问题。域随机化给出先验 p_0(θ_d)，真实世界用少量轨迹给出似然，于是得到一个**少样本域后验** q_k(θ_d)；安全包络必须在后验可信集上**逐域鲁棒**，而不是在名义域上认证。
> - **少样本学习**告诉我们：k 很小也能做事，但必须换一种做法——**离线元学习先验 + 在线只做前向推断**（amortized SBI）、**少样本保形校准**（finite-sample coverage）、**主动系统辨识**（用最值钱的一小步真实实验换最大的域信息）。
>
> 核心命题：**把 epistemic 再按「信息源」拆开：关于任务/意图的歧义（U_epi^task）问人/看场景；关于世界模型/域参数的歧义（U_trans）只能问真实世界。信息动作必须与不确定性来源匹配（source-matched routing）；用少样本域后验、保形模态集与逐域鲁棒安全包络，把 R69 的「可能问错」升级为「知道该问谁、且知道问了之后还差多少」。** 命名 **BRIDGE-RAS**（Bayesian Real-to-sim Inference with Domain-Gap Estimation for Risk-Adaptive Safety）。
>
> 定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「该向谁求证」，R70 问「**我的世界模型还配得上这个真实世界吗；几帧真实数据够不够把它校准到敢用**」。

## 0. 直觉与动机

**灵感 1（仿真到现实 → 不确定性有第三个源：域）**
直觉：R69 把 epistemic 当成一个整体，默认「多问几次就能收窄」。但真实部署里，最大的 epistemic 往往不是「人想让我走左边还是右边」，而是「我脑子里的物理和眼前的物理差多少」。前者可以问人；后者问人没用，必须做实验。把域参数 θ_d（摩擦、质量、延迟、接触刚度、传感器偏置）显式化后，R69 的模态不确定性可以进一步分解：
`H(M|o) = I(M; θ_d|o) + H(M|o,θ_d)`。
右边第二项是「就算知道域参数也还在的任务歧义」，交给 R69 的 MINT；第一项是「因为不知道域参数而产生的模态歧义」，只能靠真实数据/主动探针降低。**这是本轮最重要的结构性区分：不是所有 epistemic 都该用同一种信息动作去解。**

**灵感 2（少样本学习 → k 很小不是借口，是约束）**
直觉：真实部署给不起大规模标注，往往只有 k=1~10 条轨迹。few-shot 的正确姿势不是「拿 k 条微调整个大模型」（会灾难性遗忘/过拟合），而是：
- 用**离线元学习**把「如何从 k 条数据推断域」学成一个**摊销推断器** q_φ(θ_d | e_{1:k})，部署时只做前向；
- 用**低维域参数**（d_d 小）使 k-shot 后验可辨识；k 与 d_d 不匹配时，后验必须保持宽（保守），而不是假装收敛；
- 用**保形预测**给出有限样本覆盖：k 条校准样本下，最小可达误覆盖率是 1/(k+1) —— 这是一个硬下界，k=5 时连 90% 都保证不了。few-shot 的诚实做法是**把「不够」显式写进安全包络**，而不是把 k 条样本的均值当真理。

**灵感 3（源匹配 → 问错对象比不问更危险）**
直觉：R69 的最大风险是「追问一个幻影」。R70 指出一个更根本的错误：**把域不确定性拿去问人**。如果系统把「真实摩擦未知」误判成「人类意图歧义」，它会去问「你希望我从上面抓还是侧面抓？」——人给了一个答案，系统以为消除了不确定性，实际上摩擦仍然是错的，动作仍然会滑。更糟的是，人的回答会被当作「已验证」的证据，盖上一个错误的章。**信息动作的价值，首先取决于它是否作用在正确的不确定性源上。** 这就是源匹配原则：task-epistemic → 人/场景；transfer-epistemic → 真实世界探针；aleatoric → 不问，直接收紧。

**灵感 4（少样本保形 → 给 R69 的模态权重上保险）**
直觉：R69 的 MCG 用 ECE 检查模态权重，但 ECE 是在**有标签的校准集**上算的；仿真标签再多，也不等于真实标签。少样本保形把「模态权重可信吗」变成一个**分布无关的覆盖问题**：用真实部署中少量**已核实**的 episode 做校准，构造模态预测集 C_α(o)，使得在可交换性下 `P(M* ∈ C_α) ≥ 1−α`。若 C_α 仍然多模态，说明 k 条不够、歧义仍在，继续保守或继续问；若 C_α 为空，说明「真实模态不在模型假设里」——这比 R69 的 ECE 越界更早、更直接地报警。分布漂移下用 ACI 维持长期覆盖率，并显式承认它给不了单步保证。

**灵感 5（严格包含 + 新威胁 → R69 是「域已知、样本无限」的边界）**
直觉：当域后验收缩到名义域（q_k=δ_{θ0}）、可信集退化为单点、且校准集与部署可交换时，BRIDGE-RAS 必须逐指令退化为 FLUID-RAS；当 k=0 时把 U_trans 整体并入 U_floor，退化为 R68 的纯保守。新层不推翻旧层，只在「域未知 + 样本极少」的边界外加上一段**少样本迁移**。
但 few-shot 也带来新的攻击面：**校准样本可以被挑选/投毒**（只给你看干燥地面，部署时是油面），**元先验可以漏掉真实物理**（真实世界根本不在域随机化支撑集里），**保形覆盖在非可交换下失效**，以及**把真实故障归因成域差**（gap 成为新的「标定吸收」）。所以本轮必须同时交付：校准数据卫生、负迁移检测、域外/新物理检测、以及「域差解释」与「故障」的可辨识判据。

## 1. 形式化定义（增量：定义 310–327）

**定义 310（BRIDGE-RAS 总览）** BRIDGE-RAS = (DPM, ASI, TAU, GNF, FSC, RSE, APT, JIB, NTG, ABF, VQA-B, RAS-WM‡)。四不变式：
(i) **实时安全路径零学习写操作**（继承 R68/R69 定义 276-i）；
(ii) **适配隔离**：域后验、保形表、适配器只在轮间、隔离进程更新，且更新后须通过认证并影子运行才可换装；
(iii) **逐域鲁棒认证**：所有安全认证在域可信集 C_ε(q_k) 上进行，不得只对后验均值认证；
(iv) **证据纪律扩展**：校准样本不得同时用于定案/验证（no double-dipping），单条样本不得把系统从保守切到激进。

**定义 311（部署设定与少样本 episode）** 真实部署给出 episode 序列 e_i = {(o_t, a_t, o_{t+1})}_{t=1}^{H_i}，i=1..k，k 很小（1–10）。域参数 θ_d ∈ Θ_d ⊂ ℝ^{d_d}，d_d 低维（≤8）。任务模态 M ∈ {1..K}。仿真器族 {Sim_θ} 由 θ_d 参数化；域随机化给出先验 p_0(θ_d)。真实数据生成分布 P_{θ*}，θ* 未知且可能不在 supp(p_0) 内。

**定义 312（域后验与摊销 SBI）** `q_k(θ_d) := q_φ(θ_d | e_{1:k})`，由离线训练的神经后验（normalizing flow）近似 `p(θ_d | e_{1:k}) ∝ p_0(θ_d) ∏_i p(e_i | θ_d)`。训练数据来自域随机化仿真；部署时只做前向，不写参数。**少样本温度回退**：`q_k ← (1−β) q_k + β p_0`，`β = max(0, 1 − k/d_d)`；即样本数不足以约束 d_d 维后验时，强制退回先验，宁可宽不可假窄。

**定义 313（域条件流策略与模态）** 条件编码器扩展为 `z_t = Φ(o_t, θ_d)`，速度场 `v_θ(x_s, s | z_t)`；给定 θ_d 采样得模态 `{m_j(θ_d)}`、权重 `ŵ_j(θ_d)`。后验预测模态分布 `p(M|o,e_{1:k}) = ∫ p(M|o,θ_d) q_k(dθ_d)`。R69 的 FMP 是 `q_k = δ_{θ0}` 的单点特例。

**定义 314（三分不确定性）**
- `U_ale = E_{θ~q_k} Σ_j ŵ_j(θ) tr Σ_j(θ)`（模态内噪声，方差量纲）；
- `U_epi^task = E_{θ~q_k} [H_mode(θ)·g(Δ_min(θ))]`（知道域后仍有的任务歧义，继承定义 297 的熵尺度形式）；
- `U_trans = I(M; θ_d | o, e_{1:k}) = H(M|o,e) − E_θ H(M|o,θ)`（由域未知贡献的模态歧义）+ `λ_g·G_0`（未解释的模型差异项）。
三者语义不同，不做简单加和：`U_ale → λ_floor`；`U_epi^task → MINT`（人/场景）；`U_trans → APT`（真实世界探针）+ 少样本证据；`G_0`（新物理/域外）→ 不学习，直接 R68 保守 + 人工升级。

**定义 315（gap 归一化流似然与四分类归因）** 定义
`a_raw = −log p_{θ0}(ξ|o)`（R69 的 FMA）；
`a_adapt = −log ∫ p_θ(ξ|o,θ_d) q_k(dθ_d)`（域混合似然）；
`Δa_gap = a_raw − a_adapt`。
四分类：
- **H_gap**：`a_raw↑` 且 `a_adapt` 正常，`θ̂` 在支撑集内 ⇒ 域差解释；
- **H_fault**：`a_adapt↑` 且 `Δa_gap` 小 ⇒ 真实故障；
- **H_novel**：所有 `θ ∈ supp(p_0)` 下似然都低，或 `G_0 > τ_g` ⇒ 新物理/域外；
- **H_poison**：校准样本本身与所有 θ 不相容，或单样本影响超阈。
只有 H_fault 进入 R68 故障通道；H_gap 走适配通道；H_novel/H_poison 走保守/审计通道。**禁止把 H_gap 当作「已校准」的借口。**

**定义 316（少样本保形模态校准 FSC）** 非一致性分数 `s(o,m) = 1 − ŵ_m(o)`（或模态排名）。校准集 `D_cal = {(o_i, m_i*)}`，`|D_cal|=k`，来自**已核实**的真实 episode。阈值 `q̂ = ⌈(k+1)(1−α)⌉/k` 分位数；预测集 `C_α(o) = {m : s(o,m) ≤ q̂}`。可交换性下 `P(M* ∈ C_α) ≥ 1−α`。**few-shot 硬下界**：`α_min = 1/(k+1)`；若任务要求 `α < α_min`，FSC 不可用，只能退回 R69 保守或继续采集校准样本。分布漂移下用 ACI 更新 `α_t` 维持长期平均覆盖；单步无保证，由 NTG 监控。

**定义 317（域可信集与逐域鲁棒包络 RSE）** `C_ε(q_k) = {θ : q_k(θ) ≥ ε·max_θ q_k}`（HPD 近似）或保形域集。动作前缀 A 通过认证 iff `∀θ∈C_ε`：`C-RAS-WM_θ(A)` 安全且 `λ_floor(U_ale(θ)+U_trans(θ))` 满足。等价地，安全包络是各域包络的交集。若交集为空 ⇒ 不存在同时安全的动作，触发最小风险控制器/人工接管。

**定义 318（主动迁移探针 APT）** 候选真实探针 `g_d ∈ 𝒜_probe`（轻触、滑动、抬升、短脉冲、低幅扫掠）。`EIG(g_d) = H[q_k] − E_{y~p(·|g_d)} H[q_{k+1}(·|y)]`。选择 `g_d* = argmax [EIG − c(g_d)]`，s.t. 物理/社交成本、RSE 认证、且不破坏任务。与 R69 的 MINT 任务探针 `g_t` 共享预算（定义 319）。

**定义 319（联合信息预算 JIB）** 总预算 B（每单位时间信息动作 ≤1 次，位移/力/社交成本 ≤ 预算）。联合候选 `{(g_t, g_d)}`，目标 `max VoI_task(g_t) + EIG_trans(g_d) − c(g_t,g_d)`，s.t. 预算与 RSE。**源匹配优先级**：若 `U_trans` 高而 `U_epi^task` 低，先做域探针；因为域后验不收窄时，任务探针的似然本身不可信（定义的熵分解里 `H(M|o,θ)` 的 θ 还是错的）。

**定义 320（校准数据卫生）** 四规则：
(i) **分层**：校准样本覆盖域随机化主轴（每个 d_d 方向至少 k_s 条，或按 D-最优设计选点）；
(ii) **隔离**：校准集与验证/定案集不重叠（no double-dipping）；
(iii) **预注册**：采集协议在部署前锁定，事后不得按结果挑样本；
(iv) **影响力上限**：leave-one-shot-out 对后验/决策的影响 ≤ ι_max；超过则要求 `k_agree ≥ 2` 条独立样本同向，否则回退。

**定义 321（负迁移检测 NTG）** 三个统计量：**支撑集检验**（真实数据在 p_0 支撑外的概率）、**覆盖审计**（经验覆盖 vs 目标 1−α 的偏差）、**决策翻转率**（单样本引起的最优动作变化）。任一越界 ⇒ 冻结适配、扩大 C_ε、回退 R68。

**定义 322（校准投毒与新物理威胁模型 ℰ_bridge）** `ℰ_bridge = ℰ_FLUID × ℰ_poison-cal × ℰ_prior-miss × ℰ_gap-disguise`。其中 ℰ_poison-cal：对手控制校准样本（只给简单工况/注入错误标签）；ℰ_prior-miss：真实 `θ* ∉ supp(p_0)`（域随机化没覆盖）；ℰ_gap-disguise：把真实故障伪装成域差，使系统持续适配而不报警。

**定义 323（迁移审计 VQA-B）** 审计：校准样本来源与代表性、SBI 后验是否被单样本主导、FSC 覆盖是否达标、H_gap/H_fault 归因是否可复核、RSE 是否真的逐域认证。结论回灌 AuditBuf，成为下一轮 APT 的采样先验与 JIB 成本先验。

**定义 324（证书 J_BRIDGE）** `J_BRIDGE = (J_FLUID, k_shots, d_d, α_min, domain_cover, fsc_cover_emp, aci_gap, gap_fault_auc, neg_transfer_flags, rse_margin, bridge_ver)`。Valid ⇔ `Valid(J_FLUID)` ∧ `k_shots ≥ k_min(α)` ∧ 覆盖审计通过 ∧ 无 NTG 越界 ∧ RSE 非空。

**定义 325（退化阶梯）** 优先级从高到低：BRIDGE 适配 → R69 FLUID（域已知/不可适配）→ R68 CALM（连交互也不可信）→ 最小风险控制器/人工。每降一级，λ 单调不降；任何一级失败都不得跳到更激进的一级。

**定义 326（非可交换监控）** 维护漂移统计 `D_t`（域后验预测误差、协变量漂移、覆盖残差）。低于阈值：FSC 可交换；超过：启用 ACI + 缩短校准窗口 + 提高 λ_floor；超过硬阈：判定部署已离开校准分布，禁用适配（定义 325 降级）。

**定义 327（冻结适配器银行与离线元训练）** 离线训练 M 个适配器 `{h_j}`（对应域簇/物理模式）与摊销后验 q_φ；在线不训练，只按 q_k 的权重做**前向加权/选择**。新适配器只有在通过 RSE 认证 + 影子模式无违规后才允许换装（继承 R68 换装不变式）。这把 few-shot 学习关在安全环路之外。

## 2. 关键算法骨架

```python
# IP-265/273：摊销域后验 + 冻结适配器银行（部署只前向，零学习写）
class AmortizedDomainPosterior:
    def __init__(self, q_flow, p0, adapter_bank, d_d):
        self.q_flow, self.p0 = q_flow, p0          # 离线训练好的神经后验
        self.adapters, self.d_d = adapter_bank, d_d

    def infer(self, shots):                        # shots: k 条真实 episode
        q = self.q_flow.condition(summarize(shots)).sample_posterior()
        beta = max(0.0, 1.0 - len(shots) / self.d_d)
        return (1 - beta) * q + beta * self.p0     # 少样本温度回退

# IP-268：少样本保形模态集（含 few-shot 硬下界）
class FewShotConformal:
    def fit(self, cal_scores, alpha):
        k = len(cal_scores)
        if alpha < 1.0 / (k + 1):                  # α_min 不可达
            self.mode = 'infeasible'
            return
        self.qhat = quantile(cal_scores, ceil((k + 1) * (1 - alpha)) / k)

    def set(self, o, mode_scores):
        return [m for m in modes if mode_scores[o, m] <= self.qhat]

# IP-267/266：gap 归一化似然 + 三分不确定性 + 四分类
def attribute_and_decompose(policy, xi, o, o_cal, qk, p0, shots):
    a_raw = -policy.log_likelihood(xi, o)                    # R69 通道
    a_adapt = -log(mean([exp(-policy.log_likelihood(xi, o, theta))
                         for theta in sample(qk, 4)]))       # 域混合
    gap = a_raw - a_adapt
    U_ale, U_task, U_trans = decompose_three_way(policy, o, qk)
    gap_floor = support_test(shots, p0)                      # 域外/新物理
    if gap_floor > TAU_G:          return NOVEL,  ...
    if influence(qk, shots) > IOTA:return POISON, ...
    if a_adapt > TAU_FAULT:        return FAULT, ...
    if gap > TAU_GAP:              return GAP,   ...
    return NORMAL, (U_ale, U_task, U_trans)

# IP-270/271：源匹配的联合信息分配
def allocate_info(U_task, U_trans, modes, qk, budget):
    cand_t = mint_candidates(modes) if U_task > TAU_TASK else []
    cand_d = apt_candidates(qk)   if U_trans > TAU_TRANS else []
    # 联合枚举（候选 ≤5），域探针优先；不可行则只做任务探针/不交互
    best = max(((g_t, g_d) for g_t in cand_t + [None]
                           for g_d in cand_d + [None]
                if budget.allow(g_t, g_d)
                and rse.certify(g_t, g_d, qk)),
               key=lambda g: voi_task(g[0]) + eig_trans(g[1]) - cost(g))
    return best

# IP-277：BRIDGE 主闭环（继承 R69，仅在迁移/归因/校准处插入新层）
def BRIDGE_round(M, obs, shots):
    z0, o = M.mtm.forward(obs)                     # R68/R69 一次前向
    qk = M.asi.infer(shots)                        # 少样本域后验（缓存）
    attr, (U_ale, U_task, U_trans) = attribute_and_decompose(
        M.fmp, M.last_action, o, M.o_cal, qk, M.p0, shots)
    if attr in (NOVEL, POISON):                    # 不可适配：直接保守
        return M.fallback_r68(obs, reason=attr)
    g_t, g_d = M.jib.allocate(U_task, U_trans, M.modes, qk, M.budget)
    if g_d is not None:
        shots = shots + [M.apt.execute(g_d, qk)]   # 真实世界探针
        qk = M.asi.infer(shots)                    # 后验前向更新
    if g_t is not None:
        U_task = M.mint.execute(g_t, M.modes)      # R69 人/场景交互
    # 逐域鲁棒认证：在可信集上取最坏情况
    C_eps = M.rse.credible_set(qk)
    A = M.ach.propose(M.x_prime, M.vista.H)
    k = M.c_ras_wm.certified_prefix_robust(A, C_eps, M.wm_preds)
    lam = max(M.efs.risk_scale(...),
              max(M.rse.lam_floor(U_ale + (U_task if g_t is None else 0.0)
                                  + U_trans, theta) for theta in C_eps))
    # 少样本保形：不可信则退回 R69 的 MCG / R68
    C_mode = M.fsc.set(o)
    if not C_mode or M.fsc.mode == 'infeasible':
        return M.fallback_r69_or_r68(obs, reason='fsc_infeasible')
    mode = select_mode(C_mode, U_task, U_trans, lam)
    tau = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_b.submit(shots, qk, attr, C_mode, C_eps, lam)   # 异步审计
    return k, lam, mode, (U_ale, U_task, U_trans)
```

## 3. 推导

**引理 19（源匹配：问人不能消解域不确定性）** 设人类回答 `y_h` 在给定 `(M,o,g_t)` 下条件独立于域参数 `θ_d`（人只回答任务意图，不知道仿真摩擦/延迟）。则 `I(θ_d; y_h | o, e_{1:k}, g_t) = 0`，故 `H(θ_d | ·)` 与 `U_trans` 不变。系：在「人不是域专家」的模型下，任何把 transfer-epistemic 当作 task-epistemic 去问人的策略，都只能改变 `U_epi^task`，不能降低 `U_trans`；若系统随后放松 λ，它是在**没有获得相应信息**的情况下放松，安全侧不成立。反例边界：若人类被认证为域 oracle（能回答摩擦/延迟），则 `I>0`，但该通道仍须与真实探针交叉验证，不能单源定案（定义 293-iii 的证据纪律）。

**引理 20（少样本保形覆盖与 α_min 硬下界）** 在 `(o_i,m_i*)` 与部署样本可交换的假设下，split conformal 的 `C_α` 满足 `P(M*∈C_α) ≥ 1−α`，且该界对任意分数函数、任意数据分布成立（分布无关）。当 `|D_cal|=k` 时，可达的最小误覆盖率为 `α_min = 1/(k+1)`；`α < α_min` 时不存在有限阈值，只能取全集（trivial）或承认不可用。系：few-shot 不是「用一点数据也能达到任意精度」，而是「k 决定了你能承诺的覆盖等级」；`k_min(α) = ⌈1/α⌉ − 1` 是采集校准样本的硬预算。

**引理 21（gap 归一化的去偏与残余风险）** 设真实域 `θ* ∈ supp(q_k)` 且 `q_k(θ*) = ρ > 0`。由 `p_mix = ∫ p_θ q_k(dθ) ≥ ρ·p_{θ*}`，有 `a_adapt ≤ a_{θ*} + log(1/ρ)`。故当后验给真实域足够质量时，域混合似然把「系统性域差」吸收掉，`a_raw − a_adapt` 主要反映域差而非故障。残余项 `log(1/ρ)` 是 few-shot 的直接代价：`ρ` 小（样本少/先验漏掉真域）时，`a_adapt` 可能仍然偏高，系统会**把域差误报成故障**；反之若 `q_k` 给了一个错误但高权重的域，系统会**把故障解释成域差**（ℰ_gap-disguise）。因此归因必须同时报告 `ρ` 与 `G_0`，不能只看 `Δa_gap`。

**引理 22（负迁移与校准投毒上界）** 设校准分布 `P_cal` 与部署分布 `P_dep` 的 TV 距离为 `d_TV`，则保形覆盖相对目标的下探不超过 `O(d_TV)`（非可交换时无单步保证，只能由 ACI 维持长期平均）。若校准集中有比例 `δ_p` 的投毒样本、单样本对后验的影响被定义 321 限制为 `ι_max`，则单源采纳的决策翻转概率 ≤ `δ_p + k·ι_max`；采用 `k_agree ≥ 2` 条独立同向样本时降为 `δ_p^2 + ε_σ`。系：few-shot 的校准样本越少，`δ_p` 的一票权重越大；因此「少样本 + 无隔离验证」比「多样本 + 隔离验证」更危险。

**定理 18（BRIDGE 严格包含 FLUID-RAS）** 在 A95–A99 下：
(i) 当 `q_k = δ_{θ0}`、`C_ε = {θ0}`、`α ≥ α_min` 且校准/部署可交换时，BRIDGE 与 FLUID-RAS 逐指令相同；
(ii) 当 `k=0` 时，`U_trans` 整体并入 `U_floor`，BRIDGE 退化为 R68 的保守策略；
(iii) 一般情形下，BRIDGE 的期望风险 ≤ R69 在「域已知」假设下会犯的风险，且安全包络是 R69 包络在 `C_ε` 上的交集 ⇒ 安全侧不弱于 R69。
因此 R69 是 BRIDGE 在「域已知、样本充足」边界上的严格退化；R70 的新层只在「域未知、样本极少」时介入。

**定理 19（少样本适配的安全性与无突变）** 适配只发生在冻结后验/适配器银行与保形表上（定义 327），实时环路无梯度写；RSE 在 `C_ε` 上取最坏情况，且 `C_ε` 随证据增加单调收缩（HPD 的嵌套性近似）⇒ λ 随证据增加单调不增、随证据丢失单调不减；任何 H_novel/H_poison/覆盖失败都触发定义 325 的降级阶梯，λ 单调不降。换装不变式（R68 定理 15）在影子认证后保持 ⇒ 控制连续、无突变。

**定理 20（联合信息预算的源匹配最优性）** 若 `VoI_task(g_t)` 与 `EIG_trans(g_d)` 各自关于候选集是单调子模的，且预算为基数约束，则 JIB 的贪心分配达到 `(1−1/e)` 近似；在候选 ≤5 的实时路径上直接枚举即得精确最优。系：当 `U_trans` 高而 `U_epi^task` 低时，最优解优先分配域探针；这与引理 19 的源匹配一致——**预算应该流向能真正降低对应不确定性的源**。

## 6. 本轮最大风险

**一句话**：BRIDGE-RAS 的全部收益押在「那 k 条真实样本能代表部署分布、且元先验覆盖真实物理」这一前提上——**若校准样本被挑选/投毒，或真实域落在域随机化支撑集之外，少样本后验会给出一个自信但错误的 θ_d，保形覆盖在非可交换下失效，而 gap 归一化又会把真实故障解释成「域差」；于是系统不是「诚实的不知道」，而是「用几帧数据学会了错误的物理，并给它盖了章」——学错，比不学更危险。**

**次级风险与缓解**：
1. **few-shot 硬下界被忽视**（k < k_min(α) 却承诺高覆盖）→ 定义 316 的 α_min 显式拒绝 + 退化阶梯；
2. **校准投毒/挑选**（ℰ_poison-cal）→ 定义 320 的数据卫生 + 定义 321 的影响力上限 + k_agree 纪律；
3. **先验漏掉真域**（ℰ_prior-miss）→ 支撑集检验 + H_novel + 不自动适配、升级人工；
4. **gap 成为新的「标定吸收」**（ℰ_gap-disguise）→ 归因必须同时报告 `Δa_gap`、`ρ`、`G_0`，并由 VQA-B 复核；
5. **逐域鲁棒过保守导致不可行** → RSE 交集为空时走最小风险控制器，而不是偷偷放宽；
6. **实时预算被多域回放击穿** → 域后验/可信集/包络全部低频缓存，APT/校准在轮间完成。

## 2. 形式化定义（要点版）

**定义 310–312（总览/部署/域后验）** 四不变式：实时零学习写；适配隔离；逐域鲁棒认证；校准证据纪律（no double-dipping、单样本不得由保守切激进）。真实部署给 k 条 episode，`q_k ← (1−β)q_k+βp_0`，`β=max(0,1−k/d_d)`；样本不足时宁可宽不可假窄。

**定义 313–314（域条件策略与三分不确定性）** `z=Φ(o,θ_d)`，`p(M|o,e)=∫p(M|o,θ)q_k(dθ)`。`U_ale→λ_floor`；`U_epi^task→MINT`（人/场景）；`U_trans=I(M;θ_d|o,e)+λ_gG_0→APT`（真实世界）；`G_0`（新物理）→ 不学习、R68 保守 + 人工。

**定义 315（GNF 四分类）** `a_raw`、`a_adapt`、`Δa_gap`。H_gap：原始高、适配正常、θ̂ 在支撑内；H_fault：适配高、Δa_gap 小；H_novel：所有 θ∈supp(p_0) 都低或 G_0>τ_g；H_poison：校准样本与所有 θ 不相容/单样本影响超阈。只有 H_fault 进 R68 故障通道；禁止把 H_gap 当「已校准」。

**定义 316（FSC）** `s(o,m)=1−ŵ_m(o)`；`q̂` 取 `⌈(k+1)(1−α)⌉/k` 分位；`C_α={m:s≤q̂}`；可交换下覆盖 ≥1−α；`α_min=1/(k+1)`，不可达则拒绝承诺；漂移下 ACI 维持长期覆盖，单步无保证。

**定义 317–319（RSE/APT/JIB）** 动作前缀 A 对 `∀θ∈C_ε` 都安全才认证，包络取交集；空交集 → 最小风险控制器/人工。`g_d*=argmax[EIG−c]`；联合目标 `max VoI_task+EIG_trans−c`，源匹配优先域探针（域后验不收窄时任务探针似然不可信）。

**定义 320–322（数据卫生/NTG/威胁）** 分层采样、校准/验证隔离、预注册、单样本影响 ≤ι_max 否则 k_agree≥2。NTG 用支撑集检验、覆盖审计、决策翻转率；越界冻结适配并降级。`ℰ_bridge=ℰ_FLUID×ℰ_poison-cal×ℰ_prior-miss×ℰ_gap-disguise`。

**定义 323–327（审计/证书/退化/监控/适配器银行）** VQA-B 审校准代表性、单样本主导、FSC 覆盖、gap/fault 归因、RSE 真实性；J_BRIDGE 并入上述字段；退化阶梯 BRIDGE→R69→R68→最小风险，λ 单调不降；非可交换监控触发 ACI/加严/禁用适配；冻结适配器银行把 few-shot 学习关在安全环路之外。

## 3. 关键算法伪代码

```python
# IP-265/273：摊销域后验 + 冻结适配器（部署只前向）
class AmortizedDomainPosterior:
    def infer(self, shots):
        q = self.q_flow.condition(summarize(shots)).sample_posterior()
        beta = max(0.0, 1.0 - len(shots) / self.d_d)
        return (1 - beta) * q + beta * self.p0        # k<d_d 退回先验

# IP-268：少样本保形（含 α_min 硬下界）
class FewShotConformal:
    def fit(self, cal_scores, alpha):
        k = len(cal_scores)
        if alpha < 1.0 / (k + 1):
            self.mode = 'infeasible'; return
        self.qhat = quantile(cal_scores, ceil((k+1)*(1-alpha))/k)
    def set(self, o, scores):
        return [m for m in modes if scores[o, m] <= self.qhat]

# IP-266/267：三分不确定性 + gap 归因
def attribute(policy, xi, o, qk, p0, shots):
    a_raw   = -policy.log_likelihood(xi, o)
    a_adapt = -log(mean([exp(-policy.log_likelihood(xi, o, th))
                         for th in sample(qk, 4)]))
    U_ale, U_task, U_trans = decompose_three_way(policy, o, qk)
    G0 = support_test(shots, p0)
    if G0 > TAU_G:                 return NOVEL, ...
    if influence(qk, shots) > IOTA:return POISON, ...
    if a_adapt > TAU_FAULT:        return FAULT, ...
    if a_raw - a_adapt > TAU_GAP:  return GAP, ...
    return NORMAL, (U_ale, U_task, U_trans)

# IP-270/271：源匹配联合信息分配（候选≤5 枚举）
def allocate(U_task, U_trans, qk, budget):
    ct = mint_candidates() if U_task > TAU_TASK else [None]
    cd = apt_candidates(qk) if U_trans > TAU_TRANS else [None]
    return max(((t, d) for t in ct for d in cd
                if budget.allow(t, d) and rse.certify(t, d, qk)),
               key=lambda g: voi_task(g[0]) + eig_trans(g[1]) - cost(g))

# IP-277：BRIDGE 主闭环（继承 R69）
def BRIDGE_round(M, obs, shots):
    z0, o = M.mtm.forward(obs)
    qk = M.asi.infer(shots)                          # 轮间缓存
    attr, (U_ale, U_task, U_trans) = attribute(
        M.fmp, M.last_action, o, qk, M.p0, shots)
    if attr in (NOVEL, POISON):
        return M.fallback_r68(obs, reason=attr)
    g_t, g_d = M.jib.allocate(U_task, U_trans, qk, M.budget)
    if g_d: shots += [M.apt.execute(g_d, qk)]; qk = M.asi.infer(shots)
    if g_t: U_task = M.mint.execute(g_t, M.modes)
    C_eps = M.rse.credible_set(qk)                   # 逐域可信集
    A = M.ach.propose(M.x_prime, M.vista.H)
    k = M.c_ras_wm.certified_prefix_robust(A, C_eps, M.wm_preds)
    lam = max(M.efs.risk_scale(...),
              max(M.rse.lam_floor(U_ale + (U_task if g_t is None else 0.0)
                                  + U_trans, th) for th in C_eps))
    C_mode = M.fsc.set(o)
    if not C_mode or M.fsc.mode == 'infeasible':
        return M.fallback_r69_or_r68(obs, reason='fsc_infeasible')
    mode = select_mode(C_mode, U_task, U_trans, lam)
    tau = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_b.submit(shots, qk, attr, C_mode, C_eps, lam)
    return k, lam, mode, (U_ale, U_task, U_trans)
```

## 4. 推导

**引理 19（源匹配）** 若人类回答 `y_h` 在给定 `(M,o,g_t)` 下条件独立于 `θ_d`，则 `I(θ_d; y_h|o,e,g_t)=0`，问人不能降低 `U_trans`；把 transfer-epistemic 当 task-epistemic 去问人，只改 `U_epi^task`，若随后放松 λ 则安全侧不成立。人类被认证为域 oracle 时 `I>0`，但仍须与真实探针交叉验证、不得单源定案。

**引理 20（少样本保形覆盖与 α_min）** 可交换性下 `P(M*∈C_α)≥1−α`，分布无关；`|D_cal|=k` 时可达最小误覆盖率 `α_min=1/(k+1)`，`α<α_min` 无有限阈值。系：`k_min(α)=⌈1/α⌉−1` 是采集校准样本的硬预算；few-shot 决定的是可承诺的覆盖等级，不是任意精度。

**引理 21（gap 归一化的去偏与残余风险）** 若 `θ*∈supp(q_k)` 且 `q_k(θ*)=ρ>0`，则 `p_mix≥ρp_{θ*}`，故 `a_adapt≤a_{θ*}+log(1/ρ)`：域混合似然吸收系统性域差，`Δa_gap` 主要反映域差而非故障。残余 `log(1/ρ)` 是 few-shot 代价：ρ 小则域差误报为故障；q_k 高权重给错域则故障被解释成域差（ℰ_gap-disguise）。归因必须同时报告 `Δa_gap`、`ρ`、`G_0`。

**引理 22（负迁移/投毒上界）** `P_cal` 与 `P_dep` 的 TV 距离为 `d_TV` 时，保形覆盖下探为 `O(d_TV)`；非可交换时无单步保证，只能 ACI 维持长期平均。投毒比例 `δ_p`、单样本影响 ≤`ι_max` 时单源决策翻转 ≤`δ_p+k·ι_max`；`k_agree≥2` 独立同向时降为 `δ_p^2+ε_σ`。

**定理 18（严格包含 FLUID-RAS）** 当 `q_k=δ_{θ0}`、`C_ε={θ0}`、`α≥α_min` 且校准/部署可交换时，BRIDGE 与 FLUID-RAS 逐指令相同；`k=0` 时 `U_trans` 并入 `U_floor`，退化为 R68。一般情形 BRIDGE 的风险 ≤ R69「域已知」假设下会犯的风险，安全包络是 R69 包络在 `C_ε` 上的交集 ⇒ 安全侧不弱于 R69。

**定理 19（少样本适配安全/无突变）** 适配只在冻结后验/适配器银行/保形表上发生（实时无梯度写）；RSE 在 `C_ε` 上取最坏情况，`C_ε` 随证据增加单调收缩 ⇒ λ 随证据增加单调不增、随证据丢失单调不减；H_novel/H_poison/覆盖失败触发定义 325 降级，λ 单调不降；影子认证后换装不变式保持 ⇒ 控制连续、无突变。

**定理 20（联合预算源匹配最优性）** 若 `VoI_task` 与 `EIG_trans` 各自关于候选集单调子模且预算为基数约束，JIB 贪心达 `(1−1/e)` 近似；候选≤5 时直接枚举即精确最优。系：`U_trans` 高而 `U_epi^task` 低时，最优解优先域探针——预算流向能真正降低对应不确定性的源。

## 7. 本轮最大风险

**一句话**：BRIDGE-RAS 的全部收益押在「那 k 条真实样本能代表部署分布、且元先验覆盖真实物理」这一前提上——**若校准样本被挑选/投毒，或真实域落在域随机化支撑集之外，少样本后验会给出一个自信但错误的 θ_d，保形覆盖在非可交换下失效，而 gap 归一化又会把真实故障解释成「域差」；于是系统不是「诚实的不知道」，而是「用几帧数据学会了错误的物理，并给它盖了章」——学错，比不学更危险。**

**次级风险与缓解**：few-shot 硬下界被忽视（α_min 显式拒绝 + 退化阶梯）；校准投毒/挑选（数据卫生 + 影响力上限 + k_agree）；先验漏掉真域（支撑集检验 + H_novel + 人工升级）；gap 成为新的「标定吸收」（同时报告 Δa_gap/ρ/G_0 + VQA-B 复核）；逐域鲁棒过保守不可行（空交集走最小风险控制器，不偷偷放宽）；实时预算被多域回放击穿（低频缓存，APT/校准轮间完成）。
