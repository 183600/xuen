## 0. 直觉与动机

**灵感 1（移动操作 → 自运动既是证书的敌人，也是证书的朋友）**
直觉：v22 把底座（PGEV 能量）和机械臂（ACSC 配空间）当成两本独立证书。可真实移动操作里两者强耦合：臂的可达工作空间取决于底座位姿，底座的移动又改变视角、暴露原本被遮挡的角落。于是出现 v23 完全没有的失效模式——**自运动导致的证书自我失效 (self-induced certificate invalidation)**：你在位姿 p 签发了"目标区无人"的缺席证书，底座向目标移动，到了 p′ 才发现原先被货架挡住的角落里站着人，证书在运输途中悄悄过期。
反直觉的妙处：**自运动不是任意分布漂移，而是一个已知、受控的 SE(3) 群作用**。已知意味着可补偿：(a) 在规范帧里标定的 conformal 证书可以沿已知自运动"运输"到新位姿，附带可计算的运输松弛 ε_trans；(b) 机器人可以**零标签**地制造成对校准样本——移到 p 观察、再移回 p 观察同一静止场景，残差直接给出运输误差的经验界。**已知自运动 = 免费的少样本校准器**。核心创新：**全身配置证书 (Whole-Body Configuration Certificate, WBCC)** + **自运动证书运输 (Ego-Motion Certificate Transport, EMCT)**。

**灵感 2（小样本学习 → 技能可以学，安全不能学）**
直觉：v23 的 FSVC 只把少样本用于"感知校准"（原型 + 分位数）。移动操作真正的少样本需求是**新任务/新物体/新环境**：看 1–5 次人类演示，就要会"把杯子放进洗碗机"。但把 K=1 学到的策略直接放上安全关键机器人是危险的。
关键设计是彻底**解耦学习与安全**：少样本学习只决定"提议什么动作"（proposal），证书决定"允许执行什么动作"（certified set），中间夹一层**证书护盾 (Certificate Shield)**——每步把学习策略的提议投影回认证动作集 A_cert(q)；越界则退回认证兜底动作（后退/重定位/停）。于是**安全是与 K 无关的护盾保证，性能是与 K 相关的 conformal 风险控制**：K=0 时机器人照样安全，只是笨；K 越大越能干。这直接回答"少样本能不能上安全关键机器人"：能，只要它永远不拥有越过证书的权力。核心创新：**少样本操作技能证书 (Few-Shot Manipulation Skill Certificate, FSMSC)**。

**灵感 3（两者如何焊接：证书不变的移动操作）**
直觉：移动操作 = "先移动到能操作的位置，再操作"。但移动会失效证书。所以真正的规划问题不是"找一条到目标的路径"，而是"找一条**证书在沿途始终有效**的路径"——**证书不变路径 (certificate-invariant path)**。自运动运输给每段路径一个可累积的松弛预算；预算耗尽（视角变化过大或场景疑似非刚体变化）就执行 **stop-and-look**：停下、重观察、刷新证书、重置松弛。这把"连续移动（快但证书旧）"与"走走停停（慢但证书新）"变成一个可优化的谱系，而不是二选一。

**三者如何统一**
统一为 v23 之上的**移动操作层**：WBCC 回答"全身这个姿态安全吗"，MMRC 回答"底座停哪里才能安全够到目标"，EMCT 回答"移动途中证书还信不信"，FSMSC 回答"新技能提议的动作能否被认证放行"。统一准入门 **HPC-M = HPC-E+ ∧ WBCC ∧ EMCT-valid ∧ MMRC-reachable ∧ FSMSC-shield**，且 `Exec_v24 ⊆ Exec_v23 ⊆ …`。共享状态扩展为 ζ_mm = ζ_ce ∪ (q, R(τ), ε_trans, skill_lib, shield_state)。

## 2. 设计原则（在 P37–P42 基础上新增 P43–P46）

**P43 自运动可运输律（Certificate Transport under Known Ego-Motion）**
对任意已知自运动 g = p′∘p⁻¹，存在规范映射 T_p 与表示 ρ，使 T_{p′}(O_{p′}) ≈ ρ(g)·T_p(O_p)。定义位姿相关运输松弛 `ε_trans(p,p′; α) = Quantile_{1-α}{‖T_{p′}(O_{p′}) − ρ(g)T_p(O_p)‖}`（由零标签运动对经验估计）。证书运输只做保守操作：障碍框膨胀 ε_trans，自由/缺席区域收缩 ε_trans。运输松弛沿路径按"视角变化度量"可组合，超过预算即触发 stop-and-look 重置。**故运输永远只会让执行集变小**。

**P44 全身可达-安全耦合律（Whole-Body Reach-Safe Coupling）**
全身配置 `q=(p,q_arm)`，扫掠体 `V(q)=V_base(p)∪V_arm(q)`。全身安全：`V(q)∩Obs_t=∅`（含膨胀）。可达-安全集 `R(τ)={p : ∃q_arm, τ∈EE(p,q_arm) ∧ V(p,q_arm)∩Obs_t=∅ ∧ E_arm(q)≤E_budget}`。移动操作可行 ⟺ 存在一条从当前位姿到某个 p∈R(τ) 的**证书不变路径**。底座移动引起的 Obs_t 变化必须由 P43 的运输松弛覆盖，否则不允许该段移动。

**P45 护盾化少样本律（Certified Proposal, Shielded Execution）**
少样本策略 π_θ(D_K) 只产生提议 a_prop；执行动作为 `a_exec = Shield(a_prop; q, HPC-M) = a_prop if a_prop∈A_cert(q) else Fallback(q)`，其中 `A_cert(q)={a : next(q,a) 满足 HPC-M}`，且急停 `a_stop∈A_cert(q)` 恒成立。故 `∀K≥0: Exec(Shield(π_θ)) ⊆ Exec_v23`，安全与 K 无关；任务成功下界 `P(success) ≥ 1-κ_task(K)` 由 conformal 风险控制给出，随 K 单调收紧。

**P46 证书不变路径律（Certificate-Invariant Path）**
路径 π = (q_0,…,q_n) 证书不变 ⟺ 对每个相邻段 (q_i,q_{i+1})，`cert(q_i)` 经 P43 运输后在新位姿仍覆盖执行所需区域，且累计运输松弛 ≤ 预算。松弛耗尽或无可行段时，插入 stop-and-look 节点刷新证书并重置松弛。返回的路径若存在，则沿途每点证书有效；若不存在，退回 v23 的静态停靠（更保守）。

## 3. 与基线的接口（如何退化）

- EMCT 失效（无法估计运输松弛 / 非刚体检测触发）⇒ 禁止连续移动，仅允许 stop-and-look 的"一步一证"⇒ 比 v23 更保守；
- WBCC 失效（全身模型不可信）⇒ 底座与臂退回各自独立证书（v22 行为）⇒ 等价 v22 的保守交集；
- MMRC 无解（无可达-安全位姿）⇒ 不执行操作，保持当前位置 ⇒ 子集；
- FSMSC 护盾失效（A_cert 计算异常）⇒ 直接执行急停兜底 ⇒ 子集；
- 少样本 K=0 / 任务风险界过松 ⇒ 护盾仍在，只是全部走兜底（低活性但不失安全）⇒ 子集；
- 全失效 ⇒ 完全回退 v23 ⇒ `Exec_v24 ⊆ Exec_v23 ⊆ … ⊆ Exec_v18`。
- **安全继承**：EMCT 只膨胀障碍/收缩自由、WBCC 只增全身障碍、MMRC 只在 R(τ) 内选点、FSMSC 只把提议投影回 A_cert；任意失效都向更保守方向退化。

## 4. 预期贡献

1. **自运动证书运输**：首次把移动机器人的已知自运动当作 SE(3) 群作用，把 conformal 覆盖沿运动运输并给出可计算运输松弛；零标签运动对作为免费校准源，直接缓解 v23 的少样本覆盖不足与断联共振。
2. **全身耦合证书**：把底座与机械臂从两本独立证书升级为全身扫掠体 + 可达-安全集 R(τ)，显式建模"移动到能操作的位置"这一移动操作核心耦合。
3. **证书不变路径**：把"快但证书旧 / 慢但证书新"形式化为可累积运输松弛 + stop-and-look 重置的可优化谱系，给出路径级安全保证。
4. **护盾化少样本**：安全 K 无关（护盾保证）、性能 K 相关（conformal 风险控制），给出"少样本可上安全关键机器人"的充分条件与显式任务失败上界。
5. **封堵 v23 最大风险**：自运动运动对在云端断联时仍可本地生成，覆盖监控不再完全依赖云边同步，降低"分布剧变 × 断联"共振面。

## 5. 本轮最大风险

**一句话**：EMCT 的运输松弛建立在"场景刚性 + 自运动已知"的等变性假设上，一旦场景中存在**非刚体运动**（行人走动、可变形物体、光照剧变），机器人无法把"自己动了"与"世界动了"分开，运输松弛会系统性低估证书退化，导致**"运输诱导的缺席幻觉"——机器人带着一张在旧位姿有效、在新位姿已悄悄失效的缺席证书，自信地驶向目标**。

```python
# ============================================================
# IP-441 Ego-Motion Certificate Transport (EMCT)
# ============================================================
@dataclass
class MotionPair:
    g: np.ndarray           # 已知自运动 p' ∘ p^{-1}
    p_from: 'Pose'
    p_to: 'Pose'
    residual: float         # ‖T_{p'}(O_{p'}) − ρ(g) T_p(O_p)‖

class EgoMotionCertificateTransport:
    def __init__(self, canonicalizer, rho, alpha=0.01, delta=0.001, max_pairs=4000):
        self.T = canonicalizer
        self.rho = rho
        self.alpha, self.delta = alpha, delta
        self.pairs = deque(maxlen=max_pairs)
        self.buckets = defaultdict(list)   # view_key -> [residual,...]

    def register_static_pair(self, O_from, O_to, p_from, p_to, g, rigid_gate) -> bool:
        """仅登记被刚性门控判定为静止场景的运动对；零标签。"""
        if not rigid_gate.accept(O_from, O_to, g):
            return False
        resid = float(np.linalg.norm(self.T(O_to) - self.rho(g) @ self.T(O_from)))
        self.pairs.append(MotionPair(g, p_from, p_to, resid))
        self.buckets[self._view_key(p_from, p_to)].append(resid)
        return True

    def transport_slack(self, p_from, p_to) -> float:
        """运输松弛 = 近邻残差的 (1-α) conformal 分位 + Hoeffding 有限样本修正。"""
        samples = self._neighbor_residuals(self._view_key(p_from, p_to))
        n = len(samples)
        if n < 30:
            return float('inf')            # 样本不足 → 禁止运输，退 stop-and-look
        q = conformal_quantile(samples, 1 - self.alpha)
        return q + math.sqrt(math.log(1 / self.delta) / (2 * n))

    def transport_certificate(self, cert, p_from, p_to):
        """保守运输：障碍膨胀 slack，自由/缺席区域收缩 slack；失败返回 None。"""
        slack = self.transport_slack(p_from, p_to)
        if math.isinf(slack):
            return None
        return cert.conservative_inflate(slack)   # 只增障碍、只缩自由


# ============================================================
# IP-440 Whole-Body Configuration Certificate (WBCC)
# ============================================================
class WholeBodyConfigurationCertificate:
    def __init__(self, base_kin, arm_kin, inflation=0.05):
        self.base, self.arm = base_kin, arm_kin
        self.infl = inflation

    def swept_volume(self, q):
        return (self.base.swept(q.p, self.infl)
                | self.arm.swept(q.p, q.q_arm, self.infl))

    def admits(self, q, obs_t) -> bool:
        return not self.swept_volume(q).intersects(obs_t)

    def reachable_safe_set(self, tau, obs_t, E_budget):
        """R(τ)：能安全够到目标 τ 且能量可行的底座位姿。"""
        R = []
        for p in self.base.candidate_poses(tau):
            for q_arm in self.arm.ik(tau, p):
                q = WholeBody(p, q_arm)
                if self.admits(q, obs_t) and self.arm.energy(q) <= E_budget:
                    R.append((p, q_arm))
        return pareto_filter(R)   # 按能量/裕度非支配筛选，抑制组合爆炸


# ============================================================
# IP-442 Certificate-Invariant Planner (CIP)
# ============================================================
class CertificateInvariantPlanner:
    def __init__(self, wbcc, emct, slack_budget):
        self.wbcc, self.emct, self.budget = wbcc, emct, slack_budget

    def plan(self, q0, tau, obs_t, E_budget):
        R = self.wbcc.reachable_safe_set(tau, obs_t, E_budget)
        if not R:
            return None
        for target in R:
            path = self.base.plan(q0.p, target[0])
            if path is None:
                continue
            if self._certificate_invariant(path):
                return path, target
        return None

    def _certificate_invariant(self, path) -> bool:
        used = 0.0
        for a, b in zip(path, path[1:]):
            slack = self.emct.transport_slack(a, b)
            if math.isinf(slack):
                path.insert_after(b, StopAndLook(b))   # 刷新证书，重置累计
                used = 0.0
                continue
            used += slack
            if used > self.budget:
                path.insert_after(b, StopAndLook(b))
                used = 0.0
        return True

        self.task_fail_bound = 1.0

    def fit(self, demos_K):
        """少样本学技能：骨干可复用 v23 FSVC 的冻结特征；只学生成提议的策略。"""
        self.policy = meta_bc(demos_K)
        return self.policy

    def shield(self, q, obs_t, a_prop, hpc_m):
        """证书护盾：提议在 A_cert 内则放行，否则退回认证兜底；stop 恒可认证。"""
        if hpc_m.action_admissible(q, a_prop, obs_t):
            return a_prop
        for fallback in (hpc_m.retreat(q), hpc_m.reposition(q), hpc_m.stop(q)):
            if hpc_m.action_admissible(q, fallback, obs_t):
                return fallback
        return hpc_m.stop(q)   # 急停恒在 A_cert(q) 内

    def calibrate_task_risk(self, holdout):
        """护盾后任务失败率的 conformal 上界；安全不依赖此界。"""
        losses = [0.0 if run_episode_shielded(self.policy, e) else 1.0
                  for e in holdout]
        self.task_fail_bound = conformal_risk_upper(losses, self.alpha)
        return self.task_fail_bound


# ============================================================
# IP-444 HPC-M 统一全身准入门
# ============================================================
@dataclass
class HPCM:
    hpc_e_plus: 'HPCEPlus'
    wbcc: WholeBodyConfigurationCertificate
    emct: EgoMotionCertificateTransport
    cip: CertificateInvariantPlanner
    fsmc: FewShotManipulationSkillCertificate

    def admits_whole_body(self, q, obs_t, cert_at_q, p_ref) -> bool:
        # 1) 继承 v23 四证（几何/规范/负信息/能量/差距/云边/少样本/IP）
        if not self.hpc_e_plus.admits_pose(q, obs_t):
            return False
        # 2) 全身扫掠体无碰撞
        if not self.wbcc.admits(q, obs_t):
            return False
        # 3) 旧位姿证书必须能运输到当前位姿，否则拒证（退 stop-and-look）
        if cert_at_q.origin_pose != q.p:
            if self.emct.transport_certificate(cert_at_q, cert_at_q.origin_pose, q.p) is None:
                return False
        return True

    def action_admissible(self, q, a, obs_t) -> bool:
        return self.admits_whole_body(next_config(q, a), obs_t,
                                      current_cert(), q.p)

    def admits_plan(self, plan, q0, tau, obs_t, E_budget) -> bool:
        # 4) 可达-安全 + 证书不变路径
        if self.cip.plan(q0, tau, obs_t, E_budget) is None:
            return False
        return all(self.admits_whole_body(q, obs_t, current_cert(), q.p)
                   for q in plan.waypoints)


# ============================================================
# 端到端：移动操作单步
# ============================================================
class MobileManipulationPipeline:
    def __init__(self, cfg):
        self.hpc_m = cfg['hpc_m']
        self.fsmc = cfg['fsmc']
        self.emct = cfg['emct']
        self.wbcc = cfg['wbcc']

    def step(self, q, obs_t, O_prev, O_cur, g, a_prop):
        # 1) 零标签运动对入池（若刚性门控通过）
        self.emct.register_static_pair(O_prev, O_cur, q.p_prev, q.p, g,
                                       cfg['rigid_gate'])
        # 2) 护盾：少样本提议 → 认证动作
        a_exec = self.fsmc.shield(q, obs_t, a_prop, self.hpc_m)
        # 3) 全身准入
        admitted = self.hpc_m.action_admissible(q, a_exec, obs_t)
        return a_exec if admitted else self.hpc_m.stop(q)
```

## 3. 正确性论证

### 引理 5（自运动运输的覆盖保持）
**陈述**：若刚性门控通过且经验残差以 ≥1-δ 概率不超过 ε_trans，则把 p 处覆盖 ≥1-α 的证书运输到 p′ 后，新证书覆盖 ≥1-α-δ。
**证明**：
1. 由 P43，规范帧下 T_{p′}(O_{p′}) 与 ρ(g)T_p(O_p) 的偏差以 ≥1-δ 概率 ≤ ε_trans（conformal 分位 + Hoeffding 修正）。
2. 证书 conservative_inflate(ε_trans) 只膨胀障碍/收缩自由，故原覆盖在偏差预算内仍成立。
3. 运输不新增自由空间，覆盖损失至多 δ；故新覆盖 ≥1-α-δ。∎

### 引理 6（护盾安全性 K 无关）
**陈述**：∀K≥0、∀π_θ(D_K)，`Exec(Shield(π_θ)) ⊆ Exec_v23`。
**证明**：
1. Shield 的输出要么是 a_prop（当 a_prop∈A_cert(q)），要么是 fallback，要么是 stop；三者都在 A_cert(q) 内（stop 恒可认证）。
2. A_cert(q) 由 HPC-M 定义，而 HPC-M 的第一项即 HPC-E+（v23 准入门）；故 A_cert(q) ⊆ Exec_v23 的逐步动作集。
3. 执行轨迹逐点落在 A_cert 内 ⇒ 轨迹 ∈ Exec_v23。K 只影响 a_prop 的分布，不影响 A_cert。∎

### 引理 7（证书不变路径的沿途有效性）
**陈述**：若 CIP 返回路径 π，则 π 上每个航点证书有效；否则退回静态停靠。
**证明**：
1. 对相邻段 (a,b)，EMCT 给出运输松弛；累计未超预算时，由引理 5，cert(a) 运输到 b 仍有效。
2. 累计超预算或松弛不可得时插入 StopAndLook(b)，在 b 重新观测刷新证书并重置累计，由归纳法每点有效。
3. 若无可行段则返回 None，退回 v23 静态停靠（更保守）。∎

### 引理 8（移动操作单调退化链）
**陈述**：任意单点/组合失效下，`Exec_v24 ⊆ Exec_v23 ⊆ Exec_v22 ⊆ Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18` 恒成立。
**证明**：
- EMCT 失效 ⇒ 禁连续移动，仅 stop-and-look ⇒ 更保守子集。
- WBCC 失效 ⇒ 底座/臂退回 v22 独立证书交集 ⇒ ⊆ Exec_v22 ⊆ Exec_v23。
- MMRC 无解 ⇒ 不操作 ⇒ 空集（子集）。
- FSMSC 失效 ⇒ 急停兜底 ⇒ 子集；K=0 ⇒ 全兜底，安全不变。
- 组合失效取交，单调性保持。∎

### 定理（HPC-M 全身安全-可操作-可学习完备性）
**陈述**：对任意全身计划 π，`HPCM.admits_plan(π)=True` ⟺ π 同时满足：(1) v23 四证（几何/规范/负信息/能量/云边/少样本/IP）；(2) 全身扫掠体无碰撞；(3) 旧证书可运输至当前位姿；(4) 存在可达-安全位姿且路径证书不变；(5) 少样本动作经护盾放行。
**证明**：由 `admits_plan` 的连言条件直接可得必要性；充分性由引理 5–8 保证运输覆盖、护盾安全、路径有效与单调退化，构成闭环。∎

## 6. 本轮最大风险（最终确认）

**一句话**：EMCT 的全部运输可靠性押在"场景刚性 + 自运动已知"的等变性假设上；一旦有**非刚体运动**（行人、形变物体、光照突变）与机器人自运动同时发生，刚性门控可能漏检，运输松弛会系统性低估证书退化，机器人便带着一张**在旧位姿有效、在新位姿已悄悄失效的缺席证书**自信驶向目标——即**运输诱导的缺席幻觉**，而护盾因信任这张过期证书也无法拦截。
