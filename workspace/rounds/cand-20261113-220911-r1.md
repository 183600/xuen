# 第 69 轮（承接第 68 轮「CALM-RAS 自标定·自监督·单模型多任务风险自适应闭环」IP-243~252；灵感循环新循环第 2 轮；本轮灵感：「低延迟推理」×「云边协同」）

> 第 68 轮 CALM-RAS 把「测量可信度」提升为一等公民，但它把全部重资产（MTM 五头、COF EKF、影子训练、五关 CAC、VQAuditor）都压在机器人这一台边缘设备上；更关键的是，它的自陈最大风险——「缓变故障落在标定带宽内被当成漂移标好」——暴露了一个方法论缺口：**系统始终用本机自己的历史去证明自己没坏，缺少一个不受本机标定偏置污染的参照系**。在单机时间序列里，慢漂移与慢故障同谱同形，这是信息论层面的不可分，调参无法解决。
>
> 本轮两个灵感恰好提供两把钥匙：低延迟推理告诉我们「哪些计算必须留在边缘、怎样用早退/投机把延迟从『平均快』变成『WCET 可证』」；云边协同告诉我们「哪里能找到一个独立的外部参照系」。合成核心命题：
>
> **把安全闭环按延迟类切成「边缘硬实时核心 + 云/边端增强」，用「云只收紧、不放宽」的单调权限契约把云的不可靠性彻底隔离出安全路径；同时用机群联邦的差分标定给每台机器一个空间参照系，把时间域不可分的缓变故障转成跨机群可分的离群点——LACE-RAS（Latency-Aware Cloud-Edge RAS）。**
>
> 一句话定位：R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「**这套判断该在哪算、断网了还算不算数、我凭什么相信自己的标定**」。

## 0. 直觉与动机

**灵感 1（低延迟推理 → 安全路径与能力路径必须物理分离）**
直觉：R68 的 2.6ms 预算是把「一次前向」当作单一瓶颈优化的，但真正决定安全的是**最坏执行时间 WCET**，不是平均延迟。云边协同把延迟谱骤然拉宽到 0.1ms～500ms：只要让一个 500ms 的云审计落进安全环路，任何尾延迟就都会变成安全事件。第一性原理因此是——**安全关键路径必须被边缘的确定性 WCET 独占，云只能走旁路**。低延迟推理在本轮的价值不是「更快」，而是「可预测」：早退级联、投机草稿、状态检查点，都是把统计平均变成上界证明的手段。

**灵感 2（云边协同 → 云不是更大的边缘，而是另一个物种）**
直觉：工程上常把云当「算力更大的边缘」，于是直接 offload 整个模型——这是把云的强项（横向视野）和弱项（不可靠、不可控、不可证）一起搬进环路。云真正不可替代的是**同时看见 N 台机器人、跨月的时间、独立维护的仿真与审计**；它的致命弱点是分区、乱序、重放、时钟偏移、拜占庭。正确的角色分配是：**边缘拥有 authority（权限），云拥有 perspective（视野）**——云只能说「更保守一点」，永远不能说「可以放行」。

**灵感 3（把 R68 的死穴变成 R69 的入口 → 差分标定）**
直觉：缓变故障（传感器渐进老化、慢泄漏、缓慢松动）与温漂/蠕变在**单机时间域**上同谱同形，单机永远分不开。破局只能引入第二个维度：空间。若同型号机群在相近环境下的标定漂移本应**相关**，那么「只有我一台持续偏了」就是强故障信号；「全机群一起偏」更像环境/共性。把本地标定 c_i 与机群鲁棒中心 c̄ 做马氏距离检验，即**以空间换时间**（spatial-to-temporal substitution）——这是本轮最重要的方法论跃迁，也直接改写 R68 的 H_cal 先验。

**灵感 4（三机制合流 → LACE-RAS 七组件）**
1. **TPL Task Placement Ledger**：按延迟类 T0/T1/T2 + 安全相关性，为每个任务定位置并做编译期/运行期校验；
2. **LBC Latency Budget Contract**：非阻塞不变式，云调用「发射即忘、超时即弃」；
3. **CTO Cloud-Tightens-Only**：保守偏序 ∨，云消息只能把安全状态往保守方向推；
4. **FDC Fleet Differential Calibration**：机群空间参照系 + 隐私摘要；
5. **SER Speculative Edge Reasoning**：early-exit 草稿 + 云端校验 + 认证检查点回滚；
6. **PSM Partition-Safe Mode**：断网自动退化为 edge-only 可证安全；
7. **RAS-CE† 继承核**：R68 的 CALM-RAS 全部保留，只是被重新放置并套上云边契约。

**灵感 5（对 R68 风险的对症下药）**
- R68「缓变故障被标定吸收」→ **FDC**：单机离群即冻结标定吸收，转入 H_sensor^trans；
- R68「CAC 边缘算力不够 / 60s 窗口太紧」→ **分层 CAC**：边缘 fast-CAC 只允许「收紧类」更新上线，云端 full-CAC 才允许「放宽类」更新；
- R68「VQAuditor 单机短上下文」→ 审计迁云，但结论只能经 CTO 收紧通道回灌，审计永不进入实时环路；
- R68「一切押在单机标定带宽 + canary」→ 安全证明搬到边缘 WCET + 权限单调性上，云的不可靠性被结构性隔离。

## 1. 形式化定义（增量：定义 293–309）

**定义 293（LACE-RAS 总览）** LACE-RAS = (TPL, LBC, CTO, FDC, SER, PSM, RAS-CE†)。三条不变式：
(i) **延迟-安全分离**：实时安全环路的可证安全性只依赖边缘 T0 任务的 WCET 与本地认证结果，不依赖任何 T1/T2 任务是否在线、是否及时、是否正确；
(ii) **权限单调性**：远端消息只能使 (λ, τ_risk, k) 更保守（定义 297），任何消息都不能增加放行自由度；
(iii) **参照系外置**：任何「标定正常」的结论必须同时通过本地残差检验（R68 COF）与机群差分检验（FDC）——单机自证无效。

**定义 294（任务图与延迟类）** 计算任务图 G=(V,E)。对 v∈V：WCET(v)、延迟类 ℓ(v)∈{T0,T1,T2}、安全相关性 s(v)∈{SC,SR,BE}、依赖边带传输代价 hop(u,v)。T0：边缘 <1ms 硬实时；T1：MEC 5–20ms 半硬；T2：云 50–500ms 尽力。

**定义 295（安全放置约束）** 放置 π:V→{edge,mec,cloud} 合法 ⇔
(a) s(v)=SC ⇒ π(v)=edge；
(b) 关键路径 Σ_{v∈CP} WCET(v) + Σ hop ≤ D_T0；
(c) 依赖云的边必须是「单向通知」或「可超时放弃」的，不得出现在关键路径的必经边上。

**定义 296（延迟预算契约 LBC 与非阻塞不变式 NB）** 端到端截止期 D = D_T0 + D_T1 + D_T2。每个跨层调用有硬超时 t_out，语义为 fire-and-forget：边缘发出后立即继续，结果迟到即丢弃。形式化 **NB**：实时环路最大阻塞 ≤ max_v WCET(v)（T0 内），与网络状态无关；对冲请求按 p99 而非 mean 设计。

**定义 297（云只收紧 CTO 与保守偏序）** 安全状态 s=(λ,τ_risk,k)。偏序 s'≽s ⇔ λ'≥λ ∧ τ_risk'≤τ_risk ∧ k'≤k。远端消息 m 的施加算子 ∘ 满足 s∘m ≽ s：λ←max(λ,m_λ)，τ_risk←min(τ_risk,m_τ)，k←min(k,m_k)。对任意消息序列 m_1..m_T（乱序、重复、恶意）有 s_T ≽ s_0。

**定义 298（陈旧度门控）** 消息 m=(seq,t_mono,TTL,sig,payload)。边缘维护 last_seq。接受条件：seq>last_seq ∧ (t_now−t_mono)<TTL ∧ sig 验证通过。过期/不合格 → 丢弃并触发保守默认 λ←max(λ,λ_floor,0.8)。时钟只用单调计数（防 NTP 偏移与重放）。

**定义 299（联邦差分标定 FDC）** 机群 N 台，云按隐私摘要聚合鲁棒中心 c̄_t（加权几何中位数）。本地偏差 z_i,t=(c_i,t−c̄_t)^T Σ_F^{-1}(c_i,t−c̄_t)。三态判定：
- z_i<τ_common：与机群一致 → 共性漂移，允许本地 COF 吸收（H_cal）；
- z_i>τ_outlier：单机离群 → 冻结标定吸收，上调 H_sensor^trans；
- c̄ 自身低速漂移 → 环境/共性，**不改变单机判定**（其系统性风险见第 6 节）。
FDC 改写 R68 定义 281 的先验：P(H_cal)←P(H_cal)·exp(−z_i/2)——机群一致性成为标定可信的**必要条件**。

**定义 300（隐私聚合）** 只上报 DP 噪声后的摘要 ĉ_i=c_i+Lap(Δ/ε_dp) 或裁剪梯度，云用 secure aggregation。检验功效随 N 提升，但 DP 噪声抬高 z 的下限 → 可检幅值 a_min(ε_dp,N)（引理 17）。

**定义 301（投机式边缘推理 SER）** 边缘 early-exit MTM 产出草稿 d_t；云端 verifier 产出 v_t 与一致性 agreement(d,v)。接受规则：agreement>θ_spec 且未过期 → 沿用草稿；否则在 κ 步内回滚到认证检查点 cps 并转保守策略。期望延迟 E[D]=p_acc·D_edge+(1−p_acc)(D_edge+D_rtt)，但安全硬延迟恒为 D_edge。

**定义 302（早退级联与安全头不可早退）** 每层 l 有门控 g_l(z)：若 max 头置信度>γ_l 且 margin>m_l 则早退。约束：fault/qual 两个安全相关头**不得早退**（漏检代价不对称），只有 emo/wm 可早退。给出延迟-误接受的 Pareto。

**定义 303（认证检查点）** cps=(z,c,λ,k,seq) 周期落地；SER 拒绝或分区切换时回滚到 cps，禁止半更新状态。回滚 <0.2ms（KB 级状态）。

**定义 304（分区安全模式 PSM）** 心跳超时判定分区 → 进入 edge-only：π 退化为全 edge，禁用 SER 云校验，λ←max(λ,λ_floor^part)，λ_floor^part=max(0.8,λ_floor)，k≤k_edge_max。恢复后需重新同步 seq 并重新认证才退出。

**定义 305（云审计与长期记忆）** VQAuditor-C 迁云，利用跨机群长上下文审计；结论只能经 CTO 回灌，延迟分钟级，不进入实时环路（满足 NB）。

**定义 306（分层 CAC）** 边缘 fast-CAC（轻量金标 + canary，<2s）通过 → 允许**收紧类**更新上线；云端 full-CAC（全量回放 + 联邦对照，分钟级）通过 → 才允许**放宽类**更新。两关都过才做完整换装。

**定义 307（干扰集 ℰ_LACE）** ℰ_LACE = ℰ_CALM × ℰ_net × ℰ_spec × ℰ_fed；ℰ_net={分区, 延迟/乱序/重放, 时钟偏移, 拜占庭云}；ℰ_spec={草稿-验证共谋, 验证过期, 回滚失败}；ℰ_fed={联邦投毒, DP 噪声过大, 机群共模故障}。

**定义 308（J_LACE 证书）** J_LACE=(J_CALM, π, latency_budget_vec, z_i, staleness_ok, spec_agreement, partition_mode)。Valid ⇔ Valid(J_CALM) ∧ CP(WCET)≤D_T0 ∧ 无过期云消息被采纳 ∧ FDC 检验已执行。

**定义 309（管线）** 离线：云训练 MTM + 机群先验 + 联邦初始化；在线：边缘 T0 环 + MEC 聚合 + 云审计/FDC 异步；分区自动降级、恢复再认证。

## 2. 关键算法骨架

```python
# IP-253 TPL：任务放置账本（编译期穷举 + 运行期校验）
SAFE_CLASS = {'mtm_forward', 'cof', 'cfa', 'safety_heads', 'cto_apply', 'psm'}
def place(G, D_T0=2.6e-3):
    pi = {v: 'edge' for v in G.V if v.kind in SAFE_CLASS}
    for v in G.V - pi.keys():                    # 非安全任务在 MEC/云上做最小割
        pi[v] = min_cost_tier(v, latency_class=v.lc)
    assert all(pi[v] == 'edge' for v in G.V if v.sr == 'SC')       # 定义 295-a
    assert critical_path_wcet(G, pi) <= D_T0                        # 定义 295-b
    return pi

# IP-254/255/258 LBC + CTO + PSM：非阻塞发送 + 只收紧 + 分区降级
class CloudEdgeShell:
    def __init__(self, edge):
        self.edge, self.last_seq, self.partition = edge, -1, False
    def fire(self, msg):                          # 发射即忘，绝不阻塞
        if self.partition: return
        try: self.nic.send_nonblocking(msg)
        except NetError: self.enter_partition()
    def on_msg(self, m):                          # 陈旧门控 + 单调收紧
        if m.seq <= self.last_seq or now_mono() - m.t > m.TTL: return
        if not verify(m.sig): return
        self.last_seq = m.seq
        s = self.edge.s
        self.edge.s = (max(s.lam, m.lam), min(s.tau_risk, m.tau_risk),
                       min(s.k, m.k))             # 定义 297：只往保守推
    def enter_partition(self):                    # 定义 304
        self.partition = True
        self.edge.lam = max(self.edge.lam, 0.8)
        self.edge.k   = min(self.edge.k, K_EDGE_MAX)
        self.edge.ser.disable_cloud_verify()

# IP-256 FDC：机群差分标定（云聚合 + 边缘判定）
class FleetDifferentialCalibration:
    def update_center(self, summaries):           # 云侧：鲁棒中心 + secure agg
        self.c_bar = geometric_median([s.c for s in summaries])
        self.Sigma_F = robust_cov(summaries)
    def judge(self, c_i):                          # 边缘侧：三态判定
        z = mahalanobis(c_i, self.c_bar, self.Sigma_F)
        if z < TAU_COMMON:    return 'COMMON_DRIFT', z     # 允许 COF 吸收
        if z > TAU_OUTLIER:   return 'SUSPECT_FAULT', z    # 冻结吸收
        return 'AMBIGUOUS', z

# IP-257 SER：投机草稿 + 云端校验 + 检查点回滚
class SpeculativeEdgeReasoning:
    def step(self, obs, cps):
        d = self.mtm.early_exit(obs, skip_safe_heads=False)   # fault/qual 必须跑满
        self.shell.fire({'draft': d, 'seq': self.seq})        # 不阻塞
        if self.cached_verdict and self.cached_verdict.agree(d) > THETA_SPEC:
            return d                                           # 接受草稿
        return self.rollback(cps)                              # 拒绝 → 回到认证状态

# IP-262 主闭环：LACE-RAS round（T0 路径，无任何云阻塞）
def LACE_RAS_round(M, obs):
    cps = M.checkpoint.save()                                  # 定义 303
    x = M.lsf.fuse(M.usr.fuse(*obs[:4]))
    z, o = M.mtm.forward(obs, M.a_prev, M.ctx)                 # 边缘，<0.9ms
    r = residuals(x, o, M.wm_cache)
    c, U, thr = M.cof.step(o['cal'], r, sigma_stat(M))
    verdict, z_i = M.fdc.judge(c)                              # 空间参照
    if verdict == 'SUSPECT_FAULT': thr['lam_floor'] = max(thr['lam_floor'], 0.8)
    joint = M.cfa(rho=M.fir(z), face=o['pi'], c=c, U=U)
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x, H=M.vista.H),
                                    joint, min(M.vista.m, M.m_emo),
                                    M.alpha_chunk, M.mtm.rollout(z, M.ach.actions()))
    lam = max(M.efs.risk_scale(joint), thr['lam_floor'])
    tau = M.pi_sigma.prefix_dispatch(M.ach.plan()[:k]) * lam
    M.shell.fire({'z': z, 'c': c, 'U': U, 'z_i': z_i, 'seq': M.seq})  # 异步增强
    M.shell.on_msg(pending_cloud_msg_snapshot)                 # 只收紧
    return k, lam, joint, (c, U), z_i
```

## 3. 推导

**引理 16（云只收紧的安全性隔离）** 在定义 297、298 下，对任意云消息序列（含拜占庭/重放/乱序），边缘安全状态 s(t)≽s_edge(t)（edge-only 基线）。证明：∘ 逐分量取最保守值且单调，陈旧门控只删除消息、不反转方向；归纳得 s_T≽s_0。系：**云故障是可隔离的可用性故障，而非安全性故障**；安全性因此与云的可用性、延迟、正确性解耦（定理 17）。

**引理 17（空间换时间：FDC 的慢故障可检性）** 设单机慢故障幅值 a、机群其余无故障，DP 噪声等效方差 σ_DP²。FDC 统计量期望 μ_z≈a/σ_F，方差由 σ_DP² 与聚合误差决定。检出概率 P_d=Φ((a/σ_F−τ_outlier)/s_z)。对比无 FDC：故障频率 ω_f<ω_cal ⇒ 一阶跟踪器稳态残余 →0 ⇒ P_d→0（性能被标定吸收）。故只要 a>a_min≈τ_outlier·σ_F·s_z，FDC 可检，而该 a 在时间域**完全不可分**。代价：需 N 足够大以稳定 c̄，且**假设故障在机群间独立**（第 6 节的命门）。

**引理 18（投机推理的延迟-安全权衡）** 接受率 p_acc、误接受概率 ε_spec、回滚成本 c_rb。E[D]=D_edge+(1−p_acc)(D_rtt+c_rb)，安全违规增量 ≤ ε_spec + P(回滚失败)，后者由认证检查点界住。提高 p_acc 降延迟却抬 ε_spec，需 θ_spec 随云可用性自适应。

**定理 16（LACE-RAS 端到端风险一致性）** 在 R68 的 A87–A94 与 LACE 假设 A95（单机故障独立、DP 界、消息签名完备）下：
1. P(|τ_cmd−τ*|>ε) ≤ α_chunk+δ_fi+α_emotion+α_wm+α_vqa+α_cal+α_spec+α_fed，其中 **α_net=0**（引理 16 把它归入可用性）；
2. 分区期间 λ≥0.8 ∧ k≤k_edge_max ⇒ 安全违规 ≤ R68 基线；
3. FDC 使缓变故障的可检幅值从 ∞（被吸收）降到 a_min（引理 17）。

**定理 17（延迟-安全分离 / CAP 式）** 在 NB + CTO 下，Safety(系统)=Safety(edge-core)，与云可用性 A_c、延迟 D_c、正确性 C_c 解耦；云只影响 Capability（精度/视野/长尾）。系：网络分区破坏的是能力与可用性，不是安全——这正是「云边协同」能安全落地的前提。

## 6. 本轮最大风险

**一句话**：FDC 的全部效力押在「故障在各机之间独立」这一假设上——**若缓变故障是共模/系统性的（同批次传感器、同一固件 bug、同一环境应力），机群中位数会随故障一起漂移，z_i 恒小，故障被提升为「机群正常」；而 N 越大 c̄ 越稳、置信区间越窄，系统就会越自信地集体失明**——这是「以空间换时间」的规模悖论：用更多机器换来的不是更多证据，而是对同一个错误均值的更高置信度。

**次级风险与缓解**：
1. **只收紧棘轮 → 可用性坍缩**：拜占庭持续收紧会造成永久退化 → 收紧需单调但可由 full-CAC + 人类授权重置，并监控可用性下限；
2. **联邦投毒 / DP 噪声**：鲁棒聚合（几何中位数/裁剪）+ 签名 + 单点贡献上限 + E292 功效门限；
3. **投机共谋 / 验证过期**：独立 verifier、TTL、认证检查点回滚、E289 对抗测试；
4. **放置错误**：SC 任务误置云端 → 编译期断言 + 运行期 WCET 监控（定义 295）；
5. **时钟/重放**：单调序号 + TTL + 签名，禁用墙钟做新鲜度判据；
6. **共模故障的兜底**：保留少量「独立计量锚」（不同批次/不同原理传感器、外部基准站、定期人工抽检）作为机群之外的第三参照系，并对 c̄ 做偏置漂移告警。

## 2. 形式化定义（要点版）

**定义 293（总览与三不变式）** 延迟-安全分离（安全性只依赖边缘 T0 的 WCET 与本地认证）；权限单调性（远端消息只能更保守）；参照系外置（「标定正常」须同时过本地残差与机群差分检验）。

**定义 294–295（任务图与安全放置）** 任务按 T0/T1/T2 分类；合法放置要求 s(v)=SC⇒π(v)=edge，关键路径 ΣWCET+Σhop ≤ D_T0，且不得让云依赖成为关键路径必经边。

**定义 296（LBC / NB）** 跨层调用硬超时 + fire-and-forget；实时环路最大阻塞 ≤ max WCET(v)，与网络状态无关。

**定义 297（CTO 保守偏序）** `s'≽s ⇔ λ'≥λ ∧ τ_risk'≤τ_risk ∧ k'≤k`；消息施加 `λ←max, τ_risk←min, k←min`；任意乱序/重复/恶意序列仍 `s_T≽s_0`。

**定义 298（陈旧度门控）** `seq>last_seq ∧ (t_now−t_mono)<TTL ∧ sig 通过`；过期即丢弃并触发保守默认；只用单调计数，禁墙钟。

**定义 299（FDC）** `z_i=(c_i−c̄)^T Σ_F^{-1}(c_i−c̄)`；`z_i<τ_common`→共性漂移可吸收；`z_i>τ_outlier`→冻结吸收并上调 H_sensor^trans；`P(H_cal)←P(H_cal)exp(−z_i/2)`。

**定义 300（隐私聚合）** DP 摘要 / 裁剪梯度 + secure aggregation；噪声抬高 z 下限，得到可检幅值 `a_min(ε_dp,N)`。

**定义 301–303（SER / 早退 / 检查点）** 边缘草稿 + 云端 verifier；`agreement>θ_spec` 才接受；fault/qual 安全头**不得早退**；拒绝或分区时回滚到 cps，禁止半更新。

**定义 304（PSM）** 分区→全 edge 放置、禁用云校验、`λ←max(λ,max(0.8,λ_floor))`、`k≤k_edge_max`；恢复需重同步 seq 并再认证。

**定义 305–306（云审计 / 分层 CAC）** VQAuditor-F 迁云、仅经 CTO 回灌；fast-CAC 放行收紧类、full-CAC 才放行放宽类。

## 4. 推导

**引理 16（云只收紧的安全性隔离）** 在定义 297、298 下，对任意云消息序列（乱序/重放/拜占庭），有 `s(t)≽s_edge(t)`。因 ∘ 逐分量取最保守值且单调，陈旧门控只删消息不改方向，归纳即得。系：云故障是可隔离的**可用性**故障，不是安全性故障。

**引理 17（空间换时间 / FDC 可检性）** 单机慢故障幅值 a 时 `μ_z≈a/σ_F`，检出概率 `P_d=Φ((a/σ_F−τ_outlier)/s_z)`。无 FDC 时 `ω_f<ω_cal` 导致一阶跟踪器稳态残余→0、`P_d→0`（故障被标定吸收）；FDC 使可检下界降至 `a_min≈τ_outlier·σ_F·s_z`——**该幅值在时间域完全不可分，在空间域可分**。代价：N 要足够大，且故障须机群独立（第 7 节命门）。

**引理 18（投机延迟-安全权衡）** `E[D]=D_edge+(1−p_acc)(D_rtt+c_rb)`，安全硬延迟恒为 `D_edge`；违规增量 `≤ ε_spec + P(回滚失败)`，后者由 cps 界住。

**定理 16（端到端风险一致性）** A87–A94 与 A95 下：
1. `P(|τ_cmd−τ*|>ε) ≤ α_chunk+δ_fi+α_emotion+α_wm+α_vqa+α_cal+α_spec+α_fed`，其中 **α_net=0**（引理 16 归入可用性）；
2. 分区期间 `λ≥0.8 ∧ k≤k_edge_max ⇒` 违规 ≤ R68 基线；
3. FDC 把缓变故障可检幅值从 ∞（被吸收）降到 `a_min`（引理 17）。

**定理 17（延迟-安全分离 / CAP 式）** 在 NB + CTO 下 `Safety(系统)=Safety(edge-core)`，与云可用性、延迟、正确性解耦；云只影响 Capability（精度/视野/长尾）。系：网络分区破坏能力，不破坏安全。

| E298 消融 | CTO/FDC/SER/PSM 贡献 | 去 CTO→拜占庭可放宽；去 FDC→慢故障不可检 |
| E299 扩展性 | N=10/100/1000 | c̄ 方差 ∝1/N；a_min 随 N 下降 |
| E300 延迟-安全帕累托 | 放置+投机联合调优 | 给出 P99 延迟 vs 安全裕度前沿 |

## 7. 本轮最大风险

**一句话**：FDC 的全部效力押在「故障在机群间独立」这一假设上——**若缓变故障是共模/系统性的（同批次传感器、同一固件 bug、同一环境应力），机群中位数会随故障一起漂移，z_i 恒小，故障被提升为「机群正常」；而 N 越大 c̄ 越稳、置信区间越窄，系统就会越自信地集体失明**——这是「以空间换时间」的规模悖论：用更多机器换来的不是更多证据，而是对同一个错误均值的更高置信度。

**次级风险与缓解**：只收紧棘轮导致可用性坍缩（full-CAC + 人类授权重置 + 可用性下限监控）；联邦投毒/DP 噪声（鲁棒聚合 + 签名 + 单点贡献上限）；投机共谋/验证过期（独立 verifier + TTL + cps 回滚）；放置错误（编译期断言 + 运行时 WCET 监控）；时钟重放（单调序号 + TTL + 签名）；**共模兜底**——保留少量不同批次/不同原理的「独立计量锚」（外部基准站、定期人工抽检）作为机群之外的第三参照系，并对 c̄ 做偏置漂移告警。
