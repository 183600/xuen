# 第 8 轮 · A3：情感计算不是读表情，是让通用机器人平台对自己的进展有“感觉”

> 检索/复核日期：2026-10-24（UTC）。赛事身份不变：用户所指是宇树科技的 **UniBot 世界挑战赛**（unibot.unitree.com），G1 + Dex1、32 项桌面任务、通才单模型赛道、选手自部署 + 官方远程真机 API 评测。提示写的是“新循环第 1 轮”，但状态文件已累积到第 7 轮；我按“接续迭代”处理，编号第 8 轮，保留第 7 轮的 SSG/PGL/OPT/ICR/SVL/NRB，只修剪与评分结构不再匹配的部分。本轮三个灵感词是「情感计算」「通用机器人平台」「演示数据」。

**本轮主判断：UniBot 现在缺的不是又一个更强的 VLA，而是一个能判断“我现在到底在不在正轨上、还剩多少时间、该不该多花算力”的元认知层。把“情感计算”从表情识别翻译成机器人自身的三种可测状态——自信（self-efficacy）、惊讶（prediction violation / sense of agency）、挫败（persistent non-progress）——再用官方 33k 演示数据做“正常性先验 + 恢复矿 + 校准集”，就能在不引入第二个模型、不依赖外部数据的前提下，直接抬高成功率的闸门，并把 20% 的人为干扰试验变成可检测、可恢复的事件。**

## 0. 本轮先核实：三件事改变了判断

### 0.1 排名是“成功率优先，步骤分只做加赛”

中文参赛手册写明：

> “实时榜单按 32 个任务的总平均成功率进行排序，成功率相同时按总平均步骤分排序，若仍相同，则提交日期较早的模型排序靠前。”  
> “每个任务执行 10 次独立运行……10 次运行中包含 5 种泛化类型，每种类型各出现 2 次。”  
> “所有任务须基于同一模型完成，不得混合使用多个模型一起进行测试，但对模型类型不作限制（World Model、VLA 均可）。”  
> “每个任务单次真机执行最大允许执行时间为 180 秒，超时记为失败。”

来源：参赛手册中文版/英文版（[R1][R2]，检索 2026-10-24）。首页写的“按平均成功率与步骤分综合排序”是营销口径，**手册的字典序规则才是权威**。

这条规则的含义比第 7 轮更锋利：

- 总试验数是 **32 × 10 = 320** 个 episode；每个 episode 值 **0.3125 个百分点**。
- **成功率是第一目标；步骤分只在成功率打平时才起作用。** 因此第 7 轮“终局步骤占 39.8% 步骤分”的论据要降级为辅助论据；终局放置仍然最重要，但原因是它是 **32/32 任务的成功闸门**，不是因为它分值高。
- 五个泛化轴各占 **64/320 = 20%**；人为干扰轴是一个边界清晰、只有 64 个 episode 的子问题，正好适合用“惊讶/能动性”去攻。
- 任何“为了多拿步骤分而牺牲成功率”的策略都是错的；任何“可能破坏本来成功 episode”的干预都要用保守阈值。

### 0.2 榜单头部仍是占位：29.7% 不是真实成绩

本轮抓取 `leaderboard.html`、`leaderboard_data.json` 和详情页（[R3][R4][R5]）：

- 页面确实渲染了 8 个模型：MolmoAct2 29.7%、WALL-OSS-0.5 28.5%、DreamZero 27.9%、Spirit-v1.5 25.9%、DM0 23.5%、PI-0.5 22.8%、GigaBrain-0 22.6%、GR00T N1.5 20.5%。
- 但 `leaderboard_data.json` 的 `generated_from` 字段是 `gen_leaderboard.py`；详情页每个任务都写着“测试视频占位，后续可替换为真实视频文件”；表格下方仍保留“即将发布”。
- 结论：**这 8 个分数是占位数据，不是真实参赛成绩**。用户看到的“榜首不到 30%”确实对应占位榜首 29.7%，但不能据此推断真实头部方案的做法或瓶颈。真实榜单尚未发布。

占位数据仍有两个弱用途，必须标注“未核实”：

1. **难度先验**：占位榜里最难的是 PlugInEthernet 17.7、Unlock 20.1、SpellRobot 21.8、OrganizeStationery 22.5、OpenPillBottle 22.7；最易的是 StackCups 30.3、ConveyorFoodSorting 29.1。模式是“接触丰富的插入/关节操作 + 精细小件”最难，“堆叠/排列”相对容易。这与第 7 轮的“终局接触是闸门”一致。
2. **失败位置先验**：8 个占位模型的步骤分平均比成功率高 **8.6pp**（39.0−29.7、38.9−28.5……）。如果真实数据也呈这个结构，说明多数失败发生在“做了大部分步骤、倒在最后一步/最后几步”。但这只是先验，不能当结论。

因此本轮不写“榜单头部团队怎么做”，而写“8 个占位模型名所代表的公开方案类型，在 UniBot 评分结构下最可能卡在哪”。这是类型学分析，不是榜单实证。

官方基线 **UnifoLM-WLA-1.0-Base**（[R7][R8][R9]，检索 2026-10-24）：

- 6B 参数；约 2,500 小时真机数据；单模型覆盖 64 个任务（54 个桌面 + 10 个全身）。

这条基线事实意味着：**base model 的军备竞赛已经很拥挤，官方自己就有 6B/2,500h 的强先验；参赛者更大的边际收益在“执行时的最后一公里”，而不是从零再造一个 VLA。**

## 1. 三个灵感词：先拒绝字面义，再操作化

### 1.1 情感计算：不是表情识别，是“内生元认知”

字面理解“情感计算”会想到表情/语音/生理信号识别。但 UniBot 里：

- 没有音频、没有面部特写、没有 affect 标签；
- 人类只作为“干扰源”出现，不做对话；
- 评分只看任务成功率和步骤分，识别情绪不直接改变分数。

所以字面义是个 1/5 轴的旁支，投入产出比很低。真正可用的翻译是**把情感计算里的“内部状态”概念拿过来，做成机器人可测量、可校准的控制变量**：

| 变量 | 情感/认知对应 | 机器人定义 | 观测方式 |
|---|---|---|---|
| 自信 \(c_t\) | self-efficacy / confidence | 当前步骤能成功完成的概率 | 动作采样离散度、动作似然、校准后的成功率 |
| 惊讶 \(s_t\) | surprise / sense of agency | 实际观测偏离“我的动作本该造成的结果”的程度 | 动作条件未来预测误差、本体残差 |
| 挫败 \(f_t\) | frustration / non-progress | 当前步骤停留时间超过演示先验的程度 | SSG 步骤状态 + 时间/尝试次数 |

这不是拟人化修辞。2025–2026 年已经有一批直接可用的证据：

- **Robot Metacognition**（[R13]）：把 confidence 定义为“对决策的二阶判断”，并用它调节机器人的资源分配与行为；这正是 A3 的哲学基础。
- **Confidence Calibration in VLA**（[R14]）：VLA 的置信度通常 miscalibrated；prompt ensemble 与 action-wise Platt scaling 可把 ECE 降 20%+；置信度在任务取得进展后更可靠——支持“分步骤校准”。
- **TD Calibration for VLA**（[R15]）：把序列任务的置信度校准与 value function 联系起来，用 TD 做时序校准；说明“步骤级自信”可以被形式化为一个 value head。
- **ReconVLA**（[R16]）：对 VLA 的动作 token 做 conformal prediction，得到与执行质量相关的校准不确定性，并在不重训的情况下做失败预警。
- **UPS**（[R17]）：用 conformal prediction 校准 VLM verifier，把不确定性映射为“执行 / 询问 / 重训”三种策略；虽然 UniBot 不能问人，但“不确定性→策略”的框架可直接借用。
- **Metacognitive evaluation framework**（[R29]）与 **REFLEX**（[R30]）：用 self-monitoring AUC、error detection delay、Brier score 评估元认知，并证明元认知模块能提高任务成功率与异常响应速度。

一句话：**“情感”在这里不是情绪，而是机器人对自己进展的“感觉”；它必须是可校准的，否则只是噪声。**

### 1.2 通用机器人平台：不是再造一个机器人，是做一个策略无关的元认知运行时

“通用机器人平台”可以理解为“跨本体/跨任务的基础模型”，但 UniBot 的评测只在 G1 + Dex1 上做，跨本体不是直接分数杠杆；官方 WLA 已经把跨本体先验做进去了。更合适的平台层解读是：

- 比赛规则是“单模型 + 全 32 任务 + N 端口远程服务 + 180 秒”；
- 官方 WLA 是一个强 base，但所有参赛者都可以微调它；
- 真正能拉开差距的是 **base model 之外的运行时**：观测/动作标准化、reset 时校准、步骤状态机、置信度/惊讶监控、测试时算力分配、恢复库、N 端口状态隔离、延迟与动作规整性。

因此本轮把“通用机器人平台”落地为一个 **policy-agnostic 的元认知运行时（PNMR）**：它不替代 base model，而是包在 base model 外面；可以包 WLA，也可以包 π0.5、GR00T、MolmoAct。它必须满足单模型规则：**学习组件只在同一个 checkpoint 里；控制器是确定性代码；校准是统计表，不是第二个模型。**

这也是一个战略判断：当所有人都在微调同一个 WLA 时，**平台层的“最后一公里”是差异化更高的资产**；它还能复用到其他机器人/任务，赛后价值更大。

### 1.3 演示数据：不是再加数据，是“正常性先验 + 进度先验 + 恢复矿 + 校准集”

33k/169h 已经不小；再堆同分布数据边际收益很低，而且外部数据政策未明。更有价值的是换一种用法：

| 用法 | 数据 | 产出 | 为什么可行 |
|---|---|---|---|
| 正常性先验 | 33k 成功演示 | 动作条件未来预测器 \(f_\phi\) | 成功演示定义“正常”；失败是偏离正常 |
| 进度先验 | `score_steps` + 演示 | 步骤分类/剩余时间头 | 官方已公开每任务 2–5 个步骤及顺序 |
| 恢复矿 | 成功演示中的微恢复段 | 重抓/回退/微调动作库 | 成功轨迹里本来就有 pause→re-approach、gripper 反复开合、轻推校正 |
| 校准集 | held-out 演示 + 官方 human 备注扰动 | conformal 阈值 | 不需要真实失败数据也能控制误报 |
| 扰动剧本 | 官方 `human_1_note`/`human_4_note` | 64 个（32×2）扰动脚本 | 与评测的人为干扰轴 2 次/任务一一对应 |

这条思路的核心是：**成功演示不只用来模仿，还用来定义“正常”；有了正常，偏离就可以被检测。** 2026 年的执行时验证/恢复文献正好在往这个方向走：

- **Foresight**（[R18]）：用 action-conditioned world model latent 做长程失败检测，只用最终成功/失败标签训练，并用 conformal 校准阈值。
- **CheckVLA**（[R19]）：用 action-conditioned world model 在 chunk 执行中验证“承诺的动作是否产生预期观测”，RoboCasa365 36.1% vs 周期重规划 27.6%（+8.5pp）；动作条件把及时召回从 48.6% 提到 77.9%。
- **FaRe**（[R20]）：把失败恢复表述为对因果历史做 test-time scaling，真实双臂 71.7%→83.3%。
- **B2FF**（[R21]）：用预想象的未来 milestone 做恢复，冻结 VLA，failure-injected LIBERO +17.7pp。
- **VeriVLA**（[R22]）：用 JEPA latent world model 做自适应测试时验证，真实任务 50.8%→65.5%，每次触发 +326ms。
- **WEAVER**（[R23]）：多视图世界模型做 best-of-N 测试时规划，真实任务 +14–15%。
- **GeoBoN**（[R24]）：用跨视图几何一致性做无标签 rollout 选择，N=8 普遍涨点，且“只在初始 rollout 不一致时触发”可回收 74.8% 的增益。

这些工作说明“执行时监控/验证/恢复”是 2026 年的主赛道，但也说明它已经很拥挤。我们的差异必须落在 UniBot 的三个特殊性上：

1. **评分是 success-first**：监控的目标不是“更漂亮的步骤分”，而是“别把本来能成功的 episode 弄失败”；误报的代价必须被严格约束。
2. **人为干扰轴有官方逐任务剧本**：我们可以用 `human_1_note`/`human_4_note` 做“忠实扰动校准”，而不是随机噪声。
3. **单模型规则**：不能用第二个 verifier 模型；必须把信号做进同一个 checkpoint，或用训练无关信号。这反而逼出一种更轻、更可解释的方案。

## 2. 主判断：给单模型加一层“自我效能感”，把测试时算力花在刀刃上

### 2.1 失败模型：不是“不会做”，而是“不知道自己做错了/该不该再试”

把第 7 轮的六类放置失败（P1–P6）重新按“元认知”归因：

| 失败 | 传统解释 | 元认知解释 | A3 对策 |
|---|---|---|---|
| P1 目标 grounding 错 | 空间感知不足 | 自信很高但预测错（miscalibrated） | 低自信→verify；锚点重定位 |
| P2 接近碰撞 | 运动规划差 | 惊讶尖峰被忽略 | 高惊讶→短前缀/重试 |
| P3 姿态不对 | 位姿精度不够 | 终局自信未校准 | 终局 self-efficacy→SVL |
| P4 释放过早/过高 | 开环 chunk | 没有“结果验证” | 释放后 settle 检查 |
| P5 插入力不够 | 力控不足 | 惊讶/本体残差持续 | 柔顺插入 + 重试 |
| P6 不验证就以为完成 | 无步骤状态 | 没有“完成感” | SSG 谓词 + 步骤状态机 |
| P7 人把物体移走/撤销 | 外部扰动 | 惊讶高但归因错 | 动作条件残差→外部归因→yield/replan |

一句话：**多数失败不是“动作不够好”，而是“系统不知道自己已经偏了”。** 这正是情感计算/元认知能补的层。

### 2.2 算术：为什么这层比“再换一个 VLA”更划算

- 320 个 episode；每个 0.3125pp。
- 终局放置是 32/32 任务的成功闸门。若到达终局的概率 \(q=0.5–0.7\)，终局成功率 +15pp 的上限收益是 **+7.5–10.5pp**（实际会低一些，因为 q 也会变）。
- 人为干扰轴 64/320 = 20%。若该轴基础成功率 15%、其他轴 25%，A3 把该轴失败恢复 30%，则总体增益约 **0.2 × 0.85 × 0.30 ≈ +5.1pp**。这是一个边界清晰、可单独验证的目标。
- 误报代价：若 A3 在 5% 的正常 episode 上触发“重试/重抓”（16 个），每个破坏 0.5 个成功，损失约 2.5pp——**这足以吃掉全部收益**。所以 A3 必须把“verify（安全、只花时间）”与“retry/regrasp（有风险）”分开，并对后者用更保守的 conformal 阈值。
- 时间预算：演示平均 18.3s，最长 37.6s；180s 允许 1–2 次 verify + 0–1 次 retry。长程任务（T16/T17/T31）要限次数。

对比三条路：

| 路线 | 边际成本 | 风险 | 预期收益 |
|---|---|---|---|
| 再训一个更大的 VLA | 8×H100 数周；数据/调参 | 高；可能不如 WLA 基线 | 不确定 |
| 外部实验室补数据 | 协调/合规/硬件 | 规则未明；可能违规 | 背景/位置轴 +Δ/5 |
| **A3 元认知层** | 小头 + 校准 + 运行时；1–2 人 6 周 | 误报、域差、单模型解释 | **成功率 +3–5pp；人为干扰轴 +10–25pp** |

A3 的杠杆不在“更强”，而在“更会止损/更会重试/更会让行”。

### 2.3 与第 7 轮的关系：保留效应器，升级调度器

- **保留**：SSG（步骤图）、PGL（放置目标阶梯）、OPT（少样本位姿迁移）、ICR（检索上下文）、SVL（落点闭环）、NRB（官方备注恢复）、DebugLoop、GPR-VLA/WLA 底座、Endurance/Compliance。
- **升级**：SVL 从“固定终局循环”变成 A3 的一个动作（`verify`）；SSG 从“步骤匹配器”变成“步骤状态 + 谓词 + 回归检测”；NRB 从“训练数据”变成“校准扰动 + 恢复库”。
- **修正**：第 7 轮把“步骤分 39.8%”当主论据；本轮改为“终局是成功闸门，步骤分只是加赛”。这会让预算更偏向“成功率保护”，而不是“多拿部分分”。
- **修剪**：FLEET 作为研究轴、全 32 任务高保真孪生、自由仿真数据、运行时仿真/MPC、仿真 RL、布料/拉链/透明全物理、WMA-0 进主路径、每任务 LoRA、把外部实验室数据当依赖、字面情感识别、独立 verifier 模型。

## 3. 方案轮廓：A3（Affect-as-Arbitration）

```text
语言(160条复述之一) ──► SSG 步骤图 ──► 当前步骤 s_t / 谓词 / 剩余时间
                                      │
观测(4相机+proprio) ──► WLA 单 checkpoint ──► N 个 action chunks
                                      │
                     ┌────────────────▼────────────────┐
                     │ EMC 内生元认知信号                │
                     │  c_t：动作采样离散度→校准成功率    │
                     │  s_t：动作条件未来预测误差         │
                     │  f_t：步骤停滞时间/尝试次数        │
                     │  a_t：外部扰动 vs 内部失败归因     │
                     └────────────────┬────────────────┘
                                      ▼
                     ┌─────────────────────────────────┐
                     │ 仲裁器（确定性规则+conformal阈值） │
                     │ commit / verify / retry / regrasp │
                     │ replan / yield / reset-step       │
                     └────────────────┬────────────────┘
                                      ▼
              PGL 锚点 / OPT 位姿 / ICR 检索 / SVL 落点 / NRB 恢复
```

三个关键设计：

1. **信号内生**：自信来自同一模型的动作采样；惊讶来自同一 checkpoint 的未来预测头（或训练无关的本体残差）；挫败来自 SSG。**不引入第二个模型。**
2. **仲裁保守**：`verify` 是安全的（短前缀 + 重观测 + best-of-N），`retry/regrasp` 是有风险的（只在惊讶高且内部归因时用），`yield` 只用于外部扰动。阈值用 conformal 控制在正常演示上 ≤5% 误报。
3. **运行时平台化**：N 端口、每端口状态隔离、共享推理后端、180s 时间守卫、延迟/动作规整性日志；可以包任何 base policy。

## 4. 风险与我先立的反驳

- **“情感计算是噱头”**：我同意字面情感识别是噱头；所以本轮把它严格定义为 confidence/surprise/frustration 三个可测量、可校准的控制变量，并给出 2025–2026 的 VLA 置信度/元认知文献。若离线校准都做不出来（ECE>0.2、惊讶 AUROC<0.6），这个点就自动降级。
- **“误报会把成功 episode 弄坏”**：这是最大风险。对策是把 verify 与 retry 分开，后者用更保守的阈值；先做“只读监控”离线评估，再上调试槽；任何大版本最多 1 个调试槽做 A/B。
- **“单模型规则不允许第二个模型”**：A3 的 full 版本把未来预测/进度头放进同一个 checkpoint；minimal 版本完全训练无关（动作采样离散度 + 本体残差 + SSG 时间），不新增任何模型。两条路都保留。
- **“惊讶头会被背景/光照域差带偏”**：所以主信号用本体/EE 残差与动作条件预测，不用像素重建；背景轴用官方 5 轴数据/合成扰动做分组校准；AUROC 不达标就回退。
- **“base policy 太弱，监控也救不了”**：A3 是互补件，不是替代品；先用 WLA 官方微调把 base 做到可用，再用 A3 抬最后一段。若 E0 基线成功率 <15%，优先补 base，而不是加监控。
- **“真实榜单不可得，无法证明头部方案”**：本轮明确标注占位数据，不做“头部方案实证”；用公开模型家族做类型学分析，用规则/数据/调试槽做自己的验证。

## 5. 一句话押注

**本轮最值得押注：在 WLA 单模型上做「内生元认知控制（A3）」——用动作采样离散度、动作条件未来预测误差、步骤停滞三个可校准信号，决定何时提交、验证、重试、重抓或让行；它不引入第二个模型、不依赖外部数据，直接提高成功率（步骤分只是加赛），并把人类干扰轴变成可检测、可恢复的事件。**

**共同瓶颈**（假设，需调试槽验证）：

1. 没有显式的“当前步骤/谓词”状态，容易跳步、假完成、被撤销后不知道；

3. 终局接触（插入、堆叠、闭合、倒药）是 success gate，但策略通常在开环 chunk 里“放完就走”；

5. 远程 API 的延迟/抖动会放大上述问题，但大多数方案只优化离线成功率。

## 2. 评分算术：success-first 下的资源分配

### 2.1 目标函数

设任务 \(i\) 的第 \(j\) 次运行为 \(s_{ij}\in\{0,1\}\)，步骤分为 \(p_{ij}\in[0,100]\)：

\[
S=\frac{1}{320}\sum_{i=1}^{32}\sum_{j=1}^{10}s_{ij},\qquad
P=\frac{1}{320}\sum_{i=1}^{32}\sum_{j=1}^{10}p_{ij}.
\]

排名规则：先比 \(S\)，\(S\) 相同再比 \(P\)，再相同比提交日期。因此：

\[
\text{maximize } S \quad\text{subject to}\quad \text{do not destroy successful episodes;}
\]

\(P\) 只在 \(S\) 打平时有价值。**任何“为了步骤分牺牲成功率”的改动都不做。**

### 2.2 每个 episode 的边际价值

\[
\Delta S = \frac{1}{320} = 0.3125\text{pp}.
\]

救回 10 个 episode = +3.125pp；救回 16 个 = +5pp。反过来，误伤 16 个成功 episode = −5pp。**A3 的误报预算必须远小于恢复收益。**

### 2.3 三个杠杆

| 杠杆 | 规模 | 上限收益 | 现实目标 | 备注 |
|---|---|---|---|---|
| 终局放置 | 32/32 任务的成功闸门 | \(\bar q \Delta p_{\text{term}}\)，q≈0.5–0.7 | +3–5pp | 不是步骤分，是 success gate |
| 人为干扰 | 64/320=20% | \(0.2\Delta S_h\) | +3–5pp | 官方备注可校准 |
| 长程步骤回归 | 全部任务 | 防止“做了又撤销” | +1–2pp | SSG 回归检测 |

### 2.4 为什么不是“再换一个 VLA”

- WLA 已经 6B/2,500h/64 任务；从零训练一个更强的 base 成本极高，且评测分布只有 32 任务。
- 32k 数据 + 官方微调 recipe 已经把“模仿”这条路铺好；边际收益更多在“执行时”。
- 单模型规则让“多模型路由/多专家”不可用；A3 的“单 checkpoint + 确定性仲裁”是合规的差异化。
- 成功率优先意味着“保守的止损/重试”比“更激进的探索”更值钱；这正是元认知层的强项。

### 2.5 误报的代价：必须把 verify 与 retry 分开

| 干预 | 风险 | 成本 | 阈值 |
|---|---|---|---|
| `verify`（多采样/短前缀/重观测） | 低（不改变任务状态，只多花时间） | +0.5–2s | 自信低即可触发；正常演示 ≤5% |
| `retry`（重执行当前步骤） | 中（可能碰撞/掉物） | +3–10s | 仅惊讶高且内部归因；≤2 次/步 |
| `regrasp` | 中高 | +5–15s | 仅抓取失败谓词；≤1 次/步 |
| `replan`（检索/换策略） | 中 | +5–20s | 挫败高；≤1 次/步 |
| `yield`（让人） | 低 | +0.5–1s | 外部归因；≤2 次/步 |
| `reset-step`（回退 SSG） | 低 | 0 | 谓词从 1→0；必须 |

**核心设计**：verify 是“安全的”，可以多触发；retry/regrasp 是“有风险的”，必须保守。这样即使自信/惊讶有噪声，也不会轻易破坏成功 episode。

### 3.2 EMC：三个内生信号

#### 3.2.1 自信 \(c_t\)（self-efficacy）

**定义**：当前步骤能成功完成的概率。**来源**：同一 base policy 的随机性。

对每个决策点采样 \(N\) 个 action chunk \(\{a_t^{(i)}\}_{i=1}^N\)（flow/diffusion 的初始噪声不同），计算归一化离散度：

\[
d_t=\frac{2}{N(N-1)}\sum_{i<j}\frac{\|a_t^{(i)}-a_t^{(j)}\|_2}{\sqrt{D}},
\]

其中 \(D=54\) 是动作维度。离散度越低，策略越“确定”。用 held-out 演示拟合等渗回归/Platt scaling：

\[
c_t=g(d_t)\approx P(\text{step success}\mid d_t).
\]

**为什么可行**：

- 不需要额外模型；只用 base policy 的采样。
- 与 VLA 置信度校准文献一致（[R14]）：动作级不确定性可以被校准成成功率预测。
- 计算成本可控：N=4，动作头很小；只在 chunk 边界算。

**注意**：采样离散度可能低估“系统性错误”（模型很自信但全错）。所以 \(c_t\) 只作为“是否需要 verify”的信号，不作为唯一真相；要和惊讶、谓词一起用。

#### 3.2.2 惊讶 \(s_t\)（surprise / sense of agency）

**定义**：实际观测偏离“我的动作本该造成的结果”的程度。**来源**：动作条件未来预测。

训练一个轻量未来预测头 \(f_\phi\)（同一 checkpoint 的辅助头）：

\[
\hat{z}_{t+k}=f_\phi(z_t,\ a_{t:t+k}),
\]

其中 \(z_t\) 是 VLM 的压缩特征（或 EE/物体状态的归一化向量），\(k\) 对应 0.5s/1s。惊讶：

\[
s_t=\|\hat{z}_{t+k}-z_{t+k}\|_2.
\]

**两种实现**：

1. **Full（推荐）**：在冻结 VLM 特征上加 4 层 transformer + MLP，预测未来 EE 位姿（6D）和任务相关物体关键点（2D/3D）。训练目标 L1/L2；数据用 33k 演示；参数量 <50M。
2. **Minimal（合规兜底）**：不用学习头，用**本体残差**：
   \[
   e_t=\|x_{t+1}-\hat{x}_{t+1}\|_2,\quad \hat{x}_{t+1}=x_t+J(q_t)\Delta q_t,
   \]
   其中 \(x\) 是 EE 位姿，\(J\) 是雅可比，\(\Delta q\) 是关节命令。残差大 = 跟踪失败/碰撞；残差小但物体动了 = 外部扰动。

**外部 vs 内部归因**：

| 模式 | 本体残差 \(e_t\) | 物体/未来残差 \(s_t\) | 解释 | 动作 |
|---|---|---|---|---|
| 正常 | 小 | 小 | 按预期 | commit |
| 内部失败 | 大 | 大 | 滑落/碰撞/跟踪失败 | retry/regrasp |
| 外部扰动 | 小 | 大 | 人移动物体/撤销步骤 | yield/replan/reset-step |
| 遮挡/丢失 | 大 | 大 | 视觉丢失/遮挡 | verify/重观测 |

这个 2×2 归因是 A3 的核心：**它不是“检测异常”，而是“区分谁造成的异常”**。CheckVLA（[R19]）证明动作条件比 observation-only 的召回高得多（77.9% vs 48.6%）；我们把它用于“外部/内部归因”。

#### 3.2.3 挫败 \(f_t\)（non-progress）

**定义**：当前步骤停留时间超过演示先验的程度。

\[
f_t=\frac{t-t_{\text{last step transition}}}{\hat{T}_{\text{step}}},
\]

其中 \(\hat{T}_{\text{step}}\) 是当前步骤在演示中的期望时长（按任务/步骤统计）。也可加“失败尝试次数”：

\[
f_t=\max\left(\frac{t-t_{\text{last}}}{\hat{T}_{\text{step}}},\ \frac{n_{\text{fail}}}{2}\right).
\]

**触发**：\(f_t>2\)（比正常慢一倍）→ `replan` 或 `reset-step`；\(f_t>3\) → 优先保时间，降级为保守执行。

**为什么可行**：SSG 已经给出步骤顺序；演示给出每步时长分布；不需要学习。

#### 3.2.4 进度的来源

- 官方 `score_steps` 给出每任务 2–5 步及顺序（T27: 30/30/40；T10: 30/30/40）。
- 演示是成功轨迹，步骤顺序已知；用 EE/物体轨迹的 change-point 检测 + 语言步骤文本对齐，得到帧级步骤标签（允许噪声）。
- 训练一个进度头 \(h_\psi(z_t)\) 预测步骤索引/剩余时间；用 ordinal loss/soft label 抗噪。
- 运行时用谓词（物体在容器内/堆叠高度/拉链闭合/插头到位）确认步骤完成；谓词从 1→0 触发 `reset-step`。

### 3.3 仲裁器：规则 + conformal 阈值

#### 3.3.1 决策表

| 优先级 | 条件 | 动作 | 预算 | 说明 |
|---:|---|---|---|---|
| 1 | 剩余时间 <20s | commit only | 0 | 避免 timeout |
| 2 | 谓词 1→0（被撤销） | reset-step + replan | 1/步 | 人为干扰/自身回退 |
| 3 | \(s_t>\tau_s\) 且外部归因 | yield 0.5s → 重定位 → 必要时 replan | 2/步 | 人移动物体 |
| 4 | \(s_t>\tau_s\) 且内部归因 | retry/regrasp | 2/步 | 滑落/碰撞 |
| 5 | \(f_t>\tau_f\) | replan（ICR/NRB） | 1/步 | 卡住 |
| 6 | \(c_t<\tau_c\) | verify（ATTS） | 3/episode | 不确定 |
| 7 | 默认 | commit full chunk | — | 高效 |

#### 3.3.2 阈值校准

- **自信阈值 \(\tau_c\)**：在 held-out 正常演示上，选择 \(\tau_c\) 使 verify 触发率 ≤5%；同时要求被触发的样本中失败比例显著高于基线（ enriched failure rate）。
- **惊讶阈值 \(\tau_s\)**：用正常演示做负例、官方 human 备注扰动做正例；选择阈值使 FPR≤5%、召回≥80%；按任务/步骤分组（group-conditional conformal）。
- **挫败阈值 \(\tau_f\)**：用演示的步骤时长分布，取 95 分位；超过即“异常慢”。
- **风险控制**：用 conformal risk control 给“误报率”一个有限样本保证；如果分布漂移（背景/位置轴），用分组校准/更保守的分位数。

#### 3.3.3 为什么用规则而不是再学一个策略

- 单模型合规：规则是确定性代码，不是第二个模型。
- 可解释/可审计：每个干预都有明确的触发条件与预算。
- 数据效率：33k 成功演示不足以训练一个可靠的恢复策略；规则+校准更稳。
- 可回退：任何阈值都可以在调试槽里单独 A/B。

### 3.4 单模型合规：两条路

| 版本 | 学习组件 | 合规性 | 性能 | 适用 |
|---|---|---|---|---|
| Full | WLA + 未来预测头 + 进度头（同一 checkpoint） | 高（一个 checkpoint） | 最好 | 规则允许辅助头 |
| Minimal | WLA only；c 用采样离散度，s 用本体残差，f 用 SSG | 最高（训练无关） | 稍低 | 规则严格/审计保守 |

**披露**：模型卡写清“唯一学习模型是 WLA checkpoint；辅助头属于同一 checkpoint；A3 仲裁器/校准表是确定性代码/统计表；无外部数据”。如果官方认定辅助头是第二个模型，切 Minimal。

### 3.5 ATTS：选择性测试时 scaling

只在 `verify` 触发时做：

1. 采样 \(N=4\) 个 action chunks；
2. 对每个候选，用未来预测头想象 0.5–1s 的结果；
3. 评分：
   \[
   J(a^{(i)})=\hat{p}_{\text{progress}}(z_t,a^{(i)})-\lambda\,\hat{s}(z_t,a^{(i)})-\mu\,\|a^{(i)}-a^{(0)}\|_2,
   \]
   第一项鼓励进度，第二项惩罚预测惊讶，第三项防止离先验太远；
4. 选最高分，执行**短前缀**（如前 5–10 步），然后重观测；
5. 若所有候选都低分，转 `replan`。

**为什么不是 always-on**：always-on 的 best-of-N 会把延迟和算力拉爆；GeoBoN（[R24]）显示“只在初始 rollout 不一致时触发”可回收大部分增益，只多花 26.2% 的决策点。A3 的 \(c_t/s_t\) 就是那个 gate。

### 3.6 与 SSG/PGL/OPT/ICR/SVL/NRB 的接线

| A3 动作 | 调用 | 输入 | 输出 |
|---|---|---|---|
| commit | WLA | obs/language | action chunk |
| verify | ATTS + SVL | 候选 chunk、锚点、谓词 | 选中的短前缀/稳定性 |
| retry | OPT + PGL + SVL | 容器系释放位姿、锚点 | 重执行放置 |
| regrasp | PGL + 抓取先验 | 物体位姿、夹爪状态 | 重抓 |
| replan | ICR + NRB | 步骤/相位/关系键 | 检索段/恢复动作 |
| yield | 无 | 外部归因 | 等待/重定位 |
| reset-step | SSG | 谓词 1→0 | 回退步骤状态 |

**SVL 的新定位**：不再是“每个放置都跑固定闭环”，而是 A3 的 `verify` 动作；自信高时跳过，自信低/终局时触发。这样既保留第 7 轮的落点闭环，又避免它对所有 episode 都加时间。

### 3.7 PNMR：平台化运行时

```text
Evaluator ──WS/msgpack──► Port 8765 ─┐
                          Port 8766 ─┼─► 轻量 endpoint（每端口状态隔离）
                          Port 8767 ─┘        │
                                              ▼
                                    共享推理后端（WLA + 头）
                                    ├─ 动态 batching
                                    ├─ 每请求 episode 状态
                                    ├─ A3 仲裁器
                                    ├─ 180s 时间守卫
                                    └─ 延迟/动作规整性日志
```

- **N 端口**：从 8765 起连续 N 个；每端口独立 `reset()`/历史；不能共享 episode 状态。
- **共享后端**：N 个轻量 endpoint 转发到同一模型；动态 batching 提高吞吐；每请求带 `episode_id` 做状态隔离。
- **时间守卫**：每 episode 记录开始时间；剩余 <20s 时只 commit；剩余 <5s 时输出保持动作，避免 timeout 前的剧烈动作。
- **延迟**：目标 p50 <50ms、p99 <200ms（不含网络）；若 base 6B 单卡不够，用多卡/多进程；N 未知，按 N≤8 设计。
- **规整性**：动作裁剪、限幅、平滑；避免 NaN/极端值；日志记录每步延迟与动作统计，便于审计。
- **部署**：Docker 镜像；模型权重本地加载；token 双处校验；健康检查。

## 4. 演示数据引擎（DNL：Demo Normalcy Library）

### 4.1 正常性先验

**目标**：学习“在正常执行下，动作应该导致什么未来”。

- 输入：VLM 特征 \(z_t\)（冻结）、EE 位姿/夹爪、动作 chunk；
- 输出：未来 0.5s/1s 的 EE 位姿（6D）+ 任务相关物体关键点（可选）；
- 训练：33k 演示；按 episode 90/10 划分；5Hz 采样（每 6 帧）；L1/L2 + 平滑损失；
- 结构：4 层 transformer（hidden 512）+ MLP；<50M 参数；
- 推理：每 chunk 一次；与 base 共享 VLM 特征，不重复编码。

**为什么不是像素世界模型**：

- 像素重建在背景/光照轴上不稳定，且算力大；
- EE/物体状态的残差更接近“任务相关”，对背景轴更鲁棒；
- 单模型/低延迟约束下，轻量状态预测比视频生成更实际。

### 4.2 进度先验

- 官方 `score_steps` 给出步骤顺序与分值；
- 演示是成功轨迹；用 EE/物体轨迹的 change-point + 语言步骤文本对齐，得到帧级步骤标签；
- 训练进度头：输入 \(z_t\)，输出步骤索引（ordinal）与剩余时间；
- 运行时用谓词确认完成；谓词 1→0 触发回归。

**标签噪声的处理**：

- 用 soft label/ordinal loss；
- 用多个 change-point 检测器投票；
- 只要求“步骤边界附近”的准确率，不要求每帧精确；
- 人工抽检 32 任务 × 10 段，校准标签质量。

### 4.3 恢复矿：从成功演示里挖“微恢复”

成功演示不是“完美直线”；里面常有：

- EE 速度降到 0 后重新接近（pause→re-approach）；
- 夹爪反复开合（regrasp）；
- 放置后轻推/微调（nudge）；
- 物体滑落后重新抓（slip-recover）。

**挖掘方法**：

1. 计算 EE 速度/加速度；检测 \(v<\epsilon\) 持续 >0.2s，随后方向反转；
2. 检测夹爪开合周期（同一物体附近 ≥2 次）；
3. 检测物体位姿的小幅修正（放置后 0.5s 内的 nudge）；
4. 提取 ±1s 窗口，标为“recovery”，存入恢复库；
5. 用这些段训练/检索 `replan` 的先验，或作为 few-shot 恢复示例。

**价值**：不需要真实失败数据；成功演示里的“微恢复”就是天然的恢复正例。这比合成失败更接近真实分布。

### 4.4 官方 human 备注 → 64 个扰动脚本

官方每个任务有 `human_1_note`/`human_4_note`（T27/T10 本轮复核；其余沿用第 7 轮）。它们大多是“对某物体做一次 1-DOF 平移”或“在某步完成后撤销”：

| 任务 | human_1 | human_4 | 场景化 |
|---|---|---|---|
| T27 | 粉色碗向下移动 | 叠了第二个之后拿下第二个 | Δz 平移；移除 bowl2 |
| T10 | 抓插头前移动 | 将插头拔起 | 平移插头；拔出 |
| T19 | 包向左移动 | 拉上拉链之后拉开 | 平移；反向闭合 |
| T14 | 拧开盖子后拧回 | 瓶子向左移动 | 反向旋转；平移 |
| T17 | 荧光笔向后 | 笔盒合上后手动打开 | 平移；反向闭合 |
| T24 | 可乐快到了放回起点 | 薯片快到了放回起点 | 移动运动目标 |
| T12 | 锁向左移动 | 中途把锁拿走 | 平移；移除 |
| T02/T04/T11/T25 | 移动水果/盘子/底座 | 移动水果/底座 | 平移 |

**用途**：

- 校准惊讶阈值（正例）；
- 构造恢复对（训练/检索）；
- 在调试槽里按官方剧本做 A/B；
- 与评测的人为干扰轴 2 次/任务一一对应（假设备注就是剧本；编号含义未核实）。

### 4.5 校准集与 conformal

- **正常集**：held-out 演示（按 episode 划分）。
- **扰动集**：64 个官方备注脚本 + 随机平移/撤销/遮挡。
- **分组**：按任务、步骤、泛化轴（位置/背景/干扰物/未见物品/人为）分组校准。
- **指标**：FPR（正常集误报）、召回（扰动集）、检测延迟、ECE/Brier（自信）。
- **阈值**：group-conditional conformal；目标 FPR≤5%、召回≥80%；若某组样本不足，回退到任务级/全局阈值并降级该组的干预。

**重要**：conformal 的 exchangeability 在 OOD 下不严格成立；所以我们用它做“保守阈值”，不做“保证”。调试槽的真实数据要用来重新校准。

## 6. 评测协议

### 6.1 离线（每天）

| 指标 | 目标 | 说明 |
|---|---:|---|
| 自信 ECE | <0.10 | 校准后的步骤成功率 |
| 自信 Brier | <0.15 | 概率预测 |
| 惊讶 AUROC | >0.75 | 正常 vs 官方备注扰动 |
| 惊讶 FPR@95TPR | <0.10 | 误报 |
| 进度 F1 | >0.80 | 步骤分类 |
| 终局成功预测 AUROC | >0.75 | 终局 self-efficacy |
| 未来 EE 误差 | <2cm | 0.5–1s 预测 |

### 6.2 本地/回放（每周）

- **TCLB 降级为离线相对比较台**：用 held-out 演示 + 扰动做开环/短闭环回放，只做失败挖掘，不做模型选择。
- **恢复回放**：在演示的扰动注入点，比较 A3 的 `replan` 选择与人工恢复段；命中率/时间。
- **误报回放**：在正常演示上跑 A3，统计干预率；目标 ≤5%。

### 6.3 平台调试槽（版本门）

官方 profile 页提供不计分单任务调试（[R8] 第 7 轮来源；本轮未重抓，标注沿用）。约定：

- 每个大版本最多 1 个调试槽；
- 任务选择：T27（堆叠/终局）、T10（插入/力控）、T19（拉链/闭合）、T24（传送带/人为干扰）；
- 每个任务 10–20 个 episode；A/B：base vs A3；
- 判定：终局步 +10pp、人类轴恢复 ≥30%、误报 ≤5%、无任务回归 >5pp；
- 不达标 → 回退阈值/关闭对应动作，不带着问题进计分跑。

### 6.4 计分跑

- 计划 2 次：W7 中期、W8 终期；若只能 1 次，W8 唯一一次。
- 提交前 4h soak：N 端口并发、状态隔离、延迟 p99、动作规整性、健康检查。
- 指标：总成功率（主）、步骤分（tie-break）、每任务成功率、五轴分轴成功率、平均时长、超时率、干预率/恢复率。
- 统计：320 trials；p=0.25 时 SE≈2.4pp；目标 +5pp；用 per-task 配对/bucket bootstrap；CI 跨 0 不上线。

### 6.5 实验矩阵

| ID | 配置 | 验证 | Go/No-Go |
|---|---|---|---|
| E0 | WLA 微调基线 | 复现 | 可用 |
| E1 | +自信 only | verify 触发/成功率 | +1pp，误报≤5% |
| E2 | +惊讶 only | 人类轴检测/恢复 | AUROC>0.75 |
| E3 | +挫败 only | 长程/卡住恢复 | +1pp |
| E4 | A3 full | 成功率/时间 | +3pp |
| E5 | E4+ATTS | best-of-N 增益/延迟 | +1pp，p99<200ms |
| E6 | E4+DNL-R | 人类轴恢复 | +3pp |
| E7 | E4+PNMR | 并发/稳定性 | 无回归 |
| E8 | Minimal（训练无关） | 合规兜底 | 不低于 E4−2pp |

### 6.6 消融

- 自信/惊讶/挫败单独 vs 组合；
- 动作条件 vs observation-only 惊讶（验证外部/内部归因）；
- 分组 conformal vs 全局；
- 官方备注扰动 vs 随机扰动；
- verify 安全版 vs retry 风险版；
- ATTS N=2/4/8；
- Full vs Minimal；
- 未来头预测 EE vs 物体关键点 vs latent。

- **可行性**：33k 演示；change-point/速度/夹爪事件；小头 <50M。
- **资源**：1–2 天头训练；1 周挖掘/校准；无新硬件。
- **步骤**：划分 → 未来头 → 进度标签 → 恢复矿 → conformal。
- **风险**：步骤标签噪声/恢复矿误检 → soft label/多检测器投票。
- **状态**：主押注支持件。

### I16 ATTS 情感驱动测试时 scaling（新增）
- **动机**：test-time compute 有增益，但 always-on 太慢；用 c/s 做 gate。
- **差异**：只在低自信/高惊讶时采样 N=4；用同一模型的进度/惊讶头选择；短前缀执行。
- **可行性**：flow head 可采样；1s chunk；180s；p99 目标 <200ms。
- **资源**：GPU 采样；无新数据；运行时。
- **步骤**：采样 → 评分 → 选择 → 短前缀 → 重观测。
- **风险**：选择错误/延迟饱和 → N≤4，门控。
- **状态**：新增。

### I17 PNMR 平台化元认知运行时（新增）
- **动机**：N 端口/状态隔离/180s/延迟/规整性是硬约束；部署也是评分的一部分。
- **差异**：policy-agnostic；包 WLA/π0.5/GR00T；单模型合规；统一观测/动作/校准/日志。
- **可行性**：Python/WebSocket/msgpack；共享后端；动态 batching；Docker。
- **资源**：N 卡或共享 GPU；1 工程师 2 周。
- **步骤**：wrapper → 每端口状态 → 共享后端 → soak → 调试槽。
- **风险**：并发/显存/延迟 → 压测/限流。
- **状态**：工程主件。

### I18 HIA 人为干扰意图预判（新增，探索）
- **动机**：人类轴 20%；若能在人动手前预判，可提前让行/保护物体。
- **差异**：从“事后检测”升级为“意图/轨迹预判”；用官方备注 + 合成人/公开数据。
- **可行性**：低——演示无人类；相机未必看到人；域差大。
- **资源**：合成人/公开视频；GPU；2–3 周。
- **步骤**：合成/采集 → 意图分类 → 早期预警 → 调试槽。
- **风险**：无数据/隐私/误报；收益可能不如事后恢复。
- **状态**：探索，非主线。

### I19 RTC reset 时平台校准（新增）
- **动机**：背景/位置 OOD；相机/桌面/延迟差异；空间 grounding。
- **差异**：用演示标定相机/桌面；reset 时用首帧估计平面/外参；归一化观测；不新增模型。
- **可行性**：高；4 相机 + EE 位姿；OpenCV。
- **资源**：CPU；1 周；无新数据。
- **步骤**：演示标定 → reset 估计 → 归一化 → 背景/位置轴评估。
- **风险**：遮挡/标定失败 → 回退默认。
- **状态**：工程支持。

### I20 WLA-M 单 checkpoint 多头微调（新增，底座）
- **动机**：官方 6B 是最强起点；单模型规则；24GB 可微调。
- **差异**：冻结 VLM，action expert + 进度/未来头同 checkpoint；不是新 base。
- **可行性**：官方代码/配置；33k 数据；LoRA。
- **资源**：8×H100 2–3 周或 24GB 4–6 周。
- **步骤**：基线 → 微调 → 头 → 评估。
- **风险**：过拟合/遗忘/算力。
- **状态**：底座，必须。

## 12. 一句话押注

**本轮最值得押注：在 WLA 单模型上做「内生元认知控制（A3）」——用动作采样离散度、动作条件未来预测误差、步骤停滞三个可校准信号，决定何时提交、验证、重试、重抓或让行；它不引入第二个模型、不依赖外部数据，直接提高成功率（步骤分只是加赛），并把人类干扰轴变成可检测、可恢复的事件。**
