# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化证据承诺」IP-133~138；灵感驱动研究循环第 2 轮；本轮灵感：「数据集」×「模型预测控制」）

> 第 57 轮把"当前该不该承诺"做成了元认知问题：MFSL 摊销先验、XMC 跨模态对账、PTM 个性化信任，证据门 FSE 只在"此刻"的证据上判定。但它默认了一个更深的假设：**用于前视规划的控制模型是可信的**。MPC 每个节拍都要把当前状态沿 H 步向前推演；第 57 轮的 OOD 门只检查"此刻的观测是否像语料"，共形带只包住"此刻的参数后验"，没有任何机制保证**这 H 步预测管本身落在数据支撑内**。于是出现一个跨轮接缝：**(a)** 数据只被当作信念的证据，没有被当作**控制模型的定义域**——模型在无数据区外推时，MPC 会以"数学上可行"的轨迹穿过"认识论上不存在"的世界；**(b)** 数据集是外生给定的历史语料，而 MPC 在部署中不断产生新数据——**预测控制既是数据集的消费者，也是数据集的作者**，闭环把安全与学习焊在一起；**(c)** 安全策略天然回避未覆盖区域，于是永远不去采集那里的数据，覆盖债务只增不减，最终系统"越来越确信一个越来越窄的世界"。本轮把「数据集」从静态语料升级为**带出处、覆盖、时效与归因的活账本**，把「模型预测控制」从名义模型优化升级为**数据认证的鲁棒前视**：每个候选计划必须携带"整条预测管都在数据支撑内（或按带内最坏模型优化）"的证书；信息增益只能作为**安全可行集内的排序项**，永远不能扩大可行集；探索以有界风险的"数据远航"显式调度。核心命题由"证据说可信"升级为 **"前视可覆盖、数据可归因、探索有预算"**。

核心矛盾：
- **H33（前视 vs 外推）**：MPC 需要 H 步预测，而数据只认证已观测支撑；一步共形区间在 H 步上会严重低估误差累积，"每步都 95% 覆盖"绝不等于"整条预测管 95% 覆盖"。
- **H34（安全 vs 学习）**：最安全的策略是只走已覆盖区域，但这样永远不会产生新覆盖；要学习就必须进入未覆盖区，而进入未覆盖区正是安全约束要禁止的事——这是一个没有免费解的覆盖率-安全性悖论。
- **H35（内生数据 vs 自证）**：MPC 自己产生的数据与它自己的模型强相关；只用闭环数据再训练，会把"模型以为的世界"固化成"数据证明的世界"，形成自证偏差。
- **H36（数据规模 vs 数据质量）**：更多数据不等于更安全；陈旧、相关、被污染或配比失衡的数据会制造**自信的错误覆盖**。数据集的安全属性是"覆盖×出处×时效×可归因"，不是"条数"。

## 0. 直觉与动机

**灵感 1（数据集 → 覆盖账本而不是数据堆）**
直觉：一份数据集真正的安全属性不是"有多少帧"，而是"在部署会遇到的状态-动作-上下文空间里，哪些地方它见过、见得新不新、是谁给的、错了能不能追责"。于是把每个数据点记成 (z_i,y_i,π_i,t_i,ω_i)：z_i 是地形/状态/动作/上下文描述子，π_i 是出处，t_i 是采集时间，ω_i 是信任权重；由它们诱导一个**覆盖度 κ(z)** 与有效性区域 𝒱_κ。数据集从"训练素材"变成"模型的定义域地图"：模型在 𝒱_κ 内是数据支撑的，在 𝒱_κ 外只是外推。再定义**数据债务** D_cov：部署相关上下文里未被覆盖的质量占比。要审计的不是数据规模，而是覆盖、时效、出处与配比。

**灵感 2（模型预测控制 → 前视即承诺）**
直觉：MPC 的本质不是"算一条轨迹"，而是"用一个模型对 H 步未来做承诺"。因此安全的单位不是单点预测，而是**预测管**：名义轨迹外加分层多步共形残差。第 57 轮已有一阶共形思想，但"每步 1−α 覆盖"经 H 步联合后覆盖率会崩到 1−Hα 量级；必须按 horizon 分层校准，并让管在数据覆盖域内才可承诺。模型本身也不该是一个点估计，而应是**与数据一致的模型集 ℱ_κ**：在其上做最坏情况优化（鲁棒 MPC），而不是拿均值模型赌未来。

**灵感 3（合流 → 数据认证的预测控制 DPG）**
直觉：把灵感 1 与 2 相乘，得到本轮的核心不变式——**前视覆盖不变式**：任一被承诺执行的控制序列 π，其预测管 ∪_k 𝒯_k 必须落在有效性区域 𝒱_κ 内，且 π 在模型集 ℱ_κ 上鲁棒可行；否则只能执行保守回退（H=1/降档/停车），或先做一次有界风险的数据远航。这把"覆盖"从数据集属性变成**控制级硬约束**：模型可以在没有数据的地方做梦，但机器人不可以在那里承诺。

**灵感 4（学习悖论 → 信息导向 MPC + 数据远航）**
直觉：安全策略不探索 ⇒ 覆盖债务只增；但盲目探索又会把风险拉满。解不是"允许探索"，而是把探索做成**安全可行集内的一次显式经济交换**：ID-MPC 的代价里加一项信息增益，但只用来在已通过 PCC 的可行计划之间排序；L2 不可逆接触禁止任何信息项（λ_info=0）；覆盖债务超过阈值时，调度一次**数据远航**——目标为信息增益、终点必须可逆、最坏风险 ≤ρ_sortie、每次只把覆盖前沿推进一个"桥接半径"，桥接误差由 Lipschitz 界与共形残差共同兜底，桥接证书失败就立即返回。

**灵感 5（数据中毒 → 归因、隔离与退役）**
直觉：既然数据决定模型，坏数据的破坏力就等价于坏模型。第 57 轮已让"模态"可按事后证伪回溯降权；本轮把同一逻辑下沉到**单个数据点**：用影响函数/留一法把一次预测违背归因到最相关的数据，只有在**独立证据**（另一模态、另一区域或延迟真值）也指向它时才降权，低于阈值则退役并重算模型；若影响数据分散且随时间聚集，则判为分布漂移而非数据错误，触发覆盖重估而不是乱杀数据。负样本账本保留被退役的数据与理由，供后续审计与复原。

**灵感 6（给第 57 轮打补丁 → 第六类证据与 PCE+++）**
直觉：新增证据类 **EV-plan**（计划级证据，仅限 L1 可逆接触），必须携带 PCC、鲁棒界与信息预算；不可逆接触的必要证据集仍只认 EV-probe*/EV-margin 与人工佐证，绝不允许"计划看起来可行"顶替实证。PCE+ 升级为 PCE+++：每检查点先查覆盖与时效，再构造模型集，再做元推断/跨模态对账，再用 ID-MPC 选计划，最后过证据门；承诺、数据远航、绕行、降档、L2 协商、安全停六态完备。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（数据覆盖账本 DCL）** 数据集账本 ℒ_D={(z_i,y_i,π_i,t_i,ω_i)}_{i=1}^N，描述子 z_i=(地形特征,状态,动作,上下文)；信任权重 ω_i(t)=ω_i^0·exp(−(t−t_i)/τ_fresh)·m_i，m_i 为漂移/证伪乘子。覆盖度 κ(z)=max_i ω_i·K_h(z−z_i)（核式）或基于 k-NN 距离的保守分位数。有效性区域 𝒱_κ={z:κ(z)≥κ_0}。数据债务 D_cov(C)=∫_C rel(z)·1[κ(z)<κ_0]dz / ∫_C rel(z)dz，rel 为部署上下文相关质量。覆盖更新只在**独立验证**（非自采集、或延迟真值）后生效；自采集数据带 endogenous 标记与初始低权 ω_self。

**定义 140（前视共形管 HOT 与计划覆盖证书 PCC）** 多步残差校准集按 horizon k 分层，q_{k,1−α} 为加权共形分位数（分布漂移时按时间衰减加权）。名义管 𝒯_k={x:‖Σ_k^{-1/2}(x−x̂_k)‖≤q_{k,1−α}}。计划 π=(u_{0:H−1}) 的覆盖证书：
PCC(π)=1 ⇔ ∀k≤H, tube(𝒯_k)⊆𝒱_κ ∧ robust_feasible(π,ℱ_κ)。
歧义模型集 ℱ_κ={f: f 在 ℒ_D 上的残差落在共形带内}；鲁棒规划
min_π max_{f∈ℱ_κ} J_H(π;f) s.t. 约束 ∀f∈ℱ_κ。
**前视覆盖不变式**：任何被承诺执行的 π 必须 PCC(π)=1；无证书者只许进入保守回退集合 Π_fb={H=1, 降档, 停车}，且不得接触 L2。

**定义 141（信息导向预测控制 ID-MPC）** 代价
J_H^info(π)=max_{f∈ℱ_κ} E[Σ_{k=0}^{H−1}ℓ(x_k,u_k)] − λ_info·IG(π|ℒ_D) + λ_term·V_f(x_H)，
IG=H(Θ|ℒ_D)−E_{y|π}[H(Θ|ℒ_D∪{(π,y)})]，用集成方差或 Fisher 信息近似。安全屏蔽：π∈Π_safe(PCC, 鲁棒约束)；contact_level(π)=L2 ⇒ λ_info=0；每个检查点/远航信息预算 B_info；若 π 的最坏风险高于保守基线，即使 IG 再大也拒绝排序入内。自采集样本进入账本时标注 π_i='self' 且 ω_i≤ω_self，须独立佐证方可升权。

**定义 142（数据归因与退役 DAR）** 失败/近失事件 e 后，数据影响度 A_i(e)=∂ℓ_e/∂ω_i 或用影响函数近似；取 top-k 高影响数据。降权条件：独立证据 corroborate(top-k, e)（另一模态/另一区域/延迟真值）∧ 影响度集中。更新 ω_i←γ_ret·ω_i；ω_i<ω_min 则退役并重算模型集 ℱ_κ。若 top-k 分散且随时间在邻域聚集，则判为分布漂移，触发 DCL 重估与覆盖重标定，而非退役。负样本账本 ℒ_neg 记录退役数据、理由与可复原句柄。

**定义 143（覆盖债务突围 CSB）** 当 D_cov>θ_debt，或预测未来任务上下文将越过 𝒱_κ 时，调度数据远航 π_s：目标为最大化相关质量下的信息增益；约束 worst_case_risk(π_s)≤ρ_sortie、终点为可逆安全态、全程禁 L2、信息预算 ≤B_info。前沿桥接：每次只把覆盖前沿推进 r_bridge，桥接段预测误差须同时满足 Lipschitz 界 L_f·r_bridge 与共形残差 q_{1−α}；桥接证书失败 ⇒ 立即返回并标记 frontier blocked。每次远航要么使 D_cov 下降 ≥Δ，要么显式声明该区域不可达/不值得覆盖。

**定义 144（数据认证控制门 DPG 与证书 J_d）** 证据类新增 **EV-plan**（计划级证据，仅 L1 可逆；须挂 PCC ∧ 鲁棒界 ∧ 信息预算 ∧ 非 L2）；不可逆接触必要证据集仍为 {EV-probe*∨EV-margin}∪人工佐证，**不含 EV-plan 与 EV-xmodal**。PCE+++ 每检查点顺序：⓪覆盖/时效查询（κ,D_cov）→①构造 ℱ_κ→②第 57 轮元推断与共形保底→③跨模态对账/共识探针→④ID-MPC（PCC+信息预算）→⑤证据门（含 EV-plan 校验）→承诺/远航/绕行/降档/L2/安全停。J_d=(J_p, data_ledger, coverage_map, model_version, residual_cal, attribution_log, quarantine_log, sortie_log, plan_cert_log)，继承 J_p 全检。

## 2. 关键算法伪代码（完整版见产物区）

```python
def coverage(ledger, z, t):
    return max(w(rec, t) * kernel(z, rec.z) for rec in ledger)   # 保守核

def plan_covered(pi, x0, F_kappa, ledger, alpha, H):
    for k in range(1, H + 1):
        tube = conformal_tube(F_kappa, x0, pi, k, alpha)         # 分层多步
        if not subset(tube, valid_region(ledger)):               # 前视覆盖不变式
            return False
    return robust_feasible(pi, F_kappa)                          # 最坏模型可行

def id_mpc(x0, ledger, task, budget):
    cands = admissible_plans(task)
    safe = [p for p in cands
            if plan_covered(p, x0, model_set(ledger), ledger, ALPHA, H)
            and robust_risk(p) <= budget.rho]
    if not safe:
        return conservative_fallback(x0)                         # H=1/降档/停车
    return max(safe, key=lambda p: task_value(p)
               - (0 if contact_level(p) == 'L2'
                  else budget.lam_info * info_gain(p, ledger)))
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| DCL | O(N) 建账；O(log N) 查询 | O(N) | κ 保守、时效/漂移诚实、自采集低权 |
| HOT | O(H·C_cal) 校准；O(H·n³)/计划 | O(H·n_x) | 分层共形覆盖、管保守、漂移权重 |
| ID-MPC | O(H·\|ℱ_κ\|·(C_mpc+C_ig)) | O(H·\|ℱ_κ\|) | 信息项只在 Π_safe 内排序 |
| DAR | O(N·d)/归因（k-NN 近似） | O(N) | 独立佐证后才退役、漂移与数据错分离 |
| CSB | O(\|frontier\|·H) | O(\|frontier\|) | 桥接界、风险有界、终点可逆、禁 L2 |
| DPG | O(\|σ\|·H) | O(\|σ\|) | 无 PCC 不承诺、EV-plan 限 L1 |

**正确性定理（DCPC, Data-Certified Predictive Control soundness 概要）**：在第 57 轮 A33–A40 上加 (A41) 覆盖诚实（κ 为保守下界、D_cov 按相关质量加权、时效与漂移检测诚实）；(A42) 前视共形有效（分层多步残差在交换性/加权交换性下覆盖 ≥1−α）；(A43) 探索有界（信息项不扩大 Π_safe、L2 的 λ_info=0、远航最坏风险 ≤ρ_sortie 且终点可逆）；(A44) 归因诚实（退役需独立佐证、模型重算可复现、污染数据不入评估）。则：
(i) 计划健全性：PCC(π)=1 时实际违反率 ≤δ_tube(H)+δ_data+δ_model+δ_f；朴素一步共形不在保证内；
(ii) 覆盖硬阻断：无 PCC 的计划不得越过保守回退，"数据未覆盖区的乐观外推"不能进入不可逆承诺；
(iii) 探索单调性：信息项只改变 Π_safe 内排序，不扩大 Π_safe；远航风险有界，故探索不抬高最坏风险上界，只可能缩小 ℱ_κ；
(iv) 债务不静默：相关未覆盖质量可达且存在合法远航时，每次远航使 D_cov 下降 ≥Δ，否则系统显式收缩任务包络——禁止"假装覆盖"；
(v) PCE+++ 在 H、探针预算、信息预算与远航次数有界时终止于六态之一。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 覆盖被高估（相关/污染/自证） | 高 | 保守核 κ + 独立数据保持 + 自采集低权 + 归因审计 |
| 多步共形在分布漂移下失效 | 高 | 分层加权共形 + 漂移检测 + 管长自动缩回 |
| 探索越界 → 把学习变成冒险 | 高 | 前沿桥接 + L2 禁入 + worst-case 风险上限 + 可逆终点 |
| 误杀稀有但正确的数据 | 中高 | 独立佐证 + 影响度集中判据 + 负样本账本可复原 |
| 鲁棒 MPC 计算量进入实时回路 | 中 | 采样近似 ℱ_κ + 热启动 + 可退回名义 H=1 保守控制 |
| 自证偏差固化假覆盖 | 中高 | endogenous 标记 + 独立数据配比审计 + 定期盲区探测 |

## 6. 本轮最大风险

**一句话**：本轮把安全赌注从"证据质量"移到"数据覆盖"上，最大风险是**覆盖本身被高估且自证**——若 κ 把相关、陈旧或被污染的数据算作覆盖，MPC 就会沿一条"证书齐全"的预测管自信地驶入数据集只是想象出来的世界；必须以保守覆盖、独立数据保持、数据归因退役与有界风险远航四重护栏，让"没有覆盖"永远等价于"没有承诺"，而不是"模型觉得没问题"。

# 第 58 轮产物 · 创新点清单 v34：Data-Certified MPC（数据覆盖账本×前视共形管×信息导向预测控制，DCL×HOT×ID-MPC×DAR×CSB×DPG）

## 2. 关键算法伪代码

### IP-139 DCL（数据覆盖账本）

```python
def w(rec, t):
    return rec.w0 * exp(-(t - rec.t) / TAU_FRESH) * rec.m   # 时效×漂移/证伪乘子

def coverage(ledger, z, t):
    return max(w(rec, t) * kernel(z, rec.z) for rec in ledger)  # 保守核

def valid_region(ledger, t):
    return {z: coverage(ledger, z, t) >= KAPPA_0}

def data_debt(ledger, ctx_dist, t):
    num = integral(ctx_dist(z) * (1 if coverage(ledger, z, t) < KAPPA_0 else 0))
    den = integral(ctx_dist(z))
    return num / (den + 1e-12)

def admit_new_data(ledger, rec, independent):
    rec.w0 = W_SELF if rec.provenance == 'self' else W_INDEP
    if rec.provenance == 'self' and not independent:
        rec.m = self_confirm_discount(rec)          # 自采集先降权
    ledger.insert(rec); return ledger
```

### IP-140 HOT（前视共形管与计划覆盖证书）

```python
def conformal_tube(F_kappa, x0, pi, k, alpha):
    preds = [f.rollout(x0, pi, k) for f in F_kappa]
    xhat  = mean(preds)
    q     = conformal_quantile(RES_CAL[k], alpha, weights=time_weights(k))
    return {x: mahalanobis(x, xhat, SIGMA[k]) <= q}

def plan_covered(pi, x0, F_kappa, ledger, alpha, H):
    for k in range(1, H + 1):
        tube = conformal_tube(F_kappa, x0, pi, k, alpha)
        if not subset(tube, valid_region(ledger, now())):   # 前视覆盖不变式
            return False
    return robust_feasible(pi, F_kappa)                     # 最坏模型可行

def robust_plan(x0, task, F_kappa, ledger, H):
    cands = admissible_plans(task, x0)
    ok = [p for p in cands if plan_covered(p, x0, F_kappa, ledger, ALPHA, H)]
    if not ok:
        return fallback(x0)                                 # H=1/降档/停车
    return min(ok, key=lambda p: max(f.cost(p) for f in F_kappa))
```

### IP-141 ID-MPC（信息导向预测控制）

```python
def info_gain(pi, ledger):
    H0 = entropy(param_posterior(ledger))
    H1 = mean(entropy(param_posterior(ledger_with(pi, y)))
              for y in simulate_observations(pi, model_set(ledger)))
    return H0 - H1

def id_mpc(x0, ledger, task, budget):
    F = model_set(ledger)
    safe = [p for p in admissible_plans(task, x0)
            if plan_covered(p, x0, F, ledger, ALPHA, H)
            and robust_risk(p, F) <= budget.rho]
    if not safe:
        return fallback(x0)
    def score(p):
        info = 0.0 if contact_level(p) == 'L2' else budget.lam_info * info_gain(p, ledger)
        return task_value(p, F) - info                    # 信息项只排序，不扩可行集
    return max(safe, key=score)

def spend_info(budget, p):
    budget.info_left -= estimate_info_cost(p)
    return budget.info_left >= 0
```

def attribute_and_retire(ledger, fail_event, independent):

### IP-143 CSB（覆盖债务突围）

```python
def coverage_sortie(x0, ledger, frontier, budget):
    if data_debt(ledger, ctx_dist) < THETA_DEBT:
        return None
    seg = frontier_step(frontier, r_bridge)                # 一次只推一个桥接半径
    pi = id_mpc(x0, ledger, goal=seg, budget=budget_with_info(LARGE, B_INFO))
    if pi is None or reaches_L2(pi): return None
    if worst_case_risk(pi) > RHO_SORTIE: return None
    if not bridge_certificate(pi, seg, L_F, q_conf(ALPHA)):
        frontier.mark_blocked(seg); return None            # 桥接失败即返回
    return pi

def bridge_certificate(pi, seg, L_f, q):
    return l_max(pi) * L_f * r_bridge + q <= DELTA_BRIDGE   # Lipschitz + 共形双兜底
```

### IP-144 DPG（数据认证控制门与证书 J_d）

```python
def data_certified_gate(c, ledger, F, budget):
    if c.ev == 'EV-plan':
        ok = c.level == 'L1' and plan_covered(c.pi, c.x0, F, ledger, ALPHA, H) \
             and robust_risk(c.pi, F) <= budget.rho \
             and c.info_spent <= budget.info_left
    elif c.ev == 'EV-probe*':
        ok = round57_probe_check(c, ledger)                # 继承第 57 轮
    elif c.ev == 'EV-xmodal':
        ok = c.level == 'L1' and round57_xmodal_check(c)
    elif c.ev == 'EV-human':
        ok = round57_human_check(c)
    elif c.ev in ('EV-visit', 'EV-margin'):
        ok = round56_checks(c)
    else:
        return ('reject', 'no_evidence_class', c)
    if not ok: return ('reject', 'evidence_insufficient', c)
    if c.irreversible and c.ev in ('EV-plan', 'EV-xmodal'):
        return ('reject', 'plan_or_xmodal_on_irreversible', c)   # 硬禁令
    return ('ok', c)

def certificate_d(sched, log, ledger, F, consent_log, auth_log, ood_reg):
    for c in contacts(sched):
        if data_certified_gate(c, ledger, F, budgets)[0] != 'ok':
            return ('reject', 'gate')
    if min(x.K_margin for x in sched) < budgets.theta_K: return ('reject', 'K_margin')
    if rho_sem(sched) < budgets.rho_min:               return ('reject', 'rho_sem')
    if not all(l2.resolved for l2 in consent_log):     return ('reject', 'consent_open')
    return ('ok', Jd(Jp_core(sched), ledger.snapshot(), coverage_map(ledger),
                     model_version(F), residual_cal(F), ledger.attribution_log,
                     ledger.quarantine_log, ledger.sortie_log, plan_cert_log(sched)))
```

### IP-138→PCE+++（探-诺-演+++：覆盖前置 × 数据远航 × 信息排序）

```python
def probe_commit_evolve_plusplus(x0, ledger, task, budget, consent, personas):
    route = plan_on_map(ledger.coverage_map(), task, risk_model)
    sched, log = [], []
    for cp in route.checkpoints:
        if coverage(ledger, cp.z, now()) < KAPPA_0:          # ⓪ 未覆盖不承诺
            s = coverage_sortie(x0, ledger, frontier(cp), budget)
            if s is None: return safe_stop(cp, 'uncovered')
            execute(s); ledger = update_ledger(ledger, s); continue
        F = model_set(ledger)                               # ① 歧义模型集
        inf = meta_few_shot_infer(M, cp.region, M.obs[cp.region], meta)  # ② 第 57 轮
        M, fused, D = xmodal_fuse(M, cp.region, observe(cp))             # ③ 对账
        pi = id_mpc(x0, ledger, task=cp.task, budget=budget)             # ④ 前视
        if pi is None: 
            alt = reroute(M, cp, risk_model)
            if alt: route = alt; continue
            return negotiate_or_stop(cp, consent, tau_int(personas.active.auth))
        if few_shot_evidence_gate(plan_contact(pi), M, personas, ood_reg)[0] == 'ok':
            sched.append(commit(pi)); log.append(tag_evidence(pi, M))
            ledger = update_ledger(ledger, executed(pi))                 # ⑤ 闭环记账
        else:
            return negotiate_or_stop(cp, consent, tau_int(personas.active.auth))
    return sched, log, ledger
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| DCL | O(N) 建账；O(log N) 查询 | O(N) | κ 保守下界、时效/漂移诚实、自采集低权（A41） |
| HOT | O(H·C_cal) 校准；O(H·n³)/计划 | O(H·n_x) | 分层多步共形覆盖 ≥1−α（A42） |
| ID-MPC | O(H·\|ℱ_κ\|·(C_mpc+C_ig)) | O(H·\|ℱ_κ\|) | 信息项只在 Π_safe 内排序（A43） |
| DAR | O(N·d)/归因（k-NN 近似） | O(N) | 独立佐证才退役、漂移/数据错分离（A44） |
| CSB | O(\|frontier\|·H) | O(\|frontier\|) | 桥接界、风险有界、终点可逆、禁 L2 |
| DPG | O(\|σ\|·H) | O(\|σ\|) | 无 PCC 不承诺、EV-plan 限 L1 |
| PCE+++ | O(\|CP\|·(H·\|ℱ_κ\|·(C_mpc+C_ig)+k_p·d_φ)) | O(\|V\|+N) | 六态完备、预算终止 |

**正确性定理（DCPC, Data-Certified Predictive Control soundness）**
假设 A22–A40（第 53–57 轮）成立；**(A41)** 覆盖诚实：κ 是真实支撑的保守下界，D_cov 按相关质量加权，时效衰减与漂移检测不隐瞒；**(A42)** 前视共形有效：分层多步残差在交换性（漂移下为加权交换性）下覆盖 ≥1−α，且管对模型集取并；**(A43)** 探索有界：信息项不扩大 Π_safe，L2 接触 λ_info=0，远航最坏风险 ≤ρ_sortie 且终点可逆，信息预算有限；**(A44)** 归因诚实：退役需独立佐证，模型重算可复现，污染数据不进入评估集。则：

1. **计划健全性**：若 PCC(π)=1，则实际约束违反率 ≤ δ_tube(H)+δ_data+δ_model+δ_f；若用朴素一步共形替代 HOT，则保证失效（k≥2 起覆盖按联合界衰减）。
2. **覆盖硬阻断**：任何无 PCC 的计划只能进入 Π_fb；因此"数据未覆盖区的乐观外推"在结构上无法进入不可逆承诺——这是硬约束，不是概率压低。
3. **探索单调性**：ID-MPC 的信息项只改变 Π_safe 内排序，不扩大 Π_safe；远航风险有界且终点可逆，故探索不抬高最坏风险上界，只可能缩小模型集 ℱ_κ（`ℱ_κ^{t+1}⊆ℱ_κ^t`，在独立数据入账时）。
4. **债务不静默**：若相关未覆盖质量可达且存在合法远航，则每次远航使 D_cov 下降 ≥Δ，否则系统显式收缩任务包络；不存在"任务照做、覆盖悄悄不增长"的第三态。
5. **终止性**：H、探针预算、信息预算与远航次数有界 ⇒ PCE+++ 终止于 {承诺, 数据远航, 绕行, 降档, L2 协商, 安全停} 六态之一。

**部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp [δ_f + δ_tube(H) + δ_data + δ_model + δ_probe + ε_h + δ_oor·α_conf]
             − P(漂移未检出) − P(归因错误退役) − P(远航越出桥接界)
```

关键：**数据给定义域、共形给前视、鲁棒给最坏情况、信息只给排序**——四件事解耦。第 57 轮解决"此刻该不该信"，本轮解决"未来 H 步该不该按这个模型承诺"；两者共享同一套证据门，但用 PCC 把"预测控制的外推"隔离在可逆层。

## 6. 本轮最大风险

**一句话**：本轮把安全赌注从"证据质量"移到"数据覆盖"上，最大风险是**覆盖本身被高估且自证**——若 κ 把相关、陈旧或被污染的数据算作覆盖，MPC 就会沿一条"证书齐全"的预测管自信地驶入数据集只是想象出来的世界；必须以保守覆盖、独立数据保持、数据归因退役与有界风险远航四重护栏，让"没有覆盖"永远等价于"没有承诺"，而不是"模型觉得没问题"。
