# 第 2 轮想法区：从「静态证书」到「在线竞争式证书」

## 直觉：两个灵感词其实指向同一件事

- **在线学习**：v23 的 FSVC 是「一次性 K-shot 校准 + 静态 conformal 覆盖」。但部署是无限长的非平稳流，交换性（exchangeability）假设必然破裂。在线学习——尤其是自适应 conformal 推断（ACI）——告诉我们：不需要假设分布不变，只要让显著性水平 `α_t` 随「覆盖债务」反馈更新，就能得到「长程平均覆盖 → 1-α」的保证，且对漂移、甚至对抗序列仍成立（误差 O(1/(γT))）。这把 conformal 从「统计检验」升级为「反馈控制器」。
- **比赛策略**：v23 的版本切换是「固定 200ms 双轨 + 单一 pending 版本」，像一场固定圈速的计时赛。真实部署更像多车竞速：旧版本、新版本、多个 IP-safe 变体同时在「排行榜」上竞争，路况（分布）在变，何时「进站」（切换）应由证据而非固定计时决定。赛车里的排位赛 / 淘汰赛 / 保胎 / 安全车，分别对应影子评估 / 逐轮筛选 / 保守策略 / 云端断联冻结。

## 核心命题

把证书从「一次性静态证明」升级为「持续在线、可竞争、带遗憾界」的动态证明：

**在线竞争式证书（Online Competitive Certification, OCC）**
= 在线覆盖控制器（保证时间维度上覆盖不漂移）
+ 无遗憾证书锦标赛（保证在可行专家集合内渐近最优）
+ 竞速式原子切换（把固定窗口换成证据驱动的进站决策）
+ 策略防操纵排行榜（防止专家通过刷榜绕过安全约束）。

一句话：v23 证明了「此刻可信」，v24 要证明「持续可信、越跑越准、切换不翻车」。

## 关键洞察（值得单独记下）

1. **覆盖债务就是 PID 误差**。定义 `D_t = Σ_s (err_s - α*)`。`D_t > 0` 表示长期欠覆盖，应收紧 `α_t`（预测集变大 → 更保守）；`D_t < 0` 表示过保守，可放松。更新式 `α_{t+1} = Π(α_t + γ(α* - err_t))` 恰好使 `Σ(err_t - α*) = (α_1 - α_{T+1})/γ` 被 `O(1/γ)` 夹住，于是平均覆盖误差 `O(1/(γT))` 自动消失——这是本方案最重要的理论抓手。
2. **无遗憾 ≠ 安全**。必须把「硬证书可行域」作为掩码，只在可行专家上做 EXP3；可行集为空时安全停车（safe-stop），而不是让「低损失但违规」的专家获胜。安全是约束，不是损失项。
3. **竞争的同质化是新型失效**。若排行榜上的专家共享同一骨干 / 同一校准集，其错误高度相关；此时「多数票」与「低 regret」会同时被系统性偏差欺骗。需要专家去相关（diversity bonus / DPP 采样）与策略防操纵（proper scoring rule）。
4. **竞速式切换天然消解 v23 的 R1**。旧版本永远留在赛道上；云端断联 = 安全车出动（冻结比赛、继续用旧版本）。不再有「旧模型覆盖失效 + 新模型无法验证 + 回滚无可用版本」的三重失效。
5. **切换是「进站」而非「换车」**。进站有成本（窗口风险、能耗、任务中断），所以最优策略不是「挑战者一领先就换」，而是「挑战者的置信下界显著超过旧版本置信上界」才换——这正是 sequential racing / SPRT 的决策逻辑。

## 严谨定义的草图

- 在线覆盖：`Coverage_online(T) = 1 - (1/T)Σ err_t`，要求 `liminf_T Coverage_online(T) ≥ 1-α*`，且对任意（含对抗）序列成立。
- 可行专家：`e ∈ Feasible_t ⟺ HPC-E+(e, certs_t) = True`，其中可行性是硬布尔掩码。
- 竞争选择：`π_t = argmin_{e∈Feasible_t} UCB_e(t)`；若 `Feasible_t = ∅` 则输出 `SAFE_STOP`。
- 性能遗憾：`R_T = Σ_t ℓ_t^perf(π_t) - min_{e∈Feasible} Σ_t ℓ_t^perf(e)`，目标 `R_T = O(√(T N ln N))`。
- 竞速切换：仅当 `LCB_challenger > UCB_incumbent + margin` 时切换，否则 `HOLD`；断联则 `PAUSE`。

## 开放问题

- 在线覆盖能否从「边际覆盖」升级到「条件覆盖」？（Mondrian / group-conditional ACI，按场景分组维护 `α_t^{(g)}`）
- 硬约束在线学习（safe OCO）中，遗憾界与安全违反次数之间是否存在下界权衡？
- 排行榜在专家可共谋时是否仍能保证真实汇报？（机制设计 + 相关均衡）
- 竞速切换在非平稳流上的「平均切换时延 vs 误切换率」如何权衡？SPRT 的漂移鲁棒性如何？

## 与 v23 的关系

v24 = v23 的时间维度补全。必须保持 `Exec_v24 ⊆ Exec_v23 ⊆ Exec_v22 ⊆ …` 的单调链：在线层只做「收紧」不做「放松」，任何在线模块失效都退回 v23 的静态四证。

**本轮最大风险（一句话）**：在线覆盖控制器与竞争排行榜若共享同一批相关专家，对抗性漂移可同时低报覆盖债务、并让同质专家刷榜，使「无遗憾」退化为「集体自信的错误」。

## 1. 关键算法骨架

### IP-440 Adaptive Conformal Certificate（ACC）
**直觉**：把「覆盖债务」当作控制误差，`err_t=1`（漏覆盖）就把 `α_t` 调小（预测集变大、更保守），反之放松。更新式让债务在长期被 `O(1/γ)` 夹住，平均覆盖误差自动趋零。

```python
class AdaptiveConformalCertificate:
    def __init__(self, alpha_star=0.01, gamma=0.01,
                 alpha_min=1e-4, alpha_max=0.2, window=5000):
        self.alpha_star = alpha_star
        self.alpha_t = alpha_star
        self.gamma = gamma
        self.alpha_min, self.alpha_max = alpha_min, alpha_max
        self.calib = deque(maxlen=window)     # (score, err) 滑动校准集
        self.coverage_debt = 0.0              # D_t

    def _quantile(self, score):
        return empirical_quantile(self.calib, 1.0 - self.alpha_t)

    def observe(self, score, err):
        """err = 真实误差；返回本步是否覆盖。"""
        covered = int(err <= self._quantile(score))
        err_t = 1 - covered
        self.calib.append((score, err))
        # ACI 反馈更新（投影到 [alpha_min, alpha_max]）
        self.alpha_t = min(self.alpha_max, max(
            self.alpha_min,
            self.alpha_t + self.gamma * (self.alpha_star - err_t)))
        self.coverage_debt += (err_t - self.alpha_star)
        return covered

    def mode(self) -> str:
        # 覆盖债务超过阈值 → 强制保守模式（只允许最保守计划）
        return "CONSERVATIVE" if self.coverage_debt > self.debt_max else "NORMAL"

    def online_ok(self) -> bool:
        # 长程覆盖下界（债务归一化后）仍达标
        return self.coverage_debt <= self.debt_max
```

### IP-441 No-Regret Certificate Tournament（NRCT）
**直觉**：专家 = 「证书链 + 计划 + 变体」的组合。只在通过硬证书的专家里比赛；空集就安全停车。用 EXP3 处理 bandit 反馈（只观测到被选中计划的结果）。

```python
class NoRegretCertificateTournament:
    def __init__(self, experts, horizon, gamma_exp3=0.07):
        self.experts = experts
        self.N = len(experts)
        self.w = np.ones(self.N)
        self.eta = math.sqrt(8.0 * math.log(self.N) / max(horizon, 1))
        self.gamma_exp3 = gamma_exp3
        self.feasible = np.ones(self.N, dtype=bool)
        self.last = None

    def update_feasibility(self, certs_t):
        # 硬证书掩码：任一失败即不可行（安全是约束，不是损失项）
        self.feasible = np.array([e.hard_gate(certs_t) for e in self.experts])

    def select(self):
        if not self.feasible.any():
            self.last = None
            return SAFE_STOP
        p = self.w * self.feasible
        p = p / p.sum()
        i = int(np.random.choice(self.N, p=p))
        self.last = i
        return self.experts[i]

    def observe(self, perf_loss):
        if self.last is None:
            return
        denom = float((self.w * self.feasible).sum())
        p_i = self.w[self.last] / max(denom, 1e-12)
        # EXP3 重要性加权估计 + 乘性更新
        est = perf_loss / max(p_i, 1e-12)
        self.w[self.last] *= math.exp(-self.eta * est)
        # 数值稳定：整体缩放（不改变选择分布）
        self.w /= self.w.max()

    def current_leader(self):
        masked = np.where(self.feasible, self.w, -np.inf)
        return int(np.argmax(masked)) if np.isfinite(masked).any() else None
```

### IP-442 Competitive Safe-Variant Portfolio（CSVP）
**直觉**：多个 IP-safe 变体不能「一上来就真跑」。先在影子模式（数字孪生 / 回放）做排位赛，用逐轮淘汰（successive halving）把评估预算集中到领先者，降低真实切换风险。

```python
class CompetitiveSafeVariantPortfolio:
    def __init__(self, variants, rounds=3, budget=300):
        self.variants = variants          # 每个含独立证书链/校准/原型
        self.rounds = rounds
        self.budget = budget

    def qualifying(self, replay_stream):
        alive = list(self.variants)
        b = self.budget
        for r in range(self.rounds):
            # 影子评估：不进入真实执行，仅回放
            scores = {v.id: v.shadow_eval(replay_stream, n=max(b // len(alive), 1))
                      for v in alive}
            alive.sort(key=lambda v: scores[v.id], reverse=True)
            alive = alive[:max(1, len(alive) // 2)]   # 淘汰一半
            b //= 2
        return alive[0] if alive else None

    def diversity_bonus(self):
        # 去相关惩罚：与已选专家特征越相似，权重折扣越大
        # 简化：按骨干/校准集指纹聚类，簇内样本数做有效样本量折算
        return effective_sample_size_discount(self.variants)
```

### IP-443 Race-Paced Atomic Switch（RPAS）
**直觉**：不再固定等 200ms。挑战者的覆盖置信下界必须显著超过旧版本的置信上界才「进站」；旧版本始终保留在赛道上；云端断联 = 安全车（PAUSE），不会出现「无版本可用」。

```python
class RacePacedAtomicSwitch:
    def __init__(self, incumbent, challenger, margin=0.005,
                 delta=0.01, min_samples=30):
        self.inc, self.ch = incumbent, challenger
        self.margin, self.delta = margin, delta
        self.min_samples = min_samples
        self.n_inc = self.n_ch = 0
        self.mean_inc = self.mean_ch = 0.0
        self.paused = False
        self.state = "RACING"

    def _update_mean(self, mean, n, x):
        n += 1
        return mean + (x - mean) / n, n

    def update(self, cover_inc, cover_ch):
        self.mean_inc, self.n_inc = self._update_mean(
            self.mean_inc, self.n_inc, cover_inc)
        self.mean_ch, self.n_ch = self._update_mean(
            self.mean_ch, self.n_ch, cover_ch)

    @staticmethod
    def _bound(n, delta):
        return math.sqrt(math.log(1.0 / delta) / (2.0 * max(n, 1)))

    def decide(self):
        if self.paused:
            return "PAUSE"
        if self.n_ch < self.min_samples:
            return "HOLD"                     # 证据不足：继续跑旧版本
        lcb_ch = self.mean_ch - self._bound(self.n_ch, self.delta)
        ucb_inc = self.mean_inc + self._bound(self.n_inc, self.delta)
        if lcb_ch > ucb_inc + self.margin:
            self.state = "SWITCHING"
            return "SWITCH"                   # 挑战者显著领先 → 进站
        if self.mean_inc < 1.0 - self.alpha_star - self.margin:
            self.state = "SWITCHING"
            return "SWITCH_IF_FEASIBLE"       # 旧车退化，必须换胎
        return "HOLD"

    def on_cloud_disconnect(self):
        self.paused = True                    # 安全车：冻结比赛
        self.state = "PAUSED"

    def on_reconnect(self):
        self.paused = False
        self.state = "RACING"

    def safe_to_switch(self):
        # 只有存在至少一个已验证的挑战者，且旧版本仍在保底
        return self.ch is not None and self.inc is not None
```

### IP-444 Strategyproof Ranking（SPR）
**直觉**：专家若可虚报「我很准」，排行榜就会被刷。用严格 proper scoring rule（对数分数）使「如实报告」成为严格占优策略；再叠加去相关惩罚，防止同质专家合谋刷榜。

```python
class StrategyproofRanking:
    def __init__(self, delta_div=0.1):
        self.delta_div = delta_div

    def score(self, q_report, outcome):
        # 严格 proper scoring rule：真实报告 q 是唯一最优
        return math.log(q_report[outcome] + 1e-12)

    def ranking(self, reports, outcomes, fingerprints):
        raw = {e: self.score(reports[e], outcomes[e]) for e in reports}
        # 去相关：与已选集合越相似，边际贡献折扣越大（submodular 贪心）
        selected, adjusted = [], dict(raw)
        while len(selected) < len(raw):
            best = max((e for e in raw if e not in selected),
                       key=lambda e: adjusted[e])
            selected.append(best)
            for e in raw:
                if e not in selected:
                    sim = cosine(fingerprints[e], fingerprints[best])
                    adjusted[e] -= self.delta_div * max(sim, 0.0)
        return selected

    def audit_consistent(self, reported, shadow):
        # 报告分数与影子评估的偏差超过阈值 → 判定操纵
        return abs(reported - shadow) <= self.audit_tol
```

### IP-445 HPC-E++ 统一在线竞争式准入门

```python
@dataclass
class HPCEPlusPlus:
    hpc_e_plus: HPCEPlus              # v23 四证
    acc: AdaptiveConformalCertificate
    nrct: NoRegretCertificateTournament
    rpas: RacePacedAtomicSwitch
    spr: StrategyProofRanking

    def admits(self, plan, certs_t, x, v, z, E_res, margin_req, modules):
        # 1–4. v23 四证（物理接地 / 云边同步 / 少样本 / IP）
        if not self.hpc_e_plus.admits(plan, x, v, z, E_res, margin_req, modules):
            return False
        # 5. 在线覆盖：债务未超限
        if not self.acc.online_ok():
            return False
        # 6. 锦标赛可行性：被选专家必须在可行域内
        if self.nrct.last is None or not self.nrct.feasible[self.nrct.last]:
            return False
        # 7. 竞速切换就绪：切换中必须有保底版本
        if self.rpas.state == "SWITCHING" and not self.rpas.safe_to_switch():
            return False
        # 8. 排行榜审计：报告与影子评估一致（防操纵）
        if not self.spr.audit_consistent(
                self.nrct.reported_score(), self.nrct.shadow_score()):
            return False
        return True

    def exec_set(self):
        return Exec_v23 & {pi: self.acc.online_ok()
                           and self.nrct.last in Feasible_t
                           and self.rpas.state != "UNSAFE"
                           and self.spr.audit_ok}
```

### 端到端增量流水线（相对 v23 只加在线层）

```python
class OnlineCompetitivePipeline(PerceptionComplianceEnergyPipeline):
    def __init__(self, config):
        super().__init__(config)
        self.acc = AdaptiveConformalCertificate(
            config.get("alpha_star", 0.01), config.get("gamma", 0.01))
        self.nrct = NoRegretCertificateTournament(
            config["experts"], config.get("horizon", 10**6))
        self.csvp = CompetitiveSafeVariantPortfolio(config["variants"])
        self.rpas = RacePacedAtomicSwitch(
            incumbent=self.cesc.current_version(),
            challenger=None, margin=config.get("margin", 0.005))
        self.spr = StrategyProofRanking()
        self.gate = HPCEPlusPlus(self.hpc_e_plus, self.acc,
                                 self.nrct, self.rpas, self.spr)

    def step(self, sensor_data, cloud_update=None):
        # A. 在线覆盖观测（每帧）
        for frame in sensor_data["camera_frames"]:
            self.acc.observe(*self._score_and_error(frame))

        # B. 更新专家可行域，锦标赛选专家（可行集空则 SAFE_STOP）
        self.nrct.update_feasibility(self._generate_certificates(sensor_data))
        expert = self.nrct.select()

        # C. 竞速式切换（若有挑战者）
        if self.cesc.V_pending is not None:
            self.rpas.challenger = self.cesc.V_pending
            action = self.rpas.decide()
            if action == "SWITCH":
                self.cesc.atomic_switch()      # 内部仍做 FewShotValid 兜底
            elif action == "PAUSE":
                self.cesc.handle_cloud_disconnect()

        # D. 统一准入
        plan = SAFE_STOP if expert is SAFE_STOP else expert.plan
        admitted = self.gate.admits(
            plan, self._generate_certificates(sensor_data),
            sensor_data["x"], sensor_data["v"], sensor_data["z"],
            sensor_data["E_res"], sensor_data["margin_req"],
            self._modules_in_plan(plan))
        return admitted, {
            "plan": plan if admitted else None,
            "expert": expert,
            "alpha_t": self.acc.alpha_t,
            "coverage_debt": self.acc.coverage_debt,
            "race_state": self.rpas.state,
        }
```

## 3. 正确性论证

### 引理 1（ACI 长程覆盖，无需交换性）
**陈述**：对任意序列 `{(s_t, err_t)}`（可对抗、可非平稳），采用 `α_{t+1} = Π_{[α_min,α_max]}(α_t + γ(α* - err_t))`，则
`|(1/T) Σ_{t=1}^T err_t - α*| ≤ (α_max - α_min)/(γT)`。

**证明**：
1. 记 `e_t = err_t - α*`，则更新可写为 `α_{t+1} = α_t - γ e_t`。
2. 递推求和：`α_{T+1} = α_1 - γ Σ_{t=1}^T e_t`，故 `Σ e_t = (α_1 - α_{T+1})/γ`。
3. 由投影 `α_1, α_{T+1} ∈ [α_min, α_max]`，得 `|Σ e_t| ≤ (α_max - α_min)/γ`。
4. 两边除以 T 即得结论。整个推导不使用任何分布/交换性假设，故对对抗序列成立。∎

**含义**：即使分布剧变导致覆盖瞬时跌破，`α_t` 会自动收紧，平均覆盖仍以 `O(1/(γT))` 回到 `1-α*`。这直接消除 v23 中「旧模型静态覆盖失效」的隐患。

### 引理 2（约束 EXP3 的无遗憾性）
**陈述**：若全程 `Feasible_t ≠ ∅` 且选择只在 `Feasible_t` 内进行，则相对最佳固定可行专家 `e*` 的性能遗憾
`R_T ≤ 2√(T N ln N)`（EXP3，bandit 反馈）。

**证明**：
1. 将不可行专家在第 t 步的权重视为 0（硬掩码），等价于在动态子集上做 EXP3。
2. 标准 EXP3 分析给出 `R_T ≤ 2√(T N ln N)`（Auer et al. 2002），其中基线为任意固定臂。
3. 因可行专家始终可选，取基线为 `e* = argmin_{e∈∩_t Feasible_t} Σ ℓ_t(e)`，结论成立。∎

**注意**：若某步可行集为空，系统执行 `SAFE_STOP`，此时不计入性能遗憾（安全优先），但会记一次「可用性事件」用于运维告警。

### 引理 3（竞速切换保持证书单调）
**陈述**：RPAS 在任意时刻至少保留一个通过硬证书的版本；切换、PAUSE、回退均不产生「无认证版本」状态，故 `Exec_v24 ⊆ Exec_v23`。

**证明**：
1. `decide()` 仅返回 `HOLD / SWITCH / SWITCH_IF_FEASIBLE / PAUSE`；`SWITCH` 的前提是挑战者覆盖 LCB 显著领先，且 `safe_to_switch()` 要求旧版本仍在。
2. 切换失败或超时 → `cesc._rollback()`，`V_active` 不变（v23 已有性质）。
3. 云端断联 → `PAUSE`，`cesc.handle_cloud_disconnect()` 冻结 `V_last_valid`，继续用旧版本签发证书。
4. 因此任何时刻活跃版本集合非空且均已认证，在线层只收紧可行域，不放松。∎

### 引理 4（严格 proper scoring 的策略防操纵）
**陈述**：若专家报告预测分布 `q`、真实结果 `y`，按 `S(q,y)=log q[y]` 计分，则如实报告是严格占优策略；据此构建的排行榜对单专家虚报免疫。

**证明**：
1. 对数分数是严格 proper scoring rule：`E_{y∼p}[log q[y]]` 在 `q=p` 处取得唯一最大值（Gibbs 不等式）。
2. 故任何 `q≠p` 的期望得分严格更低，虚报无利可图。
3. 对多个专家，去相关贪心保证同质专家的边际贡献递减，抑制合谋刷榜（启发式，非形式化保证，见 R4）。∎

### 引理 5（单调退化链）
**陈述**：`Exec_v24 ⊆ Exec_v23 ⊆ Exec_v22 ⊆ … ⊆ Exec_v18` 在任意单点/组合失效下恒成立。

**证明**：
- 在线层失效（ACC 债务超限 / NRCT 空可行集 / RPAS 不安全 / SPR 审计失败）→ 该步拒证或 `SAFE_STOP`，退回 v23 静态四证，执行集只减不增。
- 云端断联 → `PAUSE` + `OfflineMode`，冻结 `V_last_valid`，等价于 v23 的离线退化路径。
- 专利风险 → `IP-SafeVariant` 进入 CSVP 排位，未通过影子评估前不切换，保持 v23 行为。
- 组合失效取交集，单调性保持。∎

### 定理（HPC-E++ 的在线安全—性能—合规完备性）
**陈述**：对任意计划 `π`，`HPCEPlusPlus.admits(π)=True` ⟺ `π` 同时满足：
(1) v23 四证（物理接地 ∧ 云边同步 ∧ 少样本 ∧ IP）；
(2) 长程在线覆盖 `Coverage_online(T) ≥ 1-α* - O(1/(γT))`；
(3) 被选专家在硬可行域内（安全违反 = 0）；
(4) 切换处于竞速安全态（存在保底版本）。
且在此前提下，性能遗憾 `R_T = O(√(TN lnN))`，平均覆盖误差 `O(1/(γT))`。

**证明**：由 `HPCEPlusPlus.admits` 的四个连言条件，分别对应引理 1（在线覆盖）、引理 2（无遗憾选择）、引理 3（切换单调）、引理 4（防操纵）与 v23 的四证定理。安全性由硬掩码保证（违反数恒为 0）；性能界由引理 2；覆盖界由引理 1。∎
