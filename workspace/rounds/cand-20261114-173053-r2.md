# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；灵感循环新循环第 2 轮；本轮灵感：「可扩展性」×「通信延迟」）

> R69 把不确定性拆成 aleatoric 与 epistemic，让系统学会「看、问、触、等」，并用 VoI 决定值不值得求证。但它悄悄预设了三件在真实部署中几乎从不成立的事：
> 1. **只有一个决策者**（单机、单人类、单环境）；
> 2. **信息瞬时到达**（问一句，答案立刻可用，状态没有移动）；
> 3. **所有 VoI 都能在本地实时算完**（K 次流采样、轨迹聚类、模态枚举都免费）。
>
> 当 FLUID-RAS 放大到一支机队、一个边缘—云协同体、或一个跨人类/智能体/外部服务的开放环境时，这三条同时崩塌：求证要跨网络、答案有延迟、算力被 N 个节点分摊。更致命的是，R69 自己承认的最大风险——**模态权重不可信时会在错误信念上追问一个幻影**——在规模化之后不会消失，反而会被「N 个节点都这么说」放大成虚假共识。
>
> 本轮两个灵感恰好给出两把尺子：
> - **通信延迟** → 信息是**易腐**的。VoI 不是一个标量，而是时间的函数；超过决策期限的答案价值为零，状态漂移会让旧答案自己作废。R69 的 VoI 只是「零延迟」这个理想边界。
> - **可扩展性** → 稀缺的不是算力本身，而是「谁在什么时刻算、花多少通信、N 个证据里到底有几个是独立的」。规模不会自动带来冗余，**相关故障会让 N 个节点退化成 1 个节点的 N 次复制**。
>
> 核心命题：**把 R69 的「值不值得问」升级为「在什么期限前问、在哪个节点算、答案来不来得及、以及多源证据是否真的独立」。** 用双时钟架构把安全快环与认知慢环解耦（快环永不等待通信），用期限感知 VoI（DVoI）给信息定价，用相关性感知的有效证据数（k_eff）拆穿规模幻觉，用联邦摊销校准把 R69 的模态可信度问题从单机推广到群体。命名 **TIDE-RAS**（Time-aware Information Decay at scalE）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「该向谁求证、还能问什么」，R70 问「**什么时候还值得问、答案等不等得起、以及一群节点一起说对了吗**」——信息不是免费的查询，而是带保质期、带邮费、可能被相关噪声淹没的资源。

## 0. 直觉与动机

**灵感 1（通信延迟 → 信息有半衰期）**
直觉：R69 的 VoI(g)=H(M|o)−E[H(M|o,y)] 默认「问完立刻知道」。可真实链路里，远处人类的一句回答可能要 300ms，云端一次大模型求证可能要 2s，而机器人在 50ms 后就必须决定是否让出通道。一个来不及时的正确答案，与没有答案在决策意义上等价。于是「价值」必须先乘以「按时到达的概率」与「到达时还相关的概率」：信息像放射性同位素，有自己的半衰期 τ½。R69 的交互收益曲线是「越歧义越值钱」；在延迟下它多了一个悬崖——**超过盈亏平衡延迟 τ*，再大的歧义也不值得问**，因为答案只对已经错过的状态有效。

**灵感 2（可扩展性 → 解耦时钟，而非加速一切）**
直觉：最朴素的可扩展方案是把 FLUID 全流程塞进每个节点，让所有节点都跑 K 次流采样、都算 VoI、都做轨迹聚类。这既贵又危险：安全控制被迫和网络/推理抢同一个截止期。真正的可扩展性来自**分层与解耦**——安全快环只依赖本地缓存与 R68 兜底，硬截止、绝不等待；认知慢环异步地做昂贵消歧，只有被升级的少数歧义节点才付全价。这就像人的脊髓反射与有意识思考：手碰到烫的东西会先缩回，再慢慢想为什么烫。规模化的收益不是「每个节点更强」，而是「便宜的节点做便宜的事，贵的推理只落在真正需要的地方」。

**灵感 3（规模幻觉 → N 个证据不等于 N 份独立信息）**
直觉：R69 的证据纪律是「k 个正交证据源一致才定案」，并给出投毒上界 δ_p·ρ^{k−1}。但在机队里，十台同型号机器人在同一场地、被同一段虚假广播、同一个物理扰动同时影响——它们不是十个证人，而是一个证人的十次回声。有效独立源数 k_eff 会随相关 ρ 塌缩；当 ρ→1，k_eff→1，上界原地退回单源。**可扩展性最危险的失败不是算不动，而是「算得动却一起错」**：分布式一致性越强，虚假共识越自信。这正好把 R69 的最大风险从单机推广成舰队级风险，也是本轮必须正面处理的核心。

**灵感 4（旧层是边界，而不是被替代）**
直觉：R69 相对 R68 的理论姿态是「严格包含」，本轮必须延续：当延迟为零、节点唯一、延迟分布退化、证据完全独立、无分区时，TIDE 必须逐指令退化为 FLUID；当 VoI 无利可图时再退化为 R68。否则每加一层就多一个独立需要信任的黑箱。**好架构是俄罗斯套娃，不是违章加盖。**

**灵感 5（规模是新攻击面 → 通信与时钟本身可被攻击）**
直觉：一旦系统依赖远程证据，就有了新的攻击面：延迟注入（把关键回答拖过截止期，逼迫系统在不确定下行动）、时钟偏移（伪造新鲜度）、女巫攻击（伪造大量相关节点制造共识）、分区撕裂（让两半各自以为掌握了全局）。所以 TIDE 的证书必须新增：证据年龄上界、期限余量、有效独立源数、升级比例、通信预算、分区标志。**没有这些字段的「规模化」只是把单点故障换成了分布式集体误判。**

## 1. 形式化定义（增量：定义 310–321）

**定义 310（TIDE-RAS 总览与四不变式）** TIDE-RAS = (DVC, TSL, HBA, FAC, SAF, CAP, RAS-WM†)。四不变式：
(i) **快环非阻塞**：安全相关通路永不等待任何远程证据或网络；期限未到而证据未至 ⇒ 用缓存信念 + R68 保守兜底；
(ii) **信息易腐**：任何信息动作按「期限截断、漂移折损」的期望熵减定价，预计到达晚于决策期限则 VoI ≡ 0；
(iii) **规模预算硬约束**：每轮每节点平均广域消息 O(1)，昂贵推理只作用于升级子集，通信/算力是约束而非优化目标；
(iv) **独立性诚实**：证据只按有效独立源数计票，超过有效期的陈旧证据不得单独定案。

**定义 311（通信动作与延迟模型）** 在 R69 增广动作空间上再增通信动作 g_comm ∈ 𝒜_comm（查询对象、信道、优先级），ξ=(a,g,g_comm)。每个信息动作 g 带延迟分布 L(g)（允许重尾：均值 μ_g、P99 τ_g^{99}）、带宽 b(g)、通信成本 c_comm(g)。一条证据 e 记为 (s_e, t_e, t_a, τ_v, γ_e)：源、生成时刻、到达时刻、有效期、独立组编号。

**定义 312（证据年龄与相关性核）** 决策期限 t_d 下，证据年龄 Δ = t_d − t_e。相关性核
κ(Δ) = P(决策纪元未变 | Δ) · e^{−ρΔ} · 1[Δ ≤ τ_v]，
其中 ρ 为状态漂移/信息老化率，半衰期 τ½ = ln2/ρ。κ(Δ) 单调不增，Δ > τ_v 时归零。R69 对应 κ≡1（ρ=0, τ_v=∞）。

**定义 313（期限感知 VoI，DVoI）** 对候选信息动作 g：
DVoI(g; t_d) = [H(M|o_t) − E_{y∼p(·|g,o_t)} H(M|o_t,y)] · κ(Δ_g) · Pr[t_a ≤ t_d − ε] − c(g) − c_comm(g)，
选 g* = argmax_g DVoI，s.t. risk(g) ≤ ε_int、预算未超；若 max DVoI ≤ 0 则不交互、走 R68。**当 L≡0、τ_v=∞、ρ=0、c_comm=0 时 DVoI ≡ R69 的 VoI（定义 298）**——这是本轮严格包含 R69 的锚点。

**定义 314（双时钟调度器 TSL）** 快环周期 T_f（有界，目标 P99 < 1.5ms）；慢环周期 T_s（异步、可跨越多个快环）。状态机：本地推测执行 → 异步派发证据请求（带截止期 D_t = t_d − ε）→ 若在 D_t 前到达则合并并做**增量重规划**；否则维持保守执行。快环输出始终是缓存信念下的 C-RAS-WM 认证前缀；证据合并只允许在安全包络内改变模态选择（与定义 302、R68 定理 15 一致）。

**定义 315（分层信念聚合 HBA）** 三层：L0 每节点本地 z_t、mode_head、U_epi；L1 边缘按空间/物理相关性做协方差交叉，得到摊销模态后验；L2 云端做长时程校准与全局裁决。升级集合 A_esc = {i : U_epi,i > τ_e ∨ 与邻节点冲突}。仅 A_esc 运行 K 次流采样 + 轨迹聚类 + VoI 枚举。复杂度从 O(N·K) 降为 O(N + K·|A_esc|)。

**定义 316（联邦摊销校准 FAC）** 各节点只上报低维充分统计量（可靠图分箱计数、残差矩），加 DP 噪声后在边缘聚合，维护 MCG 的群体 ECE。关键：记节点间故障/误差相关为 ρ̂，**有效样本数 N_eff = N / (1 + (N−1)ρ̂)**。若 N_eff < N_min，则拒绝认证群体模态权重，退回本地 R68 纯保守。规模只有在不相关时才是规模（对应 R69 最大风险的群体版）。

**定义 317（陈旧感知融合 SAF）** 证据合并算子 ⊗_τ 先按有效期过滤；存活证据权重乘 κ(Δ)；新鲜证据与陈旧证据冲突时以新鲜为准；任意多条陈旧证据不得累加绕过 R69 的 k-正交纪律。形式要求：合并后的后验熵满足数据处理器不等式 H(M|o,E_stale) ≥ H(M|o) − I(M; o_{t_e})，即陈旧信息最多回到它生成时刻的价值，不能凭空更新。

**定义 318（相关性感知证据数 CAE）** 把 R69 的 k_orthogonal 升级为 k_eff。设证据源两两平均相关 ρ̄，则
k_eff = 1 + (k−1)(1−ρ̄)（下界按 Gershgorin 型估计给出）。
R69 的投毒上界相应变为 δ_p·ρ̄^{k_eff−1} + ε_σ。系：**增加相关源的数量收益指数衰减**；结构性多样性（不同物理模态、不同故障域、不同时间尺度）比单纯增加节点数更值钱。

**定义 319（分区与降级模式 DMG）** 分区标志 P_net；分区期间远程证据冻结并随年龄衰减；控制只用本地信念。分区时长 > τ_part ⇒ λ = λ_floor(U_ale + U_epi)（R68 保守）且禁止发起跨区交互；重连后必须先做新鲜度对账（reconcile fresh），未对账前不得信任任何跨区旧证据。

**定义 320（通信安全与优先级）** g_comm 不得占用安全通路；消息分级：安全证书 > 证据请求 > 审计日志；单节点发送速率与队列长度硬上限；抑制广播风暴。任一通信动作若挤占快环截止期，则视为未通过认证，按定义 302 作废。

**定义 321（证书 J_TIDE）** J_TIDE = (J_FLUID, max_evidence_age, deadline_slack, N_eff, escalate_fraction, message_budget_used, partition_flag, calib_coverage, independence_estimate, tide_ver)。Valid ⇔ Valid(J_FLUID) ∧ max_evidence_age ≤ τ_v ∧ deadline_slack ≥ 0 ∧ N_eff ≥ N_min ∧ message_budget_used ≤ B_max ∧ (¬partition_flag ∨ 已降级)。

## 2. 关键算法骨架

```python
# IP-264 DVC：期限感知 VoI，零延迟时退化为 R69 VoI
def dvoi(g, modes, w, o_t, t_d, net):
    H0   = entropy(w)
    H1   = expected_entropy(w, g, o_t)                # 假设按时到达的熵
    mu, p99 = net.latency_dist(g)                     # 重尾感知
    p_on   = net.P_arrival_before(g, t_d - EPS)       # 按时到达概率
    age    = net.expected_age(g, t_d)
    kappa  = relevance(age)                           # e^{-rho*age}, age>tau_v -> 0
    return (H0 - H1) * kappa * p_on - cost(g) - net.c_comm(g)

def choose_interaction(modes, w, o_t, t_d, budget, net):
    best = None
    for g in info_action_candidates(modes):
        if not budget.allow(g) or not c_ras_wm.certify_info(g, o_t): continue
        score = dvoi(g, modes, w, o_t, t_d, net)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None   # <=0 -> R68 兜底

# IP-265 TSL：双时钟——快环绝不等待，慢环异步消歧
def fast_loop(M, obs):
    z, o = M.mtm.forward(obs)                         # 复用 R68，无网络
    belief = M.cache.latest(z)                        # 可能陈旧，但带年龄
    U_ale, U_epi = M.aud.decompose_cached(belief)
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + U_epi * belief.stale_factor))
    k   = M.c_ras_wm.certified_prefix(M.ach.propose(...), ...)  # 安全前缀
    return k, lam, belief.mode

def slow_loop(M, obs, t_d):
    if not M.hba.should_escalate(obs): return None     # 便宜门控
    samples = M.fmp.sample(obs, K=4)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples)
    g = M.mint.choose_interaction(modes, ..., t_d, M.budget, M.net)
    if g is None: return None                          # VoI<=成本 -> R68
    fut = M.cap.dispatch_async(g, deadline=t_d - EPS)  # 不阻塞快环
    M.cache.attach(fut, validity=M.saf.horizon(g))
    return fut

def merge_evidence(M, e, t_now):                      # 仅当在期限内到达
    if M.saf.is_stale(e, t_now): return M.cache.belief  # 丢弃/降权
    e = M.saf.discount(e, t_now)                      # 乘 kappa(age)
    if M.cae.k_eff(e.group) < M.evidence.k_min:       # 相关源不算数
        return M.cache.belief
    return M.cia.update_belief(M.cache.belief, e, discipline='k_eff_agree')

# IP-270 CAP：通信感知规划，消息预算与优先级
def schedule_comm(requests, net, budget):
    requests = sorted(requests, key=lambda r: -r.dvoi / r.bytes)  # 价值密度
    out = []
    for r in requests:
        if not budget.can_send(r) or net.would_block_fast_loop(r): continue
        out.append(r)
    return out                                        # 安全证书永远优先

# IP-271 DMG：分区/降级治理
def degraded_mode(M, P_net, t_now):
    if not P_net:
        if M.was_partitioned: M.reconcile_fresh()     # 重连先对账
        return
    M.freeze_remote_evidence(t_now)
    if t_now - M.partition_start > TAU_PART:
        M.force_r68_conservative()                    # lam -> lam_floor(U_ale+U_epi)
        M.mint.disable_interaction()

# IP-273 主闭环（TIDE 版；快慢分离）
def TIDE_RAS_round(M, obs):
    # --- 快环：本地、有界、绝不等待 ---
    k, lam, mode = fast_loop(M, obs)
    # --- 慢环：异步派发，不参与本级安全决策 ---
    M.slow.schedule(slow_loop, M, obs, t_d=M.deadline)
    # --- 若上一轮证据恰在期限内到达，则合并后增量重规划 ---
    if M.pending.ready(within=M.deadline):
        M.cache.update(merge_evidence(M, M.pending.pop(), t_now))
        return M.replan_incremental(k, lam, mode)     # 仅在安全包络内换模态
    M.vqa_i.submit_async(M.cache.age, M.cae.k_eff_estimate(), M.partition_flag)
    return k, lam, mode
```

## 3. 推导

**引理 19（DVoI 的延迟单调性与盈亏平衡延迟）** 固定 g 与状态，DVoI(g;t_d) 关于期望延迟 μ_g 单调不增；当 c(g)+c_comm(g)>0 时存在有限 τ*，使 μ_g>τ* 后 DVoI<0。证明要点：Pr[按时到达] 与 κ(age) 均关于延迟单调不增，成本非负，故成立。系：**R69 的 VoI 是 L=δ_0 的退化边界**；延迟越大，可消歧的歧义集合单调收缩，这正是「信息易腐」。

**引理 20（相关源的有效证据数塌缩）** 设 k 个源的误差两两相关 ρ̄，则有效独立源数 k_eff ≤ 1+(k−1)(1−ρ̄)。代入 R69 引理 18 的多数一致上界，错误采纳率 ≤ δ_p·ρ̄^{k_eff−1}+ε_σ。当 ρ̄→1 时 k_eff→1，上界退回单源。系：**规模化若无结构性去相关，只是把 1 个证人复制成 N 个回声**；这是「可扩展性」必须与独立故障域绑定的原因。

**引理 21（陈旧证据的数据处理上界）** 对年龄 Δ>τ_v 的证据 e_stale，有 I(M; e_stale | o_t) ≤ I(M; o_{t_e})，且合并后熵满足 H(M|o_t,e_stale) ≥ H(M|o_t) − I(M;o_{t_e})。故陈旧证据最多把后验恢复到其生成时刻的水平，无法凭空增加确定性，更不能单独满足 k-正交定案。系：**有效期 τ_v 必须显式入证书**，否则「旧答案 + 大数量」会伪造共识。

**定理 18（严格包含链 TIDE ≻ FLUID ≻ R68）** 在零延迟（L=δ_0）、单节点（N=1）、证据完全独立（ρ̄=0）、无分区、τ_v=∞ 时，DVoI≡VoI，TSL 退化为 FLUID 单环，HBA 退化为本地信念，SAF/CAE 恒等——TIDE 逐指令等于 FLUID；进一步当 VoI≤成本时逐指令等于 R68（继承定理 16）。因此安全侧对 R69、R68 均不做让步，效率侧只在「信息来得及且有独立证据」时获得 resolution bonus。

**定理 19（期限安全与非阻塞）** 对任意网络延迟（含重尾/丢包），快环的决策延迟只由本地计算与缓存信念决定，上界不随 N、K、L 增长；其输出始终是 C-RAS-WM 认证前缀，风险 ≤ R68 同状态保守策略。证据若在期限内未到，λ 单调不降地退化为 R68；证据若到达，合并被限制在安全包络内改变模态选择，提交/换装不变式（R68 定理 15）保持 ⇒ 控制连续、无突变。

**定理 20（规模复杂度）** 设升级比例 α=|A_esc|/N、单节点廉价路径成本 c_0、昂贵路径成本 c_1，则每轮总计算为 N·c_0 + αN·c_1，广域消息为 O(N)（平均每节点 O(1)），而非全互联 O(N²)。在故障域数 D 有界时 k_eff ≤ D，证据聚合的冗余收益上界与 N 脱钩。系：**可扩展性的正确度量是「每节点常数消息 + 升级子集线性」，不是「总吞吐」**；α 本身是歧义率与相关性 ρ̄ 的函数，可监控、可预算。

**定理 21（相关故障下的安全—效率权衡）** 若 ρ̄≥ρ_max 使 k_eff<k_min，则 FAC 拒绝群体标定、CAE 拒绝多源定案，系统回退到本地 R68 保守。此回退是安全单调的，但会把「本可由独立证据获得的 resolution bonus」全部放弃——即在高相关环境下，TIDE 的收益上界由结构性多样性而非节点数量决定。

## 6. 本轮最大风险

**一句话**：TIDE-RAS 的全部收益押在「延迟/相关性可估、且规模带来独立证据」这一前提上——**若延迟分布被重尾或对手拖长、节点故障高度相关（或时钟被伪造），DVoI 会系统性低估求证价值而漏掉可解歧义，联邦校准与多源定案则会给出一个「N 个回声互相作证」的虚假共识；此时系统不是算不动，而是整个机队以更高置信度一起问错、一起盖章——R69 把「诚实的不知道」升级成「被证实的错误」，R70 则可能把它升级成「被分布式共识证实的错误」**。

**次级风险与缓解**：
1. **重尾延迟导致 deadline 误判** → 用 P99/尾部分布而非均值定价，DVoI 按 `Pr[t_a ≤ t_d]` 截断，E301–E302 验证；
2. **相关故障/女巫攻击制造虚假共识** → CAE 的 k_eff + FAC 的 N_eff 拒绝门 + E306/E313，宁可退 R68 也不集体盖章；
3. **陈旧证据绕过证据纪律** → SAF 有效期硬过滤 + 引理 21 数据处理器上界 + 证书记录 max_evidence_age；
4. **快环被慢环/通信挤占** → TSL 硬隔离、消息优先级、CAP 预算，E309 压测；
5. **分区期两半各自为政** → DMG 冻结 + λ 退化 R68 + 重连对账，E308 验证。

用一句话总结：本轮把「值不值得问」推进为「是否来得及问、是否真的有多源独立证据」，用双时钟、期限感知 VoI 与相关性感知有效证据数，把 FLUID-RAS 的消歧能力从单机扩展成机队——但规模只有在故障不相关时才是冗余，否则只是更自信的集体误判。

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** TIDE-RAS=(DVC,TSL,HBA,FAC,SAF,CAE,CAP,DMG,RAS-WM†)；快环非阻塞；信息易腐；规模预算硬约束（每节点平均 O(1) 消息、昂贵推理仅升级子集）；独立性诚实（只按 k_eff 计票、陈旧证据不得单独定案）。

**定义 311–312（通信模型与年龄）** 信息动作带重尾延迟分布 L(g)、带宽、通信成本；证据携带生成/到达时刻、有效期与独立组；相关性核 `κ(Δ)=P(纪元未变)·e^{−ρΔ}·1[Δ≤τ_v]`，单调不增。

**定义 313（DVoI）** `DVoI(g;t_d)=[H(M|o_t)−E H(M|o_t,y)]·κ(Δ_g)·Pr[t_a≤t_d−ε]−c(g)−c_comm(g)`；取 max，≤0 则不交互走 R68。零延迟/无限有效期/零通信成本时精确退化为 R69 定义 298。

**定义 314（双时钟）** 快环周期 T_f、慢环周期 T_s；快环用缓存信念与 R68 兜底、输出认证前缀；慢环异步派发证据请求；到期前到达则合并并增量重规划，否则保守执行。

**定义 315（HBA）** L0 本地 z_t/mode_head/U_epi；L1 边缘协方差交叉得摊销后验；L2 云端长时程校准。仅 `A_esc={i:U_epi,i>τ_e ∨ 冲突}` 跑昂贵路径，复杂度 O(N+K·|A_esc|)。

**定义 316（FAC）** 低维统计量 + DP 聚合；`N_eff=N/(1+(N−1)ρ̂)`；N_eff<N_min 时拒绝群体认证、退回本地 R68。

**定义 317（SAF）** 有效期过滤 + κ 降权 + 新优于旧；合并满足 `H(M|o,E_stale) ≥ H(M|o)−I(M;o_{t_e})`，陈旧信息最多回到生成时刻价值。

**定义 318（CAE）** `k_eff=1+(k−1)(1−ρ̄)`；投毒上界 `δ_p·ρ̄^{k_eff−1}+ε_σ`；ρ̄→1 时 k_eff→1，退回单源。

**定义 319（DMG）** 分区期冻结远程证据并随龄衰减；超过 τ_part 则 `λ=λ_floor(U_ale+U_epi)`、禁交互；重连先对账再信任。

**定义 320（通信安全）** 消息分级（安全证书 > 证据请求 > 审计）、速率/队列硬上限；挤占快环截止期即认证失败。

**定义 321（J_TIDE）** 在 J_FLUID 上追加 `max_evidence_age`、`deadline_slack`、`N_eff`、`escalate_fraction`、`message_budget_used`、`partition_flag`、`calib_coverage`、`independence_estimate`；全满足才 Valid。

## 3. 关键算法伪代码

```python
# IP-264 DVC：期限感知 VoI（零延迟时 = R69 VoI）
def dvoi(g, modes, w, o_t, t_d, net):
    H0, H1 = entropy(w), expected_entropy(w, g, o_t)
    p_on   = net.P_arrival_before(g, t_d - EPS)          # 重尾感知
    kappa  = relevance(net.expected_age(g, t_d))         # e^{-rho*age}, age>tau_v -> 0
    return (H0 - H1) * kappa * p_on - cost(g) - net.c_comm(g)

def choose_interaction(modes, w, o_t, t_d, budget, net):
    best = None
    for g in info_action_candidates(modes):
        if not budget.allow(g) or not c_ras_wm.certify_info(g, o_t): continue
        s = dvoi(g, modes, w, o_t, t_d, net)
        if best is None or s > best.score: best = (g, s)
    return best if best and best.score > 0 else None      # <=0 -> R68

# IP-265 TSL：快环不等待，慢环异步消歧
def fast_loop(M, obs):
    z, o = M.mtm.forward(obs)                             # 复用 R68，无网络
    b    = M.cache.latest(z)                              # 带年龄的缓存信念
    U_ale, U_epi = M.aud.decompose_cached(b)
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + U_epi*b.stale_factor))
    k   = M.c_ras_wm.certified_prefix(M.ach.propose(...), ...)
    return k, lam, b.mode

def slow_loop(M, obs, t_d):
    if not M.hba.should_escalate(obs): return None        # 便宜门控
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(obs, K=4))
    g = M.mint.choose_interaction(modes, ..., t_d, M.budget, M.net)
    if g is None: return None                             # 无利可图 -> R68
    fut = M.cap.dispatch_async(g, deadline=t_d - EPS)     # 不阻塞快环
    M.cache.attach(fut, validity=M.saf.horizon(g))

# IP-268/269 SAF+CAE：仅合并期限内、且独立源足够的证据
def merge_evidence(M, e, t_now):
    if M.saf.is_stale(e, t_now): return M.cache.belief   # 过期丢弃
    e = M.saf.discount(e, t_now)                         # 乘 kappa(age)
    if M.cae.k_eff(e.group) < M.evidence.k_min:          # 相关源不计票
        return M.cache.belief
    return M.cia.update_belief(M.cache.belief, e, discipline='k_eff_agree')

# IP-270 CAP：按价值密度调度通信，安全证书永远优先
def schedule_comm(requests, net, budget):
    requests = sorted(requests, key=lambda r: -r.dvoi / r.bytes)
    return [r for r in requests
            if budget.can_send(r) and not net.would_block_fast_loop(r)]

# IP-271 DMG：分区降级与重连对账
def degraded_mode(M, P_net, t_now):
    if not P_net:
        if M.was_partitioned: M.reconcile_fresh()
        return
    M.freeze_remote_evidence(t_now)
    if t_now - M.partition_start > TAU_PART:
        M.force_r68_conservative()                       # lam -> lam_floor(U_ale+U_epi)
        M.mint.disable_interaction()

# IP-273 主闭环（快慢分离）
def TIDE_RAS_round(M, obs):
    k, lam, mode = fast_loop(M, obs)                     # 快环：本地、有界
    M.slow.schedule(slow_loop, M, obs, t_d=M.deadline)   # 慢环：异步、不参与本级
    if M.pending.ready(within=M.deadline):
        M.cache.update(merge_evidence(M, M.pending.pop(), t_now))
        return M.replan_incremental(k, lam, mode)        # 仅在安全包络内换模态
    M.vqa_i.submit_async(M.cache.age, M.cae.k_eff_estimate(), M.partition_flag)
    return k, lam, mode
```

## 4. 推导

**引理 19（延迟单调性与盈亏平衡 τ*）** DVoI 关于期望延迟单调不增；成本为正时存在有限 τ*，超过后 DVoI<0。R69 的 VoI 是 L=δ_0 的退化边界；可消歧集合随延迟单调收缩。

**引理 20（相关源塌缩）** k 个源两两相关 ρ̄ 时 `k_eff ≤ 1+(k−1)(1−ρ̄)`；错误采纳率 ≤ `δ_p·ρ̄^{k_eff−1}+ε_σ`；ρ̄→1 时退回单源。规模化必须绑定独立故障域。

**引理 21（陈旧证据上界）** 年龄 Δ>τ_v 的证据满足 `H(M|o_t,e_stale) ≥ H(M|o_t)−I(M;o_{t_e})`；陈旧证据最多回到生成时刻价值，不能单独定案。

**定理 18（严格包含链 TIDE ≻ FLUID ≻ R68）** 零延迟、单节点、证据独立、无分区、τ_v=∞ 时，DVoI≡VoI、TSL≡FLUID 单环、HBA≡本地、SAF/CAE 恒等 ⇒ 逐指令等于 FLUID；再当 VoI≤成本时逐指令等于 R68。安全不让步，仅在「来得及且独立」时获得 resolution bonus。

**定理 19（期限安全与非阻塞）** 快环延迟只由本地计算与缓存决定，上界不随 N、K、L 增长；输出恒为 C-RAS-WM 认证前缀，风险 ≤ R68 同状态保守策略；证据未到则 λ 单调不降退化 R68；证据到达后合并只在安全包络内改模态，提交/换装不变式（R68 定理 15）保持。

**定理 20（规模复杂度）** 每轮总计算 `N·c_0+αN·c_1`，广域消息 O(N)（每节点平均 O(1)），非 O(N²)；故障域数 D 有界时 `k_eff≤D`，冗余收益与 N 脱钩。可扩展性的正确度量是「每节点常数消息 + 升级子集线性」。

**定理 21（相关故障下的安全—效率权衡）** 当 ρ̄≥ρ_max 使 k_eff<k_min 时，FAC 拒绝群体标定、CAE 拒绝多源定案，系统安全单调地退回本地 R68；代价是放弃依赖独立证据的 resolution bonus。高相关环境下的收益上界由结构性多样性而非节点数量决定。

## 7. 本轮最大风险

**一句话**：TIDE-RAS 的全部收益押在「延迟/相关性可估、且规模带来独立证据」这一前提上——**若延迟被重尾或对手拖长、节点故障高度相关（或时钟被伪造），DVoI 会系统性低估求证价值而漏掉可解歧义，联邦校准与多源定案则会给出「N 个回声互相作证」的虚假共识；系统不是算不动，而是整个机队以更高置信度一起问错、一起盖章——R69 把「诚实的不知道」升级成「被证实的错误」，R70 则可能把它升级成「被分布式共识证实的错误」**。

**次级风险与缓解**：重尾延迟致 deadline 误判（P99/尾部分布定价 + E301/E302）；相关故障/女巫制造虚假共识（k_eff + N_eff 拒绝门 + E306/E313，宁可退 R68）；陈旧证据绕过纪律（SAF 有效期硬过滤 + 引理 21 + 证书记录年龄）；快环被慢环/通信挤占（TSL 硬隔离 + 消息优先级 + E309）；分区期各自为政（DMG 冻结 + λ 退化 R68 + 重连对账 + E308）。
