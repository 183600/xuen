# 第 66 轮（承接第 65 轮「VISTA 视觉知情安全时序归因」IP-214~223；灵感循环（本轮标注）第 2 轮；本轮灵感：「多任务学习」×「数据集」）

> 第 65 轮把「几何可证伪」推进到「故障可归因」，其自述的最大风险是：**故障假设集有限、且视觉与几何的失效相互独立**这两个隐藏前提一旦不成立，FIR 会把未知复合故障强行归入最近假设、只膨胀错误的球，系统还会因为「已经归因」而更自信地继续执行。本轮不再增加模态，也不继续细分故障类型，而是追问一个更根上的问题：**这些归因似然 `p(ρ|H)` 与这些 conformal 界，到底是从哪份数据集里学出来、又能推广到哪些任务？** 本轮核心命题是：
>
> **把「单任务的故障归因」升级为「跨任务可迁移、且由数据集覆盖度背书的故障归因」：用多任务学习的共享-稀疏结构让罕见故障签名跨任务复用，用任务分层 conformal 与数据覆盖账本保证证书在多任务部署下仍然成立，用数据集主动采集把「安全证据的缺口」而非「模型精度」作为下一批数据的采集目标，并在共享有害时显式退回任务专用头。**

## 0. 直觉与动机

**灵感 1（多任务学习 → 故障签名是可共享的低维因子，但负迁移是新的单点故障）**
直觉：第 65 轮的 FIR 假设每类故障都有一个足够大的离线标定集。但真实机器人是多任务部署——钉孔、擦拭、堆叠、插拔，**同一个 F/T 零力窗 DC 偏置、同一种几何幻觉造成的接触斑落点冲突、同一种软接触的「轻触正常、加载后偏离」**，在不同任务里长得非常像。因此故障签名不是每个任务各学一套，而是若干**共享的低维故障因子**（偏置方向、几何偏移、模型刚度误差、视觉污染）在不同任务上的实例化。多任务学习可以让数据稀缺的罕见故障「借用」高资源任务的统计强度，实现 few-shot 故障归因。但多任务学习的经典失败是**负迁移 / 任务干扰**：共享参数被高资源任务主导，低资源任务的判别方向被投影掉。在安全语境下这比"精度低"更糟——模型会**自信地归错因**，VISTA 便只膨胀错误的球。故共享必须由**任务条件可辨识性**门控，而不是由平均精度决定。

**灵感 2（数据集 → 证书的根不是模型，而是标定数据）**
直觉：第 65 轮的 conformal 保证（`q_vis(α)`、`α_chunk`、`δ_fi`）本质是**对可交换样本**的承诺，不是对模型参数的承诺。多任务部署意味着许多任务分层，把各任务混成一个池子做标定，少数/稀有任务会被系统性欠覆盖，而证书表面看不出来。还需要防两件数据层的事：(i) **数据泄漏**——多任务预训练语料与 conformal 标定集重叠，可交换性被破坏；(ii) **共享语料投毒**——一个被污染的共享样本会同时污染所有任务的归因，这是比单任务传感器故障更深的共因失效。因此必须把「这个任务-故障组合有多少有效标定数据」作为一等安全资产记账。

**灵感 3（合流 → 共享但不混池：TANDEM）**
直觉：多任务学习解决「样本不够」，数据集视角解决「保证不成立」，二者必须同时用、且相互约束。命名 **TANDEM（Task-AwareNested Data-Exchangeability & Multi-task fault attribution，任务感知、数据集背书的可迁移故障归因）**。它不是把 VISTA 换成一个大模型，而是给 VISTA 的每个归因/证书加两层结构：**共享-稀疏的故障表示**（省样本）+ **任务分层的校准与覆盖账本**（保有效）。原则一句话：**共享表示可以借力，但不能借掉每个任务自己的可辨识性与覆盖性。**

**灵感 4（TANDEM 闭环）**
任务身份识别 τ̂ → 共享-稀疏故障编码 MTF → 任务条件 FIR 后验 `P(H|ρ,τ)` → 任务条件可辨识性/负迁移守卫 TCI/NTG（不行就退回任务专用头）→ 任务分层 conformal 查表 MSCon → 定向球增第四项 `r_task`（RSC-T）→ 任务分层技能规划 CSP-T → 任务条件认证前缀 CSC-T（只执行 k* 步）→ 带溯源执行落账 → 覆盖账本 DCL → 数据集主动采集 DAL → 数据/投毒对抗认证 AIC-D → `J_tandem`。与第 65 轮相比，新增的不是第 5 个模态，而是**"证据从哪来、能覆盖到哪个任务"的元层**。

**灵感 5（VISTA 组件的原位升级）**
- **FIR → MTF-FIR**：故障似然从"每任务独立拟合"改为"共享因子 + 任务实例化"的分层模型；用经验贝叶斯在共享先验与任务似然间收缩。
- **VCV / VPG 不变**，但其 conformal 界 `q_vis(α)` 改为**按任务分层** `q_vis,τ(α)`；无该任务标定时不得复用他任务界。
- **AFA → AFA-D 双预算**：测试时的物理探针（力预算）与训练时的数据探针（采集预算）统一成一个"证据缺口"框架；探针目标从"降低故障假设熵"扩展到"降低**任务分层证书风险**"。
- **RSC-V → RSC-T**：在 `r_geo/r_force/r_model` 之外增加 `r_task`（由迁移间隙 γ_τ 与覆盖债决定），只膨胀真正缺证据的那一项。
- **CSP-V → CSP-T**：技能图按任务分层，跨任务复用技能须同任务族且 `J_tandem` 有效。
- **CSC → CSC-T**：认证前缀用任务条件 `q_τ` 与 `α_chunk,τ`；任务未覆盖时 `k*=0` 直接 safe_idle，而不是拿别的任务的界硬撑。
- **AIC-V → AIC-D**：干扰集增共享语料投毒、标签噪声、重复样本泄漏、任务身份伪装；显式建模"一次坏、全任务坏"的数据共因。
- **J_vista → J_tandem**：证书增加 task_id、task_posterior、transfer_gap、κ_fi(τ)、coverage_sig、calib_prov_hash、nt_flag、ood_task、aic_d_ver。

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（TANDEM 闭环）**：TANDEM = (VISTA, MTF, TCI/NTG, MSCon, DCL, DAL, RSC-T, CSP-T, CSC-T, AIC-D, J_tandem)。定位：VISTA 的"跨任务可迁移 + 数据集背书"升级。不变式：**多任务训练、覆盖账本、数据采集、分层校准只发生在离线/语义流；实时流与第 65 轮完全一致（只读冻结的任务分层查表），零学习写操作。**
- **定义 234（任务族与任务身份）**：任务 τ ∈ 𝒯，τ=(技能族, 物体类, 接触模式)。任务描述子 d_τ；部署时由上下文得任务后验 p(τ|x)。若 τ∉𝒯 或任务后验最大质量 < 1−δ_τ，则置 `ood_task`，禁止跨任务证书复用。
- **定义 235（分层故障签名模型）**：故障签名 `ρ_τ = S_τ θ + ε`，其中 `S_τ = S_0 + U_τ V_τᵀ`，`S_0` 为跨任务共享签名子空间，`U_τV_τᵀ` 为秩 ≤r_max 的任务残差。定义**迁移间隙** `γ_τ = ‖Δ_τ‖_F / ‖S_τ‖_F`，`Δ_τ=S_τ−S_0`；定义任务相关度为共享子空间与任务子空间的主夹角余弦 `cos∠(S_0,S_τ)`。
- **定义 236（任务条件可辨识性与负迁移守卫 TCI/NTG）**：任务 τ 的有效 Fisher 信息 `J_fi(τ)=S_τᵀΣ_{ρ,τ}⁻¹S_τ`，可辨识裕度 `κ_fi(τ)=λ_min(J_fi(τ))/λ_max(J_fi(τ))`。共享允许 ⇔ `κ_fi(τ)≥κ_min` ∧ `γ_τ≤τ_transfer` ∧ 任务标定覆盖达标。否则 `nt_flag=True`，**退回任务专用头**（不共享），并拒绝用共享头解释该任务的反常残差。
- **定义 237（数据集覆盖账本 DCL）**：标定语料 `D={(τ_i,H_i,ρ_i,prov_i)}`，`prov_i` 为溯源（采集批次/预训练来源/去重哈希）。覆盖矩阵 `C[τ,H]=n_eff(τ,H)`，`n_eff` 为多样性加权有效样本数（如按签名协方差行列式或聚类熵折算）。**覆盖债** `Debt_cov=Σ_{τ,H} w_{τ,H}·max(0, n_req(α,δ_fi)−n_eff(τ,H))`；覆盖率签名 `coverage_sig=hash(C)`。硬约束：`train∩calib=∅`（按 prov 哈希校验），否则该单元视为不可用于证书。
- **定义 238（任务分层 conformal MSCon）**：对每个任务 τ 独立取非一致性分数 `s_i`，`q_τ(α)=⌈(n_τ+1)(1−α)⌉/n_τ` 分位数，`P[e≤q_τ(α)]≥1−α` 仅在同一任务层的可交换样本上成立。**禁止跨任务池化**；若确需池化，必须用任务密度比 `w_τ(x)` 做加权 conformal，且覆盖损失随任务间 TV 距离显式增大（见引理 9）。`n_eff(τ,H)<n_req` 时输出 `coverage_insufficient`，不得签发该任务的证书。
- **定义 239（多任务故障归因 MTF-FIR）**：`p(ρ|H,τ)` 由分层生成模型给出；经验贝叶斯收缩 `p_shrunk(ρ|H,τ) ∝ p(ρ|H,τ)^{n_eff/(n_eff+λ_τ)} · p_shared(ρ|H)^{λ_τ/(n_eff+λ_τ)}`，收缩权重 `λ_τ = exp(−γ_τ/γ_0)·n_shared·ρ_corr`，即**迁移间隙越大、任务相关度越低，越不收缩**。后验 `P(H|ρ,τ) ∝ p_shrunk(ρ|H,τ)P(H)`；`max_H<1−δ_fi` 时仍走 ambiguous/AFA，规则同第 65 轮。
- **定义 240（任务分层证书与降级）**：`Valid(J_tandem) ⇔ Valid(J_vista) ∧ (τ 已覆盖 ∨ 明确 nt_flag 且已退回专用头) ∧ 任务身份非 OOD ∧ 迁移间隙与 κ_fi(τ) 在证书声明范围内`。**未覆盖任务不得借用他任务界**；只能退化为任务无关的保守联合膨胀（`r_task=∞` 的有限版本：以 r_max 截断）+ `safe_idle`，并显式写 `coverage_insufficient`。
- **定义 241（数据集主动采集 DAL）**：采集单元 `u=(τ,H,cost)`；目标不是提升平均精度，而是最小化**证书缺口**：`u* = argmax_u ΔRisk_cert(u)/cost_u`，其中 `ΔRisk_cert` 为对最坏任务分层误覆盖率或覆盖债的期望下降。覆盖债函数在单元可加意义下近似次模，贪心给 `(1−1/e)` 近似。**关键单元** = 低覆盖 × 高先验风险 × 高下游使用频率。
- **定义 242（RSC-T 任务感知球校准）**：`r = √(r_geo²+r_force²+r_model²+r_task²)`，`r_task ∝ γ_τ·(1+Debt_cov,τ/n_req)`。只膨胀被归因且被覆盖债/迁移间隙真正削弱的项；H_force 仍不降级几何，H_geo 仍不怀疑已标定力传感。
- **定义 243（CSP-T 任务分层规划）**：技能图为 τ 分层；每条块边需 Valid(J_tandem,τ) 且 `k*≥1`。跨任务复用技能 σ 需 (i) 同任务族，(ii) σ 的块签名到目标任务的 Mahalanobis 距离 ≤τ_chunk，(iii) 目标任务覆盖达标；否则插入 `null_test/visual_probe/fi_probe` 或专用元技能。
- **定义 244（CSC-T 任务条件认证前缀）**：用 `q_τ` 与 `α_chunk,τ` 选最小 `k*`，`k*≤m_τ`；任务覆盖不足时 `k*=0`（safe_idle）或退到 `k*=1` 且降低力限。执行 k* 步后强制重规划与重归因。
- **定义 245（AIC-D 数据/投毒对抗认证）**：干扰集 `ℰ_D = ℰ_V × ℰ_poison × ℰ_leak × ℰ_task`；`ℰ_poison` 含共享语料投毒/标签翻转/重复样本，`ℰ_leak` 含预训练-标定泄漏，`ℰ_task` 含任务身份伪装/混合任务。最坏情形按"共享污染同时影响所有任务"计算；共因下不要求归因正确，只要求**每个受影响任务都被判 coverage/ambiguous 并降级**。
- **定义 246（TANDEM 证书 J_tandem）**：`J_tandem=(J_vista, task_id, task_posterior, transfer_gap γ_τ, κ_fi(τ), coverage_sig, calib_prov_hash, nt_flag, ood_task, coverage_insufficient, aic_d_ver)`。Valid 规则见定义 240；审计链新增："这个任务凭什么可用共享证据"、"这份证书用的是哪批标定数据"。
- **定义 247（任务身份与混合任务处理）**：任务后验 `p(τ|x)` 由上下文特征给出；若为多任务混合且无单任务质量 ≥1−δ_τ，则对后验做**任务边缘化**（按 p(τ) 加权最坏情形），并置 `mixed_task=True`，只允许任务无关保守处置。
- **定义 248（TANDEM 闭环算子）**：语义流 [VISTA 全链 → 任务识别 τ̂ → MTF 共享-稀疏签名 → MTF-FIR → TCI/NTG → MSCon 分层查表 → DCL 记账 → RSC-T → CSP-T → CSC-T → 执行 → 溯源落账 → DAL 采集决策 → AIC-D]；实时流 [同 VISTA：视觉/力残差采集→阶段判定→CSC-T 早停→前缀派发→J_tandem 构建（仅读冻结查表）]。

## 2. 关键算法骨架

```python
# 任务分层归因 + 负迁移守卫（语义流）
tau, p_tau = infer_task(context)
if tau not in T or p_tau[tau] < 1 - delta_tau:
    return conservative_no_transfer(reason="ood_task")

rho = signature(phases)
if not dcl.covered(tau):                       # 覆盖不足：禁止跨任务借界
    return conservative_no_transfer(reason="coverage_insufficient")

S_tau = mtf.shared_S0 + mtf.task_residual(tau)  # S_0 + U_tau V_tau^T
gamma = mtf.transfer_gap(S_tau, mtf.shared_S0)
kappa = identifiability_margin(S_tau, Sigma_rho[tau])
if gamma > TAU_TRANSFER or kappa < KAPPA_MIN:
    nt_flag = True
    post = fir.attribute_task_specific(rho, tau)     # 退回专用头
else:
    post = fir.attribute_shrunk(rho, tau, n_eff=dcl.n_eff(tau),
                                lam=shrink_weight(gamma, corr(tau)))
    nt_flag = False

# 分层 conformal 与任务条件前缀
q_tau = mscon.quantile(tau, alpha)
k_star = csc_t.certified_prefix(A, post, m_tau, alpha_chunk_tau, q_tau)
if k_star == 0:
    return safe_idle(coverage_sig=dcl.sig(tau))

# 数据集主动采集（离线/低频）：补证书缺口，而不是补精度
u_star = dal.choose_unit(dcl, w_risk, cost)     # argmax ΔRisk_cert / cost
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（任务分层 conformal 的必要性）**：若把任务按权重 `w_τ` 混池，池化分位数 `q_pool` 对任务 τ 的实际误覆盖率满足 `P_τ[e>q_pool] ≥ (1−α−(1−w_τ)TV(P_τ,P_¬τ))/w_τ` 的量级下界；因此当 `w_τ` 小或尾部差异大时，池化会**静默欠覆盖**少数任务。任务分层 `q_τ` 恢复每任务 `≥1−α`，代价是 `n_eff(τ)≥n_req` 的样本要求。
- **引理 10（共享-稀疏的迁移收益与负迁移界）**：在 `S_τ=S_0+Δ_τ`、`‖Δ_τ‖≤γ_τ·‖S_τ‖` 下，`κ_fi(τ) ≥ κ_0 − O(γ_τ/sep)`；经验贝叶斯收缩的有效样本量 `n_eff = n_τ + λ_τ n_shared`，归因后验误差 `≤ exp(−n_eff·κ_fi(τ)/2)`。当 `γ_τ` 超过 `τ_transfer`，收益项被负迁移项压过，最优策略是 `λ_τ→0`（退回专用头）。这给出"共享但不混池"的严格条件。
- **定理 9（TANDEM 跨任务归因-安全）**：在 A94–A98 下，对已覆盖任务，`Valid(J_tandem)` ⇒ 归因在任务层内正确或显式 ambiguous、每任务覆盖 ≥1−α、负迁移被守卫、安全性与 VISTA 相同；对未覆盖/OOD/混合任务，**不得签发可迁移证书**，只能保守降级，故不会出现"跨任务借来的假保证"。
- **定理 10（数据集采集的近最优性）**：以覆盖债/最坏任务误覆盖率为目标的采集函数近似次模，贪心达 `(1−1/e)`；以证书缺口为目标的采集在稀有任务上的收敛快于以平均精度为目标。
- **实时性**：TANDEM 新增计算全在离线/语义流；实时流只多一次任务分层查表（O(1)）与 `k*` 早停，目标仍 ≤2.5ms（A99 修订契约）。

## 5. 本轮最大风险

## 2. 形式化定义（完整版）

**定义 233（TANDEM 闭环）** TANDEM 是 VISTA 的"跨任务可迁移 + 数据集背书"升级：在 VISTA 的语义流/实时流骨架上挂载 MTF（共享-稀疏故障编码）、TCI/NTG（任务条件可辨识性与负迁移守卫）、MSCon（任务分层 conformal）、DCL（数据覆盖账本）、DAL（数据集主动采集），并原位升级 RSC-V→RSC-T、CSP-V→CSP-T、CSC→CSC-T、AIC-V→AIC-D、J_vista→J_tandem。不变式：**多任务训练、分层校准、覆盖记账、数据采集只发生在离线或语义流；实时路径与第 65 轮一致，只读冻结的任务分层查表，零学习写操作。**

**定义 234（任务族与任务身份）** 任务 `τ=(skill_family, object_class, contact_mode) ∈ 𝒯`。部署时由上下文（指令、物体、历史技能）得任务后验 `p(τ|x)`。若 `τ∉𝒯` 或 `max_τ p(τ|x) < 1−δ_τ`，置 `ood_task=True`，**禁止任何跨任务证据/证书复用**。若任务后验分散在多个任务且无单点达标，置 `mixed_task=True`，只按任务边缘化做最坏情形。

**定义 235（分层故障签名模型）** 设故障幅度 `θ`，任务 τ 的签名
`ρ_τ = S_τ θ + ε`，`ε∼N(0,Σ_{ρ,τ})`，`S_τ = S_0 + U_τ V_τᵀ`，
其中 `S_0∈ℝ^{15×d_H}` 为跨任务共享签名子空间，`U_τ∈ℝ^{15×r}`、`V_τ∈ℝ^{d_H×r}`，`rank(U_τV_τᵀ)≤r_max`。迁移间隙
`γ_τ = ‖Δ_τ‖_F / ‖S_τ‖_F`，`Δ_τ=U_τV_τᵀ`；
任务相关度 `corr(τ)=cos∠(span(S_0), span(S_τ))`。直觉：`S_0` 承载"偏置/几何偏移/模型误差在多数任务中共有的方向"，`Δ_τ` 承载任务特有方向；`γ_τ` 小则可借力，大则负迁移。

**定义 236（任务条件可辨识性与负迁移守卫 TCI/NTG）** 任务有效 Fisher 信息
`J_fi(τ)=S_τᵀ Σ_{ρ,τ}⁻¹ S_τ`，`κ_fi(τ)=λ_min(J_fi(τ))/λ_max(J_fi(τ))`。
共享判定：
`share(τ) ⇔ κ_fi(τ)≥κ_min ∧ γ_τ≤τ_transfer ∧ n_eff(τ,H)≥n_req(α,δ_fi) ∀ 需归因 H`。
不满足则 `nt_flag=True`，**退回任务专用头** `S_τ`（不做任何跨任务收缩），且禁止用共享头解释该任务的反常残差。负迁移运行期监测：若 `|p_shared(H|ρ)−p_specific(H|ρ)|` 在已知覆盖任务上系统偏离且共享头更自信，熔断共享头并写入 `J_tandem`。

**定义 237（数据集覆盖账本 DCL）** 标定语料 `D={(τ_i,H_i,ρ_i,prov_i)}`，`prov_i` 记录采集批次、预训练来源、去重哈希、标注者/仿真版本。覆盖矩阵 `C[τ,H]=n_eff(τ,H)`，`n_eff` 为多样性加权有效样本：`n_eff = (Σ_i w_i)² / Σ_i w_i²`（Kish 有效样本），`w_i` 按签名聚类/去重核权。覆盖债
`Debt_cov = Σ_{τ,H} w_{τ,H} · max(0, n_req(α,δ_fi) − n_eff(τ,H))`，
`w_{τ,H}` 由故障先验风险与下游任务使用频率给出。硬约束：`train ∩ calib = ∅`（按 `prov` 哈希校验）、`calib` 内部去重；任一违反则该单元标 `unusable`，不得签发证书。

**定义 238（任务分层 conformal MSCon）** 对任务 τ，非一致性分数 `s_i`（如 `e_vis`、`e_force` 或块安全裕度负部），
`q_τ(α)=s_{(⌈(n_τ+1)(1−α)⌉)}`（第该序位）。
在同一任务层可交换样本上 `P[e≤q_τ(α)]≥1−α`。**禁止跨任务池化**；若必须池化，需用任务密度比 `w_τ(x)=dP_τ/dP_pool` 做加权 conformal，且覆盖损失随任务间 TV 距离增大（引理 9）。`n_eff(τ,H)<n_req` 时输出 `coverage_insufficient`，不得签发该任务该故障的证书。

**定义 239（多任务故障归因 MTF-FIR）** 分层似然 `p(ρ|H,τ)` 由定义 235 生成。经验贝叶斯收缩：
`p_shrunk(ρ|H,τ) ∝ p(ρ|H,τ)^{n_τ/(n_τ+λ_τ)} · p_shared(ρ|H)^{λ_τ/(n_τ+λ_τ)}`，
`λ_τ = n_shared·corr(τ)·exp(−γ_τ/γ_0)`。
直觉：本任务样本多（`n_τ` 大）或迁移间隙大（`γ_τ` 大）→ 越少收缩到共享先验；反之罕见故障可借 `n_shared`。后验
`P(H|ρ,τ) ∝ p_shrunk(ρ|H,τ) P(H)`；
`max_H P(H|ρ,τ) < 1−δ_fi` 时仍按第 65 轮进入 ambiguous/AFA，规则不变。

**定义 240（任务分层证书与降级）**
`Valid(J_tandem) ⇔ Valid(J_vista) ∧ τ 已覆盖 ∧ (γ_τ≤τ_transfer ∧ κ_fi(τ)≥κ_min ∨ nt_flag=True 且已退回专用头) ∧ ¬ood_task ∧ γ_τ、κ_fi(τ) 落在证书声明范围`。
**未覆盖任务不得借用他任务界**：只能退化为任务无关保守处置——`r_task` 取截断上界、`k*=0`、`safe_idle`，并显式写 `coverage_insufficient`。混合任务按 `p(τ|x)` 边缘化取最坏，且只允许任务无关处置。

**定义 241（数据集主动采集 DAL）** 采集单元 `u=(τ,H,cost_u)`，其中 `cost_u` 为采集/标注/仿真成本。目标不是平均精度，而是**证书缺口**：
`u* = argmax_u E[ΔRisk_cert(u)] / cost_u`，
`Risk_cert = Σ_τ w_τ · P_τ[证书失效]`，近似用 `Debt_cov` 与最坏任务误覆盖率的减少量。覆盖债在可加采集下单调、边际递减（次模），贪心达 `(1−1/e)`。**关键单元** = 低覆盖 × 高故障先验 × 高下游频率。与 AFA 统一：AFA 花**力预算**降测试时假设熵，DAL 花**采集预算**降训练时覆盖债；两者都是"用最小代价换最多可辨识性"。

**定义 242（RSC-T 任务感知球校准）** `r=√(r_geo²+r_force²+r_model²+r_task²)`，
`r_task = r_0 · (γ_τ/τ_transfer) · (1 + Debt_cov,τ/n_req)`，并截断 `r_task≤r_max`。
只膨胀被归因且被迁移间隙/覆盖债真正削弱的项：H_force 仍不降级几何，H_geo 仍不怀疑已标定力传感。任务已覆盖且 `γ_τ` 小 → `r_task≈0`，不额外保守。

**定义 243（CSP-T 任务分层规划）** 技能图按 τ 分层；块边需 `Valid(J_tandem,τ)` 且 `k*≥1`。跨任务复用技能 σ 需三条同时成立：(i) 同任务族；(ii) σ 的块签名到目标任务分布 Mahalanobis 距离 ≤τ_chunk；(iii) 目标任务覆盖达标。否则插入 `null_test`（零力窗标定）、`visual_probe`、`fi_probe` 或任务专用元技能。代价增 `λ_cov·Debt_cov,τ + λ_nt·1[nt_flag]`。

**定义 244（CSC-T 任务条件认证前缀）** 用 `q_τ`、`α_chunk,τ` 选最小
`k* = min{k≤m_τ : P_τ[∃s≤k, 通道越界] ≤ α_chunk,τ}`。
任务覆盖不足时 `k*=0`（safe_idle）或 `k*=1` 且降力限；不得用他任务 `q` 硬撑。执行 k* 步后强制重规划与重归因。

**定义 245（AIC-D 数据/投毒对抗认证）** 干扰集
`ℰ_D = ℰ_V × ℰ_poison × ℰ_leak × ℰ_task`；
`ℰ_poison`：共享语料投毒、标签翻转、重复样本、近重复污染；`ℰ_leak`：预训练-标定泄漏、模板泄漏；`ℰ_task`：任务身份伪装、对抗性混合任务。最坏情形按"共享污染同时影响所有任务"计算；共因下**不要求归因正确**，只要求每个受影响任务被 `coverage_insufficient/ambiguous` 捕获并降级。`n_cert 128→160`（其中 32 给数据层）；`J_dir` 增 `data_prov_ver`、`task_strata_ver`。

**定义 246（TANDEM 证书 J_tandem）** 如符号表；Valid 规则见定义 240。审计链新增三问：**"这个任务凭什么可用共享证据？"（γ_τ, κ_fi(τ), nt_flag）**、**"这份证书用的是哪批标定数据？"（calib_prov_hash, coverage_sig）**、**"该任务是否真的被数据覆盖？"（coverage_insufficient）**。

**定义 247（任务身份与混合任务处理）** 任务后验 `p(τ|x)`；若 `max_τ<1−δ_τ` 则 `mixed_task/ood_task`。混合任务下对 `P(H|ρ,τ)` 与 `q_τ` 按 `p(τ|x)` 做边缘化最坏：`q_mix = max_{τ:p(τ|x)>δ_τ} q_τ`，`r_task` 取最大，`k*` 取最小；只允许任务无关保守处置，不签发单任务可迁移证书。

**定义 248（TANDEM 闭环算子）** 语义流：[VISTA 全链 → 任务识别 τ̂ → MTF 共享-稀疏签名 → MTF-FIR → TCI/NTG → MSCon 分层查表 → DCL 记账 → RSC-T → CSP-T → CSC-T → 执行 → 溯源落账 → DAL 采集决策 → AIC-D]；实时流：[同 VISTA：视觉/力残差采集 → 阶段判定 → CSC-T 早停 → 前缀派发 → J_tandem 构建（仅读冻结查表）]。

### IP-224/225 MTF + TCI/NTG（任务分层归因）

```python
class MultiTaskFaultEncoder:
    """S_tau = S0 + U_tau V_tau^T；共享借力，迁移间隙门控。"""
    def signature_matrix(self, tau):
        return self.S0 + self.U[tau] @ self.V[tau].T

    def transfer_gap(self, tau):
        d = self.U[tau] @ self.V[tau].T
        return np.linalg.norm(d) / (np.linalg.norm(self.signature_matrix(tau)) + 1e-9)

    def shrink_weight(self, tau, n_eff, corr):
        return self.n_shared * corr * np.exp(-self.transfer_gap(tau) / self.gamma0) \
               if n_eff > 0 else 0.0


class IdentifiabilityGuard:
    def allow_share(self, tau, S_tau, Sigma_rho, coverage_ok):
        J = S_tau.T @ np.linalg.inv(Sigma_rho) @ S_tau
        lam = np.linalg.eigvalsh(J)
        kappa = lam.min() / (lam.max() + 1e-12)
        gamma = self.mtf.transfer_gap(tau)
        return (kappa >= self.kappa_min and gamma <= self.tau_transfer
                and coverage_ok), kappa, gamma


class MultiTaskFIR:
    def attribute(self, rho, tau, n_eff, coverage_ok):
        S_tau = self.mtf.signature_matrix(tau)
        ok, kappa, gamma = self.guard.allow_share(tau, S_tau, self.Sigma[tau], coverage_ok)
        if not ok:
            lik = self.task_specific_lik[tau]          # 退回专用头，不收缩
            nt_flag = True
        else:
            lam = self.mtf.shrink_weight(tau, n_eff, self.corr[tau])
            lik = lambda rho: self._shrink(self.task_lik[tau](rho),
                                           self.shared_lik(rho), n_eff, lam)
            nt_flag = False
        post = self._posterior(lik, rho)
        return post, nt_flag, kappa, gamma
```

### IP-226/227 MSCon + DCL（分层校准与覆盖记账）

```python
class MondrianConformal:
    def __init__(self, alpha, delta):
        self.alpha, self.delta = alpha, delta
        self.q = {}                                     # tau -> quantile

    def fit(self, D, score_fn):
        for tau, rows in group_by_task(D):
            n = len(rows)
            if n < self.n_req(n):
                self.q[tau] = None                      # 覆盖不足，拒绝签发
                continue
            s = np.sort([score_fn(r) for r in rows])
            self.q[tau] = s[min(n - 1, int(np.ceil((n + 1) * (1 - self.alpha))) - 1)]

    def quantile(self, tau):
        if self.q.get(tau) is None:
            raise CoverageInsufficient(tau)
        return self.q[tau]


class DatasetCoverageLedger:
    def __init__(self, n_req, w_risk):
        self.n_req, self.w_risk = n_req, w_risk

    def n_eff(self, tau, H):
        w = self.weights(tau, H)                        # 去重/聚类核权
        return (w.sum() ** 2) / (np.sum(w ** 2) + 1e-12) # Kish 有效样本

    def debt(self, tau=None):
        cells = [(t, h) for t in self.tasks for h in HYP] if tau is None else \
                [(tau, h) for h in HYP]
        return sum(self.w_risk[t, h] * max(0.0, self.n_req - self.n_eff(t, h))
                   for t, h in cells)

    def covered(self, tau):
        return (self.debt(tau) == 0.0
                and self.provenance_disjoint(tau)        # train ∩ calib = ∅
                and not self.flagged_unusable(tau))
```

```python
        best, best_gain = None, -np.inf
        for u in candidates:                            # u = (tau, H, cost)
            p = dcl.coverage_prob(u.tau, u.H)            # 当前覆盖达标概率
            gain = dcl.w_risk[u.tau, u.H] * (1.0 - p)    # 缺口期望下降
            gain += self.worst_task_bonus(u.tau)         # 优先补最坏任务
            if gain / u.cost > best_gain and u.cost <= budget:
                best, best_gain = u, gain / u.cost
        return best, best_gain
```

```python
def rsc_t_update(balls, tau, gamma, debt_ratio, kappa):
    balls['r_task'] = min(R_MAX, R0 * (gamma / TAU_TRANSFER) * (1.0 + debt_ratio))
    return balls


def certified_prefix_t(A, post, tau, m_tau, alpha_chunk_tau):
    q_tau = mscon.quantile(tau)                          # 未覆盖则抛异常
    top = top_hypotheses(post, 2)
    k_best = 0
    for k in range(1, min(len(A), m_tau) + 1):
        if any(safety_margin(A[s], h, q_tau) < 0
               for h in top for s in range(k)):
            break
        if violation_prob_task(A[:k], top, tau) <= alpha_chunk_tau:
            k_best = k
        else:
            break
    return k_best                                        # 未覆盖 -> 0 -> safe_idle
```

```python
def TANDEM_round(M, obs, delta_f_req, context):
    V, T, P, L, P_cloud, W_meas, tactile, img, depth, flow = obs
    # ---- 任务识别与覆盖门控 ----
    tau, p_tau = M.task_id.infer(context)
    if tau not in M.T or p_tau[tau] < 1 - M.delta_tau:
        return conservative_no_transfer(M, reason='ood_task')
    coverage_ok = M.dcl.covered(tau)
    if not coverage_ok:
        return M.safe_idle(coverage_insufficient=True,
                           coverage_sig=M.dcl.sig(tau))

    # ---- 语义流：与 VISTA 相同的前端 ----
    M.lsf.update_geometry(P_cloud)
    x_prime = M.lsf.fuse(M.usr.fuse(V, T, P, L))
    y_vis = M.f_vis(img, depth, flow)
    phi_hat_geo, *_ = M.mel.infer_by_mode(M.ocb_skill.choose().mel_mode,
                                          V, T, P, L, x_prime)
    A = M.ach.propose(x_prime, H=M.H)
    visual = M.vpg.verify_and_predict(y_vis, A, M.mws.last_contacts)

    # ---- 共享-稀疏归因 + 负迁移守卫 ----
    phases = M.stage.split(M.residual_log, visual)
    post, nt_flag, kappa, gamma = M.mtf_fir.attribute(
        M.fir.signature(phases), tau, M.dcl.n_eff(tau), coverage_ok)
    if nt_flag:
        post = M.mtf_fir.task_specific(M.fir.signature(phases), tau)
    if max(post.values()) < 1 - M.delta_fi:
        a, ig = M.afa.choose_probe(post, phi_hat_geo, M.f_safe, M.object_fragile)
        if a is not None:

            post, nt_flag, kappa, gamma = M.mtf_fir.attribute(
                M.fir.signature(phases), tau, M.dcl.n_eff(tau), coverage_ok)

    if max(post.values()) >= 1 - M.delta_fi:

            max(post, key=post.get), M.balls, M.w_vis, M.H)
    M.balls = rsc_t_update(M.balls, tau, gamma,
                           M.dcl.debt(tau) / M.dcl.n_req, kappa)

    # ---- 任务分层规划 + 任务条件认证前缀 ----
    goal = M.dms.parse_goal((M.usr.U_ep, M.usr.U_al))

    if k_star == 0:

    K_safe, EV_exec, cert_exec = realtime_step_vista(
        M, delta_f_req, tau_chunks, k_star, x_prime)

    # ---- 溯源落账 + 数据侧决策（离线/低频）----
    M.dcl.record(tau, phases, provenance=M.prov_now())
    M.olp.online_step(M.olp.fuse_evidence(x_prime, W_meas, tactile, visual, post),
                      execution_loss_grad(K_safe, EV_exec, M.balls))
    M.rsc_v.update(EV_exec, W_meas, phi_hat_geo, post, M.balls)

        coverage_insufficient=False, aic_d_ver=AIC_D_VERSION), u_star
```

## 4. 推导

**引理 9（任务分层 conformal 的必要性）** 设两任务 τ 与 ¬τ，分数分布 `P_τ,P_¬τ`，池化权重 `w=P(τ)`，池化分数分布 `P_pool=wP_τ+(1−w)P_¬τ`，池化分位数 `q_pool` 满足 `F_pool(q_pool)=wF_τ(q_pool)+(1−w)F_¬τ(q_pool)=1−α`。于是
`F_τ(q_pool) = (1−α) + ((1−w)/w)·((1−α)−F_¬τ(q_pool))`。
若另一任务在 `q_pool` 处累积分布更高（`F_¬τ(q_pool)>1−α`），则 τ 的实际覆盖低于 `1−α`，缺口
`1−α−F_τ(q_pool) = ((1−w)/w)·(F_¬τ(q_pool)−(1−α)) ≤ ((1−w)/w)·TV(P_τ,P_¬τ)`。
故任务权重越小或任务间尾部分布差越大，池化越会**静默欠覆盖**少数任务；任务分层 `q_τ` 在同一任务层可交换下恢复 `≥1−α`，代价是样本要求 `n_eff(τ)≥n_req`。这正是 VISTA 单池化 conformal 在多任务部署下失效的机制。∎

**引理 10（共享-稀疏的迁移收益与负迁移界）** 由 `S_τ=S_0+Δ_τ` 与 Weyl 不等式，
`λ_min(J_fi(τ)) ≥ λ_min(J_fi(0)) − ‖Δ_τ‖·(‖S_τ‖+‖S_0‖)·‖Σ_{ρ,τ}⁻¹‖`，
故 `κ_fi(τ) ≥ (λ_min(J_0)−cγ_τ)/(λ_max(J_0)+cγ_τ)`，在 `γ_τ < λ_min(J_0)/c` 时仍可辨识。经验贝叶斯收缩的等价后验精度约为 `n_τ + λ_τ`（高斯线性模型下后验精度可加），故归因误差满足
`P(错误归因) ≤ C·exp(−(n_τ+λ_τ)·κ_fi(τ)/2)`。
共享带来的样本增益约 `λ_τ n_shared`，但由 `γ_τ` 引入的均值偏移使有效分离度下降约 `γ_τ/sep`；当
`λ_τ n_shared·(γ_τ/sep)² > n_τ` 时负迁移项压过收益，最优 `λ_τ→0`。这给出 `τ_transfer` 的判定含义：**不是"任务像不像"，而是"借来的样本是否还能提升可辨识性"**。∎

**定理 9（TANDEM 跨任务归因-安全）** 在 A94–A98（任务分层可交换、覆盖达标、溯源不泄漏、迁移间隙有界、故障假设集在任务层内封闭）下：
1. **已覆盖任务**：由引理 9，`q_τ` 给出每任务 `≥1−α` 覆盖；由引理 10，`share(τ)` 为真时 `J_fi(τ)≻0`，归因后验集中；为假时退回专用头，仍保持第 65 轮的三阶段可辨识性。故归因正确或显式 ambiguous，且只膨胀被归因的球。
2. **证书有效性**：`Valid(J_tandem)` 蕴含 `Valid(J_vista)`、任务覆盖达标、负迁移被守卫，故 VISTA 的引理 7/8 与定理 7 的安全结论在任务层内继承。
3. **未覆盖/OOD/混合任务**：定义 240/247 拒绝签发可迁移证书，只能保守降级（`k*=0`/safe_idle），故不存在"借来的假保证"。
4. **数据共因**：若共享语料被投毒，AIC-D 要求受影响任务全部被 `coverage_insufficient/ambiguous` 捕获并降级；不要求归因正确性。
5. **审计性**：`J_tandem` 同时记录任务、迁移间隙、可辨识裕度、覆盖签名与标定溯源，任何"为什么敢共享"都可复核。∎

**定理 10（数据集采集的近最优性）** 设覆盖债 `F(S)=Σ_cells w_c·max(0, n_req−n_eff(S∩cell))`，`n_eff` 对所选单元可加或次可加。`max(0, n_req−·)` 关于覆盖量单调、凹，故每新增一个单元的边际收益递减；`F` 单调次模。贪心选择 `u*=argmax ΔF(u)/cost_u` 达 `(1−1/e)` 近似。若把目标换成最坏任务误覆盖率，其关于覆盖量同样单调递减且边际递减，贪心优势保持。故以"证书缺口"为目标的采集在稀有任务上收敛快于以平均精度为目标的采集。∎

**命题（覆盖债是证书失效的先行指标）** 在任务分层可交换且无泄漏的单元上，`n_eff≥n_req` 是 `q_τ` 达到 `1−α` 置信覆盖的必要样本条件；`Debt_cov>0` 的单元恰好是 `q_τ` 无法以目标置信度签发的单元。因此 `Debt_cov` 的下降与"证书可签发率"的上升同向，可作为数据采集的 dense reward，而不必等端到端失败。∎

## 8. 已知风险

**一句话**：TANDEM 的跨任务保证依赖"每个任务分层的标定语料足够、可交换、且未被共享预训练污染"这一前提；真实多任务数据集往往既不按任务均衡、又难以证明可交换性——一旦覆盖账本测错了总体、或共享语料被投毒/泄漏，系统会拿着**看似齐全的证书**在所有任务上同时失效，这比单任务失效更隐蔽、更系统性（A94）。

**次级风险与缓解**：
1. **覆盖账本本身是估计**：`n_eff` 与 `n_req` 都可能低估真实缺口（多样性、标注噪声、协变量漂移未计入）。缓解：报告置信下界、在线漂移检测触发重估、把 `Debt_cov` 当保守上界而非精确量。
2. **任务身份识别错误**：τ̂ 错会把任务路由到错误的 `q_τ`/专用头，产生"合法但错误"的证书。缓解：`p(τ|x)` 阈值 + 混合任务最坏边缘化 + 任务伪装进 `ℰ_task`；τ̂ 不确定时禁止迁移。
3. **负迁移守卫的代价**：过严的 `τ_transfer`/`κ_min` 使共享几乎不启用，退回单任务样本荒。缓解：把守卫阈值作为风险预算变量而非硬常数，按下游失效代价标定。
4. **共享语料投毒**：一个共享样本可同时污染所有任务，且投毒可能刻意落在"高覆盖"单元以绕过覆盖门。缓解：AIC-D 显式建数据共因、按来源隔离训练/标定、异常来源检测、对高杠杆共享样本做影响函数审计。
5. **数据泄漏与不可交换**：预训练语料与标定集重叠会破坏 conformal 覆盖，而泄漏往往不可见。缓解：`prov` 哈希硬约束、去重/近重复检测、必要时对 `q_τ` 做保守放大（代价是可用性）。
6. **罕见故障仍在假设集外**：多任务共享只解决"有假设但没样本"，不解决"假设根本没定义"。缓解：保留第 65 轮 ambiguous/高熵拒答，扩充故障库，把未知故障检测作为独立指标。
7. **任务分层样本要求与长尾冲突**：稀有任务 `n_eff<n_req` 会被直接判不可签发，导致"安全但不干活"。缓解：DAL 优先补这些单元；对低风险任务允许降级到 `k*=1` 的保守执行而非完全停机。
8. **实时预算**：CSC-T 查表与 RSC-T 很轻，但任务识别若放在实时流会吃掉预算。缓解：任务识别留在语义流，实时流只读冻结 `τ` 与 `q_τ`。
9. **多任务训练范式的隐含耦合**：共享编码器可能同时改变故障签名与视觉/力残差分布，使 `Σ_{ρ,τ}` 与 `S_τ` 的标定随训练版本漂移。缓解：签名与校准绑定模型版本号（`visual_calib_ver`、`task_strata_ver`），版本变更即失效重标定。
