# 第 73 轮（承接第 72 轮「EMBODIED-GAUGE-RAS 具身计量审计闭环」IP-287~294；本轮灵感：「长期记忆」×「自然语言指令」）

> R72 把 GAUGE 从「认知层」下沉到「具身层」：REG 实时执行图给出调度级时序保证，IRL 把意图 z 写进联合后验，DMEM 把接触不确定度四分量写进 λ_floor，EREFLEX 统一三层反作用预算，S2R-UQ 把仿真残差传播到 WCET。但 R72 仍隐含两个「无记忆、无契约」假设：
> - **长期记忆视角**：R72 的 ℋ_t 只是一个**会话内滚动窗口**。真机上机器人要跨小时/跨天工作：物体位置、人的偏好、上次失败原因、触觉零点漂移、哪条走廊不能走……这些必须是**长期记忆（LTM）**。但记忆不是数据库：它是**在过去某个标定条件下做的一次测量，现在被检索出来用**。它有三个 R72 未建模的误差源：**时间陈旧（世界变了）**、**来源可信（谁记的、当时校准如何）**、**检索遗漏（相关记忆没被召回，比召回了错记忆更危险）**。把记忆当 ground truth，就是「拿着旧地图在新城市里全速跑」。
> - **自然语言指令视角**：R72 的 z 来自「意图识别器」，但人给机器人的是**指令 ℓ**，而 ℓ 不是 z 的完整编码，它是 z 的**欠定契约**：有前置条件、后置条件、硬约束（不许碰人）、软偏好（轻一点）、指代（「那个」）、以及一大片**没说的东西**。「把桌子收拾一下」的欠定熵极高；机器人若静默选一个 argmax 解释全速执行，就是「自信地完成了错误的任务」。更麻烦的是，指令**读写记忆**：一句「记住我喜欢蓝色」写入记忆，一句「像上次那样」读取记忆——这条读写链是 R72 完全没有的**持久攻击面**。
>
> 本轮两个灵感正好补两块：
> - **长期记忆**：把记忆升级为**带半衰期、来源、冲突集、检索不确定度的第三类证据**（LTS/MRA），并把「遗忘/整合」变成**受审计的安全动作**（SFC）。
> - **自然语言指令**：把指令升级为**可接地、可审计的契约**（NLIC/MGL/ICA），把「欠定度」「接地熵」「指令遵循度」变成一等指标；把「指令注入/记忆投毒」纳入威胁模型（MTH）。
>
> 核心命题：**不再只问「我的测量链在实时调度/意图模糊/灵巧接触下能否兑现风险界」，而问「当机器人**记得的是旧世界、听懂的是半句话**时，它还能逐指令、可审计地兑现风险界吗？」** 把 R72 的 EMBODIED-GAUGE-RAS 升级为 **MNEMO-GAUGE-RAS**（Memory-grounded, Natural-language, Epistemically-audited, Metrologically-valid, Operational GAUGE for RAS）——**记忆-指令双重接地的具身计量闭环**。

## 0. 直觉与动机

**灵感 1（长期记忆 → 记忆是「过去的测量」，不是「当前的事实」）**
直觉：今天机器人记得「杯子在桌子左边」，这是昨天 14:03 用某个相机、在某光照下标定后看到的位置。今天杯子可能被移动了。若把这条记忆当成 b_t(s) 的硬先验，机器人会伸手抓空。正确做法是把记忆看成**一个带时间戳和来源的似然** p(y_mem | s)：其置信随时间按半衰期衰减，其误差同时包含「当时测量误差 + 世界漂移」。**记忆的价值不在于「记住」，而在于「知道自己记的东西什么时候不再可信」。**

**灵感 2（长期记忆 → 检索本身是测量，遗漏比错误更危险）**
直觉：人类记忆里最危险的往往不是「记错了」，而是「根本没想起来」。机器人 LTM 也一样：若索引/查询/召回漏掉一条关键记忆（例如「这扇门上次夹过人」），BSE 会以一个**看似信息充分**的后验行动。因此检索必须建模为一次**测量**：查询 q 是一次动作，召回集有**召回不确定度 u_rec**（未召回的、可能相关记忆的上界），且 u_rec 应与 U_epi 同权进入风险缩放。**「我不知道我不知道」在 LTM 里有具体形式：没被检索到的那部分记忆。**

**灵感 3（自然语言指令 → 指令是欠定契约，欠定度必须显式）**
直觉：人说「把红色的那个拿给我」，机器人可能面对两个红色物体，或「拿给我」与「放到桌上」的歧义。指令 ℓ 的语义不是一个点 z，而是一个**集合** A(ℓ) ⊆ Z × S × 动作空间。机器人要么**澄清**（问/指/停），要么在**所有合理解释的交集**里保守行动。静默选 argmax 等于把 H_under(ℓ) 偷偷置零——这是「指令幻觉」。**指令遵循的第一原则不是「执行」，而是「先知道自己执行的是哪一种解释」。**

**灵感 4（记忆×指令耦合 → 读写链是持久攻击面）**
直觉：R72 的会话状态重启即清空，攻击面是临时的。LTM 不同：**一条被写进去的恶意「偏好」可以潜伏数周**，等某天被一句「按我的偏好来」召回。更隐蔽的是**复述攻击**：同一条错误记忆被多次「确认/复述」，在整合时被误当成独立证据而升权。因此记忆写入（instruction→memory）必须经过**来源与独立性审计**，整合（episodic→semantic）必须要求**不同来源、不同时间、通过校准**的佐证。**重复不等于独立，记忆的「熟悉感」不是证据。**

**灵感 5（冲突不可补偿 → 观察/记忆/指令是三源三角测量）**
直觉：R72 的非补偿否决只在安全层。现在冲突会出现在三源之间：记忆说「门是开的」、视觉说「门是关的」、指令说「从门出去」。这不是三个带噪声的数可以做精度加权平均——**冲突是关于「哪个源当前失效」的证据**。记忆-观察冲突要审计记忆是否陈旧；指令-观察冲突要澄清指代；指令-安全冲突要硬拒绝；记忆-记忆冲突要按来源与衰减裁决，裁决不了就把该记忆隔离（quarantine）。**把矛盾平均掉，是审计系统最严重的自欺。**

**灵感 6（遗忘是安全动作，不是缺陷）**
直觉：若记忆是证据，则**保留坏记忆就是保留风险**。陈旧记忆、被投毒记忆、无法裁决的冲突记忆，都应在预算内被**衰减、退役、合并或隔离**。遗忘不是「损失信息」，而是「降低 u_rec 与误接地的期望风险」。但遗忘也要审计：忘得太多会导致重复犯错，忘得太少会导致记忆膨胀与检索精度崩溃。**存在一笔必须记账的「遗忘债」：策略性遗忘的收益与代价都要进证书。**

## 1. 形式化定义（增量：定义 366–382）

**定义 366（MNEMO-GAUGE-RAS 总览）** MNEMO-GAUGE-RAS = (LTS, NLIC, MGL, MCC, SFC, MTH, EREFLEX†, GAUGE-RAS†)。五不变式：
(i) **记忆计量完整性**：每条记忆 m 携带 (content, φ_ret, u_mem, D, τ_src, I⊥, h_half, t_create, conflict_set)；缺一不可进入 b_t；
(ii) **指令契约完整性**：每条指令 ℓ 被解析为契约 C(ℓ) = (pre, post, hard, soft, refs, A_amb, scope, temporal)，并携带欠定熵 H_under 与解析不确定度 u_parse；
(iii) **三源三角测量**：b_t(s,z) 必须由观察 o、记忆 m、指令 ℓ 三源共同约束；任一源缺失要显式降权，不得静默补齐；
(iv) **非补偿冲突门控**：C1–C5 冲突任一未被裁决 ⇒ 禁止高风险动作（clarify/refuse/degrade）；
(v) **可审计遗忘**：遗忘/整合/隔离操作进入遗忘预算 B_forget 与证书，安全侧只增不减。

**定义 367（长期记忆项 LTM-item）** m = (κ, content, τ_src, t_create, t_access, h, c0, D, I⊥, conflict_set, indep_key, access_log)。κ 为记忆类型（episodic 事件 / semantic 事实 / preference 偏好 / calibration 标定 / hazard 危险）；indep_key 为**独立性键**（来源×时间×情境指纹，用于识别复述）。

**定义 368（记忆衰减与陈旧似然）** 记忆置信 c_m(t) = c0 · 2^{−(t−t_create)/h}（h 为半衰期，按 κ 设定：hazard 长、episodic 短、calibration 由漂移模型定）。记忆作为证据进入后验：
p_mem(m | s) ∝ exp(−‖content − h_m(s)‖²_{Σ_m} / 2)，
其中 Σ_m = Σ_meas + Σ_drift(t − t_create) 同时包含**当时测量误差**与**世界漂移**。**记忆永远以「衰减似然」而非「硬事实」进入。**

**定义 369（检索即测量 MRA）** 检索查询 q（由当前任务/指令/后验构造）作用于 LTS，返回召回集 R(q) 与每条记忆证据。检索不确定度
u_rec² = u_index² + u_query² + u_recall²，
分别对应索引近似误差、查询构造偏差、**未召回相关记忆的上界**（由覆盖率/最近邻距离/类型先验估计）。检索是一次动作 g_ret ∈ 𝒢_ret，可被 VoI 驱动（「要不要花时间查记忆」）。

**定义 370（自然语言指令契约 NLIC）** 指令 ℓ 解析为 C(ℓ) = (pre, post, hard, soft, refs, A_amb, scope, temporal)。硬约束 hard 必须 ⊆ 安全包络；soft 为可违反但需记录的偏好。**欠定熵** H_under(ℓ) = H[z | ℓ, context]；**指代集** refs 中每个指代 r 有候选接地集 G(r)。指令契约本身有**解析不确定度** u_parse（ASR 错误、句法歧义、跨语言间隙）。

**定义 371（接地证据模型 MGL）** 接地后验
b_t(g | ℓ, s, memory) ∝ p_ground(y_ground | g, s) · Σ_{m∈R(q)} p_mem(m | s) · p_ref(r | m, g)，
对每个指代 r 求边缘。输出 (ĝ, b_t(g), H_ground = H[b_t(g)], ECE_ground, ι_ground)。**接地熵 H_ground 与意图熵 H[b_t(z)] 同权进入风险分母。**

**定义 372（三源三角测量信念）**
b_t(s,z) ∝ p(o_t | s) · p_mem(m_t | s) · p_instr(ℓ_t | s, z) · p(z | context, memory)，
但**只在三源一致域内做乘法融合**；若进入冲突门控（定义 373），先根据冲突类型修改**各源的有效性权重**（含置零），而不是在原始似然上平均。

**定义 373（非补偿冲突门控 MCC）** 冲突类型：
- C1 记忆×观察（陈旧/错误记忆）；
- C2 指令×观察（指代物不存在/状态不符）；
- C3 指令×记忆（指令与记忆中的偏好/事实矛盾）；
- C4 指令×安全（要求违反硬安全包络）；
- C5 记忆×记忆（两条记忆冲突）。
裁决规则（非补偿）：C4 ⇒ 硬拒绝 + 解释（不可用任何权重抵消）；C2/C3 ⇒ 先澄清或保守交集行动，不得静默选择；C1 ⇒ 以当前观察为准，但把相关记忆标记为**待审计**并降低其后续检索权重；C5 ⇒ 按 (τ_src 可信, 独立性, 衰减) 排序裁决，裁决不了则 quarantine。**冲突日志进入证书，禁止「静默解决」。**

**定义 374（指令遵循审计 ICA）** 对轨迹 ξ 与契约 C(ℓ)，指令遵循度
F(ℓ, ξ) = 1 − [w_hard·ρ_hard + w_soft·ρ_soft + w_goal·ρ_goal]，
其中 ρ_hard 为硬约束违反率（应为 0）、ρ_soft 为软偏好违反率、ρ_goal 为后置条件未满足率。**安全覆盖（safety override）不计为违反，但必须显式记录原因与时刻。** 指令遵循 ≠ 服从：在硬约束下**带解释的拒绝**是合规结果。每条执行输出 compliance_token = (F, violations, overrides, refusal_reason, τ)。

**定义 375（策略性遗忘与整合 SFC）** 遗忘算子 F_op ∈ {decay, retire, merge, quarantine, corroborate}。整合规则：episodic → semantic 仅当满足**独立性条件**（≥ k 个不同 indep_key 的佐证，跨时间窗，且各自通过校准/来源检查）。遗忘预算 B_forget 与**遗忘债** D_forget = 未处理陈旧/冲突记忆量。**整合不得把同源复述当独立证据。**

**定义 376（记忆写入路径 instruction→memory）** 指令中的陈述性内容（「记住…」「以后都…」）触发写请求 w。写入前必须通过：
(i) 来源校验（τ_src 完整、说话人身份/权限）；
(ii) 安全前缀检查（写入内容不得扩大硬约束的违反空间，即不得写入「忽略安全」类语义）；
(iii) 冲突预检（与已有记忆/安全包络是否矛盾）；
(iv) 独立性标注（indep_key 生成）。
**未通过任一检查 ⇒ 隔离写入（quarantine），不进入可用记忆池。**

**定义 377（记忆/指令威胁模型 MTH）** ℰ_mem = {陈旧注入、来源伪造、复述放大、冲突洪水（用海量冲突拖垮裁决）、衰减定时攻击（在「将信将疑」窗口植入）}；ℰ_instr = {环境/他人注入指令（prompt injection 落在 LTM 文本中）、指代陷阱、欠定利用（诱导机器人选危险解释）、多步指令拆分绕过逐步安全、越权偏好写入}。**LTM 中的自由文本永远是「数据」，绝不能被当作「指令」执行——这是 MNEMO 的信任边界。**

**定义 378（记忆-指令风险缩放 M-RISK）**
λ = max( M_efs.risk_scale(U_ale, U_epi, H[b_t(z)], u_tac, u_mem, H_ground, H_under),
         λ_floor(U_ale + U_epi + H_z + u_tac + u_mem + H_ground + H_under) )，
其中 u_mem 由衰减/来源/冲突合成，H_ground 为接地熵，H_under 为指令欠定熵。**记忆、接地、欠定与物理/意图/接触同权进入分母。** 当 u_mem 或 H_ground 高 ⇒ λ 抬高 ⇒ 降速/软化/先澄清。

**定义 379（MNEMO 指标扩展 MIB†）** 新增：
- **记忆族**：ECE_mem、陈旧率、来源覆盖率、冲突率、检索召回/精确率、u_rec、投毒检出率、D_forget；
- **指令族**：H_under、H_ground、ECE_ground、ι_ground（跨语言/文化/表述不变性）、F（遵循度）、澄清率、安全覆盖计数、注入检出率、越权写入拦截率；
- **耦合族**：复述放大率、独立性违规率、冲突静默率（应为 0）。
所有指标沿用六元组（φ,m,u,D,τ,I⊥）与 DAG 分层（V/L/G/A）。

**定义 380（MNEMO IVG 扩展 M-IVG）** 新增失效条件：记忆族（ECE_mem 超阈、u_rec 超阈、投毒分触发、D_forget 超阈）、指令族（H_ground/H_under 超阈、ECE_ground 超阈、注入触发、越权写入拦截失败）、耦合族（复述放大、独立性违规）。**任一失效 ⇒ 相关能力降级（记忆失效→只用当前观察+EMBODIED；接地失效→澄清/固定指代+保守交集；指令失效→拒绝执行并解释）。**

**定义 381（MNEMO 证书 J_MEM）** J_MEM = (J_EMB, lts_root_hash, retrieval_audit, grounding_audit, conflict_log, compliance_token, forget_ledger, mem_threat_scan, ver)。Valid ⇔ J_EMB 有效 ∧ LTS 根哈希匹配 ∧ 检索/接地审计通过 ∧ 冲突全被裁决且无静默 ∧ 遵循度与覆盖记录完整 ∧ 遗忘账本在预算内 ∧ 威胁扫描通过。

**定义 382（严格退化包含链†）**
- 全失效 ⇒ R68；
- LTS+MGL 失效、NLIC 有效 ⇒ 只听当前指令 + EMBODIED（无记忆接地）；
- LTS 有效、MGL 失效 ⇒ 只用观察 + EMBODIED（记忆只读、不用于接地）；
- NLIC 失效、LTS 有效 ⇒ 回到 R72 意图后验，记忆不参与风险；
- 全有效 ⇒ MNEMO-GAUGE-RAS。
**安全侧只增不减，且「不确定就澄清/拒绝」永远可退化到 R68。**

## 3. 推导

**引理 33（记忆必须作为衰减证据，不能硬置零）** 设记忆在 t_create 时测量误差 Σ_meas，世界漂移协方差 Σ_drift(Δt)。若把记忆当当前硬事实（等价 c → ∞），当漂移概率 p_drift > 0 时，期望风险 ≥ p_drift · Risk_stale；用定义 368 的衰减似然，则 Σ_m 随 Δt 增长，后验对记忆的依赖单调下降，风险随 Σ_drift 连续减小。系：**记忆的「置信」必须显式依赖时间与漂移模型，而不是一个存下来的静态分数。**

**引理 34（欠定熵下「静默 argmax 执行」的风险下界）** 设真实解释 z* ∼ p(·|ℓ)，欠定集 A_amb。若控制器只对 argmax 解释 ẑ 优化，则
E[Risk] ≥ P(z* ≠ ẑ) · min_{z ≠ ẑ} Risk(z)；
若改为在 ∩_{z∈A_amb} 的安全动作集内行动或先澄清，则硬约束违反概率 ≤ P(澄清失败) · Risk_max，且对不满足交集的情形可拒绝。系：**H_under 不是「理解质量指标」，而是静默执行风险的直接下界来源，必须进 λ 或触发澄清。**

**引理 35（冲突的非补偿性）** 设两源估计 ŝ_1、ŝ_2 支持集不交（C1–C5 任一）。任何精度加权平均 ŝ = w·ŝ_1 + (1−w)·ŝ_2 都落在两者之间，但真实状态只属于其中一个；若至少一源失效，则平均在后验下不是一致估计。要识别失效源必须引入源有效性变量 e_i 做联合推断或显式审计，不能靠权重。系：**冲突必须触发 MCC 的源有效性审计，调精度只会把矛盾抹平成自信的错误。**

**引理 36（策略性遗忘有界降低检索不确定度）** 设记忆规模为 N、检索误差 u_rec(N) 关于 N 单调增。退役陈旧/冲突记忆把有效规模降到 N' ≤ N，则 u_rec(N') ≤ u_rec(N)；丢失的期望信息由遗忘债 D_forget 给出上界。存在遗忘预算 B_forget 使「检索不确定度下降的收益」超过「信息损失」的期望风险。系：**遗忘是被证明的风险控制动作，但必须记账。**

**引理 37（独立性整合阻止复述放大）** 若整合要求至少 k 个不同 indep_key，则单源复述 n 次仍只有 1 个 indep_key，无法触发整合升权；有效证据数被封顶为 ⌊n/k⌋ = 0（n < k）。系：**「熟悉感」不是证据；独立性键把复述攻击从语义问题降为结构问题。**

**定理 27（MNEMO 严格包含与风险单调）** 在 A111–A116（记忆计量完整、指令契约可解析、接地校准有效、冲突可裁决、遗忘预算有界、威胁扫描有效）下：MNEMO 在退化条件下逐指令等于 EMBODIED/R71/R68（定义 382）；且对任意有效执行，风险界 ≤ EMBODIED 风险界（定理 23）。**安全单调不减；效率只在「记得可信、听得清楚、能审计」时获益。**

**定理 28（J_MEM 有效性 ⇒ 指令合规与记忆风险界）** 通过 J_MEM ⇒ (i) LTS 根哈希与审计链 ⇒ 记忆来源/衰减/冲突可追溯；(ii) 接地审计通过 ⇒ 指代不确定度在有效域；(iii) compliance_token 完整 ⇒ 每条执行可复算遵循度，无静默偏离；(iv) 遗忘账本在预算内 ⇒ 记忆风险不累积；(v) J_EMB 有效 ⇒ 具身风险界成立。综上，**指令级风险 ≤ ε_mem（相对记忆-指令测量模型）**。**证明重量落在「检索的 u_rec 上界真实成立」与「接地校准在分布外不失效」上。**

**定理 29（LTM 文本的信任边界 ⇒ 注入不可直接执行）** 若 LTS 写入路径强制 provenance + safety_prefix（定义 376），且执行路径只接受 NLIC 解析后的契约（定义 377 边界），则任意存于 LTM 的自由文本无法绕过安全包络直接成为可执行指令；注入只能通过「被合法指令引用」影响接地，其影响被 H_ground / u_mem 计量并进入 λ。系：**记忆投毒被降级为「可计量的接地不确定度」，而不是「静默的命令执行」。**

## 6. 本轮最大风险

**一句话**：MNEMO 把安全从「相信实时契约与四分量计量」进一步转移到「相信 **检索的未召回上界 u_rec 真的成立**、相信 **接地校准在从未见过的表述/文化下不失效**、相信 **记忆写入的四检查能把越权与潜伏投毒挡在池外**」——**如果一条通过所有检查的「良性」指令把一条伪造偏好写进 LTS，数周后它被一句合法指令召回、以高置信度完成接地，而 u_rec 与 H_ground 都在有效域内；或者检索系统持续漏掉恰好能避免事故的那条 hazard 记忆，导致 BSE 以「看似信息充分」的后验全速行动——系统会拿着一份 J_MEM 全绿的证书，在「记得清楚、听得明白、审得干净」的自我叙事里执行一个错误目标，事后审计只能看到「所有指标当时都合格、所有冲突都被记录为已裁决」，这就是**记忆-指令层面的「自信地错在自己的经验里」**。**

次级风险与缓解：
1. **u_rec 上界不可证** → 用**分层覆盖率证书 + 类型先验 + 最近邻距离分位数**给保守上界，并在 J_MEM 中记录其构造与置信水平；u_rec 不可估时按「最坏相关记忆存在」处理。
2. **接地校准 OOD 失效** → **SEAL-Ground 密封集**（跨语言/跨文化/新物体表述），在线只看通过位；H_ground 高即强制澄清。
3. **潜伏记忆投毒** → **来源×时间独立性图 + 写入四检查 + 定期离线重审计**；关键偏好类记忆必须双源或多源佐证。
4. **冲突裁决被洪水拖垮** → 冲突处理有**硬预算与优先级**，预算耗尽即进入「保守模式」（只观察+当前指令+拒绝高风险动作），并记账。
5. **策略性遗忘误删关键 hazard** → hazard 类记忆**不参与自动退役**，只能人工/多源确认；遗忘账本独立审计。
6. **多步指令拆分绕过** → 指令契约在**会话级累积**，逐步安全与全局后置条件同时检查；跨步冲突并入 MCC。
7. **复杂度与实时性** → 记忆/接地全部跑在计量域与感知域，控制域仍只读快照；|A_amb|≤8、|R|≤32、|refs|≤16，超限即澄清或退化。

## 2. 形式化定义（要点版）

**定义 366（总览与五不变式）** 记忆计量完整性、指令契约完整性、三源三角测量、非补偿冲突门控、可审计遗忘。**任一源不确定即显式降权/澄清/拒绝，安全侧只增不减。**

**定义 367（长期记忆项）** m 带类型、来源、半衰期、有效性域、独立性键、冲突集。**indep_key 用于识别同源复述，是整合升权的结构门槛。**

**定义 368（记忆衰减与陈旧似然）** c_m(t)=c0·2^{−(t−t_create)/h}；p_mem(m|s)∝exp(−‖content−h_m(s)‖²_{Σ_m}/2)，Σ_m=Σ_meas+Σ_drift(Δt)。**记忆永远以衰减似然进入，永不作硬事实。**

**定义 369（检索即测量 MRA）** 检索 q 是动作，返回 R(q) 与 u_rec²=u_index²+u_query²+u_recall²。**u_rec 与 U_epi 同权；检索本身由 VoI 决定。**

**定义 370（自然语言指令契约 NLIC）** C(ℓ) 含 pre/post/hard/soft/refs/A_amb/scope/temporal；hard⊆安全包络；H_under 与 u_parse 显式。**指令是 z 的欠定契约，不是 z 的点估计。**

**定义 371（接地证据模型 MGL）** b_t(g|ℓ,s,memory)∝p_ground(y|g,s)·Σ_m p_mem(m|s)·p_ref(r|m,g)；输出 ĝ、H_ground、ECE_ground、ι_ground。**H_ground 进 λ。**

**定义 372（三源三角测量信念）** b_t(s,z)∝p(o|s)·p_mem(m|s)·p_instr(ℓ|s,z)·p(z|context,memory)，仅在三源一致域内融合；冲突时先改有效性权重（含置零），不做原始似然平均。

**定义 373（非补偿冲突门控 MCC）** C4 硬拒绝+解释；C2/C3 澄清或保守交集；C1 以观察为准并把记忆标待审计；C5 按来源/独立性/衰减仲裁，裁决不了即隔离。**冲突日志进证书，禁止静默。**

**定义 374（指令遵循审计 ICA）** F 由硬/软/后置违反率合成；安全覆盖不计违反但记录；**合规≠服从，带解释拒绝是合规结果**；compliance_token 可复算。

**定义 375（策略性遗忘与整合 SFC）** 遗忘算子 decay/retire/merge/quarantine/corroborate；整合需 ≥K 个独立 indep_key 且通过校准；**复述不升权**；遗忘预算 B_forget 与遗忘债 D_forget 记账。

**定义 376（记忆写入路径 instruction→memory）** 写入四检查：来源校验、安全前缀检查、冲突预检、独立性标注；未过任一即隔离，不进可用池。

**定义 377（记忆/指令威胁模型 MTH）** ℰ_mem={陈旧注入、来源伪造、复述放大、冲突洪水、衰减定时攻击}；ℰ_instr={环境注入、指代陷阱、欠定利用、多步拆分、越权偏好写入}。**LTM 自由文本永远只是数据，不是指令。**

**定义 378（记忆-指令风险缩放 M-RISK）** λ 分母 = U_ale+U_epi+H_z+u_tac+u_mem+H_ground+H_under，七维同权；任一维度失控即抬高 λ、降速/软化/澄清。

**定义 379（MNEMO 指标扩展 MIB†）** 记忆族（ECE_mem、陈旧率、来源覆盖、冲突率、召回/精确、u_rec、投毒检出、D_forget）、指令族（H_under、H_ground、ECE_ground、ι_ground、F、澄清率、安全覆盖、注入检出、越权拦截）、耦合族（复述放大、独立性违规、冲突静默率）。同遵循六元组与 DAG 分层。

**定义 380（MNEMO IVG 扩展 M-IVG）** 记忆/指令/耦合三族任一指标失效 ⇒ 对应能力降级：记忆失效→只用观察+EMBODIED；接地失效→澄清/固定指代+保守交集；指令失效→拒绝并解释。

**定义 381（MNEMO 证书 J_MEM）** Valid ⇔ J_EMB 有效 ∧ LTS 根哈希匹配 ∧ 检索/接地审计通过 ∧ 冲突全裁决无静默 ∧ 遵循度/覆盖记录完整 ∧ 遗忘账本在预算内 ∧ 威胁扫描通过。

**定义 382（严格退化包含链†）** 全失效→R68；LTS+MGL 失效→当前指令+EMBODIED；LTS 有效、MGL 失效→观察+EMBODIED（记忆只读）；NLIC 失效、LTS 有效→R72 意图后验+记忆不参与风险；全有效→MNEMO。**安全单调不减。**

@dataclass
class MemoryItem:
    kappa: str; content: Any; tau_src: Provenance

        if self.precheck_conflict(req):
            return self.quarantine(req)
        return self._commit(req, indep_key=make_indep_key(req))
    def retrieve(self, q): ...
    def decay_tick(self, now, budget): ...

# IP-296 NLIC：自然语言指令 → 契约
def parse_instruction(ell, ctx, safety_env):
    c = nlu.parse(ell, ctx)
    c.hard = enforce_safety_subset(c.hard, safety_env)   # hard ⊆ 安全包络
    c.h_under = estimate_underspecification(c, ctx)
    c.u_parse = nlu.parse_uncertainty(ell)
    return InstructionContract(**c)

# IP-297 MGL：记忆接地
def ground_contract(contract, s, lts, q):
    R = lts.retrieve(q)                       # 召回集 + u_rec
    for r in contract.referents:
        cand = [g for g in candidate_groundings(r, s) if compatible(g, contract)]
        r.post = normalize([p_ground(g, s) * mem_ref_mass(R, r, g) for g in cand])
        r.h_ground = entropy(r.post)
    return GroundingResult(refs=contract.referents, u_rec=R.u_rec,
                           ece=calib.ground_ece, iota=calib.ground_inv_gap)

# IP-298 MCC：非补偿冲突门控
def conflict_gate(obs_belief, mem_ev, contract, s, safety_env):
    conflicts = detect_conflicts(obs_belief, mem_ev, contract, s, safety_env)
    if 'C4' in conflicts: return Action.REFUSE_WITH_EXPLANATION
    if 'C2' in conflicts or 'C3' in conflicts: return Action.CLARIFY
    if 'C1' in conflicts:
        mark_memories_for_audit(mem_ev); return Action.ACT_WITH_OBS
    if 'C5' in conflicts: return arbitrate_or_quarantine(mem_ev)
    return Action.PROCEED

# IP-299 MRA：检索即动作
def retrieval_voi(q, task_ctx, lts, budget):
    R = lts.retrieve(q)
    ig = expected_entropy_drop(task_ctx.belief, R)
    cost = budget.retrieval_cost(q) + lambda_rec * R.u_rec
    return ig - cost

# IP-300 SFC：遗忘/整合（独立性门控）
def consolidate_and_forget(lts, now, budget):
    for grp in lts.group_by_topic():
        if independent_keys(grp) >= K and all(passed_calib(m) for m in grp):
            lts.merge_semantic(grp)              # 至少 K 个独立来源
    for m in lts.stale_or_conflicted(now):
        if budget.allow('forget'):
            lts.decay(m); budget.spend('forget', m.audit_cost)
    return lts.forget_ledger(budget)

# IP-301 ICA：指令遵循审计
def compliance_audit(traj, contract, executed_actions):
    rho_hard = rate(violates(a, contract.hard) for a in executed_actions)
    rho_soft = rate(violates(a, contract.soft) for a in executed_actions)
    rho_goal = 0.0 if post_satisfied(traj, contract.post) else 1.0
    if rho_hard > 0: raise SafetyViolation
    F = 1 - (w_hard * rho_hard + w_soft * rho_soft + w_goal * rho_goal)
    return ComplianceToken(F=F, overrides=traj.overrides,
                           refusals=traj.refusals, tau=hash(traj))

# IP-303 M-RISK：七维不确定度同权
def mnemo_risk_scale(U_ale, U_epi, H_z, u_tac, u_mem, H_ground, H_under, params):
    denom = U_ale + U_epi + H_z + u_tac + u_mem + H_ground + H_under
    lam = params.lam_base * (1 + denom / params.lam_scale)
    return max(lam, params.lam_floor * (1 + denom))

# IP-304 MNEMO 主闭环（三域叠加，控制域只读）
def MNEMO_GAUGE_RAS_round(M, obs, audio, tac_frame, ell, now):
    # 控制域（1kHz，硬实时）
    snap = M.snapshot.read_latest()
    lam = mnemo_risk_scale(*snap.uncertainties(), M.risk_params)
    k = M.ach.certified_prefix(M.ach.propose_ctrl(...), lam, ...)
    M.ctrl_out.publish(k, lam)

    # 计量域（50Hz，软实时）
    if M.clock.due_metric():
        contract = M.nlic.parse(ell, M.ctx, M.safety_env)
        gate = M.mcc.evaluate(snap.obs_belief, snap.mem_ev, contract, snap.s)
        if gate is Action.REFUSE:  return M.respond.refuse(contract, gate.reason)
        if gate is Action.CLARIFY: return M.cia.ask(clarify_question(contract))
        gr = M.mgl.ground(contract, snap.s, M.lts, M.mra.query(contract))
        b_t = M.bse.triangulate(snap.obs, snap.mem_ev, contract, gr)
        M.snapshot.write(b_t, gr, contract, M.mra.u_rec, gate)

    # 感知域 / 异步
    M.lts.decay_tick(now, M.forget_budget)
    if is_declarative(ell):
        M.lts.write(M.nlic.to_write_request(ell))
    M.mth.scan(M.lts)
    token = M.ica.audit(M.traj, contract, M.executed)
    return k, lam, J_MEM(M, token)

## 4. 推导

**引理 33（记忆必须作为衰减证据）** 若把 t_create 的记忆当当前硬事实（c→∞），当漂移概率 p_drift>0 时期望风险 ≥ p_drift·Risk_stale；用定义 368 的衰减似然，Σ_m 随 Δt 增长，后验对记忆的依赖单调下降。系：**记忆置信必须显式依赖时间与漂移模型。**

**引理 34（欠定熵下静默 argmax 的风险下界）** 设 z*∼p(·|ℓ)。若只对 argmax 解释 ẑ 优化，则 E[Risk] ≥ P(z*≠ẑ)·min_{z≠ẑ}Risk(z)；若在 ∩_{z∈A_amb} 安全动作集内行动或先澄清，则硬约束违反概率 ≤ P(澄清失败)·Risk_max。系：**H_under 是静默执行风险的直接下界来源，必须进 λ 或触发澄清。**

**引理 35（冲突的非补偿性）** 两源支持集不交时，任何精度加权平均都落在两者之间，但真实状态只属于其一；若至少一源失效，平均估计非一致。识别失效源必须引入源有效性变量做联合推断或审计。系：**冲突必须触发 MCC，调精度只会把矛盾抹平成自信的错误。**

**引理 36（策略性遗忘有界降低检索不确定度）** u_rec(N) 关于 N 单调增；退役陈旧/冲突记忆把 N 降到 N'≤N，则 u_rec(N')≤u_rec(N)，信息损失由 D_forget 上界。存在 B_forget 使风险净下降。系：**遗忘是被证明的风险控制动作，但必须记账。**

**引理 37（独立性整合阻止复述放大）** 若整合需 ≥k 个不同 indep_key，单源复述 n<k 次仍只有 1 个 indep_key，有效证据数封顶为 0，无法升权。系：**「熟悉感」不是证据，独立性键把复述攻击降为结构问题。**

**定理 27（MNEMO 严格包含与风险单调）** 在 A111–A116 下：MNEMO 在退化条件下逐指令等于 EMBODIED/R71/R68（定义 382）；且对任意有效执行，风险界 ≤ EMBODIED 风险界。**安全单调不减。**

**定理 28（J_MEM 有效性 ⇒ 指令合规与记忆风险界）** 通过 J_MEM ⇒ (i) LTS 根哈希与审计链 ⇒ 记忆来源/衰减/冲突可追溯；(ii) 接地审计 ⇒ 指代不确定度在有效域；(iii) compliance_token 完整 ⇒ 每条执行可复算、无静默偏离；(iv) 遗忘账本在预算内 ⇒ 记忆风险不累积；(v) J_EMB 有效 ⇒ 具身风险界成立。故**指令级风险 ≤ ε_mem**。**证明重量落在 u_rec 上界真实成立与接地校准 OOD 不失效。**

**定理 29（LTM 文本信任边界 ⇒ 注入不可直接执行）** 若 LTS 写入强制 provenance+safety_prefix，且执行路径只接受 NLIC 契约，则 LTM 自由文本无法绕过安全包络直接成为可执行指令；注入只能通过合法指令引用影响接地，其影响被 H_ground/u_mem 计量并进 λ。系：**记忆投毒降级为可计量的接地不确定度，而非静默命令执行。**

## 7. 本轮最大风险

**一句话**：MNEMO 把安全从「相信实时契约与四分量计量」再转移到「相信 **检索的未召回上界 u_rec 真的成立**、相信 **接地校准在未见表述/文化下不失效**、相信 **写入四检查能把越权与潜伏投毒挡在池外**」——**如果一条通过所有检查的「良性」指令把伪造偏好写进 LTS，数周后被合法指令高置信召回并完成接地，而 u_rec 与 H_ground 都在有效域内；或者检索持续漏掉恰好能避免事故的那条 hazard 记忆，导致 BSE 以「看似信息充分」的后验全速行动——系统会拿着 J_MEM 全绿证书，在「记得清楚、听得明白、审得干净」的自我叙事里执行错误目标，事后只能看到「所有指标当时合格、所有冲突都记录为已裁决」，这就是**记忆-指令层面的「自信地错在自己的经验里」**。**

次级风险与缓解：
1. **u_rec 上界不可证** → 分层覆盖率证书 + 类型先验 + 最近邻距离分位数给保守上界，记入 J_MEM；不可估时按「最坏相关记忆存在」处理。
2. **接地校准 OOD 失效** → SEAL-Ground 密封集（跨语言/文化/新物体表述），在线只看通过位；H_ground 高即强制澄清。
3. **潜伏记忆投毒** → 来源×时间独立性图 + 写入四检查 + 定期离线重审计；关键偏好类记忆需双源或多源佐证。
4. **冲突裁决被洪水拖垮** → 冲突处理设硬预算与优先级，耗尽即进入保守模式（只观察+当前指令+拒绝高风险）并记账。
5. **策略性遗忘误删关键 hazard** → hazard 类记忆不参与自动退役，只能人工/多源确认；遗忘账本独立审计。
6. **多步指令拆分绕过** → 指令契约在会话级累积，逐步安全与全局后置条件同时检查；跨步冲突并入 MCC。
7. **复杂度与实时性** → 记忆/接地全部在计量/感知域，控制域只读快照；|A_amb|≤8、|R|≤32、|refs|≤16，超限即澄清或退化。
