# 第 10 轮（新灵感循环；本轮灵感：「动作分块」×「四足机器人」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**接触语法 + 相位分块 + 双类退化**。两个灵感分别治理 v9 的两笔债：**接触债**（v9 的块证书本质是自由空间点质量间隙，把四足最关键的支撑多边形、摩擦锥与触地事件当噪声处理）、**相位债**（v9 的 K 是抽象控制步数，与步态相位和触地时刻错位，允许一个证书跨过尚未验证的落脚点）。核心手段：把动作块的原子单位从「控制步」改为「接触相位」，把证书从点质量间隙升级为质心-接触证书，并用**触地前重规划律**保证分块绝不跨入未验证落脚点。任一新模块失效 ⇒ 注入对应类型的中立元，逐位退回 v9，而非行为漂移。

## 0. 直觉与动机

### 灵感 1（四足机器人 → 接触是动作的语法，不是环境的噪声）

直觉：v9 把安全论证局部化在「块证书 + 中止点」上，但它继承的是机械臂式的自由空间直觉——机器人是一个带半径的质点，安全等于「间隙大于刹车距离」。四足机器人恰恰相反：它的动作首先是一张**触地日程表**（哪条腿支撑、何时抬落、落在哪里），安全首先是**接触可行性**。同一条关节轨迹，换一个落脚点就会从「支撑多边形内可捕获」变成「质心在支撑多边形外不可捕获」；同一个间隙，在摩擦系数 μ=0.15 的湿地面上会在 40ms 内滑成一条腿的失败。因此本轮第一个判断是：**四足的动作块必须以接触模式为原子，证书必须建立在质心动力学与接触约束上**，而不是在 v9 的点质量证书上打补丁。

严谨定义（本节先给核心式，完整定义见产物区 540–542）：动作块扩展为
```
ζ_t = (ξ_t^{1:K}, χ_t, Φ_t, Ĉ_t, P_t, R_t)
```
其中 χ_t = {(σ_j, τ_j^on, τ_j^off)}_{j=1..M} 是接触时序表，σ_j ∈ {0,1}^4 为第 j 段的支撑模式，Φ_t 为落脚点集。对每个模式 σ，支撑多边形 S(σ)=Conv(落脚点投影)，发散运动分量 ξ = x_com + ẋ_com/ω（ω=√(g/z_com)），支撑裕度 m_dcm(σ)=dist(ξ, ∂S(σ))。块证书
```
Ĉ_t = (m_dcm^min − β_dcm, m_fric^min − β_fric, m_reach^min − β_reach, m_viab^min − β_viab)
```
证书有效 ⇔ 四项均 ≥0 ∧ 接触力 QP 可行。注意 β_dcm 必须同时吞掉单刚体质心模型误差 β_c **和**地形高度误差 ε_h 经坡度放大的项，这是四足特有的误差耦合。

### 灵感 2（动作分块 → 相位对齐分块与触地前重规划）

直觉：动作分块（ACT）的原始红利是「一次生成 K 步、低频重规划、高频廉价守卫」，v9 已经拿到；但 v9 的 K 是固定的控制步数，与步态相位不同步。这带来一个隐蔽但致命的问题：一个 10 步块可能横跨一次触地，而这次触地的落脚点是在**块生成时**的旧感知上算出来的；等真正触地时，地形可能已经变了，证书却还在按旧地图给绿灯。分块越省算力，这个「证书跨越未验证触地」的窗口就越大。正确的修法不是缩短 K，而是**让块的边界与接触相位对齐，并在第一个未验证触地之前截断**：块可以跨多少个接触相位，是一个独立于 Δ_dom 的安全门控。

严谨定义（定义 543–545）：设 U_terr(t) 为未验证落脚点集合（地形高度不确定度 > ε_h、或 Δ_dom ≥ τ_dom、或当前感知未覆盖）。定义相位门控
```
K_phase(t) = min{ k : 第 k 步后存在触地且落脚点 ∈ U_terr } − 1
K_eff(t)   = min( K_eff^{v9}(t), K_phase(t), K_margin(t) )，下限 1
```
即：块在「第一个未验证触地」之前截断；若支撑裕度跌破 τ_dcm，也在该点截断。回撤-重捕获集 P_t 相应升级为「能回撤摆动腿、并在 R_t 中找到一个已认证落脚点重建支撑」的前缀集合；P_t=∅ 则拒绝该块。

### 灵感 3（合流 → 腿失效的支撑集替换与双类中立元）

直觉：v9 的退化代数是单一中立元代数——任何模块失效都注入恒等元 v^⊥，系统「当它不存在」。这对性能模块成立，对四足的接触端口却是**类型错误**：一条腿卡死或足端打滑时，正确的语义不是「这条腿不存在」，而是「支撑集必须重写为三分体步态」；而如果重写后仍不可行，正确语义是「锁存站姿」——一个吸收态，不是可逆的恒等元。把吸收态误当恒等元，等于把「已经安全停驻」当成「可以继续走」，会直接破坏退化链。由此得到本轮更深的形式化贡献：**双类中立元代数**（性能端口用 ⊕ 恒等元，安全/接触端口用 ⊗ 替换-吸收元），并对端口类型做静态检查。

严谨定义（定义 546–549）：支撑集替换算子 ⊙: (χ, e) ↦ χ' 从每个接触模式中移除失效腿 e 并重排为三分体时序，要求存在 χ' 使 m_dcm(χ')≥0；否则输出锁存站姿 ⊥。⊥ 满足吸收性 (χ⊙e)⊙⊥ = ⊥，速度归零、质心在全部可用腿支撑多边形内，仅显式复位可退出。双类代数满足：性能端口 x ⊕ v^⊕ = x；接触端口 x ⊗ v^⊗ = v^⊗，且 v^⊗ 为吸收态。类型检查器拒绝把 v^⊕ 注入接触端口。

## 1. 研究问题（轮次升级版）

- **Q1（接触证书健全性）**：在单刚体质心模型误差 ≤ β_c、地形高度误差 ≤ ε_h、摩擦系数不确定的条件下，质心-接触证书能否保证「证书有效 ⇒ 真实 DCM 始终在真实支撑多边形内且无滑移」？接触力 QP 的裕度与真实滑移之间如何标定？接触切换瞬间（混合系统的离散跳变）如何不让证书出现「模式内有效、模式间失效」的空洞？
- **Q2（相位门控与触地前重规划）**：如何定义未验证落脚点与相位截断，使「块绝不执行一次未验证触地」成为可证性质？在感知时延、足端力觉时延与执行时延有界时，回撤-重捕获集能保证中块地形突变零跌倒吗？相位对齐是否会牺牲 v9 的算力摊销红利？
- **Q3（双类中立元的组合正确性）**：如何把 v9 的单一退化代数拆成 ⊕/⊗ 两型，使任意失效序列的组合仍是安全侧吸收？腿失效、足端滑移、接触传感器故障三类事件在 ⊙ 下是否收敛到「已认证站姿或锁存站姿」？类型错误能否被部署期静态检查穷尽拒绝？

## 2. 设计原则（在 P10–P12 基础上新增 P16–P18）

**P16 相位对齐分块律（Phase-Aligned Chunking, HCC）**
动作块以接触相位为原子：ζ_t 由整数个接触模式组成，块边界对齐触地/离地事件。块的证书按模式分段给出，每段都必须在当前 τᵢ(t) 下复核；不再允许「整块一个点质量间隙」的粗证书。

**P17 触地前重规划律（Re-plan-before-Touchdown, TG）**
对任何落在未验证地形上的触地，块必须在该触地之前截断并重新规划：K_eff(t) ≤ K_phase(t)。块内不得执行任何「证书生成时未被感知覆盖」的落脚点；违反即视为证书无效，回退 K=1 或最近回撤点。

**P18 双类中立元退化律（Two-Sorted Neutral Algebra, CSD）**
性能端口失效注入恒等元 v^⊕；安全/接触端口失效注入替换-吸收元 v^⊗。失效腿由 ⊙ 改写支撑集；改写不可行则进入锁存站姿 ⊥（吸收态）。任何新模块旁路后，系统逐位退回 v9；接触端口禁止使用恒等元。

## 3. 与基线的接口（如何退化）

- HCC/CCC 失效（块生成超时、QP 不可行、证书解析失败）⇒ 使用 v9 AC 的点质量块证书与 v9 的 K_eff，决策粒度等价 v9；
- 相位门控失效（地形验证不可用）⇒ K_phase ← K_max，即退回 v9 的 Δ_dom/risk_SLAM 门控；
- 接触一致性守卫失效 ⇒ 仍由 CSD 在下一相位做支撑集重写，最坏退回 v9 中块守卫 + 安全停驻；
- CSD 失效 ⇒ 腿失效一律映射为 v9 的安全停驻（保守，等价 v9 AC 的吸收元路径）；
- v9 的 AC/MW/ID 任一失效 ⇒ 依 v9 五级退化链；
- 全部失效 ⇒ 退回 v9 → v8 → v7 → v6。

## 4. 预期贡献

1. **接触混合动作块**：把动作分块的原子从控制步升级为接触相位，使四足的安全论证与步态/触地事件同构，块证书按模式局部化；
2. **质心-接触证书**：DCM-支撑多边形、摩擦锥、可达性与生存性四重裕度，并给出 β_c 与 ε_h 的显式耦合界；
3. **触地前重规划律**：把「未验证触地」变成硬截断条件，给出感知/力觉/执行时延下中块地形突变的安全性证明；
4. **双类中立元代数**：指出 v9 单一恒等元代数在接触端口的类型错误，用 ⊕/⊗ 分型与吸收态锁存站姿修正，保留逐位退回 v9 的能力；E571–E590 覆盖相位分块、接触健全性、打滑、腿失效、地形突变与端到端。

## 5. 本轮最大风险

**一句话**：质心-接触证书建立在「单刚体质心动力学 + 刚性接触 + 无滑移」之上，而四足最危险的接触失效——松软/湿滑地形的足端滑移、可变形地面的支撑塌陷、腿别造成的支撑集突变——恰好都在这套模型之外，于是系统可能在「最需要接触安全的地形上，用最不接触现实的接触模型」给出证书。

**定义 540（接触混合动作块 Hybrid Contact Chunk）** 一次决策的输出单元：
```
ζ_t = (ξ_t^{1:K}, χ_t, Φ_t, Ĉ_t, P_t, R_t)
```
ξ 为关节/机体参考轨迹，χ_t 为 M 个完整接触相位的时序表，Φ_t 为落脚点，Ĉ_t 为定义 542 的分段证书，P_t/R_t 为定义 544 的回撤/重捕获集。块由整数个接触相位组成，K = Σ_j (τ_j^off − τ_j^on)/Δt。5Hz 生成、50Hz 逐控制周期执行；块边界强制对齐触地/离地事件。

**定义 541（支撑多边形与四重裕度）** 对接触模式 σ，支撑多边形 S(σ)=Conv{ p_f : f∈σ }，p_f 为足端在地形切平面的投影。设质心 x_com、速度 ẋ_com、等效摆长 z_com，ω=√(g/z_com)，DCM ξ=x_com+ẋ_com/ω。则
```
m_dcm(σ)   = dist(ξ, ∂S(σ))
m_fric(σ)  = min_{f∈σ} ( μ_f f_z^f − ‖f_t^f‖ )       由接触力 QP 求得
m_reach(σ) = min_{f∈swing(σ)} ( L_max − ‖p_hip,f − p_f‖ )
m_viab(σ)  = dist(ξ_next, ∂S(σ_next))                下一段触地后的生存裕度
```
其中 f_z^f、f_t^f 为法向/切向接触力，μ_f 为该足摩擦系数下界。所有量在各自接触点的地形切平面上计算；坡度放大的高度误差见定义 542。

**定义 542（质心-接触证书 CentroidalContactCertificate）** 对块内所有接触模式取最坏值并扣除误差余量：
```
Ĉ_t = ( m_dcm^min − β_dcm,  m_fric^min − β_fric,
        m_reach^min − β_reach, m_viab^min − β_viab )
β_dcm   = β_c/ω_min + ε_h·tanθ_max
β_fric  = L_μ·ε_h + η_slip
β_reach = ε_h + δ_joint
β_viab  = β_c/ω_min + ε_h·tanθ_max
```
β_c 为单刚体质心模型误差上界，ε_h 为地形高度误差，θ_max 为最大坡度，L_μ 为摩擦系数对法向力的 Lipschitz 常数，η_slip 为足端滑移速度积分余量，δ_joint 为关节跟踪误差。证书有效 ⇔ 四项均 ≥ 0 ∧ 接触力 QP 可行 ∧ 下一步触地满足生存裕度。β 由 E583/E584 标定。

**定义 543（触地前重规划门控 TouchdownGate）** 未验证落脚点集合
```
U_terr(t) = { p : height_unc(p) > ε_h  ∨  Δ_dom(t) ≥ τ_dom  ∨  p ∉ coverage(t) }
K_phase(t) = min{ k : 第 k 步之后存在触地且落脚点 ∈ U_terr(t) } − 1   （无则 K_max）
K_margin(t)= min{ k : m_dcm^min(k) < τ_dcm } − 1                     （无则 K_max）
K_eff(t)   = max(1, min( K_eff^{v9}(t), K_phase(t), K_margin(t) ))
```
语义：块在第一个未验证触地之前截断；若支撑裕度先破阈值，也在该点截断。K_eff=1 时逐接触步重规划，退回 v9 的逐步语义。

**定义 544（回撤-重捕获集 Retract-Recapture Set）**
```
P_t = { p : ∃χ'_p, Φ'_p 使
        (i)  从 p 起可将全部摆动腿回撤至离地间隙 h_safe；
        (ii) 存在 r ∈ R_t 使重建支撑后 m_dcm(χ'_p) ≥ 0；
        (iii) 刹停/重捕获时间 T_cap(p) ≤ (m_dcm(p) − β_dcm)/v_dcm,max } }
R_t = { r : r ∈ 当前可达域 ∧ height_unc(r) ≤ ε_h ∧ 落入 r 后 m_viab(r) ≥ 0 }
```
P_t=∅ ⇒ 拒绝候选块；若执行中落入无 P_t 状态 ⇒ 进入锁存站姿 ⊥。中块违规时切换到 ≤ 当前执行步的最大回撤点 p*。

**定义 545（接触一致性偏差与守卫）** 实际接触态 ĉ_f = 1[foot_force_f > f_thr]，计划态 σ_f。偏差
```
δ_c(t) = (1/4)·|{ f : ĉ_f ≠ σ_f }| + 1[ max_f v_slip,f > v_slip ]
```
50Hz 守卫：δ_c > δ_max 或持续超过 1 个接触相位 ⇒ 切换到最近回撤点 p*；若无 p* ⇒ ⊥。滑移速度 v_slip 由足端位置差分与力觉切向残差联合估计。

**定义 546（支撑集替换算子 ContactSubstitution）** 对失效腿 e：
```
⊙ : (χ, e) ↦ χ'，σ_j' = σ_j \ {e}（∀j），并按三分体（tripod）时序重排
```
要求存在 χ' 使 m_dcm(χ') ≥ 0 且摩擦 QP 可行；否则输出 ⊥。性质：(i) 幂等：若 e∉σ_j 则 χ⊙e=χ；(ii) 单调：S(χ')⊆S(χ)；(iii) 有限次替换后要么停在已认证站姿，要么进入 ⊥。

**定义 547（锁存站姿吸收元 LockedStance）** ⊥ = 全部可用腿支撑、机体速度归零、质心投影位于 S(σ_all) 内部且 m_dcm ≥ m_lock > 0 的站姿。吸收性：(χ⊙e)⊙⊥ = ⊥；进入 ⊥ 后仅显式/离线复位可退出。⊥ 是安全停驻，不是恒等元。

**定义 548（双类中立元代数 Two-Sorted Neutral Algebra）** 端口分为两类：
- 性能端口 P：失效语义为恒等元 v^⊕，x ⊕ v^⊕ = x（继承 v9）；
- 安全/接触端口 S：失效语义为替换-吸收元 v^⊗，x ⊗ v^⊗ = v^⊗，且 v^⊗ 为吸收态。
退化表逐端口标注类型（见第 0 节表）。类型规则：接触端口禁止 v^⊕；部署期静态检查器对契约表做类型推导，任何 `S × P` 错配即拒绝部署。

**定义 549（步态信任域 GaitTrustRegion）**
```
U_g(t) = { Δ_dom(t) < τ_dom  ∧  ε_h(t) ≤ ε_h,max
           ∧ m_dcm(t) ≥ τ_dcm  ∧  δ_c(t) = 0 }
```
U_g 成立时块可跨 M 个接触相位；否则 K_eff=1（逐接触步），且 U_terr 内的触地必须触发重规划。U_g 是 v9 信任域 U_t 在接触维度上的精化：U_g ⊆ U_t。

# IP-357 HybridContactChunker：接触混合分块器
class HybridContactChunker:
    def __init__(self, policy, certifier, K_max=10, M_max=3,
                 tau_dcm=0.03, dt=0.02):
        self.policy, self.cert = policy, certifier
        self.K_max, self.M_max = K_max, M_max
        self.tau_dcm, self.dt = tau_dcm, dt

    def effective_K(self, delta_dom, tau_dom, trust_ok, terrain, margins):
        K_v9 = 1 if not trust_ok else max(
            1, int(self.K_max * (1 - min(1.0, delta_dom / tau_dom))))
        K_phase = self._first_unverified_touchdown(terrain)   # 定义 543
        K_margin = self._margin_truncation(margins, self.tau_dcm)
        return max(1, min(K_v9, K_phase, K_margin))

    def generate_chunk(self, state, delta_dom, tau_dom, trust_ok, terrain):
        K = self.effective_K(delta_dom, tau_dom, trust_ok, terrain,
                             self.cert.current_margins(state))
        if K == 1:
            return self._single_contact_step(state)           # 等价 v9 逐步
        best = None
        for chi, phi in self.policy.sample_contact_schedules(
                state, K, M=self.M_max, n=64):
            cert = self.cert.certify(chi, phi, terrain)       # 定义 542
            if cert is None:
                continue
            pts = self._retract_recapture(state, chi, phi, cert)  # 定义 544
            if not pts:
                continue
            score = self.policy.score(chi, phi, cert)
            if best is None or score > best.score:
                best = ContactChunk(chi, phi, cert, pts)
        return best or self._single_contact_step(state)

    def contact_guard(self, chunk, k_exec, live):
        """50Hz：接触一致性 + 支撑裕度；返回 ('continue',k+1) / ('retract',p*)"""
        delta_c = self._contact_consistency(chunk, k_exec, live)  # 定义 545
        if delta_c > self.delta_max:
            return self._nearest_retract(chunk, k_exec)
        if live.m_dcm < self.tau_dcm:
            return self._nearest_retract(chunk, k_exec)
        return ('continue', k_exec + 1)


# IP-358 CentroidalContactCertifier：质心-接触证书器
class CentroidalContactCertifier:
    def __init__(self, beta_c, eps_h, theta_max, mu_lb, L_mu, eta_slip):
        self.beta_c, self.eps_h, self.theta_max = beta_c, eps_h, theta_max
        self.mu_lb, self.L_mu, self.eta_slip = mu_lb, L_mu, eta_slip

    def certify(self, chi, phi, terrain):
        worst = [1e9] * 4
        for sigma, t_on, t_off in chi:                        # 逐接触模式
            S = support_polygon(sigma, phi)
            dcm = self._dcm(terrain.state_at(t_on))
            m_dcm = signed_dist(dcm, S.boundary)
            m_fric = self._friction_qp_margin(sigma, phi, self.mu_lb)
            m_reach = self._swing_reach_margin(sigma, phi)
            m_viab = self._viability(chi, phi)
            worst = [min(worst[0], m_dcm), min(worst[1], m_fric),
                     min(worst[2], m_reach), min(worst[3], m_viab)]
        beta = self._beta_bounds()
        cert = tuple(w - b for w, b in zip(worst, beta))
        if min(cert) < 0 or not self._qp_feasible:
            return None
        return Cert(cert, chi)

    def _beta_bounds(self):
        b_dcm = self.beta_c / self.omega_min + self.eps_h * tan(self.theta_max)
        b_fric = self.L_mu * self.eps_h + self.eta_slip
        return (b_dcm, b_fric, self.eps_h + self.delta_joint, b_dcm)

## 4. 推导

**引理 87（质心-接触证书的健全性）** 设 U_g 成立，单刚体质心模型一致误差 ‖F̂−F‖∞ ≤ β_c，地形高度误差 ≤ ε_h，摩擦系数下界 μ_f 已知。若分段证书 Ĉ_t 四项均 ≥0，则对块内每个接触模式 σ：(i) 真实 DCM 位于真实支撑多边形内且余量 ≥0；(ii) 真实接触力在摩擦锥内且余量 ≥0；(iii) 摆动腿在可达域内。证明：真实 DCM 与预测 DCM 之差 ≤ β_c/ω_min；地形高度误差使支撑多边形边界沿坡向内偏移 ε_h·tanθ_max，两者相加即 β_dcm。由三角不等式，真实裕度 ≥ 预测裕度 − β_dcm ≥ 0。摩擦项同理：QP 预测切向力误差 ≤ L_μ ε_h，叠加滑移积分余量 η_slip 后真实摩擦裕度 ≥0。可达项由 ε_h+δ_joint 膨胀。∎

**引理 88（触地前重规划的保守性）** 若 K_eff(t) ≤ K_phase(t)，则块执行前缀内的每次触地，其落脚点在块生成时均已被感知覆盖（不在 U_terr）；因此执行前缀不含「用旧地图验证的新触地」。进一步，若中块地形高度突变 ≥ ε_h 且感知/力觉总时延 T_sense 满足 T_sense + T_cap ≤ (m_dcm − β_dcm)/v_dcm,max，则守卫在 DCM 裕度耗尽前触发回撤，存在 p* ∈ P_t 安全重捕获。证明：K_phase 的定义保证第一个未验证触地被执行前即截断；突变情形由定义 544(iii) 的时延不等式与定义 545 的 δ_c 检测共同给出；三角不等式给出 v_dcm·(T_sense+T_cap) ≤ m_dcm−β_dcm。∎

**引理 89（相位门控的单调保守性与 v9 特例）** K_eff^{v10}(t) = min(K_eff^{v9}, K_phase, K_margin) ≤ K_eff^{v9}(t)。门控只截断候选前缀、不新增候选，故 v10 可执行动作集 ⊆ v9 可执行动作集。当 U_terr∩[t,t+K_max]=∅ 且 m_dcm ≥ τ_dcm 时 K_phase=K_margin=K_max，K_eff^{v10}=K_eff^{v9}，行为逐位一致。∎

**引理 90（支撑集替换代数与吸收安全元）** ⊙ 幂等（e 已移除时不变）；S(χ⊙e) ⊆ S(χ) 且每段模式支撑腿数递减，故替换只会收紧支撑多边形、不会放大可行域。有限次替换（至多 3 次单腿失效）后，若仍存在 m_dcm≥0 的时序则停在已认证站姿，否则输出 ⊥；⊥ 吸收，故任意后续替换不再改变状态。因此任意有限失效序列的像 ∈ {已认证站姿, ⊥}，二者均为安全侧。∎

**引理 91（接触一致性守卫的响应时间界）** 足端力觉 1kHz、主守卫 50Hz，滑移事件在 ≤2 个控制周期（≤40ms）内被 δ_c 捕获；若回撤时延 T_retract 满足 v_dcm·(40ms + T_retract) ≤ m_dcm − β_dcm，则回撤距离不超过可用裕度，回撤本身不引入新的 DCM 越界。证明：检测延迟上界由采样定理与 50Hz 守卫周期给出；回撤轨迹的 DCM 位移由速度上界 v_dcm 积分界定。∎

**引理 92（双类中立元的逐位等价退化）** 对退化表每行，将新端口置为其 v^⊗ 或 v^⊕ 后，下游端口读数与 v9 对应显式退化分支逐位一致：HCC/CCC 失效 → v9 AC 点质量证书与 v9 K_eff；相位门控失效 → K_phase=K_max 即 v9 门控；CSD 失效 → v9 安全停驻；接触一致性守卫失效 → v9 中块守卫 + 安全停驻。四类均旁路时 v10 主闭环与 v9 的差异仅剩类型检查器（无运行时副作用），故可观测日志逐位一致。结合 v9 引理 83 得 v10 → v9 → v8 → v7 → v6。∎

## 8. 本轮最大风险

**一句话**：质心-接触证书建立在「单刚体质心动力学 + 刚性接触 + 无滑移」之上，而四足最危险的接触失效——松软/湿滑地形的足端滑移、可变形地面的支撑塌陷、腿别造成的支撑集突变——恰好都在这套模型之外，于是系统可能在「最需要接触安全的地形上，用最不接触现实的接触模型」给出证书。
