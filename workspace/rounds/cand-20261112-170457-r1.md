# 第 61 轮（承接第 60 轮「场景感知闭环」IP-153~160；灵感循环第 7 轮；本轮灵感：「三维感知」×「用户测试」）

> 第 60 轮的 SGEC 打通了「场景→意图→约束→阻抗→执行→EV-exec→场景更新」的认知闭环，但仍有三处结构性缺口：
> 1. **证据的标量化/平面化**：EV-exec 仍是力、阻抗、时间戳的标量记录，场景语义由隐状态近似；真实接触是三维几何事件（接触法向、接触斑、曲率、穿透深度、剪切牵引），标量 K_safe 无法表达「方向性安全」——法向很硬但切向很软的阻抗可能数值合规、却在斜面上打滑。
> 2. **场景先验缺少几何条件**：π_scene(K|z) 只以场景标签 z 为条件，但同样叫「桌面」，曲率、粗糙度、边缘锐度不同，所需阻抗张量完全不同；几何不进入先验，就会把「桌子中央」的安全参数错误迁移到「桌子边缘」。
> 3. **自证循环与外部效度缺失**：第 60 轮所有证据都来自系统自身传感器与模型，系统只能证明「我认为我合规」，无法回答「用户是否感知到安全」「用户是否理解了意图」。用户测试尚未成为一等证据：没有噪声模型、没有统计功效设计、没有与物理证据之间的「接地差」度量。

## 0. 直觉与动机

**灵感 1（三维感知 → 执行几何场 EGF）**
直觉：一次接触不是一个点，而是一个**场**。把深度/点云与力/位姿融合成截断符号距离场（TSDF/SDF）φ(x)，接触集 C={x|φ(x)≤0}，接触法向 n=∇φ/|∇φ|，曲率 κ=∇·n，穿透深度 δ_pen，接触斑面积 A_c，切向牵引 τ_s。于是一条执行证据不再是「F=8N、K=200」，而是「在法向 n 上以 0.3mm 穿透、接触斑 42mm²、边缘曲率 8m⁻¹」。关键洞见：**安全是方向相关的张量性质，必须由几何场定义**，而标量证据只能事后报警，不能事前判定。

**灵感 2（三维感知 → 几何条件化各向异性阻抗 GAI）**
直觉：人类擦玻璃时「法向要硬、切向要软」，抓取杯子时「切向要硬、法向要柔」。把第 60 轮标量 K_safe 升级为接触系 (n,t₁,t₂) 下的 6×6 对称正定阻抗张量 K_3D = k_n·nnᵀ + k_t·(I−nnᵀ) + 转动块，并让场景先验以几何 g=(κ,粗糙度,边缘距) 为条件：π_scene(K_3D|z,g)。关键洞见：**曲率与边缘距离决定应力集中**，几何条件化能把「场景先验」从离散标签细化到连续几何，避免边缘处的抽象泄漏。

**灵感 3（用户测试 → 人因证据 HFE）**
直觉：用户是一个**有偏、有噪、会学习、会疲劳的外部传感器**。用户说「刚才有点吓人」「我没看懂它为什么停」，这不是主观噪声，而是关于可理解性与信任校准的测量值。把用户评分写成测量模型 y_{u,i}=μ(true)+b_u+e_{u,i}，用锚定试验（已知安全/危险）标定每个用户的偏置 b_u，用重测信度（ICC）与行为指标（干预率、完成时间）建立效度。关键洞见：**用户测试必须像传感器一样被校准，而不是像投票一样被平均**。

**灵感 4（用户测试 → 用户测试带 UBP）**
直觉：用户测试不是「跑几个人打几分」，而是一个**带统计功效、拉丁方平衡、盲法、停止规则**的协议带 P=(U,T,D,M,S)。同一用户看多个条件会学习，所以用被试内+拉丁方抵消顺序效应；主观量表会被期望效应污染，所以用盲法与行为指标交叉验证；样本小会假阳性，所以先做功效分析再定 N_u。关键洞见：**测试协议本身是被测量的测量仪器，仪器必须先被标定**。

**灵感 5（双灵感合流 → 双接地闭环 DGC）**
直觉：物理接地回答「实际上发生了什么」（三维几何证据），人因接地回答「人是否理解并接受」（用户测试证据）。两者不是互相替代，而是互为**外部校验**：R_3D 与 R_HF 的接地差 Δ_g 本身就是最有信息量的信号。Δ_g 小 ⇒ 物理安全与主观安全一致，可放心更新先验；Δ_g 大 ⇒ 必须分诊：是三维感知错了（H_p）、用户误解了（H_u）、还是系统真有缺陷（H_s）。关键洞见：**分歧不是噪声，而是可解释性的诊断入口**；简单平均两个证据源会把系统缺陷抹平。

**灵感 6（PCE+++++ → 五维/六维预算）**
直觉：三维融合要算力与显存，用户测试要人的时间与注意力，两者都是严格预算。把第 60 轮认知预算再扩展：B_3d（体素分辨率、SDF 更新频率、显存）、B_hf（被试数、每人试次、会话时长、疲劳上限）。B_3d 耗尽 ⇒ 回退到 2.5D 深度直方图代理并标记不确定；B_hf 耗尽 ⇒ 用已校准的用户代理模型，但置信度设上限，**绝不静默插补**。

## 1. 形式化定义（增量：定义 161–169）

**定义 161（三维执行几何场 EGF）** 时刻 t 的执行几何场
E_3D(t) = (φ_t, C_t, n_t, κ_t, δ_pen(t), A_c(t), τ_s(t), S_t)
其中：
- **SDF**：φ_t: ℝ³→ℝ 为截断符号距离场，C_t={x | φ_t(x)≤0} 为接触集
- **接触法向**：n_t(x)=∇φ_t(x)/|∇φ_t(x)|；**曲率**：κ_t(x)=∇·n_t(x)
- **穿透深度**：δ_pen(t)=max(0, −min_{x∈C_t} φ_t(x))
- **接触斑面积**：A_c(t)=∫_{C_t} dA；**剪切牵引**：τ_s(t) 为力旋量在切平面的投影
- **几何风险**：R_3D(t)=σ(α_n·m_n + α_t·m_t + α_δ·δ_pen/δ_max + α_κ·|κ|A_c^{1/2})，其中 m_n=(σ_n^max−σ_n)/σ_n^max，m_t=(τ_max−|τ_s|)/τ_max 为方向性安全裕度，σ(·) 为 logistic 压缩到 [0,1]。
EGF 的关键是：**接触证据从标量集合升级为带空间坐标与法向的场**，可被哈希、存档、重放（承接第 60 轮 EPIR）。

**定义 162（几何条件化各向异性阻抗 GAI）** 接触系 (n,t₁,t₂) 下的阻抗张量
K_3D = k_n·nnᵀ + k_t·(I−nnᵀ) + K_rot ∈ Sym⁺(6)
- **方向性安全集**：K_safe^dir(z,g)={K_3D≻0 | λ_min(K_3D)≥λ_min^safe，k_n≤κ_n^max(z,g)，k_t≤κ_t^max(z,g)，|K_{nt}|≤ρ·√(k_n k_t)}
- **几何条件化先验**：π_scene(K_3D|z,g)=N(logChol(K_3D); μ(z,g), Σ(z,g))，其中 g=(κ, 粗糙度, 边缘距离)
- **边缘保守化**：当边缘距离 d_edge<d_safe 时，κ_n^max 按 exp(−d_edge/d_safe) 收缩，使边缘处自动更柔
- **投影算子**：Π_safe(K)=argmin_{S∈K_safe^dir} ‖logChol(S)−logChol(K)‖²_Σ，保证编译结果始终落在方向性安全集内（承接 EEIS 编译）。

**定义 163（人因证据与用户噪声模型 HFE）** 用户 u 在第 i 个试次的观测
y_{u,i} = μ(true_i) + b_u + e_{u,i},  b_u~N(0,σ_b²),  e_{u,i}~N(0,σ_e²)
- **观测量**：y=(safety_rating, trust, workload, intent_match, preference)，前两项用累积链接序数模型映射为感知风险 R_HF
- **锚定校准**：用已知真值的锚定试次 A={a_j} 估计 b̂_u=mean_j(y_{u,a_j}−μ(true_j))，并估计 σ_e
- **信度**：重测信度 ICC(2,k)≥ρ_retest，评分者间 ICC≥ρ_inter
- **效度**：R_HF 与独立行为指标（人工干预率、完成时间、急停次数）的秩相关 ≥ρ_valid
- **合成**：R_HF = posterior_risk({y_{u,i}−b̂_u}, σ_e)，输出分布而非点估计。

**定义 164（用户测试协议带 UBP）** 协议 P=(U,T,D,M,S)：
- **被试** U：目标人群、纳入/排除标准、N_u 由功效分析给出
- **任务** T：覆盖场景×意图×几何边缘的因子化任务集
- **设计** D：被试内、拉丁方平衡、条件盲法（用户不知道系统版本）
- **指标** M：客观（成功率、干预率、恢复时间）+ 主观（安全、信任、NASA-TLX、SUS、意图匹配）
- **停止规则** S：序贯检验或固定样本；主分析用混合效应模型 y~condition+(1|user)+(1|task)
- **功效**：N_u ≥ f(δ_min, α=0.05, 1−β=0.8)，并在报告中给出实际效应量与置信区间。

**定义 165（双接地闭环 DGC）** 算子 DGC(M, z, I, δ_f_req, probe_points)：
```
① EGF:   E_3D ← integrate_3d_perception(depth, pose, force, mask)
② GAI:   K_3D ← compile_anisotropic(π_scene(·|z,g), E_3D, δ_f_req)；Π_safe 投影
③ CIEC:  C_intent ← ϕ(I)（第 60 轮）；ERTC.lock_constraints(C_intent)
④ Exec:  telemetry ← execute(K_3D, C_intent)
⑤ EV3D:  EV-exec-3D ← build_exec_evidence_3d(telemetry, E_3D)，含 E_3D 哈希与 seq_id
⑥ HFE:   R_HF ← hfe.aggregate(ubp.probe(probe_points)) 或 surrogate（标记低置信）
⑦ CPC:   Δ_g ← W₁(R_3D, R_HF)（Wasserstein 距离，归一化）
⑧ Triage: if Δ_g≤τ_g: 更新 π_scene 与信任；else: cause←cpc.diagnose(...)，分诊处理
⑨ Budget: 消耗 B_3d/B_hf；若耗尽走代理并降置信
⑩ Return (E_3D, K_3D, R_3D, R_HF, Δ_g, cause, status)
```

**定义 166（跨接地一致性 CPC 与接地差）** 给定物理风险分布 R_3D 与人因风险分布 R_HF：
- **接地差**：Δ_g = W₁(R_3D, R_HF)/Δ_max ∈ [0,1]，其中 W₁ 为一阶 Wasserstein 距离
- **一致性判定**：Consistent ⟺ Δ_g ≤ τ_g
- **分诊假设**：H_p（三维感知误差）、H_u（用户误解/期望偏差）、H_s（系统真实缺陷）
- **判别依据**：物理测量可重复性 ρ_3d（重复观测的方差倒数）与用户共识可重复性 ρ_hf（ICC）
  - ρ_3d 高、ρ_hf 低 ⇒ H_u（用户侧问题，注入解释/再校准）
  - ρ_3d 低、ρ_hf 高 ⇒ H_p（感知侧问题，重融合/降分辨率/换视角）
  - 两者都高且持续分歧 ⇒ H_s（真实缺陷，降级或回滚，禁止用平均掩盖）
- **保守原则**：分诊不确定时取 max(R_3D,R_HF) 作为风险下界，偏向安全。

**定义 167（五维/六维预算 PCE+++++）** B_all=(B_3d,B_hf,B_scene,B_intent,B_ros,B_exec)：
- **B_3d**=(voxel_resolution, SDF_fps, voxel_memory, raycast_budget)
- **B_hf**=(N_users, trials_per_user, session_minutes, fatigue_cap)
- **成本**：cost_3d=λ_vox·Fusion_cost+λ_ray·Query_cost；cost_hf=λ_time·Σ_session_minutes+λ_fatigue·Fatigue(N_u,trials)
- **VOI 扩展**：voi_all(π)=VOI_internal(π)−cost_3d(π)−cost_hf(π)−cost_cog(π)−cost_exec(π)
- **耗尽策略**：B_3d<θ_3d ⇒ 2.5D 深度直方图代理，R_3D 方差上界放大；B_hf<θ_hf ⇒ 已校准代理用户模型，置信度上限 γ_hf^max；任一预算耗尽必须显式写入证据证书，禁止静默替代。

**定义 168（信任-能力校准 TAC）** 信任状态 T_t 与物理风险 R_3D(t)：
- **信任更新**：T_{t+1}=clip(T_t + α(r_t−T̂_t) + γ·Δ_g·s_t, 0, 1)，r_t 为结果反馈，s_t 为解释信号
- **校准误差**：CE_t=|T_t−R_3D(t)|
- **过信任**：T_t>R_3D+ε_trust（危险，用户会放任系统）；**欠信任**：T_t<R_3D−ε_trust（低效，用户会频繁干预）
- **目标**：min E[CE_t]，约束 P(过信任)≤δ_trust；即**校准信任而非最大化信任**——解释的目标是把 T 拉向 R，而不是把 T 拉高。

**定义 169（双接地决策 DGD）** 给定场景序列 Z、意图序列 I、用户群体 U：
```
if ∀z_i: SIC_valid(z_i,K_3D^scene(z_i)) and Δ_g(z_i)≤τ_g and CE≤ε_trust:
    选取 K_3D = argmax_{K∈∩K_safe^dir(z_i,g_i)} EU(K | R_3D, R_HF)
elif cause=H_p:  re-perceive（换视角/降分辨率/多帧融合）；若仍失败→K_conservative
elif cause=H_u:  注入解释并重测；若仍失败→降低自动化等级（L2→L1）
elif cause=H_s:  回滚到第 60 轮标量 K_safe（已知安全的降级路径）并记录缺陷
else:            return DEGRADE_EXEC
```
关键：**双接地不是把两个分数加权平均，而是先判一致性、再分诊、最后才决策**；H_s 必须显式回滚，不能被「共识」掩盖。

## 2. 关键算法伪代码

### IP-161 EGF（三维执行几何场）

```python
class ExecutionGeometryField:
    def __init__(self, voxel=0.005, trunc=0.04):
        self.voxel = voxel
        self.trunc = trunc
        self.tsdf = TSDFVolume(voxel, trunc)

    def integrate(self, depth, pose, seg_mask, force):
        self.tsdf.fuse(depth, pose, seg_mask)          # O(V)
        phi = self.tsdf.field
        C = (phi <= 0.0)
        n = self._normal(phi)                          # ∇φ/|∇φ|
        kappa = self._divergence(n)
        A_c = C.sum() * self.voxel ** 2
        delta_pen = max(0.0, -phi[C].min()) if C.any() else 0.0
        tau_s = shear_traction(force, n)
        return E3D(phi, C, n, kappa, delta_pen, A_c, tau_s)

    def risk(self, e3d, sigma_n_max, tau_max):
        m_n = (sigma_n_max - normal_stress(e3d)) / sigma_n_max
        m_t = (tau_max - norm(e3d.tau_s)) / tau_max
        z = 2.0*m_n + 2.0*m_t - 5.0*e3d.delta_pen - 0.1*abs(e3d.kappa).mean()
        return sigmoid(z)
```

### IP-162 GAI（几何条件化各向异性阻抗）

```python
def compile_anisotropic(scene_prior, e3d, delta_f_req):
    g = (e3d.kappa.mean(), roughness(e3d.phi), edge_distance(e3d))
    mu, Sigma = scene_prior.condition(e3d.n.mean(axis=0), g)
    K = sample_logchol(mu, Sigma)                     # 6x6 SPD
    k_n_max = base_k_n(g) * exp(-g.edge_distance / d_safe)
    K = project_directional_safe(K, k_n=k_n_max, k_t=base_k_t(g),
                                 lam_min=LAMBDA_MIN, rho=RHO_MAX)
    return K, Cert(K, delta_f_req, g)
```

### IP-163/164 HFE + UBP（人因证据与测试带）

```python
class HumanFactorsEvidence:
    def calibrate(self, anchors):
        for u in anchors.users:
            self.bias[u] = np.mean([y - true_mu for y, true_mu in anchors[u]])
        self.sigma_e = pooled_std(anchors)

    def aggregate(self, ys):
        z = [y - self.bias[u] for u, y in ys]
        return posterior_risk(z, self.sigma_e)        # 返回分布

def analyze_ubp(data):
    # y ~ condition + (1|user) + (1|task)，拉丁方已平衡顺序
    m = mixed_effects("y ~ condition + (1|user) + (1|task)", data)
    return m.estimates, m.ci95, icc(data), power_report(data)
```

### IP-165/166 DGC + CPC（双接地闭环与分诊）

```python
def dual_grounding_loop(M, scene, intent, delta_f_req, probes):
    e3d = M.egf.integrate(M.depth, M.pose, M.mask, M.force)
    K3, cert = M.gai.compile_with_scene_prior(scene, e3d, delta_f_req)
    M.intent_ctrl.receive_intent(intent)
    telemetry = execute(K3, M.intent_ctrl.active_constraints)
    ev3d = build_exec_evidence_3d(telemetry, e3d)
    M.epir.append(ev3d)

    R3 = M.egf.risk(e3d, sigma_n_max, tau_max)
    if M.budget.hf_available(probes):
        Rhf = M.hfe.aggregate(M.ubp.run(probes))
    else:
        Rhf = M.hfe.surrogate(probes, conf_cap=GAMMA_HF_MAX)
    dg = wasserstein1(R3, Rhf) / DELTA_MAX

    if dg <= TAU_G:
        M = update_priors(M, e3d, Rhf)
        cause = "consistent"
    else:
        cause = M.cpc.diagnose(e3d, R3, Rhf,
                               rho_3d=repeatability(e3d),
                               rho_hf=icc(M.recent_ubp))
        M = handle_conflict(M, cause, R3, Rhf)
    M = consume_budgets(M, e3d, probes)
    return M, e3d, K3, R3, Rhf, dg, cause
```

class AllBudget:

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| EGF | O(V) 融合/帧，O(V) SDF 查询 | O(V) 体素 | 法向误差 ≤5°，穿透误差 ≤1mm，接触斑 IoU ≥0.85 |
| GAI | O(1) 6×6 SPD 编译与投影 | O(1) | 方向性安全集内，边缘保守化 |
| HFE | O(N_u·N_trials) 聚合 | O(N_u) | 校准后偏置下降 ≥50%，ICC ≥0.75 |
| UBP | O(N_u·N_trials·|conditions|) 分析 | O(N) | 功效 ≥0.8 才启动主分析 |
| DGC | O(EGF + 闭环 + 分诊) | 复用 | Δ_g 检测 F1 ≥0.85，误分诊 ≤10% |
| PCE+++++ | O(1) 预算判定 | O(1) | 任一耗尽显式降级并写入证书 |

**正确性定理（DBG, Dual-Binding Guarantee）**：

### IP-161 EGF（三维执行几何场）

```python
class ExecutionGeometryField:
    def __init__(self, voxel=0.005, trunc=0.04):
        self.voxel = voxel
        self.trunc = trunc
        self.tsdf = TSDFVolume(voxel, trunc)

    def integrate(self, depth, pose, seg_mask, force):
        self.tsdf.fuse(depth, pose, seg_mask)          # O(V)
        phi = self.tsdf.field
        C = (phi <= 0.0)
        n = self._normal(phi)                          # ∇φ/|∇φ|
        kappa = self._divergence(n)
        A_c = C.sum() * self.voxel ** 2
        delta_pen = max(0.0, -phi[C].min()) if C.any() else 0.0
        tau_s = shear_traction(force, n)
        return E3D(phi, C, n, kappa, delta_pen, A_c, tau_s)

    def risk(self, e3d, sigma_n_max, tau_max):
        m_n = (sigma_n_max - normal_stress(e3d)) / sigma_n_max
        m_t = (tau_max - norm(e3d.tau_s)) / tau_max
        z = 2.0*m_n + 2.0*m_t - 5.0*e3d.delta_pen - 0.1*abs(e3d.kappa).mean()
        return sigmoid(z)
```
