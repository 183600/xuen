# 第 69 轮（承接第 68 轮「CALM-RAS 标定感知风险自适应闭环」IP-243~252；本轮灵感：「跨物体泛化」×「行为树」）

> 第 68 轮把「测量是否可信」升级为在线潜变量 c_t，用自监督与单模型多任务把标定、归因、放行串成闭环。但它留下一个比缓变故障更根本的未言明前提：**安全契约与行为是「物体无关」的**。COF 能解释传感器为什么歪，却无法解释「同一套动作，为什么在这个物体上安全、在另一个物体上危险」。τ_risk、力上限、抓取策略、回退逻辑都只在训练物体分布上被验证；一旦物体换了，测量可以完全准确，契约却已经失效。
>
> 跨物体泛化不是「特征能不能迁移」的问题，而是「**风险余量能不能迁移、迁移失败时能不能被看见**」的问题。行为树也不是工程编排的语法糖，而是一族**可组合验证的策略模式（policy schema）**：叶节点携带契约，选择器携带保守序，回退是内建的安全动作。
>
> 核心命题：
>
> **把跨物体泛化重新表述为「物体条件化的风险契约迁移」：用物体签名与共形新颖度把开集物体映射到原型风险上界，用风险标注行为树（RABT）把「不确定性只能收紧」从标量阈值提升为策略拓扑，用行为树嫁接（BTG）在相似物体上复用已验证子树、在新颖物体上退化为安全探测，用契约监控（CMB）在任务层独立设防——GRAFT-RAS（Generalization via Risk-Annotated Fallback Trees）。**
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「**对这个物体，我还敢用同样的力度、同样的策略吗**」——泛化失败不可怕，可怕的是泛化失败时系统仍然自信地执行激进分支。

## 0. 直觉与动机

**灵感 1（跨物体泛化 → 泛化的不是特征，而是风险余量）**
直觉：一个抓取策略可以在视觉上「泛化」得很好，却在安全上完全失败。陶瓷杯和喷了金属漆的塑料杯可以有几乎相同的几何签名，却有不同的质量、柔顺与易碎性；同一个动作，一个安全，一个灾难。深度表征把「看起来像」变成「处理起来像」，但安全契约必须回答「**后果是否也像**」。因此跨物体泛化至少包含三层，且缺一不可：
1. **表征泛化**：不同物体映到可比较的签名；
2. **风险迁移**：在一个物体上认证的风险上界，在签名相近的物体上仍然成立；
3. **契约迁移**：动作的前置/后置条件与安全不变式在目标物体上仍然成立。
R68 只补了测量层，R69 补的是第 2、3 层。关键纪律与 R68 同构：**新颖性不是探索奖励，而是安全信号；越不认识的物体，动作攻击性只能越低。**

**灵感 2（行为树 → 从「一个策略」到「一族可验证策略」）**
直觉：端到端策略把安全性和任务性纠缠在一个网络里，失败时无法定位是「看错了」「估错了」还是「契约不适用」。行为树把策略拆成可审计的节点：条件叶回答「这个物体、这种不确定性下我有没有资格执行」，动作叶携带契约与风险预算，选择器按攻击性降序排列，回退是显式的、可验证的保守动作。于是安全证明可以像搭积木一样组合：**若每个叶在其物体区域内安全，且选择器的守卫对不确定性单调，则整棵树在物体漂移下仍然安全。**
更重要的是，行为树给「泛化」提供了第三种可能：不是让一个策略覆盖所有物体，而是**在已验证的子树库里做选择与嫁接**。这比端到端模型更诚实——它不假装无所不能，它只承诺在认识范围内激进、在认识范围外保守。

**灵感 3（两者合流 → 物体条件契约层）**
直觉：把 R68 的不确定序扩成 u_t = (ν_t, U_cal, U_emo, U_wm)，其中 ν_t 是物体新颖度；把 R68 的「不确定只收紧」从 λ_floor 一个标量，提升为**执行攻击性 a(u) 的单调不增**。行为树的选择器是这条纪律的天然载体：
- 新颖度低、原型覆盖好 → 走已验证的激进子树；
- 新颖度中 → 降级到更保守的叶子，并缩减风险预算 β；
- 新颖度高 → 强制进入 Probe/Explore，只做安全探测，不允许接触丰富动作。
这不是「为了保守而保守」，而是把**开集泛化的不可知性显式编码进控制拓扑**。

**灵感 4（对 R68 最大风险的正交补丁）**
直觉：R68 的最大风险是缓变故障落在标定带宽内、被 COF「标好」而隐形。GRAFT 无法也不应去改标定带通，但它增加了一条**任务层、与标定独立的证据通道**：契约监控 CMB。即使 COF 认为一切正常，缓变故障仍会改变力、位移、滑移的后置条件统计；CMB 在任务层看到的是「承诺没有兑现」，而不是「传感器是否漂移」。两条通道正交，任何一条报警都只收紧。这不能完全消除 R68 的风险，但把它从「单点防线」变成「双通道冗余」。

**灵感 5（为什么不直接堆域随机化/更大模型）**
直觉：域随机化覆盖的是采样到的分布，给不出开集保证；更大模型提高平均成功率，却不会告诉你「这一个物体是否在支持集内」。GRAFT 的立场是：**不承诺泛化一定成功，只承诺泛化失败时系统优雅退化且可验证**。这在安全关键场景里比平均精度更重要。它把「泛化能力」重新定义为「在未知物体上保持安全不变式的能力」，而不是「在测试集上不失分的能力」。

**灵感 6（合流 → GRAFT-RAS 七组件）**
1. **OPI Object Prototype Identifier**：复用 MTM trunk，新增 obj_head，输出物体签名 o_t 与共形新颖度 ν_t；
2. **XTR Cross-object Risk Transfer**：原型风险加权 + Lipschitz 距离项 + 共形分位数，给出上界 R̄(o)；
3. **RABT Risk-Annotated Behavior Tree**：节点携带 (Pre, Post, Inv, β, a)，选择器按 a 降序，守卫对 u 单调；
4. **BTG Behavior-Tree Grafting**：契约嵌入匹配 → 复用已验证子树 / 插入 Explore→Probe 安全梯；
5. **CMB Contract Monitor**：任务层后置条件与不变式在线监控，违反即回退并审计；
6. **NPG Novelty-Priority Guard**：ν 超阈值时根节点强制 Probe/Explore，禁用激进叶；
7. **RAS-CALM† 继承核**：CALM-RAS 全部保留（COF/CFA/CAC/MTM/SSG），只在其上增加物体条件层与树拓扑层。

## 1. 形式化定义（增量：定义 293–308）

**定义 293（GRAFT-RAS 总览）** GRAFT-RAS = (OPI, XTR, RABT, BTG, CMB, NPG, RAS-CALM†)。四条新增不变式：
(i) **对象条件安全**：每个动作叶的契约在其原型邻域 B_ℓ 上成立，而不是只在训练实例上成立；
(ii) **单调回退**：同一选择器内子节点按攻击性严格降序，守卫对不确定性序 u 单调不增；
(iii) **新颖性零激进**：ν_t > τ_nov ⇒ 根执行器只允许 Probe/Explore 子树，一切接触丰富或大力量叶被禁用；
(iv) **认证生长**：原型库与行为树库的任何增删改都走 CAC† 五关认证的原子提交，实时流零学习写操作（继承 R68 不变式 i）。

**定义 294（物体签名与原型库）** o_t = φ_obj(z_t, g_t, ι_t) ∈ ℝ^{32}，其中 z_t 为 MTM trunk 潜状态，g_t 为几何描述（点云尺度、主轴、曲率、拓扑统计），ι_t 为交互描述（质量、惯量、摩擦、柔顺的在线估计，来自 CALM 的力残差与抓取阶段）。原型库 𝒫 = {(o_k, R_k, 𝕋_k, B_k)}_{k=1}^{K}：o_k 为原型签名，R_k 为经认证的风险上界，𝕋_k 为已验证行为子树集，B_k 为契约成立的原型邻域（半径 r_k 的球或椭球）。

**定义 295（共形新颖度）** 令 s(o) = d_(1)(o) = min_k ‖o − o_k‖₂；在留出原型上计算自距离校准集 {s_j}。定义共形 p 值 p(o) = (1 + Σ_j 1[s_j ≥ s(o)])/(n_cal + 1)，新颖度 ν_t = 1 − p(o_t) ∈ [0,1]。阈值取 τ_nov = 1 − α_nov，则在同分布物体上 P(ν > τ_nov) ≤ α_nov。此定义把「不认识」变成一个有分布无关误报率的可校准量，而不是拍脑袋的距离阈值。

**定义 296（风险标注行为树 RABT）** RABT = (N, E, n_0, C, Ψ, ρ)。节点类型：Sequence(→)、Selector(?)、Parallel(⇉)、Condition、Action、Recovery。标准 tick 语义返回 SUCCESS/FAILURE/RUNNING，Selector 返回第一个非 FAILURE 子节点；所有 Condition 叶每 tick 反应式重估。每个节点 n 携带契约 C_n = (Pre_n, Post_n, Inv_n, β_n, a_n)。动作叶封装既有组件：ACH 提议叶、EFS 风险缩放叶、C-RAS-WM 前缀叶、CALM 标定叶、Probe 安全探测叶。

**定义 297（节点契约与攻击性）** 对动作叶 ℓ：
- Pre_ℓ(o, ĉ, U, ν)：可执行前提（物体落在 B_ℓ、ν、U、R̄ 满足预算）；
- Post_ℓ：任务后置条件（位移 ≤ d_max、接触力 ∈ [f_min, f_max]、滑移 ≤ s_max、位姿误差 ≤ e_max）；
- Inv_ℓ：安全不变式（碰撞力 ≤ F_safe、不跌落、不越界、不越速）；
- β_ℓ ∈ [0,1]：风险预算（允许的最大 λ_risk）；
- a_ℓ = E[Δsuccess_ℓ]/ρ_ℓ ∈ ℝ_+：攻击性，ρ_ℓ 为最坏违反代价。
组合契约：Sequence 要求 Post_{n_i} ⇒ Pre_{n_{i+1}}；Selector 要求所有子节点共享同一目标谓词且 a 严格降序；Parallel 取各子契约的合取与不变式交集。

**定义 298（不确定性序与守卫单调性）** u_t = (ν_t, Ũ_cal, Ũ_emo, Ũ_wm) ∈ [0,1]^4，其中 Ũ = U/(1+U)。定义偏序 u ≼ u′ ⇔ 逐分量 ≤。守卫 g_n: [0,1]^4 × 𝒪 → {0,1} 称为单调，若 u ≼ u′ ⇒ g_n(u, o) ≥ g_n(u′, o)。动作叶守卫：
`g_ℓ(u,o) = 1[o ∈ B_ℓ] · 1[ν ≤ τ_nov] · 1[Ũ_cal ≤ τ_cal] · 1[β_ℓ − L_κ·d(o,B_ℓ) ≥ R̄(o)]`。
最后一项把「契约松弛随物体失配线性下降」写进守卫（见引理 17）。

**定义 299（跨物体风险迁移 XTR）** 对 o 的 m 个最近原型：
`R̄(o) = Σ_{k∈NN_m(o)} w_k(o)·R_k + L_R·d_(1)(o) + q̂_{1−α_tr}`，
`w_k(o) = exp(−d(o,o_k)/h) / Σ_j exp(−d(o,o_j)/h)`。
L_R 为风险对签名距离的认证 Lipschitz 常数；q̂ 为留出「物体对」上迁移残差 R* − Σ w R_k 的共形分位数。当 ν > τ_nov 时直接令 R̄ = R_max（悲观上限），不允许外推。含义：**越远越悲观，越新越不许外推**。

**定义 300（行为树嫁接 BTG）** 给定 (o, ν, R̄)，BTG: (𝕋, o) → T′：
1. 计算契约嵌入 κ(T_k) = (目标谓词、叶契约签名、B_k 中心、β 向量)；
2. 匹配分数 δ_k = d_κ(κ(T_k), κ_target) + γ·d(o, o_k)；
3. 若 min_k δ_k ≤ τ_graft 且 ν ≤ τ_nov：复用 T_k，并对每个叶重参数化 β_ℓ ← β_ℓ − L_κ·d(o, B_k)，再剪除 β_ℓ < R̄(o) 的叶；
4. 否则：构造 T′ = Selector(Explore(o), Probe_Ladder)，Explore 只做安全探测以改进 o 与 ν，Probe 为最保守叶；
5. 强制 enforce_monotone(T′)：同一 Selector 的子节点按 a 降序重排并校验守卫单调。
「嫁接」是跨物体泛化的操作化定义：**复用被验证过的行为，而不是复用未经证明的权重。**

**定义 301（契约运行时监控 CMB）** 每个 tick 对活动叶 ℓ 计算归一化违约度
`e_ℓ,t = max(F_max(t)/F_safe − 1, d(t)/d_max − 1, s(t)/s_max − 1, |x(t)−x_post|/e_max − 1)`。
若 e_ℓ,t > 1：叶返回 FAILURE，Selector 前进到更保守子节点（回退），写审计记录，并把带删失的风险观测回灌 XTR；若 e_ℓ,t > 1 − δ_warn：提前收紧 λ 与 β（预警）。CMB **不读取也不写入 COF 标定状态**，是任务层独立通道。

**定义 302（单调回退阶梯 MFL）** 设 Selector S 的子节点 ℓ_1,…,ℓ_m 满足 a_1 > a_2 > … > a_m = 0（最后为 Probe），守卫 g_i 单调。执行索引
`i*(u) = min{ i : g_i(u,o)=1 ∧ ℓ_1,…,ℓ_{i−1} 均未 SUCCESS }`。
则 u ≼ u′ ⇒ i*(u) ≤ i*(u′) ∧ a_{i*(u)} ≥ a_{i*(u′)}：不确定性增加只能让执行更保守，绝不可能更激进。

**定义 303（新颖性优先守卫 NPG）** 根节点规则：ν_t > τ_nov ⇒ 强制 T = Selector(Explore, Probe)，并将所有动作限制在安全探测包络 `ℰ_probe = {‖f‖ ≤ F_probe, ‖v‖ ≤ v_probe, 时长 ≤ T_probe}`。若连续 N_probe 次探测后 ν 仍 > τ_nov，则保持 Probe 并请求外部帮助（人/远程），不进行自主激进操作。

**定义 304（物体条件证书 J_obj）** J_obj = (J_CALM, o_hash, NN_ids, ν, R̄(o), tree_hash, {verdict_ℓ}, commit_verdict†)。Valid ⇔ Valid(J_CALM) ∧ R̄(o) ≤ R_max ∧ 树通过单调性校验 ∧ 所有活动叶守卫为真 ∧ (ν > τ_nov ⇒ 根为 Probe/Explore)。证书按对象实例签发，随物体签名与树哈希绑定。

**定义 305（干扰集）** ℰ_GRAFT = ℰ_CALM × ℰ_obj × ℰ_tree：
ℰ_obj = {新颖性假阴性（签名碰撞/对抗伪装）、原型污染、迁移乐观偏差、开集长尾物体}；
ℰ_tree = {嫁接错配、契约漏检、回退抖动/恢复环、树结构非单调、审计缺失}。

**定义 306（管线）** 离线：R68 的 MTM 预训练 → 物体签名编码器与风险头训练（仿真 + 真机少量）→ 原型库构建与风险认证 → 共形校准 (q̂, τ_nov) → 从已验证技能契约合成树库 𝕋。在线：每 tick OPI→(o,ν) → XTR→R̄ → BTG（带滞回缓存，仅在 o 或 ν 跃迁时重嫁接）→ RABT tick（MFL）→ CMB 监控 → 异步审计与 CAC† 认证生长。

**定义 307（统一风险纪律）** 攻击性 A_t = a_{i*(u_t)} 对 ν 与 U_cal 单调不增；风险下限
`λ_floor(u) = max(0.6, 0.8·1[Ũ_cal > τ_cal ∨ ν > τ_nov ∨ R̄ > R_max])`。
R68 的 λ_floor 只处理测量与预测不确定性；R69 把物体不确定性并入同一纪律：**任何「我不认识/我不确定」都只能抬高下限**。

**定义 308（物体相对安全集）** S(o) = { x : 活动叶的 Inv_ℓ 与 Post_ℓ 在裕度内成立 }。GRAFT 的目标不是最大化 S(o) 的覆盖，而是保证轨迹在概率 ≥ 1−α_total 下前向不变地留在 S(o) 内，并在 S(o) 过小时退化为 Probe（见定理 16）。

## 2. 关键算法骨架

```python
# IP-253 OPI：物体签名 + 共形新颖度
class ObjectPrototypeIdentifier:
    def __init__(self, encoder, bank, cal_scores, tau_nov):
        self.enc, self.bank = encoder, bank
        self.cal_scores, self.tau_nov = np.sort(cal_scores), tau_nov

    def infer(self, z, geo, inter):
        o = self.enc(z, geo, inter)                  # ℝ³²
        d, idx = self.bank.query(o, k=2)             # 最近、次近
        p = (1 + np.sum(self.cal_scores >= d[0])) / (len(self.cal_scores) + 1)
        nu = 1.0 - p                                 # 共形新颖度
        return o, nu, idx, d

# IP-254 XTR：越远越悲观的风险上界
def transfer_risk(o, nu, bank, L_R, q_tr, R_max, tau_nov):
    if nu > tau_nov:
        return R_max, None                           # 开集：禁止外推
    d, idx = bank.query(o, k=bank.m)
    w = softmax(-d / bank.h)
    R_bar = float(np.dot(w, bank.R[idx])) + L_R * d[0] + q_tr
    return min(R_bar, R_max), idx

# IP-255 RABT：风险标注 + 单调回退
class RiskAnnotatedBehaviorTree:
    def tick(self, u, o, R_bar):
        for leaf in self.ladder:                     # a_1 > a_2 > ... > a_m = 0
            if not leaf.guard(u, o, R_bar):
                continue
            status = leaf.action.tick()
            if status in (SUCCESS, RUNNING):
                return status, leaf
            audit(leaf, u, R_bar)                    # FAILURE → 下一档更保守
        return FAILURE, self.probe

# IP-256 BTG：嫁接或安全退化
def graft(tree_lib, o, nu, R_bar, tau_nov, tau_graft):
    if nu > tau_nov:
        return Selector([Explore(o), ProbeLadder()])
    dk = [tree_lib.match(t, o) for t in tree_lib]
    k = int(np.argmin(dk))
    if dk[k] > tau_graft:
        return Selector([Explore(o), ProbeLadder()])
    T = clone(tree_lib.trees[k])
    for leaf in T.leaves:
        leaf.beta -= L_kappa * tree_lib.dist(o, k)
    T = prune(T, lambda leaf: leaf.beta >= R_bar)
    return enforce_monotone(T)

# IP-257 CMB：任务层契约监控（不碰 COF）
def contract_monitor(leaf, obs_after):
    e = max(norm_violation(leaf.post, obs_after),
            norm_violation(leaf.inv, obs_after))
    if e > 1.0:
        audit({'leaf': leaf.id, 'e': e, 'channel': 'TASK_INDEPENDENT'})
        return FAILURE
    if e > 1.0 - DELTA_WARN:
        tighten_budget(leaf, factor=1.0 + K_WARN * (e - (1 - DELTA_WARN)))
    return SUCCESS

# IP-258 主闭环：GRAFT-RAS round（R68 前端 + 物体条件树）
def GRAFT_RAS_round(M, obs):
    z, o_head = M.mtm.forward(obs)                        # R68 一次前向
    c, U, thr = M.cof.step(o_head['cal'], residuals(...)) # R68 标定

    o, nu, idx, _ = M.opi.infer(z, geo_of(obs), inter_of(obs))

    R_bar, nn = M.xtr(o, nu)
    T = M.btg.maybe_regraft(o, nu, R_bar)                 # 滞回：o/ν 跃迁才重嫁接
    if nu > TAU_NOV:
        T = M.npg.force_probe(T)                          # 新颖性零激进

    u = (nu, U/(1+U), emo_unc(o_head), wm_unc(o_head))
    status, leaf = T.tick(u, o, R_bar)                    # MFL 单调回退
    tau = leaf.dispatch() * max(M.efs.risk_scale(...), thr['lam_floor'])
    M.cmb.observe(leaf, obs)                              # 独立契约监控

    M.vqa_c.submit_async(T, {'o': o, 'nu': nu, 'R_bar': R_bar, 'u': u})
    M.cac_graft.maybe_commit(M.proto_shadow, M.tree_shadow)
    return status, tau, (o, nu, R_bar)
```

## 3. 推导

**引理 16（迁移风险上界）** 在 A95（风险对物体签名的 Lipschitz 性：|R*(o) − R*(o′)| ≤ L_R‖o−o′‖）与 A96（距离分层可交换性）下，XTR 上界满足 P(R*(o) ≤ R̄(o)) ≥ 1 − α_tr。且 R̄ 随 d_(1) 单调增、随原型密度单调减；当 ν > τ_nov 时 R̄ = R_max，保证开集区域绝不乐观外推。

证明要点：把真实风险分解为「原型风险加权 + 距离项 + 残差项」；原型风险由认证 R_k 覆盖，距离项由 Lipschitz 控制，残差项由共形分位数以 1−α_tr 覆盖。注意每个 d(o,o_k) ≥ d_(1)，故加权距离不小于 d_(1)，悲观性成立。

**引理 17（嫁接契约松弛）** 若子树 T_k 在原型 o_k 上满足契约，且契约谓词对物体签名 L_κ-Lipschitz，则将 T_k 嫁接到 o 后，契约裕度至少为原裕度 − L_κ‖o−o_k‖。因此叶的可用风险预算必须从 β_ℓ 中扣除 L_κ·d，否则会出现「几何上像、物理上不像」的乐观迁移。

证明要点：Pre/Post/Inv 是签名上的 Lipschitz 函数，签名移动 d 使谓词值最多变化 L_κ·d，裕度按同量收缩；当收缩后 β_ℓ < R̄(o) 时该叶被剪除，只能走更保守叶。

**引理 18（单调回退的保守性）** 在定义 302 下，u ≼ u′ ⇒ i*(u) ≤ i*(u′) 且 a_{i*(u)} ≥ a_{i*(u′)}。即不确定性增加不可能让执行更激进。

证明要点：守卫单调不增 ⇒ 在 u′ 可执行的叶在 u 也可执行，故第一个可执行索引不增；a 对索引严格降序，故攻击性不增。

**引理 19（契约监控对标定盲区的正交覆盖）** 设缓变故障 f 被 COF 吸收（ω_f < ω_cal，标定后残差 < τ_det），但 f 使任务后置条件产生偏差 Δ_post(f)。在 A97（Δ_post(f) ≥ ε_post > 0）与 A98（CMB 噪声有界）下，CMB 在 T_det 内检出概率 ≥ 1 − α_cmb，且该检出与 U_cal 无关。故 R68 的「缓变故障隐形」在任务层被部分恢复为可见；代价是 CMB 只能看见「影响任务的故障」，对任务无关的慢漂移仍然不可见（也不需要对它可见）。

**定理 16（GRAFT-RAS 跨物体安全与优雅退化）** 在 A92–A98 下：
1. **前向不变**：P(∀t, x_t ∈ S(o_t)) ≥ 1 − (α_nov + α_tr + α_cmb + α_cal + α_tree)；
2. **单调退化**：执行攻击性 A_t = a_{i*(u_t)} 对 ν_t 与 U_cal 单调不增（引理 18、定义 307）；
3. **新颖性零激进**：ν_t > τ_nov ⇒ 根只执行 Probe/Explore，且 ‖f‖ ≤ F_probe、‖v‖ ≤ v_probe（定义 303）；
4. **优雅性能下界**：若原型库对 o 的最近邻覆盖率为 c(o)，则任务成功率 ≥ (1−ν)·c(o)·S_reuse + ν·S_probe；即泛化失败退化为探测，而不是失稳；
5. **迁移增益**：相对无原型库的平面 RAS，近原型物体成功率提升 Δ_transfer，且风险不升（由引理 16 的上界约束）。

**定理 17（原型库与树库的认证生长）** 将 CAC 扩为 CAC†，新增两关：
- **新颖性假阴性关（novelty canary）**：注入一组「外观相近、物理不同」的对抗物体，要求 ν 至少高于 τ_nov 的比例 ≥ r_nov（否则拒绝新原型，防止签名碰撞稀释新颖性）；
- **树单调性关**：对候选树做随机 u 采样，验证 Selector 子节点 a 严格降序与守卫单调，否则拒绝。
在 canary 检出率 r_nov ≥ 0.95、金标回归衰减 ≤ 1% 时，被污染原型/非单调树上线的概率 ≤ 0.05·p_poison；回滚失败落入 ℰ_tree 并触发全局 Probe 降级。

## 6. 本轮最大风险

**一句话：整套安全性押在「物体签名足以区分后果」与「共形新颖度不产生假阴性」上——若两个物理后果迥异的物体在签名空间里碰撞（外观/几何近而质量、柔顺、摩擦远），ν 会保持低值，XTR 输出乐观上界，BTG 嫁接激进子树，系统就会在「我认识这个物体」的错觉下执行错误契约；即泛化能力越强，那个恰好落在签名盲区里的物体越隐形——这是跨物体泛化的原罪：你无法用有限原型证明一个无限开集上的契约。**

**次级风险与缓解**：
1. **签名碰撞/affordance spoofing**：单模态签名不足 → 多模态签名（几何 × 交互 × 语义）+ 主动探测激励 + E293 对抗测试；
2. **原型污染**：在线吸收坏原型 → CAC† 的 novelty canary 关 + 原型来源溯源 + 认证原子提交；
3. **迁移乐观偏差**：Lipschitz 常数低估 → 用留出物体对做上界校准 + 保守取 q̂ 高分位 + 超界即降级；
4. **回退抖动/恢复环**：守卫在阈值附近反复翻转 → 滞回带 + 最小驻留时间 + 回退计数器；
5. **契约漏检**：Post/Inv 未覆盖真实失效模式 → 契约来自失效模式分析（FMEA）+ 影子回放 + VQAuditor-G 反事实审计。

## 3. 关键算法伪代码

```python
# IP-253 OPI：物体签名 + 共形新颖度
class ObjectPrototypeIdentifier:
    def infer(self, z, geo, inter):
        o = self.enc(z, geo, inter)                       # ℝ³²
        d, idx = self.bank.query(o, k=2)
        p = (1 + np.sum(self.cal_scores >= d[0])) / (len(self.cal_scores) + 1)
        return o, 1.0 - p, idx, d                          # (o, ν, NN, dists)

# IP-254 XTR：越远越悲观的风险上界
def transfer_risk(o, nu, bank, L_R, q_tr, R_max, tau_nov):
    if nu > tau_nov:
        return R_max, None                                # 开集禁止外推
    d, idx = bank.query(o, k=bank.m)
    return min(float(np.dot(softmax(-d / bank.h), bank.R[idx]))
               + L_R * d[0] + q_tr, R_max), idx

# IP-255 RABT：风险标注 + 单调回退
class RiskAnnotatedBehaviorTree:
    def tick(self, u, o, R_bar):
        for leaf in self.ladder:                          # a_1 > ... > a_m = 0
            if leaf.guard(u, o, R_bar):
                st = leaf.action.tick()
                if st in (SUCCESS, RUNNING):
                    return st, leaf
                audit(leaf, u, R_bar)                     # FAILURE → 更保守叶
        return FAILURE, self.probe

# IP-256 BTG：嫁接或安全退化
def graft(tree_lib, o, nu, R_bar, tau_nov, tau_graft):
    if nu > tau_nov:
        return Selector([Explore(o), ProbeLadder()])
    dk = [tree_lib.match(t, o) for t in tree_lib]
    k = int(np.argmin(dk))
    if dk[k] > tau_graft:
        return Selector([Explore(o), ProbeLadder()])
    T = clone(tree_lib.trees[k])
    for leaf in T.leaves:
        leaf.beta -= L_kappa * tree_lib.dist(o, k)        # 契约松弛（引理 17）
    return enforce_monotone(prune(T, lambda l: l.beta >= R_bar))

# IP-257 CMB：任务层契约监控（独立于 COF）
def contract_monitor(leaf, obs_after):
    e = max(norm_violation(leaf.post, obs_after),
            norm_violation(leaf.inv, obs_after))
    if e > 1.0:
        audit({'leaf': leaf.id, 'e': e, 'channel': 'TASK_INDEPENDENT'})
        return FAILURE
    if e > 1.0 - DELTA_WARN:
        tighten_budget(leaf, 1.0 + K_WARN * (e - 1.0 + DELTA_WARN))
    return SUCCESS

# IP-262 主闭环：GRAFT-RAS round
def GRAFT_RAS_round(M, obs):
    z, o_head = M.mtm.forward(obs)                        # R68 一次前向
    c, U, thr = M.cof.step(o_head['cal'], residuals(...)) # R68 标定
    o, nu, idx, _ = M.opi.infer(z, geo_of(obs), inter_of(obs))
    R_bar, nn = M.xtr(o, nu)
    T = M.btg.maybe_regraft(o, nu, R_bar)                 # 滞回缓存
    if nu > TAU_NOV:
        T = M.npg.force_probe(T)                          # 新颖性零激进
    u = (nu, U/(1+U), emo_unc(o_head), wm_unc(o_head))
    status, leaf = T.tick(u, o, R_bar)                    # MFL 单调回退
    tau = leaf.dispatch() * max(M.efs.risk_scale(...), thr['lam_floor'])
    M.cmb.observe(leaf, obs)                              # 独立契约监控
    M.vqa_c.submit_async(T, {'o': o, 'nu': nu, 'R_bar': R_bar, 'u': u})
    M.cac_graft.maybe_commit(M.proto_shadow, M.tree_shadow)
    return status, tau, (o, nu, R_bar)
```

## 4. 推导

**引理 16（迁移风险上界）** A95（风险对签名 L_R-Lipschitz）与 A96（距离分层可交换）下，P(R*(o) ≤ R̄(o)) ≥ 1 − α_tr。R̄ 随 d_(1) 单调增、随原型密度单调减；ν > τ_nov ⇒ R̄ = R_max，开集绝不乐观外推。

**引理 17（嫁接契约松弛）** 契约谓词 L_κ-Lipschitz ⇒ 嫁接到 o 后的裕度 ≥ 原裕度 − L_κ‖o−o_k‖；可用风险预算必须扣除 L_κ·d，否则出现「几何像、物理不像」的乐观迁移。

**引理 18（单调回退保守性）** 守卫单调不增 + 子节点攻击性严格降序 ⇒ u ≼ u′ 时 i*(u) ≤ i*(u′)、a_{i*(u)} ≥ a_{i*(u′)}。不确定性增加不可能让执行更激进。

**引理 19（CMB 对 COF 盲区的正交覆盖）** 缓变故障被 COF 吸收后（标定残差 < τ_det）若仍使任务后置条件偏差 ≥ ε_post，则 CMB 在 T_det 内检出概率 ≥ 1−α_cmb，且与 U_cal 无关。代价：只可见「影响任务的故障」，任务无关慢漂移仍不可见（也无需可见）。

**定理 16（GRAFT-RAS 跨物体安全与优雅退化）** A92–A98 下：
1. P(∀t, x_t ∈ S(o_t)) ≥ 1 − (α_nov + α_tr + α_cmb + α_cal + α_tree)；
2. 攻击性 A_t = a_{i*(u_t)} 对 ν_t 与 U_cal 单调不增；
3. ν_t > τ_nov ⇒ 根只执行 Probe/Explore，且 ‖f‖ ≤ F_probe、‖v‖ ≤ v_probe；
4. 任务成功率 ≥ (1−ν)·c(o)·S_reuse + ν·S_probe：泛化失败退化为安全探测，而非失稳；
5. 近原型物体相对平面 RAS 成功率 +Δ_transfer，且风险不升（引理 16）。

**定理 17（CAC† 认证生长）** 新增「新颖性假阴性关（novelty canary）」与「树单调性关」。canary 检出率 r_nov ≥ 0.95、金标回归衰减 ≤ 1% 时，污染原型/非单调树上线的概率 ≤ 0.05·p_poison；回滚失败落入 ℰ_tree 并触发全局 Probe 降级。

## 7. 本轮最大风险

**一句话：整套安全性押在「物体签名足以区分后果」与「共形新颖度不产生假阴性」上——若两个物理后果迥异的物体在签名空间里碰撞（外观/几何近而质量、柔顺、摩擦远），ν 会保持低值，XTR 输出乐观上界，BTG 嫁接激进子树，系统就会在「我认识这个物体」的错觉下执行错误契约；即泛化能力越强，那个恰好落在签名盲区里的物体越隐形——这是跨物体泛化的原罪：你无法用有限原型证明一个无限开集上的契约。**

**次级风险与缓解**：签名碰撞/affordance spoofing（多模态签名 + 主动探测 + E293）；原型污染（CAC† novelty canary + 来源溯源）；迁移乐观偏差（Lipschitz 上界校准 + 保守分位数 + 超界降级）；回退抖动/恢复环（滞回带 + 最小驻留 + 回退计数）；契约漏检（FMEA 驱动契约 + 影子回放 + VQAuditor-G 反事实审计）。
