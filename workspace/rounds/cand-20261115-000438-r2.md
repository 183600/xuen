# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；本轮灵感：「课程学习」×「力觉传感」）

> R69 第一次让系统学会「问」——看、问、触都是可生成、可认证、可审计的信息动作，并把不确定性一分为二。但它留下两个被自己最大风险点破、却尚未回答的问题：
> **（i）凭什么相信这个信息源？** 流模型的模态权重可能未校准，语言回答可能被投毒；R69 只用一道二值 MCG（全局 ECE ≤ τ）把整个模态分布判生判死，且对「看/触/问」三种通道一视同仁，没有可信度之分——**低信任源与高信任源在 VoI 里等权**。
> **（ii）先问谁、按什么顺序问？** R69 的 VoI 是单步贪心，把所有歧义摆上天平按瞬时收益比排序；但「先问什么」决定了后面还能问什么——先被污染的证据会把后验带偏，便宜的交互可能耗尽预算却只换来无关信息（R69 引理 16 已点明：模糊而不可分的项，交互无益）。
>
> 本轮两个灵感正好补上这两块：
> - **力觉传感**给出一个**因果接地**的证据通道——力/触觉直接测量接触本身；要让它说谎，攻击者必须真的施加力、真的改变接触状态，代价高且会被力/力矩守恒暴露。它天然是接触丰富任务里的**原级标准（primary standard）**，可以用它去校准视觉、世界模型、乃至语言通道。R69 里 `g_probe` 只是众多信息动作之一，R70 把「触」升格为**锚**。
> - **课程学习**给出**顺序**——消解歧义不该按瞬时 VoI 贪心，而应按难度从易到难、从物理到社交、从可信到待验证地推进；更关键的是，**信任本身应当被「修」出来，而不是被假设**：每个证据通道要通过逐步加难的校准课程逐级获得授权，未毕业的通道只能做旁证、不能单独定案。
>
> 核心命题：**把 R69 的「问谁」升级为「凭什么信它、先信谁」——用力觉做锚、用课程做序，把证据信任从二值开关变成逐级挣得的能力，并把「课程序」本身纳入安全与投毒的威胁模型。** 命名 **TACT-RAS**（Tactile-Anchored Curriculum-guided Trust）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「该问谁、还能问什么」，R70 问「**我凭什么信它、又该先信谁**」。

## 0. 直觉与动机

**灵感 1（力觉是最后的物理真值 → 锚）**
直觉：视觉会被遮挡与光照骗，世界模型会被分布外场景骗，语言会被社交工程骗；但接触力不会凭空出现——你要让力传感器读到 20N，就得真的压上去 20N。力觉因此不是「又一路传感器」，而是**能反过来给其他模态定标尺的参照物**：抓取是否真的闭合、是否在滑、夹多紧才不碎、插孔到底差多少，这些接触丰富任务的核心歧义，力觉给的是物理上不可争辩的答案。R69 把 `g_probe` 当作一个可选的信息动作；R70 把它升格为**原级标准**：其他通道的可靠性只有相对力觉锚的「校准链」才有意义。

**灵感 2（课程学习 → 消解有难度序，贪心是错的）**
直觉：人不会一上来就问最难的问题。老师按「最近发展区」给题，学生按难度爬坡；跳过台阶去啃难题，既挫败又学不到。R69 的 VoI 贪心有一个静默假设：所有歧义项彼此独立、顺序无关。但现实里（a）预算有限，先花掉的预算买不回；（b）难项的信息增益估计本身更不可靠，容易高估；（c）先消解易项能**降低后续项的难度**（拿到接触状态后，很多几何/语义歧义自动塌缩）。所以消解应该有一个**课程序**：从可分性高、成本低、物理可锚的项开始，把超出现有能力（ZPD）的项推到队尾——**不硬问，先审计或兜底**。

**灵感 3（信任课程 → 通道权限是挣来的，不是假设的）**
直觉：R69 的 MCG 是一个二值总闸：模态权重 ECE 达标就全开，不达标就全关。这把「视觉可信但语言不可信」「接触类可信但语义类不可信」这类真实结构压平了。更合理的做法是给每个通道一张**信任等级证书**（0 禁用 / 1 仅旁证 / 2 条件授权 / 3 单方授权），等级由逐级加难的审计（干净→加噪→遮挡→分布外→对抗投毒）**挣得**，失配则降级。语言通道初始只能做旁证，且在对接触/几何的判定上**永久封顶为旁证**——这正面封堵 R69 的「问错比不问更危险」。

**灵感 4（力觉伪标签 → 用物理真值给流模态打标签，修 R69 的校准洞）**
直觉：R69 最大风险是「流模态分布不可信」。但很多接触事件的结果是可观测的物理事实：抓取后力曲线稳定在 stick 且载荷不滑 = 闭合成功；瞬时力尖峰后切向力骤降 = 滑脱。这些高置信接触事件能反推「哪一动作模态是对的」，给模态权重和 mode_head 提供**锚伪标签**。再用课程学习按伪标签难度分桶（力信噪比高的先学），就把 R69 的全局 ECE 拆成**分桶 ECE**：难桶失准就局部冻结，而不是让它污染全局、也不是被全局平均掩盖。

**灵感 5（锚也会坏、课程也会被投毒 → 假锚比无锚更危险）**
直觉：一旦系统把力觉奉为原级标准并赋予最高权限，攻击面就集中到一个点：**让锚说假话**（传感器漂移/饱和/温漂/安装偏置/物理篡改），或者**让课程被操纵**（把投毒样本伪装成「简单项」诱骗系统提前授权）。此时课程越推进、信任越高，系统越自信地错，且假锚能绕过 R69 的多源一致纪律。所以本轮必须同时交付：力觉自检与锚持出集、假易项审计、锚冲突即降级冻结、以及「锚失效时的安全退化路径」。否则 R70 不是进步，而是给 R69 装了一个**不会撒谎但会坏掉的真值表**。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（TACT-RAS 总览与四不变式）** TACT-RAS = (TAC, ANCHOR, CDM, CCR, TCL, TDF, AuthGate, FSS, ACC, CMC, PAC, J_TACT, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i；力觉前哨亦不得在线改参）；
(ii) **信任单调授权**：通道权限只能由审计课程逐级授予，任何越级授权视为无效（fail-closed）；
(iii) **力觉锚定优先**：物理接触类歧义在力觉可用时，未经与力觉锚一致的模态不得定案；
(iv) **课程可审计**：每个消解/授权决策须携带难度估计、所用通道信任等级与锚一致性，进入证书。

**定义 311（接触状态与力觉证据）** 接触状态 c_t ∈ 𝒞 = {free, make, stick, slip, break}；测得六维力/力矩 w_t = (f_t, τ_t)，标称接触模型 ŵ(o_t; c_t)。力觉残差
r_tac = ‖w_t − ŵ(o_t; c_t)‖²_{Σ_w^{-1}} / (1 + ‖w_t‖²)
（归一化，跨量程可比）。接触状态转移受物理约束（如 stick→slip 需超过库仑阈值），**不可任意跳变**——这是力觉因果接地性的来源。

**定义 312（力觉锚定证据通道）** R69 的证据五元组升级为六元组 ℰ⁺ = ℰ_CALM ∪ {r_tac}。力觉不是普通残差：它是**因果接地**观测（定义 311 的转移约束），职责不止投票，更是校准其他通道可靠性的**原级标准**。

**定义 313（锚定伪标签 ANCHOR）** 当接触事件高置信可分（如抓取后 r_tac 稳定于 stick 且载荷不滑），由 (c_t, 成功/失败) 反推「哪一动作模态是对的」，生成伪标签 y_anchor ∈ {1..K̂} 及置信 α。准入：α ≥ α_min 且该事件不在攻击者可影响集合内（定义 324）。

**定义 314（课程难度度量 CDM）** 对每个待消解项 i（歧义模态或待校准通道）
d_i = w_1(1 − sep_i) + w_2·U_epi,i/U_ref + w_3·c(g_i)/c_ref + w_4(L_req − L_{c_i})_+ + w_5·risk_i，
sep 为模态可分性（Δ_min/σ_in），L_req 为该歧义类所需信任等级，L_{c_i} 为通道当前等级。**课程假设 A101：d_i 与成功消解所需信息量单调一致。**

**定义 315（课程化消解调度 CCR）** 维护待消解队列 Q，按 d_i 升序处理；仅接纳 d_i ≤ κ_t 的项（最近发展区 ZPD，定义 316），超出者不强行交互，而转「审计/委派」或走 R68 兜底。每轮至多处理预算允许的项，且**不允许跨难度跳跃**：要跳到更难的项，须先由独立锚降低其 d 估计。

**定义 316（能力水平与课程推进）** κ_t ∈ [0,3] 为当前能力（可处理难度上限），满足 κ_{t+1} ≥ κ_t，除非检测到锚一致性破坏（定义 324）时 κ_t ← κ_t − Δκ。推进规则：连续 n_pass 个 d ≤ κ_t 的消解成功且被力觉锚确认 ⇒ κ 上调；任一锚冲突 ⇒ 冻结并复核。

**定义 317（信任等级与信任课程 TCL）** 每个证据通道 c ∈ {tac, vis, wm, ask} 有等级 L_c ∈ {0,1,2,3}：0 禁用；1 仅旁证（只改似然、不能定案）；2 条件授权（需 ≥1 正交源一致）；3 单方授权（在本通道优势歧义类可单独定案）。等级由**审计阶梯**逐级授予（干净→加噪→遮挡→分布外→对抗投毒），通过则 L←L+1，连续失配则 L←L−1 并重审。**语言通道初始 L_ask=1，且在接触/几何歧义类上永久封顶为 1。**

**定义 318（信任折扣贝叶斯融合 TDF）** 通道 c 的证据 e_c 按可靠性 ρ_c(L_c) ∈ [0,1] 温控，融合后验
p(M|ℰ⁺) ∝ p(M) Π_c p(e_c|M)^{ρ_c(L_c)}。
ρ_c 由审计可靠图拟合（ρ=1 完全采信，ρ→0 忽略）。低信任源只能弱推后验，不能翻转高信任源主导的结论（引理 20）。

**定义 319（通道权限 AuthGate）** Auth(𝒜_class, c)=1 ⇔ L_c ≥ L_req(𝒜_class, c)，歧义类 𝒜_class ∈ {contact, geom, semantic, dynamics}。权限矩阵 A（类×通道）示例：contact：tac=3、vis=2、wm=2、ask=1；geom：tac=2、vis=3、wm=2、ask=1；semantic：tac=1、vis=2、wm=1、ask=3；dynamics：tac=3、vis=2、wm=2、ask=1。未达权限不得单独定案（fail-closed）。

**定义 320（力觉安全前哨 FSS）** 快环（≥1kHz）监测 w_t、ẇ_t 与 r_tac：滑移前兆（切向力比/微振动/力率异常）、过力（|f|>f_max）、失接触（状态跳变）、力率越界（|df/dt|>ḟ_max）⇒ 立即预紧/退让/停机。FSS 不经学习层、不等慢环，**只收紧不放松**（定理 19）。

**定义 321（力觉原级标准与跨通道校准 ACC）** 以力觉锚为参考重标定其他通道的残差阈值与可靠性：用滑移事件的力觉预测误差更新 vis 的接触信任；用 r_tac 与 r_geo/r_wm 的相干性检测视觉/世界模型漂移。形式化为可追溯关系 r_tac ⇝ ρ_c：其他通道的可靠性只有挂在力觉校准链上才有意义。

**定义 322（课程化模态校准 CMC）** 用定义 313 的锚伪标签按难度分桶（d 的分位桶）训练/校准 mode_head 与模态权重 ŵ_k；每桶单独测 ECE_b。要求 max_b ECE_b ≤ τ_ece；任一分桶越界即**冻结该桶对应的 VoI 决策（局部 MCG）**，而非 R69 的全局停用。这修正「全局 ECE 掩盖难桶失准」的盲点。

**定义 323（课程化风险退避）** λ 随课程进度与信任等级分档：全部由 L≥2 且力觉锚确认 ⇒ λ=λ_floor(U_ale)（resolution bonus）；仅由 L=1 旁证支持 ⇒ λ=λ_floor(U_ale + β_U·U_epi)，β_U∈(0,1] 随 L 降低而增大；未消解/超预算/锚冲突 ⇒ λ=λ_floor(U_ale+U_epi)。β_U=1 即 R69，β_U→0 即完全采信，课程给出连续插值。

**定义 324（防投毒课程 PAC）** 课程不得被数据投毒操纵：维护攻击者不可影响的**锚持出集** 𝒜_hold（已知标定质量、接触物理、力觉自检动作），用于 (i) 估计真实难度 d̂_i 并审计声称的 d_i，若 |d_i − d̂_i| > τ_d 判为「假易项」并隔离；(ii) 检测锚一致性破坏（r_tac 与 𝒜_hold 预测不符）；(iii) 冻结信任升级与 κ 推进。任何来自 ask/vis 的「这是简单项」声明，须经力觉/持出集复核才能改变课程顺序。

**定义 325（证书 J_TACT）** J_TACT = (J_FLUID, r_tac_p95, contact_state_confusion, trust_levels{L_c}, curriculum_progress κ_t, per_bucket_ECE_max, anchor_coverage γ, poison_flags, tact_ver)。Valid ⇔ Valid(J_FLUID) ∧ max_b ECE_b ≤ τ_ece ∧ γ ≥ γ_min ∧ 无未决 poison_flag ∧ 权限矩阵无越级。

**定义 326（三时间尺度与严格包含）** 快环（FSS，≥1kHz，无学习）、中环（TACT 消解，≤2.8ms）、慢环（信任课程/模态校准，分钟级离线）。力觉不可用 ⇒ L_tac=0、ℰ⁺=ℰ_CALM 且信任矩阵坍缩为 R69 的二值 MCG；课程为空（κ=0 且无待消解）⇒ 逐指令退化为 FLUID-RAS；再关闭交互 ⇒ 退化为 R68。故 **R68 ⊂ FLUID ⊂ TACT**，安全侧逐层不弱。

## 2. 关键算法骨架

```python
# IP-264 TAC：力觉接触状态与残差（快环，无学习）
class TactileAnchor:
    def step(self, w, dw, o_t):
        c = contact_fsm(w, dw)                    # free/make/stick/slip/break，物理转移约束
        r_tac = norm(w - contact_model(o_t, c), Sigma_w) / (1 + norm(w)**2)
        return c, r_tac

# IP-265 ANCHOR：高置信接触事件 -> 模态伪标签（慢环）
def anchor_label(c, r_tac, success, alpha_min):
    alpha = confidence(c, r_tac, success)
    if alpha < alpha_min or in_attacker_reach(): return None
    return PseudoLabel(mode=argmax_mode_posterior(), alpha=alpha)

# IP-266/267 CDM+CCR：难度度量与课程化消解调度（ZPD）
def schedule(queue, kappa, budget):
    for i in queue: i.d = difficulty(i)           # 定义 314
    queue.sort(key=lambda i: i.d)
    return [i for i in queue if i.d <= kappa][:budget.n]   # 超 ZPD 不硬问，转审计/兜底

# IP-268 TCL：信任阶梯（审计通过升级，失配降级）
def trust_update(L, audit):
    for c in L: L[c] = min(3, L[c] + 1) if audit.pass_(c) else max(0, L[c] - 1)
    return L

# IP-269 TDF：信任折扣贝叶斯融合
def fuse(prior, evidence, rho):
    post = prior
    for c, e in evidence.items():
        post = post * tempered_likelihood(e, rho[c])   # p(e|M)^{rho_c}
    return normalize(post)

# IP-270 AuthGate：权限门（fail-closed）
def can_decide(cls, chan, L, A):
    return L[chan] >= A[cls][chan] and A[cls][chan] >= 2

# IP-271 FSS：力觉安全前哨（最快环，只收紧）
def force_sentinel(w, dw, lim):
    if norm(w.force) > lim.f_max or norm(dw.force) > lim.fdot_max:
        return Preempt(retract=True, hard=True)
    if slip_precursor(w, dw):
        return Preempt(grip_up=True)              # 只增夹持/退让，不放松
    return None

# IP-272 ACC：以力觉为原级标准校准其他通道
def recalibrate(vis_res, wm_res, r_tac, hist):
    return update_reliability(coherence(r_tac, vis_res, hist),
                              coherence(r_tac, wm_res, hist))

# IP-273 CMC：按难度分桶做模态校准（局部 MCG）
def curriculum_mode_calib(labels, buckets):
    for b in buckets:
        if fit_and_calibrate(labels[b]) > TAU_ECE: freeze_voi_for_bucket(b)
    return max_bucket_ece(labels, buckets)

# IP-274 PAC：防投毒课程（锚持出集 + 假易项隔离）
def poison_guard(queue):
    for i in queue:
        if abs(i.claimed_d - difficulty_from_holdout(i, A_hold)) > TAU_D:
            quarantine(i); freeze_trust_upgrade(); i.kappa_penalty = DELTA_K
    return queue

# IP-276 TACT-RAS 主闭环（快/中/慢三时间尺度）
def TACT_RAS_round(M, obs):
    # 快环：力觉前哨永远先跑，不依赖学习
    pre = M.fss.step(obs.w, obs.dw)
    if pre and pre.hard: return pre.act()          # 物理预紧/退让，绕过学习层
    c, r_tac = M.tac.step(obs.w, obs.dw, obs.o)
    # 中环：继承 FLUID 的流采样与不确定性二分
    z, o = M.mtm.forward(obs); c_cal, U_cal, _ = M.cof.step(obs)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, obs.o, obs.o_cal)
    slow  = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    # 1) 课程排序：按难度，仅处理 ZPD 内的项；假易项隔离
    queue = build_items(modes, U_epi, r_tac, M.L, M.kappa)
    todo  = M.pac.poison_guard(M.ccr.schedule(queue, M.kappa, M.budget))
    # 2) 逐项用「够格的通道」消解；力觉锚优先
    resolved, U_epi_after = [], U_epi
    for item in todo:
        chan = choose_channel(item, M.L, M.A)       # Auth 矩阵，fail-closed
        e    = execute(chan, item)                  # tac/vis/ask...
        post = M.tdf.fuse(item.posterior, {chan: e}, M.rho)
        if M.auth.can_decide(item.cls, chan, M.L, M.A) and anchor_agree(post, r_tac):
            U_epi_after -= item.gain; resolved.append(item)   # 否则只作旁证，不消解
    # 3) 课程推进 / 回退
    if resolved and all(anchor_agree(r, r_tac) for r in resolved):
        M.kappa = min(3, M.kappa + eta)
    if any(conflict(r, r_tac) for r in resolved):
        M.kappa = max(0, M.kappa - dk); M.trust.freeze()
    # 4) 风险退避：按信任等级与是否消解取 λ（定义 323）
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + beta_U(U_epi_after, M.L)))
    A = M.ach.propose(...); k = M.c_ras_wm.certified_prefix(A, ...)
    if slow: lam = max(lam, 0.8); k = min(k, k_cal_shrink(A, U_cal))
    mode = select_mode(modes, U_epi_after, lam, M.L)
    # 5) 慢环：锚伪标签 -> 分桶校准；审计 -> 信任课程（异步）
    y = M.anchor.label(c, r_tac, M.last_success)
    if y: M.cmc.submit(y)
    M.j_tact.submit(r_tac, M.L, M.kappa, M.cmc.max_bucket_ece)
    return k, lam, mode, (U_ale, U_epi_after)
```

## 3. 推导

**引理 19（力觉锚的欺骗代价下界 / 非对称可伪造性）** 设攻击者伪造一项证据的代价为 C_spoof。语言通道单次欺骗代价 ~0（只需说错话）；力觉通道要让测得 w_t 与假接触状态 c̃ 自洽，必须真实施加产生该 w 的外力/力矩，或物理篡改传感器，代价 ≥ E_min(c̃)（由力/力矩守恒与执行器功率下界给出）。在 A100（无物理接触权限即不能改力觉）下，力觉欺骗率 δ_tac ≤ δ_ask·e^{−λ_c E_min}。系：**同等攻击预算下力觉是最难被投毒的证据通道**，故适合作原级标准（定义 321）。

**引理 20（信任折扣下低信任源不可翻转）** 设最大信任源 c* 的对数似然差 Δ* = log[p(e_*|M=1)/p(e_*|M=0)] > 0，且其余通道的加权支持上界 Σ_{c≠c*} ρ_c|Δ_c| < Δ*，则融合后验仍倾向 M=1，即低信任源不能推翻高信任源主导的决策。系：L=1 的旁证通道（含语言）在多源冲突时**只能降低置信、不能改写结论**——这正面封堵 R69「问错比不问更危险」。

**引理 21（课程化的交互预算收益）** 设待消解项难度 d_i 与单位预算信息增益单调反相关（A101），预算 B 固定。按难度升序处理（CCR）相较按瞬时 VoI 贪心，ZPD 内完成的期望项数 ≥ 贪心，且**浪费在不可解项上的交互次数** ≤ ⌈κ_t 以内的项数⌉。要点：贪心会被「高 VoI 但不可分（Δ_min 小）」的项吸走预算（R69 引理 16 的系已指出这类交互无益），课程先用可分性/成本把这类项排到队尾，且先解易项会降低后续项难度（条件化塌缩）。

**引理 22（锚伪标签的分桶校准一致性）** 若在难度桶 b 上锚伪标签准确率 ≥ 1−ε_anchor、覆盖 γ_b ≥ γ_min，且伪标签与真实模态在给定接触事件下条件独立，则分桶模态 ECE_b ≤ ε_anchor + O(1/√(γ_b n_b))。系：**用物理锚监督流模态，可把 R69 的全局 ECE 盲点拆成分桶可证**；难桶越界即被定义 322 局部冻结，不再拖累全局，也不被全局平均掩盖。

**定理 18（TACT 严格包含 FLUID 与 R68）** 在 A100–A102 下：(i) 关闭力觉（L_tac=0、ℰ⁺=ℰ_CALM）且信任矩阵坍缩为二值 MCG ⇒ TACT 与 FLUID 逐指令相同；(ii) 再置课程为空、永不交互 ⇒ 与 R68 逐指令相同；(iii) 对任意状态，TACT 期望风险 ≤ FLUID ≤ R68（力觉前哨只会额外收紧 λ 与 k，定义 323、定理 19）。故安全侧逐层不弱，效率侧每一步放松都由「挣得的信任等级」作抵押。

**定理 19（力觉前哨的无突变与最坏时延界）** FSS 在快环（周期 T_f）直接作用于测得 w_t、ẇ_t，不经学习写操作；预紧/退让动作有界加加速度（jerk ≤ j_max），且只增夹持/减速度。若滑移前兆检测时延 ≤ τ_d 且 τ_d < t_slip（安全裕度），则接触力不越 f_max、工件不脱落的概率 ≥ 1−ε_fss（A102 的滑移前兆单调性）。与 R68 定理 15 的换装不变式相容 ⇒ 提交连续、无突变。

**定理 20（课程 + 锚下的投毒授权上界）** 在 PAC（定义 324）启用、锚持出集不可被攻击者影响、且信任升级要求连续 n_pass 次锚确认的条件下，攻击者使某通道被越级授权的概率 ≤ (δ_p·ρ^{k−1})^{n_pass}·2^{−L_req} + ε_hold。系：课程越往后（L_req 越高），伪造「假易项」骗过课程所需的一致欺骗越多，投毒收益指数衰减；它与 R69 引理 18 的多源一致纪律叠加，而非替代。

## 6. 本轮最大风险

**一句话**：TACT-RAS 的全部安全与效率论证押在「力觉锚是因果接地、可信且未被物理篡改」这一前提上——一旦锚本身失效（力传感器漂移/饱和/温漂/安装偏置，或攻击者获得物理接触权限），系统会把**假锚当真值**：用错误的力觉去校准视觉/世界模型/语言，用错误的伪标签去训练 mode_head，并让信任课程把别的通道也逐级「带歪」。更糟的是，力觉在权限矩阵里被赋予最高等级（contact/dynamics 类可单方定案），因此**假锚是唯一能绕过 R69 多源一致纪律的单点**：课程越推进、信任越高、系统越自信地错。**锚错，比无锚更危险。**

**次级风险与缓解**：
1. **力觉漂移/温漂** → 自检动作 + 锚持出集 + 交叉校准（定义 321/324），漂移检测即降 L_tac、冻结课程；
2. **物理篡改/传感器攻击** → 力/力矩守恒一致性、执行器电流与力矩双通道冗余、J_TACT 审计；
3. **课程被投毒（假易项/假标签）** → PAC 难度审计 + 锚持出集 + 定理 20；
4. **ZPD 过保守导致课程停滞**（κ 不升，退化为 R68）→ 把「安全自检」本身作为课程推进动作；
5. **分桶 ECE 数据稀疏（难桶样本少）** → 分层采样 + 置信下界，样本不足桶直接禁用而非默认放行。

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** 零学习写操作继承；信任只能由课程逐级授予（fail-closed）；接触类歧义须过力觉锚一致；每个消解/授权决策须携带难度、信任等级与锚一致性入证。

**定义 311–312（力觉证据与锚通道）** `c_t` 受物理转移约束；`r_tac` 归一化；`ℰ⁺=ℰ_CALM ∪ {r_tac}`；力觉不只是残差，更是校准其他通道的原级标准。

**定义 313（ANCHOR）** 高置信接触事件 `(c_t, success)` 反推正确模态，生成 `y_anchor`，准入 `α ≥ α_min` 且不在攻击者可影响集。

**定义 314–316（CDM / CCR / κ）** `d_i = w1(1−sep)+w2·U_epi/U_ref+w3·c/c_ref+w4(L_req−L_c)_+ +w5·risk`；按 d 升序、仅接纳 `d_i ≤ κ_t`（ZPD）；成功且锚确认则 κ 升，锚冲突则冻结/回退。

**定义 317–319（TCL / TDF / AuthGate）** 通道等级 0–3，审计阶梯升级、失配降级；`p(M|ℰ⁺) ∝ p(M)Π p(e_c|M)^{ρ_c}`；`Auth=1 ⇔ L_c ≥ A[cls][c]`，未达权限不得单独定案；语言在接触/几何类永久封顶为旁证。

**定义 320–321（FSS / ACC）** 快环监测滑移前兆、过力、失接触、力率，只收紧不放松；以力觉为参考重标定 vis/wm 的残差阈值与可靠性（可追溯关系 `r_tac ⇝ ρ_c`）。

**定义 322（CMC）** 用锚伪标签按难度分桶校准 mode_head 与 ŵ_k，逐桶测 `ECE_b`；`max_b ECE_b > τ_ece` 即局部冻结该桶 VoI，而非全局停用。

**定义 323（课程化退避）** 全锚确认 ⇒ `λ=λ_floor(U_ale)`；仅 L=1 旁证 ⇒ `λ=λ_floor(U_ale+β_U U_epi)`；未消解/冲突 ⇒ `λ=λ_floor(U_ale+U_epi)`；`β_U=1` 即 R69。

**定义 324（PAC）** 锚持出集估计真实难度、审计假易项、检测锚一致性破坏、冻结信任升级与 κ；任何「这是简单项」声明须经力觉/持出集复核。

**定义 325–326（证书与包含）** J_TACT 并入 r_tac、等级、课程进度、分桶 ECE、锚覆盖、投毒标志；三时间尺度；`R68 ⊂ FLUID ⊂ TACT`。

## 3. 关键算法伪代码

```python
# IP-264 TAC：力觉接触状态 + 残差（快环，无学习）
def tactile_anchor(w, dw, o):
    c = contact_fsm(w, dw)                              # 物理转移约束
    return c, norm(w - contact_model(o, c), Sigma_w)/(1 + norm(w)**2)

# IP-265 ANCHOR：高置信接触事件 -> 模态伪标签（慢环）
def anchor_label(c, r_tac, success, alpha_min):
    a = confidence(c, r_tac, success)
    return PseudoLabel(argmax_mode_posterior(), a) if a >= alpha_min else None

# IP-266/267 CDM+CCR：难度排序 + ZPD 门控
def schedule(queue, kappa, budget):
    for i in queue: i.d = difficulty(i)
    queue.sort(key=lambda i: i.d)
    return [i for i in queue if i.d <= kappa][:budget.n]      # 超 ZPD 不硬问

# IP-268 TCL：信任阶梯
def trust_update(L, audit):
    return {c: min(3, L[c]+1) if audit.pass_(c) else max(0, L[c]-1) for c in L}

# IP-269 TDF：信任折扣融合
def fuse(prior, evidence, rho):
    for c, e in evidence.items(): prior = prior * tempered_likelihood(e, rho[c])
    return normalize(prior)

# IP-271 FSS：力觉前哨（只收紧）
def force_sentinel(w, dw, lim):
    if norm(w.force) > lim.f_max or norm(dw.force) > lim.fdot_max:
        return Preempt(retract=True, hard=True)
    return Preempt(grip_up=True) if slip_precursor(w, dw) else None

# IP-273 CMC：分桶模态校准（局部 MCG）
def curriculum_mode_calib(labels, buckets):
    for b in buckets:
        if fit_and_calibrate(labels[b]) > TAU_ECE: freeze_voi_for_bucket(b)
    return max_bucket_ece(labels)

# IP-276 主闭环（快/中/慢三时间尺度）
def TACT_RAS_round(M, obs):
    pre = M.fss.step(obs.w, obs.dw)
    if pre and pre.hard: return pre.act()                  # 快环绕过学习层
    c, r_tac = M.tac.step(obs.w, obs.dw, obs.o)
    z, o = M.mtm.forward(obs); c_cal, U_cal, _ = M.cof.step(obs)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    slow = (M.fma.flow_anomaly(M.fmp, M.last_action, obs.o, obs.o_cal) > TAU_FMA) \
           and (M.last_r_res < TAU_RES)
    todo = M.pac.poison_guard(M.ccr.schedule(build_items(modes, U_epi, r_tac, M.L, M.kappa),
                                             M.kappa, M.budget))
    resolved, U_epi_after = [], U_epi
    for item in todo:
        chan = choose_channel(item, M.L, M.A)
        post = M.tdf.fuse(item.posterior, {chan: execute(chan, item)}, M.rho)
        if M.auth.can_decide(item.cls, chan, M.L, M.A) and anchor_agree(post, r_tac):
            U_epi_after -= item.gain; resolved.append(item)   # 否则仅旁证
    if resolved and all(anchor_agree(r, r_tac) for r in resolved): M.kappa = min(3, M.kappa+eta)
    if any(conflict(r, r_tac) for r in resolved): M.kappa = max(0, M.kappa-dk); M.trust.freeze()
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + beta_U(U_epi_after, M.L)))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ...)
    if slow: lam = max(lam, 0.8); k = min(k, k_cal_shrink(...))
    mode = select_mode(modes, U_epi_after, lam, M.L)
    if (y := M.anchor.label(c, r_tac, M.last_success)): M.cmc.submit(y)
    M.j_tact.submit(r_tac, M.L, M.kappa, M.cmc.max_bucket_ece)
    return k, lam, mode, (U_ale, U_epi_after)
```

## 4. 推导

**引理 19（力觉锚的欺骗代价下界）** 语言单次欺骗代价 ~0；力觉要让测得 w 与假接触状态自洽，须真实施力/力矩或物理篡改传感器，代价 ≥ `E_min`（力/力矩守恒 + 执行器功率下界）。A100（无物理权限不能改力觉）下 `δ_tac ≤ δ_ask·e^{−λ_c E_min}`。系：同预算下力觉最难被投毒，适合作原级标准。

**引理 20（低信任源不可翻转）** 若最大信任源对数似然差 `Δ* > Σ_{c≠c*} ρ_c|Δ_c|`，则融合后验仍倾向其主导假设。系：L=1 的旁证（含语言）冲突时只能降置信、不能改写结论。

**引理 21（课程化的预算收益）** 难度与单位预算信息增益单调反相关（A101）时，按 d 升序较瞬时 VoI 贪心在 ZPD 内完成期望项数更多，且浪费在不可解项上的交互 ≤ κ 内项数。系：贪心会被「高 VoI 但不可分」项吸走预算，课程先把它们排到队尾；先解易项还能条件化塌缩后续项。

**引理 22（锚伪标签分桶一致性）** 桶 b 上锚伪标签准确率 ≥ `1−ε_anchor`、覆盖 `γ_b ≥ γ_min`、给定接触事件条件独立，则 `ECE_b ≤ ε_anchor + O(1/√(γ_b n_b))`。系：物理锚监督把 R69 的全局 ECE 盲点拆成分桶可证，难桶局部冻结。

**定理 18（TACT 严格包含 FLUID 与 R68）** A100–A102 下：关力觉且信任矩阵坍缩为二值 MCG ⇒ 与 FLUID 逐指令相同；再空课程、永不交互 ⇒ 与 R68 逐指令相同；任意状态 `Risk_TACT ≤ Risk_FLUID ≤ Risk_R68`（前哨只额外收紧 λ、k）。安全逐层不弱，放松皆由信任抵押。

**定理 19（力觉前哨无突变与最坏时延）** FSS 快环直接作用于 w、ẇ，无学习写操作；预紧/退让有界 jerk、只增夹持/减速度；若滑移前兆时延 `τ_d < t_slip`，则越力/脱落概率 `≤ ε_fss`。与 R68 定理 15 换装不变式相容 ⇒ 控制连续、无突变。

**定理 20（课程 + 锚的投毒授权上界）** PAC 启用、锚持出集不可影响、升级需连续 `n_pass` 次锚确认时，越级授权概率 `≤ (δ_p ρ^{k−1})^{n_pass}·2^{−L_req} + ε_hold`。系：课程越往后，伪造「假易项」需的一致欺骗越多，投毒收益指数衰减；与 R69 引理 18 叠加而非替代。

## 7. 本轮最大风险

**一句话**：TACT-RAS 的全部安全与效率论证押在「力觉锚是因果接地、可信且未被物理篡改」这一前提上——**一旦锚本身失效（力传感器漂移/饱和/温漂/安装偏置，或攻击者获得物理接触权限），系统会把假锚当真值：用错误的力觉去校准视觉/世界模型/语言，用错误的伪标签去训练 mode_head，并让信任课程把别的通道也逐级带歪**；由于力觉在权限矩阵里被赋予最高等级（contact/dynamics 可单方定案），**假锚是唯一能绕过 R69 多源一致纪律的单点**——课程越推进、信任越高、系统越自信地错。**锚错，比无锚更危险。**

**次级风险与缓解**：力觉漂移/温漂（自检 + 锚持出集 + 交叉校准，漂移即降 L_tac、冻结课程）；物理篡改/传感器攻击（力/力矩守恒 + 电流-力矩双通道冗余 + J_TACT 审计）；课程投毒/假易项（PAC 难度审计 + 锚持出集 + 定理 20）；ZPD 过保守致课程停滞（把安全自检当作课程推进动作）；分桶 ECE 样本稀疏（分层采样 + 置信下界，样本不足桶直接禁用而非默认放行）。
