> R66–R69 把「安全闭环」一路推进到「不确定时该向谁求证」，但整条链路有一个从未被审视的默认：**任务规格以目标 / 轨迹 / 查询的形式给出，语言只是旁路**。本轮两个灵感正面掀翻这个默认：
> - **自然语言指令**是人下达任务的原生接口：离散、欠定、依赖语境、可被误读、也可被欺骗；
> - **力矩控制**是任务最终被「兑现」的物理层：连续、受执行器与接触动力学约束、硬安全边界在此。
>
> 它们之间横着**维度鸿沟**（符号 token vs 连续 6+ DoF）与**因果鸿沟**（语言说结果与方式，力矩是原因；逆映射多对一、非线性、病态）。现有「语言→轨迹/关键点→逆动力学」的两段式把这两条鸿沟塞进一个不可解释的黑箱：既无法保证安全，也无法在指令变更时保证力矩连续。
>
> 核心命题：**把自然语言接地成力矩空间上的「契约」——一个由指令诱导的代价度量 G_ℓ 与可行集 K_ℓ；语言不注入设定点，而是『弯曲』力矩优化的几何。控制 = 该语言度量下的最优力矩，再投影到与语言无关的认证安全集 K_safe。** 歧义 = 度量后验；度量歧义用「物理探询 + 语言澄清」消解，消解不了就执行 maximin。命名 **LATCH-RAS**（Language-Anchored Torque Contracts，语言锚定的力矩契约）。
>
> 一句话定位：R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**一句话到底值多少牛顿·米**」——语义的尽头是力矩。

## 0. 直觉与动机

**灵感 1（形容词就是力矩 / 阻抗量词）**
直觉：「轻一点」「扶稳」「别捏碎」「拧到底」——这些词的物理内容不是轨迹，而是**力 / 刚度 / 阻尼 / 接触**。「轻」= 低法向力与低阻抗；「扶稳」= 高刚度对准 + 低漂移；「别捏碎」= 法向力上界受物体强度约束；「拧到底」= 力矩阈值 / 卡死检测。也就是说，自然语言的核心物理语义天然住在**力-阻抗空间**，而力矩正是该空间的驱动器。把语言接地到轨迹，恰恰把「怎么用力」这个真正被指定的东西丢掉了。

**灵感 2（度量而非设定点 → 连续性与安全可分）**
直觉：若语言直接映射到力矩设定点，指令切换（“再轻一点”）会造成力矩跳变、抖振、甚至破坏接触。改用一个更稳的对象：让指令生成一个 **SPD 度量 G_ℓ**（定义在扳手 / 接触空间上），控制器求该度量下的最优力矩。指令连续变化 ⇒ 度量连续变化 ⇒ 力矩连续变化（强凸 QP 的解对参数 Lipschitz）。更关键的是，**硬安全集 K_safe 与语言无关**，语言只能在 K_safe 内部重塑代价——于是「语言不能放宽安全」成为结构性的、而非靠训练约束的性质。

**灵感 3（歧义 = 度量后验；两种消解：问 vs 探）**
直觉：同一句「轻一点」，对鸡蛋和对铁块意味着不同的力；陌生人说「随便放」可能其实有偏好。歧义不是动作的多峰，而是**度量 / 契约的后验分布**。消解有两条通道：语言澄清（“要多轻？像捏豆腐还是捏苹果？”）与**物理探询**——施加一个受认证的小力，观测物体响应，从而同时识别（a）物体刚度 / 强度（决定力度的世界侧上界）与（b）合适的度量。后者是 R69「信息动作」在力矩域的化身：**用最小的力换取最多的『该用多大力』的信息**。

**灵感 4（安全信封 ≠ 语义信封 —— 本轮的核心张力）**
直觉：R66–R69 的硬安全信封保护的是**机器人自身**（关节 / 力 / 速度 / 世界模型认证）。但「别把鸡蛋捏碎」保护的是**世界**，而这个约束**恰恰写在语言契约里**——也就是最可能被误接地的部分。于是出现一个危险空隙：**机器人绝对安全（在 K_safe 内），却可能在语义上错、在世界侧破坏**。这不是靠收紧 λ 能解决的，因为力矩本身合法；错的是「合法力矩 + 错误语义」。本轮必须把「世界侧安全」从语言里**部分搬出来**：用探询估计物体强度，把「不能超过物体强度」升级为一条与语言无关的硬约束 K_world。

**灵感 5（指令切换本身是一个控制问题）**
直觉：语言指令是离散事件，力矩必须连续。两句话之间的「过渡」不是免费的：从「推」到「停」，从「紧握」到「松开」，若瞬时切换度量会激励未建模高频动力学。需要一个**契约空间的测地插值 + 指令速率限制**：在度量空间上做平滑过渡，使 τ(t) 的 jerk 有界。这是「自然语言 × 力矩控制」区别于「语言条件策略」的一个独立控制论贡献。

## 1. 形式化定义（增量：定义 310–321）

**定义 310（LATCH-RAS 总览）** LATCH-RAS = (LGE, TCM, CRC, MIC, IPP, ITS, CVD, RAS-WM†)。三不变式：
(i) **语言不放宽安全**：语言只重塑代价，执行力矩恒在认证安全集 K_safe 内（K_safe 与 ℓ 无关）；
(ii) **指令-力矩连续性**：度量对指令 Lipschitz，力矩对度量 Lipschitz ⇒ 指令变更下 τ 连续、jerk 有界；
(iii) **接地审慎**：任何指令先过「可实现性 + 歧义显著性」检查，未通过者不得静默执行，只能澄清 / 拒绝 / maximin。

**定义 311（力矩契约）** 指令 ℓ 诱导契约 C(ℓ) = (G_ℓ, w_ℓ, K_ℓ)：G_ℓ ∈ SPD(𝒲) 是**扳手空间** 𝒲 ⊂ ℝ⁶ 上的语言条件度量（与具体机器人无关，便于跨本体迁移）；w_ℓ ∈ 𝒲 为参考扳手（可为 0）；K_ℓ 为任务软 / 硬约束集（如“保持水平”）。代价 J_ℓ(w) = (w − w_ℓ)ᵀ G_ℓ (w − w_ℓ)。

**定义 312（语言-几何接地器 LGE）** E_φ: ℓ ↦ (μ_ℓ, Σ_ℓ)，经 head 映射为 G_ℓ = L_ℓ L_ℓᵀ（Cholesky 参数化，保 SPD）。训练 = 对比学习（同意图指令聚拢）+ **力标定回归**（预测的 (G,w) 诱导的力分布须匹配人类示范 / 物理测量）。语言编码器可冻结大模型，只训小 head 以保证实时与可审计。

**定义 313（力矩契约滤波器 TCM）** 每拍解强凸 QP：
τ* = argmin_τ J_ℓ(J(q)τ) + ρ‖τ − τ_prev‖²，s.t. τ ∈ K_safe(q, ẋ)（执行器 / 力 / 速度 / 世界模型认证）、接触约束、K_ℓ 硬部分。τ = Jᵀ w + τ_null。ρ>0 ⇒ 解唯一且对 (G_ℓ, w_ℓ) Lipschitz。

**定义 314（跨本体的度量映射）** 语言度量定义在扳手空间，与本体无关；τ = Jᵀ w。换机器人时只需重算 J 与 K_safe，G_ℓ 不变（至多按执行器带宽重标定）⇒ 同一句话在不同本体上「语义相同、力矩不同」。这是「语言→关节力矩」直接回归所不具备的性质。

**定义 315（可实现性 CRC）** 结合探询得到的物体刚度 / 强度估计与执行器饱和，检查 K_ℓ ∩ K_safe ∩ K_world ≠ ∅ 且 ∃τ 使 J_ℓ 低于阈值。若不可实现（如“把钢棒捏断”），判为**不可实现 / 世界侧不安全指令**，不得静默饱和执行。

**定义 316（世界侧安全信封 K_world）** K_world 由探询估计的物体强度 ŝ、接触模型给出：法向力 / 力矩不得超过 κ·ŝ。它**与语言无关**，一旦估计即在 TCM 中作为硬约束；从而把「别捏碎」从易错的语言契约里提出一部分，变成可认证的物理边界。

**定义 317（契约歧义与遗憾）** 后验 p(C | ℓ, o)。**契约遗憾** R(τ) = max_{C∈supp} [J_C(τ) − min_{τ'} J_C(τ')]。歧义显著 ⇔ min_τ max_C 归一化遗憾 > τ_reg。显著则进入 MIC；否则执行后验均值（MAP）最优。

**定义 318（度量-歧义控制器 MIC）** 在 {执行 maximin τ† = argmin_τ max_C J_C(τ)、语言澄清、物理探询} 中按 (VoI − 成本) 选择。maximin 给出「无论哪种语义都不至于太糟」的兜底，与 R69 的 λ_floor 同构，但作用在契约而非风险标量上。

**定义 319（阻抗探询 IPP）** 信息动作 = 一段受认证的低幅接触轨迹（法向力 ≤ ε_probe）。观测 y = S_obj · w_probe + n（S_obj 为物体柔度），据此更新 G_ℓ 后验与物体强度 ŝ。目标：在 ε_probe 内最大化对 (度量, 强度) 的 Fisher 信息。探询动作同样过 C-RAS-WM 认证，且**探询本身不得触发世界侧隐患**（力度必须低于当前 ŝ 的保守下界 κ·ŝ_lo）。

**定义 320（指令过渡平滑 ITS）** 指令序列 ℓ_i 在时刻 t_i 到达。在度量空间做测地插值 G(t) = Geodesic(G_{ℓ_i}, G_{ℓ_{i+1}}, s(t))，s 为满足 jerk 界的 S 型时间律；同时限制指令速率 ‖dG/dt‖ ≤ L_G。输出 τ(t) 因此连续且 jerk ≤ J_max。

**定义 321（证书 J_LATCH）** J_LATCH = (J_FLUID, metric_ece, contract_violation_rate, realizability_margin, world_force_margin, instruction_continuity(jerk_p99), ambiguity_regret, refusal_precision/recall, latch_ver)。Valid ⇔ Valid(J_FLUID) ∧ metric_ece ≤ τ_ece ∧ jerk_p99 ≤ J_max ∧ 无静默的世界侧越界。

## 2. 关键算法骨架

```python
# IP-264 LGE：语言 -> 扳手空间度量（冻结 LM + 小 head，零重复训练）
class LanguageMetricGrounder:
    def __init__(self, lang_encoder, metric_head, w_head):
        self.enc, self.head, self.whead = lang_encoder, metric_head, w_head

    def contract(self, instruction):
        z  = self.enc(instruction)                      # 冻结编码
        mu, log_s = self.head(z)                        # 低维柔度潜变量
        L  = cholesky_spd(softplus(log_s))              # 保 SPD
        return Contract(G=L @ L.T, w_ref=self.whead(z),
                        posterior=(mu, log_s))

# IP-265 TCM：语言度量下的认证力矩 QP
def torque_contract_filter(C, q, qd, tau_prev, obj_strength):
    J = geometric_jacobian(q)
    H = J.T @ C.G @ J + RHO * np.eye(q.dof)             # 强凸 ⇒ Lipschitz 解
    f = -(J.T @ C.G @ C.w_ref)
    tau = solve_qp(H, f,
                   A=stack(K_safe(q, qd), K_world(obj_strength), K_contact),
                   b=...)
    return clip_to_actuator(tau, q, qd)

# IP-266 CRC：可实现性（世界侧安全与执行器饱和）
def realizable(C, obj_strength, limits):
    need = required_wrench_range(C)                     # 由 G,w 推出所需扳手
    return need.f_max <= min(limits.F_max, KAPPA * obj_strength.lo)

# IP-268 IPP：最大安全探询力的 Fisher 信息
def safe_probe_force(obj_strength, eps_probe):
    f = min(eps_probe, KAPPA * obj_strength.lo)         # 世界侧硬上限
    return f, fisher_info_stiffness(f)                  # 信息 ∝ f^2 / σ^2

# IP-267 MIC：歧义 -> maximin / 澄清 / 探询
def ambiguity_control(post, obs):
    reg = contract_regret(post)                         # 定义 317
    if reg > TAU_REG and voi_probe(post, obs) > cost_probe():
        return "probe"
    return "maximin" if reg > TAU_REG else "execute"

# IP-275 主闭环（继承 R69，仅在「任务规格」处插入语言契约层）
def LATCH_RAS_round(M, obs, instruction):
    C    = M.lge.contract(instruction)
    post = M.lge.posterior(instruction, obs)
    # 1) 歧义：值钱且安全则物理探询（同时识别物体强度）
    act = M.mic.ambiguity_control(post, obs)
    if act == "probe":
        f = M.ipp.safe_probe_force(M.obj_strength, M.eps_probe)
        y = M.ipp.probe(f); post = M.lge.update(post, y)
        M.obj_strength.update(y)
        act = M.mic.ambiguity_control(post, obs)
    # 2) 可实现性：不可实现 -> 拒绝 / 协商，绝不静默饱和
    if not M.crc.realizable(M.lge.contract_from(post), M.obj_strength, M.limits):
        tau = M.ref.refuse_or_negotiate(instruction, post)
        M.vqa_l.submit_async(instruction, post, refused=True)
        return tau, post, "refused"
    # 3) 仍显著歧义 -> maximin，否则 MAP
    tau_star = (M.mic.maximin(post, obs) if act == "maximin"
                else M.tcm.solve(M.lge.contract_from(post), obs))
    # 4) 指令过渡平滑（度量空间测地插值 + jerk 限）
    tau = M.its.smooth(tau_star, M.prev_contract, M.t_now)
    # 5) 契约违约检测（世界模型 + 力残差）
    v = M.cvd.violation(obs, tau, M.lge.contract_from(post))
    # 6) 审计 + 证书
    M.vqa_l.submit_async(instruction, post, act, v, tau)
    return tau, post, v
```

## 3. 推导

**引理 19（度量 Lipschitz ⇒ 力矩 Lipschitz）** 设 E_φ 对指令 Lipschitz（常数 L_E，由冻结编码器 + 有界 head 保证），且 QP 强凸（ρ>0）。由 KKT 隐函数定理，τ*(G,w) 对 (G,w) 连续且局部 Lipschitz，常数 L_τ ∝ 1/ρ。故相邻指令下 ‖Δτ‖ ≤ L_τ L_E ‖Δℓ‖。系：指令抖动不会造成力矩抖振；配合 ITS 可把 jerk 进一步压到 J_max 下。

**引理 20（语言不放宽安全）** TCM 的可行域始终包含 K_safe(q) ∩ K_world，而 J_ℓ 只改变目标、不改变可行域。故对任意 ℓ，执行 τ* ∈ K_safe ∩ K_world。即语言无法放大可执行力矩集合。这是结构性的、不依赖训练的性质。（注意：K_world 依赖估计 ŝ，故其正确性取决于探询 / 先验，见定理 19 与风险。）

**引理 21（探询的最优幅度）** 若观测 y = S w + n，n~𝒩(0,σ²)，则关于柔度 S 的 Fisher 信息 ∝ w²/σ²，单调增于探询力 f；但 f ≤ ε_probe 且 f ≤ κ·ŝ_lo（世界安全）。故最优探询 f* = min(ε_probe, κ·ŝ_lo)，信息增益随安全上限饱和。系：**在小力下识别大刚度物体最难**——这正好是「轻放重物」这类最危险的指令，是 LATCH 的结构性盲区，需靠语言先验兜底。

**定理 18（歧义下的 maximin 支配）** 设归一化遗憾 R 有界。maximin 定义给出存在 τ 使 max_C J_C(τ) ≤ min_τ' max_C J_C(τ') · (1+R)；而若直接执行 MAP 契约 Ĉ，存在后验使 max_C J_C(τ_MAP) 任意大于 maximin。故在歧义显著（R > τ_reg）时 maximin 的契约遗憾上界严格优于 MAP 执行；当后验收敛（R ≤ τ_reg）时两者一致。⇒ MIC 是「先判歧义、再决定执行 / 探询」的两级策略，R69 的纯执行是其退化。

**定理 19（拒绝的安全性与不完备性）** 若 CRC 在保守区间 [ŝ_lo, ŝ_hi] 上判不可实现，则在真实强度 s ∈ [ŝ_lo, ŝ_hi] 下不存在同时满足 K_ℓ 与 K_world 的力矩，拒绝是安全的；若判可实现但真实强度低于估计（估计误差），则 K_world 可能被高估而越界。故拒绝是**可靠但不完备**的保险丝：它绝不误放行「区间内明确不可行」的指令，但无法覆盖强度估计本身错误的情形。⇒ 必须与保守下界 κ·ŝ_lo 联用，并把 ŝ 的不确定性计入证书。

**定理 20（LATCH 对 R69 的包含）** 当指令退化为「保持 R69 的目标 / 轨迹」、或歧义不显著且无世界侧约束时，G_ℓ 取各向同性、K_ℓ 退化为跟踪约束，TCM 即 R69 的认证前缀控制；此时 LATCH 与 R69 逐指令一致。世界侧探询关闭（ε_probe = 0）时 IPP 不触发。⇒ 安全侧不让步，新增的是「语言→度量」的语义层与「世界侧硬约束」。

## 4. 推导

**引理 19（度量 Lipschitz ⇒ 力矩 Lipschitz）** E_φ 对指令 Lipschitz（L_E），QP 强凸（ρ>0）⇒ KKT 隐函数定理给出 τ* 对 (G,w) 局部 Lipschitz（L_τ ∝ 1/ρ），故 `‖Δτ‖ ≤ L_τ L_E ‖Δℓ‖`；指令抖动不致力矩抖振。系：配合 ITS 可把 jerk 压到 J_max 下。

**引理 20（语言不放宽安全）** TCM 可行域恒含 `K_safe∩K_world`，J_ℓ 只改目标不改可行域 ⇒ 任意 ℓ 下 `τ*∈K_safe∩K_world`。语言无法放大可执行力矩集合（结构性、非训练约束）。

**引理 21（探询最优幅度）** `y=S w+n`，`n~𝒩(0,σ²)` ⇒ 关于 S 的 Fisher 信息 `∝ f²/σ²`，增于 f；受 `f≤ε_probe` 与 `f≤κ·ŝ_lo` 约束 ⇒ `f*=min(ε_probe,κ·ŝ_lo)`。系：小力识别大刚度物体最难（「轻放重物」为结构性盲区，需语言先验兜底）。

**定理 18（歧义下 maximin 支配）** R 有界时 maximin 的 worst-case 契约代价 `≤(1+R)·最优`；执行 MAP 契约存在后验使其 worst-case 任意更大。故显著歧义（R>τ_reg）下 maximin 严格优于 MAP，后验收敛时二者一致；R69 纯执行为其退化。

**定理 19（拒绝的安全性与不完备性）** CRC 在 `[ŝ_lo,ŝ_hi]` 上判不可实现 ⇒ 真实强度落在区间内时无可行力矩，拒绝安全；但若估判可实现而真实强度低于估计，则 K_world 可能过松。故拒绝是**可靠但不完备**的保险丝：不误放行「区间内明确不可行」，但覆盖不了强度估计本身的错误 ⇒ 与保守下界 κ·ŝ_lo 联用，ŝ 不确定性进证书。

**定理 20（对 R69 的严格包含）** 指令退化为 R69 目标 / 轨迹、或歧义不显著且无世界侧约束时，G_ℓ 各向同性、K_ℓ 退化为跟踪约束，TCM 即 R69 认证前缀控制，二者逐指令一致；`ε_probe=0` 时 IPP 不触发。安全侧不让步，新增「语言→度量」语义层与「世界侧硬约束」。
