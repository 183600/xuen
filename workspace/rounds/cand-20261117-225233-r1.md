# 第 2 轮（UniBot 线累计；本轮灵感：「用户测试」×「双足机器人」）

> **接续说明**：第 1 轮 UniBot-SAGE 把主问题定义为"能力栈"（接地层抓握显式化 × 技能层路由 × 适应层推理期调制 + 工程层），编号 U1–U12 / L1–L7 / E601–E618 / IP-01–IP-08。本轮**不推翻**其领域事实与机制结论，而是把研究对象往下挪一层：不问"策略还能加什么能力"，而问"**我们凭什么相信它行**"以及"**它站得住吗**"。一句话：从"能力栈"转向"**生存 × 证据栈**"。新增编号 U13–U25 / L8–L14 / E619–E636 / IP-09–IP-16；第 1 轮资产全部保留。

## 0. 本轮先做的三件事（核验与纠错）

我先把第 1 轮当"别人写的论文"审一遍，找出三个必须在动手前修掉的东西。**核验分层**（避免把假设当事实）：

- **A 类（沿用，已由第 1 轮核实）**：32 任务 / 5 类泛化 / 通才单模型赛道 / 远程 API（`metadata`·`get_action`·`reset`）/ N 个连续端口 / 观测含 4 路相机、arm、gripper 标量、EE 相对基座位姿、`lower_body`(15)；动作含 arm / gripper / `pivot`(7)；teaser 榜为占位表。
- **B 类（本轮必须用一次"零成本探测"确认，否则不做强声明）**：① 评测端是否提供 base pose / IMU；② `action.pivot` 是否被跟踪、语义是"基座位姿"还是"朝向 / 高度"；③ 官方数据是否带 teleoperator ID；④ 桌面任务中机器人是否允许 / 需要迈步；⑤ chunk 执行语义（第 1 轮 Q5 仍未闭环）。
- **C 类（纯假设，只用于设计备选路径）**：评测时人类干扰者的策略分布；真机跌落率量级。

**纠错 1（吸收态缺失）**：第 1 轮的六因子串行分解 `P(success)=∏P_j` 隐含"失败是某阶段没做成"。但双足机器人多了一个**吸收态：跌倒 / 失稳**——一旦发生，后面所有阶段因子都无意义。正确的分解必须先过一道**生存门**：`P(success)=P(全程不失稳)·P(完成 | 全程不失稳)`，后者才可继续串行分解。这不是记号问题：它把"平衡"从一个可选姿态先验（第 1 轮 IP-05，P1）提升为**一级计分变量**。

**纠错 2（漂浮基座混叠）**：第 1 轮的旗舰 GraspVerify 用"末端随动 + 夹爪闭合 + 腕部几何"判"抓住没有"。但 G1 是**漂浮基座**：基座一晃，EE 在基座系里的速度 / 位姿就变；如果判定器把"EE 在动"当作"物体随手动"的正证据，那么**基座摆动会被读成抓握成功**。这是一个可证伪的方法学 bug，且恰好会随"桌面远端任务 + 人为推搡"变严重。必须在任何新能力之前修掉。

**纠错 3（单一指标混淆两种能力）**：teaser 榜只有 success / step 两列，且二者近共线。但"成功率"同时混合了**操作技能**与**平衡生存**；第 1 轮 L1「只优化终态成功」在跨模型截面上成立，却不能推出"success 的每一分都来自操作能力"。若某模型操作更弱但更稳，排名会把它读成"操作更强"。⇒ 本轮所有结论必须**同时报告条件成功率与失稳率**，否则不可归因。

## 1. 直觉与动机（两灵感的第一性原理）

### 灵感 1 ·「用户测试」→ 评测不是裁判，而是研究对象

**直觉**：做产品的人都知道，最贵的不是把功能做出来，而是**知道它到底行不行**。用户测试的第一性原理有三条：(a) **用户不是你**——设计者的盲区只能靠"别人来用"暴露；(b) **测试是抽样**——你测的用户 / 任务 / 场景是从一个总体里抽的，结论只对那个总体有效；(c) **测出来的东西有噪声与偏差**——评分者不一致、学习效应、复测漂移，都会让你把噪声当信号。

**严谨化**：把评测写成一个五元组 `T = (q, π_test, P, M, R)`：场景采样器 `q`（"用户总体"）、被测策略 `π_test`、协议 `P`（任务定义 / 容差 / reset / 重试）、测量 `M`（成功、失败编码、失稳、恢复）、可靠性 `R`（评分者一致性、复测方差、最小可检测效应 MDE）。"用户测试"在本线不是一句口号，而是要求：**q 要覆盖 5 类泛化轴并防止演示者泄漏；M 要能把失败拆到可行动；R 要能回答"这 +1.5 分是真的吗"。**

### 灵感 2 ·「双足机器人」→ 平衡不是阶段，是每一步的生存谓词

**直觉**：机械臂的失败是"没做到"；双足机器人的失败是"**先倒了**，于是什么都没做到"。双足的关键不是"会走路"，而是**支撑、重心、接触**三件事在每个控制步都成立。桌面任务看似静止，实则处处是平衡问题：伸手够远端 → 重心前移；双手协同 → 内力与反力矩；人推一把 → 必须迈步或撑住。

**严谨化**：设 `m_t` 为稳定裕度（ZMP / 捕获点到支撑多边形的有符号距离），生存谓词 `S_t = 1[m_t ≥ m_min]`。任务成功要求 `∏_t S_t = 1`。于是平衡是**逐步门控**，不是可选的"姿态先验"。更关键的是：**基座状态是隐变量**——若观测不给 base pose / IMU，`m_t` 只能从腿关节、足接触、EE 相对位姿与视觉中估计，且这个估计误差会直接污染抓握判定（纠错 2）。

### 合成：生存 × 证据 = 一条"先站稳、再被测准、最后才更强"的栈

- **生存层**：稳定裕度估计 + 动作安全投影 + 站位 / 迈步 + 恢复监督（把"跌倒"从吸收态变成可避免事件）。
- **证据层**：测试者分布与覆盖、演示者留出、失败编码可靠性、稀缺真机时段的信息最优调度（把"评测"从裁判变成可设计的实验）。
- **能力层（第 1 轮修正后）**：抓握确认改为**基座运动不变量**；技能路由与推理期适配保留，但每条收益必须过"生存门 + 证据门"才允许上报。
- **工程层**：端口隔离、延迟整形、审计（沿用第 1 轮 IP-03 / IP-08），并新增**平衡事件日志**与**测试元数据日志**。

**一句话**：第 1 轮在问"怎么更强"；本轮在问"**强得站得住、且我们测得准吗**"——因为在这条赛道上，后者是前者的前置条件，而不是附加项。

## 2. 瓶颈在哪里（把"评测"和"平衡"变成可量化瓶颈）

| 观察 / 推导 | 数值 | 含义 |
|---|---|---|
| 成功 = (1−f)·S_c，f 为失稳 / 中止率 | 在 S≈30%、f=5% 时，dS/df ≈ −0.316 | **1.5 分的"提升"可能只是 4.7 个百分点的跌落率改善**；不报告 f 就无法归因 |
| 两比例检验的样本量（α=.05, power=.8） | n ≈ 16·p(1−p)/Δ²；p=.3, Δ=.05 → ≈1344 / 臂（独立） | 32 任务 × 少量重复**根本不足以支撑 1–2 分的细粒度结论**；必须配对 / 分层 / 共用随机数 |
| 评分者误差的衰减 | 观测差异 ≈ 真差异·√reliability；MDE ∝ 1/√reliability | 失败编码不可靠时，"哪个 IP 有效"会被噪声支配 |
| 演示者泄漏 | 随机 episode 切分把同一操作员放进训练与测试 | 会**系统性高估**"新用户"泛化；必须 operator-held-out |
| 覆盖 vs 泛化（Kantorovich–Rubinstein） | 风险差 ≤ L·W₁(D_demo, T_test)（L 为损失的 Lipschitz 常数） | "泛化"可被翻译成一个**可测的分布距离**；测试者分布不是玄学 |
| 子模贪心（测试选择） | 熵减目标下贪心 ≥ (1−1/e)·最优（在条件独立假设下） | 稀缺真机时段可以**按信息增益选任务**，无需穷举 |
| teaser 榜 step≈1.337·succ+0.09（R²=.9955） | 截面近共线 | 只说明"平均而言 step 不提供独立排序"，**不**说明"平衡不影响 step"；不能拿截面共线做因果推断 |

**三条可执行结论**：

- **T4 生存优先于技能**：跌倒 / 失稳是吸收态，任何能力收益都必须先扣掉"失稳税"；平衡是**一级指标**，不是 IP-05 那种可选先验。
- **T5 证据是稀缺资源**：真机时段少、方差大、编码有噪声 ⇒ 把"测什么、测几次、谁来编码"当成实验设计问题，能把同等预算下的可判定性提高数倍。
- **T6 用户总体要显式建模**：5 类泛化轴 + 演示者 + 干扰者共同定义"用户总体"；用覆盖 / 留出 / 风险敏感目标替代"在 32 个任务上碰运气"。

## 3. 研究问题（本轮 Q6–Q11）

- **Q6（平衡可观测性）**：在观测不给 base pose / IMU 的假设下，能否从腿关节 + 足接触 + EE 相对位姿 + 视觉估计出**带校准不确定性的稳定裕度**？估计误差如何传播到成功判定？
- **Q7（混叠可分离性）**：抓握确认能否被改造成**对基座运动不变**（或显式条件化）？混叠造成的假阳性率随基座速度方差的增长曲线是什么？
- **Q8（保守-探索的平衡）**：安全投影 / 迈步 / 恢复会牺牲探索性动作；在"跌倒为吸收态"下，**何时该稳、何时该冒险**的最优切换规则是什么？其收益上界与实证兑现比例？
- **Q9（测试者总体）**：如何定义并测量"用户测试总体"，使代理评测与真机风险差有界？覆盖度量（W₁ / MMD）能否预测真机掉点？
- **Q10（证据经济学）**：给定 K 个真机时段、每时段可跑 n 个 episode，如何选任务-场景-重复次数，使"该改哪个 IP"的决策错误率最小？
- **Q11（演示者泛化）**：官方数据是否可检测出操作员签名？operator-held-out 与 random split 的差距有多大？这个差距是不是"新用户泛化差距"的下界？

## 4. 设计原则（在第 1 轮 P1–P6 上增补）

- **P7 生存门先于一切**：任何动作块执行前先过稳定裕度检查；不允许"为了成功率牺牲不跌倒"。跌倒的代价是吸收态，不是一步的奖励。
- **P8 相对不变量优先**：所有接触 / 抓握 / 位移特征优先用**相对量**（物体相对夹爪、基座相对世界），并对基座运动做显式条件化；禁止用绝对末端速度直接当抓握证据。
- **P9 测试即实验设计**：每个真机时段先写"要判定的假设 / 需要的样本量 / 预注册判据"；不做"跑完再看数字"。
- **P10 报告不确定性**：所有结论带 CI 与 MDE；不能给出"小于 MDE"的结论。
- **P11 用户总体显式化**：测试集必须标注其覆盖的泛化轴与演示者来源；不允许把"随机切分"当"新用户"。
- **P12 可回滚的保守性**：安全层与证据层都可一键关闭，退回第 1 轮基线；安全层关闭时必须在报告中标注"未保护"。

## 5. MVP 与退化链

**MVP = IP-10（基座运动解耦的抓握确认）+ IP-09（稳定裕度与安全投影）+ IP-15（信息最优测试调度）+ IP-16（失败编码可靠性）+ 第 1 轮基线策略。**

理由：IP-10 修的是**已存在资产里的 correctness bug**（最便宜、最先该做）；IP-09 防的是**吸收态风险**（尾部最大）；IP-15 / 16 决定其余一切能否被可信地判定（没有它们，前两者好坏不可知）。IP-13 / 14 是测量基础设施，排在 MVP 之后但先于任何"大改模型"。

**退化链**：

- L0 稳定裕度估计不可信 ⇒ 收紧动作包络 + 冻结 pivot / 迈步，只做保守臂动作（宁可低分，不可跌倒）。
- L1 安全投影不可行 / 超时 ⇒ 回到上一安全动作 + 减速，并记录 degraded。
- L2 基座解耦不可用 ⇒ 退回第 1 轮 GraspVerify，但把阈值调高（高精度低召回），并禁止其单独触发非抓取原语。
- L3 测试调度不可用 ⇒ 均匀分层抽样（覆盖优先）。
- L4 失败编码可靠性不达标（κ<0.6）⇒ 只报二值成功，加宽 CI，不做细粒度归因。
- L5 整条新链路失效 ⇒ 提交第 1 轮基线 + 一张"证据卡"（说明哪些结论未验证）。

## 6. 预期贡献（可验收）

1. **把平衡从"姿态先验"提升为"一级计分变量"**：给出吸收态下的正确成功分解，并量化"不报告失稳率就无法归因"。
2. **发现并修掉第 1 轮旗舰信号的漂浮基座混叠**：给出混叠的假阳性率界与基座不变量的抓握判定，AUROC / FPR 双指标验证。
3. **把"用户测试"工程化**：测试者总体、覆盖度量、operator-held-out、失败编码可靠性、MDE——让"这 +X 分是真的吗"可回答。
4. **信息最优的稀缺真机调度**：给出可证明近似比的测试选择算法，并在代理环境中量化"同样预算多判定出多少"。
5. **一套"生存 × 证据"的代理评测**：在第 1 轮六因子上加"失稳 / 恢复"因子，并与真机锚点做相关标定。

## 7. 下一轮迭代计划（深化与修剪）

- **深化**：把 U13–U25 落到可执行代码（稳定裕度估计器、基座解耦特征、测试调度器、编码表）；用官方数据先做**离线可证伪**的三件事（E619 / E620 / E625）。
- **修剪预案**：若 E620 显示混叠对 FPR 的影响 <2 个百分点（即基座摆动很小），则 IP-10 降级为"锦上添花"，把资源转到 IP-09 / IP-15；若 E625 显示无操作员签名（不可检测），则删掉 IP-14 的强声明，只保留"随机切分可能过于乐观"的保守表述。
- **保留项**：IP-09（吸收态）、IP-10（correctness）、IP-15 / 16（证据）四者在任何情况下不砍；IP-11 / 12 / 13 / 14 视核验结果推进。

## 8. 本轮最大风险（一句话）

**本轮最大风险是把"平衡门控"与"用户测试"当成两个可加的正交改进，而它们共享同一个失效模式——我们用来判定"稳"与"测得准"的代理（无 IMU 的稳定裕度、模拟测试者分布、teaser 相关性）一旦在真机上整体偏移，就会把"更保守、更可解释"误当成"更高分"，用一个测得更漂亮的 25% 替换掉一个粗糙但能拿 30% 的策略。**

## 0. 本轮结论摘要

**一句话路线**：第 1 轮解决"怎么更强"；本轮把两个前置条件做成系统——**先站稳（生存层），再被测准（证据层），最后才是更强（修正后的能力层）**。

**为什么是这两个词（三条量化依据）**：

| 证据 / 推导 | 数值 | 推出的设计 |
|---|---|---|
| 失稳 / 跌倒是**吸收态**：成功 = (1−f)·S_c | S≈30%、f=5% 时 1pp 跌落率 ≈ 0.32pp 成功率；1.5 分"提升"≈ 4.7pp 跌落率改善 | 平衡必须是一级指标 → **IP-09 / IP-12**；所有结论同时报失稳率 |
| 漂浮基座使"末端绝对运动"混叠基座运动 | 假阳性 FPR 随基座速度方差单调上升（引理 L9） | 抓握确认改为基座不变量 → **IP-10**（修第 1 轮 correctness bug） |
| 真机测试是稀缺、有噪声的抽样：p=.3 时检测 Δ=.05 需 ≈1344 / 臂（独立） | 细粒度结论对样本量极敏感；随机切分还会因演示者泄漏而乐观 | 评测即实验设计 → **IP-15 / IP-16 / IP-13 / IP-14** |

**与第 1 轮的关系**：

| 第 1 轮资产 | 本轮处置 |
|---|---|
| IP-01 技能路由 / IP-03 chunk 缝合 / IP-04 上下文调制 / IP-06 代理评测 | **保留**；但收益上报前必须过"生存门 + 证据门" |
| IP-02 GraspVerify（旗舰） | **修正**：绝对运动 → 基座运动不变量（IP-10） |
| IP-05 PosturePrior（P1，pivot 语义未知） | **升级**：从可选先验变为生存门控（IP-09），并保留"接口不支持则降级" |
| IP-07 DualSpace / IP-08 AuditLayer | **暂存**；其审计部分并入平衡事件日志与测试元数据日志 |

## 2. 创新点详述

### IP-09 · StanceGuard 稳定裕度估计 + 安全投影（P0）

- **动机**：双足 G1 是漂浮基座；桌面远端任务需要重心前移，双手协同产生内力与反力矩，人为干扰直接推基座。跌倒使 episode 进入吸收态——后续所有阶段因子失效。
- **与第 1 轮的差异**：第 1 轮 IP-05 把 `pivot` 当"可选姿态先验"（P1），且承认语义未知；本轮把**稳定裕度**做成每步门控，并给出两条估计路径：若观测含 base pose / IMU 则用 LIPM / 捕获点 + 离散 CBF；若不含，则用腿关节正运动学 + 足接触 + EE 相对位姿 + 视觉地标估计**基座系内的相对裕度代理**，并显式携带不确定性。
- **技术可行性**：中。离线可先在官方数据上做 E619（能否恢复可信基座状态）与 E633（pivot 是否被跟踪）。在线只需一个轻量估计器 + 一个投影器。
- **所需资源**：在线 <3 ms；离线单卡数小时；无需新增接口字段（纯策略内部）。
- **落地步骤**：① E619 审计 base 可观测性；② 拟合 / 训练裕度代理 `m̂_t ± σ_t`；③ 安全投影：离散 CBF `m̂_{t+1} ≥ (1−γ)·m̂_t`，或动作包络收缩（限速、限幅、禁越界）；④ 双模式（`guarded` / `observe`）+ 一键关闭；⑤ 真机 A/B（E622）。
- **风险**：裕度估计偏差 → 过度保守。对冲：默认 `guarded` 但阈值由数据分布定；`guarded` 下若连续 K 步裕度充足则逐步放开；记录 `degraded` 与投影次数，纳入审计。

### IP-10 · BaseDecouple 基座运动解耦的抓握确认（P0）

- **动机**：第 1 轮旗舰 GraspVerify 依赖"末端随动"；漂浮基座下，基座摆动会注入共同的末端速度分量，被误读为"物体随手动"。这直接威胁第 1 轮最大的机制资产。
- **与第 1 轮的差异**：从**绝对量**（EE 速度、EE 位姿）改为**相对不变量**：物体相对夹爪的位姿变化（腕部视觉 + 几何）、夹爪开合、腕部图像相对背景的光流；并把基座速度估计 `v̂_b` 及其协方差作为条件输入，而不是忽略。
- **技术可行性**：高（**完全可离线证伪**）。官方 32 个数据集的 episode 提供了"抓住后物体随动"的间接标签；可按基座运动幅度分层，比较绝对特征与不变量特征的 FPR / AUROC。
- **所需资源**：检测器 ResNet18 / ViT-S 级，单卡数小时；在线 ≤6 ms。
- **落地步骤**：① 估计每帧基座运动（若有 IMU 直接用；否则用头部相机背景光流 / 腿 FK 推断）；② 构造不变量特征；③ 训练判定器 + 可靠性图；④ 在"基座静止 / 小幅摆动 / 大幅摆动"三档上分层报 FPR 与 AUROC（E620 / E621）；⑤ 把阈值改为随 `σ_b` 自适应（不确定性越高越保守），并接入第 1 轮 U6 介入准则。
- **风险**：无 IMU 时基座速度估计噪声大；分层样本不均衡。对冲：视觉背景流 + 腿 FK 双通道交叉校验；对高不确定样本直接输出低置信（退回"不干预"）。
- **为何是本轮第一优先**：它是**唯一一个能用公开数据离线验证的 correctness 修复**，且不依赖真机时段与合规答复。

### IP-15 · TestScheduler 信息最优真机调度（P0）

- **动机**：真机时段稀缺、方差大；第 1 轮的做法是"每轮 2–3 个时段取样做相关标定"，这是**被动抽样**。用户测试的第一性原理告诉我们：测试的价值取决于"它能否区分你要区分的假设"。
- **与第 1 轮的差异**：把"评测"从"跑完看均值"改成**序贯实验设计**：把每个 `(task, scenario, repeat)` 视为一个测试项，估计其对"哪个 IP 有效 / 哪个任务最弱 / 整体是否达标"的信息增益，在预算与 MDE 约束下选样。
- **技术可行性**：高。Entropy reduction 在条件独立假设下是子模函数 ⇒ 贪心有 `(1−1/e)` 近似（引理 L10）；工程上可用 Thompson sampling 处理非平稳。
- **所需资源**：离线算法 + 一张实验台账；在线无。
- **落地步骤**：① 定义决策目标 θ（每任务成功率 / 每 IP 的边际收益）；② 先验（来自第 1 轮代理评测 + teaser 结构）；③ 每次选样最大化期望熵减 / 覆盖，受 MDE 与配对约束；④ 输出"本时段能回答 / 不能回答什么"；⑤ 用历史时段回测校准（E629）。
- **风险**：条件独立假设不成立（任务间相关）⇒ 贪心非最优。对冲：回测校准 + 分层约束（每类泛化轴至少 1 个样本）+ 保留随机探索比例。

### IP-16 · FailureCode 可靠性编码 + 严重度加权（P0）

- **动机**：第 1 轮六因子分解依赖"规则 + VLM 伪标"，但没有报告**编码可靠性**。teaser 榜本身还是占位表；如果连失败标签都不可靠，任何"某 IP 涨点"的归因都失效。
- **与第 1 轮的差异**：引入编码手册、双编码 + 仲裁、Krippendorff α、严重度权重与 MDE；把"跌倒 / 近失稳 / 恢复"作为一等类别，而不是塞进 `release` 或忽略。
- **技术可行性**：高（流程活）。VLM 初筛 + 人工抽检；严重度按"不可恢复 > 可恢复但任务失败 > 可恢复且任务继续"排序。
- **所需资源**：小；编码成本是主要成本（可用主动学习只编码高不确定样本）。
- **落地步骤**：① 写编码手册（含边界案例）；② 三编码者 / 双人 + VLM，计算 α 与分歧；③ 分歧仲裁并更新手册；④ 定义严重度加权成功 `SW`；⑤ 每个结论附 MDE，低于 MDE 的差异一律标记"不可判定"。
- **风险**：类别不平衡导致 κ 虚高；编码成本高。对冲：分层抽样编码 + 报告每类支持度。

### IP-13 · TesterBench 测试者总体与覆盖度量（P1）

- **动机**：5 类泛化场景（位置 / 干扰物 / 背景 / 未见物品 / 人为干扰）本质是"用户总体"的抽样轴；第 1 轮 IP-06 做了 OOD 切分，但没有把"总体"写成分布，也没有覆盖度量。
- **与第 1 轮的差异**：定义测试者采样器 `q` 与覆盖度量 `W₁ / MMD`；用 Kantorovich–Rubinstein 界（引理 L11）把"覆盖差距"翻译成"风险上界"；选择指标从均值改为 **CVaR**（尾部泛化），均值照常上报。
- **技术可行性**：中–高。可用官方数据 + 可控合成（背景替换、遮挡、干扰物增删、目标位置扰动）；"未见物品"需外部资产或留出实例。
- **所需资源**：中（数据工程 + 生成）。
- **落地步骤**：① 参数化 5 轴 + 干扰强度；② 构造 `T_test` 采样器；③ 计算与训练集的分布距离；④ 训练 / 选择时用 CVaR；⑤ 验证覆盖度量与真机掉点的相关（E626）。
- **风险**：合成与真机存在"仿真-现实"差距，覆盖度量可能高估。对冲：只用覆盖度量做**相对排序**，绝对风险仍以真机锚点为准。

### IP-14 · OperatorSplit 演示者签名与留出评估（P1）

- **动机**：官方数据由人类遥操作采集（B 类：是否有 operator ID 待查）。若随机切分让同一操作员的风格同时出现在训练与测试，"新用户泛化"会被系统性高估。
- **与第 1 轮的差异**：第 1 轮用随机 / OOD 切分；本轮增加**operator-held-out**，并把随机切分与留出切分的差值作为"新用户泛化差距"的下界。
- **技术可行性**：高（有 ID 时）；无 ID 时用动作统计（速度剖面、接近方向、抓取高度）做无监督聚类，需验证聚类稳定性。
- **所需资源**：小。
- **落地步骤**：① 查元数据 / 数据卡；② 无 ID 则聚类并做稳定性检验；③ 三种切分（随机 / 任务留出 / 操作员留出）对比；④ 报告差距；⑤ 用风格增广缩小差距。
- **风险**：聚类不稳或数据无签名 ⇒ 只能报告"无法检测"，不能声称"无差距"（不可证伪的陷阱）。

### IP-11 · StepToReach 站位 / 迈步决策（P1）

- **动机**：桌面远端目标可能超出"不迈步"的可达域；迈步能扩大支撑多边形与可达域，但也引入失稳与时间成本。
- **与第 1 轮的差异**：第 1 轮把 `pivot` 当常量或忽略；本轮把"站位"作为显式动作，并给出成本-收益触发规则（引理 L13）。
- **技术可行性**：中–低——**强依赖 B 类探测**：pivot 是否被跟踪、评测是否允许迈步。若接口不支持，降级为"重心偏移 + 躯干前倾"的准静态策略。
- **所需资源**：中（离线学"目标 → 可行站位"映射）。
- **落地步骤**：① E633 零成本探测；② 离线学站位先验；③ 在线选 stance + 触发迈步；④ 成本-收益规则；⑤ 真机 A/B（E623）。
- **风险**：迈步本身失稳 / 破坏桌面设定 / 时间超预算。对冲：默认关闭；仅在"不迈步必失败"且裕度充足时触发。

### IP-12 · RecoverySupervisor 恢复监督与优雅降级（P1）

- **动机**：人为干扰是 5 类泛化之一；一次跌倒是吸收态，代价远高于放弃当前任务。
- **与第 1 轮的差异**：第 1 轮退化链只有"不干预"；本轮有主动恢复技能：**松手（放弃物体）→ 后退 / 降重心 → 迈步 / 撑 → 重新接近**。原则是"任务可失败，平衡不可失败"。
- **技术可行性**：中。需要失稳预测器（可用 IP-09 的裕度 + 时序）+ 恢复技能库；迟滞切换避免抖动。
- **所需资源**：中；在线 <1 ms。
- **落地步骤**：① 定义失稳 / 近失稳事件；② 预测器或阈值 + 迟滞；③ 恢复技能库与优先级；④ 只在置信度高时触发；⑤ 人为扰动实验（E624）。
- **风险**：误触发破坏任务进度；恢复动作本身引入新失稳。对冲：迟滞 + 预算上限（每 episode ≤2 次）+ 触发前先做一次"最小干预"（减速 / 松手）。

## 3. 符号与定义（U13–U25）

| 符号 | 含义 |
|---|---|
| `m_t` | 稳定裕度：ZMP / 捕获点到支撑多边形的有符号距离 |
| `S_t` | 生存谓词 `1[m_t ≥ m_min]`；`fall` 为吸收态 |
| `b_t` | 漂浮基座状态（位置 / 姿态 / 线速度 / 角速度） |
| `b̂_t, Σ_b` | 基座状态估计及其协方差（B 类：可能不可直接观测） |
| `ψ_t` | 基座不变的抓握证据特征（相对位姿变化 / 开合 / 相对光流） |
| `q` | 测试者采样器（"用户总体"） |
| `T` | 测试五元组 `(q, π_test, P, M, R)` |
| `W₁, MMD` | 1-Wasserstein 距离 / 最大均值差异（覆盖度量） |
| `CVaR_α` | 尾部风险指标：最差 `α` 比例场景的平均成功率 |
| `o_k` | 演示者（teleoperator）隐变量 |
| `IG(i)` | 测试项 `i` 的信息增益 |
| `α_K` | Krippendorff 编码一致性 |
| `MDE` | 最小可检测效应 |
| `SW` | 严重度加权成功 |

**定义 U13（稳定裕度）** `m_t = signedDist(zmp_t, P_support(feet_t))`，其中 `zmp_t` 由 CoM 与其加速度（LIPM 近似）或全身动力学估计；`P_support` 为当前足接触构成的支撑多边形。无 base 观测时，`m_t` 替换为基座系内的相对裕度代理 `m̃_t`，并携带估计协方差 `Σ_m`。

**定义 U14（生存谓词与吸收态成功）** `S_t = 1[m_t ≥ m_min]`；跌倒后 episode 不再可能成功。定义 `Survive = ∏_{t=1}^{T} S_t`，`P(success) = P(Survive=1)·P(complete | Survive=1)`。

**定义 U15（漂浮基座状态与可观测性）** `b_t = (p_b, R_b, v_b, ω_b)`；若观测不含 `b_t`，则 `b̂_t = g_b(leg_joints, foot_contacts, ee_poses, images)`，并输出 `Σ_b`。可观测性指标 `ρ_b = 1 − tr(Σ_b)/tr(Σ_prior)`。

**定义 U16（基座运动混叠）** 基座系下末端速度 `v_ee^{b} = R_b^{T}(v_ee^{w} − v_b − ω_b × r_ee)`。若抓握判定使用 `v_ee^{b}` 的绝对幅值作正证据，则在"未抓住"假设下，假阳性由 `v_b, ω_b` 的分布决定（见 L9）。

**定义 U17（基座不变抓握证据与隐变量）** `g_t = σ(f_θ(ψ_t, Σ_b))`，`ψ_t = [Δpose(obj, gripper) 由腕部视觉估计；Δgrip_t；wrist_flow_t − background_flow_t；v̂_b, ω̂_b]`。`g_t ∈ [0,1]` 为"已抓稳"的概率；**不确定性越高，`g_t` 越向 0.5 收缩（保守）**。

**定义 U18（测试者总体）** `T = (q, π_test, P, M, R)`；`q` 在 5 轴 `(position, distractor, background, novel_object, human_interference)` 上定义分布，并允许轴间相关（如"拥挤 + 人干扰"）。

**定义 U19（覆盖与风险敏感目标）** 覆盖 `Cov = −W₁(D_demo, T_test)`（越大越好）；风险敏感目标 `J = mean(success) − λ·(mean(success) − CVaR_α(success))`，`λ≥0` 控制尾部权重。

**定义 U20（演示者签名）** `o_k` 为操作员隐变量；若在动作统计 `z(a)` 上存在可检测差异（置换检验 p<0.05），则称存在签名。定义"新用户泛化差距" `G_op = R_heldout − R_random`。

**定义 U21（测试信息增益）** `IG(i) = H(θ) − E_{y_i}[H(θ | y_i)]`，`θ` 为待判定量（每任务成功率 / IP 边际收益）。预算 `K`、成本 `c_i`、MDE 约束下选 `argmax Σ IG(i)`。

**定义 U22（编码可靠性与 MDE）** `α_K` 为 Krippendorff α；`MDE = (z_{1−α/2}+z_{1−β})·√(2p(1−p)(1−ρ)/n)`（配对相关 `ρ`），编码误差按 `MDE_eff ≈ MDE/√reliability` 近似放大。

**定义 U23（严重度加权成功）** `SW = Σ_j w_j·1[final outcome = j]`，`w_fall < w_task_fail < w_success_with_recovery < w_clean_success`；用于检查二值成功是否掩盖了严重度差异。

**定义 U24（恢复切换）** 监督器状态 `s ∈ {normal, guarded, recovering}`；带迟滞的切换规则：`normal→guarded` 当 `P_fall > τ_hi`；`guarded→normal` 当 `P_fall < τ_lo`（`τ_lo < τ_hi`）；`recovering` 有预算 `B`，耗尽强制回 `guarded`。

**定义 U25（平衡感知的失败分解）** `P(success) ≈ P(Survive)·∏_{j∈{reach,grasp,transport,align,insert,release}} P_j`；其中 `P(Survive)` 吸收 `fall / near-fall / recovery` 事件，`P_j` 仅在 `Survive=1` 条件下估计。

## 4. 关键算法骨架

```python
# ===== IP-09：稳定裕度 + 安全投影（每步门控）=====
class StanceGuard:
    def __init__(self, m_min=0.02, kappa=2.0, gamma=0.1, mode="guarded"):
        self.m_min, self.kappa, self.gamma, self.mode = m_min, kappa, gamma, mode

    def margin(self, obs):
        q_leg = obs["observation.state.lower_body"]
        feet = contact_estimate(obs)                  # 有足接触则用；否则视觉/EE 代理
        com_b = com_from_leg_fk(q_leg)                # 基座系重心
        b_hat, Sigma_b = self.base_estimator(obs)     # U15；可能来自 IMU / 腿FK+背景光流
        sup = support_polygon(feet, b_hat)            # 支撑多边形
        m = signed_distance(com_b, sup)               # U13
        return m, Sigma_b

    def project(self, a, obs):
        if self.mode == "observe":
            return a, "observe"
        m, S = self.margin(obs)
        if m - self.kappa * float(torch.sqrt(S.trace())) >= self.m_min:
            return a, "normal"
        # 离散 CBF 近似：先限速/限幅，再退让（抬升、后撤、收臂）
        a_safe = self.safe_projection(a, m)           # 收缩到 m_{t+1} >= (1-gamma)*m_t
        return a_safe, "guarded"


# ===== IP-10：基座不变的抓握确认（替换第 1 轮 GraspVerifier）=====
class BaseDecoupledGraspVerifier:
    def prob(self, obs):
        # 1) 相对几何：物体相对夹爪的位姿变化（腕部视觉 + 几何）
        d_rel = relative_object_motion(
            obs["observation.images.cam_left_wrist"],
            obs["observation.images.cam_right_wrist"],
            obs["observation.state.left_ee_pose_gripper_base"],
            obs["observation.state.right_ee_pose_gripper_base"],
        )
        # 2) 相机自运动：头部相机背景光流（无需 IMU 的基座运动代理）
        flow_bg = background_flow(
            obs["observation.images.cam_left_high"],
            obs["observation.images.cam_right_high"],
        )
        v_base, Sigma_b = self.base_estimator(obs)    # U15
        grip = torch.cat([obs["observation.state.left_gripper"],
                          obs["observation.state.right_gripper"]], dim=-1)
        x = self.feat(d_rel, flow_bg, grip, v_base, Sigma_b)
        logit = self.net(x)
        # 3) 不确定性感知：Sigma_b 越大，越向 0.5 收缩（保守）
        shrink = 1.0 / (1.0 + self.lam * float(Sigma_b.trace()))
        return 0.5 + shrink * (torch.sigmoid(logit) - 0.5)


# ===== IP-12：恢复监督（迟滞 + 预算，防抖）=====
class RecoverySupervisor:
    def __init__(self, tau_hi=0.6, tau_lo=0.3, budget=2):
        self.tau_hi, self.tau_lo, self.B = tau_hi, tau_lo, budget
        self.state, self.budget = "normal", budget

    def act(self, a, obs):
        p_fall = self.fall_risk(obs)                  # 裕度时序 + 速度 + 接触
        if self.state == "normal" and p_fall > self.tau_hi:
            self.state, self.budget = "recovering", self.B
        elif self.state == "recovering":
            self.budget -= 1
            if self.budget <= 0 or p_fall < self.tau_lo:
                self.state = "guarded" if p_fall >= self.tau_lo else "normal"
        if self.state == "recovering":
            return self.recovery_skill(obs)           # 松手 → 后撤/降重心 → 迈步/撑
        return a


# ===== IP-15：信息最优测试调度（子模贪心 + MDE 约束）=====
def schedule_tests(tests, K, theta_prior, mde):
    chosen, remaining = [], list(tests)
    for _ in range(K):
        # IG(i) = H(theta) - E[H(theta | y_i)]；条件独立假设下熵减子模（L10）
        best = max(remaining, key=lambda i: info_gain(i, chosen, theta_prior))
        if interpolated_mde(chosen + [best], mde) > mde.target:
            break
        chosen.append(best)
        remaining.remove(best)
    return chosen
```

## 5. 推导（引理 L8–L14）

**引理 L8（吸收态下的成功分解）** 若跌倒 / 失稳使 episode 不可恢复，则 `P(success) = P(Survive=1)·P(complete | Survive=1)`；第 1 轮的 `∏P_j` 只在 `Survive=1` 条件下成立。推论：两个模型的条件成功率相同但失稳率不同，原始成功率排序会被失稳率支配；在 `S=30%` 附近，1pp 失稳率约等于 0.32pp 成功率。∎

**引理 L9（基座混叠的假阳性单调性）** 设未抓握时相对末端速度 `v_rel ~ N(μ_rel, σ_rel²)`，基座注入 `v_b ~ N(0, σ_b²)`，判定规则为 `v_rel + v_b > τ`。则 `FPR(σ_b) = 1 − Φ((τ − μ_rel)/√(σ_rel² + σ_b²))`，对 `σ_b` 单调递增。⇒ 若不建模基座运动，FPR 会随摆动幅度上升；要维持 `FPR ≤ α`，阈值必须随 `σ_b` 放大（或改用不变量特征）。∎

**引理 L10（测试选择的贪心近似比）** 若测试结果在给定 `θ` 下条件独立，则熵减 `IG` 是子模函数；在基数约束 `|S| ≤ K` 下，贪心达到 `(1−1/e)` 的最优近似（Nemhauser–Wolsey–Fisher）。若任务间相关，贪心仅为启发式，需回测校准。∎

**引理 L11（覆盖-风险界）** 若损失 `ℓ` 关于相关状态是 `L`-Lipschitz 且有界，则由 Kantorovich–Rubinstein 对偶，`|E_T[ℓ] − E_D[ℓ]| ≤ L·W₁(D, T)`。⇒ 最小化 `W₁(D_demo, T_test)` 可给出"新用户"风险差的上界；`MMD` 可作为高维替代（但需核函数选择）。∎

**引理 L12（MDE 与可靠性）** 两系统配对比较的成功率差估计量方差 `Var(Δ̂) = 2p(1−p)(1−ρ)/n`；在显著性 `α`、功效 `1−β` 下 `MDE = (z_{1−α/2}+z_{1−β})√(Var)`。若失败标签可靠性为 `r`，有效方差约放大 `1/r` ⇒ `MDE_eff ≈ MDE/√r`。⇒ 低于 `MDE_eff` 的"提升"不可作为证据；可靠性越低，可支持的结论越粗。∎

**引理 L13（安全投影的代价-收益）** 设不投影时任务收益为 `G`、跌倒概率为 `f`、跌倒损失为 `L_f`；投影移除的动作集合占最优动作分布的质量 `μ`，带来收益损失约 `μ·ΔG`，但把跌倒概率降到 `f'`。投影占优于不投影当 `(f − f')·L_f > μ·ΔG`。若可通过迈步扩大支撑（成本 `c`）进一步降低 `f'`，则迈步值得当 `(f' − f'')·L_f > c + 迈步本身的风险`。⇒ 给出"何时该稳、何时该迈步"的可计算判据。∎

**引理 L14（操作员留出的偏差）** 设操作员 `k` 的条件风险为 `R_k`，随机切分下测试集的操作员权重为 `w_k`，留出切分下为 `w'_k`。则 `R_random − R_heldout = Σ_k (w_k − w'_k)R_k`。当 `w ≠ w'` 且 `R_k` 有差异时该差非零；因此 `G_op = R_heldout − R_random` 是"新操作员"泛化差距的可估计下界（在留出操作员同分布假设下）。若检测不到签名，只能报告"未检测到差异"，不能声称"无差距"。∎
