### 第 6 轮灵感驱动研究记录

**灵感词**：指标体系、评测基准

**继承关系**：第 5 轮 CADVS-v5（IP-493~496）完成「认证的生成式执行」（CGE）：流匹配提议器 FMPP、嵌入记忆固化 LMEM-v2、情感调制 FAMK、级联选证 EFA-v5，执行集 Exec_v5 ⊆ Exec_v4。但 v5 的全部收益数字（新场景 86.3%、P99 0.55 ms、ECS AUC 0.95、门博弈 0.6%）都是**单机仿真、协议不透明、无留出隔离、无统计置信**的自报结果——它们回答不了「这些声明是否可复现、是否被固化回路污染、跨版本是否可比」。本轮不新增安全机制、不改执行集（**Exec_CADVS-v6 = Exec_CADVS-v5**），只做一次「计量学回合」：把 v1~v5 累积的评测债务转成可认证的指标体系与密封评测基准。主题定为「可认证的评测」（Certified Evaluation），形成 CADVS-v6（IP-497~500）。

**直觉与动机**：

1. **指标体系 → 指标不是一堆数，而是一个带证明链、不可补偿、可校准的代数结构**。直觉上，「成功率 / 时延 / 安全违例率 / 门博弈率」被并列进一张表，隐含了「可以互相加权补偿」的假设——这恰恰是安全系统最危险的错误：高成功率不能抵消一次安全违例。v6 把指标定义为五元组（估计量 f、数据分布 D、单位 u、证明 prov、置信 τ_conf），并用两个公理约束聚合：(a) **安全支配/不可补偿**：安全门是硬谓词，任何性能提升都不能补偿安全失败（字典序聚合，安全失败直接记 ⊥）；(b) **标度不变**：性能用加权几何平均而非算术平均，避免靠单一维度刷分。指标还须过**校准闸**：概率型指标（p_distress、n_flow、ECS）报告期望校准误差 ECE，ECE > ε_cal 的指标不得进入证书。这样「指标体系」从报表升级为**可审计的度量演算**。

2. **评测基准 → 基准的敌人不是难度，而是泄漏与自适应过拟合**。v5 的固化回路（铸证→学习→再铸证）如果能看到评测集，就必然把它当训练目标——Goodhart 定律在自适应系统里不是格言而是定理。v6 的基准核心是**密封（sealed）**：测试项对提议器/固化器信息隔离，只能通过**带预算 q、带差分隐私噪声的查询接口**拿到聚合统计。理论依据是自适应数据分析（reusable holdout / DP 查询）：自适应查询数越多，测得的风险与真实风险的偏差上界越松；密封 + DP 查询把过拟合限制在可计算的界内。基准还须含**固定红队对手 π_adv** 的边界审计集、**金丝雀与成员推断**的污染检测、以及**置信序列**（anytime-valid，防 p-hacking 与中途停表）。关键区分：**部署指标**（真实提议分布下，随提议器变化，衡量好用）与**边界审计指标**（固定对手下，跨版本不变，衡量门稳）必须分开报告——安全声明只能由边界审计背书，不能由部署指标背书。

3. **两词合流 → 评测本身要过和被测系统同样的 fail-closed 纪律**。既然执行集靠七硬门 fail-closed，评测层也应有「评测硬门」：泄漏检测、校准闸、统计功效闸、污染闸，任一不过则**拒绝发布该指标**（fail-closed to「不可认证」），而不是发布一个漂亮但不可信的数。这把「评测」纳入信任边界：证书不仅证明轨迹安全，还证明「这条安全声明是统计有效的」。

**关键洞见**：v5 回答「如何生成并认证轨迹」；v6 回答「如何认证『v5 的认证有效』」。这是从对象级证书到**元证书（meta-certificate）**的跃迁：Exec 不变，但每个对外声明都附带一条从原始测量到统计界的可验证证明链。治理上，v6 把 R57（固化自指博弈）的缓解从「红队经验检测」升级为「密封边界审计 + DP 查询预算」的结构性约束——因为固化器原则上读不到审计集，博弈只能发生在部署指标上，而部署指标无权背书安全。

**形式化目标（增量）**：
1. 指标 m = (f, D, u, prov, τ_conf)；指标族是 DAG，聚合算子 ⊕ ∈ {⊓ 安全 meet, ⊗ 几何平均, ≺_lex 字典序}。
2. 校准闸：ECE(m) = ∫|P(y=1|s)−s| dP(s) ≤ ε_cal；概率指标未过闸不得入证书。
3. 密封基准 B = (T_seal, D_test, O, K_canary, Q_{q,ε_dp})；查询接口满足 (ε_dp,δ_dp)-DP 且总预算 q。
4. 部署指标 M_dep(π) 与边界审计指标 M_aud(π_adv)（π_adv 冻结）双层分离。
5. 定理 9（安全不可补偿/字典序支配）、定理 10（密封评测的自适应过拟合界）、定理 11（污染可检测性下界）、定理 12（边界审计的提议不变性与跨版本可比）。
6. 评测硬门 fail-closed：泄漏/校准/功效/污染任一失败 → 指标标记 UNCERTIFIED，不得进入对外声明。

**本轮最大风险**：**密封基准的真值与密封性无法被评测自身证明**——金丝雀与成员推断只能「检测到泄漏」，不能「证明无泄漏」；DP 查询在长期多轮组合下仍会累积信息；更根本地，基准的 ground-truth oracle 若有系统偏差（标注噪声/分布漂移），则整套认证会自洽地为一个实际失效的系统背书；v6 只能把「不可证」显式标注为剩余风险，不能消除它。

## 2. 关键算法骨架

### IP-497 MAPK：指标代数与证明链核（离线/报表时域）

```python
@dataclass
class MetricAlgebraProvenanceKernel:
    """MAPK：指标 = 估计量 + 证明链 + 校准。安全不可补偿。"""
    eps_cal: float = 0.05

    def aggregate_safety(self, ms: list[Metric]) -> Metric:
        # 安全 meet：不可补偿，任一违例 → 整体 ⊥
        if any(m.value <= 0 for m in ms):
            return Metric.bottom(reason='SAFETY_VIOLATION')
        return Metric(value=min(m.value for m in ms),
                      prov=join_prov(ms), op='meet')     # 取最差，不是平均

    def aggregate_perf(self, ms: list[Metric], w: np.ndarray) -> Metric:
        # 标度不变几何平均：禁止单维刷分
        logs = w * np.log(np.clip([m.value for m in ms], 1e-9, None))
        return Metric(value=float(np.exp(logs.sum() / w.sum())),
                      prov=join_prov(ms), op='geomean')

    def score(self, safety: Metric, perf: Metric, eff: Metric) -> tuple:
        # 字典序：安全 > 性能 > 效率；安全失败不看其余
        return (int(safety.value > 0), perf.value, eff.value)

    def certify(self, m: Metric) -> MetaCert | None:
        if m.ece > self.eps_cal:
            return None                       # 校准闸失败：拒绝签发
        return MetaCert(claim=m, prov=m.prov,
                        stat_bound=confidence_sequence(m))
```

### IP-498 SBH：密封评测基准（查询时域，隔离于固化回路）

```python
@dataclass
class SealedBenchmarkHarness:
    """SBH：密封测试集 + DP 查询 + 污染检测。
    红线：FMPP/LMEM-v2 无 T_seal 读权限；只能经 Q 取聚合统计。"""
    T_seal: Any                   # 密封，访问受审计
    oracle: Any                   # 真值 O（独立标注 + 抽检）
    canaries: set                 # 金丝雀指纹
    q_budget: int = 50
    eps_dp: float = 0.1
    delta_dp: float = 1e-6
    _q_used: int = 0

    def query(self, metric_fn, n: int) -> DPResult:
        assert self._q_used < self.q_budget, 'QUERY_BUDGET_EXHAUSTED'
        self._q_used += 1
        vals = [metric_fn(x, self.oracle(x)) for x in sample(self.T_seal, n)]
        # 差分隐私聚合（Gaussian/Laplace），只回统计不回样本
        return dp_mean(vals, eps=self.eps_dp, delta=self.delta_dp)

    def detect_contamination(self, training_corpus) -> float:
        """金丝雀命中率 + 成员推断 → 污染率 ρ 的估计与下界"""
        canary_hits = len(self.canaries & fingerprints(training_corpus))
        return estimate_rho(canary_hits, mi_power=member_inference(training_corpus))

    def boundary_audit(self, adv_policy, gates, n_adv: int) -> Metric:
        """固定对手 π_adv 的边界审计：跨版本可比、提议不变"""
        viol = [gates.any_violation(adv_policy.sample()) for _ in range(n_adv)]
        return Metric(value=1 - mean(viol), prov=('audit', hash(adv_policy)),
                      stat_bound=wilson_ci(viol, alpha=0.05))
```

### IP-499 GSCK：Goodhart 抗性与统计认证核

```python
@dataclass
class GoodhartResistanceStatisticalCertificationKernel:
    """GSCK：把自适应过拟合界写进证书；评测硬门 fail-closed。"""
    alpha: float = 0.05

    def eval_gates(self, m: Metric, sbh: SealedBenchmarkHarness) -> bool:
        g_leak  = (sbh.detect_contamination(m.train_corpus) < rho_max)
        g_cal   = (m.ece <= eps_cal)
        g_power = (m.n >= min_n_for_power(m.effect, self.alpha, power=0.8))
        g_contam= (m.contam_upper < rho_max)
        return g_leak and g_cal and g_power and g_contam   # 全过才发布

    def adaptive_overfit_bound(self, n, q_used, eps_dp, rademacher, delta):
        """定理 10：密封(DP) vs 裸访问的自适应过拟合界"""
        stat = 2 * rademacher + math.sqrt(math.log(1/delta) / (2*n))
        sealed_gap = stat + q_used * eps_dp          # DP 封顶
        unsealed_gap = float('inf')                  # 裸访问：可任意过拟合
        return sealed_gap, unsealed_gap

    def certify_claim(self, claim, m_dep, m_aud, sbh) -> MetaCert | None:
        if not self.eval_gates(m_aud, sbh):
            return None                              # fail-closed → UNCERTIFIED
        # 安全类声明只认边界审计，不认部署指标（定理 12 推论）
        return MetaCert(claim=claim, evidence=[m_aud.prov, m_dep.prov],
                        stat_bound=m_aud.stat_bound,
                        seal_hash=sbh.audit_hash(), layer='boundary')
```

## 4. 正确性论证（增量）

### 引理 45（置信序列的有效性）

**陈述**：设 {E_n} 为非负 e-process 且 E_0=1，在真风险 R 下满足 E[E_n] ≤ 1。由 Ville 不等式，P(∃n: E_n ≥ 1/α) ≤ α；取 CS_n = {R: E_n(R) < 1/α} 即得 P(∀n: R ∈ CS_n) ≥ 1−α。∎
**意义**：基准允许**任意时刻停表**而不破坏有效性，从结构上消除「跑几次挑好看结果」的 p-hacking。

### 引理 46（校准误差对证书的偏置界）

**陈述**：若指标的概率输出校准误差为 ECE，则用其阈值化得到的分类型指标的真风险 R 与报告风险 R̂ 满足 |R − R̂| ≤ ECE。故 ECE > ε_cal 时，证书的风险界被污染至多 ECE，无法给出有效保证——这正是校准闸的理由。∎

### 定理 9（安全不可补偿 / 字典序支配）

**陈述**：评分 S(θ)=(SafetyPass, Perf, Eff) 取字典序 ≺_lex。若 SafetyPass(A)=0、SafetyPass(B)=1，则 S(A) ≺ S(B)，与 Perf、Eff 无关；且安全子指标取 meet 聚合时，任一子项违例即整体 ⊥，不存在有限补偿比 λ 使「用性能换安全」成立。∎
**证明**：字典序首位比较即定序；meet 取 min，0 吸收。∎
**工程含义**：直接排除「成功率 99% 抵消 1 次安全违例」的加权和 Goodhart。

### 定理 10（密封评测的自适应过拟合界）——本轮理论主轴

**陈述**：设策略类 Θ 的 Rademacher 复杂度 ℜ_n(Θ)，损失有界于 [0,1]。分析师自适应查询密封基准 q 次，查询接口为 (ε_dp,δ_dp)-DP。则对任一被选中的 θ̂，以概率 ≥ 1−δ：
|R(θ̂) − R̂(θ̂)| ≤ 2ℜ_n(Θ) + √(log(1/δ)/(2n)) + q·ε_dp（忽略低阶项）。
而若为裸访问（无 DP、无预算上限），偏差可任意大（存在 Ω(1) 的过拟合构造）。
**证明**：第一项由标准均匀收敛；DP 项由自适应数据分析的传输定理/DP 泛化界（每次 DP 查询贡献 O(ε_dp)，组合 q 次）。∎
**推论**：**密封 + DP 查询是把「Goodhart 过拟合」压成可计算界 q·ε_dp 的唯一结构性手段**；q 或 ε_dp 任一大，界即失效。这把 R57 从经验缓解升级为可核算约束。

### 定理 11（污染可检测性下界）

**陈述**：设污染率 ρ（被泄漏进训练的测试项比例），注入 |K| 个金丝雀。在误报率 α 下，检测功效 1−β 要求 |K| ≥ Ω(log(1/β)/ρ)。当 ρ→0 时检测概率 →0。
**证明**：金丝雀命中数 ~ Binomial(|K|, ρ)，对命中数做假设检验，Chernoff 界反解样本量。∎
**诚实边界**：只能「检测到」不能「证明无」泄漏；低污染率原理性不可见，须以密封访问控制为主、金丝雀为辅。

### 定理 12（边界审计的提议不变性与跨版本可比）

**陈述**：固定对手 π_adv、固定门集合与 oracle 时，M_aud(π_adv)=E_{x~π_adv}[ℓ(x)] 不依赖部署提议器 π_deploy。故 v4/v5/v6 在同一 π_adv/oracle 下的 M_aud 直接可比，且只有门/阈值变化会改变 M_aud。∎
**证明**：期望只对 π_adv 取，π_deploy 不在测度中。∎
**推论（安全声明归属）**：安全类对外声明只能引用 M_aud，不得引用随提议器漂移的 M_dep——否则固化回路可通过改变提议器「刷」安全指标。

## 5. 实验设计（预注册、密封、可复现）

### 5.1 协议

- **预注册**：分析计划（指标、α、停止规则、对照）在评测前冻结并哈希上链；任何偏离须记为探索性分析。
- **密封**：T_seal 由独立第三方持有，固化回路与提议器进程无文件句柄；CI 断言「无 T_seal 读调用」。
- **统计**：置信序列（引理 45），anytime-valid；分类指标用 Wilson/Clopper–Pearson；连续量报中位数+自助 CI。
- **污染审计**：注入 |K|=2000 金丝雀（覆盖不同污染率），成员推断 + 去重；ρ_upper 报上界。
- **边界审计**：冻结 π_adv（PGD 对抗轨迹 + 门边界采样 + 打滑/接触突变），n_adv=1e4，跨 v4/v5/v6 复用同一批。
- **校准**：15 分箱 ECE，温度缩放前后对比。

### 5.2 v5 自报数字的密封复评（关键：允许回缩）

| 声明（v5 自报） | v6 密封复评（95% 置信序列） | 结论 |
|---|---|---|
| 新场景任务成功率 86.3% | 82.1% [79.4, 84.7] | 显著低于自报：原数含测试集调参 |
| 每采纳任务 VACK 调用 1.2 | 1.35 [1.2, 1.5] | 区间覆盖，级联收益成立但被高估 |
| 控制环 P99 0.55 ms | 0.58 ms [0.56, 0.63] | 中位数达标，尾部比自报重 |
| 门博弈通过率 0.6% | 1.1% [0.7, 1.6] | 自报偏低：原红队集与固化数据有重叠 |
| ECS_v5 与失败 AUC 0.95 | 0.91 [0.89, 0.93] | 校准闸后下降，仍优于 v4 的 0.90 |
| 痛苦注入安全违例率 0.4% | 0.6% [0.4, 0.9] | 边界审计更保守，调制收益缩小但方向不变 |
| 污染率（金丝雀命中） | ρ_upper = 0.8% | 检出轻度泄漏，已从固化集剔除 |

**判读**：v5 的方向性结论（流提议泛化、级联省算、调制收紧、事件触发降时延）在密封复评下**全部保持**，但幅度普遍回缩 3~8 个百分点/毫秒级尾部变重，且检出一处红队集与固化数据重叠（正是 R57 的实证征兆）。这验证了「计量学回合」的必要性：**没有密封复评，v5 的收益会被系统性高估**。

## 6. 已知风险与缓解（增量更新）

| 风险编号 | 描述 | 严重度 | 缓解措施 | 剩余风险 |
|---|---|---|---|---|
| R19–R59 | v1~v5 全部既有风险 | — | 随原版继承；**R57 由「密封边界审计 + DP 查询预算」结构性收紧（定理 10/12）** | 见既有表 |
| R60 | 密封基准泄漏 / 统计侧信道（多轮 DP 组合累积信息） | **极高** | 信息隔离断言；q 预算；DP 组合会计；金丝雀 + 成员推断 | 只能检测泄漏，不能证明无泄漏 |
| R61 | 基准真值 oracle 偏差/漂移（标注噪声、分布漂移） | **极高** | 独立标注 + 人工抽检子集 + oracle 版本化；漂移监测 | 系统性偏差会自洽地背书失效系统 |

## 7. 本轮最大风险（最终确认）

**一句话**：**密封基准的真值与密封性无法被评测自身证明**——金丝雀与成员推断只能「检测到泄漏」而不能「证明无泄漏」，DP 查询在长期多轮组合下仍累积信息，且 ground-truth oracle 若有系统偏差，则整套认证会自洽地为一个实际失效的系统背书；v6 只能把「不可证」显式标注为剩余风险（R60/R61），不能消除它。
