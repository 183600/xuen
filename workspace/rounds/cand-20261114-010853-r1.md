# 第 71 轮（承接第 70 轮「GROUND-RAS 假设契约 × 证书格 × 失效关闭降级」IP-264~276；灵感循环新循环第 4 轮；本轮灵感：「流匹配策略」×「自然语言指令」）

> R70 把散落在六十九轮括号里的前提提成一等公民：假设原子、有效包络、证书格、部署许可、失效关闭降级。它回答的是「**这些保证在什么条件下成立、条件失效时谁接住我**」。但它自己默认了一个从未被审计的输入——**自然语言指令**。整个研究栈里，指令一直是 `ℓ`，被编码成一个条件向量，然后被当作真值。可「把杯子放到桌边，别碰壶」这句话里至少埋着四个前提：哪个杯子（指称）、「桌边」多远（参数）、`别` 的辖域覆盖到哪（否定/作用域）、以及**谁有资格说这句话**（权威）。R70 的证书能保证「在目标被正确形式化的前提下安全执行」，却不能保证「目标被正确形式化了」。这是整棵树上最后一层没被打开的递归：**验证者依赖一个未被验证的翻译器。**
>
> 两个灵感正好各补一半：
> - **流匹配策略**给出「指令 → 动作分布」的显式生成器。指令有歧义，动作分布就多峰；于是「这句话我听没听懂」变成了一个**可在动作空间被采样、聚类、测量**的量，而不是靠模型自省的一句「我懂了」。
> - **自然语言指令**把话本身当成一份**部分指定的契约**：它承诺目标、时序、安全不变量与授权范围，但因为用自然语言写，必须被接地、消解歧义、仲裁冲突、合规验证。
>
> 核心命题：**把「指令」从不可质疑的条件升级为可验证的契约——形式化解析成指令契约 IC；为每个语素建立可测的接地证书并标注有效包络；用语言条件流匹配策略把歧义显式为动作模态并定义语义合规分；用权威格 + 安全否决仲裁多来源指令；用双解析冗余、受限澄清问句和可追溯的指令溯源链，把「理解错」从静默失效变成可见、可问、可拒、可审计的失败。** 命名 **LINGUA-RAS**（Language-Instruction grouNding with Guarantees, Uncertainty & Arbitration — Risk-Adaptive System）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「离开实验室后这些保证还剩多少」，R71 问「**你说的这句话我真的听懂了吗？我凭什么相信我的听懂是对的？**」——安全不只要求做对动作，还要求对「什么叫对」本身保持怀疑。

## 0. 直觉与动机

**灵感 1（自然语言指令 → 指令是部分指定的契约，不是条件向量）**
直觉：`ℓ` 被送进编码器后，模型输出的那个向量**看起来**很确定，但确定的是表示，不是含义。自然语言的关键麻烦不在句法，而在它天然**欠指定**（underspecified）：指称要靠场景、参数要靠常识、否定和量词有辖域、意图要看语用。把它压成一个向量，等于把「这里本来有 4 个未决变量」悄悄变成「已经全定了」。正确做法是把指令解析成一份**带洞的契约**：能定的定成可测谓词，定不了的显式标成 UNKNOWN，并记录每个变量由谁、凭什么证据来定。**没有洞的契约是幻觉；有洞但不承认的契约是灾难。**

**灵感 2（流匹配策略 → 歧义可以在动作空间里被采样出来）**
直觉：R69 已经证明流匹配能生成多模态动作块。现在把它条件在 `ℓ` 上：如果同一句话真的对应两种理解（「靠左放」还是「放左边那个」），那么策略在不同解释下生成的轨迹会落在不同的模态。反之，如果各解释下动作分布重合，说明这个「歧义」对行为**无关紧要**——不值得问。于是歧义有了一个操作定义：**由解释引起的动作分布之间的可分性**。这比让语言模型自报「这句话可能有歧义」可靠得多，因为它把语义问题投射到了可观测的物理量上。

**灵感 3（接地 → 词必须落到可测谓词上，且带有效包络）**
直觉：`桌边` 不是一个像素，`别碰` 不是一个力阈值。要把契约变成可验证的，每个关键语素都要有一条接地证书：它对应哪个可测谓词、在什么场景包络内这个对应才可信、误接地率是多少、证据来自符号解析器、神经解析器还是人类确认。**「接地」不是查词典，是签合同**：词义在具体场景里的有效范围必须被写明，否则 `别碰` 在湿滑地面上到底对应 5N 还是 20N 就是一笔糊涂账。R70 的有效包络 𝒱(J) 由此从「场景」扩张到「(场景, 指令)」的二元组。

**灵感 4（权威与安全否决 → 不是所有话都该被听，安全约束只能否绝不能授权）**
直觉：真实环境里指令有多个来源：操作员、安全监督员、路人、上层规划器、模型自己生成的子目标。它们会冲突。一个只做「解析 + 合规」的系统会陷入「最后一句赢」或「谁声音大听谁」。正确结构是一个**仲裁格**：来源带权威等级，冲突时高权威优先；但安全不变量是**单向**的——任何来源都可以**否决**一个危险指令，却没有任何来源可以**授权**一个违反安全不变量的指令。这条「安全向上封闭、权威向下封闭」的不对称性，是防止社会工程与提示注入的结构性护栏。

**灵感 5（双解析与溯源 → 别让验证器和被验证者共享同一个误解）**
直觉：R70 最大的教训是「保证与其前提共享同一个分布，前提静默失效时验证它的门也一起失效」。语言层完全同构：如果形式化器和神经策略共享同一个编码器、同一个训练偏差，它们会**一起**把「别碰壶」理解成「别碰壶旁边的杯子」。所以关键字段必须由**两个独立解析器**（符号文法 + 神经语义）分别给出，分歧即 UNKNOWN；再加上一条从原始话音/文本 → 接地证书 → 解释后验 → 被执行动作 → 证书的哈希溯源链，让「谁在什么依据下把哪个词变成了哪个动作」可事后复核。**理解的可审计性，是理解可信的前提。**

**灵感 6（包含性 → LINGUA 必须把 GROUND / FLUID / R68 当作退化边界）**
直觉：延续 R68→R69→R70 的姿态：新层必须是旧层的严格泛化。当指令完全接地、无歧义、在语言包络内、且来源有权限时，LINGUA 退化为「按解释好的目标运行的 FLUID/GROUND」；任一条件不满足时，它不发明新行为，而是沿着 R70 的证书格**单调下降**到底层 J_⊥（拒绝执行 / 安全停机 / 请求人工）。R70 是格底，FLUID 是能力顶，LINGUA 是把「目标本身从哪来、是否可信」显式化的语言元层。

## 1. 形式化定义（增量：定义 329–345）

**定义 329（LINGUA-RAS 总览与三不变式）** LINGUA-RAS = (ILC, ICG, SAD, LCFM, SCV, LSE, IAL, IAC, SQM, DPM, SMG, IPA, AIC-LING, J_LING, RAS-WM¶)。三不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i / R69 293-i / R70 310-i）：指令解析、接地、歧义后验、仲裁只在语言慢环写，控制快环只读冻结的 IC 与合规门；
(ii) **无未接地执行**（no ungrounded execution）：任一关键语素缺乏有效接地证书，或存在未仲裁冲突，或语义合规分未达标，则不得执行，只能澄清/拒绝/降级；
(iii) **语义失效关闭**：解析失败、双解析分歧、超语言包络、无权指令一律映射为 UNKNOWN，并按 R70 证书格单调下降到 `J_⊥`；**任何「大概懂了」都不得被解释为「可以执行」。**

**定义 330（指令契约 IC）** 自然语言指令 ℓ 解析为
`IC(ℓ) = (φ_goal, ψ_temporal, I_safe, Auth_req, 𝒢, Amb)`：
φ_goal 是轨迹上的可测目标谓词；ψ_temporal 是时序/时限约束（含「先…再…」「直到…」）；I_safe 是必须恒成立的安全不变量；Auth_req 是执行所需权限；𝒢 是语素到可测谓词的接地映射；Amb 是显式歧义集（维度 × 候选解释）。IC 是**部分**规格：未定字段取 ⊥ 并进入 Amb，绝不默认填值。

**定义 331（接地证书 GC）** 对 ℓ 的每个关键语素 u（实体、指称、谓词、参数、限定词），
`GC(u) = (pred_u, 𝒱_u, β_u, src_u, t_u)`：
pred_u 为场景内可测谓词；𝒱_u ⊆ 𝒞 为其有效包络（R70 定义 312 在语言维的扩张）；β_u 为误接地率上界；src_u ∈ {symbolic, neural, human, scene-graph} 为证据来源；t_u 为签发时间。语素**已接地** ⇔ `c ∈ 𝒱_u ∧ β_u ≤ β_max ∧ pred_u 可实时求值`。未接地语素集合记为 `U(ℓ)`。

**定义 332（语义歧义分解 SAD）** 歧义沿四个维度展开：词汇（lexical，`轻放` 的力阈值）、指称（referential，哪个杯子）、辖域（scope，`别碰壶和杯` 否定覆盖谁）、语用（pragmatic，`快点` 是催促还是抱怨）。得解释集 `ℐ(ℓ)={ι_1,…,ι_m}` 与后验 `w(ι) ∝ p(ℓ|ι)·p(ι|o)`。对每个 ι 由 LCFM 生成动作分布 `π_θ(·|o,ℓ,ι)`。定义
`U^lang_ale = Σ_ι w(ι)·tr Σ_ι`（同一解释内的动作噪声，不可约）；
`U^lang_epi = H(ℐ|o,ℓ)`（解释间熵，可约，靠澄清）。
与 R69 的 (U_ale, U_epi) 并列但**语义不同**：R69 的歧义是「世界是什么」，R71 的歧义是「你要什么」。

**定义 333（语言条件流策略 LCFM）** `v_θ(x_s, s | o_t, e(ℓ), ι)`，`e(ℓ)` 为冻结文本编码，ι 为解释令牌；条件编码复用 R69 trunk（z_t）与 R70 场景上下文，零重复训练；采样 `ξ_{t:t+H}=(a,g)` 仍走 rectified N_step=2。语言编码器**冻结且不接收快环梯度**，防止「为了完成任务而扭曲理解」。

**定义 334（语义合规分 SCV 与合规门）** 对给定解释 ι，
`C(ℓ,ι) = P_{ξ~π_θ(·|o,ℓ,ι)}[ ξ ⊨ IC(ℓ,ι) ]`（用 K 个样本 + 能量/似然估计）。
合规门：`C ≥ 1−α_c` 才允许执行；否则视为该解释不可执行。对已执行/候选动作 ξ，定义违约严重度 `sev(ξ) = max_{I∈I_safe} max_t (I(ξ_t))₊`（归一化）。

**定义 335（语义 Lipschitz 与语言支撑包络 LSE）** 在语言包络内（A109：策略对语言嵌入 L_ℓ-Lipschitz、对场景 L_z-Lipschitz），
`W₂(π(·|o,ℓ₁), π(·|o,ℓ₂)) ≤ L_ℓ‖e(ℓ₁)−e(ℓ₂)‖₂ + L_z d(o,o′)`。
语言支撑包络 `𝒱_lang(J) = { (c,ℓ) : dist(e(ℓ), E_train) ≤ δ_lang ∧ C(ℓ,ι*) ≥ 1−α_c ∧ 关键语素已接地 }`。证书只在 𝒱_lang 内可主张；超出不是「泛化稍差」，而是**指令证书失效**。

**定义 336（指令仲裁格 IAL）** 指令来源集合 S 带权威偏序 `≽_auth`（操作员 ≻ 监督员 ≻ 终端用户 ≻ 路人 ≻ 自生成子目标）。两条指令冲突（φ/ψ 不相容）时取 `ℓ* = max_{≽_auth} {ℓ : 不违反 I_safe}`。关键不对称：**安全不变量向上封闭**——任意来源可对任意指令施加否决 `I_safe ⊨ ¬compatible(ℓ)`，但**没有任何来源**能授权违反 I_safe 的指令。仲裁结果带滞回与最短驻留，避免指令抖动。

**定义 337（指令权威与能力 IAC）** 每个来源 s 绑定能力集 `Cap(s)` 与会话证明 `att(s)`（签名/在场证明/角色令牌）。指令所需权限 `Auth_req(ℓ) ⊆ Cap(s)` 且 `att(s)` 有效，才进入仲裁；否则**拒绝**而非降级猜测。权限不足、跨场景重放、角色冒充均记入威胁日志。

**定义 338（语义澄清 SQM）** 候选澄清动作 g（来自 R69 的 g_ask，受定义 294 约束）以形式化歧义为目标生成（问的是「哪个杯」而不是泛泛「请再说一遍」）：
`VoI_lang(g) = H(ℐ|o,ℓ) − E_{y~p(·|g,o,ℓ)}[H(ℐ|o,ℓ,y)]`。
选 `g* = argmax_g [VoI_lang(g) − c(g)]`，s.t. 只能向**有权回答该歧义的来源**提问（不能向社会工程者求证），且单次回答不得单独定案（继承 R69 定义 293-iii，需与另一正交证据一致）。`VoI_lang ≤ c` 时**不猜、不问、拒绝或降级**。

**定义 339（双解析与语义监控 DPM）** 两个独立解析器：符号文法解析器 `P_sym`（组合语义、辖域/否定显式）与神经语义解析器 `P_neu`（鲁棒、覆盖广）。两路在关键字段（φ_goal、I_safe、否定辖域、数值参数、指称对象）上必须一致；不一致 ⇒ 该字段 UNKNOWN ⇒ 澄清或降级。DPM 自身带有效包络与事后校准：用人工复核/物理后果回灌其误一致率，超阈则冻结神经路、仅用符号路。

**定义 340（语义校准门 SMG）** 接地误接地率 β 与合规分 C 的估计器都需校准（可靠图、ECE）。`ECE_ground > τ_g` 或 `ECE_compliance > τ_c` ⇒ 禁用「自动解释 + 执行」快路径，改为「符号解析 + 人工确认 IC + 保守执行」；不可信的语言理解不得驱动物理动作（R69 MCG / R70 监控校准的语言镜像）。

**定义 341（指令生命周期与失效关闭）** 状态机：`RECEIVED → PARSED → GROUNDED | UNKNOWN → DISAMBIGUATED → ARBITRATED → COMPLIANCE_VERIFIED → EXECUTING → COMPLETED | ABORTED`。不变式：任意状态若其有效性前提失效（包络越界、监控告警、新指令冲突升级），立即 `→ ABORTED` 并按 R70 证书格下降到 `J_⊥`；执行中失效必须先进入安全态再退出。

**定义 342（指令溯源 IPA）** 每条指令生成哈希链
`κ(ℓ) = H( raw_input, IC(ℓ), {GC(u)}, w(ι), ι*, arbiter_chain, ξ_exec, C, J_LING )`，
逐跳签名、只追加。它回答四个审计问题：词如何变成谓词、歧义如何被消解、谁授权了执行、动作是否满足契约。链断/签名失效/时间戳回退 ⇒ 判定不可信并触发审计。

**定义 343（威胁模型 AIC-LING）** `ℰ_LING = ℰ_FIELD × ℰ_inject × ℰ_conflict × ℰ_scope × ℰ_ground × ℰ_drift × ℰ_replay_lang`：提示注入（数据里夹带指令）、多来源冲突/权威冒充、否定与量词辖域陷阱、接地对抗样本（同音/同形/诱饵指称）、语言分布漂移（新俚语/新本体词）、指令重放与跨场景复用。**语言注入被列为一等威胁**：它攻击的正是「文本 → 契约」这一步。

**定义 344（证书 J_LING）** `J_LING = (J_FIELD, H(IC), H({GC}), U^lang_epi_before/after, C_min, parser_agree, auth_chain, LSE_membership, IPA_root, lingua_ver)`。
`Valid ⇔ Valid(J_FIELD) ∧ 关键语素全接地 ∧ C ≥ 1−α_c ∧ 双解析关键字段一致 ∧ 权限有效 ∧ (c,ℓ) ∈ 𝒱_lang ∧ 无未仲裁冲突 ∧ IPA 完整`。

**定义 345（指令–证书对偶 / Galois 连接）** 把指令按「要求强度」偏序化：`ℓ ⊑ ℓ′` 当且仅当 ℓ′ 的执行蕴含 ℓ 的执行且要求更多前提。存在单调映射 `J(·)` 把指令送到证书格。于是 `ℓ ⊑ ℓ′ ⇔ Req(J(ℓ)) ⊆ Req(J(ℓ′))` 构成 Galois 连接：**「这句话要求了多少保证」可以被机械地查出来**，而不是靠人读。这也给出拒绝的规范理由：当 `Req(J(ℓ)) ⊄ H_t` 时，系统不是「不想做」，而是**当前世界没有资格兑现这句话**。

```python
def parse_instruction(text, scene, parsers):
    IC_sym = parsers.symbolic(text)              # 显式辖域/否定
    IC_neu = parsers.neural(text)                # 鲁棒覆盖
    IC, agree = merge_contracts(IC_sym, IC_neu)  # 分歧字段置 UNKNOWN
    for u in critical_constituents(IC):
        IC.G[u] = ground(u, scene)               # pred_u, envelope, beta, src
    IC.Amb = enumerate_ambiguity(IC)             # 词义/指称/辖域/语用
    return IC, agree

def ground(u, scene):
    pred = resolve_predicate(u, scene)           # 词 -> 可测谓词
    if pred is None or not pred.measurable(scene):
        return GroundingCert(u, pred=None, envelope=None, beta=1.0)
    return GroundingCert(u, pred, envelope=validity_of(pred, scene),
                         beta=misground_rate(u, scene), src=pred.src)

def decompose_language(policy, o, IC):

    w = interpretation_posterior(IC, o)          # 先验 x 解析似然

    return U_ale, U_epi, samples, w

# IP-281/282 SCV + LSE：合规门 + 语言支撑包络
def compliance_gate(policy, o, IC, iota):
    if not in_language_envelope(IC, iota, o): return 0.0, "OUT_OF_LSE"
    xi = policy.sample(o, IC, iota, K=8)
    C  = mean(satisfies(x, IC, iota) for x in xi)  # xi |= (phi, psi, I_safe)
    return C, ("OK" if C >= 1-ALPHA_C else "LOW_COMPLIANCE")

# IP-283/284 IAL + IAC：权威仲裁，安全只能否决不能授权
def arbitrate(instructions, scene, held_assumptions):
    valid = [l for l in instructions if authorized(l.source, l) and att_valid(l)]
    valid = [l for l in valid if not violates_safety(l, scene)]     # 安全否决
    if not valid: return None
    l_star = max(valid, key=lambda l: AUTHORITY[l.source])          # 权威优先
    if conflicting(valid) and AUTHORITY[l_star.source] < max_needed(valid):
        return None                                                 # 冲突未决
    return l_star

# IP-285 SQM：受限澄清（只问有权回答者，单次不定案）
def ask_to_disambiguate(IC, o, budget):
    best = None
    for g in formal_clarifications(IC.Amb):          # 针对具体歧义维度
        if not budget.allow(g) or not may_answer(g.target, IC): continue
        score = voi_lang(IC, g, o) - cost(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None  # 无利可图 -> 拒绝/降级

# IP-290 LINGUA-RAS 主闭环（包住 GROUND，不重写其内部）
def LINGUA_RAS_round(M, text, scene, hist):
    IC, agree = M.ilc.parse(text, scene, M.parsers)     # 1) 形式化 + 接地
    if M.icg.ungrounded(IC) or not M.dpm.critical_agree(agree):
        return M.ground.degrade(scene, hist, reason="SEMANTIC_UNKNOWN")  # 2) 不猜
    l_star = M.ial.arbitrate(M.pending, scene, M.amn.held_set(scene, hist))
    if l_star is None:
        return M.ground.degrade(scene, hist, reason="NO_AUTHORIZED_INTENT")
    U_ale, U_epi, samples, w = M.sad.decompose_language(M.lcfm, scene.o, IC)  # 3)
    if U_epi > TAU_LANG_EPI:
        g = M.sqm.ask_to_disambiguate(IC, scene.o, M.budget)
        if g is not None: IC, w = M.sqm.apply_answer(IC, g, M.cia.execute(g))
    iota = argmax_interpretation(w, IC)                 # 4) 选解释
    C, status = M.scv.compliance_gate(M.lcfm, scene.o, IC, iota)
    if status != "OK":
        return M.ground.degrade(scene, hist, reason=status)  # 5) 合规失败即降级
    out = M.ground.round(scene, hist, intent=IC, iota=iota)  # 6) 交给 GROUND/R69
    M.ipa.append(text, IC, w, iota, out.action, C, out.cert) # 7) 溯源 + 审计
    M.cert.issue(J_LING(M, IC, w, C, out.cert))
    return out
```

## 3. 推导

**引理 22（接地误差的传播上界）** 设关键语素集合 U，误接地率 `P(GC(u) 错) ≤ β_u`，合规估计误差 ≤ ε_est。若各语素接地错误独立，则「按形式化契约执行的动作违反真实意图」的概率
`P_mis ≤ 1 − ∏_{u∈U}(1−β_u) + ε_est`；正相关时用 copula 联合校准替换乘积项。要点：**下游验证再严格，也只能保证「相对契约正确」，无法把契约本身的错变对**；因此 β 必须显式进入风险裕量，而不是被合规分吸收。

**引理 23（语言 Lipschitz 下的组合性界）** 在 A109 下，对两条指令 ℓ₁,ℓ₂（如「放左」与「放右」、或加了「别」的版本），
`W₂(π(·|ℓ₁),π(·|ℓ₂)) ≤ L_ℓ‖e(ℓ₁)−e(ℓ₂)‖`。故若组合（否定/量词/连接）后的嵌入落在训练语言包络内，其行为改变有界；落在包络外，该界失效，证书作废。系：**组合性不是一个形容词，而是一个带 δ_lang 的局部性质**——在包络内可组合，出包络必须重新验证。

**引理 24（仲裁的单调安全性与终止性）** 定义可行指令集 `F = {ℓ : Auth_req ⊆ Cap(src) ∧ att 有效 ∧ 不违反 I_safe}`。安全不变量向上封闭 ⇒ `F` 对「降低要求」单调；权威只用于在 F 内挑极大元，故**任何仲裁结果都仍在 F 内**。冲突集的权威偏序有限且无环，取极大元必终止。系：安全否决使 `F` 永不包含危险指令，权威无法把 F 外的指令搬进 F。

**引理 25（双解析的误读压低）** 设单解析器关键字段错误率 δ_s，两路错误相关 ρ<1，且分歧必被检测。则漏检的语义误读率 ≤ `δ_s·ρ + P(两路同错且关键字段未覆盖)`。系：DPM 把「单模型自信地理解错」压低一个 ρ 量级；残余项由定义 340 的校准门与定义 332 的歧义集兜住——**不能检测的分歧，等于没有分歧**。

**定理 22（LINGUA 严格包含 GROUND / FLUID / R68）** 在 A109–A112（语言 Lipschitz、接地证书有效、双解析关键字段一致、仲裁安全否决成立）下，若 `(c,ℓ) ∈ 𝒱_lang`、关键语素全接地、`C ≥ 1−α_c`、来源有权，则 LINGUA 的执行与「以 IC(ℓ) 为目标运行 GROUND/R69」逐指令一致；若任一条件失败，则按 R70 证书格单调下降到 `J_⊥` 或拒绝，**不产生任何未经证书支持的新行为**。故 `Risk_LINGUA ≤ Risk_GROUND ≤ Risk_FLUID ≤ Risk_R68`（在各自有效包络内）。

**定理 23（语义失效关闭 / 无未接地执行）** 若系统满足定义 329 的三不变式，则任意执行序列中不存在「关键语素未接地、或双解析关键字段分歧、或合规分未达标、或权限无效」却被执行的动作；即 `Pr(未接地执行)=0`。**注意这是相对 IC 而言的**——它保证「不带着已知的未知去执行」，不保证「IC 忠实于真实意图」（见第 6 节）。

**定理 24（澄清提问的净收益与权威不可提升）** SQM 仅在 `VoI_lang(g*) > c(g*)` 时提问，且只向有权来源提问、单次回答不单独定案。故提问带来的期望解释熵下降 ≥ `VoI_lang − c > 0`，且提问动作不改变任何来源的权限（`Cap` 与 `att` 只读），即**提问不能成为提权通道**；提问失败/超时/被投毒时 `U^lang_epi` 保持，走定理 22 的降级。

**定理 25（指令溯源的不可抵赖性）** 在哈希链抗碰撞、签名不可伪造、时间戳单调的假设下，IPA 能唯一重建「原始输入 → IC → 接地 → 解释 → 仲裁 → 动作 → 证书」的因果链；任何对任一环节的篡改都会使链校验失败。故审计可回答「错误发生在翻译、接地、消歧、仲裁还是执行」，把责任定位从「模型整体不行」细化到**具体失效环节**。

## 6. 本轮最大风险

**一句话**：LINGUA-RAS 的全部保证最终都押在 `𝒢`（自然语言语素 → 可测谓词）这张**接地映射**上——如果它把「往左一点，别碰那个」错译成 φ，那么下游越严格的接地、合规与双解析验证，反而越是在**为错误的意思背书**；系统会对一个它根本没理解对的意图开出一张完美合规的证书——**验证的是翻译，不是意思**。

**次级风险与缓解**：
1. **歧义枚举不完备**（没列进 Amb 的解释永远无法被消解）→ 开放维度 + 人类研究 + 不可枚举即保守降级；
2. **双解析共享偏差**（同一训练数据/本体导致一起错）→ 独立语料与符号锚 + 分歧必报 + 定义 339 事后校准；
3. **权威模型被社会工程绕过** → 会话证明 + 能力集 + 「安全只能否决不能授权」的格不对称（定理 24）；
4. **澄清疲劳 / 过度提问** → VoI−成本门 + 交互预算 + E324 的过度提问上界；
5. **语言漂移出包络** → LSE 检出 + 重新认证 + 退回纯符号解析（定义 340）；
6. **过度拒绝导致不可用** → 退化到底层而非一律停机 + 人机研究 + E330 的过度拒绝预算。

**定义 329（总览与三不变式）** LINGUA-RAS 全栈；零学习写操作继承；**无未接地执行**；**语义失效关闭**（解析失败/双解析分歧/超包络/无权 → UNKNOWN → 按 R70 格降到 `J_⊥`）。

**定义 330–331（指令契约与接地证书）** `IC(ℓ)` 是带洞契约，未定字段进 Amb 而非默认填值；`GC(u)=(pred,𝒱,β,src,t)`，已接地 ⇔ `c∈𝒱 ∧ β≤β_max ∧ pred 可实时求值`。

**定义 332–333（语义歧义分解与 LCFM）** 四维歧义 → 解释集与后验；`U^lang_ale=Σw·trΣ`，`U^lang_epi=H(ℐ)`；`v_θ(x_s,s|o,e(ℓ),ι)` 复用 R69 trunk，文本编码冻结。

**定义 334–335（语义合规与语言包络）** `C=P[ξ⊨(φ,ψ,I_safe)]`，`C≥1−α_c` 才执行；语义 Lipschitz `W₂≤L_ℓ‖Δe‖+L_z d`；`𝒱_lang` 外证书失效。

**定义 336–337（仲裁格与权威能力）** 冲突取权威极大元，但安全不变量向上封闭：任何来源可否决、无人可授权违反安全；`Auth_req⊆Cap ∧ att 有效` 才进入仲裁，否则拒绝。

**定义 338（语义澄清）** `g*=argmax[VoI_lang−c]`，只问有权来源，单次回答不定案；无利可图则不猜不问、拒绝或降级。

**定义 339–340（双解析与语义校准门）** 符号/神经两路关键字段须一致，分歧即 UNKNOWN；DPM 自身带包络与事后校准；接地/合规估计器 ECE 越界则退化为「符号解析 + 人工确认」。

**定义 341–342（生命周期与溯源）** 状态机任一步前提失效即 ABORT 并按 R70 格下降；`κ(ℓ)` 哈希链记录词→谓词→解释→仲裁→动作→证书，支持环节级责任定位。

**定义 343–345（威胁/证书/对偶）** `ℰ_LING` 含注入、冲突、辖域陷阱、接地对抗、语言漂移、指令重放；`J_LING` 并入 IC/接地哈希、解释熵、合规分、解析一致、权限链、LSE、IPA；`ℓ⊑ℓ′ ⇔ Req(J(ℓ))⊆Req(J(ℓ′))` 给出「这句话要求多少保证」的机械查询。

## 3. 关键算法伪代码

```python
# IP-277/278 ILC + ICG：带洞契约 + 语素接地证书（分歧字段置 UNKNOWN）
def parse_instruction(text, scene, parsers):
    IC, agree = merge_contracts(parsers.symbolic(text), parsers.neural(text))
    for u in critical_constituents(IC):
        pred = resolve_predicate(u, scene)
        IC.G[u] = (GroundingCert(u, pred, validity_of(pred, scene),
                                 misground_rate(u, scene), pred.src)
                   if pred and pred.measurable(scene)
                   else GroundingCert(u, None, None, 1.0, "none"))
    IC.Amb = enumerate_ambiguity(IC)          # 词汇/指称/辖域/语用
    return IC, agree

# IP-279/280 SAD + LCFM：歧义在动作空间中被采样、聚类
def decompose_language(policy, o, IC):
    samples = {i: policy.sample(o, IC, i, K=K_i) for i in IC.Amb}
    w = interpretation_posterior(IC, o)
    return (sum(w[i]*trace(cov(samples[i])) for i in samples),  # U_lang_ale
            entropy(w), samples, w)                             # U_lang_epi

# IP-281/282 SCV + LSE：合规门 + 语言支撑包络
def compliance_gate(policy, o, IC, iota):
    if not in_language_envelope(IC, iota, o): return 0.0, "OUT_OF_LSE"
    xi = policy.sample(o, IC, iota, K=8)
    C  = mean(satisfies(x, IC, iota) for x in xi)
    return C, ("OK" if C >= 1-ALPHA_C else "LOW_COMPLIANCE")

# IP-283/284 IAL + IAC：安全只能否决，权威不能授权
def arbitrate(instructions, scene):
    valid = [l for l in instructions
             if authorized(l.source, l) and att_valid(l) and not violates_safety(l, scene)]
    if not valid: return None
    l_star = max(valid, key=lambda l: AUTHORITY[l.source])
    return None if (conflicting(valid) and AUTHORITY[l_star.source] < max_needed(valid)) else l_star

# IP-285 SQM：受限澄清（只问有权来源，单次不定案）
def ask_to_disambiguate(IC, o, budget):
    cands = [(g, voi_lang(IC, g, o) - cost(g)) for g in formal_clarifications(IC.Amb)
             if budget.allow(g) and may_answer(g.target, IC)]
    best = max(cands, key=lambda t: t[1], default=None)
    return best[0] if best and best[1] > 0 else None   # 无利可图 -> 拒绝/降级

# IP-290 LINGUA-RAS 主闭环（包住 GROUND，不重写其内部）
def LINGUA_RAS_round(M, text, scene, hist):
    IC, agree = M.ilc.parse(text, scene, M.parsers)            # 1) 契约 + 接地
    if M.icg.ungrounded(IC) or not M.dpm.critical_agree(agree):
        return M.ground.degrade(scene, hist, reason="SEMANTIC_UNKNOWN")  # 2) 不猜
    if M.ial.arbitrate(M.pending, scene) is None:
        return M.ground.degrade(scene, hist, reason="NO_AUTHORIZED_INTENT")
    U_ale, U_epi, samples, w = M.sad.decompose_language(M.lcfm, scene.o, IC)  # 3)
    if U_epi > TAU_LANG_EPI:
        g = M.sqm.ask_to_disambiguate(IC, scene.o, M.budget)
        if g: IC, w = M.sqm.apply_answer(IC, g, M.cia.execute(g))
    iota = argmax_interpretation(w, IC)                        # 4) 选解释
    C, status = M.scv.compliance_gate(M.lcfm, scene.o, IC, iota)
    if status != "OK":
        return M.ground.degrade(scene, hist, reason=status)    # 5) 合规失败即降级
    out = M.ground.round(scene, hist, intent=IC, iota=iota)    # 6) 交 GROUND/R69
    M.ipa.append(text, IC, w, iota, out.action, C, out.cert)   # 7) 溯源 + 审计
    M.cert.issue(J_LING(M, IC, w, C, out.cert))
    return out
```

## 4. 推导

**引理 22（接地误差传播界）** 关键语素 U，误接地率 `P(错)≤β_u`，合规估计误差 ≤ ε_est，则 `P_mis ≤ 1−∏_{u∈U}(1−β_u)+ε_est`（相关时用 copula 联合校准）。下游验证只能保证「相对契约正确」，无法把契约本身的错变对；β 必须显式进入风险裕量。

**引理 23（语言 Lipschitz 组合性界）** A109 下 `W₂(π(·|ℓ₁),π(·|ℓ₂)) ≤ L_ℓ‖e(ℓ₁)−e(ℓ₂)‖`；组合（否定/量词/连接）在语言包络内行为改变有界，出包络则界失效、证书作废。组合性是带 δ_lang 的局部性质，不是全局形容词。

**引理 24（仲裁单调安全与终止性）** 可行集 `F={ℓ: Auth_req⊆Cap ∧ att 有效 ∧ 不违反 I_safe}`；安全不变量向上封闭 ⇒ F 对降低要求单调，权威仅在 F 内取极大元，故仲裁结果恒在 F 内；权威偏序有限无环 ⇒ 终止。

**引理 25（双解析误读压低）** 单解析器关键字段错误率 δ_s、两路相关 ρ<1 且分歧必检，则漏检误读 ≤ `δ_s·ρ + P(两路同错且关键字段未覆盖)`；DPM 把「自信地理解错」压低一个 ρ 量级，残余项由 SMG 与 Amb 兜住。

**定理 22（LINGUA 严格包含 GROUND/FLUID/R68）** A109–A112 下，若 `(c,ℓ)∈𝒱_lang`、全接地、`C≥1−α_c`、来源有权，则执行与「以 IC 为目标运行 GROUND/R69」逐指令一致；否则按 R70 格单调降到 `J_⊥` 或拒绝，不产生未经证书支持的新行为。故 `Risk_LINGUA ≤ Risk_GROUND ≤ Risk_FLUID ≤ Risk_R68`（各自包络内）。

**定理 23（语义失效关闭 / 无未接地执行）** 满足定义 329 三不变式时，不存在「未接地 / 解析分歧 / 合规不足 / 无权」却被执行的动作，`Pr(未接地执行)=0`。这是**相对 IC** 的保证：不等于 IC 忠实于真实意图（见第 7 节）。

**定理 24（澄清净收益与权威不可提升）** `VoI_lang>c` 才问、只问有权来源、单次不定案 ⇒ 期望解释熵下降 ≥ `VoI_lang−c>0`，且 `Cap/att` 只读 ⇒ 提问不是提权通道；失败/超时/投毒则 `U^lang_epi` 保持并走降级。

**定理 25（溯源不可抵赖性）** 抗碰撞哈希 + 不可伪造签名 + 单调时间戳下，IPA 唯一重建「输入→IC→接地→解释→仲裁→动作→证书」链；任一环节篡改使校验失败，从而把责任定位细化到具体失效环节。

## 7. 本轮最大风险

**一句话**：LINGUA-RAS 的全部保证最终都押在 `𝒢`（自然语言语素 → 可测谓词）这张**接地映射**上——如果它把「往左一点，别碰那个」错译成 φ，那么下游越严格的接地、合规与双解析验证，反而越是在**为错误的意思背书**；系统会对一个它根本没理解对的意图开出一张完美合规的证书——**验证的是翻译，不是意思**。

**次级风险与缓解**：歧义枚举不完备（开放维度 + 不可枚举即保守降级）；双解析共享偏差（独立语料/符号锚 + 分歧必报 + 事后校准）；权威模型被社会工程绕过（会话证明 + 能力集 + 安全否决不可授权，定理 24）；澄清疲劳（VoI−成本门 + 预算 + E324）；语言漂移出包络（LSE + 重认证 + 退符号解析）；过度拒绝（退化到底层而非停机 + E330）。
