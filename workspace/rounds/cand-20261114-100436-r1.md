# 第 73 轮（承接第 72 轮「EMBODIED-GAUGE-RAS」IP-287~294；灵感循环第 1 轮；本轮灵感：「模仿学习」×「续航能力」）

> R72 把 GAUGE 从「认知层算法」下沉为**具身实时闭环**：REG 调度契约使「计量不阻塞控制」成为时序定理，IRL 把意图 z 纳入联合后验并进入风险分母，DMEM 把灵巧手证据升级为带接触模式 c 的计量证据，EREFLEX/ERVOI 合算三层反作用预算，S2R-UQ 把仿真参数不确定度传播进 WCET 与 λ_floor。但 R72 仍有两个**未审计的"上游"**：
>
> - **模仿学习视角（策略来源链未审计）**：R72 把控制器 `M.ach.propose_ctrl` 当成给定算子，只审计**观测 y**，不审计**策略 π**。真机上 π 几乎总来自示教（行为克隆 / 扩散策略 / VLA）。示教数据是一个**计量对象**：谁示范（人/专家/脚本）、什么本体、什么传感与能量条件、什么意图、覆盖哪些状态——它测量的不是"世界状态"，而是"在**示范者本体**下如何完成任务"。把它迁到机器人上，是一次**换本体的规范变换**，与 sim2real 同构但**残差结构不同**（D2R：Demonstration-to-Robot）。更致命的是行为克隆的**协变量偏移/复合误差**、**因果混淆**（网络抓住背景、遮挡、时长等伪相关）、**动作分布未校准**——这些风险在 R72 的 `R_state` 风险分解里**根本不存在**，却可能主导真实风险。
> - **续航能力视角（审计自身有成本、且会污染审计）**：R72 隐含假设「计量审计免费、且永远能以声明频率运行」。但每个 REG 节点、每次证书组装、每个 AURA/DMEM 推理都在**耗电**。低电量下：时钟降频影响控制 WCET、电压基准漂移使 ADC 全通道偏移、热节流使推理抖动、电池内阻上升使力矩指令电压跌落——这是**同时污染所有模态的共模不确定度**，直接使 R72「独立误差按平方和聚合」的风险界**偏乐观（underestimate）**。更尖锐的是：**电量越低越需要审计，但系统越有动机降载省电**——降载若静默进行，就等于**静默吊销证书**。
>
> 两个灵感相乘，得到本轮真正的核心矛盾——**双尾（double tail）**：
> **低电量区间既是安全关键区（安全余量最小、失效代价最高），又恰恰是示教覆盖最稀疏区（人几乎从不演示"电量 5% / 热节流 / 电压跌落时怎么办"），同时还是审计最想被裁掉区。** 这是「电池的尾部 ∩ 示教的尾部 ∩ 审计的尾部」三重叠加。R72 的证书在这里既不完整（策略没进证书），也不诚实（降载不记账），更不稳健（共模被当独立）。
>
> 核心命题：**不再只问「我的测量链在具身执行中还守得住风险界吗」，而问「当我的策略来自示教、我的电量在耗尽、我的审计本身在耗电并污染审计时，我还能给出一个**诚实**的风险界吗——即声明的界永远是真实风险的上界，且每一次为省电而放宽的界都被显式记录、可复算、可追溯？」** 把 R72 的具身证书升级为 **LIFE-GAUGE-RAS**（**L**earned-policy provenance · **I**mitation validity · **F**inite-energy endurance · **E**nergy–epistemic co-scheduling GAUGE for RAS）——**能量诚实的具身计量审计闭环**。

## 0. 直觉与动机

**灵感 1（模仿学习 → 策略是"被测量出来的"，来源链必须进证书）**
直觉：若策略 π 由示教 D 训练而来，那么「π 在状态 s 会做什么」这件事的可信度，取决于 D 是否覆盖 s、是否因果、示范者是否胜任、以及示范者本体与机器人本体的差距。R72 的 `b_t(s,z)` 只对**世界**不确定，对**策略**是完全自信的——这是一个**未建模的确定性假设**。把 π 当成"又一个传感器"来看：它有**量程（覆盖 C_D）**、有**偏置（示范者次优/习惯）**、有**共模误差（示范者本体的运动学/能量画像）**、有**校准误差（动作分布 ECE_π）**、有**伪相关（因果混淆）**。**「观测可信」不等于「策略可信」；策略也需要自己的计量链。**

**灵感 2（换本体 = 规范变换 → D2R 残差）**
直觉：示教是在**示范者本体**（人手/遥操作臂/另一台机器人）里做的；部署是在**机器人本体**里。这就是一次**规范变换**：同一个任务，不同执行器、不同动力学、不同能量效率。S2R-UQ 处理的是"仿真→实机"，D2R-UQ 处理的是"示范者→机器人"。二者都写作 `θ_robot = φ(θ_source) + Δ`，但**Δ_D 的来源不同**：S2R 残差来自建模误差/域随机化不足；D2R 残差来自**本体差异 + 示范者次优 + 示教噪声**。尤其**能量画像**：人示范的动作可能能耗极高（快速、大加速度），BC 学到后机器人在低电量下会更早耗尽——**示范者不承担机器人的续航后果**。

**灵感 3（续航 → 能量既是资源、又是测量、还是共模污染源）**
直觉：电池不是一个"剩余百分比"，而是一条**带不确定度的测量链**：库仑计数有累积偏置、OCV 曲线随温度/老化漂移、SoH 未知、内阻随温度上升。于是 **SoC 本身需要 GAUGE 审计**。更关键，能量状态**耦合进所有别的证据**：电压基准漂移使视觉/触觉 ADC 同向偏；降频使控制抖动、计量丢帧；热节流使推理延迟分布改变。这些不是独立噪声，而是**共模**——R72 的 `√(u₁²+u₂²+...)` 聚合在此**系统性低估**，必须改成"独立项平方和 ⊕ 共模项线性相加"。**能量不是背景，能量是所有人都共享的那一份误差。**

**灵感 4（能量价格 → 续航必须被"定价"进 VoI 与风险）**
直觉：一次澄清交互（ERVOI 的 g）能带来信息增益，但会耗电、缩短续航、抬高温升。R72 的 VoI 只减反作用成本，不减**能量成本**。必须引入能量的**影子价格 λ_E(t)**：电量越低、剩余任务越重、安全停靠所需储备越大，λ_E 越高。于是 `VoI^L = 信息增益 − 反作用成本 − λ_E·能量成本 − 远期损失`。**"要不要问/要不要动/要不要审计"三个决策，统一被同一个能量价格裁决。**

**灵感 5（可审计降载 → 省电可以，静默不行）**
直觉：低电量时降载是**正确且必要**的——但降载会让某些指标失效、证书变弱。问题不在"降载"，而在"**静默**降载"：系统一边跑着，一边悄悄把计量频率从 50Hz 降到 5Hz，却仍然对外宣称"证书有效"。必须把降载变成**有账可查**的行为：每降一格，写一条**降级记录**（节点、旧风险界、新风险界、省了多少电、原因、时间、签名），且台账满足**单调性**（界只增不减）。**省电是被允许的，撒谎不被允许。** 这就是"诚实证书"。

**灵感 6（双尾 → 三重重叠的失效区）**
直觉：把三件事画在同一个 SoC 轴上：①**关键性**（安全余量、失效代价）随 SoC↓ 而↑；②**示教覆盖** κ_D 随 SoC↓ 而↓（人没演示过极限低电）；③**审计强度**随 SoC↓ 而↓（省电降载）。三个箭头在低 SoC 端**同时朝最坏方向**。再叠加对抗：攻击者只需把机器人**逼到低电量 + OOD 状态**，就能同时让 H[b_t(z)]、u_tac、ι_π 变大而审计被裁掉——这是**用能量把系统"合法地"逼进盲区**。因此安全设计的目标不是"消灭双尾"（可证不可消灭），而是"**在双尾区也诚实**"。

## 1. 形式化定义（增量：定义 366–382）

**定义 366（LIFE-GAUGE-RAS 总览）** LIFE-GAUGE-RAS = (PIV, D2R, EBD, CMU, E-VOI, E²-RISK, E-SHED, GAUGE-RAS‡)。六不变式：
(i) **策略来源完整性**：任何部署策略 π 必携带 `(D, τ_D, κ_D, ι_π, ECE_π, Σ_ΔD, D_π)`（示范集、追溯链、覆盖、因果不变性间隙、动作校准、D2R 残差、有效域）；缺一不得部署；
(ii) **能量可核算**：每个 REG 节点/边带能量成本 `c_E`；每个控制周期能量被记账；SoC/SoH/热状态估计携带 `(θ_E, u_E, τ_E)`，能量计量链本身可审计；
(iii) **共模诚实聚合**：能量诱导的共模不确定度 `u_common` 为**跨模态相关**误差，任何风险界必须用**线性聚合算子 ⊕_c**（独立项平方和 ⊕ 共模项线性相加），禁止对共模项用平方和；
(iv) **可审计降载**：任何降低计量频率/关停节点的行为，必须写入**降级台账 L_shed** 且声明风险界**单调不降**；**静默降载视为证书伪造**；
(v) **诚实证书**：J_LIFE 有效 ⇔ 声明的风险界是真实风险（含搁浅风险）的上界，且所有降载可复算；**"界更宽"被允许，"界撒谎"被禁止**；
(vi) **严格逐指令退化链**：PIV 失效 ⇒ 部署**非学习的安全回退策略** + R72；D2R 失效 ⇒ 收窄有效域 + R72；EBD 失效 ⇒ 最坏电量假设 + R72；E-SHED 触底 ⇒ R68。**新层只在"策略可溯源、能量可核算、共模已计入"时启用。**

**定义 367（政策来源链 PIV）** 策略 π 可部署当且仅当六元组齐全且过阈：
- **来源**：`D = {(o_i, a_i, ctx_i)}_{i=1..N}`，含示范者身份/胜任证书、本体、传感器、时间、能量画像；
- **覆盖**：`κ_D: 𝒮×𝒵×ℰ → [0,1]` 为示教分布在任务相关（状态×意图×能量）空间上的支持估计；
- **因果不变性间隙**：`ι_π = sup_{I∈ℐ} | R_obs(π) − R_do(I)(π) |`，ℐ 为干预集（背景/光照/遮挡/本体替换/能量档位）；ι_π 大 ⇒ 策略依赖伪相关；
- **动作校准**：`ECE_π` 与保形预测集覆盖率；
- **D2R 残差**：见定义 369；
- **有效域**：`D_π ⊆ 𝒮×𝒵×ℰ`，域外即策略 OOD。
**判定**：`PIV_valid ⇔ 来源完整 ∧ κ_D 在可达关键集上达标 ∧ ι_π ≤ τ_ι ∧ ECE_π ≤ τ_ECE ∧ Σ_ΔD 有界`。

**定义 368（示范数据集作为计量对象）** 示教不是"真值轨迹"，而是一次测量：
`D ~ p_D(a | s, ctx; θ_demo, embodiment_demo, E_demo)`，
其中 `θ_demo` 为示范者策略、`embodiment_demo` 为本体、`E_demo` 为示范时能量画像。**同一任务在不同本体/能量下的最优动作不同**，故 D 测量的是"示范者条件下如何做"，其**可比性**由规范变换（定义 369）桥接。D 的每个片段携带追溯链 `τ_D`（来源、时间、同步质量、标定版本），**示教投毒/冒充/剪辑**均在威胁模型定义 379 内。

**定义 369（D2R-UQ：示范-机器人不确定度桥接）** 示范参数与机器人参数满足
`θ_robot = φ(θ_demo) + Δ_D,  Δ_D ~ 𝒩(0, Σ_ΔD)`，
`Σ_ΔD` 由**少量共执行标定集**（机器人复现示范片段，比对状态/力/能耗）贝叶斯估计。**所有由示教学得的控制律、阻抗增益、动作分块长度、能量画像，进入 REG 前必须携带 `(θ_robot, u_demo, u_robot, Σ_ΔD, τ_D2R)`**；`u_robot` 的 99.9% 分位进入 λ_floor，且 `WCET(θ_robot) ≤ WCET(θ_nom) + L_T·u_robot` 进入 REG 静态验证（与定义 357 的 S2R 并列）。

**定义 370（因果混淆与政策不变性）** 设策略输入含**因果特征** `x_c` 与**伪相关特征** `x_s`（背景、遮挡、示范者手形、恒定节拍）。因果混淆度
`χ_π = I_π(a; x_s | x_c)`（条件互信息）。
**在线代理**：干预探针（短暂改变背景/光照/遮挡）下动作分布漂移 `d_π = D_KL(π(·|s) ‖ π(·|s_{do(I)}))`；`ι_π ≥ f(d_π)`。**χ_π 越高，越不允许在高风险状态下以高置信执行**（进入 E-IVG 的额外否决项）。

**定义 371（能量计量链 EBD）** 能量状态 `E = (SoC, SoH, T, V_ref)`，后验 `b_t(E)`，由库仑计数 + OCV + 热模型融合：
`SoC_{t+1} = SoC_t − η(T)∫ I dt / Q(SoH) + w_t`，
`u_E² = u_coulomb² + u_OCV²(T) + u_aging²(SoH) + u_thermal²`。
**能量成本映射** `c_E: N∪E_REG → ℝ⁺`（每周期算力/传感/通信/驱动）。**能量储备约束**：剩余能量 ≥ `m_E`（最坏情况安全停靠所需），否则触发搁浅否决（定义 374）。**SoC 估计的偏置/漂移本身受审计**（能量计量链的 GAUGE）。

**定义 372（能量-认知共模不确定度 CMU）** 低电量/热节流诱导的误差同时进入所有模态：
`e_i = u_i·ζ_i + u_common(E)·ζ_0 + b_i(E)`，其中 `ζ_0` 为**共享**标准正态源。于是
`Var(Σe_i) = Σu_i² + (Σu_common)²`，
故**诚实上界**为
`U_total = ( ⊕_c u_i ) + u_common = √(Σu_i²) + u_common`，**绝不可**写成 `√(Σu_i² + u_common²)`。
`u_common(E) = g(1/SoC, T−T_ref, throttle, V_ref drift)` 单调于这些量。**这是 R72 独立误差假设在高负载/低电量下的直接反例。**

**定义 373（能量价格与能量感知 VoI：E-VOI）** 能量影子价格
`λ_E(t) = ∂V*/∂E |_{E_t}`（Bellman 价值对剩余能量的导数），性质：`λ_E` 随 SoC↓、剩余任务需求↑、储备缺口↑ 而单调↑，且 `λ_E ≥ λ_E^min > 0`。
`VoI^L(g) = c(ψ)·IG_s + η_z·IG_z + η_π·IG_π − c_reflex^ψ − c_reflex^z − c_reflex^c − λ_E·c_E(g) − γ·E[Δloss_future | E_{t+1}]`。
**选择 `g* = argmax VoI^L s.t. 三层稳态 ∧ 能量储备 ∧ PIV 有效域`；`max VoI^L ≤ 0` ⇒ 停止并回退。** `IG_π` 为**政策信息增益**（新信息对 κ_D/ι_π/ECE_π 的降低），`η_π` 由任务风险决定。

**定义 374（能量感知风险缩放 E²-RISK）** 物理/意图/接触之外，把**能量不确定度**与**共模**同权纳入，并叠加**搁浅否决**：
`λ = max( risk_scale(U_ale, U_epi, H[b_t(z)], u_tac ⊕_c u_E ⊕_c u_common),
          λ_floor(U_ale + U_epi + H[b_t(z)] + u_tac.total() + u_E + u_common) )`。
**任务级风险**：`R_mission = P_collision + P_strand`，其中 `P_strand = P(E_{t+T_task} < m_E)`。**若 `P_strand > τ_strand` 触发非补偿性搁浅否决**（与 R72 安全否决同级：不可被"完成概率高"补偿）⇒ 立即进入回充/停靠/降级。

**定义 375（可审计降载 E-SHED 与降级台账）** 降载动作集合 `{ρ_j}`（降低某计量域频率/关停某感知节点/缩小证书字段）。每个动作 `ρ` 有 `(Δc_E, ΔB)`：省下的能量与被放宽的风险界增量。**排序键 = ΔB / Δc_E（每瓦放宽多少安全界）**，优先降 "性价比" 最差者。每执行一步，向**降级台账 L_shed** 追加一条不可篡改记录：
`(node, old_bound, new_bound, Δc_E, reason, t, sig)`。
**不变量**：沿台账，声明风险界 `B_declared` 单调不降；任何控制/规划决策使用的 `λ_floor` 基于 `B_declared` 而非旧界。**静默降载（B 变了但无台账）⇒ 证书无效。**

**定义 376（双尾覆盖-关键性失配）** 定义失配度
`M_tail = ∫ w(s,z,E)·(1 − κ_D(s,z,E))·p_t(E) d(s,z,E)`，
其中关键性 `w` 随 SoC↓、任务余量↓ 单调↑，覆盖 `κ_D` 通常随 SoC↓ 单调↓（示教稀少）。**双尾区 = `argmax` 同时具有高 `w`、低 `κ_D`、低审计强度。** 在线监控 `M_tail`；超阈即禁止进入该区（除非主动补示教，定义 382）。

**定义 377（能量归一化模仿评价）** 不以裸成功率评价 π，而用
`R_E(π) = E[success] / E[energy]` 与**续航约束成功率** `P(success | SoC_0, T_task, task)`。
示范者的能量画像 `E_demo` 是来源链的一部分；**若示范本身能量浪费，朴素 BC 会继承浪费**——因此需要**能量条件化策略** `π(a|s,z,E)` 与**能量分层示教**（在低能量档也采集示范）。

**定义 378（LIFE 证书 J_LIFE）** `J_LIFE = (J_EMB, piv_valid, d2r_hash, energy_ledger_hash, u_common_hash, shed_ledger, e_risk_bound, life_ver)`。
`Valid ⇔ Valid(J_EMB) ∧ PIV_valid ∧ D2R 链完整 ∧ 能量台账一致 ∧ B_declared ≥ 真实风险（含 P_strand，按 ⊕_c 保守聚合）∧ 无静默降载`。
**关键语义**：`Valid` 不声称"风险很小"，只声称"**声明的界是真的上界**"。允许"界很宽但仍诚实"。

**定义 379（威胁模型 AIC-LIFE）** `ℰ_LIFE = ℰ_EMB × ℰ_piv × ℰ_energy`：
- `ℰ_piv = {示教投毒、示范者冒充、伪相关利用（只在特定背景触发）、覆盖空洞定向（只在低电量状态攻击）、D2R 残差投毒、剪辑/回放攻击}`；
- `ℰ_energy = {SoC 谎报（虚报高电量）、热攻击（强制节流诱导抖动）、能量成本低报、台账篡改、电池老化扩宽共模}`。
**最危险攻击 = 双尾定向**：把系统逼入 `低电量 × OOD 状态 × 审计降载` 的交点，使所有"独立性/覆盖"假设同时失效而每张单点证书都"当时有效"。

**定义 380（严格退化链 LIFE）** 逐指令等价：
- PIV 失效 ⇒ 切换到**非学习的安全回退策略**（保守脚本/解析控制），**绝不**部署未审计学习策略；
- D2R 失效 ⇒ 把 `D_π` 收窄至标定共执行覆盖区 + R72；
- EBD 失效（SoC 不可信）⇒ 假设最坏电量、立即保守能量策略 + R72；
- E-SHED 触底或搁浅否决 ⇒ R68 安全停靠；
- 全有效 ⇒ LIFE 完整形态。
**安全侧只增不减：任何退化都保留 R68 硬包络与 R72 λ_floor，且额外保留"诚实界"不变量。**

**定义 381（能量治理器与单向下行 veto）** 能量治理器 `Gov_E` 运行在计量域（可抢占、非最高优先级），持有能量预算/储备/λ_E，向控制域写**只读快照**。它到控制环只有一条**单向下行 veto 线**：只能**抬高 λ / 降低速度 / 触发降级**，**绝不允许抬高速度、解除任何安全否决、抢占控制周期**。**这让"省电"永远不能变成"更激进/更不安全"**，也不引入优先级反转（沿用引理 28/38）。

**定义 382（政策信息增益与主动示范请求）** `IG_π(g)` = 执行动作 g（如请求一次示范、提出一个澄清、切换能量档采集）后对 `κ_D, ι_π, ECE_π` 的期望降低。**主动示范请求**：当 `M_tail` 高且 `VoI^L(请求示范) > 0` 时，请求在**低能量档**补一次示教（人成本与机器人能量成本均入 VoI）。**这把"续航"从被动消耗变成主动学习资源分配**。

# IP-295 PIV：政策来源链审计（离线 + 在线轻量）
class PolicyProvenanceAuditor:
    def __init__(self, demo_store, calib_d2r, intervention_probe, conformal):
        self.D, self.d2r, self.probe, self.cp = demo_store, calib_d2r, intervention_probe, conformal
    def coverage(self, state, z, E):
        return self.D.kernel_density(state, z, E)          # κ_D
    def causal_gap(self, policy, s_batch):
        d = 0.0
        for I in self.probe.interventions():               # 背景/光照/遮挡/本体
            d = max(d, kl(policy(s_batch), policy(self.probe.do(I, s_batch))))
        return d                                           # 代理 ι_π

        return PIVCert(
            provenance_ok=self.D.chain_intact(),
            kappa=self.coverage, iota=self.causal_gap,

def e_voi(b_t, pi_cert, psi, z, c, budget, energy, fmp):
    lamE = energy.shadow_price()                           # ∂V*/∂E，≥ λ_E^min
    best = None
    for g in embodied_action_candidates(b_t, z, top_k=3):
        if not budget.allow(g) or not pi_cert.in_domain(g): continue
        if energy.reserve_violated(g): continue            # 储备约束

        cost = reflex_cost(psi,z,c,g) + lamE*energy.cost(g) + GAMMA*future_loss(g)
        score = info - cost

    return best if best and best.score > 0 else None

# IP-300 E²-RISK：能量感知风险缩放 + 搁浅否决（控制域 <0.05ms）

    denom  = U_ale + U_epi + H_z + u_tac.total() + uE_eff

                 params.lam_floor*(1+denom))

# IP-301 E-SHED：可审计降载（计量域，写降级台账）
class AuditableShedder:
    def __init__(self, registry, ledger):
        self.reg, self.ledger = registry, ledger
    def step(self, bE, risk_bound):
        if bE.SoC > SHED_SOC: return risk_bound
        cand = [(r, delta_energy(r), delta_bound(r, risk_bound)) for r in self.reg.sheddable()]
        cand.sort(key=lambda x: x[2]/max(x[1],1e-9))       # 每瓦放宽多少界
        for r, dE, dB in cand:
            if dE <= 0: continue
            self.reg.disable(r)
            self.ledger.append(node=r, old_bound=risk_bound,
                               new_bound=risk_bound+dB, dE=dE,
                               reason='low_soc', t=now(), sig=self.reg.key)
            risk_bound += dB
            break                                          # 一次只降一格，可回滚
        return risk_bound                                  # 单调不降

## 3. 推导

**引理 33（策略风险不可被观测审计归约）** 总风险可分解
`R_total ≤ R_state + R_policy + R_energy`（联合界）。
R72 的 J_EMB 只约束 `R_state`（与状态估计/意图/接触相关）；`R_policy` 由示教覆盖 κ_D、因果混淆 χ_π、协变量偏移、D2R 残差决定，在 R72 中**无界**。故存在策略使 `R_state→0` 而 `R_total` 任意大 ⇒ **PIV 是证书完备性的必要条件。** 系：**"观测都对" 挡不住 "策略会错"。**

**引理 34（共模误差使正交聚合失效）** 设 `e_i = u_i ζ_i + u_c ζ_0`，`ζ_i, ζ_0` 独立标准正态。则
`Var(Σ e_i) = Σu_i² + (n u_c)² > Σu_i² + n²u_c² / n`（当 n>1 时 `n²u_c² > n u_c²`）。
故平方和聚合 `√(Σu_i² + n u_c²)` **严格低估**真实标准差；诚实上界必须把共模项**线性相加** `√(Σu_i²) + n u_c`。系：**低电量/热节流下 R72 的独立误差界系统性偏乐观**，E²-RISK 必须用 ⊕_c。

**引理 35（可审计降载的单调台账存在性）** 设每个降载动作 `ρ` 的界增 `ΔB_ρ ≥ 0`、省能 `Δc_ρ > 0`。按 `ΔB/Δc` 升序执行，得 Pareto 前缀序列；每步 `B_declared` 单调不降，且对任意能量目标 `c*` 存在前缀使"省够电且界增量最小"。**证明**：贪心交换论证（与分数背包同构）。系：**降载可以不撒谎，且是最优的撒谎-free 策略。**

**引理 36（双尾不可避免性）** 若示教能量分布 `p_D(E)` 支撑在 `[E_min, E_max]` 且 `P_D(E ≤ ε) = 0`，而关键性 `w(E) ≥ w_0 > 0` 对 `E < ε` 成立，则对任意有限示教 `κ_D(E<ε) = 0` ⇒ `M_tail ≥ w_0 · P_t(E<ε) > 0`。**结论**：**任何非能量分层的示教都无法覆盖低电量区**；降低 `M_tail` 只能靠**能量分层示教**（定义 377/382）或**禁止进入该区**（拒止策略）。**不可通过更多"普通"示教消除。**

**引理 37（能量价格 VoI 的有限停止仍成立）** 在引理 31 条件下追加 `λ_E ≥ λ_E^min > 0` 且 `c_E(g) > 0`。每步边际净收益 ≤ 0 的判据更早到来，故停止集非空、有限。系：**续航约束只会让"何时停"更早，不会破坏可证明性。**

**引理 38（单向下行 veto 保实时且保安全）** Gov_E 运行于低优先级计量域，仅通过无锁快照与"只收紧"的 λ 下行走廊影响控制；不抢占、不回写、不等待（沿用 R72 定义 363/引理 28）。且由于它**只能抬高 λ / 触发降级**，绝不解除 R72/E-IVG 的安全否决，故 `λ_effective ≥ λ_R72`，安全单调不减、无优先级反转。**省电不能买到激进。**

**定理 27（LIFE 严格包含与诚实风险单调）** 在 A106–A110 及新增 A111–A114（PIV 六元组可测、D2R 残差有界、能量计量链可审计、共模项可用 ⊕_c 保守聚合）下：
(i) LIFE 在退化条件下逐指令等于 EMBODIED/R72/R68（定义 380）；
(ii) 能量充足且 PIV 有效时，`R_total(LIFE) ≤ R_total(EMBODIED)`（额外来源链与能量项只会收紧 λ）；
(iii) 能量受限时，`B_declared(LIFE) ≥ B_true(LIFE)`（诚实界），即使 `B_declared` 被降载放宽。**安全单调不减，"界更宽"与"界撒谎"被严格区分。**

**定理 28（诚实证书 ⇒ 无静默失效）** 若一次执行通过 J_LIFE，则 (i) 控制时序安全（J_EMB）；(ii) 策略在有效域内或已切回退（PIV/D2R）；(iii) 共模已线性计入（E²-RISK）；(iv) 任何降载都有台账且 `B_declared` 单调（E-SHED）；(v) `P_strand` 已被否决机制覆盖。故 **声明的风险界是真实风险（含搁浅）的上界**，且事后可从 `L_shed` 重建"当时哪些证书已失效、界被放宽了多少"。**"事后发现所有证书都有效却仍出事" 在 LIFE 中被排除——除非审计者根本不读台账。**

**定理 29（双尾只能被显式定价，不能被算法消除）** 由引理 36，任何不改变示教/任务分布的在线算法都有 `M_tail > 0`。故不存在保证双尾区安全的策略；可达到的最优是：把双尾残差 `M_tail` 与 `P_strand` 作为**显式下界**写入 `B_declared`，并**拒绝进入**不可覆盖的双尾（拒止）或**主动补示教**（定义 382）。**"消灭双尾"是不可能的，"诚实定价 + 拒止/补覆盖"是可行的。**

**定理 30（LIFE 在饱和能量下恢复 EMBODIED 且不多耗安全裕度）** 当 `SoC→高`、`u_common→0`、`λ_E→λ_E^min`、`P_strand→0`、PIV 有效时，E²-RISK → R72 E-RISK，E-VOI → RVOI/ERVOI（能量项趋零），E-SHED 不触发，退化链为空。**LIFE 是 EMBODIED 的严格泛化，不是替代。**

## 6. 本轮最大风险

**一句话**：LIFE-GAUGE-RAS 把安全从「相信具身证书」进一步转移到「相信 **能量计量链在低温/老化/大电流下仍然诚实**、相信 **示教覆盖与因果不变性在双尾区仍然有效**、相信 **降级台账真的被读**」——**如果 SoC 估计在低温+老化下系统性高估（库仑计数偏置 + OCV 曲线漂移），而策略在"低电量 × 未示范状态"的双尾区恰好最自信（因果混淆 + 共模低估使 λ 偏低），那么系统会以最节能、最流畅、最像专家的姿态，在续航耗尽的边缘无声越过安全边界；更隐蔽的是，E-SHED 会**诚实地**把风险界一格一格放宽并逐条记账，于是事后审计看到的是"所有证书都如实写着自己已经变弱、所有降载都有签名"——**风险没有被隐藏，而是被"合规地正常化"了**。这不是"自信地错"，而是**"诚实地把诚实的失效写成合规"（certificate inflation / normalization of deviance）**：证书永远不说谎，但界被放宽到失去意义，而人早已不再逐条读台账。**

**次级风险与缓解**：
1. **共模被低估 → 平方和偷偷回流** → 把 ⊕_c 写成**类型系统强制**：任何风险聚合只能调用 `correlated_bound()`，`quadrature_sum()` 对共模项编译期报错；E373 做红队回归。
2. **能量计量链漂移** → 在线自校准（已知放电段/静置段做 OCV 校正）+ **SoH 与温度分层**的分位数界；EBD 失效即最坏电量假设。
3. **示教因果混淆** → **因果探针 + 干预正则**训练；高风险状态下 ι_π 超阈即降低置信/回退非学习安全策略。
4. **双尾不可消除** → 显式 `M_tail` 入 `B_declared`；不可覆盖则**拒止进入**或**主动补能量分层示教**（定义 382）；禁止"用更多普通示教"自我安慰（引理 36）。
5. **降载台账被无视/篡改** → 台账链式哈希 + 硬件签名；**关键降载要求人工确认或自动回充**；E394/E385 常态化红队。
6. **能量治理器被攻击** → 单向下行 veto + 双通道一致性（电压/温度/放电曲线）+ Gov_E 与 RTM 交叉校验；攻击只能让系统更保守。
7. **复杂度/实时压力** → 沿用 |N|≤20 等模块上限；CMU/搁浅否决做成 O(1) 查表；证书组装异步（R72 的 E359）。

# IP-295 PIV：政策来源链审计
class PolicyProvenanceAuditor:
    def __init__(self, demo_store, calib_d2r, intervention_probe, conformal):
        self.D, self.d2r, self.probe, self.cp = demo_store, calib_d2r, intervention_probe, conformal
    def audit(self):
        iota = max(kl(self.policy(s), self.policy(self.probe.do(I, s)))
                   for I in self.probe.interventions() for s in self.probe.states)
        return PIVCert(provenance_ok=self.D.chain_intact(), kappa=self.D.coverage,
                       iota=iota, ece=self.cp.action_ece(), d2r=self.d2r.cert,
                       domain=self.D.reachable_support())

# IP-296 能量计量链
class EnergyGauge:
    def step(self, I, V, T, dt):
        self.ekf.predict(I, T, dt); self.ekf.update(V, T)
        bE, uE = self.ekf.posterior(), self.ekf.uncertainty()
        return bE, uE, self.ekf.trace()

# IP-297 共模诚实聚合
def honest_aggregate(u_list, bE):
    u_common = g_common(1.0/bE.SoC, bE.T - T_REF, bE.throttle, bE.vref_drift)
    return math.sqrt(sum(u*u for u in u_list)) + u_common   # ⊕_c

def d2r_bridge(theta_demo, u_demo, coexec_data):

# IP-299 E-VOI
def e_voi(b_t, piv, psi, z, c, budget, energy, fmp):
    lamE = energy.shadow_price()
    best = None
    for g in embodied_action_candidates(b_t, z, top_k=3):
        if not budget.allow(g) or not piv.in_domain(g) or energy.reserve_violated(g):
            continue
        info = credibility(psi)*IG_s(b_t,g) + ETA_Z*IG_z(z,g) + ETA_PI*IG_pi(piv,g)
        score = info - reflex_cost(psi,z,c,g) - lamE*energy.cost(g) - GAMMA*future_loss(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None

# IP-300 E²-RISK + 搁浅否决
def e2_risk_scale(U_ale, U_epi, H_z, u_tac, uE, u_common, params):
    denom = U_ale + U_epi + H_z + u_tac.total() + uE + u_common
    return max(params.lam_base*(1+denom/params.lam_scale),
               params.lam_floor*(1+denom))

def strand_veto(bE, demand, m_E):

## 4. 推导

**引理 33（策略风险不可被观测审计归约）** `R_total ≤ R_state + R_policy + R_energy`。J_EMB 只约束 `R_state`；`R_policy` 由 κ_D、χ_π、协变量偏移、D2R 决定，在 R72 中无界。存在 π 使 `R_state→0` 而 `R_total` 任意大 ⇒ PIV 是证书完备性的必要条件。系：**"观测都对" 挡不住 "策略会错"。**

**引理 34（共模使正交聚合失效）** 令 `e_i = u_i ζ_i + u_c ζ_0`，独立标准正态。`Var(Σe_i) = Σu_i² + (n u_c)²`；平方和聚合 `√(Σu_i² + n u_c²)` 少算 `(n²−n)u_c²`，严格低估（n>1）。诚实上界须共模线性相加 `√(Σu_i²) + n u_c`。系：**低电量/热节流下 R72 风险界系统性偏乐观。**

**引理 35（可审计降载的单调台账）** 每个降载动作 `(Δc_E>0, ΔB≥0)`；按 `ΔB/Δc_E` 升序执行得 Pareto 前缀，每步 `B_declared` 单调不降，且对任意节能目标存在"省够电且界增量最小"的前缀（贪心交换/分数背包）。系：**降载可以不撒谎且近似最优。**

**引理 36（双尾不可避免性）** 若 `p_D(E)` 支撑在 `[E_min,E_max]` 且 `P_D(E≤ε)=0`，而 `w(E)≥w_0>0` 于 `E<ε`，则 `κ_D(E<ε)=0` ⇒ `M_tail ≥ w_0·P_t(E<ε) > 0`。**任何非能量分层示教都覆盖不到低电量区**；只能靠能量分层示教（定义 377/382）或拒止。系：**"多采点普通示教"治不了双尾。**

**引理 37（能量价格 VoI 有限停止）** 在引理 31 条件上追加 `λ_E ≥ λ_E^min>0`、`c_E(g)>0`，则边际净收益 ≤0 更早出现，停止集非空有限。系：**续航只会让"何时停"更早，不破坏可证明性。**

**引理 38（单向下行 veto 保实时保安全）** Gov_E 低优先级、只读快照、不抢占不回写不等待（R72 定义 363/引理 28）；且只抬高 λ / 触发降级 ⇒ `λ_effective ≥ λ_R72`，不解除任何安全否决 ⇒ 安全单调、无优先级反转。**省电买不到激进。**

**定理 27（严格包含与诚实风险单调）** 在 A106–A110 与新增 A111–A114（PIV 可测、D2R 有界、能量链可审计、⊕_c 可保守聚合）下：(i) LIFE 逐指令退化为 EMBODIED/R72/R68；(ii) 能量充足且 PIV 有效时 `R_total(LIFE) ≤ R_total(EMBODIED)`；(iii) 能量受限时 `B_declared ≥ B_true`（诚实界），即便界被降载放宽。**"界更宽"与"界撒谎"被严格区分。**

**定理 28（诚实证书 ⇒ 无静默失效）** 若执行通过 J_LIFE，则控制时序安全（J_EMB）、策略在域内或已回退（PIV/D2R）、共模已线性计入（E²-RISK）、降载有台账且 `B_declared` 单调（E-SHED）、`P_strand` 被否决覆盖。故**声明界是真实风险（含搁浅）的上界**，且事后可由 `L_shed` 重建"何时哪些证书失效、界被放宽多少"。**"所有证书当时有效却仍出事"在 LIFE 中不可能——除非审计者根本不读台账。**

**定理 29（双尾只能显式定价，不能消除）** 由引理 36，任何不改示教/任务分布的在线算法都有 `M_tail>0`，故不存在保证双尾安全的策略。最优可达到：把 `M_tail` 与 `P_strand` 作为显式下界写入 `B_declared`，并**拒止进入**不可覆盖双尾或**主动补示教**。**"消灭双尾"不可能，"诚实定价 + 拒止/补覆盖"可行。**

**定理 30（饱和能量下恢复 EMBODIED）** 当 `SoC→高`、`u_common→0`、`λ_E→λ_E^min`、`P_strand→0`、PIV 有效时，E²-RISK→E-RISK、E-VOI→ERVOI（能量项→0）、E-SHED 不触发、退化链为空。**LIFE 是 EMBODIED 的严格泛化。**

## 7. 本轮最大风险

**一句话**：LIFE-GAUGE-RAS 把安全从「相信具身证书」进一步转移到「相信 **能量计量链在低温/老化/大电流下仍然诚实**、相信 **示教覆盖与因果不变性在双尾区仍然有效**、相信 **降级台账真的被读**」——**如果 SoC 估计在低温+老化下系统性高估（库仑计数偏置 + OCV 曲线漂移），而策略在"低电量 × 未示范状态"的双尾区恰好最自信（因果混淆 + 共模低估使 λ 偏低），那么系统会以最节能、最流畅、最像专家的姿态，在续航耗尽的边缘无声越过安全边界；更隐蔽的是，E-SHED 会**诚实地**把风险界一格一格放宽并逐条记账，于是事后审计看到的是"所有证书都如实写着自己已经变弱、所有降载都有签名"——**风险没有被隐藏，而是被"合规地正常化"了**。这不是"自信地错"，而是**"诚实地把诚实的失效写成合规"（certificate inflation / normalization of deviance）**：证书永远不说谎，但界被放宽到失去意义，而人早已不再逐条读台账。**

**次级风险与缓解**：
1. **共模被低估 → 平方和偷偷回流** → 把 ⊕_c 写成**类型系统强制**（共模项禁止调用 `quadrature_sum()`，编译期报错）；E372/E373 常态化红队回归。
2. **能量计量链漂移** → 在线自校准（已知放电段/静置段 OCV 校正）+ SoH/温度分层分位数界；EBD 失效即最坏电量假设。
3. **示教因果混淆** → 因果探针 + 干预正则训练；高风险状态下 ι_π 超阈即降置信/回退非学习安全策略。
4. **双尾不可消除** → 显式 `M_tail` 入 `B_declared`；不可覆盖则**拒止进入**或**主动补能量分层示教**；禁止"用更多普通示教"自我安慰（引理 36）。
5. **降载台账被无视/篡改** → 链式哈希 + 硬件签名；**关键降载要求人工确认或自动回充**；E394/E385 常态化审计。
6. **能量治理器被攻击** → 单向下行 veto + 双通道一致性（电压/温度/放电曲线）+ Gov_E 与 RTM 交叉校验；攻击只能让系统更保守。
7. **复杂度/实时压力** → 沿用 |N|≤20 等模块上限；CMU/搁浅否决 O(1) 查表；完整证书异步组装（R72 E359）。
