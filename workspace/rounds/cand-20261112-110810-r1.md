# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 1 轮，上一循环为第 55–57 轮；本轮灵感：「双臂协作」×「视觉语言模型」）

> 第 57 轮把赌注从"模型置信"换到"证据质量"，又从"手工证据"换到"摊销先验 + 共形保底"，但风险自陈暴露了单主体认识论的两个天花板：**(a)** 所有证据来自**同一具身体、同一条力回路、同一个视角**——"跨模态对账"再细，也仍是"一个人自问自答"，共因误差（同一相机被同一反光骗、同一控制器产生同一偏差）无法被自身发现；**(b)** 语义与物理被硬绑在同一个摊销先验里，语料盲区的材质只能等 OOD 门"事后"识别，而 OOD 门本身也学自同一语料——"坏先验普遍"没有被真正外部化。本轮两个灵感各引入一个"他者"：**双臂协作**引入第二具身体（可独立施力、可交叉佐证、可否决），**视觉语言模型**引入一个"博览群书却从未落地"的语义顾问（可提议、可命名、可解释，但不可作证）。核心命题由"证据说可信"升级为 **"能证者证、能议者议、耦合折权、责任可分的证据说可信"**（testimony–proposal separation）。

核心矛盾：
- **H29（耦合 vs 独立）**：两臂一致只有在"误差条件独立"时才是强证据；但共享对象、共享力回路、共享控制器让两臂极易**共因**——两臂同时被透明冰面骗到，不是两个证人，而是同一份口供抄了两遍。一致可能比单臂更危险，因为它是"看起来更强的假证据"。
- **H30（语义 vs 实证）**：VLM 恰好补上第 57 轮"语料盲区"的缺口（能命名没见过的场景），但它的幻觉**平滑而自信**，正是之前拼命要消灭的"模型置信"。一旦 VLM 的标签渗进证据门，"模型置信"就以"语义先验"的马甲回潮。
- **H31（协同 vs 责任）**：双臂联合不可逆动作一旦失败，"谁承诺的"变得模糊——每臂做一半验证、都假设另一半做完了（责任稀释）；若责任可稀释，证据门就可被"分工"绕过。协同把单体的"证据完备"问题升级成"责任完备"问题。

## 0. 直觉与动机

**灵感 1（双臂协作 → 第二证人 + 耦合折权 + 否决权）**
直觉：第二臂不是"两倍的一臂"。它带来三样单臂永远没有的东西：**第二个视角**（不同接触几何、不同本体感受）、**可交叉的物证**（一臂不可逆动作前另一臂独立触探）、**否决**（任一臂可叫停联合动作）。但它同时带来单臂没有的**共因通道**：同一根力回路、同一个被搬物体、同一套控制器——两臂会"串供"。所以设计的关键不是"让两臂一致"，而是**先估两臂的有效独立度 κ，再按 κ 折权**：κ≈1（物理分离、独立探针）时一致是强佐证；κ≈0（共享力回路/共同对象）时一致几乎不加分，只剩"分歧警报"还有用。一句：**两个串过供的证人，证词只能当一份用**。

**灵感 2（视觉语言模型 → 只提议、不作证）**
直觉：VLM 像一位"读过所有地图、却从没下过场"的顾问。它能脱口说出"这像结冰的栈道""那像空心的木质平台"，能在语料之外命名危险，能用人话解释——但它从没**摸过**任何东西。正确的用法不是让它投票，而是把它放进"提案缓冲区"：它提议**去哪儿探**、**可能是什么**、**怎么向人说**；最终是否可信，仍由物理探针（第 57 轮证据门）裁决。这样它扩展了**语义覆盖**，却不扩展**作证特权**——恰好对冲第 57 轮"坏先验普遍"，又不会把"模型置信"放回来。

**灵感 3（合流 → 双 OOD 门 + 联合证书）**
直觉：第二臂提供"物理侧的第二条检测线"（跨臂分歧），VLM 提供"语义侧的第二条检测线"（语义 OOD）。第 57 轮只有一个密度 OOD 门，漏检就把坏信念带进承诺；本轮用**语义门与密度门正交**：两门都报警才强 OOD（纯共形 + 禁 EV-probe），**恰好一门报警本身就是警报**（触发额外共识探针）。而双臂把第 57 轮的"个体证据门"升级为**联合证书 J_j**：每个核心接触必须归属到某臂的证据链（责任分区 ∂A），一臂不可逆动作需要另一臂的交叉佐证，任一臂可 veto——协同不再稀释责任，而是**显式分摊责任**。

**灵感 4（PCE+ → PCE++：探前任一票"耦合检查"）**
直觉：双人协作的安全阀往往不是"多探一次"，而是"探之前先确认我们不是在同一条船上"。PCE++ 在联合不可逆动作前插入**耦合检查**：估 κ、查共享对象力回路一致性；κ<κ_0 就直接单臂化或降为 L1。VLM 提议探针位置，但每检查点保留**探索地板**（≥floor 比例探针必须由非 VLM 规则生成），防止顾问把系统引向它自己偏爱的区域而漏探。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（共证后验与耦合折减 JCE）** 臂集 A={L,R}，区域信念 {b_r^A} 与 per-arm 探针日志。有效独立度 κ_AB(r)∈[0,1]（1=误差条件独立，0=完全共因），由共享对象标志、共享力回路、共同控制器版本、空间邻近度与历史证伪相关性估计，取**保守上界**。共证一致度 A(r)=1[TV(b_r^L,b_r^R)≤θ_A]。EV-coarm ⇔ A(r) ∧ κ_AB(r)≥κ_0 ∧ dist(r_L,r_R)≥d_0 ∧ 与融合同侧，**仅限 L1**；其等效佐证权重=κ_AB(r)（≤1）。κ<κ_0 ⇒ EV-coarm 禁用，一致不降为"作证"、只作为分歧警报的反面；分歧 A(r)=0 ⇒ 强制加宽。事后某臂被证伪 ⇒ κ 回溯降权并标记共因。

**定义 140（视觉语言提议生成 VPG）** VLM v 产生提议集 H_v(r)={(label, mask, constraint, p_sem)}。提议只允许三条**提议通道**：(P1) 元推断上下文 z_r 的语义分量（改"像哪类"，不改证据账）；(P2) 探针/绕行候选位置（受探索地板约束）；(P3) 解释渲染（模板约束生成，禁用 J_p 之外的事实）。**禁止通道**：H_v 恒不得进入任何证据类、不得提升 P_safe、不得降低 θ_voi；提案先入隔离缓冲区，需物理探针确认才可能改写信念（**提案≠证词**）。

**定义 141（语义-密度双 OOD 门 SOG）** 密度门 n_dens(o)（第 57 轮）与语义门 n_sem(r)=−log p_v(语义符合训练分布)，由 VLM 报告"场景/材质在语义上是否熟悉"。四象限：(ID,ID) 正常；(ID, OOD_sem) 语义可疑 ⇒ 保守先验 + 提示 + 额外共识探针；(OOD_dens, ID) 物理异常但语义常见 ⇒ 保留摊销但加宽；(OOD,OOD) 强 OOD ⇒ 纯共形带 + 禁 EV-probe。**单门分歧即警报**。语义门不宣称与密度门独立，仅在双门同报时收紧、单门报时加宽。

**定义 142（角色-责任分配与联合证书 RPA）** 协作态 c=(role, share, veto)，role∈{leader,follower,peer}，share 为负载/权威份额，veto∈{on,off}（默认 on，任一臂可对联合不可逆动作行使）。联合证书 J_j=J_p^L ⊕ J_p^R ⊕ 责任分区 {∂A_c}：每个核心接触必须归属到至少一臂的**完整**证据链（∂A 完备性），"假设另一臂已证"不计入；角色切换/份额变更需重过证据门（**继承 ≠ 自动继承证据**）；任一方 veto ⇒ 联合不可逆动作被拒（联合 halt）。

**定义 143（联合证据门 JSE）** 证据类扩为 EV-probe*/EV-visit/EV-margin/EV-xmodal(L1)/**EV-coarm(L1, 权重 κ)**/EV-human；VLM 提议**不产生证据类**，只产生候选探针（受地板配额）。不可逆接触必要证据集={EV-probe*∨EV-margin} ∪ 跨臂交叉佐证（一臂不可逆动作需另一臂独立 EV-probe* 或 κ≥κ_0 的 EV-coarm） ∪ 人对齐；**VLM 提议永不满足任何必要证据位**。

**定义 144（探-诺-演-协 PCC / PCE++）** 每检查点：①双边元推断与对账（同时检查跨模态 D(r) 与跨臂 A(r)）；②若含联合不可逆动作 ⇒ 耦合检查（估 κ、查共享对象力回路）；κ<κ_0 ⇒ 单臂化或降 L1；③VLM 提议探针位置，但 ≥floor 比例探针由非 VLM 规则生成；④联合承诺 ⇔ J_j 责任分区完备 ∧ 双方 veto 未触发 ∧ 证据门过；否则按 VOI_元悲观 选探针 / 绕行 / 降档 / L2 协商(auth) / 安全停；⑤任一臂 halt ⇒ 联合 halt，禁止"一臂推另一臂冒险"；协商有界（角色切换次数上限，超限单臂化）。

## 2. 关键算法伪代码（完整版见产物区）

```python
def joint_reconcile(M, r, arms):                    # IP-139 JCE
    bL, bR = M.b[r]['L'], M.b[r]['R']
    agree = TV(bL, bR) <= theta_A
    kappa = kappa_upper(M, r, arms)                 # 保守上界：共享对象/力回路/控制器
    if not agree:
        return widen(bL, bR), 'divergence'          # 分歧 ⇒ 加宽（永不加分）
    if kappa < kappa_0 or arms.dist(r) < d_0:
        return bL, 'coarm_disabled'                 # 耦合过高 ⇒ 一致不作证
    return bL, EvCoarm(weight=kappa)                # 一致作证，但按 kappa 折权（仅 L1）

def vlm_propose(M, r, task_text, vlm):              # IP-140 VPG: 只提议
    H = vlm.ground(task_text, M.views[r])           # (label, mask, constraint, p_sem)
    H = [h for h in H if h.p_sem >= p_min]
    M.proposal_buffer[r] = H                        # 隔离缓冲区，禁止进 evidence
    return H                                        # 供 P1 上下文 / P2 候选 / P3 解释

def ood_dual_gate(o, r, M, meta, vlm):              # IP-141 SOG
    d = density_ood(o, meta); s = semantic_ood(vlm, r, meta)
    if d and s:   return 'OOD_STRONG'               # 纯共形 + 禁 EV-probe
    if d != s:    return 'OOD_DISAGREE'             # 单门分歧 ⇒ 警报 + 共识探针
    return 'ID'

def joint_certificate(sched, M, arms, c, personas): # IP-142/143 J_j
    JpL = map_evidence_certificate_p(sched, ..., persona('L'))
    JpR = map_evidence_certificate_p(sched, ..., persona('R'))
    for contact in core_contacts(sched):
        owner = responsible_arm(contact, sched, M)  # ∂A：必须归属到完整证据链
        if owner is None or not chain_complete(owner, contact):
            return ('reject', 'responsibility_dilution', contact)
        if contact.irreversible and not cross_corroborated(contact, arms, M):
            return ('reject', 'no_cross_corroboration', contact)
    if c.veto == 'on' and any(arm.veto_pending for arm in arms):
        return ('reject', 'veto', sched)
    return ('ok', Jj(JpL, JpR, partition, kappa_used, veto_state))
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| JCE | O(\|A\|²·d_b)/区域 | O(\|V\|·\|A\|·d_b) | κ 保守上界、EV-coarm 限 L1 |
| VPG | 缓存命中 O(1)，未命中 O(C_vlm) | O(缓存) | 提议隔离、模板约束、永不入证据账 |
| SOG | O(1)+密度门 | O(1) | 单门分歧即警报、不宣称独立 |
| RPA | O(\|A\|)+O(\|σ\|·\|A\|) | O(\|A\|) | ∂A 完备、veto、切换复检 |
| JSE | O(\|σ\|·\|A\|) | O(\|σ\|·\|A\|) | VLM 不作证、交叉佐证 |
| PCC | O(\|CP\|·(k_p+k_cons+k_couple)·(C_VOI+d_φ)+VLM miss) | O(\|V\|+\|σ\|) | 有界协商、耦合降级、联合 halt |

**正确性定理（Joint Calibrated Cooperative Soundness, JCCS 概要）**：在 A22–A40 上增加 (A41) 耦合折减诚实：κ_AB 为两臂误差相关系数的保守上界，κ<κ_0 时 EV-coarm 禁用且仅限 L1；(A42) 提议-证词分离：VLM 提议对任何证据门恒返回 reject-as-evidence，且每检查点 ≥floor 比例探针由非 VLM 规则生成；(A43) 双门互补：语义门与密度门在真实 OOD 上同时漏检概率 ≤δ_ood²（不假设独立）；(A44) 责任分区完整且 veto 有效。则：

1. **联合承诺健全性**：记单臂失败界 P_A(fail)=δ_f+ε_meta(k)+δ_probe+ε_h(w_max)，联合不可逆动作失败率 ≤ **κ·Σ_A P_A(fail) + (1−κ)·max_A P_A(fail) + δ_ood²·α_conf + δ_xm·1[L1]·κ**（κ=1 退化为 union bound，κ=0 退化为更保守的单臂界，两端皆保守）。
2. **证词-提议分离不变性**：VLM 只能经 (a) 探针位置分布 (b) 语义先验宽度 (c) 解释文本 影响系统；不存在"VLM 提议 ⇒ 证据门通过"的路径；floor 探索配额保证任何区域不会被 VLM 的偏好完全免于物理探询。
3. **交互单调性（延续强化）**：EV-coarm 权重 κ≤1 且限 L1，VLM 不降低 θ_voi、不提升 P_safe，否决与耦合检查只会使动作更保守——无升险路径。
4. **终止性**：每检查点探针 ≤ k_probes+k_cons+k_couple；协商有限步（角色切换有界，超限单臂化），终止于 {联合承诺, 绕行, L2 协商, 安全停}。
5. **部署界**（对检查点取联合界）：
   `P_safe ≥ 1 − Σ_cp [κ·Σ_A P_A(fail)+(1−κ)·max_A P_A(fail)+δ_ood²·α_conf+δ_xm·1[L1]·κ] − P(κ 低估未检出) − P(VLM 越权) − P(协商超时 ∧ 安全停失效)`。

## 6. 本轮最大风险

**一句话**：把第二臂与 VLM 都请进决策圈后，风险从"坏先验普遍"变为"**共因伪装成独立**"——若 κ 低估了双臂/视觉与物理的共同误差源，两臂的一致会被当成独立佐证、VLM 的语义先验会把探询引导到它自己偏爱的区域，系统就在"两个证人其实串过供、顾问只会背书"的情况下更快地联合承诺；必须以 κ 保守上界、EV-coarm 仅限 L1 且按 κ 折权、VLM 永不进入必要证据位、探索地板与非 VLM 交叉佐证为硬护栏。

### IP-139 JCE（跨臂共证与耦合折减）

```python
def kappa_upper(M, r, arms):
    k = 1.0
    k *= 1 - shared_object(M, r, arms)          # 共同搬运对象 ⇒ 共因↑
    k *= 1 - shared_force_loop(M, r, arms)      # 同一力回路/同一控制器版本 ⇒ 共因↑
    k *= proximity_factor(arms.dist(r))         # 空间邻近 ⇒ 观测相关
    k *= (1 - hindsight_corr(M.audit, r, arms)) # 历史证伪相关性回溯
    return clamp(k, 0.0, 1.0)                   # 保守上界：宁可低估独立性

def joint_reconcile(M, r, arms, level):
    bL, bR = M.b[r]['L'], M.b[r]['R']
    agree = TV(bL, bR) <= theta_A
    D_arm = TV(bL, bR)
    if not agree:
        M.b[r]['fused'] = widen_mix(bL, bR)     # 分歧 ⇒ 强制加宽
        return M, D_arm, ('widen', None)        # 绝不因"两臂都错"而降险
    kappa = kappa_upper(M, r, arms)
    if kappa < kappa_0 or arms.dist(r) < d_0:
        M.audit.log(('coarm_disabled', r, kappa))
        return M, D_arm, ('widen', None)        # 高耦合 ⇒ 一致不作证
    if level != 'L1':
        return M, D_arm, ('agree_no_evidence', None)  # 不可逆接触不得用 EV-coarm
    return M, D_arm, ('agree', EvCoarm(weight=kappa))  # 一致作证，按 κ 折权
```

### IP-140 VPG（视觉语言提议生成，只提议不作证）

```python
def vlm_propose(M, r, task_text, vlm):
    H = vlm.ground(task_text, M.views[r])        # 开放词表：标签/掩码/约束/语义置信
    H = [h for h in H if h.p_sem >= p_min]
    H = [h for h in H if not grounded_in_evidence(h, M)]  # 不重复已知物证
    M.proposal_buffer[r] = H                     # 隔离缓冲：仅可被探针确认后转化
    return H

def proposal_to_probes(H, r, M, floor):
    # P2 通道：VLM 提议的探针位置（受探索地板约束）
    vlm_cands = [q for h in H for q in affordance_probes(h, r)]
    need = need_probes(M, r)
    floor_k = ceil(need * floor)                 # 至少 floor 比例非 VLM
    non_vlm = rule_based_probes(r, M, k=floor_k) # 覆盖率/最坏情形驱动，不看 VLM
    return dedupe(vlm_cands[:max(0, need - floor_k)] + non_vlm)

def vlm_explain(exp, Jp, m_E):                   # P3 通道：模板约束生成
    facts = flatten_certificate(Jp)              # 只允许 J_p 内的事实
    return render_template(exp, m_E, facts)      # 禁止引入 J_p 之外的内容
```

def ood_dual_gate(o, r, M, meta, vlm):
    d = density_ood(o, meta)                     # 第 57 轮密度门 n_dens
    s = semantic_ood(vlm, r, meta)               # 语义门 n_sem

def joint_certificate(sched, M, arms, c, personas):
    JpL = map_evidence_certificate_p(sched, log, M, consent_log, auth_log, ood_reg, persona('L'))
    JpR = map_evidence_certificate_p(sched, log, M, consent_log, auth_log, ood_reg, persona('R'))

def joint_evidence_gate(c, M, personas, arms, ood_reg):
    if c.ev == 'EV-probe*':
        ok = (c.inf.cls == 'ID' and c.inf.ece_k <= eps_meta(c.k)) or \
             (c.inf.cls == 'OOD' and c.region in ood_reg.certified)
    elif c.ev == 'EV-coarm':
        ok = c.level == 'L1' and c.kappa >= kappa_0 and \
             c.indep_declared and c.agree and arms.dist(c.region) >= d_0
    elif c.ev == 'EV-xmodal':
        ok = c.level == 'L1' and c.indep_declared and D(c.region) <= theta_D
    elif c.ev == 'EV-human':
        ok = personas[c.op].auth >= 'A1' and c.corrob >= quarantine_exit(personas[c.op].auth)
    elif c.ev in ('EV-visit', 'EV-margin'):
        ok = round56_checks(c, M)
    else:
        return ('reject', 'no_evidence_class', c)
    if c.source == 'VLM':
        return ('reject', 'proposal_not_testimony', c)   # VLM 提议永不作证
    if not ok: return ('reject', 'evidence_insufficient', c)
    if c.irreversible and c.ev in ('EV-coarm', 'EV-xmodal'):
        return ('reject', 'joint_soft_evidence_on_irreversible', c)

```python
def probe_commit_evolve_coop(x0, M, task, budget, consent, personas, arms, vlm):
    route = plan_on_map(M, task, risk_model)
    c = role_assign(arms, task, M)
    sched, log = [], []
    for cp in route.checkpoints:
        infL = meta_few_shot_infer(M, cp.region, M.obs['L'][cp.region], meta)
        infR = meta_few_shot_infer(M, cp.region, M.obs['R'][cp.region], meta)
        gate = ood_dual_gate(M.obs['L'][cp.region], cp.region, M, meta, vlm)
        M, D_arm, status = joint_reconcile(M, cp.region, arms, contact_level(cp))
        H = vlm_propose(M, cp.region, task.text, vlm)      # 只提议
        sigma = foothold_schedule(x0, cp, M); R = schedule_risk(sigma, M)
        if joint_irreversible(cp):
            kappa = kappa_upper(M, cp.region, arms)
            if kappa < kappa_0 or not force_loop_consistent(cp, arms):
                if not de_couple_to_single(cp, arms):      # 退化为单臂或降 L1
                    return negotiate_or_stop(cp, M, sigma, R, consent,
                                             tau_int=tau_int(personas.active.auth))
        while select_gait(R) == 'halt' and budget.probes_left > 0:
            cands = admissible_probes(cp, M, F_abs)         # 非破坏性过滤（A34）
            cands = proposal_to_probes(H, cp.region, M, floor) + cands  # VLM 候选+地板
            p = argmax(cands, key=lambda q: voi_meta_pessimistic(q, M, infL) - cost(q))
            if voi_meta_pessimistic(p, M, infL) < theta_voi: break
            M, _, _ = xmodal_fuse(M, cp.region, execute_probe(p, cap=F_abs))
            if status[0] == 'divergence' and 'consensus' not in cp.done:
                M, _, _ = xmodal_fuse(M, cp.region,
                                      execute_probe(most_disagreeing_modality_probe(M, cp.region), cap=F_abs))
                cp.done.add('consensus')
            if gate in ('OOD_STRONG', 'OOD_SEM', 'OOD_DISAGREE') and 'couple' not in cp.done:
                M, _, _ = xmodal_fuse(M, cp.region,
                                      execute_probe(coupling_consistency_probe(cp, arms), cap=F_abs))
                cp.done.add('couple'); budget.spend_extra('couple')
            sigma = reselect_footholds(x0, cp, M); R = schedule_risk(sigma, M)
            budget.spend(p)
        Jj = joint_certificate(sched + [cp], M, arms, c, personas)
        if select_gait(R) != 'halt' and Jj[0] == 'ok':
            sched.append(commit(sigma, select_gait(R))); log.append(tag_evidence_p(sigma, M, cp)); continue
        alt = reroute(M, cp, risk_model)
        if alt and select_gait(schedule_risk(alt, M)) != 'halt': route = alt; continue
        return negotiate_or_stop(cp, M, sigma, R, consent,
                                 tau_int=tau_int(personas.active.auth))  # 超时保守停
    return sched, log, M
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| JCE | O(\|A\|²·d_b)/区域 | O(\|V\|·\|A\|·d_b) | κ 保守上界、EV-coarm 限 L1（A41） |
| VPG | 缓存命中 O(1)，未命中 O(C_vlm) | O(缓存) | 提议隔离、模板约束、永不入证据（A42） |
| SOG | O(1)+密度门 | O(1) | 单门分歧即警报、不宣称独立（A43） |
| RPA | O(\|A\|)+O(\|σ\|·\|A\|) | O(\|A\|) | ∂A 完备、veto、切换复检（A44） |
| JSE | O(\|σ\|·\|A\|) | O(\|σ\|·\|A\|) | VLM 不作证、交叉佐证 |
| PCC | O(\|CP\|·(k_p+k_cons+k_couple)·(C_VOI+d_φ)+VLM miss) | O(\|V\|+\|σ\|) | 有界协商、耦合降级、联合 halt |

**正确性定理（Joint Calibrated Cooperative Soundness, JCCS）**
假设 A22–A40 成立；**(A41)** 耦合折减诚实：κ_AB(r) 为两臂误差相关系数的保守上界，κ<κ_0 时 EV-coarm 禁用且 EV-coarm 仅限 L1，等效权重=κ≤1；**(A42)** 提议-证词分离：VLM 提议对任何证据门恒返回 reject-as-evidence，且每检查点 ≥floor 比例探针由非 VLM 规则生成；**(A43)** 双门互补：语义门与密度门在真实 OOD 上同时漏检概率 ≤δ_ood²（不假设两门条件独立）；**(A44)** 责任分区完整（每个核心接触归属至少一臂完整证据链）且 veto 有效。则：

1. **联合承诺健全性**：记 P_A(fail)=δ_f+ε_meta(k)+δ_probe+ε_h(w_max)，联合不可逆动作失败率
   `≤ κ·Σ_A P_A(fail) + (1−κ)·max_A P_A(fail) + δ_ood²·α_conf + δ_xm·1[L1]·κ`。
   κ=1（独立）退化为两臂 union bound；κ=0（完全共因）退化为更保守的单臂界；中间为凸组合，两端皆保守，**不存在"耦合却按独立叠加"的乐观路径**。
2. **证词-提议分离不变性**：VLM 只能经 (a) 探针位置分布 (b) 语义先验宽度 (c) 解释文本 影响系统；形式化地，证据门函数对 source=VLM 恒返回 reject，故不存在"提议 ⇒ 承诺"通道；floor 探索配额保证任何区域不被 VLM 偏好完全免于物理探询。
3. **交互单调性（延续强化）**：EV-coarm 权重 κ≤1 且限 L1；VLM 不降低 θ_voi、不提升 P_safe；双门单报只加宽不收紧；否决与耦合检查只使动作更保守——无升险路径。
4. **终止性**：每检查点探针 ≤ k_probes+k_cons+k_couple；协商有限步（角色切换有界，超限单臂化），终止于 {联合承诺, 绕行, L2 协商, 安全停}。
5. **部署界**（对检查点取联合界）：
```
P_safe ≥ 1 − Σ_cp [ κ·Σ_A P_A(fail) + (1−κ)·max_A P_A(fail) + δ_ood²·α_conf + δ_xm·1[L1]·κ ]
             − P(κ 低估未检出) − P(VLM 越权) − P(协商超时 ∧ 安全停失效)
```

关键：**第二臂给物证，但按 κ 折权**（串供的证人只算一份）；**VLM 给语义，但永不作证**（提案走隔离孔，物理侧裁决）；**双门互补把单门漏检从 δ_ood 压到 δ_ood²**；**联合证书用 ∂A 责任分区杜绝"都以为对方证了"**。四者全部经"信念更准/加宽"或"动作更保守/协商更长"两个安全通道起作用。

云边协议 CEB++ → **CEB+++**：VLM 推理布在云端，按区域缓存并异步下发（控制回路只用缓存/文本回退）；云端同时下发元模型与 VLM 的**增量版本**，二者都走影子隔离——元模型过校准回归，VLM 过**提议质量审计**（越权=0、floor 满足、语义门不劣化）后才可接管提案孔；边端回传跨臂共证残差、证伪事件与 κ 回溯记录，作为云端共因建模与语料补盲依据。第 57 轮"一切判定器走隔离"在本轮推广为"**一切提议者走隔离、一切共证按耦合折权**"。

## 6. 本轮最大风险

**一句话**：把第二臂与 VLM 都请进决策圈后，风险从"坏先验普遍"变为"**共因伪装成独立**"——若 κ 低估了双臂/视觉与物理的共同误差源，两臂的一致会被当成独立佐证、VLM 的语义先验会把探询引导到它自己偏爱的区域，系统就在"两个证人其实串过供、顾问只会背书"的情况下更快地联合承诺；必须以 κ 保守上界、EV-coarm 仅限 L1 且按 κ 折权、VLM 永不进入必要证据位、探索地板与非 VLM 交叉佐证为硬护栏。
