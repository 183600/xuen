# 第 44 轮（新循环第 4 轮） · Few-Shot-Cert × Agent-Cert：证据台账驱动的少样本证书迁移与「提议-验证分离」智能体（四层架构 v10）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 把「用户」与「并发」纳入证书闭环，但仍压着两个未言明的假设：**(H1) 技能与证书是大数据预训练后冻结的**——新任务、新物体、新场景要么命中查表，要么全量重训；真实部署恰恰是「给 3~10 个演示就要上手」，少样本泛化被当成工程技巧而非证书问题。**(H2) 智能体只负责语义提议**——但真正的智能体会主动问人、试探、检索、写记忆、调工具、甚至改自己的策略参数；一旦它同时提供证据并签发证书，就会发生**自我认证**与**证书过拟合**。本轮灵感词「小样本学习」「智能体」精确命中这两个假设：**小样本学习**迫使我们承认泛化的本质是**证据不足下的风险控制**，而不是策略的平均性能；**智能体**迫使我们把「自主性」重新定义为**主动获取证据的自由**，而不是改写安全证书的自由。二者耦合处是本轮真正的新问题：**智能体会主动挑选用于认证自己的数据**，从而破坏共形预测赖以成立的可交换性，并可能把证书「训练」到看似覆盖、实则失效。

## 0. 直觉与动机

**灵感 1（小样本 → 泛化的不是策略，是证据台账）**：k 个演示无法证明未见状态上的安全，平均成功率也不是 soundness。直觉上正确的做法不是「用少样本把策略练得更强」，而是：**先用持证骨架锁住结构，再只让少样本去调一小盒参数**；能不能部署，取决于「证据够不够把迁移误差界压到安全裕度以下」，而不是取决于演示看起来像不像。于是把少样本学习从「策略拟合」改写为**证书迁移**：β(A,S) 是适配算子 A 在支持集 S 上相对基础证书的最大可能退化；只有 m₀ − β ≥ θ 才允许部署。一句话：**少样本不产生证书，少样本只缩小证书上的未知项。**

**灵感 2（智能体 → 自主性在「获取证据」，不在「改证书」）**：把智能体拆成提议者 P 与验证者 V。P 可以任意聪明：问人、安全试探、检索 CKB、合成演示、调用工具、生成计划；V 只做一件事——独立检查证据来源、留出审计集、迁移界与参数盒，然后签字。P 不能写 V 的信任根，不能提供自己唯一的证据，不能改已签发证书。**智能体的自由被定义为「选择下一个最有信息量的证据动作」**，其目标函数是单位风险/成本下的证书收缩量。这样，LLM 的幻觉、VLM 的误识别、甚至对抗性提示注入，最多让 P 提出坏建议，不能直接变成物理违例。

**灵感 3（耦合 → 主动选数据会破坏可交换性，必须审计集隔离）**：共形预测的覆盖保证依赖校准集与测试点的可交换性；而智能体为了尽快部署，会**主动挑选**那些让风险看起来最低的演示/试探。这正是「证书过拟合」：用同一批数据既适配又估计覆盖，覆盖率会系统性虚高。解决三件套：**(a) 审计集与适配集严格不相交，审计集由 V 独占**；**(b) 任务级元共形 + 新颖性门控**，任务偏离校准流形时自动膨胀 β 或拒绝；**(c) 支持集投毒鲁棒化**——来源证明、影响函数裁剪、留一稳定性、崩溃点。直觉上：**智能体可以决定「去问谁」，但不能决定「用哪张考卷给自己打分」。**

**结构原则（本轮的主杠杆）**：**结构持证、参数少样本**。新任务 = 已认证技能骨架（组合文法、Pre/Inv/Post、参数盒 Θ_cert）+ 少样本估计的低维参数 θ̂。只对 θ 做少样本，结构不重新学习；这把少样本的维度从百万参数降到个位数，迁移界才可能算得清、收得紧。

**耦合升级**：MCAE（元认证适配引擎）把支持集编译成任务指纹、检索持证骨架、算元共形分位与迁移界；AEA（主动证据智能体）在证据 POMDP 里选「问/试/查/合成/审计」，并用提议-验证分离守门；FSR（少样本红队验证器）专打任务漂移、支持集投毒、证书过拟合与跨本体迁移。四层架构由 v8 的「人格/并发证书」升级为 v10 的「**证据台账 + 证书迁移 + 提议验证分离**」闭环，v20 的人格契约与并发租约作为正交层继续复用。

## 1. 形式化定义（增量：定义 44–50）

**定义 44（少样本任务、支持集与任务指纹）**：任务 τ=(g,O,Sc,u) ~ P_T（目标、物体集、场景、用户/角色）。支持集 S_k={(o_i,a_i)}_{i=1}^{k} ~ D_τ^k，可含少量语言说明。任务指纹 z=Φ(τ,S_k)∈Z，要求对支持集扰动稳定：‖Φ(τ,S)−Φ(τ,S')‖ ≤ L_Φ·d_H(S,S')。**新颖性**：若 z 到校准任务流形 M_cal 的距离 d(z,M_cal) > r₀，则任务视为分布外，元共形保证失效，必须膨胀界或弃权。

**定义 45（元共形任务证书）**：在校准任务族 {(τ_i,S_i)}_{i=1}^{n} 上计算非一致性分数 R_i=R(π_{S_i},τ_i)（如最大裕度退化/失败指示）。对新任务按指纹加权：q_z = Quantile_{1−α}({R_i}, w_i ∝ K(z_i,z))，得到**任务级证书** P_{τ~P_T}(R(τ) ≤ q_{Φ(τ)}) ≥ 1−α。**分层版**：按任务簇 j 做 Mondrian，要求条件覆盖 P(R≤q_j | τ∈C_j) ≥ 1−α_j。**命题**：可交换性/加权协变量偏移条件成立时边际覆盖成立；任务漂移或支持集选择偏差会破坏前提——因此定义 45 只是**候选界**，必须由定义 49 的审计集与新颖性门控共同背书。

**定义 46（证书迁移界与少样本可部署域）**：基础技能 σ₀ 有已认证裕度 m₀(x) 与不变式 Inv₀；适配算子 A（残差策略/参数微调/演示条件扩散）在支持集 S 上输出 π_S。设裕度退化上界
β(A,S) = L_A·W₁(μ̂_S, μ_cal) + L_θ·‖θ̂(S)−θ_cal‖ + c·√(log(1/δ)/k) + q_{Φ(τ,S)}。
**可部署域** F(A)={S : β(A,S) ≤ m₀−θ}。**命题（迁移 sound）**：若 (i) σ₀ 在 Inv₀ 上 sound 且 m₀≥θ；(ii) sup_x |m_{A(S)}(x)−m₀(x)| ≤ β(A,S)（由 A 对支持集的 Lipschitz 性与算法稳定性给出）；则对 S∈F(A)，π_S 在 Inv₀ 上以裕度 ≥θ sound。**推论**：少样本适配只能**消耗**基础证书的裕度，不能凭空创造裕度；证据越多，β 越小，可部署域越大。

**定义 47（证据台账、证书宽度与主动证据策略）**：台账 E=(S_adapt, P_probe, Q_human, R_retrieved, A_audit, provenance)，其中适配集与审计集 A_audit 严格不相交。证书宽度 w(E)=β(A,S_adapt,E)。证据动作 a∈{ask_human, safe_probe, retrieve_CKB, synthesize, request_audit}，各有成本 c(a)、自身风险 ρ(a)（probe 必须落在已认证安全集内）与期望收缩 Δw(a)。**证据策略** π_E 最大化 E[Δw]/(c(a)·(1+ρ(a))) s.t. 预算 B_ev、审计比例 ≥η、动作安全。**无免费泛化命题**：若 w(E) > m₀−θ，则禁止部署；智能体只能继续取证、协商或降级到整技能检索，**不得用平均成功率替代界**。

**定义 48（提议-验证分离的智能体证书）**：智能体 Ag=(P,V,Tool,Mem)。P 为提议者（LLM/VLM/规划器），输出候选技能、计划、工具调用或记忆写入；V 为验证者，只读访问证书库、来源证明、审计集与参数盒，P 不可写 V 的信任根。智能体证书 C_Ag=(C_task,C_tool,C_mem,C_proc)，要求：
(1) **非干扰**：P 的写集与 V 的信任根不相交（延续定义 40 的 RG 思想）；
(2) **独立证据**：每次部署的签名证据不得仅由 P 提供，至少含一条 V 独占审计或独立来源；
(3) **工具前置/后置证书**：工具调用必须携带 (Pre,Post) 并验证；
(4) **记忆写入证书**：未认证的语义断言不得进入安全相关记忆；
(5) **禁止自证**：P 不能同时是证书的唯一签发者。
**定理（智能体可靠性）**：若 V 的检查蕴含定义 46 的迁移界与定义 48(1)(2)，则无论 P 产生多少幻觉/对抗建议，任何被部署的技能都保持 sound。**直觉**：智能体可以无限自由地「想」，但不能自由地「签发」。

**定义 49（支持集投毒、证书过拟合与审计集隔离）**：设攻击者控制比例 ε 的支持集或影响智能体的取证选择。**证书过拟合**：若适配与覆盖估计共享数据（A_audit ∩ S_adapt ≠ ∅），名义覆盖率可任意虚高。**投毒鲁棒性**：适配算子 A 的崩溃点 BP(A)=max{ε : 在 ε 比例污染下 β 界仍 sound}；要求 ε<BP(A)，且留一稳定性 LOO(A,S)=max_i ‖A(S)−A(S\{i})‖ ≤ ρ。**命题**：当审计集与适配集不相交、|A_audit|≥ηk、来源证明通过、ε<BP(A) 时，误签发概率 ≤ δ_audit；任一条件不满足则 V 拒签并触发补证/弃权。

**定义 50（持证骨架上的少样本组合）**：持证骨架 σ=(G,Θ_cert,Inv,Pre,Post) 由组合文法产生，Θ_cert 为离线鲁棒可达性算出的**认证参数盒**。新任务只估计低维参数 θ̂（抓取偏置、速度剖面、阻抗增益等），部署要求 θ̂∈Θ_cert（带置信）且组合前后置蕴含成立。**定理（结构-参数分离）**：若骨架对 ∀θ∈Θ_cert sound，且 θ̂∈Θ_cert，则实例化技能 sound。**推论**：少样本只承担「参数辨识」，不承担「结构发明」；结构创新必须走离线认证与 CKB 晋升，不得在部署时即兴生成。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 META-CERTIFIED-ADAPTATION-ENGINE（元认证适配引擎 MCAE）
1. **任务指纹与检索**：Φ(τ,S) 编码目标/物体/场景/支持集统计；从 CKB 检索最近的持证骨架与 Θ_cert。
2. **元共形任务证书**：按任务簇 Mondrian + 加权分位；新颖性门控 d(z,M_cal)>r₀ 时膨胀 β 或弃权。
3. **少样本参数辨识**：仅在骨架参数盒内拟合 θ̂；输出置信椭球与对支持集的敏感度。
4. **迁移界计算与部署判决**：β(A,S) 合成 Lipschitz 项、稳定性项、元共形分位；m₀−β≥θ 才签发 shadow 证书。
5. **证据台账接口**：把 β 分解为可归因项，返回「还差多少证据、差在哪个方向」，供 AEA 选动作。

### 2.2 IP-61 ACTIVE-EVIDENCE-AGENT（主动证据智能体 AEA）
1. **证据 POMDP**：状态=当前界与不确定方向；动作=问人/安全试探/检索/合成/申请审计；奖励=证书收缩/成本/风险。
2. **提议-验证分离**：P 生成候选与取证计划，V 独立验证来源、审计集、LOO 稳定性、参数盒与迁移界；P 不可写 V。
3. **审计集所有权**：V 独占并保密审计集；适配集与审计集严格不相交；审计比例 η 硬约束。
4. **工具与记忆证书**：工具调用带 Pre/Post；记忆写入只接受 V 签名的信念，防语义幻觉污染安全记忆。
5. **回退梯**：补证 → 协商/最小消歧 → 整技能检索（零少样本） → σ_⊥ 通用安全技能 → 安全停机。

### 2.3 IP-62 FEW-SHOT-REDTEAM-VALIDATOR（少样本红队验证器 FSR）
1. **任务漂移基准**：构造校准族之外的新任务/新物体/新场景，测任务级与条件覆盖、弃权率。
2. **支持集投毒**：注入错误演示、偏向性演示、来源伪造；测崩溃点与误签发率。
3. **证书过拟合测试**：复用适配/审计数据 vs 隔离审计的覆盖率对照；检测虚高覆盖。
4. **跨本体迁移**：3 种机器人/夹爪/相机下验证 β 界与重校准成本。
5. **对抗性提议者**：红队 P 伪造来源、自证、隐藏失败演示、提示注入工具；验证 V 的拒签率 100%。

## 2. 关键算法（伪代码）

### IP-60 MCAE：指纹、元共形、迁移界与部署判决
```
def certify_few_shot(task, S_adapt, base_lib, alpha, audit):
    z = fingerprint(task, S_adapt)                 # Φ(τ,S)
    if d(z, M_cal) > r0:
        return Abstain(NOVELTY, z)                 # 分布外：不签发
    sk = retrieve_skeleton(z, base_lib)            # CKB 检索持证骨架
    if sk is None:
        return Abstain(NO_SKELETON, z)
    theta_hat, conf = few_shot_fit(sk.param_space, S_adapt)
    if not in_box_conf(theta_hat, conf, sk.Theta_cert):
        return NeedEvidence(ASK, gap=box_gap(theta_hat, conf, sk.Theta_cert))
    q   = meta_conformal_quantile(z, sk.cal_scores, alpha)   # 加权/Mondrian
    beta = (L_A * wasserstein1(S_adapt, sk.mu_cal)
            + L_theta * norm(theta_hat - sk.theta_cal)
            + c * sqrt(log(1/delta) / max(len(S_adapt), 1))
            + q)
    if sk.m0 - beta < theta:
        return NeedEvidence(ledger_gap(sk.m0 - theta - beta),
                            decompose(beta))       # 还差多少、差在哪一项
    return ShadowCert(sk, theta_hat, beta, version=sk.version,
                      evidence=ledger_hash(S_adapt, audit))

def meta_conformal_quantile(z, scores, alpha):
    w = [kernel(z, z_i) for z_i in scores.z]       # w_i ∝ K(z_i,z)
    return weighted_quantile(scores.R, w, 1 - alpha)
```

### IP-61 AEA：取证选择、提议-验证分离与审计集
```
def next_evidence(state, budget):
    actions = [ASK_HUMAN, SAFE_PROBE, RETRIEVE_CKB, SYNTHESIZE, REQUEST_AUDIT]
    best = None
    for a in actions:
        if not within_budget(a, budget): continue
        if a == SAFE_PROBE and not certified_safe(a, state): continue
        gain = expected_beta_reduction(a, state)   # 对 β 各分项的期望收缩
        risk = expected_risk(a, state)
        score = gain / (cost(a) * (1 + risk / lambda_risk))
        best = argmax(best, (score, a))
    return best or FALLBACK_CHAIN(state)

def fallback_chain(state):
    if state.can_negotiate: return NEGOTIATE_MIN_DISAMBIGUATION
    if state.has_whole_skill: return RETRIEVE_WHOLE_SKILL   # 零少样本
    return SAFE_STOP

def agent_step(obs, memory, ledger):
    proposal = P.propose(obs, memory, ledger)      # 可幻觉、可被注入
    if proposal.kind == TOOL_CALL and not tool_cert_ok(proposal):
        return ASK_OR_FALLBACK(proposal)
    if proposal.kind == MEMORY_WRITE and not V.certify_belief(proposal):
        return REJECT_MEMORY(proposal)
    sig = V.sign(proposal, ledger)                 # 独立验证，P 不可写 V
    if sig is None:
        return next_evidence(state_from(proposal), ledger.budget)
    return execute(proposal, sig)

def V.sign(proposal, ledger):
    if not provenance_ok(ledger.S_adapt):             return None   # 来源不可信
    if not ledger.S_adapt.isdisjoint(ledger.A_audit): return None   # 过拟合
    if not audit_coverage_test(proposal, ledger.A_audit): return None
    if loo_stability(proposal.A, ledger.S_adapt) > rho: return None
    if not in_box(proposal.theta_hat, proposal.sk.Theta_cert): return None
    if proposal.sk.m0 - proposal.beta < theta:        return None
    if proposal.evidence_source == ONLY_PROPOSER:     return None   # 禁止自证
    return Sign(proposal, verifier_id=monotonic_now())
```

### IP-60/62：投毒鲁棒适配与少样本组合
```
def robust_fit(sk, S, trim):
    infl = influence(sk.A, S)                      # 每条演示对 θ̂/β 的影响
    S_clean = trim_top(S, infl, trim)              # 裁掉高影响离群演示
    theta = fit(sk.param_space, S_clean)
    return theta, loo_stability(sk.A, S_clean), breakdown_est(S_clean)

def instantiate_few_shot(sk, theta_hat, conf):
    if not cert_box_contains(sk.Theta_cert, theta_hat, conf):
        return ASK                                       # 参数出盒：补证/协商
    plan = sk.G.instantiate(theta_hat)                   # 结构来自持证文法
    if not pre_post_chain(plan, sk.Pre, sk.Post):
        return REJECT
    return plan

def certificate_overfit_guard(S_adapt, A_audit, eta):
    if not S_adapt.isdisjoint(A_audit): return FAIL       # 数据泄漏
    if len(A_audit) < eta * len(S_adapt): return FAIL     # 审计不足
    return OK
```
