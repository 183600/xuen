# 第 11 轮（新灵感循环第 2 轮；本轮灵感：「迁移学习」×「对比实验」）
> **基线**：第 10 轮 MetricVoiceGauge-NCD（定义 540–553；引理 87–95；实验 E571–E588），其基线为第 9 轮 MetricVoiceGauge-ACMD。
> 本轮纪律：**迁移机制与先验、而非表象与策略；用配对对比实验为迁移盖章**。不推倒 v10：NGE/DSL/CC/CWM/CAE/NCP 与 MetricVoiceGauge 九不变式、v9 的 AC/MW/ID、v8 的 DA/SPR/Cal 全部保留；三个新组件一律以**中立元**接入，失效即严格退回 v10（引理 102），再沿 v10 九级链退回 v9/v8/v7。本轮只做三件事：给"跨域迁移"发一张**可证伪证书**、把"观测消融"升级为**配对对比实验**、让规范先验**分层迁移**。

## 0. 直觉与动机

**灵感 1（迁移学习 → 迁移的是机制与先验，不是表象与策略）**
直觉：v10 每进入一个新家庭、新文化、新本体（换机器人/换手），都近似从零在线学习；CWM 的不变父集 S* 在目标域样本稀少时估不准，NGE 的规范先验也从头更新。朴素迁移会把策略、观测特征或阈值整包搬过去，在分布偏移大时产生**负迁移**——比不迁移更糟，而且系统往往"更自信地错"。核心创新：**可迁移机制引擎（Transferable Mechanism Engine, TME）** 与 **迁移证书（TransferCertificate, TC）**。用选择图（selection diagram）显式标出"哪些机制在域间共享、哪些被域选择节点改写"，用 do-演算搬运公式只搬**机制 P(Y|do(a), pa)** 与**规范先验**，绝不搬观测分布 P(X)、不搬策略 π、不搬未经检验的阈值。迁移前必须过三关：机制不变性检验（在源域对比实验中稳定）、目标域支撑重叠、敏感性界在预算内；任一不过就**退回保守（不迁移）**，而不是硬搬。

**灵感 2（对比实验 → 用配对对比把共享混杂 H 差掉）**
直觉：v10 的最大风险是规范信念 b_ν 与因果模型共享同一个未观测混杂 H（人类真实意图），于是两者同时错、错得一致、还很有信心。v10 的 CAE 仍主要是观测性的 with/without 消融，两臂上下文不同，H 无法被差分掉；这是"相关冒充因果"的结构性漏洞，加更多模型复杂度只会把共享误差埋得更深。核心创新：**配对对比引擎（Paired Contrast Engine, PCE）**。在匹配的上下文层内随机化模块/技能开关（配对 RCT），或对时间耦合场景使用 switchback 设计，用配对差分/双重差分（DiD）估计 ACE；只要 H 在配对内（或时间上）稳定，就被差分消去。再加**负对照结果**：选一个只可能经 H 受影响、而治疗不可能影响的"安慰剂"量，一旦它在对比中出现显著效应，就说明可交换性被 H 破坏——把"看不见的混杂"变成**会响的告警**。对比实验不只是估计器，更是 v10 共享混杂的**证伪工具**。

**灵感 3（两者如何统一 → 可迁移性 = 可被对比实验认证的机制不变性）**
直觉：迁移学习与对比实验其实是一件事的两面。**源域的每个域本身就是目标机制的一次自然对比**；而**配对对比是判断"这条经验到底能不能搬"的唯一可信手段**。于是给出一个可证伪的迁移定义：

> 一项能力可迁移 ⇔ 其机制在源域对比实验中稳定（不含 H 驱动的伪效应）∧ 目标域与源域支撑重叠 ∧ 目标域上的配对对比预测净增益为正。

这把 v10 的"自信地礼貌且因果错误"改造成一个**可测量、可告警、可拒绝迁移**的闭环：当规范通道与任务通道两条独立对比在"共同 H"假设下本应一致、实际却不一致时，负对照与交叉对比会把矛盾暴露为告警，而不是继续自信执行。

**统一接口**：在 v10 的块接口 ζ=(skills, Ĉ_safety, Ĉ_contact, Ĉ_norm, P) 之外，新增可迁移-可对比字段 τ=(TC, CCtr, Ĥ_alarm)，二者并列组成 v11 块接口。规范回答"能不能做"，灵巧回答"怎么做"，因果回答"做了会怎样、为什么有效"，**迁移回答"在别处成立的经验凭什么在这里成立"，对比实验回答"凭什么相信这条经验是真的"**。

## 1. 研究问题（轮次升级版）

- **Q1（迁移可证伪性）**：如何把"这条经验/机制可迁移"写成一个**可被数据否决**的命题，而不是一个架构默认假设？选择图、搬运公式、不变性检验、支撑重叠与敏感性界如何组合成一张可复用的迁移证书？
- **Q2（对比实验的可交换性与干扰）**：在真实连续部署中，配对可交换性会被时间耦合、携带效应与 SUTVA 违背破坏；如何在存在干扰时仍给出带**偏差界**的因果对比，而不是退回不可信的点估计？
- **Q3（共享 H 的可检测性）**：当 b_ν 与 CWM 共享同一 H 时，如何用负对照与跨通道对比把"共同误差"转化为**可告警的统计信号**，并控制误报率？
- **Q4（负迁移与退化）**：迁移门控、分层先验与配对对比三者组合后，能否证明"最坏不比不迁移更差"，并在新域样本稀少/规范冲突时严格退回 v10 而不产生僵局？

## 2. 设计原则（在 P13–P15 基础上新增 P16–P18）

**P16 机制迁移律（Mechanism Transport, TME）**
跨域只允许搬运三类对象：机制 M=P(Y|do(a), pa)、规范先验 θ_ν、接触/证书的误差余量 β；禁止搬运观测分布 P(X)、策略 π 与未经检验的硬阈值。任何搬运必须以选择图声明域选择节点，并给出搬运公式或显式标注"不可搬运"。迁移前必须持有有效 TC（定义 556）。

**P17 配对对比律（Paired Contrast, PCE）**
凡进入 ID 归因或迁移门控的因果量，必须来自**匹配随机对比**（配对 RCT 或 switchback），或显式标注为观测性并附带敏感性界。每个因果声明必须配一个负对照；未通过负对照或干扰界超预算的对比，其结论只能降低置信、不得用于迁移。

**P18 迁移门控律（Transfer Gate, HNT）**
迁移门 g∈{transfer, conservative, local} 由 TC 与目标域对比共同决定：`g=transfer` 需机制不变性通过 ∧ 支撑重叠 ≥o_min ∧ 敏感性界 ≤B_max ∧ 净增益下置信界 >η_net>0；否则 `g=conservative`（只用共享先验的保守包络，如规范取各域硬约束的并集）或 `g=local`（不迁移、等价 v10 单域）。分层规范先验只允许**均值/先验**的部分池化，硬规范永远由目标域证据 + 保守上界决定。

## 3. 与基线的接口（如何退化）

- **TME/TC 失效** ⇒ 注入迁移中立元 v^⊥=**local-only**（不做任何跨域搬运，τ 置空），行为等价 v10 单域；
- **PCE 失效** ⇒ 退回 v10 的 CAE 观测消融 c_m^obs，并把所有归因标注为 observational；
- **HNT 失效** ⇒ 规范先验退化为 v10 的平坦先验（θ_ν 不跨域共享）；
- **三者全失效** ⇒ MetricVoiceGauge-NCD v10，再沿 v10 九级链退回 v9/v8/v7；
- **安全继承**：TC 只能**删候选或保守化**，PCE 只改归因、不改执行，HNT 只改先验、不改硬规范盾；新组件不能放宽任何 v10 适用证书（引理 104）。

## 4. 预期贡献

1. **可迁移性证书**：选择图 + 搬运公式 + 机制不变性检验 + 支撑重叠 + 敏感性界 + 净增益下界，组成一张**可证伪、可复用、失效即退回**的迁移契约，覆盖规范、因果、接触三类机制；
2. **配对对比引擎与负对照诊断**：把 v10 的观测消融升级为配对 DiD/switchback，并用负对照把共享混杂 H 从"沉默失败"变成"可告警事件"，直接针对 v10 的最大风险；
3. **分层规范迁移**：跨家庭/跨文化的层级贝叶斯先验 + 部分池化 + 迁移门，量化"适应回合数"与"负迁移率"，给出最坏不退化的保证；
4. **统一的"迁移=被对比实验认证的机制不变性"框架**：E589–E606 覆盖机制不变性、证书校准、负迁移压力、配对对比对 RCT 真值、H 告警、跨本体接触迁移与端到端任务。

## 5. 本轮最大风险

**一句话**：配对对比的可交换性会被真实部署中的时间耦合与携带效应破坏，而源域到目标域的"不变机制"假设又可能同时失效，于是迁移证书与对比证书**互相背书**，把负迁移认证成正迁移——即**在错误的域上做了正确的实验，并为错误的迁移盖章**。

**定义 554（域、选择图与不变机制）** 域 e 由数据生成机制族 {P_e(X), P_e(Y|do(a),pa)} 标识。选择图 D=⟨V,E,S⟩ 在因果 DAG 上增加域选择节点 s∈S，s 指向"随域改写"的机制。机制 M_e=P_e(Y|do(a),pa(Y)) 在域集 E' 上**不变**，当且仅当对未被 S 指向的每个机制族，M_e=M_{e'}（∀e,e'∈E'）。被 S 指向的机制视为**候选可迁移**，必须经检验方可搬运。

**定义 555（搬运算子与可迁移机制）** 若 S 只指向输入分布，则目标域反事实由搬运公式给出：
```
P_{e'}(Y|do(a)) = Σ_{pa} P_e(Y|do(a),pa) · P_{e'}(pa)
```
若 S 指向结果机制，则先用 z-可识别性判定能否在源域内重构该机制；可重构则搬运其 do-分布，不可重构则**标记为不可搬运**，不进入 TME 输出。TME 只允许输出三类可迁移对象：
```
TME(P_e→P_{e'}) ⊂ { M, θ_ν, β }      （机制、规范先验、误差余量）
```
并显式禁止输出 P_e(X)、策略 π、未经检验的硬阈值。

**定义 556（迁移证书 TC）** 一次从源域集 E_src 到目标域 e' 的搬运携带证书
```
TC = ( ι̂, Ô, B̂_Γ, Ĝ, LCB(Ĝ), Ĉtr_src )
```
其中 Ĉtr_src 是认证该机制的对比证书（定义 560）。**TC 有效** ⇔
```
ι̂ 通过（p<α） ∧ Ô ≥ o_min ∧ B̂_Γ ≤ B_max ∧ LCB(Ĝ) > η_net > 0 ∧ Ĉtr_src.label ∈ {RCT-paired, switchback}
```
任一分量不满足 ⇒ 该搬运**被拒**，迁移门降为 conservative 或 local。TC 是可证伪对象：它同时声明了"用哪个对比认证、在哪些域上不变、残差多大、预期增益多少"。

**定义 557（配对对比设计）** 给定上下文分层 c(s)，在层 c 内随机指派治疗 Z_i∈{0,1}：Z_i=1 表示启用模块/技能 m，Z_i=0 为关闭。配对差分估计为
```
Δ_pair = (1/|P|) Σ_{i∈P} ( Y_i(1) − Y_i(0) ),  P = 匹配对集合
```
对时间耦合不可同时开关的场景使用 **switchback**：按时间块轮换治疗/对照，块间插入洗脱窗 T_wash，估计
```
Δ_sw = (1/|B_T|)Σ_{b∈B_T} Ȳ_b − (1/|B_C|)Σ_{b∈B_C} Ȳ_b
```
并报告携带效应上界。

**定义 558（配对 DiD 与识别条件）** 存在前后测时，双重差分
```
Δ_did = ( Ȳ_T,post − Ȳ_T,pre ) − ( Ȳ_C,post − Ȳ_C,pre )
```
识别条件：(I1) 配对内可交换（同一层内 Z 独立于潜在结果）；(I2) 携带效应可洗脱或被建模；(I3) 平行趋势，违背量 |δ_pt|≤δ̄。在 (I1)(I2) 下 Δ_pair 无偏估计 ACE_m；若仅 (I3) 近似成立，则
```
|E[Δ_did] − ACE_m| ≤ δ_pt
```
估计值必须附带 (δ_pt, T_wash, 干扰界) 三项偏差预算，否则只能作观测性结论。

**定义 559（负对照与共享混杂检验）** 选结果 Y^neg 使其满足：(N1) 对治疗 A 的因果效应为零（排他性）；(N2) 与 H 强相关。若配对对比在 Y^neg 上显著非零，则说明配对可交换性被 H（或其它共同原因）破坏。定义告警
```
Ĥ_alarm = 1[ p_{Y^neg} < α_neg ∨ 跨通道方向不一致 ]
```
跨通道一致性指：规范通道（NGE 的 b_ν 干预）与任务通道（CWM/技能干预）在同一 H 假设下对同一目标的效应应同号；异号即为不一致告警。

**定义 560（对比证书 CCtr）** 每个因果声明携带
```
CCtr = ( bal, ovl, pwr, neg, intf, label )
```
`bal` 为配对后协变量平衡（SMD≤0.1），`ovl` 为重叠系数，`pwr` 为功效，`neg` 为负对照是否通过，`intf` 为干扰界，`label∈{RCT-paired, switchback, quasi, observational}`。**可用于迁移**的最低要求是 `label∈{RCT-paired,switchback} ∧ neg=pass ∧ intf≤intf_max`；`quasi/observational` 只能用于降置信与报告敏感性界，禁止进入 TC。

**定义 561（分层规范迁移 HNT）** 规范参数按层级组织：总先验 θ_ν^(0)、文化层 μ_c、家庭层 h：
```
θ_ν^(h) ~ N( μ_{c(h)}, Σ_ν ),   μ_c ~ N( θ_ν^(0), Σ_culture )
```
后验用部分池化，收缩权重 λ_h = n_h/(n_h+κ)。**只迁移均值与先验**；硬规范的**阈值本身不迁移**，取目标域证据支持的保守上界与源域硬约束的并集（更严者优先）。当目标域证据与先验冲突超过阈值时，门 g 降为 conservative/local。

**定义 562（迁移门与净增益）** 迁移门
```
g = transfer      若 TC 有效 ∧ LCB(Ĝ)>η_net
  = conservative  若机制部分不变但净增益不可证（用保守包络）
  = local         若 TC 无效或对比未通过负对照（不迁移）
```
净增益 Ĝ = E_{e'}[Δ_task] − Δ_risk − cost_transfer，其中 Δ_risk 含规范违规风险与物理/接触证书余量的保守化代价。**g=local 时 v11 严格等价 v10 单域行为**。

**定义 563（迁移感知目标）** 对候选块 ζ 与迁移状态 τ：
```
J_TCC(ζ|s,b) = J_v10(ζ|s,b) − λ_T · Risk_transfer(ζ,τ)
subject to  TC valid/g=transfer（若使用任何跨域机制）
          ∧ CCtr 合法（若使用任何因果归因）
          ∧ 所有 v10 证书有效
```
若使用跨域机制而 TC 无效，则该项候选被**删除**；若全部候选被删除，退回 v10 的 a_ask（v10 定义 544），不产生新僵局。

**定义 564（v11 中立元表）**

| 新组件 | v^⊥ | 等价退化点 |
|---|---|---|
| TME / TC | 不搬运，T(P_e→P_{e'})=I；只用目标域在线数据 | Level-3（v10 单域） |
| PCE / CCtr | 归因退回 v10 CAE 的 c_m^obs，label=observational | Level-1（v10 归因） |
| HNT | 先验退回 v10 平坦先验（不共享 μ_c） | Level-2（v10 NGE） |
| NCM | Ĥ_alarm≡0，不产生额外告警 | Level-1（v10） |
| v10 组件 | 沿用定义 553 的中立元 | Level-4…12 |

**定义 565（配对实验评测协议）** 评测采用**同体配对设计**：同一场景/同一初始状态分层下，成对运行基线与被试，配对比较。预注册配对假设与等价界；报告配对效应量、置信区间、方差缩减因子，禁止把配对优势与样本量优势混为一谈。对不可配对的部署场景，用 switchback 并在报告中给出洗脱窗与干扰界。

**定义 566（共享 H 的可检测化）** 当规范通道与任务通道共享 H 时，定义联合诊断统计量
```
Λ_H = w_1·|Δ_pair(Y^neg)| + w_2·1[sign(Δ_norm) ≠ sign(Δ_task)]
```
`Λ_H>λ_H` 时置 Ĥ_alarm=1：系统暂停自动迁移与自动休眠，转 a_ask 或人工确认。该统计量把"两个模型共享错误"从不可见的结构缺陷变成可观测的检验结果。

# IP-365/366 TransferableMechanismEngine + TransferCertificate
class TransferableMechanismEngine:
    def __init__(self, selection_diagram, alpha=0.05):
        self.D, self.alpha = selection_diagram, alpha

    def transport(self, src_domains, target, mechanism_ids, contrast_engine):
        # 1) 只对选择图声明可搬运的机制族做搬运
        transportable = [m for m in mechanism_ids
                         if m not in self.D.selection_targets or
                            z_identifiable(self.D, m, src_domains)]
        if not transportable:
            return None, TransferCertificate.rejected(reason='not-transportable')
        # 2) 机制不变性检验：在源域间的配对对比上检验
        inv_test = self._invariance_test(src_domains, transportable, contrast_engine)
        # 3) 搬运公式 / z-识别
        mech = {m: transport_formula(m, src_domains, target, self.D)
                for m in transportable}
        return mech, inv_test

    def _invariance_test(self, src_domains, mechanism_ids, contrast_engine):
        stats = []
        for m in mechanism_ids:
            cc = contrast_engine.run(m, domains=src_domains)   # 源域配对对比
            stats.append(cc.invariance_stat)                  # 域间效应异质性
        return InvarianceTest(stats, alpha=self.alpha)

    def certify(self, inv_test, target, predicted_gain, overlap, sensitivity):
        ok = (inv_test.pvalue < self.alpha
              and overlap >= O_MIN
              and sensitivity <= B_MAX
              and lower_confidence_bound(predicted_gain) > ETA_NET)
        return TransferCertificate(
            inv=inv_test, overlap=overlap, sens=sensitivity,
            gain=predicted_gain, accepted=ok,
            src=inv_test.contrast_ids)          # 证书必须绑定对比来源

class PairedContrastEngine:
    def __init__(self, strata_key, washout=5, intf_max=0.02, alpha_neg=0.05):
        self.key, self.washout = strata_key, washout
        self.intf_max, self.alpha_neg = intf_max, alpha_neg

    def run(self, module, domains=None, mode='paired'):
        if mode == 'paired':
            pairs = match_pairs(self.observations, module, self.key)
            assign = randomized_assignment(pairs)          # 定义 557
            delta = paired_difference(pairs, assign)
            design = 'RCT-paired'
        else:                                              # switchback

            delta = switchback_difference(blocks)
            design = 'switchback'
        neg = self._negative_control_test(module, mode)    # 定义 559
        cc = ContrastCertificate(
            balance=balance_check(pairs_or_blocks),

# IP-369 HierarchicalNormTransfer
class HierarchicalNormTransfer:
    def __init__(self, global_prior, culture_prior, kappa):
        self.theta0, self.Sigma_c, self.kappa = global_prior, culture_prior, kappa

    def adapt(self, family_id, evidence):
        n = evidence.n
        lam = n / (n + self.kappa)                       # 定义 561 部分池化
        mu = self.Sigma_c.posterior_mean(family_id)
        post = lam * evidence.mean + (1 - lam) * mu      # 只池化均值/先验
        if discrepancy(post, evidence) > DELTA_CONFLICT:
            return post, Gate('conservative')            # 冲突超阈则降门
        return post, Gate('transfer')

    def hard_norm_threshold(self, nu, target_evidence):
        # 硬规范阈值永不迁移：取目标证据保守上界与源域约束的更严者
        return stricter(nu.source_threshold,
                        conservative_bound(target_evidence, nu))


# IP-370 NegativeControlMonitor：共享 H 告警
class NegativeControlMonitor:
    def __init__(self, w1=1.0, w2=2.0, lam_H=1.5):
        self.w1, self.w2, self.lam_H = w1, w2, lam_H

    def diagnose(self, cc_norm, cc_task):

              self.w2 * (sign(cc_norm.delta) != sign(cc_task.delta))
        return HAlarm(active=(lam > self.lam_H), score=lam)


# IP-371 TransferCertifiedPlanner：迁移门 + v10 NCP
class TransferCertifiedPlanner:
    def __init__(self, ncp, tme, hnt, pce, ncm):
        self.ncp, self.tme, self.hnt = ncp, tme, hnt
        self.pce, self.ncm = pce, ncm

    def plan(self, state, belief, target_domain, delta_dom, tau_dom, trust_ok):
        # 0) 迁移门：先决定三态
        tc = self.tme.certify_for(target_domain, state)
        g = gate(tc)
        if g == 'local':
            return self.ncp.plan(state, belief, delta_dom, tau_dom, trust_ok)
        if g == 'conservative':
            belief = self.hnt.conservative_belief(belief)     # 硬约束取并集
        else:
            belief = self.hnt.transfer_belief(belief, target_domain)
        # 1) v10 NCP 规划（物理/接触证书 + 规范盾 + 因果评分）
        chunk = self.ncp.plan(state, belief, delta_dom, tau_dom, trust_ok)
        # 2) 共享 H 告警：命中则暂停自动迁移/休眠，转认知恢复
        cc_n = self.pce.run('NGE', domains=[target_domain])
        cc_t = self.pce.run('CWM', domains=[target_domain])
        alarm = self.ncm.diagnose(cc_n, cc_t)
        if alarm.active:
            return self.ncp.nge.epistemic_recovery(), alarm
        return chunk, alarm

## 3. 推导

**引理 96（配对对比去混杂与方差缩减）** 设配对层内可交换（I1）且 H 在配对内取常数。则配对差分 Δ_pair 是 ACE_m 的无偏估计，且 H 在差分中精确消去；若平行趋势违背量为 δ_pt，则 |E[Δ_did]−ACE_m|≤δ_pt。又若配对结果相关系数为 ρ，则
```
Var(Δ_pair) = 2σ²(1−ρ) ≤ 2σ² = Var(Δ_unpaired)
```
故达到同等功效所需样本量降至 1/(1−ρ) 分之一。证明：配对内 E[Y_i(1)−Y_i(0)|pair]=ACE_m，常数 H 在两项相减时抵消；DiD 的偏差项由平行趋势违背直接展开得上界；方差按两变量差的标准公式并利用相关系数即得。∎

**引理 97（负对照的检出力与误报控制）** 设负对照 Y^neg 对治疗 A 因果零效应、与 H 的关联强度为 β_H。在无 H 破坏时，负对照检验的误报率 ≤α_neg；在 H 破坏使配对偏差达到 β_H 时，检验功效 ≥ 1−Φ(z_{1−α_neg} − β_H/σ_neg)。因此只要 β_H/σ_neg 足够大，共享混杂必然以 ≥1−β 的概率触发 Ĥ_alarm。证明：由 (N1) 原假设下统计量分布得误报率；由 (N2) 的效应量与正态近似得功效；定义 559 的告警为单侧检验。∎

**引理 98（迁移证书的误差界）** 若 TC 有效：机制 M 在源域集上不变、目标支撑重叠 Ô≥o_min、敏感性界 B̂_Γ、且源域对比为配对 RCT/switchback。则目标域预测风险满足
```
Err_{e'}(TME) ≤ Err_{E_src}(TME) + C·(1−o_min) + B̂_Γ + O(√(log(1/δ)/n))
```
其中 C 只依赖机制族的 Lipschitz 常数，**不显式含 Δ_dom**。证明：由定义 554 的机制不变性，P(Y|do(a),pa) 跨域相同；由定义 555 的搬运公式，域间差异只通过 P(pa) 进入，其影响由支撑重叠项控制；未观测混杂由敏感性界覆盖；有限样本由标准泛化界覆盖。相加即得。∎
**推论 98.1**：v10 的黑箱 F̂ 的误差界随 Δ_dom 增长，而 TME 的界不随 Δ_dom 显式增长——这正是把 v10"域越陌生、预测越错"的风险，转成"只要机制不变且支撑重叠，误差就可控"的可证伪命题；若 E590 中机制不变性检验失败，则该命题被数据否决，门自动降级。

**引理 99（无负迁移保证）** 在定义 562 的迁移门下，若 g=transfer 只在 LCB(Ĝ)>η_net>0 时启用，且 HNT 只池化均值/先验、硬规范取更严者，则对任意目标域
```
E_{e'}[R_target(TCC)] ≤ E_{e'}[R_target(v10-local)] + ε_gate
```
且不可能出现"迁移后显著更差"的灾难性负迁移（概率 ≥1−δ，ε_gate 为门估计误差）。证明：g=transfer 要求净增益下置信界为正，故期望增益为正；g=conservative 只用更严的硬约束与保守包络，不改善也不放宽安全集；g=local 与 v10 逐位相同。部分池化的收缩估计均方误差不超过"只用源域"或"只用目标域"两者中的较优者在 O(1/√(n_h)) 内（标准层级贝叶斯收缩性质）。三者取并即得。∎

**引理 100（分层规范迁移的适应界）** 在定义 561 的层级模型下，若目标家庭真实参数距文化先验的距离为 d，则部分池化后验的估计误差满足
```
E‖θ̂_h − θ_h‖² ≤ (κ/(n_h+κ))·d² + σ²/(n_h+κ)
```
适应回合数 T_adapt = O(log(1/ε))，且当 d² 超过迁移门阈值时自动降为 conservative/local。证明：标准层级贝叶斯偏差-方差分解；收缩权重 λ=n/(n+κ) 使偏差项按 (1−λ)² 衰减、方差项按 λ²/n 衰减，取 n 使得两项均 ≤ε 得 T_adapt。冲突检测由定义 561 的 discrepancy 阈值触发。∎

**引理 101（共享 H 的可检测化）** 设 v10 中规范通道与任务通道共享 H，其在各自归因上的偏差为 B_norm、B_task。若使用定义 559–566 的配对对比、负对照与跨通道一致性诊断，则当 |B_norm|+|B_task| ≥ B_H^* 时，以下至少之一以概率 ≥1−β 发生：(i) 负对照显著；(ii) 两通道效应异号。因而 v10 的"沉默共错"被转化为可告警事件；在无 H 共错时误报率 ≤α_neg+α_cross。证明：若两通道偏差同源同向，则由 (N2) 负对照必然继承该偏差并触发 (i)；若两者在参数上被 H 推向相反方向，则触发 (ii)。两种情形的检验由引理 97 给出功效；无误报由两个单侧检验的水平相加（Bonferroni）控制。∎

**引理 102（中立元退化等价 v10）** 将定义 564 的四个中立元分别注入 TME/TC、PCE/CCtr、HNT、NCM 端口，则 TCP 的迁移门恒为 local、归因退回 c_m^obs、先验退回平坦先验、告警恒 0，主闭环调用序列与 v10 逐位一致（仅调度顺序可交换）。证明：local 门直接调用 v10 NCP；PCE 中立元即 v10 CAE；HNT 中立元即 v10 平坦先验；NCM 不改变任何输出。四端口互不相交，逐端口代入即得 v10 程序，再由 v10 引理 93 继续退回 v9/v8/v7。∎

**引理 103（预算守恒）** 新增在线成本上界：PCE 配对匹配与估计 ≤0.4ms（每 T_abl 一回合，均摊 ≤0.1ms）；TC 在离线/低频计算，在线查表 ≤0.02ms；HNT 后验更新 ≤0.05ms；NCM 交叉诊断 ≤0.05ms；TCP 门控 ≤0.05ms。决策侧合计 p99 仍 ≤20ms，50Hz 保持。证明：逐项代入复杂度并做静态 EDF 校验 ΣŴ_m≤B_dec 即得。∎

**引理 104（安全继承与无绕过）** v11 的执行管线为"v10 物理/接触/规范证书 → 迁移门（删除或保守化） → v10 NCP 因果评分"。迁移门只能把候选集**缩小**或把约束**收紧**；PCE 只改归因字段、不改执行；HNT 只改信念先验、不改硬规范盾；NCM 只可能触发 a_ask（其本身由 v10 定义 544 保证安全）。因此不存在绕过 v10 适用证书的执行路径，v10 引理 95 的物理/接触/规范安全在 v11 继续成立。∎

## 7. 已知风险与失效模式

1. **不变机制假设失效**：源域与目标域的"共享机制"可能只是巧合相关；负迁移由此发生。缓解：选择图显式声明、源域对比实验检验、TC 拒迁、E589/E591 专项。
2. **配对可交换性被破坏**：真实部署中存在时间耦合、携带效应与 SUTVA 违背，配对差值可能残留 H。缓解：switchback + 洗脱窗 + 干扰界 + 负对照；不通过只降置信不迁移。
3. **负对照选择错误**：若 Y^neg 实际受治疗影响（排他性失败），告警会误报或漏报。缓解：多负对照、排他性的人工审计、E597 校准。
4. **证书互相背书**：TC 用源域对比、源域对比又假设机制不变，形成循环论证。缓解：TC 必须绑定**独立**的对比来源与负对照；源域与目标域各留一份留出对比；E601 专门构造"证书自洽但事实错误"的场景。
5. **分层先验负迁移**：文化先验本身带偏见，部分池化会把偏见注入新家庭。缓解：硬规范不迁移、冲突检测降门、保守上界、人工审核。
6. **样本与功效不足**：配对对比在小样本下层内可交换性无法验证。缓解：预注册功效分析、合并层、报告敏感性界、必要时只用观测性结论。
7. **算力与实时性**：PCE/TC 若在线全量运行会挤占预算。缓解：PCE 每 T_abl、TC 离线/低频、静态 EDF 校验、缓存搬运表。
8. **评测协议污染**：配对设计若与训练数据重叠，会高估迁移收益。缓解：留出家庭/文化/本体，预注册切分，E606 跨 ≥5 家庭。

## 8. 本轮最大风险

**一句话**：配对对比的可交换性会被真实部署中的时间耦合与携带效应破坏，而源域到目标域的"不变机制"假设又可能同时失效，于是迁移证书与对比证书**互相背书**，把负迁移认证成正迁移——即**在错误的域上做了正确的实验，并为错误的迁移盖章**。
