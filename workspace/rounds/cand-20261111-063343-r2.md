# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 2 轮；本轮灵感：「轻量化结构」×「对话管理」）

> 第 54 轮把技能组合推进到「动作空间剖面 + 动作-鲁棒性双证书」，但留下三处硬伤：组合图与证书随 `|A_c|·|A_e|` 膨胀、证书在云边带宽上传不动、单轮 `Explain` 只能否决不能澄清。本轮把证书从「全量、单轮、被动」推进到「轻量、多轮、主动协商」。核心矛盾：**H22**：`α_S` 与 `ρ` 的全量证书体积爆炸，压缩后低秩近似会抹平动作覆盖边界，产生**虚假兼容（compression artifact）**；**H23**：云边与人机之间存在意图/语义不确定性，单轮否决既无法定位歧义、也无法请求补采样，只能二选一：过度保守或带错执行。

## 0. 直觉与动机

**灵感 1（轻量化结构 → 把证书从「张量」压成「结构基 + 稀疏残差」）**
直觉：动作剖面 `α_S : A_c × A_e → [0,1]` 看似巨大，但技能在动作空间上的占用高度结构化：沿粗动作方向近似分段常值、沿细动作方向近似平滑。因此 `α_S ≈ U_S V_S^T + R_S`，`U_S∈ℝ^{|A_c|×r}`、`V_S∈ℝ^{r×|A_e|}`、`R_S` 稀疏。证书体积从 `O(|A_c||A_e|)` 降到 `O(r(|A_c|+|A_e|)+k)`。鲁棒谱同理：多个技能的 `ρ` 共享一组**鲁棒原语字典** `D`，只传稀疏系数 `c_S`。这直接缓解第 54 轮的「组合图规模爆炸」与「云边带宽」风险。

**灵感 2（轻量化是有损的 → 必须把压缩误差写进判据）**
直觉：低秩 + Top-k 稀疏会在覆盖边界附近产生「抹平/过冲」，使 `compat` 被高估。若仍用 `compat ≥ θ_a` 判定，就会把「压缩出来的兼容」误当真实兼容。正确做法是：**先给压缩兼容性一个误差上界 `ε_c`，再用下界 `compat_lb = compat_hat - ε_c ≥ θ_a` 作保守判定**。轻量化的代价被显式转成「更保守的可行域」，而不是偷偷放宽。

**灵感 3（对话管理 → 把 Explain 从单轮信号升级为多轮协商）**
直觉：云边协同不应是一次性的「云端下计划、边端否决」。把它建模成**有信念状态的多轮对话**：`b_t = (β_t, δ_t, ν_t, g_t)` 分别为意图分布、动作对齐误差、鲁棒性亏空、接地下置信度。对话动作 `a_dm ∈ {EXEC, CLARIFY_H, NEGOTIATE_E, RESAMPLE, ABORT}`。边端发现覆盖缺口时，不再直接 reject，而是发起 `RESAMPLE` 请求局部补采样；歧义时云端向人发起 `CLARIFY_H`；语义不一致时用 `NEGOTIATE_E` 对齐本体。这把第 54 轮「Explain 回传导致震荡」从根上改成**有状态的收敛过程**（hysteresis 由信念平滑天然给出）。

**灵感 4（对话即主动学习 → 用轮次换证书精度）**
直觉：轻量证书的误差不是均匀的，而是在高频动作区/边界区更大。对话提供了一条**按需局部加密**的通道：每一轮 `RESAMPLE` 只在当前信念最不确定的动作子域上降低 `ε_α`，而不是全局重采样。于是「压缩率、对话轮次、时延预算」形成可调三角：带宽越紧 → 证书越轻 → 不确定性越高 → 需要更多对话轮次，但每轮只做局部精化，整体仍可能满足 `τ_loop`。

**灵感 5（澄清不是免费 → 用信息价值门控）**
直觉：多轮对话会带来澄清疲劳与累计时延。只有当澄清的**信息价值 `VoC` 为正**且轮次预算未耗尽时才发问。这把「对话管理」落到可判定的策略上：`EXEC / CLARIFY / NEGOTIATE / RESAMPLE` 由 `b_t` 与 `VoC` 共同决定，避免「为对话而对话」。

**灵感 6（金字塔扩层 → 轻量-对话层 `ℂ`）**
直觉：在第 54 轮 `𝔸`（动作协同层）之上再叠一层 `ℂ`：`ℂ_0` 原始证书、`ℂ_1` 轻量结构证书、`ℂ_2` 对话信念、`ℂ_3` 对话-鲁棒联合契约。跨层传递必须同时满足**压缩预算 `B_cert`** 与**对话轮次预算 `K_turn`**，形成「带宽-精度-澄清」三预算约束。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（轻量化结构证书 LSC）**
对技能 `S`，动作剖面 `α_S` 的轻量证书 `S(α_S) = (U_S, Σ_S, V_S, R_S)`，其中 `U_S Σ_S V_S^T` 为秩 `r` 近似，`R_S` 满足 `‖R_S‖_0 ≤ k`。证书体积
```
|S(α_S)| = r(|A_c| + |A_e|) + k
```
重建误差 `ε_α(S) = ‖α_S - S(α_S)‖_F / ‖α_S‖_F`。鲁棒谱用共享字典 `D` 压缩：`ρ_S ≈ D c_S`，`‖c_S‖_0 ≤ k_ρ`。**可接受证书**需同时满足 `|S| ≤ B_cert` 且 `ε_α ≤ ε_max`，否则进入对话补采样。

**定义 122（压缩感知兼容性 CACE）**
由轻量证书计算的兼容性 `ĉ(S_i,S_j) = Jaccard(S(α_i), S(α_j))`。存在误差上界
```
|ĉ(S_i,S_j) - compat(S_i,S_j)| ≤ ε_c(ε_i, ε_j, r, k)
```
**保守判定**：仅当 `compat_lb = ĉ - ε_c ≥ θ_a` 时才允许组合；`compat_lb < θ_a ≤ ĉ` 的灰区不直接拒绝，而是进入 `RESAMPLE / NEGOTIATE_E` 对话分支。

**定义 123（对话状态 / 信念）**
`b_t = (β_t, δ_t, ν_t, g_t)`：
- `β_t ∈ Δ(Intent)` 任务意图后验；
- `δ_t` 动作对齐误差的估计（含压缩误差 `ε_c`）；
- `ν_t = Σ_d max(0, ρ_min(d) - ρ_t(d))` 鲁棒亏空；
- `g_t ∈ [0,1]` 云边/人机本体接地置信度。
更新 `b_{t+1} = τ(b_t, o_t)`，`o_t` 来自边端仿真结果、人回答或局部重采样。

**定义 124（对话动作与轻量策略）**
`a_dm ∈ {EXEC, CLARIFY_H, NEGOTIATE_E, RESAMPLE, ABORT}`。策略 `π_dm : b_t → a_dm` 必须可在边端运行，故限制为**决策表 / 深度 ≤ 3 的小决策树**（叶子数 `≤ L`），其规模本身计入 `B_cert`。

**定义 125（澄清信息价值 VoC）**
```
VoC(b) = max_a E_{b'|ask}[U(a|b')] - max_a E_b[U(a|b)] - λ_c·cost(ask) - λ_τ·E[τ_turn]
```
仅当 `VoC(b) > 0` 且剩余轮次 `> 0` 时允许 `CLARIFY_H / NEGOTIATE_E / RESAMPLE`，否则退化为保守 `ABORT`。

**定义 126（对话-鲁棒联合契约 DRCC）**
`C_dr = (b_t, π_dm, S(α), S(ρ), γ_g, Δ_cert, K_turn, τ_turn)`，其中 `γ_g` 为共享本体接地映射。**可部署条件**：
```
dom = in  ∧  compat_lb ≥ θ_a  ∧  δ_t + ε_c ≤ Θ_a
          ∧  ρ_lb ≥ ρ_min       ∧  g_t ≥ θ_g       ∧  K_turn > 0
```

## 2. 关键算法 伪代码

### IP-121 LSC（Lightweight Structural Certificate）

```python
def compress_profile(alpha, r, k, B_cert, eps_max):
    U, S, Vt = truncated_svd(alpha, rank=r)
    R = alpha - U @ diag(S) @ Vt
    R = topk_sparse(R, k)                 # 保留 k 个最大残差元
    sketch = LSC(U, S, Vt, R)
    eps = fro_norm(alpha - sketch.reconstruct()) / fro_norm(alpha)
    if sketch.size() > B_cert or eps > eps_max:
        return None, eps                 # 不可接受 → 触发局部 RESAMPLE
    return sketch, eps

def compress_spectrum(rho, D, k_rho, B_cert):
    c = orthogonal_matching_pursuit(rho, D, k_rho)
    return SparseSpectrum(D, c, size=k_rho)
```

### IP-122 CACE（Compression-Aware Compatibility Estimation）

```python
def compat_lower_bound(sk_i, sk_j, theta_a):
    chat = jaccard(sk_i.sketch, sk_j.sketch)
    eps_c = bound_from_errors(sk_i.eps, sk_j.eps, r, k)
    lb = chat - eps_c
    if lb >= theta_a:
        return 'compatible', lb
    if chat + eps_c < theta_a:
        return 'incompatible', lb
    return 'gray', (chat, eps_c)          # 灰区交给对话管理
```

### IP-123 DST（Dialogue State Tracker）

```python
def update_belief(b, observation):
    beta = bayes_update(b.beta, observation.intent_likelihood)
    delta = kalman_like(b.delta, observation.alignment_residual)
    nu = max(0.0, b.nu - observation.robust_gain)
    g = grounding_update(b.g, observation.ontology_match)
    return Belief(beta, delta, nu, g)
```

### IP-124 DMP（Lightweight Dialogue Management Policy）

```python
def dialogue_policy(b, K_turn, tau_left, theta_g):
    if b.g < theta_g:
        return 'NEGOTIATE_E'
    if b.delta + b.compression_err > THETA_A:
        return 'RESAMPLE' if voc(b, 'RESAMPLE') > 0 else 'ABORT'
    if entropy(b.beta) > H_INTENT and K_turn > 0:
        return 'CLARIFY_H' if voc(b, 'CLARIFY_H') > 0 else 'EXEC_CONSERVATIVE'
    if b.nu > 0:
        return 'RESAMPLE' if tau_left > TAU_MIN else 'ABORT'
    return 'EXEC'
```

### IP-125 DGR（Dialogue Grounding）

```python
def ground(coarse_act, ontology_c, ontology_e):
    cand = match(ontology_c, coarse_act, ontology_e)
    if cand.confidence < THETA_G:
        return 'NEGOTIATE_E', cand.disambiguation_question
    gamma_g = bind(coarse_act, cand)
    return 'GROUNDED', gamma_g
```

### IP-126 DRCC（Dialogic-Robust Certificate Check）

```python
def drcc_certify(skill_seq, b, pi_dm, K_turn, gamma_g):
    sketches = [compress_profile(s.alpha, r, k, B_cert, EPS) for s in skill_seq]
    if any(sk is None for sk, _ in sketches):
        return 'RESAMPLE', worst_region(skill_seq)
    for si, sj in adjacent_pairs(skill_seq):
        verdict, lb = compat_lower_bound(si, sj, THETA_A)
        if verdict == 'incompatible':
            return 'REJECT', (si.id, sj.id, lb)
        if verdict == 'gray':
            return 'NEGOTIATE_E', (si.id, sj.id, lb)
    if b.delta + max_eps(sketches) > THETA_A:
        return 'CLARIFY_H', b.delta
    rho_lb = compose_spectrum_lower_bound([s.rho for s in skill_seq], D)
    if min(rho_lb.values()) < RHO_MIN or b.g < THETA_G:
        return 'ABORT', (rho_lb, b.g)
    return 'EXEC', DRCC(b, pi_dm, sketches, gamma_g, K_turn)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| LSC | O(\|A_c\|\|A_e\|·r) | O(r(\|A_c\|+\|A_e\|)+k) | 截断误差可界、Top-k 残差可控 |
| CACE | O(r(\|A_c\|+\|A_e\|)+k) | O(1) 额外 | `ε_c` 上界 sound、灰区不误判 |
| DST | O(\|Intent\|+\|𝔇_ρ\|) | O(\|Intent\|+\|𝔇_ρ\|) | 贝叶斯更新校准 |
| DMP | O(L) 查表 | O(L) | 策略规模 ≤ L、VoC 门控 |
| DGR | O(\|O_c\|·\|O_e\|) | O(\|O_c\|+\|O_e\|) | 接地置信阈值 |
| DRCC | O(\|S\|²·r(\|A_c\|+\|A_e\|)) | O(\|S\|·\|A_c\|) | 三预算闭合、保守判定 |

**正确性定理（Lightweight Dialogic Deployment Soundness）**
承接第 54 轮 (A26)–(A28)，新增：**(A29)** 轻量证书重建误差 `ε_α ≤ ε_max` 且压缩兼容误差界 `ε_c` 正确；**(A30)** 对话策略 `π_dm` 校准（ECE `≤ ε_π`），单轮时延 `≤ τ_turn`；**(A31)** 接地置信 `g_t ≥ θ_g` 时本体映射无系统性错配。
则部署成功概率满足
```
P_success ≥ 1 - Σ_d(1-ρ_min(d))
             - P(ε_c > Θ_c)
             - P(δ_t + ε_c > Θ_a)
             - ε_π
             - P(K_turn = 0)
             - (1 - g_t)
```
其中第一项为鲁棒性亏空、第二项为**压缩伪影导致虚假兼容**、第三项为动作对齐超预算、第四项为对话策略误判、第五项为对话预算耗尽、第六项为接地失败。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 低秩压缩抹平覆盖边界 → 虚假兼容 | 高 | 保守下界 `compat_lb` + 边界区局部重采样 + 压缩误差入证书 |
| 对话策略轻量化后校准漂移 | 高 | 决策表在线校准 + 置信门控 + 回退到保守 ABORT |
| 澄清疲劳 / 轮次爆炸 | 中 | VoC 门控 + 轮次预算 `K_turn` + 单轮只问最高信息量问题 |
| 多轮对话累计时延超 `τ_loop` | 高 | 局部重采样 + 异步对话 + 边端缓存锚点 |
| 接地漂移（粗/细本体错配） | 高 | 共享本体锚点 + 接地证书 `γ_g` + 周期性红队对齐 |

## 6. 本轮最大风险

**一句话**：轻量化结构证书与多轮对话管理把云边协同从「全量单轮否决」升级为「有损压缩 + 主动协商」，但 soundness 依赖**压缩误差界 `ε_c` 的保守性、对话策略的校准性、以及接地的无系统性偏差**；一旦压缩伪影把边界区的动作覆盖抹平、而对话又因接地错误无法纠正，系统会系统性地把「压缩出来的可对齐假象」当作部署前提，故必须以 **保守下界判定 + 边界局部重采样 + 接地锚点** 三重护栏，宁可多问一轮，也不拿有损证书赌真实动作空间。

```python
        g=grounding_update(b.g, obs.ontology_match))
```

### IP-124 DMP

```python
def dialogue_policy(b, K_turn, tau_left, theta_g):
    if b.g < theta_g:                                return 'NEGOTIATE_E'
    if b.delta + b.compression_err > THETA_A:
        return 'RESAMPLE' if voc(b,'RESAMPLE') > 0 else 'ABORT'
    if entropy(b.beta) > H_INTENT and K_turn > 0:
        return 'CLARIFY_H' if voc(b,'CLARIFY_H') > 0 else 'EXEC_CONSERVATIVE'

    return 'EXEC'
```

### IP-126 DRCC

```python
def drcc_certify(skill_seq, b, pi_dm, K_turn, gamma_g):
    sketches = [compress_profile(s.alpha, r, k, B_cert, EPS) for s in skill_seq]
    if any(sk is None for sk, _ in sketches):
        return 'RESAMPLE', worst_region(skill_seq)
    for si, sj in adjacent_pairs(skill_seq):
        verdict, lb = compat_lower_bound(si, sj, THETA_A)
        if verdict == 'incompatible': return 'REJECT', (si.id, sj.id, lb)
        if verdict == 'gray':         return 'NEGOTIATE_E', (si.id, sj.id, lb)
    if b.delta + max_eps(sketches) > THETA_A:
        return 'CLARIFY_H', b.delta
    rho_lb = compose_spectrum_lower_bound([s.rho for s in skill_seq], D)
    if min(rho_lb.values()) < RHO_MIN or b.g < THETA_G:
        return 'ABORT', (rho_lb, b.g)
    return 'EXEC', DRCC(b, pi_dm, sketches, gamma_g, K_turn)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| LSC | O(\|A_c\|\|A_e\|·r) | O(r(\|A_c\|+\|A_e\|)+k) | 截断误差可界，Top-k 残差可控 |
| CACE | O(r(\|A_c\|+\|A_e\|)+k) | O(1) | `ε_c` sound，灰区不误判 |
| DST | O(\|Intent\|+\|𝔇_ρ\|) | O(\|Intent\|+\|𝔇_ρ\|) | 贝叶斯更新校准 |
| DMP | O(L) | O(L) | `VoC` 门控、策略规模 ≤ L |
| DGR | O(\|O_c\|·\|O_e\|) | O(\|O_c\|+\|O_e\|) | 接地阈值 `θ_g` |
| DRCC | O(\|S\|²·r(\|A_c\|+\|A_e\|)) | O(\|S\|·\|A_c\|) | 三预算闭合 |

**正确性定理（Lightweight Dialogic Deployment Soundness）**
承接 (A26)–(A28)，新增 **(A29)** `ε_α≤ε_max` 且 `ε_c` 正确；**(A30)** `π_dm` 校准（ECE≤ε_π）且单轮 `≤τ_turn`；**(A31)** `g_t≥θ_g` 时本体映射无系统错配。则：
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - P(ε_c>Θ_c) - P(δ_t+ε_c>Θ_a)
             - ε_π - P(K_turn=0) - (1-g_t)
```
关键：**先压缩后保守判定**、**灰区交给对话**、**接地失败不执行**。

## 6. 本轮最大风险

**一句话**：轻量化结构证书与多轮对话管理把云边协同从「全量单轮否决」升级为「有损压缩 + 主动协商」，但 soundness 依赖**压缩误差界 `ε_c` 的保守性、对话策略的校准性、以及接地的无系统性偏差**；一旦压缩伪影把边界区的动作覆盖抹平、而对话又因接地错误无法纠正，系统会系统性地把「压缩出来的可对齐假象」当作部署前提，故必须以 **保守下界判定 + 边界局部重采样 + 接地锚点** 三重护栏，宁可多问一轮，也不拿有损证书赌真实动作空间。
