# 第 55 轮（研究线累计；本轮灵感循环第 1 轮；承接第 54 轮 v31 GroundEdge-GenSim+++；本轮灵感：「成功率」×「面部表情识别」）

> 第 54 轮给出了动作-鲁棒性联合证书 `J=(ρ,A_cert,γ_ce,δ_a)`，但成功率仍停留在最坏情况并集界 `P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a) - P(compat<θ_a)`。本轮以「成功率」为第一性量、以「面部表情识别（FER）」为方法迁移源，提出 **表达感知的成功率证书（Expression-Aware Success Certificate, ESC）**。核心矛盾：**H22**：并集界既可能为负、也不反映真实部署成功率；组合规划只做阈值判定，而聚合成功率会被任务混合比例（mix shift）欺骗——出现「每个表达子群都更差、总体却更好」的 Simpson 反转。**H23**：失败前兆是短时、低幅、类不均衡的「微表情」，现有 TRO/REX 只在失败后解释，缺少失败前的可观测表达通道；跨具身/跨任务的表达分布漂移让离线成功率外推失效。

## 0. 直觉与动机

**灵感 1（成功率不是布尔阈值，而是带区间的分层统计量）**
直觉：第 54 轮把成功率当成一个由 `ρ_min` 推出的**下界常数**，但真实部署关心的是「在这个任务混合、这个具身上，成功率大概多少、最坏多少」。FER 的第一课正是：不要只输出一个类别，而要输出**校准后的类别概率与置信区间**，并区分「模型置信」与「真实频率」。因此把成功率升级为 **逐表达类别的同时置信区间** `{[s_e^-,s_e^+]} `，用 Clopper–Pearson / anytime-valid e-process 给出频率派保证；并集界降级为「假设失效时的兜底」，而不是主指标。

**灵感 2（表达类别 → 任务表达单元 TAU，分层以对抗 Simpson）**
直觉：FER 不会把「微笑」和「惊讶」混成一个平均表情，因为平均会抹掉关键结构。任务成功率也一样：把任务按**任务表达单元（Task Action Unit, TAU）**——接触模式、抓取相位、运动基元、力曲线拐点等可观测原子签名——分成表达类别 `e`。成功率是 `(s_e, β_e)` 的混合：`s=Σ_e β_e s_e`。**只报 `s` 会把「换了一批更容易的任务」误判为「技能变强」**。所以组合门控必须逐层检查 `s_e^- ≥ θ_s`，并按目标部署混合 `β_T` 重加权比较。

**灵感 3（微表情 → 失败的 onset–apex–offset 预警）**
直觉：面部微表情的特点是**短时（<0.5s）、低幅、仅局部动作单元激活、类极度不均衡**；这几乎逐条对应机器人失败前兆：力曲线的一个小拐点、末端执行器的短暂停顿、关节误差的局部尖峰。FER 的时序建模（onset–apex–offset 三阶段、时序注意力、类不均衡重采样）可直接迁移为 **微表情失败识别器 MEFR**：在边端流式检测 `(t_on,t_apex,t_off,a)` 四元组，在失败发生前触发重剖分，而不是失败后解释。关键是给它**误报预算 η 与漏报预算 μ**，避免把噪声当预言。

**灵感 4（跨主体泛化 / 标签噪声 → 跨具身成功率校准）**
直觉：FER 最著名的失败是「跨主体/跨数据集掉点」——在源域校准好的阈值到新受试者就失效。成功率估计同样：在源具身/源任务上校准的区间，直接搬到新具身会系统性过自信。FER 的对策是**主体个性化校准 + 域泛化 + 对模糊样本用软标签**；对应到本框架：用目标具身的小样本做**逐具身校准**，用软成功标签（部分成功/降级成功）代替硬 0/1，并在无目标样本时**明确弃权（abstain）**，绝不外推。

**灵感 5（三元证书 → 在动作-鲁棒性双证书上叠加表达-成功率层）**
直觉：第 54 轮是 `(ρ, A_cert)` 双证书；本轮加第三根支柱 `S_cert` 与 `MEF_cert`，形成 **动作-鲁棒性-成功率三元联合证书 `J^+`**。金字塔新增 `𝕊` 层：`𝕊_0` 原始成败观测，`𝕊_1` TAU 表达分层，`𝕊_2` 分层成功率区间，`𝕊_3` 目标混合下的组合门控。跨层传递时三类证书必须同时成立，缺一即拒。

## 1. 形式化定义（增量：定义 121–128）

**定义 121（成功率泛函）**
给定策略/组合 `π`、任务上下文分布 `D`、表达类别 `e∈E`，逐层成功率与总体成功率为
```
s_e(π) = Pr_{x∼D | φ(τ(x))=e}[succ(π,x)]
s(π)   = Σ_{e∈E} β_π(e)·s_e(π),   β_π(e)=Pr_{x∼π}[φ(τ(x))=e]
```
**关键事实**：`s(π)` 只是 `(s_e,β_π)` 的混合，不能由 `s(π)` 反推任何 `s_e`。称 `Gap(π)=s(π)-min_e s_e(π)` 为**聚合-分层落差**。

**定义 122（任务表达单元与表达分层）**
任务轨迹 `τ` 上抽取 `m` 个任务表达单元 `U(τ)=(u_1,…,u_m)`，`u_j∈[0,1]` 为原子可观测签名（接触/抓取相位/运动基元/力拐点）。表达分层 `φ:𝒯→E` 由 `U` 经（软）聚类或标签分布学习得到；`β_π` 为表达分布。类比 FER 的 AU→表情类别映射。

**定义 123（成功率证书 SRCC）**
```
S_cert = (E, {[s_e^-,s_e^+]}_{e∈E}, 1-α, {n_e}_{e∈E}, β_π, ν)
```
其中 `Pr[∀e∈E: s_e∈[s_e^-,s_e^+]] ≥ 1-α`（**同时**覆盖），`n_e` 为类内校准样本数，`ν` 为有效性假设（类内可交换，或任意时间有效的 e-process）。单侧下界 `s_e^-` 是部署门控使用的量。

**定义 124（微表情失败事件 MEF）**
失败前窗口 `[t_f-Δ, t_f)` 内的三元组 `(t_on,t_apex,t_off)` 与幅度 `a`，谓词
```
MEF(x,t)=1  ⇔  U(x, t-Δ..t) 出现短时低幅异常 ∧ t_off-t_on ≤ δ_mef
```
检测器 `D_η=(f_θ, γ_η)` 在误报率 `≤η` 的操作点上工作，并要求漏报率 `≤μ`、检测延迟 `≤τ_mef`。

**定义 125（逐层可部署条件）**
组合 `S_1⊗…⊗S_k` 可部署当且仅当
```
∀e∈E: s_e^- ≥ θ_s  ∧  TV(β_π, β_T) ≤ ε_mix  ∧  MEFR 在线且 FAR≤η
```
其中 `β_T` 为目标部署表达混合。**注意：逐层条件严格强于聚合条件 `s^- ≥ θ_s`**，前者自动排除被 mix shift 抬高的伪优组合。

**定义 126（Simpson 安全）**
若存在组合 `A,B` 使 `s(A)>s(B)` 但 `∀e: s_e(A)<s_e(B)`，称发生 **Simpson 反转**。证书要求 (i) 逐层支配检查，或 (ii) 在共同 `β_T` 下重加权后再比较；禁止用各自 `β` 下的聚合值排序。

**定义 127（跨具身成功率迁移证书）**
```
T_cert = (s_src, s_tgt, W, κ, n_tgt, δ)
```
`W` 为源/目标表达分布的 Wasserstein-1（或 TV）距离，`κ` 为目标域校准映射。保证以概率 `≥1-δ`：
```
|s_tgt - κ(s_src)| ≤ f(W, n_tgt, δ)
```
`n_tgt=0` 时 `f=+∞`，**只能弃权**。

**定义 128（表达感知三元联合证书）**
```
J^+ = (ρ, A_cert, S_cert, MEF_cert, γ_ce, evidence)
```
部署条件：`dom_J(T)=in ∧ δ_a<Θ_a ∧ 定义125 成立 ∧ T_cert 未弃权`。`evidence` 需含：分层校准日志、MEF 操作点、目标混合估计、以及第 54 轮的动作/鲁棒性证据。

## 2. 关键算法 伪代码

### IP-121 SRCE（Success-Rate Calibration Estimator）

```python
def srce(streams, E, alpha, theta_s):
    # streams[e] = [0/1,...]，类内可交换；同时区间用 Bonferroni 拆分 alpha
    m = len(E)
    cert = {}
    for e in E:
        n = len(streams[e]); k = sum(streams[e])
        lo = beta_ppf(alpha/(2*m), k, n-k+1) if k > 0 else 0.0
        hi = beta_ppf(1-alpha/(2*m), k+1, n-k) if k < n else 1.0
        cert[e] = (lo, hi, n)
    ok = all(cert[e][0] >= theta_s for e in E)
    return ('ok' if ok else 'reject', cert)
```

### IP-122 EXS（Expression Stratifier / TAU）

```python
def expression_stratify(tracks, m_tau, K, use_soft=True):
    U = [extract_tau(tr, m_tau) for tr in tracks]
    if use_soft:
        q = label_distribution_model(U)      # 处理模糊/多标签表达
        E = soft_cluster(q, K)
    else:
        E = hard_cluster(U, K)
    beta = normalize(bincount(E))
    return E, beta, U

def mix_shift_guard(beta_pi, beta_T, eps_mix):
    return 'ok' if tv(beta_pi, beta_T) <= eps_mix else 'reject'   # 防 Simpson
```

### IP-123 MEFR（Micro-Expression Failure Recognizer）

```python
def mefr_update(state, tau_t, eta, tau_mef):
    state = temporal_encoder(state, tau_t)        # onset-apex-offset 编码
    thr = calibrate_threshold(state.val_stream, eta)  # 按误报预算定阈
    if state.score > thr:
        return ('warn', state.t_on, state.t_apex, state.score, state.delay)
    return ('quiet', state)
```

### IP-124 SRX（Success-Rate Transfer）

```python
def success_transfer(s_src_cert, target_streams, E, delta):
    if sum(len(v) for v in target_streams.values()) == 0:
        return ('abstain', 'no_target_evidence')       # 绝不无证据外推
    W = w1_distance(dist_source, dist_target)
    if shift_test(dist_source, dist_target) > eps_shift:
        return ('reject', 'expression_shift')
    s_tgt = per_class_calibrate(s_src_cert, target_streams, E)
    return ('ok', T_cert(s_src_cert, s_tgt, W, n_tgt=n_total, delta=delta))
```

### IP-125 ESC（Expression-Aware Success Certificate / 门控）

```python
def esc_gate(J, S_cert, mef, beta_T, theta_s, eps_mix):
    if J.domain != 'in' or J.delta_a > Theta_a:          # 第 54 轮条件
        return ('reject', 'action_or_robustness')
    if any(S_cert[e][0] < theta_s for e in S_cert):      # 逐层，非聚合
        return ('reject', 'stratum_below_threshold')
    if tv(S_cert.beta, beta_T) > eps_mix:                # 防 Simpson/mix shift
        return ('reject', 'mix_shift')
    if (not mef.online) or mef.far > eta:                # 预警通道必须健康
        return ('reject', 'mef_unavailable')
    return ('ok', JointCertPlus(J, S_cert, mef, min(S_cert[e][0] for e in S_cert)))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| SRCE | O(Σ_e n_e + |E|·log(1/α)) | O(|E|) | 同时覆盖、类内可交换/e-process |
| EXS | O(N·m + N·|E|) | O(N·m) | TAU 可识别、软标签校准 |
| MEFR | O(T·h) 流式 | O(h) | FAR≤η、延迟≤τ_mef、漏报≤μ |
| SRX | O(n_tgt·m + |E|²) | O(n_tgt·m) | 有目标证据、漂移可检出 |
| ESC | O(|E|) | O(|E|) | 继承第 54 轮 + 逐层门控 |

**正确性定理（Expression-Aware Success Soundness）**
假设：**(A29)** 每个表达类别的校准流与部署流类内可交换（或使用任意时间有效的 e-process）；**(A30)** 表达分层 `φ` 可识别，或 shift test 能拒绝不可识别情形；**(A31)** MEF 检测器满足 `FAR≤η`、`FNR≤μ`、延迟 `≤τ_mef`；**(A32)** 承接第 54 轮 (A26)–(A28)。
则对任一通过 `esc_gate` 的部署，以概率 `≥1-α`：
```
P(success | deploy) ≥ min_{e∈E} s_e^-  -  μ  -  P(δ_a > Θ_a)
```
且**不存在**被接受的组合在某表达层 `s_e^- < θ_s`；当 `β_π` 与 `β_T` 的 TV 距离超过 `ε_mix` 时直接拒部署，从而排除 Simpson 反转导致的误放行。
**与并集界的关系**：并集界 `1-Σ_d(1-ρ_min(d))` 不需要分布假设、但可能为负且通常很松；SRCC 是统计下界，在 (A29)–(A31) 下更紧、且永不为负。工程上取
```
LCB_used = max( union_bound ,  min_e s_e^- - μ )   （仅当 shift test 通过）
```
假设失效时回退到并集界并标红，绝不把统计区间冒充安全证书。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 表达类别不可识别 / 不稳定 | 高 | TAU 物理接地 + 分层稳定性检验 + shift test 拒绝 |
| 微表情是虚假相关 | 高 | 误报预算 + 干预试验（拔除前兆看失败是否消失）+ 绊线 |
| 校准流非平稳 | 高 | anytime-valid e-process + 滑窗重置 + 弃权 |
| 跨具身无目标证据 | 高 | 显式 abstain，禁止外推 |
| 聚合指标掩盖子群崩塌 | 中 | 逐层门控 + 按 `β_T` 重加权 + Simpson 审计 |
| 统计保证被误读为安全证书 | 高 | 统计界与最坏界分栏展示 + 并集界兜底 + 红队 |

## 6. 本轮最大风险

**一句话**：把成功率从「并集悲观界」升级为「表达分层的校准区间」在数学上更紧、更可用，但其有效性**同时押注于表达分层可识别、类内可交换、微表情前兆因果且跨具身可迁移**；一旦这些假设在真实部署中破裂，一个窄而漂亮的置信区间会造成 **「精确地错」的过度自信**，把原本松而安全的并集界换成紧而失效的统计界，诱导组合在 mix shift 下激进放行——因此必须以 **逐层门控 + 漂移检测 + 无证据弃权 + 并集界兜底 + 因果绊线** 五重护栏，宁可弃权，绝不把「表情像成功」当成「成功」。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim⁺⁺⁺⁺（SRCE×EXS×MEFR×SRX×ESC×SJC⁺）

> 承接第 54 轮产物 v31（ACS×SCOM×CEC×AEC×JTC）。本轮以「成功率」×「面部表情识别」为灵感，在**动作-鲁棒性双证书**之上加第三根支柱：**表达感知的成功率证书**。核心升级：
> - **SRCE（Success-Rate Calibration Estimator）**：把成功率从并集界升级为**逐表达类别的同时置信下界**；
> - **EXS（Expression Stratifier）**：用 **TAU（任务表达单元）** 做表达分层，显式对抗 Simpson 反转与 mix shift；
> - **MEFR（Micro-Expression Failure Recognizer）**：把失败前兆当作**微表情**（onset–apex–offset）做边端流式预警；
> - **SRX（Success-Rate Transfer）**：FER 式**跨具身校准**，无目标证据即弃权；
> - **ESC（Expression-Aware Success Certificate）**：逐层门控，拒绝聚合伪优；
> - **SJC⁺（Success-Aware Joint Certificate）**：三元联合证书 `J⁺=(ρ,A_cert,S_cert,MEF_cert,γ_ce)`。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-118/120 以纳入 `S_cert`。

```python
        hi = beta_ppf(1-alpha/(2*m), k+1, n-k) if k < n else 1.0
        cert[e] = (lo, hi, n)
    return ('ok' if all(cert[e][0] >= theta_s for e in E) else 'reject', cert)
```

```python
def esc_gate(J, S_cert, mef, beta_T, theta_s, eps_mix):
    if J.domain != 'in' or J.delta_a > Theta_a:
        return ('reject', 'action_or_robustness')
    if any(S_cert[e][0] < theta_s for e in S_cert):   # 逐层，绝不看聚合
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SRCE | O(Σ_e n_e + |E|log(1/α)) | O(|E|) | 同时覆盖 ≥1-α；e-process 任意时间有效 |
| EXS | O(N·m + N·|E|) | O(N·m) | TAU 可识别、软标签校准 |
| MEFR | O(T·h) 流式 | O(h) | FAR≤η、FNR≤μ、延迟≤τ_mef |
| SRX | O(n_tgt·m + |E|²) | O(n_tgt·m) | 有目标证据；漂移可检出 |
| ESC | O(|E|) | O(|E|) | 逐层门控，排除 Simpson 伪优 |

**正确性定理（Expression-Aware Success Soundness）**
假设 **(A29)** 类内可交换或 e-process；**(A30)** `φ` 可识别或 shift test 能拒绝；**(A31)** MEFR `FAR≤η, FNR≤μ, delay≤τ_mef`；**(A32)** 第 54 轮 (A26)–(A28) 成立。则任一通过 `esc_gate` 的部署，以概率 `≥1-α`：
```
P(success | deploy) ≥ min_{e∈E} s_e^-  -  μ  -  P(δ_a > Θ_a)
```
并且被接受组合满足 `∀e: s_e^-≥θ_s`，`TV(β_π,β_T)≤ε_mix`，故**聚合成功率无法掩盖任一子群崩塌**。
工程口径：`LCB_used = max(union_bound, min_e s_e^- - μ)`（仅当 shift test 通过）；假设失效时回退并集界并标红。

## 6. 本轮最大风险

**一句话**：本轮把成功率从「并集悲观界」升级为「表达分层的校准区间」，但它的 soundness **同时押注表达分层可识别、类内可交换、微表情前兆因果且跨具身可迁移**；一旦假设在真实部署中破裂，窄而漂亮的置信区间会造成 **「精确地错」的过度自信**，把松而安全的并集界替换为紧而失效的统计界，诱导组合在 mix shift 下激进放行——故必须以 **逐层门控 + 漂移检测 + 无证据弃权 + 并集界兜底 + 因果绊线** 五重护栏，宁可弃权，绝不把「表情像成功」当成「成功」。
