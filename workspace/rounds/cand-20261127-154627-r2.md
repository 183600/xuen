### 第 2 轮灵感驱动研究记录（语义地图 × 激光雷达 · v31 增量）

**灵感词**：语义地图、激光雷达

**直觉与动机**：

回看 v30 的 CADVS 证书链，它几乎是「本体感知 + 时间 + 视觉」的：IMU、编码器、视觉特征、证书时效。这些证书能回答「我现在稳不稳、证书新不新」，却回答不了一个更根本的问题——**我脚下的世界到底是什么**。而 KEMPC 的常识规则里，大量谓词（支撑面面积、可通行性、台阶高度、湿滑）本质上都是**关于外部世界几何与语义的断言**。没有外部证据，这些规则只能靠人工先验，既无法证伪，也无法判断何时失效。

激光雷达给几何，语义地图给类别与拓扑。两者合起来，第一次让「常识」可以被**接地（grounding）**：把抽象规则 φ_i 绑定到可测量的场景证据上。直觉上，这相当于在 KEMPC 的「规则层」与「控制层」之间插入一个**世界锚定层**：规则不再直接约束控制，而是先由 LiDAR + 语义地图生成一张「证据证书」，只有当证据足以支持该规则时才让它生效；证据不足时，宁可退回几何保守包络，也不让一条未被验证的常识规则去「保护」机器人。这与 v30 的证书思想一脉相承，但把证书的**证据来源**从本体扩展到了外部世界。

更细的三点直觉：

1. **语义-几何必须联合**：一条规则「支撑面积 > 200cm²」在语义地图上可能只是一个标签 `flat_ground`，但真正决定支撑面积的是 LiDAR 测得的地形法向与可落脚凸包。语义提供「这是什么」，几何提供「它到底多平、多高」。单用语义会「把地毯当平地」，单用几何会「把冰面当可落脚」——两者缺一不可。

2. **LiDAR 并非全知，退化必须显式建模**：长走廊、隧道、空旷大厅中，点到面约束在某个方向上退化（λ_min(H) ≈ 0），此时位姿沿该方向不可观测。若仍用退化方向的位姿去查询语义地图，会得到「看起来一致」的错误接地。因此必须把**退化方向证书**作为接地置信度的一个因子：退化方向上禁止做语义推理，而不是假装位姿可信。

3. **地图与在线雷达是共源的**：语义地图通常由同一批 LiDAR 离线构建。于是「在线 LiDAR 与地图一致」并不等于「与现实一致」——两者共享标定误差、共享被动态物体污染的历史、共享建图算法的先验。这是一种**共源相关失效**，交叉验证无法发现。必须引入**独立证据**（IMU/足端滑移、触觉、视觉材质）并显式建模证据相关性，否则会得到「两个证人其实是同一个人」的虚假确信。

**关键洞见**：语义地图 + LiDAR 不是给 KEMPC 再加一个传感器，而是把「常识」从**先验断言**转变为**可证伪假设**。每条 KC 规则都携带一张接地证书，证书包含证据值、残差、地图版本、退化方向与**证据独立性**。系统的安全性不再取决于规则写得多好，而取决于规则是否被充分且**独立地**接地。这把 v30 的「证书驱动」推进为「证据驱动」。

**形式化目标（增量）**：

1. 定义语义地图 M = (G_sem, {c_v, Σ_v}_{v∈V}, V_map, t_map)，及接地算子 G_φ: (M, P_lidar, T_pose) → (v_φ, γ_φ, r_φ, d_deg)。
2. 定义接地置信度 γ_i = q_sem · q_geo · q_map · q_obs · q_indep（五项因子相乘，AND 语义，保守）。
3. 定义 LiDAR 退化证书 LOC = (λ_1..λ_6, D_deg, r_align, ρ_inlier)，KC 规则 kc_lidar_obs。
4. 定义地图一致性证书 SMCC = (δ_sg, δ_geo, V_map, τ_stale)，超阈即降级为纯几何模式并触发重定位。
5. 定义接地感知 MPC（GAMPC）：约束按 a_i = σ((γ_i − γ_min)/τ) 软激活，低置信时切换到保守几何包络。
6. 定义证据独立性审计器 EIA：由证据相关矩阵 ρ 计算有效独立证据数 n_eff = n/(1+(n−1)ρ)。
7. 证明：在接地误差界 |v_φ − φ_true| ≤ ε(γ) 与证据独立性假设下，SEAL 执行集 ⊆ CADVS 执行集，且 false-safe 率不高于 v30。

**本轮最大风险**：**共源相关失效导致的「伪接地」**——语义地图与在线 LiDAR 同源，几何一致会掩盖语义错误（例如地图把湿滑冰面标为 `flat_ground`，LiDAR 也确认其平坦），两项「证据」高度相关，交叉验证给出虚假高置信；此时机器人会以「已被证书保护」的姿态走上最危险的地面，反而比没有语义地图时更危险，因为无地图时系统至少会保守减速。这是「证据独立性」缺失的系统性风险，无法靠继续增加同源传感器消除，只能靠独立物理探针与相关性感知的融合来缓解。

### IP-478 Semantic-Geometric Grounding Certificate (SGGC)

```python
@dataclass
class GroundingCertificate:
    """SGGC：把一条 KC 谓词 φ 接地到 (语义, 几何, 残差)，输出可证伪证书。"""
    pred_id: str                       # 谓词 ID，如 'kc_support_area'
    class_key: str                     # 相关语义类别，如 'flat_ground'
    b_i: float                         # 谓词阈值（支撑面积 200cm² 等）
    s_i: float                         # 残差归一化尺度
    gamma_min: float = 0.6
    tau: float = 0.05
    sigma_geo: float = 0.02            # 几何残差尺度（m）
    tau_map: float = 600.0             # 地图新鲜度时间常数（s）

    def ground(self, M: SemanticMap, P: PointCloud, T: Pose,
               loc: LOCCert, eia: EIAState) -> tuple[float, float, dict]:
        # 1) 语义支持：查询 T 邻域内节点的类别概率质量
        nbhd = M.query_neighborhood(T.translation, radius=0.6)
        p_cls = sum(node.c_v[self.class_key] * node.weight for node in nbhd)
        H_sem = normalized_entropy(aggregate_dist(nbhd))   # 语义不确定性
        q_sem = (1.0 - H_sem) * p_cls                       # 类别可信度

        # 2) 几何支持：仅用非退化方向上的点估计局部平面/凸包
        P_obs = remove_degenerate_dirs(P, T, loc.D_deg)
        slope, rough, support_area = fit_local_geometry(P_obs, T)
        v_phi = support_area                                # 谓词接地值
        r_phi = abs(v_phi - self.b_i) / self.s_i
        q_geo = exp(-(r_phi ** 2) / (2 * self.sigma_geo ** 2))

        # 3) 地图新鲜度：陈旧地图置信指数衰减
        q_map = exp(-max(0.0, (now() - M.t_map)) / self.tau_map)

        # 4) 可观测性：λ_min 越低越不可信；退化方向直接判 0
        q_obs = 0.0 if loc.D_deg else sigmoid(loc.lambda_min / loc.lambda_obs)

        # 5) 证据独立性：与 LiDAR 共源的语义源打折
        q_indep = eia.independence_factor(src_a='semantic_map',
                                          src_b='lidar_geometry')

        gamma = q_sem * q_geo * q_map * q_obs * q_indep
        a_i = sigmoid((gamma - self.gamma_min) / self.tau)
        eps = self.eps0 * (1.0 - gamma)
        return v_phi, gamma, {
            'pred_id': self.pred_id, 'value': v_phi, 'residual': r_phi,
            'q_sem': q_sem, 'q_geo': q_geo, 'q_map': q_map,
            'q_obs': q_obs, 'q_indep': q_indep,
            'gamma': gamma, 'activation': a_i, 'margin': eps,
            'map_version': M.V_map,
        }

    def cert_payload(self, v_phi, gamma, meta) -> dict:
        return {'cert_id': f'ground_{self.pred_id}', 'payload': meta,
                't_stamp': now(), 'validity_window': 0.2,
                'src_node': 'grounding'}
```

### IP-479 LiDAR Observability Certificate (LOC)

```python
@dataclass
class LOCCert:
    lambdas: np.ndarray                # 升序 6 个特征值
    eigvecs: np.ndarray                # 对应特征向量 (6x6)
    D_deg: list[int]                   # 退化方向索引
    r_align: float
    rho_inlier: float
    lambda_obs: float = 0.05           # 可观测性阈值（按量纲标定）

    @property
    def lambda_min(self) -> float:
        return float(self.lambdas[0])


def build_loc(P, T, correspondences, lambda_obs=0.05) -> LOCCert:
    """点到面 ICP 法方程特征分解 → 可观测性证书。"""
    H = np.zeros((6, 6))
    sq_err, n_in = 0.0, 0
    for (p_j, n_j, q_j) in correspondences:      # q_j 为地图面点
        J = np.concatenate([n_j, np.cross(p_j, n_j)])   # 1x6
        w = robust_weight(p_j, q_j, n_j)                # Huber/Cauchy
        H += w * np.outer(J, J)
        sq_err += w * (np.dot(n_j, p_j - q_j) ** 2)
        n_in += 1
    lambdas, eigvecs = np.linalg.eigh(H)         # 升序
    D_deg = [k for k in range(6) if lambdas[k] < lambda_obs]
    return LOCCert(lambdas, eigvecs, D_deg,
                   r_align=np.sqrt(sq_err / max(n_in, 1)),
                   rho_inlier=n_in / max(len(correspondences), 1),
                   lambda_obs=lambda_obs)


def kc_lidar_obs(loc: LOCCert, u_cmd: np.ndarray) -> tuple[bool, np.ndarray]:
    """KC 规则：若指令在退化方向有显著分量，则投影掉该分量并告警。"""
    if not loc.D_deg:
        return True, u_cmd
    u_safe = u_cmd.copy()
    for k in loc.D_deg:
        d = loc.eigvecs[:, k]
        proj = np.dot(u_cmd, d[:3] if u_cmd.shape[0] == 3 else d)
        u_safe -= proj * d
    return False, u_safe
```

### IP-480 Semantic Map Consistency Certificate (SMCC)

```python
@dataclass
class SMCC:
    """在线语义/几何 与 离线地图 的一致性证书；防陈旧与共源盲区。"""
    tau_stale: float = 120.0
    delta_sg_max: float = 0.25
    delta_geo_max: float = 0.05        # m（RMS 点-面距离）

    def check(self, M: SemanticMap, P_sem: PointCloud,
              T: Pose) -> tuple[bool, dict]:
        # 1) 语义不一致：逐点在线类别 vs 地图标签的加权混淆
        agree, total = 0.0, 0.0
        for p_j, c_j, conf_j in P_sem.classified_points():
            node = M.nearest_node(T.transform(p_j))
            if node is None:
                continue
            agree += conf_j * node.c_v[c_j]
            total += conf_j
        delta_sg = 1.0 - agree / max(total, 1e-9)

        # 2) 几何不一致：在线点到地图面的 RMS 距离
        d = point_to_surface_distances(P_sem, M, T)
        delta_geo = float(np.sqrt(np.mean(d ** 2))) if d else 0.0

        # 3) 新鲜度
        stale = (now() - M.t_map) > self.tau_stale

        ok = (delta_sg < self.delta_sg_max and
              delta_geo < self.delta_geo_max and not stale)
        return ok, {'delta_sg': delta_sg, 'delta_geo': delta_geo,
                    'stale': stale, 'map_version': M.V_map,
                    't_map': M.t_map}

    def cert_payload(self, ok, meta) -> dict:
        return {'cert_id': 'kc_map_consistent', 'payload': {**meta, 'ok': ok},
                't_stamp': now(), 'validity_window': 1.0,
                'src_node': 'smcc'}
```

### IP-481 Grounding-Aware MPC (GAMPC)

```python
def gampc_cost_and_constraints(x_traj, u_traj, ground_certs, geo_env):
    """在 KT-MPC 代价上叠加接地软约束；低置信时退化为几何保守包络。"""
    J = kt_mpc_cost(x_traj, u_traj)          # v30 原有代价（含十二证）
    cons = []
    for gc in ground_certs:
        a = gc['activation']
        eps = gc['margin']
        # 激活时收紧阈值（保守裕度）；未激活时以包络约束替代
        phi = gc['pred_value_fn'](x_traj)
        cons.append(a * (phi - (gc['b_i'] - eps)))          # 软 KC
        cons.append((1.0 - a) * envelope_slack(x_traj, geo_env))
        J += gc['lambda'] * a * relu(phi - gc['b_i'] + eps) ** 2
    return J, cons
```

### IP-482 Evidence Independence Auditor (EIA)

```python
@dataclass
class EIAState:
    """估计证据源相关矩阵，输出有效独立证据数与独立性折扣。"""
    rho_e: float = 0.0                 # 两源等效相关系数（在线估计）
    n_sources: int = 2

    def update(self, residuals_a, residuals_b):
        # 用残差序列的皮尔逊相关估计共源程度（滑窗）
        self.rho_e = float(np.clip(pearson(residuals_a, residuals_b),
                                   -1.0, 1.0))

    @property
    def n_eff(self) -> float:
        n, rho = self.n_sources, max(self.rho_e, 0.0)
        return n / (1.0 + (n - 1) * rho)

    def independence_factor(self, src_a: str, src_b: str) -> float:
        # n_eff 从 1（完全共源）到 n（完全独立）线性映射到 [0,1]
        if self.n_sources <= 1:
            return 1.0
        return float(np.clip((self.n_eff - 1.0) / (self.n_sources - 1.0),
                             0.0, 1.0))
```

### IP-483 Slip-Grounding Probe (SGP)

```python
@dataclass
class SlipGroundingProbe:
    """与视觉-几何独立的摩擦证据：IMU/足端滑移 + 触觉。"""
    mu_hat: float = 1.0
    slip_ratio: float = 0.0
    alpha: float = 0.1                 # 指数遗忘

    def update(self, imu, foot_contact):
        slip = detect_slip(imu, foot_contact)      # 0=无滑移，1=完全打滑
        self.slip_ratio = (1 - self.alpha) * self.slip_ratio + self.alpha * slip
        self.mu_hat = (1 - self.alpha) * self.mu_hat + self.alpha * mu_from_slip(slip)

    def friction_evidence(self) -> dict:
        # 独立于语义/几何；用于校准地图的 'flat_ground' 是否真的可落脚
        return {'mu_hat': self.mu_hat, 'slip_ratio': self.slip_ratio,
                'independent': True}
```

### SEAL 统一执行流（单步）

```python
def seal_step(robot_state, sensor_data) -> ControlOutput:
    """SEAL = Semantic-Exteroceptive Anchor Layer（v31 单步）。"""
    # 0) v30 证书聚合（十二证）仍为第一道闸
    cert_agg = wait_for_topic('/cert/aggregated', timeout=0.005)
    if cert_agg is None or not cert_agg.all_passed:
        return fallback_to_teacher(robot_state, sensor_data, reason='cert_agg_fail')

    # 1) LiDAR 配准 + 可观测性证书
    loc = build_loc(sensor_data.points, sensor_data.T, sensor_data.corr)
    if loc.D_deg and np.linalg.norm(loc.lambdas) < 1e-6:
        return fallback_to_teacher(robot_state, sensor_data, reason='lidar_degenerate')

    # 2) 地图一致性证书（防陈旧/动态污染）
    smcc_ok, smcc_meta = SMCC().check(sensor_data.map, sensor_data.points, sensor_data.T)
    if not smcc_ok:
        # 降级为纯几何模式：不用语义先验，仅保留几何包络
        return geometric_only_control(robot_state, sensor_data, B_geo())

    # 3) 逐谓词接地
    grounds = [g.ground(sensor_data.map, sensor_data.points, sensor_data.T,
                        loc, sensor_data.eia) for g in sensor_data.kc_grounders]

    # 4) 接地感知 MPC（低置信自动走保守包络）
    u_cmd, path = gampc_solve(robot_state, grounds, B_geo())

    # 5) 独立物理探针交叉校准（若与语义冲突，压置信并告警）
    fric = sensor_data.sgp.friction_evidence()
    if conflicts_with_semantics(fric, grounds):
        grounds = downweight(grounds, factor=0.5)
        path += '+sgp_conflict'

    return ControlOutput(u_cmd, path=path, certs=cert_agg, grounding=grounds)
```

## 4. 正确性论证（增量）

### 引理 32（接地误差界下的约束保守性）

**陈述**：设谓词真值 φ_true 与接地值 v_φ 满足 |v_φ − φ_true| ≤ ε(γ) = ε_0(1−γ)。若 GAMPC 采用收紧阈值 b_i − ε(γ) 执行约束 φ(x) ≤ b_i − ε(γ)，则实际满足 φ_true(x) ≤ b_i 的概率至少为 γ（在误差界成立的意义下）。

**证明**：由 φ_true ≤ v_φ + ε 且 v_φ ≤ b_i − ε，得 φ_true ≤ b_i。误差界 |v_φ−φ_true| ≤ ε 以概率 γ 成立（γ 为接地置信），故约束满足真值以概率 ≥ γ 成立。ε 随 γ 单调减，置信越高越不保守。∎

**工程含义**：`margin = ε_0(1−γ)` 直接实现了「不确定就多留裕度」；当 γ→0 时约束退化为「不可用」，触发几何包络。

### 引理 33（LiDAR 退化方向的可观测性下界）

**陈述**：在点到面残差为独立同分布零均值高斯（方差 σ²）的假设下，位姿估计误差协方差满足 Cramér–Rao 下界 Cov(T̂) ⪰ σ² H⁻¹。若 λ_min(H) < λ_obs，则存在方向 u_min 使 Var(⟨T̂, u_min⟩) ≥ σ²/λ_min > σ²/λ_obs，该方向位姿不可被证书保证。

**证明**：H 即 Fisher 信息矩阵，CRLB 为标准结论。对 H 特征分解 H = Σ λ_k u_k u_kᵀ，沿 u_k 的方差下界为 σ²/λ_k；λ_min 对应最大方差方向。λ_min < λ_obs 时该方向方差超过可接受上界。∎

**工程含义**：`D_deg` 就是「不可信位姿方向」；SGGC 用 `remove_degenerate_dirs` 剔除这些方向上的点，并在 q_obs 中直接置零，避免用退化位姿查询语义地图。

### 引理 34（共源证据的有效独立数）

**陈述**：设有 n 个方差相同（σ²）、两两相关系数为 ρ 的估计量，朴素逆方差融合的方差为 σ²/n；真实融合方差为 σ²(1+(n−1)ρ)/n。故朴素融合把不确定度低估了因子 (1+(n−1)ρ)，有效独立证据数为 n_eff = n/(1+(n−1)ρ)。

**证明**：等权平均 X̄ 的方差 Var(X̄) = (1/n²)Σ_i Σ_j Cov(X_i,X_j) = (1/n²)(nσ² + n(n−1)ρσ²) = σ²(1+(n−1)ρ)/n。与独立情形 σ²/n 相比即得低估因子；令 n_eff 使 σ²/n_eff = 真实方差，得 n_eff = n/(1+(n−1)ρ)。∎

**推论**：当语义地图由 LiDAR 建图（ρ→0.9）、n=2 时，n_eff ≈ 1.05——交叉验证几乎不提供独立信息。EIA 的 `independence_factor` 必须据此把 γ 打折，否则「地图与雷达一致」会变成伪证据。

### 定理（SEAL 执行集包含与 false-safe 率不增）

**陈述**：在以下假设下：
(A1) v30 十二证与 TCVM 时序条件成立（引理 31）；
(A2) LOC 正确识别退化方向（引理 33）；
(A3) 接地误差界 |v_φ−φ_true| ≤ ε(γ) 成立（引理 32）；
(A4) EIA 给出的证据相关估计不低估真实相关性（引理 34）；
则 (i) Exec_SEAL ⊆ Exec_CADVS ⊆ Exec_v29；(ii) 在 (A1)–(A4) 下，SEAL 的 false-safe 率不高于 v30。

**证明**：
- (i) SEAL 的每条新约束都以 a_i ∈ [0,1] 软激活，且当 a_i < 1 时由保守几何包络 B_geo 替代；B_geo 是 v30 教师/急停回退动作集的子集。SMCC 失败时直接走 `geometric_only_control`（B_geo 子集），LOC 严重退化时走教师兜底。故所有新增分支都不超出 v30 执行集。
- (ii) v30 仅凭语义标签（或人工先验）接受规则，无接地误差界；SEAL 要求 γ ≥ γ_min 才激活，并按 ε(γ) 收紧阈值。由引理 32，被激活约束以概率 ≥ γ 满足真值；由引理 34 与 (A4)，γ 不会因共源而高估。故「证书说安全但实际不安全」的概率不增。∎

**诚实声明**：(A3)(A4) 在部署中**并非恒真**。语义分割的分布外（OOD）样本、地图被动态物体污染、EIA 的相关估计滞后，都会让 γ 高估；此时定理退化为「有条件的正确性」。SEAL 用 SGP 独立探针、SMCC 陈旧检测与共源告警做运行时缓解，而非静态保证。

## 5. 实验设计（含预期趋势，非实测数据）

**平台**：Isaac Gym / Gazebo 仿真（含语义标签真值）+ 公开 SemanticKITTI / GO-SLAM 序列回放 + 四足实机（LiDAR+IMU+足端触觉）。

**基线**：v30 CADVS（无语义接地）；语义-only（直接信任地图标签）；几何-only（只用 LiDAR 局部几何）；SEAL（本文）。

**指标**：
1. false-safe 率：证书判「安全」但真值违反安全约束的比例（核心指标）。
2. 接地校准误差 ECE：γ 与「接地值落在误差界内」频率的一致性。
3. 退化检测 AUROC：LOC 对走廊/隧道/空旷场景的退化识别。
4. 地图陈旧检测延迟：动态障碍进入地图后 SMCC 报警所需时间。
5. 任务成功率 / 约束违规率 / 端到端 P99 延迟。

**预期趋势（待验证）**：
| 场景 | v30 false-safe | 语义-only | 几何-only | SEAL |
|---|---|---|---|---|
| 静态结构化室内 | 中 | 高（标签错） | 低 | 最低 |
| 长走廊/隧道（退化） | 中 | 高（位姿漂移） | 中 | 低 |
| 动态行人/移动物 | 中 | 高（烘进地图） | 低 | 低 |
| 湿滑/结冰（语义错） | 中 | 高（共源伪接地） | 中 | 中（SGP 缓解但不消除） |

**消融**：去掉 EIA（预期 false-safe 显著上升，尤其在共源场景）；去掉 LOC（退化场景失败）；去掉 SMCC（动态场景失败）；去掉 SGP（湿滑场景失败）。

**关键实验**：构造「地图与 LiDAR 一致但语义错误」的对抗场景（冰面标为 flat_ground、地毯标为硬地），专门测共源相关失效——这是本轮风险的核心验证。

## 7. 本轮最大风险（最终确认）

**一句话**：**语义地图与 LiDAR 的共源相关性会把「两个证人」退化成「一个人的两种说法」**——当语义地图本身由同一批 LiDAR 构建时，在线几何与离线语义的一致性并不构成独立证据；系统会因「几何确认 + 语义确认」而给出高接地置信，却对真正决定安全的物理属性（摩擦、承载、材质）一无所知。更隐蔽的是，这种失效在证书层面表现为「全部通过」，比 v30 的无语义保守更危险。缓解只能来自**独立物理探针（滑移/触觉）与相关性感知的融合（EIA）**，而这两者都只能覆盖接触面、且估计滞后，因此这是 SEAL 从「看起来可证伪」走向「真正可证伪」的生死线。
