# 第 47 轮（灵感循环 R2；承接第 46 轮 v23；本轮灵感：放置 × 持续学习） · Place-Cert × Continual-Cert：放置作为观测变更的因果闭环与持续学习下的时变证书可交换性维护（v11）

> 承接第 46 轮 v23 Memory-Safety-Voice 与第 45 轮 v10 Energy-Context-Depth。v23 把语音-记忆-安全绑定进全局决策，v10 把能量租约与深度门控纳入姿态证书，但共同隐含两个假设：**H5 放置是轨迹终点，放下物体不会改变后续感知的可观测性**；**H6 证书校准是离线的、模型参数在部署期冻结**。UniBot 的真实任务是反复 pick-and-place：每一次放置都会改变支撑面、遮挡与可达空间（放置既是“读世界”也是“写世界”）；而跨场景部署又要求在线持续学习新物体/新光照/新支撑面，任何一次梯度更新都可能破坏共形证书赖以成立的**可交换性（exchangeability）**。两个灵感词正击中 H5/H6：**放置**迫使我们把放置升级为带稳定性/容差/诱导遮挡的证书与观测变更算子；**持续学习**迫使证书从“一次性校准”升级为“版本化、时变、可回退”的持续认证。二者耦合成一个**内生的闭环分布漂移**：放置改变数据分布 → 持续学习改变感知模型 → 证书重新校准 → 又改变放置策略。核心新问题：**当放置本身会制造未见过的遮挡与支撑分布、而模型又在持续更新时，如何保证放置证书与姿态证书在任意时刻都不会“数值上有效、语义上失效”，并在漂移未被察觉时仍然 fail-closed。**

## 0. 直觉与动机

**灵感 1（放置 → 不是终点，而是观测变更）**
直觉：在 pick-and-place 里，place 常被当作轨迹终点与夹爪张开的那一刻。但物体一旦放下，世界几何就变了：把高杯放在相机与桌沿之间，会新增遮挡层、透明/镜面反射层与深度空洞；把物体放进抽屉会制造自遮挡与弱纹理。也就是说，放置不只是“读世界”，它还在“写世界”，直接改写下一轮姿态证书所依赖的可观测性分层 ω。若把放置只当奖励终点，就会在放置后把已经退化（甚至已失效）的观测当成仍然可信的输入。
定义化（详见定义 59–60）：放置证书 P^pl=(S,m_stab,C,T_tol,O^occ,τ_pl)，其 soundness 同时约束**物理稳定**（质心投影落在膨胀后的支撑多边形内、摩擦锥可行）与**最终位姿容差**；并把放置写成观测变更算子 Place，使可见域 V_{t+1}=H(V_t,O^occ) 与上下文 c_{t+1} 一起更新。放置是否可执行，取决于它是否落在**放置安全包络**内：诱导遮挡后仍需保留所有活跃租约所需的可观测性，否则必须先安排再观测（消耗能量租约）。

**灵感 2（持续学习 → 在线进化，但证书不能悄悄过期）**
直觉：部署期必须适应新物体、新光照、新支撑面，模型会持续微调。可是共形证书的 1−α 覆盖保证依赖校准集与测试样本**可交换**；每次梯度更新后，旧校准集已经不能代表新模型的误差分布。证书的“格式”仍然合法（阈值在、区间在），但它的“语义”可能已经错了——这是最危险的一类失效。
定义化（详见定义 61–62）：把模型序列 f_{1:K} 与证书内核版本 κ_t=(f 版本, 校准集版本, 阈值 q, 审计时间) 绑定；用自适应共形推断（ACI）在线更新 α_t，用 e-process/鞅做**任意时刻有效（anytime-valid）**的覆盖检验，用 CUSUM 做漂移检测；一旦拒绝覆盖假设或遗忘超界，就回退到上一个已认证内核 κ*，并使所有绑定旧 κ 的证书级联失效。关键不变量：**证书只有在其内核版本等于当前认证内核且未见漂移告警时才有效**。

**灵感 3（耦合 → 放置-学习是内生分布漂移的闭环）**
直觉：放置改变我们能看到什么，学习改变我们如何理解看到的东西，理解又改变我们敢把东西放在哪里。这是一个反馈回路。数据采集应当选择“既完成任务又能补证书盲区”的放置，但同一个选择也可能放大确认偏误：模型只在自己擅长的地方采集，盲区永远不被审计。
定义化（详见定义 63）：为放置动作定义双效用 U_pl(a)=任务收益 + λ_info·信息增益 − λ_e·能耗，并强制多样性约束 d(a,replay)≥δ_div 与独立审计集解耦；主动采集只负责“训练池”，审计集必须由独立放置分布生成，防止监控器与学习器共谋。

**耦合升级**：在 v10/v23 之上新增 **L5 持续认证层**（CL-CERT）与根信任层的证书内核版本 κ。ECPS 在每次放置后重算 Δ_vis 与模态效用并预留再观测能量；PSE 用放置后的可见域签发姿态证书；SAB/CAR 的联合守卫加入放置证书与内核版本一致性；DCL 从“被动回灌”升级为“主动放置采集 + 覆盖缺口优先 replay”；CCA 新增持续学习红队（replay 投毒、灾难遗忘、漂移逃逸、确认偏误）。

## 1. 形式化定义（增量：定义 59–63）

**定义 59（放置证书 P^pl 与稳定性）**
给定世界状态 X_t、抓取位姿 g、目标位姿 y 与深度观测，定义
P^pl=(S_t, m_stab, C_t, T_tol, O^occ_t, τ_pl)，
其中 S_t 为支撑多边形（按支撑面估计误差 ε_S 外膨胀），m_stab=dist(p_com,∂S_t)−ε_S 为稳定裕度，C_t 为接触集，T_tol 为最终位姿容差盒，O^occ_t 为放置诱导遮挡区，τ_pl 为租约有效期。
**放置 soundness**：若 m_stab≥m_min、C_t 满足摩擦锥条件且深度在目标区有效，则
Pr( 稳定 ∧ 最终位姿∈T_tol, ∀s∈[t,t+τ_pl] | P^pl, 感知 ) ≥ 1−α_pl。
**单调性**：ε_S 越大、m_min 越保守，soundness 越高但可放置区域越小（安全-能力权衡）。

**定义 60（放置诱导的观测变更算子）**
Place: X_{t+1}=T_pl(X_t)，可见域 V_{t+1}=H(V_t,O^occ_t, freed_t)，上下文 c_{t+1}=C(X_{t+1},V_{t+1})。
**放置诱导漂移**：Δ_vis(m)=D_TV( P(ω|c_{t+1},m), P(ω|c_t,m) )。
**放置安全包络**：P^pl 可执行当且仅当对每个活跃租约 o∈{ℓ_p,ℓ_e,ℓ_pl} 所需的可观测层 ω(o)，有 V_cert(ω(o))⊆V_{t+1}，或存在满足能量租约的再观测计划 R_t 使 V 在 τ_re 内恢复；否则拒绝该放置或转入保守姿态盒。

**定义 61（持续学习序列与时变覆盖）**
模型序列 f_{1:K}，分数 s_t=score(f_{κ_t},X_t,y_t)，预测集 P_t={y: s_t≤q_t}。
**ACI 阈值更新**：α_t=clip(α_{t−1}+γ(α−err_t), α_lo, α_hi)，q_t=Quantile(calib_scores,1−α_t)。
**任意时刻覆盖检验（e-process）**：E_t=∏_{s≤t}(1+λ_s(err_s−α))；若 sup_{s≤t}E_s>1/δ，则在显著性 δ 下拒绝“覆盖≥1−α”的原假设。
**覆盖缺口**：g_t=(1/W)Σ_{s=t−W+1}^{t}1[y_s∈P_s]−(1−α)。
**目标保证**：在任意（可自适应、非平稳）分数序列下，错误失效概率 ≤δ；长程覆盖 ≥1−α−O(γ)（ACI 标准结论，需在放置分布下重证）。

**定义 62（证书内核版本与回退）**
κ_t=(f 版本, 校准集版本, q_t, 审计时间戳)。**兼容判据**：证书有效 ⇔ κ_cert=κ_current ∧ 租约未过期 ∧ 无漂移告警。
**遗忘度量**：F_k=max_{j<k}(cov_j−cov_k)_+，其中 cov 在**独立审计集**上计算。
**回退规则**：若 e-process 拒绝 ∨ CUSUM>h ∨ g_t<−δ_g ∨ F_k>F_max，则 κ_t←κ*（最近一次通过认证的内核），并级联失效所有旧 κ 证书。

**定义 63（放置-学习双效用与主动采集）**
候选放置 a 的双效用
U_pl(a)=E[task(a)] + λ_info·IG(a;coverage) − λ_e·E_energy(a)，
约束 P^pl sound、a 在放置安全包络内、d(a,replay)≥δ_div。
IG(a) 用当前内核在放置结果域与 Ω_deg 上的**分数方差/集成分歧**近似；多样性约束与独立审计集分离用于阻断确认偏误。

## 2. 新增产出与既有 IP 升级

**IP-69 PLACE-CERT（放置证书合成器）**
- 支撑面/接触集估计：深度+分割，按 ε_S 外膨胀吸收估计误差
- 稳定裕度与摩擦锥可行性、最终位姿容差盒（逐物体共形校准）
- 诱导遮挡区 O^occ 与放置安全包络检查

**IP-71 ALP（主动放置采集规划器）**
- 双效用放置选择（任务+信息增益−能量）
- 多样性/审计解耦约束，防确认偏误

**既有 IP 升级**
IP-63 ECPS：放置后重算 Δ_vis、重排模态效用、预留再观测能量
IP-66 MVR：记忆条目绑定 κ；κ 失效即记忆失效；新增遗忘守卫

IP-45 总线：placement-cert / cert-kernel / drift-alarm / replay-priority / reobserve-plan

## 3. 算法骨架

每控制周期：
1. 生成候选放置，先做放置安全包络与能量可行性筛选
2. 执行放置，签发 P^pl，更新 X、V、c，重算 Δ_vis
3. ECPS 决定是否再观测/开深度，并更新能量租约
4. 以 (X,P^pl,outcome) 回灌 DCL；按覆盖缺口与多样性设置 replay 权重
5. CL-CERT 更新 α_t/q_t，跑 e-process、CUSUM 与审计窗口；必要时回退 κ*
6. PSE/SAB/CAR 仅接受满足 (κ_cert=κ_current ∧ 租约有效 ∧ 包络成立) 的联合证书；任一失败→fail-closed

## 4. 本轮最大风险

**一句话**：放置-学习闭环会让学习器、监控器与放置策略共同漂移，缓慢的遮挡/支撑分布变化可能既不触发 CUSUM 也不越过审计窗口，使“数值有效但语义失效”的放置证书长期存活；因此必须以任意时刻有效的 e-process、与训练池解耦的独立审计集、版本化内核回退构成三重防线，并在证据不足时默认 fail-closed。

## 2. 关键算法 伪代码

### IP-69 PLACE-CERT
```
def placement_certify(X_t, grasp, target, depth, calib_pl,
                      eps_S=0.01, m_min=0.02):
    S = support_polygon(X_t, target, depth)
    S_infl = inflate(S, eps_S)               # 吸收支撑面估计误差
    p_com = predicted_com(grasp, target)     # 放置后整体质心的水平投影
    m_stab = dist_to_boundary(p_com, S_infl)
    C = contact_set(grasp, target, S)
    T_tol = calib_pl.tolerance_box(target)   # 逐物体共形容差
    O_occ = occlude(X_t, target)             # 放置诱导遮挡区
    if m_stab < m_min or not friction_cone_ok(C):
        return None
    if depth_valid_ratio(target, depth) < calib_pl.rho_min:
        return None
    return PlacementCert(S_infl, m_stab, C, T_tol, O_occ,
                         tau_pl=calib_pl.tau, kappa=calib_pl.kappa)
```

### 放置安全包络（与 ECPS/能量租约联合）
```
def placement_envelope(cert, V_t, active_leases, B_t, E_min):
    V_next = update_visibility(V_t, cert.O_occ)
    for o in active_leases:
        for om in required_omega(o):
            if subset(V_cert(om), V_next):
                continue
            R = plan_reobserve(om, V_next, B_t)   # 再观测计划
            if R is None or not energy_feasible(R, B_t, E_min):
                return False                      # 拒绝放置或转保守姿态盒
    return True
```

### IP-70 CL-CERT（持续认证内核）
```
def cl_cert_update(kernel, stream, drift, alpha=0.05, gamma=0.02,
                   W=200, delta=1e-3, h=8.0, delta_g=0.03, F_max=0.02):
    # 1) ACI 在线阈值
    err = 0.0 if stream.y in kernel.predict(stream.x) else 1.0
    kernel.alpha = clip(kernel.alpha + gamma * (alpha - err),
                        1e-4, 1 - alpha)
    kernel.q = quantile(kernel.calib_scores, 1 - kernel.alpha)

    # 2) 任意时刻覆盖检验（e-process / Ville 不等式）
    lam = kernel.lam
    drift.log_e += log1p(lam * (err - alpha))
    if drift.log_e > log(1 / delta):
        return rollback(kernel, reason='coverage_reject')

    # 3) CUSUM 漂移检测
    drift.cusum = max(0.0, drift.cusum + (err - alpha))
    if drift.cusum > h:
        return rollback(kernel, reason='drift')

    # 4) 独立审计窗口覆盖门控
    g = audit_window_coverage(kernel, W) - (1 - alpha)
    if g < -delta_g:
        return rollback(kernel, reason='audit_gap')

    # 5) 灾难遗忘守卫
    F = max_backward_forgetting(kernel, audit_sets=kernel.audit)
    if F > F_max:
        return rollback(kernel, reason='forgetting')

    return kernel

def rollback(kernel, reason):
    new = kernel.last_certified          # κ*
    new.generation += 1                  # 版本号单调递增
    broadcast_invalidate(old=kernel)     # 旧 κ 证书级联失效
    return new
```

### IP-71 ALP（主动放置采集）
```
def active_placement_select(cands, task, replay, kernel, B_t,
                            lam_info=1.0, lam_e=0.1, delta_div=0.15):
    best, best_u = None, -inf
    for a in cands:
        cert = placement_certify(a.X, a.grasp, a.target,
                                 a.depth, kernel.pl_calib)
        if cert is None:
            continue
        if not placement_envelope(cert, a.V, a.active_leases,
                                  B_t, E_min):
            continue
        if min_dist(a, replay) < delta_div:
            continue                     # 多样性约束，阻断确认偏误
        r_task = task_value(a, task)
        ig = info_gain(a, replay, kernel)  # 分数方差/集成分歧代理
        u = r_task + lam_info * ig - lam_e * energy(a)
        if u > best_u:
            best, best_u = a, u
    return best
```

### 全局闭环（放置 → 再观测 → 学习 → 认证 → 守卫）
```
def loop(c_t, X_t, B_t, v_t, kernel, replay, drift, Q_safe):
    a = active_placement_select(candidates(c_t, v_t), v_t,
                                replay, kernel, B_t)
    if a is None:
        return 'fail-closed', 'no_admissible_placement'

    cert = placement_certify(a.X, a.grasp, a.target,
                             a.depth, kernel.pl_calib)
    execute_place(a)
    X_t = apply(a, X_t)
    V_t = update_visibility(a.V, cert.O_occ)
    c_t = understand(X_t, V_t)

    m_t = ecps_schedule(c_t, B_t, kernel)    # 放置后重算 Δ_vis 与模态
    if not joint_guard(cert, m_t, B_t, kernel):
        return 'fail-closed', 'certificate_or_energy_invalid'

    replay = dcl_ingest(replay, (X_t, cert, outcome),
                        priority=coverage_gap(kernel, X_t),
                        diversity=delta_div)
    kernel = cl_cert_update(kernel, outcome_stream, drift)
    broadcast_kernel(kernel)                 # κ 变更→旧证书级联失效
    return 'ok'
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| IP-69 放置证书 | O(n_depth log n_depth + |S| log|S|) | O(|S|+|O_occ|) | 支撑误差有界 + 共形容差 ⇒ 放置 soundness ≥1−α_pl |
| 放置安全包络 | O(|active|·|V_cert|) | O(|V|) | 包络成立或有能量可行再观测 ⇒ 不会在退化观测上签发姿态证书 |
| IP-70 CL-CERT | O(|calib|+W) 每次更新 | O(|calib|+W) | e-process 控制误失效 ≤δ；回退保证 fail-closed |
| IP-71 ALP | O(|cands|·(T_cert+|replay|·d)) | O(|replay|) | 多样性 δ_div>0 且审计解耦 ⇒ 限制确认偏误 |
| 全局闭环 | O(|cands|·(T_cert+|replay|·d)+W) | O(|replay|+|calib|) | 放置/感知/认证/守卫四重检查 ⇒ fail-closed |

**命题 1（支撑误差下的放置 soundness）**
若支撑多边形估计与真实支撑的 Hausdorff 误差 ≤ε_S，且估计裕度 m̂_stab≥m_min+2ε_S，则真实裕度 m_stab≥m_min。证明：由三角不等式 dist(p_com,∂S) ≥ dist(p_com,∂Ŝ) − ε_S ≥ m_min+ε_S ≥ m_min。结合在放置试次上可交换校准的 T_tol，得 Pr(稳定 ∧ 位姿∈T_tol)≥1−α_pl。

**命题 2（任意时刻失效控制）**
在 H0：覆盖≥1−α 下，若增量有界且 λ_s 使 E_t 为非负上鞅，则由 Ville 不等式 Pr(∃t: E_t≥1/δ)≤δ。因此漂移告警的误失效概率 ≤δ，避免单点噪声频繁触发回退。

**命题 3（回退安全 / fail-closed）**
若总线同步广播 κ 失效且控制周期大于广播延迟，且守卫强制 κ_cert=κ_current，则任何在覆盖拒绝后签发的证书都不会被执行，系统进入 fail-closed 而非带病运行。异步总线需追加 epoch/generation 校验，否则命题不成立。

**命题 4（审计独立性）**
若审计集由与放置策略无关的独立分布采样，且主动采集只进入训练池，则审计覆盖率估计无选择偏差；多样性约束 δ_div>0 与 replay 权重上限只改变训练分布，不改变审计无偏性（需经验验证）。

## 4. 实验设计 E115–E121

| 实验 | 指标 | 门槛 |
|---|---|---|
| E115 放置证书 soundness | 经验覆盖、稳定违例率、ε_S 鲁棒性 | 覆盖 ≥0.95（α_pl=0.05）；稳定违例 ≤1%；ε_S∈[0,2cm] 不明显退化 |
| E116 放置诱导观测漂移 | Δ_vis、放置后覆盖下降、检测延迟、误报 | 检测 ≤5 个放置周期；误报 ≤1% |
| E117 持续学习时变覆盖 | 任意时刻覆盖、长程覆盖、对比静态共形 | 任意时刻 ≥0.93；长程 ≥0.95；显著优于静态 |
| E118 灾难遗忘与回退 | F_k、回退召回、误回退 | F_k ≤2%；回退召回 ≥99%；误回退 ≤2% |
| E119 主动放置数据效率 | 每放置信息增益、每百次放置覆盖提升 | 较随机放置提升 ≥2× 样本效率 |
| E120 确认偏误/投毒红队 | 5% replay 投毒下覆盖、盲区扫描 | 覆盖不低于 0.92；盲区不扩大 |
| E121 100h 全局闭环 | 放置成功率、安全违例、fail-closed 次数、能耗 | 成功率 ≥98%；安全违例 0；fail-closed ≤5；能耗 ≤基线+10% |

**回退策略**：E115 覆盖 <0.90 → 增大 ε_S 与 m_min、缩短 τ_pl；E116 检测 >10 周期 → 降 CUSUM 阈值并强制按需深度；E117 覆盖下跌 → 增大 γ、缩短 W、冻结更新并回退 κ*；E119 无增益 → 关闭主动选择，回退均匀采样；E120 漂移逃逸 → 强化独立审计集与 replay 权重上限；E121 不可用 → 进入保守模式（m_min 上调、深度常开、主动采集关闭）。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 持续学习破坏可交换性、覆盖静默下降 | 高 | ACI + e-process + 独立审计 + 版本化回退 |
| 放置诱导遮挡造成未见分布 | 高 | 放置安全包络、再观测计划、按需深度 |
| 支撑/深度误差高估稳定裕度 | 高 | ε_S 膨胀、接触验证、保守 m_min |
| 主动采集确认偏误 / replay 投毒 | 中 | 多样性约束、审计解耦、CCA 红队、权重上限 |
| 回退频繁导致任务不可用 | 中 | 影子内核并行认证、达标再切换、渐进回退 |
| 能量与再观测冲突 | 中 | ECPS 预留能量、包络与能量租约联合判定 |

## 6. 本轮最大风险

**一句话**：放置-学习闭环使训练分布、监控分布与决策分布相互耦合，缓慢的遮挡/支撑漂移可能在 CUSUM 与审计窗口下“隐身”，让放置证书在数值上持续有效却在语义上失效；必须以任意时刻有效证书、独立审计集与版本化回退构成三重防线，并在证据不足时默认 fail-closed。
