# 第 3 轮（灵感循环第 3 轮；本轮灵感：「平衡控制」×「抓取」）

> **基线继承**：第 2 轮 **ToolGauge**（IP-315–320；定义 416–431；引理 46–50；实验 E426–E440）。
> 本轮纪律：**在 ToolGauge 上改进，而不是推倒重来**——6C 闭环、MTC/TCV、MP-Φ/AP-Cal、P-Quarantine、
> MODGAUGE 五不变式与严格退化链全部保留；两条灵感分别沿「支撑/平衡」与「接触/抓取」两轴升级，
> 并审计并修复第 2 轮遗留的七处缺陷（见 §5）。

## 三位一体映射（升级而非重写）

| 灵感词 | 第 2 轮对象 | 升级为 | 一句话动机 |
|---|---|---|---|
| 平衡控制 | TCV 只检查「调用是否合法、预算是否够」，从不检查「身体是否站得住」 | **E-Box + CBF-Shield + SB-Contract**：把每个探测放进 H 步可行核，用支撑多边形/捕捉点/摩擦锥余量做物理闸门 | ToolGauge 只证明了「被拒绝的探测零副作用」，却没证明「已执行的探测不会把机器人或物品弄倒」 |
| 抓取 | AP-Cal 的契约参数 u_s 只含数值/感知量 | **G-Tools + EC-Cal**：把质量、质心、惯量、摩擦、刚度纳入耦合契约 u_s=(u_num,u_mech)，用微升/微捏/滑移临界主动测量 | 数值上修好的世界，可能一抓就掉；机械参数才是抓取任务真正的盲区 |
| 合流 | 6C：H→C→E→C→V→U（探测被视为免费观测） | **8C：H→C→A→E→S→C→V→U**（锚定→执行→沉降） | 探测是一个「花稳定性买信息」的接触事务，必须借、付、还平衡预算 |

**核心命题**：把 ToolGauge 的「**合法即可执行**的探测」升级为「**合法 ∧ 平衡可行 ∧ 抓取可行**的接触事务」：
探测不是免费的观测，而是一次会改变质心、角动量与接触力分配的物理交互；数值真值仍由计量层独占，
机械真值（质量/质心/摩擦/刚度）由抓取计量层与平衡一致性残差共同约束；
系统只在可行核内、以显式稳定预算、经「锚定—执行—沉降」三段完成修复，并只做平衡兼容的热替换。

**不变式保持声明**：
- MODGAUGE 五不变式全部保留；ToolGauge 的 MTC/TCV（416–418）、AP-Cal（420）、6C（421）作为 8C 的子集保留。
- 新增 **平衡-抓取不变式**：任何已执行探测都必须携带有效 E-Cert，且执行后状态仍位于可行核 K；无证书的物理探测在语义上即非法。
- **严格退化链修正**：EquiGauge 认证主动探测 ⇒ 被动观测（零接触）⇒ stub + RED；
  **无证书主动探测只允许在外部支撑证书 BCert 下执行**——ToolGauge 恰为「K = 全空间」的退化特例，而不是默认工作模式。

## 0. 直觉与动机

### 灵感 1（平衡控制 → 探测是「花稳定性买信息」的接触事务）

直觉：第 2 轮把安全性定义成「TCV 拒绝 ⇒ 零副作用」，这在逻辑上只覆盖了**没做的事**，
却把**已经做的事**（执行成功的探测）默认为安全。但敲击会推物体、变光会晃相机云台、微升会改变质心与支撑反力——
**每一次成功的探测都是一次扰动**。对移动机械臂/人形而言，真正的约束不是「参数在不在 schema 内」，
而是「做完这一步，质心还在支撑多边形内吗？捕捉点还有余量吗？接触力还在摩擦锥内吗？」。

平衡控制给我们的第一性原理是 **前向不变性（forward invariance）**：安全的不是某一个状态，而是
一个**在扰动下仍然能留在安全集内**的状态集合（可行核）。因此本轮把探测程序编译成
「带平衡证书的控制动作序列」：先算 E-Cert（H 步可达/GP 置信管），再由 CBF-Shield 在执行时做最小干预投影，
任一约束将破 ⇒ 直接否决并制动。第二性原理是 **支点借用**：站不稳时，人可以扶墙；
机器人也可以借外部支撑（夹具、扶手、双足以外的第三接触、坐姿），但借力必须付反力预算，
且借力证书本身要可被物理残差证伪。

### 灵感 2（抓取 → 机械参数才是真正的盲区）

直觉：第 2 轮的盲区 s 是「格子 (d,m,i) 没验证过」，u_s 是数值/感知参数。
但在抓取任务里，决定成败的是物体的 **质量 m、质心 c_o、惯量 I、摩擦系数 μ、接触刚度 k**——
这些量在视觉上可能完全正常，在数值上也可能「已覆盖」，却会在提起的瞬间让物体滑落。
更关键的是：**这些参数只能通过接触来测量**。微升给出 m 与 c_o，微捏给出 k 与 μ 的局部信息，
腕部微抖给出 I，滑移临界给出 μ 的上界。它们的信息量最大之处恰在「快要滑」的边界附近，
而那里也最危险——于是抓取计量天然是一个**信息-稳定折中**：在证书允许的滑移裕度内，尽可能贴近边界探测。

### 灵感 3（合流 → 平衡与抓取是同一个「接触平衡」问题的对偶）

直觉：平衡是**全局支撑**问题（地面接触集 ⊇ 质心投影），抓取是**局部接触**问题（手指接触力的合力 ∈ 摩擦锥且能抵抗外力）。
两者共享同一个数学对象：**接触力分配 + 支撑/摩擦锥约束 + 有界扰动下的不变性**。
把二者统一为「接触平衡」后，会出现三个第 2 轮没有的结构：
(a) **状态转移即证据**：探测改变了 X，而 X 的改变本身（滑移、反力、质心漂移）是比回执更硬的证据；
(b) **守恒律是独立通道**：由刚体动力学算出的地面反力/关节力矩残差（ECR）与视觉/红外完全不同源，
     可以用来交叉验证数值修复是否在物理上自洽；
(c) **热替换会改变力学**：新契约改变控制器输出，可能破坏原有平衡——所以「数值等价」不够，
     必须再加「平衡兼容」。

## 1. 形式化定义（增量：定义 432–447）

**定义 432（耦合接触平衡状态）** X(t) = (x_b, x_o)：
- x_b = (c, ċ, L, S_sup, 𝒞, {w_i}_{i∈𝒞})：质心位置/速度、角动量、支撑多边形、接触集与各接触扳手；
- x_o = (p_o, R_o, v_o, ω_o, λ)：物体位姿/速度与接触力分配 λ；
- 平衡裕度 m_b(X) = dist(c, ∂S_sup)（或捕捉点余量 ξ_cp 的归一化版本）；
- 抓取裕度 m_g(X) = min_{i∈𝒞_g} (μ_i f_{n,i} − |f_{t,i}|)/(μ_i f_{n,i} + ε)；
- 安全集 **K** = {X : m_b ≥ ε_b, m_g ≥ ε_g, ||ċ|| ≤ v_max, 所有接触力 ∈ 摩擦锥, 关节力矩 ∈ 硬限}。

**定义 433（探测副作用算子与接触事务）** 每个工具的语义从「回执生成器」升级为「状态转移 + 回执」：
𝒟_t(X, a) → (X′, r)，其中 X′ 是执行后的物理状态分布，r 仍是定义 417 的签名回执。
副作用幅度 d_t(X,a) = ||E[X′ − X]||_𝒫 + γ_w·||∫w_t dt||，并要求 |d_t| ≤ D_t（工具级上界）。
**被拒绝的探测 d_t = 0；被执行的探测 d_t > 0 是常态**——第 2 轮的安全论证只覆盖了前者，本轮必须处理后者。

**定义 434（H 步可行核与平衡证书 E-Cert）** 给定既有平衡控制器 π_b（50Hz，不动）、有界扰动集 𝒲
（负载突变、地面不平、外部推力）、探测算子 𝒟_t：
K_H = { X ∈ K : ∀（w_0,…,w_{H−1}）∈ 𝒲，在 π_b 与 𝒟_t 下 X_{t+k} ∈ K, k ≤ H }。
E-Cert(Π_s, X) = (H, {m_k}_{k=0..H}, assumptions) 有效，当且仅当 min_k m_k ≥ m_res 且最坏扰动下仍可行。
实现给两档：**区间/可达性**（确定性、保守，模型内 δ_m = 0）与 **GP 置信管**（概率性，越界概率 ≤ δ_cert）。

**定义 435（守恒守卫过滤器 CBF-Shield）** 对每个安全约束 h_i(X) ≥ 0（支撑多边形、捕捉点、摩擦锥、力矩上限）
构造离散/连续 CBF 条件 L_f h_i + L_g h_i u + α_i(h_i) ≥ 0；探测指令 u_probe 经最小干预 QP 投影：
u_safe = argmin_u ||u − u_probe||² s.t. CBF 条件 ∧ u ∈ U_act。
QP 不可行 ⇒ veto + brake 并结束程序。**Shield 优先级高于探测指令与 VLA 编程，且不依赖 VLA**。

**定义 436（稳定性预算契约 SB-Contract）** SB = (M_bal, M_grasp, m_res, ρ_max, τ_settle, B_settle, BCert, recovery)：
每次探测预留 m_res；消耗 Δm = (m_pre − m_expected_post) + 扰动上界；要求任意时刻剩余裕度 ≥ m_res；
执行后进入沉降窗口，直到 ||Ẋ|| ≤ v_settle 且裕度恢复到 m_res − δ，否则回滚到上一平衡安全契约。
TB-Contract（定义 424）被 SB-Contract 包住：除工具代价 c_t 外再计稳定性代价与沉降时间。

**定义 437（抓取计量工具集 G-Tools）** T_g = {grasp.micro_lift, grasp.micro_squeeze, grasp.wrist_dither, grasp.slip_onset, balance.load_shift}：
每个工具仍满足 MTC（定义 416），但 Post 增加物理回执字段 (slip_flag, wrench_trace, ΔX, settle_time)；
信息增益 Ĝ^g_t(h) 定义为对 u_mech 的后验熵减；风险由滑移概率积分度量（定义 438）。
其中 slip_onset 仅在 ρ_max 与外部兜底（低高度/软垫/BCert）同时满足时启用。

**定义 438（滑移风险积分与近边界约束）** ρ(Π) = Σ_k ∫_{t_k}^{t_k+τ_k} P_slip(X(t)) dt，
P_slip 由摩擦锥余量与 μ 的后验给出；可行探测要求 ρ(Π) ≤ ρ_max；在此约束下最大化 Ĝ^g，
得到「近边界但可证安全」的探测方案。这把「最大信息在滑移临界」的直觉变成带约束优化。

**定义 439（平衡一致性残差 ECR）** 由刚体动力学线性参数化：
W_meas = Φ(q, q̇, q̈)·θ + d_ext + n，θ = (m, m·c_o, I)；
残差 r_ecr = W_meas − Φ·θ̂ = Φ·δθ + d_ext + n。激励充分（persistent excitation）时 δθ 可辨识；
阈值检验用 χ²。**ECR 是与 cross.modal 不同物理通道的独立回执**：它由守恒律给出，
不依赖同一组视觉/红外传感器，因此补上第 2 轮「独立回执其实不独立」的漏洞。

**定义 440（耦合契约参数）** u_s = (u_num, u_mech)，u_mech = (m, c_o, I, μ, k)；
盲区 s 同时具有数值维度与机械维度；只有二者都在容差内才算修复。
U_mech 为物理可行域（m > 0，0 ≤ μ ≤ μ_max，k > 0，I ≻ 0）。

**定义 441（EC-Cal：平衡约束下的摊销校准）** q_θ(u_s) = 𝒩(μ_θ, Σ_θ) 由 MP-Φ 输出；训练/推理损失增加：
(i) 物理可行性投影 Π_{U_mech}（重参数化 softplus / 约束高斯）；
(ii) ECR 似然 −log p(r_ecr | u_s)。上下文回执扩展为 (数值回执, wrench/IMU 轨迹, slip 标志)。
保留定义 420 的保守性夹紧，并新增**机械保守界** σ_m ≥ σ_{m,phys}（称重/力矩噪声底）。

**定义 442（EquiGauge 8C 闭环）** = H→C→A→E→S→C→V→U：
1. H：D-Box + L-Box（继承）给出 H_s；
2. C：VLA 编译 Π_s，TCV 验证（继承）；
3. **A（Anchor，锚定）**：E-Box 计算 E-Cert；SB-Contract 预留预算；选择自平衡 / 支点借用 / 放弃；
4. E：在 CBF-Shield 下执行，记录回执 + 物理状态转移；
5. **S（Settle，沉降）**：等待并复核 X 回到 m_res 以上；失败 ⇒ 回滚；
6. C：EC-Cal 输出耦合后验；
7. V：三通道验证——独立 cross.modal 回执、ECR 残差、契约/平衡回归；
8. U：平衡兼容热替换 + 语言修复证书 + 更新 R 的 (σ_num, σ_mech)。
关系：6C = 8C 去掉 A、S 两段（K = 全空间、零沉降）。

**定义 443（平衡兼容热替换）** EC_new 平衡兼容，当且仅当：
(a) 数值等价（第 2 轮引理 44/49 的未触及子图等价性）；
(b) 在运行包络 𝒳_env 与扰动集 𝒲 下，闭环（既有 π_b + 新契约）保持 X ∈ K；
(c) 平衡回归套件通过（含最坏扰动、载荷突变、单接触失效模拟）。
任一不满足 ⇒ 保留旧 EC 或回滚到 passive stub。

**定义 444（平衡安全退化链）**
- L_A：认证主动探测（E-Cert 有效 + SB 预算充足）；
- L_A′：借力主动探测（BCert = true：外部支撑/夹具/坐姿；ToolGauge 仅在此合法）；
- L_B：被动观测（零接触；视觉/先验/IMU-only，ECR 仍可被动运行）；
- L_C：stub + RED + 人工队列。
规则：**不存在从 L_B 直接跳到无证书主动探测的边**；P-Quarantine 触发时同样只能降级到 L_B，
不能「带着坏先验继续探」。

**定义 445（支点借用证书 BCert）** 令 S_sup⁺ = conv(S_sup ∪ S_ext)。BCert 有效，当且仅当
c ∈ S_sup⁺ ⊖ ε_b，且对所有 w ∈ 𝒲，支撑反力在 brace 力限与摩擦锥内。
BCert 把「平衡」转化为「带反力约束的支撑」：可以借外部支点，但必须支付反力预算；
且 BCert 自身可被 ECR 证伪（支撑反力与预测不一致 ⇒ BCert 失效 ⇒ 回退 L_B）。

**定义 446（锚定窗口）** Window(X, τ) ⇔ X ∈ K_H ∧ m ≥ m_res ∧ 任务阶段允许 ∧ 工作空间无未预期的第三人/障碍。
探测调度器只在 Window 内启动程序；窗口消失 ⇒ 中止并进入 S 段。这防止在动态步态/快速搬运中做探测。

**定义 447（继承与编号）** 未重定义记号沿用定义 398–431。退化关系：
- K = 全空间、忽略 𝒲、无 G-Tools ⇒ EquiGauge ≡ ToolGauge；
- 再令 VLA = ∅、T₀ = {被动观测} ⇒ LeanGauge；
- 关闭 E-Box 但保留 BCert ⇒ ToolGauge（借力特例）。
数值路径与安全路径正交：安全层只能**否决/降级**，不能修改任何数值真值。

## 2. 关键算法骨架

```python
@dataclass
class EquilibriumState:
    m_bal: float          # 平衡裕度 m_b
    m_grasp: float        # 抓取裕度 m_g
    vel: float
    contacts: list        # 接触集与扳手

class EBox:
    def cert(self, prog, X, H, W):
        # 区间可达 / GP 置信管，返回 (ok, margins, assumptions)
        margins, ok = self.reachability(prog, X, H, W)
        return Cert(ok=ok and min(margins) >= M_RES, margins=margins)
    def window(self, X):
        return X.m_bal >= M_RES and X.m_grasp >= M_RES and not self.dynamic_phase()

class CBFShield:
    def project(self, u_probe, X):
        u = solve_qp(lambda u: norm(u - u_probe)**2,
                     constraints=lambda u: all_cbf_ok(X, u) and u in U_ACT)
        if u is None: return None         # veto + brake
        return u

class SBContract:
    def reserve(self, cert, budget):
        return cert.min_margin - M_RES >= 0 and budget.cost <= M_BAL
    def settle(self, M, tau_max):
        ok = wait_until(lambda: M.X.vel <= V_SETTLE and M.X.margin >= M_RES,
                        tau_max)
        return ok                          # False ⇒ rollback

class GTools:  # 继承 MetrologyTool；Post 增加物理回执
    ...

class ECR:
    def residual(self, W_meas, q, dq, ddq, theta_hat):
        return W_meas - regressor(q, dq, ddq) @ theta_hat
    def test(self, r, eps):
        return chi2_pvalue(r, eps) > ALPHA

def equigauge_8c(M, s):
    H    = M.lbox.hypothesize(s, M.dbox.R[s])                     # H
    prog = M.tbox.select(H, M.tools + M.gtools, M.tcv,
                         M.budget_left(s))                        # C
    if not M.ebox.window(M.X):
        return passive_or_red(s, "no_window")                     # L_B
    cert = M.ebox.cert(prog, M.X, H=H_HORIZON, W=M.W)             # A
    if not cert.ok:
        if M.bcert.valid(M.X):
            cert = M.ebox.cert_braced(prog, M.X)                  # L_A′
        else:
            return passive_or_red(s, "uncertifiable")             # L_B
    if not M.sb.reserve(cert, M.budget):
        return passive_or_red(s, "stability_budget")              # L_B
    receipts = M.tcv.execute(prog, M.env, shield=M.shield)        # E
    if not M.sb.settle(M, TAU_SETTLE_MAX):
        return rollback(s, "settle_failed")                       # S
    mu, Sig = M.ec_cal.calibrate(receipts, H, s)                  # C
    ok_v = (M.apcal.cross_validate(mu, Sig, M.cross_receipt(s)) and
            M.ecr.test(M.ecr.residual(M.W_meas, M.q, M.dq, M.ddq,
                                      M.theta_hat), EPS_ECR) and
            contract_regression(M.dpe) and
            equilibrium_regression(M.dpe, M.W))                   # V
    if not ok_v:
        return rollback_or_passive(s, "verify_failed")
    new_ec = M.ec_cal.update_contract(M.dpe, mu, Sig, s)
    if not equilibrium_compatible(new_ec, M.X, M.W):              # U
        return rollback(s, "incompatible")
    M.mreg.hot_replace(M.dpe, new_ec)
    M.dbox.update_from_posterior(s, mu, Sig)
    bind_claims(new_ec, H, prog, receipts, cert)                  # 定义 427 扩展
    M.pquar.record(M.ec_cal.last_gain, realized_gain(receipts))
    return True

def EquiGauge_round(M, obs, audio, tac, depth, det):
    M.ebox.update(obs, depth, tac)                 # 50Hz 只读，O(|𝒞|)
    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight and M.ebox.window(M.X):
            M.inflight.add(s)
            submit_async(equigauge_8c, M, s)       # 修复全异步
    if M.pquar.triggered():
        M.apcal.pause(); M.ec_cal.pause()          # 坏先验只许被动观测
    return MODGAUGE_round(M, obs, audio, tac, depth, det)  # 主控/平衡环不变
```

## 3. 推导

**引理 51（概率前向不变性与无跌倒/无掉落界）** 设 X₀ ∈ K_H；扰动越界概率 ≤ δ_w；
模型误差使真实状态离开证书管的概率 ≤ δ_m/步；每步 CBF-QP 可行。则
P(∀k ≤ H : X_k ∈ K) ≥ 1 − δ_w − H·δ_m。
证明：CBF 前向不变性给出确定性的管；对扰动与模型误差取 union bound。
**系 51.1**：跌倒概率与掉落概率均 ≤ δ_w + H·δ_m；Shield 不可行时程序 veto（d_t = 0），界更强。
**系 51.2**：GP 置信管下 δ_m 由 GP 校准给出；区间可达性下 δ_m = 0 但证书更保守（见引理 52 的否决阈值）。

**引理 52（近边界探测的信息-稳定折中）** 设抓取切向力 F_t、法向力 F_n，摩擦系数 μ ~ 𝒩(μ̂, σ_μ²)，
滑移条件 F_t > μF_n。令归一化滑移裕度 m = (μ̂F_n − F_t)/(σ_μF_n) ≥ 0，则 P_slip = Φ(−m)；
设观测模型的信息增益 Ĝ(m) = ½·log(1 + F_t(m)²/σ_obs²)，F_t(m) = μ̂F_n − m·σ_μF_n。
目标 J(m) = Ĝ(m) − λ_s·Φ(−m)。若 λ_s·φ(0) > |Ĝ′(0)|，则 J 在 (0, μ̂/σ_μ) 内有驻点，
且常规正则性下唯一，满足一阶条件 |Ĝ′(m*)| = λ_s·φ(m*)。
比较静态：∂m*/∂λ_s > 0（越怕滑越远离边界）。
**系 52.1（主动探测的否决阈值）** 存在 λ_s^c，使 λ_s ≥ λ_s^c 时 J 的最大值在 m = m_max
（即 F_t = 0，不探测）取得——「稳定优先」制度下最优策略是放弃高信息量接触探测，转被动观测。
**系 52.2**：σ_obs 增大或 σ_μ 增大都会降低主动探测的净价值，因此存在一个由可辨识性决定的停止探测条件。

**引理 53（ECR 的可辨识性与证伪功效）** 刚体动力学对惯性参数线性：W = Φθ + d_ext + n。
若 rank(Φ) = dim(θ)（持续激励），则 θ 可辨识；无扰动时 r = Φδθ + n。
在 H₀（θ 正确、无外扰）下 ||r||²/σ² ~ χ²_k；在参数误差 δθ 下为非中心 χ²，
非中心参数 λ = δθᵀΦᵀΦδθ/σ²。当 λ ≥ λ_min(α, β) 时，检验以功效 ≥ 1 − β 检测出 δθ。
**系 53.1（归因）** 将 r 投影到 range(Φ) 得参数误差方向，投影到正交补得外扰方向；
因此 ECR 不仅能说「错了」，还能区分「质量估错 / 质心估错 / 被人推了」。
**系 53.2**：微升、微捏、负载扰动这些高信息量探测天然提供持续激励，V 阶段因此比第 2 轮的单条 cross.modal 回执更有功效。

**引理 54（契约-平衡兼容热替换）** 若 (i) 未触及子图满足第 2 轮引理 44/49 的数值等价；
(ii) EC_new 在运行包络与扰动集下保持闭环 X ∈ K；(iii) 平衡回归通过，则热替换同时保持
第 2 轮的数值不变式与本轮的平衡-抓取不变式：不存在由本次替换**新增**的跌倒/掉落。
证明：把受影响的子图与平衡环解耦；数值部分用引理 44/49，物理部分用引理 51 的前向不变性；
(ii) 保证新参考轨迹不把状态推出 K。**系 54.1**：ToolGauge 的热替换是 K = 全空间、𝒲 = ∅ 的特例。

**引理 55（SB-Contract 的可调度性与 anytime 安全）** 设每次探测的最小裕度消耗 Δm_min > 0，
预留 m_res。若调度器仅在「剩余预算 ≥ Δm̂ + m_res」且「预计沉降 ≤ τ_settle」时放行，则：
(a) 探测次数 N_probe ≤ ⌊(M_bal − m_res)/Δm_min⌋，不会出现「预算赌博」；
(b) 每个时刻（含探测中）安全不变式成立（anytime 安全）；
(c) 总沉降时间 ≤ N_probe·τ_settle ≤ B_settle。
证明：单调消耗 + 预留不变量 + settle 后复核；任何一次复核失败即回滚并停止，故不变量不被破坏。

**引理 56（退化安全与硬实时保持）** 被动观测段不产生接触动作 ⇒ 不会诱发跌倒/掉落；
Shield 仍运行，且退化链中不存在指向「无证书主动探测」的边。
50Hz 主路径新增的 E-Box 读取为 O(|𝒞|)（|𝒞| ≤ 4）且只读；CBF-Shield 的 QP 仅在 PROBING 期间
以控制率运行（n_c ≤ 4，O(n_c³) < 0.5ms），非探测期旁路。
因此第 2 轮引理 45/50 的硬实时与预算不变式保持，且退化延迟 ≤ τ_settle^max + τ_rollback。

## 6. 本轮最大风险（一句话）

**一句话**：E-Cert 依赖的接触/平衡模型本身可能错误——一旦可行核 K_H 被高估（摩擦锥、支撑多边形、
外部扰动界或质心估计偏乐观），CBF 会签发看似合法的安全证书并放行危险探测；由于证书被所有探测共享，
**一次平衡模型错误会同时放行所有危险动作，导致成批跌倒/掉落**——这是把第 2 轮「跨盲区相关污染」
从数值域搬到物理域后的最危险版本。

**次级风险与缓解**：
1. **证书死锁（过保守）** → 分级可行核 + 用微升/负载扰动主动学习可行核参数 + BCert 扩展支撑；监控 veto 率，过高则放宽并在低风险对象上重校准；
2. **滑移临界不可逆** → slip_onset 仅在低高度/软垫/BCert 兜底时启用；优先用 micro_squeeze 估计 μ；ρ_max 硬约束；
3. **ECR 多接触不可辨识** → 结构化残差 + 主动激励；不可辨识时显式降级为 L_B，不假装已验证；
4. **沉降延迟威胁节拍** → τ_settle 上界 + 异步 + 超时回滚；锚定窗口避开动态步态；
5. **支点借用反作用力超限** → BCert 含 brace 自身力限与摩擦锥，双通道监测；
6. **仿真到现实的摩擦/柔顺误差** → 域随机化 + 在线鲁棒界 + 放大 ε_b/ε_g（保守性优先）；
7. **实时性** → Shield 仅在 PROBING 启用、QP 规模小、硬件力矩/电流硬限作为机械层最后防线。

## 3. 关键算法骨架

```python
class EBox:
    def cert(self, prog, X, H, W):
        margins, ok = self.reachability(prog, X, H, W)     # 区间/GP 置信管
        return Cert(ok and min(margins) >= M_RES, margins)
    def window(self, X):
        return X.m_bal >= M_RES and X.m_grasp >= M_RES and not self.dynamic_phase()

class CBFShield:
    def project(self, u_probe, X):
        u = solve_qp(lambda u: norm(u-u_probe)**2,
                     lambda u: all_cbf_ok(X, u) and u in U_ACT)
        return u            # None ⇒ veto + brake

class SBContract:
    def reserve(self, cert, budget):
        return cert.min_margin - M_RES >= 0 and budget.cost <= M_BAL
    def settle(self, M, tau_max):
        return wait_until(lambda: M.X.vel <= V_SETTLE and M.X.margin >= M_RES, tau_max)

class ECR:
    def residual(self, W_meas, q, dq, ddq, theta_hat):
        return W_meas - regressor(q, dq, ddq) @ theta_hat
    def test(self, r, eps):
        return chi2_pvalue(r, eps) > ALPHA

def equigauge_8c(M, s):
    H    = M.lbox.hypothesize(s, M.dbox.R[s])                    # H
    prog = M.tbox.select(H, M.tools + M.gtools, M.tcv, M.budget_left(s))  # C
    if not M.ebox.window(M.X): return passive_or_red(s, "no_window")
    cert = M.ebox.cert(prog, M.X, H=H_HORIZON, W=M.W)            # A
    if not cert.ok:
        if not M.bcert.valid(M.X): return passive_or_red(s, "uncertifiable")
        cert = M.ebox.cert_braced(prog, M.X)                      # L_A′
    if not M.sb.reserve(cert, M.budget): return passive_or_red(s, "stability_budget")
    receipts = M.tcv.execute(prog, M.env, shield=M.shield)        # E
    if not M.sb.settle(M, TAU_SETTLE_MAX): return rollback(s, "settle_failed")  # S
    mu, Sig = M.ec_cal.calibrate(receipts, H, s)                  # C
    ok_v = (M.apcal.cross_validate(mu, Sig, M.cross_receipt(s)) and
            M.ecr.test(M.ecr.residual(M.W_meas, M.q, M.dq, M.ddq,
                                      M.theta_hat), EPS_ECR) and
            contract_regression(M.dpe) and equilibrium_regression(M.dpe, M.W))  # V
    if not ok_v: return rollback_or_passive(s, "verify_failed")
    new_ec = M.ec_cal.update_contract(M.dpe, mu, Sig, s)
    if not equilibrium_compatible(new_ec, M.X, M.W):              # U
        return rollback(s, "incompatible")
    M.mreg.hot_replace(M.dpe, new_ec)
    M.dbox.update_from_posterior(s, mu, Sig)
    bind_claims(new_ec, H, prog, receipts, cert)
    return True

def EquiGauge_round(M, obs, audio, tac, depth, det):
    M.ebox.update(obs, depth, tac)                                # 50Hz 只读
    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight and M.ebox.window(M.X):
            M.inflight.add(s); submit_async(equigauge_8c, M, s)
    if M.pquar.triggered(): M.apcal.pause(); M.ec_cal.pause()
    return MODGAUGE_round(M, obs, audio, tac, depth, det)
```

## 4. 推导

**引理 51（前向不变与无跌倒/无掉落界）** X₀∈K_H、扰动越界 ≤δ_w、模型误差 ≤δ_m/步、QP 每步可行 ⇒
P(∀k≤H: X_k∈K) ≥ 1−δ_w−Hδ_m；系：跌倒/掉落概率同界；veto 时 d_t=0 更强。
**引理 52（近边界信息-稳定折中）** m=(μ̂F_n−F_t)/(σ_μF_n)，P_slip=Φ(−m)，Ĝ(m)=½log(1+F_t(m)²/σ_obs²)；
J=Ĝ−λ_sΦ(−m)；λ_sφ(0)>|Ĝ′(0)| 时驻点满足 |Ĝ′(m*)|=λ_sφ(m*)，∂m*/∂λ_s>0；
存在 λ_s^c 使 λ_s≥λ_s^c 时最优为不探测（被动观测）。
**引理 53（ECR 可辨识与功效）** rank(Φ)=dim θ ⇒ θ 可辨识；H₀ 下 ||r||²/σ²~χ²_k，
参数误差下非中心参数 λ=δθᵀΦᵀΦδθ/σ²；λ≥λ_min(α,β) 时功效 ≥1−β；range/正交补分解可区分参数误差与外扰。
**引理 54（契约-平衡兼容热替换）** 数值等价（引理 44/49）∧ 闭环 X∈K ∧ 平衡回归 ⇒ 替换后无新增跌倒/掉落；ToolGauge 为 K=全空间特例。
**引理 55（SB 可调度与 anytime 安全）** Δm_min>0、预留 m_res ⇒ N_probe≤⌊(M_bal−m_res)/Δm_min⌋；每时刻不变量成立；总沉降 ≤ B_settle。
**引理 56（退化安全与实时保持）** 被动观测无接触 ⇒ 不诱发跌倒/掉落；退化链无「无证书主动」边；
50Hz 新增 <0.3ms（E-Box 只读），探测期 Shield QP <0.5ms ⇒ 引理 45/50 保持。

## 8. 本轮最大风险

**一句话**：E-Cert 所依赖的接触/平衡模型可能被高估（摩擦锥、支撑多边形、扰动界、质心估计偏乐观），
CBF 因此签发**看似合法实则错误的共享安全证书**，一次模型错误同时放行所有探测，造成成批跌倒/掉落；
这是第 2 轮「跨盲区相关污染」在物理域的对应物。
**兜底**：E444/E452/E454 证伪、ECR 在线模型检验（引理 53）、BCert 反力校验、
以及独立于软件的硬件力矩/电流硬限与机械保险。
