# 第 61 轮（承接第 60 轮「场景感知闭环」IP-153~160；灵感循环第 7 轮；本轮灵感：「关节驱动」×「VLA」）

> 第 60 轮把「场景语义 × 认知意图 × ROS 因果隔离」统一为场景感知闭环 SGEC，解决了「场景改变只能先失败后回退」「意图单向」「ROS 丢包断链」。但它仍停留在**中间抽象层**：场景、意图、阻抗、证据都是"中间量"，而真正的力由**关节驱动器**（伺服环 / 力矩环 / 电流环）产生，真正的"动作"由 **VLA（Vision-Language-Action）模型**输出。两者之间有三个尚未解决的核心局限：
> 1. **物理接地缺失**：VLA 输出的是低频（5–10 Hz）、离散、语义丰富但**物理无知**的动作分块（action chunk）；关节驱动是高频（1–10 kHz）、连续、受力矩 / 电流 / 温度硬约束的执行器。中间没有「物理可行性接地层」——VLA 可以输出一个"语义正确但关节不可执行"的动作（超限、奇异、堵转、过热）。
> 2. **频率-语义双重鸿沟**：VLA 一个 chunk 的周期内，关节闭环要跑成百上千个周期；慢环的语义约束在快环**每一个插值周期**是否仍成立，缺乏契约化保证。这与第 60 轮的 ERTC 实时契约同源，但对象从"阻抗参数"下沉到"关节力矩"。
> 3. **自下而上的证据断裂**：第 60 轮的 SERC / EPIR 只把"执行证据"回传给场景 / 意图层，却没有把**关节层的物理失败证据**（力矩饱和、回差、摩擦、奇异、堵转、过热）翻译成 VLA 能理解的**语义失败信号**——导致 VLA 在同一个物理不可行动作上反复规划（"语义幻觉 + 物理失明"）。

## 0. 直觉与动机

**灵感 1（关节驱动 → 关节动作令牌接地 JATG）**
直觉：VLA 的动作分块像"一句句自然语言命令"，而关节驱动器只懂"力矩 / 位置 / 速度"的物理语言。中间需要一个"翻译 + 安检"：把每个动作令牌 a_i 落地成关节参考轨迹 (q_ref, τ_ff)，并给每个令牌发一张**可执行性证书**——好比给每件行李贴上"是否超重 / 超尺寸"的标签。关键洞见：**接地不只是 IK 求解，而是逐令牌的物理可行性认证** m_i（力矩 / 速度 / 加速度 / 位置 / 温度的归一化裕度）；不可执行的令牌必须被"截断"，而不是"硬执行后报警"。

**灵感 2（VLA → 语义-力矩双频契约 STDC）**
直觉：慢环（VLA）说"去抓杯子"，快环（关节）以 1 kHz 问"现在这一毫秒还能不能抓"。把二者写成一份**双频契约**：慢环承诺一个**语义不变式**（"抓握过程中接触力不超过 F_safe、末端保持在区域 R 内"），快环承诺一个**物理不变式**（"力矩 / 速度 / 温度永不越限"），并约定慢环必须在"语义管 Ξ(S_k)"失效前交出下一个可行语义约束。关键洞见：**用 assume-guarantee 把频率失配形式化为"管道保持 + 截止时间"问题**，而不是靠调参凑。

**灵感 3（VLA 动作分块 → 关节可行性预测 ACJF）**
直觉：VLA 一次吐出 T 步动作，若第 3 步就撞到关节限位，后 7 步全是浪费甚至危险。应当**先预测、后执行**：用关节动力学残差模型预测每个令牌的可行性风险曲线 r_i，只执行"可证可行"的最长前缀 L*，然后重新问 VLA。关键洞见：**把动作分块从"开环剧本"改成"滚动时域的可证前缀"**（receding-horizon certified prefix）。

**灵感 4（关节驱动 → 驱动逆模型残差补偿 JDIR）**
直觉：关节不是理想执行器——有摩擦、回差、谐波减速器柔度、齿隙、温漂。VLA 与规划器对这些一无所知，于是"想给的力矩"和"真给的力矩"之间有残差 Δ。在线学习 Δ̂ 并前馈补偿，把关节的"物理脏活"对上层透明化。关键洞见：**残差必须带界** |Δ−Δ̂| ≤ ε_res；否则补偿本身会成为新的不稳定源，只有带界的补偿才能进入安全证书。

**灵感 5（VLA → 语义回退-关节证据对齐 SFVA）**
直觉：当关节层发现"抓空了 / 打滑了 / 堵转了 / 到限位了"，这其实是一个**语义级失败**："抓取"这个动词失败了。把 EV-joint 翻译成 VLA 能消费的语义失败令牌 b=(failure_type, D_sem, suggested_constraint)，回填 VLA 上下文让它重规划。关键洞见：**闭环必须回到"语言 / 动作"层才算真正闭合**，否则只是低层 PID 在硬撑。

**灵感 6（关节驱动 × VLA 合流 → VLA-关节接地闭环 VJGC）**
直觉：VLA 出动作分块 → ACJF 截取可证前缀 → JATG 接地成关节轨迹+证书 → STDC 双频契约执行 → JDIR 残差补偿 → EV-joint → SFVA 语义回退 → VLA 重规划。形成**"语义→物理→语义"的完整双频闭环**。

**灵感 7（PCE+++++ → 物理-语义联合预算）**
直觉：预算不能只算"认知 / 执行"的抽象开销，必须显式包含**关节物理预算**（力矩裕度、电流裕度、热预算、jerk 预算）与**语义预算**（VLA 查询延迟、重规划次数）。任一耗尽触发确定性降级：慢环超时→保持可证前缀；接地算力耗尽→保守固定阻抗；力矩耗尽→降速降力；热耗尽→降额；语义修复耗尽→安全停。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（关节动作令牌接地 JATG）** 接地算子 G = (π_IK, M_feas, Cert_ground)。给定 VLA 动作分块 A=(a_1,…,a_T)，a_i=(Δx_i, c_i)（末端增量与接触模式令牌），关节状态 x=(q,q̇)：
- **运动学落地**：q_i^ref = IK(x_0 ⊕ Σ_{k≤i} Δx_k)，τ_i^ff = M(q_i)q̈_i^ref + C(q_i,q̇_i)q̇_i^ref + g(q_i)
- **逐令牌可行性裕度**：
  m_i = min_j { (τ_j^max−|τ_{i,j}|)/τ_j^max, (q̇_j^max−|q̇_{i,j}|)/q̇_j^max, (q̈_j^max−|q̈_{i,j}|)/q̈_j^max, d_j^limit/q_j^range, (T_j^max−T_j(t))/T_j^max }
- **接地判定**：Grounded(a_i) ⟺ m_i ≥ m_min（默认 0.1）∧ IK 收敛 ∧ 雅可比非奇异（σ_min(J_i) ≥ σ_0）
- **接地证书**：Cert_ground(i) = (m_i, σ_min(J_i), hash(q_i^ref, τ_i^ff), seq)
- **截断规则**：L* = min{ i : ¬Grounded(a_i) } − 1；只执行 A[1:L*]

**定义 162（语义-力矩双频契约 STDC）** 契约 C = (S_k, I_sem, I_phys, Ξ, T_slow, τ_tube)。其中：
- 慢环（f_s≈5–10 Hz）在时刻 k 发布语义约束 S_k=(g_k, c_k, κ_k)：g 为目标、c 为接触模式、κ 为安全等级
- 快环（f_f≈1 kHz）执行 τ(t)=τ^ff + K_j(c)e + D_j(c)ė − Δ̂
- **语义不变式**：I_sem = □(F_contact ≤ F_safe(c_k) ∧ ee ∈ R(g_k) ∧ mode = c_k)
- **物理不变式**：I_phys = □(|τ_j| ≤ τ_j^max ∧ |q̇_j| ≤ q̇_j^max ∧ T_j ≤ T_j^max)
- **语义管**：Ξ(S_k) = { x : dist(x, 𝒳(S_k)) ≤ ρ_k }，𝒳(S_k) 为满足 S_k 的状态集
- **契约义务**：快环保证 □(x∈Ξ(S_k) ∧ I_phys)；慢环保证 T_slow ≤ τ_tube（在管道失效前交付下一个可行 S_{k+1}）
- **违约处理**：若 x∉Ξ(S_k) 或 I_phys 将破，触发 semantic_interrupt，冻结慢环当前 token 并进入 SFVA

**定义 163（动作分块关节可行性预测 ACJF）** 预测器 F_chunk: (A, x, Γ_scene) → (L*, r_1:T)。其中：
- **残差动力学集合**：{f_θm}_{m=1}^M 由关节驱动数据训练，预测 (τ, q̇, T) 的 T 步演化
- **风险曲线**：r_i = (1/M) Σ_m 1[ m_i^{(m)} < m_min ]，即令牌 i 不可行的经验概率
- **可证前缀**：L* = max{ L : max_{i≤L} r_i ≤ δ_feas }（δ_feas 默认 0.05）
- **重规划触发**：执行 A[1:L*] 后无条件重问 VLA；若 L*<T−1，额外把"截断原因"注入 VLA 上下文

**定义 164（关节驱动逆模型残差补偿 JDIR）** 真实关节动力学
τ = M(q)q̈ + C(q,q̇)q̇ + g(q) + f_fric(q̇) + f_back(q) + f_harm(q) + d(t)
- **标称模型**：τ_nom = M̂q̈ + Ĉq̇ + ĝ，残差 Δ = τ − τ_nom
- **在线估计**：Δ̂ ← RLS / GP / 神经残差模型，输入 (q,q̇,τ_cmd,τ_meas)
- **带界保证**：|Δ − Δ̂| ≤ ε_res，且 ε_res ≤ ε_budget（进入 Cert_contract 的前置条件）
- **补偿指令**：τ_cmd = τ_ref − Δ̂；若估计不确定度 > ε_budget，回退 τ_cmd = τ_ref 并降速

**定义 165（语义回退-关节证据对齐 SFVA）** 语义偏差
D_sem = w_p‖ê_i − Δx_i‖ + w_c·1[c_obs≠c_i] + w_s·slip + w_st·1[stall] + w_l·1[limit_hit]
其中 ê_i = FK(q_i) − FK(q_{i−1}) 为观测到的末端效应。
- **语义失败令牌**：若 D_sem > τ_sem，生成 b = (failure_type, D_sem, suggested_constraint)，追加到 VLA 上下文
- **失败类型**：grasp_miss / slip / stall / limit_hit / singularity / thermal_derate
- **重规划规则**：VLA.plan(o_t, ℓ, context ∪ {b})，并强制 suggested_constraint 进入 S_{k+1}

**定义 166（接触模式条件关节阻抗映射 SJIM）** 映射 Ψ: c ↦ (K_j(c), D_j(c), F_max(c))：
- c=free → (K_low, D_mid, —)；c=contact → (K_mid, D_high, F_safe)；c=grasp → (K_low, D_mid, F_grasp)；c=push → (K_high, D_mid, F_push)；c=slide → (K_mid, D_high, F_slide)；c=insert → (K_high, D_high, F_insert)
- **关节空间投影**：K_j = Jᵀ K_x J，D_j = Jᵀ D_x J
- **无源性约束**：K_j, D_j ⪰ 0 且满足接触无源条件（不向环境注入能量），否则投影到最近的无源矩阵

**定义 167（VLA-关节接地闭环 VJGC）** 算子 VJGC(M, o_t, ℓ)：
```
① A ← VLA.plan(o_t, ℓ, context)                    # 低频动作分块 + 接触令牌
② (L*, r) ← ACJF.predict(A, q, scene)              # 可证前缀
③ (K_j, D_j, F_max) ← SJIM.map(A[1:L*].c)          # 语义→关节阻抗
④ (q_ref, τ_ff, Cert_ground) ← JATG.ground(A[1:L*], x)
⑤ STDC.freeze(S_k); loop @1kHz:
       τ_cmd ← τ_ff + K_j e + D_j ė − Δ̂
       if ¬I_phys or x∉Ξ(S_k): semantic_interrupt
⑥ Δ̂ ← JDIR.update(q, q̇, τ_cmd, τ_meas)            # 带界残差
⑦ EV_joint ← (q,τ,F_contact,slip,stall,T,seq,hash) # 关节证据
⑧ D_sem ← SFVA.align(EV_joint, A[1:L*])
⑨ if D_sem > τ_sem or L* < T or interrupt:
       context ← context ∪ {SFVA.token(D_sem)}; goto ①
⑩ return (A_used, EV_joint, Cert_ground, Cert_contract)
```

**定义 168（物理-语义联合预算 B_js 与 PCE+++++）** B_js = (B_slow, B_fast, B_ground, B_sem, B_torque, B_thermal)。
- B_slow=(VLA_latency, token_budget)；B_fast=(joint_loop_WCET, bus_jitter)；B_ground=(IK_iters, trajectory_opt)；B_sem=(replan_count, repair_latency)；B_torque=(τ_headroom, I_headroom)；B_thermal=(T_headroom, derate_rate)
- **VOI 扩展**：voi_js(π) = VOI_meta_pessimistic(π) − cost_sem(π) − cost_phys(π)
  cost_sem = λ_vla·VLA_latency + λ_replan·replan_count
  cost_phys = λ_τ·max(0,|τ|−τ_headroom) + λ_I·max(0,|I|−I_headroom) + λ_T·max(0,T−T_headroom)
- **降级序**：B_slow 耗尽 → 保持当前可证前缀并冻结慢环；B_ground 耗尽 → 保守固定阻抗（第 60 轮 K_safe^general）；B_torque 耗尽 → 降速降力；B_thermal 耗尽 → 按 derate_rate 降额；B_sem 耗尽 → 安全停；B_fast 耗尽 → 切硬件安全环

### IP-161 JATG（关节动作令牌接地）

```python
class JointActionTokenGrounding:
    def __init__(self, robot, m_min=0.1, sigma0=1e-3):
        self.robot = robot
        self.m_min = m_min
        self.sigma0 = sigma0

    def ground(self, A, x0, dt=0.02):
        q_ref, tau_ff, certs, L_star = [], [], [], len(A)
        x = x0
        for i, a in enumerate(A):
            x = compose(x, a.delta_x)          # 6-DoF 位姿增量
            q = self.robot.ik(x)
            qd, qdd = finite_diff(q_ref[-1] if q_ref else q, q, dt)
            tau = self.robot.rnea(q, qd, qdd)  # M qdd + C qd + g
            m = self._margin(q, qd, qdd, tau)
            sigma = np.linalg.svd(self.robot.jacobian(q), compute_uv=False).min()
            grounded = (m >= self.m_min) and (sigma >= self.sigma0)
            certs.append(dict(m=m, sigma=sigma, hash=sha(q, tau), seq=i))
            if not grounded:
                L_star = i
                break
            q_ref.append(q); tau_ff.append(tau)
        return q_ref[:L_star], tau_ff[:L_star], certs[:L_star], L_star

    def _margin(self, q, qd, qdd, tau):
        vals = []
        for j in range(len(q)):
            vals += [(self.tau_max[j]-abs(tau[j]))/self.tau_max[j],
                     (self.qd_max[j]-abs(qd[j]))/self.qd_max[j],
                     (self.qdd_max[j]-abs(qdd[j]))/self.qdd_max[j],
                     self.dist_to_limit[j]/self.q_range[j],
                     (self.T_max[j]-self.T[j])/self.T_max[j]]
        return min(vals)
```

### IP-162 STDC（语义-力矩双频契约）

```python
class DualRateSemanticTorqueContract:
    def __init__(self, robot, f_fast=1000.0, tau_tube=0.15):
        self.robot = robot
        self.f_fast = f_fast
        self.tau_tube = tau_tube
        self.S_k = None
        self.frozen = False

    def publish(self, S_k):
        self.S_k = S_k
        self.frozen = True
        self.t_publish = time.time()

    def fast_step(self, x, q_ref, tau_ff, K_j, D_j, d_hat):
        if self.S_k is None:
            raise ContractViolation("no semantic constraint published")
        tau = tau_ff + K_j @ (q_ref - x.q) + D_j @ (x.qd_ref - x.qd) - d_hat
        if not self._phys_ok(x, tau):
            return "semantic_interrupt", tau
        if self._tube_dist(x, self.S_k) > self.S_k.rho:
            return "semantic_interrupt", tau
        if time.time() - self.t_publish > self.tau_tube:
            return "slow_loop_timeout", tau
        return "ok", tau
```

### IP-163 ACJF（动作分块关节可行性预测）

```python
class ActionChunkJointFeasibility:
    def __init__(self, ensemble, delta=0.05, m_min=0.1):
        self.ensemble = ensemble
        self.delta = delta
        self.m_min = m_min

    def certify_prefix(self, A, x, scene):
        risks = []
        for i in range(len(A)):
            bad = 0
            for model in self.ensemble:
                tau, qd, T = model.rollout(A[:i+1], x, scene)
                if self._margin(tau, qd, T) < self.m_min:
                    bad += 1
            risks.append(bad / len(self.ensemble))
        L_star = len(A)
        for i, r in enumerate(risks):
            if r > self.delta:
                L_star = i
                break
        return L_star, risks
```

### IP-164 JDIR（关节驱动逆模型残差补偿）

```python
class JointDriveInverseResidual:
    def __init__(self, nominal_model, eps_budget=0.05, lam=0.999):
        self.nom = nominal_model
        self.eps_budget = eps_budget
        self.lam = lam
        self.theta = np.zeros(nominal_model.n_features)

    def update(self, q, qd, tau_cmd, tau_meas):
        tau_nom = self.nom.rnea(q, qd, self.nom.qdd_hat(q, qd, tau_cmd))
        delta = tau_meas - tau_nom
        phi = self.nom.regressor(q, qd, tau_cmd)
        P = self.cov
        K = (P @ phi) / (self.lam + phi @ P @ phi)
        self.theta += K * (delta - phi @ self.theta)
        self.cov = (P - np.outer(K, phi @ P)) / self.lam
        return phi @ self.theta, float(np.sqrt(phi @ self.cov @ phi))

    def command(self, tau_ref, q, qd, tau_meas):
        d_hat, unc = self.update(q, qd, tau_ref, tau_meas)
        if unc > self.eps_budget:
            return tau_ref, False          # 不确定度过大：不补偿，降速
        return tau_ref - d_hat, True
```

### IP-165 SFVA（语义回退-关节证据对齐）

```python
class SemanticFallbackJointEvidence:
    def __init__(self, tau_sem=0.2):
        self.tau_sem = tau_sem

    def align(self, EV_joint, A_used, robot):
        b = []
        for i, a in enumerate(A_used):
            e_hat = robot.fk(EV_joint.q[i]) - robot.fk(EV_joint.q[i-1])
            D = (self.w_p * norm(e_hat - a.delta_x)
                 + self.w_c * (EV_joint.c_obs[i] != a.c)
                 + self.w_s * EV_joint.slip[i]
                 + self.w_st * EV_joint.stall[i]
                 + self.w_l * EV_joint.limit_hit[i])
            if D > self.tau_sem:
                b.append(dict(failure_type=self._classify(EV_joint, i),
                              D_sem=D,
                              suggested_constraint=self._repair(EV_joint, i)))
        return b
```

### IP-166 SJIM（接触模式条件关节阻抗）

```python
def map_contact_mode(c, robot, J):
    table = {
        'free':    (K_LOW,  D_MID,  None),
        'contact': (K_MID,  D_HIGH, F_SAFE),
        'grasp':   (K_LOW,  D_MID,  F_GRASP),
        'push':    (K_HIGH, D_MID,  F_PUSH),
        'slide':   (K_MID,  D_HIGH, F_SLIDE),
        'insert':  (K_HIGH, D_HIGH, F_INSERT),
    }
    Kx, Dx, Fmax = table[c]
    K_j = J.T @ Kx @ J
    D_j = J.T @ Dx @ J
    if not is_passive(K_j, D_j):
        K_j, D_j = project_to_passive(K_j, D_j)
    return K_j, D_j, Fmax
```

### IP-161 JATG（关节动作令牌接地）

```python
class JointActionTokenGrounding:
    def __init__(self, robot, m_min=0.1, sigma0=1e-3):
        self.robot, self.m_min, self.sigma0 = robot, m_min, sigma0

    def ground(self, A, x0, dt=0.02):
        q_ref, tau_ff, certs, L_star = [], [], [], len(A)
        x = x0
        for i, a in enumerate(A):
            x = compose(x, a.delta_x)
            q = self.robot.ik(x)
            qd, qdd = finite_diff(q_ref[-1] if q_ref else q, q, dt)
            tau = self.robot.rnea(q, qd, qdd)
            m = self._margin(q, qd, qdd, tau)
            sigma = np.linalg.svd(self.robot.jacobian(q), compute_uv=False).min()
            grounded = (m >= self.m_min) and (sigma >= self.sigma0)
            certs.append(dict(m=m, sigma=sigma, hash=sha(q, tau), seq=i))
            if not grounded:
                L_star = i
                break
            q_ref.append(q); tau_ff.append(tau)
        return q_ref[:L_star], tau_ff[:L_star], certs[:L_star], L_star

    def _margin(self, q, qd, qdd, tau):
        vals = []
        for j in range(len(q)):
            vals += [(self.tau_max[j]-abs(tau[j]))/self.tau_max[j],
                     (self.qd_max[j]-abs(qd[j]))/self.qd_max[j],
                     (self.qdd_max[j]-abs(qdd[j]))/self.qdd_max[j],
                     self.dist_to_limit[j]/self.q_range[j],
                     (self.T_max[j]-self.T[j])/self.T_max[j]]
        return min(vals)
```

class DualRateSemanticTorqueContract:
    def __init__(self, tau_tube=0.15):
        self.tau_tube = tau_tube
        self.S_k, self.frozen = None, False

    def publish(self, S_k):
        self.S_k, self.frozen, self.t_publish = S_k, True, time.time()

    def fast_step(self, x, q_ref, tau_ff, K_j, D_j, d_hat):
        if self.S_k is None:
            raise ContractViolation("no semantic constraint published")
        tau = tau_ff + K_j @ (q_ref - x.q) + D_j @ (x.qd_ref - x.qd) - d_hat
        if not self._phys_ok(x, tau):                 return "semantic_interrupt", tau
        if self._tube_dist(x, self.S_k) > self.S_k.rho: return "semantic_interrupt", tau
        if time.time() - self.t_publish > self.tau_tube: return "slow_loop_timeout", tau
        return "ok", tau

class ActionChunkJointFeasibility:
    def __init__(self, ensemble, delta=0.05, m_min=0.1):
        self.ensemble, self.delta, self.m_min = ensemble, delta, m_min

    def certify_prefix(self, A, x, scene):

                      for model in self.ensemble)

                return i, risks
        return len(A), risks

### IP-164 JDIR（关节驱动逆模型残差补偿）

```python
class JointDriveInverseResidual:
    def __init__(self, nominal_model, eps_budget=0.05, lam=0.999):
        self.nom, self.eps_budget, self.lam = nominal_model, eps_budget, lam
        self.theta = np.zeros(nominal_model.n_features)
        self.cov = np.eye(nominal_model.n_features) * 1e-3

    def update(self, q, qd, tau_cmd, tau_meas):
        tau_nom = self.nom.rnea(q, qd, self.nom.qdd_hat(q, qd, tau_cmd))
        delta = tau_meas - tau_nom
        phi = self.nom.regressor(q, qd, tau_cmd)
        K = (self.cov @ phi) / (self.lam + phi @ self.cov @ phi)
        self.theta += K * (delta - phi @ self.theta)
        self.cov = (self.cov - np.outer(K, phi @ self.cov)) / self.lam
        return phi @ self.theta, float(np.sqrt(phi @ self.cov @ phi))

    def command(self, tau_ref, q, qd, tau_meas):
        d_hat, unc = self.update(q, qd, tau_ref, tau_meas)
        if unc > self.eps_budget:
            return tau_ref, False
        return tau_ref - d_hat, True
```

                              D_sem=D,

def map_contact_mode(c, J):
    table = {
        'free':    (K_LOW,  D_MID,  None),
        'contact': (K_MID,  D_HIGH, F_SAFE),
        'grasp':   (K_LOW,  D_MID,  F_GRASP),
        'push':    (K_HIGH, D_MID,  F_PUSH),
        'slide':   (K_MID,  D_HIGH, F_SLIDE),
        'insert':  (K_HIGH, D_HIGH, F_INSERT),

    Kx, Dx, Fmax = table[c]
    K_j, D_j = J.T @ Kx @ J, J.T @ Dx @ J

| E194 ACJF | 不可行前缀 AUC；危险执行下降 | AUC ≥ 0.9；−80% |

| E196 VJGC 端到端 | vs 第 60 轮：接触任务成功率、语义恢复、物理违规 | +20%；≤ 300ms；< 0.1% |

## 5. 本轮最大风险

**一句话**：ACJF 与 JDIR 都是数据驱动估计器，若它们"自信地错"（高估可证前缀 / 低估残差），"接地证书"就会变成**虚假保证**，让 VLA 的幻觉动作在"已认证"旗号下把关节驱入力矩饱和或热损伤；因此必须以**非学习的解析硬限（力矩/电流/温度/限位）作为不可绕过的最后闸门**，只有在硬限监测同时通过时才签发证书。
