## 1. 直觉与动机（两个灵感的碰撞）

**灵感 1（角色一致性 → 合成数据的第一杀手不是动作质量，而是身份漂移）**

直觉：先想一个具体失败。用 WMA-0 仿真模式（F15/F21）把一条成功示教从中间帧续写成「偏离→修正」段，动作标签看上去很合理；但视频里那个杯子在第 8 帧悄悄换成了另一个杯子，瓶口在第 12 帧融化了。策略学到的是「对着一个会变形的物体执行修正」——这比不加数据更糟，因为它污染了 I2/I5 整个数据引擎的地基。多数队伍把「生成更多数据」当目标，真正该做的是「先证明这条合成轨迹里的物体还是同一个物体」。

「角色一致性」在视频生成里指主体身份跨帧保持；搬到机器人示范合成，它必须拆成三层，缺一不可：
1. **对象身份一致性**（还是同一个实例吗）：跨帧 re-ID 嵌入不漂移；
2. **几何/刚体一致性**（还是同一个形状吗）：对刚体，掩码应服从同一 SE(3) 变换，不能融化/穿模；
3. **任务角色一致性**（还在演同一个技能吗）：修正段必须属于**同一个得分点转移**（F17），不能被世界模型偷换成另一个技能。

严谨定义：设合成 rollout 帧 `{x_0..x_T}`、目标物体掩码 `{M_t}`、官方得分点里程碑序列 `{g_k}`。定义一致性向量
`C = (C_id, C_geo, C_flow, C_role)`，其中
`C_id = min_t cos(φ(x_t,M_t), φ(x_0,M_0))`；
`C_geo = min_t IoU(M_t, W_{0→t}(M_0))`（刚体用最佳拟合变换回投；可变形物体改用关键点二分匹配的归一化残差）；
`C_flow = 1 − 归一化刚体流残差`；
`C_role = 下一里程碑 P(g_{k+1}|x_t) 的单调达成度 × 与源技能分类器的一致度`。
合成段只有**每个分量**都过阈、且 `C_agg = min_i C_i ≥ τ_C` 时才允许入库。这里用 min 聚合而非加权平均是刻意的：加权平均会让一个满分分量掩盖一个已漂移的分量，而身份漂移恰恰是「只要一层坏了就全坏」。

第二重读法（行为角色一致性）：I5 合成「偏离→修正」时，修正必须仍由同一策略角色完成——同一技能、同一目标物体、同一得分点。否则我们教的是「抓偏了就换任务」，而不是「抓偏了就修正」。

核心反直觉点：**合成数据的瓶颈已从「造得出来」变成「敢不敢用」；一致性门禁不是后处理，而是数据引擎的准入定义。**

**灵感 2（论文创新点 → 清单不是越长越好，而是只能有一条可证伪的主线）**

直觉：两轮下来清单有 9 条，每条单看都合理；但若当论文投出去，审稿人只会问一句「你的**一个**新贡献是什么？」I1 是对标官方考纲做增广，I2 是加权混训，I3 是关键点伺服，I6 是部署工程——单独看都接近已知技巧，堆在一起反而稀释主张。真正的创新点不在模块数量，而在**闭环结构**：官方得分点（F17）同时充当（a）增广分布的考纲、（b）合成示教的验收标签、（c）离线消融的代理指标——即「考纲即监督信号（rubric-as-supervision）」。这条主张能被一句话陈述，也能被一个对照实验证伪。

严谨定义：一条创新点记为「可发表（paper-worthy）」，当且仅当同时满足四条：
(1) **可测**：对应至少一条计分轴或明确代理指标；
(2) **不可归约**：不能一句话还原为「换数据集/加增广/加正则」这类已知技巧；
(3) **可证伪**：存在一个最小实验，结果若为负就必须撤回主张；
(4) **有位置**：能说清最近前作与 delta。
据此建立**新颖性台账（Novelty Ledger, I11）**：逐条记录「主张—计分轴映射—最近前作—delta—可证伪预测—最小实验—审稿人最可能的攻击」。台账不是为写论文，而是**决定预算**：只有过四闸的点才配真机通道与人力，没过的显式降级为工程支撑项（要赢必须做，但不作为论文主张）。

本轮锁定主论文主张（v1.2）：
**「考纲即监督」的封闭数据引擎——用公开得分点同时定义增广分布、合成失败示教的验收条件与离线代理指标，把零样本泛化转化为分布内泛化，并用身份一致性门禁保证合成数据不反噬。**
I1/I2/I5/I10 是这条主张的四个环节；I3/I4/I6/I7/I9 要么是工程支撑，要么是待并入的候选证据。

**两者统一**：角色一致性给数据引擎补上「敢不敢用」的准入闸，论文创新点给整份清单补上「值不值得押」的审计闸。二者共同把第 2 轮的「数据引擎」从「多造数据」推进到「只造可验证、可归因、可发表的数据」。本轮结论：**中期胜负手仍是数据引擎，但引擎的护城河从生成能力转移到验收标准。**

## 2. 对第 2 轮痛点的增量修订

- P8（示教质量）扩为 **P8′**：质量不只指真实示教；合成示教有更硬的失败模式——身份漂移，均匀使用会把漂移当监督。
- 新增 **P9（身份漂移污染）**：世界模型 rollout 的对象身份/几何/技能角色漂移，会把「对变形物体的修正」写进策略；这是 I5/I7 的一票否决风险。
- 新增 **P10（清单膨胀与新颖性稀释）**：9→11 条，若不分层，人力被工程项吃掉、论文主线说不清；需 Novelty Ledger 做预算裁决。
- P2（泛化缺口）：一致性门禁与 I9 的检索表示共用同一套对象身份特征，减少重复建设。
- P7（先手窗口）：台账 + 分级消融共同决定「先做什么」，先手复利从「跑得快」变成「少走弯路」。

## 3. 研究问题（本轮立项 Q9–Q11，Q1–Q8 保留）

- **Q9（一致性的可计算定义与阈值标定）**：在无 3D 真值、无触觉（F8）条件下，`C_id/C_geo/C_flow/C_role` 哪些可稳定估计？`τ_C` 应按「最大化下游代理增益」还是「最大化真/伪 AUROC」标定，两者何时背离？
- **Q10（任务角色一致性的守门）**：如何用得分点里程碑 + 技能分类器保证合成修正段属于同一技能转移，而不是世界模型编造的新技能？误判如何止损？
- **Q11（新颖性台账到实验的映射）**：每条创新点能否压缩成「一句可证伪声明 + 一个最小实验 + 一个审稿人攻击点」？台账的决策规则如何避免误杀工程必需项、误留包装项？

## 4. 设计原则（新增 PR6/PR7，其余保留）

- **PR6 身份一致优先律**：任何合成数据先过一致性门禁，再谈数量与多样性；`C_agg < τ_C` 默认丢弃，不因「多样性」豁免。与 PR5 互补：PR5 问「教什么」，PR6 问「这条数据配不配教」。
- **PR7 单一主张律**：每轮只允许一条主论文主张；其余创新点必须作为该主张的证据或工程支撑，否则显式降级，防止清单膨胀稀释新颖性。
- PR1–PR5 保留（第 1/2 轮）。

## 6. 本轮最大风险

**一句话**：一致性门禁的最大风险是「用自己的代理指标证明自己」——若 `τ_C` 只在少量真机结果上标定，二维验收可能同时出现**假拒**（误杀合法的新物体合成数据）与**假收**（放过缓慢漂移），而离线指标依旧好看，导致 I5/I2 被漂移数据慢性污染且无人察觉。

## 7. 下轮迭代计划（深化与修剪，不推倒）

- **深化**：I10（把三层一致性落到可执行实现：SAM/开放词汇检测 + DINOv2 + 光流 + 里程碑分类器；先做四类人工腐蚀的分离度实验）；I11（为每条 paper-core 填「一句可证伪声明 + 最小实验」）；

- **待核实**：WMA-0 实际 rollout 的身份漂移量级、DiverseManip 是否足以作为「真值正样本」校准门禁、N 值与步骤分精确公式、榜单真实数据。

## 0. 创新点清单（每点：动机 / 与现有方案差异 / 技术可行性 / 所需资源 / 落地步骤 / 风险）

### I1 考纲校准五轴增广引擎 ★★★★★（维持 v2）
- **动机**：计分的 320 次真机评测每次都在 5 轴上偏离训练分布（P2/F2）；官方考纲与示例公开（F17），可把零样本泛化转成分布内泛化。
- **与现有方案差异**：直接 SFT 用标称数据；盲目增广用无校准随机化；本点用「考纲卡」把增广对准计分轴（PR1/PR5）。
- **技术可行性**：高。考纲卡 = LLM 解析 wiki + 人工校对（每任务约 10 分钟 × 32）；每轴 3 档剂量做响应曲线。
- **所需资源**：分割/inpainting 1×24GB GPU（F11）；磁盘同 v1.0。
- **落地步骤**：①32 张考纲卡；②背景/干扰物两轴按考纲放量；③外观/位置两轴 L0 先行；④剂量-响应定档；⑤轴间交互 2 档析因。
- **风险**：考纲卡与真实评测仍有偏差（示例截图锚定 + 单任务抽测）；位置重拼接物理不可行（L0「不可行动作占比」>5% 即降级为平移不变增广）。

### I2 数据引擎 2.0：孪生迁移 + 加权共训 ★★★★★（v3）
- **动机**：单模型平均分被最弱任务支配（P1）；真实与合成示教质量双重浪费（P8′）。
- **本轮深化（角色一致性）**：在 v2 的「孪生入训 + 官方 loader 加权 patch + 示教质量加权」之上，增加一条硬约束——**任何合成轨迹在入训前必须过 I10 一致性门禁**；门禁分数作为 per-episode 权重的一部分（`w_ep ∝ 质量分 × 1[C_agg ≥ τ_C]`），而不是仅做二值丢弃。
- **与现有方案差异**：均匀混训把容量浪费在已会任务、低质示教与漂移合成数据上；本点诊断先行、孪生定向、权重受控、合成验收。
- **技术可行性**：高（frozen-VLM/LoRA 单卡起步，F11；全参 action expert 4–8 卡）。
- **所需资源**：孪生子集 ≈1–2TB + 32 任务 ≈2TB；门禁离线 1×GPU 日。
- **落地步骤**：①孪生表；②下载孪生子集；③loader patch + batch 任务频率单测；④接入 I10 门禁；⑤族级 L0 验证正迁移后放量。
- **风险**：负迁移（孪生动态相反，如 ZipUp vs Unzip 拉链受力方向）——家族级 L0、低权重起步、退步即裁；门禁假拒导致可用合成数据过少——保留真实数据全量，门禁只作用于合成。

### I3 接触任务族关键点视觉伺服回退 ★★★（降级为工程支撑）
- 六要素同 v1.0；本轮按 I11 台账判定为「近似已知技巧」，不再作为论文主张，但仍是接触任务族的**必备工程回退**。
- I3′ 预案保留：若组委会裁定混合推理违规，改为「训练时辅助监督」，伺服关键点作辅助标签，推理纯端到端。
- **风险**：混合推理的「单模型」边界仍待书面确认；确认前不上计分通道。

### I4 人手干预感知门控 + 自适应 chunk ★★★★（工程支撑）
- 同 v1.0：手部检测 + `obs_delta_indices` 历史栈判别干预（<50ms）；状态机 INTERFERED→停持→重估→续做（PR3）；干预态短 chunk、稳定态长 chunk。
- 参照 WMA-0 部署参数（15Hz、horizon 16，F12）：干预态 4–6 步、稳定态 8–16 步，待真机标定。
- **风险**：误检导致频繁停持拖慢步骤分；用滞回 + 低置信回退。

### I5 非标称示教合成 + 得分点对齐恢复 ★★★★★（v3，本轮核心）
- **动机**：步骤分 = 官方得分点制（F17，每任务满分 100）；超时仍按进度计步骤分（F3）；数据集全成功、无失败示教（P8′）。
- **本轮深化（角色一致性 × 论文主张）**：把 v2 的「合成 + 达成下一得分点才保留」升级为**二维准入**——
  1. **合成方式不变**：扰动重放、跨段缝合、WMA-0 仿真续写（F15/F21）；
  2. **验收轴 A（任务角色一致性）**：只有达成下一官方得分点 `g_{k+1}`、且技能分类器判定仍属同一技能转移的段才保留；
  3. **验收轴 B（身份一致性）**：`C_agg = min(C_id, C_geo, C_flow, C_role) ≥ τ_C`；
  写入规则：`admit = (Δprog ≥ 0) AND (C_agg ≥ τ_C)`；仅两者同时成立才入库，否则丢弃或降权。
- **与现有方案差异**：v1.0 手工恢复原语引入「恢复动作新分布」；v2 只验进度；v3 同时验「进度」与「身份/角色」，堵住世界模型最隐蔽的污染路径。
- **技术可行性**：中-高。扰动/缝合是纯数据工程；身份度量用开放词汇检测 + SAM + DINOv2 + 光流，均为现成模型；里程碑检测器为轻量视觉分类器。
- **所需资源**：1×24GB GPU；数据工程 2 人周；检测器训练 1 GPU 日/任务族；I10 复用。
- **落地步骤**：①得分点逆向（wiki + JS 端点）；②3 个弱任务试点（PlugCharger/ZipUp/PourOutMedicine）；③接 I10 门禁；④进度头改得分点监督；⑤LoRA 增量训练；⑥单任务通道 A/B。
- **风险**：合成偏离分布与真实偏离失配（扰动幅度从 I1 考纲卡采样）；里程碑/技能分类器误差污染标签（置信门控 + 人工抽检 5%）；门禁阈值不当造成假拒（见 I10 标定协议）。

### I6 确定性低延迟部署服务 ★★★★（工程支撑）
- 同 v1.0：共享 backend + 每端口独立队列与 episode 状态隔离、fp8/INT8、torch.compile/CUDA Graph、obs 预取、`image_resize`、断线重连 + 健康探针（PR4）。
- 复用官方 model_server 的 msgpack/websocket 模式（F12）；2×A100 80G 覆盖 N=3–5 端口；单步预算参照 15Hz（≈66ms），目标 p99 < 40ms。
- **风险**：量化/编译带来动作分布漂移；每次提交前跑动作健康度回归。

### I7 世界模型测试时前瞻 ★★（v2，缓，新增客观裁撤判据）
- 同 v1.0：高险节点 O(1–2) 次小规模 rollout 择优；推理路径若第 3 轮延迟余量不足即裁撤。
- **本轮深化（角色一致性）**：裁撤判据从「延迟」单轴扩展为「延迟 × 一致性」双轴——先在离线用 I10 度量 WMA-0 在目标任务的 rollout 一致性；若 `C_agg` 中位数低于任务阈值，则直接把推理路径裁撤，世界模型资产仅作 I5 数据引擎的生成器。
- **风险**：一致性离线评估与真机前瞻收益相关性未建立；先只做诊断，不投入推理集成。

### I8 评测运营闭环 + 分级消融注册表 ★★★★（v2 维持）
- L0 离线 in-silico（免费无限次）→ L1 分数因子（2^(k-p)）→ L2 真机 top 2–3 候选（≥2 任务 × 各 2 次）。
- 注册表记录「离线预测增益 vs 真机实测增益」，滚动计算分层 Spearman；某代理指标相关性 >0.6 才可单独作 L2 准入依据。
- **本轮新增职责**：为 I10 的 `τ_C` 提供真机回填点——每次门禁开/关的 A/B 都写入注册表，用于校准「离线一致性 → 真机增益」映射。
- **风险**：相关性建立慢；先用 3–4 个已知真机结果回填对齐点。

### I9 reset 期检索类比迁移 ★★★★（维持）
- 在 `reset()`（每 episode 恰好一次，F18）用 DINOv2/开放词汇嵌入把首帧目标物体映射到「物体-技能库」（110 语料 + 32 任务），检索关键动作参数（gripper 开度、接近高度/朝向、技能模式），episode 内缓存作软先验。
- **本轮协同**：检索用的身份嵌入与 I10 的 `C_id` 共用同一编码器，既省算力又保证「检索认为同物」与「门禁认为同物」口径一致。
- **风险**：误检索注入错误先验（距离阈值门控，超阈退回无先验）；reset 期检索合规性需书面确认。

### I10 身份一致性门禁（新，本轮核心方法）★★★★★
- **动机**：世界模型合成数据的第一失败模式是身份漂移（P9）；官方仿真模式无一致性指标（F21）。没有门禁，I5 的「合成失败示教」与 I2 的「合成扩充」都会把漂移当监督。
- **与现有方案差异**：数据筛选通常只看动作成功/奖励；本点用**三层一致性 × 官方得分点**的二维准入，且一致性用 min 聚合而非平均，专防「一层坏了被其它层掩盖」。
- **严谨定义**：见想法区 §1 的 `C=(C_id,C_geo,C_flow,C_role)`；`admit = (Δprog ≥ 0) ∧ (∀_i C_i ≥ τ_i) ∧ (C_agg ≥ τ_C)`。
- **技术可行性**：高。C_id：DINOv2 物体块嵌入余弦；C_geo：SAM 掩码 + 背景最佳拟合 SE(2)/SE(3) 回投 IoU；C_flow：RAFT 光流减刚体拟合残差；C_role：得分点里程碑分类器 + 技能分类器一致度。全部离线、无新训练数据需求（分类器小样本微调）。
- **所需资源**：1×GPU 日跑库 + 1 人周工程；无额外标注（用官方得分点 + 少量人工抽检）。
- **落地步骤**：①四类人工腐蚀构造负样本（换物体、掩码畸变、帧乱序、技能换绑）；②在真实留出段（正样本）上测分离度 AUROC/各腐蚀检出率；③阈值 `τ_C` 按「最大化下游代理增益」而非「最大化 AUROC」选取；④接 I5/I2 入库；⑤真机 A/B 回填 I8。
- **风险**：**假拒**误杀合法的新物体合成数据（缓解：真实数据永不被门禁拦；合成数据保留 top-k 兜底）；**假收**放过缓慢漂移（缓解：每段多点采样 + `C_role` 交叉校验）；指标与真机增益相关性未建立前，门禁只用于「排序/降权」，不做唯一否决。

### I11 新颖性台账（新，元研究）★★★★
- **动机**：清单 11 条，若不分层会出现「工程项吃掉真机预算、论文主线说不清」的膨胀（P10）；需要把每条创新点映射到可证伪的最小实验。
- **与现有方案差异**：普通消融只回答「有没有用」；台账同时回答「新不新、能不能被证伪、值不值得投真机」。
- **技术可行性**：高（表格 + 评审 checklist）。
- **所需资源**：0.5 人周；无 GPU。
- **落地步骤**：①建 schema（见 §1.2）；②逐条填「主张/前作/delta/可证伪预测/最小实验/审稿攻击」；③按状态分 `paper-core / support / prune`；④每轮复盘更新。
- **风险**：自评偏乐观、把包装当创新（缓解：每条必须有「若结果为负就撤回」的硬条件；引入外部 checklist 或同伴评审）。

```python
def consistency(frames, masks, instr, skill_id):
    e0 = reid(frames[0], masks[0])                         # DINOv2 object embedding
    C_id   = min(cos(reid(frames[t], masks[t]), e0) for t in range(len(frames)))
    W      = [best_fit_rigid(frames[0], frames[t], bg_mask) for t in range(len(frames))]
    C_geo  = min(iou(masks[t], warp(masks[0], W[t])) for t in range(len(frames)))
    C_flow = 1.0 - mean(normalized_rigid_residual(flow[t], W[t]) for t in range(len(frames)))
    C_role = min(progress_monotone(frames, skill_id),
                 skill_agreement(frames, skill_id))         # 同一得分点转移 / 同一技能
    return {"id": C_id, "geo": C_geo, "flow": C_flow, "role": C_role}

TAU = {"id": .90, "geo": .85, "flow": .80, "role": .85}   # 占位，按 §2 G0 标定
TAU_C = .85

def admit(segment):
    c = consistency(segment["frames"], segment["masks"],
                    segment["instruction"], segment["skill_id"])
    return (segment["score_progress"] >= 0) and \
           all(c[k] >= TAU[k] for k in c) and min(c.values()) >= TAU_C
    # 关键1：min 聚合，防一层掩盖另一层
    # 关键2：二维准入，身份与得分点进度同时成立
```

def calibrate_tau(real_segments, corruptions, heldout, proxy_gain):
    # 负样本四类：换物体 / 掩码畸变 / 帧乱序 / 技能换绑
    pos = [min(consistency(s).values()) for s in real_segments]
    neg = [min(consistency(c).values()) for c in corruptions]
    report_auroc(pos, neg)                                  # 分离度诊断
    # 阈值不取 max-AUROC，而取下游代理增益最大点（决策论）
    return max(TAU_C_grid, key=lambda t: proxy_gain(apply_gate(t, heldout)))

## 2. 实验设计（v1.2：在分级消融上新增 G/N 系列）

| 级别 | 内容 | 通道/成本 | 通过判据 |
|---|---|---|---|
| G0 | 一致性指标分离度：真实留出段 vs 四类人工腐蚀（换物体/掩码畸变/帧乱序/技能换绑） | 离线（免费） | 综合 AUROC ≥ 0.85，且四类腐蚀各自检出率 ≥ 0.7 |
| G1 | 门禁开/关对下游 L0 代理与前 2 个任务真机增益 | 离线 + 少量真机 | 开 > 关；假拒率 < 10%；真机增益 ≥ 离线预测的 50% |
| G2 | 任务角色一致性：跨技能缝合段的识别 | 离线 | 技能换绑检出 ≥ 0.8 |
| N1 | 台账最小实验回填：每条 paper-core 至少一个可证伪结果 | 离线 + 已有真机 | 每条有「负结果即撤回」的明确判据 |
| L0 | I1 剂量-响应；I2 孪生正/负迁移；I5 合成质量；I9 不伤标称 | 离线（免费） | 孪生 Δprog>0 且无家族退步；I9 标称 Δprog≥0 |
| L1 | 增广 4 轴 × {on/off} 部分析因；guard 栈 3 模块析因 | 离线 + 少量真机 | 主效应显著的 ≤3 个组合进 L2 |
| L2 | top 组合真机确认 ≥2 任务 × 各 2 次 | 单任务通道 | 真机增益 ≥ 离线预测的 50% |

**首批 L2 排队计划**：①I10 门禁 G1（只开/关，变量最小）→ ②I5 试点 3 任务（二维准入）→ ③I2 共训基线 → ④I1 背景+干扰物轴 → ⑤I9 未见轴抽测。
