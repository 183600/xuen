# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 1 轮；本轮灵感：「可解释性」×「动作分块」）

> 第 54 轮已把技能组合下沉为动作空间剖面 `α_S`、组合图 `G_S`、云边契约 `C_ce` 与联合证书 `J=(ρ,A_cert,γ_ce,δ_a)`。本轮聚焦 **动作块的可解释化、解释对块长的反向门控、重叠混合的归因可识别性**。核心矛盾：H22：动作分块使"决策时间"与"失败时间"解耦，块内归因无法定位真正的因果片段，长块还会把一次误判放大成整段开环执行；H23：现有可解释性多为事后附加，不能进入控制回路，解释与块长/切块时机之间缺少可判定的契约，导致"解释看起来对、控制并未受益"。

## 0. 直觉与动机

**灵感 1（动作块是意图的自然单位 → 块级解释）**
直觉：解释单步动作 `a_t` 既琐碎又噪声大，而解释一个块 `chunk_t=(a_t,…,a_{t+H-1})` 更接近人类"意图级"理解。失败时人真正想问的是"这块里哪一段、哪些关节/维度出了问题"，而不是"第 37 步的第 4 维偏了 0.01"。因此把解释的作用域从单点扩展到 **时间-维度支撑集** `(Σ_span, D_dims)`，并强制给出忠实度证书，而不是一张热力图。

**灵感 2（可解释性反向控制块长 → 连贯块长与解释门控）**
直觉：块长的经典矛盾是"长块平滑但迟钝、短块灵活但抖动"。若解释在某个前缀长度内保持自洽（同一支撑集、同一主导维度），说明策略在该前缀内处于同一"意图 regime"，可以安全开环；一旦解释支撑集切换，就说明 regime 变了，应立刻截断。于是定义 **连贯块长 `H_coh`**，让解释稳定性成为块长的第一性约束：`H_t = min(H_coh, H_react, H_max)`。这把可解释性从"事后诊断"变成"在环控制参数"。

**灵感 3（块边界是因果悬崖 → 边界解释与解释导数触发器）**
直觉：块边界处策略输出会跳变，且下一块基于新观测，微小的边界扰动常被放大。若把解释沿时间求导 `||dE/dt||`，它在边界附近会显著升高。用这个"解释导数"作为变化检测器：超过阈值 `θ_E` 就提前切块并触发第 54 轮的 `Explain_loop → reprofile`。这样切块不再只由固定 stride 决定，而由"解释是否还稳定"决定。

**灵感 4（反事实块 → 可操作的最小解释）**
直觉：真正有用的解释是"如果这 3 步、这 2 个维度改成这样，就成功了"。这就是 **最小反事实块** `δ*`：在动作块上做稀疏编辑，使结果从失败翻转为成功，并最小化编辑代价。`δ*` 同时是解释（因果支撑）和修复建议（可回传云端重规划），比梯度热力图更可操作、更可验证。若在搜索预算内找不到 `δ*`，必须显式标记"解释不完整"，而不是假装解释成功。

**灵感 5（重叠混合的归因守恒 → 交互残差门控）**
直觉：时间集成下 `ā_t = Σ_i w_i(t) a_t^{(i)}`，执行动作是多个块的混合，归因天然不可识别。若归因算子对动作近似线性（如积分梯度），则可写成 `e_t = Σ_i w_i(t) e_t^{(i)} + r_t`，`r_t` 是混合引入的交互残差。**归因守恒**要求 `Σ_i w_i=1`；**可识别**要求 `||r_t||∞ ≤ θ_r`。一旦残差超阈值，就判定"混合解释不可信"，退回单块执行或缩短重叠，绝不把混合后的伪归因当成事实。

**灵感 6（可解释-动作金字塔扩展）**
直觉：在第 54 轮 `𝕃`（鲁棒性）与 `𝔸`（动作协同）之上叠加 **可解释层 `𝔼`**：`𝔼_0` 单步归因，`𝔼_1` 块级支撑集证书，`𝔼_2` 混合归因守恒，`𝔼_3` 意图级解释。跨层传递证书同时携带 `ρ`、`A_cert`、`E_cert`、`β`，形成 **鲁棒性-动作-解释三证书体系**。

## 1. 形式化定义（增量：定义 121–127）

**定义 121（动作块与时间集成）**
策略 `π_θ` 在时刻 `t` 输出动作块 `chunk_t = (a_t,…,a_{t+H-1}) ∈ A^H`，`H` 为块长，跨步 `S`，重叠率 `o = 1 - S/H`。时间集成执行动作
```
ā_t = Σ_{i: t∈[t_i, t_i+H)} w_i(t) a_t^{(i)} / Σ_{i} w_i(t),   Σ_i w_i(t) = 1
```
其中 `w_i(t)` 为权重（线性或指数衰减），`a_t^{(i)}` 为第 `i` 个块在 `t` 处的预测。

**定义 122（块级归因解释）**
`Explain_chunk(chunk_t, outcome) → E = (Σ, D, w)`：
- `Σ ⊆ {0,…,H-1}` 为块内连续时间子区间（可并集）；
- `D ⊆ {1,…,d}` 为动作维度子集；
- `w ∈ Δ^{|Σ|×|D|}` 为归因权重，满足 `Σ w = 1`。
`E` 要求覆盖归因质量 `≥ η`（如取支撑集使累计 |归因| 达总量的 80%），且 `Σ` 优先取最小连续区间（可读性偏好）。

**定义 123（解释忠实度证书）**
`E_cert = (Σ, D, suff, nec, min, stab)`：
```
suff(E) = P(R=1 | do(a_{Σ,D}:=a^{orig}_{Σ,D}, a_{¬Σ,¬D}:=a^{base}))
nec(E)  = 1 - P(R=1 | do(a_{Σ,D}:=a^{base}))
min(E)  = 1 - |Σ|·|D| / (H·d)
stab(E) = 1 - E_{||Δs||≤ε}[ JSD(E(s), E(s+Δs)) ]
```
其中 `suff` 为充分性（只保留支撑集即可复现结果），`nec` 为必要性（移除支撑集即破坏结果），`min` 为稀疏性，`stab` 为局部分布稳定性。称 `E` **忠实** 当且仅当
`suff ≥ τ_s ∧ nec ≥ τ_n ∧ min ≥ τ_m ∧ stab ≥ τ_b`。
另定义 **解释-动作一致性**：`D ⊆ D_ctrl`（可控制维度）且支撑集上动作未饱和，否则 `E` 为"动作不可达解释"，判不忠实。

**定义 124（连贯块长与解释门控调度）**
```
H_coh(s) = max{ H ≤ H_max : ∀ h ≤ H,
                agree(E_cert(s,h), E_cert(s,H))
                ∧ suff(E_cert(s,h)) ≥ τ_s
                ∧ stab(E_cert(s,h)) ≥ τ_b }
```
`agree` 要求支撑维度相同且时间区间嵌套/重叠比例 `≥ θ_span`。调度器取
```
H_t = clip( min(H_coh(s), H_react), 1, H_max ),   H_react = ⌊τ_e / c_trans⌋
```
其中 `H_react` 由第 54 轮边端可控延迟 `τ_e` 与转换成本 `c_trans` 导出。若解释导数 `||dE/dt|| > θ_E`，则提前截断 `H_t ← max(1, ⌊H_t/2⌋)`，并触发重规划。

**定义 125（时间索引动作剖面与块间兼容）**
将第 54 轮的动作剖面升级为 `α_S: A × {0,…,H-1} → [0,1]`，`α_S(a,τ)` 表示技能/策略在块内第 `τ` 步对动作 `a` 的占用度。块间兼容性定义为末端-初端剖面的 Jaccard：
```
compat_b(S_i,S_j) = |α_{S_i}(·,H_i-1) ∩ α_{S_j}(·,0)| / |α_{S_i}(·,H_i-1) ∪ α_{S_j}(·,0)|
```
块级组合可行当且仅当 `compat_b ≥ θ_a ∧ c_trans ≤ τ_e ∧ H_i ≤ H_react ∧ E_cert(S_i), E_cert(S_j) 忠实`。这把第 54 轮"技能级兼容"细化为"块边界兼容"。

**定义 126（混合归因守恒与交互残差）**
对时间集成，执行动作归因分解为
```
e_t = Σ_i w_i(t) e_t^{(i)} + r_t,   Σ_i w_i(t) = 1
```
其中 `e_t^{(i)}` 为第 `i` 个块的归因向量，`r_t` 为交互残差。称混合归因 **守恒可识别** 当且仅当 `||r_t||∞ ≤ θ_r`。若 `||r_t||∞ > θ_r`，混合解释被声明为不可信，执行退回单块模式或减小重叠率 `o`。

**定义 127（联合可解释证书 J+）**
```
J+ = (J, E_cert, H*, β, r, evidence, exhausted)
```
- `J = (ρ, A_cert, γ_ce, δ_a, evidence)` 为第 54 轮联合证书；
- `E_cert` 为块级解释忠实度证书；
- `H*` 为实际执行块长（由定义 124 给出）；
- `β` 为混合权重及归因，`r` 为交互残差；
- `exhausted` 标记反事实搜索是否耗尽预算。
**可部署谓词**：
```
deploy(J+) = [dom_J(T)=in] ∧ [δ_a<Θ_a] ∧ [E_cert 忠实]
             ∧ [||r||∞≤θ_r] ∧ [D⊆D_ctrl] ∧ [H*≤H_react] ∧ [¬exhausted]
```

## 2. 关键算法 伪代码

### IP-121 CHX（Chunk eXplanation）

```python
def chunk_explain(policy, s, H, outcome, eta=0.8):
    A = policy.chunk(s, H)                       # H x d
    G = integrated_gradients(policy, s, A)       # H x d 归因
    time_imp = G.abs().sum(dim=1)                # 时间重要性
    span = minimal_contiguous_interval(time_imp, mass=eta)
    dims = topk_dims(G.abs()[span].sum(dim=0), mass=eta)

    suff = do_success(policy, s, A, span, dims, mode='keep')
    nec  = 1.0 - do_success(policy, s, A, span, dims, mode='mask')
    stab = local_stability(policy, s, span, dims, eps)
    minm = 1.0 - (len(span) * len(dims)) / (H * policy.d)
    consistent = set(dims).issubset(policy.ctrl_dims) and not saturated(A, span, dims)
    return Explanation(span, dims, G, suff, nec, minm, stab, consistent)

def faithful(e, tau):
    return (e.suff >= tau.s and e.nec >= tau.n and e.min >= tau.m
            and e.stab >= tau.b and e.consistent)
```

### IP-122 CHS（Coherent Horizon Scheduler）

```python
def coherent_horizon(policy, s, H_max, tau):
    prev, H_best = None, 1
    for H in range(1, H_max + 1):
        e = chunk_explain(policy, s, H, outcome='open_loop')
        if prev is not None and not agree(e, prev):
            break
        if e.suff < tau.s or e.stab < tau.b or not e.consistent:
            break
        prev, H_best = e, H
    return H_best

def schedule_chunk(policy, s, H_react, H_max, tau, theta_E):
    H = min(coherent_horizon(policy, s, H_max, tau), H_react, H_max)
    if explanation_derivative(policy, s) > theta_E:
        H = max(1, H // 2)
        return H, 'replan'
    return H, 'ok'
```

### IP-123 CBX（Chunk Boundary eXplanation）

```python
def boundary_sensitivity(policy, s, chunk, eps=1e-2):
    e0 = chunk_explain(policy, s, len(chunk), outcome='open_loop')
    e1 = chunk_explain(policy, s + eps, len(chunk), outcome='open_loop')
    J_b = jacobian_norm(chunk[0], s)             # 边界动作雅可比范数
    dE  = js_divergence(e0, e1)                  # 解释突变
    trigger = (dE > theta_E) or (J_b > theta_J)
    return BoundaryCert(J_b, dE, trigger)
```

### IP-124 CFX（Counterfactual Chunk eXplanation）

```python
def counterfactual_chunk(policy, s, chunk, budget):
    # 在时间x维度上做稀疏编辑，最小化编辑代价，使失败->成功
    frontier = [(0.0, zero_edit(chunk))]
    visited = set()
    while frontier and budget > 0:
        cost, delta = heappop(frontier)
        budget -= 1
        if rollout_success(policy, s, chunk + delta):
            return Counterfactual(delta, span(delta), dims(delta),
                                  cost=cost, exhausted=False)
        for (tau, d) in attribution_guided_dims(chunk, delta):
            for step in candidate_steps(chunk, tau, d):
                nd = delta.with_edit(tau, d, step)
                key = nd.hash()
                if key not in visited:
                    visited.add(key)
                    heappush(frontier, (edit_cost(nd), nd))
    return Counterfactual(delta=None, exhausted=True)   # 显式标记不完整
```

### IP-125 BAT（Blend Attribution for Temporal ensembling）

```python
def blend_attribution(chunks, weights, s, theta_r):
    terms = [w * attribution(c, s) for c, w in zip(chunks, weights)]
    e_sum = sum(terms)                      # Σ w_i e^{(i)}
    a_bar = sum(w * c[t] for c, w in zip(chunks, weights))
    e_actual = attribution_of_action(a_bar, s)
    r = e_actual - e_sum                    # 交互残差
    if norm_inf(r) > theta_r:
        return ('unfaithful', e_sum, r)     # 回退单块 / 降重叠
    return ('ok', e_sum, r)
```

### IP-126 JIC（Joint Interpretable Certificate）

```python
def joint_interpretable_certificate(skill_seq, gamma_ce, s,
                                    delta_a_budget, rho_min, tau, H_react):
    J = joint_certificate(skill_seq, gamma_ce, delta_a_budget, rho_min)  # IP-118
    if J.status != 'ok':
        return J
    H, mode = schedule_chunk(policy, s, H_react, H_max, tau, theta_E)
    E = chunk_explain(policy, s, H, outcome='open_loop')
    if not faithful(E, tau):
        return ('reject', 'unfaithful_explanation', E)
    beta, r = blend_attribution(J.chunks, J.weights, s, theta_r)
    if norm_inf(r) > theta_r:
        return ('reject', 'blend_ambiguous', r)
    cf = counterfactual_chunk(policy, s, J.chunk, CF_BUDGET)
    if cf.exhausted:
        return ('reject', 'explanation_incomplete', cf)
    return ('ok', JointInterpretableCert(J, E, H, beta, r, cf))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| CHX | O(n_grad·H·d) | O(H·d) | 归因支撑覆盖 ≥ η、忠实度四项硬测试 |
| CHS | O(H_max·CHX) | O(H_max) | 解释一致性在 regime 内可传递 |
| CBX | O(CHX + H·d) | O(H·d) | 边界雅可比有界、解释导数可比 |
| CFX | O(b·L·|Σ|·d) | O(b·L) | 预算内完备或显式标记未耗尽 |
| BAT | O(k·CHX) | O(k·H·d) | 归因近线性、Σw=1 守恒 |
| JIC | O(AEC + CHS + CHX + BAT) | 同 | 门控逐项 sound |

**正确性定理（Interpretability-Gated Chunking Soundness）**
假设第 53–54 轮 (A22)–(A28) 成立；**(A29)** 参考解释器以概率 `≥1-β_f` 给出忠实归因；**(A30)** 在 `H_coh` 内解释一致蕴含同一因果支撑（无未检测的 regime switch）；**(A31)** 反事实搜索在预算内完备，否则置 `exhausted=True` 并拒绝部署。则
```
P(success ∧ deploy | P_c feasible)
  ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a) - β_f
      - P(||r||∞>θ_r) - P(regime switch ∧ not flagged)
```
且因 `H* ≤ H_coh ≤ H_react`，最坏校正延迟不超过边端可控延迟 `τ_e`。**门控的代价是覆盖率下降**：`¬deploy` 的样本被保守拒绝，故定理只承诺"部署样本内的成功率"，不承诺召回。

**推论（块长的反应性上界）**：若真实连贯块长为 `H*`、实际选择为 `H_t`，则累计反应性损失满足
`ReactivityLoss ≤ Σ_t |H*_t - H_t| · c_react`，故解释门控不会以"无限长块"换取平滑性。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 重叠混合导致归因不可识别 | 高 | 归因守恒 + 交互残差 `r` 门控 + 单块回退 |
| 连贯块长震荡 / 频繁切块 | 高 | 滞回 `hysteresis` + 最小驻留时间 + 冷启动锚点 |
| 反事实搜索组合爆炸 | 中 | 归因引导 beam + 预算上限 + `exhausted` 标记 |
| 解释-动作不一致（饱和/不可控维度） | 高 | `D⊆D_ctrl` + 饱和检测 + 否决部署 |
| "解释剧场"：好看但不因果 | 高 | suff/nec 反事实硬测试 + 红队 + 解释证书不通过即拒绝 |
| 长块把单次误判放大成整段错误 | 高 | `H_coh` 上限 + 解释导数提前截断 + 短块安全回退 |

## 6. 本轮最大风险

**一句话**：解释门控分块把动作块从"开环执行单元"升级为"可解释的因果单元"，但其 soundness **同时依赖归因在时间-维度上的可识别性、反事实测试的因果忠实、以及解释一致性能在块内可靠传递**；一旦重叠混合令归因不可识别、或解释证书在分布外退化为"解释剧场"，系统就会用高置信的错误解释去驱动过早/过晚切块，形成"看似可解释、实则失控"的部署，故必须以 **归因守恒 + 交互残差门控、suff/nec 反事实硬测试、单块安全回退** 三重护栏，宁可短块保守执行，也绝不把"可解释"当成"已理解"。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（CHX×CHS×CBX×CFX×BAT×JIC）

> 承接第 54 轮产物 v31。本轮在"动作空间剖面化 + 云边协同"之上，增加 **动作块可解释化、解释门控块长、反事实块解释、混合归因守恒** 四大算子，把可解释性从"事后诊断"改造为"在环控制变量"：
> - **CHX（Chunk eXplanation）**：块级时间-维度归因与忠实度证书 `E_cert`；
> - **CHS（Coherent Horizon Scheduler）**：以解释稳定性定义连贯块长 `H_coh`，门控块长与切块时机；
> - **CBX（Chunk Boundary eXplanation）**：块边界敏感度与解释导数触发器；
> - **CFX（Counterfactual Chunk eXplanation）**：最小反事实块 `δ*`，提供可操作、可验证的解释；
> - **BAT（Blend Attribution for Temporal ensembling）**：重叠混合的归因守恒与交互残差门控；
> - **JIC（Joint Interpretable Certificate）**：把第 54 轮联合证书 `J` 扩展为 `J+`。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-115/116/117/118 以纳入动作块与解释维度。

## 1. 符号体系增量（新增定义 121–127）

| 符号 | 含义 |
|---|---|
| `chunk_t ∈ A^H` | 动作块：`(a_t,…,a_{t+H-1})`，块长 `H`，跨步 `S` |
| `o = 1 - S/H` | 块重叠率 |
| `ā_t = Σ w_i(t) a_t^{(i)}` | 时间集成后的执行动作 |

| `E_cert = (Σ,D,suff,nec,min,stab)` | 解释忠实度证书 |
| `H_coh` | 连贯块长：解释支撑集自洽的最大前缀长度 |
| `H_react = ⌊τ_e/c_trans⌋` | 边端可控延迟导出的块长上界 |

| `α_S(a,τ)` | 时间索引动作剖面 |

| `e_t = Σ w_i e_t^{(i)} + r_t` | 混合归因分解，`r_t` 为交互残差 |
| `J+ = (J,E_cert,H*,β,r,exhausted)` | 联合可解释证书 |
| `D_ctrl` | 可控制动作维度集合 |

## 2. 关键算法 伪代码

### IP-121 CHX

```python
def chunk_explain(policy, s, H, outcome, eta=0.8):
    A = policy.chunk(s, H)                       # H x d
    G = integrated_gradients(policy, s, A)       # H x d
    time_imp = G.abs().sum(dim=1)
    span = minimal_contiguous_interval(time_imp, mass=eta)
    dims = topk_dims(G.abs()[span].sum(dim=0), mass=eta)
    suff = do_success(policy, s, A, span, dims, mode='keep')
    nec  = 1.0 - do_success(policy, s, A, span, dims, mode='mask')
    stab = local_stability(policy, s, span, dims, eps)
    minm = 1.0 - (len(span) * len(dims)) / (H * policy.d)
    consistent = set(dims).issubset(policy.ctrl_dims) and not saturated(A, span, dims)
    return Explanation(span, dims, G, suff, nec, minm, stab, consistent)

def faithful(e, tau):
    return (e.suff >= tau.s and e.nec >= tau.n and e.min >= tau.m
            and e.stab >= tau.b and e.consistent)
```

### IP-122 CHS

```python
def coherent_horizon(policy, s, H_max, tau):
    prev, H_best = None, 1
    for H in range(1, H_max + 1):
        e = chunk_explain(policy, s, H, outcome='open_loop')
        if prev is not None and not agree(e, prev):
            break
        if e.suff < tau.s or e.stab < tau.b or not e.consistent:
            break
        prev, H_best = e, H
    return H_best

def schedule_chunk(policy, s, H_react, H_max, tau, theta_E):
    H = min(coherent_horizon(policy, s, H_max, tau), H_react, H_max)
    if explanation_derivative(policy, s) > theta_E:
        return max(1, H // 2), 'replan'
    return H, 'ok'
```

### IP-123 CBX

```python
def boundary_sensitivity(policy, s, chunk, eps=1e-2):
    e0 = chunk_explain(policy, s, len(chunk), outcome='open_loop')
    e1 = chunk_explain(policy, s + eps, len(chunk), outcome='open_loop')
    J_b = jacobian_norm(chunk[0], s)
    dE  = js_divergence(e0, e1)
    return BoundaryCert(J_b, dE, trigger=(dE > theta_E) or (J_b > theta_J))
```

### IP-124 CFX

```python
def counterfactual_chunk(policy, s, chunk, budget):
    frontier = [(0.0, zero_edit(chunk))]
    visited = set()
    while frontier and budget > 0:
        cost, delta = heappop(frontier)
        budget -= 1
        if rollout_success(policy, s, chunk + delta):
            return Counterfactual(delta, span(delta), dims(delta),
                                  cost=cost, exhausted=False)
        for (tau, d) in attribution_guided_dims(chunk, delta):
            for step in candidate_steps(chunk, tau, d):
                nd = delta.with_edit(tau, d, step)
                if nd.hash() not in visited:
                    visited.add(nd.hash())
                    heappush(frontier, (edit_cost(nd), nd))
    return Counterfactual(delta=None, exhausted=True)
```

### IP-125 BAT

```python
def blend_attribution(chunks, weights, s, theta_r):
    e_sum = sum(w * attribution(c, s) for c, w in zip(chunks, weights))
    a_bar = sum(w * c[t] for c, w in zip(chunks, weights))
    r = attribution_of_action(a_bar, s) - e_sum
    if norm_inf(r) > theta_r:
        return ('unfaithful', e_sum, r)
    return ('ok', e_sum, r)
```

### IP-126 JIC

```python
def joint_interpretable_certificate(skill_seq, gamma_ce, s,
                                    delta_a_budget, rho_min, tau, H_react):
    J = joint_certificate(skill_seq, gamma_ce, delta_a_budget, rho_min)
    if J.status != 'ok':
        return J
    H, mode = schedule_chunk(policy, s, H_react, H_max, tau, theta_E)
    E = chunk_explain(policy, s, H, outcome='open_loop')
    if not faithful(E, tau):
        return ('reject', 'unfaithful_explanation', E)
    beta, r = blend_attribution(J.chunks, J.weights, s, theta_r)
    if norm_inf(r) > theta_r:
        return ('reject', 'blend_ambiguous', r)
    cf = counterfactual_chunk(policy, s, J.chunk, CF_BUDGET)
    if cf.exhausted:
        return ('reject', 'explanation_incomplete', cf)
    return ('ok', JointInterpretableCert(J, E, H, beta, r, cf))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CHX | O(n_grad·H·d) | O(H·d) | 支撑覆盖 ≥ η，忠实度四项硬测试 |
| CHS | O(H_max·CHX) | O(H_max) | 解释一致性在 regime 内可传递 |
| CBX | O(CHX + H·d) | O(H·d) | 边界雅可比有界，解释导数可比 |
| CFX | O(b·L·|Σ|·d) | O(b·L) | 预算内完备，否则 `exhausted` 拒绝 |
| BAT | O(k·CHX) | O(k·H·d) | 归因近线性，`Σw=1` 守恒 |
| JIC | O(AEC+CHS+CHX+BAT) | 同 | 门控逐项 sound，`¬deploy` 保守拒绝 |

**正确性定理（Interpretability-Gated Chunking Soundness）**
假设第 53–54 轮 (A22)–(A28) 成立；**(A29)** 参考解释器以概率 `≥1-β_f` 忠实；**(A30)** `H_coh` 内解释一致蕴含同一因果支撑；**(A31)** 反事实搜索预算内完备或标记耗尽。则
```
P(success ∧ deploy | P_c feasible)
  ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a) - β_f
      - P(||r||∞>θ_r) - P(regime switch ∧ not flagged)
```
且 `H* ≤ H_coh ≤ H_react`，最坏校正延迟不超过 `τ_e`。代价是覆盖率下降：定理只承诺部署样本内成功率，不承诺召回。

**推论（反应性上界）**：`ReactivityLoss ≤ Σ_t |H*_t - H_t| · c_react`，故解释门控不会用无限长块换取平滑性。

## 6. 与第 54 轮的差异

| 维度 | 第 54 轮 v31 | 第 55 轮 v32 |
|---|---|---|
| 动作单元 | 单步动作 `a` | 动作块 `chunk ∈ A^H` |
| 解释对象 | 失败后根因 `a_e` | 块内时间-维度支撑集 `(Σ,D)` |
| 解释角色 | 事后诊断 / 回传重剖分 | 在环门控块长与切块时机 |
| 块长 | 未建模 | `H_coh` 由解释稳定性定义 |
| 混合 | 无 | 归因守恒 + 交互残差 `r` |
| 证书 | `J=(ρ,A_cert,γ_ce,δ_a)` | `J+=(J,E_cert,H*,β,r)` |

**保留**：ACS/SCOM/CEC/AEC/JTC、鲁棒性谱 `ρ`、反向解释 `Explain`、云边契约 `C_ce`。
**升级**：动作剖面时间索引化、组合兼容边界化、联合证书可解释化。
**剪枝**：不引入新的云边通信通道；解释证书复用 `Explain_loop` 回传，仅增加 `E_cert` 字段。

## 7. 本轮最大风险

**一句话**：解释门控分块把动作块从"开环执行单元"升级为"可解释的因果单元"，但其 soundness **同时依赖归因在时间-维度上的可识别性、反事实测试的因果忠实、以及解释一致性能在块内可靠传递**；一旦重叠混合令归因不可识别、或解释证书在分布外退化为"解释剧场"，系统就会用高置信的错误解释去驱动过早/过晚切块，形成"看似可解释、实则失控"的部署，故必须以 **归因守恒 + 交互残差门控、suff/nec 反事实硬测试、单块安全回退** 三重护栏，宁可短块保守执行，也绝不把"可解释"当成"已理解"。
