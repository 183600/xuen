# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「语义分割」×「关节驱动」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**双证实测 + 关节可行 + 语义保守**。v9 的块证书本质是"预测的证书"（前向模型 F̂），其最大风险正是模型误差与域偏移同源。本轮从两个与"预测"正交的通道补证：语义分割给**外部致密证据**（眼前是什么、哪里可安全通过/抓取），关节驱动给**内部本体证据**（身体是否做得到、是否已经撞上）。二者以 meet-半格与 v9 证书合成，任一新因子失效即注入 ⊤、逐位退回 v9，绝不因"没分割到"或"没算到"而放宽安全。

## 0. 直觉与动机

**灵感 1（语义分割 → 从几何距离场到语义边缘场）**
直觉：v9 证书只知道"离障碍 O 有多远"，却不知道 O 是什么。地上的电缆、透明玻璃门、人的手、湿滑液体，在几何上是同一团点云，安全半径却相差一个量级。语义分割把标量间隙升级为**类条件间隙场**：`g_sem(x)=min_c(d_c(x)−r_c−u(x))`。再往前一步，分割给出 affordance——把手是可抓区、按钮是可压区，于是"哪里能抓"也变成可度量、可验证的量。关键纪律：分割只被允许**收紧**证书（类半径 + 边界不确定度膨胀 + 动态类时域膨胀），分割不可信（OOD/闪烁/遮挡）时该因子整块退化为 ⊤，绝不因"没分割到"而放宽安全。

**灵感 2（关节驱动 → 从任务空间预测到关节空间可行）**
直觉：v9 的中止点是任务空间几何点，"看起来能停"不等于"关节真的停得下来"。高速、大负载、近奇异位形下，刹车需要力矩/热预算，关节限位与速度上限才是硬约束。关节驱动思想给出**由内而外**的证书：逆动力学沿块轨迹算 τ、q̇、热累积、可操作度，得到归一化关节裕度 `j_min`；中止点必须满足**运动动力学可达**（存在满足 τ_max/q̇_max 的刹停轨迹）。更关键的是本体残差 `r_prop=‖τ_meas−τ̂‖`：它在每个 50Hz 周期都被**实测**，是接触/负载突变的 1 周期探测器，恰好补上 v9 前向证书只能"块边界才发现错了"的盲区。

**灵感 3（耦合 → 双证 meet 与"语义说哪里、关节说能否"）**
直觉：两个通道不是并列堆叠，而是同一张证书的两个正交维度：语义分割约束**间隙 g**，关节驱动约束**可行裕度 j**，v9 前向模型约束**间隙与 effort**。三者用逐分量 meet 合成：g 取 min、e 取 max、j 取 min、γ 取 AND。这带来两条漂亮性质：加因子只会更保守（单调），任一因子置 ⊤ 即精确退化为其余因子的合取，两个新因子都置 ⊤ 就逐位回到 v9。抓取上则体现为 `A_t`(语义 affordance) ∩ `R_t`(关节可达)——语义说"这是把手"，关节说"我够得到且扭得动"，交集为空就主动看/问人，而不是盲抓。

## 1. 研究问题（轮次升级版）

- **Q1（语义证书的保守性）**：在分割边界误差 ≤ ε、未知类按危险类处理、动态类按速度上界膨胀的假设下，`g_sem` 是否为真实间隙的下界？2.5D 反投影误差、细线/透明物体、遮挡会在哪里击穿这个下界？
- **Q2（关节可行性与双证代数）**：如何把力矩/速度/热/可操作度/运动动力学中止统一为归一化裕度 `j` 与证书 meet？双证合成的保守性、单调性与"新因子失效⇒⊤⇒逐位退回 v9"能否同时成立？
- **Q3（双证是否真的互补）**：语义失效与关节失效在什么条件下独立（`ρ_fail≈1`）？当共同未知原因（新颖可变形物体：既视觉 OOD、又动力学未建模）使 `ρ_fail≫1` 时，双证共识是否只是虚假安心？如何在线检测"共识崩塌"并退回保守短块？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 语义边缘证书律（Semantic Margin Certificate, SMC）**
安全间隙按危险类条件定义：`g_sem(x)=min_{c∈C_haz}(d_c(x)−r_c−u(x))`，u 为标定边界不确定度 + 熵；动态类按速度上界时域膨胀。分割通道仅在 OOD 分数、时域一致性满足阈值时可信（`γ_S=1`）；不可信即整因子置 ⊤。语义漂移 `Δ_sem` 只能**单向**抬高有效域偏移 `Δ_dom_eff=max(Δ_dom, αΔ_sem)`，绝不降低。

**P14 关节可行证书律（Joint Feasibility Certificate, JFC）**
块轨迹经 IK/逆动力学得到归一化裕度 `j_min=min_k min(力矩、速度、限位、可操作度、热预算)`；`j_min≥ν_min` 才可行。中止集收缩为运动动力学可达集 `P_t^kin`；空集即拒绝块。本体残差 `r_prop` 每 50Hz 实测，超阈即最近中止点停驻。

**P15 双证单调律（Dual-Certificate Monotonicity, DCC）**
最终证书 `Ĉ=Ĉ^F⊓Ĉ^S⊓Ĉ^J`，L 为逐分量 min/max/AND 的 meet-半格，`⊤=(+∞,−∞,+∞,1)` 为单位元。加因子只收紧不放宽；新因子失效注入 ⊤；两新因子皆 ⊤ ⇒ 逐位等于 v9 证书。语义/关节两视图分歧越大，`K_eff` 只许缩短。

## 3. 与基线的接口（如何退化）

- SMC 失效（OOD/闪烁/遮挡/投影不可靠）⇒ `Ĉ^S←⊤`，`Δ_sem≡0`；证书回到 v9 前向 +（若在）关节因子；
- JFC 失效（逆动力学模型失配 / IK 不可行）⇒ `Ĉ^J←⊤`，中止集回到 v9 几何集 `P_t^geo`（此时必须同时按 v9 语义降低速度上限）；
- SMC 与 JFC 同时失效 ⇒ `Ĉ=Ĉ^F`，`K_eff` 门控、`Δ_dom` 全部回到 v9，逐位等价 MetricVoiceGauge-ACMD；
- 关节残差守卫失效 ⇒ 该周期回退"按块证书执行 + 块边界复核"，等价 v9 中块守卫；
- AC/MW/ID 失效 ⇒ 按 v9 既有五级退化链继续下退；
- 全部失效 ⇒ v8 → v7 → v6。

## 4. 预期贡献

1. **语义边缘证书**：把分割变成可证明保守的类条件间隙场与 affordance 证据，并明确列出透明/细线/遮挡的击穿条件；
2. **关节可行证书 + 运动动力学中止**：把"看起来能停"升级为"身体真的停得下来"，并给出力矩/热/奇异裕度的归一化证书维度 j；
3. **双证 meet-半格**：证书合成的代数化——保守性 = 因子合取，退化 = 注入 ⊤，两因子缺席 = 逐位 v9；并引入失效相关指数 `ρ_fail` 作为"双证是否真互补"的诚实门槛；
4. **本体残差 1 周期守卫**：用实测关节残差补上前向模型的中块误差盲区；E571–E590 覆盖语义标定、透明/细线、关节裕度、运动动力学中止、残差时延、双证相关性、语义漂移、对抗分割与端到端任务。

## 5. 本轮最大风险

**一句话**：两个"实测"通道可能共享同一个未知原因——新颖可变形/透明危险物同时让分割变成 OOD（语义因子退化为 ⊤）并让关节在接触后才给出残差（本体因子迟到），此时双证共识不是互补而是同向失效（`ρ_fail≫1`），而 2.5D 语义投影还可能漏掉细线与透明障碍、高估 `g_sem`——系统会在最危险的新颖场景里得到最虚假的安心。

# 第 10 轮产物 · 创新点清单 v10：**MetricVoiceGauge-SJDC**（Semantic-Joint Dual Certificate）

> 背景：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮灵感：「语义分割」×「关节驱动」
> **继承纪律**：MetricVoiceGauge 九不变式（CVC-闭环、SpatialCert、RT-CVC、FaultCert、PrimitiveGraph、严格退化链、OTL、GCT、ER）全部保留；v8 的 DA-ML/SPR/Cal 与 v9 的 AC/MW/ID 原样继承。新组件一律为**可选增强**：任一环节不可用 ⇒ 该证书因子注入 `⊤`（对应 meet 的单位元），两新因子皆失效时**逐位等价退回 v9**（引理 90），而非行为漂移。

- Level-1：SMC 不可信（OOD/闪烁/遮挡/投影不可靠）⇒ `Ĉ^S←⊤`、`Δ_sem≡0`，证书 = `Ĉ^F⊓Ĉ^J`；

**新增定义 540（语义边缘场 Semantic Margin Field）** 设语义图 `S_t: Ω→C∪{unknown}` 及逐像素置信度，危险类集合 `C_haz`。点 x 的语义边缘：
```
g_sem(x) = min_{c∈C_haz} ( d_c(x) − r_c − u(x) )
u(x) = ε + λ_H·H(x),   H(x) 为分割熵
```
未知像素按 `r_unknown = +∞` 的危险类处理（保守）。对块路径 `Γ={x_1..x_K}`，动态类半径按 `r_c + v_c^max·kΔt` 膨胀，`g_S = min_{k≤K} g_sem(x_k)`。语义边缘场只用于**收紧**几何间隙，不用于放宽。

**新增定义 541（语义证书 Semantic Certificate）**
```
Ĉ^S = (g_S, +∞, +∞, γ_S)
γ_S = 1 ⇔ s_OOD ≤ τ_sem ∧ ρ_t ≥ ρ_min
ρ_t = min_{c∈C_haz} IoU( M_t^c, warp(M_{t−1}^c) )
```
`Ĉ^S` 只约束 g 维；e、j 维为 ⊤（不表态）。`γ_S=0` 时整因子替换为 ⊤（不是把 g 置 0，也不是置 −∞）。

**新增定义 542（语义漂移与有效域偏移 Semantic Drift）**
```
Δ_sem(t) = clip( JS(P_t^C ‖ P_ref^C) / Z, 0, 1 )
Δ_dom_eff(t) = max( Δ_dom(t), α·Δ_sem(t) ),  α ∈ [0,1]
```
`Δ_sem` **单向**：只可能抬高有效域偏移，从而只可能缩短 `K_eff`、更早触发 `ID` 强制唤醒。SMC 缺席时 `Δ_sem≡0`（单位元），`Δ_dom_eff=Δ_dom`，逐位回到 v9。

**新增定义 543（关节可行证书 Joint Feasibility Certificate）** 对块动作 `a^{1:K}` 做 IK 得关节轨迹 `(q_k,q̇_k,q̈_k)`，以辨识模型与负载估计 `ŵ` 做逆动力学得 `τ_k`。逐关节归一化裕度：
```
m_τ,k = min_i (τ_max,i − |τ_k,i|)/τ_max,i
m_v,k = min_i (q̇_max,i − |q̇_k,i|)/q̇_max,i
m_q,k = min_i [ min(q_k,i−q_min,i, q_max,i−q_k,i)/Δq_i ]
m_μ,k = (μ(q_k) − μ_min)/μ_ref                 # 可操作度/奇异裕度
m_E   = 1 − (E_0 + Σ_k Σ_i |τ_k,i·q̇_k,i|·Δt)/E_budget   # 热预算
j_k   = min(m_τ,k, m_v,k, m_q,k, m_μ,k)
j_min = min( min_k j_k, m_E )
Ĉ^J   = (+∞, −∞, j_min, γ_J)
```
`γ_J` 为模型可信位（负载估计在标定区间、逆动力学残差在校准带内）。IK 任一步不可行 ⇒ `j_min←−∞`（该维 ⊥）。`j_min ≥ ν_min` 才判可行。

**新增定义 544（运动动力学可达中止集 Kinodynamic Abort Set）**
```
P_t^kin = { p ∈ P_t^geo : ∃ 刹停关节轨迹 (q_p,q̇_p)→静止
            满足 |τ|≤τ_max, |q̇|≤q̇_max, q∈[q_min,q_max],
            且刹车全程语义+几何间隙 ≥ d_safe }
```
最终中止集 `P_t←P_t^kin`。`P_t=∅` ⇒ 拒绝该块、退回 K=1（等价 v9 逐步语义）。JFC 缺席时 `P_t^kin←P_t^geo`（单位元）。

**新增定义 545（扩展证书格与双证 meet Extended Certificate Lattice）**
```
L = (ℝ∪{±∞})³ × {0,1}
⊤ = (+∞, −∞, +∞, 1),   ⊥ = (−∞, +∞, −∞, 0)
x ⊓ y = ( min(x.g,y.g), max(x.e,y.e), min(x.j,y.j), x.γ∧y.γ )
```
序：`x ⪯ y ⇔ x.g≤y.g ∧ x.e≥y.e ∧ x.j≤y.j ∧ x.γ≤y.γ`（x 更保守）。`(L,⊓,⊤)` 为交换、结合、幂等的 meet-半格。块证书：
```
Ĉ_t = Ĉ^F ⊓ Ĉ^S ⊓ Ĉ^J
valid(Ĉ) ⇔ g≥d_safe ∧ e≤τ_eff ∧ j≥ν_min ∧ γ=1
```
其中 `Ĉ^F=(g_F,e_F,+∞,γ_F)` 为 v9 前向证书（j 维补 ⊤）；`Ĉ^S=(g_S,+∞,+∞,γ_S)`；`Ĉ^J=(+∞,−∞,j_min,γ_J)`。

**新增定义 546（本体残差守卫 Proprioceptive Residual）**
```
r_prop(k) = max( ‖τ_meas(k) − τ̂_k‖∞ / τ_max^max,
                 ‖q̇_meas(k) − q̇_k‖∞ / q̇_max^max )
```
50Hz 每周期计算。`r_prop > τ_prop` ⇒ 判为接触/负载/模型失配，切换到 `≤k` 的最大 `p*∈P_t` 停驻，并记 `reason=PROP`。它是**实测**通道，不是预测通道。

**新增定义 547（语义-关节抓取准入 Semantic-Affordance Joint Admission）**
```
A_t = { 由语义 affordance 掩码（把手/边缘/按钮）反投影得到的候选位姿 }
R_t = { p∈A_t : IK 可行 ∧ j(p) ≥ ν_min ∧ 抓取构型可操作度达标 }
G_t = A_t ∩ R_t
```
`G_t=∅` ⇒ 触发主动感知（改变关节构型取新视角）或人机确认，**禁止盲抓**。该模块为可选增强；失效时退回 v9 的几何抓取候选集。

**新增定义 548（证书因子清单 Certificate Factor Manifest）** 每周期记录
```
µ_t = (b_F, b_S, b_J, b_ID, reason)
```
`b_*=1` 表示该因子在场且可信，`b_*=0` 表示已注入 `⊤`（或 v9 对应休眠）；`reason ∈ {OK, OOD, LOW_IOU, IK_INFEAS, MODEL_MISMATCH, PROP, DEADLINE, DORMANT}`。该清单是退化逐位等价审计与"共识崩塌"统计的唯一事实源。

**新增定义 549（双证失效相关指数 Dual-Failure Correlation Index）** 在标定压力测试集（N 个回合）上
```
p_S = P(S 因子失效), p_J = P(J 因子失效)
ρ_fail = P(S 失效 ∧ J 失效) / (p_S·p_J)
```
`ρ_fail=1` 表示（该分布上）近似独立，`ρ_fail<1` 亚独立，`ρ_fail>1` 正相关。预注册：只有 `ρ_fail ≤ 1.2` 时方可宣称"双证互补"；否则必须把双证共识降级为启发式，安全论证只依赖 v9 因子 + 保守短块。

HAZARD = {'human', 'glass', 'cable', 'liquid', 'heat', 'unknown'}
TOP = Cert(g=float('inf'), e=float('-inf'), j=float('inf'), gamma=1)

def meet(a, b):
    return Cert(min(a.g, b.g), max(a.e, b.e), min(a.j, b.j),
                a.gamma and b.gamma)

def cert_valid(c, d_safe, tau_eff, nu_min):
    return (c.g >= d_safe and c.e <= tau_eff
            and c.j >= nu_min and c.gamma == 1)


# IP-357 SemanticMarginCertifier：语义边缘证书器
class SemanticMarginCertifier:
    def __init__(self, radii, epsilon, lambda_H=0.3, tau_sem=0.6,
                 rho_min=0.5, alpha=0.5):
        self.r = radii                    # class -> 安全半径 (m)
        self.eps, self.lam = epsilon, lambda_H
        self.tau_sem, self.rho_min = tau_sem, rho_min
        self.alpha = alpha
        self.prev = None

    def _u(self, x, entropy):
        return self.eps + self.lam * entropy[x]          # 定义 540

    def certify(self, sem, plan, dt, K):
        # sem: labels, probs, per-class distance transforms, vel bounds
        g = float('inf')
        for k in range(K):
            x = plan.point(k)
            for c in HAZARD:
                r_k = self.r[c] + sem.vmax[c] * k * dt   # 动态膨胀
                g = min(g, sem.dist[c][x] - r_k - self._u(x, sem.entropy))
        rho = sem.temporal_iou(self.prev, classes=HAZARD)  # 定义 541
        s_ood = sem.energy_score(self.ref_stats)
        gamma = int(s_ood <= self.tau_sem and rho >= self.rho_min)
        d_sem = sem.js_hist(self.ref_hist) / sem.norm_z    # 定义 542
        self.prev = sem
        return Cert(g=g, e=float('-inf'), j=float('inf'),
                    gamma=gamma), d_sem


# IP-358 JointFeasibilityCertifier：关节可行证书器
class JointFeasibilityCertifier:
    def __init__(self, robot, nu_min=0.10, tau_prop=0.15,
                 payload_range=(0.0, 1.5)):
        self.robot, self.nu_min = robot, nu_min
        self.tau_prop, self.payload_range = tau_prop, payload_range

    def certify(self, q0, qd0, actions, dt):
        try:
            q, qd, qdd = self.robot.ik_traj(q0, qd0, actions, dt)
        except IKInfeasible:
            return Cert(float('inf'), float('-inf'), float('-inf'), 1), None
        w = self.robot.payload_estimate()
        tau = self.robot.inverse_dynamics(q, qd, qdd, w)
        m_tau = ((self.robot.tau_max - abs(tau))
                 / self.robot.tau_max).min()
        m_v = ((self.robot.qd_max - abs(qd)) / self.robot.qd_max).min()
        m_q = self.robot.limit_margin(q).min()
        m_mu = ((self.robot.manip(q) - self.robot.mu_min)
                / self.robot.mu_ref).min()
        m_E = 1.0 - ((self.robot.E0 + abs(tau * qd).sum(axis=1).sum() * dt)
                     / self.robot.E_budget)
        j = min(m_tau, m_v, m_q, m_mu, m_E)
        gamma = int(self.payload_range[0] <= w <= self.payload_range[1])
        return Cert(float('inf'), float('-inf'), float(j), gamma), (q, qd, tau)

    def kinodynamic_abort_set(self, q, qd, geo_pts, sem_cert, dt):
        pts = []
        for p in geo_pts:
            if self.robot.exists_braking_traj(
                    q[p], qd[p], limits='all',
                    clearance=lambda s: sem_cert.clearance_at(s) >= self.d_safe):
                pts.append(p)                                # 定义 544
        return pts


# IP-359 DualCertificateCompositor：双证合成
class DualCertificateCompositor:
    def compose(self, c_forward, c_sem, c_joint):
        return meet(meet(c_forward, c_sem), c_joint)         # 定义 545

    def midchunk(self, chunk, k_exec, live, prop_guard, sem):
        r = prop_guard.residual(live)                        # 定义 546
        if r > prop_guard.tau_prop:
            return ('abort', chunk.nearest_abort(k_exec), 'PROP')
        if sem is not None and not sem.boundary_consistent(live):
            return ('shorten', max(1, k_exec), 'SEM_FLICKER')
        return ('continue', k_exec + 1, 'OK')


# IP-360 SemanticAffordanceJointAdmission：语义-关节抓取准入

## 4. 推导

**引理 87（语义边缘场保守性）** 设 (A1) 分割边界误差 Hausdorff ≤ ε；(A2) 真实危险像素均属于 `C_haz`，未知像素按危险类处理；(A3) 动态类在 k 步内位移 ≤ `v_c^max·kΔt`。则对任意路径点 x：
```
g_sem(x) = min_c( d_c(x) − r_c − u(x) ) ≤ 真实危险间隙(x)
```
证明：由 (A1)，预测距离是对真实距离的至多 ε 高估，即 `d_true ≥ d_c(x) − ε`。于是 `d_true − r_c ≥ d_c(x) − r_c − ε ≥ d_c(x) − r_c − u(x)`（因 `u≥ε`）。动态类由 (A3) 把真实最小间隙下界变为 `d_c − v kΔt`，定义 540 的膨胀半径 `r_c+v kΔt` 恰好抵消。取 min 保序，结论成立。故 `g_S≥d_safe ⇒ 真实间隙≥d_safe`。∎
*击穿条件*：A1 对亚像素细线/透明/镜面不成立（距离变换可能漏检），A2 对"伪装成安全类"的对抗纹理不成立。

**引理 88（关节可行证书保守性）** 设实际与标称逆动力学误差满足 `‖τ−τ̂‖∞ ≤ δ_τ`，速度测量无误，热模型误差 ≤ `δ_E`，且 `ν_min ≥ δ_τ/τ_max + δ_E/E_budget + δ_v/q̇_max`。若 `j_min ≥ ν_min`，则块内实际执行满足 `|τ|≤τ_max`、`|q̇|≤q̇_max`、`q∈[q_min,q_max]`，且不越热预算。证明：由三角不等式 `|τ|≤|τ̂|+δ_τ ≤ τ_max(1−m_τ)+δ_τ ≤ τ_max(1−ν_min)+δ_τ ≤ τ_max`；速度与热同理；限位由 IK 可行 + `m_q` 保证，可操作度裕度排除近奇异。∎

**引理 89（双证 meet 的保守性、单调性与退化）** 对定义 545 的 `(L,⊓,⊤)`：
(i) `valid(Ĉ) ⇒` 每个在场因子满足各自约束；若各因子约束对其物理量是可靠的（引理 87、88 与 v9 引理 82），则其合取可靠；
(ii) 单调性：`x⊓y ⪯ x`，即增加因子只会更保守（g 更小、e 更大、j 更小、γ 更弱）；
(iii) 单位元：`x⊓⊤ = x`；
(iv) 退化：若 `Ĉ^S=Ĉ^J=⊤`，则 `Ĉ=Ĉ^F`，逐位等于 v9 证书；
(v) 任一因子 `γ=0` 或 `g<d_safe`、`e>τ_eff`、`j<ν_min` ⇒ `valid(Ĉ)=0`。
证明：(i) 由 meet 逐分量取最保守值与 γ 的 AND；(ii)(iii) 由 min/max/AND 的格性质直接展开；(iv) 代入 `⊤` 逐分量化简；(v) 由 valid 定义。∎

**引理 90（退化逐位等价）** SMC 失效注入 `Ĉ^S=⊤` 且 `Δ_sem≡0`；JFC 失效注入 `Ĉ^J=⊤` 且 `P_t^kin=P_t^geo`。由引理 89(iv)，两因子皆失效时 `Ĉ=Ĉ^F`；由定义 542，`Δ_dom_eff=Δ_dom`；由定义 548，因子清单记录 `(1,0,0,·)`。故下游（`δ_trigger`、`K_eff`、M₀ 硬检查、中止语义）读到的输入与 v9 逐位一致，可观测日志仅多出因子清单字段。∎

**引理 91（本体残差守卫的中块检测时延）** 设接触/负载突变在一个控制周期内使实测关节力矩变化超过 `τ_prop·τ_max^max`。因 `r_prop` 每周期由**实测**量计算（定义 546），首次越阈发生在事件后第 1 个周期，守卫随即切换至 `p*≤k` 停驻，检测+处置时延 ≤ 1 个周期（20ms）。对比 v9 前向块证书只在块边界复核，误差暴露时延 ≤ K·Δt。注意：该引理只保证"接触后快速缓解"，**不**保证"接触前预测"，故不能替代语义/几何避障。∎

**引理 92（语义漂移门控的单调性与即时性）** 由定义 542，`Δ_dom_eff ≥ Δ_dom`，而 v9 定义 539 中 `K_eff` 对域偏移单调不增、`ID` 唤醒对域偏移单调不减，故语义漂移只会收紧、不会放宽；SMC 缺席时 `Δ_sem≡0` 精确恢复 v9。若类直方图漂移在单帧掩码内可观测，则语义路径的检测时延为 1 帧，短于 DA-ML 的 20 帧滑窗（在"漂移首先表现为类分布变化"的假设下）。∎

**引理 93（双证互补性的诚实门槛）** 设压力分布上 `ρ_fail=P(S∧J)/(p_S p_J)`。则 `P(S∧J)=ρ_fail·p_S p_J`。若 `ρ_fail ≤ 1+ε_ind`，双证同时失效概率不超过独立乘积的 `1+ε_ind` 倍；若 `ρ_fail>1+ε_ind`，则不得以"双证独立"论证安全性，安全论证必须退回 v9 因子 + 保守短块（`K_eff` 上限下调）。证明：代数恒等。∎ 该引理的作用是**拒绝**把相关性当独立性、把共识当证明。

| 语义漂移（E581） | 时延 1 帧且无额外误唤醒 | 调 α、加迟滞 |

## 8. 本轮最大风险

**一句话**：两个"实测"通道可能共享同一个未知原因——新颖可变形/透明危险物同时让分割变成 OOD（语义因子退化为 ⊤）并让关节在接触后才给出残差（本体因子迟到），此时双证共识不是互补而是同向失效（`ρ_fail≫1`），而 2.5D 语义投影还可能漏掉细线与透明障碍、高估 `g_sem`——系统会在最危险的新颖场景里得到最虚假的安心。
