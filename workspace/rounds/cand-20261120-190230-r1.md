# 第 1 轮（感知—交互子循环第 1 轮；本轮灵感：「手眼标定」×「阻抗控制」）

> **基线**：MetricVoiceGauge-NCD-HUTDH-v16（定义 627–656；引理 131–136；实验 E671–E690）。
> 本轮纪律：**不推倒 v16**。BTS/TRM/WBC/CSC 以及 v15→v14→…→v6 全部保留。三个新组件——HCM（手眼校准管理器，含坐标系证书 CalCert）、ICC（阻抗证书控制器，含能量罐/力/摩擦锥证书 ImpCert）、PIC（感知—交互耦合证书）——一律以**中立元**接入，失效即严格退回 v16（引理 143），再沿 v16→v15→…→v6 退化链退回。本轮只做三件事：把"手眼标定"改写为**随运动与观测演化的坐标系可信域**、把"阻抗控制"改写为**可记账的交互能量证书**、把"先看清再接触"改写为**刚度—不确定度对偶约束下的单调退化调度**。

## 0. 直觉与动机

**灵感 1（手眼标定 → 坐标系不是常量，而是一张会过期的证书）**
直觉：v16 的行为树节点默认"我看得准、我知道自己在哪"。但所有视觉 Action 的证书其实都挂在一个外部手眼变换 `T_C^E` 上。标定不是一个一次求出的矩阵：它有协方差、有工作空间有效域、有可观测性条件（退化位形下某些方向根本不可观），还会因碰撞、温漂、换相机、重装夹具而漂移。现有做法把标定误差当成"小噪声"，于是节点照常执行，只是精度差一点。核心创新：**手眼校准管理器（Hand-Eye Calibration Manager, HCM）+ 坐标系证书（Calibration Certificate, CalCert）**。`CalCert = (T̂, Σ_T, r_T, O, V_valid, t_stamp)`：变换估计、李代数协方差、置信半径、可观测性指标、有效工作域、时间戳。任何依赖视觉的节点，其前置证书 `Pre` 必须包含 `CalCert` 有效；标定一旦过期或漂移，节点不是"稍微不准"，而是**证书不成立、必须回退**。
关键反直觉点：**手眼标定的产物不是"一个矩阵"，而是"一个随运动和观测演化的可信域"**；标定的正确性问题是证书新鲜度问题，不是参数估计精度问题。

**灵感 2（阻抗控制 → 阻抗不是增益，而是一本能量账）**
直觉：v16 的 WBC 只保证动力学可行，但接触任务里"动力学可行"不等于"接触稳定"。笛卡尔阻抗 `(M_d, D_d, K_d)` 若任意时变，会向系统注入能量、破坏无源性；接触力可能超过执行器/工件上限，切向力可能冲出摩擦锥，刚度突变还会产生冲击。核心创新：**阻抗证书控制器（Impedance Certificate Controller, ICC）+ 交互证书（Impedance Certificate, ImpCert）**。`ImpCert = (K_min, K_max, D_min, F_max, μ, E_tank, φ_pass, t_stamp)`：刚度/阻尼可行区间、力上界、摩擦系数、能量罐余量、无源性裕度。阻抗参数的任何调整都必须从能量罐"扣款"，刚度升高扣款、降低退款，余额恒非负。接触切换必须通过**能量桥梁**，而不是直接跳增益。
关键反直觉点：**阻抗控制的证书不是"跟踪误差小"，而是"能量账本不透支"**；一个跟踪得很好但能量罐见底的阻抗，在证书语言里是不可执行的。

**灵感 3（手眼标定 × 阻抗控制 → 刚度—不确定度对偶，同一份安全预算的两种花法）**
直觉：视觉越不确定，刚度就必须越低。接触时力近似 `F ≈ K·e`，而位置误差的最坏值正是视觉证书给出的 `e_vis`；要保证 `F ≤ F_max`，就必须 `K ≤ F_max/e_vis`。可另一方面，任务要求位置精度 `ε`，在扰动 `w_max` 下又要求 `K ≥ w_max/ε`。两者夹出一个可行区间 `[K_req, K_allow]`。核心创新：**感知—交互耦合证书（Perception-Interaction Certificate, PIC）**：`K_req ≤ K_allow` 才允许执行接触节点；等价地 `e_vis ≤ ε·F_max/w_max`。当不可行时，只有三条合法退化路：**降力/增柔**（缩小 `F_max` 或放宽 `ε`）、**主动重标定**（拉低 `e_vis`）、**改接触策略**（切换力伺服/柔顺搜索）。
关键反直觉点：**"提高视觉精度"和"降低刚度"不是两件事，而是同一份安全预算的两种花法**；"看不清就硬顶"在证书语言里等价于透支，且透支的利息由接触力一次性偿付。

**三者如何统一**
统一为 **v16 行为层之下的感知—交互证书层**：v16 回答"按行为树语义、当前里程碑与 WBC 阶层能执行哪个全身行为序列"（`Exec_v16`），v17 回答"在坐标系证书有效、交互能量不透支、刚度—不确定度对偶可行时，还能把哪个行为真正落到接触上"（`Exec_v17`）。HCM 维护 `CalCert` 并向 BTS 的视觉节点供给前置证书；ICC 维护 `ImpCert` 并把阻抗参数约束为能量可行的算子；PIC 在两者之间做可行性判定与退化选择；CSC 在原有 `(tick预算, 里程碑, WBC阶层)` 三元退化之外，增加**标定维护预算**这一可抢占维度。共享状态 `ζ_vi = (CalCert, ImpCert, PIC, B_tick, B_cal, m*, h*, drift_vis, mode_vi)`。**HCM 回答"我现在看得到多准"，ICC 回答"我现在能用力多硬、账上还有多少能量"，PIC 回答"在这个视觉精度下最多允许多硬"，CSC 回答"这一帧是先干活还是先补标定、接触节点到底放不放行"**。四者不是四个补丁，而是"感知—交互—调度—退化"的实现链，且 `Exec_v17 ⊆ Exec_v16 ⊆ Exec_v15`。

## 1. 研究问题（轮次升级版）

- **Q1（坐标系证书的表示与传播）**：如何在 SE(3) 上定义带协方差半径与可观测性指标的 `CalCert`，使"置信域覆盖真实变换"的概率可证？标定误差如何经针孔投影、深度、工作域传播为视觉误差界 `e_vis`？退化位形（纯平移、单轴旋转、平面运动）下可观测性指标如何触发协方差膨胀？
- **Q2（交互证书的能量与接触语义）**：时变阻抗、接触切换、刚度突变下，能量罐如何保证无源性且不过度保守？摩擦锥、法向力单向性、接触模式切换如何进入 `ImpCert`？能量罐见底时如何单调退化为更低刚度/位置控制而不产生冲击？
- **Q3（感知—交互对偶可行域）**：`K_req ≤ K_allow` 的可行域在力/位混合任务中如何按轴分解？不可行时的三条退化路（降力、重标定、改策略）如何选择与排序？视觉→力觉切换桥梁如何保证瞬态力不超界？
- **Q4（标定维护预算与单调退化）**：主动标定需要激励运动，与任务执行争夺 tick；如何在证书价值意义下分配 `B_tick` 与 `B_cal`？标定漂移率与检测周期如何给出未检测漂移界？标定/阻抗/耦合三者失效时如何严格退回 v16？

## 2. 设计原则（在 P25–P27 基础上新增 P28–P31）

**P28 坐标系即证书律（Frame as Certificate）**
任何使用视觉测量或视觉伺服的动作节点，其 `Pre` 必须包含有效 `CalCert`：`CalCert.valid = (t_now - t_stamp ≤ TTL) ∧ (r_T ≤ r_max(task)) ∧ (x ∈ V_valid)`。视觉误差界必须由证书半径显式传播：`e_vis ≤ r_trans + d_max·r_rot + d_max·e_pix/f`。证书过期或残差检验失败时，节点只能走 Fallback 或进入"先补标定"分支，**禁止以"先跑跑看"的方式使用过期标定**。

**P29 阻抗即能量证书律（Impedance as Energy Bookkeeping）**
每个阻抗模式必须携带 `ImpCert`，其能量罐 `E_tank ≥ 0` 恒成立。刚度提升 `ΔK` 必须从能量罐扣除势能增量 `ΔE = ½·ΔxᵀΔK·Δx`；刚度下降返还能量但不许超过罐容量。接触力必须满足 `0 ≤ F_n ≤ F_max` 且 `‖F_t‖ ≤ μF_n`。任何不满足 `ImpCert` 的阻抗参数必须被投影回可行域，投影算子本身必须无损（只减不增能量）。

**P30 感知—交互对偶律（Perception—Interaction Duality）**
对接触任务规格 `Tsk = (x_d, F_req, ε_pos, w_max, contact_mode)`，定义 `K_req = w_max/ε_pos`、`K_allow = F_max/e_vis`。仅当 `K_req ≤ K_allow`（逐轴或保守标量）时 PIC 放行；否则必须显式选择退化路：降力（缩 `F_max`）、增柔（放 `ε_pos`）、重标定（降 `e_vis`）或改策略（力伺服）。**禁止在 PIC 不可行时仍以边界刚度执行**——那正是误差被放大成力冲击的路径。

**P31 标定维护即预算抢占律（Calibration Maintenance as Preemptive Budget）**
标定维护与任务执行共享同一帧预算：`B_tick + B_cal ≤ B_frame`。当残差检验或漂移检测触发时，`B_cal` 可抢占 `B_tick`，但只能抢占非安全关键节点；抢占后任务侧必须单调退格（节点降级或延后），而不是压缩安全证书检查。标定维护本身也必须带"收益上界"：若补标定的证书增益低于被抢占任务的证书损失，则维持旧标定并收紧 `e_vis` 余量。

## 3. 与基线的接口（如何退化）

- HCM 失效 ⇒ 冻结最后一次有效标定并注入保守膨胀：`r_T ← r_T + δ_drift·(t_now - t_stamp)`，视觉节点仅保留"证书仍覆盖当前任务域"的部分，**等价 v16 的视觉无关回退路径**；
- ICC 失效 ⇒ 阻抗退化为固定刚度位置控制，能量罐视为无限但力上界仍由硬件守卫硬限幅，**等价 v16（+HCM）路径**；
- PIC 失效 ⇒ 拒绝所有"视觉 + 接触"耦合节点，只允许纯视觉或纯力控两类不相交节点，**等价 v16（+HCM+ICC）路径**；
- 标定维护调度失效 ⇒ 固定周期重标定，不抢占任务 tick，仅使用保守 `e_vis`，**等价 v16 调度路径**；
- 四者全失效 ⇒ MetricVoiceGauge-NCD-HUTDH-v16，再沿 v16→v15→…→v6 退化；
- **安全继承**：HCM 只收紧坐标系可信域、ICC 只从能量罐扣款、PIC 只做可行性拒绝、调度器只做单调抢占；四端口互不相交，均不能新增授权或放宽任何阈值；`Exec_v17⊆Exec_v16` 由引理 143 保证。

## 4. 预期贡献

1. **坐标系证书**：把 SE(3) 手眼标定从"一次性参数估计"改写为"带协方差半径、可观测性与有效域的运行时可信域"，给出误差到视觉任务空间的显式传播界，填补"标定精度"与"动作证书"之间的语义断层；
2. **交互能量证书**：把阻抗控制从"调增益"改写为"记能量账"，给出时变刚度/接触切换下的无源性证书与力/摩擦锥约束，使接触任务可证稳定；
3. **感知—交互对偶**：给出 `K_req ≤ F_max/e_vis` 的刚度—不确定度可行性判据，把"看多准"与"能多硬"统一到同一预算，并给出不可行时的三条单调退化路；
4. **标定维护调度**：把主动标定作为可抢占的证书维护动作纳入 CSC，给出"任务执行 vs 补标定"的预算分配与收益上界；
5. **四层解耦再进一步**：v12 管"允许什么"、v13 管"时限内实现多少"、v15 管"技能如何扩散"、v16 管"全身行为如何按里程碑执行"、v17 管"感知与交互如何互相授权"，用 `Exec_v17⊆Exec_v16⊆Exec_v15⊆Exec_v13⊆Exec_v12` 把行为、路线、动力学、实时、蒸馏、感知、接触全解耦；E691–E710 覆盖坐标系证书覆盖、可观测性、在线重标定、能量罐无源性、对偶可行域、视觉—力觉切换、漂移耦合与端到端消融。

## 5. 本轮最大风险

**一句话**：感知—交互对偶律把视觉误差当作一个可证书化的**静态上界** `e_vis`，但真实视觉失效（遮挡、反光、运动模糊、标定板被碰）是**重尾、非平稳、偶发跳变**的；一次未被 `e_vis` 捕获的离群跳变，就足以让恰好卡在可行边界的刚度把微小位置误差放大为超限接触力——即**证书自洽、能量不透支、对偶可行的、却因视觉离群而瞬间致命的接触动作**。

## 0. 核心符号体系（定义 657–684）

| 符号 | 含义 |
|---|---|
| `T_C^E ∈ SE(3)` | 手眼变换：相机系 C 到末端系 E 的齐次变换；`T̂` 为其估计 |
| `ξ = log(T̂^{-1}T) ∈ se(3)` | 左不变误差的李代数坐标（6 维） |
| `Σ_T ∈ R^{6×6}` | `T̂` 的李代数协方差（信息矩阵 `Λ_T = Σ_T^{-1}`） |
| `r_T(α) = sqrt(χ²_{6,1-α}·λ_max(Σ_T))` | 置信水平 `1-α` 下的保守误差半径 |
| `O = σ_min(Λ_T)` | 手眼可观测性指标；低于 `O_min` 时信息增益饱和 |
| `CalCert = (T̂, Σ_T, r_T, O, V_valid, t_stamp)` | 坐标系证书；`V_valid` 为标定有效工作域 |
| `r_trans, r_rot` | 由 `r_T` 分解的平移/旋转半径（按度规权重） |

| `ImpCert = (K_min, K_max, D_min, F_max, μ, E_tank, φ_pass)` | 交互证书：刚度/阻尼区间、力上界、摩擦系数、能量罐、无源性裕度 |

| `K_req = w_max / ε_pos` | 满足位置精度所需的最小刚度（逐轴或保守标量） |
| `K_allow = F_max / e_vis` | 保证接触力不超界的最大刚度（逐轴或保守标量） |
| `e* = ε_pos·F_max / w_max` | 感知容差：当且仅当 `e_vis ≤ e*` 时对偶可行 |

| `ζ_vi = (CalCert, ImpCert, PIC, B_tick, B_cal, m*, h*, drift_vis, mode_vi)` | 感知—交互层共享状态 |

**证书嵌套关系（v17 新增不变式）**
`Fallback_n ⊆ Pre_n ⊆ Run_n ⊆ Post_n`（v16，定义 627）保持不变，并在视觉/接触节点上追加：

# IP-416 Hand-Eye Calibration Manager：坐标系证书
class HandEyeCalibrationManager:
    def __init__(self, prior_T, prior_cov, ttl, alpha=0.05, O_min=1e-3):
        self.T_hat = prior_T                 # T_C^E 估计
        self.Lambda = np.linalg.inv(prior_cov)  # 信息矩阵 Λ_T
        self.ttl = ttl
        self.alpha = alpha
        self.O_min = O_min
        self.t_stamp = now()
        self.V_valid = prior_T.valid_workspace

    def ingest(self, pairs, dt):
        """pairs = [(T_E, T_C, weight)]；线性化 AX=XB 累积 Fisher 信息"""
        for T_E, T_C, w in pairs:
            J = self._calibration_jacobian(T_E, T_C, self.T_hat)
            self.Lambda = self.Lambda + w * (J.T @ J)
        self.t_stamp = now()

    def observability(self):
        return float(np.linalg.eigvalsh(self.Lambda)[0])

    def inflate_drift(self, dt):
        # 漂移是信息损失：协方差随未观测时间增长
        Sigma = np.linalg.inv(self.Lambda) + (self.delta_drift ** 2 * dt) * np.eye(6)
        self.Lambda = np.linalg.inv(Sigma)

    def residual_test(self, T_meas):
        """χ² 残差检验：测量是否落在当前证书可信域内"""
        e = log_se3(np.linalg.inv(self.T_hat) @ T_meas)
        stat = float(e.T @ self.Lambda @ e)
        return stat <= chi2.ppf(1 - self.alpha, df=6)

    def certificate(self, x, task):
        Sigma = np.linalg.inv(self.Lambda)
        r_T = np.sqrt(chi2.ppf(1 - self.alpha, df=6) * np.linalg.eigvalsh(Sigma)[-1])
        r_trans, r_rot = self._split_radius(r_T)
        e_vis = r_trans + task.d_max * r_rot + task.d_max * task.e_pix / task.f
        O = self.observability()
        valid = ((now() - self.t_stamp) <= self.ttl and
                 x in self.V_valid and O >= self.O_min and
                 e_vis <= task.e_vis_max)
        return CalCert(self.T_hat, Sigma, r_T, O, self.V_valid,
                       self.t_stamp, e_vis, valid)


# IP-417 Impedance Certificate Controller：交互能量证书
class ImpedanceCertificateController:
    def __init__(self, robot, limits, tank):
        self.robot = robot
        self.limits = limits          # K_min,K_max,D_min,F_max,mu,E_max
        self.tank = tank              # {'E': E_tank}
        self.K = limits.K_min
        self.D = limits.D_min

    def project(self, K_des, D_des, x_d, x):
        """Π_Imp：投回可行域；先检查能量，再检查边界，只减不增"""
        dK = K_des - self.K
        dx = (x_d - x)
        dE = 0.5 * float(dx.T @ dK @ dx)   # 刚度提升所需的势能增量
        K = np.clip(K_des, self.limits.K_min, self.limits.K_max)
        if dE > 0:
            if dE > self.tank['E']:
                # 能量不足：按比例缩刚度增量
                scale = max(0.0, self.tank['E'] / dE)
                K = self.K + scale * (K - self.K)
                dE = self.tank['E']
            self.tank['E'] -= dE
        else:
            self.tank['E'] = min(self.limits.E_max, self.tank['E'] - dE)  # 退款
        D = np.clip(D_des, self.limits.D_min, None)
        return K, D

    def compute(self, x, x_d, xdot):
        """阻抗控制律 + 能量罐耗散记账"""
        e = x - x_d
        F = -(self.K @ e + self.D @ xdot)          # 期望交互力
        tau = self.robot.J(x).T @ F + self.robot.gravity_coriolis(x, xdot)
        self.tank['E'] = min(self.limits.E_max,
                             self.tank['E'] + float(xdot.T @ self.D @ xdot) * dt)
        return tau, F, self.tank['E']

    def verify_contact(self, F):
        """IP-425：法向单向、力上界、摩擦锥"""
        F_n, F_t = decompose_contact(F)
        return (0.0 <= F_n <= self.limits.F_max and
                np.linalg.norm(F_t) <= self.limits.mu * max(F_n, 1e-9))


# IP-418 Perception-Interaction Certificate：刚度—不确定度对偶
class PerceptionInteractionCertificate:
    def __init__(self, printer, ddp):
        self.printer = printer       # 逐轴/保守标量处理
        self.ddp = ddp               # IP-426 退化规划器

    def feasible(self, task, cal_cert, imp_cert):
        e_vis = cal_cert.e_vis
        K_req = task.w_max / max(task.eps_pos, 1e-9)
        K_allow = imp_cert.F_max / max(e_vis, 1e-9)
        K_req, K_allow = self.printer.project(K_req, K_allow, task)
        ok = bool(np.all(K_req <= K_allow)) and cal_cert.valid
        path = None if ok else self.ddp.choose(task, cal_cert, imp_cert)
        return PIC(K_req, K_allow, ok, path), (K_req, K_allow)

    def select_stiffness(self, task, pic, imp_cert):
        """在可行区间内取"安全余量最大"的刚度，而非最大刚度"""
        if not pic.feasible:
            raise InfeasibleInteraction(pic.degrade_path)
        K = 0.5 * (pic.K_req + pic.K_allow)   # 几何中心，留两侧余量
        return np.clip(K, imp_cert.K_min, imp_cert.K_max)


# IP-420 Visual-Haptic Transition Bridge：视觉伺服 → 阻抗接触
class VisualHapticTransitionBridge:
    def __init__(self, margin_force=0.1, margin_energy=0.1):
        self.margin_force = margin_force
        self.margin_energy = margin_energy

    def verify(self, cal_cert, imp_cert, task, pic):
        if not cal_cert.valid or not pic.feasible:
            return False
        # 1. 视觉目标必须落在阻抗可接受位置域内
        if cal_cert.e_vis > task.eps_pos + task.e_vis_max:
            return False
        # 2. 接触瞬时力上界留余量
        if task.F_req > (1 - self.margin_force) * imp_cert.F_max:
            return False
        # 3. 能量罐足以完成刚度爬升
        dE = 0.5 * float((task.x_d - task.x_contact).T
                         @ (pic.K_req - imp_cert.K_min)
                         @ (task.x_d - task.x_contact))
        return imp_cert.E_tank >= (1 + self.margin_energy) * dE


# IP-421 Calibration-Aware Scheduler：标定维护预算抢占
class CalibrationAwareScheduler:
    def __init__(self, csc, hcm, aep, B_frame, w_task=0.7):
        self.csc = csc
        self.hcm = hcm
        self.aep = aep
        self.B_frame = B_frame
        self.w_task = w_task

    def schedule(self, x, ctx):
        stale = (now() - self.hcm.t_stamp) > self.hcm.ttl
        residual_bad = ctx.last_residual > ctx.residual_threshold
        need_cal = stale or residual_bad or self.hcm.observability() < self.hcm.O_min

        if not need_cal:
            return self.csc.schedule(x, ctx), 0

        # 标定收益上界 vs 任务损失：收益更大才抢占
        e_vis_before = self.hcm.certificate(x, ctx.task).e_vis
        excitation = self.aep.best_excitation(ctx, budget=self.B_frame)
        e_vis_after = self.hcm.predicted_e_vis(excitation)
        gain = val_cal(e_vis_before) - val_cal(e_vis_after)
        loss = self.csc.estimate_loss(ticks=excitation.ticks)

        if gain > loss:
            B_cal = min(excitation.ticks, self.B_frame)
            plan = self.hcm.execute_excitation(excitation, B_cal)
            # 剩余预算执行任务，且任务侧只能单调退格
            return self.csc.schedule(x, ctx, B_frame - B_cal, degraded=True), B_cal
        # 不补标定：维持旧证书但膨胀漂移界，任务按保守 e_vis 执行
        self.hcm.inflate_drift(now() - self.hcm.t_stamp)
        return self.csc.schedule(x, ctx, degraded=True), 0

## 3. 推导

**引理 137（坐标系证书到视觉误差的传播界）** 设 `T ∈ SE(3)` 落在 `CalCert` 的可信域内，即左不变误差满足 `‖log(T̂^{-1}T)‖_Σ ≤ r_T`，将其分解为 `(δp, δθ)` 且互作保守相加。对任意深度 `d ≤ d_max` 的相机点 `p_C`，其在末端系的位置误差满足
`‖δp_E‖ ≤ r_trans + d_max·r_rot + d_max·e_pix/f = e_vis`。
证明：`p_E = T̂_C^E · p_C`。误差由三部分组成：平移估计误差 `δp`、旋转估计误差作用在深度 `d` 上的力臂项 `‖δθ‖·d`、以及像素量化/检测误差经针孔投影放大 `d·e_pix/f`。由左不变度规的三角不等式与旋转群上的 Lipschitz 性（`‖R(δθ)p - p‖ ≤ ‖δθ‖‖p‖`），三项相加得上界。取 `d_max` 即得全局界。∎ 推论：**视觉误差界是坐标系证书半径的线性函数**；想让 `e_vis` 减半，最有效的不是换更高分辨率相机，而是降低 `r_rot`（旋转不确定性经深度放大）。

**引理 138（在线重标定的协方差单调与可观测性下限）** 设标定观测线性化为 `z_i = J_i ξ + η_i`，`η_i ~ N(0, W_i^{-1})`，信息矩阵按 `Λ_{new} = Λ_{old} + Σ_i J_iᵀW_iJ_i` 更新。则：(1) `Λ_new ⪰ Λ_old`，从而 `Σ_new ⪯ Σ_old`、`r_T` 单调不增；(2) 若 `O = σ_min(Λ) < O_min`，则存在常数 `c>0` 使单步信息增益 `≤ c·O²`，协方差无法在有限步内降到 `r_T < r_target`；(3) 残差检验通过时，真实变换以至少 `1-α` 概率仍落在可信域内。
证明：(1) 每个 `J_iᵀW_iJ_i` 半正定，故 `Λ` 在 Loewner 序下单调增，取逆得协方差单调减，`λ_max(Σ)` 与 `r_T` 随之单调不增。(2) 当 `Λ` 的最小特征值很小时，`J` 在对应零空间方向上的投影被 `O` 界住，单步信息增益二次小；由 Stam 类不等式或矩阵扰动界可得有限步内无法跨越 `O_min` 以下的平台，此为可观测性下限。(3) 若真实 `T` 使 `ξ` 的 Mahalanobis 距离超过 `sqrt(χ²_{6,1-α})`，则残差检验以概率 `≤α` 误接受；反之在域内则以 `≥1-α` 接受。∎ 推论：**重标定不是"多跑几次就更准"**——激励不足（`O` 小）时旧协方差几乎不降，此时唯一安全的动作是承认 `e_vis` 不降并相应降低刚度。

**引理 139（刚度—不确定度对偶可行性）** 对接触任务 `Tsk`，若执行刚度为 `K`，最坏位置误差为 `e_vis`，则存在可信域内的状态使接触力达到 `K·e_vis`；要保证 `F ≤ F_max` 必须有 `K ≤ K_allow = F_max/e_vis`。另一方面，在外部扰动 `w_max` 下要保证位置误差 `≤ ε_pos`，必须 `K ≥ K_req = w_max/ε_pos`。因此存在同时满足力界与精度界的 `K` 当且仅当
`K_req ≤ K_allow ⇔ e_vis ≤ ε_pos·F_max/w_max = e*`。
证明：力的最坏情形由 `e_vis` 的定义直接构造——取可信域边界上使位置偏差方向与接触法向一致的状态，力为 `K·e_vis`。精度最坏情形由扰动上界直接给出。两不等式的交集非空当且仅当 `K_req ≤ K_allow`；代入定义即得 `e*`。若 `K_req > K_allow`，任何 `K` 不是力超界就是精度不足，故单靠"选一个更好的 K"不可解，必须改变 `F_max`、`ε_pos` 或 `e_vis` 之一。∎ 推论：**PIC 的不可行不是调参失败，而是任务规格与感知精度的结构性矛盾**；退化路必须修改这三者之一。

**引理 140（时变阻抗的能量罐无源性）** 设阻抗系统取存储函数
`V = ½ẋᵀM_dẋ + ½eᵀK_de + E_tank`。
若每次刚度提升从能量罐扣除势能增量 `ΔE = ½·ΔxᵀΔK·Δx` 且 `E_tank ≥ 0`，刚度下降返还能量但不超过 `E_max`，阻尼耗散 `ẋᵀD_dẋ ≥ 0` 全部入罐，则对任意时变 `K_d(t)` 与任意被动环境，闭环满足
`dV/dt ≤ ẋᵀF_ext`，
即从外部端口看是无源的，接触稳定。
证明：对 `V` 求导，`½ẋᵀṀ_dẋ` 项在 `Ṁ_d` 有界且由控制器补偿时消失或被动；`eᵀK_dė` 与 `ẋ` 项合成 `ẋᵀF_ext - ẋᵀD_dẋ - ½ėᵀK̇_de`。当 `K̇_d>0` 时，`-½ėᵀK̇_de` 被能量罐扣款 `ΔE` 抵消；当 `K̇_d<0` 时，势能减少返还罐中。耗散项非负，故 `dV/dt ≤ ẋᵀF_ext`。被动环境本身满足其端口无源性，级联仍无源，故接触稳定。∎ 推论：**能量罐是"时变增益"与"无源性"之间的唯一合法接口**；没有它，任何刚度上调都可能成为能量注入。

**引理 141（视觉→力觉切换桥梁的瞬态安全）** 若切换桥梁 `Bridge_vi` 非空，且切换在桥梁内完成（`K ∈ [K_req, K_allow]`、`E_tank` 足以支付刚度爬升、`F_req ≤ (1-margin)F_max`），则切换全程满足 `F ≤ F_max`、位置误差 `≤ e_vis`，且切换冲击不超过 `margin·F_max`。
证明：桥梁是 `CalCert` 可行域、`ImpCert` 可行域与对偶区间的交集。在桥梁内，`K ≤ F_max/e_vis` 保证 `K·e_vis ≤ F_max`；`F_req` 的余量保证稳态力不触顶；能量罐预算保证 `K` 的爬升速率有界，故瞬态不产生未记账的能量注入。由引理 139、140，切换前后证书均成立；由连续性，切换路径上证书的凸组合仍成立。∎ 推论：**视觉→力觉不是"两个控制器的硬切换"，而是"在交集里滑行"**；交集为空时必须先降力或先重标定，不能强行接触。

**引理 142（漂移检测周期的安全余量）** 设标定误差漂移率上界为 `δ_drift`，检测周期为 `Δ_cal`，则两次检测之间未被发现的误差增长不超过 `δ_drift·Δ_cal`。若初始视觉界为 `e_vis`，则整个周期内可保证的安全条件为
`e_vis + δ_drift·Δ_cal ≤ e*`。
证明：误差增长被速率上界积分界住，区间长度 `Δ_cal` 即得增量界；由引理 139，只要最坏总误差仍不超过 `e*`，对偶可行性与力界在整个周期内成立。∎ 推论：**检测周期不能凭经验设定，必须由漂移率与感知容差反解**：`Δ_cal ≤ (e* - e_vis)/δ_drift`；漂移率增大会强制缩短检测周期，进而与任务 tick 争夺预算——这正是 CAS 需要处理的核心张力。

**引理 143（感知—交互崩溃回退到 v16）** 若 HCM、ICC、PIC、CAS 全部以中立元注入（HCM 冻结证书并只做保守膨胀、ICC 视为固定刚度且能量罐无限但硬件力限幅仍在、PIC 拒绝一切视觉—接触耦合节点、CAS 固定周期不抢占），则
`Exec_v17 = Exec_v16`；
若仅部分失效，则 `Exec_v17 ⊆ Exec_v16`。
证明：四个模块对行为树只做"收紧前置证书、拒绝节点、投影参数、抢占预算"四类操作，均不新增任何授权。中立元下每类操作退化为恒等或纯保守，故行为树可执行集合等于 v16。部分失效时，剩余模块仍只做收紧，故为 v16 的子集。∎ 推论：**v17 不可能比 v16 更"敢动"**；它只可能更保守，因此安全继承成立。

## 7. 已知风险与失效模式

1. **视觉误差的重尾与非平稳性**：`e_vis` 由高斯/χ² 假设给出，但遮挡、镜面反光、运动模糊会产生**离群跳变**，其尾部远厚于高斯。一次离群即可让边界刚度产生超限力。缓解：EVT/极值理论尾部建模、在线离群检测、遮挡时强制降刚度、`e_vis` 加入经验分位数余量、对偶判据使用保守分位数而非均值。

2. **协方差低估与信息矩阵病态**：线性化 `AX=XB` 的 Jacobian 在近退化位形下条件数极大，`Λ` 最小特征值接近零，导致 `Σ` 数值上被低估或不可逆。缓解：正则化/伪逆、可观测性阈值硬门、退化方向显式膨胀、多传感器融合。

3. **能量罐耗竭导致刚度塌缩**：连续高刚度任务会耗尽 `E_tank`，系统被迫降到最低刚度，可能剧烈改变任务动力学。缓解：能量预算规划、任务间能量回收、限制刚度爬升速率、显式向调度器报告低能量状态。

4. **摩擦锥模型误差**：库仑摩擦系数 `μ` 随表面/磨损/湿度变化，固定 `μ` 会在真实摩擦更低时放行切向力。缓解：在线估 `μ`、保守下界、触觉滑移检测、滑移触发降切向力。

5. **标定漂移的静默累积**：`δ_drift` 是上界估计，真实漂移可能阶段性加速（温漂、碰撞后），而残差检验需要观测到明显偏差才触发。缓解：多源监测（IMU/关节编码器/视觉重投影）、变点检测、保守 `δ_drift`、碰撞后强制重标定。

6. **视觉—力觉时间同步误差**：视觉帧与力/力矩帧存在毫秒级延迟，快速接触时位置与力不匹配，`F≈K·e` 的静态假设失效。缓解：时间戳对齐、状态预测、延迟补偿、接触前减速。

7. **能量罐与硬件力限幅的语义冲突**：能量罐允许的刚度可能高于硬件瞬时力限幅允许的刚度。缓解：`F_max` 取二者较紧者、硬件限幅作为最后防线、证书中显式区分"能量可行"与"硬件可行"。

8. **多相机/多标定源的一致性**：多相机各自有 `CalCert`，外参误差与时间不同步会导致融合后的 `e_vis` 估计错误。缓解：统一坐标系证书、外参联合标定、交叉验证、保守取最差源。

9. **PIC 逐轴分解的保守性**：逐轴 `K_req ≤ K_allow` 会过度保守，各向异性任务（如沿法向高刚度、切向低刚度）可能被误判不可行。缓解：按任务主轴分解、椭球证书、方向性对偶判据。

10. **主动标定激励与任务安全的冲突**：为提升可观测性需要大幅运动，可能与当前里程碑的安全边界冲突（如粗糙地形上不能做大幅标定动作）。缓解：安全域内激励、仿真预验证、里程碑许可的激励集、标定与任务分时。

11. **CAS 抢占的活性风险**：若标定长期"收益 > 损失"，任务 tick 被持续抢占，系统陷入"只标定不干活"的活锁。缓解：抢占配额上限、任务保底预算、收益估计的滞后修正、看门狗。

12. **v17 与 v16 证书栈的累积保守性**：坐标系证书、交互证书、对偶证书再与 v16 的 NC/MC/WBC 取交，层数增加后可行域可能收缩到近空，系统几乎只能执行回退。缓解：证书价值加权、选择性松弛（需证明）、动态 α、监控可行域体积并告警。

## 8. 本轮最大风险

**一句话**：感知—交互对偶律把视觉误差当作可证书化的静态上界 `e_vis`，但真实视觉失效（遮挡、反光、运动模糊、标定板被碰）是重尾、非平稳、偶发跳变的；一次未被 `e_vis` 捕获的离群跳变，就足以让恰好卡在可行边界的刚度把微小位置误差放大为超限接触力——即**证书自洽、能量不透支、对偶可行的、却因视觉离群而瞬间致命的接触动作**。
