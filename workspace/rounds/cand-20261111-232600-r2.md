# 第 57 轮（承接第 56 轮「证据地图×主动探询×信任协商」IP-127~132；灵感循环第 3 轮；本轮灵感：「用户画像」×「时空推理」）

> 第 56 轮把安全赌注从"模型置信"换到"证据质量"，用持久地图 𝓜、探-诺-演 PCE、协商护盾 ISE 让每个承诺接触都挂证据类。但它自陈的最大风险恰恰暴露了两个隐含的"静态"假设：**信念是按区域独立的**（陈旧只用一个全局半衰期）、**人是一个全局标量**（`w_h` 只看一个校准分）。真实世界里风险沿空间相邻传播、随时间演化，人的可靠性也随区域、任务、疲劳与注意力漂移。本轮两个灵感各拆一个静态假设：**时空推理**把 `b_r` 升级为时空信念场，让证据带上"在哪儿、到何时有效"的作用域；**用户画像**把"操作者校准分"升级为情境画像（能力包络 × 校准场 × 注意力 × 信任轨迹），但严格限定它只改"怎么交互"，不改"允许多冒险"。核心命题再进一步：**预测只能收紧，画像只能改说法；只有观察在正确时空点的证据才能放行**。

核心矛盾：
- **H26**：第 56 轮的 `w_h` 是一个全局标量，把"操作者在 A 区标地板很准"错误外推到"他在 B 区标薄冰也准"；更危险的是，画像一旦被当作"授权"来放宽风险预算（"这个用户能接受更快"），就绕过证据门，把个性化变成系统性升险通道。画像既不够准，又可能被误用。
- **H27**：第 56 轮的区域信念相互独立、陈旧用统一半衰期；但风险是时空相关的——相邻区域共享基底/光照/天气，风险前沿会随时间推进（融冰、人流、地基松动）。独立融合会同时犯两种错：慢变区"旧证据放行今日风险"，快变热点"新证据来不及传播到邻居"，且一次局部坏证据无法被邻域一致性检验发现。
- **H28**：时空推理与画像本质都是**推断**，而第 56 轮的安全契约是"观察才算证据"。若允许预测或画像参与放行，就会出现"**预测冒充证据、画像冒充授权**"：模型越自信，越能跳过重探；画像越"体贴"，越能把用户放进更高风险档。这正是证据门最容易被内部绕过的地方。

## 0. 直觉与动机

**灵感 1（时空推理 → 证据有"时空作用域"，信念从逐点变量变成场）**
直觉：一条"这块可承重"的证据不是全图通用的，也不是永久的——它只在发出点附近、一段时间内算"观察"。于是给每条证据 `e` 配一个作用域 `val(e)={(r,t): k_s(r,r_e)·k_t(t,t_e) ≥ ρ_val}`：域内它是直接观察，域外它只是先验。信念由独立后验 `b_r` 升级为时空场 `b_{r,t}`，用时空高斯过程/OU 动力学建模：相邻区域共享基底（空间核 `k_s`），同一区域的参数按 OU 过程漂移（时间核 `k_t`）。好处是双向的：一次探针能同时降低邻域不确定性（探询更值钱），风险前沿能被预测并提前重探；但**只允许"借力于参数、收紧于风险"**——向未观察区域传播时只取风险上界，绝不允许局部乐观证据被平滑成全局乐观。

**灵感 2（用户画像 → 不是偏好向量，而是"能力-校准-注意力-信任"四个场）**
直觉：服务机器人真正需要的画像不是"用户喜欢什么"，而是"这个人此刻、在此处、做此事有多可靠、能承受什么、能不能被叫到"。拆成四个量：能力包络 `cap`（步速、反应时、可达、负重——只可**收缩**可行动集）、情境校准场 `cal(r,τ,t)`（按区域×任务池化的可靠性，带变点检测）、注意力过程 `attn(t)`（人在不在听、能不能及时响应）、信任轨迹 `trust(t)`（自动化依赖/告警疲劳的隐状态）。关键不是画像更细，而是**用途隔离**：画像只决定解释的详略、通道、时机与同级安全方案间的偏好，绝不进入 `δ_f、δ_probe、w_max、θ_L1、τ_int` 这些安全参数。

**灵感 3（两者耦合 → 交互请求是一个"时空可送达窗口"问题）**
直觉：第 56 轮的 L2 同步确认假设"问了就有人答"。若把人的注意力看成时空过程，L2 请求就有了"可送达窗口"：人正在远处/背对/高负荷时发问，等于逼出一次无效确认或误确认。于是同意阶梯升级为**时序契约**：`G(¬attn_valid(t) → ¬request_L2(t))`，请求前先预测注意力，窗口不足则**延迟（defer）**到下一窗口，延迟耗尽则保守停；**非响应永远不等于同意**。信任轨迹则用来调节解释频率与详略，降低告警疲劳，但调节的是"说多少"，不是"允许多险"。

**灵感 4（安全单调原则 → 本轮的核心命题）**
直觉：把前三条收束成一条可审计的不变式：**预测只可收紧、画像只可改说法**。时空预测只允许提高风险上界、缩短证据有效期、增加重探频率；画像只允许收缩可行集、增加交互保守性、改变解释方式。任何一个"降低风险、放宽预算、跳过探针"的影响路径都被类型系统与证书审计拒绝。这样，新增的两个推断模块即使错了，也只能让系统更保守，不会让系统更冒险。

## 1. 形式化定义（增量：定义 133–138）

**定义 133（时空信念场 STBF）** `𝓜_ST = (G×T, b, k_s, k_t, prov, ver, val)`：状态 `θ_{r,t}=(label, μ, k, F_bear, occ)`；信念 `b_{r,t}=p(θ_{r,t}|E_{≤t})`；先验协方差 `Cov(θ_{r,t},θ_{r',t'})=σ²·k_s(r,r')·k_t(t,t')`，取 Matérn 空间核（长度 `ℓ_s`）与 OU 时间核（长度 `ℓ_t`）；动力学 `θ_{r,t+1}=f(θ_{r,t})+w_t`（接触参数线性高斯、占据为 CTMC）。证据作用域 `val(e)={(r,t): k_s·k_t ≥ ρ_val}`；**保守迁移公理**：域内按观测融合，域外只作为先验，且安全评估统一取上侧分位 `θ⁺_{r,t}=Q_{1-α}(b_{r,t})`，故迁移只能抬高风险界。

**定义 134（时空用户模型 STUM）** `U=(cap, cal, attn, trust, pref)`：`cal(r,τ,t)∈[0,1]` 为按（区域×任务×时间）分层池化的校准场，带 CUSUM 变点；`attn(t)` 为注意力/可响应隐马尔可夫过程；`trust(t)` 为信任-疲劳隐状态；`cap` 为能力包络；`pref` 为**同级安全方案**上的偏好序。**用途隔离公理**：安全判定 `D_safe` 与安全参数集 `{δ_f,δ_probe,w_max,θ_L1,τ_int}` 不接收 `pref,trust`；`cap` 只可收缩可行集，任何画像分量不得扩张可行集或抬高风险预算。

**定义 135（情境信任门 CTG）** `w_h(r,τ,t)=min(w_max, w0·Ĉal(r,τ,t)·κ_fresh(t−t_ann;τ_h)·1[attn_valid(t)])`，其中 `Ĉal` 取校准场下置信界；标注仅在 `val(ann)` 内有效；乐观偏差经 CUSUM 检出任一上下文后该上下文权重置零并要求佐证。

**定义 136（时空探-诺-演 ST-PCE）** 检查点 `(r,t)` 风险 `R_{r,t}(σ)=Σ_i P_fail(r_i,t_i|b)`。承诺 ⇔ `∃g: R_{r,t}(σ) ≤ δ_f(g)`。否则选 `argmax_π [VOI_ST(π;r,t)−cost(π)] ≥ θ_voi`，其中 `VOI_ST` 计入对时空邻域 `N_{ℓ_s}(r)×[t,t+H]` 的风险降幅与未来重探需求；探 + 场更新 + 重估。探尽→绕行；绕尽→降档；降尽→时序协商或安全停。每检查点 `k_probes` 上限 + 全局预算保证终止。

**定义 137（时序交互契约 STL-IC）** 交互受信号时序逻辑 `φ` 约束，至少含：`φ1=G(occ_h(r,t)∧irr(r,t)→¬commit(r,t))`（人占该区时不得不可逆接触）；`φ2=G(hotspot(r,t)→F_{≤T_r} probe(r))`（热点限期重探）；`φ3=G(request_L2(t)→(F_{≤τ_int}dec(t) ∨ F_{≤τ_int+Δ}safe_stop(t)))`；`φ4=G(¬attn_valid(t)→¬request_L2(t))`。请求可 `defer` 至下一注意力窗口，延迟预算耗尽则安全停；**非响应 ≠ 同意**。

**定义 138（时空-用户证书 J_stu）** `J_stu=(J_m, 𝓜_ST_core, U_cert, φ, STL_trace, prediction_log, profile_use_log)`：每个承诺接触必须携带**在正确时空点有效**的证据类 `EV-probe@(r,t,val) / EV-visit / EV-margin / EV-human@(r,τ,t)`；**预测不得充当证据**（`prediction ≠ evidence`），`prediction_log` 仅用于证明预测只收紧；`profile_use_log` 必须证明 `D_safe` 与安全参数未被画像改动、画像只影响解释/通道/偏好；`STL_trace` 满足 `φ`。

## 2. 关键算法伪代码（完整版见产物区）

### IP-133 STBF（时空信念场更新）

```python
def stbf_update(M, e, now):
    r0, t0 = e.region, e.time
    scope = {(r,t): k_s(r,r0)*k_t(t,t0) >= rho_val for r in M.V for t in M.T}
    for (r,t) in scope:                              # 域内：直接观测
        M.b[r,t] = gp_posterior_update(M.b[r,t], e)
        M.prov[r,t] = touch(M.prov[r,t], e)
    for (r,t) not in scope:                          # 域外：只作先验，收紧不放松
        M.b[r,t] = conservative_prior(M.b[r,t], e)   # theta_plus 单调不减风险
    return M
```

### IP-136 ST-PCE（时空探询 + 预测只收紧）

```python
def st_pce(x0, M, task, budget, profile, phi):
    route = plan_on_field(M, task, risk_model)
    for cp in route.checkpoints:
        R = schedule_risk(foothold_schedule(x0, cp, M), cp, M)
        while select_gait(R) == 'halt' and budget.left > 0:
            cands = admissible_probes(cp, M, F_abs)
            if not cands: break
            p = argmax(cands, key=lambda q: voi_st(q, M, R, H) - cost(q))
            if voi_st(p, M, R, H) < theta_voi: break
            M = stbf_update(M, execute_probe(p, cap=F_abs), t_now)
            R = schedule_risk(foothold_schedule(x0, cp, M), cp, M)
            budget.spend(p)
        R = tighten_only(R, predict_field(M, cp, H))   # 预测只可抬高 R
        g = select_gait(R)
        if g != 'halt' and stl_ok(phi, cp, M, profile):
            commit_and_log(cp, g, M, profile); continue
        return temporal_negotiate(cp, M, R, profile, phi)
    return done
```

### IP-137 STL-IC（注意力门控的时序协商）

```python
def temporal_negotiate(cp, M, R, U, phi):
    for t in defer_windows(cp, U, phi, W_def):       # 只在可送达窗口发问
        if not attn_predict(U, t) >= theta_attn: continue
        exp = grounded_explanation(M, cp, R)
        if confirm(exp, t, timeout=tau_int): return approved(cp)
    return safe_brake(cp)                            # decide: 非响应绝不等于同意
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| STBF | O(\|val\|·(d_θ³+E)) 增量 | O(\|V\|·\|T\|·d_θ) | 保守迁移、`θ⁺` 单调、作用域有效 |
| STUM/CTG | O(\|ctx\|·H_op+CUSUM) | O(\|ctx\|) | 用途隔离、`w_h≤w_max`、权重可归零 |
| ST-PCE | O(\|CP\|·k_p·(C_VOI+\|N\|)) | O(\|V\|·\|T\|) | 预测只收紧、`k_p` 终止 |
| STL-IC | O(\|φ\|·H) 监控 | O(\|trace\|) | 有界时域 sound、非响应≠同意 |
| ST-MEC | O(\|σ\|+\|trace\|) | O(\|σ\|) | 证据时空有效、预测不入证据门 |

**正确性定理（Spatio-Temporal Evidence-Grounded Commitment Soundness, ST-EGCS）**：在 A29–A36 基础上加 **(A37)** 时空场预测区间校准且保守迁移（域外只抬风险界），预测误差上界 `ε_ST`；**(A38)** 无洗白：任何转移不得降低未直接观测点的风险界；**(A39)** 用途隔离：画像只改模态、只收缩可行集，安全参数与 `D_safe` 不变；**(A40)** 注意力预测校准、延迟有界、非响应不授权；**(A41)** 校准场变点检测延迟 `≤τ_cp`、超上下文回退零权重；**(A42)** STL 监控对有限时域 sound 且实时。则：(i) 每次承诺接触失效概率 `≤δ_f+ε_cal+ε_probe+ε_h+ε_ST`；(ii) **安全单调性**：时空预测、画像、注意力、协商只经"收缩可行集 / 抬高风险界 / 改变交互模态 / 触发停"影响系统，不存在升险路径；(iii) **时序健全性**：不产生违反 `φ` 的不可逆接触（尤其人占区域）；(iv) ST-PCE 在 `k_probes` 与有限 `defer` 预算内终止于 {承诺, 绕行, 降档, 协商, 安全停}。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 时空平滑把局部坏证据"洗白"成全图乐观 | 高 | 保守迁移 + `θ⁺` 上界 + 域外禁止降风险 + 邻域一致性抽检 |
| 预测被当成证据、跳过重探 | 高 | `prediction ≠ evidence` 硬门 + 预测只收紧 + `prediction_log` 审计 |

| 注意力推断错误 / 隐私泄露 | 中 | 保守默认 abstain、端侧推断、不响应即停、最小化采集 |
| 校准变点检测滞后 | 中 | CUSUM + 超分布回退零权重 + 强制佐证生效 |
| STL 监控实时性与复杂度 | 中 | 有限时域/有界历史、运行时监控、退化到安全停 |

## 6. 本轮最大风险

**一句话**：时空推理与用户画像都是"推断"，而安全契约只认"观察"——一旦让预测冒充证据、让画像冒充授权，系统就会自信地"预测掉"本该重探的检查点、体贴地"个性化掉"本该保守的风险预算；因此必须把 **预测只收紧、画像只改说法、非响应不等于同意** 做成不可绕过的类型不变式与证书审计，宁可多探一次、多说一句，也绝不让推断为风险放行。

| `val(e)` | 证据作用域；域内为观测、域外仅为先验 |
| `θ⁺_{r,t}=Q_{1-α}(b_{r,t})` | 安全评估所用风险上侧分位（保守迁移） |
| `U=(cap,cal,attn,trust,pref)` | 情境用户画像四场 + 偏好 |

## 2. 关键算法伪代码

### IP-133 STBF（时空信念场）

```python
def stbf_update(M, e, now):
    r0, t0, changed = e.region, e.time, set()
    for r in M.V:                                    # 域内 = 直接观测
        for t in M.T:
            if k_s(r, r0) * k_t(t, t0) >= rho_val:
                M.b[r, t] = gp_posterior_update(M.b[r, t], e)
                M.prov[r, t] = touch(M.prov[r, t], e)
                changed.add((r, t))
    for r in M.V:                                    # 域外 = 只作先验
        for t in M.T:
            if (r, t) not in changed:
                M.b[r, t] = conservative_prior(M.b[r, t], e)   # 风险界单调不减
    M.ver.bump(changed)
    return M, changed

def conservative_prior(b, e):
    # 只允许借力于参数均值，安全评估取上侧分位；不得降低既有风险界
    return clip_covariance(b, e, risk_non_decreasing=True)

def predict_field(M, cp, H):
    # OU/GP 前向预测，返回带校准区间的风险前沿
    return [ou_forward(M.b[r, cp.t], dt) for r in neighborhood(cp.r, ell_s)
            for dt in range(1, H + 1)]

def tighten_only(R, pred):
    # 预测只可抬高风险，不可替代观测或降低重探频率
    return max(R, R_from_upper_bound(pred))
```

### IP-134/137 STUM + CTG（情境画像与信任门）

```python
def update_profile(U, ann, op_hist, audit):
    ctx = (ann.region, ann.task)
    residual = ann.predicted - ann.observed_truth      # 事后实测/探针回填
    if cusum_detect(op_hist[ctx], residual):           # 该上下文可信度突变
        op_hist[ctx].weight = 0.0                      # 回退零权重，强制佐证
    cal = lower_confidence_bound(hier_bayes_cal(op_hist, ctx))
    U.cal[ctx] = cal
    U.attn = attn_filter(U.attn, ann.obs)              # 注意力/可响应过程
    audit.append(('profile_update', ctx, cal, t_now))
    return U

def contextual_weight(U, r, tau, t, ann_time):
    if not in_scope(val_ann(ann_time), (r, t)): return 0.0
    if not attn_valid(U, t): return 0.0
    return min(w_max, w0 * U.cal.get((r, tau), 0.0)
               * freshness(t - ann_time, tau_h))

def modality_only(U, failc, u):
    # 画像只允许选择解释通道/详略/同级偏好，安全参数不可达
    lvl = consent_level(failc, u)                      # 与第 56 轮一致
    style = explain_style(U.trust, U.pref)             # 只改"怎么说"
    return lvl, style
```

### IP-135 ST-PCE（时空探询 + 预测只收紧）

```python
def select_gait(R):
    for g in ['trot', 'pace', 'crawl']:
        if R <= delta_f_of_gait(g): return g
    return 'halt'

def st_pce(x0, M, task, budget, U, phi):
    route = plan_on_field(M, task, risk_model)
    sched, log = [], []
    for cp in route.checkpoints:
        if not stbf_gate(M, cp, t_now):                # 作用域失效先补一次 view
            M, _ = stbf_update(M, execute_probe(view_probe(cp.region), cap=F_abs), t_now)
        sigma = foothold_schedule(x0, cp, M)
        R = schedule_risk(sigma, cp, M)
        while select_gait(R) == 'halt' and budget.left > 0:
            cands = admissible_probes(cp, M, F_abs)
            if not cands: break
            p = argmax(cands, key=lambda q: voi_st(q, M, R, H) - cost(q))
            if voi_st(p, M, R, H) < theta_voi: break
            M, _ = stbf_update(M, execute_probe(p, cap=F_abs), t_now)
            sigma = reselect_footholds(x0, cp, M)
            R = schedule_risk(sigma, cp, M)
            budget.spend(p)
        R = tighten_only(R, predict_field(M, cp, H))    # A37: 预测只可收紧
        g = select_gait(R)
        if g != 'halt' and stl_ok(phi, cp, M, U):
            sched.append(commit(sigma, g))
            log.append(tag_evidence(sigma, M, cp))      # 附 (r,t,val) 证据
            continue
        alt = reroute(M, cp, risk_model)
        if alt and select_gait(schedule_risk(alt, cp, M)) != 'halt':
            route = alt; continue
        return temporal_negotiate(cp, M, R, U, phi)
    return sched, log, M
```

### IP-136 STL-IC（时序交互契约）

```python
def stl_monitor(phi, trace):
    # 运行时监控有限时域 STL：G/F/U 的有界语义
    return all(eval_bounded(formula, trace, horizon=H_phi) for formula in phi)

def defer_windows(cp, U, phi, W_def):
    # 预测未来可响应窗口，只在这些窗口发起 L2
    return [t for t in range(cp.t, cp.t + W_def) if attn_predict(U, t) >= theta_attn]

def temporal_negotiate(cp, M, R, U, phi):
    for t in defer_windows(cp, U, phi, W_def):
        exp = grounded_explanation(M, cp, R)           # 第 56 轮 Exp
        lvl, style = modality_only(U, R, 'contact')    # 画像只改说法
        if lvl == 'L2' and confirm(exp, t, timeout=tau_int,
                                   style=style):
            return approved(cp, t)
        if lvl == 'L1': notify(exp, t, style=style)
    return safe_brake(cp)                              # A40: 非响应绝不等于同意
```

```python
def st_map_evidence_certificate(sched, log, M, U, phi, consent_log, budgets):
    for c in contacts(sched):
        if   c.ev == 'EV-probe':  ok = c.probe.passed and c.probe.nondestructive
        elif c.ev == 'EV-visit':  ok = M.prov[c.region, c.t].n_visits >= k_v

                                                              c.ann_time) > 0
                                        and c.corroborated)
        else: return ('reject', 'no_evidence_class', c)
        if not ok: return ('reject', 'evidence_insufficient', c)
        if not in_scope(val(c.evidence), (c.region, c.t)):
            return ('reject', 'evidence_out_of_scope', c)      # 时空有效性
    if prediction_used_to_relax(budgets.prediction_log):
        return ('reject', 'prediction_as_evidence')            # A37
    if profile_used_for_safety(budgets.profile_use_log):
        return ('reject', 'profile_became_authorization')      # A39
    if min(x.K_margin for x in sched) < budgets.theta_K: return ('reject', 'K_margin')
    if rho_sem(sched, M) < budgets.rho_min:             return ('reject', 'rho_sem')
    if not all(l2.resolved for l2 in consent_log):      return ('reject', 'consent_open')
    if not stl_monitor(phi, budgets.STL_trace):         return ('reject', 'stl_violation')
    return ('ok', STCert(M.core, sched, U.cert, phi, budgets.probe_log,
                         budgets.prediction_log, budgets.profile_use_log))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| STBF | O(\|val\|·(d_θ³+E)) 增量 | O(\|V\|·\|T\|·d_θ) | 保守迁移、`θ⁺` 单调、作用域有效（A37/A38） |
| STUM/CTG | O(\|ctx\|·H_op+CUSUM) | O(\|ctx\|) | 用途隔离、`w_h≤w_max`、超分布归零（A39/A41） |
| ST-PCE | O(\|CP\|·k_p·(C_VOI+\|N_ℓ\|)) | O(\|V\|·\|T\|+\|σ\|) | 时空 VOI 悲观、预测只收紧、`k_p` 终止（A37） |
| STL-IC | O(\|φ\|·H) 监控 | O(\|trace\|) | 有界时域 sound、延迟有界、非响应≠同意（A40/A42） |
| ST-MEC | O(\|σ\|+\|trace\|+\|logs\|) | O(\|σ\|) | 证据时空有效、预测/画像用途审计（A37/A39） |

**正确性定理（Spatio-Temporal Evidence-Grounded Commitment Soundness, ST-EGCS）**
假设 A22–A28（第 53/54 轮）、A29–A32（第 55 轮）、A33–A36（第 56 轮）成立；新增：
**(A37)** 时空场预测区间校准，覆盖 `≥1−α`，且保守迁移（域外只抬风险界），预测误差上界 `ε_ST`；
**(A38)** 无洗白：任何空间/时间转移不得降低未直接观测点的风险界；
**(A39)** 用途隔离：画像只改解释通道/详略/同级偏好，`cap` 只收缩可行集，`{δ_f,δ_probe,w_max,θ_L1,τ_int}` 与 `D_safe` 不接收画像；
**(A40)** 注意力预测校准、`defer` 预算有界、非响应不授权；
**(A41)** 校准场变点检测延迟 `≤τ_cp`，超分布上下文权重归零并要求佐证；
**(A42)** STL 运行时监控对有限时域 sound 且实时。则：

1. **承诺健全性**：每次承诺接触 `P(fail) ≤ δ_f + ε_cal + ε_probe + ε_h + ε_ST`；
2. **安全单调性**：时空预测、画像、注意力、协商只经（a）收缩可行集、（b）抬高风险界、（c）改变交互模态、（d）触发保守动作 影响系统，不存在升险路径；
3. **时序健全性**：不产生违反 `φ` 的不可逆接触，尤其不在人占据区域做出不可逆接触；
4. **终止性**：ST-PCE 在每检查点 `k_probes` 与有限 `defer` 预算内终止于 {承诺, 绕行, 降档, 协商, 安全停}；
5. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_cal + ε_probe + ε_h + ε_ST)
             − P(作用域误判) − P(预测越界∧被用于放松) − P(画像越权)
             − P(变点漏检) − P(注意力误判∧误授权) − P(STL 监控漏报)
```

关键：**推断只能收紧不能放行**——预测抬高风险界、画像只改说法、注意力低则不发问；**证据必须同时"在正确地点、正确时间、正确上下文"**——`val(e)` 把第 56 轮"永久的证据"变成"会过期的观察"；**变点与用途审计把"内部绕过"变成可检测的证书拒绝**。

## 6. 本轮最大风险

**一句话**：时空推理与用户画像都是"推断"，而安全契约只认"观察"——一旦让预测冒充证据、让画像冒充授权，系统就会自信地"预测掉"本该重探的检查点、体贴地"个性化掉"本该保守的风险预算；因此必须把 **预测只收紧、画像只改说法、非响应不等于同意** 做成不可绕过的类型不变式与证书审计，宁可多探一次、多说一句，也绝不让推断为风险放行。
