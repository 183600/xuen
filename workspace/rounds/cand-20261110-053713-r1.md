# 第 41 轮 · 双灵感落地 v8：可观测性融合证书 × 无刷电机执行包络 × 传感-驱动对偶闭环（四层架构 v6）

> 承接第 40 轮（v7/v17：可认证流匹配执行 × 度量语义几何锚定 × 证书驱动课程引擎，四层架构 v5）。本轮灵感词「传感器融合、无刷电机」驱动设计沿证书链**向下再钻一层**：把第 40 轮的「漂移球 B_t」细化为「可观测性 + 一致性 + 时间同步」三重融合证书，把证书从「策略输出」钉到「电机电流环与热包络」，并用传感-驱动对偶把两者闭成物理环。

## 0. 直觉与动机

**灵感 1（传感器融合 → 融的是证书，不是数值）**：第 40 轮的 B_t 由 LIO 单帧残差推出，隐含假设「融合系统没有系统性错误」。但真正的传感器融合不是把测量加权平均，而是同时回答三个问题：a) 状态在哪些方向上**可观测**——长走廊里横向位移不可观测，漂移球再小也是空头支票；b) 各模态**是否互相一致**——究竟是视觉被反光/遮挡骗了，还是激光被雨雾粉尘骗了；c) 融合的**时间对齐**误差有多大——IMU 与相机/激光的时间戳偏差会变成系统性偏置，直接击穿误差界。于是把「融合」本身升级为一张**融合证书 CertFusion**：(x̂, Σ, o, χ², τ_sync)。直觉：可观测性说明「证书在哪个方向上是空头支票」，一致性说明「哪个传感器在说谎」，时间同步说明「这张证书过期了没有」。三者缺一，B_t 就只是「看起来很小」。

**灵感 2（无刷电机 → 把证书钉到电流环与热包络）**：第 40 轮证书最底端只到动作块 a ∈ R^{d_a·H}，但机器人能否执行由无刷电机的物理包络决定：扭矩常数 k_t、相电流上限 i_max、母线电压 V_bus 与反电动势 k_e·q̇ 的电压约束，以及最容易被忽略的**热约束**——绕组电阻随温度上升、永磁体高温退磁使 k_t 下降。一个不知道 k_t、i_max、R_th、C_th 的证书，是在给一个虚构的机器人发合格证。直觉：「策略说能跳 40 cm，电机说再跳就烧了——证书必须取二者的交集」。同时无刷电机也是**传感器**：编码器 + 相电流可构造扰动观测器，估计外部接触力矩 d̂，正好补上纯外感受融合对内力和接触的盲区。

**灵感 3（两者的对偶 → 物理可执行证书域 PFR）**：传感与驱动是同一物理环的两端——融合证书定义「你能看见什么」，执行器证书定义「你能做到哪」。二者求交得到 **PhysicalFeasibleRegion (PFR)**：几何有效 ∧ 可观测 ∧ 执行器可达 ∧ 热安全。更关键的是**对偶一致性**：外感受融合预测的接触/运动残差应与电机电流反推的 d̂ 互相印证；不一致意味着要么状态估计错了，要么存在未建模外力——两者都直接使证书失效。这样第 40 轮的区域化证书从一个几何区域升级为**物理闭环内自洽的区域**：证书不再是「策略的自我承诺」，而是「策略、感知、执行器三者共同签字」的合同。

## 1. 形式化定义

**定义 27（融合信念与融合证书 CertFusion）**：设多模态测量 {z_i}，因子图信念 b = (x̂, Σ)。对每个模态 i：残差 r_i = z_i − h_i(x̂)，协方差 S_i = H_i Σ H_iᵀ + R_i，稳健门控权重 g_i = min(1, c/||r_i||_{S_i^{-1}})（Huber）。Fisher 信息矩阵 J = Σ_i g_i H_iᵀ S_i^{-1} H_i，在任务相关子空间 U 上取**可观测性边际** o = λ_min(J|_U)。一致性统计 χ² = Σ_i g_i ||r_i||²_{S_i^{-1}}，自由度 df = Σ dim(z_i) − dim(x)。时间同步偏差 τ_sync 经灵敏度 J_τ 传播为额外协方差 Σ_sync = J_τ Σ_τ J_τᵀ，并有先验上界 τ_sync ≤ τ_max。
- CertFusion = {x̂, Σ, o, χ², τ_sync, B_t}，其中 B_t = k_δ·√tr(Σ+Σ_sync) 为 (1−δ) 漂移球。
- **有效判定**：CertFusion 有效 ⟺ P(||x̂−x|| ≤ B_t) ≥ 1−δ ∧ o ≥ o_min ∧ χ² ≤ χ²_{1−δ,df} ∧ τ_sync ≤ τ_max。
- **命题（污染鲁棒性）**：若被污染模态的总权重占比 ≤ ε，则稳健门控后的 B_t 至多膨胀为 (1/(1−ε)) 倍的无污染界（加权 M 估计的标准界）；当 ε→1 时证书自动判无效而非静默漂移。

**定义 28（执行器证书 CertAct 与认证扭矩包络）**：电机参数 θ_m = (R, L, k_e, k_t, i_max, V_bus, R_th, C_th, T_amb) 及其区间不确定集 Θ_m（由在线辨识给出）。热模型：C_th dT/dt = i²R(T) − (T−T_amb)/R_th，其中 R(T)=R₀(1+α(T−T₀))，k_t(T)=k_{t0}(1−β(T−T₀))。电压约束 |R i + L di/dt + k_e q̇| ≤ V_bus；FOC（i_d=0）下 τ = k_t(T)·i。
- 可行包络 E(q̇, T; θ_m) = {τ : ∃i, |i| ≤ i_max ∧ 电压约束成立 ∧ 前视热预测 T(t+Δ) ≤ T_max}。
- **认证扭矩上界** τ_max^cert(q̇, T) = min_{θ_m ∈ Θ_m} [ max feasible τ ] − ripple_margin，即对参数不确定集取**保守下界**再扣齿槽/电流环纹波裕度。
- CertAct = {τ_max^cert, B_T, m_th = T_max − B_T − T̂, t_th（热有效时域）}。
- **动作投影**：a* = argmin_a ||a − a_θ||² s.t. inverse_dynamics(a) ∈ E（逐关节盒约束 + QP，轨迹级平滑）。

**定义 29（物理可执行证书域 PFR 与传感-驱动对偶）**：
- **PFR(C)** = {x : ValidRegion_geom(x) ∧ o(x) ≥ o_min ∧ m_act(x) ≥ 0 ∧ m_th(x) ≥ 0}，其中 m_act = τ_max^cert − |τ_req|。
- **扰动观测器（电机即传感器）**：τ_ext ≈ τ_cmd − (M(q)q̈ + C(q,q̇)q̇ + g(q))，经观测器动态滤波得 d̂，带认证界 B_d。
- **对偶一致性**：δ_dual = || d̂ − d_fusion ||（d_fusion 由视觉/几何接触残差给出）；有效 ⟺ δ_dual ≤ B_d + B_contact。δ_dual 超界不语义为故障，而是「发生未建模接触 / 状态估计失效」二选一，交由 L3 仲裁。
- **CertBundle 升级**：新增 {CertFusion, CertAct, PFR, δ_dual}，与第 40 轮 {L_v, κ, ε_ode, N*, C_ms, ValidRegion} 并列，构成「流-几何-融合-执行器」四元证书。

## 2. 三大产出设计

### 2.1 IP-51 CERTIFIED-FUSION-ESTIMATOR（可观测性感知的融合证书）
1. 稳健因子图：IMU 预积分 + 激光 scan-to-map + 视觉特征 + 轮/关节编码器统一建模，逐模态 Huber/χ² 软门控，输出 (x̂, Σ)。
2. 可观测性监测：在任务子空间 U 上计算 FIM 最小特征值 o，在线判断「当前证书在哪些方向有效」；o 跌破阈值即触发主动感知或降级。
3. 一致性监测：滑窗 χ² 检验 + CUSUM 变点检测，区分「慢漂移」与「突跳」，避免单帧噪声误熔断。
4. 时间同步证书：硬件时间戳 + 缓冲区最大偏差估计 τ_sync，按灵敏度传播进 Σ，超出 τ_max 直接判证书过期。
5. 退化阶梯：o 下降 → 扩球 + 主动感知（减速/环视）；χ² 超界 → 软降权可疑模态；全部失效 → 交总线熔断并切换保守技能。输出 CertFusion 给 C_ms（IP-36）与 ValidRegion（IP-49）。

### 2.2 IP-52 ACTUATOR-ENVELOPE-CERTIFICATE（无刷电机执行包络证书）
1. 在线参数辨识：阶跃/正弦激励辨识 R、L、k_t、k_e；温升响应辨识 R_th、C_th；输出参数区间而非点值，形成 Θ_m。
2. 热-电压联合包络：把电流上限、母线电压/反电动势、前视热预测合并为 E；对 Θ_m 采样/区间优化取保守 τ_max^cert，并给出热有效时域 t_th。
3. 动作投影：流匹配输出的动作块经逆动力学映射到关节力矩，逐关节投影进 E（QP），再做轨迹级平滑与速率限制，保证「说得出就做得到」。
4. 电机即传感器：电流环 d 轴/ q 轴指令与编码器差分构造扰动观测器，输出 d̂ 与 B_d，喂给 IP-53 的对偶检测与安全交互。
5. 故障与降级：过流/过温/参数漂移触发重辨识与 RCA 重颁；热逼近上限时按「降载-降速-停机」三级阶梯降级。

### 2.3 IP-53 DUAL-CONSISTENCY-RUNTIME（传感-驱动对偶闭环）
1. 物理可执行域：融合 CertFusion、CertAct 与几何 ValidRegion 求交得 PFR，作为总线路由与规划器的硬约束。
2. 五类熔断触发器：几何出区、可观测性不足、执行器饱和、热超限、对偶不一致；每类有独立的降级策略（环视/减速/位姿调整/降载/阻抗切换）。
3. 对偶仲裁：δ_dual 超界时用「短时观测窗 + 置信区间交集」判定是未建模接触还是估计失效，分别走阻抗控制或状态重初始化。
4. 证书域健康度回注：把 m_act、m_th、o、δ_dual 作为第 40 轮课程引擎 D(τ) 的新边际项，课程主动避开「热边界/可观测边界/执行器边界」，让训练分布与物理可行域对齐。

## 5. 本轮最大风险

**一句话**：整套「物理接地」悬于「参数与热模型的地基」——若电机参数在线辨识与热模型在老化、负载与环境扰动下失准，执行器包络会要么过于乐观（烧电机/静默失证）要么过于保守（PFR 缩成空集、机器人僵住），叠加可观测性证书自身的保守性，可能让这次「向下接地」反而制造出新的系统性故障源，故 E73/E75 为本轮第一守门实验。

## 2. 关键算法

### IP-51 融合证书（伪代码）
```
def fusion_certificate(measurements, x_hat, task_subspace, delta):
    factors = []
    for z_i, H_i, R_i in measurements:
        r = z_i - h(x_hat); S = H_i @ Sigma @ H_i.T + R_i
        g = huber_gate(r, S)                 # g∈[0,1] 软门控
        if g > 0: factors.append((g, r, H_i, S))
    x_hat, Sigma = robust_factor_graph(factors)
    J    = sum(g * H.T @ inv(S) @ H)
    o    = lambda_min(project(J, task_subspace))
    chi2 = sum(g * r.T @ inv(S) @ r)
    tau  = max_timestamp_skew(measurements)
    B_t  = delta_quantile(Sigma) + sync_inflation(tau)
    cert = CertFusion(x_hat, Sigma, o, chi2, tau, B_t)
    if not cert.valid(): degrade(cert)       # 扩球/主动感知/交总线
    return cert

def degrade(cert):
    if cert.o < o_min:      Bus.request('active_sensing'); widen(cert)
    if cert.chi2 > crit:    downweight_outlier_modalities(cert)
    if cert.tau_sync > tau_max: Bus.fuse('stale_certificate')
```

def certified_torque_envelope(model, qd, T_hat, horizon):

def physical_feasible_gate(cf, ca, geom):
    d_hat    = disturbance_observer(tau_cmd, q, qd, qdd)

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 正确性保证 |
|---|---|---|
| 融合证书 | 因子图 O(iter·E)；FIM 谱 O(d_x²·n_s) | **命题**：污染占比 ε ⟹ B_t ≤ B_0/(1−ε)；无效则显式判失效 |
| 可观测性 | 任务子空间投影 O(d_U·d_x²) | o ≥ o_min ⟹ 证书在 U 上非空头支票 |
| 参数辨识 | 单轴激励 O(T·d_θ)，在线增量 | 区间覆盖真值（含老化）由区间估计保证 |
| 扭矩包络 | 场景采样 K·O(d_joint)，可缓存 | **定理**：τ ≤ τ_max^cert ⟹ 电流/电压/热约束对 ∀θ_m∈Θ_m 成立 |
| 动作投影 | QP O(d_a³)（小规模） | 投影后轨迹满足逐关节力矩盒约束 |
| 扰动观测器 | 每控制周期 O(d_joint²) | d̂ 误差界 B_d 由模型不确定集导出 |
| 对偶检测 | O(d_joint) | 超界 ⟹ 存在未建模接触或估计失效（二者必居其一） |
| 组合契约 | O(|V|+|E|) | PFR 交集非空检查 + o_comp=min(o_i) + E_comp=∩E_i |

## 5. 风险与缓解

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 参数/热模型失准（老化、负载、环境）→ 包络乐观或过保守 | 高 | 在线重辨识 + 区间不确定集 + 保守包络；E75 第一守门；漂移触发 RCA 重颁 |
| 可观测性证书过保守 → PFR 空集、机器人僵住 | 高 | 仅任务子空间计算 + 主动感知 + 滞回放宽；E73 守门 |
| 卡方门控误杀好传感器 | 中 | Huber 软加权 + CUSUM 变点 + 窗口滞回；E74 守门 |
| 对偶不一致难分「未建模接触」与「估计失效」 | 中 | 置信区间交集 + 短时观测窗 + 阻抗/重初始化双分支仲裁；E77 守门 |
| 热慢时间尺度与课程/重认证快时间尺度冲突 | 中 | 双时间尺度 + 热前视 horizon + 课程侧 EWMA |
| 动作投影引发轨迹抖动/不连续 | 中 | QP 平滑 + 轨迹级投影 + 速率限制 + 投影代价入奖励 |
| 五类熔断相互叠加导致频繁降级 | 中 | 触发器优先级 + 冷却期 + 降级状态机；E78 限制熔断次数 |

## 6. 本轮最大风险

**一句话**：整套「物理接地」悬于「参数与热模型的地基」——若电机参数辨识与热模型在老化/负载/环境扰动下失准，执行器包络要么乐观到烧电机并静默失证，要么保守到 PFR 缩成空集、机器人僵住，叠加可观测性证书的保守性，可能让这次「向下接地」反而变成新的系统性故障源，故 E73/E75 为本轮第一守门实验。
