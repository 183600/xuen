# 第 69 轮（承接第 68 轮「CALM-RAS 自标定风险自适应闭环」IP-243~252；灵感循环第 2 轮；本轮灵感：「移动底盘」×「迁移学习」）

> 第 68 轮 CALM-RAS 把「标定」从离线常数升级为在线潜变量，用零标签自监督持续驱动、用单模型多任务保证同源一致，回答了「我的测量还准吗」。但它的地基里藏着两个从未写出的假设：**平台是静止的、身体是不变的**。
>
> 静态段门控 `σ_stat` 假设存在「机器人 + 场景都静止」的时刻来回收零漂；标定向量 `c_t ∈ ℝ¹²` 假设同一组常数对整台机器终身有效。**移动底盘**一来，两条同时崩塌：轮式底盘在世界系里几乎不存在真正的静止段（悬架微振、载荷转移、轮地蠕动），而且最关键的身体参数（轮半径、轮距、里程计尺度、质心）在静止时**根本不可观测**——可观测性来自持续激励，不来自静止。**迁移学习**一词点破第二层：换型/换载荷/换地形时 `c` 是身体条件的函数；把整组 `c` 从 A 车搬到 B 车，身体特异参数就成了 EKF 里一个「自信的错误先验」，比没有先验更危险。
>
> 核心命题：**把「静止自标定」升级为「运动可观测自标定」，把标定与表征分解为「共享不变子空间 + 身体特异子空间」，迁移只搬不变部分，并给跨身体迁移加一道负迁移否决门——MoTRA-RAS（Mobile-chassis Transfer-Robust Adaptive RAS）。**
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「**换了一具身体、换了一种运动状态之后，我还能信自己吗**」。

## 0. 直觉与动机

**灵感 1（移动底盘 → 静止段是幻觉，激励才是标定之母）**
直觉：R68 用「静止段」自标定，因为在静止时所有模态理应给出同一答案。可移动底盘在世界系里几乎从不真正静止；更关键的是，轮半径、轮距、里程计尺度这些最要命的参数在静止时**不可观测**——站着不动无法估出轮子多大。正确的可观测条件不是「速度为零」，而是**持续激励（persistent excitation）**：平移激励轮半径与尺度，偏航/差速激励轮距与偏航偏置，地形起伏激励悬架与质心。这是经典结论：标定可辨识性 = 回归矩阵的秩，不是「零速度」。所以把 `σ_stat` 换成激励门控 `g_exc`；否则 R68 的静态回归会把运动残差当「漂移」吃掉，产生假标定。

**灵感 2（迁移学习 → 身体差异与知识差异必须分开）**
直觉：迁移学习的前提是源域与目标域「共享某些东西」。若把整组 `c` 从底盘 A 直接迁移到 B，任何不同的身体特异参数（轮半径、质心、悬架）都会变成**自信的错误先验**；R68 的 EKF 信任先验、抗吸收速率限制器又慢，结果是「越迁越错」。解法：把标定拆成 `c_sh`（共享计量：相机内外参、力零偏、时间同步、曝光）与 `c_body`（轮半径、轮距、悬架、质心、载荷、轮胎侧偏刚度），迁移只搬 `c_sh` 与不变表征；`c_body` 必须在新身体的激励丰富段重新估计。再加负迁移否决门：目标身体风险上界若超过源身体基线就拒绝迁移，退化为从零标定。

**灵感 3（移动底盘 × 迁移学习 → 里程计漂移是新的计量层）**
直觉：底盘一旦会动，**基座位姿本身就是一种测量**（轮里程计 / IMU / 视觉里程计）。它的漂移（尺度因子、轮距误差、偏航偏置、打滑）与 R68 的传感器漂移是同一类慢变量，只因为 R68 假设基座固定才没进 `c`。把里程计状态纳入计量层，并用非完整约束残差（无侧滑、无离地）、回环残差、视觉-轮式一致性作为零标签信号——这是移动底盘白送的自监督金矿，也顺手把「传感器故障 / 打滑 / 地形」从同一个 H_sensor 里拆开。

**灵感 4（三灵感合流 → MoTRA-RAS 六组件）**
1. **EKM Embodiment Kinematic Model**：基座 SE(3) + 非完整约束 + 轮地接触，把「平台」从背景变成可观测状态；
2. **PEX Persistent Excitation Gate**：以回归矩阵有效秩取代 `σ_stat`，欠激励只预测不更新；
3. **ECC Embodiment-Conditioned Calibration**：`c = (c_sh, c_body)`，`c_sh` 慢漂移、`c_body` 事件驱动跳变；
4. **IVD Invariant–Variant Decomposition**：表征与标定双分解，跨身体对齐只作用于不变子空间；
5. **ODM + CAF**：里程计计量 + 约束零空间投影的在线滤波（新增运动感知抗吸收）；
6. **NTG + J_MoTRA**：负迁移否决 + 身体绑定证书；RAS-WM† / CALM-RAS 继承核全部保留。

**灵感 5（对 R68 风险的对症下药，及其反噬）**
R68 的最大风险是「落在标定带宽内的缓变故障被标好」。移动底盘把它**放大**：运动残差大且与身体参数强相关，抗吸收更难。对症下药不是更乐观，而是用非完整约束的解析零空间给出物理上可靠的分离结构，并增加「身体不变性 canary」。但这也引入新风险：若不变性假设错了，迁移就是**自信地错**——这正是本轮的自陈风险。

## 1. 形式化定义（增量：定义 293–310）

**定义 293（MoTRA-RAS 总览）** MoTRA-RAS = (EKM, PEX, ECC, IVD, ODM, CAF, NTG, RAS-WM††)。三条不变式：
(i) **实时流零学习写操作**继承 R68（更新只在影子流、认证后原子换装）；
(ii) **身体标识不变式**：任何标定/适配器只在与 `embodiment_hash` 绑定的认证下生效，跨身体迁移必须重新过 NTG，未认证迁移的证书一律失效；
(iii) **激励可观测不变式**：`g_exc = 0`（回归矩阵欠秩）时禁止更新 `c_body`，只允许 EKF 预测步；欠激励段的一切残差不得归因于 `cal_body`。

**定义 294（基座运动状态）** `ξ_t = (v_b, ω_b) ∈ ℝ⁶` 为机体坐标系下的基座 twist，`ℬ_t ∈ SE(3)` 为世界系位姿。平面轮式底盘满足非完整约束：`v_y ≈ 0`（无侧滑）、`v_z ≈ 0`、`ω_x ≈ ω_y ≈ 0`（不翻滚/不俯仰离地）。约束残差 `e_kin,t = (v_y, v_z, ω_x, ω_y)` 由 IMU + 轮速 + 视觉几何在机体系独立测得。

**定义 295（身体条件标定向量）** `c_t = (c_sh, c_body) ∈ ℝ¹² × ℝ⁸`：
- `c_sh` 继承 R68 的 12 维共享计量（外参、焦距、力零偏、`Δt_sync`、曝光、情绪阈值）；
- `c_body = (r_L, r_R, b, k_s, ΔCOM_x, ΔCOM_y, m_payload, c_tire) ∈ ℝ⁸`（左右轮半径、轮距、悬架刚度、质心偏移、载荷、轮胎侧偏刚度）。
动力学分段：`c_sh⁺ = c_sh + w_sh`（慢漂移，`w_sh ~ 𝒩(0, Q_sh)`）；`c_body⁺ = c_body + δ_body·1[embodiment event] + w_body`——换型/换载荷是**事件驱动的跳变**，非高斯、不可用平滑滤波器吞掉。

**定义 296（运动可观测回归）** 标定观测模型 `y_t = h(c_t; ξ_t, obs_t) + ε`，线性化后 `y_t ≈ Y_t·c_t + ε`，回归矩阵 `Y_t ∈ ℝ^{m×20}` 由 twist、轮速、IMU 比力、视觉几何构成。可观测性度量 `ρ_exc(t) = σ_min(Y_tᵀY_t)/σ_max(Y_tᵀY_t)`，并以数值有效秩 `rank_ε(Y)` 判定。

**定义 297（持续激励门控 PEX）** 替代 R68 的 `σ_stat`：
`g_exc(t) = 1[rank_ε(Y_{t−W:t}) = d_c ∧ ρ_exc(t) > ρ_min]`。
语义：**静止不是可观测，运动丰富才是可观测**；纯静止只观测零偏/重力模式，观测不到 `r_L, r_R, b`。`g_exc=1` 才允许 CAF 更新，`g_exc=0` 一律退化为预测步（冻结 `ĉ_body`）。

**定义 298（不变/特异分解 IVD）** 表征与标定双分解：
`z_t = Π_inv z_t ⊕ Π_var z_t`，投影到不变子空间 `𝒮_inv` 与身体特异子空间 `𝒮_var`。
分解目标：跨身体对齐 `Π_inv`（同一场景不同底盘 → 同一表征），同时对 `Π_var` 施加身体判别器对抗（身体标签可预测），并约束 `Π_inv ⊥ Π_var`。标定同理：`c_sh ∈ 𝒮_inv^cal`、`c_body ∈ 𝒮_var^cal`。

**定义 299（迁移散度与负迁移否决 NTG）** 源身体 S、目标身体 T：
`γ_tr = d_MMD(Π_inv Φ_S, Π_inv Φ_T) + λ_c·‖c_sh^S − c_sh^T‖`。
迁移收益上界 `Δ_benefit ≤ B_inv(γ_tr)`，风险下界 `Δ_risk ≥ R_var(c_body^T 未重估)`。
**否决条件**：目标身体 worst-case `λ_risk` 上界 > 1.0× 源身体基线，**或** 目标身体上的金标 canary 残差 `‖r_canary‖` 未改善，则拒绝迁移，退化为从零标定（保守但不错误）。

**定义 300（里程计计量 ODM）** 里程计状态 `c_odo = (s_L, s_R, b_odo, β_yaw, τ_slip) ⊂ c_body`（轮速尺度、轮距、偏航偏置、滑移时间常数）。零标签信号：非完整约束残差 `‖e_kin‖²` + 回环位置残差 + 视觉/轮式里程计一致性。

**定义 301（运动感知残差向量）** 把 R68 的 `r_t` 扩展为 `r_t^M = (r_geo, r_sync, r_zero, r_emo, r_wm, r_kin, r_odo)`：
`r_kin = e_kin`（非完整约束残差）；`r_odo =` 闭环/视觉-轮式一致性残差。

**定义 302（运动感知归因）** 把定义 280 的静态归因替换为激励条件归因：
`P(cause ∈ {cal_sh, cal_body, fault, real} | r_t^M, g_exc, ξ_t) ∝ p(r_t^M | cause, ξ_t)·P(cause)`，
其中 `p(r | cal_body, ξ) = 𝒩(r; Y_t δ̂_body, R)` **仅当 `g_exc=1` 时可信**；`g_exc=0` 时该分量退化为宽先验（不许吸收）。这是「欠激励不得硬标定」的归因级保证。

**定义 303（运动感知抗吸收 CAF）** 在 R68 速率限制器之外增加**约束零空间投影**：标定更新只落在 `N(Y_t)` 内，`δc ← Proj_{N(Y_t)} δc`；落在行空间 `R(Y_t)` 的快变残差分量不吸收。带宽仍为 `ω_cal ≈ 0.1 Hz`。注意：身体参数的**慢**变化（如轮胎磨损使 `r` 以 ≪ ω_cal 漂移）仍落在可解释方向，会被吸收——见定义 310 与本轮风险。

**定义 304（迁移感知阈值重参数化 CAR-T）** 令 `U = tr(Σ_c)`：
`τ_temporal = τ⁰_temporal(1+κ_T U)(1+κ_G γ_tr)`；
`τ_wm = τ⁰_wm(1+κ_w U)(1+κ_G γ_tr)`；
`τ_risk = τ⁰_risk(1−κ_r U)(1−κ_G γ_tr)`；
`λ_floor = max(0.6, 0.8·1[U > τ_cal ∨ γ_tr > τ_tr])`。
语义：标定或迁移任一不确定 → 一致性阈值放宽（防误报）∧ 风险阈值收紧 ∧ λ 下限抬升；与 R68 同构，新增迁移这道闸。

**定义 305（干扰集 AIC-MoTRA）** `ℰ_MoTRA = ℰ_CALM × ℰ_mob × ℰ_tr`：
`ℰ_mob = {欠激励误标定, 运动残差吸收, 滑移误归因, 里程计漂移}`；`ℰ_tr = {负迁移, 假不变性, 身体错配, 证书跨身体失效}`。

**定义 306（J_MoTRA 证书）** `J_MoTRA = (J_CALM, embodiment_hash, ρ_exc, invariance_test_stat, γ_tr, transfer_verdict, motra_ver)`。
Valid ⇔ `Valid(J_CALM) ∧ g_exc 满足持久激励 ∧ invariance_test = PASS ∧ transfer_verdict ∈ {ACCEPT, REBUILD} ∧ 红线（定义 276-ii）未越界`。

**定义 307（迁移自监督损失）** `L_tr = λ_inv·L_inv + λ_var·L_var + λ_kin·‖e_kin‖² + λ_odo·‖r_odo‖² + λ_ntg·max(0, γ_tr − γ_max)`。
全部零人工标签：不同底盘/地形的同一场景对（`L_inv` 对齐）、身体标签（`L_var` 对抗判别）、约束残差、回环。`λ_ntg` 项把「迁移散度」当预算约束而非自由收益。

**定义 308（管线）** 离线：舰队多身体数据预训练不变表征 → 身体条件微调 → 每身体 PEX 标定 → NTG 认证。在线：新身体接入 → `embodiment_hash` 注册 → 激励丰富段在线重估 `c_body` → IVD/NTG 判定 → 通过才允许迁移 `c_sh`，否则从零标定。

**定义 309（假不变性）** 若存在身体特异方向 `v ∈ 𝒮_var` 被错误投影进 `𝒮_inv`（`‖Π_inv v‖ > 0`），迁移就把源身体偏差当作普适先验。定义 `invariance_test_stat = sup_v |corr(Π_inv v, body_label)|`，要求 `< τ_inv` 才判 PASS。

**定义 310（跨身体误差分解）** `R_T(θ) − R_S(θ) = [R_T(θ) − R_T(θ_{S→T})] + [R_T(θ_{S→T}) − R_S(θ)]`：
第一项是**迁移间隙**，由 `γ_tr` 与 `invariance_test_stat` 界住；第二项是**不变部分收益**，由共享计量样本增益界住。**负迁移 ⇔ 迁移间隙 > 不变收益**——这正是 NTG 要观测的量。

class EmbodimentKinematicModel:
    def __init__(self, wheelbase, track):
        self.b, self.W = wheelbase, track
        self.B = SE3.identity()          # 世界系位姿
        self.xi = np.zeros(6)            # 机体系 twist

    def step(self, odo, imu, dt):
        self.B = self.B @ exp_se3(self.xi * dt)
        V = self.wheel_velocity(odo)     # r_L/r_R 估计来自 c_body
        e_kin = np.array([V[1] - self.xi[1],             # 无侧滑
                          self.xi[2], self.xi[3]])       # 无离地/翻滚
        return self.B, self.xi, e_kin

    def regressor(self, odo, imu, vis):
        # Y_t ∈ R^{m×20}：twist/轮速/比力/视觉几何 → c_sh⊕c_body
        return build_Y(self.xi, odo, imu, vis)


# IP-254 PEX：持续激励门控（取代 σ_stat）
class PersistentExcitationGate:
    def __init__(self, d_c=20, rho_min=0.02, W=40, eps=1e-3):
        self.d_c, self.rho_min, self.W, self.eps = d_c, rho_min, W, eps
        self.buf = deque(maxlen=W)

    def update(self, Y_t):
        self.buf.append(Y_t)
        Y = np.vstack(self.buf)
        s = np.linalg.svd(Y, compute_uv=False)
        rho = (s[-1] / s[0]) ** 2
        rank = int((s > self.eps * s[0]).sum())
        return (rank == self.d_c) and (rho > self.rho_min)

    def __init__(self, d_sh=12, d_body=8, omega_cal=0.1):
        self.c_sh, self.c_body = np.zeros(d_sh), np.zeros(d_body)
        self.S = block_diag(Q_sh, Q_body)

    def step(self, y, Y, g_exc, event=None):
        self.predict(event)                  # c_sh 慢漂移；c_body 事件跳变
        if g_exc:                            # 欠激励只预测不更新
            delta = self.kalman_gain(Y) @ (y - Y @ self.c())
            delta = nullspace_project(Y, delta)   # 0.1Hz 带宽 + 零空间投影
            self.update(delta)
        self.rate_limit(omega_cal)           # 继承 R68 反吸收物理防线
        U = np.trace(self.S)
        return self.c(), U


# IP-256 IVD：不变/特异分解（影子流训练）
class InvariantVariantDecomposer:
    def project(self, z):
        return self.P_inv @ z, self.P_var @ z

    def loss(self, zs_S, zs_T, body_labels):
        z_inv_S, z_inv_T = self.project(zs_S)[0], self.project(zs_T)[0]
        L_inv = mmd(z_inv_S, z_inv_T)                  # 跨身体对齐

        return L_inv + L_var + L_orth

def negative_transfer_guard(source, target, c_sh, invariance_stat, gamma_tr):

        return 'REBUILD'                          # 退回从零标定

    r = residuals_motion(o, e_kin, M.odo_residual)            # 5) 七元组残差
    cause = M.cfa_motion(r, g_exc, xi, c)                     # 6) 激励条件归因
    A = M.ach.propose(z, H=cause)
    k = M.c_ras_wm.certified_prefix(A, cause, M.m_ras, M.alpha_chunk)
    if (not g_exc) or U > TAU_CAL:
        k = min(k, M.k_cal_shrink(A, max(U, TAU_CAL)))        # 7) 欠激励/不确定收缩
    lam = max(M.efs.risk_scale(cause), lam_floor(U, M.gamma_tr))
    tau = M.pi_sigma.prefix_dispatch(A[:k]) * lam
    M.vqa_c.submit_async(z, {'cal': (c, U), 'exc': g_exc, 'cause': cause})
    M.cac.maybe_commit(M.shadow, M.time_since_last_commit)    # 8) 继承认证提交
    return k, lam, cause, (c, U)
```

## 3. 推导

**引理 16（激励可观测性）** 在平面轮式底盘模型下，回归矩阵 `Y` 的秩随运动模式分解：纯平移 `v_x` 激励平均轮半径 `(r_L+r_R)/2` 与里程计尺度；差速/转向 `ω_z` 激励轮距 `b` 与偏航偏置 `β_yaw`；静止 `ξ=0` 时 `rank(Y) ≤ dim(零偏子空间)`，无法辨识 `r, b`。故 R68 的静态门控在移动底盘上对这些参数**系统性不可观测**；PEX 以 `rank_ε(Y)` 为门，在含平移 + 旋转的轨迹下是必要且充分的辨识条件。

**引理 17（不变迁移界 / 负迁移阈值）** 设不变子空间对齐误差 ≤ `ε_inv`、身体特异散度 `γ_var`，则
`R_T^tr − R_T^{from-scratch} ≤ C_inv·ε_inv − B_trans + L·γ_var`，
`B_trans` 为共享计量带来的样本增益。**负迁移发生当且仅当 `L·γ_var + C_inv·ε_inv > B_trans`**；NTG（定义 299）正是对该不等式右侧的可观测代理（canary 残差 + 风险上界 + `γ_tr`）。

**引理 18（运动感知抗吸收）** CAF 的零空间投影使标定只吸收 `N(Y)` 内分量；对行空间 `R(Y)` 中的快变故障分量，一阶跟踪器抑制增益仍为 `ω_cal/ω_f`（继承 R68 引理 13），故 PEX + CAF 不牺牲快变故障灵敏度。但**慢变身体参数**（轮胎磨损使 `r` 以 ≪ ω_cal 漂移、载荷缓慢蠕变）落在可解释方向，仍会被吸收——这是定义 310 的迁移间隙之外、本轮真正的残余风险。

**定理 16（MoTRA 端到端风险一致性）** 在 A87–A94 与 A95–A99 下：
1. `P(|τ_cmd − τ*| > ε) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_vqa + α_cal + α_tr`，`α_tr` 受引理 17 与 NTG 限制；
2. `g_exc = 0`（欠激励）⇒ 禁止 `cal_body` 更新、`λ_risk ≥ 0.8`、`k` 收缩——欠激励永远导向保守；
3. `γ_tr > τ_tr` 或 `invariance_test FAIL` ⇒ 拒绝迁移、退回从零标定（可能低效，但不会自信地错）；
4. 快变故障（`ω_f ≥ 3ω_cal`）检出概率不降（引理 18）。

**定理 17（迁移认证安全性）** NTG 是一次性否决：若目标身体 canary 未改善或风险上界超源基线，迁移被拒；假不变性检测（定义 309）以控制误接受率 `α_inv`，故有害迁移上线概率 ≤ `α_inv + (1−r_canary)·p_h`。证书跨身体失效由 `embodiment_hash` 绑定阻断：任何未重新认证的 `c_sh` 迁移都无法进入有效 `J_MoTRA`。

## 6. 本轮最大风险

**一句话**：MoTRA-RAS 的全部迁移安全性押在「不变/特异分解正确」这一条单一假设上——**若某个被当作不变的方向其实是身体特异的（假不变性），迁移会把源身体的偏差当成普世先验注入目标身体；与此同时，轮胎磨损、载荷蠕变这类缓变身体退化恰好落在 CAF 的可解释零空间里被当作「标定」缓慢吸收，而 NTG 的 canary 又是用同一套不变性假设构造的、抓不到这个偏差**，系统会在「迁移让我更懂这具身体」的错觉中，同时失去对慢变底盘故障的检出能力和对新身体真实差异的感知。

**次级风险与缓解**：
1. **欠激励误标定**：运动段稀疏时 `g_exc` 长期为 0、标定冻结 → 明确降级为「已知未标定」，λ 抬升，不假装准；
2. **假不变性**：`invariance_test_stat` 监控 + 多身体对照 + 证伪即 `REBUILD`；
3. **负迁移**：NTG 一次否决 + 从零标定回退（保守但不错误）；
4. **事件跳变被平滑**：`embodiment event` 触发 `c_body` 协方差膨胀而非平滑跟踪；
5. **证书链跨身体污染**：`embodiment_hash` 强绑定，任何未重新认证的迁移不得进入 `J_MoTRA`。

# IP-253 EKM：机身运动学与约束残差
class EmbodimentKinematicModel:
    def __init__(self, wheelbase, track):
        self.b, self.W = wheelbase, track
        self.B, self.xi = SE3.identity(), np.zeros(6)

    def step(self, odo, imu, dt):
        self.B = self.B @ exp_se3(self.xi * dt)
        V = self.wheel_velocity(odo)
        e_kin = np.array([V[1] - self.xi[1], self.xi[2], self.xi[3]])
        return self.B, self.xi, e_kin

    def regressor(self, odo, imu, vis):
        return build_Y(self.xi, odo, imu, vis)   # Y_t ∈ R^{m×20}

# IP-254 PEX：持续激励门控（取代 σ_stat）
class PersistentExcitationGate:
    def __init__(self, d_c=20, rho_min=0.02, W=40, eps=1e-3):
        self.d_c, self.rho_min, self.eps, self.buf = d_c, rho_min, eps, deque(maxlen=W)

    def update(self, Y_t):
        self.buf.append(Y_t)
        s = np.linalg.svd(np.vstack(self.buf), compute_uv=False)
        rank = int((s > self.eps * s[0]).sum())
        return (rank == self.d_c) and ((s[-1]/s[0])**2 > self.rho_min)

# IP-255/258 ECC + CAF：身体条件标定 + 零空间投影抗吸收

        return self.c(), np.trace(self.S)

def negative_transfer_guard(source, target, c_sh, inv_stat, gamma_tr):
    if inv_stat > TAU_INV:                     return 'REBUILD'   # 假不变性
    if target.canary_residual_after(c_sh) > 0.9 * target.canary_residual():
        return 'REJECT'                                        # canary 未改善
    if target.worst_case_lambda(c_sh) > source.baseline_lambda:
        return 'REJECT'
    return 'ACCEPT' if gamma_tr < TAU_TR else 'REBUILD'

# IP-262 主闭环
def MOTRA_round(M, obs):
    B, xi, e_kin = M.ekm.step(obs.odo, obs.imu, obs.dt)        # 1) 运动学
    z, o = M.mtm.forward(obs.pack, M.a_prev, M.scene_ctx)      # 2) 继承 CALM-RAS
    Y = M.ekm.regressor(obs.odo, obs.imu, obs.vis)
    g_exc = M.pex.update(Y)                                    # 3) 激励门控
    c, U = M.caf.step(o['cal'], Y, g_exc, obs.embodiment_event)# 4) 运动感知标定
    r = residuals_motion(o, e_kin, M.odo_residual)             # 5) 七元组残差
    cause = M.cfa_motion(r, g_exc, xi, c)                      # 6) 激励条件归因
    A = M.ach.propose(z, H=cause)
    k = M.c_ras_wm.certified_prefix(A, cause, M.m_ras, M.alpha_chunk)
    if (not g_exc) or U > TAU_CAL:
        k = min(k, M.k_cal_shrink(A, max(U, TAU_CAL)))         # 7) 欠激励/不确定收缩
    lam = max(M.efs.risk_scale(cause), lam_floor(U, M.gamma_tr))
    tau = M.pi_sigma.prefix_dispatch(A[:k]) * lam
    M.vqa_c.submit_async(z, {'cal': (c, U), 'exc': g_exc, 'cause': cause})
    M.cac.maybe_commit(M.shadow, M.time_since_last_commit)     # 8) 继承认证提交
    return k, lam, cause, (c, U)
```

## 4. 推导

**引理 16（激励可观测性）** 平面轮式底盘下 `Y` 的秩随运动模式分解：平移 `v_x` 激励平均轮半径与尺度；差速/转向 `ω_z` 激励轮距与偏航偏置；静止时 `rank(Y) ≤ dim(零偏子空间)`，无法辨识 `r, b`。R68 静态门控对这些参数系统性不可观测；PEX 以 `rank_ε(Y)` 为门，在含平移 + 旋转轨迹下是必要且充分的辨识条件。

**引理 17（不变迁移界 / 负迁移阈值）** `R_T^tr − R_T^{from-scratch} ≤ C_inv·ε_inv − B_trans + L·γ_var`；负迁移 ⇔ `L·γ_var + C_inv·ε_inv > B_trans`；NTG 为该不等式右侧的可观测代理（canary + 风险上界 + `γ_tr`）。

**引理 18（运动感知抗吸收）** CAF 零空间投影使标定只吸收 `N(Y)` 分量；行空间中快变故障分量抑制增益仍为 `ω_cal/ω_f`（继承 R68 引理 13），快变故障灵敏度不降。但慢变身体参数（轮胎磨损、载荷蠕变）落在可解释方向，仍会被吸收——主风险。

**定理 16（MoTRA 端到端风险一致性）** A87–A99 下：
1. `P(|τ_cmd−τ*|>ε) ≤ α_chunk+δ_fi+α_emotion+α_wm+α_vqa+α_cal+α_tr`；
2. `g_exc=0 ⇒ 禁止 cal_body 更新 ∧ λ_risk≥0.8 ∧ k 收缩`；
3. `γ_tr>τ_tr ∨ invariance_test FAIL ⇒ 拒绝迁移、从零标定`（保守但不错误）；
4. `ω_f≥3ω_cal ⇒ 快变故障检出概率不降`。

**定理 17（迁移认证安全性）** NTG 一次否决；假不变性检测以 `α_inv` 控制误接受率，故有害迁移上线概率 ≤ `α_inv+(1−r_canary)·p_h`；`embodiment_hash` 绑定使任何未重新认证的迁移无法进入有效 `J_MoTRA`。

## 7. 本轮最大风险

**一句话**：MoTRA-RAS 的全部迁移安全性押在「不变/特异分解正确」这一条单一假设上——**若某个被当作不变的方向其实是身体特异的（假不变性），迁移会把源身体的偏差当普世先验注入目标身体；同时轮胎磨损、载荷蠕变等缓变身体退化恰好落在 CAF 的可解释零空间被当作「标定」吸收，而 NTG 的 canary 又用同一套不变性假设构造、抓不到该偏差**，系统会在「迁移让我更懂这具身体」的错觉中，同时失去对慢变底盘故障的检出能力与对新身体真实差异的感知。

**次级风险与缓解**：欠激励误标定（`g_exc` 长期为 0 → 明确降级为「已知未标定」、λ 抬升，不假装准）；假不变性（`invariance_test_stat` + 多身体对照 + 证伪即 `REBUILD`）；负迁移（NTG 一次否决 + 从零标定回退）；事件跳变被平滑（`embodiment event` 触发协方差膨胀而非平滑跟踪）；证书链跨身体污染（`embodiment_hash` 强绑定，未重新认证迁移不得进入 `J_MoTRA`）。
