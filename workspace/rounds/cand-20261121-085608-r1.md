# 第 2 轮（UniBot 线 · 承接第 1 轮 UniBot-SAGE；本轮灵感：「动力学」×「低成本方案」）

> **连续性声明（不重新基线化）**：第 1 轮已建立 UniBot 线，定义 U1–U12、引理 L1–L7、实验 E601–E618、创新点 IP-01–IP-08 继续有效并封存。本轮新增定义 **U13–U22**、引理 **L8–L13**、实验 **E619–E634**、创新点 **IP-09–IP-14**。第 1 轮的四条硬结论继续作为约束：①终态成功是唯一计分货币（teaser 上 `step ≈ 1.337·succ + 0.09`，R²=0.9955）；②跨任务专长准正交，单 checkpoint 内技能路由 oracle +4.26；③断点在最后的对齐/插入/释放；④"做得快"没有红利（任务内 `corr(dur,succ) ≈ −0.011`）。

## 0. 本轮一句话：把"猜抓握"换成"测动力学"

第 1 轮把抓握当作需要学习的隐变量，代价是训练检测器、且漏判会把可救的失败变成硬失败。本轮反过来：**夹爪的开合本身就是一个一阶动力系统，物体只在它偏离"自由空间响应"时才存在**。于是接触/滑移检测退化为**一个标量参数 α + 一次减法**，训练成本≈0、推理<0.01 ms、延迟≈2 帧（67 ms）；省下来的算力只花在两个地方——最后一毫米的对齐/插入，以及真机 A/B。这就是「动力学」×「低成本方案」的交点。

## 1. 直觉（先不给公式）

**画面 1 · 夹爪是这台机器人上唯一"免费"的力传感器。**
接口没有力矩、没有触觉、没有夹爪力，只有 1 维夹爪开度。但夹爪从"开"到"闭"不是瞬时的：它有自己的响应时间。自由空间里，它会按一条可预测的曲线合拢到指令位置；两指之间夹了东西时，它**合不拢**——实际开度会停在比预测更高的位置。**"比预测多张开多少"就是接触强度的一个代理**。我们不需要训练一个网络去认物体，只需要先量出夹爪在自由空间里的那条曲线。

**画面 2 · 动力学是免费的物理先验，且比学习更抗分布外。**
一阶滞后、摩擦锥、动量守恒、单边接触——这些在训练分布外仍然成立。学习残差只在见过的数据里准；物理结构在没见过的东西上仍然给得出"会不会滑、能不能夹住、加速度上限多少"。所以正确的顺序是：**先用物理把可观测性拿到，再让学习在物理包络内收紧**。第 1 轮先学检测器、再谈物理，顺序反了。

**画面 3 · 低成本不是"少做事"，而是"按 ROI 排序"。**
第 1 轮的 SkillToken-MoE 要 8×A100×2–3 天，换 +2.5 分；而一个标量的接触检测几乎不花算力，换的是"把漏判从硬失败变成可救"。研究预算有限时，正确策略不是把每个想法都做一点，而是**先做每单位成本收益最高的那个，再用它省下的真机时段去买贵的那个**。这就是本轮的"低成本方案"：不是廉价替代，而是**成本归一化的研究组合**。

## 2. 接口现实：能测的动力学只有一条通道

本轮沿用并复核第 1 轮核实的接口事实：

- 观测：4 路 RGB（头 stereo + 左右腕）、双臂各 7 维关节位置、EE 位姿（base 系 xyz+rpy）、**1 维夹爪开度**、15 维下半身、语言串；**没有力矩、电流、触觉、腕部六维力**。
- 动作：**位置目标**——`joint` 给 7 维关节目标，`ee` 给 6 维位姿目标，二选一互斥；另有夹爪开度与 7 维 `pivot`。**不能直接下发力矩**。
- ⇒ 本轮所称"动力学"只能是**位置参考层的动力学**；唯一稳定可测的动力学量，是**指令与实测之差**（`action.*_gripper − observation.state.*_gripper`）以及它在时间上的演化。

## 3. 量化动机：一条免费的接触信号（本地子集探针）

在 `exp/duo_rows_cache`（15 任务、428 段、42,800 帧）上，用 **ConveyorSorting** 的自由空间段拟合一个一阶模型，得到：

| 量 | 数值 | 含义 |
|---|---|---|
| 自由空间一阶增益 α | **0.949**（τ≈35 ms，一步 R²=**0.877**） | 夹爪响应几乎是一阶的；一个标量就能刻画 |
| 自由张开时 state−action 偏移 | **−0.0078 ± 0.0175** | 空载时实测几乎无偏，说明残差不是标定误差 |
| 自由闭合时模型残差 | **+0.0012 ± 0.0256** | 自由空间残差≈0，阈值有 4σ 余量 |
| 接触密集任务模型残差均值 | **+0.12 … +0.22** | 明显偏离自由空间预测 |
| 阈值 τ=0.1 的精确率 / 召回 | **0.993 / 0.476** | 高精度、低召回——正好符合第 1 轮"只在确证未抓住时介入" |
| 帧级 AUC（接触 > 自由） | **0.675** | 单帧不完美，但门控足够 |
| 闭合到持续超阈的延迟 | 中位 **2 帧（67 ms）**，p90 3 帧 | 比一个 chunk（8–16 帧）短，能在一个块内抢占 |
| 接触组 vs 搬运组残差 | **0.162 vs 0.038**，Mann–Whitney **p=1.6×10⁻⁴** | 组间分离强（n=7/8，任务级标签为启发式） |
| 与 teaser 榜首均值的 Spearman | **−0.407（p=0.13, n=15）** | 方向对但**不显著**；只作弱证据，不据此调参 |

**这张表是本轮的地基**：它说明"接触"在接口里不是完全不可观测的，而是被藏在夹爪的动力学里；把它读出来不需要训练、不需要新传感器。**但它也暴露了本轮的软肋**：精确率高、召回只有 0.48，意味着"确证未抓住"很可靠，但"确证已抓住"不可靠——所以本轮的介入逻辑必须继续坚持第 1 轮的"高精度、低召回"。

## 4. 从"抓握隐变量"到"动力学残差"（严谨化）

第 1 轮把抓握写成 `g_t = σ(f_θ(φ_t, v_ee, Δgrip))`，需要伪标签与训练。本轮改写为**自由空间动力学 + 残差**：

**定义（自由空间夹爪模型）** 对每一侧夹爪，令 `q_t` 为实测开度、`a_t` 为指令开度，自由空间下
`q_{t+1} = q_t + α (a_t − q_t) + ε_t`，`α∈(0,1]`，`ε_t` 零均值、方差 `σ²`。
`α` 用**无接触段**（张开保持、或已知空载的闭合）最小二乘一次性拟合，不随任务更新。

**定义（接触残差）** `r_t = q_t − q̂_t`，其中 `q̂_t` 是用同一 `α` 与过去 `(q,a)` 递推得到的**自由空间预测**。
自由空间下 `r_t ≈ ε_t`（均值≈0）；有物体阻挡闭合时，`q_t` 系统性高于预测 ⇒ `r_t > 0`。

**定义（接触事件）** `C_t = 1[ r_{t−k+1}, …, r_t > τ_c ]`，取 `k=2`、`τ_c=0.1≈4σ`。
这是**高精度**判据：在自由空间上误报≈0.7%。

**定义（力代理）** 若指部等效刚度 `k_f` 已知（可由标定或数据回归得到），则接触法向力代理 `F̂_N ≈ k_f · r_t`（小变形线性近似）。
于是摩擦锥给出**滑移裕度** `S_t = μ F̂_N − m‖a_ee − g‖`；`S_t<0` 判为滑移风险。`m, μ` 不可测，用尺寸类别给保守上下界，只用于**限速**，不用于精确力控。

**关键点**：同一个残差 `r_t` 同时给出三件事——**(a) 有没有接触、(b) 接触有多"硬"、(c) 允许多大加速度而不滑**。这是"一个标量买三个功能"的低成本来源。

## 5. 研究问题（本轮版）

- **Q6（自由空间模型的可迁移性）**：`α` 在 15 个任务、不同 episode 之间是否稳定？采集控制器与评测控制器不同时，`α` 与 `τ_c` 会漂移多少？能否用**每个 episode 开头的自由张开段**在线自校准（零额外成本）？
- **Q7（残差是接触还是瞬态）**：`r_t` 里有多少来自"夹爪正在闭合"的自身瞬态、多少来自"真的夹住了"？一阶模型能否把瞬态消掉？腕部视觉的物体流残差能否作为第二证据做交叉验证（需要图像，本轮未验）？
- **Q8（低成本反层与昂贵栈的替代关系）**：在固定预算下，`{FreeDynSense, ReflexGate, LastMillimeter}` 与 `{SkillToken-MoE}` 的最优组合是什么？反层把真机时段省下来之后，贵的组件是否才值得买？
- **Q9（动力学校验的双重收益）**：加速度/加加速度/自由空间一致性校验，能否同时提升成功率与官方"动作统计规律性/可信度"评分？即"物理上良构"是否等于"审计上可信"？

## 6. 设计原则（在 P1–P6 之上新增 P7–P10）

- **P7 动力学优先**：能用解析残差解释的现象，不训练网络；学习只用于在物理包络内收紧，不用于替代包络。
- **P8 成本归一**：每个改进必须同时报告 `Δscore` 与 `Δcost`（GPU·h、真机·h、工程·人日）；不能给出 ROI 的改进不进入主线。
- **P9 精度优先于召回**：介入只在 >4σ 证据下触发；"没确证抓住"可以继续开环执行，但"确证没抓住"必须能救。宁可少救，不可误伤。
- **P10 只用接口保证存在的量**：不依赖隐藏低层控制器的增益、不依赖未声明的 chunk 插值语义；任何依赖先用官方 client 复刻验证。

## 7. 架构：快反层 + 慢决策层 + 成本账本

```
                ┌──────────────── 慢决策层（chunk 级，~3–8 Hz）────────────────┐
观测 o_t ──────►│ VLA 主干（单 checkpoint）→ 动作块 a_{1:T_a}（joint/ee）        │
                │ 可选：skill token / 阶段条件化（IP-01，本轮降级为可选）          │
                └───────────────┬───────────────────────────────────────────────┘
                                │ a_{1:T_a}
                ┌───────────────▼──── 快反层（观测级，30–60 Hz，CPU，<1 ms）───────┐
                │ FreeDynSense：r_t=q_t−q̂_t → C_t（接触/滑移）                     │
                │ ReflexGate：高精度触发重抓/改抓；n_retry≤3；否则不干预             │
                │ DynGuard：加速度/加加速度/自由空间一致性限幅（兼作可信度审计）      │
                └───────────────┬───────────────────────────────────────────────┘
                                │ 修正后的动作块
                ┌───────────────▼──── 成本账本（离线，每轮一次）────────────────────┐
                │ CostLedger：ROI_i = ΔS_i / (w·c_i)；按预算贪心分配；预注册 kill    │
                └────────────────────────────────────────────────────────────────┘
```

**严格退化链（任一环节不可用 ⇒ 行为回退而非漂移）**：

- L0 `FreeDynSense` 的 `α` 无法标定（如夹爪无状态反馈）⇒ 退回第 1 轮的学习检测器，再退回"不干预"；
- L1 `ReflexGate` 置信度不足 ⇒ 只做开环执行，不重抓；
- L2 `DynGuard` 限幅过紧导致成功率下降 ⇒ 关闭限幅，只保留审计；
- L3 整个反层失效 ⇒ 退回**纯基线策略**（永远保留一份能跑通、可信度合规的最小提交）。

## 9. 本轮最大风险（一句话）

**本轮把整个方案压在"夹爪 state−action 残差 ≈ 接触"这一条通道上，而它只在离线遥操数据里被验证过；一旦评测端的低层控制器、夹爪标定或采样率与采集时不同，`α` 与阈值就会整体漂移，于是最需要它的未见物体/新控制器场景，恰是它最不可识别的地方——便宜不是风险，"便宜地错"才是。**

## 0. 本轮结论摘要

**一句话路线**：把第 1 轮的"学习抓握检测器 + 昂贵技能混合"改成"**解析动力学残差反层 + 成本账本**"——用夹爪的一阶自由空间模型把接触/滑移变成一次减法，用高精度门控只在确证未抓住时介入，把省下的算力与真机时段投给最后一毫米。

**三条量化依据**：

| 证据（本地子集探针） | 数值 | 推出的设计 |
|---|---|---|
| 自由空间夹爪一阶模型 | α=0.949，τ≈35 ms，一步 R²=0.877 | 一个标量即可刻画夹爪响应；无需训练检测器 |
| 自由空间残差 vs 接触残差 | +0.001±0.026 vs +0.12…+0.22；τ=0.1 时精确率 0.993、召回 0.476 | 高精度、低召回 ⇒ 正好匹配第 1 轮 L3 的"只在确证未抓住时介入" |
| 接触组 vs 搬运组 | 0.162 vs 0.038，Mann–Whitney p=1.6×10⁻⁴ | 残差携带真实的接触信息，不是噪声 |
| 闭合到持续超阈延迟 | 中位 2 帧（67 ms），p90 3 帧 | 信号足够快；但控制延迟受 chunk 长度限制，需自适应短 chunk |

**低成本的含义（本轮定义）**：不是"用更差的模型"，而是**成本归一化的研究组合**——`ROI_i = ΔS_i / (w·c_i)`，先做每单位成本收益最高的解析反层，再用它省下的真机时段去购买昂贵的技能混合。第 1 轮的 IP-01（8×A100×2–3 天）因此**降为 P2**，而不是被否定。

**一句话结论**：**接触不需要被"学会"，它已经写在夹爪的动力学里；本轮的成本优势来自"先读物理、再买学习"。**

## 3. 创新点详述

### IP-09 · FreeDynSense 自由空间动力学接触/滑移检测（P0）

- **动机**：第 1 轮的最大风险是抓握误判的不对称性——漏判（以为抓住其实没有）会把可救的失败变成硬失败。学习检测器需要伪标签，而伪标签在未见物体上会漂移；偏偏未见物体是 5 类泛化场景之一。动力学提供了一条**不依赖物体外观**的通道：夹爪的闭合响应本身。
- **与现有方案的差异**：第 1 轮用 `g_t=σ(f_θ(φ_t,v_ee,Δgrip))`，需要训练与校准；本轮用**自由空间模型残差** `r_t=q_t−q̂_t`，只有 1 个标量 α，且残差有明确的物理含义（物体阻挡闭合的量）。它不是"更小的网络"，而是**换了一种可观测性来源**。
- **技术可行性**：高。全部量都在接口里（`action.*_gripper`、`observation.state.*_gripper`）；α 用无接触段最小二乘拟合，秒级完成；推理是 3 次乘加。
- **所需资源**：0 GPU·h；CPU <0.01 ms/步；内存 O(1)/端口。**不需要新数据、不需要新传感器、不需要新端口。**
- **落地步骤**：
  1. 从官方数据抽取"自由张开保持"与"自由闭合"段，拟合每侧 α、σ（本轮已在 15 任务子集上得到 α=0.949、σ≈0.026）；
  2. 用 `τ_c=0.1≈4σ`、`k=2` 定义接触事件；在自由空间上量误报（本轮 0.7%）；
  3. 在线自校准：每个 episode 开头若出现张开保持段，用最近 N 帧重估 α 的局部修正（只允许 ±10% 漂移）；
  4. 与第 1 轮的相位分类器对齐：只在 `grasp/lift/transport` 相位启用接触判定；
  5. 输出 `C_t`、`r_t`、`F̂_N=k_f·r_t`（k_f 需标定）给 IP-10/IP-12。
- **风险**：①残差里混有"夹爪自身闭合瞬态"——一阶模型能消掉大部分，但若评测端控制器有二阶/饱和特性，α 不够；②评测端夹爪标定与采集端不同 ⇒ 需在线自校准（Q6）；③残差只能说明"有东西挡着"，不能区分"夹住物体"与"顶到桌面"——需与 EE 运动/腕部视觉交叉验证（Q7）。

### IP-10 · ReflexGate 高精度反射门控 + 重抓/改抓（P0）

- **动机**：检测到"没抓住"之后，必须有一个**有界、可回退**的介入策略，否则反层只是看客。
- **与现有方案的差异**：第 1 轮 IP-02 的介入准则是"置信度 > τ_conf 才判未抓住"；本轮把它落到**可测量的 4σ 残差**上，并显式耦合 chunk 长度：接触相位返回 1–2 步短 chunk，使下一次 `get_action` 能在 ~100 ms 内看到结果。**反层不能打断已下发的 chunk**，所以"反应带宽"由 chunk 长度决定，这是本 IP 与 IP-03 的强耦合点。
- **技术可行性**：高。纯策略内部逻辑，不新增接口。
- **所需资源**：0 训练；真机 A/B 2–3 h（插入/旋转任务）。
- **落地步骤**：
  1. 触发条件：`C_t ∧ phase∈{grasp,lift,transport} ∧ P_feasible=1 ∧ n_retry<3`；
  2. 重抓原语：微开 → 下探 → 闭合 → 等待 `r_t` 上升并持续 k 帧 → 继续；
  3. 改抓：若同一物体连续 2 次重抓失败，切换到非抓取原语（推/扫/倾倒，沿用第 1 轮 IP-02 的 `Π`）；
  4. 失败兜底：`n_retry≥3` 或 `P_feasible=0` ⇒ 放弃该物体，执行"保底放置/回原位"，避免超时；
  5. 与短 chunk 调度：接触相位 `T_a=1–2`，搬运相位 `T_a=8–16`（U18）。
- **风险**：①误介入（自由空间误报 0.7%）会打断正常抓取 ⇒ 4σ + k=2 + 最多 3 次；②重抓本身可能把物体推走 ⇒ 下探前先小幅回退；③短 chunk 增加 API 调用与延迟压力 ⇒ 只在接触相位启用，压测见 E625。

### IP-11 · CostLedger 研究成本账本与 ROI 路由（P0，元创新）

- **动机**："低成本方案"若只停留在口号，最后仍会滑回"什么都做一点"。必须把成本变成一等公民，否则无法在预算内做取舍。
- **与现有方案的差异**：常见研究计划只列"要做什么"；本轮同时列"每个想法的成本与收益"，并用预注册的 kill 准则决定何时停。它不产生新算法，但决定**哪个算法值得被做**。
- **技术可行性**：高（工程/管理活）。
- **所需资源**：0 算力；1 人日维护。
- **落地步骤**：
  1. 定义成本向量 `c_i=(GPU·h, 真机·h, 人日)`，权重 `w` 由剩余预算决定；
  2. 对每个 IP 给出 `ΔS_i` 的先验区间（不是点估计）；
  3. 计算 `ROI_i=ΔS_i/(w·c_i)`，按依赖关系（IP-09 先于 IP-10）做拓扑排序后的贪心分配；
  4. 预注册 kill：若某 IP 的首个可证伪实验未达门槛，立即停止并释放预算；
  5. 每轮末重算一次，公开账本（可审计）。
- **风险**：①`ΔS_i` 的先验可能过于乐观，导致 ROI 排序失真 ⇒ 用区间 + 最坏情况下界排序；②"元工作"可能被视为不产生分数 ⇒ 只作为内部决策工具，不占提交接口。

### IP-12 · LastMillimeter 位置域有界柔顺 + 接触触发搜索（P1）

- **动机**：第 1 轮与 RoboDojo 都指向同一断点——最后的对齐/插入/释放。插入失败的本质是**接触后的微小位姿误差**，而接口只能给位置目标。
- **与现有方案的差异**：不追求力控（接口不允许），而是在**位置参考层**模拟柔顺：接近目标时降低增量增益、限制单步位移；当 `C_t` 或关节跟踪残差超阈时，触发一个**有界搜索**（螺旋/微扫/回退-再进），而不是继续硬推。
- **技术可行性**：中。位置域柔顺是经典做法；难点是不知道低层控制器的增益，需先复刻评测器语义。
- **所需资源**：0–1 GPU·h（参数整定）；真机 4–6 h。
- **落地步骤**：
  1. 用官方 client 复刻"位置目标→实际运动"的响应，测出低层跟踪带宽；
  2. 接近阶段：`a_t = a_{t-1} + β·(target−a_{t-1})`，`β` 随距离递减；
  3. 接触阶段：若 `r_t>τ` 或关节跟踪误差超阈，进入螺旋搜索（半径/步长由插入间隙先验给）；
  4. 搜索预算用尽 ⇒ 回退到"对准-再进"，不无限硬推；
  5. 只在插入/旋转类任务启用，其余保持原策略。
- **风险**：①低层控制器可能自带柔顺/插值，叠加后振荡 ⇒ 默认关闭，真机 A/B 再启用；②搜索可能把物体推离目标 ⇒ 限制搜索半径与次数；③短 chunk + 柔顺会增加延迟 ⇒ 与 E625 联合压测。

### IP-13 · DynSurrogate 动力学可行性预筛（P1）

- **动机**：真机时段极稀缺，不能每个想法都上真机。需要一层**便宜、保守**的离线筛选，只拒绝"动力学上明显不可行"的动作。
- **与现有方案的差异**：第 1 轮 IP-06 试图用代理评测预测**成功率**（难、易失真）；本轮只做**可行性过滤**（易、可证伪）：检查动作块的加速度/jerk 是否超执行器/摩擦预算、夹爪指令是否与自由空间模型一致、chunk 边界是否产生不可行的位置跳变。
- **技术可行性**：高。自由空间模型与加速度限幅都是解析的；可选一个 1–2 GPU·h 的小模型拟合残余。
- **所需资源**：1–2 GPU·h；CPU 推理。
- **落地步骤**：
  1. 从官方数据统计每任务/每相位的加速度、jerk 分布，定保守阈值；
  2. 对候选 chunk 计算 `max‖a‖`、`max jerk`、chunk 边界跳变；
  3. 只拒绝超过**硬上界**的动作（例如 >3× 数据 p99），不拒绝"看起来不优"的动作；
  4. 离线回放验证"0 次误拒可行动作"；
  5. 与 IP-14 共享同一套统计。
- **风险**：①代理模型在接触密集任务上失真 ⇒ 只做硬约束，不做成功率预测；②阈值过松则无筛选作用，过紧则误拒 ⇒ 用数据分布 + 预注册校准。

### IP-14 · DynAudit 动力学校验与可审计证书（P2）

- **动机**：官方明确会采集 per-step 延迟波动与动作统计规律性，并可能据此评估可信度。动力学校验天然产出"动作是否良构"的证据。
- **与现有方案的差异**：把"可信度"从被动合规变成**可导出的工程产物**：jerk/加速度直方图、自由空间一致性残差、chunk 边界跳变计数、降级次数。
- **技术可行性**：高（工程活）。
- **所需资源**：0 算力。
- **落地步骤**：埋点 → 导出报告 → 设置告警阈值 → 与 IP-10 的限幅联动。
- **风险**：过度限幅会压低成功率 ⇒ 限幅阈值由数据分布定，且默认只告警不强制。

## 4. 符号与定义（U13–U22）

| 符号 | 含义 |
|---|---|
| `q_t` | 夹爪实测开度（`observation.state.*_gripper`） |
| `a_t` | 夹爪指令开度（`action.*_gripper`） |
| `α, σ` | 自由空间一阶增益与残差标准差（每侧各一组） |
| `q̂_t` | 自由空间模型预测开度 |
| `r_t` | 接触残差 `q_t − q̂_t` |
| `C_t` | 接触事件指示（连续 k 帧 `r>τ_c`） |
| `k_f` | 指部等效刚度（N/单位开度，需标定） |
| `F̂_N` | 接触法向力代理 `k_f·r_t` |
| `S_t` | 滑移裕度 `μF̂_N − m‖a_ee−g‖` |
| `τ_c, k` | 接触阈值与持续帧数（默认 0.1、2） |
| `T_lo, T_hi` | 接触相位/搬运相位的 chunk 长度（1–2 / 8–16） |
| `c_i` | 第 i 个 IP 的成本向量（GPU·h、真机·h、人日） |
| `ρ_i` | ROI `ΔS_i/(w·c_i)` |
| `D` | 动力学可行域（加速度/jerk/边界跳变上界） |

**定义 U13（自由空间夹爪模型）** 对每一侧，自由空间下
`q_{t+1} = q_t + α(a_t − q_t) + ε_t`，`ε_t ~ (0, σ²)`，`q_t∈[0, Q_max]`；`α` 由无接触段最小二乘拟合：
`α = Σ(a_t−q_t)(q_{t+1}−q_t) / Σ(a_t−q_t)²`。

**定义 U14（接触残差）** `r_t = q_t − q̂_t`，`q̂_t` 由 U13 用同一 α 与过去 `(q,a)` 递推；自由空间下 `r_t≈ε_t`。

**定义 U15（接触事件）** `C_t = ∏_{j=0}^{k−1} 1[r_{t−j} > τ_c]`，默认 `k=2, τ_c=0.1`。

**定义 U16（力代理与滑移裕度）** `F̂_N = k_f·r_t`；`S_t = μF̂_N − m‖a_ee − g‖`；`S_t<0` 判滑移风险。`m, μ` 用尺寸/材质类别的保守界，不用于精确力控。

**定义 U17（反射门控）** 介入指示
`G_t = C_t ∧ (z_phase∈{grasp,lift,transport}) ∧ P_feasible ∧ (n_retry<3)`；
`G_t=1` 时用重抓原语替换当前 chunk 的前 `T_lo` 步，否则原样执行。

**定义 U18（相位自适应 chunk）** `T_a = T_lo` 若 `z_phase∈{grasp,align,insert}`，否则 `T_hi`；切换只在块边界，且满足最小驻留时间。

**定义 U19（成本与 ROI）** `c_i=(c^{gpu}_i,c^{robot}_i,c^{eng}_i)`，`ρ_i=ΔS_i/(w·c_i)`，`w` 由剩余预算归一化。

**定义 U20（预算化组合）** 给定预算 `B` 与依赖偏序 `≺`，选 `P⊆IPs` 最大化 `Σ_{i∈P}ΔS_i`，s.t. `Σ c_i≤B` 且 `P` 对 `≺` 封闭。

**定义 U21（代理筛选）** `Φ(a_{1:T}) = 1[max_t ‖a_t‖≤A_max ∧ max_t jerk_t≤J_max ∧ ‖a_1−a_T^{prev}‖≤Δ_max]`；只做硬约束过滤。

**定义 U22（审计证书）** `A = {p50/p99 延迟, jerk 直方图, 加速度直方图, 边界跳变计数, 降级次数, 自由空间残差分布}`。

```python
# ===== IP-09: FreeDynSense（0 训练，1 个标量/侧）=====
class FreeDynSense:
    def __init__(self, alpha=0.949, tau=0.10, k=2):
        self.alpha = alpha          # 离线拟合；可在线微调 ±10%
        self.tau, self.k = tau, k
        self.q_hat = {}             # 每端口/每侧一份
        self.hist = {}

    def reset(self, port):
        self.q_hat[port] = {}
        self.hist[port] = {}

    def step(self, port, side, q, a):
        key = (port, side)
        qh = self.q_hat[port].get(side)
        if qh is None:
            qh = q
        pred = qh + self.alpha * (a - qh)      # U13
        r = q - pred                            # U14
        self.q_hat[port][side] = pred
        h = self.hist[port].setdefault(side, [])
        h.append(r); h[:] = h[-self.k:]
        contact = len(h) == self.k and all(x > self.tau for x in h)   # U15
        return dict(r=r, contact=contact, force_proxy=self.k_f * r)

    def calibrate_free(self, port, side, q, a, lr=0.05):
        # 只在自由张开保持段调用；限制 ±10% 漂移（Q6）
        qh = self.q_hat[port].get(side, q)
        g = (a - qh)
        if abs(g) > 1e-6:
            self.alpha = float(min(1.0, max(0.5, self.alpha + lr * g * (q - qh) / (g*g + 1e-6))))
```

```python
# ===== IP-10: ReflexGate（高精度、低召回、有界重试）=====
GRASP_PHASES = {"grasp", "lift", "transport"}

def reflex_gate(obs, sess, fd, phase, feasible, retry_cap=3):
    r = {}
    for side in ("left", "right"):
        r[side] = fd.step(sess.port, side,
                          obs[f"observation.state.{side}_gripper"],
                          sess.last_action[f"{side}_gripper"])
    contact = r["left"]["contact"] or r["right"]["contact"]
    if not contact or phase not in GRASP_PHASES or not feasible:
        return None                                   # 不干预
    if sess.n_retry >= retry_cap:
        return ("give_up", None)                      # 保底，避免超时
    sess.n_retry += 1
    return ("regrasp", r)                             # 返回 1–2 步重抓原语
```

```python
# ===== 统一策略服务 v2（仍是单 checkpoint、单 API）=====
class UniBotSAGEv2Policy:
    def __init__(self, ckpt, alpha_left, alpha_right, k_f):

        phase = self.phase(obs)                       # 沿用第 1 轮 U3
        T_a = T_LO if phase in {"grasp", "align", "insert"} else T_HI   # U18

                    s.last_action.get(f"{side}_gripper", 0.0))

        # 2) 慢层：VLA 产生候选块
        a = self.model.act(obs, phase, T_a)

        # 3) 快层：接触门控（IP-10）
        gate = reflex_gate(obs, s, self.fd, phase, feasible=True)
        if gate and gate[0] == "regrasp":
            a = self.regrasp_primitive(obs, T_lo=2)    # 只替换前 2 步
        elif gate and gate[0] == "give_up":
            a = self.safe_park(obs, T_a)

        # 4) 动力学限幅/审计（IP-13/IP-14）
        a = self.dyn_guard(a, s.last_action, obs)
        s.last_action = a[-1]
        return self.pack(a, T_a, obs)
```

```python
# ===== IP-11: CostLedger（离线，每轮一次）=====
def allocate(ips, budget, weights, prereq):
    # 拓扑序后按 ROI 贪心；ΔS 用区间下界做保守排序
    order = topo_sort(ips, prereq)
    chosen, spent = [], 0.0
    for ip in sorted(order, key=lambda x: -x.roi(weights)):
        if spent + ip.cost(weights) <= budget:
            chosen.append(ip); spent += ip.cost(weights)
    return chosen, spent
```

## 6. 推导（引理 L8–L13）

**引理 L8（自由空间残差的可识别性与误报界）**
设自由空间满足 U13，且 `ε_t` 独立、`E[ε]=0`、`Var[ε]=σ²`。则自由空间下 `r_t=ε_t`。若物体在夹爪间形成宽度下界 `w`，且自由模型会把 `q̂_t` 驱向指令 `a_t`，则 `r_t ≥ w − q̂_t`。因此当 `w > a_t + τ_c` 时 `r_t > τ_c`，接触可被识别。自由空间误报率满足 `P(r>τ_c) ≤ σ²/τ_c²`（Chebyshev），取 `σ=0.026, τ_c=0.1` 得上界 6.5%；若 `ε` 近高斯，实测尾概率为 0.7%（本轮子集）。∎

> **注意**：L8 只保证"有东西挡着"，不保证"夹住了"。因此 `C_t` 是**接触**判据，不是**抓握成功**判据；抓握成功还需"物体随臂运动"的第二证据（Q7，需图像或 EE 运动一致性）。

**引理 L9（高精度介入不伤害基线）**
沿用第 1 轮 L3 的净收益式 `Net = r·ΔG − α_FP·ΔL − overhead`，其中 `r` 为真实未抓住的召回、`α_FP` 为误报率。本轮实测 `α_FP=0.007`，远低于第 1 轮要求的 0.02；因此只要 `r·ΔG > 0.007·ΔL`，介入净收益为正。以最保守 `ΔG=0.2ΔL`、`r=0.4` 计，`Net ≈ (0.08−0.007)ΔL > 0`。∎

**引理 L10（力代理给出加速度上界）**
若物体不滑移，需 `m‖a_ee−g‖ ≤ μF_N`。用 `F̂_N=k_f r_t` 且 `r_t≥τ_c` 得保守上界
`‖a_ee‖ ≤ μ k_f τ_c / m_max − g`。
该上界不依赖物体外观，只依赖可测残差与保守的 `m_max, μ_min`；因此可用于**限速**（IP-13）而无需精确力控。∎

**引理 L11（反层的控制延迟由 chunk 长度决定）**
`get_action` 每返回一个长度为 `T_a` 的块，评测端顺序执行完后才再次调用；因此反层的**有效反应周期**为 `T_a·Δt + ℓ_infer`，而不是信号延迟 `ℓ_sig`。本轮实测 `ℓ_sig≈2` 帧（67 ms）；若 `T_a=2, Δt=33 ms, ℓ_infer≈30 ms`，则控制延迟≈96 ms，能在一个抓握相位内闭环。若 `T_a=8`，则延迟≈294 ms，反层形同虚设。⇒ **反层必须与短 chunk 绑定**（U18），这是 IP-09 与 IP-03 的强耦合。∎

**引理 L12（ROI 贪心的适用边界）**
若成本可细分且 `ΔS_i` 可加，按 `ρ_i=ΔS_i/c_i` 降序的贪心是分数背包的最优解；若成本不可细分，贪心是 `1/2` 近似（在物品相对预算较小时接近最优）。因此 CostLedger 的排序**只应作为决策启发式**，并必须用区间下界 `ΔS_i^{lo}` 做保守排序；不得把贪心结果当作最优性证明。∎

**引理 L13（代理筛选的可靠性）**
若 `Φ` 只在动力学违反量 `v(a)>δ` 时拒绝，且所有真实可行动作满足 `v(a)≤δ_true`，则当 `δ≥δ_true` 时 `Φ` 不误拒任何可行动作（soundness）；当 `δ<δ_true` 时会误拒边界动作。因此 `δ` 必须由数据分布的上界（如 p99×3）设定，且 `Φ` 只作安全网、不作优化器。∎

### 8.4 这些结果支持什么、不支持什么

**支持**：
1. 夹爪响应在自由空间近似一阶，**一个标量 α** 就能解释 88% 的一步方差；
2. 自由空间残差≈0，而接触密集任务系统性为正，**组间分离显著**（p=1.6×10⁻⁴）；
3. 4σ 阈值给出 **0.993 精确率**，满足第 1 轮 L3 的"高精度、低召回"介入要求；
4. 信号延迟 2 帧，**在短 chunk（T_a=2）下可做到 ~100 ms 闭环**。

**不支持 / 不能声称**：
1. 这只是 **15/32 任务、前 3000 帧**的子集，且任务级"接触/搬运"标签是启发式的（例如 HangCup 残差很低，说明采样段可能尚未接触或杯子很轻）；
2. **无图像**，因此没有验证"滑移"的视觉残差，也没有区分"夹住物体"与"顶到桌面"；
3. 与 teaser 榜的 Spearman 不显著（p=0.13），且 teaser 本身是占位表 ⇒ **不得据此调参**；
4. 自由空间代理只用 ConveyorSorting，若该任务实际有物体，α 会被低估；需在更多任务/真机上复核（E619/E620）。

### 8.5 一个必须说清的反例

在 `exp/lowcost_dyn_probe7.py` 里，我们检查了"臂加速度 vs 夹爪残差"的逐任务相关：接触密集任务多为**负相关**（ZipUp −0.495、PlugInEthernet −0.256），并非"加速度越大残差越大"。这否定了"残差直接反映惯性滑移"的简单叙事，说明 **IP-10 的动量限速不能只靠残差-加速度相关来证明**；它必须作为保守的解析约束，在真机上单独 A/B（E626）。这是本轮主动记录的反例，避免把"看起来合理"当成"已验证"。

## 14. 本轮最大风险（一句话）

**整个方案依赖"夹爪 state−action 残差 ≈ 接触"这条通道，而它只在离线遥操子集上被验证；若评测端的低层控制器、夹爪标定或采样率与采集时不同，α 与阈值会整体漂移，最需要它的未见物体/新控制器场景恰是它最不可识别的地方——便宜不是风险，"便宜地错"才是。**
