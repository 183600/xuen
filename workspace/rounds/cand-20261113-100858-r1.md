# 第 66 轮（承接第 65 轮「VISTA 视觉知情故障归因闭环」IP-214~223；灵感循环第 1 轮；本轮灵感：「迭代验证」×「研究空白」）

> 第 65 轮把「几何可证伪」升级为「故障可归因」，其自述的最大风险仍然成立：**归因能力依赖「故障属于有限假设集 + 视觉/几何失效相互独立」；未知复合故障与共因失效会让 FIR 强行归入最近假设，系统反而因「已经归因」而更自信地执行。** 本轮不再追问「还有哪些故障」，而是退后一步问一个更根本的问题：**我们凭什么相信这套安全论证？它到底被验证过多少？** 第 65 轮的证书 J_vista 只覆盖「已命名故障 × 已采样状态」，它无法区分 **「验证过且成立」** 与 **「从未验证」**——后者才是真实部署中的主导风险，也是现有工作里尚未被度量的研究空白。本轮核心命题是：
>
> **把「验证」从一次性离线步骤升级为一等状态变量：用随时有效的统计过程维护一份「假设—证据台账」，用行为多样性度量「验证覆盖」，把未被覆盖的区域显式标为研究空白，并让机器人用有界风险预算迭代地填空白；任何不可逆承诺只能落在已验证支撑域内。**

## 0. 直觉与动机

**灵感 1（研究空白 → 真正的空白不是「未知故障清单的下一项」，而是「验证覆盖本身」）**
直觉：VISTA 扩充假设集会陷入军备竞赛：每遇到一种新故障就加一个 H，永远慢一步。研究者真正该找的 gap 是元层面的——**所有安全证书都只保证「在标定分布上、对已列出的扰动成立」，却从不报告「这些保证被多大范围、多多样地验证过」**，就像论文只报 p 值不报样本量与统计功效。把 coverage 变成显式状态后，「未知复合故障」不再需要被命名：它落在已验证支撑域之外时，系统直接判 `unvalidated` 并安全降级，而不是硬塞进最近假设。

**灵感 2（迭代验证 → 部署即一场持续的可证伪实验）**
直觉：迭代验证不是「多跑几次测试」，而是 Popper 式的**假设—实验—证伪—修订**循环：每条承重假设都是一个可证伪命题；每次操作都在无意中做实验；安全窗口（自由空间、搬运、待机、仿真、遥操作）是可用来做**机会性验证**的低风险实验时间。关键统计难点是：系统会**边看边停**（证据够了就停、看到异常就查），固定样本 conformal 的覆盖在 optional stopping 下失效；必须用 **e-process / anytime-valid 置信序列**，保证任意停时下误证伪率仍受控。这样「迭代」才不是统计幻觉。

**灵感 3（迭代验证 → 验证债：现在欠下的验证，未来连本带利地还）**
直觉：没验证就执行，本质是借了**验证债**。债可以借（否则无法部署），但必须有额度、有利率、有还款计划：额度=可接受的在未验证假设下执行的风险质量；利率=环境漂移/磨损让旧证据过期的速度；还款=机会性/主动验证。把「安全」从二值改为**债有界的资产负债表**，才能既不停机又不过度冒险。

**灵感 4（研究空白 → 验证剧场与验证者共谋：覆盖不等于多样性）**
直觉：跑一万次同一场景能把 count 刷满，却对分布外一无所知——这是**验证剧场**。覆盖必须按**行为多样性/有效样本量**度量（特征空间有效秩、对名义分布的 MMD、细胞熵），而不是原始次数。更隐蔽的是**验证者共谋**：视觉、力觉、仿真器可能共享同一个错误，导致「证据一致地确认了一个错误假设」。台账必须记录验证者来源与失效相关性，并允许 `validator_untrusted`。

**灵感 5（合流 → VIGIL：Validation-Integrated Gap-aware Iterative Loop，验证覆盖感知的迭代安全论证闭环）**
闭环：**VAL** 假设—证据台账 → **GAP** 研究空白图（覆盖不足/矛盾/漂移区）→ **SBC** 支撑域证书（域外一律 unvalidated）→ **IVP/VOC** 迭代验证策略（被动/机会/主动/延后，按覆盖价值与风险选实验）→ **CDR** 证伪—修订（e-process 触发，沿依赖图降级，不强行归因）→ **VDB** 验证债预算门控 → **DRIFT** 漂移重开空白 → **AIC-G** 对抗验证（验证剧场、验证者共谋、假验证）→ **J_vigil**。一句话：**VISTA 回答「这次是谁坏了」，VIGIL 回答「我们凭什么相信这套判断，以及还差多少验证」。**

**灵感 6（VISTA 组件的原位升级）**
- **FIR → FIR-L**：归因前先查台账；域外样本不允许定向归因，只能 `unvalidated` + 保守联合 + 验证探针。
- **CSC → VAP**：认证前缀同时要求每一步都在已验证支撑域内；否则先验证或缩短 k。
- **RSC-V → RSC-G**：新增 `r_val`（验证不确定半径），随 gap 质量膨胀、随覆盖收缩；域外时 r_val 主导。
- **WCV-V → WCV-G**：搜索域增 `𝒮_val`（已验证支撑）约束。
- **CSP-V → CSP-G**：规划图增「验证实验」节点，代价含验证债与 gap 价值。
- **AIC-V → AIC-G**：干扰集增「验证剧场/验证者共谋/假验证」。
- **J_vista → J_vigil**：证书增 coverage、gap_measure、validation_debt、ledger_version、assumption_ids、unvalidated_flag、validator_provenance。

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（VIGIL 闭环）**：VIGIL = (VISTA, VAL, GAP, SBC, IVP/VOC, CDR, VDB, DRIFT, AIC-G, J_vigil)。定位：VISTA 的「验证覆盖与迭代论证」升级。不变式：**台账更新、e-process、gap 计算、验证调度、证伪修订只在语义流；实时流只做支撑域查询、债门控、前缀执行与早停，零学习写操作。**
- **定义 234（承重假设与验证台账）**：承重假设 a=(id, 命题, 依赖集, 失效域, 验证器集, version)。台账 L={a↦(E_a, CS_a, R_a, prov_a)}，E_a 为 e-process，CS_a 为覆盖置信序列，R_a 为证据记录，prov_a 为验证者来源与相关性。证书 J 的承重集 A(J) 为推导 J 时用到的全部假设。
- **定义 235（验证覆盖与行为多样性）**：episode 特征 φ(x)∈ℝ^d，细胞划分 𝒞。假设 a 在集合 S 上的覆盖 C_a(S)=ESS_a(S)/|S|，ESS=(Σw)²/Σw² 为核/杠杆加权有效样本量；多样性折扣 C_a^div=C_a·exp(−MMD²(φ(S),φ_ref))。覆盖声明必须使用置信序列下界 `C̲_a`，并折扣验证者独立性 ρ_indep。
- **定义 236（研究空白图与相关空白）**：每个细胞 c 状态 ∈{covered, thin, contradicted, unvisited}；空白测度 G=Σ_{c≠covered} μ(c)，空白熵 H_gap。**动作相关空白** G_rel=μ(𝒳\𝒮_val ∩ Reach)，只有与可达/计划动作相交的空白才计入紧迫度。
- **定义 237（支撑域证书 SBC）**：对证书 J 与 episode x，SBC(J,x)=certified ⇔ x∈⋂_{a∈A(J)}𝒮_val(a) ∧ 所有 e-process 未越阈 ∧ 债≤B；否则 J 为 `unvalidated`。**这是「域内封闭世界」语义：域外不是「未知故障 #7」，而是「本证书拒绝发言」。**
- **定义 238（anytime-valid 验证统计）**：对假设 a 的原假设 H0「a 成立」构造 E_a(0)=1 且 E[E_a(t)|F_{t−1}]≤1 的 e-process，Ville 不等式给出 P[sup_t E_a(t)≥1/α]≤α；覆盖用置信序列满足 P[∀t:C_a(t)≥`C̲_a`(t)]≥1−α。自适应选实验合法，当且仅当赌注是 F_{t−1}-可料的（先选实验、后看结果）。
- **定义 239（假设依赖图与失效传播）**：DAG D=(A∪J,E)，a→J 若 a 承重，a→a′ 若 a′ 依赖 a。证伪 a 时，其全部后代证书置为 invalid 并排队重验；按依赖中心性排序，不把矛盾映射回最近假设。
- **定义 240（证伪—修订算子 CDR）**：当 E_a 越阈，置 status(a)=contradicted，失效后代证书，生成研究问题 q=(a, 观测违背, 候选判别实验)。VISTA 的已知假设可作为候选解释记录，但在通过支撑域验证前不得认证。
- **定义 241（迭代验证策略 IVP）**：模式={passive 自然操作记录, opportunistic 安全窗轻探针, active 不可逆承诺前主动验证, deferred 仿真/遥操作}；实验集={null_test, visual_probe, light_touch, replay, sim_rollout, teleop_demo}。在预测风险≤预算下选择 (模式, 实验, 目标细胞)。
- **定义 242（覆盖价值 VOC）**：VOC(a,c)=E[ΔD]+λ_g E[ΔG_rel]−λ_r·risk−λ_t·time−λ_w·wear；用一步前瞻近似。只有 VOC≥θ_voc 且预测力/形变在预算内才做主动验证。
- **定义 243（验证债 VDB）**：D_t=γD_{t−1}+Σ_{执行承诺中未验证的 a} w_a·risk(commitment)−repayment_t，γ≥1 为漂移「利息」。门控：D_t>B 时只允许零未验证暴露的动作；累计未验证风险 ≤B·L。
- **定义 244（漂移与空白重开 DRIFT）**：用验证残差的 e-process/CUSUM 监测非平稳；检出后使受影响细胞的覆盖下界失效、空白重开并重校准。度量：重开延迟、误重开率。
- **定义 245（验证感知前缀 VAP）**：k*=max{k≤min(H,m) : ∀s≤k, x_s∈𝒮_val ∧ 无 contradicted 承重假设 ∧ D≤B}；k*=0 时不执行块，转入验证/恢复。
- **定义 246（AIC-G 对抗验证）**：ℰ_G=ℰ_V×ℰ_val，ℰ_val 含验证剧场（窄分布重复）、验证者共谋（共享失效）、假验证（能通过但同源失效的对抗 episode）、覆盖投毒、漂移；验证者带来源图与相关性，覆盖按独立性折扣。
- **定义 247（J_vigil 证书）**：J_vigil=(J_vista, ledger_version, assumption_ids, coverage_lb, gap_measure, gap_entropy, validation_debt, unvalidated_flag, validator_provenance, drift_flag, aic_g_ver)。Valid ⇔ Valid(J_vista) ∧ SBC(J,x)=certified ∧ 无 contradicted 承重假设 ∧ D≤B ∧ 验证者可信或已折扣。
- **定义 248（VIGIL 闭环算子）**：语义流 [LSF→USR/MEL→VPG/VCV→阶段签名→FIR-L→SBC 查支撑→GAP 更新→CDR→VOC/IVP 调度→RSC-G→CSP-G→VAP→AIC-G→J_vigil]；实时流 [支撑域 O(1) 查询→债门控→前缀派发→早停→J_vigil 构建]。

## 2. 关键算法骨架

```python
# 每步执行前：支撑域 + 债联合门控（实时，O(1)）
def admit(x, cert, ledger, debt, B):
    if debt > B: return False, 'debt_exceeded'
    for a in cert.load_bearing:
        if a.status == 'contradicted': return False, 'assumption_contradicted'
        if not ledger.in_support(a, x): return False, 'unvalidated'
    return True, 'ok'

# 证伪—修订（语义流）：不映射到最近假设，而是失效后代证书
def on_evalue_cross(a, ledger, dag):
    a.status = 'contradicted'
    for j in dag.descendants(a):
        j.status = 'invalid'; enqueue_revalidation(j)
    return ResearchQuestion(a, a.violation_episode, propose_discriminating_experiments(a))

# 迭代验证调度（语义流）：覆盖价值 vs 风险预算
def choose_validation(gap_map, ledger, risk_budget):
    best = None
    for c in gap_map.action_relevant():
        for e in EXPERIMENTS:
            if predict_risk(e, c) > risk_budget: continue
            voc = expected_debt_reduction(e, c, ledger) \
                  + LAM_G * expected_gap_reduction(e, c) \
                  - LAM_R * predict_risk(e, c) - LAM_T * cost_time(e)
            if voc > THETA_VOC and (best is None or voc > best.voc):
                best = Candidate(e, c, voc)
    return best
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（域外不认证）**：若证书只在已验证支撑域内发言，则域外 episode 无论故障类型为何都输出 `unvalidated`，不需要把未知复合故障映射到有限假设；配合 e-process 与 Ville 不等式，任意停时下误证伪率 ≤α。代价是保守性，换掉的是「强行归因」这一单点故障。
- **引理 10（验证债安全）**：若每次未验证承诺的损失 ≤L 且债门控 D≤B，则累计未验证风险 ≤B·L；还款项使 D 以受控速率下降，漂移利率 γ 决定 B 的下界。
- **定理 9（VIGIL 端到端论证）**：在 A94–A99 下，已知故障在支撑域内仍由 VISTA 处理；未知/复合故障要么离开支撑域被标 `unvalidated` 并安全降级，要么在测量签名上与已验证行为不可分（此时风险低于测量分辨率，且不会被伪证为「已命名故障」）；不可逆承诺被限制在支撑域与债额度内。
- **定理 10（迭代覆盖收敛）**：平稳环境、正 visitation、诚实验证者下，覆盖下界 →1、动作相关空白 G_rel→0，速率由置信序列给出 O(√(log(1/δ)/n))；VOC 主动采样降低的是风险加权空白，非平稳时重开率由检测延迟界定。
- **命题（无法凭空辨识）**：任何证书都无法区分「在自身测量签名下行为等价」的故障；VIGIL 不承诺消除这一极限，而是把它变成显式、可审计、可预算的支撑域边界。

## 0. 研究空白与核心 IP 设计

**本轮所填的五个空白**：
1. **覆盖空白**：证书没有「被验证范围/多样性」的度量，无法区分「测过且成立」与「从未测过」。
2. **归因空白**：未知复合故障被迫映射到有限假设；缺少「拒绝发言」的合法状态。
3. **统计空白**：迭代验证必然伴随 optional stopping 与自适应选实验，固定样本 conformal 的覆盖保证失效。
4. **对抗空白**：验证剧场（窄分布刷次数）与验证者共谋（同一错误被多模态一致确认）会让覆盖虚高。
5. **经济学空白**：未验证执行没有成本记账，系统无法在「现在停机验证」与「先执行再还债」之间做理性权衡。

## 2. 形式化定义（完整版）

**定义 233（VIGIL 闭环）** VIGIL 是 VISTA 的「验证覆盖与迭代论证」升级：在 VISTA 的语义流/实时流骨架上挂载 VAL（假设台账）、GAP（空白图）、SBC（支撑域证书）、IVP/VOC（迭代验证策略）、CDR（证伪—修订）、VDB（验证债）、DRIFT（漂移重开）、AIC-G（对抗验证），并原位升级 FIR→FIR-L、CSC→VAP、RSC-V→RSC-G、WCV-V→WCV-G、CSP-V→CSP-G、J_vista→J_vigil。不变式：**台账更新、e-process、gap 计算、验证调度、证伪修订、证书构建只发生在语义流；实时路径只做支撑域查询、债门控、认证前缀执行与早停，零学习写操作。**

**定义 234（承重假设与验证台账）** 承重假设 `a=(id, 命题, deps, 失效域, 验证器集, ver)` 是证书推导中显式列出的可证伪命题。验证台账 `L={a↦(E_a, CS_a, R_a, prov_a)}`：`E_a` 为对抗原假设「a 成立」的 e-process；`CS_a` 为覆盖率的 anytime-valid 置信序列；`R_a={r_i}` 为证据记录 `r_i=(episode_id, cell, outcome, validator_id, ts, provenance_hash)`；`prov_a` 记录验证者身份与失效相关性估计。证书 J 的承重集 `A(J)` 为推导 J 用到的全部假设；**未列入 A(J) 的假设视为不成立，而不是默认成立。**

**定义 235（验证覆盖与行为多样性）** 设 episode 特征 `φ(x)∈ℝ^d`（任务、物体、接触模式、故障签名、环境），细胞划分 `𝒞`（网格/哈希/聚类）。假设 a 在证据集 S 上的覆盖
`C_a(S)=ESS_a(S)/|S|`，`ESS_a(S)=(Σ_i w_i)²/Σ_i w_i²`，
其中 `w_i` 为核权重或 D-最优杠杆。计数多但集中在窄区域时 ESS 不增长。多样性折扣
`C_a^div(S)=C_a(S)·exp(−MMD²(φ(S),φ_ref))·ρ_indep(prov_a)`，
`ρ_indep∈(0,1]` 随验证者共享失效相关性下降。覆盖声明必须使用置信序列下界 `C̲_a(t)=inf_{s≤t} CS_a(s)`，且满足 `C̲_a≥1−α_c` 才标 covered。

**定义 236（研究空白图与动作相关空白）** 每个细胞 `c` 的状态为 `covered / thin / contradicted / unvisited`。空白测度 `G=Σ_{c≠covered} μ(c)`；空白熵 `H_gap=−Σ_c p_c log p_c`，`p_c∝μ(c)·1[c≠covered]`。**动作相关空白** `G_rel=μ((𝒳∖𝒮_val)∩Reach)`：只有与可达或计划动作相交的空白才计入紧迫度；再远的研究空白可以延后，不能用它阻塞当前任务。

**定义 237（支撑域证书 SBC）** 对证书 J 与 episode x：
`SBC(J,x)=certified ⇔ x∈⋂_{a∈A(J)}𝒮_val(a) ∧ max_a E_a(t)<1/α_a ∧ D_t≤B ∧ 无 contradicted 承重假设`；
否则 `SBC(J,x)=unvalidated`。其中 `𝒮_val(a)={x: C̲_a(N(x))≥1−α_c ∧ a.status=valid}`，`N(x)` 为 x 所在细胞及其邻域。**语义是「域内封闭世界」：域外不是「未知故障 #7」，而是「本证书拒绝发言」。** SBC 不是要证明未知故障不存在，而是拒绝在无证据处作承诺。

**定义 238（anytime-valid 验证统计）** 对假设 a 的原假设 `H0:a 成立`，构造 `E_a(0)=1`、`E[E_a(t)|F_{t−1}]≤1` 的 e-process；由 Ville 不等式，任意停时 `τ` 下 `P_{H0}[sup_t E_a(t)≥1/α_a]≤α_a`。覆盖率用置信序列满足 `P[∀t:C_a(t)≥C̲_a(t)]≥1−α_c`。**自适应选实验合法当且仅当赌注是 F_{t−1}-可料的**：先依据历史选实验与赌注，再看当前结果；这让 IVP 可以在不破坏有效性前提下边看边选。固定样本 split-conformal 只在预先固定的检验点有效，是本轮明确替换的对象。

**定义 239（假设依赖图与失效传播）** 依赖 DAG `D=(A∪J,E)`：`a→J` 若 a 承重，`a→a′` 若 a′ 依赖 a。证伪 a 时，`desc(a)` 内全部证书置 `invalid` 并排队重验；优先级按 `centrality(a)=|desc(a)|/|A∪J|` 与风险权重排序。失效传播深度默认无界，但可用 `δ_prop` 截断并显式计入风险预算。

**定义 240（证伪—修订算子 CDR）** 当 `E_a` 越阈或覆盖下界塌陷，置 `status(a)=contradicted`，失效后代证书，生成研究问题 `q=(a, 违背观测, 候选判别实验)`。VISTA 的已知假设可作为**候选解释**记录到 `q`，但在通过支撑域验证前不得认证。**CDR 的第一原则是「不硬猜」：宁可标 unvalidated，也不把矛盾映射到最近假设。**

**定义 241（迭代验证策略 IVP）** 模式 `M={passive, opportunistic, active, deferred}`；实验集 `A_val={null_test, visual_probe, light_touch, replay, sim_rollout, teleop_demo}`。passive 始终开启（自然操作即证据）；opportunistic 在 `f_n≈0`、待机、搬运等安全窗执行轻探针；active 在不可逆承诺前且前缀与空白相交时执行；deferred 在仿真或遥操作中验证。选择 `(m,e,c)` 在预测风险≤`R_val`、预测形变≤`ε_strain` 下最大化 VOC。

**定义 242（覆盖价值 VOC）** 
`VOC(a,c)=E[ΔD(a,c)]+λ_g·E[ΔG_rel(c)]−λ_r·risk(e,c)−λ_t·time(e)−λ_w·wear(e)`。
第一项是未来验证债的期望下降，第二项是动作相关空白的下降；用一步前瞻或高斯过程后验近似。只有 `VOC≥θ_voc` 才做主动验证，避免「为验证而验证」把任务拖死。

**定义 243（验证债 VDB）** `D_t=γD_{t−1}+Σ_{s≤t} risk(s)·1[s 在未验证承重假设下执行]−repayment_t`，`γ≥1` 为漂移/磨损导致的「利息」。门控：`D_t>B` 时只允许零未验证暴露的动作（支撑域内且无 contradicted 假设）。若每次未验证承诺损失 ≤L，则累计未验证风险 ≤B·L+o(1)。还款由 passive/opportunistic/active 验证共同完成。

**定义 244（漂移与空白重开 DRIFT）** 对验证残差流维护 e-process/CUSUM；检出漂移后，使受影响细胞的覆盖下界失效、状态退回 thin/unvisited、空白重开，并触发重校准与重验。度量重开延迟 `τ_d` 与误重开率。非平稳下 `γ` 增大，等价于债务利息上升、B 的有效额度下降。

**定义 245（验证感知前缀 VAP）** 
`k*(A_t)=max{k≤min(H,m) : ∀s≤k, x_s∈⋂_{a∈A(J)}𝒮_val(a) ∧ D_s≤B ∧ 无 contradicted 承重假设}`。
执行 k* 步后强制重接地、重验证、重归因；若 `k*=0`，不执行块，转入验证实验或 VISTA 的安全恢复阶梯。

**定义 246（AIC-G 对抗验证）** `ℰ_G=ℰ_V×ℰ_val`，`ℰ_val` 含：验证剧场（同一窄区域重复，掩盖分布外）、验证者共谋（视觉/力觉/仿真共享失效，一致地确认错误假设）、假验证（对抗 episode 故意通过验证但携带同源失效）、覆盖投毒（注入误导性证据）、漂移。验证者带来源图与相关性矩阵，覆盖按 `ρ_indep` 折扣；`n_cert=192`，其中 64 用于验证剧场/共谋/假验证最坏。**对抗下不要求验证正确，只要求不产生假证书、能标 `validator_untrusted` 并安全降级。**

**定义 247（J_vigil 证书）** 
`J_vigil=(J_vista, ledger_version, assumption_ids, coverage_lb, gap_measure, gap_entropy, validation_debt, unvalidated_flag, validator_provenance, drift_flag, aic_g_ver)`。
`Valid(J_vigil) ⇔ Valid(J_vista) ∧ SBC(J,x)=certified ∧ (∀a∈A(J): a.status≠contradicted) ∧ D_t≤B ∧ (prov 可信 ∨ 覆盖已按 ρ_indep 折扣) ∧ aic_g_ver 为当前版本`。审计链新增：**凭什么相信这个证书（ledger/coverage）、还差多少验证（gap/debt）、验证者是谁（provenance）、有没有旧证据过期（drift）。**

**定义 248（VIGIL 闭环算子）** 语义流：`[LSF→USR/MEL→VPG/VCV→阶段签名→FIR-L→SBC 查支撑→GAP 更新→CDR→VOC/IVP 调度→RSC-G→CSP-G→VAP→AIC-G→J_vigil]`；实时流：`[支撑域 O(1) 查询→债门控→WCV-G 编译→前缀派发→早停→J_vigil 构建]`。

### IP-224/225 VAL + GAP（台账与空白图）

```python
class ValidationLedger:
    def __init__(self, alpha, gamma=1.0):
        self.rec = {}          # id -> evidence records
        self.eproc = {}        # id -> e-process state
        self.cs = {}           # id -> coverage confidence sequence
        self.status = {}       # id -> valid | thin | contradicted
        self.alpha, self.gamma = alpha, gamma

    def update(self, a, episode, outcome, validator):
        r = Evidence(episode.cell, outcome, validator.id, episode.provenance)
        self.rec[a].append(r)
        self.eproc[a] = ville_update(self.eproc[a], outcome, validator.bet)
        self.cs[a] = cs_update(self.cs[a], r)
        if self.eproc[a] >= 1 / self.alpha:
            self.status[a] = 'contradicted'
        elif self.cs[a].lower < 1 - self.alpha:
            self.status[a] = 'thin'

    def in_support(self, a, x):
        c = cell_of(x)
        return (self.status[a] == 'valid'
                and self.cs[a].lower_at(c) >= 1 - self.alpha
                and ess(self.rec[a], c) >= K_MIN)

class GapMap:
    def status(self, c):
        if self.covered(c): return 'covered'
        if self.contradicted(c): return 'contradicted'
        if self.thin(c): return 'thin'
        return 'unvisited'

    def action_relevant_gap(self, reachable):
        return measure([c for c in reachable if self.status(c) != 'covered'])

    def entropy(self):
        p = normalize([mu(c) for c in self.cells if self.status(c) != 'covered'])
        return -sum(pi * log(pi + 1e-12) for pi in p)
```

### IP-226 SBC（支撑域证书）

```python
def sbc_certify(J, x, ledger, debt, B):
    if debt > B:
        return False, 'debt_exceeded'
    for a in J.load_bearing:
        if ledger.status[a] == 'contradicted':
            return False, 'assumption_contradicted'
        if not ledger.in_support(a, x):
            return False, 'unvalidated'        # 不映射到任何已知故障
        if ledger.eproc[a] >= 1 / ledger.alpha:
            return False, 'falsified'
    return True, 'certified'
```

### IP-229 CDR（证伪—修订）

```python
def contradiction_revision(a, ledger, dag, risk_weights):
    ledger.status[a] = 'contradicted'
    affected = dag.descendants(a)
    for j in affected:
        j.status = 'invalid'
        enqueue_revalidation(j, priority=centrality(a) * risk_weights[j])
    q = ResearchQuestion(
        assumption=a,
        violation=ledger.rec[a][-1].outcome,
        experiments=propose_discriminating_experiments(a, ledger),
    )
    return q, affected          # 不返回 argmax_H P(H|rho)
```

### IP-227/228 IVP + VOC（迭代验证调度）

```python
def choose_validation(gap_map, ledger, reachable, risk_budget):
    best = None
    for c in reachable:
        if gap_map.status(c) == 'covered':
            continue
        for e in ('null_test', 'visual_probe', 'light_touch',
                  'replay', 'sim_rollout', 'teleop_demo'):
            risk = predict_risk(e, c)
            if risk > risk_budget:
                continue
            voc = (expected_debt_reduction(e, c, ledger)
                   + LAM_G * expected_gap_reduction(e, c)
                   - LAM_R * risk
                   - LAM_T * time_cost(e)
                   - LAM_W * wear_cost(e))
            if voc >= THETA_VOC and (best is None or voc > best.voc):
                best = Candidate(e, c, voc)
    return best
```

### IP-230 VDB + IP-245 VAP（债门控与验证感知前缀）

```python
def debt_update(D, commitment, ledger, gamma, repayment):
    exposed = any(ledger.status[a] != 'valid'
                  for a in commitment.load_bearing) or not in_support(commitment)
    new = gamma * D + (commitment.risk if exposed else 0.0) - repayment
    return max(0.0, new)

def certified_prefix_vigil(A, post, m, ledger, debt, B):
    k_best = 0
    for k in range(1, min(len(A), m) + 1):
        if debt > B:
            break
        x = predict_state(A[:k])
        if not all(ledger.sbc_ok(a, x) for a in A[k].load_bearing):
            break
        k_best = k
    return k_best            # k*=0 -> 不执行，转验证/恢复
```

### IP-233 VIGIL 闭环算子（整合）

```python
def VIGIL_round(M, obs, delta_f_req):
    V, T, P, L, P_cloud, W_meas, tactile, img, depth, flow = obs
    # ———— 语义流 ————
    M.lsf.update_geometry(P_cloud)
    x_prime = M.lsf.fuse(M.usr.fuse(V, T, P, L))
    y_vis = M.f_vis(img, depth, flow)
    phi_hat, *_ = M.mel.infer_by_mode(M.ocb_skill.choose().mel_mode, V, T, P, L, x_prime)

    # 1) 阶段签名 + VISTA 归因（仅在支撑域内信任）
    A = M.ach.propose(x_prime, H=M.H)
    visual = M.vpg.verify_and_predict(y_vis, A, M.mws.last_contacts)
    post, h_star, ambiguous = M.fir_l.attribute(M.stage.split(M.residual_log, visual))

    # 2) 台账与空白：先查支撑，再决定是否允许定向归因
    ok, why = sbc_certify(M.j_pending, x_prime, M.val, M.debt, M.B)
    if not ok:
        h_star, ambiguous = 'unvalidated', True     # 域外不归因
        M.balls['r_val'] = inflate(M.balls['r_val'], why)
    else:
        M.balls, M.w_vis, M.H = M.fir_l.directed_demote(h_star, M.balls, M.w_vis, M.H)

    # 3) 证伪/漂移检查 → 失效传播
    for a in M.val.contradicted():
        q, affected = contradiction_revision(a, M.val, M.dag, M.risk_weights)
        M.gap.invalidate(affected); M.val_schedule.push(q)

    # 4) 迭代验证调度（在规划前，优先填与计划动作相交的空白）
    reach = M.csp_g.reachable(x_prime, phi_hat, M.balls)
    M.gap.update(M.val.rec)
    cand = choose_validation(M.gap, M.val, reach, M.risk_budget)
    if cand is not None and cand.mode in ('opportunistic', 'active'):
        M.execute_validation(cand)                  # 低风险实验，实时预算内
        M.debt -= cand.expected_repayment

    # 5) 规划 + 验证感知前缀
    goal = M.dms.parse_goal((M.usr.U_ep, M.usr.U_al))
    tau = M.csp_g.plan_chunks(goal, x_prime, phi_hat, M.balls, post, M.gap)
    k_star = certified_prefix_vigil(tau.A, post, M.m,
                                    M.val, M.debt, M.B)

    # 6) 执行（k*=0 则只做验证/恢复）
    K_safe, EV_exec, cert_exec = realtime_step_vigil(
        M, delta_f_req, tau, k_star, x_prime, visual)

    # 7) 在线更新（纯语义流）：台账、空白、债务、漂移
    M.val.update_all(M.residual_log, visual, M.validator_prov)
    M.gap.recompute()
    M.debt = debt_update(M.debt, EV_exec.commitment, M.val, M.gamma, repayment=cert_exec.repay)
    M.drift.update(M.val.residual_stream)
    rho_dir = M.aic_g.certify(tau, x_prime, phi_hat, M.balls, post, M.val, M.gap)
    return M, K_safe, EV_exec, build_j_vigil(
        cert_exec, J_vista=M.j_vista, ledger_version=M.val.version,
        assumption_ids=M.j_pending.load_bearing,
        coverage_lb=M.val.min_lower_bound(M.j_pending.load_bearing),
        gap_measure=M.gap.action_relevant_gap(reach),
        gap_entropy=M.gap.entropy(), validation_debt=M.debt,
        unvalidated_flag=(why == 'unvalidated'),
        validator_provenance=M.validator_prov, drift_flag=M.drift.flag,
        aic_g_ver=AIC_G_VERSION)
```

## 4. 推导

**假设 A94–A99**：
- **A94（承重集完备性）**：证书构建时列出的 A(J) 覆盖其推导所依赖的全部假设；未列入者视为不成立。
- **A95（验证者可观测与相关性可估）**：每条承重假设至少有一个可观测验证器；验证者失效相关性可估，独立性不足时按 `ρ_indep` 折扣。
- **A96（测量签名充分性）**：若故障改变任务相关行为，则它在 φ(x) 或安全签名上留下可测差异；否则视为在测量分辨率内等价——这是不可消除的极限，显式声明而非隐藏。
- **A97（e-process 条件有效性）**：自适应选实验下赌注 F_{t−1}-可料，`E[E_t|F_{t−1}]≤1`。
- **A98（分段平稳/漂移可检）**：环境分段平稳，漂移可在有限延迟 τ_d 内被 DRIFT 检出。
- **A99（债损失有界）**：每次未验证承诺的损失 ≤L，债门控可实时执行。

**引理 9（域外不认证与 anytime-valid 证伪）** 由 SBC 定义，域外 episode 直接输出 `unvalidated`，与故障类型无关，故不存在「未知复合故障被强行映射到有限假设」的误认证路径。由 Ville 不等式，对任意停时 τ 与自适应实验序列（A97），`P_{H0}[∃t≤τ:E_a(t)≥1/α_a]≤α_a`，即任意「边看边停」下误证伪率受控；覆盖声明同理由置信序列统一覆盖所有 t。∎

**引理 10（验证债安全）** 设债按定义 243 更新且始终门控 D≤B。每次在未验证假设下的承诺损失 ≤L，故累计未验证损失 `≤Σ risk(s)·1[未验证] ≤ B·L + (γ−1)ΣD_s`；当 γ=1 或漂移可检（A98）且 B 按 γ 调整时，上界为 B·L+o(1)。还款项只减小 D，不影响上界。∎

**定理 9（VIGIL 端到端论证）** 在 A94–A99 下：
1. **域内继承 VISTA**：`SBC=certified` 时，VISTA 的归因与安全保证（定理 7）在已验证支撑域内成立。
2. **域外不硬猜**：未知/复合故障若改变任务相关行为（A96），则或早于不可逆点在 φ/安全签名上离开 `𝒮_val`，被 SBC 标 `unvalidated` 并转保守源/验证；若始终留在 `𝒮_val`，则它与已验证行为在测量签名上不可分，风险低于测量分辨率，且不会被伪证为「已命名故障」。
3. **证伪正确传播**：CDR 只失效后代证书、不返回最近假设；由 DAG 与 A94，后代集合覆盖所有依赖该假设的承诺。
4. **不可逆承诺受双重约束**：VAP 要求每步在支撑域内且债≤B，故块级承诺不引入超出「支撑域 + 债额度」的新风险。
5. **失败可审计**：J_vigil 显式记录 coverage/gap/debt/provenance/drift，失败时可回答「是没验证、验证过期、还是验证者共谋」。∎

**定理 10（迭代覆盖收敛）** 设环境平稳（A98 的无漂移情形）、每个可达细胞在策略下有正 visitation 概率、验证者诚实（A95 且 ρ_indep 已知）。对细胞 c，覆盖是 [0,1] 有界随机变量，置信序列宽度 `O(√(log(1/δ)/n_c))`；当假设成立时真实通过率→1，故 `C̲_a(c)→1`、`c` 变 covered。于是 `G_rel→0`，且达到 `G_rel≤ε` 的样本复杂度为 `O((1/ε²)log(1/δ))`（每细胞，乘以活跃细胞数）。VOC 主动采样只改变采样分布、不改变一致性；它加速的是风险加权空白 `Σ w_c·gap_c` 的下降。漂移时（A98），空白以 `O(τ_d)` 的延迟重开，重开质量受 τ_d 与 γ 约束。∎

**命题（无法凭空辨识）** 对任意证书，若两个故障在本系统的全部测量签名上不可分，则不存在只依赖这些签名的检验能以非平凡功效区分它们。VIGIL 不承诺消除这一极限；它把极限显式化为 `𝒮_val` 的边界与 `unvalidated` 状态，使系统在边界外拒绝发言，而不是用一个自信的 argmax 掩盖它。∎

**命题（验证剧场会被 ESS/MMD 惩罚）** 若 n 个验证 episode 集中在特征空间测度 μ_s 的窄区域，而名义参考测度为 μ_ref，则多样性折扣满足 `C^div ≤ (μ_s/μ_ref)·exp(−MMD²)` 量级；原始计数 n 无法把该细胞抬成 covered。故「刷次数」不能替代「覆盖多样性」，除非同时扩大行为支撑。∎

## 7. 已知风险

**一句话**：VIGIL 的「已验证支撑域」由同一套可能出错的感觉、仿真与标定来度量；共享失效会把「未验证」误记为「已验证」，而系统又用自己的验证器去验证验证器，存在元回归——**它最大的风险不是漏掉未知故障，而是把自己的盲区认证成安全区，并用「覆盖率高」为继续执行背书。**

**次级风险与缓解**：
1. **元验证回归**：台账/验证器本身的安全性由谁验证？缓解：验证器分层（至少一层独立的物理/人工程序）、验证者来源图、对台账本身做离线审计与签名；`validator_untrusted` 是一等状态。
2. **验证者共谋**：视觉/力觉/仿真共享失效。缓解：AIC-G 显式建共因模型，覆盖按 `ρ_indep` 折扣；共谋下不要求正确归因，只要求不产生假证书并安全降级。
3. **验证剧场/覆盖投毒**：窄分布刷次数或注入误导证据。缓解：ESS + MMD + 细胞熵而非原始计数；证据带来源与时间，投毒经 CDR/DRIFT 回溯降权。
4. **保守性代价**：域外拒答会降低任务成功率、增加停机。缓解：opportunistic 验证利用安全窗；VOC 只填动作相关空白；债额度允许有界冒险；`k*=0` 时才停机。
5. **支撑域判定的分布外误判**：特征 φ 选得不好会把真域内判成域外。缓解：φ 含任务/接触/故障签名，离线校准误拒率；域边界用 conformal 管。
6. **统计有效性依赖 A97**：自适应赌注若用了当前结果就破坏 anytime-valid。缓解：代码级强制「先选实验后看结果」；赌注序列可审计。
7. **漂移利息与债额度**：非平稳使旧证据快速过期，B 需要随 γ 调整，否则要么过度保守要么债失控。缓解：DRIFT 触发重校准；γ 在线估计；额度按风险预算分段调整。
8. **实时预算**：SBC/VAP/债门控叠加逼近 2.7ms。缓解：支撑域用哈希/区间树，台账与 AIC-G 全部留在语义流，实时只做 O(1) 门控。
9. **承重集完备性（A94）本身是假设**：漏列一条假设会让证书虚假成立。缓解：证书模板强制列出假设；离线审计与变异测试；把「A94 是否成立」也作为可验证假设。
