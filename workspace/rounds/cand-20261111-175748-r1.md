# 第 56 轮（承接第 55 轮想法区「语义-接触接地」与第 54 轮产物 v31；灵感循环新第 1 轮；本轮灵感：「大语言模型」×「末端位姿」）

> 第 55 轮把部署安全性推进到“语义-接触证书”。本轮把视角从“接触是否可信”上移到“语言如何变成末端位姿、位姿又如何落回接触与全身生存核”。核心矛盾：**H24**：大语言模型擅长关系、次序与意图，不擅长米、弧度与坐标系，它输出的“精确位姿”往往只是语言流畅性的延伸；**H25**：末端位姿是 `SE(3)` 的连续量，存在坐标系、参数化与符号的多重表示，同一物理位姿可写成无穷多串数字，语言模型的错误常表现为“表示别名 / 坐标系串味”而非显式数值错误，因此“再看一眼数字”根本无法审计位姿。

## 0. 直觉与动机

**灵感 1（大语言模型 → 位姿约束编译器，而非坐标生成器）**
直觉：让 LLM 直接吐 `(x,y,z,qx,qy,qz,qw)` 等于让它做它最不擅长的事。它真正可靠的是“从上方接近”“把手朝左”“先退再进”“贴住杯壁”这类**关系型意图**。于是把 LLM 的输出空间限制为一个带类型的 **位姿约束程序**：原子是 `align / rel / clear / region / contact`，数字只允许以区间或“工具查询结果”出现。**语言负责结构，几何负责度量**。

**灵感 2（末端位姿 → 表示商空间与 frame-cocycle）**
直觉：位姿不是一串数，而是 `SE(3)` 的一个点；四元数 `±q`、欧拉角回绕、旋转矩阵列序、对偶四元数只是同一物理位姿的不同标签。LLM 极易把“同一位姿的两种表示”当成两个不同位姿，或把 `world/body/EE/object` 四个坐标系混为一谈。因此验证器必须 **对表示不变、对坐标系敏感**：表示别名靠规范形与多编码一致性抓，坐标系混淆靠 frame 图上闭环残差抓。

**灵感 3（语言位姿 → 接触选择器）**
直觉：“从上方抓”与“从侧面抓”不是两个数字，而是两个**接触帧**，分别选择不同的语义接触集 `C(Σ)` 与摩擦锥。第 55 轮的语义-接触图 `κ` 与生存核 `K(Σ)` 正好可以把位姿从“几何点”升级为“可执行的接触承诺”：位姿合法 ⇔ 它选中的接触在语义上可信、且整机在生存核内可达。

**灵感 4（不可行 → 最小不可满足核驱动接地修复）**
直觉：当 LLM 给的约束集为空或触犯生存核时，最糟的做法是“把整段话重写一遍”，那会引入新的幻觉。正确做法是从 `SE(3)` 求解器返回 **最小不可满足核 MUS** 与一个反例位姿，只让 LLM 修那几个原子；修复被限制在核内，既不越权，也可证终止。

**灵感 5（云边 → 语言在云、位姿证书在边）**
直觉：云端大模型适合做全局语言理解与约束生成，边端拥有真实标定、碰撞几何与力反馈。两者以 **位姿契约接口** 对接：云端给约束程序与溯源，边端做 frame 解析、可达/碰撞/生存核校验并签发证书；边端回传 MUS 与反例位姿，云端只做增量重写。这把第 55 轮的语义-动作联合重剖分再推进为 **语言-位姿-接触联合重剖分**。

## 1. 形式化定义（增量：定义 127–132）

**定义 127（位姿约束程序 PCP）**
设坐标系集合 `ℱ = {W,B,E,O,C,…}`（世界/基座/末端/物体/相机），位姿空间 `𝒫 = SE(3)`。位姿原子
`a = (τ, X, θ, s)`，其中类型 `τ ∈ {frame, align, rel, clear, contact, region, soft}`，`X⊆𝒫∪ℱ`，`θ` 为参数，`s⊆instruction` 为溯源片段。原子语义：
- `frame(p,F)`：`p^W = T_{WF} ⊙ p^F`；
- `align(e,n,α)`：`∠(R_e e, n) ≤ α`（末端轴 `e` 对齐目标方向 `n`）；
- `rel(p_i,p_j,Δ)`：`p_i^{-1} ⊙ p_j ∈ N_Δ`（相对位姿邻域）；
- `clear(p,O,d)`：`dist(EE(p), O) ≥ d`；
- `contact(p,c)`：`κ(Σ̄(contact-frame(p)), c) ≥ θ_κ`；
- `region(p,R)`：`p ∈ R`（位置与朝向的可行域）。
**位姿约束程序** `P = (A_h, A_s, s)`，`A_h` 为硬原子合取，`A_s` 为软偏好，可行集
`Π(P) = {p ∈ 𝒫^k : ∀a∈A_h, p ⊨ a}`。

**定义 128（语言-位姿接地与接地误差）**
参考意图语义 `Φ(x,S)` 由可执行任务谓词给出（如“杯口朝上且把手朝左、位于层板前半区”）。接地映射 `G:(x,S) ↦ P`。在受限工作空间 `B` 上定义接地误差
`ε_G = d_H(Π(P)∩B, Π(Φ)∩B)`（Hausdorff 距离，空集记 `∞`）。
若 `Π(P) ⊆ Π(Φ)` 称接地 **sound**（只收紧不越界），若 `Π(P) ⊇ Π(Φ)` 称 **complete**；`ε_G ≤ θ_G` 称 **grounded**。

**定义 129（位姿表示商与规范形）**
`p ~ p'` 当且仅当二者表示同一刚体变换。规范映射 `can: 𝒫 → 𝒫/~`：四元数取 `w≥0`、旋转矩阵正交化并固定列序、对偶四元数单位化。对验证器 `V` 的带符号裕度 `m`，定义表示残差
`ρ_rep(P,p) = max_{enc∈Enc} m_enc(P,p) − min_{enc∈Enc} m_enc(P,p)`。
`ρ_rep = 0` 称 **表示不变**；`V` 在换坐标系 `p ↦ T⊙p` 时显式计入 `T`，称 **坐标系敏感**。

**定义 130（位姿幻觉三项残差）**
给定 LLM 的数值提示 `p̂`（若有）与多次采样的 `p̂_1,p̂_2`：
- 度量漂移 `δ_p = min_{p∈Π(P)} d_{SE(3)}(p̂,p)`；
- 自一致漂移 `δ_c = d_{SE(3)}(p̂_1,p̂_2)`；
- frame 闭环残差 `ρ_F = max_{cycle γ in 𝒢_ℱ} ‖log(∏_{(i,j)∈γ} T_{ij})‖`。
若 `δ_p > Θ_p ∨ δ_c > Θ_c ∨ ρ_F > Θ_F`，判为 **位姿幻觉**。其中表示别名主要由 `δ_c / ρ_rep` 暴露，坐标系混淆主要由 `ρ_F` 暴露——两类错误源正交，必须分别设门。

**定义 131（生存核耦合位姿集）**
沿用第 55 轮 `C⁺(Σ)`、`K(Σ)`。末端位姿 `p` 的接触选择 `C(p) = {(contact-frame(p), c) : κ(Σ̄,c) ≥ θ_κ}`。
`Π_K(P,Σ) = {p∈Π(P) | ∃ x_0,u_{0:T},λ : EE(x_T)=p ∧ supp(λ)⊆C⁺(Σ) ∧ x_t∈K(Σ), ∀t}`。
即：位姿必须**语义接触可信、整机生存核可达**，而非仅几何无碰撞。

**定义 132（语言-位姿证书）**
`J_p = (P_core, p_wit, μ_Π, δ_p, ρ_F, ρ_rep, ρ_sem, prov, evid)`：
- `P_core ⊆ A_h` 证书所依赖的硬约束核；
- `p_wit ∈ Π_K(P_core,Σ)` 已校验的见证位姿；
- `μ_Π = min_{a∈P_core} margin_a(p_wit)` 含原子边界裕度、避障间隙与生存核裕度；
- `δ_p, ρ_F, ρ_rep` 如上，`ρ_sem` 为第 55 轮语义鲁棒谱在 `C(p_wit)` 上的取值；
- `prov` 为原子到指令片段的溯源映射，`cov(prov)=1` 且无孤儿原子；
- `evid` 含 frame 闭环、碰撞、可达、接触与 MUS 历史。
当 `p_wit` 存在、`μ_Π≥θ_μ`、`δ_p≤Θ_p`、`ρ_F≤Θ_F`、`ρ_rep≤Θ_rep`、`ρ_sem≥ρ_min` 且 `cov(prov)=1` 时，语言-位姿可部署。

def compile_pose_program(instruction, scene, llm):
    schema = PoseDSL.schema(
        frames=scene.frames,          # frame 名必须来自场景本体，禁止自造
        kinds=ATOM_KINDS,

    )

        instruction,
        tools=[scene.frame_lookup, scene.object_pose, scene.affordance_lookup],
        response_schema=schema,       # 约束解码，保证结构合法

    return PoseProgram(
        hard=[a for a in atoms if a.kind != 'soft'],
        soft=[a for a in atoms if a.kind == 'soft'],
        prov=link_provenance(raw, instruction),
    )

### IP-128 FCR（Frame Consistency Resolver）

```python
def resolve_frame_consistency(program, scene):
    G = build_frame_graph(scene, program)          # W/B/E/O/C 为节点，T_ij 为边
    worst, culprit = 0.0, None
    for cyc in find_cycles(G):
        r = norm(log_SE3(compose_cycle(cyc)))     # 物理上应为 0
        if r > worst:
            worst, culprit = r, cyc
    if worst > theta_F:
        return ('reject', 'frame_cocycle', worst, culprit)
    return ('ok', collapse_to_world(program, G), worst)
```

### IP-129 RIV（Representation Invariance Verifier）

```python
def representation_invariance(program, poses):
    out = {}
    for p in poses:
        m = [signed_margin(program, enc(p))
             for enc in (quat, euler, rotmat, dualquat)]
        out[p] = max(m) - min(m)                   # 同一物理位姿的裕度应一致
    return out                                     # 全部 <= theta_rep 才算表示不变
```

### IP-130 VCP（Viability-Coupled Pose Projection）

```python
def viability_coupled_poses(program, Sigma, K, x0):
    feasible = []
    for p in branch_and_bound_SE3(program):        # 区间给出 inner / outer
        for c_star in contact_selectors(p, Sigma, kappa):   # 上抓/侧抓/推压…
            if c_star not in C_plus(Sigma):
                continue
            ok, x_traj, mu_k = reach_within_kernel(K, x0, p, c_star)
            if ok:
                feasible.append((p, c_star, mu_k))
                break
    return PoseSet(inner=inner_hull(feasible),
                   outer=outer_hull(feasible, eps))
```

### IP-131 MUR（Minimal Unsatisfiable-core Repair）

```python
def minimal_core_repair(program, Sigma, K, llm, max_rounds):
    for r in range(max_rounds):
        Pi = viability_coupled_poses(program, Sigma, K)
        if Pi.nonempty():
            return ('ok', program, Pi, r)
        mus = quickxplain(program.hard,
                          test=lambda S: viability_coupled_poses(
                              restrict(program, S), Sigma, K).nonempty())
        p_bad = closest_pose_outside(Pi.outer)
        program = llm.repair(
            spans=[a.span for a in mus],           # 只修 MUS 覆盖的片段
            witness=p_bad,
            keep=[a for a in program.hard if a not in mus],
            schema=PoseDSL,
        )
        if has_orphan(program) or not provenance_covers(program):
            return ('reject', 'repair_violates_schema')
    return ('reject', 'repair_not_converged', mus)
```

### IP-132 LPC（Language-Pose Certificate）

```python
def language_pose_certificate(program, Pi, Sigma, rho_sem, budgets):
    if Pi.inner.empty():
        return ('reject', 'no_pose_witness')
    p = argmax_margin(Pi.inner)
    mu = pose_margin(p, program)                   # 原子边界/避障/生存核取 min
    delta_p = metric_drift(program, p)
    rho_F = frame_cocycle_residual(program)
    rho_rep = max(representation_invariance(program, Pi.samples).values())
    if provenance_coverage(program) < 1.0 or has_orphan(program):
        return ('reject', 'orphan_constraint')     # 语言里没说的，不许变成约束
    if mu < budgets.mu or delta_p > budgets.dp \
       or rho_F > budgets.F or rho_rep > budgets.rep:
        return ('reject', 'language_pose_budget_exceeded')
    if rho_sem(Pi.contact_set()) < budgets.rho_sem:
        return ('reject', 'semantic_contact_fail')
    return ('ok', LangPoseCert(program.core, p, mu, delta_p,
                               rho_F, rho_rep, rho_sem, program.prov))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| PCC | O(|x|·|ℱ| + |A|) | O(|A|) | 约束解码、溯源非空、frame 属场景本体 |
| FCR | O(|ℱ| + |E_ℱ|) | O(|ℱ|) | T_ij 标定、闭环残差真实可测 |
| RIV | O(N_pose·|Enc|·|A_h|) | O(N_pose) | 规范形正确、编码族覆盖 |
| VCP | O(|Π|·(IK + reach + QP)) | O(|Π|) | 区间外近似 sound、接触集完备 |
| MUR | O(R·MUS·VCP) | O(|Π|) | 仅收紧/删除 MUS 原子、重验 |
| LPC | O(|Π|·|A_h|) | O(|Π|) | 见证非空、预算闭合、零孤儿 |

**分离引理（Representation–Frame Separation）**
若验证器表示不变（`ρ_rep=0`）且坐标系敏感（显式计入 `T_{WF}`），则：(i) 仅由**表示别名**造成的位姿错误必被 `δ_c/ρ_rep` 检出；(ii) 仅由**坐标系混淆**造成的位姿错误必被 `ρ_F` 检出；(iii) 二者不能互相替代——纯数值复核既看不见别名（同一物理位姿数字不同），也看不见 frame 串味（闭环残差非零但每个数字都“合法”）。

**正确性定理（Language-to-Pose Grounding Soundness）**
假设第 55 轮 (A29)–(A32) 成立；追加 **(A33)** 约束解码保证每个硬原子结构合法、`frame` 来自场景本体且溯源非空（无孤儿原子）；**(A34)** frame 图闭环残差 `ρ_F ≤ Θ_F` 且所有 `T_{ij}` 已标定；**(A35)** 见证器表示不变，且 `Π_in ⊆ Π_K ⊆ Π_out`（区间外近似 sound）；**(A36)** MUR 只删除或收紧返回 MUS 内的原子，轮数 ≤ R，且每次修复后全量重验。
则部署后位姿同时满足语言意图与全身安全的概率：
```
P_safe ≥ 1 − P(ε_G > θ_G) − P(ρ_F > Θ_F) − P(Π_out \ Π_in ≠ ∅)
            − P(δ_p > Θ_p) − P(MUR 引入孤儿)
            − P(‖Σ−Σ̂‖∞ > ε_s) − P(κ miscalibrated) − P(K_out \ K_in ≠ ∅)
```
关键：**语言只分配结构、几何只负责度量、表示不变抓别名、frame 闭环抓串味、MUS 把修复关进最小核**；任一层失守都不允许把“话说得通顺”当作“位姿可实现”。

## 6. 本轮最大风险

**一句话**：语言-位姿接地的 soundness 同时依赖“约束编译的溯源完整、frame 闭环的标定准确、表示不变验证的严格、以及 MUS 修复只收紧不放宽”；一旦 LLM 生成缺少溯源却貌似合理的约束、或 frame 图存在未被发现的闭环偏差，证书就会在一个错误的可行域上签发，让末端以高置信撞上语义与动力学上都不可达的位姿——因此必须以 **零孤儿约束 + frame 闭环残差门 + 多编码不变审计 + 安全原子禁止放宽** 四重护栏，宁可拒绝执行，绝不把语言的流畅当作位姿的可行。

# IP-121 SCG
def semantic_contact_map(rgbd, seg_model, kappa, theta_k, theta_conf):
    Sigma = seg_model.predict_soft(rgbd)
    C = {(p, c) for p in grid(rgbd) for c in CONTACT_TYPES
         if confidence(Sigma[p]) >= theta_conf
         and kappa[argmax(Sigma[p])][c] >= theta_k}
    M = boundary_margin(Sigma)                      # m_s(p)
    return Sigma, C, M

# IP-122 WBV
def viability_kernel(Sigma, C_plus, x0, horizon, eps):
    K, margins = set(), []
    for x in sample_state_space(x0, horizon):
        feas, u, lam = solve_contact_dynamics(x, C_plus, friction_cone=mu)
        if feas:
            K.add(x); margins.append(distance_to_infeasible(x, C_plus))
    return KernelApprox(inner_hull(K), outer_hull(K, eps),
                        min(margins) if margins else 0.0)

# IP-123 SSF
def semantic_shield(u_nom, x, Kernel, C_plus, W):
    u = qp_solve(H=W, g=-W @ u_nom,
                 constraints=[viability_constraint(x, u, Kernel.K_in),
                              contact_constraint(u, C_plus),
                              friction_cone_constraint(u, mu),
                              joint_limit_constraint(u)])
    return (u, 'ok') if u is not None and projection_gap(u, u_nom) <= Delta_u \
        else (safe_brake(x), 'shield_infeasible')

# IP-124 SCC
def semantic_contact_certificate(traj, Sigma, kappa, rho_sem, budgets):
    Sigma_core = core_semantics(traj, Sigma)
    C_core = contacts_used(traj) & conservative_contacts(Sigma_core, M, kappa, theta_m)
    if not C_core: return ('reject', 'no_core_contact')
    K_margin = min(distance_to_boundary_K(x, Sigma) for x in traj)
    delta_s = semantic_perturbation(Sigma_core, calibrated_eps)
    if K_margin < budgets.theta_K or delta_s > budgets.Theta_s:
        return ('reject', 'semantic_budget_exceeded', K_margin, delta_s)
    if rho_sem(delta_s) < budgets.rho_min:
        return ('reject', 'semantic_robustness_fail')
    return ('ok', SemanticCert(Sigma_core, C_core, K_margin, rho_sem, delta_s))

# IP-125 SRS
def semantic_robustness_spectrum(Sigma_hat, eps_s, sampler):
    worst = 1.0
    for Sigma_adv in sampler.ball(Sigma_hat, eps_s, worst_case=True):
        worst = min(worst, empirical_viability(renormalize(Sigma_adv), sampler.states))
    return worst

# IP-126 CEB
def cloud_edge_semantics(Sigma_c, kappa_c, edge):
    Sigma_e, C_e = edge.local_semantics()
    mismatch = boundary_disagreement(Sigma_c, Sigma_e)
    if mismatch.area > delta_A:
        return ('reprofile', region=mismatch.hotspots, evidence=edge.explain_contact_failure())
    return ('ok', conservative_contacts(C_e, edge.margin, kappa_c, theta_m),
            merge_uncertainty(Sigma_c, Sigma_e))

# IP-127 PCC：LLM 只产出带溯源的位姿约束程序
def compile_pose_program(instruction, scene, llm):
    schema = PoseDSL.schema(frames=scene.frames,        # frame 名必须来自场景本体
                            kinds=ATOM_KINDS,
                            numeric="interval")         # 禁止裸点坐标
    raw = llm.generate(instruction,
                       tools=[scene.frame_lookup, scene.object_pose,
                              scene.affordance_lookup],
                       response_schema=schema)          # 约束解码
    atoms = [a for a in parse_atoms(raw) if a.span and scene.has(a.frame)]
    return PoseProgram(hard=[a for a in atoms if a.kind != 'soft'],
                       soft=[a for a in atoms if a.kind == 'soft'],
                       prov=link_provenance(raw, instruction))

# IP-128 FCR：frame 图闭环残差
def resolve_frame_consistency(program, scene):
    G = build_frame_graph(scene, program)               # W/B/E/O/C 节点
    worst, culprit = 0.0, None
    for cyc in find_cycles(G):
        r = norm(log_SE3(compose_cycle(cyc)))           # 物理上应为 0
        if r > worst: worst, culprit = r, cyc
    if worst > theta_F:
        return ('reject', 'frame_cocycle', worst, culprit)
    return ('ok', collapse_to_world(program, G), worst)

# IP-129 RIV：表示不变审计
def representation_invariance(program, poses):
    out = {}
    for p in poses:
        m = [signed_margin(program, enc(p))
             for enc in (quat, euler, rotmat, dualquat)]
        out[p] = max(m) - min(m)                        # 同一物理位姿裕度应一致
    return out                                          # 全部 <= theta_rep 才通过

# IP-130 VCP：位姿投影进生存核 + 接触集
def viability_coupled_poses(program, Sigma, K, x0):
    feasible = []
    for p in branch_and_bound_SE3(program):             # 区间 inner/outer
        for c_star in contact_selectors(p, Sigma, kappa):   # 上抓/侧抓/推压
            if c_star not in C_plus(Sigma): continue
            ok, x_traj, mu_k = reach_within_kernel(K, x0, p, c_star)
            if ok:
                feasible.append((p, c_star, mu_k)); break
    return PoseSet(inner=inner_hull(feasible),
                   outer=outer_hull(feasible, eps))

# IP-131 MUR：最小不可满足核驱动修复
def minimal_core_repair(program, Sigma, K, llm, max_rounds):
    for r in range(max_rounds):
        Pi = viability_coupled_poses(program, Sigma, K)
        if Pi.nonempty(): return ('ok', program, Pi, r)
        mus = quickxplain(program.hard,
                          test=lambda S: viability_coupled_poses(
                              restrict(program, S), Sigma, K).nonempty())
        p_bad = closest_pose_outside(Pi.outer)
        program = llm.repair(spans=[a.span for a in mus],   # 只修 MUS 覆盖片段
                             witness=p_bad,
                             keep=[a for a in program.hard if a not in mus],
                             schema=PoseDSL)
        if has_orphan(program) or not provenance_covers(program):
            return ('reject', 'repair_violates_schema')
    return ('reject', 'repair_not_converged', mus)

# IP-132 LPC：语言-位姿联合证书
def language_pose_certificate(program, Pi, Sigma, rho_sem, budgets):
    if Pi.inner.empty(): return ('reject', 'no_pose_witness')
    p = argmax_margin(Pi.inner)
    mu = pose_margin(p, program)                        # 原子/避障/生存核取 min
    delta_p = metric_drift(program, p)
    rho_F = frame_cocycle_residual(program)
    rho_rep = max(representation_invariance(program, Pi.samples).values())
    if provenance_coverage(program) < 1.0 or has_orphan(program):
        return ('reject', 'orphan_constraint')          # 语言没说的不许变成约束
    if mu < budgets.mu or delta_p > budgets.dp \
       or rho_F > budgets.F or rho_rep > budgets.rep:
        return ('reject', 'language_pose_budget_exceeded')
    if rho_sem(Pi.contact_set()) < budgets.rho_sem:
        return ('reject', 'semantic_contact_fail')
    return ('ok', LangPoseCert(program.core, p, mu, delta_p,
                               rho_F, rho_rep, rho_sem, program.prov))

**分离引理（Representation–Frame Separation）**
表示不变且坐标系敏感的验证器下：纯表示别名错误必被 `δ_c/ρ_rep` 检出，纯坐标系混淆必被 `ρ_F` 检出；纯数值复核对二者均无鉴别力。

**正确性定理（GroundEdge v32 全链证据 Soundness）**
假设 v31 的 (A26)–(A28)、SCT 的 (A29)–(A32) 成立；LPG 追加 **(A33)** 约束解码使每个硬原子结构合法、`frame` 属场景本体且溯源非空；**(A34)** frame 闭环残差 `ρ_F ≤ Θ_F` 且 `T_{ij}` 已标定；**(A35)** 见证器表示不变且 `Π_in ⊆ Π_K ⊆ Π_out`；**(A36)** MUR 只删除/收紧返回 MUS 内原子、轮数 ≤ R 且修复后全量重验。
则端到端部署成功概率：
```
P_success ≥ 1 − Σ_d(1−ρ_min(d)) − β_E − P(δ_a > Θ_a)                       # v31 动作-协同
            − P(‖Σ−Σ̂‖∞ > ε_s) − P(κ miscalibrated) − P(K_out\K_in ≠ ∅)    # SCT 语义-接触
            − P(ε_G > θ_G) − P(ρ_F > Θ_F) − P(Π_out\Π_in ≠ ∅)               # LPG 接地/坐标系
            − P(δ_p > Θ_p) − P(MUR 引入孤儿)                                # LPG 度量/修复
```
关键：**动作对齐（v31）→ 接触可信（SCT）→ 语言可接地且坐标系自洽（LPG）**，任一环失守只允许降级/制动/拒证，不允许用“话说得通顺”替代“位姿被证书覆盖”。

## 5. 本轮最大风险

**一句话**：v32 把“语义-接触”与“语言-位姿”两条证据链都建立在对模型输出的二次信任上——语义证书依赖分割置信校准，位姿证书依赖 LLM 约束的溯源完整与 frame 标定；一旦 LLM 生成了缺少溯源却貌似合理的约束、或 frame 图存在未被发现的隐性闭环偏差，LPC 就会在错误的可行域上签发“语言可达、几何可行”的假象，让末端高置信地撞上语义与动力学都不可达的位姿，故必须以 **零孤儿约束 + frame 闭环残差门 + 多编码不变审计 + 安全原子禁止放宽** 四重护栏，宁可拒证，绝不以语言的流畅替代位姿的可行。
