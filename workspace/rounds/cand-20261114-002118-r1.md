# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「比赛策略」×「技能组合」）

> R69 教会系统「问、看、触」，但它的整座信息论建立在两个从未被检验的假设上：**(a) 回答是外生的**——`p(y|g,o)` 与提问者是谁、问完之后会发生什么无关；**(b) 动作是单块的**——由一个流策略直接吐出 `(a,g)`，不区分技能、更不区分技能与技能之间的接缝。真实对局里这两条同时不成立。**比赛策略**说：提问是一个暴露弱点的动作，对手会利用你的提问（cheap talk / 信号 / 定价），暂停、挑战、算力都是有限预算，确定性策略会被预测、被针对；**技能组合**说：能力是技能库而不是动作块，单个技能都安全，接缝处（控制器切换、接触过渡、坐标系/工具切换）却可能整体失效，组合风险不等于局部风险之和，而离散层歧义（用哪个技能、什么顺序）根本不是连续流模态能表达的。
>
> 核心命题：**把闭环升级为「从一本经过认证的战术手册里，针对一个把你的提问当作博弈动作的对手，选择并组合技能」的有限预算对抗博弈**。技能组合的安全由 assume-guarantee 契约 + 接缝风险担保；提问的收益由**策略性信息价值 SVoI**（干预式信息增益 − 信息泄漏 − 对手最优反应造成的利用成本 − 节奏成本）度量；预算分配用**带逐路径安全约束的对抗遗憾最小化**；混合只发生在已认证的安全动作内，安全性**不依赖随机化、不依赖对手配合、不依赖对手诚实**。三不变式：逐路径安全、严格包含 R69、证据纪律继承。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**这一问会不会先把我自己卖了？我要用哪一套连招，才能在对手反应下仍然安全？**」——信息不是白拿的，技能也不是堆起来就安全的。

## 0. 直觉与动机

**灵感 1（比赛策略 → 提问是暴露弱点的动作）**
直觉：对手问你「你怕左路还是右路」，无论你怎么答，你都暴露出自己的判断；高手甚至用假动作逼你先亮牌。R69 的 `VoI(g)=H(M|o)−E[H(M|o,y)]` 把回答当成天气：你观测它，它不因你观测而改变。但对局里回答是策略性的：自利的协作者会讨价还价，对抗者会撒谎、拖延、或用你的问题反推你的下一步。更隐蔽的是**提问本身是一个信号**：你问「杯子在左还是右」，等于告诉对方你对杯子的位置不确定，也暴露了你打算去拿它。于是「信息收益」必须先扣掉**信息泄漏**（我暴露了什么）、**利用成本**（对手的最优反应会让我多付什么）、**节奏成本**（发问花掉的暂停与先手）。R69 的风险是「问错」，R70 的新风险是「**问这一下先把自己摆上了牌桌**」。

**灵感 2（比赛策略 → 预算是元博弈，确定性可被针对）**
直觉：一场比赛只有几次暂停、几次挑战；把它们花在哪一回合，是比「这一回合问不问」更高层的决策。更关键：如果提问的时机、对象、内容都是确定的，对手就能预判并布置陷阱——**确定性策略在对抗下是可利用的**。但随机化不能拿安全换：能混合的只有「已经认证安全」的战术，安全性必须逐条路径成立，而不是在期望上成立。这把 R69 的「≤1 次/单位时间」硬预算升级为「**整场比赛的预算分配 + 不可预测但安全的混合**」。

**灵感 3（技能组合 → 组合风险 ≠ 局部风险之和）**
直觉：一个机器人会「伸手」「抓取」「抬起」「放下」，每个单独测试都过；但在堆叠货架上，「伸手」之后手停在遮挡位，恰好破坏了「抓取」假设的可见性，「抓取」的末端位姿又把「抬起」的可行域压到边界——**每个技能都对，连起来就错**。风险长在**接缝**上：控制器切换的不连续、接触从自由空间到约束空间的跃迁、坐标系/工具/传感器更换、以及上游技能 post-condition 与下游技能 pre-condition 之间的分布漂移。R69 用一个流策略直接生成整段动作，根本没有「技能」与「接缝」这两个概念，也就无法为组合给出证书。

**灵感 4（技能组合 → 连招既是能力也是探针）**
直觉：有些连招本身就是最好的信息动作——「先轻推让物体转一点，再看清标签」「先伸到侧面，用视差判断深度」，这不是一个抽象的「看」或「问」，而是一段**有物理后果的验证连招**。于是 R69 的动作级 VoI 升级为**战术级（plan-level）VoI**：在组合空间里选一条既安全又能照亮歧义的连招。指数级组合空间由「**战术手册**」剪枝：把已验证接缝的连招固化为 play；新连招先「空跑/热身」认证，否则不进手册、按未知风险保守执行。

**灵感 5（对抗 → 正面对撞 R69 的最大风险）**
直觉：R69 最恐惧的是「模态分布不可信 → 问一个幻影」。R70 说：**即使模态分布完全可信，回答者仍可能是策略性的，连招接缝仍可能是未验证的**。所以需要两条与「模态校准」正交的独立防线：（i）**策略不一致检测**——把回答代入计划，检查它是否会把连招推向接缝契约失效或流似然异常的区域，而不是只看回答像不像真话；（ii）**接缝契约**——未验证的组合一律按未知风险收紧，而不是假设「每个技能都测过，所以组合也安全」。这样「问错」不再只由 ECE 拦截，而是由**行为后果**拦截。

## 1. 形式化定义（增量：定义 310–327）

**定义 310（PLAYBOOK-RAS 总览）** PLAYBOOK-RAS = (SGL, SGC, PBK, SVG, OPM, BAR, CPS, SSB, RAS-WM‡)。三不变式：
(i) **实时环零学习写操作**（继承 R68 定义 276-i / R69 定义 293-i）；
(ii) **逐路径安全**：对任意实现的战术 p、任意对手反应 y、任意随机化种子，执行控制都落在已认证安全包络内；混合仅在安全战术的支撑集上进行；安全不依赖对手诚实/配合，也不依赖期望；
(iii) **严格包含 R69**：当技能库退化为单技能、回答者退化为非策略型（θ 固定、σ 外生）、预算不跨回合耦合时，逐指令等于 FLUID-RAS。

**定义 311（技能与契约）** 技能 `s = (π_s, Pre_s, Post_s, Inv_s, C_s, D_s, cert_s)`：策略、前置/后置状态分布、安全不变式、资源成本 `C_s=(c_time,c_energy,c_social)`、证书有效域 `D_s`、局部证书。`cert_s` 在 `D_s` 上给出局部风险上界 `R_loc(s)`。

**定义 312（技能图与战术）** 技能图 `G=(S,E)`，边 `e=(s_i,s_j)` 带守卫 `g_{ij}(x)` 与切换算子 `H_{ij}`。战术（play）`p=(s_1,…,s_L)` 是 G 中的一条路径，执行算子 `Φ_p = H_{L−1,L}∘…∘H_{1,2}∘π_{s_L}∘…∘π_{s_1}`。

**定义 313（接缝风险）** 对相邻技能 `(s_i,s_j)` 在切换时刻 τ：
```
r_seam(i,j) = W1(Post_{s_i}, Pre_{s_j})
            + ‖H_{ij}(x_{τ−}) − x_{τ+}‖_{Σ_cert}
            + ρ_frame/tool + ρ_contact
```
前两项为分布失配与切换不连续；ρ 项为坐标系/工具/接触模态变更残差。`r_seam` 度量「两个各自合格的技能，在缝上是否仍然合格」。

**定义 314（组合风险上界）** 对战术 p：
```
R(p) ≤ Σ_i R_loc(s_i) + Σ_{i=1}^{L−1} r_seam(s_i,s_{i+1}) + R_ho(p)
```
`R_ho` 为多接缝联合效应。若所有接缝认证（`r_seam ≤ ε_seam` 且 `G_{s_i} ⊨ A_{s_{i+1}}`），则上界有效；否则接缝项按保守上界计入 `U_epi`（视为未消解）。

**定义 315（assume-guarantee 契约代数）** 每个技能有假设 `A_s` 与保证 `G_s`。组合 `s_i; s_j` 合法当且仅当 `G_{s_i} ⊨ A_{s_j}`（在证书裕度内）；串联可结合，并联要求帧/资源不相交。契约合取给出组合的局部证书；缺任一条即视为未验证。

**定义 316（策略型环境）** 回答者类型 `θ ∈ Θ`（honest / noisy / self-interested / adversarial / coalition），私有效用 `u_R(a,y,θ)` 与私有信息。回答核 `σ(y|g,o,θ)` 是给定 `(g,o,θ)` 的策略（均衡/最优反应），**不是**外生分布；提问者维持先验 `μ(θ)` 并仅在慢环更新。

**定义 317（策略性信息价值 SVoI）**
```
SVoI(g) = I_{do(g)}(M; y) − λ_L·Leak(g) − λ_E·Exploit(g) − λ_T·Tempo(g)
```
- `I_{do(g)}` 为**干预式**互信息（对 g 做 do 操作，切断 g 与提问者私有状态的混淆），因为回答分布内生依赖于 g；
- `Leak(g) = I(Θ_asker; g)`：提问暴露的私有不确定性/预算/意图；
- `Exploit(g) = max_{θ∈Θ} E[ΔLoss | 对手观测 g 并按最优反应 σ_θ]`：最坏类型下因暴露而增加的损失；
- `Tempo(g)`：发问占用的时间/先手折价。
默认取 `min_θ` 稳健版本；有可信先验时可取 `E_{μ}` Bayes 版本。

**定义 318（安全混合策略）** 查询策略 `π_q` 的支撑集 `Q_safe = {g : certify_info(g) ∧ budget.allow(g)}`。`π_q` 可随机化以降低可预测性，但**逐路径安全**要求 `∀g∈supp(π_q)` 均安全；不采用「以高概率安全」的弱保证。混合熵 `H(π_q)` 进入证书，作为可利用性代理。

**定义 319（预算分配为对抗 bandit）** 比赛视界 T 内可花费预算 B（查询/挑战/高风险连招次数）。每回合选 `q_t∈Q_safe`，支付 `cost(q_t)`，获得 SVoI 奖励；`Σ cost ≤ B`。奖励可为对抗性（无随机假设），用 EXP3/对抗遗憾最小化：`Regret_T = max_{q∈Q_safe} ΣSVoI(q) − ΣSVoI(q_t) = O(√(BT log|Q|))`。**安全不在遗憾里，而在约束里**。

**定义 320（战术手册 PBK）** `P={p_1,…,p_m}`，每个 play 附证书 `J_play=(局部证书哈希, 接缝证书哈希, 资源, playbook 版本)`。`p∈P` 当且仅当所有局部证书有效、所有接缝认证、资源在预算内。**手册外组合**需「空跑认证」或按未验证保守执行（定义 324）。

**定义 321（对手模型与策略不一致检测 OPM）** 维持 `μ(θ)`；对回答 y 计算其代入战术后的**行为后果一致性**：
```
SI(y) = max{ ΔFMA(p2), seam_violation_prob(p2), h_p(x_t) − SSB.predict(p2) }
```
其中 `p2 = replan_with_answer(p, y)`。若 `SI(y) > τ_SI`，则即使 y 语义上很「合理」，也判为策略不一致并拒绝单源采纳（叠加 R69 证据纪律）。这把「真假」从「像不像」改为「**做了会不会坏**」。

**定义 322（验证连招 / 挑战技能 CPS）** 一类特殊技能 `p_chal∈S`，唯一目的是用**物理后果或承诺代价**验证回答：用视差/接触得到独立测量，或让对手的声明必须以可观测代价兑现。CPS 输出作为正交证据源之一；单次 CPS 不得单独定案（继承 R69 定义 293-iii）。

**定义 323（策略安全障碍 SSB）** 对执行中的战术 p 定义障碍函数 `h_p(x) ≥ 0` 表示距认证包络的裕度；要求沿轨迹不降于切换引入的界：`h_p(x_{τ+}) ≥ h_p(x_{τ−}) − δ_switch`。若对手回答导致的计划使 `h_p` 无法认证，则拒绝该计划并回退。

**定义 324（预算与组合感知的两级退避）** `U_unres = U_ale + U_epi_unresolved + R_seam_unknown`（未认证接缝按保守上界计入）。`λ = max(λ_task, λ_floor(U_unres))`。当（预算耗尽 ∨ `SI>τ_SI` ∨ ECE 越界 ∨ 手册外且未空跑 ∨ 对手模型不可信）时，退化为 R69 单技能非策略保守路径，且 λ 单调不降。

**定义 325（证书 J_PLAYBOOK）** `J_PLAYBOOK = (J_FLUID, playbook_ver, play_id, seam_cert_hash, SVoI_ratio, leakage_bound, exploit_bound, mix_entropy, regret_bound, challenge_log_hash, SI_p95)`。Valid ⇔ `Valid(J_FLUID) ∧ 接缝全部认证 ∧ 预算未越界 ∧ 证据纪律 ∧ SSB ∧ SI_p95 ≤ τ_SI`。

**定义 326（慢环策略学习与无悔）** 对手模型 `μ(θ)`、SVoI 先验、接缝风险模型仅在慢环更新（实时环零学习写操作不变）；更新以对历史对局的遗憾为准则，保证次线性遗憾，且**不得放松任何已认证接缝的保守界**（单调安全）。

**定义 327（安全占优与 R69 边界）** 称策略 π 相对 π₀ 安全占优，若 `∀对手策略 σ、∀状态：Risk(π,σ) ≤ Risk(π₀,σ)`，且执行控制始终落在 π₀ 的认证包络内。PLAYBOOK-RAS 对 FLUID-RAS 安全占优；性能 ≥ FLUID 仅在 `SVoI−成本 > 0` 时成立，否则逐指令相同。

```python
# IP-264/265 SGL+SGC：技能图、契约与接缝认证
class SkillGraphLibrary:
    def compose(self, plan):                          # plan = [s1..sL]
        certs = [s.cert for s in plan]                # 局部证书
        seams = []
        for si, sj in zip(plan, plan[1:]):
            if not implies(si.G, sj.A, margin=EPS_MARGIN):
                return None, U_unknown(seam=(si, sj))  # 契约不闭合 → 未验证
            r = (W1(si.Post, sj.Pre) + switch_gap(si, sj)
                 + frame_tool_contact(si, sj))
            if r > EPS_SEAM:
                return None, U_unknown(seam=(si, sj))
            seams.append(r)
        return PlayCert(plan, certs, seams), sum(seams)   # 组合风险上界

# IP-267 SVG：策略性信息价值（干预式，扣泄漏/利用/节奏）
def strategic_voi(g, modes, opp_model, budget):
    info  = interventional_mi(modes.M, query=g)          # do(g)
    leak  = mutual_info(asker_private_type, g)           # 暴露了什么
    expl  = max(loss_delta_under_best_response(g, theta)
                for theta in opp_model.support())        # 最坏利用
    tempo = budget.tempo_cost(g)
    return info - LAM_L * leak - LAM_E * expl - LAM_T * tempo

# IP-269/271 BAR+PBO：只在安全查询集上混合，无利可图则不玩
def choose_move(playbook, modes, opp, budget):
    Q = [g for g in playbook.safe_queries()
         if budget.allow(g) and certify_info(g)]
    if not Q:
        return None                                      # 无安全问法 → R69 兜底
    scores = {g: strategic_voi(g, modes, opp, budget) for g in Q}
    good = [g for g, s in scores.items() if s > 0]
    if not good:
        return None                                      # 问了不赚 → 不问
    dist = exp3_weights(scores, good)                    # 慢环遗憾更新
    return sample(dist), dist                            # 混合仅为不可预测

# IP-268 OPM：把回答代入计划，检查行为后果而非语气
def answer_consistency(y, plan, cert, M, o):
    p2        = replan_with_answer(plan, y)
    fma_delta = flow_anomaly(M.fmp, p2, o, o_calibrated)
    seam_viol = seam_violation_prob(p2, cert)
    h_drop    = M.last_h - M.ssb.predict(p2)             # 安全障碍下降
    return max(fma_delta, seam_viol, h_drop)             # SI(y)

# IP-274 主闭环（继承 R69，仅在「问什么/怎么连」处插入博弈与组合层）
def PLAYBOOK_round(M, obs):

    # 1) 组合层：任务 → 候选战术（手册内 + 保守新战术）
    plans = M.pbo.candidates(z, M.sgl, M.pbk)
    for p in plans:
        cert_p, r_seam = M.sgc.compose(p.plan)           # A-G + 接缝
        p.U = U_cal + r_seam + (0.0 if cert_p else U_unknown())
    # 2) 信息层：只在安全查询集上算 SVoI；无利可图则不问
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4

         if modes.U_epi > TAU_EPI else None)
    # 3) 验证：回答必须过行为后果一致性（SI），否则单源不采纳
    best = min(plans, key=lambda p: (p.U, risk(p)))

        else:

    M.budget.charge(g)
    M.pbo.update_regret(g, realized_reward=observed_gain)
    return k, lam, best
```

## 3. 推导

**引理 19（接缝可加性与二阶余项）** 在 A99（接口局部性：每个技能只通过边界状态与外界交互，且切换算子 Lipschitz）下，组合风险的高阶项 `R_ho = O(ε_seam²·L²)`；于是 `R(p) ≤ Σ R_loc + Σ r_seam + O(ε²)`。要点：**接缝不是可忽略的噪声，而是有量纲的风险项**；当接缝不可认证时，`r_seam` 只能取保守上界，不能取 0。

**引理 20（SVoI 不超过 R69 的 VoI）** 对任意 g，`SVoI(g) ≤ VoI_{R69}(g)`；等号当且仅当回答非策略外生（σ 不依赖 θ 与对手反应）、且 `Leak=Exploit=Tempo=0`。故 R69 是「无博弈、无泄漏、无接缝成本」边界；策略性只会**降低**提问的净值——这保证了系统不会因为会算博弈而比 R69 更爱乱问。

**引理 21（确定性的可利用性与安全混合）** 在重复对局中，若查询调度对对手可观测且确定，则存在自适应对手使提问者的遗憾 `Ω(T)`；采用支撑在 `Q_safe` 上的熵正则混合后，对手对经验频率的最优利用收益 ≤ `O(√(log|Q|/T))`，且因 `∀g∈supp(π_q)` 已认证，逐路径安全不受混合影响。系：**不可预测性可以与安全性正交地获得**，只要混合集本身是安全集。

**引理 22（组合式证书可靠性）** 若每个技能的证书在其有效域 `D_s` 上可靠，且每条接缝满足 `G_{s_i} ⊨ A_{s_{i+1}}` 且 `r_seam ≤ ε_seam`，则组合计划 p 在其执行域内安全；反之若存在未认证接缝，则存在对手/扰动使组合失效，其概率不被任何局部证书约束。系：**「每个都测过」不蕴含「连起来安全」**，必须显式认证接缝。

**定理 18（PLAYBOOK 严格包含 R69）** 在 A99–A101 下，PLAYBOOK-RAS 的逐路径风险 ≤ FLUID-RAS；且当（单技能库 ∨ `∀g: SVoI(g)≤0` ∨ ECE>τ_ece ∨ 对手模型不可信）时，两者逐指令相同。故 R69 是 PLAYBOOK 在「无博弈 × 单技能 × 无接缝」边界上的退化；安全侧不让步，效率侧获得「组合 + 策略」的收益。

**定理 19（预算-遗憾-安全三明治）** 在 `Q_safe` 上以 EXP3 分配预算 B，`Regret_T ≤ O(√(BT log|Q|))`；同时任意时刻 `t`、任意对手反应、任意随机种子，执行控制落在认证包络内（SSB 保持）。**遗憾界只管收益，安全由约束逐路径保证**——这是与「用期望安全换性能」的根本区别。

**定理 20（策略性无套利：不问定理）** 若 `∀g∈Q_safe: SVoI(g) ≤ 0`，则任何提问策略相对不提问的期望收益上界为 0，且在最坏类型下严格为负；此时最优策略是不问、走 R69 保守。因此 R69 的直觉「问错比不问更危险」被内化为一条**可计算的不等式**：当 `Leak+Exploit+Tempo ≥ I_{do}(M;y)` 时，提问被保守支配。

## 4. 推导

**引理 19（接缝可加性）** A99（接口局部性 + 切换 Lipschitz）下 `R_ho=O(ε_seam²L²)`，故 `R(p) ≤ ΣR_loc + Σr_seam + O(ε²)`；接缝是有量纲风险项，不可认证时只能取保守上界。

**引理 20（SVoI ≤ R69 VoI）** `SVoI(g) ≤ VoI_{R69}(g)`，等号当回答非策略外生且无泄漏/利用/节奏成本。策略性只降低提问净值：会算博弈不会让系统更爱乱问。

**引理 21（确定性可利用性与安全混合）** 对可观测的确定性调度，存在自适应对手使遗憾 `Ω(T)`；在 `Q_safe` 上熵正则混合后对手利用收益 `O(√(log|Q|/T))`，且逐路径安全不受混合影响。系：不可预测性与安全性可正交获得。

**引理 22（组合式证书可靠性）** 每技能证书在 `D_s` 可靠且每条接缝契约闭合、`r_seam≤ε_seam` ⇒ 组合在执行域内安全；存在未认证接缝时，其失效概率不被任何局部证书约束。系：「每个都测过」不蕴含「连起来安全」。

**定理 18（PLAYBOOK 严格包含 R69）** A99–A101 下逐路径风险 ≤ FLUID；当单技能库或 `∀g:SVoI(g)≤0` 或 ECE 越界或对手模型不可信时逐指令相同。R69 = 「无博弈 × 单技能 × 无接缝」边界。

**定理 19（预算-遗憾-安全三明治）** 在 `Q_safe` 上 EXP3：`Regret_T ≤ O(√(BT log|Q|))`；同时任意时刻、任意对手反应、任意随机种子下执行控制落在认证包络内（SSB 保持）。遗憾管收益，安全由约束逐路径保证。

**定理 20（策略性无套利 / 不问定理）** 若 `∀g∈Q_safe: SVoI(g)≤0`，则不提问严格优于任何提问策略；R69 的「问错比不问更危险」被内化为可计算不等式 `Leak+Exploit+Tempo ≥ I_do(M;y) ⟹ 保守支配`。

## 7. 本轮最大风险

**一句话**：PLAYBOOK-RAS 把安全性押在「技能契约与接缝风险模型本身是对的」这一**近似**上——接缝的未建模部分会沿组合链累积，却被 assume-guarantee 的「局部都对所以整体对」包装成一张看似严谨的证书；一旦它同时误判了对手类型，系统就会用一张失真的证书，在一场真实的比赛里自信地执行错误的连招——**最危险的不是问错，而是拿着一份盖了章的错。**

**次级风险与缓解**：契约是近似（接缝项强制保守上界 + 空跑认证 + SSB 逐路径校验）；对手类型误判（`μ(θ)` 后验 + 慢环学习 + 不可信即退 R69）；混合被利用（只在 `Q_safe` 混合，熵正则降可利用性，安全不依赖随机化）；组合空间爆炸（手册剪枝 + 候选预算 ≤16）；长时程遗忘（慢环回放 + 认证界单调不放松 + E314）。
