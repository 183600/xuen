# 第 48 轮（承接第 47 轮 v24；本轮灵感：末端执行器控制 × 轮足机器人） · EEC-Loco-Cert：末端执行器-轮足模式联合证书与模式切换守卫的全身安全保证（架构 v12）

> 承接第 47 轮 v24 ROS-Cert × Reward-Contract。v24 把证书升级为受 QoS 约束的分布式能力、把奖励升级为安全支配的合约，但隐含假设 H6：**姿态证书只描述本体（base）位姿，末端执行器被视为刚性延伸且控制误差可忽略；运动模式被视为静态常数，与证书的适用条件无关**。UniBot 是“轮足底盘 + 机械臂”：轮式在平地高效稳定但越障弱，足式越障强但机身振荡与足端滑移大，模式切换存在瞬态失稳；机械臂的关节柔顺、TCP 跟踪误差、负载与接触力会反向影响本体稳定，进而影响 base 姿态证书。两个灵感词精确命中 H6：**末端执行器控制**把安全谓词从 base pose 扩展到 TCP pose × 接触 × 负载；**轮足机器人**把“运动模式”变成证书的一等公民（不同模式的稳定裕度、振动上界、可达工作空间、能耗模型都不同）。二者耦合出的新问题：**base 证书与 TCP 证书可能各自有效，但组合后 TCP 落在当前模式不可达或不稳定区域，或在模式切换窗口内旧证书仍被消费而新证书尚未建立，安全保证被静默击穿**。

## 0. 直觉与动机

**灵感 1（末端执行器控制 → TCP 证书与误差预算）**
直觉：任务真正关心的是“夹爪/工具中心点在哪里、以多大力接触什么”，而不是底盘中心在哪里。base 证书 P_t 只覆盖了运动链的第一段；从 base 到 TCP 还要经过关节编码器、减速器回差、连杆柔顺、标定误差与负载形变。于是 TCP 证书应由 base 证书与关节证书经前向运动学的 Lipschitz 界**合成**，其半径是两段误差的传播和，而不是取二者最大值。更进一步，末端控制与底盘稳定在争夺同一个误差预算：为了稳住 base 收臂，会牺牲 TCP 跟踪；为了压 TCP 误差而伸展手臂，会抬高质心、降低稳定裕度。误差预算必须被显式分配，而不是各自调参。

**灵感 2（轮足机器人 → 模式即证书适用条件）**
直觉：同一台机器人在轮式和足式下不是“同一个人穿不同鞋”。轮式的支撑是连续轮地接触，稳定裕度大、振动小、可达工作空间受轮距与转向约束；足式是离散足端支撑，稳定裕度随步态相位变化，机身俯仰/滚转振荡显著，TCP 在高动态相位上的可达集收缩。模式切换（轮→足、足→轮）存在抬轮/落足、重心转移、接触重建的瞬态窗口，此时两套证书都不完全成立。因此模式 σ 必须进入证书：L_t=(σ, 稳定裕度, 振动上界, 可达集, 能耗模型, 租约)，且切换期间必须用一张保守的“过渡证书”覆盖整个窗口。

**灵感 3（耦合 → 全身合成证书与切换守卫）**
直觉：把 base 证书、TCP 证书、模式证书拼起来，不等于得到全身证书。组合的 soundness 需要显式处理：模式一致性（TCP 是否落在当前模式可达集）、误差传播（FK 雅可比谱范数放大关节误差）、时间一致性（三段证书是否在同一时刻有效）、相关性（三个估计器共享标定与 IMU 误差时不能简单 Bonferroni）。切换守卫则是一个“先建后拆”的原子协议：在 τ_sw 内冻结机械臂到安全收拢构型、收缩速度、要求保守支撑多边形，只有新模式的稳定裕度与振动上界被实测满足后，才允许撤销旧证书。

**耦合升级**：在 v24 之上新增 **末端执行器-运动模式联合证书层**。EECC 合成 TCP 证书并跟踪接触/负载；LMG 签发模式证书并执行切换守卫；WBSA 做全身合成、误差预算分配与故障降级。v12 分层：根信任层增加 TCP 租约与模式租约，L1 几何层由 base 半径扩展为全身半径，L2 上下文/记忆层检索键加入模式与负载，L3 CAR 守卫消费 W_t，L4 采集层收集模式切换与接触轨迹。

## 1. 形式化定义（增量：定义 64–68）

**定义 64（末端执行器证书 E_t）**
设关节角区间 [q^-_t, q^+_t] 由编码器量化与回差给出，前向运动学 f，雅可比 J(q)。TCP 相对 base 的估计与半径
\[
\hat{x}^{tcp}_b=f(\hat q),\qquad r_{tcp}=L_J\|q^+_t-q^-_t\|/2+\epsilon_{cal}+\epsilon_{load},
\]
其中 \(L_J=\sup_{q}\|J(q)\|_2\)。接触状态 c∈{free, contact, slip}，力/力矩证书给出 wrench 界。末端证书
E_t=(x̂^{tcp}_b, r_{tcp}, c_t, wrench_t, ℓ_{ee})，
满足 **TCP soundness**：P(x^{tcp,true}_b ∈ Ball(x̂^{tcp}_b,r_{tcp})) ≥ 1−α_e。当 c_t=slip 或 wrench 超界时 E_t 立即失效。

**定义 65（轮足模式证书 L_t）**
模式 σ∈{W(轮式), L(足式), T(过渡)}。模式证书
L_t=(σ, m_σ, b_σ, R_σ, P_σ, ℓ_{loco})，
其中 m_σ 为稳定裕度（轮式用轮地接触多边形，足式用支撑多边形/ZMP 裕度），b_σ 为机身振动幅值上界，R_σ 为 TCP 相对 base 的可达集，P_σ 为能耗模型。**模式 soundness**：在 σ 下若 m_σ≥m_min、b_σ≤b_max、且无未建模滑移，则 P(姿态与支撑谓词成立) ≥ 1−α_l。过渡模式 T 不签发常规证书，只允许使用保守证书 L^safe。

**定义 66（全身合成证书 W_t）**
W_t = Compose(P_t, E_t, L_t)，其 world-frame TCP 证书为
\[
\hat{x}^{tcp}_w=T(\hat{x}_b)\,\hat{x}^{tcp}_b,\qquad r_w=r_b+L_{T}\,r_{tcp}+L_{\sigma}b_\sigma,
\]
并要求 \(\hat{x}^{tcp}_w\) 在 \(T(\hat{x}_b)R_\sigma\) 内且 r_w≤r_max(task, clearance)。**联合 soundness**：若 P_t、E_t、L_t 在同一时刻均有效且模式一致，则
P(x^{tcp,true}_w∈W_t) ≥ 1−(α_p+α_e+α_l+α_comp)，
其中 α_comp 由共享标定/IMU 误差的联合 conformal 校准给出（共享误差时用联合校准而非独立并集界）。

**定义 67（模式-末端联合误差预算与门控）**
动作 a=(σ, q_cmd, 底盘位姿指令, 速度)。误差预算
r_b + L_T r_{tcp}(q_cmd) + L_σ b_σ(σ,v) ≤ r_task。
在预算约束与能量租约 ℓ_e 下联合选择
\[
a^*=\arg\max_{a}\ \frac{\mathbb{E}[\text{TaskReward}(a)] - c_e P_\sigma - c_s \text{Risk}(\sigma)}{1}
\]
s.t. W_t 有效、r_w≤r_max、E(t)≥E_min。误差预算在“底盘稳姿”和“末端跟踪”之间按拉格朗日乘子分配：稳定裕度紧张时优先收臂压 r_tcp 并降速降 b_σ。

**定义 68（模式切换守卫）**
切换 σ→σ′ 仅当存在保守证书 W^safe 覆盖整个过渡窗口 [t, t+τ_sw]：期间机械臂冻结在安全收拢构型 q_safe（或退避到 R_σ∩R_σ′ 内）、速度上界 v_safe、支撑条件保守化，且 m_σ,m_σ′ 均不低于 m_trans。新证书 L_{σ′} 只有在稳定时间 τ_settle 后实测 m_{σ′}≥m_min 且 b_{σ′}≤b_max 时才签发；否则保持 W^safe 并进入停走（fail-closed），绝不使用“旧模式证书 + 新模式动作”的组合。

## 2. 三大新增产出与既有 IP 升级

**IP-72 EECC（End-Effector Certificate Compositor）**
- 关节证书 → FK 雅可比 Lipschitz 半径传播
- TCP 证书合成、标定/负载误差项在线辨识
- 接触状态机（free/contact/slip）与 wrench 证书
- 负载导致的质心偏移估计，回馈 LMG 稳定裕度

**IP-73 LMG（Locomotion Mode Governor）**
- 模式证书签发：m_σ、b_σ、R_σ、P_σ
- 模式切换守卫与保守过渡证书
- 足端滑移/轮地打滑检测，触发模式证书撤销
- 模式可行性预测（结合 L2 上下文/地形先验）

**IP-74 WBSA（Whole-Body Safety Arbiter）**
- 全身证书合成与联合 conformal 校准
- 误差预算分配（底盘稳姿 vs 末端跟踪）
- 组件失效降级：冻结臂 → 收拢 → 停走/fail-closed
- 与 RCA 安全项、QCB QoS 租约、CAR 守卫对接

**既有 IP 升级**
IP-51 CAR：守卫从 P_t 升级为 W_t，TCP 越界或模式不一致即撤销
IP-62 CCA：新增模式切换红队、接触滑移注入、负载突变测试
IP-63 ECPS：模态/模式联合决策，Depth 需求随足式高动态相位上升
IP-69 QCB：新增 tcp-lease / mode-lease / transition-safe 话题与代际号
IP-70 RCA：任务奖励加入 TCP 精度项，安全项加入全身证书硬约束
IP-66 MVR：记忆键加入模式 σ、负载与接触状态
IP-67 VAD：语音指令解析出 TCP 目标锚点，经 W_t 校验后才可执行

## 3. 算法骨架

WBSA 每控制周期：
1. 读 P_t、关节区间/回差、力/力矩、IMU、模式 σ、ℓ_e、ℓ_loco
2. EECC 合成 E_t，更新接触状态与负载质心偏移
3. LMG 校验 m_σ、b_σ、R_σ，必要时签发/撤销 L_t
4. WBSA 合成 W_t，检查模式一致性与 r_w≤r_max
5. 在预算 r_b+L_T r_tcp+L_σ b_σ≤r_task 与能量租约下解 a*
6. 若任一组件失效/过期 → 冻结臂到 q_safe → 降速 → 停走或 fail-closed
7. 若请求切换模式 → 先进入 W^safe，实测满足后再签发 L_{σ′}
EECC/LMG 的输出作为 CAR 守卫与 RCA 安全项的输入。

## 4. 本轮最大风险

**一句话**：模式切换守卫可能低估轮↔足过渡窗口内的机身振动与足端滑移，而机械臂控制器又会用“压 TCP 误差”去补偿底盘抖动，导致过渡期间全身证书的半径被系统性低估、TCP 静默越界；因此必须以实测过渡包络标定 b_σ 与 L_σ，切换期间强制冻结机械臂到安全构型并在任何分量失效时 fail-closed。

## 2. 关键算法 伪代码

### IP-72 EECC
```
def tcp_certificate(q_lo, q_hi, base_cert, calib, FTs, payload):
    q_hat = (q_lo + q_hi) / 2
    x_rel = forward_kinematics(q_hat)
    L_J = max_singular_value(J(q_hat))          # 或用区间界
    r_joint = L_J * norm(q_hi - q_lo) / 2
    r_tcp = r_joint + calib.eps_cal + load_deform(payload)
    c = contact_state(FTs)                       # free/contact/slip
    if c == 'slip' or wrench_exceeds(FTs, payload):
        return None, 'contact_invalid'
    return EndEffCert(x_rel, r_tcp, c, FTs.wrench, lease=base_cert.lease), 'ok'

def com_shift(payload, q_hat):
    # 负载与臂构型导致的质心偏移，回馈 LMG 稳定裕度
    return (mass_arm(q_hat)*x_arm(q_hat) + payload.m*x_tcp(q_hat)) / total_mass()
```

### IP-73 LMG
```
def mode_certificate(sigma, state):
    if sigma == 'W':
        m = wheel_stability_margin(state.contacts, com_shift(state))
        b = wheel_vibration_bound(state.speed, state.terrain)
        R = wheel_reachable_set(state)
    elif sigma == 'L':
        m = zmp_margin(state.support_polygon, com_shift(state))
        b = gait_phase_vibration(state.gait, state.speed)
        R = leg_reachable_set(state)
    else:
        return TransitionCert(conservative=True)   # T 不签发常规证书
    if m < m_min or b > b_max or slip_detected(state):
        return None, 'mode_invalid'
    return ModeCert(sigma, m, b, R, power_model(sigma, state)), 'ok'

def guarded_switch(sigma, sigma_new, state, tau_sw, tau_settle):
    safe = TransitionCert(q_safe=retract_config(state),
                          v_safe=v_trans, footprint=conservative(state))
    execute_transition(sigma_new, safe)            # 期间冻结机械臂
    if not covers(safe, entire_window(tau_sw)):
        return 'abort', 'no_cover'
    wait(tau_settle)
    cert, status = mode_certificate(sigma_new, refresh(state))
    if status != 'ok':
        return 'hold_safe', status                # 保持 W^safe，停走
    return cert, 'switched'
```

### IP-74 WBSA
```
def compose_whole_body(P_t, E_t, L_t, calib):
    if P_t is None or E_t is None or L_t is None:
        return None, 'component_invalid'
    if L_t.sigma == 'T':
        return None, 'transition_no_regular_cert'
    x_w = transform(P_t.x_hat, E_t.x_rel)
    r_w = P_t.radius + calib.L_T * E_t.r_tcp + calib.L_sigma * L_t.b
    if x_w not in transform_set(P_t.x_hat, L_t.R):
        return None, 'out_of_mode_workspace'
    return WholeBodyCert(x_w, r_w, P_t, E_t, L_t), 'ok'

def wbsa_control(P_t, joints, FTs, state, task, lease_e):
    sigma = state.mode
    E_t, s1 = eec_certificate(joints.q_lo, joints.q_hi, P_t, calib, FTs, state.payload)
    L_t, s2 = mode_certificate(sigma, state)
    W_t, s3 = compose_whole_body(P_t, E_t, L_t, calib)
    if 'ok' not in (s1, s2, s3):
        return degrade(freeze_arm='q_safe', slow=1, then='stop', reason=s1 or s2 or s3)
    # 联合误差预算分配：底盘稳姿 vs 末端跟踪
    a_star = solve_joint_action(
        budget=lambda a: P_t.radius + calib.L_T*E_t.r_tcp(a.q_cmd)
                          + calib.L_sigma*L_t.b(a.speed) <= task.r_max,
        energy=lambda a: E(t, a.sigma) >= E_min,
        objective=lambda a: task_reward(a) - c_e*L_t.P(a) - c_s*risk(a))
    if a_star is None:
        return degrade(freeze_arm='q_safe', slow=1, then='stop', reason='no_feasible')
    return a_star, W_t
```

### 全局决策 Π''（在 v24 的 Π' 上扩展）
```
def global_decision_v12(c_t, omega_t, B_t, v_t, M, terms, graph_cert,
                        audit, Q_safe, P_t, joints, FTs, state):
    if not graph_cert.ok:
        return 'fail-closed', 'graph-cert'
    R, status = compose_reward(terms, t, audit)
    if R is None:
        return 'fail-closed', status
    a, W_t = wbsa_control(P_t, joints, FTs, state, task, lease_e)
    if isinstance(a, str):
        return a, W_t                        # degrade 指令
    if not qos_valid(W_t.lease, t) or not R.safety_ok(a):
        return 'fail-closed', 'whole-body-or-reward'
    if requested_switch(v_t):
        cert, s = guarded_switch(state.mode, target_mode(v_t), state, tau_sw, tau_settle)
        if s != 'switched':
            return 'hold-safe', s
    B_prob = safety_bind(v_t, W_t, omega_t)   # 绑定在 TCP 而非仅 base
    if B_prob < theta_safe:
        push(Q_safe, v_t)
        return a, 'queued'
    return a, 'execute'
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| EECC 证书合成 | O(n³) FK+雅可比（或 O(n) 区间传播） | O(n) | 关节区间+Lipschitz ⇒ TCP 半径覆盖真值 |
| LMG 模式证书 | O(|contacts| + |polygon|) | O(|V|) | m_σ/b_σ/R_σ 实测满足 ⇒ 模式 soundness |
| WBSA 合成 | O(1) 证书级 + O(solve) 动作 | O(1) | 组件有效且模式一致 ⇒ 联合 soundness |
| 切换守卫 | O(1) 协议 + τ_settle 等待 | O(1) | W^safe 覆盖窗口 + 新模式实测 ⇒ 原子切换 |

正确性定理：设定 P_t、E_t、L_t 的覆盖率分别为 1−α_p、1−α_e、1−α_l，且 W_t 使用联合 conformal 校准吸收共享标定/IMU 误差，则当三段证书在同一时刻有效、模式一致且 TCP 落在 T(x̂_b)R_σ 内时，联合证书满足 P(x^{tcp,true}_w∈W_t) ≥ 1−(α_p+α_e+α_l+α_comp)。任何组件失效、模式不一致、TCP 越界、能量租约失效或切换未完成，Π'' 均不执行任务动作，而是按“冻结臂→降速→停走”的降级链 fail-closed。误差预算约束保证 r_b+L_T r_tcp+L_σ b_σ≤r_task 时任务精度需求与安全半径不冲突。

## 4. 实验设计 E121–E126

| 实验 | 指标 | 门槛 |
|---|---|---|
| E121 TCP 证书覆盖率 | 经验覆盖率、半径松紧度 | 覆盖 ≥ 1−α_e；半径不超真值误差 2× |
| E122 模式半径校准 | 轮式/足式分别覆盖率、足式步态相位分层 | 各模式覆盖 ≥ 1−α_l；相位最差层 ≥ 0.98 |
| E123 全身合成 soundness | TCP 越界次数、联合覆盖率 | 越界 0；覆盖 ≥ 1−(α_p+α_e+α_l+α_comp) |
| E124 模式切换安全 | 过渡失败次数、臂冻结正确率、停走次数 | 失败 0；冻结正确 100%；停走可解释 |
| E125 误差预算分配 | 跟踪误差 vs 稳定裕度 Pareto、负载突变恢复 | 无预算越界；恢复 < 200ms |
| E126 100h 轮足闭环 | 安全违例、任务成功率、切换次数、能耗 | 违例 0；成功率 ≥ 95%；能耗不超基线 10% |

回退策略：E121 覆盖不足 → 放大 r_tcp 并降低臂速；E122 足式某相位覆盖不足 → 该相位禁用伸展构型；E124 过渡失败 > 0 → 强制 τ_sw 内收拢 + 两步停走；E125 预算冲突 → 优先安全半径，降级任务精度而非放宽 r_max；E126 能耗超限 → 减少模式切换频率，优先轮式。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| FK 雅可比谱范数被低估 | 高 | 用区间/采样上界，独立审计集验证 r_tcp 覆盖 |
| 接触滑移检测延迟 | 高 | 力/力矩+视觉滑移双通道，超时即撤销 E_t |
| 过渡窗口振动包络低估 | 高 | 实测过渡包络标定 b_σ，守卫期冻结臂到 q_safe |
| 负载突变导致质心漂移 | 中 | 在线质量/质心辨识，稳定裕度按最坏负载计算 |
| 模式证书过保守导致频繁停走 | 中 | 自适应 m_trans 但安全优先，允许降速轮式而非放开半径 |
| 三段证书时间不同步 | 中 | 统一时间戳与 QoS 代际号，跨代组合一律作废 |

## 6. 本轮最大风险

**一句话**：模式切换守卫可能低估轮↔足过渡窗口内的机身振动与足端滑移，而机械臂控制器又会用“压 TCP 误差”去补偿底盘抖动，导致过渡期间全身证书半径被系统性低估、TCP 静默越界；因此必须以实测过渡包络标定 b_σ 与 L_σ，切换期间强制冻结机械臂到安全构型并在任何分量失效时 fail-closed。
