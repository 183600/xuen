### 第 5 轮灵感驱动研究记录

**灵感词**：数据规模、示教学习

**继承关系**：第 4 轮 CADVS-v4（IP-489~492）在 v3 五锚点之上追加价值锚 VACK（kc_val）与平衡锚 BCK（kc_bal），形成七硬门 kc_evidence_forged_v4，并以「执行集单调收缩」Exec_CADVS-v4 ⊆ Exec_CADVS-v3 ⊆ … ⊆ Exec_v29 作为安全叙事。本轮不推翻 v4，而是指出它忽略的两个维度：**证据是有「量」的（数据规模）**、**规则的源头是「人」的示范（示教学习）**。据此形成 CADVS-v5（IP-493~496），并**把 v1~v4 的「集合单调收缩」升级为「风险单调扩张」**：执行集可以随数据增长而合法扩张，但认证风险界只降不升。

**直觉与动机**：

1. **数据规模的直觉：每一道硬门其实都是一次有限样本的统计检验，但 v4 的阈值是「数据无关」的常数**。kc_val 的 α_val ≥ 0.6、kc_bal 的边际 > 0、MSRG 的 μ_pass ≥ 0.75，都隐含「样本足够、模型可信」。当示教/校准数据只有几十条时，同一阈值要么过度拒绝（fail-closed 但系统瘫痪），要么过度放行（假安全）。正确做法是让阈值随样本量 n 收缩：τ_i(n_i) = τ_i^0 + c_i·√(log(1/δ_i)/(2n_i))（Hoeffding/Bernstein/Clopper–Pearson 修正），并给出「认证错误上界」err_i(n_i)。数据规模由此从背景假设变成一等公民：它决定了每道门能「买到」多少置信度。

2. **示教学习的直觉：规则不是天上掉下来的，它们来自人的示范；v4 的「教师介入」本质是一次示教查询**。于是有两个新问题：(a) 当前状态-动作 (s,a) 是否落在示教分布的支撑内？落在支撑外时，任何基于示范学到的评分器都不可信，必须 fail-closed 或查询教师——这正是**示教覆盖门 kc_demo**。(b) 示教数据不是免费午餐：行为克隆的复合误差 J(π_BC) ≤ J(π*) + O(εT²)，而 DAgger 式交互示教只需 O(εT)；因此「教师查询预算 B_T」是一种**安全资源**，查询策略应按信息增益/成本择优。

3. **单调收缩悖论**：v1~v4 宣称执行集只缩不涨。但一条曾因「数据不足/证据缺失」被拒的规则，在积累足够示教数据后本应被**重新授信**；若永远只缩，系统会越跑越保守直至无法行动。v4 的定理在数学上没错，却在工程上把「暂时不确定」错当成「永久不安全」。本轮给出解法：区分**安全门（只缩）**与**证据再铸（可扩）**，用保形预测（conformal prediction）与 anytime-valid 风险账本，证明「扩张是安全的当且仅当扩张由数据支持的证书背书」。安全叙事从「集合单调」改为「风险单调」。

**关键洞见**：**数据规模 ≠ 数据覆盖**。示教学习最危险的错觉是「再多采一些同样的示教就安全了」——若示范分布不覆盖部署分布（协变量漂移），有效样本量 n_eff = (Σŵ)²/Σŵ² 会远小于名义 n，保形证书在安全关键尾部失效。因此 v5 的核心不是「堆数据」，而是「用保形证书把数据规模兑换为可认证的覆盖，并用风险账本约束执行集的扩张」。八硬门 kc_evidence_forged_v5 = kc_evidence_forged_v4 ∧ kc_demo；软评分 ECS_v5 = ECS_v4 · η_demo；执行集不再嵌套，但认证风险界 B_R(n) 非增。

**形式化目标（增量）**：
1. 定义示教覆盖证书 DCC = (Γ_α, p_val, ŵ, n_eff, κ_demo, t)，及硬门 kc_demo = (Γ_α = {pass} ∧ shift_ok)，软因子 η_demo = 1 − ambiguity_rate。
2. 定义数据规模缩放律 err_i(n) = C_i n^{−α_i^s} 与分布无关界 err_i(n) ≤ err_hat + √(log(2/δ_i)/(2n))，给出各门最小样本量 n_i^min。
3. 定义样本预算分配器 SBA：min Σ c_i n_i s.t. Σ_i err_i(n_i) ≤ δ_total（可分离凸规划，water-filling/KKT 求解）。
4. 定义风险单调安全扩张定理：对任意 n，R(n) = P(fail|accept) ≤ Σα_i；嵌套校准集下 anytime-valid 上界 B_R(n) 非增；存在严格扩张 x ∉ Exec(n−1) ∧ x ∈ Exec(n) 且不抬高 B_R。
5. 定义示教缩放律：BC 复合误差 O(εT²) vs DAgger O(εT)，教师查询预算 B_T 与主动查询准则 Q(s)。
6. 定义 EFA-v5：八硬门 + 风险账本 + 主动示教查询，ECS_v5 = ECS_v4 · η_demo。
7. 明确 v5 与 v4 的关系：Exec_CADVS-v5 不再 ⊆ Exec_CADVS-v4（可扩张），但 B_R^{v5}(n) ≤ B_R^{v4} + α_demo 且随 n 非增。

**本轮最大风险**：风险单调扩张定理依赖示教/校准数据与部署分布的可交换性，而闭环部署的协变量漂移恰在安全关键尾部破坏该假设，使证书过度自信地扩张执行集——数据越多，反而可能越危险。

### IP-493 DC3K：示教覆盖保形核（准入/歧义时，评分推理异步 ~1–10 ms）

```python
@dataclass
class DemonstrationCoverageConformalKernel:
    """DC3K：保形预测给出分布无关覆盖；密度比校正协变量漂移；kc_demo 硬门"""
    alpha_demo: float = 0.05
    w_max: float = 10.0                 # 密度比上界，超过即视为支撑外
    scorer: Any = None                  # p_hat(pass | s,a)
    calib_scores: np.ndarray = None     # A_i = 1 - p_hat(y_i | x_i)，已排序
    density_ratio: Any = None           # ŵ(s,a) 估计器
    competence: Any = None              # κ_demo(s,a) 示教质量权重

    def _nonconformity(self, s, a, y: str) -> float:
        p = self.scorer.predict_pass_prob(s, a)
        return 1.0 - (p if y == 'pass' else 1.0 - p)

    def p_value(self, s, a, y: str) -> float:
        Aq = self._nonconformity(s, a, y)
        n = len(self.calib_scores)
        # 有序分数二分，O(log n)
        return (1.0 + float(np.sum(self.calib_scores >= Aq))) / (n + 1.0)

    def prediction_set(self, s, a) -> set:
        G = set()
        for y in ('pass', 'fail'):
            if self.p_value(s, a, y) > self.alpha_demo:
                G.add(y)
        return G

    def kc_demo(self, s, a) -> tuple[bool, dict]:
        G = self.prediction_set(s, a)
        w = float(self.density_ratio.predict(s, a))
        shift_ok = w <= self.w_max
        ok = (G == {'pass'}) and shift_ok
        return ok, {'Gamma': G, 'w': w, 'shift_ok': shift_ok}

    def eta_demo(self, window: list[set]) -> float:
        # 软因子：滑动窗内歧义率越低越接近 1
        amb = float(np.mean([len(G) != 1 for G in window])) if window else 0.0
        return 1.0 - amb

    def _weighted_valid(self, s, a) -> bool:
```

### IP-494 SBA：样本预算分配与自适应阈值（离线/慢时域）

```python
@dataclass
class SampleBudgetAllocator:
    """SBA：认证错误缩放律 + 样本预算分配 + 数据规模自适应阈值"""
    delta_total: float = 0.05
    eps: dict = field(default_factory=dict)        # eps[i] 目标认证错误
    scaling: dict = field(default_factory=dict)    # scaling[i] = (C_i, alpha_i^s)
    cost: dict = field(default_factory=dict)       # c_i 单样本成本

    def min_samples(self, i: int) -> int:
        C, a = self.scaling[i]
        return int(np.ceil((C / self.eps[i]) ** (1.0 / a)))

    def distribution_free_samples(self, i: int) -> int:
        # 无幂律先验：Hoeffding n >= log(2/delta_i) / (2 eps_i^2)
        delta_i = self.delta_total / max(len(self.eps), 1)
        return int(np.ceil(np.log(2.0 / delta_i) / (2.0 * self.eps[i] ** 2)))

    def adaptive_threshold(self, i: int, n_i: int, tau0: float, sigma_i: float) -> float:
        delta_i = self.delta_total / max(len(self.eps), 1)
        return tau0 + sigma_i * np.sqrt(np.log(2.0 / delta_i) / (2.0 * n_i))

    def allocate(self, budget: float) -> dict:
        # 可分离凸规划：min Σ c_i n_i  s.t. Σ_i err_i(n_i) <= delta_total
```

### IP-495 SAFEEXP：风险账本与安全扩张（控制环内 O(1)）

```python
@dataclass
class SafeExpansionLedger:
    """SAFEEXP：约束执行集扩张不抬升 anytime-valid 风险界"""
    alpha_total: float = 0.10
    e_process: float = 1.0
    history: list = field(default_factory=list)

    def try_expand(self, x, gamma: set, balance_ok: bool, delta_hat: float) -> bool:
        # 仅当保形置信单例 pass 且平衡门通过时，才考虑扩张
        if gamma != {'pass'} or not balance_ok:
            return False
        # e-process 更新；Ville 不等式保证任意时刻误扩张概率受控
        self.e_process *= (1.0 + max(delta_hat, 0.0))
        if self.e_process >= 1.0 / self.alpha_total:
            self.e_process = 1.0          # 重置窗口
            return False                  # 触发一次保守收缩（fail-closed）
        self.history.append((x, gamma, delta_hat))
        return True

    def risk_bound(self, n_eff: float) -> float:
        # B_R(n) = alpha_total + C/sqrt(n_eff)，随 n_eff 非增
        return self.alpha_total + 1.0 / np.sqrt(max(n_eff, 1.0))
```

### IP-496 EFA-v5：八硬门 + 主动示教 + 自适应阈值

```python
@dataclass
class EvidenceForgingAssemblerV5:
    """EFA-v5：八硬门 fail-closed + 风险账本；ECS_v5 = ECS_v4 · η_demo"""
    scf: SpatialCoverageFieldKernel
    msrg_cache: dict
    hic: HumanIntentCertificateKernel
    eek: EndEffectorFidelityKernel
    ltem: LongTermEpisodicMemory
    vack: ValueAlignmentCertificateKernel
    bck: BalanceControlKernel
    dcc: DemonstrationCoverageConformalKernel
    sba: SampleBudgetAllocator
    ledger: SafeExpansionLedger
    mu_S: float = 0.75

    def hard_gate_v5(self, x, t_now, rule_id, hic, eec: EEC, bcc: BCC,
                     s, a, traj: Trajectory, context: Context) -> tuple[bool, str]:
        # 优先级：HIC veto > 其余七硬门（并行评估，任一失败即拒）
        if self.hic.veto_active(hic):             return False, 'HIC_STOP'
        if not self.scf.kc_coverage(x, t_now):    return False, 'COVERAGE_BLIND'
        s2rc = self.msrg_cache.get(rule_id)
        mu_thr = self.sba.adaptive_threshold(rule_id, s2rc.n if s2rc else 0, self.mu_S, 0.05)
        if s2rc is None or s2rc.verdict != 'accept' or s2rc.mu_pass < mu_thr:
            return False, 'PHYSICS_UNPROVEN'
        if not self.eek.kc_ee(eec):               return False, 'EE_UNPROVEN'
        if not self.bck.kc_bal(bcc):              return False, 'BALANCE_UNSTABLE'
        pass_mem, eta_mem, novelty = self.ltem.query(object_class, geo_sig, theta_fp, rule_id)
        if not pass_mem:                          return False, 'MEMORY_REJECT'
        vac = self.vack.evaluate(traj, context, t_now)
        if not self.vack.kc_val(vac):             return False, 'VALUE_MISALIGNED'
        ok_demo, info = self.dcc.kc_demo(s, a)    # 第 8 门
        if not ok_demo:
            if info['Gamma'] != {'pass'}:         return False, 'DEMO_UNCOVERED'
            return False, 'DEMO_SHIFT'
        return True, 'FORGED' + ('|NOVELTY' if novelty else '')

    def active_query(self, s, budget_left: int) -> bool:
        # 主动示教：歧义点若信息增益/成本优于备选且预算未耗尽，则查询教师
        return budget_left > 0 and self._info_gain(s) / self._cost(s) > self._best_alt(s)

    def ecs_v5(self, x, t_now, rule_id, A_att=0.0, eta_mem=0.5, eta_val=0.5,
               eta_bal=0.5, eta_demo=0.5) -> float:
        base = self.ecs_v4(x, t_now, rule_id, A_att, eta_mem, eta_val, eta_bal)
        return base * eta_demo
```

## 4. 正确性论证（增量更新）

### 引理 43（协变量漂移下的保形覆盖）

**陈述**：设校准 (X_i,Y_i) iid P_cal，测试 (X,Y) ~ P_t，非一致性分数 A。若密度比 w = dP_t/dP_cal 已知，加权保形满足 P(Y ∈ Γ_α) ≥ 1−α；若用无加权保形且 w ≤ w_max，则 P(Y ∈ Γ_α) ≥ 1−α/w_max；若 ŵ 有估计误差，则覆盖至少 1−α−TV(P_t,P_cal)。

**证明**：加权可交换性 + 标准保形论证（Tibshirani et al. 2019）；TV 项由 Le Cam 不等式。∎

**工程含义**：kc_demo 的「覆盖」不是名义 n 的函数，而是 n_eff 与漂移的函数；漂移超界时保形保证失效，必须 fail-closed（DEMO_SHIFT）。

### 引理 44（示教缩放律与复合误差）

**陈述**：设监督误差 ε、时域 T。(a) BC：J(π_BC) ≤ J(π*) + O(εT²)；若 ε = O(√(d/n))，则超额 ~ O(T²√(d/n))。(b) DAgger：J ≤ J* + O(εT)，达到同精度所需专家查询数比 BC 少 O(T) 量级。(c) 因果混淆：若示范存在与动作虚假相关、相关强度 ρ 的混杂特征，则 BC 渐近误差 ≥ cρ（不随 n 增大而消失）。

**证明**：(a)(b) 见 Ross & Bagnell 2010 / Ross et al. 2011 的复合误差分析；(c) 由反例构造：虚假特征在有限样本下被拟合并主导，纯观测示教无法识别因果父节点。∎

**工程含义**：数据规模只能降方差，不能消偏差；kc_demo 的支撑必须是「因果充分」的示范支撑，需 IRL/干预增强来保证可辨识性。

### 引理 45（有效样本量与覆盖的分离）

**陈述**：n_eff = (Σŵ_i)²/Σŵ_i² ≤ n；若校准与目标在质量 m 的区域不相交，则 n_eff/n ≤ 1−m。故「数据规模 ≠ 数据覆盖」。

**证明**：Cauchy–Schwarz 给出 (Σŵ)² ≤ n Σŵ²，故 n_eff ≤ n；Kish 有效样本量性质给出不交区域上的上界。∎

**工程含义**：SBA 必须以 n_eff 计预算；盲目增加同分布示教对覆盖无益。

### 定理 5（风险单调安全扩张）

**陈述**：设八门各自保形/统计有效，总显著性 Σα_i = α_total。(i) 对任意 n，R(n) = P(fail|accept, n) ≤ α_total。(ii) 若校准集嵌套且风险账本采用 anytime-valid e-process，则 B_R(n) 非增。(iii) 存在严格扩张：∃n, x，x ∉ Exec(n−1) 且 x ∈ Exec(n)，且该扩张不抬高 B_R。

**证明**：(i) 逐门覆盖 + 联合界。(ii) Ville 不等式给出 B_R(n) = α_total + O(√(log n / n))，单调下降。(iii) 取在 n−1 时 Γ = {pass,fail}（歧义→fail-closed）、新增一个校准点后 Γ = {pass}（单例）的点 x；加入该点不破坏覆盖有效性，故风险界不变。∎

### 定理 v5（八硬门 + 风险单调扩张 + 示教覆盖）

**陈述**：在 (B1)~(B6)（继承 v4）及 (B7) 校准-部署可交换或密度比有界、(B8) 示范因果可辨识 下：
(i) R_v5(n) ≤ α_total，∀n；
(ii) B_R(n) 非增；Exec_CADVS-v5 不再 ⊆ Exec_CADVS-v4（允许扩张），但每次扩张均有证书背书；
(iii) 示教覆盖门将漂移下的假安全率降低至少 α_demo 量级（引理 43）；
(iv) 认证一个质量 μ 区域所需有效样本 n_eff ≥ Ω(log(1/δ)/(μ·α_demo²))（覆盖样本复杂度）。

**证明**：(i)(ii) 由定理 5；(iii) 由引理 43；(iv) 由 DKW 界：以 1−δ 置信估计区域覆盖需 n ≥ log(2/δ)/(2ε²)，ε 为覆盖误差，对质量 μ 区域再乘 1/μ。∎

**诚实声明**：(B7) 在非平稳闭环中很难满足；(B8) 因果可辨识需要干预数据，纯观测示教无法保证。缓解：加权保形 + 漂移检测 + 主动干预查询；漂移超界时无条件 fail-closed。这也意味着 v5 的安全性上界比 v4 的「集合嵌套」更弱（是概率性的、依赖假设的），换来的是可扩张、可恢复的实用性。

## 5. 实验设计与初步结果（计划中，第 5~6 轮实机）

- **示教来源**：遥操作/脚本专家（含 10%~30% 次优示范以测 κ_demo），DAgger 交互式教师。

## 7. 本轮最大风险（最终确认）

**一句话**：**风险单调扩张定理依赖示教/校准数据与部署分布的可交换性，而闭环部署的协变量漂移恰在安全关键尾部破坏该假设，使证书过度自信地扩张执行集——数据越多，反而可能越危险。**
