# 第 71 轮（承接第 70 轮「BELIEF-RAS 贝叶斯估计交互消歧」IP-264~274；灵感循环新循环第 1 轮；本轮灵感：「单模型多任务」×「跌倒恢复」）

> R70 把闭环推到显式世界后验 b_t，并证明 BELIEF ⊃ FLUID ⊃ R68：安全侧层层不让步，效率侧拿 resolution bonus。但这个包含关系有一条从未写进假设的前提——**机器人始终处在「标称运行流形」内**：策略有定义、安全集近似凸、"慢下来"总是安全的、b_t 的观测模型失配可控。
>
> **跌倒恢复恰好是这条前提的反例，而且是最危险的那类反例**：状态被抛出训练分布，安全集非凸甚至不连通，"慢下来"不再是安全动作——你没法以 0.5 的速度完成一次翻滚起身；风险主成分从「歧义」变成「不可逆性」（撞头、关节过载、自碰撞、二次跌落）。R68–R70 的 λ_floor 在跌倒瞬间会施加**恰好相反**的指令。
>
> 本轮两个灵感正好补上两块：
> - **单模型多任务**：跌倒样本稀少、形态多样，独立恢复模型既训不起也覆盖不全；共享 trunk 用 locomotion/manipulation 的海量数据托举稀有恢复任务。但共享也让任务梯度在同一表征上打架，并让一个任务的动作泄漏进另一个任务。
> - **跌倒恢复**：它不是"再加一个任务"，而是**一个新风险体制（risk regime）**——安全语义、不确定性语义、时间语义同时改变。把它当成标称任务的低权重版本，是 R68–R70 框架最深的盲点。
>
> 核心命题：**把「任务（做什么）」与「风险体制（正处在什么危险状态）」解耦。单模型多任务提供共享表征与无冷启动的快速模式切换；RISE-RAS 在其上加一层「体制证书」：只有当前体制被可校准地识别、该体制安全包络被认证、且动作不把系统带出「可恢复区域」时才执行；体制不可辨时，退化为「最小不可逆性」动作，而不是「最小速度」动作。** 命名 **RISE-RAS**（Regime-switching, Irreversibility-aware, Single-model Emergency-recovery）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「测量准吗」，R69 问「向谁求证」，R70 问「世界是什么状态」，R71 问「**我处在哪个风险体制、还来不来得及站起来**」。

## 0. 直觉与动机

**灵感 1（单模型多任务 → 共享表征是稀有事件的样本放大器，也是故障的共享总线）**
直觉：跌倒恢复数据昂贵且长尾，单靠 recovery 任务训不出稳健表征；但 locomotion 天天在学"保持直立、接触、平衡"，这些恰恰是恢复所需的物理先验。共享 trunk 让稀有任务搭常见任务的便车（正迁移）。代价是双向的：任何标称任务的梯度都可能侵蚀恢复头（负迁移/灾难性遗忘），任何恢复专用的强动作 latent 也可能在标称时泄漏。更关键的是**时间**——独立恢复控制器需要加载、切换、冷启动，而跌倒以毫秒计；单模型可以在同一次前向里连续产出"刹车→支撑→起身"的动作，**模式切换是连续的而不是加载的**。这既是效率优势，也是安全难点：切换无需显式 staging，也就没有天然的"切换检查点"。

**灵感 2（跌倒恢复 → 风险不是标量，"慢"不是安全方向的同义词）**
直觉：R68–R70 的保守主义建立在"λ 越小越安全"的单调性上。这在高空走钢丝时成立，在跌倒时不成立：跌倒需要**足够的力矩、足够的反应速度、足够大的动作幅度**才能把质心拉回支撑多边形；把动作缩到 0.3 倍，只会让你以优雅的姿态摔得更彻底。安全在跌倒体制里是一个**双向带** [λ_min, λ_max]：太猛会撞头，太软会站不起来。这是对前四轮"单向收紧"哲学的一次根本修正——不是更保守，而是**换个方向保守**。

**灵感 3（可恢复性 → 真正的安全变量是"还来不来得及"）**
直觉：跌倒不是一个二值事件，而是一条不可逆性递增的路径。与其问"当前动作风险多大"，不如问"从当前状态出发，预算内成功回到标称流形的概率还剩多少"——即**可恢复性价值 V_rec**。V_rec 低于阈值的状态构成"不可回头点（point of no return, PNR）"。这给出一条主动安全律：**不要去那些你站不起来的地方**。标称运行不应只满足 CBF，还应满足 V_rec ≥ R_min 的"可恢复约束包络"。这把安全从"避免碰撞"升级为"保留退出选项"——安全是一张期权，不能为了短期任务收益把它卖掉。

**灵感 4（体制是一等公民 → 前序工作是新框架的标称切片）**
直觉：BELIEF/FLUID/R68 都是 nominal regime 下的策略。RISE 不是并列替代，而是在体制空间上的**切换超结构**：当体制后验高置信地落在 nominal、且 V_rec 充足时，RISE 逐指令等于 BELIEF（严格包含原则不破）。新增能力只出现在 perturbed/falling/grounded/recovering 这些前序框架从未形式化的体制里。这样每加一层仍然只多一个可审计的边界，而不是多一个需要整体重训的黑箱。

**灵感 5（单模型的安全认证 → 需要显式的"干扰证书"与"模式边际"）**
直觉：认证一个多任务网络，不能对每个任务各出一张证书就算了——共享参数让任务之间可以互相污染。必须同时证明三件事：(a) 每个任务的包络成立；(b) 跨任务干扰被上界约束；(c) 当前体制的判定有足够边际。三者任一不满足就弃权。但弃权在跌倒里不能是"什么都不做"（你已经在摔了），只能是**最小不可逆性动作**（护头、顺势、增柔顺），这与标称里的"停住"是两种完全不同的回退。**"回退"这个动作本身的语义，也是体制相关的。**

**灵感 6（就绪是会过期的 → 恢复能力需要像灭火器一样被定期检查）**
直觉：一个模型在标称任务上训得越久，恢复头可能越退化（灾难性遗忘），而你恰恰在跌倒那一刻才发现。R70 的审计是事后的。本轮加一个**想象式演练 RRR**：在低频率、在学得世界模型里，从当前标称状态注入跌倒扰动，检查单模型能否在预算内恢复；若不能，就**主动收紧标称包络**。这是在"不写真实系统"的约束下，把"恢复就绪"变成一个可在线监控、可前瞻干预的量——把"能不能站起来"从运气变成运行时不变量。

## 1. 形式化定义（增量：定义 326–344）

**定义 326（RISE-RAS 总览）** RISE-RAS = (UMA, RCD, IRV, RSP, MTG, TEB, RRR, MIB, BELIEF-RAS†, RAS-WM†)。三不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **体制认证**：执行动作必须属于当前被认证体制的包络 𝒰_r，且体制后验置信 c_t ≥ τ_mode；否则只允许最小不可逆性回退 MIB；
(iii) **可恢复约束**：标称动作须使后继状态留在可恢复集 S_rec = {s : V_rec(s) ≥ R_min}，不得以牺牲退出选项换取短期任务收益。

**定义 327（统一多任务模型 UMA）** 共享 trunk Φ_θ: 𝒪→𝒵；任务头 h_τ: 𝒵→𝒜_τ，τ ∈ 𝒯 = {locomotion, manipulation, fall_detect, brace, recover, getup}。联合策略 π_θ(a, τ | o)。关键区分：**任务 τ 回答"我在做什么"，体制 r 回答"我正处在什么危险状态"**；二者经状态与事件耦合，但不可互相替代（同一 locomotion 任务可横跨 nominal 与 recovering 两个体制）。恢复头复用同一 trunk，因此无独立加载延迟、无冷启动。

**定义 328（风险体制空间）** r ∈ ℛ = {nominal, perturbed, falling, grounded, recovering}，另设吸收失败态 ⊥（不可恢复）。每个 r 配备安全集 S_r ⊆ 𝒮、风险泛函 ρ_r、包络 𝒰_r(s) ⊆ 𝒜、时间常数 τ_r。体制转移由首达事件与后验共同触发：r_{t+1} = δ(r_t, event_t, p(r | o_{1:t}))。

**定义 329（体制后验与校准弃权 RCD）** 由 R70 世界后验边缘化得 p(r | o_{1:t}) = Σ_s b_t(s)·[s ∈ S_r]。置信 c_t = max_r p(r | o_{1:t})。RCD 须校准（ECE_regime ≤ τ_regime）。若 c_t < τ_mode 且各体制最优动作的不可逆性差异超过 Δ_irr，则禁止按最大后验执行，转 MIB（定义 338）。**体制判定本身是一个 epistemic 问题，直接复用 R70 的 b_t 与 R69 的 VoI。**

**定义 330（可恢复性价值 IRV）** V_rec(s) = P(∃ t ≤ T_rec : s_t ∈ S_nominal ∧ 全程 damage = 0 | s_0 = s, π_recover)，或折扣回报形式 E[Σ_k γ^k · 1{recovered by k}]。定义不可回头集 PNR = {s : V_rec(s) < R_min}，可恢复集 S_rec = 𝒮 ∖ PNR。V̂_rec 由 UMA 在学得世界模型中的短程 rollout 估计（想象，不写真实系统）。

**定义 331（不可逆性风险泛函）** ρ_irr(s, a) = E[damage(s')] + α(1 − V_rec(s')) + β·P_selfcoll(s') + η·E[peak_contact_force]。它是 fall 体制的主风险，区别于标称的任务误差 ρ_task。**核心性质：不可逆性单调——损伤一旦发生，不能用后续动作补偿。** 因此 fall 体制的优化目标不是"期望任务损失最小"，而是"最坏不可逆损失最小"。

**定义 332（双向风险缩放带 RSP）** 标称体制沿用 λ_floor 单边下界 λ ∈ [λ_floor, 1]；falling/recovering 体制改用**双向带** λ ∈ [λ_min(r), λ_max(r)]，其中 λ_min(r) > 0 是"最小紧迫度"（低于它无法产生足够的质心修正/翻身冲量），λ_max(r) 由冲击/自碰撞上界给出。安全不再等价于"更慢"；引理 25 给出 λ_min 的必要性，并说明这是对 R68–R70 单调保守主义的边界修正。

**定义 333（体制条件安全包络）** 𝒰_r(s) = {a : CBF_r(s, a) ≥ 0 ∧ 力矩/力/冲量 ∈ ℬ_r ∧ 接触构型 ∈ 𝒞_r}。不同体制的 CBF 不可复用：标称 CBF 约束"不跌倒"，恢复 CBF 约束"跌倒过程不造成不可逆损伤并最终站起"。跨体制相容性要求存在桥接动作（定义 334）。

**定义 334（切换无突变 / 桥接动作）** 体制切换 r→r' 需存在一个控制周期内的 a_b 同时满足 𝒰_r(s) ∩ 𝒰_{r'}(s)，或一条被认证的过渡轨迹 ξ_b，使包络切换不产生指令跳变。若不存在，则切换必须推迟，并在推迟期内保持 𝒰_r。继承 R68 定理 15 的提交/换装不变式的体制版。

**定义 335（任务干扰证书 MTG）** 对任务 τ，记共享梯度 g_τ = ∇_θ L_τ，干扰 I(τ, τ') = 1 − cos(g_τ, g_τ')。证书要求存在 κ 使每个任务头 ‖Δh_τ‖ ≤ ε_τ + κ·Σ_{τ'≠τ} I(τ, τ')·‖g_{τ'}‖。当证书不成立，触发梯度手术/任务适配器/临时冻结恢复头，并在 J_RISE 标记 degraded。**特别地：locomotion 的"保持直立、刚性强"与 recover 的"顺势倒下、增柔顺"天然反相关，I 偏高——这正是单模型最危险的耦合，也是必须显式认证它的理由。**

**定义 336（恢复就绪演练 RRR）** 以周期 T_r3、对当前状态 s_t 注入跌倒扰动族 𝒟_fall（推、绊、失稳、传感器饱和）后，用世界模型 + UMA 采样恢复轨迹，估计 V̂_rec 并记录失败模式。若 min_{d∈𝒟} V̂_rec(s_t | d) < R_min + margin，则收紧标称包络 S_rec ← S_rec ∩ {V̂_rec ≥ R_min + margin}。零真实写操作，纯想象；结果回灌 MTG/TEB。

**定义 337（恢复预算 TEB）** 恢复需消耗时间 T_rec、能量 E_rec、关节热/力矩 RMS 预算 Θ_rec。若当前状态下任一预算不足以完成恢复，则该状态并入 PNR 的保守估计。预算随电池/温度/磨损在线更新——**可恢复性不是纯几何量，它随"体力"衰减。**

**定义 338（最小不可逆性回退 MIB）** 当 c_t < τ_mode 或证书失效时，a* = argmin_{a ∈ ⋂_{r∈ℛ_amb} 𝒰_r(s)} max_{r∈ℛ_amb} ρ_irr,r(s, a)。若交集为空（无动作可同时安全），执行"保护性支撑"：护头、限关节速、增柔顺、最小化峰值接触力。**MIB 不是"什么都不做"——在 falling 体制里，"什么都不做"本身就是最大不可逆性动作。**

**定义 339（非对称跌倒判定）** 跌倒判定损失 C_FN ≫ C_FP（漏报远贵于误报），但误报也非免费——频繁误触恢复会劫持 locomotion（恢复 DoS）。工作点应随 V_rec 与 TEB 动态调整：越接近不可恢复，判定阈值越低（越倾向判 falling）。引理 27 证明该动态阈值是贝叶斯最优的。

**定义 340（AIC-FALL）** 新增干扰集：任务干扰/负迁移、模式混淆（绊一下 vs 真跌倒、跌倒 vs 主动躺下、被推 vs 自主失衡）、冲击瞬间传感器饱和、对抗性假跌倒（伪造 IMU 触发恢复 DoS）、恢复头遗忘。并入 AIC：ℰ_RISE = ℰ_BELIEF × ℰ_interfere × ℰ_regime × ℰ_impact。

**定义 341（证书 J_RISE）** J_RISE = (J_BELIEF, ECE_regime, c_t_traj, V_rec_min, interference_bound_ok, recovery_readiness, transition_cert, budget_ok, rise_ver)。Valid ⇔ Valid(J_BELIEF) ∧ ECE_regime ≤ τ_regime ∧ 体制证书 ∧ 切换桥接 ∧ 预算未越界。

**定义 342（严格包含：标称切片）** 在 c_t ≥ τ_mode、r = nominal、V_rec ≥ R_min 且 MTG 证书成立的条件下，RISE 的动作选择与 BELIEF（进而 FLUID、R68）逐指令相同；RISE 仅在非标称体制与前序未覆盖的不可恢复区域引入新行为。⇒ 安全侧在前序已覆盖的定义域内不让步。

**定义 343（就绪-包络耦合的单调安全）** 若 RRR 估计的 V̂_rec 有偏 ≤ ε_v、世界模型漂移有界，则收紧后的包络 S_rec' 的可恢复性不低于原包络；包络收缩是单调安全的（更小的可行域不会引入新的不可恢复状态）。系：把"恢复能力监控"变成"运行域收缩"这一保守动作，而不是依赖运行时临时反应。

**定义 344（升级映射）** RISE 复用 BELIEF 的 BSE/FMP/AUD/MINT/CIA/FMA/MCG 全部组件；只新增体制层、可恢复层、多任务干扰层与就绪层。BELIEF 的全部 11 个 IP 保留为"标称体制专用"，不重训、不替换。

```python
# IP-275 UMA：单 trunk 多任务头（共享表征，任务适配器隔离干扰）
class UnifiedMultiTaskActor:
    def __init__(self, trunk, heads, adapters):
        self.trunk, self.heads, self.adapters = trunk, heads, adapters

    def forward(self, o):
        z = self.trunk(o)
        return {tau: h(z + self.adapters[tau](z)) for tau, h in self.heads.items()}

    def act(self, o, task):
        z = self.trunk(o)
        return self.heads[task](z + self.adapters[task](z))

# IP-276/277 RCD + IRV：体制后验与可恢复性价值（想象 rollout，off critical path）
def infer_regime_and_recoverability(M, o, b_t):
    p_r = marginalize_regime(b_t)                     # R70 后验 -> 体制后验
    c   = max(p_r.values())
    V   = M.irv.estimate(M.uma, M.wm, o, b_t, N=8, H=M.cfg.T_rec)
    return p_r, c, V

# IP-278 RSP：体制条件、双向风险缩放
def regime_scale(r, V, U_ale, U_epi, lam_nom):
    if r == 'nominal':
        return max(lam_nom, lam_floor(U_ale + U_epi))   # 沿用 R68–R70
    lo, hi = M.cfg.RSP_BAND[r]
    lam = clip(urgency(r, V), lo, hi)                  # 注意 lo > 0
    return lam

# IP-281 RRR：恢复就绪演练（低频，不在控制关键路径）
def readiness_rehearsal(M, o, b_t, disturb_family):
    V = []
    for d in disturb_family:
        s0 = M.wm.inject(o, d)                          # 想象中注入跌倒
        V.append(M.irv.rollout(M.uma, M.wm, s0, H=M.cfg.T_rec))
    worst = min(V)
    if worst < M.cfg.R_min + M.cfg.margin:
        M.envelope.shrink(lambda s: M.irv.estimate(s) >= M.cfg.R_min + M.cfg.margin)
    return worst

# IP-283 MIB：最小不可逆性回退
def minimally_irreversible_fallback(M, o, p_r, V):
    R_amb = [r for r, p in p_r.items() if p > M.cfg.p_amb]
    cand  = [a for a in M.uma.candidate_actions(o)
             if all(M.envelope.satisfies(a, r) for r in R_amb)]
    if cand:
        return min(cand, key=lambda a: max(M.rho_irr(r, a) for r in R_amb))
    return M.protective_brace(o)                        # 护头/增柔顺/限关节速

# IP-286 RISE 主闭环
def RISE_round(M, obs):
    z, o = M.mtm.forward(...); c_cal, U_cal, _ = M.cof.step(...)
    b_t = M.bse.step(M.b_prev, o, M.last_action, M.last_g, M.last_y)   # R70
    p_r, c_regime, V_rec = infer_regime_and_recoverability(M, o, b_t)
    # 1) 恢复就绪演练（低频，仅想象）
    if M.tick % M.cfg.T_R3 == 0:
        M.rrr.readiness_rehearsal(o, b_t, M.cfg.D_FALL)
    # 2) 可恢复约束：标称动作不得离开 S_rec
    allow_nominal = V_rec >= M.cfg.R_min
    r  = max(p_r, key=p_r.get)
    # 3) 体制认证：置信 + 干扰证书 + 包络
    if c_regime >= M.cfg.TAU_MODE and allow_nominal and M.mtg.certified(r):
        lam = regime_scale(r, V_rec, U_ale, U_epi, M.efs.risk_scale(...))
        a   = M.uma.act(o, task_of(r))
        if not M.c_ras_wm.certify_regime(a, r, b_t):
            a = M.mib.fallback(o, p_r, V_rec)
    else:
        r, lam = 'ambiguous', M.cfg.lam_conservative
        a = M.mib.fallback(o, p_r, V_rec)
    # 4) 切换桥接，防指令跳变
    a = M.transition.bridge(M.last_a, a, M.last_r, r)
    # 5) 审计 + 证书
    M.raa.submit_async(b_t, p_r, V_rec, a, M.mtg.last_bound)
    M.last_a, M.last_r = a, r
    return a, r, V_rec
```

## 3. 推导

**引理 23（单模型正迁移—负迁移的分解）** 设共享表征维度 d_z，恢复任务样本 n_rec，常见任务样本 n_nom ≫ n_rec。在梯度范数与干扰 I 有界的假设下，恢复头期望误差满足 E[err_rec] ≤ ε_0/√(n_rec) + c_1·I·√(d_z/n_nom) + ε_head。第一项是独立训练也有的样本项；第二项是共享代价；共享收益体现在 ε_0 的降低（表征先验）。⇒ **当 n_rec 小且 I 低于阈值时单模型严格占优；当"保持直立"与"顺势增柔顺"强反相关（I→2）时，单模型可能劣于分离模型。** 这解释了为什么"单模型多任务"不是免费午餐，必须由 MTG 证书守住——它把 I 从一句口号变成一个可测量、可进证书的量。

**引理 24（可恢复约束的失败概率上界）** 若 V̂_rec 有偏 ≤ ε_v，标称策略保证 s_t ∈ S_rec，则每次跌倒事件的不可恢复概率 ≤ 1 − (R_min − ε_v) + L_v·ε_dyn，其中 L_v 为 V_rec 对状态扰动的 Lipschitz 常数。⇒ 长期不可恢复率随运行时间线性累积，因此必须在**进入** S_rec 边界前就收紧，而不是等 V_rec 触底；RRR 的 margin 正是为此预留的先行量。

**引理 25（双向缩放的必然性 / λ_min > 0）** 在 falling 体制，设质心修正所需最小冲量 J*，可执行冲量 J(λ) = λJ_max，恢复成功概率 P_rec(λ) 在 [0, J*/J_max] 上严格递增。故存在 λ_min = J*/J_max > 0，使 λ < λ_min 时 P_rec 单调下降。⇒ R68–R70 的"λ 越小越安全"只在 nominal 体制成立；跨体制机械套用会**主动制造失败**。这是对前四轮保守主义最重要的一条边界修正：安全不是"更慢"，而是"在正确的方向上用正确的力度"。

**引理 26（模式混淆的弃权最优性）** 设两体制最优动作的不可逆性差为 Δ_irr，模式后验置信 c。按最大后验执行的期望额外不可逆风险 ≥ c(1 − c)·Δ_irr；而 MIB 在交集非空时把该额外风险压到 ≤ (1 − c)·min_a max_r ρ_irr。⇒ 低置信时"选择对两种体制都不太坏的动作"严格优于"押注最可能体制"；交集为空时，护头/增柔顺是唯一有界回退。这也说明为什么 MIB 不能统一实现为"停住"。

**引理 27（可恢复性调制的判定阈值是贝叶斯最优）** 在非对称代价 C_FN ≫ C_FP 下，贝叶斯最优跌倒判定阈值 τ*(V_rec) 随 V_rec 下降而下降：越接近不可恢复，越应倾向判为 falling（宁可误报）。⇒ 定义 339 的动态工作点不是工程拍脑袋，而是可推导的最优策略；注意它与"误报导致恢复 DoS"的代价通过 TEB/预算项共同平衡。

**定理 20（RISE 在标称切片上严格包含 R68–R70）** 在 r = nominal、c_t ≥ τ_mode、V_rec ≥ R_min、MTG 证书成立时，RISE 与 BELIEF/FLUID/R68 逐指令相同（定义 342），故在其已覆盖的定义域内安全侧不让步。RISE 的新增风险只出现在前序未定义的体制与不可恢复区域，且被 MIB 与可恢复约束显式管理。⇒ 新层是旧层的严格泛化，不是并列替代。

**定理 21（切换无突变与恢复可行性）** 若每次体制切换都有桥接动作（定义 334）或认证过渡轨迹，则控制指令连续、无包络越界；且从 falling 到 grounded 的切换可行当且仅当 V_rec ≥ R_min 且 TEB 预算足够。⇒ 恢复不是"更激进的控制"，而是"在预算内被证明可完成的控制"；不可行的恢复会被提前拒绝，而不是在失败中暴露。

**定理 22（就绪演练的主动安全）** 在引理 24 与定义 343 下，若 RRR 以周期 T_r3 验证 V̂_rec ≥ R_min + margin 并据此收缩包络，则在一个漂移界内，系统进入 PNR 的概率被 margin/T_r3 与漂移率共同上界；且包络收缩单调安全。⇒ "恢复就绪"从一次性训练属性变成可持续的运行时不变量——这正是对"能力会过期"的结构性回答。

## 6. 本轮最大风险

**一句话**：RISE-RAS 的全部新增能力押在「体制能被及时且可信地识别、且恢复头在长期标称训练后仍保持就绪」这一前提上，而**能力与可信度在时间上恰好反相关**——跌倒瞬间正是单模型最 OOD、冲击使传感器最饱和、体制后验最不可信、MTG 证书最可能失效的时刻；一旦把 falling 误判为 nominal，系统会施加恰好相反的保守刹车，把可恢复的跌倒变成不可恢复的伤害，**而它还会因为"安全侧不让步"的定理而自信地认为自己没错**。

**次级风险与缓解**：
1. **任务干扰/负迁移**（locomotion 与 recover 反相关）→ MTG 干扰证书 + 任务适配器 + 梯度手术，证书失效即标记 degraded；
2. **恢复就绪过期**（灾难性遗忘）→ RRR 想象式演练 + 包络收缩（定理 22），把能力衰减转成运行域收缩；
3. **模式混淆**（绊 vs 跌、跌 vs 躺、被推 vs 自失衡）→ RCD 校准 + 引理 26 的 MIB 弃权，绝不押注单一体制；
4. **恢复 DoS/假跌倒**（对抗性触发恢复）→ 非对称判定 + 多源一致性 + AIC-FALL 对抗训练（定义 340）；
5. **预算误判**（电量/热限下仍尝试恢复）→ TEB 在线更新 + 预算不足即并入 PNR，主动回避而非硬撑；
6. **定理自证**（"安全侧不让步"只在标称切片成立，却被误读为全局保证）→ J_RISE 显式标注体制与切片，审计拒绝跨切片引用定理 20。

**定义 335（MTG）** 干扰证书如上；不成立则梯度手术/适配器/冻结恢复头，J_RISE 标 degraded。

**定义 336（RRR）** 周期 T_r3 注入 𝒟_fall，估计 min V̂_rec；< R_min+margin 则 S_rec ← S_rec ∩ {V̂_rec ≥ R_min+margin}。纯想象。

**定义 337（TEB）** 恢复预算三元组；任一不足即并入 PNR；预算随电池/温度/磨损在线更新。

**定义 338（MIB）** a* = argmin_{a∈∩𝒰_r} max_{r∈ℛ_amb} ρ_irr,r(s,a)；交集空则保护性支撑（护头/限速/增柔顺/降峰值力）。

**定义 339（非对称判定）** C_FN≫C_FP；τ*(V_rec) 随 V_rec 下降而下降（引理 27 证明最优）。

**定义 340（AIC-FALL）** ℰ_RISE = ℰ_BELIEF × ℰ_interfere × ℰ_regime × ℰ_impact，覆盖负迁移、模式混淆、冲击饱和、假跌倒 DoS、恢复头遗忘。

**定义 341（J_RISE）** 见符号表；Valid ⇔ 全部子证书成立且预算未越界。

**定义 342（标称切片严格包含）** c_t≥τ_mode ∧ r=nominal ∧ V_rec≥R_min ∧ MTG 成立 ⇒ 与 BELIEF/FLUID/R68 逐指令相同。

**定义 343（就绪-包络单调安全）** V̂_rec 有偏≤ε_v、世界模型漂移有界 ⇒ 收缩包络可恢复性不降；包络收缩单调安全。

**定义 344（升级映射）** BELIEF 全组件保留；RISE 只做体制/可恢复/干扰/就绪四层增量。

# IP-275 UMA
class UnifiedMultiTaskActor:
    def __init__(self, trunk, heads, adapters):
        self.trunk, self.heads, self.adapters = trunk, heads, adapters

    def act(self, o, task):
        z = self.trunk(o)
        return self.heads[task](z + self.adapters[task](z))

# IP-276/277 体制 + 可恢复性
def infer_regime_and_recoverability(M, o, b_t):
    p_r = marginalize_regime(b_t)                 # R70 b_t -> 体制后验
    c   = max(p_r.values())
    V   = M.irv.estimate(M.uma, M.wm, o, b_t, N=8, H=M.cfg.T_rec)
    return p_r, c, V

# IP-278 双向缩放
def regime_scale(M, r, V, U_ale, U_epi, lam_nom):
    if r == 'nominal':
        return max(lam_nom, lam_floor(U_ale + U_epi))
    lo, hi = M.cfg.RSP_BAND[r]
    return clip(urgency(r, V), lo, hi)            # lo > 0 是关键

# IP-279 干扰证书
def mtg_certify(M, task):
    for tau in M.tasks:
        bound = M.cfg.eps[tau] + M.cfg.kappa * sum(
            M.interfere[(tau, tp)] * M.grad_norm[tp]
            for tp in M.tasks if tp != tau)
        if M.head_drift[tau] > bound:
            return False
    return True

# IP-281 恢复就绪演练
def readiness_rehearsal(M, o, b_t, disturb_family):
    worst = min(
        M.irv.rollout(M.uma, M.wm, M.wm.inject(o, d), H=M.cfg.T_rec)
        for d in disturb_family)
    if worst < M.cfg.R_min + M.cfg.margin:
        M.envelope.shrink(lambda s: M.irv.estimate(s)
                          >= M.cfg.R_min + M.cfg.margin)
    return worst

# IP-282 最小不可逆性回退
def mib_fallback(M, o, p_r, V):
    R_amb = [r for r, p in p_r.items() if p > M.cfg.p_amb]
    cand  = [a for a in M.uma.candidate_actions(o)
             if all(M.envelope.satisfies(a, r) for r in R_amb)]
    if cand:
        return min(cand, key=lambda a: max(M.rho_irr(r, a) for r in R_amb))
    return M.protective_brace(o)                  # 护头/增柔顺/限关节速

# IP-286 主闭环
def RISE_round(M, obs):
    z, o = M.mtm.forward(...); c_cal, U_cal, _ = M.cof.step(...)
    b_t = M.bse.step(M.b_prev, o, M.last_action, M.last_g, M.last_y)  # R70
    p_r, c_regime, V_rec = infer_regime_and_recoverability(M, o, b_t)
    if M.tick % M.cfg.T_R3 == 0:                  # 低频、仅想象
        M.rrr.readiness_rehearsal(o, b_t, M.cfg.D_FALL)
    allow_nominal = V_rec >= M.cfg.R_min          # 可恢复约束
    r = max(p_r, key=p_r.get)
    if (c_regime >= M.cfg.TAU_MODE and allow_nominal
            and M.mtg.certified(r)):
        lam = regime_scale(M, r, V_rec, U_ale, U_epi,
                           M.efs.risk_scale(...))
        a = M.uma.act(o, task_of(r))
        if not M.c_ras_wm.certify_regime(a, r, b_t):
            a = M.mib.fallback(o, p_r, V_rec)
    else:
        r, lam = 'ambiguous', M.cfg.lam_conservative
        a = M.mib.fallback(o, p_r, V_rec)
    a = M.transition.bridge(M.last_a, a, M.last_r, r)   # 防跳变
    M.raa.submit_async(b_t, p_r, V_rec, a, M.mtg.last_bound)
    M.last_a, M.last_r = a, r
    return a, r, V_rec

## 4. 推导

**引理 23（正迁移—负迁移分解）** E[err_rec] ≤ ε_0/√(n_rec) + c_1·I·√(d_z/n_nom) + ε_head。共享收益降低 ε_0；共享代价随 I 增长。⇒ 单模型占优当且仅当 n_rec 小且 I 低于阈值；loco 与 recover 的反相关使 I 天然高，故 MTG 不可省。

**引理 24（可恢复失败上界）** 每次跌倒不可恢复概率 ≤ 1 − (R_min − ε_v) + L_v·ε_dyn；长期按事件数累积。⇒ 必须在进入 S_rec 边界前收紧（margin 的由来）。

**引理 25（λ_min 的必然性）** falling 体制中 P_rec(λ) 在 [0, J*/J_max] 严格递增，故 λ_min = J*/J_max > 0；λ<λ_min 时恢复概率随"更保守"而下降。⇒ R68–R70 的单调保守主义是 nominal-only 引理。

**引理 26（模式混淆弃权最优）** 最大后验的额外不可逆风险 ≥ c(1−c)Δ_irr；MIB 将其压到 ≤ (1−c)·min_a max_r ρ_irr。⇒ 低置信必须弃权到"对两种体制都不太坏"的动作。

**引理 27（可恢复性调制阈值）** 非对称代价下，贝叶斯最优 τ*(V_rec) 随 V_rec 下降而下降。⇒ 越接近 PNR 越倾向判 falling（宁可误报），但由 TEB 约束误报代价。

**定理 20（标称切片严格包含）** 在 nominal、c_t≥τ_mode、V_rec≥R_min、MTG 成立时，RISE ≡ BELIEF ≡ FLUID ≡ R68。安全侧在已定义域内不让步。

**定理 21（切换无突变 + 恢复可行性）** 有桥接/认证过渡 ⇒ 指令连续、无越界；falling→grounded 可行 ⇔ V_rec≥R_min ∧ TEB 足够。

**定理 22（就绪演练主动安全）** RRR 周期验证并收缩包络 ⇒ 进入 PNR 的概率被 margin/T_r3 与漂移率共同上界；收缩单调安全。

## 7. 本轮最大风险

**一句话**：**能力与可信度在时间上反相关**——RISE 最需要它的时刻（跌倒瞬间）正是单模型最 OOD、传感器最饱和、体制后验最不可信、MTG 与 J_RISE 最可能失效的时刻；一旦把 falling 误判为 nominal，系统会施加恰好相反的保守刹车，把可恢复的跌倒变成不可恢复的伤害，而定理 20 的"安全侧不让步"还会让它自信地认为自己没错。
