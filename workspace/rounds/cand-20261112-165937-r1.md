# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC IP-153~160；灵感循环第 1 轮；本轮灵感：「奖励设计」×「差异化定位」）

> 第 60 轮把「执行层→证据层」升级为「认知驱动的场景-执行闭环」：SSM 场景语义建模、CIEC 认知意图约束、EPIR ROS 因果隔离、SERC 场景感知闭环、PCE++++ 四维认知预算。但它仍停在 **「信念更新」**，尚未进入 **「价值更新」**，暴露三个根本局限：
> 1. **有信用、无归因（credit collapse）**：SIC 只用 `exp(−D⁺)` 更新 `scene_conf`，却从不区分 `D⁺` 的改善究竟归功于场景先验、意图锁定、阻抗选择还是模态融合。多方共因、单一标量回报 ⇒ 会把「运气」记成「能力」，把「意图救场」记成「场景正确」，策略在错误因果上越走越远。
> 2. **有通用、无差异（behavior collapse）**：`π_scene(K|z)` 是单峰高斯，且置信度低就回退「通用先验」。在真实多峰场景里，这等于把系统逼成 **「处处及格的通才」**，主动放弃在特定场景中「相对最强」的差异化能力——这正是奖励趋同导致的行为坍缩。
> 3. **有对账、无权衡（fusion dilution）**：XMC++ 让模态参与分歧，但融合权重不随「历史信誉」变化——一个在本场景一贯失准的模态与一个可靠模态等权，融合结果被噪声稀释，且无法解释「该信谁」。
>
> 本轮两个灵感词恰好互补：**奖励设计**回答「如何把执行证据变成可信、不可被劫持的价值信号」；**差异化定位**回答「如何在安全可行集内选择『相对最强』而非『绝对平均』的行为位置」。二者合流为 **奖励差异化定位闭环（RDPL, Reward-Differentiated Positioning Loop）**，把 SGEC 从「认知闭环」推进到 **「价值-定位闭环」**。

## 0. 直觉与动机

**灵感 1（奖励设计 → 反事实信用分配 CCA）**
直觉：一次执行的成败是「场景先验 a_scene × 意图锁定 a_intent × 阻抗选择 a_imp × 模态融合 a_fuse」的共同产物。若只给一个总回报，系统无法回答「谁做对了」。差分奖励（difference reward）给出极干净的直觉：**某因子的信用 = 有它时的回报 − 把它换成中性默认值时的回报**。若去掉场景先验回报大跌，场景先验才该拿大信用；若去掉意图锁定毫无影响，意图锁定就不该邀功。关键洞见：**信用必须反事实化，否则多方贡献会互相冒领（free-rider / credit collapse）**。

**灵感 2（奖励设计 → 势函数塑形，保策略不变）**
直觉：把信用回灌成奖励有「改目标」的风险——一旦塑形项本身可被策略操纵，最优行为就被扭曲（reward hacking / Goodhart）。经典结论（Ng, Harada & Russell, 1999）：只要塑形项写成**势函数差分** `F = γΦ(s′) − Φ(s)`，最优策略严格不变，只是收敛更快。关键洞见：**差异化奖励只能经由势函数进入，绝不允许直接改写安全目标**——「奖励可以加速学习，但不能改变『什么是对的』」。

**灵感 3（差异化定位 → 行为生态位库 DPB）**
直觉：生态学里，**竞争排斥原理（Gause）** 指出生态位完全重叠的两个物种无法长期共存；生存之道是**生态位分化**。机器人也一样：与其维护一个「到处还行」的通用策略（会被所有专才夹击），不如维护一组**差异化行为位置**（精密位、速度位、柔顺位、鲁棒位），按**比较优势**（Ricardo）而非绝对分数选择——「我不一定样样最强，但我要在当下场景里相对最强」。关键洞见：**定位 = 在安全可行集内最大化『相对他人』的优势，而不是最大化绝对回报**。

**灵感 4（差异化定位 → 比较优势 + 质量-多样性档案）**
直觉：MAP-Elites 证明「保留一组高质量但行为各异的解」比只留单一最优更能适应环境切换。把定位库做成**质量-多样性档案**：每个场景格子存放该格内适应度最高的行为位置，并强制不同格子的优势剖面不能共线（否则就是「伪差异」）。关键洞见：**差异化需要显式的多样性正则**，否则奖励最大化会把所有位置拉回同一点（行为坍缩）。

**灵感 5（合流 → 奖励差异化定位闭环 RDPL + PCE+++++）**
直觉：CCA 产出信用 θ → 经势函数塑形得到场景条件奖励地形 ρ_z → DPB 用比较优势在安全可行位置中选 p* → 执行 → EV-exec → EPIR 保证证据不可篡改 → 更新 θ 与 ρ_z。闭环从「场景→意图→约束→阻抗→执行→场景更新」升级为「**场景→信用→地形→定位→执行→证据→信用/地形更新**」。预算也从四维扩为六维：新增 `B_credit`（反事实采样/Shapley 预算）与 `B_position`（生态位探索/档案维护）。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（反事实信用分配 CCA）** 一次执行回合 e 分解为因子 `a=(a_scene, a_intent, a_imp, a_fuse)`，中性默认值 `a⁰`。给定结局回报 `R(e)`（可取 `R = −D⁺ − λ_s·1[fail]`）：
- **差分信用**：`θ_i(e) = R(e) − R(e | a_i := a_i⁰)`，`i ∈ {scene, intent, imp, fuse}`
- **可加性残差**：`ε_attr(e) = |R(e) − (R₀ + Σ_i θ_i(e))|`，其中 `R₀ = R(e | a := a⁰)`
- **Shapley 精化（预算允许时）**：`θ_i^Sh = E_{S ⊆ N\{i}}[ R(S∪{i}) − R(S) ]`，用置换采样近似，单轮采样数 `m ≤ B_credit`
- **可信信用**：`θ̃_i = θ_i · 1[ε_attr ≤ τ_attr]`；否则标记「归因不可靠」并抑制地形更新（但保留原始回报用于安全判定）
- **安全护栏**：安全关键因子（intent ∈ {stop, danger}）的信用只允许非负进入塑形，且**不允许因信用低而被关闭**；信用只影响「加速」，不影响「约束」。

**定义 162（势函数奖励地形 PBRL）** 场景 z 与位置 p 上的势函数 `Φ_z(p)`，形状奖励：
```
R̃(e|z) = R(e|z) + γ·Φ_z(p′) − Φ_z(p)
```
由势函数不变性，`argmax_π R̃ = argmax_π R`（最优策略不变）。场景条件奖励地形：
```
ρ_z(p) ← (1−η)·ρ_z(p) + η·R̃(e|z)
```
**差异化项** `R_diff(e|z) = Σ_i θ̃_i(e)` 只用于塑形加速，**不进入安全判定**——安全判定仍用原始 `R` 与 SIC。

**定义 163（差异化定位库 DPB）** 行为生态位档案 `P = {p_1,…,p_M}`，每个 p 是一个行为配置（阻抗剖面、速精权衡、恢复策略）。对每个场景 z：
- **优势剖面** `ρ(p|z)`；**比较优势** `A(p|z) = ρ(p|z) − (1/(M−1))Σ_{q≠p} ρ(q|z)`
- **相对优势（z-score）** `A_norm(p|z) = (ρ(p|z) − μ_z)/σ_z`
- **伪差异判定**：若 `cos(∇ρ(p|z), ∇ρ(q|z)) > τ_niche`，则 p、q 视为「同生态位」，触发合并或强制分化
- **档案更新（质量-多样性）**：单元格 `c = QD_cell(z, behavior_descriptor(p))`；若 `ρ(p|z) > ρ(archive[c])` 则替换，且**每格至少保留一个解**，防止坍缩

**定义 164（比较优势定位决策 CAPD）** 给定场景 z 与安全可行集 `𝕂_safe(z)`（由定义 158 的 SIC 生成）：
```
P_feasible = { p ∈ P | SIC_valid(z, K_p) ∧ ρ(p|z) ≥ ρ_min(z) }
if P_feasible = ∅: return DEGRADE_EXEC
p* = argmax_{p ∈ P_feasible} [ A_UCB(p|z) ]
     其中 A_UCB(p|z) = A(p|z) + c·√( ln N / n_p )    # 比较优势的置信上界，鼓励探索
if DI(P_feasible, z) < τ_D: p* ← diversify(P_feasible, z)   # 差异化不足则强制探索新生态位
return p*
```
关键：**先过安全地板 ρ_min，再比相对优势**——绝不为了「差异化」牺牲绝对安全。

**定义 165（信誉加权跨模态对账 RWC）** 模态 m 的信誉 `θ_m` 由 CCA（定义 161）给出，融合权重：
```
w_m = softmax(θ̃_m / τ_w)，并加安全帽 w_m ≤ w_max（防单模态独裁）
EV_fused = Σ_m w_m · EV_m
```
安全关键判定要求至少 2 个模态一致（2-of-N）。权重随场景更新：`w_m(z) ← (1−η_w)·w_m(z) + η_w·softmax(θ̃_m(z)/τ_w)`。

**定义 166（奖励差异化预算 PCE+++++）**
```
B_rdp = (B_credit, B_position, B_scene, B_intent, B_ros, B_exec)
```
- **B_credit**：反事实重放次数、Shapley 采样预算
- **B_position**：生态位探索次数、档案维护开销
- **边际优势分配**：`B_position(p) ∝ A_UCB(p) − A_LCB(p)`（不确定性越大越值得探索），且 `Σ_p B_position(p) ≤ B_position`
- **降级**：若 B_credit 耗尽 ⇒ 用一阶差分 θ 近似、停止 Shapley；若 B_position 耗尽 ⇒ 冻结档案、退化为贪心定位；B_scene/B_intent/B_ros/B_exec 沿用第 60 轮策略。

**定义 167（奖励差异化定位闭环 RDPL）** 算子 `RDPL(M, scene, intent, Δf)`：
```
① SSM:      z ← R_scene.update(telemetry)                      # 复用 IP-153
② CCA:      θ, ε ← CounterfactualCredit.attribute(last_episode) # 定义 161
③ PBRL:     ρ_z ← PotentialRewardLandscape.update(z, θ)        # 定义 162
④ CAPD:     p* ← ComparativeAdvantagePosition.select(z, ρ_z, SIC) # 定义 164
⑤ CIEC:     C_intent ← ϕ_intent→constraint(intent); ERTC.lock(C_intent)  # IP-154/159
⑥ EEIS:     K_safe ← compile(Δf, p*, ρ_z, K_safe^scene)
⑦ Execute:  telemetry ← wait_contact(); EV-exec ← build_exec_evidence(...)
⑧ EPIR:     S_local.append(EV-exec)                            # 复用 IP-155/160
⑨ RWC:      w_m ← update(θ); EV_fused ← Σ_m w_m·EV_m           # 定义 165
⑩ DPB:      archive.update(QD_cell(z,p*), ρ_z(p*))             # 定义 163
⑪ Cert:     J_reward ← build(θ, ε, Φ-consistency, chain)       # 定义 168
⑫ Return:   (z, p*, K_safe, EV-exec, EV_fused, J_reward)
```

**定义 168（奖励证书与反劫持校验 J_reward）**
```
J_reward = (θ̃, ε_attr, PBRS_ok, SafetyFloor_ok, Chain_ok, DI)
```
- **PBRS_ok**：塑形项满足 `R̃ − R = γΦ(s′) − Φ(s)`，否则判「目标被改写」
- **SafetyFloor_ok**：所有被选中的位置满足 `ρ(p|z) ≥ ρ_min` 且 `SIC_valid`
- **Chain_ok**：θ 所依赖的 EV-exec 哈希链与 IP-155 EPIR 一致（防「篡改证据后刷信用」）
- **DI（差异化指数）** = `H(p* 分布) + 平均优势间隔`；`DI < τ_D` 判「定位坍缩」
- **反 Goodhart 三条**：① 信用项不可自报，只由外部回报差分产生；② 势函数由固定基线策略产生，不可由被评策略优化；③ 安全关键因子信用只增不减。

## 2. 关键算法伪代码

### IP-161 CCA（反事实信用分配）

```python
class CounterfactualCredit:
    def __init__(self, tau_attr=0.15, shapley_samples=8):
        self.tau_attr = tau_attr
        self.shapley_samples = shapley_samples
        self.NEUTRAL = {
            'scene': lambda e: e.scene_default,
            'intent': lambda e: e.intent_none,
            'imp': lambda e: e.impedance_neutral,
            'fuse': lambda e: e.fuse_single_modality,
        }

    def attribute(self, episode, R):
        R0 = self._eval(episode, neutral=True)
        theta = {}
        for f, neutral in self.NEUTRAL.items():
            R_f = self._eval(episode, replace={f: neutral(episode)})
            theta[f] = R - R_f
        eps = abs(R - (R0 + sum(theta.values())))

        if theta.get('intent', 0.0) and episode.intent in ('stop', 'danger'):
            theta['intent'] = max(theta['intent'], 0.0)  # 安全关键因子只增不减

        if eps > self.tau_attr:
            return {k: 0.0 for k in theta}, eps  # 归因不可靠 → 抑制地形更新
        return theta, eps

    def _eval(self, episode, neutral=False, replace=None):
        env = episode.clone()
        if neutral:
            for f, fn in self.NEUTRAL.items():
                setattr(env, f, fn(episode)())
        if replace:
            for f, val in replace.items():
                setattr(env, f, val)
        return self.env_outcome(env)  # 复用仿真器/回放器
```

### IP-162 PBRL（势函数奖励地形）

```python
class PotentialRewardLandscape:
    def __init__(self, gamma=0.97, eta=0.1):
        self.gamma, self.eta = gamma, eta
        self.phi = {}   # (z, p) -> potential
        self.rho = {}   # (z, p) -> shaped reward estimate

    def shaped(self, z, p, p_next, R):
        d = self.gamma * self.phi.get((z, p_next), 0.0) - self.phi.get((z, p), 0.0)
        return R + d, d  # d 必须可被 J_reward 校验

    def update(self, z, p, R_tilde):
        old = self.rho.get((z, p), 0.0)
        self.rho[(z, p)] = (1 - self.eta) * old + self.eta * R_tilde
```

### IP-163 DPB（差异化定位库 / 质量-多样性档案）

```python
class DifferentiatedPositionBank:
    def __init__(self, positions, tau_niche=0.95):
        self.P = positions
        self.tau_niche = tau_niche
        self.rho = defaultdict(lambda: defaultdict(float))
        self.counts = defaultdict(lambda: defaultdict(int))
        self.archive = {}   # cell -> (position, value)

    def advantage(self, p, z):
        others = [self.rho[q][z] for q in self.P if q != p]
        return self.rho[p][z] - (sum(others) / len(others) if others else 0.0)

    def is_pseudo_distinct(self, p, q, z):
        gp, gq = self._grad(p, z), self._grad(q, z)
        return self._cos(gp, gq) > self.tau_niche

    def update(self, z, p, value):
        self.rho[p][z] = value
        self.counts[p][z] += 1
        cell = self._cell(z, self._descriptor(p))
        if cell not in self.archive or value > self.archive[cell][1]:
            self.archive[cell] = (p, value)
```

### IP-164 CAPD（比较优势定位决策）

```python
def comparative_advantage_position(z, bank, sic, rho_min, c=0.5, tau_D=0.2):
    feas = [p for p in bank.P
            if sic.valid(z, p) and bank.rho[p][z] >= rho_min]
    if not feas:
        return DEGRADE_EXEC
    N = sum(bank.counts[p].values()) + 1
    score = {
        p: bank.advantage(p, z)
           + c * math.sqrt(math.log(N) / (bank.counts[p][z] + 1))
        for p in feas
    }
    p_star = max(score, key=score.get)
    if differentiation_index(feas, bank, z) < tau_D:
        p_star = explore_new_niche(bank, z)
    return p_star
```

### IP-165 RWC（信誉加权跨模态对账）

```python
def reward_weighted_consensus(modalities, theta, tau_w=0.5, w_max=0.6):
    w = softmax({m: theta.get(m, 0.0) / tau_w for m in modalities})
    w = {m: min(v, w_max) for m, v in w.items()}
    s = sum(w.values())
    w = {m: v / s for m, v in w.items()}
    fused = sum(w[m] * modalities[m] for m in modalities)
    critical = [m for m in modalities if modalities[m].critical]
    if not two_of_n_agree(critical):
        fused.flag = 'INCONSISTENT'
    return w, fused
```

### IP-166 PCE+++++（奖励差异化预算）

```python
class RewardDifferentiatedBudget:
    def __init__(self, credit_ops=32, position_ops=20, scene_ops=100,
                 intent_ops=50, ros_retry=3, exec_budget=None):
        self.B_credit, self.B_position = credit_ops, position_ops
        self.B_scene, self.B_intent, self.B_ros = scene_ops, intent_ops, ros_retry
        self.B_exec = exec_budget or ExecBudget()
        self.used_credit = self.used_position = 0

    def allocate_position(self, adv_ucb, adv_lcb, total):
        gaps = {p: max(0.0, adv_ucb[p] - adv_lcb[p]) for p in adv_ucb}
        S = sum(gaps.values()) or 1.0
        return {p: total * g / S for p, g in gaps.items()}

    def credit_mode(self):
        return 'shapley' if self.used_credit + 8 <= self.B_credit else 'first_order'
```

### IP-168 J_reward（奖励证书与反劫持）

```python
class RewardCertificate:
    def __init__(self, tau_D=0.2):
        self.tau_D = tau_D

    def build(self, theta, eps, phi_ok, floor_ok, chain_ok, DI):
        violations = []
        if not phi_ok:
            violations.append('GOAL_REWRITTEN')
        if not floor_ok:
            violations.append('SAFETY_FLOOR')
        if not chain_ok:
            violations.append('EVIDENCE_TAMPERED')
        if DI < self.tau_D:
            violations.append('POSITION_COLLAPSE')
        return {
            'theta': theta, 'eps': eps, 'DI': DI,
            'violations': violations, 'valid': not violations,
        }
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CCA | O(k·C_eval)（k=4 因子；Shapley 采样 m 时 O(m·C_eval)） | O(k) | 差分信用在指定反事实模型下无偏；ε_attr 量化可加性误差 |
| PBRL | O(1)/更新 | O(|Z|·M) | 势函数不变性 ⇒ 最优策略不变 |
| DPB | O(M) 优势计算/场景；O(1) 档案更新 | O(M·|Z|) | 每格至少一解，DI 监控防坍缩 |
| CAPD | O(M log M) 排序/场景 | O(M) | 选中位置必然满足 SIC_valid 且 ρ ≥ ρ_min |
| RWC | O(|modalities|) | O(|scenes|·|modalities|) | 2-of-N 安全一致；单模态权重 ≤ w_max |
| RDPL | O(闭环) | 复用 | 12 步闭环 + J_reward 校验 |

**正确性定理（RDP，奖励差异化定位）**：
假设 A66–A70 成立：**(A66)** CCA 所用反事实模型与真实执行因果图一致，差分信用在期望意义下无偏；**(A67)** Φ 由固定基线策略产生、不随被评策略更新；**(A68)** DPB 的 ρ 估计由 UCB 收集且每格至少一个样本；**(A69)** RWC 至少两模态在安全关键判定上独立；**(A70)** EPIR 哈希链完整（IP-155/160）。

则：
1. **信用可信性**：若 `ε_attr ≤ τ_attr`，则 `|θ̃_i − θ_i^true| ≤ δ_credit`；否则更新被抑制，不污染地形。
2. **策略不变性**：PBRS 塑形不改变最优策略，`argmax_π R̃ = argmax_π R`。
3. **定位安全性**：`p* ∈ P_feasible ⇒ SIC_valid(z, K_p*) ∧ ρ(p*|z) ≥ ρ_min(z)`，差异化永远不会越过绝对安全地板。
4. **反劫持性**：`J_reward.valid = true ⇒` 目标未被改写、未越过安全地板、证据未被篡改、定位未坍缩。
5. **预算安全性**：任一 `B_rdp` 维度耗尽 ⇒ 触发对应降级，闭环不中断。

**与第 60 轮的差异**：第 60 轮的正确性只到「场景信念 → K_safe」，本轮把正确性下沉到「**信用是否可信、定位是否安全、奖励是否被劫持**」，使闭环具备可审计的价值层。

## 4. 实验设计 E192–E196

| 实验 | 指标 | 目标 |
|---|---|---|
| E192 CCA | 信用归因误差（vs Shapley 真值）；ε_attr 拒绝率 | 误差 ≤ 0.1；拒绝率 < 5% |
| E193 PBRL | 样本效率（对比无塑形）；最优策略间隙 | 少 30% 回合；间隙 ≤ 1% |
| E194 DPB/CAPD | 场景专精增益（vs 通用策略）；DI；坍缩率 | 增益 ≥ 20%；DI ≥ 0.5；坍缩 = 0 |
| E195 RWC | 故障模态下的融合误差；故障模态权重 | 误差 −25%；故障权重 < 0.15 |
| E196 端到端 | vs 第 60 轮：场景切换成功率、奖励劫持率、安全违规 | 成功率 +15%；劫持 = 0；违规 = 0 |

**消融**：去 CCA（信用坍塌 → 地形学到错误因果）；去势函数、直接加信用项（策略间隙放大 → 证明目标被改写）；去安全地板（差异化选到「相对最优但绝对危险」的生态位）；去多样性正则（所有位置坍缩到同一点，DI→0）。

## 5. 本轮最大风险

### IP-161 CCA（反事实信用分配）

```python
class CounterfactualCredit:
    def __init__(self, tau_attr=0.15, shapley_samples=8):
        self.tau_attr = tau_attr
        self.shapley_samples = shapley_samples
        self.NEUTRAL = {
            'scene': lambda e: e.scene_default,
            'intent': lambda e: e.intent_none,
            'imp': lambda e: e.impedance_neutral,
            'fuse': lambda e: e.fuse_single_modality,
        }

    def attribute(self, episode, R):
        R0 = self._eval(episode, neutral=True)
        theta = {}
        for f, neutral in self.NEUTRAL.items():
            R_f = self._eval(episode, replace={f: neutral(episode)})
            theta[f] = R - R_f
        eps = abs(R - (R0 + sum(theta.values())))

        if theta.get('intent', 0.0) and episode.intent in ('stop', 'danger'):
            theta['intent'] = max(theta['intent'], 0.0)

        if eps > self.tau_attr:
            return {k: 0.0 for k in theta}, eps
        return theta, eps

    def _eval(self, episode, neutral=False, replace=None):
        env = episode.clone()
        if neutral:
            for f, fn in self.NEUTRAL.items():
                setattr(env, f, fn(episode)())
        if replace:
            for f, val in replace.items():
                setattr(env, f, val)
        return self.env_outcome(env)
```

### IP-162 PBRL（势函数奖励地形）

```python
class PotentialRewardLandscape:
    def __init__(self, gamma=0.97, eta=0.1):
        self.gamma, self.eta = gamma, eta
        self.phi, self.rho = {}, {}

    def shaped(self, z, p, p_next, R):
        d = self.gamma * self.phi.get((z, p_next), 0.0) - self.phi.get((z, p), 0.0)
        return R + d, d

    def update(self, z, p, R_tilde):
        old = self.rho.get((z, p), 0.0)
        self.rho[(z, p)] = (1 - self.eta) * old + self.eta * R_tilde
```

### IP-163 DPB（差异化定位库 / 质量-多样性档案）

```python
class DifferentiatedPositionBank:
    def __init__(self, positions, tau_niche=0.95):
        self.P = positions
        self.tau_niche = tau_niche
        self.rho = defaultdict(lambda: defaultdict(float))
        self.counts = defaultdict(lambda: defaultdict(int))
        self.archive = {}

    def advantage(self, p, z):
        others = [self.rho[q][z] for q in self.P if q != p]
        return self.rho[p][z] - (sum(others) / len(others) if others else 0.0)

    def is_pseudo_distinct(self, p, q, z):
        return self._cos(self._grad(p, z), self._grad(q, z)) > self.tau_niche

    def update(self, z, p, value):
        self.rho[p][z] = value
        self.counts[p][z] += 1
        cell = self._cell(z, self._descriptor(p))
        if cell not in self.archive or value > self.archive[cell][1]:
            self.archive[cell] = (p, value)
```

### IP-164 CAPD（比较优势定位决策）

```python
def comparative_advantage_position(z, bank, sic, rho_min, c=0.5, tau_D=0.2):
    feas = [p for p in bank.P
            if sic.valid(z, p) and bank.rho[p][z] >= rho_min]
    if not feas:
        return DEGRADE_EXEC
    N = sum(bank.counts[p].values()) + 1
    score = {
        p: bank.advantage(p, z)
           + c * math.sqrt(math.log(N) / (bank.counts[p][z] + 1))
        for p in feas
    }
    p_star = max(score, key=score.get)
    if differentiation_index(feas, bank, z) < tau_D:
        p_star = explore_new_niche(bank, z)
    return p_star
```

### IP-165 RWC（信誉加权跨模态对账）

```python
def reward_weighted_consensus(modalities, theta, tau_w=0.5, w_max=0.6):
    w = softmax({m: theta.get(m, 0.0) / tau_w for m in modalities})
    w = {m: min(v, w_max) for m, v in w.items()}
    s = sum(w.values())
    w = {m: v / s for m, v in w.items()}
    fused = sum(w[m] * modalities[m] for m in modalities)
    critical = [m for m in modalities if modalities[m].critical]
    if not two_of_n_agree(critical):
        fused.flag = 'INCONSISTENT'
    return w, fused
```

class RewardDifferentiatedBudget:
    def __init__(self, credit_ops=32, position_ops=20, scene_ops=100,
                 intent_ops=50, ros_retry=3, exec_budget=None):
        self.B_credit, self.B_position = credit_ops, position_ops
        self.B_scene, self.B_intent, self.B_ros = scene_ops, intent_ops, ros_retry
        self.B_exec = exec_budget or ExecBudget()
        self.used_credit = self.used_position = 0

    def allocate_position(self, adv_ucb, adv_lcb, total):
        gaps = {p: max(0.0, adv_ucb[p] - adv_lcb[p]) for p in adv_ucb}
        S = sum(gaps.values()) or 1.0
        return {p: total * g / S for p, g in gaps.items()}

    def credit_mode(self):
        return 'shapley' if self.used_credit + 8 <= self.B_credit else 'first_order'

### IP-168 J_reward（奖励证书与反劫持）

```python
class RewardCertificate:
    def __init__(self, tau_D=0.2):
        self.tau_D = tau_D

    def build(self, theta, eps, phi_ok, floor_ok, chain_ok, DI):
        violations = []
        if not phi_ok:
            violations.append('GOAL_REWRITTEN')
        if not floor_ok:
            violations.append('SAFETY_FLOOR')
        if not chain_ok:
            violations.append('EVIDENCE_TAMPERED')
        if DI < self.tau_D:
            violations.append('POSITION_COLLAPSE')
        return {'theta': theta, 'eps': eps, 'DI': DI,
                'violations': violations, 'valid': not violations}
```
