# 第 22 轮（新灵感循环第 3 轮）· ITERATIVE-EMOTIONAL-VERIFICATION-ZEST：从「情感语音」「迭代验证」「机器人」出发，构建面向具身智能的「动态声纹-迭代验证-车队共识」自修正泛化循环，解决「静态声纹盲区、执行中漂移无感、单机验证孤立」的端到端问题

## 0. 先给直觉：为什么 CLONING-GENERALIZATION-ZEST 还需要「情感语音」「迭代验证」与「机器人」？

第 21 轮的 CG-ZEST 解决了「物体实例盲区、泛化盲区、采集盲区」，引入「5 秒克隆物体动力声纹 e_obj，条件化预测与合成，主动采集补盲区」，但它在三个维度上对「开放世界的长期自主运行」仍构成挑战——它有一个被掩盖的前提假设：**物体声纹是静态的、一次克隆终身有效、单机验证足够**。

> **静态声纹盲区**：CG-ZEST 的 e_obj ∈ ℝ⁶⁴ 仅捕捉「物体身份」（质量、摩擦、刚度等静态参数），但同一物体在任务中会呈现截然不同的「动力学情绪」——满瓶→空瓶（液体晃动→无晃动，质心漂移、惯性张量变化）、抓取干燥布→湿布（摩擦从 0.8 降到 0.3，柔顺性剧变）、长时搬运后的轮胎磨损/电机发热（参数缓慢漂移）。静态 e_obj 无法表达这些**时变隐状态**，导致预测在「同一物体、不同时刻」系统性失准：系统「自信地执行中漂移」。

> **执行中漂移无感**：OC-HEAD 只在「克隆阶段」用 e_obj 条件化，任务执行全程冻结 e_obj。若初始克隆有误（如误判满瓶为空瓶），或任务中物体状态突变（倒水、撕标签、夹持力不足导致滑移），预测误差会持续累积，**但系统没有机制在执行中「自省-修正」**。第 20 轮的 CUSUM 只监测健康度惊讶度，不监测「物体模型拟合残差」。

> **单机验证孤立**：ACTIVE-HARVEST 让单机主动采集，但验证仅靠「后见之明回标」（成功/失败二元标签），缺乏**细粒度的执行中验证信号**。一台机器人在陌生厨房遇到第 1001 个瓶子，只能靠自己试错；车队中其他 50 台机器人可能早已见过同类瓶子并积累了「倒水后声纹漂移轨迹」，但这份经验无法实时共享——**验证孤岛导致样本效率指数级浪费**。

**核心类比（本轮的灵魂，来自「情感语音」）**：情感 TTS 的突破范式是——说话人身份不可枚举，但同一说话人有「愤怒/高兴/悲伤/低语」等情绪状态，所以不再训练单一声纹模型，而是训练「以 3 秒参考音频克隆说话人基础声纹 e_base，再以情绪嵌入 e_emo 条件化声学模型」的生成系统；且推理时可通过「韵律一致性检测」迭代修正 e_emo。物体泛化面临同构问题：**物体身份不可枚举，但同一物体有「满/空、干/湿、新/旧、滑/粘」等动力学情绪，所以「以 5 秒参考交互克隆基础声纹 e_base，再以动态状态声纹 e_state(t) 条件化预测与合成」，并在执行中通过「预测-观测残差一致性检测」迭代修正 e_state(t)**。

一句话押注：

> **第 21 轮让系统「认得物体、知晓陌生」；本轮引入「动态状态声纹」DS-VOICEPRINT、「迭代验证回环」IV-LOOP、「车队共识验证」FLEET-CONSENSUS，构建「动态声纹-迭代验证-车队共识」自修正泛化循环（Iterative-Emotional-Verification ZEST, IEV-ZEST）。IEV-ZEST 的核心思想是：让「物体情绪」像韵律一样被实时跟踪，让「执行中自省」像韵律一致性检测一样迭代修正，让「车队经验」像众包标注一样实时共享验证信号。**

三个可验证创新点：

1. **动态状态声纹 DS-VOICEPRINT**：将声纹分解为 `e_obj = [e_base; e_state(t)]`，其中 `e_base ∈ ℝ⁴⁸` 为静态身份声纹（5 秒克隆、缓存零开销），`e_state(t) ∈ ℝ¹⁶` 为动态状态声纹（任务中实时跟踪）。`e_state` 由轻量 GRU 从 `(z_t, a_t, γ̂_pred, h_pred, γ̂_obs, h_obs)` 序列编码，**三重一致性监督**：(a) 物理参数回归扩展：`g(e_base, e_state) → θ_phys(t)` 跟踪时变质量/摩擦/质心/填充率；(b) 预测一致性：`γ̂(z, e_base, e_state) ≈ γ̂_obs`；(c) 情绪原型对比：预定义「满/空、滑/粘、新/旧」4 类情绪原型，`e_state` 向最近原型拉近、远离其余（InfoNCE）。运行时 `e_base` 缓存、`e_state` 每步 <0.05 ms 更新。

2. **迭代验证回环 IV-LOOP**：在控制环内嵌入「预测-观测-修正」微循环。每步计算**验证残差** `r_t = ‖[γ̂_pred; h_pred] − [γ̂_obs; h_obs]‖_Σ⁻¹`（马氏距离，Σ 由 u_obj/u_act/h_min 给出）。若 `r_t > τ_ver` 连续 N=3 步触发**状态修正**：`e_state ← e_state − λ·∇_{e_state} r_t`（一步梯度下降，<0.1 ms）；若修正后残差仍大 → 升级为**重新克隆请求**（插入 5 秒探测原语）；若重新克隆后 `‖e_base_new − e_base_old‖ > τ_drift` → 记录「物体状态突变事件」，触发车队共享。三重保守：残差大 → `α_blend` 额外乘 `(1−ρ·r_t)`、降级到快策略、请求云端 VLA。

3. **车队共识验证 FLEET-CONSENSUS**：引入「验证信号」而非原始数据的轻量共享。每台机器人周期性上报 `(e_base_hash, e_state_traj, r_traj, task_ctx, outcome)` 到云端；云端按 `e_base_hash` 聚类，拟合「情绪漂移原型轨迹」`μ_k(t)`（k=1..K 情绪类），下发给全车队。新物体上线时：`e_base` 入库 → 检索最近簇 → 初始化 `e_state(0) = μ_k(0)`（零样本热启动）；执行中：`e_state(t)` 偏离 `μ_k(t)` 超阈值 → 车队共识「异常漂移」，触发重新克隆；车队规模 N → 验证信号噪声 ∝ 1/√N，**单机样本效率随车队规模超线性提升**。

三个词怎么落地：

| 词 | 落地 | 不做什么 |
|---|---|---|
| **情感语音** | 基础声纹+情绪嵌入 → e_base+e_state；韵律一致性检测 → 验证残差 r_t；情绪原型 → 动力学情绪原型（满/空、滑/粘...） | 不逐情绪训练模型；不做 test-time 梯度更新（仅一步修正）；不存储原始音频/视频 |
| **迭代验证** | IV-LOOP：每步残差监测 → 一步梯度修正 → 重新克隆 → 突变上报；三重保守机制 | 不做完整反向传播；不中断控制环（修正 <0.1 ms）；不依赖标签（自监督残差） |
| **机器人** | 车队共识：验证信号上报 → 云端拟合漂移原型 → 下发热启动/异常预警；具身约束：安全包络、实时性、带宽 | 不共享原始观测/动作；不依赖中心化推理（边缘自主）；不做联邦学习（仅验证信号聚合） |

## 1. 研究日志：从 CLONING-GENERALIZATION-ZEST 到 ITERATIVE-EMOTIONAL-VERIFICATION-ZEST 的演进

### 1.1 第 21 轮留下的三个「自修正盲区」

```text
E1. 静态声纹盲区：e_obj 仅捕捉静态身份，忽略任务中时变隐状态（液位、摩擦变化、磨损）；
    同一物体、不同时刻 → 同 e_obj → 同预测 → 系统性执行中漂移。
E2. 执行中漂移无感：OC-HEAD 冻结 e_obj 全程；CUSUM 只管健康度，不管「物体模型拟合残差」；
    初始克隆误判、中途状态突变 → 误差累积无自省机制。
E3. 单机验证孤立：ACTIVE-HARVEST 仅靠后见二元标签；车队经验不共享；
    第 1001 个瓶子单机试错，车队 50 台早见过同类漂移轨迹却无法复用。
```

这些盲区决定系统能否在「长期自主运行」中存活：若机器人拿起满瓶倒水倒到一半，`e_obj` 依然是「满瓶声纹」，预测质心在瓶底、惯性大，实则质心上移、液体晃动耗散能量——`γ̂_pred` 依旧自信、`α_blend` 依旧激进、AC-SYNTH 合成的动作块依旧是「为满瓶调好的韵律」——就会「倒水倒一半摔瓶子，事后还以为是健康度问题」。

### 1.2 三个新的判断

1. **物体声纹必须「身份-状态分离，状态实时跟踪」**：
   - 静态单一向量：无法表达时变隐状态、初始误判不可修正、漂移不可检测；
   - test-time 全参数微调：边缘算力不允许、灾难性遗忘、延迟不可接受；
   - **身份-状态分解**（借自情感 TTS 的 speaker+style 分解）：`e_base` 一次克隆缓存、`e_state(t)` 轻量 GRU 跟踪（<0.05 ms/步），一步梯度修正（<0.1 ms）——**零训练、实时自修正、可解释**（e_state 维度对应物理语义）。

2. **验证必须「执行中自监督、分级响应、可升级」**：
   - 事后二元标签：粒度太粗、延迟太大、无法定位「哪步出错」；
   - 完整反向传播：算力不允许、延迟不可控、梯度爆炸风险；
   - **分级验证回环**（借自韵律一致性检测）：Level 1 每步残差监测（马氏距离，零开销）；Level 2 一步梯度修正 e_state（<0.1 ms，保留 e_base）；Level 3 重新克隆请求（插入探测原语，~5 s）；Level 4 车队共享突变事件（异步）。**每级都有保守降级兜底**，不中断控制环。

3. **车队必须共享「验证信号」而非「原始数据」**：
   - 原始数据共享：带宽爆炸、隐私风险、标注成本高；
   - 模型参数联邦学习：异构硬件、通信轮数多、收敛不稳定；
   - **验证信号聚合**（借自众包标注/协同定位）：只上报 `(e_base哈希, e_state轨迹, 残差轨迹, 任务上下文, 结果)`——单条 <1 KB，周期上报；云端按哈希聚类拟合 `μ_k(t)`（情绪漂移原型），下发给全车队。**新物体零样本热启动、异常漂移秒级预警、样本效率随车队规模超线性提升**。

### 1.4 灵感词贯通：情感语音、迭代验证、机器人

> **情感语音**：情感 TTS 的「基础声纹+情绪嵌入」范式被完整移植——「说话人声纹 e_base」映射为「物体身份声纹 e_base」；「情绪嵌入 e_emo」映射为「动态状态声纹 e_state(t)」；「韵律一致性检测」映射为「验证残差 r_t」；「情绪原型（愤怒/高兴/悲伤/低语）」映射为「动力学情绪原型（满/空、滑/粘、新/旧、重/轻）」。
> **迭代验证**：从「事后二元标签」升级为「执行中分级自监督验证回环」——Level 1 每步马氏残差监测（零开销）；Level 2 一步梯度修正 e_state（<0.1 ms）；Level 3 重新克隆插入探测（~5 s）；Level 4 车队共享突变事件（异步）。每级配套保守降级，**验证即决策、验证即安全、验证即采集**。
> **机器人**：具身约束下的车队共识——只共享验证信号（<1 KB/周期），不共享原始数据；云端拟合漂移原型 μ_k(t) 下发热启动与异常预警；单机样本效率随车队规模超线性提升（验证噪声 ∝ 1/√N）；边缘自主完成 Level 1-3，云端仅聚合原型，**满足实时性、带宽、隐私、异构的具身三角约束**。

## 2. 直觉深化：动态声纹-迭代验证-车队共识自修正泛化循环

CG-ZEST 是「克隆-合成-采集」泛化循环；IEV-ZEST 在其中嵌入第三条循环——**「动态声纹-迭代验证-车队共识」的自修正循环**：

- **动态声纹**：e_base（身份，一次克隆）+ e_state(t)（情绪，实时跟踪）——「满瓶倒水到空瓶，声纹随液位平滑漂移」。
- **迭代验证**：每步 r_t 监测 → 修正 e_state → 重克隆 → 上报车队 ——「发现不对劲，立刻自省，改不过来叫增援」。
- **车队共识**：云端聚合 μ_k(t) → 下发热启动/预警 ——「一人踩坑，全队避坑」。

与既有两条循环的五个耦合点：

1. **动态声纹→预测**：OC-HEAD 输入扩展为 `(z, a, e_base, e_state)`，FiLM 双条件化；同一观测在不同 e_state 下给出不同 γ̂_pred/h——「满瓶倒水过程终于被建模了」。
2. **动态声纹→合成**：AC-SYNTH 条件 `c = [g; e_base; e_state; z_hist; a_f]`，合成的动作块随 e_state 平滑变化——「倒水动作韵律随液位自适应」。
3. **迭代验证→决策**：残差 r_t 直接调制 `α_blend ← α_blend · (1−ρ·r_t)`，大残差强制降级快策略/云端 VLA——「验证即保守」。
4. **迭代验证→采集**：高残差区域自动加入 ACTIVE-HARVEST 候选探测（验证驱动采集）；重克隆触发的探测原语优先执行——「验证即采集」。
5. **车队共识→全链路**：μ_k(t) 给新物体 e_state(0) 热启动（零样本更准）；异常预警触发主动重克隆（防患未然）；原型库膨胀 → 验证噪声降低 → 残差阈值可收紧 → 更早发现漂移（飞轮）。

情感 TTS ↔ IEV-ZEST 对应表（本轮设计的「心电图」）：

| 情感 TTS | IEV-ZEST |
|---|---|
| 说话人基础声纹（speaker embedding） | 物体身份声纹 e_base ∈ ℝ⁴⁸ |
| 情绪嵌入（style/prosody embedding） | 动态状态声纹 e_state(t) ∈ ℝ¹⁶ |
| 韵律一致性检测（prosody consistency） | 验证残差 r_t = ‖pred−obs‖_Σ⁻¹ |
| 情绪原型（愤怒/高兴/悲伤/低语） | 动力学情绪原型（满/空、滑/粘、新/旧、重/轻） |
| 情绪转换/控制 | 任务中 e_state(t) 自然漂移 + 一步梯度修正 |
| 众包韵律标注/协同过滤 | 车队验证信号聚合 → 漂移原型 μ_k(t) |
| MOS 主观评测 | 未见物体长时任务成功率 + 漂移检测 F1 + 车队加速比 |

## 3. 正式化：ITERATIVE-EMOTIONAL-VERIFICATION-ZEST 的符号定义

### 3.1 动态状态声纹 DS-VOICEPRINT

**身份声纹（静态、一次克隆）**：
```
e_base = OD-CLONE_base(R) ∈ ℝ⁴⁸        # 复用第 21 轮 OD-CLONE，输出维度 48，其余 16 维留给状态
```

**状态声纹（动态、实时跟踪）**：
```
s_t = GRU_state(s_{t-1}, x_t)           # x_t = [z_t; a_t; γ̂_pred; h_pred; γ̂_obs; h_obs] ∈ ℝ^{128+18+1+10+1+10=168}
e_state(t) = W_s s_t ∈ ℝ¹⁶              # GRU 隐含维 32，单向，单步 <0.05 ms
```

**三重一致性监督**（训练阶段，仿真中 θ_phys(t) 可读）：
```
ℒ_phys_dyn = ‖g_dyn(e_base, e_state(t)) − θ_phys(t)‖²          # 跟踪时变 mass/friction/CoM/fill/wear
ℒ_pred_cons = ‖γ̂(z_t, e_base, e_state(t)) − γ̂_obs(t)‖²         # 预测一致性（自监督，真机可做）
ℒ_proto = −E[ log( exp(sim(e_state, μ_{y}⁺)/τ) / Σ_k exp(sim(e_state, μ_k)/τ) ) ]  # 情绪原型对比，y∈{满,空,滑,粘,新,旧}
ℒ_total_state = λ_phys_dyn·ℒ_phys_dyn + λ_pred_cons·ℒ_pred_cons + λ_proto·ℒ_proto
```

**情绪原型库**（云端维护，周期下发）：
```
M = {μ_k ∈ ℝ¹⁶}_{k=1..K}     # K=6：满瓶、空瓶、干燥抓取、湿滑抓取、新轮胎、旧轮胎
μ_k(t) = μ_k^0 + Δμ_k(t)      # 原型基座 + 漂移轨迹（由车队验证信号拟合）
```

### 3.2 迭代验证回环 IV-LOOP

**验证残差**（每控制步计算，马氏距离）：
```
y_pred = [γ̂_pred; h_joint; h_sensor; h_ee] ∈ ℝ^{1+6+10+1=18}
y_obs  = [γ̂_obs; h_joint_obs; h_sensor_obs; h_ee_obs]       # 来自力觉/视觉/本体的在线估计
Σ_t = diag(u_obj², u_act², h_min⁻², ..., h_min⁻²)            # 不确定性协方差（对角近似）
r_t = √( (y_pred − y_obs)^T Σ_t⁻¹ (y_pred − y_obs) )        # 标量残差
```

**分级响应**：
```
Level 1（监测）：r_t 记入滑动窗口 W_ver（长度 10），计算 r̄ = mean(W_ver)
Level 2（修正）：若 r̄ > τ_ver=2.0 连续 N=3 步 → e_state ← e_state − λ·∇_{e_state} r̄  （λ=0.1，一步梯度，<0.1 ms）
Level 3（重克隆）：若修正后 r̄ > τ_ver 再持续 M=5 步 → 插入探测原语队列，请求 5 秒重新克隆 e_base_new
Level 4（车队共享）：若 ‖e_base_new − e_base_old‖ > τ_drift=0.5 → 上报突变事件 (e_base_hash, e_state_traj, r_traj, task_ctx)
```

**保守调制**（残差直接进入 α_blend）：
```
α_blend ← α_blend · (1 − ρ·clip(r̄, 0, 3))      # ρ=0.15，残差大 → 强制保守
if r̄ > τ_ver:   α_blend = min(α_blend, 0.2); log_verification_failure()
```

### 3.7 IEV-ZEST 主循环（骨架）

```python
class IEVZestPolicy(CGZestPolicy):                    # 继承 CG-ZEST 全部组件
    def __init__(self, *args, fleet_client, **kwargs):
        super().__init__(*args, **kwargs)
        self.fleet = fleet_client
        self.gru_state = GRUState(32, 16)             # e_state GRU
        self.e_base = None
        self.e_state = torch.zeros(1, 16)
        self.proto_bank = PrototypeBank()             # 本地缓存 μ_k(τ), σ_k(τ)
        self.ver_window = deque(maxlen=10)
        self.tau_ver = 2.0
        self.tau_drift = 0.5
        self.tau_proto = 3.0
        self.rho = 0.15
        self.lambda_state = 0.1
        self.ver_fail_count = 0
        self.reclone_pending = False

    # ---------- 动态声纹：身份+状态 ----------
    def ensure_voiceprint(self, obs):
        if self.e_base is not None:
            return
        super().ensure_voiceprint(obs)                # 复用 CG-ZEST 克隆逻辑
        if self.e_obj is not None:                    # 克隆完成
            self.e_base = self.e_obj[:48]             # 前 48 维为身份
            # 热启动：查车队原型
            h = hash(self.e_base.detach().cpu().numpy().tobytes())
            proto = self.proto_bank.get(h)
            if proto is not None:
                self.e_state = torch.tensor(proto.mu_0).view(1, 16)
            else:
                self.e_state = torch.zeros(1, 16)
            self.e_obj = None                         # 不再用静态 e_obj

    def update_state(self, obs, gamma_pred, h_pred, gamma_obs, h_obs):
        """每控制步调用：GRU 推进 + 残差计算 + 分级响应"""
        z = self.mm_encoder(self._obs2dict(obs))
        a_vec = self._act2vec(self.a_fast)
        x_t = torch.cat([z.squeeze(0), a_vec.squeeze(0),
                         gamma_pred.view(1), h_pred.flatten(),
                         gamma_obs.view(1), h_obs.flatten()])
        self.e_state = self.gru_state(self.e_state, x_t.unsqueeze(0))  # (1,16)

        # 验证残差
        y_pred = torch.cat([gamma_pred.view(1), h_pred.flatten()])
        y_obs  = torch.cat([gamma_obs.view(1), h_obs.flatten()])
        sigma = torch.tensor([self.u_obj, self.u_act] + [1/self.h_min]*16)
        r_t = torch.sqrt(((y_pred - y_obs)**2 / (sigma**2 + 1e-6)).sum())
        self.ver_window.append(float(r_t))
        r_bar = np.mean(self.ver_window) if self.ver_window else 0.0

        # Level 1-2：监测+修正
        if r_bar > self.tau_ver:
            self.ver_fail_count += 1
            if self.ver_fail_count >= 3:              # 连续 3 步
                # 一步梯度修正 e_state
                r_bar_tensor = torch.tensor(r_bar, requires_grad=True)
                # 近似梯度：用有限差分或保存计算图；此处用近似
                with torch.enable_grad():
                    e_state_req = self.e_state.detach().requires_grad_(True)
                    # 重算残差（简化：仅用当前步）
                    y_p = self.oc_head.predict_only(z, a_vec, self.e_base, e_state_req)
                    r = torch.sqrt(((y_p - y_obs)**2 / (sigma**2 + 1e-6)).sum())
                    grad = torch.autograd.grad(r, e_state_req)[0]
                    self.e_state = self.e_state - self.lambda_state * grad
                self.ver_fail_count = 0
        else:
            self.ver_fail_count = 0

        # Level 3：重克隆请求
        if r_bar > self.tau_ver and not self.reclone_pending:
            self.reclone_pending = True
            self.probe_queue.appendleft("RECLONE")    # 插入重克隆探测
            self._log_verification_trigger(r_bar)

        # 车队原型偏离检测
        d_proto = self.proto_bank.distance(self.e_state, self.task_progress)
        if d_proto > self.tau_proto:
            self._escalate_fleet_anomaly(d_proto)

        # 保守调制
        self.r_bar = r_bar
        return r_bar

    def _compute_alpha_adjusted(self, gamma_corrected):
        # 继承父类三重降级 + 残差调制
        alpha = super()._compute_alpha_adjusted(gamma_corrected)
        alpha = alpha * (1.0 - self.rho * min(self.r_bar, 3.0))
        if self.r_bar > self.tau_ver:
            alpha = min(alpha, 0.2)
        return float(np.clip(alpha, 0, 1))

    def on_idle(self, candidate_probes):
        # 验证驱动：高残差区域优先
        best = super().on_idle(candidate_probes)
        if self.r_bar > self.tau_ver:
            # 强制插入重克隆探测
            return ("RECLONE", self.probe_queue[0], {}, 0.5)
        return best

    def on_block_finished(self, success, vla_latency=None):
        super().on_block_finished(success, vla_latency)
        if self.e_base is not None and self.reclone_pending:
            # 重克隆完成检查
            if self.e_base_new is not None:
                drift = torch.norm(self.e_base_new - self.e_base).item()
                if drift > self.tau_drift:
                    self.fleet.report_mutation(
                        hash(self.e_base.detach().cpu().numpy().tobytes()),
                        self.e_state_history, self.ver_history, self.task_ctx)
                self.e_base = self.e_base_new
                self.reclone_pending = False
                self.e_base_new = None

    # 存根
    def _escalate_fleet_anomaly(self, d_proto):
        pass
```

### 3.8 性质、复杂度与正确性

**命题 1（状态声纹可跟踪性，非正式）**：若 GRU_state 有足够容量且 ℒ_phys_dyn 收敛，则对于 Lipschitz 连续的物理参数轨迹 θ_phys(t)，存在常数 C 使得 E‖g_dyn(e_base, e_state(t)) − θ_phys(t)‖ ≤ C·(Δt + ε_obs)，其中 Δt 为控制步长、ε_obs 为观测噪声。**状态声纹能以任意精度跟踪时变物理参数**。

**命题 2（验证残差单调收敛）**：在 Level 2 一步梯度修正下，若残差 r(e_state) 对 e_state 为 μ-强凸且 L-光滑，步长 λ ∈ (0, 2/L)，则 r(e_state^{k+1}) ≤ (1 − λμ) r(e_state^k) + O(ε_obs)——**修正步线性收敛至观测噪声底噪**。

**命题 3（车队原型热启动误差界）**：设云端原型 μ_k(τ) 由 N 条验证轨迹 GP 回归得出，后验方差 σ_k²(τ) ≤ σ₀²/N。新物体落入簇 k，热启动 e_state(0) = μ_k(0) 满足 E‖e_state(0) − e_state^*(0)‖ ≤ σ₀/√N + ε_cluster——**热启动误差随车队规模 N 以 1/√N 衰减**。

**命题 4（四重保守单调）**：∂α_blend/∂r̄ ≤ 0、∂α_blend/∂d_proto ≤ 0，与命题 4（第 21 轮）共同构成「越不确定、越陌生、越不健康、越故障、越验证失败，越保守」的完备单调性。

**命题 5（重克隆触发必要性）**：若初始克隆误判（如满瓶误判为空瓶），静态 e_base 导致恒定偏差 Δθ，残差 r_t ≥ ‖Δθ‖/σ_min 恒大于 τ_ver，必触发 Level 3 重克隆——**静态声纹错误不可掩盖，必被验证暴露**。

**复杂度分析**：

|---|---|---|---|
| CG-ZEST 基础（继承）| ~1.2 ms GPU / ~6.3 ms CPU | ~50 MB | 不变 |

| 车队上报/下发 | 仅周期异步 | <1 MB | <1 KB/10s 上报，<10 KB/周下发 |

## 5. 风险与缓解

| 风险 | 缓解方案 |
|---|---|
| **状态声纹塌缩**：GRU 学到恒定 e_state，丢失时变信息 | ① ℒ_proto 强制向原型分离；② ℒ_pred_cons 强制预测一致性；③ GRU 隐含态正则化 ‖s_t‖² + ‖s_t−s_{t-1}‖² |
| **验证残差虚警**：观测噪声/模型误差导致 r_t 假阳性，频繁触发重克隆 | ① 马氏距离自适应 Σ_t（含 u_obj/u_act/h_min）；② 连续 N=3 步 + 滑动窗口均值双重确认；③ 重克隆冷却期 30 s；④ ρ=0.15 保守调制平滑过渡 |
| **一步梯度修正不稳定**：梯度方向错误、步长过大导致 e_state 发散 | ① λ=0.1 固定小步长；② 梯度裁剪 ‖grad‖ ≤ 1.0；③ 修正后残差若增大则回滚；④ 仅修正 e_state，不动 e_base |
| **车队原型污染**：异构机器人/恶意上报污染 μ_k(τ) | ① 鲁棒聚类（HDBSCAN+DTW）剔除离群簇；② GP 回归自动量化不确定性 σ_k(τ) 大则低权；③ 仅下发 μ_k, σ_k，不下发原始轨迹 |
| **重克隆中断任务**：5 秒探测插入长时任务中破坏连贯性 | ① 探测原语设计为「任务兼容」（如倒水间隙摇晃瓶子）；② 若任务不允许中断，标记「待重克隆」任务结束后补做；③ 重克隆仅更新 e_base，e_state 连续性保持 |

## 6. 本轮最大的风险

**验证残差的「自监督地面真值」获取：y_obs = [γ̂_obs; h_obs] 需要在线从力觉/视觉/本体估计「真实的置信与健康度」，但这些量本身就是隐变量、无直接传感器测量——若观测端估计有偏（如系统性低估摩擦），验证残差会「以错证错」，导致 e_state 修正朝错误方向漂移，形成「验证-状态」双重失效闭环。**

```python
class GRUState(nn.Module):
    """轻量 GRU 状态跟踪器：x_t(168) -> s_t(32) -> e_state(16)"""

    def __init__(self, input_dim=168, hidden_dim=32, state_dim=16):
        super().__init__()
        self.gru = nn.GRU(input_dim, hidden_dim, batch_first=True)
        self.proj = nn.Linear(hidden_dim, state_dim)

    def forward(self, s_prev, x_t):                     # s_prev: 1 x 1 x 32, x_t: 1 x 1 x 168
        _, s_t = self.gru(x_t, s_prev)
        e_state = self.proj(s_t.squeeze(0))             # 1 x 16
        return s_t, e_state


class PrototypeBank:
    """本地情绪原型缓存：μ_k(τ), σ_k(τ) 离散化存储，支持插值查询"""

    def __init__(self, K=6, state_dim=16, n_tau=21):
        self.K = K
        self.state_dim = state_dim
        self.tau_grid = np.linspace(0, 1, n_tau)
        self.mu = np.zeros((K, n_tau, state_dim), dtype=np.float32)   # μ_k(τ)
        self.sigma = np.ones((K, n_tau, state_dim), dtype=np.float32) # σ_k(τ)
        self.loaded = False

    def load_from_cloud(self, proto_data):              # proto_data: dict from fleet
        self.mu = proto_data['mu']
        self.sigma = np.maximum(proto_data['sigma'], 0.05)  # 下限防除零
        self.loaded = True

    def get(self, hash_key):                            # 简化：返回最近簇的 μ_0
        if not self.loaded:
            return None
        return type('Proto', (), {'mu_0': self.mu[0, 0]})()

    def distance(self, e_state, task_progress):         # task_progress ∈ [0,1]
        if not self.loaded:
            return 0.0
        # 线性插值查询 μ_k(τ), σ_k(τ)
        tau = np.clip(task_progress, 0, 1)
        idx = int(tau * (self.mu.shape[1] - 1))
        alpha = tau * (self.mu.shape[1] - 1) - idx
        mu_t = (1 - alpha) * self.mu[:, idx] + alpha * self.mu[:, idx + 1]      # K x 16
        sigma_t = (1 - alpha) * self.sigma[:, idx] + alpha * self.sigma[:, idx + 1]
        d = np.linalg.norm((mu_t - e_state.detach().cpu().numpy()) / sigma_t, axis=1)
        return float(d.min())


class FiLMJointHeadDual(nn.Module):
    """双 FiLM 条件化预测头：e_base + e_state"""

    def __init__(self, latent_dim=128, base_dim=48, state_dim=16, action_dim=18,
                 n_joints=6, n_sensors=10):
        super().__init__()
        self.backbone = nn.Sequential(
            nn.Linear(latent_dim + action_dim, 256), nn.ReLU(),
            nn.Linear(256, 128), nn.ReLU(),
        )
        self.film_base = nn.Linear(base_dim, 256)       # γ_c_base(128) + β_c_base(128)
        self.film_state = nn.Linear(state_dim, 256)     # γ_c_state(128) + β_c_state(128)
        self.novelty = nn.Linear(base_dim + 4, 1)       # [e_base; d_knn; u_obj; d_proto; ‖e_state‖]
        self.gamma_head = nn.Sequential(nn.Linear(128, 1), nn.Sigmoid())
        self.h_joint = nn.Sequential(nn.Linear(128, n_joints), nn.Sigmoid())
        self.h_sensor = nn.Sequential(nn.Linear(128, n_sensors), nn.Sigmoid())
        self.h_ee = nn.Sequential(nn.Linear(128, 1), nn.Sigmoid())
        self.p_failure = nn.Sequential(nn.Linear(128, 1), nn.Sigmoid())

    def forward(self, z, a, e_base, e_state, d_knn, u_obj, d_proto):
        h = self.backbone(torch.cat([z, a], dim=-1))
        gb = self.film_base(e_base)
        h = gb[:, :128] * h + gb[:, 128:]               # 身份 FiLM
        gs = self.film_state(e_state)
        h = gs[:, :128] * h + gs[:, 128:]               # 状态 FiLM（乘法融合）
        gamma_pred = self.gamma_head(h).squeeze(-1)
        h_j = self.h_joint(h)
        h_s = self.h_sensor(h)
        h_e = self.h_ee(h).squeeze(-1)
        p_f = self.p_failure(h).squeeze(-1)
        h_min = torch.minimum(torch.minimum(h_j.min(dim=-1)[0], h_s.min(dim=-1)[0]), h_e)
        nu_in = torch.cat([e_base,
                           d_knn.view(-1, 1), u_obj.view(-1, 1),
                           d_proto.view(-1, 1), e_state.norm(dim=-1, keepdim=True)], dim=-1)
        nu = torch.sigmoid(self.novelty(nu_in)).squeeze(-1)
        return gamma_pred, h_j, h_s, h_e, p_f, h_min, nu

        self.h_min, self.nu = float(h_min), float(nu)

        # 观测端估计 γ̂_obs, h_obs（简化：用力觉/视觉残差启发式估计）
        gamma_obs, h_obs = self._estimate_obs_confidence(obs, a_fast)

        # IV-LOOP：验证残差 + 分级响应
        r_bar = self._verification_step(z, a_vec, gamma_pred, h_j, h_s, h_e,
                                        gamma_obs, h_obs)
        self.r_bar = r_bar

        # KCL 压缩-校准
        gamma_c = self.cmap_c.compress(float(gamma_pred.detach()))
        gamma_corrected = self._cloud_correct(gamma_c)

        # 异步动作块合成
        if self.synth_future is None:
            c = self._build_cond(obs, a_fast)
            a_f = self._act2vec(a_fast)
            self.synth_future = self.executor.submit(
                self.synth.sample, c, 8, 4, 0.1, a_f)

        alpha = self._compute_alpha_adjusted(gamma_corrected)
        self.alpha_blend = alpha
        self.a_fast = a_fast
        return self._execute_blended(obs, a_fast, alpha)

    # ---------- IV-LOOP 核心：验证步 ----------
    def _verification_step(self, z, a_vec, gamma_pred, h_j, h_s, h_e,
                           gamma_obs, h_obs):
        # 马氏残差
        y_pred = torch.cat([gamma_pred.view(1), h_j.flatten(), h_s.flatten(), h_e.view(1)])
        y_obs  = torch.cat([gamma_obs.view(1), h_obs.flatten()])
        sigma = torch.tensor([self.u_obj, self.u_act] + [1/(self.h_min+1e-6)] * 17)
        r_t = torch.sqrt(((y_pred - y_obs)**2 / (sigma**2 + 1e-6)).sum())
        self.ver_window.append(float(r_t))
        r_bar = np.mean(self.ver_window) if self.ver_window else 0.0

        self.e_state_history.append(self.e_state.detach().cpu().numpy().copy())
        self.ver_history.append(float(r_t))

        # Level 2：一步梯度修正
        if r_bar > self.tau_ver:
            self.ver_fail_count += 1
            if self.ver_fail_count >= 3:
                # 近似梯度（有限差分，避免保存计算图）
                with torch.no_grad():
                    e_state_orig = self.e_state.clone()
                    best_e_state = e_state_orig
                    best_r = r_bar
                    for _ in range(5):                    # 5 方向随机搜索近似梯度
                        pert = torch.randn_like(e_state_orig) * 0.01
                        e_try = e_state_orig + pert
                        y_p = self._predict_only(z, a_vec, self.e_base.unsqueeze(0), e_try)
                        r_try = torch.sqrt(((y_p - y_obs)**2 / (sigma**2 + 1e-6)).sum())
                        if r_try < best_r:
                            best_r = r_try
                            best_e_state = e_try
                    if best_r < r_bar:
                        self.e_state = best_e_state
                        self._log_state_correction(r_bar, best_r)
                self.ver_fail_count = 0
        else:
            self.ver_fail_count = 0

        # Level 3：重克隆请求
        if r_bar > self.tau_ver and not self.reclone_pending:
            self.reclone_pending = True
            self.probe_queue.appendleft("RECLONE")
            self._log_verification_trigger(r_bar)

        # 车队原型偏离
        d_proto = self.proto_bank.distance(self.e_state, self.task_progress)
        if d_proto > self.tau_proto:
            self._escalate_fleet_anomaly(d_proto)

        return r_bar

    def _predict_only(self, z, a_vec, e_base, e_state):
        """仅前向预测，用于验证步梯度近似"""
        gamma_pred, h_j, h_s, h_e, _, _, _ = self.oc_head(
            z, a_vec, e_base, e_state,
            torch.tensor([0.0]), torch.tensor([0.0]), torch.tensor([0.0]))
        return torch.cat([gamma_pred.view(1), h_j.flatten(), h_s.flatten(), h_e.view(1)])

    # ---------- 置信调制：四重降级 ----------
    def _compute_alpha_adjusted(self, gamma_corrected):
        gamma_adjusted = gamma_corrected * self.h_min * (1.0 - self.eta * self.nu)
        var_approx = 0.05 / (self.h_min ** 2 + 1e-6)
        u_total = float(np.hypot(self.u_obj, self.u_act))
        alpha = gamma_adjusted * (1.0 - self.kappa * np.sqrt(var_approx)
                                       - self.kappa_u * u_total)
        alpha = alpha * (1.0 - self.rho * min(self.r_bar, 3.0))
        alpha = float(np.clip(alpha, 0.0, 1.0))

        if self.p_failure > self.tau_failure:
            alpha = min(alpha, 0.2)
            self._trigger_maintenance_alert()
        elif self.h_min < self.tau_health:
            alpha = min(alpha, 0.3)
            self._log_health_degradation()
        elif self.nu > self.tau_novel:
            alpha = min(alpha, 0.3)
            self._log_novel_object()
        elif self.r_bar > self.tau_ver:
            alpha = min(alpha, 0.2)
            self._log_verification_failure()
        return alpha

    # ---------- 三级专家级联 ----------
    def _execute_blended(self, obs, a_fast, alpha):
        a_f = self._act2vec(a_fast)
        if self.synth_future is not None and self.synth_future.done():
            A_synth, self.u_act = self.synth_future.result()
            self.synth_future = None

        if self.vla_future is not None:

            elif alpha > 0:
                return a_f + alpha * (self.vla_future - a_f)
        return a_f

    # ---------- 采集：验证驱动 ----------
    def on_idle(self, candidate_probes):

            return ("RECLONE", self.probe_queue[0], {}, 0.5)
        return super().on_idle(candidate_probes) if hasattr(super(), 'on_idle') else candidate_probes[0]
```

| 风险 | 缓解方案 |
|---|---|
| **状态声纹塌缩**：GRU 学到恒定 e_state，丢失时变信息 | ① ℒ_proto 强制向原型分离；② ℒ_pred_cons 强制预测一致性；③ GRU 隐含态正则化 ‖s_t‖² + ‖s_t−s_{t-1}‖² |

| **车队原型污染**：异构机器人/恶意上报污染 μ_k(τ) | ① 鲁棒聚类（HDBSCAN+DTW）剔除离群簇；② GP 回归自动量化不确定性 σ_k(τ) 大则低权；③ 仅下发 μ_k, σ_k，不下发原始轨迹 |
| **重克隆中断任务**：5 秒探测插入长时任务中破坏连贯性 | ① 探测原语设计为「任务兼容」（如倒水间隙摇晃瓶子）；② 若任务不允许中断，标记「待重克隆」任务结束后补做；③ 重克隆仅更新 e_base，e_state 连续性保持 |

## 5. 本轮最大的风险

```
e_state(t) = W_s s_t ∈ ℝ¹⁶           # 线性投影
```

**三重一致性监督**（训练阶段）：
```
ℒ_phys_dyn = ‖g_dyn(e_base, e_state(t)) − θ_phys(t)‖²          # θ_phys(t) = [mass, friction, CoM, fill, wear](t)
ℒ_pred_cons = ‖γ̂(z_t, e_base, e_state(t)) − γ̂_obs(t)‖²         # 真机自监督可做
ℒ_proto = −E[ log( exp(sim(e_state, μ_{y}⁺)/τ) / Σ_k exp(sim(e_state, μ_k)/τ) ) ]  # y ∈ {满,空,滑,粘,新,旧}
ℒ_total_state = λ_phys_dyn·ℒ_phys_dyn + λ_pred_cons·ℒ_pred_cons + λ_proto·ℒ_proto
# 典型权重：λ_phys_dyn=1.0, λ_pred_cons=0.5, λ_proto=0.3
```

### 1.3 IV-LOOP：迭代验证回环

**验证残差（每步）**：
```
y_pred = [γ̂_pred; h_joint; h_sensor; h_ee]
y_obs  = [γ̂_obs; h_joint_obs; h_sensor_obs; h_ee_obs]          # 在线估计：力觉滑移→γ̂_obs，视觉接触→h_obs
Σ_t = diag(u_obj², u_act², h_min⁻², ..., h_min⁻²)              # 对角近似
r_t = √( (y_pred − y_obs)ᵀ Σ_t⁻¹ (y_pred − y_obs) )
```

**分级响应**：
```
Level 1：W_ver ← W_ver ∪ {r_t}，r̄ = mean(W_ver)
Level 2：若 r̄ > τ_ver 连续 3 步 → e_state ← e_state − λ·∇_{e_state} r̄  （自动微分/有限差分，<0.1 ms）
Level 3：若修正后 r̄ > τ_ver 再持续 5 步 → 插入 RECLONE 探测，请求 5 秒重克隆 e_base_new
Level 4：若 ‖e_base_new − e_base_old‖ > τ_drift → fleet.report_mutation(hash, e_state_traj, r_traj, ctx)
```

**保守调制**：
```
α_blend ← α_blend · (1 − ρ·clip(r̄, 0, 3))
if r̄ > τ_ver: α_blend = min(α_blend, 0.2)
```

### 1.4 FLEET-CONSENSUS：车队共识验证

**验证信号上报**（T_report=10s，<1 KB）：
```
S_i = ( hash(e_base), e_state_traj[−100:], r_traj[−100:], task_ctx, outcome )
```

**云端原型拟合**（T_fit=1h）：
```
对每哈希簇 C_h：
  1. DTW 对齐 e_state_traj 到 τ ∈ [0,1]
  2. GP 回归：μ_h(τ) ~ GP(0, k(τ,τ')), σ_h²(τ) 后验方差
  3. 跨簇 DTW 聚类 → 全局原型 {μ_k(τ), σ_k(τ)}_{k=1..K}  (K=6)
  4. 下发：μ_k^0, μ_k(τ), σ_k(τ)
```

**边缘热启动与预警**：
```
新物体：e_base 入库 → h=hash(e_base) → h* = argmin_h DTW(h, h*) → e_state(0) = μ_{h*}(0)
执行中：d_proto = min_k ‖e_state(t) − μ_k(τ_t)‖ / σ_k(τ_t)
若 d_proto > τ_proto → 触发 Level 3 + 保守降级
```

```python
class GRUState(nn.Module):
    """轻量 GRU 状态跟踪器：x_t(168) -> s_t(32) -> e_state(16)"""

    def __init__(self, input_dim=168, hidden_dim=32, state_dim=16):
        super().__init__()
        self.gru = nn.GRU(input_dim, hidden_dim, batch_first=True)
        self.proj = nn.Linear(hidden_dim, state_dim)

    def forward(self, s_prev, x_t):                     # s_prev: 1 x 1 x 32, x_t: 1 x 1 x 168
        _, s_t = self.gru(x_t, s_prev)
        e_state = self.proj(s_t.squeeze(0))             # 1 x 16
        return s_t, e_state


class PrototypeBank:
    """本地情绪原型缓存：μ_k(τ), σ_k(τ) 离散化存储，支持插值查询"""

    def __init__(self, K=6, state_dim=16, n_tau=21):
        self.K = K
        self.state_dim = state_dim
        self.tau_grid = np.linspace(0, 1, n_tau)
        self.mu = np.zeros((K, n_tau, state_dim), dtype=np.float32)   # μ_k(τ)
        self.sigma = np.ones((K, n_tau, state_dim), dtype=np.float32) # σ_k(τ)
        self.loaded = False

    def load_from_cloud(self, proto_data):              # proto_data: dict from fleet
        self.mu = proto_data['mu']
        self.sigma = np.maximum(proto_data['sigma'], 0.05)  # 下限防除零
        self.loaded = True

    def get(self, hash_key):                            # 简化：返回最近簇的 μ_0
        if not self.loaded:
            return None
        return type('Proto', (), {'mu_0': self.mu[0, 0]})()

    def distance(self, e_state, task_progress):         # task_progress ∈ [0,1]
        if not self.loaded:
            return 0.0
        # 线性插值查询 μ_k(τ), σ_k(τ)
        tau = np.clip(task_progress, 0, 1)
        idx = int(tau * (self.mu.shape[1] - 1))
        alpha = tau * (self.mu.shape[1] - 1) - idx
        mu_t = (1 - alpha) * self.mu[:, idx] + alpha * self.mu[:, idx + 1]      # K x 16
        sigma_t = (1 - alpha) * self.sigma[:, idx] + alpha * self.sigma[:, idx + 1]
        d = np.linalg.norm((mu_t - e_state.detach().cpu().numpy()) / sigma_t, axis=1)
        return float(d.min())


class FiLMJointHeadDual(nn.Module):
    """双 FiLM 条件化预测头：e_base + e_state"""

    def __init__(self, latent_dim=128, base_dim=48, state_dim=16, action_dim=18,
                 n_joints=6, n_sensors=10):
        super().__init__()
        self.backbone = nn.Sequential(
            nn.Linear(latent_dim + action_dim, 256), nn.ReLU(),
            nn.Linear(256, 128), nn.ReLU(),
        )
        self.film_base = nn.Linear(base_dim, 256)       # γ_c_base(128) + β_c_base(128)
        self.film_state = nn.Linear(state_dim, 256)     # γ_c_state(128) + β_c_state(128)
        self.novelty = nn.Linear(base_dim + 4, 1)       # [e_base; d_knn; u_obj; d_proto; ‖e_state‖]
        self.gamma_head = nn.Sequential(nn.Linear(128, 1), nn.Sigmoid())
        self.h_joint = nn.Sequential(nn.Linear(128, n_joints), nn.Sigmoid())
        self.h_sensor = nn.Sequential(nn.Linear(128, n_sensors), nn.Sigmoid())
        self.h_ee = nn.Sequential(nn.Linear(128, 1), nn.Sigmoid())
        self.p_failure = nn.Sequential(nn.Linear(128, 1), nn.Sigmoid())

    def forward(self, z, a, e_base, e_state, d_knn, u_obj, d_proto):
        h = self.backbone(torch.cat([z, a], dim=-1))
        gb = self.film_base(e_base)
        h = gb[:, :128] * h + gb[:, 128:]               # 身份 FiLM
        gs = self.film_state(e_state)
        h = gs[:, :128] * h + gs[:, 128:]               # 状态 FiLM（乘法融合）
        gamma_pred = self.gamma_head(h).squeeze(-1)
        h_j = self.h_joint(h)
        h_s = self.h_sensor(h)
        h_e = self.h_ee(h).squeeze(-1)
        p_f = self.p_failure(h).squeeze(-1)
        h_min = torch.minimum(torch.minimum(h_j.min(dim=-1)[0], h_s.min(dim=-1)[0]), h_e)
        nu_in = torch.cat([e_base,
                           d_knn.view(-1, 1), u_obj.view(-1, 1),
                           d_proto.view(-1, 1), e_state.norm(dim=-1, keepdim=True)], dim=-1)
        nu = torch.sigmoid(self.novelty(nu_in)).squeeze(-1)
        return gamma_pred, h_j, h_s, h_e, p_f, h_min, nu


class IEVZestPolicy:
    """IEV-ZEST 主策略：继承 CG-ZEST，新增动态声纹+迭代验证+车队共识"""

    def __init__(self, node_id, drs_client, mm_encoder, ensemble, oc_head_dual,
                 synth, voicebank, cmap_comp, cmap_decomp, gamma_corr,
                 fleet_client, proto_bank):

        self.lambda_state = 0.1

        self.reclone_pending = False
        self.e_base_new = None
        self.e_state_history = []
        self.ver_history = []
        self.task_ctx = "unknown"
        self.task_progress = 0.0

        # 继承 CG-ZEST 参数
        self.cusum = 0.0
        self.surprise_window = deque(maxlen=5)
        self.gamma_hist = deque(maxlen=10)
        self.a_fast = "HOLD"
        self.alpha_blend = 0.0
        self.L_max = 0.3
        self.kappa = 1.0
        self.kappa_u = 2.0
        self.eta = 0.5
        self.tau_failure = 0.5
        self.tau_health = 0.7
        self.tau_novel = 0.8
        self.tau_esc = 0.05
        self.p_failure = 0.0
        self.h_min = 1.0
        self.vla_future = None
        self.vla_start = 0.0
        self.r_bar = 0.0

    # ---------- 动态声纹：身份克隆 + 状态热启动 ----------
    def ensure_voiceprint(self, obs):
        if self.e_base is not None:
            return
        # 复用 CG-ZEST 克隆逻辑（简化：直接调用 ensemble 编码）
        self.ref_buffer.append(self.mm_encoder(self._obs2dict(obs)).squeeze(0))
        if len(self.ref_buffer) >= self.T_ref:
            z_seq = torch.stack(self.ref_buffer).unsqueeze(0)
            e_stack = torch.stack([c(z_seq)[0].squeeze(0) for c in self.ensemble])
            e_full = e_stack.mean(0)                      # 64 维
            self.u_obj = float(e_stack.std(0).mean())
            self.e_base = e_full[:48]                     # 前 48 维为身份
            self.ref_buffer.clear()

            # 车队热启动
            h = self._hash_base(self.e_base)
            proto = self.proto_bank.get(h)
            if proto is not None:
                self.e_state = torch.tensor(proto.mu_0).view(1, 16)
            else:
                self.e_state = torch.zeros(1, 16)
            self.gru_hidden = torch.zeros(1, 1, 32)
            self._log_clone_done(self.e_base, self.e_state)

    def _hash_base(self, e_base):
        return hash(e_base.detach().cpu().numpy().tobytes())

    # ---------- 主循环 ----------
    def get_action(self, obs):
        self.M_local.update(obs)
        _ = self.drs.get_weights()
        self.ensure_voiceprint(obs)
        if self.e_base is None:
            return self._execute_blended(obs, self.probe_queue[0], 0.0)

        obs_dict = self._obs2dict(obs)
        z = self.mm_encoder(obs_dict, self._check_modality_availability(obs))

        a_fast = self._select_fast_action(obs)
        a_vec = self._act2vec(a_fast)
        e_base_b = self.e_base.unsqueeze(0)
        e_state_b = self.e_state
        d_knn = torch.tensor([self.voicebank.knn_distance(
            self.e_base.detach().cpu().numpy())], dtype=torch.float32)
        u_obj = torch.tensor([self.u_obj], dtype=torch.float32)
        d_proto = torch.tensor([self.proto_bank.distance(self.e_state, self.task_progress)],
                               dtype=torch.float32)

        gamma_pred, h_j, h_s, h_e, p_f, h_min, nu = \
            self.oc_head(z, a_vec, e_base_b, e_state_b, d_knn, u_obj, d_proto)
        self.h_joint, self.h_sensor = h_j, h_s
        self.h_ee, self.p_failure = float(h_e), float(p_f)
        self.h_min, self.nu = float(h_min), float(nu)

        # 观测端估计 γ̂_obs, h_obs（简化：用力觉/视觉残差启发式估计）
        gamma_obs, h_obs = self._estimate_obs_confidence(obs, a_fast)

        # IV-LOOP：验证残差 + 分级响应
        r_bar = self._verification_step(z, a_vec, gamma_pred, h_j, h_s, h_e,
                                        gamma_obs, h_obs)
        self.r_bar = r_bar

        # KCL 压缩-校准
        gamma_c = self.cmap_c.compress(float(gamma_pred.detach()))
        gamma_corrected = self._cloud_correct(gamma_c)

        # 异步动作块合成
        if self.synth_future is None:
            c = self._build_cond(obs, a_fast)
            a_f = self._act2vec(a_fast)
            self.synth_future = self.executor.submit(
                self.synth.sample, c, 8, 4, 0.1, a_f)

        alpha = self._compute_alpha_adjusted(gamma_corrected)
        self.alpha_blend = alpha
        self.a_fast = a_fast
        return self._execute_blended(obs, a_fast, alpha)

    # ---------- IV-LOOP 核心：验证步 ----------
    def _verification_step(self, z, a_vec, gamma_pred, h_j, h_s, h_e,
                           gamma_obs, h_obs):
        # 马氏残差
        y_pred = torch.cat([gamma_pred.view(1), h_j.flatten(), h_s.flatten(), h_e.view(1)])
        y_obs  = torch.cat([gamma_obs.view(1), h_obs.flatten()])
        sigma = torch.tensor([self.u_obj, self.u_act] + [1/(self.h_min+1e-6)] * 17)
        r_t = torch.sqrt(((y_pred - y_obs)**2 / (sigma**2 + 1e-6)).sum())
        self.ver_window.append(float(r_t))
        r_bar = np.mean(self.ver_window) if self.ver_window else 0.0

        self.e_state_history.append(self.e_state.detach().cpu().numpy().copy())
        self.ver_history.append(float(r_t))

        # Level 2：一步梯度修正
        if r_bar > self.tau_ver:
            self.ver_fail_count += 1
            if self.ver_fail_count >= 3:
                # 近似梯度（有限差分，避免保存计算图）
                with torch.no_grad():
                    e_state_orig = self.e_state.clone()
                    best_e_state = e_state_orig
                    best_r = r_bar
                    for _ in range(5):                    # 5 方向随机搜索近似梯度
                        pert = torch.randn_like(e_state_orig) * 0.01
                        e_try = e_state_orig + pert
                        y_p = self._predict_only(z, a_vec, self.e_base.unsqueeze(0), e_try)
                        r_try = torch.sqrt(((y_p - y_obs)**2 / (sigma**2 + 1e-6)).sum())
                        if r_try < best_r:
                            best_r = r_try
                            best_e_state = e_try
                    if best_r < r_bar:
                        self.e_state = best_e_state
                        self._log_state_correction(r_bar, best_r)
                self.ver_fail_count = 0
        else:
            self.ver_fail_count = 0

        # Level 3：重克隆请求
        if r_bar > self.tau_ver and not self.reclone_pending:
            self.reclone_pending = True
            self.probe_queue.appendleft("RECLONE")
            self._log_verification_trigger(r_bar)

        # 车队原型偏离
        d_proto = self.proto_bank.distance(self.e_state, self.task_progress)
        if d_proto > self.tau_proto:
            self._escalate_fleet_anomaly(d_proto)

        return r_bar

    def _predict_only(self, z, a_vec, e_base, e_state):
        """仅前向预测，用于验证步梯度近似"""
        gamma_pred, h_j, h_s, h_e, _, _, _ = self.oc_head(
            z, a_vec, e_base, e_state,
            torch.tensor([0.0]), torch.tensor([0.0]), torch.tensor([0.0]))
        return torch.cat([gamma_pred.view(1), h_j.flatten(), h_s.flatten(), h_e.view(1)])

    # ---------- 置信调制：四重降级 ----------
    def _compute_alpha_adjusted(self, gamma_corrected):
        gamma_adjusted = gamma_corrected * self.h_min * (1.0 - self.eta * self.nu)
        var_approx = 0.05 / (self.h_min ** 2 + 1e-6)
        u_total = float(np.hypot(self.u_obj, self.u_act))
        alpha = gamma_adjusted * (1.0 - self.kappa * np.sqrt(var_approx)
                                       - self.kappa_u * u_total)
        alpha = alpha * (1.0 - self.rho * min(self.r_bar, 3.0))
        alpha = float(np.clip(alpha, 0.0, 1.0))

        if self.p_failure > self.tau_failure:
            alpha = min(alpha, 0.2)
            self._trigger_maintenance_alert()
        elif self.h_min < self.tau_health:
            alpha = min(alpha, 0.3)
            self._log_health_degradation()
        elif self.nu > self.tau_novel:
            alpha = min(alpha, 0.3)
            self._log_novel_object()
        elif self.r_bar > self.tau_ver:
            alpha = min(alpha, 0.2)
            self._log_verification_failure()
        return alpha

    # ---------- 三级专家级联 ----------
    def _execute_blended(self, obs, a_fast, alpha):
        a_f = self._act2vec(a_fast)
        if self.synth_future is not None and self.synth_future.done():
            A_synth, self.u_act = self.synth_future.result()
            self.synth_future = None
            if float(self.u_act.mean()) > self.tau_esc:
                self._escalate_to_cloud_vla(obs)
            if alpha > 0 and self.vla_future is None:
                a_s = A_synth[0, 0].view(1, -1)
                return a_f + alpha * (a_s - a_f)
        if self.vla_future is not None:
            if time.time() - self.vla_start > self.L_max:
                self.vla_future = None
            elif alpha > 0:
                return a_f + alpha * (self.vla_future - a_f)
        return a_f

    # ---------- 采集：验证驱动 ----------
    def on_idle(self, candidate_probes):
        if self.r_bar > self.tau_ver:
            return ("RECLONE", self.probe_queue[0], {}, 0.5)
        return super().on_idle(candidate_probes) if hasattr(super(), 'on_idle') else candidate_probes[0]

    def on_block_finished(self, success, vla_latency=None):
        if self.e_base is not None and self.reclone_pending:
            if self.e_base_new is not None:
                drift = torch.norm(self.e_base_new - self.e_base).item()
                if drift > self.tau_drift:
                    self.fleet.report_mutation(
                        self._hash_base(self.e_base),
                        self.e_state_history, self.ver_history, self.task_ctx)
                self.e_base = self.e_base_new
                self.reclone_pending = False
                self.e_base_new = None
        # CG-ZEST 原有逻辑
        raw = 1.0 - np.mean(list(self.surprise_window))
        self.cusum = max(0.0, self.cusum + raw - 0.15)
        self.gamma_hist.append(raw)

    # ---------- 存根 ----------
    def _estimate_obs_confidence(self, obs, a_fast):
        # 简化：力觉滑移/接触力残差启发式估计 γ̂_obs, h_obs
        return torch.tensor([0.8]), torch.ones(18) * 0.85

    def _build_cond(self, obs, a_fast):
```

## 4. 风险与缓解

| 风险 | 缓解方案 |
|---|---|
| **状态声纹塌缩**：GRU 学到恒定 e_state，丢失时变信息 | ① ℒ_proto 强制向原型分离；② ℒ_pred_cons 强制预测一致性；③ GRU 隐含态正则化 ‖s_t‖² + ‖s_t−s_{t-1}‖² |
| **验证残差虚警**：观测噪声/模型误差导致 r_t 假阳性，频繁触发重克隆 | ① 马氏距离自适应 Σ_t（含 u_obj/u_act/h_min）；② 连续 N=3 步 + 滑动窗口均值双重确认；③ 重克隆冷却期 30 s；④ ρ=0.15 保守调制平滑过渡 |
| **一步梯度修正不稳定**：梯度方向错误、步长过大导致 e_state 发散 | ① λ=0.1 固定小步长；② 梯度裁剪 ‖grad‖ ≤ 1.0；③ 修正后残差若增大则回滚；④ 仅修正 e_state，不动 e_base |
| **车队原型污染**：异构机器人/恶意上报污染 μ_k(τ) | ① 鲁棒聚类（HDBSCAN+DTW）剔除离群簇；② GP 回归自动量化不确定性 σ_k(τ) 大则低权；③ 仅下发 μ_k, σ_k，不下发原始轨迹 |
| **重克隆中断任务**：5 秒探测插入长时任务中破坏连贯性 | ① 探测原语设计为「任务兼容」（如倒水间隙摇晃瓶子）；② 若任务不允许中断，标记「待重克隆」任务结束后补做；③ 重克隆仅更新 e_base，e_state 连续性保持 |

## 5. 本轮最大的风险

**验证残差的「自监督地面真值」获取：y_obs = [γ̂_obs; h_obs] 需要在线从力觉/视觉/本体估计「真实的置信与健康度」，但这些量本身就是隐变量、无直接传感器测量——若观测端估计有偏（如系统性低估摩擦），验证残差会「以错证错」，导致 e_state 修正朝错误方向漂移，形成「验证-状态」双重失效闭环。**
