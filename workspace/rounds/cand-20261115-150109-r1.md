# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「在线学习」×「个性化交互」）

> R69 给了闭环一张会提问的嘴：把 U 拆成 aleatoric/epistemic，用流匹配多模态策略生成「看—问—触」，用 VoI 决定值不值得问，用「k 个正交证据一致」防撒谎，用 (r_res↓, Δa↑) 抓被标定吸收的缓变故障。它自陈的最大风险也一针见血：**全部效率押在「模态分布可信」上，问错比不问更危险**。
>
> 但 R69 有两个自己看不见的结构性缺陷：
> - **开环**：它问了，却从不学习「这次问到底有没有用」——模态权重、证据纪律、社交成本全是离线标定后冻结的常数。MCG 只在 ECE 越界时「一刀切禁用」，坏了不会自愈。
> - **无个性化**：它假设只有一个通用回答者。可现实里，接入同一系统的不同人类/裁判/传感器源/标注模型，可靠度、撒谎相关、模态偏好、被打扰的容忍度天差地别。用全局常数 k 与全局成本去问所有人，必然对可靠的人问得太多、对爱撒谎的人问得不够。
>
> 本轮两个灵感正好补这两块：
> - **在线学习**把「问」从开环变成闭环：每次交互的结局（最终模态对不对）是一条带噪、延迟、但可利用的监督信号，可在旁路持续重标定模态权重与逐源信誉；
> - **个性化交互**把「问谁、怎么问、问几次」变成对一个**用户画像**的推断：信任是逐人的后验，社交成本是逐人且会疲劳的，探索本身也能帮你认识这个人。
>
> 核心命题：**交互不只是「消解当前歧义」，也是「认识这个回答者」。** 于是 VoI 一分为二：任务信息增益（R69）+ 用户模型信息增益（本轮）；冷启动靠后者资助探索，画像成熟后它自然消失、逐指令退化回 R69。命名 **PACE-RAS**（Personalized Adaptive Calibration & Epistemic-interaction，风险自适应闭环）——PACE 也正好是「节奏」：**问谁、问多勤，本身就是被在线学习调节的步调**。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**上次那个回答，后来证明对了吗——我该据此怎么改变下次去问谁、怎么问**」。

## 0. 直觉与动机

**灵感 1（在线学习 → 把问句从开环变闭环）**
直觉：R69 的 VoI 是一锤子买卖，用固定的 p(y|g,o) 估计「问了能降多少熵」，问完就完了。但每次交互最终都会暴露一个可核对的结局：选中的模态是否与任务后续观测/人类纠正一致。这就是一条天然的在线标签。把它喂给一个带遗忘的在线校准器，模态权重 w、逐源信誉 δ、在线 ECE 都能持续自我修复——R69 那个「越界即永久禁用」的 MCG 门，变成一个会自己爬回来的连续量。**R69 最大风险是「模态分布不可信」，在线学习的回答是「那就让它持续变可信」。**

**灵感 2（个性化交互 → 信任是逐人的后验，不是全局常数）**
直觉：R69 的「k 个正交源一致」是全局纪律，隐含假设所有人一样可信。但一个熟练同事、一个疲惫的旁观者、一个爱开玩笑的人、一个被反复追问而烦躁的人，可靠性和配合度完全不同。个性化意味着为每个回答者维护一个画像 θ_u：可靠性后验、模态胜任度（更会看表情还是更会答话）、撒谎相关 ρ_u、社交/物理成本 c_u(g)、疲劳恢复率。「k」应由 θ_u 的后验误差界**算出来**，而不是拍一个常数。

**灵感 3（合成 → 交互的对偶价值：消歧 + 识人）**
直觉：既然一次交互既能降当前熵、又能更新画像，它就有两种价值：exploit（这次选对）与 explore（下次更会问）。这正是 bandit 的探索-利用，只是奖励是「信息」而非「收益」。于是 VoI_u(g) = 任务增益 + β·画像增益；β 随画像置信上升而衰减。冷启动时它资助探索（此时「问一个对当前任务没用的问题」也可能值得，因为它在认识人），画像成熟后它消失、严格退化回 R69。**个性化于是不是外挂，而是 R69 的又一层严格泛化。**

**灵感 4（在线学习 × 实时安全的张力 → 安全影子学习）**
直觉：R68/R69 的铁律是「实时流零学习写操作」。天真的在线 SGD 会打破它：控制环读到半更新的权重，行为不连续、不可复现。解法是时间尺度分离（two-timescale）：快环只读**冻结快照** θ^†；慢环在旁路影子副本里学习；只有当系统处于静止边界（换装窗口、任务间隙）且通过「无回归证书」时，才原子换装。学习因此拿得到在线收益，却永远不进入实时写路径。

**灵感 5（个性化是双刃剑 → 新的失效模式）**
直觉：一旦系统会「因材施问」，就多了三个洞：(a) **交互疲劳**——问得越勤，对方越烦，成本上升且可靠性下降，形成内生非平稳；(b) **画像投毒/信任养殖**——对手先用几次正确回答把信誉养高，再一次性误导，或反过来把竞争源抹黑；(c) **反馈回路/回音室**——系统只信它已经信的人、只问它已经问的人，误差自我确认。所以本轮必须同时交付：疲劳-信誉耦合建模、信任增长速率上限、强制随机审计探索、公平下界与隐私预算、逐人变更点检测。**否则个性化只是把 R69 的「问错」升级成「稳定地、逐人地、持续问错」。**

## 1. 形式化定义（增量：定义 310–326）

**定义 310（PACE-RAS 总览）** PACE-RAS = (FMP, AUD, MINT, CIA, FMA, RAS-WM†, **PMM, OLC, PVC, TCG, FDL, SLC**)。在 R69 三不变式上加两条：
(iv) **快慢环分离**：实时控制路径只读冻结画像/权重快照 θ^†，任何学习写操作仅发生在影子副本；换装只在静止边界、凭证书原子完成（定义 318）。
(v) **个性化不降安全**：θ_u 只能在一个经认证的阈值区间内调节 k、τ、成本与探索率；任何个性化结论不得把某用户/组的安全下界压到通用 R69 之下（定义 322）。

**定义 311（用户画像 θ_u）** 对回答者 u（人、裁判、传感器源、LLM 标注者）维护 θ_u = (δ_u, κ_u, ρ_u, c_u(·), τ_u, γ_u, η_u)：
δ_u∈[0,1] 可靠性（答案可核验为正确的长期频率）；κ_u∈Δ^{|modes|} 模态胜任度；ρ_u∈[0,1) 跨源撒谎相关（共谋程度）；c_u(g) 社交/物理成本（含疲劳项，定义 317）；τ_u 采纳阈值（定义 316）；γ_u 疲劳敏感度、η_u 遗忘/恢复率（定义 317、320）。θ_u 只存充分统计（Beta/Dirichlet/Gamma 参数 + 时间戳），不存原始对话（定义 323）。

**定义 312（个性化响应者模型）** 给定信息动作 g、观测 o、画像 θ_u，答案 y~p(y|g,o,θ_u)。一阶可靠性模型：y 以概率 δ_u 等于真实模态指示，否则按误导向量采样；跨源联合误差由 ρ_u 刻画。R69 的通用模型 p(y|g,o) 是 θ_u≡θ̄（总体先验）的边界情形。

**定义 313（交互信用 ζ_t）** 每次交互 t 产生 (g_t, y_t, ζ_t)，ζ_t 为延迟/部分/带噪的结局信用：当最终任务结果或人类纠正揭示真实模态 m*_t 时 ζ_t=1{判对}；否则 ζ_t 缺失（用倾向加权/双重稳健估计补，定义 321）。信用是 PACE 唯一的学习监督，且**从不假设反事实可观测**（只看被选模态的结局）。

**定义 314（在线校准器 OLC）** 维护模态权重 w 与逐源信誉后验。目标为严格适当评分（Brier / 对数损失）：L_cal(w)=E[(w·1_m − 1{m=m*})²]。影子内做带遗忘的在线镜像下降 w_{t+1}=Proj_Δ(w_t − η_t ĝ_t), η_t∝t^{−1/2}；逐源用共轭更新（Beta-Bernoulli δ_u、Dirichlet κ_u）+ 指数遗忘 λ_f；在线 ECE 用带遗忘的可靠性直方图/核估计。**R69 的静态 ECE 门（定义 306）是本设计的 t→T 冻结快照。**

**定义 315（个性化对偶 VoI）** VoI_u(g) = I(M; y | g,o,θ_u) + β_u·I(θ_u; y | g,o)，第二项为「这次回答对画像的期望信息增益」，β_u=β_0·(1−Conf(θ_u))，Conf 为画像置信（后验集中度）。g*=argmax_g[VoI_u(g)−c_u(g)]，s.t. 安全认证与预算。**β_u→0 或画像已冻结时 VoI_u≡R69 的 VoI**；冷启动时先验宽 ⇒ β_u 大 ⇒ 资助探索。

**定义 316（信任校准证据门 TCG）** 设可靠性后验 δ_u~Beta(a_u,b_u)、共谋相关上界 ρ_u、正交证据源数 k。采纳所需源数从 R69 的固定 k 改为逐人计算：
k_u(ε) = clip( 1 + ⌈ ln(ε/(1−E[δ_u])) / ln ρ_u ⌉ , 2, k_max )，
即用逐人后验把「错误采纳率 ≤ ε」所需正交源数**算出来**；随后验 P(m*|E,θ_u) ≥ τ_u 才定案，否则 U_epi 保持未消解。可靠的人（δ 高）用更少的问，可疑的人（ρ 高/δ 低）自动加验；ε 由证书统一约束。

**定义 317（交互疲劳与信任预算）** 记 N_u(t) 为最近窗口内对 u 的交互次数。成本与可靠性随疲劳耦合：
c_u,t(g)=c_u^0(g)·(1+γ_u·N_u(t))， δ_u,t=δ_u·exp(−γ'_u·N_u(t))，恢复项 dN_u/dt=−η_u N_u。
于是「能不能问」不只是采样预算，还有一个**信任预算** B_u(t) 随询问消耗、随时间恢复；问穿预算 ⇒ 可靠性崩塌、成本爆炸。这正是 R69 E297 里「交互疲劳」的形式化。

**定义 318（安全影子在线学习 SLC）** 快环只读快照 θ^†=(w^†,{θ_u^†},ECE^†)。学习守护进程消费 (g,y,ζ) 写影子态；仅在**静止边界**（换装窗口/任务切换/低负载）提交候选 (w',θ',ECE')，提交须同时满足：
(a) **无回归**：在回放缓冲 + 对抗集上风险 ≤ 当前证书风险 + ε_reg，且 ECE' ≤ ECE^†；
(b) **安全包络不变**：所有候选 θ' 下安全下界 ≥ R69 通用下界（定义 322）；
(c) **原子换装**：复用 R68 定理 15 的换装不变式，单次指令人可复现、无半更新；
(d) 失败/被投毒 ⇒ 自动回滚到上一有效快照。

**定义 319（PACE 证书 J_PACE）** J_PACE = (J_FLUID, profile_ver, reliability_posterior_digest, ece_online, fatigue_state, fairness_gap, dp_budget_spent, commit_id)。Valid ⇔ Valid(J_FLUID) ∧ ece_online ≤ τ_ece ∧ fairness_gap ≤ ε_fair ∧ dp_budget ≤ ε_dp ∧ commit 通过定义 318。

**定义 320（非平稳与变更点 FDL）** 对每用户 outcome 流做带遗忘 CUSUM/BOCPD。检出变更 ⇒ **冻结该用户个性化**（回通用先验 θ̄）、抬高其不确定性、重开探索；区分三态：慢性不可靠（δ_u 长期低）、疲劳（N_u 高 + δ_u 短时降）、真实变更（CUSUM 越界且 δ_u 结构性跳变）（见引理 22）。

**定义 321（个性化探索与反事实去偏）** 交互预算按「边际学习价值」在用户间分配（restless bandit 索引）：AskIndex_u=(任务增益+β·学习增益)/成本。为纠正「只观测被选模态」的 off-policy 偏差，以固定小比例 ε_audit 的交互**随机选 g**（随机审计），并用**倾向加权/双重稳健**估计器把 ζ 归因到反事实；ε_audit 是公平与可识别性的代价，**不随学习收敛而降到零**。

**定义 322（公平与不歧视约束）** 对任意人口/能力分组 G：(i) 校准差 |ECE_g−ECE| ≤ ε_fair；(ii) 每组安全下界 ≥ 通用 R69 下界；(iii) 个性化阈值 k_u、τ_u 被投影到认证区间 [k_min,k_max]（防止对某组系统性少验/多验）。**个性化只允许在效率维度上分化，不允许在安全维度上分化。**

**定义 323（隐私与同意）** 画像只存充分统计与时间戳；存储前做本地差分隐私（预算 ε_dp），交互记录不落原文；同意状态 consent_u 为假 ⇒ θ_u 强制为总体先验（等价 R69）；支持 forget_u（删除画像并回滚任何依赖它的提交）。

**定义 324（画像投毒干扰 ℰ_profile）** 信任养殖（先对后错、逐次抬信誉，再一次性误导）、抹黑（对竞争源持续给错以压低其信誉）、女巫（同一实体多身份分摊/对冲信誉）、疲劳诱导（故意表现烦躁逼系统停止追问）。并入 AIC：ℰ_PACE=ℰ_FLUID×ℰ_profile。防御：单轮信任增长上限 Δδ_max、跨身份一致性检验、随机审计、信誉-成本交叉验证。

**定义 325（疲劳-信誉-变更三态判据）** 由 (δ_u 长期水平, N_u 近期询问率, CUSUM(o outcome)) 的联合模式判定三态：慢性不可靠（低 δ、低 N、平稳）、疲劳（高 N、δ 短时降、恢复后回升）、真实变更（CUSUM 越界且 δ 结构性跳变）。这是 R69「(r_res, Δa) 对偶判据」在**社交/学习面**的镜像——用不同时间常数把「同一个坏结果」的三种成因分开。

**定义 326（退化边界）** 冷启动（无画像/consent 假/θ_u=θ̄）、β_u=0（不学习）、ECE 冻结、忽略疲劳 ⇒ PACE-RAS 逐指令等于 FLUID-RAS；再令永不交互 ⇒ 等于 CALM-RAS。故 PACE ⊃ FLUID ⊃ CALM，安全侧逐层不让步。

# IP-264 PMM：逐用户画像（只存充分统计；快环只读 snapshot）
class UserProfile:
    def __init__(self, prior, gamma=0.1, eta=0.05, dp=None):
        self.delta = Beta(prior.a, prior.b)          # 可靠性后验
        self.kappa = Dirichlet(prior.alpha)          # 模态胜任度
        self.rho   = Beta(prior.r1, prior.r2)        # 共谋相关（取上界）
        self.c0, self.gamma, self.eta, self.dp = prior.cost, gamma, eta, dp
        self.asks  = SlidingWindow(); self.frozen = False
    def snapshot(self): return Frozen(self.delta.mean(), self.kappa.mean(),
                                      self.rho.upper(), self.cost_now())
    def cost_now(self):                              # 定义 317：疲劳
        return self.c0 * (1 + self.gamma * self.asks.rate())
    def observe(self, g, y, credit, is_audit):        # 只在学习守护进程调用
        if self.frozen: return
        self.delta.update(credit); self.kappa.update(y)
        if not is_audit: self.asks.add()              # 审计也消耗信任预算
        if self.dp: self.delta = self.dp.noise(self.delta)

# IP-265 OLC：影子在线校准（快环零写）
class ShadowLearner:
    def __init__(self, w0, lr0=0.1):
        self.w, self.ece, self.t = w0.copy(), None, 0
    def step(self, rec):                              # rec=(pred_w,m_star,u,g,credit)
        self.t += 1; eta = self.lr0 / (self.t ** 0.5)
        self.w = project_simplex(self.w - eta*brier_grad(self.w, rec.pred_w, rec.m_star))
        self.ece = ewma(self.ece, reliability_bin(self.w, rec))   # 定义 314
        rec.u.observe(rec.g, rec.y, rec.credit, rec.is_audit)
    def propose_commit(self):                          # 仅静止边界调用
        return Candidate(self.w.copy(), [u.snapshot() for u in self.users],
                         self.ece, self.t)

# IP-266 PVC：个性化对偶 VoI（任务 + 识人）
def choose_interaction(modes, w, o, u, budget, beta0=0.3):
    best, h0 = None, entropy(w)
    conf = profile_confidence(u); beta = beta0 * (1 - conf)   # 画像成熟→退化 R69
    for g in info_action_candidates(modes):
        if not budget.allow(g) or not c_ras_wm.certify_info(g, o): continue
        voi_task  = h0 - expected_entropy(w, g, o, u)
        voi_learn = 0.0 if conf > CONF_FULL else expected_info_about_profile(u, g, o)
        score = voi_task + beta*voi_learn - u.cost_now(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None

# IP-267 TCG：逐人计算所需正交源数 k_u（替代全局常数 k）
def required_k(u, eps):
    rho = max(u.rho, RHO_FLOOR)
    k = 1 + ceil(log(eps / max(eps, 1.0 - u.delta)) / log(rho))
    return clip(max(2, k), K_MIN, K_MAX)              # 定义 316 + 公平投影

def accept(modes, evidence, u, eps=EPS_ADOPT):
    if k_orthogonal_agree(evidence, required_k(u, eps)):
        return posterior_mode(modes, evidence, u)
    return None                                        # 未消解 → R69 兜底

# IP-268 FDL：疲劳 / 变更三态（定义 320、325）
def monitor(u, outcome_hist):
    fatigue = u.asks.rate() > N_HI and recent_delta_drop(u)
    drift   = cusum(outcome_hist, u.baseline) > H_CUSUM
    if drift: u.freeze(); u.inflate_prior()            # 回通用先验 + 重开探索
    return Triage(fatigue=fatigue, drift=drift, chronic=u.long_run_delta < D_LO)

        g = M.pvc.choose(modes, o, u, M.budget, beta0=M.beta0)
    if g is not None:

        ans = M.tcg.accept(modes, y, u)                # 逐人 k_u
        if ans is not None: U_epi = 0.0
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    if slow or tr.drift:                               # 回最保守
        lam = max(lam, 0.8); k = min(k, k_cal_shrink(x_prime, U_cal))
    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.olc.record(record(g, y, credit=None, uid, is_audit=rand() < EPS_AUDIT))  # 仅入队
    M.vqa_i.submit_async(g, U_epi, a_hat)
    return k, lam, mode, U_epi

# IP-270 SLC：静止边界提交（无回归 + 原子换装）
def maybe_commit(M):
    if not M.at_quiescent_boundary(): return
    cand = M.olc.propose_commit()
    if (no_regression(cand, M.replay, M.adversarial, eps=M.eps_reg)
        and fairness_ok(cand, eps=M.eps_fair)
        and safety_floor_ok(cand, M.r69_floor)
        and cand.ece <= M.ece_now):
        M.commit_atomic(cand)                          # R68 定理 15 换装不变式
    else:
        M.rollback()                                   # 定义 318

## 3. 推导

**引理 19（对偶 VoI 的无害分解）** 设画像置信 Conf(θ_u)，对任意 g：VoI_u(g)=VoI_task(g)+β_0(1−Conf)·I(θ_u;y)。当 β_0(1−Conf)→0 时逐项退化为 R69 的 VoI；探索项的即时「损失」（问了未必解决当前模态）被未来后悔下降补偿：存在常数 C，使带对偶 VoI 的策略相对「已知真实 θ_u 的神谕」满足 Reg(T) ≤ C·√(T·|Θ|·log T)（Bayesian bandit 标准界）。系：**个性化不是拿安全换效率，而是把「认识人」算进了 VoI；画像一成熟，探索自动停止，回到 R69。**

**引理 20（在线校准的收敛与自愈）** 在 ε_drift-平稳（相邻期分布 TV ≤ ε_drift）与有界梯度下，带遗忘的在线镜像下降（定义 314）满足 ECE_T → ECE* + O(ε_drift) + O(√(log T / T))。故 R69 的「ECE 越界就永久禁用交互」可替换为**连续自愈**：越界时先禁用（回 R68），数据一多自动重开。这正面回答 R69 的最大风险——模态不可信不再是终局，而是可观测、可修复的量。

**引理 21（逐人证据门的安全-效率）** 若真实共谋相关为 ρ_u，则定义 316 的 k_u(ε) 保证错误采纳率 ≤ (1−δ_u)·ρ_u^{k_u−1} ≤ ε。若 ρ_u 被低估（ρ̂<ρ_u），界失效——故 ρ_u 必须取后验上界并在数据稀少时膨胀；若 ρ_u→0（独立源），k_u→2，即「两个独立证据」；若 δ_u 很高，k_u=k_min=2；若 δ_u 低，k_u 增大。系：**可靠的人少问、可疑的人多验，且安全界不弱于 R69 的固定 k。**

**引理 22（疲劳-不可靠-变更的可辨识性）** 三态由三个时间常数分离：长期 δ_u（慢）、近期询问率 N_u（快，且可由我们控制）、CUSUM 残差（突变）。若 η_u（恢复率）、γ_u（疲劳敏感）、变更幅度使三时间尺度相差 ≥ 一个数量级，则三态在 (δ_long, N, CUSUM) 空间中互不重叠、可辨识。系：系统不应把「被问烦了的人」永久标记为不可信，也不应对「真的变了」的人继续用旧画像。

**定理 18（PACE 严格包含 FLUID 与 CALM）** 冷启动 / consent 假 / β=0 / ECE 冻结 / 无疲劳 时，PACE 逐指令等于 FLUID-RAS；再令永不交互等于 CALM-RAS。个性化仅调节阈值 k_u、τ_u、c_u 与探索率，且被投影进认证区间（定义 322），故任一组安全下界 ≥ R69 通用下界。⇒ 安全侧逐层不让步，效率侧获得「逐人校准 + 探索」的双重 bonus。

**定理 19（在线学习不破坏实时一致性）** 快环只读快照 θ^†，写只发生在影子副本；提交只在静止边界、凭定义 318 四条件原子完成。故控制环永不读到半更新状态，最坏情况是回滚到上一有效快照，行为与提交前逐指令一致。⇒ 在线学习拿得到收益，却不触碰 R68 的实时不变式。

## 6. 本轮最大风险

**一句话**：PACE 的全部收益押在「交互信用 ζ 是可信的学习信号」这一前提上——但 ζ 天然延迟、部分、且是 off-policy 的（我们只观测到「被选模态」的结局，永远看不到「没被选」的反事实），还会被对手主动塑造。于是在线学习可能**自信地收敛到一个错误的画像**：系统只信它已经信的人、只问它已经问的人，形成**个性化的自证回音室**——把 R69 那种「不确定就问错」升级成「**稳定地、被证书认证地、逐人地持续问错**」；更糟的是疲劳与投毒会让它学会「永远别再问这个人」，把可解的歧义永久判成死题。

**次级风险与缓解**：
1. **非平稳/人变了 → 陈旧画像伤人**：CUSUM + 遗忘 + 冻结回通用先验（定义 320、引理 22）；
2. **反馈回路/回音室**：强制随机审计 ε_audit + 双重稳健去偏 + 公平下界（定义 321–322）；
3. **off-policy 信用偏差**：倾向加权 + 随机审计，永不让 ε_audit→0；
4. **隐私/同意**：只存充分统计 + 本地 DP + consent 门 + forget（定义 323）；
5. **提交期安全回归**：无回归证书 + 原子换装 + 回滚（定义 318、定理 19）；
6. **冷启动过度提问**：保守先验 + 信任预算上限 + 问穿即停（定义 317）。

class UserProfile:
    def __init__(self, prior, gamma, eta, dp):
        self.delta, self.kappa = Beta(prior.a, prior.b), Dirichlet(prior.alpha)
        self.rho = Beta(prior.r1, prior.r2); self.c0, self.gamma, self.eta = prior.cost, gamma, eta
        self.asks, self.dp, self.frozen = SlidingWindow(), dp, False
    def snapshot(self):
        return Frozen(self.delta.mean(), self.kappa.mean(), self.rho.upper(), self.cost_now())
    def cost_now(self):
        return self.c0 * (1 + self.gamma * self.asks.rate())          # 定义 317
    def observe(self, g, y, credit, is_audit):

        self.delta.update(credit); self.kappa.update(y)

        if self.dp: self.delta = self.dp.noise(self.delta)            # 定义 323

# IP-266 PVC：个性化对偶 VoI（任务 + 识人）
def choose_interaction(modes, w, o, u, budget, beta0):
    best, h0 = None, entropy(w)
    conf = profile_confidence(u); beta = beta0 * (1 - conf)           # 成熟→退化 R69
    for g in info_action_candidates(modes):
        if not budget.allow(g) or not c_ras_wm.certify_info(g, o): continue
        voi_task  = h0 - expected_entropy(w, g, o, u)
        voi_learn = 0.0 if conf > CONF_FULL else expected_info_about_profile(u, g, o)
        score = voi_task + beta*voi_learn - u.cost_now(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None

# IP-267 TCG：逐人 k_u（替代全局常数 k）
def required_k(u, eps):
    rho = max(u.rho, RHO_FLOOR)
    return clip(max(2, 1 + ceil(log(eps/max(eps, 1-u.delta))/log(rho))), K_MIN, K_MAX)

def accept(modes, evidence, u, eps=EPS_ADOPT):
    return posterior_mode(modes, evidence, u) if k_orthogonal_agree(evidence, required_k(u, eps)) else None

# IP-268 FDL：疲劳 / 变更三态
def monitor(u, outcome_hist):
    fatigue = u.asks.rate() > N_HI and recent_delta_drop(u)
    drift   = cusum(outcome_hist, u.baseline) > H_CUSUM
    if drift: u.freeze(); u.inflate_prior()                            # 回通用先验
    return Triage(fatigue=fatigue, drift=drift, chronic=u.long_run_delta < D_LO)

# IP-274 PACE 主闭环（快环）；学习全部异步
def PACE_round(M, obs, uid):
    z, o = M.mtm.forward(obs); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o_obs, o_cal)
    slow  = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    u, tr = M.pmm.snapshot(uid), M.fdl.monitor(M.pmm.snapshot(uid), M.outcome_hist(uid))
    g = None
    if U_epi > TAU_EPI and not slow and not u.frozen and not tr.drift:
        g = M.pvc.choose(modes, o, u, M.budget, beta0=M.beta0)
    if g is not None:
        y = M.cia.execute(g); ans = M.tcg.accept(modes, y, u)
        if ans is not None: U_epi = 0.0
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    if slow or tr.drift: lam = max(lam, 0.8); k = min(k, k_cal_shrink(x_prime, U_cal))
    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.olc.record(record(g, y, credit=None, uid, is_audit=rand() < EPS_AUDIT))  # 仅入队
    M.vqa_i.submit_async(g, U_epi, a_hat)
    return k, lam, mode, U_epi

# IP-269 SLC：静止边界原子提交
def maybe_commit(M):
    if not M.at_quiescent_boundary(): return
    cand = M.olc.propose_commit()
    if (no_regression(cand, M.replay, M.adversarial, M.eps_reg)
        and fairness_ok(cand, M.eps_fair) and safety_floor_ok(cand, M.r69_floor)
        and cand.ece <= M.ece_now):
        M.commit_atomic(cand)
    else:
        M.rollback()

## 4. 推导

**引理 19（对偶 VoI 的无害分解）** `VoI_u(g)=VoI_task(g)+β_0(1−Conf)·I(θ_u;y)`；β_0(1−Conf)→0 时逐项退化 R69。探索的即时损失由未来后悔下降补偿：相对「已知真实 θ_u 的神谕」满足 `Reg(T) ≤ C·√(T·|Θ|·log T)`。系：个性化把「认识人」算进 VoI，画像成熟即停探索、回 R69。

**引理 20（在线校准自愈）** ε_drift-平稳、有界梯度下，带遗忘在线镜像下降满足 `ECE_T → ECE* + O(ε_drift) + O(√(log T/T))`。R69 的「ECE 越界永久禁用」替换为连续自愈：越界先禁用、数据足够自动重开。

**引理 21（逐人证据门安全-效率）** 真实共谋 ρ_u 下，`k_u(ε)` 使错误采纳率 `≤(1−δ_u)ρ_u^{k_u−1}≤ε`；ρ_u 低估则界失效，故取后验上界并随数据稀缺膨胀。ρ_u→0 ⇒ k_u→2；δ_u 高 ⇒ k_u=k_min；δ_u 低 ⇒ k_u 增大。

**引理 22（三态可辨识）** 长期 δ_u、近期 N_u、CUSUM 残差三时间尺度相差 ≥ 一个数量级时，慢性不可靠/疲劳/真实变更在 (δ_long,N,CUSUM) 空间互不重叠、可辨识——不把「被问烦的人」永久标记为不可信，也不对「真变了的人」用旧画像。

**定理 18（PACE 严格包含 FLUID 与 CALM）** 冷启动/consent 假/β=0/ECE 冻结/无疲劳 ⇒ 逐指令等于 FLUID-RAS；再令不交互等于 CALM-RAS。个性化仅调认证区间内阈值，任一组安全下界 ≥ R69 通用下界 ⇒ 安全不让步，效率获逐人校准 + 探索双 bonus。

**定理 19（在线学习不破坏实时一致性）** 快环只读快照、写只在影子、静止边界凭四条件原子提交；控制环永不读半更新状态，最坏回滚到上一有效快照，行为与提交前逐指令一致。

## 7. 本轮最大风险

**一句话**：PACE 的全部收益押在「交互信用 ζ 是可信的学习信号」这一前提上——但 ζ 延迟、部分、且 off-policy（只看被选模态、看不到未被选的反事实），还会被对手塑造；在线学习可能**自信地收敛到一个错误画像**，只信已信之人、只问已问之人，形成**个性化的自证回音室**，把 R69 的「不确定就问错」升级成「**稳定地、被证书认证地、逐人地持续问错**」；疲劳与投毒更会教它「永远别再问这个人」，把可解的歧义永久判成死题。

**次级风险与缓解**：非平稳/人变了（CUSUM + 遗忘 + 冻结回通用先验）；反馈回路/回音室（强制 ε_audit 随机审计 + 双重稳健 + 公平下界）；off-policy 偏差（倾向加权，ε_audit 永不→0）；隐私/同意（充分统计 + 本地 DP + consent + forget）；提交期安全回归（无回归证书 + 原子换装 + 回滚）；冷启动过问（保守先验 + 信任预算上限）。
