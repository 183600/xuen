# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「安全交互」×「云边协同」）

> R69 把「看 / 问 / 触」变成了消歧动作，并给出两条纪律：**交互预算**与**k 个正交证据源一致**。但它默默依赖了三个假设：答案**同步到达**、证据**相互独立**、交互**只花预算、不产生承诺**。云边协同撕开前两个：多模态流采样、瞬时变分似然、问句解码这些最贵的能力天然该放在云上，而云恰恰是最慢、最不可信、最容易与同伙共谋的一层——答案会迟到、会过时、会来自同一朵云上三个「正交」的服务。安全交互撕开第三个：让人让路，他就真的动了；凝视一个人，他就被凝视了；问一句「这里安全吗」，就把责任部分转移了——**交互不是免费的信息采样，而是一份可能无法撤回的承诺**。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**这条答案有资格让我动吗，我若信错了还退得回来吗**」。
>
> 核心命题：**把「能力」放上云边分层，把「权威」锁在边侧的模型无关安全核，把「安全」写成一条可释放的系绳（可逃逸 + 有截止 + 带来源）。云可以提出模态、生成问句、给出证据，但永远不能直接执行；任何外部答案都不能扩张已认证的安全集，只能收缩它。** 命名 **TETHER-RAS**（Trust-tiered Escape-safe Time-bounded Hierarchical Evidence Routing；能力上云、权威留边、安全系绳）。

## 0. 直觉与动机

**灵感 1（云边协同 → 能力与信任在分层里结构性错位）**
直觉：R69 的 FMP 多采样、FMA 瞬时变分、LLM 问句解码都是「能力」，越强越贵，越该外包给云；可云同时是最慢、最不干净、最易被单点攻破的一层。于是出现一个结构错位：**我们最需要的那部分智能，恰好住在我们最不该信任的地方**。正确姿态既不是「信云」也不是「不信云」，而是**分层授权**：云只**提议**，边只**裁决**，安全核只**否决**。云边不是把模型劈成两半，而是把「能力」与「权威」劈开。

**灵感 2（安全交互 → 交互是承诺，不是采样）**
直觉：R69 的 MINT 把交互当成一次条件化——问完，后验变窄，代价是预算。但真实的「问 / 看 / 触」有不可逆副作用：人动了、关系变了、责任转移了。一个只在**期望回答**上算 VoI 的控制器，可能为了 0.3 nat 的信息增益，把自己逼进一个「所有答案都逃不出去」的位置。安全交互的第一性原理因此是：**先保证还有退路，再谈值不值得问**。信息不是白拿的，问是要还的。

**灵感 3（逃逸 vs 包络 → R69 的物理认证太薄）**
直觉：R69 定义 302 只认证信息动作 g 本身不越力 / 位包络，定理 17 说「交互只改模态选择、不改安全包络」。这在同步、单层、无承诺的世界里成立；一旦答案异步且可能 adversarial，g 之后就多出一个**不受控的后续分支**。安全不能只对「动作」成立，必须对「动作 × 所有可能回答 × 等待时长」成立——即**最坏回答安全**与**等待期安全**。这把安全从「点」升级成「管」。

**灵感 4（共谋 →「k 个正交源」可能是一个幻觉）**
直觉：R69 引理 18 用「k 个正交证据源、欺骗相关 ρ<1」给出错误采纳率上界。但云边架构里，三个「独立」服务很可能共用同一朵云、同一份训练数据、同一个版本、同一条网络。攻击者拿下云，就免费获得 k 个「正交」同谋。**独立性不是数出来的，是查来源查出来的**。因此必须把 ρ 从「假设」变成「测量」，并接受残酷结论：ρ→1 时 R69 的证据纪律退化为单源，唯一安全的选择是回退。

**灵感 5（时鲜 → 迟到的真相不是真相）**
直觉：云回答要 80ms，控制环只要 2.6ms。等，可能错过窗口；不等，可能基于旧世界做决定。信息有保质期：200ms 前的「左边没人」对 100km/h 的车几乎等于噪声。所以 VoI 必须乘一个**时鲜折减** D(a)，并把「继续等」本身当成一个动作（有限期最优停止）。R69 的 VoI 是 a=0、deadline=∞ 的边界情形。

**灵感 6（孪生分歧 → 第三条异常通道）**
直觉：R69 用动作似然补了传感器残差补不了的洞（标定不可吸收）。云边架构天然多一条通道：**边侧世界模型与云侧世界模型对同一观测的分歧**。漂移、版本错配、云被投毒、地图过期，往往先表现为「两个大脑看见的不是同一个世界」。异常签名于是从二元 (r_res, Δa) 变成三元 (r_res, Δa, d_twin)。

**灵感 7（严格包含 → 又一层必须是旧层的泛化）**
直觉：这是本系列的底线。TETHER 必须在「单层、零延迟、ρ=0、deadline=∞、MISK≡C-RAS-WM」时**逐指令等于 FLUID（R69）**；禁止交互时等于 CALM（R68）。云边不是并列的新模块，而是把 R69 的「同步 / 单层 / 独立」三个隐含假设显式化，并让它们成为可退化参数——否则每加一层就多一个需要独立信任的黑箱。

## 1. 形式化定义（增量：定义 310–328）

**定义 310（TETHER-RAS 总览与五不变式）** TETHER-RAS = (FLUID-RAS, TEF, ESIK, D-VoI, PAEC, MISK, TDC, APS, DPL, J_TETHER)。五不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i、R68 定义 276-i）；
(ii) **权威分离**：只有边侧 MISK 拥有执行权；云 / 人只提供证据或候选提议；任何外部证据**不得扩张**已认证安全集，只能收缩或保持；
(iii) **逃逸不变**：每个决策点都存在模型无关的逃逸轨迹，且对所有可能回答、以及整个等待期成立；交互不得消耗最后一条退路；
(iv) **时鲜纪律**：每条证据带来源与龄期；迟到、陈旧、共模相关的证据不得单独定案；
(v) **严格包含**：`latency=0 ∧ 单层 ∧ ρ=0 ∧ deadline=∞ ∧ MISK≡C-RAS-WM` ⇒ 逐指令等于 R69；禁止交互 ⇒ 等于 R68。

**定义 311（分层证据织物 TEF）** 证据层集合 𝒯 = {e（边）, c（云）, h（人）}（云可含多个区域 / 多个服务）。每层 τ 有画像 `(μ_τ, Σ_τ, b_τ, p_τ, κ_τ, ρ_τ, v_τ)`：延迟分布、容量、带宽、隐私成本、信任等级、共模相关基线、模型 / 标定版本。边：低延迟、低容量、高信任、私有；云：高延迟、高容量、低信任、会出网；人：最高延迟、最高语义带宽、有社交成本、可能对抗。

**定义 312（证据项与来源 provenance）** 证据 `e = (y, τ, t_emit, t_recv, v, h, route)`，其中 y 为内容，τ 为来源层，v 为模型 / 标定版本，h 为 `hash(τ, v, route, calibration_id)`，route 为跨层路径。龄期 `a = t_recv − t_emit`。来源哈希使「同一朵云上的三个服务」在证据层面可被识别为同源。

**定义 313（时鲜折减）** 有效信息 `I_eff(M; y | a) = I(M; y) · D(a)`，其中 D 单调不增、`D(0)=1`、`D(a≥d)=0`（d 为截止）。实例：`D(a)=exp(−a/τ_c)` 或硬截止。A101 要求 D 是真实信息衰减的**上界**，宁可低估不可高估。

**定义 314（截止感知信息价值 D-VoI 与路由）** 对查询 g 路由到层 τ、截止 d：
`D-VoI(g→τ,d) = P(a≤d)·E[I_eff] − c_comm(τ) − μ_E·c_energy(τ) − c_priv(τ) − c_social(τ) − c_wait(τ,d)`。
选择 `(g*,τ*,d*) = argmax D-VoI`，s.t. 逃逸安全（定义 316）、C-RAS-WM 认证（R69 定义 302）、预算未超。若 max ≤ 0：不交互，走 R69 兜底。**R69 的 VoI 是「仅边层、a=0、c_comm=c_priv=0」的特例。**

**定义 315（最优提交与截止）** 在每个决策步比较「继续等」与「立即提交」：
`W_t = E[D-VoI 残值 | 已到证据] − risk_wait(t)`；`W_t ≤ 0` 或到达硬截止即提交。这是有限期最优停止，「等待」是一种显式动作；产出的提交时刻 t* 与硬截止 d 写进证书。

**定义 316（可逃逸与非遗留交互 ESIK）** 给定状态 s，信息动作 g 称为**可逃逸**，当且仅当存在逃逸策略 π_esc 与逃逸时域 H_esc，使 `∀y∈supp(g,s)`：执行 g 后接 π_esc 能在 H_esc 内回到安全集；且 g 不消耗最后一条逃逸选项。**非遗留**：不可逆责任 `ℓ(g) ≤ ℓ_max`，否则 g 被禁止，除非可认证为可逆。

**定义 317（最坏回答安全）** `sup_{y∈supp} risk(g,y) ≤ ε_int`，且在整个等待区间 `[t, t+d]` 内成立。R69 用**期望回答**算 VoI；TETHER 在其上再叠一层**最坏回答**护栏。二者不是重复：前者决定值不值得问，后者决定能不能问。

**定义 318（模型无关安全核 MISK）** 由模型无关约束（CBF / 可达性 / 物理限位 / 静态地图 / 车载感知）构成的安全盾，**不依赖**学习策略，也**不依赖**云下发的动态模型；可否决任何层的动作。单调性：执行指令 `= project(proposal)` 只做限制、不做扩张；攻击只会让安全集收缩，不会让它变大。

**定义 319（权威分离）** 只有 MISK 的输出进入执行器。云 / 人的输出只能作为证据（定义 312）或候选提议；**永远不能成为执行指令**。这是定理 19 的前提，也是「云被投毒只亏性能、不亏安全」的结构性保证。

**定义 320（随时渐进分流 APS）** 流策略设检查点：边侧早退 `(K=1, N_step=1)` 给粗模态集；云端继续 `(K=4, N_step=2)` 做精化。**anytime 性**：任意时刻被打断，最后一个已认证输出都有效；精化只能在「provenance + 时鲜 + PAEC 通过」时**降低**保守度，且不得低于边侧地板。

**定义 321（算力放置）** 放置决策 `ρ: {K 采样, FMA 似然, LLM 问句解码, 标定} → 𝒯`，按 D-VoI（已含延迟 / 能耗 / 隐私 / 通信成本）联合选择。这把 R69 定义 308 的「自适应 K（多少样本）」升级为「(多少样本, 放哪里)」二维决策。

**定义 322（来源感知证据合并 PAEC）** 证据之间有共模相关 `ρ_ij`，由共享依赖图与共失败日志估计；有效独立度 `k_eff = 1 + Σ_{i<j} 2(1−ρ_ij)/(k(k−1)) · (k−1)`（等价 `k_eff = 1 + (k−1)(1−ρ̄)`）。高相关证据先**坍缩为一个**，再做信任加权贝叶斯更新。`k_eff < k_min` ⇒ U_epi 视为未消解、走兜底。**R69 的「k 正交」是 ρ=0 的特例。**

**定义 323（孪生分歧通道 TDC）** `d_twin = W_2(p_edge(·|o), p_cloud(·|o))` 或边 / 云对模态或意图分布的 JS / Wasserstein 距离。与 (r_res, Δa) 组成三元异常签名，分离真漂移、局部故障、云投毒、版本错配。R69 的 FMA 是「云缺席、d_twin 未定义」的特例。

**定义 324（分区与退化阶梯 DPL）** 网络状态 ∈ {connected, degraded, partitioned, Byzantine}。阶梯：完整 TETHER → 仅边（R69）→ R68 纯保守 → 安全停车。要求**单调**：λ 不降、交互频率不增、已认证安全集不增；层间切换连续（R68 定理 15 的换装不变式），**能力不得无再认证地跳升**。

**定义 325（威胁模型 ℰ_TETHER）** `ℰ_TETHER = ℰ_FLUID × ℰ_tier × ℰ_net`。ℰ_tier：云投毒 / Byzantine、版本错配、陈旧重放、幻影模态、诱导性问句、人类同谋 / 胁迫；ℰ_net：分区、延迟注入、带宽饥饿、Sybil「正交源」、流量侧信道。

**定义 326（证书 J_TETHER）** `J_TETHER = (J_FLUID, provenance_hash, staleness_max, deadline_miss_rate, escape_margin, authority_sep_proof, k_eff, ρ_max, partition_state, twin_div_p95, tether_ver)`。Valid ⇔ `Valid(J_FLUID) ∧ escape_margin>0 ∧ 权威违规=0 ∧ 截止 / 分区约束满足 ∧ (k_eff≥k_min ∨ 显式回退)`。

**定义 327（可读性与同意契约）** 交互必须**可读**（问句可解码、意图无歧义）、**非胁迫**（不利用人的有限理性）、**责任有界**、**可解释可撤回**。可读性 `L(g) ≥ L_min`、胁迫指数 `C(g) ≤ C_max`，否则 g 被禁止。这把「安全交互」从物理安全扩展到语义与关系安全。

**定义 328（校准版本一致性）** 标定 ECE 必须版本匹配：若 `v_cloud ≠ v_edge`（策略或标定版本），信任按 `δ_ver` 折减。防止 R69 的 MCG 被一朵「自称已校准」但版本错配的云骗过。

```python
# IP-264 TEF：分层证据织物（边 / 云 / 人）
class TieredEvidenceFabric:
    def __init__(self, tiers):            # {edge, cloud, human}
        self.tiers = tiers
    def profile(self, tau):
        return self.tiers[tau]            # latency, capacity, privacy, trust, rho, version

# IP-265 ESIK：可逃逸 + 非遗留过滤（对最坏回答，而非期望回答）
def escape_safe(g, s, misk, H_esc):
    if not misk.invariant(s):                       return False
    if misk.irreversible_liability(g) > L_MAX:      return False
    for y in support_answers(g, s):                 # 最坏回答
        if misk.after(g, y, s).reachable_safe(H_esc) is None:
            return False
    return misk.escape_margin(g, s) >= M_MIN

# IP-266 D-VoI：把延迟 / 通信 / 隐私 / 等待折进信息价值
def choose_route(modes, w, o, budget, tef, mu_E):
    best = None
    for g in info_candidates(modes):
        if not c_ras_wm.certify_info(g, o):          continue
        if not escape_safe(g, o, misk, H_ESC):       continue
        for tau in tef.tiers:
            p = tef.profile(tau)
            dv = (p_arrive(p.latency) * staleness_discount(p.latency)
                  * entropy_gain(w, g, o))
            dv -= (comm_cost(g, tau) + mu_E * energy_cost(g, tau)
                   + privacy_cost(g, tau) + social_cost(g, tau))
            if budget.allow(g, tau) and (best is None or dv > best.dv):
                best = (g, tau, dv)
    return best if best and best.dv > 0 else None   # 无利可图 → R69 兜底

# IP-267 PAEC：共模相关坍缩 + 信任加权
def provenance_aware_update(modes, evidence, rho):
    groups = collapse_correlated(evidence, rho, RHO_MAX)   # 同源合并
    k_eff  = 1 + (len(groups) - 1) * (1 - mean_pairwise(rho))
    if k_eff < K_MIN:
        return modes, 'insufficient_independence'          # 走保守兜底
    return bayes_update(modes, trust_weighted(groups)), 'resolved'

# IP-268 MISK + 权威分离：只有模型无关核能执行
def actuator(proposal, s):
    return misk.project(proposal, s)     # 只否决 / 收缩；云与人从不直接执行

# IP-268 TDC：孪生分歧（第三条异常通道）
def twin_divergence(edge_wm, cloud_msg, o):
    return wasserstein(edge_wm.predict(o), cloud_msg.predict(o))

# IP-275 主闭环：边 anytime 粗动作 + 云异步精化 + 系绳安全
def TETHER_round(M, obs):
    z, o = M.mtm.forward(obs); c, U_cal, thr = M.cof.step(...)
    # 1) 边侧 anytime 粗通过（永远可用，K=1/N=1）
    coarse = M.aps.edge_exit(o, K=1, N=1)
    U_ale, U_epi, modes, _ = M.aud.decompose(coarse, z, M.mode_head)
    # 2) 双通道异常：R69 流似然 + 跨层孪生分歧
    d_twin = M.tdc(M.edge_wm, M.last_cloud_msg, o)
    slow = (M.fma.flow_anomaly(...) > TAU_FMA) and (M.last_r_res < TAU_RES)
    # 3) 截止感知路由；等待期由 ESIK 保持安全
    route = (M.mint_dv.choose_route(modes, o, M.budget, M.tef, M.mu_E)
             if not slow and d_twin < TAU_TWIN else None)
    status = 'unresolved'
    if route is not None:
        g, tau, _ = route
        M.aps.request(g, tau, deadline=M.deadline)
        M.esik.hold(o)                          # 非阻塞：等待期间仍安全
        ev = M.aps.collect_until(M.deadline)    # 可能为 None
        if ev is not None:
            modes, status = M.paec.update(modes, ev, M.rho)
        else:
            status = 'deadline_miss'
    # 4) 未消解即视同 aleatoric（R68 兜底）；消解仅获 resolution bonus
    U_floor = U_ale + (U_epi if status != 'resolved' else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    # 5) 权威分离：MISK 是唯一执行者
    A = M.misk.project(M.ach.propose(x_prime, M.vista.H), o)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    if slow or d_twin > TAU_TWIN or M.dpl.partitioned:
        lam = max(lam, 0.8); k = min(k, k_cal_shrink(A, U_cal))
    # 6) 选模态 + 审计 + 证书
    mode = select_mode(modes, U_epi, lam)
    tau_cmd = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_x.submit(g if route else None, status, d_twin, M.paec.k_eff)
    return k, lam, mode, (U_ale, U_epi, status)
```

## 3. 推导

**假设 A99–A103**：A99（MISK 可靠性）MISK 仅用车载感知与静态地图、对不可达 / 不安全集做**过近似**，与云动态模型无关，保守度有界；A100（逃逸预算）`H_esc ≥ max(μ_c, μ_h) + 控制周期`，逃逸策略在安全集内非空；A101（时鲜标定）D(a) 是真实信息衰减的上界（held-out 验证）；A102（共模估计）ρ_ij 由依赖图与共失败日志估计，无法估计时取 ρ=1；A103（版本单调）跨版本精化仅在 provenance 与标定版本匹配时允许，否则信任折减。

**引理 19（逃逸不变 ⇒ 最坏回答安全）** 在 A99–A100 下，若 g 对 MISK 可逃逸，则对任意 `y∈supp(g,s)`（含对抗回答）以及整个等待期，闭环风险 ≤ ε_int，且交互不缩小已认证安全集。要点：MISK 与 y 无关且只做限制；对每个 y 都取到逃逸策略，动作复合后用并集界。系：**R69 的期望回答 VoI 不足以保证安全**，可逃逸是更强的要求；「先留退路，再谈信息」有形式依据。

**引理 20（共模相关击穿 k-正交）** 设单源欺骗率 δ_p、来源两两共模相关均值 ρ̄，有效独立度 `k_eff = 1 + (k−1)(1−ρ̄)`。R69 的错误采纳上界 `δ_p ρ̄^{k−1}+ε` 在 ρ̄→1 时退化为 δ_p，即「k 个同源正交服务」不提供任何保护；PAEC 先把同源坍缩，再以 k_eff 重算，等价恢复 `δ_p ρ̄^{k_eff−1}+ε`。系：**独立性必须来自 provenance，而不是计数**；当 k_eff 过小，唯一安全动作是回退（定义 322）。

**引理 21（时鲜折减与外包阈值）** 由定义 313–314，`D-VoI_cloud ≤ D(μ_c)·VoI_sync − c_comm − c_priv − μ_E c_E − c_wait`。故云外包只有在 `D(μ_c)·VoI_sync > 通信 + 隐私 + 能量 + 等待成本` 时才划算：歧义大、延迟低时上云；隐私敏感或歧义小时留边 / 问人。也给出「截止未到就先等」的边界：等待的边际收益低于 `risk_wait` 即提交（定义 315）。

**引理 22（随时早退的单调保守）** 边侧早退信息更少，故 `λ_floor^{edge} ≥ λ_floor^{full}` 且逃逸集 `S_esc^{edge} ⊇ S_esc^{full}`；云端精化只能在 provenance + 时鲜 + PAEC 通过时把保守度降低到边侧地板之上。因此任意检查点被打断都安全，云边分层不带来安全损失，只可能损失未兑现的 resolution bonus。

**定理 18（TETHER 严格包含 R69 / R68）** 在 A99–A103 下，TETHER 任意状态的期望风险 ≤ FLUID（R69）；且当 `单层 ∧ latency=0 ∧ ρ=0 ∧ deadline=∞ ∧ MISK≡C-RAS-WM` 时两者**逐指令相同**；禁止交互时逐指令等于 CALM（R68）。DPL 只收缩安全集，故安全侧逐级不让步，效率 / 续航 / 能力侧逐级获增益。

**定理 19（权威分离安全性，本轮核心）** 若 MISK 模型无关且单调（定义 318），且所有外部输出只以证据 / 提议身份进入（定义 319），则 Byzantine 云或受胁迫的人只能造成**有界性能损失**（≤ 放弃的 VoI + 查询开销），**不能扩张已认证安全集**，故不能直接造成安全违规。系：R69「问错比不问更危险」在 TETHER 中被降级为「问错只亏性能，不亏安全」——前提是 MISK 真的不依赖云。

**定理 20（分区容错与无迟提交）** 在分区 / 截止未达 / 信任跌破时，DPL 单调回退；借 R68 换装不变式保持控制连续；期望风险 ≤ `max(R69, safe-stop) + 放弃 VoI 的有界项`。任何超过硬截止才到达的证据**不得追溯**为已提交动作的依据（可留作未来），从而杜绝「用迟到的真相为旧决定背书」。

## 6. 本轮最大风险

**一句话**：TETHER 的安全性全部押在「边侧存在一个**真正模型无关**的安全核」这一前提上——**若 MISK 偷偷依赖了云下发的（可能过时、被投毒、版本错配的）地图 / 动态模型，那么「权威分离」就只是名义上的：系统会在一个错误的世界里证明自己「可逃逸」，实际早已被围死，「能力上云、权威留边」也就退化成把安全外包给最不可信的一方**。

**次级风险与缓解**：
1. **时鲜折减被高估**（D(a) 太乐观 → 过度信任陈旧云证据）→ D 取保守上界 + 硬截止 + A101 验证 + E304；
2. **共模相关难估** → 无法估计时取 ρ=1 的最坏假设 + provenance 依赖图 + E303；
3. **逃逸检查过保守**（交互被永久禁用、效率收益清零）→ 预计算可达集 + 分级 resolution bonus + E305/E315；
4. **上云隐私泄漏** → 边侧编码 / DP 特征 + 隐私预算 + E312；
5. **问句诱导 / 人类胁迫** → 可读性与同意契约（定义 327）+ VQAuditor-X + E309；
6. **MISK 被悄悄「云化」** → 对 MISK 的输入做来源审计、静态地图签名、任何云依赖即判证书无效 + E301。

```python
    if slow or d_twin > TAU_TWIN or M.dpl.partitioned:
        lam = max(lam, 0.8); k = min(k, k_cal_shrink(A, U_cal))
    mode = select_mode(modes, U_epi, lam)
    tau_cmd = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_x.submit(g if route else None, status, d_twin, M.paec.k_eff)
    return k, lam, mode, (U_ale, U_epi, status)
```

## 4. 推导

**假设 A99–A103**：MISK 仅依赖车载感知 + 静态地图、对不安全集过近似、与云动态模型无关；`H_esc ≥ max(μ_c,μ_h)+控制周期`；D(a) 是真实信息衰减上界；ρ 未知时取 1；跨版本精化需 provenance 与标定版本匹配。

**引理 19（逃逸 ⇒ 最坏回答安全）** MISK 与回答 y 无关且只收缩；对每个 y 存在逃逸策略，动作复合 + 并集界 ⇒ `sup_y risk ≤ ε_int`，且交互不缩小安全集。系：R69 的期望回答 VoI 不足以保证安全。

**引理 20（共模击穿 k-正交）** `k_eff = 1+(k−1)(1−ρ̄)`；R69 上界 `δ_p ρ̄^{k−1}+ε` 在 ρ̄→1 时退化为单源；PAEC 坍缩同源后恢复 `δ_p ρ̄^{k_eff−1}+ε`。系：独立性来自 provenance，不来自计数。

**引理 21（时鲜与外包阈值）** `D-VoI_cloud ≤ D(μ_c)VoI_sync − c_comm − c_priv − μ_E c_E − c_wait`；仅当右侧为正才值得上云。歧义大 / 延迟低则上云，隐私敏感 / 歧义小则留边或问人。

**引理 22（随时早退单调保守）** 边早退 `λ_floor^edge ≥ λ_floor^full`、`S_esc^edge ⊇ S_esc^full`；精化仅在 provenance + 时鲜 + PAEC 通过时降到边侧地板之上 ⇒ 任意检查点中断都安全。

**定理 18（严格包含 R69/R68）** A99–A103 下期望风险 ≤ FLUID；边界 `(单层, latency=0, ρ=0, deadline=∞, MISK≡C-RAS-WM)` 逐指令相同；禁止交互 ⇒ CALM。DPL 只收缩安全集，安全逐级不让步。

**定理 19（权威分离安全性，核心）** MISK 模型无关且单调 + 外部输出只作证据 ⇒ Byzantine 云 / 被胁迫者只能造成有界性能损失，不能扩张安全集，不能直接造成安全违规。系：R69「问错比不问更危险」降级为「问错只亏性能」，前提是 MISK 真不依赖云。

**定理 20（分区容错与无迟提交）** 分区 / 截止未达 / 信任跌破时 DPL 单调回退，借 R68 换装不变式保持连续；超过硬截止的证据不得追溯为已提交动作的依据 ⇒ 杜绝「用迟到的真相为旧决定背书」。

## 7. 本轮最大风险

**一句话**：TETHER 的安全性全部押在「边侧存在一个**真正模型无关**的安全核」这一前提上——**若 MISK 偷偷依赖了云下发的（可能过时、被投毒、版本错配的）地图 / 动态模型，则「权威分离」只是名义上的：系统会在一个错误的世界里证明自己『可逃逸』，实际早已被围死，『能力上云、权威留边』也就退化成把安全外包给最不可信的一方**。

**次级风险与缓解**：D(a) 高估 → 保守上界 + 硬截止 + E304；共模难估 → 未知取 ρ=1 + provenance 依赖图 + E303；逃逸检查过保守 → 预计算可达集 + 分级 resolution bonus + E305/E315；上云隐私泄漏 → 边侧编码 / DP + 隐私预算 + E312；问句诱导 / 胁迫 → 可读性与同意契约 + VQAuditor-X + E309；MISK 被悄悄「云化」→ MISK 输入来源审计 + 静态地图签名 + 云依赖即证书无效 + E301。
