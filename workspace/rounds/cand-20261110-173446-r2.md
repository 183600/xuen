# 第 44 轮（新循环第 4 轮） · Geo-Just-Cert：把「点云配准」升格为可认证的几何证人，把「伦理与合规」升格为可验证的跨群体证据链（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 已把「个性化」与「并发」纳入证书闭环，但它仍压着两个更底层的单点假设：**(H3) 几何底座被当作可信 oracle**——点云配准只被用来产出位姿 T，没有人证明 T 在长廊、隧道、玻璃幕墙、拥挤人群等退化场景里仍然 sound；**(H4) 技术证书被默认为合规证书**——v20 的 sound 证书并不等于可部署，伦理与合规要求的是可追溯、可质疑、非歧视、有人类监督、有数据同意边界的证据链，而不是一张「已验证」的标签。本轮灵感词「点云配准」「伦理与合规」精确命中这两个假设：**点云配准**把几何证人本身变成一等公民（残差 + 重叠度 + 退化谱 + 规范锚的注册证书）；**伦理与合规**把证书从技术谓词提升为跨群体条件有效、带出处与解释的监管证据。二者耦合处是本轮真正的新问题：**配准退化是「场景 × 人群」相关的**，于是「几何不确定性」与「群体公平性」落在同一个不等式里——这恰好把上一轮「边际 vs 条件覆盖」的隐患升级为有法律牙齿的**最差群体红线**。

## 0. 直觉与动机

**灵感 1（点云配准 → 「残差小」不等于「位姿对」）**：直觉上，ICP 在长廊里能把两帧点云对得「很顺」，残差极小而位姿沿走廊轴却可能漂了几米——因为走廊沿轴方向近似平移对称，点云「滑动」不改变残差。所以用残差当置信度会**静默地过度自信**。正确的做法是给配准本身发证书：把位姿的不确定集 𝒯 用信息矩阵的特征谱表示，沿可观测方向收紧、沿退化（近零特征值）方向显式标注「不可观测」，并引入**规范锚** g（平面、标定物、语义地标）固定参考系。下游几何证书若只用点估计 T̂ 而忽略 𝒯，就会把退化方向的巨大不确定性当成零。一句话：**配准证书不是「配准成功了」，而是「位姿被约束在哪个集合里、哪些方向没被约束」**。

**灵感 2（伦理与合规 → 证书要「可辩护」，不只是「sound」）**：sound 是「不违反物理安全」，可辩护是「能向监管者、用户、受害者证明并解释」。合规把三件事变成硬约束：**(a) 可追溯**——每个动作背后有绑定到具体证书实例、带签名与出处的证据；**(b) 可比性/非歧视**——证书不能只在平均意义上成立，而必须在**弱势/受保护群体**上同样成立（最差群体红线）；**(c) 可质疑**——用户能问「为什么这么做」，系统要给出最小解释与反事实，并允许人类否决。这与上一轮的共形覆盖问题同构，但更狠：边际覆盖可以被「多数群体」撑起来，而合规审查看的是**最差群体**。

**灵感 3（耦合 → 几何公平性：退化场景 × 脆弱人群）**：退化不是均匀发生的。玻璃幕墙、拥挤、低纹理、轮椅/儿童/反光衣物，这些既是配准退化的诱因，又可能对应受保护或弱势群体。于是「几何不可观测」会**系统性地**落在某些人群上——这就是一种由传感器-算法共同制造的歧视。必须把评估单元从「平均场景」改成 `场景类 × 用户群` 的笛卡尔积，并定义**公平性缺口**（最差群体违例率 − 最好群体违例率）。这也解释了为什么本轮必须同时引入两个灵感词：只做配准认证会漏掉群体维度，只做合规会漏掉几何真值。

**耦合升级**：GWE（几何证人引擎）产出带退化谱与规范锚的注册证书 R；RCL（监管证据编译器/账本）把 R 与既有证书编译成绑定实例、可追溯、可撤销的证据链；ECC（伦理一致性与可质疑引擎）做群体公平审计、同意边界与最小解释。四层架构由 v8 的「人格契约层 + 并发证书层」升级为 v9 的「**几何证人层 + 监管证据面**」：技术证书仍是安全内核，证据面负责让它「可部署、可审计、可质疑」。

## 1. 形式化定义（增量：定义 44–50）

**定义 44（点云配准证书与规范锚）**：对源/目标点云 (P,Q) 的配准结果记 R=(T̂, 𝒯, ρ, o, σ(H), g, h_R)：T̂ 为估计位姿；𝒯⊆SE(3) 为在假设 (A_reg) 下的 **sound 位姿集**（有界内点噪声 ≤ε_n、外点率 ≤β_o、重叠度 ≥o_min）；ρ 为内点残差上界；o 为重叠度；σ(H) 为配准信息矩阵 H 的特征谱 λ_1≤…≤λ_6；g 为规范锚（使位姿唯一化的几何基元集合）；h_R 为点云与证书的哈希。**sound 性**：在 (A_reg) 下，真值 T*∈𝒯 以置信度 1−δ 成立。**退化判据**：若 λ_min<λ_th，则沿对应特征向量的方向**不可观测**；若规范锚 g 的秩不足以固定该方向，则称**规范欠定**。

**命题（残差自信反例）**：存在长廊场景，使 ρ→0 而沿轴向的位姿误差可任意大；故任何仅由 ρ 或重叠度 o 导出的置信度都不 sound。**推论**：下游几何证书必须消费整个 𝒯（尤其退化谱），不能只消费 T̂。

**定义 45（退化感知的几何证人）**：令 C_geo 为名义几何安全证书，L_geo 为其对位姿扰动的 Lipschitz 常数。**方向性证书** C_geo^dir 将证书沿 𝒯 的主轴分解：对可观测方向用收紧的边际 m_i=m_i^nom−L_geo·r_i(𝒯)（r_i 为该方向不确定半径）；对不可观测方向不发布保证，改为**弃权标记** ⊥。若任何安全关键方向为 ⊥，则触发主动感知（换视角/减速/补光/改用先验地图）或退到保守包络；**绝不**用 T̂ 补零。**命题**：若 m_i≥θ_i 对所有可观测安全方向成立，且所有不可观测方向均被弃权/主动感知覆盖，则 C_geo^dir sound。

**定义 46（监管可追溯映射与证据账本）**：给定适用监管政策 P（EU AI Act、ISO 13482/10218、UL 4600、GDPR 等的条款集合），定义映射 Φ: 证书谓词 × 阈值 → 条款集合。**证据** e=(c_id, c_hash, clause, t, signer, provenance, prev_hash, h_e)，其中 c_id 绑定到**具体证书实例**而非「流程」，prev_hash 使账本成为**仅追加哈希链**。**合规判定**：Compliant(P,t) 当且仅当对 P 中每条适用条款 c，都存在证据 e 满足：绑定当前证书实例、未过期、未被撤销、签名者可授权、且链完整。**关键**：证据完整性 ≠ 证书真实性，故须额外要求 e 绑定的 c_hash 对应一个仍 valid 的证书。

**定义 47（群体条件 soundness 与几何公平性）**：把联合群体划分为 𝒢=场景类×用户群（含受保护/弱势群）。对覆盖水平 1−α 的证书 C，要求 **inf_{g∈𝒢} coverage_g ≥ 1−α** 且 **sup_{g∈𝒢} violation_g ≤ β**。定义**公平性缺口** FG=max_g violation_g − min_g violation_g，**最差群体红线** violation_{g_vuln}=0。**命题**：群体条件 soundness ⟹ 边际 soundness，反之不成立；可构造两个群体使边际覆盖同为 1−α 而最差群体覆盖任意低。**推论**：合规审计必须按群体分层，平均指标不可作为放行依据。

**定义 48（同意范围内的个性化）**：人格契约 Π_u 只能使用同意范围 Cons_u 内的数据；个性化证书 C_u=C_global∩Π_u∩Cons_u。撤销同意须在 τ_rev 内使相关证据失效并触发重编译；数据最小化以函数 D_min 度量（为达成同一契约所用的最小数据子集）。**命题**：撤销传播若未在 τ_rev 内完成，则存在已撤销数据仍在守卫中的窗口，违反 GDPR 目的限制。

**定义 49（可质疑性：最小解释与反事实）**：对动作 a 及其证书链 Ch(a)，解释 Exp(a) 是 Ch(a) 的最小子集，使得 Exp(a) 成立 ⟹ a 被授权；**解释完备**当且仅当 Exp(a) 覆盖所有红线条款所需前件。反事实 CF(a)={δ : 最小扰动使决策改变}，并须可**重放验证**。**命题**：若解释完备且反事实可验证，则任何被质疑动作都存在可机械复核的辩护；否则存在「无法解释的授权」。

**定义 50（证据新鲜度与监管熔断）**：证据租约 ℓ_e=(c_hash, t, TTL, rev)，仅当未过期且未撤销时有效。若任一适用条款的证据失效，则触发**监管熔断**（regulatory cut）到**预授权最小风险策略 P_safe**（原地停、缓停、交还人类、急停），P_safe 自带常驻证据（安全案例），并**必须把熔断事件本身写入账本**。**定理（程序性可辩护）**：若 (i) 每张证书群体条件 sound；(ii) 账本仅追加且证据绑定实例并签名；(iii) 解释对红线条款完备；(iv) 监管熔断只收缩动作、绝不放松阈值且留痕——则任一执行动作同时满足物理安全与程序性可辩护。**注**：程序性可辩护不等于实质正义，故 (i) 仍须由 E97 的经验公平审计兜底。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 GEOMETRIC-WITNESS-ENGINE（几何证人引擎 GWE）
1. **鲁棒配准 + 证书**：特征/ICP 配准并估计信息矩阵 H 与协方差，构造 sound 位姿集 𝒯。
2. **退化谱与规范锚**：特征分解给出可观测/困难/不可观测方向；规范锚秩检查；输出退化类别。
3. **方向性几何证人**：把 𝒯 交给 IP-49 生成 C_geo^dir，对不可观测方向弃权 ⊥。
4. **主动感知触发器**：⊥ 安全方向 → 换视角/减速/补光/先验地图；不可行则保守包络或安全退避。

### 2.2 IP-61 REGULATORY-EVIDENCE-LEDGER（监管证据编译器与账本 RCL）
1. **条款映射表**：证书谓词×阈值 → 监管条款，按司法辖区版本化。
2. **证据生成与签名**：绑定证书实例哈希、出处、签名者；生成不可抵赖记录。
3. **仅追加哈希链账本**：撤销记录、版本、审计查询 API（「动作 a 在条款 c 下的证据链」）。
4. **证据租约 + 监管熔断**：证据过期/撤销 → P_safe，并记录熔断证据。

### 2.3 IP-62 ETHICAL-CONFORMANCE-ENGINE（伦理一致性与可质疑引擎 ECC）
1. **群体公平审计**：场景类×用户群的最差群体覆盖、违例率与公平性缺口。
2. **同意与数据治理**：Cons_u 边界、撤销传播、数据最小化度量。
3. **可质疑性**：最小解释证书 + 可重放反事实生成器。
4. **人类监督与问责**：覆盖/否决钩子、责任人归属、非操纵/尊严不变量检查。

## 5. 本轮最大风险

**一句话**：最大的风险是「合规剧场 / 证据洗白」——哈希链与条款映射可以做出完美可审计的外观，但若注册证书在退化方向上是 gauge-broken、且群体条件覆盖只在被测量群体上达标，系统就会「法律上可辩护、物理与伦理上错误」；因此 E97（最差群体红线）与 E98（条款证据完整性）必须设为红线，且默认回退到「配准弃权 + 纯收缩个性化 + 监管熔断」这条「不确定就停/慢/交人」的底线。

# 第 44 轮产物 · 创新点清单 v21：Geo-Just-Cert（GWE × RCL × ECC）× 可认证几何与合规证据闭环（四层架构 v9）

## 2. 关键算法（伪代码）

### IP-60 GWE：配准证书与方向性几何证人
```
def certified_register(P, Q, prior, eps_n, beta_o, o_min):
    X = robust_features(P, Q)                    # 特征 + RANSAC 初始化
    T, resid, overlap = robust_icp(P, Q, X)      # 鲁棒 ICP
    H = information_matrix(P, Q, T)              # 6x6 Fisher/信息矩阵
    lam, V = eig(H)                              # 特征谱，升序
    g = gauge_anchor(P, Q)                       # 平面/标定物/语义地标
    R = RegCert(T_hat=T,
                Tset=fit_ellipsoid(lam, V, resid, eps_n, beta_o),
                rho=resid, o=overlap, spectrum=lam,
                anchor_rank=rank(g), hash=H(P, Q))
    R.degenerate = (lam[0] < LAMBDA_TH) or (R.anchor_rank < 6)
    return R

def geometric_witness(R, C_geo, theta, L_geo):
    if not R.sound_under(A_reg):                 # 前提不成立 => 弃权
        return ABSTAIN
    C = C_geo.clone()
    for i, u in enumerate(R.principal_axes):     # 沿不确定主轴分解
        if R.observable(u):
            C.margin[i] = C.margin_nom[i] - L_geo * R.radius(u)
            if C.margin[i] < theta[i]:
                return ABSTAIN                  # 可观测但余量不足
        else:
            C.abstain_dirs.add(u)               # 不可观测 => ⊥
    if C.safety_critical_dirs() & C.abstain_dirs:
        return request_active_perception(C.abstain_dirs)  # 换视角/减速/补光/先验
    return C                                    # C_geo^dir sound

def request_active_perception(dirs):
    plan = choose_viewpoint_or_slowdown(dirs)
    return plan if feasible(plan) else conservative_envelope(dirs)
```

### IP-61 RCL：证据编译、合规判定与监管熔断
```
def compile_evidence(cert, policy, signer):
    for clause in phi(cert.predicate, cert.threshold):   # 条款映射 Φ
        e = Evidence(cid=cert.id, c_hash=hash(cert), clause=clause,
                     t=now(), signer=signer, provenance=cert.provenance,
                     prev_hash=ledger.head(), h_e=None)
        e.h_e = sign(e)
        ledger.append(e)                                 # 仅追加哈希链
    return ledger.head()

def compliance_check(policy, ledger, t):
    for clause in policy.applicable(t):
        es = ledger.query(clause)
        ok = any(bound_to_current_instance(e)   # 绑定当前证书实例
                 and fresh(e, t)                # 未过期
                 and not revoked(e)             # 未撤销
                 and authorized(e.signer)       # 签名者可授权
                 for e in es)
        if not ok:
            return False, clause                # 缺证据 => 不合规
    return True, None

def regulatory_cut(reason):
    ledger.append(CutEvidence(reason, t=now(), prev_hash=ledger.head()))
    return P_SAFE                                # 停/缓停/交人/急停，绝不放松阈值
```

### IP-62 ECC：群体公平、同意治理与可质疑性
```
def group_conditional_audit(certs, groups, alpha, beta):
    cov, vio = {}, {}
    for g in groups:                             # 场景类 × 用户群
        idx = [i for i, c in enumerate(certs) if c.group == g]
        cov[g] = coverage(certs[idx])
        vio[g] = violation(certs[idx])
    worst = min(cov, key=cov.get)
    gap = max(vio.values()) - min(vio.values())
    ok = (cov[worst] >= 1 - alpha) and (max(vio.values()) <= beta)
    return ok, worst, gap, vio

def consent_scope(persona, data, Cons_u, t):
    used = minimal_subset(persona, data)         # 数据最小化 D_min
    if not subset(used.attrs, Cons_u.attrs):
        return None, "consent_violation"
    if Cons_u.revoked_at is not None and t - Cons_u.revoked_at > TAU_REV:
        return None, "revocation_window_exceeded"
    return compile_persona_contract(used), None

def explain_minimal(chain, action, redline):
    Exp = set(chain.antecedents)
    for a in sorted(chain.antecedents, key=antecedent_cost):
        if implies(Exp - {a}, action, redline):  # 最小化解释
            Exp = Exp - {a}
    CF = minimal_counterfactuals(chain, action)  # 可重放验证
    complete = all(r in Exp for r in redline)    # 红线条款完备
    return Explanation(Exp, CF, complete)

def verify_counterfactual(chain, action, delta):
    replay = recompile_chain(chain.perturb(delta))
    return replay.decision != chain.decision     # 扰动确实改变决策
```

def car_guard(e, x, cert, R, persona, lease, evidence_ok, t):
    if not evidence_ok:
        return regulatory_cut("missing_evidence")          # 证据缺失 => 熔断
    if R.degenerate and (e in R.unobservable_dirs()):
        return ABSTAIN                                     # 退化方向不发布保证
    theta = cert.alpha_e[e] * cert.theta_sim[e]
    m = min(cert_lookup_L0(x).m_lo[e],
            lease.m - lease.lam * (t - lease.tau),
            persona_cap[e](persona),
            geometric_margin(R, e))                        # 几何膨胀后的边际
    return (m >= theta) and lease_valid(lease, theta, t)

def schedule_with_audit(tasks, overload):
    if overload:                                           # HI 模式：只删不增

## 6. 本轮最大风险

**一句话**：最大的风险是「合规剧场 / 证据洗白」——哈希链与条款映射可以做出完美可审计的外观，但若注册证书在退化方向上是 gauge-broken、且群体条件覆盖只在被测量群体上达标，系统就会「法律上可辩护、物理与伦理上错误」；因此 E97（最差群体红线）与 E98（条款证据完整性）必须设为红线，且默认回退到「配准弃权 + 纯收缩个性化 + 监管熔断」这条「不确定就停/慢/交人」的底线。
