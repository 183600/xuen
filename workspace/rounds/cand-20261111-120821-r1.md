# 第 55 轮（承接第 54 轮 v16++ GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「多传感器融合」×「低成本方案」）

> 第 54 轮把技能组合推进为「动作-鲁棒性双证书」，但所有证书都隐含一个未被追问的前提：**观测通道是给定的、充分的、且免费的**。本轮从「多传感器融合」与「低成本方案」出发，追问证书的**观测支撑**与**经济可行性**。核心矛盾：H22：证书并非技能的内禀属性，而是 (技能, 传感器组, 融合算子) 的联合属性，单通道证书在融合/降级下会失真；H23：低成本异构冗余可在期望意义上替代昂贵单传感器，但仅在失效去相关时成立，否则退化为伪安全；H24：传感器子集选择、动作覆盖、鲁棒性谱三者耦合，不能独立优化。

## 0. 直觉与动机

**灵感 1（证书的观测支撑 → 从“技能有证书”到“某传感器组能为该技能背书”）**
直觉：第 54 轮的 `α_S` 与 `ρ_S` 是在一个隐含观测通道下测得的。换一组传感器或换一个融合算子，同一个动作是否“可辨识”、同一个失败维度是否“可解释”都会改变。因此证书必须携带 **观测支撑集 Σ** 与融合算子 F，记 `ρ_S^{Σ,F}`、`α_S^{Σ,F}`。没有观测支撑的证书是悬空的：它无法回答“这条鲁棒性结论，是谁看见的”。

**灵感 2（多传感器融合 → 异构冗余换取可观测性，而非简单精度叠加）**
直觉：融合的第一价值不是“更准”，而是**让原本不可辨识的失效维度变得可辨识**。相机看不清反光，ToF 可补；IMU 漂移，轮速计可锚定。融合把单通道的盲区变成可被交叉验证的维度，从而**扩张证书的 domain**。但融合也引入新失效：标定漂移、时间不同步、融合算子被单一模态污染。故融合证书必须同时记录“扩了哪些域”与“引入了哪些共模”。

**灵感 3（低成本方案 → 用“去相关的廉价冗余”替代“昂贵的单点高可靠”）**
直觉：一个高可靠传感器很贵；三个廉价异构传感器若能**独立失效**，其同时失效概率是乘积，反而更可靠。低成本的本质不是“买便宜货”，而是**把可靠性预算从“单器件精度”转移到“失效去相关 + 融合校验”**。关键判据是有效冗余度 `k_eff` 与失效相关矩阵 Ψ，而不是传感器数量——十个同批次廉价相机可能只等价于一个通道。

**灵感 4（预算化选型 → 证书-成本前沿，而非拍脑袋堆传感器）**
直觉：给定成本预算 B、动作覆盖 `θ_cov`、鲁棒性下限 `ρ_min`、有效冗余 `k_min`，选一个子集 `Σ* ⊆ Ω`。这是**带证书约束的最小成本子集选择**。覆盖是单调次模，`k_eff` 单调但未必次模，故用 lazy greedy 取近似 + 小规模 MILP 校验。其输出是一条 **成本-证书前沿**：每多花一元买到的成功率增量，使“低成本”成为一个可优化的量而非口号。

**灵感 5（降级契约 → 传感器掉线时“收缩动作域”而不是“整体停机”）**
直觉：低成本器件失效率更高，不能假设满配常驻。与其在掉线时整体拒动，不如预先为每个单通道丢失场景 ℓ 计算**降级契约** `D_ℓ = (A_reduced, ρ_lower, τ_switch)`：主动收缩动作域到仍可证书覆盖的子集，换取“降级但安全”的持续运行。这把可靠性从“零/一”变成**可度量的连续退化曲线**，也使“低成本”的代价被显式计价。

## 1. 形式化定义（增量：定义 121–127）

**定义 121（传感器组与融合算子）**
传感器组 `Σ = {(s_i, c_i, f_i)}_{i=1}^m`：`s_i` 为模态，`c_i` 为归一化成本（采购/功耗/延迟的加权），`f_i: C → [0,1]` 为在环境条件 `c∈C` 下的可用概率。融合算子 `F: ∏_i O_i → O`，附融合延迟 `τ_F(Σ)` 与融合诱导相关性 `Ψ_F`。

**定义 122（通道-动作可观测性）**
在 `(Σ,F)` 下，动作 a 的可辨识度 `obs(a; Σ, F) ∈ [0,1]` 为融合观测能把执行 a 后的状态区分开的概率。技能动作剖面扩展为
`α_S^{Σ,F}(a) = α_S(a) · obs(a; Σ, F)`。
可证书动作集 `A_cert(Σ,F) = {a | α_S^{Σ,F}(a) ≥ θ_cov ∧ obs(a;Σ,F) ≥ θ_obs}`。

**定义 123（融合鲁棒性谱）**
`ρ_S^{Σ,F}(d) = E_{π_Σ}[ρ_S(d | Σ_avail)]`，其中 `π_Σ` 是各通道按 `f_i` 及其相关性失效后的可用子集分布；单通道退化记 `ρ_S^{Σ\{i},F}`。与第 53/54 轮的 `ρ` 兼容：当 `Σ` 为满配且 `F=id` 时退化为原谱。

**定义 124（失效相关矩阵与有效冗余度）**
失效指示 `X_i = 1[通道 i 失效]`，相关矩阵 `Ψ_{ij} = corr(X_i, X_j)`，`Ψ_ii = 1`。设通道可用度 `π_i = 1 - E[X_i]`，**有效冗余度**
```
k_eff(Σ) = (Σ_i π_i)^2 / Σ_{i,j} π_i π_j Ψ_{ij}
```
是“等效独立通道数”：完全独立时 `k_eff = Σ_i π_i`，完全共模时 `k_eff → 1`。**去相关条件** `max_{i≠j} Ψ_{ij} ≤ ψ_max`。

**定义 125（预算化选型与成本-证书前沿）**
给定候选 Ω、预算 B、阈值 `(θ_cov, θ_obs, ρ_min, k_min, τ_max)`：
```
Σ* = argmin_{Σ⊆Ω} cost(Σ)
     s.t. cover(S,A_T;Σ,F)=1
          ∧ ρ^{Σ,F}(d) ≥ ρ_min  ∀d
          ∧ k_eff(Σ) ≥ k_min
          ∧ τ_F(Σ) ≤ τ_max
```
成本-证书前沿 `𝔉 = {(cost(Σ), LB_success(Σ))}` 为其 Pareto 前沿，`LB_success` 取正确性定理给出的下界。

**定义 126（降级契约）**
对单通道丢失场景 `ℓ ∈ Σ`，降级契约 `D_ℓ = (A_reduced, ρ_lower, τ_switch, evidence)`：
- `A_reduced ⊆ A_cert(Σ\{ℓ}, F)`；
- `ρ_lower = min_d ρ^{Σ\{ℓ},F}(d)`；
- `τ_switch` 为通道切换时延。
要求 `ρ_lower ≥ ρ_min^deg` 且 `τ_switch ≤ τ_deg`。多通道丢失由 `k_eff` 与共模预算覆盖。

**定义 127（融合-技能联合证书）**
```
FJ = (J, Σ*, F, ρ^{Σ,F}, Ψ, k_eff, cost, D, evidence)
```
- `J` 为第 54 轮动作-鲁棒性联合证书；
- `(Σ*, F)` 为证书的观测支撑；
- `ρ^{Σ,F}` 为融合鲁棒性谱，`Ψ` 为失效相关，`k_eff` 为有效冗余；
- `D = {D_ℓ}` 为降级契约集；
- `evidence` 至少含**真机掉线注入**与共模事件日志，不得仅仿真。
部署条件：`dom_J(T)=in ∧ δ_a<Θ_a ∧ k_eff≥k_min ∧ (∀ℓ: D_ℓ 满足) ∧ cost(Σ*)≤B`。

## 2. 关键算法 伪代码

### IP-121 MSP（Multi-Sensor Profiling）

```python
def profile_sensor(sensor, skill, actions, episodes, conditions):
    obs = {}
    for a in actions:
        hits = 0
        for _ in range(episodes):
            c = sample_condition(conditions)
            o = sensor.observe(sim.run(skill, a, c))
            hits += int(identifiable(o, skill, a))
        obs[a] = hits / episodes
    return obs

def fusion_profile(profiles, F, actions):
    return {a: F.identifiability({i: p[a] for i, p in profiles.items()})
            for a in actions}

def action_profile_fused(skill, Sigma, F, actions, episodes, conditions):
    profs = {s.id: profile_sensor(s, skill, actions, episodes, conditions)
             for s in Sigma}
    obs = fusion_profile(profs, F, actions)
    return {a: skill.alpha[a] * obs[a] for a in actions}
```

### IP-122 FRC（Fusion Robustness Certificate）

```python
def estimate_correlation(sensor_logs):
    X = failure_indicators(sensor_logs)        # T x m
    return corrcoef(X)                          # Psi

def effective_redundancy(pi, Psi):
    num = sum(pi) ** 2
    den = sum(pi[i] * pi[j] * Psi[i][j] for i in pi for j in pi)
    return num / den if den > 0 else 1.0

def fusion_robustness(skill, Sigma, F, dims, dropout_sampler, N=2000):
    rho = {d: 0.0 for d in dims}
    for _ in range(N):
        avail = dropout_sampler.sample(Sigma)   # 必须用 latent-cause/copula
        r = robustness_spectrum(skill, dims, channels=avail, fusion=F)
        for d in dims:
            rho[d] += r[d] / N
    return rho
```

> 关键实现约束：`dropout_sampler` 必须**按 Ψ 的共模结构**采样，不能当成独立通道，否则会系统性低估同时失效概率。

### IP-123 BSS（Budgeted Sensor Selection）

```python
def budgeted_select(Omega, skill_seq, A_T, B, th, F, sampler):
    Sigma, cost = [], 0.0
    while True:
        best = None
        for s in Omega - set(Sigma):
            if cost + s.cost > B:
                continue
            Sigma2 = Sigma + [s]
            obs = fusion_profile(profile_all(Sigma2), F, A_T)
            rho = fusion_robustness(skill_seq, Sigma2, F, th.dims, sampler)
            gain = coverage(obs, A_T) + th.lam * (k_eff(Sigma2) - k_eff(Sigma))
            score = gain / s.cost
            if best is None or score > best.score:
                best = (s, score)
        if best is None:
            break
        Sigma.append(best[0]); cost += best[0].cost
        if admissible(Sigma, A_T, th, F, sampler):   # 及时刹车
            return Sigma, cost
    return None                                       # 预算内不可行

# 若 |Omega| 小且追求最优：转 MILP，约束为覆盖 + k_eff + tau_F
```

### IP-124 GDC（Graceful Degradation Contract）

```python
def build_degradation_contracts(Sigma, F, skill_seq, actions, rho_min_deg, tau_deg):
    D = {}
    for l in Sigma:
        Sl = Sigma - {l}
        A_red = set()
        for a in actions:
            if all(cover_check(action_profile_fused(s, Sl, F, [a]), [a])
                   for s in skill_seq):
                r = fusion_robustness(skill_seq, Sl, F, DIMS, SAMPLER)
                if min(r.values()) >= rho_min_deg:
                    A_red.add(a)
        D[l] = DegContract(A_reduced=A_red,
                           rho_lower=min(fusion_robustness(
                               skill_seq, Sl, F, DIMS, SAMPLER).values()),
                           tau_switch=measure_switch_latency(l))
        if D[l].tau_switch > tau_deg:
            D[l].mark_unsafe()
    return D
```

### IP-125 FSC（Fusion-Skill Co-certificate）

```python
def fusion_joint_certificate(skill_seq, Sigma, F, B, budgets):
    J = joint_certificate(skill_seq, budgets.gamma_ce,
                          budgets.delta_a, budgets.rho_min)
    if J is None or J.status != 'ok':
        return ('reject', 'base_cert_fail')
    rho_f = compose_fusion_robustness(skill_seq, Sigma, F, DIMS, SAMPLER)
    Psi = estimate_correlation(sensor_logs(Sigma))
    keff = effective_redundancy(availability(Sigma), Psi)
    if keff < budgets.k_min:
        return ('reject', 'redundancy_low', keff)
    if max_offdiag(Psi) > budgets.psi_max:
        return ('reject', 'common_mode_risk', max_offdiag(Psi))
    D = build_degradation_contracts(Sigma, F, skill_seq,
                                    budgets.actions,
                                    budgets.rho_min_deg, budgets.tau_deg)
    if not all(c.ok for c in D.values()):
        return ('reject', 'degradation_gap')
    cost = sum(s.cost for s in Sigma)
    if cost > B:
        return ('reject', 'budget_exceeded', cost)
    return ('ok', FusionJointCert(J, Sigma, F, rho_f, Psi, keff, cost, D))
```

### IP-126 CCF（Cost-Certificate Frontier）

```python
def cost_certificate_frontier(Omega, skill_seq, A_T, budgets, F):
    frontier = []
    for B in sweep(budgets.B_lo, budgets.B_hi, step):
        Sigma = budgeted_select(Omega, skill_seq, A_T, B, budgets, F, SAMPLER)
        if Sigma is not None:
            lb = soundness_lower_bound(Sigma, budgets)
            frontier.append((sum(s.cost for s in Sigma), lb))
    return pareto_filter(frontier)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| MSP | O(m·|A|·E·|C|) | O(m·|A|) | 逐通道校准、条件覆盖 |
| FRC | O(N·|𝔇_ρ|·|Σ|) | O(|Σ|²+|𝔇_ρ|) | 采样器尊重 Ψ 共模结构 |
| BSS | O(|Ω|²·|A|·N) 近似 | O(|Ω|·|A|) | 覆盖次模、可行性及时校验 |
| GDC | O(|Σ|·|A|·|𝔇_ρ|) | O(|Σ|·|A|) | 单通道丢失全覆盖、切换有界 |
| FSC | O(|S|·|A| + |Σ|² + N·|𝔇_ρ|) | O(|Σ|²+|A|) | 联合证书 sound、预算闭合 |
| CCF | O(k_B·BSS) | O(k_B) | 前沿单调、Pareto 完整 |

**正确性定理（Low-Cost Fusion Certificate Soundness）**
假设第 53/54 轮 (A22)–(A28) 成立；**(A29)** 每通道失效模型 `f_i` 在目标条件下校准；**(A30)** 成对失效相关 `max Ψ_ij ≤ ψ_max`，且融合算子 F 不引入超出 `Ψ_F` 的隐藏共模；**(A31)** 每个单通道丢失 ℓ 被 `D_ℓ` 覆盖且 `τ_switch ≤ τ_deg`。
则对满足定义 125 的任意 `Σ*`：
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a)
            - P(预算 B 内无可行 Σ*) - C_cm(Σ*)
```
其中共模项 `C_cm(Σ*) ≤ P(latent cause) + Σ_{i<j} Ψ_ij·q_i q_j`（`q_i` 为通道失效边际），且**低成本替代条件**为
```
P_fail(Σ_cheap) = P(⋂_{i∈Σ_cheap} X_i) + C_cm ≤ P_fail(s_expensive)
```
独立失效时 `P(⋂ X_i) = ∏ p_i`，故当 `∏ p_i < p_expensive` 且共模可忽略时，廉价异构冗余严格占优；`k_eff ≥ k_min` 给出同时失效贡献的上界，避免“数量堆叠的伪冗余”。

**关键说明**：定理的“低成本”结论**不是**由传感器价格推出的，而是由 `(∏p_i, C_cm, k_eff)` 三元组推出的；价格只进入 `Σ*` 的可行域与前沿，不进入 soundness。这一分离是本轮的核心方法论。

## 4. 实验设计 E162–E166

| 实验 | 指标 | 目标 |
|---|---|---|
| E162 通道可观测性校准 | `|obs - obs_real|` | MAE ≤ 0.06 |
| E163 融合鲁棒性谱校准 | `ρ^{Σ,F}` vs 真机掉线 | MAE ≤ 0.08；与昂贵单传感器成功率差 ≤ 3pt |
| E164 预算化选型 | 同成功率下成本降幅 / 可行集召回 | 降本 ≥ 35%，召回 ≥ 90% |
| E165 降级契约 | 单/双通道掉线成功率、危险动作数 | 成功率 ≥ 90%，危险动作 = 0 |
| E166 成本-证书前沿与共模检测 | 前沿覆盖度、共模事件召回 | 共模召回 ≥ 85%，跨 3 平台泛化 |

**消融设计**：(a) 去掉 Ψ 共模建模（按独立采样）→ 预期 E163 乐观偏差显著、真机掉线失败；(b) 去掉降级契约 → 预期 E165 掉线时整体停机率骤升；(c) 用“数量冗余”替代 `k_eff` → 预期同批次廉价件成组失效。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 廉价异构件存在强共模（光照/粉尘/EMI/同批次） | 高 | 共模在线监控 + `ψ_max` 硬约束 + 故意跨批次/跨供电选型 |
| 失效相关 Ψ 估计样本不足、漂移 | 高 | 持续掉线注入 + 分层贝叶斯/置信上界 + 保守先验 |
| 融合算子时间不同步引入伪观测 | 高 | 时间戳对齐 + 延迟预算 `τ_F` + 融合失败安全回退 |
| 选型在小样本上过拟合仿真 | 中 | 跨平台留出 + 冷启动保守子集 |
| 降级切换抖动/震荡 | 中 | hysteresis + 预计算契约表 + 切换去抖 |
| 低成本件标定漂移削弱 `α_S^{Σ,F}` | 中 | 在线自校准 + 可观测性衰减告警 |

## 6. 本轮最大风险

**一句话**：整套“低成本多传感器融合证书”的 soundness 全部压在**失效去相关**这一条假设上，而真实机器人上的廉价异构传感器恰恰经常共享共模成因（光照、粉尘、电磁干扰、供电轨、同批次缺陷），一旦仿真中测得的有效冗余 `k_eff` 在实地塌缩、共模项 `C_cm` 被低估，所谓“廉价冗余”就会从可靠性来源变成**伪安全的放大器**；因此必须把 Ψ 的保守上界、共模在线监控、真机掉线注入与降级契约作为四道硬护栏，宁可为冗余多付一点钱，也绝不把“仿真里独立”当作“现场里独立”。

## 2. 关键算法 伪代码

### IP-121 MSP

```python
def profile_sensor(sensor, skill, actions, episodes, conditions):
    obs = {}
    for a in actions:
        hits = sum(int(identifiable(sensor.observe(
            sim.run(skill, a, sample_condition(conditions))), skill, a))
            for _ in range(episodes))
        obs[a] = hits / episodes
    return obs

def action_profile_fused(skill, Sigma, F, actions, episodes, conditions):
    profs = {s.id: profile_sensor(s, skill, actions, episodes, conditions)
             for s in Sigma}
    obs = {a: F.identifiability({i: p[a] for i, p in profs.items()})
           for a in actions}
    return {a: skill.alpha[a] * obs[a] for a in actions}
```

### IP-122 FRC

```python
def estimate_correlation(sensor_logs):
    return corrcoef(failure_indicators(sensor_logs))

def effective_redundancy(pi, Psi):
    num = sum(pi) ** 2
    den = sum(pi[i] * pi[j] * Psi[i][j] for i in pi for j in pi)
    return num / den if den > 0 else 1.0

def fusion_robustness(skill, Sigma, F, dims, dropout_sampler, N=2000):
    rho = {d: 0.0 for d in dims}
    for _ in range(N):
        avail = dropout_sampler.sample(Sigma)   # 尊重 Ψ 的共模采样
        r = robustness_spectrum(skill, dims, channels=avail, fusion=F)
        for d in dims:
            rho[d] += r[d] / N
    return rho
```

### IP-123 BSS

```python
def budgeted_select(Omega, skill_seq, A_T, B, th, F, sampler):
    Sigma, cost = [], 0.0
    while True:
        best = None
        for s in Omega - set(Sigma):
            if cost + s.cost > B:
                continue
            Sigma2 = Sigma + [s]
            obs = fusion_profile(profile_all(Sigma2), F, A_T)
            rho = fusion_robustness(skill_seq, Sigma2, F, th.dims, sampler)
            gain = coverage(obs, A_T) + th.lam * (k_eff(Sigma2) - k_eff(Sigma))
            score = gain / s.cost
            if best is None or score > best.score:
                best = (s, score)
        if best is None:
            break
        Sigma.append(best[0]); cost += best[0].cost
        if admissible(Sigma, A_T, th, F, sampler):
            return Sigma, cost
    return None
    # |Omega| 小且需最优时改 MILP：min cost s.t. cover, k_eff>=k_min, tau_F<=tau_max
```

### IP-124 GDC

```python
def build_degradation_contracts(Sigma, F, skill_seq, actions, rho_min_deg, tau_deg):
    D = {}
    for l in Sigma:
        Sl = Sigma - {l}
        A_red = {a for a in actions
                 if all(cover_check(action_profile_fused(s, Sl, F, [a]), [a])
                        for s in skill_seq)
                 and min(fusion_robustness(skill_seq, Sl, F,
                                           DIMS, SAMPLER).values()) >= rho_min_deg}
        D[l] = DegContract(A_reduced=A_red,
                           rho_lower=min(fusion_robustness(
                               skill_seq, Sl, F, DIMS, SAMPLER).values()),
                           tau_switch=measure_switch_latency(l))
    return D
```

### IP-125 FSC

```python
def fusion_joint_certificate(skill_seq, Sigma, F, B, budgets):
    J = joint_certificate(skill_seq, budgets.gamma_ce,
                          budgets.delta_a, budgets.rho_min)
    if J is None or J.status != 'ok':
        return ('reject', 'base_cert_fail')
    rho_f = compose_fusion_robustness(skill_seq, Sigma, F, DIMS, SAMPLER)
    Psi = estimate_correlation(sensor_logs(Sigma))
    keff = effective_redundancy(availability(Sigma), Psi)
    if keff < budgets.k_min:
        return ('reject', 'redundancy_low', keff)
    if max_offdiag(Psi) > budgets.psi_max:
        return ('reject', 'common_mode_risk', max_offdiag(Psi))
    D = build_degradation_contracts(Sigma, F, skill_seq, budgets.actions,
                                    budgets.rho_min_deg, budgets.tau_deg)
    if not all(c.ok for c in D.values()):
        return ('reject', 'degradation_gap')
    cost = sum(s.cost for s in Sigma)
    if cost > B:
        return ('reject', 'budget_exceeded', cost)
    return ('ok', FusionJointCert(J, Sigma, F, rho_f, Psi, keff, cost, D))
```

def cost_certificate_frontier(Omega, skill_seq, A_T, budgets, F):

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| MSP | O(m·|A|·E·|C|) | O(m·|A|) | 逐通道校准、条件覆盖 |
| FRC | O(N·|𝔇_ρ|·|Σ|) | O(|Σ|²+|𝔇_ρ|) | 采样尊重 Ψ 共模结构 |
| BSS | O(|Ω|²·|A|·N) 近似 | O(|Ω|·|A|) | 覆盖次模、可行性校验 |
| GDC | O(|Σ|·|A|·|𝔇_ρ|) | O(|Σ|·|A|) | 单通道丢失全覆盖 |
| FSC | O(|S|·|A| + |Σ|² + N·|𝔇_ρ|) | O(|Σ|²+|A|) | 联合证书 sound、预算闭合 |
| CCF | O(k_B·BSS) | O(k_B) | 前沿单调、Pareto 完整 |
| CMM | O(m²·window) | O(m²) | Ψ 保守上界、绊线可复现 |

**正确性定理（Low-Cost Fusion Certificate Soundness）**
假设第 53/54 轮 (A22)–(A28) 成立；**(A29)** `f_i` 在目标条件下校准；**(A30)** `max Ψ_ij ≤ ψ_max` 且 F 不引入超出 `Ψ_F` 的隐藏共模；**(A31)** 每个单通道丢失 ℓ 被 `D_ℓ` 覆盖且 `τ_switch ≤ τ_deg`。
则对满足定义 125 的 `Σ*`：
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a)
            - P(B 内无可行 Σ*) - C_cm(Σ*)
```
低成本替代判据：
```
P_fail(Σ_cheap) = P(⋂_{i∈Σ_cheap} X_i) + C_cm ≤ P_fail(s_expensive)
```
独立失效 → `P(⋂X_i)=∏p_i`；当 `∏p_i < p_expensive` 且共模可忽略，廉价异构冗余严格占优；`k_eff ≥ k_min` 给出同时失效上界，防止“数量伪冗余”。

## 5. 本轮最大风险

**一句话**：整套“低成本多传感器融合证书”的 soundness 全部压在**失效去相关**这一条假设上，而真实机器人上的廉价异构传感器恰恰经常共享共模成因（光照、粉尘、电磁干扰、供电轨、同批次缺陷），一旦仿真中测得的有效冗余 `k_eff` 在实地塌缩、共模项 `C_cm` 被低估，所谓“廉价冗余”就会从可靠性来源变成**伪安全的放大器**；因此必须把 Ψ 的保守上界、共模在线监控（CMM）、真机掉线注入与降级契约（GDC）作为四道硬护栏，宁可为冗余多付一点钱，也绝不把“仿真里独立”当作“现场里独立”。
