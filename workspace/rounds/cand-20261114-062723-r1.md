# 第 70 轮（承接第 69 轮「FLUID-RAS」IP-253~263；本轮灵感：「语音合成」×「桌面操作」）

> R69 已经让不确定性有了「形状」（流匹配多模态策略）和「嘴巴」（主动提问），但它悄悄依赖两个只对连续体成立的前提。第一，**保守 = 变慢**：R68/R69 的 λ_floor 是一个连续缩放因子，前提是动作可以被「半做」。桌面操作把这个前提击碎了——你无法「半次点击 Send」，无法「以 0.5 的速度永久删除文件」；离散动作只有「做 / 不做」，而且一旦提交常常不可逆。真正对应 λ 的东西不是速度，而是**可逆性**（undo 半径与提交深度）。第二，**交互 = 提问后得到一个值**：R69 把交互压缩成一次返回标量的查询，忽略了人类最自然的通道——语音。语音不是文本的音频化，它有三个别的通道没有的物理属性：**时长**（一句话要占几百毫秒到几秒，天然是一段可打断的撤销窗口）、**韵律**（犹豫、停顿、语速本身就是置信度的显示器）、**身份**（谁在说，决定这句话能不能当授权）。三者叠加，使语音合成既是 R69 意义上的「信息动作」，又是一种**提交协议**。
>
> 本轮核心命题：**在不可逆的离散桌面操作里，保守性的正确货币是「可逆性」而不是「慢」；把「先想清楚再提交」实现为「流匹配动作 × 流匹配语音的联合生成 + 撤销图门控 + 韵律校准的言语-动作绑定」。语音既是解释，也是围栏；说出来的每一句，都必须和即将做的那一步共享同一个潜模态。** 命名 **VERB-RAS**（Voice-Enabled Reversible-Behavior Risk-Adaptive System）——verb 既是「动词 / 动作」，也是「言语」。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我该怎么说、说到哪一步、说的时候还撤得回来吗**」。

## 0. 直觉与动机

**灵感 1（桌面操作 → 保守性的货币是「可逆」，不是「慢」）**
直觉：在连续控制里，把速度降到 0.1 倍几乎等价于「先别撞上去」；在桌面里，把鼠标移到按钮上再停住，和点下去，是两种动作，而后者可能立刻不可逆。R69 的 λ 只能缩「幅度」，缩不了「提交」这个离散事件。于是本轮引入**撤销图**：每个桌面动作 a 在当前状态 s 下都有一个回退代价 ρ(a|s)，回退序列的存在性给出**可逆半径 R(a|s)** 与**提交深度 d(a|s)**。保守策略不再是「把动作调小」，而是「在不确定性未消解时，只走 d 小、R 大的动作」，把「半做」变成「先做探针、再做提交」。这把 λ_floor 从标量缩放升级为**偏序阶梯**：探针 ⊂ 软提交 ⊂ 播报后提交 ⊂ 静默硬提交。

**灵感 2（语音合成 → 声音自带「时长」这个免费的撤销窗口）**
直觉：文本确认是瞬时的；一句合成语音要持续 D 秒。这 D 秒不是纯粹的开销——它是一段**可打断、可自我中止**的时间窗：用户听到「我准备把这三封邮件永久删除」时，可以在最后一个音节落下前喊停；系统也可以在这 D 秒内收到新证据而自行撤回。更重要的是，现代 TTS（F5-TTS / Voicebox 一类 rectified-flow 模型）与 R69 的流匹配策略共享同一套数学：从噪声到序列的速度场。这让我们能做 R69 做不到的事——**把「说的」和「做的」绑到同一个潜模态上**，而不是先决定动作、再让 LLM 措辞。

**灵感 3（同源流匹配 → 说做绑定，制造一条新的「言语似然」通道）**
直觉：R69 用动作轨迹在策略密度下的似然做「标定不可吸收的第二意见」。在语音在场时，我们还能多一条更便宜、更直接的通道：**说—做一致性**。如果动作头和语音头共享模态 m，那么「嘴上说要删 A、手上却点向 B」就是一个可观测的异常分 Δsa；它不需要传感器标定，也不需要外部真值。它既能抓模型幻觉（动作模态坍缩而语言头还在按旧分布说话），也能抓**语音注入攻击**（攻击者把一句伪造的「已确认」喂进来，却无法同时改变动作模态）。

**灵感 4（语音也是新的攻击面，而且「同意」会被用旧）**
直觉：一旦系统用语音确认，攻击面从像素扩展到声波：声纹克隆冒充用户、重放一段「yes」、超声波 / 背景语音注入隐藏指令，以及最阴险的一种——**用系统自己的嗓子去骗用户**（TTS 被劫持后以可信嗓音播报错误指令）。与此同时，**反复确认会让人类进入橡皮图章模式**：用户对第 20 次「是否继续」的反应时间降到 0.3 秒、接受率升到 99%，此时「确认」在信息论上已经死了。所以本轮必须把「人类注意力」建模成一种会被消耗的资源，而不是 R69 里取之不尽的返回通道。

**灵感 5（严格包含 → FLUID 是「永不出声、动作全可逆」的退化边界）**
直觉：当动作空间连续（每个动作无穷小、皆可回退）、且语音关闭（D=0、无播报）时，可逆性门控自动失效（所有 d=0），VERB 逐指令退化为 FLUID。反过来，在离散不可逆域里 FLUID 的 λ 根本无法安全落地（缩到 0 也还是要点一次或不点），所以 VERB 不是 FLUID 的替代，而是它在「离散化 + 不可逆」方向上的**唯一正确延拓**。安全侧继续只增不减。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（VERB-RAS 总览）** VERB-RAS = (UDG, VGL, SPA, PSC, NCW, SAB, SVA, DCA, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承定义 276-i）；
(ii) **可逆性门控**：U_epi 未消解时，只允许提交深度 d(a|s) ≤ d_max(U_epi) 的动作；d_max 关于 U_epi 单调不增；
(iii) **播报-授权纪律**：硬提交（L2）必须伴随可听播报与撤销窗口；不可逆提交（L3）必须通过双通道授权，语音不得单独授权；
(iv) **说-做绑定**：实际执行的动作与播报内容必须由同一潜模态生成，绑定哈希 β 进入证书。

**定义 311（桌面动作与撤销图 UDG）** 桌面动作 a ∈ 𝒜_desk（click / type / key / menu / scroll / drag / send / delete …），状态 s ∈ 𝒮。撤销图 G_u = (𝒮, 𝒜_desk, T, U)：U(s,a) ⊆ 𝒜* 为能回到 s（语义等价，容差 ε_u）的回退序列集合。回退代价 ρ(a|s) = min_{u∈U(s,a)} cost(u)（U 为空则 ρ=∞）。**可逆半径** R_τ(a|s) = {s′ : 存在从 T(s,a) 出发、代价 ≤ τ 回到 s 的路径}。**提交深度** d(a|s) = 0 若 ρ≤ρ₀（探针级）；=1 若 ρ≤ρ₁（软提交）；=2 若 ρ 有限但昂贵（硬提交）；=∞ 若 U 为空（不可逆）。

**定义 312（提交阶梯）** 动作按可逆性偏序分层：L0 探针（hover / focus / scroll / 展开菜单 / 切换标签，ρ≈0）、L1 软提交（写入草稿、移入回收站、暂存，便宜可撤）、L2 硬提交（发送、支付、安装、永久删除）、L3 不可逆（ρ=∞）。保守性定义为一个**门控**：给定 U_epi，允许的最大层 ℓ_max(U_epi) 单调不增；候选动作若超层则被替换为其 L0 前置探针或播报-确认。

**定义 313（言语动作空间 SPA）** 言语动作 s = (intent, content, prosody) ∈ 𝒮；intent ∈ {ask（求值）, confirm（求授权）, narrate（出声思考）, warn（风险提示）, offer_undo（事后回退提议）}；content 为结构化语义（含动作指纹 action_fp），prosody = (rate, pitch_μ, pitch_σ, pause_ratio, energy)。合成音频 y = TTS_φ(content, prosody)，TTS 为冻结的 rectified-flow 模型，梯度不回流。

**定义 314（韵律校准 PSC）** 犹豫指数 h(prosody) = w₁·pause_ratio + w₂·(1−rate) + w₃·pitch_σ + w₄·filler_ratio。内部不确定性 u = U_epi 与提交风险 r(a) 的函数。要求 h 与 u 单调同向，且韵律校准误差 ECE_p = Σ_b |E[u | h∈b] − center(b)| ≤ τ_p。**双阈值**：h 过低（过度自信）比 h 过高更危险（会抑制用户纠正）——损失函数不对称。

**定义 315（播报提交窗 NCW）** 硬 / 不可逆提交前必须生成 narrate 言语动作，时长 D_s(y)。定义提交时刻 t_c = t₀ + D_s(y) − τ_c；在 [t₀, t_c) 内，用户打断（stop / undo 关键词）或系统新证据均可中止。行为等价于一段**用沟通时间买来的决策延迟**：它不是空等，而是同时完成了解释与围栏。

**定义 316（可逆性门控策略 VGL）** 流匹配策略在离散动作块上采样得模态 {m_k}，对每个模态选代表动作 a_k。门控：a_k 仅当 d(a_k|s) ≤ ℓ_max(U_epi) 时可立即执行；否则替换为（i）同模态的 L0 探针，或（ii）narrate+confirm 的延迟提交。目标：在保证不越层的前提下最大化期望任务进度。

**定义 317（说-做绑定 SAB）** 共享潜模态 m，动作头生成 a ~ p_A(·|m,o)，语音头生成 content ~ p_S(·|m,o)，二者由同一 m 约束。绑定哈希 β = H(m, action_fp(a), content)。**说-做差异** Δsa = λ₁·1[action_fp(content)≠action_fp(a)] + λ₂·(1−cos(emb(content), emb(Describe(a))))。若 Δsa > τ_sa：判定为绑定破坏（模型不一致 / 语音注入 / 执行偏差），中止提交并审计。

**定义 318（言语价值 VoI-S 与同意疲劳 SVA）** 言语动作的信息价值 VoI_S(s) = H(M|o) − E[H(M|o,y_s)]，另加可逆性价值：期望降低的不可逆损失 P(ℓ(a)≥L2)·Δrisk。成本 c(s) = 时长 + 社交打扰 + **注意力消耗**。人类注意力 α(n) = α₀·γⁿ（n 为窗口内确认次数，γ<1），有效价值 α(n)·VoI_S。选择 s* = argmax[min(α·VoI_S, cap) − c]。若接受率 > p* 且响应时延 < τ*，触发**橡皮图章告警**：确认被视为非信息性，改走探针或强制双通道。

**定义 319（探针库 PPL）** 探针 p ∈ 𝒫 为 ρ≤ρ₀ 的信息动作（hover 看 tooltip、聚焦输入框、展开菜单看选项、滚到可见区、切换只读预览、截图放大）。探针先于提问：能用零提交代价看清的，不要用人来问。探针的 VoI 计入定义 318。

**定义 320（语音威胁模型 VTM）** 声纹克隆 / 合成冒充、重放已录制的确认、隐藏音频注入（超声 / 背景语音 / 不可听指令）、系统自身 TTS 被劫持后向用户播报伪指令、以及**同意洗白**（把危险子动作打包进一句笼统的「好的」）。ℰ_VERB = ℰ_FLUID × ℰ_voice × ℰ_desk（UI 漂移 / 诱饵控件 / 撤销图过时）。

**定义 321（双通道授权 DCA）** 一次 confirm 有效当且仅当：(i) 声纹验证通过且活体检测通过；(ii) 语音内容绑定到当前 action_fp 与非重放 nonce；(iii) ℓ(a)=L3 时至少另有一个正交通道（键入短码、硬件键、长按滑块）；(iv) 播报内容已完整枚举危险子动作（反对同意洗白）。任一不满足 ⇒ 授权无效，退回可逆层。

**定义 322（言语似然异常 / 说做不一致）** 类比定义 301 的 FMA：Δsa 是「标定不可吸收」的言语侧第二意见。由共享模态约束，攻击者若只注入语音不改动作，必然抬高 Δsa；若同时改动作，则会破坏 R69 的 Δa 通道。两通道联合给出 (Δa, Δsa) 的二维异常面。

**定义 323（不可逆动作登记 IAR）** 维护不可逆动作登记表 ℐ（send / pay / delete / install / 权限修改 …）。ℐ 中动作 commit 前强制 narrate；静默执行 ℐ 动作视为协议违规（审计必报）。登记表带版本与时间戳，UI 漂移时先离线回归校验（见定义 320）。

**定义 324（流式时序预算）** speak-while-plan 的实时约束：TTS 首包 < 120ms，动作决策 < 3ms；播报与动作规划并行，动作在 t_c 前不得提交。若 TTS 首包超时，降级为最短安全播报（动作名 + 范围 + 撤销方式）而非静默。

**定义 325（静默降级 fallback）** TTS / ASR 失效、声纹可疑、或 Δsa 异常时进入 mute 模式：只允许 L0 / L1；L2 / L3 改用非语音双通道或直接拒绝。此时 VERB 退化为「不出声、只可逆」，与 FLUID 的保守侧一致。

**定义 326（证书 J_VERB）** J_VERB = (J_FLUID, ECE_p, d_hist, β_hash, narrate_coverage, voice_auth_score, rubber_stamp_index, undo_compliance, verb_ver)。Valid ⇔ Valid(J_FLUID) ∧ ECE_p ≤ τ_p ∧ 所有 L2+ 动作有播报 ∧ L3 有双通道 ∧ 可逆性门控未越层。

# IP-264 UDG：撤销图与提交深度
class UndoGraph:
    def depth(self, s, a):            # 0 探针 / 1 软提交 / 2 硬提交 / inf 不可逆
        u = self.min_undo(s, a)
        return 0 if u.cost <= RHO0 else 1 if u.cost <= RHO1 else 2 if u else INF

    def gate(self, s, modes, u_epi):  # 可逆性门控：选不越层的代表动作
        lmax = self.ladder_max(u_epi) # 关于 u_epi 单调不增
        return [self.demote_or_probe(s, m) for m in modes
                if self.depth(s, m.a) <= lmax]

# IP-266/267 SPA + PSC：言语动作与韵律校准
class SpeechActPlanner:
    def narrate(self, m, s):          # 同一潜模态 m 生成播报内容
        content = self.speech_head(m, s)
        prosody = self.psc.calibrate(u=self.u_epi, risk=self.risk(s, m.a))
        return self.tts.synth(content, prosody)   # 冻结 rectified-flow TTS

class ProsodyCalibrator:
    def calibrate(self, u, risk):
        h = self.mono_map(u, risk)    # 目标犹豫指数
        return self.invert_hesitation(h)  # -> (rate, pause, pitch...)

# IP-268 NCW：用语音时长买撤销窗口
def narrated_commit(agent, a, s, budget):
    y   = agent.spa.narrate(agent.mode, s)
    t_c = now() + dur(y) - TAU_CANCEL
    while now() < t_c:                # 可打断、可自我中止
        if agent.asr.heard_stop() or agent.evidence_changed(): return ABORT
        sleep(tick)
    return COMMIT if agent.dca.authorize(a, y) else ABORT

# IP-269 SAB：说-做绑定与说做差异
def say_do_check(mode, a, y):
    fp  = action_fingerprint(a)
    dsa = semantic_distance(y.content, describe(fp))
    return dsa <= TAU_SA, H(mode, fp, y.content)

# IP-270 SVA：言语价值 + 同意疲劳
def choose_speech_act(modes, s, attention, budget):
    best = None
    for act in speech_acts(modes):
        if not budget.allow(act): continue
        val = min(attention * voi_s(act, modes), CAP) - cost(act)
        if best is None or val > best.val: best = (act, val)
    return best if best and best.val > 0 else None

# IP-278 主闭环
def VERB_RAS_round(M, s, obs):
    z, o = M.mtm.forward(obs); _, U_cal, _ = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    modes = M.fmp.sample(o, K); U_ale, U_epi = M.aud.decompose(modes)
    # 1) 先用零提交探针把能看见的看清
    for p in M.ppl.probe_candidates(modes, s):
        if M.udg.depth(s, p) == 0 and M.ppl.voi(p) > M.ppl.cost(p):
            s = M.exec(p); modes = M.aud.refine(modes, s)
    # 2) 可逆性门控：绝不在未消解歧义下提交高层动作
    lmax = M.udg.ladder_max(U_epi)
    cand = M.udg.gate(s, modes, U_epi)
    # 3) 需要解释/授权时，用同一模态播报
    a  = M.select(cand)
    m  = M.mode_of(modes, a)
    if M.udg.depth(s, a) >= 2:
        y = M.spa.narrate(m, s)
        ok, beta = M.sab.check(m, a, y)
        if not ok: return M.degrade(s, reason='say_do_gap')
        if M.udg.depth(s, a) == INF and not M.dca.authorize(a, y):
            return M.degrade(s, reason='auth')
        if narrated_commit(M, a, s, M.budget) == ABORT:
            return M.degrade(s, reason='aborted')
    else:
        M.exec(a)
    # 4) 证书 + 审计（含韵律/绑定/疲劳指标）
    M.vqa_v.submit_async(M.speech_log, beta, U_epi, M.dca.score())
    return a, M.cert()

## 3. 推导

**引理 19（可逆性门控的灾难上界）** 在 A99（同模态任务损失关于提交深度单调不减，且 L3 动作的期望损失 ≥ L_cat）下，若门控在 U_epi>τ_e 时强制 d(a) < d_crit，则因模态选错导致的灾难性损失为 0，仅剩 aleatoric 残差。要点：R69 的 λ 只能连续缩小「错误模态的影响」，无法在离散提交处把影响截断；门控直接在提交层截断。

**引理 20（播报窗的中止概率）** 设播报时长 D，用户反应时延 τ_r，错误在音频中被察觉的强度为泊松率 p。则用户在提交前打断的概率 ≥ 1−e^{−p(D−τ_r)}（D>τ_r）。系：对 L3 动作，强制播报相当于把「零窗口」变成「正窗口」；这也是为什么不能静默执行 ℐ 中动作。

**引理 21（同意疲劳使确认信息衰减）** 设注意力 α(n)=α₀γⁿ，第 n 次确认的有效信息为 α(n)·VoI_S。若确认只值一个固定小信息量，则存在 n* 使净收益转负；此后继续确认不仅无用，还消耗未来高价值确认的注意力。系：应把确认预算花在 VoI_S 最高的少数提交上，其余交给探针。

**引理 22（韵律校准的信任单调性）** 若 h(prosody) 关于 u 单调、ECE_p ≤ ε，则用户纠正概率关于 h 单调不降；过度自信（h < u）会把本应发生的纠正压掉。要点：韵律是安全信号，不是装饰；未校准的「自信嗓音」是一种主动风险，而非中性。

**定理 18（VERB 严格包含 FLUID）** 在 A99–A101 下：当动作连续可逆（所有 d=0）且语音关闭（D=0）时，VERB 逐指令退化为 FLUID；一般情形下，若任务无短于 D_s 的硬时限（A101），VERB 的期望损失 ≤ 同一状态上 FLUID 离散化（直接提交所选模态）的损失——门控只会把动作降到更浅的提交层或加一段可中止的播报。因此安全侧不让步，效率侧获得「探针 + 播报」的额外信息。

**定理 19（说-做绑定的异常可检出性）** 在 A102（动作头与语音头对同一 m 的映射 Lipschitz，且语音注入无法改变 m）下，若发生语音注入或模态不一致，Δsa 的期望上升 ≥ L_s·δ − √(trΣ_speech)；故 (Δsa↑, Δa 不变) 判别「纯语音攻击」，(Δsa↑, Δa↑) 判别「联合攻击 / 执行故障」。语音因此成为一条不能只靠标定吸收的独立证据通道。

## 6. 本轮最大风险

**一句话**：VERB-RAS 的全部安全论证都押在「撤销图是完备且实时的」这一前提上——而开放桌面里的不可逆性恰恰常常是**事后才被发现**的（邮件已发、款已付、站点改版悄悄新增了一条不可回滚边）；一旦 G_u 漏掉一条边，越流畅、越可信的合成语音只会把用户更稳地送进那个被漏掉的黑洞——**说得越像真的，错得越不可逆**。

**次级风险与缓解**：
1. **同意疲劳 / 橡皮图章** → 注意力预算 α(n) + rubber-stamp 检测 + 优先探针；
2. **韵律过度自信污染信任** → ECE_p 门控 + 不对称损失（宁可略犹豫）；
3. **语音冒充/重放/注入** → 声纹 + 活体 + nonce 绑定 + L3 双通道 + Δsa；
4. **UI 漂移导致撤销图过时** → 登记表版本化 + 回放回归 + 漂移检出；
5. **TTS 时延破坏实时性** → 流式首包 + 并行规划 + 最短安全播报降级。

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** VERB-RAS = (UDG, VGL, SPA, PSC, NCW, SAB, SVA, DCA, RAS-WM‡)；零学习写操作继承；可逆性门控（未消解 U_epi 时只允许 d ≤ d_max(U_epi)）；播报-授权纪律（L2 必播报 + 撤销窗，L3 必双通道，语音不得单独授权）；说-做绑定（β 入证书）。

**定义 311–312（撤销图与提交阶梯）** 回退代价 `ρ(a|s)=min_{u∈U(s,a)}cost(u)`；提交深度 `d=0/1/2/∞` 对应 L0 探针 / L1 软提交 / L2 硬提交 / L3 不可逆。保守性 = 门控 `ℓ_max(U_epi)` 单调不增，而非标量缩放。

**定义 313–314（言语动作与韵律校准）** `s=(intent,content,prosody)`；`y=TTS_φ(content,prosody)`；犹豫指数 `h=w₁·pause+w₂·(1−rate)+w₃·pitch_σ+w₄·filler`；要求 h 与 u 单调且 `ECE_p ≤ τ_p`，过度自信的罚权更高。

**定义 315（播报提交窗 NCW）** 提交前必播报；`t_c=t₀+D_s(y)−τ_c`；窗内用户可打断、系统可自我中止。语音时长 = 用沟通时间买的决策延迟。

**定义 316（可逆性门控策略 VGL）** 采样模态 {m_k}；仅当 `d(a_k|s) ≤ ℓ_max(U_epi)` 可立即执行，否则降级为同模态探针或 narrate+confirm 延迟提交。

**定义 317（说-做绑定 SAB）** 动作头与语音头共享 m；`β=H(m, action_fp(a), content)`；`Δsa>τ_sa` ⇒ 绑定破坏（不一致 / 注入 / 执行偏差），中止并审计。

**定义 318–319（VoI-S 与探针）** `VoI_S = H(M|o) − E[H(M|o,y_s)] + P(ℓ≥L2)·Δrisk`；成本含注意力消耗；`α(n)=α₀γⁿ`；接受率高且时延短 ⇒ 橡皮图章告警。探针库 p 满足 `ρ≤ρ₀`，探针先于提问。

**定义 320–321（语音威胁与双通道授权）** ℰ_voice = 克隆冒充 / 重放 / 隐藏音频注入 / TTS 劫持 / 同意洗白。confirm 有效需：声纹 + 活体 + nonce 与 action_fp 绑定 + L3 第二正交通道 + 完整枚举危险子动作。

**定义 322–323（言语似然与登记表）** Δsa 与 R69 的 Δa 组成二维异常面：`(Δsa↑,Δa不变)` = 纯语音攻击，`(Δsa↑,Δa↑)` = 联合攻击/故障。ℐ 中动作强制 narrate，静默视为协议违规。

**定义 324–326（时序、降级与证书）** TTS 首包 < 120ms，动作决策 < 3ms，提交不早于 t_c；语音/声纹/Δsa 异常 ⇒ mute 模式只许 L0/L1；J_VERB = (J_FLUID, ECE_p, d_hist, β_hash, narrate_coverage, voice_auth_score, rubber_stamp_index, undo_compliance, verb_ver)。

# IP-264 UDG：提交深度与门控
class UndoGraph:
    def depth(self, s, a):
        u = self.min_undo(s, a)
        return 0 if u.cost <= RHO0 else 1 if u.cost <= RHO1 else 2 if u else INF
    def gate(self, s, modes, u_epi):
        lmax = self.ladder_max(u_epi)                  # 单调不增
        out  = []
        for m in modes:
            if self.depth(s, m.a) <= lmax: out.append(m)
            else: out.append(self.demote_or_probe(s, m))   # 降级到 L0 或播报
        return out

# IP-266/267 SPA+PSC：同一潜模态生成播报，韵律承载校准后的不确定
class SpeechActPlanner:
    def narrate(self, m, s):
        content = self.speech_head(m, s)               # 与动作头共享 m
        prosody = self.psc.calibrate(self.u_epi, self.risk(s, m.a))
        return self.tts.synth(content, prosody)        # 冻结 rectified-flow TTS

# IP-268 NCW：语音时长 -> 撤销窗口
def narrated_commit(agent, a, s):
    y, t_c = agent.spa.narrate(agent.mode, s), None
    t_c = now() + dur(y) - TAU_CANCEL
    while now() < t_c:
        if agent.asr.heard_stop() or agent.evidence_changed(): return ABORT
        sleep(tick)
    return COMMIT if agent.dca.authorize(a, y) else ABORT

# IP-269 SAB：说-做差异
def say_do_check(mode, a, y):
    fp  = action_fingerprint(a)
    dsa = semantic_distance(y.content, describe(fp))
    return dsa <= TAU_SA, H(mode, fp, y.content)

# IP-270 SVA：言语价值 × 注意力衰减
def choose_speech_act(modes, s, attention, budget):
    best = None
    for act in speech_acts(modes):
        if not budget.allow(act): continue
        val = min(attention * voi_s(act, modes), CAP) - cost(act)
        if best is None or val > best.val: best = (act, val)
    return best if best and best.val > 0 else None

# IP-278 主闭环
def VERB_RAS_round(M, s, obs):
    z, o = M.mtm.forward(obs); _, U_cal, _ = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    modes = M.fmp.sample(o, K); U_ale, U_epi = M.aud.decompose(modes)
    for p in M.ppl.probe_candidates(modes, s):          # 先零提交探针
        if M.udg.depth(s, p) == 0 and M.ppl.voi(p) > M.ppl.cost(p):
            s = M.exec(p); modes = M.aud.refine(modes, s)
    cand = M.udg.gate(s, modes, U_epi)                  # 不可逆门控
    a, m = M.select(cand), M.mode_of(cand)
    if M.udg.depth(s, a) >= 2:                          # 硬/不可逆提交
        y = M.spa.narrate(m, s)
        ok, beta = M.sab.check(m, a, y)
        if not ok: return M.degrade(s, 'say_do_gap')
        if M.udg.depth(s, a) == INF and not M.dca.authorize(a, y):
            return M.degrade(s, 'auth')
        if narrated_commit(M, a, s) == ABORT:
            return M.degrade(s, 'aborted')
    else:
        M.exec(a)
    M.vqa_v.submit_async(M.speech_log, beta, U_epi, M.dca.score())
    return a, M.cert()

## 4. 推导

**引理 19（可逆性门控的灾难上界）** A99（损失关于提交深度单调不减，L3 期望损失 ≥ L_cat）下，门控在 `U_epi>τ_e` 时强制 `d<d_crit`，则模态选错导致的灾难性损失为 0，只剩 aleatoric 残差。要点：λ 只能连续缩小错误模态的影响，门控在提交层直接截断。

**引理 20（播报窗中止概率）** 播报时长 D、反应时延 τ_r、错误可察觉强度为泊松率 p，则提交前打断概率 ≥ `1−e^{−p(D−τ_r)}`（D>τ_r）。系：L3 强制播报把零窗口变成正窗口，故禁止静默执行 ℐ 动作。

**引理 21（同意疲劳）** 设 `α(n)=α₀γⁿ`，第 n 次确认有效信息为 `α(n)·VoI_S`。固定小信息量的确认存在 n* 使净收益转负，并透支未来高价值确认的注意力。系：确认预算应集中于 VoI_S 最高的少数提交，其余交给探针。

**引理 22（韵律信任单调性）** h 关于 u 单调且 `ECE_p≤ε` 时，用户纠正概率关于 h 单调不降；过度自信（h<u）会压掉本应发生的纠正。系：未校准的自信嗓音是主动风险，不是中性装饰。

**定理 18（VERB 严格包含 FLUID）** A99–A101 下：动作连续可逆（d≡0）且语音关闭（D=0）时逐指令退化为 FLUID；一般情形若任务无短于 D_s 的硬时限（A101），VERB 期望损失 ≤ FLUID 离散化直接提交的损失。故 R69 是「永不出声、全可逆」边界，安全不让步，效率获探针 + 播报信息。

**定理 19（说-做绑定的异常可检出性）** A102（两解码头对同一 m 的映射 Lipschitz，语音注入不能改变 m）下，注入或模态不一致使 `E[Δsa] ≥ L_s·δ − √(trΣ_speech)`。故 `(Δsa↑,Δa不变)` 判别纯语音攻击，`(Δsa↑,Δa↑)` 判别联合攻击/执行故障；言语是标定不可吸收的独立证据通道。

## 7. 本轮最大风险

**一句话**：VERB-RAS 的全部安全论证都押在「撤销图完备且实时」这一前提上——而开放桌面里的不可逆性常常是**事后才被发现**的（邮件已发、款已付、站点改版悄悄新增一条不可回滚边）；一旦 G_u 漏掉一条边，越流畅、越可信的合成语音只会把用户更稳地送进那个被漏掉的黑洞——**说得越像真的，错得越不可逆**。

**次级风险与缓解**：同意疲劳/橡皮图章（注意力预算 α(n) + 检测 + 优先探针）；韵律过度自信（ECE_p 门控 + 不对称损失）；语音冒充/重放/注入（声纹 + 活体 + nonce + L3 双通道 + Δsa）；UI 漂移致撤销图过时（版本化 + 回放回归 + 漂移检出）；TTS 时延（流式首包 + 并行规划 + 最短安全播报降级）。
