# 第 55 轮（承接第 54 轮 v16++ GroundEdge-GenSim+++；灵感循环第 6 轮 / 本轮任务第 2 轮；本轮灵感：「边缘计算」×「步态规划」）

> 第 54 轮把技能组合推进为「动作空间 + 鲁棒性」双证书，并建立了云规划—边校验—反向解释—重剖分的闭环。本轮引入两个此前未被显式建模的变量：**边缘计算**与**步态规划**。核心矛盾：**H22（时间对齐缺失）**——现有云边协同只保证动作空间对齐，没有保证时间对齐；步态由离散接触事件切分，计算一旦错过接触窗口，动作证书再对齐也会因延迟而失效。**H23（相位预算错配）**——步态本身提供了天然的计算预算节拍（双支撑期宽裕、摆动末期临界），但边缘计算调度仍是任务驱动而非相位驱动，最需要计算的触地瞬间反而最拥塞。

## 0. 直觉与动机

**灵感 1（步态是计算的节拍器，不是普通负载）**
直觉：步态规划输出接触时序 `σ`、落脚点序列 `F`、相位 `φ`，它把时间切成支撑相、摆动相、双支撑相。这些相位不是计算的背景噪声，而是**硬实时计算窗口**：双支撑期宽裕，可做长时域落脚与地形规划；摆动末期极窄，只够做一次低延迟平衡修正。把相位窗口当作调度时隙，边端在窗口内完成状态估计、落脚重规划、MPC 热启动——是「身体给计算机打拍子」，而不是让计算机自由抢占身体的节拍。这直接回应 H23：调度的时间轴应由步态相位生成，而非由任务队列生成。

**灵感 2（计算延迟进入重置映射，而不是旁路噪声）**
直觉：步态是混杂系统，触地瞬间的重置映射 `R` 对状态误差极其敏感。计算延迟 `δ` 意味着用陈旧状态或迟到的落脚指令去执行重置，实际映射变为 `R_δ`。因此延迟不是「额外的跟踪误差」，而是**改变收缩因子本身**：`ρ(δ)=L_{R_δ}·e^{-κT}`。据此定义延迟裕度 `δ*`（使 `ρ(δ*)=1-ε_ρ`），把实时可调度性直接翻译为稳定性裕度。这一步把第 53 轮的鲁棒性谱 `ρ` 与第 55 轮的调度可行性统一到同一个不等式里——**截止时间不只是延迟指标，而是收缩预算**。

**灵感 3（云边卸载判据从「延迟预算」升级为「收缩裕度预算」）**
直觉：云端算力强但 RTT 大、抖动大；边端快但资源紧。该不该卸载，不应只看平均延迟，而应看当前相位的 `δ*_m`：双支撑期 `δ*` 宽，可把长时域落脚/地形规划放云端；摆动末期 `δ*` 窄，必须本地闭环。于是卸载策略是**相位条件**的，契约写成 `P(δ_policy ≤ δ*_m) ≥ 1-ε_o`。这把第 54 轮的 `γ_ce` 从纯空间映射扩展为带时间参数的 `γ_ce^τ`。这正是「边缘计算」与「步态规划」的耦合点：**用步态的相位裕度来仲裁云边算力的归属**。

**灵感 4（计算契约与可证明降级）**
直觉：任何调度都可能 miss。关键不是「永不 miss」，而是 miss 后仍可证安全：在 `δ*` 内用正常步态；超过 `δ*` 则切到「计算轻量不变量步态」（缩短步长、降低速度、加宽支撑面），并在下一个接触事件重新对齐相位时钟。降级原语必须落在前向不变集内，且 resync 必须可终止。这样「计算失败」变成证书中的一个显式分支，而不是一次事故。

**灵感 5（第 54 轮证书的时空化）**
直觉：动作剖面 `α_S(a)` 只描述空间占用；加入相位后变为 `α_S(a,τ)`，同一动作在支撑相与摆动相的可执行性不同。技能组合图 `G_S` 的边增加相位窗口交叠与转换截止时间，形成**时空技能组合**。新层 `ℂ`（计算调度层）叠加在 `𝕃`（鲁棒性层）与 `𝔸`（动作协同层）之上，证书从 `(ρ,A_cert)` 变为 `(ρ,A_cert,SCC)`：能力、鲁棒性、时间三者同时可证。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（相位计算窗口与相位时钟）**
步态计划 `g=(σ,F,φ)`，模式 `m` 的相位区间 `W_m=[t_m^-,t_m^+]`。设接触检测延迟 `ε_det`、时钟误差 `ε_clk`、守护裕度 `ε_guard`。有效计算窗口
```
W_m^eff = [t_m^- + ε_det + ε_clk,  t_m^+ - ε_det - ε_clk - ε_guard]
T_m^eff = |W_m^eff|
```
任务 `i` 的释放与截止均以相位为锚：`D_i ≤ t_{π(i)}^+ - ε_guard`。相位时钟 `κ_φ(τ)` 提供 `|κ_φ(τ)-φ(τ)| ≤ ε_det+ε_clk`。

**定义 122（延迟重置映射与计算收缩裕度）**
名义步到步映射 `P=R∘Φ_T`（流 `Φ_T` 后接触重置 `R`）。在计算延迟 `δ∈[0,T]` 下，实际使用延迟状态/指令执行重置：
```
P_δ = R_δ ∘ Φ_T,      ρ(δ) = L_{R_δ} · e^{-κT}
δ*_m = sup{ δ≥0 : ρ(δ) ≤ 1-ε_ρ }
m_c  = 1-ε_ρ-ρ(δ_max)
```
其中 `L_{R_δ}` 为延迟重置的 Lipschitz 常数，并假设 `δ↦L_{R_δ}` 单调不减（越晚越依赖越旧的状态）。若 `δ_max≤δ*_m`，称该步**计算-收缩可行**。`δ*_m` 是相位 `m` 的「收缩裕度预算」，取代纯延迟预算。

**定义 123（相位调度任务图）**
`G_τ=(T,≺,π,w,J)`：任务集 `T`、偏序 `≺`、相位分配 `π:T→M`、硬件在环（HIL）标定 WCET `w_i`、抖动上界 `J_i`。相位 `m` 内的响应时间
```
R_i = w_i + Σ_{j∈hp(i)} ⌈R_i/T_j⌉·w_j + J_i
```
**可调度** iff `∀i, R_i+offset_i ≤ T_{π(i)}^eff` 且利用率 `U_m=Σ_{i:π(i)=m} w_i/T_{π(i)}^eff < 1`。跨相位依赖只允许在接触事件处断开，以保证相位边界可重调度。

**定义 124（相位感知卸载契约）**
`O=(policy,γ_ce^τ,δ*,ε_o)`，其中 `policy:T×M→{local,edge,cloud}`，`γ_ce^τ:A_c×W→A_e`。任务 `i` 在相位 `m` 允许由 `policy(i,m)` 执行，当且仅当
```
Q_{1-ε_o}( δ_{policy(i,m)} ) ≤ δ*_m
```
`Q` 为延迟分布的 `1-ε_o` 分位。云边契约 `C_ce^τ=(g,G_τ,policy,δ*,ε_o,Explain_loop)`；一旦某任务的延迟分位超预算，触发第 54 轮的反向解释回传与动作空间重剖分，并要求在下一个相位边界前完成重分配。

**定义 125（步到步计算证书）**
```
SCC = (π, SchedCert, ρ_comp, δ*, Degrade, evidence)
```
- `SchedCert=(R_i 上界, U_m, J_m)`；
- `ρ_comp = max_i ρ(R_i)`（按最坏响应时间取上界）；
- `δ*=(δ*_m)`；
- `Degrade=(p_safe, I_safe, resync)`：安全原语、前向不变集、重同步映射；
- `evidence` 至少包含 HIL WCET 记录、接触检测日志、miss 反例。
**可部署** iff `G_τ 可调度 ∧ ρ_comp<1-ε_ρ ∧ p_safe 在 I_safe 前向不变 ∧ resync 可终止`。

**定义 126（步态-计算联合迁移证书 GTC）**
跨平台迁移 `P_src→P_tgt`，时序漂移 `Δ_τ=||w_i^{tgt}/w_i^{src}-1||_∞`。相位结构保持要求接触时序 `σ` 的拓扑不变（相继接触事件的顺序与模式图不变）。可行平台集 `Π(g)={P : SCC 可部署}`。GTC 通过 iff `Δ_τ≤Θ_τ ∧ SCC_tgt 可部署 ∧ σ 相位结构保持`；否则重算 `π`/`policy` 或拒绝迁移。

## 2. 关键算法 伪代码

### IP-121 PSW（Phase Slack Window profiler）

```python
def phase_windows(gait_plan, eps_det, eps_clk, eps_guard):
    W = {}
    for m, (t0, t1) in gait_plan.phase_intervals().items():
        lo = t0 + eps_det + eps_clk
        hi = t1 - eps_det - eps_clk - eps_guard
        W[m] = (lo, hi, max(0.0, hi - lo))
    return W

def delay_margin(gait_plan, mode, eps_rho, tol=1e-4):
    lo, hi = 0.0, gait_plan.cycle_time
    while hi - lo > tol:
        mid = 0.5 * (lo + hi)
        if rho_delayed(gait_plan, mode, mid) <= 1.0 - eps_rho:
            lo = mid
        else:
            hi = mid
    return lo          # δ*_m
```

### IP-122 PSD（Phase-Scheduled Dispatcher）

```python
def schedule_tasks(G_tau, W, policy):
    assign = {}
    for m in W:
        tasks = [i for i in G_tau.tasks if G_tau.phase[i] == m]
        for i in order_by_deadline(tasks):
            R = response_time(i, tasks, G_tau.w, G_tau.J)
            if R + G_tau.offset[i] > W[m].length:
                return ('reject', m, i, R)
            assign[i] = (m, R)
    return ('ok', assign)

def dispatch_cycle(assign, contact_event):
    # 接触事件处重排，相位内部不迁移任务，避免调度抖动
    if contact_event:
        return reschedule_at_contact(assign)
    return run_eligible(assign, phase_clock())
```

### IP-123 CAO（Contact-Aware Offloading）

```python
def contact_aware_offload(task, phase, delta_star, net_model, eps_o):
    # 先查是否必要本地闭环，再按相位裕度决定云/边
    for org in ['local', 'edge', 'cloud']:
        q = net_model.delay_quantile(org, task, phase, 1.0 - eps_o)
        if q <= delta_star[phase]:
            return org
    return 'degrade'          # 所有组织都超 δ*，进入降级分支
```

### IP-124 CSC（Computation-Step Certificate）

```python
def computation_step_certificate(gait_plan, G_tau, policy, eps_rho, eps_o):
    W = phase_windows(gait_plan, eps_det, eps_clk, eps_guard)
    delta_star = {m: delay_margin(gait_plan, m, eps_rho) for m in W}
    sch = schedule_tasks(G_tau, W, policy)
    if sch.status == 'reject':
        return ('reject', 'unschedulable', sch)
    rho_comp = max(rho_delayed(gait_plan, m, sch.assign[i][1])
                   for i, m in G_tau.phase.items())
    if rho_comp >= 1.0 - eps_rho:
        return ('reject', 'contraction_margin', rho_comp)
    if not forward_invariant(p_safe, I_safe):
        return ('reject', 'degradation_unsafe')
    return ('ok', SCC(G_tau.phase, sch, rho_comp, delta_star,
                      Degrade(p_safe, I_safe, resync), evidence))
```

### IP-125 CDR（Computation Degradation & Resync）

```python
def on_deadline_miss(mode, state, I_safe):
    if state in I_safe:
        return ('degrade', p_safe, schedule_resync(next_contact(mode)))
    return ('emergency', 'brace_or_stop')

def resync(state, contact):
    # 在接触事件处把状态投影回 I_safe，并重置相位时钟
    state = project_invariant(state, I_safe)
    phase_clock.reset(contact.tau)
    return state
```

### IP-126 GTC（Gait-Timing Transfer Certificate）

```python
def gait_timing_transfer(SCC_src, platform_tgt, theta_tau):
    delta_tau = wcet_drift(SCC_src.G_tau, platform_tgt)
    if delta_tau > theta_tau:
        return ('reject', 'timing_drift', delta_tau)
    SCC_tgt = computation_step_certificate(platform_tgt.gait_plan,
                                           platform_tgt.G_tau,
                                           platform_tgt.policy,
                                           eps_rho, eps_o)
    if SCC_tgt.status != 'ok':
        return ('reject', 'target_infeasible', SCC_tgt)
    if not phase_structure_preserved(SCC_src, SCC_tgt):
        return ('reject', 'phase_structure')
    return ('ok', GTC(SCC_src, SCC_tgt, delta_tau))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| PSW | `O(|M|·log(1/tol))` | `O(|M|)` | 相位边界保守、`δ*` 单调 |
| PSD | `O(|T|²)`（RTA）/ `O(|T|log|T|)`（EDF） | `O(|T|+|M|)` | WCET 上界 sound、跨相位断开 |
| CAO | `O(|T|·|P|)` | `O(|T|)` | 延迟分位校准、`δ*` 预算 |
| CSC | `O(|M|·|T|²+|M|·log(1/tol))` | `O(|T|+|M|)` | 调度 + 收缩 + 降级三重闭合 |
| CDR | `O(log |I_safe|)` | `O(|I_safe|)` | 不变集前向、resync 终止 |
| GTC | `O(|T|²+|M|·log(1/tol))` | `O(|T|+|M|)` | 时序漂移有界、相位结构保持 |

**正确性定理（Computation–Gait Co-Soundness）**
假设第 54 轮 `(A22)–(A28)` 成立；**(A29)** `w_i`、`ε_det`、`ε_clk` 由 HIL 标定并含保守裕度；**(A30)** `δ↦ρ(δ)` 单调不减且 `δ*_m` 以保守方式求解；**(A31)** `p_safe` 在 `I_safe` 上前向不变，`resync` 在下一接触事件前可终止；**(A32)** 各相位内延迟分布平稳，分位估计有效。若 `SCC` 可部署，则单步状态满足
```
||x_{k+1}-x*|| ≤ ρ_comp·||x_k-x*|| + ε_comp
```
且部署成功概率
```
P_success ≥ 1 - Σ_m P(miss_m) - Σ_m P(δ_policy>δ*_m)
              - P(¬I_safe) - β_E
```
其中 `P(miss_m)` 由 `G_τ` 的 RTA 上界约束，`P(δ_policy>δ*_m)` 由卸载分位预算约束，`P(¬I_safe)` 由降级原语不变性约束。与第 54 轮复合时，`SCC` 只把动作集合收缩到「相位可行」子集，因此不削弱 `J=(ρ,A_cert,γ_ce,δ_a)` 的 soundness，只会使可行域更保守；若 `α_S(a,τ)` 在有效窗口内对齐，则联合证书 `(J,SCC)` sound。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 接触检测延迟导致相位窗口失真 | 高 | 双阈值接触检测 + 守卫裕度 + 事件触发重调度 |
| 仿真 WCET 在真实边缘硬件上失效 | 高 | HIL 标定 + 硬件性能计数器 + 安全系数 + 运行时监测 |
| 延迟-收缩模型 `L_{R_δ}` 保守性不足 | 高 | 多地形/多速度标定 + 分布鲁棒分位 + 保守 `δ*` |
| 卸载策略在相位边界震荡 | 中 | 仅在接触事件处切换 + hysteresis + 冷却期 |
| 降级原语在极端地形不满足不变集 | 高 | 限定认证地形子集 + 失败即急停/支撑 + 红队测试 |
| 云边时钟不同步导致截止期漂移 | 中 | 单调本地时钟 + 相位相对截止期 + 时钟漂移上界 |

## 6. 本轮最大风险

**一句话**：把边缘计算调度嵌入步态相位、并用延迟重置映射的收缩裕度 `δ*` 作为卸载与调度判据，能把「算得完」与「走得稳」统一到同一证书下，但其 soundness **完全依赖相位窗口、WCET 与接触检测延迟的保守标定**；一旦接触检测滞后或真实边缘硬件 WCET 被低估，`SCC` 会给出虚假可调度结论，计算诱导的落脚误差将直接进入触地重置并可能击穿步态稳定性，故必须以 **HIL 标定 + 守卫裕度 + 降级不变集三重护栏** 为前提，宁可在相位边界保守降级，也不把「平均延迟达标」误当作「收缩裕度达标」。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（PSW×PSD×CAO×CSC×CDR×GTC）

> 承接第 54 轮产物 v31（ACS/SCOM/CEC/AEC/JTC，动作空间 + 鲁棒性双证书）。本轮在 v31 之上增加 **计算调度层 ℂ**，把「边缘计算」与「步态规划」耦合为同一套可证实时契约：
> - **PSW（Phase Slack Window）**：把步态相位剖面化为硬实时计算窗口，计算相位收缩裕度 `δ*_m`；
> - **PSD（Phase-Scheduled Dispatcher）**：以接触事件为节拍的相位调度与响应时间分析；
> - **CAO（Contact-Aware Offloading）**：卸载判据从延迟预算升级为收缩裕度预算；
> - **CSC（Computation-Step Certificate）**：步到步计算证书，统一可调度性、收缩性与降级安全性；
> - **CDR（Computation Degradation & Resync）**：miss 后的不变量降级与接触事件重同步；
> - **GTC（Gait-Timing Transfer Certificate）**：跨边缘平台的步态-计算联合迁移证书。
>
> IP 编号：IP-121~IP-126（共 6 个新增）；升级 IP-115（动作剖面时空化）、IP-117（云边协同加入时间契约）、IP-118（联合证书加入 SCC）、IP-120（迁移证书加入时序漂移）。

## 2. 关键算法 伪代码

### IP-121 PSW

```python
def phase_windows(gait_plan, eps_det, eps_clk, eps_guard):
    W = {}
    for m, (t0, t1) in gait_plan.phase_intervals().items():
        lo = t0 + eps_det + eps_clk
        hi = t1 - eps_det - eps_clk - eps_guard
        W[m] = (lo, hi, max(0.0, hi - lo))
    return W

def contraction_margin(gait_plan, mode, eps_rho, tol=1e-4):
    lo, hi = 0.0, gait_plan.cycle_time
    while hi - lo > tol:
        mid = 0.5 * (lo + hi)
        if rho_delayed(gait_plan, mode, mid) <= 1.0 - eps_rho:
            lo = mid
        else:
            hi = mid
    return lo      # δ*_m，单调二分，返回保守下界
```

### IP-122 PSD

```python
def build_phase_task_graph(tasks, gait_plan):
    G = nx.DiGraph()
    for t in tasks:
        m = phase_of(t.trigger, gait_plan)       # 由接触事件/相位触发
        G.add_node(t.id, phase=m, w=t.wcet_hil, jitter=t.jitter)
    for a, b in precedence_edges(tasks):
        if G.nodes[a]['phase'] != G.nodes[b]['phase']:
            require_contact_barrier(G, a, b)   # 跨相位只在接触处断开
        G.add_edge(a, b)
    return G

def schedule_tasks(G_tau, W):
    assign = {}
    for m in W:
        tasks = [i for i in G_tau if G_tau.nodes[i]['phase'] == m]
        for i in order_by_deadline(tasks):
            R = response_time(i, tasks, G_tau)
            if R + G_tau.nodes[i].get('offset', 0) > W[m][2]:
                return ('reject', m, i, R)
            assign[i] = (m, R)
    return ('ok', assign)
```

### IP-123 CAO

```python
def contact_aware_offload(task, phase, delta_star, net_model, eps_o):
    for org in ['local', 'edge', 'cloud']:
        q = net_model.delay_quantile(org, task, phase, 1.0 - eps_o)
        if q <= delta_star[phase]:
            return org
    return 'degrade'

def phase_offload_policy(G_tau, delta_star, net_model, eps_o):
    policy = {}
    for i in G_tau:
        policy[i] = contact_aware_offload(i, G_tau.nodes[i]['phase'],
                                          delta_star, net_model, eps_o)
    return policy
```

### IP-124 CSC

```python
def computation_step_certificate(gait_plan, G_tau, net_model,
                                 eps_rho=1e-2, eps_o=1e-3):
    W = phase_windows(gait_plan, eps_det, eps_clk, eps_guard)
    delta_star = {m: contraction_margin(gait_plan, m, eps_rho) for m in W}
    policy = phase_offload_policy(G_tau, delta_star, net_model, eps_o)
    if 'degrade' in policy.values():
        return ('reject', 'no_feasible_org', policy)
    sch = schedule_tasks(G_tau, W)
    if sch.status == 'reject':
        return ('reject', 'unschedulable', sch)
    rho_comp = max(rho_delayed(gait_plan, m, sch.assign[i][1])
                   for i, m in G_tau.nodes(data='phase'))
    if rho_comp >= 1.0 - eps_rho:
        return ('reject', 'contraction_margin', rho_comp)
    if not forward_invariant(p_safe, I_safe):
        return ('reject', 'degradation_unsafe')
    return ('ok', SCC(G_tau, sch, rho_comp, delta_star, policy,
                      Degrade(p_safe, I_safe, resync), evidence))
```

### IP-125 CDR

```python
def on_deadline_miss(mode, state, I_safe):
    if state in I_safe:
        return ('degrade', p_safe, schedule_resync(next_contact(mode)))
    return ('emergency', 'brace_or_stop')

def resync(state, contact):
    state = project_invariant(state, I_safe)
    phase_clock.reset(contact.tau)
    return state

def run_cycle(scc, state):
    plan = dispatch_cycle(scc.schedule, phase_clock())
    try:
        return execute(plan, state)
    except DeadlineMiss as e:
        return on_deadline_miss(e.mode, state, scc.degrade.I_safe)
```

### IP-126 GTC

```python
def gait_timing_transfer(SCC_src, platform_tgt, theta_tau):
    delta_tau = wcet_drift(SCC_src.G_tau, platform_tgt)
    if delta_tau > theta_tau:
        return ('reject', 'timing_drift', delta_tau)
    SCC_tgt = computation_step_certificate(platform_tgt.gait_plan,
                                           platform_tgt.G_tau,
                                           platform_tgt.net_model)
    if SCC_tgt.status != 'ok':
        # 先尝试重分配 π/policy，而非直接拒绝
        SCC_tgt = repair_schedule(SCC_tgt, platform_tgt)
        if SCC_tgt.status != 'ok':
            return ('reject', 'target_infeasible', SCC_tgt)
    if not phase_structure_preserved(SCC_src, SCC_tgt):
        return ('reject', 'phase_structure')
    return ('ok', GTC(SCC_src, SCC_tgt, delta_tau,
                      feasible_platforms(SCC_tgt)))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| PSW | `O(|M|·log(1/tol))` | `O(|M|)` | 相位边界保守，`δ*` 单调可解 |
| PSD | `O(|T|²)` RTA / `O(|T|log|T|)` EDF | `O(|T|+|M|)` | WCET 上界 sound，跨相位断开 |
| CAO | `O(|T|·|P|)` | `O(|T|)` | 分位预算 `ε_o`，`δ*` 约束 |
| CSC | `O(|M|·|T|²+|M|log(1/tol))` | `O(|T|+|M|)` | 调度 + 收缩 + 降级三重闭合 |
| CDR | `O(log|I_safe|)` | `O(|I_safe|)` | 不变集前向，resync 终止 |
| GTC | `O(|T|²+|M|log(1/tol))` | `O(|T|+|M|)` | 时序漂移有界，相位结构保持 |

**正确性定理（Computation–Gait Co-Soundness）**
假设第 54 轮 `(A22)–(A28)` 成立；**(A29)** `w_i,ε_det,ε_clk` 由 HIL 标定并含保守裕度；**(A30)** `δ↦ρ(δ)` 单调不减，`δ*_m` 为保守下界；**(A31)** `p_safe` 在 `I_safe` 上前向不变，`resync` 在下一接触事件前终止；**(A32)** 各相位延迟分布平稳且分位估计有效。若 `SCC` 可部署，则单步误差满足
```
||x_{k+1}-x*|| ≤ ρ_comp·||x_k-x*|| + ε_comp
```
部署成功概率满足
```
P_success ≥ 1 - Σ_m P(miss_m) - Σ_m P(δ_policy>δ*_m)
              - P(¬I_safe) - β_E
```
其中 `P(miss_m)` 由 PSD 的 RTA 上界约束，`P(δ_policy>δ*_m)` 由 CAO 的分位预算约束，`P(¬I_safe)` 由 CDR 的不变集约束。与 v31 复合时，`SCC` 只把动作集合收缩为「相位可行子集」，因此不削弱 `J=(ρ,A_cert,γ_ce,δ_a)` 的 soundness，只会让可行域更保守；当 `α_S(a,τ)` 在有效窗口内对齐时，`(J,SCC)` 联合 sound。

JCPS 输出扩展为：

其中本轮新增：
- `π` 相位任务分配；
- `SCC` 步到步计算证书；
- `δ*` 相位收缩裕度预算；
- `ρ_comp` 计算诱导的步到步收缩上界；
- `policy` 相位条件云边卸载策略。

与第 54 轮的关系：v54 的 `γ_ce` 是空间映射，本轮升级为 `γ_ce^τ`（空间 × 时间）；v54 的 `δ_a` 是动作对齐误差，本轮新增 `δ*`（时间-收缩裕度）；两者共同构成「空间对齐 + 时间对齐」的双重部署前提。

## 5. 本轮最大风险

**一句话**：把边缘计算调度嵌入步态相位、以延迟重置映射的收缩裕度 `δ*` 作为调度与卸载判据，首次将「算得完」与「走得稳」统一到同一证书，但其 soundness **完全依赖相位窗口、WCET 与接触检测延迟的保守标定**；一旦接触检测滞后或真实边缘硬件 WCET 被低估，`SCC` 会给出虚假可调度结论，计算诱导的落脚误差将直接进入触地重置并可能击穿步态稳定性，故必须以 **HIL 标定 + 守卫裕度 + 降级不变集三重护栏** 为前提，宁可在相位边界保守降级，也不把「平均延迟达标」误当作「收缩裕度达标」。
