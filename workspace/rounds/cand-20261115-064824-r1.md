# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「多传感器融合」×「大语言模型」）

> R69 问「我该向谁求证、还能问什么」，并给出一条看似坚固的证据纪律：**k 个正交证据源一致才定案**。但它把两件事当成了默认事实：**(a) 来源是正交的**——只要来自不同传感器/不同通道就算独立；**(b) 语言通道只是输出**——LLM 只把 `g_ask` 解码成问句，不参与判断。
>
> 这两个默认恰恰是最脆弱的：
> - **多传感器融合**的整个学科都在处理「传感器并不独立」：雾天同时骗过相机与激光、共用的标定漂移让所有通道一起偏、同一个攻击者可以同时污染多个通道。此时「k 个源一致」不是 k 份证据，而是**同一个原因被复读了 k 次**——伪 consilience（false consilience）。R69 的引理 18 用 ρ<1 把这个问题轻轻带过，却没有给出**如何测量 ρ、以及当 ρ→1 时怎么办**。
> - **大语言模型**让系统第一次能「把多种传感器证据讲成一个自洽的故事」、能解析人类回答、能建议融合拓扑；但它同时是**幻觉、谄媚、提示注入**的载体，而且它的流畅性会**伪造独立性**——一段措辞严谨的解释会让审计者和人类都以为「多源已验证」。R69 的「问错比不问更危险」在 LLM 参与后升级为「**讲得太好，比问错更危险**」。
>
> 核心命题：**把「证据是否独立」从默认假设变成一个被测量、被审计、可被伪造也可被证伪的量；把 LLM 从「会说话的答案源」降级为「查询编译器 / 融合调度提议者 / 语义解析器」，它永远不能自己给自己作证。一致性只有在去共因后才计入证据（consilience），否则按单源处理；当有效独立性塌缩、接地失败或见证被同源污染时，单调退化为 R69 的保守档。** 命名 **CONSILIENCE-RAS**（Consilience-aware Risk-Adaptive System）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**这几个证人是不是同一个人假扮的，翻译有没有替他们改口供**」——一致性不是证据的数量，而是独立因果路径的数量。

## 0. 直觉与动机

**灵感 1（多传感器融合 → 独立性是资源，不是标签）**
直觉：R69 的 ℰ={r_geo, r_sync, …} 按「不同物理通道」贴了正交标签。但正交性不是命名属性，而是**因果属性**：两个通道只有在「不共享未观测的共同原因」时才独立。多传感器融合的真正难点不是怎么加权平均，而是**共因**：同一场雾、同一次标定、同一个遮挡、同一个攻击者。共因下，融合的方差不会按 1/k 下降，而是饱和在一个由共因方差决定的地板上。于是 R69 的「k 源一致」在共因存在时会**系统性高估证据**。

**灵感 2（共因 → 一致性的地板，k 再大也没用）**
直觉：把每个源的错误写成「共因错误 ⊕ 私有噪声」：`E_i = C ⊕ N_i`。只要 `P(C=1)=δ_c>0`，无论 k 多大，全体一致出错的概率都 `≥ δ_c`。这就是「伪 consilience」的数学形状：**一致性能压掉私有噪声，压不掉共因**。所以增加同质传感器的边际价值很快归零；真正能突破地板的是**换因果路径**（换视角、换时间、换物理量、换见证方式），而不是「再加一个同类传感器」。

**灵感 3（LLM → 会讲故事的新证人，也是最危险的证人）**
直觉：LLM 能把「相机说 A、雷达说 B、人回答 C」编织成一个连贯解释，这对融合调度、问句生成、人类回答解析极有价值。但 LLM 的输出是**语言上自洽、因果上未必接地**的：它可以为一个错误模态编出合理叙事（幻觉），可以顺着提问者的倾向改口（谄媚），可以被一段提示注入变成「内应」。最危险的是，它的流畅性会让「单源」看起来像「多源」——**它伪造的不是证据，而是证据的独立性**。因此本轮的核心纪律是：LLM 可以是**翻译**和**调度员**，不能是**证人**；它说的每个事实性断言都必须挂一个非语言的、可物理核验的**见证**。

**灵感 4（见证 → 用不变量而不是一致性来打共因）**
直觉：共因能骗过「彼此一致」，但很难同时骗过**物理不变量**：刚体距离、运动学可行性、时间同步、能量/动量守恒、重力方向、接触相容。雾可以让相机和激光一起把远处看成近的，但很难让「双目三角化 + IMU 预积分 + 轮速」在同一个刚体约束下仍然自洽而不露馅。关键区别：一致性检验的是「源与源像不像」，不变量检验的是「源与世界符不符合」。后者提供了一条**不由被检验源本身生成**的因果轴，是突破 `δ_c` 地板的唯一途径。

**灵感 5（同源见证 → 接地契约必须可被伪造性检验）**
直觉：接地不是「给 LLM 的断言配一个见证」这么简单——如果见证也是 LLM 生成的（让它自己检查自己）、或见证来自与被检验通道共享共因的传感器，那么「接地」是空的。所以契约必须包含**见证的溯源**：见证的因果路径必须与被检验断言**不相交**（non-ancestral），并且见证的失效模式不能由同一个共因触发。这是「LLM 不能给自己作证」的形式化。

**灵感 6（严格包含 → 独立性完好时逐指令退回 R69）**
直觉：如果实测 `k_eff = k_nominal`、没有 LLM 事实断言、也没有不变量告警，那么 CONSILIENCE 的所有新机制都退化为恒等：去共因不变、见证不触发、调度候选集与 R69 相同。此时它必须逐指令等于 R69。当独立性塌缩或接地失败，它只能更保守（不授予 resolution bonus），绝不能更激进。新层是旧层的**严格泛化**，安全侧零让步。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（CONSILIENCE-RAS 总览与四不变式）** CONSILIENCE-RAS = (ESG, CMD, CSG, GLC, SFS, IVW, TCG, VQAuditor-F, AIC-CORR, RAS-WM†)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **溯源不可省略**：每条证据带溯源 `P_i` 与实测有效独立性权重；名义来源标签不构成证据；
(iii) **接地契约**：LLM 输出永不进入证据集 ℰ，只作为查询编译器/融合调度提议/语义解析；任何事实性断言必须附非语言、非祖先的可核验见证，否则进入隔离区 Q；
(iv) **单调退化**：当 `k_eff < k_min`、接地失败或见证被同源污染时，行为逐指令退化为 R69 或更保守，安全侧永不弱于 R69。

**定义 311（证据来源与溯源图）** 证据 `r_i ∈ ℰ` 携带溯源 `P_i = (sensor_i, calib_lineage_i, model_ver_i, t_i, common_cause_tags_i, ancestry_i)`。定义祖先关系 `anc(i,j)`：若 `r_i` 的生成路径包含 `r_j` 或其同源副本，则 j 是 i 的祖先。**非祖先（non-ancestral）**是「可计入独立证据」的必要条件。

**定义 312（共因因子模型与有效独立性）** 把标准化证据残差写成 `r_i = a_iᵀc + ε_i`，c 为潜在共因（环境/标定/攻击者），`ε_i` 为私有噪声。令 R 为证据相关矩阵、`λ_i` 其特征值，定义**有效独立源数**
`k_eff = (Σ_i λ_i)² / (Σ_i λ_i²) ∈ [1, k]`，
以及 **consilience gap** `Γ = k_nominal − k_eff`。`R=I` 时 `k_eff=k`；秩一（全体共因）时 `k_eff=1`。

**定义 313（consilience vs redundancy）** 给定名义一致性 A（多数票/后验重合度），定义**去共因一致性**
`C = A | (c 被边缘化或条件化)`，即对共因做偏相关/去混淆后的一致性。
只有 C 计入证据；`A−C` 是冗余（redundancy），不得提高置信。

**定义 314（LLM 角色分离与接地契约）** LLM 输出按类型分派：`g_ask`（问句）、`τ_fuse`（融合拓扑/传感器子集/视角提议）、`parse(y)`（人类回答的语义解析）、`explain`（解释，无决策权）。前三者是**动作/提议**，须过 C-RAS-WM 与 VoI；任何事实性断言 φ 须附见证 `W_φ`。LLM 不作为 ℰ 的独立源，且不得作为自己断言的见证。

**定义 315（接地见证与隔离区）** 见证是谓词 `W_φ: 观测 → {0,1,⊥}`，由与被检验通道**非祖先**的物理量计算。φ 接地 ⇔ `W_φ=1` 且见证溯源与被检验断言溯源不相交。未接地/不可判定的断言进入隔离区 Q；Q 中的断言不参与 `update_belief`，只能作为下一轮查询提议的线索。

**定义 316（融合调度器 SFS）** 候选动作扩展为 `g ∈ 𝒜_info ∪ 𝒜_fuse`，其中 `𝒜_fuse` 包含「换视角、改曝光/增益、切换模态、加/减传感器、改变融合层级（数据/特征/决策）」。SFS 选择 `(g, topology)` 最大化单位成本的有效信息增益，同时受安全与相关预算约束。

**定义 317（有效独立性加权 VoI）** `VoI_eff(g) = H(M|o) − E_{y~p_eff(·|g,o)}[H(M|o,y)]`，其中 `p_eff` 用去共因后的似然（对相关证据按 `1/k_eff` 降权）计算；相关证据不得按独立重复计数。

**定义 318（共因投毒与伪 consilience 威胁）** ℰ_corr 包含：(a) 环境共因（雾/眩光/振动/多路径）；(b) 标定共因（共享漂移）；(c) 攻击共因（同时污染多通道、重放、共谋）；(d) 语言共因（用同一提示/同一先验诱导 LLM 与人类给出同向答案）。目标是让 A 高而 C 低——制造「看起来多源一致」的假象。

**定义 319（反事实查询编译 CIP）** 对查询提议 `g_ask`，分别在「带假设先验」与「去先验」两种条件下让 LLM 生成查询/解析，比较其诱导差 `Δ_ind = D(p(y|g,prior) ‖ p(y|g,¬prior))`。若某答案只在带先验时出现，标记 `question-induced`，禁止据此行动；查询本身若只能制造它要问的答案，则拒绝。

**定义 320（不变量见证 IVW）** 给定物理不变量 I（刚体距离、运动学、时间同步、重力、接触相容等），故障子空间 𝔅 上的共因偏移 b 若满足 `∇I·b ≠ 0`，则 I 可检测该共因。定义见证覆盖度 `cov(I) = rank(∇I|_𝔅)/dim(𝔅)`。只有 `cov(I)` 足够高的不变量才可作为突破共因地板的见证；`cov=0` 的不变量（如整体刚体变换）对共因无效。

**定义 321（时间 consilience 与独立获取事件）** 把「一次获取事件」定义为不同时间/视角/激励下的一次独立采样。定义跨事件相关 `ρ_out` 与事件内通道相关 `ρ_in`。`k_eff` 在全相关矩阵上计算；当 `ρ_in` 高时，增加一次独立获取事件的边际信息严格大于增加一个同帧通道。

**定义 322（证书 J_CONS）** `J_CONS = (J_FLUID, k_eff, Γ, consilience_C, grounding_rate, witness_provenance_hash, injection_score, corr_auc, cons_ver)`。Valid ⇔ `Valid(J_FLUID)` ∧ `k_eff ≥ k_min` ∧ 所有被采纳断言均接地 ∧ 无 `question-induced` 断言被采纳 ∧ 相关预算未越界。

**定义 323（带相关惩罚的两级退避）** 若 `k_eff ≥ k_min` 且接地率达标：沿用 R69 的 resolution bonus；若 `k_eff < k_min` 或 Γ 过大：把一致性按单源处理（撤销 bonus），并加相关惩罚 `λ_corr = f(Γ)`；若接地失败/注入越界：LLM 退出决策环（仍可做无决策权的解码），走 R69 纯保守。三者均保证 λ 单调不降。

**定义 324（独立性审计 VQAuditor-F）** 审计对象：溯源是否完整、`k_eff` 估计是否被同源污染、见证是否与被检验断言非祖先、LLM 提议是否诱导、共因是否被误当独立。结论回灌 AuditBuf，成为下一轮相关预算与见证选择的先验。

**定义 325（相关预算与自适应调度）** 单位时间用于「增加证据」的预算分为「同质通道」与「独立获取事件」两类；相关预算 `cap_corr` 限制同质冗余的边际投入。默认 1 事件、1 通道；仅当 `k_eff` 低于阈值且存在高 `cov` 不变量时，才增加独立获取事件。

## 2. 关键算法骨架

```python
# IP-264/265 ESG + CMD：溯源图与有效独立性
class EvidenceGraph:
    def __init__(self, sources): self.sources = sources
    def provenance(self, r):
        return (r.sensor, r.calib, r.model_ver, r.t, r.tags, r.ancestry)
    def non_ancestral(self, i, j):                 # 见证不得是断言的祖先
        return not is_ancestor(self.sources[j], self.sources[i])
    def k_eff(self, R):                            # 相关矩阵特征值参与率
        lam = eigvalsh(R)
        return (lam.sum() ** 2) / (lam ** 2).sum() # R=I -> k ; rank-1 -> 1

# IP-266 CSG：去共因一致性（只有 C 计入证据）
def consilience(evidence, common_cause_est):
    A = agreement(evidence)                        # 名义一致
    C = agreement(deconfound(evidence, common_cause_est))
    return C, A - C                                # (consilience, redundancy)

# IP-267/315 GLC：LLM 断言的接地契约
def grounded(claim, sensors):
    if claim.kind != 'fact': return True           # 查询/提议不是事实断言
    W = witness_for(claim, sensors)                # 非语言、非祖先
    if W is None or W.value is None: return False
    return W.value and not is_ancestor(claim.channel, W.provenance)

# IP-268/317 SFS：融合调度（有效 VoI，相关证据按 1/k 降权）
def choose_action(modes, o, budget, R):
    k = evidence_graph.k_eff(R)
    best = None
    for g in info_actions(modes) + fusion_actions(o):   # 看/问/触 + 换视角/换模态/换层级
        if not budget.allow(g) or not c_ras_wm.certify(g, o): continue
        if g.kind == 'redundant' and not budget.corr.allow(g): continue
        score = voi_eff(modes, g, o, k) - cost(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None    # 无利可图 -> R69

# IP-270 IVW：不变量见证（突破共因地板的因果轴）
def invariant_witness(o, fault_basis):
    for I in PHYSICAL_INVARIANTS:                  # 刚体/运动学/时同步/接触
        if coverage(I, fault_basis) >= TAU_COV and abs(I(o)) > TAU_INV:
            return I, residual(I, o)               # 违反 -> 共因疑
    return None

# IP-272 CIP：反事实查询编译（防自证预言）
def compile_query(llm, hypothesis, o):
    q_with    = llm.propose(hypothesis, o)
    q_without = llm.propose(None, o)
    d_ind = divergence(llm.parse_dist(q_with, o), llm.parse_dist(q_without, o))
    return None if d_ind > TAU_IND else q_without   # 只能造出答案的查询被拒绝

# IP-275 主闭环（继承 R69，在证据处置处插入 CONSILIENCE 层）
def CONSILIENCE_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    # 1) 实测独立性：去共因后才算一致性
    R = M.esg.correlation(o); k = M.esg.k_eff(R)
    C, redundancy = M.csg.consilience(M.evidence(o), M.esg.common_cause(o))
    # 2) 不变量见证：找一条不被共因污染的因果轴
    inv = M.ivw.invariant_witness(o, M.fault_basis)
    # 3) LLM 只提议、不作证；事实断言须接地
    g = M.sfs.choose_action(modes, o, M.budget, R) if U_epi > TAU_EPI else None
    if g is not None and g.kind == 'ask':
        g = M.cip.compile_query(M.fmp.llm, modes[0], o)
    answer = M.cia.execute(g) if g is not None else None
    if answer is not None and not M.glc.grounded(answer.claim, M.sensors):
        answer = None; U_epi_after = U_epi            # 未接地 -> 隔离，不更新
    else:
        U_epi_after = M.cia.update_belief(modes, answer, weight=k)  # 按 k_eff 加权
    # 4) 退避：独立性塌缩/见证失败/注入 -> 只更保守
    degraded = (k < K_MIN) or (redundancy > TAU_RED) or (inv is not None)
    U_floor = U_ale + (0.0 if (answer is not None and not degraded) else U_epi_after)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    if degraded:
        lam = max(lam, lam_floor(U_ale + U_epi) + lambda_corr(redundancy))
    k_pre = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    mode = select_mode(modes, U_epi_after, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k_pre]) * lam
    M.vqa_f.submit_async(R, k, C, redundancy, inv, g, answer)
    return k_pre, lam, mode, (U_ale, U_epi_after), (k, C)
```

## 3. 推导

**引理 19（共因地板）** 错误模型 `E_i = C ⊕ N_i`，`P(C=1)=δ_c`，`N_i ~ iid Bern(ε)`。则 k 源全体一致的错误率
`P(∩_i E_i) = δ_c + (1−δ_c)ε^k ≥ δ_c`。
系：R69 引理 18 的 `δ_p ρ^{k−1}` 是「相关但无确定性共因」的特例；一旦 `δ_c>0`，增加 k 无法把错误压到 `δ_c` 以下，必须换因果路径。

**引理 20（接地的乘性约束）** 若见证 W 与被检验断言 φ 的通道**非祖先且独立**，则采纳错误 φ 的概率 `≤ δ_φ·β_W`（`β_W` 为见证假通过率），而非 `δ_φ`；若 W 由同一 LLM/同一共因生成（祖先），则该式退化为 `δ_φ`，接地为空。系：**LLM 不能给自己作证**。

**引理 21（不变量见证的共因可检测性）** 对故障子空间 𝔅 上的共因偏移 b，若 `cov(I)=1`，则任意非零 b 都使
`|I(o+b)−I(o)| ≥ σ_min(∇I|_𝔅)‖b‖ − ν`（ν 为噪声），故可检测；若 `cov=0`（如整体刚体变换），不变量对该共因完全不可见。系：见证选择等价于选一个在 𝔅 上满秩的物理约束。

**引理 22（时间独立性的边际收益）** 设事件内通道相关 `ρ_in`、跨事件相关 `ρ_out`。全相关矩阵的 `k_eff` 对「增加同帧通道」的边际增益 `≈ 1/(1+(m−1)ρ_in)`，对「增加独立事件」的边际增益 `≈ 1/(1+(n−1)ρ_out)`。当 `ρ_in > ρ_out` 时，独立获取事件的边际信息严格更大。系：相关预算应优先买「新事件」而不是「新通道」。

**定理 18（CONSILIENCE 严格包含 R69）** 在 A99–A101 下：若 `R=I`（`k_eff=k`）、无 LLM 事实断言、无见证告警，则所有新机制为恒等，CONSILIENCE **逐指令等于 R69**；若 `k_eff<k_min` 或接地失败，则撤销 resolution bonus 并加 `λ_corr`，λ 不低于 R69。故安全侧单调不弱，效率收益只在「可验证的独立证据」上发放。

**定理 19（伪 consilience 的必要与充分）** 在共因模型下，任何「只做一致性、不做去共因/不变量见证」的决策，其错误率下界为 `δ_c`；而「去共因一致性 + 满覆盖不变量见证」可在 `cov=1` 时把错误率压到 `≤ δ_c·β_W`（引理 19–21）。故 R70 的两件套既是必要的（否则有地板），也是模型内充分的。

**定理 20（反事实查询的无自证性）** 在 CIP 下，若查询 g 的诱导差 `Δ_ind > τ` 则拒绝该查询；被采纳的答案必须在去先验条件下仍出现。于是「问题制造它要找的答案」的采纳概率 `≤ 注入成功率 × (1 − 见证功效)`，且 LLM 的谄媚被结构性阻断而非靠提示词。

## 6. 本轮最大风险

**一句话**：CONSILIENCE-RAS 的全部安全性押在「`k_eff` 与见证能独立于证据被测量」这一前提上——**若共因不可观测、且独立性估计器/见证生成器本身也由同一套模型或同一批数据训练（甚至由 LLM 生成见证），那么系统只是把「相信 k 个来源」换成了「相信一个独立性估计器」，伪 consilience 会从证据层原样上升到审计层：你无法用一把可能被共因校准过的尺子去证明另一把尺子没被共因校准。**

**次级风险与缓解**：
1. **见证与断言共享祖先**（LLM 自证）→ 定义 315 的非祖先强制 + 引理 20 + E303；
2. **`k_eff` 估计被攻击者操纵**（制造低相关假象）→ 定义 318 攻击共因 + 审计交叉 + E302/E312；
3. **不变量选择失配**（`cov=0` 仍被当作见证）→ 定义 320 覆盖度门 + 引理 21 + E305；
4. **LLM 流畅性误导人类审计者**→ 解释无决策权 + 接地率与注入分进入证书 + E304；
5. **相关预算被性能压力击穿**（为省时间买同质通道）→ 定义 325 硬预算 + 引理 22 + E313。

## 4. 推导

**引理 19（共因地板）** `E_i=C⊕N_i`，`P(C=1)=δ_c`，`N_i~iid Bern(ε)` ⇒ `P(∩E_i)=δ_c+(1−δ_c)ε^k ≥ δ_c`。系：R69 引理 18 的 `δ_p ρ^{k−1}` 是「相关但无确定性共因」特例；`δ_c>0` 时加 k 无用，必须换因果路径。

**引理 20（接地的乘性约束）** 见证与断言非祖先且独立时，采纳错误率 `≤ δ_φ·β_W`；见证为祖先（同一 LLM/同一共因）时退化为 `δ_φ`，接地为空。系：LLM 不能给自己作证。

**引理 21（不变量见证的可检测性）** `cov(I)=1` 时 `|I(o+b)−I(o)| ≥ σ_min(∇I|_𝔅)‖b‖−ν`；`cov=0` 时对该共因不可见。系：选见证 = 选在 𝔅 上满秩的物理约束。

**引理 22（时间独立性的边际收益）** 加同帧通道边际增益 `≈1/(1+(m−1)ρ_in)`；加独立事件 `≈1/(1+(n−1)ρ_out)`；`ρ_in>ρ_out` 时优先买新事件。

**定理 18（CONSILIENCE 严格包含 R69）** `R=I`、无 LLM 事实断言、无见证告警 ⇒ 逐指令等于 R69；`k_eff<k_min` 或接地失败 ⇒ 撤销 bonus 并加 `λ_corr`，λ 不低于 R69。安全单调不弱，效率收益只发给可验证的独立证据。

**定理 19（伪 consilience 的必要与充分）** 只做一致性不做去共因/见证 ⇒ 错误率下界 `δ_c`；去共因一致性 + `cov=1` 不变量见证 ⇒ 错误率 `≤ δ_c·β_W`。两件套在模型内既必要又充分。

**定理 20（反事实查询的无自证性）** CIP 拒绝 `Δ_ind>τ` 的查询；被采纳答案须在去先验下仍出现 ⇒ 自证预言采纳概率 `≤ 注入成功率 × (1−见证功效)`，谄媚被结构性阻断。

## 7. 本轮最大风险

**一句话**：CONSILIENCE-RAS 的全部安全性押在「`k_eff` 与见证能独立于证据被测量」这一前提上——**若共因不可观测、且独立性估计器/见证生成器本身也由同一套模型或同一批数据训练（甚至由 LLM 生成见证），那么系统只是把「相信 k 个来源」换成了「相信一个独立性估计器」，伪 consilience 会从证据层原样上升到审计层：你无法用一把可能被共因校准过的尺子，去证明另一把尺子没被共因校准。**

**次级风险与缓解**：见证与断言共享祖先（定义 315 非祖先强制 + 引理 20 + E303）；`k_eff` 被攻击者操纵（定义 318 + 审计交叉 + E302/E312）；不变量 `cov=0` 误当见证（定义 320 + 引理 21 + E305）；LLM 流畅性误导人类审计者（解释无决策权 + 接地率/注入分入证书 + E304）；相关预算被性能压力击穿（定义 325 硬预算 + 引理 22 + E313）。
