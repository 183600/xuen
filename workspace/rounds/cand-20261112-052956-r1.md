# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 4 轮；本轮灵感：「步骤分」×「长程任务」）

> 第 57 轮把安全的赌注从"单点置信"换成"证据承诺"，又用元少样本、跨模态对账、个性化信任把证据本身做厚；但它所有的承诺判定仍然发生在**单个检查点**，并对整条路线隐含了两个未言明的假设：**(a) 检查点可加性**——用对的检查点取 union bound 就能控制整条长程任务，N 个点就每点 δ/N；**(b) 终点二值性**——任务只有"成功"与"失败"，没有"安全地完成了 8/10 并停下"这一档。本轮两个灵感各拆一个假设：**步骤分**（过程奖励/信用分配）把终点二值目标换成每步稠密、且必须对最终结果校准的步骤证据信用，使安全部分完成、断点续行与风险瓶颈定位成为可能；**长程任务**（序贯决策）把 union bound 换成**任意时有效（anytime-valid）的风险预算**——e-process 允许边走边看边停而无需为每个检查点预扣 δ，同时被迫正视"长程证据相关"这一真问题。本轮的核心新命题是 **"每一步都可计分、每一步都可追责、整条路线随时可安全停下"**，其代价是必须回答：步骤分会不会制造进度幻觉？e-process 的鞅性在相关证据下还成立吗？部分完成的价值由谁担保？

核心矛盾：
- **H29（步骤分 vs 进度幻觉）**：稠密步骤分降低全局风险估计的方差、支持早期止损，但步骤分若由同一个可能出错的世界模型自评，就会把"自认为完成"记账为"已完成"；后验证伪必须能回溯借记，否则部分完成是纸面财富。
- **H30（长程 vs 任意时有效）**：N 步 union bound 线性收紧，N 大时每步阈值趋近于零、系统只能永远探询；而真正的最优做法——边走边看边停——只有在 e-process/置信序列下才合法。但 e-process 要求每步 e-value 在给定历史下条件有效；同一地图误差、同一传感器漂移让各步共享潜在错误，乘积不再是鞅，任意时有效保证失效。
- **H31（风险预算 vs 自主性）**：把 δ_tot 当一次性预算花，就产生"现在花还是留给后面"的时序经济学；若用步骤分决定花钱节奏，一个坏步骤分器会**前置烧掉风险预算**（早期频繁承诺），让后段暴露在无保护状态。预算花费必须是单调保守且按证据块预留的。

## 0. 直觉与动机

**灵感 1（步骤分 → 过程奖励与证据信用账本）**
直觉：第 57 轮在每个检查点问"这一步能不能承诺"，然后就把结果扔进二值成功里。过程奖励换一种问法：**给每个检查点记一笔账**——这笔账由四元组决定：证据裕度 m_i、校准 c_i、跨模态分歧 d_i、相对进度 p_i；分数 S_i 是"该步已认证状态能存活到任务结束"的校准概率。关键不是"分高就继续"，而是两条约束：**(i) S_i 必须是 proper scoring rule**，即长期看 S_i 越高、真实存活率越高，否则分数只是自评自信；**(ii) 分数只决定"可记账/可分配探针"，永远不能单独授权不可逆接触**——步骤分带来效率，不带来下注权。

**灵感 2（长程任务 → 任意时有效的风险预算 ASC）**
直觉：union bound 是"先数好一共要看 N 次，每次预扣一点"。长程任务恰恰不知道要看多少次、何时该停。序贯检验给另一种问法：**每步产生一个证据 e-value，累积乘积是零假设下的上鞅，一旦穿透 1/δ_tot 就可停可承诺，且此前看多少次都不算偷看**。这把"风险"从每步常数变成**一次性总预算**：δ_tot 是整条任务的误承诺上限，花在何时由证据强度自适应决定。效率提升是数量级的：N=100 时 union bound 要求每步 δ/100，而 ASC 只需总预算 δ_tot。代价是把独立性/条件有效性搬到台面上——这正是本轮最锋利的风险点。

**灵感 3（长程证据相关 → 证据块而非证据步）**
直觉：长程任务里最容易犯的错是把"步"当独立样本。一个地图形状错了，十个检查点会一起错；一次相机标定漂了，十次视觉证据会一起漂。这与第 57 轮"同一模态重复五遍只是同一个问题问五遍"同构。解法：把共享潜在状态的步切成**证据块** B_1..B_m，块内只取最强一份证据（不连乘、不复利），块间才允许组合；总误承诺界对**有效块数 m_eff** 取界，而不是对原始步数 N。相关越强，m_eff 越小，界越保守——这是诚实的代价，而不是把相关性当不存在。

**灵感 4（三灵感合流 → 可恢复的部分承诺 + 信用分配探询）**
直觉：有了步骤分与风险预算，长程任务就从"冲到终点"变成**最优停止 + 期权定价**：每步在 {继续, 探询, 绕行, 记账后安全停, L2 协商} 中选，部分完成有真实效用 U(P_k)，停下的机会成本是"继续可能获得的增量价值减去继续暴露的风险"。探询预算也不再按检查点贪心，而是做**全局信用分配**：把探针放到"全局风险边际下降/成本"最高的瓶颈步（步骤分梯度就是瓶颈信号）。同时保留第 57 轮最锋利的武器——事后证伪回溯——并升级为 **clawback**：证伪发生时借记所有依赖该证据类的已记账步骤、重开下游证书、沿 lineage DAG 传播。

**灵感 5（长程证据账本 J_L 与 PCE++）**
直觉：第 57 轮的证书 J_p 只证明"此刻这条接触链的证据齐全"；长程版本要证明的是"这条进度账本没有被重复计分、没有被证伪污染、没有用过期的续行证书"。J_L 因此新增四样：步骤账本、证据块划分、e-process/风险预算流水、进度证书与 clawback 闭包。PCE++ 只是把 PCE+ 的每检查点流程改成一个"记分—报账—决定停/续"的序贯循环。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（步骤分证据信用 SEC）** 第 i 步（检查点 c_i，步上下文 z_i）的证据向量 e_i=(m_i 裕度, c_i 校准, d_i 跨模态分歧, p_i 相对进度)，步骤分 S_i=σ(w^⊤φ(e_i))，且**过程 proper 性**：存在真实条件存活概率 q_i=P(该步认证状态存活至任务结束 | F_i)，S_i 是 q_i 的 proper scoring rule 预测，声明 ECE_S≤ε_S。步骤记账指示 b_i=1[S_i≥θ_S ∧ 证据门过 ∧ 非重复计分]，信用 C_i=b_i·u_i（u_i 为该步部分效用）。**硬约束**：b_i 永不作为不可逆接触的充分证据。

**定义 140（长程风险预算与任意时有效认证 ASC）** 总预算 δ_tot，每步 e-value E_i≥0 在零假设 H0（该步认证为假）下满足 E[E_i|F_{i-1}]≤1。运行乘积 M_k=∏_{i≤k}E_i 为上鞅，Ville 不等式 → P_{H0}(∃k:M_k≥1/δ_tot)≤δ_tot，故"任意停止时刻的误认证"≤δ_tot。**证据块**：把步划分为块 {B_1..B_m}，块内共享潜在状态（同区域/同材质簇/同会话/同标定版本），块内取 E_B=max_{i∈B}E_i（不连乘、不因重复到访复利），块间组合 M=∏_block E_B，界按有效块数 m_eff≤m 计。无 e-value 时退化为 α-spending：α_i=δ_tot·γ_i，Σγ_i≤1，γ_i 单调可披露。**预算守恒**：已花预算 Σ_{i<k}α_i 记入账本，预留 δ_reserve 给后续块，不得透支。

**定义 141（进度证书与可恢复部分承诺 LPC）** 进度证书 P_k=(已记账步集 {C_i}, 块划分, 时效戳, 续行前置条件 τ_stale, lineage DAG)。部分效用 U(P_k)=Σ_{i∈P_k}u_i−RiskPenalty(P_k)。停止规则：安全停 ⇔ U(P_k) ≥ E[继续增量 | F_k] − Cost_cont 且证据门保持；否则继续/探询/绕行。**clawback 算子**：在步 j 的证伪事件 f 发生时，借记所有 i 使 C_i 依赖 f 所证伪的证据类（模态/标注源/地图版本），并递归重开下游证书；闭包要求不存在"已借记但其下游仍被当作已验证"的路径。

**定义 142（步骤分引导的信用分配探询 SGA）** 全局探针预算 K_glob。第 i 步的全局边际价值 VOI_i^glob=(∂R_global/∂r_i)·r_i^reducible/cost_i，其中风险梯度用步骤分与块结构估计；每轮选 argmax_i VOI_i^glob，受"单步不超过第 57 轮证据门强度"和递减回报约束；这是跨检查点的背包/注水，不是每检查点贪心。步骤分残差 g_i=S_i−Ŝ_i（Ŝ_i 为同级步的期望分）用作瓶颈定位信号。

**定义 143（长程证据账本与证书 J_L）** J_L=(J_p 全字段, step_ledger, block_partition, eproc_state, risk_budget_ledger, progress_cert,P_k, clawback_log, resume_lineage)。附加校验：(C1) 任何证据只在一个块内计分、块内不复利；(C2) Σ 已花 α ≤ δ_tot−δ_reserve；(C3) clawback 闭包成立、lineage 无环；(C4) 续行证书未超 τ_stale 或已重验。

**定义 144（PCE++ 长程算子）** 每步：①记分（S_i、b_i）并更新 e-process/α 预算；②对账（沿用第 57 轮 D(r)>θ_D 共识探针）；③决定 {继续承诺, 按 SGA 探询, 绕行, 记账+安全停, L2 协商}，其中承诺需过第 57 轮证据门 **且** e-process 穿透 **且** 预算不透支；④证伪触发 clawback 并重规划；⑤续行前按 τ_stale 重验受影响块。终止于 {完成, 安全部分停, 绕行改道, L2 协商结果, 硬故障} 五态。

## 2. 关键算法伪代码（完整版见产物区）

```python
def step_score_and_bank(M, r, cp, P):                # IP-139/141 合流
    e = evidence_vec(M, r, cp)                        # 裕度/校准/分歧/进度
    S = proper_score(e)                               # 声明 ECE_S <= eps_S
    block = block_of(cp, M)                           # 同潜在状态归块
    if S >= theta_S and few_shot_evidence_gate(cp, M, P) == 'ok' \
       and not already_scored(block, e):              # 块内不复利
        P.bank(cp, S, block); return P, S, 'bank'
    return P, S, 'probe_or_continue'

def anytime_commit(M, cp, P, delta_tot):             # IP-140: e-process
    E = e_value(M, cp, P)                             # 条件有效，块内取 max
    P.M = P.M * E                                     # 块间组合，非块内连乘
    if P.M >= 1.0 / delta_tot and risk_budget_ok(P):
        return True
    return False

def clawback(P, falsified, lineage):                 # IP-141: 回溯借记
    for i in P.banked_depending_on(falsified):
        P.debit(i); P.reopen_downstream(i, lineage)   # 递归闭包
    return P
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| SEC | O(d_φ)/步 | O(N) 账本 | 过程 proper、S 不授权不可逆接触 |
| ASC | O(1)/步 | O(m) 块状态 | e-value 条件有效、块内不复利、预算不透支 |
| LPC | O(\|P_k\|+lineage) | O(N) | clawback 闭包、时钟 τ_stale |
| SGA | O(N·d_VOI)/轮 | O(N) | 全局背包、单步强度不超证据门 |
| J_L | O(N+m) | O(N) | 四校验 C1–C4 |
| PCE++ | O(N·(d_φ+C_VOI+A\*)) | O(N) | 五态完备、预算终止 |

**正确性定理（LSC, Long-horizon Step-credited Certification 概要）**：在 A37–A40 上加 (A41) 过程 proper 与声明 ECE_S≤ε_S；(A42) e-value 条件有效且证据块划分诚实（块内最大而非连乘），有效块数 m_eff；(A43) clawback 完备、lineage 无环、τ_stale 可靠；(A44) SGA 只重分配探针不改单步证据门强度。则：(i) **任意时安全**：P(∃k 误认证) ≤ δ_tot+ε_S+m_eff·δ_dep，其中 δ_dep 为残余相关项；(ii) **部分信用健全**：任何被记账的进度或被重验、或被 clawback 借记，E[U(P_k)] 至多高估 δ_tot+ε_S；(iii) **长程效率**：union bound 的每步阈值随 N 线性收紧而 ASC 的总预算与 N 无关，故大 N 下 ASC 的可行承诺率趋于正、union bound 趋于零；(iv) **终止与可恢复**：PCE++ 在 min(K_glob,N) 次探询内终止于五态，续行代价 ≤ 重验受影响块 + O(N) 账本读。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 长程证据相关 → e-process 失效 | 高 | 证据块划分 + 块内取 max + m_eff 保守界 + 共享潜在状态建模 + 总自主性硬上限 |
| 步骤分自评 → 进度幻觉 | 高 | proper scoring 绑定后验结果 + 独立重验 + clawback 闭包 + S 不授权不可逆接触 |
| 风险预算前置烧光 | 中 | α-spending 单调 + 每块预留 + 预算账本 + 透支即保守停 |
| 续行证书过期 | 中 | τ_stale 强制重验 + lineage 传播 |
| 长程最优化进入控制回路时延 | 中低 | 每步 O(1) 更新 + 块粒度批处理 + 可退回第 57 轮逐点路径 |

## 6. 本轮最大风险

**一句话**：长程任务里"步骤独立"是最大的谎言——同一地图误差、同一传感器漂移或同一次材质误判会让各步证据共享同一个潜在错误，此时 e-process 的乘积不再是鞅、"任意时有效"保证整体失效；若再用步骤分把这些相关步骤逐一记账，就会把同一个错误反复计入进度，制造"进度幻觉"，因此必须按证据块（而非按步）计权、块内不重复计分、clawback 闭包、并对整条路线的总自主性设硬上限。

### IP-140 ASC（任意时有效认证，证据块 + e-process）

```python
def asc_update(P, credit, delta_tot, delta_reserve):
    E = conditional_e_value(credit, P.history)     # E[E|F_{i-1}] <= 1 under H0
    b = credit.block
    P.E_block[b] = max(P.E_block.get(b, 0.0), E)   # 块内取 max，不连乘
    P.M = prod(P.E_block.values())                 # 块间组合
    alpha_i = alpha_spending(P.i, delta_tot, delta_reserve)
    P.spent += alpha_i
    if P.spent > delta_tot - delta_reserve:        # 预算不透支
        return P, 'budget_exhausted'
    if P.M >= 1.0 / delta_tot:                     # Ville 界
        return P, 'anytime_certified'
    return P, 'continue'

def alpha_spending(i, delta_tot, delta_reserve):
    # 单调、可披露、预留后段；例如 gamma_i ∝ (i+1)^-1.5 归一化
    gamma = (i + 1) ** -1.5
    return (delta_tot - delta_reserve) * gamma / Z_gamma
```

### IP-141 LPC（进度证书、安全部分停、clawback、续行）

```python
def partial_commit_decision(P, credit, M, risk_model):
    if not credit.bankable:
        return 'probe_or_continue'
    P.bank(credit)                                 # 记一笔账
    cont = expected_continue_value(P, M, risk_model)
    stop = U(P)                                    # 已认证部分效用
    if stop >= cont - continuation_cost(P, M):
        return 'safe_partial_stop'                 # 期权：行权落袋
    return 'continue'

def clawback(P, falsified_event, lineage):
    doomed = P.banked_depending_on(falsified_event)  # 依赖被证伪证据类
    for i in doomed:
        P.debit(i)
        P.reopen_downstream(i, lineage)            # 递归闭包
    return P

def resume(P, now, tau_stale):
    for c in P.progress_cert.segments:
        if now - c.timestamp > tau_stale or c.block in P.clawback_log.tainted:
            c.valid = revalidate(c)                # 过期或污染必须重验
    return P.progress_cert
```

### IP-142 SGA（步骤分引导的全局信用分配探询）

```python
def allocate_probes(P, M, K_glob, F_abs):
    while P.probes_left > 0:
        best, best_v = None, 0.0
        for cp in M.route.checkpoints:
            if cp.done or not admissible(cp, M):   # A34 非破坏性过滤
                continue
            grad = risk_gradient(cp, M)            # 用 S_i 与块结构估计
            v = (grad * reducible(cp, M)) / cost(cp)
            if v > best_v and v >= theta_voi:
                best, best_v = cp, v
        if best is None:
            break
        M = execute_probe_on(best, cap=F_abs, M=M)  # 单步强度不超证据门
        P.spend(best)
    return P, M
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SEC | O(d_φ)/步 | O(N) 账本 | 过程 proper、S 不授权不可逆接触（A41） |
| ASC | O(1)/步 | O(m) 块状态 | e-value 条件有效、块内 max、预算不透支（A42） |
| LPC | O(\|P_k\|+lineage) | O(N) | clawback 闭包、τ_stale（A43） |
| SGA | O(N·d_VOI)/轮 | O(N) | 全局背包、单步强度不超证据门（A44） |
| J_L | O(N+m) | O(N) | 四校验 C1–C4 |
| PCE++ | O(N·(d_φ+C_VOI+A\*)) | O(N) | 五态完备、预算终止 |

**正确性定理（Long-horizon Step-credited Certification, LSC）**
在 A22–A32（第 53–55 轮）、A33–A36（第 56 轮）、A37–A40（第 57 轮）成立之上，新增：**(A41)** 过程 proper：S_i 是条件存活概率 q_i 的 proper scoring rule，声明 ECE_S≤ε_S；**(A42)** 序贯有效性：每步 e-value 在给定历史下条件有效（E[E_i|F_{i-1}]≤1 under H0），证据块划分诚实（共享潜在状态的步同块、块内取最大而非连乘），有效块数 m_eff，残余相关项 ≤δ_dep；**(A43)** 账本健全：clawback 对"依赖被证伪证据类的全部已记账步"完备，lineage DAG 无环，τ_stale 可靠；**(A44)** 信用分配单调：SGA 只在步间重分配探针预算，不降低任何单步的证据门强度；安全停为吸收态。则：

1. **任意时安全**：`P(∃k 误认证) ≤ δ_tot + ε_S + m_eff·δ_dep`。相比 union bound 的 `N·δ_step`，预算与 N 解耦，允许自适应停止而不膨胀一类错误。
2. **部分信用健全**：任一被记账进度或被重验、或被 clawback 借记；`E[U(P_k)]` 的高估 ≤ δ_tot+ε_S。不存在"已借记但其下游仍视作已验证"的路径（A43）。
3. **长程效率分离**：union bound 每步阈值 ∝1/N，N→∞ 时可行承诺率→0；ASC 固定 δ_tot，随证据累积承诺率单调上升。效率与安全再次解耦：**e-process 给随时可停、证据块给相关性保底**。
4. **终止与可恢复**：PCE++ 在 min(K_glob,N) 次探询内终止于 {完成, 安全部分停, 绕行改道, L2 协商, 预算/硬故障停} 五态；续行代价 ≤ 重验受影响块 + O(N) 账本读。

**部署界**（对块取联合界，而非对步）：

```
P_safe ≥ 1 − δ_tot − ε_S − Σ_blocks δ_dep
             − P(𝓜 陈旧未检出) − P(clawback 不闭合) − P(续行证书漏检)
```

关键：**步骤分给效率与部分效用，e-process 给任意时安全，证据块给相关性保底，clawback 给进度可追责**；四者各自承担一类风险，绝不把"分高"误当成"敢赌"。

## 6. 本轮最大风险

**一句话**：长程任务里"步骤独立"是最大的谎言——同一地图误差、同一传感器漂移或同一次材质误判会让各步证据共享同一个潜在错误，此时 e-process 的乘积不再是鞅、"任意时有效"保证整体失效；若再用步骤分把这些相关步骤逐一记账，就会把同一个错误反复计入进度，制造"进度幻觉"，因此必须按证据块（而非按步）计权、块内不重复计分、clawback 闭包、并对整条路线的总自主性设硬上限。
