# 第 62 轮（承接第 61 轮「具身语义进化闭环」IP-173~182；灵感循环第 1 轮；本轮灵感：「成本控制」×「异常检测」）

> 第 61 轮 ESEC 打通了「统一语义表征（USR）×具身大模型（MEL）×多轮对话（DMS）×语义-实时双流（SRT-Dual）×六维预算（PCE+++++）」。但它把「预算」误当成「成本」，把「语义对账」误当成「异常检测」，留下四个核心局限：
> 1. **预算 ≠ 成本**：B_cog5 只约束「用了多少资源」，却不回答「这次计算值不值」。MEL 一次 200ms 全模态推理、一次澄清对话、一次保守扩展，都有真实成本（算力/能量/时延/认知负荷/性能损失），系统却没有统一的「经济账本」，因此降级只能是「耗尽即降级」的硬阈值，无法做「边际收益 < 边际成本」的最优停时。
> 2. **对账 ≠ 检测**：XMC+++ 的 D⁺_sem 只度量「当前语义与观测的差异」，没有统计意义上的异常判定、没有误报/漏报的代价权衡、没有异常分级响应。**语义-现实鸿沟在灾难性失效前，必然先在残差上留下可观测的异常**，第 61 轮却把它当成一个连续分数，而不是一个「花成本去查、查错也要花钱」的决策问题。
> 3. **保守性成本被隐藏**：SRT-Dual 的保守扩展、MSPF 的 20% 收缩，都是「用性能换安全」，但系统从不度量这笔账——过度保守会浪费性能，保守不足会漏掉风险，二者都无法被优化。
> 4. **成本参数冷启动未知**：漏检一次灾难的成本 C_FN、误报一次的成本 C_FP 都没有先验，检测门限无从设定，也无法证明「多查一次是否值得」。

## 0. 直觉与动机

**灵感 1（成本控制 → 统一成本账本 UCL）**
直觉：第 61 轮把预算当成「资源配额」，但真正的成本控制要回答三个问题：**花了多少（记账）、值不值（边际分析）、超了怎么办（降级）**。构建统一成本账本 UCL，把六维预算映射为可加的标量成本——算力 c_comp（GPU·ms）、能量 c_energy（J）、时延 c_lat（ms 惩罚）、认知负荷 c_cog（澄清轮次）、**保守性成本 c_cons（因保守而损失的任务性能）**、误报成本 c_fp、漏检成本 c_fn。关键洞见：**预算维度是「物理量」，成本账本是「经济量」**，二者通过换算率 γ 连接；有了账本，「是否执行某次推理/澄清/保守扩展」就从「预算够不够」升级为「边际 VOI 是否 ≥ 边际成本」。

**灵感 2（异常检测 → 语义残差异常检测 SRAD）**
直觉：MEL 预测了「世界应该是什么样」（scene_emb、φ_phys），实时流观测到「世界实际是什么样」（E_scene(Obs)、E_evidence(EV-exec)），**二者的残差就是语义-现实鸿沟的可观测代理**。构建语义残差检测器 SRAD：在 USR 空间定义多通道残差 r_t = (r_scene, r_intent, r_imp, r_ev, r_phys)，用马氏距离/密度估计得到异常分数 s_t，再用保形预测（conformal prediction）给出分布无关的检测门限与覆盖率保证。关键洞见：**异常不是「分数高」，而是「在当前成本结构下，判定为异常比不判定更划算」**。

**灵感 3（两灵感合流 → 成本敏感检测门限 CSAT）**
直觉：这是本轮最核心的洞见。设 π_t = P(异常 | 证据)，误报成本 C_FP、漏检成本 C_FN。**判定为异常**的期望成本 = C_FP·(1-π_t)；**不判定**的期望成本 = C_FN·π_t。贝叶斯最优决策：当且仅当 C_FP·(1-π_t) < C_FN·π_t 时报警，即

> **π_t > C_FP / (C_FP + C_FN) ≜ τ\***

也就是说，**检测门限不是拍脑袋的 0.7，而是成本比的解析函数**——成本控制与异常检测在此处数学地合流：越怕漏检（C_FN 越大）门限越低、越查越勤；越怕误报（C_FP 越大）门限越高、越查越省。这把「异常检测」从「模型问题」变成了「决策问题」。

**灵感 4（异常驱动成本重分配 ACRA）**
直觉：检测到异常后，系统应把「省下来的常规成本」挪给「诊断成本」——异常时 B_mel 从缓存模式切回全模态（多花 token 换更准的物理推断），B_usr 从投影对齐切到残差分析，DMS 从执行切到澄清；正常时反向压缩（缓存模式、降频、降低保守度）。用「边际价值/边际成本」做资源再分配，本质是一个带安全约束的在线背包问题。

**灵感 5（异常分级 + 自适应保守度 ACC）**
直觉：不是所有异常都值得同样响应。区分：G0 偶然异常（接触瞬态/传感器噪声，忽略）、G1 认知异常（模型不知道，探索/澄清）、G2 分布漂移（环境变了，重推理+重对齐）、G3 安全异常（力超限/碰撞/失控，立即 abort）。**保守度 κ 本身是可调成本旋钮**：异常率高→提高 κ（成本换安全）；异常率低→降低 κ（安全换性能），用类 PID/AIMD 控制把「实际异常率」稳定在「风险预算」附近。

**灵感 6（反事实成本审计 CCA + 成本可证证书 CAC）**
直觉：C_FN/C_FP 冷启动未知，但 DMS 的 B_diag 记录了 (s,a,r,s')。**离线回放「如果当时报警/不报警」的反事实成本**，即可校准成本参数与门限（类似离线策略评估 + 重要性采样）。最终把「异常检测的统计保证（保形覆盖率）+ 检测成本 + 期望损失上界」写入证书 CAC，形成「经济可证安全」：不仅证明「控制安全」，还证明「这次监控是划算的」。

## 1. 形式化定义（增量：定义 173–184）

**定义 173（统一成本账本 UCL）** 成本账本 UCL = (c_t, C_acc, Γ, Δ)。其中：
- **成本向量**：c_t ∈ ℝ⁷，七个分量见定义 174
- **累计账本**：C_acc = Σ_{i≤t} c_i，逐分量可加
- **换算矩阵**：Γ: 预算维度 → 成本分量，Γ_{jk} = γ_{jk} ≥ 0；物理资源量（GPU·ms、J、ms、轮次）经 Γ 折算为统一「成本单位」
- **成本预算**：Δ = 每决策周期的成本上限；当 C_acc 超 Δ 触发成本降级（见定义 183）
- **记账接口**：charge(action, ops, latency, energy, cognitive, conservatism) → c_t；charge_decision(alarm, truth) → 更新 c_fp/c_fn

**定义 174（成本向量与期望总成本）** c_t = (c_comp, c_energy, c_lat, c_cog, c_cons, c_fp, c_fn)：
- c_comp = γ_comp·GPU_ms，c_energy = γ_energy·J，c_lat = γ_lat·ms，c_cog = γ_cog·澄清轮次
- c_cons = 保守性成本 = 因保守（低刚度/高阻尼/收缩）而损失的 task reward，c_cons(κ) 关于 κ 单调递增且凸
- c_fp、c_fn：误报/漏检的决策成本（先验由 CCA 校准）
- **期望总成本**：J(π) = 𝔼[Σ_{t=1}^{T} (c_comp+c_energy+c_lat+c_cog+c_cons)(a_t) + C_FP·N_FP + C_FN·N_FN]
- **关键性质**：预算维度 B_* 是物理量（不可跨维比较），成本 c_t 是经济量（可加、可比），故「跨维度取舍」只能在账本层完成

**定义 175（语义残差 SRAD）** 在 USR 空间定义五通道残差：
- r_scene = E_scene(Obs_t) − anchor.scene_emb（场景语义残差）
- r_intent = E_intent(dialogue_t) − anchor.intent_emb（意图语义残差）
- r_imp = E_impedance(K_executed, cert) − anchor.impedance_emb（阻抗-语义残差）
- r_ev = E_evidence(EV_exec) − anchor.evidence_emb_pred（证据预测残差，anchor 由 MEL 预测的期望证据嵌入）
- r_phys = φ_obs − anchor.phys_prior（物理属性残差，φ_obs 由力/力矩在线估计）
- **拼接残差**：r_t = [r_scene; r_intent; r_imp; r_ev; r_phys] ∈ ℝ^{5·d_us}
- **异常分数**：s_t = sqrt((r_t−μ_r)ᵀ Σ_r^{-1} (r_t−μ_r))（马氏距离），μ_r、Σ_r 由标定集估计（协方差收缩）

**定义 176（多通道残差检测器 MCRD）** MCRD = (SRAD, D_cal, α, τ_α)：
- **标定集**：D_cal = {r_i}_{i=1}^{n} 采自名义（无异常）工况，交换性假设下独立同分布
- **保形门限**：τ_α = Quantile_{1−α}({s_i}_{i=1}^{n})，即标定分数的 1−α 分位数
- **保形 p 值**：p_t = (1 + #{i: s_i ≥ s_t}) / (n + 1)
- **分布无关保证**：若名义残差可交换，则 P(s_{t+1} ≤ τ_α) ≥ 1−α，即**名义工况下漏检（把正常判为异常）的误报率受控于 α**
- **注意**：α 不是拍定的，而是由定义 177 的成本最小化内生决定

**定义 177（成本敏感检测门限 CSAT）** 设 π_t = P(异常 | 证据) 为校准后的异常概率（由保形 p 值或 isotonic 校准器给出），决策规则：
```
报警 ⟺ C_FP·(1−π_t) < C_FN·π_t ⟺ π_t > C_FP/(C_FP+C_FN) = τ*
```
- **贝叶斯最优性**：在成本参数已知、π_t 校准时，τ* 最小化期望决策成本
- **与保形融合**：等价于在分数空间选取 s* = 使 π(s*)=τ* 的分数门限；若用保形控制误报率，则选 α* = P_normal(s > s*)，即**成本最优的误报率预算**
- **极端情形**：C_FN ≫ C_FP ⇒ τ*→0（宁可错杀，不可放过，安全优先）；C_FP ≫ C_FN ⇒ τ*→1（宁可不查，不可打扰）
- **冷启动**：C_FP、C_FN 先验未知时取保守初值（C_FN 初始偏大，先保证安全），再由定义 181 校准

**定义 178（异常分级 AGR）** 分级函数 g_t = grade(r_t, s_t, U_mel, EV_exec) ∈ {G0, G1, G2, G3}：
- **G0 偶然异常（aleatoric）**：s_t ≤ τ_g1 且无安全通道触发；来源为接触瞬态/传感器噪声；响应 = 忽略，成本≈0
- **G1 认知异常（epistemic）**：s_t > τ_g1 或 U_epistemic > 0.5；来源为模型不确定/未见局部；响应 = 探索或澄清，成本中等
- **G2 分布漂移（shift）**：s_t > τ_g2 且 U_epistemic > 0.7；来源为环境变化/新材质；响应 = MEL 重推理 + USR 重对齐，成本高
- **G3 安全异常（safety）**：力超限/碰撞/滑移失控，或 r_phys 超安全阈；响应 = 立即 abort/最大保守，**独立于成本决策，永不因预算降级**
- **硬优先规则**：G3 ≻ G2 ≻ G1 ≻ G0，安全通道覆盖任何统计/成本判定

**定义 179（异常驱动成本重分配 ACRA）** 资源分配器把「异常等级」映射为预算再分配与动作选择：
- **再分配策略** δ(g)：G0 ⇒ B_mel↓（缓存模式）、B_usr↓、B_diag→；G1 ⇒ B_mel↑、B_usr↑、B_diag↑；G2 ⇒ B_mel↑↑（全模态）、B_usr↑↑（重对齐）、B_diag↑；G3 ⇒ 全部↑ 且强制安全动作
- **动作选择**：a_t = argmax_{a ∈ A_feasible} [VOI(a) − cost(a)]，s.t. C_acc + cost(a) ≤ Δ
- **安全约束硬编码**：g_t = G3 ⇒ a_t = abort/conservative，**不进入成本优化**
- **本质**：带安全约束的在线背包/停时问题，用边际价值贪心近似

**定义 180（自适应保守度控制 ACC）** 保守度 κ_t ∈ [κ_min, κ_max] 是成本旋钮：
- **成本-风险对偶**：c_cons(κ) = ½(κ/κ_max)² 递增凸（越保守越损性能）；risk(κ) = exp(−β·κ) 递减（越保守越安全）
- **风险预算**：目标异常率 ρ_target（如 3%）；估计 ρ̂_t = 0.95·ρ̂_{t−1} + 0.05·𝕀[alarm_t]
- **控制律**：κ_{t+1} = clip(κ_t + η·(ρ̂_t − ρ_target), κ_min, κ_max)（类 AIMD）
- **稳态最优**：κ* 满足 ∂c_cons/∂κ + ∂risk/∂κ·C_FN = 0，即**保守性边际成本 = 风险边际收益**

**定义 181（反事实成本审计 CCA）** 基于 DMS 诊断缓冲 B_diag 的离线重校准：
- **回放**：对每条 (s, a, r, s', is_true_anomaly) 计算「报警 vs 不报警」的反事实成本
- **估计**：Ĉ_FP = 𝔼[realized_cost(a) | alarm ∧ ¬anomaly]；Ĉ_FN = 𝔼[realized_loss(a, s') | ¬alarm ∧ anomaly]
- **去偏**：用重要性采样/双重稳健估计器处理策略分布偏移（overlap 假设）
- **重校准**：更新账本成本参数，重算 τ* = Ĉ_FP/(Ĉ_FP+Ĉ_FN)，并计算相对基线的**成本 regret** = J(π_new) − J(π_baseline)
- **冷启动解决**：用「探索性随机门限」采集覆盖两类错误的数据，逐步收缩到 τ*

**定义 182（成本可证异常证书 CAC）** CAC = (J_sem_exec, s_t, π_t, g_t, τ*, coverage, c_t, Û_loss)：
- **字段**：继承第 61 轮 J_sem_exec，增加异常分数 s_t、异常概率 π_t、等级 g_t、门限 τ*、保形覆盖率 1−α、当步成本 c_t、**期望损失上界 Û_loss**
- **验证规则**：
```
Valid(CAC) ⇔ Valid(J_sem_exec)
           ∧ coverage ≥ 1−α_required
           ∧ Û_loss ≤ ε_loss
           ∧ (g_t = G3 ⇒ response_executed)   # 安全异常必有响应
           ∧ (g_t ≥ G2 ⇒ re_inference_done)
```
- **经济可证性**：证书不仅证明「控制安全」，还证明「监控划算」——检测成本 c_t 与期望损失上界 Û_loss 均可审计

**定义 183（第七维预算 B_cog6 与 PCE++++++）** B_cog6 = B_cog5 ∪ (B_anomaly, B_cost)：
- **B_anomaly** = (Detector_ops, Calib_interval, Grade_thresholds, Fallback_detector)
- **B_cost** = (Per_period_cost_budget Δ, C_FP_est, C_FN_est, Conservatism_budget)
- **降级阶梯**：B_anomaly 耗尽 ⇒ 检测器 full→lightweight（仅马氏距离，无保形）；再耗尽 ⇒ safety_only（仅 G3 安全通道）；**G3 安全通道永不降级**
- **成本降级**：C_acc 超 Δ ⇒ 压缩常规推理（MEL 缓存、USR 冻结），但**安全响应与 G3 检测不进入压缩集合**
- **VOI 扩展**：voi_cog6 = VOI_meta − cost_mel − cost_usr − cost_anomaly − cost_cons，且与 C_FP/C_FN 联动

**定义 184（成本敏感异常闭环 C-SAL）** C-SAL = ACC ∘ ACRA ∘ AGR ∘ CSAT ∘ MCRD ∘ SRAD ∘ UCL，闭环结构：
```
UCL 记账 → SRAD 残差 → MCRD 保形评分 → CSAT 成本最优判定
       → AGR 分级 → ACRA 重分配预算 → ACC 调保守度
       → CAC 生成成本可证证书 → CCA 反事实审计/重校准 → 回写 UCL 成本参数
```
- **闭环意义**：把第 61 轮「语义-执行闭环」升级为「语义-执行-成本-监控」四重闭环，异常检测不再是外挂模块，而是**由成本结构驱动的内生理性行为**

## 2. 关键算法伪代码

### IP-185 UCL（统一成本账本）

```python
class UnifiedCostLedger:
    def __init__(self, cost_budget_per_period=1.0, C_FP=1.0, C_FN=20.0):
        # 预算维度 -> 成本换算率（物理量 -> 经济量）
        self.gamma = {'B_scene': 0.10, 'B_intent': 0.20, 'B_ros': 0.05,
                      'B_mel': 0.30, 'B_usr': 0.10, 'B_anomaly': 0.20}
        self.cost_budget = cost_budget_per_period
        self.C_FP, self.C_FN = C_FP, C_FN      # 误报/漏检成本（CCA 校准）
        self.acc = CostVector.zeros()          # 累计账本
        self.history = deque(maxlen=10000)

    def charge(self, action, ops=1, latency_ms=0.0, energy_j=0.0,
               cognitive=0.0, conservatism=0.0):
        c = CostVector(
            comp=self.gamma.get(action.budget_key, 0.0) * ops,
            energy=energy_j, lat=latency_ms,
            cog=cognitive, cons=conservatism, fp=0.0, fn=0.0)
        self.acc += c
        self.history.append((action, c))
        return c

    def charge_decision(self, is_alarm, is_true_anomaly):
        if is_alarm and not is_true_anomaly:
            self.acc.fp += self.C_FP
        if (not is_alarm) and is_true_anomaly:
            self.acc.fn += self.C_FN

    def marginal_worth(self, voi, est_cost):
        return voi - est_cost

    def over_budget(self):
        return self.acc.ops() > self.cost_budget

    def update_cost_params(self, C_FP, C_FN):
        self.C_FP, self.C_FN = C_FP, C_FN
```

### IP-186 SRAD + MCRD（语义残差检测器）

```python
class SemanticResidualAnomalyDetector:
    def __init__(self, d_us=256, calib_size=500, alpha=0.05):
        self.d_us, self.alpha = d_us, alpha
        self.mu = np.zeros(5 * d_us)
        self.sigma_inv = np.eye(5 * d_us)
        self.calib_scores = deque(maxlen=calib_size)
        self.tau_alpha = None

    def residual(self, anchor, obs_emb, intent_emb, imp_emb, ev_emb, phi_obs):
        r = np.concatenate([
            obs_emb    - anchor.scene_emb,          # r_scene
            intent_emb - anchor.intent_emb,         # r_intent
            imp_emb    - anchor.impedance_emb,      # r_imp
            ev_emb     - anchor.evidence_emb_pred,  # r_ev
            phi_obs    - anchor.phys_prior,         # r_phys
        ])
        return r

    def score(self, r):
        d = r - self.mu
        return float(np.sqrt(d @ self.sigma_inv @ d))  # 马氏距离

    def calibrate(self, residuals):
        X = np.array(residuals)
        self.mu = X.mean(axis=0)
        cov = np.cov(X, rowvar=False) + 1e-6 * np.eye(X.shape[1])  # 收缩
        self.sigma_inv = np.linalg.inv(cov)
        self.calib_scores = [self.score(r) for r in X]
        self.tau_alpha = float(np.quantile(self.calib_scores, 1 - self.alpha))

    def detect(self, r):
        s = self.score(r)
        # 保形 p 值：分数越大越异常；p 越小越可疑
        p = (1 + sum(1 for c in self.calib_scores if c >= s)) / (len(self.calib_scores) + 1)
        return s, p
```

### IP-187 CSAT（成本敏感检测门限）

```python
class CostSensitiveThreshold:
    def __init__(self, ledger, calibrator=None):
        self.ledger = ledger
        self.calibrator = calibrator  # isotonic: score -> P(anomaly|score)

    def bayes_threshold(self):
        C_FP, C_FN = self.ledger.C_FP, self.ledger.C_FN
        return C_FP / (C_FP + C_FN)          # tau*

    def decide(self, s, p_conformal):
        tau = self.bayes_threshold()
        pi_hat = (self.calibrator.predict(s) if self.calibrator
                  else 1.0 - p_conformal)     # 异常概率估计
        return pi_hat > tau, pi_hat, tau

    def expected_cost(self, s_normal, s_anom, pi_prior, grid):
        best_s, best_c = None, float('inf')
        for s_star in grid:
            fp = np.mean(s_normal > s_star) * (1 - pi_prior)
            fn = np.mean(s_anom <= s_star) * pi_prior
            c = self.ledger.C_FP * fp + self.ledger.C_FN * fn
            if c < best_c:
                best_s, best_c = s_star, c
        return best_s, best_c
```

### IP-189 ACRA（异常驱动成本重分配）

```python
class AnomalyConditionedResourceAllocator:
    def __init__(self, budget, ledger):
        self.budget, self.ledger = budget, ledger
        self.policy = {
            'G0_aleatoric': {'B_mel': -0.5, 'B_usr': -0.5, 'B_diag':  0.0},
            'G1_epistemic': {'B_mel': +0.5, 'B_usr': +0.3, 'B_diag': +0.5},
            'G2_shift':     {'B_mel': +1.0, 'B_usr': +1.0, 'B_diag': +0.5},
            'G3_safety':    {'B_mel': +1.0, 'B_usr': +1.0, 'B_diag': +1.0},
        }

    def allocate(self, grade, voi_est):
        for k, v in self.policy[grade].items():
            self.budget.shift(k, v)
        if grade == 'G3_safety':
            return self.budget.safe_abort()      # 安全优先，跳过成本优化
        candidates = self.budget.actions_for(grade)
        feasible = [a for a in candidates
                    if self.ledger.acc.ops() + a.est_cost <= self.ledger.cost_budget]
        if not feasible:
            return self.budget.safe_fallback(grade)  # 成本让位安全
        return max(feasible, key=lambda a: voi_est(a) - a.est_cost)
```

### IP-190 ACC（自适应保守度控制）

```python
class AdaptiveConservatismController:
    def __init__(self, kappa0=0.5, kmin=0.1, kmax=1.0, eta=0.05, rho_target=0.03):
        self.kappa = kappa0
        self.kmin, self.kmax = kmin, kmax
        self.eta, self.rho_target = eta, rho_target
        self.rho_hat = rho_target

    def update(self, alarm):
        self.rho_hat = 0.95 * self.rho_hat + 0.05 * float(alarm)
        self.kappa = float(np.clip(
            self.kappa + self.eta * (self.rho_hat - self.rho_target),
            self.kmin, self.kmax))
        return self.kappa

    def conservatism_cost(self):
        return 0.5 * (self.kappa / self.kmax) ** 2   # 递增凸

    def risk(self):
        return float(np.exp(-3 * self.kappa))         # 递减
```

```python
class CounterfactualCostAuditor:
    def __init__(self, diag_buffer, ledger):
        self.buffer, self.ledger = diag_buffer, ledger

    def estimate_costs(self, threshold_fn):
        fp_samples, fn_samples = [], []
        for s, a, r, s_next, is_true_anomaly in self.buffer:
            alarm = threshold_fn(s)
            if alarm and not is_true_anomaly:
                fp_samples.append(self._realized_cost(a))
            if (not alarm) and is_true_anomaly:
                fn_samples.append(self._realized_loss(a, s_next))
        C_FP = float(np.mean(fp_samples)) if fp_samples else self.ledger.C_FP
        C_FN = float(np.mean(fn_samples)) if fn_samples else self.ledger.C_FN
        return C_FP, C_FN

    def recalibrate(self, threshold_fn):
        C_FP, C_FN = self.estimate_costs(threshold_fn)
        self.ledger.update_cost_params(C_FP, C_FN)
        return C_FP / (C_FP + C_FN)      # 新 tau*
```

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|

| C-SAL | 实时流 + O(1) 检测开销 | 共享内存 ~10MB | 检测开销不阻塞实时环（< 0.1ms） |

**正确性定理（C-SAL-Complete）**：
假设 A61–A70 及
**(A71)** UCL：成本换算线性可加，预算→成本映射单调不减；
**(A72)** SRAD/MCRD：名义残差在标定与测试间可交换，分数分布连续；
**(A73)** CSAT：异常概率 π_t 校准良好（ECE ≤ 0.05），成本参数已知或经 CCA 估计且误差 ≤ δ_cost；
**(A74)** AGR：分级关于残差幅度单调，安全通道优先且覆盖统计判定；
**(A75)** ACRA：安全约束为硬约束，G3 响应独立于成本/预算；
**(A76)** CCA：诊断数据对目标策略有重叠（overlap），估计器一致。

则：
1. **成本最优检测**：在 A72–A73 下，CSAT 门限 τ* 最小化期望检测成本；当成本参数存在 δ_cost 误差时，成本 regret ≤ f(δ_cost, ECE)。
2. **分布无关误报控制**：在 A72 下，名义工况误报率 P(s > τ_α) ≤ α；α 由成本最优内生确定。
3. **安全不降级**：G3 异常永不因成本或预算耗尽而降级，安全响应延迟 ≤ τ_g3（与 C_FN 无关）。
4. **保守度收敛**：异常率平稳时，ACC 的 κ_t 收敛到 κ* 的 O(η) 邻域，且稳态满足「保守性边际成本 = 风险边际收益」。
5. **经济可证**：CAC 的期望损失上界 Û_loss 随 δ_cost 单调收紧；证书有效 ⇒ 控制安全 ∧ 监控划算。
6. **端到端**：相较第 61 轮，在同等安全水平下总成本下降，或在同等成本下漏检率下降（帕累托改进）。

### IP-183 UCL（统一成本账本）

```python
class UnifiedCostLedger:
    def __init__(self, cost_budget_per_period=1.0, C_FP=1.0, C_FN=20.0):
        # 预算维度 -> 成本换算率（物理量 -> 经济量）
        self.gamma = {'B_scene': 0.10, 'B_intent': 0.20, 'B_ros': 0.05,
                      'B_mel': 0.30, 'B_usr': 0.10, 'B_anomaly': 0.20}
        self.cost_budget = cost_budget_per_period
        self.C_FP, self.C_FN = C_FP, C_FN      # 误报/漏检成本（CCA 校准）
        self.acc = CostVector.zeros()          # 累计账本
        self.history = deque(maxlen=10000)

    def charge(self, action, ops=1, latency_ms=0.0, energy_j=0.0,
               cognitive=0.0, conservatism=0.0):
        c = CostVector(
            comp=self.gamma.get(action.budget_key, 0.0) * ops,
            energy=energy_j, lat=latency_ms,
            cog=cognitive, cons=conservatism, fp=0.0, fn=0.0)
        self.acc += c
        self.history.append((action, c))
        return c

    def charge_decision(self, is_alarm, is_true_anomaly):
        if is_alarm and not is_true_anomaly:
            self.acc.fp += self.C_FP
        if (not is_alarm) and is_true_anomaly:
            self.acc.fn += self.C_FN

    def marginal_worth(self, voi, est_cost):
        return voi - est_cost

    def over_budget(self):
        return self.acc.ops() > self.cost_budget

    def update_cost_params(self, C_FP, C_FN):
        self.C_FP, self.C_FN = C_FP, C_FN
```

```python
class SemanticResidualAnomalyDetector:
    def __init__(self, d_us=256, calib_size=500, alpha=0.05):
        self.d_us, self.alpha = d_us, alpha
        self.mu = np.zeros(5 * d_us)
        self.sigma_inv = np.eye(5 * d_us)
        self.calib_scores = deque(maxlen=calib_size)
        self.tau_alpha = None

    def residual(self, anchor, obs_emb, intent_emb, imp_emb, ev_emb, phi_obs):
        return np.concatenate([
            obs_emb    - anchor.scene_emb,          # r_scene
            intent_emb - anchor.intent_emb,         # r_intent
            imp_emb    - anchor.impedance_emb,      # r_imp
            ev_emb     - anchor.evidence_emb_pred,  # r_ev
            phi_obs    - anchor.phys_prior,         # r_phys
        ])

    def score(self, r):
        d = r - self.mu
        return float(np.sqrt(d @ self.sigma_inv @ d))  # 马氏距离

    def calibrate(self, residuals):
        X = np.array(residuals)
        self.mu = X.mean(axis=0)
        cov = np.cov(X, rowvar=False) + 1e-6 * np.eye(X.shape[1])  # 收缩
        self.sigma_inv = np.linalg.inv(cov)
        self.calib_scores = [self.score(r) for r in X]
        self.tau_alpha = float(np.quantile(self.calib_scores, 1 - self.alpha))

    def detect(self, r):
        s = self.score(r)
        # 保形 p 值：分数越大越异常；p 越小越可疑
        p = (1 + sum(1 for c in self.calib_scores if c >= s)) / (len(self.calib_scores) + 1)
        return s, p
```

### IP-186 CSAT（成本敏感检测门限）

```python
class CostSensitiveThreshold:
    def __init__(self, ledger, calibrator=None):
        self.ledger = ledger
        self.calibrator = calibrator  # isotonic: score -> P(anomaly|score)

    def bayes_threshold(self):
        C_FP, C_FN = self.ledger.C_FP, self.ledger.C_FN
        return C_FP / (C_FP + C_FN)          # tau*

    def decide(self, s, p_conformal):
        tau = self.bayes_threshold()
        pi_hat = (self.calibrator.predict(s) if self.calibrator
                  else 1.0 - p_conformal)     # 异常概率估计
        return pi_hat > tau, pi_hat, tau

    def expected_cost(self, s_normal, s_anom, pi_prior, grid):
        best_s, best_c = None, float('inf')
        for s_star in grid:
            fp = np.mean(s_normal > s_star) * (1 - pi_prior)
            fn = np.mean(s_anom <= s_star) * pi_prior
            c = self.ledger.C_FP * fp + self.ledger.C_FN * fn
            if c < best_c:
                best_s, best_c = s_star, c
        return best_s, best_c
```

### IP-187 AGR（异常分级）

```python
class AnomalyGrader:
    def __init__(self, tau_g1=2.0, tau_g2=3.0):
        self.tau_g1, self.tau_g2 = tau_g1, tau_g2

    def grade(self, r_channels, s, U_mel, EV_exec):
        # G3：安全通道硬优先，独立于成本与统计判定
        if (EV_exec.force_exceed or EV_exec.collision
                or EV_exec.slip_uncontrolled
                or abs(r_channels['r_phys']) > self.tau_g2):
            return 'G3_safety'
        if s > self.tau_g2 and U_mel[0] > 0.7:   # 分布漂移 + 高认知不确定
            return 'G2_shift'
        if s > self.tau_g1 or U_mel[0] > 0.5:    # 认知异常
            return 'G1_epistemic'
        return 'G0_aleatoric'
```

### IP-188 ACRA（异常驱动成本重分配）

```python
class AnomalyConditionedResourceAllocator:
    def __init__(self, budget, ledger):
        self.budget, self.ledger = budget, ledger
        self.policy = {
            'G0_aleatoric': {'B_mel': -0.5, 'B_usr': -0.5, 'B_diag':  0.0},
            'G1_epistemic': {'B_mel': +0.5, 'B_usr': +0.3, 'B_diag': +0.5},
            'G2_shift':     {'B_mel': +1.0, 'B_usr': +1.0, 'B_diag': +0.5},
            'G3_safety':    {'B_mel': +1.0, 'B_usr': +1.0, 'B_diag': +1.0},
        }

    def allocate(self, grade, voi_est):
        for k, v in self.policy[grade].items():
            self.budget.shift(k, v)
        if grade == 'G3_safety':
            return self.budget.safe_abort()      # 安全优先，跳过成本优化
        candidates = self.budget.actions_for(grade)
        feasible = [a for a in candidates
                    if self.ledger.acc.ops() + a.est_cost <= self.ledger.cost_budget]
        if not feasible:
            return self.budget.safe_fallback(grade)  # 成本让位安全
        return max(feasible, key=lambda a: voi_est(a) - a.est_cost)
```

### IP-189 ACC（自适应保守度控制）

```python
class AdaptiveConservatismController:
    def __init__(self, kappa0=0.5, kmin=0.1, kmax=1.0, eta=0.05, rho_target=0.03):
        self.kappa = kappa0
        self.kmin, self.kmax = kmin, kmax
        self.eta, self.rho_target = eta, rho_target
        self.rho_hat = rho_target

    def update(self, alarm):
        self.rho_hat = 0.95 * self.rho_hat + 0.05 * float(alarm)
        self.kappa = float(np.clip(
            self.kappa + self.eta * (self.rho_hat - self.rho_target),
            self.kmin, self.kmax))
        return self.kappa

    def conservatism_cost(self):
        return 0.5 * (self.kappa / self.kmax) ** 2   # 递增凸

    def risk(self):
        return float(np.exp(-3 * self.kappa))         # 递减
```

### IP-190 CCA（反事实成本审计）

```python
class CounterfactualCostAuditor:
    def __init__(self, diag_buffer, ledger):
        self.buffer, self.ledger = diag_buffer, ledger

    def estimate_costs(self, threshold_fn):
        fp_samples, fn_samples = [], []
        for s, a, r, s_next, is_true_anomaly in self.buffer:
            alarm = threshold_fn(s)
            if alarm and not is_true_anomaly:
                fp_samples.append(self._realized_cost(a))
            if (not alarm) and is_true_anomaly:
                fn_samples.append(self._realized_loss(a, s_next))
        C_FP = float(np.mean(fp_samples)) if fp_samples else self.ledger.C_FP
        C_FN = float(np.mean(fn_samples)) if fn_samples else self.ledger.C_FN
        return C_FP, C_FN

    def recalibrate(self, threshold_fn):
        C_FP, C_FN = self.estimate_costs(threshold_fn)
        self.ledger.update_cost_params(C_FP, C_FN)
        return C_FP / (C_FP + C_FN)      # 新 tau*
```

### IP-192 C-SAL（成本敏感异常闭环）

```python
class CostSensitiveAnomalyLoop:
    def __init__(self, srt_dual, srad, csat, agr, acra, acc, cac, cca, ledger):
        self.srt, self.srad, self.csat = srt_dual, srad, csat
        self.agr, self.acra, self.acc = agr, acra, acc
        self.cac, self.cca, self.ledger = cac, cca, ledger

    def step(self, obs, dialogue, phi_obs, U_mel, delta_f_req, fused, xi_exec, Z_env):
        # 1. 实时流执行（复用第 61 轮 SRT-Dual）
        K_safe, EV_exec, cert = self.srt.realtime_step(delta_f_req, fused, xi_exec, Z_env)
        # 2. 残差 + 保形评分
        anchor = self.srt.usr.read_latest_anchor()[0]
        r = self.srad.residual(anchor, self.srt.usr.scene_encoder(obs),
                               self.srt.usr.intent_encoder(dialogue),
                               self.srt.usr.impedance_encoder(K_safe, cert),
                               self.srt.usr.evidence_encoder(EV_exec), phi_obs)
        s, p = self.srad.detect(r)
        # 3. 成本敏感判定（tau* = C_FP/(C_FP+C_FN)）
        alarm, pi_hat, tau = self.csat.decide(s, p)
        # 4. 分级 + 重分配 + 保守度
        grade = self.agr.grade(split_channels(r), s, U_mel, EV_exec) if alarm else 'G0_aleatoric'
        action = self.acra.allocate(grade, voi_est)
        kappa = self.acc.update(alarm)
        # 5. 记账（含误报/漏检反事实成本）
        self.ledger.charge(action, ops=action.ops, latency_ms=action.latency,
                           conservatism=self.acc.conservatism_cost())
        self.ledger.charge_decision(alarm, ground_truth_anomaly())
        # 6. 成本可证证书
        cac = self.cac.build(cert, s, pi_hat, grade, tau,
                             coverage=1 - self.srad.alpha,
                             cost=self.ledger.acc.last(), loss_ub=self.acc.risk())
        # 7. 低频反事实审计与重校准
        if self.cca.due():
            self.cca.recalibrate(self.csat.decide)
        return K_safe, grade, cac
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| UCL | O(1) 记账 / 决策 | O(7·N_hist) | 成本可加、可审计；预算-成本换算单调 |
| SRAD/MCRD | O(d_us²) 评分（预计算 Σ^{-1}） | O(5·d_us × n_cal) | 名义工况误报率 ≤ α（保形交换性） |
| CSAT | O(1) 判定 / O(n) 门限搜索 | O(1) | 成本参数已知时贝叶斯最优（期望成本最小） |
| AGR | O(1) | O(1) | G3 安全通道硬优先，安全漏检率 = 0 |
| ACRA | O(|A|) 贪心 | O(1) | 安全约束硬保证，成本超限即回退 |
| ACC | O(1) | O(1) | 异常率平稳时 κ 收敛到 κ* 邻域 |
| CCA | O(|B_diag|) 离线 | O(N_turns) | 重叠假设下成本估计误差 ≤ δ_cost |
| CAC | O(1) | O(1) | 覆盖率 ≥ 1−α 且期望损失 ≤ Û_loss |
| C-SAL | 实时流 + O(1) 检测开销 | 共享内存 ~10MB | 检测开销不阻塞实时环（< 0.1ms） |

**正确性定理（C-SAL-Complete）**：
假设 A61–A70 及
**(A71)** UCL：成本换算线性可加，预算→成本映射单调不减；
**(A72)** SRAD/MCRD：名义残差在标定与测试间可交换，分数分布连续；
**(A73)** CSAT：异常概率 π_t 校准良好（ECE ≤ 0.05），成本参数已知或经 CCA 估计且误差 ≤ δ_cost；
**(A74)** AGR：分级关于残差幅度单调，安全通道优先且覆盖统计判定；
**(A75)** ACRA：安全约束为硬约束，G3 响应独立于成本/预算；
**(A76)** CCA：诊断数据对目标策略有重叠（overlap），估计器一致。

则：
1. **成本最优检测**：在 A72–A73 下，CSAT 门限 τ* 最小化期望检测成本；当成本参数存在 δ_cost 误差时，成本 regret ≤ f(δ_cost, ECE)。
2. **分布无关误报控制**：在 A72 下，名义工况误报率 P(s > τ_α) ≤ α；α 由成本最优内生确定。
3. **安全不降级**：G3 异常永不因成本或预算耗尽而降级，安全响应延迟 ≤ τ_g3（与 C_FN 无关）。
4. **保守度收敛**：异常率平稳时，ACC 的 κ_t 收敛到 κ* 的 O(η) 邻域，且稳态满足「保守性边际成本 = 风险边际收益」。
5. **经济可证**：CAC 的期望损失上界 Û_loss 随 δ_cost 单调收紧；证书有效 ⇒ 控制安全 ∧ 监控划算。
6. **端到端**：相较第 61 轮，在同等安全水平下总成本下降，或在同等成本下漏检率下降（帕累托改进）。
