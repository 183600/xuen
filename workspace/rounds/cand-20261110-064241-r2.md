# 第 42 轮（新循环第 2 轮） · 夹爪 × 评测基准：把「可认证」从连续流推到接触事件，并用「可证伪基准」审计证书（四层架构 v7）

> 承接第 41 轮 v18（CAR × LCS × CMC，四层架构 v6）。第 41 轮把证书变成了运行期的转移守卫，但留下两个从未被检验的假设：(a) 证书边际沿轨迹 Lipschitz 连续，因此 T_hold=(m₀−θ)/L_m 有意义，且 SafeStop 总是安全；(b) 证书「够不够好」由我们自己设计的 E73–E78 判定，没有独立、对抗性的第三方审计。本轮灵感词「夹爪控制」「评测基准」恰好正击这两个假设：**夹爪**是连续运动与离散接触的接缝，也是 L_m 发散、SafeStop 会掉件的地方；**评测基准**是把「证书是不是装饰」从自证变成他证、从静态门槛变成对抗探针的唯一手段。

## 0. 直觉与动机

**灵感 1（夹爪控制 → 证书的盲区在接触面，不在自由空间）**：第 41 轮的守卫几乎都是连续几何量（距离、ValidRegion、谱范数、ODE 残差），默认边际随时间连续变化，于是有 T_hold=(m₀−θ)/L_m。但夹爪一闭合，世界换了一套物理：接触力、摩擦锥、冲量、形变。margin 在接触瞬间跳变，L_m 无界，T_hold 公式当场失效。更致命的是 SafeStop 的语义：机械臂停下最多是「不动」，夹爪停下却可能「掉件」——对一个正被夹持的物体，「停机」根本不是安全集，而是软安全集的边界。因此抓取安全的正确对象不是距离边际，而是**力闭合 / 滑移 / 挤碎 / 弹射四类接触证书**；状态机也必须扩展出接触模式（Free→Approach→Close→Grasp→Lift→Transport→Release→Regrasp/Slip）。一句话：第 41 轮证明了「不撞」，这一轮要证明「不脱手、不压碎、能救回」。

**灵感 2（评测基准 → 证书最怕的不是被证伪，而是没人认真去证伪）**：E73–E78 是「自己出题自己判卷」：证书由我们定义、实验由我们挑、反例由我们找。它无法回答两个决定性问题：(i) 证书报 ok 时是否真的安全（soundness / 漏报）；(ii) 证书报危险时是否其实安全（过保守 / 误报与可用性）。真正的评测基准应像**证明携带代码（PCC）的审计器**：每个 episode 产出可复核的「证书收据」，由独立 oracle 给出真值标签，并用**专门打证书边界**的对抗探针（摩擦突变、质量漂移、控制延迟、标定误差、遮挡）去最大化「声称安全却失败」的证伪率。基准不是排行榜，而是**证书的可证伪性机器**；过保守要和漏报一样被记为失败。

**耦合**：夹爪提供证书最难的测试面（接触/冲量/力/形变），评测基准把「最难」变成可测量、可定位、可回归的量；基准找到的反例反过来定位是哪个守卫太松或极性错，喂回 CAHA 合成与课程。二者合起来，把第 41 轮「证书可执行」推进为「证书可被独立审计，且在接触事件处仍然成立」。

## 1. 形式化定义

**定义 32（接触模式与抓取证书 GCC）**：夹爪接触自动机 G=(C,X_c,Σ_c,E_c,Inv_c)，接触模式 c∈C={Free, SingleContact, DoubleContact, FormClosure, Slip}。抓取证书为四元边际 m_g(x)=(m_fc,m_slip,m_ej,m_sq)：m_fc=min_i(μ_i f_{n,i}−|F_{t,i}|) 为摩擦锥/力闭合 slack；m_slip 为实测切向力与相对加速度下的滑移 slack；m_ej 为外部扰动下的抗弹射 slack；m_sq=f_n^max(obj)−f_n 为不压碎脆弱物体的 slack。抓取不变式 GInv={x : m_fc≥θ_fc ∧ m_slip≥θ_slip ∧ m_ej≥θ_ej ∧ m_sq≥θ_sq ∧ |J|≤J_max}。**GCC 有效**当且仅当 x∈GInv 且四边际均由 (1−δ) 置信界证得。

**定义 33（接触增广乘积自动机 H⊗G 与冲量跳变证书）**：把第 41 轮 CAHA H 与接触自动机 G 做乘积，转移在接触事件 Σ_c 上同步，守卫合取、不变式相交。接触边是**跳变**而非流：要求**冲量跳变证书**——pre 状态 x⁻∈GInv，冲量 J=∫F dt 满足 |J|≤J_max，post 状态 x⁺∈GInv。于是运行证书升级为**混合归纳不变式**：模式内流封闭（沿用 CBF/barrier）+ 接触边跳变封闭（新的 jump-closure）。**关键修正**：T_hold 只在单一模式内部有效；跨接触边必须事件触发重认证，禁止用 T_hold 外推，否则会在 L_m 发散处给出错误的「仍然有效」。

**定义 34（可恢复性证书 RAC 与可用性下界）**：给定软安全集 S_soft（不掉件、不超限碰撞）与重启集 R。恢复核 Rec_q 是最大不动点：x∈Rec_q 当且仅当 x∈S_soft 且存在控制 u，使 (a) x∈R（已可重启），或 (b) u 的后继保持在 S_soft∩Rec_q 并在时域 T 内到达 R。SafeStop 被细化为**模式相关恢复动作集** Π_q^rec（Grasp 态用 lower-and-place / clamp-and-brace，Free 态用 brake），而非单一停机。可用性下界 A≥P_{x∼D}(Rec_q(x) 且证书有效)。进一步定义**不归点集 PoNR_q=S_soft∖Rec_q**：守卫必须在进入 PoNR 之前升级——这给出了「何时必须离开 Nominal」的定量判据，直接对症第 41 轮的最大风险「可用性崩塌」。

**定义 35（可证伪证书基准 FCB 与证书收据）**：任务分布 D，扰动族 P（Δ 摩擦、Δ 质量、Δ 延迟、Δ 标定、遮挡），独立 oracle O（高保真物理 + 真机抽检）给出真值标签 y∈{0,1}。每个 episode 产出**证书收据** r=(轨迹, 边际轨迹, 档位, δ, 守卫决策, 推导链)。指标：证伪率 FR=E[1{ŷ=ok ∧ y=unsafe}]（漏报/不健全）；误报率 FAR=E[1{ŷ∈{warn,trip} ∧ y=safe}]（过保守）；预测效度 AUROC(m,y)；校准 ECE；紧致比 τ_t=m_claim/m_true（阈值处）；可用性 A；恢复成功率/时间；成本归一化 FR/FLOP。收据必须**事后可复核**：审计器验证「声称界是否真的包含实测边际」且「决策链与收据一致」。

**定义 36（证书–基准对抗对偶）**：基准在真实感约束 dist(Δ,P_real)≤ε 下搜索 Δ∈P，最大化认证间隙 G(Δ)=sup_x [m_claim(x;Δ) 判安全 ∧ y(Δ)=unsafe]。证书与基准构成 min-max：min_guard max_Δ G。测得值为**证伪裕度**；只有对抗搜索在预算 B 内无法把 G 推过阈值，证书才算通过。这把「证书边界」从我们假设安全的地方，移到基准主动攻击的地方。

**定义 37（健全–紧致–可用三难）**：固定算力 Γ，证书诱导三元组 (1−FR, 1/τ, A)。**命题（三难）**：在固定 Γ 下无法同时令 FR→0、τ→1、A→1——对抗探针会集中在薄边际状态，而收紧边际必然收缩 Nominal 覆盖。基准必须报告 Pareto 曲面，并把过保守（FAR）当作与漏报同级的一等失败，从而把第 41 轮的「安全 vs 可用」直觉升级为可测的权衡律。

**设计约束（接触单调保守性）**：接触边的守卫必须单边且模式单调——若冲量/抓取证书不可证，只允许转移到恢复模式，绝不允许转移到更高性能模式；接触模式切换加滞回，防止接触处抖动与 Zeno。

## 2. 三大产出设计

### 2.1 IP-54 GRASP-CONTACT-CERTIFICATE（GCC，抓取接触证书）
1. 接触自动机 G：五模式 + 接触检测（触觉/六维力）守卫；模式单调、带滞回。
2. 四分量抓取证书：力闭合、滑移、抗弹射、抗压碎；阈值按物体类别（脆弱度、摩擦）给定。
3. **双速率认证**：慢速抓取证书（10–50 Hz，几何 + 力闭合）⊕ 快速滑移反射（≥1 kHz，触觉），后者作为新增 T_fast 档，只允许收紧、不允许放宽。
4. **冲量证书**：接触边显式 J_max 与 jump-closure 检查，接触瞬间事件触发重认证，禁用 T_hold 外推。
5. 物体类别条件化：从语义图（IP-36）取脆弱度/摩擦先验；未知物体走保守缺省，并在基准中单独统计。

### 2.2 IP-55 RECOVERY-AVAILABILITY-CERTIFICATE（RAC，可恢复性与可用性证书）
1. 把 SafeStop 细化为模式相关恢复策略集（brake / lower-and-place / clamp-and-brace / retract），恢复本身也要证书。
2. 离线计算恢复核 Rec_q（viability/reachability），在线只做成员检查；给出可用性下界 A。
3. **不归点 PoNR**：若 x∉Rec_q 则必须在进入 PoNR 前升级；这是与 ValidRegion 互补的新安全不变式。
4. 与 IP-47 乘积自动机组合，恢复契约可独立类型检查。
5. 直接缓解第 41 轮「可用性崩塌」：从「停机」改为「证明存在安全出路」，并量化「还能救多久」。

### 2.3 IP-56 FALSIFIABLE-CERT-BENCHMARK（FCB，可证伪证书基准）
1. 任务族：pick-place、peg-in-hole、铰接物体、可形变、handover、regrasp、杂乱场景；标准化接触密集场景。
2. 扰动生成器专门瞄准证书边际；密封留出集 + 轮换自适应对抗搜索，防止刷分。
3. oracle：高保真仿真 + 真机抽检；显式报告标签不确定性与 sim-to-real 间隙。
4. 收据格式（PCE）+ 独立审计器：事后验证界包含实测、决策链自洽、δ 记账正确。
5. 指标套件：双向误差（FR/FAR）、校准、紧致、可用性、恢复、成本归一化，输出三难 Pareto。
6. **基准元证书**：oracle 间隙、标签噪声、抗污染、刷分检测器（比对声称与实测边际，识别「边际注水」）。

## 4. 实验设计（E79–E84 硬门槛）

| 实验 | 指标 | 门槛 |
|---|---|---|
| E79 抓取证书健全性 | 密封探针上 FR、AUROC、ECE | FR<0.1%；AUROC≥0.90；ECE<0.05 |
| E80 接触决策等价 | 轻量=全量决策的接触迁移拍占比；重认证 p99 | ≥99%；p99<2ms |
| E81 恢复与可用性 | Nominal 占比、恢复成功率/时间、恢复期掉件率 | Nominal≥70%；≥95%；<2s；<0.5% |
| E82 基准可审计性 | 收据复核通过率、可复现性、污染检测 | ≥99.9%；逐位可复现；可检出 |
| E83 跨物体/跨本体迁移 | 性能跌幅、未知物体不安全事件 | 跌幅<15%；0 起 |
| E84 对抗鲁棒与三难 Pareto | 自适应攻击下 FR 增量、Pareto 支配、FAR | 增量<0.5%；支配静态边际基线；FAR<5% |

回退路径：E79 不通过（接触证书不可证）→ 放弃形式化抓取证书，保留 FCB 作为纯基准 + 经验滑移检测；E81 不通过（恢复核过小）→ 扩大恢复动作集/增加模式，但不放弃形式化；E84 不通过（对抗可破）→ 诚实收缩声明范围到「已认证子集」，并公开 Pareto，不用平均分掩盖。

## 5. 本轮最大风险

**一句话**：最危险的不是接触证书不可证，而是**评测基准本身不可信、且会被当成新的刷分目标**——若 oracle 真值与探针分布有偏，证书审计会退化为「对基准过拟合」，把漏报或过保守藏进测试集；因此密封留出集、双向误差（FR 与 FAR）与真机抽检必须同时守门。

## 2. 关键算法（伪代码）

### IP-54 GCC：接触模式 + 抓取/冲量证书
```
def contact_certify(x, mode, obj, budget):
    b = grasp_margins(x, obj)                    # 慢档：几何+力闭合+抗压碎
    if not all(m >= theta[mode][k] for k, m in b.items()):
        return RECOVER(mode, x)                  # 抓取失败→恢复，不是停机
    for j in [0, 1, 2, 3]:                       # anytime 精化（沿用 IP-52）
        b = tier_j(x, obj); 
        U = {e for e in contact_guards(mode) if lo(b,e) < 0 < hi(b,e)}
        if not U: return b, j
        if over_budget(budget): return downgrade_monotone(b)
    return b, 3

def contact_edge_ok(x_minus, J, x_plus):
    return in_GInv(x_minus) and norm(J) <= J_max and in_GInv(x_plus)

def slip_reflex(tactile_stream):                # T_fast，≥1kHz，只收紧
    return TRIP if tactile_slip_conf(tactile_stream) > tau else OK
```

### IP-55 RAC：恢复核与不归点
```
def recovery_kernel(HG, T):
    Rec = {q: S_soft[q] for q in HG.Q}
    while True:
        new = {q: {x in S_soft[q] :
                   x in R[q] or exists u:
                     succ(x,u) subset S_soft[q] & Rec[q]
                     and reaches(R[q], T)} for q in HG.Q}
        if new == Rec: return Rec
        Rec = new

def guard_step(x, q):
    if x not in Rec[q]:                          # 已进入不归点
        return EscalateEarly(q)                  # 提前升级，争取恢复窗口
    return NormalGuard(x, q)

def availability_lower_bound(D, Rec):
    return mean(x in Rec[q(x)] and cert_valid(x) for x in sample(D))
```

### IP-56 FCB：收据审计 + 对抗探针 + 三难报告
```
def run_episode(policy, cert, task, perturb):
    traj, receipt = rollout(policy, cert, task, perturb)
    y = oracle(task, perturb, traj)              # 独立高保真/真机标签
    return traj, receipt, y

def audit(receipt, traj):
    # 收据自洽：声称界必须包含实测边际，决策链与收据一致
    return all(contains(receipt.bound[t], traj.margin[t])
               for t in traj) and decision_consistent(receipt, traj)

def metrics(episodes):
    FR  = mean(r.claimed_ok and not y for r, y in episodes)
    FAR = mean(r.claimed_bad and y for r, y in episodes)
    return dict(FR=FR, FAR=FAR,
                AUROC=auroc(margins, labels), ECE=ece(probs, labels),
                tightness=tight_ratio(episodes), A=nominal_occupancy(episodes),
                recovery=recovery_stats(episodes),
                cost_norm=FR / total_flops(episodes))

def adversarial_probe(cert, P, budget):
    # 真实感约束下最大化认证间隙；预算 B 内破不了才算通过
    return argmax_{Delta in P, dist(Delta, P_real) <= eps} gap(cert, Delta)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 正确性保证 |
|---|---|---|
| IP-54 接触证书 | 每拍 O(接触数) + 触觉 O(1)；慢档 T0–T3 | 四边际 sound ⟹ 接触期不脱手/不压碎 |
| IP-54 冲量证书 | 接触边 O(1) 检查 | jump-closure ⟹ 接触跳变后仍在 GInv |
| IP-55 恢复核 | 离线 O(\|S_soft\|·\|U\|·T)（网格/抽象）；在线 O(1) | Rec 为最大不动点 ⟹ 存在安全恢复策略；A 为下界 |
| IP-55 PoNR | 在线成员检查 | 进入 PoNR 前升级 ⟹ 不会「停在掉件状态」 |
| IP-56 审计 | 每 episode O(长度) | 收据自洽 + 界包含实测 ⟹ 声称可复核 |
| IP-56 对抗探针 | 预算 B 内搜索 | 破不了阈值才通过；否则报告证伪裕度 |
| 三难 Pareto | 报告级 O(实验数) | 固定 Γ 下不可同时最优（命题 37） |

## 4. 实验设计（E79–E84，硬门槛）

| 实验 | 指标 | 门槛 |
|---|---|---|
| E79 抓取证书健全性 | 密封探针 FR、AUROC、ECE | FR<0.1%；AUROC≥0.90；ECE<0.05 |
| E80 接触决策等价 | 轻量=全量决策的接触迁移拍占比；重认证 p99 | ≥99%；p99<2ms |
| E81 恢复与可用性 | Nominal 占比、恢复成功率/时间、恢复期掉件率 | Nominal≥70%；≥95%；<2s；<0.5% |
| E82 基准可审计性 | 收据复核通过率、可复现性、污染检测 | ≥99.9%；逐位可复现；可检出 |
| E83 跨物体/跨本体迁移 | 性能跌幅、未知物体不安全事件 | 跌幅<15%；0 起 |
| E84 对抗鲁棒与三难 Pareto | 自适应攻击 FR 增量、Pareto 支配、FAR | 增量<0.5%；支配静态边际基线；FAR<5% |

回退路径：E79 不通过 → 放弃形式化抓取证书，保留 FCB 作纯基准 + 经验滑移检测；E81 不通过 → 扩大恢复动作集/增加模式，但不放弃形式化；E84 不通过 → 收缩声明到「已认证子集」，公开 Pareto，不用平均分掩盖。

## 5. 风险与缓解

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 基准不可信 / 被刷分：对 FCB 过拟合 | 高 | 密封留出集 + 轮换对抗探针 + 真机抽检；报告 oracle 间隙与标签噪声；刷分检测器比对声称/实测边际 |
| 接触证书不可证（形变、未知物体） | 高 | 物体类别先验 + 保守缺省；经验滑移反射兜底；未知物体单独统计，不用均值掩盖 |
| 恢复核过小 → 仍可用性崩塌 | 高 | 扩大恢复动作集、增加模式；PoNR 提前升级；E81 以 Nominal 与恢复率双守门 |
| 冲量/触觉噪声导致误 trip | 中 | 单边可靠 + 滞回 + 触觉去抖；T_fast 只收紧 |
| 接触处抖动/Zeno | 中 | 接触模式滞回 + τ_min + 事件优先于时间触发 |
| 三难被单点指标掩盖 | 中 | 强制报告 Pareto 与双向误差；过保守记为一等失败 |
| 收据/δ 记账出错 | 低-中 | 独立审计器 + 形式化 δ 组合；逐位可复现 |

## 6. 本轮最大风险

**一句话**：最危险的不是接触证书不可证，而是**评测基准本身不可信且会被当成新的刷分目标**——若 oracle 真值与探针分布有偏，证书审计会退化为「对基准过拟合」，把漏报或过保守藏进测试集；因此密封留出集、双向误差（FR 与 FAR）与真机抽检必须同时守门。
