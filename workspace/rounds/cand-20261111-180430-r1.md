# 第 56 轮（承接第 55 轮 v16 GroundEdge-GenSim++++；新一轮灵感循环第 3 轮；本轮灵感：「最优控制」×「分布外泛化」）

> 第 55 轮把证书做成「带漂移界、可复检、可巩固的活证书」。本轮再往前推一步：**证书不是一次性承诺，而是一个在分布漂移下持续做决策的闭环控制系统**。引入两个新变量：**最优控制**让“何时查询、何时部署、何时回滚、何时弃权”成为可求解的带约束决策；**分布外泛化**让“证书在什么分布范围内为真”成为可计算的**有效域**，而不是默认的“训练分布附近”。核心矛盾：**H25**：活证书只审计“是否过期”，却没有最优调度，导致仿真查询预算与部署风险之间的配置次优；**H26**：静态证书的 soundness 只在 `P_in` 邻域成立，OOD 下有效域未知，泛化界与证书签发脱节；**H27**：鲁棒性、查询、回滚彼此耦合，过度保守会冻结可用技能，过度乐观会在 OOD 上静默失效，必须用 min-max 闭环而非单边阈值治理。

## 0. 直觉与动机

**灵感 1（证书签发是开环，部署是闭环 → 把证书生命周期写成最优控制问题）**
直觉：第 55 轮的 `ECTC` 回答的是“这张证书现在还不新鲜、还成不成立”，但它不回答“现在应不应该花 10 次仿真去复检，还是先部署 1 个低风险技能，还是直接弃权”。把部署过程看成离散时间系统：状态 `x_t = (C^{(t)}, P̂_t, b_t, e_t)`（证书快照、任务分布估计、查询预算、漂移证据），控制 `u_t ∈ U = {deploy, query, reprofile, rollback, abstain}`。于是证书治理变成 **带安全约束的有限时域最优控制**，而不是一组手写 if-else 阈值。

**灵感 2（OOD 泛化是“证书的有效域”问题 → 从点证书到分布鲁棒证书）**
直觉：任何经验证书都只对训练分布 `P_in` 的邻域可信。用 Wasserstein 球 `B_ε(P_in)` 表示允许的分布漂移，则证书不应只承诺“在 `P_in` 上风险低”，而应承诺“**在球内最坏分布上风险仍低**”。这把 OOD 泛化从“再训练一个更鲁棒的模型”变成“给每张证书标注一个可计算的有效半径 `ε*`”：球内可部署，球外必须弃权或重签。

**灵感 3（最坏分布是对手 → 最优控制变成 min-max 博弈）**
直觉：分布鲁棒证书的内部是 `sup_{Q∈B_ε}`，部署控制器要在这个对手存在时最小化“风险 + 查询成本 + 回滚成本”。这正是鲁棒最优控制 / H∞ 的结构：控制器不是对某个点分布最优，而是对模糊集内最坏转移最优。好处是证书与控制器共享同一个对抗模型，避免“证书按均值评估、控制器按最坏情况执行”的口径撕裂。

**灵感 4（不是所有状态都救得回来 → 可存活性核与弃权语义）**
直觉：当漂移证据已经很强、预算耗尽、或技能图被 OOD 剪断到无法覆盖任务时，任何控制都维持不了证书有效。与其让控制器在不可行域里“硬优化”，不如先算 **可存活性核 `K`**：从 `K` 内出发存在控制序列使证书一直有效。`x_t ∉ K` 时唯一合法动作是 `abstain`（或降级到低风险子任务），这给“弃权”一个形式化、可证明的语义。

**灵感 5（运行时不重规划大步，只做最小干预 → 控制屏障证书过滤器）**
直觉：云端的 MPC 给出 nominal 动作，边端不应每次都重新解全局最优控制；更合理的是给证书定义安全函数 `h(x) ≥ 0`，运行时只解一个最小干预 QP：在满足 `h(x_{t+1}) ≥ (1-κ)h(x_t)` 的动作里，选离 nominal 最近的。这把第 54/55 轮的证书从“事后审计”变成“事前安全过滤”，且干预量可度量。

**灵感 6（查询是最贵的控制量 → 主动证书信息价值）**
直觉：仿真/边端试验是预算约束下最稀缺的资源。用 **证书信息价值** `VoI(q|x) = (V(x) - E[V(x')|q]) / cost(q)` 来选择下一次查询：优先查那些最可能改变控制决策（部署↔弃权、组合↔拒绝）的样本，而不是均匀采样。这把“主动剖面采样”“反例价值筛选”统一到同一个最优控制的价值函数下。

**灵感 7（技能图也要随分布收缩 → 分布鲁棒技能图）**
直觉：第 54 轮的 `compat` 与第 55 轮的动态图都以 `P_in` 统计量为准。OOD 下应把边权改成 **模糊集上的最坏兼容性/最坏风险**，得到随 `ε` 单调收缩的图 `G_S^{ε}`。有效域越小，图越稀疏，组合越保守；这把“OOD 泛化”直接投影到技能组合的可判定性上。

## 1. 形式化定义（增量：定义 131–140）

**定义 131（证书部署闭环系统）**
状态 `x_t = (C^{(t)}, P̂_t, b_t, e_t)`：证书快照（定义 122）、分布估计、剩余查询预算、漂移证据。控制 `u_t ∈ U = {deploy, query, reprofile, rollback, abstain}`。转移
```
x_{t+1} = f(x_t, u_t, w_t),   w_t ~ Q_t
```
其中 `Q_t` 为当前真实任务分布，`f` 由证书更新、图复检、预算消耗与漂移观测复合而成。单步代价
```
c(x,u) = 1[u=deploy]·risk(x) + λ_q·cost(query) + λ_r·cost(rollback) + λ_a·1[u=abstain]
```

**定义 132（证书风险泛函）**
对策略 `π` 与任务分布 `Q`，部署风险
```
R(Q;π) = E_{o~Q}[ ℓ(π(o)) ]
```
`ℓ` 为任务损失（成功率或安全违例指示）。经验风险记 `R̂(P̂;π)`。

**定义 133（证书有效域与有效半径）**
以 `P_in` 为中心、Wasserstein 半径为 `ε` 的模糊集 `B_ε(P_in) = {Q : W_1(Q,P_in) ≤ ε}`。策略 `π` 的证书在 `ε` 下有效当且仅当
```
DRC_ε(π) := sup_{Q∈B_ε(P_in)} R(Q;π) ≤ ρ_min
```
有效半径 `ε*(π) = sup{ ε : DRC_ε(π) ≤ ρ_min }`。**只有 `ε ≤ ε*(π)` 的 OOD 任务允许引用该证书。**

**定义 134（分布鲁棒证书 DRC）**
```
DRC_ε(π; P̂) = sup_{Q: W_1(Q,P̂) ≤ ε} R(Q;π)
```
用 Kantorovich 对偶估计：
```
DRC_ε(π;P̂) = inf_{λ≥0} { λε + E_{P̂}[ sup_{z} ( ℓ(π(z)) - λ·d(z,·) ) ] }
```
部署条件：`DRC_ε(π;P̂) + conf(n,δ) ≤ ρ_min` 且 `ε ≤ ε*(π)`。

**定义 135（OOD 泛化界 → 证书半径）**
若 `ℓ∘π` 关于输入是 `L`-Lipschitz，则以概率 `1-δ`：
```
R(Q;π) ≤ R̂(P̂;π) + L·W_1(Q,P̂) + sqrt( log(1/δ) / (2n) )
```
给定目标 `ρ_min`，可反解出可签发的最大漂移半径
```
ε_cert = ( ρ_min - R̂ - sqrt(log(1/δ)/(2n)) ) / L
```
`ε_cert` 与定义 133 的 `ε*` 取较小者作为证书上标注的有效半径。

**定义 136（证书最优控制问题）**
有限时域 `H` 上
```
min_{u_{0:H-1}}  E[ Σ_{k=0}^{H-1} c(x_k,u_k) + V_H(x_H) ]
s.t.  DRC_{ε_k}(π_k) ≤ ρ_min,   b_k ≥ 0,   x_{k+1}=f(x_k,u_k,w_k)
```
值函数 `V(x) = min_u { c(x,u) + E_w[ V(f(x,u,w)) ] }`。MPC-C 每次只执行首个控制，滚动重解。

**定义 137（可存活性核）**
```
K_0 = { x : DRC_ε(π) ≤ ρ_min }
K_{i+1} = { x ∈ K_i : ∃u∈U, ∀w∈W, f(x,u,w) ∈ K_i }
K = lim_{i→∞} K_i
```
`x ∉ K` 时不允许 `deploy/query` 之外的乐观控制，只能 `abstain` 或降级到低风险子任务。

**定义 138（控制屏障证书与最小干预过滤器）**
安全集 `S = {x : h(x) ≥ 0}`，离散控制屏障条件
```
h(x_{k+1}) ≥ (1-κ)·h(x_k),  κ∈(0,1]
```
运行时过滤器
```
u* = argmin_{u∈U} ||u - u_nom||²
     s.t. h(f(x,u,w)) ≥ (1-κ)h(x), x∈S
```
若可行集为空，则输出 `abstain`。

**定义 139（证书信息价值 VoI）**
候选查询 `q` 的信息价值
```
VoI(q|x) = ( V(x) - E_{y~q}[ V(x') ] ) / cost(q)
```
下一次查询取 `argmax_q VoI(q|x)`，并受预算 `b_t` 约束。

**定义 140（分布鲁棒技能图）**
```
G_S^{ε} = (V, E_ε),  (i,j)∈E_ε ⇔ sup_{Q∈B_ε} compat_Q(S_i,S_j) ≥ θ_a
                            ∧ sup_{Q∈B_ε} c_trans,Q(S_i,S_j) ≤ τ_e
                            ∧ DRC_ε(S_i⊗S_j) ≤ ρ_min
```
`G_S^{ε}` 随 `ε` 增大单调删边；任务在图上不可达时触发 `reprofile` 或 `abstain`。

## 2. 关键算法 伪代码

### IP-128 DROC（Distributionally Robust Optimal Certification）

```python
def dro_risk(loss, samples, eps, dist, dual_iters=50):
    # Kantorovich dual: sup_{Q:W1(Q,P_hat)<=eps} E_Q[loss]
    lam = 0.0
    for _ in range(dual_iters):
        # inner: 每个样本对最坏扰动的损失
        inner = [
            max(loss(z) - lam*dist(z, s) for z in samples)
            for s in samples
        ]
        lam = solve_dual_step(mean(inner), eps)   # λ ← argmin λε + E[max(...)]
    return lam*eps + mean(inner)

def certify(pi, P_hat, eps, loss, rho_min, delta):
    drc = dro_risk(loss, P_hat.samples, eps, P_hat.dist)
    conf = sqrt(log(1/delta) / (2*len(P_hat.samples)))
    return ('ok' if drc + conf <= rho_min else 'reject', drc, conf)
```

### IP-129 CVS（Certificate Validity Set）

```python
def validity_radius(pi, P_hat, shifted_sets, rho_min, delta):
    # 二分搜索最大 ε 使 DRC 仍在预算内
    lo, hi = 0.0, initial_upper_bound(P_hat, shifted_sets)
    while hi - lo > 1e-3:
        mid = 0.5*(lo+hi)
        ok, drc, conf = certify(pi, P_hat, mid, pi.loss, rho_min, delta)
        # 在 shifted_sets 上做经验校准，防止只信对偶界
        calib = max(empirical_risk(pi, Q) for Q in shifted_sets
                    if wasserstein(Q, P_hat) <= mid)
        if ok == 'ok' and calib <= rho_min:
            lo = mid
        else:
            hi = mid
    return lo
```

### IP-130 OCB（OOD Certificate Bound）

```python
def ood_certificate_bound(pi, P_hat, Q_shift, delta):
    L = lipschitz_const(pi.loss, pi.policy)
    w = wasserstein_1(Q_shift, P_hat)
    emp = empirical_risk(pi, P_hat)
    conf = sqrt(log(1/delta)/(2*len(P_hat.samples)))
    upper = emp + L*w + conf
    eps_cert = max(0.0, (pi.rho_min - emp - conf) / max(L, 1e-12))
    return upper, eps_cert
```

### IP-131 MPC-C（Model Predictive Certification）

```python
def mpc_certify(x0, H, U, budget, rho_min, epsilon, model):
    best = None
    for u_seq in control_sequences(U, H, budget):   # 分支定界 + 预算剪枝
        x, cost, feasible = x0, 0.0, True
        for k, u in enumerate(u_seq):
            if not within_budget(x, u, budget): feasible = False; break
            if dro_risk(model.loss, model.samples, epsilon, model.dist) > rho_min:
                feasible = False; break
            cost += c(x, u) + model.uncertainty_penalty(x, u)
            x = model.predict(x, u)
        if feasible and (best is None or cost < best.cost):
            best = (u_seq, cost, x)
    return best[0][0] if best else 'abstain'
```

### IP-132 CBF-F（Control Barrier Certificate Filter）

```python
def cbf_filter(x, u_nom, h, model, kappa):
    best, best_dev = None, float('inf')
    for u in model.controls(x):
        x_next = model.predict(x, u)
        if h(x_next) >= (1-kappa)*h(x) and h(x_next) >= 0:
            dev = norm(u - u_nom)
            if dev < best_dev:
                best, best_dev = u, dev
    return best if best is not None else 'abstain'
```

### IP-133 ACI（Active Certificate Information）

```python
def active_certify(x, candidates, V, budget, theta_voi):
    while budget > 0:
        scored = [(voi(q, x, V), q) for q in candidates if feasible(q, x)]
        if not scored: break
        val, q = max(scored)
        if val < theta_voi: break
        y = run_query(q)
        x = update_state(x, q, y)
        budget -= cost(q)
        candidates = candidates_after(q, x)
    return x
```

### IP-134 DRG（Distributionally Robust Skill Graph）

```python
def build_robust_graph(skills, eps, theta_a, tau_e, rho_min, P_hat):
    G = nx.DiGraph()
    for i, s1 in enumerate(skills):
        for j, s2 in enumerate(skills):
            if i == j: continue
            compat_w = sup_over_ball(lambda Q: compat_Q(s1,s2,Q), P_hat, eps)
            trans_w  = sup_over_ball(lambda Q: c_trans_Q(s1,s2,Q), P_hat, eps)
            drc      = dro_risk(compose_loss(s1,s2), P_hat.samples, eps, P_hat.dist)
            if compat_w >= theta_a and trans_w <= tau_e and drc <= rho_min:
                G.add_edge(i, j, compat=compat_w, cost=trans_w,
                           drc=drc, eps=eps)
    return G
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| DROC | O(I_dual·n·|A|) | O(n) | 对偶收敛、模糊集包含真分布 |
| CVS | O(log(1/δ)·n·|A|) | O(n) | 二分单调、经验校准不越界 |
| OCB | O(n·|A|) | O(n) | 损失 Lipschitz、漂移可估 |
| MPC-C | O(|U|^H·|A|)（剪枝后近似线性） | O(H·|A|) | 模型误差有界、预算剪枝 sound |
| CBF-F | O(|A|²)（QP） | O(|A|) | `h` 为有效屏障、可行集非空判定 |
| ACI | O(|Q|·|A|·log|Q|) | O(|Q|) | VoI 排序、预算单调 |
| DRG | O(|S|²·|A|·n) | O(|S|²+n) | 最坏兼容性上界、ε 单调删边 |

**正确性定理（Distributionally Robust Closed-loop Certificate Soundness）**
承接第 55 轮 (A29)–(A32)，新增：**(A33)** `f` 的模型误差有界 `||f-f̂|| ≤ δ_f`；**(A34)** 真实 OOD 分布落入所用模糊集，或漂移检测以概率 `1-γ_d` 报告越界；**(A35)** `ℓ∘π` 为 `L`-Lipschitz；**(A36)** DRO 对偶估计偏差 `≤ δ_dual`；**(A37)** `h` 为有效控制屏障且过滤 QP 可行时保持 `S` 前向不变；**(A38)** 可存活性核以容差 `δ_K` 计算。则闭环部署的 OOD 失败概率满足
```
P_fail ≤ P(x_0 ∉ K) + P(∃t: Q_t ∉ B_{ε_t}(P_in)) + T·δ_f
         + T·δ_dual + (R̂ + L·ε_cal + conf) - ρ_min + γ_d + δ_K + β_E
```
直观含义：**只要初始状态在可存活性核内、真实分布不逃出证书有效域、且模型/对偶误差被预算吸收，控制器就不会把“对训练分布最优”误当成“对 OOD 安全”**。反之，任何一项失守，证书的有效半径就是假的。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 模糊集过小导致“假安全” | 高 | 多中心模糊集 + 漂移检测 + 红队 OOD |
| 模糊集过大导致过度弃权 | 高 | 分层 ε（按任务/本体）+ 保守度预算 |
| MPC 模型误差累积 | 高 | 鲁棒 tube MPC + 在线系统辨识 + 回滚 |
| CBF 在离散动作下不可行 | 中 | 松弛 QP + 降级动作集 + 弃权兜底 |
| DRO 对偶估计高方差 | 中 | 对偶早停 + 经验校准 + bootstrap 置信 |
| 可存活性核计算爆炸 | 中 | 抽象状态聚合 + 近似核 + 离线缓存 |

## 6. 本轮最大风险

**一句话**：把证书治理升级为「分布鲁棒最优控制」后，系统的安全性不再取决于某张证书是否新鲜，而取决于**模糊集是否真的包住 OOD、模型 `f̂` 是否配得上控制器、以及可存活性核是否算对**；一旦真实漂移落在模糊集之外或仿真模型在极限动作处系统性偏差，最优控制器会“对着错误的对手做最优”，把证书有效半径变成自信的幻觉，因此必须以**漂移在线检测 + 鲁棒 tube 约束 + 核外强制弃权**三重护栏兜底，宁可少部署，也绝不让优化器替分布漂移背书。

# 第 56 轮产物 · 创新点清单 v33：GroundEdge-GenSim+++++（DROC×CVS×OCB×MPC-C×CBF-F×ACI×DRG）

> 承接第 55 轮产物 v32（CDA×CLS×EAR×SGR×RCT×ECTC）。本轮把「活证书」升级为 **分布鲁棒、闭环最优控制、可弃权** 的证书治理体系：
> - **DROC（Distributionally Robust Optimal Certification）**：模糊集上最坏风险约束下的证书签发；
> - **CVS（Certificate Validity Set）**：证书有效域与有效半径 `ε*` 的校准；
> - **OCB（OOD Certificate Bound）**：Lipschitz 泛化界反解证书可签发半径 `ε_cert`；
> - **MPC-C（Model Predictive Certification）**：证书生命周期的滚动时域最优调度；
> - **CBF-F（Control Barrier Certificate Filter）**：边端最小干预安全过滤与弃权兜底；
> - **ACI（Active Certificate Information）**：VoI 驱动的主动查询与样本高效认证；
> - **DRG（Distributionally Robust Skill Graph）**：随 `ε` 单调收缩的鲁棒技能组合图。
>
> IP 编号：IP-128~IP-134（共 7 个新增），升级 IP-121/124/126/127 以纳入 OOD 有效域与最优控制维度。

## 2. 关键算法 伪代码

### IP-128 DROC

```python
def dro_risk(loss, samples, eps, dist, dual_iters=50):
    lam = 0.0
    for _ in range(dual_iters):
        inner = [max(loss(z) - lam*dist(z, s) for z in samples)
                 for s in samples]
        lam = solve_dual_step(mean(inner), eps)
    return lam*eps + mean(inner)

def certify(pi, P_hat, eps, rho_min, delta):
    drc = dro_risk(pi.loss, P_hat.samples, eps, P_hat.dist)
    conf = sqrt(log(1/delta) / (2*len(P_hat.samples)))
    if drc + conf <= rho_min:
        return ('ok', DRCert(pi, eps, drc, conf))
    return ('reject', drc, conf)
```

### IP-129 CVS

```python
def validity_radius(pi, P_hat, shifted_sets, rho_min, delta):
    lo, hi = 0.0, initial_upper_bound(P_hat, shifted_sets)
    while hi - lo > 1e-3:
        mid = 0.5*(lo + hi)
        ok, drc, conf = certify(pi, P_hat, mid, rho_min, delta)
        calib = max(empirical_risk(pi, Q) for Q in shifted_sets
                    if wasserstein(Q, P_hat) <= mid)
        if ok == 'ok' and calib <= rho_min:
            lo = mid
        else:
            hi = mid
    return lo
```

### IP-130 OCB

```python
def ood_certificate_bound(pi, P_hat, Q_shift, delta):
    L = lipschitz_const(pi.loss, pi.policy)
    w = wasserstein_1(Q_shift, P_hat)
    emp = empirical_risk(pi, P_hat)
    conf = sqrt(log(1/delta)/(2*len(P_hat.samples)))
    upper = emp + L*w + conf
    eps_cert = max(0.0, (pi.rho_min - emp - conf) / max(L, 1e-12))
    return upper, eps_cert
```

### IP-131 MPC-C

```python
def mpc_certify(x0, H, U, budget, rho_min, epsilon, model):
    best = None
    for u_seq in control_sequences(U, H, budget):   # 分支定界 + 预算剪枝
        x, cost, feasible = x0, 0.0, True
        for u in u_seq:
            if not within_budget(x, u, budget):
                feasible = False; break
            if dro_risk(model.loss, model.samples, epsilon, model.dist) > rho_min:
                feasible = False; break
            cost += c(x, u) + model.uncertainty_penalty(x, u)
            x = model.predict(x, u)
        if feasible and (best is None or cost < best.cost):
            best = (u_seq, cost, x)
    return best[0][0] if best else 'abstain'
```

### IP-132 CBF-F

```python
def cbf_filter(x, u_nom, h, model, kappa):
    best, best_dev = None, float('inf')
    for u in model.controls(x):
        x_next = model.predict(x, u)
        if h(x_next) >= (1-kappa)*h(x) and h(x_next) >= 0:
            dev = norm(u - u_nom)
            if dev < best_dev:
                best, best_dev = u, dev
    return best if best is not None else 'abstain'
```

### IP-133 ACI

```python
def active_certify(x, candidates, V, budget, theta_voi):
    while budget > 0:
        scored = [(voi(q, x, V), q) for q in candidates if feasible(q, x)]
        if not scored: break
        val, q = max(scored)
        if val < theta_voi: break
        y = run_query(q)
        x = update_state(x, q, y)
        budget -= cost(q)
        candidates = candidates_after(q, x)
    return x
```

### IP-134 DRG

```python
def build_robust_graph(skills, eps, theta_a, tau_e, rho_min, P_hat):
    G = nx.DiGraph()
    for i, s1 in enumerate(skills):
        for j, s2 in enumerate(skills):
            if i == j: continue
            compat_w = sup_over_ball(lambda Q: compat_Q(s1,s2,Q), P_hat, eps)
            trans_w  = sup_over_ball(lambda Q: c_trans_Q(s1,s2,Q), P_hat, eps)
            drc      = dro_risk(compose_loss(s1,s2), P_hat.samples, eps, P_hat.dist)
            if compat_w >= theta_a and trans_w <= tau_e and drc <= rho_min:
                G.add_edge(i, j, compat=compat_w, cost=trans_w, drc=drc, eps=eps)
    return G
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| DROC | O(I_dual·n·|A|) | O(n) | 对偶收敛、模糊集包含真分布 |
| CVS | O(log(1/δ)·n·|A|) | O(n) | 二分单调、经验校准不越界 |
| OCB | O(n·|A|) | O(n) | 损失 Lipschitz、漂移可估 |
| MPC-C | O(|U|^H·|A|)（剪枝后近线性） | O(H·|A|) | 模型误差有界、预算剪枝 sound |
| CBF-F | O(|A|²) | O(|A|) | `h` 有效屏障、可行集非空判定 |
| ACI | O(|Q|·|A|·log|Q|) | O(|Q|) | VoI 排序、预算单调 |
| DRG | O(|S|²·|A|·n) | O(|S|²+n) | 最坏兼容性上界、ε 单调删边 |

**正确性定理（Distributionally Robust Closed-loop Certificate Soundness）**
承接第 55 轮 (A29)–(A32)，新增 **(A33)** 模型误差 `||f-f̂||≤δ_f`；**(A34)** 真实 OOD 分布落入模糊集，或漂移检测以 `1-γ_d` 报告越界；**(A35)** `ℓ∘π` 为 `L`-Lipschitz；**(A36)** DRO 对偶偏差 `≤δ_dual`；**(A37)** `h` 为有效控制屏障且 QP 可行时保持前向不变；**(A38)** 可存活性核以 `δ_K` 计算。则
```
P_fail ≤ P(x_0 ∉ K) + P(∃t: Q_t ∉ B_{ε_t}(P_in)) + T·δ_f
         + T·δ_dual + (R̂ + L·ε_cal + conf) - ρ_min + γ_d + δ_K + β_E
```
关键：**初始状态在核内**、**真实分布不逃出有效域**、**模型/对偶误差被预算吸收**；三者缺一，证书的有效半径就是虚标。

## 6. 本轮最大风险

**一句话**：把证书治理升级为「分布鲁棒最优控制」后，系统的安全性不再取决于某张证书是否新鲜，而取决于**模糊集是否真的包住 OOD、模型 `f̂` 是否配得上控制器、以及可存活性核是否算对**；一旦真实漂移落在模糊集之外或仿真模型在极限动作处系统性偏差，最优控制器会“对着错误的对手做最优”，把证书有效半径变成自信的幻觉，因此必须以**漂移在线检测 + 鲁棒 tube 约束 + 核外强制弃权**三重护栏兜底，宁可少部署，也绝不让优化器替分布漂移背书。
