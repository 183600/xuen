# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「消融实验」×「柔顺控制」）

> R69 让闭环学会了「问」，却把两个更根本的问题留在了原地。
>
> 第一，**架构在膨胀，但没人证明每一层还活着**。从 R66 到 R69，每轮都在「加层」：+FMP、+AUD、+MINT、+CIA、+FMA、+MCG……每个新层都要求被信任，却从未证明「去掉它，决策真的会变」。这是**信任蠕变（trust creep）**：系统真正的风险不是某个已知的坏模块，而是一堆**从未被证伪、也从未被证明有用**的模块越堆越高。R69 自己都把最大风险押在「模态分布是否可信」上——可它没有任何机制去检测「某个模块其实早就死了」。
>
> 第二，**R69 对「模型不可信」的回应，本质上仍然是在「断言」**。R68 说「收紧」（仍相信自己知道该往哪收），R69 说「去问」（仍相信自己知道该问什么、且回答值得信）。但当真值不可得、模型已被证明在骗你（FMA 报警）时，任何基于信念的断言——包括「去问」——都可能是错的。此刻系统缺的不是更多信息，而是一种**不依赖信念的安全姿态**。
>
> 本轮两个灵感正好补上：
> - **消融实验**给出认识论工具：一个部件是否真实，不看它「在不在」，而看**去掉它、结果变不变**（do 算子 / 因果干预）。把消融从「论文第八节的仪式」升级为**在线、带证书的治理机制**：任何想获得执行权的模块，必须持续证明自己的边际因果贡献；否则自动降权为「只观测、不执行」。
> - **柔顺控制**给出物理工具：与其**刚性断言**一条轨迹，不如用有界阻抗**让步**。被动性（passivity）把安全变成**不依赖模型**的性质——环境怎么推都不会失稳；同时，柔顺接触是**不可伪造的证据通道**：力与位移服从物理，人可以撒谎，牛顿定律不会。
>
> 核心命题：**从「加法架构」转向「可证伪架构」。每一层必须在柔顺安全包络内，用在线消融持续证明自己是承力的（load-bearing），否则失去执行权；而当模型被判定不可信时，响应从 R68 的「收紧」、R69 的「追问」升级为「柔顺」——放弃断言，让世界来纠正自己。** 命名 **FLEX-RAS**（Falsifiable Layered EXecution under compliant passivity）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我这一层，凭什么还在发号施令**」——不确定性不只该被测量、被询问，还该被**证伪**；纠正不只来自提问，也来自**让步**。

## 0. 直觉与动机

**灵感 1（消融 = 因果，不是报告）**
直觉：一个模块「在」不等于它「有用」。R69 的 FLUID 闭环把六个组件串起来，可如果 AUD 的输出被 MCG 门控悄悄短路、或 FMA 的第二意见从未改变过任何决策，它就是一个**装饰**——既增加延迟又扩大攻击面，还让运维误以为有一层保护。唯一的诚实检验是干预：去掉它看结果变不变。离线消融不够：部署分布会漂移，昨天承力的模块今天可能是僵尸。所以消融必须在**在线**做。但运行时直接删掉一个安全模块本身就不安全——这正是柔顺控制介入的地方。

**灵感 2（柔顺 = 可纠错，且证据不可伪造）**
直觉：刚性位置控制是一种「断言」——我说机械臂在 x，世界就必须让开。柔顺/阻抗控制则是一种「对话」——我用有限的刚度去推世界，世界也反过来推我。这一让步带来两件珍稀的东西：(a) **被动性使安全与模型解耦**：只要控制器相对能量罐被动、环境被动，耦合系统就 L2 稳定，模型错得再离谱也不会失稳；(b) **力–位移是不可伪造的证词**：人可以说「我没碰你」，但端口功率平衡不会陪他撒谎。R69 的证据是语言与图像，可被投毒；接触的证据由物理背书。

**灵感 3（对偶：你干预自己 vs 世界干预你）**
直觉：消融是你对系统施加 do 算子（去掉一层），柔顺是环境对你施加 do 算子（推你一下）。二者是**同一件事的两个方向**——都是对闭环做受控干预、看响应。一个可信的系统必须同时是：**合格的实验对象**（内部消融能暴露真实的因果结构）与**合格的实验平台**（外部推挤能在不受伤的前提下暴露真值）。缺前者，架构不可证伪；缺后者，安全不可检验。把两者合起来，才得到「**干预诚实（interventional honesty）**」这一姿态。

**灵感 4（对「模型不可信」的三级响应：收紧 → 追问 → 让步）**
直觉：R68 遇到不确定就收紧，前提是「收紧的坐标系是对的」；R69 遇到歧义就去问，前提是「回答值得信」。当模型本身被 FMA 判为不可信时，这两个前提同时崩塌。此时唯一不依赖前提的动作是**柔顺**：进入被动模式，让环境通过能量交换来约束我，我放弃对「世界是什么」的断言。所以 R70 不是又加一个并列层，而是给 R68/R69 补上**最后一档退避**：Trusted 走刚性认证、Suspect 走柔顺探询、Untrusted 走纯被动。三级严格嵌套。

**灵感 5（代价与博弈：探针要耗能，消融会被针对）**
直觉：在线消融要在真实系统上注入抖动，这不是免费的——它带来磨损、抖动、噪声，并可能激发危险接触。所以诊断能量必须和任务能量、交互能量挤同一个**能量罐**，硬约束、可审计。更阴险的是**消融博弈**：一个模块可以被设计成「只在测试扰动下承力」，骗过证书拿到执行权。因此扰动种子必须隐藏、要有留出方向、要成对消融测交互项——否则「可证伪架构」本身会被一个会演戏的模块腐化。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（FLEX-RAS 总览）** FLEX-RAS = (PCC, OAP, ACU, EBA, CPI, RAS-WM‡)。三不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i / R68 定义 276-i）；
(ii) **无未经证伪的权威**：任何对执行器有影响的模块 c_i 必须持有当前工况下有效的在线消融证书 AC_i（定义 314）；失效即降权至 SHADOW（只计算、记录、不进执行回路）；
(iii) **能量记账的干预**：任务、信息动作、诊断探针（消融抖动）共享同一能量罐 T(t) ≥ 0；任何会使 T < 0 的干预一律拒绝。柔顺性是这三条的统一物理底座。

**定义 311（端口-哈密顿柔顺模型与能量罐）** 被控系统写成端口-哈密顿形式 ẋ = (J(x) − R(x))∇H(x) + G(x)u + G(x)w_ext，端口功率 P = uᵀy（y 为与 u 共轭的流/速度）。能量罐 T(t) ≥ 0，更新 Ṫ = σ(P) − P_diag，P_diag 为诊断抖动取用功率。被动性：H(x(t)) − H(x(0)) ≤ ∫₀ᵗ uᵀy dτ。**柔顺裕度** ρ(t) = T(t)/T_max。

**定义 312（变阻抗律与刚度–柔顺权衡）** 期望阻抗 Z_d = (M_d, D_d, K_d)；引入柔顺标量 c(t) ∈ [0,1]，K_d(t) = K_min + (K_max − K_min)(1 − c(t))，D_d、M_d 同步插值。c→0 为刚性（保护、跟踪），c→1 为柔顺（倾听、探询）。c 由信任态与消融需求共同决定（定义 318、323）。

**定义 313（在线消融算子）** 模块 c_i 输出 o_i。消融算子 A_i^ε(o_i) = o_i + δ_i，‖δ_i‖_{W_i} ≤ ε_i：
- **硬消融** A_i^∞：以参考输出 o_i⁰ 替换（仅允许 authority ≤ ADVISORY 的非安全模块）；
- **软消融** A_i^ε：有界抖动（允许执行模块，前提是柔顺裕度 ρ_after ≥ ρ_min，由定义 311 保证）。
**边际因果贡献** 以决策泛函 D（如选中模态 a* 或 λ）度量：ΔD_i = D(o) − D(A_i^ε(o))；**归一化必要性** N_i = ‖ΔD_i‖ / (‖δ_i‖ + ν)，ν 为噪声底。N_i 是 leave-one-out 的在线、局部、有界版本（全子集 Shapley 代价过高，不做）。

**定义 314（消融证书 AC_i）** AC_i = (N_i, CI₉₅, regime_tag, ε_i, ρ_after, seed_hash)。Valid ⇔ N_i > τ_nec ∧ ρ_after ≥ ρ_min ∧ 扰动方向由隐藏随机种子生成（防定向博弈，定义 319）。证书按工况打标签——**消融证书不可跨工况迁移**。

**定义 315（权威等级与仲裁 ACU）** 每个模块 authority ℓ_i ∈ {OFF, SHADOW, ADVISORY, ACTUATING}。ACU 规则：窗口内 N_i 持续 < τ_dead ⇒ 降一级；SHADOW/ADVISORY 在**留出扰动**上 N_i > τ_nec 且过安全认证 ⇒ 可升一级；升/降均带滞回（hysteresis），避免抖振。只有 ACTUATING 且证书有效的模块才驱动执行器。

**定义 316（三重能量预算 EBA）** E_task + E_info + E_diag ≤ T_usable。E_info 为 R69 交互开销；E_diag 为消融抖动开销。Trusted 态 E_diag ≤ 5%；Suspect/Untrusted 态 E_diag 上调但硬上限 ≤ 20%，且单次探针能量必须小于柔顺裕度允许值。

**定义 317（柔顺物理探询 CPI）** 信息动作新增**柔顺接触探询**：施加有界力/速度 (f, ẋ)，读取位移–力对 (Δx, f)。证据不是「回答」，而是端口的**功率平衡残差** r_phys = |∫ fᵀẋ dt − ΔH_obs − ∫Ṫ dt|。**不可伪造性**：被动环境必须满足能量不等式；若它「报告」了物理上不自洽的位移–力（撒谎/欺骗），r_phys 升高。这是 R69 语言证据之外、由牛顿定律背书的第二证据源。

**定义 318（模型信任三级与柔顺回退）** 由 (r_res, Δa, N_FMA) 给出信任态：
- **T**rusted：刚性认证控制（R69 主路径）；
- **S**uspect：柔顺咨询（c↑，执行模块降为 ADVISORY，E_diag 上调）；
- **U**ntrusted：**纯被动模式**——放弃模型断言，只允许能量安全、能被被动性兜住的动作。
三级对应 R68「收紧」→ R69「追问」→ R70「让步」，是补全而非替代。

**定义 319（消融博弈与反制）** 消融博弈：模块被设计成只在测试种子下承力。反制：(a) 隐藏种子 + 留出扰动方向；(b) 成对消融测交互项；(c) 若 N_i(test) ≫ N_i(holdout) 且差异超置信区间 ⇒ 判为博弈，冻结权威并审计。

**定义 320（僵尸层与寄生层）** **僵尸层**：长期 N_i ≈ 0 却持续耗算力、增攻击面 ⇒ 降权或物理移除。**寄生层**：单独消融时 N_i 高，但与 j 同时消融时效应消失（N_{i,j} ≈ N_j），说明 i 是 j 的重复计算 ⇒ 合并或降为 SHADOW。二阶交互项 I_{ij} = N_i + N_j − N_{i,j} 判别冗余（I<0，可替代）与协同（I>0，互补）。

**定义 321（证书 J_FLEX）** J_FLEX = (J_FLUID, {AC_i}, ℓ 向量, energy_ledger, min_t ρ(t), regime_tags, ablation_coverage, flex_ver)。Valid ⇔ Valid(J_FLUID) ∧ 所有 ACTUATING 模块持有效 AC ∧ min ρ ≥ ρ_min ∧ 能量账本闭合。

**定义 322（消融覆盖率与可证伪度）** 覆盖度 cov = 被有效证书覆盖的执行权威占比；**可证伪度** F = 1 − (未被检验的权威质量 / 总权威质量)。系统健康指标不是「层数 L」而是 F：若 L 上升而 F 不升，说明在堆砌不可证伪的复杂度。

**定义 323（柔顺-消融联合分配）** 给定信任态与各模块必要性，联合决定 (c, E_diag, authority)：安全关键模块承力且其证据不确定 ⇒ 提高刚度（c↓，保护它）；epistemic 高且接触可判别 ⇒ 提高柔顺（c↑，倾听）；无承力模块 ⇒ 降权并把省下的能量还给任务。形式化为一个受能量罐约束的小规模优化。

**定义 324（时序与摊销）** 默认只在低危窗口/低动态段运行软消融；用轮转调度分摊 E_diag，保 P99 实时预算；高动态段只读证书、不新增探针。

**定义 325（严格退化链）** E_diag=0 ∧ c=0（刚性）∧ 全模块 ACTUATING ⇒ FLEX ≡ FLUID（R69）；再叠加「永不交互」⇒ CALM（R68）。安全侧：被动兜底与权威降权只减不增执行动作集合。

# IP-264 PCC：能量罐 + 变阻抗柔顺控制器
class PassivityComplianceController:
    def __init__(self, tank_cap=1.0, K_bounds=(200.0, 2000.0)):
        self.T, self.T_max = tank_cap, tank_cap
        self.K_min, self.K_max = K_bounds
    def margin(self): return self.T / self.T_max

    def impedance(self, c):                        # c∈[0,1]，1=最柔顺
        K = self.K_min + (self.K_max - self.K_min) * (1.0 - c)
        return Impedance(M_d=..., D_d=..., K_d=K)

    def can_afford(self, e): return e <= self.margin() * self.T_max

    def step(self, x, u_task, c, p_diag=0.0):
        P = port_power(x, u_task)
        self.T = min(self.T_max, max(0.0, self.T + self.charge(P) - p_diag))
        if self.T <= 0.0:                          # 能量耗尽 → 停探针、进阻尼被动
            c, p_diag = 1.0, 0.0
        return self.impedance(c).resolve(u_task)

    def passive_only(self, obs):                   # Untrusted：放弃模型断言
        return self.impedance(c=1.0).resolve(damping_policy(obs))  # 纯耗散

# IP-265 OAP：在线消融探针（软/硬消融 + 有界抖动）
def ablation_probe(module, out, mode, eps, pcc):
    if mode == 'hard':
        assert module.authority <= ADVISORY        # 安全模块不允许硬消融
        delta = module.reference() - out
    else:                                          # 软消融：执行模块也可
        delta = random_direction(seed=hidden_seed()) * eps
        if not pcc.can_afford(energy_of(delta)):   # 能量罐不够 → 放弃探针
            return None
    return out + clip_norm(delta, eps)

def necessity(D_full, D_abl, eps, nu):
    return norm(D_full - D_abl) / (eps + nu)       # 归一化边际因果贡献 N_i

# IP-266 ACU：因果权威仲裁（僵尸/寄生/博弈/升降级）
def arbitrate(module, N_i, ci, regime, rho_after):
    if rho_after < RHO_MIN:
        return module.demote()                     # 证书无效
    if N_i < TAU_DEAD:
        return module.demote()                     # 僵尸层
    if paired_interaction(module) < -TAU_REDUNDANT:
        return module.demote(to=SHADOW)            # 寄生层（可被替代）
    if module.authority < ACTUATING and N_i > TAU_NEC and passes_safety(module):
        return module.promote()
    return module                                  # 保持（带滞回）

# IP-267 CPI：柔顺物理探询（功率平衡残差 = 不可伪造证据）
def compliant_probe(pcc, env, f_cmd, eps_x):
    dx, f = env.contact(f_cmd, eps_x)              # 读位移–力对
    r_phys = abs(integral(f, dx) - energy_delta(env) - pcc.tank_delta())
    return {'pair': (dx, f), 'r_phys': r_phys}     # r_phys↑ ⇒ 环境不自洽/在撒谎

# IP-275 主闭环（继承 R69，插入 柔顺—消融—权威 三层）
def FLEX_RAS_round(M, obs):
    z, o = M.mtm.forward(...); _, U_cal, _ = M.cof.step(...)
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, M.aud.k(z)), z, M.fmp.mode_head)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o_obs, o_calibrated)
    regime = M.trg.classify(r_res=M.last_r_res, a_hat=a_hat)      # T / S / U
    # 1) 柔顺度与诊断预算：安全关键承力→刚；epistemic 可触→柔
    c      = M.alloc.compliance(regime, M.acu.necessity_map(), U_epi)
    p_diag = M.eba.diag_power(regime, M.pcc.margin())
    # 2) 在线消融：仅低危窗口；软消融有界，硬消融限非安全模块
    if M.epoch.is_low_risk() and M.pcc.can_afford(p_diag):
        for mod in M.acu.scheduled():
            o_abl = M.oap.probe(mod, mod.out, M.epoch.mode, M.eps[mod], M.pcc)
            if o_abl is None: continue
            N_i = M.oap.necessity(M.decision, mod.forward(o_abl), M.eps[mod], NU)
            M.acu.arbitrate(mod, N_i, mod.ci, regime, M.pcc.margin())
    # 3) 模型不可信 → 让步：纯被动；可疑 → 柔顺探询
    if regime == 'U':
        M.vqa_f.submit_async(M.acu.report(), M.eba.ledger(), evidence=None)
        return M.pcc.passive_only(obs), (U_ale, U_epi), M.acu.authority_vector()
    if regime == 'S' and U_epi > TAU_EPI:
        ev = M.cpi.compliant_probe(M.pcc, M.env, M.mint.probe_dir(modes), EPS_X)
        U_epi = M.cia.update_belief(modes, ev)     # 物理证据并入后验
    # 4) 只让持有效证书的 ACTUATING 模块进入执行回路
    act = [m for m in M.modules if m.authority == ACTUATING and M.acu.valid(m, regime)]
    u = M.pcc.step(obs.x, M.policy_ensemble(act)(o, modes), c=c, p_diag=p_diag)
    # 5) 审计：僵尸/寄生/博弈/能量账本
    M.vqa_f.submit_async(M.acu.report(), M.eba.ledger(), M.cpi.last_evidence())
    return u, (U_ale, U_epi), M.acu.authority_vector()

## 3. 推导

**引理 19（在线消融的可辨识性）** 设决策泛函 D 对模块输出是 L-Lipschitz，软消融抖动 δ 各向同性且 ‖δ‖ = ε。则 N_i = ‖D(o+δ) − D(o)‖/(ε+ν) 满足 |N_i − ‖∇_{o_i}D‖| ≤ Lε + ν/ε。取 ε* = √(ν/L) 最小化误差上界，得最优误差 ≤ 2√(Lν)。系：抖动不能任意小（被噪声淹），也不能任意大（超出线性区）——**存在最优探针能量**，正是 EBA 要在能量预算里找的那个点。

**引理 20（柔顺使在线消融安全）** 若控制器相对能量罐被动（定义 311），且单次软消融注入能量 E_δ ≤ ρ(t)·T_max，则消融后 T ≥ 0，且对任意被动环境闭环 L2 稳定，消融不改变稳定性判据。系：R69 的「问」需要信任回答，R70 的「试」只需能量罐——**试验的安全性由能量而非信念保证**。

**引理 21（被动性对未建模环境的鲁棒安全）** 被动控制器 + 被动环境 ⇒ 耦合系统 L2 稳定，且该结论与模型误差 ∇H̃ 无关（端口-哈密顿耦合稳定性）。故当 FMA/Δa 判模型不可信时，纯被动回退在**不需要正确模型**的意义下安全；而 R69 的模型认证此刻已失去依据。这给出「让步」优于「收紧/追问」的形式理由。

**引理 22（物理证据的不可伪造性 / 被动一致性）** 若环境真实被动但其报告 (Δx̂, f̂) 被篡改，则报告功率与真实储能变化之差 r_phys ≥ (被伪造成分的能量)/T；除非环境实际注入隐藏能量（即不再被动），否则 r_phys = 0。故 r_phys↑ 是「主动注入能量/欺骗」的检测量；对被动欺骗者，漏检需其注入 ≥ 阈值能量，而这本身会被能量账本捕获。

**定理 18（FLEX 严格包含 FLUID 与 CALM）** 在 E_diag=0、c=0、全模块 ACTUATING 且证书恒有效时，FLEX 的决策与执行逐指令等于 FLUID；再叠加 VoI≤成本/永不交互即等于 CALM（定义 325）。安全侧：权威降权与被动回退只会缩减执行动作集合 ⇒ 期望风险不增。

**定理 19（无未经证伪的权威 ⇒ 架构风险有界）** 设每个 ACTUATING 模块的边际影响 ‖ΔD_i‖ ≤ B_i，未被覆盖的权威质量为 M_unv。由不变式 (ii)，M_unv = 0（否则模块被降权）。故执行决策的总不可解释偏差 ≤ Σ_{i: valid AC} B_i。因此**增加层数不会线性膨胀未验证风险**——风险随「有效证书覆盖的质量」而非「层数」增长。这是对 R69 之后架构膨胀问题的正面回应。

**定理 20（柔顺回退的无突变）** 刚性↔柔顺切换用阻抗标量 c(t) 连续插值，端口功率随 c 连续；能量罐保证切换瞬态能量有界；结合 R68 定理 15 的换装不变式 ⇒ 控制连续、无突变。柔性模式与刚性模式可在同一安全包络内可交换。

## 6. 本轮最大风险

**一句话**：FLEX-RAS 的整个治理逻辑押在「消融能测出真实边际贡献」上——但**安全模块的价值恰恰体现在它阻止了那些没有发生的事**：在某个窗口内 N_i ≈ 0，可能不是因为它没用，而是因为它成功防住了一个稀有事件（稀有事件在当前样本里根本没出现）。若把「测不到」误判为「不存在」，ACU 会把最该保留的那层当作僵尸降权，而柔顺回退又兜不住它原本防住的稀有/主动攻击事件——**可证伪架构最大的危险，是用「没有证据」冒充「证据表明没有」。**

**次级风险与缓解**：
1. **被动性只对被动环境成立**，主动注入能量的对手可绕过（引理 21 的前提）→ 能量账本 + r_phys 检测 + Untrusted 时进一步收缩任务权威；
2. **诊断抖动带来磨损/噪声/激发接触** → 能量罐硬约束 + 仅低危窗口 + E309 磨损实验；
3. **消融博弈 / 定向过拟合** → 隐藏种子 + 留出扰动 + 成对消融 + 定义 319 冻结；
4. **稀有事件掩蔽（本次最大风险）** → 用先验/风险模型给 N_i 加「潜在贡献」下界，稀有安全模块默认不降权（非对称保守）；
5. **证书跨工况造假** → AC 携带 regime_tag，不跨工况迁移；J_FLEX 校验 min ρ 与账本闭合。

# IP-264 PCC：能量罐 + 变阻抗柔顺
class PassivityComplianceController:
    def margin(self): return self.T / self.T_max
    def impedance(self, c):
        K = self.K_min + (self.K_max - self.K_min) * (1.0 - c)
        return Impedance(M_d=..., D_d=..., K_d=K)
    def can_afford(self, e): return e <= self.margin() * self.T_max
    def step(self, x, u_task, c, p_diag=0.0):
        self.T = min(self.T_max, max(0.0, self.T + self.charge(port_power(x, u_task)) - p_diag))
        if self.T <= 0.0: c, p_diag = 1.0, 0.0          # 能量耗尽 → 停探针、阻尼被动
        return self.impedance(c).resolve(u_task)
    def passive_only(self, obs):                        # Untrusted：放弃断言
        return self.impedance(c=1.0).resolve(damping_policy(obs))

# IP-265 OAP：在线消融探针
def ablation_probe(module, out, mode, eps, pcc):
    if mode == 'hard':
        assert module.authority <= ADVISORY
        delta = module.reference() - out
    else:
        delta = random_direction(seed=hidden_seed()) * eps
        if not pcc.can_afford(energy_of(delta)): return None
    return out + clip_norm(delta, eps)

def necessity(D_full, D_abl, eps, nu):
    return norm(D_full - D_abl) / (eps + nu)            # N_i

# IP-266 ACU：因果权威仲裁
def arbitrate(module, N_i, regime, rho_after):
    if rho_after < RHO_MIN:                       return module.demote()
    if N_i < TAU_DEAD:                            return module.demote()      # 僵尸
    if paired_interaction(module) < -TAU_REDUN:   return module.demote(to=SHADOW)  # 寄生
    if module.authority < ACTUATING and N_i > TAU_NEC and passes_safety(module):
        return module.promote()
    return module                                  # 滞回

# IP-268 CPI：柔顺物理探询（功率平衡残差 = 不可伪造证据）

## 4. 推导

**引理 19（消融可辨识性）** D 为 L-Lipschitz、抖动各向同性 `‖δ‖=ε`，则 `|N_i − ‖∇D‖| ≤ Lε + ν/ε`；取 `ε*=√(ν/L)` 得误差 ≤ `2√(Lν)`。系：存在最优探针能量，由 EBA 在能量预算内求解。

**引理 20（柔顺使消融安全）** 控制器相对能量罐被动且单次消融能量 `E_δ ≤ ρT_max` ⇒ 消融后 `T≥0`，对任意被动环境闭环 L2 稳定。系：安全性由能量而非信念保证。

**引理 21（被动性对未建模环境鲁棒）** 被动控制器 + 被动环境 ⇒ L2 稳定，与模型误差无关。故模型不可信时纯被动回退在**不需要正确模型**下安全，而 R69 模型认证已失去依据——「让步」优于「收紧/追问」。

**引理 22（物理证据不可伪造）** 真实被动但报告被篡改的环境使 `r_phys ≥ 被伪造成分能量/T`；除非其注入隐藏能量（即不再被动）。故 `r_phys↑` 检出欺骗/主动能量注入，且注入能量本身可被账本捕获。

**定理 18（严格包含）** `E_diag=0 ∧ c=0 ∧ 全 ACTUATING` 且证书恒有效时，FLEX 逐指令等于 FLUID；再叠加永不交互等于 CALM。安全侧只减不增执行动作集合 ⇒ 期望风险不增。

**定理 19（无未经证伪的权威 ⇒ 风险有界）** 各 ACTUATING 模块边际影响 `‖ΔD_i‖≤B_i`，未覆盖权威质量 `M_unv=0`，则决策总不可解释偏差 `≤ Σ B_i`。风险随「有效证书覆盖质量」而非「层数」增长——正面回应架构膨胀。

**定理 20（柔顺回退无突变）** c(t) 连续插值使端口功率连续；能量罐保证切换瞬态能量有界；结合 R68 定理 15 换装不变式 ⇒ 控制连续、无突变。

## 7. 本轮最大风险

**一句话**：FLEX-RAS 的治理逻辑押在「消融能测出真实边际贡献」上——但**安全模块的价值恰恰体现在它阻止了那些没有发生的事**：某窗口内 N_i≈0 可能不是它没用，而是它成功防住了一个在当前样本里根本没出现的稀有事件；若把「测不到」误判为「不存在」，ACU 会把最该保留的那层当僵尸降权，而柔顺回退又兜不住它原本防住的稀有/主动攻击事件——**可证伪架构最大的危险，是用「没有证据」冒充「证据表明没有」。**

**次级风险与缓解**：被动性只对被动环境成立，主动注入能量的对手可绕过（能量账本 + r_phys + Untrusted 收缩权威）；诊断抖动带来磨损/噪声/激发接触（能量罐硬约束 + 仅低危窗口 + E309）；消融博弈/定向过拟合（隐藏种子 + 留出扰动 + 成对消融 + 定义 319 冻结）；稀有事件掩蔽（用先验/风险模型给 N_i 加潜在贡献下界，稀有安全模块默认不降权，非对称保守）；证书跨工况造假（AC 携带 regime_tag 不迁移 + J_FLEX 校验 min ρ 与账本闭合）。
