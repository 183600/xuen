# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「多视角视觉」×「语义建图」）

> R69 教会系统「向谁求证、还能问什么」，但它把观测 o_t 当成一个不透明的整体，并把 epistemic 不确定当成一个**单一的、关于世界的**量：看一眼不确定 → 就去问人。这里藏着三个从未被检验的假设：
> 1. **单视角假设**：o_t 只有一只眼。于是大量所谓「歧义」其实不是世界的，而是**我这一个视角看不见**——遮挡、对称、透明、反光、弱纹理。R69 会为一桩「换个角度就解决」的事去打扰人。
> 2. **歧义归属缺失**：R69 的 U_epi 是一个总量，它从不说「这份不确定到底该由谁负责」——是视线、是世界、还是我的地图。没有归因，MINT 的 VoI 就可能在错误的来源上花钱：用最贵的社会交互，去解一个最便宜的几何问题。
> 3. **证据独立性只是口号**：R69 用「k 个正交证据源一致」对抗投毒（引理 18），但**什么算正交**从未被测量。两个几乎共视的相机会给出一致却完全相关的证据，ρ≈1；引理 18 的上界 δ_p·ρ^{k−1} 随即失效——「多源一致」退化为同一错误的复述。
>
> 本轮两个灵感正好补上三个缺口：
> - **多视角视觉**把歧义变成**几何可归因**的量——视差（parallax）不一致是免费的、先于任何交互的信息；有效基线与退化程度**可测量证据独立性 ρ_eff**，把 R69 的「正交」从一个信念变成一个可观测量、可写进证书的量。
> - **语义建图**把歧义变成**可累积、可复现、可跨时**的对象——语义地图不是一张点地图，而是一个带**多假设、来源（provenance）、新鲜度与存在概率**的信念；它让「反复出现同一歧义」（透明杯、镜面、重复走廊）与「偶发噪声」区分开，也让地图自身的不确定成为一条可审计的通道。
>
> 核心命题：**把 R69 的 epistemic 不确定按「可约性的来源」再分解为 U_view（换视角可解）、U_world（世界/意图本身多解）、U_map（地图信念不确定或过时）；用一条从免费到昂贵的「消歧阶梯」——已有视角融合 → 主动换视角自运动 → 语义地图记忆检索 → 社会交互（R69 MINT）→ 纯保守（R69 λ_floor）——逐级下降，绝不把「自己换个角度就能看的事」拿去花社会预算；且任何用于验证的证据必须与被验证者「来源不相交」，否则地图只会把同一份偏见一致地复述给你听。** 命名 **MOSAIC-RAS**（Multi-view Object-centric Semantic-map Arbitration and Interaction-gated Conservatism：多视角几何仲裁 × 多假设语义地图的交互门控闭环）——许多视角拼成一张图，而**拼接处的缝**恰恰是最有价值的信息。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**这份不确定，是我的视线、世界本身，还是我的地图？我该先换个角度，还是先查记忆，才配去问人**」。

## 0. 直觉与动机

**灵感 1（多视角视觉 → 视差是免费的、可归因的信息）**
直觉：单张图像里，一个物体的深度/身份可以多解；但同一场景从第二个基线看过去，多解会被三角化约束压掉。人凑近、侧头、走两步，本质上是在**制造基线**。所以「歧义」并不都等价：有些是**视点造成的**（换个角度即消），有些是**世界本身多解**（两面都是真的，如两只相同的杯子、一个真正对称的物体），有些是**记忆造成的**（我记错了、地图过时了）。R69 把它们一起当成「问」；MOSAIC 先用几何把第一类免费拿走。
关键量：两视图间有效基线 b_eff = b·sin β（b 为相机中心距，β 为视线夹角），三角化后深度不确定度近似 σ_z ≈ z²σ_θ / b_eff。b_eff 越大，单视歧义被压得越低——**这个下降是可以预先算出来的，不需要真执行就知道「再挪 5cm 值不值」**。这把「要不要主动换个视角」变成一次可核算的投资，而不是碰运气的探索。

**灵感 2（语义建图 → 地图是记忆，也是一种偏见）**
直觉：语义地图的价值不是「画得漂亮」，而是**跨时间地记住世界上有什么、在哪、是什么**，从而把当下的歧义放进历史里解释：这个「白色圆柱」我上周见过，是杯子；这条走廊我走过，右侧其实是镜子。于是歧义分化为**结构性**（会反复出现，应写进地图先验）与**瞬态性**（一次性的噪声/反光）。但地图同时引入一个危险：**它是一份可以被自己反复引用的信念**。如果建图时感知就偏了，地图会把同一份偏见稳定地复述回来，形成一个自洽却错误的闭环——这与 R68 的标定吸收、R69 的幻影模态是同构的「自证」失效，只是这次自证的载体从传感器/策略变成了地图。

**灵感 3（三分 → R69 是 V=1 且地图退化为点估计的边界）**
直觉：把 R69 的 epistemic 再按**可约性来源**拆分，MINT 的 VoI 才有正确的分母：只有 U_world 值得花社会预算；U_view 该由「再生成一个视角」解决；U_map 该由「重定位/地图修订/记忆检索」解决。当 V=1 且地图是一个无假设的点估计时，U_view=U_map=0，MOSAIC 逐指令退化为 FLUID。这正是本系列一直坚持的姿态：**新层是旧层的严格泛化，旧层是新层在某一边界上的退化**——安全侧不让步，效率侧只在旧层浪费的地方赚回。若做不到这一点，每加一层就多一个需要独立信任、也会独立说谎的黑箱。

**灵感 4（证据独立性从信念变为测量 → 修补引理 18）**
直觉：R69 说「k 个正交源一致」就能把投毒错误率压到 δ_p·ρ^{k−1}，但 ρ 是假设的。多视角给出一个**可测的 ρ_eff**：两视图的基线与视角差越小、共视退化越严重，它们的误差相关性越高，独立证据量越少。语义地图则要求**来源不相交（provenance-disjoint）**：一个只由相机 v 构建的地标，不能用来验证相机 v 的观测——否则就是拿 A 的笔记去证明 A 没抄错。这给「正交」一个可审计的操作定义，也第一次让 R69 那条漂亮的上界有了成立的**前提**，而不是一个未言明的乐观假设。

**灵感 5（双刃剑 → 地图会被投毒，也会被「看得很清楚」欺骗）**
直觉：多视角与语义地图把系统从「一只眼」升级为「一群眼 + 一本账」，但也新增攻击面：**地图投毒**（塞幽灵障碍、抹掉真障碍）、**感知别名**（重复走廊/镜像场景让系统自信地定位到错误位置）、**语义共谋**（所有视角被同一张贴图/同一套先验一致地骗过）、**语义先验泄漏**（地图的生成先验「脑补」出没观测到的物体，被当作观测证据）。最危险的不是「看不清」，而是**看得又清楚又一致，却一致地错**。所以本轮必须同时交付：来源追踪、来源不相交验证、别名/投毒干扰集，以及「推断内容不得单独作为安全证据」的纪律；否则 MOSAIC 只是把一个诚实的问题，升级成一个自信的错误。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（MOSAIC-RAS 总览）** MOSAIC-RAS = (MVG, SMB, EPA, RL, AVS, SAC, PDV, MAP, RAS-WM†)。三不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **归因先于花费**：任何主动信息动作（含社会交互）前，必须先给出不确定性的来源归因 (U_view, U_world, U_map)；无法归因、或地图校准门越界 ⇒ 不花社会预算，直接走保守兜底；
(iii) **来源不相交验证**：任何用于验证观测/决策的证据，其 provenance 必须与被验证者不相交；推断内容（非观测）不得单独作为安全认证证据。

**定义 311（多视角观测与视几何）** t 时刻 V 个视图 o_t = {(I_t^{(v)}, T_t^{(v)}, K^{(v)})}_{v=1}^{V}，T_t^{(v)} ∈ SE(3)。视图对 (i,j) 的有效基线 b_eff^{ij} = ‖t_i − t_j‖·sin β_ij（β_ij 为视线夹角），退化度 κ_ij = 1/(1 + b_eff^{ij}/σ_b)，共视区域 Ω_ij。单视歧义经三角化后的深度不确定度近似 σ_z^{ij} ≈ z²σ_θ/b_eff^{ij}。视差收益预算 Π_ij = I(M; Y_ij | o_t^{(i)}) − c_self，即「再获得视图 j」对模态身份 M 的信息增益减去自运动成本。

**定义 312（语义地图信念 SMB）** 地图不是点估计，而是带来源的多假设信念
M_t = {h_i = (id_i, p_i, Σ_i, q_i, e_i, P_i, τ_i)}，
p_i 位姿、Σ_i 位姿协方差、q_i 语义标签分布、e_i 存在概率、P_i ⊆ V×time 为**来源集**、τ_i 最后观测时刻（新鲜度）。地图支持查询 q(M_t, region/label) 与冲突分 conflict(o_t, M_t)。显式区分观测与推断：M_t = M_t^obs ⊔ M_t^inf，只有 M_t^obs 携带「被看到过」的证据地位。

**定义 313（视差残差与跨视一致性）** 对视图对 (i,j)，几何残差 r_geo^{ij}（对极/重投影）、语义残差 r_sem^{ij}、深度相对差 r_dep^{ij}；跨视一致分 c_ij = exp(−(r_geo/σ_g + r_sem/σ_s + r_dep/σ_d))。注意 c_ij 只度量**相干**，不度量**为真**；其证据地位由来源集 P 决定（定义 315）。

**定义 314（epistemic 来源三分 EPA）** 设 Y_view 为「再取若干视角」可得观测，Y_map 为「检索/重定位/修订地图」可得信息，Y_world 为「必须通过世界或人才能获得」的信息。则
U_view = I(M; Y_view | o_t), U_map = I(M; Y_map | o_t), U_world = I(M; Y_world | o_t, Y_view, Y_map)。
U_epi^{R69} ≈ U_view ⊕ U_world ⊕ U_map（⊕ 表示含冗余项的分通道组合，不做标量加和；三者各自进入不同消歧动作）。**只有 U_world 允许消耗社会交互预算**；U_view/U_map 若被误花社会预算，记为「归因错配」。

**定义 315（有效证据独立性与来源不相交 PDV）** 视图对误差相关上界 ρ_eff^{ij} = f(κ_ij, overlap_ij, 同源曝光/同模型偏置)，κ 越小（越共视、越退化）ρ_eff 越接近 1。R69 引理 18 中的 ρ 由 ρ_eff 替换：错误采纳率 ≤ δ_p·(ρ_eff)^{k−1} + ε_σ。**来源不相交规则**：用证据集 E 验证对象 x 合法，仅当 prov(E) ∩ prov(x) = ∅ 且 ρ_eff(E) < ρ_max。仅由相机 v 构建的地标不得用于验证 v；仅由当前观测推出的结论不得用于验证当前观测。

**定义 316（地图一致性异常 SAC）** 类比 R69 的流似然第二意见（定义 301），定义地图—观测冲突分
a_map = −log p(M_t | o_t) ≈ D_KL( 观测语义位姿后验 ‖ 由地图预测的语义位姿分布 )。
「传感器自洽但地图冲突」是**语义别名 / 地图投毒 / 物体被移动**的判别模式；它与 R69 的 (r_res↓, Δa↑) 构成第三条正交通道 (r_res, Δa, a_map)。定义别名嫌疑 aliasing = (a_map 高) ∧ (r_res 低) ∧ (多视图一致)——**一致地错**才是最难识别的错。

**定义 317（消歧阶梯 RL）** 信息动作按成本升序分五级：
L0 融合已有视图（成本≈0）；L1 主动换视角/微基线自运动（物理成本低、无社交成本）；L2 语义地图检索/重定位/地图修订（计算与时间成本）；L3 社会交互（R69 的看/问/触，社交成本）；L4 纯保守（R69 λ_floor）。
选择规则：找到最小 ℓ 使残余 U 降到阈值以下，且该级动作通过认证与预算；否则下降一级。**禁止跨级**：L3 不得在 L0–L2 仍可支付时被触发。

**定义 318（主动视角选择 AVS）** 主动视图候选 g_view = (ΔT, τ_stay) ∈ SE(3)×ℝ_+；选 g_view* = argmax_g [Π(g) − c_self(g)]，s.t. 自运动过 C-RAS-WM 前缀认证、时间窗未过期、不进入危险区域。AVS 是 R69 信息动作空间 𝒜_info 的子集，新增「相机自运动」维度，视差收益 Π 由定义 313 预算；主动换视角也是物理动作，必须像探针一样被认证。

**定义 319（地图感知风险膨胀 MAP）** 在地图信念下，占据/可通行安全集
𝒮_map^ρ = {x : dist(x, Occ_{1−α}(M_t)) ≥ d_safe + ρ_unc(x)}，
其中 Occ_{1−α} 为占据的 (1−α) 置信集，ρ_unc(x) = √(tr Σ(x))·κ_conf 为局部位姿/语义不确定带来的额外裕度。随 M_t 收敛，𝒮_map^ρ → R69 的标称安全集；地图越不确定，包络**单调扩张**（安全侧不退让）。

**定义 320（多假设管理与修订）** 每个地标维护假设集；新观测做贝叶斯更新与存在概率 e_i 更新；e_i < ε_exist 则淘汰；出现矛盾观测时**保留两假设并标记冲突，不得强行合并为均值**（避免把「两个都真」压成一个假的中间值）。修订须写不可篡改日志，供审计反查。

**定义 321（语义先验泄漏与观测/推断隔离）** 地图生成先验可补全未观测结构（如「厨房应有台面」），记为 M_t^inf；任何安全认证、任何「已消歧」声明只允许使用 M_t^obs 及其来源不相交的验证；M_t^inf 仅可作探索先验且必须标注。**泄漏率** λ_leak = 以 M^inf 作证据的决策比例，要求 ≤ λ_max。

**定义 322（别名/投毒威胁模型 ℰ_map）** 并入 AIC：ℰ_MOSAIC = ℰ_FLUID × ℰ_map，ℰ_map = {地图投毒, 感知别名（重复/镜像/对称结构）, 跨视共谋欺骗（同一贴图/先验一致地骗过所有视角）, 语义先验泄漏, 过时地图（物体被移动）, 共视伪独立（基线不足却当作独立证据）}。

**定义 323（参与式审计 VQAuditor-M）** 审计：U 的来源归因是否正确、社会交互是否被花在 U_view/U_map 上（错配率）、验证是否满足来源不相交、是否用 M^inf 作证据、地图修订日志、别名嫌疑处置。结论回灌 AuditBuf，成为下一轮成本先验与地图可信度先验。

**定义 324（证书 J_MOSAIC）** J_MOSAIC = (J_FLUID, ambiguity_attribution (U_view,U_world,U_map), ρ_eff_min, map_ECE, provenance_hash, ladder_level, aliasing_score, leak_rate, map_version, mosaic_ver)。Valid ⇔ Valid(J_FLUID) ∧ 归因一致 ∧ 来源不相交满足 ∧ λ_leak ≤ λ_max ∧ map_ECE ≤ τ_map。

**定义 325（地图校准门 MCG-M）** 地图的存在概率 e_i 与语义分布 q_i 需校准（ECE）；map_ECE > τ_map ⇒ 地图不得参与消歧与安全认证，退化为「无地图」的 FLUID。这与 R69 的 MCG（模态校准门）同构，防的是「信念源的自信错」：一个过度自信的地图比没有地图更危险。

**定义 326（时序巩固与复现检验）** 对反复出现的歧义做复现计数：同一区域/同一标签的歧义在窗口 W 内出现 n 次 ⇒ 判为**结构性歧义**，写入地图先验（并做反表象校验）；仅出现一次 ⇒ 瞬态，只作当轮处置。结构性歧义可**预消解**（下次直接按历史结论起步），但必须带来源与可撤销标记，避免把一次错误永久化。

## 2. 关键算法骨架

# IP-264 MVG：多视角几何与视差收益预算
class MultiViewGeometry:
    def pairwise(self, T):
        for i, j in pairs(len(T)):
            b     = norm(t_i - t_j) * sin(angle_between(view_dirs(i, j)))  # 有效基线
            kappa = 1.0 / (1.0 + b / sigma_b)                               # 退化度
            yield (i, j), b, kappa

    def parallax_gain(self, i, j, z, sigma_theta):
        b_eff   = self.effective_baseline(i, j)
        sigma_z = z * z * sigma_theta / max(b_eff, eps)   # 三角化深度不确定度
        return expected_info_gain(sigma_z)                # 预算：换视角值不值

# IP-265 SMB：多假设语义地图（带来源、新鲜度、观测/推断分离）
class SemanticMapBelief:
    def update(self, o_views):
        for h in self.hypotheses:
            h.bayes_update(o_views)
            h.provenance |= provenance_of(o_views)
        self.split_on_conflict()              # 矛盾不取均值，保留双假设
        self.evict(lambda h: h.exist < EPS_EXIST)
        return self

    def conflict(self, o):
        return kl_divergence(posterior(o), self.predict(o))   # a_map

# IP-266 EPA：epistemic 来源三分
def attribute(modes, o_views, M, budget):
    U_view  = info_gain_from_new_views(modes, o_views, budget)  # L0/L1
    U_map   = info_gain_from_memory(modes, M)                   # L2
    U_world = max(0.0, entropy(modes) - U_view - U_map)         # L3 才值得花
    return U_view, U_world, U_map

# IP-267 RL：消歧阶梯（免费 → 自运动 → 记忆 → 社会 → 保守）
def resolve_ladder(U_view, U_world, U_map, o, M, budget):
    if U_view > TAU_VIEW:
        g = avs.choose(o)                                  # 主动换视角（已认证）

    if U_world > TAU_WORLD:

    return ('L4', None)                                    # R69 纯保守兜底

# IP-271 PDV：来源不相交验证
def validate(x, evidence):

# IP-276 主闭环（继承 R69，在「交互决策」前插入多视角/地图层）

## 3. 推导

**引理 19（视差的可归因信息增益）** 设单视图方位噪声 σ_θ、目标深度 z、视图对有效基线 b_eff。三角化后 σ_z ≈ z²σ_θ/b_eff，故新增一个基线为 b 的视角对深度/身份的信息增益随 b_eff 单调上升，且当 b_eff ≥ z²σ_θ/δ 时把该分量压到 δ 以下。要点：**「换视角」的可解性是可预先计算的**——U_view 不需要实际执行就能估计；且当 b_eff→0（共视近退化）时 Π→0，此时把一个共视视角当作独立证据会高估信息、低估相关 ρ_eff（接引理 20）。

**引理 20（来源不相交验证的必要性 / 自证界）** 设验证证据 E 与被验证对象 x 的误差相关为 ρ。若 prov(E) ∩ prov(x) ≠ ∅（共享来源），则 ρ→1，条件互信息 I(err_x; check_E | ·) → 0，验证的误接受率不随 k 下降。故 R69 引理 18 的 δ_p·ρ^{k−1} 只有在**来源不相交**时成立；否则「多源一致」退化为同一错误的复述。系：地图只能作为**独立于当前观测**的记忆来用，不能作为当前观测的验证者。

**引理 21（地图不确定下的安全膨胀是保守单调的）** 若安全集用占据置信集 Occ_{1−α} 与额外裕度 ρ_unc 构造，则在 M_t 的信念支撑内对任意真实地图 M，认证通过的计划都满足与真实障碍的间隔 ≥ d_safe；且当 Σ→0 时 𝒮_map^ρ → 𝒮_nominal。故地图不确定只让包络变大、不让它变小，安全侧对标称 FLUID 单调不退让。

**定理 18（MOSAIC 严格包含 FLUID 与 R68）** 在 A102–A104（视差模型 Lipschitz、来源可追踪、地图信念校准）下，MOSAIC 的期望风险 ≤ FLUID；且当 V=1、地图退化为点估计（无假设、无冲突）、或 MCG-M 触发时，归因给出 U_view=U_map=0，阶梯直接落到 L3/L4，与 FLUID 逐指令相同；再叠加 R69 定理 16，FLUID 在「永不交互」边界等于 R68。故 **MOSAIC ⊇ FLUID ⊇ R68**，安全侧零让步，效率侧只在旧层浪费处获利。

**定理 19（消歧阶梯的社会预算支配性）** 设成本序 c(L0) ≤ c(L1) ≤ c(L2) ≤ c(L3)，且各级信息增益非负、边际递减。若存在 ℓ<3 使残余 U 降到阈值以下，则任何先触发 L3 的策略都被阶梯策略**按社会成本严格支配**（相同或更高后验确定性、更低社会成本）。故阶梯在「给定社会预算下的期望残余不确定」上最优；R69 的 MINT 是其 L3 子程序。系：**R69 的「看一眼/问一句」应当被推迟为最后手段**，而不是第一反应。

**定理 20（别名/投毒下的有界误信）** 设地图投毒比例 δ_m、跨视共谋相关 ρ_c、来源不相交验证的独立源数 k。在 SAC 第三通道与来源不相交规则下，系统把「一致地错」误判为「已消歧」的概率 ≤ δ_m·ρ_c^{k−1} + ε_σ；若别名嫌疑 aliasing 触发，则强制 L4 保守，误信率进一步被 λ_floor 上界压住。系：**多视角一致不是真理，只是相干**；只有来源不相交的独立证据才能把相干性提升为可信性。

## 6. 本轮最大风险

**一句话**：MOSAIC-RAS 把「不确定从哪来」做成了一次**归因判断**，但归因本身可能错——系统可能把「世界的多解」误判成「我的视角问题」，于是自信地换个角度、看到同一份错，并把这种**相干**当成**已消歧**；更糟的是语义地图会自我复述：若建图时的偏见与当前感知共享来源，所谓「交叉验证」只是拿同一份笔记证明同一份笔记——**看得更清楚，不等于看得对**。

**次级风险与缓解**：
1. **归因错误**（U_view/U_world/U_map 分错）→ 引理 19 用可预先计算的视差收益做校准 + E301 + 归因不确定时降级到 L4；
2. **自证地图 / 共视伪独立** → 定义 315 来源不相交 + 引理 20 + E308，共享来源的证据一律不作验证；
3. **地图投毒 / 感知别名 / 跨视共谋** → 定义 322 ℰ_map + 定义 316 第三通道 + 定理 20 + E306/E307/E309，alias 触发即 L4；
4. **语义先验泄漏**（合理但不真实的脑补）→ 定义 321 M^obs/M^inf 隔离 + λ_leak 门 + E310，推断内容绝不单独作安全证据；
5. **地图过时与漂移**（物体被移动）→ 定义 312 新鲜度 τ_i + 定义 320 多假设修订 + E314，过时区域自动膨胀安全包络。

**定义 318（AVS 主动视角）** `g_view=(ΔT,τ_stay)`；`argmax[Π−c_self]`，s.t. 自运动过 C-RAS-WM、时间窗、不进入危险区；AVS ⊂ 𝒜_info。

**定义 319（MAP 风险膨胀）** `𝒮_map^ρ={x: dist(x,Occ_{1−α})≥d_safe+ρ_unc(x)}`；Σ→0 时回到标称；不确定只扩张包络。

**定义 320（多假设修订）** 贝叶斯更新 + 存在概率淘汰；矛盾时保留双假设、标记冲突，**不取均值合并**；修订不可篡改留痕。

**定义 321（先验泄漏隔离）** 仅 `M^obs` 可作认证/消歧证据；`M^inf` 只作探索先验且标注；`λ_leak≤λ_max`。

**定义 322（威胁模型）** `ℰ_MOSAIC=ℰ_FLUID×ℰ_map`；`ℰ_map={投毒, 感知别名, 跨视共谋, 先验泄漏, 过时地图, 伪独立}`。

**定义 323（VQAuditor-M）** 审归因、社会预算错配、来源不相交、M^inf 泄漏、别名处置、修订日志；回灌成本与地图可信度先验。

**定义 324（证书）** `J_MOSAIC=(J_FLUID,来源三分,ρ_eff_min,map_ECE,provenance_hash,ladder_level,aliasing_score,leak_rate,map_version,mosaic_ver)`；Valid ⇔ 继承 Valid(J_FLUID) ∧ 归因一致 ∧ 来源不相交 ∧ λ_leak≤λ_max ∧ map_ECE≤τ_map。

**定义 325（MCG-M 地图校准门）** `map_ECE>τ_map` ⇒ 地图不参与消歧/认证，退化为无地图 FLUID（过度自信的地图比没有地图更危险）。

**定义 326（时序巩固/复现检验）** 窗口 W 内复现 n 次 ⇒ 结构性歧义（写入先验，带来源与可撤销标记，做反表象校验）；单次 ⇒ 瞬态只作当轮处置。

# IP-264 MVG：视差收益可预先计算
class MultiViewGeometry:
    def parallax_gain(self, i, j, z, sigma_theta):
        b_eff   = norm(t_i - t_j) * sin(angle_between(view_dirs(i, j)))
        sigma_z = z * z * sigma_theta / max(b_eff, eps)
        return expected_info_gain(sigma_z), 1.0 / (1.0 + b_eff / sigma_b)

# IP-265 SMB：多假设 + 来源 + 观测/推断隔离
class SemanticMapBelief:
    def update(self, o_views):
        for h in self.hypotheses:
            h.bayes_update(o_views); h.provenance |= provenance_of(o_views)
        self.split_on_conflict()                    # 矛盾保留双假设，不取均值
        self.evict(lambda h: h.exist < EPS_EXIST)
    def conflict(self, o): return kl_divergence(posterior(o), self.predict(o))

# IP-266 EPA：来源三分（只有 U_world 花社会预算）
def attribute(modes, o_views, M, budget):
    U_view  = info_gain_from_new_views(modes, o_views, budget)
    U_map   = info_gain_from_memory(modes, M)
    U_world = max(0.0, entropy(modes) - U_view - U_map)
    return U_view, U_world, U_map

# IP-267 RL：消歧阶梯（禁止跨级）
def resolve_ladder(U_view, U_world, U_map, o, M, budget):
    if U_view > TAU_VIEW:
        g = avs.choose(o)
        if g and c_ras_wm.certify(g, o): return ('L1', g)
    if U_map > TAU_MAP:
        q = M.query(o)
        if q.reliable(provenance_disjoint(o)): return ('L2', q)
    if U_world > TAU_WORLD:
        g = mint.choose(modes, o, budget)
        if g: return ('L3', g)
    return ('L4', None)

# IP-270 PDV：来源不相交验证（修补 R69 引理 18 的前提）
def validate(x, evidence):
    E = [e for e in evidence if prov(e).isdisjoint(prov(x))]
    return E if len(E) >= k and rho_eff(E) < RHO_MAX else None

# IP-276 主闭环（继承 R69）
def MOSAIC_round(M, o_views):
    z, o = M.mtm.forward(o_views); M.map.update(o_views)
    modes, lam = M.fluid.step(z, o)
    U_view, U_world, U_map = M.epa.attribute(modes, o_views, M.map, M.budget)
    a_map = M.sac.map_anomaly(M.map, o)
    aliasing = (a_map > TAU_MAP) and (M.last_r_res < TAU_RES) and multi_view_agree(o)
    level, info = M.rl.resolve(U_view, U_world, U_map, o, M.map, M.budget)
    ok = (level == 'L4') or (M.pdv.validate(modes, info.evidence) is not None)
    if aliasing or not ok: level, info = 'L4', None
    resolved = level in ('L1','L2','L3') and ok
    U_after = 0.0 if resolved else (U_view + U_world + U_map)
    safe = M.map.occ_confidence(alpha=0.05)
    lam  = max(M.efs.risk_scale(...), lam_floor(U_ale + U_after), map_inflation(safe))
    A    = M.ach.propose(x_prime, H=M.vista.H)
    k    = M.c_ras_wm.certified_prefix(A, safe, wm_preds)   # 在膨胀安全集上认证
    if aliasing: lam = max(lam, 0.8); k = min(k, k_cal_shrink(A, U_cal))
    M.vqa_m.submit_async(level, info, U_view, U_world, U_map, a_map, M.map.provenance_hash())
    return k, lam, A, (U_view, U_world, U_map, level)

## 4. 推导

**引理 19（视差的可归因信息增益）** `σ_z≈z²σ_θ/b_eff` ⇒ 新视角对深度/身份的信息增益随 `b_eff` 单调升；`b_eff≥z²σ_θ/δ` 时该分量压到 δ 以下。系：U_view 可**预先**估计（不必执行）；`b_eff→0` 时 Π→0，把共视视角当独立证据会高估信息、低估 ρ_eff。

**引理 20（来源不相交验证的必要性 / 自证界）** 若 `prov(E)∩prov(x)≠∅` 则误差相关 ρ→1，条件互信息 `I(err_x;check_E)→0`，误接受率不随 k 降。故 R69 引理 18 的 `δ_p·ρ^{k−1}` 仅在来源不相交时成立；否则「多源一致」只是同一错误的复述。

**引理 21（地图不确定下安全膨胀的保守单调性）** 用占据置信集 `Occ_{1−α}` 与裕度 `ρ_unc` 构造的安全集，对信念支撑内任意真实地图都保证间隔 ≥ `d_safe`；`Σ→0` 时 `𝒮_map^ρ→𝒮_nominal`。故地图不确定只扩张包络，安全对标称 FLUID 单调不退让。

**定理 18（MOSAIC 严格包含 FLUID 与 R68）** A102–A104（视差模型 Lipschitz、来源可追踪、地图校准）下，MOSAIC 期望风险 ≤ FLUID；当 V=1、地图退化为点估计、或 MCG-M 触发时，`U_view=U_map=0`，阶梯落 L3/L4，与 FLUID 逐指令相同；再由 R69 定理 16，FLUID 在「永不交互」边界等于 R68。故 **MOSAIC ⊇ FLUID ⊇ R68**。

**定理 19（消歧阶梯的社会预算支配性）** 成本序 `c(L0)≤c(L1)≤c(L2)≤c(L3)`、各级信息增益非负且边际递减。若存在 ℓ<3 使残余 U 降到阈值下，则先触发 L3 的策略被阶梯策略按社会成本严格支配（同或更高后验确定性、更低社会成本）。系：R69 的 MINT 是本阶梯的 L3 子程序，「看一眼/问一句」应是最后手段而非第一反应。

**定理 20（别名/投毒下的有界误信）** 投毒比 δ_m、共谋相关 ρ_c、独立源 k；在 SAC + PDV 下，把「一致地错」误判为「已消歧」的概率 ≤ `δ_m·ρ_c^{k−1}+ε_σ`；aliasing 触发即强制 L4，误信率被 `λ_floor` 进一步压住。系：**多视一致不是真理，只是相干**；只有来源不相交的独立证据才能把相干升为可信。

## 7. 本轮最大风险

**一句话**：MOSAIC-RAS 把「不确定从哪来」做成一次**归因判断**，但归因本身可能错——系统可能把「世界的多解」误判成「我的视角问题」，于是自信地换个角度、看到同一份错，并把这种**相干**当成**已消歧**；更糟的是语义地图会自我复述——若建图偏见与当前感知共享来源，所谓「交叉验证」只是拿同一份笔记证明同一份笔记：**看得更清楚，不等于看得对**。

**次级风险与缓解**：归因错误（引理 19 预计算校准 + 归因不确定即降 L4 + E301）；自证地图/共视伪独立（定义 315 + 引理 20 + E308）；地图投毒/别名/跨视共谋（定义 322 + 定义 316 + 定理 20 + E306/E307/E309）；语义先验泄漏（定义 321 M^obs/M^inf 隔离 + λ_leak 门 + E310）；地图过时漂移（定义 312 新鲜度 + 定义 320 多假设修订 + E314，过时区域自动膨胀安全包络）。
