# 第 66 轮（承接第 65 轮「VISTA 故障可归因安全时序闭环」IP-214~223；灵感循环第 1 轮；本轮灵感：「多任务学习」×「基准测试」）

> 第 65 轮 VISTA 把「几何可证伪」升级为「故障可归因」，其自述最大风险一针见血：**归因依赖「故障属于有限假设集」与「视觉/几何独立失效」两个假设**；真实故障常是未知类型的组合，透明/镜面/对抗 patch 会让视觉与几何共享同一个分布外失效源，此时 FIR 会把未知复合故障强行归入最近假设、只膨胀错误的球——**第 64 轮的单点故障升级为「归因错误的复合故障」，而且系统会因为「已经归因」而更自信地继续执行（A88）。** 本轮不增加第 6 个传感器，也不继续扩充假设集，而是换一个更根本的提问：第 65 轮问「用哪个模态分离故障」，X-TAB 问「**用什么实验设计让故障可辨识，以及证书到底对谁有效**」。本轮核心命题是：
>
> **把多任务学习从「共享参数」升级为「共享对照」：任务族是天然的受控实验，用任务孪生（只差一个因子的任务对）构造 difference-in-differences 式的故障识别；把基准测试从「跑分」升级为「实验设计 + 证书作用域」：基准任务集按部分因子/正交表设计以最大化故障加载矩阵的可辨识性，证书只在声明的基准作用域内有效，并用覆盖差距、任务级留出、轮换与选择偏差校正来抵抗 Goodhart。未知故障不再强行归因，而是输出等价类或 novel。**

## 0. 直觉与动机

**灵感 1（多任务学习 → 任务族是天然的对照实验）**
直觉：多任务学习通常被理解为共享表征、提升样本效率；但它还有一个被忽视的副产品——**同一个潜在故障会在多个任务情境下被重复观测**。孤立地看一个任务，力偏置、几何幻觉、模型错仍然纠缠；但把任务排成对照：「同一几何、透明/不透明各一次」「同一外观、不同几何各一次」「同一物体、空载/重载各一次」——就得到类似 difference-in-differences 的对照。**共享偏置在任务间相减时抵消，任务特异的故障保留下来。** 多任务在这里不是「一起训练」，而是「一起做实验」。

**灵感 2（多任务学习 → task vector：共同方向与离群任务）**
直觉：若把每个任务微调后的参数增量看作 task vector，则「所有任务都沿同一方向漂移」往往指向共享编码器/传感器/标定问题（common-mode），而「只有一个任务离群」更像该任务的几何、外观或策略问题。更进一步，任务间梯度冲突（cos<0）带来负迁移，它本身就是一种**只在多任务下出现的新故障源 H_transfer**，必须显式建模，否则会被误归因为 H_policy。

**灵感 3（基准测试 → 基准不是真值，是有限样本与作用域）**
直觉：基准测试给出的是某个任务分布上的有限样本估计，不是部署真值。第 65 轮的 conformal 只在可交换性下成立；若部署任务族与基准任务族存在协变量漂移，证书的覆盖率就是虚的。因此证书必须**显式携带作用域 Σ**（任务族、物体集、传感配置、环境范围），并报告**基准覆盖差距**与**有效样本量 n_eff**；作用域外必须降级，而不是继续引用基准证书。

**灵感 4（基准测试 → Goodhart 与选择偏差）**
直觉：一旦「安全证书」成为被优化的指标，它就会被游戏化：在基准上过拟合、任务级泄漏（同一物体同时出现在标定与测试）、只报平均成功率、从 N 个候选里挑基准最好的那个（winner's curse）。所以基准必须是**抗 Goodhart 的**：任务级/物体级切分、隐藏留出任务、对抗轮换、最差任务指标、证书校准误差 CCE；并且对「从 N 个候选中选择」做同时覆盖或数据切分校准。

**灵感 5（合流 → X-TAB：Cross-Task Attribution with Benchmark scope）**
闭环：任务面板设计 TPD → 跨任务残差张量 CRT → 面板故障归因 FIR-X → 未知故障检测 NFD → 任务级判别探针 AFA-T → 任务干扰监测 TIM → 基准作用域证书 BSC/J_xtab → 加权 conformal 覆盖 WCC → 抗 Goodhart 基准 GRB/AIC-X。第 65 轮把「接触」拆成接触前/中/后；X-TAB 把「归因」拆成「**任务间可比、可辨识的部分**」与「**任务间不可辨识、只能报等价类或 novel 的部分**」，并给证书补上长期被忽略的第三维：「**对哪个任务分布有效**」。

**灵感 6（X-TAB 对 VISTA 的原位升级）**
- **FIR → FIR-X**：从单任务 15 维阶段签名分类，升级为「任务×阶段×通道」面板回归 + 等价类输出；新增 H_transfer / H_bench / H_novel。
- **AFA → AFA-T**：探针从「物理动作」扩到「任务动作」；优先选**安全任务孪生**（仿真孪生、软体复制、同几何异物体），以「单位物理风险的故障互信息」为目标。
- **RSC-V → RSC-X**：不确定球除 r_geo/r_force/r_model 外新增 r_scope；作用域外只膨胀 r_scope，并强制保守回退。
- **CSC → CSC-S**：认证前缀外再挂一个作用域门；scope 不匹配时 k* 直接截断到 1 或 0。
- **CSP-V → CSP-X**：技能图按任务族的对照边组织，块签名需在任务面板上可比。
- **AIC-V → AIC-X**：干扰集增基准泄漏、任务重放、隐藏任务轮换、选择偏差攻击。
- **J_vista → J_xtab**：证书增 benchmark_scope、coverage_gap、n_eff、fault_equivalence_class、novel_fault、cce、leakage_free。

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（X-TAB 闭环）**：X-TAB = (VISTA, TPD, CRT, FIR-X, NFD, AFA-T, TIM, BSC, WCC, GRB/AIC-X, J_xtab)。定位：VISTA 的「跨任务可辨识 + 基准作用域化」升级。不变式：**任务面板设计、面板归因、novel 检测、证书作用域判定只在语义流；实时流只做残差采集、作用域门、安全前缀执行与早停，零学习写操作。**
- **定义 234（任务族、任务孪生与基准分布）**：任务 τ=(g 几何, a 外观, o 物体, l 载荷, t 时序, σ 技能)。若 τ,τ′ 仅一个因子不同，称**任务孪生**，记 τ∼_k τ′（k 为被隔离因子）。基准 B={τ_i} 采自 P_bench；部署作用域 Σ 是任务因子的笛卡尔子集。
- **定义 235（跨任务残差张量）**：R∈ℝ^{T×P×C}，R[τ,p,c] 为任务 τ、阶段 p∈P、通道 c∈C 的标准化残差（C 沿用 VISTA 的视觉/力/力矩/块一致性/块方差，可加 task-vector 余弦）。r=vec(R) 按任务-阶段展平。
- **定义 236（故障加载张量）**：r = Lθ + b + ε，L∈ℝ^{(TPC)×K} 的第 k 列 ℓ_k(τ,p) 为故障 k 的**加载剖面**：H_force 在任务维近乎恒定、仅在 approach 非零；H_geo 在 g 相关任务与 approach/touch 非零；H_model 仅在 load 非零；H_vis 在 a 相关任务非零；H_policy 仅在单任务且块方差高；H_transfer 呈任务间反相关；H_bench 仅在作用域边界出现；H_novel 落在 span(L) 之外（或部分之外）。
- **定义 237（跨任务可辨识性与等价类）**：J_xt=LᵀΣ_R⁻¹L，κ_xt=λ_min(J_xt)/λ_max(J_xt)。θ 可辨识 ⇔ J_xt≻0；若两列 ℓ_k,ℓ_j 线性相关（在噪声度量下主角度<τ_eq），则只能输出**等价类** [k]={j:ℓ_j∈span(ℓ_k)}，不得强行二选一。
- **定义 238（面板故障归因 FIR-X）**：稳健分解 r=Lθ+UVᵀ+S+ε（低秩 nuisance + 稀疏任务特异 + 噪声），用加权/稳健最小二乘估 θ，再在已知故障上做后验 P(H|θ)∝p(θ|H)P(H)；若 max_H P<1−δ_fi，进入 AFA-T 或输出等价类。
- **定义 239（未知故障检测 NFD）**：残差 z=r−Lθ̂；novel 统计量 n=‖Π_{span(L)^⊥}z‖²/σ²，H0 下 n∼χ²_{d−K}；以 conformal/χ² 阈值 q(α_nov) 判 H_novel，并以主角度 τ_ang 与低秩/稀疏能量比排除 nuisance。若 Π⊥ℓ_new=0，则**理论上不可检测**，只能报等价类。
- **定义 240（任务级判别探针 AFA-T）**：探针 a=(τ′, 技能, 阶段模板)，优先 τ′ 为 τ 的安全孪生；选择 a*=argmax_a I(ℋ;ρ_new(a)|ρ)/(c_phys(a)+λ_c)，s.t. 物理风险≤B_risk、预测形变≤ε_strain；边际信息<δ_fi 时放弃物理探针，改纯观测。
- **定义 241（任务干扰监测 TIM）**：对共享参数计算任务梯度冲突 g_cos(τ,τ′)=⟨∇_τ,∇_τ′⟩/(‖·‖‖·‖) 与 task-vector 离群度 o_τ=‖v_τ−v̄‖/std(v)；若 g_cos<−δ_g 且某任务残差上升，判 H_transfer；与 H_policy 的区分是：H_transfer 在**跨任务**出现反相关签名，H_policy 只在单任务出现。
- **定义 242（基准作用域与覆盖差距）**：certificate scope Σ=(𝒢,𝒜,𝒪,ℒ,𝒯,𝒮)。用密度比 w(τ)=dP_dep/dP_bench(τ) 估部署；覆盖差距 g_scope=TV(P_bench,P_dep)（或 MMD），有效样本 n_eff=(Σw)²/Σw²；g_scope>ε_scope ∨ n_eff<n_min ⇒ `out_of_scope`。
- **定义 243（加权 conformal 覆盖 WCC）**：标定分数 s_i、权重 w_i、测试权重 w_test，取加权分位 q̂=inf{q:Σ_i p_i·1[s_i≤q]≥1−α}，p_i=w_i/(Σ_iw_i+w_test)；在协变量漂移下 P[s_test≤q̂]≥1−α。权重估计误差 δ_w 计入覆盖预算。
- **定义 244（基准作用域证书 J_xtab）**：J_xtab=(J_vista, benchmark_scope, coverage_gap, n_eff, fault_equivalence_class, novel_fault, cce, leakage_free, aic_x_ver)。Valid ⇔ Valid(J_vista) ∧ scope 匹配 ∧ P(H|θ) 集中或已判等价类/novel ∧ coverage_gap≤ε_scope ∧ leakage_free。
- **定义 245（抗 Goodhart 基准 GRB）**：任务级/物体级切分、隐藏留出任务集、按轮次对抗轮换、最差任务指标、证书校准误差 cce=|claimed_coverage−empirical_coverage|；禁止用平均成功率单独排名。AIC-X 在 ℰ_X=ℰ_V×ℰ_task×ℰ_leak×ℰ_select 上重算 ρ_dir。
- **定义 246（选择偏差校正）**：从 N 个候选中选基准最优者时，用同时 conformal / Bonferroni / 数据切分校正乐观偏差；校正后有效置信水平 α′≈α/N 或按 split 重新标定，避免 winner's curse 进入证书。
- **定义 247（RSC-X / CSC-S 作用域化）**：不确定球增 r_scope，作用域外 r_scope↑ 且 k*←min(k*,1)；scope 匹配时按归因膨胀 r_geo/r_force/r_model。CSC-S 的越界预算改为 α_chunk+δ_fi+α_nov+α_vis+α_scope。
- **定义 248（X-TAB 闭环算子）**：语义流 [VISTA 语义流→TPD 建任务面板/对照→CRT 残差张量→FIR-X 面板归因→NFD→AFA-T/TIM→WCC 加权覆盖→BSC 作用域证书→GRB/AIC-X]；实时流 [锚点读→残差采集→作用域门→CSC-S 前缀→派发→J_xtab 构建]。

## 2. 关键算法骨架

```python
# FIR-X + NFD：任务面板分解，已知故障后验 + 等价类 + novel
R = build_panel_tensor(residual_log, tasks, phases)      # T×P×C
r, L = flatten(R), loadings(task_design, KNOWN)          # (T·P·C)×K
theta, U, S = robust_panel_fit(r, L, rank_r=2, lam_sparse=..)
z = r - L @ theta
novel = norm(proj_orth(z, L))**2 / sigma2
if novel > chi2_ppf(1 - alpha_nov, df=len(r) - L.shape[1]):
    verdict = ('H_novel', None)
else:
    post = softmax({h: loglik[h](theta) + log prior[h] for h in KNOWN})
    eq = equivalence_class(L, post, tau_eq)              # 近共线 → 合并
    verdict = (max(post, key=post.get), eq) if max(post.values()) >= 1 - delta_fi \
              else ('ambiguous', eq)

# AFA-T：单位物理风险的信息增益
def choose_task_probe(post, task_graph, B_risk):
    best = (None, -inf)
    for a in task_probes(task_graph):                    # 孪生/仿真/软体复制
        if predict(a).physical_risk > B_risk: continue
        ig = expected_mutual_info(post, a, likelihood)
        score = ig / (predict(a).physical_risk + 1e-6)
        best = max(best, (a, score), key=lambda z: z[1])
    return best if best[1] > delta_fi else (None, best[1])

# WCC + BSC：基准作用域证书
def certify_scope(scores, w_cal, w_test, scope, gap, n_eff, alpha):
    if gap > EPS_SCOPE or n_eff < N_MIN:
        return Certificate(valid=False, reason='out_of_scope', k_star=0)
    q = weighted_quantile(scores, w_cal, w_test, 1 - alpha)
    return Certificate(valid=True, q=q, scope=scope, coverage=1-alpha-gap)
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（跨任务可辨识性）**：VISTA 的 Fisher 信息为 J_v=SᵀΣ⁻¹S；X-TAB 把任务行堆叠为 L=[S;ΔL]，则 J_xt=J_v+ΔLᵀΣ_Δ⁻¹ΔL⪰J_v，故 κ_xt≥κ_v；当且仅当 ΔL 有分量落在 span(S) 之外且任务噪声条件独立时严格增大。**多任务不是无条件增益**：若共享编码器造成任务间共模相关，Σ_Δ 退化，新增任务行共线，κ 不升反降。
- **引理 10（未知故障的检出与不可辨识下界）**：H0 下 n∼χ²_{d−K}，阈值给出误报≤α_nov；对加载 ℓ_n 的新故障，非中心参数 δ²=‖Π⊥ℓ_n‖²θ_n²/σ²，功效随 δ² 单调增；若 Π⊥ℓ_n=0，则任何检验功效≤α_nov——只能报等价类，这是信息论下界，而非算法缺陷。
- **引理 11（加权 conformal 覆盖）**：在协变量漂移、权重已知或估计误差≤δ_w 时，WCC 的部署覆盖≥1−α−δ_w；n_eff 控制分位估计方差，n_eff<n_min 时覆盖率不可信，故必须触发 `out_of_scope`。
- **定理 9（X-TAB 端到端归因-作用域安全）**：在 A94–A98 下（面板满秩、任务条件独立、scope 覆盖、无泄漏、k*≤m），Valid(J_xtab) ⇒ 故障被归入正确等价类或判 novel ∧ 不强行误归因 ∧ 块前缀安全；单块越界概率≤α_chunk+δ_fi+α_nov+α_vis+α_scope。
- **定理 10（作用域不可省与选择偏差）**：任何有限基准都无法保证作用域外部署的安全（存在基准观测完全相同、部署安全性不同的两个任务，不可区分）；从 N 个候选中选最优者的乐观偏差约 σ√(2lnN/n)，必须同时覆盖/切分校正。故「基准作用域 + 选择校正」不是工程选项，而是证书成立的前提。
- **命题（任务孪生探针的降险）**：若孪生探针物理风险≤ε_t 且信息增益≥δ_fi，则每次判别探针的期望物理风险≤ε_t，相比直接物理探针按 ε_t/ε_phys 比例下降，且判别错误率不升。

## 5. 本轮最大风险

**一句话**：X-TAB 的可辨识性与证书有效性都建立在「任务面板能覆盖部署、且任务在给定故障下条件独立」之上；但**基准/任务面板本身会成为新的单点故障**——共享编码器造成的共模失效会让所有任务同时错且方向一致，跨任务一致性会把「一起错」误读成「相互印证」，而部署任务一旦落在声明作用域之外，证书仍然可能被自信地引用；这是本轮全部面板可辨识性与作用域论证共同依赖的隐藏假设（A94）。

## 2. 形式化定义（完整版）

**定义 233（X-TAB 闭环）** X-TAB 是 VISTA 的「跨任务可辨识 + 基准作用域化」升级：保留 GRIP/VISTA 的语义流/实时流骨架，新增 TPD（任务面板设计）、CRT（跨任务残差张量）、FIR-X（面板归因）、NFD（未知故障检测）、AFA-T（任务级探针）、TIM（任务干扰监测）、BSC（作用域证书）、WCC（加权覆盖）、GRB/AIC-X（抗 Goodhart 基准），并原位升级 RSC-V→RSC-X、CSC→CSC-S、CSP-V→CSP-X、J_vista→J_xtab。不变式：**任务面板设计、面板归因、novel 检测、作用域判定只在语义流；实时流只做残差采集、作用域门、安全前缀执行与早停，零学习写操作。**

**定义 234（任务族、任务孪生与基准分布）** 任务 τ=(g 几何, a 外观, o 物体, l 载荷, t 时序, σ 技能)。若 τ,τ′ 仅一个因子不同，称**任务孪生**，记 τ∼_k τ′，k 为被隔离因子。基准 B={τ_i}_{i=1}^T 采自 P_bench；证书作用域 Σ 是任务因子取值域的笛卡尔子集。TPD 的设计目标：选任务子集 B 使 L 的列尽可能正交且覆盖高风险因子组合，等价于在任务层面做 D-最优/正交表设计。

**定义 235（跨任务残差张量）** R∈ℝ^{T×P×C}，R[τ,p,c] 为任务 τ、阶段 p∈P={approach,touch,load}、通道 c∈C 的标准化残差。C 沿用 VISTA 的 5 个通道（视觉/力/力矩/块一致性/块方差），并新增 task-vector 余弦与梯度冲突两个通道（仅训练/适配期可得）。r=vec(R) 按任务-阶段展平，噪声协方差 Σ_R 由标定/重复实验估计。

**定义 236（故障加载张量）** 设故障幅度 θ，观测模型
r = Lθ + b + ε，b 为任务/阶段固定效应 nuisance，ε∼N(0,Σ_R)。
第 k 列 ℓ_k(τ,p) 是故障 k 的**加载剖面**：
- **H_force**：ℓ_k(τ,p)≈1 对所有 τ（任务不变），仅在 approach（零力窗 DC 偏置）非零；
- **H_geo**：ℓ_k(τ,p)=1[g(τ)∈G_target]，在 approach/touch 非零，load 近零；
- **H_model**：ℓ_k(τ,p)=1[接触/加载]，仅 load 非零；
- **H_vis**：ℓ_k(τ,p)=1[a(τ)∈A_adverse]，在 approach/touch 非零；
- **H_policy**：ℓ_k(τ,p)=e_τ（单任务），伴高块方差；
- **H_transfer**：ℓ_k(τ,p) 与任务梯度冲突符号相关（任务间反相关），跨任务出现；
- **H_bench**：仅在作用域边界/基准成员上出现，属证书层故障；
- **H_novel**：ℓ_new 落在 span(L) 之外或部分之外。
加载剖面由 TPD 的设计与离线故障注入共同确定；未知故障不预设 ℓ。

**定义 237（跨任务可辨识性与等价类）** 跨任务 Fisher 信息 J_xt=LᵀΣ_R⁻¹L，κ_xt=λ_min(J_xt)/λ_max(J_xt)。θ 可辨识 ⇔ J_xt≻0。若两列 ℓ_k,ℓ_j 在噪声度量下的主角度小于 τ_eq（近共线），则它们在观测上不可分，只能输出**等价类** [k]={j:ℓ_j∈span(ℓ_k)}。**输出等价类不是失败，而是诚实**：强行给出单一标签才是本轮要修的错误。

**定义 238（面板故障归因 FIR-X）** 对 r 做稳健分解
r = Lθ + UVᵀ + S + ε，
其中 UVᵀ 为低秩共享 nuisance（跨任务共同漂移），S 为稀疏任务特异项，ε 为噪声。用加权/稳健最小二乘或 Huber 回归估 θ̂；在已知故障上计算
P(H|θ̂) ∝ p(θ̂|H) P(H)，
p(θ̂|H) 由离线故障注入拟合（高斯/混合/小归一化流）。若 max_H P<1−δ_fi，进入 AFA-T，或直接输出等价类并标记 `attribution_ambiguous`。FIR-X 的处置沿用 VISTA 的定向膨胀，但作用对象从单任务球改为「故障×任务作用域」。

**定义 239（未知故障检测 NFD）** 令 z=r−Lθ̂。novel 统计量
n=‖Π_{span(L)^⊥} z‖²/σ²。
H0（无未知故障）下 n∼χ²_{d−K}，取 q(α_nov) 为其 1−α_nov 分位，n>q 判 H_novel。为排除低秩 nuisance 与稀疏观测噪声，附加两项检验：(i) 主角度 τ_ang=angle(span(z), span(L))，只有 τ_ang>τ_min 才算结构性的未知；(ii) 结构能量比 ‖z_struct‖²/‖z‖²>ρ_min。若 Π⊥ℓ_new=0（未知故障完全落在已知加载张成内），则 n 的期望不增，**任何检验功效≤α_nov**：这是不可辨识下界，只能报等价类。

**定义 240（任务级判别探针 AFA-T）** 探针 a=(τ′, 技能, 阶段模板)，τ′ 优先取 τ 的安全孪生（仿真孪生、软体复制、同几何异物体、同外观异几何）。选择
a* = argmax_{a∈A} I(ℋ; ρ_new(a) | ρ) / (c_phys(a)+λ_c)，
s.t. 预测物理风险≤B_risk、预测形变≤ε_strain、支持视觉/力早停。
目标从 VISTA 的「故障互信息」升级为「**单位物理风险的故障互信息**」：在信息量相同的情况下优先选不接触/低载荷的任务孪生。边际信息<δ_fi 或所有物理探针超预算时，退化为纯观测 + null_test。

**定义 241（任务干扰监测 TIM）** 多任务共享参数会带来负迁移与共模失效。定义任务梯度冲突
g_cos(τ,τ′)=⟨∇_τ,∇_τ′⟩/(‖∇_τ‖‖∇_τ′‖)，
task-vector 离群度 o_τ=‖v_τ−v̄‖/std(v)，其中 v_τ=θ_τ−θ_shared。若 g_cos<−δ_g 且某任务残差上升，判 H_transfer。与 H_policy 的区分标准：H_transfer 在**跨任务**呈反相关签名、且随联合训练步数出现；H_policy 只在单任务出现、与块方差同向。TIM 只在训练/适配期与语义流运行，实时流不写。

**定义 242（基准作用域与覆盖差距）** 证书作用域 Σ=(𝒢,𝒜,𝒪,ℒ,𝒯,𝒮) 为任务因子取值域的乘积子集。用密度比 w(τ)=dP_dep/dP_bench(τ) 估计部署分布；覆盖差距 g_scope=TV(P_bench,P_dep)（或 MMD），有效样本 n_eff=(Σw)²/Σw²。判定：
`out_of_scope` ⇔ g_scope>ε_scope ∨ n_eff<n_min ∨ ∃ 因子水平不在 Σ 内。
作用域外，证书不得宣称覆盖；系统进入保守回退（RSC-X 膨胀 r_scope、CSC-S 截断 k*）。

**定义 243（加权 conformal 覆盖 WCC）** 标定分数 s_i、权重 w_i=w(τ_i)、测试权重 w_test。取加权分位
q̂=inf{q: Σ_i p_i·1[s_i≤q]≥1−α}，p_i=w_i/(Σ_iw_i+w_test)，
则协变量漂移下 P[s_test≤q̂]≥1−α。若权重由估计得到且误差≤δ_w，覆盖率降为 ≥1−α−δ_w；n_eff 小则分位估计方差大，必须提高 α 或判 out_of_scope。**覆盖率是作用域内的承诺，不是全局承诺。**

**定义 244（基准作用域证书 J_xtab）** 
J_xtab=(J_vista, benchmark_scope, coverage_gap, n_eff, fault_equivalence_class, novel_fault, cce, leakage_free, aic_x_ver)。
验证规则：
Valid(J_xtab) ⇔ Valid(J_vista)
∧ scope 匹配（部署任务∈Σ）
∧ (max_H P≥1−δ_fi ∨ 已判等价类 ∨ 已判 novel)
∧ coverage_gap≤ε_scope ∧ n_eff≥n_min
∧ leakage_free ∧ cce≤ε_cce
∧ aic_x_ver 为当前版本。
审计链新增：**为什么这个故障结论只到等价类**（主角度/不可辨识下界）、**证书对哪个任务分布有效**（scope）、**基准是否可能被游戏**（cce/leakage/选择校正）。

**定义 245（抗 Goodhart 基准 GRB）** GRB 的四条硬约束：
1. **任务级/物体级切分**：同一物体实例、同一几何族不得同时出现在标定与测试；泄漏检测器 `leakage_free` 失败即证书作废。
2. **隐藏留出任务**：维护一个不参与方法选择的隐藏任务集 B_hidden，仅用于最终报告。
3. **对抗轮换**：每轮从 ℰ_task（几何/外观/载荷/时序的系统性偏移）与 ℰ_leak（任务重放、时序错位、标定泄漏）中采样新任务，防止对固定基准过拟合。
4. **最差任务 + 证书校准**：报告 min_τ safety_margin、worst-task success 与 cce；禁止只用平均成功率排名。
AIC-X 在 ℰ_X=ℰ_V×ℰ_task×ℰ_leak×ℰ_select 上重算 ρ_dir；`H_bench` 在作用域边界被显式注入，用于测试 out_of_scope 检出。

**定义 246（选择偏差校正）** 从 N 个候选方法/策略中选基准最优者时，基准分数是有偏的。采用三选一：
(i) 同时 conformal：对每个候选取 α′=α/N（Bonferroni）；
(ii) 数据切分：一半选候选、一半标定证书；
(iii) 选择性推断：用最大值分布/参数 bootstrap 校正。
校正后的覆盖率才可写入 J_xtab。该定义把「排行榜选择」这一隐性自由度显式纳入证书预算。

**定义 247（RSC-X / CSC-S / CSP-X 作用域化）** RSC-X 维护 r_geo/r_force/r_model/r_scope：作用域外只膨胀 r_scope（不误伤已标定的几何/力球），scope 匹配时按 FIR-X 归因定向膨胀。CSC-S 的认证前缀在 VISTA 基础上加作用域门：
k* ← 0 若 out_of_scope ∨ leakage_free=False；
否则 k* 按 VISTA 计算并满足越界预算 α_chunk+δ_fi+α_nov+α_vis+α_scope。
CSP-X 在技能图上把任务孪生作为对照边，块签名需在任务面板上可比（Mahalanobis 距离按任务标准化），否则判 OOD。

**定义 248（X-TAB 闭环算子）** 语义流：[VISTA 语义流 → TPD 建任务面板/对照对 → CRT 残差张量 → FIR-X 面板归因 → NFD → AFA-T/TIM → WCC 加权覆盖 → BSC 作用域证书 → GRB/AIC-X]。实时流：[锚点读 → 视觉/力/块残差采集 → 作用域门 → CSC-S 认证前缀/早停 → WCV-V 编译 → π_σ 前缀派发 → J_xtab 构建]。

```python
class PanelFaultIsolation:
    """跨任务面板分解：已知故障后验、等价类、novel，不强行单选。"""
    def __init__(self, known, lik, prior=None, delta_fi=0.15,
                 alpha_nov=0.05, tau_eq=0.15, tau_min=0.20, rho_min=0.3):
        self.known, self.lik = known, lik
        self.prior = prior or {h: 1.0 / len(known) for h in known}
        self.delta_fi, self.alpha_nov = delta_fi, alpha_nov
        self.tau_eq, self.tau_min, self.rho_min = tau_eq, tau_min, rho_min

    def build(self, residual_log, tasks, phases):
        R = np.zeros((len(tasks), len(phases), N_CHANNELS))
        for (tau, p), ev in residual_log.items():
            R[tau, p] = standardize(ev, tau, p)
        return R

    def attribute(self, r, L):
        theta, U, S = robust_panel_fit(r, L, rank_r=RANK_R)
        z = r - L @ theta
        stat = np.linalg.norm(project_orth(z, L)) ** 2 / SIGMA2
        q = chi2.ppf(1 - self.alpha_nov, df=len(r) - L.shape[1])
        ang = principal_angle(span(z), span(L))
        struct = struct_energy_ratio(z)
        if stat > q and ang > self.tau_min and struct > self.rho_min:
            return {'verdict': 'H_novel', 'post': None, 'class': None,
                    'novel_stat': stat}
        post = self._posterior(theta)
        h_star = max(post, key=post.get)
        eq = equivalence_class(L, self.tau_eq)          # 近共线列合并
        ambiguous = post[h_star] < 1.0 - self.delta_fi
        return {'verdict': h_star, 'post': post, 'class': eq,
                'ambiguous': ambiguous}

    def _posterior(self, theta):
        lp = {h: np.log(self.lik[h](theta) + 1e-12) + np.log(self.prior[h])
              for h in self.known}
        z = np.array(list(lp.values())); z -= z.max()
        return {h: float(np.exp(v) / np.exp(z).sum()) for h, v in lp.items()}


def equivalence_class(L, tau_eq):
    """按主角度把不可分的故障列合并成等价类。"""
    K = L.shape[1]
    parent = list(range(K))
    for i in range(K):
        for j in range(i + 1, K):
            if principal_angle(span(L[:, i]), span(L[:, j])) < tau_eq:
                parent[j] = find(parent, i)
    return {i: [j for j in range(K) if find(parent, j) == find(parent, i)]
            for i in range(K)}
```

### IP-228 AFA-T（任务孪生探针）

```python
class TaskLevelProbe:
    PROBE_KINDS = ('sim_twin', 'soft_twin', 'same_geometry', 'same_appearance',
                   'same_object_light', 'null_test', 'physical_press')

    def choose(self, post, task_graph, B_risk, fragile):
        best = (None, -np.inf)
        for kind in self.PROBE_KINDS:
            if fragile and kind == 'physical_press':
                continue
            for tau2 in task_graph.twins(kind):
                a = Probe(tau2, kind)
                pred = predict_probe(a)
                if pred.physical_risk > B_risk or pred.strain > EPS_STRAIN:
                    continue
                ig = expected_mutual_info(post, a, likelihood)
                score = ig / (pred.physical_risk + LAMBDA_C)
                if score > best[1]:
                    best = (a, score)
        if best[1] < DELTA_FI:
            return None, best[1]          # 放弃物理/任务探针，纯观测
        return best
```

### IP-231 WCC（加权 conformal）

```python
def weighted_quantile(scores, w_cal, w_test, level):
    """Tibshirani 式加权 conformal：先归一化，再取加权分位。"""
    p = np.asarray(w_cal, float)
    p = p / (p.sum() + w_test)
    order = np.argsort(scores)
    cdf = np.cumsum(p[order])
    idx = np.searchsorted(cdf, level, side='left')
    return float(scores[order[min(idx, len(scores) - 1)]])


def scope_certificate(scores, w_cal, w_test, scope, gap, n_eff,
                      alpha, alpha_select):
    if gap > EPS_SCOPE or n_eff < N_MIN:
        return {'valid': False, 'reason': 'out_of_scope', 'k_star': 0}
    q = weighted_quantile(scores, w_cal, w_test, 1 - alpha - alpha_select)
    return {'valid': True, 'q': q, 'scope': scope,
            'coverage': 1 - alpha - alpha_select - gap}
```

```python
class BenchmarkScopedCertificate:
    def certify(self, j_vista, post, eq, novel, scope, deployment, bench,
                k_star, selected_from=None):
        gap = tv_distance(bench.task_dist, deployment.task_dist)
        n_eff = effective_sample_size(deployment.weights)
        leakage_free = not bench.leakage_detected(scope)
        cce = abs(bench.claimed_coverage - bench.empirical_coverage)
        alpha_sel = bonferroni_alpha(ALUHA, selected_from)   # N 选 1 校正
        valid = (is_valid(j_vista) and scope.contains(deployment)
                 and (post_concentrated(post) or eq is not None or novel)
                 and gap <= EPS_SCOPE and n_eff >= N_MIN
                 and leakage_free and cce <= EPS_CCE)
        return Certificate(valid=valid, scope=scope, coverage_gap=gap,
                           n_eff=n_eff, fault_class=eq, novel=novel,
                           cce=cce, leakage_free=leakage_free,
                           alpha_select=alpha_sel,
                           k_star=k_star if valid else 0)


class GoodhartResistantBenchmark:
    def score(self, method, bench, hidden, candidates):
        per_task = [method.eval(t) for t in bench.tasks]
        worst = min(per_task)
        hidden_score = method.eval(hidden)
        cce = abs(method.claimed_coverage - empirical_coverage(method, bench))
        penalty = sqrt(2 * log(len(candidates)) / max(bench.n_episodes, 1))
        return {'worst_task': worst, 'hidden': hidden_score,
                'cce': cce, 'selection_penalty': penalty,
                'certificate_consistent': cce <= EPS_CCE}
```

## 4. 推导

**引理 9（跨任务可辨识性）** 设 VISTA 的观测模型 r_v=Sθ+ε_v，Fisher 信息 J_v=SᵀΣ_v⁻¹S。X-TAB 把任务行堆叠为 L=[S;ΔL]、Σ_R=blkdiag(Σ_v,Σ_Δ)，则
J_xt = SᵀΣ_v⁻¹S + ΔLᵀΣ_Δ⁻¹ΔL = J_v + ΔLᵀΣ_Δ⁻¹ΔL ⪰ J_v。
故 λ_min(J_xt)≥λ_min(J_v)，κ_xt≥κ_v。若 ΔL 存在落在 span(S) 之外的分量且 Σ_Δ≻0，则严格增大；若所有新增任务行都落在 span(S) 内（例如所有任务的加载剖面完全相同），增益为零。**若共享编码器使任务噪声共模相关，Σ_Δ 近似奇异（任务方向方差趋零），新增行在噪声度量下共线，κ_xt 不升反降**——这正是引理 10 与风险节要强调的边界。∎

**引理 10（未知故障的检出与不可辨识下界）** H0 下 z=Π⊥ε，ε∼N(0,σ²I)，故 n=‖z‖²/σ²∼χ²_{d−K}，阈值 q(α_nov) 给出误报≤α_nov。若存在加载为 ℓ_n 的新故障，则 z 含均值 Π⊥ℓ_n θ_n，n 服从非中心 χ²，非中心参数 δ²=‖Π⊥ℓ_n‖²θ_n²/σ²，功效随 δ² 单调增。反之若 Π⊥ℓ_n=0，则新故障对 z 的均值无贡献，n 的分布与 H0 完全相同，任何检验的功效≤α_nov：**这类故障在观测上不可辨识，只能输出等价类**。因此 NFD 的保证是「能检出的都检出，不能检出的诚实标注」，而非「全部检出」。∎

**引理 11（加权 conformal 覆盖）** 在协变量漂移下令 w(τ)=dP_dep/dP_bench。给定标定样本与权重，按定义 243 构造加权分位 q̂。由加权可交换性（Tibshirani et al. 2019），若权重精确，则
P_{dep}[s_test≤q̂]≥1−α。
若权重由有限样本估计且相对误差≤δ_w，则覆盖下界降为 1−α−δ_w；分位估计的方差随 n_eff 增大而减小，故 n_eff<n_min 时不得签发作用域内证书。∎

**定理 9（X-TAB 端到端归因-作用域安全）** 在以下假设下：
A94：任务面板设计使 L 满列秩，κ_xt≥κ_min（任务孪生提供了足够对照）；
A95：给定故障，任务残差条件独立（无共享编码器共模失效；否则见 TIM/风险）；
A96：部署任务∈Σ，g_scope≤ε_scope，n_eff≥n_min；
A97：任务级/物体级切分无泄漏，选择偏差已按定义 246 校正；
A98：CSC-S 的 k*≤m 且越界预算含 α_scope。
则 Valid(J_xtab) ⇒
1. 故障被归入正确等价类，或判 H_novel；**不存在把未知复合故障强行归入最近假设并定向膨胀错误球的情况**；
2. 作用域内证书覆盖≥1−(α_chunk+δ_fi+α_nov+α_vis+α_scope)；
3. 作用域外/泄漏/cce 超限时证书无效，系统进入保守回退（k*=0 或 RSC-X 膨胀 r_scope）；
4. GRIP/VISTA 的几何-技能-干扰-接触安全链保持。
证明：由引理 9，A94 下 θ 可辨识；由引理 10，未知故障要么检出（H_novel）要么归入等价类；由引理 11 与 A96/A97 得覆盖；由定义 244/247 的作用域门与 k* 截断得回退安全；与第 65 轮定理 7 的联合界合并即得。∎

**定理 10（作用域不可省与选择偏差）**
(a) 对任意有限基准 B 与任意 ε>0，存在两个部署任务 τ_1,τ_2 在 B 上观测分布完全相同、但 τ_2 含有 B 未覆盖的几何/外观因子且安全性不同。任何仅依赖 B 的证书对 τ_1,τ_2 给出相同结论，故必有一个不安全。因此**没有作用域假设就没有有限基准证书**；scope 不是文档字段，而是证书成立的前提。
(b) 设候选方法在基准上的分数近似 N(μ_i,σ²/n)，从 N 个候选中取最大者，其期望乐观偏差约为 σ√(2lnN/n)（极值理论/高斯最大值的标准估计）。若不校正，声称的覆盖率会系统性偏高；Bonferroni/数据切分/选择性推断可把偏差压回 α 预算内。
故「基准作用域 + 选择校正」是可证伪证书的必要组成。∎

**命题（任务孪生探针的降险）** 设物理探针的期望伤害为 ε_phys，孪生探针为 ε_t≪ε_phys，且孪生探针提供的故障互信息 I_t≥δ_fi。则 AFA-T 的每次判别探针期望伤害≤ε_t，较直接物理探针下降 ε_t/ε_phys；在信息量不低于 δ_fi 时，判别错误率不高于物理探针（由互信息的数据处理不等式，信息量不降则后验熵不升）。易损物体上禁用 physical_press 后，该命题保证「不接触也能判别」在信息足够时成立。∎

**命题（基准设计作为 D-最优）** 任务面板设计的目标 max_B det(LᵀΣ_R⁻¹L) 等价于在任务层面做 D-最优实验设计；若候选任务对数成本可加，则贪心最大化行列式具有 (1−1/e) 近似保证（子模性）。这把「基准测试」从人工挑任务升级为可优化的实验设计问题。∎

## 7. 已知风险

**一句话**：X-TAB 的可辨识性与证书有效性共同依赖「任务面板覆盖部署、且任务在给定故障下条件独立」；但**基准/任务面板本身会成为新的单点故障**——共享编码器造成的共模失效会让所有任务同时错且方向一致，跨任务一致性会把「一起错」误读成「相互印证」，而部署任务一旦落在声明作用域之外，证书仍可能被自信地引用；这是本轮全部面板可辨识性与作用域论证共同依赖的隐藏假设（A94）。

**次级风险与缓解**：
1. **任务面板有限**：有限任务无法张成全部故障方向；缓解：D-最优/正交设计、按风险优先覆盖、显式报告 κ_xt 与等价类大小，κ_xt 过低时拒绝定向处置。
2. **共模失效（最危险）**：共享编码器/标定使任务残差相关，跨任务一致性不再是独立证据；缓解：TIM 监测梯度冲突与 task-vector 离群，强制保留至少一个**架构独立**的通道（IMU/本体感觉/独立相机），并在 A95 被违反时判 ambiguous。
3. **作用域估计不可靠**：部署分布未知，密度比与 TV 距离只能估；缓解：保守先验、OOB 检测、作用域外 k*=0、在线漂移监测与定期重标定。
4. **Goodhart 的适应性对手**：轮换基准仍可能被元过拟合；缓解：隐藏集只报告、外部审计、证书校准误差纳入失效条件、限制候选选择次数。
5. **等价类过大**：低可辨识性下只能报大等价类，实用性下降；缓解：主动选择能增大 κ_xt 的任务对照（AFA-T + TPD 联合设计），但需付出数据/时间成本。
6. **多任务负迁移**：共享参数拖累某任务；缓解：TIM 显式建模 H_transfer、按任务隔离关键安全模块、负迁移时回退单任务策略。
7. **数据泄漏**：同一物体/几何族跨切分导致覆盖虚高；缓解：任务级/物体级切分、leakage_free 硬门、审计哈希。
8. **实时预算**：作用域门与残差张量使实时路径逼近 2.6ms；缓解：增量更新、降采样、把 FIR-X/NFD/GRB 全部留在语义流。
