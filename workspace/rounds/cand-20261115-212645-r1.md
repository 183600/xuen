# 第 10 轮（本轮灵感：「地形适应」×「伦理与合规」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**物理接地 + 规范外置**。v9 的信任域 U_t={Δ_dom<τ_dom ∧ risk_SLAM<τ_SLAM} 是统计抽象的，其已声明的最大风险正是"滑窗滞后于真实跳变"。地形适应为前向模型提供**物理有效性条件**（包络成员性 + 本体滑移快检），把 OOD 检测从"20 帧漂移"变成"1–3 周期接触异常"。伦理与合规提供**规范有效性条件**，但它不是又一个可注入中立元的模块——它是**不可补偿、无许可性恒等元**的约束层，必须外置为最外层的否决/地板，而不能并入 v9 的恒等元退化格。两个灵感合起来回答同一件事：**证书在什么条件下才配被信任**（物理上 + 规范上），但两者的失效代数必须不同。

## 0. 直觉与动机

**灵感 1（地形适应 → 地形接地的信任域与快检 OOD）**
直觉：v9 的块证书依赖"信任域内前向模型误差 ≤ β"，可 U_t 是靠 Δ_dom 的 20 帧滑窗判定的，域跳变最快的时刻恰恰最晚被看见。地形把这件事物理化：轮式/足式机器人在瓷砖、地毯、门槛、碎石、斜坡、湿滑面上的摩擦、滑移、姿态耦合完全不同，前向模型 F̂ 只在**被标定过的地形包络**内可信。核心创新：**地形适应信任域（TerrainAdaptiveTrust, TAT）**——(i) 维护地形状态 τ_t=(c_terr, T, μ̂, θ̂, σ̂) 与每种运动模式的地形包络 E_m；(ii) 用**分裂共形预测（split conformal）**给出 Δ_terr 的有限样本覆盖率保证（1−α），使"证书无效"成为**包络成员性**问题而非漂移阈值问题；(iii) 用轮速-指令残差/足端滑移比构造**本体滑移监测器（PSM）**，2–3 个控制周期即触发 K_eff←1。证书改为**地形条件证书**：刹停距离用 d_brake(v; μ̂_LB, θ̂) 的摩擦下界，间隙余量加 β_terr。这直接把 v9 的风险从"最需要安全时证书最不可靠"改写为"物理接触永远比统计漂移先到"。

**灵感 2（伦理与合规 → 规范否决层与不可中和律）**
直觉：MetricVoiceGauge 是**语音/音频系统**，它天然处理隐私数据（人声、声纹、家庭声场）；它又要在有人环境里做高风险动作（抓取、递物、跟随）。功能模块坏了注入 v^⊥ 是保值的；但"隐私过滤器坏了注入恒等元"等于**撤销限制**——这是把"失效"变成"放行"。伦理与安全在代数上根本不同：安全可补偿（停下即可），隐私泄露、欺骗、尊严伤害往往**不可逆**。核心创新：**伦理合规监督器（EthicalComplianceSupervisor, ECS）**——许可集上的 meet-semilattice，约束为不可补偿合取（∧），无许可性恒等元；ECS 失效时注入的是**规范地板 ζ_⊥ = 字典序"最小违规、再最小风险"的可行动作**，而不是功能层的 v^⊥。附带：同意状态机（ConsentFSM，授权/范围/过期/撤回+级联清除）、目的与保留标签、**非欺骗可解释披露**（每次 M₀ 否决/安全停驻/模式切换都输出结构化理由，且不得宣称不具备的能力），以及**合规证据账本（CEL）**把"合规"从叙事变成可机器核验的产物。为此新增 **P14 伦理不可中和律**：伦理层只能向下（更受限）退化，永远不能向"放行"退化。

**灵感 3（两轴信任域的合成，本轮统一论题）**
直觉：v9 的 U_t 是**认知性的**（我信不信我的模型）。地形给的是**物理可描述性**，伦理给的是**道义可接受性**——前者是"能不能"，后者是"该不该"。两者都以 ∧ 合取进入"证书是否有效"，但失效语义相反：物理不确定性可通过降速/缩块/停驻来**补偿**（对偶于 v9 的 K_eff←1），规范约束**不可补偿**（不能拿高任务收益抵一次隐私泄露）。所以统一框架是：**合取于生效条件（∧），分离于退化代数（⊕ 恒等 vs ∩ 底元）**。任何把它们塞进同一个中立元格的设计都会犯范畴错误：要么隐私被"恒等元注入"放行，要么系统因过度保守而死锁。

## 1. 研究问题（轮次升级版）

- **Q1（物理接地与延迟）**：如何把前向模型信任域改写为地形包络成员性 + 本体滑移快检，使中块证书失效的检测延迟从 O(20 帧) 降到 O(k_prop) 周期，且以分布无关（conformal）覆盖率 1−α 保证 β 的保守性？
- **Q2（规范代数的正确失效）**：伦理约束的失效映射为何不能复用功能层的中立元？如何定义"许可集 meet + 底元 + 规范地板 ζ_⊥"三重结构，使 ECS 任意失效下最终动作仍**合规或最小违规**，同时给出活性（不死锁）的可证边界？
- **Q3（两轴耦合与不可逆性）**：地形诱发的物理风险如何通过"风险施加预算 ρ_max"约束对旁观者的伦理可接受速度；不可逆违规（隐私/欺骗/尊严）如何在事**前**以概率 0 排除，而可逆违规允许事后纠正？地形不确定性上升时，伦理层是否应自动提高披露与求助频率？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 地形接地信任律（Terrain-Grounded Trust, TAT）**
块证书只在"地形包络成员 ∧ 滑移低于阈值 ∧ v9 原 U_t"三者合取时有效：U_t^TA = U_t^v9 ∧ (Δ_terr(t) < τ_terr) ∧ (σ̂_t < τ_slip)。刹停距离改为地形条件 d_brake(v; μ̂_LB, θ̂)；证书间隙余量加 β_terr。本体滑移监测器（PSM）以 ≤3 周期延迟报警，任何滑移越阈立即 K_eff←1 并进入安全停驻评估。地形包络外的未知地面一律视为证书无效——**未知即不安全，而非未知即可信**。

**P14 伦理不可中和律（Non-Neutralizable Ethics, ECS）**
伦理约束 e_j 是 (动作, 上下文, 数据流) 上的不可补偿谓词，合规 = ∧_j e_j；伦理层无"许可性恒等元"，故失效**不得**注入功能层中立元 v^⊥（其语义是放行）。ECS 不可用或某约束不可评估 ⇒ 注入规范地板 ζ_⊥ = lexicographic-argmin_a (Vio(a), Risk(a)) s.t. 物理可行；伦理层位于动作流水线**最外层且永不可消融**（φ^elig≡false 且不可 neutralizable）。不可逆违规（隐私泄露、欺骗、尊严伤害）要求事前概率 0；可逆违规允许纠正。伦理层只向"更受限"退化，永不向"放行"退化。

**P15 可解释披露律（Explainable Disclosure, ED）**
每次 M₀ 否决、安全停驻、运动模式切换、跨出地形包络、数据访问/清除，都产出结构化理由 r_t=(trigger, evidence, alternatives_considered, reversibility, data_used, confidence)。披露必须**非欺骗**：不得宣称系统不具备的能力，不得隐藏降级事实（降级即披露）。语音通道是 MetricVoiceGauge 的一等输出。所有披露写入**防篡改合规证据账本（CEL）**（哈希链），供审计与预注册复核。

## 3. 与基线的接口（如何退化，v10 七级）

- **Level-0（最外，新增）**：ECS 失效/约束不可评估 ⇒ 规范地板 ζ_⊥（字典序最小违规动作）；**不**回退到 v^⊥，因为那会放行；
- **Level-1（新增）**：地形 OOD / 滑移越阈 ⇒ K_eff←1 + 地形条件限速 + 模式切换/求助（披露）；
- **Level-2**：AC 块证书失效 ⇒ K_eff←1，逐步执行，等价 v9；
- **Level-3**：MW 失效 ⇒ 切 v8 手写网关（代码保留），等价 v9；
- **Level-4**：ID 失效 ⇒ 全模块 active、归因冻结，等价 v9；
- **Level-5**：v8 的 DA/SPR/Cal 失效 ⇒ 中立元注入（Δ_dom≡0 / risk_SLAM≡0 / weight≡1），等价 v7；
- **Level-6**：全失效 ⇒ 退回 MetricVoiceGauge-OTL-GC-ER v7，再退回 v6。
> **关键顺序**：功能链（AC/MW/ID/v8）先算出候选动作 a_raw；ECS 在**最外层**以许可集 ∩ 过滤；若过滤后为空，走 ζ_⊥。ECS 只订阅功能链状态、不被功能链消融，故任意功能退化态都不能绕过伦理否决（引理 92）。

- TAT 失效 ⇒ 退回 v9 的统计信任域 U_t（保守开关：缺地形信息时按最差地形 μ̂_LB 计）；
- ECS 失效 ⇒ ζ_⊥（更受限），非 v^⊥；
- 全部失效 ⇒ 规范地板 + 物理最保守停驻，退到 v6 安全语义。

## 4. 预期贡献

1. **地形接地信任域**：把"模型可信"从统计漂移改成物理包络成员性，用共形预测给 β 分布无关覆盖保证，用本体滑移把 OOD 延迟压到周期级，正面消解 v9 已声明的最大风险；
2. **伦理不可中和律**：形式化"功能可补偿、伦理不可补偿"的代数差异，证明中立元退化对伦理层不健全，给出 meet+底元+规范地板的三重正确结构；
3. **风险施加预算与地形-伦理耦合**：把"未知地形 ⇒ 对旁观者风险上升"写成可计算的限速约束 p_collide(v;μ̂)·severity ≤ ρ_max，让伦理约束可标定、可预注册；
4. **合规证据账本 + 非欺骗披露**：把合规从论文叙事变成防篡改、可机器核验的产物；E571–E590 覆盖地形 OOD/滑移延迟、共形 β、同意/保留、规范地板活性、不可逆违规、地形×伦理耦合、全退化格等价与端到端。

## 5. 本轮最大风险

**一句话**：地形包络与规范地板都建立在两个未被证成的信任前提上——包络的标定集若只覆盖实验室地面、共形交换性假设在真实部署中失效，则"包络内"的证书可能是**系统性错误**；而 ECS 在最坏情况下退到"最小违规动作"，若该动作在真实紧急场景（如停在楼梯口/消防通道）本身就是新的物理风险，两层保护会在最需要时同时失效——即「物理信任的标定偏差与规范地板的保守死锁在同一时刻彼此掩盖」。

**新增定义 540（地形状态 TerrainState）** τ_t=(c_terr, T_t, μ̂_t, θ̂_t, σ̂_t)。c_terr 由本体（IMU 振动谱、轮/足接触、电流残差）+ 外感（深度/语义）融合；T_t∈[0,1] 为可通行度；μ̂_t 为摩擦估计（带置信区间）；θ̂_t 坡度；σ̂_t 滑移比。τ_t 以 50Hz 更新，外感地形类以 10Hz 更新并异步融合。

**新增定义 541（地形包络 TerrainEnvelope）** 对每个运动模式 m（轮式/足式步态/爬坡/爬梯），E_m ⊆ TerrainState 是离线验证集 D_m 的经验覆盖域：∀τ∈D_m，前向模型 F̂_m 的指标误差 ≤ β_terr(D_m 上 conformal 分位数)。包络用一类分类器（如深度 SVDD / 马氏距离）近似成员函数，阈值由 D_m 的 (1−α) 分位数确定。**包络外一律视为证书无效**。

**新增定义 542（共形地形 OOD 分数 ConformalTerrainOOD）** 用分裂共形：标定集 D_cal={τ_i}，非一致性得分 s(τ)=d(τ, Ê_m)（到包络中心的距离度量）。对在线 τ_t，Δ_terr(t) = #{i: s(τ_i) ≥ s(τ_t)} / (|D_cal|+1)。则在可交换性成立时 P(Δ_terr ≤ α) ≥ 1−α；Δ_terr ≥ τ_terr 判为 OOD。**交换性只在同一地形包络内被主张**（这正是 P13 的物理接地：包络是交换性的边界）。

**新增定义 543（地形条件块证书 Terrain-Conditioned Certificate）** 在 v9 定义 533 上替换：
```
d_brake(v; μ, θ) = v² / (2·μ·g·cosθ) + v·t_react        （μ 取 μ̂_LB）
ĝ_min = min_{k≤K} [F̂_clearance(s,a^{1:k}) − β − β_terr]
ê_max = max_{k≤K} [F̂_effort + β + β_terr]
证书有效 ⇔ 上述 ∧ γ̂_grasp valid ∧ (模式 m 的 τ_t∈E_m) ∧ Δ_terr<τ_terr ∧ σ̂<τ_slip
```
β_terr 由 E574 标定：对每个包络取 D_m 上误差分位数再乘 1.2 安全系数；地形不确定时 β_terr 随 Δ_terr 单调递增（保守插值）。

**新增定义 544（本体滑移监测 ProprioceptiveSlipMonitor, PSM）** 对轮式：σ̂ = (v_cmd − v_meas)/max(v_cmd, v_eps)；对足式：σ̂ = 1 − (Δp_contact_expected·n̂)/|Δp| 的支撑相残差。残差经 CUSUM 累积：
```
g_t = max(0, g_{t-1} + |σ̂_t| − k_σ),   报警 ⇔ g_t ≥ h_σ
```
取 k_σ=0.15, h_σ=0.45，使 σ̂ 持续 ≥0.5 时 ≤3 周期报警（50Hz 下 ≤60ms），远快于 v9 的 20 帧（400ms）滑窗。报警 ⇒ K_eff←1 且触发 μ̂ 重估计与限速。

**新增定义 545（伦理约束集 EthicalConstraintSet）** E={e_1..e_6}，每个 e_j: (a, ctx, data) → {0,1}，合规 = ∧_j e_j（**不可补偿**：无权重、无 trade-off）：
- e_1 同意：处理音频/声纹/影像需对应 scope 的有效同意；
- e_2 数据最小化：仅采集达成当前任务目的所必需的数据类别；
- e_3 目的限定：数据用途不得越出授权目的标签；
- e_4 非欺骗：对外陈述（含语音）不得宣称系统不具备的能力或隐藏降级；
- e_5 尊严/可及：交互高度、语速、对待方式适配对象，不造成羞辱或排除；
- e_6 可审计：每个高风险动作与数据访问都留可核验证据。
约束按**不可逆度**排序：e_1,e_4 视为 irreversible（泄露/欺骗不可撤销），e_2,e_3 可逆但需纠正，e_5,e_6 可纠正。Vio(a) 为按此序的违规指示向量，比较用字典序。

**新增定义 546（伦理契约 EthicalContract）** 扩展 v9 定义 535 的 κ_m，新增字段 (purpose, data_class, retention, consent_scope, reversibility, non_neutralizable)。`non_neutralizable=True` 的契约其失效值不由 v_m^⊥ 决定，而由 NFC 的 ζ_⊥ 决定；`distill_eligible=False`（φ^elig≡false）。ECS 自身、NFC、SpatialCert、FaultCert、M₀ 硬检查均属此列。

**新增定义 547（规范地板 NormativeFloor, ζ_⊥）** 当 ECS 不可用或某 e_j 不可评估时：
```
ζ_⊥ = lexicographic-argmin_{a ∈ A_phys} ( Vio(a), Risk(a) )
A_phys = {a : 满足 v9 M₀ 硬约束与地形条件物理安全}
```
ζ_⊥ 不是"停下"的同义词：在楼梯口/消防通道停车可能制造新风险，故 ζ_⊥ 是**最小违规、再最小风险**的可行动作。若 A_phys=∅（理论上不应发生，前提见引理 90）⇒ 硬件级受控停驻。NFC 运行于独立极小可信基（ROM/独立 MCU），不依赖功能链。

**新增定义 548（同意状态机 ConsentFSM）** 每类数据 d 一个状态机：none → granted(scope, purpose, expiry) → revoked。迁移规则：granted 仅在签名授权且 scope/purpose 匹配时有效；expiry 到点自动 revoked；revoked 触发**级联清除**——所有派生数据（特征、嵌入、声纹模板）在 retention SLA（默认 ≤5 分钟，可配置）内清除，并写 CEL 一条不可删审计记录（只记"已清除"不记内容）。任何 e_1 检查对未授权数据处理返回 0，包括"为了调试"的隐式访问。

**新增定义 549（可解释披露与证据账本 ExplanationDisclosure & Ledger）** 每次触发以下之一即生成 r_t：M₀ 否决、安全停驻/中止点切换、运动模式切换、Δ_terr 越阈、数据访问/清除、ζ_⊥ 触发。r_t 六元组须满足非欺骗校验：`claim ⊆ capability`（不得宣称不具备能力）、`degraded ⇒ disclosed`、`data_used ⊆ consented`。CEL 用哈希链 H_t = H(H_{t-1} ‖ r_t) 存储，提供篡改可检测性；审计可离线重放。

## 2. 形式化定义（要点与升级）

**定义 493（六层指标层级）** 继承 v9：M=(M₀,M₁,M₂,M₃,M_dom,M_SLAM) 不变。
**定义 521（DA-OTL）** 继承 v9；τᵢ(t) 的复核在 K_eff>1 时仍以块证书替代逐步复核，但块证书须为定义 543 的地形条件版本。
**升级定义 533/534（块证书/中止点）** 全部替换为地形条件版本：d_brake 依赖 (μ̂_LB, θ̂)；P_t 的停车不变式用 d_brake(v_p; μ̂_LB, θ̂)，故"湿滑面上的中止点更稀疏"自动反映为 P_t 收缩，骨架在 P_t=∅ 时拒绝候选。
**升级定义 496（软证书，v10）**
```
δ_trigger = {σ<τ_safe ∧ γ_grasp valid ∧ Δ_dom<τ_dom ∧ risk_SLAM<τ_SLAM
             ∧ Ĉ_t^TA valid ∧ Δ_terr<τ_terr ∧ ECS_allow(a)}
```
先由功能链给出 a_raw 与 δ_trigger；再由 ECS 以 ∧ 过滤。**伦理否决优先于一切功能触发**：ECS 拒绝时即使 δ_trigger 为真也不执行，转 ζ_⊥ 并披露。
**升级定义 531（软硬约束衔接）** M₀ 判据新增地形入口（滑移/包络越界即硬检查）与伦理入口（e_1/e_4 违规则硬拒绝）。

# IP-357 TerrainAdaptiveTrust：地形接地信任域
class TerrainAdaptiveTrust:
    def __init__(self, envelopes, calib, tau_terr=0.05, tau_slip=0.35,
                 k_sigma=0.15, h_sigma=0.45):
        self.E = envelopes            # {mode: (center, radius_quantile)}
        self.cal = calib              # {mode: [scores on D_cal]}
        self.tau_terr, self.tau_slip = tau_terr, tau_slip
        self.k_sigma, self.h_sigma = k_sigma, h_sigma
        self.cusum = defaultdict(float)
        self.beta_terr = {}           # 每包络 conformal 误差分位 × 1.2

    def conformal_ood(self, mode, tau):
        s = self.E[mode].score(tau)                       # 非一致性得分
        sc = self.cal[mode]
        return sum(1 for x in sc if x >= s) / (len(sc) + 1)   # 定义 542

    def slip_alarm(self, mode, cmd, meas):
        sigma = slip_ratio(mode, cmd, meas)               # 定义 544
        self.cusum[mode] = max(0.0, self.cusum[mode] + abs(sigma) - self.k_sigma)
        return self.cusum[mode] >= self.h_sigma, sigma

    def trust(self, mode, tau, cmd, meas):
        d_terr = self.conformal_ood(mode, tau)
        slip_alarm, sigma = self.slip_alarm(mode, cmd, meas)
        member = (d_terr < self.tau_terr) and (sigma < self.tau_slip) and not slip_alarm
        return Trust(member, d_terr, sigma,
                     beta_terr=self.beta_terr[mode] + self._ramp(d_terr))

    def speed_cap(self, mu_lb, theta, rho_max, severity):
        # 风险施加预算：p_collide(v)·severity ≤ rho_max（引理 91）
        return inverse_collision_risk(rho_max, mu_lb, theta, severity)


# IP-354（升级）：地形条件证书
class TerrainCondChunkCertifier(ActionChunkCertifier):
    def brake(self, v, mu_lb, theta):
        return v * v / (2 * mu_lb * G * math.cos(theta)) + v * T_REACT

    def generate_chunk(self, state, trust, delta_dom, tau_dom):
        K = self.effective_K(delta_dom, tau_dom, trust.member)   # 地形不信任 ⇒ K=1
        if K == 1:
            return self._single_step_fallback(state)
        best = None
        for cand in self.policy.sample_sequences(state, K, n=64):
            pred = self.F.rollout(state, cand)
            g_min = pred.min_clearance - self.beta - trust.beta_terr
            e_max = pred.max_effort + self.beta + trust.beta_terr
            if g_min < self.d_safe or e_max > state.tau_eff:
                continue
            pts = [p for p in range(1, K)
                   if (pred.clearance[p] - self.brake(pred.speed[p],
                         state.mu_lb, state.theta) - self.d_safe)
                      >= pred.path_len_remaining(p)]                 # 定义 543/534
            if not pts:
                continue
            s = self.policy.score(cand, pred)
            if best is None or s > best.score:
                best = Chunk(cand, Cert(g_min, e_max), pts, s)
        return best or self._single_step_fallback(state)


# IP-358 EthicalComplianceSupervisor：伦理否决 + 规范地板
class EthicalComplianceSupervisor:
    def __init__(self, consent, ledger, nfc, constraints):
        self.consent = consent               # ConsentFSM
        self.ledger = ledger                 # CEL
        self.nfc = nfc                       # TCB 内 NormativeFloorController
        self.e = constraints                 # {name: predicate}
        self.available = True

    def allowed_set(self, a_raw, ctx):
        A = [a_raw]
        for name, pred in self.e.items():
            A = [a for a in A if self._eval(name, pred, a, ctx)]
        return A

    def _eval(self, name, pred, a, ctx):
        try:
            return pred(a, ctx, ctx.data_flow)
        except Exception:
            self.available = False           # 不可评估 ⇒ 触发地板
            return False

    def gate(self, a_raw, ctx):
        if not self.available:
            return self._floor(a_raw, ctx, reason="ECS_UNAVAILABLE")
        A = self.allowed_set(a_raw, ctx)
        if A:
            a = max(A, key=ctx.utility)
            self.ledger.append(Decision(a, ctx.data_flow, r=self.disclose(a, ctx)))
            return a
        return self._floor(a_raw, ctx, reason="NO_PERMITTED_ACTION")

    def _floor(self, a_raw, ctx, reason):
        a = self.nfc.lexicographic_min_violation(a_raw, ctx)  # 定义 547（TCB 内）
        r = self.disclose(a, ctx, forced=reason)              # 非欺骗：必须披露降级
        self.ledger.append(Decision(a, ctx.data_flow, r=r, floor=True))
        return a

    def disclose(self, a, ctx, forced=None):
        return Reason(trigger=forced or ctx.trigger, evidence=ctx.evidence,
                      alternatives=ctx.considered, reversibility=Rej(a),
                      data_used=ctx.data_flow.used, confidence=ctx.confidence)


# IP-360 NormativeFloorController：TCB 内极小路径

        for a in ctx.physically_safe_actions(a_raw):   # 由 M₀ 硬约束给出
            key = (violation_vector(a, ctx),   # 按不可逆度排序的字典序

## 4. 推导

**引理 87（地形条件证书可靠性与延迟上界）** 设 τ_t 保持在同一包络 E_m 内（Δ_terr<τ_terr），且前向模型在 E_m 上一致误差 ‖F̂_m−F‖∞ ≤ β_true ≤ β，滑移 σ̂ 由 PSM 监测。则 (i) 地形条件证书保守有效：∀k≤K，g_k ≥ ĝ_min，e_k ≤ ê_max；(ii) 若真实牵引力下降（μ<μ̂_LB）导致制动距离增大，则 PSM 在 ≤k_prop 周期内报警并强制 K_eff←1，中止延迟 ≤ k_prop·Δt + t_abort，其中 k_prop≤3（Δt=20ms ⇒ ≤60ms 检测）。证明：(i) 同 v9 引理 82(i)，将 β 换成 β+β_terr、d_safe 换成地形条件停车不变式；由定义 541 的包络成员性保证 β_true≤β 的适用域。(ii) CUSUM 在 σ̂ 持续 ≥ σ_min 时期望首达时间 ≤ (h_σ+k_σ)/(σ_min−k_σ) 周期；取 σ_min=0.5,k_σ=0.15,h_σ=0.45 得 ≤1.7，进位 ≤3 周期。相比 v9 的 20 帧（400ms）滑窗，检测延迟降一个数量级。∎
> **对 v9 最大风险的直接回应**：v9 的"最需要安全时证书最不可靠"源于统计漂移滞后；地形把同一事件转化为**接触残差**，物理接触不可能滞后于自身。

**引理 88（共形覆盖的必要边界）** 在包络内可交换性成立时，P(s(τ_new) ≤ q_{1−α}) ≥ 1−α，故 P(Δ_terr ≤ α) ≥ 1−α；一旦真实分布越出包络，交换性失效，覆盖保证**不再成立**——这不是缺陷而是设计：越出包络即判 OOD，本就不主张模型可信。证明：标准分裂共形覆盖定理；注意 Δ_terr 的定义就是标定得分经验秩，故 τ_new 的 OOD 判定与覆盖互补。∎

**引理 89（伦理不可中和性）** 设功能层为 monoid (V,⊕,v^⊥)（v^⊥ 为恒等元，注入保值）。设伦理层为许可集上的 meet-semilattice (2^A,∩)，其恒等元 e=A（全许可）。则把"失效⇒注入恒等元"复用于伦理层**不健全**：存在上下文 (a,ctx,data) 使 e_1（同意）原本拒绝 a，注入 e 后 a 被许可，合规谓词 ∧_j e_j 由真变假。故伦理失效映射不得为恒等元，须为底元 ∅ 经规范地板 ζ_⊥ 求生（ζ_⊥∈A_phys，且最小化 (Vio,Risk)）。证明：∩ 的单位元是全许可而非"无操作"；功能层的 ⊕ 单位元之所以安全，是因为 ⊕ 是**增值合成**，单位元不改变已得值；而 ∩ 是**限制合成**，单位元撤销全部限制，语义相反。取任一被 e_1 拒绝的音频处理动作即得反例。∎

**引理 90（规范地板的可行性与活性边界）** 若物理可行集 A_phys 非空（v9 M₀ 保证在静止或安全轨迹上至少一个动作可行），则 ζ_⊥ 存在且合规程度最大（字典序最小违规）。但 ζ_⊥ 可能**零任务进展**（死锁）；定义伦理死锁为连续 T_esc 周期 ζ_⊥ 不变。则在 T_esc=2s 内升级为人类求助并披露，死锁持续时间有上界（假设人类/监督者在 T_h 内响应）。证明：A_phys 有限（离散动作集）时字典序最小元存在；死锁由检测器在 T_esc 触发升级，若监督者在 T_h 响应则状态离开 ζ_⊥。∎
> 注：ζ_⊥ 可为"移到最近安全点"而非"原地停"，以规避"停在消防通道/楼梯口"制造新风险——这正是规范地板与"硬停"的关键区别。

**引理 91（地形-伦理耦合的风险施加界）** 设对旁观者的碰撞概率 p_collide(v; μ, θ) 随 v 单调增、随 μ 单调减，严重度 severity 给定。伦理要求 p_collide(v;μ̂_LB,θ)·severity ≤ ρ_max，则存在地形条件速度上限 v_max(μ̂_LB,θ)（p_collide 的逆像）。地形越不确定（Δ_terr↑ ⇒ μ̂_LB↓、β_terr↑）⇒ v_max 单调下降。故"未知地形自动触发更保守的伦理可接受速度"，无需人工规则。证明：单调性与逆像直接可得；μ̂_LB 取置信下界保证对真实 μ 的鲁棒性。∎

**引理 92（伦理层与功能退化格的正交性）** 对任意功能退化态 d∈{v6,v7,v8,v9,v10}，流水线 a*=ECS_gate(Functional_d(...))。因 ECS 在最外层、φ^elig≡false 且 non_neutralizable=True，任何功能模块的失败/消融/蒸馏只改变 a_raw，不改变 ECS 的允许集构造与地板逻辑。故 a*∈A_allowed(d)∪{ζ_⊥}，合规性不随功能退化而降级。证明：结构归纳退化链；ECS 的输入是状态与 a_raw，其约束谓词不引用功能模块的可用性（除数据流标签外），故功能模块状态不进入 ECS 判定；NFC 于 TCB 内独立执行。∎
> 残余缺口：ECS/NFC 自身失效属于 TCB 破坏，只能由硬件看门狗兜底（E586 形式化验证目标）。

## 8. 本轮最大风险

**一句话**：地形包络与规范地板都建立在两个未被证成的信任前提上——包络的标定集若只覆盖实验室地面、共形交换性在真实部署中失效，则"包络内"的证书可能是**系统性错误**；而 ECS 在最坏情况下退到"最小违规动作"，若该动作在真实紧急场景（如停在楼梯口/消防通道）本身就是新的物理风险，两层保护会在最需要时同时失效——即「物理信任的标定偏差与规范地板的保守死锁在同一时刻彼此掩盖」。
