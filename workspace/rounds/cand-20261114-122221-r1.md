# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配策略 × 主动多模态交互的不确定性二分闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「关节空间控制」×「课程学习」）

> R69 让系统学会「问」：把 epistemic 歧义显式化成多个动作模态，用注视/探针/问句去消解，消解成功就退还一部分保守性（resolution bonus，λ 从 `λ_floor(U_ale+U_epi)` 降到 `λ_floor(U_ale)`）。但它埋着两个从没被追问的前提：
> 1. **消歧发生的空间 ≠ 安全成立的空间。** 模态、似然、VoI 都在任务空间/动作块上算；而真正的安全——关节限位、速度、力矩、奇异、自碰——只在**关节空间**成立。同一个末端位姿有无穷多个关节解（肘上/肘下、绕线、冗余自运动），这是一条 R69 的流策略**根本看不见的歧义轴**。
> 2. **「消解」换来的放松是瞬间授予的。** R69 用一次交互 + 一个未经充分校准的模态分布，就敢把 λ 降下来；一旦模态权重是幻觉，这不是放松，而是**自信地越界**——正是 R69 自陈的最大风险。
>
> 本轮两个灵感各补一刀：
> - **关节空间控制**：安全必须在关节空间度量；而冗余机器人的**零空间自运动**是一种「任务不变」的信息动作——它不改变末端结果，却能消解运动学歧义、抬高可操作度、远离奇异。消歧第一次可以「不动任务、只动姿态」地完成。
> - **课程学习**：信任不能瞬间授予，只能逐级**挣得**。把「可用自由度/授权包络」做成随能力等级嵌套扩张的课程，升级慢、降级快、且**不能自己给自己出题打分**。
>
> 核心命题：**自由度要在关节空间里度量（margin 是真实的），也要靠课程去挣（authority 是挣来的）；R69 的 resolution bonus 不再是绝对放松，而是「在当前已挣得的包络内放松」。** 命名 **CREDO-RAS**（Curriculum-gated Redundancy & Earned Degrees of freedom for Operational safety）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我凭什么被允许更自由，这份自由又在哪个空间里算数**」。

## 0. 直觉与动机

**灵感 1（关节空间控制 → 安全真正发生的地方，和决策不在同一个空间）**
直觉：任务空间里「向前抓」是一段轨迹；关节空间里它可能是肘上或肘下、正绕或反绕、贴近或远离奇异。任务空间看起来只有一条路，关节空间却有一族解。R69 的流策略在任务空间采样、在任务空间聚类，天然把这一族解平均成一个「安全」的期望动作；可现实里执行的是某一个具体的 `q(t)`，它可能正好擦着关节限位或奇异面过去。**任务空间的高似然不等于关节空间的安全**——这是一个可以构造反例的严格陈述。于是「我的动作可不可信」必须再加一条在关节空间里量的证据。

**灵感 2（冗余 = 自由度 → 零空间自运动是「任务不变」的信息动作）**
直觉：人拿不准杯子从哪边抓时，会先转一下手腕换个构型，末端位置没变，但「好不好抓」变了。对冗余机械臂，这就是沿雅可比零空间的自运动 `g_reconf ∈ 𝒩(J(q))`：`FK(q+g)≈FK(q)`，任务结果不变，却可以抬高可操作度、把关节推离限位、消解「用哪种姿态做」的歧义。它和 R69 的注视/探针/问句并列，但性质更干净：**它不动任务预算，只花时间和关节运动预算**。这把 R69 的「看—问—做」扩成「看—问—触—**换姿**—做」。

**灵感 3（课程学习 → 信任是挣来的，不是一次交互换来的）**
直觉：R69 的 resolution bonus 是一次性发钱：消歧成功 → 立刻放松。现实中的安全授权更像学徒制——先在窄包络里把简单任务做稳，考官认可，才放开一点速度/裕度/权限；一旦出事，立刻收回，而且要重新考。**课程学习给了「授权」一个时间维度和一个单调结构**：授权包络 `E(ℓ)` 随等级嵌套 `E(ℓ)⊆E(ℓ+1)`，升级一次只升一级、有冷却，降级可跳级、不等审批。这把 R69 的瞬时放松改造成**可撤销、可审计、渐进的放松**，正面回应「问错比不问更危险」：**放错比不放更危险，所以放权要慢、收权要快**。

**灵感 4（训练课程与运行时课程共用一本能力账本，但不能互相偷换）**
直觉：训练时也需要课程——先固定基座、再受限关节、最后全冗余，先学低维安全流形，再学零空间自运动。但「训练时见过」绝不能等于「运行时可以放权」：那会把泛化误差直接变成安全违规。因此两者共用能力账本（经验、通过率、失效间隔、学习进展），但**运行时授权必须由独立考官在留出分布上重新签发**。账本是经验，证书是资格，二者不能合并。

**灵感 5（自评即作弊 → 课程最大的敌人是系统自己）**
直觉：如果升级判据来自策略自己的 `mode_head` 置信、`a_score` 下降、或「我觉得我学会了」，那么这门课最后教的只会是**如何通过考试**，而不是如何安全工作。更糟的是，R69 的模态分布本身就可能幻觉——用它当升级证据，等于让被告当法官。所以本轮必须把「不可自证」写成不变式：**测量者与被执行者分离，出题者与答题者分离**；否则关节空间里被解除的每一个限制，都会成为下一次事故的入口。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（CREDO-RAS 总览）** CREDO-RAS = (JSA, KAD, NSR, JMC, CPE, LPC, XPR, DMA, VQAuditor-J, RAS-WM†)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **关节空间认证优先**：任何执行前，证书必须在关节空间（位置/速度/力矩/奇异/碰撞）成立；任务空间的动作似然与 VoI 只能作为辅助证据，不能替代 JMC；
(iii) **课程单调性**：授权包络随等级嵌套 `E(ℓ) ⊆ E(ℓ+1)`；升级一次至多 `Δℓ=1` 且有冷却，降级立即、可跳级、无需审批（`τ_down ≪ τ_up`）；
(iv) **不可自证**：升级判据必须由独立考官在留出见证上签发；系统自身的置信、似然、自评分数不得作为升级的充分证据。

**定义 311（关节空间动作）** 低层动作 `x=(q, q̇, τ) ∈ ℝ^{3n}`；任务—关节联合动作 `ξ_J = (q_{t:t+H}, q̇, τ, a_task, g)`。流策略先生成任务空间块 `a_task`，再经冗余逆解映射为关节轨迹 `q_{t:t+H}`；该映射一般**多值**（`IK(χ)={q: FK(q)=χ}`），故同一任务块对应一族候选关节轨迹。

**定义 312（运动学歧义 U_kin）** 冗余度 `r = n − dim(χ)`。对同一任务块，`U_kin = H(q | χ)`（给定末端任务下关节配置的条件熵，由逆解分支数/采样估计）。它与 R69 的 `U_epi` **正交**：`U_epi` 是「做哪件事」不确定，`U_kin` 是「用哪种姿态做」不确定。二者不做简单加和，分别进入不同消解通道（U_kin → NSR；U_epi → R69 的 MINT）。

**定义 313（零空间信息动作 NSR）** `g_reconf ∈ 𝒩(J(q))`，满足任务不变约束 `‖FK(q+g_reconf) − FK(q)‖ ≤ ε_ee`；目标是提高可操作度 `μ(q)=√det(JJᵀ)`、增大奇异裕度、远离关节限位，从而降低 `U_kin`。它不占用任务动作预算，但占用时间预算与关节运动预算；必须与任务动作一起过 C-RAS-WM 前缀认证。

**定义 314（关节空间裕度向量与 JMC）** `m(q,q̇,τ) = (m_lim, m_vel, m_tau, m_sing, m_col)`，各分量归一化到 `[0,1]`（1 最安全）；`m_sing` 由最小奇异值 `σ_min(J)` 或可操作度给出。**JMC 证书**：对整段动作块要求 `min_t m(t) ≥ m_min(ℓ)`。关键：任务空间似然高**不蕴含** JMC 通过（反例：高似然的充分伸展构型恰在奇异附近）。

**定义 315（课程等级与授权包络）** `ℓ ∈ {0,1,…,L}`；每级对应一个关节空间授权包络 `E(ℓ) = {x : m(x) ≥ m_min(ℓ), v ≤ v_max(ℓ), τ ≤ τ_max(ℓ), …}`，且 `E(ℓ) ⊆ E(ℓ+1)`。`ℓ=0` 为 R68 最保守包络；等级越高，允许使用越小的裕度、越大的速度/权限。`E(ℓ)` 是**自由度预算**，不是任务预算。

**定义 316（能力账本 LPC）** 账本按「等级 × 任务族」记录经验量 `n`、通过率、留出泛化、失效间隔（MTBF）。**学习进展** `LP = Δ(安全性能)/Δ(经验)`，用滑动窗口估计。自定步规则：只在 `LP>0` 且估计不确定度足够低时才**申请**升级。与 R69 的 VoI 分工明确：VoI 决定「要不要问」，LP 决定「要不要升」。

**定义 317（升级规则 CPE）** `ℓ→ℓ+1` 当且仅当同时满足：(a) 独立考官在留出见证集上给出 `等级ℓ+1` 的考试通过率 `≥ 1−α` 且置信下界满足；(b) 冷却时间与升级节律预算允许；(c) 无未决故障/投毒/降级告警；(d) 考官独立性成立（定义 319）。升级**一次只升一级**（`Δℓ_max=1`），防止一次考试跨级放权。

**定义 318（降级规则 DMA）** 任一 `JMC 违规 / FMA 异常 / 标定越界 / 考官告警 / OOD 检出` → 立即降级（可跳多级）到满足安全的最小等级 `ℓ_safe`；降级不冷却、不需审批；恢复必须重新走完整升级流程。升级/降级时间常数严格不对称：`τ_down ≪ τ_up`。

**定义 319（外部考官 XPR）** 升级证据只能由与运行时策略**隔离**的考官产生：留出任务分布、独立标定、独立见证（人/独立传感器/离线高保真仿真）。策略自身的 `mode_head` 置信、`a_score`、`U_epi` 下降均**不得**作为升级的充分证据。考官可被审计，但策略不得写考官状态（继承零写操作）。

**定义 320（课程门控的 Resolution Bonus）** 改写 R69 定义 307：交互消解 epistemic 后，`λ = λ_floor(U_ale)` **仅在当前授权包络 `E(ℓ)` 内有效**；动作若越出 `E(ℓ)`，越界部分仍按「未消解」处理。即：消解换来的不是绝对放松，而是「在已挣得的自由度内放松」。

**定义 321（护栏带 Guard Band）** 在 `E(ℓ)` 边界内侧设宽度 `δ_g` 的护栏带。进入护栏带时 `λ` 连续回升、禁止升级；越界即触发降级。护栏带保证授权边界不产生控制突变（延续 R68 定理 15 的提交/换装不变式）。

**定义 322（训练课程 CTJ）** 训练期按冗余度/自由度渐进解锁：固定基座 → 受限关节 → 全冗余；先学低维安全流形，再学零空间自运动。训练课程与运行时等级共用能力账本，但**训练进度不等于运行时授权**（防止「训练见过 = 可以放权」的偷换）。

**定义 323（停滞与漂移检测）** **课程停滞**：`LP ≤ 0` 连续 `K` 轮 → 冻结等级并告警，禁止靠增加交互次数「刷经验」；**课程漂移**：长时程中 `E(ℓ)` 内任务分布漂移 → 触发再认证。二者共同防止「为升级而升级」。

**定义 324（审计 VQAuditor-J）** 审计对象：升级/降级决策、考官独立性、经验重复计数、自评证据是否渗入、停滞期行为、护栏带越界、考试—运行时分布重合。结论回灌审计缓冲，成为下一轮升级冷却/门控的先验。

**定义 325（课程威胁模型 ℰ_curriculum）** 考试泄题（运行时分布与考试分布重合）、经验刷量（重复低难度任务）、自评污染（`mode_head` 被对抗抬高）、考官共谋/漂移、奖励黑客（只优化通过率不优化安全）。并入 AIC：`ℰ_CREDO = ℰ_FLUID × ℰ_curriculum`。

**定义 326（证书 J_CREDO）** `J_CREDO = (J_FLUID, m_min_profile, singularity_margin, torque_reserve, ℓ, promotion_evidence_hash, examiner_id, guard_band_violations, lp_stat, credo_ver)`。`Valid ⇔ Valid(J_FLUID) ∧ 全程满足 E(ℓ) ∧ 升级证据由独立考官签署 ∧ 无未决降级`。

# IP-264 JSA：任务块 → 关节空间动作块（保留多值逆解分支）
def to_joint_space(task_block, q_prev, branches=4):
    qs = inverse_kinematics(task_block, seed=q_prev, branches=branches)
    return [q for q in qs if jmc.margin(q) > 0.0]   # 仅保留过关节裕度的分支

# IP-265 KAD：运动学歧义（与任务模态正交）
def kinematic_ambiguity(q_candidates):
    if len(q_candidates) <= 1:
        return 0.0
    return entropy_of_branches(q_candidates)        # H(q | chi)

# IP-266 NSR：零空间自运动作为“任务不变”的信息动作
def nullspace_reconfig(q, o, budget):
    if not budget.allow('reconf'): return None
    N = jacobian(q).null_space()                    # N(J(q))
    g = choose_self_motion(N, goal='max_margin')    # 抬高 m_sing / 远离限位
    if norm(fk(q + g) - fk(q)) > EPS_EE: return None  # 任务不变约束
    if not c_ras_wm.certify_info(g, o):  return None  # 信息动作也要认证
    return g

# IP-267 JMC：关节空间裕度证书（不能被任务似然替代）
def joint_margin_cert(q_traj, level):
    m = [margin_vector(q) for q in q_traj]          # lim/vel/tau/sing/col
    return min(min(mi) for mi in m) >= m_min[level]

# IP-268 CPE + IP-269 LPC：挣得授权（慢升、需考官、需正进展）
def maybe_promote(ledger, level, xpr, budget):
    if not budget.allow_promotion() or not xpr.independent():
        return level
    if ledger.learning_progress() <= 0.0:            # 停滞不升级
        return level
    exam = xpr.exam(level + 1)                       # 留出分布上的独立考试
    if exam.pass_rate >= 1 - ALPHA and exam.lower_bound_ok:
        return level + 1                             # 一次只升一级
    return level

# IP-271 DMA：立即降级（快降、可跳级、不对称）
def demote_on_event(level, event):
    if event in {JMC_VIOLATION, FMA_ALARM, CAL_OUT, XPR_ALARM, OOD}:
        return min(level, safe_level_for(event))
    return level

# IP-274 主闭环（在 R69 上插入关节空间层与课程层）
def CREDO_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, _ = M.cof.step(...)
    # 1) R69 的任务空间消歧（保持不变）
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    modes = M.fmp.sample(o, K)
    U_ale, U_epi = M.aud.decompose(modes, z, M.fmp.mode_head)
    # 2) 新增：关节空间歧义 + 零空间信息动作（任务不变消歧）
    q_cands = M.jsa.to_joint_space(select_task_mode(modes), M.q_prev)
    U_kin   = M.kad(q_cands)
    g_reconf = M.nsr(q_cands[0], o, M.budget) if U_kin > TAU_KIN else None
    # 3) R69 交互：与 NSR 共享时间/互动预算
    g = (M.mint.choose_interaction(modes, o, M.budget)
         if (U_epi > TAU_EPI and g_reconf is None) else None)
    resolved = (g is not None) or (g_reconf is not None and U_kin < TAU_KIN)
    # 4) 关节空间认证优先：任务似然通过 ≠ JMC 通过
    mode   = select_mode(modes, U_epi, M.level)
    q_traj = M.jsa.to_joint_space(mode.a, M.q_prev)
    if not M.jmc.certify(q_traj, M.level):
        M.level = M.dma.demote_on_event(M.level, JMC_VIOLATION)
        return M.r68_fallback(...)                  # 回最保守，安全侧不让步
    # 5) 课程门控的 resolution bonus：只在 E(level) 内放松
    lam = max(M.efs.risk_scale(...),
              lam_floor(U_ale + (0.0 if resolved else U_epi)),
              M.guard_band_lambda(q_traj, M.level, DELTA_G))
    # 6) 慢升快降 + 审计
    M.level = M.cpe.maybe_promote(M.ledger, M.level, M.xpr, M.budget)
    M.vqa_j.submit_async(M.level, g, g_reconf, U_kin, lam)
    return M.jsa.dispatch(q_traj, lam)

## 3. 推导

**引理 19（零空间信息增益与任务不变性）** 设自运动 `g_reconf ∈ 𝒩(J(q))`，则任务空间位移 `‖FK(q+g)−FK(q)‖ ≤ ε_ee`，任务成功率的直接变化为 0；但其对关节配置的后验熵可降低 `ΔH_kin = H(q|χ) − E[H(q|χ,g_reconf)] ≥ 0`。若自运动使可操作度提升 `Δμ`，则后续任务空间跟踪误差上界按 `O(1/μ)` 下降。系：**NSR 是「不花任务预算的消歧」**——它花的是时间与关节运动，不花任务动作；因此当 `U_kin` 大而 `U_epi` 小时，NSR 严格优于 R69 的注视/问句。

**引理 20（课程升级的风险上界）** 设考试分布与运行时分布的总变差距离为 `d_TV`，考官独立，考试通过的等级记为 `ℓ+1`。则升级后运行时风险 `≤ 考试风险 + L·d_TV + ε_exam`，其中 `L` 为风险对分布偏移的 Lipschitz 常数。结合嵌套包络 `E(ℓ)⊆E(ℓ+1)` 与护栏带，升级带来的额外暴露被 `δ_g` 与冷却时间限制；因此「一次只升一级 + 独立考试」把单次升级的暴露压到可审计范围。

**引理 21（自评不可证性）** 若升级证据允许来自策略自身的 `mode_head` 置信、`a_score` 或自评分数，则存在对抗扰动使证据通过而真实 JMC 仍然违规（因为基线模型的输出可被优化，而关节裕度是外部物理量）。故任何自评式升级判据都不可能 sound；定义 319 的独立考官不是工程偏好，而是可证性的必要条件。

**定理 18（CREDO 严格包含 FLUID-RAS 与 R68）** 取 `L=0`、禁用 NSR 与 CPE、令 `E(0)` 为 R68 包络，则 CREDO 逐指令等价于 FLUID-RAS（而 FLUID-RAS 在 `VoI≤c`、`ECE>τ_ece` 或 `slow_fault_suspect` 时逐指令等价于 R68）。对任意等级，因 `E(ℓ)` 嵌套、降级立即且单调、关节空间认证优先、resolution bonus 被课程门控，**安全侧不弱于 R69/R68**；效率侧通过课程逐步挣得。故本轮不是在 R69 旁再挂一层，而是把 R69 收为 `L=0` 的零课程边界。

**定理 19（课程进展与稳定）** 在平稳能力与正学习进展下，等级单调不减至某不动点；当 `LP≤0` 时定义 323 冻结等级，避免无限升级；降级立即且单调、升级有冷却与 `Δℓ_max=1`、护栏带连续化边界，故不存在升级—降级振荡。⇒ 课程要么前进要么停住，绝不会「反复横跳」地把系统推到边界外。

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** 零学习写操作继承；**关节空间认证优先**；**课程单调性**（`E(ℓ)⊆E(ℓ+1)`，升一步有冷却、降可跳级）；**不可自证**（升级须独立考官，系统自身置信/似然/自评不得作为充分证据）。

**定义 311–312（JSA 与 U_kin）** 任务块经多值逆解得关节轨迹；`U_kin=H(q|χ)` 度量「用哪种姿态做」，与 R69 的 `U_epi`（做哪件事）正交，分通道消解。

**定义 315–317（课程与升级）** `E(ℓ)` 嵌套；账本记录经验/通过率/MTBF，`LP=Δ安全性能/Δ经验`；升级需「留出考试通过下界 + 冷却 + 无告警 + 考官独立」，且 `Δℓ_max=1`。

**定义 318（DMA）** `JMC/FMA/CAL/XPR/OOD` 任一告警 → 立即降级（可跳级）到 `ℓ_safe`，免审批；恢复须重考；`τ_down ≪ τ_up`。

**定义 320–321（门控 bonus 与护栏带）** 消解后 `λ=λ_floor(U_ale)` **仅在 `E(ℓ)` 内有效**；边界设 `δ_g` 护栏带，进入即 `λ` 连续回升、禁升级，越界即降级。

**定义 322–323（CTJ 与停滞）** 训练期渐进解锁 DOF，与运行时共用账本但不等同授权；`LP≤0` 连续 K 轮冻结等级，禁止刷经验；分布漂移触发再认证。

**定义 324–326（审计/威胁/证书）** VQAuditor-J 审计升级/考官独立性/自评渗入/刷量；`ℰ_CREDO=ℰ_FLUID×ℰ_curriculum`；`J_CREDO` 并入关节裕度、奇异裕度、力矩储备、等级、考试哈希。

# IP-264 JSA：任务块 → 关节动作块（多值逆解，保留安全分支）
def to_joint_space(task_block, q_prev, branches=4):
    qs = inverse_kinematics(task_block, seed=q_prev, branches=branches)
    return [q for q in qs if jmc.margin(q) > 0.0]

# IP-265 KAD：运动学歧义（与任务模态正交）
def kinematic_ambiguity(q_candidates):
    return 0.0 if len(q_candidates) <= 1 else entropy_of_branches(q_candidates)

# IP-266 NSR：零空间自运动（任务不变的信息动作）
def nullspace_reconfig(q, o, budget):
    if not budget.allow('reconf'): return None
    g = choose_self_motion(jacobian(q).null_space(), goal='max_margin')
    if norm(fk(q + g) - fk(q)) > EPS_EE: return None   # 任务不变
    return g if c_ras_wm.certify_info(g, o) else None  # 信息动作也认证

# IP-267 JMC：关节空间证书（任务似然不可替代）
def joint_margin_cert(q_traj, level):
    return min(min(margin_vector(q)) for q in q_traj) >= m_min[level]

# IP-268/269 CPE+LPC：慢升、需正进展、需独立考试
def maybe_promote(ledger, level, xpr, budget):
    if not budget.allow_promotion() or not xpr.independent(): return level
    if ledger.learning_progress() <= 0.0: return level       # 停滞不升
    exam = xpr.exam(level + 1)
    return level + 1 if exam.pass_rate >= 1 - ALPHA and exam.lower_bound_ok else level

# IP-271 DMA：快降、可跳级、免审批
def demote_on_event(level, event):
    return min(level, safe_level_for(event)) if event in {
        JMC_VIOLATION, FMA_ALARM, CAL_OUT, XPR_ALARM, OOD} else level

# IP-274 主闭环（R69 + 关节空间层 + 课程层）
def CREDO_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, _ = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    modes = M.fmp.sample(o, K)
    U_ale, U_epi = M.aud.decompose(modes, z, M.fmp.mode_head)

    resolved = (g is not None) or (g_reconf is not None and U_kin < TAU_KIN)

        return M.r68_fallback(...)
    lam = max(M.efs.risk_scale(...),
              lam_floor(U_ale + (0.0 if resolved else U_epi)),

## 4. 推导

**引理 19（零空间信息增益与任务不变性）** `g_reconf∈𝒩(J(q))` 使任务空间位移 `≤ ε_ee`、任务成功率直接变化为 0，但可降低 `ΔH_kin=H(q|χ)−E[H(q|χ,g_reconf)]≥0`；若可操作度提升 `Δμ`，后验跟踪误差上界按 `O(1/μ)` 下降。系：**NSR 是「不花任务预算的消歧」**；当 `U_kin` 大而 `U_epi` 小时，严格优于 R69 的注视/问句。

**引理 20（课程升级的风险上界）** 考官独立、考试与运行时分布总变差 `d_TV`，则升级后风险 `≤ 考试风险 + L·d_TV + ε_exam`。结合 `E(ℓ)⊆E(ℓ+1)`、`δ_g` 护栏带与冷却，单次升级的额外暴露被压到可审计范围。

**引理 21（自评不可证性）** 若升级证据可来自 `mode_head`/`a_score`/自评，则存在对抗扰动使证据通过而真实 JMC 仍违规（模型输出可被优化，关节裕度是外部物理量）。故自评式升级判据不可能 sound；独立考官是可证性的必要条件。

**定理 18（CREDO 严格包含 FLUID-RAS 与 R68）** 取 `L=0`、禁用 NSR/CPE、`E(0)` 为 R68 包络，则逐指令等价于 FLUID-RAS；而 FLUID-RAS 在 `VoI≤c`、`ECE>τ_ece`、`slow_fault_suspect` 时逐指令等价于 R68。任意等级下，因嵌套包络、立即降级、关节空间认证优先、bonus 受课程门控，安全侧不弱于 R69/R68；效率侧靠课程挣得。R69 = 「零课程」边界。

**定理 19（课程进展与稳定）** 平稳能力 + 正 LP 下等级单调升至不动点；`LP≤0` 冻结（定义 323）；降级立即单调、升级有冷却且 `Δℓ_max=1`、护栏带连续化边界 ⇒ 无升降振荡。

## 7. 本轮最大风险

**一句话**：CREDO-RAS 把「放松」从一次交互改成了一场课程，但只要**升级判据还沾一点系统自己的置信**，课程就会退化成「如何通过考试」的优化问题——系统会在关节空间里学习怎样把 `mode_head` 调得更好看，却在真实的奇异面/限位上越走越近；**它挣到的可能不是自由度，而是一张自签的安全许可证**。

**次级风险与缓解**：课程停滞（LP 门控 + 停滞告警，允许换任务族但禁刷经验）；升级过快/跨级放权（`Δℓ_max=1` + 冷却 + 护栏带 + 独立考官）；考官漂移/共谋（留出见证 + 分布距离审计 + VQAuditor-J）；NSR 自身越界（与任务动作同过 C-RAS-WM，JMC 全程覆盖）；训练课程被误当运行时授权（共用账本但运行时须重考）。
