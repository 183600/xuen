# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「场景泛化」×「通用机器人平台」）

> R69 把不确定性一分为二，并让系统学会「问」。它自陈的最大风险是：**若流模型的模态分布不可信，问错比不问更危险**。但 R70 要指出一个更上游、更致命的问题：R66–R69 的**每一条阈值都属于某一次部署**——标定偏置、残差基线、噪声方差、安全包络、模态先验、交互成本（τ_ece、TAU_FMA、TAU_EPI、λ_floor、ε_g、c_max）全部是在**一个场景、一台机器**上「挣来的」。把整套闭环搬到新场景/新本体，却沿用旧数字，等于**相信了「标定本身不需要被标定」**。这恰恰是「场景泛化 × 通用机器人平台」逼我们回答的问题：**一个能安全地问的系统，如何在一个它从未见过的世界里，仍然知道自己什么时候不该相信自己？**
>
> 本轮两个灵感正好各补一刀：
> - **场景泛化**告诉我们：泛化不是「一个模型通吃」的拟合问题，而是「**哪些东西可携带、哪些必须就地重新挣得**」的**可移植性分解**问题；
> - **通用机器人平台**告诉我们：平台是异构的（机械臂/夹爪/相机/时延/负载都变），所以安全必须由**跨平台可认证的不变量内核**给出，而性能参数必须由**每台机器、每个场景各自的护照**给出。
>
> 核心命题：**把每个能力的参数拆成「不变量内核 φ_inv（一类平台/场景通用，可一次性认证）」与「局部参数 ψ_loc（必须就地挣得，带置信集）」，用『能力护照』记录二者；只有当护照在目标部署上盖章，才放开 R69 的完整闭环；否则先在『不变量兜底技能』保护下执行『探针协议』把这台机器/这个场景的局部参数挣出来，挣不出来就永久退化到只由不变量保证的安全兜底。** 命名 **PORTAL-RAS**（Portability-Oriented Robust Transfer with Active Learning：可移植性导向的主动再标定风险自适应闭环）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**换了一个世界、换了一副身体，我还知道什么是真的吗**」——泛化不是把旧答案带过去，而是知道哪些前提可以带、哪些必须在这里重考。

## 0. 直觉与动机

**灵感 1（场景泛化 ≠ 通吃模型，而是可移植性分解）**
直觉：我们习惯把泛化当成「训练分布更宽一点」「加 domain randomization」。但 R66–R69 的闭环里真正脆弱的东西不是网络权重，而是**数字**：λ_floor 的安全系数、残差的阈值、标定窗口长度、模态权重的校准。它们在源场景里被证据「挣得」，一旦换场景就退化成**没有根据的先验**。因此泛化的第一性原理不是「让模型对所有场景都准」，而是先回答：**这套系统里，哪部分是物理/语义/逻辑上的不变量（可以带着走），哪部分是场景证据的产物（必须留下重挣）？** 把这个问题显式化，泛化才从「祈祷分布接近」变成「可核查的移植契约」。
> 一句话：**可携带的是「结构」，不可携带的是「读数」。**

**灵感 2（通用机器人平台 = 异构接口 + 共享不变量）**
直觉：同一个软件栈要跑在机械臂、移动底盘、双臂、不同夹爪、不同相机与不同控制频率上。指望「一套经过认证的安全包络」跨本体成立是幻觉；但指望「每次从零认证」又会让平台失去通用性。正确的分层是：**安全由物理不变量保证（几何、准静态稳定性、接触力上界相对于质量、可达性、时延上界），性能由局部标定保证（这个夹爪的摩擦、这台相机的噪声、这个场景的地面反照率）。** 前者可以**一次认证、全类复用**；后者必须**一机一场景一护照**。这也给「通用平台」一个可操作定义：**通用性 = 不变量内核的覆盖半径**，而不是模型参数有多少。

**灵感 3（主动探询的另一层用法：R69 的任务消歧 → R70 的部署自标定）**
直觉：R69 的「看/问/触」是为了**在一次任务里**消解模态歧义。R70 发现同一套信息动作可以**换一个时间尺度**使用：新场景/新平台开机后的前若干分钟，用探针动作主动激励系统、感知边界、测噪声与时延，把 ψ_loc 的置信集从「先验很宽」压到「可以盖章」。这不是新机器，而是**同一台信息获取引擎换了被估计的对象**：R69 估计「任务模态 M」，R70 估计「部署参数 ψ_loc」。妙处在于：**探针的安全性不依赖 ψ_loc**——它由不变量内核约束，所以可以「在还不会走路时安全地学走路」。

**灵感 4（移植的双向失败：过度信任与过度保守）**
直觉：迁移有两种错法。**过度信任**：护照早已过期，却拿旧标定在新场景盖章 → 自信地做错，比不会做更危险。**过度保守**：因为无法证明接近源场景，就永远只跑兜底 → 通用平台退化成「昂贵的急停按钮」，泛化能力等于零。所以需要一道**本身被校准过的移植门**：它既要控制「误放行」（把 OOD 当 ID 部署）的概率，也要控制「误拒绝」（把可用的场景判死）的概率，并给出一个**可声明的泛化半径**——在半径内提供有限样本保证，在半径外诚实地退回不变量兜底，而不是假装覆盖。

**灵感 5（车队是资产，也是新的投毒面）**
直觉：通用平台的规模效应来自**车队**：一千台机器在几千个场景里挣到的局部参数可以互相借鉴，冷启动因此变快。但共享证据把 R69 已经担心的「单源投毒」放大成**跨机污染**：一台被黑、一个传感器批次有系统性偏差、一个场景被恶意构造，都可能通过共享先验把错误扩散到整队。于是必须引入**证据来源图与独立性**：借鉴必须可追溯、跨来源要近似独立、护照要有签名与撤销机制。R69 的「k 个正交证据源一致」在 R70 升级为「k 个正交**部署来源**一致」。

**灵感 6（诚实的不可能性）**
直觉：**不存在无假设的任意场景泛化保证**。任何分布无关的承诺在任意协变量偏移下都会被反例击穿。R70 不承诺「哪里都行」，而是承诺三件可核查的事：(i) 不变量兜底的安全性**不依赖**任何学习参数；(ii) 性能保证只在**声明的场景族与泛化半径内**成立，半径外由移植门显式弃权；(iii) 探针把「不可证」转成「可证」时，其自身受不变量保护。把不可能性讲清楚，比伪造一个全能保证更接近严谨。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（部署与源/目标分布）** 部署 d = (s, e, τ)：场景 s、本体/平台 e、任务 τ。源部署族 𝒟_src（护照与阈值被挣得之处），目标部署 d_tgt ~ 𝒟_tgt。局部参数 ψ_loc ∈ Ψ 由 (s,e,τ) 决定；不变量参数 φ_inv 在声明的平台/场景类 𝒞 内保持一致。

**定义 311（可移植分解）** 每个能力的完整参数 θ = (φ_inv, ψ_loc)。φ_inv 只包含**物理/几何/逻辑不变量**：准静态稳定性、接触力相对质量上界、运动学可达、时延上界、时间-碰撞几何、控制-安全分层顺序。ψ_loc 包含**证据产物**：标定偏置、噪声统计、残差基线、安全包络裕度、模态先验、交互成本与全部阈值 (τ_ece, TAU_FMA, TAU_EPI, λ_floor, ε_g, c_max)。要求：θ 的每个分量**有且仅有**一个归属，禁止「既是先验又是标定」的模糊量。

**定义 312（能力护照 CAP）** CAP_c = (cap_id, φ_inv_ver, {ψ̂_loc, C_ψ}, prov, D̂(𝒟_src,·), t_stamp, t_expire, sig)。其中 C_ψ 是 ψ_loc 的置信集（如椭球/分位数区间），prov 是证据来源集合，D̂ 是源-目标散度估计，sig 由平台根密钥签名。**盖章（stamp）** ⇔ C_ψ 收缩到可接受半径 ∧ 移植门（定义 318）判为 deploy ∧ 未过期未撤销。

**定义 313（移植风险与泛化半径）** 移植风险 TR(d) = sup_{ψ∈C_ψ}[R_τ(π;ψ) − R_src] + κ·D_f(𝒟_src, 𝒟_tgt) + ν_mismatch，其中 R 为任务风险、D_f 为 f-散度、ν_mismatch 为接口失配项。**泛化半径** ρ 定义为：使 TR(d) ≤ ε_TR 且移植门保证仍成立的最大散度。ρ 是护照的显式字段，不是隐含假设；d 超出 ρ 即视为未覆盖，必须探针或兜底。

**定义 314（安全不变量内核 SIK）** 对声明平台类 𝒞，SIK = {g_i(x,u,θ_phys) ≤ 0} 为一组只依赖物理量（质量、惯量、几何、执行器额定、通信时延上界）的约束。给定动力学不确定集 𝒰（由 SIK 而非 ψ̂_loc 界定），若控制器满足控制屏障条件 Ḣ + α(H) ≥ 0（H 为约束的屏障函数），则在任意 ψ_loc ∈ Ψ 下轨迹不离开安全集。**SIK 的正确性只能被证伪、不能被数据「校准」**——它是本方案唯一无条件的承诺。

**定义 315（不变量兜底技能 IFS）** IFS：只使用 SIK 可验证的量（如「保持当前接触力下停住 / 撤回到可达安全位 / 以时延上界内的减速曲线停下」），不含任何 ψ̂_loc。IFS 在任意部署上**恒可执行**。R70 的最终安全承诺是：任何时刻要么在印章能力内运行，要么在 IFS 内运行，二者切换连续。

**定义 316（探针协议 PROBE）** 复用 R69 的信息动作空间 𝒜_info，但目标改为估计 ψ_loc：探针动作 g_probe = (激励动作、感知配置、自检序列)，例如小幅多轴激励辨识惯量/摩擦、改变视角估计反照率与曝光、空载动作测时延与回差。PROBE 是一个**分批贝叶斯实验设计**：在 SIK-CBF 约束下选使 ψ_loc 后验熵下降最快的 g。

**定义 317（探针价值 VoP 与预算）** VoP(g) = H(ψ_loc | 已有证据) − E_{y~p(·|g)}[H(ψ_loc | y)] − c(g)，s.t. risk(g) ≤ ε_probe **由 SIK-CBF 保证**（注意：该约束不依赖 ψ_loc 的点估计，只用不确定集）。探针总预算 = 时间窗 T_probe + 物理动作次数 N_probe + 对生产节拍的扰动上界；超预算则放弃盖章。

**定义 318（移植门 TG）** 三态决策：**stamp**（护照完整且在 ρ 内 → 放开 R69/FLUID 全闭环）、**probe**（护照不完整但 TR 可期下降 → 在 IFS 保护下执行 PROBE 后再判）、**fallback**（超出 ρ / 探针超预算 / 探针结果与源先验强冲突 → 只允许 IFS）。TG 的判据由定义 319 的有限样本证书给出，禁止用点估计的 TR 直接盖章。

**定义 319（有限样本移植认证）** 在**声明的场景族** ℱ（护照上写明）内，用共形预测对非一致性分数 s(d)（融合 FMA 的 Δa、残差通道 r_res、接口一致性）给出 p 值；当 p ≥ α 且多重比较校正后仍成立，判 deploy，控制**误放行率 ≤ α**。协变量偏移下采用加权共形或鲁棒半径 ρ 版本；**在 ℱ 与 ρ 之外，该保证失效并强制 fallback**——这不是补丁，而是定义的一部分。

**定义 320（异构接口适配器 EA）** 每台机器一个适配器 EA_e：(𝒜_e, 𝒪_e, Δt_e) → (𝒜_+, 𝒪_+)，把平台动作/观测映射到共享 φ 空间。EA 通过「仿真-实机一致性检查 + 饱和/时延/单位」静态验证，并作为护照字段。EA 失效等价于部署未覆盖。

**定义 321（车队证据图 FEG）** 有向图，节点为 (部署, 证据)，边表示共享来源（同实验室、同传感器批次、同场景模板、同训练数据）。对每条借鉴关系记录 provenance 与近似独立性；**证据独立性数** k_FEG 为可选出 k 条近似正交来源的最大 k。

**定义 322（跨机污染上界）** 设被污染/被黑的部署比例为 δ_p，跨来源欺骗相关为 ρ<1。单源采纳的错误率为 δ_p；要求 k_FEG ≥ k 且多数一致时，错误采纳率 ≤ δ_p·ρ^{k−1} + ε_σ。护照伪造/重放/过期复用属于 ℰ_portal 干扰集，必须由签名、撤销列表与时间戳拦截。

**定义 323（移植感知不确定度与三级退避）** 定义 U_transfer = 由 C_ψ 与 D̂ 诱导的部署级 epistemic 不确定度。R70 的保守度为 λ = λ_floor(U_ale + 未消解 U_epi + U_transfer)。当护照盖章且 U_transfer → 0（探针把 C_ψ 压到可忽略）时，λ 逐项退化为 R69 公式；若探针失败/超预算/被污染，U_transfer 保持其上限并进入 fallback。因此 R69 是 R70 在「单部署、护照已知」边界上的退化。

**定义 324（护照生命周期）** 护照有签发、过期、撤销、再认证四种状态；传感器批次变更、执行器更换、场景类别变更、或 FMA 的漂移信号持续越界，均触发**自动降级为 probe/fallback**。护照状态是 J_PORTAL 的一等公民：**没有有效护照的能力不得被部署**。

**定义 325（场景分类学与半径估计）** 维护一个场景/平台类层级 𝒯（几何、材质、光照、动态体、时延档），每类的 ρ 由历史护照的 TR 分布经验估计并给出置信带。TG 用最近类中心与最坏类距离判定是否在覆盖内；分类学本身可增长，但增长必须走同一盖章流程。

**定义 326（证书 J_PORTAL）** J_PORTAL = (J_FLUID, passport_hash, TR_hat, rho, tg_decision, probe_log_hash, ece_transfer, provenance_hash, portal_ver)。Valid ⇔ Valid(J_FLUID) ∧ 护照有效且已盖章 ∧ TG 决策与证据一致 ∧（若 probe）探针在 SIK 内且预算未越界。

## 2. 关键算法骨架

```python
# IP-264 CAP：可移植分解与护照构建（把 R69 的每个阈值显式归入 φ_inv 或 ψ_loc）
class CapabilityPassport:
    def __init__(self, cap_id, inv_kernel_ver, psi_hat, psi_conf, prov, rho, src):
        self.id, self.inv = cap_id, inv_kernel_ver
        self.psi, self.conf = psi_hat, psi_conf      # ψ̂_loc 与置信集 C_ψ
        self.prov, self.rho, self.src = prov, rho, src
        self.state, self.stamp_t = "UNSTAMPED", None

    def stamp(self, tr_hat, gate_ok, now):
        if gate_ok and tr_hat <= EPS_TR and self.conf.radius <= R_PSI:
            self.state, self.stamp_t = "STAMPED", now

    def revoke(self, reason):                        # 换传感器/换本体/FMA 漂移触发
        self.state = "REVOKED"; self.reason = reason

# IP-265 SIK/IFS：安全只由物理不变量给出，完全不读 ψ̂_loc
def invariant_shield(state, u_task, s_unc):
    u_safe = project_to_safe_set(state, s_unc)       # 仅用质量/几何/额定/时延
    if barrier_condition(state, u_task, s_unc) >= 0:
        return u_task
    return invariant_fallback(state)                 # IFS：停住 / 撤回 / 限速减速

# IP-266 PROBE：把 R69 的信息动作改为「估计 ψ_loc」的贝叶斯实验设计
def plan_probe(psi_post, budget, s_unc):
    best = None
    for g in probe_candidates():                     # 激励 / 视角 / 自检序列
        if not budget.allow(g):                continue
        if not invariant_cbf_ok(g, s_unc):     continue   # 探针安全不看 ψ̂
        vop = entropy(psi_post) - expected_entropy(psi_post, g) - cost(g)
        if best is None or vop > best.vop: best = (g, vop, g.safety_margin)
    return best if best and best.vop > 0 else None

def run_probe(cap, target, budget):                  # 在 IFS 保护下执行
    log = []
    while not cap.stamped() and budget.remain() > 0:
        g = plan_probe(cap.psi_post, budget, target.s_unc)
        if g is None: break
        y = target.execute_under_shield(g, invariant_shield)  # SIK 保证安全
        cap.psi_post = bayes_update(cap.psi_post, y); log.append((g, y))
        cap.conf = credible_set(cap.psi_post)
        if not target.interface_consistent(): cap.revoke("adapter_mismatch")
    return log

# IP-267 TG：被校准过的移植门（误放行率受控），三态输出
def transfer_gate(cap, target, alpha):
    if cap.state != "STAMPED" and cap.rho <= 0: return "fallback"
    score = nonconformity(target, cap)               # Δa, r_res, 接口一致性
    p = conformal_pvalue(score, cap.calib_scores, family=cap.src.family)
    if cap.conf.radius <= R_PSI and p >= alpha and cap.divergence <= cap.rho:
        return "stamp"
    if cap.probe_budget_viable(target) and tr_is_improvable(cap, target):
        return "probe"
    return "fallback"                                # 半径外/无预算/强冲突

# IP-268 三级退避：U_transfer 进入 λ floor，盖章后退化为 R69
def portal_risk_scale(M, U_ale, U_epi_res, cap):
    U_transfer = transfer_uncertainty(cap.conf, cap.divergence)  # 0 if stamped
    return max(M.efs.risk_scale(...),
               lam_floor(U_ale + U_epi_res + U_transfer))

# IP-274 PORTAL 主闭环（外层是部署级，内层调用 R69 的 FLUID_RAS_round）
def PORTAL_round(M, obs, target):
    cap = M.passports.get(target.cap_id)
    mode = M.tg.transfer_gate(cap, target, alpha=M.alpha)   # stamp/probe/fallback
    if mode == "fallback":
        return M.ifs.act(obs, target.s_unc)                  # 只由不变量保证
    if mode == "probe":
        M.probe.run(cap, target, M.budget)                   # 在 IFS 保护下挣参数
        mode = M.tg.transfer_gate(cap, target, alpha=M.alpha)
        if mode != "stamp": return M.ifs.act(obs, target.s_unc)
    # 已盖章：放开 R69 全闭环，但保留 U_transfer 作为附加保守项
    k, lam, a, (U_ale, U_epi) = M.fluid.FLUID_RAS_round(M, obs)
    lam = M.portal.portal_risk_scale(M, U_ale, U_epi, cap)
    M.vqa_t.submit_async(cap, mode, M.probe.log, lam)
    return k, lam, a
```

## 3. 推导

**引理 19（可移植性分解界）** 设任务风险 R_τ(π;ψ) 对 ψ 局部 L_ψ-Lipschitz，接口失配项为 ν。若目标部署的局部参数满足 ‖ψ − ψ̂‖ ≤ ε_ψ（由 C_ψ 半径给出），且源-目标 f-散度为 D_f，则
R_tgt ≤ R_src + L_ψ·ε_ψ + κ·D_f + ν。
当 ε_ψ = D_f = ν = 0（同部署、已盖章）时严格退化为 R69 的风险；这给出「盖多少章、能省多少保守度」的定量关系。系：**探针的价值 = 把 ε_ψ 压小从而换来 λ 的松弛**，且此收益可加、可审计。

**引理 20（探针的绝对安全性）** 若探针动作 g 满足 SIK 定义 314 的屏障条件，且 SIK 的物理量界在平台类 𝒞 内成立，则从任意初始安全状态执行 PROBE，其轨迹在任意 ψ_loc ∈ Ψ 下都不离开安全集，物理风险 ≤ ε_probe，**该结论不使用 ψ̂_loc**。证明要点：屏障条件对动力学不确定集 𝒰 取最坏情形即可，探针只改变激励、不改变约束集。系：**可以在不信任自己标定的时候安全地做标定**。

**引理 21（探针收敛率）** 在正则条件下，对局部参数 ψ 的第 m 次探针观测的 Fisher 信息 J_m 满足 Cramér–Rao：E‖ψ̂_m − ψ‖² ≥ tr(J_m^{-1})，而贝叶斯实验设计使每步最大化预期信息增益，故 ε_ψ(m) 以 O(m^{-1/2}) 收缩（可辨识子空间内）；当 J_m 在不可辨识方向奇异时，C_ψ 在该方向保持先验宽度，TG 必须拒绝盖章。系：**探针只能消掉「可被激励看到」的参数**，看不见的量永远留在 U_transfer 里。

**引理 22（移植门的有限样本校准）** 设目标来自声明的场景族 ℱ 且与校准集可交换，则共形 p 值满足 P(p < α) ≤ α，故误放行率 ≤ α；在加权协变量偏移下，若密度比被正确估计，则加权共形保持同一界。**在 ℱ 之外或密度比不可估时，该界不成立**，因此 TG 必须以 ρ 硬性兜底。证明为标准共形 + 分离假设的否定。系：**门的可信度也是相对的、被声明的**，这正是对「标定的标定」的正面回答。

**引理 23（跨机污染上界）** 在定义 322 的独立性假设下，k 条近似正交来源多数一致时错误采纳率 ≤ δ_p·ρ^{k−1} + ε_σ；若来源因共享传感器批次而完全相关（ρ=1），则上界退化为 δ_p，无任何增益。系：**车队规模不自动带来鲁棒**，独立性数 k_FEG 才是可利用的证据量。

**定理 18（PORTAL 严格包含 FLUID-RAS/R68）** 在 A99（SIK 覆盖平台类 𝒞）、A100（目标在声明族内或被显式弃权）下：(i) 任意部署的物理风险 ≤ max(R69 风险, ε_fallback)，因安全由 SIK/IFS 兜底且切换连续；(ii) 当护照已盖章且 U_transfer=0 时，PORTAL 与 FLUID-RAS **逐指令相同**；(iii) 当目标在 ρ 内但未盖章时，PORTAL 通过探针获得 resolution bonus，期望风险 ≤ 相同前提下不探针的 R69 保守策略。故 R69 = PORTAL 在「单部署、护照已知、无需探针」边界上的退化；安全侧永不让步。

**定理 19（安全自举与无突变）** 探针全程受 SIK-CBF 约束（引理 20），物理风险 ≤ ε_probe；探针失败、超预算、接口失配、护照撤销时，TG 单调降级为 fallback，λ 单调不降；R68 的提交/换装不变式保持，故控制连续、无突变，且**不会出现「正在学走路时摔倒」的探索性事故**。

**命题 1（泛化的不可能性，诚实声明）** 不存在仅凭源族数据、对任意目标分布成立的非平凡性能保证。任何声称「无假设全场景安全且高性能」的方案，必在某个人造偏移下被反例击穿。PORTAL 的承诺被**限定**为：SIK 给出无条件安全；性能保证只在声明的 ℱ 与 ρ 内成立；ρ 外显式弃权。这是本方案的伦理与工程底线，而非弱点。

## 6. 本轮最大风险

**一句话**：PORTAL-RAS 的安全承诺完全押在「**不变量内核 SIK 真正覆盖了声明的平台/场景类**」这一**无法由数据校准、只能被证伪**的假设上——一旦新平台存在 SIK 未建模的隐藏约束（非刚体负载、执行器饱和动力学、传感器时延抖动、接触非平稳），**连兜底技能 IFS 本身都会失效**，而护照与移植门仍会显示「已盖章/在半径内」，给出一种「已经泛化」的虚假安全感；泛化最危险的失败，不是不会做，而是**以为自己会做**。

**次级风险与缓解**：
1. **SIK 覆盖缺口**（隐藏物理约束）→ 压力测试 + 在线屏障残差监测 + 超界即撤销护照（定义 324）；
2. **移植门在族外失效**（协变量偏移破坏共形保证）→ 显式泛化半径 ρ + 族外强制 fallback（定义 319、命题 1）；
3. **探针不可辨识方向**（有些 ψ 无论怎么激励都估不出）→ Cramér–Rao 奇异方向检查，拒绝盖章（引理 21）；
4. **跨机污染/护照伪造** → FEG 独立性 + 签名/撤销/时间戳 + k 源一致（定义 321–322、引理 23）；
5. **过度保守导致平台「昂贵急停」** → 可部署率指标 E308 + 探针 resolution bonus，确保泛化是收益而非退化的借口；
6. **阈值本身迁移**（τ_ece/TAU_FMA 也属 ψ_loc）→ 定义 311 强制归属，禁止把源场景的阈值当作不变量。

```python
        self.prov, self.rho, self.src, self.state = prov, rho, src, "UNSTAMPED"
    def stamp(self, tr_hat, gate_ok, now):
        if gate_ok and tr_hat <= EPS_TR and self.conf.radius <= R_PSI:
            self.state, self.stamp_t = "STAMPED", now
    def revoke(self, reason):
        self.state, self.reason = "REVOKED", reason

# IP-265 SIK/IFS：安全不读任何学习参数
def invariant_shield(state, u_task, s_unc):
    if barrier_condition(state, u_task, s_unc) >= 0: return u_task
    return invariant_fallback(state)                 # 停住 / 撤回 / 限速减速

# IP-266 PROBE：估计 ψ_loc 的贝叶斯实验设计（探针安全不看 ψ̂）
def run_probe(cap, target, budget):
    log = []
    while not cap.stamped() and budget.remain() > 0:
        g = plan_probe(cap.psi_post, budget, target.s_unc)   # s.t. invariant_cbf_ok
        if g is None: break
        y = target.execute_under_shield(g, invariant_shield)
        cap.psi_post = bayes_update(cap.psi_post, y); log.append((g, y))
        cap.conf = credible_set(cap.psi_post)
        if not target.interface_consistent(): cap.revoke("adapter_mismatch")
    return log

# IP-267 TG：被校准的移植门，三态
def transfer_gate(cap, target, alpha):
    score = nonconformity(target, cap)               # Δa, r_res, 接口一致性
    p = conformal_pvalue(score, cap.calib_scores, family=cap.src.family)
    if cap.conf.radius <= R_PSI and p >= alpha and cap.divergence <= cap.rho:
        return "stamp"
    if cap.probe_budget_viable(target) and tr_is_improvable(cap, target):
        return "probe"
    return "fallback"                                # 半径外 / 无预算 / 强冲突

# IP-268/274 PORTAL 主闭环（外层部署级 + 内层 R69 全闭环）
def PORTAL_round(M, obs, target):
    cap  = M.passports.get(target.cap_id)
    mode = M.tg.transfer_gate(cap, target, M.alpha)
    if mode == "fallback":
        return M.ifs.act(obs, target.s_unc)          # 只由不变量保证
    if mode == "probe":
        M.probe.run(cap, target, M.budget)
        if M.tg.transfer_gate(cap, target, M.alpha) != "stamp":
            return M.ifs.act(obs, target.s_unc)
    k, lam, a, (U_ale, U_epi) = M.fluid.FLUID_RAS_round(M, obs)
    lam = M.portal.portal_risk_scale(M, U_ale, U_epi, cap)   # + U_transfer
    M.vqa_t.submit_async(cap, mode, M.probe.log, lam)
    return k, lam, a

def portal_risk_scale(M, U_ale, U_epi_res, cap):
    U_transfer = transfer_uncertainty(cap.conf, cap.divergence)   # 盖章则为 0
    return max(M.efs.risk_scale(...),
               lam_floor(U_ale + U_epi_res + U_transfer))
```

## 4. 推导

**引理 19（可移植性分解界）** R_τ 对 ψ 局部 L_ψ-Lipschitz、接口失配 ν、源-目标 f-散度 D_f 下：`R_tgt ≤ R_src + L_ψ ε_ψ + κD_f + ν`。ε_ψ=D_f=ν=0 时严格退化为 R69。系：探针价值 = 压小 ε_ψ 换取 λ 松弛，收益可加可审计。

**引理 20（探针绝对安全）** 探针满足 SIK 屏障条件且 SIK 物理界在类 𝒞 内成立 ⇒ 任意 ψ_loc 下轨迹不离开安全集，风险 ≤ ε_probe，**不使用 ψ̂_loc**。系：可在不信任自己标定时安全地做标定。

**引理 21（探针收敛率）** Cramér–Rao：`E‖ψ̂_m−ψ‖² ≥ tr(J_m^{-1})`；贝叶斯设计每步最大化信息增益 ⇒ 可辨识子空间内 ε_ψ(m)=O(m^{-1/2})；J_m 奇异方向保持先验宽度，TG 必须拒盖。系：只能消掉「可被激励看到」的参数。

**引理 22（移植门有限样本校准）** 声明族 ℱ 内可交换 ⇒ 共形 p 满足 P(p<α) ≤ α，误放行 ≤ α；加权偏移下密度比正确则同界；**ℱ 外/密度比不可估时保证失效，必须 ρ 硬兜底**。系：门的可信度也是相对的、被声明的。

**引理 23（跨机污染上界）** `δ_p·ρ_c^{k−1}+ε_σ`；ρ_c=1（共享传感器批次）时退化为 δ_p，无增益。系：车队规模不自动带来鲁棒，k_FEG 才是可用证据量。

**定理 18（PORTAL 严格包含 FLUID/R68）** 在 A99（SIK 覆盖类 𝒞）、A100（目标在声明族内或显式弃权）下：(i) 任意部署物理风险 ≤ max(R69, ε_fallback)；(ii) 盖章且 U_transfer=0 时与 FLUID **逐指令相同**；(iii) 在 ρ 内未盖章时探针获 resolution bonus，期望风险 ≤ 不探针的保守策略。故 R69 = PORTAL 的「单部署、护照已知、无需探针」边界。

**定理 19（安全自举与无突变）** 探针全程受 SIK-CBF（引理 20），风险 ≤ ε_probe；失败/超预算/失配/撤销时 TG 单调降级 fallback，λ 单调不降；R68 提交/换装不变式保持 ⇒ 控制连续、无突变，**无「学走路时摔倒」的探索事故**。

**命题 1（泛化不可能性）** 不存在仅凭源族数据、对任意目标成立的非平凡性能保证。PORTAL 只承诺：SIK 无条件安全；性能仅在声明 ℱ 与 ρ 内；ρ 外显式弃权。

## 7. 本轮最大风险

**一句话**：PORTAL-RAS 的安全承诺完全押在「**SIK 真正覆盖了声明的平台/场景类**」这一**无法由数据校准、只能被证伪**的假设上——一旦新平台存在 SIK 未建模的隐藏约束（非刚体负载、执行器饱和动力学、传感器时延抖动、接触非平稳），**连兜底技能 IFS 本身都会失效**，而护照与移植门仍显示「已盖章/在半径内」，给出「已经泛化」的虚假安全感；泛化最危险的失败，不是不会做，而是**以为自己会做**。

**次级风险与缓解**：SIK 覆盖缺口 → 压力测试 + 在线屏障残差监测 + 超界即撤销；族外共形失效 → 显式 ρ + 强制 fallback（命题 1）；探针不可辨识方向 → Cramér–Rao 奇异检查拒盖（引理 21）；跨机污染/护照伪造 → FEG 独立性 + 签名/撤销/时间戳 + k 源一致（引理 23）；过度保守 → 可部署率 E308 + 探针 resolution bonus；阈值本身迁移 → 定义 311 强制归属，禁止把源场景阈值当不变量。
