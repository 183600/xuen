# 第 45 轮（新循环第 1 轮；承接第 44 轮 v21；本轮灵感：多视角视觉 × 视觉伺服） · MV-Cert × VS-Cert：把「姿态集合」升级为「闭环视觉伺服不变量」，把「主动采集」升级为「在环信息增益 + 端到端可观测性审计」（四层架构 v10）

> 承接第 44 轮 v21（Pose-Cert × Data-Cert）。v21 自陈最大风险是「审计集与采集策略不独立 → 覆盖沿自己采到的流形自我确认（Goodhart）」，但它与整个 v21 证书栈共享两个更底层的未言明假设：**(H4) 姿态证书是「单次、单组传感器」估计出的集合，多视角只会让它更紧**，以及 **(H5) 下游是离散决策，闭环连续控制的稳定性不在证书范围内**。现实 UniBot 只有头部双目 + 本体感觉，且头部会持续运动；真正的安全发生在「边走边看」的连续回路里。两个灵感词精确命中 H4/H5：**多视角视觉**迫使我们把姿态集合升级为**多视角约束交集**，并证明交集只在视角独立、共享误差有界时才真收缩（否则是**虚收缩**）；**视觉伺服**迫使我们把证书直接架在**图像空间闭环不变量**上，用姿态集合上的**鲁棒/区间交互矩阵**保证 Lyapunov 收缩，并处理深度不可观测与雅可比奇异。二者耦合出本轮真正的新问题：**机器人的运动既推进任务又制造视差、降低不确定性（对偶控制 / 主动感知），于是可观测性分层 ω_t 从外生环境量变成控制器内生变量——控制器会主动回避会证伪自己证书的退化层，使「占用覆盖」看起来完美，而「扰动可达集」里仍藏着未审计的退化姿态（控制器诱导的 Goodhart）**。

## 0. 直觉与动机

**灵感 1（多视角视觉 → 姿态盒是「约束交集」，但交集可能只是假收缩）**
直觉：一个视角给出一片「与图像观测相容的位姿区域」，多个视角的正确融合是**求交**，交集当然更小。但这是有条件的：若各视角的误差共享同一个来源（头部双目共基线、共享外参标定误差、同一时刻同一光照、同一弱纹理/透明表面），它们会**同向错**；此时求交只收缩了「独立误差方向」，**共享误差方向上的半径不会因增加视角而变小**。因此多视角证书的正确写法是 `rad(P_mv) ≥ r_shared`，任何声称比共享误差还小的融合都是**虚收缩**，必须拒绝。多时视角（靠机器人运动/里程计获得）还会额外引入里程计漂移，需与漂移界做 Minkowski 和。

**灵感 2（视觉伺服 → 证书应架在图像空间闭环不变量上，而非「先估姿态再离散决策」）**
直觉：IBVS 的控制律 `v = −λ L_s⁺ e` 能否稳定，取决于交互矩阵 `L_s`（尤其深度 Z）和 `L_s L_s⁺` 的正定性。姿态是集合 P_t，则 `L_s` 不是矩阵而是**矩阵族 L(P_t)**。正确做法是求一组增益，使 `∀L∈L(P_t)` 都有 `eᵀ L L⁺ e ≥ μ‖e‖²`，从而 `V=½‖e‖²` 在不确定下仍收缩；并把安全性表达为**嵌套漏斗**（进入 F_{k+1} 且全程留在 F_k）。深度不可观测、雅可比奇异（σ_min 太小）、目标出视野时，**不发伺服证书**，只能先「安全地获取深度」或停/减速。

**灵感 3（耦合 → 运动同时是任务与信息采集，必须做「认证的对偶控制」）**
直觉：最省不确定性的动作，往往不是直奔目标，而是**侧移制造视差**。于是动作 = 任务项 + 认知项，效用里加「预测半径缩减」。但预测信息增益用的是（可能有偏的）当前姿态集与噪声模型，可能**虚高**；且认知动作本身不能越出安全漏斗。所以只接受**认证的信息增益下界 Δr_lo**，并事后与实测收缩比对，虚增益回灌审计。

**耦合升级（控制器诱导的 Goodhart）**：v21 的审计对象是「数据采集分布」，本轮必须升级为「闭环可达测度」。因为 ω_t = W(x_t, sensor_t, π) 由策略决定：控制器可以把难层占用压到 0，使经验覆盖 `Ĉov→1`，但一个**有界扰动**就可能把它推进未审计的退化层。审计必须用 `μ_reach`（在有界扰动/人在环下 H 步内可达的层测度）+ 对抗控制器红队，而不是 `μ_π`（策略自占用）。四层架构由 v9 的「姿态根信任 + 数据治理」升级为 v10：新增 **多视角融合层** 与 **闭环视觉伺服层**，并把审计从「数据覆盖」升级到「闭环可达覆盖」。

## 1. 形式化定义（增量：定义 50–56）

**定义 50（视角约束、多视角姿态证书与防虚收缩）**
第 i 个视角给出局部姿态约束集 `P_i = { X∈SE(3) : ‖π(K T_i(X) m_j) − u_{ij}‖ ≤ ε_i, ∀ j∈F_i }`，多视角交集 `P_mv = ⋂_{i=1}^m P_i`。将测角误差分解为共享分量与独立分量 `e_i = e_shared + e_i^⊥`，`‖e_shared‖ ≤ ε_s`，`‖e_i^⊥‖ ≤ ε_i`，并令 `S` 为共享误差在 SE(3) 上诱导的子空间。**视角独立条件**：各 `e_i^⊥` 条件独立且不张成 S 中新增方向。**防虚收缩命题**：在视角独立条件下，`rad(P_mv) ≥ r_shared`，其中 `r_shared = sup_{δ∈S} ‖induced_pose(δ)‖`；增加视角只能收缩 S^⊥ 方向，**不能收缩 S 方向**。任何融合若报告 `rad < r_shared`，判为 spurious contraction 并拒绝签发。多时视角用 `X(t_i)` 约束并叠加里程计漂移界：`P_mv(t) = (⋂_i P_i) ⊕ B_odo(t)`（Minkowski 和），漂移不能再被视角数抵消。

**定义 51（证书交互矩阵与鲁棒伺服不变量）**
图像特征误差 `e = s − s*`，交互矩阵 `L_s(X)` 依赖深度与几何。姿态集合 P 诱导矩阵族 `L(P) = {L_s(X) : X∈P}`。**鲁棒收缩**：存在 `λ>0, μ>0` 使 `∀L∈L(P), ∀e≠0: eᵀ L L⁺ e ≥ μ‖e‖²`，则取 `v = −λ L⁺ e` 时 `V=½‖e‖²` 满足连续 `V̇ ≤ −λμ‖e‖²`（离散：`V_{k+1} ≤ ρ V_k`，ρ<1）。**证书漏斗**：嵌套集合 `F_0 ⊇ F_1 ⊇ …`，要求 `∀state∈F_k` 在 T 步内进入 `F_{k+1}` 且全程留在 `F_k`。**失效即拒发**：`σ_min(L_s) < σ_req`、深度区间退化（单目/弱视差）、目标出视野，任一成立则不签发伺服证书。

**定义 52（信息增益预算与认证对偶控制）**
在安全动作集 `U_safe`（由定义 51 漏斗保证）内，动作分解为任务项与认知项。预测信息增益由可观测性 Gramian/Fisher 下界 `I(u)` 给出：`Σ' = (Σ^{-1} + I(u))^{-1}`，预测半径缩减 `Δr̂(u) = rad(Σ) − rad(Σ')`。**认证信息增益**：只接受对模型误差鲁棒的下界 `Δr_lo(u) ≤ Δr̂(u)`，且要求认知动作**整条轨迹**留在已认证层并集内、漏斗安全成立。效用 `J(u) = J_task + β·Δr_lo(u) − c_risk·Risk(u)`。**在环诚实性**：事后比对 `Δr_lo` 与实测半径缩减，偏差超界则该认知动作记为「虚增益」并回灌审计。

**定义 53（内生可观测性与控制器诱导选择偏差）**
`ω_t` 不是外生给定，而是 `ω_t = W(x_t, sensor_t, π)`，`x_{t+1}=f(x_t,u_t)`，`u_t~π(·|·)`。故分层占用分布 `μ_π(ω)` 由策略决定。定义**闭环可达测度** `μ_reach^H(ω) = P(∃有界扰动/人在环输入 d, ∃t≤H: ω_t=ω | π,d)`。**证书覆盖要求**从 i.i.d. 经验覆盖升级为 `P(cover | ω) ≥ 1−α, ∀ω∈supp μ_reach`。若审计用 `μ_π`（策略自占用）而非 `μ_reach`，则存在策略把难层占用压到 0 使 `Ĉov→1`，偏差 `sup_{ω∈reach} (1 − μ_π(ω)/μ_reach(ω))` 可达任意大——这就是控制器诱导的 Goodhart。

**定义 54（闭环覆盖与可达性审计）**
审计集不再从数据池抽样，而由**闭环轨迹回放 + 有界扰动/人在环注入**生成可达层样本。对每层用单侧置信下界（Clopper–Pearson）。新增**控制器红队**：允许对抗控制器（在物理/执行器约束内）主动搜索使证书失效的输入序列，产出反例与采集/降级请求。审计独立性从「与采集策略无关」加强为「与部署策略无关」：`A ⟂ (π_deploy, π_acq, D_cal)`。

**定义 55（端到端视觉伺服证书组合与级联失效）**
证书链：`P_mv → L(P_mv)` 鲁棒伺服证书 → 图像/几何安全谓词 □ 提升 → 安全动作集 `U_safe` → 动作。**级联失效**：目标丢失、雅可比病态、深度不可观测、视角独立性失效、共享误差界超限、漏斗破坏，任一发生则整链 fail-closed（停/减速/保守先验）。**视野租约** `ℓ_v = (target_id, visible, σ_min, depth_interval, τ, λ_o, λ_d)`；目标出视野或 σ_min 低于阈值即过期，依赖它的伺服证书级联失效。

**定义 56（多视角/伺服租约新鲜度）**
租约膨胀 `r_v(t) = r_v0 + λ_o(t−τ) + λ_d√(t−τ)`，并约束 `σ_min(t) ≥ σ_min^req`、深度区间不退化、已认证视角数 `m_valid(t) ≥ m_req`。任一破坏 → 伺服证书失效；恢复需回环/已知标定物/新视角重新刷新。**根信任命题加强**：姿态租约是根，多视角与伺服租约是其上的中间节点；根或中间节点失效都按定义 55 级联，不允许「局部降级后继续用」。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-63 MULTI-VIEW-CERT-FUSION（多视角融合证书 MVCF）
1. **逐视角约束集**：由重投影残差与像素误差界构造 `P_i`，误差界含标定/同步/量化误差。
2. **共享/独立误差分解**：估计 `e_shared`（外参、时间同步、光照/纹理偏差）与共享子空间 S。
3. **防虚收缩融合**：求交并强制 `rad ≥ r_shared`；多时视角叠加里程计漂移 Minkowski 和；输出 `P_mv` 与视角独立性标志。
4. **视角护照与相关族标记**：同一刚体挂载、同一标定来源、同一时刻的视角标为相关族，融合时按族去重。

### 2.2 IP-64 CERTIFIED-VISUAL-SERVO（认证视觉伺服 CVS）
1. **区间交互矩阵**：由 `P_mv` 与深度区间计算 `L(P_mv)` 的上下界。
2. **鲁棒增益**：求 `(λ, μ)` 使全族收缩；若不存在则退化到 position-based（用 `P_mv` 的 □ 提升）；仍不满足则拒发。
3. **证书漏斗**：构造嵌套安全集，逐段验证 `F_k → F_{k+1}` 的进入与全留。
4. **奇异/深度/视野守卫**：`σ_min`、深度区间、目标可见性任一失效 → fail-closed 并签发视野租约失效。

### 2.3 IP-65 EPISTEMIC-DUAL-CONTROL-AUDITOR（认知对偶控制审计器 EDCA）
1. **认证信息增益**：只接受 `Δr_lo`；认知动作须整段留在已认证层与漏斗内。
2. **闭环可达覆盖审计**：以 `μ_reach` 而非 `μ_π` 估计覆盖；注入有界扰动/人在环。
3. **控制器红队**：在物理约束内搜索使证书失效的输入序列，量化控制器诱导 Goodhart 偏差。
4. **虚增益检测**：比对预测与实测半径缩减，超界即标记并回灌。

## 3. 四层架构 v10

```
根信任层:
  TRI-FUSE(INT8) + 双目/本体感觉 + 头部外参恢复
    → IP-60 PSE: ω_t → P_t；多视角 → IP-63 MVCF: P_mv（防虚收缩）
    → 未观测层/共享误差超界/漂移过大 → 膨胀或 fail-closed
闭环视觉层（新）:
  IP-64 CVS: L(P_mv) 区间 → 鲁棒增益 (λ,μ) → 证书漏斗 F_k
    → 奇异/深度不可观测/出视野 → 拒发 + 视野租约失效
  IP-65 EDCA: 认知动作 Δr_lo + μ_reach 覆盖 + 控制器红队
L1: 几何/物体位姿 → C_ms,B_t,L_m；人 → H_u（均以 P_mv 为条件）
L2: CTC + VLM + IP-35 仲裁 → 分支池；检索键含 ω/视角族/护照
L3: IP-51 CAR(含漏斗与伺服证书) → IP-49 □ → IP-47 组合 → IP-39 规划
    → IP-45 总线(pose-cert/view-fusion/servo-cert/funnel) → IP-53 区间监控
L4: IP-61 DCL(可达层缺口驱动 + 认知动作) ← IP-62 CCA(控制器红队 + 可达覆盖)
    → 重校准 → IP-55 CKB + IP-54 SCV → IP-44/50 → RCA 重颁 → 热更新
运行期：多视角→姿态集→伺服不变量→谓词提升→守卫
        退化/奇异/出视野/虚收缩 → fail-closed
```

## 5. 本轮最大风险

### IP-63 MVCF：逐视角约束、防虚收缩融合、视角护照

def view_constraint_set(view, model, eps_px):
    # 每个特征给一片位姿可行域；用局部线性化+区间得到内外包络
    cones = [backproject_cone(view.K, view.T, model.m_j, view.u_j, eps_px)
             for j in view.features]
    return intersect_cones(cones)                    # 外包络 P_i（保守）

def decompose_view_error(view, calib):
    e_shared = shared_calib_sync_error(view, calib)  # 外参/同步/光照/纹理偏差
    e_indep  = view.residual - e_shared
    return e_shared, e_indep

def fusion_certificate(views, model, calib):
    if len({v.mount_family for v in views}) > 1:
        pass
    sets, indep_ok = [], True
    r_shared = 0.0
    for v in views:
        e_s, e_i = decompose_view_error(v, calib)
        r_shared = max(r_shared, induced_pose_radius(e_s, v))
        sets.append(view_constraint_set(v, model, v.eps_px))
        indep_ok &= is_conditionally_independent(e_i, calib.shared_subspace)
    P = intersect_sets(sets)
    # 关键：交集半径绝不能小于共享误差诱导半径
    if geodesic_radius(P) < r_shared:
        P = inflate_to(P, r_shared)                  # 防虚收缩
    P = minkowski_add(P, odometry_drift_ball(views))  # 多时视角漂移
    return MultiViewCert(P, r_shared=r_shared, independent=indep_ok,
                         family=view_family(views))

def interaction_interval(P_mv, features):
    Ls = []
    for X in sample_extremes(P_mv):                  # 区间扩张/顶点采样
        Ls.append(interaction_matrix(X, features))

def robust_servo_gain(L_interval, e):
    # 在 λ 网格上验证全族收缩；返回 (λ, μ) 或 None
    for lam in gain_grid():
        mu = min_quadratic_ratio(L_interval, e)      # min_L eᵀLL⁺e / ‖e‖²
        if mu > MU_MIN and contraction_ok(lam, mu):
            return lam, mu
    return None

def servo_certificate(P_mv, target, features, sigma_req):
    if depth_unobservable(P_mv, features):            # 单目/弱视差
        return Reject('depth_unobservable')
    L_int = interaction_interval(P_mv, features)
    if sigma_min(L_int) < sigma_req:
        return Reject('jacobian_singular')
    if not target_in_fov(target, P_mv):
        return Reject('out_of_fov')
    g = robust_servo_gain(L_int, current_error(features))
    if g is None:
        return fallback_position_based(P_mv)          # □ 提升 + 降速
    return ServoCert(gain=g, L_interval=L_int,
                     funnel=build_funnel(P_mv, g))

def build_funnel(P_mv, gain):
    # 嵌套集合：由 Lyapunov 下界反解每层允许误差
    lam, mu = gain
    return [F for F in nested_safe_sets(lam, mu, P_mv)]

### IP-65 EDCA：认证信息增益、可达覆盖审计、控制器红队
```
def epistemic_utility(u, Sigma, task, budget):
    if u not in safe_action_set:                      # 定义 51 漏斗
        return -inf
    I = observability_gramian_lower(u, Sigma)         # 对模型误差取鲁棒下界
    Sigma_next = inv(inv(Sigma) + I)
    dr_lo = geodesic_radius(Sigma) - geodesic_radius(Sigma_next)
    return task.gain(u) + BETA * dr_lo - C_RISK * risk(u)

def reachable_coverage_audit(model, policy, distractions, horizon, delta):
    samples = []
    for d in distractions:                            # 有界扰动/人在环注入
        for traj in rollout(policy, d, horizon):
            samples += [observability_stratum(s) for s in traj]
    # 用可达占用而非策略自占用估计覆盖
    return {w: clopper_pearson_lower(samples, w, delta)
            for w in strata(samples)}

def controller_redteam(model, policy, budget):
    # 在物理/执行器约束内搜索使证书失效的输入序列
    worst = None
    for u_seq in adversarial_search(policy, bounds=budget):
        bad = first_unsound_step(model, u_seq)
        if bad and (worst is None or bad.deficit > worst.deficit):
            worst = bad
    return worst                                     # 反例 → 降级/采集请求

def virtual_gain_check(predicted_dr_lo, realized_dr):
    if abs(predicted_dr_lo - realized_dr) > TAU_GAIN:
        return Flag('virtual_gain', action='disable_epistemic')
    return None
```
