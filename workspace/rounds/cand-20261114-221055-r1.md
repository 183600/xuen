# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「视觉编码器」×「柔顺控制」）

> R69 教会系统**向外求证**（看、问、触），并把不确定性拆成 aleatoric/epistemic。但 R69 的整套求证仍悬在一个未经检验的假设上：**它的"证据"最终都落回同一个视觉表征 z，而它的"探针"只是一个带粗略风险约束的通用动作。** 于是 R69 自陈的最大风险——"问错比不问更危险"——并没有被真正堵住：
> - 视觉编码器若只为语义分类优化，会丢掉接触几何、表面法向、摩擦、局部柔度这些**柔顺控制真正需要**的低层物理量；它看不见的东西，会被流策略"幻觉"成模态，VoI 就在一个物理上不存在的世界里计算；
> - 反过来，R69 的 `g_probe` 只是"轻触一下"：既没有证明触了**不危险**（缺少无源/能量约束），也没有证明触了**能分辨**（缺少可辨识性/激励设计）。
>
> 本轮两个灵感正好互补：
> - **视觉编码器**不该只是语义分类器，而应是一个**接触假设场**——它提出"哪里能碰、法向朝哪、多软多滑、有多大把握"，把视觉从"是什么"升级为"能怎么碰"的物理猜想生成器；
> - **柔顺控制**不只是执行器，而是一种**物理测量仪器**——用阻抗/导纳在能量受限下施加受控探针，读出"力—位移响应"，这是视觉永远给不出的独立证据；同时"保持柔软"本身就是不确定下最安全的默认姿态。
>
> 核心命题：**一个模态/信念只有在物理上"兑现"后才算被确认：视觉提出可实现的接触假设，柔顺控制以无源、可辨识、可逆的探针去签署它；签署之前，机器人保持柔软。** 命名 **PACT-RAS**（Physical-Agreement Contact-Testing for Risk-Adaptive Systems，视觉—柔顺物理契约）。
>
> 一句话定位：R66 问"谁控制"，R67 问"未来怎样"，R68 问"我的测量还准吗"，R69 问"我该向谁求证"，R70 问"**这个答案能不能在物理上兑现——碰一下会更确定，而不是更糟**"。

## 0. 直觉与动机

**灵感 1（视觉编码器 → 从语义特征到接触假设场）**
直觉：感知栈的默认目标是"认得出这是什么"，但抓取/装配/擦拭这些柔顺任务问的是"这块表面能不能碰、法向朝哪、多硬多滑、边界在哪"。为分类训练的编码器会把高对比的语义线索留下来，把低对比但决定接触成败的几何/材质线索（微纹理、反光、局部形变、遮挡边缘）压掉。R69 的流策略条件在这样一个 z 上，它的多模态分布其实是在一个**被语义化剪裁过的世界**里产生的：真在那儿的分支可能已经被编码器扔掉，不存在的分支却可能被补出来。所以第一步不是换策略，而是换编码器的**输出对象**：输出稠密接触假设场 `h(p)`，并把每个模态配上一张"若该模态为真，接触应如何发生"的物理响应预测。

**灵感 2（柔顺控制 → 一种带安全证明的测量仪器）**
直觉：视觉在遮挡、透明、可变形物体上天然失效，而接触恰恰在这些场景里信息量最大。阻抗控制可以在**几乎不改变物体状态**的前提下施加小幅、多频、限力的激励，从力—位移响应里反推刚度、阻尼、摩擦与滑移。更关键的是，柔顺控制自带一套成熟的安全语言：**无源性（passivity）与能量罐（energy tank）**。这正好把 R69 那句含糊的"探针物理风险 ≤ ε_int"变成可证的：注入能量有上界、接触力有上界、闭环无源，就不会把环境或机器人搞失稳。**柔顺既是探针，也是保险。**

**灵感 3（可实现性 → 先证伪"幻影"，再花钱去问）**
直觉：R69 最怕流模型幻觉出一个模态，然后系统自信地去追问一个幻影。但很多幻影在物理上是**一眼假**的：它要求在一个没有支撑面的地方形成接触、要求负摩擦、要求超过材料极限的形变、或与运动学法向矛盾。所以可以在任何探针之前加一道**可实现性过滤器**：物理上不可能实现的模态直接剔除，不进入 VoI 计算。这比"多问几个源"更便宜，也更根本——**幻影最本质的弱点不是它不被相信，而是它无法被实现。**

**灵感 4（可辨识性 → 探针要"软而准"，不要"硬而盲"）**
直觉：R69 默认"触一下就有信息"。但系统辨识告诉我们，激励若落在参数的不敏感方向（null space）上，再大的力也不产生信息；反之，沿最大灵敏度方向的小幅多频激励可以高效辨识。于是探针设计是一个**最优实验设计**问题：在能量/力/不可逆预算内，选能使 Fisher 信息矩阵最"胖"（最小特征值最大）的激励。**信息增益不是力气的函数，而是方向与频谱的函数。** 这也解释了为什么某些"摸一下就知道"的物体，换一个抓法怎么摸都不确定。

**灵感 5（不可逆性 → 信息也有单向门）**
直觉：R69 的交互成本 `c(g)` 假设动作可撤回。但接触常不可撤回：压过头就塑性变形，切向力过大就滑落摔坏，热/化学接触可能不可逆。于是必须引入一条 R69 完全没有的成本轴——**不可逆损失**。有些信息"值这个钱"，有些不值；更有些探针即使信息很大也必须放弃，因为失败后果不可承受。这把 R69 的 `VoI − c` 升级为 `VoI_irr = 信息增益 − ρ_irr · P_irr · L_irr`，并加硬约束 `P_irr ≤ p_max`。**不是所有"值得知道"的事都"值得去碰"。**

**灵感 6（先软后硬 → 柔顺是默认，确认是变刚的许可证）**
直觉：R69 的 λ 只是一个刹车系数，压在所有动作上。PACT 把阻抗也纳入同一条安全逻辑：**不确定时保持低刚度（柔软、被动安全、可被人/环境推开），只有在物理确认后才允许提高刚度去精确执行。** 这既是控制策略，也是安全论证：低刚度的默认姿态本身是无源安全的；"变硬"是一个需要证据才能解锁的动作，而不是默认。**"先软后硬"把 R69 的'少动'变成了'软着动、确认后再硬着做'。**

**灵感 7（正面回应 R69 最大风险：让答案去物理兑现）**
直觉：R69 用"k 个正交证据源一致"防投毒，但一致可以是共谋。PACT 补的不是"更多源"，而是**一种不同性质的源**：视觉说的是"应该摸到什么"，柔顺测的是"实际摸到了什么"。要让一个错误模态通过认证，攻击者必须同时伪造视觉可实现性与力响应，成本陡增；而探针的无源约束保证即使被骗，造成的物理伤害仍有上界。**视觉提出契约，接触签署契约；签不了字的，一律当作没确认。**

## 1. 形式化定义（增量：定义 310–326）

**定义 310（PACT-RAS 总览）** PACT-RAS = (FLUID-RAS, CVE, Rf, PCI, PAP, IVO, VCC, PIC, PAG, CFIC)。四不变式：
(i) **实时流零学习写操作**（继承定义 293-i；CVE/蒸馏均为离线训练）；
(ii) **无源能量预算**：每个信息动作都实现为带能量罐证书的阻抗轨迹，注入能量 ≤ E_int、接触力 ≤ F_max、预测不可逆形变 ≤ ε_irr，任一越界即中止并回到柔顺保持；
(iii) **物理兑现纪律**：模态被"确认"当且仅当它同时通过可实现性（定义 313）、可辨识性（定义 318）与物理一致性（定义 317）；多个视觉/语言源一致但无物理兑现时，仍只算弱证据；
(iv) **严格包含**：当探针不可行/不安全/不可辨识时，PACT 逐指令退化为 FLUID-RAS（进而 R68）。

**定义 311（接触中心视觉编码器 CVE）** 视觉编码器 Φ_c: o ↦ h，其中对每个候选接触面元 p ∈ Ω，
`h(p) = (n̂(p), κ(p), μ̂(p), σ̂_c(p), d̂(p), π(p), Σ_h(p))`
分别为表面法向、曲率、摩擦系数、局部柔度（刚度倒数）、有符号距离/穿透、接触概率、估计协方差。Φ_c 由语义骨干 + 法向/曲率/材质/深度/不确定性多任务头组成，训练时以"力/触觉特权教师"做蒸馏（定义 320），部署时不假设有力/触觉传感器可用于感知。对 R69 的每个候选模态 m_k，输出模态条件接触图 `h_k = h|m_k` 与力—位移响应预测 `R̂_k(δ) = Phys(h_k, θ_k, δ)`。

**定义 312（物理参数与物理不确定性）** 每个模态附带物理参数 `θ_k = (μ_k, σ_{c,k}, d_k, n_k)`（摩擦、柔度、几何/法向）。定义**物理认知不确定性** `U_phys = H(θ | o)`（或 R̂ 的预测方差）。它与 U_ale（不可约噪声）、U_epi（离散模态歧义）语义不同：U_phys 是**连续参数**的认知不确定性，且**只能由接触显著降低**（视觉对它多为欠定）。

**定义 313（可实现性过滤器 Rf）** 给定模态 m_k、接触假设 h_k、任务动作 a 与不可逆阈值 ε_irr，`Realizable(m_k) ⇔`
- **摩擦锥**：所需切向力 ≤ μ̂_k · F_n（不在静摩擦下必然滑移）；
- **能量自洽**：R̂_k 的力—位移回线耗散非负（不要求物体对外做功）；
- **几何自洽**：接触点与法向和运动学/深度一致（不悬空、不穿模）；
- **可逆性**：预测形变/穿透 ≤ ε_irr。
任一不满足 ⇒ m_k 不可实现，从 VoI 候选中剔除。**幻影先在物理上被证伪，再谈值不值得问。**

**定义 314（柔顺探针 PCI）** 信息动作升级为阻抗程序
`g_c = (K_d, B_d, δ(t), f_max, T)`，
其中 K_d、B_d 为期望刚度/阻尼，δ(t) 为小幅位移激励（单次按压、斜坡、多正弦/啁啾），T 为时长；执行律 `τ = Jᵀ(K_d(x_d−x) + B_d(ẋ_d−ẋ)) + g(q)`。观测为力—位移响应 `y = (f(t), x(t))`。K_d 有上界 K_max（"软"），f_max 有上界 F_max。

**定义 315（无源能量证书 PAP）** 能量罐 `E_tank(t) = E_tank(0) + ∫(τ·ẋ − P_diss)dt`。探针可行当且仅当 `E_tank(t) ≥ 0 ∀t` 且 `E_inj = max_t(E_tank(0) − E_tank(t)) ≤ E_int` 且 `f(t) ≤ F_max`。越界立即中止并切换柔顺保持（K_d ← K_soft）。无源性 ⇒ 交互不会向系统或环境注入无界能量 ⇒ 接触风险 ≤ ε_int。这是 R69 定义 302 的严格版本。

**定义 316（不可逆感知的 VoI）** 设信息增益 `IG(g) = H(M,θ|o) − E_{y~p(·|g,o)}[H(M,θ|o,y)]`，不可逆概率 `P_irr(g)` 与损失 `L_irr`。定义
`VoI_irr(g) = IG(g) − ρ_irr·P_irr(g)·L_irr`，
选 `g* = argmax_g [VoI_irr(g) − c(g)]`，s.t. `P_irr(g) ≤ p_max`、PAP 通过、预算未超。若 `max[VoI_irr − c] ≤ 0`：不探测，走 FLUID 兜底。

**定义 317（视觉—柔顺一致性 VCC）** 对模态 m_k，测得 y 与预测 R̂_k 的加权残差 `r_comp,k = ‖y − R̂_k(δ)‖_W`。物理后验重加权
`w_k^post ∝ w_k · exp(−r_comp,k² / (2σ_comp²))`。
`r_comp` 构成第三条自洽通道（前两条为 R69 的 r_res 与 Δa）：r_res 测"传感器自洽"，Δa 测"行为自洽"，r_comp 测"物理自洽"。

**定义 318（物理可辨识性证书 PIC）** 探针 g 对区分模态/参数的可辨识性由 Fisher 信息矩阵
`F(g) = E_{y|θ,g}[ (∂ log p(y|θ,g)/∂θ)(·)ᵀ ]`
刻画。g 可辨识当且仅当 `λ_min(F(g)) ≥ λ_min^thr`（或条件数 ≤ κ_max），即激励满足持续激励（PE）条件。不可辨识则既不消耗探针也不据此定案。设计目标为 D-最优：`argmax_g log det(F(g) + εI)`。

**定义 319（物理兑现门 PAG）** 模态 m_k 被**认证**当且仅当：(i) 可实现（定义 313）；(ii) 至少一次探针满足可辨识（定义 318）；(iii) `r_comp` 低于阈值且物理后验熵下降 ≥ ΔH_min；(iv) 无不可恢复的不可逆事件。否则 U_epi/U_phys 保持未消解并走 FLUID 兜底。**单一通道（哪怕多个视觉源一致）不得单独认证。**

**定义 320（力特权蒸馏 FPD）** 离线训练：教师（仿真或实验台）可访问力/触觉与真实物理参数，学生仅用视觉。损失
`L_CVE = L_contact + λ_f L_forcepred + λ_c L_cal + λ_m L_masked`，
其中 `L_contact` 监督接触位置/法向/柔度，`L_forcepred` 监督 R̂(δ)，`L_cal` 校准 Σ_h，`L_masked` 遮住接触区后仍能由上下文预测力响应（迫使编码器使用物理相关线索而非语义捷径）。仅离线，不违反不变式 (i)。

**定义 321（证书 J_PACT）** `J_PACT = (J_FLUID, ECE_contact, r_comp_p95, P_irr_max, E_inj, F_max, λ_min(F), physical_agreement_rate, pact_ver)`。Valid ⇔ Valid(J_FLUID) ∧ 可实现性 ∧ 无源证书 ∧ 可辨识 ∧ 兑现纪律满足 ∧ 预算未越界。

**定义 322（物理威胁模型）** `ℰ_PACT = ℰ_FLUID × ℰ_physical`，其中 ℰ_physical 含：**欺骗性刚度**（看起来软、实为硬/脆）、**触发式陷阱**（探针本身触发破坏/吸附/倾倒）、**摩擦陷阱**（静/动摩擦与视觉不符，诱发滑落）、**力觉欺骗**（篡改力传感）、以及**视觉—物理共谋**（构造同时骗过外观与响应的物体）。关键约束：无源证书保证被骗时伤害有上界，故威胁主要是"错判"而非"失控"。

**定义 323（扩展的两级保守退避）** 在 R69 定义 307 之上加"接触否决"分支：
- 可实现性失败 / P_irr 过高 / PAP 失败 / 不可辨识 ⇒ **不探测**，U_epi+U_phys 未消解，退 FLUID（λ = λ_floor(U_ale+U_epi+U_phys)）；
- 探测但结论不确定 ⇒ 探针能量计为沉没成本，仍退 FLUID；
- 探测并通过 PAG ⇒ 获得 resolution bonus，`λ = λ_floor(U_ale + 残余 U_phys)`，并解锁刚度。
安全侧永不弱于 FLUID。

**定义 324（自适应探测调度）** 每分钟至多一次接触探针；用廉价 `probe_head(z, h)` 预测 `VoI_irr` 与 `λ_min(F)`，仅当预测可辨识且不可逆风险低时执行。优先序：`decidability = λ_min(F) · g(Δ_min) / (P_irr·L_irr + c)`。与前一轮未决模态共享探针，避免重复激励。

**定义 325（接触状态估计 CSE）** 融合视觉假设 h_k 与力测量 y，用带接触物理模型的粒子/卡尔曼滤波输出接触状态 `(位置, 法向, 刚度, 摩擦, 滑移)` 及其不确定性；该后验既回灌 U_phys，也作为柔顺控制器的前馈参数。视觉给先验、接触给似然、控制器给执行。

**定义 326（先软后硬的合规风险缩放）** 阻抗刚度按证据门控：
`K_d = K_soft`（未确认/未消解）或 `K_stiff(λ)`（已通过 PAG），且 `K_stiff` 受变刚度速率限制 `|dK_d/dt| ≤ ṙ_K`。风险缩放与 R69 一致，但 U_floor 增加未消解的 U_phys；**刚度是安全许可证，不是性能旋钮。**

## 2. 关键算法骨架

```python
# IP-264 CVE：接触中心视觉编码器（离线力特权蒸馏，在线零学习）
class ContactVisualEncoder:
    def __call__(self, o):
        f = self.backbone(o)                      # 多尺度骨干（可复用 MTM）
        return ContactField(
            n   = self.n_head(f),  kappa = self.k_head(f),
            mu  = self.mu_head(f), comp  = self.comp_head(f),
            d   = self.d_head(f),  pi    = self.pi_head(f),
            Sig = self.var_head(f))
    def predict_response(self, h, theta, delta):
        return self.phys_model(h, theta, delta)   # R_hat(delta)

# IP-265 Rf：可实现性过滤（先证伪幻影）
def realizable(mode, h, theta, eps_irr):
    if tangential_load(mode.a, h) > theta.mu * normal_load(mode.a, h): return False
    if not energy_consistent(h, theta):                                return False
    if penetration(h, mode.a) > eps_irr:                               return False
    if not normal_consistent(h, mode.a, kinematics):                   return False
    return True

# IP-266/268 PCI + IVO：在能量/不可逆预算内选可辨识探针
def choose_probe(modes, h, theta, budget):
    best = None
    for g in probe_library:                     # 按压 / 斜坡 / 多正弦 / 啁啾
        if not budget.allow(g):                        continue
        if not passivity_certify(g, budget.E_int):     continue
        if predict_p_irr(g, h) > P_MAX:                continue
        Fm = fisher_information(h, theta, g)           # 预测力响应雅可比
        if min_eig(Fm) < LAM_MIN:                      continue   # 不可辨识
        score = logdet(Fm + 1e-6*I) - irr_penalty(g) - cost(g)
        if best is None or score > best.score: best = (g, score, Fm)
    return best if best and best.score > 0 else None             # 无利可图 -> FLUID

# IP-267 无源执行：能量罐 + 力上限，越界即柔顺中止
def run_probe(ctrl, g, E_int, F_max):
    tank = EnergyTank(E_int)
    ctrl.set_impedance(g.K_d, g.B_d)
    for t in g.timeline:
        tau = ctrl.impedance_tau(g.delta(t))
        if not tank.admit(tau, ctrl.xdot) or ctrl.force > F_max:
            ctrl.abort_to_soft(); return None      # fail-safe
        ctrl.step(tau)
    return ctrl.measured_response()                 # (f(t), x(t))

# IP-269 VCC：物理后验重加权
def physical_posterior(modes, theta, y, g):
    logw = []
    for k in range(len(modes)):
        r = residual(y, modes[k].R_hat(theta[k], g.delta))
        logw.append(log(modes[k].w) - r**2 / (2*SIGMA_COMP**2))
    return softmax(logw), r

# IP-275/276 主闭环：继承 FLUID，仅在"求证"处插入物理兑现层
def PACT_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    h   = M.cve(o)                                   # 接触假设场
    K   = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    modes = M.fmp.sample(o, K)
    U_ale, U_epi = M.aud.decompose(modes)
    modes = [m for m in modes if realizable(m, h.at(m), M.theta[m], EPS_IRR)]
    U_phys = M.cve.physical_entropy(h)
    g = None
    if (U_epi > TAU_EPI or U_phys > TAU_PHYS) and not M.slow_fault_suspect():
        g = M.pci.choose(modes, h, M.theta, M.budget, E_int=M.E_int)
    certified = False
    if g is not None:
        y = run_probe(M.ctrl, g, M.E_int, M.F_max)
        if y is not None:
            w_post, r_comp = physical_posterior(modes, M.theta, y, g)
            if r_comp < TAU_COMP and entropy(w_post) < entropy(modes.w) - DH_MIN:
                modes = update(modes, w_post); certified = True
                U_phys = M.cse.update(h, y, g)
            else:
                g = None                          # 探测但不确证 -> FLUID 兜底
    U_floor = U_ale + (0.0 if certified else U_epi + U_phys)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    K_d = K_SOFT if not certified else K_stiff(lam)  # 先软后硬
    k   = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    mode = select_mode(modes, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k], K_d) * lam
    M.vqa_i.submit(g, U_epi, U_phys, r_comp, certified)
    return k, lam, mode, K_d
```

## 3. 推导

**引理 19（可实现性排除幻影）** 设真实模态 m* 在 A99（接触参数估计误差有界）下以概率 ≥ 1−ε_r 通过 Rf；任一满足"无支撑/负摩擦/超限形变/法向矛盾"之一的幻影 m_h 以概率 1 被 Rf 拒绝。则进入探针阶段的幻影比例 ≤ 该类幻影未违反物理约束的比例。系：**先做零成本物理证伪，再谈信息价值**，R69 的"追问幻影"被结构性削减。

**引理 20（无源性给出探针风险上界）** 若探针满足定义 315，则对任意环境（含时变、非线性），机器人与环境互联闭环无源，注入能量 ≤ E_int、接触力 ≤ F_max；接触冲量/位移有界，且中止时状态回到柔顺保持吸引域。故探针物理风险 ≤ ε_int，且不会诱发失稳突变。这是 R68 定理 15 / R69 定理 17 的物理化加强。

**引理 21（可辨识性 ⇒ 有效信息）** 若 `λ_min(F(g)) ≥ λ_min^thr`，则在局部线性化下参数后验协方差满足 `Σ_post⁻¹ ≽ Σ_prior⁻¹ + F(g)`，故熵降 `ΔH ≥ ½ log det(I + Σ_prior F(g))`；若激励落在 F(g) 的零空间（λ_min→0），则 `ΔH→0`。系：探针收益由**方向与频谱**决定，而非力幅；"软而准"可优于"硬而盲"。

**引理 22（不可逆—信息的最优幅度）** 设信息方差 `σ²(E) ~ 1/E`（Fisher 标度）而 `P_irr(E)` 随 E 单调增，则 `E* = argmin_E [σ²(E) + ρ_irr P_irr(E) L_irr]` 有限且内点；超过可辨识饱和点后继续加力只增加不可逆风险、不增加信息。系：存在"刚好够辨识"的力档，硬碰不是更聪明，只是更危险。

**定理 18（PACT 严格包含 FLUID）** 在 A99–A102 下，PACT 的期望风险 ≤ FLUID；且当无可实现探针、PAP 失败、不可辨识、P_irr > p_max 或探测不确证时，两者**逐指令相同**（定义 323）。FLUID 是 PACT 在"永不接触兑现"边界上的退化；安全侧不让步，效率侧获物理 resolution bonus 与刚度解锁。

**定理 19（物理兑现抬高欺骗成本）** 设视觉可实现性欺骗率 δ_v、力响应欺骗率 δ_f、二者相关 ρ<1。认证错误模态需同时通过两者，错误率 ≤ δ_v·δ_f + ρ·min(δ_v,δ_f) + ε_σ；且即使被骗，PAP 保证伤害 ≤ ε_int。系：**共谋一致（多个视觉源）不再是充分证据，物理响应提供了一个不同性质的、更难同时伪造的源。**

**定理 20（先软后硬的无突变安全不变式）** 在未认证区间 K_d = K_soft（无源、可被环境推开），仅当 PAG 通过才按 `|dK_d/dt| ≤ ṙ_K` 升至 K_stiff；则刚度切换连续、能量有界、接触力连续，换装/提交不变式保持。故 PACT 不引入力的突变，且"变硬"严格是需要证据的动作。

## 6. 本轮最大风险

**一句话**：PACT 把"物理兑现"当作最终仲裁，但**接触不是真值，而是另一个模型**——若视觉与接触估计共享同一个错误先验（同一仿真器、同一批数据、同一个错误的接触模型），它们的"一致"只是**模型自我背书**，而且这次会被盖上"已认证"的章；更糟的是探针本身不可逆，"骗过认证"或"误触陷阱"的代价不再是保守的慢，而是**物理世界里的不可撤销损坏**——**签字画押，比不敢签字更危险**。

**次级风险与缓解**：
1. **接触模型失配**（摩擦/柔度/滞后建模错误）→ 模型不确定性并入 J_PACT、域随机化 + 在线 CSE 残差监控，失配越界即退回"不认证"；
2. **不可逆探针**（脆弱/危险物体）→ 定义 316 硬约束 P_irr ≤ p_max + 力/位移双限 + 可辨识饱和即停；
3. **可辨识性不可达**（某些物体任何安全探针都打不出信息）→ 放弃探测、退 FLUID 保守，承认"问不出来"；
4. **CVE 需要力特权数据**（并非处处可得）→ 仿真教师 + 小样本真机迁移，报告跨域差距；
5. **认证后物体变化**（执行中非平稳）→ 证书带时效，刚度解锁需周期性复核，否则自动降回 K_soft。

```python
# IP-264 CVE：接触中心视觉编码器（离线蒸馏，在线前向）
class ContactVisualEncoder:
    def __call__(self, o):
        f = self.backbone(o)
        return ContactField(n=self.n_head(f), kappa=self.k_head(f), mu=self.mu_head(f),
                            comp=self.comp_head(f), d=self.d_head(f),
                            pi=self.pi_head(f), Sig=self.var_head(f))
    def predict_response(self, h, theta, delta): return self.phys_model(h, theta, delta)

# IP-265 Rf：先证伪幻影
def realizable(m, h, theta, eps_irr):
    return (tangential_load(m.a, h) <= theta.mu * normal_load(m.a, h)
            and energy_consistent(h, theta)
            and penetration(h, m.a) <= eps_irr
            and normal_consistent(h, m.a, kinematics))

# IP-266/268 PCI + IVO：可辨识且可逆的探针
def choose_probe(modes, h, theta, budget):
    best = None
    for g in probe_library:                         # 按压/斜坡/多正弦/啁啾
        if not budget.allow(g) or not passivity_certify(g, budget.E_int): continue
        if predict_p_irr(g, h) > P_MAX: continue
        Fm = fisher_information(h, theta, g)
        if min_eig(Fm) < LAM_MIN: continue          # 打空处的力没有信息
        score = logdet(Fm + 1e-6*I) - irr_penalty(g) - cost(g)
        if best is None or score > best.score: best = (g, score, Fm)
    return best if best and best.score > 0 else None

# IP-267 无源执行
def run_probe(ctrl, g, E_int, F_max):
    tank = EnergyTank(E_int); ctrl.set_impedance(g.K_d, g.B_d)
    for t in g.timeline:
        tau = ctrl.impedance_tau(g.delta(t))
        if not tank.admit(tau, ctrl.xdot) or ctrl.force > F_max:
            ctrl.abort_to_soft(); return None
        ctrl.step(tau)
    return ctrl.measured_response()

# IP-269/270 VCC + PIC：物理后验
def physical_posterior(modes, theta, y, g):
    logw = [log(m.w) - residual(y, m.R_hat(theta[k], g.delta))**2/(2*SIGMA_COMP**2)
            for k, m in enumerate(modes)]
    return softmax(logw), residual(y, modes[argmax(logw)].R_hat(theta, g.delta))

# IP-276 主闭环：继承 FLUID，仅在"求证"处插入物理兑现层
def PACT_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    h = M.cve(o)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    modes = [m for m in M.fmp.sample(o, K)
             if realizable(m, h.at(m), M.theta[m], EPS_IRR)]
    U_ale, U_epi = M.aud.decompose(modes); U_phys = M.cve.physical_entropy(h)
    g, certified = None, False
    if (U_epi > TAU_EPI or U_phys > TAU_PHYS) and not M.slow_fault_suspect():
        g = M.pci.choose(modes, h, M.theta, M.budget, E_int=M.E_int)
    if g is not None:
        y = run_probe(M.ctrl, g, M.E_int, M.F_max)
        if y is not None:
            w_post, r_comp = physical_posterior(modes, M.theta, y, g)
            if r_comp < TAU_COMP and entropy(w_post) < entropy(modes.w) - DH_MIN:
                modes = update(modes, w_post); certified = True
                U_phys = M.cse.update(h, y, g)
            else:
                g = None                              # 探测但不确证 -> FLUID
    U_floor = U_ale + (0.0 if certified else U_epi + U_phys)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    K_d = K_SOFT if not certified else K_stiff(lam)   # 先软后硬
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    mode = select_mode(modes, lam)
    tau = M.pi_sigma.prefix_dispatch(mode.a[:k], K_d) * lam
    M.vqa_i.submit(g, U_epi, U_phys, r_comp, certified)
    return k, lam, mode, K_d
```

## 4. 推导

**引理 19（可实现性排除幻影）** 真实模态在 A99 下以概率 ≥ 1−ε_r 通过 Rf；违反"无支撑/负摩擦/超限形变/法向矛盾"之一的幻影以概率 1 被拒。进入探针的幻影比例被结构性削减。

**引理 20（无源风险上界）** 定义 315 成立 ⇒ 机器人与环境互联闭环无源，`E_inj ≤ E_int`、`F ≤ F_max`，中止回柔顺吸引域 ⇒ 探针风险 ≤ ε_int，无失稳突变。

**引理 21（可辨识性 ⇒ 有效信息）** `λ_min(F(g)) ≥ λ_min^thr` ⇒ `Σ_post⁻¹ ≽ Σ_prior⁻¹ + F(g)`，`ΔH ≥ ½ logdet(I + Σ_prior F(g))`；激励落在零空间则 `ΔH→0`。系：**软而准 > 硬而盲**。

**引理 22（不可逆—信息最优幅度）** `σ²(E)~1/E` 而 `P_irr(E)` 单调增 ⇒ `E* = argmin[σ² + ρ_irr P_irr L_irr]` 为有限内点；过可辨识饱和后加力只增风险不增信息。系：**存在"刚好够辨识"的力档。**

**定理 18（PACT 严格包含 FLUID）** A99–A102 下 PACT 期望风险 ≤ FLUID；当不可实现/PAP 失败/不可辨识/P_irr>p_max/不确证时逐指令相同（定义 323）。FLUID = "永不接触兑现"边界。

**定理 19（物理兑现抬高欺骗成本）** 视觉可实现性欺骗率 δ_v、力响应欺骗率 δ_f、相关 ρ<1 时，认证错误率 ≤ `δ_v·δ_f + ρ·min(δ_v,δ_f) + ε_σ`；即使被骗，PAP 保证伤害 ≤ ε_int。系：**多视觉源一致不再充分，物理响应是不同性质、更难共谋的源。**

**定理 20（先软后硬无突变）** 未认证区间 `K_d=K_soft`（无源、可被推开）；仅 PAG 通过后按 `|dK/dt|≤ṙ_K` 升至 K_stiff ⇒ 刚度/接触力连续、能量有界、换装不变式保持 ⇒ 无力的突变，"变硬"严格需要证据。

## 7. 本轮最大风险

**一句话**：PACT 把"物理兑现"当作最终仲裁，但**接触不是真值，而是另一个模型**——若视觉与接触估计共享同一个错误先验，它们的"一致"只是**模型自我背书**，而且这次会被盖上"已认证"的章；更糟的是探针本身不可逆，"骗过认证"或"误触陷阱"的代价不是保守的慢，而是**物理世界里不可撤销的损坏**——**签字画押，比不敢签字更危险**。

**次级风险与缓解**：接触模型失配 → 不确定性并入 J_PACT + 域随机化 + CSE 残差监控，越界即不认证；不可逆探针 → P_irr 硬约束 + 力/位移双限 + 可辨识饱和即停；可辨识性不可达 → 放弃探测、退 FLUID 保守；CVE 需力特权数据 → 仿真教师 + 小样本迁移并报告跨域差距；认证后物体变化 → 证书带时效、周期复核，否则自动降回 K_soft。
