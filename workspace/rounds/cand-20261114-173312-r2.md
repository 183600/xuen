# 第 74 轮（承接第 73 轮「MODGAUGE-RAS 计量契约代数」IP-295~302；灵感循环第 2 轮；本轮灵感：「可解释性」×「零样本泛化」）

> R73 用**证据契约（EC）**把「证据」变成可组合的一等公民，并证明系统级安全性质在模块热替换下保持。但 R73 留下两个**认识论**缺口，而且它们是同一件事的两面：
> - **证书不透明（可解释性缺口）**：`Valid(J_MOD)` 只是一个布尔。它不回答「**是哪些证据、哪条契约、哪个否决指示**使这个决策成立或被拒绝」。R73 自己在最大风险里承认：系统可以「证书齐全、审计全合规」却组合出一个错误的世界。审计日志是给机器看的，不是给人看的——**合规 ≠ 可理解**。更糟的是，若可解释性只做事后 saliency，那它就是「又一个没有契约、没有不确定度、没有有效域的观测」，正是 R73 所批判对象的翻版。
> - **保证绑死在交换性上（零样本缺口）**：conformal 覆盖率、SEAL 校准、CCA 的「允许缩窄」许可，全部以「测试分布 = 校准分布」（可交换性）为前提。零样本意味着材质/类别/任务/本体都在校准集之外；此时**覆盖率静默失效**——证书仍然有效，覆盖率不再成立。R73 的假设 A111（契约表达力）只保证同分布内成立；跨分布时它是**一笔未被计量的负债**。
> - **两者共享同一个对象——证据的有效域**：可解释性回答「**为什么**在这个域内这样决策」（内生的有效域声明）；零样本回答「**是否**还在这个域内」（外生的有效域声明）。方向相反，账本同一本。
>
> 本轮两个灵感正好补齐：
> - **可解释性 → XEC / XCA / XMM**：解释 = **关于证据的二阶证据**。每个模块除输出一阶证据外，必须输出**归因证书**（最小充分解释 MSE 或最小冲突核 MCS）及其不确定度 `u_x`、有效域 `D_x`。解释沿 CCA 组合（**解释函子性**），解释本身要过保真度/稳定性/覆盖率/校准四项计量。**不能解释的动作 = 不能审计的动作 = 否决**（非补偿）。
> - **零样本泛化 → ANM / TCC / STEM / ZSO**：零样本不是一个「能力」，而是一份**可审计的适用性声明**。系统输出新颖度 `n_t`（三区间：域内 / 已证迁移 / 契约外），用**迁移证书**给出**风险膨胀上界**；契约外一律**带解释地弃权**（certified abstention），而不是盲目泛化。再用**契约层（sheaf）**把二者统一：局部证书可粘合 ⇔ 可迁移；**粘合障碍（最小矛盾环）就是「为什么在这里不能泛化」的解释**。
>
> 核心命题：**把「可信」拆成两个可计量的问句——「为什么」（解释）与「还在不在域内」（适用性）——让它们由同一套契约代数组合、同一本审计账结算。** 系统名 **CLEAR-GAUGE-RAS**（**C**ertified, **L**egible, **E**vidence-**A**ware, **A**bstention-**G**overned **RAS**）。
>
> 连续性：R73.5 的 **ECG（证据因果图）**被吸收为 XCA 的**因果归因边**，**MIC（形态无关契约）**被吸收为 TCC 的**形态迁移前提**，IP-302 的因果组合算子成为 XCA 在「因果边权」下的特例。理论姿态照旧：**新层是旧层的严格泛化，安全侧只增不减，退化链逐指令等价。**

## 0. 直觉与动机

### 灵感 1（可解释性 → 解释是「二阶证据」，不是事后故事）

**直觉。** 一阶证据模块测量「世界状态 s 是什么」；解释 `e` 不断言世界，而断言**决策函数对证据的依赖结构**：「如果证据子集 S 被改变到区间 I 之外，决策会变；只要改变被限制在 I 内，决策不变」。这句话是一个**可证伪的谓词**——它可以在密封审计集上用反事实扰动检验真假。既然可检验，它就有准确率、覆盖率与校准误差；既然有这些，它就该像深度/触觉证据一样被**计量**，而不是当作文本或热图交差。

更关键的一步：解释的「有效域」可以直接复用模块契约里的 `D`。于是**解释天然是域相对的（domain-relative）**——「在材质后验未饱和、无互扰、距离在 [d_min,d_max] 的条件下，决策依赖的是触觉接触柱而非深度边缘」。这把可解释性从「模型内在属性」改造成「契约图上的局部截面」，从而能**沿组合代数传播**。

**严谨定义（要点）。** `AC(e,d) = (S, I, ρ, h)`：S 是归因支撑集，I 是反事实不敏感盒，ρ 是该解释在 SEAL-X 上的保真概率，h 是追溯哈希链。**最小充分解释** `MSE(e,d)=argmin_{S: suff(S)} |S|`，其中 `suff(S) ⇔ ∀e'，e'_{S^c}∈D_{S^c} ⇒ d(e')=d(e)`（只在契约有效域内要求不变——这是与一般「充分性」不同的地方，也是可计算的关键）。**最小冲突核** `MCS(e)=argmin_{S: unsat(S)}|S|`，用于否决/弃权：**每一个否决都必须给出一个可定位的最小矛盾集**。

结果：解释不再是「额外的可解释性模块」，而是**证据契约的必填字段**（定义 384），解释质量有独立预算与独立 stub（定义 388/395）。

### 灵感 2（零样本泛化 → 零样本是「适用性认证」，不是「盲目能力」）

**直觉。** 把已校准的仪器运到新环境，你不会闭眼相信读数：你会附一张**迁移证书**，写明「在什么条件下这台仪器的校准仍成立、出了条件误差会放大多少」。零样本的正确工程化不是「让模型在一切分布上都对」，而是「**知道自己在哪儿不再对，并为每一步迁移标价**」。

这个价格必须用**契约得到的语义坐标**来度量，而不是像素或嵌入距离：契约已经告诉你哪些维度重要（材质类别、接触模式、任务文法、本体描述子、视角）。因此新颖度是「**契约维度上的覆盖缺口**」，而不是黑箱 OOD 分数。这样它才能**解释**：「当前输入的透明材质类从未在校准集中出现，深度模块的 `b_t(m)` 已饱和，故 `D_depth` 被违反」。

**严谨定义（要点）。** 新颖度 `n_t` 由三通道合成：(a) 描述子密度比 `ŵ(x)`；(b) conformal 非一致性；(c) **证据级新颖**（未见的材质类/接触模式/任务符号/本体描述子）。三区间：`R_in`（域内）、`R_shift`（有证书的迁移，附带风险膨胀 `ε_T`）、`R_out`（契约外，必须弃权）。**结构覆盖下限**：若输入不被任何契约局部截面的定义域覆盖，则无条件判 `R_out`——这条不依赖任何学习型检测器，**不可被骗**。

### 灵感 3（把二者统一 → 契约层与粘合障碍）

**直觉。** 局部证书像地图上的一块块拼片：只有拼片在重叠处一致，才能画出全局地图。一个新情形若落在拼片并集内、且拼片在重叠处一致，就可「粘合」出一份全局证书；若存在**矛盾的环**，就粘不上——而那个矛盾环**本身就是**「为什么不能在这里泛化」的人话解释。

**严谨定义（要点）。** 在情境空间 `𝕊`（物体×任务×本体×环境）上取有限覆盖 `𝒰={U_i}`，每个 `U_i` 携局部证书截面 `σ_i`；重叠一致性由 R73 的**跨模态一致性审计残差** `r_ij∈C_α` 判定。定义**障碍上链** `ω_ij = 0 if r_ij∈C_α else (失败标签)`，`[ω]∈Ȟ¹(G_𝒰;𝒜)` 非零 ⇔ 覆盖矛盾。**最小矛盾环** = 粘合约束的 MCS = **不可泛化的解释**。于是可解释性与零样本在有限契约层上**同构**（定理 32）。

### 灵感 4（解释-适用性联合门：解释即安全）

**直觉。** 如果允许「安全证书齐全但无法解释」的动作通过，R73 的「合规但错误」风险原样保留；如果允许「解释漂亮但适用性未认证」的动作通过，那只是把自信的错误说得更动听。二者必须**非补偿地与**在一起：`Accept ⇔ SafetyCert ∧ Explainable ∧ Applicable`。任一项为假 ⇒ 带解释地弃权。为防瘫痪，允许**保守解释**：「我弃权，因为存在粘合障碍 ω」，其本身也是一份可审计的 MCS。

## 1. 形式化定义（增量：定义 383–398）

**定义 383（CLEAR-GAUGE-RAS 总览与六不变式）** CLEAR = (MMS†, CCA†, XEC, XCA, XMM, ANM, TCC, STEM, XNG, ZSO, CPB†)。六不变式：
(i) **契约完整性**（继承 R73-i）：无完整证据契约不入图；
(ii) **组合单调性**（继承 R73-ii）：无「凭空变好」路径；
(iii) **反作用通道完备**（继承 R73-iii）：每个证据模块声明 `χ_R`（可为平凡）；
(iv) **解释完备性（新）**：进入核心认证路径的模块必须输出**可计量归因证书**（保真/稳定/覆盖/校准四项）；无法解释的动作不得被接受；
(v) **适用性认证（新）**：任何跨域决策必须携带**域内证书**或**已证迁移证书**；二者皆无 ⇒ **弃权**（非补偿）；
(vi) **主张绑定扩展 + 严格退化链**：每个组件绑定 C1–C6 或为工程附件；解释/新颖/迁移失效 ⇒ 各级 stub，安全侧只增不减。

**定义 384（可解释证据契约 XEC）** `XEC = EC ∪ (α, x_bud, D_x, x_merge, ν, x_seal)`：
- `α: E → Attr`：归因算子（E 为证据代数）；
- `x_bud`：解释预算（生成 + 验证的 WCET 与信息预算，解释不是免费的）；
- `D_x ⊆ D`：解释有效域（可小于证据有效域——「在极近场深度证据仍可用，但其解释已不可信」）；
- `x_merge`：归因合并函数（组合时用）；
- `ν: E → ℝ_+^k`：新颖度报告器（按契约维度报告缺口）；
- `x_seal`：SEAL-X 解释审计集引用。
**类型系统扩展**：`T_out` 从 `Evidence` 变为 `(Evidence, AC)`；「有证据无归因」在类型上不合法。

**定义 385（归因证书 AC 与可证伪语义）** `AC(e,d) = (S, I, ρ, h, κ)`：
- `S ⊆ coords(e)`：归因支撑集；
- `I = ∏_{i∈S^c} I_i`：反事实不敏感盒（对 S 之外坐标的允许扰动范围）；
- `ρ∈[0,1]`：解释置信度（该解释在 SEAL-X 上保真的校准概率）；
- `h`：与 R73 `τ_merge` 合并的追溯哈希链；
- `κ∈{MSE,MCS}`：解释类型（充分性 / 冲突性）。
**语义**：`AC` 为真 ⇔ (i) 充分性：`∀e'，e'_{S^c}∈I ⇒ d(e')=d(e)`；(ii) 必要性：`∃e''，仅改 S 内坐标 ⇒ d(e'')≠d(e)`；(iii) h 可复算。真值可在 SEAL-X 上用受控扰动估计 ⇒ **解释是可证伪的证据**。

**定义 386（最小充分解释 MSE / 最小冲突核 MCS）**
`MSE(e,d) = argmin_{S} |S|  s.t. suff(S)`，`suff(S) ⇔ ∀e', e'_{S^c}∈D_{S^c} ⇒ d(e')=d(e)`；
`MCS(e) = argmin_{S} |S|  s.t. unsat(S)`，`unsat(S)` 指 S 内契约/否决约束联立不可满足。
**性质**：MSE 给出「决策为何成立」，MCS 给出「决策为何被拒/为何弃权」。一般 MSE 是 NP-hard（最小命中集同构），故限定 `|S|≤s_max≤6` 并用 SAT/ILP 求精确解或带**间隙证书**的近似解（定义 397）。

**定义 387（解释组合代数 XCA）** 归因是函子 `Φ: MReg → (V_attr, ⊕, ⊗)`：
- **SER（A∘B）**：`Φ(A∘B) = J_B^A · Φ(A) + Φ(B) + κ_{AB}`，`J_B^A` 为 B 对 A 的雅可比传递，`κ_{AB}` 为交互项，`|κ_{AB}| ≤ I_{AB}`（Shapley 交互指数上界）；
- **PAR（A⊕B）**：按可靠性权重分配归因；**跨模态残差 r 单独作为一个归因项**（归因给「审计」而非任一模态）——于是「融合为什么缩窄/为什么退保守」本身被解释；
- **VETO（A⊠B）**：`Φ = MCS(否决约束)`，输出包含「哪个模块、哪条谓词」；
- **因果边（吸收 ECG）**：`Φ` 只在因果祖先上非零（do-干预语义），抑制「相关但未被使用」的伪解释。
**效率公理**：`Σ_i Φ_i = d(e) − d(∅) + O(κ)`；零贡献者公理：未被决策使用的证据归因为 0。

**定义 388（解释计量 XMM）** XMM = (Fid, Stab, Cov_x, Cal)：
- `Fid = P_{SEAL-X}[sign(归因预测的 Δd) = sign(实际反事实 Δd)]`；
- `Stab =` 归因映射在 e 处的局部 Lipschitz 常数 `L_x`（对输入扰动的上确界）；
- `Cov_x =` 在预算内能找到 `|MSE|≤s_max` 且 `Fid≥φ_min` 的决策比例；
- `Cal =` `ρ` 与实际保真率的 ECE；并对「解释误导风险」`r_x` 做 conformal 上界。
输出 `x_ev = (AC, u_x)`，`u_x = g(Fid, Stab, Cov_x, Cal)`。`u_x > τ_x` ⇒ **解释 stub**（定义 395）。

**定义 389（适用域新颖度 ANM）** 三通道：
`n_t = h(n_desc, n_conf, n_evid)`，其中 `n_desc = ŵ(x)`（密度比），`n_conf` = conformal 非一致性分位，`n_evid` = 证据级缺口（`b_t(m_unknown)`、未见接触模式、未见任务符号、未见本体描述子）。
用 SEAL-Z 校准阈值 `τ_in < τ_out`，得三区间：
`R_in = {n_t ≤ τ_in}`，`R_shift = {τ_in < n_t ≤ τ_out}`，`R_out = {n_t > τ_out}`。
**结构覆盖下限**：`x ∉ ∪_i D_i ⇒ R_out`（与检测器无关，fail-closed）。

**定义 390（迁移证书 TCC）** 域态射 `φ: X_src → X_tgt`（作用于证据描述子）；漂移 `δ = W_1(P_src, P_tgt)`（或 TV）；有效样本量 `n_eff = n / E[w²]`；密度比上界 `W_max`。**迁移证书** `TC = (δ̂, W_max, n_eff, ε_T, conds)`，有效 ⇔ `δ̂ + conf ≤ δ_max ∧ n_eff ≥ n_min ∧ W_max ≤ W_cap`。**风险膨胀界**（`L_π`-Lipschitz 策略、有界损失 B，概率 ≥1−β）：
`R_tgt(π) ≤ R_src(π) + L_π·δ + B·√(log(1/β)/(2 n_eff))`，取 `ε_T` 为右端增量。TC 有效 ⇒ 可在 `λ += ε_T` 下执行；否则弃权。

**定义 391（证据契约层 STEM 与粘合障碍）** 情境空间 `𝕊` 上的有限覆盖 `𝒰={U_i}`，局部截面 `σ_i`；重叠残差 `r_ij`（R73 PAR 审计）。**障碍上链** `ω_ij = 0 if r_ij∈C_α else ℓ_ij`（失败标签），`[ω]∈Ȟ¹(G_𝒰;𝒜)`。`[ω]=0` ⇔ 存在全局证书截面（可粘合）。**零样本定理的前置**：输入被覆盖且 `[ω]=0` ⇔ 迁移证书可构造。**最小矛盾环** `C* = MCS(粘合约束)` 即「不可泛化」的解释。

**定义 392（零样本安全操作 ZSO）**
`d* = π_cert` 若 `R_in` 且 SafetyCert；`d* = π_cert(λ+ε_T)` 若 `R_shift` 且 TC 有效；否则 `d* = π_abs`（R73 stub / 保守策略）+ `MCS(障碍)`。
**零样本度量**：ZS-Safety（违规率）、弃权精确率/召回率、迁移界紧致度（实际风险 − 预测上界）、弃权解释保真度。**主张**：零样本能力应以「契约覆盖 + 弃权质量」度量，而非原始任务成功率。

**定义 393（解释-适用性联合门 XNG）** 非补偿门：
`Accept(d) ⇔ SafetyCert(d) ∧ Explainable(d) ∧ Applicable(d)`，
`Explainable ⇔ u_x ≤ τ_x ∧ Cov_x ≥ c_min ∧ (d 为否决 ⇒ MCS 定位置信 ≥ γ)`；
`Applicable ⇔ n_t ≤ τ_out ∧ (n_t>τ_in ⇒ TC 有效)`。
任一为假 ⇒ 带解释弃权。**任何安全证书不能补偿解释缺失，反之亦然。**

**定义 394（XPB：主张绑定扩展）**
- **C4（可解释性作为计量）**：XEC/XCA/XMM/MSE ← MB4 ← AB4 ← (Fid, Stab, Cov_x, Expl-ECE, 审计时间, 否决定位准确率)；
- **C5（零样本作为认证弃权）**：ANM/TCC/ZSO ← MB5 ← AB5 ← (界紧致度, 弃权精确/召回, 迁移膨胀误差, ZS-Safety)；
- **C6（解释-泛化对偶，理论）**：STEM+XNG ← MB4∪MB5 ← AB6 ← (障碍对失败的 AUROC, 对偶一致性)；
- **C1–C3** 继承 R73。非绑定组件 = 工程附件，不入 MReg、不进正文。

**定义 395（分层失效 E-IVG†）**
- 解释失效（`u_x>τ_x` 或预算内无 MSE/MCS）⇒ **XMM stub** ⇒ 升级/弃权（**绝不静默继续**）；
- 新颖失效（学习型检测器沉默）⇒ 由**结构覆盖下限**兜底判 `R_out`（不依赖检测器）；三通道全失效时默认 fail-closed；
- 迁移失效（TC 无效）⇒ 弃权，**不允许「赌一把」**；
- R73 模块失效 ⇒ R73 各级 stub；REG 失效 ⇒ R68（唯一系统级降级）。
安全侧单调不减：`stub ⊑ 正常` 在风险序上。

**定义 396（MBench-XZ）** MB4（解释：受控反事实矩阵 + 3 个下游任务 + 人类审计计时）、MB5（零样本/迁移：新材质×新类别×新任务文法×新本体，含对抗性描述子漂移）。各 `≤3h` 单卡可复现，预注册脚本 + 固定种子 + 密封集 `SEAL-X / SEAL-Z`。

**定义 397（解释-迁移成本 XCost）** `XCost = 解释生成 + 解释验证 + 新颖估计 + 粘合检验`。精确 MSE 为 NP-hard；限定 `s_max ≤ 6` 时用 SAT/ILP，复杂度 `O(poly(|E|)·C(|E|,≤s_max))`，并输出**间隙证书**（近似解大小 / 下界）。组合解释成本 `O(|V_M|·|S|)`（引理 39），而非对全系统重算。

**定义 398（因果归因 CA）** 借 R73.5 ECG 的因果边，归因只在 `do`-干预下可辨识的因果祖先上非零。**性质**：对「被解释器观测、但决策未使用」的混杂子，因果归因保持不变（相关归因会漂移）。这直接针对「faithfulness vs plausibility」缺口：**解释必须在干预下仍成立，而不是在观测分布上相关。**

# IP-303 XEC：可解释证据契约
@dataclass(frozen=True)
class ExplanatoryContract:
    ec: EvidenceContract                        # R73 证据契约（类型/预算/通道/域/否决/追溯/时序）
    alpha: Callable[[Evidence], Attr]           # 归因算子
    x_bud_us: float                             # 解释预算（生成+验证 WCET）
    D_x: Predicate                              # 解释有效域（可 ⊂ D）
    x_merge: Callable[[Attr, Attr], Attr]       # 归因合并
    novelty: Callable[[Evidence], NoveltyVec]   # 契约维度上的新颖度报告
    x_seal: str                                 # SEAL-X 引用

# IP-304 XCA：解释组合代数（沿 MReg 传播，成本 O(|V_M|·|S|)）
def compose_attr(pa, pb, op, ec_a, ec_b):
    if op == 'SER':
        J = jacobian(pb, ec_b, pa)                     # B 对 A 的传递
        kappa = interaction_bound(pa, pb)              # |κ| ≤ I_{AB}
        return Attr(S=(pa.S | pb.S), I=pa.I & pb.I,
                    vec=J @ pa.vec + pb.vec, kappa=kappa,
                    h=hash_merge(pa.h, pb.h))
    if op == 'PAR':
        r = cross_modal_residual(pa, pb)
        w = reliability_weights(pa, pb)
        residual_attr = AttrItem('AUDIT_RESIDUAL', mass=r)   # 分歧本身被归因
        return Attr(S=(pa.S | pb.S), vec=w[0]*pa.vec + w[1]*pb.vec,
                    extra=[residual_attr], h=hash_merge(pa.h, pb.h))
    if op == 'VETO':
        if pa.veto or pb.veto:
            return Attr(kind='MCS', S=min_conflict_core(pa, pb),
                        h=hash_merge(pa.h, pb.h))
        return Attr(S=(pa.S & pb.S), vec=min_norm(pa.vec, pb.vec))

# IP-305 XMM：解释计量（保真/稳定/覆盖/校准）
class ExplanationMetrology:
    def measure(self, e, d, ac):
        fid = self.seal_x.fidelity(ac, e, d)              # 反事实符号一致率
        stab = self.seal_x.local_lipschitz(self.alpha, e)
        cov = self.seal_x.coverage(ac)
        cal = self.seal_x.ece(ac.rho)                     # 置信度校准
        u_x = combine(fid, stab, cov, cal)
        return XEvidence(ac=ac, u_x=u_x, valid=(u_x <= TAU_X))

# IP-306 ANM：适用域与新颖度（三通道 + 结构覆盖下限）
def applicability(x, contract_cover):
    if not contract_cover.covers(x):                      # 结构兜底，不可被骗
        return Regime.R_OUT, NoveltyVec(structural_gap=True)
    n_desc = density_ratio(x)
    n_conf = conformal_nonconformity(x)
    n_evid = evidence_novelty(x)                          # 未知材质/接触模式/任务符号/本体
    n = combine_novelty(n_desc, n_conf, n_evid)
    regime = R_IN if n <= TAU_IN else (R_SHIFT if n <= TAU_OUT else R_OUT)
    return regime, NoveltyVec(n=n, channels=(n_desc, n_conf, n_evid))

# IP-307 TCC：迁移证书与风险膨胀界
def transfer_certificate(src_calib, tgt_desc):
    delta = wasserstein1(src_calib.desc, tgt_desc)
    w = density_ratio_estimate(src_calib, tgt_desc)
    n_eff = len(src_calib) / mean_square(w)
    eps_T = L_PI * delta + B * sqrt(log(1/BETA) / (2 * max(n_eff, 1)))
    valid = (delta + delta_conf <= DELTA_MAX) and (n_eff >= N_MIN) \
            and (max(w) <= W_CAP)
    return TransferCert(delta=delta, n_eff=n_eff, eps_T=eps_T, valid=valid)

# IP-308 STEM：契约层粘合与障碍解释
def sheaf_glue(cover, sections, audit):
    G = build_overlap_graph(cover)
    omega = {}
    for (i, j) in G.edges:
        r = cross_residual(sections[i], sections[j])
        omega[(i, j)] = 0 if audit.conformal_covers(r) else audit.failure_label(i, j)
    if is_coboundary(omega, G):                           # [ω] = 0
        return GlueResult(ok=True, section=merge_sections(sections))
    C_star = min_contradictory_cycle(G, omega)            # 最小矛盾环 = MCS
    return GlueResult(ok=False, obstruction=omega, explanation=C_star)

# IP-309 XNG/ZSO：联合门与零样本安全操作
def zso_decide(d, safety_cert, x_ev, regime, tc):
    explainable = (x_ev.u_x <= TAU_X) and (x_ev.cov >= C_MIN)
    if regime is Regime.R_IN:
        applicable, lam_add = safety_cert.valid, 0.0
    elif regime is Regime.R_SHIFT:
        applicable, lam_add = tc.valid, tc.eps_T
    else:
        applicable, lam_add = False, 0.0
    if safety_cert.valid and explainable and applicable:
        return Decision(d, lambda_add=lam_add, explain=x_ev.ac)
    return Decision.abstain(explain=min_conflict_core(x_ev.ac, safety_cert))

# IP-310 CLEAR 主闭环（在 R73 MODGAUGE 上增量插入解释/适用性门）
def CLEAR_round(M, obs, audio, tac_frame, depth_img):
    # 感知域（100Hz）：证据 + 归因同时产出
    d_ev, d_ac = M.dpe.update_explained(depth_img, rgb, M.cam_state, M.motion, M.peers)
    t_ev, t_ac = M.dmem.update_explained(tac_frame, M.last_action)
    x_d = M.xmm.measure(d_ev, decision=None, ac=d_ac)      # 解释计量（延迟到决策后复核）
    x_t = M.xmm.measure(t_ev, decision=None, ac=t_ac)

    # 计量域（50Hz）：三件事并置——安全、解释、适用性
    if M.clock.due_metric():
        regime, nov = applicability(M.current_desc, M.cover)
        tc = transfer_certificate(M.src_calib, M.current_desc) if regime is Regime.R_SHIFT else None
        b_t = M.bse.step_full(..., d_ev=d_ev, t_ev=t_ev)
        z_dist, _, _ = M.irl.update(M.y_intent_buf, M.psi, b_t)
        g = M.ervoi.choose(b_t, M.psi, z_dist, t_ev.c_dist, M.budget)
        s2, cost = sigmareflex_step(M.mods, g, M.state, M.budget) if g else (None, 0)
        decision = M.policy(b_t, z_dist, g)
        attr = compose_attr(d_ac, t_ac, 'PAR', M.mods['depth'], M.mods['tactile'])
        x_ev = M.xmm.measure(decision, attr, seal=M.xec.x_seal)
        glue = sheaf_glue(M.cover, M.sections, M.audit)     # 契约层粘合
        out = zso_decide(decision, M.safety_cert, x_ev, regime, tc)
        M.audit_log.write(out, nov, glue, tc)               # 人可读解释 + 机器审计同账
        M.snapshot.write(b_t, z_dist, d_ev, t_ev, out)

    # 控制域（1kHz）：只读快照；解释/适用性任一失效则走保守前缀
    snap = M.snapshot.read_latest()
    if snap.out.abstained:
        k, lam = M.ctrl_out.conservative_prefix(snap.out.explain)
    else:
        lam = embodied_risk_scale(..., snap.out.lambda_add)
        k = M.c_ras_wm.certified_prefix(M.ach.propose_ctrl(...), lam)
    return k, lam, snap.out

## 3. 推导

**引理 38（归因效率与零贡献者）** 若每个模块的 `α` 满足效率（`Σ_i α_i = d(e)−d(∅)`）与零贡献者公理，则 SER/PAR 组合满足效率，误差仅来自交互项 `κ`，且 `|κ| ≤ Σ_{i<j} I_ij`。系：**组合不会凭空产生「解释不了」的贡献；任何多出来的贡献都能记账到某个交互项。**

**引理 39（解释函子性与组合成本）** 归因 `Φ` 是 MReg 到 `(V_attr,⊕,⊗)` 的函子（定义 387 的三算子保持复合）。⇒ 复合系统的解释可由模块解释在 `O(|V_M|·|S|)` 内合成，无需对全系统重跑反事实。系：**可解释性享有与模块化相同的复利——解释成本 O(模块) 而非 O(系统)，这是 C4 与 C3 的耦合。**

**引理 40（保真-稳定不可兼得）** 若决策函数在有效域内存在测度为正的跳变面（阈值/否决），则任何局部 Lipschitz 常数为 `L_x` 的归因，其保真度满足 `Fid ≤ 1 − c·Δ/L_x`（`Δ` 为跳变幅度，`c` 与跳变面几何有关）。⇒ **稳定与保真存在可计算的前沿**；因此解释必须携带 `u_x`，并在 `u_x>τ_x` 时弃权，而不是假装两者都完美。系：**「解释不可解释」本身必须成为可计量状态（解释 stub），否则可解释性就是新的黑箱。**

**引理 41（新颖度-覆盖率单调）** 在加权 conformal 下，若密度比 `w≤W_max`、有效样本量 `n_eff`，则目标域覆盖率
`P(Y∈C(X)) ≥ 1 − α − δ(W_1(P_src,P_tgt)) − O(√(log(1/β)/n_eff))`。
⇒ 覆盖率退化**被漂移 δ 显式上界化**，而不是静默失败。系：**零样本的代价第一次被写成可测的量。**

**引理 42（迁移风险膨胀）** 对 `L_π`-Lipschitz 策略与有界损失 B，`R_tgt(π) ≤ R_src(π) + L_π·δ + B√(log(1/β)/(2n_eff))`（定义 390）。⇒ 迁移证书有效时，把 `ε_T` 加入 `λ` 即得保守安全界；无效时唯一合法动作是弃权。系：**「零样本」=「带价迁移」，价高到超过风险预算就自动变成弃权。**

**引理 43（粘合障碍 ⇔ 最小冲突核）** 在有限覆盖 `𝒰` 上，`[ω]≠0` ⇔ 覆盖图中存在矛盾环；取最短矛盾环 `C*`，则 `C*` 是粘合约束的 MCS，且 `C*` 可由图上 BFS/并查集在 `O(|E|·|V|)` 内求出。⇒ **「不能泛化」总有一个人可读、机器可验的最小解释。** 系：**可解释性与零样本共用同一个计算对象（粘合障碍）。**

**定理 30（CLEAR 严格包含 MODGAUGE）** 取 `x_bud=0`（平凡解释）、`ν≡0`（恒域内）、`TC=identity`、`𝒰={𝕊}` 单拼片，则 XNG 退化为 R73 的五不变式门，ZSO 退化为 R73 主闭环。由引理 39 与定义 395，退化条件下逐指令等于 R73，再退化等于 R72/R71/R68。**安全单调不减，解释/迁移仅在契约满足时获益。**

**定理 31（联合门安全性：无静默错误）** 若 `Accept(d)`，则概率 ≥1−α 下 `risk(d) ≤ ε + ε_T`（域内 `ε_T=0`）；若 `¬Accept(d)`，则系统输出 `π_abs` 且附带 `|MCS|≤s_max` 的解释。⇒ **每一个决策要么「被认证且被解释」，要么「被显式弃权且被解释」；不存在「被认证、被解释、却是错的」静默路径**（在 A114–A116 下：迁移界成立、保真度量校准、覆盖无空洞）。

**定理 32（解释-泛化对偶）** 在有限契约层上，对输入 x：存在 x 的全局解释（局部解释可沿覆盖粘合）⇔ 粘合障碍 `[ω]=0` ⇔ 迁移证书可构造。⇒ **可解释性与零样本泛化不是两个模块，而是同一上同调条件的两个投影。** 系：这给出 C6 的可证伪形式——**用粘合障碍预测迁移失败，其 AUROC 应与解释充分性对失败的 AUROC 同向且接近。**

## 6. 本轮最大风险

**一句话**：CLEAR 的安全性最终取决于「解释计量」与「迁移界」这两个**自身也要校准的仪器**——若新颖度检测器在真正的分布漂移下沉默、且结构覆盖因契约过宽而给出虚假覆盖，那么系统会在**域外**照样产出高保真、高稳定、校准良好的解释，把「自信地组合出一个错误的世界」升级为「**自信地、可解释地、逐条引用证据地组合出一个错误的世界**」：失败不但没被解释暴露，反而被解释**背书**了——可解释性成了错误的担保人，而不是照妖镜。

次级风险与缓解：
1. **解释的保真-稳定前沿被误用**（引理 40）→ 预注册 `u_x` 阈值 + 解释 stub 率作为一级指标；禁止只报 Fid 不报 Stab。
2. **MSE 的 NP-hard 与近似间隙** → 限定 `s_max≤6` + 间隙证书 + 结构化 SAT；近似解必须标注 gap。
3. **密度比/迁移界在真实高维下不稳定** → 用契约维度（低维语义坐标）估 δ；`n_eff` 与 `W_max` 双门限；界过松时自动降级为弃权。
4. **结构覆盖被「宽契约」虚化** → 契约覆盖必须可审计（`∪ D_i` 的样本外质量）；覆盖声明本身纳入 SEAL-Z。
5. **解释的「合理性」与「真实性」混淆** → 因果归因（定义 398）+ 反事实检验；人类可读性单独作为附属指标，不作安全依据。
6. **联合门导致过度弃权（系统瘫痪）** → 弃权率预算 + 主动取证（PVOP/ERVOI）优先于弃权；把「取证失败」与「不可解释」区分。
7. **对偶定理（定理 32）只在有限离散覆盖上成立** → 连续域用离散化误差项 `η` 显式记入证书；E410 专测该误差。
8. **MBench-XZ 过拟合** → SEAL-X/SEAL-Z 密封 + 预注册 + 三方复现（E415）；C4–C6 只认预注册指标。

## 2. 形式化定义（要点版）

**定义 383（总览与六不变式）** 契约完整性 / 组合单调性 / 反作用通道完备（继承 R73）+ **解释完备性**（无归因不得接受）+ **适用性认证**（域内证书或迁移证书，皆无即弃权）+ **主张绑定扩展与严格退化链**（解释/新颖/迁移失效各有 stub）。

**定义 384（XEC）** 见符号表。核心：**归因是契约字段**——「我的决策依赖哪些证据、依赖到什么程度」成为模块必须声明的接口信息，而不是事后外挂。

**定义 385（AC 与可证伪语义）** `AC` 为真 ⇔ 充分性（S 外坐标在 I 内任意扰动决策不变）∧ 必要性（仅改 S 内坐标存在使决策改变的扰动）∧ 追溯可复算。真值可由 SEAL-X 受控扰动估计 ⇒ **解释是可证伪的证据**。

**定义 386（MSE/MCS）** MSE 回答「为什么成立」，MCS 回答「为什么被拒/为何弃权」；充分性**只在契约有效域内要求**（domain-relative），这既是可计算性的来源，也是与一般充分性解释的关键区别。精确 MSE NP-hard，限 `s_max≤6` + 间隙证书。

**定义 387（XCA）** 归因是函子。SER：`J_B^A·Φ(A)+Φ(B)+κ`；PAR：可靠性加权 + **跨模态残差单独归因**；VETO：`MCS`；因果边（吸收 ECG）只在 `do`-可辨识祖先上非零。效率：`ΣΦ_i = Δd + O(κ)`；零贡献者：未用证据归因 0。

**定义 388（XMM）** `Fid/Stab/Cov_x/Cal → u_x`；`u_x>τ_x` ⇒ **解释 stub**。**保真-稳定前沿**（引理 40）：决策有跳变面时二者不可兼得，故 `u_x` 必报。

**定义 389（ANM）** 三通道新颖度 + 三区间；**结构覆盖下限**：`x∉∪D_i ⇒ R_out`，与检测器无关，fail-closed。

**定义 390（TCC）** 迁移证书有效 ⇔ 漂移、有效样本量、密度比上界三条件同时满足；有效则以 `ε_T` 膨胀风险预算执行，无效即弃权。**零样本 = 带价迁移，价超预算即弃权。**

**定义 391（STEM）** 有限覆盖 + 重叠一致性 + 障碍上链 `[ω]∈Ȟ¹`；`[ω]=0` ⇔ 全局证书可粘合 ⇔ 迁移证书可构造；最小矛盾环 `C*` 即不可泛化的解释。

**定义 392（ZSO）** 三区间操作：域内 → 认证策略；已证迁移 → 策略 + `λ+=ε_T`；契约外 → 保守策略 + `MCS(障碍)`。零样本以「覆盖 + 弃权质量」度量，而非原始成功率。

**定义 393（XNG）** 非补偿联合门；任一为假即带解释弃权；允许「保守解释」（弃权本身有 MCS）。

**定义 394（XPB）** C4←(XEC,XCA,XMM,MSE)←MB4←AB4←(Fid,Stab,Cov_x,Expl-ECE,审计时间,否决定位)；C5←(ANM,TCC,ZSO)←MB5←AB5←(界紧致度,弃权精确/召回,膨胀误差,ZS-Safety)；C6←(STEM,XNG)←MB4∪MB5←AB6←(障碍 AUROC,对偶一致性)。非绑定=工程附件。

**定义 395（分层失效 E-IVG†）** 解释失效 ⇒ XMM stub ⇒ 升级/弃权（绝不静默继续）；新颖失效 ⇒ 结构覆盖兜底判 `R_out`；迁移失效 ⇒ 弃权；R73 模块失效 ⇒ R73 stub；REG ⇒ R68。安全侧单调不减。

**定义 396（MBench-XZ）** MB4 解释（受控反事实矩阵 + 3 下游任务 + 人类审计计时）；MB5 迁移（新材质×新类别×新任务文法×新本体 + 对抗描述子漂移）；各 `≤3h` 单卡、预注册、SEAL-X/SEAL-Z。

**定义 397（XCost）** 精确 MSE NP-hard；`s_max≤6` 用 SAT/ILP 并输出间隙证书；组合解释 `O(|V_M|·|S|)`。

**定义 398（因果归因 CA）** 归因只在 `do`-可辨识因果祖先上非零；对「观测到但决策未用」的混杂子保持不变。针对 faithfulness vs plausibility 缺口：**解释必须在干预下成立，而非在观测分布上相关。**

# IP-303 XEC：可解释证据契约
@dataclass(frozen=True)
class ExplanatoryContract:
    ec: EvidenceContract                        # R73 证据契约
    alpha: Callable[[Evidence], Attr]           # 归因算子
    x_bud_us: float                             # 解释预算（生成+验证）
    D_x: Predicate                              # 解释有效域（可 ⊂ D）
    x_merge: Callable[[Attr, Attr], Attr]       # 归因合并
    novelty: Callable[[Evidence], NoveltyVec]   # 契约维度上的新颖度
    x_seal: str                                 # SEAL-X 引用

# IP-304 XCA：解释组合代数
def compose_attr(pa, pb, op, ec_a, ec_b):
    if op == 'SER':
        J = jacobian(pb, ec_b, pa)
        kappa = interaction_bound(pa, pb)                  # |κ| ≤ I_{AB}
        return Attr(S=pa.S | pb.S, I=pa.I & pb.I,
                    vec=J @ pa.vec + pb.vec, kappa=kappa,
                    h=hash_merge(pa.h, pb.h))
    if op == 'PAR':
        r = cross_modal_residual(pa, pb)
        w = reliability_weights(pa, pb)
        return Attr(S=pa.S | pb.S,
                    vec=w[0]*pa.vec + w[1]*pb.vec,
                    extra=[AttrItem('AUDIT_RESIDUAL', mass=r)],   # 分歧被归因
                    h=hash_merge(pa.h, pb.h))
    if op == 'VETO':
        if pa.veto or pb.veto:
            return Attr(kind='MCS', S=min_conflict_core(pa, pb),
                        h=hash_merge(pa.h, pb.h))
        return Attr(S=pa.S & pb.S, vec=min_norm(pa.vec, pb.vec))

# IP-305 XMM：解释计量
class ExplanationMetrology:
    def measure(self, e, d, ac):
        fid = self.seal_x.fidelity(ac, e, d)               # 反事实符号一致率
        stab = self.seal_x.local_lipschitz(self.alpha, e)  # 归因 Lipschitz

        return XEvidence(ac=ac, u_x=u_x, valid=(u_x <= TAU_X))

# IP-306 ANM：适用域与新颖度
def applicability(x, cover):
    if not cover.covers(x):                                # 结构兜底：不可被骗
        return Regime.R_OUT, NoveltyVec(structural_gap=True)
    n = combine_novelty(density_ratio(x),
                        conformal_nonconformity(x),
                        evidence_novelty(x))
    regime = R_IN if n <= TAU_IN else (R_SHIFT if n <= TAU_OUT else R_OUT)

# IP-307 TCC：迁移证书
def transfer_certificate(src, tgt_desc):
    delta = wasserstein1(src.desc, tgt_desc)
    w = density_ratio_estimate(src, tgt_desc)
    n_eff = len(src) / mean_square(w)
    eps_T = L_PI * delta + B * sqrt(log(1/BETA) / (2 * max(n_eff, 1)))
    valid = (delta + DELTA_CONF <= DELTA_MAX) and (n_eff >= N_MIN) \
            and (max(w) <= W_CAP)
    return TransferCert(delta, n_eff, eps_T, valid)

def sheaf_glue(cover, sections, audit):
    G = build_overlap_graph(cover)
    omega = {(i, j): (0 if audit.conformal_covers(cross_residual(sections[i], sections[j]))
                      else audit.failure_label(i, j))
             for (i, j) in G.edges}
    if is_coboundary(omega, G):                            # [ω] = 0

    return GlueResult(ok=False, obstruction=omega,
                      explanation=min_contradictory_cycle(G, omega))

def zso_decide(d, safety_cert, x_ev, regime, tc):

    if regime is Regime.R_IN:      applicable, lam_add = safety_cert.valid, 0.0

    else:                          applicable, lam_add = False, 0.0
    if safety_cert.valid and explainable and applicable:

    return Decision.abstain(explain=min_conflict_core(x_ev.ac, safety_cert))

def CLEAR_round(M, obs, audio, tac_frame, depth_img):

## 4. 推导

**引理 38（归因效率与零贡献者）** 各模块 `α` 满足效率与零贡献者 ⇒ SER/PAR 组合满足效率，误差仅来自交互项 `κ`，`|κ| ≤ Σ_{i<j} I_ij`。系：**多出来的贡献总能记账到某个交互项，不会「解释不了」。**

**引理 39（解释函子性与组合成本）** `Φ` 是 MReg→`(V_attr,⊕,⊗)` 的函子 ⇒ 复合系统解释由模块解释在 `O(|V_M|·|S|)` 内合成。系：**可解释性享有模块化复利：解释成本 O(模块) 而非 O(系统)** —— C4 与 C3 的结构耦合。

**引理 40（保真-稳定不可兼得）** 决策在有效域内有测度为正的跳变面时，局部 Lipschitz 常数为 `L_x` 的归因满足 `Fid ≤ 1 − c·Δ/L_x`。⇒ **存在可计算前沿**，故解释必带 `u_x`，超阈即弃权。系：**「解释不可解释」必须成为可计量状态（解释 stub），否则可解释性就是新黑箱。**

**引理 41（新颖度-覆盖率单调）** 加权 conformal 下，`w≤W_max`、`n_eff` 时，目标域覆盖率 `≥ 1−α−δ(W_1)−O(√(log(1/β)/n_eff))`。⇒ 覆盖率退化被漂移显式上界化，而非静默失败。

**引理 42（迁移风险膨胀）** `R_tgt ≤ R_src + L_π·δ + B√(log(1/β)/(2n_eff))`。⇒ 证书有效则以 `ε_T` 膨胀预算；无效则唯一合法动作是弃权。系：**零样本 = 带价迁移。**

**引理 43（障碍 ⇔ 最小冲突核）** 有限覆盖上 `[ω]≠0` ⇔ 矛盾环存在；最短矛盾环 `C*` 为粘合约束的 MCS，`O(|E|·|V|)` 可求。⇒ **「不能泛化」总有可读、可验的最小解释。**

**定理 30（CLEAR 严格包含 MODGAUGE）** `x_bud=0`、`ν≡0`、`TC=identity`、单拼片时，XNG 退化为 R73 五不变式门。由引理 39 与定义 395 逐指令等价 ⇒ 再退化为 R72/R71/R68。**安全单调不减。**

**定理 31（联合门安全性：无静默错误）** `Accept(d)` ⇒ `risk(d) ≤ ε+ε_T`（域内 `ε_T=0`，概率 ≥1−α）；`¬Accept` ⇒ 输出 `π_abs` 且附 `|MCS|≤s_max` 解释。⇒ **每个决策要么「被认证且被解释」，要么「被显式弃权且被解释」；不存在「被认证、被解释、却是错的」静默路径**（A114–A116：迁移界成立、保真度量校准、覆盖无空洞）。

**定理 32（解释-泛化对偶）** 有限契约层上，输入 x 存在全局解释（局部解释可粘合）⇔ `[ω]=0` ⇔ 迁移证书可构造。⇒ **可解释性与零样本不是两个模块，而是同一上同调条件的两个投影。** 系：C6 的可证伪形式——用粘合障碍预测迁移失败的 AUROC 应与解释充分性对失败的 AUROC 同向且接近（E410）。

**一个最小数值示例（迁移界，展示「带价」而非「保证」）**：设 `R_src=0.02`、`L_π=1.5`、`δ=0.01`、`B=1`、`n_eff=400`、`β=0.05`，则
`R_tgt ≤ 0.02 + 1.5×0.01 + 1×√(ln20/800) = 0.02 + 0.015 + 0.061 ≈ 0.096`。
**读法**：界成立但偏松——这正是 E405 要测的「紧致度」；若 `n_eff` 增大到 10⁴，末项降到 ≈0.012，界收紧到 ≈0.047。**方案不承诺零样本「好用」，只承诺每一步迁移的风险被标价、超出预算即自动弃权。**

## 8. 本轮最大风险

**一句话**：CLEAR 的安全性最终取决于「解释计量」与「迁移界」这两个**自身也要校准的仪器**——若新颖度检测器在真正的分布漂移下沉默、且结构覆盖因契约过宽而给出虚假覆盖，系统就会在**域外**照样产出高保真、高稳定、校准良好的解释，把「自信地组合出一个错误的世界」升级为「**自信地、可解释地、逐条引用证据地组合出一个错误的世界**」——可解释性从照妖镜退化为错误的担保人。

次级风险与缓解：
1. **保真-稳定前沿被误用**（引理 40）→ 预注册 `u_x` 阈值 + 解释 stub 率作为一级指标；禁止只报 Fid 不报 Stab。
2. **MSE 的 NP-hard 与近似间隙** → `s_max≤6` + 间隙证书 + 结构化 SAT；近似解必须标 gap。
3. **密度比/迁移界在高维不稳** → 在契约语义坐标（低维）估 δ；`n_eff` 与 `W_max` 双门限；界过松自动降级弃权。
4. **结构覆盖被宽契约虚化** → 覆盖声明本身纳入 SEAL-Z 审计；`∪D_i` 的样本外质量作为一级指标。
5. **「合理性」与「真实性」混淆** → 因果归因（定义 398）+ 反事实检验；人类可读性单独作为附属指标，不作安全依据。
6. **联合门导致过度弃权** → 弃权率预算 + 主动取证（PVOP/ERVOI）优先于弃权；区分「取证失败」与「不可解释」。
7. **对偶定理（定理 32）只在有限离散覆盖成立** → 连续域离散化误差 η 显式记入证书；E410 专测该误差。
8. **MBench-XZ 过拟合** → SEAL-X/SEAL-Z 密封 + 预注册 + 三方复现（E415）；C4–C6 只认预注册指标。
