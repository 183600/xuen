# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「迭代验证」×「模仿学习」）

> R69 给闭环装上了一张嘴：系统终于会**问**（看/问/触），用 value-of-information 把「下一步该选哪个动作模态」的歧义当作可以花预算消解的题。但 R69 把两件事当成了天经地义：
> 1. **策略本身是称职的。** 它只问「这个世界/这一步该选什么」，从不问「**我真的会做吗**」。而模仿学习告诉我们：策略的全部能力都是从示范里借来的；一旦离开示范支撑，它可能**自信地错**（协变量偏移的复合误差、把虚假相关当因果的混淆），而 R69 的流似然只测「像不像我学过的」，不测「对不对」——这是一个循环论证。
> 2. **一次验证通过就等于永远通过。** R69 用 ECE、AUC、证据纪律做一次性门控；但真正的证书要在**被反复攻击、按失败重选测试、边测边停**的过程中仍然成立。朴素的「再验一遍看看」会让 Type-I 错误随验证次数膨胀，让策略学会**通过测试**而不是**学会做事**（Goodhart）。
>
> 本轮两个灵感正好补上这两处：
> - **模仿学习**把「能力」变成一个**可被示范修正**的量，并暴露两类特有失败：支撑外的复合误差、以及把虚假相关当因果的混淆；纠正示范（"show me, don't tell me"）是比口头回答信息量大得多的新信息动作。
> - **迭代验证**把「证书」变成一个**对可选停时与自适应选样仍然有效**的统计对象（e-process / anytime-valid confidence sequence），并强制区分「测试」与「训练」两笔预算——否则验证会退化为对测试集的过拟合。
>
> 核心命题：**R69 的不确定性只有两档（噪声 aleatoric、模态歧义 epistemic）；R70 加第三档——能力不确定性 U_comp（我在这个状态到底会不会，以及我凭什么相信我会）。U_ale 收紧，U_epi 去问，U_comp 去「迭代验证 + 要一段纠正示范」；而证书本身必须 anytime-valid，且验证不得被训练污染。** 命名 **VALID-RAS**（Validation-Aware Learning from Imitation & Demonstration；可验证模仿—迭代检验闭环）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我凭什么相信我真的会做这件事——而且这个『相信』本身经得起反复检验吗**」——不确定性不只是刹车、提问，也可以是一次「**你示范给我看，然后我们再验一遍**」。

## 0. 直觉与动机

**灵感 1（模仿学习 → 能力是借来的，不是自证的）**
直觉：R69 的策略是从数据里学出来的，而数据是示范。模仿学习有一个残酷的结论：在示范没覆盖到的地方，策略的误差会**复合**（小偏差把状态推离示范分布，状态偏离又放大偏差，最坏 O(T²)）；更隐蔽的是**因果混淆**——策略可能抓住示范里与动作虚假相关的背景/姿态/时序线索，在训练分布上似然很高，一旦干预掉那条虚假线索就立刻失效。所以「高似然」只说明「像示范」，不说明「会做事」。R70 的第一刀就是把这两件事切开：**支撑（我见过）≠ 能力（我能做成）**。

**灵感 2（迭代验证 → 一次通过的证书不是证书）**
直觉：R69 的证书是一次性盖章。但真正的验证是**迭代**的：先按当前最可疑处出题，测失败，再按失败重出题，边测边决定停不停。问题在于，统计上「反复偷看结果再决定要不要继续测」会系统性地高估置信度：同一零假设做 m 次 α 检验，只要有一次通过就宣布有能力，族错误率约 1−(1−α)^m；若还按失败重选测试，选择偏差会让膨胀更严重。R70 的第二刀是：证书必须是 **anytime-valid 的 e-process**——允许任意停时、允许用历史结果选下一个测试，而 Type-I 仍被 Ville 不等式压住。这把「迭代验证」从口号变成可证明的对象。

**灵感 3（第三类不确定性 → R69 的二分是不完备的）**
直觉：R68 的 U 只有「噪声」，R69 拆成「噪声 + 模态歧义」。但真实的失败还有第三种：「这一步我连**怎么做**都不知道，或者我以为会其实不会」。它不是噪声（不是随机抖动）、也不是模态歧义（不是两个都合理的选项，而是一个都不会）。把这第三种塞进 R69 的任何一档都会出错：塞进 aleatoric 会永远过度保守、永不学习；塞进 epistemic 会让系统去「问一个怎么做的答案」，而控制任务最有效的监督不是答案，是**示范**。所以 R70 做严格三分：U_ale → 收紧；U_epi → 看/问/触；U_comp → 验证 + 要示范。

**灵感 4（似然 ≠ 能力 → 正面回应 R69 的循环论证）**
直觉：R69 最漂亮的补丁是 FMA：用动作在策略密度下的似然做「标定不可吸收」的第二意见，正面回应 R68 缓变故障被吸收的风险。这个用法是对的——它测的是「行为相对策略是否异常」，能抓观测偏置。但 R69 随后把 FMA 的读数**顺手当成了能力证据**，这就是范畴错误：策略密度由策略自己定义，用自己的密度证明自己称职，是循环。R70 保留 FMA 作为**新颖性/OOD 触发器**，但明确规定：任何能力主张必须由**外部**验证结果（成功/失败、干预后行为、人的示范）签发 anytime-valid 证书。**FMA 负责喊「这里不对劲」，CCT 负责判「这里到底会不会」。**

**灵感 5（双刃剑 → 验证会被被测者喂养，示范会被示范者投毒）**
直觉：这是本轮最需要正视的黑暗面。迭代验证一旦和训练共用数据/梯度，就会被 Goodhart：验证器出的题会逐渐变成策略的「训练集」，证书漂亮但语义已空。另一边，纠正示范是比回答更贵、信息更多、也**更容易投毒**的通道：示范者可能无能、前后不一致、甚至故意教错；单段示范若被直接采纳，等于把执行器交给一个未经验证的人。且系统会陷入**验证死锁**——没有证书不敢动，不动就拿不到证书。所以本轮必须同时交付：信息屏障与验证泄漏记账（GVG）、anchor 集与生成器轮换、示范可信度与跨示范者一致（DCV）、影子验证与两把钥匙晋级（SVP）、以及「证书失效/预算耗尽 → 安全停机或交还」的单调退避。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（VALID-RAS 总览）** VALID-RAS = (SCM, CCT, TIG, DQR, SVP, GVG, RAS-WM†)。四条不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **能力主张必须有证书**：任何「我能在此执行」的主张必须由 CCT 的 anytime-valid 证书支撑；似然、置信度、模型自评、历史成功率的一次点估计，一律不算；
(iii) **示范不等于授权**：人的纠正示范只能进入延迟缓冲，或经 SVP 两把钥匙晋级为局部补丁；它绝不直接驱动执行器；
(iv) **验证-训练预算分离**：用于发证的测试不得无偿进入训练；任何复用都要经 GVG 记账，并从证书效力中扣除。

**定义 311（示范记忆与支撑图 SCM）** 示范集 𝒟 = {(o_i, ξ_i)}；支撑图 S(x) = 到示范流形的距离或密度（flow 密度 / kNN），支撑覆盖率 Cov(R) = P_{x~R}[S(x) ≥ s_0]。SCM 同时维护两张图：**支撑图**（我见过哪些状态）与**能力图**（我在哪些区域被证成）。二者不重合；R69 隐含地把「像示范」当成了「会做」。

**定义 312（能力与能力不确定性）** 在状态 x 执行策略 π 的**能力** C(x) = P(success | π, x)。**能力不确定性** U_comp(R) = 在区域 R 上对 C 的后验不可信宽度（或等价地：证书未覆盖的测度）。关键区分：似然 ℓ_π(x) = −log p_π(ξ_obs|o) 高 ⇏ C(x) 高；见引理 19。

**定义 313（模仿间隙分解）** 总误差可分解为 E_total ≤ E_approx + E_covshift + E_confusion + E_leak：近似误差（模型容量）、协变量偏移/复合误差（离开示范支撑）、因果混淆（虚假相关）、验证泄漏（测试被训练吃掉）。四类各有独立检测器：E_covshift 用支撑图 + OOD，E_confusion 用干预探针（定义 323），E_leak 用 GVG（定义 321）。

**定义 314（证伪测试生成器 TIG）** 测试分布 q_t 由「最可疑处」生成：q_t = argmax_q E_{x~q}[ H(C(x)) − E_{y}[H(C(x)|y)] ]，即在当前能力后验下期望信息增益最大的状态。TIG 受**两把钥匙**约束：不得读取被测策略的训练梯度/参数更新（信息屏障），不得使用 anchor 集 A 做生成；生成器按周期 T_r 轮换，防止被测策略对其过拟合。

**定义 315（anytime-valid 能力证书 CCT）** 对区域 R、目标能力 c、显著性 α，用可预测下注 λ_s ∈ [0, 1/c] 构造 e-process
E_t(R) = ∏_{s≤t} (1 + λ_s (X_s − c)), X_s ∈ {0,1} 为第 s 次验证是否成功。
在 H₀: C(R) ≤ c 下 E_t 为非负上鞅，Ville 不等式给出
P( sup_t E_t(R) ≥ 1/α ) ≤ α。
当任意（可基于历史自适应的）停时 τ 满足 E_τ(R) ≥ 1/α，签发 **Cert(R, c, α)**。这是「迭代验证」的严格兑现：可以边测边停、可以按失败选下一次测试，Type-I 仍 ≤ α。

**定义 316（区域证书的组合与覆盖）** 状态空间按 SCM 的支撑/混淆风险划分为单元 {R_j}。e-process 只对**实际被采样的分布**有效；若 TIG 把测试推向某个易失败子区域，证书只覆盖该子区域，不能代表整个 R。因此：要么逐单元发证并以 α-spending（Bonferroni 或 e-value merging）分配总显著性，要么用重要性加权把单元证书提升为父区域证书。**覆盖图 CovCert 是证书的一部分**；父区域证书不得无偿下放到未认证子区域。

**定义 317（纠正示范查询 DQR）** 增广动作在 R69 的 𝒜_info 上再加 𝒢_demo = {g_demo, g_critique, g_replay}：请求一段短示范、一次标量批评、或请人复核某个具体状态。VoI 扩展为两项：
VoI(g) = VoI_mode(g) + β·VoI_comp(g) − c(g)，其中 VoI_comp(g) = E[H(C(R)|o)] − E_{y_g}[H(C(R)|o, y_g)] + γ·E[ΔC_after_patch]。
选择 g* = argmax_g VoI(g)，s.t. risk(g) ≤ ε_int 且预算未超；若 max VoI ≤ 0：不查询、走定义 322 的退避。R69 的 g_ask 是 g_demo 的退化（返回标签而非轨迹），因此 𝒜_info 被严格包含。

**定义 318（示范可信度 DCV）** 每次示范带示范者标识与上下文；维护示范者能力先验 D_c 与跨示范者一致性 κ。单段示范不得定案（继承 R69 定义 293-iii 的证据纪律）：需不同示范者/不同会话的 k 段示范在关键决策点上一致，或经 g_critique 交叉确认；否则只降低 U_comp 的方差、不签发证书。

**定义 319（延迟缓冲与局部补丁）** 示范入延迟缓冲 B（实时环只写、不训练）。可立即使用的只有**局部检索补丁**
π_patch(x) = Σ_i softmax(−d(x,x_i)/τ)·ξ_i，
且仅在已认证区域内、且只作为候选动作，仍须过 C-RAS-WM 认证。补丁的适用域由支撑距离与混淆探针共同界定；越域即失效。

**定义 320（影子验证与两把钥匙晋级 SVP）** 补丁先在影子模式对真实状态做反事实比较（只记录、不执行）。晋级为可执行/可合并策略需两个正交条件同时成立：(a) C-RAS-WM 对补丁动作的安全认证；(b) 在 anchor 集与新鲜留出测试上通过 CCT（定义 315）。任一不满足，补丁永不触达执行器；两者都满足才写入下一轮离线训练，仍不在实时环内更新。

**定义 321（验证泄漏与 Goodhart 护栏 GVG）** 维护训练事件与测试结果之间的互信息估计 I(train; test) 与泄漏预算 L_max。anchor 集 A 永不参与训练、永不参与 TIG 生成、只用于最终发证；anchor 有半衰期，过期需由新鲜留出测试续期。若 I(train; test) > L_max 或 anchor 过期比例超阈值，则**吊销**相关证书并回退到未认证。核心纪律：**验证者不得被被测者喂养**。

**定义 322（能力感知风险缩放与三档退避）**
- **已认证**（Cert(R, c, α) 有效）：λ = λ_floor(U_ale)，并允许覆盖 R69 对 FMA 高似然异常的过度保守（能力 bonus）；安全包络不变。
- **未认证但可改善**（VoI_comp > c(g) 且预算未耗尽）：执行最小风险探针或短暂保持，同时请求示范；λ = max(λ_floor(U_ale + U_epi + ρ·U_comp), λ_probe)。
- **未认证且不可改善**（VoI_comp ≤ 成本 / 预算耗尽 / GVG 吊销 / 存在未处理因果混淆）：安全停机或交还人类；λ = λ_max，k = k_min。
R69 是「所有状态已认证且不请求示范」的边界（U_comp = 0）；再关闭交互即 R68。安全侧单调不弱。

**定义 323（因果混淆干预探针 CIP）** 对疑似被策略当作捷径的变量 z（背景、姿态、时间上下文、语言模板），做干预 do(z) 并比较 π(·|do(z)) 与 π(·)。若在任务不变的干预下行为显著改变，标记 causal_confusion(x)；该区域立即降级为未认证，并成为 TIG 的优先出题区。CIP 是「模仿学习诊断」而非「世界模型诊断」，补 R69 只诊断观测的盲区。

**定义 324（证书 J_VALID）** J_VALID = (J_FLUID, cert_coverage, cert_alpha, e_value_min, support_coverage, imitation_gap, demo_voi_ratio, leakage_used, patch_promotion_hash, valid_ver)。Valid ⇔ Valid(J_FLUID) ∧ cert_coverage ≥ τ_cov ∧ leakage_used ≤ L_max ∧ 无未处理的 causal_confusion ∧ 所有在用补丁 promotion_hash 对得上。

**定义 325（验证器的元验证 VQAuditor-V）** 审计审计者：CCT 的实际覆盖率与名义 α 是否相符、TIG 的测试多样性是否退化（是否总出同一类题）、anchor 是否过期、DCV 是否被单一示范者主导。元验证递归深度硬限 d_max（默认 2），残差风险显式记入账本；不允许无限自证——否则系统会把全部预算花在「证明自己能证明自己」上。

**定义 326（非平稳重认证 RCS）** 世界漂移使证书过期。按漂移率、支撑覆盖率变化与 anchor 半衰期调度重认证：重认证频率 ∝ √(漂移率)（最小化「验证成本 + 过期风险」的经典平方根律）；过期证书自动降级为未认证，继承 R69 定义 310-iii 的锚点过期思想。

```python
# IP-264 SCM：支撑图 vs 能力图（两件事不再混同）
class SupportCompetenceMap:
    def support(self, x):      return self.demo_density(x)      # 我见过吗
    def competence(self, R):   return self.cct.query(R)         # 我被证成了吗
    def decompose(self, modes, z):
        return U_ale, U_epi, self.u_comp(modes, z)              # 第三类不确定性

# IP-265 CCT：anytime-valid e-process 能力证书（允许边测边停）
def cct_update(state, R, success, c, alpha):
    lam = state.predictable_bet(R)                 # 只依赖历史，0 <= lam <= 1/c
    state.E[R] *= (1.0 + lam * (success - c))      # 非负鞅
    if state.E[R] >= 1.0 / alpha:                  # Ville：任意停时有效
        state.issue_cert(R, c, alpha, e_value=state.E[R])
    return state

# IP-266 TIG：证伪驱动出题（信息屏障 + anchor 隔离）
def generate_tests(policy, scm, barrier, anchors):
    assert barrier.cannot_read(policy.grads)       # 第一把钥匙
    assert not barrier.touches(anchors)            # anchor 永不参与出题
    cand = scm.high_ucomp_states()                 # 最可疑处
    return argmax(cand, key=lambda x: expected_info(x))

# IP-267 DQR：把「问」升级为「要一段示范」
def choose_query(modes, comp, budget):
    best = None
    for g in demo_candidates(comp):                # demo / critique / replay
        if not budget.allow(g) or not c_ras_wm.certify_info(g): continue
        voi = mode_voi(modes, g) + BETA * comp_voi(comp, g) - cost(g)
        if best is None or voi > best.voi: best = (g, voi)
    return best if best and best.voi > 0 else None # 无利可图 -> 退避

# IP-268 SVP：影子验证 + 两把钥匙晋级（不满足绝不触达执行器）
def promote(patch, policy, anchors, alpha):
    if not c_ras_wm.certify_patch(patch): return False           # 钥匙 a
    shadow = shadow_compare(patch, policy)                       # 只记录
    return shadow.safe and cct_test(patch, anchors, c, alpha).valid  # 钥匙 b

# IP-269 GVG：验证泄漏记账（超预算即吊销）
def account(train_events, test_events, L_max):
    L = estimate_mutual_information(train_events, test_events)
    if L > L_max: revoke_certificates()
    return L

# IP-270 主闭环（继承 R69，仅在不确定性处置处插入能力层）
def VALID_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    modes = M.fmp.sample(o, K)
    U_ale, U_epi, U_comp = M.scm.decompose(modes, z)
    # 1) 能力证书：先问「我会不会」，再问「选哪个」
    cert = M.cct.query_region(o)
    if not cert.valid and M.scm.support(o) >= S0:       # 见过，但没证成
        g = M.dqr.choose_query(modes, cert, M.budget)
        if g is not None:
            traj = M.dqr.execute(g)                     # 人示范一段轨迹
            M.buf.add(traj)
            patch = M.svp.make_patch(traj)
            M.svp.promote(patch, M.fmp, M.anchors, ALPHA)   # 不在实时环训练
            cert = M.cct.query_region(o)
    # 2) 三档风险缩放
    if cert.valid:
        lam = max(M.efs.risk_scale(...), lam_floor(U_ale))       # 能力 bonus
    elif M.scm.support(o) >= S0 and M.budget.has(M.dqr):
        lam = max(M.efs.risk_scale(...),
                  lam_floor(U_ale + U_epi + RHO * U_comp), LAM_PROBE)
    else:
        lam = LAM_MAX                                        # 停机/交还
    # 3) 安全前缀 + 模态选择
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    if lam == LAM_MAX: k = K_MIN
    mode = select_mode(modes, U_epi, lam, cert)
    # 4) 因果混淆探针 + 审计/记账
    if M.cip.suspect(o): M.cct.demote(region_of(o))
    M.vqa_v.submit_async(cert, U_comp, M.gvg.leakage)
    return k, lam, mode, (U_ale, U_epi, U_comp, cert)
```

## 3. 推导

**引理 19（似然—能力分离）** 存在策略 π̂ 与状态 x，使 −log p_π̂(ξ|o) 很低（高似然）而 C(x) 很低。构造：示范分布中某条与任务无关的线索 z（背景纹理/姿态/时间上下文）与动作 a 强相关，π̂ 学到 z→a；在任务不变、仅对 z 做干预 do(z) 后，π̂ 仍高置信输出 a，但失败。形式化地，似然只约束 KL(p_demo(ξ|o) ‖ p_π̂(ξ|o))，不约束 P(success | do(·))。**系**：R69 的 FMA 是合法的「观测偏置/新颖性」探测器，但不是能力证书；把它当能力证据是范畴错误。R70 用 CCT 把「像」与「会」分开。

**引理 20（朴素重复验证的 Type-I 膨胀）** 对同一 H₀ 做 m 次独立 α 水平检验，只要一次拒绝就宣布有能力，则 FWER = 1−(1−α)^m ≈ mα；若按失败自适应重选测试，选择偏差使实际膨胀更严重。故「多验几遍」不能提高可信度，只会提高假阳性——这正是迭代验证必须配 anytime-valid 统计的原因。

**引理 21（e-process 的任意停时有效性与覆盖边界）** 在 H₀: C(R) ≤ c 下，定义 315 的 E_t 是非负上鞅，Ville 不等式给出 sup_t 的尾部控制，故对任意可选停时 τ 与任意基于历史的可预测下注 λ_s，P(E_τ ≥ 1/α) ≤ α。**但** e-process 只认证「实际被采样的分布」：若 TIG 把测试推向易失败子区域，证书只覆盖该子区域。要认证整个 R，必须逐单元发证并按 α-spending/e-value merging 组合（定义 316）；否则会得到「平均合格、关键角落不合格」的假证书。**系**：覆盖图与证书同等重要，缺一不可。

**引理 22（示范相对回答的信息优势）** 对控制任务，回答 y 只提供至多 log K bits 的模态标签；纠正示范提供一整段动作轨迹，信息量可达 H(ξ)，且直接落在策略的更新方向上。在 A99（示范者能力 ≥ 阈值、跨示范者一致性 κ ≥ κ₀）下，一段合格示范对 U_comp 的期望下降 ≥ 同成本回答的 H(ξ)/log K 倍；但成本更高，且带投毒风险（R69 引理 18 的对偶）。**系**：DQR 的 VoI 必须同时计 VoI_mode 与 VoI_comp；只算前者会低估示范、只算后者会被昂贵示范拖垮预算。

**定理 18（VALID 严格包含 FLUID 与 R68）** 分三种边界：(a) 关闭能力 bonus、所有状态已认证且不请求示范 ⇒ VALID 的每步指令与 FLUID 相同（U_comp=0）；(b) 再令 VoI ≤ 成本、无交互 ⇒ 与 R68 相同；(c) 开启能力 bonus 时，仅在证书有效事件（概率 ≥ 1 − α_total）内比 FLUID 更少保守，证书失效事件进入 λ_max 停机。故安全侧永不弱于 R69，效率侧在概率保证下获得能力 bonus。R68/R69 都是 VALID 在「不学习、不验证」边界上的退化。

**定理 19（Goodhart/验证泄漏上界）** 设训练与测试的互信息 ≤ L、anchor 新鲜度未过期、TIG 与策略间存在信息屏障。则被测策略通过「迎合测试」获得的证书语义膨胀受 exp(L) 因子约束（自适应数据分析的互信息界）；当 L ≤ L_max 且 anchor 有效时，证书对真实分布仍成立；一旦 L > L_max，证书被吊销并回退未认证。**系**：验证者的独立性（两把钥匙）不是工程细节，而是证书有效性的前提条件；「自己出题自己判卷」在本框架中不被承认为证书。

**定理 20（无未认证晋级与单调退避）** 未经 SVP 两把钥匙的补丁永远不能触达执行器；任何证书失效、GVG 吊销、CIP 报警或预算耗尽，都使 λ 单调不降地退向 λ_max（停机/交还）。结合 R68 定理 15 的换装不变式，控制连续、无突变；最坏情形是安全停机，而不是「自信地执行一个不会的动作」。

## 6. 本轮最大风险

**一句话**：VALID-RAS 把安全押在一张「能力证书」上，而证书只能来自一个**由策略自己参与选择、又会被训练反过来污染**的测试分布——一旦测试生成器与被测策略共谋（Goodhart / 验证泄漏 / anchor 过期 / TIG 退化），系统会拿到一张统计上无可挑剔、语义上却已失效的证书，于是**「被验证过的无能」比「未被验证的无能」更危险**，因为它会以最高置信度去执行一个它其实不会的动作。

**次级风险与缓解**：
1. **验证死锁**（无证书不敢动、不动拿不到证书）→ 定义 322 的最小风险探针 + 预算耗尽即安全停机/交还，禁止无证书执行；
2. **Goodhart / 验证泄漏** → GVG 泄漏预算 + anchor 隔离 + TIG 信息屏障与轮换 + 定理 19 上界，超预算即吊销；
3. **示范投毒/无能示范者** → DCV 跨示范者一致 + 单源不定案 + ℰ_demo 对抗训练（并入 R69 的 ℰ_poison）；
4. **补丁越权** → SVP 两把钥匙（安全认证 + 留出 anytime-valid 证书），未晋级补丁永不触达执行器（定理 20）；
5. **因果混淆被当能力** → CIP 干预探针 + 混淆区强制降级，E307 专门审计；
6. **元验证无限递归** → 硬限 d_max 与显式残差风险账本，宁可承认残余风险也不把预算烧在自证上。

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** VALID-RAS = (SCM, CCT, TIG, DQR, SVP, GVG, RAS-WM†)；零学习写操作继承；**能力主张必须有 anytime-valid 证书**；**示范不等于授权**；**验证-训练预算分离**。

**定义 311–312（支撑、能力与 U_comp）** 支撑图 S(x) 与能力图 C(x) 不重合；U_comp 是第三类不确定性。似然 ℓ_π 高 ⇏ C 高（引理 19）。

**定义 313（模仿间隙）** `E_total ≤ E_approx + E_covshift + E_confusion + E_leak`；四类各有检测器（支撑/OOD、CIP、GVG）。

**定义 314–316（TIG 与 CCT）** 证伪出题 `q_t = argmax E[IG(C; y)]`，信息屏障 + anchor 隔离 + 轮换；e-process `E_t = ∏(1+λ_s(X_s−c))`，Ville 保证 `P(sup_t E_t ≥ 1/α) ≤ α`。e-process 只认证实际采样分布，故须逐单元发证 + α-spending，**覆盖图是证书的一部分**。

**定义 317–318（DQR 与 DCV）** `VoI = VoI_mode + β·VoI_comp − c`；`g_ask` 是 `g_demo` 的退化；单段示范不得定案，需 k 个示范者/会话在关键决策点一致。

**定义 319–320（延迟缓冲与 SVP）** 示范入 B，实时环只写不训练；局部检索补丁仅在认证域内当候选；晋级需 **两把钥匙**（C-RAS-WM 安全认证 + 留出 anytime-valid 证书）。

**定义 321–322（GVG 与三档退避）** `I(train;test) ≤ L_max`，anchor 永不参与训练/出题，超预算吊销；已认证 → λ_floor(U_ale)（能力 bonus）；未认证可改善 → 探针 + 高 ρ·U_comp；未认证不可改善 → λ_max 停机/交还。

**定义 323–324（CIP 与 J_VALID）** 对捷径变量 do(z) 干预，行为异常即降级；J_VALID 并入覆盖、α、e_value、泄漏、补丁哈希。

**定义 325–326（元验证与重认证）** 审计审计者，硬限 d_max、残差风险记账；证书半衰期 + 重认证频率 ∝ √漂移率。

## 3. 关键算法伪代码

# IP-264 SCM：支撑 vs 能力
class SupportCompetenceMap:
    def support(self, x):    return self.demo_density(x)
    def competence(self, R): return self.cct.query(R)      # 证书，不是似然

# IP-265 CCT：anytime-valid 证书（允许边测边停）
def cct_update(state, R, success, c, alpha):
    lam = state.predictable_bet(R)                         # 0 <= lam <= 1/c
    state.E[R] *= (1.0 + lam * (success - c))
    if state.E[R] >= 1.0 / alpha:
        state.issue_cert(R, c, alpha, e_value=state.E[R])  # Ville 保证
    return state

# IP-266 TIG：证伪出题（信息屏障 + anchor 隔离）
def generate_tests(policy, scm, barrier, anchors):
    assert barrier.cannot_read(policy.grads) and not barrier.touches(anchors)
    return argmax(scm.high_ucomp_states(), key=expected_info)

# IP-267 DQR：问 -> 要示范
def choose_query(modes, comp, budget):
    best = None
    for g in demo_candidates(comp):
        if not budget.allow(g) or not c_ras_wm.certify_info(g): continue
        voi = mode_voi(modes, g) + BETA * comp_voi(comp, g) - cost(g)
        if best is None or voi > best.voi: best = (g, voi)
    return best if best and best.voi > 0 else None

# IP-268 SVP：影子 + 两把钥匙
def promote(patch, policy, anchors, alpha):
    if not c_ras_wm.certify_patch(patch): return False
    shadow = shadow_compare(patch, policy)
    return shadow.safe and cct_test(patch, anchors, c, alpha).valid

# IP-269 GVG：验证泄漏
def account(train_events, test_events, L_max):
    L = estimate_mutual_information(train_events, test_events)
    if L > L_max: revoke_certificates()
    return L

# IP-275 主闭环（继承 R69）
def VALID_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    modes = M.fmp.sample(o, K)
    U_ale, U_epi, U_comp = M.scm.decompose(modes, z)
    cert = M.cct.query_region(o)
    if not cert.valid and M.scm.support(o) >= S0:
        g = M.dqr.choose_query(modes, cert, M.budget)
        if g is not None:
            traj = M.dqr.execute(g); M.buf.add(traj)
            M.svp.promote(M.svp.make_patch(traj), M.fmp, M.anchors, ALPHA)
            cert = M.cct.query_region(o)
    if cert.valid:
        lam = max(M.efs.risk_scale(...), lam_floor(U_ale))         # 能力 bonus
    elif M.scm.support(o) >= S0 and M.budget.has(M.dqr):
        lam = max(M.efs.risk_scale(...),
                  lam_floor(U_ale + U_epi + RHO * U_comp), LAM_PROBE)
    else:
        lam = LAM_MAX                                          # 停机/交还
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    if lam == LAM_MAX: k = K_MIN
    mode = select_mode(modes, U_epi, lam, cert)
    if M.cip.suspect(o): M.cct.demote(region_of(o))
    M.vqa_v.submit_async(cert, U_comp, M.gvg.leakage)
    return k, lam, mode, (U_ale, U_epi, U_comp, cert)

## 4. 推导

**引理 19（似然—能力分离）** 存在 π̂、x 使 `−log p_π̂(ξ|o)` 低而 `C(x)` 低：示范中捷径 z 与动作 a 虚假相关，`do(z)` 后仍高置信输出 a 但失败。似然只约束 KL(p_demo‖p_π̂)，不约束 `P(success|do(·))`。系：R69 的 FMA 是新颖性/观测偏置探测器，**不是**能力证书；R70 用 CCT 把「像」与「会」分开。

**引理 20（朴素重复验证膨胀）** 对同一 H₀ 做 m 次 α 检验、任一拒绝即宣布有能力，`FWER = 1−(1−α)^m ≈ mα`；自适应重选测试更糟。故「多验几遍」只提高假阳性。

**引理 21（e-process 任意停时有效 + 覆盖边界）** H₀: C(R) ≤ c 下 `E_t` 为非负上鞅，Ville 给出 `P(sup_t E_t ≥ 1/α) ≤ α`，对任意可选停时与可预测下注成立。但 e-process 只认证实际采样分布；TIG 若把测试推向易失败子区域，证书只覆盖该子区域。要认证整个 R 须逐单元发证 + α-spending/e-value merging（定义 316）。系：**覆盖图与证书同等重要**。

**引理 22（示范相对回答的信息优势）** 回答 ≤ log K bits；纠正示范可达 H(ξ) bits 且直接落在策略更新方向。A99 下，一段合格示范对 U_comp 的期望下降 ≥ 同成本回答的 H(ξ)/log K 倍；但成本高、有投毒风险。系：DQR 必须同时计 VoI_mode 与 VoI_comp。

**定理 18（VALID 严格包含 FLUID 与 R68）** (a) 关闭能力 bonus、全认证、不请求示范 ⇒ 每步指令 = FLUID；(b) 再 VoI ≤ 成本、无交互 ⇒ = R68；(c) 开启 bonus 时仅在证书有效事件（概率 ≥ 1−α_total）内比 FLUID 少保守，失效事件进 λ_max 停机。安全侧永不弱于 R69，效率侧获能力 bonus。

**定理 19（Goodhart/泄漏上界）** 训练-测试互信息 ≤ L、anchor 未过期、TIG 有信息屏障时，迎合测试带来的证书语义膨胀受 exp(L) 约束；L ≤ L_max 且 anchor 有效则证书对真实分布成立；L > L_max 即吊销。系：验证者的独立性是证书有效性的前提，「自己出题自己判卷」不算证书。

**定理 20（无未认证晋级与单调退避）** 未经两把钥匙的补丁永不触达执行器；证书失效/GVG 吊销/CIP 报警/预算耗尽都使 λ 单调不降退向 λ_max。结合 R68 定理 15 换装不变式 ⇒ 控制连续、无突变；最坏情形是安全停机，而非自信执行不会的动作。

## 7. 本轮最大风险

**一句话**：VALID-RAS 把安全押在一张「能力证书」上，而证书只能来自一个**由策略自己参与选择、又会被训练反过来污染**的测试分布——一旦测试生成器与被测策略共谋（Goodhart / 验证泄漏 / anchor 过期 / TIG 退化），系统会拿到一张统计上无可挑剔、语义上却已失效的证书，于是**「被验证过的无能」比「未被验证的无能」更危险**，因为它会以最高置信度去执行一个它其实不会的动作。

**次级风险与缓解**：验证死锁（最小风险探针 + 预算耗尽即安全停机/交还）；Goodhart/泄漏（GVG 预算 + anchor 隔离 + 信息屏障 + 定理 19，超预算吊销）；示范投毒/无能示范者（DCV 一致 + 单源不定案 + ℰ_demo 对抗训练）；补丁越权（SVP 两把钥匙 + 定理 20）；因果混淆被当能力（CIP 探针 + 混淆区强制降级）；元验证无限递归（硬限 d_max + 显式残差风险账本）。
