# 第 71 轮（承接第 70 轮「BELIEF-RAS 贝叶斯状态估计层」IP-264~274；灵感循环新循环第 1 轮；本轮灵感：「零样本泛化」×「对话管理」）

> R70 把 epistemic 不确定性从「动作模态」锚定到显式世界状态后验 b_t，并交付了基线协议与原型验收。但 R70 有一条从未写进假设的前提：**真实状态必须落在它预先枚举的假设集里**（M≤20 个语义假设）。当机器人遇到训练时从未见过的状态——新工具、新容器、新摆放、新同伴意图——正确假设根本不在 b_t 的支撑集里。此时 H[b_t] 可以很小，不是因为系统知道，而是因为它**不知道自己不知道**；R70 自陈的最大风险「后验自信地错」，在数学上正是**支撑集错配（support misspecification）**。
>
> 本轮两个灵感正好补上两块缺失：
> - **零样本泛化**要求系统在运行时**组合**已知原语，实例化从未见过的状态假设，而不是在固定菜单里挑；
> - **对话管理**把 R70 的一次性 VoI 询问升级为多轮 POMDP（问→听→澄清→确认→修复→承诺），使「新假设」可以被**逐步接地、验证、纠错**，而不是靠一次回答定案。
>
> 核心命题：**零样本泛化与对话管理是同一枚硬币的两面**——语言提供组合先验，让未见状态可由已知原语重新组合；对话提供序列决策，让这种组合在运行时被主动获取、交叉验证与修复。把「状态后验」升级为「**开放世界、可组合、可对话修复的信念**」。命名 **LINGUA-RAS**（Language-grounded Interactive Novel-state Generalization Under uncertainty with Adaptive dialogue）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「测量还准吗」，R69 问「该向谁求证」，R70 问「世界是什么状态」，R71 问「**如果正确答案根本不在我的选项里，我能不能用语言把它临时造出来，并通过一场对话确认它**」——语言是零样本泛化的生成器，对话是它的验证器。

## 0. 直觉与动机

**灵感 1（零样本泛化 → 真正的敌人是支撑集错配，不是方差）**
直觉：R70 的 b_t 是在固定菜单 {s^1…s^M}（M≤20）上归一化的。只要正确答案不在菜单里，再精确的滤波器也只能在错误集合里挑一个「最像」的。更危险的是，归一化强行把概率质量分给菜单，导致 H[b_t] 变小——系统把「我没见过」误读成「我很确定」。零样本泛化要求把菜单从「枚举的假设」换成「由原语按需组合生成的假设」：未见过的状态不是新物种，而是已知属性/关系的新组合。

**灵感 2（组合性 → 未见 = 已知原语的新语法）**
直觉：人可以理解「把蓝色方块放进红色碗里」，即使从未见过这个具体组合，因为颜色、形状、容器、动作是分离的、可重组的。零样本泛化的可计算形式是**组合泛化**：训练只覆盖原语与浅层关系，测试是深层/新组合。关键前提是表示必须**解耦**（disentangled），否则组合会退化成记忆。语言恰好提供了这种解耦的天然坐标系：属性名词、关系介词、动作动词。于是「用语言造状态」不是比喻，而是把组合语法当作假设生成器。

**灵感 3（对话管理 → 一次性询问是多轮 POMDP 的退化）**
直觉：R70 的 MINT 只问一次、按一次回答更新。但真实澄清是序列的：先问「你要哪个」，听不懂就换个说法，答非所问就澄清，回答与观察冲突就修复，涉及不可逆动作就确认。对话管理不是「多说几句话」，而是把 `Ask / Clarify / Confirm / Repair / Defer / Commit` 组织成一个带终止条件的 POMDP。R70 的 MINT = 只允许 `Ask` 一次、且没有 `Repair` 的退化策略。

**灵感 4（两者是同一枚硬币 → 对话是零样本泛化的运行时机制）**
直觉：没有对话的零样本泛化 = 用先验硬猜一个未见组合；没有零样本泛化的对话 = 只能问菜单里已有的选项。合起来才成立：**语言负责「造出」候选（组合），对话负责「验真」候选（接地）**。一场对话本身就是一次小型主动学习：每一轮都在为「这个新组合是否真的成立」收集证据。因此「零样本」不是「不问就 generalization」，而是「用更少的、可复用的先验 + 更有针对性的交互去 generalization」。

**灵感 5（对 R70 最大风险的正面回应 → 允许熵上升，但必须可审计）**
直觉：R70 假设后验熵单调不增，这在开放世界里是错的：当证据与信念冲突时，正确的反应是**熵上升**（承认自己错了），而不是继续压低。对话的 `Repair` 正是合法的「熵注入」通道。要防的不是熵上升，而是**无依据的熵下降**。所以本轮把 R70 的「熵单调不增」替换为「熵变可审计」：每次显著变化都要有对应证据事件（新观测/回答/矛盾/修复）并写进证书。这条改动看似放宽，实则更严——它禁止系统悄悄变自信。

**灵感 6（对话是新的攻击面 → 多轮操纵、谄媚与死循环）**
直觉：多轮对话把 R69 的单次投毒放大为**渐进式信念操纵**：对方可以用多轮小谎言把你推向一个错误但自洽的状态；可以在确认轮里只复述你的假设（谄媚），让证据看起来「一致」；也可以用无休止的澄清拖垮预算。零样本生成还会幻觉出不存在的属性值或关系，让对话去追一个幻影。必须交付：来源可靠性、反谄媚折扣、终止性证明、承诺门，以及「新假设不得由对话单独认证」的证据纪律。

**灵感 7（开放世界的诚实 → s_⊥ 是一等公民）**
直觉：承认「不知道」必须有一个数学位置。给定一个显式的未知质量 s_⊥（novelty mass），系统才能在「没有匹配假设」时保持高熵，而不是被迫从菜单里挑。s_⊥ 不是失败的标志，而是零样本泛化的入口：它触发组合生成与对话，而不是直接保守。R70 的「自信地错」本质上是缺少 s_⊥ 这一维。

## 1. 形式化定义（增量：定义 331–350）

**定义 331（LINGUA-RAS 总览）** LINGUA-RAS = (CGA, OWB, DST, DMP, REP, CG, DGC, ZSC, DBG, RAS-WM†)，在 BELIEF-RAS 之上增量。四不变式：
(i) **实时流零学习写操作**（继承 R70 定义 310-i）；
(ii) **对话预算硬约束**：单次任务对话轮数 ≤ T_max、累计社交成本 ≤ c_max、必须有限步终止（定义 344）；
(iii) **承诺纪律**：不可逆动作只有在接地证书（定义 342）满足后才允许；新组合假设不得由单轮回答定案（继承并强化 R69 证据纪律）；
(iv) **诚实不确定性**：s_⊥ 质量不得被对话单独压到 0；显著熵下降必须有对应证据事件（定义 349）。

**定义 332（组合状态本体）** 状态 s = (a_1,…,a_n, r)，a_i ∈ 𝔄_i 为类型化属性（离散/连续），r ∈ ℛ 为关系（二元/时序）。训练支撑 𝒮_train 只覆盖原语与关系深度 ≤ d_0 的组合。测试状态 s* ∉ 𝒮_train 但每个原语值都曾在训练中出现，称为**组合新颖**（compositionally novel）。

**定义 333（组合闭包与覆盖）** 给定原语域与关系语法，组合闭包 Cl(𝒮_train) = 由训练原语在关系深度 ≤ d 内可生成的全部状态。组合覆盖率 cov = |Cl(𝒮_train) ∩ 𝒮_test| / |𝒮_test|。零样本泛化的目标是在 cov 高、而联合出现率低的区域仍然可靠。

**定义 334（语言接地 Γ）** Γ_θ(q, o) : 语言描述 q × 观测 o → Δ(𝒮_gen)，其中 𝒮_gen ⊆ Cl(𝒮_train) 为由因子分解生成的候选集。Γ = (π_LLM, V, E)：冻结 LLM 给先验 π_LLM；验证器 V 做可执行/可观测检查（属性可测、关系物理可行）；E 做证据一致性打分。接地置信度 γ(s) ∝ π_LLM(s)·V(s)·exp(E(s))。LLM 梯度不回传（继承 R69 定义 295 的语言隔离）。

**定义 335（开放世界信念）** b_t ∈ Δ(𝒮_train ∪ 𝒮_gen ∪ {s_⊥})，s_⊥ 为未知/新颖质量。新颖性用 conformal p 值 p_⊥(o_t)：若 p_⊥ < α，则强制 b_t(s_⊥) ≥ m_min。约束：b_t(s_⊥) 只能由独立证据事件更新，不能由对话回答单独降低（定义 349-iv）。开放世界熵下界见引理 23。

**定义 336（零样本判据）** 策略在组合新颖测试集上达到 (ε, δ)-零样本泛化，若 P[argmax_{s≠s_⊥} b_t(s) = s*] ≥ 1−ε 且该事件在 ≥1−δ 的回合中成立，且只使用了 𝒮_train 中出现过的原语。

**定义 337（对话状态）** d_t = (b_t, γ_t, κ_t, h_t, ρ_t)：b_t 为世界信念；γ_t 为逐属性接地状态（grounded / unclear / contradicted）；κ_t 为承诺账本（已执行/已承诺/不可逆动作）；h_t 为对话历史摘要；ρ_t 为来源可靠性估计。DST 更新 d_{t+1} = U(d_t, a^d_t, y_t, o_t)。

**定义 338（对话动作）** 𝒜_dlg = {Ask(attr), Clarify(attr, alternatives), Confirm(hypothesis), Repair(contradiction), Explain(reason), Probe(physical), Defer(handoff), Commit(action)}。每个动作 = 结构化槽位 + 由冻结 LLM 实现的表层文本；表层文本须过与任务动作相同的安全过滤（防诱导、防越权承诺）。

**定义 339（对话 POMDP）** 元组 (𝒟, 𝒜_dlg, T, O, R, γ)。回答模型 p(y | s, a^d, ρ) 含可靠性 ρ 与可能的欺骗/谄媚；奖励 R = 任务效用 − c_dlg(a^d) − λ_risk·risk(Commit)。目标 π_dlg* = argmax E[Σ γ^t R_t]，且必须满足终止条件（定义 344）。

**定义 340（多轮对话 VoI）** 单轮 VoI(g) = H[b_t] − E_y[H[b_{t+1}]]；多轮计划价值 V^π(d_t, D) = E[Σ_{τ=0}^{D−1}(VoI_τ − c_τ)]，D 为 rollout 深度。注意：加入 Repair 后单步 VoI 不再保证子模性（修复会重新打开已关闭的假设），因此只在 D≤2 上用贪婪，D>2 用 beam search + 上界剪枝。

**定义 341（修复算子 REP）** 矛盾触发条件：回答与独立证据冲突、回答与执行结果冲突、或回答分布异常（谄媚/复制问题）。算子集 {Rollback(checkpoint), Widen(Σ), Reopen(s_⊥), Reask(alternative phrasing), Escalate(human)}。形式化为信念变换 b ← τ_rep(b)，并要求 τ_rep 只能增加熵或重置到检查点，不得无证据地降低熵。

**定义 342（承诺门 CG）** Commit(a) 允许 ⇔ 接地证书满足：(i) 动作相关属性后验 ≥ τ_g；(ii) 至少两个正交证据源一致（R69 证据纪律）；(iii) 若动作涉及 𝒮_gen 中的新组合，至少一次 Confirm 且无未处理矛盾；(iv) 若 b_t(s_⊥) > τ_⊥，只允许可逆动作/物理探针。可逆动作集 𝒜_rev 由 R68 安全包络定义。

**定义 343（零样本风险分解）** R_total ≤ R_approx + R_comp + R_ground + R_est + R_ctrl：
- R_approx：训练近似误差；
- R_comp：组合外推误差（cov 与解耦质量决定）；
- R_ground：语言→状态的接地误差（Γ 的 ECE 决定）；
- R_est：BSE 估计误差（继承 R70）；
- R_ctrl：控制/执行误差（继承 R68）。
对话只能降低 R_comp 与 R_ground，且以预算为代价；它不能降低 R_approx/R_ctrl。

**定义 344（对话预算与终止）** 预算 = (T_max, c_max, patience_max)。终止条件（任一）：(a) 任务相关属性后验 ≥ τ_g 且证据纪律满足；(b) max_g [VoI(g) − c(g)] ≤ 0；(c) 预算耗尽；(d) 连续两轮无信息增益。终止后必须返回 Commit 或 Defer，不得空转。引理 26 给出硬终止界。

**定义 345（反谄媚可靠性）** 回答权重 w(y) = ρ_t · (1 − β_s·sim(y, paraphrase(hypothesis))) · 1[consistency]，β_s 为谄媚折扣，sim 为语义相似度。ρ_t 用在线校准更新（回答与后续独立证据一致/冲突）。系：仅复述智能体假设的回答不提供新信息。

**定义 346（对话投毒威胁模型 ℰ_dlg）** 渐进式信念操纵（多轮小谎言收敛到错误自洽态）、虚假确认（在 Confirm 轮复述假设）、矛盾洪泛（用矛盾耗尽 Repair 预算）、社交工程（诱导越权 Commit）、上下文注入（在回答中注入指令）、幻觉实体（诱导 Γ 生成不存在的属性）。并入 AIC：ℰ_LINGUA = ℰ_BELIEF × ℰ_dlg。

**定义 347（接地校准门 DGC）** 校准 Γ 的接地可靠性 ECE_ground。ECE_ground > τ_g ⇒ 禁用 𝒮_gen 生成，退回 R70 固定支撑；ECE_dlg > τ_dlg ⇒ 禁用对话驱动的零样本实例化，退回 R69 单轮 VoI。绝不让未校准的接地驱动新组合承诺。

**定义 348（含新颖项的二级退避）** λ = λ_floor(U_ale + α·H[b_t] + β·m_⊥)，m_⊥ = b_t(s_⊥)。若消歧成功且新颖性被独立证据清除：α = β = 0（resolution bonus）；若未消解/超预算/被投毒/DGC 越界：α = β = 1（新颖性视同 aleatoric）。R70 是 m_⊥≡0 且禁止 s_⊥ 的边界。

**定义 349（诚实熵审计）** 记录熵变 ΔH_t = H[b_{t+1}] − H[b_t] 与证据事件 e_t。规则：ΔH_t < −τ_H ⇒ 必须存在证据事件 e_t 使该下降可归因；否则拒绝更新并告警。允许 ΔH_t > 0（矛盾/修复/新颖性暴露），但须记录触发源。这替代 R70 定义 310-ii 的「后验熵单调不增」。

**定义 350（证书 J_LINGUA 与 AIC）** J_LINGUA = (J_BELIEF, grounding_ece, novelty_mass_p95, composition_coverage, dialogue_turns_p95, repair_count, termination_proof_hash, sycophancy_discount_hash, lingua_ver)。Valid ⇔ Valid(J_BELIEF) ∧ ECE_ground ≤ τ_g ∧ ECE_dlg ≤ τ_dlg ∧ 承诺门从未被绕过 ∧ 熵审计无未归因下降 ∧ 终止性证明通过。

```python
# IP-275 CGA：组合状态生成（语言槽位 -> 候选状态集）
class CompositionalGrounder:
    def __init__(self, ontology, llm_prior, verifier):
        self.O, self.prior, self.V = ontology, llm_prior, verifier

    def generate(self, query, obs):
        slots = self.O.parse(query)                    # 属性/关系槽位
        cand  = [self.O.topk_attr(a, obs, self.prior, k=3) for a in slots.attrs]
        S_gen = []
        for combo in itertools.product(*cand):         # 组合笛卡尔积
            s = self.O.assemble(combo, slots.relations)
            if self.V.physical_ok(s) and self.V.observable_ok(s, obs):
                S_gen.append((s, self.prior.score(s) + self.V.evidence(s, obs)))
        return dedup_topk(S_gen, k=K_GEN)              # 保留可行且高分的候选

# IP-276 OWB：开放世界质量（conformal novelty）
class OpenWorldBelief:
    def novel(self, o_t):
        return self.cal.pvalue(o_t) < self.alpha

    def merge(self, b_in, S_gen):
        b = dict(b_in)
        for s, w in S_gen:
            b[s] = b.get(s, 0.0) + w
        p_perp = self.cal.pvalue_from(b_in)
        m_min  = self.cal.m_min(p_perp)                # p<alpha -> m_min>0
        b[PERP] = max(b.get(PERP, 0.0), m_min)
        return normalize(b)

# IP-278 DMP：对话 POMDP（浅层贪婪，深层 beam）
def choose_dialogue_act(d, budget, depth=2):
    if commit_gate(d):                                 # 已可安全承诺
        return Commit(select_action(d.b))
    if depth <= 2:
        cands = [Ask(a) for a in unclear_attrs(d)] + \
                [Clarify(a, alt) for a in ambiguous_attrs(d)] + \
                [Confirm(argmax(d.b))]
        scored = [(g, myopic_voi(d, g) - cost(g)) for g in cands]
    else:
        scored = beam_search_plans(d, width=8, depth=depth,
                                   upper_bound=entropy(d.b))
    best = max(scored, key=lambda x: x[1])
    if best[1] <= 0:
        return Defer() if d.b[PERP] > TAU_PERP else Commit(select_action(d.b))
    return best[0]

# IP-279 REP：矛盾检测与修复（只允许熵增/回滚）
def repair(d, contradiction, o):
    if contradiction.kind == 'answer_vs_evidence':
        d.b = rollback(d.b, d.checkpoint)              # 回到矛盾前
        d.b = widen(d.b, sigma=WIDEN)                  # 增大方差
        d.b[PERP] = max(d.b[PERP], M_REPAIR)           # 重开未知
        return d, Reask(alternative=True)
    if contradiction.kind == 'sycophancy':
        return d, Clarify(target=argmax(d.b), alternatives=True)
    if contradiction.kind == 'budget_flood':
        return d, Defer()                              # 不再接招，交人/降级
    if contradiction.kind == 'phantom_entity':
        disable_entity(contradiction.entity); return d, Ask(attr_of(contradiction))

def LINGUA_round(M, obs, user):
    z, o = M.mtm.forward(...)
    c, U_cal, thr = M.cof.step(...)
    b = M.bse.step(M.b_prev, o, M.last_action, M.last_g, M.last_y)

    # 1) 开放世界：检测新颖并生成组合假设
    if M.owb.novel(o):
        S_gen = M.cga.generate(user.query, o)
        b = M.owb.merge(b, S_gen)
    mode = M.dgc.check(b)
    if mode == FIXED_SUPPORT: b = project_to_train(b)   # 不可信接地 -> R70

    # 2) 对话（后台线程；实时环只消费当前 b 的一个快照）
    d = M.dst.init(b, o)
    while not M.dbg.terminate(d):
        a_d = M.dmp.choose(d, M.dbg)
        y   = user.answer(a_d)                          # 可能不可靠/被投毒
        d   = M.dst.update(d, a_d, y, o)
        if M.rep.trigger(d, y, o):
            d, a_fix = M.rep.repair(d, M.rep.why(d, y, o), o)
            if a_fix is not None: M.dst.push(d, a_fix)

    # 3) 承诺门：不可逆动作必须证据齐备
    U_ale = expectation(d.b, lambda s: trace(obs_noise_cov(s)))
    if M.cg.allow(d):
        s_hat = argmax_no_perp(d.b)
        A = M.ach.propose_from_state(s_hat, H=M.vista.H)
        k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
        lam = max(M.efs.risk_scale(...),
                  lam_floor(U_ale + ALPHA*entropy(d.b) + BETA*d.b[PERP]))
    else:
        A = reversible_or_probe(d)                      # 只做可逆/探针
        k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
        lam = lam_floor(U_ale + entropy(d.b) + d.b[PERP])

    # 4) 审计 + 证书（熵变必须可归因）
    M.vqa_iii.submit_async(d, M.owb.last_p, M.rep.log, lam)
    M.entropy_audit.record(d.b, evidence_events=d.h.events)
    M.b_prev = d.b
    return k, lam, d
```

## 3. 推导

**引理 23（开放世界熵下界）** 若 b_t(s_⊥) = m，则 H[b_t] ≥ h(m) = −m log m − (1−m)log(1−m)。证明：按 s_⊥ 与其余事件分解熵，H = h(m) + (1−m)H[·|¬⊥] ≥ h(m)。系：只要 m 有正下界，R70 式的熵坍缩（H→0）在数学上不可能；m=0.2 时下界约 0.5 nat，正好是「承认不知道」的代价。这也是对 R70 最大风险的直接封堵。

**引理 24（组合泛化误差界）** 设属性生成近似独立、解码器解耦，训练覆盖每个原语与关系深度 d_0，测试关系深度 ≤ d。则组合外推误差
R_comp ≤ Σ_{i=1}^n ε_i + L_rel·(d−d_0)·δ_rel + √(log(1/δ)/(2N_comp))，
其中 ε_i 为单属性泛化误差，L_rel 为关系算子的 Lipschitz 常数，N_comp 为组合样本数。系：**覆盖率 cov 高不等于 R_comp 低**；真正决定零样本的是解耦质量（ε_i）与关系深度差（d−d_0）。语言接地的价值在于用 Γ 把有效假设数从 |𝔄|^n 压到可行子集，从而降低 N_comp 需求。

**引理 25（多轮修复的指数抑制）** 若每轮独立检测到「当前假设错误」的概率 ≥ p_d，且修复后不会回到同一错误（去重/回滚保证），则 T 轮内仍以错误假设提交的概率 ≤ (1−p_d)^T + ε_cal。系：对话的价值主要在检测能力 p_d 与轮数 T，而非单轮回答准确率；当 p_d=0（无独立证据、只有回答自洽）时，多问只会放大谄媚，不改变错误概率——这解释了为什么「问一次」和「问十次同一来源」一样危险。

**引理 26（对话终止性）** 在定义 344 的预算与「每轮成本 c>0、无信息增益轮次计数」下，任何策略在 ≤ min(T_max, ⌈c_max/c⌉) 轮内终止；若 DMP 采用「无增益即停」，则期望轮数 ≤ 1/(1−ρ_gain)，ρ_gain 为单轮产生正增益的概率。系：幻觉实体导致的无效追问被终止条件 (d) 截断，不会出现「追问到预算崩溃」。

**定理 20（严格包含链）** 在 A102–A105（开放世界可识别、接地可校准、修复有效、预算有限）下，LINGUA 的期望风险 ≤ BELIEF ≤ FLUID ≤ R68；当 m_⊥≡0、Γ 禁用、对话禁用时，四者逐指令相同。安全侧层层不让步，效率侧才获得零样本与 resolution bonus。

**定理 21（安全承诺）** 若承诺门 CG 满足定义 342，且接地 ECE ≤ τ_g、证据源欺骗相关 ρ<1，则不可逆动作的错误承诺率 ≤ ECE_ground + δ_p·ρ^{k−1} + P(矛盾漏检)。系：把 R69 引理 18 从单轮扩展到多轮，并把「新组合」纳入证据纪律；单次 Confirm 永远只提供似然，不单独定案。

**定理 22（零样本部署保证）** 若组合覆盖 cov ≥ 1−ζ、Γ 的 ECE_ground ≤ τ_g、开放世界检测漏检率 ≤ η，则在新组合测试分布上
R_total ≤ R_train + c_1·ζ + c_2·τ_g + c_3·η + c_4·H_unresolved，
其中 H_unresolved 为预算内未消解的信念熵。当 ζ, τ_g, η→0 且对话预算足够时，退化为 R70 的估计误差界；当对话预算为 0 时，β m_⊥ 项自动加回，退化为 R70 的保守行为。

## 6. 本轮最大风险

**一句话**：LINGUA-RAS 的全部零样本收益押在「Γ 生成的组合假设既覆盖真实状态、又不引入大量幻觉」这一前提上——**若接地 ECE 在开放世界失控，系统会自信地承诺一个由语言幻觉拼出的、不存在的状态；多轮对话非但不能纠错，反而会用一次「确认」给幻觉盖章**，于是 R70 的「自信地错」被升级为「被对话验证过的自信地错」。

**次级风险与缓解**：
1. **支持集外仍被强行归一化** → s_⊥ 一等公民 + 引理 23 熵下界 + DGC 门控；
2. **组合爆炸导致候选集不可行** → 验证器剪枝 + top-k 槽位 + 组合覆盖阈值 cov*；
3. **多轮谄媚/渐进投毒** → 反谄媚折扣 + 正交证据纪律 + 引理 25 的 p_d 前提 + ℰ_dlg 对抗训练；
4. **对话死循环/预算击穿** → 终止条件 (a)–(d) + 引理 26 硬界 + DBG；
5. **修复本身引入不稳定** → 只允许「增熵/回滚」的 τ_rep + 熵审计 + 承诺门。

**定义 339（对话 POMDP）** 回答模型 p(y|s,a^d,ρ) 含欺骗/谄媚；奖励 = 任务效用 − c_dlg − λ_risk·risk(Commit)。

**定义 340（多轮 VoI）** 单轮 VoI 如上；多轮 V^π 见符号表；Repair 破坏子模性，D≤2 贪婪、D>2 beam。

**定义 341（修复算子）** 触发：回答 vs 独立证据 / 回答 vs 执行 / 谄媚分布。算子：Rollback、Widen、Reopen(s_⊥)、Reask、Escalate；τ_rep 只增熵或回滚。

**定义 342（承诺门）** Commit ⇔ 后验≥τ_g ∧ 双正交源一致 ∧ 新组合已确认 ∧ (m_⊥>τ_⊥ ⇒ 仅可逆动作)。

**定义 343（风险分解）** 五分量见符号表；对话只降 R_comp/R_ground。

**定义 344（预算与终止）** (T_max,c_max,patience)；终止条件 (a) 可承诺 (b) VoI≤成本 (c) 预算耗尽 (d) 连续两轮无增益；终止必返回 Commit/Defer。

**定义 345（反谄媚）** w(y)=ρ_t·(1−β_s·sim(y,paraphrase(h)))·1[consistency]；ρ 在线校准。

**定义 346（对话威胁 ℰ_dlg）** 渐进操纵、虚假确认、矛盾洪泛、社交工程、上下文注入、幻觉实体。

**定义 347（DGC）** ECE_ground>τ_g ⇒ 禁用 𝒮_gen（回 R70）；ECE_dlg>τ_dlg ⇒ 禁用对话零样本（回 R69 单轮）。

**定义 348（含新颖项的退避）** λ=λ_floor(U_ale+αH[b_t]+βm_⊥)；消解且新颖清除 ⇒ α=β=0；否则 α=β=1。

**定义 349（诚实熵审计）** ΔH_t < −τ_H 必须可归因到证据事件 e_t，否则拒绝更新；允许 ΔH_t>0。

**定义 350（证书）** J_LINGUA=(J_BELIEF, ECE_ground, ECE_dlg, m_⊥_p95, cov, turns_p95, repair_count, termination_hash, sycophancy_hash, lingua_ver)。Valid 还需：承诺门零绕过、熵审计零未归因下降、终止性证明通过。

## 4. 关键算法伪代码（实现导向）

```python
PERP = object()   # s_⊥ 的哨兵键

# IP-275 CGA
def cga_generate(query, obs, ontology, prior, verifier, k=3, K_GEN=24):
    slots = ontology.parse(query)                       # attrs + relations
    per_attr = [ontology.topk(a, obs, prior, k) for a in slots.attrs]
    out = []
    for combo in itertools.product(*per_attr):
        s = ontology.assemble(combo, slots.relations)
        if verifier.physical(s) and verifier.observable(s, obs):
            out.append((s, prior.logp(s) + verifier.log_evidence(s, obs)))
    return dedup_topk(out, K_GEN)

# IP-276 OWB
def owb_merge(b_in, obs, S_gen, cal, alpha=0.05):
    b = defaultdict(float, b_in)
    for s, w in S_gen:
        b[s] += math.exp(w)
    p = cal.pvalue(obs)
    if p < alpha:
        b[PERP] = max(b[PERP], cal.m_min(p))              # 强制未知质量
    return normalize(b)

# IP-277 DST
def dst_update(d, a_d, y, o, model):
    lik = model.answer_likelihood(y, a_d, d.rho)         # 含谄媚折扣
    b   = normalize({s: d.b[s] * lik.get(s, 1.0) for s in d.b})
    b   = fuse_independent(b, independent_evidence(o))
    gamma = update_gamma(d.gamma, a_d, y, model)
    rho   = online_calibrate(d.rho, y, o)
    return replace(d, b=b, gamma=gamma, rho=rho,
                   h=d.h.append(a_d, y), checkpoint=d.b)

# IP-278 DMP
def dmp_act(d, budget, depth=2):
    if commitment_gate(d): return Commit(argmax_no_perp(d.b))
    cands = list(ask_candidates(d)) + list(clarify_candidates(d)) + [Confirm(argmax_no_perp(d.b))]
    if depth <= 2:
        scored = [(g, myopic_voi(d, g) - cost(g, d)) for g in cands]
        best = max(scored, key=lambda x: x[1], default=(Defer(), 0.0))
    else:
        best = beam_plan(d, cands, width=8, depth=depth,
                         upper=entropy(d.b) - min_cost(d))
    if best[1] <= 0:
        return Defer() if d.b[PERP] > TAU_PERP else Commit(argmax_no_perp(d.b))
    return best[0]

# IP-279 REP
def rep_maybe(d, y, o):
    kind = detect_contradiction(d, y, o)                 # 见定义 341
    if kind is None: return d, None
    if kind == 'answer_vs_evidence':
        d = replace(d, b=reopen(widen(rollback(d.b, d.checkpoint), WIDEN), M_REPAIR))
        return d, Reask(alternative=True)
    if kind == 'sycophancy':
        return d, Clarify(target=argmax_no_perp(d.b), alternatives=True)
    if kind == 'budget_flood':
        return d, Defer()
    if kind == 'phantom_entity':
        return d, Ask(attr_of(kind))
    return d, None

# IP-280 CG
def commitment_gate(d, tau_g=0.85, tau_perp=0.2):
    s = argmax_no_perp(d.b)
    grounded  = all(d.gamma[a] >= tau_g for a in relevant_attrs(s))
    two_src   = d.evidence.count_orthogonal(s) >= 2
    novel_ok  = (not is_novel(s)) or (d.h.confirmed(s) and not d.h.unresolved(s))
    safe_novel = d.b[PERP] <= tau_perp
    return grounded and two_src and novel_ok and safe_novel

# IP-283 DBG + IP-288 entropy audit
def dialogue_loop(d, user, model, budget, audit):
    while not budget.exhausted(d):
        a = dmp_act(d, budget)
        if isinstance(a, (Commit, Defer)): return d, a
        y = user.answer(a)                               # 不可信来源
        d_new = dst_update(d, a, y, user.obs, model)
        d_new, fix = rep_maybe(d_new, y, user.obs)
        if not audit.attributable(d.b, d_new.b, d_new.h.last_event):
            break                                        # 拒绝未归因熵降
        budget.charge(a, d_new)
        if budget.no_gain(d_new): break
        if fix is not None: d_new = dst_update(d_new, fix, user.answer(fix), user.obs, model)
        d = d_new
    return d, (Commit(argmax_no_perp(d.b)) if commitment_gate(d) else Defer())

# IP-289 主闭环
def lingua_round(M, obs, user):
    z, o = M.mtm.forward(...); c, U_cal, _ = M.cof.step(...)
    b = M.bse.step(M.b_prev, o, M.last_action, M.last_g, M.last_y)

    if M.owb.novel(o):
        b = M.owb.merge(b, o, M.cga.generate(user.query, o), M.cal)
    mode = M.dgc.check(b)
    if mode == FIXED_SUPPORT: b = project_to_train(b)     # 回 R70
    if mode == SINGLE_SHOT:   return M.r69_round(b, o)    # 回 R69

    d, action = dialogue_loop(M.dst.init(b, o), user, M.model, M.dbg, M.audit)
    U_ale = expectation(d.b, lambda s: trace(obs_noise_cov(s)))
    if isinstance(action, Commit):
        A = M.ach.propose_from_state(argmax_no_perp(d.b), H=M.vista.H)
        k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
        lam = max(M.efs.risk_scale(...),
                  lam_floor(U_ale + ALPHA*entropy(d.b) + BETA*d.b[PERP]))
    else:
        A = reversible_or_probe(d); k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
        lam = lam_floor(U_ale + entropy(d.b) + d.b[PERP])

    M.vqa_iii.submit_async(d, M.owb.last_p, M.rep.log, M.audit.log)
    M.b_prev = d.b
    return k, lam, d
```

## 5. 推导（证明要点）

**引理 23（开放世界熵下界）**
证明：令 m=b_t(s_⊥)。按事件 {s_⊥} 与其余分解：H[b_t]=h(m)+(1−m)H[b_t(·|¬⊥)]≥h(m)，其中 h 为二元熵。故 m≥m_min>0 ⇒ H[b_t]≥h(m_min)>0。R70 在 m≡0 时 H 可任意接近 0，因此本引理严格补上了 R70 的漏洞。m=0.2 时 h≈0.50 nat。

**引理 24（组合泛化误差界）**
证明要点：将 R_comp 分解为属性误差 + 关系误差 + 有限样本项。属性近似独立时，联合误差 ≤ Σ ε_i（三角不等式）；关系深度每超一层，Lipschitz 放大 δ_rel；用 Hoeffding 控制 N_comp 个组合的经验风险。Γ 的验证器把不可行组合的先验置零，相当于缩小假设空间，故 N_comp 的有效需求下降。

**引理 25（多轮修复指数抑制）**
证明：设 E_t 为「第 t 轮检测到错误且修复成功」。各轮检测独立、修复后不回到同一错误，则错误提交概率 ≤ P(∩_{t≤T}¬E_t)+ε_cal = (1−p_d)^T+ε_cal。p_d=0 时界退化为 1，说明没有独立证据的对话无纠错能力。

**引理 26（终止性）**
证明：每轮成本 c>0，预算 c_max ⇒ 轮数 ≤ ⌈c_max/c⌉；T_max 为硬上限；「连续两轮无增益即停」把每轮的停概率下界化为 ρ_gain>0，故期望轮数 ≤ 1/(1−ρ_gain)。终止条件 (a)–(d) 至少一个在有限步成立。

**定理 20（严格包含链）**
证明：LINGUA 在 s_⊥≡0、Γ 禁用、对话禁用时，CGA 退化为固定支撑、DMP 退化为单步 MINT、REP 无操作、CG 退化为 R70 的投影，故与 BELIEF 逐指令相同。开放世界只增加可选动作（生成/询问/修复），且所有新增动作受预算与承诺门约束，由定义 348 的风险单调性知期望风险不增。归纳得 LINGUA ≤ BELIEF ≤ FLUID ≤ R68。

**定理 21（安全承诺）**
证明：错误承诺需同时绕过 (i) 后验门 (ii) 双源纪律 (iii) 新组合确认。由定理 21 条件，后验门失误率 ≤ ECE_ground；双源在欺骗相关 ρ<1 下失误率 ≤ δ_p·ρ^{k−1}（R69 引理 18）；新组合确认漏检率 ≤ P(漏检)。三者取并集界得上式。∎

**定理 22（零样本部署保证）**
证明：R_total 按定义 343 五分解。组合项由引理 24 控制为 c_1ζ，接地项由 ECE_ground≤τ_g 控制，新颖漏检项由 η 控制，估计/控制项继承 R70/R68。未消解熵项在预算耗尽时保留，保证不会因为「没问完」而低估风险。ζ,τ_g,η→0 且预算充足 ⇒ 收敛到 R70 的估计界；预算=0 ⇒ β=1，退化为 R70 保守行为。∎

## 9. 本轮最大风险

**一句话**：LINGUA-RAS 把零样本能力建立在「语言接地生成的组合既覆盖真实状态、又不大量幻觉」之上——**一旦 ECE_ground 在开放世界失控，系统会用一个由语言幻觉拼出的状态去通过多轮「确认」，把 R70 的「自信地错」升级成「被对话盖章的自信地错」；此时问得越多，错误越可信**。

**缓解的优先级**：DGC 门控与 s_⊥ 熵下界是最后防线（宁可退回 R70 固定支撑，也不让未校准接地驱动承诺）；其次是 REP + 双源证据纪律（把单轮错误转为可检测矛盾）；再次是 DBG 终止界（防止对话被拖入死循环）；最后才是 CGA/DMP 的收益优化。
