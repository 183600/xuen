# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「状态机」×「开放词汇」）

> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**单一模式真源 + 开放词汇安全边界**。两个灵感分别治理 v9 的两笔债：状态债（v9 已有 DistillFSM、块生命周期、5 级退化链、v8 模式门四套状态机隐式耦合，只做过两两论证）、词汇债（MetricVoice 的语音与任务层假设封闭词表，无法接地操作员的新指称，且无显式"未知"语义）。必须保证：开放词汇只能扩展**任务层**可及性，永不得改变**硬安全谓词**的真值。

## 0. 直觉与动机

**灵感 1（状态机 → 单一监督状态图）**
直觉：v9 的"模式"散落在四五个手写状态变量里，每加一个模块就多一个 mode flag，组合空间按乘积爆炸；工程上最危险的往往不是单点故障，而是**模式混淆**（mode confusion）——系统处在一个状态、操作员以为在另一个状态。核心创新：**监督状态图（SupervisoryStatechart, SSC）**：把全部模式（退化级、提炼态、块生命周期、任务态）纳入一个分层状态图（UML statechart 语义：层次态 + 正交区域 + 进入/退出动作 + 守卫）。v9 的 5 级退化链不再是 if-else 链，而是 SSC 的一个**正交区域**；DistillFSM 是另一个区域的子图。静态分析强制"任何行为不得依赖未声明为 SSC 状态的模式变量"——**P14 单一模式真源律**。

**灵感 2（开放词汇 → 接地词表的安全扩展）**
直觉：MetricVoice 说的是"语音度量"，但它的"词汇"其实是封闭的——固定 6 层指标、固定抓取标签、固定指令集。真实操作员会说"把那个蓝色马克杯放到洗碗机上层"，指称天然开放。核心创新：**开放词汇接地器（OpenVocabGrounder, OVG）**：用视觉-语言模型把语音片段 + 场景接地为动态符号集 Σ_t，输出带**共形预测集**的接地命题（conformal grounded proposition）。关键安全设计不是"接得准"，而是"接不准也知道自己不准"：共形集的大小给出可证明的弃权语义。开放词汇只允许进入任务层守卫。

**两灵感交汇 = 开放词汇状态图（OVSC）**：状态图的迁移守卫是三值谓词，既可读封闭度量、也可读开放词汇命题；开放词汇把"能做什么"从固定词表扩展到任意指称，而分层律把"允许危及什么"锁死在封闭度量上。二者不是简单叠加，而是靠**安全权威分层**（P13）强行解耦：开放词汇扩展可及性，封闭度量守住安全。

## 1. 研究问题（轮次升级版）

- **Q1（开放词汇的可靠性边界）**：在何种统计假设（可交换性）下，共形接地能给出"唯一指称接错概率 ≤ α"的保证？当开放词汇的立身之本恰是处理校准分布之外的新概念时，该保证如何失效？能否用域偏移信号 Δ_dom 在守卫处实时收紧？
- **Q2（状态图的安全合成）**：如何把 v9 的 5 级退化链、DistillFSM、块生命周期嵌入单一分层状态图，并证明其为 v9 的保守扩展（双模拟）？正交区域如何避免非法交互与死锁？
- **Q3（未知即安全）**：三值守卫 + "UNKNOWN → 安全询问态"如何保证开放词汇的错误只损失活性（liveness）、不损失安全性（safety）？宣告完备的性能否把模式混淆降到零？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 开放词汇不越硬安全律（Open-Vocab Cannot Bypass Hard Safety）**
守卫集分为 Γ = Γ_hard ⊎ Γ_task。Γ_hard（M₀ 硬检查、SpatialCert、FaultCert、力/速上限、停车不变式）的自由变元只能来自封闭、已标定的度量词表；Γ_task 才可引用开放词汇命题。静态检查：任何 Γ_hard 谓词含开放词汇符号 ⇒ 构建失败。推论：开放词汇的任何接地错误都不能改变 Γ_hard 的真值。

**P14 单一模式真源律（Single Source of Mode Truth）**
系统全部模式语义由一个分层状态图 SSC 定义；禁止 SSC 未声明的模式变量参与行为决策。v9 的 DistillFSM / 块生命周期 / 退化级作为 SSC 内部子图嵌入，不再有独立的状态全局变量。静态分析（模式变量逃逸检测）保证。

**P15 未知即安全询问律（Unknown ⇒ Safe Inquiry）**
守卫取三值 {T, F, U}，Kleene 语义；U 只能迁移到指定的安全/询问态，绝不迁移到会降低硬安全余量的乐观态。开放词汇的失败模式被限制为"停下来问人"，而非"自信地做错"。

## 3. 与基线的接口（如何退化）

- OVG 失效 / 全部弃权（Σ_t 命题皆为 U）⇒ 所有开放词汇迁移不可用，SSC 收缩到封闭子图，逐位等价 v9（引理 91）；
- SSC 失效 ⇒ 运行期回落到 v9 手写模式逻辑（代码保留、非状态图驱动），等价 v9；
- 语义安全包络 E_safe 校验失败 ⇒ 拒绝该开放词汇迁移，停留当前态（等同 U 处理）；
- 宣告通道失效 ⇒ 退回无宣告模式（行为不变，仅操作员可观测性下降，模式混淆上界恢复为 v9 水平）；
- v9 的 AC / MW / ID 任一失效 ⇒ 按 v9 定义 536/539 注入中立元，等价 v8 / v7；
- 全部失效 ⇒ 完整退回 MetricVoiceGauge-ACMD v9 → OTL-GC-ER v7 → v6。

## 4. 预期贡献

1. **监督状态图（SSC）**：将多套隐式模式机统一为分层状态图，给出正交区域确定性与无非法交互的合成证明（引理 88），把"模式混淆"从工程直觉变成可验证的宣告完备性（引理 92）。
2. **开放词汇安全接地（OVG）**：共形预测集 + 弃权语义，把"开放词汇能不能用"从准确率问题变成可证明的覆盖/误接地界（引理 87），并诚实暴露其在分布外的失效（本轮最大风险）。
3. **安全权威分层（P13）与未知即安全（P15）**：非干扰引理（89）把硬安全与开放词汇彻底解耦；最坏情况是活性损失而非安全违背（引理 90）。
4. **双向语音度量**：MetricVoice 由"输出度量"升级为"输入开放指令 + 输出当前状态宣告"的闭环，支撑宣告完备性与人工接管。

## 5. 本轮最大风险

**一句话**：开放词汇的共形覆盖保证以"校准分布与部署分布可交换"为前提，而开放词汇的立身之本恰是处理校准分布之外的新概念——于是在最需要它的新指称上，覆盖保证静默失效；分层律（P13）只保住了硬安全谓词，却保不住"抓错物体"这类语义层面的安全。

**定义 540（开放词汇集与版本 OpenVocabulary）** 词集 Σ_t = (L_t, V_t, e)，L_t 为已接地词元（来自语音片段 + 场景），V_t 单调递增。**集内只增**：Σ_{t+1} ⊇ Σ_t（仅回合边界可清空重来）。每个 σ ∈ L_t 带文本嵌入 e(σ) 与域标签 dom(σ) ∈ {in, out}。

**定义 541（共形接地命题 ConformalGroundedProposition）** 给定查询 (u, o) 与校准集，分裂共形给出
```
C_α(u, o) ⊆ Referents,   P(r* ∈ C_α(u, o)) ≥ 1 − α    （可交换性假设下）
```
接地命题 g=(σ, C_α, c)。**接受**（将命题置为 T）⇔ |C_α(u,o)|=1 ∧ c ≥ τ_ov；**弃权**（置为 U）⇔ 否则（集为空或非单点、置信不足）。弃权是**显式**语义而非错误。

**定义 542（三值守卫 ThreeValuedGuard）** 守卫 γ: (封闭度量, 接地命题) → {T, F, U}，Kleene 三值逻辑：¬U=U；T∧T=T，F∧*=F，U∧U=U；对偶 ∨。语义：T=可证真，F=可证假，U=不可判定（弃权/超时/缺值）。

**定义 543（监督状态图 SupervisoryStatechart）** SSC = (S, s⁰, E, R, δ, A_in, A_out, Π)。R = {R_deg, R_distill, R_chunk, R_task} 为**正交区域**，Π 为区域优先级序 R_deg ≻ R_distill ≻ R_chunk ≻ R_task（低索引可抢占高索引）。层次态允许含子图；δ: S × E × Γ → S 为确定性（部分）迁移；A_in/A_out 为进入/退出动作。v9 的 5 级退化链 = R_deg 子图；DistillFSM = R_distill 子图；块生命周期 = R_chunk 子图。

**定义 544（安全权威分层 SafetyAuthorityLayering）** Γ = Γ_hard ⊎ Γ_task，且
```
vars(γ) ∩ OpenVocab = ∅   ∀γ ∈ Γ_hard
```
即 Γ_hard 仅自由引用封闭、已标定的度量符号（M₀ 硬检查、SpatialCert、FaultCert、力/速上限、停车不变式 d_stop）。此为静态可检查的语法约束。

**定义 545（语义安全包络 SemanticSafetyEnvelope）** E_safe ⊆ S × S 为**预注册**的任务迁移白名单。开放词汇守卫只能触发 (s, s') ∈ E_safe；包络外迁移必须由封闭度量或人工显式确认触发。作用：即便接地错误，错误也只能在预先审核过的任务迁移中发生。

**定义 546（状态宣告通道 Annunciation）** MetricVoice 每周期可播报 a_out(s)（当前态 + 迁移原因），延迟 L_ann。SSC **宣告完备** ⇔ 对任意两态 s ≠ s'，若其允许的"控制权威动作集"不同，则 a_out(s) ≠ a_out(s')。

**定义 547（模式混淆度 ModeConfusionMetric）** MC = P(操作员据可观测信息推断的控制权威态 ≠ 真实态)。宣告完备且 L_ann ≤ 人类反应界 ⇒ MC = 0（见引理 92）。

```python
# IP-357 OpenVocabGrounder：开放词汇接地器（共形 + 弃权）
class OpenVocabGrounder:
    def __init__(self, vl_model, text_encoder, calib_scores,
                 alpha=0.05, tau_ov=0.6):
        self.vl = vl_model                     # 开放词汇检测/分割 + 视觉-文本对齐
        self.enc = text_encoder
        self.qhat = conformal_quantile(calib_scores, alpha)  # 分裂共形分位数
        self.alpha, self.tau_ov = alpha, tau_ov
        self.vocab = Vocabulary()              # Σ_t，只增、版本化

    def ground(self, utterance, obs):
        spans = parse_referring_expressions(utterance)
        props = []
        for u in spans:
            self.vocab.add_span(u)             # 只增；版本 V_t += 1
            scores = self.vl.score_referents(u, obs)         # 每个候选指称一致性
            cand = {r: s for r, s in scores.items() if s >= 1 - self.qhat}
            c = max(scores.values(), default=0.0)
            accepted = (len(cand) == 1 and c >= self.tau_ov)
            props.append(GroundedProp(sigma=u, C=cand, conf=c,
                                      val=TRUE if accepted else UNKNOWN))
        return props, self.vocab.version

# IP-358 SupervisoryStatechart：分层状态图（正交区域 + 三值守卫）
class SupervisoryStatechart:
    def __init__(self, regions, priority):
        self.regions = regions                 # [R_deg, R_distill, R_chunk, R_task]
        self.priority = priority               # Π：低索引抢占高索引
        self.state = initial_state(regions)

    def step(self, event, ctx):
        # 按优先级序同步：任一区域先产生抢占迁移即锁定本周期
        for r in self.priority:
            enabled = [tr for tr in self.regions[r].transitions(self.state[r], event)
                       if eval3(tr.guard, ctx) is TRUE]     # 仅 T 允许迁移
            if enabled:
                tr = enabled[0]                # δ 确定性：守卫全序
                self._exit(self.state[r], r, ctx)
                self.state[r] = tr.target
                self._enter(self.state[r], r, ctx)
                return tr, r                   # 抢占：本周期锁定
        # 无 T 迁移：检查是否有 U 需要安全询问（仅 R_task 允许）
        if any(eval3(tr.guard, ctx) is UNKNOWN for tr in
               self.regions['R_task'].transitions(self.state['R_task'], event)):
            return self._ask_state_transition(), 'R_task'
        return None, None

# IP-359 SafetyAuthorityBridge：分层检查 + 包络 + 未知即安全
class SafetyAuthorityBridge:
    def __init__(self, envelope, hard_symbols):
        self.E_safe = envelope                 # 预注册任务迁移白名单
        self.hard_symbols = hard_symbols       # Γ_hard 允许的封闭符号

    def check_static(self, ssc):
        for tr in ssc.all_transitions():
            if tr.region in ('R_deg', 'R_chunk') or tr.guard.hard:
                assert tr.guard.symbols <= self.hard_symbols, "P13 违反：硬守卫含开放词汇"
            if tr.guard.uses_open_vocab:
                assert (tr.src, tr.target) in self.E_safe, "迁移不在语义安全包络内"

    def gate(self, tr, grounded_props):
        if tr.guard.uses_open_vocab and tr.guard.value(grounded_props) is UNKNOWN:
            return 'ASK'                       # P15：未知即安全询问
        return 'ALLOW' if eval3(tr.guard, ctx=None) is TRUE else 'BLOCK'

    ctx = mw_default_ctx()
    results = middleware.run_cycle(runners={                # v9 契约化感知，不变
        'DA_ML': ..., 'SPR': ..., 'CAL_FI': ..., 'OTL': ...}, ctx=ctx)

    # ---- OVG：仅在任务层需要时接地；全部弃权即 LEVEL-0 ----
    if utterance is not None:
        props, _ = grounder.ground(utterance, obs)
        ctx.grounded = {g.sigma: g for g in props}
    else:
        ctx.grounded = {}

    # ---- SSC：一次同步步进（正交区域，优先级抢占）----
    event = assemble_event(ctx, obs)                       # 感知/块/任务事件
    tr, region = ssc.step(event, ctx)
    if tr is not None:
        verdict = bridge.gate(tr, ctx.grounded)
        if verdict == 'ASK':
            ssc.force_state('R_task', 'AskUnknown')        # P15：安全询问
        elif verdict == 'BLOCK':
            ssc.rollback(tr)                               # 保持原态

    # ---- 由 SSC 当前态驱动 v9 既有路径（AC/MW/ID/v8 继承）----
    C, spatial_cert, claims, metrics, rewards = M.run_under_mode(
        mode=ssc.state, ctx=ctx)

    # ---- 宣告：MetricVoice 播报当前态与原因（定义 546）----
    voice.announce(a_out(ssc.state), reason=current_reason)
    return C, spatial_cert, claims, metrics, rewards
```

## 4. 推导

**引理 87（共形守卫可靠性 / Conformal Guard Soundness）** 设校准集与部署查询可交换，α ∈ (0,1)。对任一被接受的开放词汇命题（|C_α|=1 且 c≥τ_ov），其唯一指称 r̂ 满足 P(r̂ ≠ r\*) ≤ α。证明：接受 ⇔ C_α 为单点；由共形覆盖 P(r\* ∈ C_α) ≥ 1−α，故 P(接受 ∧ r̂≠r\*) ≤ P(r\* ∉ C_α) ≤ α。一回合内若含 Q 个独立查询，误接地概率经并集界 ≤ Q·α。∎

**引理 88（状态图确定性与无非法交互）** 设 (i) 每区域迁移函数 δ_r 关于事件确定（守卫全序）；(ii) 区域守卫只读本区域拥有变量与只读共享变量；(iii) 跨区域抢占由有限事件集上的优先级序 Π 同步。则乘积迁移确定，且不存在跨区域非法交互；若每区域存在可达静止态且 Π 良基，则乘积无死锁。证明：按 Π 归纳，首个产生 T 迁移的区域锁定本周期，其余区域不改变自身态；变量拥有权排除写-写冲突，只读共享排除守卫求值竞争；良基 Π 保证抢占不会无限下推，各区域静止态可达 ⇒ 乘积可回到联合静止态。∎

**引理 89（开放词汇安全无干扰 Non-interference）** 记 H 为任一声明的硬安全不变式，其自由变元 vars(H) ⊆ Γ_hard 符号集。则 H 的真值与 Σ_t、接地结果、E_safe 选择**无关**。证明：系统对开放词汇的唯一入口是 Γ_task 所辖迁移（经 E_safe 过滤）与 R_task 内部事件；由 P13/定义 544，Γ_hard 谓词与开放词汇符号自由变元不交；由定义 543，R_deg/R_chunk 的推进不读 R_task 的开放变量。故改变接地结果不改变任何 Γ_hard 谓词的求值，H 保持。**注意**：该结论相对"声明的 H"成立，不覆盖语义层面的选择正确性（见本轮风险）。∎

**引理 90（未知即安全 / 无安全回退）** 在三值 Kleene 守卫与"U→安全询问态"策略下，任何会降低硬安全余量的迁移都不可能被 U 触发。证明：降低安全余量的迁移其守卫必含 Γ_hard 项（P13）；Γ_hard 只由封闭度量求值，且 Kleene 语义下 U 与任意项合取不会得 T（T∧U=U，F∧U=F）；而迁移仅在守卫= T 时执行。开放词汇迁移若为 U 则归入 Ask，不执行动作。故最坏结果为活性损失（停留 Ask/当前态），可由操作员恢复，而非安全违背。∎

**引理 91（SSC 对 v9 的保守扩展 / 双模拟）** 当 OVG 关闭（全部开放命题为 U）且 E_safe 迁移移除，SSC 限制到封闭子图后与 v9 的模式复合（DistillFSM × 块生命周期 × 5 级退化链）双模拟。证明：构造关系 ℛ：SSC 的封闭态投影 = v9 模式元组；R_deg 与 5 级链逐态对应，R_distill 与定义 538 逐态对应，R_chunk 与定义 532–534 逐态对应；开放词汇迁移与 Ask 态在 v9 中无对应，故在 ℛ 下作为内部（τ）迁移被吸收，形成互模拟的 stuttering 步。因此可观测量与迁移序列一致，v9 行为被精确复现。∎

**引理 92（宣告完备 ⇒ 模式混淆为零）** 若 SSC 宣告完备（定义 546）且 L_ann ≤ L_react（人类反应界），则操作员的控制权威态推断与真实态一致，MC = 0。证明：宣告完备 ⇔ a_out 在"控制权威动作集不同"的态上单射；操作员据 a_out(s) 直接读出真实态类；延迟界保证推断在操作相关时间窗内完成。故不一致概率为 0。若宣告通道失效，则退化为无宣告，MC 上界回到 v9 水平。∎

## 8. 本轮最大风险

**一句话**：开放词汇的共形覆盖保证以"校准分布与部署分布可交换"为前提，而开放词汇的立身之本恰是处理校准分布之外的新概念——于是在最需要它的新指称上，覆盖保证静默失效；分层律（P13）只保住了碰撞/力限这类硬安全谓词，却保不住"抓错物体"这一语义层面的安全。
