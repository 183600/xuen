# 第 4 轮（新一轮灵感循环第 1 轮；承接第 3 轮 InstructGauge；本轮灵感：「痛点分析」×「步态规划」）

> **基线**：第 3 轮 InstructGauge（IP-321–327；定义 432–447；引理 51–58；实验 E441–E456）。第 2 轮 ToolGauge、第 1 轮 LeanGauge / MODGAUGE 骨架继续继承不变。
> 本轮纪律：**增量升级 + 严格退化**。痛点分析只升级「修谁、先修谁」的排序轴，步态规划只升级「何时测、怎么换位」的时序轴；两者都不扩物理可行域，任一环节不可用都必须能一键退回 InstructGauge。降级链：StrideGauge ⇒ InstructGauge ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE。

## 0. 直觉与动机

**灵感 1（痛点分析 → 从「信息增益最大化」到「决策相关痛感优先」）**
直觉：前几轮把每一个盲区都当成同等的探测机会，默认「多知道一点总是好的」。但真实修复现场不是这样：大量盲区从不改变任何下游决策，真正值得先修的是少数**高频出现、后果重、且会改变动作选择**的盲区。痛点分析的三个动作恰好补上这一层——**分诊**（按严重度 × 频度 × 决策耦合 × 不可逆性排序，而不是按信息熵）、**辨因**（区分症状与病根：探测有时只是止痛药，病根可能是标定漂移或夹具松动）、**用户口径**（以返工/下游决策损失计效果，不以「探测了多少次」计效果，避免虚荣指标）。关键纪律与第 3 轮语言层同构：**痛点只改「先修谁」，不改「能修什么」**，即只在安全等价类内重排，绝不扩大物理可行域。

**灵感 2（步态规划 → 从「块长 K 一个标量」到「接触时序 + 相位 + 步态模式」）**
直觉：第 3 轮的动作分块把复杂时序压缩成一个 K。腿式步态规划提醒我们，**什么时候测比一次测多少更重要**：只有支撑相（stance）才适合采样，摆动相（swing）只是换位；支撑多边形决定当前是否站得稳；左右腿交替天然给出交叉验证；地形一变就要换步态而不是硬走。映射到探测域：**落脚点 = 探测位置/工具接触点，支撑多边形 = 当前有效回执与契约的集合，捕获距离 = 漂移速度 × 反应时**。于是「块长 K」被升级为「步态模式 + 接触调度 + 相位」这个更丰富的时序对象：保守单步是 stand，交替独立探测是 trot，激进并行是 bound。这不仅是换名，而是把「证据新鲜度」从长度一维扩展为「长度 × 相位 × 支撑稳定性」三维。

**灵感 3（两者耦合 → 痛点决定去哪，步态决定怎么走而不摔）**
直觉：只追痛点会饿死「低痛但维持稳定」的维护步（复检、标定、契约刷新），让支撑集悄悄变空；而步态是周期性的，若步态周期与工件/扰动周期**通约**，采样混叠会把一个小偏差沿周期同相累积成系统性错误。再叠加一个风险：痛点权重可被注入伪造，造成资源饥饿。解法不是禁用二者，而是三根结构支柱：**分诊只排序**（痛点只在安全等价类内重排，优先级盾兜底）、**相位门控证据**（只有支撑相且已沉降的回执才入账）、**稳定性优先于覆盖率**（强制维护地板 + 每次步态迁移出稳定性证书）；再叠加**混叠守卫**（周期通约即抖动相位或错周期采样）与**痛点账本**（用实测下游损失校准声称痛点，防 Goodhart）。

## 1. 研究问题（本轮要回答什么）

- **Q1（痛点的可测性）**：盲区痛点能否被定义成可观测、可证伪的量，而不是拍脑袋的优先级？排序能否逼近真实下游损失，而不退化成「探测次数」这类虚荣指标？
- **Q2（步态的增益）**：接触时序与相位结构是否真的优于标量块长？相位门控能消掉多少采样偏差，稳定性证书能挡住多少「为赶进度而失稳」？
- **Q3（耦合的失稳与混叠）**：当痛点排序驱动步态，是否会出现「为追痛点清空支撑集」的失稳，或「周期采样 × 周期扰动」的混叠放大？能否用结构把二者压到可界？

## 2. 三条设计原则（雏形，正式化见产物区定义 448–459）

**P1 分诊只排序（Preference-Only Triage）**
痛点打分只能改变修复队列的顺序与预算分配，不能新增工具、不能放宽安全约束、不能把安全攸关项排到其下界之后。形式化方向：分诊算子是作用在既有可行计划集上的置换，`feasible(Tri(Π)) = feasible(Π)`；违反安全序一律夹紧并告警。这保证「痛点分析」不会变成新的越权通道。

**P2 相位门控证据（Phase-Gated Evidence）**
任何回执只有在「支撑相 + 瞬态已沉降」时才可进入数值路径；摆动相只允许产生「我到了哪个落脚点」这类位姿证据，不允许产生被测工件的计量结论。直观：脚还没踩稳就量，量到的是上一脚激起的振动，不是工件。

**P3 稳定优先于覆盖（Stability-First）**
排程必须为维护步保留强制地板 `f_min`；每次步态迁移必须通过稳定性证书（裕度 ≥ 捕获距离）；若证书失效，单调退化为 stand（等价逐步探测）或直接停。追痛点的收益永远不能以清空支撑集为代价。

## 3. 与基线的接口（如何退化）

- 痛点模型缺失 / 不可信 / 样本不足 ⇒ 均匀信息增益优先级，等价 InstructGauge 的 `ΔH(C)` 排序；
- 根因不可归因 ⇒ 退回「探测即治疗」的 InstructGauge 策略（不做 fix-vs-probe 路由）；
- 步态规划器不可用 / 地形平坦 / 单点作业 ⇒ stand 模式，等价 InstructGauge 逐步执行（K=1）；
- 稳定性证书不可计算或失效 ⇒ 强制 stand 或停机，绝不带病迁移；
- 相位无法识别 ⇒ 禁用门控并按保守量收紧 `δ_c`，退回第 3 轮 CVC；
- 混叠守卫失效 ⇒ 先抖动相位，再降采样频率，最后退回非周期调度；
- InstructGauge 失效 ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE 原样。

## 4. 预期贡献

1. 一个**决策相关痛点泛函**与**症状-根因归因图**，把「先修谁」从启发式变成可审计、可证伪的排序，并证明分诊只排序不扩权；
2. 一个**探测步态**时序对象（接触调度 × 相位 × 模式 × 支撑集），把第 3 轮的标量块长升级为带稳定性的结构化时序；
3. 一个**相位门控 + 混叠守卫**组合，把周期采样的系统性偏差从线性累积压到次线性/有界；
4. 一条完整可证伪路径：E457–E472 覆盖痛点排序效度、根因归因、虚荣探测抑制、步态稳定性、相位偏差、混叠、维护地板、对抗注入与 50Hz 时序保全。

## 5. 本轮最大风险

**一句话**：痛点只是「关于损失的估计」，而步态会把估计变成周期性的行动——一旦痛感口径被优化成代理指标（Goodhart），或步态周期与工件动力学通约形成混叠，系统就会**稳定地、可重复地反复测错地方**，这种系统性错误比随机错误更难被察觉。

## 2. 形式化定义（要点）

**定义 448（决策相关痛点泛函 Pain）** 对盲区 `s`，记 `sev(s)` 为其涉及目标的最坏后果归一化值、`freq(s)` 为其出现频率、`dec(s)=E[|ΔU_dec|]/ΔU_max` 为解析 `s` 后下游决策效用的期望改变、`irr(s)` 为所涉动作不可逆比例。定义
`Pain(s) = sev(s)·freq(s)·dec(s)·irr(s)`，并取稳健下界 `Pain_LB(s) = Pain(s) − z_β·σ_Pain(s)`。
关键：`dec(s)=0`（无论知道与否都不改变任何决策）的盲区痛点恒为 0——这是「虚荣探测」的过滤器。排序一律用下界，避免对高不确定痛点过度乐观。

**定义 449（症状-根因图与归因）** `G_RC = (V_S ∪ V_C, E)`，`V_S` 为可观测症状（某处持续超差、反复盲区），`V_C` 为候选病根（标定漂移、夹具松动、地图过期、工具磨损、真实几何缺陷）。`ρ_rc(c|s, receipts)` 为按回执更新的归因后验；`C*(s) = {c : ρ_rc(c|s) ≥ 1−β}`。若 `C*(s) ∩ C_ext ≠ ∅` 且本次探测不更新 `ρ_rc`，称该探测为**症状性探测（止痛）**。

**定义 450（分诊算子 Tri 与 ≻_pain）** `Tri: 2^{S_blind} × Θ → Π` 把盲区映射为修复队列 `Π`。要求：(i) `Tri` 只对既有可行动作集合做置换，`feasible(Tri(Π)) = feasible(Π)`；(ii) `≻_pain` 必须延拓安全序：若 `s ≻_safe s'`，则不得因痛点把 `s'` 排到 `s` 之前（除非二者同属一个安全等价类）。违反者夹紧并告警——分诊层不能成为新的越权通道（引理 59）。

**定义 451（探测步态 𝒢）** `𝒢 = (T_g, σ, δ_duty, 𝔽, mode)`：`T_g` 为步态周期；`σ: ℤ → 2^{𝒜_probe}` 为接触调度，`σ(t)` 是第 t 拍允许发生的探测动作集合；`δ_duty = |{t: φ_t=stance}|/T_g` 为占空比；`𝔽` 为落脚点（探测位置）集合；`mode ∈ {stand, walk, trot, bound}` 决定并发度与交叉验证结构：stand 单步单接触（K=1），walk 单支撑保守前进，trot 成对交替探测以获独立交叉验证，bound 高并发激进分块。`mode` 的并发度与块长受定义 440 的 `K ≤ K_MAX(ι)` 约束。

**定义 452（相位与证据门控 PEG）** 相位函数 `φ_t ∈ {stance, swing, transition}`。证据门控 `g_phase(t) = 1[φ_t = stance ∧ settle(σ_t)]`，其中 `settle` 为瞬态沉降判据。仅当 `g_phase(t)=1` 时，回执可进入契约校准等数值路径；`φ_t=swing/transition` 时只允许产生「落脚点/位姿」类证据，禁止产生被测工件计量结论。相位不可辨识时令 `g_phase≡1` 但按 `Δ_bias_max` 收紧 `δ_c`，退回第 3 轮 CVC。

**定义 453（稳定性裕度与捕获距离）** 记 `𝕊_t` 为 t 时刻仍有效且未陈旧的「回执 ∪ 契约」支撑集，`m_stab(t) = dist(𝕊_t, ∂𝕊_feasible)` 为信念空间中支撑集到可行边界的裕度；`d_cap(t) = v_drift^max(t)·τ_react + d_settle` 为捕获距离（漂移速度 × 反应时 + 沉降位移）。稳定性证书 GSC 要求在每次相位/模式迁移处 `𝕊_t ≠ ∅ ∧ m_stab(t) ≥ d_cap(t) + m₀`。

**定义 454（步态迁移自动机 A_gait）** 状态为 `mode × φ`；触发包括地形/表面变化、不确定性跃迁、痛点队列变更、GSC 失效。迁移规则：(i) 迁移只允许在 `φ_t = transition`（即已 drain 或按 `abort` 截断）时发生，禁止在 swing 中途切换契约；(ii) 每次迁移必须出新 GSC；(iii) GSC 失败时单调退化为 stand，除非停机。由此任何时刻都不会有「半条腿在旧步态、半条腿在新步态」。

**定义 455（痛点对齐接触调度 PACS）**
`𝒢* = argmax_{𝒢 admissible} [ Σ_s Pain_LB(s)·cover_s(𝒢) − λ_E·E(𝒢) − λ_T·T(𝒢) ]`
`s.t. GSC(𝒢)`、`floor_maint(𝒢) ≥ f_min`、`K ≤ K_MAX(ι)`、`Barrier(𝒢)`、`B_chunk ≤ B_left`。`cover_s(𝒢) ∈ [0,1]` 为步态在预算内解析痛点 `s` 的覆盖率，`E(𝒢)` 为换位/接触能耗，`T(𝒢)` 为周期时长。

**定义 456（强制维护地板）** `floor_maint(𝒢) = (1/|T|)·|{t : σ(t) 含维护步}|`，维护步包括复检、重标定、契约刷新、交叉验证。要求 `floor_maint(𝒢) ≥ f_min`；当痛点队列挤压维护步时，调度器按 `f_min` **抢占式保留**维护时隙。直观：支撑集是「站得住」的前提，不能为了多探几个痛点而让它变空。

**定义 457（相位混叠因子与守卫）** 设扰动/工件特征周期为 `T_d`，步态周期为 `T_g`。定义
`A_alias(T_g,T_d) = |(1/N)Σ_{n=1}^N exp(i2π n T_g/T_d)|`。
若 `A_alias > α_alias`（周期通约、采样总落在同一相位），AliasGuard 依次执行：抖动周期 `T_g ← T_g(1+ξ)`、随机化起始相位、错周期抽样。理想均匀抖动下相位偏差零均值，累积偏差由 `O(n)` 降为 `O(√n)`（引理 63）。

**定义 458（痛点-步态修复证书）** `PainGaitCert(s) = (Π_pain, ρ_rc, 𝒢, GSC, phase_receipts, claims)`，使人类审计可沿「痛点排序→根因判断→步态调度→相位回执→主张」五级证据链复现一次修复。

**定义 459（痛点账本与实现率）** `realized_pain = 实测下游决策损失下降`，`claimed_pain = Σ_s Pain_LB(s)·cover_s`，`achievement = realized_pain / max(claimed_pain, ε)`。当 `achievement < a_min` 连续 `q` 次 ⇒ 痛点模型进入隔离/重标定（与 P-Quarantine 共用断路器），防止代理指标自洽而实际无效。

## 3. 关键算法骨架

```python
# IP-328/329 痛点分诊 + 根因归因（只排序、只路由，不扩权）
class PainTriage:
    def score(self, s, records):
        a = self.attrs(s, records)                      # sev, freq, dec, irr
        pain = a.sev * a.freq * a.dec * a.irr           # dec=0 ⇒ pain=0
        return max(0.0, pain - Z_BETA * self.sigma(s))

    def triage(self, blind_spots, records, safety_order):
        queue = sorted(blind_spots,
                       key=lambda s: (-self.score(s, records),
                                      safety_rank(s, safety_order)))
        # 只置换；任何安全序反转都被 safety_rank 夹回
        return self._clamp_to_safety_order(queue, safety_order)

    def route(self, s, rho_rc):
        causes = {c for c, p in rho_rc.items() if p >= 1 - BETA}
        if causes & C_EXT:                              # 病根在外（标定/夹具/地图）
            return Route.RECALIBRATE, causes            # 先治本，不做症状性探测
        return Route.PROBE, causes

# IP-330 SGP：模式选择 + 接触调度（步态升级块长）
class GaitPlanner:
    def plan(self, pain_queue, terrain, uncertainty, iota):
        mode = self.select_mode(terrain, uncertainty, iota)   # stand/walk/trot/bound
        T_g  = self.period(mode, uncertainty)
        sigma, footholds = self.contact_schedule(pain_queue, mode, T_g)
        g = Gait(T_g=T_g, sigma=sigma, duty=self.duty(mode),
                 footholds=footholds, mode=mode)
        if not self.floor_ok(g, F_MIN):                # 维护地板不足
            g = self.reserve_maintenance(g, F_MIN)     # 抢占式保留维护时隙
        if not self.gsc.certify(g):                    # 稳定性不达标
            g = self.degrade_to_stand(g)               # 单调退化 ⇒ InstructGauge
        if self.alias.score(g.T_g, self.T_d) > ALPHA_ALIAS:
            g = self.alias.dither(g)                   # 抖动/错周期，避免混叠
        return g

# IP-331 GSC：相位/模式迁移前的稳定性证书
class GaitStabilityCert:
    def certify(self, g):
        for t in g.transition_points():
            S = self.support_set(t)                    # 有效回执 ∪ 契约
            d = self.drift_speed(t) * TAU_REACT + self.settle_disp(t)
            if not S or self.margin(S) < d + M0:
                return False
            self.emit_cert(g, t, margin=self.margin(S), d_cap=d)
        return True

# IP-332 PEG：相位门控提交
def phase_gated_commit(g, env, iota):
    receipts = []
    for t in g.window():
        if not g.g_phase(t):                           # swing/transition 不入账
            receipts.append(PoseOnly(t)); continue
        y = env.measure()
        if settle(env, g) and not drifting(env, g):
            receipts.append(Receipt(t, y, phase="stance"))
    return receipts

# IP-334 AliasGuard：周期通约检测与抖动
class AliasGuard:
    def score(self, T_g, T_d):
        n = 1
        return abs(sum(exp(2j*pi*i*T_g/T_d) for i in range(1, N_ALIAS+1)) / N_ALIAS)

# IP-335 StrideGauge-8C：P→I→H→C(gait)→E(phase)→C(CVC)→V→U
def stridegauge_8c(M, s, ell):
    Pq   = M.triage.triage(M.dbox.detect_blind_spot(), M.records, M.safety_order)
    s    = Pq[0] if Pq else s
    route, causes = M.triage.route(s, M.rca.posterior(s))
    if route is Route.RECALIBRATE:
        return M.recalibrate(causes)                   # 先治本，不探测
    out  = M.nlib.ground(ell, M.scene, M.ontology)
    iota = out[0] if out else M.default_iota
    H    = M.lbox.hypothesize(s, M.dbox.R[s], iota)
    g    = M.gait.plan(Pq, M.terrain(s), M.uncertainty(s), iota)
    y    = phase_gated_commit(g, M.env, iota)          # 相位门控证据
    C    = M.iac.plan_chunk(iota, H, M.tools, M.budget_left(s),
                            M.drift_bound(s), gait=g)  # 块长受步态时序约束
    cert = M.cvc.commit(C, M.env, iota)
    receipts = y + cert.receipts
    if len(receipts) < n_min(s):
        return stub_and_red(s, "insufficient")
    mu, Sig = M.apcal.calibrate(receipts, H, s)
    if not M.apcal.cross_validate(mu, Sig, M.cross_receipt(s)):
        return stub_and_red(s, "cross_failed")
    new_ec = M.apcal.update_contract(M.dpe, mu, Sig, s)
    if not contract_regression(new_ec):
        return stub_and_red(s, "regression")
    M.mreg.hot_replace_at_quiescence(M.dpe, new_ec, cert.boundary)
    M.ledger.record(claimed=Pain_LB(s), realized=realized_pain(s, receipts))
    if M.ledger.achievement(s) < A_MIN:
        M.pquar.quarantine("pain_model")
    return True

# IP-335 主闭环（50Hz 路径不变）
def StrideGauge_round(M, obs, audio, tac, depth, det, ell=None):
    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight:
            M.inflight.add(s)
            submit_async(stridegauge_8c, M, s, ell)
    return InstructGauge_round(M, obs, audio, tac, depth, det, ell)
```

## 4. 推导

**引理 59（分诊只排序不扩权）** 若 `Tri` 仅对既有可行动作集合做置换，且 `≻_pain` 延拓 `≻_safe`，则 `feasible(Tri(Π)) = feasible(Π)`，且任何安全不变式在分诊前后保持不变；特别地 `Plan(Tri(Π)) ⊆ Plan_InstructGauge`。*证明*：置换不改变集合；安全序约束保证任何安全攸关项仍先于/不低于其下界；故可行域与安全类不变。推论：痛点层不能新增工具、不能放宽幅值、不能绕过不可逆屏障。

**引理 60（症状性探测的信息价值上界）** 若 `C*(s)` 中外部病根质量为 `ρ_ext = Σ_{c∈C_ext} ρ_rc(c|s)`，且探测只更新真实几何参数 `θ` 而不改变 `c`，则
`EVOI(probe) ≤ (1−ρ_ext)·ΔH_max − c_probe`。
故当 `ρ_ext` 足够大时，先重标定/紧夹具的期望收益严格优于继续探测。*证明*：外部病根不变时，探测对 `c` 的后验无更新；只有 `1−ρ_ext` 的「真实缺陷」分支能获得信息增益，取上界 `ΔH_max` 即得。这是「治本优先」的定量依据，由 E458/E459 检验。

**引理 61（步态稳定不变量）** 若每次相位/模式迁移处 GSC 成立（`𝕊_t ≠ ∅` 且 `m_stab ≥ d_cap + m₀`），且迁移只在 `transition` 相位发生，则覆盖/契约不变式 `Inv` 在所有时刻保持；若 GSC 失败触发 stand，则 `Inv` 仍保持且系统逐指令等价于 InstructGauge 的逐步执行。*证明*：对迁移次数归纳。迁移间隙内支撑集不变、漂移由 `d_cap` 界住，故 `Inv` 保持；stand 模式 `σ(t)` 为单步单接触，与第 3 轮 CVC 逐步提交逐指令对齐。

**引理 62（相位门控的偏差界）** 设回执 `y = θ + b(φ, τ) + ε`，`b` 为相位/沉降相关偏差。若支撑相窗口满足 `settle`，则 `|b_stance| ≤ B_s`；摆动相采样偏差满足 `|b_swing| ≥ B_s` 且通常更大。门控后的均方误差改善满足
`MSE_ungated − MSE_gated = E[b_swing²] − E[b_stance²] ≥ 0`。
相位不可辨识时以 `Δ_bias_max` 收紧 `δ_c`，可保证不因门控缺失而放宽安全界。由 E462 检验。

**引理 63（混叠累积与抖动上界）** 若 `T_g/T_d = p/q` 为有理数且采样固定于同一相位，则偏差同相累积 `|B_n| = n·|b_alias|`（线性）。若起始相位在 `[0,T_g)` 上均匀抖动，则 `E[B_n]=0`，`Var(B_n) ≤ b_alias²/n`，故典型累积为 `O(√n)`；以随机周期抖动可在高概率下得到同阶界。由 E463 检验。

**引理 64（痛点覆盖的次模近似）** `cover_s(𝒢)` 是「被步态访问并解析的痛点集合」上的单调次模覆盖函数。无维护地板时贪心调度满足 `cover ≥ (1−1/e)·OPT`；当强制维护占用预算比例 `f_min` 时，可用预算降为 `1−f_min`，故 `cover ≥ (1−1/e)(1−f_min)·OPT`。*证明*：标准次模贪心 + 预算截断；维护地板的占用是确定性扣减。

**引理 65（稳定-痛点权衡无免费午餐）** 若维护地板约束紧（`floor_maint=f_min`），则周期内最多 `(1−f_min)` 比例用于痛点探测，`max cover ≤ (1−f_min)·cap`。若强行提高痛点覆盖而增大并发或块长，则由 `d_cap` 增大导致 GSC 收紧，必须降速或提高占空比，二者都增加 `T(𝒢)` 或 `E(𝒢)`。存在影子价格 `λ_floor > 0` 刻画该权衡。由 E465 检验。

**引理 66（摊销、50Hz 与退化等价）** 分诊/步态规划/混叠检测均在异步路径，主循环内联仅新增 O(1) 相位门控与支撑集查询，新增周期 `< 0.2ms`；`mode=stand` 时 `σ` 退化为单步、`K=1`，逐指令等价于 InstructGauge；`PainGaitCert` 中新字段均为纯投影，不改变数值行为；热替换等价回到第 3 轮引理 57。继承 ToolGauge 引理 50 的硬实时结论。
