# 第 10 轮（灵感循环第 2 轮；本轮灵感：「四足机器人」×「激光雷达」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**换身体、换传感器，但不换安全论证骨架**。两个灵感不是给 v9 再挂两个模块，而是暴露 v9 里两个被"轮式底盘 + 理想深度传感器"偷偷假设掉的前提：(a) 安全停驻 = 刹车距离；(b) 间隙 = 最小欧氏距离。四足机器人证伪 (a)：腿式系统在腾空相**刹不住车**，只能"落步—支撑—站定"；激光雷达证伪 (b)：最小距离只在**被观测到的方向**上成立，盲区里"没测到障碍"与"没有障碍"是两件事。故 v10 的核心动作是：把这两个隐藏假设**显式化为证书条件**，并用中立元保证任一条件缺失时严格退回 v9。

## 0. 直觉与动机

**灵感 1（四足机器人 → 从"刹车"到"落步"）**
直觉：v9 的中止点 p 满足 `d_brake(v_p) + d_safe ≤ 剩余间隙`，这行不等式默认了一个连续可减速的执行器。四足在 trot 的腾空相里没有任何可施加的制动力——它只能在**可停相位**把摆动腿放下、进入四足支撑、再站定。于是"安全停驻"从一维距离约束变成**离散落脚序列的存在性**。核心创新：**步态块证书器（GaitChunkCertifier, GC）**：决策单元从 tick-chunk 升为 stride-chunk；中止点集从"任意前缀"收紧为"可停相位"；证书新增**动态稳定裕度**（XCoM 到支撑多边形的距离）与**滑移裕度**（摩擦锥）。副产品是"减速"的离散对应物——**步态阶梯** trot→walk→stand，而不是调一个连续速度标量。

**灵感 2（激光雷达 → 从"间隙"到"可见自由空间"）**
直觉：v9 的 `ĝ_min = min F̂_clearance − β` 把感知当成全向且访问即真的距离场。真实 LiDAR 有三件事：视场有盲区（近场下视、机身后方、腿间自遮挡）、几何会退化（长走廊里沿轴向约束近乎消失）、扫描会随运动畸变。核心创新：**视域可通行性证书器（LiDARVisibilityCertifier, LVC）**：证书变成一个多元组 `(ρ_dir, d_vis, λ_deg, ε_deskew, ν_neg)`——方向覆盖率、已观测最小自由距离、扫描匹配退化指数、去畸变残差、负障碍可分性。关键语义翻转：**未观测不等于自由**；规划只允许走在"已观测自由集的闭包"内，证书是对闭包的陈述而不是对世界的陈述。附**主动探测**：覆盖率不足时先转头/侧移"看一眼"再承诺动作块。

**交叉灵感（真正的创新点，不是两个模块的拼接）**
直觉：LiDAR 固连机身，四足的机身姿态在一个步态周期内周期性俯仰/横滚；而姿态又由步态决定。所以"能看见什么"是"打算怎么走"的函数——**感知证书必须前移到规划期**。核心创新：**姿态-视域耦合器（AttitudeFOVCoupler, AFC）**：用步态预测的姿态包络 Θ_t 计算覆盖率**下界** ρ̂ = min_{θ∈Θ_t} ρ_dir(θ)，证书用 ρ̂ 而非瞬测 ρ；若 ρ̂ 不足，规划器必须选一个"机身更稳、看得见落脚点"的步态，或插入探测动作，而不是先走再补看。再配**相互退化仲裁器（MutualDegradationArbiter, MDA）**：LiDAR 退化（长走廊/玻璃/黑绒）⇒ 降速 + 接触辅助腿式里程计接管定位；稳定裕度不足 ⇒ 借 LiDAR 地形扩大支撑面/改落脚。两条退路互为备份，且每级都声明中立元。

## 1. 研究问题（轮次升级版）

- **Q1（离散停驻安全）**：当停驻被建模为"至多 N_stop 步的静态稳定落脚序列"时，块级证书与中止点集在什么条件下给出与 v9 逐步执行相同的安全保证？"无点可退"在新语义下对应什么、是否只发生在终端站立态？
- **Q2（视域证书的保守性与可证伪性）**：方向覆盖率 + 退化指数 + 去畸变残差能否构成一个**集合保守**的自由空间证书（valid ⇒ 不进入未观测区），而不是一个"大概率没撞"的概率陈述？λ_deg 跌破阈值时如何退化而不说谎？
- **Q3（姿态-视域包络的可靠性）**：步态预测的姿态包络 Θ_t 能否在扰动下覆盖真实姿态？当稳定裕度下降时，Θ_t 是否恰好被撑破——即稳定证书与视域证书是否**相关失效**？
- **Q4（相互退化的等价性）**：GC/LVC/AFC/MDA 任一缺失时，注入的中立元能否使可观测行为逐位退回 v9（乃至 v8/v7）？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 步态停驻律（Gait-Stop, GC）**
中止点 p 必须落在可停相位集 Φ_stop(g) 内，且满足**步态停驻不变式**：存在至多 N_stop(v_p) 步的停驻序列 σ，其每个落脚点可支撑（地形/摩擦/运动学）、每个中间支撑相 ξ_m ≥ ξ_safe、终端为静态四足站立且距已观测障碍 ≥ d_safe。停机不是距离不等式，而是**离散序列的存在性**；无可行 σ 的候选块直接拒绝。

**P14 可见自由空间律（Observed-Free-Space, LVC）**
路径必须包含在已观测自由集 F_t 的闭包内；未观测方向按"占据"处理。证书有效 ⇔ `ρ_dir ≥ ρ_min ∧ d_vis ≥ d_safe ∧ λ_deg ≥ λ_min ∧ ε_deskew ≤ ε_max ∧ ν_neg ≥ ν_min ∧ 扇区龄 ≤ τ_age`。视场盲区里的危险不被"最小距离很大"抵消，因为那里的距离根本没被测量。

**P15 相互退化仲裁律（Mutual Degradation, MDA）**
步态阶梯 Γ_g（trot→walk→stand）与感知阶梯 Γ_p（LiDAR-SLAM→LiDAR+腿式里程计→纯腿式里程计）按触发谓词耦合推进；任一模组缺失注入中立元，MDA 本身缺失则两阶梯退化为互不耦合的 v9 独立链。**只允许沿安全格点下行，不允许上行**。

## 3. 与基线的接口（如何退化）

- GC 失效（前向模型超差 / 无可行停驻序列 / 连续证书失效）⇒ 退回 v9 tick-chunk，用 v9 刹车距离不变式，等价 v9 决策粒度与中止语义；
- LVC 失效 ⇒ 注入 v^⊥ = (ρ_dir≡1, λ_deg≡1, ε_deskew≡0, ν_neg≡1, age≡0)，多元组合取交集后**恰好还原** v9 的 `ĝ_min ≥ d_safe` 单一条件（引理 90）；
- AFC 失效 ⇒ 用当前实测姿态代替预测包络（Θ_t 退化为单点 θ(t)），即"当拍感知"，等价 v9；
- MDA 失效 ⇒ Γ_g 与 Γ_p 解耦，各自按 v9 独立退化链执行；
- v9 的 AC/MW/ID 失效 ⇒ 按 v9 定义 536 注入中立元，退回 v8；
- v8 的 DA/SPR/Cal 失效 ⇒ 退回 v7；全部失效 ⇒ v6。

## 4. 预期贡献

1. **步态块证书**：把"安全停驻"从连续制动重写为离散落脚序列的可达性证书，首次让四足的动作分块与安全论证在同一坐标系里闭合（引理 87）；
2. **可见自由空间证书**：把 LiDAR 的盲区、退化、畸变统一成一个集合保守的多元证书，并给出"未观测 ≠ 安全"的可证伪判据（引理 88）；
3. **姿态-视域耦合**：把感知证书前移到步态规划期，用姿态包络给出覆盖率下界，并诚实暴露其与稳定裕度的相关失效风险（引理 89 + 本轮最大风险）；
4. **相互退化格**：两条阶梯的耦合仲裁与中立元等价（引理 90–92），使换身体/换传感器不破坏 v6→v9 的严格退化链。

## 5. 本轮最大风险

**一句话**：姿态-视域耦合证书的保守性依赖"步态预测的姿态包络 Θ_t 覆盖真实姿态"，而稳定裕度下降时真实姿态恰恰最容易冲出包络——于是**稳定证书与视域证书在同一个扰动下同向失效**，二者的联合置信度被高估，系统可能在最需要看清落足点的那一步，用一个已经失效的视域下界去批准一块落在未观测区域的"安全"停驻。

# 第 10 轮产物 · 创新点清单 v10：**MetricVoiceGauge-QGV**（Metric Voice Gauge with Quadruped Gait-Stop certificates & LiDAR Visibility certificates）

> 背景：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮灵感：「四足机器人」×「激光雷达」
> **继承纪律**：MetricVoiceGauge 九不变式（CVC-闭环、SpatialCert、RT-CVC、FaultCert、PrimitiveGraph、严格退化链、OTL、GCT、ER）全部保留；v9 的 AC/MW/ID 三模块原样继承。新组件一律为**可选增强**：任一环节不可用 ⇒ 注入中立元，严格等价退回 v9 行为（引理 90），而非行为漂移。**v10 不新增安全论证，只把 v9 的两个隐藏执行器假设显式化。**

## 1. 符号体系增量（定义 540–549）

**新增定义 540（步态块 GaitChunk）** 一次运动决策的输出单元：ζ_t^g = (g_t, F_t^{1:K}, Ĉ_t^g, P_t^stop, π_t^probe)。g ∈ {stand, walk, trot} 为步态；K = K_eff^g(t) ≤ K_max^g = 4 个步幅（一个 trot 步幅 ≈ 0.4s，4 步 ≈1.6s 时域）；块在 2–5Hz 生成，逐相位执行。**v9 的 tick-chunk 是 K=1、g=stand 的特例。**

**新增定义 541（动态稳定裕度 DynamicStabilityMargin）** 对计划中的每个支撑相 k，令外推质心 XCoM_k = x_com + v_com/ω₀（ω₀=√(g/z_com)），支撑多边形 P_k 由计划落脚点张成：
```
ξ_k = dist(XCoM_k, ∂P_k) − η_v·‖v_com‖
ξ_min = min_k ξ_k ，  滑移裕度 ζ_k = μ − ‖F_t,k‖/F_n,k
```
证书要求 ξ_min ≥ ξ_safe 且 ζ_min ≥ ζ_safe。ξ 用**计划**支撑面算，不用当前支撑面——这使"即将落下的那只脚"进入证书。

**新增定义 542（可停相位与步态停驻不变式 Gait-Stop Invariant）** 可停相位集 Φ_stop(g) ⊆ [0,1) 是步态周期中能在一个步幅内进入四足支撑的相位。中止点 p 只允许取在 φ(p) ∈ Φ_stop(g) 的前缀上，且
```
G_stop(p) ⇔ ∃ σ ∈ Seq_{≤N_stop(v_p)}:
   (i)   σ 的每个落脚点可行：η_f ≥ η_safe 且 f ∈ F_t（已观测自由闭包）
   (ii)  每个中间支撑相 ξ_k ≥ ξ_safe 且 ζ_k ≥ ζ_safe
   (iii) 终端为静态四足站立（v=0，b_com ∈ conv(supports)）
   (iv)  dist(terminal, O_obs) − |traj_{p:terminal}| ≥ d_safe
```
**注意与 v9 定义 534 的差异**：v9 用连续刹车距离 d_brake(v_p)；v10 用离散 N_stop(v_p) 与落脚序列存在性。两者在 g=stand（K=1）时一致，这就是退化锚点。

**新增定义 543（落脚可行性证书 FootholdCertificate）** 候选落脚点 f=(x,y) 的可行性：
```
η_f = min{ slope_margin(f), rough_margin(f),
           friction_margin(f), kinematic_margin(f), neg_obs_margin(f) }
```
其中 `neg_obs_margin` 要求该点下视扇区已被观测且 ν_neg ≥ ν_min；**未观测点 f ∉ F_t 一律不可行**（即使地形预测看似平坦）。落脚点不可"猜"，只能"看"。

**新增定义 544（视域可通行性证书 VisibilityTraversability）**
```
Ĉ_t^vis = (ρ_dir, d_vis, λ_deg, ε_deskew, ν_neg)
ρ_dir = |{s ∈ S_req : a(s) ≤ τ_age 且 s 已观测}| / |S_req|
d_vis = min{ dist(x, ∂O_obs) : x ∈ 已观测自由区 }，未观测区不计入 d_vis（由 ρ 记账）
```
S_req 为必测方向扇区（前向 ±60°、近场下视 ±40°、双侧近场、后方 90°）。证书有效 ⇔
```
ρ_dir ≥ ρ_min ∧ d_vis ≥ d_safe ∧ λ_deg ≥ λ_min
∧ ε_deskew ≤ ε_max ∧ ν_neg ≥ ν_min
```
**集合语义**：valid ⇒ 规划路径 ⊆ F_t（已观测自由集）的闭包，而未观测区被视作占据。故本证书是"对闭包"的陈述，不是"对世界"的陈述——这是它可证伪、可审计的原因，也是它的边界（引理 88 的适用条件）。

**新增定义 545（姿态-视域耦合 Attitude-FOV Coupling）** LiDAR 固连机身系 F_L，世界视域 = R(θ_body)·F_L。块内由步态模型给出预测姿态 θ̂^{1:K}，并附稳定相关膨胀 δ_stab(k) ∝ (1−ξ_k/ξ_safe)：
```
Θ_t = { θ : ‖θ − θ̂^k‖ ≤ δ_stab(k),  k ≤ K }
ρ̂_dir(t) = min_{θ ∈ Θ_t} ρ_dir(θ)
```
证书一律用 ρ̂_dir；规划选择 (g, K, 落脚) 使 ρ̂_dir ≥ ρ_min。若不存在，则按 P15 降阶梯或插入探测。**耦合算子 C: (g, ξ-budget) → ρ̂** 是 v10 的核心接口。

**新增定义 546（相互退化仲裁 MutualDegradationArbiter）**
```
Γ_g : trot → walk → stand
Γ_p : LiDAR-SLAM → LiDAR + leg-odom → leg-odom only
触发：
  λ_deg < λ_min  ∨  ρ̂_dir < ρ_min     ⇒ Γ_p ↓，且 Γ_g ↓（降速换稳定/覆盖率）
  ξ_min < ξ_safe                       ⇒ Γ_g ↓；若 ρ̂ 不足则 stand + probe
  ε_deskew > ε_max (速度导致)          ⇒ Γ_g ↓（降速）
中立元：MDA 缺失 ⇒ Γ_g、Γ_p 解耦，各自 v9 独立退化。
```

**新增定义 547（步态阶梯 GaitLadder）** 有序集带不变式：`risk(g_{i+1}) ≤ risk(g_i)`，其中 risk 同时度量姿态摆幅（影响 ε_deskew 与 ρ̂）与 XCoM 速度（影响 ξ）。stand 为终端：姿态摆幅=0 ⇒ ε_deskew=0、Θ_t 退化为单点 ⇒ ρ̂=ρ，且步态诱发风险为 0。阶梯只能下降，返回上层需离线/显式证据（避免抖动，沿用 v9 引理 85 的迟滞思想）。

**新增定义 548（主动探测动作 ProbeAction）** π_probe ∈ {转头/转躯干 yaw ±ψ, 侧移半步}，代价 c_probe，收益 Δρ(s)。承诺规则：
```
commit ζ^g  ⇔ ρ̂_dir ≥ ρ_min
否则 probe（≤ N_probe 次）→ 重算 ρ̂ → 仍不足则 Γ_g ↓ 至 stand
```
探测把"信息获取"变成与"移动"同级的动作，且其自身必须满足当前支撑稳定（probe 时 ξ ≥ ξ_safe）。

**新增定义 549（视域更新龄与陈旧证书 Visibility Age）** 动态障碍可能在你"看过"之后进入盲区。故扇区 s 的证书有效期由龄 a(s) ≤ τ_age 约束；超龄扇区按未观测计入 ρ。这把 v9 的"当拍观测"推广为"带时效的观测"，也是 LVC 与 v9 感知接口的兼容点（τ_age→0 即当拍）。

**升级定义 539（有效块长门控，v10 步幅版）**
```
K_eff^g(t) = 1                                       若 U_t 不成立或 ρ̂_dir < ρ_min
           = max(1, ⌊K_max^g·(1−Δ_dom/τ_dom)·ρ̂_dir⌋)  否则
```
K 的单位从 tick 变为 stride；K_eff^g=1 ∧ g=stand 恰好是 v9 tick-chunk。

## 2. 形式化定义（要点与升级）

**定义 493（六层指标层级）** 继承 v8：M=(M₀,M₁,M₂,M₃,M_dom,M_SLAM) 不变。
**定义 495/524（MetaWeight/情感）** 继承 v8 不变。
**定义 521（DA-OTL）** 继承 v9；τᵢ(t) 在 stride-chunk 内用块证书替代逐层逐步复核。
**升级定义 496（软证书，v10）** 触发条件扩为六元：
```
δ_trigger = {σ < τ_safe ∧ γ_grasp valid ∧ Δ_dom < τ_dom
             ∧ risk_SLAM < τ_SLAM
             ∧ Ĉ_t^g valid（含 ξ_min、η_min）
             ∧ Ĉ_t^vis valid（含 ρ̂_dir、λ_deg）}
```
任一项失败即触发 M₀ 硬检查，且**不得**用其他项的"看起来更宽松"抵消——多证书取交集，不取加权平均。
**升级定义 531（软硬约束衔接）** M₀ 增加两个块级入口：(a) 中块稳定裕度违规 ⇒ 切换到 p*∈P^stop 并执行 π_stop；(b) 视域证书失效（ρ̂ 跌破或 λ_deg 跌破）⇒ 立即降速+探测，未恢复则 stand。

# IP-357 GaitChunkCertifier：步态块证书器（把 v9 的"刹车"换成"落步"）
class GaitChunkCertifier:
    def __init__(self, gait_model, F_hat, K_max=4, beta=0.02,
                 d_safe=0.15, xi_safe=0.06, eta_safe=0.5, N_stop_max=3):
        self.G, self.F = gait_model, F_hat   # 步态动力学模型 + 指标前向代理
        self.K_max, self.beta, self.d_safe = K_max, beta, d_safe
        self.xi_safe, self.eta_safe = xi_safe, eta_safe
        self.N_stop_max = N_stop_max

    def steps_to_stop(self, v):
        return min(self.N_stop_max, max(1, math.ceil(v / self.dv_step)))

    def generate_chunk(self, state, dom, trust_ok, vis):
        K = self.effective_K(dom, vis, trust_ok)      # 定义 539'，单位=步幅
        if K == 1:
            return self._stand_or_single_step(state)  # = v9 tick-chunk
        best = None
        for g in self.gait_ladder(state, upto=K):     # trot/walk 候选
            for F in self.G.sample_footholds(state, g, K, n=48):
                if not all(self.foothold_ok(f, vis) for f in F):
                    continue                          # 定义 543：未观测点不可行
                pred = self.G.rollout(state, g, F)     # 姿态+指标轨迹
                xi = min(self._xcom_margin(pred))
                if xi < self.xi_safe:
                    continue
                vis_pred = self.AFC.predict_coverage(pred.attitude)  # 定义 545
                if vis_pred < state.rho_min:
                    continue
                cert = Cert(g_min=pred.min_clearance - self.beta,
                            xi_min=xi, eta_min=min(map(eta, F)),
                            rho_min=vis_pred)
                if cert.g_min < self.d_safe:
                    continue
                P = self._stoppable_prefixes(state, g, F, pred)
                if not P:
                    continue                          # 无停驻序列 ⇒ 拒绝
                if best is None or self.score(cert) > best.score:
                    best = GaitChunk(g, F, cert, P)
        return best or self._stand_or_single_step(state)

    def _stoppable_prefixes(self, state, g, F, pred):
        pts = []
        for p in range(1, len(F)):
            if self.phase_of(g, p) not in PHI_STOP[g]:
                continue                              # 只能在可停相位退
            seq = self.G.stop_sequence(pred, p, self.steps_to_stop(pred.v[p]))
            if seq and all(self.foothold_ok(f, pred.vis) for f in seq) \
               and self._static_stable(seq.terminal) \
               and self._clearance_ok(seq.terminal, pred):
                pts.append(p)                         # 定义 542 的 G_stop(p)
        return pts

    def midchunk_guard(self, chunk, phase, live):
        """相位级廉价守卫：证书时效 + 稳定裕度 + 视域龄"""
        if self.age_exceeded(chunk, live) or not chunk.cert_valid(live):
            return ('abort', self._nearest_stoppable(chunk, phase))
        if live.xi < self.xi_safe or live.rho_hat < self.rho_min:
            return ('abort', self._nearest_stoppable(chunk, phase))
        return ('continue', next_phase(chunk, phase))


# IP-358 LiDARVisibilityCertifier：视域可通行性证书器
class LiDARVisibilityCertifier:
    def __init__(self, tau_age=0.3, rho_min=0.8, lam_min=0.02,
                 eps_max=0.03, nu_min=0.5):
        self.tau_age, self.rho_min = tau_age, rho_min
        self.lam_min, self.eps_max, self.nu_min = lam_min, eps_max, nu_min
        self.sector_age = {s: INF for s in S_REQ}

    def update(self, cloud, imu, leg_odom, t):
        desk = self._deskew(cloud, imu, leg_odom)     # 去畸变
        self.F_t, self.O_obs = self._freespace(desk)   # 已观测自由闭包 + 占据
        for s in S_REQ:
            if self._observed(s, desk):
                self.sector_age[s] = 0.0
            else:
                self.sector_age[s] += self.dt
        H = self._scan_match_info(desk)                # Σ n nᵀ
        lam = self._eigen_ratio(H)
        return VisibilityCert(rho=self._coverage(), d_vis=self._d_vis(),
                              lam=lam, eps=self._deskew_residual(),
                              nu=self._neg_obs_margin())

    def valid(self, c, pose_envelope):
        rho_hat = self.attitude_lower_bound(pose_envelope)   # 定义 545
        return (rho_hat >= self.rho_min and c.d_vis >= self.d_safe
                and c.lam >= self.lam_min and c.eps <= self.eps_max
                and c.nu >= self.nu_min
                and max(self.sector_age.values()) <= self.tau_age)


# IP-359 AttitudeFOVCoupler：姿态 → 视域下界
class AttitudeFOVCoupler:
    def predict_coverage(self, attitude_hat, delta_stab):
        worst = +INF
        for th in envelope_corners(attitude_hat, delta_stab):
            worst = min(worst, self._coverage_at(th))
        return worst                                   # ρ̂ = min_{θ∈Θ} ρ_dir(θ)


# IP-360 MutualDegradationArbiter：两条阶梯的耦合仲裁
class MutualDegradationArbiter:
    def arbitrate(self, vis, stab, cmd):
        level_p, level_g = self.cur_p, self.cur_g
        if vis.lam < self.lam_min or vis.rho_hat < self.rho_min:
            level_p = min(level_p + 1, len(GAMMA_P) - 1)   # 感知降级
            level_g = min(level_g + 1, len(GAMMA_G) - 1)   # 同时降速
        if stab.xi < self.xi_safe:
            level_g = min(level_g + 1, len(GAMMA_G) - 1)
            if vis.rho_hat < self.rho_min:
                return ('probe', cmd)                       # 站定+探测
        return (GAMMA_G[level_g], GAMMA_P[level_p])

## 4. 推导

**引理 87（步态块停驻安全性）** 设块内满足：(i) 指标前向模型一致误差 ‖F̂−F‖∞ ≤ β_true ≤ β；(ii) 姿态/稳定预测误差 ≤ β_ξ；(iii) 落脚可行性证书在已观测地形上 sound（观测到的坡度/摩擦/负障碍不优于真值）；(iv) 步态跟踪误差被 β_ξ 吸收。则 (a) 证书 valid ⇒ ∀k≤K 真实间隙 g_k ≥ ĝ_min ≥ d_safe 且 ξ_k ≥ ξ_safe；(b) 若块内真实间隙或稳定裕度跌破安全界，则存在 p*∈P^stop 使 G_stop(p*) 成立，执行 π_stop(p*) 在 ≤N_stop(v_{p*}) 步内到达静态四足站立且终点距已观测障碍 ≥d_safe。证明：(a) 同 v9 引理 82(i) 的误差传播，ξ 用 (ii)+(iv) 的界；(b) P^stop 的构造保证每个 p 都有满足定义 542 的停驻序列；跟踪误差被 β_ξ 吸收后不变式仍成立；对步数归纳，每步 XCoM 速度严格下降且 ξ≥ξ_safe，故 N_stop 步内 v→0 且静态支撑多边形包含 b_com；终点间隙由 (iv) 与 β 余量保证。∎
> 与 v9 的本质区别：v9 用连续制动距离，v10 的"刹车"消耗步数且必须落脚在**已观测可行点**上——这正是四足与轮式不可互换的地方。

**引理 88（视域证书的集合保守性）** 设未观测区按占据处理（保守闭包），且 λ_deg ≥ λ_min 蕴含扫描匹配位姿误差 ≤ e(λ_min)，ε_deskew ≤ ε_max 蕴含点位移 ≤ δ_p。则证书 valid ⇒ 规划路径包含于已观测自由集 F_t 的闭包内，且路径到 ∂F_t 的距离 ≥ d_safe − (e(λ_min)+δ_p)。故任何真实间隙 < d_safe 的障碍，若在已观测区则被 d_vis 检出，若在未观测区则路径根本不允许进入（ρ 条件强制 invalid）。证明：路径 ⊆ Cl(F_t) 由规划器约束给出；F_t 内障碍距离由 d_vis 给出并减去匹配/去畸变误差上界；未观测区进入与 ρ_dir ≥ ρ_min ∧ 扇区龄 ≤ τ_age 矛盾。∎
> 诚实边界：这不是"世界无碰撞"的证明，而是"不进入未观测区"的证明。玻璃/黑绒这类**观测到但测不到**的表面是本引理假设 (iii) 的盲点，由 ν_neg 与反射强度通道部分补偿，不能完全消除。

**引理 89（姿态包络的视域下界）** 若块内真实姿态 θ(t) ∈ Θ_t（由引理 87 的稳定界与跟踪界保证），则 ∀t: ρ_dir(θ(t)) ≥ min_{θ∈Θ_t} ρ_dir(θ) = ρ̂_dir。故 ρ̂_dir ≥ ρ_min ⇒ 包络内每个姿态都满足覆盖率门槛。证明：逐点取 min 即得；时刻 t 的姿态落在 Θ_t 内是假设。∎
> **关键**：引理 89 与引理 87 共用同一个 ξ 预算。这不是巧合，而是本轮最大风险的数学来源（见第 8 节）。

**引理 90（相互退化的中立元等价）** GC/LVC/AFC/MDA 任一缺失时，注入中立元后 v10 的可观测输出与 v9 逐位一致：
- GC^⊥：g=stand、K=1、刹车距离不变式 ⇒ v9 定义 534；
- AFC^⊥：Θ_t={θ(t)}（实测单点）⇒ ρ̂=ρ ⇒ v9 当拍感知；
- LVC^⊥：ρ≡1, λ≡1, ε≡0, ν≡1, age≡0 ⇒ 五元交退化为 `d_vis ≥ d_safe` ≡ v9 `ĝ_min ≥ d_safe`；
- MDA^⊥：Γ_g、Γ_p 解耦 ⇒ v9 独立退化链。
证明：逐行对照表 535/536 与 v9 定义 532–539，代入中立元后各聚合算子取恒等；调度顺序与取值集合均不变，故输出序列逐位相同（沿用引理 83）。∎

**引理 91（步态阶梯的单调安全）** Γ_g 按 risk 降序排列：trot→walk→stand。下降一级严格减小姿态摆幅与 XCoM 速度 ⇒ ε_deskew 与 δ_stab 单调不增、ρ̂ 单调不减、ξ 风险单调不增。故降阶梯不会提高任一证书的违规概率；stand 为吸收态（摆幅 0 ⇒ ε=0、Θ 单点）。证明：由步态动力学单调性（摆幅与速度随步频/步幅单调）与定义 545 的包络膨胀 δ_stab ∝ (1−ξ/ξ_safe)；注意过渡瞬态需一个完整站立相，见 E573。∎

**引理 92（探测-承诺的有限终止 / 无 Zeno）** 每次探测至少使一个必测扇区的龄归零或使 ρ 增加 ≥ δ_ρ>0；N_probe 次后仍不足则进入 stand（吸收态）。块内中止转移次数 ≤ N_stop ≤ N_stop_max。故每个块内探测/中止事件数有界，相邻事件间隔 ≥ 半个步幅时间，有限时间事件数有限。∎

**引理 93（组合安全传递）** 在引理 87–92 与 v9 引理 82–86 下，任意执行轨迹都落在退化格点（v10 → v9 → v8 → v7 → v6）的某一层，且新失效模式只可能把系统**向下**推，不可能向上跳。故 v10 的安全性由已证的 v6–v9 逐层继承；v10 新增的只是"在格点更高层时可用的额外保守条件"。∎

## 8. 本轮最大风险

**一句话**：姿态-视域耦合证书的保守性依赖"步态预测的姿态包络 Θ_t 覆盖真实姿态"，而稳定裕度下降时真实姿态恰恰最容易冲出包络——于是**稳定证书与视域证书在同一个扰动下同向失效**，二者的联合置信度被高估，系统可能在最需要看清落足点的那一步，用一个已经失效的视域下界去批准一块落在未观测区域的"安全"停驻。
