# 第 55 轮（承接第 54 轮 v16++ GroundEdge-GenSim+++；新灵感循环第 1 轮；本轮灵感：「场景驱动创新」×「UniBot世界挑战赛」）

> 第 54 轮把技能组合推进到动作空间剖面、技能组合图与云边联合证书，体系已拥有 ACS/SCOM/CEC/AEC/JTC 与定义 115–120。本轮灵感来自竞赛现场而非论文：**UniBot 世界挑战赛的评分对象不是“算子数量”，而是“在给定世界/场景中的可复现表现”**。核心矛盾：H22 现有证书 ρ、A_cert、γ_ce 都是“场景无关”的，而竞赛评测是“场景分布相关”的；H23 继续叠加算子的边际收益递减，真正的创新点应来自 **场景覆盖缺口**，而不是能力清单的继续延长。

## 0. 直觉与动机

**灵感 1（场景是一等公民：把 σ 加进证书的索引）**
过去我们把技能写成 `S → (ρ, α_S, A_cert, ...)`，隐含假设“部署场景不变”。但 UniBot 的多赛道意味着同一技能在「桌面抓取」「杂乱堆叠」「低光照」「湿滑地面」下的 ρ 完全不同。直觉：证书应从 `J` 升级为 **场景索引证书族 `J(σ)`**——σ 不是测试集标签，而是证书的定义域变量；证书不再问“这个技能行不行”，而问“在哪些场景格上、以多大把握行”。

**灵感 2（场景驱动创新：用覆盖缺口定义“下一个创新点”）**
场景驱动创新不是“为每个场景各写一个 demo”，而是建立 **场景图集 `Σ̂`**，把赛道要求铺成带权重的场景格；创新点 = 能最大化降低加权缺口 `Gap_w` 的 **最小算子**。这样“要不要加一个模块”从直觉争论变成可计算的 **缺口收益 / 实现成本** 选择，也直接回应了 H23。

**灵感 3（UniBot 世界挑战赛：从排行榜到证据义务）**
竞赛不是发论文，评委看的是「任务成功、鲁棒、可解释、可复现」的组合。直觉：把每条赛道拆成 **证据义务映射 `TrackMap`**，每个 IP 必须回答“在哪条赛道、用哪个协议、达到什么下界、失败如何解释”。排行榜名次只是证据义务被满足后的副产物，不能用它反推体系正确性。

**灵感 4（场景迁移证书：把“换场景还能不能用”说清楚）**
每次换场景都重训重证成本太高。直觉：用 **场景度量 `d_Σ`** 与鲁棒性的 **Lipschitz 界**给出证书的有效半径 `r(σ)`；目标场景落在半径内则证书可迁移，半径外必须重证。这把“域泛化”从口号变成带预算的可判定问题，并把第 54 轮的 `J`、`A_cert` 统一纳入场景条件。

**灵感 5（最小可行参赛：先跑通一条场景-证据闭环）**
54 轮体系已很重。竞赛策略应是 **MVP 优先**：选 2 条主轴赛道 → 建最小场景图集 → 产出“3 个 demo + 1 张证书面板 + N 张失败解释卡” → 用隐藏/对抗场景守门。先证明“场景→证书→证据→改进”闭环，再横向扩算子；否则体系再优雅，也交不出可复现的参赛包。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（场景）**
场景 `σ = (E_σ, O_σ, G_σ, D_σ, C_σ)`：
- `E_σ`：环境几何、光照、材质与物理参数；
- `O_σ`：物体集合及其语义/可供性；
- `G_σ`：任务目标规格；
- `D_σ`：扰动分布（遮挡、延迟、噪声、动力学偏差）；
- `C_σ`：安全/时间/能耗约束。
场景总体 `σ ~ μ`，`Σ` 为场景空间。**注意**：σ 是分布级对象，单次回放只是一个样本 `x ~ D_σ`。

**定义 122（场景条件鲁棒性谱与场景证书）**
技能 `S` 在场景 σ 下的维度鲁棒性
```
ρ_S(d|σ) = P_{x~D_σ}[ m_S(x) ≥ θ_d ]
```
场景证书 `J(σ) = (ρ(·|σ), A_cert(σ), γ_ce(σ), δ_a(σ), evidence(σ))`。
部署域 `Dom(J) = { σ ∈ Σ | dom_J(σ)=in ∧ δ_a(σ) < Θ_a }`。
**与第 54 轮的区别**：`ρ`、`A_cert`、`γ_ce` 全部显式条件于 σ，禁止再把某一场景的证书当成全局证书。

**定义 123（场景度量与证书有效半径）**
场景度量 `d_Σ : Σ×Σ → R_{≥0}` 满足同一性、对称性与三角不等式，由四项归一化后加权：
```
d_Σ(σ,σ') = w_v·d_vis + w_p·d_phys + w_o·d_obj + w_d·d_dist
```
设 `ρ(·|σ)` 关于 σ 的 Lipschitz 常数为 `L_Σ`（对 d_Σ）。证书在源场景 σ_s 的有效半径为
```
r(σ_s) = min_d (ρ_S(d|σ_s) - ρ_min(d))_+ / L_Σ
```
即：只要 `d_Σ(σ_s,σ_t) ≤ r(σ_s)`，则可保证目标场景的维度鲁棒性不低于阈值（在有限样本误差外）。半径内可迁移，半径外必须重证。

**定义 124（场景图集、覆盖与加权缺口）**
场景图集 `Σ̂ = {(σ_i, w_i, C_i)}_{i=1..k}`：格中心、任务先验权重、已收集证据。
```
cov(Σ̂) = Σ_{σ_i 已覆盖} w_i / Σ_i w_i
Gap_w(Σ̂) = Σ_{σ_i 未覆盖 ∨ ρ(σ_i)<ρ_min} w_i
```
其中“未覆盖”指没有满足 `Dom(J)` 的证书，而非没有采样。**创新点判据**：新增算子 `op` 的价值 `V(op) = ΔGap_w / cost(op)`，优先做 `V` 最大且能复用既有证书的最小算子。

**定义 125（场景迁移证书 STC）**
```
STC(σ_s→σ_t) = (ρ(·|σ_s), r(σ_s), Δρ_bound, δ_a(σ_t), evidence)
Δρ_bound(d) = L_Σ · d_Σ(σ_s,σ_t)
```
判定：`d_Σ ≤ r(σ_s) ∧ δ_a(σ_t) ≤ Θ_a ∧ ρ(d|σ_s) - Δρ_bound(d) ≥ ρ_min(d) ∀d` 时通过；否则返回 `reject` 并给出需重证的维度子集。STC 是第 54 轮 JTC 在“场景维度”上的对偶：JTC 管跨任务迁移，STC 管跨场景迁移。

**定义 126（赛道证据映射与就绪度）**
设 UniBot 赛道集合 `𝒯 = {T_1,...,T_m}`。证据义务映射
```
TrackMap : (IP, T_j) ↦ O_{IP,j} = { (claim, metric, protocol, lower_bound) }
```
就绪度 `R_track(T_j) = Σ_{o∈O_{·,j}} w_o·1[evidence_db ⊨ o] / Σ_o w_o`。
隐藏场景泛化缺口 `G_hidden = E_{σ~public}[score] - E_{σ~hidden}[score]`。
**参赛门槛**：`R_track ≥ 0.8`（至少两条赛道）且 `G_hidden ≤ 8%`，否则不得把公开榜成绩写进方案主张。

## 2. 关键算法 伪代码

### IP-121 SFP（Scenario Fingerprinting，场景指纹与图集）

```python
def scenario_fingerprint(sigma):
    phi = concat(
        visual_embed(sigma.E),
        physics_signature(sigma.E.physics),      # 摩擦/质量/延迟/传感器噪声
        object_graph_embed(sigma.O),             # 语义 + 可供性图
        disturbance_spectrum(sigma.D),
        goal_signature(sigma.G),
    )
    return l2_normalize(phi)

def build_atlas(scenarios, k, must_link):
    Z = [scenario_fingerprint(s) for s in scenarios]
    cells = constrained_kmeans(Z, k, must_link=must_link)   # 同赛道不拆散
    weights = task_prior(cells) * track_importance(cells)
    return Atlas(cells, weights)
```

### IP-122 SCX（Scenario-Conditioned eXecution，场景条件证书）

```python
def scenario_certificate(skill, sigma, dims, sim, n, alpha):
    rho = {}
    for d in dims:
        samples = [sim.rollout(skill, sample(sigma.D)) for _ in range(n)]
        rho[d] = clopper_pearson_mean(samples, d, alpha)   # 置信下界，不是点估计
    A_cert = action_occupancy(skill, sigma)                # 复用 IP-115
    gamma  = cloud_edge_map(sigma)                         # 复用 IP-117
    delta_a = alignment_error(gamma, A_cert)
    return J(sigma, rho, A_cert, gamma, delta_a,
             evidence=sim.trace_hash())

def lookup_or_reject(sigma, atlas, cert_index):
    cell = nearest_cell(sigma, atlas, metric=d_Sigma)
    J = cert_index.get(cell.id)
    if J is None or sigma not in J.Dom:
        return ('reject', 'out_of_domain', cell)
    return ('ok', J)
```

### IP-123 SGA（Scenario Gap Attack，缺口驱动采样与创新点排序）

```python
def propose_next(atlas, budget, safety):
    candidates = []
    for cell in atlas.cells:
        if not cell.covered or cell.rho_min_violation:
            gain = cell.weight * expected_gap_reduction(cell)
            cost = mutation_cost(cell) + recert_cost(cell)
            nov  = novelty(cell, atlas)
            candidates.append((gain * nov / (cost + eps), cell))
    score, seed = max(candidates)
    sigma_new = constrained_mutate(seed, objective=max_rho_drop,
                                   constraints=safety + physics_consistency,
                                   budget=budget)
    return score, sigma_new

def innovation_value(op, atlas, cost_op):
    before = Gap_w(atlas)
    after  = Gap_w(atlas.estimate_with(op))
    return (before - after) / (cost_op + eps)     # V(op)：越小越好实现，越大越值得做
```

### IP-124 STC（Scenario Transfer Certificate）

```python
def transfer_certificate(J_src, sigma_src, sigma_tgt, L_Sigma, Theta_a):
    d = d_Sigma(sigma_src, sigma_tgt)
    if d > J_src.r:
        return ('reject', 'outside_validity_radius', d, J_src.r)
    bound = {dim: L_Sigma * d for dim in J_src.rho}
    delta_a = alignment_drift(J_src.gamma_ce, sigma_tgt)
    if delta_a > Theta_a:
        return ('reject', 'action_alignment_fail', delta_a)
    bad = [dim for dim in J_src.rho
           if J_src.rho[dim] - bound[dim] < rho_min[dim]]
    if bad:
        return ('reject', 'robustness_bound_violation', bad)
    return ('ok', STC(sigma_src, sigma_tgt, d, J_src.r,
                      rho=J_src.rho, bound=bound,
                      evidence=J_src.evidence + [('d_Sigma', d)]))
```

### IP-125 TAP（Track Alignment Protocol）

```python
def track_readiness(ips, tracks, evidence_db):
    R = {}
    for t in tracks:
        obligations = union(track_map(ip, t) for ip in ips)
        hit = [o for o in obligations if evidence_db.satisfies(o)]
        R[t] = sum(o.weight for o in hit) / sum(o.weight for o in obligations)
    return R

def hidden_gap(public_scores, hidden_scores):
    return mean(public_scores) - mean(hidden_scores)
```

### IP-126 SDI（Scenario-Driven Innovation 闭环）

```python
def sdi_loop(pipeline, atlas, budget, max_rounds):
    for _ in range(max_rounds):
        if budget <= 0: break
        score, sigma = propose_next(atlas, budget, safety=SAFE)
        J = scenario_certificate(pipeline.entry_skill, sigma, dims, sim)
        if not J.ok:
            root = explain_failure(sim, sigma)       # 复用第 53 轮 Explain
            op = minimal_operator_to_fix(root.cause) # 只做最小修复，不叠模块
            pipeline.add(op)
            J = scenario_certificate(pipeline.entry_skill, sigma, dims, sim)
        atlas.add(sigma, J)
        budget -= cost_of(sigma) + cost_of(op if 'op' in locals() else None)
    return pipeline, atlas
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| SFP | O(|Σ|·(|E|+|O|+d_φ)) | O(|Σ|·d_φ) | 指纹对场景差异敏感、对无关扰动不变 |
| SCX | O(|S|·|Σ|·n·T_roll) | O(|S|·|Σ|·|𝔇_ρ|) | 置信下界、样本独立同分布 |
| SGA | O(|Σ̂|·C_mut + |S|·|Σ|·n·T_roll) | O(|Σ̂|+|S|) | 变异受物理/安全硬约束 |
| STC | O(|𝔇_ρ|) | O(|𝔇_ρ|) | d_Σ 为度量、L_Σ 上界可信 |
| TAP | O(|IP|·|𝒯|·|O|) | O(|IP|·|𝒯|·|O|) | 义务映射先于结果确定 |
| SDI | O(rounds·(|Σ̂|+SCX)) | O(|Σ̂|+|S|) | 每轮只加一个最小算子、预算单调 |

**正确性定理（Scenario-Transfer Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** `d_Σ` 为度量，且 `ρ(·|σ)` 关于 `d_Σ` 的 Lipschitz 常数不超过 `L_Σ`；**(A30)** 源场景证书由独立样本估计，置信下界覆盖误差 `ε_sample`；**(A31)** `γ_ce` 的动作对齐漂移在目标场景有界；**(A32)** 目标保持同一任务语义（goal-preserving）。
则对任意 `σ_t` 满足 `d_Σ(σ_s,σ_t) ≤ r(σ_s)`：
```
P_success(σ_t) ≥ 1 - Σ_d (1 - ρ_min(d)) - L_Σ·d_Σ(σ_s,σ_t)
                  - β_E - P(δ_a > Θ_a) - ε_sample
```
证明要点：以 d_Σ 的三角不等式把目标场景的 ρ 拉到源场景证书，再用 Lipschitz 界与并集界合并各维度失败事件；`A29` 保证界有效，`A32` 排除“场景换了任务也换了”的伪迁移。**该定理的价值是把“换场景能否复用证书”变成可计算的半径判定，而不是一次盲测。**

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| `d_Σ` 不具语义，半径是伪安全 | 高 | 锚点场景对 + 人评校准 + 用违约率反推 L_Σ |
| 场景图集被公开赛道污染 | 高 | 隐藏场景留出 + 物理约束的对抗生成 + 赛前盲测 |
| `L_Σ` 低估导致过度乐观 | 高 | 保形预测/分位数上界 + 保守常数 + 半径外强制重证 |
| 算子膨胀、闭环不收敛 | 中 | 每轮仅一个最小算子 + 创新价值 V(op) 门限 |
| 证据义务与评委口径错位 | 中 | 先做 TrackMap 再跑实验 + 干跑评分 + 保留原始日志 |

## 6. 本轮最大风险

**一句话**：场景驱动创新最容易退化为“公开场景/排行榜过拟合”——整套场景迁移证书的 soundness 只取决于场景度量 `d_Σ` 是否真的语义有效、以及 Lipschitz 常数 `L_Σ` 是否被保守上界化；一旦隐藏场景落在认证半径之外或 `d_Σ` 把关键物理差异压平，公开榜的高分只是“场景海市蜃楼”，会在正式挑战赛的隐藏世界中系统性崩塌，故必须把隐藏/对抗场景与保形半径作为主门禁，而不是把排行榜名次当作部署前提。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-SceneOS（SFP×SCX×SGA×STC×TAP×SDI）

> 承接第 54 轮产物 v31。本轮不再横向叠加机器人算子，而是把整个体系 **按场景重索引**，形成面向 UniBot 世界挑战赛的“场景驱动参赛操作系统”：
> - **SFP（Scenario Fingerprinting）**：把世界/场景编码为可聚类的指纹，构建带权场景图集；
> - **SCX（Scenario-Conditioned eXecution）**：把 ρ、A_cert、γ_ce 全部升级为 σ 条件证书 `J(σ)`；
> - **SGA（Scenario Gap Attack）**：用加权覆盖缺口与创新价值 `V(op)` 排序“下一个创新点”；
> - **STC（Scenario Transfer Certificate）**：用场景度量与 Lipschitz 界给出证书有效半径；
> - **TAP（Track Alignment Protocol）**：把 IP 映射到 UniBot 赛道证据义务，计算就绪度；
> - **SDI（Scenario-Driven Innovation loop）**：每轮只加一个最小算子的参赛 MVP 闭环。
>
> IP 编号：IP-121~IP-126（共 6 个新增）；升级 IP-115/117/118/120，使动作、云边、联合迁移证书全部场景条件化。

## 0. 核心 IP 设计

| 编号 | 名称 | 类型 | 关键改进 |
|---|---|---|---|
| IP-121 | SFP Scenario Fingerprinting | 新增 | 场景指纹 `φ(σ)`，带权图集 `Σ̂` 与覆盖 `cov(Σ̂)` |
| IP-122 | SCX Scenario-Conditioned eXecution | 新增 | 场景证书 `J(σ)`，置信下界 ρ(·\|σ) |
| IP-123 | SGA Scenario Gap Attack | 新增 | 加权缺口 `Gap_w`，创新价值 `V(op)=ΔGap_w/cost` |
| IP-124 | STC Scenario Transfer Certificate | 新增 | 有效半径 `r(σ)`，迁移界 `L_Σ·d_Σ` |
| IP-125 | TAP Track Alignment Protocol | 新增 | 证据义务映射 `TrackMap`，就绪度 `R_track` |
| IP-126 | SDI Scenario-Driven Innovation | 新增 | “缺口→最小算子→证据→重证”闭环 |

**总原则（本轮的方法论转向）**：
1. **场景即接口**：任何证书必须写明 σ 定义域，禁止全局化；
2. **缺口即路线图**：创新点由 `Gap_w` 最大的场景格驱动，而非由算子清单驱动；
3. **半径即承诺**：只能对 `d_Σ ≤ r(σ)` 的目标场景作鲁棒性承诺；
4. **证据即参赛**：不能映射到 `TrackMap` 的工作不进主方案，只进探索分支。

| `J(σ)` | 场景证书 `(ρ,A_cert,γ_ce,δ_a,evidence)` |
| `Dom(J)` | 证书可部署的场景域 |
| `d_Σ` | 场景度量（视觉/物理/物体/扰动加权） |
| `L_Σ` | ρ 关于 d_Σ 的 Lipschitz 常数 |
| `r(σ)` | 证书有效半径 |
| `Σ̂` | 场景图集（格中心+权重+证据） |
| `Gap_w` | 加权覆盖缺口 |
| `STC` | 场景迁移证书 |
| `TrackMap` | IP→赛道→证据义务映射 |
| `R_track` | 赛道证据就绪度 |
| `G_hidden` | 公开场景与隐藏场景的成绩缺口 |
| `V(op)` | 创新价值 = ΔGap_w / cost(op) |

**与 v31 的接口关系**：`α_S(σ)`、`γ_ce(σ)`、`J(σ)` 分别继承 IP-115、IP-117、IP-118；`STC` 与 IP-120 `JTC` 构成“场景维 × 任务维”的双迁移证书；`TAP` 为全体系提供对外可验收的端口。

## 2. 关键算法 伪代码

### IP-121 SFP

```python
def scenario_fingerprint(sigma):
    phi = concat(
        visual_embed(sigma.E),
        physics_signature(sigma.E.physics),
        object_graph_embed(sigma.O),
        disturbance_spectrum(sigma.D),
        goal_signature(sigma.G),
    )
    return l2_normalize(phi)

def build_atlas(scenarios, k, must_link):
    Z = [scenario_fingerprint(s) for s in scenarios]
    cells = constrained_kmeans(Z, k, must_link=must_link)
    return Atlas(cells, weights=task_prior(cells) * track_importance(cells))

def coverage(atlas, rho_min):
    covered = [c for c in atlas.cells if c.has_cert and c.rho >= rho_min]
    return sum(c.weight for c in covered) / sum(c.weight for c in atlas.cells)
```

### IP-122 SCX

```python
def scenario_certificate(skill, sigma, dims, sim, n, alpha):
    rho = {}
    for d in dims:
        ys = [sim.rollout(skill, sample(sigma.D)) for _ in range(n)]
        rho[d] = clopper_pearson_mean(ys, d, alpha)   # 置信下界
    A_cert = action_occupancy(skill, sigma)           # IP-115 场景化
    gamma  = cloud_edge_map(sigma)                    # IP-117 场景化
    delta_a = alignment_error(gamma, A_cert)
    J = J_sigma(sigma, rho, A_cert, gamma, delta_a, evidence=sim.trace_hash())
    return J if J.delta_a < Theta_a else J.with_status('action_mismatch')
```

### IP-123 SGA

```python
def innovation_value(op, atlas, cost_op):
    before = Gap_w(atlas)
    after  = Gap_w(atlas.estimate_with(op))
    return (before - after) / (cost_op + eps)

def propose_next(atlas, budget, safety):
    ranked = []
    for c in atlas.cells:
        if c.covered and not c.rho_min_violation: continue
        gain = c.weight * expected_gap_reduction(c)
        cost = mutation_cost(c) + recert_cost(c)
        ranked.append((gain * novelty(c, atlas) / (cost + eps), c))
    score, seed = max(ranked)
    sigma_new = constrained_mutate(seed, objective=max_rho_drop,
                                   constraints=safety + physics_consistency,
                                   budget=budget)
    return score, sigma_new
```

### IP-124 STC

```python
def transfer_certificate(J_src, sigma_s, sigma_t, L_Sigma, Theta_a):
    d = d_Sigma(sigma_s, sigma_t)
    if d > J_src.r:
        return ('reject', 'outside_validity_radius', d, J_src.r)
    bound = {dim: L_Sigma * d for dim in J_src.rho}
    delta_a = alignment_drift(J_src.gamma_ce, sigma_t)
    if delta_a > Theta_a:
        return ('reject', 'action_alignment_fail', delta_a)
    bad = [dim for dim in J_src.rho
           if J_src.rho[dim] - bound[dim] < rho_min[dim]]
    if bad:
        return ('reject', 'robustness_bound_violation', bad)
    return ('ok', STC(sigma_s, sigma_t, d, J_src.r, J_src.rho, bound,
                      evidence=J_src.evidence + [('d_Sigma', d)]))
```

### IP-125 TAP

```python
def track_readiness(ips, tracks, evidence_db):
    R = {}
    for t in tracks:
        obs = union(track_map(ip, t) for ip in ips)
        hit = [o for o in obs if evidence_db.satisfies(o)]
        R[t] = sum(o.weight for o in hit) / sum(o.weight for o in obs)
    return R

def gate(R, G_hidden, min_ready=0.8, max_gap=0.08):
    return ('pass' if max(R.values()) >= min_ready and G_hidden <= max_gap
            else 'blocked')
```

### IP-126 SDI

```python
def sdi_loop(pipeline, atlas, budget, max_rounds):
    for _ in range(max_rounds):
        if budget <= 0: break
        score, sigma = propose_next(atlas, budget, safety=SAFE)
        J = scenario_certificate(pipeline.entry_skill, sigma, dims, sim)
        if not J.ok:
            root = explain_failure(sim, sigma)         # IP-REX
            op = minimal_operator_to_fix(root.cause)   # 单算子、可回滚
            pipeline.add(op)
            J = scenario_certificate(pipeline.entry_skill, sigma, dims, sim)
        atlas.add(sigma, J)
        budget -= cost_of(sigma) + cost_of(op if 'op' in locals() else None)
    return pipeline, atlas
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SFP | O(|Σ|·(|E|+|O|+d_φ)) | O(|Σ|·d_φ) | 指纹稳定性、赛道不混簇 |
| SCX | O(|S|·|Σ|·n·T_roll) | O(|S|·|Σ|·|𝔇_ρ|) | 置信下界覆盖率 ≥ 95% |
| SGA | O(|Σ̂|·C_mut + |S|·|Σ|·n·T_roll) | O(|Σ̂|+|S|) | 变异满足物理/安全约束 |
| STC | O(|𝔇_ρ|) | O(|𝔇_ρ|) | d_Σ 度量性、L_Σ 上界、半径 sound |
| TAP | O(|IP|·|𝒯|·|O|) | O(|IP|·|𝒯|·|O|) | 义务先定、证据可审计 |
| SDI | O(rounds·(|Σ̂|+SCX)) | O(|Σ̂|+|S|) | 每轮单算子、预算单调递减 |

**正确性定理（Scenario-Transfer Soundness）**
假设 (A26)–(A28) 成立；**(A29)** `d_Σ` 为度量且 `ρ(·|σ)` 关于 `d_Σ` 为 `L_Σ`-Lipschitz；**(A30)** 场景证书以独立样本估计，样本误差 `ε_sample`；**(A31)** `γ_ce` 的目标场景对齐漂移有界；**(A32)** 场景迁移保持任务语义。则对 `d_Σ(σ_s,σ_t) ≤ r(σ_s)`：
```
P_success(σ_t) ≥ 1 - Σ_d (1 - ρ_min(d)) - L_Σ·d_Σ(σ_s,σ_t)
                  - β_E - P(δ_a > Θ_a) - ε_sample
```
**推论（参赛门禁）**：若某主张只在 `d_Σ > r(σ_s)` 的目标场景上成立，则该主张必须重新取证，不得进入 `TrackMap`；这条推论把“泛化口号”转成可执行的门禁规则。

- **H22**：场景条件 ρ(·|σ) 对隐藏场景成功率的预测优于场景无关 ρ（预期 MAE 降低 ≥ 30%）。

## 6. 本轮最大风险

**一句话**：场景驱动创新的成败被两个量“卡死”——场景度量 `d_Σ` 是否真的捕捉物理/语义差异、Lipschitz 常数 `L_Σ` 是否被保守上界化；若 `d_Σ` 把关键差异压平或隐藏场景落在认证半径之外，STC 会把“公开场景的鲁棒”误签为“隐藏场景的可用”，公开榜高分将在正式挑战赛中系统性崩塌，故必须以 **隐藏/对抗场景留出 + 保形半径 + 违约率反推 L_Σ** 作为主门禁，榜单身位只做参考。
