# 第 1 轮（灵感循环 v2：「数据采集」×「跨任务泛化」）—— 从「推理时补救」转向「数据侧的因果覆盖」

> **承接 research.md 的 v1（UIP-01~10），但换一个更底层的问题。** v1 的旗舰 UIP-01 把希望押在推理时的滚动验证与重试；UIP-03 押专家路由，UIP-04 押世界模型裁决，UIP-06 只是笼统地说「针对 5 条泛化轴做域增广」。它们共同默认了一件事：**数据本身是够的，缺的是更好的推理/路由/增广。** 本轮要挑战这个默认。如果 32 个任务的数据在结构上是「每个任务只在一个固定的物体集合与背景上采一遍」，那么模型完全可以靠「先认出这是哪个任务、再回放该任务的轨迹」拿到训练集上的解；一旦评测执行 `do(物体)`、`do(背景)`、`do(人)`，这条捷径就断了。此时真正缺的不是推理算力，而是**数据采集的因果结构**。本轮把研究重心从「推理时怎么救」下移到「采什么数据、怎么采」。

---

## 0. 直觉：32 个任务填满的是一张三维表的对角线

把数据想成一张三维表：**任务是行 T（32 行），物体/可供性是列 O，场景上下文是深度 C（背景、干扰物、光照、相机位姿、人是否在场）。** 原始数据集在每个任务行上，基本只填了一个很窄的格子：该任务录制时用的那一套物体、那一个背景。评测却会在**非对角格**上采样：同一条任务指令，换一个物体实例、换一个背景、加入干扰物、或让人闯入。

于是「跨任务泛化」可以被拆成两个可分别测量的东西：

1. **上下文不变性（context invariance）**：固定任务与技能，沿 C 轴移动时策略不变；
2. **任务间正迁移（task transfer）**：固定技能，沿 T 轴移动时，A 任务的抓取/插入/倾倒经验能帮到 B 任务。

而「数据采集」在这个视角下不是「再多录 1000 条」，而是**主动选择要填哪些非对角格**。这解释了为什么「每条任务已有约 1000 条 episode」并不令人安心：**第 1001 条同格样本的边际覆盖收益接近 0；真正稀缺的是新格子。**

> **一句话直觉**：我们不是数据太少，而是数据的**支撑集（support）太窄且与任务身份高度共线**；跨任务泛化的问题，首先是数据采集的实验设计问题。

**这张表最重要的读法不是「谁最难」，而是第四行**：如果当前评测/榜单均值没有因为物体缺口而显著掉分，说明**平均分数对覆盖缺口不敏感**，而隐藏评测的五条泛化轴恰恰会去戳这些缺口。因此数据采集应当由**覆盖（coverage）**驱动，而不是由当前榜单分数驱动——否则会把预算花在已经能拿分的格子上。

**边界**：榜单数字来自生成式 fixture，不是官方结果；五条泛化轴来自用户给定，飞书手册正文仍未取得；「缺少某物体」是任务档案的字段，需在正式提测前复核。以上都只用于**方法设计**，不当作真机结论。

## 2. 两个灵感词的交叉解读

1. **数据采集 = 实验设计，而不是「更多演示」。** 在远程 API 赛制里，选手不能反复上真机，但可以：（a）用公开 32 数据集做**重组/反事实合成**；（b）在允许的范围内采集少量真实补充数据；（c）在仿真里按需生成。真正可控制的变量不是「episode 数量」，而是**对 (O, C, T) 的干预**。因此数据采集的核心是一个**主动实验设计**问题：在预算内选哪些干预，使训练分布从「任务–场景共线」变成「任务与场景近似独立、技能与动作保持因果相关」。
2. **跨任务泛化 = 不变性 + 正迁移，两者要分开优化。** 不变性是对 C 的（背景/干扰物/人），正迁移是对 T 的（共享技能）。很多方案把两者混成一个「更强模型」，结果既不知道是记忆还是迁移在起作用，也无法定位失败。本轮把它们拆成两个可测量量：`Inv(C)` 与 `Transfer(T)`，并分别用覆盖矩阵与留一任务实验来度量。
3. **交叉点**：数据采集应当**打断 `T → (O,C)` 的伪相关边，同时保留 `S → A` 的因果边**。一句话：**去混杂（de-confound）任务身份，保留技能信号。**

## 3. 形式化：把「窄支撑集」写成可优化的对象

**直觉版**：每个 episode 是一份「配方卡」，记录了任务 T、场景 C、物体 O、技能序列 S、动作 A。训练分布里，T 几乎决定了 (O,C)，所以模型可以偷懒用 T 当 (O,C) 的代理。我们要做的是：在数据里**把 T 和 (O,C) 拆开**，让同一个 T 出现在多个 (O,C) 上，让同一个 (O,C) 出现在多个 T 上；同时保证每个合成样本在几何/运动学/物理/语义上都成立。

**定义 1（episode 因子化）** `τ = (T, C, O, S, A, Y)`：T 为指令/任务；O 为物体实体集合（类别、可供性、位姿）；C 为上下文（背景、光照、干扰物、相机位姿、人在场）；S 为技能段序列（reach/grasp/lift/move/place/insert/pour/fold/zip/unscrew/hang…）；A 为动作序列（末端增量 + 夹爪，或关节）；Y 为成功与步骤分。

**定义 2（任务–场景混杂度）** 在数据集 D 上，
`κ = I_D(T; O, C) / H_D(T)`，
并用一个「只看场景、不看语言」的探针分类器 `p(T | O, C)` 的准确率上界交叉验证；再用「只用 T 预测 A」的 `R²_{T→A}` 度量捷径可走多远。定义**捷径风险** `SG = κ · R²_{T→A}`。若 `SG` 高，说明数据允许「认任务→回放」，泛化必然脆。

**定义 3（覆盖格与覆盖度）** `cell = (s, o_class, c_axis_value)`；`M[cell]` 为该格 episode 数；`cov_m(D) = #{cell : M[cell] ≥ m}`；最差格覆盖 `worst_m(D) = min_{cell∈Cells} M[cell]`。

**定义 4（近似去混杂分布）** 给定 `ε>0, m∈N`，称 D′ 是 `(ε,m)`-去混杂的，若对每个有支撑的 (t,o,c) 有 `|P_{D′}(O=o | T=t) − P_{D′}(O=o)| ≤ ε`（C 同理），且 `M[t,o,c] ≥ m`。这是「T 与 (O,C) 近似独立、且每格有足够样本」的合取。

**定义 5（重组合法谓词）** `V(τ̂) = G ∧ K ∧ P ∧ Sem`：G 几何（深度/遮挡/边界一致）、K 运动学（IK 可达、无自碰撞、夹爪开合匹配物体宽度）、P 物理（不穿透、放置后稳定、插入公差）、Sem 语义（语言–物体–目标一致，技能段标签被独立分类器确认）。只有 `V=1` 的合成样本才入训练集。

**定义 6（预算化采集目标）** 给定候选干预集合 Ξ、成本 `c(ξ)`、预算 B：
`max_{I⊆Ξ, Σc≤B} [ worst_m(D ∪ I), −SG(D ∪ I) ]`（按词典序或加权），或等价的**覆盖数组**目标：在最小成本下让每个 cell 至少被覆盖 m 次。该目标通常近似次模，可用贪心加 `1−1/e` 近似。

**定义 7（轴分层选择）** 对轴 `a ∈ {pos, distractor, background, unseen, human}` 计算 `SR_a(π)`；模型选择用 `max_π min_a LCB_α(SR_a(π))`，而不是只看平均成功率。

**完整定义、伪代码与实验见产物区。**

## 4. 瓶颈假设（工作假设）

- **H1（混杂是主因）**：用「只看场景」的探针能高准确率预测任务身份；`SG` 高。若成立，则再多的推理重试也治不好泛化。
- **H2（覆盖极稀）**：每个 `(task, object, context)` 格只有一条窄带样本；新增 1000 条同格数据的边际收益远小于新增 100 个新格。
- **H3（榜单盲区）**：当前榜单均值对物体覆盖缺口不敏感（审计已给出初步证据：缺口组 step 甚至略高），所以按分数分配数据预算会系统性错过隐藏轴。
- **H4（合成合法性是瓶颈）**：反事实重组的主要失败不是「生成不出来」，而是「生成了几何/动力学不成立、标签却错的样本」，这会注入新的伪相关。
- **H5（技能重叠高）**：32 个任务在技能层高度共享（抓取-放置、插入、倾倒、折叠、拉链、堆叠、分类）；因此跨任务迁移的上限由**技能段覆盖**决定，而不是由「32 个独立专家」决定。
- **H6（人类轴近乎空白）**：只有 3/32 有明确人为干扰记录；人类轴必须靠专门合成/采集，不能指望自然覆盖。
- **H7（选手权限边界）**：不能改执行层、不能反复上真机；因此「数据采集」必须主要是**离线重组 + 有限真实补充 + 仿真**，而不是大规模真机重录。

## 5. 候选创新点：DIP-01~08（Data & Invariance Point）

（完整表、伪代码、实验见产物区。）

- **DIP-01 CASCADE（旗舰）**：因果主动技能覆盖引擎——先诊断任务–场景混杂，再用「物体槽替换 / 上下文重绘 / 指令重标 / 跨任务技能缝合」做反事实重组，用合法谓词过滤，最后在预算下按最差格覆盖选样本。
- **DIP-02 TCL**：任务–场景泄漏探针——用场景-only 与任务-only 两个探针量化 `SG`，判断该补数据还是补模型。
- **DIP-03 OSR**：物体槽重组——在同一可供性类内替换物体实例（杯子↔杯子、瓶↔瓶），并在末端空间做动作重定向（夹爪开度、预抓取偏移）。
- **DIP-04 CSR**：上下文重绘——分割前景、替换背景/光照/相机位姿、插入干扰物，覆盖 background 与 distractor 轴，同时保持物体–机器人几何。
- **DIP-05 XSS**：跨任务技能缝合——在末端/夹爪空间的技能边界上拼接不同任务的技能段，合成「新任务组合」，直接测试正迁移。
- **DIP-06 HIX**：人为干扰扩展——合成人手/人臂入镜、物体被拿走/移动的事件段，构造「暂停–等待–恢复/重抓」的监督信号；服务几乎空白的人类轴。
- **DIP-07 VF**：重组合法性过滤器——几何+运动学+物理+语义四重门，防止「像真的错样本」污染训练。
- **DIP-08 LAS**：留轴分层选择——按 5 条轴做分层留出与下置信界选模，用最差轴而非平均分做提交门禁。

**旗舰理由**：CASCADE 同时命中两个灵感词——「数据采集」被写成预算化的实验设计，「跨任务泛化」被写成去混杂 + 技能覆盖；且它完全落在选手权限内（训练侧数据工程 + 推理侧不变），不依赖官方规则改动。

## 6. 与 v1 的关系（不是推倒，是下沉）

- **UIP-06 GAX → DIP-01 CASCADE**：GAX 是「按轴做增广 + 重加权」的浅层配方；CASCADE 把它升级为「用因果覆盖目标选择干预」的实验设计，并给出合法性过滤与可验证指标。
- **UIP-07 RRV → DIP-08 LAS**：离线回放 harness 仍然复用，但评测切分从「按任务」升级为「按 5 条泛化轴分层 + 留一任务」。
- **UIP-01 RHPV-V 不被替代**：推理时重试处理「执行中的不确定」，CASCADE 处理「训练分布的混杂」，两者正交，可叠加；但本轮**不再把重试当旗舰**。
- **UIP-03 MoA-Router 变成可证伪假设**：如果数据去混杂 + 技能覆盖有效，32 专家路由的收益应显著下降；这是一个干净的消融，而不是再堆一个模块。
- **UIP-05 LCAG 获得训练信号**：物体/可供性/关系三元组正是 DIP-03/05 的标注中间层。

## 7. 本轮最大风险

**一句话**：最大的风险不是「合成数据不够多」，而是**合成样本在几何/动力学上不成立、却通过了偏弱的合法谓词**，于是模型学到的是更精致的伪相关；如果隐藏评测轴与合成轴不匹配，整个数据工程会退化为昂贵的自欺——因此必须先用 TCL 证明混杂存在、用 VF 证明合成合法、用 LAS 证明增益落在正确轴上，再投入规模。

### 1.3 三个读法（以及一个反例）

1. **物体覆盖是已知的窄**：23/32 有明确「缺少某变体」记录。这不是「可能过拟合」，而是任务档案自己写下的覆盖缺口。
2. **人类轴几乎空白**：只有 3/32 有明确人为干扰扰动记录，而评测却有人为干扰轴。人类轴必须专门构造，不能靠自然覆盖。
3. **平均分数对覆盖缺口不敏感**：有缺口组的最佳 step 均值（46.01）反而略高于无缺口组（44.35）。这并不证明缺口无害；它说明**当前可用的榜单代理没有去戳这些缺口**。因此按当前分数分配数据预算会系统性地漏掉隐藏轴。
4. **反例/自我约束**：`P_step` 与「缺口」强绑定，不能把它当作真实收益预测；它只是一个「先补已知空洞」的排班表。若 TCL 探针显示混杂很低，则本轮的旗舰前提就被削弱（见 §6 的可证伪预测）。

## 2. 旗舰点深潜：CASCADE（DIP-01）

### 2.1 机制（五步闭环）

`CASCADE = Confound diagnosis → Candidate interventions → Validity filter → Coverage-optimal selection → Invariant training`

1. **诊断（TCL）**：在原始数据上训练两个探针：`p(T | O, C)`（只看场景预测任务）与 `q(A | T)`（只看任务预测动作）。定义捷径风险 `SG = κ · R²_{T→A}`。若 `SG` 高，说明「认任务→回放」是可行捷径，数据侧干预的优先级最高。
2. **生成候选干预**：对每个任务生成四类反事实候选：
   - 物体槽替换（OSR）：在可供性类内换物体；
   - 上下文重绘（CSR）：换背景/光照/相机/干扰物；
   - 指令重标（relabel）：保留技能/物体一致性的前提下换语言表述；
   - 跨任务技能缝合（XSS）：把别的任务里同技能的片段接到本任务的技能序列中；
   - 人类干扰扩展（HIX）：人手/人臂入镜、物体被拿走/移动。
3. **合法过滤（VF）**：几何 G、运动学 K、物理 P、语义 Sem 四重门。**宁可少要，不要错样本。**
4. **预算化选择**：把候选放进覆盖矩阵 `M[s, o_class, c_axis]`，用贪心最大化「最差格覆盖」并同时压低 `SG`；每选一个样本要付生成/验证成本。
5. **不变训练 + 留轴选模**：在重组数据上用标准行为克隆（可选加不变性正则）；用 LAS 按 5 轴分层留出，按最差轴下置信界选模与决定是否提测。

### 2.2 与 v1 / UIP-06 的差异

| 维度 | v1 UIP-06 GAX | 本轮 CASCADE |
|---|---|---|
| 数据干预的依据 | 「5 轴」直觉式增广 | 先量化 `SG`，再决定是否/在哪一轴干预 |
| 目标函数 | 增广 + 重加权 | 预算下的最差格覆盖 + 去混杂，显式可优化 |
| 合成样本准入 | 未明确 | 四重合法谓词 `V=G∧K∧P∧Sem`，先过滤再入训 |
| 泛化度量 | 逐轴成功率 | 留轴 + 留一任务 + 覆盖矩阵，三者分离 |
| 与推理层关系 | 隐含替代 | 与 UIP-01 正交，可叠加；不把重试当旗舰 |
| 可证伪性 | 弱 | 给出「路由收益应下降」「最差轴增益 > 平均增益」等预测 |

### 2.4 可行性、资源、落地步骤

- **可行性：中高。** 分割（SAM 类）+ 深度/几何一致性 + 图像重绘（inpainting / diffusion）已经是成熟工具链；动作重定向在末端空间是小残差问题；四重合法谓词中「语义」可用小 VLM，其余可用几何/运动学规则。最不确定的是**重绘后动作标签是否仍成立**，这正是 VF 与残差重定向要解决的。
- **资源**：公开 32 数据集（训练/校准）；1–2 张推理卡（策略 + 小 VLM + 分割）；离线回放 harness（复用 UIP-07 RRV）；无额外接口要求。
- **落地步骤（9 步）**：
  1. 用 `data_coverage_audit.py` 固化覆盖表与缺口清单；
  2. 实现 TCL 两个探针，测原始数据的 `κ` 与 `SG`；
  3. 训练/接入分割、深度一致性与重绘模块；
  4. 实现 OSR 的动作重定向（夹爪开度、预抓取偏移、残差修正）；
  5. 实现 CSR 的前景保持与背景/光照/干扰物替换；
  6. 实现 XSS 的技能分段与边界兼容检查；
  7. 实现 VF 四重门与拒绝原因记录；
  8. 用贪心覆盖选择生成 D′，在 RRV 上做留轴/留一任务实验；
  9. 通过 LAS 门禁后再预约真机提测，用真实数据校准合成分布。
- **主要风险**：① 重绘引入的「假纹理/假几何」被策略当成真线索；② 动作重定向失败但 VF 没抓住；③ 合成分布与隐藏评测轴不匹配；④ 生成/验证成本超过预算。对应护栏：四重门 + 残差重定向 + 合成/真实混合比例上限 + 逐轴消融。

## 3. 形式化定义

**定义 1（episode 因子化）**
`τ = (T, C, O, S, A, Y)`。T 为指令/任务；C 为上下文（背景、光照、相机位姿、干扰物、人在场）；O 为物体实体集合，`o=(class, affordance, pose, size, state)`；S 为技能段序列；A 为动作序列（末端增量 + 夹爪，或关节）；Y 为成功与步骤分。

**定义 2（技能段）**
`S = ((s_1, o_1, g_1, [t_1^0, t_1^1]), …, (s_m, o_m, g_m, [t_m^0, t_m^1]))`，其中 `s_j` 属于技能词表 `𝒮={reach, grasp, lift, move, place, insert, pour, fold, zip, unscrew, hang, sort, stack, remove}`，`g_j` 为子目标（可观测谓词）。

**定义 3（任务–场景混杂度）**
`κ = I_D(T; O, C) / H_D(T)`（归一化互信息），并用场景-only 探针 `p(T|O,C)` 的宏 F1 交叉验证；用任务-only 动作探针的 `R²_{T→A}` 度量捷径可走多远。**捷径风险** `SG = κ · R²_{T→A} ∈ [0,1]`。

**定义 4（覆盖格与覆盖度）**
`cell = (s, o_class, c_axis_value)`，`c_axis ∈ {pos, distractor, background, unseen, human}`。`M[cell] = |{τ : cell ∈ τ}|`；
`cov_m(D) = |{cell : M[cell] ≥ m}|`；`worst_m(D) = min_{cell ∈ Cells} M[cell]`。

**定义 5（近似去混杂）**
给定 `ε>0, m∈ℕ`，D′ 是 `(ε,m)`-去混杂的，若对每个有支撑的 `(t,o,c)`：
`|P_{D′}(O=o | T=t) − P_{D′}(O=o)| ≤ ε`，`|P_{D′}(C=c | T=t) − P_{D′}(C=c)| ≤ ε`，且 `M[t,o,c] ≥ m`。
**目标**：在预算内使 D′ 逼近 `(ε,m)`-去混杂，同时不破坏 `P(A | O, S, g)` 的因果一致性。

**定义 6（重组合法谓词）**
`V(τ̂) = G(τ̂) ∧ K(τ̂) ∧ P(τ̂) ∧ Sem(τ̂)`。
- `G`：深度/遮挡/边缘一致，前景–背景接缝无光晕，物体不悬空；
- `K`：末端轨迹 IK 残差 `≤ ε_ik`，无自碰撞，夹爪开度匹配目标物体宽度；
- `P`：物体不穿透支撑面，放置后静态稳定，插入–倾倒满足公差；
- `Sem`：指令–物体–目标一致，技能段标签被独立分类器确认。
训练集只接受 `V(τ̂)=1` 的样本；被拒样本记录原因，用于改进生成器（active hard-negative mining）。

**定义 7（预算化采集目标）**
候选干预 `Ξ={ξ_i}`，成本 `c(ξ_i)`（生成 + 验证 + 存储），预算 B。选择 `I⊆Ξ`：
`max_I  min_{cell} M_{D∪I}[cell]`（最差格覆盖），
` s.t.  Σ_{ξ∈I} c(ξ) ≤ B`，且 `SG(D∪I) ≤ SG(D) − Δ`（去混杂约束），
并对合成/真实比例设上限 `|I| / |D∪I| ≤ ρ`（防止分布被合成主导）。
该目标对覆盖是次模的，贪心有 `1−1/e` 近似；`SG` 约束用拉格朗日或可行性过滤实现。

**定义 8（留轴分层选择）**
对每个轴 `a` 与模型 `π`，用 `n_a` 次留出试验的成功数算 Clopper–Pearson 下界 `L_a(π)`。提交门禁：
`LASOK(π) = ∀a: L_a(π) ≥ γ_a`；
在 `LASOK` 内按 `min_a L_a(π)` 或平均分排序。若无模型可行，退回保守基线并记录，而不是提交平均分最高者。

### 4.1 因子化与覆盖矩阵

```python
def factorize(episode, segmenter, detector, skill_clf):
    T = episode.language
    O = detector.track(episode.frames)                 # (class, affordance, pose, size, state)
    C = context_estimator(episode.frames)              # background id, lighting, camera, humans
    S = segmenter(episode.actions, episode.frames)     # skill boundaries
    S = [(s, skill_clf.confirm(seg), o, g) for (s, o, g, seg) in S]
    return Episode(T=T, C=C, O=O, S=S, A=episode.actions, Y=episode.outcome)


def coverage_matrix(episodes):
    M = Counter()
    for e in episodes:
        for (s, _, o, _) in e.S:
            for c_val in context_values(e.C):
                M[(s, o.class, c_val)] += 1
    return M
```

### 4.2 候选干预生成

```python
def candidates(e, object_bank, context_bank, skill_bank):
    out = []
    for o_src in e.O:
        for o_dst in object_bank.same_affordance(o_src):     # OSR
            out.append(OSR(e, o_src, o_dst))
    for c in context_bank.sample(k=4):                        # CSR
        out.append(CSR(e, c))
    for wording in paraphrase_bank(e.T):                      # relabel
```

### 4.3 动作重定向（OSR 的关键）

物体从 `o_s` 换成 `o_t` 时，不能原样搬动作；在物体对齐坐标系里做重定向：

```python
def retarget(action, o_src, o_dst):
    s = o_dst.size / o_src.size
    # 夹爪开度按宽度缩放，预抓取偏移按质心差平移
    action.gripper = clip((action.gripper - o_src.width / 2) * s + o_dst.width / 2,
                          o_dst.width * 0.6, o_dst.width * 1.2)
    action.ee_pos += R_align(o_src) @ (o_dst.centroid - o_src.centroid)
    return action

def retarget_or_reject(traj, o_src, o_dst, ik_solver, eps=1e-3):
    tr = [retarget(a, o_src, o_dst) for a in traj]
    resid = max(ik_solver.residual(a) for a in tr)
    return (tr, True) if resid <= eps else (traj, False)   # 失败则拒绝，不硬塞
```

### 4.4 四重合法过滤

```python
def valid(tau_hat, vlm, ik, depth_model, physics):
    G   = depth_model.is_geometrically_consistent(tau_hat.frames)
    K   = all(ik.residual(a) <= EPS_IK for a in tau_hat.A) and not ik.self_collide(tau_hat.A)
    P   = physics.no_penetration(tau_hat) and physics.stable_after_place(tau_hat)
    Sem = vlm.instruction_matches(tau_hat.T, tau_hat.O, tau_hat.S) and \
          all(skill_clf.confirm(seg) for seg in tau_hat.S)
    return G and K and P and Sem
```

### 4.5 覆盖优先的贪心选择

```python
def select(cands, M, budget, rho, delta_sg, cost, sg_fn, D):
    selected, spent = [], 0.0
    pool = [c for c in cands if valid(c)]
    while pool:
        best, best_gain = None, -1
        for c in pool:
            if spent + cost(c) > budget: 
                continue
            if (len(selected) + 1) / (len(D) + len(selected) + 1) > rho:
                break
            M2 = M + coverage_delta(c)
            gain = min_cell(M2) - min_cell(M)            # 最差格提升
            if gain > best_gain and sg_fn(D + selected + [c]) <= sg_fn(D) - delta_sg:
                best, best_gain = c, gain
        if best is None:
            break
        selected.append(best); spent += cost(best); pool.remove(best)
    return selected
```

### 4.6 不变性正则（可选，防止数据仍有残余混杂）

```python
def invariance_penalty(features, task_ids, ctx_ids, head):
    # 任务/上下文对抗头：特征不应能预测 T 或 C
    task_loss = adv_ce(head.task(features), task_ids)
    ctx_loss  = adv_ce(head.ctx(features), ctx_ids)
    return task_loss + ctx_loss

# 总损失：行为克隆 + λ * 对抗不变性
loss = bc_loss(policy(obs), action) + lam * invariance_penalty(features, T, C, adv_head)
```

> 注意：**优先靠数据去混杂，正则只是补丁**。若数据仍高度混杂，单靠对抗正则可能学到「任务不可辨但场景仍可辨」的伪不变特征。

| **E201** | 原始数据是否真的有任务–场景混杂 | 场景-only 探针 vs 任务-only 探针 | `κ`、`SG`、探针宏 F1、`R²_{T→A}` | `SG` 显著 > 0；否则本轮前提被削弱 |
| **E202** | CASCADE 是否降低混杂 | 原数据 vs +OSR vs +CSR vs +OSR+CSR | `κ`、`SG`、场景-only 探针准确率 | 探针准确率显著下降（捷径被拆） |
| **E203** | 覆盖选择是否优于随机/按分数 | 随机增广 vs 按当前分数 vs 贪心最差格覆盖 | `cov_m`、`worst_m`、单位成本覆盖增益 | 贪心覆盖 > 随机（同预算） |
| **E204** | 跨任务正迁移是否存在 | 留一任务 vs 全任务训练；有/无 XSS | 留出任务成功率、技能段成功率 | XSS 提升留出任务；否则 H5 不成立 |
| **E205** | 合成样本是否提升轴外泛化 | 无合成 vs 有合成（同真实数据） | 5 轴逐轴 SR、最差轴 LCB | 最差轴增益 > 平均轴增益 |
| **E206** | VF 是否必要 | 无 VF vs 弱 VF vs 四重 VF | 物理违例率、下游 SR、方差 | 无 VF 会更差或更不稳定；四重 VF 最优 |
| **E207** | 合成比例是否有上限 | ρ ∈ {0, .25, .5, .75} | 真实分布 SR、轴外 SR、`SG` | 存在最优 ρ；过高会分布漂移 |
| **E208** | 端到端 CASCADE + UIP-01 | UIP-01 单独 vs +CASCADE vs +LAS | 代理榜单分、最差轴、可信度代理 | 最差轴提升；平均分不显著下降 |

**切分原则**：按 `(任务族, 物体类, 轴)` 分层留出；**同一物体实例的不同 episode 不能同时出现在训练与测试**，否则会高估泛化。
**合成–真实校准**：先在 RRV 上做，任何「真机」结论必须标注为代理；正式提测后用真实榜单与事件日志重估 `κ`、`SG`、逐轴 SR。

## 7. 可证伪预测（预注册）

若 CASCADE 的核心假设成立，应观察到：

1. **P1（去混杂）**：加入 OSR+CSR 后，场景-only 探针预测任务身份的宏 F1 显著下降，而动作预测性能不降（或降幅远小于探针）。
2. **P2（覆盖优于平均）**：同预算下，最差格覆盖策略的**最差轴**增益大于平均轴增益；若只提升平均、不提升最差轴，说明选择器偏了。
3. **P3（路由收益收缩）**：若数据去混杂有效，UIP-03 的 32 专家路由相对单模型的增益应缩小；若反而扩大，说明数据仍未解决混杂。
4. **P4（VF 必要性）**：去掉 VF 后，物理违例率与下游方差上升；若去掉 VF 反而更好，则说明当前生成器的错误恰好是「有益噪声」，需要重新审视假设。
5. **P5（人类轴）**：HIX 应主要在 human 轴上提升，而不应显著改变其他轴；若所有轴一起涨，可能是合成数据泄漏了评测信息（需排查）。

这些预测是**可失败的**：任意一条在预注册的统计口径下失败，都应当收缩或改写本轮旗舰，而不是靠调参掩盖。

## 9. 本轮最大风险

**一句话**：最大的风险不是合成数据不够多，而是**合成样本在几何/动力学上不成立、却通过了偏弱的合法谓词**，于是模型学到更精致的伪相关；如果隐藏评测轴与合成轴不匹配，整套数据工程会退化为昂贵的自欺——因此必须先用 TCL 证明混杂存在、用 VF 证明合成合法、用 LAS 证明增益落在正确轴上，再投入规模。
