# 第 65 轮（承接第 64 轮「GRIP 接触接地闭环」IP-204~213；灵感循环 III 第 1 轮；本轮灵感：「多机协作」×「惯性测量单元」）

> 第 64 轮用 F/T 与触觉把几何先验从"不可检验的假设"变成"可证伪的在线假设"，其最大风险直指隐藏假设 A83：**若力觉传感器存在未建模偏置、漂移或饱和，且接触模型本身错误（软接触、未建模动力学、接触点歧义），CGG 会把"传感器/模型错误"误判为"几何幻觉"——在正确几何上主动降级、在错误几何上放行，力觉从接地真值反变为单点故障与物理伤害源。** 更根本地，第 64 轮仍是**单体**论证：一台机器人的力觉再准，也只是"一个证人"。
>
> 本轮用两个正交灵感正面拆解 A83：
>
> - **惯性测量单元（IMU）** 提供牛顿方程的"惯性半边"，把测得旋量精确分解为「自运动惯性项 + 外部接触项」，直接消除"未建模动力学"这一最大误归因来源；反过来，接触事件提供**零运动/已知加速度锚点**，把 IMU 的零偏与漂移钉住——**IMU 需要接触来定漂，接触需要 IMU 来去自运动，二者是对偶而非替代**。
> - **多机协作** 提供"多个独立物理证人"：共享物体上的旋量平衡 Σ_r W_ext^r + W_g = W_dyn 是一个**分布式物理不变式**，任一机器人几何幻觉导致的力预测偏差都会破坏该不变式而被其余机器人证伪；再用拜占庭鲁棒共识拒绝"说谎/故障"的少数。
>
> 核心命题：**把"接地"从单体接触真值，升级为「惯性-接触对偶 + 多机物理共识」——一个力觉可以骗人，N 个独立机器人 + 牛顿定律不会同时骗人；单体的"暂时保守"由此升级为多体的"交叉证伪"。**

## 0. 直觉与动机

**灵感 1（IMU → 惯性归因门 IAG：把"自运动"从"接触"里减掉）**
直觉：机器人快速移动时，腕部 F/T 读到的"力"很大一部分是自己加速产生的惯性伪力，而不是接触。第 64 轮的 CGG 却把它全归给接触/几何，于是出现两类系统性错误：几何正确 + 加速度未建模 → 残差大 → 误降级；几何错误 + 恰好被惯性项抵消 → 残差小 → 误放行。IMU 直接测质心加速度 a_com 与角速度 ω，可算 W_in = [m·a_com; I·ω̇ + ω×(Iω)]（含 IMU→腕部杠杆臂项的刚体变换），**先减掉再检验**。CGG 的输入从 W_meas 变为 Ŵ_ext = W_meas − Ŵ_in。这把 A83 中"未建模动力学"这一项从 CGG 的残差里移出，交给一个可单独标定、单独认证的通道。

**灵感 2（接触 → 接触-漂移锚 CDA：用接触反哺 IMU）**
直觉：IMU 航位推算会漂，但"接触"是天然的零速/已知运动锚点：机器人静止接触、或与运动学已知的物体保持接触时，a_com 被接触约束固定。把每个接触段当作一次 ZUPT（零速更新）或已知加速度更新，零偏与漂移被反复钉住。**接触越频繁，IMU 越准；IMU 越准，接触归因越准**——这是一个正反馈，但也是本轮最危险的耦合（见第 5 节风险 6）。

**灵感 3（多机 → 分布式旋量平衡不变式 + 拜占庭共识）**
直觉：两人抬桌，若一人虚报"我托住了"，桌子会倾斜或另一人受力突变，物理会揭穿他。形式化：共享刚体 O 上各机器人外部旋量之和必须等于重力加物体惯性项，Σ_r Ŵ_ext^r + W_g = Ŵ_dyn^O。任一机器人若因几何幻觉而错报接触力，Σ_r Ŵ_ext^r 就偏离；残差检验可检出，leave-one-out 可定位元凶。再用坐标中位数/Krum 做鲁棒聚合，使 f < n/2 个故障机器人无法翻转"几何是否降级"的决策。

**灵感 4（多机 → 相对惯性几何 RIG + 接触时统 CTS）**
直觉：多机共识要求"同一个世界、同一块表"。IMU 预积分给高频相对位姿，但会漂；共享接触事件（同一物体接触、碰撞冲量）是天然的 loop closure 与共同时刻。RIG 把 IMU 预积分与接触约束紧耦合，使相对位姿漂移被接触事件反复拉回；CTS 用接触冲量起始时刻对齐各机时钟，保证见证可比较、因果序一致。

**灵感 5（合流 → CONCERT 与组件原位升级）**
五者咬合：每个机器人本地跑 GRIP + IAG/CDA，产出跨机见证 w_r；WIT/DCC 在分布式语义层做旋量平衡检验与拜占庭共识，更新共享 φ 球与 geo_degraded；RIG/CTS 保证各见证在同一参考系、同一时间轴；COS 把安全从"单体不滑不压伤"扩展到"协作力闭合 + 机间不碰撞"。组件原位升级：RSC-F→RSC-M（多见证球校准，不一致只许膨胀）、WCV-F→WCV-M（一致取交集、不一致取并集）、OLP-F→OLP-M（增惯性/相对位姿特征）、AIC-F→AIC-M（增 IMU 欺骗/通信/拜占庭干扰）、J_grip→J_concert（quorum 分布式证书）。

## 1. 形式化定义（增量：定义 217–230）

- **定义 217（CONCERT 闭环）**：CONCERT = ({GRIP_r}_{r=1..n}, IAG, CDA, WIT, DCC, RIG, CTS, COS, J_concert)。定位：GRIP 的"惯性-多机"升级，全部新增组件挂载在第 64 轮骨架上，单体 GRIP 原样保留。不变式：**每个机器人的实时路径只做本地前向（≤2ms）；IAG/CDA 的偏置更新、WIT/DCC 共识、RIG/CTS 与证书构建只在分布式语义层（10–50Hz）；跨机学习写操作永不出现在实时路径。**
- **定义 218（惯性归因门 IAG）**：测得旋量分解 W_meas = W_ext + W_in + b_W + η。由 IMU 给出 â_com、ω̂、ω̇̂，经 IMU→腕部刚体变换（杠杆臂 r_imu、旋转 R_wi）得 Ŵ_in = [m·â_com^w; Î·ω̇̂ + ω̂×(Îω̂) + 杠杆臂耦合项]。归因残差 e_in = W_meas − Ŵ_in，归因误差 δ_in ≤ m‖b_a‖ + ‖∂W_in/∂ω‖‖b_g‖ + 杠杆项。**只有 Ŵ_ext = W_meas − Ŵ_in 送入 CGG（定义 202）。**
- **定义 219（接触-漂移锚 CDA）**：接触段 c 上，接触运动学给出已知或零的 a_com^c、ω^c。零偏更新 b ← b + K(o_c − g(a_imu, ω_imu; 接触约束))，K 为卡尔曼增益，o_c 为接触约束残差。相邻锚点间隔 τ_anchor；期间位置漂移 O(½‖b_a‖τ_anchor²)，姿态漂移 O(‖b_g‖τ_anchor)。接触约束秩 ≥3 时零偏可观测。
- **定义 220（跨机见证 WIT）**：机器人 r 的见证 w_r = (T_t^r, C^r, φ̂^r, Σ_φ^r, geo_degraded^r, W_ext^r, τ_r, sig_r)。T_t^r 为 GRIP 接触一致性统计量（定义 202），W_ext^r 为 IAG 输出，τ_r 为 CTS 对齐后的时间戳，sig_r 为设备签名。
- **定义 221（分布式旋量平衡不变式）**：共享刚体 O 上，Σ_r Ŵ_ext^r + W_g = Ŵ_dyn^O（准静态时右端为 0，W_g 为物体重力旋量，Ŵ_dyn^O = [m_O a_O; d(I_Oω_O)/dt + ω_O×I_Oω_O]）。共识残差 e_cons = Σ_r Ŵ_ext^r + W_g − Ŵ_dyn^O，检验统计量 T_cons = e_consᵀΣ_cons⁻¹e_cons ~ χ²₆（H0）。leave-one-out 残差 T_cons^{−r}；若 T_cons − T_cons^{−r} > δ_attrib，则 r 为嫌疑。
- **定义 222（拜占庭鲁棒共识 DCC）**：n 机、至多 f 故障。φ̂_G = coordinate_median({φ̂^r})（或 Krum 选择）；geo_degraded_G = quorum(≥ n−f)。条件：坐标中位数需 f < n/2；Krum 需 n ≥ 2f+3。输出含被拒集合 R_bad 与 quorum 签名集 Q；DCC 只聚合**充分统计量**（φ̂、Σ、T、哈希），不传原始传感流。
- **定义 223（相对惯性几何 RIG）**：机间相对位姿 (ΔR_ij, Δv_ij, Δp_ij) 由 IMU 预积分给出；共享物体表面点/碰撞事件提供接触约束 r_contact（loop closure）。优化 min Σ‖r_imu‖²_{Σ_i} + Σ‖r_contact‖² + Σ‖r_obs‖²，输出相对位姿及其协方差，供 WIT 对齐坐标系。
- **定义 224（接触时刻同步 CTS）**：接触冲量起始时刻 t_imp 为共享物理事件。估计钟差 δ_ij 与钟漂，使同一冲量在两机的检测时间差 ≤ ε_t，且事件因果序一致；冲量事件同时校验 RIG 的相对位姿跳变。
- **定义 225（协作物体安全 COS）**：共享物体需协作力闭合 Σ_r G_r f_r + W_g ≈ 0，且 f_r 在摩擦锥内；ρ_shared 为力闭合方程残差裕度，ρ_sep 为机间最小距离裕度。联合安全裕度 ρ_collab = min(ρ_rob, ρ_dir, ρ_slip, ρ_force, ρ_shared, ρ_sep)。
- **定义 226（RSC-M 多见证球校准）**：球半径融合自身残差与共识残差；与共识不一致的机器人**不得单独收缩全局球，只能膨胀**（保守单向），防止一个被欺骗的机器人把全局球压小。
- **定义 227（WCV-M 多机鲁棒编译）**：多机 φ 球在一致时取交集（更紧），不一致时取并集（保守膨胀）；分布式 CVaR 取各机最坏尾部；交集为空则回退并置 `consensus_conflict=True`。
- **定义 228（OLP-M 多机力/惯性增强投影）**：x''' = [x''; e_in; e_rel]，e_in 为 IAG 归因特征，e_rel 为 RIG 相对位姿特征；遗憾界增 L_in、L_rel 项。
- **定义 229（AIC-M 多机干扰扩展认证）**：ℰ_M = ℰ_F × ℰ_imu × ℰ_comm × ℰ_byz，ℰ_imu 含零偏/漂移/欺骗/振动，ℰ_comm 含延迟/丢包/分区，ℰ_byz 含拜占庭机器人，另加相对位姿误差；ρ_dir 在 ℰ_M 上重算，ρ_force 在偏置/欺骗边界上取最坏。
- **定义 230（J_concert 分布式证书）**：J_concert = ({J_grip^r}_{r∈Q}, consensus_hash, T_cons, quorum, time_sync_ver, imu_calib_ver, rel_pose_hash, R_bad)。Valid ⇔ |Q| ≥ n−f ∧ ∀r∈Q Valid(J_grip^r) ∧ T_cons ≤ χ²₆,₁₋α_cons ∧ ε_t ≤ ε_t,max ∧ δ_in ≤ δ_in,max ∧ ρ_collab ≥ 0。

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 7（惯性归因把误降级压回偏置量级）**：无 IAG 时 CGG 残差含未减惯性项 δ_in = W_in，非中心参数 λ_noIMU = ‖Σ_w^{-1/2}W_in‖²；典型 m=2kg、a=1m/s²、σ_F=0.05N 时 λ_noIMU ≈ 1600，误降级几乎必然。有 IAG 后 δ_in ≈ m·b_a（b_a ≤ 0.05m/s²），λ_IAG ≈ 4，低于 χ²₆ 阈值——**惯性归因把"未建模动力学"从决定性错误降为可控偏置**。
- **引理 8（接触-漂移锚的偏置可观测性）**：接触约束秩 ≥3 时，零偏 Fisher 信息 J_b = N_c·Σ_imu⁻¹，后验协方差 ⪯ Σ_imu/N_c；两锚点间位置漂移 ≤ ½‖b_a‖τ_anchor²。τ_anchor=1s、b_a=0.05m/s² 时漂移 ≈ 2.5cm，落在接触几何容差内。
- **定理 7（拜占庭共识的决策不可翻转）**：n 机至多 f 故障，若 f < n/2，则逐坐标中位数落在诚实机器人逐坐标区间内；若所有诚实机器人对 geo_degraded 判定一致，则共识判定与诚实一致——**少数故障无法翻转降级决策**。Krum 版本需 n ≥ 2f+3。quorum 证书要求 |Q| ≥ n−f。
- **定理 8（共享物体残差的幻觉定位）**：若机器人 r 的几何幻觉使其接触力预测偏差 δf，则其外部旋量偏差 δW_r = G(c_r)δf，共识残差整体偏移 δW_r；当 ‖δW_r‖ 超过阈值即可检出，且 leave-one-out 使 T_cons 显著下降从而定位 r。f < n/2 时最多 f 个嫌疑，鲁棒定位成立。
- **定理 9（CONCERT 端到端安全）**：Valid(J_concert) ⇒ 每个 quorum 内机器人满足第 64 轮定理 6 ∧ IAG 归因误差 ≤ δ_in,max ∧ 共享物体旋量平衡 ∧ 时统/相对位姿在界内 ∧ 协作力闭合与机间距离安全——**证书链从"几何-技能-干扰-接触"四层扩到"几何-技能-干扰-接触-惯性-共识"六层**。

## 2. 形式化定义（完整版）

**定义 217（CONCERT 闭环）** CONCERT 是 GRIP 的"惯性-多机"升级：每个机器人 r 本地保留第 64 轮完整 GRIP_r，并在其前后挂载 IAG（惯性归因）与 CDA（接触-漂移锚）；分布式语义层运行 WIT/DCC（跨机见证与拜占庭共识）、RIG/CTS（相对惯性几何与接触时统）、COS（协作物体安全），并原位升级 RSC-F→RSC-M、WCV-F→WCV-M、OLP-F→OLP-M、AIC-F→AIC-M、J_grip→J_concert。不变式：**本地实时路径只做 IAG 前向、CGG 残差、SLD/FCS、OLP-M/WCV-M 编译与首技能派发（≤2ms）；偏置更新、共识、相对定位、时统与证书构建只在分布式语义层（10–50Hz）；跨机学习写操作永不出现在实时路径。**

**定义 218（惯性归因门 IAG）** 设腕部测得旋量 W_meas ∈ ℝ⁶。刚体动力学给出
W_meas = W_ext + W_in + b_W + η，W_in = [m·a_com; I·ω̇ + ω×(Iω)]，
其中 a_com、ω、ω̇ 由 IMU 测得并变换到腕部系：â_com^w = R_wi(a_imu − b_a) + [ω̂]×²·r_imu + [ω̇̂]×·r_imu（r_imu 为 IMU 到腕部的杠杆臂），Î 为含平行轴项的质量惯量。于是
Ŵ_in = [m·â_com^w; Î·ω̇̂ + ω̂×(Îω̂) + 杠杆臂耦合项]，Ŵ_ext = W_meas − Ŵ_in。
归因残差 e_in = W_meas − Ŵ_in；归因误差
δ_in ≤ m‖b_a‖ + ‖∂W_in/∂ω‖·‖b_g‖ + ‖∂W_in/∂r_imu‖·δr_imu + δ_model。
**只有 Ŵ_ext 送入 CGG（定义 202）**；e_in 单独作为 IAG 的健康指标：e_in 大而 CGG 残差正常，说明问题在 IMU/惯性模型而非几何。

**定义 219（接触-漂移锚 CDA）** 在接触段 c 上，接触运动学给出已知或零的参考加速度 a_com^c 与角速度 ω^c：
- 静止支撑/抓持：a_com^c = 0（或仅重力补偿），ω^c = 0 → ZUPT；
- 与运动学已知的物体保持接触：a_com^c = a_contact（由物体运动模型给出）。
零偏更新 b ← b + K(o_c − g(a_imu, ω_imu; 接触约束))，K 为卡尔曼增益，o_c 为接触约束残差，g 为预测观测。接触约束秩 ≥3 时 b_a 可观测，秩 ≥3 时 b_g 可观测。相邻锚点间隔 τ_anchor 内位置漂移 ≤ ½‖b_a‖τ_anchor² + ‖v_0‖τ_anchor，姿态漂移 ≤ ‖b_g‖τ_anchor。

**定义 220（跨机见证 WIT）** 机器人 r 在时刻 τ_r 输出见证
w_r = (T_t^r, C^r, φ̂^r, Σ_φ^r, geo_degraded^r, W_ext^r, τ_r, sig_r)，
其中 T_t^r 为 GRIP 定义的接触一致性统计量，C^r 为接触集，φ̂^r 为 GRIP 物理估计（含 Σ_φ^r），W_ext^r 为 IAG 输出的外部旋量，τ_r 为 CTS 对齐后的时间戳，sig_r 为设备签名。WIT 只封装**充分统计量**，不暴露原始传感流（带宽与隐私）。

**定义 221（分布式旋量平衡不变式）** 设 n 个机器人共同作用于共享刚体 O（或各自观测同一 O）。在统一参考系、统一时间戳下，刚体静力学/动力学要求
Σ_r Ŵ_ext^r + W_g = Ŵ_dyn^O，
W_g = [m_O g; r_c×m_O g]（对参考点取矩），Ŵ_dyn^O = [m_O a_O; d(I_Oω_O)/dt + ω_O×I_Oω_O]。
定义共识残差 e_cons = Σ_r Ŵ_ext^r + W_g − Ŵ_dyn^O，T_cons = e_consᵀΣ_cons⁻¹e_cons；H0（所有见证与外模型正确）下 T_cons ~ χ²₆。leave-one-out 残差 T_cons^{−r} = e_cons^{−r}ᵀΣ_cons⁻¹e_cons^{−r}（从和中扣除 r 的 W_ext^r）；若 T_cons − T_cons^{−r} > δ_attrib，则 r 为嫌疑。

**定义 222（拜占庭鲁棒共识 DCC）** n 机、至多 f 故障（f 为认证时声明的上界）。对 φ̂ 逐坐标取中位数：
φ̂_G = coordinate_median({φ̂^r}_{r=1..n})，
或使用 Krum：选择与其他 n−f−2 个向量距离和最小的向量。geo_degraded_G = quorum(≥ n−f)。适用条件：坐标中位数需 f < n/2（逐坐标破坏点 50%）；Krum 需 n ≥ 2f+3。输出 (φ̂_G, geo_degraded_G, Q, R_bad)：Q 为签名有效且未被判为离群的机器人集合，R_bad = {r: T_cons − T_cons^{−r} > δ_attrib} ∪ Krum 离群集。DCC 不解释原始数据，只聚合定义 220 的见证。

**定义 223（相对惯性几何 RIG）** 机间相对位姿由 IMU 预积分给出 (ΔR_ij, Δv_ij, Δp_ij)。共享物体接触约束 r_contact：若两机在物体表面已知点 {p_i^k}、{p_j^k} 同时接触，则 T_ij·p_j^k ≈ p_i^k（T_ij 为相对位姿）；碰撞冲量事件亦给相对位置/速度约束。优化
min_{T_ij} Σ_k‖r_imu,k‖²_{Σ_imu} + Σ_k‖r_contact,k‖²_{Σ_c} + Σ_k‖r_obs,k‖²_{Σ_o}，
输出 T_ij 及其协方差 Σ_T。接触事件在无外参观测时充当 loop closure，把 IMU 漂移拉回。

**定义 224（接触时刻同步 CTS）** 设同一物理冲击在机器人 i、j 上的检测时刻为 t_i、t_j。钟差模型 t_i = t_j + δ_ij + ε_ij。由多次冲击事件估计 δ_ij（加权最小二乘/卡尔曼），并校验钟漂。要求估计后 |t_i − t_j − δ_ij| ≤ ε_t，且同一冲击在两机的派生事件因果序一致。CTS 的冲击事件同时用于 RIG 的相对位姿跳变校验（若冲击时刻相对位姿发生非物理跳变，判 RIG 异常）。

**定义 225（协作物体安全 COS）** 共享物体 O 上多机接触力 {f_r} 需满足协作力闭合
Σ_r G_r(c_r) f_r + W_g ≈ 0，f_r ∈ K_{μ_r}(n_r)，‖f_r‖ ≤ f_{max,r}，
其中 G_r 为机器人 r 接触点到物体质心的旋量映射。ρ_shared = 归一化力闭合残差裕度（残差越小裕度越大，取与阈值之差）。ρ_sep = (d_min − d_safe)/d_safe 为机间最小距离裕度。联合安全裕度
ρ_collab = min(ρ_rob, ρ_dir, ρ_slip, ρ_force, ρ_shared, ρ_sep)。
ρ_shared < 0 时 COS 触发负载重分配或协作退让（compliant retreat）。

**定义 226（RSC-M 多见证球校准）** 机器人 r 的球更新同时使用自身残差 e_t^r 与共识残差映射 e_cons^r = ‖Σ_cons^{-1/2}e_cons‖/σ_J。融合权重按 IAG 归因质量 w_in（δ_in 越小权重越大）与共识一致性调节。关键规则：**与共识不一致的机器人不得单独收缩全局球，只能膨胀**（保守单向），即
if r ∈ R_bad or T_cons − T_cons^{−r} > δ_attrib: r_global ← max(r_global, κ_infl·r_global)
else: r_global ← clip((1−β_c)r_global + β_c e_t^r, r_min, r_max)。
这样单个被欺骗/故障机器人无法把全局不确定球压小。

**定义 227（WCV-M 多机鲁棒编译）** 各机 φ 球 B(φ̂^r, r^r)。一致时（R_bad 为空且 T_cons ≤ 阈值）取交集
B_G = ∩_r B(φ̂^r, r^r)（更紧，降低保守性）；
不一致时取并集/凸包
B_G = conv(∪_r B(φ̂^r, r^r))（保守膨胀）。
分布式 CVaR 取各机最坏尾部的上包络；搜索域 B_G ∩ 𝒢(g) ∩ K(μ̂_G) ∩ ℱ(f_lim)。若交集为空，回退并集并置 `consensus_conflict=True` 写入 J_concert。

**定义 228（OLP-M 多机力/惯性增强投影）** x''' = [x''; e_in; e_rel] ∈ ℝ^{d''+d_in+d_rel}，d_in=d_rel=16。e_in = E_in(e_in 向量, IMU 健康度)，e_rel = E_rel(T_ij, Σ_T)。投影头
K_W(x''') = Π₀(x''') + h(x''')ᵀW，梯度上界 G̃_m = G·(L_h + L_force + L_in + L_rel)·(1+κ_φ·r_max)。
惯性/相对位姿特征使移动基座与多机协同段的 ℓ̃ 更平滑，遗憾常数在移动/协作任务上下降。

**定义 229（AIC-M 多机干扰扩展认证）** 干扰集
ℰ_M = ℰ_F × ℰ_imu × ℰ_comm × ℰ_byz，
ℰ_imu = {‖b_a‖≤ε_a, ‖b_g‖≤ε_g, 漂移, 欺骗 a_spoof, 振动}；
ℰ_comm = {延迟≤d_max, 丢包≤p_loss, 分区}；
ℰ_byz = {至多 f 个见证任意伪造（受签名/物理一致性约束）}；
另加相对位姿误差 {‖δT‖ ≤ ε_T}。ρ_dir 在 ℰ_M 上重算（采样数 n_cert 由 96 增至 128，其中 32 给 IMU、32 给通信/拜占庭）；ρ_force 在 IMU 偏置/欺骗顶点与通信最坏延迟下取最坏。J_dir 增 `imu_calib_ver`、`comm_ver`、`byz_ver`。

**定义 230（J_concert 分布式证书）** J_concert = ({J_grip^r}_{r∈Q}, consensus_hash, T_cons, quorum, time_sync_ver, imu_calib_ver, rel_pose_hash, R_bad)。验证规则：
Valid(J_concert) ⇔
1. |Q| ≥ n−f 且 Q 中每个 J_grip^r 有效（第 64 轮定义 215）；
2. T_cons ≤ χ²₆,₁₋α_cons（共享物体旋量平衡）；
3. ε_t ≤ ε_t,max 且 time_sync_ver 一致（定义 224）；
4. δ_in ≤ δ_in,max 且 imu_calib_ver 为当前标定版本（定义 218/219）；
5. rel_pose_hash 与 RIG 输出一致且 Σ_T 在界内（定义 223）；
6. ρ_collab ≥ 0 且 R_bad 已记录（定义 225）。
审计链：每个 J_grip^r 可追溯单机接触接地（第 64 轮 contact_hash/probe_log），consensus_hash 追溯多机见证与共识过程，R_bad 追溯被拒机器人，imu_calib_ver/time_sync_ver 追溯惯性与时统状态。

### IP-214 IAG（惯性归因门）

```python
class InertialAttributionGate:
    """先减自运动惯性旋量，再把外部接触旋量交给 CGG。实时 <0.1ms。"""
    def __init__(self, mass, inertia, r_imu, Sigma_w, Sigma_imu):
        self.m, self.I = mass, inertia
        self.r_imu = r_imu
        self.Sigma_w, self.Sigma_imu = Sigma_w, Sigma_imu

    def subtract(self, W_meas, a_imu, omega, omega_dot, b_a, b_g, R_wi):
        a_w = R_wi @ (a_imu - b_a)
        # 杠杆臂：a_com = a_imu + omega_dot x r + omega x (omega x r)
        a_com = a_w + np.cross(omega_dot, self.r_imu) \
                    + np.cross(omega, np.cross(omega, self.r_imu))
        alpha = omega_dot - b_g
        # 平行轴：I_wrist = I_com + m*(r^T r I - r r^T)
        I_w = self.I + self.m * (np.dot(self.r_imu, self.r_imu) * np.eye(3)
                                 - np.outer(self.r_imu, self.r_imu))
        tau_in = I_w @ alpha + np.cross(omega, I_w @ omega)
        W_in = np.concatenate([self.m * a_com, tau_in])
        W_ext = W_meas - W_in
        e_in = W_meas - W_in
        return W_ext, e_in, np.linalg.norm(W_in)
```

### IP-215 CDA（接触-漂移锚）

```python
class ContactDriftAnchor:
    """接触段 = 零速/已知加速度锚点，在线估计 IMU 零偏。"""
    def __init__(self, Sigma_imu, Sigma_anchor=1e-4):
        self.b_a = np.zeros(3); self.b_g = np.zeros(3)
        self.P = np.eye(6) * 1e-2
        self.Sigma_imu, self.Sigma_anchor = Sigma_imu, Sigma_anchor

    def update(self, a_imu, omega, contact_mode, a_contact=None):
        if contact_mode == 'free':
            return self.b_a, self.b_g, 0.0           # 无锚点，不更新
        if contact_mode == 'static':
            a_ref, omega_ref = np.zeros(3), np.zeros(3)   # ZUPT
        else:                                          # 已知运动接触
            a_ref, omega_ref = a_contact, np.zeros(3)
        H = np.hstack([-np.eye(3), np.zeros((3, 3))])   # 观测 a_imu ~ b_a
        innov = a_imu - self.b_a - a_ref
        # 简化卡尔曼更新（w 通道同理，省略）
        S = H @ self.P @ H.T + self.Sigma_anchor
        K = self.P @ H.T @ np.linalg.inv(S)
        delta = np.concatenate([innov, omega - self.b_g - omega_ref])
        self.b_a += K @ innov
        self.P = (np.eye(6) - K @ H) @ self.P
        rank = 3 if contact_mode == 'static' else 3
        return self.b_a, self.b_g, rank
```

### IP-216/217 WIT + DCC（跨机见证与拜占庭共识）

```python
def witness(T_t, C, phi, Sigma_phi, degraded, W_ext, tau, key):
    payload = (hash_contact(C), hash_phi(phi), degraded, tau)
    return dict(T=T_t, C=C, phi=phi, Sigma=Sigma_phi, degraded=degraded,
                W_ext=W_ext, tau=tau, sig=sign(key, payload))

def dcc_consensus(witnesses, n, f):
    phis = np.array([w['phi'] for w in witnesses])
    phi_med = np.median(phis, axis=0)                 # 逐坐标中位数
    # Krum（可选，n >= 2f+3）
    def krum():
        d = [np.sum(sorted(np.linalg.norm(phis - v, axis=1))[1:n-f])
             for v in phis]
        return phis[int(np.argmin(d))]
    phi_G = krum() if n >= 2*f + 3 else phi_med
    votes = sum(w['degraded'] for w in witnesses)
    degraded_G = votes >= (n - f)                     # quorum
    dist = np.linalg.norm(phis - phi_G, axis=1)
    R_bad = set(np.argsort(dist)[-f:]) if f > 0 else set()
    Q = [i for i in range(n) if i not in R_bad and verify_sig(witnesses[i])]
    return phi_G, degraded_G, Q, R_bad

def wrench_balance_check(witnesses, W_g, W_dyn_hat, Sigma_cons, delta_attr):
    e = sum(w['W_ext'] for w in witnesses) + W_g - W_dyn_hat
    T = e.T @ np.linalg.inv(Sigma_cons) @ e
    suspects = []
    for i, w in enumerate(witnesses):
        e_minus = e - w['W_ext']
        T_minus = e_minus.T @ np.linalg.inv(Sigma_cons) @ e_minus
        if T - T_minus > delta_attr:
            suspects.append(i)                        # leave-one-out 定位
    return T, suspects
```

### IP-218/219 RIG + CTS（相对惯性几何与接触时统）

```python
def rig_optimize(imu_preint, contact_events, T_init, Sigma):
    """IMU 预积分 + 接触 loop closure 的因子图优化。"""
    T = T_init
    for _ in range(5):
        H, g = np.zeros((6, 6)), np.zeros(6)
        for (dR, dv, dp, tau) in imu_preint:           # IMU 因子
            r = residual_imu(T, dR, dv, dp)
            J = jacobian_imu(T)
            H += J.T @ Sigma['imu'] @ J; g += J.T @ Sigma['imu'] @ r
        for (p_i, p_j) in contact_events:              # 接触因子（loop closure）
            r = T @ p_j - p_i
            J = jacobian_contact(T, p_j)
            H += J.T @ Sigma['contact'] @ J; g += J.T @ Sigma['contact'] @ r
        T = exp_se3(-np.linalg.solve(H + 1e-6*np.eye(6), g)) @ T
    return T, np.linalg.inv(H + 1e-6*np.eye(6))

def cts_sync(impact_events):
    """impact_events: [(t_i, t_j)] 同一冲击在两机的检测时刻。"""
    A = np.array([[1.0, t] for (t, _) in impact_events])   # 钟差 + 钟漂
    b = np.array([tj - ti for (ti, tj) in impact_events])
    (delta, skew), *_ = np.linalg.lstsq(A, b, rcond=None)
    residual = np.max(np.abs(A @ [delta, skew] - b))
    return delta, skew, residual                   # residual 即 ε_t
```

### IP-220/227 COS + WCV-M（协作安全与多机编译）

```python
def cooperative_force_closure(contacts_by_robot, W_g, mu, f_max):
    """多机协作力闭合：min ||sum_r G_r f_r + W_g||^2, s.t. 摩擦锥/力限。"""
    G = np.hstack([wrench_jacobian(c) for (c, f) in all_contacts(contacts_by_robot)])
    f0 = np.zeros(G.shape[1])
    f = solve_friction_qp(G, -W_g, mu, f_max, f0)   # QP
    res = np.linalg.norm(G @ f + W_g)
    rho_shared = (RES_THRESH - res) / RES_THRESH
    return rho_shared, f

def wcv_m_compile(balls, olp_m, x_dprime, G_set, mu_hat, f_lim, same_consensus):
    if same_consensus:
        lo = np.max([b['lo'] for b in balls], axis=0)   # 交集
        hi = np.min([b['hi'] for b in balls], axis=0)
        if np.any(lo > hi):
            same_consensus = False
    if not same_consensus:
        lo = np.min([b['lo'] for b in balls], axis=0)   # 并集/凸包
        hi = np.max([b['hi'] for b in balls], axis=0)
    K, rho, cvar, conflict = wcv_f_compile(
        olp_m, x_dprime, (lo + hi) / 2, np.max(hi - lo) / 2,
        None, None, 1.0, G_set, mu_hat['mu'], mu_hat['delta'], f_lim)
    if not same_consensus:
        conflict = True
    return K, rho, cvar, conflict
```

## 4. 推导

**引理 7（惯性归因把误降级压回偏置量级）** 设真实旋量 W_meas = W_ext + W_in + b_W + η，η~N(0,Σ_w)。第 64 轮 CGG 用 W_meas 直接与接触模型预测比较，若惯性项未被建模，则残差 e_noIMU = e_contact + W_in + b_W + η，其检验统计量服从非中心 χ²₆，非中心参数
λ_noIMU = ‖Σ_w^{-1/2}W_in‖²。
以 m=2kg、a_com=1m/s²、σ_F=0.05N 计，‖W_in^force‖=2N，λ_noIMU ≈ (2/0.05)² = 1600 ≫ χ²₆,₀.₉₅≈12.6，误降级概率趋近 1；且几何正确时被误判为"幻觉"。
启用 IAG 后残差 e_IAG = e_contact + (W_in − Ŵ_in) + b_W + η，其中 W_in − Ŵ_in = m·b_a + Ĩb_g 项。若 b_a ≤ 0.05m/s²，则 ‖m·b_a‖ ≈ 0.1N，λ_IAG ≈ (0.1/0.05)² = 4 < 12.6——落入接受域。
故 **IAG 把"未建模动力学"从决定性错误（λ~10³）降为可控偏置（λ~10⁰），CGG 的误降级率随之从趋近 1 降到 α_geo 量级**。∎

**引理 8（接触-漂移锚的偏置可观测性）** 在接触段，接触约束给出参考 a_com^c。观测模型 a_imu = a_com^c + b_a + R_wiᵀ(...) + η_imu，线性化后 ∂o/∂b_a = I。N_c 个独立接触锚点的 Fisher 信息
J_b = Σ_{k=1}^{N_c} (∂o_k/∂b)ᵀΣ_imu⁻¹(∂o_k/∂b) = N_c·Σ_imu⁻¹ ⪰ N_c/σ_imu²·I。
故后验协方差 Σ_b ⪯ Σ_imu/N_c，零偏误差以 1/√N_c 收缩。两锚点间位置漂移由双积分给出
‖Δp_drift‖ ≤ ½‖b_a‖τ_anchor² + ‖v_0‖τ_anchor。
取 τ_anchor=1s、‖b_a‖=0.05m/s²、v_0≈0，得 ‖Δp_drift‖ ≈ 2.5cm，落在接触几何容差内；若锚点间隔缩到 0.5s，漂移降至约 0.6cm。∎

**定理 7（拜占庭共识的决策不可翻转）** 设 n 个机器人中至多 f 个故障，f < n/2。对任一坐标 k，把 {φ̂_k^r} 排序，中位数位于第 ⌈n/2⌉ 位。由于故障数 f < n/2，诚实值至少占 n−f > n/2，故中位数必为某个诚实机器人的值（或落在诚实值区间内）。因此 φ̂_G 的每个坐标都被诚实区间包含。若所有诚实机器人对 geo_degraded 的判定一致为 d，则 quorum 投票中支持 d 的票数 ≥ n−f，而反对票 ≤ f < n−f，故 degraded_G = d——**f < n/2 个故障无法翻转降级决策**。对 Krum，当 n ≥ 2f+3 时，被选向量的距离和上界小于故障向量，结论同理。quorum 证书额外要求 |Q| ≥ n−f，保证认证时诚实多数在场。∎

**定理 8（共享物体残差的幻觉定位）** 设机器人 r 因几何幻觉把接触点 c_r' 误判为 c_r，并在其上预测接触力 f_r。其贡献的外部旋量预测偏差
δW_r = G(c_r)f_r − G(c_r')f_r'。
在共识残差中，e_cons 增加 δW_r，T_cons 增加约 ‖Σ_cons^{-1/2}δW_r‖² + 交叉项。当该增量超过检测阈值 τ_cons（由 χ²₆,₁₋α_cons 与 δ_attrib 给出）即可检出。leave-one-out 后 e_cons^{−r} = e_cons − δW_r，故 T_cons − T_cons^{−r} ≈ ‖Σ_cons^{-1/2}δW_r‖² + 2⟨Σ_cons^{-1/2}e_cons^{−r}, Σ_cons^{-1/2}δW_r⟩；当 δW_r 主导时该差值为正且超过 δ_attrib，从而把 r 列入 R_bad。由 f < n/2，至多 f 个诚实机器人可能被误列，quorum 仍由诚实多数构成，鲁棒定位成立。∎

**定理 9（CONCERT 端到端安全）** 假设第 64 轮 A77–A87 及：
- **(A88)** 通信在认证窗口内满足延迟 ≤ d_max、丢包 ≤ p_loss、分区可被检测；故障机器人数 ≤ f < n/2，且诚实机器人物理上满足牛顿定律。
- **(A89)** IMU 在标定范围内零偏有界 ‖b_a‖≤ε_a、‖b_g‖≤ε_g，接触锚点间隔 ≤ τ_anchor，欺骗幅度被 IAG 健康指标与共识残差共同约束。
- **(A90)** 共享物体质量/惯量/重力旋量 W_g 的模型误差 ≤ δ_O，且由 RIG/CTS 对齐后的相对位姿误差 ≤ ε_T、时统误差 ≤ ε_t。
- **(A91)** COS 的力闭合 QP 可行，ρ_shared、ρ_sep 的计算误差 ≤ δ_c。
- **(A92)** 分布式语义层延迟 ≤ 20ms，本地实时路径仍 ≤ 2ms，无跨机学习写操作。
则：
1. **惯性可分离**：IAG 将惯性项扣除，CGG 误降级率由引理 7 压到 α_geo 量级；e_in 与 CGG 残差分离使"IMU 故障"与"几何幻觉"可区分。
2. **接触可定漂**：接触锚点使 IMU 零偏误差以 1/√N_c 收缩，锚点间漂移 ≤ ½ε_aτ_anchor²（引理 8）。
3. **多机可交叉证伪**：共享物体旋量平衡在 T_cons 越界时检出，leave-one-out 定位嫌疑（定理 8）。
4. **共识可抗少数故障**：f < n/2 时几何降级决策不可被翻转，证书需 |Q| ≥ n−f（定理 7）。
5. **协作安全**：ρ_collab ≥ 0 覆盖各体力限/滑移 + 力闭合 + 机间距离；任一项越界触发负载重分配或协作退让。
6. **优雅降级**：通信中断 → 退回各机单体 GRIP（quorum 失效则证书不签发，但本地仍安全）；IMU 失效 → IAG 退化为第 64 轮（β 按 e_in 增大而降低）；单机故障 → DCC 将其列入 R_bad；多数故障 → 证书拒绝签发并进入 safe_idle。
7. **证书六层链**：Valid(J_concert) ⇔ 几何"接受或降级" ∧ φ 球含真值 ∧ 滑移/力限安全 ∧ 单体 LIRO 有效 ∧ 惯性归因/定漂在界内 ∧ 多机共识与协作安全成立。∎

**命题（接触-惯性对偶的漂移-耦合权衡）** 设接触时间占比为 φ_c，锚点间隔 τ_anchor ≈ τ_c/φ_c。零偏后验误差 ~ σ_imu/√(N_c) ~ σ_imu/√(φ_c·T/τ_c)，随 φ_c 增大而下降；但 CDA 用接触去校 IMU、IAG 又用 IMU 去判接触，二者形成正反馈回路。若接触模型本身错误，误差会沿回路放大，增益约为 g = (∂b̂/∂接触误差)·(∂接触判定/∂b̂)。因此存在最优接触占比 φ_c* 使"定漂收益"与"耦合放大风险"平衡；**不能无条件相信"接触越多越好"**。∎

## 7. 已知风险

**一句话**：若通信延迟/网络分区与 IMU 欺骗同时发生，DCC 的 f < n/2 假设被打破，系统可能把诚实的少数判为异常、把被欺骗的多数当作真值，而跨体惯性耦合会把任一机器人的 IMU 欺骗通过"共识"扩散为全局错误——**"多机共识"本身成为新的单点故障，CONCERT 的全部保证都依赖"多数机器人物理上诚实且时钟可比"这一隐藏假设（A88）。**

**次级风险与缓解**：
1. **多数诚实假设失效（A88）**：f ≥ n/2 时中位数/Krum 失效；缓解：证书强制 |Q| ≥ n−f 且要求通信签名与物理残差双重校验，检测到多数异常直接拒绝签发并 safe_idle，而非"猜一个共识"。
2. **通信延迟/分区使见证过期**：共识基于陈旧见证，T_cons 与 T_cons^{−r} 不再对应同一时刻；缓解：每个见证带 τ_r，超过 τ_max 的见证不进入共识（quorum 不足则不签发）；CTS 的因果序校验拦截乱序。
3. **IMU 欺骗与振动**：振动使 a_com 高频噪声大，IAG 反而引入噪声；欺骗可让 W_in 抵消真实接触；缓解：IMU 健康指标 e_in 与共识残差联合检验（两个物理独立通道），低通/频域分离振动，AIC-M 在欺骗顶点取最坏。
4. **RIG 少接触退化**：无共享接触时 IMU 预积分漂移无 loop closure；缓解：显式标注 `rel_pose_degraded`，WCV-M 取并集、证书降低置信等级，必要时回退到外参/视觉观测。
5. **共享物体模型错误**：W_g、m_O、I_O 未知或有误，使旋量平衡不变式本身错，导致误定位；缓解：把 W_g 作为联合估计变量（多机共同辨识 m_O、I_O），模型误差 δ_O 纳入 A90 与 AIC-M。
6. **接触-惯性正反馈失稳**：CDA 用（可能错误的）接触去校 IMU，IAG 再用（被污染的）IMU 去判接触；缓解：命题给出的 φ_c* 权衡、对回路增益 g 做在线稳定性监测，g 超阈值时冻结 CDA 并回退到第 64 轮。
7. **分布式实时预算与能耗**：本地新增 IAG/OLP-M/WCV-M 使实时路径逼近或超过 2ms；缓解：IAG 与 LSF 共享编码、WCV-M 用缓存候选、OLP-M 降级为 OCB-Skill 调度，语义层与本地线程隔离。
8. **隐私与带宽**：多机交换见证可能泄露传感数据；缓解：WIT 只传充分统计量（φ̂、Σ、T、哈希、签名），原始流不出本地，差分隐私可加在统计量上。
