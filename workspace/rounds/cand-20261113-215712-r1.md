> R68 的 CALM-RAS 用「在线标定潜变量 + 零标签自监督 + 单模型多任务」回答了「我的测量还准吗」，也留下了两句自陈：其一是**落在标定带宽内的缓变故障会被越标越隐形**；其二写在复杂度表里却从未被当成科学问题——**整套闭环按最坏情况、每 tick、全量运行**：五头 MTM 前向、WM k=5 滚动、COF EKF、CFA 联合后验、CAC 每 60s 影子训练与五关认证、VQAuditor 异步审计。R66 问「谁控制」，R67 问「未来怎样」，R68 问「测量还准吗」，三轮不断加能力，却把「算力与延迟当作免费且均匀的资源」。这是贯穿 R66–R68 的第二个元失败：**系统从不问「这份安全值得花多少算力、什么时候停手仍然安全」。**
>
> 本轮两个灵感正好各补一半：
>
> - **低延迟推理**不是「把全部东西跑得更快」，而是「**只把必须快的东西跑快**」。真正需要在毫秒内响应的只是快危险（碰撞、打滑、接触失稳）；而 R68 的慢故障恰恰相反——它需要的是**时间**，不是频率。于是延迟问题第一次可以被**重排**：快慢分治，反射层常驻，审慎层按需调用；并且用「随时可停的认证」（anytime certificate）保证无论计算在何处被截止，系统手里始终握有一个有效的风险上界，因而**截断不等于失守**。
> - **成本控制**不是少算，而是**把钱花在边际安全收益最高的地方**。R68 定理 14 已把总误差写成若干 α 项之和，这天然是一个可分离的凸资源配置问题：每一份算力买到的是某一项的下降，停止条件是「证书已低于安全阈值」或「边际收益低于边际成本」。昂贵的认证与训练也无需周期性全量执行——用**序贯 e 值检验**提前停止、用**事件触发**代替定时学习、用**算力积压 Lyapunov** 保证摊销不变成饥饿。
>
> 核心命题：
>
> **THRIFT-RAS（Timescale-Hierarchical Risk-aware Inference with Frugal Testing RAS，分时尺度分层风险推断 × 节俭认证闭环）——把延迟、能量、金钱提升为与风险并列的一等约束，用「频谱算力组合分配 + 随时可停认证 + 慢通道结构审计 + 节俭序贯认证 + 事件触发学习」把 R68 的固定最坏成本闭环改造成预算约束下风险最优的按需计算闭环。**
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「测量还准吗」，R69 问「**这份安全到底该花多少算力，以及在哪里停手仍然是安全的？**」

## 0. 直觉与动机

**灵感 1（低延迟推理 → 快慢分治：反射层与审慎层）**
直觉：人类不会对每一次伸手都做完整规划——多数时刻靠「系统 1」反射，只有在边界模糊、后果重大时才调用「系统 2」审慎推理。R68 的闭环恰好相反：每一 tick 都做全量审慎推理。但绝大多数 tick 的状态离安全边界很远，一个 <0.2ms 的微型策略加一个离线合成的鲁棒不变集盾，就足以在**可证明**的意义上给出安全动作；只有当状态接近不变集边界、或廉价证书不够紧时，才升级到完整 CALM-RAS。低延迟不是通过「更快地算全部」获得，而是通过「**大多数时候不算全部**」获得。

**灵感 2（低延迟推理 → 随时可停认证：截止不是悬崖）**
直觉：实时系统最怕「算到一半被截止」。若算法是 anytime 的——计算前缀越长证书越紧，且在任意一点都有一个**有效的保守上界**——那么截止就只是「用一个更松但仍然有效的证书做决策」，而不是「失控」。这把硬实时从「必须算完」变成「必须在预算内达到可接受证书」，是延迟可调度性的根基。R68 的定理 14 本身就是一个求和上界，天然适合 anytime 化：未计算的项用保守默认值，已计算的项逐步收紧。

**灵感 3（成本控制 → 安全算力是一种可定价的投资组合）**
直觉：每一次额外推理都是一次「投资」：付出毫秒、焦耳、美元，换取风险上界某一项的下降。若不做预算，系统会在安全裕度充足时继续烧算力（过度认证），而在真正危险时又可能因为预算被前面耗尽而捉襟见肘（预算饥饿）。正确做法是让**预算影子价格 μ** 内生决定：边际风险下降/边际成本 > μ 的模块才配算力；当证书已低于安全阈值就停止；当预算不可行就执行 R68 最坏情况回退——**成本压力只能让系统更保守，绝不能让系统更冒险**。

**灵感 4（成本控制 → 摊销：序贯认证与事件触发学习）**
直觉：R68 每 60s 全量跑五关认证、持续影子训练，是「定时」而非「按需」。认证本质是假设检验：按成本效率排序各关，用 e 值财富过程提前接受/拒绝，期望只跑 2~3 关即可达到同样错误率；训练本质是对分布漂移的响应：用漂移 e 值触发，没漂移就不训练，并用算力积压 Lyapunov 证明摊销不会让模型无限陈旧。安全关键关（如 canary）永远全跑，可摊销的只是非关键关——**省的是冗余，不是防线**。

**灵感 5（两灵感合流 → 反向 Nyquist：算力应按危险带宽分配）**
直觉：采样定理说，要看清带宽 ω 的变化，采样率至少 2ω；而算力成本正比于采样率。于是「每 tick 全量」等于**用最快危险的采样率去补贴所有慢危险**，极其浪费；而「统一降频」又会让快危险混叠成看不见的慢变化，极度危险。正确结构是**多速率**：快危险高频、贵、常驻；慢危险低频、廉、长窗口。更妙的是，慢故障的检测能力随时间以 √n 甚至 T·√n 增长——**耐心可以替代算力**。这解释了 R68 的原罪：它想用「更高频的标定」解决慢故障，方向反了；慢故障需要的是**更长的记忆与结构先验**，而那几乎免费。

**灵感 6（对 R68 原罪的对症下药 → 慢通道审计：审计计量学本身）**
直觉：R68 分不清「传感器漂移」与「缓变故障」，因为二者都在标定带宽内、都以加性偏置出现。但它们在**物理成因结构**上可分：热漂移是可逆的、由温度驱动、在温度循环下会反向；老化/慢泄漏/缓慢松动是不可逆的、由载荷与时间驱动、在温度反向时不跟随。于是最便宜的守卫不是更高频的滤波器，而是对**标定估计 ĉ_t 本身**做低频审计：把 ĉ_t 分解为「物理漂移先验可解释部分 + 不可解释残差」，用 e 过程检测不可解释残差的系统性增长，用「温度反向时漂移是否反向」的可逆性统计量区分老化与热漂移。它以 ~0.01Hz 运行、复用已有的 ĉ_t、几乎不占实时预算，却恰好覆盖 R68 最致命的盲区——**被标定吸收的慢故障**。这是「审计计量学」：不只标定传感器，还要标定「标定过程本身」。

## 1. 形式化定义（增量：定义 293–310）

**定义 293（THRIFT-RAS 总览）** THRIFT-RAS = (RCF, SPA, AEC, SRL, ESB, ETL, RAS-WM†)。四条不变式：
(i) **三本账**：每个模块必须记账——延迟 ℓ（ms）、能量 e（J）、金钱 $（元）；任何绕过账本的推理非法；
(ii) **随时有效认证**：在计算的任意前缀 τ，系统持有一个对决策误差的有效上界 B(τ)，且实际执行的动作在 B(τ) 下可证保守；
(iii) **快慢分治**：危险类 h 的检查节奏 f_h 与其带宽匹配（快类 f_h ≥ 2ω_h；慢类用长窗口结构检验），禁止用统一节奏覆盖全部危险；
(iv) **无安全回归的预算纪律**：若预算/截止导致无法认证，回退到 R68 最坏情况（λ ≥ 0.8、k 收缩、必要时保持）——**省算力只能更保守，不能更冒险**。

**定义 294（算力账本与成本向量）** 模块 m 的成本 c_m = (c^ℓ_m, c^e_m, c^$_m)（ms, J, 元）。窗口 T 内账本 L_T = Σ_m n_m c_m。预算 B = (B_ℓ, B_e, B_$)：B_ℓ 为每决策硬实时上限，B_e/B_$ 为软预算 + 硬上限。预算影子价格 μ_t ≥ 0 为约束的 Lagrange 乘子，随余量动态变化。记账恒等式：L_T ≤ B（硬项）且超软预算时 μ_t 抬升。

**定义 295（风险上界分解与模块可约性）** 由 R68 定理 14，决策误差上界可写为
B(τ) = Σ_{i∈ℐ} α_i(τ_i), ℐ = {chunk, fi, emotion, wm, vqa, cal, slow}，
其中 α_i(τ_i) 对分配算力 τ_i 单调不增且凸，α_i(0) = α_i^default 为保守默认（不计算时的有效上界）。任何前缀计算集合都给出一个有效的 B；「未算的项用默认值」正是 anytime 化的关键。

**定义 296（随时认证与安全截断）** 给定当前证书 B_t 与安全阈值 ρ_safe，可执行动作集 𝒜(B_t) = {a : risk(a) ≤ ρ_safe(B_t)}。若 𝒜 非空则从中取动作，否则进入回退 π_fb（R68 最坏情况）。停止规则：B_t ≤ ρ_safe（提前退出）、或到达截止 d、或预算耗尽。**任意停时 τ ≤ d 都满足**：实际误差 ≤ B_τ（因为 B 是逐点有效上界，可选停时对确定性上界无害）。因此「截断」只影响证书紧度，不影响有效性。

**定义 297（频谱算力分配 / 反向 Nyquist）** 危险类 h 带宽 ω_h，采样/检查节奏 f_h。为保证最坏情况可检出，须 f_h ≥ 2ω_h（Nyquist）；该类成本 C_h = c_h·f_h。统一最坏速率管线成本 C_uni = (Σ_h c_h)·max_{h'} f_{h'}；频谱分配成本 C_spec = Σ_h c_h·2ω_h。当存在 1 个 kHz 级快危险与 4 个 Hz 级慢危险时，C_uni/C_spec ≈ 5×——统一高频是在为慢危险支付它根本不需要的采样税；统一低频则让快危险混叠、风险无界。**多速率不是优化技巧，而是可检出性的必要条件。**

**定义 298（快慢算力对偶 / 耐心定理）** 对速率 δ 的漂移、噪声 σ、观测时域 T、样本数 n = fT，最小二乘斜率估计的检测 SNR ≈ (δ/σ)·T·√n；成本 ∝ n。达到目标 SNR* 所需样本 n* = (σ·SNR*/(δT))²，故**成本 ∝ 1/T²：耐心以二次方替代算力**。相反，幅度 Δ 的阶跃/脉冲故障 SNR ≈ Δ√n/σ，成本 ∝ (σ/Δ)²，与 T 无关——**快故障只能用算力换时间**。这为分时尺度分配提供了定量依据：慢故障应该被「长时间、低速率、结构化地」观察。

**定义 299（最佳优先证书精炼 BPCR）** 每步在尚未精炼且可负担的模块中选
i* = argmax_i [α_i^cur − α_i^refined(τ_i)] / ‖c_i‖，
即单位成本的最大风险上界下降；精炼后更新 B。停止于 B ≤ ρ_safe / 截止 / 预算耗尽。由于目标对 τ 可分且凸、约束线性，连续情形下该贪心即**注水（water-filling）最优**（KKT）。这给「只算主导项」一个严格解释，而非启发式。

**定义 300（预算约束风险最小化与影子价格）** 
min_{τ≥0} Σ_i α_i(τ_i)  s.t.  cᵀτ ≤ B。
KKT：对活跃模块 −α_i'(τ_i)/c_i = μ；边际收益低于 μ 的模块取默认（不计算）。μ 即「安全算力的影子价格」：危险逼近时证书项变陡，μ 上升 → 更多模块被激活；裕度充足时 μ 下降 → 系统自动变懒。若在预算内可达的最优 B* > ρ_safe，则判**不可行**并回退，而不是超支冒险。

**定义 301（反射层 RCF 与鲁棒不变集盾）** 微型策略 π_ref（INT8, <0.2ms）配离线合成的鲁棒控制不变集 Ω_ρ（含扰动界）。若 x_t ∈ Ω_ρ 且 π_ref(x_t) 在扰动下仍使 x_{t+1} ∈ Ω_ρ，则该动作在反射层被认证（risk ≤ ρ_ref），无需审慎层。仅当 x_t 接近 ∂Ω_ρ、或廉价证书 B_ref > ρ_safe 时升级。Ω_ρ 的合成是离线一次性的，运行期零成本——**把昂贵的证明摊销到出厂**。

**定义 302（慢通道物理漂移先验）** 标定估计分解为
ĉ_t = P(Θ_t) + u_t，
其中 P（温度/载荷/时间的物理漂移模型，如热膨胀与零偏温漂）是可解释部分，u_t 是不可解释残差。真实热漂移满足 u_t ≈ 0（或经 P 后残余有界）；真实慢故障（老化、慢泄漏、缓慢松动）产生结构化、非 P 可解释的 u_t。慢通道只在 u_t 的低维子空间上做低频统计。

**定义 303（不可解释漂移 e 过程）** 检验 H0：u_t 在物理先验界内（可解释） vs H1：存在系统性不可解释漂移。构造 e 值
E_t = Π_{s≤t} exp(λ û_s − λ²σ_u²/2)，并对 λ 取混合得到 e 过程；由 Ville 不等式，在 H0 下 P(∃t: E_t ≥ 1/α_slow) ≤ α_slow。以 ~0.01Hz 运行、统计量维度 ≤ 3，摊销成本可忽略。报警时 α_slow 下降但 λ_floor 抬升。

**定义 304（可逆性 / 迟滞检验）** 热漂移可逆：温度反向时漂移方向随之反向；老化/泄漏/松动不可逆。定义可逆性统计量 R_T = corr(Δĉ, ΔΘ)（在自然或诱发温度循环上），并用单调性检验 M_T = 漂移符号在温度反向区间内是否保持。若 M_T 显著且 R_T ≈ 0 ⇒ 不可逆慢故障嫌疑。温度循环可由正常运行免费提供；若窗口内无自然循环，才调度一次极小热激励（成本计入账本）。

**定义 305（慢故障证书 α_slow）** α_slow(t) = Pr(存在幅度 > ε_slow 的未检出慢故障 | E_t, R_T, M_T)。H0 下由 e 过程给出 α_slow ≤ min(1, 1/E_t)；报警时 α_slow 下降（已检出），但同时触发保守回退。若慢通道过期（staleness s > s_slow），α_slow 回升至默认，强制触发一次廉价审计——**慢通道的「忘记」本身就是可检测的风险项**。

**定义 306（节俭序贯认证 ESB）** 五关按成本效率排序（期望信息/成本），逐关产生 e 值，财富 W_t = Π_g e_g。停止：W ≥ 1/α 则拒绝（判有害适配器）；安全侧置信序列显示裕度达标则接受；否则继续下一关。由 Ville 不等式，Type-I ≤ α；期望成本 C_seq = Σ_g c_g·P(到达 g) ≤ C_full。**canary 与风险界两关永久全跑**，只有非关键关可摊销;证书复用仅在适配器距离 d ≤ ε 且陈旧 s ≤ s_max 时允许。

**定义 307（证书复用与陈旧度）** 证书陈旧度 s_t = t − t_last_cert。保守膨胀：α_i(s) = α_i^0 + κ_s·s（陈旧越久默认越保守）。复用/摊销只有在 (i) 适配器距离 d(M_t, M_last) ≤ ε、(ii) s ≤ s_max、(iii) 复用项非安全关键 时合法；否则重算。这把「摊销」从工程技巧变成可验证的安全条件。

**定义 308（事件触发学习与算力积压）** 漂移 e 值 E_shift；当 E_shift ≥ 1/α_shift 或积压 q_t > q_trigger 时触发影子训练。积压动力学 q_{t+1} = max(0, q_t + λ_t − μ_t)，λ_t 为学习需求到达，μ_t 为分配的算力预算。Lyapunov V_t = q_t²，若 E[λ] < E[μ] 且预算可行则 q_t 稳定、陈旧有界；若 q_t > q_max，强制保守（λ_floor 抬升、k 收缩）——**学不动时显式降级，而不是悄悄陈旧**。

**定义 309（干扰集 ℰ_THRIFT）** ℰ_THRIFT = ℰ_CALM × ℰ_sched × ℰ_slow × ℰ_seq：
- ℰ_sched = {预算饥饿、风险收益（VOI）误定价、证书截断竞态、多速率混叠、影子价格震荡}；
- ℰ_slow = {物理先验误设、慢故障模仿热漂移、不可解释子空间逃逸、可逆性伪证}；
- ℰ_seq = {可选停时滥用、门排序博弈、陈旧证书复用、e 值回收失效}。

**定义 310（J_THRIFT 证书与管线）** 
J_THRIFT = (J_CALM, B_t, latency_ledger, cost_ledger, μ_t, slow_e_value, seq_wealth, staleness, sched_ver)。
Valid ⇔ Valid(J_CALM) ∧ B_t ≤ ρ_safe ∧ 硬预算未越界 ∧ 慢通道未超期 ∧ 无 ℰ_seq 违规。
管线：离线做「频谱画像 + 反射盾合成 + 漂移先验拟合」；在线多速率运行（反射层每 tick、快审慎层按需、慢通道 0.01Hz）；影子训练事件触发；提交用序贯认证提前停止；全程三账记账。

## 2. 关键算法骨架

# IP-253 RCF：反射层（离线不变集 + 在线 <0.2ms 策略）
class ReflexCertifiedFilter:
    def __init__(self, policy_int8, invariant_set):
        self.pi, self.Omega, self.rho_ref = policy_int8, invariant_set, RHO_REF
    def certified_action(self, x):
        if self._inside_with_margin(x, self.Omega):
            a = self.pi(x)
            if self._keeps_invariant(x, a, self.Omega):
                return a, self.rho_ref          # 反射层已认证，无需审慎层
        return None, None                       # 边界/裕度不足 → 升级

# IP-254 SPA：频谱算力组合分配（多速率 + 最佳优先证书精炼）
class SpectralPortfolioAllocator:
    def __init__(self, risk_terms, costs, budget, rho_safe, deadline_ms):
        self.alpha, self.cost = risk_terms, costs   # alpha[i](tau_i) 凸不减
        self.B, self.rho_safe, self.d = budget, rho_safe, deadline_ms
    def allocate(self, state):

        B   = sum(t.default for t in self.alpha.values())
        while B > self.rho_safe and not self._past_deadline() and not self._budget_out(tau):
            i = max(self._unrefined(tau),
                    key=lambda i: (self.alpha[i].cur - self.alpha[i].refine(tau[i]+1))
                                  / self.cost[i])
            tau[i] += 1; B = sum(self.alpha[j].bound(tau[j]) for j in tau)
        if B > self.rho_safe:
            return tau, B, 'INFEASIBLE'         # → R68 最坏情况回退
        return tau, B, 'CERTIFIED'

    # 1) 廉价 scout：粗证书（只算主导项）

    tau, B, verdict = M.spa.allocate(x_t)
    if verdict == 'INFEASIBLE':

    # 3) 只有被分配的模块才运行（COF/CFA/WM 按需）
    o = M.mtm.partial_forward(x_t, tasks=M.spa.active_tasks(tau))

    if verdict == 'PASS' and M.ledger.within_hard_caps():

## 3. 推导

**引理 16（频谱算力下界与多速率最优性）** 对带宽 ω_h 的危险类，任何保证最坏情况可检出的检测器必须 f_h ≥ 2ω_h（否则存在混叠输入使其不可见）。于是统一最坏速率成本 C_uni = (Σ_h c_h)·max_h f_h，而频谱分配成本 C_spec = Σ_h c_h·2ω_h；两者之比 C_uni/C_spec ≥ 1，且在「一个快类 + 多个慢类」时约为慢类数量倍。反向地，统一低频会让快危险混叠，风险无界。系：**多速率架构是可检出性与成本的双重必要条件**；R68 的单速率全量管线同时是昂贵且对慢故障低效的。

**引理 17（随时认证的安全截断与最佳优先最优性）** (i) 因 B(τ) 对任意前缀都是有效上界，且 B > ρ_safe 时必走 π_fb，故对任意停时 τ ≤ d 的执行动作满足 risk ≤ max(ρ_safe, risk(π_fb))——**截断零安全损失**，且期望延迟 ≤ E[min(τ_stop, d)]。(ii) 在可分凸目标与线性预算下，按单位成本边际下降贪心即 KKT 注水解，故 BPCR 的停止点风险不劣于任何等预算分配。系：早期退出率 α_exit 越高，平均成本越低而安全界不变。

**引理 18（慢故障的耐心—算力对偶与可辨识条件）** 由定义 298，漂移斜率检测成本 n* = (σ·SNR*/(δT))² ∝ 1/T²，即观测时域翻倍可把所需样本降到 1/4；阶跃故障成本与 T 无关。故把快故障交给高频贵路径、把慢故障交给低频长窗口是**成本最优且检测力最优**的分工。对落在标定带宽内的慢故障：若其不可解释分量 u 落在物理先验 P 的正交补且幅度 > ε_slow，则 e 过程功效随 √n_eff 增长，检测条件 Δ_struct·√n_eff/σ_u ≥ z_{1−α_slow}；若 u 完全落在 P 的张成空间内，则内部数据下**信息论不可分**（诚实边界），此时只能靠可逆性统计量 M_T（老化不可逆 vs 热漂移可逆）或外部计量打破。系：R68 的「越标越准、慢故障越隐形」被拆成「可解释子空间内的真不可分」与「正交补内可低成本检出」两部分，前者由可逆性/外部计量处理，后者由慢通道廉价处理。

**引理 19（序贯认证期望成本与 Type-I 控制）** 设各关 e 值在 H0 下期望 ≤ 1，财富 W_t 为非负上鞅，则由 Ville 不等式 P(∃t: W_t ≥ 1/α) ≤ α，Type-I ≤ α。按成本效率排序并以「拒绝/接受」双停止规则运行，期望关数 E[N] = Σ_g P(到达 g) ≤ G，期望成本 C_seq ≤ C_full；canary 与风险界强制全跑 ⇒ 认证安全性不因摊销而下降。系：在典型适配器（多数安全）上，期望只需 2~3 关，成本约降一半。

**定理 16（预算约束下的端到端风险一致性）** 在 A87–A94 与新增 A95（危险频谱可分、存在有限 ω_h）、A96（物理漂移先验覆盖可逆热漂移）、A97（e 值有界、预算可行或可回退）下，THRIFT-RAS 的输出满足：
1. `P(|τ_cmd − τ*| > ε) ≤ Σ_i α_i + α_slow`，其中 α_slow 在 H0 下受 e 过程控制、报警时转为保守回退；
2. **随时有效**：对任意停时 τ ≤ d，误差 ≤ B_τ；截止/预算耗尽走 π_fb，故 `risk ≤ max(ρ_safe, risk(π_fb))`——成本约束不产生新的冒险通道；
3. **频谱保真**：快危险（ω_h 达 Nyquist）检出概率与 R68 相同；慢危险在正交补内以 √n_eff 增长的功效被检出，在 P 内则显式标注不可分并抬升 λ_floor；
4. **摊销安全**：ESB Type-I ≤ α 且 canary 全跑 ⇒ 有害适配器上线概率 ≤ R68 定理 15 的界；ETL 若积压不稳定则强制保守，故陈旧被显式支付而非隐藏。

**定理 17（节俭认证与事件触发学习的安全性）** ESB 的拒绝/接受停时满足 Ville 界，故错误接受有害适配器的概率不升；ETL 的 Lyapunov 稳定性给出陈旧上界 `s ≤ q_max/(E[μ]−E[λ])`，越界即强制 λ_floor ≥ 0.8 与 k 收缩。因此**成本控制的所有失效模式都映射到「更保守」，不映射到「更冒险」**——这是 THRIFT 与普通「降本」方案的伦理分界。

## 6. 本轮最大风险

**一句话**：THRIFT-RAS 把「安全」折算成了可优化的风险上界与预算，而其证书的保守默认项、VOI 估计与慢通道物理先验**本身都是被学习/近似的**——一旦分布漂移使某个廉价默认界失效，调度器会因为「账面上证书已达标、预算还很充裕」而系统性地在**最不该省的地方省算力**，形成一种被漂亮的成本账本掩盖的「安全债务」（certified-looking but under-verified）；这是「把安全经济学化」的原罪：能被定价的东西，最终会被折价。

**次级风险与缓解**：
1. **慢通道先验误设**：P 不覆盖真实热行为 → 用 E295 做先验鲁棒性；不可解释时宁可抬高 α_slow，也不假装可分；
2. **多速率混叠攻击**：快故障伪装成慢漂移 → Nyquist 下界由硬件看门狗兜底，反射层独立于慢通道；
3. **e 值回收失效**：复用陈旧证书破坏 Type-I → 只用非安全关键关、加距离与陈旧双门（定义 307）；
4. **预算积压不稳定**：学习长期挨饿 → Lyapunov 越界即强制保守（定义 308），把饥饿变成可见的保守而非隐藏的陈旧；
5. **反射层脆弱**：π_ref 分布外失效 → 不变集只覆盖已验证区域，越界即升级；对抗扰动由 E297 专项压测。

## 2. 形式化定义（要点版）

**定义 293（总览与四不变式）** (i) 三账记账（延迟/能量/金钱，绕过账本即非法）；(ii) 随时有效认证（任意计算前缀持有有效 B(τ)，执行动作在 B 下可证保守）；(iii) 快慢分治多速率（快类 Nyquist、慢类长窗口结构检验）；(iv) 无安全回归预算纪律（无法认证即回退 R68 最坏情况，省算力只能更保守）。

**定义 294（算力账本与成本向量）** `c_m = (c^ℓ_m, c^e_m, c^$_m)`；窗口账本 `L_T = Σ_m n_m c_m ≤ B`；`μ_t` 随余量动态抬升。硬项越界即触发 BAF 回退。

**定义 295（风险分解与模块可约性）** `B(τ) = Σ_{i∈ℐ} α_i(τ_i)`，`ℐ = {chunk, fi, emotion, wm, vqa, cal, slow}`；`α_i` 单调不增且凸，`α_i(0)=α_i^default`。未计算项取默认值仍得有效上界——anytime 化的根基。

**定义 296（随时认证与安全截断）** 可执行集 `𝒜(B) = {a: risk(a) ≤ ρ_safe(B)}`；B ≤ ρ_safe 提前退出；截止/预算耗尽则 `π_fb`（λ ≥ 0.8、k 收缩、必要时保持）。对任意停时 τ ≤ d，实际误差 ≤ B_τ。

**定义 297（反向 Nyquist 分配）** 检测带宽 ω_h 的危险须 `f_h ≥ 2ω_h`；`C_uni = (Σ_h c_h)·max f_h`，`C_spec = Σ_h c_h·2ω_h`。一个 kHz 快类 + 四个 Hz 慢类时 `C_uni/C_spec ≈ 5×`；统一低频则快类混叠、风险无界。

**定义 298（快慢算力对偶）** 漂移（速率 δ）的斜率检测 `SNR ≈ (δ/σ)·T·√n`，成本 `∝ n`，故 `n* = (σ·SNR*/(δT))² ∝ 1/T²`——耐心二次方替代算力；阶跃故障 `SNR ≈ Δ√n/σ`、成本 `∝ (σ/Δ)²`，只能用算力换时间。

**定义 299（最佳优先证书精炼 BPCR）** 选 `i* = argmax_i [α_i^cur − α_i^refined] / ‖c_i‖` 精炼，直至 B ≤ ρ_safe / 截止 / 预算；可分凸 + 线性约束下贪心即注水最优（KKT）。

**定义 300（预算约束风险最小化）** `min Σ α_i(τ_i) s.t. cᵀτ ≤ B`；活跃模块 `−α_i'(τ_i)/c_i = μ`。最优 B* > ρ_safe 判不可行，走回退而非超支。

**定义 301（RCF 反射层）** 鲁棒控制不变集 Ω_ρ（含扰动界）+ INT8 策略 π_ref。`x_t ∈ Ω_ρ ∧ π_ref` 在扰动下保持不变 ⇒ 反射层认证（risk ≤ ρ_ref）；仅接近 ∂Ω_ρ 或 B_ref > ρ_safe 时升级。

**定义 302–305（SRL 慢通道）** `ĉ_t = P(Θ_t) + u_t`；H0：u 在先验界内。e 值 `E_t = Π exp(λû_s − λ²σ_u²/2)`（对 λ 混合），Ville 控制误报；可逆性 `R_T = corr(Δĉ, ΔΘ)` 与单调性 `M_T` 区分热漂移（可逆）与老化/泄漏（不可逆）；`α_slow(t) = Pr(未检出慢故障 | E_t, R_T, M_T)`，H0 下 ≤ 1/E_t，过期则回升至默认并强制审计。

**定义 306（ESB 序贯认证）** 五关按成本效率排序，`W_t = Π e_g`；`W ≥ 1/α` 拒绝、安全侧置信序列达标则接受，否则继续；Type-I ≤ α（Ville），`C_seq = Σ_g c_g·P(到达 g) ≤ C_full`；canary 与风险界永久全跑。

**定义 307（证书复用与陈旧度）** 复用仅当适配器距离 `d ≤ ε`、陈旧 `s ≤ s_max`、且该项非安全关键；否则重算；`α_i(s) = α_i^0 + κ_s·s`。

**定义 308–310（ETL / 干扰集 / 证书与管线）** 漂移 e 值或积压触发训练；`q_{t+1}=max(0,q_t+λ_t−μ_t)`，`V=q²`；不稳定或 `q>q_max` ⇒ 强制保守。`ℰ_THRIFT = ℰ_CALM × ℰ_sched × ℰ_slow × ℰ_seq`。`J_THRIFT` Valid ⇔ Valid(J_CALM) ∧ B_t ≤ ρ_safe ∧ 硬预算未越界 ∧ 慢通道未超期 ∧ 无 ℰ_seq。

class ReflexCertifiedFilter:
    def certified_action(self, x):
        if self._inside_with_margin(x, self.Omega):
            a = self.pi(x)
            if self._keeps_invariant(x, a, self.Omega):
                return a, self.rho_ref          # 已认证，无需审慎层
        return None, None                       # 边界/裕度不足 → 升级

# IP-254/255 SPA + AEC：多速率 + 最佳优先证书精炼 + 安全截断
class SpectralPortfolioAllocator:
    def allocate(self, state):
        tau = {i: 0 for i in self.alpha}
        B   = sum(t.default for t in self.alpha.values())
        while B > self.rho_safe and not self._past_deadline() and not self._budget_out(tau):
            i = max(self._unrefined(tau),
                    key=lambda i: (self.alpha[i].cur - self.alpha[i].refine(tau[i]+1)) / self.cost[i])
            tau[i] += 1; B = sum(self.alpha[j].bound(tau[j]) for j in tau)
        return (tau, B, 'INFEASIBLE') if B > self.rho_safe else (tau, B, 'CERTIFIED')

def anytime_decide(B_t, rho_safe, extra):           # 任意截断都安全

           else (FALLBACK, worst_case_action(extra)) # λ>=0.8, k 收缩

# IP-262 主闭环：THRIFT-RAS round
def THRIFT_RAS_round(M, obs):
    x_t = M.lsf.fuse(M.usr.fuse(*obs[:4]))
    a_ref, rho = M.rcf.certified_action(x_t)          # 0) 反射层（~85% tick 结束）
    if a_ref is not None and rho <= M.rho_safe:

    B, terms = M.scout.cheap_bound(x_t)               # 1) 廉价 scout（~8% 结束）

    o = M.mtm.partial_forward(x_t, tasks=M.spa.active_tasks(tau))  # 3) 按需运行

    wm_preds = M.mtm.rollout(o['z'], M.ach.propose_actions(x_t, 5)) if 'wm' in o else []

        M.shadow.train(M.ssg.batch(M.replay), budget=M.budget.remaining('learn'))

## 4. 推导

**引理 16（频谱算力下界与多速率最优性）** 带宽 ω_h 的危险须 `f_h ≥ 2ω_h`，否则存在混叠输入不可见。`C_uni/C_spec = (Σ_h c_h·max f_h)/(Σ_h c_h·2ω_h) ≥ 1`，在「一快多慢」时约为慢类数量倍；统一低频则快类混叠、风险无界——多速率是可检出性与成本的双重必要条件。

**引理 17（随时认证的安全截断与注水最优）** (i) B(τ) 逐前缀有效且 B > ρ_safe 时走 π_fb，故任意停时 τ ≤ d 的执行动作满足 `risk ≤ max(ρ_safe, risk(π_fb))`，截断零安全损失、期望延迟 ≤ E[min(τ_stop, d)]；(ii) 可分凸 + 线性预算下，按单位成本边际下降贪心即 KKT 注水解，BPCR 停止点风险不劣于任何等预算分配。

**引理 18（慢故障耐心—算力对偶与可辨识条件）** 漂移检测成本 `n* ∝ 1/T²`，阶跃检测成本与 T 无关，故快类用高频贵路径、慢类用低频长窗口是最优分工。慢故障落在物理先验 P 的正交补时，e 过程功效随 √n_eff 增长，条件 `Δ_struct·√n_eff/σ_u ≥ z_{1−α_slow}`；若完全落在 P 的张成空间内则内部数据信息论不可分——只能靠可逆性 `M_T`（老化不可逆 vs 热漂移可逆）或外部计量打破。R68 的「越标越隐形」由此被拆为「P 内真不可分」与「正交补内可廉价检出」两半。

**引理 19（序贯认证期望成本与 Type-I）** H0 下各关 e 值期望 ≤ 1，W_t 为非负上鞅，Ville 给出 `P(∃t: W_t ≥ 1/α) ≤ α`；按成本效率排序 + 双停止规则，`E[N] = Σ_g P(到达 g) ≤ G`、`C_seq ≤ C_full`；canary 与风险界强制全跑 ⇒ 认证安全性不因摊销下降。典型安全适配器期望 2~3 关、成本约降一半。

**定理 16（预算约束下的端到端风险一致性）** 在 A87–A94 与 A95（危险频谱可分）、A96（漂移先验覆盖可逆热漂移）、A97（e 值有界、预算可行或可回退）下：
1. `P(|τ_cmd − τ*| > ε) ≤ Σ_i α_i + α_slow`（α_slow 在 H0 下受 e 过程控制，报警时转保守回退）；
2. 任意停时 τ ≤ d 误差 ≤ B_τ；截止/预算耗尽走 π_fb，`risk ≤ max(ρ_safe, risk(π_fb))`——成本约束不产生新冒险通道；
3. 快危险（达 Nyquist）检出同 R68；慢危险在 P 正交补内以 √n_eff 功效检出，在 P 内显式标注不可分并抬升 λ_floor；
4. ESB Type-I ≤ α 且 canary 全跑 ⇒ 有害适配器上线概率 ≤ R68 定理 15 的界；ETL 不稳定即强制保守，陈旧被显式支付而非隐藏。

**定理 17（节俭认证与事件触发学习的安全性）** ESB 的拒绝/接受停时满足 Ville 界；ETL 的 Lyapunov 稳定性给出陈旧上界 `s ≤ q_max/(E[μ]−E[λ])`，越界即 λ_floor ≥ 0.8 与 k 收缩。故成本控制的所有失效模式都映射到「更保守」，而非「更冒险」——这是 THRIFT 与普通降本方案的伦理分界。

## 7. 本轮最大风险

**一句话**：THRIFT-RAS 把安全折算成可优化的风险上界与预算，而证书的保守默认项、VOI 估计与慢通道物理先验**本身都是被学习/近似的**——一旦漂移使某个廉价默认界失效，调度器会因「账面证书已达标、预算仍充裕」而在最不该省的地方省算力，形成被漂亮成本账本掩盖的「安全债务」（certified-looking but under-verified）；这是「把安全经济学化」的原罪：能被定价的东西，最终会被折价。

**次级风险与缓解**：慢通道先验误设（E295 鲁棒性；不可解释时宁可抬高 α_slow）；多速率混叠攻击（Nyquist 下界 + 独立硬件看门狗，反射层不依赖慢通道）；e 值回收失效（仅非关键关复用 + 距离/陈旧双门）；预算积压不稳定（Lyapunov 越界即强制保守）；反射层分布外失效（不变集只覆盖已验证区域，越界即升级）。
