# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「激光雷达」×「步态规划」）

> R69 让系统学会「问」，但它问的方式是无身体的：信息动作 g = (注视 / 手探 / 问句) 被当作可以额外插入、与任务动作并列的探针，代价是一个标量 c(g)，失败顶多是「白问一次」。可一旦把系统放到有腿的身体上，两个物理事实把这个假设击穿：
> - **激光雷达给的是几何，不是力学。** 它能告诉你前面是一块平面，却不会告诉你它滑不滑、能不能承重、是不是一层盖住深坑的薄板。
> - **腿的每一次落脚，既是在移动，也是在测量。** 你必须在某个地方把体重交出去；脚一旦踩下，接触力就是关于地形力学最直接、也最难伪造的证据——但代价是，如果踩错，探测本身就把你摔了。
>
> R69 问「我该向谁求证、还能问什么」；R70 必须接着问：**我这一步踩下去，是在测量，还是在把自己交给一个我从未验证过的世界？感知和承重能不能不是两个动作，而是同一个动作的两面？**
>
> 核心命题：**把「观测」与「承重」统一为同一个物理动作。** 用双用途步态（dual-use gait）让每一次落脚同时承担支撑与探询；用几何—力学分解说清 LiDAR 的认知边界；用感知—步态耦合不动点处理「视角由步态决定、步态又由感知决定」的循环；用可中止的渐进加载把不可逆的探询变成可认证的；用本体感受（接触力 / 惯性）作为激光无法伪造的信任锚。命名 **TREAD-RAS**（Terrain-Referenced Evidence-Acquisition & Dual-use for Risk-Adaptive Safety）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**这一步踩下去，是测量还是冒险？我能不能让两者兼得，且失败还能收回来**」。

## 0. 直觉与动机

**灵感 1（激光雷达 → 几何的诚实与力学的沉默）**
直觉：LiDAR 是一种主动传感器：它自己发光，所以它的「看见」依赖发射—反射—接收这条物理链，也就有自己的失败模式——镜面、透明、逆反射、多路径幽灵点、以及被人为注入的假回波。更重要的是，它测的是光程，不是力学。一个光滑的冰面和一个粗糙的柏油面在点云里都可能是「平面」；一块盖住坑洞的薄板和一个实心台阶都可能是「高度 z 的支撑面」。于是 R69 里「看一眼再决定」的乐观在这里失效：**几何上可通行 ≠ 力学上可承载**。LiDAR 能消灭几何歧义，却几乎不减少最要命的力学歧义。

**灵感 2（步态规划 → 落脚就是测量，且测量有下行风险）**
直觉：足式机器人不能悬浮着观察地面。它必须在某个落点上承重。这个被迫的承重恰好是获取地形力学的最佳机会：接触瞬间的力、加速度、下沉量，是地面刚度、摩擦、承载力的直接读数。由此得到一个与 R69 本质不同的结论：**信息动作不一定是额外的；它可以是本来就要做的支撑动作的一个「顺带读数」**。在必须经过的路径上，地形信息是「免费」的——你本来就要踩那里。这与机械臂必须专门伸出去探一下完全不同。R69 的信息动作成本 c(g) 恒为正；在足式运动里，双用途落脚的边际信息成本可以接近零，甚至为负（一个信息更多的落点同时可能更稳）。

**灵感 3（耦合 → 视角由步态决定，步态又由感知决定）**
直觉：LiDAR 装在本体上，它的视角是身体位姿的函数；而身体位姿由步态决定。想看清一块被腿遮挡的地面，唯一的办法是改变步态（迈开腿、侧移、降低机身）。反过来，步态该往哪迈，又取决于 LiDAR 看到的地形。这不是两个可以串行求解的子问题，而是一个**不动点**：计划 G 产生观测，观测更新信念，信念又改变计划。它的危险不在于不收敛，而在于收敛到一个**自我确认**的解——最优步态恰好绕开了所有能证伪当前信念的地方。系统越「高效」，越活在自己的想象里。

**灵感 4（不可逆性 → R69 的「安全认证」不够，需要「可中止」）**
直觉：R69 对信息动作的要求是「过 C-RAS-WM 认证、不越安全包络」。但足式探询有一个 R69 没有的性质：**世界会被这次探询不可逆地改变**。你把体重压上一块薄板，板塌了就是塌了，没有「重来一次」。所以安全不能只认证「这个动作此刻安全」，还要认证「如果它立刻证伪了我的假设，我还能不能退回到一个站得住的状态」。这把「可逆动作」放宽为「**可中止的不可逆动作**」：允许你做不可逆的事，但必须在每一步都保留一条经过认证的撤退轨迹，且撤退终点落在存活核（viability kernel）里。

**灵感 5（本体感受 → 重力不会配合标定撒谎）**
直觉：R69 最担心的是「标定把缓变故障吸收掉」。在激光—步态系统里，我们有一条 R69 没有的、物理上正交的第二意见：**我自己的脚感到的力和我自己的身体加速度**。你可以向 LiDAR 注入假回波，但你无法让机器人的 IMU 相信它没有在下坠——除非它真的在下坠。这给出一个比「流似然」更硬的信任锚：几何可以被欺骗，力学不行。前提是本体感受本身经过 R68 的标定监控（A99）。

**灵感 6（与 R69 的关系 → 不是替代，而是给「问」补上身体）**
直觉：R69 的交互消歧解决「语义 / 动作多峰」的歧义；TREAD 解决「物理世界是否如我所见」的歧义。二者正交，可以叠加。TREAD 的定位必须是 R69 的严格增强：当地形力学已知、LiDAR 完美、无需探询时，TREAD 逐指令退化为 FLUID-RAS；而在有腿系统里，它把 R69 那个「额外插一个探针」的模型，替换成「支撑即探询」的更紧的物理模型。**安全侧不让步，效率侧拿回被 R69 的保守铁律误伤的 resolution bonus。**

## 1. 形式化定义（增量：定义 310–326）

**定义 310（TREAD-RAS 总览）** TREAD-RAS = (ALS, TSM, DUS, GOM, CGF, VCP, TSPRT, SCA, GVoI, LIM, CCP, GSS, RAS-WM†)。继承 R69 定义 293 的实时流零学习写操作、交互预算与证据纪律；新增四条不变式：
(i) **支撑认证纪律**：任何全承重落脚必须有至少两个独立证据源（≥2 个不同基线视角的几何一致，或一次接触预载验证），单视角支持声明不得独立认证；
(ii) **探询可中止性**：任何以获取地形信息为目的的落脚，必须在 VCP 意义下 k-可中止，且中止后的状态落在存活核内；
(iii) **反确认覆盖**：对任何信念质量超过 w 的歧义地形单元，步态计划必须或者覆盖它（踩 / 扫），或者把它未消解的不确定度显式计入 λ；不允许靠「绕开它」来维持高置信；
(iv) **不可伪本体锚**：安全关键的地形力学判定至少需一路本体感受（接触力 / 惯性 / 关节力矩）佐证，纯外感受（LiDAR）不得单独决定承重。

**定义 311（地形状态与几何—力学分解 TSM）** 地形单元 θ = (h, g, μ, k, b)：h 为高度 / 坡度，g 为粗糙度，μ 为摩擦，k 为柔顺 / 下沉参数，b 为承载能力。外感受只能以有限精度观测 (h, g)；机械量 (μ, k, b) **只能由接触观测**。定义两条歧义通道：U_epi^geo（可由更多视角 / 运动视差 / 更长积分消解）与 U_epi^mech（只能由接触消解）。R69 的 U_epi 在此被细化为 U_epi = (U_epi^geo, U_epi^mech)，且两者不可相加后一起交给「多看几眼」处理。

**定义 312（主动激光扫描行动 ALS）** g_scan = (v, ρ, I)：v 为传感器位姿（由步态相位决定），ρ 为扫描模式 / ROI（方位—俯仰分辨率），I 为积分时间 / 功率。测量模型：点 p 有效 ⇔ 在量程内 ∧ 入射角 φ < φ_max ∧ 无自遮挡 ∧ 不落在镜面 / 透明 / 逆反射失效集 ∧ 在 ROI 内。定义逐点可靠度 α_lidar(p) ∈ [0,1]，以及行动的安全约束：激光眼安全等级、功耗、对人眼的闪烁。**关键约束**：v 的可达集 R(G) 由步态计划 G 的身体轨迹决定，不能任意指定。

**定义 313（双用途落脚 DUS）** 步态计划 G = {f_i}，落脚 f_i = (x_i, t_i, ℓ_i)，ℓ_i 为分段加载曲线。每个落脚同时有支撑效用 U_sup(f) 与信息效用 I(f) = E[H(θ_{cell}) − H(θ_{cell} | contact)]。净效用
J(f) = U_sup(f) + β·I(f) − R_viab(f) − c_probe(f)，
其中 c_probe(f) 是**相对名义路径**的边际探询成本。定义边际信息成本 c_info(f) = ∂R_viab/∂探询 − 0（支撑风险本来就要承担），故 c_info 可 ≤ 0。增广动作 ξ = (G, g_scan)。

**定义 314（步态条件可观测性映射 GOM）** 映射 M_G 把每个地形单元映到覆盖概率对 (p_lidar, p_contact)：p_lidar 由 R(G) 与扫描模式决定，p_contact 为落脚落入该单元的概率。由此定义步态 G 的信息吞吐率 ℐ(G) = Σ_cells [p_contact·I_contact + p_lidar·I_geo]，以及单位时间证据率 ℐ(G)/T(G)。GOM 是把「步态」解释为「证据获取时序表」的形式化。

**定义 315（感知—步态耦合不动点 CGF）** 信念 b(θ) 与计划 G 的耦合算子 T: (G, b) ↦ (G'(b), b'(G))。求不动点 (G*, b*) = T(G*, b*)。定义耦合模数 κ = L_dyn·η，L_dyn 为计划对信念的 Lipschitz 常数，η 为单轮信息带来的信念收缩率。κ < 1 时不动点唯一且几何收敛（定理 22）。**自确认步态**定义为：在不动点处，被选中的 G* 对一切满足 b 误差 > δ 的地形单元赋予零采样概率。自确认步态是耦合系统的病态吸引子。

**定义 316（地形不确定性二分与三级来源）** U_ale^terrain = 当前落脚下粗糙度 / 植被等随机性造成的不可约方差；U_epi^geo（可扫消解）；U_epi^mech（只能踩消解）。三者在 λ 中不同权：U_ale 直接进 floor；U_epi^geo 可由运动视差 / 多视角在预算内消解；U_epi^mech 只有在可中止探询后才允许折减。

**定义 317（可存活探询 VCP）** 设存活核 K 为存在安全回退轨迹的状态集。探询计划按加载级 ℓ_1 < ℓ_2 < … < ℓ_m 推进，并配有中止映射 Abort。称其 **k-可中止**，若对每个阶段 j，执行 Abort 后能在 t_abort 内以概率 ≥ 1−δ_abort 到达 K 内状态，且 k ≥ m 个阶段全部满足。只有 k-可中止的探询才被认证。这把 R69 定义 302 的「信息动作安全」升级为「信息动作失败可收回」。

**定义 318（渐进加载地形序贯检验 TSPRT）** 假设 H0：该落脚属于安全类（μ, k, b 在包络内），H1：不安全。观测量 y 为接触力 / 加速度 / 下沉量的联合残差。用 SPRT：在每级加载后更新对数似然比 Λ，当 Λ ≥ log A 接受 H1（中止并撤退），当 Λ ≤ log B 接受 H0（继续加载），阈值 A = (1−β)/α，B = β/(1−α)。总失败概率 ≤ α + δ_abort。

**定义 319（支撑认证规则 SCA）** 全承重落脚可认证 ⇔ (a) 至少两个基线 b ≥ b_min 的 LiDAR 视角给出几何一致，或 (b) 一次接触预载（部分承重）确认，或 (c) 在静态稳定宽步态下以低于 b_safe 的短步通过。落在镜面 / 透明失效壳内的单视角支持声明**不得认证**。这是 R69 证据纪律在「支撑」这一物理谓词上的实例化。

**定义 320（步态级信息价值 GVoI）** GVoI(G) = E[ΔH(θ_amb | G, contact)] / [T(G)·(1 + ρ_risk·R_viab(G))] − c_gait(G)。选择 G* = argmax GVoI(G)，s.t. 每一步 k-可中止、SCA 满足、交互预算未越界。R69 的 VoI 是 G 固定、信息只来自额外 g 的退化情形。

**定义 321（LiDAR 完整性监视 LIM）** 完整性分 = min{ 强度—距离一致性, 多回波一致性, 距离梯度连续性, 运动视差一致性, 时间持久性 }。输出 integrity ∈ [0,1] 与 ghost/specular 指示。integrity < τ_lidar 时，几何降级为「建议」，不得用于支撑认证。

**定义 322（接触一致性第二意见 CCP）** 预测接触（由步态动力学 + 地形信念）与实际测量（力 / 力矩 / IMU / 关节）之差 r_c。判据：
(r_c↑, integrity↓) ⇒ **SPOOF_SUSPECT**（激光被注入）；
(r_c↑, integrity↑) ⇒ **TERRAIN_MODEL_ERROR**（地形类别误判）；
(r_c↓, integrity↑) ⇒ **CONSISTENT**。
本体感受是外感受无法伪造的锚：几何可以被欺骗，力学不行。

**定义 323（步态安全退避集 GSS）** 当地形认知未消解、LIM 低、或 SCA 不满足时，限制到**静态稳定步态集** S_gait-safe：≥3 足支撑、宽站距、低质心、慢速、允许驻留扫描。GSS 是 R69 语义不变安全集 SIS 在步态层的对应物，构成第三级退避。

**定义 324（威胁模型 ℰ_TREAD）** ℰ_TREAD = ℰ_FLUID × ℰ_lidar × ℰ_terrain × ℰ_gait。ℰ_lidar：注入假回波、致盲、幽灵点、距离伪造；ℰ_terrain：透明 / 镜面、冰面、伪装坑洞、看起来结实实则松软的植被 / 泡沫；ℰ_gait：对手从观察到的步态预测自遮挡窗口并在盲区放置危险，或从步态泄露意图。

**定义 325（VQAuditor-G 与 J_TREAD）** 审计新增：支撑是否由 ≥2 独立源认证、探询是否 k-可中止、幽灵点是否驱动了落脚、反确认覆盖是否满足、退避是否及时。J_TREAD = (J_FLUID, lidar_integrity_p95, contact_residual_p95, probe_abort_margin, falsification_coverage, terrain_ece, ghost_acceptance, tread_ver)。Valid ⇔ Valid(J_FLUID) ∧ SCA 全满足 ∧ 探询可中止 ∧ 覆盖约束满足 ∧ 预算未越界。

**定义 326（三级退避与 R69 严格包含）** 若双用途步态或接触探询在预算内消解 U_epi^mech，则 λ = λ_floor(U_ale^terrain)（获得 resolution bonus，但不低于 R69 的安全下界）；若未消解 / 不可认证 / 被投毒 / LIM 越界，则 λ = λ_floor(U_ale + U_epi^geo + U_epi^mech) 并退到 GSS。当 U_epi^geo = U_epi^mech = 0、LiDAR 完美、步态无探询时，定义 326 逐指令退化为 R69 定义 307。

```python
def plan_scan(belief, gait_plan, power_budget):
    reach = sensor_poses(gait_plan)             # 由步态轨迹决定的可见位姿

    return min(parallax_consistency(points, history),

def coupled_plan(belief, K_iters=3):

    for _ in range(K_iters):

    geo   = M.als.scan(o) if obs.has_lidar else None
    integ = M.lim.score(geo, M.history)
    U_epi_geo, U_epi_mech = M.tsm.split(U_epi, geo, integ)
    # 3) 耦合规划 + 反确认覆盖
    G, b_terrain, cov = M.cgf.plan(belief=M.belief, geo=geo, integ=integ)
    if cov < COV_MIN:
        U_epi_mech += M.confirmation_penalty(G)       # 自确认的代价显式入 λ
    # 4) 只对「失败了还站得住」的落脚做渐进探询
    for f in M.dus.uncertain_footholds(G, b_terrain):
        if M.vcp.abortable(f) and M.budget.allow(f):
            r = M.vcp.probe(f, b_terrain)
            b_terrain = M.cia.update_terrain(b_terrain, r)  # k 源一致纪律
    # 5) 本体感受第二意见
    r_c     = M.ccp.residual(M.last_gait_pred, M.last_measured)
    verdict = M.ccp.trust_gate(integ, r_c)
    # 6) 风险缩放与三级退避（R69 边界）
    U_floor = U_ale + (U_epi_mech if verdict == "CONSISTENT"
                       else U_epi_mech + U_epi_geo)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    if verdict != "CONSISTENT" or cov < COV_MIN:
        G = M.gss.fallback_gait(G)                    # 静态稳定宽步慢速
    k    = M.c_ras_wm.certified_prefix(...)
    mode = M.dus.select_foothold(modes, G, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_g.submit_async(geo, G, r_c, cov, lam)
    return k, lam, mode, (U_ale, U_epi_mech, U_epi_geo)
```

## 3. 推导

**引理 19（双用途的边际信息成本）** 设步态 G 必须经过落脚集 F(G)。支撑动作的可行性风险 R_viab(f) 与信息动作的探询风险共享同一次接触，故相对名义路径的边际信息成本 c_info(f) = R_viab(f | 探询) − R_viab(f | 名义) ≥ 0（探询只会增加或持平风险），但**总成本**中不再包含额外的移动成本 c_move。对比 R69 的专用探针，c_probe = c_info + c_move，其中 c_move > 0。系：**当歧义单元落在必经路径上，双用途步态在相同识别精度下严格优于「走完再专门探」**；这就是「支撑即探询」的定量含义。

**引理 20（步态条件信息速率与速度—信息 Pareto）** 单位时间接触样本率近似为 N_support·v/L_step，其中 v 为步速、L_step 为步长、N_support 为同时支撑足数。LiDAR 证据率受驻留时间与 ROI 约束，≈ ROI_cells / I_dwell。故 ℐ(G)/T(G) 随 v 增大而下降、随步长减小与支撑足数增加而上升。于是存在明确的「速度—信息」Pareto 前沿：**快走 = 少采样、弱中止；慢走 / 宽步 = 多采样、强中止**。步态选择因此不是纯运动学问题，而是证据调度问题。

**引理 21（可中止探询的失败概率上界）** 在渐进加载 + SPRT + 存活核撤退下，若每级中止成功概率 ≥ 1−δ_abort，SPRT 的第一类错误 ≤ α，则「对不安全地面施加全承重」的概率 ≤ α + δ_abort。期望加载级数由 Wald 近似 E[N] ≈ [α log A + (1−α) log B] / KL(H1‖H0) 给出。系：**探询的不可逆性被「分段 + 可撤回」转化为可认证的有限风险**；α 由安全预算给定，δ_abort 由存活核的可行性保证。

**引理 22（单视角幽灵支撑的不可认证性）** 在对抗注入（ℰ_lidar）下，对任意单视角分类器，总存在一个与该视角完全一致的伪造点云；因此单视角对「支撑」的接受概率在无先验限制时可被对手推到 1。加入第二个独立测量（不同基线的几何，或一次接触预载）后，伪造必须在两个独立约束下同时一致，接受概率 ≤ ε_2（由视差分辨力与接触模型误差决定）。系：**支撑认证必须是「双源」的**；这也解释了为什么步态能「免费」提供第二视角——走路改变了基线，但自遮挡窗口内这条免费通道会暂时失效，恰是对手可利用的窗口（ℰ_gait）。

**引理 23（接触一致性的不可吸收性与检出延迟）** LiDAR 注入只改变外感受点云，不改变真实的接触力 / 惯性。若伪造的「支撑面」实际不存在，则一旦加载，机体竖直加速度将偏离支撑假设所预测的值，时间尺度为自由落体特征时间 t_f ≈ √(2Δh/g)。故在首次接触后，检测延迟 ≤ t_f + t_abort，且该残差**不能被传感器标定吸收**：标定要吸收它，就必须预测到真实的下坠，也就是必须是对的。系：**接触 / 惯性通道是 R69「流似然第二意见」在物理侧的镜像，且比它更硬**（前提 A99：本体感受经 R68 COF 监控）。

**定理 21（TREAD 严格包含 R69）** 当 U_epi^geo = U_epi^mech = 0、LiDAR 完美、LIM 恒高、关闭渐进探询时，ALS 退化为 R69 的被动 g_gaze，DUS 退化为普通支撑动作，GVoI 的信息项为零，GSS = 全集，VCP 为空，定义 310–326 逐条退化为 R69 定义 293–309，决策逐指令相同。当存在地形歧义时：(a) 消解成功只折减 U_epi^mech，且动作仍受 C-RAS-WM 认证与 SCA 约束，风险不高于 R69 使用同等信息时；(b) 未消解 / 被投毒 / LIM 越界时 λ 使用 ≥ R69 的 floor 并退到 GSS，认证安全包络不大于 R69。故 TREAD 的期望风险 ≤ FLUID-RAS，等号在「永不探询 / 地形全知」边界取得。

**定理 22（耦合不动点的收敛与反确认覆盖的必要性）** 若 κ = L_dyn·η < 1，则 T 是压缩映射，不动点唯一且 ‖(G_n, b_n) − (G*, b*)‖ ≤ κ^n·‖(G_0, b_0) − (G*, b*)‖。但压缩性**不保证正确性**：构造两个地形模型 θ 与 θ′，它们在 G* 以正概率采样的单元上完全一致，仅在一个被 G* 赋予零概率的单元上不同；则同一个 G* 对二者都最优，信念永不分离——这是自确认步态的存在性证明。故任何正确性保证都必须附加反确认覆盖约束：对 b 误差 > δ 且质量 > w 的单元，采样概率 > 0，或其不确定度显式进入 λ。**反确认覆盖不是工程调参，而是可辨识性的必要条件。**

**定理 23（探询安全与无突变）** 渐进探询的每一级都受 VCP 约束，中止轨迹落在存活核内，故物理风险 ≤ ε_int + δ_abort·s_max；探询只改变「选哪个落脚 / 哪条步态」，不改变安全包络；失败 / 超时 / 投毒时 λ 单调不降地退化为 R69 并切入 GSS；提交 / 换装不变式（R68 定理 15）保持 ⇒ 控制连续、无突变。

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** TREAD-RAS 继承 R69 的零学习写、交互预算、证据纪律；新增：支撑认证纪律（≥2 独立源）、探询可中止性（撤退落存活核）、反确认覆盖（不许靠绕开维持高置信）、不可伪本体锚（外感受不得单独决定承重）。

**定义 311–312（TSM 与 ALS）** `θ=(h,g,μ,k,b)`，LiDAR 只可观 `(h,g)`，`(μ,k,b)` 只能由接触观测；扫描动作 `g_scan=(v,ρ,I)`，有效点需满足量程/入射/无自遮挡/非失效集，且 `v ∈ R(G)`（视角受苦于步态）。

**定义 313–314（DUS 与 GOM）** 落脚净效用 `J(f)=U_sup+βI−R_viab−c_probe`，边际信息成本相对名义路径可 ≤0；`M_G` 把步态映射为每单元的 `(p_lidar,p_contact)` 覆盖，信息吞吐率 `ℐ(G)/T(G)` 给出速度—信息 Pareto。

**定义 315（CGF）** 耦合算子 `T:(G,b)↦(G'(b), b'(G))`，不动点 `(G*,b*)`；耦合模数 `κ=L_dyn·η`，κ<1 压缩收敛。**自确认步态**：`G*` 对误差 >δ 的单元赋予零采样概率——耦合系统的病态吸引子。

**定义 316–318（不确定性三分与探询）** `U_ale^terrain / U_epi^geo / U_epi^mech` 分通道；VCP 要求每级加载的中止轨迹 `t_abort` 内落到存活核 `K`；TSPRT 用 `Λ` 与 `(A,B)` 判定 H0（支持）/H1（不安全），总失败概率 `≤ α+δ_abort`。

**定义 319（SCA）** 全承重 ⇔ 双基线几何一致 ∨ 接触预载确认 ∨ 静态宽步短步；镜面/透明失效壳内单视角声明不得认证。

**定义 320–321（GVoI 与 LIM）** `GVoI = E[ΔH]/[T(1+ρ_risk·R_viab)] − c_gait`；LIM = min{强度—距离、多回波、梯度连续、视差一致、时间持久}，低分则几何降级。

**定义 322–323（CCP 与 GSS）** `r_c` 联合完整性判 `SPOOF_SUSPECT / TERRAIN_MODEL_ERROR / CONSISTENT`；未消解或完整性低时退到 `S_gait-safe`（静态稳定、宽步、慢速、驻留扫描）。

**定义 324–326（威胁、审计、证书、三级退避）** `ℰ_TREAD=ℰ_FLUID×ℰ_lidar×ℰ_terrain×ℰ_gait`；VQAuditor-G 审支撑双源、探询中止、幽灵落脚、覆盖约束；J_TREAD 并入完整性、接触残差、中止裕度、覆盖、地形 ECE；消解成功 `λ=λ_floor(U_ale)`，失败/投毒 `λ=λ_floor(U_ale+U_epi^geo+U_epi^mech)` 并退 GSS；全知时逐指令退化为 R69。

## 4. 推导

**引理 19（双用途边际信息成本）** 支撑与探询共享同一次接触，故 `c_info = R_viab(探询) − R_viab(名义) ≥ 0`，但总成本不含额外移动成本 `c_move`；R69 专用探针 `c_probe = c_info + c_move > c_info`。系：歧义单元在必经路径上时，双用途步态严格优于「走完再专门探」。

**引理 20（步态条件信息速率）** 接触样本率 `≈ N_support·v/L_step`，LiDAR 证据率 `≈ ROI_cells/I_dwell`。故信息速率随步速上升而下降、随步长减小与支撑足数增加而上升，形成速度—信息 Pareto。步态选择即证据调度。

**引理 21（可中止探询失败界）** 渐进加载 + SPRT + 存活核撤退下，全承重施加于不安全地面的概率 `≤ α + δ_abort`；期望加载级数 `E[N] ≈ [α log A + (1−α) log B]/KL(H1‖H0)`。不可逆性被转化为可认证的有限风险。

**引理 22（单视角幽灵支撑不可认证）** 对抗注入下，任意单视角分类器都存在一致的伪造点云，单视角接受率可被推到 1；加入第二独立测量（不同基线几何或接触预载）后接受率 `≤ ε_2`。系：支撑认证必须双源；走路免费提供第二基线，但自遮挡窗口内失效，是对手的可利用窗口。

**引理 23（接触一致性不可吸收）** LiDAR 注入只改外感受点云，不改真实接触力/惯性；伪造支撑一旦加载，机体加速度在自由落体特征时间 `t_f≈√(2Δh/g)` 内偏离预测，检测延迟 `≤ t_f + t_abort`；标定无法吸收（吸收了就必须预测真实下坠，也就是必须是对的）。系：接触/惯性是比 R69 流似然更硬的物理第二意见（A99）。

**定理 21（严格包含 R69）** 全知地形、LiDAR 完美、LIM 恒高、关闭探询时，ALS→被动 g_gaze、DUS→普通支撑、GVoI 信息项为 0、GSS=全集、VCP 为空，定义 310–326 逐条退化为 R69 定义 293–309，决策逐指令相同。有歧义时：消解成功只折减 `U_epi^mech` 且仍受 SCA/C-RAS-WM 约束；未消解/投毒/LIM 越界时 `λ` 使用 ≥ R69 的 floor 并退 GSS。故期望风险 ≤ FLUID-RAS，等号在「永不探询 / 地形全知」边界。

**定理 22（耦合收敛与反确认覆盖的必要性）** `κ=L_dyn·η<1` 时 T 为压缩映射，`‖(G_n,b_n)−(G*,b*)‖ ≤ κ^n‖(G_0,b_0)−(G*,b*)‖`。但压缩不保证正确：存在 θ 与 θ′ 在 G* 正概率采样单元上完全相同、仅在一个零概率单元不同，则同一 G* 对二者都最优、信念永不分离——自确认步态存在。故正确性必须附加反确认覆盖：误差 >δ 且质量 >w 的单元采样概率 >0，或其不确定度显式入 λ。**这是可辨识性的必要条件，不是调参。**

**定理 23（探询安全与无突变）** 每级探询受 VCP 约束、中止落存活核，物理风险 `≤ ε_int + δ_abort·s_max`；探询只改选落脚/步态，不改安全包络；失败/超时/投毒时 λ 单调不降地退化为 R69 并切 GSS；R68 换装不变式保持 ⇒ 控制连续、无突变。
