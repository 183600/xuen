# 第 1 轮（新灵感循环第 1 轮；本轮灵感：「语音交互」×「机器人基础模型」）

> **基线**：上一轮产出 MetricVoiceGauge-NCD-HUTDH-v20 + IP-420–424（v20 完整方案）。
> 本轮纪律：**语音是分布而非指令、修正是在证书域内做局部编辑、承诺是单调账本而非上下文、基础模型只提名不裁决**。不推倒 v20：v17 的 CLP/S2C/HCG/PSV/APS/AMC、v19 的 DCM/OGCC/CCV/DRS/OGC、v20 的 PCA/CTS/CFC/HPC/CFCtrl 全部保留。本轮只做一件事：**把「语音对话 + 机器人基础模型」安全地接入证书格，使系统能听、能问、能改、能记，但每一个动作仍由证书裁决**。

## 0. 直觉与动机

**灵感 1（语音交互 → 在「听懂」之前就不做错：歧义晶格与安全澄清）**
直觉：语音输入的第一性事实不是「一段文本」，而是 **ASR 的 N-best 概率晶格**加**韵律/停顿/修复**等副语言信号。传统做法先取 top-1 转写再规划：低置信度的误识别会静默穿过整条链路；另一种极端是凡有歧义就要求用户重复，活性崩溃。我们注意到了一个被忽视的交互优势：**语音天然支持澄清**。关键反直觉点：**语音层的目标不是「最大化听懂」，而是「在没听懂时也绝不擅自做错」**——只执行被**所有合理解释**同时认证的参数点；当各解释的证书域没有交集时，最安全的动作不是猜，而是**问一个能把歧义集合切开的问题**。更进一步，问题的选择目标不是单纯的信息增益，而是**证书分离度**：优先问那种「无论用户怎么答，两个分支都各自有非空且可认证域」的问题。
严谨定义：设 ASR 输出 `L_asr = {(h_i, p_i)}_{i=1}^{N}`，取歧义集合 `H_ε = {h_i | p_i ≥ ε_voice 或累计后验覆盖 ≥ 1-δ}`。对每个 `h ∈ H_ε`，经 v17 S2C 编译为 `(A(h), Θ(h)) ∪ {⊥}`，其中 `A(h)` 是认证锚序列、`Θ(h)` 是参数域。若所有 `h` 的 `A(h)` 相同，则定义**语音共识域** `Θ^sp = ⋂_{h∈H_ε} Θ(h)`；仅当 `Θ^sp ≠ ∅ ∧ vol(Θ^sp) ≥ margin_voice ∧ CCV(Θ^sp) = SAFE` 时进入 `CONSENSUS` 模式执行。若锚序列不一致或交集为空，进入 `CLARIFY` 模式，选择 `q* = argmax_{q∈Q_safe} [IG(q) + λ·CertSep(q)]`，约束是**问题本身不产生新动作**（`compile(q) = ⊥` 或完全落在既有认证域内）。韵律信号只允许**加宽** `H_ε`（更保守），永远不能收窄它，更不能成为授权。

**灵感 2（语音交互 → 修正不是重规划，而是证书域内的局部编辑 + 承诺单调账本）**
直觉：真实对话充满打断（barge-in）、「停」、「往左一点」、「不是这个」。朴素系统一听到修正就整段重规划，既慢又会把已经验证过的执行前缀作废，产生「旧计划已停、新计划未证」的危险缝隙。我们的观察是：**大多数语音修正不是新任务，而是当前参数域内的一次小位移**。因此修正应被编译为**证书增量（certificate delta）**：若新参数仍在当前 `Θ_n^col` 内且执行前缀不变，则无需重证；只有跨出域时才升级为完整重编译。打断时**已执行前缀立即冻结**，新计划只能从当前状态重新开始，绝不能与旧计划在时间上重叠。与此同时，多轮对话中的「别碰红色」「先别松手」不是可被模型遗忘的上下文，而是**只能单调增加的约束账本**：只要会话未结束，约束就一直生效，除非用户显式、且有权限地释放它。
严谨定义：设当前认证域为 `Θ_n^col`、当前参数为 `θ`，语音修正 `r` 经参数编辑语法解析为 `Δθ`。若 `θ + Δθ ∈ Θ_n^col` 且当前执行前缀未跨越冻结点，则定义 `CRE_OK`，仅记录 `CertDelta = (n, θ, θ+Δθ, r, t)`；否则冻结前缀 `PrefixFreeze(t)`，从当前状态触发完整 `S2C + HCG/PSV + CCV` 重证。承诺账本 `L_commit = {C_c}` 中每个 `C_c` 是参数域约束或锚排除约束，生效域定义为 `Θ^eff = Θ^cert ∩ ⋂_{c active} C_c`，且 `L_commit` 在会话内**单调增长**。释放 `release(c, u)` 只有当 `u` 含显式否定且 `auth(u) ≥ auth_level(c)` 时才允许；时间到期不自动释放，只触发一次「是否仍然有效」的确认。

**灵感 3（机器人基础模型 → 越强的模型越只配做提名者：证书边际排序与证书对齐迁移）**
直觉：机器人基础模型（VLA / RFM）能给出看似通用的动作与计划，但其**似然不是安全性**。采样 K 个候选再用模型分数投票，恰恰会系统性地选中「模型很自信但几何上危险」的样本。正确的位置是：**基础模型是提议分布，证书是唯一裁判**。它可以在潜空间里提出跨任务/跨物体的对应关系，但潜空间的「相似」不等于证书的「可迁移」；所以迁移必须再过一道**证书包含测试**与**共形校准**。另一个常被忽略的问题是模型版本漂移：今天验证过的证书不能默认迁移到明天更新后的权重上，必须**按模型版本哈希钉住证书**，升级即失效并重新校准。
严谨定义：基础模型为 `q_FM(·|context)`，采样 `Π_K = {π_1,…,π_K}`。每个 `π_k` 编译为 `(A_k, Θ_k)` 并送入 v20 的 `CCV/OGCC/HPC` 硬门，定义**证书边际** `margin_cert(π) = min_{θ∈∂Θ(π)} clear(θ) / margin_col`（并要求 `vol(Θ(π)) ≥ margin_voice`）。接受序只按 `margin_cert` 降序，模型分数仅在证书边际相等时做次级排序。对跨任务迁移，设潜空间对齐诱导映射 `T_φ`，仅当 `Θ_trans = T_φ(Θ_src) ∩ Θ_tgt^col` 非空、`vol(Θ_trans) ≥ margin_voice`、且共形非一致性分数 `s_trans ≤ q̂_α` 时接受。所有证书带模型版本哈希 `h_FM`；`h_FM` 变化即触发 `Invalidate-Cache → Recalibrate → Revalidate`，禁止静默延续旧证书。关键反直觉点：**基础模型越强，越应该只扩大「提案空间」，而不是扩大「授权空间」**。

**三者如何统一**
统一为 **v20 证书格之上的「对话—基础模型」层（Conversational Foundation Certificate Layer, CFCL）**。SALC 是理解侧（歧义晶格→共识域），CRE 是修正侧（局部证书增量），DCL 是记忆侧（单调承诺账本），FMPG 是提议侧（基础模型提名与证书对齐迁移），CCS 是时序侧（流式稳定、打断冻结、模式阶梯）。共享状态 `ζ_voice = (asr_lattice, H_ε, Θ^sp, commitment_ledger, θ_current, CertDelta, fm_version, Π_K, margin_cert, τ_stream, mode_voice)`。SALC 回答「哪些解释同时被认证」，CRE 回答「这条修正是否还在域内」，DCL 回答「历史承诺是否仍然约束」，FMPG 回答「基础模型提名了哪些候选、哪些可迁移」，CCS 回答「这一帧能否安全推进或必须冻结」。统一接口：**任一候选只有在 SALC 共识/澄清、CRE 局部性或完整重证、DCL 约束满足、FMPG 证书排序、CCS 稳定前缀五者全部通过后，才允许 v20 的 CCV/HPC 返回 SAFE；否则保持、澄清或退回 v20**。

## 1. 研究问题（轮次升级版）

- **Q1（语音歧义晶格的覆盖与共识）**：如何从 N-best 与韵律信号构造 `H_ε`，使真实意图以 ≥1-δ 的概率被覆盖？当锚序列不一致时，是整体澄清还是按分支局部澄清？`Θ^sp` 的交集在参数域高维时体积塌缩，如何用「证书分离度」而非单纯体积来选择澄清问题？韵律只能加宽歧义集合的约束如何在工程上强制执行？
- **Q2（修正局部性与打断安全）**：语音修正的「参数编辑语法」如何覆盖否定、范围、相对量（「再往左一点」「别太快」）而不误解？证书增量在什么条件下可证明不弱于原证书？打断后旧前缀的冻结边界如何与 v17 APS 的前缀截断对齐，保证新旧计划不重叠？
- **Q3（基础模型提名、迁移与版本漂移）**：如何定义 `margin_cert` 使「模型自信但不安全」的样本被稳定排到后面？潜空间对齐诱导的 `T_φ` 在分布漂移下如何用共形校准控制迁移风险？模型版本更新时，证书失效与重校准的最小代价路径是什么？
- **Q4（承诺账本与流式时序）**：承诺的语法、权限与释放语义如何定义，才能既防止模型遗忘又不过度杀死活性？流式 ASR 的未稳定 partial 如何被硬性隔离在执行环之外？`CONSENSUS → CLARIFY → V20` 的阶梯如何与 v20 的 APS/CFCtrl TTL 单调复合？

## 2. 设计原则（在 P31–P33 基础上新增 P34–P38）

**P34 语音无直通律（Speech is a Distribution, Not a Command）**
语音输出是后验分布，不是命令。执行集只能取 `Θ^sp = ⋂_{h∈H_ε} Θ(h)` 且要求锚序列一致、交集非空、体积达标、CCV 通过；否则不得执行，只能澄清或保持。韵律/情感/置信度只允许**扩大** `H_ε`，不得缩小；澄清问题自身必须是非动作的（`compile(q)=⊥` 或完全落在既有认证域）。**语音层新增的动作授权基数恒为零**。

**P35 修正局部律（Repair Locality）**
语音修正 `r` 优先编译为 `Δθ`。若 `θ+Δθ ∈ Θ_n^col` 且前缀未冻结，则仅记录 `CertDelta`，不重证；若越界，则 `PrefixFreeze(t)` 后完整重证。打断即冻结已执行前缀；新计划只能从当前状态起步，**禁止新旧计划时间重叠、禁止跨冻结点复用旧证书**。修正只能收缩或保持当前认证域，不能扩张。

**P36 承诺单调律（Commitment Monotonicity）**
多轮承诺 `C_c` 在会话内只增不减，生效域 `Θ^eff = Θ^cert ∩ ⋂ C_c`。模型上下文可以丢，账本不能丢；释放必须显式否定且有权限，时间到期不自动释放、只触发确认。承诺只能收缩授权域，不能扩张。**对话记忆因此是「账本」而非「上下文窗口」**。

**P37 基础模型提名律（Foundation Model Nominates, Certificate Decides）**
基础模型只产生候选 `Π_K` 与迁移提议 `T_φ`，不产生授权。候选按 `margin_cert` 排序，模型分数只做次级 tie-break；迁移必须满足 `T_φ(Θ_src) ∩ Θ_tgt^col` 非空、体积达标、共形分数 `≤ q̂_α`。证书按 `h_FM` 版本钉住，版本变更即失效并重校准。**基础模型只能扩大提案空间，不能扩大授权空间**。

**P38 流式阶梯律（Streaming Freshness Ladder）**
未稳定 partial 永不进入编译；只有满足 `stable(h)`（连续两次 partial 的锚序列一致且参数在容差内）的片段才可编译。打断立即冻结前缀并取消待定基础模型提案。模式阶梯严格单调：`FULL → CONSENSUS → CLARIFY → V20`；`τ_stream > TTL_voice` 时降级，`> 2·TTL_voice` 时退回 v20 APS。控制环永不等待 ASR 或基础模型。

## 3. 与基线的接口（如何退化）

- SALC 失效（ASR 晶格损坏/校准丢失）⇒ 固定 top-1 + 强制口头确认，每次只执行最短认证动作 ⇒ 等价 v17/v20（更保守、更慢）；
- CRE 失效（参数编辑语法不可用）⇒ 任何修正都触发完整重证与前缀冻结 ⇒ 等价 v20（活性下降但安全）；
- DCL 失效（账本损坏）⇒ 立即结束当前会话、清空承诺并要求重新确认 ⇒ 等价 v20（安全但健忘）；
- FMPG 失效（模型超时/版本不可信）⇒ 不采样基础模型，只用 v20 的 DCM/OGCC 演示挖掘路径 ⇒ 等价 v20；
- CCS 失效（流式调度不可用）⇒ 同步整句、无打断、TTL 到期即退回 v20 APS ⇒ 等价 v20；
- 五者全失效 ⇒ 完全回退到 MetricVoiceGauge-NCD-HUTDH-v20；
- **安全继承**：SALC 只做域交与提问、CRE 只在域内做增量或完整重证、DCL 只加约束、FMPG 只提名与受证书包含约束的迁移、CCS 只截断与冻结；五端口都不新增授权、不放宽阈值，`Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19` 由引理 163 保证。

## 4. 预期贡献

1. **语音共识证书**：首次把「语音→动作」改写为「在后验歧义集合上求认证域交集」，证明低置信度不会静默直通，而是显式转化为「澄清」这一安全动作；
2. **证书分离式澄清**：提出以 `IG + λ·CertSep` 选择澄清问题，使语音交互的澄清不仅减少语义不确定性，也保证两个回答分支都落在可认证域内；
3. **修正即证书增量**：把 barge-in 与「往左一点」形式化为 `CertDelta` 与前缀冻结，给出局部修正不弱于原证书的充分条件，关闭「旧计划已停、新计划未证」的缝隙；
4. **单调承诺账本**：把多轮安全约束从「模型上下文」提升为不可遗忘、可审计、需显式释放的账本，证明模型遗忘不导致历史约束失效；
5. **基础模型提名治理**：给出证书边际排序、证书包含测试、共形迁移校准与版本钉住，使基础模型的通用性只扩大提案空间、不扩大授权空间；
6. **对话—感知—碰撞三层统一**：v20 管「分布式感知给出的碰撞域」，v21 管「语音歧义与对话承诺如何安全地选择/修正这些域」，以 `Exec_v21 ⊆ Exec_v20` 把语言、感知、几何三层闭环到同一个证书格。

## 5. 本轮最大风险

**一句话**：SALC/CRE/DCL 的全部安全保证都以「真实意图与真实承诺落在系统可见的歧义集合/账本内」为前提，若远场语音、方言或指代消解把真实意图系统性排除在 `H_ε` 之外，系统就会在「所有候选都被认证」的形式保证下执行一个几何安全、却语义错误且从未被任何证书真正覆盖的动作——即「安全地做错事」。

| Π_K = {π_1,…,π_K} | 基础模型采样的候选计划集合 |
| margin_cert(π) | 证书边际：域边界最小间隙 / margin_col（并含体积门控） |
| T_φ | 潜空间对齐诱导的跨任务参数迁移映射 |
| Θ_trans = T_φ(Θ_src) ∩ Θ_tgt^col | 迁移后参数域（强制与目标认证域求交） |
| s_trans | 迁移共形非一致性分数 |
| q̂_α | 迁移校准集的 (1-α) 分位数 |
| h_FM | 基础模型版本哈希（权重+分词器+适配器） |
| Cache(h_FM) | 按模型版本钉住的证书缓存 |
| τ_stream | 流式语音片段的新鲜度年龄 |
| stable(h) | 连续两次 partial 锚序列一致且参数在容差内 |
| mode_voice ∈ {FULL, CONSENSUS, CLARIFY, V20} | 语音层单调模式阶梯 |
| ζ_voice | 对话—基础模型层共享状态 |
| Exec_v21 | SALC/CRE/DCL/FMPG/CCS 全部通过、且可由 v20 CSC 执行的计划集合 |

## 1. 关键定义（定义 821–845，严格化）

**定义 821（ASR 晶格）** `L_asr = {(h_i, p_i)}_{i=1}^N`，其中 `p_i ≥ 0`、`Σ_i p_i = 1`；`h_i` 是第 i 个转写假设，可携带槽位、指代与说话人标记。

**定义 822（歧义集合）** 给定 `ε_voice, δ ∈ (0,1)`，按后验降序排列后取
`H_ε = {h_i | p_i ≥ ε_voice} ∪ {h_i | Σ_{j≤i} p_j < 1-δ}`。韵律校准只能降低 `ε_voice`（扩大 `H_ε`），不得提高其低于 `ε_floor`。

**定义 823（语音编译）** `compile(h) = (A(h), Θ(h))` 当且仅当 v17 S2C 将 h 的每个子任务投影到认证锚且 `A(h)` 全部满足当前里程碑/硬件门控；否则 `compile(h) = ⊥`。`Θ(h)` 是该锚序列在当前物体与 v20 感知证书下的参数域。

**定义 824（语音共识域）** 若 `∀h,h' ∈ H_ε: compile(h),compile(h') ≠ ⊥ ∧ A(h)=A(h')`，则
`Θ^sp = ⋂_{h∈H_ε} Θ(h)`；否则 `Θ^sp = ∅`。仅当 `Θ^sp ≠ ∅ ∧ vol(Θ^sp) ≥ margin_voice ∧ CCV(Θ^sp)=SAFE` 时 `CONSENSUS_OK = true`。

**定义 825（安全澄清）** `q* = argmax_{q∈Q_safe} [IG(q) + λ·CertSep(q)]`，其中
`CertSep(q) = min_{a ∈ Ans(q)} vol(⋂_{h∈H_ε, h⊨a} Θ(h))`（空集记 0），且 `Q_safe = {q | compile(q)=⊥ 或 compile(q) 完全落在既有认证域内}`。问题本身不得改变机器人状态。

**定义 826（修正参数化）** 修正话语 `r` 经参数编辑语法 `parse_repair(r)` 得到 `Δθ`；支持否定、相对量、范围与停止四类算子。解析失败返回 `⊥`，必须转入澄清。

**定义 827（证书增量）** `CRE_OK(r, θ, n) ⇔ θ+Δθ ∈ Θ_n^col ∧ CCV(n, o, θ+Δθ)=SAFE ∧ prefix_unchanged`。成立时仅记录 `CertDelta`；不成立时 `PrefixFreeze(t)` 并完整重证。

**定义 828（前缀冻结）** 时刻 `t` 之后，任何新计划的首状态必须等于 `x_t`；旧计划中 `t` 之后的未执行段全部作废；不允许新旧计划在时间区间上重叠。

**定义 829（承诺）** `C_c = (type, scope, required_auth, created_at)`，`type ∈ {param_exclusion, anchor_exclusion, clearance_floor}`。承诺在会话内只能追加，不能因模型上下文裁剪而消失。

**定义 830（生效域）** `Θ^eff = Θ^cert ∩ ⋂_{c ∈ L_commit, active} C_c`；对锚排除型承诺，计划锚序列必须满足 `A(π) ∩ scope(c) = ∅`。

**定义 831（释放）** `release(c,u)` 允许当且仅当 `u` 含显式否定（「可以碰红色了」）且 `auth(u) ≥ required_auth(c)`；到期只触发确认，不自动释放。

**定义 832（基础模型提议）** `π_k ~ q_FM(·|context)`，`k=1..K`；每个 `π_k` 必须经 `compile(π_k)` 与 v20 `CCV/OGCC/HPC` 硬门，失败者直接丢弃。

**定义 833（证书边际）** `margin_cert(π) = min_{θ∈∂Θ(π)} clear(θ) / margin_col`，且要求 `vol(Θ(π)) ≥ margin_voice`；排序键为 `(margin_cert, -model_score)`，证书优先、模型分数仅 tie-break。

**定义 834（证书对齐迁移）** `Θ_trans = T_φ(Θ_src) ∩ Θ_tgt^col`；接受当且仅当 `Θ_trans ≠ ∅ ∧ vol(Θ_trans) ≥ margin_voice ∧ s_trans ≤ q̂_α`。迁移结果永远与目标认证域求交，故不可能超出目标域。

**定义 835（迁移共形分数）** 在校准集 `D_cal = {(src_j, tgt_j, T_{φ_j})}` 上定义
`s_trans = 1 - vol(T_φ(Θ_src) ∩ Θ_tgt^col) / vol(T_φ(Θ_src))`（分母为 0 时记 1）；`q̂_α` 为其 `⌈(n+1)(1-α)⌉/n` 分位数。

**定义 836（版本钉住）** 每份证书携带 `h_FM`；若当前模型 `h_FM' ≠ h_FM`，该证书进入 `INVALID`，必须经 `Recalibrate(h_FM')` 与 `Revalidate` 才能重新使用。

**定义 837（流式稳定）** `stable(h) ⇔ A(h_t)=A(h_{t-1}) ∧ ||θ(h_t)-θ(h_{t-1})|| ≤ ε_stable`；未稳定的 partial 永不进入 `compile`。

**定义 838（模式阶梯）** `FULL → CONSENSUS → CLARIFY → V20` 严格单调；`τ_stream ≤ TTL_voice` 允许 FULL/CONSENSUS，`TTL_voice < τ_stream ≤ 2·TTL_voice` 只允许 CLARIFY/V20，`> 2·TTL_voice` 强制 V20。禁止跨级、禁止拼接。

**定义 839（共享状态）** `ζ_voice = (L_asr, H_ε, Θ^sp, L_commit, θ_current, {CertDelta}, h_FM, Π_K, margin_cert, τ_stream, mode_voice)`。

**定义 840（v21 执行集）** `Exec_v21 = {π | SALC_OK(π) ∧ CRE_OK ∨ FullRecert(π) ∧ DCL_OK(π) ∧ FMPG_OK(π) ∧ CCS_OK(π) ∧ π ∈ Exec_v20}`。

# IP-425 Spoken Ambiguity Lattice Compiler
class SpokenAmbiguityLatticeCompiler:
    def __init__(self, s2c, ccv, margin_voice=0.01, eps_floor=1e-3, delta=0.05, lam=0.5):
        self.s2c = s2c
        self.ccv = ccv
        self.margin_voice = margin_voice
        self.eps_floor = eps_floor
        self.delta = delta
        self.lam = lam

    def ambiguity_set(self, L_asr, prosody=None):
        # 韵律只能扩大歧义集合：只允许降低 eps，不允许抬高
        eps = 1e-3
        if prosody is not None:
            eps = max(self.eps_floor, min(eps, self.suggest_eps(prosody)))
        H, cum = [], 0.0
        for h, p in sorted(L_asr, key=lambda x: -x[1]):
            cum += p
            if p >= eps or cum < 1.0 - self.delta:
                H.append((h, p))
        return H

    def compile_lattice(self, L_asr, x, m_star, h_star, prosody=None):
        H = self.ambiguity_set(L_asr, prosody)
        if not H:
            return None, "NO_HYPOTHESIS", "CLARIFY"

        compiled = []
        for h, p in H:
            hit = self.s2c.compile(h, x, m_star, h_star)
            if hit is None:
                # 只要有一个合理解释无法认证，就不得执行其它解释
                return None, "HYPOTHESIS_UNCOMPILABLE", "CLARIFY"
            A, domain = hit
            compiled.append((h, p, A, domain))

        anchors = {self.anchors_key(A) for _, _, A, _ in compiled}
        if len(anchors) != 1:
            return None, "ANCHOR_DISAGREEMENT", "CLARIFY"

        domain_sp = compiled[0][3]
        for _, _, _, d in compiled[1:]:
            domain_sp = domain_sp.intersect(d)
            if domain_sp.is_empty():
                return None, "EMPTY_CONSENSUS", "CLARIFY"

        if domain_sp.volume() < self.margin_voice:
            return None, "CONSENSUS_TOO_SMALL", "CLARIFY"
        if not self.ccv.verify_domain(compiled[0][2].node, x.obj, domain_sp):
            return None, "CONSENSUS_CCV_REJECT", "CLARIFY"

        return (compiled[0][2], domain_sp), "CONSENSUS_OK", "CONSENSUS"

    def clarify(self, H, candidates):
        best, best_score = None, float("-inf")
        for q in candidates:
            if not self.question_safe(q):
                continue
            branches = self.split_by_answer(H, q)      # 每个回答对应一个子歧义集
            volumes = []
            for branch in branches.values():
                doms = [d for _, _, _, d in branch if not d.is_empty()]
                volumes.append(intersect_all(doms).volume() if doms else 0.0)
            cert_sep = min(volumes) if volumes else 0.0
            ig = self.entropy(H) - sum(self.entropy(b) for b in branches.values())
            score = ig + self.lam * cert_sep
            if score > best_score:
                best, best_score = q, score
        return best

    def question_safe(self, q):
        # 问题必须是非动作的：编译为 ⊥，或完全落在既有认证域
        hit = self.s2c.compile(q, self.current_x, self.m_star, self.h_star)
        return hit is None or self.ccv.verify_domain(hit[0].node, self.current_x.obj, hit[1])


# IP-426 Certified Repair Editor
class CertifiedRepairEditor:
    def __init__(self, s2c, ccv, ledger, margin_repair=1e-3):
        self.s2c = s2c
        self.ccv = ccv
        self.ledger = ledger
        self.margin_repair = margin_repair

    def on_repair(self, r, plan, theta, x, commitments):
        if plan.frozen:
            return "HOLD_FROZEN", None

        delta = self.parse_repair(r)
        if delta is None:
            return "REPAIR_UNPARSED", None

        theta_new = theta + delta
        if not self.ledger.allows(theta_new, plan.anchors):
            return "COMMITMENT_VIOLATION", None

        in_domain = plan.domain.contains(theta_new, margin=self.margin_repair)
        near_boundary = not plan.domain.contains(theta_new, margin=2 * self.margin_repair)
        if in_domain and (not near_boundary or
                          self.ccv.verify(plan.node, x.obj, theta_new)[0] == "SAFE"):
            cert_delta = CertDelta(node=plan.node, theta_old=theta, theta_new=theta_new,
                                   utterance=r, timestamp=x.t)
            plan.apply_delta(cert_delta)
            return "APPLY_DELTA", cert_delta

        # 越界：冻结已执行前缀，完整重证；新计划从当前状态起步
        plan.freeze_prefix(x.t)
        new_plan, status = self.s2c.recompile(plan, x, theta_new)
        if status != "OK":
            return "RECOMPILE_REJECT", None
        return "FULL_RECERT", new_plan

    def parse_repair(self, r):
        # 支持：否定/相对量/范围/停止；不可解析返回 None
        return parse_parameter_edit(r, frame="camera", units="metric")


# IP-427 Dialogue Commitment Ledger
class DialogueCommitmentLedger:
    def __init__(self):
        self.active = []
        self.released = []
        self.session_id = None

    def add(self, c, utterance, authority):
        if authority < c.required_auth:
            return "AUTH_INSUFFICIENT"
        self.active.append(c)
        return "ADDED"          # 只增不减，保证单调

    def release(self, cid, utterance, authority):
        c = self.find(cid)
        if c is None or authority < c.required_auth:
            return "AUTH_INSUFFICIENT"
        if not contains_explicit_negation(utterance):
            return "NOT_EXPLICIT"
        self.active.remove(c)
        self.released.append((c, utterance, authority))
        return "RELEASED"

    def effective_domain(self, cert_domain, anchors):
        domain = cert_domain
        for c in self.active:
            if c.type == "param_exclusion":
                domain = domain.subtract(c.scope)
            elif c.type == "clearance_floor":
                domain = domain.intersect(domain.filter(lambda t: clearance(t) >= c.scope))
            elif c.type == "anchor_exclusion":
                if any(a in c.scope for a in anchors):
                    return None
        return domain

    def allows(self, theta, anchors):
        dom = self.effective_domain(ALL, anchors)
        return dom is not None and dom.contains(theta)


# IP-428 Foundation Model Proposal Governor
class FoundationModelProposalGovernor:
    def __init__(self, fm, cert_pipeline, margin_voice=0.01, alpha=0.05):
        self.fm = fm
        self.pipeline = cert_pipeline
        self.margin_voice = margin_voice
        self.alpha = alpha
        self.cache = VersionPinnedCache()

    def propose(self, context, K):
        h_fm = self.fm.version_hash()
        raw = [self.fm.sample(context) for _ in range(K)]
        scored = []
        for pi in raw:
            compiled = self.pipeline.compile(pi)
            if compiled is None:
                continue
            A, domain = compiled
            if domain.volume() < self.margin_voice:
                continue
            if not self.pipeline.ccv.verify_domain(A.node, context.obj, domain):
                continue
            m = self.cert_margin(domain, context.obj)
            scored.append((m, self.fm.score(pi), pi, domain))
        scored.sort(key=lambda t: (-t[0], -t[1]))
        return [(pi, dom) for _, _, pi, dom in scored], h_fm

    def cert_margin(self, domain, obj):
        boundary = domain.boundary_samples()
        clearances = [signed_clearance(t, obj) for t in boundary]
        return min(clearances) / self.pipeline.margin_col

    def transport(self, src, tgt, calibration):
        T = self.fm.align(src, tgt)
        theta_trans = T(src.domain).intersect(tgt.certified_domain)
        if theta_trans.is_empty() or theta_trans.volume() < self.margin_voice:
            return None, "TRANSPORT_VOLUME"
        s = self.nonconformity(T, src, tgt)
        if s > calibration.quantile(self.alpha):
            return None, "TRANSPORT_CONFORMAL_REJECT"
        if not self.pipeline.ccv.verify_domain(tgt.node, tgt.obj, theta_trans):
            return None, "TRANSPORT_CCV_REJECT"
        cert = TransportCert(src=src, tgt=tgt, T=T, theta_trans=theta_trans,
                             s_trans=s, h_fm=self.fm.version_hash())
        return cert, "OK"

    def nonconformity(self, T, src, tgt):
        transported = T(src.domain)
        return 1.0 - transported.intersect(tgt.certified_domain).volume() / max(
            1e-12, transported.volume())

    def on_version_change(self, new_version, calibration_factory):
        self.cache.invalidate_all()
        self.fm.rebind(new_version)
        self.calibration = calibration_factory.recalibrate(new_version)
        return "INVALIDATED_RECALIBRATED"


# IP-429 Conversational Certificate Scheduler
class ConversationalCertificateScheduler:
    def __init__(self, salc, cre, ledger, fmpg, aps, ttl_voice=1.0):
        self.salc = salc
        self.cre = cre
        self.ledger = ledger
        self.fmpg = fmpg
        self.aps = aps
        self.ttl_voice = ttl_voice
        self.last_partial = None

    def tick(self, partial, now, x, m_star, h_star):
        if partial.is_barge_in:
            self.freeze_and_cancel(now)
            return "PREFIX_FROZEN"

        if not self.stable(partial):
            return "HOLD_UNSTABLE"

        tau = now - partial.created_at
        if tau > 2 * self.ttl_voice:
            return self.aps.activate_freshness_ladder("V20")

        consensus, status, mode = self.salc.compile_lattice(
            partial.lattice, x, m_star, h_star, partial.prosody)
        if mode == "CONSENSUS":
            eff = self.ledger.effective_domain(consensus[1], consensus[0].anchors)
            if eff is None or eff.is_empty():
                return "COMMITMENT_EMPTY"
            return ("EXECUTE_CONSENSUS", consensus[0], eff)

        if tau > self.ttl_voice:
            return self.aps.activate_freshness_ladder("V20")

        q = self.salc.clarify(self.salc.ambiguity_set(partial.lattice), partial.questions)
        return ("CLARIFY", q)

    def stable(self, partial):
        sig = (tuple(partial.anchor_signature), round(partial.theta_norm, 6))
        ok = self.last_partial == sig
        self.last_partial = sig
        return ok

    def freeze_and_cancel(self, now):
        self.cre.current_plan.freeze_prefix(now)
        self.fmpg.cancel_pending()
        self.aps.on_barge_in(now)

## 3. 推导

**引理 157（语音共识安全性）** 假设真实意图 `h* ∈ H_ε`。若 `compile_lattice` 返回 `CONSENSUS_OK`，则 `∀h∈H_ε: A(h)` 相同且 `Θ^sp = ⋂ Θ(h)`；于是任何被执行参数 `θ ∈ Θ^sp ⊆ Θ(h*)`，且 v20 `CCV(Θ^sp)=SAFE` 保证该域内零碰撞。若任一假设 `⊥`、锚序列不一致、交集为空或体积不足，则不执行、只澄清。故语音层不新增授权，`Exec_v21 ⊆ Exec_v20`。∎ 推论：**低置信度只能降低活性（更多澄清），不能变成一条静默直通的不安全动作**。

**引理 158（澄清非动作安全性）** 澄清问题 `q ∈ Q_safe` 满足 `compile(q)=⊥` 或完全落在既有认证域，且不改变机器人状态。因此提问本身不引入新的动作序列，也不产生新的碰撞路径；其唯一后果是获取信息。故在共识失败时选择澄清永远不弱于随机猜测或强行执行。∎

**引理 159（修正局部性）** 若 `CRE_OK`，则 `θ+Δθ ∈ Θ_n^col` 且 `CCV=SAFE`；由 v20 引理 146，域内点已有 SAFE 证书，故不重证不降低安全性。若越界，则 `PrefixFreeze(t)` 后完整重证，且新计划从 `x_t` 起步，旧计划未执行段作废；不存在「旧段仍在执行、新段尚未认证」的重叠区间。故 CRE 只能收缩或保持授权域。∎

**引理 160（承诺单调性）** `L_commit` 在会话内只追加；`Θ^eff = Θ^cert ∩ ⋂ C_c` 随 `C_c` 增加而单调不增。任何被执行计划都必须通过 `effective_domain` 与 `allows_plan`；模型上下文裁剪不影响账本。释放需显式否定与权限。故历史承诺不会因基础模型遗忘而失效，DCL 只能收缩授权域。∎

**引理 161（基础模型提名与迁移保守性）** 所有被接受的 `π_k` 均通过 v20 `compile/CCV/OGCC/HPC` 硬门；`margin_cert` 只改变排序，不改变是否安全。迁移域 `Θ_trans = T_φ(Θ_src) ∩ Θ_tgt^col` 强制与目标认证域求交，故必为 `Θ_tgt^col` 子集；共形分数只做拒绝、不做授权；版本变更使旧证书失效。故 FMPG 只能扩大提案空间，不能扩大授权空间。∎

**引理 162（流式时序安全）** 未稳定 partial 不进入 `compile`；打断立即 `PrefixFreeze` 并取消待定提案；`τ_stream > 2·TTL_voice` 强制 V20；控制环只做非阻塞状态检查。故控制环 p99 与 ASR/基础模型延迟解耦，且不存在「执行了尚未稳定或已过期语义」的路径。∎

**引理 163（v21 整体安全继承）** 在同一 ASR 校准集、同一承诺账本快照、同一基础模型版本下，SALC 只做域交与提问（引理 157、158），CRE 只在域内增量或前缀冻结后完整重证（引理 159），DCL 只加约束（引理 160），FMPG 只提名且迁移强制求交（引理 161），CCS 只截断/冻结/降级（引理 162）。五端口复合只能产生 `Exec_v20` 的子集，故 `Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ …`。∎

## 7. 已知风险与失效模式

1. **歧义集合覆盖失败**：远场、方言、语速、鸡尾酒会噪声、代码切换与言语反讽可能使真实意图落在 `H_ε` 之外。系统会在「所有候选都安全」的形式保证下执行一个语义错误的动作。缓解：多麦克风阵列、说话人自适应、主动确认、把「低覆盖风险」本身作为澄清触发条件。
2. **指代/接地错误**：语音中的「那个」「这里」依赖共享视觉注意，若视觉接地与语音指代同时偏移，`H_ε` 内所有假设可能共享同一个错误指代，交集仍然非空。缓解：显式指代确认、目光/手势融合、候选物体高亮复述。
3. **否定与范围解析错误**：「不要往左，往右一点」的否定辖域解析错误可能产生一个仍在域内、但方向相反的 `Δθ`；几何安全但语义错误。缓解：参数编辑语法强约束、复述确认、否定范围标注。
4. **打断竞态**：ASR final 与 barge-in 可能在同一帧到达，若先提交 final 再处理打断，会多执行一个控制周期。缓解：时间戳全序、final 与 barge-in 同队列仲裁、冻结点取更早者。
5. **承诺账本膨胀**：长会话中承诺只增不减会杀死活性，用户又不总会显式释放。缓解：承诺合并、过期确认（不自动释放）、可视化账本、按约束强度分层。
6. **迁移共形校准的分布漂移**：`D_cal` 未覆盖的新任务/新物体上，`s_trans` 的分位数不再有效，潜空间对齐可能把源域映射到「目标域内但语义错误」的区域。缓解：在线漂移检测、拒绝选项、扩大校准集、证书包含测试之外的语义一致性检查。
7. **模型版本静默漂移**：边缘端热更新、适配器切换、量化版本变化可能未正确改变 `h_FM`，导致旧证书被错误复用。缓解：权重+分词器+适配器联合哈希、启动自检、证书与版本双向绑定。
8. **基础模型提案的同质化**：K 个样本可能高度相关，证书排序在相关样本上无法覆盖真正的安全备选。缓解：多样性采样、温度调节、按证书边际分层采样。
9. **多说话人/侧边对话误触发**：电视、旁人对话可能被当作命令。缓解：声源定位+说话人验证+唤醒词+权限等级，默认只接受已登记说话人。
10. **可审计性与隐私**：语音与承诺日志含敏感信息，Merkle 审计链需要在不泄露原始音频的前提下可验证。缓解：承诺与证书哈希上链、音频本地脱敏、最小化留存。

## 8. 本轮最大风险

**一句话**：SALC/DCL/CRE 的安全保证全部以「真实意图与真实承诺都落在系统可见的歧义集合/账本内」为前提；若远场语音或指代消解把真实意图系统性排除在 `H_ε` 之外，系统就会在「所有候选都被认证」的形式保证下执行一个几何安全、语义错误且从未被任何证书真正覆盖的动作——即「安全地做错事」。
