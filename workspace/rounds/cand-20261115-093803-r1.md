# 第 4 轮（灵感循环第 4 轮；本轮灵感：「故障诊断」×「通用操作」）

> **基线**：第 3 轮 InstructGauge（IP-321–327；定义 432–447；引理 51–58；实验 E441–E456）。第 1/2 轮 LeanGauge / ToolGauge 骨架继续继承不变。
> 本轮纪律：**增量升级 + 严格退化**。两个新灵感各沿一条轴升级 InstructGauge，且任一环节不可用都必须能一键退回 InstructGauge → ToolGauge → LeanGauge → MODGAUGE。诊断与包线是增强项、不是依赖项。

## 0. 直觉与动机

**灵感 1（故障诊断 → 诊断的是「哪个假设坏了」，而不只是「坏了」）**
直觉：前几轮把整条计量栈当作可信仪器；但真实部署里仪器会坏、契约会过期、模型会随新工具失配。故障诊断的核心从来不是「报警」，而是**隔离**——判断是传感器偏了、工具磨了、还是世界变了。把这一点抬到系统层：**降级链本身就是一次诊断决策**。过去「ToolGauge 失败 ⇒ LeanGauge」是硬编码布尔；在通用场景里「失败」是**模糊证据**，而误诊本身就是一种故障——误报导致无谓降级、白白丢能力；漏报导致带病继续、丢掉安全。因此正确的姿态不是「加一个报警器」，而是把「信任哪一层」显式建模成诊断推理。

**灵感 2（通用操作 → 泛化不是「处处正确」，而是「知道自己在哪有效」）**
直觉：通用操作意味着任意物体、任意工具、任意本体，操作域大到无法逐点证明。追求「全局正确」是错误目标；正确姿态是给每个契约标注**有效域**，只在域内激活，域外一律映射到安全回退。于是「泛化」被改写成一个**覆盖问题**：部署分布被多少个「受守护且已诊断健康」的契约覆盖，覆盖不到的部分是否安全。这把一个无法证明的「策略普适性」问题，换成了可度量、可退化的「覆盖度 + 回退安全性」问题。

**灵感 3（两者耦合 → 诊断使泛化可退，泛化使诊断必要）**
直觉：通用操作制造「未知故障」（尤其模型性/语义性故障，往往**没有残差**），而故障诊断给泛化提供「分区信任」。耦合后最关键的结构是**诊断格**：证据 → 一组相容故障假设 → 在安全配置格上取**下确界（meet）**。取 meet 的保守性给出「歧义只降能力、不降安全」；真正危险的只剩**漏检**。于是安全性被干净地归结为一个**检测保证**，而隔离精度不再是安全瓶颈。再往前一步：被动残差在模型部分未知时无法区分「模型坏了」与「硬件坏了」，必须用**安全的主动探针**去主动证伪——而探针恰好复用前一轮的分块与信息增益机制，整个体系形成闭环。

## 1. 研究问题（本轮要回答什么）

- **Q1（可诊断性）**：在模型部分未知的通用场景，哪些残差还能构造（模型轻量残差）？哪些故障可隔离、哪些先天不可分（例如模型故障 vs. 硬件故障）？
- **Q2（保守退化）**：当证据只能给出「相容故障假设集合」而非唯一故障时，如何选择安全配置而不牺牲不必要的能力？能否证明「歧义只降能力、不降安全」？
- **Q3（泛化的安全口径）**：如何把「通用操作」从「处处保证」改写为「受守护契约覆盖 + 域外安全回退」？覆盖度如何度量、如何随分布漂移优雅退化？
- **Q4（主动诊断）**：被动残差不可分时，能否用安全探针主动区分，且诊断动作本身不扩大物理包线？

## 2. 三条设计原则（雏形，正式化见产物区定义 448–463）

**P1 残差模型轻量化（Model-light Residuals）**
通用场景下不能依赖精确模型做奇偶校验（模型本身可能正是故障源）。优先用**不变量/跨模态/跨回执/任务进展**四族残差；它们对本体差异做不变量归一，从而跨本体可比。残差必须**因果绑定**到可能的故障，而不是只绑定到「执行发生了」。

**P2 歧义保守（Ambiguity-Conservative）**
诊断输出是**假设集合**而非单点。配置取各相容假设安全配置的 **meet（下确界）**；由于安全沿降级方向单调，歧义只会把配置压低（能力更小），绝不会越过任何相容故障的安全配置。真正需要被校准与控制的是**漏检**（真实故障不在假设集合内）。

**P3 守卫域 + 安全回退（Guarded Envelope + Safe Fallback）**
契约只在有效域 `Dom` 内激活；域外一律回退到 `c_fallback`（探测/停止/逐步），**绝不默认信任**。泛化不靠全局保证，而靠「域内已诊断健康 + 域外安全回退」。守卫本身的风险（把域外误判为域内）必须被显式度量。

## 3. 与基线的接口（如何退化）

- 主动诊断不可用 ⇒ 退回被动诊断（只检测不隔离）；隔离歧义下取保守 meet（可能过度降级，但安全）；
- 诊断完全不可用 ⇒ 退回 InstructGauge 继承的 ToolGauge P-Quarantine 单一断路器（只检测、不隔离），并降低分块 K；
- 包线守护不可用 ⇒ 退回 InstructGauge 的全局共形阈值，显式承认域外风险（并 `K` 收紧）；
- 再资格认证不可用 ⇒ 禁止自动重入，保守要求离线复核；
- InstructGauge 失效 ⇒ ToolGauge 逐步执行；ToolGauge 失效 ⇒ LeanGauge 纯数值；LeanGauge 失效 ⇒ MODGAUGE 原样。

诊断与包线都是增强项：关掉它们、恒输出 `c_full` 且不做域判定时，控制流精确退化为 InstructGauge（引理 68 的操作等价，而非纯投影）。

## 4. 预期贡献

1. 把**降级链重述为故障诊断决策**的形式化：信任配置格 + 相容故障集 + 保守 meet（定义 451/452/459）；
2. 一条核心安全定理：**歧义只降能力、不降安全，安全性归结为漏检概率**（引理 60 + 63）；
3. 一个「通用操作 = 受守护契约覆盖 + 域外安全回退」的泛化口径与可度量的覆盖/泛化间隙（定义 454/455，引理 62）；
4. **主动诊断**用于区分模型故障与硬件故障（含一条被动不可分的不可能性结果），以及风险加权校准与再资格认证（定义 453/456/457，引理 61/64/66）；
5. 可证伪路径 E457–E472：故障注入、扰动-故障可分、模型/语义故障、主动诊断增益、歧义安全、误报/漏报、包线覆盖、再资格、跨本体、时序、对抗与不可分性负对照。

## 5. 本轮最大风险

**一句话**：包线守护器本身也是学习组件，与被守护策略共享同一分布外盲区——当「沉默的模型性故障」既无残差可测、又恰被守卫判为「域内」时，诊断闭环失去杠杆，安全性只能退化为对「可注入故障」的校准假设。

## 2. 形式化定义（要点）

**定义 448（故障模型 F）** `F = F_hw ∪ F_proc ∪ F_model ∪ F_sem ∪ {f₀}`：`F_hw` 为传感器偏置/漂移、工具磨损、执行器增益丢失；`F_proc` 为世界变化（盲区移动、材质改变）——**不是仪器故障**，但改变契约有效性；`F_model` 为工具/动力学/包线模型对新对象/新本体失配（通用操作的主故障）；`F_sem` 为接地/目标语义错误（继承 InstructGauge）；`f₀` 为无故障。关键：`F_proc` 与 `F_hw` 可产生同向残差，须靠主动探针可分（定义 450/453、引理 66）。

**定义 449（结构化残差与特征矩阵）** 四族残差 `r = (r_inv, r_pred, r_cross, r_prog)`：`r_inv` 为物理不变量残差（接触刚性、几何一致、能量/动量守恒），**模型轻、可跨本体**；`r_pred` 为一步/块预测残差（复用 Round 3 的 drift）；`r_cross` 为跨模态/跨回执一致性（视觉-触觉-本体感受、`cross_receipt`）；`r_prog` 为任务进展残差（信念更新 vs. 期望信息增益）。特征矩阵 `S: F×R → {+,-,?}`，`+` 敏感、`-` 不敏感、`?` 未知。**通用场景里 `?` 大量存在，这正是歧义的根源**。残差按本体不变量归一：`r̃ = r / ι_emb`，使跨本体可比。

**定义 450（可诊断性与不可分对）** 故障对 `(f_i,f_j)` **可隔离**当且仅当 `∃ r ∈ R`，`S[f_i,r] ≠ S[f_j,r]` 且二者均非 `?`。隔离矩阵 `Iso ∈ {0,1}^{|F|×|F|}`；不可分关系取传递闭包得**不可分等价类** `[f]`。若不可分对内各故障安全配置不同，只能取 meet（定义 452）或必须主动探针（定义 453）分开。特别地，`F_model` 与 `F_hw` 在被动残差下**一般不可分**（引理 66）。

**定义 451（诊断格 𝔇）** 信任配置 `c ∈ 𝔇` 为**逐层信任向量的乘积格**（硬件层/契约层/校准层/接地层各一轴），偏序 `c₁ ⊑ c₂` 表示「`c₁` 更降级（能力更小）」。主轴链 `c_full ⊒ c_step ⊒ c_lean ⊒ c_mod ⊒ c_fallback`。安全成本 `safe: 𝔇 → [0,1]` 关于 `⊑` **单调**：`c₁ ⊑ c₂ ⇒ safe(c₁) ≥ safe(c₂)`（越降级越安全）。`⊓` 为逐轴 meet（下确界）。

**定义 452（保守退化映射与歧义安全）** 诊断相容集 `B(e) = { f ∈ F : P(e|f) ≥ τ_ev }`（或信念支撑集）。定义
`degrade(B) = ⊓_{f∈B} safe_cfg(f)`。
性质（引理 60）：若 `safe` 关于 `⊑` 单调、`𝔇` 为格，则 (i) `safe(degrade(B)) ≥ safe(safe_cfg(f))` 对所有 `f∈B`；(ii) `degrade(B)` 是满足该安全性质中**能力损失最小**者；(iii) 剩余安全缺口仅为 `f* ∉ B`（漏检）。即**歧义只降能力、不降安全**，真正的漏洞是漏检。

**定义 453（主动诊断目标 ADP）** 探针 `p` 取自安全可采纳集。期望信息增益 `J(p) = H(B) − E_{r_p}[H(B | e, r_p)]`。选择 `p* = argmax_p J(p) s.t. ProbeSafe(p), cost(p) ≤ B_diag`。贪心次模 ⇒ `(1−1/e)` 近似（引理 61）。探针**不得扩大物理包线**——诊断本身必须先安全（定义 460）。

**定义 454（守卫式契约与包线）** `K = (Dpe, Dom, Guard)`，`Dom ⊆ X` 为有效域，`Guard: X → {in, out, ?}`。仅当 `Guard(x)=in` **且**该契约被 DIAG 判为健康时才激活；`Guard=out ⇒ c_fallback`；`Guard=? ⇒` 保守按 `out`（或先降级探测）。**绝不默认信任**。

**定义 455（覆盖度与泛化间隙）** 部署分布 `P_gen`。`Cov = P_gen(∪_i Dom_i^{trusted})`，`Γ_gap = 1 − Cov`。泛化口径：`P_safe(P_gen) = 1` 当且仅当 (i) 激活契约都在其 `Dom` 内且已诊断健康，(ii) 域外映射 `c_fallback`。用加权共形/置信下界估计 `Cov`（引理 62）。引入 guard 误入率 `γ_g = P(Guard=in | x∉Dom)` 作为覆盖可信度的显式量。

**定义 456（风险加权诊断校准 RW-Cal）** 按动作不可逆性分层 `a ∈ {rev, irr}`，阈值 `τ_rev > τ_irr`（越不可逆越敏感）。混合代价 `C = c_fa·P(FA) + c_md·P(MD)`，`c_md^{irr} ≫ c_md^{rev}`。滞回带 `[τ_lo, τ_hi]` 防抖。分层共形给 `P(MD | irr) ≤ β_irr`、`P(MD | rev) ≤ β_rev`（引理 63）。

**定义 457（再资格认证 RQ）** 故障清除后重入需：(i) 窗口 `W` 内无故障证据；(ii) 通过**资格探针套件**（覆盖该层关键不变量的探针）；(iii) 滞回。重入映射 `Requal: c_degraded × Evidence → c'` 满足 `c' ⊒ c_degraded` 且**仅在证据超阈时上升**——杜绝「静默重信」（引理 64）。

**定义 458（诊断证书 DiagCert）** `DiagCert(s) = (r, B(e), degrade(B), probes, RQ, timestamp)`，与 Round 3 的 `RepairCert′` 组合成「故障 → 假设 → 配置 → 探针 → 再资格」五级审计链。

**定义 459（故障感知退化偏序）** 把 Round 3 的退化链升级为格：每级配置附带适用假设集 `A(c)`；激活 `c` 蕴含 `A(c)` 全成立。诊断即收缩 `A`，退化即沿格下行。**降级链 = 诊断输出**：`c_activated = degrade(B(e))`。

**定义 460（探针安全约束 ProbeSafe）** `p` 合法当且仅当 `p ∈ 𝔸_adm`（不扩物理包线）、`Barrier(p)`（不跨不可逆动作，除非单独成块 + 独立交叉验证）、且 `CVC` 可截断。诊断动作与操作动作共用同一安全盾——**诊断不能成为新的越权通道**。

**定义 461（时序诊断窗口）** 证据在窗口 `W` 上累积（诊断器/HMM 语义）：`B_{t} = update(B_{t-1}, r_t)`；长时程中故障可叠加，需联合后验而非逐拍独立。检测延迟 `L_det ≤ W_max`，计入 50Hz 预算（引理 65）。

**定义 462（包线分层校准）** 按 `stratum_E = (embodiment, tool class, regime)` 分层，每层独立检测阈值与覆盖下界；低样本层回退全局（沿用 Round 3 引理 55 的分层共形）。分布漂移用加权共形/betting 处理。

**定义 463（DiagGauge-8C 闭环）** 在 InstructGauge-7C 的 `I→H→C→E(chunk)→C→V→U` 上增加 **D**（诊断/隔离，置于 V 与 U 之间、异步否决点）与 **R**（再资格，置于热替换前否决点）。否决规则：D 判故障 ⇒ 沿格下降；R 未过 ⇒ 禁止重入。50Hz 内联路径仍只在 `MODGAUGE_round`。

## 3. 关键算法骨架

```python
# IP-328 FSR：四族结构化残差（模型轻量 + 跨本体归一）
def residuals(receipts, contract, emb):
    r_inv   = invariants(receipts)                  # 接触刚性/几何/能量一致性
    r_pred  = contract.predict_error(receipts)      # 一步/块预测残差（复用 drift）
    r_cross = cross_receipt_consistency(receipts)   # 视觉-触觉-本体感受
    r_prog  = task_progress_residual(receipts)      # 信念更新 vs 期望信息增益
    return normalize_emb((r_inv, r_pred, r_cross, r_prog), emb)   # 按本体不变量归一

# IP-329 DIAG-Lattice：相容集 → 保守 meet
class DiagLattice:
    def belief(self, e, window):                    # 时序联合后验，非逐拍独立
        return {f for f in F if self.P(e, window, f) >= self.tau_ev}
    def degrade(self, B):
        cfg = TOP
        for f in B:
            cfg = meet(cfg, self.safe_cfg[f])       # 逐轴下确界
        return cfg                                  # ⊑ 最大的安全选择

# IP-330 ADP：安全探针主动区分（尤其模型 vs 硬件）
class ActiveDiagnoser:
    def choose(self, B, budget):
        if len(B) <= 1: return None                 # 已隔离/无歧义
        best, bestJ = None, -inf
        for p in safe_probes(B):                    # ProbeSafe：不扩包线、过 Barrier/CVC
            J = entropy(B) - self.expected_entropy(B, p)
            if J > bestJ and cost(p) <= budget:
                best, bestJ = p, J
        return best                                 # 贪心次模，(1-1/e) 近似

# IP-331 EnvelopeGuard：守卫式契约，域外必回退
class EnvelopeGuard:
    def gate(self, x, contract):
        g = contract.guard(x)                        # in / out / ?
        if g == "out":  return FALLBACK
        if g == "?":    return PROBE_DEGRADED        # 保守：不默认信任
        return contract                              # 仍需 DIAG 判健康才激活

# IP-332 RW-Cal：按不可逆性分层阈值 + 滞回
class RWCal:
    def threshold(self, act_class, cal):
        s = (stratum_E(act_class), act_class)        # 包线分层 × 不可逆性
        if len(cal.get(s, [])) < N_MIN: s = GLOBAL
        tau = conformal_quantile(cal[s], alpha=ALPHA[act_class])
        return hysteresize(tau)                      # 防在两种配置间振荡

# IP-333 RQ：再资格认证（禁止静默重信）
class Requalifier:
    def requal(self, f, evidence, probe_suite):
        if not self.clear_for_window(f, evidence):   return None
        if not self.qualification_probes_pass(probe_suite): return None
        return self.ascend(f)                        # 仅单调上升、需证据

# IP-334 DiagGauge-8C 闭环
def diaggauge_8c(M, s, ell, x):
    out  = M.nlib.ground(ell, M.scene, M.ontology)
    iota = out[0] if out else M.default_iota
    k    = M.envguard.gate(x, M.contract(s))         # 域外 ⇒ 回退/降级探测
    if k is FALLBACK:
        return stub_and_red(s, "out_of_envelope")
    H    = M.lbox.hypothesize(s, M.dbox.R[s], iota)
    C    = M.iac.plan_chunk(iota, H, M.tools, M.budget_left(s), M.drift_bound(s))
    cert = M.cvc.commit(C, M.env, iota)
    receipts = cert.receipts
    e    = residuals(receipts, M.contract(s), M.embodiment)
    B    = M.diag.belief(e, M.window)                # D：诊断/隔离（异步否决点）
    cfg  = M.diag.degrade(B)                         # 歧义 ⇒ 保守 meet
    if M.diag.ambiguous(B) and M.adp.choose(B, M.b_diag):
        p = M.adp.choose(B, M.b_diag)                # 主动探针须 ProbeSafe
        e = e + residuals(M.cvc.commit(p, M.env, iota).receipts, M.contract(s), M.embodiment)
        B, cfg = M.diag.belief(e, M.window), M.diag.degrade(B)
    if cfg ⊏ M.contract(s).config:                   # 需下降
        if not M.requal.requal(cfg, e, M.probe_suite):    # R：再资格（否决点）
            M.contract(s) = M.contract(s).degrade_to(cfg)
    if len(receipts) < n_min(s):
        return stub_and_red(s, "insufficient")
    mu, Sig = M.apcal.calibrate(receipts, H, s)
    new_ec  = M.apcal.update_contract(M.dpe, mu, Sig, s)
    if contract_regression(new_ec):
        return stub_and_red(s, "regression")
    M.mreg.hot_replace_at_quiescence(M.dpe, new_ec, cert.boundary)
    M.diagcert.record(DiagCert(e, B, cfg, M.adp.last, M.requal.last))
    M.pquar.record(M.apcal.last_gain, realized_gain(receipts))
    return True

# IP-335 主闭环（50Hz 路径不变）
def DiagGauge_round(M, obs, audio, tac, depth, det, ell=None):
    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight:
            M.inflight.add(s)
            submit_async(diaggauge_8c, M, s, ell, M.scene)
    return MODGAUGE_round(M, obs, audio, tac, depth, det)
```

## 4. 推导

**引理 59（残差充分性与可诊断性）** 给定特征矩阵 `S`，故障对 `(f_i,f_j)` 可隔离当且仅当存在某残差 `r` 的两列可区分且非 `?`。若 `S` 的列在去掉 `?` 后两两不同，则存在确定性解码器 `D: R → 2^F`，使无噪声下 `D(r) = [f*]`；存在 `?` 时 `D` 只能给出 `[f*]` 的超集，安全由定义 452 的 meet 兜底。*证明骨架*：把每族残差视作对故障的检验统计量，列可区分即存在分离超平面；`?` 相当于该维无约束，故只能界定到等价类。

**引理 60（歧义安全的保守退化）** 设 `𝔇` 为乘积格、`safe` 关于 `⊑` 单调、`degrade(B) = ⊓_{f∈B} safe_cfg(f)`。则 (i) 对任意 `f∈B`，`safe(degrade(B)) ≥ safe(safe_cfg(f))`；(ii) `degrade(B)` 是所有满足 (i) 的元素中 `⊑`-最大（能力损失最小）者；(iii) 若真实故障 `f* ∈ B`，则激活配置不越过 `f*` 的安全配置。推论：**歧义只降能力、不降安全**，唯一安全缺口是漏检 `f* ∉ B`。*证明*：meet 是 `{safe_cfg(f)}` 的下界（逐轴 ≤ 各元素），由 `safe` 单调得 (i)；meet 为下确界即最大下界，得 (ii)；对逐轴逐层套用 (i) 得 (iii)。

**引理 61（主动诊断的次模性与安全性）** 若 `J(p)` 关于已选探针集次模，则贪心 `(1−1/e)` 近似最优；且所有候选 `p` 受 `ProbeSafe`（定义 460）约束，故诊断动作不扩物理包线、不越过不可逆屏障，安全盾归纳保持。*证明*：信息增益对条件观测次模（经典结果）；`ProbeSafe` 把候选限制在已证明安全的 `𝔸_adm` 内，故归纳不变量不被破坏。

**引理 62（包线覆盖与泛化间隙界）** 设 `Guard` 误入率 `γ_g = P(Guard=in | x∉Dom)`，漏检率 `β`。若激活契约都在 `Dom` 内且健康、域外映射 `c_fallback`，则 `P_unsafe(P_gen) ≤ γ_g + β`。`Cov` 的置信下界由加权共形给出；`Γ_gap = 1 − Cov` 上的安全性完全依赖 `c_fallback` 的构造安全性（继承 MODGAUGE 不变式）。*证明*：不安全事件只能发生在 (a) 域外被误判域内 `(≤γ_g)`，或 (b) 域内但漏检 `(≤β)`；两者并集界。

**引理 63（风险加权检测与端到端安全归结为漏检）** 由引理 60，若 `f*∈B` 则安全；故 `P_unsafe ≤ P(f*∉B) = P(MD)`。RW-Cal 按不可逆性分层校准给 `P(MD|irr) ≤ β_irr ≤ 1%`、`P(MD|rev) ≤ β_rev ≤ 5%`。因此**整个框架的安全性不依赖隔离精度，只依赖漏检界**；隔离歧义被 meet 免费吸收。*证明*：结合 60(iii) 与定义 456 的共形覆盖。

**引理 64（再资格单调性与无静默重信）** `Requal` 仅在证据超阈时上升（`c' ⊒ c_degraded`），故不存在无证据的重入；滞回带 `[τ_lo,τ_hi]` 使配置切换次数在证据间隔不小于 `h` 时被 `1/h` 界住，不产生无界振荡。*证明*：上升需谓词通过（定义 457），切换需穿越滞回带，两次反向切换至少间隔一个带宽的证据量。

**引理 65（诊断延迟与 50Hz 保全）** 诊断在异步事件上运行，`L_det ≤ W_max`；内联路径只做残差采样与格查表，新增周期 `< 0.2ms`，继承 ToolGauge 引理 50 与 InstructGauge 引理 58 的硬实时结论。*证明*：同引理 58 的摊销论证，诊断与采样解耦。

**引理 66（模型故障 vs. 硬件故障的被动不可分 / 主动可分）** 若两类故障在**当前（可能错误）模型**下对所有被动残差给出相同的推前分布（`f_model` 使模型高估刚度、`f_hw` 使传感器低估力，二者在 `r_pred` 上同分布），则任何被动检验都无法分离二者。存在**主动干预** `p`（施加已知载荷、观测与传感器偏置解耦的响应）使二者推前分布不同 ⇒ 可分。*证明*：不可分由 Neyman-Pearson 推前测度相同直接得；主动可分由构造一个与偏置正交的观测量得。**结论：通用操作中的模型故障诊断必须主动。**

**引理 67（跨本体残差归一的迁移界）** 若 `r̃ = r/ι_emb` 用本体不变量归一，则跨本体迁移的安全退化随不变量失配 `Δι` 线性增长：`ε_transfer ≤ ε_0 + c·Δι`；这给出 E466 的预注册退化界基础。*证明*：泰勒展开归一化残差在不变量失配下的一阶扰动。

**引理 68（端到端退化等价）** 若关闭诊断与包线（恒 `B=F`、`degrade(B)=c_full`、`Guard≡in`、`RQ≡通过`、`ADP` 不触发），则 `diaggauge_8c` 的控制流与 `instructgauge_7c` 逐指令相同（diff = 0）。这是**操作等价**（诊断是决策层，会改控制流），不同于 Round 3 `claims` 的纯投影等价。*证明*：逐分支代入关闭值，唯一差异路径均被常量短路。

## 8. 本轮最大风险

**一句话**：包线守护器本身也是学习组件，与被守护策略共享同一分布外盲区——当「沉默的模型性故障」既无残差可测、又恰被守卫判为「域内」时（`γ_g` 无法对未知-未知校准），诊断闭环失去杠杆，安全性只能退化为对「可注入故障」的校准假设；缓解只能依赖结构（模型轻量不变量残差提高 `S` 的覆盖、主动探针把不可分对变可分、meet 保证歧义不越权、`Dom` 收缩 + 安全回退缩小暴露面），并以 E459/E464/E469/E472 主动证伪。
