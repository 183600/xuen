# 第 56 轮（承接第 55 轮 v32 GroundEdge-GenSim+++；灵感循环第 7 轮；本轮灵感：「自适应控制」×「移动操作」）

> 第 55 轮把组合合法性前移到「ROS 接口可连 + 标定可观测」，但证书仍是**一次测得、静态持有**。本轮用 **自适应控制** 把证书变成需要在线维持的过程量，用 **移动操作** 把动作空间、观测空间与标定状态全部位姿条件化。核心矛盾：H24：静态证书隐含「动力学参数、标定、可观测性不随位姿变化」，而移动底座使 `θ`、`Σ_cal`、`α_S` 都成为位姿 `b` 的函数，证书在移动中会**静默过期**；H25：自适应能在线补偿，但其收敛依赖持续激励（PE），精细移动作业常处于**低激励准静态**，参数会在弱可辨识方向漂移，形成「看似自适应、实则失稳」的假鲁棒。

## 0. 直觉与动机

**灵感 1（移动操作 = 动作空间被位姿条件化）**
直觉：第 54 轮的 `α_S(a)` 默认机器人站在原地。移动操作中底座位姿 `b` 改变了可达性、可操作度、接触几何与标定残差，所以技能不是 `S`，而是**位姿族** `S(b)`。动作剖面应写成 `α_S(a|b)`，组合图 `G_S` 应扩张为**位姿分层图** `G_S(B)`：同一条动作兼容边只在其位姿切片内成立。底座不是「搬运工具的附件」，而是动作空间的一个**坐标**。

**灵感 2（自适应控制 = 证书从名词变成动词）**
直觉：第 55 轮的证书 `𝕁` 像一张体检报告，签发后就假定身体不变。自适应控制认为参数 `θ`（负载、摩擦、刚度、接触）会变，控制器必须在线更新 `θ̂`。因此证书不再是一次性谓词，而是一个**需要持续维持的不变式**：只在「自适应运行包络」`E_S` 内成立，出包络即失效。证书要记录的不只是 `ρ`，还有**参数估计 `θ̂`、协方差 `P_θ`、Lyapunov 裕度**与**再认证时刻**。

**灵感 3（持续激励 = 可辨识性的燃料，也是稀缺资源）**
直觉：自适应只能辨识被运动「激励」到的方向。若机械臂长时间做准静态精细对准，回归向量 `Φ` 近乎共线，激励矩阵 `M` 病态，参数在零空间里漂移。于是出现一个反直觉结论：**移动本身可能是证书的燃料**——底座的平移/旋转为惯性参数与标定外参提供激励；但同一运动又破坏精细作业。证书必须携带**方向性 PE 证书**，并要求「证书依赖的参数子空间」被充分激励，而不是只看总体激励。

**灵感 4（底座-机械臂耦合 = 未建模动态的主要入口）**
直觉：移动操作不是底座和机械臂各自控制后相加。底座加速度通过反作用力矩进入机械臂，机械臂运动又反作用于底座；接触力经底座柔顺性传导。第 55 轮的 `ρ^cal` 仍假设「扰动有界」，而移动操作把未建模动态 `Δ` 的界 `η` 本身变成位姿与加速度的函数。因此证书必须含**耦合证书** `K_ba`：明确 `b̈` 预算与任务空间扰动上界，并把底座轨迹纳入联合规划，而不是事后补偿。

**灵感 5（证书随位姿传输 → 移动-自适应联合证书）**
直觉：沿底座轨迹 `b(t)`，证书裕度会随运动与自适应误差**消耗**。把证书看作带「电量」的对象：每移动一米、每次大加速度、每一段低激励，都扣电量；电量耗尽就触发**再认证锚点**，而不是等失败。反过来，规划器可主动选择「信息丰富」的位姿/路径（提升 PE、可观测锥、标定条件数），形成 **自适应-验证-再认证-回退** 的四拍闭环。

## 1. 形式化定义（增量：定义 127–132）

**定义 127（位姿条件化全身动作剖面）**
底座位姿 `b ∈ B ⊆ SE(3)`，全身动作 `a = (a_base, a_arm) ∈ A`。技能 `S` 的位姿条件化剖面：
```
α_S : A × B → [0,1],   ∫_A α_S(a|b) da = vol(S,b)
```
**全身覆盖** `cover_whole(S, A_T, b_traj)=1` 当且仅当
```
∀t, a_t∈A_T:  α_S(a_t|b(t)) ≥ θ_cov  ∧  m_S(a_t|b(t)) > 0
```
其中 `m_S` 为第 55 轮可观测裕度，现已位姿条件化。第 54/55 轮的 `α_S(a)`、`m_S(a)` 是 `b=b_0` 的切片。

**定义 128（自适应技能模型）**
技能 `S = (π_S(θ), θ*∈Θ_S, M_ref, Adapt)`：
- 参考模型 `ẋ_m = A_m x_m + B_m r`，跟踪误差 `e = x − x_m`；
- 参数 `θ`（负载、摩擦、惯量、接触刚度）未知但有界；
- 自适应律带 σ-修正与投影：
```
θ̇̂ = Proj_{Θ_safe}( Γ Φ(x,r) e − σ Γ θ̂ )
```
- Lyapunov 函数 `V(e, θ̃) = eᵀP e + θ̃ᵀΓ⁻¹θ̃`，`θ̃ = θ̂ − θ*`。

**定义 129（激励证书与方向性 PE）**
在窗口 `T` 上，回归矩阵 `Φ` 的激励矩阵与 PE 水平：
```
M(t) = ∫_{t−T}^{t} Φ(τ)Φ(τ)ᵀ dτ,   μ_PE(t) = λ_min(M(t))
```
对证书实际依赖的参数子空间 `Q`（由 `∂ρ/∂θ` 与 `∂α/∂θ` 的非零行张成），**方向性激励**：
```
μ_PE^Q(t) = λ_min( Π_Q M(t) Π_Q ),   Π_Q 为到 Q 的正交投影
```
**激励证书** `X = (M, μ_PE, μ_PE^Q, Q, T, η)`，要求 `μ_PE^Q ≥ μ_min(η)`，`η` 为未建模动态上界。

**定义 130（自适应运行包络）**
```
E_S(ρ_min) = { (a,b) :  V̇(e,θ̃) ≤ −λV(e,θ̃) + c‖Δ‖²,
                        ‖θ̃‖ ≤ δ_θ,  θ̂∈Θ_safe,
                        μ_PE^Q ≥ μ_min(η) }
```
`E_S` 是自适应律**可证明有界**的动作-位姿集合；`E_S` 之外不签发自适应证书，只能回退到保守非自适应控制器。

**定义 131（移动操作耦合证书）**
底座-机械臂耦合算子 `C_ba(b) : (b̈, a_arm) → 任务空间扰动`，满足
```
e_task ≤ e_task^arm + ‖C_ba(b) b̈‖ + η_contact
```
耦合证书 `K_ba = (C_ba, L_C, η_ba, b̈_max)`，要求 `max_t ‖C_ba(b(t)) b̈(t)‖ ≤ η_ba` 且 `C_ba` 关于 `b` 的 Lipschitz 常数 ≤ `L_C`。

**定义 132（移动-自适应联合证书 MAC）**
```
𝔸 = ( 𝕁, E_S, X, K_ba, θ̂, P_θ, b_traj, m_𝔸, τ_renew, δ_adapt )
```
其中 `𝕁` 为第 55 轮三元证书，`P_θ` 为参数估计协方差，`m_𝔸(t)` 为**证书裕度**：
```
m_𝔸 = min_d (ρ^ad_d − ρ_min) + w_PE·(μ_PE^Q − μ_min)
      + w_θ·(δ_θ − ‖θ̃‖) + w_c·(η_ba − ‖C_ba b̈‖)
```
有效性：
```
dom_𝔸(T)=in  ⟺  dom_𝕁=in ∧ κ_stale≤1 ∧ consistent(C_cal)
                ∧ ∀t: (a_t,b(t))∈E_S ∧ μ_PE^Q(t)≥μ_min
                ∧ m_𝔸(t) ≥ 0
```
**证书传输不等式**：沿 `b_traj`，若 `‖ḃ‖,‖b̈‖` 有界，则
```
m_𝔸(t+Δt) ≥ m_𝔸(t) − L_𝔸 ∫_t^{t+Δt}(‖ḃ‖+‖b̈‖)dτ − c_a∫‖Δ‖dτ
```
`m_𝔸≤0` 时触发 `re-certify`（锚点再认证）或 `fallback`（保守控制器）。

## 2. 关键算法 伪代码

### IP-127 PAP（Pose-conditioned Action Profile）

```python
def pose_conditioned_profile(skill, B_grid, A_grid, sampler):
    alpha = {}
    for b in B_grid:
        for a in A_grid:
            feas, conf = sampler.query(skill, a, b)
            alpha[(a, b)] = conf if feas else 0.0
    L_alpha = estimate_lipschitz(alpha, B_grid)   # 位姿方向局部敏感度
    return PoseProfile(alpha, L_alpha, B_grid, A_grid)

def cover_whole(profile, A_T, b_traj, theta_cov=0.8):
    for t, b in enumerate(b_traj):
        for a in A_T[t]:
            if profile.interp(a, b) < theta_cov:       return False
            if observability_margin(a, b) <= 0:          return False
    return True
```

### IP-128 ADE（Adaptive Envelope Estimation）

```python
def estimate_envelope(skill, b_grid, a_grid, eta, delta_theta):
    E = set()
    for b in b_grid:
        for a in a_grid:
            Vdot = lie_derivative(skill.V, skill.adapt_law, a, b)
            if (Vdot <= -skill.lam * skill.V + skill.c * eta**2
                and skill.theta_bound <= delta_theta
                and skill.mu_pe_Q(a, b) >= mu_min(eta)):
                E.add((a, b))
    return AdaptiveEnvelope(E, lam=skill.lam, delta_theta=delta_theta)
```

### IP-129 EXC（Excitation Certificate）

```python
def excitation_certificate(phi_hist, Q, T, eta):
    M    = integral_outer(phi_hist, window=T)
    mu   = lambda_min(M)
    mu_Q = lambda_min(project(M, Q))
    ok   = mu_Q >= mu_min(eta)
    return ok, ExcitationCert(M, mu, mu_Q, Q, T, eta)
```

### IP-130 APT（Adaptive Parameter Tracking）

```python
def adaptive_track(theta_hat, e, phi, Gamma, sigma, Theta_safe, exc, dt):
    if exc.mu_Q < exc.mu_min:
        return theta_hat, 'frozen_low_excitation'      # 低激励冻结，禁止漂移
    dtheta = Gamma @ phi * e - sigma * Gamma @ theta_hat
    theta_new = project(theta_hat + dt * dtheta, Theta_safe)
    if norm(theta_new - theta_hat) > drift_budget:
        return theta_hat, 'drift_guard'                # 漂移熔断
    return theta_new, 'ok'
```

### IP-131 MBC（Mobile-Base Coupling Certificate）

```python
def coupling_certificate(C_ba, b_traj, bddot_max, eta_ba, L_C):
    worst = 0.0
    for b, bddot in zip(b_traj.pos, b_traj.acc):
        worst = max(worst, norm(C_ba(b) @ bddot))
    if worst > eta_ba:                 return ('reject', 'base_disturbance_budget', worst)
    if lipschitz(C_ba, b_traj) > L_C:  return ('reject', 'coupling_nonstationary')
    return ('ok', CouplingCert(C_ba, worst, eta_ba))
```

### IP-132 MAC（Mobility-Aware Adaptive Certificate）

```python
def mac_certificate(J, skill_seq, b_traj, A_T, budgets):
    if domain_check(J, A_T) != 'in':                    return ('reject', 'static_domain')
    E = estimate_envelope_chain(skill_seq, b_traj, budgets.eta)
    if not cover_whole_chain(skill_seq, A_T, b_traj):   return ('reject', 'pose_coverage')
    if not all((a, b) in E for a, b in trace(A_T, b_traj)):
        return ('reject', 'envelope_escape')

    X = excitation_certificate(phi_hist(skill_seq, b_traj),
                               Q=budgets.Q, T=budgets.T, eta=budgets.eta)
    if not X.ok: return ('reject', 'insufficient_excitation', X)

    ok, K = coupling_certificate(budgets.C_ba, b_traj,
                                 budgets.bddot_max, budgets.eta_ba, budgets.L_C)
    if not ok: return ('reject', K[1], K[2])

    m = certificate_margin(J, E, X, K, budgets)
    for t in transport_steps(b_traj):
        m -= L_A * (norm(b_traj.vel[t]) + norm(b_traj.acc[t])) * dt
        if m <= 0:
            return ('renew', 'certificate_transport_budget', t)  # 锚点再认证
    return ('ok', MAC(J, E, X, K, m, tau_renew=budgets.tau_renew))
```

### 主动激励规划（MAC 内部子程序 AEP）

```python
def active_excitation_plan(task, B, budget):
    # 在任务/安全约束下最大化「证书资源」：PE + 可观测锥 + 标定条件数
    return argmax_{b_traj in feasible(B, task)} min(
        mu_PE_Q(b_traj),
        min_t observability_margin(a_t, b_t),
        1 / cond(Sigma_cal(b_traj)) - tau_fresh_margin(b_traj)
    ) - cost(b_traj)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| PAP | O(\|B\|·\|A\|·q) | O(\|B\|·\|A\|) | 位姿采样覆盖、Lipschitz 估计 |
| ADE | O(\|B\|·\|A\|·\|θ\|²) | O(\|B\|·\|A\|) | V̇ 上界、η 有界 |
| EXC | O(T·\|Φ\|²) | O(\|Φ\|²) | 方向性子空间 Q 正确、μ_min(η) 保守 |
| APT | O(\|θ\|²) / step | O(\|θ\|²) | σ-修正 + 投影 + 漂移熔断 |
| MBC | O(\|b_traj\|·\|C_ba\|) | O(\|C_ba\|) | C_ba Lipschitz、b̈ 预算 |
| MAC | O(\|B\|·\|A\|·\|θ\|² + \|b_traj\|·\|Φ\|²) | O(\|B\|·\|A\|+\|Φ\|²) | 包络、PE、传输不等式同时成立 |

**正确性定理（Adaptive Whole-Body Certificate Soundness）**
假设第 54/55 轮 (A26)–(A31) 成立；新增：
**(A32)** 自适应律 `θ̇̂ = Proj(ΓΦe − σΓθ̂)` 在 `Θ_safe` 内有界，且存在 `λ>0, c>0` 使 `V̇ ≤ −λV + c‖Δ‖²`；
**(A33)** 未建模动态 `‖Δ‖ ≤ η`，且 `μ_PE^Q ≥ μ_min(η)` 足以保证参数误差最终有界（标准鲁棒自适应条件）；
**(A34)** 耦合算子 `C_ba(b)` 在有界位姿域上 Lipschitz 且已标定，`‖C_ba b̈‖ ≤ η_ba`；
**(A35)** 证书传输损耗满足 `dm_𝔸/dt ≥ −L_𝔸(‖ḃ‖+‖b̈‖) − c_a‖Δ‖`。
则沿 `b_traj` 的部署成功概率：
```
P_success ≥ 1 − Σ_d(1−ρ^ad_min(d)) − β_E − P(δ_a>Θ_a) − P(compat<θ_a)
              − P(interface_mismatch) − P(κ_stale>1) − P(ε_cal>Θ_cal)
              − P(μ_PE^Q<μ_min) − P(‖θ̃‖>δ_θ) − P(m_𝔸(t)≤0)
```
关键：**静态证书只是初值，动态证书靠 PE 供能、靠包络约束、靠传输预算续命**。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 准静态精细作业低激励 → 假自适应 | 高 | 方向性 PE 监控 + 主动激励 + 低激励冻结/回退 |
| 底座柔顺、负载、接触未建模动态 | 高 | σ-修正 + 投影 + dead-zone + 在线 η 上界估计 |
| 自适应与重标定互相污染 | 高 | 时间尺度分离 + 重标定期间冻结自适应 + 双估计器 |
| 长轨迹证书传输裕度耗尽 | 中 | 传输预算 + 再认证锚点 + 分段规划 |
| 位姿网格/组合图爆炸 | 中 | 可达性剪枝 + GP 插值 + 动作哈希 |

## 6. 本轮最大风险

**一句话**：本轮把静态证书升级为「靠 PE 供能、靠包络约束、靠传输预算续命」的移动-自适应联合证书，但整套 soundness 建立在**低激励方向上参数不漂移**这一与移动操作现实直接冲突的假设上；一旦准静态精细作业让 `μ_PE^Q` 悄悄跌破阈值，同时底座柔顺与接触未建模动态把 `η` 推高，证书会在 `m_𝔸>0` 的名义有效状态下系统性失稳，形成**激励-稳定性幻觉**；故必须把方向性 PE 当作一等运行时资源、以传输预算硬门控再认证、并在低激励时无条件回退保守控制器，宁可牺牲自适应性能，也不把「参数看似有界」当作「系统真正稳定」。

# 第 56 轮产物 · 创新点清单 v33：GroundEdge-GenSim++++（PAP×ADE×EXC×APT×MBC×MAC）

> 承接第 55 轮产物 v32。本轮在 ROS 接口契约 + 标定可观测性之上，增加 **位姿条件化动作空间、自适应运行包络、方向性持续激励、移动底座耦合、移动-自适应联合证书** 五类算子：
> - **PAP（Pose-conditioned Action Profile）**：把 `α_S(a)` 升级为 `α_S(a|b)`，动作空间随底座位姿条件化；
> - **ADE（Adaptive Envelope Estimation）**：用 Lyapunov 条件估计自适应可证明有界的运行包络 `E_S`；
> - **EXC（Excitation Certificate）**：方向性持续激励证书 `μ_PE^Q`，判定证书依赖的参数子空间是否可辨识；
> - **APT（Adaptive Parameter Tracking）**：σ-修正 + 投影 + 低激励冻结 + 漂移熔断的在线参数更新；
> - **MBC（Mobile-Base Coupling Certificate）**：底座-机械臂耦合算子 `C_ba` 与加速度预算 `η_ba`；
> - **MAC（Mobility-Aware Adaptive Certificate）**：在 `𝕁` 之上叠加自适应包络、PE、耦合与传输裕度的联合证书 `𝔸`。
>
> IP 编号：IP-127~IP-132（共 6 个新增），升级 IP-115/117/118/122/126 以纳入位姿与自适应维度。

## 2. 关键算法 伪代码

### IP-127 PAP

```python
def pose_conditioned_profile(skill, B_grid, A_grid, sampler):
    alpha = {}
    for b in B_grid:
        for a in A_grid:
            feas, conf = sampler.query(skill, a, b)
            alpha[(a, b)] = conf if feas else 0.0
    return PoseProfile(alpha, estimate_lipschitz(alpha, B_grid), B_grid, A_grid)

def cover_whole(profile, A_T, b_traj, theta_cov=0.8):
    return all(profile.interp(a, b) >= theta_cov
               and observability_margin(a, b) > 0
               for t, b in enumerate(b_traj) for a in A_T[t])
```

### IP-128 ADE

```python
def estimate_envelope(skill, b_grid, a_grid, eta, delta_theta):
    E = set()
    for b in b_grid:
        for a in a_grid:
            Vdot = lie_derivative(skill.V, skill.adapt_law, a, b)
            if (Vdot <= -skill.lam * skill.V + skill.c * eta**2
                and skill.theta_bound <= delta_theta
                and skill.mu_pe_Q(a, b) >= mu_min(eta)):
                E.add((a, b))
    return AdaptiveEnvelope(E, lam=skill.lam, delta_theta=delta_theta)
```

### IP-129 EXC

```python
def excitation_certificate(phi_hist, Q, T, eta):
    M    = integral_outer(phi_hist, window=T)
    mu_Q = lambda_min(project(M, Q))
    return (mu_Q >= mu_min(eta),
            ExcitationCert(M, lambda_min(M), mu_Q, Q, T, eta))
```

### IP-130 APT

```python
def adaptive_track(theta_hat, e, phi, Gamma, sigma, Theta_safe, exc, dt):
    if exc.mu_Q < exc.mu_min:
        return theta_hat, 'frozen_low_excitation'
    dtheta = Gamma @ phi * e - sigma * Gamma @ theta_hat
    theta_new = project(theta_hat + dt * dtheta, Theta_safe)
    if norm(theta_new - theta_hat) > drift_budget:
        return theta_hat, 'drift_guard'
    return theta_new, 'ok'
```

### IP-131 MBC

```python
def coupling_certificate(C_ba, b_traj, bddot_max, eta_ba, L_C):
    worst = max(norm(C_ba(b) @ bddot)
                for b, bddot in zip(b_traj.pos, b_traj.acc))
    if worst > eta_ba:                return ('reject', 'base_disturbance_budget', worst)
    if lipschitz(C_ba, b_traj) > L_C: return ('reject', 'coupling_nonstationary')
    return ('ok', CouplingCert(C_ba, worst, eta_ba))
```

### IP-132 MAC

```python
def mac_certificate(J, skill_seq, b_traj, A_T, budgets):
    if domain_check(J, A_T) != 'in':                   return ('reject', 'static_domain')
    E = estimate_envelope_chain(skill_seq, b_traj, budgets.eta)
    if not cover_whole_chain(skill_seq, A_T, b_traj):  return ('reject', 'pose_coverage')
    if not all((a, b) in E for a, b in trace(A_T, b_traj)):
        return ('reject', 'envelope_escape')

    X = excitation_certificate(phi_hist(skill_seq, b_traj),
                               Q=budgets.Q, T=budgets.T, eta=budgets.eta)
    if not X.ok: return ('reject', 'insufficient_excitation', X)

    ok, K = coupling_certificate(budgets.C_ba, b_traj,
                                 budgets.bddot_max, budgets.eta_ba, budgets.L_C)
    if not ok: return ('reject', K[1], K[2])

    m = (min_d(J.rho[d] - budgets.rho_min)
         + budgets.w_PE * (X.mu_Q - budgets.mu_min)
         + budgets.w_theta * (budgets.delta_theta - norm(J.theta_tilde))
         + budgets.w_c * (budgets.eta_ba - K.worst))
    for t in transport_steps(b_traj):
        m -= budgets.L_A * (norm(b_traj.vel[t]) + norm(b_traj.acc[t])) * dt
        if m <= 0:
            return ('renew', 'certificate_transport_budget', t)
    return ('ok', MAC(J, E, X, K, m, tau_renew=budgets.tau_renew))
```

## 3. 关键推导：证书传输裕度

`m_𝔸` 由四项构成：鲁棒性裕度、激励裕度、参数误差裕度、耦合裕度。沿 `b_traj` 每一项的时间导数有界：

```
d/dt min_d(ρ^ad_d - ρ_min)   ≥ -L_ρ (‖ḃ‖ + ‖Δ‖)
d/dt (μ_PE^Q - μ_min)        ≥ -L_PE (‖ḃ‖ + ‖b̈‖ + ‖Δ‖)
d/dt (δ_θ - ‖θ̃‖)            ≥ -L_θ (‖Δ‖ + σ‖θ̂‖)
d/dt (η_ba - ‖C_ba b̈‖)      ≥ -L_C ‖ḃ‖ - L_ba ‖b̈‖
```

取 `L_𝔸 = max(L_ρ, L_PE, L_θ, L_C, L_ba)`、`c_a = max(L_ρ, L_PE, L_θ)`，合并即得

```
m_𝔸(t+Δt) ≥ m_𝔸(t) − L_𝔸 ∫_t^{t+Δt}(‖ḃ‖+‖b̈‖)dτ − c_a∫_t^{t+Δt}‖Δ‖dτ
```

因此 `τ_renew` 可由 `m_𝔸(0) / (L_𝔸·v_max)` 预估：**证书寿命与底座运动速度成反比**。这给出可执行的再认证调度，而不是拍脑袋的固定周期。

## 4. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| PAP | O(\|B\|·\|A\|·q) | O(\|B\|·\|A\|) | 位姿采样覆盖、Lipschitz 估计 |
| ADE | O(\|B\|·\|A\|·\|θ\|²) | O(\|B\|·\|A\|) | `V̇` 上界、`η` 有界 |
| EXC | O(T·\|Φ\|²) | O(\|Φ\|²) | `Q` 正确、`μ_min(η)` 保守 |
| APT | O(\|θ\|²)/step | O(\|θ\|²) | σ-修正 + 投影 + 漂移熔断 |
| MBC | O(\|b_traj\|·\|C_ba\|) | O(\|C_ba\|) | `C_ba` Lipschitz、`b̈` 预算 |
| MAC | O(\|B\|·\|A\|·\|θ\|² + \|b_traj\|·\|Φ\|²) | O(\|B\|·\|A\|+\|Φ\|²) | 包络、PE、传输不等式同时成立 |

**正确性定理（Adaptive Whole-Body Certificate Soundness）**
假设第 54/55 轮 (A26)–(A31) 成立；**(A32)** 自适应律在 `Θ_safe` 内有界且 `V̇ ≤ −λV + c‖Δ‖²`；**(A33)** `‖Δ‖ ≤ η` 且 `μ_PE^Q ≥ μ_min(η)` 保证参数误差最终有界；**(A34)** `C_ba(b)` Lipschitz 且已标定、`‖C_ba b̈‖ ≤ η_ba`；**(A35)** 传输损耗满足上文不等式。则：
```
P_success ≥ 1 − Σ_d(1−ρ^ad_min(d)) − β_E − P(δ_a>Θ_a) − P(compat<θ_a)
              − P(interface_mismatch) − P(κ_stale>1) − P(ε_cal>Θ_cal)
              − P(μ_PE^Q<μ_min) − P(‖θ̃‖>δ_θ) − P(m_𝔸(t)≤0)
```
关键：**静态证书只是初值；动态证书靠 PE 供能、靠包络约束、靠传输预算续命**；任一供能/约束/预算失效，`𝔸` 必须 `renew` 或 `fallback`，不许降级持有。

## 7. 本轮最大风险

**一句话**：本轮把静态证书升级为「靠 PE 供能、靠包络约束、靠传输预算续命」的移动-自适应联合证书，但整套 soundness 建立在**低激励方向上参数不漂移**这一与移动操作现实直接冲突的假设上；一旦准静态精细作业让 `μ_PE^Q` 悄悄跌破阈值，同时底座柔顺与接触未建模动态把 `η` 推高，证书会在 `m_𝔸>0` 的名义有效状态下系统性失稳，形成**激励-稳定性幻觉**；故必须把方向性 PE 当作一等运行时资源、以传输预算硬门控再认证、并在低激励时无条件回退保守控制器，宁可牺牲自适应性能，也不把「参数看似有界」当作「系统真正稳定」。
