# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「轻量化设计」×「模型量化」）

> R69 给闭环装上了眼睛和嘴：看不清就看、拿不准就问、质感不明就触；并把不确定性一分为二，用流匹配策略显式表示多模态，用 VoI 决定值不值得求证。但 R69 的全部论证都默认一件事：**这些精确、校准、可微的概率量，是在一个全精度推理栈上算出来的**——流似然 a_score、模态权重 ŵ_k、模态内协方差 Σ_k、VoI、ECE、CBF 裕度。一旦走出实验室，机器人要在嵌入式 NPU 上跑，这些量就必须由**量化后的**算子来算。
>
> 量化不是「把模型压小」这么简单。它是一个**有偏、输入相关、非零均值、会移动决策边界**的算子：它可以把两个真模态合并（Δ_min 缩小）、把一个模态劈成两个幻影（Δ_min 虚大）、把流似然抬高或压低（FMA 第二意见失真）、把 ECE 从 0.02 推到 0.1（MCG 门控失效）。更糟的是，这些失真**看起来和真实世界的不确定性一模一样**：量化噪声会被当成 aleatoric、量化劈裂会被当成 epistemic、量化偏置会被当成缓变故障。R69 用来「诚实地说不知道」的那套仪器，在低比特下可能开始**自信地说错**。
>
> 两个灵感正好从两个方向切进来：
> - **模型量化**告诉我们：精度的代价不是均匀的，而是**按功能、按输入、按决策边界**分布的；有些比特是「性能比特」，有些比特是「安全比特」。
> - **轻量化设计**告诉我们：轻量化从来不是「免费省资源」，而是**一次记账迁移**——机械上省下的质量会变成刚度/控制带宽的债，模型上省下的比特会变成统计裕度/证书有效性的债；债不会消失，只会转移到你没在测量的那个通道。
>
> 核心命题：**不要「先量化、再祈祷证书还成立」；要把证书本身当作轻量化的对象。用证书敏感度决定比特预算，用共形包络把量化误差写进证书，用「主动计算」把加比特与问人统一进同一个 VoI 账本，用多精度一致性把量化从纯成本变成探针；一旦预算内无法认证，就沿退化阶梯只增不减地退回 R69/R68，绝不允许带着一张失效证书运行。** 命名 **LITE-RAS**（Lightweight Invariant-preserving Trustworthy Embedded Risk-Adaptive System）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**为了跑得动，我愿意少看几位？少看的这几位，谁来担保没动我的安全边界？**」

## 0. 直觉与动机

**灵感 1（轻量化是记账，不是删除）**
直觉：机械工程师做轻量化时不会说「我删掉了一块材料，所以更轻了」；他会问「刚度掉了多少、模态频率移到哪、控制带宽还够不够」。省下的质量一定以别处的性能/安全为代价，必须显式记账。模型量化完全同构：省下的比特一定以数值误差为代价，而误差会流向四本账——(a) 任务性能（可接受），(b) 标定/校准（ECE 漂移），(c) 不确定性分解（U_ale/U_epi 失真），(d) **证书**（J_FLUID 的置信）。前三本账 R69 都隐约管了，第四本没人管。LITE-RAS 的第一性姿态：**把「量化误差记到哪本账、由谁担保」写成显式结构，而不是留给部署工程师的良心。**

**灵感 2（量化误差是有条件、有形状的）**
直觉：最常见的错误是「量化误差 ≈ 零均值高斯，加个方差就行」。真实的量化误差是 `δ(x) = round(x/s)·s − x`：它**依赖输入落在哪个舍入区间**，在 cell 边界附近最大、在中心最小，且跨层会累积、会相关。用全局标量 ε 去界定它，必然在边界处低估、在中心处高估。正确做法是**条件包络** ε_f(x)：确定性的仿射/区间传播给下界，共形预测给分布无关的统计上界。这样「安全比特」才有可计算的定义——不是「这一层看起来重要」，而是「这一层的误差经过证书敏感度放大后，会不会顶破某个 τ_J」。

**灵感 3（比特和信息是同一种货币）**
直觉：R69 的 MINT 已经在做「花一次交互去买信息」的决策。但系统还有另一条买信息的通道：**多花几个比特、多跑一次高精度回放**。这两件事在决策论上是同一件事——都是「付出成本，降低与决策相关的不确定性」。既然同一种货币，就该进同一个账本：
`argmax_{g,β} [VoI_world(g) + VoI_model(β) − c_human(g) − c_comp(β)]`。
人不可信（δ_p 高）时，买比特更划算；算力饱和时，问人更划算。把「向世界求证」与「向机器要精度」统一，是本轮最优雅的一步：**量化预算不再是离线超参，而是在线决策变量。**

**灵感 4（把量化当探针，正面回应 R69 的最大风险）**
直觉：R69 自陈最大风险是「流模型的模态分布不可信——幻影模态/模态坍缩」。量化恰好提供了一个**可控扰动源**：真模态应当在精度变化下保持存在（多精度持续性强），幻影模态则随比特数出现/消失（持续性弱），只在低精度出现的「模态」几乎肯定是量化伪影。于是同一个量化器，既是成本，也是**免费的压力测试仪**：不需要额外数据，只需在精度阶梯上比对模态结构。这把 R69 的致命弱点变成 R70 的一个可测量指标。

**灵感 5（低比特制造新的攻击面与退化路径）**
直觉：一旦比特成为决策变量，对手就有了新杠杆：把输入推到舍入边界，让低精度与高精度给出不同动作（precision-gap attack）；污染 scale/zero-point 校准表；回放旧包络（stale-envelope replay）；甚至在运行时把系统「劝降」到最低精度档。更隐蔽的是**证书剧场**：只要包络是在一个不覆盖部署的标定集上估的，它就会在纸上永远有效。因此 LITE-RAS 必须同时交付：量化威胁模型、精度间隙统计、精度库的无扰切换，以及「认证不通过就只能更保守」的单调退化阶梯。

## 1. 形式化定义（增量：定义 310–323）

**定义 310（LITE-RAS 总览）** LITE-RAS = (QEM, CAS, PAB, ACX, QFMA, CQB, PB, RAS-WM§)。四条不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i；量化只允许离线编译与离散选档，运行时不重量化、不更新 scale/zero-point）；
(ii) **先认证后执行**：任何量化配置 Q 在派发前必须有有效的 J_LITE；精度切换只能在预编译精度库内、且满足无扰条件；
(iii) **非对称精度地板**：安全通道函数集 J_safe = {a_score, h_CBF, ECE, λ_floor} 有独立于任务通道的比特地板 b_safe；任务通道可在其约束内自由压缩；
(iv) **严格包含**：比特预算 B→∞ 时 LITE-RAS 与 FLUID-RAS 逐指令相同；认证失败时沿退化阶梯单调退回 R68——安全侧永不变弱。

**定义 311（量化算子与条件误差包络 QEM）** 模块 f 的量化版本 f_Q = f + δ_f，其中 δ_f(x) = δ_f^round(x) + δ_f^acc(x)（舍入误差 + 跨层累积）。条件误差包络
ε_f(x) = ε_f^det(x) + ε_f^conf(x)，
ε_f^det 由仿射/区间算术给出确定界，ε_f^conf 由 split-conformal 在留出标定集上给出分布无关界（覆盖率 ≥ 1−α）。**包络条件于 x 而非全局常数**；在舍入 cell 边界附近 ε_f(x) 显著变大，这正是 precision-gap 攻击可利用之处。

**定义 312（证书敏感度与比特必要性 CAS）** 对安全相关泛函 J ∈ J_safe ∪ {U_ale, U_epi, VoI}，定义模块 i 的证书敏感度
S_i(J) = sup_{x∈𝒳_calib} |∂J/∂ε_i|（或经认证的有限差分上界）。
给定容差 τ_J，模块 i 对 J 的必要比特数为
b_i^min(J) = min{ b : S_i(J)·ε_i(b) ≤ τ_J }。
于是「安全比特」第一次有了可计算定义：不是重要性启发式，而是**证书容差的预算约束**。

**定义 313（量化不确定性二分）** U_q = U_q^irr(b) + U_q^red(b→b+Δb)。U_q^irr 是当前硬件配置下不可再降的舍入地板，按 aleatoric 处理并进入 λ_floor；U_q^red 是可通过追加比特消解的「模型 epistemic」——它与 R69 的「世界 epistemic」不同：**问世界消不掉它，只能向机器买比特**。二者同形不同源，必须分账。

**定义 314（主动计算 ACX 与联合 VoI）** 在 R69 的信息动作 g 之外，加入计算信息动作 β ∈ ℬ（向模块子集追加比特 / 触发高精度回放），成本 c_comp(β)（延迟 + 能耗）。联合选择
(g*, β*) = argmax_{g,β} [ VoI_world(g) + VoI_model(β) − c_human(g) − c_comp(β) ]，
s.t. risk(g) ≤ ε_int、总预算未超、精度切换在库内。
**问人与问比特是同一账本下的两种仪器**；当人类回答欺骗率高（δ_p↑）或社交成本高时 β 占优，当算力饱和/能耗受限时 g 占优（相变阈值见定理 19）。

**定义 315（保护精度流似然 QFMA 与精度间隙）** 设 a_Q(o) = −log p_{θ_Q}(ξ_obs|o)。定义精度间隙
G_q(o) = |a_{Q_safe}(o) − a_{Q_task}(o)|，
以及保护精度下的偏置包络 ε_a(Q_safe)。缓变故障判定改为**保守下界**：
detect ⇔ (a_{Q_safe} − ε_a > τ_FMA) ∧ (r_res < τ_res) ∧ (G_q ≤ τ_gap)。
若 G_q > τ_gap：量化似然不可信，**禁止使用 FMA**，直接退 R69 保守。这样量化既不能伪装成缓变故障（假阳），也不能掩盖小于 2ε_a 的真故障（假阴，见引理 21）。

**定义 316（量化鲁棒模态可分性 QMS）** 量化后原型 ξ̄_k^Q、模态内协方差 Σ_k^Q。称模态**认证可分** ⇔
Δ_min^Q ≥ 3 σ_in^Q + 2 ε_mode(Q)。
不满足时，该歧义是「精度诱发」的：对它计算 VoI 无效（R69 引理 16 的 A95 已破），必须选择「花比特 β」或「当作 aleatoric 保守」，**不得对量化劈裂出的幻影发起交互**。

**定义 317（多精度模态持续性 MPP）** 在精度阶梯 Q_0≻…≻Q_m 上，用 Fréchet 距离 ≤ τ_match 跨配置匹配模态。模态 k 的持续性
p_k = (#{Q_j : 存在匹配模态}) / (m+1)。
只有 p_k ≥ p_min 的模态才进入 VoI 决策。**真模态在精度扰动下稳定，幻影模态不稳定**：只在低精度出现的模态判为量化伪影；只在高精度出现的模态判为「脆弱真模态」，应优先花比特。这是对 R69 最大风险的直接仪器化。

**定义 318（共形量化证书 CQB）** 对泛函 J 与配置 Q，用 split / 加权 conformal 在留出集上得包络
𝒞_α(J,Q) = [ Ĵ_Q − q_{1−α}, Ĵ_Q + q_{1−α} ]。
证书对该泛函有效 ⇔ 𝒞_α ⊆ 允许集且 J_float ∈ 𝒞_α。覆盖率分布无关（≥1−α），不假设高斯量化噪声；协变量漂移下用加权共形并显式记录权重有效范围。

**定义 319（精度库与无扰切换 PB）** 预编译精度库 {Q_0（最保守/最高精度）, …, Q_m（最快/最低精度）}，每档预先持有证书。运行时只做离散选档，不重量化、不学习。切换需满足：滞回（防抖）、状态携带、以及无扰条件
‖y_{Q_new}(x_probe) − y_{Q_old}(x_probe)‖ ≤ δ_switch。
继承 R68/R69 的换装不变式，保证控制连续、无突变。

**定义 320（轻量证书调度 LCS）** 令 m(s) 为决策裕度（到安全/决策边界的距离），d_Q(x) 为到量化 cell 边界的距离。昂贵认证（完整 Hutchinson 回放、包络刷新）仅在
m(s) ≤ m_0 ∨ d_Q(x) ≤ d_0 ∨ OOD(x)
时触发；否则使用缓存代理证书，并按认证裕度保守膨胀。期望成本 = C_full·P(trigger) + C_surr；在裕度密度有界时呈次线性（引理 22）。**这让「证书本身」也变轻，而不是只有模型变轻。**

**定义 321（量化威胁模型 AIC-LITE）** ℰ_quant = { precision-gap 攻击（把输入推到舍入边界使高低精度动作分歧）、scale/zero-point 校准表投毒、部署权重比特翻转、过期包络回放、把系统「劝降」到最低精度档 }。
ℰ_LITE = ℰ_FLUID × ℰ_quant。审计必须记录 (配置、包络版本、触发原因、精度间隙)。

**定义 322（证书 J_LITE）**
J_LITE = (J_FLUID@b_safe, Q_hash, {b_i}, {ε_i}, conformal_coverage, precision_gap_p95, bit_budget_used, switch_log_hash, lite_ver)。
Valid ⇔ Valid(J_FLUID 在保护精度下) ∧ 所有安全泛函的共形包络落在允许集 ∧ 可分性与持续性满足 ∧ 预算未越界 ∧ 无边界攻击标记。

**定义 323（轻量目标与退化阶梯 LDL）** 轻量化目标不是 min size，而是
min_Q [ latency(Q) + η_E·energy(Q) + η_M·memory(Q) ]，
s.t. 证书有效且留有余量（所有 𝒞_α 宽度 ≤ τ_J、覆盖率 ≥ 1−α、可分/持续、P99 延迟 ≤ L_max）。
认证失败时沿阶梯**只增不减**地退化：Q_m（快档）→ 追加比特 Q_{m−1} → 只保护安全通道（任务通道降到最低）→ R68 保守（λ_floor 计入 U_q）→ 安全停机。每一级 λ 单调不降、包络单调不缩、无突变；**绝不允许未认证执行**。

# IP-264/265/266：离线构建——条件包络、证书敏感度、比特分配、精度库
def build_lite_stack(float_model, calib_loader, budget, taus):
    env = {m: conditional_error_envelope(m, calib_loader)  # ε_f(x) = det + conformal
           for m in float_model.modules}
    S   = certificate_sensitivity(float_model, calib_loader)  # J x module -> slope
    b   = allocate_bits(S, env, budget, taus)                 # 证书约束下的背包
    bank = compile_precision_bank(float_model, b)             # Q_0..Q_m，逐档预认证
    return bank, S, env

def allocate_bits(S, env, budget, taus):
    # min Σ cost_i(b_i)   s.t. ∀J: Σ_i S_i(J)·ε_i(b_i) ≤ τ_J
    # 比特网格上的多约束背包：拉格朗日对偶 + 贪心取整，离线一次
    return solve_multi_constraint_knapsack(S, env, budget, taus)

# IP-268/315：保护精度第二意见（安全通道单独用 b_safe）
def qfma(policy, xi, o, cfg_safe, cfg_task):
    a_safe = -policy.loglik(xi, o, cfg_safe)          # 安全比特
    a_task = -policy.loglik(xi, o, cfg_task)          # 任务比特
    gap    = abs(a_safe - a_task)
    eps_a  = policy.error_envelope(cfg_safe, 'a_score')
    return a_safe, eps_a, gap

# IP-269/317：量化下的模态有效性（可分 + 多精度持续）
def validate_modes(modes_by_cfg, cfg, eps_mode):
    M = modes_by_cfg[cfg]
    if delta_min(M) < 3 * sigma_in(M) + 2 * eps_mode:
        return None                                   # 精度诱发歧义，VoI 无效
    return [k for k in M if persistence(k, modes_by_cfg) >= P_MIN]

# IP-276：主闭环（继承 R69，只在不确定性处置与认证处插入 LITE 层）
def LITE_RAS_round(M, obs):
    cfg = M.bank.current()                            # 当前已认证档
    z, o = M.trunk_q(obs, cfg)
    K = 1 if M.mode_head_q(z, cfg) < TAU_MODE else 4
    modes = M.fmp_q.sample_and_cluster(o, K, cfg)
    # 1) 模态有效性：可分性 + 多精度持续性
    valid = M.qms.validate(modes, M.bank.ladder, cfg)
    if valid is None:                                 # 花比特或退化
        beta = M.acx.bits_for_separability(modes, cfg)
        if beta is None: return M.ldl.fallback(M, cfg, reason='mode')
        cfg = M.bank.switch(beta)
    # 2) 保护精度第二意见（量化不可吸收 / 不可伪装）
    a_safe, eps_a, gap = M.qfma(M.fmp_q, M.last_action, o, M.bank.safe, cfg)
    slow = (a_safe - eps_a > TAU_FMA) and (M.last_r_res < TAU_RES) and (gap <= TAU_GAP)
    # 3) 联合 VoI：问人 vs 问比特（同一账本）
    g, beta = M.acx.choose_joint(valid, o, M.budget, cfg)
    if beta is not None:
        cfg = M.bank.switch(beta)                     # 无扰切换 + 重新认证
        modes = M.fmp_q.resample(o, cfg)
        U_epi_after = M.aud.epistemic(modes)
    elif g is not None:
        U_epi_after = M.cia.update_belief(modes, M.cia.execute(g))
    else:
        U_epi_after = M.aud.epistemic(modes)
    # 4) 先认证后执行
    J = M.cqb.build(M, cfg, modes, a_safe, gap)
    if not M.cqb.valid(J):
        return M.ldl.degrade(M, cfg, J)               # 只增不减地退
    # 5) 风险缩放：aleatoric + 未消解 epistemic + 不可约量化地板
    U_floor = M.aud.aleatoric(modes) + U_epi_after + M.qem.irreducible(cfg)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., M.wm_preds)
    mode = select_mode(modes, U_epi_after, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    # 6) 审计（记录配置/包络版本/触发原因/精度间隙）
    M.vqa_i.submit_async(g, beta, gap, U_epi_after, J)
    return k, lam, mode, (U_floor, U_epi_after, cfg)

## 3. 推导

**引理 19（证书误差传播与安全比特）** 设安全泛函 J = F(y_1,…,y_M)，量化使各中间量产生 |δ_i| ≤ ε_i。若 F 对各参数 L_i-Lipschitz，则
|J(Q) − J(float)| ≤ Σ_i L_i ε_i = Σ_i S_i(J) ε_i。
因此「让 J 的偏差 ≤ τ_J」是一个以 ε_i(b_i) 为代价的多约束背包；最优比特分配由「单位成本能削减的 S_i·ε_i」排序贪心/对偶得到。系：**安全比特 = 对 J 的敏感度 × 该层可压缩性所决定的比特下界**，与「这一层参数多不多」无关。

**引理 20（量化导致模态混淆）** 若每个采样轨迹被量化扰动 ≤ ε_tr，经 Fréchet 匹配后原型扰动 ≤ ε_tr、模态内标准差扰动 ≤ c·ε_tr，则
Δ_min^Q ∈ [Δ_min − 2ε_tr, Δ_min + 2ε_tr]，σ_in^Q ≤ σ_in + c'·ε_tr。
当 Δ_min − 2ε_tr < 3(σ_in + c'·ε_tr) 时 A95 失效：R69 引理 16 的交互增益下界不再成立（VoI 可能被高估或符号错误）。极端情形下，一个真模态可被劈成两个（Δ_min 虚大 ⇒ 假 epistemic），两个真模态可被合并（Δ_min 虚小 ⇒ 假保守）。系：**量化下的 VoI 必须先过 QMS 门，不能直接沿用 R69 的模态分解。**

**引理 21（量化下 FMA 的可检出性）** 设真实缓变故障在 a_score 上的签名幅度为 Δa*，保护精度偏置包络为 ε_a，精度间隙为 G_q。则：
(i) 若 Δa* ≤ ε_a + τ_noise，任何检测器的功效 ≤ 1/2——这是**不可观测区**；
(ii) 若 G_q > τ_gap，任务精度通道的误差可超过 Δa*，用它判定会同时制造假阳与假阴。
因此保护比特地板由「我们承诺检出的最小故障签名」反解：
b_safe = min{ b : ε_a(b) ≤ Δa*_min / 2 }。
系：**FMA 的灵敏度不是免费的，它是一笔必须预先支付的比特预算**；把 FMA 和任务通道一起压到 INT4，等于拆掉了 R69 的第二意见。

**引理 22（事件触发认证的成本与有效性）** 设触发概率 p_t、全量认证成本 C_f、代理成本 C_s，则期望成本 = p_t·C_f + (1−p_t)·C_s。若代理证书按决策裕度 m_0 保守膨胀，则「裕度 > m_0 时用代理、否则全量」的证书与全量认证**同有效性**。若裕度分布在 0 附近密度 ≤ κ，则 p_t ≤ κ·m_0，成本为 O(κ m_0 C_f + C_s)——相对决策次数是摊还常数，**不随运行时长线性增长**。

**定理 18（严格包含与安全单调性）** 在 A99（全精度极限）、A100（共形覆盖率）、A101（可分/持续门）、A102（无扰切换）下，对任意比特预算 B：
- 若 J_LITE 有效，期望风险 ≤ R_FLUID + Δ_cert，其中 Δ_cert = max_J width(𝒞_α)/2 是显式、有界的证书余量；
- 若无效，LDL 使 λ 单调不降，并在最低档与 R68 保守策略逐指令一致；
- 当 B→∞，ε→0、Δ_cert→0、门恒通过，LITE-RAS ≡ FLUID-RAS（逐指令相同）。
故安全性永不弱于 R69；「轻量」只在认证区内换取效率，**不能把认证区外的风险一起买走**。

**定理 19（人-比特仪器的联合最优与相变）** 在预算约束下，联合目标对 (g,β) 可分离为两件「信息商品」的背包；其最优解是「单位可靠成本的期望信息增益」排序。存在欺骗率阈值
δ_p* = 1 − (c_human / c_comp)·(I_bits / I_human)，
当人类欺骗率 δ_p > δ_p* 时，买比特严格优于问人（若比特可买）；当算力成本爆炸时反之。系：**「问人还是加精度」不是工程口味，而是由欺骗率与算力价格共同决定的相变。**

**定理 20（无扰精度切换与无突变）** 预编译精度库 + 滞回 + 状态携带 + 输出投影到已认证前缀集，使切换瞬间的输出跳变 ≤ δ_switch；结合 C-RAS-WM 前缀认证，执行前缀始终落在认证包络内，控制连续、无突变（R68 定理 15 的换装不变式在精度维度上成立）。

## 6. 本轮最大风险

**一句话**：LITE-RAS 的合法性建立在「量化误差包络在部署分布上仍然覆盖真值」这一共形/交换性假设上；而**部署分布漂移与缓变故障——恰恰是 R68/R69 存在的理由——会破坏交换性，使包络系统性低估误差**。于是系统会拿着一份「纸面有效」的证书，把安全通道压到刚好被量化吃掉的精度上：轻量认证沦为轻量剧场。

**次级风险与缓解**：
1. **敏感度是在全精度工作点估的**，量化后工作点漂移导致 S_i 失准 → 迭代重估 + 对 S_i 本身加鲁棒区间（元层面的包络）；
2. **保护精度吃掉轻量收益** → 非对称精度 + 事件触发 QFMA + 只对安全通道升档，任务通道继续低比特；
3. **精度切换抖动** → 滞回 + 无扰条件 + 切换频率预算（定义 319、定理 20）；
4. **精度间隙攻击/校准表投毒** → G_q 统计 + 包络版本哈希 + 冗余校准 + 独立见证（定义 321）；
5. **极端低比特（≤2bit）下模态结构整体坍塌** → QMS/MPP 直接判不可分，退化到 R68，不在低比特上强行做交互消歧。

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** 零学习写；先认证后执行；非对称精度地板 b_safe；B→∞ 严格包含 FLUID-RAS、认证失败单调退回 R68。

**定义 311（QEM 条件包络）** δ_f = 舍入 + 累积；ε_f(x)= ε_f^det(x)+ε_f^conf(x)，条件于输入，cell 边界附近增大；共形界分布无关。

**定义 312（CAS 敏感度/必要比特）** `S_i(J)=sup|∂J/∂ε_i|`，`b_i^min(J)=min{b:S_i(J)ε_i(b)≤τ_J}`；安全比特由证书容差反推，而非参数规模启发式。

**定义 313（量化不确定性二分）** `U_q^irr` 按 aleatoric 进 λ_floor；`U_q^red` 是「模型 epistemic」，只能靠 β 消解，问世界无效。

**定义 314（ACX 联合 VoI）** 人交互 g 与计算动作 β 同一账本：`argmax[VoI_world+VoI_model−c_human−c_comp]`；欺骗率与算力价格决定谁占优（定理 19）。

**定义 315（QFMA）** 安全通道 b_safe 下算 a_score；`G_q=|a_safe−a_task|`；`detect ⇔ a_safe−ε_a>τ_FMA ∧ r_res<τ_res ∧ G_q≤τ_gap`；G_q 超限则禁用 FMA、退 R69 保守。

**定义 316（QMS 可分门）** `Δ_min^Q ≥ 3σ_in^Q + 2ε_mode`；不满足则歧义为精度诱发，VoI 无效，只能花比特或保守。

**定义 317（MPP 多精度持续）** 跨精度阶梯 Fréchet 匹配得 p_k；仅 p_k≥p_min 的模态进入 VoI；真模态稳定、幻影不稳、仅高精度出现的判为脆弱真模态优先花比特。

**定义 318（CQB 共形证书）** `𝒞_α(J,Q)=[Ĵ_Q−q, Ĵ_Q+q]`；有效 ⇔ 包络⊆允许集且 J_float∈包络；支持加权共形应对协变量漂移。

**定义 319（PB 精度库/无扰）** 预编译档位、只离散选档、滞回 + 状态携带 + `‖y_new−y_old‖≤δ_switch`；运行时零学习写。

**定义 320（LCS 轻量认证）** 仅当决策裕度小、靠近舍入边界或 OOD 时触发昂贵认证；否则用保守膨胀的代理证书；成本摊还常数（引理 22）。

**定义 321（AIC-LITE）** `ℰ_LITE=ℰ_FLUID×ℰ_quant`；覆盖 precision-gap、scale/zero-point 投毒、比特翻转、过期包络回放、精度劝降；审计记录配置/版本/触发/间隙。

**定义 322（J_LITE）** `Valid ⇔ Valid(J_FLUID@b_safe) ∧ ∀J 包络⊆允许集 ∧ QMS/MPP 满足 ∧ 预算未越 ∧ G_q 无攻击标记`。

**定义 323（轻量目标 + LDL）** `min latency+η_E energy+η_M memory` s.t. 证书有效且留余量；失败沿阶梯只增不减退化，λ 单调不降、包络不缩。

    env = {m: conditional_error_envelope(m, calib_loader) for m in float_model.modules}
    S   = certificate_sensitivity(float_model, calib_loader)
    b   = allocate_bits(S, env, budget, taus)          # min cost s.t. dJ <= tau
    return compile_precision_bank(float_model, b), S, env

def allocate_bits(S, env, budget, taus):
    # 多约束背包：∀J: Σ_i S_i(J) ε_i(b_i) ≤ τ_J；成本 Σ cost_i(b_i)
    return solve_multi_constraint_knapsack(S, env, budget, taus)

# IP-268/315：保护精度第二意见
def qfma(policy, xi, o, cfg_safe, cfg_task):
    a_safe = -policy.loglik(xi, o, cfg_safe)
    a_task = -policy.loglik(xi, o, cfg_task)
    return a_safe, policy.error_envelope(cfg_safe, 'a_score'), abs(a_safe - a_task)

# IP-269/317：量化下模态有效性
def validate_modes(modes_by_cfg, cfg, eps_mode):
    M = modes_by_cfg[cfg]
    if delta_min(M) < 3 * sigma_in(M) + 2 * eps_mode:
        return None                                    # 精度诱发歧义
    return [k for k in M if persistence(k, modes_by_cfg) >= P_MIN]

# IP-276：主闭环
def LITE_RAS_round(M, obs):
    cfg = M.bank.current()
    z, o = M.trunk_q(obs, cfg)
    K = 1 if M.mode_head_q(z, cfg) < TAU_MODE else 4
    modes = M.fmp_q.sample_and_cluster(o, K, cfg)
    valid = M.qms.validate(modes, M.bank.ladder, cfg)
    if valid is None:
        beta = M.acx.bits_for_separability(modes, cfg)
        if beta is None: return M.ldl.fallback(M, cfg, reason='mode')
        cfg = M.bank.switch(beta)
    a_safe, eps_a, gap = M.qfma(M.fmp_q, M.last_action, o, M.bank.safe, cfg)
    slow = (a_safe - eps_a > TAU_FMA) and (M.last_r_res < TAU_RES) and (gap <= TAU_GAP)
    g, beta = M.acx.choose_joint(valid, o, M.budget, cfg)
    if beta is not None:
        cfg = M.bank.switch(beta); modes = M.fmp_q.resample(o, cfg)
        U_epi = M.aud.epistemic(modes)
    elif g is not None:
        U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    else:
        U_epi = M.aud.epistemic(modes)
    J = M.cqb.build(M, cfg, modes, a_safe, gap)
    if not M.cqb.valid(J): return M.ldl.degrade(M, cfg, J)
    U_floor = M.aud.aleatoric(modes) + U_epi + M.qem.irreducible(cfg)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., M.wm_preds)
    mode = select_mode(modes, U_epi, lam)
    tau = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_i.submit_async(g, beta, gap, U_epi, J)
    return k, lam, mode, (U_floor, U_epi, cfg)

## 4. 推导

**引理 19（证书误差传播与安全比特）** 对 L_i-Lipschitz 的 J：`|J(Q)−J(float)| ≤ Σ_i S_i(J) ε_i`。故「偏差 ≤ τ_J」是 ε_i(b_i) 代价下的多约束背包；最优分配按「单位成本削减的 S_i·ε_i」排序。系：安全比特由**敏感度 × 可压缩性**决定，与层大小无关。

**引理 20（量化模态混淆）** 轨迹扰动 ≤ ε_tr ⇒ `Δ_min^Q ∈ [Δ_min−2ε_tr, Δ_min+2ε_tr]`、`σ_in^Q ≤ σ_in+c'ε_tr`。当 `Δ_min−2ε_tr < 3(σ_in+c'ε_tr)` 时 A95 失效，R69 引理 16 的交互增益下界不再成立；一个真模态可被劈成两个（假 epistemic），两个真模态可被合并（假保守）。系：量化下 VoI 必须先过 QMS。

**引理 21（量化下 FMA 可检出性）** 设真实故障签名 Δa*、保护精度偏置包络 ε_a、精度间隙 G_q。(i) `Δa* ≤ ε_a+τ_noise` 为不可观测区，任何检测器功效 ≤ 1/2；(ii) `G_q > τ_gap` 时低精度通道误差可超 Δa*，同时制造假阳/假阴。故 `b_safe = min{b: ε_a(b) ≤ Δa*_min/2}`。系：FMA 灵敏度是一笔必须预付的比特预算，不能与任务通道一起压到 INT4。

**引理 22（事件触发认证成本/有效性）** 期望成本 `p_t C_f+(1−p_t)C_s`；代理证书按裕度 m_0 保守膨胀时与全量认证同有效性；裕度密度 ≤ κ 时 `p_t ≤ κ m_0`，成本摊还常数、不随时长线性增长。

**定理 18（严格包含与单调安全）** A99–A102 下：J_LITE 有效 ⇒ 期望风险 ≤ R_FLUID+Δ_cert（Δ_cert 为显式包络宽度）；无效 ⇒ LDL 使 λ 单调不降并最终与 R68 逐指令一致；B→∞ ⇒ ε→0、Δ_cert→0、门恒通过 ⇒ LITE ≡ FLUID。故安全永不弱于 R69。

**定理 19（人-比特联合最优与相变）** 联合目标是两件信息商品的背包；最优解按单位可靠成本的信息增益排序。存在 `δ_p* = 1 − (c_human/c_comp)(I_bits/I_human)`：欺骗率超过 δ_p* 时买比特严格优于问人；算力成本爆炸时反之。「问人还是加精度」由欺骗率与算力价格共同决定。

**定理 20（无扰切换与无突变）** 预编译库 + 滞回 + 状态携带 + 输出投影到已认证前缀集 ⇒ 切换跳变 ≤ δ_switch；结合 C-RAS-WM 前缀认证，执行前缀始终在包络内，控制连续、无突变（R68 定理 15 的精度维度版本）。

## 7. 本轮最大风险

**一句话**：LITE-RAS 的合法性建立在「量化误差包络在部署分布上仍然覆盖真值」这一共形/交换性假设上；而**部署分布漂移与缓变故障——恰恰是 R68/R69 存在的理由——会破坏交换性，使包络系统性低估误差**。于是系统会拿着一份「纸面有效」的证书，把安全通道压到刚好被量化吃掉的精度上：轻量认证沦为轻量剧场。

**次级风险与缓解**：敏感度在全精度工作点估计、量化后漂移（迭代重估 + 对 S_i 加鲁棒区间）；保护精度吃掉轻量收益（非对称精度 + 事件触发）；切换抖动（滞回 + 无扰 + 切换频率预算）；精度间隙攻击/表投毒（G_q + 版本哈希 + 冗余校准 + 独立见证）；极端低比特模态坍塌（QMS/MPP 直接判不可分，退 R68，不强行交互消歧）。
