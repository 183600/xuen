# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「目标检测」×「通用机器人平台」）

> 第 54 轮把技能组合推进为动作空间剖面 `α_S`、组合图 `G_S` 与云边联合证书 `J`。本轮把更上游的「感知」正式纳入证书体系：**目标检测不是独立评分模块，而是任务前提 `O_T` 的生成器**。核心矛盾：H22：检测基准的 mAP 对类别与条件求平均，而任务失败由任务相关对象在运行包络上的最坏情况决定，二者可能系统性脱节；H23：通用机器人平台意味着同一检测器要在不同本体、传感器与算力上复用，检测证书一旦绑定单一本体，跨平台迁移时会在传感签名漂移处集体失效。

## 0. 直觉与动机

**灵感 1（检测 = 任务前提生成器，而非下游模块）**
直觉：任务不能只写成动作序列 `A_T`，必须写成 `T = (O_T, R_T, A_T)`，其中 `O_T` 是任务必需对象集、`R_T` 是对象关系、`A_T` 才是动作序列。检测器输出 `Ô`，规划器默认假设 `O_T ⊆ Ô`。于是检测错误不是“精度下降”，而是**任务前提被污染**：漏检让必需对象消失，误检让不存在的对象进入关系图，定位漂移让关系 `R_T` 错位。第 54 轮说“动作空间是技能组合的第一性约束”；本轮补上更上游的一句：**检测覆盖是动作空间可用的第一性前提**。若 `O_T` 未被可靠覆盖，后续 `α_S`、`ρ`、`γ_ce` 全部失去意义，因为它们服务于一个被错误刻画的任务。

**灵感 2（平均精度陷阱 → 任务加权的最坏情况包络）**
直觉：mAP 在类别与运行条件上取平均，长尾对象与极端光照被平均掉；但机器人任务往往只依赖少数关键对象，且失败发生在运行包络边缘（远距离、逆光、遮挡、快速运动）。因此需要把检测能力写成 `π_M(o,ω)`（对象类 × 运行条件的剖面），并在任务相关的 `O_T × Ω_T` 上取**最坏情况**，而不是对全集取平均。一个检测器可以 mAP 很高却在任务关键的小目标逆光条件下几乎全漏——这就是“平均精度陷阱”。检测证书要证明的是**任务关键对象在任务运行包络上的下界召回/精度**，不是总体均值。

**灵感 3（检测误差 → 动作误差的耦合放大）**
直觉：不是所有检测错误等价。导航任务对远处行人漏检的容忍度，与抓取任务对目标框 2cm 漂移的容忍度完全不同。定义检测-动作耦合矩阵 `D`，其元素是“对象 `o` 的某类检测扰动对动作 `a` 的 P95 偏差”，则检测误差经 `D` 放大后进入动作空间：`||Δa|| ≤ ||D||·||δπ||`。这把“检测指标”转换为“任务动作风险”，也为第 54 轮的动作剖面提供上游门控：只有当 `||D||` 在预算内，动作空间的覆盖才有意义。

**灵感 4（通用机器人平台 → 本体签名与证书可移植性）**
直觉：通用平台的核心不是“一个模型跑所有机器人”，而是“一份证书能否被安全搬运”。定义本体签名 `sig(E) = (fov, res, mount, fps, exposure, max_vel, …)`，把平台建成图 `G_E`，边为迁移算子 `τ_{ij}` 与迁移风险 `r_{ij}`。检测证书只在 `r_{ij} ≤ ρ_plat` 的连通分量内有效；跨出该分量必须**再认证**（re-certify）或拒绝。这把“通用”从营销词变成可判定的证书传播问题：**通用 ≠ 无条件复用，通用 = 在签名连通分量内可迁移**。对 UniBot 这类多形态平台，这是能否规模化部署的关键。

**灵感 5（开集世界 → 风险受控弃权是合法安全动作）**
直觉：通用机器人一定遇到训练集外的新对象。此时强行检测并执行比“停下/重规划/求助”更危险。应把弃权建模为**带风险界的安全动作**：`abstain(x)=1` if 未知分高于 `θ_ood` 或置信度低于 `τ`，并要求在标定集上 `R_unk = P(accept ∧ unknown) ≤ α`。弃权不是任务失败，而是把不确定性转成一个可验证的安全回退；它使开集风险从“不可控”变为“可预算”。

**灵感 6（三证书融合 → 感知门控的 PAC 证书）**
直觉：把感知能力剖面 `π` 作为乘法门作用到第 54 轮动作剖面上：`α_S^π(a) = α_S(a)·g_M(a)`，其中 `g_M(a)=1` 当且仅当动作 `a` 所需的全部对象在任务包络上被 `π_M` 覆盖。于是动作可行域被感知收缩，鲁棒性谱只在收缩后的可行域内评估。最终证书 `C_par = (π_M, D, α_S^π, ρ, A_cert, abstain, sig(E), evidence)` 把“看得见—动得了—扛得住—搬得走”四件事统一到一张可判决的证书上。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（感知能力剖面 PCP）**
检测器 `M` 在对象类 `o∈O`、运行条件 `ω∈Ω`（光照、距离、遮挡、运动模糊、视角）上的能力剖面
```
π_M(o,ω) = (rec_M(o,ω), prec_M(o,ω), ece_M(o,ω))
κ_M(o,ω) = min(rec_M(o,ω), prec_M(o,ω)) · (1 - ece_M(o,ω))
```
任务相关覆盖：
```
cover_det(M, O_T, Ω_T, θ_det) = 1  ⇔  ∀o∈O_T, ∀ω∈Ω_T:
    min(rec_M(o,ω), prec_M(o,ω)) ≥ θ_det(o)  ∧  ece_M(o,ω) ≤ θ_cal
```
注意这是**最坏情况下界**，不是全集平均；`Ω_T` 是任务实际运行包络，而非训练分布。

**定义 122（检测-任务耦合矩阵 DTC）**
任务 `T=(O_T,R_T,A_T)`。检测扰动 `δπ` 经耦合矩阵 `D∈ℝ^{|A_T|×|O_T|}` 传到动作：
```
D[a,o] = P95_{pert∈𝒫} || Δ action_a(pert(o)) ||
||Δa|| ≤ ||D||₂ · ||δπ|| ,   ampl(M,T) = ||D||₂
```
其中 `𝒫 = {漏检 FN, 误检 FP, 框抖动, 类别替换}`。任务级检测可行性：
```
feas_det(T,M,Ω_T) = cover_det(M,O_T,Ω_T,θ_det) ∧ ampl(M,T) ≤ θ_amp
```

**定义 123（本体签名与平台异构图 PHG）**
本体 `E = (S_E, K_E, C_E)`（传感 / 运动学 / 算力），签名
```
sig(E) = (fov, res, mount_h, fps, exposure, max_vel, …)
```
平台图 `G_E=(V_E,E_E)`，边迁移风险
```
r_{ij} = d_H(sig(E_i), sig(E_j)) + λ·|rec_i - rec_j|
```
检测迁移证书 `C_plat = (E_i,E_j,r_{ij},gap_{ij},recert_set)`；仅当 `r_{ij} ≤ ρ_plat` 且 `gap_{ij} ≤ β_plat` 时证书可传播，否则必须对 `E_j` 再认证。

**定义 124（风险受控开集弃权 OAC）**
未知分 `u(x)`，弃权策略 `abstain(x)=1 ⇔ u(x) > θ_ood ∨ conf(x) < τ`。开集误收风险
```
R_unk = P(abstain(x)=0 ∧ x∈Unknown)
```
证书 `(θ_ood, τ, α)` 满足在标定集上 `R_unk ≤ α`；弃权触发安全回退 `F_abstain ∈ {stop, replan, ask}`，且 `F_abstain` 本身必须通过第 54 轮动作/鲁棒性校验。

**定义 125（感知门控动作剖面 PAG）**
动作 `a` 的对象前提集 `pre(a) ⊆ O_T`。门函数
```
g_M(a) = 1  ⇔  ∀o∈pre(a), ∀ω∈Ω_T: κ_M(o,ω) ≥ θ_det(o)
α_S^π(a) = α_S(a) · g_M(a)
```
感知门控后的覆盖 `cover_π(S,A_T) = 1 ⇔ ∀a∈A_T, α_S^π(a) ≥ θ_cov`。语义：**感知不可靠的动作不是低质量动作，而是不可行动作**。

**定义 126（感知-动作-鲁棒性联合证书 PAC）**
```
C_par = (π_M, O_T, Ω_T, D, α_S^π, ρ, A_cert, abstain_policy, sig(E), evidence)
```
部署可判定条件（全部满足）：
```
cover_det(M,O_T,Ω_T,θ_det) = 1
∧ ampl(M,T) ≤ θ_amp
∧ cover_π(S,A_T) = 1
∧ ∀d: ρ(d) ≥ ρ_min(d)
∧ r_{E→E'} ≤ ρ_plat
∧ R_unk ≤ α
```
`evidence` 至少包含：运行包络分层采样日志、检测扰动反事实仿真、目标本体影子运行日志、开集标定集与回退触发记录。

## 2. 关键算法 伪代码

### IP-121 PCPT（Perception Capability Profiling over envelope）

```python
def perception_profile(detector, classes, envelope, n_strata, alpha=0.05):
    prof = {}
    for o in classes:
        for omega in stratify(envelope, n_strata):   # 光照×距离×遮挡×模糊
            xs = sample_operating_points(omega, n=n_strata)
            rec, prec = eval_detector(detector, o, xs)
            ece = calibration_error(detector, o, xs)
            lo_r, lo_p = bootstrap_lower(rec, prec, alpha)
            prof[(o, omega)] = (lo_r, lo_p, ece)
    return prof

def detection_cover(prof, O_T, Omega_T, theta_det, theta_cal):
    for o in O_T:
        for w in Omega_T:
            r, p, ece = prof[(o, w)]
            if min(r, p) < theta_det[o] or ece > theta_cal:
                return False, (o, w, min(r, p), ece)
    return True, None
```

### IP-122 DTC（Detection-Task Coupling）

```python
def coupling_matrix(task, detector, sim, perturbations):
    D = np.zeros((len(task.A_T), len(task.O_T)))
    for i, a in enumerate(task.A_T):
        for j, o in enumerate(task.O_T):
            devs = []
            for pert in perturbations:              # FN/FP/jitter/class-swap
                obs = sim.inject(detector, o, pert)
                devs.append(action_deviation(sim.run(task, obs), a))
            D[i, j] = np.percentile(devs, 95)
    return D, spectral_norm(D)

def detection_feasible(D, theta_amp):
    return spectral_norm(D) <= theta_amp
```

### IP-123 PHT（Platform Heterogeneous Transfer）

```python
def platform_signature(E):
    return dict(fov=E.sensor.fov, res=E.sensor.res, mount=E.sensor.mount,
                fps=E.sensor.fps,
                blur=E.kin.max_vel * E.sensor.exposure)

def transfer_risk(M, E_src, E_tgt, probe_set):
    d_sig = normalized_distance(platform_signature(E_src),
                                platform_signature(E_tgt))
    rec_s = eval_detector(M, E_src, probe_set)
    rec_t = eval_detector(M, E_tgt, probe_set)
    return d_sig, abs(rec_s - rec_t)

def certify_transfer(M, E_src, E_tgt, tau_plat, beta_plat):
    d, gap = transfer_risk(M, E_src, E_tgt, probe_set)
    if d > tau_plat:
        return ('reject', 'signature_shift', d)
    if gap > beta_plat:
        return ('recertify', E_tgt, gap)
    return ('ok', TransferCert(E_src, E_tgt, d, gap))
```

### IP-124 OAC（Open-set Abstention Certificate）

```python
def calibrate_abstention(unknown_scores, alpha):
    # 选取使 P(accept | unknown) ≤ α 的分位阈值
    return quantile(unknown_scores, 1 - alpha)

def abstain(x, det, theta_ood, tau_conf):
    return det.unknown_score(x) > theta_ood or det.conf(x) < tau_conf

def safe_fallback(state, skill_lib):
    # 回退动作本身也须通过动作/鲁棒性证书
    return select_containment_skill(state, skill_lib)
```

### IP-125 PAG（Perception-gated Action Profile）

```python
def perception_gated_profile(skill, prof, theta_det):
    alpha_pi = {}
    for a, objs in skill.preconditions.items():
        g = 1.0 if all(prof[(o, w)][0] >= theta_det[o]
                       and prof[(o, w)][1] >= theta_det[o]
                       for o in objs for w in skill.envelope) else 0.0
        alpha_pi[a] = skill.alpha[a] * g
    return alpha_pi
```

### IP-126 PAC（Perception-Action-Robustness Composite）

```python
def composite_certificate(task, skill_seq, detector, platform, theta):
    prof = perception_profile(detector, task.O_T, platform.envelope, theta.n)
    ok, why = detection_cover(prof, task.O_T, platform.envelope,
                              theta.det, theta.cal)
    if not ok:
        return ('reject', 'detection_coverage', why)

    D, amp = coupling_matrix(task, detector, sim, PERTURBATIONS)
    if amp > theta.amp:
        return ('reject', 'coupling_amplification', amp)

    alpha_pi = [perception_gated_profile(s, prof, theta.det)
                for s in skill_seq]
    if not cover_check(merge(alpha_pi), task.A_T, theta.cov):
        return ('reject', 'action_coverage_after_gating')

    tc = certify_transfer(detector.model, platform.src, platform.tgt,
                          theta.plat, theta.beta_plat)
    if tc[0] != 'ok':
        return tc

    theta_ood = calibrate_abstention(calib_unknown_scores, theta.alpha)
    rho = compose_robustness_chain([s.rho for s in skill_seq], K)
    if min(rho.values()) < theta.rho_min:
        return ('reject', 'robustness', rho)

    return ('ok', PA_Cert(prof, D, alpha_pi, rho, tc,
                          (theta_ood, theta.tau), platform.sig, evidence))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| PCPT | O(\|O_T\|·\|Ω_T\|·n·C_eval) | O(\|O_T\|·\|Ω_T\|) | 分层覆盖、置信下界 |
| DTC | O(\|A_T\|·\|O_T\|·\|𝒫\|·C_sim) | O(\|A_T\|·\|O_T\|) | 扰动完备、P95 稳健 |
| PHT | O(\|V_E\|²·C_eval) | O(\|V_E\|²) | 签名度量与失效对齐 |
| OAC | O(n log n) 标定 | O(n) | 标定集可交换、风险单调 |
| PAG | O(\|S\|·\|A\|·\|pre\|) | O(\|A\|) | 前提完备、门控 sound |
| PAC | O(PCPT+DTC+PHT+OAC+ρ) | 各项之和 | 四条件合取、预算闭合 |

**正确性定理（Perception-Action-Robustness Composite Soundness）**
承接第 53/54 轮 (A22)–(A28)；新增假设：
**(A29)** `π_M` 的 `O_T×Ω_T` 分层采样覆盖运行包络，bootstrap 下界有效；
**(A30)** 检测扰动集 `𝒫` 覆盖任务相关失效模式，`||Δa|| ≤ ||D||·||δπ||` 成立；
**(A31)** 开集标定集与部署分布可交换，弃权阈值按定义 124 校准；
**(A32)** 平台签名距离与真实检测退化满足单调关系（同一 `r` 分量内可比）。
则部署成功概率下界：
```
P_success ≥ 1 - Σ_d (1 - ρ_min(d))
              - P(cover_det = 0)
              - ||D||₂ · E[||δπ||]
              - P(R_unk > α)
              - P(r_{E→E'} > ρ_plat)
              - β_E
```
关键：**感知前提先于动作覆盖、动作覆盖先于鲁棒性评估**；任一上游条件失败，下游证书不得被单独引用。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 运行包络 `Ω_T` 组合爆炸、采样不足 | 高 | 分层重要性采样 + 主动学习 + 极端条件红队 |
| 最坏覆盖与平均指标错位导致误判 | 高 | 双指标并行报告 + 关键对象白名单审计 |
| 耦合矩阵 `D` 在真实任务上不可辨识 | 高 | 反事实仿真 + 小规模真机标定 + 保守上界 |
| 平台签名距离与失效不对齐 | 高 | 用影子运行校准 `d_H` 权重 + 局部再认证 |
| 开集弃权过多拖垮任务完成率 | 中 | 风险-收益曲线 + 分级回退 + 主动求助 |
| 三证书叠加过于保守 | 中 | 证书剪枝 + 置信度分层 + 允许带预算的降级部署 |

## 6. 本轮最大风险

**一句话**：把目标检测提升为“任务前提生成器”并用感知门控动作剖面后，方案的正确性同时押在**运行包络最坏覆盖的采样完备性、检测-动作耦合矩阵 `D` 的可辨识性、以及跨本体签名距离与真实失效的对齐**三件事上；其中任何一件在真实 UniBot 平台上失真，都会让“感知已覆盖”的证书变成虚假前提，使下游动作与鲁棒性证书集体失效，因此必须以**任务关键对象白名单 + 反事实扰动标定 + 影子运行再认证**作为不可省略的三重护栏，宁可对未覆盖对象保守弃权，也不把 mAP 的“平均幻觉”当作部署许可。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim⁽ᴾ⁾（PCP×DTC×PHG×OAC×PAG×PAC）

> 承接第 54 轮产物 v31。本轮在“动作-协同层”之上补齐最上游的**感知层**，把目标检测从评分模块改造为任务前提生成器，并面向 UniBot 等通用机器人平台解决证书可移植性：
> - **PCP（Perception Capability Profile）**：任务加权、运行包络最坏情况下的检测能力剖面 `π_M(o,ω)`；
> - **DTC（Detection-Task Coupling）**：检测扰动到动作偏差的耦合矩阵 `D` 与放大系数 `ampl`；
> - **PHG（Platform Heterogeneity Graph）**：本体签名 `sig(E)`、平台图 `G_E` 与迁移风险 `r_{ij}`；
> - **OAC（Open-set Abstention Certificate）**：风险受控的开集弃权 `R_unk ≤ α` 与安全回退；
> - **PAG（Perception-gated Action Profile）**：`α_S^π(a)=α_S(a)·g_M(a)`，感知门控动作可行域；
> - **PAC（Perception-Action-Robustness Composite Certificate）**：四条件合取的联合证书。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-115/116/117/118/120 以纳入感知维度。体系由 v16+++ 升级为 v17⁽ᴾ⁾。

## 0. 核心 IP 设计

## 2. 关键算法 伪代码

### IP-121 PCPT（最坏覆盖剖面）

```python
def perception_profile(detector, classes, envelope, n_strata, alpha=0.05):
    prof = {}
    for o in classes:
        for omega in stratify(envelope, n_strata):
            xs = sample_operating_points(omega, n=n_strata)
            rec, prec = eval_detector(detector, o, xs)
            ece = calibration_error(detector, o, xs)
            lo_r, lo_p = bootstrap_lower(rec, prec, alpha)
            prof[(o, omega)] = (lo_r, lo_p, ece)
    return prof

def detection_cover(prof, O_T, Omega_T, theta_det, theta_cal):
    for o in O_T:
        for w in Omega_T:
            r, p, ece = prof[(o, w)]
            if min(r, p) < theta_det[o] or ece > theta_cal:
                return False, (o, w, min(r, p), ece)
    return True, None
```

### IP-122 DTC（检测-动作耦合）

```python
def coupling_matrix(task, detector, sim, perturbations):
    D = np.zeros((len(task.A_T), len(task.O_T)))
    for i, a in enumerate(task.A_T):
        for j, o in enumerate(task.O_T):
            devs = []
            for pert in perturbations:              # FN/FP/jitter/class-swap
                obs = sim.inject(detector, o, pert)
                devs.append(action_deviation(sim.run(task, obs), a))
            D[i, j] = np.percentile(devs, 95)
    return D, spectral_norm(D)
```

### IP-123 PHT（跨本体迁移证书）

```python
def platform_signature(E):
    return dict(fov=E.sensor.fov, res=E.sensor.res, mount=E.sensor.mount,
                fps=E.sensor.fps,
                blur=E.kin.max_vel * E.sensor.exposure)

def certify_transfer(M, E_src, E_tgt, tau_plat, beta_plat):
    d_sig = normalized_distance(platform_signature(E_src),
                                platform_signature(E_tgt))
    rec_s = eval_detector(M, E_src, probe_set)
    rec_t = eval_detector(M, E_tgt, probe_set)
    gap = abs(rec_s - rec_t)
    if d_sig > tau_plat:
        return ('reject', 'signature_shift', d_sig)
    if gap > beta_plat:
        return ('recertify', E_tgt, gap)
    return ('ok', TransferCert(E_src, E_tgt, d_sig, gap))
```

### IP-124 OAC（开集弃权）

```python
def calibrate_abstention(unknown_scores, alpha):
    return quantile(unknown_scores, 1 - alpha)

def abstain(x, det, theta_ood, tau_conf):
    return det.unknown_score(x) > theta_ood or det.conf(x) < tau_conf

def safe_fallback(state, skill_lib):
    return select_containment_skill(state, skill_lib)   # stop/replan/ask
```

### IP-125 PAG（感知门控动作剖面）

```python
def perception_gated_profile(skill, prof, theta_det):
    alpha_pi = {}
    for a, objs in skill.preconditions.items():
        g = 1.0 if all(prof[(o, w)][0] >= theta_det[o]
                       and prof[(o, w)][1] >= theta_det[o]
                       for o in objs for w in skill.envelope) else 0.0
        alpha_pi[a] = skill.alpha[a] * g
    return alpha_pi
```

### IP-126 PAC（联合证书构建）

```python
def composite_certificate(task, skill_seq, detector, platform, theta):
    prof = perception_profile(detector, task.O_T, platform.envelope, theta.n)
    ok, why = detection_cover(prof, task.O_T, platform.envelope,
                              theta.det, theta.cal)
    if not ok:
        return ('reject', 'detection_coverage', why)

    D, amp = coupling_matrix(task, detector, sim, PERTURBATIONS)
    if amp > theta.amp:
        return ('reject', 'coupling_amplification', amp)

    alpha_pi = [perception_gated_profile(s, prof, theta.det)
                for s in skill_seq]
    if not cover_check(merge(alpha_pi), task.A_T, theta.cov):
        return ('reject', 'action_coverage_after_gating')

    tc = certify_transfer(detector.model, platform.src, platform.tgt,
                          theta.plat, theta.beta_plat)
    if tc[0] != 'ok':
        return tc

    theta_ood = calibrate_abstention(calib_unknown_scores, theta.alpha)
    rho = compose_robustness_chain([s.rho for s in skill_seq], K)
    if min(rho.values()) < theta.rho_min:
        return ('reject', 'robustness', rho)

    return ('ok', PA_Cert(prof, D, alpha_pi, rho, tc,
                          (theta_ood, theta.tau), platform.sig, evidence))
```

### IP-126b 三证书判决表

| 条件 | 失败语义 | 处置 |
|---|---|---|
| `cover_det = 0` | 任务关键对象在包络上不可见/不可分辨 | 拒绝部署 / 缩任务 / 换传感器 |
| `ampl > θ_amp` | 检测误差对动作放大过强 | 降低动作精度要求 / 增加主动感知 |
| `cover_π = 0` | 感知门控后动作不可行 | 拒绝该技能路径 |
| `r > ρ_plat` | 跨本体签名漂移超预算 | 目标平台再认证 |
| `R_unk > α` | 开集误收风险超预算 | 收紧弃权阈值 / 扩展训练 |
| `ρ < ρ_min` | 鲁棒性不足 | 回退到保守技能 |

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| PCPT | O(\|O_T\|·\|Ω_T\|·n·C_eval) | O(\|O_T\|·\|Ω_T\|) | 分层覆盖 ≥ 95%，下界置信 |
| DTC | O(\|A_T\|·\|O_T\|·\|𝒫\|·C_sim) | O(\|A_T\|·\|O_T\|) | 扰动集完备，P95 稳健 |
| PHT | O(\|V_E\|²·C_eval) | O(\|V_E\|²) | 签名距离-失效率单调 |
| OAC | O(n log n) | O(n) | 可交换性、风险 ≤ α |
| PAG | O(\|S\|·\|A\|·\|pre\|) | O(\|A\|) | 门控保守、前提完备 |
| PAC | 各项之和 | 各项之和 | 四条件合取、预算闭合 |

**正确性定理（Perception-Action-Robustness Composite Soundness）**
承接第 53/54 轮 (A22)–(A28)；本轮新增：
**(A29)** `π_M` 在 `O_T×Ω_T` 上分层采样覆盖运行包络，bootstrap 下界有效；
**(A30)** 扰动集 `𝒫` 覆盖任务相关失效模式，`‖Δa‖ ≤ ‖D‖·‖δπ‖`；
**(A31)** 开集标定集与部署分布可交换，弃权阈值按定义 124 校准；
**(A32)** 平台签名距离与真实检测退化在同一分量内单调可比。
则：
```
P_success ≥ 1 - Σ_d (1 - ρ_min(d))
              - P(cover_det = 0)
              - ‖D‖₂ · E[‖δπ‖]
              - P(R_unk > α)
              - P(r_{E→E'} > ρ_plat)
              - β_E
```

**引理（感知门控单调性）**：若 `θ_det` 单调不降，则 `α_S^π` 单调不增，`cover_π` 只会从 1 变为 0，不会出现“越收紧越可行”的反常，保证证书保守性。

**引理（证书不可越级引用）**：`C_par` 的任一上游条件失败时，不得单独引用 `ρ` 或 `A_cert` 作为部署依据；因为二者均以 `O_T` 被正确感知为隐含前提。

## 4. 集成更新：v16+++ → v17⁽ᴾ⁾ 体系

```
根信任 + 能力格
│
├─ L0   分布式底座与执行边 (GPC/SEN/TBC)
├─ L0.5 任务迁移与仿真证据 (TIX,XFR,CRC,SFE,FDR,RAB,DST,SBC)
├─ L0.5+ 鲁棒性层 (TRO,RXC,RCO,REX,RTA,TRC,RUR)             ← v53
├─ L0.5++ 动作-协同层 (ACS,SCOM,CEC,AEC,JTC)                ← v54
├─ L0.6  感知-平台层 (PCP,DTC,PHG,OAC,PAG,PAC)              ← v55 新增
├─ L1   几何感知
├─ L2   任务/上下文/记忆/语音
...
└─ L6   原型证伪/XFER/LFF/IXD
```

> 设计原则：**L0.6 是 L0.5++ 的前置门**。凡进入动作-协同层的技能路径，必须先通过感知覆盖与平台迁移判定；否则动作证书只是在为错误任务背书。

JCPS 输出扩展为：
```
(v,a,m,q,ι,κ,g,λ,τ,σ,ρ,Explain,RUR_state,
 α_S,A_cert,γ_ce,δ_a,
 π_M,D,sig(E),R_unk,abstain)
```

其中本轮新增：
- `π_M` 任务加权最坏检测剖面；
- `D` 检测-动作耦合矩阵；
- `sig(E)` 本体签名；
- `R_unk` 开集误收风险；
- `abstain` 弃权与安全回退状态。

## 5. 面向 UniBot 的落地建议

1. **任务关键对象白名单**：每个任务声明 `O_T` 与每类阈值 `θ_det(o)`，禁止用全局 mAP 作为验收口径。
2. **运行包络先验**：把平台实际工作距离、光照区间、最大速度写进 `Ω_T`，作为检测评测的强制分层。
3. **平台注册表**：为每种本体登记 `sig(E)`，新本体上线先走 `certify_transfer`，未通过则进入再认证队列。
4. **弃权即安全动作**：把 `F_abstain` 纳入技能库并参加第 54 轮组合与鲁棒性校验，避免“弃权后乱动”。
5. **证书不可越级**：部署看板同时展示 `cover_det / ampl / cover_π / ρ / r / R_unk`，任一红项即阻断，不允许以高 `ρ` 掩盖低 `cover_det`。

## 6. 本轮最大风险

**一句话**：把目标检测提升为“任务前提生成器”并以感知门控动作剖面后，v17⁽ᴾ⁾ 的正确性同时押在**运行包络最坏覆盖的采样完备性、检测-动作耦合矩阵 `D` 的可辨识性、以及跨本体签名距离与真实失效的对齐**三件事上；任一环节在真实通用机器人平台上失真，都会让“感知已覆盖”的证书变成虚假前提，使下游动作、鲁棒性与云边证书集体失效，因此必须以**任务关键对象白名单 + 反事实扰动标定 + 影子运行再认证**作为不可省略的三重护栏，宁可对未覆盖对象保守弃权，也绝不把 mAP 的“平均幻觉”当作部署许可。
