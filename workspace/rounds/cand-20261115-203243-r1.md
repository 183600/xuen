# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「基线复现」×「数据采集」）

> R69 的 FLUID-RAS 把不确定性拆成 aleatoric/epistemic，用流匹配给不确定性「形状」，用主动交互去消解它，用流似然做标定不可吸收的第二意见。整个闭环在纸面上是自洽的、甚至优雅的。但把这一摞推理从头到尾读一遍，会发现一个不舒服的事实：**R66→R69 是一座向上生长的塔，而塔的第一块砖——「R68 的基线数字是真的」「流模型吐出的模态是世界的模态」——从来没有被真正测过。**
>
> 本轮的两个灵感词异常朴素，甚至「不够前沿」：**基线复现**、**数据采集**。这正是它们的力量。它们逼我们从「再加一层聪明机制」退回到「这些聪明机制赖以成立的经验前提到底是什么」。
> - **基线复现**问的是：R68 号称被 R69 严格包含（定理 16），可 R68 本身在一个固定代码/种子/数据快照下能复现到小数点后几位？如果不能，定理 16 的「逐指令相同」比较的就是两个都漂浮的东西。
> - **数据采集**问的是：E287 要测「模态校准时 ECE<0.05」，E286 要测「模式召回≥85%」——**可模态身份 M 是一个隐变量，谁采集了它的标注？标注协议是否与策略自己定义模态的方式循环？** 如果没有独立的 M 标注，这些实验是在用模型给自己打分。
>
> 核心命题：**不确定性闭环的瓶颈已经从「算法不够巧」转移到「经验主张不可证伪、评估目标不可识别」。本轮不加控制层，而是加一个「地基/记账」层 FLOOR-RAS：把每条经验主张挂到可执行的复现单元上（主张-证据账本 + 复现依赖图），把「模态」从模型的内部产物提升为必须通过行为可识别性检验的外部构念，并把 R69 的 U_epi 反向用作数据采集的采集函数——在最值钱的地方采标签。** 关键姿态：FLOOR 不动控制律，「安全不变」是平凡的（因为它根本不碰动作），它唯一的产出是**让「我有多确定」这句话第一次可被审计**。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我凭什么相信上面四句话是真的**」——FLUID 需要 FLOOR，否则流匹配的不确定性只是悬在空中的漂亮分布。

## 0. 直觉与动机

**灵感 1（基线复现 → 「严格包含」是条件语句，不是事实）**
直觉：定理 16 说「FLUID 的期望风险 ≤ R68」，前提 A95–A97。R69 自己也承认当 VoI≤成本时二者「逐指令相同」。但「相同」要能被检验，必须先有一个**可复现的 R68**：同样的种子、同样的数据快照、同样的硬件包络，跑出同样的 λ、同样的 k、同样的 U。否则「相同」只是在比较两份各自漂移的实现。复现不是「跑一遍 demo」，而是**给「基线」这个词一个可执行的定义**：一个 (代码哈希, 种子集, 数据快照哈希, 数值容差) 四元组，任何人重放都落在容差带内。没有这个四元组，「严格包含」就无法被证伪，也就不是科学主张。

**灵感 2（基线复现 → 经验债会复利）**
直觉：R66 假设 WM 预测可信，R67 假设 VISTA 的 H 步外推可用，R68 假设标定残差能解释慢变故障，R69 假设流模态可信。每一层都把上一层的经验结论当作**公理**往下推。这在数学上是干净的（定理就是「若 A 则 B」），但在工程上是危险的：**只要最底层一条经验假设崩了，上面所有「严格包含」「安全不让步」都一起失效，而且失效是静默的。** 这就是「经验债」：借来的确定性，利息是整座塔。R70 的第一个任务是把债务显性化——给每条主张记一个「支持集」，标出哪些支持是分析的（可证明），哪些是经验的（必须复现）。

**灵感 3（数据采集 → 模态可能是模型自己造出来的）**
直觉：最尖锐的问题在这里。R69 说流模型采样出 K 个模态、权重 ŵ、间距 Δ_min，然后拿它算 VoI、算 ECE、算模式召回。**但「模态身份 M」是谁的模态？** 如果是流模型聚类出来的，那 E286 的「模式召回」就是拿模型的分组去对模型的分组——循环论证。真实世界里，人面对岔路时未必有「两个离散意图」，可能只是一个连续的犹豫分布；把连续犹豫强行聚类成两峰，再宣布「我发现了两模态、去问一问」，就是**构念实在化（reification）**：系统制造了它随后「发现」的多模态。所以数据采集的第一件事不是采更多，而是定义**可识别性**——什么条件下，两种「模态」在可观测行为上真的可分，因而是世界的区分而非表征的伪影。

**灵感 4（数据采集 → 说-做差：问出来的标签不可信）**
直觉：R69 让系统去「问」。那人给的答案就是标签吗？不是。人对「你刚才是想绕左还是绕右」的回答是**事后合理化**，与真实意图常有系统偏差（说-做差，say-do gap）。更稳的标签是**行为代理**：在同一个歧义状态下，人实际做了什么（而不是说自己想做什么）。这把数据采集从「问卷」变成「自然实验/偏好揭示」。同时，标注者之间的分歧（inter-annotator disagreement）不是要平均掉的噪声，而是**aleatoric 的直接测量**——如果两个认真的人对同一状态给出不同的「意图」，那这份歧义本来就是不可约的，正好对应 R69 的 U_ale，而非 U_epi。这个对应关系是本轮最漂亮的一点：**分歧率 ≈ aleatoric 的经验估计；分歧可被证据消解的比例 ≈ epistemic。**

**灵感 5（数据采集 → 采集器继承 R69 的威胁模型）**
直觉：R69 说交互会被投毒。数据采集是同一个攻击面，而且更隐蔽：投毒者不需要骗过实时控制器，只需污染「真值」数据集，让 ECE 永远看起来达标。所以采集必须带**来源账本**（provenance）：每条标签记录采集协议、采集者、时间、是否与训练集重叠（污染检查）、以及「这条标签能否被独立重采」。投毒检测从「扰动一个静止的模型」变成「扰动正在学习的数据」。

**灵感 6（正向循环 → 用歧义探测器当采集函数）**
直觉：R69 花大力气算 U_epi（哪里歧义大且可分）。这恰好是一个**主动学习采集函数**：在 U_epi 高的状态采标签，信息回报最高。于是 R69 的推理机器被「倒过来」用于数据采集：模型认为「这里有两种可能」，我们就去这里要真值。风险也翻转了——如果模型幻觉出一个模态，主动采集会在那里浪费标注预算，但标注员会说「这里根本没有你说的两种意图」，于是**幻影模态变成可检测的**（在 R69 里它只会在实时环里静默地驱动一次无用追问）。这把 R69 最大的风险（模态幻觉）从「不可见」变成「数据采集阶段可见」。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（FLOOR-RAS 总览）** FLOOR-RAS = (MRB, CEL, R-DAG, IDP, ATDC, PDL, GGG)。它是 RAS-WM 的**基底元层**，不在实时环内、不产生控制动作。三不变式：
(i) **控制律零扰动**：FLOOR 不修改 R66–R69 的任何动作、λ、k，因此安全包含关系平凡成立；
(ii) **经验主张必须可挂载**：任何 empirical 主张必须绑定一个可执行复现单元（MRB 快照 + 检查脚本 + 容差），否则标记为 `UNGROUNDED`，其下游主张自动降级为 `CONDITIONAL`；
(iii) **评估目标必须可识别**：用于校准/评分/ECE 的模态标签必须通过 IDP（定义 313）的分离性检验，且来自与策略定义模态时**不相交的协议**（定义 322）。

**定义 311（主张-证据账本 CEL）** 账本节点 c = (id, statement, kind ∈ {analytic, empirical}, support ⊆ 𝒜, deps ⊆ C, evidence)。其中 𝒜 为假设集（A95–A99…），kind=analytic 的支持可由证明消解，kind=empirical 必须由复现证据消解。每条主张状态 σ(c) ∈ {GROUNDED, REPRODUCED, CONDITIONAL, UNGROUNDED, FALSIFIED}。

**定义 312（复现依赖图 R-DAG 与承重质量）** 以 CEL 为顶点、deps 为边构成 DAG。承重质量 `B(c) = Σ_{d ∈ Desc(c)} w_d`，w_d 为下游主张 d 的科学权重（默认 1；若 d 已被判错则其下游权重加倍——错误会沿依赖传播）。复现优先级 `Pri(c) = B(c)·(1−κ(c))/cost(c)`，κ(c) 为当前证据强度（0–1）。**复现不是平铺，而是按「塔会不会因为这块砖塌」排序。**

**定义 313（模态可识别性 IDP）** 设潜在意图 M ∈ {1..K}，可观测行为 b（轨迹/选择/时序），观测上下文 o。称 M 在 (o, 𝒫) 下**可识别**，若行为分布族 {p(b|o,M=m)} 两两可分：`min_{i≠j} d_TV(p(b|o,i), p(b|o,j)) ≥ δ_id`，且该分离不被标签协议 𝒫 的观测噪声抹平。**不可识别 ⇒ 不是真模态，是表征伪影**；此时禁止用其算 VoI/ECE。

**定义 314（行为代理标签）** 标签 y = φ(b)，φ 为「实际行为」到意图的映射（偏好揭示），而非自陈报告。定义说-做差 `g_sd = D(p_self-report(M|o) ‖ p_behavior(M|o))`；g_sd 越大，自陈标签越不可用于校准，须降权 `u_sd(g_sd)`。

**定义 315（歧义定向主动采集 ATDC）** 采集函数 `Acq(o) = U_epi(o)·IDGain(o) − c_label(o)`，IDGain 为「采到该状态标签后对 M 后验熵的期望下降 × 可识别性提升」，c_label 为标注成本。选 `o* = argmax Acq`，s.t. 采集预算与来源多样性约束。`U_epi(o)` 复用 R69 定义 297（模型已算，零额外推理）。

**定义 316（分歧即 aleatoric）** 对同一 o 的 n 个独立行为标注得分歧熵 `H_dis(o)`；令 `U_ale^emp = H_dis`，`U_epi^emp = H(M|o) − H_dis`（可被证据消解的部分）。用 (U_ale^emp, U_epi^emp) 与模型 (U_ale, U_epi) 做一致性检验——这是 E287 的「接地」版本，取代循环自评。

**定义 317（数据来源账本 PDL）** 每条样本记 `(协议ID, 采集者, 时间, 去重哈希, 与训练集重叠度, 可重采指纹)`。污染检测：若某标签子集对下游 ECE 的影响方向随「来源」系统性翻转，则判为投毒/选择偏差。继承 R69 的 ℰ_poison，新增 ℰ_data（标签投毒、协议漂移、采集者共谋）。

**定义 318（复现单元与容差）** 复现单元 r = (code_hash, seed_set S, data_snapshot_hash, env, metric, τ_tol)。REPRODUCED ⇔ 对 ∀s∈S 重放，|metric_s − metric_ref| ≤ τ_tol 且符号/排序一致。τ_tol 由浮点非确定性与硬件包络给出（定义 324）。

**定义 319（接地门 GGG）** 主张 c 可被「当作公理」用于新推导 ⇔ σ(c) ∈ {REPRODUCED}，或（kind=analytic 且其全部 empirical 前提已 REPRODUCED）。否则 c 及其下游一律 CONDITIONAL，必须在论文/证书里显式标注条件。

**定义 320（经验债预算）** `Debt(C) = Σ_{c: σ(c)∈{CONDITIONAL,UNGROUNDED}} B(c)`。约束：每轮新增经验主张的承重质量 ≤ 本轮复现退休的承重质量（净债务不增）。否则禁止新增算法层——**先还债，再加层**。

**定义 321（复现证书 J_FLOOR）** J_FLOOR = (CEL_hash, R_DAG_hash, MRB_report, IDP_report, ATDC_log_hash, PDL_hash, debt_before/after, floor_ver)。Valid ⇔ MRB 全过 ∧ 所有被引经验主张 σ=REPRODUCED ∨ 显式 CONDITIONAL ∧ 评估标签均通过 IDP ∧ 无 PDL 污染告警。

**定义 322（评估-构造解耦）** 用于**定义**模态的协议 `𝒫_def` 与用于**评分**模态的协议 `𝒫_eval` 必须由不同人群/不同环境/不同场景生成，且 `𝒫_def ∩ 𝒫_eval = ∅`。违反则 E286/E287 的指标作废（循环性禁令）。

**定义 323（样本复杂度与采集预算）** 在分离边际 δ_id 下，ATDC 达到 ECE 误差 ≤ ε（置信 1−γ）所需标签数 `N ≥ c·(1/δ_id²)·log(K/γ)`；均匀采集 `N_uni ≥ c·K/δ_id²`。预算 B_label 是硬约束，采集不足则相应主张只能标 CONDITIONAL。

**定义 324（重放确定性与数值容差）** 实时路径的 λ、k、mode 选择在确定性模式下必须逐位一致；浮点非确定性路径以「决策等价」判定（同 λ 档、同 k、同选中模态），τ_tol 按经验分布 P99 设定。**「逐指令相同」由此第一次有了一把可操作的尺子。**

**定义 325（接地追溯 RE-TRACE）** 给定一条最终主张（如「FLUID 严格包含 R68」），RE-TRACE 返回其依赖闭包中所有 empirical 节点的复现状态；若存在 UNGROUNDED，输出「该主张当前不可检验」并列出缺口清单。

**定义 326（与 R69 的关系：基底而非替代）** FLOOR-RAS 不引入新控制组件，仅对 (MRB, CEL, R-DAG, IDP, ATDC, PDL, GGG) 做工程与统计。`RAS-WM†† = RAS-WM† ⊕ FLOOR`，其动作轨迹与 RAS-WM† **恒等**；FLOOR 只改变「我们对 RAS-WM† 能断言什么」。

## 2. 关键算法骨架

```python
# IP-264 CEL：从研究档案抽取主张，构造主张-证据账本与 R-DAG
def build_cel(round_docs):
    nodes = []
    for doc in round_docs:                       # 逐轮解析定义/引理/定理
        for claim in parse_claims(doc):
            nodes.append(Claim(
                id=claim.id, stmt=claim.text,
                kind=('analytic' if claim.proof else 'empirical'),
                support=claim.assumptions,       # A95..A99
                deps=claim.references))          # 它引用了谁的结论
    return CEL(nodes)                            # 拓扑排序即得 R-DAG

def load_bearing(cel):                           # 定义 312：谁塌了会带走谁
    B = defaultdict(float)
    for c in reversed(cel.topo()):               # 逆拓扑累积下游权重
        B[c.id] += cel.weight(c)
        for p in c.parents: B[p.id] += B[c.id]
    return B                                     # Pri = B*(1-kappa)/cost

# IP-265 MRB：最小可复现基线（让「基线」这个词可执行）
def reproduce(unit, runner):                     # 定义 318/324
    outs  = [runner(unit.code, s, unit.data_snap) for s in unit.seeds]
    ok    = all(abs(o[unit.metric] - unit.ref) <= unit.tol for o in outs)
    order = same_ranking(outs, unit.ref_ranking) # 排序/符号也要一致
    return Status.REPRODUCED if ok and order else Status.UNGROUNDED

# IP-266 IDP：模态可识别性探针（反对循环论证）
def identifiability(o, modes, behavior_model):
    P = {m: behavior_model.distribution(o, m) for m in modes}   # 行为代理，非自陈
    delta = min(tv(P[i], P[j]) for i != j in modes)
    return delta >= DELTA_ID                     # 不可分 ⇒ 表征伪影

# IP-267 ATDC：把 U_epi 倒过来当采集函数（IP-255 的对偶）
def collect(policy, state_stream, budget):
    log = []
    while budget.left and state_stream:
        o = max(state_stream, key=lambda o: policy.U_epi(o)*id_gain(o) - c_label(o))
        if not identifiability(o, policy.modes(o), behavior_model):
            state_stream.remove(o); log.append(('phantom', o)); continue  # 幻影：跳过并记账
        log.append((o, behavior_label(o), provenance(o))); budget.spend(o)
    return Dataset(log)

# IP-268 PDL+GGG：来源账本与接地门（决定我们「能断言什么」）
def grounding_gate(cel, mrb, idp, pdl):
    debt_before = cel.debt()
    for c in cel.empirical_nodes():
        c.status = REPRODUCED if mrb.pass_(c) else UNGROUNDED
    for c in cel.analytic_nodes():
        c.status = (REPRODUCED
                    if all(p.status == REPRODUCED for p in c.emp_premises)
                    else CONDITIONAL)
    debt_after = cel.debt()                      # 定义 320
    return J_FLOOR(valid=(debt_after <= debt_before) and not pdl.alarm(),
                   debt_before=debt_before, debt_after=debt_after)
```

## 3. 推导

**引理 19（不可识别时 ECE 无意义）** 若模态 M 在 (o,𝒫) 下不可识别（定义 313），则任何基于 M 的校准曲线（可靠图）在 𝒫 上不可估：存在两组真值一致的标注使 ECE 估计相差 ≥ 1/K。故 **ECE<τ 只能作为「可识别子集上」的主张**；对不可识别子集，「模态校准达标」是不可证伪的伪命题。系：R69 的 MCG 门必须限定在 IDP 通过的样本上，否则门形同虚设。

**引理 20（ATDC 的标签效率）** A99（分离边际 δ_id>0）：ATDC 的期望信息增益是均匀采集的 Θ(1/δ_id²·log K) 倍；达到同一 ECE 精度，`N_ATDC = O((1/δ_id²)log(K/γ))`，`N_uni = Ω(K/δ_id²)`。要点：若 δ_id→0（模态不可分），两者增益都趋于 0——**此时正确的动作是停止采集、把该歧义判为 aleatoric，而不是采更多标签**。这与 R69 的「模糊不可分时应直接保守」是同一句话的数据侧版本。

**引理 21（说-做差的可校正性）** 若自陈噪声与意图独立（g_sd 有限），则行为代理标签的估计误差 ≤ g_sd 的 TV 上界；故在 g_sd>τ_sd 的域上自陈标签必须降权，否则校准被**系统性偏差**污染（不是随机噪声，无法靠增加样本量消除）。

**定理 18（接地可靠性：FLOOR 不能让系统更安全，但能阻止虚假自信）** 在定义 310–326 下：(i) FLOOR 不改变 RAS-WM† 的任何动作，故 ∀s，`risk_FLOOR(s) = risk_RAS†(s)`（安全平凡保持）；(ii) 对任意主张 c，GGG 通过时 c 的经验前提已复现，故以 c 为依据的下游主张不再携带隐藏假设；(iii) 若 c 未通过却被当作公理使用，RE-TRACE 必输出缺口，使「虚假自信」从静默变为显式。**结论：FLOOR 的价值不在控制风险，而在认知风险——它把「我们以为我们知道」变成「我们确知我们知道多少」。**

**定理 19（经验债守恒与加层禁令）** 若每轮净经验债不增（定义 320），则塔的总债务有界、不随层数爆炸；若某轮新增层的承重质量超过当轮退休量，则必须拒绝新增层（或将其整体标记 CONDITIONAL）。系：这条禁令是对 R66–R69「每轮加一层」模式的制度性刹车——**当算法创新的边际收益低于债务利息时，正确的动作是复现，不是再提出一个新缩写词。**

# IP-264/265 CEL + R-DAG
def build_cel(round_docs):
    nodes = [Claim(id=c.id, kind=('analytic' if c.proof else 'empirical'),
                   support=c.assumptions, deps=c.refs)
             for doc in round_docs for c in parse_claims(doc)]
    return CEL(nodes)

def load_bearing(cel):
    B = defaultdict(float)
    for c in reversed(cel.topo()):
        B[c.id] += cel.weight(c)
        for p in c.parents: B[p.id] += B[c.id]
    return B                                     # Pri = B*(1-kappa)/cost

# IP-266 MRB
def reproduce(unit, runner):
    outs  = [runner(unit.code, s, unit.data_snap) for s in unit.seeds]
    ok    = all(abs(o[unit.metric] - unit.ref) <= unit.tol for o in outs)
    return Status.REPRODUCED if ok and same_ranking(outs, unit.ref_ranking) \
           else Status.UNGROUNDED

# IP-267 IDP
def identifiability(o, modes, behavior_model):
    P = {m: behavior_model.distribution(o, m) for m in modes}
    return min(tv(P[i], P[j]) for i != j in modes) >= DELTA_ID

# IP-268 ATDC（U_epi 的对偶用法）
def collect(policy, stream, budget):
    log = []
    while budget.left and stream:
        o = max(stream, key=lambda o: policy.U_epi(o)*id_gain(o) - c_label(o))
        if not identifiability(o, policy.modes(o), behavior_model):
            stream.remove(o); log.append(('phantom', o)); continue
        log.append((o, behavior_label(o), provenance(o))); budget.spend(o)
    return Dataset(log)

# IP-272/273 GGG + J_FLOOR
def grounding_gate(cel, mrb, idp, pdl):
    debt0 = cel.debt()
    for c in cel.empirical_nodes():
        c.status = REPRODUCED if mrb.pass_(c) else UNGROUNDED
    for c in cel.analytic_nodes():
        c.status = (REPRODUCED
                    if all(p.status == REPRODUCED for p in c.emp_premises)
                    else CONDITIONAL)
    return J_FLOOR(valid=(cel.debt() <= debt0) and not pdl.alarm(),
                   debt_before=debt0, debt_after=cel.debt())

## 4. 推导

**引理 19（不可识别时 ECE 无意义）** 若 M 不可识别，则存在两组真值一致的标注使 ECE 估计相差 ≥ 1/K。故 ECE<τ 只是「可识别子集上」的主张；对不可识别子集，「模态校准达标」不可证伪。系：R69 的 MCG 门必须限定在 IDP 通过的样本上。

**引理 20（ATDC 标签效率）** A99 下 ATDC 期望增益为均匀采集的 Θ(1/δ_id²·log K) 倍；`N_ATDC=O((1/δ_id²)log(K/γ))`，`N_uni=Ω(K/δ_id²)`。若 δ_id→0，两者增益均趋于 0——此时应停止采集、判为 aleatoric，而非采更多标签。

**引理 21（说-做差可校正性）** 自陈噪声与意图独立时，行为代理标签误差 ≤ g_sd 的 TV 上界；g_sd>τ_sd 的域上必须降权，否则校准被系统性偏差污染（加样本无法消除）。

**定理 18（接地可靠性）** (i) FLOOR 不改变任何动作 ⇒ `risk_FLOOR ≡ risk_RAS†`（安全平凡保持）；(ii) GGG 通过后下游主张不再携带隐藏假设；(iii) 未通过却被当公理使用时 RE-TRACE 必报缺口 ⇒ 虚假自信由静默变显式。**价值在认知风险，不在控制风险。**

**定理 19（经验债守恒与加层禁令）** 每轮净经验债不增 ⇒ 总债务有界、不随层数爆炸；若某轮新增承重质量超过当轮退休量，则必须拒绝新增层或整体标 CONDITIONAL。系：这是对「每轮加一层」模式的制度性刹车——**当创新边际收益低于债务利息时，正确动作是复现，不是再提出一个新缩写词。**
