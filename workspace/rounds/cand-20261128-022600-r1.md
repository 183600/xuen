### 第 5 轮灵感驱动研究记录

**灵感词**：场景理解、域随机化

**继承关系**：第 4 轮 CADVS-v4（IP-489~492）在 v3 五锚点（3DCF/MSRG/HICK/EEK/LTEM + FFA）之上追加价值锚 VACK（kc_val）与平衡锚 BCK（kc_bal），形成七硬门 kc_evidence_forged_v4 = ∧_{i=1..7} kc_i，fail-closed；执行集 Exec_CADVS-v4 ⊆ Exec_CADVS-v3 ⊆ Exec_CADVS-v2 ⊆ Exec_CADVS-v1 ⊆ Exec_v29。本轮不推翻 v4，而是补两个「认知/分布」锚点：场景理解锚 SUK（kc_scene）与域随机化鲁棒锚 DRRK（kc_dr），并用场景条件随机化调度器 SCRD（IP-495）把二者桥接，形成 CADVS-v5（IP-493~496）。九硬门 kc_evidence_forged_v5 = ∧_{i=1..9} kc_i，执行集嵌套升级为 Exec_CADVS-v5 ⊆ Exec_CADVS-v4 ⊆ Exec_CADVS-v3 ⊆ Exec_CADVS-v2 ⊆ Exec_CADVS-v1 ⊆ Exec_v29。

**直觉与动机**：

1. **场景理解：从「空间覆盖」到「语义-可供性-物理属性理解」**。v3/v4 的 3DCF 只回答「这个空间位置我见过没有」（几何覆盖），却不知道「这里是什么、能做什么、有多重/多滑/多软」。一个区域可以被 100% 覆盖，却把透明玻璃杯误当空气、把湿滑地面误当干燥、把可变形物体误当刚体——覆盖通过而语义/物理全错。引入场景理解锚 SUK：输出场景图 G_s = (V, E, A, Φ)（对象、关系、可供性、物理属性区间），用 conformal prediction 校准语义置信度 σ_sem 与可供性置信度 σ_aff，用能量/密度比给 OOD 得分 ood。硬门 kc_scene 要求 σ_sem ≥ τ_sem、σ_aff ≥ τ_aff、ood ≤ τ_ood、物理属性落在可行域 Φ_plausible。直觉：证书不仅要「我看见过」，还要「我看懂了」。

2. **域随机化：从「标称物理通过」到「分布鲁棒通过」**。v4 的 MSRG/S2RC 在标称参数 θ_0 下证明物理可行，但真实世界是 θ 的一个分布：质量、摩擦、延迟、噪声、光照、纹理、位姿都在变。标称通过可能在分布偏移下大面积失效。引入域随机化鲁棒锚 DRRK：在场景条件分布 P_DR(·|G_s) 上采样 θ，估计规则成功率并给出置信下界 p_L（Clopper-Pearson）与尾部风险 CVaR_α，硬门 kc_dr 要求 p_L ≥ τ_dr 且 CVaR_α ≤ ε_cat。直觉：证书不是「在一点成立」，而是「在一片分布上以高置信成立」。

3. **二者是对偶的：场景理解决定「随机化什么」，域随机化回答「变了还成不成」**。这是本轮的核心洞见。若没有场景理解，随机化只能均匀撒胡椒面，把预算浪费在与任务无关的维度上，且在关键维度上覆盖不足（ε_phys 大）；若没有域随机化，场景理解给出的只是单点语义标签，无法回答分布偏移下的鲁棒性（ε_sem 无法转化为执行保证）。二者结合才能把「真实分布 P_R 与随机化分布 P_DR 的总变差距离 ε_scene」分解并控制：ε_scene ≤ ε_sem + ε_phys + ε_support + ε_est。任一缺失，分解中的对应项失控——这正是「场景-随机化互补完备性」。

4. **理论增量：场景-随机化分解定理**。把「仿真到现实」从口号变成可计算的界：E_{P_R}[S] ≥ p_L − ε_scene。场景理解压缩 ε_sem（语义误判）与 ε_est（估计误差），域随机化压缩 ε_phys（物理分布偏移）与 ε_support（支撑集空洞）。这为「九锚点缺一不可」提供了新的反例维度，也把 v4 的工程模块继续凝练为可发表的理论。

**关键洞见**：v4 的七锚点回答「覆盖/物理/人因/末点/记忆/价值/平衡」；v5 追加场景锚回答「我是否真正看懂了这个场景的语义与可供性」（SUK），分布锚回答「在场景条件化的参数分布下规则是否仍以高置信成立」（DRRK），并用 SCRD 让二者互为条件。九硬门 kc_evidence_forged_v5 = kc_coverage ∧ kc_scene ∧ kc_physics ∧ kc_dr ∧ kc_human ∧ kc_ee ∧ kc_bal ∧ kc_mem ∧ kc_val，fail-closed；软评分 ECS_v5 = ECS_v4 · η_scene · η_dr。

**形式化目标（增量）**：
1. 定义场景理解证书 SCN = (σ_sem, σ_aff, φ, ood, fp, t)，及硬门 kc_scene = (σ_sem ≥ τ_sem ∧ σ_aff ≥ τ_aff ∧ ood ≤ τ_ood ∧ φ ∈ Φ_plausible)，软因子 η_scene = σ_sem · σ_aff · (1 − ood)。
2. 定义随机化参数空间 Θ = Θ_phys × Θ_sens × Θ_scene 与场景条件分布 P_DR(·|G_s)。
3. 定义域随机化证书 DRC = (p_L, n, cvar, θ_worst, t)，及硬门 kc_dr = (p_L ≥ τ_dr ∧ cvar ≤ ε_cat)，软因子 η_dr = p_L。
4. 定义 SCRD：由场景图计算因子相关权重 ρ_j(G_s)、预算分配 b_j ∝ ρ_j、构造 P_DR(·|G_s)、估计支撑空洞 ε_support。
5. 定义场景-随机化分解定理：E_{P_R}[S] ≥ p_L − ε_scene，ε_scene ≤ ε_sem + ε_phys + ε_support + ε_est。
6. 定义 EFA-v5 九硬门 + 软评分 ECS_v5 = ECS_v4 · η_scene · η_dr。
7. 定义 Exec_CADVS-v5 ⊆ Exec_CADVS-v4：在 v4 每条路径上追加 kc_scene（感知/规则准入时）与 kc_dr（规则准入离线），故只缩不涨。

**本轮最大风险**：场景理解与域随机化可能共同制造「分布内错觉」——当真实世界落入随机化支撑集之外时，场景理解的高置信度会把 OOD 误判为 ID，使 p_L 再高也只覆盖了一个错误的分布，九硬门在系统性域偏移下整体 fail-open（伪安全）。

### IP-493 SUK：场景理解核（感知回路 30–60 Hz，异步于 1 kHz 控制环）

```python
@dataclass
class SceneUnderstandingKernel:
    """SUK：语义-可供性-物理属性理解 + conformal 校准 + OOD；kc_scene 硬门"""
    tau_sem: float = 0.8
    tau_aff: float = 0.7
    tau_ood: float = 0.5
    conf_alpha: float = 0.1
    semantic_model: Any = None       # 开放词汇分割/检测（可校准）
    affordance_head: Any = None      # 可供性头（抓/推/倒/开）
    physical_head: Any = None        # 质量/摩擦/柔顺区间回归
    conformal_calib: Any = None      # 校准集与 p-value 计算
    phys_plausible: Any = None       # Φ_plausible 约束

    def perceive(self, rgbd, tactile, proprio, t_now: float) -> SCN:
        G_s = self._scene_graph(rgbd, tactile, proprio)       # V,E,A
        sigma_sem = 1.0 - self.conformal_calib.p_value(G_s)   # 校准置信
        sigma_aff = self._affordance_conf(G_s)
        phi = self._physical_attrs(G_s)                       # 区间 [φ_lo, φ_hi]
        ood = 1.0 - self._ood_pvalue(rgbd, G_s)               # 能量/密度比校准
        return SCN(sigma_sem=sigma_sem, sigma_aff=sigma_aff,
                   phi=phi, ood=ood, fp=hash_canonical(G_s), t=t_now)

    def kc_scene(self, scn: SCN) -> bool:
        """引理 43：通过 ⟹ 语义覆盖率达标、OOD 在支持内、物理属性可信"""
        return (scn.sigma_sem >= self.tau_sem
                and scn.sigma_aff >= self.tau_aff
                and scn.ood <= self.tau_ood
                and self.phys_plausible.contains(scn.phi))

    def _scene_graph(self, rgbd, tactile, proprio): ...
    def _affordance_conf(self, G_s) -> float: ...
    def _physical_attrs(self, G_s): ...
    def _ood_pvalue(self, rgbd, G_s) -> float: ...
```

### IP-494 DRRK：域随机化鲁棒核（规则准入离线，秒–分钟级）

```python
@dataclass
class DomainRandomizationRobustnessKernel:
    """DRRK：场景条件域随机化 + 置信下界 + 尾部风险；kc_dr 硬门"""
    tau_dr: float = 0.9
    n_samples: int = 2000
    conf_alpha: float = 0.05
    cvar_alpha: float = 0.05
    eps_cat: float = 0.01
    scr: SceneConditionedRandomizationDirector = None   # IP-495
    simulator: Any = None

    def certify(self, rule, scn: SCN, t_now: float) -> DRC:
        dist = self.scr.condition(scn)                    # P_DR(·|G_s)
        thetas = dist.sample(self.n_samples)              # θ ~ P_DR(·|G_s)
        outcomes = np.array([self._rollout(rule, th) for th in thetas])
        k = int(outcomes.sum())
        p_l = clopper_pearson_lower(k, self.n_samples, self.conf_alpha)
        cvar = self._cvar(outcomes, self.cvar_alpha)      # 尾部条件风险
        theta_worst = thetas[int(np.argmin(outcomes))]
        return DRC(p_l=p_l, n=self.n_samples, cvar=cvar,
                   theta_worst=theta_worst, t=t_now)

    def kc_dr(self, drc: DRC) -> bool:
        """引理 44：通过 ⟹ 真实成功率以 1−α 置信 ≥ p_L，且尾部风险受控"""
        return drc.p_l >= self.tau_dr and drc.cvar <= self.eps_cat

    def _rollout(self, rule, theta) -> int: ...
    def _cvar(self, outcomes, alpha) -> float: ...
```

### IP-496 EFA-v5：九硬门 + 软评分 + 证据铸造流水线 v5

```python
@dataclass
class EvidenceForgingAssemblerV5:
    """EFA-v5：九硬门 fail-closed；ECS_v5 = ECS_v4 · η_scene · η_dr"""
    scf: SpatialCoverageFieldKernel
    msrg_cache: dict
    hic: HumanIntentCertificateKernel
    eek: EndEffectorFidelityKernel
    ltem: LongTermEpisodicMemory
    vack: ValueAlignmentCertificateKernel
    bck: BalanceControlKernel
    suk: SceneUnderstandingKernel
    drrk: DomainRandomizationRobustnessKernel
    mu_S: float = 0.75
    w: tuple = (0.4, 0.4, 0.2)

    def hard_gate(self, x, t_now, rule_id, hic, eec: EEC, bcc: BCC,
                  scn: SCN, drc: DRC, object_class, geo_sig,
                  theta_domain_fp, traj: Trajectory, context: Context) -> tuple[bool, str]:
        # 优先级：HIC veto > 其余八硬门（并行评估，任一失败即拒）
        if self.hic.veto_active(hic):            return False, 'HIC_STOP'
        if not self.scf.kc_coverage(x, t_now):   return False, 'COVERAGE_BLIND'
        if not self.suk.kc_scene(scn):           return False, 'SCENE_UNUNDERSTOOD'
        s2rc = self.msrg_cache.get(rule_id)
        if s2rc is None or s2rc.verdict != 'accept' or s2rc.mu_pass < self.mu_S:
            return False, 'PHYSICS_UNPROVEN'
        if not self.drrk.kc_dr(drc):             return False, 'DR_UNROBUST'
        if not self.eek.kc_ee(eec):              return False, 'EE_UNPROVEN'
        if not self.bck.kc_bal(bcc):             return False, 'BALANCE_UNSTABLE'
        pass_mem, eta_mem, novelty = self.ltem.query(
            object_class, geo_sig, theta_domain_fp, rule_id, scn.fp)
        if not pass_mem:                         return False, 'MEMORY_REJECT'
        vac = self.vack.evaluate(traj, context, t_now)
        if not self.vack.kc_val(vac):            return False, 'VALUE_MISALIGNED'
        return True, 'FORGED' + ('|NOVELTY' if novelty else '')

    def ecs_v5(self, x, t_now, rule_id, A_att=0.0, eta_mem=0.5,
               eta_val=0.5, eta_bal=0.5, eta_scene=0.5, eta_dr=0.5) -> float:
        return (self.ecs_v4(x, t_now, rule_id, A_att, eta_mem, eta_val, eta_bal)
                * eta_scene * eta_dr)
```

```
       ──▶ VACK.evaluate ──▶ kc_val
       ──▶ EFA-v5.hard_gate（含 ltem.query）──▶ KC 库 v+1（Bonferroni α_eff=α/m）

在线控制环（1 kHz）：
  每周期：
    EEK → EEC → kc_ee
    BCK → BCC → kc_bal
    EFA-v5.hard_gate(x, t, rule, hic, eec, bcc, cached_scn, cached_drc, ...)
      ├─ HIC_STOP            → S_stop
      ├─ COVERAGE_BLIND      → 回退 STCK + 教师
      ├─ SCENE_UNUNDERSTOOD  → 主动感知（换视角/触探）+ 教师    ← 新增
      ├─ PHYSICS_UNPROVEN    → 规则降权
      ├─ DR_UNROBUST         → 规则降权/重随机化 + 教师          ← 新增
      ├─ EE_UNPROVEN         → 末端复位/重触 + 教师
      ├─ BALANCE_UNSTABLE    → 阻抗软化/回退姿态 + 教师
      ├─ MEMORY_REJECT       → 教师介入或重新 MSRG
      └─ VALUE_MISALIGNED    → 价值对齐修正/教师介入
```

## 3. 复杂度分析（增量更新）

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 | 实时性指标 |
|---|---|---|---|---|
| SUK perceive | O(N_obj²) 关系图 / O(N_obj) 注意力 | O(N_obj·d) | N_obj=对象数, d=特征维 | ~10–30 ms（30–60 Hz 异步） |
| SUK kc_scene | **O(1)** | O(1) | — | < 0.01 ms |
| SCRD condition | O(\|factors\| + N_obj) | O(\|factors\|) | 因子数 5–10 | 秒级（离线） |
| DRRK certify | O(n_samples · T_rollout) | O(n_samples) | n=2000, T_rollout | 秒–分钟级（离线准入） |
| DRRK kc_dr | **O(1)** | O(1) | — | < 0.01 ms |
| EFA-v5 硬门 | **O(1)** | O(1) | — | < 0.04 ms（不含 SUK/DRRK 观测） |
| 控制环增量（v4→v5） | **O(1)** | O(1) | 读缓存 SCN/DRC | **< 0.02 ms** |
| v4 既有（EEK/BCK/LTEM/VACK） | — | — | — | 见 v4 表 |

**通信开销**：SCN 仅感知回路产生、控制环读缓存（~200 B/帧）；DRC 仅规则准入产生（低频，~1 KB/规则）；FFA Δ_i 扩充至 ~6–12 KB/站点；DR rollout 不产生站点间通信（仿真在本地/服务器）。

**实时性缓解（回应 v4 R49）**：
- SUK 完全异步于 1 kHz 控制环，控制环仅 O(1) 读取缓存 SCN 与 kc_scene 结果。
- DRRK 完全离线（规则准入），不进入控制环；kc_dr 仅 O(1) 读取缓存 DRC。
- 因此 v5 对控制环的净增量 < 0.02 ms，v4 的实时性风险不被放大。

## 4. 正确性论证（增量更新）

### 引理 43（场景语义 conformal 覆盖率）

**陈述**：设校准集与测试场景可交换（exchangeable）。对任意显著性 α_sem，conformal 预测集 C_{1−α_sem}(X) 满足 P(Y ∈ C_{1−α_sem}(X)) ≥ 1−α_sem。定义 σ_sem = 1 − p_conf，其中 p_conf 为真实标签的 conformal p-value。则 kc_scene 通过（σ_sem ≥ τ_sem）⇒ 以概率 ≥ τ_sem 真实语义标签位于预测集内；OOD 部分由 conformal p_ood 控制误纳率 ≤ 1−τ_ood。

**证明**：由 conformal prediction 的边际覆盖定理，p_conf ≤ 1−τ_sem ⇒ P(Y ∈ C) ≥ τ_sem；OOD 由同一 p-value 机制对「分布内」零假设做检验，第一类错误 ≤ 1−τ_ood。∎

**工程含义**：把「语义置信」从不可校准的 softmax 概率升级为有分布保证的覆盖率；σ_sem 是可审计的，而非模型自报。

### 引理 44（DR 成功率的置信下界与尾部风险）

**陈述**：设 n 次独立同分布 rollout，k 次成功。Clopper-Pearson 下界 p_L 满足 P(p ≥ p_L) ≥ 1−α_conf。若进一步要求 CVaR_α ≤ ε_cat，则 kc_dr 通过 ⇒ 以概率 ≥ 1−α_conf，真实分布成功概率 p ≥ τ_dr，且最坏 α 尾部的条件期望失败率 ≤ ε_cat。

**证明**：Clopper-Pearson 基于二项分布的精确覆盖给出单侧下界；CVaR 由经验尾部估计加 DKW/集中不等式给出有限样本上界。∎

**工程含义**：把「域随机化成功」从点估计升级为带置信与尾部约束的证书；避免「平均成功率很高但少数灾难场景」被平均掩盖。

### 定理 5（场景-随机化分解定理）

**陈述**：设 (C1) conformal 校准有效；(C2) rollout i.i.d. 来自 P_DR(·|G_s)；(C3) 真实部署分布 P_R 满足 d_TV(P_R, P_DR(·|G_s)) ≤ ε_scene；(C4) ε_scene ≤ ε_sem + ε_phys + ε_support + ε_est。则对任意有界成功指示 S∈[0,1]，以概率 ≥ 1−α_conf：
E_{P_R}[S] ≥ p_L − ε_scene。
且该分解在「缺 SUK」或「缺 DRRK」时分别由 ε_sem 或 ε_phys+ε_support 失控，故两锚点对控制 ε_scene 均必要。

**证明**：对任意 f∈[0,1] 与分布 P,Q，有 |E_P f − E_Q f| ≤ d_TV(P,Q)。取 f=S、P=P_R、Q=P_DR，得 E_{P_R}[S] ≥ E_{P_DR}[S] − ε_scene ≥ p_L − ε_scene（后者由引理 44 以 1−α_conf 成立）。分解由三角不等式与各分量定义直接得到；必要性由 0.2 节与 R53~R55 的反例构造。∎

**工程含义**：首次把「仿真到现实」的落差拆成四个可分别度量、可分别优化的项：语义（SUK 管）、物理分布（DRRK 管）、支撑空洞（SCRD 的 support_gap 管）、估计误差（校准/样本量管）。这比 v4 的「单点物理通过」强得多，也解释了为何两个灵感词必须同时引入。

### 定理 v5（执行集严格收缩与九锚点完备）

**陈述**：在 (C1)~(C5) 与 v4 的 (B1)~(B6) 下：
(i) Exec_CADVS-v5 ⊆ Exec_CADVS-v4 ⊆ … ⊆ Exec_v29（严格收缩）；
(ii) 场景误纳率由引理 43 界；
(iii) 真实分布成功率的 sim2real 落差由定理 5 界；
(iv) 证书演算构成九原子有界分配格，九硬门合取为最大下界，fail-closed；
(v) 九锚点互补完备：去任一锚点均可构造反例使某 ε 项失控或安全违例；
(vi) 控制环净增量 < 0.02 ms，v4 的实时性风险不被放大。

**证明**：(i) v5 在 v4 每条路径上追加 kc_scene（准入/感知时）与 kc_dr（准入离线），只缩不涨；严格性由两硬门非恒真保证。(ii)(iii) 分由引理 43、定理 5。(iv) 由 v4 定理 1 的格结构向九原子平凡扩展。(v) 逐锚点反例见 R53~R59。(vi) 由 SUK/DRRK 的异步化与缓存读取设计。∎

**诚实声明**：(C1) conformal 交换性假设在真实分布持续漂移时失效；(C3) 的 d_TV 上界在实践中只能估计，无法精确验证；(C4) 的 ε_support 是估计量本身，存在「估计器也 OOD」的递归风险。因此定理 5 给出的是「条件性保证」，而非无条件安全证明。

### 5.1 实验设计

- **平台**：MuJoCo 3.x + MJX（仿真）+ NVIDIA Isaac Sim（高保真渲染与 DR）+ N 台实机 Panda（舰队，N=3~5）+ 透明/反光/可变形物体测试集 + 人类偏好标注平台。

  (a) 语义 OOD 注入：新颖物体、对抗纹理、透明/镜面、遮挡与反光；

## 7. 本轮最大风险（最终确认）

**一句话**：**场景理解与域随机化可能共同制造「分布内错觉」**——当真实世界落入随机化支撑集之外时，场景理解的高置信度会把 OOD 误判为 ID，使 p_L 再高也只覆盖了一个错误的分布，九硬门在系统性域偏移下整体 fail-open（伪安全）。
