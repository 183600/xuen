# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC IP-153~160；新灵感循环第 1 轮；本轮灵感：「Gazebo」×「材料选型」）

> 第 60 轮把「执行层→证据层」升级为「认知驱动的场景-执行闭环」：SSM 场景语义、CIEC 认知意图、EPIR ROS 因果隔离、SERC、SIC、CESC、PCE++++。但三个关键局限仍在：
> 1. **材料是「被给定的常量」**：SSM 的场景先验 π_scene(K|z) 与 EEIS 的 K_safe 都默认接触界面参数（μ, k_n, c_n, e）已知且稳定；而真实末端垫片、抓取面、轮面是可替换的物理材料，其参数直接决定「可达安全阻抗空间」的形状——前 60 轮从未把材料选型当作决策变量。
> 2. **Gazebo 的 sim-to-real 材料鸿沟未被结构性处理**：Gazebo 的 SDF `<surface>` 只给名义接触参数，软材料刚度/阻尼误差可达 30–50%；现有做法是域随机化加事后验证，把材料误差当成「必须估计的噪声」，成本高且无保证。
> 3. **材料会漂移，证书会静默失效**：磨损、温升、污染使 θ_real 随时间漂移，第 59 轮的 J_exec 与第 60 轮的 SIC 均假设材料参数静态；一旦漂移，之前「合规」的 K_safe 会静默越界。

## 0. 直觉与动机

**灵感 1（Gazebo → 材料扰动实验台 MPT）**
直觉：Gazebo 不是「真相 oracle」，而是**可控的材料参数扰动台**。SDF 的 `<surface><friction><ode>` 让我们能对同一轨迹做「只改材料、其余全同」的配对 rollout（common random numbers, CRN）。由此可估计执行证书对材料参数的**敏感度矩阵** S(m)=∂J_exec/∂θ，而不只是看一次仿真是否成功。关键洞见：**仿真器最有价值的输出不是「成功/失败」，而是「哪个材料参数方向会改变执行结果」**。

**灵感 2（材料选型 → 仿真不敏感材料选择 LMS）**
直觉（Taguchi 稳健设计 × sim-to-real）：与其花预算去估计 θ_real，不如**选一种让执行结果对 θ 不敏感的材料**。若 J_exec 对 θ 的 Lipschitz 常数为 L(m)，则 sim-real 执行差 ≤ L(m)·W₂(Θ_sim,Θ_real)。因此材料选型能把「不可消除的参数鸿沟」压缩成「可被硬件选择消除的执行鸿沟」。关键洞见：**参数空间的距离不重要，被 J_exec push-forward 后的执行空间距离才重要**——选材料就是选一个使 push-forward 收缩的映射。

**灵感 3（选型 × 证据 → 材料证据闭环 MEC）**
直觉：真实 EV-exec 的接触力/速度轨迹是材料参数的**似然证据**。用贝叶斯更新 p(θ|EV-exec)，并在残差上跑 CUSUM 检测材料漂移（磨损/温升）；漂移超阈值再触发重选。关键洞见：**材料不是一次性选型，而是随证据维护的「活参数」**——但重选必须带滞回与最小驻留时间，否则会「材料抖动」。

**灵感 4（三灵感合流 → 材料-场景-阻抗协同 MESC）**
直觉：场景 z 决定所需接触 regime（湿滑地面要高摩擦、精密装配要低冲击），材料 m 决定可达 K_safe(m,z) 与敏感度 L(m)。三者构成**场景-材料-阻抗三元协同**：z→候选材料→鲁棒 K_safe→执行→EV-exec→材料后验→z 更新。关键洞见：**联合决策比串联决策安全**——先选材料再编译阻抗会锁死可行域，应该在同一鲁棒可行域内联合优化。

**灵感 5（预算 → PCE+++++ 材料-仿真预算）**
直觉：第 60 轮四维认知预算要再加两维：B_sim（Gazebo rollout 次数、敏感度估计精度）与 B_mat（材料库存/换装次数/换装时延）。B_sim 耗尽⇒用 Lipschitz 上界替代数值敏感度（保守）；B_mat 耗尽⇒复用当前材料加保守阻抗；其余沿用第 60 轮降级链。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（材料接触模型与目录 MCM）** 材料目录 M = {(m_i, θ_i^nom, Σ_i, c_i^unit, τ_i^swap)}。接触参数 θ = (μ_s, μ_k, e, k_n, c_n, E)，其中 μ_s/μ_k 为静/动摩擦、e 为恢复系数、k_n 为法向接触刚度、c_n 为接触阻尼、E 为弹性模量。SDF 嵌入 Ψ：Gazebo `<surface>` 参数 → 接触模型。真实参数的不确定集 Θ_i^α = {θ : (θ−θ_i^nom)^T Σ_i^{-1}(θ−θ_i^nom) ≤ χ²_{α,6}}。换装算子 σ：机器人在 τ_i^swap 内切换末端材料 i。

**定义 162（Gazebo 材料扰动实验台 MPT）** 给定任务轨迹 τ 与材料 m，配对 rollout 算子 G_ε(m,d) 在 θ=θ_nom+εd 下以相同随机种子重放，输出执行指标向量 J_exec。敏感度矩阵：
```
S(m) = [ (J(θ_nom+εe_j) − J(θ_nom−εe_j)) / (2ε) ]_{j=1..6}
L̂(m) = || S(m) Σ^{1/2} ||_2
```
**材料零空间** N(m)=ker(S(m)Σ^{1/2})：落在此空间的 sim-real 参数差在执行空间不可见。**敏感谱** svd(S(m)Σ^{1/2}) 的前 k 个右奇异向量给出「真正要紧」的材料参数方向（active subspace）。

**定义 163（仿真不敏感材料选型 LMS）** 对场景 z，鲁棒安全阻抗集：
```
K_safe^rob(m,z) = { K : ∀θ∈Θ^α, C(K,θ,z) 成立 }
ρ(m,z) = max_K min_{θ∈Θ^α} margin(K,θ,z)
```
选型规则：
```
m*(z) = argmin_{m∈M} L̂(m)
s.t.  K_safe^rob(m,z) ≠ ∅,  ρ(m,z) ≥ ρ_min,
      c_i^unit + λ_swap·τ_i^swap ≤ C_max
```
等价 Pareto 形式：`max_m [ ρ(m,z) − λ_L L̂(m) − λ_C c(m) ]`。
**定理（执行空间收缩）**：若 J_exec 对 θ 在 Θ^α 上 L(m)-Lipschitz，则
```
W₂(J_exec#P_sim, J_exec#P_real) ≤ L(m)·W₂(P_sim, P_real)
```
因此 min_m L̂(m) 给出与参数分布形式无关的 sim-real 执行差上界。

**定义 164（材料鲁棒执行证书 MRC）** 证书 J_mat(m,K,z) = (L̂(m), ρ(m,z), δ_θ=W₂(P_sim,P_real), ε_bound=L̂(m)δ_θ)。J_mat 有效当且仅当 `ρ(m,z)>0 ∧ ε_bound ≤ ε_exec^max`。J_mat 与 J_exec 绑定：J_exec 的有效性从「数值合规」升级为「对材料不确定集一致合规」。

**定义 165（材料证据闭环 MEC）** 真实 EV-exec 给出接触轨迹 D_real。似然 L(θ)=p(D_real|θ)，后验 p(θ|D_real)∝L(θ)p(θ)。材料后验价值：
```
V(m) = E_{θ~p(θ|D_real)}[J_exec(m,θ)] − λ_v·Var_{θ}[J_exec(m,θ)]
```
漂移检测：残差 r_t=F_real−F_sim(θ_t)，双侧 CUSUM：
```
g_t^± = max(0, g_{t−1}^± ± r_t − ν)
```
若 max g_t^± > h_drift，标记材料漂移。

**定义 166（材料漂移重选 MDR）** 设漂移后提案材料 m'，换装收益 `Δ(m→m')=V(m')−V(m)−c_swap`。重选当且仅当 Δ>0，且漂移持续 k 个窗口，且距上次换装 ≥ T_dwell（防抖）。引入「材料抖动率」Jitter = 换装次数/任务时长，作为约束。

**定义 167（材料-场景-阻抗协同 MESC）** 算子 MESC(M, z, task, B)：
```
① z ← SSM.update(telemetry)
② M_c ← {m ∈ M : π(z,m) ≥ τ_π}
③ for m ∈ M_c: (K_safe^rob(m,z), L̂(m)) ← MPT + EEIS_robust
④ (m*,K*) ← LMS(M_c,z) 与 EEIS 联合鲁棒编译
⑤ dispatch(m*, K*, J_mat)
⑥ execute；EV-exec ← build_exec_evidence()
⑦ MEC.update(EV-exec); z ← SSM.update(EV-exec)
⑧ if MDR.trigger(): m* ← re-select; dispatch
⑨ return (m*, K*, J_mat, MEC.status)
```

**定义 168（PCE+++++ 材料-仿真预算）** B = (B_sim, B_mat, B_cog, B_exec)：
- `B_sim = (N_rollout, ε_fd, Active_subspace_dim)`
- `B_mat = (Inventory, Swap_limit, Dwell_time)`
- B_cog、B_exec 沿用第 60 轮。
VOI：
```
voi_mat(π) = VOI_meta_pessimistic(π) − cost_sim(π) − cost_mat(π) − cost_cog(π) − cost_exec(π)
cost_sim = λ_roll·N_rollout + λ_fd/ε_fd
cost_mat = λ_swap·n_swap + λ_inv·|inventory|
```
若 B_sim 耗尽⇒`L̂^UCB = L̂ + κ√(2log(1/δ)/N_rollout)` 保守上界；若 B_mat 耗尽⇒复用当前 m 并收紧 K_safe；其余降级沿用第 60 轮。

                cost=8.0, swap_time=0.6),
        }

    def to_sdf(self, m):
        x = self.materials[m]
        return f'''<surface><friction><ode>
          <mu>{x.mu_k}</mu><mu2>{x.mu_s}</mu2>
        </ode></friction>
        <contact><ode>
          <kp>{x.k_n}</kp><kd>{x.c_n}</kd>
          <max_vel>0.01</max_vel><min_depth>0.001</min_depth>
        </ode></contact>
        <bounce><restitution_coefficient>{x.e}</restitution_coefficient></bounce>
        </surface>'''

    def uncertainty_set(self, m, alpha=0.95):
        x = self.materials[m]
        return Ellipsoid(center=x.theta, shape=x.sigma, alpha=alpha)

### IP-162 MPT（Gazebo 材料扰动实验台）

```python
class GazeboMaterialPerturbationTestbed:
    def __init__(self, world, task, catalogue, eps=1e-3):
        self.world = world
        self.task = task
        self.catalogue = catalogue
        self.eps = eps

    def paired_rollout(self, m, direction):
        theta0 = self.catalogue.materials[m].theta
        seed = stable_hash((m, tuple(np.round(direction, 8)))) & 0xffffffff
        self._load_material(m)
        J_plus = self._rollout(theta0 + self.eps * direction, seed)
        J_minus = self._rollout(theta0 - self.eps * direction, seed)
        return (J_plus - J_minus) / (2.0 * self.eps)

    def sensitivity(self, m, n_roll=1):
        x = self.catalogue.materials[m]
        d = len(x.theta)
        S = np.zeros((len(self.task.metrics), d))
        for j in range(d):
            e_j = np.eye(d)[j]
            S[:, j] = np.mean(
                [self.paired_rollout(m, e_j) for _ in range(n_roll)], axis=0)
        W = sqrtm(x.sigma)
        S_w = S @ W
        L_hat = np.linalg.norm(S_w, 2)
        U, sv, Vt = np.linalg.svd(S_w, full_matrices=True)
        null_space = Vt[len(sv):].T
        return Sensitivity(
            S=S, sigma=sv, L_hat=L_hat,
            null_space=null_space, active_dirs=Vt[:3].T,
            n_roll=n_roll)
```

### IP-163 LMS（仿真不敏感材料选型）

```python
class LipschitzMaterialSelector:
    def __init__(self, catalogue, mpt, eeis, rho_min=0.05,
                 lambda_L=1.0, lambda_C=0.05):
        self.catalogue = catalogue
        self.mpt = mpt
        self.eeis = eeis
        self.rho_min = rho_min
        self.lambda_L = lambda_L
        self.lambda_C = lambda_C

    def select(self, z, alpha=0.95, budget=None, delta=0.05):
        best = None
        for m, x in self.catalogue.materials.items():
            if not self._scene_compatible(z, m):
                continue
            theta_set = self.catalogue.uncertainty_set(m, alpha)
            K_rob, rho = self.eeis.compile_robust(z, theta_set)
            if K_rob is None or rho < self.rho_min:
                continue
            sens = self.mpt.sensitivity(m)
            L_ucb = sens.L_hat
            if budget is not None and budget.sim_exhausted:
                L_ucb += math.sqrt(2.0 * math.log(1.0 / delta)
                                   / max(1, budget.n_roll_used))
            c = x.cost + self.lambda_C * x.swap_time
            score = rho - self.lambda_L * L_ucb - c
            if best is None or score > best.score:
                best = MaterialSelection(
                    m=m, K=K_rob, rho=rho, L_hat=L_ucb,
                    null_space=sens.null_space, score=score)
        return best
```

### IP-164 MRC（材料鲁棒执行证书）

```python
class MaterialRobustCertificate:
    @staticmethod
    def issue(sel, delta_theta, eps_max, alpha=0.95):
        eps_bound = sel.L_hat * delta_theta
        valid = (sel.rho > 0.0) and (eps_bound <= eps_max)
        return {
            'material': sel.m,
            'K_safe': sel.K,
            'L_hat': sel.L_hat,
            'rho': sel.rho,
            'alpha': alpha,
            'delta_theta': delta_theta,
            'eps_bound': eps_bound,
            'null_space_dim': sel.null_space.shape[1],
            'valid': valid,
        }
```

### IP-165 MEC（材料证据闭环与漂移检测）

```python
class MaterialEvidenceClosure:
    def __init__(self, prior, noise_cov, lambda_v=0.1,
                 drift_h=4.0, drift_nu=0.5):
        self.posterior = prior
        self.R = noise_cov
        self.lambda_v = lambda_v
        self.drift_h = drift_h
        self.drift_nu = drift_nu
        self.g_plus = 0.0
        self.g_minus = 0.0

    def update(self, ev_exec, material):
        D = ev_exec.contact_trajectory

        def loglik(theta):
            r = D - contact_model(theta, ev_exec.command)
            return -0.5 * r.T @ np.linalg.inv(self.R) @ r

        self.posterior = bayes_update(self.posterior, loglik, D)
        r = ev_exec.F_real - contact_model(self.posterior.mean, ev_exec.command)
        self.g_plus = max(0.0, self.g_plus + r - self.drift_nu)
        self.g_minus = max(0.0, self.g_minus - r - self.drift_nu)
        drift = max(self.g_plus, self.g_minus) > self.drift_h
        return drift

    def value(self, material, n=64):
        samples = self.posterior.sample(n)
        J = np.array([exec_metric(material, th) for th in samples])
        return J.mean() - self.lambda_v * J.var()
```

### IP-166 MDR（材料漂移重选）

```python
class MaterialDriftReselection:
    def __init__(self, dwell=30.0, k_windows=3, c_swap=1.0):
        self.dwell = dwell
        self.k_windows = k_windows
        self.c_swap = c_swap
        self.last_swap = -math.inf
        self.drift_windows = 0

    def should_reselect(self, now, drift, m_cur, m_new, mec):
        self.drift_windows = self.drift_windows + 1 if drift else 0
        if self.drift_windows < self.k_windows:
            return False
        if now - self.last_swap < self.dwell:
            return False
        gain = mec.value(m_new) - mec.value(m_cur) - self.c_swap
        if gain <= 0.0:
            return False
        self.last_swap = now
        self.drift_windows = 0
        return True
```

### IP-167 MESC（材料-场景-阻抗协同闭环）

```python
def material_scene_execution_loop(M, task, budget):
    M.scene_model.update(M.telem_force, M.telem_pos)
    z = M.scene_model.get_scene_distribution()
    candidates = [m for m in M.catalogue.materials if M.scene_compatible(z, m)]

    best = None
    for m in candidates:
        theta_set = M.catalogue.uncertainty_set(m, alpha=0.95)
        K_rob, rho = M.eeis.compile_robust(z, theta_set)
        if K_rob is None or rho < M.rho_min:
            continue
        sens = M.mpt.sensitivity(m)
        L_ucb = sens.L_hat + (budget.sim_ucb(delta=0.05)
                              if budget.sim_exhausted else 0.0)
        score = rho - M.lambda_L * L_ucb - M.lambda_C * M.catalogue.materials[m].cost
        if best is None or score > best.score:
            best = MaterialSelection(m, K_rob, rho, L_ucb, sens.null_space, score)

    if best is None:
        return DEGRADE_EXEC

    cert = MaterialRobustCertificate.issue(
        best, delta_theta=budget.delta_theta, eps_max=M.eps_exec_max)
    if not cert['valid']:
        best = M.conservative_material()
        cert = MaterialRobustCertificate.issue(
            best, budget.delta_theta, M.eps_exec_max)

    M, fused, D_plus, ev_exec, cert_exec = closed_loop_exec_probe(
        M, M.current_cp, task.delta_f_req, budget)

    drift = M.mec.update(ev_exec, best.m)
    if drift:
        m_new = M.selector.select(z, budget=budget)
        if M.mdr.should_reselect(M.now, drift, best.m, m_new.m, M.mec):
            best = m_new
            dispatch_material(best.m, M.catalogue)
            dispatch_impedance_params(best.K.best, cert_exec)

    M.epir.append(ev_exec.__dict__)
    return M, best, cert, drift, fused, D_plus
```

### IP-168 PCE+++++（材料-仿真预算）

```python
class MaterialSimBudget:
    def __init__(self, n_roll=64, swap_limit=5, dwell=30.0,
                 cog=None, exec_b=None):
        self.n_roll = n_roll
        self.n_roll_used = 0
        self.swap_limit = swap_limit
        self.n_swap = 0
        self.dwell = dwell
        self.B_cog = cog
        self.B_exec = exec_b
        self.delta_theta = 0.15

    @property
    def sim_exhausted(self):
        return self.n_roll_used >= self.n_roll

    @property
    def mat_exhausted(self):
        return self.n_swap >= self.swap_limit

    def sim_ucb(self, delta=0.05, kappa=1.0):
        n = max(1, self.n_roll_used)
        return kappa * math.sqrt(2.0 * math.log(1.0 / delta) / n)

    def degrade_level(self):
        if self.mat_exhausted:
            return 'reuse_material_conservative_K'
        if self.sim_exhausted:
            return 'lipschitz_upper_bound'
        if self.B_cog is not None and self.B_cog.exhausted:
            return 'general_scene_prior'
        if self.B_exec is not None and self.B_exec.exhausted:
            return 'exec_degrade'
        return 'normal'
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| MCM | O(\|M\|·d) | O(\|M\|·d) | 目录覆盖真实材料，Σ 为 1-α 置信椭球 |
| MPT | O(N_roll·d·T_sim) | O(k·d) | 敏感度误差 O(ε + σ_sim/√N_roll) |
| LMS | O(\|M\|·(C_EEIS + N_roll·d·T_sim)) | O(\|M\|·k·d) | sim-real 执行差 ≤ L̂·δ_θ |
| MRC | O(1) | O(k·d) | 若 valid，则 ∀θ∈Θ^α 约束成立 |
| MEC | O(N_p·d) / 更新 | O(N_p·d) | 后验覆盖率 ≥ 1−β |
| MDR | O(1) / 步 | O(k) | 抖动率 ≤ Swap_limit / T |
| MESC | O(闭环) | 复用 | 场景静态时闭环收敛 |

**数量级示意（合成数据，非实测）**：

| 材料 | k_n (N/m) | μ_k | 主要不确定方向 | 合成 L̂ | 读法 |
|---|---:|---:|---|---:|---|

**正确性定理（MESC-C）**：
假设 A66–A70 成立：**(A66)** MPT 用 CRN 配对 rollout，有限差分梯度估计无偏，误差 O(ε+σ_sim/√N_roll)；**(A67)** J_exec 在 Θ^α 上 L-Lipschitz；**(A68)** EEIS_robust 在 Θ^α 上返回非空 K_safe^rob 且裕度 ρ≥ρ_min；**(A69)** MEC 后验校准，θ_real 以概率 ≥1−β 落在后验可信集内；**(A70)** MDR 的滞回与最小驻留保证换装次数有限。
则：
1. **执行差有界**：`W₂(J#P_sim, J#P_real) ≤ L̂(m)·δ_θ + O(ε)`，故 LMS 的 min L̂ 直接压缩 sim-real 执行鸿沟。
2. **鲁棒安全**：若 J_mat valid，则对 Θ^α 内任意真实材料参数，K_safe^rob 仍满足全部执行约束，不因材料偏差静默越界。
3. **漂移可检**：CUSUM 的误报平均运行长度随 h_drift 指数增长，检测延迟 ≤ h_drift/ν + O(1)，磨损/温升导致的参数漂移不会无限期潜伏。
4. **预算安全**：B_sim/B_mat/B_cog/B_exec 任一耗尽，触发对应保守策略；最坏情况退化为「固定材料 + 第 60 轮保守 K_safe」。
5. **闭环收敛**：若场景与材料漂移均平稳，MESC 的 (m*,K*) 序列在有限次换装后收敛到 Pareto 前沿上的稳定点。

## 2. 关键定义（压缩版）

### 定义 161（MCM）
材料目录 M 与 SDF 嵌入 Ψ 把「物理材料」映射为 Gazebo 接触参数；每个材料带单位成本 c_i^unit、换装时延 τ_i^swap 与不确定椭球 Θ_i^α。材料不再是被动常量，而是可被 σ 换装的决策变量。

### 定义 162（MPT）
对同一轨迹 τ 用相同随机种子做 θ±εd 的配对 rollout，得敏感度矩阵 S(m) 与 `L̂(m)=‖S(m)Σ^{1/2}‖₂`。其关键输出是**材料零空间** N(m) 与**敏感谱**：不是「仿真成不成功」，而是「哪些材料参数方向会改变执行指标」。

### 定义 163（LMS）
`m*(z) = argmin_m L̂(m)`，约束为 `K_safe^rob(m,z)≠∅`、`ρ≥ρ_min`、成本/换装时延上限。**执行空间收缩定理**：若 J_exec 是 L-Lipschitz，则
`W₂(J#P_sim, J#P_real) ≤ L(m)·W₂(P_sim,P_real)`。
故选 min L̂ 等于选一个让 sim-real 执行分布最接近的材料，而不必先估准参数。

### 定义 164（MRC）
`J_mat=(L̂,ρ,δ_θ,ε_bound=L̂δ_θ)`；当 `ρ>0 ∧ ε_bound≤ε_exec^max` 时有效。证书把「仿真里 K_safe 没撞限」升级为「Θ^α 内任意真实材料参数下都不撞限」。

### 定义 165（MEC）
真实接触轨迹 D_real 给出似然，更新 p(θ|D_real)；在残差 r_t=F_real−F_sim 上跑双侧 CUSUM，检测磨损/温升/污染导致的材料漂移。后验价值 `V(m)=E[J_exec]−λ_v Var[J_exec]` 用于重选排序。

### 定义 166（MDR）
仅当漂移持续 k 窗口、距上次换装 ≥T_dwell、且换装收益 `Δ=V(m')−V(m)−c_swap>0` 时换装；以 Jitter 约束防止材料抖动。

### 定义 167（MESC）
统一闭环：`z → M_c → (K_safe^rob, L̂) → (m*,K*) → execute → EV-exec → MEC → z`，漂移时插入 MDR 重选。

### 定义 168（PCE+++++）
`B=(B_sim,B_mat,B_cog,B_exec)`；`voi_mat=VOI_meta−cost_sim−cost_mat−cost_cog−cost_exec`。B_sim 耗尽用 Lipschitz UCB 保守化，B_mat 耗尽复用材料并收紧 K_safe。

```python
class GazeboMaterialPerturbationTestbed:
    def __init__(self, world, task, catalogue, eps=1e-3):
        self.world, self.task = world, task
        self.catalogue, self.eps = catalogue, eps

    def paired_rollout(self, m, direction):
        theta0 = self.catalogue.materials[m].theta
        seed = stable_hash((m, tuple(np.round(direction, 8)))) & 0xffffffff
        self._load_material(m)
        Jp = self._rollout(theta0 + self.eps * direction, seed)
        Jm = self._rollout(theta0 - self.eps * direction, seed)
        return (Jp - Jm) / (2.0 * self.eps)

    def sensitivity(self, m, n_roll=1):
        x = self.catalogue.materials[m]
        d = len(x.theta)
        S = np.zeros((len(self.task.metrics), d))
        for j in range(d):
            e_j = np.eye(d)[j]
            S[:, j] = np.mean(
                [self.paired_rollout(m, e_j) for _ in range(n_roll)], axis=0)
        S_w = S @ sqrtm(x.sigma)
        U, sv, Vt = np.linalg.svd(S_w, full_matrices=True)
        return Sensitivity(
            S=S, sigma=sv, L_hat=np.linalg.norm(S_w, 2),
            null_space=Vt[len(sv):].T, active_dirs=Vt[:3].T,
            n_roll=n_roll)
```

### IP-163 LMS（仿真不敏感材料选型）

```python
class LipschitzMaterialSelector:
    def __init__(self, catalogue, mpt, eeis, rho_min=0.05,
                 lambda_L=1.0, lambda_C=0.05):
        self.catalogue, self.mpt, self.eeis = catalogue, mpt, eeis
        self.rho_min = rho_min
        self.lambda_L, self.lambda_C = lambda_L, lambda_C

    def select(self, z, alpha=0.95, budget=None, delta=0.05):
        best = None
        for m, x in self.catalogue.materials.items():
            if not self._scene_compatible(z, m):
                continue
            theta_set = self.catalogue.uncertainty_set(m, alpha)
            K_rob, rho = self.eeis.compile_robust(z, theta_set)
            if K_rob is None or rho < self.rho_min:
                continue
            sens = self.mpt.sensitivity(m)
            L_ucb = sens.L_hat
            if budget is not None and budget.sim_exhausted:
                L_ucb += budget.sim_ucb(delta=delta)
            c = x.cost + self.lambda_C * x.swap_time
            score = rho - self.lambda_L * L_ucb - c
            if best is None or score > best.score:
                best = MaterialSelection(
                    m=m, K=K_rob, rho=rho, L_hat=L_ucb,
                    null_space=sens.null_space, score=score)
        return best
```

class MaterialRobustCertificate:
    @staticmethod
    def issue(sel, delta_theta, eps_max, alpha=0.95):
        eps_bound = sel.L_hat * delta_theta
        return {
            'material': sel.m, 'K_safe': sel.K,
            'L_hat': sel.L_hat, 'rho': sel.rho, 'alpha': alpha,
            'delta_theta': delta_theta, 'eps_bound': eps_bound,

            'valid': sel.rho > 0.0 and eps_bound <= eps_max,
        }

### IP-165 MEC（材料证据闭环）

```python
class MaterialEvidenceClosure:
    def __init__(self, prior, noise_cov, lambda_v=0.1,
                 drift_h=4.0, drift_nu=0.5):
        self.posterior, self.R = prior, noise_cov
        self.lambda_v = lambda_v
        self.drift_h, self.drift_nu = drift_h, drift_nu
        self.g_plus = self.g_minus = 0.0

    def update(self, ev_exec, material):
        D = ev_exec.contact_trajectory

        def loglik(theta):
            r = D - contact_model(theta, ev_exec.command)
            return -0.5 * r.T @ np.linalg.inv(self.R) @ r

        self.posterior = bayes_update(self.posterior, loglik, D)
        r = ev_exec.F_real - contact_model(self.posterior.mean, ev_exec.command)
        self.g_plus = max(0.0, self.g_plus + r - self.drift_nu)
        self.g_minus = max(0.0, self.g_minus - r - self.drift_nu)
        return max(self.g_plus, self.g_minus) > self.drift_h

    def value(self, material, n=64):
        J = np.array([exec_metric(material, th)
                      for th in self.posterior.sample(n)])
        return J.mean() - self.lambda_v * J.var()
```

### IP-166 MDR（漂移重选）

```python
class MaterialDriftReselection:
    def __init__(self, dwell=30.0, k_windows=3, c_swap=1.0):
        self.dwell, self.k_windows, self.c_swap = dwell, k_windows, c_swap
        self.last_swap = -math.inf
        self.drift_windows = 0

    def should_reselect(self, now, drift, m_cur, m_new, mec):
        self.drift_windows = self.drift_windows + 1 if drift else 0
        if self.drift_windows < self.k_windows:
            return False
        if now - self.last_swap < self.dwell:
            return False
        if mec.value(m_new) - mec.value(m_cur) - self.c_swap <= 0:
            return False
        self.last_swap, self.drift_windows = now, 0
        return True
```

def material_scene_execution_loop(M, task, budget):
    M.scene_model.update(M.telem_force, M.telem_pos)
    z = M.scene_model.get_scene_distribution()
    candidates = [m for m in M.catalogue.materials if M.scene_compatible(z, m)]

    best = None
    for m in candidates:
        theta_set = M.catalogue.uncertainty_set(m, alpha=0.95)
        K_rob, rho = M.eeis.compile_robust(z, theta_set)
        if K_rob is None or rho < M.rho_min:
            continue
        sens = M.mpt.sensitivity(m)
        L_ucb = sens.L_hat + (budget.sim_ucb() if budget.sim_exhausted else 0.0)
        score = rho - M.lambda_L * L_ucb - M.lambda_C * M.catalogue.materials[m].cost
        if best is None or score > best.score:
            best = MaterialSelection(m, K_rob, rho, L_ucb, sens.null_space, score)

    if best is None:
        return DEGRADE_EXEC

    cert = MaterialRobustCertificate.issue(
        best, budget.delta_theta, M.eps_exec_max)
    if not cert['valid']:
        best = M.conservative_material()
        cert = MaterialRobustCertificate.issue(
            best, budget.delta_theta, M.eps_exec_max)

    M, fused, D_plus, ev_exec, cert_exec = closed_loop_exec_probe(
        M, M.current_cp, task.delta_f_req, budget)

    drift = M.mec.update(ev_exec, best.m)
    if drift:
        m_new = M.selector.select(z, budget=budget)
        if M.mdr.should_reselect(M.now, drift, best.m, m_new.m, M.mec):
            best = m_new
            dispatch_material(best.m, M.catalogue)
            dispatch_impedance_params(best.K.best, cert_exec)

    M.epir.append(ev_exec.__dict__)
    return M, best, cert, drift, fused, D_plus

### IP-168 PCE+++++（材料-仿真预算）

```python
class MaterialSimBudget:
    def __init__(self, n_roll=64, swap_limit=5, dwell=30.0,
                 cog=None, exec_b=None):
        self.n_roll, self.n_roll_used = n_roll, 0
        self.swap_limit, self.n_swap = swap_limit, 0
        self.dwell = dwell
        self.B_cog, self.B_exec = cog, exec_b
        self.delta_theta = 0.15

    @property
    def sim_exhausted(self):
        return self.n_roll_used >= self.n_roll

    @property
    def mat_exhausted(self):
        return self.n_swap >= self.swap_limit

    def sim_ucb(self, delta=0.05, kappa=1.0):
        n = max(1, self.n_roll_used)
        return kappa * math.sqrt(2.0 * math.log(1.0 / delta) / n)

    def degrade_level(self):
        if self.mat_exhausted:
            return 'reuse_material_conservative_K'
        if self.sim_exhausted:
            return 'lipschitz_upper_bound'
        if self.B_cog is not None and self.B_cog.exhausted:
            return 'general_scene_prior'
        if self.B_exec is not None and self.B_exec.exhausted:
            return 'exec_degrade'
        return 'normal'
```

**正确性定理（MESC-C）**：
若 A66–A70 成立（CRN 无偏差分、J_exec L-Lipschitz、鲁棒编译非空、MEC 校准、MDR 滞回），则：
1. `W₂(J#P_sim,J#P_real) ≤ L̂(m)δ_θ + O(ε)`，LMS 的 min L̂ 直接压缩执行鸿沟。
2. J_mat valid ⇒ Θ^α 内任意真实材料参数下，K_safe^rob 满足全部执行约束。
3. CUSUM 误报 ARL 随 h_drift 指数增长，漂移检测延迟 ≤ h_drift/ν+O(1)。
4. 任一预算维度耗尽 ⇒ 触发对应保守降级，最坏退化为「固定材料+第 60 轮保守 K_safe」。
5. 场景与漂移平稳 ⇒ 有限次换装后 (m*,K*) 收敛到 Pareto 前沿稳定点。

## 6. 本轮最大风险

**一句话**：若 MPT 的扰动方向只覆盖 Gazebo 接触模型自身的参数子空间，而真实材料的主敏感方向落在其补空间（例如 ODE 低估了软材料的迟滞与粘附，使仿真中的「材料零空间」在现实中并不为零），LMS 就会选中一个「在错误方向上鲁棒」的材料，让 J_mat 在仿真中完美有效、在现实中静默失效；必须以真实 EV-exec 主动探针、正交扰动集与 sim-real Lipschitz 上置信界三重校准，确保「材料零空间」不是仿真器的一厢情愿。
