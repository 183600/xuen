# 第 1 轮（新一轮循环；方法论承接第 65 轮 VISTA 的「可归因 + 定向处置 + 证书链」，但把对象从「接触故障」换成「泛化失败」；本轮灵感：「真实世界泛化」×「语义分割」）

> 前 65 轮把「机器人接触任务里的不确定性」做到了可证伪、可归因、可证书，但它们共享一个默认前提：**任务与类别是封闭的，失效来自已知故障**。一旦走向真实世界，最大的未知不再是「接触模型对不对」，而是「**我到底在哪儿已经不在训练分布里，而且我自己不知道**」。本轮核心命题是：
>
> **把「全局泛化指标（mIoU / 平均置信度）」升级为「逐区域、逐成因、可局部修复、带证书的泛化证据」：用语义分割提供空间化、组合化的泛化坐标系，用区域级加权 conformal 给出分布无关（或误差显式化）的覆盖，用成因归因把「新类 / 新外观 / 边界歧义 / 传感器退化 / 标定失真」拆开，只对可修成因在预算内做局部自适应，并让每个区域都带一张可审计的证书供下游门控。**

## 0. 直觉与动机

**灵感 1（真实世界泛化 → 失效是空间局部化、稀疏、随时间漂移的，不是均匀的）**
直觉：一个分割模型可以在 95% 像素上很好，却在湿地反光、透明容器、长尾新类上灾难性错误。全局 mIoU 恰好把尾部平均掉了。部署真正需要的不是"模型平均多好"，而是"**这张图的哪些区域现在不可信、为什么不可信、能不能就地修好、修不好该怎么退**"。真实世界的分布偏移天然是局部的（一个物体、一块材质、一片光照），而不是整幅图同时均匀变坏。

**灵感 2（语义分割 → 天然的区域坐标系与组合单元）**
直觉：分割的输出本身就是离散区域划分，是泛化分析的天然原子：(i) 可以逐区域给不确定性，而不必把整图压成一个标量；(ii) 可以逐区域做扰动稳定性，把"看不清"与"没见过"分开；(iii) 可以逐区域问"这是什么"（开放词表），从而在没有标签的真实世界里识别新类；(iv) 还能表达**组合泛化**——每个区域都认识，但它们的空间关系（支撑、接触、共现、相对位姿）没在训练里见过。而**边界**正是标签噪声、歧义与偏移共同堆积的地方，单独度量边界稳定性是关键证据。

**灵感 3（可归因优于一刀切）**
直觉：面对偏移，最朴素的做法是全局降置信度或全局域自适应——前者牺牲所有好区域，后者可能把好区域一起带坏，甚至因无监督目标（如熵最小化）而坍缩。第 65 轮 VISTA 的教训是：**先分离成因，再定向处置**。泛化完全同理：新类应当弃权/求助，新外观可以局部自适应，边界歧义应交给几何/多视角，传感器退化应先修传感器，标定失真应先修标定。**成因不同，正确动作完全不同；把成因搞错，比不适配更危险。**

**灵感 4（合流 → SPARC：Semantic Partition Attribution & Regional Certification）**
闭环：冻结骨干的分割/掩码提议（RPN）→ 区域格与区域图 → 区域级非一致性 + 加权 conformal 偏移证书（RSC）→ 成因归因（SCA）→ 只对可修成因、在预算内做局部自适应（LTA）→ **抗坍缩门**（ACG：用同分布锚点否决"以退化为代价的改善"）→ 开放词表新类归因（OVA）→ 组合泛化证据（CGE）→ **区域泛化证书 J_sparc** → 下游门控与回退（DGC）→ 漂移监控与回放（DM）。核心不再是"适配整个世界"，而是"**给每个区域签发它配得上的信任等级**"。

**灵感 5（与第 65 轮的直接对照）**
- 第 65 轮问"哪个故障、该膨胀哪个球"；SPARC 问"**哪个区域、哪种偏移、该修还是该弃权**"。
- 第 65 轮的球是几何/力/模型半径；SPARC 的"球"是**区域信任集与自适应预算**。
- 第 65 轮用主动物理探针分离故障；SPARC 用**扰动稳定性 / 多视角 / 开放词表 / 时间一致性**分离偏移成因，不额外施加物理动作，代价与伤害都更低。
- 第 65 轮的证书是执行安全；SPARC 的证书是**感知可信范围**，是下游规划/操作/导航的前置输入。

## 1. 形式化定义（增量：定义 233–247）

- **定义 233（SPARC 闭环）**：SPARC = (RPN, RSC, SCA, LTA, ACG, OVA, CGE, RGC, DGC, DM)。定位：把稠密语义分割升级为"区域级泛化证据 + 证书 + 门控"的闭环。不变式：**骨干冻结；自适应只写独立的区域条件适配器；任何自适应在升级证书前必须通过抗坍缩门；证书只由带校准锚点的量产生，且每个证书携带其密度比估计与校准版本。**
- **定义 234（区域格与区域图）**：对图像 x，分割骨干给出掩码/建议，经超像素合并得到区域划分 R={r_i}，每区域含像素集 P_r、掩码 m_r、类别分布 p_r；区域邻接图 G_R=(R,E) 的边带相对位姿、边界长度、语义相容性、支撑/接触关系。区域是泛化的记账单位。
- **定义 235（区域非一致性分数与加权 conformal 偏移证书）**：区域非一致性 s_r=λ₁H(p_r)+λ₂(1−stab_r)+λ₃d_feat(r)+λ₄e_photo(r)，分别对应语义熵、扰动稳定度、到校准特征流形的距离、光度/深度残差。在协变量偏移下用**加权 split-conformal**：由域分类器估密度比 ŵ(x)，加权经验分位数给 q_r(α)，证书声明 P[s_r≤q_r(α)]≥1−α−δ_w，其中 δ_w 是密度比估计误差（**显式入账，不假装 1−α 仍然成立**）。
- **定义 236（边界/扰动不变性证据）**：在一族保标签扰动 T（光度、小几何、局部遮挡）下度量掩码一致性 stab_r=E_T[IoU(m_r,m_r(T(x)))] 与边界位移；边界带熵与内部熵之差 b_r。高 b_r + 低语义熵更像边界歧义/标定噪声，而非新类。
- **定义 237（偏移成因假设集）**：𝒞={C0 同分布, C_novel 新类, C_appear 已知类新外观/域, C_bound 边界歧义, C_sensor 传感器退化（模糊/噪声/过曝/深度缺失）, C_cal 标定失真（密度比错、校准集非代表/含标签噪声）}。
- **定义 238（区域证据与成因归因 SCA）**：ρ_r=[s_r, b_r, u_r, o_r, t_r, g_r]ᵀ：偏移分、边界不稳定、语义熵、开放词表新颖裕度、时间/多视角不一致、全局传感器退化指数。离线注入+真实标定拟合 p(ρ_r|C)（高斯混合/小归一化流），后验 P(C|ρ_r)∝p(ρ_r|C)P(C)。若 max_C P(C|ρ_r)≥1−δ_c 则定向处置；否则 ambiguous，默认按**不可修**处理（弃权/回退），而非强行归因。
- **定义 239（成因可辨识性与标定失真的不可分性）**：线性化 E[ρ_r|θ]=Sθ、ρ_r∼N(Sθ,Σ_ρ)，可辨识 ⇔ SᵀΣ_ρ⁻¹S≻0。C_novel 与 C_appear 靠开放词表裕度 o_r 分离；C_bound 靠 b_r、t_r 分离；C_sensor 靠全图共享的 g_r 分离；**但 C_cal 无法从 ρ_r 本身辨识**（它污染的是分位数与权重，不是区域现象），只能在校准锚点/监控层识别——必须在定义上显式承认，否则会把"标定坏了"误判为"场景变了"。
- **定义 240（局部自适应算子与预算 LTA）**：A={A_bn 归一化统计重估, A_adapter 区域条件特征仿射/LoRA, A_temp 温度/阈值重校准, A_mask 边界细化, A_proto 类原型更新, A_abstain 弃权}。仅对可修成因 {C_appear, C_sensor, C_bound} 启用（C_bound 只允许边界细化，不改语义）；C_novel/C_cal 禁止语义自适应。预算 B = 适配参数量×步数（另含每区域算力/时延预算）必须受限。
- **定义 241（抗坍缩门 ACG）**：设同分布锚点集 A_IID（校准中已知受控区域）。自适应 f→f′ 必须同时满足：(R1) 锚点一致性下降 ≤ε_ret；(R2) 目标区域 s_r 下降 ≥ε_gain；(R3) 锚点上输出 KL(f′‖f)≤ε_fn；(R4) 适配批预测类别分布熵 ≥H_min 且有效类别数 ≥K_min（防熵最小化坍缩）；(R5) 边界不稳定不增。全部通过才接受，否则回滚。**没有 R1/R4，无监督自适应会系统性地"自证其错"。**
- **定义 242（开放词表新类归因 OVA）**：用区域掩码池化特征与候选词表文本嵌入 + "unknown" 原型比较；当最大文本相似度低于阈值且掩码一致时判 C_novel（名称可选，检测不必先验知道类名）。与特征 OOD、边界证据交叉验证。
- **定义 243（组合泛化证据 CGE）**：在区域图上比较观测关系分布与校准关系分布（按类别对条件化），得到组合偏移分 c_G。用于捕捉"每个区域都在分布内、但关系/布局没见过"的情况；c_G 超阈值时触发几何/物理推理或保守规划，而非语义自适应。
- **定义 244（区域泛化证书 J_sparc）**：J_sparc(r)=(region_id, cause_posterior, cause_entropy, s_r, q_r(α), α, status, adapt_id, acg_evidence, model_hash, calib_hash, ratio_hash, ts)。status∈{IN_DIST, ADAPTED, ABSTAIN_NOVEL, ABSTAIN_AMBIG, REJECT_DEGRADED, SENSOR_FAULT}。Valid(r) ⇔ 覆盖率声明成立 ∧（ADAPTED⇒ACG 通过）∧（ABSTAIN⇒下游不得当作可信）∧ 哈希为当前版本。图像级证书按最坏区域与"已认证像素比例"聚合，**不做平均**。
- **定义 245（下游门控与回退 DGC）**：门控函数 g: r↦{trust, trust_with_prior, reobserve, fallback, human}。安全契约：若下游决策的支持域与未认证区域相交，则必须使用保守近似（视为未知/障碍）或触发再观测；**未认证 ≠ 不可见，但未认证也绝不等于可信**。
- **定义 246（漂移监控、回放与校准版本 DM）**：在线跟踪覆盖率违规率 ν_t、成因分布漂移、密度比漂移；当 ν_t>α+margin 或 ratio drift 超阈，触发重校准/回放/扩校准集。所有证书量版本化（calib_hash / ratio_hash），版本不匹配的证书作废。
- **定义 247（SPARC 闭环算子）**：语义流 [图像→RPN 区域格→RSC 非一致性→SCA 归因→OVA/CGE→LTA（预算内）→ACG→RGC 证书→DM 监控→回放/重校准]；实时流 [冻结骨干前向→区域分数查表→证书状态门控→派发/回退]，实时流零自适应写操作。

## 2. 关键算法骨架

```python
# RSC + SCA：逐区域偏移分与成因归因（语义流）
regions = rpn.partition(img, masks)
rho = [region_evidence(r, img, T_aug, text_emb) for r in regions]   # s,b,u,o,t,g
for r, e in zip(regions, rho):
    post = cause_posterior(e, calib.lik, calib.prior)               # 𝒞 上后验
    r.status = attribute(post, delta_c)                            # 定向 / ambiguous

# LTA + ACG：只对可修成因做预算内局部自适应
for r in [r for r in regions if r.cause in FIXABLE and r.status == 'attributed']:
    f_prime = adapt(r, ops=BUDGET_OPS[r.cause], budget=B)
    if anti_collapse_gate(f_prime, anchors=A_IID, target=r):
        adopt(f_prime); r.status = 'ADAPTED'
    else:
        rollback(f_prime); r.status = 'REJECT_DEGRADED'

# RGC + DGC：签证书 → 下游只消费已认证区域
cert = [sign_region_certificate(r, q_r(alpha), calib) for r in regions]
cert_img = worst_case_aggregate(cert)                              # 不用平均
dispatch(gate(cert, downstream_plan))
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（密度比误差下的 conformal 覆盖）**：若密度比估计满足 sup_x|ŵ(x)−w*(x)|/E[w*] ≤ δ_w，则用 ŵ 的加权分位数 q_r(α) 时，真实覆盖 P[s_r≤q_r(α)] ≥ 1−α−δ_w。这一条把"分布无关覆盖"从无条件的漂亮话，改成**带误差预算的诚实契约**：δ_w 必须被估计、被监控、被写进证书。
- **引理 10（成因可辨识性）**：在开放词表裕度、边界稳定性、时间一致性、全局传感器指数共同激励下，S 对 {C_novel,C_appear,C_bound,C_sensor} 满列秩；但 C_cal 的列与"场景偏移"在区域证据上共线，**只能在锚点/监控层辨识**，必须显式置为 meta-cause。
- **引理 11（抗坍缩门的保留界）**：若 ACG 通过且输出在锚点分布上的期望 KL 变化 ≤ε_fn，则交叉熵风险在锚点覆盖分布上的变化被 O(ε_fn) 控制（损失对对数概率的 Lipschitz 性）；无门控的熵最小化不具此界，且存在坍缩到单类的构造。
- **定理 9（SPARC 端到端）**：在 A94–A99 下，每个 IN_DIST/ADAPTED 区域的覆盖声明成立（含 δ_w），每个 ADAPTED 区域通过 ACG（无退化、无坍缩），未认证区域被 DGC 强制门控，故下游不会把未认证感知当作已认证使用；视觉/标定失效时优雅降级而非自信犯错。
- **定理 10（局部自适应不劣于全局）**：在可分离偏移场景（仅比例 π 区域偏移），局部自适应的保留损失随 π 线性，全局自适应为 1；故"只修该修的区域"在保留上严格更优，且算力预算同阶。
- **命题（逐区域证书的组合盲点）**：存在场景使每个区域 s_r≤q_r(α)（逐区域全在分布内）而组合关系分布外——如"已知物体悬浮/穿模"。故逐区域证书不足以覆盖泛化，必须叠加 CGE；而 CGE 又依赖关系校准覆盖，仍有盲区。
- **实时性**：区域打分、查表、门控在实时流（目标 ≤3ms）；RSC/SCA/LTA/ACG/OVA/CGE/证书全部在语义流。

## 5. 本轮最大风险

**一句话**：SPARC 的全部覆盖与归因保证都建立在"密度比 ŵ 可估、区域非一致性分数由未偏移的模型产生"之上；但真实部署中这两者都由**正在被检验的分割模型自身**给出——当模型在 OOD 区域系统性自信地错时，错误的 ŵ 会给出"已覆盖"的假证书，局部自适应又在该区域自证其错，系统于是从"不知道自己在分布外"升级为"**拿着自己签发的证书、自信地继续错**"，这是本轮复用的加权 conformal 与抗坍缩论证共同依赖的隐藏假设（A94）。

# 第 1 轮产物 · 创新点清单 v1：SPARC（Semantic Partition Attribution & Regional Certification：语义分割像素分区 × 区域级偏移归因 × 局部自适应 × 泛化证书；RPN×RSC×SCA×LTA×ACG×OVA×CGE×RGC×DGC×DM）

> 承接第 65 轮 IP-214~223（VISTA：视觉知情的安全时序归因闭环）的方法论遗产——**可归因、定向处置、证书链、实时/语义双流**——但把对象从「接触故障」换成「真实世界泛化失败」。第 65 轮的隐藏前提是任务与类别封闭；真实部署的第一性问题变成「**我在哪儿已经不在分布里，而且我自己不知道**」。本轮用**语义分割**提供空间化、组合化的泛化坐标系，用**区域级加权 conformal** 给带误差预算的覆盖，用**成因归因**把新类/新外观/边界歧义/传感器退化/标定失真拆开，只对可修成因做**预算内局部自适应**，并用**抗坍缩门**防止无监督自适应自证其错，最终签发**区域泛化证书**供下游门控。实现 **「偏移可定位、成因可分离、修复有预算、证书可审计」**。
>
> IP 编号：IP-224~IP-233（共 10 个）。相较前一循环闭环的"安全执行"，本轮证书面向**感知可信范围**，是规划/操作/导航的前置输入。

## 2. 形式化定义（完整版）

**定义 233（SPARC 闭环）** SPARC 是"稠密分割→区域级泛化证据"的闭环：冻结分割骨干经 RPN 得到区域格与区域图；RSC 给区域非一致性分数与加权 conformal 覆盖；SCA 在成因集 𝒞 上做贝叶斯归因；OVA 与 CGE 分别处理新类与组合偏移；LTA 只对可修成因在预算 B 内做区域局部自适应；ACG 用同分布锚点否决"以退化为代价的改善"；RGC 签发区域证书；DGC 供下游门控与回退；DM 监控漂移并触发重校准。不变式：**骨干冻结；自适应只写独立区域适配器，不覆盖骨干参数；任何自适应在升级证书前必须通过 ACG；证书只由带校准锚点的量产生，且携带 ratio_hash / calib_hash / model_hash 版本。**

**定义 234（区域格与区域图）** 对图像 x，RPN 由冻结骨干的分割头/掩码提议（如 SAM 类提示分割或超像素）产生过分割，再按"掩码一致性 + 颜色/深度相似 + 最大区域面积上限"合并为区域划分 R={r_i}。每区域 r 有像素集 P_r、掩码 m_r、类别分布 p_r=softmax(mean logits over P_r)。区域图 G_R=(R,E)：边 e_ij 携带相对位姿 ΔT_ij、边界长度、语义相容性、支撑/接触关系（可选，来自几何或单目深度）。**区域是泛化记账的最小单位**，图像级证书由其聚合而来。

**定义 235（区域非一致性分数与加权 conformal 偏移证书）** 定义
s_r=λ₁H(p_r)+λ₂(1−stab_r)+λ₃d_feat(r)+λ₄e_photo(r)，
其中 H 为归一化熵，stab_r=E_{T∼𝒯}[IoU(m_r,m_r(T(x)))]（𝒯 为保标签光度/小几何扰动），d_feat(r)=min_{i∈D_cal}‖φ(r)−φ_i‖_{Σ⁻¹}（φ 为掩码池化特征），e_photo 为光度/深度残差。
标定集 D_cal 给每个区域非一致性 s_i。部署分布 p_test 与 p_cal 存在协变量偏移时，用域分类器估密度比 ŵ(x)≈p_test(x)/p_cal(x)，加权经验分布
F_ŵ(q)=Σ_{i∈D_cal} ŵ(x_i)·1[s_i≤q] / Σ_{i∈D_cal} ŵ(x_i)，
取 q_r(α) 为满足 F_ŵ(q)≥1−α 的最小分位数。证书声明
P[s_r(x)≤q_r(α)] ≥ 1−α−δ_w，
其中 δ_w 是密度比估计误差（引理 9）。**与标准 split-conformal 的区别：我们不假装 δ_w=0；估计误差被当成一等公民写进证书与监控。**

**定义 236（边界/扰动不变性证据）** 在 𝒯 下计算掩码稳定性 stab_r 与边界位移 disp_r；再算边界带（m_r 的形态学膨胀减去腐蚀）平均熵 H_bd 与内部平均熵 H_in，定义 b_r=(H_bd−H_in)_+ + η·disp_r。直觉：**高 b_r 配低 u_r 更像边界歧义或标定/标签问题，而非"新类"**；新类通常整块高熵、高开放词表新颖度，而边界歧义只在窄带出现。

**定义 237（偏移成因假设集）** 𝒞={C0 同分布, C_novel 新类（语义新颖）, C_appear 已知类新外观/域（协变量偏移但标签空间不变）, C_bound 边界/混合像素歧义（偶然不确定）, C_sensor 传感器退化（模糊/噪声/过曝/深度缺失，空间上呈全图或成像相关结构）, C_cal 标定失真（密度比估计错、校准集非代表或含标签噪声）}。**C_cal 是 meta-cause**：它不表现为某个区域"看起来不同"，而表现为分位数/权重本身不可信。

**定义 238（区域证据与成因归因 SCA）** 区域证据
ρ_r=[s_r, b_r, u_r, o_r, t_r, g_r]ᵀ，
其中 u_r=H(p_r)（语义熵，与 s_r 中的分量可共享计算但独立记录以便归因），o_r 为开放词表新颖裕度（定义 242），t_r 为时间或多视角不一致（相邻帧掩码/类别漂移、左右视差/多相机分歧），g_r 为全图共享传感器退化指数（拉普拉斯方差/噪声谱/过曝像素比/深度缺失率）。离线故障注入 + 真机标定拟合各成因的似然 p(ρ_r|C)（高斯混合或小归一化流）。后验
P(C|ρ_r)=p(ρ_r|C)P(C) / Σ_{C'}p(ρ_r|C')P(C')。
处置规则：
- **C0**：签发 IN_DIST。
- **C_novel**：**禁止语义自适应**；签发 ABSTAIN_NOVEL，下游回退/求助/再观测。
- **C_appear / C_sensor**：允许 LTA（外观→适配器/原型；传感器→先修预处理或 A_bn/A_temp）。
- **C_bound**：只允许 A_mask 边界细化（不改语义），否则 ABSTAIN_AMBIG。
- **C_cal**：**禁止在该区域自适应**；由 DM 在校准层处置（重估密度比、清洗校准、重算分位数），并把受污染证书批量作废。
- **ambiguous**（max_C P(C|ρ_r)<1−δ_c）：默认按**不可修**处理（等同 C_novel/C_bound 的保守分支），不得强行归因后自适应。

**定义 239（成因可辨识性与标定失真的不可分性）** 线性化 E[ρ_r|θ]=Sθ、ρ_r∼N(Sθ,Σ_ρ)，θ 为各成因幅度。可辨识 ⇔ SᵀΣ_ρ⁻¹S≻0，裕度 κ_c=λ_min(·)/λ_max(·)。结构上：
- C_novel 列：o_r 高、u_r 高、b_r 中；C_appear 列：s_r 高、o_r 低（已知类文本仍匹配）；
- C_bound 列：b_r、t_r 高而 o_r 低；C_sensor 列：g_r 高且跨区域共享；
- **C_cal 列与"场景整体偏移"在 ρ_r 上共线**（它同时抬高分位数与分数，区域层面不可分），因此 C_cal 必须从 S 中移除，作为 meta-cause 由锚点/监控层单独辨识。
若缺少开放词表裕度或边界证据，C_novel/C_appear/C_bound 列坍缩，归因退化为"分布内 vs 分布外"的二分类。

**定义 240（局部自适应算子与预算 LTA）** 自适应算子集 A 及适用成因：
- A_bn：重估归一化统计（仅 C_sensor 且退化全局时；必须过 ACG）；
- A_adapter：区域条件特征仿射/LoRA（仅 C_appear），用自监督目标 = 掩码一致性 + 有界熵正则（不使用纯熵最小化，防坍缩）；
- A_temp：温度/弃权阈值重校准（C_appear/C_sensor）；
- A_mask：边界细化（仅 C_bound，CRF/引导滤波）；
- A_proto：类原型更新（仅 C_appear）；
- A_abstain：弃权（C_novel/ambiguous/C_cal）。
预算 B：适配参数数量 × 优化步数 ≤ B（另设每区域时延/算力上限）。超预算即丢弃该适配。**骨干冻结、适配器隔离**保证可回滚、可审计、可版本化。

**定义 241（抗坍缩门 ACG）** 设同分布锚点集 A_IID（校准集中已知受控、且有可靠标签/一致性监督的区域）。自适应 f→f′ 必须同时满足：
- (R1) 锚点一致性/准确率下降 ≤ ε_ret；
- (R2) 目标区域平均 s_r 下降 ≥ ε_gain；
- (R3) 锚点分布上 E[KL(f′(x)‖f(x))] ≤ ε_fn（函数空间信任域）；
- (R4) 适配批预测类别分布熵 ≥ H_min，且有效类别数 exp(entropy) ≥ K_min（**直接封堵熵最小化的坍缩解**）；
- (R5) 目标区域边界不稳定 b_r 不增。
全部通过才 adopt；任一失败即 rollback 并置 REJECT_DEGRADED。**R1 与 R4 是本轮对"无监督自适应自证其错"的结构性防线。**

**定义 242（开放词表新类归因 OVA）** 用区域掩码池化特征 φ(r) 与候选词表文本嵌入 {e_k} 及 unknown 原型 e_u 比较，得 o_r=min_k cos(φ(r),e_k)（或 max_k 与阈值之差）。当 max_k cos 低于阈值且掩码一致性 stab_r 高时，判 C_novel；**检测不要求先验知道类名**，命名是可选下游。必须与边界证据交叉：若低相似度仅出现在窄边界带，降级为 C_bound。

**定义 243（组合泛化证据 CGE）** 对区域图 G_R，按类别对 (c_i,c_j) 条件化统计关系特征分布（相对位姿、支撑/接触、共现），与校准关系分布 𝒟_cal(c_i,c_j) 比较，得
c_G=Σ_{(i,j)∈E} π_ij · D_KL( p_obs(rel_ij|c_i,c_j) ‖ 𝒟_cal(rel_ij|c_i,c_j) )。
c_G>τ_G 表示**逐区域都可能同分布，但组合关系分布外**（如已知杯子悬浮在已知桌面上）。CGE 触发几何/物理推理或保守规划，**不触发语义自适应**。

**定义 244（区域泛化证书 J_sparc 与 RGC）** 
J_sparc(r)=(region_id, cause_posterior, cause_entropy, s_r, q_r(α), α, status, adapt_id, acg_evidence, model_hash, calib_hash, ratio_hash, ts)。
Valid(r) ⇔ (status∈{IN_DIST,ADAPTED} ⇒ 覆盖声明 P[s_r≤q_r]≥1−α−δ_w 成立，且 q_r 的 calib_hash/ratio_hash 与当前版本一致) ∧ (status=ADAPTED ⇒ acg_evidence 五条全过且 adapt_id 可回溯) ∧ (status∈{ABSTAIN_*,SENSOR_FAULT,REJECT_DEGRADED} ⇒ 下游不得当作可信) ∧ model_hash 为当前骨干。图像级证书按**最坏区域**与**已认证像素比例**聚合：Cert_img=(min_r margin_r, Σ_{r:Valid} |P_r| / |x|)；**不做平均**，避免好区域掩盖坏区域。

**定义 245（下游门控与回退 DGC）** 门控函数 g: r↦{trust, trust_with_prior, reobserve, fallback, human}：
- IN_DIST → trust；ADAPTED → trust_with_prior（同时给出 acg 证据）；
- C_appear 已适配且 ACG 通过 → trust_with_prior；
- ABSTAIN_NOVEL / ABSTAIN_AMBIG / REJECT_DEGRADED → reobserve/fallback/human（按安全等级）；
- SENSOR_FAULT → reobserve（先修传感器）或 fallback。
安全契约：**若下游决策的支持域与任何未认证区域相交，则必须采用保守近似（未知/障碍/最坏类别）或触发再观测**；未认证不等于不可见，但绝不等于可信。

**定义 246（漂移监控、回放与校准版本 DM）** 在线跟踪：覆盖率违规率 ν_t（在带标签审计流或强代理上测"证书声称可信但实际错"的比例）、成因分布漂移、密度比漂移（域分类器判别力）。当 ν_t>α+margin、或成因分布显著漂移、或 ratio drift 超阈，触发：重估密度比、重算分位数、回放更新适配器、必要时扩充校准集。所有证书量版本化；版本不匹配的证书立即作废（定义 244）。**DM 是 C_cal 的唯一正规处理通道。**

**定义 247（SPARC 闭环算子）** 语义流：[图像→RPN 区域格→RSC 非一致性→SCA 归因→OVA/CGE→LTA（预算内）→ACG→RGC 证书→DM 监控→回放/重校准]；实时流：[冻结骨干前向→区域分数查表→证书状态门控→派发/回退]。不变式同定义 233：实时流**零自适应写操作**，所有学习与证书构建在语义流。

## 3. 关键算法伪代码

### IP-225 RSC（区域偏移分与加权 conformal）

```python
class RegionalShiftCertificate:
    def __init__(self, calib_scores, calib_weights, alpha, delta_w):
        self.s = np.asarray(calib_scores)
        self.w = np.asarray(calib_weights)          # ŵ(x_i)，已在锚点上校准
        self.alpha, self.delta_w = alpha, delta_w

    def score(self, region, img, aug, feat_fn):
        H = normalized_entropy(region.p_r)
        stab = np.mean([iou(region.m, segment(aug(img)) & region.m) for _ in range(N_AUG)])
        d_feat = knn_feature_distance(feat_fn(region), self.feat_bank)
        e_photo = photometric_depth_residual(img, region)
        return LAM1*H + LAM2*(1-stab) + LAM3*d_feat + LAM4*e_photo

    def quantile(self, s_new):
        order = np.argsort(self.s)
        sw = self.w[order]
        F = np.cumsum(sw) / sw.sum()               # 加权经验 CDF
        idx = np.searchsorted(F, 1 - self.alpha, side='left')
        return float(self.s[order][min(idx, len(self.s)-1)])
```

### IP-226 SCA（成因归因）

```python
class ShiftCauseAttribution:
    CAUSES = ('C0','C_novel','C_appear','C_bound','C_sensor','C_cal')

    def __init__(self, lik, prior=None, delta_c=0.2):
        self.lik = lik                              # p(rho|C)，离线注入标定
        self.prior = prior or {c: 1/len(self.CAUSES) for c in self.CAUSES}
        self.delta_c = delta_c

    def evidence(self, r):
        return np.array([r.s, r.b, r.u, r.o, r.t, r.g])

    def attribute(self, r, meta_cal_suspect=False):
        if meta_cal_suspect:                        # DM 已报 C_cal
            return {'C_cal': 1.0}, 'C_cal', False
        rho = self.evidence(r)
        logp = {c: np.log(self.lik[c](rho)+1e-12) + np.log(self.prior[c])
                for c in self.CAUSES if c != 'C_cal'}   # C_cal 不在区域层辨识
        z = np.array(list(logp.values())); z -= z.max()
        post = {c: float(np.exp(v)/np.exp(z).sum()) for c, v in logp.items()}
        c_star = max(post, key=post.get)
        return post, c_star, post[c_star] < 1 - self.delta_c
```

### IP-227/228 LTA + ACG（局部自适应与抗坍缩门）

```python
def local_adapt(regions, cause, f, anchors, budget):
    ops = {'C_appear': ['A_adapter','A_proto','A_temp'],
           'C_sensor': ['A_bn','A_temp'],
           'C_bound' : ['A_mask']}[cause]
    used = 0; results = []
    for r in [x for x in regions if x.cause_star == cause]:
        for op in ops:
            if used + op_cost(op) > budget: break
            f_prime = apply_op(f, op, r); used += op_cost(op)
            if anti_collapse_gate(f, f_prime, anchors, r):
                f = f_prime; r.status = 'ADAPTED'; r.adapt_id = op
            else:
                r.status = 'REJECT_DEGRADED'
            results.append((r, f))
    return f, results

def anti_collapse_gate(f, f_prime, anchors, r):
    r1 = anchor_consistency(f_prime, anchors) >= anchor_consistency(f, anchors) - EPS_RET
    r2 = mean_score(f_prime, r) <= mean_score(f, r) - EPS_GAIN
    r3 = mean_kl(f_prime, f, anchors) <= EPS_FN
    p = predict_distribution(f_prime, r.pixels)
    r4 = entropy(p) >= H_MIN and np.exp(entropy(p)) >= K_MIN
    r5 = boundary_instability(f_prime, r) <= boundary_instability(f, r)
    return r1 and r2 and r3 and r4 and r5
```

### IP-229/230 OVA + CGE（新类与组合偏移）

```python
def open_vocab_novelty(feat, text_emb, e_unknown):
    sims = [cosine(feat, e) for e in text_emb] + [cosine(feat, e_unknown)]
    return float(max(sims) - cosine(feat, e_unknown))   # 越大越新颖

def compositional_score(G_R, cond_probs, calib_rel):
    cG = 0.0
    for (i, j, rel) in G_R.edges(data='rel'):
        ci, cj = G_R.nodes[i]['cls'], G_R.nodes[j]['cls']
        p_obs = cond_probs(rel, ci, cj)
        cG += G_R[i][j]['area_frac'] * kl(p_obs, calib_rel[(ci, cj)])
    return cG
```

### IP-233 SPARC 闭环算子

```python
def SPARC_round(M, img, text_vocab, downstream_plan):
    # ———— 语义流 ————
    regions = M.rpn.partition(img)                       # 冻结骨干
    M.dm.maybe_flag_calibration()                        # C_cal 监控
    cal_sus = M.dm.calibration_suspect
    for r in regions:
        r.s = M.rsc.score(r, img, M.aug, M.feat_fn)
        r.q = M.rsc.quantile(r.s)
        r.b = boundary_evidence(r, img)
        r.o = open_vocab_novelty(M.feat_fn(r), text_vocab, M.e_unknown)
        r.t = temporal_multiview_inconsistency(r, M.history)
        r.g = M.sensor_index(img)
        post, c_star, amb = M.sca.attribute(r, meta_cal_suspect=cal_sus)
        r.cause, r.cause_post = c_star if not amb else 'AMBIG', post

    # 组合偏移（区域图）
    cG = compositional_score(M.rpn.graph, M.cond_probs, M.calib_rel)
    M.cge_flag = cG > TAU_G

    # 只对可修成因做预算内局部自适应
    for cause in ('C_appear', 'C_sensor', 'C_bound'):
        M.f, _ = local_adapt(regions, cause, M.f, M.anchors, M.budget)

    # 签发区域证书 + 下游门控
    cert = [M.rgc.sign(r, M.rsc, M.acg_log, M.version) for r in regions]
    cert_img = M.rgc.aggregate(cert)                     # 最坏 + 已认证比例
    actions = [M.dgc.gate(r, downstream_plan) for r in regions]

    # 监控与版本化
    M.dm.update(cert, M.rsc, M.sca)
    return M.f, cert_img, actions, cG
```

## 4. 推导

**引理 9（密度比误差下的 conformal 覆盖）** 设真实密度比 w*(x)=p_test(x)/p_cal(x)，估计 ŵ 满足
sup_x |ŵ(x)−w*(x)| / E_{cal}[w*] ≤ δ_w。
对任意阈值 q，加权经验分布 F_w(q)=Σ_i w(x_i)1[s_i≤q]/Σ_i w(x_i) 的分子、分母相对扰动均 ≤δ_w，故 |F_ŵ(q)−F_{w*}(q)| ≤ 2δ_w/(1−δ_w) ≤ 3δ_w（δ_w 小时）。取 q=q_r(α) 使 F_ŵ(q)≥1−α，则 F_{w*}(q)≥1−α−3δ_w。在协变量偏移+加权可交换性下，F_{w*} 即测试非一致性的真实 CDF，故
P[s_r≤q_r(α)] ≥ 1−α−3δ_w。
把 δ_w 吸收进常数得证书形式 1−α−δ_w（δ_w 按此重定义）。**要点：覆盖保证不是无条件的，δ_w 必须可估、可监控；当密度比估不准时，证书会诚实地变宽/降级（提高 α 或拒绝签发），而不是给出虚假的 1−α。** ∎

**引理 10（成因可辨识性）** 在证据向量 ρ_r 上，C_novel 与 C_appear 的差别主要沿 o_r 轴（开放词表裕度），C_bound 沿 b_r、t_r 轴，C_sensor 沿全图共享的 g_r 轴。若这些轴上的条件分布两两可区分（似然比的 KL>0），则 S 的对应列线性无关、SᵀΣ_ρ⁻¹S 在子空间上正定，归因后验以 O(exp(−nκ_c/2)) 集中。**C_cal 的效应是乘性污染分位数与权重，不产生独立的区域证据方向**，其列与"整体场景偏移"共线；把它放进区域层会得到不可辨识的 S，故必须作为 meta-cause 由锚点/监控层处理。若去掉开放词表或边界证据，C_novel/C_appear/C_bound 列坍缩，归因退化为二分类。∎

**引理 11（抗坍缩门的保留界）** 设损失 ℓ 在对数概率空间 L-Lipschitz（有界 logits 下成立）。对锚点分布 P_A，
|R_{P_A}(f′)−R_{P_A}(f)| ≤ L·E_{P_A}‖log f′−log f‖ ≤ L·√(2·E_{P_A}[KL(f′‖f)])，
末步由 Pinsker 不等式。由 ACG 的 R3，E_{P_A}[KL]≤ε_fn，故锚点风险变化被 L√(2ε_fn) 控制。对与 P_A 的 TV 距离 ≤ρ 的分布，风险变化再增 2L'ρ。**无门控的纯熵最小化没有这一界**：存在构造使 f′ 在目标区域把几乎所有像素判为单类（熵→0，s_r 表面下降），但锚点与真实风险大幅恶化——这正是 R1/R4 要封堵的"自证其错"。∎

**定理 9（SPARC 端到端泛化-证书）** 在假设 A94–A99 下：
- A94：密度比可在 δ_w 内估计并被 DM 监控；
- A95：部署偏移属于 𝒞 或被判 ambiguous；
- A96：区域划分在偏移下足够稳定（区域级归因有意义）；
- A97：锚点 A_IID 代表同分布且 ACG 被精确评估；
- A98：自适应仅区域局部、骨干冻结、预算受限；
- A99：下游严格服从 DGC 门控。
则：
1. **覆盖诚实**：每个 IN_DIST/ADAPTED 区域的覆盖 ≥1−α−δ_w；δ_w 增大时 DM 触发重校准或证书降级。
2. **无退化升级**：每个 ADAPTED 区域通过 ACG，锚点风险变化 ≤L√(2ε_fn)，且无坍缩（R4）。
3. **与错分离**：C_novel/ambiguous 不进入语义自适应；C_cal 只经 DM 处理并批量作废受污染证书，避免把"标定坏了"误当"场景变了"而越修越错。
4. **下游安全**：未认证区域被 DGC 强制保守/再观测，故下游不会把未认证感知当作可信；Cert_img 用最坏区域，不被好区域平均掩盖。
5. **优雅降级**：传感器退化→C_sensor（先修预处理）；新类→弃权/求助；组合陌生→CGE 触发保守规划；标定失真→证书作废与重校准。∎

**定理 10（局部自适应不劣于全局）** 考虑可分离偏移：比例 π 的区域发生可修偏移，其余 1−π 为同分布。设自适应在偏移区域的增益为 G（分数下降），在异质/同分布区域的附带退化损失为 D。
- 全局自适应：增益 πG，保留损失 (1−π)D；
- 局部自适应：增益 πG（仅作用于偏移区域），保留损失 ≈0（因 ACG 与区域隔离）。
故局部自适应的净收益严格更优，差为 (1−π)D；当 π 小（真实世界偏移通常稀疏）时优势最大。算力上局部只需对 π|R| 区域算适配，预算同阶且更省。∎

**命题（逐区域证书的组合盲点）** 构造一幅图：所有区域都是校准中见过的类别与外观（草地、路面、水面），逐区域 s_r≤q_r(α)，但它们的空间排列是分布外的（例如草地正方形悬在路面上方、水面出现在室内天花板）。此时逐区域证书全部 IN_DIST，而真实语义关系是 OOD。故**逐区域证书不能覆盖组合泛化**，必须叠加 CGE（定义 243）；而 CGE 依赖关系校准覆盖，若校准集中没有该类别对的足够关系样本，c_G 同样不可靠——这是必须显式承认的第二类盲区。∎

## 7. 已知风险

**一句话**：SPARC 的全部覆盖与归因保证都建立在"密度比 ŵ 可估、区域非一致性分数由未偏移的模型产生"之上；但真实部署中这两者都由**正在被检验的分割模型自身**给出——当模型在 OOD 区域系统性自信地错时，错误的 ŵ 会给出"已覆盖"的假证书，局部自适应又在该区域自证其错，系统于是从"不知道自己在分布外"升级为"**拿着自己签发的证书、自信地继续错**"，这是本轮复用的加权 conformal 与抗坍缩论证共同依赖的隐藏假设（A94）。

**次级风险与缓解**：
1. **密度比/域分类器误估（A94 失效）**：δ_w 被低估会让覆盖名不副实；缓解：用保守 δ_w、集成多个域分类器取最坏、在线锚点审计、覆盖违规率监控、δ_w 高时直接拒绝签发证书（宁可 ABSTAIN 不可假认证）。
2. **成因集不完整、新偏移被强行归类**：有限假设集固有缺陷；缓解：后验熵上界触发 ambiguous→默认不可修；持续扩充注入库；对未知偏移只做弃权与保守回退。
3. **C_cal 与场景偏移混淆**：区域层不可辨识；缓解：显式置为 meta-cause、只有在锚点/审计流证据下处理、受污染证书批量作废、版本化。
4. **区域划分不稳定 / 跨边界泄漏**：偏移区域与掩码不一致会污染归因；缓解：多尺度区域、超像素边界带单独标记、区域级证据用边界带外的稳健统计。
5. **无监督自适应坍缩或确认偏误**：熵最小化天然趋坍缩；缓解：不用纯熵最小化、掩码一致性+有界熵、R1/R4 门控、锚点回放；仍可能对系统性偏差无效。
6. **组合偏移盲区**：CGE 依赖关系校准覆盖；缓解：显式标注 `relation_uncalibrated`，触发物理/几何推理而非语义自适应，必要时保守规划。
7. **证书聚合与下游误用**：平均会掩盖坏区域；缓解：最坏区域+已认证像素比例、安全契约强制保守近似、审计日志。
8. **算力与时延**：扰动稳定性、开放词表、适配器都较重；缓解：全放语义流、每区域采样、文本嵌入缓存、适配预算硬上限、实时路径只查表门控。
9. **δ_w 的统计假设**：协变量偏移模型本身可能不成立（标签偏移/概念偏移）；缓解：监控标签偏移信号，概念偏移下加权 conformal 不适用，退回弃权/重校准并声明假设失效。
