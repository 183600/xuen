# 第 74 轮（承接第 73 轮「MODGAUGE-RAS 计量契约代数」IP-295~302；灵感循环第 4 轮；本轮灵感：「步骤分」×「语音识别」）

> R73 把系统安全问题重构为「证据计量的可组合契约」：MMS / EC / CCA / ΣREFLEX / CPB，并在尾部补入 ECG 因果证据图、MIC 形态无关契约与 IP-302 因果证据组合。它回答的是「**同一时刻的多个证据如何被审计、组合、热替换**」。但它默认了两个从未被检查的前提：
> - **前提 A：信用是结果级的。** J_MOD 证明「整段系统都有效」，却无法回答「**是哪一步/哪个词**让这次决策成立或失败」。结果安全至少混合了三种来源：真实过程、运气、外部救援。只看最终碰撞率，会把「坏过程 + 好运气」误认证为安全。这是比 R73 所批判的「把不确定度压成标量」更隐蔽的压缩：**把过程压成了结局**。
> - **前提 B：证据是点值/单假设的。** 所有模块输出一个分布或标量 u。AURA 把整段音频压成 `ψ_hat`，丢掉 ASR 的**加权格、n-best、部分假设与词级时间对齐**。这与 R73 批判的「把模态结构压成标量」是同型错误——只不过这次压掉的是**解释的多重性**。
>
> 本轮两个灵感正好补这两块：
> - **步骤分** → **SCT（Step-Credit Trace）/ SCA（Step-Credit Algebra）/ e-process 步骤信用 / J_STEP（过程证书）**：给证据-决策 DAG 的每个节点/边打**因果局部、可校准**的信用分；用 anytime-valid e-process 处理「等到分数够了再承诺」的**可选停止**问题；把最终结果分解为**幸运安全 / 冤枉失败 / 名副其实**三类，并支持**步骤级局部撤销**（比 R73 模块级 stub 更细）。
> - **语音识别** → **SLEC（Speech Lattice Evidence Contract）**：证据类型从 `Sense` 升级为 `Set[Sense]`（加权格）；六分量 ASR 不确定度（声学/语言模型/领域/信道/对齐/承诺）；**安全相关歧义否决**（同音、否定、口音导致安全极性翻转时禁止承诺）；**CGC（Commitment Gate Controller）** 的 act/wait/ask/abort 承诺门控；**L5 监听/追问反作用通道 χ_L**；**τ_align** 词级溯源。
>
> 核心命题：**不再问「最终结果是否安全」，而问「证据链上每一步的信用是多少，系统能否只在累积步骤分足以支撑时才承诺一个解释与动作？」** 把 MODGAUGE 的「瞬时证据契约」扩展为 **STEPGAUGE-RAS（Step-scored, Transcript-lattice Evidence metrology with Process-credit GAUGE audits for RAS）**：**过程即证据，步骤分即预算，承诺即测试。**

## 0. 直觉与动机

**灵感 1（步骤分 → 安全是过程的属性，不是结局的标签）**
直觉：批改数学证明时，正确的中间步骤拿步骤分，最终答案对但推理错则拿零分；反过来，推理全对但最后一步算错只扣最后一步的分。R73 的 J_MOD 则像一个只看最终答案的评分器。机器人安全里，一次「没有碰撞」可能来自三种完全不同的世界：(a) 证据充分、决策正确（名副其实）；(b) 证据不足但环境宽松、未被惩罚（**幸运安全**）；(c) 证据充分却遭遇未建模的外因（**冤枉失败**）。结果-only 的评估把三者混为一谈，最危险的后果是**把幸运安全写进证书并拿去训练**：策略学到的是「这样做没撞」，而不是「这样做有依据」。步骤分要求我们给每个证据-决策步骤一个信用 `s_i∈[0,1]`，并且这个信用必须：**因果局部**（只能用当前及过去证据，不能偷看未来）、**校准**（高风险步骤的信用要系统性地低）、**零缺省**（缺证据/stub 的步骤信用为 0，不是先验 1——否则「回避难模态」反而提高分数）。更微妙的是：既然机器人可以**等到分数够了再承诺**，那么「何时停」本身是数据依赖的。若用「每步置信度 ≥ 1−δ」反复偷看，假承诺率会随步数膨胀；正确工具是 **anytime-valid e-process**（Ville 不等式），它让「等到证据足够」不产生多重比较惩罚。最后，步骤分还给了 R73 缺失的**降级粒度**：模块级 stub 会整个废掉语音；词/步骤级信用允许只撤销某个词派生的动作。

**灵感 2（语音识别 → 证据是格，不是句子；歧义是离散风险，不是方差）**
直觉：ASR 从不输出「那句话」，它输出一个**加权格 / n-best 列表**，每个候选带时间对齐的 token 序列，并且以**增量部分假设**的形式到达。R73 的 AURA 把格压成 `ψ_hat`，等于把「要停」和「不要停」两个都还活着的解释平均成一个不存在的中间意图。语音的失效也有确定性物理/统计结构，可分解为**六分量**：声学模型/发音（口音、语速）、语言模型先验、领域/OOV/专名、信道（远场、混响、噪声）、对齐（词边界、端点）、承诺（流式部分假设不稳定）——与 DPEM 的深度六分量、DMEM 的接触四分量严格同构。但语音最独特的一点是：歧义往往不是「方差变大」，而是**离散的安全极性翻转**（授权运动 vs 否决运动、肯定 vs 否定、数字/单位）。此时正确操作不是融合取平均，而是**解释层否决（VETO on acting）**：在歧义消解前不得承诺。这直接复用 R73 COMP-VETO 的非补偿语义。流式还带来一个一等决策：**何时承诺**——继续听（WAIT）、追问（ASK）、执行（ACT）还是放弃（ABORT）。等待与追问都是**动作**，会改变证据质量（更多音频、澄清回答），这正是 R73 ΣREFLEX 的第五层通道 χ_L，而不是手写分支。

**灵感 3（综合 → 过程信用契约，承诺即假设检验）**
直觉：把两者放在一起，会得到一个比 R73 更自然的闭环。语音格提供了「一个逐步展开、多假设、可对齐」的过程对象；步骤分提供了「沿这个过程累积信用、并在信用足够时才停止」的度量与停止规则。于是一次承诺不再是「某一帧的最佳猜测」，而是「沿证据链累积到 e-process 越过 1/δ，且当前格不跨安全极性」的**停止事件**。承诺本身成为一个可审计的假设检验：拒绝「当前解释错误」的原假设。严格退化也很清楚：步骤分→只看结果、格→best-1、承诺→固定端点、χ_L→恒等时，STEPGAUGE 逐指令退化为 R73 MODGAUGE，再退化为 R72/R71/R68。**安全侧只增不减，效率的收益只在「步骤分校准 + 格覆盖 + 停止有效」三者同时成立时兑现。**

## 1. 形式化定义（增量：定义 383–399）

**定义 383（STEPGAUGE-RAS 总览与六不变式）** STEPGAUGE-RAS = (SLEC, SCT, SCA, CGC, χ_L, J_STEP, MODGAUGE-RAS†)。六不变式：
(i) **过程完备**：每个被承诺的动作携带一条可复算的步骤信用轨迹（SCT），缺链不得承诺；
(ii) **步骤分校准**：每步信用在标定分布上条件校准（定义 385），缺失/stub 步骤信用恒为 0；
(iii) **可选停止有效**：承诺时机由 e-process 决定，满足 Ville 型上界（定义 386），数据依赖停止不放大假承诺率；
(iv) **歧义否决**：语音格出现安全相关歧义（定义 389）时禁止承诺，非补偿；
(v) **信用单调**：未获新证据时信用沿路径非增，任何组合不得凭空产生信用（定义 394）；
(vi) **严格退化**：步骤分→结果、格→best-1、承诺→固定端点、χ_L→id 时逐指令退化为 R73（再退化为 R72/R71/R68）。

**定义 384（步骤信用轨迹 SCT）** 审计轨迹是一个证据-决策 DAG `G=(V,E)`（R73 ECG 的实例化），每节点 `i` 携带 `(e_i, d_i, EC_i)`，`e_i` 为契约型证据、`d_i` 为该步决策。步骤信用 `s_i∈[0,1]`，路径信用 `S(π)=⊗_{i∈π} s_i`（默认 `min`，或 e-process 乘积）。`SCT=(G,{s_i},{τ_i})`。**因果局部性**：`s_i=φ(e_{≤i}, d_i, EC_i)`，不含未来证据；**缺省为零**：`stub`/空证据 ⇒ `s_i=0`。

**定义 385（步骤分校准）** 在标定分布 `𝒟_cal` 上，步骤分满足风险校准：存在非增 `ρ` 使 `P(violation at i | s_i≥θ) ≤ ρ(θ)`，且 `ρ(θ) ≤ 1−θ`（保守）。等价的 conformal 形式：由留出集得分构造 `p_i`，令 `s_i = 1−p_i`。**零缺省**：若模块为 stub 或证据为空，`s_i=0`。系：**规避高风险模态不能提高路径信用**。

**定义 386（可选停止步骤证据 / e-process）** 每步给出 e 值 `E_i≥0`，在 `H_i`（"当前承诺错误"）下满足条件有效性 `E[E_i | F_{i−1}] ≤ 1`。运行乘积 `M_t=∏_{i≤t}E_i`，`M_0=1`。Ville 不等式：`P(∃t: M_t ≥ 1/δ) ≤ δ`。承诺规则：`M_t ≥ 1/δ` 且无安全歧义时允许承诺。**由 p 值构造**：`E(p)=κ·p^{κ−1}`（`κ∈(0,1)`）是合法 e 值（`p~U(0,1)` 时 `E=κ∫_0^1 p^{κ−1}dp=1`）。系：**"等到分数够"必须用 e-process，而不是每步 `p≤δ` 反复偷看（后者假阳性随步数膨胀）。**

**定义 387（语音格证据 SLEC）** 语音证据是加权格 `L=(V,E,start,end,w,align)`；路径 `π=(t_1…t_m)` 为 token 序列，`align(π)` 给出每 token 的时间区间；意图语义映射 `sense(π)`。**校准集** `Z_α(L)={sense(π) : p_π>α}`（`p_π` 由留出集 conformal 校准）。SLEC 的输入/输出类型是 `Set[Sense]` 而非 `Sense`——**类型系统保证"格不会被静默压成点估计"**。

**定义 388（语音六分量不确定度）** `u_asr² = u_aco² + u_lm² + u_dom² + u_chan² + u_align² + u_commit²`：
- `u_aco` 声学/发音（口音、语速、发音变体）；`u_lm` 语言模型先验；`u_dom` 领域/OOV/专名；`u_chan` 远场/混响/噪声；`u_align` 词边界/端点；`u_commit` 流式部分假设不稳定。
各有独立追溯链 `τ_i`，与 DPEM 六分量同构（引理 45）。**有效域** `D_asr = {b_t(accent) 可覆盖} ∧ {SNR≥ρ} ∧ {Z_α 存在}`。

**定义 389（安全相关歧义与解释否决）** 将 sense 映射到安全类 `c(π)∈𝒞_safe`（STOP/MOVE/LOCAL/…）或风险泛函 `r(π)`。若 `∃π,π′∈Z_α` 使 `c(π)` 与 `c(π′)` 的**否决语义不同**（一个通过、一个否决，或风险跨越阈值），称 `Z_α` **安全歧义**。规则：安全歧义 ⇒ **禁止 ACT**（解释层 VETO），只能 WAIT / ASK / ABORT。**非补偿**：其它模态的高信用不能抵消解释歧义。系：**语音歧义不是方差，是离散风险；平均会制造一个不存在的"中间解释"。**

**定义 390（承诺门控 CGC）** 每帧决策 `a_t∈{ACT,WAIT,ASK,ABORT}`。成本：错误 ACT（安全相关解释错）`L_cat≫0`；正确 ACT 为 0；WAIT 为 `λ_w·Δt`；ASK 为 `λ_q+d_q`（人类负担）；ABORT 为 `L_abort`。**风险约束** `P(错误承诺)≤δ`（由定义 386 提供）。策略：继续域内 WAIT；越过 `1/δ` 且已消歧时 ACT；超时/持续歧义 ASK；预算耗尽或危险 ABORT。单调似然比下最优策略为阈值策略（引理 49）。

**定义 391（内生承诺时域 h_commit）** `h_commit = inf{ t : M_t≥1/δ ∧ 非安全歧义 ∧ 动作通过 R73 CCA/J_MOD 校验 }`。承诺时域不是超参数，而是由证据、歧义与预算共同决定的**停止时间**；每次承诺附带 `h_commit` 与预算快照。注意它与"动作块长度"不同：这里的时间是**证据积累时间**，不是开环执行时间。

**定义 392（L5 监听/追问反作用通道 χ_L）** `χ_L: g∈{listen(Δ), ask(q)} ↦ Δθ_noise × D′`，声明额外音频/澄清如何降低 `(u_aco,u_chan,u_commit,u_dom)`。成本 `c_reflex^L = λ_w·Δ`（listen）或 `λ_q+d_q`（ask）。**有限停止**：每次监听有正成本，边际信息增益随音频饱和非增 ⇒ 存在最优监听步数（引理 51）。**层数仍是模块声明**：L5 是 ΣREFLEX 的当前实例，不是主闭环里的手写分支。

**定义 393（对齐追溯 τ_align）** 对承诺动作 `a`（时刻 t），`provenance(a)=⋃_{token∈align(π*)} (audio_τ(token) ⊗ model_hash ⊗ calib_τ) ⊗ action_τ`。支持**溯源局部撤销**：某 token 区间事后被标为不可信（ASR 漂移/对抗注入）时，只撤销由该区间派生的动作，而非整个语音模态。**可复算性**：给定格与模型哈希可重放该动作的完整信用链。

**定义 394（步骤信用代数 SCA）** 三算子：
- **STEP-SER**（过程串联）：`S(A→B)=min(S_A,S_B)`；`M=M_A·M_B`（条件有效时）；跨步预算 `u_out ≥ u_A+L_B u_A`；信用非增。
- **STEP-PAR**（同一步多源证据）：e 值按条件独立加权/相乘；仅在跨模态一致性审计（R73 CCA）通过且条件独立时才允许信用上升，否则 `S=min(S_A,S_B)`（保守）。源间分歧触发 `I⊥`。
- **STEP-VETO**：任一步 `S=0` 或安全歧义 ⇒ 整条路径 `S=0`（非补偿）。
**步骤单调性（引理 46）**：任何组合路径的信用 ≤ 路径上最小信用；未刷新时沿时间非增。

**定义 395（步骤分证书 J_STEP）** `J_STEP=(SCT,{M_t},{provenance},校准报告)`。`Valid(J_STEP)` ⇔ 每个被承诺动作 (i) 有完整 SCT 且 `min s_i≥θ` 或 `M_t≥1/δ`；(ii) 无未处理安全歧义；(iii) provenance 可复算；(iv) 无 stub 步骤贡献正信用；(v) 校准报告在有效期内。**与 J_MOD 分工**：J_MOD 管"空间契约闭合"，J_STEP 管"过程信用闭合"；二者皆 Valid ⇒ 过程安全（定理 35）。

**定义 396（过程级降级与局部撤销）** 步骤级失效（某 token 不可信 / 某步证据断链）⇒ 该步 `s=0`，撤销其派生承诺，路径截断到最后一个信用 ≥θ 的步骤；**不**降级整个模态。仅当不可定位（模型整体漂移）才回退到 R73 模块级 stub。这把"模块级零级联"细化为"**步骤级零级联**"。

**定义 397（过程级 stub 语义）** 步骤 stub：证据 ∅、`s=0`、`τ=∅`、否决 = 该步命题全集；仍保留在 SCT 中（路径可审计为"此处缺证据"），但不得贡献正信用、不得作为 PAR 缩窄来源。与 R73 定义 381 模块 stub 兼容。

**定义 398（MBench 过程扩展 MB4/MB5）** MB4：语音过程基准（同音/否定/口音/远场/流式 × 步骤分校准 × 承诺门控）；MB5：过程信用基准（幸运/冤枉分解、选择性认证、步骤级撤销）。各 ≤3h 单卡可复现，预注册 + 密封保持集 `SEAL-MB`。

**定义 399（CPB 扩展 C4/C5/C6）**
- **C4（过程信用）**：步骤分选择性认证在匹配覆盖率下比结果-only 降低 selective risk 与"幸运安全"漏放；
- **C5（格证据）**：格 + 安全歧义否决比 best-1 在匹配延迟下降低安全相关误承诺，且 conformal 覆盖成立；
- **C6（承诺门控）**：anytime-valid 门控（含 L5）比固定端点在匹配延迟下降低误承诺，或匹配误承诺下降低延迟。

## 2. 关键算法骨架

```python
# IP-303 SLEC：语音格证据（感知域，流式）
class SpeechLatticeEvidence:
    def update(self, audio_chunk, asr, calib):
        L = asr.decode_lattice(audio_chunk)              # 加权格 + 时间对齐
        senses = {}
        for pi in L.paths(top_k=32):
            p = calib.conformal_pvalue(L, pi)            # 留出集校准
            if p > self.alpha:
                senses[sense(pi)] = min(senses.get(sense(pi), 1.0), p)
        Z = set(senses)                                   # Set[Sense]，绝不压成点
        u = math.sqrt(self.u_aco(L)**2 + self.u_lm(L)**2 + self.u_dom(L)**2
                      + self.u_chan(L)**2 + self.u_align(L)**2
                      + self.u_commit(L)**2)              # 六分量
        ambiguous = safety_ambiguous(Z)                   # 安全极性是否分歧
        return SpeechEvidence(Z=Z, u=u, ambiguous=ambiguous,
                              align=L.align, tau=self.tchain.merge(L.tau))

# IP-304 SCT：步骤分 + e-process（计量域，50Hz）
def step_credit_trace(ev, prev_M, delta, kappa, theta):
    p = ev.conformal_p if hasattr(ev, 'conformal_p') else (1.0 - ev.step_score)
    e = kappa * max(p, 1e-15) ** (kappa - 1.0)            # 合法 e 值
    M = prev_M * e
    s = 0.0 if ev.is_stub else (1.0 - p)                  # 缺省信用为 0
    return StepNode(s=s, e=e, M=M), M

# IP-305 CGC：承诺门控（act / wait / ask / abort）
def commitment_gate(node, ev, budget, cfg):
    if ev.ambiguous:
        return 'WAIT' if budget.audio_left > 0 else 'ASK'  # 歧义绝不 ACT
    if node.M >= 1.0 / cfg.delta and node.s >= cfg.theta:
        return 'ACT'
    if budget.spent_reflex + cfg.lam_w * cfg.dt > budget.B:
        return 'ABORT'
    return 'WAIT'

# IP-306 χ_L：L5 监听/追问反作用通道
def reflex_L(action, mod, state, budget):
    if action == 'LISTEN':
        chi = mod.ec.chi_R(('listen', cfg.dt))
        cost = cfg.lam_w * cfg.dt
    elif action == 'ASK':
        chi = mod.ec.chi_R(('ask', cfg.query))
        cost = cfg.lam_q + cfg.human_cost
    else:
        return state, 0.0
    s2 = mod.propagate(state, chi)                        # E[u_asr] 下降，非手写层
    if budget.spent + cost > budget.B or s2 not in mod.safe_set:
        return state, 0.0
    return s2, cost

# IP-307 SCA：步骤信用代数
def compose_credit(a, b, op, audit):
    if op == 'STEP-SER':
        return PathCredit(S=min(a.S, b.S), M=a.M * b.M,
                          u=a.u + lipschitz(b, a.u), D=a.D & b.D)
    if op == 'STEP-PAR':
        if audit.consistent(a, b) and audit.conditionally_independent(a, b):
            return PathCredit(S=min(1.0, a.S + b.S - a.S * b.S), M=a.M * b.M)
        return PathCredit(S=min(a.S, b.S), M=a.M * b.M, veto=a.veto | b.veto)
    if op == 'STEP-VETO':
        return PathCredit(S=0.0 if (a.S == 0 or b.S == 0) else min(a.S, b.S),
                          veto=a.veto | b.veto)

# IP-308 τ_align + 局部撤销
def revoke_by_token(token_span, commitments):
    for c in commitments:
        if c.align_span.intersects(token_span):
            c.revoke(reason='TOKEN_UNTRUSTED')            # 只撤销依赖该词的承诺
    return [c for c in commitments if not c.revoked]

# IP-309 STEPGAUGE 主闭环（复用 R73 三域，过程信用贯穿）
def STEPGAUGE_round(M, obs, audio, tac_frame, depth_img):
    # 感知域
    d_ev = M.dpe.update(depth_img, rgb, M.cam_state, M.motion, M.peers)
    t_ev = M.dmem.update(tac_frame, M.last_action)
    s_ev = M.slec.update(audio, M.asr, M.calib)           # IP-303：格 + 歧义
    # 计量域
    if M.clock.due_metric():
        node, M.M = step_credit_trace(s_ev, M.M, M.delta, M.kappa, M.theta)  # IP-304
        act = commitment_gate(node, s_ev, M.budget, M.cfg)                   # IP-305
        if act in ('WAIT', 'ASK'):
            s2, c = reflex_L(act, M.slec_mod, M.state, M.budget)             # IP-306
            M.state = s2 if s2 is not None else M.state
        elif act == 'ACT':
            g = M.ervoi.choose(..., credit=node.s)                           # R73†
            if g and sigmareflex_step(M.mods, g, M.state, M.budget)[0] is not None:
                M.last_g = g
        M.snapshot.write(..., s_ev=s_ev, SCT=node, J_STEP=J_STEP(M))         # IP-309
    # 控制域（1kHz，只读快照）
    snap = M.snapshot.read_latest()
    lam = embodied_risk_scale(snap.U_ale, snap.U_epi, snap.H_z,
                              max(snap.t_ev.u, snap.d_ev.u, snap.s_ev.u),
                              M.risk_params)
    k = M.c_ras_wm.certified_prefix(M.ach.propose_ctrl(..., pvop_bias=snap.pvop), lam)
    return k, lam, J_STEP(M), J_MOD(M.mreg)
```

## 3. 推导

**引理 45（语音六分量条件正交性）** 给定 `(口音, LM 上下文, 领域, 信道, 对齐区间, 流式位置)` 条件，六分量由独立机制产生（发音变体、先验、词表、声学信道、边界、部分假设），条件近似不相关；遗漏任一 ⇒ 系统性低估（与 R73 引理 33 同型）。系：**语音不确定度不是"给置信度加个方差"，而是把 DPEM 的"(动作, 场景)条件"推广为"(说话人, 信道, 时间)条件"。**

**引理 46（步骤信用单调：无凭空信用）** STEP-SER 取 `min`、STEP-PAR 仅在一致性审计 + 条件独立时上升、STEP-VETO 归零 ⇒ 任何组合路径信用 ≤ 路径最小信用；未刷新时 e-process 只随新证据变化，历史信用不增。系：**与 R73 组合单调性同型——过程不产生认知免费午餐。**

**引理 47（安全歧义否决的可靠性）** 若 `Z_α` 安全歧义，则存在 `π,π′∈Z_α` 使 `c(π)≠c(π′)`（否决语义不同）。任何确定性 commit `a*` 必在其中至少一个校准一致的世界里违反安全类或违反"动作有依据"；故在 `1−α` 置信水平上，commit 不被支持。系：**歧义下唯一可靠的动作是获取更多证据（WAIT/ASK），不是融合。**

**引理 48（e-process 可选停止有效性）** 在定义 386 的条件有效性下，`M_t` 为非负鞅/上鞅；Ville ⇒ `P(∃t: M_t≥1/δ)≤δ`。故在任意数据依赖的停止时刻承诺，假承诺率 ≤δ。反之，若用每步 `p_t≤δ` 反复偷看，`P(∃t≤K)=1−(1−δ)^K`，随 K 膨胀。系：**"等到分数够"的合法性来自 e-process，不来自置信度阈值本身。**

**引理 49（承诺门控的阈值最优性）** 在成本结构（定义 390）与单调似然比下，最优停止集是 `{M_t≥τ}` 形式的继续/停止区域；`h_commit` 是首个进入停止集且消歧的时刻，故良定义且对 `δ`、`L_cat` 单调（`δ↓` 或 `L_cat↑` ⇒ 承诺更晚）。系：**门控不是启发式，是带风险约束的最优停止。**

**引理 50（步骤分选择性认证的 risk–coverage 优势）** 在步骤分校准（定义 385）下，按 `S` 做选择性认证的 selective risk 随覆盖率单调、且在同一覆盖率下不高于任何仅依赖结局的排序（结局排序对"过程有效性"的 AUC≈0.5，只有随机排序能力）；形式化地，`P(V=0 | S≥θ) ≤ ρ(θ)`，而结果-only 的 `P(V=0 | safe)` 无法被控制（可高达幸运率）。系：**结果-only 会把幸运安全当作可认证对象。**

**引理 51（L5 有限停止与预算吸收）** 每次监听/追问成本正下界 `ε_L`，边际信息增益 `Δu_asr` 随音频/澄清饱和非增 ⇒ 存在有限 `n*`；与 ΣREFLEX 预算合算后仍有限停止（R73 引理 36 的 L5 推广）。系：**多一层反作用不破坏停止性，层数仍由模块声明。**

**引理 52（步骤级局部撤销的因果充分性）** 在 `align` 单射（不同 token 区间不相交，A115）下，撤销 `provenance` 与 `token_span` 相交的承诺，恰好撤销所有、且仅撤销依赖于该 token 的动作；不误伤无关承诺。系：**溯源粒度 = 撤销粒度 = 信用粒度，三者一致。**

**定理 34（STEPGAUGE 严格包含 MODGAUGE）** 令步骤分退化为结局 bool、SLEC 退化为 best-1、CGC 退化为固定端点、`χ_L=id`、`θ=0`，则 `J_STEP` 退化为"结果证书"，`SCT` 退化为 R73 ECG，主闭环逐指令等于 R73；再退化为 R72/R71/R68。**安全单调不减。**

**定理 35（J_STEP ∧ J_MOD ⇒ 过程安全）** 若 `Valid(J_STEP)` 且 `Valid(J_MOD)`，则对每个被承诺动作：空间契约闭合（R73 定理 28）且过程信用闭合（引理 46/48），故 (i) 物理执行风险 ≤ `ε_mod`；(ii) 假承诺率 ≤ `δ`；(iii) 承诺时刻的解释集合不含未处理安全歧义。**证明重量落在步骤分校准在分布外仍成立、以及 e 值条件有效性不被流式非可交换性破坏。**

**定理 36（步骤级零级联）** 单步骤失效 ⇒ 该步 `s=0` + 局部撤销（定义 396）⇒ 仅依赖于该步的承诺被撤销，其余步骤与模态不受污染；不可定位时才回退模块 stub。系：**失效传染路径从"整个模态"缩到"依赖该证据的承诺集合"。**

**定理 37（过程层热替换保持）** 若 `impl′` 与 `impl` 满足同一 `SLEC/SCT` 契约且 `cert′` 有效，则 `J_STEP` 的信用链结构与停止语义逐指令保持；归纳于 SCT 的 DAG。系：**换 ASR / 换 LM / 换意图网只需模块级重认证，过程证书不重算。**

## 6. 本轮最大风险

**一句话**：STEPGAUGE 把安全证明的负担从「系统级审计」转移到「**步骤分在流式非可交换数据上的校准**」——一旦每步 conformal p 值不再条件有效（口音/信道漂移、说话人变化、对抗性置信度膨胀），e-process 的 Ville 保证就名存实亡；系统可以「合法地」一直等待、把 M_t 推到 1/δ、然后**以随时有效（anytime-valid）的自信承诺一个错误的、安全极性翻转的解释**，而每一步的校准日志都显示「合规」。

次级风险与缓解：
1. **非可交换流式音频** → 在线 conformal / 加权 e-process + 漂移检测；检测到非平稳即冻结校准、降低 δ、回退 best-1 保守模式。
2. **安全歧义检测器本身漏检（否定/同音）** → 极性分类器独立于 ASR、专用语义否定测试集、漏检即触发 VETO（保守默认）。
3. **步骤分自证循环（用语音证据给语音步骤打分）** → 跨模态外部锚（视觉/触觉/本体）+ 留出集校准 + SEAL-Contract 审计；不允许单源自评。
4. **e-process 停滞/预算耗尽导致无法行动** → ASK/ABORT 兜底 + 人类负担预算 + 分层 δ（安全关键命令更严）。
5. **格 top-k 截断导致真意图不在 Z_α** → top-k 自适应 + 覆盖率在线监控 + 截断即视为安全歧义。
6. **步骤级撤销误伤/漏撤** → align 单射假设 A115 的在线校验 + 撤销影响域静态分析 + E403 精确性验收。
7. **过程信用过保守使系统不可用** → 分层 θ（照护/协作场景与危险操作不同）+ 效率-安全 Pareto 预注册。
8. **MB4/MB5 过拟合** → 密封保持集 SEAL-MB + 预注册指标 + 三方复现（承接 E385 协议）。

## 2. 形式化定义（要点版）

**定义 383（总览与六不变式）** 过程完备 / 步骤分校准 / 可选停止有效 / 歧义否决 / 信用单调 / 严格退化。

**定义 384（SCT）** 证据-决策 DAG `G=(V,E)`；`s_i=φ(e_{≤i},d_i,EC_i)`；路径信用取 min 或 e-process 乘积；缺省零（stub 信用=0）。

**定义 385（步骤分校准）** `P(violation|s_i≥θ)≤ρ(θ)≤1−θ`；conformal 形式 `s_i=1−p_i`；缺失证据信用为零，规避模态无收益。

**定义 386（e-process）** `E[E_i|F_{i−1}]≤1`；`M_t=∏E_i`；Ville `P(∃t:M_t≥1/δ)≤δ`；`E(p)=κp^{κ−1}`。承诺需 `M_t≥1/δ` 且无安全歧义。

**定义 387（SLEC）** 加权格 + 对齐；`Z_α` 为 conformal 语义集；类型 `Set[Sense]`，禁止静默压成点。

**定义 388（语音六分量）** 声学 / LM / 领域 / 信道 / 对齐 / 承诺；各有独立追溯链，与 DPEM 六分量同构。

**定义 389（安全歧义与解释否决）** `Z_α` 跨安全极性 ⇒ 禁止 ACT（解释层 VETO，非补偿）。歧义不是方差，是离散风险。

**定义 390（CGC）** 四动作与成本；`P(误承诺)≤δ`；风险约束下的最优停止，阈值策略（引理 49）。

**定义 391（h_commit）** 首个 `M_t≥1/δ ∧ 非歧义 ∧ CCA/J_MOD 通过` 的时刻；由证据决定而非超参数。

**定义 392（χ_L）** `listen(Δ)/ask(q)` 降低 `(u_aco,u_chan,u_commit,u_dom)`；正成本 + 边际增益非增 ⇒ 有限停止。

**定义 393（τ_align）** 词级溯源；支持只撤销依赖不可信 token 的承诺；可复算。

**定义 394（SCA）** STEP-SER 取 min；STEP-PAR 仅在一致性审计 + 条件独立时上升；STEP-VETO 归零；信用单调。

**定义 395（J_STEP）** 完整 SCT ∧（`min s_i≥θ` 或 `M_t≥1/δ`）∧ 无未处理歧义 ∧ provenance 可复算 ∧ 无 stub 正信用 ∧ 校准有效。与 J_MOD 联合 ⇒ 定理 35。

**定义 396（过程级降级）** 步骤失效 ⇒ `s=0` + 局部撤销 + 路径截断；不可定位才回退模块 stub。步骤级零级联。

**定义 397（步骤 stub）** 证据 ∅、`s=0`、否决=该步命题全集；保留在 SCT 中但不贡献正信用、不作 PAR 缩窄源。

**定义 398（MB4/MB5）** 语音过程基准 / 过程信用基准；预注册 + 固定种子 + 密封保持集。

**定义 399（CPB v2）** C4 过程信用 / C5 格证据 / C6 承诺门控，各绑定最小基准与隔离消融。

## 3. 关键算法伪代码

```python
# IP-303 SLEC：语音格证据（感知域，流式）
class SpeechLatticeEvidence:
    def update(self, audio_chunk, asr, calib):
        L = asr.decode_lattice(audio_chunk)              # 加权格 + 时间对齐
        senses = {}
        for pi in L.paths(top_k=32):
            p = calib.conformal_pvalue(L, pi)            # 留出集校准
            if p > self.alpha:
                senses[sense(pi)] = min(senses.get(sense(pi), 1.0), p)
        Z = set(senses)                                   # Set[Sense]，绝不压成点
        u = math.sqrt(self.u_aco(L)**2 + self.u_lm(L)**2 + self.u_dom(L)**2
                      + self.u_chan(L)**2 + self.u_align(L)**2
                      + self.u_commit(L)**2)              # 六分量
        return SpeechEvidence(Z=Z, u=u, ambiguous=safety_ambiguous(Z),
                              align=L.align, tau=self.tchain.merge(L.tau))

# IP-304 SCT：步骤分 + e-process（计量域，50Hz）
def step_credit_trace(ev, prev_M, delta, kappa, theta):
    p = ev.conformal_p if hasattr(ev, 'conformal_p') else (1.0 - ev.step_score)
    e = kappa * max(p, 1e-15) ** (kappa - 1.0)            # 合法 e 值
    M = prev_M * e
    s = 0.0 if ev.is_stub else (1.0 - p)                  # 缺省信用为 0
    return StepNode(s=s, e=e, M=M), M

# IP-305 CGC：承诺门控（act / wait / ask / abort）
def commitment_gate(node, ev, budget, cfg):
    if ev.ambiguous:
        return 'WAIT' if budget.audio_left > 0 else 'ASK'  # 歧义绝不 ACT
    if node.M >= 1.0 / cfg.delta and node.s >= cfg.theta:
        return 'ACT'
    if budget.spent_reflex + cfg.lam_w * cfg.dt > budget.B:
        return 'ABORT'
    return 'WAIT'

# IP-306 χ_L：L5 监听/追问反作用通道
def reflex_L(action, mod, state, budget, cfg):
    if action == 'LISTEN':
        chi, cost = mod.ec.chi_R(('listen', cfg.dt)), cfg.lam_w * cfg.dt
    elif action == 'ASK':
        chi, cost = mod.ec.chi_R(('ask', cfg.query)), cfg.lam_q + cfg.human_cost
    else:
        return state, 0.0
    s2 = mod.propagate(state, chi)                        # E[u_asr] 下降，非手写层
    if budget.spent + cost > budget.B or s2 not in mod.safe_set:
        return state, 0.0
    return s2, cost

# IP-307 SCA：步骤信用代数
def compose_credit(a, b, op, audit):
    if op == 'STEP-SER':
        return PathCredit(S=min(a.S, b.S), M=a.M * b.M,
                          u=a.u + lipschitz(b, a.u), D=a.D & b.D)
    if op == 'STEP-PAR':
        if audit.consistent(a, b) and audit.conditionally_independent(a, b):
            return PathCredit(S=1.0 - (1.0 - a.S) * (1.0 - b.S), M=a.M * b.M)
        return PathCredit(S=min(a.S, b.S), M=a.M * b.M, veto=a.veto | b.veto)
    if op == 'STEP-VETO':
        return PathCredit(S=0.0 if (a.S == 0 or b.S == 0) else min(a.S, b.S),
                          veto=a.veto | b.veto)

# IP-308 τ_align + 局部撤销
def revoke_by_token(token_span, commitments):
    for c in commitments:
        if c.align_span.intersects(token_span):
            c.revoke(reason='TOKEN_UNTRUSTED')            # 只撤销依赖该词的承诺
    return [c for c in commitments if not c.revoked]

# IP-311 STEPGAUGE 主闭环（复用 R73 三域，过程信用贯穿）
def STEPGAUGE_round(M, obs, audio, tac_frame, depth_img):
    d_ev = M.dpe.update(depth_img, rgb, M.cam_state, M.motion, M.peers)
    t_ev = M.dmem.update(tac_frame, M.last_action)
    s_ev = M.slec.update(audio, M.asr, M.calib)           # IP-303：格 + 歧义
    if M.clock.due_metric():
        node, M.M = step_credit_trace(s_ev, M.M, M.delta, M.kappa, M.theta)  # IP-304
        act = commitment_gate(node, s_ev, M.budget, M.cfg)                   # IP-305
        if act in ('WAIT', 'ASK'):
            s2, c = reflex_L(act, M.slec_mod, M.state, M.budget, M.cfg)      # IP-306
            M.state = s2 if s2 is not None else M.state
        elif act == 'ACT':
            g = M.ervoi.choose(..., credit=node.s)                           # R73†
            if g and sigmareflex_step(M.mods, g, M.state, M.budget)[0] is not None:
                M.last_g = g
        M.snapshot.write(..., s_ev=s_ev, SCT=node, J_STEP=J_STEP(M))         # IP-309
    snap = M.snapshot.read_latest()
    lam = embodied_risk_scale(snap.U_ale, snap.U_epi, snap.H_z,
                              max(snap.t_ev.u, snap.d_ev.u, snap.s_ev.u),
                              M.risk_params)
    k = M.c_ras_wm.certified_prefix(M.ach.propose_ctrl(..., pvop_bias=snap.pvop), lam)
    return k, lam, J_STEP(M), J_MOD(M.mreg)
```

## 4. 推导

**引理 45（语音六分量条件正交性）** 条件于 (口音, LM 上下文, 领域, 信道, 对齐区间, 流式位置)，六分量由独立机制产生，条件近似不相关；遗漏任一 ⇒ 系统性低估。系：**语音不确定度是 DPEM「(动作, 场景) 条件」的进一步推广到「(说话人, 信道, 时间) 条件」。**

**引理 46（步骤信用单调）** STEP-SER 取 min、STEP-PAR 仅在一致性审计 + 条件独立时上升、STEP-VETO 归零 ⇒ 组合路径信用 ≤ 路径最小信用；未刷新时沿时间非增。系：**过程不产生认知免费午餐。**

**引理 47（安全歧义否决可靠性）** `Z_α` 安全歧义 ⇒ 任何确定性 commit 在至少一个校准一致世界里违反安全类；在 `1−α` 水平上不被支持。系：**歧义下唯一可靠动作是获取更多证据，不是融合。**

**引理 48（e-process 可选停止有效性）** 条件有效 ⇒ `M_t` 非负上鞅；Ville ⇒ `P(∃t:M_t≥1/δ)≤δ`；反例：每步 `p≤δ` 反复偷看，假阳性 `1−(1−δ)^K` 随 K 膨胀。系：**"等到分数够"的合法性来自 e-process。**

**引理 49（门控阈值最优性）** 成本结构 + 单调似然比 ⇒ 最优停止集为 `{M_t≥τ}`；`h_commit` 良定义且对 `δ`、`L_cat` 单调。系：**门控是带风险约束的最优停止，不是启发式。**

**引理 50（步骤分选择性认证优势）** 步骤分校准下 `P(V=0|S≥θ)≤ρ(θ)`；结果-only 的 `P(V=0|safe)` 不可控（可高达幸运率）。系：**结果-only 把幸运安全当作可认证对象。**

**引理 51（L5 有限停止）** 监听/追问正成本下界 + 边际信息增益非增 ⇒ 有限 `n*`；ΣREFLEX 合算后仍有限停止。系：**加一层反作用不破坏停止性。**

**引理 52（步骤级撤销因果充分性）** align 单射（A115）下，撤销与 token_span 相交的承诺，恰好撤销所有且仅依赖该 token 的动作。系：**溯源粒度 = 撤销粒度 = 信用粒度。**

**定理 34（STEPGAUGE 严格包含 MODGAUGE）** 步骤分→结局、SLEC→best-1、CGC→固定端点、`χ_L=id`、`θ=0` ⇒ `J_STEP` 退化结果证书、SCT 退化 ECG、主闭环逐指令等于 R73，再退化 R72/R71/R68。**安全单调不减。**

**定理 35（J_STEP ∧ J_MOD ⇒ 过程安全）** 若双证书 Valid，则每承诺动作空间契约闭合（R73 定理 28）+ 过程信用闭合（引理 46/48）⇒ 物理风险 ≤`ε_mod`、假承诺率 ≤`δ`、承诺时刻无未处理安全歧义。**证明重量落在步骤分校准在分布外成立、e 值条件有效性不被非可交换性破坏。**

**定理 36（步骤级零级联）** 单步骤失效 ⇒ `s=0` + 局部撤销 ⇒ 仅依赖该步的承诺被撤销；不可定位才回退模块 stub。系：**失效传染路径从"整个模态"缩到"依赖该证据的承诺集合"。**

**定理 37（过程层热替换保持）** 同 `SLEC/SCT` 契约 + 有效 cert ⇒ `J_STEP` 信用链结构与停止语义逐指令保持；归纳于 SCT DAG。系：**换 ASR/LM/意图网只需模块级重认证。**

## 8. 本轮最大风险

**一句话**：STEPGAUGE 把安全证明的负担从「系统级审计」转移到「**步骤分在流式非可交换数据上的校准**」——一旦每步 conformal p 值不再条件有效（口音/信道漂移、说话人变化、对抗性置信度膨胀），e-process 的 Ville 保证就名存实亡；系统可以「合法地」一直等待、把 M_t 推到 1/δ，然后以随时有效（anytime-valid）的自信承诺一个错误的安全极性翻转解释，而每一步的校准日志都显示合规。

次级风险与缓解：
1. **非可交换流式音频** → 在线 conformal / 加权 e-process + 漂移检测；非平稳即冻结校准、降 δ、回退 best-1 保守模式。
2. **安全歧义检测器漏检（否定/同音）** → 极性分类器独立于 ASR + 专用否定测试集；漏检默认 VETO。
3. **步骤分自证循环** → 跨模态外部锚（视觉/触觉/本体）+ 留出集校准 + SEAL-Contract；禁止单源自评。
4. **e-process 停滞/预算耗尽致无法行动** → ASK/ABORT 兜底 + 人类负担预算 + 分层 δ（安全关键更严）。
5. **格 top-k 截断漏掉真意图** → top-k 自适应 + 覆盖在线监控 + 截断即视为安全歧义。
6. **步骤级撤销误伤/漏撤** → align 单射假设 A115 在线校验 + 撤销影响域静态分析 + E403 验收。
7. **过程信用过保守使系统不可用** → 分层 θ + 效率-安全 Pareto 预注册。
8. **MB4/MB5 过拟合** → 密封保持集 SEAL-MB + 预注册 + 三方复现。
