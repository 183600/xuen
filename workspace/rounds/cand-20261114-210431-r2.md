# 第 2 轮（灵感循环第 2 轮；本轮灵感：「自主导航」×「灵巧手」）

> 承接第 1 轮 **LeanGauge**：D-Box 发现「需求盲区」、I-Box 用「可预测自助下注」采样、BP-Cal 做少样本局部校准、4CV 完成局部热替换。第 1 轮最大的风险是**自证循环**：I-Box 用同一个 DPEM 产生 σ_pred 来决定探测什么，又用同源观测去校准它；一旦遭遇环境突变或「盲区注入」，系统会把「从未被真正测量」误判为「已经覆盖」。
>
> 本轮把 LeanGauge 从「抽象子空间里的自助下注」推进到「物理世界里的主动干预」：
> - **自主导航**提供「到达能力」：把盲区从矩阵里的一个格子，变成世界里一个可规划、可安全抵达的地点；
> - **灵巧手**提供「干预能力」：用按压、滑动、抓取这些 `do(g)` 操作，获得与视觉通道独立、且必须由真实物理世界作答的接触回执；
> - 两者相乘，把第 1 轮的「可预测下注」升级为「可达 × 可激励 × 可观测」的**物理挑战-应答**。
>
> 核心命题：**不要把「模型同意模型」当作证据；要让世界通过一次安全的触碰来作证。**
>
> 方案命名 **ReachGauge**（触达计量）：Reach 是自主导航的「触达」，Gauge 是灵巧手的「计量」。它在不破坏 R73/MODGAUGE 五不变式的前提下，为 LeanGauge 增加一个「具身证据层」。

## 0. 直觉与动机

**直觉 1（自主导航 → 盲区是一个「地点」，不是一行矩阵）**
第 1 轮的盲区 s=(d,m,i) 只存在于覆盖矩阵里，系统知道「这里没数据」，却不知道「这里在哪里、能不能去、去了安不安全」。自主导航恰好补齐这一维：每个盲区对应世界中一组物理实现位置 φ(s)（某块反光地面、某个低摩擦边缘、某片未建模的桌角）。于是问题从「该不该采样」变成**带风险的主动探索**：值不值得走这段路、站在哪里、是否给自己留好退路。盲区因此获得三个新属性——可达性、抵达代价、探针价值。

**直觉 2（灵巧手 → 接触是最难伪造的「物证」）**
视觉可以「看起来对」，接触不行：世界必须真实地提供法向刚度、切向摩擦、接触几何与滑移响应。灵巧手的价值不只是「多一个传感器」，而是**能做干预实验**：轻拍测法向刚度，切向滑动测摩擦，包络抓取测形状闭合，双指对压测材料软硬。这正是从「观察性计量」到「干预性计量」的跃迁。一次设计良好的干预，能把「模型不确定」变成「参数不可辨识/可辨识」的明确判断；如果手只沿法向轻拍，摩擦参数根本不可辨识——系统就应当拒绝为它签发证书，而不是猜一个值。

**直觉 3（两者相乘 → 认证前沿的「胡须式」扩张）**
主动探测本身有风险：为了看清未知，机器人可能先走进未知。ReachGauge 的关键约束是**只从已知的边缘伸手，不把身体探进未知**：维护一个已认证安全集 C（certified set），机器人只在 C 内移动到前沿 F(C)，再用灵巧手作为「胡须」越过前沿做接触探测；只有接触回执确认前沿之外与契约一致后，才把认证集向外扩一小块。这把「好奇」关进了「安全包络」里。
一把灵巧手因此成为整台机器人的触须：**用最小的暴露面积，换取对未知的最大信息增益。**

**关键转向（相对第 1 轮）**：观察性计量问「观测是否落在契约预测内」；干预性计量问「当我主动改变世界的作用量时，世界的反作用是否与契约预测一致」。后者更难被「同一模型的偏差」自我满足——因为回执来自独立物理通道，且必须由真实材质、真实力响应兑现。

## 0.1 思路轨迹（研究者视角）

1. **先找第 1 轮的死穴**：I-Box 的 σ_pred 与 BP-Cal 的观测同源，证据不独立；盲区没有物理位置，无法用「到场」来排除误判。
2. **拿灵感词做碰撞**：自主导航提供「到场 + 覆盖 + 信息增益路径」；灵巧手提供「接触 + 干预 + 多指冗余」。一个负责「去哪里」，一个负责「怎么问」。
3. **合成新机制**：把「探测」重定义为「一次受安全包络约束的物理挑战-应答」，把「校准」重定义为「以接触为锚点的跨模态局部外推」，把「探索」重定义为「认证前沿的单调扩张」。
4. **补上可证伪性**：给出最小可检测违约（MDR）、持续激励（PE）与相关长度，说明「能测多大的谎、能在多远外推、何时必须拒绝认证」。
5. **保留退化路径**：不可达/不可激励/不可观测的盲区，不硬修，转为「守卫证书 + 受限策略」，避免第 1 轮「自信地放大盲区」的风险。

## 1. 形式化定义（增量：定义 416–430）

约定：S 为第 1 轮的盲区子空间集合；X = M_surface × M_semantic 为物理位置与语义材质流形；θ ∈ Θ 为接触物理参数（法向刚度 κ、切向摩擦 μ、接触几何 g0、阻尼 c 等）；g ∈ G 为灵巧手干预（力轨迹 + 手指构型 + 运动基元）；EC 为模块计量契约。

**定义 416（具身需求地图 E-Map）**
对每个 s ∈ S，令 φ(s) ⊆ X 为其物理实现位置集。E-Map 为
E[s] = (n_verify, [u_lo, u_hi], cost_risk, φ(s), ρ_reach, ρ_excite, ρ_obs, V_probe)，
其中：
- ρ_reach(s) = max_{x∈φ(s)} Pr(∃ 安全路径 γ: C → x0，且 x ∈ Reach_arm(x0))；
- ρ_excite(s) = max_{g∈G} λ_min(∫_0^T Φ_g(t)^T Φ_g(t) dt) 的归一化值，Φ_g = ∂h/∂θ；
- ρ_obs(s) = λ_min(J_g^T Σ_c^{-1} J_g) 的归一化值；
- V_probe(s) 见定义 426。
E-Map 是 LeanGauge 的 R 矩阵在「物理可实施性」上的扩张：R 记录「测过没有」，E-Map 记录「能不能测、值不值得测」。

**定义 417（R-E-O 可探测性）**
盲区 s 可探测 ⇔
Π(s) = 1[ρ_reach(s) ≥ ρ_R ∧ ρ_excite(s) ≥ ρ_E ∧ ρ_obs(s) ≥ ρ_O ∧ V_probe(s) ≥ V_min]。
- R（Reachability）：存在不穿越未认证区域的安全路径，且目标在手臂工作空间内；
- E（Excitability）：存在干预 g 使待辨识参数满足持续激励，Fisher 信息正定；
- O（Observability）：接触回执对该参数的灵敏度高于标定噪声。
Π(s)=0 时称 s 为**不可探测盲区**，必须走定义 429 的守卫证书，而不是假装修好了。

**定义 418（接触回执 Contact Receipt, CR）**
一次干预产生的回执
r = h_θ(g; x_s) + ε，ε ~ N(0, Σ_c)，
r = (p_c, f, τ, I_tac, q, t) 包含接触质心、六维力/力矩、触觉图、关节本体感觉与时间戳。**计量可追溯性条件**：Σ_c 与 h 的零偏必须由已知参考件（已知质量/刚度/摩擦的标准块）离线标定；否则接触只是「另一个有偏传感器」，不构成独立证据。

**定义 419（物理挑战-应答检验）**
在契约 EC 声明的参数下，回执的预测分布为 p_EC(r|g)。构造统计量
T(r,g) = (r - μ_EC(g))^T Σ_EC(g)^{-1} (r - μ_EC(g))。
H0：世界与 EC 一致；H1：存在契约违约。当 T > χ²_{d_r, 1-α} 时拒绝 H0，标记 s 为「契约失配」，进入局部校准或退化。
与第 1 轮 CAS 的区别：CAS 监控**被动观测**是否越界；这里系统**主动施加 g**，考察世界的因果反作用是否兑现契约。

**定义 420（最小可检测违约 MDR）**
对违约方向 δθ，非中心参数为
λ(δθ, g) = δθ^T J_g^T Σ_c^{-1} J_g δθ，J_g = ∂h/∂θ|_g。
在显著性 α、功效 1-β 下，可检测的最小违约幅度为
δ_min(g) = sqrt( (z_{1-α} + z_{1-β})² / λ_unit(g) )。
含义：接触并非万能，它只能抓住「足够大的谎言」；δ_min 给出了「这次触碰能为多大的误差背书」的硬边界。

**定义 421（持续激励与局部可辨识）**
干预轨迹 g(t) 对 θ 是 k 阶持续激励的，若回归矩阵 Φ_g(t) 满足
∫_0^T Φ_g(t)^T Φ_g(t) dt ≽ α I_k，α > 0。
此时 θ 在 g 下局部可辨识。反例：只做纯法向轻拍，切向摩擦 μ 的回归列近似为零，μ 不可辨识；系统必须拒绝签发 μ 的证书。

**定义 422（接触锚定跨模态校准）**
先验 u(x) ~ GP(μ_0, k_0)，接触锚点 A = {(x_i, y_i)}_{i=1}^{N_A}，复合核
k(x,x') = k_geo(x,x') · k_sem(x,x')，
其中 k_geo 用表面测地距离，k_sem 用材质/语义相似度。后验
μ_A(x) = μ_0(x) + k_A(x)^T (K_AA + Σ_c)^{-1} (y_A - μ_0(x_A))，
σ_A²(x) = k_0(x,x) - k_A(x)^T (K_AA + Σ_c)^{-1} k_A(x)。
用后验更新 EC 的 u_fields、χ_R、D，实现第 1 轮 BP-Cal 的「接触版」局部校准。

**定义 423（探针安全包络 PSE）**
一条「导航 γ + 干预 g」的探针轨迹是 PSE-允许的，当且仅当 ∀t：
1. 位姿不确定椭球完全落在 EC 认证的自由空间内；
2. 接触力/冲量在 [f_min, f_max] 与关节力矩上限内；
3. 预测的最坏反作用（物体移动、滑移、回弹）不违反任务安全不变式；
4. 机器人始终保留一条回到认证集 C 的已认证退路。
任一不满足即中止探针；中止不是失败，而是「用一次放弃换取安全」。

**定义 424（探针副作用算子与可逆性）**
干预 g 诱导世界状态迁移 do(g): w → w'。定义任务相关副作用度量 Δ(w,w')。若 Δ ≤ ε_rev，称探针**可逆**，其影响可作为 EC 的小扰动界吸收；否则称**破坏性探针**，必须持有显式「破坏性证书」并经操作者授权，且不得走局部热替换，而要为「新世界」重新签发契约。

**定义 425（认证前沿与胡须扩张）**
认证集 C_t ⊆ SE(3) 为当前契约下可保证安全的位姿集合；前沿
F(C_t) = { x0 ∈ ∂C_t : ∃ s, x ∈ φ(s) 使 x ∈ Reach_arm(x0) }。
扩张规则：只在 F(C_t) 处伸手探测；仅当挑战-应答通过，才令
C_{t+1} = C_t ∪ B(x_contact, r_cert)，
其中 r_cert 是接触可证的小邻域半径。若检验拒绝，则 C 不扩张，并把 x_contact 之外标为守卫区。

**定义 426（探针价值 / 信息-风险比）**
V_probe(s) = IG(s) / (C_nav(s) + C_probe(s) + λ_R · R_probe(s))，
其中 IG(s) 为回执与 θ 的期望互信息（KL 增益），C_nav 为抵达代价，C_probe 为干预代价，R_probe 为 PSE 下的最坏风险，λ_R 为风险价格。只有 V_probe ≥ V_min 才值得出动。

**定义 427（双尺度 4CV / TS-4CV）**
- **D（Detect）**：由 LeanGauge D-Box + E-Map 检出盲区并算 V_probe；
- **R（Reach）**：Nav-Planner 在 C 内规划到前沿的安全路径；
- **P（Probe）**：Dex-Probe 选择持续激励干预，执行挑战-应答；
- **U（Update）**：Anchor-GP 以接触为锚做跨模态校准，热替换 EC 或签发守卫证书，并按定义 425 扩张 C。
一次 TS-4CV 的终点只有三种：修复、标记不可探测、降级，杜绝「无证据通过」。

**定义 428（ReachGauge 总览）**
ReachGauge = (MODGAUGE, LeanGauge, E-Map, Nav-Planner, Dex-Probe, Anchor-GP, PSE)。
LeanGauge 是「发现与采样层」，ReachGauge 是叠加其上的「具身证据层」；五不变式保持不变。

**定义 429（不可探测盲区的守卫证书）**
若 Π(s)=0，为 s 签发守卫证书 g(s)：
- 不确定性膨胀 u_guard(s) = u_decl(s) + Δ_guard(s)，Δ_guard 覆盖「无法排除的最坏偏差」；
- 策略约束 π|_{s} = ⊥（禁止在该子空间执行高代价动作）；
- 证书声明：在 u_guard 下，受限策略对任意与观测一致的世界都安全。
若任务强制需要进入 s，则触发任务级降级/求助，而不是让探针硬闯。

**定义 430（接触-导航定位耦合，可选增强）**
接触时手-物闭合给出基座位姿测量
z_contact = T_base_hand(q) · T_hand_contact，
可作为导航位姿滤波器的一次更新，降低定位漂移。该耦合不改变安全论证，只提供额外信息通道；在 SLAM 失效场景中可作为「触觉重定位」。

# IP-320 E-Map：把 LeanGauge 的覆盖矩阵扩展为具身需求地图
class EmbodiedMap:
    def __init__(self, S, X, arm_reach, depth_sensor):
        self.E = {s: Cell(n=0, u_interval=None, cost=0.0,
                          sites=phi(s, X),                        # 物理实现位置集
                          rho_reach=0.0, rho_excite=0.0,
                          rho_obs=0.0, v_probe=0.0) for s in S}
        self.C = certified_set()                                  # 已认证安全集
        self.arm_reach = arm_reach

    def probeable(self, s, rho_R, rho_E, rho_O, v_min):
        c = self.E[s]
        return (c.rho_reach >= rho_R and c.rho_excite >= rho_E
                and c.rho_obs >= rho_O and c.v_probe >= v_min)

    def frontier(self):
        return [x0 for x0 in boundary(self.C)
                if any(x in reach_ball(x0, self.arm_reach)
                       for s in self.E for x in self.E[s].sites)]

# IP-321 Nav-Planner：风险约束下的信息增益路径（自适应子模贪心 + 安全剪枝）
class NavPlanner:
    def __init__(self, emap, gp, path_budget, risk_price):
        self.emap, self.gp = emap, gp
        self.B, self.lam = path_budget, risk_price

    def plan(self, s_candidates):
        tour, C, budget, ig = [], self.emap.C.copy(), self.B, 0.0
        while s_candidates and budget > 0:
            best = None
            for s in s_candidates:
                x0 = nearest_station(s, self.emap.C)             # 只从前沿伸手
                path = safe_path(self.emap.C, x0)                # 路径必须 ⊆ C
                if path is None:
                    continue                                     # 不可达 → 不参与
                gain = self.gp.expected_mutual_info(s)            # 自适应子模
                cost = path.length + self.lam * pse_risk(path)
                score = gain / max(cost, 1e-6)
                if best is None or score > best.score:
                    best = (s, path, gain, cost)
            if best is None or best.gain / best.cost < V_MIN:
                break
            s, path, gain, cost = best
            tour.append((s, path))
            budget -= cost
            ig += gain
            s_candidates.remove(s)
            # 注意：此处不立即扩张 C；扩张必须等 P 阶段回执确认（定义 425）
        return tour, ig
```

# IP-322 Dex-Probe：持续激励的干预设计 + 物理挑战-应答
class DexProbe:
    def __init__(self, hand, contact_model, sigma_c, alpha=0.01, beta=0.2):
        self.hand, self.h, self.Sigma = hand, contact_model, sigma_c
        self.alpha, self.beta = alpha, beta

    def design_intervention(self, s, theta_uncertain):
        """在力矩/力限制与 PSE 下最大化 Fisher 信息（等价最小化 MDR）"""
        best = None
        for g in hand.skill_library:                              # tap / press / slide / pinch
            if not pse_admissible(g, s):
                continue
            Phi = self.h.regressor(g, s)                          # ∂h/∂θ
            I = Phi.T @ inv(self.Sigma) @ Phi
            if lambda_min(I) < ALPHA_PE:                          # 不满足持续激励
                continue
            mdr = self.min_detectable_violation(I)
            if best is None or mdr < best.mdr:
                best = (g, I, mdr)
        return best                                               # None ⇒ 不可激励

    def challenge_response(self, s, g):
        r = self.hand.execute(g)                                  # 物理执行，非仿真
        pred = self.h.predict(g, s, theta=self.h.ec.theta)
        T = mahalanobis(r, pred, self.Sigma)
        accept = T <= chi2_ppf(1 - self.alpha, df=len(r))
        return accept, r, T, self.h.local_information(g, s)
```

# IP-323 Anchor-GP：以接触为锚的跨模态局部校准
class AnchorGP:
    def __init__(self, mu0, k0):
        self.mu0, self.k0 = mu0, k0

    def calibrate(self, anchors, x_query, Sigma_c):
        Xa = [a.x for a in anchors]
        ya = [a.y for a in anchors]
        Kaa = self.k0(Xa, Xa) + Sigma_c
        Kaq = self.k0(Xa, x_query)
        mean = self.mu0(x_query) + Kaq.T @ solve(Kaa, ya - self.mu0(Xa))
        var = self.k0(x_query, x_query) - Kaq.T @ solve(Kaa, Kaq)
        return mean, var

    def certified_radius(self, anchors, eps):
        """由后验方差反解可信外推半径；超出即守卫区，禁止认证"""
        return invert_variance_envelope(anchors, eps)             # 引理 49

# IP-324/325 TS-4CV 与 ReachGauge 主闭环
def reach_gauge_ts4cv(RG, s):
    if not RG.emap.probeable(s, RHO_R, RHO_E, RHO_O, V_MIN):
        return RG.issue_guard_certificate(s), "UNPROBEABLE"

    x0, path = RG.nav.plan_to_frontier(s)                         # Reach
    if path is None or not RG.safety.enter(path):                 # PSE 拒绝
        return RG.issue_guard_certificate(s), "NO_SAFE_REACH"

    g = RG.dex.design_intervention(s, RG.gp.theta_uncertainty(s))
    if g is None:                                                 # 无法持续激励
        return RG.issue_guard_certificate(s), "UNEXCITABLE"

    accept, r, T, fisher = RG.dex.challenge_response(s, g)        # Probe
    RG.emap.E[s].n_verify += 1
    if not accept:
        if not RG.safety.pse_holds(g, r):                         # 探针引发危险
            return RG.abort_and_retreat(), "PROBE_ABORTED"
        if destructive(g, r) and not RG.operator_authorized(s):
            return RG.issue_guard_certificate(s), "DESTRUCTIVE_DENIED"
        RG.loglevel = "CONTRACT_MISMATCH"
        return RG.issue_guard_certificate(s), "MISMATCH"

    anchors = RG.dex.to_anchors(r, s)                             # Update
    radius = RG.gp.certified_radius(anchors, EPS_CERT)
    new_ec = RG.gp.update_contract(RG.mreg, s, anchors, radius)
    if not contract_valid(new_ec) or not budget_ok(RG):
        return RG.issue_guard_certificate(s), "BUDGET_OR_CONTRACT"
    RG.mreg.hot_replace(s, new_ec)                                # 局部热替换
    RG.emap.C = RG.emap.C | ball(anchors[0].x, radius)            # 胡须式扩张
    return True, "REPAIRED"


def ReachGauge_round(RG, obs, audio, tac, depth, dets):
    # 任务尺度：先补证据，再做当轮；任何补证据动作都受 PSE 与实时抢占约束
    for s in sorted(RG.emap.blind_spots(), key=lambda z: -V(z)):
        status = reach_gauge_ts4cv(RG, s)
        if status == "REPAIRED":
            break
        if RG.preempted_by_realtime():
            break
    return MODGAUGE_round(RG.M, obs, audio, tac, depth, dets)
```

## 3. 推导

**引理 46（接触回执的可检测性下界）**
设接触传感器已按定义 418 标定，力-位移模型 h 对 θ 局部 Lipschitz，Jacobian 为 J_g。对违约方向 δθ，n 次独立重复干预的非中心参数为 n·λ(δθ,g)。则挑战-应答检验在显著性 α 下以功效 ≥ 1-β 检出 δθ 的充分条件为
n ≥ (z_{1-α} + z_{1-β})² / λ(δθ,g) = (δ_min(g) / ||δθ||)²。
系：MDR 随 sqrt(n) 下降、随接触噪声 σ_c 线性上升、随灵敏度 ||J_g|| 反比下降。这解释了为什么「摸得越准、激励越充分，越能戳穿小偏差」。

**引理 47（认证前沿扩张的安全单调性）**
若每一步扩张都满足 PSE，且 r_cert 只覆盖被接触回执直接支持的邻域，则认证集序列 C_0 ⊆ C_1 ⊆ … 安全单调：在 EC 为真的世界中，机器人以概率 1 不进入未认证的不安全状态；在 EC 为假的世界中，接触挑战会在扩张之前以引理 46 的功效检出该违约（若违约幅度 ≥ δ_min）。
证明要点：对步数归纳。PSE 保证轨迹始终在 C_t 内且保留退路；扩张仅在检验通过后发生；r_cert 的保守性保证新纳入区域没有「未被任何回执覆盖的内部」。注意：这是**条件安全**，条件是 EC 的误差不超过 δ_min 且 PSE 模型正确。

**引理 48（信息增益路径的近似保证）**
GP 观测的期望互信息在候选探针上是自适应子模的；在路径预算 B 与安全可行性约束下，贪心选址达到最优期望 IG 的 (1 - 1/e) 近似；若安全约束使可行集非拟阵，则退化为经验近似比，需在实验中报告实际比值。
证明要点：Golovin–Krause 的自适应子模 greedy 定理；GP 互信息自适应子模性来自核矩阵的子模性。诚实说明：安全剪枝可能破坏形式保证，因此本文把它作为「有条件的工程保证」。

**引理 49（接触锚定的外推极限）**
对任意查询点 x，接触锚点集 A 的后验方差满足
σ_A²(x) ≤ σ_0²(x) · (1 - ρ²(x, A))，
其中 ρ(x,A) 为归一化核相关。若复合核随测地距离 d_geo 与语义距离 d_sem 指数衰减，则 ρ 的有效相关长度 ℓ 有限；超出 ℓ 后 σ_A² 回到先验量级。
系：**一次触碰不能为整片区域背书**。可认证半径 r_cert 必须由 σ_A² ≤ ε_cert 反解，超出即守卫区。这条直接约束了「以点代面」的过度外推。

**引理 50（双尺度契约保持）**
若 (i) 导航契约满足位姿/路径不变式，(ii) 接触契约满足力/接触不变式，(iii) PSE 成立，(iv) 热替换满足第 1 轮引理 44，则 ReachGauge 的复合系统保持 MODGAUGE 五不变式；探针作为「内部实验」只更新 u-field 与认证集，不改变契约代数本身。
注意边界：若探针是破坏性的（定义 424），世界已被改变，此时**不得**热替换旧契约，必须为新世界重新签发契约；引理 50 不覆盖这一情形，这是有意的保守设计。

**引理 51（探针的时间与预算）**
每个探针周期 ≤ τ_probe（导航 + 操作），总预算 ≤ B_probe；50Hz 控制环与 REG 硬实时契约不受影响，因为探针运行在任务/计量尺度，且可被实时安全事件抢占并断点续行。
证明要点：探针的所有原语都在 PSE 内且可中止；抢占后 C 与 E-Map 保持一致（事务式更新），不会留下半认证状态。

**引理 52（不可探测盲区的安全退化）**
若 Π(s)=0，则守卫证书 g(s) 的膨胀不确定性 u_guard 是对所有与观测一致世界的保守过近似；任何满足 π|_s = ⊥ 的受限策略在 u_guard 下安全。
证明要点：标准鲁棒过近似 + 契约单调性；Δ_guard 覆盖「因不可探测而无法排除」的最坏偏差。

## 6. 本轮最大风险

**一句话**：ReachGauge 最大的风险是「以点代面」——一次局部、可逆性未经证明的接触回执，被相关长度有限的外推和「认证前沿」的乐观扩张放大为对整片未知区域的认证；若探针本身不可逆地改变了环境或耗尽了退路，那么系统会**用一次触碰为一片未知背书，并在此过程中失去纠错的第二次机会**。

次级风险与缓解：
1. **接触标定漂移** → 每次任务前用参考件做零点/增益自检；Σ_c 失配即拒绝探针（定义 418 的可追溯性条件）。
2. **MDR 之外的「小谎」** → 守卫证书总是吸收 δ_min 以下残差；不得把「未检出」当作「无违约」。
3. **相关长度外推过度** → r_cert 由后验方差反解（引理 49），并用独立第二次接触做交叉验证；外推区默认守卫。
4. **PSE 模型错误** → 第 0 层物理包络（力/温/电流/碰撞）兜底；PSE 违约即中止并回退到 C。
5. **破坏性探针** → 定义 424 的破坏性证书 + 操作者授权；未授权一律不执行。
6. **导航不可达/被围困** → 保留退路作为硬约束；无退路则不探，直接守卫证书。
7. **多指接触的几何/摩擦耦合导致辨识病态** → 检查 Fisher 条件数；病态则增加激励基元或拒绝认证（定义 421）。
8. **任务时间被探针耗尽** → V_probe 与 B_probe 双预算；实时事件可抢占并断点续行（引理 51）。

## 2. 形式化定义（要点）

**定义 416（E-Map）** 把 LeanGauge 的 R 扩张为
`E[s] = (n_verify, [u_lo,u_hi], cost_risk, φ(s), ρ_reach, ρ_excite, ρ_obs, V_probe)`。
R 记录「测过没有」，E-Map 记录「能不能测、值不值得测」。

**定义 417（R-E-O 可探测性）**
`Π(s) = 1[ρ_reach ≥ ρ_R ∧ ρ_excite ≥ ρ_E ∧ ρ_obs ≥ ρ_O ∧ V_probe ≥ V_min]`。
- Reach：存在不穿越未认证区域的安全路径且目标在臂展内；
- Excite：存在 g 使 `∫Φ_g^TΦ_g ≽ αI`，参数局部可辨识；
- Observe：`λ_min(J_g^TΣ_c^{-1}J_g)` 高于标定噪声。
`Π(s)=0` 即**不可探测盲区**，只能走守卫证书。

**定义 418（接触回执 CR）** `r = h_θ(g;x_s)+ε`，`ε~N(0,Σ_c)`，含接触质心、六维力/力矩、触觉图、关节本体感觉与时间戳。**可追溯性条件**：Σ_c 与零偏需由已知参考件标定，否则接触不构成独立证据。

**定义 419（物理挑战-应答）**
`T(r,g) = (r-μ_EC(g))^T Σ_EC(g)^{-1} (r-μ_EC(g))`；`T > χ²_{d_r,1-α}` 则拒绝「契约一致」。
与 CAS 的区别：CAS 监控被动观测越界；这里系统主动施加干预，考察世界反作用是否兑现契约。

**定义 420（MDR）**
`δ_min(g) = sqrt((z_{1-α}+z_{1-β})² / λ_unit(g))`，`λ_unit` 为 `J_g^TΣ_c^{-1}J_g` 的最小特征值。
含义：接触只能抓住「足够大的谎言」；δ_min 以下必须由守卫证书吸收。

**定义 421（持续激励与可辨识）**
`∫_0^T Φ_g(t)^TΦ_g(t)dt ≽ αI_k` 时 θ 在 g 下局部可辨识。反例：纯法向轻拍无法辨识切向摩擦 μ，系统必须拒绝为 μ 签发证书。

**定义 422（接触锚定 GP）**
`μ_A(x) = μ_0(x)+k_A(x)^T(K_AA+Σ_c)^{-1}(y_A-μ_0(x_A))`，
`σ_A²(x) = k_0(x,x)-k_A(x)^T(K_AA+Σ_c)^{-1}k_A(x)`，
核 `k = k_geo · k_sem`。后验写回 EC 的 u_fields/χ_R/D，实现第 1 轮 BP-Cal 的接触版。

**定义 423（PSE）** 位姿不确定椭球 ⊆ 认证自由空间；力/冲量/力矩在限内；最坏反作用不违反任务不变式；始终保留回 C 的已认证退路。任一不满足即中止。

**定义 424（副作用算子）** `do(g): w→w'`；`Δ(w,w') ≤ ε_rev` 为可逆，可吸收为 EC 小扰动；否则为破坏性探针，需显式证书与授权，且不得热替换旧契约，须为新世界重签发。

**定义 425（认证前沿与胡须扩张）**
`F(C_t) = {x0∈∂C_t : ∃s, x∈φ(s), x∈Reach_arm(x0)}`；
只在 F(C_t) 伸手；检验通过才 `C_{t+1}=C_t ∪ B(x_contact, r_cert)`。
**不把身体探进未知，只从已知边缘伸手。**

**定义 426（探针价值）** `V_probe(s)=IG(s)/(C_nav+C_probe+λ_R R_probe)`，仅当 ≥ V_min 才出动。

**定义 427（TS-4CV）** D：E-Map 检盲区并算 V_probe；R：Nav-Planner 在 C 内到前沿；P：Dex-Probe 持续激励 + 挑战-应答；U：Anchor-GP 校准、热替换或守卫证书、扩张 C。出口只有修复/不可探测/降级三态。

**定义 428（ReachGauge）** `(MODGAUGE, LeanGauge, E-Map, Nav-Planner, Dex-Probe, Anchor-GP, PSE)`。

**定义 429（守卫证书）** `Π(s)=0` 时签发：`u_guard = u_decl + Δ_guard`，策略 `π|_s = ⊥`，证书声明受限策略在 u_guard 下安全；任务强制进入则降级/求助。

**定义 430（接触-导航耦合，可选）** `z_contact = T_base_hand(q)·T_hand_contact` 作为导航位姿更新，可在 SLAM 失效时做「触觉重定位」。

# IP-320 E-Map
class EmbodiedMap:
    def probeable(self, s, rho_R, rho_E, rho_O, v_min):
        c = self.E[s]
        return (c.rho_reach >= rho_R and c.rho_excite >= rho_E
                and c.rho_obs >= rho_O and c.v_probe >= v_min)

    def frontier(self):
        return [x0 for x0 in boundary(self.C)
                if any(x in reach_ball(x0, self.arm_reach)
                       for s in self.E for x in self.E[s].sites)]
```

```python
# IP-321 Nav-Planner：自适应子模贪心 + 安全剪枝（路径必须 ⊆ C）
def plan(emap, gp, s_candidates, B, lam):
    tour, budget = [], B
    while s_candidates and budget > 0:
        best = max(
            ((s, p, gp.expected_mutual_info(s), p.length + lam*pse_risk(p))
             for s in s_candidates
             for p in [safe_path(emap.C, nearest_station(s, emap.C))]
             if p is not None),
            key=lambda z: z[2] / max(z[3], 1e-6), default=None)
        if best is None or best[2] / best[3] < V_MIN:
            break
        s, path, gain, cost = best
        tour.append((s, path)); budget -= cost
        s_candidates.remove(s)
        # 不在此扩张 C：扩张必须等 P 阶段回执确认（定义 425）
    return tour
```

```python
# IP-322 Dex-Probe：持续激励干预 + 挑战-应答
class DexProbe:
    def design_intervention(self, s, theta_unc):
        best = None
        for g in self.hand.skill_library:            # tap/press/slide/pinch
            if not pse_admissible(g, s):
                continue
            Phi = self.h.regressor(g, s)
            I = Phi.T @ inv(self.Sigma) @ Phi
            if lambda_min(I) < ALPHA_PE:             # 不满足 PE
                continue
            mdr = self.min_detectable_violation(I)
            if best is None or mdr < best.mdr:
                best = (g, I, mdr)
        return best                                  # None ⇒ 不可激励

    def challenge_response(self, s, g):
        r = self.hand.execute(g)                     # 物理执行
        pred = self.h.predict(g, s, theta=self.h.ec.theta)
        T = mahalanobis(r, pred, self.Sigma)
        return T <= chi2_ppf(1-self.alpha, len(r)), r, T
```

```python
# IP-323 Anchor-GP：接触锚定校准 + 可认证外推半径
def calibrate(anchors, xq, mu0, k0, Sigma_c):
    Xa, ya = [a.x for a in anchors], [a.y for a in anchors]
    Kaa = k0(Xa, Xa) + Sigma_c
    Kaq = k0(Xa, xq)
    mean = mu0(xq) + Kaq.T @ solve(Kaa, ya - mu0(Xa))
    var  = k0(xq, xq) - Kaq.T @ solve(Kaa, Kaq)
    return mean, var

def certified_radius(anchors, eps):
    return invert_variance_envelope(anchors, eps)    # 引理 49
```

```python
# IP-324/325 TS-4CV 与主闭环
def reach_gauge_ts4cv(RG, s):
    if not RG.emap.probeable(s, RHO_R, RHO_E, RHO_O, V_MIN):
        return RG.issue_guard_certificate(s), "UNPROBEABLE"
    x0, path = RG.nav.plan_to_frontier(s)             # Reach
    if path is None or not RG.safety.enter(path):
        return RG.issue_guard_certificate(s), "NO_SAFE_REACH"
    g = RG.dex.design_intervention(s, RG.gp.theta_uncertainty(s))
    if g is None:
        return RG.issue_guard_certificate(s), "UNEXCITABLE"
    accept, r, T = RG.dex.challenge_response(s, g)    # Probe
    RG.emap.E[s].n_verify += 1
    if not accept:
        if not RG.safety.pse_holds(g, r):
            return RG.abort_and_retreat(), "PROBE_ABORTED"
        if destructive(g, r) and not RG.operator_authorized(s):
            return RG.issue_guard_certificate(s), "DESTRUCTIVE_DENIED"
        return RG.issue_guard_certificate(s), "MISMATCH"
    anchors = RG.dex.to_anchors(r, s)                 # Update
    radius = RG.gp.certified_radius(anchors, EPS_CERT)
    new_ec = RG.gp.update_contract(RG.mreg, s, anchors, radius)
    if not contract_valid(new_ec) or not budget_ok(RG):
        return RG.issue_guard_certificate(s), "BUDGET_OR_CONTRACT"
    RG.mreg.hot_replace(s, new_ec)
    RG.emap.C |= ball(anchors[0].x, radius)           # 胡须式扩张
    return True, "REPAIRED"

def ReachGauge_round(RG, obs, audio, tac, depth, dets):
    for s in sorted(RG.emap.blind_spots(), key=lambda z: -V(z)):
        status = reach_gauge_ts4cv(RG, s)
        if status == "REPAIRED" or RG.preempted_by_realtime():
            break
    return MODGAUGE_round(RG.M, obs, audio, tac, depth, dets)
```

## 4. 推导

**引理 46（接触可检测性）** 已标定接触、Lipschitz 模型 h、Jacobian J_g 下，n 次独立干预的非中心参数为 n·λ(δθ,g)；检验以功效 ≥1-β 检出 δθ 的充分条件为 `n ≥ (δ_min(g)/||δθ||)²`。系：MDR 随 √n 下降、随 σ_c 线性上升、随 ||J_g|| 反比下降。

**引理 47（前沿扩张的安全单调性）** 若每步扩张满足 PSE 且 r_cert 只覆盖接触直接支持的邻域，则 `C_0⊆C_1⊆…` 安全单调；EC 为真时以概率 1 不进入未认证不安全状态；EC 为假且违约 ≥ δ_min 时，挑战在扩张前检出。**这是条件安全**，条件为违约不小于 MDR 且 PSE 模型正确。

**引理 48（信息路径近似）** GP 期望互信息自适应子模；路径预算与安全可行约束下，贪心选址达到 `(1-1/e)` 近似；若安全剪枝破坏拟阵结构，则退化为经验近似比并在 E427 报告实际比值。

**引理 49（外推极限）** `σ_A²(x) ≤ σ_0²(x)(1-ρ²(x,A))`。复合核指数衰减时相关长度 ℓ 有限，超出 ℓ 后验方差回到先验量级。系：**一次触碰不能为整片区域背书**；r_cert 必须由 `σ_A² ≤ ε_cert` 反解。

**引理 50（双尺度契约保持）** 导航契约 + 接触契约 + PSE + 第 1 轮引理 44 ⇒ 复合系统保持 MODAUGE 五不变式。边界：破坏性探针改变了世界，此时不得热替换旧契约，须为新世界重签发；引理不覆盖该情形，这是有意的保守设计。

**引理 51（时间与预算）** 每探针 ≤ τ_probe，总 ≤ B_probe；50Hz 控制环与 REG 硬实时不受影响，探针在任务尺度运行且可被实时安全事件抢占、断点续行。

**引理 52（守卫证书安全）** `Π(s)=0` 时，`u_guard` 是对所有与观测一致世界的保守过近似；受限策略在 u_guard 下安全。证明：鲁棒过近似 + 契约单调性。

## 7. 本轮最大风险

**一句话**：ReachGauge 最大的风险是「以点代面」——一次局部、可逆性未经证明的接触回执，被有限相关长度的外推与乐观的前沿扩张放大为对整片未知区域的认证；若探针不可逆地改变环境或耗尽退路，系统将**用一次触碰为一片未知背书，并失去纠错的第二次机会**。

次级风险与缓解：
1. **接触标定漂移** → 任务前参考件自检；Σ_c 失配即拒绝探针（定义 418）。
2. **MDR 以下的「小谎」** → 守卫证书吸收 δ_min 以下残差；不把「未检出」当「无违约」。
3. **外推过度** → r_cert 由后验方差反解（引理 49），并用独立第二次接触交叉验证；外推区默认守卫。
4. **PSE 模型错误** → 第 0 层物理包络兜底；违约即中止回退到 C。
5. **破坏性探针** → 定义 424 证书 + 操作者授权；未授权不执行、不热替换。
6. **导航被围困** → 退路为硬约束；无退路则不探，直接守卫证书。
7. **多指耦合病态** → 检查 Fisher 条件数；病态则增激励基元或拒绝认证（定义 421）。
8. **任务时间耗尽** → V_probe 与 B_probe 双预算；实时事件可抢占并断点续行（引理 51）。
