# 第 61 轮（承接第 60 轮「场景感知闭环」IP-153~160；灵感循环第 7 轮；本轮灵感：「安全交互」×「点云配准」）

> 第 60 轮建立了「场景→意图→约束→阻抗→执行→证据→场景更新」的认知闭环 SGEC。但**三个结构性盲点**仍未触及：
> 1. **语义有先验、接触无几何**：SSM 用 π_scene(K|z) 给出场景先验，CIEC 用意图给约束，但没有任何机制验证「接触真的发生在模型以为的位置」。场景说是「桌面」，力却落在边缘——语义正确、几何错误，闭环照样误判。
> 2. **安全是标量阈值，不是空间性质**：K_safe、F_max、τ_response 全是标量；而真实的安全交互取决于**接触点在整个末端执行器表面上的分布、法向与滑移**。总力合格但接触点偏心的抓取，局部压强仍可能超限。
> 3. **证据有因果、无空间一致性**：EPIR 保证 EV-exec 的 seq/hash 不乱序、不丢失，但一条因果完美的证据仍可能**建立在错误的外参/接触坐标系上**——证据链完整，却整体错位。
>
> 本轮的核心转向：**把「安全交互」从标量阈值问题，改写为「接触点云的安全感知配准」问题**。安全不是「力小于 F_max」，而是「预测的接触流形与观测的接触流形能否被一个可信的刚体变换对齐，且该变换的不确定度被膨胀进安全包络」。

## 0. 直觉与动机

**灵感 1（安全交互 → 接触不是一个数，而是一片点云）**
直觉：一次接触从来不是「一个力值」，而是末端表面上一组带法向、带力矩、带局部柔度的**接触点云** C = {(p_i, n_i, w_i)}。安全交互的破坏性往往来自「局部」：边缘压强、切向滑移、偏心扭矩。只要把末端表面离散成点云，每次接触就变成一次**分布式的空间观测**，安全判据也从「max 力」升级为「接触点云的几何-力场包络」。ISO/TS 15066 的压强/力限值本质上是在约束这片点云在人体表面上的**投影**，而不是单个关节力矩。

**灵感 2（点云配准 → 用配准残差作为安全证书）**
直觉：点云配准的常规用途是估位姿；这里反过来用——**配准是「预测接触」与「观测接触」之间的一致性检验**。预测点云 C_pred 由「规划轨迹 × 场景先验 π_scene」生成，观测点云 C_obs 由分布式触觉/力传感生成。若存在一个刚体变换 T 把 C_pred 对齐到 C_obs，且残差小、内点高、协方差低，说明「我们以为要碰的地方」与「实际碰到的地点」一致，安全证书 J_reg = (T, Σ_T, κ_inl, r_max) 成立；否则说明模型与现实的接触几何已经脱节，必须降级。**配准残差是一个比力阈值更早、更细粒度的安全信号。**

**灵感 3（鲁棒配准的暗面 → 假安全 false-safe）**
直觉：ICP 在**部分重叠、对称、离群、可变形**的接触点云上极易落入错误局部极小——而这恰好是真实安全交互的常态（只碰到一角、桌面左右对称、人手非刚体）。危险在于：错误配准往往**收敛得很自信**（残差小、内点高），于是系统在**错误的坐标系**里算出「安全」，这才是真正的灾难。因此配准必须配「多假设 + 歧义门 + 保守并集包络」：当两个位姿盆地难分伯仲时，安全必须在**所有合理假设下同时成立**，取安全包络的**交集**（保守），而不是取最优假设的包络。

**灵感 4（三灵感合流 → CRISP：安全不是阈值，是可验证的共享坐标系）**
直觉：把 SSM 的场景先验当作配准初值/先验，把 CIEC 的意图当作配准的安全约束（意图『轻触』直接收紧包络），把 EPIR 的因果证据当作配准观测的时序锚点；反过来，配准给出的 T 与 Σ_T 又**回灌**到 EEIS 的 K_safe 编译与 ERTC 的约束锁定。核心闭环变成：**场景先验 → 预测接触点云 → 观测接触点云 → 安全感知配准 → 配准证书 → 安全包络 → 阻抗/约束 → 执行 → 新证据**。一句话：**安全交互 = 人机之间维持一个可验证的共享接触坐标系。**

**灵感 5（配准预算 B_reg → PCE+++++）**
直觉：配准不是免费的——迭代次数、对应点数量、假设数、协方差收敛都是资源。若把配准当作无限算力，就会在算力紧张时**悄悄输出一个未收敛的 T**。因此把 B_reg 加入预算族：协方差未达 Cov_target 而预算耗尽 ⇒ 冻结上一次 T 并按 δ_T^max 膨胀安全距离；膨胀超过工作空间余量 ⇒ STOP。这样「配准不确定」不会变成「静默的假安全」。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（接触点云 CPC）** 末端执行器表面 S 的 ε-网采样给出 P_EE = {(p_i, n_i, c_i)}_{i=1..N}（p_i∈R³ 为 EE 系坐标，n_i 单位法向，c_i 局部柔度）。一次安全交互的接触点云为
C = (P, N, W, Σ)，其中
- 预测点云：P_pred = T_plan · P_EE，w_i^pred = π_scene.predict_wrench(n_i)（由第 60 轮场景先验给出期望法向力/切向力）；
- 观测点云：P_obs = {(q_j, f_j, Σ_j^q, Σ_j^f)}_{j=1..M}（分布式触觉阵列/关节力矩估计反演）；
- 点云统一记为 C = {(x_k, n_k, w_k, Σ_k)}，x_k∈R³，w_k=(f_k, τ_k)∈R⁶。
CPC 使「接触」从标量 F 变为带几何、带力场、带不确定度的**分布式对象**。

**定义 162（安全感知鲁棒配准 SRR）** 给定 C_pred、C_obs 与先验 T_prior（来自 SSM 场景先验或上周期 T），求解
```
T* = argmin_{T∈SE(3)} Σ_{i∈I(T)} ρ_σ( || q_{c(i)} − T p_i ||²_{Σ_i} )
                    + λ_n Σ_{i∈I(T)} (1 − n_{c(i)}ᵀ R n_i)
                    + λ_r || T ⊖ T_prior ||²_Γ
```
其中 c(i) 为门控最近邻对应（半径 3σ、法向夹角 < 45°），ρ_σ 为 GNC-TLS 鲁棒核（σ 从 0.10 退火到 σ_min），最后一项把 SSM 场景先验作为正则。SRR 输出安全门
```
G(T*) = [κ_inl ≥ τ_inl] ∧ [r_max ≤ ε_r] ∧ [tr(Σ_T) ≤ τ_cov]
```
只有 G 通过，T* 才被接受；否则进入多假设/保守模式。

**定义 163（配准不确定度—安全距离膨胀 DIB）** 设真实变换 T 与估计 T̂ 满足 ||T̂ ⊖ T||₂ ≤ δ_T 以概率 ≥ 1−α，工作空间半径为 R，有符号距离场 d(·) 为 L_d-Lipschitz。则对任意 x：
```
| d(T̂x) − d(Tx) | ≤ L_d·||T̂−T||·||x|| ≤ L_d·R·δ_T
```
因此把**观测到的**安全距离阈值抬升 Δd_safe = L_d·R·δ_T + z_{1−α}·sqrt(λ_max(Σ_T))，即可保证**真实**间隙满足 d(Tx) ≥ d_min 的概率 ≥ 1−α。力同理：|f̂ − f| ≤ L_f·δ_T，故力上限收紧为 f_cap = f_max − L_f·δ_T。**这是本轮最关键的推导：配准误差不是噪声，而是必须显式兑换成安全裕度。**

**定义 164（安全交互包络 SIE）** 配准后的安全交互包络
```
E_safe(T, J_reg) = { x : d(Tx) ≥ d_min + Δd_safe,
                          f_n(x) ≤ f_max − L_f·δ_T,
                          |f_t(x)| ≤ μ_s·f_n(x),
                          p_c(x) = f_n(x)/A_c ≤ p_max }
```
即同时约束**间隙、法向力、切向滑移（摩擦锥）、局部压强**（对齐 ISO/TS 15066 的 power-and-force limiting 思想）。配准安全证书
```
J_reg = (T*, Σ_T, κ_inl, r_max, δ_T, Δd_safe, δ_amb)
J_safe = (J_exec, J_reg)        # 与第 59 轮执行证书合流
```
J_safe 成立当且仅当 J_exec 成立且 G(T*) 通过且 E_safe 非空。

**定义 165（多假设配准与歧义门 MHR-AG）** 由位姿聚类（FPFH/法向直方图 + RANSAC 种子）得到假设集 H = {(T_j, w_j)}_{j=1..k}，w_j 为归一化内点权重。歧义缺口
```
δ_amb = w_(1) − w_(2)      # 降序
```
若 δ_amb < τ_amb，或累计质量达到 1−α 前跨越多个不同位姿盆地，则判为「配准歧义」。此时**不信任最优假设**，取保守包络
```
E_safe^cons = ⋂_{j : Σ_{l≤j} w_l ≥ 1−α} E_safe(T_j)
```
含义：在真实变换落入前 1−α 后验质量的所有可能盆地内，安全都必须成立。**宁可把包络收缩到空（→ STOP），也不接受一个自信但二义的 T。**

**定义 166（安全主动探测 SAP）** 探测动作 a（下一接触位置/微动轨迹）。期望信息增益
```
ΔH(a) = H(T | D) − E_{y_a}[ H(T | D, a, y_a) ]
```
选取
```
a* = argmax_a [ ΔH(a) − λ·cost(a) ]   s.t.  P( E_safe under a ) ≥ 1−β
```
即**风险有界**的主动感知：只在安全包络内选择最能消解配准歧义的接触。这把第 59 轮的主动探测从「信息-能耗」扩展为「信息-安全」二维前沿。

**定义 167（人机接触配准与意图落地 HCR）** 人体点云 P_H（部分可见、非刚体）。将其配准到机器人接近走廊，得到重叠率 ρ_ov 与预测接触点 ê。若 ρ_ov < τ_ov，**禁止**意图推断，CIEC 锁定「默认/危险」约束；若 ρ_ov 足够，则输出意图后验 P(I|P_H) 与 ê，经 ϕ_intent→constraint 收紧 B_intent/ERTC。非刚体部分用「局部刚体块 + 关节模型」近似，并显式标记非刚性残差为配准不确定度来源。

**定义 168（配准预算 B_reg 与 PCE+++++）** B_reg = (Iter_max, Corr_max, Hyp_max, Cov_target)。配准成本
```
cost_reg = λ_it·Iter + λ_co·Corr + λ_hy·Hyp
```
PCE+++++ 的 VOI：
```
voi_reg(π) = VOI_meta_pessimistic(π) − cost_cog(π) − cost_reg(π) − cost_exec(π)
```
若 B_reg 在达到 Cov_target 前耗尽：
- 若 δ_T^max < θ_freeze ⇒ 冻结上周期 T，按 Δd_safe(δ_T^max) 膨胀包络；
- 否则 ⇒ 返回 STOP（安全包络为空）。
**任何情况下都不允许「预算耗尽但仍按未收敛 T 继续」，从而杜绝静默假安全。**

### IP-162 SRR（安全感知鲁棒配准 + 安全门）

```python
class SafetyAwareRegistration:
    def __init__(self, tau_inl=0.7, eps_r=4e-3, tau_cov=1e-4,
                 iters=30, L_d=1.2, L_f=2.0, R=0.6):
        self.tau_inl, self.eps_r, self.tau_cov = tau_inl, eps_r, tau_cov
        self.iters, self.L_d, self.L_f, self.R = iters, L_d, L_f, R

    def register(self, C_pred, C_obs, T_prior, Sigma_prior, alpha=0.01):
        T = T_prior.copy()
        sigma = 0.10
        corr = None
        for _ in range(self.iters):
            corr = knn_correspondence(
                C_pred, C_obs, T,
                radius=3.0 * sigma, normal_gate=np.cos(np.deg2rad(45)))
            w = tls_weights(corr.r, sigma)            # GNC-TLS
            T, W = weighted_umeyama(C_pred.p, C_obs.p[corr.j], w)
            sigma = max(sigma * 0.85, 1e-3)

        Sigma_T = self._pose_covariance(corr, W, Sigma_prior)
        delta_T = self._mahalanobis_radius(Sigma_T, 1.0 - alpha)
        kappa = w.sum() / max(len(C_pred.p), 1)
        r_max = float(corr.r.max()) if corr.r.size else np.inf

        delta_d = self.L_d * self.R * delta_T \
                  + norm_ppf(1 - alpha) * np.sqrt(np.linalg.eigvalsh(Sigma_T).max())
        f_cap = self.f_max - self.L_f * delta_T

        J = RegistrationCert(T, Sigma_T, kappa, r_max, delta_T,
                             delta_d, f_cap)
        ok = (kappa >= self.tau_inl
              and r_max <= self.eps_r
              and np.trace(Sigma_T) <= self.tau_cov)
        return T, J, ok
```

### IP-164/165 SIE + MHR-AG（保守包络与歧义门）

```python
def multi_hypothesis_register(self, C_pred, C_obs, T_prior, k=5):
    seeds = self._pose_cluster_seeds(C_pred, C_obs)   # FPFH + RANSAC
    Hyps = []
    for T0 in seeds[:k]:
        T, J, ok = self.register(C_pred, C_obs, T0, self.Sigma_prior)
        if ok:
            Hyps.append((T, J, J.weight))
    Hyps.sort(key=lambda h: h[2], reverse=True)
    if not Hyps:
        return None, None, True

    w = normalize([h[2] for h in Hyps])
    delta_amb = w[0] - (w[1] if len(w) > 1 else 0.0)
    ambiguous = delta_amb < self.tau_amb

    keep, mass = 0, 0.0
    for j, wj in enumerate(w):
        keep, mass = j + 1, mass + wj
        if mass >= 1 - self.alpha:
            break
    E_cons = intersect_envelopes([envelope(h[0], h[1]) for h in Hyps[:keep]])
    if E_cons.is_empty():
        return Hyps, E_cons, True                       # 空包络 ⇒ STOP
    return Hyps, E_cons, ambiguous
```

### IP-166 SAP（风险有界的主动探测）

```python
def safe_active_probe(self, M, candidates):
    best = None
    for a in candidates:
        if not M.safety.predict_ok(a, beta=0.05):      # P(E_safe) ≥ 1-β
            continue
        dH = M.reg.expected_info_gain(a)               # 熵减 / 协方差收缩
        score = dH - self.lam * a.cost
        if best is None or score > best.score:
            best = ProbeCandidate(a, score, dH)
    if best is None:
        return None, "NO_SAFE_PROBE"                   # 不允许冒险探测
    return best, "OK"
```

### IP-168 PCE+++++（配准预算与降级）

```python
class RegistrationBudget:
    def __init__(self, iters=30, corr=400, hyps=5, cov_target=1e-4,
                 delta_T_max=0.02):
        self.iters, self.corr, self.hyps = iters, corr, hyps
        self.cov_target, self.delta_T_max = cov_target, delta_T_max

    def exhausted(self, used) -> bool:
        return (used.iter >= self.iters or used.corr >= self.corr
                or used.hyps >= self.hyps)

    def fallback(self, J):
        if np.trace(J.Sigma_T) >= self.cov_target:
            if J.delta_T < self.delta_T_max:
                return "freeze_and_inflate", J.delta_T
            return "STOP", None
        return "ok", J
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CPC | O(N + M) | O(N + M) | ε-网覆盖，法向噪声有界 |
| SRR | O(I·N log M)（kd-tree） | O(N + M) | 配准平移误差 ≤ 2 mm，旋转 ≤ 0.5° |
| MHR-AG | O(k·I·N log M) | O(k·N) | 歧义检出率 ≥ 95%，假安全率 ≤ 0.1% |
| SIE | O(N) | O(N) | 膨胀后真实安全违规 = 0（在 A67–A68 下） |
| SAP | O(|A|·N) | O(N) | 安全约束满足概率 ≥ 1−β |
| PCE+++++ | O(1) / 决策 | O(1) | 预算耗尽 ⇒ 单调降级至 STOP |

**正确性定理（CRISP）**：设 A66–A71 成立：
- **(A66)** CPC 为表面 ε-网，法向/力观测噪声有界；
- **(A67)** SRR 的鲁棒核保证内点集包含至少 τ_inl 比例的真实对应，且估计误差 ||T̂⊖T|| ≤ δ_T（以概率 1−α）；
- **(A68)** 距离场 d 与力映射 f 分别 L_d、L_f-Lipschitz；
- **(A69)** 真实变换落在 MHR 假设集前 1−α 质量内的概率 ≥ 1−α；
- **(A70)** SAP 的安全约束以概率 ≥ 1−β 成立；
- **(A71)** B_reg 单调消耗，耗尽即触发 fallback。

则：
1. **安全距离认证**：以 Δd_safe = L_d·R·δ_T + z_{1−α}√λ_max(Σ_T) 膨胀后，若观测间隙 ≥ d_min+Δd_safe，则真实间隙 ≥ d_min 的概率 ≥ 1−α——**配准误差被兑换为保守裕度，而非被忽略**。
2. **歧义保守性**：E_safe^cons = ⋂_{前 1−α 质量} E_safe(T_j) 非空 ⇒ 在 1−α 置信下，任一合理配准假设均满足安全；若为空 ⇒ STOP，绝不输出自信错误解。
3. **信息-安全前沿**：SAP 在 P(E_safe) ≥ 1−β 约束下最大化 ΔH，故单位风险信息增益不劣于任何被动策略。
4. **预算单调安全**：B_reg 耗尽 ⇒ freeze_and_inflate 或 STOP，不存在「未收敛仍放行」的路径。

> 注意定理是**条件性**的：只要 A67 的「内点包含真实对应」失败（错误盆地 + 高内点），证书会**自信地错**。这正是下一节的风险所在，也是为何必须叠加 SSM 场景先验交叉校验。

### IP-162 SRR（安全感知鲁棒配准）

```python
def register(self, C_pred, C_obs, T_prior, Sigma_prior, alpha=0.01):
    T, sigma = T_prior.copy(), 0.10
    for _ in range(self.iters):
        corr = knn_correspondence(C_pred, C_obs, T,
                                  radius=3*sigma, normal_gate=cos45)
        w = tls_weights(corr.r, sigma)
        T, W = weighted_umeyama(C_pred.p, C_obs.p[corr.j], w)
        sigma = max(sigma * 0.85, 1e-3)
    Sigma_T = self._pose_covariance(corr, W, Sigma_prior)
    delta_T = self._mahalanobis_radius(Sigma_T, 1 - alpha)
    kappa, r_max = w.sum()/len(C_pred.p), corr.r.max()
    delta_d = self.L_d*self.R*delta_T \
              + norm_ppf(1-alpha)*sqrt(eigvalsh(Sigma_T).max())
    J = RegistrationCert(T, Sigma_T, kappa, r_max, delta_T, delta_d,
                         self.f_max - self.L_f*delta_T)
    ok = kappa >= self.tau_inl and r_max <= self.eps_r \
         and trace(Sigma_T) <= self.tau_cov
    return T, J, ok
```

### IP-165 MHR-AG（多假设歧义门与保守包络）

```python
def multi_hypothesis_register(self, C_pred, C_obs, k=5):
    Hyps = []
    for T0 in self._pose_cluster_seeds(C_pred, C_obs)[:k]:
        T, J, ok = self.register(C_pred, C_obs, T0, self.Sigma_prior)
        if ok: Hyps.append((T, J, J.weight))
    Hyps.sort(key=lambda h: h[2], reverse=True)
    if not Hyps: return None, None, True
    w = normalize([h[2] for h in Hyps])
    delta_amb = w[0] - (w[1] if len(w) > 1 else 0.0)
    ambiguous = delta_amb < self.tau_amb
    keep, mass = 0, 0.0
    for j, wj in enumerate(w):
        keep, mass = j + 1, mass + wj
        if mass >= 1 - self.alpha: break
    E_cons = intersect_envelopes([envelope(h[0], h[1]) for h in Hyps[:keep]])
    return Hyps, E_cons, ambiguous or E_cons.is_empty()
```

def safe_active_probe(self, M, candidates):
    best = None
    for a in candidates:
        if not M.safety.predict_ok(a, beta=0.05):
            continue
        score = M.reg.expected_info_gain(a) - self.lam * a.cost

### IP-168 PCE+++++（配准预算降级）

```python
class RegistrationBudget:
    def __init__(self, iters=30, corr=400, hyps=5, cov_target=1e-4,
                 delta_T_max=0.02):
        self.iters, self.corr, self.hyps = iters, corr, hyps
        self.cov_target, self.delta_T_max = cov_target, delta_T_max
    def exhausted(self, used):
        return (used.iter >= self.iters or used.corr >= self.corr
                or used.hyps >= self.hyps)
    def fallback(self, J):
        if trace(J.Sigma_T) >= self.cov_target:
            if J.delta_T < self.delta_T_max:
                return "freeze_and_inflate", J.delta_T
            return "STOP", None
        return "ok", J
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性 |
|---|---|---|---|

| SRR | O(I·N log M) | O(N+M) | ≤ 2 mm / ≤ 0.5° |

| SIE | O(N) | O(N) | 膨胀后违规 = 0 |
| SAP | O(|A|·N) | O(N) | P(E_safe) ≥ 1−β |
| PCE+++++ | O(1) | O(1) | 耗尽 ⇒ STOP |

**正确性定理（CRISP）**：若 A66–A71 成立（CPC ε-网、SRR 误差 ≤ δ_T、d/f 分别 L_d/L_f-Lipschitz、真实变换在前 1−α 假设质量内、SAP 概率安全、B_reg 单调），则：
1. 以 Δd_safe 膨胀后，观测间隙 ≥ d_min+Δd_safe ⇒ 真实间隙 ≥ d_min 的概率 ≥ 1−α；
2. E_safe^cons 非空 ⇒ 前 1−α 质量内任一配准均安全；为空 ⇒ STOP；
3. SAP 在 P(E_safe)≥1−β 下取得不劣于被动的单位风险信息增益；
4. B_reg 耗尽 ⇒ freeze_and_inflate 或 STOP，无「未收敛仍放行」路径。

**核心推导（DIB）**：|d(T̂x)−d(Tx)| ≤ L_d·||T̂−T||·||x|| ≤ L_d·R·δ_T，故配准误差必须以安全距离膨胀的形式显式支付；力同理收紧 L_f·δ_T。
