# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「状态机」×「动力学」）

> R69 给了闭环一张嘴——它会问、会看、会摸。但它留下两个从未真正兑现的欠账：
> 1. **VoI 是"凭空"算的**。`VoI(g)=H(M|o)−E_{y∼p(·|g,o)}[H(M|o,y)]` 里的 `p(y|g,o)`——"如果我去问/看/触，我会学到什么"——R69 只在文字里假设它存在，却从未定义它。没有这个预测模型，MINT 的 `expected_entropy` 是一个它并不拥有的神谕。
> 2. **安全是一堆并列的 if**。`VoI≤成本`、`ECE>τ`、`slow_fault_suspect`、预算越界、投毒、OOD——每一条都独立判断、独立兜底，却没有任何东西保证这些分支**组合起来**仍然安全：会不会来回横跳？会不会永远"再问一次"？会不会从一个它以为安全的区域切进真正不安全的区域？R69 的"控制连续、无突变"只是口号，不是证明。
>
> 本轮两个灵感恰好是这两笔欠账的对偶补集：
> - **动力学**：把"我会学到什么"从神谕变成**受控动力系统**——不确定性/标定状态 `x=(U_ale,U_epi,ECE,r_res,a_score,b)` 在任务动作与信息动作下如何演化；于是 VoI 不再是一步启发式，而是**信念动力学上的有限时域最优控制**（对偶控制）。R69 的单步 VoI 恰好是 `H_p=1` 的退化。
> - **状态机**：把"这一堆 if"提升为**带守卫/不变式/滞留的监督混合自动机**；离散状态是"认知模式"（正常 / 消歧 / 锁定 / 兜底 / 疑似 / 重标定 / 安全停），守卫是动力学的水平集穿越。于是安全 = **可达性规避**，活性 = **排序函数**，稳定 = **切换 Lyapunov**。
>
> 核心命题：**FLUID-RAS 的下一步不是再加一个并列模块，而是把它整体"编译"成一个可认证的元层——HYDRA-RAS：一个连续状态为"怀疑的动力学"、离散状态为"认知模式"的混合自动机。R66–R69 全部被降为这个自动机里的"流 / 守卫 / 状态"，而不是被替换；因此新增这一层不新增黑箱，只新增局部证明义务。**
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我该在何时切换，以及这次切换本身是否安全**」——不确定性不只是信号或提问，它是一个**需要被控制、并且可以被证明受控**的动力系统。

## 0. 直觉与动机

**灵感 1（状态机 → R69 的分支其实已经是一台隐式状态机，只是没被承认）**
直觉：把 R69 的代码顺着时间展开，你会看到若干反复出现的"处境"：一切正常；有歧义值得问；问完了、锁定某个模态去执行；问不出来、只能保守；残差和似然对不上、怀疑标定被吸收；正在重标定；只能停车。这已经是**认知状态**的集合。R69 没把它们命名，于是它们以布尔变量的形式散落各处，互相之间没有守卫、没有滞留、没有"不许悄悄放松"的规则。显式化成状态机买到三样东西：(a) **组合性**——加一层 = 加一个状态 + 几条带证明的边，而不是改主循环的一堆 if；(b) **可审计性**——每次切换都有守卫、有证书、有日志；(c) **可证性**——可以谈论序列（滞留、Zeno、死锁、伪极限环），而这些是逐点规则根本无法表达的。

**灵感 2（动力学 → "会学到什么"本身是可控动力学，VoI 是多步最优控制）**
直觉：信息动作不是魔法。问一句，`U_epi` 按某个**信息率**下降；同时环境扰动会往系统里**重新注入**歧义；标定误差 ECE 会缓慢漂移；行为似然分 `a_score` 随观测偏移上升；预算被消耗。把这些写成一个受控 ODE/SDE `ẋ=f_Q(x,u,w)`，"问不问、问几次、何时停"就变成了在**信念动力学**上做有限时域规划——这正是经典的对偶控制（dual control）：动作同时改变物理状态和知识状态。R69 的单步 VoI 是 `H_p=1`、终端代价为 0 的特例。更重要的是，动力学给了"值不值得问"一个**结构性判据**：若信息率 `κ_g·I_g` 小于扰动注入率 `ρ_e·d`，则 `U_epi` 根本压不到阈值以下——此时 DISAMBIG 是一个**稳定但无用的吸引子**，正确动作是立刻 FALLBACK，而不是反复追问（见引理 20 的分岔阈值）。

**灵感 3（切换稳定性 → 三个各自稳定的控制器，切换起来未必稳定）**
直觉：R66 的控制分配、R67 的预测、R68 的保守缩放、R69 的交互策略，单看都可能稳定。但**切换系统**的经典教训是：多个稳定的子系统，在任意切换下可以发散。R69 说"交互只改选哪个模态、不改安全包络"，这只对单次切换成立；对"消歧→失败→兜底→重标定→再消歧"这种**序列**，没有任何保证。所以本轮必须给出切换证书：公共 Lyapunov 或带滞留时间的多 Lyapunov。这是 R69"无突变"口号的严格版本。

**灵感 4（安全 = 可达性 → 真正要证的不是"这个动作安全"，而是"不存在一条可达的切换路径会违规"）**
直觉：R68/R69 的安全都是"当前动作 + 当前不确定度 → 收紧"的**逐点**论证。但危险往往在序列里：一次安全的注视，把你带到一个"必须立即刹车但时间窗已过"的状态；一次可接受的等待，让标定缓慢漂移越过了恢复窗口。正确的提法是：在**有界模型误差** `𝔽` 下，从初始状态出发的**前向可达集**是否与不安全集 `𝕌` 相交。用鲁棒归纳不变式 + 控制障碍证书来证。这一下就把"这层没有黑箱"从口号变成了**证明义务**。

**灵感 5（严格包含 + 组合审计 → 元层不能是第六个黑箱）**
直觉：本项目最危险的失败模式是"每加一层就多一个需要独立信任的黑箱"。HYDRA 若只是又一层，就重蹈覆辙。所以它的定位必须是**归约**：R66 = 所有状态共用的执行层；R67 = Flow 里的预测项；R68 = NORMAL/FALLBACK 的控制律；R69 = DISAMBIG/SUSPECT 以及守卫。并且必须在边界上**逐指令**退化为 R69/R68。能做到这一点的唯一方式是同时启用"降级格 + 局部证明组合"：保守性只许在有新证据时放松，且整栈证书由每状态局部证书与每条边局部证书拼成（定理 21）。这样"加一层"只多一个**局部**证明，而不是重验整栈。

## 1. 形式化定义（增量：定义 310–324）

**定义 310（HYDRA-RAS 总览）** HYDRA-RAS = (H, 𝔇, 𝔽, MPIC, CERT, SLC, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i、R69 定义 293-i）；
(ii) **切换即证明**：任一离散切换 q→q′ 仅在 Guard 成立**且**目标状态不变式可认证时允许；认证失败一律沿降级格转向更保守状态；
(iii) **保守闭包**：动力学不可用、包络失效、证明超时、预算耗尽 ⇒ 进入 FALLBACK（逐指令退化为 R69→R68），**绝不在证据不足时切向更激进状态**；
(iv) **组合性**：整栈安全性由「每状态流证书 + 每条边转移证书」局部组合，新增一层不破坏既有证明。

**定义 311（监督混合自动机 H）** H = (Q, X, U, E, Guard, Reset, Inv, Flow, Urg)。
- Q 有限离散状态（定义 312）；X ⊆ ℝ^{d_x} 连续状态 = 怀疑的动力学状态（定义 313）；
- U = 𝒜_task × 𝒜_info（继承 R69 定义 294，含任务动作与信息动作）；
- E ⊆ Q×Q 切换边；Guard: E → 2^{X×U} 守卫谓词；Reset: E×X → X 重置（如交互后重设预算/后验）；
- Inv: Q → 2^X 为状态不变式；Flow: Q → 向量场族 {f_q}；
- Urg ⊆ E 为紧急边，必须在离开不变式前触发。
语义：在 q 内 x 按 `ẋ ∈ f_q(x,u,w)` 演化；触及紧急边守卫必须立即切换，否则 Guard 成立即可切换。**这是把 R69 的逐点规则嵌入一个带时间与序列语义的混合系统。**

**定义 312（离散状态与「层→状态」归约表）** Q = {NORMAL, DISAMBIG, COMMIT, FALLBACK, SUSPECT, RECAL, SAFE_STOP}：
- **NORMAL**：执行 R68 控制律，λ = λ_floor(U_ale)；
- **DISAMBIG**：执行 R69 MINT 主动消歧（信息动作过 C-RAS-WM 认证）；
- **COMMIT**：歧义已消解，锁定模态执行，U_epi 冻结为已消解；
- **FALLBACK**：R68 纯保守，λ = λ_floor(U_ale + U_epi)；
- **SUSPECT**：FMA 第二意见触发，λ≥0.8，只观测/重标定，不做信息动作；
- **RECAL**：预测性重标定（定义 320），运动降额；
- **SAFE_STOP**：经认证的最保守停车。
归约表：R66 控制分配器 = 所有状态共用的执行层；R67 VISTA = Flow 中的预测项；R68 λ_floor = NORMAL/FALLBACK 的控制律；R69 的 MINT/FMA/MCG = DISAMBIG/SUSPECT/守卫。**没有任何旧层被丢弃——它们或被降为流、或被降为守卫、或被降为状态。**

**定义 313（不确定性–标定动力学 𝔇）** 连续状态 `x=(u_a,u_e,e,r,s,b)` 分别表示 U_ale、U_epi、ECE、r_res、a_score、预算。受控动力学（灰箱，`f = f̂ + δ`）：
```
u̇_a = −κ_a(u_a − u_a*) + σ_a ξ_a
u̇_e = −κ_g(g,x)·I_g(x) + ρ_e·d(t) + σ_e ξ_e      # 交互降歧义，扰动注入新歧义
ė   =  μ_e·e + d_e(t) − γ_e·c_cal               # ECE 慢漂移 + 标定修正
ṙ   = −κ_r·r + d_r(t)                           # 残差一阶自回归
ṡ   = −κ_s·s + L_z·|o−o_cal| + σ_s ξ_s          # 行为似然随观测偏移上升
ḃ   = −c(g) − c_task(a),  b∈[0,b_max]
```
其中 `I_g` 为信息动作瞬时信息率，`d(·)` 为有界扰动/新歧义注入，`c(·)` 为物理/社交成本，`u_a*` 为不可约噪声底。系数由数据拟合，扰动界由定义 314 给出。

**定义 314（可认证动力学包络 𝔽）** 名义模型 `f̂` 与误差界 `Δ_f(x,u)`：`𝔽 = {f : ‖f(x,u,w) − f̂(x,u)‖ ≤ Δ_f(x,u), ∀w∈W}`。`Δ_f` 由留出轨迹的区间校准给出（覆盖率 ≥ 1−δ），运行时用**轨迹一致性检查**（新轨迹是否落在预测管道内）持续认证；不通过即包络失效 → FALLBACK。**关键：所有安全结论都对整个集合 𝔽 成立，而不是对单点 f̂ 成立。**

**定义 315（模型预测信息控制 MPIC）** 有限时域 `H_p`：
```
min_{u_{0:H_p−1}} E[ Σ_{k=0}^{H_p−1} ( ℓ_task(x_k,a_k) + ℓ_safe(x_k) + λ_int·c(g_k) ) + V_f(x_{H_p}) ]
s.t.  x_{k+1}=f(x_k,u_k),  Pr(x_k∈𝕌) ≤ δ ∀k,  b_k≥0,  U_epi 终止条件
```
`ℓ_safe` 为安全裕度代价，`V_f` 为终端代价（未消解 epistemic 的保守代价）。求解用短时域 + 候选信息动作枚举（候选集与 R69 MINT 相同）。**`H_p=1` 且 `V_f=0` 时逐项等于 R69 的单步 `VoI−c`。**

**定义 316（状态不变式与证书）** 对每个 q：
- **归纳不变式** `Inv_q`：`Init ⊆ Inv_{q0}`，且 `Inv_q` 对 `f∈𝔽` 前向不变；
- **控制障碍证书** `B_q: X→ℝ`：`B_q≥0` 于 `Inv_q`，且 `Ḃ_q + α(B_q) ≥ 0`（CBF 条件）；
- **离散转移证书**：对 `e=(q,q′)`，`Inv_q ∩ Guard_e ⊆ Reset_e^{−1}(Inv_{q′})`（转移保持安全）。
安全性 ⇔ 不存在从 `Init` 出发的可达状态进入不安全集 `𝕌`。

**定义 317（守卫、滞后与滞留）** 每条边的守卫由动力学状态阈值穿越给出，带滞后带 `h` 与最小滞留 `τ_d`。例如：
```
e_DISAMBIG: u_e > τ_epi ∧ e < τ_ece ∧ b > b_min ∧ ¬suspect
e_COMMIT  : u_e ≤ τ_commit ∧ 证据纪律满足
e_FALLBACK: 包络失效 ∨ b ≤ b_min ∨ ECE > τ_ece ∨ suspect
e_RECAL   : ê(t*) > τ_pre ∧ e < τ_ece          # 预测性触发, 见定义 320
```
进入与退出阈值不同（`τ_in ≠ τ_out`）以消除抖振。

**定义 318（活性排序函数、无 Zeno、无伪极限环）** 定义排序函数
`R(x,q) = M·(1 − b/b_max) + H_mode(U_epi) + 1[q≠NORMAL] + ε_r·|ECE−τ_ece|`。
每次信息动作严格降低 R（预算消耗 + 后验熵下降）；每次标定严格降低 ECE 的 Lyapunov 项。则在任一 `[0,T]` 内切换次数 `≤ ⌊T/τ_d⌋ + N_info(b_max)`，无 Zeno；且沿自动机的任一**完整环**（如 NORMAL→DISAMBIG→RECAL→NORMAL）R 严格下降，故**不存在伪极限环/永久追问**。若守卫持续不满足且 SAFE_STOP 可达，则在 `N_info` 次交互内进入 SAFE_STOP（不死锁、不无限等）。**注意：仅靠滞留只能排 Zeno，排不掉活锁；必须靠这个跨环排序函数。**

**定义 319（切换稳定性证书 SLC）** 各状态内闭环 `ẋ=f_q(x)`。存在公共 Lyapunov `V_c` 使 `∀q: ∂V_c/∂x·f_q(x) ≤ −αV_c + β`，且 Reset 不增加 `V_c`；或采用带滞留的多 Lyapunov：`V(x(t_k)) ≤ e^{−λτ_d}V(x(t_k^{−}))`。则切换闭环对任意满足滞留的切换序列**指数 ISS**。若公共 Lyapunov 不存在，退化为逐状态多 Lyapunov + 平均滞留时间证书。

**定义 320（预测性重标定 PRC）** 用 `ė` 动力学预测 ECE 穿越 `τ_ece` 的时刻 `t* = min{t: ê(t) ≥ τ_ece}`。若 `t* − t ≤ T_pre` 且预算允许，主动进入 RECAL 执行预标定，而不是等 MCG 硬门触发后被动退回。重标定本身受 C-RAS-WM 认证且运动降额。**这把 R69 的"越界急停"改成"越界前换挡"。**

**定义 321（模式可信度监控 MCM，MCG 守卫化）** R69 的 MCG 是"一票否决门"；HYDRA 把它降为 DISAMBIG 的**进入守卫**与 FALLBACK 的**退出条件**：只有当 ECE 在认证区间内、且动力学包络覆盖模态权重空间时，才允许进入 DISAMBIG；进入后持续用可靠图在线检验。于是"不可信"不再导致全系统急停，而是把状态机限制在保守子集内，并给出恢复路径（RECAL→DISAMBIG）。

**定义 322（证书 J_HYDRA）** `J_HYDRA = (J_FLUID, f_model_version, envelope_coverage, reachability_hash, {B_q}_q, dwell_table, lyap_margin, switch_log_hash, hydra_ver)`。
`Valid ⇔ Valid(J_FLUID) ∧ 𝔽 认证 ∧ 所有 B_q≥0 ∧ 无 𝕌 可达 ∧ 滞留/Zeno 满足 ∧ 切换日志与证书一致。`

**定义 323（降级格与单调退化）** 在 Q 上定义保守偏序 `≼`：
`COMMIT ≼ NORMAL ≼ DISAMBIG ≼ RECAL ≼ SUSPECT ≼ FALLBACK ≼ SAFE_STOP`，
越靠右行为收缩越强、λ 越大。规则：任何守卫失败 / 证书超时 / 包络失效 ⇒ 只能**沿 ≼ 向右**切换；向左（如 FALLBACK→DISAMBIG）必须有**新证据 + 重新认证**。这给出"绝不悄悄放松"的归纳保证。

**定义 324（严格包含链）** 令 `H_p=1`、`𝔽={f̂}`（零模型误差）、且 H 始终只在 `{NORMAL, DISAMBIG, COMMIT, FALLBACK}` 上按 R69 规则切换，则 HYDRA 与 FLUID-RAS **逐指令等价**；再令 `VoI≤c` 恒成立（不交互），则与 CALM-RAS（R68）逐指令等价。故 **R68 ⊂ R69 ⊂ R70，安全侧只增不减。**

```python
        Ig = info_rate(u.g, x)                                    # 信息率
        return np.array([
            -KA * (ua - UA_FLOOR),                                # 不可约噪声底
            -KG * Ig + RHO * disturbance(t),                      # 交互降歧义/扰动注入
              MU * e - GAMMA * cal_correction(u),                 # ECE 慢漂移+标定
            -KR * r,                                              # 残差
            -KS * s + LZ * obs_shift(u),                          # 行为似然
            -cost(u.g) - cost(u.a),                               # 预算
        ])
    def envelope(self, x, u):
        return self.f_hat(x, u), DELTA_F(x, u)    # 返回中心与半径；语义为集合 𝔽（定义 314）

# IP-267 MPIC：多步 VoI（H_p=1 时逐项等于 R69 单步）
def mpic(x, q, budget, H_p=1):
    best = None
    for seq in candidate_info_action_sequences(H_p):        # 候选与 R69 MINT 同集
        xs = rollout_interval(x, seq, budget)              # 定义 313/314 的区间滚动
        if violates_chance(xs, UNSAFE, delta): continue    # Pr(x∈𝕌) ≤ δ
        cost = sum(task_cost(xs[k]) + lam_int*cost(seq[k]) for k in range(H_p))
        cost += safe_cost(xs) + terminal_Vf(xs[-1])        # 定义 315
        if best is None or cost < best[0]:
            best = (cost, seq[0])
    return None if best is None else best[1]               # None → 不交互 / FALLBACK

# IP-268 HInv：鲁棒归纳不变式 + CBF（对 f ∈ 𝔽 而非单点）
def verify_state(q):
    assert init_within(INV[q])                             # 引理 22-(i)
    assert forward_invariant(INV[q], F_SET[q])             # 对所有 f∈𝔽
    for e in EDGES[q]:
        assert subset(INV[q] & GUARD[e],
                      preimage_reset(INV[e.q2], e))        # 离散转移证书
    assert min_B(INV[q]) >= 0                              # CBF: B_q ≥ 0

# IP-272 PRC / IP-273 MCM：预测性重标定 + 模式可信度守卫化
def monitor(q, x, f_hat):
    t_star = predict_crossing(f_hat, x, THRESH_ECE)        # 定义 320
    if t_star - now() <= T_PRE and budget_ok(x):
        return RECAL
    if not mode_weights_covered(x) or reliable_map_bad(x):
        return FALLBACK if q == DISAMBIG else q            # MCG 守卫化（定义 321）
    return q

# IP-274 HYDRA Pipeline：主闭环
def HYDRA_round(M, obs, q, x):
    z, o = M.mtm.forward(obs)
    x = M.udyn.step(x, obs)                    # 用观测更新怀疑动力学状态
    q = M.hydra.step(q, x, None, now())        # 先过状态机
    if q == SUSPECT:
        return M.r68_conservative(o, lam_min=0.8)      # R68 保守措辞
    if q == RECAL:
        return M.prc.recalibrate(o)                    # 运动降额 + 预标定
    if q == DISAMBIG:
        g = M.mpic.plan(x, H_p=M.hp)                   # IP-267 多步 VoI
        if g is None:
            q = FALLBACK
        else:
            x = M.r69_execute(g, x)                    # 调用 R69 的 MINT/CIA/FMA
    if q in (NORMAL, COMMIT, FALLBACK):
        k, lam, mode = M.r68_r69_policy(q, o, x)       # 旧层控制律
    cert = M.hinv.verify_reachable(x, q)               # IP-268
    if not cert.safe:
        q = SAFE_STOP
    M.auditor.submit_async(q, x, cert)                 # 参与式审计
    return q, cert
```

## 3. 推导

**引理 19（多步 VoI 的单调性与近视次优界）** 在信息增益次模（submodular）、成本可加的假设下，多步最优值 ≥ 单步 `VoI − 未来成本`；近视策略（R69）的 regret ≤ `(H_p−1)·Δ_IG,max`。系：R69 是 `H_p=1` 的特例；当歧义可在一步内消解时近视无损失。

**引理 20（消歧的分岔阈值）** 在定义 313 下，`U_epi` 能被压到阈值 `τ_epi` 以下的必要条件是在 DISAMBIG 停留期间 `κ_g·I_g > ρ_e·d`（信息率大于扰动注入率）。若该条件不成立，则 DISAMBIG 是一个"稳定但无用"的吸引子：系统会反复询问而 `U_epi` 不降。系：**这是一条可以在进入 DISAMBIG 之前就检查的结构性判据**——不满足则守卫直接不成立、走 FALLBACK，从源头消灭"永远在问"的活锁。

**引理 21（守卫可靠性 guard soundness）** 若阈值 `τ` 与包络 `Δ_f` 满足 `τ ≥ sup_{f∈𝔽} sup_{x: 属性未成立} f(x)`（即安全侧不可能因模型误差误触发），则守卫触发以概率 `≥ 1−δ` 蕴含对应属性成立。系：防止"因为模型高估信息增益而误入 DISAMBIG"。

**引理 22（混合归纳不变式）** 若 (i) `Init ⊆ Inv_{q0}`；(ii) 每个 `Inv_q` 在 `f∈𝔽` 下前向不变；(iii) 每条边 `e` 满足 `Inv_q ∩ Guard_e ⊆ Reset_e^{−1}(Inv_{q′})`；则所有可达状态都属于 `∪_q Inv_q`；若 `∪Inv_q ∩ 𝕌 = ∅`，则闭环安全。关键差异：`𝔽` 是**集合**，不变式必须在集合上验证（鲁棒不变式），这正是对 R69"逐点收紧"的严格升级。

**引理 23（无 Zeno、无伪极限环）** 由最小滞留 `τ_d>0` 与每次交互消耗正预算，任意 `[0,T]` 内信息动作 ≤ `b_max/c_min`，切换次数 ≤ `⌊T/τ_d⌋ + N_info`，故切换时刻无聚点 ⇒ 无 Zeno。进一步，定义 318 的跨环排序函数沿任一完整自动机环严格下降，故不存在伪极限环/永久追问。系：**交互预算在 R69 里只是成本，在 R70 里同时是"无 Zeno + 无活锁"的结构性证书。**

**引理 24（降级格的归纳单调）** 若初始处于格中某状态，且每次切换只能沿 `≼` 向右，或带新证据重新认证后向左，则无重新认证时 `λ_t` 单调不减；故保守性只增不减、不会被悄悄丢掉。

**定理 18（HYDRA 安全 + 活性）** 在 A99–A104（包络认证、鲁棒不变式、守卫可靠、滞留/预算、降级格、活性排序）下，闭环 (i) 永不进入 `𝕌`；(ii) 从任意 NORMAL 出发，要么有限步内消解 `U_epi` 回到 COMMIT/NORMAL，要么在 `N_info` 次交互内进入 SAFE_STOP；(iii) 无 Zeno、无死锁、无伪极限环。即**安全与活性同时成立**——这是 R66–R69 从未同时给出的。

**定理 19（切换 ISS 与不弱于 R68 的稳定裕度）** 若存在 SLC（公共或带滞留多 Lyapunov），则 R66–R70 各层之间任意满足滞留的切换闭环指数 ISS；特别地 NORMAL/FALLBACK 子自动机与 R68 的稳定裕度一致 ⇒ 加入状态机不降低 R68 已证明的稳定性。若 SLC 不存在，则 HYDRA 强制 FALLBACK（定义 310-iii），仍不弱于 R68。

**定理 20（严格包含链）** `R70 ⊇ R69 ⊇ R68`，在定义 324 的边界上逐指令相等。证明由归约表（定义 312）+ 动力学边界（`H_p=1, 𝔽={f̂}`）+ 守卫在边界上的恒真/恒假给出。

**定理 21（组合审计）** 整栈 `J_HYDRA` 由各状态局部证书与各边局部证书组合而成；新增一层（新状态 + 新守卫 + 新流）只需证明 (a) 新状态的 `Inv/B_q`、(b) 与既有状态间的边证书、(c) 降级格位置，无需重验既有层。故"每加一层就多一个需要独立信任的黑箱"被替换为"每加一层只多一个**局部**证明义务"——这是对 R69 灵感 3 的方法论兑现。

## 6. 本轮最大风险

**一句话**：HYDRA 把全部安全性押在"不确定性–标定动力学 𝔽 是可信的"这一前提上——**如果 `f̂` 本身错了（或攻击者把它训练/投毒成一个"恰好让所有守卫都安全触发"的模型），那么可达性就是在错误的向量场上算出来的，归纳不变式不再归纳，状态机会自信地从一个它以为安全、实际不安全的区域切换过去；状态机于是把"诚实的不知道"升级成"被证明的安全"，而证明用的是错的模型——验证器本身成了新的单点故障，错误的动力学让"已认证安全"等于"已认证地错"。**

**次级风险与缓解**：
1. **状态爆炸/组合爆炸** → 层归约表 + 状态数上限 + 局部证明；不可证即 FALLBACK（定义 310-iv、定理 21）；
2. **守卫抖振/滞留不足** → 双阈值滞后 + 最小滞留 + 引理 23；
3. **动力学非马尔可夫/历史依赖** → 增广短历史窗口 + 包络在线失效检测（定义 314）；
4. **学习模型难以认证（高维非线性）** → 分段仿射/区间神经网络 + 保守包络；只认证包络、不认证点；
5. **活性与探索预算冲突** → 排序函数 + SAFE_STOP 作为有界终止（定义 318、定理 18）；
6. **对 R69"模态分布可信"风险的回应** → MCM 守卫化 + 在 𝔽 上做鲁棒可达性；但若包络不覆盖模态权重误差，鲁棒性名不副实，故单列 E308/E314——**这是本轮最需要诚实面对的地方**。

**定义 313（不确定性–标定动力学）** `u̇_a` 回落到不可约底；`u̇_e = −κ_g I_g + ρ_e d`（交互降歧义、扰动注入歧义）；`ė = μ_e e − γ_e c_cal`（慢漂移+标定）；`ṙ` 自回归；`ṡ = −κ_s s + L_z|o−o_cal|`；`ḃ = −c(g)−c_task`。

**定义 314（鲁棒包络）** `𝔽={f:‖f−f̂‖≤Δ_f}`，`Δ_f` 由留出轨迹区间校准（覆盖 ≥ 1−δ），运行时轨迹一致性检查；失效即 FALLBACK。

**定义 315（MPIC / 多步 VoI）** 有限时域 `H_p` 上最小化任务代价 + 安全裕度代价 + 交互成本 + 终端保守代价，满足机会约束 `Pr(x∈𝕌)≤δ` 与预算；`H_p=1, V_f=0` 时等于 R69 单步 `VoI−c`。

**定义 316（不变式与证书）** 归纳不变式 + CBF（`B_q≥0, Ḃ_q+α(B_q)≥0`）+ 转移证书 `Inv_q∩Guard_e ⊆ Reset_e^{−1}(Inv_{q′})`；安全 ⇔ 可达集与 `𝕌` 不交。

**定义 317–318（守卫/滞留/活性）** 双阈值滞后 `τ_in≠τ_out` + 最小滞留 `τ_d`；排序函数 `R=M(1−b/b_max)+H_mode(U_epi)+1[q≠NORMAL]+ε_r|ECE−τ_ece|` 沿任一完整自动机环严格下降 ⇒ 无 Zeno、无伪极限环、不死锁。

**定义 319（SLC）** 公共 Lyapunov `∂V_c·f_q ≤ −αV_c+β` 且 Reset 不增；或带滞留多 Lyapunov `V(t_k)≤e^{−λτ_d}V(t_k^{−})` ⇒ 切换闭环指数 ISS。

**定义 320–321（PRC 与 MCM）** 由 `ė` 预测 ECE 穿越时刻，越界前主动 RECAL；R69 的 MCG 降为 DISAMBIG 进入守卫与 FALLBACK 退出条件，并给恢复路径（RECAL→DISAMBIG）。

**定义 322–324（证书/降级格/严格包含）** `J_HYDRA` 增加包络、可达性、障碍证书、滞留、Lyapunov、切换日志；降级格 `≼` 只许向右、向左需新证据+重认证；边界 `H_p=1, 𝔽={f̂}, VoI≤c` 上 `R70=R69=R68`（逐指令）。

## 3. 关键算法伪代码

```python
# IP-264 H-HSM：监督混合自动机（旧层 = 流/守卫/状态，不新增黑箱）
class HydraAutomaton:
    Q = [COMMIT, NORMAL, DISAMBIG, RECAL, SUSPECT, FALLBACK, SAFE_STOP]
    def step(self, q, x, u, t):
        xdot = FLOW[q](x, u)                           # 复用 R66-R69 控制律
        for e in sorted(EDGES[q], key=lambda e: URGENCY[e]):
            if GUARD[e](x, u) and self.certified_target(e, x):
                return RESET[e](x), self.audit(e, x)   # 定义 322
        return x + DT * xdot, q
    def certified_target(self, e, x):
        return (rank(e.q2) >= rank(e.q1)) or self.revalidate(e, x)  # 降级格

# IP-265 UDyn：怀疑的动力学（灰箱 + 有界扰动）
def f_hat(x, u, t):
    ua, ue, e, r, s, b = x
    Ig = info_rate(u.g, x)
    return np.array([
        -KA*(ua - UA_FLOOR),
        -KG*Ig + RHO*disturbance(t),                   # 交互 vs 扰动注入
         MU*e - GAMMA*cal_correction(u),
        -KR*r,
        -KS*s + LZ*obs_shift(u),
        -cost(u.g) - cost(u.a),
    ])

# IP-267 MPIC：多步 VoI（H_p=1 时逐项等于 R69 单步）
def mpic(x, q, budget, H_p=1):
    best = None
    for seq in candidate_info_action_sequences(H_p):
        xs = rollout_interval(x, seq, budget)
        if violates_chance(xs, UNSAFE, delta): continue
        c = sum(task_cost(xs[k]) + lam_int*cost(seq[k]) for k in range(H_p))
        c += safe_cost(xs) + terminal_Vf(xs[-1])
        if best is None or c < best[0]: best = (c, seq[0])
    return None if best is None else best[1]           # None → FALLBACK

# IP-268 HInv：对 f ∈ 𝔽 的鲁棒归纳不变式 + CBF
def verify_state(q):
    assert init_within(INV[q])
    assert forward_invariant(INV[q], F_SET[q])         # 集合语义
    for e in EDGES[q]:
        assert subset(INV[q] & GUARD[e], preimage_reset(INV[e.q2], e))
    assert min_B(INV[q]) >= 0

# IP-272/273：预测重标定 + 模式可信度守卫化
def monitor(q, x, f_hat):
    if predict_crossing(f_hat, x, THRESH_ECE) - now() <= T_PRE and budget_ok(x):
        return RECAL
    if not mode_weights_covered(x) or reliable_map_bad(x):
        return FALLBACK if q == DISAMBIG else q
    return q

# IP-274 主闭环
def HYDRA_round(M, obs, q, x):
    z, o = M.mtm.forward(obs); x = M.udyn.step(x, obs)
    q = M.hydra.step(q, x, None, now())
    if q == SUSPECT:  return M.r68_conservative(o, lam_min=0.8)
    if q == RECAL:    return M.prc.recalibrate(o)
    if q == DISAMBIG:
        g = M.mpic.plan(x, H_p=M.hp)
        if g is None: q = FALLBACK
        else:         x = M.r69_execute(g, x)          # 调 R69 MINT/CIA/FMA
    if q in (NORMAL, COMMIT, FALLBACK):
        k, lam, mode = M.r68_r69_policy(q, o, x)
    cert = M.hinv.verify_reachable(x, q)
    if not cert.safe: q = SAFE_STOP
    M.auditor.submit_async(q, x, cert)
    return q, cert
```

## 4. 推导

**引理 19（多步 VoI 单调 / 近视次优界）** 信息增益次模、成本可加时，多步最优 ≥ 单步 `VoI − 未来成本`；R69 近视 regret ≤ `(H_p−1)Δ_IG,max`；`H_p=1` 退化为 R69。

**引理 20（消歧分岔阈值）** `U_epi` 能压到 `τ_epi` 以下的必要条件是 `κ_g·I_g > ρ_e·d`（信息率 > 扰动注入率）。否则 DISAMBIG 是"稳定但无用"的吸引子——**在进入前就检查，从源头消灭永久追问的活锁**。

**引理 21（守卫可靠性）** 若阈值相对包络留裕（`τ ≥ sup_{f∈𝔽} sup_{属性未成立} f`），则守卫触发以 `≥1−δ` 概率蕴含属性成立；防止模型高估信息增益导致误入 DISAMBIG。

**引理 22（混合归纳不变式）** `Init⊆Inv_{q0}`、每 `Inv_q` 对 `f∈𝔽` 前向不变、每边 `Inv_q∩Guard_e⊆Reset_e^{−1}(Inv_{q′})` ⇒ 全可达状态安全。与 R69 的区别：`𝔽` 是集合，必须在集合上验证（鲁棒不变式）。

**引理 23（无 Zeno + 无伪极限环）** 滞留 `τ_d>0` + 每次交互正预算 ⇒ 任意 `[0,T]` 切换 ≤ `⌊T/τ_d⌋+N_info`，无聚点；排序函数沿任一完整自动机环严格下降 ⇒ 无永久追问环。**交互预算从成本升级为结构性证书。**

**引理 24（降级格单调）** 只沿 `≼` 向右 → 无重认证时 λ 单调不减；保守性只增不减，绝不悄悄放松。

**定理 18（安全 + 活性）** A99–A104 下：永不进入 `𝕌`；NORMAL 出发必在有限步消解回 COMMIT/NORMAL，或在 `N_info` 次交互内进入 SAFE_STOP；无 Zeno、无死锁、无伪极限环。**安全与活性首次同时成立**（R66–R69 均只给其一）。

**定理 19（切换 ISS / 裕度不弱于 R68）** 存在 SLC ⇒ R66–R70 层间任意满足滞留的切换闭环指数 ISS；NORMAL/FALLBACK 子自动机与 R68 稳定裕度一致；SLC 不存在则强制 FALLBACK，仍不弱于 R68。

**定理 20（严格包含链）** `R70 ⊇ R69 ⊇ R68`，定义 324 边界上逐指令相等；归约表 + 动力学边界 + 守卫恒真/恒假给出证明。

**定理 21（组合审计）** `J_HYDRA` 由各状态局部证书与各边局部证书组合；加一层只需证新状态的 `Inv/B_q`、新边证书、降级格位置，无需重验旧层。**"每层一个黑箱" → "每层一个局部证明义务"。**

## 7. 本轮最大风险

**一句话**：HYDRA 把全部安全性押在"不确定性–标定动力学 `𝔽` 可信"这一前提上——**若 `f̂` 本身错了（或被投毒成一个"恰好让所有守卫安全触发"的模型），可达性就在错误向量场上计算，归纳不变式不再归纳，状态机会自信地切进它以为安全、实际不安全的区域；状态机把"诚实的不知道"升级成"被证明的安全"，而证明用的是错的模型——验证器成了新的单点故障，错误的动力学让"已认证安全"等于"已认证地错"。**

**次级风险与缓解**：状态爆炸（归约表 + 状态上限 + 局部证明 + 不可证即 FALLBACK）；守卫抖振（双阈值 + 滞留 + 引理 23）；动力学非马尔可夫（增广历史窗口 + 在线包络失效检测）；高维非线性难认证（分段仿射/区间网络 + 只认证包络）；活性与探索预算冲突（排序函数 + SAFE_STOP）；**对 R69 模态可信度风险的回应**——MCM 守卫化 + `𝔽` 上鲁棒可达性，但若包络不覆盖模态权重误差则鲁棒性名不副实，故单列 E308/E314（本轮最需诚实面对处）。
