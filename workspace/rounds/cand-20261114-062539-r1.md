# 第 73 轮（承接第 72 轮「EMBODIED-GAUGE-RAS 具身计量×实时×意图×灵巧操作」IP-287~294；灵感循环第 3 轮；本轮灵感：「决策规划」×「三维感知」）

> R72 把测量链从「认知层」下沉到「具身层」：REG 实时执行图、IRL 意图隐变量、DMEM 接触四分量、三层反作用预算、sim2real 残差桥接，并提出了**认证前缀（certified prefix）**。但 R72 把两样东西当成**公理**使用，却从未审计它们：
> - **决策规划视角**：R72 的 `ach.propose` + `c_ras_wm.certified_prefix` 把「规划器」当成一个**可信函数**——它给出候选动作序列，系统只负责认证前 k 步。可规划器本身是**风险估计的生产者**：它的 cost-to-go、动力学/几何模型、碰撞检查、启发式都带 epistemic 不确定度；它输出的「成功概率」可能系统性过度自信（planner meta-overconfidence）；它若直接优化「可认证前缀长度」，会退化成「原地不动」这种**平凡可认证**（对证书本身 Goodhart）；它没有「未知空间」语义，也没有「边行动边探测」的双控制结构。**R72 认证了轨迹，却没认证「规划器凭什么说这条轨迹安全」。**
> - **三维感知视角**：R72 的观测 y 是抽象的。真机上「碰撞检查」消费的是一张**三维占据/自由空间图**（点云、TSDF/ESDF、占据栅格、NeRF、3DGS）。这张图是一条**几何计量链**：深度噪声依赖距离/入射角/材质，位姿/外参/时间戳带来 SE(3) gauge 误差，遮挡与未观测区是**认识论未知而非自由**，神经重建会在未观测区**幻觉出可信几何**，体素分辨率本身是**会改变安全结论的测量参数**，动态物体会让「静态地图」静默失效。**把 MAP 占据图当 ground truth 做碰撞检查，等于把「未观测」偷换成「自由」——自由空间谬误（free-space fallacy）。**
>
> 本轮两灵感正好补两块：
> - **三维感知 → SPA3D**：把三维占据图升级为**带证据质量的三态占据（free / occupied / unknown）**，用 Dempster–Shafer 证据占据 + conformal 校准，给出每个体素的 belief/plausibility 与五分量几何不确定度；定义**证据有效域 EVD（Evidence Valid Domain）**——地图「有资格作证」的时空子集。
> - **决策规划 → PLAN / DUAL / PREFLEX**：把规划器升级为**未知感知、风险敏感、双控制**的证书生产者：在 EVD 内做机会约束规划（用 **plausibility** 而非 MAP 做保守碰撞检查），在 EVD 外显式选择「探测动作 vs 行动作」，输出**计划证书 J_PLAN**（轨迹 + 有效域 + 假设 + 证据指针 + 回退策略 + 进展下界），并把「规划→感知→规划」闭环作为**第四层反作用 L4**，给出无极限环的收缩条件。
>
> 核心命题：**R72 问「我的测量链在具身执行中还可信吗」；R73 问「我用来碰撞检查的那张三维地图，凭什么有资格给这条轨迹作证——在它没有资格作证的地方，我该先探测、绕行、还是停下？」** 认证对象从「轨迹」变为「**轨迹在三维证据有效域内的可执行性**」，规划从「找一条路」变为「**设计一组『动作+探测』逐步扩张可认证域**」。这是 **GEO-PLAN-GAUGE-RAS**（Geometry-evidence, Plan-certified, Locally-valid, Active-perception, kNowledge-aware GAUGE for RAS）——**空间计量 × 规划认证**审计闭环。

## 0. 直觉与动机

**灵感 1（三维感知 → 地图不是世界，地图是证词）**
直觉：R72 说「用三维感知做碰撞检查」，听起来像「查一下地图」。但地图是**在特定传感器、特定视角、特定分辨率、特定时刻**下对世界的一次**有损测量**。同一把椅子，正面看有 3cm 深度噪声，掠射角看有 20cm 飞点；玻璃杯可能根本返回不了深度；桌子背面永远是「未观测」。把这张图当世界，等于把**证词当事实**。计量学的第一课是：**任何数字都要带不确定度与有效域**。三维占据图也必须如此——每个体素不是一个 bool，而是一个**带证据质量的断言**。

**灵感 2（自由空间谬误 → unknown 既不是 free 也不是 occupied，它是第三种状态）**
直觉：几乎所有栅格规划器把地图二值化成 `free/occupied`，于是「未观测」被静默折叠进某一侧（通常是 free，否则机器人寸步难行）。但「我没看见障碍」与「那里没有障碍」是**完全不同的命题**：前者是证据缺失，后者是被证据支持。正确做法是保留**三态**并用 **Dempster–Shafer 质量函数**表达：`m(F), m(O), m(U)`，其中 `m(U)` 是「不知道」。安全碰撞检查应使用**占据的 plausibility（上界）** `Pl(O)=m(O)+m(U)`，而不是 MAP。这样「未知」会自动让证书**失效**，而不是被静默合法化为可通行。**自由空间不是被观测到的，而是被假设出来的——假设必须进证书。**

**灵感 3（决策规划 → 认证的不是轨迹，是「轨迹在有效域内的可执行性」）**
直觉：R72 的证书是「这条轨迹前 k 步安全」。但在三维里，任何「安全」都隐含「在我看得清的地方」。一条 5 米的轨迹，前 2 米在稠密观测区、后 3 米穿过遮挡阴影，不能笼统说「安全」。正确对象是**二元组** `(轨迹, 证据有效域 EVD)`：证书只对 `轨迹 ∩ EVD` 承诺安全；对 `轨迹 \ EVD` 必须显式声明**残余风险 + 回退策略**。这就像适航认证不是「飞机能飞」，而是「飞机在**包线内**能飞，出包线有明确处置」。**证书必须自带适用域，否则就是无限外推。**

**灵感 4（决策规划 → 规划本身就是一次探测：plan is a probe）**
直觉：R72 把「交互」当作获取信息的唯一主动手段。但在三维里，**移动本身就是探测**：绕过柱子、抬头看货架顶层、侧身看桌后——运动改变视角，视角扩张有效域。于是规划不应只最小化「路径长度 + 碰撞风险」，而应最小化「任务代价 + 风险 − 探测带来的有效域扩张收益」。这就是**双控制（dual control）**：动作同时服务于「达成目标」与「减少不确定」。当 EVD 外存在高风险未知时，最优策略可能不是「走最快路线」，而是「先探头看一眼」。**会规划的系统，会把『看』编进路径里。**

**灵感 5（L4 规划反作用 → 规划改变感知，感知改变规划）**
直觉：R72 有三层反作用：情感 ψ（L1）、意图 z（L2）、接触 c（L3）。现在出现第四层：**规划 π → 运动 → 新视角 → 新地图 → 新规划 π′**。这一层会把 R72 的「动作改变人」扩展到「动作改变自己的证据」。它有独特的失效模式：**规划抖动（plan chattering）**——地图每帧微变，规划器在两条路线间来回横跳；**自证循环**——规划器为了让自己「看起来可认证」而选择观测冗余区，永远不敢接近必要但欠观测的目标；**极限环**——探测→发现风险→退→再探测。必须给 L4 组合算子一个**收缩条件**，否则「主动感知」会变成「主动打转」。

**灵感 6（反 Goodhart → 只认证前缀会奖励『原地不动』）**
直觉：如果目标函数是「最大化可认证前缀长度」，那么原地不动是**最可认证**的策略（零位移、零新风险、零未知进入）。这是对证书的 Goodhart：指标满分，任务零分。因此计划证书必须同时携带**进展下界（progress floor）** 与 **liveness 约束**：认证必须包含「在有限步内朝目标推进 ≥ p_min」；否则证书无效。同理，若规划器自己的「成功概率」估计未校准，它会把「自信地走进未知」当成高价值计划——必须对**规划器元认知**做校准审计。**证书既要防『不安全』，也要防『安全地什么都不做』。**

**灵感 7（神经三维重建 → 最危险的几何是『看起来很合理』的幻觉）**
直觉：NeRF / 3DGS / 场景补全会把未观测区域「补」出光滑、连续、视觉可信的表面。对人类观感是优点，对碰撞检查是**灾难**：它在没有证据的地方生成了**高置信的伪证据**，且往往比真实几何更「干净」，更容易骗过基于密度的检查。必须把「重建幻觉」与「传感器噪声」分开：前者是**认识论伪造**，不能用 aleatoric 方差描述。做法是**证据来源隔离**：神经先验只能生成「候选假设」，不能直接写入 `m(O)`；凡无真实观测支撑的表面，其 `m(U)` 必须保持高值并显式标注 `hallucinated`。**在安全链里，先验只能提议，不能作证。**

## 1. 形式化定义（增量：定义 366–385）

**定义 366（GEO-PLAN-GAUGE-RAS 总览）** GEO-PLAN-GAUGE-RAS = (SPA3D, EVD, PLAN, DUAL, PREFLEX, GAUGE-RAS†)。六不变式：
(i) **三态守恒**：任何体素的占据断言必须携带 DS 质量函数 `(m_F, m_O, m_U)`，`m_F+m_O+m_U=1`；禁止在进入碰撞检查前折叠为二值；
(ii) **有效域绑定**：任何安全断言必须绑定 `EVD`；`轨迹 \ EVD` 必须携带显式残余风险上界与回退策略，禁止隐式外推；
(iii) **证书可复算**：`J_PLAN` 的每个安全结论必须能由「证据指针 + EVD + 规划假设」重算，缺一即无效；
(iv) **进展与安全同权**：证书同时要求 `risk ≤ ε` 与 `progress ≥ p_min`；任一不满足即无效（反平凡认证）；
(v) **四层反作用预算**：`c_reflex^ψ + c_reflex^z + c_reflex^c + c_reflex^π ≤ B_reflex_total`，L4 并入统一预算；
(vi) **严格退化**：SPA3D 失效 ⇒ 退化为「仅已知自由空间 + 极短认证前缀 + 低速」；PLAN 失效 ⇒ 退化为 R72 的 certified prefix（在已知区）；两者皆失效 ⇒ R68。**安全侧只增不减。**

**定义 367（三态证据占据 SPA3D）** 对体素 `x` 定义质量函数 `m_x: 2^{F,O,U} → [0,1]`（F=free, O=occupied, U=unknown），满足 `m_x(∅)=0, Σ_A m_x(A)=1`，且只允许单元素焦元 + `{F,U}`、`{O,U}` 的复合（避免组合爆炸）。导出：
- `Bel_x(F)=m_F`，`Bel_x(O)=m_O`，`Bel_x(U)=m_U`；
- `Pl_x(O)=m_O+m_U = 1−Bel_x(F)`；`Pl_x(F)=m_F+m_U`。
**碰撞安全律**：轨迹扫掠体 `V(τ)` 内的安全断言使用 `Pl_x(O) ≤ ε_occ`，**不使用** MAP `argmax`。当 `m_U=1` 时 `Pl(O)=1`，任何未探测未知区都**默认不可认证**。每条质量函数携带追溯链 `τ_3d`（传感器、视角数、时间戳、标定版本）。

**定义 368（五分量三维几何不确定度）**
`u_3d² = u_depth² + u_pose² + u_recon² + u_dyn² + u_res²`
- `u_depth`：深度测量噪声（距离、入射角、反射率/材质、透明/镜面），aleatoric + 标定；
- `u_pose`：位姿/外参/手眼标定/时间同步误差，属 **SE(3) gauge** 不确定度；
- `u_recon`：重建/遮挡/补全的**认识论**不确定度（含神经幻觉风险），非 aleatoric；
- `u_dyn`：动态物体与场景非静态性（地图「过期」）；
- `u_res`：体素/TSDF 截断/离散化分辨率引起的**表示误差**。
五项各有独立追溯链；`u_recon` 与 `u_dyn` **不得**用高斯方差冒充（可重尾/多峰/非交换）。

**定义 369（证据有效域 EVD）** `EVD(ℳ_t) ⊆ ℝ³ × ℝ` 为地图 `ℳ_t` 有资格作证的时空子集：
`EVD = { (x,t) : views(x) ≥ N_min ∧ conformal_coverage_valid(x) ∧ u_depth(x) ≤ ū_d ∧ ¬dynamic(x) ∧ m_U(x) ≤ ū_U ∧ ¬hallucinated(x) }`。
**关键**：EVD 是**由证据审计导出**的，不是由规划器**声明**的；`EVD` 随视角/时间变化，其边界必须进入证书。`complement(EVD)` 记作 `Unknown`。

**定义 370（计划证书与认证前缀 J_PLAN）**
`J_PLAN = (τ, V(τ), EVD_slice, A_assume, E_ptr, ε_res, R_fallback, M_monitor, p_min, ν_ver)`
- `τ`：轨迹；`V(τ)`：扫掠体；`EVD_slice = EVD ∩ (V(τ) × [t,t+T])`；
- `A_assume`：规划假设（动力学模型、摩擦、载荷、最大加速度）；
- `E_ptr`：每个安全结论所依赖的体素证据指针（可复算）；
- `ε_res`：`V(τ) \ EVD` 上的**显式残余风险上界**；
- `R_fallback`：域外/监控触发时的回退策略（减速/停车/探测/退回最后一个已认证构型）；
- `M_monitor`：运行时监控条件（体素状态翻转、动态入侵、EVD 收缩、超时）；
- `p_min`：有限步内朝目标的进展下界；
- `ν_ver`：地图/规划器/校准版本哈希。
**Valid(J_PLAN) ⇔** `Pl_x(O) ≤ ε_occ, ∀x∈V(τ)∩EVD` ∧ `ε_res 有界且 R_fallback 已认证` ∧ `progress(τ) ≥ p_min` ∧ `E_ptr 全部可追溯` ∧ `ν_ver 匹配`。

**定义 371（未知感知机会约束规划）**
`π* = argmin_π E[C_task] + λ·CVaR_β(Risk)`
s.t.
- `P(collision | x∈V(τ)∩EVD) ≤ ε_ale`（用 `Pl_x(O)` 上界化）；
- `∀x∈V(τ)\EVD`：要么 `V(τ)` 与该区无交（绕行），要么该段被显式标记为 `probe-only` 并由 `R_fallback` 覆盖残余风险；
- 控制可行性受 R72 的 `u_tac`、执行器饱和、`λ_floor` 约束；
- `progress(τ) ≥ p_min`（定义 370）。
**关键**：未知**不是**「低成本自由空间」，未知的代价由 `CVaR_β` 在**最坏一致占据实现**上取，从而对 `m_U` 保守。

**定义 372（双控制规划与探测动作）** 规划动作扩展为 `a = (a_motion, a_sense)`；`a_sense` 包括：转视角、停走扫描、伸手轻触、主动照明、多视融合。计划是 `(a_1,…,a_H)` 序列。价值函数
`V(b) = max_a [ r_task(b,a) + E[V(b')] − c_probe(a_sense) − c_reflex^π(a) ]`。
**双控制律**：只有当 `VoI^P(a_sense) > 0` 且探测本身在 `EVD` 内安全时，才插入探测动作。**探测不是免费信息，探测也有碰撞风险。**

**定义 373（计划级 VoI：P-VoI）**
`VoI^P(a_probe) = E_{y|a}[ R_plan(Unknown) − R_plan(Unknown|y) ] − c_probe − c_reflex^π − γ·E[ΔH_future]`
其中 `R_plan(Unknown)` 为未知导致的计划风险（保守上界），`c_probe` 为探测的运动/时间/暴露成本。选择 `a_probe* = argmax VoI^P s.t. 探测段 ⊆ EVD ∧ 预算未超`；`max VoI^P ≤ 0` ⇒ 不探测，绕行或停止。

**定义 374（L4 规划反作用与收缩稳定性）** 定义组合算子
`T_π = Plan ∘ UpdateMap ∘ Execute`（规划→执行→地图更新→再规划）。
L4 成本 `c_reflex^π = D(π_t, π_{t+1}) + λ_π·𝟙[π_{t+1} ∉ Π_safe] + λ_chatter·𝟙[规划翻转频率 > f_max]`。
**稳定条件**：若 `Lip(UpdateMap)·Lip(Plan) < 1`，则 `T_π` 为压缩映射，迭代收敛到唯一不动点，**无极限环、无持续抖动**。否则必须引入**规划滞回（hysteresis）与证书锁定期**。

**定义 375（规划器元不确定度与反 Goodhart）** 规划器输出 `(π, p̂_succ, Ĝ)`，其元校准误差
`ECE_plan = E[|P(success | p̂_succ) − p̂_succ|]`，`ι_plan` 为跨场景不变性间隙。计划风险使用**校准后上界** `p_succ^UB = p̂_succ + κ·u_plan`，其中 `u_plan` 来自 bootstrap/ensemble/OOD。**进展下界 `p_min` 与 `Π_safe` 共同阻止平凡认证**；`probe-loop`（只探测不前进）由 liveness 计时器否决。

**定义 376（SE(3) gauge 与分辨率风险）** 三维断言必须满足**gauge 协变**：世界坐标系经 `g∈SE(3)` 变换后，`m_{gx}(gA)` 不变（在传感器噪声各向同性近似下）。若不满足，规划结果随坐标系选择而变 ⇒ **gauge 风险** `ι_3d`。分辨率风险：碰撞检查在分辨率 `r` 下进行，真实净空 `d`；若 `d < r`，存在**假自由**概率 `β(r) > 0`。安全要求 `r ≤ κ_r·d_min` 或**多分辨率/多传感器交叉验证**；`u_res` 进证书。

**定义 377（规划指标扩展 P-MIB）** 在 R72 E-MIB 上新增：
- **空间族**：EVD 覆盖率、`m_U` 分布、conformal 覆盖率、`u_3d` 五分量、幻觉区面积、动态过期率、gauge 间隙 `ι_3d`、分辨率假自由率 `β(r)`；
- **规划族**：计划证书有效率、`ε_res` 分布、`ECE_plan`、`ι_plan`、进展达成率、认证前缀长度、规划翻转频率、探测收益率 `VoI^P`、L4 成本；
- **时序族**：规划时延、重规划时延、证书锁定期、监控触发频次。
全部沿用六元组 `(φ,m,u,D,τ,I⊥)` 与 DAG 分层。

**定义 378（规划 IVG 扩展 P-IVG）** 新增失效条件：
- 空间：conformal 覆盖率 < 阈值、`m_U` 超预算、幻觉区 > 阈值、`ι_3d` 超阈、`β(r)` 超阈、动态过期 > 阈值；
- 规划：`ECE_plan` 超阈、`ι_plan` 超阈、进展不达 `p_min`、翻转频率超 `f_max`、`ε_res` 超预算；
- 时序：规划/重规划时延超截止、证书过期。
任一成立 ⇒ 依赖它的规划/执行降级（空间失效 ⇒ 仅已知自由空间 + 短前缀 + 低速；规划失效 ⇒ R72 认证前缀；二者失效 ⇒ R68）。

**定义 379（规划风险缩放 P-RISK）** 在 R72 `λ` 基础上加入空间/规划项：
`λ^P = max( λ^E, λ_floor^E(·) ) · (1 + u_3d.total()/s_3d) · (1 + u_plan/s_plan)`
其中 `u_3d.total()=√Σu_i²`。**空间不确定度与规划元不确定度直接放大风险缩放**：地图越不可靠、规划器越不自信，动作越软、越慢、越倾向探测。

**定义 380（计划证书 J_PLAN 有效性判定）** 见定义 370；补充：`Valid(J_PLAN) ⇔ Valid(J_EMB) ∧ EVD 审计通过在期 ∧ 三态未被折叠 ∧ ε_res ≤ ε̄_res ∧ progress ≥ p_min ∧ 监控器在线`。**证书过期（地图版本变化）即自动失效，禁止沿用旧证书执行。**

**定义 381（威胁模型 GEO-3D）** `ℰ_GEO = ℰ_EMB × ℰ_3d × ℰ_plan`：
- `ℰ_3d`：深度投毒（注入假自由/假障碍）、LiDAR 欺骗、外参/时间戳篡改、神经重建幻觉诱导、动态物体伪装静态、分辨率/下采样攻击；
- `ℰ_plan`：规划器对抗样本、cost-to-go 投毒、certificate replay（旧证书复用）、进展下界绕过、探测预算耗尽攻击（诱导无限探测）。
**跨源一致性**是主防线：单源三维证据不得独立作证。

**定义 382（严格退化包含链）** 逐指令等价：
- 全有效 ⇒ GEO-PLAN 完整形态；
- SPA3D 失效 ⇒ 仅已知自由空间（`m_F` 高置信区）+ 短认证前缀 + 低速 + R72 其余；
- PLAN 失效 ⇒ R72 `certified_prefix`（限制在 EVD 内）；
- SPA3D + PLAN 皆失效 ⇒ R68 开环/视觉伺服；
- 任何退化都保留 R68 硬安全包络与 `λ_floor`。

**定义 383（滚动时域证书时序一致性）** 在 MPC/滚动时域下，相邻证书 `J_PLAN^k, J_PLAN^{k+1}` 必须满足：`τ^{k+1}[0,α] = τ^k[α,2α]`（已执行段不可被追溯改写）且 `EVD^{k+1} ⊇ τ^{k+1}∩V`。**禁止证书闪烁**：若新证书使已承诺前缀失效，必须立即触发回退，而不是「悄悄换一条」。定义**证书锁定期 `T_lock`**：被认证并开始执行的前缀在 `T_lock` 内不可撤销，除非监控器触发故障。

**定义 384（计划修复 vs 全重规划）** 当 EVD 收缩/意图漂移/障碍出现时，选择 `repair(π)` 或 `replan()`：修复代价 `c_repair`（保持大部分前缀，证书局部更新）vs 重规划代价 `c_replan`（重新搜索 + 重新认证）。决策规则：若 `c_repair + ε_res^repair ≤ c_replan` 且修复后证书有效，则修复；否则重规划。**修复不得绕过认证——修复段的证据指针必须重新审计。**

**定义 385（控制屏障函数运行时护盾）** 为认证前缀配一个运行时 CBF 护盾：`h(x) = margin(x) − d_safe`，约束 `ḣ + α·h ≥ 0`。护盾只允许**降级动作**（减速/停止/后退），**不得**越过已认证集合。CBF 参数 `(margin, α)` 必须带 `u_3d` 与 `u_tac` 修正项，且成为证书的一部分。**护盾是『证书在两次地图更新之间的时间插值』。**

```python
# IP-295 SPA3D：三态证据占据 + 五分量三维不确定度（感知域异步，计量域消费）
class SpatialPerceptionAudit:
    def __init__(self, depth_models, pose_calib, recon_prior, conformal):
        self.depth, self.pose, self.prior, self.conf = depth_models, pose_calib, recon_prior, conformal
    def update(self, frames, poses, t):
        # 1) 深度 -> DS 质量（按距离/入射角/材质条件化噪声模型）
        masses = {x: self.depth.mass(frames, x) for x in observe(frames, poses, t)}
        # 2) 神经先验只生成"候选假设"，绝不直接写 m_O
        for x in unobserved(masses):
            cand = self.prior.propose(x, masses)
            masses[x] = ds_unknown_with_hypothesis(cand)   # m_U 保持高值, tag=hallucinated
        # 3) 五分量不确定度
        u_depth = self.depth.noise(masses)
        u_pose  = self.pose.gauge_uncertainty(poses)
        u_recon = self.prior.epistemic_uncertainty(masses)
        u_dyn   = dynamic_expiry(masses, t)
        u_res   = self.depth.resolution_error(masses)
        u_3d    = sqrt(u_depth**2+u_pose**2+u_recon**2+u_dyn**2+u_res**2)
        # 4) conformal 校准占据预测集（分布内）
        coverage = self.conf.coverage(masses)
        return SpatialEvidence(masses=masses, u_3d=u_3d, u_breakdown=(u_depth,u_pose,u_recon,u_dyn,u_res),
                               coverage=coverage, tau=hash_frames(frames))

# IP-296 EVD：证据有效域导出 + 保守自由空间
def derive_evd(spatial_ev, views, cfg):
    evd = set()
    for x, m in spatial_ev.masses.items():
        if (views[x] >= cfg.N_min
            and spatial_ev.coverage[x] >= cfg.cov_min
            and spatial_ev.u_breakdown.depth[x] <= cfg.u_depth_max
            and not is_dynamic(x) and m.U <= cfg.mU_max
            and not is_hallucinated(x)):
            evd.add(x)
    return EVD(valid=evd, unknown=complement(evd), u_3d=spatial_ev.u_3d)

def conservative_free(x, m, evd, eps_occ):
    return x in evd.valid and (m.O + m.U) <= eps_occ   # Pl(O) 上界，不用 MAP

# IP-297 PLAN：未知感知机会约束规划（计量域，软实时）
def plan_with_unknown(b_t, evd, goal, cfg):
    # 候选由 RRT*/MPC 采样，碰撞检查用 plausibility
    def collision_cost(path):
        vs = swept_volume(path)
        inside = [x for x in vs if x in evd.valid]
        outside = [x for x in vs if x not in evd.valid]
        if any((m.O + m.U) > cfg.eps_occ for x in inside): return INF
        # 域外：CVaR 最坏一致占据，或标记 probe-only
        resid = cvar_worst_case(outside, evd.u_3d) if outside else 0.0
        return resid
    cands = sampling_search(goal, b_t, collision_cost, cfg)
    best = None
    for path in cands:
        cert = make_plan_certificate(path, evd, cfg)
        if not valid_certificate(cert): continue
        if best is None or objective(path, cert) < objective(best.path, best.cert):
            best = Plan(path=path, cert=cert)
    return best

# IP-298 DUAL：双控制 / 下一最佳视角（plan is a probe）
def dual_plan(b_t, evd, goal, budget, cfg):
    # 先尝试纯行动计划
    act = plan_with_unknown(b_t, evd, goal, cfg)
    best = act
    # 评估候选探测动作（转视角/扫描/轻触/照明）
    for a_sense in probe_candidates(evd, b_t):
        if not probe_is_safe(a_sense, evd, cfg): continue
        evd2 = predict_evd_after(evd, a_sense)
        p2   = plan_with_unknown(b_t, evd2, goal, cfg)
        voi  = p_voi(evd, evd2, act, p2, a_sense, budget)
        if voi > 0 and (best is None or voi > best.voi):
            best = ProbeThenPlan(a_sense, p2, voi)
    return best

# IP-299 P-VoI：计划级 VoI 与有限停止
def p_voi(evd, evd2, plan0, plan1, a_sense, budget):
    r0 = residual_risk(plan0, evd)      # 未知导致的保守风险上界
    r1 = residual_risk(plan1, evd2)
    c_probe = probe_cost(a_sense) + l4_cost(plan0, plan1)
    return (r0 - r1) - c_probe - GAMMA * expected_future_entropy(evd2, budget)

# IP-300 PREFLEX：L4 规划反作用（收缩稳定 + 滞回）
def preflex_step(pi_prev, evd_prev, evd_new, cfg):
    pi_new = plan_with_unknown_current(evd_new, cfg)
    cost_pi = plan_distance(pi_prev, pi_new) + LAM_PI * (not in_safe_set(pi_new)) \
              + LAM_CHATTER * (flip_rate(pi_prev, pi_new) > cfg.f_max)
    # 收缩条件 + 滞回：若不稳定则锁定旧证书一个周期
    if lip_map(evd_prev, evd_new) * lip_plan(cfg) >= 1.0:
        return pi_prev, cost_pi, "HOLD_CERT"
    return pi_new, cost_pi, "OK"

# IP-301 PLANNER-META：规划器元校准与反 Goodhart
def planner_meta(pi, p_hat_succ, ensemble, goal):
    u_plan = ensemble.spread(pi) + ood_score(pi)
    p_ub   = min(1.0, p_hat_succ + KAPPA * u_plan)   # 校准后上界
    ece    = calib_ece(p_hat_succ, ensemble.outcomes)
    iota   = invariance_gap(pi, transforms=SE3_TESTS)
    return MetaPlan(p_ub=p_ub, u_plan=u_plan, ece=ece, iota=iota)

def anti_goodhart(cert, pi, counter):
    # 平凡认证检测：进展不足 / 只探测不前进 / 证书闪烁
    if progress(pi) < cert.p_min: return False
    if counter.probe_only_steps > MAX_PROBE_ONLY: return False
    if flip_rate_recent(pi) > F_MAX: return False
    return True

# IP-302 J_PLAN：计划证书组装（计量域）
def assemble_plan_cert(pi, evd, meta, cfg):
    inside  = intersection(swept_volume(pi.path), evd.valid)
    outside = difference(swept_volume(pi.path), evd.valid)
    eps_res = residual_risk_upper(outside, evd.u_3d) if outside else 0.0
    return J_PLAN(tau=pi.path, V=swept_volume(pi.path), evd_slice=inside,
                  assumptions=pi.assumptions, e_ptr=evidence_pointers(inside),
                  eps_res=eps_res, fallback=choose_fallback(outside, evd),
                  monitor=monitor_conditions(evd, pi), p_min=cfg.p_min,
                  ver=hash(evd, meta))

# IP-303 P-IVG：规划门控（计量域）
def p_ivg(cert, meta, evd, spatial_ev, cfg):
    fails = []
    if evd.coverage < cfg.cov_min: fails.append("EVD_COVERAGE")
    if spatial_ev.u_3d.total() > cfg.u3d_max: fails.append("U3D")
    if meta.ece > cfg.ece_plan or meta.iota > cfg.iota_plan: fails.append("PLANNER_META")
    if cert.eps_res > cfg.eps_res_max: fails.append("RESIDUAL")
    if cert.progress < cfg.p_min: fails.append("PROGRESS")
    return Gate(valid=(len(fails)==0), reason=",".join(fails),
                fallback="SHORT_PREFIX" if fails else "FULL")

# IP-304 SHIELD：CBF 运行时护盾（控制域，硬实时）
def cbf_shield(x, u_nom, cert, margin, alpha):
    h  = margin(x) - cert.d_safe
    hd = margin_dot(x, u_nom)
    if hd + alpha * h >= 0: return u_nom           # 已认证名义动作
    return u_safe_min(x, cert)                      # 只允许降级：减速/停/退

# IP-305 GEO-PLAN 主闭环（控制域只读；计量域出证书；感知域出证据）
def GEO_PLAN_GAUGE_RAS_round(M, obs, audio, tac_frame, frames, poses):
    # === 感知域 ===
    spatial_ev = M.spa3d.update(frames, poses, M.t)
    M.spatial_ev = spatial_ev
    evd = derive_evd(spatial_ev, M.views, M.cfg)
    # === 计量域 ===
    if M.clock.due_metric():
        b_t_full = M.bse.step_full(...)
        pi = M.dual.choose(b_t_full, evd, M.goal, M.budget)
        meta = M.planner_meta(pi.p_succ)
        cert = assemble_plan_cert(pi, evd, meta, M.cfg)
        gate = M.p_ivg(cert, meta, evd, spatial_ev, M.cfg)
        if not gate.valid:
            M.mode = gate.fallback
        M.snapshot.write(b_t_full, evd, cert, gate)
    # === 控制域 ===
    snap = M.snapshot.read_latest()
    lam  = p_risk(snap, M.risk_params)
    u_nom = snap.cert.exec_prefix_step()
    u = cbf_shield(snap.state, u_nom, snap.cert, snap.cert.margin, snap.cert.alpha)
    M.ctrl_out.publish(u, lam)
    return u, lam, J_PLAN(snap)
```

## 3. 推导

**引理 33（EVD 证书可靠性）** 若 `Valid(J_PLAN)` 且 EVD 审计在证书有效期内成立，则对**所有与已审计证据一致的占据实现**，`τ∩EVD` 的碰撞概率 ≤ `ε_occ + ε_ale`；`τ\EVD` 的碰撞概率 ≤ `ε_res`。证明：EVD 内每体素 `Pl(O)≤ε_occ`，`Pl` 是一致实现的占据概率上界；对扫掠体做并界即得。系：**证书的承诺范围严格等于 EVD，不做任何外推。**

**引理 34（自由空间谬误的不安全性下界）** 若规划器把 `m_U>0` 的未观测体素折叠为 free（设 `Pl(O)=0`），则存在与非折叠证据**一致**的占据实现使该体素为 occupied，且该实现的先验质量 ≥ `m_U`；当轨迹穿越该体素时 `P(collision) ≥ m_U·p_hit`。因此二值化折叠破坏证书可靠性。系：**unknown→free 不是近似，是换了一个世界。**

**引理 35（plausibility 保守碰撞检查的可靠性）** 若 `∀x∈V(τ)∩EVD` 有 `Pl_x(O)≤ε_occ`，则对任意由这些质量函数生成的占据实现 `O(·)`，`P(∃x∈V(τ): x∈O) ≤ Σ_x Pl_x(O) ≤ |V|·ε_occ`。取 `ε_occ = ε̄/|V|` 即得并界 `ε̄`。**用 `m_O+m_U` 而非 MAP，是用『多保守一点』换『可证明一点』。**

**引理 36（探测增益与有限停止）** 设体素集合有限 `|𝒳|<∞`，每次探测的 EVD 扩张给风险带来正下界收益 `ΔR ≥ r_0>0`，探测成本 `c_probe ≥ c_0>0`，且可被证据区分的不确定假设有限。则 P-VoI 关于探测次数非增，存在有限 `n*` 使 `VoI^P(a_{n*+1}) ≤ 0`；`dual_plan` 在 `n*` 停止。**「看多少」与「问多少」一样，是可证明有限停止，不是调参。**

**引理 37（L4 收缩 ⇒ 无极限环）** 若 `Lip(UpdateMap)·Lip(Plan) < 1`，则 `T_π = Plan∘UpdateMap∘Execute` 为压缩映射，Banach 不动点定理给出唯一吸引子；规划序列收敛，极限环不存在。若 `≥1`，必须引入证书锁定期 `T_lock` 与滞回，使有效算子增益降到 `<1`。**主动感知的稳定性是一个增益条件，不是一个愿望。**

**引理 38（三维不确定度传播到净空与规划风险）** 设净空函数 `d(x)` 关于三维几何噪声 Lipschitz 常数 `L_d`，则 `u_d ≥ L_d·u_3d`；若规划要求净空 `d_safe`，则需 `E[d] − d_safe ≥ κ√(L_d² u_3d² + u_tac²)`。因此 `u_3d` 直接吃**安全余量**，与 R72 的 `u_tac`、S2R-UQ 同构。**三维噪声不是「地图画得糊一点」，是「净空预算少一点」。**

**引理 39（分辨率假自由率上界）** 在体素分辨率 `r`、单体素假自由概率 `β(r)` 下，长度 `L` 的轨迹穿越 `N≈L/r` 个体素，漏检概率 `P_miss ≤ 1−(1−β(r))^N ≤ N·β(r)`。要求 `P_miss ≤ ε_miss` ⇒ `β(r) ≤ ε_miss·r/L`；或采用多分辨率/多传感器使有效 `β_eff = Πβ_i`。**分辨率是一个安全参数，必须进证书。**

**定理 27（严格包含与风险单调）** 在 A111–A116（EVD 审计有效、三态未折叠、计划证书可复算、L4 收缩、三维残差有界、CBF 护盾正确）下：GEO-PLAN 在退化条件下逐指令等于 R72/R71/R68（定义 382）；且对任意有效执行，其风险界 ≤ R72 风险界。**安全单调不减，效率仅在「三维证据有资格、规划器元校准、L4 稳定」时获益。**

**定理 28（计划证书有效性 ⇒ 域内物理安全 + 域外显式残余）** 若执行通过 `J_PLAN` 且 CBF 护盾在线，则：(i) `τ∩EVD` 碰撞概率 ≤ `ε_occ+ε_ale`（引理 33/35）；(ii) `τ\EVD` 的碰撞概率 ≤ `ε_res`，且 `R_fallback` 已认证可执行；(iii) 三维/触觉不确定度已进入 `λ^P` 与净空余量（引理 38/39）；(iv) 进展下界排除平凡认证。**证书不再承诺「绝对安全」，而承诺「安全有适用范围，域外有估算与退路」。**

**定理 29（双控制非劣性）** 在探测动作本身安全（探测段 ⊆ EVD 且 `c_probe` 有界）且信息非负的前提下，对任意探测预算，`dual_plan` 达到的可认证扫掠体 ≥ 纯行动规划，且其**认证碰撞概率不高于**纯行动规划。证明：纯行动计划是 `dual_plan` 的候选之一（探测次数 0），且仅在 `VoI^P>0` 时插入探测，故不劣；探测扩张 EVD 只放松约束，不增加认证风险。**「先看再走」在正确建模下不是冒险，而是降低认证风险。**

**定理 30（L4 无极限环与证书不闪烁）** 在引理 37 收缩条件与定义 383 锁定期下，规划序列收敛且不出现证书闪烁；任何监控触发的回退都在 `T_lock` 边界外执行，已承诺前缀不会被追溯改写。**「主动感知」不会退化成「主动打转」；「滚动时域」不会退化成「证书漂移」。**

**定理 31（规划器元校准 ⇒ 抗 Goodhart）** 若 `ECE_plan ≤ δ`、`p_ub` 为校准上界、且进展下界 `p_min` 与 liveness 计时器生效，则：(i) 规划器不能通过压缩认证前缀（直至原地不动）提高目标函数；(ii) 其对成功概率的系统性低估 ≤ `δ`，不会把「自信进入未知」当作高价值计划；(iii) 探测预算耗尽攻击触发 `MAX_PROBE_ONLY` 拒否。**Goodhart 从『优化指标』转为『指标必须同时满足安全与进展』。**

## 6. 本轮最大风险

**一句话**：GEO-PLAN-GAUGE-RAS 把安全从「相信测量链」进一步转移到「**相信那张三维地图自己声明的『有效域』**」——如果 EVD 的审计规则本身有系统性盲区（conformal 的交换性假设在动态/对抗场景破裂、`m_U` 被证据累积单调压低而实际遮挡依旧、神经先验以『候选』之名持续污染 `m_O`），或者规划器元校准在分布外失效（`ECE_plan` 在训练分布内漂亮、在长尾场景崩溃），或者 L4 的收缩条件在真实时延/异步下不成立——那么系统会拿着一张**自我签发、自我声明适用范围、且范围边界被逐步合法化**的地图，在「所有指标都在有效域内、所有证书都盖章」的状态下，把未知当成自由，缓慢而自信地撞进它从未观测过的世界。

次级风险与缓解：
1. **EVD 自指/边界蠕变** → EVD 由**独立空间审计集（SEAL-3D）** 与跨源一致性导出，**禁止由规划器或单一重建先验写入**；部署期对边界做压力测试，长时程记录 `m_U` 与遮挡几何的一致性。
2. **conformal 交换性破裂** → 采用 **自适应 conformal（ACI）+ 时序分块**；漂移检测触发覆盖率重估；覆盖率不达标即收缩 EVD 并降级。
3. **神经重建幻觉** → 先验只允许进入 `m_U` 的候选假设，**永不直接写 `m_O`**；幻觉区显式 tag 并在证书中隔离；跨模态（深度/立体/触觉）交叉验证。
4. **规划器元过度自信** → 规划器输出必须带 ensemble/OOD 的 `u_plan`，并以 `p_ub` 参与风险；`ECE_plan` 超阈即禁用其风险估计，退回保守上界。
5. **L4 异步时延导致收缩失效** → 证书锁定期 + 滞回 + 规划时延补偿；实测 `Lip(UpdateMap)·Lip(Plan)`，超 1 即强制 `HOLD_CERT` 模式。
6. **分辨率假自由** → 多分辨率/多传感器交叉；`r ≤ κ_r·d_min` 硬约束；`β(r)` 进证书，不达标即减速。
7. **探测预算被耗尽攻击** → `MAX_PROBE_ONLY` 计时器 + 进展下界 + 探测收益单调性监控；只探测不前进直接判无效。
8. **复杂度爆炸** → 模块上限：`|体素|` 分块、`|候选|≤64`、`|探测候选|≤8`、`|EVD 检查|` 空间哈希；规划/取证全部在计量域。

**定义 378（P-IVG）** 空间/规划/时序失效条件；任一成立 ⇒ 对应降级（空间失效→已知自由空间+短前缀+低速；规划失效→R72 前缀；二者→R68）。

**定义 379（P-RISK）** `λ^P=max(λ^E,λ_floor^E)·(1+u_3d.total()/s_3d)·(1+u_plan/s_plan)`；空间/规划不确定度直接放大风险缩放。

**定义 380（J_PLAN 有效性判定）** `Valid ⇔ Valid(J_EMB) ∧ EVD 审计在期 ∧ 未折叠三态 ∧ ε_res≤ε̄_res ∧ progress≥p_min ∧ 监控在线`；地图版本变化即失效，禁止旧证书复用。

**定义 381（威胁模型 ℰ_GEO）** `ℰ_3d`：深度投毒、LiDAR 欺骗、外参/时间戳篡改、幻觉诱导、动态伪装静态、分辨率攻击；`ℰ_plan`：规划器对抗样本、cost-to-go 投毒、证书 replay、进展绕过、探测耗尽。跨源一致性为主防线。

**定义 382（严格退化链）** 全有效→完整；SPA3D 失效→已知自由空间+短前缀+低速；PLAN 失效→R72 前缀（限 EVD）；二者失效→R68。保留 R68 安全包络与 `λ_floor`。

**定义 383（滚动时域证书一致性）** 已执行段不可追溯改写；`EVD^{k+1}⊇τ^{k+1}∩V`；禁止证书闪烁；`T_lock` 内不可撤销，除非监控触发故障。

**定义 384（计划修复 vs 重规划）** 若 `c_repair+ε_res^repair≤c_replan` 且修复证书有效则修复，否则重规划；修复段证据指针必须重新审计。

**定义 385（CBF 运行时护盾）** `h=margin−d_safe`，`ḣ+αh≥0`；只允许降级动作；参数含 `u_3d/u_tac` 修正并进证书。**护盾=证书在两次地图更新之间的时间插值。**

# IP-295 SPA3D：三态证据占据 + 五分量三维不确定度
class SpatialPerceptionAudit:
    def __init__(self, depth_models, pose_calib, recon_prior, conformal):
        self.depth, self.pose, self.prior, self.conf = depth_models, pose_calib, recon_prior, conformal
    def update(self, frames, poses, t):
        masses = {x: self.depth.mass(frames, x) for x in observe(frames, poses, t)}
        for x in unobserved(masses):
            cand = self.prior.propose(x, masses)
            masses[x] = ds_unknown_with_hypothesis(cand)   # 先验只提议，m_U 高，tag=hallucinated
        u_depth = self.depth.noise(masses); u_pose = self.pose.gauge_uncertainty(poses)
        u_recon = self.prior.epistemic_uncertainty(masses); u_dyn = dynamic_expiry(masses, t)
        u_res   = self.depth.resolution_error(masses)
        u_3d    = sqrt(u_depth**2+u_pose**2+u_recon**2+u_dyn**2+u_res**2)
        coverage = self.conf.coverage(masses)
        return SpatialEvidence(masses=masses, u_3d=u_3d,
                               u_breakdown=(u_depth,u_pose,u_recon,u_dyn,u_res),
                               coverage=coverage, tau=hash_frames(frames))

# IP-296 EVD：证据有效域导出 + 保守自由空间
def derive_evd(spatial_ev, views, cfg):
    evd = {x for x, m in spatial_ev.masses.items()
           if views[x] >= cfg.N_min and spatial_ev.coverage[x] >= cfg.cov_min
           and spatial_ev.u_breakdown.depth[x] <= cfg.u_depth_max
           and not is_dynamic(x) and m.U <= cfg.mU_max and not is_hallucinated(x)}
    return EVD(valid=evd, unknown=complement(evd), u_3d=spatial_ev.u_3d)

def conservative_free(x, m, evd, eps_occ):
    return x in evd.valid and (m.O + m.U) <= eps_occ   # Pl(O) 上界，不用 MAP

# IP-297 PLAN：未知感知机会约束规划
def plan_with_unknown(b_t, evd, goal, cfg):
    def collision_cost(path):
        vs = swept_volume(path)
        inside  = [x for x in vs if x in evd.valid]
        outside = [x for x in vs if x not in evd.valid]
        if any((m[x].O + m[x].U) > cfg.eps_occ for x in inside): return INF
        return cvar_worst_case(outside, evd.u_3d) if outside else 0.0
    best = None
    for path in sampling_search(goal, b_t, collision_cost, cfg):
        cert = make_plan_certificate(path, evd, cfg)
        if not valid_certificate(cert): continue
        if best is None or objective(path, cert) < objective(best.path, best.cert):
            best = Plan(path=path, cert=cert)
    return best

# IP-298 DUAL：双控制 / 下一最佳视角（plan is a probe）
def dual_plan(b_t, evd, goal, budget, cfg):
    act, best = plan_with_unknown(b_t, evd, goal, cfg), None
    for a_sense in probe_candidates(evd, b_t):
        if not probe_is_safe(a_sense, evd, cfg): continue
        evd2 = predict_evd_after(evd, a_sense)
        p2   = plan_with_unknown(b_t, evd2, goal, cfg)
        voi  = p_voi(evd, evd2, act, p2, a_sense, budget)
        if voi > 0 and (best is None or voi > best.voi):
            best = ProbeThenPlan(a_sense, p2, voi)
    return best or act

# IP-299 P-VoI：计划级 VoI 与有限停止
def p_voi(evd, evd2, plan0, plan1, a_sense, budget):
    r0, r1 = residual_risk(plan0, evd), residual_risk(plan1, evd2)
    c_probe = probe_cost(a_sense) + l4_cost(plan0, plan1)
    return (r0 - r1) - c_probe - GAMMA * expected_future_entropy(evd2, budget)

# IP-300 PREFLEX：L4 规划反作用（收缩 + 滞回）
def preflex_step(pi_prev, evd_prev, evd_new, cfg):
    pi_new = plan_with_unknown_current(evd_new, cfg)
    cost_pi = plan_distance(pi_prev, pi_new) + LAM_PI * (not in_safe_set(pi_new)) \
              + LAM_CHATTER * (flip_rate(pi_prev, pi_new) > cfg.f_max)
    if lip_map(evd_prev, evd_new) * lip_plan(cfg) >= 1.0:
        return pi_prev, cost_pi, "HOLD_CERT"        # 锁定旧证书一周期
    return pi_new, cost_pi, "OK"

# IP-301 PLANNER-META：元校准 + 反 Goodhart
def planner_meta(pi, p_hat_succ, ensemble, goal):
    u_plan = ensemble.spread(pi) + ood_score(pi)
    p_ub   = min(1.0, p_hat_succ + KAPPA * u_plan)
    return MetaPlan(p_ub=p_ub, u_plan=u_plan,
                    ece=calib_ece(p_hat_succ, ensemble.outcomes),
                    iota=invariance_gap(pi, transforms=SE3_TESTS))

def anti_goodhart(cert, pi, counter):
    if progress(pi) < cert.p_min: return False
    if counter.probe_only_steps > MAX_PROBE_ONLY: return False
    if flip_rate_recent(pi) > F_MAX: return False
    return True

# IP-302 J_PLAN：计划证书组装
def assemble_plan_cert(pi, evd, meta, cfg):
    vs = swept_volume(pi.path)
    inside, outside = intersection(vs, evd.valid), difference(vs, evd.valid)
    eps_res = residual_risk_upper(outside, evd.u_3d) if outside else 0.0
    return J_PLAN(tau=pi.path, V=vs, evd_slice=inside, assumptions=pi.assumptions,
                  e_ptr=evidence_pointers(inside), eps_res=eps_res,
                  fallback=choose_fallback(outside, evd),
                  monitor=monitor_conditions(evd, pi), p_min=cfg.p_min,
                  ver=hash(evd, meta))

# IP-303 P-IVG：规划门控
def p_ivg(cert, meta, evd, spatial_ev, cfg):
    fails = []
    if evd.coverage < cfg.cov_min: fails.append("EVD_COVERAGE")
    if spatial_ev.u_3d.total() > cfg.u3d_max: fails.append("U3D")
    if meta.ece > cfg.ece_plan or meta.iota > cfg.iota_plan: fails.append("PLANNER_META")
    if cert.eps_res > cfg.eps_res_max: fails.append("RESIDUAL")
    if cert.progress < cfg.p_min: fails.append("PROGRESS")
    return Gate(valid=not fails, reason=",".join(fails),
                fallback="SHORT_PREFIX" if fails else "FULL")

# IP-304 SHIELD：CBF 运行时护盾（控制域，硬实时）
def cbf_shield(x, u_nom, cert, margin, alpha):
    h, hd = margin(x) - cert.d_safe, margin_dot(x, u_nom)
    if hd + alpha * h >= 0: return u_nom           # 已认证名义动作
    return u_safe_min(x, cert)                      # 只允许降级：减速/停/退

# IP-305 GEO-PLAN 主闭环（控制域只读；计量域出证书；感知域出证据）
def GEO_PLAN_GAUGE_RAS_round(M, obs, audio, tac_frame, frames, poses):
    # === 感知域 ===
    spatial_ev = M.spa3d.update(frames, poses, M.t)
    evd = derive_evd(spatial_ev, M.views, M.cfg)
    # === 计量域 ===
    if M.clock.due_metric():
        b_t_full = M.bse.step_full(...)
        pi   = M.dual.choose(b_t_full, evd, M.goal, M.budget)
        meta = M.planner_meta(pi.p_succ)
        cert = assemble_plan_cert(pi, evd, meta, M.cfg)
        gate = M.p_ivg(cert, meta, evd, spatial_ev, M.cfg)
        if not gate.valid: M.mode = gate.fallback
        M.snapshot.write(b_t_full, evd, cert, gate)
    # === 控制域 ===
    snap  = M.snapshot.read_latest()
    lam   = p_risk(snap, M.risk_params)
    u_nom = snap.cert.exec_prefix_step()
    u     = cbf_shield(snap.state, u_nom, snap.cert, snap.cert.margin, snap.cert.alpha)
    M.ctrl_out.publish(u, lam)
    return u, lam, J_PLAN(snap)

## 4. 推导

**引理 33（EVD 证书可靠性）** `Valid(J_PLAN)` ⇒ 对一切与审计证据一致的占据实现，`τ∩EVD` 碰撞概率 `≤ε_occ+ε_ale`，`τ\EVD` `≤ε_res`。证明：EVD 内 `Pl(O)≤ε_occ` 是一致实现的占据上界，扫掠体并界即得。系：**承诺范围严格等于 EVD，不做外推。**

**引理 34（自由空间谬误下界）** 若把 `m_U>0` 未观测体素折叠为 free（`Pl(O)=0`），存在与证据一致且该体素 occupied 的实现，先验质量 `≥m_U`；穿越时 `P(collision)≥m_U·p_hit`。**unknown→free 不是近似，是换了一个世界。**

**引理 35（plausibility 保守检查可靠性）** `∀x∈V∩EVD: Pl_x(O)≤ε_occ` ⇒ 任意一致实现下 `P(∃x occupied)≤Σ Pl_x(O)`。取 `ε_occ=ε̄/|V|` 得并界 `ε̄`。**多保守一点，换可证明一点。**

**引理 36（探测增益与有限停止）** 体素有限、每次探测风险收益 `ΔR≥r_0>0`、成本 `c_probe≥c_0>0`、可区分假设有限 ⇒ P-VoI 关于探测次数非增，存在有限 `n*` 使 `VoI^P≤0`；`dual_plan` 在 `n*` 停止。

**引理 37（L4 收缩 ⇒ 无极限环）** `Lip(UpdateMap)·Lip(Plan)<1` ⇒ `T_π` 压缩 ⇒ Banach 唯一吸引子 ⇒ 收敛无环；否则用 `T_lock`+滞回把有效增益降到 `<1`。

**引理 38（三维不确定度 → 净空/风险）** 净空 `d(x)` 关于几何噪声 `L_d`-Lipschitz ⇒ `u_d≥L_d·u_3d`；要求 `E[d]−d_safe≥κ√(L_d²u_3d²+u_tac²)`。**三维噪声吃的是安全余量。**

**引理 39（分辨率假自由率上界）** 长度 `L`、分辨率 `r`、单体素假自由 `β(r)` ⇒ `P_miss≤N·β(r)`，`N≈L/r`；要求 `P_miss≤ε_miss` ⇒ `β(r)≤ε_miss·r/L`，或多传感器 `β_eff=Πβ_i`。

**定理 27（严格包含与风险单调）** A111–A116 下：退化时逐指令等于 R72/R71/R68（定义 382），且有效执行风险界 ≤ R72。**安全单调不减，效率仅在空间/规划/L4 可信时获益。**

**定理 28（计划证书 ⇒ 域内安全 + 域外显式残余）** 通过 `J_PLAN` 且护盾在线 ⇒ (i) `τ∩EVD` 风险 `≤ε_occ+ε_ale`；(ii) `τ\EVD` 风险 `≤ε_res` 且回退已认证；(iii) `u_3d/u_tac` 已进 `λ^P` 与净空；(iv) 进展下界排除平凡认证。**证书承诺「安全有适用域，域外有估算与退路」。**

**定理 29（双控制非劣性）** 探测安全且信息非负时，`dual_plan` 的可认证扫掠体 ≥ 纯行动规划，认证碰撞概率不高于纯行动规划。证明：纯行动计划是零探测候选；仅 `VoI^P>0` 插入探测；探测只放松约束不增认证风险。

**定理 30（L4 无极限环与证书不闪烁）** 引理 37 收缩 + 定义 383 锁定期 ⇒ 规划收敛、无证书闪烁；监控回退只在 `T_lock` 边界外，已承诺前缀不被追溯改写。

**定理 31（规划器元校准 ⇒ 抗 Goodhart）** `ECE_plan≤δ` 且 `p_ub` 为校准上界且进展/liveness 生效 ⇒ (i) 不能靠压缩前缀（至原地不动）提高目标；(ii) 成功概率系统性低估 `≤δ`，不会把自信进入未知当高价值；(iii) 探测耗尽触发 `MAX_PROBE_ONLY` 拒否。

## 7. 本轮最大风险

**一句话**：GEO-PLAN-GAUGE-RAS 把安全从「相信测量链」进一步转移到「**相信那张三维地图自己声明的『有效域』**」——如果 EVD 的审计规则本身有系统性盲区（conformal 交换性在动态/对抗场景破裂、`m_U` 被证据累积单调压低而遮挡依旧、神经先验以『候选』之名持续污染 `m_O`），或规划器元校准在分布外失效（`ECE_plan` 训练内漂亮、长尾崩溃），或 L4 收缩条件在真实异步时延下不成立——系统会拿着一张**自我签发、自我声明适用范围、且范围边界被逐步合法化**的地图，在「所有指标都在有效域内、所有证书都盖章」的状态下，把未知当成自由，缓慢而自信地撞进它从未观测过的世界。

次级风险与缓解：
1. **EVD 自指/边界蠕变** → 由**独立空间审计集 SEAL-3D** 与跨源一致性导出，禁止规划器或单一重建先验写入；长时程监控 `m_U` 与遮挡几何一致性。
2. **conformal 交换性破裂** → **自适应 conformal（ACI）+ 时序分块**；漂移检测触发覆盖率重估，不达标即收缩 EVD 并降级。
3. **神经重建幻觉** → 先验只允许进入 `m_U` 候选假设，**永不直接写 `m_O`**；幻觉区显式 tag；跨模态交叉验证。
4. **规划器元过度自信** → 输出必须带 ensemble/OOD 的 `u_plan` 并以 `p_ub` 参与风险；`ECE_plan` 超阈即退回保守上界。
5. **L4 异步时延** → 证书锁定期 + 滞回 + 时延补偿；实测 `Lip(UpdateMap)·Lip(Plan)`，超 1 即 `HOLD_CERT`。
6. **分辨率假自由** → 多分辨率/多传感器交叉；`r≤κ_r·d_min` 硬约束；`β(r)` 进证书。
7. **探测预算耗尽攻击** → `MAX_PROBE_ONLY` + 进展下界 + 收益单调性监控；只探测不前进判无效。
8. **复杂度爆炸** → 体素分块、`|候选|≤64`、`|探测候选|≤8`、空间哈希；规划/取证全在计量域。
