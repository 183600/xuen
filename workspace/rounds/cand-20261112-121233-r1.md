# 第 61 轮（承接第 60 轮「场景感知闭环」IP-153~160；新灵感循环第 1 轮；本轮灵感：「状态机」×「论文发表」）

> 第 60 轮用 SSM×CIEC×EPIR×SERC 把「场景—意图—执行—证据」串成闭环，但**两个结构性缺口**在本轮暴露：
> 1. **离散跳转只有 if-else，没有可验证语义**：SSM 的 `scene_conf>0.7`、CIEC 的 `2s` 锁定、EPIR 的 `seq_gap`、PCE++++ 的四种预算耗尽……这些阈值散布在代码里，彼此可能同时成立或互相冲突。第 60 轮只证明了每个组件「单独正确」（A61–A65），却没有证明**组合系统永远不会进入不安全状态**。这是控制流层的抽象泄漏：`K_safe` 再安全，只要状态跳转顺序错了，也会把错误阻抗下发到电机。
> 2. **证据链是事后拼接，不是发表级证据**：EV-exec 证书能说明「执行发生了什么」，但论文里的主张（如「场景适应时间 −40%」）与这些证据之间没有机器可检查的映射；预注册、消融、统计显著性、复现脚本都是手工的。于是「证据链完整」并不等于「论文可复现、可证伪、可 artifact evaluation」。

## 0. 直觉与动机

**灵感 1（状态机 → 执行契约状态机 ECSM）**
直觉：第 60 轮的所有机制本质上都是**离散模式切换**：探测/提交、正常/场景适应、未锁定/意图锁定、正常/降级/急停。与其让这些切换散落在 `if` 里，不如把它们收进一台**分层的、带时钟与不变式的混合自动机**：状态 = 已认证的执行模式，迁移 = 由证据谓词守卫的动作，模式不变式 = 允许的阻抗/速度/力包络。关键洞见：**安全性不再靠「记得写回退」，而靠「迁移关系 + 不变式」的归纳证明**——只要初始状态安全、每条迁移保持安全、每个不变式与守卫的交集安全，整条轨迹就安全。

**灵感 2（状态机 → 证书携带迁移 CCST）**
直觉：状态机每跳一步，就应像区块链一样留下**不可抵赖的一跳**：前态哈希、守卫见证（实测 scene_conf/seq/预算值）、动作参数、后态哈希、签名。于是「为什么从 NOM 进入 SAFE」不再是一行日志，而是一张可独立验证的证书。关键洞见：**把执行证据从「事后记录」升级为「迁移的前置条件与后置凭证」**——不携带合法证书的迁移，运行时监视器直接拒绝。

**灵感 3（论文发表 → 主张-实验可追溯矩阵 CETM）**
直觉：论文的每条主张（claim）都应对应至少一个**预注册实验**，每个实验都应对应状态机的一条或多条迁移日志。CETM 是一张矩阵：行是主张，列是实验，格子里是假设、指标、证伪条件、样本量、种子、证据等级。关键洞见：**让「写论文」变成一次编译**——把 LaTeX 里的 `\claim{...}` 编译成实验需求，缺证据的主张直接编译失败，而不是靠作者良心。

**灵感 4（论文发表 → 发表级证据协议 PGEP + 预注册 PRE-F）**
直觉：审稿人真正要的不是「结果好」，而是「**结果在什么条件下会不成立**」。PGEP 把冻结配置（代码哈希、种子、参数）、原始 EV-exec/证书、统计脚本、消融矩阵、artifact manifest 打成一个可复现包；PRE-F 在跑之前登记 H0/H1、α、样本量、停止规则，跑之后再改阈值就记为协议偏差并降级证据。关键洞见：**可证伪性可以被状态机强制**——未预注册的实验只能标为「探索性（E1）」，不能支撑论文主 claim。

**灵感 5（两灵感合流 → 可发表的执行状态机 PESM / 自描述论文状态机 SDPS）**
直觉：既然执行是状态机、发表也是状态机，就让二者共用同一套证据总线：机器人跑出的每次模式迁移携带证书 → 证书汇聚成实验日志 → 日志按 CETM 编译成论文图表与统计 → 发表流程 SDPS 用「证据等级」作为门禁（SUBMIT 要求 claim 覆盖率 100% 且等级 ≥ E3）。关键洞见：**控制平面 = 证据平面 = 发表平面**——机器人不仅执行任务，还「写自己的论文」，而且每个结论都能回到某一跳状态迁移。这不是自动造论文，而是让论文的每个数字都有可验证的出处。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（执行契约状态机 ECSM）** 分层混合自动机 H = (S, s₀, X, Σ, G, Inv, Act, T, Pri)：
- **状态** S = S_core ∪ S_comp，超状态：S_NOM（正常）、S_ADAPT（场景适应）、S_LOCK（意图锁定）、S_REC（证据恢复）、S_DEG（预算降级）、S_SAFE（急停）；复合状态如 S_NOM = {N_PROBE, N_COMMIT}。
- **时钟** X：τ_lock、τ_gap、τ_adapt 等；**迁移** T ⊆ S×G×Σ×Act×S，守卫 g ∈ G 为证据谓词（scene_conf ≥ τ_scene、seq_gap ≤ 1、B_scene > θ、τ_response ≤ τ_deadline）。
- **不变式** Inv: S→Pred(X∪V)，例如 Inv(S_NOM) = {K ∈ K_safe^base ∧ F ≤ F_max ∧ scene_conf ≥ 0.7}。
- **优先级** Pri: T→ℕ，用于**冲突消解**：S_SAFE 的迁移恒为最高优先级，且禁止同级守卫同时为真（确定性）。
- **语义**：若当前不变式被违反且无迁移可走 → 强制进入 S_SAFE。

**定义 162（证书携带迁移 CCST）** 对迁移 τ=(s,g,a,s′)，证书
```
cert_τ = (h(s), witness(g), params(a), h(s′), h_prev, σ)
```
其中 h 为状态/证据的 Merkle 哈希，witness(g) 为满足守卫的实测向量，h_prev 为上一跳证书哈希，σ 为签名。验证谓词 V(cert)=accept 当且仅当 h_prev 链接正确、σ 有效、witness(g) ⊨ g、a 在 Act 白名单内。轨迹 π=τ₁…τₙ 的证书链满足 h(s_{i+1})=h_prev(i+1)，形成**迁移证明链**。

**定义 163（离散-连续安全归纳 DCSI）** 对 ECSM 的安全集 Safe（例如所有已下发阻抗 ∈ K_safe^base 且接触力 ≤ F_max）：
- **离散归纳不变式** I_d：s₀ ⊨ I_d；对任意 τ，I_d ∧ g ⇒ wp(a, I_d)（最弱前置条件保持）。
- **连续障碍函数** B_m(x)（模式 m）：Safe_m = {x | B_m(x) ≥ 0}；沿模式流场满足 Ḃ_m + α(B_m) ≥ 0。
- **切换兼容**：守卫 g 触发时满足 B_{m′}(Reset(x)) ≥ 0，保证切换不破坏障碍。
若 (I_d, {B_m}) 存在，则 ECSM 的全部可达状态落在 Safe 内（组合安全）。

**定义 164（主张-实验可追溯矩阵 CETM）** T = (C, E, R, ρ)：
- C = {c_i} 为论文主张，结构化写作 c_i = (statement, metric, threshold, scope, level_required)；
- E = {e_j} 为实验配置；
- R ⊆ C×E，条目 r=(c,e, H0/H1, metric, falsifier, n, seeds, e_level)；
- 覆盖率 ρ(c) = |{e | (c,e)∈R ∧ e_level(e) ≥ c.level_required}| / 1。
- **发布门禁**：∀c ∈ C，ρ(c)=1，否则论文不可提交。

**定义 165（发表级证据协议 PGEP）** 证据包 B = (claim_graph, prereg, frozen, raw_logs, certs, analysis, ablation, manifest, repro_report)：
- frozen = (code_hash, config_hash, seeds, environment_hash)；
- raw_logs = 全部 EV-exec 与迁移证书；
- 复现谓词 Rep(B)：在 frozen 下重跑，主指标落在原置信区间内且证书链验证通过。

**定义 166（预注册与协议偏差 PRE-F）** 预注册 P = (H0, H1, α, power, n, primary_metric, stopping_rule, exclusion_rules)。运行后实测 A 与 P 的偏差 δ = diff(P,A)，偏差等级 L(δ) ∈ {none, minor, major, fatal}：
- **minor**：仅次要指标/日志格式变化，保持等级；
- **major**：改变样本量/停止规则/次要阈值，等级降一级；
- **fatal**：改变主指标/证伪条件/事后剔除样本，claim 必须改标为「探索性」。

**定义 167（证据等级 E-level）** E0 单次原始运行 / E1 证书验证的单次运行 / E2 多种子 + 置信区间 / E3 = E2 + 预注册 + 消融 + artifact / E4 = E3 + 独立复现或跨机器人复现。论文主 claim 要求 ≥ E3，「优于 SOTA」类 claim 要求 E4。

**定义 168（自描述论文状态机 SDPS）** P = (P_states, p₀, Δ, Gate)：
- P_states = {DRAFT, PREREG, FREEZE, RUN, ANALYZE, ABLATE, ARTIFACT, SUBMIT, REBUT, CAMERA}；
- **门禁**：FREEZE→RUN 需 Rep-ready frozen 配置；ANALYZE→ABLATE 需主指标统计显著；SUBMIT 需 CETM 覆盖率 = 1 且所有主 claim ≥ E3；REBUT→CAMERA 需每条审稿意见映射到 CETM 行或显式 limitations。
SDPS 的每条迁移也携带 CCST 证书，于是「论文怎么改的」同样可审计。

## 2. 关键算法伪代码

### IP-161 ECSM 运行时与模型检验骨架

```python
class ECSMEngine:
    def __init__(self, s0, transitions, invariants):
        self.cur = s0
        self.T = sorted(transitions, key=lambda t: -t.priority)  # 高优先级先
        self.Inv = invariants
        self.clocks = {c: 0.0 for c in s0.clocks}
        self.chain = []

    def step(self, obs, dt):
        for c in self.clocks: self.clocks[c] += dt
        if not self._invariant_holds(self.cur, obs):
            return self._force_safe(obs)              # 不变式破坏 → SAFE
        enabled = [t for t in self.T
                   if t.src == self.cur and t.guard(obs, self.clocks)]
        if not enabled:
            return self.cur, None
        if len(enabled) > 1 and enabled[0].priority == enabled[1].priority:
            raise NonDeterministicTransition(self.cur)  # 违反 A66
        t = enabled[0]
        cert = self._emit_cert(t, obs)                 # IP-162
        self.cur = t.dst
        self._reset_clocks(t)
        self._run_action(t.action, obs)
        self.chain.append(cert)
        return self.cur, cert
```

模型检验：将 ECSM 抽象为带时钟的有限迁移系统，检验 AG(¬UNSAFE)、AF(terminal)，并对每对同优先级守卫做**互斥性检查** `UNSAT(g_i ∧ g_j)`。

### IP-162 CCST 证书链

```python
def emit_cert(tau, obs, prev_hash, sk):
    payload = {
        'src': tau.src.id, 'dst': tau.dst.id,
        'guard_witness': tau.guard.witness(obs),
        'action_params': tau.action.params(obs),
        'state_hash': hash_state(obs.state),
        'prev_hash': prev_hash,
        'clock': obs.clocks,
    }
    h = sha256(canonical_json(payload)).hexdigest()
    return {'payload': payload, 'hash': h, 'sig': sign(sk, h)}

def verify_chain(certs, vk):
    prev = GENESIS
    for c in certs:
        if c['payload']['prev_hash'] != prev: return False
        if not verify_sig(vk, c['hash'], c['sig']): return False
        if not c['payload']['guard_witness'].satisfies(): return False
        prev = c['hash']
    return True
```

### IP-163 DCSI 组合安全检查

```python
def check_discrete_inductive(H, I_d, Safe):
    if not implies(H.s0, I_d): return False
    for tau in H.T:
        if not implies(I_d & tau.guard, wp(tau.action, I_d)): return False
    return implies(I_d, Safe)

def check_continuous_barrier(mode, B, alpha, samples):
    for x in samples:
        if inside(mode.flow, x) and not (B(x) >= 0): return False
        if not (B_dot(mode.f, B, x) + alpha(B(x)) >= -1e-9): return False
    return True

def check_switch_compat(H, barriers):
    for tau in H.T:
        # 守卫触发处，重置后的障碍值仍非负
        if not implies(tau.guard,
                       lambda x: barriers[tau.dst](tau.reset(x)) >= 0):
            return False
    return True
```

### IP-164 CETM 构建与覆盖率

```python
def build_cetm(claims, experiments):
    rows = []
    for c in claims:
        ok = [e for e in experiments
              if covers(e.metric, c.metric) and e.scope == c.scope
              and e.level >= c.level_required]
        rows.append({'claim': c.id, 'experiments': [e.id for e in ok],
                     'coverage': 1.0 if ok else 0.0})
    return {'rows': rows,
            'coverage': sum(r['coverage'] for r in rows) / len(rows)}

def gate_submit(cetm, sdps_state):
    return sdps_state == 'SUBMIT' and cetm['coverage'] == 1.0
```

```python
def check_deviation(prereg, actual):
    if actual.primary_metric != prereg.primary_metric: return 'fatal'
    if actual.exclusion != prereg.exclusion: return 'fatal'
    if actual.n != prereg.n or actual.stopping != prereg.stopping: return 'major'
    if actual.secondary_thresholds != prereg.secondary_thresholds: return 'minor'
    return 'none'

def apply_deviation(claim_level, level):
    return {'none': claim_level, 'minor': claim_level,
            'major': max('E1', prev(claim_level)),
            'fatal': 'E1'}[level]
```

### IP-168 SDPS 发表状态机

```python
class PublicationStateMachine:
    GATES = {
        ('FREEZE', 'RUN'):      lambda ctx: ctx.frozen_ready,
        ('ANALYZE', 'ABLATE'):  lambda ctx: ctx.primary_significant,
        ('ABLATE', 'ARTIFACT'): lambda ctx: ctx.ablation_complete,
        ('ARTIFACT', 'SUBMIT'): lambda ctx: ctx.cetm.coverage == 1.0
                                    and all(c.level >= 'E3' for c in ctx.claims),

    }
    def fire(self, event, ctx):
        key = (self.cur, event.dst)
        if key not in self.GATES or not self.GATES[key](ctx):
            return 'BLOCKED'
        cert = emit_cert(...)  # 论文流程迁移同样留证
        self.cur = event.dst
        return cert
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| ECSM | O(\|T\|) / 步 | O(\|S\|+\|T\|) | 优先级确定性；AG(¬UNSAFE) 模型检验 |
| CCST | O(1) / 证书 | O(n) 链 | 哈希链+签名，篡改可检 |
| DCSI | 离散 O(\|T\|·\|I_d\|) + 连续 O(N_samples) | O(\|S\|+\|T\|) | 归纳不变式 + 障碍函数 ⇒ 组合安全 |
| CETM/PGEP | O(\|C\|·\|E\|) | O(\|C\|+\|E\|) | 覆盖率=1 门禁；Rep(B) 复现 |
| PRE-F | O(1) | O(1) | 偏差分级，事后改参降级 |
| SDPS | O(1) / 迁移 | O(\|P_states\|) | 门禁不可绕过 |

**正确性定理（VPG，Verifiable-Publishable Grounding）**：假设 A66–A70 成立——
(A66) ECSM 迁移在优先级下确定性，同优先级守卫互斥；(A67) 存在离散归纳不变式 I_d 与模式障碍函数族 {B_m}，且切换兼容；(A68) CCST 哈希+签名不可伪造；(A69) 每条主 claim 在 CETM 中至少有一个 E3+ 实验覆盖；(A70) 预注册先于运行冻结，偏差按 PRE-F 分级。
则：
1. **执行安全**：ECSM 全部可达状态 ∈ Safe，任何被下发的 K 都来自 K_safe^base（组合安全，而非逐组件安全）。
2. **证据可审计**：每条状态迁移都有可独立验证的证书，链式篡改以压倒概率被检出。
3. **可发表性**：每条论文主 claim 可追溯到 ≥E3 实验与具体迁移日志；在 frozen 下重跑满足 Rep(B)。
4. **流程门禁**：SDPS 无法在 CETM 未覆盖或证据不足时到达 CAMERA。

## 5. 本轮最大风险

**一句话**：最大的风险是「验证剧场」——模型检验证明了抽象 ECSM 的 AG(¬UNSAFE)，但真实接触摩擦、传感器延迟、未建模动力学不在不变式里，于是「证对了模型、证错了世界」；同时预注册若僵硬到扼杀探索性机器人研究，会产出「可复现却无意义」的论文。必须用「数字孪生残差监控 + 真机 barrier 在线校验 + 探索性/确证性双轨证据」三护栏，确保形式化不脱离物理。

## 2. 关键算法伪代码

### IP-161 ECSM（执行契约状态机）

```python
class ECSMEngine:
    def __init__(self, s0, transitions, invariants):
        self.cur = s0
        self.T = sorted(transitions, key=lambda t: -t.priority)
        self.Inv = invariants
        self.clocks = {c: 0.0 for c in s0.clocks}
        self.chain = []

    def step(self, obs, dt):
        for c in self.clocks: self.clocks[c] += dt
        if not self._invariant_holds(self.cur, obs):
            return self._force_safe(obs)
        enabled = [t for t in self.T
                   if t.src == self.cur and t.guard(obs, self.clocks)]
        if len(enabled) > 1 and enabled[0].priority == enabled[1].priority:
            raise NonDeterministicTransition(self.cur)
        t = enabled[0]
        cert = self._emit_cert(t, obs)
        self.cur = t.dst
        self._reset_clocks(t)
        self._run_action(t.action, obs)
        self.chain.append(cert)
        return self.cur, cert
```

### IP-162 CCST（证书携带迁移）

```python
def emit_cert(tau, obs, prev_hash, sk):
    payload = {
        'src': tau.src.id, 'dst': tau.dst.id,
        'guard_witness': tau.guard.witness(obs),
        'action_params': tau.action.params(obs),
        'state_hash': hash_state(obs.state),
        'prev_hash': prev_hash,
        'clock': obs.clocks,
    }
    h = sha256(canonical_json(payload)).hexdigest()
    return {'payload': payload, 'hash': h, 'sig': sign(sk, h)}

def verify_chain(certs, vk):
    prev = GENESIS
    for c in certs:
        if c['payload']['prev_hash'] != prev: return False
        if not verify_sig(vk, c['hash'], c['sig']): return False
        if not c['payload']['guard_witness'].satisfies(): return False
        prev = c['hash']
    return True
```

### IP-163 DCSI（离散-连续安全归纳）

```python
def check_discrete_inductive(H, I_d, Safe):
    if not implies(H.s0, I_d): return False
    for tau in H.T:
        if not implies(I_d & tau.guard, wp(tau.action, I_d)): return False
    return implies(I_d, Safe)

def check_continuous_barrier(mode, B, alpha, samples):
    for x in samples:
        if inside(mode.flow, x) and not (B(x) >= 0): return False
        if not (B_dot(mode.f, B, x) + alpha(B(x)) >= -1e-9): return False
    return True

def check_switch_compat(H, barriers):
    for tau in H.T:
        if not implies(tau.guard,
                       lambda x: barriers[tau.dst](tau.reset(x)) >= 0):
            return False
    return True
```

### IP-164 CETM（主张-实验可追溯矩阵）

```python
def build_cetm(claims, experiments):
    rows = []
    for c in claims:
        ok = [e for e in experiments
              if covers(e.metric, c.metric) and e.scope == c.scope
              and e.level >= c.level_required]
        rows.append({'claim': c.id, 'experiments': [e.id for e in ok],
                     'coverage': 1.0 if ok else 0.0})
    return {'rows': rows,
            'coverage': sum(r['coverage'] for r in rows) / len(rows)}

def gate_submit(cetm, sdps_state):
    return sdps_state == 'SUBMIT' and cetm['coverage'] == 1.0
```

```python
def check_deviation(prereg, actual):
    if actual.primary_metric != prereg.primary_metric: return 'fatal'
    if actual.exclusion != prereg.exclusion: return 'fatal'
    if actual.n != prereg.n or actual.stopping != prereg.stopping: return 'major'
    if actual.secondary_thresholds != prereg.secondary_thresholds: return 'minor'
    return 'none'

def apply_deviation(claim_level, level):

            'major': max('E1', prev(claim_level)),
```

```python
class PublicationStateMachine:
    GATES = {
        ('FREEZE', 'RUN'):      lambda ctx: ctx.frozen_ready,
        ('ANALYZE', 'ABLATE'):  lambda ctx: ctx.primary_significant,
        ('ABLATE', 'ARTIFACT'): lambda ctx: ctx.ablation_complete,
        ('ARTIFACT', 'SUBMIT'): lambda ctx: ctx.cetm.coverage == 1.0
                                    and all(c.level >= 'E3' for c in ctx.claims),

    def fire(self, event, ctx):
        key = (self.cur, event.dst)
        if key not in self.GATES or not self.GATES[key](ctx):
            return 'BLOCKED'
        cert = emit_cert(...)
        self.cur = event.dst
        return cert
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性 |
|---|---|---|---|
| ECSM | O(\|T\|)/步 | O(\|S\|+\|T\|) | 优先级确定性；AG(¬UNSAFE) |
| CCST | O(1)/证书 | O(n) | 哈希链+签名，篡改可检 |
| DCSI | 离散 O(\|T\|·\|I_d\|)；连续 O(N) | O(\|S\|+\|T\|) | 归纳不变式+障碍函数⇒组合安全 |
| CETM/PGEP | O(\|C\|·\|E\|) | O(\|C\|+\|E\|) | 覆盖率=1；Rep(B) |
| PRE-F | O(1) | O(1) | 偏差分级、事后改参降级 |
| SDPS | O(1)/迁移 | O(\|P_states\|) | 门禁不可绕过 |

**正确性定理（VPG）**：若 A66–A70 成立，则：
1. ECSM 全部可达状态 ∈ Safe ⇒ 任何下发阻抗 ∈ K_safe^base（组合安全）。
2. 每条迁移证书可独立验证，链式篡改高概率检出。
3. 每条主 claim 可追溯到 ≥E3 实验与具体迁移日志；frozen 重跑满足 Rep(B)。
4. SDPS 在 CETM 未覆盖或证据不足时不可达 CAMERA。

## 5. 本轮最大风险

**一句话**：最大风险是「验证剧场」——模型检验证明了抽象 ECSM 的 AG(¬UNSAFE)，但真实摩擦、延迟、未建模动力学不在不变式内，导致「证对了模型、证错了世界」；必须以「数字孪生残差监控 + 真机 barrier 在线校验 + 探索性/确证性双轨证据」三护栏，防止形式化脱离物理。
