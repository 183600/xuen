### 第 6 轮灵感驱动研究记录

**灵感词**：用户共创、分层规划

**继承关系**：第 5 轮 CADVS-v5（IP-493~496）以「认证的生成式执行」（CGE）把提议从离散规则升级为条件流匹配、把记忆升级为固化闭环、把人因升级为情感调制，并用定理 5~8 证明「提议可换、门不可换」与「调制只紧不松」，执行集 Exec_CADVS-v5 ⊆ Exec_CADVS-v4 ⊆ … ⊆ Exec_v29。本轮不推翻 v5，而是补 v5 暴露的两个结构性盲区：(a) 提议仍是**扁平**的单层轨迹 x=(pose_{0:T}, wrench_{0:T})，长周期任务只能一次性生成整条轨迹，缺乏时间抽象与子任务复用，误差随 horizon 累积、证书只能整体通过或整体拒绝；(b) 人类仍是**被感知对象**（意图 veto + 情感调制），无法作为共同作者贡献示范、纠正、偏好与任务规格，经验闭环只有系统内部固化，缺少外部用户知识注入。两个灵感词统一为主题「分层共证执行」（Hierarchical Co-certified Execution, HCE），形成 CADVS-v6（IP-497~500）。本轮自律：**硬门仍为七门**（不增门，回应 R52 维护负债）；把「层级」实现为**证书合成算子**而非新门，把「共创」实现为**提案/偏好通道**而非新权限。执行集嵌套升级为 Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ … ⊆ Exec_v29。

**直觉与动机**：

1. **分层规划 → 把「一条轨迹」升级为「一棵带契约的计划树」，证书从单层交集升级为 assume-guarantee 合成**。v5 的证书是七门在一个整轨迹上的交集，长任务要么整体过要么整体不过，且误差沿时间累积。引入分层任务规划核 HTPK：高层把目标分解为子任务序列 τ_1…τ_n（符号规划器/受约束 LLM，只能调用已注册原语），每个子任务携带契约 C_i=(Pre_i, Post_i, Inv_i)；低层每个子任务仍用 v5 的 FMPP 采样候选段。证书升级为计划级 kc_plan = ∧_i kc_local(τ_i) ∧ ∧_i kc_boundary(i,i+1) ∧ kc_global。**定理 9（分层证书合成可靠性）**：若每个子任务本地七门成立、且边界满足 Post_i ⊆ Pre_{i+1} 与不变量连续，则合成轨迹满足全局契约。关键工程含义：分层不是「放松」，而是把整体安全**分解为可验证的局部安全 + 显式边界安全**，执行集反而更紧（多出边界约束），F_v6 ⊆ F_v5。

2. **分层规划的隐患 → 合成安全 ≠ 全局安全，边界是一等失效面**。分层最大的诱惑是「每个子任务都过门，于是整条计划安全」，这是错的：子任务之间接触拓扑切换、力/位姿不连续、抓取转移时的瞬时失稳，都可能让每个局部证书成立而合成轨迹违例。因此本轮把边界提升为一等公民：kc_boundary 显式检查 (a) 终态包含关系 Post_i ⊆ Pre_{i+1}、(b) wrench/接触拓扑在切换点的连续性、(c) 不变量归纳传递 Inv_i(t_{i+1}) ⇒ Inv_{i+1}(t_{i+1})。**诚实边界**：定理 9 只相对于契约集合成立，契约本身是否完备**无人证明**——这正是本轮最大风险。

3. **用户共创 → 人类从「被感知」升级为「共同作者」，但只走提案/偏好通道，永不改门**。引入共创参与引擎 COPE：用户贡献四类——示范（demonstration）、纠正（correction）、偏好（preference）、任务规格（task-spec）。它们分别进入：示范/纠正 → FMPP 的条件化或离线微调（扩提案覆盖，不改门）；偏好 → 仅在**可行集内重排** ECS（λ 有界，不降 τ）；任务规格 → 生成新子任务/原语契约，须独立通过 AGC 全局校验后才注册。**定理 10（共创非扩张性）**：任何被准入的共创集合 U 只改变提案支撑与可行集内的偏好序，不改变门与阈值，故 F_v6(U)=F_v6(∅)、Exec_v6(U) ⊆ F_v6 ⊆ F_v5；任何触碰门/τ 的贡献被结构性拒绝（GATE_TAMPER）。治理层：provenance 签名账本、声誉加权、隔离观察区、DP 噪声、显式同意与撤回。

4. **两者交汇 → 共创天然产生新层级，必须与契约绑定，否则共创成为「绕过契约的后门」**。用户最常贡献的恰恰是「宏/子任务/新原语」这类层级结构（“先…再…最后…”）。若允许用户定义子任务却不让其契约过 AGC，共创就绕过了分层证书。故 COPE 的红线：**用户新增的每个原语/子任务都必须携带契约并独立通过 kc_plan 校验**；声誉只影响「是否进入提案」，不影响「是否被认证」。这把「用户共创」约束为**覆盖/效用算子**，而非**许可算子**。

**关键洞见**：v4 回答「提议=规则时七门是否足够」；v5 回答「提议=任意生成器、记忆反哺、人因含情感时证书边界能否不动」；v6 回答「当提议变成层级、人类变成共同作者时，证书的**合成**是否仍然可靠」。核心不变量：**层级是证书的合成算子，共创是提案的覆盖算子，二者都不是权限算子**。七硬门 kc_evidence_forged_v4 记号原样复用；新增只有：计划树 Π、契约 C_i、边界关系 B_i、kc_plan、COPE 准入过滤器。执行集 Exec_CADVS-v6 ⊆ F_v6 ⊆ F_v5 ⊆ … ⊆ Exec_v29，由「同门 + 边界约束 + 阈值只紧 + 共创不改门」四重保证。

**形式化目标（增量）**：
1. 计划树 Π=(N,E)；子任务 τ_i=(C_i, [t_i,t_{i+1}], π_i)；契约 C_i=(Pre_i,Post_i,Inv_i)；边界关系 B_i ⊆ Post_i × Pre_{i+1}。
2. kc_plan(Π) = ∧_i kc_local(τ_i) ∧ ∧_i kc_boundary(i,i+1) ∧ kc_global；任一为 0 则 fail-closed 整计划拒绝。
3. HTPK = (受约束分解器 Decomp, 契约库 ContractLib, 低层 FMPP)；AGC = 合成算子 compose；COPE = (账本 Ledger, 声誉 Rep, 隔离 Q, DP, 准入过滤器 Admit)。
4. 定理 9（分层证书合成可靠性）、定理 10（共创非扩张性）、定理 11（共创信任有界性）、定理 12（层级锚完备性保持）。
5. 共创准入：Admit(u)=1[签名 ∧ r(u)≥r_min ∧ ¬touches_gate(u) ∧ ¬quarantine(u)]；贡献类型 → {提案条件, 可行集内偏好, 需 AGC 校验的新契约}。
6. Exec_CADVS-v6 = {x=⊕_i x_i : kc_plan(Π)=1, x_i∈supp(π_i)} ⊆ F_v6 ⊆ F_v5。

**本轮最大风险**：**跨层契约不完备导致的「合成安全幻觉」**——定理 9 只相对于「接口契约集合」成立，而契约集合自身的完备性无人证明：每个子任务都通过本地门、每条边界都满足显式契约，却可能在契约未刻画的跨层涌现交互处失效（接触拓扑切换的瞬态、力/位姿耦合、子任务目标冲突）；共创又不断把用户定义的新层级塞进这个未验证的契约边界，使证书从「全局安全」退化为「相对契约安全」。

## 2. 关键算法骨架

### IP-497 HTPK：分层任务规划核（准入/异步时域，不进 1 kHz 环）

```python
@dataclass
class HierarchicalTaskPlannerKernel:
    """HTPK：受约束高层分解 → 低层 FMPP 采样段。
    红线：分解器只能调用 ContractLib 中已注册原语；未知原语一律拒绝"""
    decomposer: Any                  # 符号规划器 / 受约束 LLM（grammar-constrained）
    contract_lib: ContractLib
    fmpp: FlowMatchingProposalPolicyKernel
    max_sub: int = 20                # 子任务数上限，防长链误差与组合爆炸

    def plan(self, goal, ctx) -> PlanTree:
        # 1) 受约束分解：输出原语序列，未注册原语被 grammar 直接排除
        seq = self.decomposer.decompose(goal, ctx,
                                        allowed=self.contract_lib.primitives())
        assert len(seq) <= self.max_sub
        # 2) 绑定契约（只读契约库，禁止用户/分解器改写）
        nodes = [Node(tau=tau, C=self.contract_lib.bind(tau.id)) for tau in seq]
        # 3) 低层逐段采样：条件含子目标 token + 检索记忆
        for nd in nodes:
            nd.cands = self.fmpp.propose(ctx.with_subgoal(nd.tau), self.fmpp.K)
        return PlanTree(nodes)
```

### IP-498 AGC：假设-保证证书合成器（离线/准入时域）

```python
@dataclass
class AssumeGuaranteeComposer:
    """AGC：把逐子任务证书合成为计划级证书。
    定理 9：局部全过 + 边界兼容 ⇒ 全局契约成立（相对契约集合）"""
    v4: EvidenceForgingAssemblerV4

    def compose(self, plan: PlanTree, gamma: dict) -> tuple[bool, Cert | None, str]:
        # 第 1 层：逐子任务本地七门（v4 硬门原样，阈值 γ·τ^4 只紧）
        for nd in plan.nodes:
            if not all_local_gates(nd.selected, nd.C, gamma):
                return False, None, f'LOCAL_FAIL@{nd.id}'
        # 第 2 层：边界门——分层的关键失效面
        for a, b in zip(plan.nodes, plan.nodes[1:]):
            if not self._boundary_ok(a.selected, b.selected, a.C, b.C):
                return False, None, f'BOUNDARY_GAP@{a.id}->{b.id}'
        # 第 3 层：全局契约
        if not self._global_ok(plan):
            return False, None, 'GLOBAL_CONTRACT_FAIL'
        return True, Cert(witnesses=[n.cert for n in plan.nodes] + boundary_witnesses), 'FORGED_HIER'

    def _boundary_ok(self, xa, xb, Ca, Cb) -> bool:
        # (a) 终态包含：xa(t_end) ∈ Cb.Pre
        # (b) 连续性：wrench 锥/接触拓扑在切换点不跳变超界
        # (c) 不变量传递：Ca.Inv(t_end) ⇒ Cb.Inv(t_start)
        return (in_pre(xa.terminal, Cb.Pre)
                and wrench_contact_continuous(xa.terminal, xb.initial, eps=EPS_B)
                and invariant_transfers(Ca.Inv, Cb.Inv, xa.terminal, xb.initial))
```

### IP-499 COPE：共创参与引擎（异步治理时域，与准入解耦）

```python
@dataclass
class CoCreationParticipationEngine:
    """COPE：用户贡献只经「提案条件 / 可行集内偏好 / 需 AGC 校验的新契约」进入。
    定理 10：共创非扩张——永不改门，F_v6(U)=F_v6(∅)"""
    ledger: Any                      # 签名账本（append-only）
    reputation: Any                  # r(u)：EMA，按采纳/驳回更新
    dp_eps: float = 1.0
    r_min: float = 0.5
    lam_co: float = 0.2

    def admit(self, u: Contribution) -> Admission:
        if not verify_sig(u) or not self.ledger.fresh(u):        # 重放/伪造
            return Admission.reject('UNTRUSTED')
        if touches_gate(u):                                     # 结构性红线
            return Admission.reject('GATE_TAMPER')              # 试图改门/τ/λ 上界
        if self.reputation(u.author) < self.r_min:
            return Admission.observe(u)                         # 新/低声誉：隔离
        return Admission.accept(u, weight=self._w(u))           # w=r·decay(ts)

    def apply(self, admitted, fmpp, pref, contract_lib) -> ApplyReport:
        for u in admitted:
            if u.type in ('demo', 'correction'):
                fmpp.condition_or_finetune(u.payload)           # 扩提案覆盖，不改门
            elif u.type == 'preference':
                pref.reorder_within_feasible(u.payload)         # 仅可行集内重排 ECS
            elif u.type == 'task-spec':
                # 用户新增原语/子任务：必须携带契约并独立过 AGC，否则不注册
                new = contract_lib.compile(u.payload)
                if not self._passes_agc_selfcheck(new):
                    continue                                    # 不满足 → 不进入 ContractLib
                contract_lib.register(new)
        return ApplyReport(...)
    # 隐私/治理：贡献签名可溯源；统计上报过 DP；显式同意与撤回（撤回=移出账本影响集）
```

### IP-500 EFA-v6：七门不变 + 层级合成 + 共创准入

```python
@dataclass
class EvidenceForgingAssemblerV6:
    """EFA-v6：v5 选证降为子任务段选择器；外层 AGC 合成；COPE 前置准入"""
    htpl: HierarchicalTaskPlannerKernel
    agc: AssumeGuaranteeComposer
    cope: CoCreationParticipationEngine
    v5: EvidenceForgingAssemblerV5

    def select(self, goal, x0_state, t_now, context, contributions) -> tuple[bool, PlanTree | None, str]:
        # 0) 共创准入与生效（异步，先于规划；不改门）
        admitted = [u for u in contributions if self.cope.admit(u).ok]
        self.cope.apply(admitted, self.htpl.fmpp, context.pref, self.htpl.contract_lib)
        # 1) 高层分解 + 低层采样
        plan = self.htpl.plan(goal, context)
        # 2) 逐子任务用 v5 选证（流提议 + 七门 + 情感调制；规则回退保留）
        for nd in plan.nodes:
            ok, seg, tag = self.v5.select(x0_state, t_now, nd.tau.rule_id,
                                          context.with_subgoal(nd.tau))
            if not ok:
                return False, None, f'SUBTASK_REJECT@{nd.id}:{tag}'
            nd.selected = seg
        # 3) 合成计划级证书（含边界门）
        ok, cert, tag = self.agc.compose(plan, context.gamma)
        if not ok:
            return False, None, tag                             # fail-closed 整计划
        return True, plan, 'FORGED_HCE'

    def ecs_v6(self, plan, n_flow, s_emo) -> float:
        eta_plan = sigmoid(mean_certified_margin(plan) - B_PLAN)  # 含边界边际
        eta_co = 1.0 - self.cope.lam_co * (1.0 - mean_reputation(plan.admitted))
        return self.v5.ecs_v5(plan, n_flow, s_emo) * eta_plan * eta_co
```

## 4. 正确性论证（增量更新）

### 引理 45（边界契约的传递性）

**陈述**：若对每个 i 有 Post_i ⊆ Pre_{i+1} 且 Inv_i(t_{i+1}) ⇒ Inv_{i+1}(t_{i+1})，则沿链 τ_1→…→τ_n 的「后置-前置」与不变量归纳链成立，即从 Pre_1 出发的可达集 R_n ⊆ Post_n。**证明**：对 i 归纳，R_1 ⊆ Post_1 ⊆ Pre_2，逐段复合；不变量由边界蕴含式传递。∎

### 引理 46（层级收缩）

**陈述**：F_v6 = F_v5 ∩ (∩_{i} kc_boundary(i,i+1)) ∩ kc_global ⊆ F_v5。**证明**：F_v6 在 v5 的七门交集上额外合取边界门与全局门，交集只减不增。∎

### 引理 47（共创覆盖单调、门集不变）

**陈述**：对被准入集合 U，提案对 F 的覆盖 Cov_U(F) ≥ Cov_∅(F)，而门谓词与阈值不变，故 F_v6(U)=F_v6(∅)。**证明**：示范/纠正只扩条件支撑或微调 θ_FM（定理 6：门与提议无关）；偏好只在 F 内重排；新契约须过 AGC。∎

### 引理 48（单贡献影响界）

**陈述**：加权聚合下单一贡献对提案/偏好的影响 ≤ w_max/(Σ_j w_j) + O(1/ε_DP)。**证明**：加权平均的敏感度 + DP 机制界。∎

### 定理 v6（分层合成与共创非扩张，总装）

**陈述**：在 v5 假设 (B1)~(B7) 及新增 (B8)「契约集合 C 对所建模危害完备」下：
(i) Exec_CADVS-v6 ⊆ F_v6 ⊆ F_v5 ⊆ … ⊆ Exec_v29；
(ii) 分层合成可靠：局部七门 + 边界兼容 + 全局契约 ⇒ kc_plan=1（定理 9，相对 C）；
(iii) 边界是一等失效面：任一 kc_boundary=0 ⇒ 整计划 fail-closed，不部分执行；
(iv) 共创非扩张：F_v6(U)=F_v6(∅)，Exec_v6(U) ⊆ F_v6（定理 10）；
(v) 共创影响有界：单贡献 ≤ w_max/Σw + O(1/ε)（定理 11）；
(vi) 七锚完备性在层级下保持（定理 12，给定契约完备）；
(vii) 软评分 ECS_v6 = ECS_v5·η_plan·η_co 仅用于排序，不扩可行集。

**证明**：(i) 由引理 46 + v5 嵌套。(ii) 由定理 9/引理 45。(iii) 由 kc_plan 的合取定义。(iv) 由定理 10/引理 47。(v) 由定理 11/引理 48。(vi) 由定理 12。(vii) 由软因子 ∈[0,1] 且只作用于排序。∎

**诚实声明**：(B8) 契约完备性**被假设、未被证明**——这是本轮最大风险；(ii) 中若危害不可由 (Pre,Post,Inv) 表达或跨边界非组合（涌现交互），定理不覆盖；共创的 Sybil 抗性在无身份/抵押假设下无绝对界；层级分解器（LLM）可能产生语义正确但契约不匹配的分解，需 grammar 约束 + 契约绑定双保险。

## 7. 本轮最大风险（最终确认）

**一句话**：**跨层契约不完备导致的「合成安全幻觉」**——定理 9 只相对于「接口契约集合」成立，而契约集合自身的完备性无人证明：每个子任务都通过本地门、每条边界都满足显式契约，却可能在契约未刻画的跨层涌现交互处失效（接触拓扑切换的瞬态、力/位姿耦合、子任务目标冲突）；共创又不断把用户定义的新层级塞进这个未验证的契约边界，使证书从「全局安全」退化为「相对契约安全」。
