# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环第 3 轮；本轮灵感：「灵巧操作」×「用户体验」）

> R69 把「不确定」一分为二（aleatoric / epistemic），并给 epistemic 装上了「问」的能力：看、问、触，VoI 定价，单源不定案。但 R69 的「问」仍站在两个未经审视的假设上：
> - **信息动作是可逆的、成本是逐步标量**。它把 `g_probe` 也只当作一个「过了力/位包络认证的查询」。可在灵巧操作里，**最有价值的信息（摩擦、质量、柔顺性、滑动趋势）只存在于接触中，而接触会改变物理状态**：一次辨识摩擦的微滑可能同时把物体滑掉，一次测柔顺的按压可能造成不可逆形变。VoI 与风险不是两个可加的项，而是同一个物理承诺的两面。
> - **需要消解的只有「机器人对世界的无知」**。R69 只最小化 `H(M|o)`，却不管用户对机器人意图的无知 `H(M|o_H)`。问得越多，用户越困惑；默默执行，用户又不知道机器人要干什么。用户体验不是「把成本加进 VoI」这么简单，它是一个**长时程、非对称、关系性**的状态：信任掉得快、修得慢，而目标是**校准信任**，不是最大化满意。
>
> 本轮两个灵感各补一刀：
> - **灵巧操作**要求把信息动作分成「无接触可逆查询」与「接触承诺」两类；后者必须在**可恢复管道（recoverability tube）**内、以「单位不可逆度的信息增益」定价，并接受力/冲量/滑移漏斗认证。它还给出一个硬物理事实：辨识摩擦必须耗散能量，所以「高信息 + 零不可逆」是不可能的——存在一条**信息—不可逆前沿**。
> - **用户体验**要求把交互成本升为长时程的**体验预算/体验债**，把「用户对机器人的不确定性」升为一等公民 `U_epi^H`，并用**可读性动作**（预成形、注视、微停顿、轨迹塑形、忠实解释）廉价地降低它，而不是每次都靠「问一句」。
>
> 核心命题：**把 R69 的单步 VoI 升级为「可恢复性约束 × 体验预算 × 双侧认知」的三重约束决策；接触承诺只在可恢复管道内执行，体验债越界即退回 R69，R69 再退回 R68；安全侧只增加约束、不放松。** 命名 **GRACE-RAS**（Grasp–Recoverability–Agency–Calibrated trust–Experience for Risk-Adaptive Systems）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我还能碰多深，而对方是否看懂了我**」——不确定性不只是一句提问，也可以是一次可撤回的触碰和一次被读懂的预备动作。

## 0. 直觉与动机

**灵感 1（灵巧操作 → 信息住在接触里，而接触不可逆）**
直觉：在抓取一只未知杯子时，「它有多滑、有多重、杯壁多软」这些量，视觉只能给先验，真正的后验来自手指。但手指一接触，世界就变了：接触点、物体位姿、甚至物体完整性都不可逆地改变。R69 的 `g_probe` 虽然带力/位包络，却只证明了「不越界」，没有证明「越界之前还回得来」。灵巧操作的第一性原理是：**信息动作不是查询，是承诺（commitment）**。于是要区分两种信息动作：
- `g^rev`：注视、询问、悬停、预成形——原则上可逆，沿用 R69；
- `c`：按压、滑动、微抬、旋转、拧——改变接触状态，可能在信息到手的同时把任务做死。
对后者，正确的问题不是「VoI 减成本是否为正」，而是「**在保证还能退回任务集的前提下，这个承诺能买到多少信息**」。这就是可恢复管道的来源。

**灵感 2（用户体验 → 成本是长时程关系，且认知是双向的）**
直觉：R69 的 `c(g)` 把社交成本压成一个标量，且每步独立。真实体验不是这样：
- **信任是非对称状态**：一次「说得好听但做错」掉得比十次「老实说我不确定」修得快；因此逐步贪心会系统性透支信任。
- **用户也有 epistemic**：用户不知道机器人此刻是「确定地在抓」还是「在犹豫要不要抓」。R69 通过问来降低自己的 `U_epi`，却把不确定性转嫁给用户；反之，机器人默默切换模态会让用户觉得不可预测。用户体验的核心之一，是**用户对机器人意图的可预测性**，即 `U_epi^H`。
- **目标是校准，不是讨好**：过度信任和信任不足都危险。UX 的正确目标不是让满意度最高，而是让 `|信任 − 实际可靠性|` 最小，同时控制脑力负荷与打扰。
所以本轮把 UX 建成一个可估计、可约束、可审计的状态，而不是一个拍脑袋的权重。

**灵感 3（R69 是边界纤维，不是被替代）**
直觉：把接触动作集设为空、把体验预算设为无限、把「用户侧不确定性」权重设为零、把成本重新退化为逐步标量，GRACE 就逐指令退化成 R69。新层不是并列的黑箱，而是把 R69 放进一个更大的约束族：**R69 是「无接触、可逆、短视、单侧」的那条边界纤维**。安全侧只增加约束（可恢复性、力漏斗、同意有效性），效率增益来自「可恢复的探索」与「可读的预备动作」，而不是放松任何安全谓词。

**灵感 4（信息的物理价格 → 没有免费午餐）**
直觉：想辨识静摩擦系数，就必须让接触面进入滑动；想辨识柔顺性，就必须施加位移。信息不是凭空观测到的，它由**受控的不可逆物理过程**换取。这给出本轮最重要的理论姿态：**存在一条信息—不可逆前沿（information–irreversibility frontier）**，R69 的「用时间/社交成本买信息」只是接触自由、物体无损时的退化情形。承认这条前沿，才能诚实地回答「这个物体值不值得试、试多深」。

**灵感 5（双刃剑 → 试探性损伤与信任剧场）**
直觉：一旦系统能「碰」，失败模式就升级：
- **试探性损伤**：为了辨识刚度按得太深、为了辨识摩擦滑得太远，物体掉了或坏了；更糟的是，「可恢复」证书在最需要它的接触瞬间最不可信（接触动力学模型误差、冲击、夹持突变）。
- **信任剧场**：「解释」比真实后验更乐观、动作被塑形得看起来很确定、用流畅的预成形掩盖内心歧义；用户被安抚，却没有得到真实信息。这比 R69 的「诚实不知道」更危险。
- **体验债**：短期内少问少停，体验很顺；长期一次沉默失败就把信任清零。
- **同意被制造**：系统把「问」设计成只有一种看起来安全的选项，用户没有真正的拒绝空间。
因此本轮必须同时交付：可恢复性认证、接触漏斗、忠实可读性、体验预算与节流、同意有效性、UX 审计与对抗威胁模型。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（GRACE-RAS 总览）** GRACE-RAS = (CCX, RECON, CVoI, URX, XBG, LEG, HAM, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **接触承诺必须可恢复**：任何改变接触状态的 `c` 必须落在已认证的可恢复管道 `R_δ(s)` 内，且 `Irr(c|s) ≤ δ_irr`、恢复代价 ≤ `b_rec`、通过力/冲量/滑移漏斗；否则 `c` 作废，退回 `g^rev`；
(iii) **体验预算与校准纪律**：长时程体验债 `D_t ≤ D_max`、信任校准误差 `CE_t ≤ τ_trust`；不得用乐观解释、默认勾选、时间压力制造同意；
(iv) **双侧认知纪律**：当 `U_epi^R` 与 `U_epi^H` 同时高时，必须选择「每比特成本更低」的一侧去降低；解释/预览必须忠实于真实后验，禁止用解释掩盖未消解的 `U_epi^R`（解释剧场）。

**定义 311（接触承诺动作）** 增广动作 `ξ = (a, g^rev, c)`，其中 `c ∈ 𝒜_contact ⊂ ℝ^{d_c}` 是接触承诺：指力/接触位置/腕部力旋量/持续时间/微滑指令。观测扩展为 `y = (y_tac, y_force, y_proprio, y_vis)`。接触动作产生状态转移 `s' = f_c(s,c) + ω`，且通常 `f_c` 不可逆。`𝒜_contact = ∅` 时 GRACE 退化为 R69 的动作空间。

**定义 312（可恢复管道与不可逆度）** 对状态 `s`，可恢复集 `R_δ(s) = { s' : ∃ π_rec, P(在 T_r 内到达任务集 | s', π_rec) ≥ 1−δ }`。恢复裕度 `ρ(s) = sup{ r : B_r(s) ⊆ R_δ(s) }`。接触承诺的不可逆度 `Irr(c|s) = 1 − P(s' ∈ R_δ(s) | s,c)`，期望恢复代价 `RC(c|s) = E[cost(π_rec) | s,c]`。安全承诺集 `C_safe(s) = { c : Irr(c|s) ≤ δ_irr, RC(c|s) ≤ b_rec, F_safe(s,c) }`，`F_safe` 为定义 319 的接触漏斗。

**定义 313（物理参数后验）** 物体接触动力学参数 `θ = (μ_s, μ_k, m, k_c, d_c, p_g)`（静/动摩擦、质量、接触刚度/阻尼、接触几何）。由历史接触观测维护后验 `p(θ | ℋ_t)`，`U_epi^phys = H(θ | ℋ_t)`（或用任务相关协方差迹）。R69 的模态熵记为 `U_epi^act`，机器人侧总分 `U_epi^R = (U_epi^act, U_epi^phys)`。关键：`μ`、`k_c` 在视觉通道上通常不可辨识，**只有接触能降低 `U_epi^phys`**。

**定义 314（接触 VoI，决策相关）** 不用纯熵，而用任务损失定义信息价值：
`VoI_c(c) = E_{y∼p(·|c,o)}[ L*(o) − L*(o,y) ]`，其中 `L*(o) = min_a E_{θ,M}[ℓ(a,θ,M)|o]`。分解 `VoI_c = VoI_act + VoI_phys`。纯熵版本作为上界/诊断量保留，避免「为信息而信息」。

**定义 315（联合 VoI–可恢复–体验选择）** 候选接触承诺按约束优化：
`c* = argmax_{c∈C_safe} [ VoI_c(c) − λ_irr·Irr(c) − λ_rec·RC(c) − λ_ux·c_ux(c) ]`，
s.t. `Irr(c) ≤ δ_irr`、`D_t ≤ D_max`、`CE_t ≤ τ_trust`、接触漏斗成立。等价地给出「单位不可逆度信息增益」`EL(c) = VoI_c(c)/(Irr(c)+ε)` 作为 Pareto 诊断。若无可行 `c` 或最优值 ≤ 0，退回 `g^rev`；`g^rev` 也无利可图则退回 R69/R68。

**定义 316（UX 状态与校准信任）** `u_t = (τ_t 信任, w_t 脑力负荷, a_t 主体感, p_t 感知安全, l_t 可预测性)`。可观测代理 `b_t = (接管率, 响应延迟, 犹豫时长, 注视回避, 握持力, 主动提问)`，测量模型 `b_t = h(u_t) + ν_t`。系统可靠性 `r_t` 由认证性能与残差估计；校准误差 `CE_t = |τ_t − r_t|`。UX 成本是向量 `c_ux = (ΔCE, Δw, 打扰, Δa, 延迟)`，只有声明权重后才标量化；禁止隐式权重。

**定义 317（体验预算与体验债）** 长时程约束 `E[Σ_t c_ux(t)] ≤ B_ux`。信任非对称动态：
`τ_{t+1} = τ_t + α(1−τ_t) − β·1[失信_t] + γ·1[诚实承认不确定_t]`，`β > α`，且「被延迟发现的沉默失败」按 `β_late > β` 计。体验债 `D_t = max(0, D_{t−1} + c_ux(t) − ρ_refill)`；`D_t > D_max` ⇒ 禁止接触探索、返回 R69 的非接触路径。这个「债」是 R69 标定漂移在体验侧的镜像。

**定义 318（用户侧不确定性与可读性动作）** 用户对机器人模态的后验熵 `U_epi^H = H(M | o_H, preview)`，`o_H` 是用户对机器人动作的观测。可读性动作 `ℓ ∈ 𝒜_leg`：预成形、注视方向、微停顿、轨迹塑形、接触前姿态展示、忠实短解释。可读性增益 `L(ℓ) = I(M; o_H^+ | ℓ)`。双侧平衡目标：在预算内使 `U_epi^R ≤ τ_R` 且 `U_epi^H ≤ τ_H`；若只能用一侧，选择每比特成本更低者。**忠实性约束**：`preview` 的分布必须等于当前真实模态后验（或其认证的保守近似），否则视为解释剧场并作废证书。

**定义 319（接触安全证书与接触漏斗）** `C-RAS-WM‡` 在 R69 前缀认证上增加接触层：允许力旋量锥 `𝒲_safe(s)`、冲量预算 `J_max`、滑移预算 `s_max`、接触点稳定性裕度 `ρ_c`。证书要求 `P(force ∉ 𝒲_safe) ≤ δ_F`、`P(impulse > J_max) ≤ δ_J`、`P(slip > s_max) ≤ δ_S`。**安全证据与信息证据必须独立**：不能用同一个待认证的探针同时作为「它安全」的唯一证据；安全证书必须来自动作前模型/离线认证与动作后独立监测两条通道。

**定义 320（体验感知的模态仲裁与迟滞）** 模态选择加入切换迟滞 `h_sw` 与切换成本：仅当任务收益超过阈值且新模态在安全集内才切换；因不确定性触发的切换必须先走可读性动作（或同帧短预览）。定义切换状态机与「不反复横跳」约束：在 `T_h` 窗口内同一对模态的切换次数 ≤ `n_h`。解释必须说明「为什么换」，且与真实后验一致。

**定义 321（GRACE 威胁模型与同意有效性）** `ℰ_GRACE = ℰ_FLUID × ℰ_contact × ℰ_ux`：
- `ℰ_contact`：触觉欺骗（伪造硬/软）、摩擦突变表面、接触传感器饱和、冲击导致模型失配、恶意物体诱导滑落；
- `ℰ_ux`：解释剧场、通过时间压力/默认选项制造同意、用流畅动作制造过度信任、交互疲劳、情绪/生理推断的隐私侵犯、UX 指标被刷；
- `ℰ_FLUID`：继承 R69 的流采样故障、模态坍缩、投毒与幻觉模态。
**同意有效性**：存在可执行的拒绝动作、系统不隐藏替代方案、用户能理解当前不确定性与后果（可读性达标）。形式化要求 `P(用户可拒绝) ≥ 1−ε`，且「拒绝后系统安全降级」可认证。

**定义 322（证书 J_GRACE）** `J_GRACE = (J_FLUID, ρ_min, Irr_p95, recovery_success, contact_margin, CE_trust, D_ux_max, legibility_p05, consent_valid, grace_ver)`。
Valid ⇔ `Valid(J_FLUID)` ∧ `Irr_p95 ≤ δ_irr` ∧ 恢复认证覆盖达标 ∧ `CE_trust ≤ τ_trust` ∧ `D_ux ≤ D_max` ∧ `consent_valid` ∧ (`legibility ≥ L_min` 或 `U_epi^H ≤ τ_H`)。

**定义 323（三级退避与严格包含）** 
1. 接触安全 ∧ 体验预算可用 ∧ 同意有效 ⇒ 接触探索 + R69；
2. 不可接触 / 不可逆度过高 / 体验债越界 / 同意无效 ⇒ 退回 R69 的非接触 `g^rev`（注视/询问/悬停）；
3. R69 的 `g^rev` 也无利可图、ECE 越界或 `slow_fault_suspect` ⇒ 退回 R68 的纯保守 `λ_floor`。
严格包含：`𝒜_contact=∅`、`c_ux` 退化为逐步标量、`κ=0`（忽略 `U_epi^H`）、`D_max=∞` 时，GRACE 与 R69 逐指令相同。安全集随约束单调收缩；在证书有效前提下失败概率 ≤ R69 + `δ_irr`，证书失效则回退，不产生「未经认证的额外风险」。

**定义 324（自适应探索深度）** 接触探索深度 `d_exp ∈ {0,1,2}`（0=不接触，1=单次微探针，2=受控微滑/二次确认）。默认 0；仅当 `U_epi^phys` 高、`ρ(s)` 充裕、`D_t` 低、且 `VoI_c` 超过阈值时升 1；二次确认要求事件独立（定义 325）且恢复裕度仍达标。目标是在 P99 内完成，且避免「为了确认而确认」的连续深探。

**定义 325（接触证据的正交性）** 物理参数的证据必须来自**独立接触事件**：同一探针重复加压不构成独立证据；微滑与按压对 `μ` 与 `k_c` 的判别力不同，可视为近似正交。用户口头回答、触觉估计、视觉先验三者冲突时不做简单平均，而是保持未消解并升级到 `g^ask` 或保守退避。安全证据与信息证据必须来自不同通道（定义 319）。

**定义 326（保形恢复覆盖与在线重校准）** 用保形预测对恢复结果做有限样本保证：在可交换性下 `P(s' ∈ R_δ) ≥ 1−δ`；接触动力学非平稳时用在线保形/自适应覆盖，维护滑动窗口的经验覆盖率 `ĉov`。当 `ĉov < 1−δ−ε_cov` 时，收缩 `R_δ`、降低 `d_exp`、并记入证书。这是对「可恢复证书在接触瞬间最不可信」的正面回应。

## 2. 关键算法骨架

```python
# IP-264 CCX：接触承诺动作空间与触觉编码（复用 R69 FMP trunk，新增接触头）
class ContactCommitment:
    def __init__(self, fmp, tactile_encoder, contact_head):
        self.fmp, self.tac, self.head = fmp, tactile_encoder, contact_head
    def sample(self, o_t, K):
        xi = self.fmp.sample(o_t, K)                 # (a, g^rev)
        c  = self.head(xi, self.tac(o_t))            # 候选接触承诺
        return [(x_, c_) for x_, c_ in zip(xi, c)]

# IP-265 RECON：可恢复性认证 + 保形覆盖 + 接触漏斗
def certify_commitment(c, s, recon_model, funnel, calib):
    rho   = recon_model.margin(s)                    # 距 R_δ 边界
    irr   = recon_model.irreversible_prob(s, c)      # 定义 312
    rc    = recon_model.recovery_cost(s, c)
    ok    = (irr <= DELTA_IRR and rc <= B_REC
             and funnel.force_ok(c, s) and funnel.impulse_ok(c, s)
             and funnel.slip_ok(c, s))
    if not ok or not calib.covers(rho):
        return False, None
    return True, (irr, rc, rho)

# IP-266 CVoI：任务相关的接触信息价值 + 物理参数后验更新
def contact_voi(c, s, belief, task_loss):
    base = task_loss.optimal(belief)                 # L*(o)
    exp  = 0.0
    for y, p in belief.predict_contact(c, s):        # 触觉/力/滑移预测
        exp += p * task_loss.optimal(belief.update(y))
    return base - exp                                # VoI_c，定义 314

# IP-267 URX：UX 状态估计（行为代理 + 低频量表 + 校准）
class UXEstimator:
    def update(self, b_t, survey=None):
        self.u = self.filter.predict_update(b_t)     # τ, w, a, p, l
        if survey is not None:                       # 稀疏、低打扰
            self.u = self.fuse(self.u, survey)
        self.ce = abs(self.u.trust - self.reliability)   # 校准误差
        return self.u, self.ce

# IP-268 XBG：体验预算/体验债 + 非对称信任 + 节流
class ExperienceGovernor:
    def allow(self, c_ux, u):
        self.debt = max(0.0, self.debt + c_ux - self.refill)
        self.trust = (self.trust + ALPHA*(1-self.trust)
                      - BETA*self.violation - GAMMA*self.honest_uncertainty)
        return self.debt <= self.D_max and self.ce <= self.tau_trust

# IP-269 LEG：可读性动作（降低用户侧不确定性，而非机器人侧）
def choose_legibility(modes, w, u_h, budget):
    best = None
    for leg in legible_candidates(modes):            # 预成形/注视/微停顿/忠实解释
        gain = mutual_info(mode_identity, leg.observable, modes)
        if not budget.allow_leg(leg): continue
        score = gain / (leg.cost + EPS) - LAMBDA_H * max(0.0, u_h - TAU_H)
        if best is None or score > best.score: best = (leg, score)
    return best if best and best.score > 0 else None

# IP-270 HAM：体验感知的模态仲裁（迟滞 + 不横跳 + 忠实解释）
def arbitrate_modes(modes, task_gain, safety, state):
    valid = [m for m in modes if safety.admits(m)]
    if not valid: return None, "fallback"
    m_new = max(valid, key=task_gain)
    if m_new is not state.mode:
        if not state.hysteresis_ok(m_new, T_H, N_H): return state.mode, "hold"
        if state.window_switch_count(m_new) >= N_H: return state.mode, "hold"
    return m_new, "switch" if m_new is not state.mode else "keep"

# IP-271 主闭环：R69 + 可恢复接触 + 体验预算 + 双侧认知
def GRACE_RAS_round(M, obs):
    z, o = M.mtm.forward(obs)                        # R68/R69 一次前向
    c_cal, U_cal, thr = M.cof.step(o)                # R69 标定
    # 1) R69 侧：流模态 + 机器人 epistemic 分解
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi_act, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    U_epi_phys = M.phys_posterior.entropy()
    # 2) 用户侧：UX 状态与用户不确定性
    u, ce = M.urx.update(M.proxies.last())
    U_epi_H = M.leg.user_mode_entropy(modes)
    # 3) 接触承诺：只在可恢复管道内、体验预算内、同意有效时
    c_star = None
    if (U_epi_phys > TAU_PHYS and M.xbg.allow(M.urx.cost_contact(), u)
            and M.consent.valid()):
        for cand in M.ccx.sample(o, K):
            ok, cert = M.recon.certify_commitment(cand.c, o, M.recon_model,
                                                  M.funnel, M.calib)
            if not ok: continue
            voi = M.cvoi.contact_voi(cand.c, o, M.belief, M.loss)
            score = voi - LAMBDA_IRR*cert[0] - LAMBDA_REC*cert[1] \
                        - LAMBDA_UX*M.urx.cost(cand.c)
            if score > 0 and (c_star is None or score > c_star.score):
                c_star = (cand.c, score, cert)
    # 4) 可读性：先用便宜的动作降低 U_epi^H，再决定是否问
    leg = M.leg.choose_legibility(modes, U_epi_H, M.budget)
    if leg is not None: M.leg.execute(leg, faithful=True)
    # 5) 非接触/接触消歧；失败则逐级退避
    if c_star is not None:
        y = M.contact.execute(c_star.c)               # 带独立安全监测
        M.belief.update_contact(y)
        U_epi_phys = M.phys_posterior.entropy()
        M.xbg.record_contact(c_star.c)
    elif U_epi_act > TAU_EPI and not M.fma.slow_fault_suspect:
        g = M.mint.choose_interaction(modes, o, M.budget)   # R69 边界
        if g is not None:
            U_epi_act = M.cia.update_belief(modes, M.cia.execute(g))
    # 6) 两级 + 体验退避：未消解则视同 aleatoric
    U_floor = U_ale + (U_epi_act + U_epi_phys)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    if M.fma.slow_fault_suspect or M.xbg.debt > M.D_max or not M.consent.valid():
        lam = max(lam, 0.8); U_floor = U_ale + U_epi_act + U_epi_phys
    # 7) 体验感知仲裁 + 前缀认证 + 审计
    mode, why = M.ham.arbitrate_modes(modes, M.task_gain, M.safety, M.state)
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H),
                                    ..., wm_preds, contact=c_star)
    tau = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.ux_auditor.submit_async(leg, c_star, U_epi_H, ce, M.xbg.debt, why)
    return k, lam, mode, (U_ale, U_epi_act, U_epi_phys, U_epi_H)
```

## 3. 推导

**引理 19（信息—耗散下界）** 在接触观测受高斯噪声 `σ²` 污染、摩擦辨识需要对接触面做相对位移的模型下，辨识动摩擦 `μ_k` 的信息量满足 `I(μ_k; y_c) ≤ ½ log(1 + η·J_diss/σ²)`，其中 `J_diss` 是滑动耗散能量、`η` 为接触几何常数。因此 `VoI_phys > 0 ⇒ Irr(c) > 0` 的下界随目标精度上升。系：**不存在「高物理信息 + 零不可逆」的免费探索**；R69 的「信息只用时间/社交成本买」是 `J_diss→0` 的退化。工程含义：应优化「单位不可逆度的信息增益」`EL(c)`，而不是先最大化信息再补安全。

**引理 20（可恢复接触探索的安全性）** 若 `Irr(c) ≤ δ_irr`、恢复策略在 `R_δ` 内认证成功概率 ≥ `1−δ_rec`、接触漏斗满足 `δ_F,δ_J,δ_S`、且保形覆盖 `ĉov ≥ 1−δ−ε_cov`，则由联合界，任务失败概率 ≤ `δ_irr + δ_rec + δ_F + δ_J + δ_S + ε_cov`；且递归可行性保证状态在 `R_δ` 内。证明要点：每个约束失败事件取并集；恢复策略的收缩性保证单调回到任务集。系：**可恢复性把「不可逆接触」转化为「有界不可逆预算」**，这是 GRACE 能碰的根据。

**引理 21（可读性与询问的互补）** 对模态 `M`，`H(M) − H(M|preview) = I(M;preview)`。若可读性动作每比特成本 `c_leg/I_leg` 低于询问每比特成本 `c_ask/VoI_ask`，则应优先预览；当 `preview` 已使 `U_epi^H ≤ τ_H` 时，询问只应服务于 `U_epi^R`，不应为「让用户安心」而重复问。系：**解释不是免费的安慰剂，而是一种信息通道**；其最优使用由每比特成本决定，且必须忠实。

**引理 22（体验债与节流）** 在信任动态 `β>α`、体验债按 `D_t = max(0, D_{t−1}+c_ux−ρ_refill)` 演化时，任何逐步贪心策略都可能使 `D_t` 越界；采用令牌桶（refill=`ρ_refill`，单次消耗=`c_ux`）可保证 `D_t ≤ D_max`，且长期接触探索速率收敛到 `ρ_refill/c_ux`。此外，若沉默失败被延迟发现的概率 `p_d` 满足 `p_d·β_late > c_ask`，则「诚实询问」在长期信任债上优于「沉默执行」——**诚实的不确定比被发现的确定更便宜**。

**定理 18（GRACE 严格包含 R69）** 当 `𝒜_contact=∅`、`c_ux` 为逐步标量、`κ=0`、`D_max=∞`、`CE` 不约束时，GRACE 的动作选择、模态分解与退避逻辑与 R69 逐指令相同；当允许接触时，可行安全集是 R69 安全集与可恢复约束的交集，故在证书有效前提下期望风险 ≤ R69 + `δ_irr`，证书失效则回退到 R69/R68。安全侧不做任何放松，效率增益只能来自可恢复探索与可读性。

**定理 19（忠实可读性抑制信任剧场）** 若 `preview` 的分布与真实模态后验一致（忠实性），则重复交互下 `U_epi^H` 与 `CE` 的期望单调不增；若 `preview` 系统性乐观（`preview` 把高不确定模态的概率压低），则在一阶随机占优下 `τ` 被推高而 `r` 不变，`CE` 增大，且 UXAuditor 通过「预览—实际模态」的校准残差可在 `O(1/ε²)` 次交互内以高概率检出。系：**可读性必须可证伪；解释剧场会被自己的日志抓住**。

**定理 20（接触探索的无突变与退避单调性）** 在接触漏斗、可恢复管道与迟滞仲裁下，力/冲量/滑移有界，模态切换不频繁且控制连续；当体验债越界、同意失效、保形覆盖不足或 FMA 报缓变故障时，`λ` 单调不降地退回 R69/R68，且提交/换装不变式（R68 定理 15）保持。证明要点：接触动作被限制在紧集 `C_safe`，恢复策略提供回退路径；迟滞消除极限环；退避只增加 `λ` 与收缩 `k`。

## 6. 本轮最大风险

**一句话**：GRACE 允许系统「为了知道而碰」，但**「可恢复」证书恰恰在最需要它的接触瞬间最不可信**——接触动力学模型误差、冲击与夹持突变会让 `R_δ` 高估恢复裕度，而体验层的「流畅/可读」又可能把这种风险包装成可信；一旦发生试探性损伤或沉默失败，**系统不是死于不知道，而是死于「以为自己还能退回来」**。

**次级风险与缓解**：
1. **试探性损伤/不可恢复滑移** → RECON 保形覆盖 + 接触漏斗 + 微滑预算 + 独立后监测（定义 319、326，定理 20）；
2. **信任剧场/解释剧场** → 忠实预览约束 + UXAuditor 残差审计 + 证书作废（定义 318、定理 19）；
3. **体验债短期被低估** → 非对称信任 + 令牌桶节流 + `D_max` 硬闸（定义 317、引理 22）；
4. **同意被制造** → 可拒绝动作、隐藏替代方案检测、审计（定义 321）；
5. **接触模型 OOD** → 未知物体默认 `d_exp=0`；覆盖不足即收缩 R-tube、回退 R69；E298/E313 对抗测试。

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** `GRACE-RAS = (CCX, RECON, CVoI, URX, XBG, LEG, HAM, RAS-WM‡)`；零学习写操作继承；接触承诺必须可恢复（`R_δ`、`Irr≤δ_irr`、`RC≤b_rec`、接触漏斗）；体验预算与校准纪律（`D_t≤D_max`、`CE_t≤τ_trust`，禁止制造同意）；双侧认知纪律（解释必须忠实，禁止解释剧场）。

**定义 311–312（接触承诺与可恢复性）** `ξ=(a,g^rev,c)`；`s'=f_c(s,c)` 通常不可逆。`R_δ(s)={s':∃π_rec, P(回任务集)≥1−δ}`；`Irr(c|s)=1−P(s'∈R_δ(s))`；`RC` 为期望恢复代价；`C_safe` 为满足 `Irr`、`RC` 与漏斗的承诺集。

**定义 313–314（物理后验与接触 VoI）** `p(θ|ℋ_t)` 由触觉/力/滑移更新；`U_epi^phys=H(θ|ℋ_t)`。`VoI_c(c)=E_y[L*(o)−L*(o,y)]`，分解为动作项与物理项；不用纯熵替代任务损失。

**定义 315（联合选择）** `c*=argmax_{c∈C_safe}[VoI_c−λ_irr·Irr−λ_rec·RC−λ_ux·c_ux]`，s.t. `Irr≤δ_irr`、`D_t≤D_max`、`CE_t≤τ_trust`、漏斗成立；无可行或收益 ≤0 则退回 `g^rev`。

**定义 316–317（UX 状态与体验债）** `u_t=(τ,w,a,p,l)`；行为代理 + 低频量表估计，`CE=|τ−r|`。信任非对称：`τ_{t+1}=τ_t+α(1−τ_t)−β·失信+γ·诚实承认不确定`，`β>α`；`D_t` 令牌桶式演化，越界禁接触。

**定义 318（可读性与用户侧不确定性）** `U_epi^H=H(M|o_H,preview)`；可读性动作 `ℓ`（预成形/注视/微停顿/轨迹塑形/忠实短解释）；`L(ℓ)=I(M;o_H^+|ℓ)`；预览分布必须等于真实模态后验或其认证保守近似，否则证书作废。

**定义 319（接触安全与证据独立）** `C-RAS-WM‡` 增加力旋量锥 `𝒲_safe`、冲量预算 `J_max`、滑移预算 `s_max`、接触稳定裕度 `ρ_c`；安全证据与信息证据必须独立，禁止「探针自证安全」。

**定义 320（体验感知仲裁）** 模态切换需迟滞 `h_sw` 与切换成本；不确定性触发的切换先走可读性动作；`T_h` 窗口内同对模态切换 ≤ `n_h`；解释必须说明真实原因。

**定义 321（威胁模型与同意有效性）** `ℰ_GRACE=ℰ_FLUID×ℰ_contact×ℰ_ux`；`ℰ_contact` 含触觉欺骗、突变摩擦、传感器饱和、冲击失配；`ℰ_ux` 含解释剧场、制造同意、过度信任、交互疲劳、隐私与指标刷量。同意有效性要求可拒绝、不隐藏替代方案、可理解。

**定义 322（证书）** `J_GRACE` 并入恢复裕度、不可逆度、恢复成功率、接触裕度、CE、体验债、可读性分位、同意有效性；Valid 要求 `J_FLUID` 有效且以上全部达标。

**定义 323（三级退避与严格包含）** 接触安全 + 体验预算 + 同意有效 → 接触探索 + R69；否则退回 R69 的 `g^rev`；R69 也无利可图/ECE 越界/缓变故障 → 退回 R68 纯保守。`𝒜_contact=∅`、`c_ux` 逐步标量、`κ=0`、`D_max=∞` 时与 R69 逐指令相同。

**定义 324–325（自适应深度与证据正交）** `d_exp∈{0,1,2}`，默认 0；高 `U_epi^phys` + 充裕 `ρ` + 低体验债 + 高 VoI 才升 1，二次确认需独立接触事件。同一探针重复加压不算独立证据；冲突不做平均，保持未消解并升级询问或保守退避。

**定义 326（保形恢复覆盖）** 可交换性下 `P(s'∈R_δ)≥1−δ`；非平稳接触用在线保形/滑动窗口覆盖率 `ĉov`；`ĉov<1−δ−ε_cov` 时收缩 `R_δ`、降低 `d_exp`、记入证书。

```python
# IP-264 CCX：接触承诺动作空间（复用 R69 FMP trunk；新增接触头）
class ContactCommitment:
    def __init__(self, fmp, tactile_encoder, contact_head):
        self.fmp, self.tac, self.head = fmp, tactile_encoder, contact_head
    def sample(self, o_t, K):
        xi = self.fmp.sample(o_t, K)                  # (a, g^rev)
        c  = self.head(xi, self.tac(o_t))             # 候选接触承诺
        return [(x_, c_) for x_, c_ in zip(xi, c)]

# IP-265 RECON：可恢复认证 + 接触漏斗 + 保形覆盖
def certify_commitment(c, s, recon_model, funnel, calib):
    rho = recon_model.margin(s)
    irr = recon_model.irreversible_prob(s, c)
    rc  = recon_model.recovery_cost(s, c)
    ok  = (irr <= DELTA_IRR and rc <= B_REC
           and funnel.force_ok(c, s) and funnel.impulse_ok(c, s)
           and funnel.slip_ok(c, s))
    if not ok or not calib.covers(rho):
        return False, None
    return True, (irr, rc, rho)

# IP-266 CVoI：任务相关的接触信息价值 + 物理参数后验
def contact_voi(c, s, belief, task_loss):
    base = task_loss.optimal(belief)
    exp  = sum(p * task_loss.optimal(belief.update(y))
               for y, p in belief.predict_contact(c, s))
    return base - exp

# IP-267 URX：UX 状态估计与校准误差
class UXEstimator:
    def update(self, b_t, survey=None):
        self.u = self.filter.predict_update(b_t)       # τ, w, a, p, l
        if survey is not None:
            self.u = self.fuse(self.u, survey)         # 稀疏、低打扰
        self.ce = abs(self.u.trust - self.reliability)
        return self.u, self.ce

# IP-268 XBG：体验预算/体验债 + 非对称信任 + 节流
class ExperienceGovernor:
    def allow(self, c_ux, u):
        self.debt = max(0.0, self.debt + c_ux - self.refill)
        self.trust = (self.trust + ALPHA*(1-self.trust)
                      - BETA*self.violation - GAMMA*self.honest_uncertainty)
        return self.debt <= self.D_max and self.ce <= self.tau_trust

# IP-269 LEG：可读性动作（降低用户侧不确定性）
def choose_legibility(modes, w, u_h, budget):
    best = None
    for leg in legible_candidates(modes):
        gain = mutual_info(mode_identity, leg.observable, modes)
        if not budget.allow_leg(leg): continue
        score = gain / (leg.cost + EPS) - LAMBDA_H * max(0.0, u_h - TAU_H)
        if best is None or score > best.score: best = (leg, score)
    return best if best and best.score > 0 else None

# IP-270 HAM：体验感知仲裁（迟滞 + 不横跳 + 忠实解释）
def arbitrate_modes(modes, task_gain, safety, state):
    valid = [m for m in modes if safety.admits(m)]
    if not valid: return None, "fallback"
    m_new = max(valid, key=task_gain)
    if m_new is not state.mode:
        if not state.hysteresis_ok(m_new, T_H, N_H): return state.mode, "hold"
        if state.window_switch_count(m_new) >= N_H: return state.mode, "hold"
    return m_new, "switch" if m_new is not state.mode else "keep"

# IP-271 主闭环：R69 + 可恢复接触 + 体验预算 + 双侧认知
def GRACE_RAS_round(M, obs):
    z, o = M.mtm.forward(obs)
    c_cal, U_cal, thr = M.cof.step(o)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi_act, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    U_epi_phys = M.phys_posterior.entropy()
    u, ce = M.urx.update(M.proxies.last())
    U_epi_H = M.leg.user_mode_entropy(modes)
    c_star = None
    if (U_epi_phys > TAU_PHYS and M.xbg.allow(M.urx.cost_contact(), u)
            and M.consent.valid()):
        for cand in M.ccx.sample(o, K):
            ok, cert = M.recon.certify_commitment(cand.c, o, M.recon_model,
                                                  M.funnel, M.calib)
            if not ok: continue
            voi = M.cvoi.contact_voi(cand.c, o, M.belief, M.loss)
            score = voi - LAMBDA_IRR*cert[0] - LAMBDA_REC*cert[1] \
                        - LAMBDA_UX*M.urx.cost(cand.c)
            if score > 0 and (c_star is None or score > c_star.score):
                c_star = (cand.c, score, cert)
    leg = M.leg.choose_legibility(modes, U_epi_H, M.budget)
    if leg is not None: M.leg.execute(leg, faithful=True)
    if c_star is not None:
        y = M.contact.execute(c_star.c)
        M.belief.update_contact(y)
        U_epi_phys = M.phys_posterior.entropy()
        M.xbg.record_contact(c_star.c)
    elif U_epi_act > TAU_EPI and not M.fma.slow_fault_suspect:
        g = M.mint.choose_interaction(modes, o, M.budget)
        if g is not None:
            U_epi_act = M.cia.update_belief(modes, M.cia.execute(g))
    U_floor = U_ale + (U_epi_act + U_epi_phys)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    if M.fma.slow_fault_suspect or M.xbg.debt > M.D_max or not M.consent.valid():
        lam = max(lam, 0.8)
    mode, why = M.ham.arbitrate_modes(modes, M.task_gain, M.safety, M.state)
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H),
                                    ..., wm_preds, contact=c_star)
    tau = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.ux_auditor.submit_async(leg, c_star, U_epi_H, ce, M.xbg.debt, why)
    return k, lam, mode, (U_ale, U_epi_act, U_epi_phys, U_epi_H)
```

## 4. 推导

**引理 19（信息—耗散下界）** 在接触观测受高斯噪声 `σ²` 污染、摩擦辨识依赖相对位移的模型下，`I(μ_k;y_c) ≤ ½ log(1+η·J_diss/σ²)`。故 `VoI_phys>0` 必然要求 `Irr(c)>0` 的相应下界；不存在「高物理信息 + 零不可逆」的免费探索。系：优化目标应是 `EL(c)=VoI_c/(Irr+ε)`，R69 是 `J_diss→0` 的退化。

**引理 20（可恢复接触探索的安全性）** 若 `Irr(c)≤δ_irr`、恢复成功 ≥ `1−δ_rec`、接触漏斗满足 `δ_F,δ_J,δ_S`、保形覆盖 `ĉov≥1−δ−ε_cov`，则任务失败概率 ≤ `δ_irr+δ_rec+δ_F+δ_J+δ_S+ε_cov`，且递归可行性保证状态留在 `R_δ`。系：可恢复性把不可逆接触转化为有界不可逆预算。

**引理 21（可读性与询问互补）** `H(M)−H(M|preview)=I(M;preview)`。若 `c_leg/I_leg < c_ask/VoI_ask` 则优先预览；`preview` 已使 `U_epi^H≤τ_H` 时，询问只服务 `U_epi^R`。系：解释是信息通道，不是免费安慰剂，且必须忠实。

**引理 22（体验债与节流）** 在 `β>α`、`D_t=max(0,D_{t−1}+c_ux−ρ_refill)` 下，逐步贪心可使 `D_t` 越界；令牌桶可保证 `D_t≤D_max`，长期接触探索速率收敛到 `ρ_refill/c_ux`。若沉默失败被延迟发现的概率满足 `p_d·β_late>c_ask`，则诚实询问在长期信任债上优于沉默执行。

**定理 18（GRACE 严格包含 R69）** `𝒜_contact=∅`、`c_ux` 逐步标量、`κ=0`、`D_max=∞`、不约束 `CE` 时，GRACE 与 R69 逐指令相同；允许接触时，可行安全集是 R69 安全集与可恢复约束的交集，证书有效下期望风险 ≤ R69+`δ_irr`，证书失效则回退 R69/R68。安全侧不放松。

**定理 19（忠实可读性抑制信任剧场）** 忠实 `preview` 下，`U_epi^H` 与 `CE` 期望单调不增；系统性乐观预览会推高 `τ` 而 `r` 不变，`CE` 增大，UXAuditor 可由「预览—实际模态」校准残差在 `O(1/ε²)` 次交互内高概率检出。系：解释必须可证伪。

**定理 20（接触探索无突变与退避单调）** 接触漏斗、`R_δ` 与迟滞仲裁下，力/冲量/滑移有界、模态切换不频繁、控制连续；体验债越界、同意失效、覆盖不足或 FMA 缓变故障时，`λ` 单调不降地退回 R69/R68，提交/换装不变式保持。

## 7. 本轮最大风险

**一句话**：GRACE 允许系统「为了知道而碰」，但**「可恢复」证书恰恰在最需要它的接触瞬间最不可信**——接触动力学模型误差、冲击与夹持突变会让 `R_δ` 高估恢复裕度，而体验层的流畅/可读又可能把这种风险包装成可信；一旦发生试探性损伤或沉默失败，**系统不是死于不知道，而是死于「以为自己还能退回来」**。

**次级风险与缓解**：试探性损伤/不可恢复滑移（RECON 保形覆盖 + 接触漏斗 + 微滑预算 + 独立后监测）；信任剧场/解释剧场（忠实预览 + UXAuditor 残差审计 + 证书作废）；体验债短期低估（非对称信任 + 令牌桶 + `D_max` 硬闸）；同意被制造（可拒绝动作 + 隐藏替代检测 + 审计）；接触模型 OOD（未知物体默认 `d_exp=0`，覆盖不足即回退）。
