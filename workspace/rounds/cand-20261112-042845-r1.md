# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；本轮灵感：「快速原型」×「中间件」）

> 第 57 轮把安全的赌注从"证据承诺"进一步压到"证据质量"：摊销元先验给效率、共形带保底、跨模态对账给分歧下限、个性化信任单向有界。但它的风险自陈暴露了一个更根本的工程事实：**这些判定器（元模型、模态可靠性、信任状态机、共形带、解释渲染器）已经多到没有人能同时验证它们；系统越强，越依赖"把一堆各自未证毕的部件正确组装起来"这件从未被形式化的事。** 第 57 轮说"一切判定器走隔离"，却没有回答隔离的**运行时载体**是什么、新部件如何**快速而安全地进入**、以及"谁守守卫"。本轮两个灵感正好各补一刀：**中间件**把安全从"每个部件都正确"改写成"一条不可旁路的窄腰总线 + 一个可完全测试的小内核"——能力面可以快、可以错、可以热插拔，安全面必须慢、必须小、必须可证；**快速原型**把"新能力进入"的单位从"改系统"降为"加原型"，并用**证伪先行 + 单向建议**保证原型的错误只能让系统更保守，不能让它更敢赌。核心命题由"少样本可校准、跨模态可对账、个性化有界的证据说可信"升级为 **"中间件守底、原型快进、证伪先行、声明不作数的证据说可信"**。

核心矛盾：
- **H29（快速原型 vs 验证时延）**：原型的速度来自"先跑起来再说"，安全的速度来自"证完再跑"，两者争的是同一个部署窗口。若安全层随能力一起快速演进，TCB 会被原型文化稀释；若安全层冻结，原型就被迫绕过它——绕过一旦成为惯例，纵深归零。
- **H30（中间件 vs 单点）**：中间件把安全收敛到一处，因而可验证；但也把失效收敛到一处。窄腰一旦漏（fail-open 默认、自报证书被信任、执行器未全托管），前五轮所有纵深同时归零，且失效模式是"静默的"，因为能力面看起来一切正常。
- **H31（原型建议 vs 权威）**：最近原型推断天然想"把新区域归到旧类"，这正是第 57 轮"坏先验普遍"的镜像；而如果原型永远只能保守，它又会沦为只增不减的绕行税——安全与活性必须显式分账，不能用一个"更保守"的口号同时糊弄两者。

## 0. 直觉与动机

**灵感 1（快速原型 → 原型记忆与"新类即新原型"）**
直觉：第 57 轮的摊销先验有一个隐含暴力：它假设新区域总能被解码成"已见过的某类"。真实世界更常见的是"这一片谁都没见过"。快速原型给两种互补读法：**(a)** 机器学习里的原型——用"类原型 + 最近原型距离"替代全量摊销后验，新样本按距离归类，距离过大就**拒识**而不是硬塞；**(b)** 工程里的原型——新能力先以最小可运行件进入，**不重训整个系统**。二者合起来是一条原则：**新世界不塞进旧先验，新世界生成新原型；原型是能力的增量单位，不是安全的授权单位。** 原型可以飞快地"记住"一种新表面，但它的记忆在被证伪之前只能让系统更小心。

**灵感 2（中间件 → 两平面与不可旁路窄腰）**
直觉：中间件最值钱的地方不是"解耦"，而是**把横切关注点只实现一次**。安全就是最强的横切关注点。把系统劈成两平面：**能力面**（规划器、元模型、原型、解释器、人——全都不被信任，只能"提议"）与**安全面**（一个小的引用监视器 + 固定证据模式——唯一能"承诺"的东西）。所有执行器都挂在监视器之后，任何不可逆接触必须拿到监视器的 `authorize`。这样，能力的正确性不再是系统安全的必要条件；能力的错误最多变成"更保守、更慢"。窄腰（固定证据代数）保证新增能力是**插到能力面**，而不是**加宽 TCB**。

**灵感 3（声明不作数 → 验证或降级）**
直觉：第 57 轮有一个未写进假设的信任漏洞：监视器若直接相信消息里自报的"ECE≤ε""两模态独立""我是 A2 授权""原型可靠度 0.95"，那么总线就成了骗子最省力的攻击面。中间件的铁律应是：**证书是总线上的数据，不是总线上的权威。** 任何自报属性要么被监视器独立验证，要么自动降到最低权威。声明独立 → 监视器查共模注册表与跨模态残差；声明校准 → 监视器用影子流上的留出集自算；声明授权 → 监视器验签审计链并查升级速率；声明可靠 → 监视器用自己的证伪台账。验不动就按 A0 处理。

**灵感 4（证伪先行 → 晋升流水线与"探索可锐化、承诺只加宽"）**
直觉：快速原型最大的危险不是原型错，而是**原型错了还被赋予承诺权**。因此把原型的权威与它的估计精度解耦：原型可以**为探索而锐化**（选探针、算 VOI——因为探针非破坏，错了只浪费预算），但**为承诺只能加宽**（监视器只用加宽后的包络做不可逆决策）。原型走 draft→shadow→canary→active 的晋升流水线，每一级都要求影子回归不劣化（ECE、OOD、分歧触发率）且爆炸半径有界、可自动回滚；证伪事件直接降权并回溯其来源区域。于是**安全由构造保证**（错原型只会更保守），**活性才是要拿实验去争的东西**。

**灵感 5（合流 → 证据门不变，权威来源改变）**
直觉：第 57 轮的五类证据门（EV-probe*/visit/margin/xmodal/human）**一条都不改**——它们仍是承诺的必要条件。改变的是"谁能把这些证据送上总线、以及总线信几分"：证据由能力面生产，由安全面验证；原型建议是第六类**只减不增**的证据（只能否决/加宽，不能顶替必要条件）。纵深没有变浅，而是从"五层判定器串联"变成"五层判定器 + 一个不可旁路的汇流点"，后者才是可审计、可测试、可完全重放的那一层。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（原型记忆与最近原型推断 PNM）** 原型记忆 Π={(p_j,ℓ_j,Σ_j,rel_j,prov_j,t_j)}；p_j 为表面响应签名原型（μ/k/F_bear 的充分统计），ℓ_j 语义类，Σ_j 度量尺度，rel_j∈[rel_min,1] 可靠度，prov_j 来源区域/回合，t_j 时戳。对新区域 r 的观测 o，d_j=d_Π(o,p_j;Σ_j)（Mahalanobis），j\*=argmin_j d_j。**拒识规则**：d_{j\*}>θ_proto 或 (d_{(2)}−d_{(1)})<θ_margin_proto ⇒ 判 novel，**禁止硬归类**，生成 draft 原型入隔离区。原型更新仅在事后 verdict 之后、且经定义 141 晋升；rel_j 按证伪乘性降、按证实有界升。原型只产出**建议** Advice=(ℓ_{j\*}, d_{j\*}, 加宽量 Δw, 锐化后验 q̃)，不含承诺权（定义 142）。

**定义 140（安全中间件 / 证据总线 SMB）** 两平面：能力面 𝒞（不可信，只发 Proposal）、安全面 𝒮（TCB，唯一可发 Commit）。消息信封 Env=(proposal, evidence, declared, prov, sig)。引用监视器 M\* 强制不变量集 I：
(I1) **调解完备**：所有不可逆执行器在 M\* 之后，无 `authorize` 不可动作；
(I2) **必要证据**：不可逆接触仍须 {EV-probe\*∨EV-margin}∪佐证，EV-xmodal 不得进入（继承定义 137）；
(I3) **单向建议**：M\* 对某模块提交的风险只可**加宽或拒绝**，不可收窄；
(I4) **失败关闭**：未知/畸形证据类、缺 prov、模式违约 ⇒ 拒绝；
(I5) **声明不作数**：见定义 143。
TCB 规模约束 |M\*|≤B_tcb，M\* 不含在线学习参数（或仅含经静态验证的常量表）——**受信部分必须是能被完全测试的那部分**。

**定义 141（原型晋升流水线 P3）** 生命周期 draft→shadow→canary→active→retired。draft→shadow：模式与 prov 完备，零权威影子运行；shadow→canary：窗口 W 上影子回归 ΔECE≤ε_reg ∧ ΔOOD-AUC≥−δ_reg ∧ Δ分歧触发率≥−δ_reg ∧ **零次收窄事件**；canary→active：爆炸半径 ≤β（区域/流量占比）分阶段放量，任一证伪或 I 违约自动回滚；active→retired：证伪/老化/漂移。所有迁移入审计。**晋升单调安全**：原型建议对承诺只加宽，故即使原型全错，晋升也不能提高不可逆承诺风险。

**定义 142（能力-安全窄腰 CSNW）** 证据代数 E 与权威格 𝔄（A0<A1<A2<…）。能力面输出必须是 E 的合法项；窄腰=固定版本化模式，**新增能力=新增插件并映射到既有权威类，而非修改 M\***。未知项默认最低权威（失败关闭）；提升某证据类的权威属于 **TCB 变更**，须走与定义 141 同级的重验证（重放+差分+不变量检查），**不得走快速原型通道**。权威单调：新插件默认 A0，只有模式显式授予才升级。

**定义 143（声明元数据不信任 VOD）** 对任意自报属性 π∈{indep, ECE, auth, rel, ρ, prov}，M\* 计算验证替代 π̂ 或降级：indep→共模注册表+跨模态残差检验；ECE→影子流留出集自算；auth→审计链验签与速率检查；rel→证伪台账自算；prov→溯源哈希链。若在预算内不可验证 ⇒ 权威取 A0/最小。**证书是数据，不是权威。**

**定义 144（证伪先行原型算子 FFP / PCE++）** 在第 57 轮 PCE+ 的每检查点插入：①取原型建议（加宽包络 + 锐化探索估计）；②若建议将改变承诺判定，或原型处于 draft/shadow，则以"与最近竞争原型的最大分歧"选**边界证伪探针**（非破坏预算 k_falsify 内）；③承诺只经 M\* 用加宽包络与必要证据门；④任一证伪 ⇒ rel_j 降、触发降级、回溯 prov_j 区域并记入台账。终止于 k_probes+k_cons+k_falsify。

## 2. 关键算法伪代码（完整版见产物区）

```python
def prototype_advise(Pi, r, obs):                    # IP-139: 只建议，不授权
    ds = sorted((mahalanobis(obs, p, S), j) for j, (p, S) in Pi.items())
    d1, j1 = ds[0]
    if d1 > theta_proto or (ds[1][0] - d1) < theta_margin_proto:
        return Advice(novel=True, proto=None, widen=W_NOVEL)   # 拒识 → draft
    return Advice(novel=False, proto=j1, widen=widen_from(d1),
                  sharpen=sharpen_posterior(obs, Pi[j1]))

def safety_middleware(env, Mstar):                   # IP-140/143: 唯一承诺出口
    ev = verify_or_downgrade(env.declared, env.prov, Mstar)   # 声明→验证/降级
    if not schema_ok(env) or ev is None:
        return Reject('fail_closed')                 # I4
    risk = max(env.proposal.risk, widen_by(env.evidence, ev))  # I3: 只可加宽
    if env.irreversible and not necessary_evidence(env.evidence, ev):
        return Reject('evidence_insufficient')       # I2
    if risk > Mstar.threshold(env.consent):
        return Reject('risk')
    return Commit(env.proposal, ev, Mstar.sign(env)) # 执行器只认此签名
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| PNM | O(\|Π\|·d) / 查询；原型增 O(d) | O(\|Π\|·d) | 拒识不硬归类、rel 单调受控 |
| SMB | O(1) 调解 + O(verify) | O(\|I\|) 常量 | 调解完备、失败关闭、执行器全托管 |
| P3 | O(W·\|shadow stream\|) 晋升时 | O(\|Π\|) | 回归不劣化、爆炸半径有界、可回滚 |
| CSNW | O(1) 类型检查 | O(\|E\|) 模式 | 未知项拒绝、权威单调、TCB 不变 |
| VOD | O(verify(π)) | O(台账) | 验不动即降级、无声明权威 |
| PCE++ | 继承 PCE+ + O(k_falsify·d) | O(\|V\|+\|Π\|) | 单向建议、k 内终止 |

**正确性定理（Middleware-Prototype Soundness, MPS 概要）**：在 A22–A40 上加 **(A41)** 调解完备 + 失败关闭 + 执行器全托管；**(A42)** 单向建议：承诺只用加宽包络，锐化仅用于探索/VOI；**(A43)** 验证或降级：未验证声明不授予权威；**(A44)** 晋升流水线健全、证伪台账完整。则：
1. **TCB 归约**：不可逆承诺失效率 ≤ δ_M\* + δ_gate + δ_probe + δ_h + …，与能力面各模块（含原型、元模型、解释器）正确性**解耦**；错误能力至多导致保守（活性损失），不能单独导致不安全承诺。
2. **原型安全**：由 A42+A43+A44，新增/更新/投毒原型只能使承诺风险单调不增；快速原型不提高不可逆风险。
3. **演化无旁路**：新能力经 CSNW 以最低权威进入；提升权威即 TCB 变更，须重验证；能力增长不会静默增大受信基。
4. **终止性**：PCE++ 在 k_probes+k_cons+k_falsify 内终止于 {承诺, 绕行, L2 协商, 安全停}。
5. **部署界**：P_safe ≥ 1 − δ_M\* − Σ_cp(δ_f+δ_gate+δ_probe+δ_h+δ_ood·α_conf) − P(TCB bug) − P(模式漏检) − P(执行器未托管)。

诚实注记：安全性可由"拒绝一切"平凡达成，故**活性不作定理、只作实验指标**（E181 的绕行税、拒识率、部署时延）——这正是本轮的诚实边界。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 窄腰单点：M\* bug 或模式漏检导致全系统失效 | 高 | TCB 尺寸/复杂度硬预算、形式化不变量检查、重放+差分测试、执行器全托管审计 |
| fail-open / 自报证书被信任 | 高 | 失败关闭默认、VOD 验证或降级、未知证据类一律拒绝 |
| 原型文化加宽窄腰、加旁路 | 高 | 窄腰版本化 + 权威单调 + 提升权威走 TCB 重验证（最慢通道）+ 审计 |
| 过度保守拖垮活性（绕行税） | 中 | 探索可锐化、E181 活性指标、原型只在承诺侧加宽 |
| 原型漂移/投毒 | 中 | 晋升流水线 + 证伪台账 + 来源回溯 + 自动回滚 |

## 6. 本轮最大风险

**一句话**：本轮把前五轮的全部纵深汇流到一个又小又可信的中间件上，风险从"坏先验普遍"变成"**窄腰单点**"——一旦引用监视器有 bug、模式 fail-open、或执行器未被完全托管，能力面的任何一次快速原型都可能绕过所有五层证据；而原型文化的默认压力恰恰是加宽窄腰、加旁路、相信自报证书；必须以失败关闭、执行器全托管、声明一律验证或降级、TCB 尺寸与变更预算硬约束，把"加宽窄腰"当成唯一需要最慢流程批准的变更。

# 第 58 轮产物 · 创新点清单 v34：Middleware-Prototype（安全中间件×原型快速进入×证伪先行，SMB×PNM×P3×CSNW×VOD×PCE++）

> 承接第 57 轮 IP-133~138（MFSL/XMC/PTM/MXI/FSE/PCE+）、第 56 轮 IP-127~132（SMM/PCE/BVK/ISE/TAF/MEC）与第 55 轮 IP-121~126。本轮把部署前提从"少样本可校准、跨模态可对账、个性化有界的证据承诺"升级为 **"中间件守底、原型快进、证伪先行、声明不作数的证据承诺"**：安全不再要求每个判定器都正确，而要求**所有承诺经由一条不可旁路的窄腰总线与一个可完全测试的小内核**；新能力不再靠改系统进入，而以**原型**为增量单位、经证伪先行的晋升流水线进入，且对承诺只有单向（加宽）权威。第 57 轮"一切判定器走隔离"在本轮落地为"**一切能力走窄腰，一切权威走验证**"。
> IP 编号：IP-139~IP-144（共 6 个），升级 IP-137/IP-138 以纳入中间件与原型维度。

## 0. 核心 IP 设计

### IP-139 PNM（原型记忆与最近原型推断）

```python
def prototype_advise(Pi, r, obs):
    ds = sorted((mahalanobis(obs, p, S), j) for j, (p, S) in Pi.items())
    d1, j1 = ds[0]
    if d1 > theta_proto or (ds[1][0] - d1) < theta_margin_proto:
        draft = new_prototype(obs, prov=r, state='draft')   # 新类即新原型
        Pi.add(draft)
        return Advice(novel=True, proto=draft, widen=W_NOVEL)  # 拒识+加宽
    return Advice(novel=False, proto=j1,
                  widen=widen_from(d1),                     # 承诺侧：只加宽
                  sharpen=sharpen_posterior(obs, Pi[j1]))   # 探索侧：可锐化

def update_prototype(Pi, j, verdict):                       # 仅事后 verdict 后
    if verdict.falsifies:
        Pi[j].rel = max(rel_min, Pi[j].rel * gamma_down)    # 乘性降
        flag_provenance(Pi[j].prov); Pi[j].state = 'retired'
    elif verdict.confirms:
        Pi[j].rel = min(1.0, Pi[j].rel + gamma_up)          # 有界升
```

### IP-140 SMB（安全中间件 / 证据总线）

```python
def safety_middleware(env, Mstar):
    # (I4) 失败关闭 + (I5) 声明不作数
    if not schema_ok(env) or not has_prov(env):
        return Reject('fail_closed')
    ev = verify_or_downgrade(env.declared, env.prov, Mstar)  # IP-143
    if ev is None:
        return Reject('unverifiable_declared')
    # (I3) 单向建议：风险只可加宽
    risk = max(env.proposal.risk, widen_by(env.evidence, ev))
    # (I2) 必要证据（继承 FSE）：EV-xmodal 不得进不可逆
    if env.irreversible and not necessary_evidence(env.evidence, ev):
        return Reject('evidence_insufficient')
    if risk > Mstar.threshold(env.consent):
        return Reject('risk')
    # (I1) 唯一承诺出口；执行器只认 M* 签名
    return Commit(env.proposal, ev, Mstar.sign(env))

def require_mediation(actuator):
    assert actuator.only_accepts_signed_commit(Mstar)       # I1: 全托管审计
```

### IP-143 VOD（声明元数据不信任：验证或降级）

```python
def verify_or_downgrade(declared, prov, Mstar):
    out = {}
    for k, v in declared.items():
        if k == 'indep':
            ok = Mstar.common_mode_registry.consistent(prov) \
                 and Mstar.residual_check(prov)
        elif k == 'ece':
            ok = Mstar.shadow_holdout.ece(prov) <= v        # 自算，不信自报
        elif k == 'auth':
            ok = Mstar.audit.verify_chain(prov) and Mstar.rate_ok(prov)
        elif k == 'rel':
            ok = Mstar.falsification_ledger.matches(prov, v)
        elif k == 'prov':
            ok = Mstar.hash_chain.verify(prov)
        else:
            ok = False
        out[k] = v if ok else MIN_AUTHORITY                  # 验不动 → 降级
    return out
```

### IP-141 P3（原型晋升流水线，证伪先行）

```python
def promote(proto, stream, ledger):
    if proto.state == 'draft':
        if schema_ok(proto) and has_prov(proto):
            proto.state = 'shadow'; audit.log(('shadow', proto.id))
    elif proto.state == 'shadow':
        if shadow_regression_ok(proto, stream, W):
            proto.state = 'canary'; proto.blast = beta_min
    elif proto.state == 'canary':
        if any(falsified(proto, e) for e in ledger.recent):
            return demote(proto, 'falsified')
        if proto.blast < beta_max and canary_clean(proto, W):
            proto.blast *= 2
        elif proto.blast >= beta_max:
            proto.state = 'active'
    return proto

def shadow_regression_ok(p, stream, W):
    return (ece_delta(p, stream, W) <= eps_reg
            and ood_auc_delta(p, stream, W) >= -delta_reg
            and disagreement_rate_delta(p, stream, W) >= -delta_reg
            and p.narrow_events == 0)          # 零次收窄事件
```

SCHEMA = {                       # 版本化固定窄腰；新增能力只能映射到此

### IP-144 PCE++（探-诺-演++：证伪先行）

```python
def probe_commit_evolve_plus(x0, M, task, budget, consent, personas, Pi, Mstar):
    route = plan_on_map(M, task, risk_model)
    for cp in route.checkpoints:
        adv = prototype_advise(Pi, cp.region, M.obs[cp.region])
        # 探索侧可用锐化估计选探针（非破坏，错只浪费预算）
        while select_gait(schedule_risk(foothold_schedule(x0, cp, M), M)) == 'halt' \
              and budget.probes_left > 0:
            p = argmax(admissible_probes(cp, M, F_abs),
                       key=lambda q: voi_meta_pessimistic(q, M, adv) - cost(q))
            if voi_meta_pessimistic(p, M, adv) < theta_voi: break
            M, _, D = xmodal_fuse(M, cp.region, execute_probe(p, cap=F_abs))
            budget.spend(p)
        # 证伪先行：若建议改变承诺判定或原型未 active → 边界证伪探针
        if adv.proto and (adv.changes_decision(cp) or Pi[adv.proto].state != 'active'):
            for q in boundary_probes(Pi, adv.proto, k_falsify):
                M, _, _ = xmodal_fuse(M, cp.region, execute_probe(q, cap=F_abs))
                if falsifies(Pi[adv.proto], q):
                    update_prototype(Pi, adv.proto, verdict=FALSE)
                    break
        # 承诺侧只加宽：把 advice 包成证据信封送 M*
        env = Envelope(proposal=commit_candidate(cp, M), evidence=tag_evidence_p(M, cp),
                       declared=declared_of(M, Pi, personas), prov=provenance(cp),
                       irreversible=(contact_level(cp) == 'L2'))
        st = safety_middleware(env, Mstar)
        if st.ok: commit(st.proposal); continue
        alt = reroute(M, cp, risk_model)
        if alt: route = alt; continue
        return negotiate_or_stop(cp, M, consent,
                                 tau_int=tau_int(personas.active.auth))
    return route, Pi, Mstar.audit
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| PNM | O(\|Π\|·d)/查询；增 O(d) | O(\|Π\|·d) | 拒识不硬归类、rel 单调受控（A42/A44） |
| SMB | O(1) 调解 + O(verify) | O(\|I\|) 常量 | 调解完备、失败关闭、执行器全托管（A41） |
| P3 | O(W·\|stream\|) 晋升时 | O(\|Π\|) | 回归不劣化、半径有界、可回滚（A44） |
| CSNW | O(1) 类型检查 | O(\|E\|) 模式 | 未知项拒绝、权威单调、TCB 不变（A42） |
| VOD | O(verify(π)) | O(台账) | 验不动即降级、无声明权威（A43） |
| PCE++ | O(\|CP\|·(k_p+k_c+k_f)·(C_VOI+d)+\|CP\|·A\*) | O(\|V\|+\|Π\|) | 单向建议、k 内终止 |

**正确性定理（Middleware-Prototype Soundness, MPS）**
假设 A22–A32（第 53–55 轮）、A33–A36（第 56 轮）、A37–A40（第 57 轮）成立；**(A41)** 调解完备与失败关闭：所有不可逆执行器只接受 M\* 签名，未知/畸形消息一律拒绝，无旁路；**(A42)** 单向建议：承诺只用加宽包络，原型/元模型的锐化估计仅用于探索与非破坏探针选择；**(A43)** 验证或降级：任何未通过 M\* 独立验证的自报属性不授予高于 A0 的权威；**(A44)** 晋升流水线健全：影子回归门、爆炸半径有界、自动回滚、证伪台账完整。则：

1. **TCB 归约（能力正确性不再是安全必要条件）**：不可逆承诺失效率
   `P(fail) ≤ δ_M* + δ_gate + δ_probe + δ_h + δ_ood·α_conf`，
   与能力面各模块（原型、元模型、解释器、个性化）的正确性**解耦**；错误能力至多导致保守（活性损失），不能单独导致不安全承诺。
2. **原型安全（快速原型不升险）**：由 A42（只加宽）+ A43（声明不作数）+ A44（晋升可回滚），新增、更新、投毒原型只能使承诺风险单调不增；即使原型全错，系统退化方向是"更多拒识/绕行"，不是"更敢赌"。
3. **演化无旁路（能力增长不静默扩大受信基）**：新能力经 CSNW 以最低权威进入；提升证据类权威属于 TCB 变更，须走重放+差分+不变量检查的慢通道；因此"快速原型"只加速能力面，不加速受信基。
4. **终止性**：每检查点共识探针 ≤k_cons、边界证伪探针 ≤k_falsify，PCE++ 在 k_probes+k_cons+k_falsify 内终止于 {承诺, 绕行, L2 协商, 安全停}。
5. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − δ_M* − Σ_cp (δ_f + δ_gate + δ_probe + δ_h + δ_ood·α_conf)
             − P(TCB 实现 bug) − P(模式漏检) − P(执行器未托管)
```

关键：**安全从"每个判定器都对"改写为"唯一承诺出口 + 不可旁路 + 失败关闭 + 声明不作数"**；**能力面快、可错、热插拔，安全面慢、小、可证**；**原型为探索可锐化、为承诺只加宽**，于是快速原型在构造上不能升险；**证书是总线上的数据而非权威**。诚实注记：安全性可由"拒绝一切"平凡达成，故活性（绕行税/拒识率/部署时延）不作定理、只作 E181 的实验指标。

## 6. 本轮最大风险

**一句话**：本轮把前五轮的全部纵深汇流到一个又小又可信的中间件上，风险从"坏先验普遍"变成"**窄腰单点**"——一旦引用监视器有 bug、模式 fail-open、或执行器未被完全托管，能力面的任何一次快速原型都可能绕过所有五层证据；而原型文化的默认压力恰恰是加宽窄腰、加旁路、相信自报证书；必须以失败关闭、执行器全托管、声明一律验证或降级、TCB 尺寸与变更预算硬约束，把"加宽窄腰"当成唯一需要最慢流程批准的变更。
