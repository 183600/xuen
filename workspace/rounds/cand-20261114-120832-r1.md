# 第 74 轮（承接第 73 轮「MODGAUGE-RAS 计量契约代数」IP-295~301；灵感循环第 1 轮；本轮灵感：「四足机器人」×「中间件」）

> R73 把证据计量从「认知层」推进到「契约层」：模块三元组、证据契约 EC、组合代数 CCA（SER/PAR/VETO）、反作用通道 ΣREFLEX、组合证书 J_MOD、主张绑定 CPB，并给出热替换定理（引理 35）与组合单调性（引理 34）。它回答了「证据不确定度能否成为可组合的一等公民」。但 R73 的整个代数默认了三件**未经检验**的事：
> - **静态拓扑假设**：MReg 是部署期固定的 DAG。四足机器人的**接触图以步态频率离散切换**（站立/行走/小跑/奔跑），每个相位 φ 的活跃模块、有效域 D、噪声参数、否决集都不同。R73 的组合定理没有「相位」这个维度：J_MOD 在相位切换处要么出现**证书缝合缝（certificate seam）**，要么必须每步重证——这直接违背 C3「热替换/重配置由契约保持」的初衷。
> - **共模耦合假设**：R73 把「隐共享物理过程耦合」列为第 5 次级风险（同一光源/振动/温度场）。四足机器人让这条风险升格为**主要矛盾**：机体本身就是最强的共模源——落足冲击、关节振动、机身俯仰、电机温升、地面反作用，同时调制 IMU、深度、触觉、音频。R73 的 PAR「并联仅在 \|ρ̂\|<ρ_max 时允许缩窄」在步态下被系统性违反，而且相关性是**相位条件化**的（支撑相与腾空相的共模结构不同）。
> - **时序可执行假设**：R73 在 EC 里写了 W（WCET/执行域）并断言时序隔离（引理 28），却从未规定**谁来执行**。真实中间件（ROS 2/DDS、AUTOSAR、Zenoh）决定截止期、优先级反转、执行器抖动、消息丢失、时钟偏斜、发现/销毁延迟。**迟到不是中性的**：迟到 30ms 的深度帧是一份不确定度不同的证据；错过控制截止期是不可补偿的否决。R73 把时序当工程细节，而它其实是「关于证据的证据」。
>
> 两个灵感各补一块，再合成第三块：
> - **四足机器人** → **PEC（Phase-indexed Evidence Contract）**：证据契约按步态相位索引；MReg 从一张静态图变成**相位图族** {MReg^(φ)}，相位切换带连续性义务（无证书缝合）；新增 **PLM（Proprioceptive Leg Metrology）** 足端接触/腿式里程计六分量；安全谓词从「无碰撞」升级为**可生存性 viability**（稳定裕度 + 跌倒为吸收态）；把共模显式化为 **CCM（Common-Mode Metrology）**，用独立于模块的第三方观测者辨识共享隐变量。
> - **中间件** → **TEC（Timing Evidence Contract）× MCF（Middleware Contract Fabric）**：把 EC 编译为 QoS 剖面、执行器、调度类、CPU/内存隔离、DDS 域与时钟域，并部署运行时监控；**时序不确定度 u_time 进入预算**，截止期违约、时钟偏差异常、QoS 降级全部映射为**否决**；热替换升级为**负载下准入控制**（contract equivalence + 可调度性分析 + 时钟同步界 + 共模门控）。
> - **合成** → **CADENCE-RAS（Contract Algebra for Dynamic Evidence: Networked Composition & Execution）**：**时空组合代数 PCA**——在 R73 的 SER/PAR/VETO 之外增加相位切换算子 ⇝ 与时间管道算子 ∘_t；证书从静态 J_MOD 升级为**运行时轨迹证书 J_EXEC**（跨超周期的相位轨迹 × 时序轨迹 × 共模审计 × 可生存性轨迹）。
>
> 核心命题：**R73 问「证据计量能否成为可组合的契约」；R74 问「这套契约代数能否在步态频率的动态重配置与真实中间件的时序约束下被真正执行、调度与持续审计」**——契约不再是一份声明，而是一个**被中间件执行、被监控器测量的运行时对象**。安全不再只是「不出碰撞」，而是「在有限相位族与有限时序预算内保持可生存」。

## 0. 直觉与动机

**灵感 1（四足机器人 → 证据有相位，安全是可生存性）**
直觉：四足的运动是**离散接触事件驱动的**：落足、支撑、蹬离、腾空，接触图在每次切换时改变。小跑（trot）对角支撑、行走（walk）三足支撑、奔跑（bound）含腾空相。于是同一支 IMU 在支撑相被落足冲击污染，在腾空相反而干净；同一台深度相机在机体俯仰时运动模糊变大；同一条腿式里程计在打滑（slip）或下陷（sink）时从「外部基准」退化为「错误观测」。R73 把「接触」当作手的模式条件，本轮把**整个机体的接触调度**当作证据的条件变量：p(y | s, φ, v, m, ζ)，φ 是步态相位，ζ 是共模隐变量。更关键的是，四足的安全不是「机械臂式」的碰撞避免，而是**不跌倒**——跌倒是一个不可逆吸收态，稳定裕度（支撑多边形/ZMP、捕获点、角动量）是连续安全谓词。这意味着 J_MOD 必须扩展为「相位可行 + 时序可行 + 稳定裕度可行」的联合证书；只证明「估计误差小」而不管机体是否已经要翻，是没有意义的。

**灵感 2（中间件 → 契约必须被执行，时序本身是证据）**
直觉：没有被调度的契约就是注释。中间件不是透明管道，它是**契约的执行点**：DDS 的 reliability/durability/deadline/liveliness QoS、执行器与回调组、优先级与 CPU 亲和、内存锁定、时钟域与 PTP 同步、生命周期与发现。同一份证据契约在单线程仿真里成立，在真实 DDS 上可能因为回调排队 40ms 而失效。因此必须引入 **TEC（时序证据契约）**：每个模块声明周期、截止期、优先级、隔离等级、时钟域、传输 QoS 与迟到分布；**u_time 进入不确定度预算**；截止期违约不是「性能下降」，而是**非补偿否决**（迟到的证据不得静默进入融合）。组合规则也随之改变：串联是执行器链上的截止期传播；并联要求同一时钟域或有界偏斜（否则跨模态残差无意义）；否决包含 deadline-miss、QoS 降级、时钟投毒。热替换不再只是「同契约」，而是「同契约 **且** 新图可调度（响应时间分析 RTA）**且** 时钟同步界成立」——这是**负载下热替换定理**。

**灵感 3（共模 → 不是相关性估计，而是可辨识性边界）**
直觉：步态振动同时进入所有传感器，PAR 的「|ρ̂|<ρ_max 才缩窄」会把这种相关误判为「恰好这次残差小」，从而凭空缩窄不确定度——这正是 R73 最大风险里说的「所有证书有效却组合出错误的世界」。诚实的做法不是加一个更聪明的相关性估计，而是承认**可辨识性边界**：用 k 个独立于模块的第三方观测者（高频 IMU、热电偶、光电二极管、电流计、外部动捕/已知几何）观测共享隐变量 ζ；只有当耦合矩阵 K(φ) 在激励下满秩时，才能把「模块个体误差」与「共模误差」分离。否则唯一安全的做法是**禁用 PAR 缩窄 + 提升到共模否决**。这把 R73 的次级风险 5 变成一等公民，并给出一个可能为负面的结论（引理 40）：共模可分离性不是免费的。

**灵感 4（合成 → 时空组合与运行时轨迹证书）**
直觉：R73 的证书是「部署期快照」，R74 的证书是「运行时轨迹」。一个超周期 H 内，系统经历相位序列 φ_0 ⇝ φ_1 ⇝ …，每个相位有自己的模块图、自己的时序预算、自己的共模结构。安全 = **轨迹上的每个时刻都有覆盖它的有效证书，且相位切换处无缝隙**。这把「验证」从「证明一张图」变成「证明一条带时间戳的图序列」；监控器（J_EXEC）不是可选日志，而是安全论证的组成部分——它必须在硬实时域内证明「刚才那段证据是在契约内产生的」。

## 1. 形式化定义（增量：定义 383–400）

**定义 383（CADENCE-RAS 总览）** CADENCE-RAS = (PEC, PLM, CCM, TEC, MCF, PCA, J_EXEC, GVOP, MODGAUGE-RAS†)。六不变式：
(i) **相位完备**：∀ 活跃相位 φ，MReg^(φ) 的每个节点实例化完整 PEC，缺一不可入图；
(ii) **相位连续性（无证书缝合）**：φ ⇝ φ′ 的切换窗口内，要么两侧契约的有效域交非空且 J 连续，要么进入已认证安全相位 Φ_safe（默认 stand）并显式记录证书间隙；
(iii) **时序闭合**：每个组合的端到端截止期可调度，u_time 进入预算，任何截止期违约/QoS 降级/时钟越界 ⇒ 非补偿否决；
(iv) **共模可辨识或保守**：共享隐变量 ζ 要么被独立观测者充分辨识，要么该相位禁用 PAR 缩窄并提升否决；
(v) **可生存性安全**：安全谓词为 viability（稳定裕度 h(x) ≥ 0），跌倒为吸收态；不考虑稳定裕度的「低估计误差」不构成安全；
(vi) **严格退化链扩展**：相位失效 → 相位级 stub → 安全相位回退 → 系统级 R68；中间件时序违约 → 模块 stub（不得静默降级）。安全侧只增不减。

**定义 384（相位索引证据契约 PEC）** EC_φ = (EC, φ, Γ, δ_sw, cont)：
- EC 为 R73 定义 367 的证据契约；
- φ ∈ Φ：步态相位（contact schedule 的标签）；
- Γ：相位进入守卫（guard）——本体状态/接触估计/负载条件满足时才允许在该相位使用本契约；
- δ_sw：相位切换窗口（≥ 最慢模块延迟 + 监控周期）；
- cont：连续性义务——相邻相位的有效域、否决集、预算在切换走廊内如何拼接（见定义 391 的 ⇝）。
**同契约替换**（R73 引理 35）在 R74 中升级为：∀φ，EC′_φ 与 EC_φ 逐字段相同且 Γ/δ_sw/cont 相容。

**定义 385（相位图族 MReg^Φ）** MReg^Φ = ({MReg^(φ)}_{φ∈Φ}, E_Φ)：每个相位一张模块 DAG；E_Φ 为带守卫的相位迁移边。活跃节点 V_M(φ) ⊆ V_M、活跃边 E_M(φ) ⊆ E_M 可随 φ 变化。接触图 CT(φ) = (feet, stance/swing, 估计接触力) 是相位图的**物理索引**：CT 的每条边决定 PLM 的哪些分量有效。

**定义 386（步态相位与接触调度）** Φ = {stand, walk, trot, pace, bound, transition}（|Φ| ≤ 6）；占空比 β(φ)、相位时长 T_φ、切换时刻 {t_k}。接触变量 c_f(t) ∈ {0,1}（足 f 是否着地）。**安全相位集** Φ_safe ⊆ Φ：stand/crouch 等可在任意时刻进入且处于 viability 核内的相位。相位迁移必须满足守卫 Γ 与切换窗口 δ_sw；未建模接触模式（绊倒/滑移恢复）统一归入 φ_unknown，并由保守策略处理（见定义 395）。

**定义 387（本体运动计量 PLM）** 观测 y_leg = (关节编码器 q, q̇, τ, 足端力 f_foot, IMU)。条件似然 p(y_leg | s, φ, terrain)。六分量：
u_leg² = u_slip² + u_sink² + u_compliance² + u_impact² + u_enc² + u_kin²
分别对应：足端切向滑移、软地形下陷、足垫/地形柔顺、落足冲击（与 φ 强相关）、编码器偏置/量化、腿部运动学标定误差。接触似然 p(c_f=1 | y_leg) 与腿式里程计 Δx_leg（协方差 Σ_leg）。**关键连接**：PLM 是 R73 定义 378 深度在线自标定的**外部基准来源**——但仅在 p(c=1) 高且 u_slip/u_sink 低于阈值时；腿式里程计自身失效时不得用作锚点（防止自举循环升级为跨模态自举循环）。

**定义 388（共模计量 CCM）** 共享隐变量 ζ_t = (振动 v, 温度 T, 光照 L, 电磁/电源 E)。独立观测者集 O = {高频 IMU、热电偶、光电二极管、电流计、外部动捕/已知几何}，**其定义域不与任何证据模块共享**（否则不是独立观测）。模块 i 的噪声：
u_i² = u_i,indep² + u_i,cm²，u_i,cm = ‖K_i(φ) ζ‖ + ν_i，
K_i(φ) 为耦合矩阵。共模相关 ρ_cm(φ) = Corr(ε_i, ε_j | ζ, φ)。**可辨识条件**：在激励下 rank([K_i(φ)]_i) = dim(ζ) 且观测噪声足够小，则可分离个体/共模；否则只能给保守上界。门控：ρ_cm(φ) > ρ_cm,max 或 rank 不足 ⇒ **本相位禁用 PAR 缩窄**，并允许任一模块对「共模异常下的融合结论」投否决票。

**定义 389（时序证据契约 TEC）** TEC = (T_period, D_deadline, p_priority, iso_class, κ_clock_domain, qos_profile, π_lateness)。时序不确定度：
u_time² = u_late² + u_jitter² + u_skew² + u_drop²，
由运行时监控器在线测量。**语义**：deadline miss、QoS 降级（reliability/durability/deadline/liveliness 不满足）、时钟偏斜超界、消息乱序/丢失 ⇒ **否决**（非补偿）。u_time 是 u_out 的组成项，不是外部日志。

**定义 390（中间件契约织构 MCF）** 编译器 Compile: EC_φ → Manifest，Manifest = (DDS domain/topic/QoS, executor 与回调组, 调度类与优先级, CPU 亲和/内存锁定, 隔离域, 时钟域, 监控探针, 生命周期租约)。MCF 负责：发现→配置→激活→（热替换）→销毁；每个模块实例持有**租约**，租约过期即 stub。MCF 同时输出 TEC 证据流供 J_EXEC 使用。**契约-执行分离原则**：计量域只声明契约，MCF 只执行契约，二者通过 Manifest 与 TEC 流解耦。

**定义 391（时空组合代数 PCA）** 在 R73 定义 370 的 SER/PAR/VETO 上增加：
- **相位切换 COMP-SWITCH（A ⇝ B）**：guard 成立的 δ_sw 窗口内，u_out = max(u_A, u_B)（保守并集，禁止缩窄）；D_out = D_A ∩ D_B；若交为空则强制进入 Φ_safe 并记录 seam；χ_R,out = χ_R,B ∘ χ_R,A。
- **时间管道 COMP-TSER（A ∘_t B）**：端到端 D_e2e = Σ D_i − Σ slack_i；优先级按 deadline-monotonic 分配并做优先级天花板，禁止无界反转；u_time 逐级累加（抖动不可相互抵消）。
- **准入 COMP-ADMIT（G ⇒ G′）**：热替换/重配置前检查（见定义 400）；未通过则拒绝，旧图继续运行。
**单调性（引理 34†）**：任何路径的输出不确定度对 (u_space, u_time, u_cm) 单调；只有 PAR 在**同时**满足 conformal 一致性审计、\|ρ̂\|<ρ_max、**且** CCM 可辨识门控通过时才允许缩窄。

**定义 392（运行时轨迹证书 J_EXEC）** J_EXEC = 超周期 H 上的带时间戳元组轨迹：
J_EXEC(t) = (φ(t), J_MOD^(φ(t)), TEC_trace(t), CCM_audit(t), V_trace(t), seam_log)。
Valid(J_EXEC, H) ⇔ ∀t：J_MOD 有效 ∧ TEC 未违约 ∧ CCM 未越界 ∧ h(x_t) ≥ 0 ∧ 相位切换 seam 已闭合或显式进入 Φ_safe。**J_MOD 是 J_EXEC 的单相位特例**。

**定义 393（可生存性安全谓词）** 令 h(x) 为稳定裕度（归一化捕获点距离/支撑多边形/角动量裕度之组合），h ≥ 0 为可生存，h < 0 为跌倒（吸收态）。安全 = 状态停留在 viability 核 K 内；风险单调性相对 h 定义：h 越小，允许的估计误差与反作用预算越紧。**这取代 R73「仅碰撞」的安全语义**，并让「冻结步态」成为一等安全动作（见定义 395）。

**定义 394（步态-视角-可生存性规划 GVOP）** 在计量域求解
a* = argmax_a [ Progress(a) − λ_u·E[u^{next}(a)] − λ_v·FallRisk(a) − Σ_i c_reflex^i(a) − λ_t·SlackPenalty(a) ]
s.t. REG 时序契约、D_φ、TEC 截止期、V_safe、C_safe。
与 R73 PVOP 的区别：动作空间从「视角」扩展到（足端落点，机身速度，视角），并显式惩罚跌倒风险与截止期余量不足。E[u^{next}] 仍由 χ_R 解析给出，但相位切换处必须用保守并集，不能解析外推。

**定义 395（相位级 stub 与安全相位回退）** stub^φ 继承 R73 定义 381（证据 ∅、u=∞、D=∅、I⊥=本模态全集、χ_R 平凡），并增加：stub 期间若 φ ∉ Φ_safe，则触发**步态冻结/回退**到 Φ_safe 中最近的认证相位；回退动作本身必须有 viability 证书（引理 43）。**未建模相位 φ_unknown 一律按 stub + 冻结处理**，宁可停在已证明安全的位置，也不在未证明的相位里继续运行。

**定义 396（中间件攻击面 AIC-MID）** 威胁面：QoS 降级攻击、发现投毒（伪造节点）、消息重放、时钟操纵（回拨/加速）、topic 冒充、执行器饥饿、生命周期劫持。防线：签名 Manifest + QoS 锁定 + 外部单调时钟/PTP 校验 + DDS 域隔离 + 速率限制 + 单源不定案（继承 E356/E357）。

**定义 397（复杂度结构上限†）** |Φ| ≤ 6、|V_M(φ)| ≤ 24、组合深度 ≤ 4、相位迁移边 ≤ |Φ|²、超周期内监控点 ≤ N；全部为**相位图族的可审计图性质**（部署期全查 + 运行时增量查）。

**定义 398（CPB† 扩展：C4）** 新增第四条可证伪主张：
**C4（可执行时空契约）**：把相位索引契约与时序证据纳入组合后，系统能在**步态相位切换处无证书缝合**地保持安全性质，且**时序违约 100% 被检出并映射为否决/stub**（不静默）。绑定：C4 ← (PEC, TEC, MCF, J_EXEC, PCA-⇝/∘_t) ← MB4 ← AB4（相位索引+时序证据 vs 静态单相位 vs 无时序审计）← (seam_gap, deadline_miss_detect, phase_switch_recovery, false_freeze_rate)。**判据**：若 C4 无法与 C3 隔离（即 MB4 的收益全部可由 MB3 静态热替换解释），则 C4 降级并折叠进 C3；预注册此降级条件。

**定义 399（MBench†：MB4/MB5）** MB4（相位计量）：受控步态×地形×负载矩阵 + 相位切换脚本，≤3h 单卡复现；MB5（中间件时序与负载）：ROS 2/DDS 上注入延迟/丢包/QoS 降级/时钟偏斜 + 负载下热替换，≤3h 单机复现。均预注册 + 固定种子 + 密封保持集 SEAL-MB。

**定义 400（负载下准入控制 ADMIT）** ADMIT(G ⇒ G′) = 契约等价 ∧ RTA 可调度（新端到端截止期满足）∧ 时钟同步界成立 ∧ CCM 门控通过 ∧ 相位连续性义务满足 ∧ 安全相位回退可用。任一失败 ⇒ 拒绝重配置，保留旧图。**热替换只在 ADMIT 通过后发生**。

```python
# IP-302 PEC：相位索引契约与相位图族
@dataclass(frozen=True)
class PhaseContract:
    ec: EvidenceContract                  # R73 定义 367
    phi: str                              # 步态相位
    guard: Callable[[State], bool]        # 相位进入守卫 Γ
    switch_window_s: float                # δ_sw ≥ 最慢模块延迟 + 监控周期
    continuity: Callable                  # cont：与相邻相位的拼接义务

class PhaseRegistry:                      # MReg^Φ
    def active_graph(self, phi):
        return self.graphs[phi]           # V_M(φ), E_M(φ)
    def switch(self, phi_old, phi_new, t):
        if not self.guards[phi_new](t): return 'HOLD'
        union = self.conservative_union(phi_old, phi_new)  # u=max, D=∩, 禁缩窄
        if union.domain_empty: return self.fallback_safe_phase()  # 定义 395
        self.seam_log.append((phi_old, phi_new, union, t)); return union

# IP-303 PLM：本体运动计量（感知域，100–200Hz）
class ProprioceptiveLegMetrology:
    def update(self, q, qdot, tau, f_foot, imu, phi):
        u_slip = self.contact.slip_unc(qdot, f_foot, phi)     # 切向滑移
        u_sink = self.terrain.sink_unc(f_foot, phi)            # 软地形下陷
        u_comp = self.foot.compliance_unc(f_foot)              # 柔顺
        u_imp  = self.impact_unc(imu, phi)                     # 落足冲击（相位强相关）
        u_enc  = self.enc.bias_unc(q)                          # 编码器
        u_kin  = self.kin.calib_unc(q)                         # 运动学标定
        p_contact = self.contact.likelihood(f_foot, qdot, phi)
        anchor_ok = p_contact > TAU_C and (u_slip < TAU_SLIP) and (u_sink < TAU_SINK)
        return LegEvidence(u=math.sqrt(u_slip**2+u_sink**2+u_comp**2+u_imp**2+u_enc**2+u_kin**2),
                           breakdown=(u_slip,u_sink,u_comp,u_imp,u_enc,u_kin),
                           p_contact=p_contact, anchor_ok=anchor_ok,
                           dx=self.leg_odom(q, qdot), phi=phi)

# IP-304 CCM：共模隐变量与可辨识门控
class CommonModeMetrology:
    def update(self, observers, phi):
        zeta = self.identify(observers)                  # 振动/温度/光照/电源
        K = self.coupling[phi]                           # 模块×隐变量 耦合
        rank_ok = matrix_rank(K) >= len(zeta)            # 可辨识条件
        rho = self.estimate_corr(phi)
        gate_ok = rank_ok and (rho < RHO_CM_MAX)
        return CCMEvidence(zeta=zeta, K=K, rho=rho,
                           gate_ok=gate_ok,
                           veto=set() if gate_ok else {'CM_UNIDENTIFIABLE'})

# IP-305 MCF：契约→中间件清单 + 时序监控（部署期 + 运行时）
def compile_manifest(ec_phi):
    return Manifest(qos=deadline_qos(ec_phi.tec.D, ec_phi.tec.T),
                    executor=choose_executor(ec_phi.tec.iso_class),
                    priority=deadline_monotonic(ec_phi.tec.D, ec_phi.tec.p),
                    isolation=pin_cpu_and_lock_memory(ec_phi.tec.iso_class),
                    clock=ec_phi.tec.kappa, lease_s=ec_phi.tec.D * 2,
                    probes=['lateness', 'jitter', 'drop', 'skew'])
def timing_monitor(module, tec):
    lateness = module.last_completion - module.last_deadline
    u_time = math.sqrt(lateness**2 + tec.jitter**2 + tec.skew**2 + tec.drop**2)
    veto = {'DEADLINE_MISS'} if lateness > 0 or tec.qos_violated else set()
    return TimingEvidence(u_time=u_time, veto=veto, trace=(lateness, tec.jitter, tec.drop))

# IP-306 PCA：时空组合（串/并/否 + 相位切换 + 时间管道 + 准入）
def compose_st(a_ev, b_ev, op, audit, ccm, tec):
    if op == 'TSER':
        if not rta_schedulable(a_ev.tec, b_ev.tec): return veto('RTA_FAIL')
        return Ev(u=monotone_sum(a_ev.u, b_ev.u, a_ev.u_time, b_ev.u_time),
                  D=a_ev.D & b_ev.D, veto=a_ev.veto | b_ev.veto,
                  d_e2e=a_ev.tec.D + b_ev.tec.D)
    if op == 'PAR':
        if not ccm.gate_ok: return Ev(u=max(a_ev.u, b_ev.u), veto=ccm.veto | {'PAR_BLOCKED_CM'})
        r = cross_modal_residual(a_ev, b_ev)
        if audit.conformal_covers(r) and abs(audit.estimate_corr(a_ev,b_ev)) < RHO_MAX \
           and same_clock_domain(a_ev, b_ev, TAU_SKEW):
            return fuse(a_ev, b_ev)
        return Ev(u=max(a_ev.u, b_ev.u), veto={'PAR_AUDIT_FAIL'})
    if op == 'SWITCH':
        return Ev(u=max(a_ev.u, b_ev.u), D=a_ev.D & b_ev.D,
                  seam=(a_ev.phi, b_ev.phi), veto=a_ev.veto | b_ev.veto)

# IP-307 J_EXEC：运行时轨迹证书（硬实时监控）
def jexec_tick(t, phi, j_mod, tec_trace, ccm, x):
    ok = j_mod.valid and not tec_trace.veto and ccm.gate_ok and h(x) >= 0
    if not ok: return 'STUB_AND_SAFE_PHASE'
    return 'VALID'

# IP-308 GVOP：步态-视角-可生存性规划（计量域 20Hz）
def gvop(b_t, mods, phi, risk):
    def J(a):
        prog = task_progress(b_t, a)
        u_next = conservative_next_u(mods, a, phi)       # 相位切换处 max，不解析外推
        reflex = sum(m.reflex_estimate(a) for m in mods)
        return prog - risk.lam_u*u_next - risk.lam_v*fall_risk(a) \
                    - reflex - risk.lam_t*deadline_penalty(a)
    return optimize_under_reg_contract(J, horizon=0.5, viability=K)

# IP-309 ADMIT + 相位级 stub / 安全回退
def admit_and_swap(old_graph, new_graph, phi):
    if not (contract_equiv(old_graph, new_graph) and rta_schedulable(new_graph)
            and clock_bound_ok(new_graph) and ccm.gate_ok
            and continuity_ok(old_graph, new_graph, phi)
            and safe_phase_available(phi)):
        return 'REJECT'                                  # 保留旧图
    return 'SWAP'

def on_phase_failure(phi):
    if phi in PHI_SAFE: return stub(phi)                 # 冻结在安全相位
    target = nearest_safe_phase(phi)
    assert viability_certified(phi, target)              # 引理 43
    return transition_to(target)

# IP-301† CADENCE 主闭环（在 R73 三域上加入相位与时序）
def CADENCE_round(M, obs, audio, tac_frame, depth_img, q, f_foot, imu):
    phi = M.gait.phase_estimate()                        # 步态相位（含 φ_unknown）
    # 感知域：契约证据 + 相位
    d_ev = M.dpe.update(depth_img, rgb, M.cam_state, M.motion, M.peers, phi)
    l_ev = M.plm.update(q, qdot, tau, f_foot, imu, phi)  # IP-303
    c_ev = M.ccm.update(M.observers, phi)                # IP-304
    if not d_ev.valid: d_ev = stub(M.dpe, phi)
    if not l_ev.anchor_ok: l_ev.anchor = None            # 禁止污染深度自标定
    # 计量域：相位图 + 时空组合 + 运行时证书
    if M.clock.due_metric():
        mreg = M.preg.active_graph(phi)
        b_t = M.bse.step_full(..., d_ev=d_ev, l_ev=l_ev, c_ev=c_ev)
        M.gvop = gvop(b_t, M.mods, phi, M.risk_params)   # IP-308
        g = M.ervoi.choose(b_t, ..., M.budget)
        if g and c_ev.gate_ok and not l_ev.veto:
            s2, _ = sigmareflex_step(M.mods, g, M.state, M.budget)
            if s2 is not None: M.last_g, M.state = g, s2
        M.jexec = jexec_tick(M.t, phi, J_MOD(mreg), M.tmon.latest(),
                             c_ev, M.state)              # IP-307
        if M.jexec != 'VALID': phi = on_phase_failure(phi)
        M.preg.switch(phi, M.gait.next_phase(), M.t)
    # 控制域：只读快照，硬实时；时序违约 ⇒ 冻结/回退
    snap = M.snapshot.read_latest()
    lam = embodied_risk_scale(..., max(snap.t_ev.u, snap.d_ev.u, snap.u_time, snap.u_cm))
    k = M.c_ras_wm.certified_prefix(M.ach.propose_ctrl(..., pvop_bias=snap.gvop), lam)
    M.ctrl_out.publish(k, lam)
    return k, lam, M.jexec
```

## 3. 推导

**引理 38（PLM 六分量的相位条件正交性）** 给定 (φ, terrain, c_f, 落足时刻) 条件下，u_slip/u_sink/u_compliance/u_impact/u_enc/u_kin 由独立物理机制产生（接触摩擦、地形承压、柔顺变形、冲击动力学、编码器、运动学标定），条件近似不相关；遗漏任一 ⇒ 系统性低估。系：**PLM 把 R73 的「(动作, 场景) 条件」扩展为「(动作, 场景, 步态相位) 条件」；接触模式从手扩展到全身接触调度。**

**引理 39（时序预算闭合与端到端截止期传播）** 对 COMP-TSER 链，若每段满足 WCET ≤ D_i、优先级按 deadline-monotonic 且采用优先级天花板，则端到端响应时间 R = Σ(C_i + 干扰_i) ≤ Σ D_i − Σ slack 当且仅当 RTA 通过；u_time 逐级不可抵消（抖动非负），故 u_out,time ≥ max_i u_time,i。系：**时序组合不产生「时间上的免费午餐」——与 R73 引理 34 的空间单调性同构。**

**引理 40（共模可辨识性边界）** 设 ζ ∈ ℝ^d，k 个独立观测者、m 个证据模块。若 rank([K_i(φ)]_{i=1..m}) < d，则个体误差与共模误差不可分离，任何 PAR 缩窄都可能把共模相关误判为独立性；此时唯一可证的界是保守并集 max 或共模否决。即使 rank = d，也要求观测噪声与激励满足持续激励条件。系：**共模不是「估个相关系数」能解决的；它给出一个可能为负面的结论——某些步态/机体布局下 PAR 根本不该缩窄。**

**引理 41（相位切换的证书连续性）** 若 (a) 守卫 Γ_{φ′} 在切换前已成立；(b) δ_sw ≥ max_i(模块延迟_i) + 监控周期；(c) 切换窗口内采用保守并集 u=max(u_φ,u_{φ′})、D=D_φ∩D_{φ′}；(d) Φ_safe 可用且回退动作有 viability 证书；则 J_EXEC 在 φ ⇝ φ′ 处无未记录缝隙。**注意**：这是「无静默缝隙」，不是「无缝隙」——δ_sw 内保守并集必然损失精度，且若 D 交为空则显式进入安全相位。系：**相位切换的代价被显式计入证书，而非被平均掉。**

**引理 42（负载下热替换保持）** 若 ADMIT(G ⇒ G′) 通过（契约等价、RTA 可调度、时钟界、CCM 门控、连续性、安全回退），则 G′ 上的 J_EXEC 保持 R73 引理 35 的全部性质，并额外保持时序与相位连续性。归纳于超周期内的相位序列。系：**「同契约」升级为「同契约且可执行」——热替换定理从静态代数进入运行时。**

**引理 43（步态冻结的安全性）** 若 Φ_safe ⊆ viability 核 K，且从当前相位到 Φ_safe 的迁移轨迹在 K 内（回退证书），则步态冻结/回退不引入新的跌倒风险；反之若回退轨迹离开 K，则冻结本身不安全，必须选择最近的 K 内安全相位或维持当前步态到下一步可行落足。系：**「停下来」不是默认安全动作——这也是 R73 简单 stub 语义在四足上失效的地方。**

**定理 30（CADENCE 严格包含 R73）** 在 A114–A119 下：取单相位 |Φ|=1（静态站立）、u_time≡0、ζ≡0（无共模）、MCF 为恒等传输，则 CADENCE-RAS 逐指令退化为 MODGAUGE-RAS；再退化到 R72/R71/R68。**安全单调不减，效率只在契约满足时获益。**

**定理 31（J_EXEC 有效性 ⇒ 运行时安全）** 若 Valid(J_EXEC, H) 且 A114–A119 成立，则超周期 H 内物理风险 ≤ ε_mod，其中 ε_mod 相对（具身测量模型 × 相位模型 × 共模可辨识边界 × 时序分析）。**证明重量落在：相位模型是否覆盖真实接触模式、共模是否可辨识、WCET/RTA 是否在真实中间件负载下成立。**

**定理 32（相位级失效零级联）** 任一模块在相位 φ 失效 ⇒ stub^φ；由引理 41/43，系统退化为少模态、可能冻结的版本，其他相位的证书不受污染；相位迁移的守卫阻止失效传播到不相关相位。系：**失效的传染路径 = 该模态在该相位的缺失 + 安全回退，二者均显式可审计。**

**定理 33（时序违约不可静默）** 由 TEC 的否决语义与 J_EXEC 的逐 tick 检查：任何 deadline miss/QoS 降级/时钟越界/丢包都必然产生 veto 或 stub，且被写入 J_EXEC 轨迹；不存在「迟到证据被当作准时证据静默融合」的路径。系：**中间件从「可能的故障源」变为「安全论证的执行点」。**

## 6. 本轮最大风险

**一句话**：CADENCE 把安全证明的支点从 R73 的「契约表达力」进一步移到「**相位模型的完备性 × 共模可辨识性 × 中间件时序分析的可信度**」这三根柱子上——而四足机器人最危险的时刻恰恰是它的相位模型失效的时刻（绊倒、滑移、非结构地形上的恢复瞬态，系统进入 φ_unknown），中间件最不可信的负载恰恰是故障/攻击下的过载瞬态，共模最不可辨识的场景恰恰是多传感器同时被同一冲击饱和；于是可能出现这样的结果：**平稳步态下证书完备且漂亮，真正要防的失稳瞬态里系统只能按定义保守冻结，而「在半空中冻结」本身就可能直接导致跌倒**——即形式化在最需要它的地方给不出可用结论。

次级风险与缓解：
1. **相位缝合缝（seam）与监控盲窗** → δ_sw 覆盖最坏模块延迟；切换窗口用保守并集；监控器双缓冲 + 事件时间戳；seam 显式入证书，禁止静默。
2. **共模不可辨识（rank 不足）** → 显式共模否决 + 禁用 PAR 缩窄；引入外部动捕/已知几何作第三方基准；在机体设计阶段优化观测者布局。
3. **WCET/RTA 在真实 DDS 上过于乐观** → 测量驱动的最坏情况膨胀 + CPU 亲和/内存锁定/隔离域；关键环使用时间触发或认证 RTOS 后备；E396 以实测反标定。
4. **冻结不安全性（在半空中停）** → 仅允许迁移到 viability 核内的 Φ_safe；否则维持当前步态至下一步可行落足；引理 43 的迁移证书预计算。
5. **过度冻结导致活性丧失** → 相位感知的降级运动模式（degraded-but-moving）+ 冻结频率/任务完成率 Pareto 预注册（E411）。
6. **中间件攻击面扩大**（DDS 域、时钟、QoS）→ 签名 Manifest + QoS 锁定 + 外部单调时钟 + 域隔离；AIC-MID 纳入威胁模型。
7. **仿真到真实的接触/地形差距** → 硬件在环 + 地形对抗集 + 密封保持集 SEAL-MB + 三方复现；主张只认预注册指标。
8. **C4 与 C3 不可隔离（主张膨胀）** → 定义 398 预注册降级条件：若 MB4 收益可完全由 MB3 静态热替换解释，则 C4 折叠进 C3，避免「为创新而创新」。

## 2. 形式化定义（要点版）

**定义 383（总览与六不变式）** 相位完备 / 相位连续性（无静默 seam）/ 时序闭合（u_time 进预算，违约即否决）/ 共模可辨识或保守 / 可生存性安全（viability）/ 严格退化链扩展（相位 stub → 安全相位 → R68）。

**定义 384（PEC）** EC_φ = (EC, φ, Γ, δ_sw, cont)。同契约替换升级为「∀φ 逐字段相同且 Γ/δ_sw/cont 相容」。

**定义 385–386（相位图族与步态）** MReg^Φ 为相位图族；接触图 CT(φ) 是物理索引；Φ_safe 为可安全进入的相位集；未建模接触模式归 φ_unknown，一律保守处理。

**定义 387（PLM）** 六分量本体计量 + 接触似然 + 腿式里程计；`anchor_ok = p(c)>τ_c ∧ u_slip<τ_s ∧ u_sink<τ_k`；腿式里程计失效时不得作深度自标定锚点（防跨模态自举）。

**定义 388（CCM）** u_i² = u_i,indep² + ‖K_i(φ)ζ‖²；独立观测者 O 与证据模块定义域不相交；门控 `rank(K)≥dim(ζ) ∧ ρ_cm<ρ_max`，否则禁 PAR 缩窄 + 共模否决。

**定义 389（TEC）** 周期/截止期/优先级/隔离/时钟域/QoS/迟到分布；u_time 四项；deadline miss、QoS 降级、时钟偏斜超界、丢包 ⇒ 非补偿否决。

**定义 390（MCF）** Compile: EC_φ→Manifest；发现→配置→激活→热替换→销毁；租约过期即 stub；输出 TEC 证据流。

**定义 391（PCA）** SER/PAR/VETO + ⇝ + ∘_t + ADMIT。⇝：u=max(u_A,u_B)、D=D_A∩D_B、交空即 Φ_safe；∘_t：D_e2e=ΣD−Σslack，u_time 不可抵消，deadline-monotonic + 优先级天花板；PAR 额外要求同钟域/有界偏斜且 CCM 门控通过。

**定义 392（J_EXEC）** 超周期轨迹证书；Valid ⇔ ∀t（J_MOD 有效 ∧ TEC 未违约 ∧ CCM 未越界 ∧ h≥0 ∧ seam 已闭合或显式进入 Φ_safe）。J_MOD 为单相位特例。

**定义 393（viability）** h(x)≥0 为可生存，跌倒为吸收态；风险随 h 减小而收紧（允许误差与反作用预算）。

**定义 394（GVOP）** 动作 =（落点，机身速度，视角）；目标含 Progress、E[u^next]、FallRisk、Σc_reflex、SlackPenalty；约束 REG/D_φ/TEC/V_safe/C_safe；相位内可解析，切换处保守。

**定义 395（相位级 stub / 安全回退）** stub^φ 继承 stub 语义；φ∉Φ_safe 时回退到最近认证安全相位；回退需 viability 证书；φ_unknown ⇒ stub + 冻结。

**定义 396（AIC-MID）** QoS 降级/发现投毒/重放/时钟操纵/topic 冒充/执行器饥饿/生命周期劫持；防线：签名 Manifest + QoS 锁 + 外部单调时钟 + 域隔离 + 速率限制 + 单源不定案。

**定义 397（结构上限）** |Φ|≤6、|V_M(φ)|≤24、组合深度≤4、相位迁移≤|Φ|²、超周期监控点有界；全部为相位图族可审计性质。

**定义 398（CPB†：C4）** C4（可执行时空契约）← (PEC,TEC,MCF,J_EXEC,PCA-⇝/∘_t) ← MB4 ← AB4（相位索引+时序证据 vs 静态单相位 vs 无时序审计）← (seam_gap, deadline_miss_detect, phase_switch_recovery, false_freeze_rate)。预注册降级条件：若收益可由 MB3 静态热替换完全解释，C4 折叠进 C3。

**定义 399（MB4/MB5）** MB4 相位计量（步态×地形×负载 + 切换脚本）；MB5 中间件时序与负载（延迟/丢包/QoS 降级/时钟偏斜 + 负载下热替换）；均 ≤3h、预注册、固定种子、密封保持集 SEAL-MB。

**定义 400（ADMIT）** 契约等价 ∧ RTA 可调度 ∧ 时钟同步界 ∧ CCM 门控 ∧ 相位连续性 ∧ 安全相位回退可用；任一失败即拒绝，保留旧图。

```python
# IP-302 PEC / 相位图族
@dataclass(frozen=True)
class PhaseContract:
    ec: EvidenceContract; phi: str
    guard: Callable[[State], bool]         # Γ：相位进入守卫
    switch_window_s: float                 # δ_sw ≥ 最慢模块延迟 + 监控周期
    continuity: Callable                   # cont：相邻相位拼接义务

class PhaseRegistry:
    def active_graph(self, phi): return self.graphs[phi]      # MReg^(φ)
    def switch(self, old, new, t):
        if not self.guards[new](t): return 'HOLD'
        u = self.conservative_union(old, new)                 # u=max, D=∩, 禁缩窄
        if u.domain_empty: return self.fallback_safe_phase()  # 定义 395
        self.seam_log.append((old, new, u, t)); return u

# IP-303 PLM：本体运动计量
class ProprioceptiveLegMetrology:
    def update(self, q, qdot, tau, f_foot, imu, phi):
        u = (self.slip(qdot,f_foot,phi), self.sink(f_foot,phi),
             self.compliance(f_foot), self.impact(imu,phi),
             self.encoder(q), self.kinematics(q))
        p_c = self.contact_likelihood(f_foot, qdot, phi)
        anchor_ok = p_c > TAU_C and u[0] < TAU_SLIP and u[1] < TAU_SINK
        return LegEvidence(u=norm6(u), breakdown=u, p_contact=p_c,
                           anchor_ok=anchor_ok, dx=self.leg_odom(q,qdot), phi=phi)

# IP-304 CCM：共模可辨识门控
class CommonModeMetrology:
    def update(self, observers, phi):
        zeta = self.identify(observers)                       # 振动/温度/光照/电源
        K = self.coupling[phi]; rank_ok = matrix_rank(K) >= len(zeta)
        rho = self.estimate_corr(phi); gate_ok = rank_ok and rho < RHO_CM_MAX
        return CCMEvidence(zeta, K, rho, gate_ok,
                           veto=set() if gate_ok else {'CM_UNIDENTIFIABLE'})

# IP-305 MCF：清单编译 + 时序监控
def compile_manifest(ec):
    t = ec.tec
    return Manifest(qos=deadline_qos(t.D, t.T),
                    executor=choose_executor(t.iso),
                    priority=deadline_monotonic(t.D, t.p),
                    isolation=pin_and_lock(t.iso), clock=t.kappa,
                    lease_s=2*t.D, probes=['lateness','jitter','drop','skew'])
def timing_monitor(module, t):
    late = module.completion - module.deadline
    u_time = math.sqrt(late**2 + t.jitter**2 + t.skew**2 + t.drop**2)
    return TimingEvidence(u_time, veto={'DEADLINE_MISS'} if late > 0 or t.qos_violated else set())

# IP-306 PCA：时空组合
def compose_st(a, b, op, audit, ccm, t):
    if op == 'TSER':
        if not rta_schedulable(a.tec, b.tec): return veto('RTA_FAIL')
        return Ev(u=mono_sum(a.u,b.u,a.u_time,b.u_time), D=a.D & b.D,
                  veto=a.veto|b.veto, d_e2e=a.tec.D+b.tec.D)
    if op == 'PAR':
        if not ccm.gate_ok: return Ev(u=max(a.u,b.u), veto=ccm.veto|{'PAR_BLOCKED_CM'})
        r = residual(a,b)
        if audit.covers(r) and abs(audit.corr(a,b)) < RHO_MAX and same_clock(a,b,t):
            return fuse(a,b)
        return Ev(u=max(a.u,b.u), veto={'PAR_AUDIT_FAIL'})
    if op == 'SWITCH':
        return Ev(u=max(a.u,b.u), D=a.D & b.D, seam=(a.phi,b.phi), veto=a.veto|b.veto)
    return veto_or_inherit(a, b, op)

# IP-307 J_EXEC：运行时证书
def jexec_tick(phi, j_mod, tec, ccm, x):
    ok = j_mod.valid and not tec.veto and ccm.gate_ok and h(x) >= 0
    return 'VALID' if ok else 'STUB_AND_SAFE_PHASE'

# IP-308 GVOP：步态-视角-可生存性规划
def gvop(b_t, mods, phi, risk):
    def J(a):
        return (task_progress(b_t,a) - risk.lam_u*conservative_next_u(mods,a,phi)
                - risk.lam_v*fall_risk(a) - sum(m.reflex_estimate(a) for m in mods)
                - risk.lam_t*deadline_penalty(a))
    return optimize_under_reg_contract(J, horizon=0.5, viability=K)

# IP-309 ADMIT / 安全回退
def admit_and_swap(old, new, phi):
    return 'SWAP' if (contract_equiv(old,new) and rta_schedulable(new)
                      and clock_bound_ok(new) and ccm.gate_ok
                      and continuity_ok(old,new,phi) and safe_phase_available(phi)) else 'REJECT'
def on_phase_failure(phi):
    if phi in PHI_SAFE: return stub(phi)
    target = nearest_safe_phase(phi)
    assert viability_certified(phi, target)               # 引理 43
    return transition_to(target)

# IP-301† CADENCE 主闭环
def CADENCE_round(M, obs, audio, tac_frame, depth_img, q, f_foot, imu):
    phi = M.gait.phase_estimate()                          # 含 φ_unknown
    d_ev = M.dpe.update(depth_img, rgb, M.cam_state, M.motion, M.peers, phi)
    l_ev = M.plm.update(q, qdot, tau, f_foot, imu, phi)    # IP-303
    c_ev = M.ccm.update(M.observers, phi)                  # IP-304
    if not d_ev.valid: d_ev = stub(M.dpe, phi)
    if not l_ev.anchor_ok: l_ev.anchor = None              # 防跨模态自举
    if M.clock.due_metric():
        mreg = M.preg.active_graph(phi)
        b_t = M.bse.step_full(..., d_ev=d_ev, l_ev=l_ev, c_ev=c_ev)
        M.gvop = gvop(b_t, M.mods, phi, M.risk_params)     # IP-308
        g = M.ervoi.choose(b_t, ..., M.budget)
        if g and c_ev.gate_ok and not l_ev.veto:
            s2, _ = sigmareflex_step(M.mods, g, M.state, M.budget)
            if s2 is not None: M.last_g, M.state = g, s2
        M.jexec = jexec_tick(phi, J_MOD(mreg), M.tmon.latest(), c_ev, M.state)
        if M.jexec != 'VALID': phi = on_phase_failure(phi)
        M.preg.switch(phi, M.gait.next_phase(), M.t)
    snap = M.snapshot.read_latest()
    lam = embodied_risk_scale(..., max(snap.t_ev.u, snap.d_ev.u, snap.u_time, snap.u_cm))
    k = M.c_ras_wm.certified_prefix(M.ach.propose_ctrl(..., pvop_bias=snap.gvop), lam)
    M.ctrl_out.publish(k, lam)
    return k, lam, M.jexec
```

## 4. 推导

**引理 38（PLM 相位条件正交性）** 给定 (φ, terrain, c_f, 落足时刻) 下六分量由独立物理机制产生，条件近似不相关；遗漏任一 ⇒ 系统性低估。系：**接触条件从手扩展到全身接触调度。**

**引理 39（时序预算闭合与截止期传播）** COMP-TSER 链在 WCET≤D、deadline-monotonic + 优先级天花板下，R=Σ(C_i+干扰_i)≤ΣD_i−Σslack ⇔ RTA 通过；u_time 抖动非负不可抵消 ⇒ u_out,time ≥ max_i u_time,i。系：**时间上没有免费午餐，与引理 34 空间单调性同构。**

**引理 40（共模可辨识性边界）** 若 rank([K_i(φ)])<dim(ζ)，个体/共模误差不可分离，任何 PAR 缩窄可能把共模相关误判为独立性；唯一可证界是保守并集或共模否决。即使满秩也需持续激励。系：**共模不是「估个相关系数」能解决的；某些机体布局下 PAR 根本不该缩窄。**

**引理 41（相位切换证书连续性）** 守卫成立 + δ_sw≥max延迟+监控周期 + 切换窗口保守并集 + Φ_safe 可用 ⇒ J_EXEC 无未记录缝隙。**这是「无静默缝隙」而非「无缝隙」**；保守并集损失精度，域交空则显式进入安全相位。

**引理 42（负载下热替换保持）** ADMIT 通过 ⇒ G′ 上 J_EXEC 保持 R73 引理 35 全部性质，并保持时序与相位连续性。系：**「同契约」升级为「同契约且可执行」。**

**引理 43（步态冻结安全性）** Φ_safe⊆K 且迁移轨迹在 K 内 ⇒ 冻结/回退不引入新跌倒风险；若回退离开 K，则冻结本身不安全。系：**「停下来」不是默认安全动作——R73 简单 stub 语义在四足上失效。**

**定理 30（CADENCE 严格包含 R73）** 取单相位、u_time≡0、ζ≡0、MCF 恒等传输 ⇒ 逐指令退化为 MODGAUGE-RAS，再退化 R72/R71/R68。安全单调不减。

**定理 31（J_EXEC ⇒ 运行时安全）** Valid(J_EXEC,H) ∧ A114–A119 ⇒ 物理风险 ≤ ε_mod（相对测量模型 × 相位模型 × 共模可辨识边界 × 时序分析）。**证明重量落在相位模型完备性、共模可辨识、WCET/RTA 真实可信度。**

**定理 32（相位级失效零级联）** 单模块在 φ 失效 ⇒ stub^φ；由引理 41/43 退化为少模态/冻结版本，其他相位证书不受污染；守卫阻止跨相位传播。

**定理 33（时序违约不可静默）** TEC 否决语义 + J_EXEC 逐 tick 检查 ⇒ 任何 deadline miss/QoS 降级/时钟越界/丢包必然 veto/stub 并入轨迹；不存在迟到证据被当准时证据静默融合的路径。系：**中间件从故障源变为安全论证的执行点。**

## 7. 本轮最大风险

**一句话**：CADENCE 把安全证明的支点从 R73 的「契约表达力」移到「**相位模型完备性 × 共模可辨识性 × 中间件时序分析可信度**」三根柱子上——而四足最危险的时刻恰是相位模型失效的失稳瞬态（φ_unknown），中间件最不可信的负载恰是故障/攻击过载瞬态，共模最不可辨识的场景恰是多传感器被同一冲击同时饱和；于是可能出现「平稳步态下证书完备漂亮，真正要防的失稳瞬态里只能保守冻结，而在半空中冻结本身就会导致跌倒」——**形式化在最需要它的地方给不出可用结论。**

次级风险与缓解：
1. **相位缝合缝/监控盲窗** → δ_sw 覆盖最坏延迟；切换窗口保守并集；双缓冲 + 事件时间戳；seam 显式入证书。
2. **共模 rank 不足** → 共模否决 + 禁 PAR 缩窄；外部动捕/已知几何第三方基准；机体观测者布局优化。
3. **WCET/RTA 在真实 DDS 上过于乐观** → 测量驱动 Worst-case 膨胀 + CPU 亲和/内存锁定/隔离域；关键环时间触发/认证 RTOS 后备；E396 实测反标定。
4. **冻结不安全性** → 仅迁移到 K 内 Φ_safe；否则维持当前步态至下一步可行落足；引理 43 迁移证书预计算。
5. **过度冻结丧失活性** → 相位感知 degraded-but-moving 模式 + 冻结频率/完成率 Pareto（E411）。
6. **中间件攻击面扩大** → 签名 Manifest + QoS 锁 + 外部单调时钟 + 域隔离；AIC-MID 入威胁模型。
7. **仿真到真实接触/地形差距** → 硬件在环 + 地形对抗集 + SEAL-MB + 三方复现；只认预注册指标。
8. **C4 与 C3 不可隔离（主张膨胀）** → 定义 398 预注册降级条件，收益可由 MB3 解释则折叠 C4。
