# 第 56 轮（承接第 55 轮 v32 GroundEdge-GenSim++++；新灵感循环第 2 轮；本轮灵感：「预训练」×「抓取」）

> 第 55 轮把静态双证书升级为带有效期、可辨识域与激励证据的“活证书”。本轮引入两个此前被隔离的变量：**大规模预训练给出的先验** 与 **抓取这一接触密集、准静态的典型任务**。核心矛盾：**H24** 抓取执行多为低速/准静态，恰好落在第 55 轮的不可辨识盲区 `B_t`；在线证书在最需要它时不可更新，系统被迫依赖未在目标本体上校准的预训练先验，形成“盲区先验越权”。**H25** 预训练模型学到的是“外观/语义 → 抓取姿态”的相关性，不是力封闭/抗滑移的物理保证；把 proposal 当 certificate 会产生“自信但物理不可行”的抓取。**H26** 预训练覆盖是长尾偏斜的，条件校准误差随分布漂移而变，单一全局阈值不可靠。

## 0. 直觉与动机

**灵感 1（预训练 = 提案先验，不是证书）**
直觉：预训练模型首先是一个**提案分布** `π_θ(g|o)`——它能在毫秒级给出大量候选抓取，极大提升“找到可行解”的召回，但它内部的置信分数 `c_θ` 是训练分布上的统计量，不是目标本体上的物理保证。正确的分工是 **生成-验证不对称**：预训练负责“广撒网式提案”，物理与证书负责“严格判定”。一句话：**pretraining proposes, physics certifies**。

**灵感 2（抓取落在盲区 → 用静态物理证书替代在线证书）**
直觉：抓取常常是低速、准静态、接触保持，回归矩阵激励极弱，`id({a},W) < μ0`，第 55 轮的在线活证书在此**冻结**。但力封闭/滑移裕度是**静态几何 + 摩擦物理**，不依赖执行器参数的可辨识性。于是盲区里可以“换裁判”：在线证书退场，静态力封闭证书上场；预训练只提供候选。这样既不违反第 55 轮“盲区不得自信外推”，又不至于在盲区完全无法部署。

**灵感 3（本体落地：规范抓取到目标夹爪的有损映射）**
直觉：预训练抓取多在规范手/规范物体坐标系，落到二指、三指或灵巧手需要重定向。重定向可能碰奇异、超出开合、接触点漂移，产生落地残差 `δ_g`。因此证书的第一道门不是“像不像好抓取”，而是 **是否可落地、落地后接触集是否仍成立**。不落地就认证，等于借别人的手型为自家人背书。

**灵感 4（力封闭 + 滑移机会约束：把软分数换成硬证书）**
直觉：抓取的成败由摩擦锥决定。给定接触集 `C`、法向 `n_i`、摩擦系数区间 `[μ_lo, μ_hi]` 与外部力旋量界 `w_bound`，若存在位于 `FC(μ_lo)` 内的内部力平衡 `w_ext` 且最小裕度 `λ_min ≥ λ0`，则对区间内任意摩擦都稳健力封闭。再叠加滑移机会约束 `P(μ < μ_req) ≤ p_slip`。预训练的 `0.93 成功率`不能替代 `λ_min` 与 `p_slip`，但可以作为提案排序的先验。

**灵感 5（先验可信域 + 防重复计数融合）**
直觉：预训练的覆盖是长尾偏斜的，且目标分布与预训练分布不同（新本体、新材质、新物体）。因此必须定义 **先验可信域** `R_π`：局部校准误差小、支撑密度高、OOD 分数低。域内可用先验置信；域外只当提案，不据此部署。把先验与在线活证书融合时，二者数据相关，不能当独立证据简单相乘；用有效样本量 `n_eff` 做伪计数融合，并在检测到分布漂移时把先验权重归零，避免“预训练 + 自训练”的确认偏误闭环。

**灵感 6（覆盖与可靠性解耦 → 设计原则）**
直觉：抓取失败有两类根因：**没提出可行解（覆盖失败）** 与 **认证放过了不可行解（可靠性失败）**。预训练只应改善前者，物理证书独占后者。于是总成功率可写成两段之积，风险可归因、可分配、可独立加固：预训练侧做召回与长尾补全，物理侧做力封闭与滑移，在线侧做执行器漂移。这比“一个大模型端到端”更可审计。

## 1. 形式化定义（增量：定义 127–132）

**定义 127（预训练抓取先验与提案分布）**
预训练语料 `D_pre`，模型 `π_θ(g | o, c)` 输出规范坐标系下的抓取假设 `g`；内部置信 `c_θ(g,o) ∈ [0,1]`；支撑/密度估计 `s_θ(g,o)`。提案集
```
G_τ(o) = { g : π_θ(g|o) ≥ τ }
```
`π_θ` 视为**提案先验**，不作为部署证书。

**定义 128（本体落地映射与落地残差）**
落地映射 `G_{E,o} : g ↦ (a_e, C)`，把规范抓取 `g` 映射为目标本体 `E` 的动作 `a_e ∈ A_e` 与接触集 `C`。落地残差
```
δ_g = d_A(a_e, G_{E,o}(g)) + d_C(C, C_g)
```
且要求运动学可行 `a_e ∈ A_e^feas`。`δ_g ≤ Θ_g` 才允许进入认证。

**定义 129（鲁棒力封闭与滑移裕度证书）**
接触集 `C = {(p_i,n_i)}`，摩擦系数 `μ_i ∈ [μ_i^lo, μ_i^hi]`，外部力旋量界 `‖w_ext‖ ≤ w_bound`。抓取**鲁棒力封闭**且仅当存在内部力 `f_i ∈ FC(μ_i^lo)` 使得
```
G f = -w_ext,   λ_min(f) ≥ λ0
```
其中 `G` 为抓取映射，`λ_min` 为摩擦锥裕度。滑移机会约束
```
p_slip = P( μ < μ_req(w_bound) ) ≤ p_slip_max
```
证书 `C_fc = (C, λ_min, μ_req, p_slip, w_bound, evidence)`。**关键**：用 `μ_lo` 求内部力，保证对 `[μ_lo,μ_hi]` 内任意真实摩擦稳健。

**定义 130（先验可信域）**
```
R_π(ε, s0, o0) = { (o,g) : ECE_loc(g,o) ≤ ε ∧ s_θ(g,o) ≥ s0 ∧ OOD(g,o) ≤ o0 }
```
域内先验置信可参与部署；域外状态为 `proposal_only`（可探索、可认证，但不得凭先验置信部署）。`ECE_loc` 为条件校准误差，`OOD` 为分布外分数。

**定义 131（先验锚定活证书融合）**
先验伪计数 `n_π` 与在线证据量 `n_t` 相关，定义有效样本量
```
n_eff = n_t / (1 + ρ_corr · n_t / max(n_π,1))
w_π = n_π / (n_π + n_eff)
```
融合证书 `C_t^π = fuse(C_t, C_fc, w_π, conf)`，其中 `conf = w_π·c_cal + (1-w_π)·conf_online`。**硬约束**：`C_fc` 的可靠性是门（gate），不被加权平均稀释；`w_π` 只影响提案排序与置信估计。若数据集漂移监控 `shift > SHIFT_MAX`，令 `w_π = 0`。预训练主干 `π_θ` 冻结，只允许用物理证据校准 `c_cal` 头，禁止用自标注成功样本微调，以防确认偏误闭环。

**定义 132（抓取部署证书与盲区策略）**
```
G_cert = (C_fc, R_π_status, C_t^(π), δ_g, blind_zone_policy)
```
部署条件：`C_fc = ok ∧ δ_g ≤ Θ_g ∧ (R_π = trusted ∨ 物理证书已足以独立担保) ∧ blind_zone_policy ≠ blocked`。盲区策略承接第 55 轮：
- `open_loop_hold`：在不可辨识区保持开环/力控保持，不外推在线证书；
- `conservative_envelope`：退化为保守包络抓取（包络抓、低加速度、慢速闭合）。
不满足则回退到保守抓取或触发探索，而不是“凭先验硬抓”。

## 2. 关键算法 伪代码

### IP-127 PGP（Pretrained Grasp Prior）

```python
def propose_and_score(pi_theta, o, tau, support_model, calib_head):
    props = []
    for g, p, c_theta in pi_theta(o):
        if p < tau:
            continue
        s = support_model(o, g)             # 预训练支撑/密度
        c_cal = calib_head.calibrate(c_theta, o)  # 条件校准（目标域）
        props.append((g, p, c_cal, s))
    return props
```

### IP-128 GEP（Grasp Embodiment Projection）

```python
def ground_grasp(g, E, o, sim):
    a_e, C = retarget(g, E)                 # 规范抓取 -> 目标夹爪动作 + 接触集
    if not sim.kinematically_feasible(a_e, E, o):
        return ('infeasible', a_e)
    delta_g = residual(g, a_e, E, o)
    if delta_g > THETA_G:
        return ('grounding_drift', a_e, delta_g)
    return ('ok', a_e, C, delta_g)
```

### IP-129 FCC（Force-Closure Certificate）

```python
def force_closure_cert(C, w_bound, mu_lo, mu_hi, lam0, p_slip_max):
    f, lam = solve_force_closure(C, w_bound, mu_lo)   # 最坏摩擦求内部力
    if f is None or lam < lam0:
        return ('reject', 'no_force_closure', lam)
    mu_req = required_friction(C, w_bound)
    p_slip = posterior_slip_prob(mu_req, mu_lo, mu_hi)
    if p_slip > p_slip_max:
        return ('reject', 'slip_risk', p_slip)
    return ('ok', ForceClosureCert(C, lam, mu_req, p_slip, w_bound))
```

### IP-130 PTR（Prior Trust Region）

```python
def prior_trust(g, o, c_cal, s, ece_loc, ood, eps, s0, o0):
    if s < s0:
        return ('proposal_only', 'low_support')
    if ood > o0:
        return ('proposal_only', 'ood')
    if ece_loc > eps:
        return ('proposal_only', 'miscalibrated')
    return ('trusted', c_cal)
```

### IP-131 PAC（Prior-Anchored Certificate Fusion）

```python
def prior_anchored_fusion(cert_online, C_fc, prior, n_pi, n_t, rho_corr):
    n_eff = n_t / (1 + rho_corr * n_t / max(n_pi, 1))
    w_pi = n_pi / (n_pi + n_eff)
    if dataset_shift_monitor(prior, cert_online) > SHIFT_MAX:
        w_pi = 0.0                       # 漂移 -> 先验归零，物理证书仍硬门
    conf = w_pi * prior.c_cal + (1 - w_pi) * cert_online.conf
    return fuse(cert_online, C_fc, w_pi, conf)   # C_fc 是 gate，不是可加权项
```

### IP-132 GDC（Grasp Deployment Certificate）

```python
def grasp_deploy_gate(o, E, props, certs, mu_lo, mu_hi, lam0, p_slip_max):
    feasible = []
    for g, p, c_cal, s in props:
        st, a_e, C, dg = ground_grasp(g, E, o, sim)
        if st != 'ok':
            continue
        fc = force_closure_cert(C, w_bound(o), mu_lo, mu_hi, lam0, p_slip_max)
        if fc[0] != 'ok':
            continue
        trust = prior_trust(g, o, c_cal, s, ece_loc(g, o),
                            ood(g, o), EPS_CAL, S0, O0)
        act = blind_zone_policy(certs, a_e)      # 承接 IP-125 HOC
        if act == 'blocked':
            continue
        feasible.append((g, a_e, fc[1], trust, act))
    if not feasible:
        return ('fallback', conservative_envelope_grasp(o, E))  # 包络/慢速
    return ('ok', max(feasible, key=margin_then_trust))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| PGP | O(|\mathcal{G}_τ|·d) 推理 | O(|\mathcal{G}_τ|) | 提案召回、校准头独立 |
| GEP | O(|\mathcal{G}_τ|·|C|) | O(|C|) | 重定向可行、残差可测 |
| FCC | O(|\mathcal{G}_τ|·LP(|C|)) | O(|C|) | μ_lo 最坏稳健、滑移界 sound |
| PTR | O(|\mathcal{G}_τ|) | O(1) | 校准/OOD 阈值保守 |
| PAC | O(p²+d) | O(p+d) | n_eff 防重复计数、漂移归零 |
| GDC | O(|\mathcal{G}_τ|·(LP+|C|)) | O(|\mathcal{G}_τ|) | 物理门不被先验稀释 |

**正确性定理（Propose–Ground–Certify Soundness）**
假设第 55 轮 (A29)–(A33) 成立，且新增：
**(A34)** 目标分布上提案召回 `P(E_prop) ≥ r0(R_π)`；
**(A35)** 力封闭证书对 `μ∈[μ_lo,μ_hi]` 与 `‖w_ext‖≤w_bound` sound；
**(A36)** 先验可信域内 `ECE_loc ≤ ε_cal`；
**(A37)** 落地残差 `δ_g ≤ Θ_g`，否则被拒。
则对任一部署抓取：
```
P_success ≥ r0(R_π)·(1 - ε_cal - p_slip) - P(δ_g > Θ_g)
```
且**覆盖与可靠性分离**：`p_slip` 只由 (A35) 的物理证书控制，**与预训练先验无关**；预训练只通过 `r0(R_π)` 影响上限。门控收紧 `R_π` 会降低 `r0` 但降低 `ε_cal`，故最优门控是如下 Pareto 问题的解：
```
max_{R_π}  r0(R_π)·(1 - ε_cal(R_π) - p_slip)
s.t.       p_slip ≤ p_slip_max,  δ_g ≤ Θ_g
```
在盲区 `B_t`，在线证书不可用，但 `C_fc` 不依赖 PE，故部署仍可 sound；此时**禁止**用 `c_θ` 替代 `C_fc`。

## 4. 实验设计 E167–E172

| 实验 | 指标 | 目标 |
|---|---|---|
| E167 先验跨本体校准 | 目标域 ECE / Brier（换夹爪、换手） | ECE ≤ 0.05，较原模型降 ≥ 50% |
| E168 提案-认证分解 | 提案召回 r0 / 认证后滑移率 | r0 ≥ 90%，认证后滑移 ≤ 2% |
| E169 力封闭证书准确性 | 预测 λ_min、p_slip vs 实测滑移 | AUC ≥ 0.95，漏报 ≤ 1% |
| E170 先验可信域门控 | OOD/低支撑检出的 precision/recall | 均 ≥ 90% |
| E171 先验锚定融合 | 纯先验 / 纯在线 / PAC 的样本效率 | 达到同等成功率少 ≥ 40% 在线样本 |
| E172 盲区抓取部署 | 准静态抓取成功率、开环保持冲击 | 成功率 ≥ 92%，冲击下降 ≥ 40% |

**E168 关键设置**：人为混入摩擦被低估的物体与长尾几何，检验“预训练高置信但物理不可行”的抓取是否被 FCC 全部拦下；预期错误只体现为 r0 下降，而非滑移率上升，从而验证覆盖/可靠性解耦。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 先验在目标本体上系统性过自信 | 高 | 条件校准头 + 先验可信域 + OOD 门控 |
| 摩擦系数估计错误导致滑移漏报 | 高 | `μ_lo` 最坏鲁棒 + 区间贝叶斯 + 滑移机会约束 |
| 重定向残差被低估 | 高 | 落地后重新计算接触集 + δ_g 硬预算 |
| 预训练/自训练确认偏误闭环 | 高 | 主干冻结 + 仅物理证据校准 + 漂移归零 |
| 候选多、逐抓取 LP 认证延迟高 | 中 | 分层剪枝 + 凸包预筛 + GPU 批量力封闭 |
| 门控过严导致长尾抓不到 | 中 | 域外回退保守包络/探索，不降物理标准 |

## 6. 本轮最大风险

**一句话**：把预训练降格为“提案先验”、把力封闭证书升格为“唯一可靠性门”，能同时获得广覆盖与物理 soundness，但其成立**同时依赖目标域条件校准的准确、摩擦区间与外部力旋量界估计的保守、以及重定向后接触集的可信**；一旦摩擦被低估或落地残差被漏算，物理证书会在“看似力封闭”的抓取上系统性漏报滑移，而预训练的高置信又会掩盖这一漏报，故必须以 **μ_lo 最坏鲁棒 + δ_g 硬预算 + 先验可信域门控** 三重护栏，宁可少抓（r0 下降），也绝不把“预训练说行”当作“物理上行”。

# 第 56 轮产物 · 创新点清单 v33：GroundEdge-GenSim+++++（PGP×GEP×FCC×PTR×PAC×GDC）

> 承接第 55 轮产物 v32。本轮引入 **预训练先验** 与 **抓取（接触密集、准静态）**，把“提案”与“证书”彻底分层：预训练只负责提升候选召回，物理与证书独占可靠性判定。
> - **PGP（Pretrained Grasp Prior）**：预训练抓取提案分布 + 条件校准 + 支撑/OOD 估计；
> - **GEP（Grasp Embodiment Projection）**：规范抓取到目标本体的有损落地与残差 `δ_g`；
> - **FCC（Force-Closure Certificate）**：对摩擦区间鲁棒的力封闭 + 滑移机会约束证书；
> - **PTR（Prior Trust Region）**：先验可信域，域外只作提案；
> - **PAC（Prior-Anchored Certificate fusion）**：有效样本量 `n_eff` 防重复计数的先验-在线融合；
> - **GDC（Grasp Deployment Certificate）**：整合盲区策略的最终部署门。
>
> IP 编号：IP-127~IP-132（共 6 个新增），升级 IP-121/122/125 以接入先验与抓取盲区。

### IP-128 GEP

```python
def ground_grasp(g, E, o, sim):
    a_e, C = retarget(g, E)                    # 规范抓取 -> 目标夹爪
    if not sim.kinematically_feasible(a_e, E, o):
        return ('infeasible', a_e)
    delta_g = residual(g, a_e, E, o)
    if delta_g > THETA_G:
        return ('grounding_drift', a_e, delta_g)
    return ('ok', a_e, C, delta_g)
```

### IP-129 FCC

```python
def force_closure_cert(C, w_bound, mu_lo, mu_hi, lam0, p_slip_max):
    f, lam = solve_force_closure(C, w_bound, mu_lo)   # 最坏摩擦求内部力
    if f is None or lam < lam0:
        return ('reject', 'no_force_closure', lam)
    mu_req = required_friction(C, w_bound)
    p_slip = posterior_slip_prob(mu_req, mu_lo, mu_hi)
    if p_slip > p_slip_max:
        return ('reject', 'slip_risk', p_slip)
    return ('ok', ForceClosureCert(C, lam, mu_req, p_slip, w_bound))
```

### IP-130 PTR

```python
def prior_trust(g, o, c_cal, s, ece_loc, ood, eps, s0, o0):
    if s < s0:        return ('proposal_only', 'low_support')
    if ood > o0:      return ('proposal_only', 'ood')
    if ece_loc > eps: return ('proposal_only', 'miscalibrated')
    return ('trusted', c_cal)
```

### IP-131 PAC

```python
def prior_anchored_fusion(cert_online, C_fc, prior, n_pi, n_t, rho_corr):
    n_eff = n_t / (1 + rho_corr * n_t / max(n_pi, 1))
    w_pi = n_pi / (n_pi + n_eff)
    if dataset_shift_monitor(prior, cert_online) > SHIFT_MAX:
        w_pi = 0.0
    conf = w_pi * prior.c_cal + (1 - w_pi) * cert_online.conf
    return fuse(cert_online, C_fc, w_pi, conf)   # C_fc 是硬门，不被加权稀释
```

### IP-132 GDC

```python
def grasp_deploy_gate(o, E, props, certs, mu_lo, mu_hi, lam0, p_slip_max):
    feasible = []
    for g, p, c_cal, s in props:
        st, a_e, C, dg = ground_grasp(g, E, o, sim)
        if st != 'ok':
            continue
        fc = force_closure_cert(C, w_bound(o), mu_lo, mu_hi, lam0, p_slip_max)
        if fc[0] != 'ok':
            continue
        trust = prior_trust(g, o, c_cal, s, ece_loc(g, o),
                            ood(g, o), EPS_CAL, S0, O0)
        act = blind_zone_policy(certs, a_e)     # 承接 IP-125 HOC
        if act == 'blocked':
            continue
        feasible.append((g, a_e, fc[1], trust, act))
    if not feasible:
        return ('fallback', conservative_envelope_grasp(o, E))
    return ('ok', max(feasible, key=margin_then_trust))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| PGP | O(|\mathcal{G}_τ|·d) | O(|\mathcal{G}_τ|) | 提案召回、校准头独立 |
| GEP | O(|\mathcal{G}_τ|·|C|) | O(|C|) | 重定向可行、δ_g 可测 |
| FCC | O(|\mathcal{G}_τ|·LP(|C|)) | O(|C|) | μ_lo 稳健、滑移界 sound |
| PTR | O(|\mathcal{G}_τ|) | O(1) | 校准/OOD 阈值保守 |
| PAC | O(p²+d) | O(p+d) | n_eff 防重复计数、漂移归零 |
| GDC | O(|\mathcal{G}_τ|·(LP+|C|)) | O(|\mathcal{G}_τ|) | 物理门不被先验稀释 |

**正确性定理（Propose–Ground–Certify Soundness）**
假设第 55 轮 (A29)–(A33) 成立，新增 **(A34)** 提案召回 `P(E_prop)≥r0(R_π)`；**(A35)** 力封闭证书对 `μ∈[μ_lo,μ_hi]`、`‖w_ext‖≤w_bound` sound；**(A36)** 可信域内 `ECE_loc≤ε_cal`；**(A37)** `δ_g≤Θ_g`。则
```
P_success ≥ r0(R_π)·(1 - ε_cal - p_slip) - P(δ_g > Θ_g)
```
**覆盖-可靠性分离**：`p_slip` 仅由物理证书 (A35) 控制，与预训练无关；预训练只通过 `r0(R_π)` 影响上限。门控优化为
```
max_{R_π} r0(R_π)·(1 - ε_cal(R_π) - p_slip)
s.t.      p_slip ≤ p_slip_max,  δ_g ≤ Θ_g
```
盲区 `B_t` 中在线证书冻结，但 `C_fc` 不依赖 PE，故部署仍 sound；**禁止**用 `c_θ` 替代 `C_fc`。

## 5. 本轮最大风险

**一句话**：把预训练降格为“提案先验”、把力封闭证书升格为“唯一可靠性门”，能同时获得广覆盖与物理 soundness，但其成立**同时依赖目标域条件校准的准确、摩擦区间与外部力旋量界估计的保守、以及重定向后接触集的可信**；一旦摩擦被低估或落地残差被漏算，物理证书会在“看似力封闭”的抓取上系统性漏报滑移，而预训练的高置信又会掩盖这一漏报，故必须以 **μ_lo 最坏鲁棒 + δ_g 硬预算 + 先验可信域门控** 三重护栏，宁可少抓（r0 下降），也绝不把“预训练说行”当作“物理上行”。
