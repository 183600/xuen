# 第 66 轮（承接第 65 轮「VISTA 视觉知情故障归因」IP-214~223；灵感循环第 1 轮；本轮灵感：「大语言模型」×「续航能力」）

> 第 65 轮把「不可辨识」升级成「可归因」，其自述的最大风险同样精准：**归因依赖「故障属于有限假设集、且视觉与几何失效相互独立」两个假设；真实故障常是未知复合故障，透明/镜面/对抗 patch 又让视觉与几何共享同一个分布外失效源，于是 FIR 把未知复合故障强行塞进最近假设、只膨胀错误的球——系统反而因为「已经归因」而更自信地继续执行。** 本轮不再往里加第五个模态，也不再改"谁坏了"，而是换一个被长期忽略的坐标轴：**时间跨度与资源**。第 65 轮问「此刻该信谁」，本轮问「**这套证书本身能撑多久、什么时候必须花代价重新接地、能量耗尽前能不能安全退役**」。核心命题：
>
> **把「每步安全 / 单块安全」升级为「部署寿命内的安全可续航」：大语言模型从任务语义预测未来风险与漂移，充当"预算分配的先验"而非真值；把信任当作会折旧的电池（trust SoC），把重接地当作耗电的充电；用推测式证书（便宜草稿 + 昂贵核验）把核验成本压到"按需"，用退化阶梯保证能量/算力枯竭时仍安全退役。**

## 0. 直觉与动机

**灵感 1（大语言模型 → 慢时间尺度上的语义先验，而不是新的真值）**
直觉：第 64/65 轮的所有证据都在**快时间尺度**（毫秒级残差、块内三阶段）。但部署寿命是**慢时间尺度**（小时、周、月）：任务会重复，环境会缓慢漂移，传感器会老化。人类操作员正是用"语义"在慢尺度上做规划——"接下来这段是重复的分拣，可以省着点；下面要处理未知物体，得认真校准"。大语言模型恰好擅长「把语言目标、场景描述、操作日志」转成这种**分段的风险/新颖度先验**，并给出"语义时段边界"（相当于上下文窗口的切分）。但必须诚实：LLM 会幻觉、会被提示注入、其"风险评估"没有物理保证。所以 LLM **只允许影响"资源怎么分配"，绝不允许影响"什么动作被认证"**——LLM 错了只该浪费电，不该撞坏东西。这是本轮最重要的分工。

**灵感 2（续航能力 → 信任是消耗品，证书会折旧）**
直觉：证书不是一次性获得的永久属性。标定集与当前分布一旦偏离，conformal 覆盖率就悄悄失效；而"重新接地"（重标定、主动探针、重归因、重建世界模型）要花**电和算力**，这些恰恰是续航最紧张时最先被砍掉的东西。于是产生一个隐蔽的死亡螺旋：**为了省电 → 少做重接地 → 证书悄悄过期 → 系统仍按旧证书自信运行 → 直到一次罕见但灾难性的越界**。把"信任"显式建成一个有荷电状态（SoC）的电池：漂移让它放电，重接地给它充电；能量也是电池；两者耦合。续航问题第一次变成**"用有限能量维持证书有效性到任务结束"的随机最优控制问题**，而不是一句"轻量化"。

**灵感 3（大语言模型 × 续航 → 推测式证书，speculative certificate）**
直觉：推测解码（speculative decoding）用小模型草拟、大模型只在分歧处核验，把昂贵计算摊薄。证书也可以这样：日常用**便宜的草稿证书**（缓存的几何、低分辨率世界模型、策略置信度）先判"安全/不安全"；只有当草稿"接近边界"或"语义新颖"时，才动用**昂贵的核验证书**（完整 VISTA 归因 + 主动探针）。LLM 的作用是预测"哪一段草稿会靠得住"，从而提高草稿接受率、进一步省电。核验的接受阈值用 conformal 校准，使"草稿放行的额外风险"有上界——**速度/能量与安全之间第一次有了可审计的前沿，而不是拍脑袋的开关**。

**灵感 4（续航 → 退化阶梯与安全退役）**
直觉：电池不会"突然没电"，而是先热、先降频、再限功率。安全系统也应有一条**能力阶梯**：每一级都自带一个认证过的不变量，能量/算力下降时**有原则地往下降级**（高精度主动感知 → 低功耗反射 → 最小保持姿态 → 受控停机），并且每一级都为"退到下一级或安全退役"预留能量储备。关键不是"永不降级"，而是**降级过程本身被证明安全**——避免第 65 轮"归因错误反而更自信"的翻版："省电成功反而更危险"。

**灵感 5（双时间尺度合流 → LIFELINE：LLM-Informed Lifetime Fault-accountable Inference under eNergy-budget）**
闭环（慢环套快环）：LLM 语义风险预报（LSRF）给出风险/新颖度/时段先验 → 信任-能量资产管理（TAM）估计证书折旧与 SoC → 重接地调度（ERS）按"能量影子价格"决定何时充电 → 推测式证书（SC）在快环内按需核验 → 自适应 conformal（ACI-L）维持终身覆盖 → 终身故障归因（FIR-L）区分"世界漂了 / 标定旧了 / 省电跳过了 / LLM 带偏了" → 退化阶梯（GDF）保证安全退役 → 终身规划（CSP-L）把维护窗口排进任务 → J_life 证书。第 65 轮是**块内的三段时序**，本轮是**跨部署的长时序**：同一套"用不同时间签名分离故障"的思想，从毫秒扩到周月。

**灵感 6（与第 65 轮组件的原位关系）**
- **VPG/VCV/FIR → 增加慢特征**：残差的趋势、变点、自相关进入纵向签名；归因新增 H_drift / H_stale / H_energy / H_llm。
- **CSC → SC（推测式）**：认证前缀的"每块都全量核验"改为"草稿 + 按需核验"，省下的正是重接地的电。
- **RSC-V/WCV-V → WCV-L**：不确定球除几何/力/模型外，增加**漂移膨胀** r_drift(t)（随信任 SoC 下降而增大），而非只在故障后膨胀。
- **CSP-V → CSP-L**：在"寿命"上规划，把 `reground` / `sleep` / `retire` 作为一等元技能，把维护窗口当成任务约束。
- **AIC-V → AIC-L**：干扰集增"慢漂移、传感器老化、热降频、能量饥饿、LLM 提示注入"。
- **J_vista → J_life**：证书增 trust_SoC、energy_ledger、drift_bound、draft_verify_tally、degradation_rung、llm_prior_hash、remaining_safe_horizon。

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（LIFELINE 闭环）**：LIFELINE = (VISTA, TAM, LSRF, SC, ERS, ACI-L, FIR-L, WCV-L, GDF, CSP-L, AIC-L, J_life)。定位：VISTA 的"寿命/能量"升级。不变式：**LLM 先验、漂移估计、重接地调度、终身规划只在语义慢环；快环（毫秒级）只做草稿证书、按需核验、退化阶梯切换与安全退役，零学习写操作。** 并且：**任何动作被派发前必须落在一个已认证的退化阶梯级上；LLM 输出永不直接授权动作。**
- **定义 234（信任-能量资产 TAM）**：设 τ_t∈[0,1] 为证书信任（有效覆盖率的下界裕度），E_t≥0 为剩余能量（J），B_t 为剩余算力预算（FLOPs）。资产状态 s_t=(τ_t,E_t,B_t)。重接地动作 r 花 c_reg(r) 能量把 τ 拉回 τ_0；漂移使 τ 按折旧算子下降。TAM 维护两者与账本 L_t（每次充/放电、核验/草稿的可审计条目）。
- **定义 235（证书折旧与漂移界）**：令 ρ_t = sup_x dP_t/dP_cal 为目标分布与标定分布的似然比上界。由保形预测的非可交换推广，加权 conformal 的实际覆盖率下界为 1−α·ρ_t。漂移使 ρ_t 增长：ρ_{t+Δ}=ρ_t·exp(∫_t^{t+Δ}λ(s)ds)，λ 为局部漂移率；重接地把 ρ 重置为 ρ_0。**信任 τ_t:=1−α·ρ_t 是单调折旧的、可被重接地"充电"的量**。这是本轮全部"续航"论证的物理量。
- **定义 236（LLM 语义风险预报 LSRF）**：L_θ(指令/场景/日志) → (r̂_1..r̂_L 分段风险与新颖度, 时段边界 {b_i}, 漂移率预测 λ̂_i, 不确定度 σ_i, 建议分配 â_i)。输出带 `unverified_prior` 标签。用途仅为**设置分配先验与维护窗口**；经温度标定/分位数校准后用其**上置信界** r̂^UCB=r̂+κσ 做保守决策。校准误差 ECE>ε_ece 或幻觉检测触发即冻结先验、退回均匀保守分配。
- **定义 237（语义时段与信任视界）**：语义时段 seg_i=[b_{i−1},b_i) 是 LLM 预测的风险平稳区。信任视界 H_trust,i=Δ*_i=(1/λ_i)ln(α_target/(α·ρ_0)) 是在该时段内"不重接地仍满足 τ≥1−α_target"的最长时长（类比上下文窗口：证书在这个窗口内可安全"复用"）。Δ*_i=0 表示必须立即重接地。
- **定义 238（推测式证书 SC）**：草稿证书 C_d（缓存几何 + 低分辨率世界模型 + 策略置信度）花 c_d 能量给出 accept/verify；核验证书 C_v（完整 VISTA 归因 + 必要探针）花 c_v。草稿接受域用 conformal 校准使 P(C_v 判不安全 | C_d 接受)≤ε_spec。执行路径：接受则按草稿认证前缀执行；核验则按 C_v 的 k* 执行。期望能量 c̄=c_d+(1−a)c_v，a=P(accept)；相对"总是核验"节省 a(c_v−c_d)。
- **定义 239（能量-覆盖前沿）**：对给定语义时段，定义策略族 {(a, 1−α_eff)}：a 为草稿接受率、1−α_eff 为实际覆盖率下界。前沿由 SC 的接受阈值与 ACI-L 的更新频率共同刻画。目标是在 τ≥1−α_target 约束下最小化 c̄；LLM 只通过提高 a（更好的草稿可信区预测）推动前沿，而不改变其上的安全约束。
- **定义 240（自适应 conformal 终身有效 ACI-L）**：在每个更新时刻按下式调整名义水平 α_{t+1}=α_t+γ(α_target−1[e_t>q_t])（自适应保形推断 ACI），使长期平均覆盖率 ≥1−α_target 在**任意漂移**下成立（无需可交换性）。但更新有代价：更新越稀疏（间隔 Δ），覆盖率偏差可达 O(L_λ·Δ)（L_λ 为漂移率 Lipschitz 常数）。于是"更新频率"直接连到"续航"：这是把统计保证和能量账本焊在一起的关键引理。
- **定义 241（重接地调度 ERS）**：在每个慢决策点选择 a∈{coast, reground, probe, sleep, retire}。决策价值 = 重接地带来的预期风险下降 ΔV_t（用 FIR-L 后验与 WCV-L 的越界概率估计），成本 = 能量 c(a) 乘以能量影子价格 λ*_t。采用阈值/Whittle 指标策略：当且仅当 ΔV_t ≥ λ*_t·c(a) 时执行最优点；λ*_t 随 E_t 逼近储备而单调上升（能量越少，充得越"贵"）。这给出"续航"的显式经济解释。
- **定义 242（终身故障假设 FIR-L）**：ℋ_L=ℋ ∪ {H_drift 世界真漂移, H_stale 标定过期但世界未变, H_energy 省电/降频导致的证据缺失, H_llm LLM 先验带偏分配}。纵向签名 ρ^L=[trend(e_vis), changepoint(e_force), autocorr(e_force), corr(e_res, power/thermal), alloc_semantic_alignment, post_reground_persistence]。H_drift 与 H_stale 用"重接地后残差是否持续"区分；H_energy 用"异常与功耗/温度相关"区分；H_llm 用"分配异常对齐语义边界"区分。归因在慢环，实时环只采集纵向特征。
- **定义 243（退化阶梯 GDF）**：能力级 g=0..R，Cap_g 递减、单位任务能耗 C_g 递减，每级带认证不变量 I_g 且 I_g⇒I_{g+1}（越保守越强）。仅当 τ_t、E_t、B_t 低于级阈值时允许向 g+1 单向下移；每次下移必须在剩余能量下可到达一个安全退役态（受控停机/回撤）。跨级切换由"不变量单调"保证安全，而非靠"别降级"。
- **定义 244（预算感知鲁棒编译 WCV-L）**：在第 65 轮搜索域基础上加漂移约束 B(φ̂,√(r_geo²+r_force²+r_model²+r_drift(t)²))，其中 r_drift(t) 随 τ_t 下降而增大（证书越旧，预留越宽）；编译目标从"最小执行损失"改为"在能量预算内最小期望损失"，对 LLM 分段用风险 UCB 取最坏。交集为空则降一级退化阶梯并置 `budget_conflict=True`。
- **定义 245（终身规划 CSP-L）**：在语义时段图上规划，节点=(任务段, 退化级)，边含能量成本与 τ 演化；`reground`/`sleep`/`retire` 为一等元技能。约束：全程 τ_t≥τ_min（除退役外）、E_t≥E_reserve、每个维护窗口内完成至少一次重接地或在 Δ* 内。软代价增 λ_E·Σ energy + λ_τ·Σ hinge(τ_min−τ_t)。
- **定义 246（LLM 先验守护 PG）**：任何由 LLM 先验参与的决定必须过三道门：(i) 校准门（ECE≤ε_ece 且分布内）；(ii) 上置信界门（用 r̂^UCB 与 λ̂_robust=CVaR_{1−β}(λ̂) 而非点估计）；(iii) 授权门（最终动作落在已认证退化级，LLM 不直接下达动作）。**故 LLM 幻觉只降低效率（接受率 a 下降、重接地变多），不破坏安全界**——除非校准门失效且被对抗者利用。

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（推测式证书的联合界）**：若核验路径风险 ≤α_v、被接受的草稿风险 ≤ε_spec（conformal 校准），则单步期望越界 ≤α_v+a·ε_spec≤α_v+ε_spec；期望能量 c̄=c_d+(1−a)c_v。故**安全界不因推测而破，能量随接受率线性下降**。
- **引理 10（终身覆盖-更新间隔）**：ACI-L 在任意漂移下长期平均覆盖 ≥1−α_target；若重接地间隔为 Δ 且漂移率 Lipschitz 常数 L_λ，则任意时刻覆盖下界 ≥1−α_target−L_λ·Δ−α·(ρ(Δ)−ρ_0)。取 τ_min=1−α_target，可得最大安全间隔 Δ*=(1/λ)ln(α_target/(α ρ_0))。
- **定理 9（续航-安全可行域）**：要在时长 T 内维持 τ≥τ_min 且完成任务，所需能量 E_req(T)≈T·c_exec+(T/Δ*)·c_reg（再加推测节省 a(c_v−c_d) 与退化级节省）。系统可续航 ⇔ E_0≥E_req(T)+E_reserve。ERS 的阈值策略在该约束下渐近最优（Lagrangian/Whittle），且能量影子价格 λ*_t 随 E_t→E_reserve 单调上升——**电量越低越"舍不得"跳过重接地**，从而自动避免死亡螺旋。
- **定理 10（LLM 隔离性）**：在 PG 生效时，LLM 先验只改变分配与接受率 a，不进入任何认证边界。故 LLM 幻觉/提示注入导致的性能损失有界（a 下降、重接地次数上升），而 τ≥τ_min 与 J_life 有效性不依赖 LLM 正确性。失败模式被限制为"更费电/更保守"，而非"更不安全"。
- **定理 11（退化阶梯的跨级安全）**：若每级 I_g 成立且 I_g⇒I_{g+1}，且每次下移保留可安全退役的能量，则任意降级序列保持安全不变量；能量耗尽前系统必已进入可退役态。这直接封堵第 65 轮"归因错误→更自信"的续航版"省电成功→更危险"。
- **实时性**：快环只增草稿证书（缓存查表 <0.1ms）与退化级不变量检查（<0.02ms），核验复用第 65 轮 VISTA 语义流；慢环（LSRF/ERS/CSP-L）全部离线/低频，目标快环 ≤2.6ms。

## 2. 形式化定义（完整版）

**定义 233（LIFELINE 闭环）** LIFELINE 是 VISTA 的"寿命/能量"升级：在 VISTA 的快环（毫秒级残差、块内三阶段、认证前缀）之外，增加一个慢环（语义时段、漂移估计、信任/能量资产、重接地调度、终身规划、退化阶梯）。形式化为 (VISTA, TAM, LSRF, SC, ERS, ACI-L, FIR-L, WCV-L, GDF, CSP-L, AIC-L, PG, J_life)。两条不变式：
(I) **资源不变式**：LLM 先验、漂移估计、重接地调度、终身规划只在慢环；快环只做草稿证书、按需核验、退化级不变量检查和派发，零学习写操作。
(II) **授权不变式**：任何动作被派发前必须落在一个已认证的退化级 g 上（I_g 成立）；LLM 输出永不直接授权或否决动作。**LLM 只能改变"花多少电去核验/接地"，不能改变"什么是被认证的"。**

**定义 234（信任-能量资产 TAM）** 资产状态 s_t=(τ_t,E_t,B_t)，τ_t∈[0,1] 为信任、E_t 为能量（J）、B_t 为算力预算。动作 a∈A_asset 包含 coast（不动）、reground（重标定/重建世界模型）、probe（主动判别）、sleep（低功耗休眠并维持最小保持）、retire（安全停机）。能量动力学
E_{t+1}=E_t−c_exec(a_t,x_t)−c(a_t)（不低于 0；触底即强制 retire），
其中 c_exec 为执行能耗、c(a_t) 为资产动作额外能耗。账本 L_t 记录 (时间, 动作, Δτ, ΔE, 触发理由, 证书哈希)，供 J_life 审计。

**定义 235（证书折旧与漂移界）** 令 ρ_t=sup_x dP_t(x)/dP_cal(x) 为当前分布相对标定分布的似然比上界。保形预测在非可交换下的加权形式给出实际覆盖率下界 1−α·ρ_t（Barber–Candès–Ramdas–Tibshirani 型界）。定义信任
τ_t := 1 − α·ρ_t。
漂移使 ρ 指数增长：ρ_{t+Δ}=ρ_t·exp(∫_t^{t+Δ}λ(s)ds)，λ≥0 为局部漂移率；重接地把 ρ 重置为 ρ_0（标定噪声底），花 c_reg。于是 τ 是**可折旧、可充电**的资产，且**证书有效性第一次成为一个有物理单位（J）的收支问题**。

**定义 236（LLM 语义风险预报 LSRF）** L_θ 接收语言指令、场景描述、近期操作日志，输出
(r̂_1..r̂_L, {b_i}, λ̂_i, σ_i, â_i)，
分别是分段风险/新颖度、语义时段边界、漂移率预测、不确定度、建议分配。输出必须带 `unverified_prior` 标签。工程上做温度/分位数校准后，只使用**上置信界** r̂^UCB=r̂+κσ 与**鲁棒漂移率** λ̂_robust=CVaR_{1−β}(λ̂)，绝不用点估计授权。若校准误差 ECE>ε_ece，或分布外检测（提示注入/异常指令）触发，则冻结先验并退回均匀保守分配。**LSRF 是"预算参谋"，不是"安全裁判"。**

**定义 237（语义时段与信任视界）** 语义时段 seg_i=[b_{i−1},b_i) 是 LLM 预测的风险平稳区。在 seg_i 内，若漂移率为 λ_i，则不重接地仍满足 τ≥1−α_target 的最长时长为
Δ*_i = (1/λ_i)·ln(α_target/(α·ρ_0))，
称为信任视界（类比上下文窗口：证书在该窗口内可被安全复用）。Δ*_i=0（或 α_target≤α ρ_0）表示证书当前已不达标、必须立即重接地。若真实 λ>λ̂_i，则实际视界短于预测视界——这正是 PG 必须用 λ̂_robust 的原因。

**定义 238（推测式证书 SC）** 草稿证书 C_d 以低分辨率/缓存几何/策略置信度花 c_d 能量输出"安全区域 + 认证前缀 k_d"或"需核验"；核验证书 C_v 花 c_v 运行完整 VISTA 归因与必要探针。用 conformal 在离线草稿/核验对 (n_d,n_v) 上校准接受域，使
P(C_v 判不安全 | C_d 接受) ≤ ε_spec。
执行路径：C_d 被接受 → 执行 k_d 步；否则核验 → 执行 k* 步。期望单步能量
ḡ = c_d + (1−a)·c_v，a=P(accept)，
相对"总是核验"节省 a(c_v−c_d)。**草稿只被允许"更快地到达同一安全结论"，不被允许"放宽安全结论"。**

**定义 239（能量-覆盖前沿）** 对每个语义时段定义策略参数 (θ_acc, γ)，θ_acc 为草稿接受阈值、γ 为 ACI-L 步长。实际覆盖率下界 1−α_eff(θ_acc,γ)、单步能量 ḡ(θ_acc)。前沿是该可达集的 Pareto 边界。目标：
min ḡ s.t. 1−α_eff ≥ 1−α_target 且 τ_t≥τ_min。
LSRF 只通过提高草稿接受率 a（预测"哪里草稿靠得住"）推动前沿内移，却不移动安全约束本身——因此**先验的收益是效率，代价若错也只是效率**。

**定义 240（自适应 conformal 终身有效 ACI-L）** 在每个更新时刻 t 观测非一致性分数 e_t 与阈值 q_t，按 ACI 更新
α_{t+1}=α_t + γ(α_target − 1[e_t>q_t])。
在**任意（含对抗）漂移**下，长期平均覆盖 ≥1−α_target，无需可交换性。但更新并非免费：若两次更新间隔为 Δ，且漂移率 λ(s) 为 L_λ-Lipschitz，则任意时刻的覆盖率下界为
1−α_target − L_λ·Δ − α·(ρ(Δ)−ρ_0)。
令其 ≥1−α_target 即得定义 237 的 Δ*。**这条式子把"统计保证"和"续航"焊死：更新越稀，偏差越大。**

**定义 241（重接地调度 ERS）** 在慢决策点，给定 FIR-L 后验、WCV-L 越界估计与 TAM 状态，选择 a∈A_asset 最大化
ΔV_t(a) − λ*_t·c(a)，
其中 ΔV_t(a) 为动作 a 带来的期望越界风险下降（相对 coast），c(a) 为其能量成本，λ*_t 为能量影子价格。λ*_t 由长期资源约束的对偶给出，并随 E_t→E_reserve 单调上升。采用阈值/Whittle 指标近似：执行使上式为正且最大者。直观：**电量越低，λ* 越高，越"舍不得"省掉一次重接地**——从而在结构上避免"省电→过期→更自信"的死亡螺旋。

**定义 242（终身故障假设 FIR-L）** ℋ_L=ℋ∪{H_drift, H_stale, H_energy, H_llm}：
- H_drift：世界真的变了（接触属性、光照、物体分布）；
- H_stale：世界没变，但标定/世界模型旧了（重接地可修复）；
- H_energy：因省电/降频/跳过核验导致证据缺失，不像故障而像"没看"；
- H_llm：LLM 先验把预算带偏，导致该核验的没核验。
纵向签名
ρ^L=[trend(e_vis), changepoint(e_force), autocorr(e_force), corr(e_res, power/thermal), alloc_semantic_alignment, post_reground_persistence]。
判别逻辑：**H_stale** 的残差在重接地后消失、**H_drift** 在重接地后仍持续；**H_energy** 的异常与功耗/温度强相关且随降级缓解；**H_llm** 的异常对齐语义时段边界且可由随机化分配消融。归因在慢环，快环只采集纵向特征。若后验不集中则判 `lifetime_ambiguous` 并触发 GDF 下移一级。

**定义 243（退化阶梯 GDF）** 能力级 g=0..R，Cap_g 递减、单位任务能耗 C_g 递减；每级有认证不变量 I_g，且 I_g⇒I_{g+1}（更保守的级自动满足上一级的安全要求）。级间切换规则：
- 仅当 τ_t<τ_g 或 E_t<E_g 或 B_t<B_g 时，允许 g→g+1（单向下移）；
- 任意时刻必须存在能量可行路径到达"安全退役态"（受控停机/回撤到安全位形），即 E_t ≥ E_retire(g,当前任务点)；
- 不允许未经认证的上移（恢复需重新核验并记入账本）。
安全由**不变量单调性 + 退役储备**保证，而非依赖"系统判断自己还健康"。这封堵了"省电成功→更危险"的翻版。

**定义 244（预算感知鲁棒编译 WCV-L）** 在 WCV-V 搜索域上增加漂移膨胀：
B(φ̂, r_L) ∩ 𝒢(g) ∩ K(μ̂) ∩ ℱ(f_lim) ∩ 𝒱，r_L=√(r_geo²+r_force²+r_model²+r_drift(t)²)，
r_drift(t)=κ_d·(1−τ_t)/τ_t（证书越旧，预留越宽）。编译目标从"最小执行损失"改为"能量预算内最小期望损失"：
min_K E_{φ∈B}[loss(K,φ)] s.t. E[energy(K,φ)] ≤ ḡ_budget，
对 LLM 语义段用 r̂^UCB 取最坏。交集为空则触发 GDF 下移一级并置 `budget_conflict=True`。

**定义 245（终身规划 CSP-L）** 在语义时段图 × 退化级上规划：节点 (seg_i, g)，边含能量成本、τ 演化与任务进度；`reground`/`sleep`/`retire` 为一等元技能。约束：
- ∀t：τ_t≥τ_min（退役除外）、E_t≥E_reserve(g)、
- 每个 seg_i 内要么完成一次重接地，要么其时长 ≤Δ*_i；
- 每个任务段结束必须处于可达退役态。
软代价 = λ_E·Σ energy + λ_τ·Σ hinge(τ_min−τ_t) + λ_R·Σ risk_i。规划失败（无可行寿命路径）时提前进入受控退役，而不是"跑到没电"。

**定义 246（LLM 先验守护 PG）** 任何由 LSRF 参与的决定必须过三道门：
(i) **校准门**：ECE≤ε_ece 且输入被 OOD 检测判为分布内，否则冻结先验、均匀保守分配；
(ii) **上置信界门**：用 r̂^UCB 与 λ̂_robust=CVaR_{1−β}(λ̂)，而非点估计；
(iii) **授权门**：最终执行的动作必须落在已认证退化级 g 且通过 J_life，LLM 不直接下达/否决动作。
在此三门下，LLM 误差的可达影响限于：草稿接受率 a 下降、重接地次数上升、任务进度变慢——即**只损失效率，不破坏 τ≥τ_min 与动作认证**。

**定义 247（终身证书 J_life）** J_life=(J_vista, τ_t, ρ_t, L_t, (n_d,n_v,a), g, llm_prior_hash+ECE, Ĥ, aic_l_ver)。验证规则：
Valid(J_life) ⇔ Valid(J_vista)
∧ τ_t ≥ τ_min
∧ E_t ≥ E_reserve(g)
∧ (coast 时，由 ρ_t 推出的 coverage 下界仍 ≥ 1−α_target)
∧ I_g 成立（当前退化级不变量）
∧ LLM 先验经 PG 且未被当作真值
∧ aic_l_ver 为当前版本。
审计链新增：**为什么现在不充电（ERS 的 ΔV 与 λ* 账本）、为什么在这一级（GDF 阈值与退役储备）、证书还剩多少"电"（τ_t 与 Ĥ）、LLM 说了什么以及是否被守护门拦下。**

**定义 248（LIFELINE 算子）** 见 IP-233 伪代码。慢环：[LiDAR/日志→LSF→USR/MEL→LSRF 分段风险/时段→TAM 折旧与 SoC→FIR-L 纵向归因→ERS 重接地调度→CSP-L 终身规划→WCV-L 预算鲁棒编译→GDF 选级→ACI-L 认证与重校准→J_life]。快环：[锚点读→VISTA 快环（阶段残差/归因后验）→SC 草稿证书→(按需)C_v 核验→I_g 不变量检查→安全退役/前缀派发→账本记账]。

### IP-224/235 TAM（信任-能量资产）

```python
class TrustEnergyManager:
    """τ = 1 - α·ρ；漂移放电、重接地充电；账本可审计。慢环。"""
    def __init__(self, alpha, rho0, tau_min, c_reg):
        self.alpha, self.rho0 = alpha, rho0
        self.tau_min, self.c_reg = tau_min, c_reg
        self.rho = rho0
        self.tau = 1.0 - alpha * rho0
        self.E = None
        self.ledger = []

    def drift(self, dt, lam):
        self.rho = min(RHO_MAX, self.rho * np.exp(lam * dt))
        self.tau = 1.0 - self.alpha * self.rho

    def reground(self, cost=None):
        cost = self.c_reg if cost is None else cost
        if self.E < cost + self.reserve:
            return False
        self.E -= cost
        self.rho = self.rho0
        self.tau = 1.0 - self.alpha * self.rho0
        self.ledger.append(('reground', cost, self.tau))
        return True

    def time_to_threshold(self, lam):
        # 从当前 rho 到 tau_min 所需时长，即剩余信任视界
        if self.tau <= self.tau_min:
            return 0.0
        target_rho = (1.0 - self.tau_min) / self.alpha
        return max(0.0, np.log(target_rho / self.rho) / max(lam, 1e-9))
```

```python
class SpeculativeCertificate:

class ReGroundingScheduler:
    def __init__(self, tam, reserve):
        self.tam, self.reserve = tam, reserve

    def energy_price(self, E):
        # 影子价格随电量逼近储备单调上升
        return LAMBDA0 * (1.0 + np.exp(-(E - self.reserve) / TAU_E))

    def choose(self, post, tau, E, seg):
        lam = self.energy_price(E)
        options = {'coast': (0.0, 0.0), 'reground': (self._dv_reground(post), self.tam.c_reg),
                   'probe': (self._dv_probe(post), C_PROBE)}
        best, best_val = 'coast', 0.0
        for a, (dv, c) in options.items():
            val = dv - lam * c
            if val > best_val and E >= c + self.reserve:
                best, best_val = a, val
        if tau <= self.tam.tau_min and best == 'coast':
            best = 'reground' if E >= self.tam.c_reg + self.reserve else 'retire'
        return best, best_val
```

```python
class GracefulDegradationLadder:
    """每级有认证不变量 I_g 与退役储备；只允许单向下移。"""
    def select_rung(self, g_cur, tau, E, B, I_holds):
        g = g_cur
        while g < R and (tau < TAU_TH[g] or E < E_TH[g] or B < B_TH[g]):
            g += 1
        while g > g_cur and not I_holds[g]:
            g += 1
        return g

    def reachable_safe_retire(self, g, E, task_point):
        return E >= energy_to_retire(g, task_point) + E_RESERVE

    def step(self, g, E):
        if not self.reachable_safe_retire(g, E, self.task_point):
            return 'retire_now'          # 宁可提前受控停机，不跑到没电
        return g
```

## 4. 推导

**引理 9（推测式证书的联合界）** 设核验路径的越界概率 ≤α_v；被接受的草稿由 conformal 校准使 P(不安全 | accept)≤ε_spec。则在一次决策中，
P(越界) = a·P(越界|accept) + (1−a)·P(越界|verify) ≤ a·ε_spec + (1−a)·α_v ≤ α_v + ε_spec。
能量：接受时花 c_d，核验时花 c_d+c_v。故 E[cost]=c_d+(1−a)c_v。两条式子说明：**推测把安全界从 α_v 抬到 α_v+ε_spec（可控的常数），把能量从 c_v 降到 c_d+(1−a)c_v（随接受率线性下降）**。接受率 a 由 LSRF 辅助提高，但不改变上界结构。∎

**引理 10（终身覆盖-更新间隔）** ACI-L 的更新 α_{t+1}=α_t+γ(α_target−1[e_t>q_t]) 在任意漂移下给出长期平均覆盖 ≥1−α_target（Gibbs–Candès）。设两次更新间隔 Δ、漂移率 λ(s) 为 L_λ-Lipschitz，则区间 [t,t+Δ] 内 ρ 至少增长 e^{λ_min Δ}、名义水平只更新一次，覆盖偏差被两项支配：
(i) 由 ρ(Δ) 引起的加权 conformal 损失 α(ρ(Δ)−ρ_0)；
(ii) 由 λ 变化引起的偏差 ≤L_λ·Δ。
故任意时刻覆盖 ≥1−α_target−L_λΔ−α(ρ(Δ)−ρ_0)。令其 ≥1−α_target 得 α(ρ(Δ)−ρ_0) ≤ −L_λΔ，即 ρ(Δ) ≤ ρ_0 + (−L_λΔ)/α——在 L_λ≥0、α>0 时只有 Δ=0 严格成立；工程上取保守 λ_max 上界并解
Δ* = (1/λ)·ln(α_target/(α·ρ_0))，
其中 α_target<α 时 Δ*>0。**结论：更新越稀，覆盖越低；Δ* 是"不充电还能撑多久"的显式上界。** ∎

**定理 9（续航-安全可行域）** 设任务时长 T、每单位时长执行能耗 c_exec、重接地间隔 Δ、重接地成本 c_reg、推测节省 s=a(c_v−c_d)。则所需能量
E_req(T) ≈ T·(c_exec − s) + (T/Δ)·c_reg + E_reserve。
（若退化级 g>0，用 C_g 替代 c_exec，通常 C_g<c_exec。）
系统在 T 内可维持 τ≥τ_min 且安全完成任务 ⇔ E_0 ≥ E_req(T)。
ERS 的阈值 ΔV≥λ*c 策略是资源约束下的 Lagrangian 最优（静态情形精确，动态情形在 Whittle 指标可分时渐近最优）；且 λ*_t 随 E_t→E_reserve 单调上升，故接近储备时系统自动减少 coast、增加 reground，从结构上避免"省电→过期"死亡螺旋。
优化 Δ：对 T/Δ·c_reg 与覆盖约束 Δ≤Δ* 求最小能量，取 Δ=Δ*（把充电间隔拉到信任视界上限），即"**能撑多久就撑多久，但绝不超过视界**"。∎

**定理 10（LLM 隔离性）** 在 PG 三门下，LSRF 输出仅进入两处：(i) 草稿接受域的先验（影响 a），(ii) CSP-L 的分配建议（影响能量分配）。二者都不改变 J_vista 的认证边界与 τ 的定义。故：
- 若 LLM 完全错误，PG 的校准门/OOD 门把其冻结为均匀保守分配，a 下降、重接地次数上升，E_req 上升，任务变慢；
- 但 τ_t≥τ_min 与"动作落在已认证退化级"均由 TAM/GDF/J_life 强制，与 LLM 正确性无关。
因此 LLM 误差的最坏后果是**能量浪费与吞吐下降**，而非安全性下降。唯一例外是校准门被对抗性绕过（见风险 6），此时需 AIC-L 的对抗漂移项兜底。∎

**定理 11（退化阶梯的跨级安全）** 若对每级 g，I_g 成立且 I_g⇒I_{g+1}，且每次下移后仍有可达安全退役态（E_t≥E_retire(g)+E_reserve），则任意降级序列保持安全不变量；由能量单调下降与 E_retire 的构造，能量耗尽前系统必已进入受控退役。故"降级/退役过程本身"被认证，而不需要"系统判断自己健康"。这正面封堵第 65 轮"归因错误→更自信"的续航版"省电成功→更危险"。∎

**命题（续航管理的收益量化）** 相对"每步全量核验 + 定期固定重接地"，LIFELINE 的期望能量节省来自三项：
(1) 推测节省 s=a(c_v−c_d)；
(2) 调度节省：把固定间隔 Δ_fixed 改为信任视界 Δ*，当 λ 较小时 Δ*>Δ_fixed，重接地次数降 Δ_fixed/Δ*；
(3) 退化级节省：在低风险时段下移到 g>0，单位能耗由 c_exec 降至 C_g。
三者独立可加（在同一约束下），且均不放松 τ≥τ_min。∎

## 7. 已知风险

**一句话**：LIFELINE 的全部续航论证都压在「证书折旧 τ_t 与漂移界 ρ_t 可被现有残差观测到」这一隐藏假设上；若存在**慢速、静默、无残差签名的漂移**（如接触属性随温湿度缓慢变化、标定轴系缓慢松动、世界模型在长尾场景的盲区悄悄扩大），TAM 会算出"信任仍满、电量还够"，于是 ERS 理性地持续"省电滑行"，系统把"省电成功"当成健康信号，一路自信地运行到一张早已过期的证书上——**本轮把第 65 轮的"归因错误更自信"升级成"续航管理更自信"，而这一次连故障后验都不会亮红灯**。

**次级风险与缓解**：
1. **漂移不可观测 / 无残差签名**：ρ_t 本身由残差估计，若漂移不体现在任何被监测的残差上，τ_t 系统性偏高。缓解：引入**独立于任务的探针信号**（周期性 null_test、参考标记物、环境指纹），并把"长时间无异常"本身视为可疑（对 ρ 设下限增长项，防止过度乐观）；用 AIC-L 的对抗漂移项兜底。
2. **LLM 校准门被对抗绕过**：提示注入可欺骗 ECE 与 OOD 检测，使错误先验通过 PG。缓解：PG 的授权门保证动作仍须认证；AIC-L 显式建模对抗漂移；定期随机化分配做消融以检出 H_llm。
3. **推测式证书的分布偏移**：草稿/核验对在离线标定，真实接受率 a 与 ε_spec 可能失配。缓解：在线监控"草稿接受后核验判不安全"的比例，超阈即收紧接受域并触发重标定。
4. **能量模型不准**：c_exec、c_reg 随温度/老化漂移，E_req 估计失真。缓解：能量账本在线辨识 + 保守上界；E_reserve 留足；热降频由 GDF 直接处理。
5. **退化阶梯不变量维护成本**：每级都要认证 I_g，级数多则认证成本高。缓解：只认证实际可能到达的级；I_g 用"包含式"构造（更保守级自动满足上级）。
6. **续航天花板**：若任务本征能耗 > 电池容量，任何调度都无法避免退役。缓解：CSP-L 提前判定不可行并受控退役，而不是中途崩溃；向高层报告"需要换电/补能"。
7. **ACI-L 覆盖是"长期平均"而非"逐时刻"**：短窗口内可能暂时低于目标。缓解：对 τ 设逐时刻硬下界（用 λ_max），并在 J_life 中显式记录瞬时覆盖下界。
8. **两端时间尺度耦合**：慢环结论滞后于快环故障，可能"充电太晚"。缓解：快环的 CSC 早停与 GDF 独立于慢环；慢环只做分配，不承担即时安全。

## 8. 与前 65 轮的定位

- **第 64 轮（GRIP）**：几何先验可证伪（接触接地）。
- **第 65 轮（VISTA）**：故障可归因（视觉 × 动作分块，块内三阶段）。
- **第 66 轮（LIFELINE）**：安全可续航（LLM 语义先验 × 证书折旧/能量预算，跨部署长时序）。
- **扩展的假设集**：A94（漂移可被至少一个独立探针观测）、A95（能量/温度可在线辨识且保守上界可得）、A96（LLM 仅作先验且 PG 生效）、A97（退化级不变量包含式成立）、A98（重接地可把 ρ 重置到 ρ_0 的邻域）、A99（ACI-L 更新步长 γ 满足 Gibbs–Candès 条件）。
- **本轮贡献的一句话**：把"证书"从一次性的静态资产，变成**有电量、会折旧、需维护、可退役**的生命体——并证明**省电与安全可以在同一套可审计的预算下并存，前提是永远不允许 LLM 替安全签字**。
