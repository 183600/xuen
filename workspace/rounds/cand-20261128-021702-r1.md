### 第 1 轮灵感驱动研究记录（新循环第 1 轮，继承上一循环 CADVS-v5）

**灵感词**：模型蒸馏、常识推理

**继承关系**：上一循环第 5 轮 CADVS-v5（IP-493~496）以「认证的生成式执行」（CGE）把提议从离散规则升级为条件流匹配（FMPP）、记忆升级为嵌入检索+固化（LMEM-v2）、人因升级为面部情感调制（FAMK），并用定理 6（证书不变性）证明「换提议不换门」；执行集 Exec_v5 ⊆ Exec_v4 ⊆ … ⊆ Exec_v29。但 v5 留下三个未偿还的结构性债务：(a) R53——流提议在语义新场景仍会自信幻觉，密度新颖度 n_flow 只测几何分布、测不到「语义荒谬」；(b) R54/R49——昂贵证书（VACK 约 50 ms、BCK QP）在准入时域仍是瓶颈；(c) R57——固化只在自己铸证的片段上学习，缺独立于门的外部信号，自指博弈无外部真值。本轮两个灵感词各补一刀：**模型蒸馏**提供「把昂贵能力压进实时预算」的算子，**常识推理**提供「独立于几何密度的语义先验」。统一为主题「认证的常识蒸馏」（Certified Commonsense Distillation, CCD），形成 CADVS-v6（IP-497~500）。本轮自律：**不新增第 8 道硬门**；常识只做「提议先验 + 单向升级通道」，蒸馏只做「延迟算子 + 有界可用性损失」，两者都不许扩张信任边界。执行集升级为 Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ …。

**直觉与动机**：

1. **常识推理 → 补上「语义 OOD」这一 v5 的盲区，但常识永远不是证书**。直觉：n_flow 能发现「从没见过的几何」，却对「见过无数次、但语义上荒谬」的输入无感——把水倒进倒扣的杯子、抓刀刃、把杯子塞进比自己还小的盒子。这些轨迹在几何/力分布上可能完全落在训练支撑内，密度模型给高分，甚至逐门通过，但人一眼就知道不对。常识教师 T（大 VLM/LLM + 可供性模型）恰好能给出这种「语义荒谬」信号。但常识是概率性、有偏、会幻觉的，**绝不能当硬门**：一旦让常识参与「放行」，幻觉就直接变成安全事故。因此只允许常识做两件事：(i) 作为提议先验/排序项，改变候选分布而不改变门；(ii) 作为**单向升级通道**——高置信语义荒谬只触发「转人工/回退」，绝不触发「放行」。由定理 6，提议怎么换都不动执行边界；由单调性，升级只会缩小自主执行集。

2. **模型蒸馏 → 把「大而慢的常识」和「大而慢的证书」分别压进实时预算，但蒸馏只买延迟，不买信任**。第一层：教师 T 太大不能端侧实时跑，用**选择性模仿蒸馏**把 T 压成学生 S_φ：只在教师「多提示一致 ∧ 高置信」的样本上模仿，教师自相矛盾/OOD 的样本不模仿、学生输出弃权 ⊥，避免把幻觉一起蒸馏进来。第二层更关键：把昂贵门验证器（VACK 的力/价值评分、BCK 的 QP 边际）蒸馏成快速代理 f_i^D，但代理**只能用于「快速否决」**：若 f_i^D 低于一个由 conformal 分位数定出的 λ_i，就直接判该门不过（不再调用精确验证器）；否则仍调用精确门。于是复合门 kc_i^D 只会比 kc_i 更严（Exec^D ⊆ Exec），结构上不可能假放行；唯一代价是「可能误杀本来能过的候选」，其概率由 conformal 的 β_i 界住。这把蒸馏从「信任风险」降级为「可用性预算」，并用 β_i 预算做延迟-可用性帕累托调度。

3. **统一：常识给「往哪找」，蒸馏给「找得起、验得快」，门给「能不能放」**。三者职责严格分离：常识/蒸馏都作用在提议与预筛（proposal/evaluation）侧，门是唯一信任边界。这样 v5 的定理 5/6/7 原样保持，v6 只新增「蒸馏算子的一侧性」与「常识通道的一侧性」两条结构性定理。副产品：常识教师作为**外部预训练信号**，可为 LMEM-v2 的固化过滤提供独立于门的第三票（门 ∧ 结局 ∧ 人工 ∧ 常识一致性），部分偿还 R57 的自指；但必须诚实——教师自身有偏，这是「外部先验」不是「外部真值」。

**关键洞见**：v5 把提议换成任意生成器，证明了「提议无关性」；v6 进一步证明「**学习无关性**」——无论提议器是流、是常识教师、还是被蒸馏到会幻觉的学生，只要它不进入门谓词，执行边界不变；而蒸馏进门的唯一合法方式是「只加否决、不加放行」，于是蒸馏也被纳入单调收缩。一句话：**常识负责想象力，蒸馏负责速度，门负责责任**。

**形式化目标（增量）**：
1. CSDK（常识选择性蒸馏）：教师 T(c)=(p_T,a_T,r_T)，学生 S_φ(c)=(p_φ,a_φ,s_cs,u_φ)；选择性模仿权重 w(c)=1[Agree(T_{1:M}(c))≥ρ ∧ max p_T≥κ]；损失 L_KD 含软标签 KL、可供性回归、理由（rationale）对齐与不确定度校准；弃权 u_φ>u_max → ⊥ → 回退 v5。
2. CDV（认证蒸馏验证器）：每个昂贵门 i 的代理 f_i^D ≈ 边际 m_i；split-conformal 在正例代理分上取 β_i 下分位 λ_i；守卫门 kc_i^D(x)=0 若 f_i^D(x)<λ_i，否则 kc_i(x)；预算调度 min E[延迟] s.t. Σβ_i≤β_budget。
3. CEC（常识升级通道）：单向升级谓词 esc_cs(x,c)=1[s_cs(x,c)>τ_cs ∧ u_φ(c)≤u_max ∧ c∈C_cert]；esc=1 → NEED_HUMAN（不是放行）；η_cs 软因子；语义 OOD 分数 s_cs 与 n_flow 取 OR 但仅用于升级/排序。
4. 定理 9（守卫蒸馏门一侧性/无假放行）、定理 10（conformal 可用性损失界）、定理 11（常识提议/升级不变性）、定理 12（选择性模仿的幻觉封闭与教师错误不可消除）；引理 45（split-conformal 有限样本分位覆盖）、引理 46（选择性模仿泛化界）。
5. EFA-v6：七门不变（昂贵门按认证替换为守卫蒸馏门）+ CEC 升级 + CSDK 先验；ECS_v6 = ECS_v5·η_cs；Exec_v6 = {x∈Exec_v5 : ∀i f_i^D(x)≥λ_i ∧ ¬esc_cs(x)} ⊆ Exec_v5。

**本轮最大风险**：**分布内保证被误读为分布外真理**——conformal 的可用性界与 KD 的泛化界都以可交换性/同分布为前提，部署漂移或对抗性语义攻击下两者同时失效；更隐蔽的是学生继承了教师的常识盲区，教师与学生**相关失败**，却因「两个模型都同意」而被误当成独立验证，制造出「常识蒸馏提供了外部真值」的错觉（它其实只是把同一个偏见复制了两份）。

**定义 2390（单向升级谓词）**：esc_cs(x,c) = 1[ s_cs(x,c) > τ_cs ∧ u_φ(c) ≤ u_max ∧ c ∈ C_cert ]。语义：该候选在语义上足够可疑，系统拒绝自主执行，转人工确认；**它不产生「放行」**。

## 2. 关键算法骨架

### IP-497 CSDK：常识选择性蒸馏核（教师离线；学生端侧 10–30 Hz）

```python
@dataclass
class CommonsenseSelectiveDistillationKernel:
    """CSDK：大教师 → 端侧学生；只学教师自洽且高置信的部分。
    红线：学生输出只进提议/排序/升级，永不进门谓词（定理 11）"""
    teacher: Any                  # 冻结：大 VLM/LLM + affordance head，多提示 M 次
    student: Any                  # 端侧 ~50M Transformer/ViT
    rho: float = 0.8              # 多提示一致性阈
    kappa: float = 0.7            # 教师置信阈
    u_max: float = 0.2            # 学生弃权阈（conformal 风险控制）
    tau_cs: float = 0.6           # 升级阈值（校准）
    lam_a: float = 0.5
    lam_r: float = 0.1

    def selective_weight(self, c) -> float:
        outs = [self.teacher(c, prompt=j) for j in range(self.M)]
        agree = 1.0 - mean([entropy(o.p) for o in outs]) / LOG_K
        conf = max(o.p.max() for o in outs)
        return float(agree >= self.rho and conf >= self.kappa)

    def train_loss(self, batch) -> float:
        # 只在 C_conf 上回传；其余样本权重 0，避免蒸馏幻觉
        w = batch.w
        p_t, a_t, r_t = batch.teacher
        loss = (w * (kl(p_t, self.student.p(batch.c))
                     + self.lam_a * mse(a_t, self.student.a(batch.c))
                     + self.lam_r * rationale_ce(r_t, self.student.r(batch.c)))).mean()
        return loss + self.lam_u * uncertainty_nll(self.student.u(batch.c), batch.err)

    def infer(self, c) -> CSOut:
        p, a, s_cs, u = self.student(c)
        if u > self.u_max:                    # 弃权：回退 v5 提议，不用常识
            return CSOut(a=None, s_cs=0.0, u=u, abstain=True)
        return CSOut(a=a, s_cs=calibrate(s_cs), u=u, abstain=False)

    def calibrate_abstention(self, cal_set, alpha_s: float) -> None:
        """conformal 风险控制选 u_max，使 P(未弃权 ∧ 学生与教师不一致) ≤ alpha_s。
        注意：只约束对教师的一致性，不约束教师本身对错（定理 12-iv）"""
```

### IP-498 CDV：认证蒸馏验证器与 β 预算调度（离线校准 + 在线 O(1) 判定）

```python
@dataclass
class CertifiedDistilledVerifier:
    """CDV：昂贵门 → 快速代理；代理只能否决、不能放行。
    定理 9：kc_i^D ≤ kc_i ⇒ Exec^D ⊆ Exec，与代理精度无关；
    定理 10：可交换性下误杀率 ≤ Σβ_i"""
    surrogate: dict                # i -> f_i^D（边际回归/排序网络）
    lam: dict                      # i -> λ_i（split-conformal 下分位）
    beta: dict                     # i -> β_i
    exact: dict                    # i -> 精确门验证器（v5 原样）

    def calibrate(self, i, D_cal_i, beta_i) -> float:
        pos = [self.surrogate[i](x, c) for (x, c, kc) in D_cal_i if kc == 1]
        k = floor(beta_i * (len(pos) + 1)) - 1     # split-conformal 有限样本修正
        return sorted(pos)[max(k, 0)]

    def schedule(self, cand_stream, c_i, beta_budget) -> dict:
        """min Σ_i c_i·P(f_i^D ≥ λ_i(β_i))  s.t.  Σ_i β_i ≤ beta_budget。
        λ_i 随 β_i 单调不增 ⇒ 每条门有「延迟-可用性」帕累托曲线；
        用拉格朗日/贪心在曲线上分配预算（离线，低频重算）"""
        ...

    def guarded_gate(self, i, x, c) -> bool:
        if self.surrogate[i](x, c) < self.lam[i]:
            return False                 # 快速否决：省一次昂贵验证
        return self.exact[i](x, c)       # 否则必须走精确门（绝不用代理放行）
```

### IP-499 CEC：常识升级通道（端侧；与控制环解耦）

```python
@dataclass
class CommonsenseEscalationChannel:
    """CEC：语义可疑 → NEED_HUMAN；只减自主执行，不增放行（定理 11）"""
    csdk: CommonsenseSelectiveDistillationKernel
    lam_cs: float = 0.3              # η_cs 软因子系数

    def escalate(self, x, c, s: CSOut) -> bool:
        return (not s.abstain) and (s.s_cs > self.csdk.tau_cs) and (c in self.csdk.C_cert)

    def eta_cs(self, s: CSOut) -> float:
        if s.abstain:
            return 1.0
        return max(1.0 - self.lam_cs * s.s_cs, 0.1)   # ∈ [0.1,1]，只降不升

    def semantic_ood(self, s: CSOut) -> float:
        # 与 n_flow OR 合成，仅用于升级/排序；不作为独立硬门
        return float(s.s_cs) if not s.abstain else 0.0
```

### IP-500 EFA-v6：七门 + 守卫蒸馏 + 常识升级

```python
@dataclass
class EvidenceForgingAssemblerV6:
    """EFA-v6：七硬门不变；昂贵门换守卫蒸馏门；常识只做先验与升级"""
    fmpp: FlowMatchingProposalPolicyKernel
    lmem: LongTermMemoryEmbeddingConsolidation
    famk: FacialAffectModulationKernel
    csdk: CommonsenseSelectiveDistillationKernel
    cec: CommonsenseEscalationChannel
    cdv: CertifiedDistilledVerifier
    v5: EvidenceForgingAssemblerV5

    def select(self, x0_state, t_now, rule_id, context):
        s_emo = self.famk.observe(context.face, t_now)
        gamma = self.famk.gamma(s_emo)
        cs = self.csdk.infer(context)                    # 弃权则 a=None
        c = build_ctx(context, s_emo, self.lmem, cs.a)   # 常识可供性 token
        cands = self.fmpp.propose(c, self.fmpp.K)        # K=8，异步准入

        # 第 1 层：廉价门（含 n_flow 与 s_cs 仅作排序/升级信号）
        surv = [x for x in cands if self._cheap_gates(x, gamma)]
        if not surv:
            return self._fallback_rule_proposal(gamma)
        surv.sort(key=lambda x: self._rank(x, cs), reverse=True)   # ECS_v5·η_cs

        # 第 2/3 层：昂贵门用守卫蒸馏（快速否决），通过者再精确确认
        finals = []
        for x in surv[:3]:
            if not all(self.cdv.guarded_gate(i, x, c) for i in ('val', 'bal')):
                continue
            if self.cec.escalate(x, c, cs):              # 语义可疑 → 转人工
                continue
            finals.append(x)
        if not finals:
            # 有候选但全被语义升级 → NEED_HUMAN；否则精确全灭
            return (False, None, 'NEED_HUMAN') if any(
                self.cec.escalate(x, c, cs) for x in surv[:3]
            ) else (False, None, 'ALL_CANDIDATES_REJECTED')
        best = max(finals, key=lambda x: self._ecs_v6(x, cs, s_emo))
        return True, best, 'FORGED_CCD'

    def _ecs_v6(self, x, cs, s_emo) -> float:
        return self.v5.ecs_v5(x, s_emo) * self.cec.eta_cs(cs)   # 只降不升
```

## 4. 正确性论证（增量更新）

### 引理 45（split-conformal 有限样本分位覆盖）

**陈述**：设 (Z_1,…,Z_n,Z_{n+1}) 可交换，取 λ 为 {Z_j : kc_j=1} 中第 ⌊β(n+1)⌋ 小的值，则 P(Z_{n+1} < λ | kc_{n+1}=1) ≤ β。∎

**证明**：正例集合内的秩统计量在可交换性下均匀分布，标准 conformal 论证给出覆盖；有限样本用 ⌊β(n+1)⌋ 修正。∎

**诚实边界**：可交换性在部署漂移、时间相关、主动采样（候选由策略选择，非 iid）下不成立。缓解：加权 conformal（重要性权重）、在线 adaptive conformal（ACI）、按上下文分层校准；否则只能保证「有偏的」误杀率。

### 引理 46（选择性模仿泛化界）

**陈述**：在 C_conf 上，以概率 ≥ 1−δ，E_{c∼P_conf}[KL(p_T‖p_φ)] ≤ L̂ + O(√((C(Φ)+log(1/δ))/n))，C(Φ) 为假设类复杂度。∎

**证明**：标准 Rademacher 复杂度 + 有界 KL 的 McDiarmid 集中。∎

**诚实边界**：界的是「对教师的模仿误差」，教师对真值的误差完全不在界内（定理 12-iv）。

### 定理 9（守卫蒸馏门一侧性 / 无假放行）

**陈述**：对任意代理 f_i^D、任意 λ_i，定义 kc_i^D = 1[f_i^D≥λ_i]·kc_i，则 Exec^D ⊆ Exec。∎

**证明**：逐点 kc_i^D ≤ kc_i，交集单调。∎ 该结论**不依赖**代理精度、校准质量或分布假设——即使代理完全错误，也只会误杀，不会假放行。

### 定理 10（conformal 可用性损失界）

**陈述**：在引理 45 的可交换性下，对 x∈Exec，P(x∉Exec^D) ≤ Σ_i β_i。∎

**证明**：单门 P(f_i^D<λ_i | kc_i=1) ≤ β_i；x∈Exec 满足所有 kc_i=1；对门取并集界。∎

**推论**：期望精确调用减少 Σ_i P(f_i^D<λ_i)；可用性损失可写成预算约束 Σβ_i≤β_budget。

### 定理 11（常识提议/升级不变性）

**陈述**：对任意学生 S_φ（可任意错误/幻觉）：(i) 常识先验只改 supp(π) 与排序，门定义的可执行集 G 不变；(ii) esc_cs 只把候选移出自主执行，Exec_v6 ⊆ Exec_v5；(iii) η_cs∈(0,1] 只降 ECS。∎

**证明**：(i) 门是轨迹空间上的固定谓词，与 π 无关（定理 6 推广）；(ii) NEED_HUMAN 是拒绝的强化，不产生新通过；(iii) 单调乘法。∎

### 定理 12（选择性模仿的幻觉封闭与教师错误不可消除）

**陈述**：(i) C_conf 上模仿误差由引理 46 界；(ii) C_conf 外学生弃权并回退 v5；(iii) conformal 风险控制选 u_max，使 P(未弃权 ∧ 与教师不一致) ≤ α_S；(iv) d(p_true,p_φ) ≥ d(p_true,p_T) − d(p_T,p_φ)。∎

**证明**：(i) 引理 46；(ii) §1 的弃权规则（u_φ>u_max → ⊥）；(iii) conformal risk control 选阈值；(iv) 三角不等式。∎

**诚实边界**：蒸馏只能逼近教师，不能超越教师；教师若系统性错误（文化偏见、物理常识盲区），学生会忠实地复制它。

### 定理 v6（执行集嵌套与信任边界不变，总装）

**陈述**：在 v5 假设 (B1)~(B7) 及新增 (B8) 校准/部署可交换（或已做加权/在线修正）下：
(i) Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ … ⊆ Exec_v29（严格：存在被快速否决或被升级的候选）；
(ii) 守卫蒸馏门无假放行（定理 9），误杀率 ≤ Σβ_i（定理 10）；
(iii) 常识提议/升级不扩张执行集（定理 11），幻觉最坏导致可用性损失；
(iv) 选择性模仿把学生误差限制在 C_conf，且以教师误差为下界（定理 12）；
(v) v5 的定理 5/6/7/8 原样保持（门集合不变、阈值只紧、固化只改提议器）。

**证明**：(i) 由 kc_i^D ≤ kc_i 与 esc_cs 只减；(ii) 定理 9/10；(iii) 定理 11；(iv) 定理 12；(v) 各模块未改门谓词与 τ^4。∎

**诚实声明**：(B8) 在真实部署中很难严格成立（候选非 iid、分布漂移、对抗输入），conformal 界需在线修正且修正本身可能滞后；常识教师的文化/物理偏见会被学生继承，形成相关失败；「教师-学生一致」不等于「独立验证」；语义 OOD 检测仍有盲区，只是把 v5 的几何盲区换成了语义盲区。

| R64 | 教师被舰队数据回流污染，自指经教师重新进入 | 高 | 教师冻结 + 数据溯源 + 独立审计 + 版本签名 | 供应链/数据来源难完全审计 |
| R65 | β 预算调度低估真实延迟（GPU 抖动、批大小变化） | 中 | 在线延迟反馈 + 保守调度 + 自适应 β | SLO 抖动 |
| R66 | 语义对抗输入同时骗过教师与学生（双错） | 高 | 仅升级/提议，绝不放行；门仍精确；红队对抗训练 | 对抗语义空间无界；最坏为可用性损失 |

## 7. 本轮最大风险（最终确认）

**一句话**：**分布内保证被误读为分布外真理**——conformal 的可用性界与 KD 的泛化界都以可交换性/同分布为前提，部署漂移或对抗性语义攻击下两者同时失效；更隐蔽的是学生继承了教师的常识盲区，教师与学生**相关失败**，却因「两个模型都同意」而被误当成独立验证，制造出「常识蒸馏提供了外部真值」的错觉（它其实只是把同一个偏见复制了两份）。
