## 1. 力控增量：接触异常残差 r_anom 与阻抗调制

### 1.1 直觉
真实抓取/插入/装配的成败往往取决于接触形成瞬间的力一致性：双指接触时序不对称、法向力不足、切向滑移、环境刚度突变。现有 WAVE-SERVO 已有虚拟力预测 `f_virt = K_p (x_des - x_obs) + K_d v` 与关节电流观测 `τ_obs`，但缺乏「预测力与观测力是否一致」的显式自监督信号。引入第 4 个残差通道 `r_anom`，直接度量虚拟力预测与电流反解力的差异，作为接触内部异常的早期预警；同时将任务条件化参数 `θ_prim` 输出的阻抗增益 `K_p, K_d` 注入 WAVE-SERVO，实现「软接触/硬装配」的在线阻抗切换。

### 1.2 形式化定义
设第 `b` 个 5 步块结束时，末端期望位姿 `x^{des}_b`，实测关节位置 `q_b`，关节速度 `qdot_b`，关节电流 `I_b`（或电流指令 `τ_cmd`）。定义：

**虚拟力预测**（WAVE-SERVO 内部已计算）：
```math
f^{virt}_b = K_p (x^{des}_b - \mathrm{fk}(q_b)) + K_d \cdot J(q_b) qdot_b
```

**电流反解接触力**（简化模型，忽略重力/摩擦补偿，仅作一致性代理）：
```math
f^{obs}_b = J(q_b)^{-\top} (\tau^{cmd}_b - \tau^{model}_b) \approx c^{obs}_b \cdot \mu |I_b|
```
其中 `c^{obs}_b` 为标定常数，`μ` 为电流-力换算系数（离线标定后冻结）。

**接触异常残差**（第 4 通道）：
```math
r^{\mathrm{anom}}_b = 
\frac{\| f^{virt}_b - f^{obs}_b \|}{\| f^{virt}_b \| + \epsilon}
```

**阻抗参数任务条件化调整**：
```math
(K_p, K_d) = \theta_{\mathrm{prim}}(u, M) \in \mathbb{R}^2_{>0}
```
其中 `θ_prim` 由 §3 定义。典型映射：「精密插入」→ 高 `K_p`、低 `K_d`（刚性）；「柔性抓取/未知物体」→ 低 `K_p`、高 `K_d`（顺应）。

### 1.3 与现有残差的融合（四通道）
块 `b` 结束后并行计算四通道残差向量 `r_b ∈ ℝ^4`：
- `r^{tmp}_b`：时序一致性（动作块平滑度）
- `r^{geo}_b`：几何一致性（FK 位移 vs 规划位移 + 光流）
- `r^{goal}_b`：目标进度（距离收敛 / edit score）
- `r^{anom}_b`：接触异常（**本轮新增**）

**自归一化（MAD）**：
```math
\sigma_{k,b} = 1.4826 \cdot \mathrm{MAD}(\{r^k_{b-W+1},...,r^k_b\}) + \epsilon_k, \quad
z^k_b = r^k_b / \sigma_{k,b}
```

**融合惊讶分数**（固定权重，不学习）：
```math
s_b = w_{\mathrm{dyn}} z^{\mathrm{dyn}}_b + w_{\mathrm{tmp}} z^{\mathrm{tmp}}_b + w_{\mathrm{geo}} z^{\mathrm{geo}}_b + w_{\mathrm{goal}} z^{\mathrm{goal}}_b + w_{\mathrm{anom}} z^{\mathrm{anom}}_b
```
固定 `w_dyn=3, w_tmp=w_geo=w_goal=w_anom=1`。动力学通道权重最高（安全兜底），其余均等。

|---|---|---|---|
| H6 | `r_anom` 能区分接触内部异常（滑移/脱开/过载）与正常接触，AUROC ≥ 0.7 | AUROC < 0.55 | 主 |
| H7 | ZEST+`r_anom` 在含接触异常的 OOD 任务上成功率相对无 `r_anom` 基线提升 ≥ 3pp | 相对无 `r_anom` 无提升 | 主 |

## 2. 决策规划增量：信任门、生命周期状态机、降级语法

### 2.1 直觉
VOI-MAP 调度器基于信息增益选择 `SERVO/LOOK/VLA/FALLBACK`，但缺乏「当前执行是否可信」的全局治理。VLA 可能因分布外输入产生幻觉动作，几何原语可能因地图误差失效。需要一个**独立于任务调度的胜任力层**，实时融合四通道残差，输出三态决策：`TRUST`（继续当前策略）、`FALLBACK`（切换几何原语）、`HOLD`（紧急停止等待）。引入 self-normalized split conformal 预测 + CUSUM 顺序检测，提供有限样本覆盖保证与快速变点检测；显式生命周期状态机管理跨块上下文（GROUND→TRACK→RECOVER→HOLD）；几何原语语法在降级时自动简化（移除高风险原语）。

### 2.2 形式化定义

#### 2.2.1 Self-Normalized Conformal 校准
ID 校准集（与测试集严格分离）收集 `N` 个块的融合分数 `{s_1,...,s_N}`。取经验 `(1-α)` 分位数：
```math
q_\alpha = \mathrm{Quantile}_{1-\alpha}\{s_i\}, \quad \alpha = 0.1
```
测试块惊讶指示：`e_b = \mathbb{1}[s_b > q_\alpha]`。边际保证：`\Pr(e_{B+1}=1) \le \alpha`。

#### 2.2.2 CUSUM 信任门
```math
S_b = \max(0, S_{b-1} + e_b - \alpha - k), \quad S_0 = 0
```
参数：`k = 0.5`（参考值）、`h = 3.0`（判决阈值），经验证集冻结。
触发条件：`S_b > h` **或** `r^{anom}_b > \theta_{anom}`（硬阈值，`θ_anom=2.5`）→ 进入 `FALLBACK`。

#### 2.2.3 滞回与复检
`FALLBACK` 模式下每 `R=3` 个块执行一次 `PROBE`：发射一个低风险 SERVO 探针，若 `e_b=0` 且 `r^{anom} \le \theta_{anom}` 连续 2 块，回 `TRUST`；否则继续 `FALLBACK`。禁止在 `CONTACT/CARRY` 相位复检（避免破坏接触）。

#### 2.2.4 显式生命周期状态机
```math
\sigma \in \{\mathrm{INIT}, \mathrm{GROUND}, \mathrm{TRACK}, \mathrm{RECOVER}, \mathrm{HOLD}\}
```
转移规则：
| 当前态 | 条件 | 下一态 |
|---|---|---|
| INIT | VLA 首块返回 + 地图初始化完成 | GROUND |
| GROUND | grounding 收敛（目标信念熵 `< H_th`） | TRACK |
| TRACK | 信任门触发 (`S_b>h` 或 `r_anom>θ_anom`) | RECOVER |
| TRACK | 编辑检测触发 / VLA 超时 | RECOVER |
| RECOVER | 复检通过（连续 2 块无惊讶） | TRACK |
| RECOVER | 连续 3 块复检失败 / 关节限位 / 碰撞 | HOLD |
| HOLD | 人工介入 / 远程重置 | INIT |

#### 2.2.5 几何原语语法降级
`FALLBACK` 模式下可用原语集 `Π_{fallback} ⊆ Π_{full}`：
```math
\Pi_{\mathrm{fallback}} = \Pi_{\mathrm{full}} \setminus \{\mathrm{INSERT\_PRECISE}, \mathrm{GRASP\_ADAPTIVE}, \mathrm{SCREW}\}
```
仅保留 `APPROACH, ALIGN, GRASP_BASIC, LIFT, PLACE, RETRACT` 等低风险原语。

| 编号 | 假设 | 证伪条件 | 级别 |
|---|---|---|---|
| H1 | 四通道残差融合能区分 OOD-E（执行幻觉）与 OOD-S（语义地图偏移），AUROC ≥ 0.65 | AUROC < 0.65 或 ID 假警报 > 10% | 主 |

## 3. 用户需求分析增量：任务条件化原语参数 θ_prim 与信念初始化

### 3.1 直觉
同一几何原语（如 `GRASP`、`INSERT`）在不同任务、不同物体上需要截然不同的参数：握幅、插入深度、力限、速度、容差。VOI-MAP grounding 已将指令 `u` 映射为目标信念分布 `b_t`，但「把杯子放在桌上」与「把易碎玻璃杯轻放在桌子中央」在几何目标上相近，所需参数却大相径庭。引入**任务条件化原语参数函数** `θ_prim(u, M)`，从指令语义与语义地图属性联合推断原语参数，零新参数、零学习；同时将风险关键词注入 VOI-MAP 信念初始化 `b_0`，诱导高风险任务分配更多 LOOK/SERVO 预算。

### 3.2 形式化定义

#### 3.2.1 θ_prim：指令-地图联合参数推断
设语义地图 `M` 包含物体实例集 `{o_i}`，每实例有类别 `cat_i`、包围盒 `bbox_i`、姿态 `R_i`、摩擦估计 `μ_i`、脆性标签 `fragile_i`。
定义参数模板库 `T = {τ_1,...,τ_P}`，每个模板 `τ_p = (触发条件, 参数映射)`。

**触发条件**：指令关键词正则 + 地图属性谓词（如 `u` 含「插入」∧ `M` 存在 `cat=USB`）。
**参数映射**：输出原语参数字典，如：
```python
{
  "GRASP": {"width": w_b, "force_limit": f_lim, "approach_speed": v_app},
  "INSERT": {"depth": d_ins, "force_limit": f_lim, "compliance": (K_p, K_d)},
  "PLACE": {"pos_tol": tol, "force_limit": f_lim, "verify_time": t_ver}
}
```

**推断算法**（确定性、线性扫描模板库）：
```math
\theta_{\mathrm{prim}}(u, M) = \bigcup_{p: \mathrm{match}(\tau_p.\mathrm{cond}, u, M)} \tau_p.\mathrm{params}
```
冲突解决：后匹配覆盖先匹配；未匹配项使用全局默认值（验证集调优后冻结）。

**典型模板示例**（共 15 条，冻结）：
| 触发条件 | 输出参数 |
|---|---|
| `u` 含「小心/轻轻/易碎/玻璃」 | `GRASP.force_limit↓0.5, GRASP.width↑0.01, INSERT.compliance←(low K_p, high K_d)` |
| `u` 含「快速/急」 | `GRASP.approach_speed↑2.0, INSERT.depth↓0.1` |
| `M` 存在 `fragile=True` | `PLACE.pos_tol←0.002, PLACE.verify_time↑1.0` |
| `M` 物体类别 `cup/mug/bowl` | `GRASP.type←BOTTOM, GRASP.width←bbox_diameter*0.9` |
| `M` 物体类别 `thin/rod/cable` | `GRASP.type←SIDE, GRASP.width←thickness*1.1` |

#### 3.2.2 信念初始化偏移（风险感知先验）
原 VOI-MAP 初始信念 `b_0(x) ∝ \exp(-d(x, target)/σ)`。引入风险偏移：
```math
b_0'(x) \propto b_0(x) \cdot \exp\big( \beta_{\mathrm{risk}} \cdot \mathbb{1}[\mathrm{risk\_kw}(u)] \cdot \mathbb{1}[x \in \mathcal{N}_\delta(target)] \big)
```
其中 `risk_kw(u)` 检测指令中的风险关键词（易碎/液体/昂贵/危险），`β_risk=1.0`（验证集冻结），`N_δ` 为目标邻域。高风险任务在目标附近分配更高先验，诱导调度器分配更多 LOOK/SERVO 预算。

## 6. 本轮最大的风险

**接触一致性代理的信噪比**：`r_anom` 完全依赖虚拟力预测与关节电流反解力的对比，但无 F/T 传感器时，电流反解力受摩擦模型误差、重力补偿残差、电机温漂、关节耦合影响极大，信噪比可能低到无法与正常接触变异区分（AUROC < 0.55）。若合成实验 G6 验证失败，第 4 通道将被砍掉，导致本轮「力控」增量归零，ZEST 退化为三通道系统，失去接触内部异常的感知能力——这是本轮四通道融合中唯一**依赖物理近似而非纯几何/语义**的风险点，必须在仿真与少量实机标定中严格把关。

## 0. 结论与边界

### 0.1 一句话结论
第 1 轮在 FACT-VLA/GEO-RESIDUAL/CHUNK-SERVO/WAVE-SERVO/VOI-MAP 五层基座之上，引入「接触异常残差 `r_anom`（力控）」「自归一化 conformal + CUSUM 信任门 + 生命周期状态机（决策规划）」「任务条件化原语参数 `θ_prim` 与风险感知信念初始化（用户需求分析）」，将执行治理从「调度选择动作」升级为「胜任力感知的三态决策（TRUST/FALLBACK/HOLD）+ 可验证统计保证 + 参数自适应」，构成 ZEST-VLA 零样本鲁棒系统的核心骨架。

| 等级 | 含义 | 本报告中的例子 |

| A | 官方文档、提交模板、数据集元数据、经典文献直接核实 | Conformal prediction 理论、CUSUM ARL 公式、WAVE-SERVO TD-PC 推导、33,276 eps 数据集规模 |

## 2. 符号与形式化定义

### 2.1 冻结的 VLA 与执行层
设 VLA 为 `π_θ`，`θ` 冻结。给定观测 `o_t` 和指令 `u`，输出 30 步动作块 `A_t = (a_{t,0},...,a_{t,29})`。执行层按 5 步块执行，块索引 `b=0,...,5`。

**观测空间**：`o = (q, qdot, qddot, I, img_wrist, img_static, u)`，其中 `I` 为关节电流，**无深度、无 F/T、无腕相机内参**。

**语义地图**：`M = {o_i}`，每实例 `o_i = (cat_i, bbox_i, R_i, μ_i, fragile_i, target_pose_i)`。

**原语库**：`Π = {APPROACH, ALIGN, GRASP_BASIC, GRASP_ADAPTIVE, INSERT_BASIC, INSERT_PRECISE, LIFT, PLACE, RETRACT, SCREW, ...}`。每个原语 `π ∈ Π` 有参数签名 `params(π)`。

### 2.2 四通道自监督残差向量
在块 `b` 结束后，四个残差并行计算：

**动力学残差（dynamic，安全兜底）**
```math
r^{\mathrm{dyn}}_b = \max\big(0, \max(\|qdot_b\|/\dot{q}_{\max}, \|qddot_b\|/\ddot{q}_{\max}) - 1\big)
```

**时序残差（temporal，动作块平滑度）**
```math
r^{\mathrm{tmp}}_b = \frac{\|A_{b} - A_{b-1}\|_F}{\|A_{b-1}\|_F + \epsilon} \quad (b>0), \quad r^{\mathrm{tmp}}_0 = 0
```

**几何残差（geometric，FK 位移 + 光流）**
```math
r^{\mathrm{geo}}_b = \frac{\|\mathrm{fk}(q_b) - \mathrm{fk}(q_{b-1}) - \Delta x^{\mathrm{plan}}_b\|}{\|\Delta x^{\mathrm{plan}}_b\| + \epsilon} + \lambda_F \cdot \frac{\|\mathrm{flow}_{\mathrm{obs}} - \mathrm{flow}_{\mathrm{pred}}\|}{\sigma_{\mathrm{flow}}}
```
其中 `Δx^plan_b` 为规划的笛卡尔位移，`flow_pred` 由深度无关的平面运动模型预测（或无深度时置 0），`λ_F=0.5`。

**目标进度残差（goal-progress）**
```math
r^{\mathrm{goal}}_b = 
\begin{cases}
\frac{(d_0 - d_1) - \Delta d^{\mathrm{plan}}}{\Delta d^{\mathrm{plan}} + \epsilon}, & \phi_b \in \{\mathrm{APPROACH},\mathrm{PRECONTACT}\} \\
\mathrm{edit\_score}(o_{b-1}, o_b), & \text{otherwise}
\end{cases}
```
其中 `d_0, d_1` 为末端到目标距离，`edit_score` 为第 11 轮编辑距离检测器输出（0~1）。

**接触异常残差（anomaly，本轮新增，第 4 通道）**
```math
f^{\mathrm{virt}}_b = K_p (x^{\mathrm{des}}_b - \mathrm{fk}(q_b)) + K_d \cdot J(q_b) qdot_b
```
```math
f^{\mathrm{obs}}_b = c^{\mathrm{obs}}_b \cdot \mu |I_b| \quad (\text{标量模长近似，方向沿 } f^{\mathrm{virt}}_b)
```
```math
r^{\mathrm{anom}}_b = \frac{\| f^{\mathrm{virt}}_b - f^{\mathrm{obs}}_b \|}{\| f^{\mathrm{virt}}_b \| + \epsilon}
```
阻抗参数 `(K_p, K_d) = \theta_{\mathrm{prim}}(u, M).\mathrm{compliance}`，见 §2.5。

### 2.3 自归一化与 Conformal 校准
**滑动窗口 MAD 归一化**（窗口 `W=10`）：
```math
\sigma_{k,b} = 1.4826 \cdot \mathrm{MAD}(\{r^k_{b-W+1},...,r^k_b\}) + \epsilon_k, \quad
z^k_b = r^k_b / \sigma_{k,b}
```

**融合惊讶分数**（固定权重）：
```math
s_b = 3.0 \cdot z^{\mathrm{dyn}}_b + z^{\mathrm{tmp}}_b + z^{\mathrm{geo}}_b + z^{\mathrm{goal}}_b + z^{\mathrm{anom}}_b
```

**Split Conformal 校准**（ID 校准集 `N=500` 块，与测试集严格分离）：
```math
q_\alpha = \mathrm{Quantile}_{1-\alpha}\{s_i^{\mathrm{cal}}\}, \quad \alpha = 0.1
```
测试块惊讶指示：`e_b = \mathbb{1}[s_b > q_\alpha]`。理论保证：`\Pr(e_{B+1}=1) \le \alpha`（边际覆盖，有限样本）。

### 2.4 CUSUM 信任门与滞回/复检
**CUSUM 统计量**：
```math
S_b = \max(0, S_{b-1} + e_b - \alpha - k), \quad S_0 = 0
```
参数：`k=0.5`（参考值）、`h=3.0`（判决阈值），验证集冻结。

**模式判决**：
- `TRUST`：`S_b \le h` 且 `r^{\mathrm{anom}}_b \le \theta_{\mathrm{anom}}`（`θ_anom=2.5`）
- `FALLBACK`：`S_b > h` **或** `r^{\mathrm{anom}}_b > \theta_{\mathrm{anom}}`
- `HOLD`：生命周期状态 `σ = HOLD`（见 §2.6）

**滞回与复检**：
- `FALLBACK` 模式下每 `R=3` 块执行一次 `PROBE`（低风险 SERVO 探针）
- 若连续 2 个 `PROBE` 块满足 `e_b=0` 且 `r^{\mathrm{anom}}_b \le \theta_{\mathrm{anom}}`，回 `TRUST`，`S_b ← 0`
- 禁止在 `CONTACT/CARRY` 相位复检（相位见 §2.7）

**软胜任力**（用于调度器增益）：
```math
c_b = 1 - \frac{1}{W}\sum_{i=0}^{W-1} e_{b-i} \in [0,1]
```

### 2.5 任务条件化原语参数 θ_prim
**模板库**：`T = {τ_1,...,τ_P}`，`P=15`（冻结）。每个 `τ_p = (cond_p, params_p)`。

**触发条件** `cond_p`：指令正则 `regex_p(u)` ∧ 地图谓词 `pred_p(M)`。
**参数映射** `params_p`：`Dict[Primitive, Dict[Param, Value]]`。

**推断算法**：
```python
def theta_prim(u: str, M: SemanticMap) -> PrimitiveParams:
    out = DEFAULT_PARAMS.copy()  # 全局默认，验证集冻结
    for regex, pred, params in TEMPLATE_LIBRARY:  # 15 条，顺序固定
        if re.search(regex, u, re.IGNORECASE) and pred(M):
            out = deep_merge(out, params)  # 后覆盖前
    return out
```

**典型模板**（节选）：
| 触发正则 | 地图谓词 | 输出参数片段 |
|---|---|---|
| `小心|轻轻|易碎|fragile|glass` | — | `GRASP.force_limit=1.5, GRASP.width+=0.01, INSERT.compliance=(K_p=500, K_d=50)` |
| `快速|quickly|fast` | — | `GRASP.approach_speed=0.5, INSERT.depth*=0.9` |
| `插入|insert|plug` | `∃ o: cat=USB` | `INSERT.depth=0.04, INSERT.force_limit=8.0, INSERT.compliance=(K_p=2000, K_d=20)` |
| `抓取|grasp|pick` | `∃ o: cat∈{cup,mug,bowl}` | `GRASP.type=BOTTOM, GRASP.width=bbox_diam*0.9, GRASP.force_limit=2.0` |
| — | `∃ o: fragile=True` | `PLACE.pos_tol=0.002, PLACE.verify_time=1.0, GRASP.force_limit*=0.7` |

**域检查**（前置条件守卫）：
```math
\mathrm{dom}(\sigma(u)) = \{\pi \in \Pi \mid \mathrm{IK\_feasible}(\pi) \land \mathrm{collision\_free}(\pi) \land \mathrm{params\_in\_range}(\pi)\}
```
若 `GRASP.width ∉ [w_min, w_max]` 或 `IK` 失败，原语被禁用，调度器自动降级。

### 2.6 显式生命周期状态机
```math
\sigma \in \{\mathrm{INIT}, \mathrm{GROUND}, \mathrm{TRACK}, \mathrm{RECOVER}, \mathrm{HOLD}\}
```
**转移表**：
| 当前态 | 触发条件 | 下一态 | 动作 |
|---|---|---|---|
| INIT | VLA 首块返回 ∧ 地图初始化完成 | GROUND | 发布 `status=GROUND` |
| GROUND | 目标信念熵 `H(b) < H_{th}=1.5` | TRACK | 开始正常调度 |
| TRACK | `S_b > h` ∨ `r_anom > θ_anom` | RECOVER | `fallback_dwell=0`，切换原语集 `Π_fallback` |
| TRACK | 编辑检测触发 ∨ VLA 超时 `> 2s` | RECOVER | 同上 |
| RECOVER | 复检通过（连续 2 块 `e=0 ∧ r_anom≤θ_anom`） | TRACK | 恢复 `Π_full`，`cusum=0` |
| RECOVER | 连续 3 块复检失败 ∨ 关节限位 ∨ 碰撞 | HOLD | 发布 `status=HOLD`，零速度指令 |
| HOLD | 人工介入 / 远程重置指令 | INIT | 重置所有状态 |

**超时守卫**：每态设 `τ_max`（INIT=5s, GROUND=10s, TRACK=∞, RECOVER=15s, HOLD=∞），超时强制 `HOLD`。

### 2.7 几何原语语法降级
`FALLBACK` 模式下可用原语集：
```math
\Pi_{\mathrm{fallback}} = \Pi_{\mathrm{full}} \setminus \{\mathrm{INSERT\_PRECISE}, \mathrm{GRASP\_ADAPTIVE}, \mathrm{SCREW}\}
```
保留：`APPROACH, ALIGN, GRASP_BASIC, INSERT_BASIC, LIFT, PLACE, RETRACT`。
`RECOVER` 探针仅使用 `APPROACH/ALIGN/RETRACT`。

### 2.8 VOI-MAP 信念初始化偏移（风险感知）
原信念：`b_0(x) ∝ \exp(-d(x, target)/σ)`，`σ=0.05`。
风险偏移：
```math
b_0'(x) \propto b_0(x) \cdot \exp\big( \beta_{\mathrm{risk}} \cdot \mathbb{1}[\mathrm{risk\_kw}(u)] \cdot \mathbb{1}[x \in \mathcal{N}_\delta(target)] \big)
```
`β_risk=1.0`，`δ=0.03m`，`risk_kw(u)` 正则：`易碎|液体|水|倒|昂贵|危险|fragile|liquid|pour|expensive|dangerous`。
归一化后作为 VOI-MAP 初始信念，诱导高风险任务在目标邻域分配更高先验 → 调度器分配更多 LOOK/SERVO 预算。

## 3. 算法步骤总览（累积 13 步）

在原有 8 步（第 10–14 轮）基础上增 5 步：

1. **VLA 推理**：获取 30 步动作块 `A_t` + 相位标签 `φ_t`
2. **地图更新**：VOI-MAP 融合观测，更新目标信念 `b_t`
3. **相位观测**：从 `M, o_t` 推断当前相位 `ϕ_t ∈ {FREE, APPROACH, PRECONTACT, CONTACT, CARRY, PLACE, RETRACT}`
4. **编辑检测**：第 11 轮编辑距离检测器，输出 `edit_score`
5. **WAVE-SERVO 执行**：5 步闭环，虚拟力 + TD-PC 限幅
6. **原语执行**：FALLBACK 模式下按原语序列执行，参数来自 `θ_prim`
7. **残差计算**：块结束并行算四通道 `r_b`
8. **自归一化融合**：MAD 归一化 → `s_b` → `e_b`
9. **CUSUM 更新**：`S_b` 更新，模式判决 `mode ∈ {TRUST, FALLBACK, HOLD}`
10. **生命周期跃迁**：`σ` 状态机更新
11. **调度器动作选择**：基于 `mode, c_b, b_t, ϕ_t` 选 `SERVO/LOOK/VLA/FALLBACK/PROBE/HOLD`
12. **信念初始化偏移**：任务开始时注入风险先验 `b_0'`
13. **参数条件化**：FALLBACK 原语参数实时读取 `θ_prim(u,M)`

## 4. 伪代码：核心组件

### 4.1 主循环（Per-Port PolicyService）
```python
class ZestPolicy:
    def __init__(self, calib_scores, lambda_grasp, lambda_insert, lambda_lift):
        # 校准分位数
        self.q_alpha = np.quantile(calib_scores, 0.9)  # α=0.1
        # CUSUM
        self.cusum = 0.0
        self.k = 0.5
        self.h = 3.0
        self.alpha = 0.1
        # 惊讶窗口
        self.W = 10
        self.surprise_window = deque(maxlen=self.W)
        # 模式
        self.mode = "TRUST"
        self.fallback_dwell = 0
        self.RECHECK_EVERY = 3
        # 生命周期
        self.cycle_sigma = "INIT"
        self.cycle_timer = 0.0
        # 参数
        self.theta_anom = 2.5
        self.theta_prim = ThetaPrim(TEMPLATE_LIBRARY)  # 15 条模板
        self.D = None
        # 原语库
        self.primitives = PRIMITIVE_LIBRARY
        self.fallback_primitives = FALLBACK_PRIMITIVE_SET
        # 相位
        self.phase = "FREE"
        # 调度器
        self.budget = BUDGET_INIT
        
    def get_action(self, obs):
        # 1. 地图更新 + 相位观测 + 编辑检测
        self.M = update_map(self.M, obs, self.plan)
        self.phase = observe_phase(self.M, obs)
        if edit_detected(obs):
            self.phase = "RECOVER"
            self.cycle_sigma = "GROUND"
        
        # 2. 生命周期状态机更新
        self._update_cycle_state(obs)
        
        # 3. 根据模式选择动作集
        allowed = self._allowed_actions()
        if not allowed:
            return self._safe_hold()
        
        # 4. 调度器选择
        act = self.select_action(obs, allowed)
        
        # 5. 执行对应动作
        if act == "SERVO":
            chunk = self._wave_servo_chunk(obs, self.plan)
            self._record_pending_residual_check(obs, chunk)
            return chunk
        if act == "FALLBACK":
            adapted = self._adapt_primitive_params(self.plan)
            if adapted is None:
                return self._safe_hold()
            chunk = self._execute_next_primitive(obs, adapted)
            self._record_pending_residual_check(obs, chunk, fallback=True)
            return chunk
        if act == "LOOK":
            return self._look_action(obs)
        if act == "VLA":
            self._request_plan_async(obs)
            return self._safe_hold_or_last_chunk()
        if act == "HOLD":
            return self._safe_hold()
        if act == "PROBE_ANOM":
            return self._probe_anom(obs)
        return self._commit_action(obs)
    
    def _update_cycle_state(self, obs):
        # 超时守卫
        self.cycle_timer += 0.02  # 50Hz
        timeouts = {"INIT": 5.0, "GROUND": 10.0, "TRACK": float('inf'), 
                    "RECOVER": 15.0, "HOLD": float('inf')}
        if self.cycle_timer > timeouts.get(self.cycle_sigma, float('inf')):
            self.cycle_sigma = "HOLD"
            self.cycle_timer = 0.0
            return
        
        # 状态跃迁
        if self.cycle_sigma == "INIT":
            if self.plan is not None and self.M.initialized:
                self.cycle_sigma = "GROUND"
                self.cycle_timer = 0.0
        elif self.cycle_sigma == "GROUND":
            if self.M.target_entropy < 1.5:
                self.cycle_sigma = "TRACK"
                self.cycle_timer = 0.0
        elif self.cycle_sigma == "TRACK":
            if self.mode == "FALLBACK":
                self.cycle_sigma = "RECOVER"
                self.fallback_dwell = 0
                self.cycle_timer = 0.0
        elif self.cycle_sigma == "RECOVER":
            if self.mode == "TRUST" and self.fallback_dwell >= 2:
                self.cycle_sigma = "TRACK"
                self.cycle_timer = 0.0
            elif self.fallback_dwell >= 3:
                self.cycle_sigma = "HOLD"
                self.cycle_timer = 0.0
        # HOLD 等待外部重置
    
    def _allowed_actions(self):
        base = {"SERVO", "LOOK", "VLA", "FALLBACK", "HOLD", "PROBE_ANOM", "COMMIT"}
        if self.cycle_sigma == "HOLD":
            return {"HOLD"}
        if self.cycle_sigma == "RECOVER":
            return {"SERVO", "HOLD", "PROBE_ANOM"}  # 仅探针与保持
        if self.mode == "FALLBACK":
            return {"SERVO", "FALLBACK", "HOLD", "LOOK"}  # 禁用 VLA/COMMIT
        return base
    
    def select_action(self, obs, allowed):
        b = self.M.target_belief  # (H,W) 信念图
        p = self.progress  # 0~1
        c = self.soft_competence()
        bmax = max(b.flatten())
        
        opts = []
        if "SERVO" in allowed:
            gain = c * bmax * (f(p + 0.1) - f(p))
            opts.append(("SERVO", gain, C_SERVO))
        if "LOOK" in allowed and self.phase in ("APPROACH", "PRECONTACT"):
            gain = look_gain(b, self.M, self.phase)
            opts.append(("LOOK", gain, C_LOOK))
        if "VLA" in allowed and self.budget >= C_VLA:
            c_after = c + (1 - c) * Q_VLA
            gain = (c_after - c) * bmax * f(p) + 0.05
            opts.append(("VLA", gain, C_VLA))
        if "FALLBACK" in allowed:
            g = self.g_prim.get(self.current_primitive, G_PRIOR)
            gain = bmax * g * (f_geo(p + 0.1) - f_geo(p))
            opts.append(("FALLBACK", gain, C_FALLBACK))
        if "PROBE_ANOM" in allowed and self.cycle_sigma == "RECOVER":
            opts.append(("PROBE_ANOM", 1.0, C_PROBE_ANOM))
        
        if not opts:
            return "HOLD"
        act, gain, cost = max(opts, key=lambda o: o[1] / o[2])
        if gain / cost < LAMBDA_OPPORTUNITY:
            return "COMMIT" if "COMMIT" in allowed else "HOLD"
        return act
    
    def _on_vla_response(self, plan):
        self.plan = plan
        self.prev_plan = self.plan
    
    def on_block_finished(self, obs_before, obs_after, executed):
        # 1. 计算四通道残差
        if executed in ("SERVO", "FALLBACK"):
            r = compute_residuals(obs_before, obs_after, self.plan,
                                  self.prev_plan, self.M, self.phase)
            # 2. MAD 归一化
            scales = self._update_mad_scales(r)
            z = {k: r[k] / (scales[k] + 1e-6) for k in r}
            # 3. 融合分数
            s = (3.0 * z["dyn"] + z["tmp"] + z["geo"] + z["goal"] + z["anom"])
            # 4. 惊讶指示
            surprise = int(s > self.q_alpha)
            self.surprise_window.append(surprise)
            # 5. CUSUM 更新
            self.cusum = max(0.0, self.cusum + surprise - self.alpha - self.k)
            # 6. 模式更新
            self._update_mode(surprise, r["anom"])
        
        # 7. 生命周期更新
        self._update_cycle_state({})
        
        # 8. 进度更新
        self.progress = update_progress(self.M, obs_after)
    
    def _update_mode(self, surprise, r_anom):
        if self.mode == "TRUST":
            if self.cusum > self.h:
                self.mode = "FALLBACK"
                self.fallback_dwell = 0
            elif r_anom > self.theta_anom:
                self.mode = "FALLBACK"
                self.fallback_dwell = 0
        elif self.mode == "FALLBACK":
            self.fallback_dwell += 1
            if self.fallback_dwell >= self.RECHECK_EVERY:
                self.mode = "PROBE"
                self.fallback_dwell = 0
        elif self.mode == "PROBE":
            if not surprise and r_anom <= self.theta_anom:
                self.mode = "TRUST"
                self.cusum = 0.0
            else:
                self.mode = "FALLBACK"
                self.fallback_dwell = 0
    
    def soft_competence(self):
        if len(self.surprise_window) == 0:
            return 1.0
        return 1.0 - sum(self.surprise_window) / len(self.surprise_window)
    
    def _adapt_primitive_params(self, plan):
        if plan is None:
            return None
        params = self.theta_prim.compute(self.instruction, self.M)
        adapted = []
        for prim_name, prim_args in plan.primitives:
            if prim_name not in self._allowed_primitives():
                continue
            merged = deep_merge(prim_args, params.get(prim_name, {}))
            if self._domain_check(prim_name, merged):
                adapted.append((prim_name, merged))
        return adapted if adapted else None
    
    def _allowed_primitives(self):
        if self.mode == "FALLBACK" or self.cycle_sigma == "RECOVER":
            return self.fallback_primitives
        return set(self.primitives.keys())
    
    def _domain_check(self, prim_name, params):
        # IK 可达 + 碰撞自由 + 参数范围
        if prim_name == "GRASP_BASIC" or prim_name == "GRASP_ADAPTIVE":
            w = params.get("width", 0.04)
            if w < 0.01 or w > 0.1:
                return False
        return check_ik_and_collision(prim_name, params, self.M)
```

### 4.2 四通道残差计算
```python
def compute_residuals(obs0, obs1, plan, prev_plan, M, phase):
    r = {}
    # dynamic
    r["dyn"] = max(0.0, max(
        np.linalg.norm(obs1.qdot) / QDOT_MAX,
        np.linalg.norm(obs1.qddot) / QDDOT_MAX
    ) - 1.0)
    
    # temporal
    if prev_plan is not None:
        r["tmp"] = np.linalg.norm(plan.actions - prev_plan.actions) / \
                   (np.linalg.norm(prev_plan.actions) + 1e-6)
    else:
        r["tmp"] = 0.0
    
    # geometric
    dx_obs = fk(obs1.q) - fk(obs0.q)
    dx_cmd = planned_cartesian_delta(plan, obs0)
    r["geo"] = np.linalg.norm(dx_obs - dx_cmd) / (np.linalg.norm(dx_cmd) + 1e-6)
    if obs1.flow is not None and target_visible(M, obs1):
        flow_pred = project_motion(dx_cmd, obs1.camera)
        r["geo"] += 0.5 * np.linalg.norm(obs1.flow - flow_pred) / SIGMA_FLOW
    
    # goal
    if phase in ("APPROACH", "PRECONTACT"):
        d0 = np.linalg.norm(fk(obs0.q)[:3] - M.target_pos)
        d1 = np.linalg.norm(fk(obs1.q)[:3] - M.target_pos)
        dd_plan = planned_distance_delta(plan)
        r["goal"] = ((d0 - d1) - dd_plan) / (dd_plan + 1e-6)
    else:
        r["goal"] = edit_score(obs0, obs1)
    
    # anomaly (contact)
    K_p, K_d = theta_prim_compliance(plan, M)  # 从 θ_prim 读取
    f_virt = K_p * (plan.des_pos - fk(obs1.q)[:3]) + K_d * J(obs1.q) @ obs1.qdot
    f_obs_mag = C_OBS * MU * np.abs(obs1.I).mean()
    f_obs = f_obs_mag * (f_virt / (np.linalg.norm(f_virt) + 1e-6))
    r["anom"] = np.linalg.norm(f_virt - f_obs) / (np.linalg.norm(f_virt) + 1e-6)
    
    return r
```

### 4.3 θ_prim 计算器
```python
class ThetaPrim:
    def __init__(self, templates):
        self.templates = templates  # List[(regex, pred, params_dict)]
        self.defaults = DEFAULT_PRIMITIVE_PARAMS
    
    def compute(self, u: str, M: SemanticMap) -> PrimitiveParams:
        out = deepcopy(self.defaults)
        for regex, pred, params in self.templates:
            if re.search(regex, u, re.IGNORECASE) and pred(M):
                out = deep_merge(out, params)
        return out
```

### 4.4 信念初始化偏移
```python
def inject_risk_prior(b0: np.ndarray, u: str, M: SemanticMap, beta=1.0, delta=0.03) -> np.ndarray:
    if not risk_keyword(u):
        return b0
    target = M.target_pos
    mask = np.zeros_like(b0, dtype=bool)
    for i, cell_pos in enumerate(M.grid_positions):
        if np.linalg.norm(cell_pos - target) < delta:
            mask[i] = True
    b0_prime = b0.copy()
    b0_prime[mask] *= np.exp(beta)
    return b0_prime / b0_prime.sum()
```

## 6. 正确性论证

### 6.1 统计性质保持
**命题 1（边际覆盖）**：Split conformal 校准后，测试块惊讶率满足 `\Pr(e_{B+1}=1) \le \alpha`。

*证明*：残差序列 `{r_b}` 在 ID 分布下交换性成立（i.i.d. 块假设）。融合分数 `s_b = g(r_b)` 为确定性函数，保持交换性。Split conformal 理论（Vovk et al., 2005; Angelopoulos & Bates, 2021）直接适用。∎

**命题 2（CUSUM ARL）**：在 ID 分布下，CUSUM 平均运行长度 `ARL_0 \ge 1/\alpha`（约 10 块），在均值偏移 `δ` 下 `ARL_1 \approx \exp(h \cdot δ)` 快速检测。

*证明*：标准 CUSUM 性质（Page, 1954；Moustakides, 1986）。参数 `k=α/2=0.05` 近似最优。∎

**命题 3（维度扩展不破坏保证）**：后续轮次增加残差通道（如 `r_intent`），仅改变融合维度，交换性假设不依赖维度，conformal/CUSUM 保证保持。

*证明*：残差向量维度从 `d` 到 `d+1`，联合分布交换性等价于边际交换性。融合函数 `g: ℝ^{d+1} → ℝ` 为确定性映射。∎

### 6.2 生命周期状态机安全性
**命题 4（有限终止）**：从任意初始态，状态机在有限步内进入 `{TRACK, HOLD}`，不存在活锁。

*证明*：状态空间有限（5 态），转移图中仅 `TRACK↔RECOVER` 可能循环，但 `RECOVER` 有 `fallback_dwell≥3` 强制进入 `HOLD`，`HOLD` 仅外部重置离开。故无活锁。∎

**命题 5（接触保护）**：`CONTACT/CARRY` 相位下禁止复检探针，避免破坏已建立接触。

*证明*：调度器 `_allowed_actions` 在 `phase ∈ {CONTACT, CARRY}` 时移除 `PROBE_ANOM`，且 `FALLBACK` 模式下禁用 `LOOK/VLA`，仅允许 `SERVO` 执行原语。∎

### 6.3 θ_prim 单调性与域检查
**命题 6（参数调整单调性）**：`θ_prim` 仅在模板触发时覆盖默认值，不引入振荡；域检查 `dom(σ(u))` 保证所有发布原语满足物理约束。

*证明*：模板库顺序固定，后覆盖前，单次任务内确定性单调。域检查为硬前置条件，不通过即禁用原语，调度器自动选择备选。∎

### 6.4 OOD 边界显式化
**命题 7（OOD 分类完备性）**：ZEST 可检测边界定义为：
- OOD-E（执行幻觉）：四通道残差融合 `s_b` 超阈值 → `FALLBACK`
- OOD-S（语义地图偏移）：`r_geo`/`r_goal` 主导惊讶 → `FALLBACK` + 降级原语
- OOD-G（目标错误）：VLA 与地图共享先验，**不可检测**，系统自信执行错误目标

*证明*：OOD-E/OOD-S 表现为动作-观测不一致，被残差捕获。OOD-G 表现为动作-观测一致但目标错误，无自监督信号区分。∎

## 9. 一句话押注
**用「动作-观测一致性」四通道残差构建可验证的胜任力信号，用 conformal/CUSUM 赋予其统计保证，用生命周期状态机治理跃迁，用 θ_prim 让几何原语懂任务：ZEST-VLA 将零样本执行从「信策略」进化为「知胜任、懂参数、守边界」。**

## 10. 本轮最大的风险
**接触一致性代理的信噪比**：`r_anom` 完全依赖虚拟力预测与关节电流反解力的对比，但无 F/T 传感器时，电流反解力受摩擦模型误差、重力补偿残差、电机温漂、关节耦合影响极大，信噪比可能低到无法与正常接触变异区分（AUROC < 0.55）。若合成实验 G6 验证失败，第 4 通道将被砍掉，导致本轮「力控」增量归零，ZEST 退化为三通道系统，失去接触内部异常的感知能力——这是本轮四通道融合中唯一**依赖物理近似而非纯几何/语义**的风险点，必须在仿真与少量实机标定中严格把关。
