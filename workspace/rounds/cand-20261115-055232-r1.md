# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「遥操作」×「视觉语言动作模型」）

> R69 的闭环已经会「问」：流匹配给不确定性以形状，VoI 决定值不值得看/问/触，FMA 给出一条标定吸收不掉的行为似然第二意见。但 R69 的主动性仍被一条隐含前提锁死：**机器人始终握着方向盘**——所有「信息动作」都必须先通过 C-RAS-WM 认证，且不得越出安全包络。真实世界里最强的消歧信号往往不在机器人的传感器里，而在**人**手里：操作者一眼就看出「杯子在左边」，机器人却要在模态间犹豫半天。遥操作（teleoperation）正是这条通道——但它把 R69 的「问」升级成「交权」，风险性质完全改变：问错了只是慢一点，交错了会撞。
>
> 本轮两个灵感正好构成一对张力：
> - **遥操作**给出「人类在环」的最高带宽校正通道，也给出最危险的动作面——权威切换（authority handover）、时延、操作者疲劳与恶意注入；
> - **视觉语言动作模型（VLA）**给出一个语言接地的通才先验，它既是「人类大概会怎么做」的可计算近似，也是把「左/右/轻一点」这类语言校正落成动作的解释器。
>
> 核心命题：**把「权威」与「学习」拆成两个独立而耦合的对象。遥操作不是「人类接管」，而是一条高带宽、高风险的「校正证据流」；VLA 不是最终策略，而是「关于人类会怎么做的先验 + 语言接地解释器」。任何权威切换必须可逆、无突变、可认证（RAE）；任何校正必须先归因、再定向学习（CA→TGU）——没有归因，就没有学习。**
>
> 命名 **CARE-RAS**（Correction-Attributed and Reversible-authority Exchange for teleoperated VLA）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**什么时候把方向盘交出去，交出去之后怎么保证不撞、又怎么不把人的错误学进模型**」。

## 0. 直觉与动机

**灵感 1（遥操作 = 高带宽局部校正，而非整体接管）**
直觉：人类操作者不是「替代」机器人，而是在机器人犹豫/出错的那一小段里注入一个**局部校正**。像老师批改作业：不是重写整篇，而是在错处画一道。若把整段遥操作都当示范（naive DAgger），就等于把老师顺手写的每个字都当范文——包括他手抖的那一下、走神的那一秒、以及故意写错的陷阱。所以关键不是「学人」，而是「**先判断人改的是什么**」。

**灵感 2（VLA = 关于人的先验，而非最终答案）**
直觉：VLA 在互联网规模数据上学到「看到杯子 + 听到『拿杯子』→ 伸手」。它天然携带两类知识：(i) 语言到任务/物体的接地；(ii) 人类在相似场景下**大概会怎么做**。前者让语言校正可执行，后者让机器人能**预判**操作者下一步要改什么——预判得准，就能提前平滑地让出权威（anticipatory blending），而不是等人猛打方向再急刹。但 VLA 也会自信地犯错（幻觉可操作性、指令接地错），所以它只能当先验，不能当权威。

**灵感 3（权威是一个可逆、可认证的过程量，不是一个开关）**
直觉：从「自主」切到「遥操作」再切回，最危险的不是两端，而是**切换瞬间**：指令跳变、能量注入、证书失效、状态估计错位。人类开车换驾驶员不会在高速上直接换手，而是先减速、对齐、再交接。形式化上，权威 α 必须有界速率、必须保持无源性（passivity）、必须在 C-RAS-WM 的安全包络内、必须可逆（能验证地退回自主）。这是 R69「交互预算硬约束」在**控制层**的升级：R69 约束「问几次」，R70 约束「交多少权、交多快、怎么收回」。

**灵感 4（归因是新的「标定」：没有归因就没有学习）**
直觉：一次校正可能是六种东西之一——指令歧义、感知/状态错、策略错、真实意图变化、操作者自己错、对抗注入。它们对应**完全不同的更新**：改语言接地、改状态估计/标定、改策略权重、改目标、什么都不改只记录、拒绝并告警。R69 已证明「任何不确定 → 只收紧」会混淆 aleatoric/epistemic；R70 的对应病理是「**任何校正 → 都学习**」，它会把感知错学成策略错、把人的偏好学成物理规律、把攻击学成能力。归因就是 R68「标定」在**学习来源侧**的镜像：标定问「我的测量还准吗」，归因问「**这条校正到底在纠正谁**」。

**灵感 5（学习要有「来源审计」与「局部围栏」）**
直觉：即使归因对了，一次局部校正也不该重写全局先验——否则「杯子这次在左边」会被学成「杯子永远在左边」，或操作者的个人习惯被当成通用规律（R68「缓变故障被标定吸收」在学习侧的翻版：**局部校正被参数吸收而泛化错**）。所以更新要**定向**（只动归因指向的那一块）且**围栏**（反事实优势 + 重要性权重 + 局部支撑集），并把「校正→归因→更新→证书」写成不可篡改的**学习来源账本**，支持回滚。

**灵感 6（交权是双刃剑：新的威胁模型）**
直觉：一旦接受遥操作，攻击面从「传感器/回答」扩展到「**控制通道**」：伪造操作者、重放合法校正、用高频接管把恶意示范灌进 VLA、用语言「帮我拿刀」做社交工程、以及「权威劫持」——先骗到接管权再乱来。R69 的「k 个正交证据源一致」在这里升级为「**控制通道认证 + 归因门 + 来源账本**」三重纪律：单次接管永远只提供证据，不单独改变模型。

**定义 310（CARE-RAS 总览）** CARE-RAS = (VP, CA, RAE, OM, TGU, LSC, OG, LP, HIC, TAP, RAS-WM†)。四不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）：在线控制路径绝不更新权重，学习只发生在离线/准静态账本提交；
(ii) **权威可逆且可认证**：任一时刻权威状态 α 的转移满足速率界、无源性、安全包络（定义 313、321）；
(iii) **无归因不学习**：任何来自遥操作/语言校正的更新必须携带归因后验 b(c)，且 max_c b(c) ≥ τ_attr 且 c ∈ {C_perc, C_pol, C_int, C_ins}；否则只记录不进权重（定义 315、317）；
(iv) **来源可审计**：每次更新在 LP 中留下不可篡改三元组（校正哈希、归因、更新增量哈希），支持按来源回滚（定义 318、323）。

**定义 311（VLA 先验 VP）** 视觉语言动作模型 π_VLA(a_{t:t+H} | o_t, ℓ)，ℓ 为语言指令/校正，输出动作块。三用途：(a) 自主先验采样；(b) 语言接地的校正解释器；(c) 通过冻结 VLA 特征/动作头构造**操作者模型**（定义 316）。VP 不直接作为安全关键输出，必须经 RAS-WM† 认证。

**定义 312（遥操作通道与权威状态）** 遥操作输入 u_H = (a_H, ℓ_H, h_H) ∈ 𝒰，a_H 为人工动作、ℓ_H 为语言校正、h_H 为置信/犹豫信号（停顿、反复、力度）。权威状态 α ∈ [0,1]：α=1 纯自主，α=0 纯人工；混合指令 a_cmd = (1−α)·proj_{𝒜_safe}(a_H) + α·a_VLA。α 由 RAE 连续调节，不由人直接跳变。

**定义 313（可逆权威交换 RAE）** 权威转移满足：
(a) **速率界** |dα/dt| ≤ ρ_α；
(b) **无源性** 存在存储函数 V_α 使 Ḣ ≤ u_H^⊤ẏ − γV_α（或波变量等价）；
(c) **安全包络** 任意 α 下 a_cmd ∈ 𝒜_safe(o_t)（继承 C-RAS-WM）；
(d) **可逆回归** 只有当归因已决、安全证书刷新、且自主策略在 shadow 模式下预测安全时，才允许 α 回升。
一次「交权—收权」构成混合自动机的一个非 Zeno 转移。

**定义 314（潜在归因空间）** 潜在因 c ∈ 𝒞 = {C_ins 指令歧义, C_perc 感知/状态错, C_pol 策略错, C_int 意图变化, C_op 操作者错, C_adv 对抗}。维护后验 b(c) = P(c | u_H, o_t, 证据)，先验 b_0 由上下文给出（首次接管偏向 C_pol/C_perc，重复同向校正抬高 C_int）。

**定义 315（校正归因 CA）** 证据向量 e = (r_res, Δa, Δ_ℓ, Δ_safe, Δ_OM, a_H 的时域一致性)：r_res/Δa 继承 R68/R69（感知残差与行为似然），Δ_ℓ 为语言接地偏移（VLA 对 ℓ 与 ℓ_H 的嵌入差），Δ_safe 为人工动作相对安全包络的越界度，Δ_OM 为操作者模型预测残差，时域一致性刻画反复/犹豫。后验 b(c) ∝ P(e|c)·b_0(c)。归因置信 κ_attr = 1 − H(b)/log|𝒞|。

**定义 316（操作者模型 OM）** 由遥操作日志与冻结 VLA 特征训练 π_H(a_H | o_t, ℓ_H, z)，预测操作者意图动作并输出预测不确定度。OM 用于：(a) 预判校正、提前平滑让权（定义 313d 的 anticipatory 变体）；(b) 判别「操作者错」vs「模型错」（预测残差 + 安全越界）；(c) 生成澄清问题（回接 R69 的 g_ask）。OM 须经 operator-ECE 校准（定义 320）。

**定义 317（定向接地更新 TGU）** 由归因指向更新目标：C_ins ⇒ 更新语言接地/任务嵌入；C_perc ⇒ 更新状态估计/标定（**不改策略**）；C_pol ⇒ 更新 VLA 策略（经围栏）；C_int ⇒ 更新目标/任务条件；C_op/C_adv ⇒ **不更新**，只记录与告警。更新量 Δθ 施加**局部围栏**（定义 325）。「无归因不学习」为硬门。

**定义 318（学习来源账本 LP）** 追加写入记录 rec = (h(o_t), h(a_H), b(c), h(Δθ), 证书, 时间戳)，链式哈希。任何模型版本可追溯到其全部来源校正；支持按来源回滚（撤销一条被判定为攻击的校正及其更新）。

**定义 319（时延感知共享控制 LSC）** 遥操作存在往返时延 d（网络 + 操作者反应）。用 d 步前向预测/波变量补偿得等效人工指令 û_H(t) = Predict_H(u_H(t), d)，补偿器须保持无源性（引理 23）；当 d > d_max 时强制抬高 α（更自主）并发出「延迟过高」证书。

**定义 320（操作者信任规 OG）** 对每个操作者维护可靠性校准：operator-ECE（其校正与后续客观结果/多源一致的比例校准）、一致性、犹豫频率。信任 τ_op ∈ [0,1] 与信任预算 B_op。τ_op 低于阈值时，遥操作从**权威**降级为**建议**（α 不下降，仅作证据）——「听得见，但不交方向盘」。

**定义 321（交权不变式证书 HIC）** 证书 C_ho = (α 轨迹, 最大 |dα/dt|, 安全包络验证, 无源性余量, 时延上下界, 回权 shadow 预测)。Valid(C_ho) ⇒ 交权期间与回权后控制连续、无能量爆增、无包络越界。

**定义 322（遥操作攻击面 TAP / AIC-T）** 威胁：伪造操作者、重放校正、高频接管灌毒、语言社交工程、权威劫持。并入 AIC：ℰ_CARE = ℰ_FLUID × ℰ_teleop × ℰ_demo。防御：控制通道签名 + 频率/带宽限制 + 归因门 + LP 回滚 + 多源一致。

**定义 323（证书 J_CARE）** J_CARE = (J_FLUID, attr_ece, κ_attr_p05, operator_ece, authority_trace_hash, handover_cert_hash, update_ledger_root, delay_manifest, poison_reject_rate, care_ver)。Valid ⇔ Valid(J_FLUID) ∧ attr_ece ≤ τ_attr_ece ∧ C_ho 全段有效 ∧ 无未归因更新。

```python
# IP-264 VP：VLA 先验（异步、动作块；不直接进安全关键路径）
class VLAPrior:
    def __init__(self, model, chunk=H, rate_hz=8):
        self.m, self.chunk, self.rate = model, chunk, rate_hz
    def sample(self, o, ell, K=1):        # 语言接地 + 多峰动作块
        return [self.m.act(o, ell) for _ in range(K)]
    def embed(self, ell):                 # 语言接地嵌入，供 CA/TGU 用
        return self.m.text_encode(ell)

# IP-265 CA：校正归因（先归因，再决定学不学、学哪里）
def attribute_cause(u_H, o, ev):
    logp = {c: log_lik(ev, c) + log_prior(c, o) for c in CAUSES}
    b = softmax(logp)
    return b, 1.0 - entropy(b) / log(len(CAUSES))     # (后验, 归因置信)

# IP-266/321 RAE+HIC：可逆权威交换（速率界 + 无源性 + 安全包络）
class AuthorityExchange:
    def step(self, alpha, target, u_H, o, dt):
        a_n = clip(alpha + sign(target-alpha)*min(abs(target-alpha), RHO*dt), 0, 1)
        cmd = (1-a_n)*project_safe(u_H.a) + a_n*vla_action
        if not c_ras_wm.inside_envelope(cmd, o):
            a_n = alpha                              # 包络优先：冻结权威
        if not passivity_ok(self.V, u_H, cmd, dt):
            a_n = max(a_n, alpha)                    # 只允许更自主（更保守）
        return a_n, cmd

# IP-267/320 OM：操作者模型 + 信任规
def operator_residual(om, u_H, o, ell_H):
    a_hat, unc = om.predict(o, ell_H)
    return norm(u_H.a - a_hat), unc, om.ece

# IP-268/325 TGU：定向 + 围栏更新（无归因不学习）
def targeted_update(model, u_H, o, b, kappa, ledger):
    c = argmax(b)
    if kappa < TAU_ATTR or c in (C_OP, C_ADV):
        ledger.append(u_H, b, delta=None)            # 只记录，不学
        return model
    adv  = counterfactual_advantage(o, u_H.a, a_vla)
    w    = clip(pi_H(u_H.a | o) / pi_VLA(u_H.a | o), W_LO, W_HI)
    mask = local_support(u_H.a, a_vla, r_f)          # 局部围栏
    if   c == C_INS:  model = update_language_grounding(model, u_H.ell, w, adv)
    elif c == C_PERC: model = update_state_estimator(model, o, u_H, w)  # 不动策略
    elif c == C_POL:  model = update_policy_masked(model, o, u_H, w, adv, mask)
    elif c == C_INT:  model = update_goal_conditioning(model, u_H.ell, w)
    ledger.append(u_H, b, hash_delta(model))          # 来源可追溯
    return model

# IP-276 主闭环（继承 R69；仅在权威/校正处置处插入 CARE 层）
def CARE_round(M, o, u_H):
    a_v = M.vp.sample(o, ell, K=1)[0]                 # 旧行动作块
    # 1) 先归因：这条校正到底在纠正谁
    ev = (M.cof.r_res, M.fma.delta_a(o), M.om.residual(u_H, o, ell),
          safe_gap(u_H.a, o), consistency(u_H.history))
    b, kappa = M.ca.attribute(u_H, o, ev)
    # 2) 不可信/未决/延迟过大 → 不交权，严格回退 R69
    if kappa < TAU_ATTR or M.og.tau(u_H.op) < TAU_OP or M.lsc.delay > D_MAX:
        return M.fluid_round(o)
    # 3) 目标权威：策略错/意图变→让权；感知错/指令歧义/人错/对抗→留权
    target = M.om.suggest_alpha(b)                    # C_OP/C_ADV → 1.0（拒绝交权）
    alpha, cmd = M.rae.step(M.alpha, target, u_H, o, dt)
    cert = M.hic.step(M.alpha, alpha, cmd, o)         # 交权证书
    if not cert.valid: return M.fluid_round(o)
    # 4) 定向学习进离线队列（在线零写）
    M.tgu.enqueue(o, u_H, b, kappa)
    # 5) 来源审计 + 证书
    M.lp.append(u_H, b, kappa); M.vqa_c.submit_async(b, kappa, cert)
    return alpha, cmd, cert, b
```

## 3. 推导

**引理 19（归因可辨识性与后验收缩）** 设任一对因 c≠c′ 的证据分布满足 KL(P(e|c)‖P(e|c′)) ≥ δ_e，先验有界。则对 n 次同因校正事件，误归因概率 ≤ exp(−n·δ_e + O(log n))。系 1：**重复且同向的校对比单次校正可归因得多**——这正是「单次接管不改模型」的证据纪律来源；系 2：当 δ_e 很小（证据签名不可分）时，归因本质上不可判，κ_attr 低，CARE 必须不学并回退 R69 去「再问一次」，而不是硬猜。

**引理 20（误归因的定向污染界 / 校正吸收）** 若真实因为 c*，却按 c≠c* 定向更新，则被污染模块的输出误差下界 ≥ β·‖Δa‖·(1−b(c*)) − ε_noise，其中 β 为校正在该模块敏感方向上的投影，且该偏差**不随数据增多而消失**（是系统偏差，不是方差）。系：无归因的学习不是「多学一点噪声」，而是**有偏地学错**——比不学更坏；这是 R69「问错比不问更危险」在学习侧的严格对应。

**引理 21（可逆权威的无源与无突变）** 在 RAE 的速率界、无源存储 V_α 与安全投影下，混合指令的总变差有界：任一区间内 |a_cmd(t+dt)−a_cmd(t)| ≤ ρ_α·dt·‖a_H−a_VLA‖ + margin_proj；交权注入能量 ≤ 无源预算；给定驻留时间，权威轨迹在有限时间内切换次数有限（非 Zeno）。故交权过程控制连续、无可控能量爆增。

**引理 22（操作者信任的加权界）** 设每操作者校正正确率 ρ_op，信任估计 τ_op 经 operator-ECE 校准。则按 τ_op 分配权威的期望安全损失 ≤ (1−τ_op)·ℓ_pol + τ_op·ℓ_op，且在 τ_op < ℓ_pol/(ℓ_pol+ℓ_op) 时**不交权**严格优于交权。这给「权威 vs 建议」的切换一个可计算阈值。

**引理 23（时延补偿的无源性）** 采用波变量/无源前向预测补偿，对 d ≤ d_max，遥操作环路保持无源，存储能量随 d 至多线性增长；d > d_max 时无源余量不足，必须抬高 α（更自主）以维持引理 21。故定义 319 的 d_max 是安全参数，不是工程调参。

**定理 18（CARE 严格包含 FLUID/R68）** 在「不交权 / 归因未决 / 操作者不可信 / 证书失效」边界上，CARE 逐指令派发到 R69 的 FLUID 决策路径；当 FLUID 的 VoI ≤ 成本或 ECE 越界时继续退化为 R68。故任意状态 s 上 CARE 期望风险 ≤ R69 ≤ R68，且安全侧不做任何让步；效率侧只在「可归因、可信、可认证」时获得交权收益。

**定理 19（学习安全与投毒拒绝界）** 在控制通道认证（误接受概率 ε_auth）、归因门（误归因率 ≤ δ_attr）、来源账本回滚下，一条投毒校正进入模型的概率 ≤ ε_auth + δ_attr·ρ_ev + ε_σ；即便进入，其对全局策略的遗憾增量被围栏项 β·r_f 界住，并可按 LP 来源精确撤销。故遥操作无法在纪律下对 VLA 造成不可逆全局投毒。

**定理 20（交权无突变与单调回退）** 由引理 21 + 定义 313d：任一交权序列的指令变差有界；当 {κ_attr 低, τ_op 低, d 过大, 证书失效} 任一触发时，α 朝自主方向**单调不减**（更保守），绝不发生「突然全交」；回升（收权）必须经 shadow 安全预测。故回退方向上安全单调。

## 6. 本轮最大风险

**一句话**：CARE-RAS 的全部学习收益押在「归因可辨识」这一前提上——**但单次遥操作校正在观测上高度混淆**：策略错、感知错、操作者自己错、真实意图变化可以产生几乎相同的 a_H；一旦归因错，系统就会把一条正确的校正学进错误的模块（或把正确校正当真值拒掉），而来源账本还会给这次污染盖上「已审计、可追溯」的合法印章——**它比 R69「问错」更危险，因为它不仅问错，还把错误写进了模型，并让审计为它背书**。

**次级风险与缓解**：
1. **VLA 先验幻觉/延迟**（错误可操作性、指令接地错）→ VP 只作先验、不做安全关键输出；异步动作块 + RAS-WM† 认证 + E301 校准；
2. **权威切换失稳**（跳变、能量注入、回权错位）→ RAE 速率界 + 无源性 + HIC 证书 + 引理 21/定理 20；
3. **操作者过信/过疑** → OG 信任规 + operator-ECE + 引理 22 阈值，低信任自动降级为建议；
4. **遥操作通道攻击**（伪造/重放/权威劫持）→ 通道签名 + 频率限制 + 归因门 + LP 回滚 + E308；
5. **校正吸收/局部过拟合** → 反事实围栏 + 定向更新 + E311 长时程漂移检测。

```python
        return M.fluid_round(o)                                  # 严格回退 R69
    target = M.om.suggest_alpha(b)      # 策略错/意图变→让权；感知/指令/人错/对抗→留权
    alpha, cmd = M.rae.step(M.alpha, target, u_H, o, dt)
    cert = M.hic.step(M.alpha, alpha, cmd, o)
    if not cert.valid: return M.fluid_round(o)
    M.tgu.enqueue(o, u_H, b, kappa)                              # 离线定向学习
    M.lp.append(u_H, b, kappa); M.vqa_c.submit_async(b, kappa, cert)
    return alpha, cmd, cert, b
```

## 4. 推导

**引理 19（归因可辨识性）** 任一对因 `KL(P(e|c)‖P(e|c′))≥δ_e` 时，n 次同因校正的误归因概率 `≤exp(−nδ_e+O(log n))`。系：重复同向校对比单次更可归因（「单次接管不改模型」的根据）；`δ_e` 小则本质不可判，必须不学并回退 R69 再问。

**引理 20（误归因的定向污染界）** 真实因 `c*` 却按 `c≠c*` 更新，被污染模块误差 `≥β‖Δa‖(1−b(c*))−ε`，且为**系统偏差**，不随数据增多消失。系：无归因学习不是加噪，而是有偏学错——比不学更坏（R69「问错比不问更危险」的学习侧对应）。

**引理 21（可逆权威无源无突变）** RAE 速率界 + 无源存储 + 安全投影下，混合指令总变差有界 `|Δa_cmd|≤ρ_α·dt·‖a_H−a_VLA‖+margin`；交权注入能量 ≤ 无源预算；给定驻留时间切换次数有限（非 Zeno）。

**引理 22（操作者信任加权界）** 校正正确率 `ρ_op`、校准信任 `τ_op` 时，期望安全损失 `≤(1−τ_op)ℓ_pol+τ_op ℓ_op`；`τ_op<ℓ_pol/(ℓ_pol+ℓ_op)` 时不交权严格更优——给出「权威↔建议」的可计算阈值。

**引理 23（时延补偿无源性）** 波变量/无源前向预测补偿下，`d≤d_max` 时环路无源、存储能量随 d 至多线性增长；`d>d_max` 必须抬高 α 维持引理 21。故 `d_max` 是安全参数而非工程调参。

**定理 18（CARE 严格包含 FLUID/R68）** 「不交权/归因未决/操作者不可信/证书失效」时逐指令派发到 R69；R69 的 VoI≤成本或 ECE 越界时再退 R68。故任意 s 上 `Risk(CARE)≤Risk(R69)≤Risk(R68)`，安全不让步，效率仅在「可归因、可信、可认证」时获益。

**定理 19（学习安全与投毒拒绝界）** 通道认证（误接受 `ε_auth`）+ 归因门（误归因 `δ_attr`）+ LP 回滚下，投毒进入模型概率 `≤ε_auth+δ_attr ρ_ev+ε_σ`；即便进入，全局遗憾增量被围栏 `β·r_f` 界住，并可按来源精确撤销。

**定理 20（交权无突变与单调回退）** 任一交权序列指令变差有界；`{κ_attr 低, τ_op 低, d 过大, 证书失效}` 任一触发时 α 朝自主方向单调不减（更保守），绝不「突然全交」；回升须经 shadow 安全预测。故回退方向安全单调。

## 7. 本轮最大风险

**一句话**：CARE-RAS 的全部学习收益押在「归因可辨识」这一前提上——**但单次遥操作校正在观测上高度混淆**：策略错、感知错、操作者自己错、真实意图变化可以产生几乎相同的 `a_H`；一旦归因错，系统就会把一条正确校正学进错误模块（或把正确校正当真值拒掉），而来源账本还会给这次污染盖上「已审计、可追溯」的合法印章——**它比 R69「问错」更危险，因为它不仅问错，还把错误写进了模型，并让审计为它背书**。

**次级风险与缓解**：VLA 幻觉/延迟（只作先验 + 异步动作块 + RAS-WM† + E301）；交权失稳（RAE 速率界 + 无源性 + HIC + 引理 21/定理 20）；操作者过信/过疑（OG + operator-ECE + 引理 22 阈值）；通道攻击（签名 + 频率限制 + 归因门 + LP 回滚 + E308）；校正吸收（反事实围栏 + 定向更新 + E311）。
