# 第 55 轮（承接第 54 轮 v16+++ GroundEdge-GenSim+++；新灵感循环第 1 轮；本轮灵感：「上下文理解」×「跨物体泛化」）

> 第 54 轮已把技能组合提升为「动作空间剖面 + 云边协同 + 动作-鲁棒性联合证书 J」。但 ρ 与 α_S 都被默认为**无条件量**。本轮要拆掉这个隐含假设：一切鲁棒性与动作占用都只在某个**上下文 c** 与某个**物体 o** 的条件下成立。核心矛盾：H22：上下文条件鲁棒性——忽略 c 会把「在上下文 A 下鲁棒」误当成「处处鲁棒」，且上下文误识别会让证书静默失效；H23：跨物体泛化——动作剖面 α_S(·|o) 只在物体支撑集 O_S 内可外推，离开 affordance 度量 d_O 的泛化半径即系统性失效。

## 0. 直觉与动机

**灵感 1（上下文是条件随机变量，不是标签）**
直觉：技能 S 的鲁棒性谱 ρ_S(d) 其实是条件谱 ρ_S(d|c) 对上下文分布 P_C 的边缘化。把它写成无条件标量，等价于假设「上下文不变」——这在开放世界里几乎总被违反。正确对象是 **上下文条件谱**：`ρ_S: 𝔇 × C → [0,1]`，部署判据不是单点值，而是 `E_{c~b}[ρ_S(d|c)] ≥ ρ_min` 且上下文敏感度有界。这样「上下文理解」就从感知模块的附属品，变成**鲁棒性证书的前置条件**。

**灵感 2（上下文识别也要证书）**
直觉：运行时机器人并不确知 c，只有后验 `b(c)`。如果 b 过度自信或未标定，那么「条件鲁棒」会在错误上下文下**静默失效**——系统自认为在厨房、实际在实验室。因此必须把 **上下文识别可靠性**（误识别率 `β_C`、标定误差 `ε_cal`、歧义半径 `ε_c`）显式写进证书，并强制「未知上下文即拒识」。

**灵感 3（跨物体泛化 = affordance 度量下的 Lipschitz 外推）**
直觉：`α_S(a)` 应是 `α_S(a|o)`。技能对物体不是「长得像就能用」，而是由 **可操作性嵌入 `φ_O`** 决定。若在 `d_O` 度量下 o′ 距训练物体 o 不超过泛化半径 `r_O`，则动作剖面可被 Lipschitz 界约束；超出支撑集 O_S 就是外推，必须拒绝。跨物体泛化由此从经验口号变成**可计算的迁移间隙 Δ_xo**。

**灵感 4（上下文与物体耦合，不能分开证书）**
直觉：同一个杯子在「厨房」上下文是容器，在「实验室」上下文可能是危险品；上下文改变物体的 affordance 语义。所以 `α_S(a|o)` 实际是 `α_S(a | o, c)` 的投影，上下文与物体必须**联合证书化**，否则两个各自 sound 的证书拼起来可能不 sound。

**灵感 5（金字塔再加一层 𝕏：上下文-物体层）**
直觉：在第 54 轮的动作-协同层 `𝔸` 之上叠加 **上下文-物体层 `𝕏`**：`𝕏_0` 物理感知、`𝕏_1` 上下文识别、`𝕏_2` 物体 affordance、`𝕏_3` 上下文-物体联合泛化。跨层传递证书需同时携带 `ρ(·|c)`、`b(c)`、`α(·|o)`、`r_O`、`Δ_xo`，形成 **上下文-物体-动作-鲁棒性四元证书体系**。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（上下文条件鲁棒性谱）**
上下文空间 `C` 配 σ-代数与分布 `P_C`，上下文随机变量 `c ~ P_C`。技能 S 在维度 d 上的上下文条件谱：
```
ρ_S(d|c) = inf_{δ∈Δ_S(c)} Pr_{x~D_c}[ margin_S(x,d) ≥ δ ]
```
其中 `D_c` 为上下文 c 下的数据分布。**上下文敏感度** `sens_S(d) = sup_{c,c'} |ρ_S(d|c)-ρ_S(d|c')| / d_C(c,c')`。部署条件：`E_{c~b}[ρ_S(d|c)] ≥ ρ_min` 且 `sens_S(d) ≤ s_max`（不允许「靠平均掩盖上下文悬崖」）。

**定义 122（上下文识别可靠性）**
上下文分类器 `f_C: X → Δ(C)` 输出后验 `b(c)=P(c|x)`。给定真实上下文 c：
- 误识别率 `β_C = P_{x~D_c}(argmax b ≠ c)`；
- 标定误差 `ε_cal = sup_b |P(correct | b) - b|`（ECE 型）；
- 歧义半径 `ε_c = sup_{c': b(c') ≥ θ_b} d_C(c,c')`。
**上下文证书** `C_ctx = (ρ(·|c), b, β_C, ε_cal, ε_c)`，可部署当且仅当 `β_C ≤ β_max ∧ ε_cal ≤ ε_cal,max ∧ ε_c ≤ ε_c,max`。

**定义 123（物体条件动作剖面）**
物体空间 `O` 配度量 `d_O` 与 affordance 嵌入 `φ_O: O → ℝ^m`。技能 S 的物体条件动作占用 `α_S(a|o) ∈ [0,1]`。**物体支撑集** `O_S = { o : cover(S, A_T, o) ≥ θ_cov }`。**泛化半径** `r_O(S) = sup{ r : ∀o'≠o, d_O(o,o')≤r ⇒ |α_S(a|o)-α_S(a|o')| ≤ L_O·d_O(o,o') }`。

**定义 124（跨物体泛化证书）**
跨物体迁移间隙：
```
Δ_xo(S, o→o') = E_{a~A_T}[ |α_S(a|o) - α_S(a|o')| ] + |ρ_S(d|o) - ρ_S(d|o')|
```
**跨物体证书** `C_obj = (α(·|o), O_core, r_O, L_O, Δ_xo, evidence)`。泛化成立当且仅当 `o' ∈ O_S ∧ d_O(o,o') ≤ r_O(S) ∧ Δ_xo ≤ Δ_max`。

**定义 125（上下文门控）**
运行时给定上下文后验 b 与目标物体 o，门控：
```
g(b,o) = 1  iff  b(c*) ≥ θ_b ∧ o ∈ O_S ∧ E_{c~b}[ρ_S(d|c)] ≥ ρ_min
```
**误部署率** `P(g=1 | 实际失败)` 与**覆盖率** `P(g=1 | 实际成功)` 构成门控的 Pareto 对。

**定义 126（联合上下文-物体证书）**
在第 54 轮联合证书 `J=(ρ, A_cert, γ_ce, δ_a, evidence)` 上扩展：
```
J' = ( J, C_ctx, C_obj )
C_ctx = (ρ(·|c), b, β_C, ε_cal, ε_c)
C_obj = (α(·|o), O_core, r_O, L_O, Δ_xo)
```
`dom_{J'}(T) = in` 当且仅当 `dom_J(T)=in ∧ c ∈ supp(b) 且 ε_c 有界 ∧ o ∈ O_S`。可部署当且仅当 `δ_a < Θ_a ∧ β_C < β_max ∧ Δ_xo < Δ_max`。**注意**：J′ 不是 J 与 C_ctx、C_obj 的简单拼接，而是要求三者**在同一 (c,o) 切片上共同成立**。

## 2. 关键算法 伪代码

### IP-121 CCC（Context-Conditioned Certificate）

```python
def context_conditioned_spectrum(skill, contexts, dims, data_by_ctx):
    rho = {}
    for c in contexts:
        for d in dims:
            rho[(d,c)] = empirical_quantile(skill, data_by_ctx[c], d, delta=0.05)
    sens = {d: max_ratio(rho, d, metric_C) for d in dims}
    return rho, sens

def context_robust_deployable(rho, sens, belief, rho_min, s_max):
    exp_rho = {d: sum(belief[c]*rho[(d,c)] for c in belief) for d in dims()}
    return all(exp_rho[d] >= rho_min for d in dims()) and \
           all(sens[d] <= s_max for d in dims())
```

### IP-122 CIR（Context Identification Reliability）

```python
def context_certificate(f_C, calib_set, theta_b):
    beta_C = base_rate_misclass(f_C, calib_set)
    ece    = expected_calibration_error(f_C, calib_set)
    eps_c  = max_context_radius(f_C, calib_set, theta_b)   # 后验支撑的直径
    ok = beta_C <= BETA_MAX and ece <= ECE_MAX and eps_c <= EPS_MAX
    return ('ok' if ok else 'reject', CtxCert(beta_C, ece, eps_c))

def open_set_gate(b, theta_b):
    if max(b.values()) < theta_b: return 'unknown_reject'   # 未知即拒
    return max(b, key=b.get)
```

### IP-123 OGP（Object Generalization Profile）

```python
def object_profile(skill, objects, actions, phi_O):
    alpha, support = {}, set()
    for o in objects:
        for a in actions:
            alpha[(a,o)] = skill.occupancy(a, o)
        if cover_check({a: alpha[(a,o)] for a in actions}, TASK_ACTIONS):
            support.add(o)
    return alpha, support

def generalization_radius(alpha, objects, phi_O, L_O):
    r = inf
    for o in objects:
        for o2 in objects:
            if o == o2: continue
            gap = max_alpha_gap(alpha, o, o2)
            r = min(r, gap / (L_O * d_O(phi_O(o), phi_O(o2))))
    return r
```

### IP-124 XOG（Cross-Object Generalization）

```python
def cross_object_certify(skill, o_train, o_test, alpha, support, r_O, L_O):
    if o_test not in support:
        return ('reject', 'out_of_support', o_test)
    if d_O(phi_O(o_train), phi_O(o_test)) > r_O:
        return ('reject', 'beyond_radius')
    delta_xo = action_gap(alpha, o_train, o_test) + rho_drift(skill, o_train, o_test)
    if delta_xo > DELTA_MAX:
        return ('reject', 'gap_exceeded', delta_xo)
    return ('ok', C_obj(alpha, support, r_O, L_O, delta_xo, evidence=(o_train,o_test)))
```

### IP-125 CAG（Context-Aware Gating）

```python
def context_aware_gate(b, o, support, rho_ctx, rho_min, theta_b):
    c_star = max(b, key=b.get)
    if b[c_star] < theta_b:                 return 0
    if o not in support:                    return 0
    if min(expect_rho(rho_ctx, b).values()) < rho_min: return 0
    return 1
```

### IP-126 JCOC（Joint Context-Object Certificate）

```python
def joint_context_object_cert(J, C_ctx, C_obj, delta_a_budget):
    if C_ctx.status != 'ok' or C_obj.status != 'ok':
        return ('reject', 'context_or_object_unsound')
    if not (C_obj.o_test in C_obj.support and C_obj.d_O <= C_obj.r_O):
        return ('reject', 'object_out_of_domain')
    if C_ctx.beta_C > BETA_MAX or C_ctx.ece > ECE_MAX:
        return ('reject', 'context_misidentified')
    if J.delta_a > delta_a_budget or C_obj.delta_xo > DELTA_MAX:
        return ('reject', 'joint_budget_exceeded')
    # 上下文-物体耦合切片一致性：同一 (c,o) 上 rho 与 alpha 必须同域
    if not same_slice(J.rho_domain, C_ctx.c_star, C_obj.o_test):
        return ('reject', 'coupling_slice_mismatch')
    return ('ok', JCert(J, C_ctx, C_obj))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| CCC | O(\|C\|·\|𝔇\|·N_c) | O(\|C\|·\|𝔇\|) | 上下文分层采样充分、敏感度上界 |
| CIR | O(N_cal·\|C\| + N_cal log N_cal) | O(\|C\|) | 后验标定、开集拒识 sound |
| OGP | O(\|O\|·\|A\|) | O(\|O\|·\|A\|) | affordance 嵌入保距、支撑集完备 |
| XOG | O(\|O\|²·\|A\| + \|O_S\|) | O(\|O\|·\|A\|) | d_O Lipschitz、Δ_xo 预算闭合 |
| CAG | O(\|C\|+\|A\|) | O(1) | 门控单调、未知即拒 |
| JCOC | O(\|C\|·\|𝔇\| + \|O\|·\|A\|) | O(\|C\|·\|𝔇\|+\|A\|) | 三证书同切片合取 sound |

**正确性定理（Context-Object Generalization Soundness）**
假设第 53/54 轮 (A22)–(A28) 成立；新增：
**(A29)** 上下文后验标定，`β_C ≤ β_max` 且 `ε_cal ≤ ε_cal,max`；
**(A30)** `φ_O` 与 `d_O` 对 affordance 满足 `L_O`-Lipschitz，且测试物体 `o ∈ O_S`、`d_O(o,o_train) ≤ r_O`；
**(A31)** 上下文-物体耦合映射 `(c,o) ↦ affordance` 在切片上连续。
则部署成功概率：
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a > Θ_a) - β_C - Δ_xo - P(o ∉ O_S)
```
关键：**上下文可识别**、**物体在支撑内且不超泛化半径**、**三者同切片合取**，缺一不可。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 上下文分类器过度自信 | 高 | 温度标定 + conformal prediction + 开集拒识 |
| 上下文分类学不完备（开放世界） | 高 | 未知上下文即拒 + 在线聚类扩展上下文 |
| affordance 嵌入与真实可操作性脱节 | 高 | 主动探针 + 对比学习校准 d_O + 人工审计 |
| 上下文×物体组合爆炸 | 中 | 因子分解 + 切片缓存 + 分层剪枝 |
| 门控过保守导致覆盖率坍塌 | 中 | 误部署-覆盖 Pareto 前沿 + 自适应阈值 |
| 上下文-物体耦合切片不一致 | 高 | 联合证书强制同切片校验 + 负迁移绊线 |

## 6. 本轮最大风险

**一句话**：上下文条件鲁棒性与跨物体泛化把证书从「动作可对齐」推进到「上下文可识别 + 物体在支撑内」，但其 soundness **双重依赖上下文分类器的标定与物体 affordance 度量的保距性**；一旦分类器过度自信、或 d_O 抓不住真实可操作性，联合证书 J′ 就退化成一张「自证的泛化许可证」，系统会在错误上下文与越界物体上自信地部署并负迁移，故必须以 **开集拒识 + conformal 标定 + affordance 主动探针** 三重护栏，未知即拒，绝不把「看起来相似」当作泛化前提。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（CCC×CIR×OGP×XOG×CAG×JCOC）

> 承接第 54 轮产物 v31。本轮在动作空间剖面 + 云边协同体系之上，增加 **上下文条件化、上下文识别证书、物体条件动作剖面、跨物体泛化证书、上下文门控、联合上下文-物体证书** 六个算子：
> - **CCC（Context-Conditioned Certificate）**：鲁棒性谱升级为 `ρ_S(d|c)`，带上下文敏感度；
> - **CIR（Context Identification Reliability）**：上下文后验 `b(c)`、误识别率 `β_C`、标定误差 `ε_cal`、歧义半径 `ε_c`；
> - **OGP（Object Generalization Profile）**：动作剖面升级为 `α_S(a|o)`，定义物体支撑集 `O_S` 与泛化半径 `r_O`；
> - **XOG（Cross-Object Generalization）**：跨物体迁移间隙 `Δ_xo` 与泛化证书 `C_obj`；
> - **CAG（Context-Aware Gating）**：运行时上下文-物体门控，未知即拒；
> - **JCOC（Joint Context-Object Certificate）**：`J′=(J,C_ctx,C_obj)`，要求三证书同切片合取。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-115/118 以纳入上下文与物体维度。

```python
    for o in objects:
        for o2 in objects:
            if o == o2: continue
            gap = max_alpha_gap(alpha, o, o2)
            r = min(r, gap / (L_O * d_O(phi_O(o), phi_O(o2))))
    return r
```

### IP-124 XOG

```python
def cross_object_certify(skill, o_train, o_test, alpha, support, r_O, L_O):
    if o_test not in support:
        return ('reject', 'out_of_support', o_test)
    if d_O(phi_O(o_train), phi_O(o_test)) > r_O:
        return ('reject', 'beyond_radius')
    delta_xo = action_gap(alpha, o_train, o_test) + rho_drift(skill, o_train, o_test)
    if delta_xo > DELTA_MAX:
        return ('reject', 'gap_exceeded', delta_xo)
    return ('ok', C_obj(alpha, support, r_O, L_O, delta_xo,
                        evidence=(o_train, o_test)))
```

## 5. 本轮最大风险

**一句话**：上下文条件鲁棒性与跨物体泛化把证书从「动作可对齐」推进到「上下文可识别 + 物体在支撑内」，但其 soundness **双重依赖上下文分类器的标定与物体 affordance 度量的保距性**；一旦分类器过度自信、或 d_O 抓不住真实可操作性，联合证书 J′ 就退化成一张「自证的泛化许可证」，系统会在错误上下文与越界物体上自信地部署并负迁移，故必须以 **开集拒识 + conformal 标定 + affordance 主动探针** 三重护栏，未知即拒，绝不把「看起来相似」当作泛化前提。
