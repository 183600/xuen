> 本轮纪律：**证书要经得起别人的考卷（密封留出 + 对抗扰动 + 独立裁判复算），协作要同时证"不撞"（安全，可组合）与"不死锁"（活性，不可组合）**。不推倒 v23：CESC/FSVC/IPAM/HPC-E+/CFC+++ 全部保留。本轮只做一件事：**在 v23 的云边-语义-能量证书链之上加一层"锦标赛级 + 联盟级"证书，把"自己测过"升级为"别人复算过、密封留出集上仍成立、且在联盟乘积空间里既安全又前进"，并顺手封堵 v23 的最大风险（T_switch 窗口内分布剧变 × 断联的共振崩塌）**。

## 0. 直觉与动机

**灵感 1（UniBot 世界挑战赛 → 从"自证"到"他证"：锦标赛级证书）**
直觉：v23 的 CESC/FSVC 让证书在**自己的**校准集与云端版本上自洽，但世界挑战赛的语义是：**考卷是别人出的、测试集是留出的、裁判是独立的、对手是对抗的**。一个只在自家排行榜上成立的证书不是证书，是一次押注。由此需要三件 v23 没有的东西：**密封留出集上的泛化下界**（不是经验覆盖，而是"换个留出集还 ≥1-α"的有限样本保证）、**对抗扰动下的认证半径**（不是平均鲁棒，而是半径 ε 内最坏情况仍成立）、以及**裁判可复算**（认证者 ≠ 执行者，日志可被第三方按已提交随机性逐位重放）。核心创新：**锦标赛级证书 (Tournament-Grade Certificate, TGC) + 裁判复算引擎 (Referee Replay Engine, RRE) + 基准溯源账本 (Benchmark Provenance Ledger, BPL)**。关键反直觉点：**公开分与私有效度可能反相关**——你在公开排行榜上越努力，越可能把分布信息"背"进参数里，于是定义 **Goodhart 间隙 Δ_Goodhart = ŝ_pub − ŝ_seal** 作为告警量：证书必须携带"我在密封集上比公开集掉了多少"，而不是只报公开分。

**灵感 2（多机器人协作 → 联盟证书：安全可组合、活性不可组合）**
直觉：前几轮把 N 个机器人当成 N 张独立票（CFC/CFC+/CFC++/CFC+++），这在协作里是错的：共享计划让票**相关**，共享走廊让动作**耦合**。协作真正需要的是**联盟 (coalition) 层面的联合证书**：在乘积配置空间 `X_C = ∏ X_i` 上同时证明（a）任意时刻互不碰撞（含"第三机器人堵住逃生走廊"的高阶情形）、（b）共享资源（走廊/泊位/充电桩）按令牌互斥、（c）互惠义务（"我让你、你也让"）可满足。核心创新：**联盟证书 (Coalition Certificate, CCoal) + 互惠锁与义务协议 (Reciprocal Lock & Obligation Protocol, RLOP) + 活性证书 (Liveness Certificate, LIV)**。关键反直觉点：**安全在组合下单调（交集只会更小），活性在组合下不单调**——两个各自无死锁的机器人可能因对称让行而永久互等。因此安全可以用 ∩ 轻松继承，活性必须用**资源全序 + 确定性优先级让行**单独构造无环等待图；这正是"不撞"与"不死锁"必须分两张证的根本原因。

**灵感 3（协作共识 → 机器人数量 ≠ 证据数量：相关性校正法定人数）**
直觉：CFC+++ 的"计数 ≥ N−F ∧ 模态 ≥ 2"隐含"票独立"。耦合让单因子相关故障（同一光照、同一模型、同一次云推）一次带偏一群机器人，N 张票实际只有 `n_eff = N / (1 + (N−1)ρ̄)` 张独立票。核心创新：**相关性校正法定人数 (Correlation-Adjusted Quorum, CAQ / CFC#)**：以滑动窗口估计平均两两相关 ρ̄，用设计效应 `DE = 1+(N−1)ρ̄` 折算有效样本，法定人数改为 `n_eff ≥ max(N−F, q_min)`。反直觉点：**加机器人不等于加证据**——当 ρ̄ 高时，N 增大几乎不增加 n_eff，反而放大"众口铄金"。

**三者如何统一**
统一为 **v23 之上的"锦标赛-联盟"证书层**：TGC/RRE 回答"这张证书能否被独立第三方在密封留出集上复算通过"，CCoal/RLOP/LIV 回答"这组机器人能否既安全又前进地联合行动"，CAQ 回答"我们到底有几张独立票"。共享状态扩展为 `ζ_coal = ζ_ce ∪ (C, Res, ≺, ≺_R, locks, contracts, W_C, D_seal_hash, ρ̄, n_eff, Log)`。统一准入门 **HPC-C = HPC-E+ ∧ TGC ∧ CCoal ∧ LIV ∧ CAQ**，且 `Exec_v24 = Exec_v23 ∩ Fil_tgc ∩ Fil_coal ∩ Fil_liv ∩ Fil_caq ⊆ Exec_v23`。安全继承由"新增的每个门都是交集/失败即保守"保证；活性则作为**独立的、非单调的**显式证明，绝不被安全继承"顺带"承诺。

## 2. 设计原则（在 P37–P42 基础上新增 P43–P46）

**P43 锦标赛级可复算律（Tournament-Grade Reproducibility）**
证书必须携带三样可被第三方核验的量：**密封覆盖下界** `Cov_LB(D_seal, δ) ≥ 1-α`、**对抗认证半径** `R_adv ≥ ε_req`、**Goodhart 间隙** `Δ_Goodhart ≤ Δ_max`。认证者与执行者分离：所有非确定性（校准集哈希、平滑采样种子、版本五元组 V）写入日志 `Log`，裁判 `RRE` 可按 `Log` 逐位重放并复现 admit/reject。任何一项不满足即拒证。关键：`D_seal` 一旦封存，**永不参与任何选择/调参**，否则 Clopper–Pearson 保证失效。

**P44 协作安全组合律（Collaborative Safety Composition）**
联盟安全只做"加约束"：`Exec_coal(C) = {π_C ∈ ∏_{i∈C} Exec_i : Safe_C(π_C) ∧ Lock_C(π_C) ∧ Contract_C(π_C) ∧ Live_C(π_C)}`，其中 `Safe_C` = 成对间距 + 逃生走廊互斥（高阶），`Lock_C` = 资源令牌不超容，`Contract_C` = 互惠义务可满足。故 `Exec_coal(C) ⊆ ∏_{i∈C} Exec_i`，且成员增减只会收缩或等价，不会放宽单机证书。

**P45 活性不可组合律（Liveness Non-Composition）**
活性必须**单独证明**，绝不由安全继承顺带承诺：`Live(C1) ∧ Live(C2) ⇏ Live(C1∪C2)`。LIV 证书要求等待图 `W_C` 无环；构造性充分条件为：资源按全序 `≺` 获取、机器人按确定性优先级 `≺_R` 让行、且仅低优先级让行。期限义务超时 → 触发角色重分配或可审计 SafeStop 升级，禁止静默死等。

**P46 相关性校正法定人数律（Correlation-Adjusted Quorum）**
共识以**有效独立票数**判定：`n_eff = N / (1 + (N−1)ρ̄)`，要求 `n_eff ≥ max(N−F, q_min)` 且模态数 ≥ 2。ρ̄ 由滑动窗口的两两票相关估计；相关结构变化时 `n_eff` 立即下降、法定人数自动收紧（fail-closed）。加机器人不自动等于加证据。

## 3. 与基线的接口（如何退化）

- TGC 失效（密封集不足/对抗半径不足/复算不一致）⇒ 拒证，退回 v23 的"自证"证书（更不信任，但不放宽执行）；
- CCoal 失效（无法证明联盟安全）⇒ 联盟解散为单机，各自退回 v23 单机证书；
- LIV 失效（等待图有环/无法无环化）⇒ 触发可审计 SafeStop 或角色重分配，绝不放行；
- CAQ 失效（ρ̄ 不可估/样本不足）⇒ 法定人数退回 v23 的 CFC+++（等价 v23）；
- RRE 失效（日志不可复算）⇒ 该步证书降级为"未他证"，只保留 v23 决策；
- 全部失效 ⇒ 完全回退 v23 ⇒ `Exec_v24 ⊆ Exec_v23 ⊆ Exec_v22 ⊆ … ⊆ Exec_v18`。
- **安全继承**：TGC/CCoal/LIV/CAQ 全是交集或失败即保守，任意失效向更保守方向退化；活性是独立附加证明，失效只会导致"停"（仍在安全集内）。

## 4. 预期贡献

1. **锦标赛级证书**：首次把"他证"形式化为密封留出泛化下界 + 对抗认证半径 + 独立裁判复算三件套，并用 Goodhart 间隙显式度量"排行榜过拟合"；

3. **活性不可组合定理与无死锁构造**：证明安全可 ∩、活性不可 ∩，并用资源全序 + 优先级让行构造等待图无环的充分条件；

## 5. 本轮最大风险

**一句话**：把"他证"误当成"真证"——密封留出集与裁判复算只能保证"在封存分布上、按已提交随机性"成立；一旦联盟耦合结构或任务分布漂移快于 ρ̄ 与校准的再估计，证书会在裁判处完美通过、却在当下失效（**过期的他证 + 相关性低估的共识**），机器人会举着锦标赛级证书撞上今天没见过的情形。

## 1. 关键算法骨架（在 IP-425–439 骨架上扩展）

```python
# ============================================================
# IP-440 Tournament-Grade Certificate (TGC) — 锦标赛级证书
# ============================================================
from scipy.stats import beta

def clopper_pearson_lower(k: int, n: int, delta: float) -> float:
    """覆盖率的单侧 (1-delta) 精确下界。k=覆盖数, n=样本数。"""
    if n == 0:
        return 0.0
    if k == 0:
        return 0.0
    return beta.ppf(delta, k, n - k + 1)

class TournamentGradeCertificate:
    def __init__(self, alpha: float = 0.01, delta: float = 1e-3,
                 eps_req: float = 0.05, delta_max: float = 0.03,
                 sigma_smooth: float = 0.25):
        self.alpha = alpha
        self.delta = delta
        self.eps_req = eps_req
        self.delta_max = delta_max
        self.sigma = sigma_smooth

    def issue(self, theta, D_seal, D_pub, detector) -> dict:
        """签发 TGC：密封覆盖下界 + 对抗半径 + Goodhart 间隙。"""
        # 1) 密封留出集覆盖：D_seal 永不参与选择，保证 CP 有效性
        covered = sum(1 for (x, y) in D_seal if detector.covers(theta, x, y))
        n = len(D_seal)
        cov_lb = clopper_pearson_lower(covered, n, self.delta)

        # 2) 随机平滑对抗半径：g(x)=E_{e~N(0,sigma^2)}[person(x+e)]
        pA, pB = self._smoothed_bounds(detector, D_seal, theta)
        R_adv = 0.0
        if pA > 0.5 and pB < 0.5:
            R_adv = (self.sigma / 2.0) * (norm.ppf(pA) - norm.ppf(pB))

        # 3) Goodhart 间隙：公开分 vs 密封分
        s_pub = detector.score(theta, D_pub)
        s_seal = detector.score(theta, D_seal)
        delta_g = s_pub - s_seal

        ok = (cov_lb >= 1 - self.alpha) and (R_adv >= self.eps_req) \
             and (delta_g <= self.delta_max)
        return {
            "cov_lb": cov_lb, "R_adv": R_adv, "delta_goodhart": delta_g,
            "delta_seal_hash": sha256(D_seal), "theta_hash": sha256(theta),
            "ok": ok,
        }

    def _smoothed_bounds(self, detector, D_seal, theta):
        """用 Clopper-Pearson 给平滑后主/次类概率的置信界。"""
        n_s = 1000
        counts = detector.smoothed_person_counts(theta, D_seal, self.sigma, n_s)
        # 返回 (主类概率下界, 次类概率上界)；此处取二分类人/无人
        pA = clopper_pearson_lower(counts.max(), n_s, self.delta)
        pB = 1.0 - clopper_pearson_lower(n_s - counts.min(), n_s, self.delta)
        return pA, pB

# IP-441 Referee Replay Engine (RRE) — 裁判复算引擎
# ============================================================
class RefereeReplayEngine:
    """认证者 != 执行者。裁判只信 Log 与公开规则，按已提交随机性重放。"""
    def __init__(self, public_rules, merkle_verifier):
        self.rules = public_rules
        self.merkle = merkle_verifier

    def replay_step(self, log_entry: dict) -> bool:
        # 1) 校验证书 Merkle 根与版本五元组
        if not self.merkle.verify(log_entry["merkle_certs"], log_entry["V"]):
            return False
        # 2) 用已提交 seed 重建所有非确定性（平滑采样、校准分位数）
        rng = np.random.default_rng(log_entry["seed"])
        # 3) 机械地重算准入（只调用公开规则与证书内容，不读执行者内部状态）
        recomputed = self.rules.admits(
            log_entry["plan"], log_entry["certs"], log_entry["V"],
            rng=rng,
        )
        return recomputed == log_entry["decision"]

    def audit(self, ledger: list[dict], full_sample_rate: float = 0.01) -> dict:
        """O(1) 增量校验 + 抽样全量复算。"""
        inc_ok = all(self.merkle.verify(e["merkle_certs"], e["V"]) for e in ledger)
        sample = [e for e in ledger if rng_random() < full_sample_rate]
        full_ok = all(self.replay_step(e) for e in sample)
        return {"incremental_ok": inc_ok, "sample_full_ok": full_ok,
                "referee_sound": inc_ok and full_ok}

# IP-442/443/444 Coalition + Liveness + RLOP
# ============================================================
class CoalitionCertificate:
    def __init__(self, col_margin: float = 0.1, escape_margin: float = 0.05):
        self.col_margin = col_margin
        self.escape_margin = escape_margin

    def safe_C(self, plans: dict, t_grid) -> bool:
        ids = list(plans)
        # (a) 成对间距
        for a in range(len(ids)):
            for b in range(a + 1, len(ids)):
                i, j = ids[a], ids[b]
                for t in t_grid:
                    d = dist(plans[i].pose(t), plans[j].pose(t))
                    if d < plans[i].radius + plans[j].radius + self.col_margin:
                        return False
        # (b) 逃生走廊互斥（高阶：第三机器人堵住他人的制动逃生集）
        for i in ids:
            esc_i = plans[i].escape_set(t_grid)  # 制动距离内可达的安全集
            for j in ids:
                if j == i:
                    continue
                if esc_i.intersects(plans[j].occupied_set(t_grid),
                                    margin=self.escape_margin):
                    return False
        return True

    def lock_C(self, plans, res: "ResourceTable") -> bool:
        for r in res.resources:
            if len(res.holders(r)) > res.cap(r):
                return False
        # 所有获取顺序必须服从资源全序 ≺（Dijkstra 有序获取）
        for p in plans.values():
            seq = p.acquisition_sequence()
            if any(not res.leq(seq[k], seq[k + 1]) for k in range(len(seq) - 1)):
                return False
        return True

    def contract_C(self, plans, contracts) -> bool:
        # 互惠义务：不得出现对称让行；仅低优先级让行（≺_R）
        for (i, j, tau) in contracts:
            if plans[i].priority ≺_R plans[j].priority:
                if not plans[i].can_yield_within(tau):
                    return False
            # 高优先级方不需让行；对称义务由优先级打破
        return True

    def certify(self, plans, t_grid, res, contracts) -> dict:
        safe = self.safe_C(plans, t_grid)
        lock = self.lock_C(plans, res)
        contract = self.contract_C(plans, contracts)
        return {"safe": safe, "lock": lock, "contract": contract,
                "cc_ok": safe and lock and contract}


class LivenessCertifier:
    def build_wait_for(self, plans, res) -> dict:
        W = defaultdict(set)
        for i, p in plans.items():
            for r in p.pending_resources():
                h = res.holder(r)
                if h is not None and h != i:
                    W[i].add(h)          # i 等持有者 h 释放
            for j in p.yield_targets():   # 让行边：i 让 j
                W[i].add(j)
        return W

    def acyclic(self, W: dict) -> bool:
        WHITE, GRAY, BLACK = 0, 1, 2
        color = defaultdict(int)
        def dfs(u):
            color[u] = GRAY
            for v in W.get(u, ()):
                if color[v] == GRAY:
                    return False
                if color[v] == WHITE and not dfs(v):
                    return False
            color[u] = BLACK
            return True
        return all(color[u] != WHITE or dfs(u) for u in list(W))

    def certify(self, plans, res) -> dict:
        W = self.build_wait_for(plans, res)
        ok = self.acyclic(W)
        # 期限义务超时 → 升级（角色重分配 / SafeStop），不静默死等
        escalate = any(p.deadline_exceeded() for p in plans.values())
        return {"wait_for": W, "live": ok, "escalate": escalate,
                "liv_ok": ok and not escalate}


class ReciprocalLockObligationProtocol:
    """RLOP：有序获取 + 优先级让行 + 期限计数 + 原子移交。"""
    def acquire(self, robot, r, res):
        # 只允许按全序 ≺ 非降序获取；否则阻塞并登记等待边
        if res.next_required(robot) != r:
            res.block(robot, on=res.holder(res.next_required(robot)))
            return False
        return res.try_acquire(robot, r)

    def transfer_on_coalition_change(self, leaving, entering, res):
        # 原子移交：先冻结两方，再在单锁内完成 holders 重映射，最后解冻
        with res.atomic():
            for r in res.held_by(leaving):
                res.holders[r].discard(leaving)
                if entering is not None:
                    res.holders[r].add(entering)
        return True

# IP-445 Correlation-Adjusted Quorum (CAQ / CFC#)
# ============================================================
class CorrelationAdjustedQuorum:
    def __init__(self, N: int, F: int, q_min: float, window: int = 500):
        self.N, self.F, self.q_min = N, F, q_min
        self.history = deque(maxlen=window)  # list of vote vectors

    def estimate_rho(self) -> float:
        if len(self.history) < 30:
            return 1.0  # 样本不足 → 视为完全相关（最保守）
        X = np.asarray(self.history, dtype=float)  # [T, N]
        C = np.corrcoef(X, rowvar=False)
        iu = np.triu_indices(self.N, k=1)
        rho = np.nanmean(C[iu]) if len(iu[0]) else 1.0
        return float(np.clip(rho, 0.0, 1.0))

    def effective_n(self) -> float:
        rho = self.estimate_rho()
        de = 1.0 + (self.N - 1) * rho
        return self.N / de

    def quorum(self, votes: dict, modalities: set) -> bool:
        n_eff = self.effective_n()
        count_ok = n_eff >= max(self.N - self.F, self.q_min)
        modality_ok = len(modalities) >= 2
        return count_ok and modality_ok
```

## 3. 正确性论证

### 引理 A（密封留出集的覆盖保证）
**陈述**：若 `TGC(θ)` 成立且 θ 在 D_seal 封存**之前**固定（D_seal 不参与任何选择/调参），则 `P(Cov_Dseal(θ) ≥ Cov_LB(k,n,δ)) ≥ 1−δ`，从而 `P(Cov ≥ 1−α) ≥ 1−δ`。

**证明**：
1. 覆盖率是 n 个可交换 Bernoulli(1−p) 试验，覆盖数 k 服从 Binomial(n, 1−p)。
2. 单侧 Clopper–Pearson 下界 `Beta⁻¹(δ; k, n−k+1)` 是精确的，满足 `P_p(p ≥ Cov_LB) ≥ 1−δ`（对每个 p 一致）。
3. TGC 要求 `Cov_LB ≥ 1−α`，故 `P(p ≥ 1−α) ≥ P(p ≥ Cov_LB) ≥ 1−δ`。
4. 关键在于 D_seal 封存后不参与选择：若 θ 依赖 D_seal，则覆盖事件与下界不独立，第 2 步失效——这正是"密封"的必要性。∎

### 引理 B（Goodhart 间隙的告警语义）
**陈述**：`Δ_Goodhart = ŝ_pub − ŝ_seal > Δ_max` 表明 θ 在公开集上相对密封集存在超额的性能落差，即公开选择已把公开分布信息"背"入参数；TGC 因此拒证。

**证明**：这是定义性检测（不是覆盖定理）。`Δ_Goodhart` 是选择偏差的可观测代理：在无选择偏差且两集同分布时 `E[Δ_Goodhart]≈0`；当 θ 被公开集过拟合时 `ŝ_pub` 系统性高于 `ŝ_seal`。阈值 Δ_max 给出可调灵敏度。注意它只能**告警**，不能**证明**私有效度——这是本轮保留风险之一。∎

### 引理 C（联盟安全组合律）
**陈述**：`Exec_coal(C) ⊆ ∏_{i∈C} Exec_i`。成员加入/离开只会收缩或保持，不会放宽任何单机证书。

**证明**：
1. `Exec_coal(C)` 的定义含 `π_C ∈ ∏ Exec_i` 作为第一个合取项。
2. 其余项 `Safe_C, Lock_C, Contract_C, Live_C` 均为附加约束，只会进一步求交。
3. 成员加入：`∏_{i∈C∪{k}} Exec_i ⊆ ∏_{i∈C} Exec_i`（多一个因子）且新增约束，故收缩。成员离开：去掉约束，可能扩大——但离开者不再由本证书背书，`Exec_coal(C)` 的论域随之缩小，对留下的计划不产生新的许可。∎

### 引理 D（活性不可组合——反例）
**陈述**：存在联盟 C1、C2 使 `Live(C1) ∧ Live(C2)` 成立但 `¬Live(C1∪C2)`。

**证明（构造）**：两台机器人 R1、R2 在单车道走廊相向而行，各自单独运行时均可在有限时间到达（`Live({R1})`、`Live({R2})`）。协作时施加对称互惠义务 `O_1^2(τ)` 与 `O_2^1(τ)`：双方都在 τ 内让行 ⇒ 双方同时停下等待对方先走。等待图 `W = {R1→R2, R2→R1}` 含 2-环 ⇒ `¬Live({R1,R2})`。故活性不满足组合封闭。∎

### 引理 E（资源全序 + 优先级让行 ⇒ 无死锁）
**陈述**：若（i）所有机器人按资源全序 `≺` 非降序获取资源，（ii）让行只由低优先级机器人执行（优先级 `≺_R` 为严格全序），（iii）期限义务超时触发升级而非无限等待，则等待图 `W_C` 无环，`Live_C` 成立。

**证明**：
1. 资源边：i 等 j 当且仅当 j 持有 i 所需的下一个资源 r。由于按 `≺` 非降序获取，i 已持有的资源均 ≺ r，故 j 持有的 r 满足 i 的等待方向严格沿 `≺` 递增，资源等待边不可能成环。
2. 让行边：i 让 j 仅当 `i ≺_R j`（i 优先级低于 j）。`≺_R` 是严格全序，故让行边严格沿 `≺_R` 递增，亦不可能成环。
3. 两类边各自严格单调；跨类边（i 因让行而等 j，j 又因资源等 k）仍沿两个严格序的字典序 `(≺_R, ≺)` 严格递增，故整体 `W_C` 无环。
4. 超时升级保证不会有"无限等待"被误判为"有限等待"：超过 τ 即转入角色重分配或 SafeStop（SafeStop 属于安全集，不破坏引理 C）。∎

### 引理 F（相关性校正法定人数的安全界）
**陈述**：在单因子相关故障模型下（存在公共故障指示 Z，`P(Z=1)=p_Z`，Z=1 时全体票同时错误），headcount 法定人数 `count ≥ N−F` 可在任意大 N 下被满足而**全部为错**，其概率 ≥ p_Z；改用 `n_eff ≥ max(N−F, q_min)` 后，有效独立票数随 ρ̄→1 收缩至 1，法定人数自动失败（fail-closed）。

**证明**：
1. 若 Z=1，则所有 N 票错误，`count = N ≥ N−F` 恒成立，故 headcount 共识在概率 p_Z 上给出"一致但错误"的结论，与 N 无关。
2. 单因子模型下两两相关 ρ̄ = p_Z/(1−p_Z)·(…) 随 p_Z 单调；设计效应 `DE = 1+(N−1)ρ̄ → N`（ρ̄→1），故 `n_eff = N/DE → 1`。
3. `n_eff ≥ max(N−F, q_min)` 在 ρ̄→1 时要求 `1 ≥ N−F`，当 F<N−1 时失败 ⇒ 拒证。∎
4. 与 v23 的模态多样性（≥2）叠加：即便 n_eff 偶然达标，单一模态的相关故障仍被模态门槛拦截，形成双重防线。

### 引理 G（v24 单调退化链）
**陈述**：任意单点/组合失效下，`Exec_v24 ⊆ Exec_v23 ⊆ Exec_v22 ⊆ … ⊆ Exec_v18` 恒成立。

**证明**：
- TGC 失败 ⇒ 拒证（交集少一项）⇒ 子集。
- CCoal 失败 ⇒ 联盟解散为单机，各机退回 v23 单机证书 ⇒ 子集。
- LIV 失败 ⇒ SafeStop 或角色重分配（停止/降级均在安全集内）⇒ 子集。
- CAQ 失败 ⇒ 退回 CFC+++ 的 headcount（等价 v23）⇒ 子集。
- RRE 失败 ⇒ 该步降级为 v23 决策 ⇒ 子集。
- 组合失效：取交集，单调性保持。∎

### 定理（HPC-C 的锦标赛-联盟完备性）
**陈述**：对任意联盟联合计划 π_C，`HPCC.admits(π_C)=True` ⟺ π_C 同时满足：(1) v23 五证（HPC-E+）；(2) 锦标赛级他证（密封覆盖 ∧ 对抗半径 ∧ Goodhart 间隙）；(3) 裁判可复算；(4) 联盟安全（含高阶逃生走廊）；(5) 活性/无死锁；(6) 相关性校正共识。

**证明**：由 `HPCC.admits` 的六个合取条件直接可得。必要性：任一条件缺失即拒证，对应六类风险之一未被缓解。充分性：六条件全满足，由引理 A–G 给出覆盖、安全组合、无死锁、共识有效性与单调退化链，构成闭环。∎

| R5 | 高阶逃生走廊条件过于保守，联盟规模增大时活性坍缩 | 中 | 1) 逃生集按制动距离分层；2) 仅对相邻机器人检查；3) 允许受控"编队让行"降低互斥 | 狭窄场景仍可能退化为逐一通过，吞吐下降 |

## 6. 本轮最大风险（最终确认）

**一句话**：把"他证"误当成"真证"——密封留出集与裁判复算只能保证"在封存分布上、按已提交随机性"成立；一旦联盟耦合结构或任务分布漂移快于 ρ̄ 与校准的再估计，证书会在裁判处完美通过、却在当下失效（**过期的他证 + 相关性低估的共识**），机器人会举着锦标赛级证书撞上今天没见过的情形。
