# 第 44 轮（新循环第 4 轮） · Fleet-Cert × NL-Ground-Cert：把「多机协同」与「自然语言指令」纳入可验证证书闭环（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 自陈最大风险是「共形只保边际覆盖 + 多用户契约空集」，但它仍压着两个未言明的单点假设：**(H3) 系统被当作单机**——真实部署是机器人舰队，单机证书不能横向组合，协同会引入耦合安全约束、通信时延/分区、共识与死锁；**(H4) 自然语言被默认为已正确落地为形式规约**——NL 有歧义、依赖上下文，落地错误会静默绕过安全域。本轮灵感词「多机协同」「自然语言指令」精确命中这两个假设：**多机协同**把「并发」从单机任务级升级为跨机空间/资源级，证书必须可组合、可分片、可在分区下安全降级；**自然语言指令**把「人」从意图估计升级为「规约来源」，但 NL→形式的落地必须持证（歧义集全覆盖才可执行）。二者耦合处（一条 NL 指令发给多机）是本轮真正的新问题：同一句话被不同机器人落地成不一致的规约，导致协同失效甚至冲突。

## 0. 直觉与动机

**灵感 1（多机协同 → 证书必须可组合，而组合不是简单求交）**：直觉上，两台各自安全的机器人凑在一起不一定安全——都以为自己能先过窄门，结果死锁或相撞。因此单机证书不能「都通过就安全」，必须显式引入**联合约束 J**（互斥资源、安全间距、角色分工），并证明每台机器人在其余机器人的 guarantee 下保持自己的 rely。关键工程点：通信不是瞬时的，邻居状态会陈旧，于是复用 v20 的**租约**思想，把「邻居状态租约」作为 rely 的时间前提；通信分区时不能继续协同，必须落到**分区安全回退**——每台单独进入一个对任意子集都安全的不变集（停在安全位/退回安全区），并为此在协同前预留**回退裕度**。

**灵感 2（自然语言指令 → 落地必须持证，歧义集内全安全才执行）**：直觉上，「把那个红盒子拿过来」在指代不清、位置有歧义时，直接执行可能拿错甚至撞人。于是把 NL→形式规约视为**集合值映射** Ĝ(u)，执行判据不是「选最可能的解释」，而是「**所有可信解释都安全**」（safety-consensus）：只有当所有 φ∈Ĝ(u) 在安全关键谓词上一致、且计划对每个 φ 都安全，才执行；否则主动澄清（问一句把集合缩小）。这与 v20「收缩免费、扩张持证」同构：**执行是收缩（对所有解释都安全），澄清是扩张的代价**。NL 落地错误是「静默」的，必须把歧义显式化，绝不用单一最高概率解释冒充确定规约。

**灵感 3（耦合 → 多机共享落地 / common ground）**：一条指令发给舰队（「你们去左边搜索」），每台各自落地可能得到不同的目标区域、角色、时序。需要**共享落地证书**：在协同关键谓词（角色分配、目标区、时间窗）上，所有机器人的落地集合必须存在**公共解释**（交集非空）；否则不能各自执行，必须走舰队级澄清/协商。同时要防「语义投毒」（某台被误导）与「分区下语义漂移」（两台各自更新了不同的世界模型却继续协同）。

**耦合升级**：FCC（舰队证书组合器）把单机证书 + 联合约束 + 网络租约组合成可验证舰队不变式；NGC（自然语言落地证书）把指令编译为带覆盖保证的规约集合，并给出安全一致执行判据；FNV（舰队-语言验证器）在仿真中枚举多机交错、通信分区、语义歧义与对抗，把反例回灌 CKB/SCV。四层架构由此从 v8 的「单机人格 + 并发」升级为 v9 的「单机证书 + 舰队组合层 + 语言落地层」。

## 1. 形式化定义（增量：定义 44–50）

**定义 44（指令落地证书与歧义集）**：自然语言指令 u∈U，形式规约空间 S，落地映射 Ĝ(u)⊆S 为语义/共形候选集，满足对真实意图 φ*(u) 的覆盖 P(φ*∈Ĝ(u))≥1−α（可交换性 + 校准）。安全关键投影 π_safe: S→P_safe。**安全一致执行判据**：计划 a 可执行当且仅当 (i) ∀φ∈Ĝ(u)，π_safe(φ) 一致（无安全关键分歧）；(ii) ∀φ∈Ĝ(u)，a⊨_safe φ（计划对每个可信解释都安全）。任一失败 → 澄清或安全停机，绝不以 argmax 单一解释放行。**命题（落地 sound）**：若覆盖成立且判据通过，则真实意图 φ* 下不产生安全违例。

**定义 45（网络感知跨机 rely-guarantee）**：舰队 R={r_1..r_n}，每机证书 C_i 与不变式 I_i；共享约束 J（互斥区、最小间距、角色互斥）。每机声明 guarantee G_i 与 rely R_i，但 rely 依赖邻居状态，带**邻居租约** ℓ_j=(x_j,τ_j,λ_j)（复用定义 41 的衰减模型）。**有界陈旧 rely**：R_i 仅在 ∀j≠i，ℓ_j 未过期时成立。**组合可靠性命题**：若 (a) 未过期租约下非干扰 ∀i≠j，G_i⇒R_j；(b) 局部保持 {I_fleet∧R_i} step_i {I_fleet}；(c) 协调协议保持 J，则任意有界时延交错下 I_fleet=⋂_i I_i∩J 保持；时延超过租约则租约过期，转入定义 46 回退。

**定义 46（分区安全回退与联合安全闭包）**：通信图 G_comm(t)，分区为若干连通分量。**分区安全**：存在回退策略 ρ，使对任意分量 S⊆R、任意其余机器人合法动作，执行 ρ 后 I_fleet 仍保持。**联合安全闭包** SafeFallback={x : ∀S，ρ_S(x) 保持 I_fleet}。**命题**：若每台单独回退到「停/退安全区」且 J 在静止点满足，则分区安全；否则必须在协同前预留**回退裕度**（类似 CBF 的安全裕度），把「能否安全退出协同」纳入证书。

**定义 47（共享落地与 common-ground 一致性）**：舰队级指令 u 的共享落地要求存在**公共解释** φ_c∈⋂_i Ĝ_i(u)（协同关键谓词一致）。**一致性判据**：交集非空 → 选 φ_c，所有机执行同一 φ_c 导出的证书；交集为空 → 舰队澄清/协商，禁止各自执行。**语义非干扰**：低关键机（仅对话/个性化）的落地不得写协同关键谓词（角色、目标区、时间窗）。

**定义 48（角色分配证书）**：NL 指令常含角色/任务指派（「你左、你右、你堵门」）。角色映射 σ: Roles→R 需 (i) 单射或完备（无遗漏/无重叠），(ii) 每个角色规约可安全落地，(iii) 角色间约束 J_role 可满足。**证书** RoleCert=(σ,{φ_role},可行性证明)；不满足则澄清「哪个词对应哪台/哪个区域」。

**定义 49（语义租约与语义漂移）**：世界模型/语言上下文随时间漂移，落地集合 Ĝ 与邻居租约都会陈旧。定义**语义租约** (Ĝ,τ_g,λ_g)：若上下文变化速率有界 ||Δctx||≤v_ctx·(t−τ)，取 λ_g=L_g·v_ctx 保证过期判据 sound。过期即重新落地/澄清，不得复用陈旧规约。**推论**：语义租约把「落地时刻」与「执行时刻」解耦，是 NL 指令在动态环境里唯一可被静态审计的新鲜度契约。

**定义 50（舰队级证书一致选择与死锁安全）**：协同规划并行展开联合候选 (β_1..β_n)，每机独立认证 c_i，并联合检查 J。**一致选择**：选 (β_1..β_n) 当且仅当 ∀i，c_i valid ∧ c_i⊆C_i ∧ 联合满足 J ∧ 无等待环；否则回退/协商。**定理**：只选全部有效且联合可行的候选，则舰队执行 sound；资源获取采用全局偏序（如按资源 ID）可消除死锁，等待图无环是充分条件。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 FLEET-CERT-COMPOSER（舰队证书组合器 FCC）
1. **联合不变式组合**：I_fleet=⋂_i I_i∩J；读写集由工具生成，联合约束 J 编译为可检查谓词。
2. **网络感知 rely-guarantee**：邻居状态租约 + 有界陈旧；租约过期即视邻居为「未知」，转回退。
3. **分区安全回退**：SafeFallback 计算 + 协同前回退裕度预留 + 分区检测（心跳/租约）。
4. **舰队一致选择与死锁安全**：联合候选认证、资源全局偏序、等待图无环检查。

### 2.2 IP-61 NL-GROUNDING-CERT（自然语言落地证书 NGC）
1. **落地候选集生成**：LLM 解析 + 本体/语法约束 + 共形校准，输出 Ĝ(u)，维护条件覆盖。
2. **安全一致执行判据**：π_safe 一致 + 全解释安全才执行；否则澄清。
3. **主动澄清**：以信息增益/风险下降最大选择澄清问题，快速缩小 Ĝ。
4. **共享落地与角色分配**：公共解释 φ_c、RoleCert、舰队级语义协商。

### 2.3 IP-62 FLEET-NL-VALIDATOR（舰队-语言验证器 FNV）
1. **多机交错 + 通信分区注入**：按拓扑/时延/丢包枚举分区与恢复。
2. **语义歧义与对抗**：指代投毒、角色混淆、否定/时序陷阱、上下文漂移。
3. **舰队共识/线性一致性审计**：公共解释选择与证书更新序列可线性化。
4. **落地覆盖与澄清效率压测**：实测 Ĝ 条件覆盖、澄清轮数、任务成功率。

## 5. 本轮最大风险

**一句话**：语义落地的「覆盖」与多机「公共解释非空」是两条彼此独立的静默失效通道，叠加通信分区会让「安全一致执行」退化成「各自为政」，因此 E95/E96/E97/E98 必须设为红线实验，且默认回退到「单机收缩证书 + 澄清优先 + 分区即停」这条永不失 sound 的底线。

### IP-60 FCC：组合、网络租约与分区回退
```
def compose_fleet(certs, J, neighbor_leases, now):
    I_fleet = intersect_all([c.I for c in certs]) & J
    for i, c in enumerate(certs):
        for j, lj in neighbor_leases[i].items():
            if lj.expired(now):                              # 邻居未知
                return PartitionFallback(i)                  # 定义 46
        if not rely_holds(c.rely, neighbor_leases[i], now):
            return PartitionFallback(i)
    return I_fleet

def partition_fallback(robot, I_fleet):
    if in_safe_fallback(robot.x, I_fleet):                   # 停/退安全区
        return stop_or_retreat(robot)
    return reserve_margin_violation(robot)                   # 协同前本应预留裕度

def fleet_select(joint_candidates, certs, J):
    valid = [jc for jc in joint_candidates
             if all(c.valid and c.subset(C_i) for c, C_i in zip(jc.certs, certs))
             and J.satisfied(jc) and acyclic(wait_graph(jc))]
    if not valid:
        return negotiate_or_fallback()
    return max(valid, key=joint_score)
```

## 6. 本轮最大风险

**一句话**：语义落地的「覆盖」与多机「公共解释非空」是两条彼此独立的静默失效通道，叠加通信分区会让「安全一致执行」退化成「各自为政」，因此 E95/E96/E97/E98 必须设为红线实验，且默认回退到「单机收缩证书 + 澄清优先 + 分区即停」这条永不失 sound 的底线。
