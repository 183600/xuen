# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「机器人竞赛」×「热管理」）

> R69 让系统学会了「问」，但它只回答了「该向谁求证」，没有回答「**我还剩多少本钱去求证、去冒险、去赢**」。R69 的预算全是抽象的：单位时间 ≤1 次交互、位移 ≤ ε_g、社交成本 ≤ c_max；它默认算力恒久、关节力矩恒定、传感器噪声不随工况变化。真实机器人不是这样：持续冲刺会发热，发热让 GPU 降频、电机降额、相机热漂移；而**热是慢变量、跨子系统共享、且不可逆**。更尖锐的是，R69 自陈的最大风险——缓变故障被标定吸收——在热域有一个近乎完美的现实实例：热致传感器偏置与执行器增益漂移恰恰是缓慢的，COF 会把它们解释掉。
>
> 而「竞赛」给这条研究线注入了一个此前完全缺席的东西：**保守本身也会输**。R66–R69 的目标始终是「在安全前提下尽量不犯错」；但比赛的目标是「在绝不越线的硬约束下把分拿到」。二者不是一回事：为了赢，系统必须**主动花掉一部分安全裕度去换性能**（冲刺、抢位、逼抢），同时又必须保证那部分裕度永远花不完——否则一次冲刺就会把前几轮辛苦守住的底线烧穿。
>
> 本轮把两个灵感合成一条主轴：**热是竞赛中的货币、证人与软肋**。
> - 作为**货币**：热预算有限、可跨子系统转移、有记忆；冲刺与交互都要花它。R69 的「抽象交互预算」因此被替换为**物理热预算**，「何时冲刺、冲多久」变成一个带**硬安全储备约束**的有限时程最优控制问题，其解由**热影子价格 μ_T** 刻画。
> - 作为**证人**：热力学第一定律提供一个标定**无法吸收**的独立残差通道。COF 能改写传感器模型参数，却改写不了能量守恒；于是 (r_res↓, Δa≈0, r_therm↑) 成为「被标定掩盖的热致缓变故障」的判别指纹，正面补 R69 的洞。
> - 作为**软肋**：降额可被对手利用——逼你追、堵你散热、在你热峰时发力（热 DoS）。竞赛层因此必须有对手感知的热节奏博弈（RACE）与裁判审计（REF）。
>
> 核心命题：**把「安全约束（硬、永不交易）」与「性能风险（软、可按热影子价格交易）」彻底分开；用热影子价格把 R69 的 epistemic 消解动作按焦耳定价；用第一定律做不可吸收的第三通道；用安全储备硬约束保证任何冲刺都不烧穿底线。** 命名 **MATCH-RAS**（Match-Aware Thermal-Coupled Hierarchical Risk-Adaptive Safety）。
>
> 一句话定位：R66 问「谁控制」，R67「未来怎样」，R68「我的测量还准吗」，R69「我该向谁求证、还能问什么」，R70 问「**我的本钱还够不够问、够不够冲，什么时候该冲、冲完还剩不剩保命的那一口气**」——不确定性之外还有预算，安全之外还有胜负。

## 0. 直觉与动机

**灵感 1（机器人竞赛 → 保守会输，必须把硬约束与软风险分开）**
直觉：前四轮把「不确定 → 收紧」当作美德，但在比赛里，处处收紧等于把冠军让出去。真正的竞赛策略不是「最安全」，而是「**在不被取消资格的前提下把期望得分做大**」。因此需要一次概念切换：把约束分成两类——**硬约束**（不碰撞、不失稳、不越过热极限与安全储备）永远不可交易；**软风险**（走更快的路径、用更强的动作、在歧义未完全消解时先做）则是可以用期望得分去买的东西。R68 的 λ_floor 从此不再是一块固定的地板，而是「性能风险的价格」：安全侧不动，性能侧按赛况浮动。这是本轮最重要的姿态——**不是把安全换成分数，而是把「可花的安全裕度」与「不可花的安全底线」显式分开**。

**灵感 2（热管理 → 热是慢的、共享的、有记忆的货币）**
直觉：电池、GPU、电机、相机共用同一套散热，且温度是**积分量**：一次冲刺的后果不会立刻消失，而是以几十秒到几分钟的热时间常数衰减。于是「当前温度」就是过去所有决策的压缩记忆，而「热余量」就是可冲刺的体力条。热的三个性质决定了它的地位：(a) 守恒 → 可审计；(b) 慢 → 可预测、可规划、也可被「标定吸收」；(c) 耦合 → 传感器、算力、执行器不是独立预算，而是同一笔钱的不同口袋。R69 的「算力预算」在这里第一次有了物理价格。

**灵感 3（耦合 R69 → epistemic 消解有焦耳价格，推迟会欠下认知债）**
直觉：R69 的交互是「免费的智能」——它从不问一次注视、一次探针、一次 LLM 问句要耗多少电、发多少热。把热价接进去，VoI 判据就变成 `VoI(g) − c(g) − μ_T·q(g)`：**不是所有正 VoI 的交互都值得做，尤其当你很热的时候**。但这里藏着一个陷阱：因为热而推迟消歧，不是「回到 R68 的保守」，而是**借了一笔债**——未消解的歧义会随状态发散与截止临近而**计息**，并且往往在你最热、最不能出错的关键时刻到期。所以本轮必须同时记账两笔债：热债 D_th 与认知债 D_epi。**只省热、不还认知债的调度，会把小歧义滚成大崩盘。**

**灵感 4（热漂移 → 第一定律是不可吸收的证人）**
直觉：摩擦增大、散热堵塞、功率器件老化，都会让系统在同样指令下更热；而热又反过来让传感器偏置、电机增益漂移。COF 看到的是「传感器读数与模型不符」，它会调参数把残差抹平——这正是 R68/R69 最怕的「缓变故障被解释掉」。但**功率与温度的账本对不上**这件事，不是靠改传感器模型能掩盖的：能量守恒给出一条与控制标定近正交的通道。更进一步，可以主动打一个**有界、安全、已认证的热脉冲**，测它的温度响应（时间常数 τ_th 与增益 G），像敲击测结构一样给热系统做「指纹」。若 (τ_th, G) 的漂移与能量残差同向，就可把「真漂移」与「热致效率退化」分开。妙处在于：**「测自己还剩多少体力」本身也是一次有热价的信息动作**，于是 TIR 递归地落回 R69 的 VoI 框架——自知也要付得起。

**灵感 5（竞赛对抗 → 热 DoS、沙袋与裁判）**
直觉：一旦热=体力，对手就有了新武器：逼你追（持续高负载）、堵你散热（占住通风位/在旁边加温）、在你热峰时进攻（趁你降额）；弱队还可能「沙袋」——故意示弱诱你多花体力。这些都是 R69 的 ℰ_poison 里没有的**物理层攻击**。所以竞赛层需要 (a) 对手感知的热节奏博弈 RACE：若我热裕度领先，就**提节奏逼对手降额**；若落后，就**守住、把决战放到对手热峰**；(b) 裁判 REF：审计储备是否被违反、是否沙袋、温度是否被欺骗。热不只是一种资源，也是一种**可以被竞争的资源**。

## 1. 形式化定义（增量：定义 310–327）

**定义 310（MATCH-RAS 总览与不变式）** MATCH-RAS = (TMM, TSP, TVOI, TDC, TAR, TED, RACE, REF, RAS-WM‡)。五条不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **硬安全储备不变式**：任意计划 π 在执行后必须满足 H_i(t) − R_safe,i(t) ≥ 0；违反者**否决**而非罚分（定义 322）；
(iii) **热预算记账**：每一次计算/感知/执行/信息动作都从其子系统热账户扣款，无免费动作（定义 311）；
(iv) **证据纪律**继承 R69 定义 293-iii（k 个正交证据源一致才定案）；
(v) **严格包含**：当散热 → ∞、子系统解耦、热价 → 0 时，逐步退化为 FLUID-RAS（定义 327）。

**定义 311（耦合热状态与热账户）** 子系统 i ∈ {compute, sense, actuate, comm} 的温度满足
C_i Ṫ_i = P_i^{gen}(a, c, g) − Σ_{j≠i}(T_i − T_j)/R_{ij} − (T_i − T_amb)/R_i^{amb}，
其中 P_i^{gen} 由任务动作 a、计算配置 c（含 K、N_step、模型档、精度）、信息动作 g 决定。离散化 T_{t+1} = A T_t + B P_t + E T_amb + w_t，A 的特征值 <1 给出热记忆时间常数 τ_th。热账户 D_th,i(t) = ∫_0^t (T_i(s) − T_nom,i)_+ / ΔT_i^ref ds 记录「已花的体力」与需要的恢复量。

**定义 312（热致能力包络）** 热不是外挂模块，它改写前几轮的全部输入：执行器 τ_max,i(T) = τ_0,i · d_τ(T)（降额，d_τ 非增）；计算时延 L(c;T) = L_0(c) · κ(T)（κ ≥ 1，降频）；传感器噪声 σ_s(T) = σ_0(1 + β_s max(0, T − T_ref))、偏置 b_s(T)。于是可行动作集 𝒜(T) = {a : τ(a) ≤ τ_max(T)}，R69 的 U_ale 变成 U_ale(T)，实时预算变成 L(c;T) ≤ B_rt。**热是 R68/R69 所有子模块的参数，而不是它们旁边的新模块**。

**定义 313（热余量、热债与安全储备）** 热余量 H_i = T_limit,i − T_i；热债 D_th,i 如定义 311。安全储备 R_safe,i(t) 定义为执行**任意安全机动** m ∈ M_safety（急停、后退、脱离接触）在最坏环境温度与最坏对手加热下所需温升的最大值再加模型不确定裕度：R_safe,i = max_m [ΔT_i(m) + γ·σ_model]。冲刺可行 ⇔ H_i − q_i(sprint) ≥ R_safe,i。**储备是硬边界，余量才是可花的钱。**

**定义 314（赛况状态、得分敏感度与关键时刻）** 赛程视界 T_end（可含资格赛→决赛的多回合与冷却窗口），状态 (S_t, O_t) 为比分与对手状态。得分敏感度 ρ(t) = ∂E[比分]/∂(可用能力)；关键时刻 t* 由 R67 世界模型 + 对手模型预测的边际性能收益给出：criticality(t) = ρ(t)·perf_gap(t)，t* = argmax criticality。RACE 与 TSP 都以 criticality 为输入的「何时值得花」。

**定义 315（热影子价格与冲刺调度 TSP）** 求解有限时程问题
max E[Σ_t ρ(t)·u(a_t)]  s.t. 定义 311 的动力学、T_i ≤ T_limit,i、H_i − q ≥ R_safe,i。
其拉格朗日乘子 μ_T(t) ≥ 0 即**热影子价格**（每焦耳额外热所换掉的未来得分）。冲刺 a_s 相对保守 a_c 被选中 ⇔ E[ρ·Δperf(a_s,a_c)] ≥ μ_T·q(a_s,a_c)，且硬储备检查通过。等价最优性条件：所有被激活的冲刺窗口的「单位热量边际得分」相等（KKT/ Pontryagin）。储备约束紧时 μ_T → ∞，冲刺自动停止。

**定义 316（按焦耳定价的 VoI，TVOI）** 信息动作 g 的热成本 q(g) 由定义 311 的产热模型给出且随 T 变化（越热效率越差）。选择
g* = argmax_g [ VoI(g) − c(g) − μ_T·q(g) − μ_D·δ_debt(g) ]，
s.t. risk(g) ≤ ε_int、预算未超、储备可行、C-RAS-WM 认证通过。若 ≤0 或储备不可行，则不交互。**当 μ_T = μ_D = 0 时逐项退化为 R69 定义 298。**

**定义 317（认知债账本 TED）** 未消解 epistemic 的债务 D_epi(t) = ∫_0^t U_epi^{unres}(s)·e^{ρ_epi(t−s)} ds，离散为 D ← (1+ρ_epi)D + U_epi^{unres}；利率 ρ_epi 随状态发散速度与截止临近而升高。推迟一次交互的省热为 μ_T·q(g)，但其代价是债务现值增加；只有当**省下的热价 > 债务利息的期望现值 + 在降额态被迫还债的风险**时，推迟才被允许。定义「债务到期事件」= 关键时刻 t* 上 U_epi > 阈值且 T 处于降额区；REF 对此审计。

**定义 318（热自适应计算配置 TAR）** 给定热余量与降频状态，选择 c = (K, N_step, 模型档, 精度)：
c* = argmax_c utility(c)  s.t. L(c;T) ≤ B_rt 且 q_compute(c) ≤ available_heat(T)。
降级顺序固定为 K: 4→2→1、N_step: 2→1、tier: full→lite、precision: fp16→int8，且**绝不降到实时安全可执行档以下**。这把 R69 的 P99 保证从「常温假设」变成「热态仍成立的显式保证」。

**定义 319（热-标定对偶 TDC：第一定律残差）** r_therm = C_eff·Ṫ_meas + (T_meas − T_amb)/R_eff − P_meas^{elec}。在**A99**（存在至少一个不进入 COF 标定图的热/功率测量通道，如独立热电偶、IR 或电机电阻估计）与**A100**（准静态效率模型）下，任何满足 r_res = 0 的标定 θ̂ 都不改变 r_therm 的期望值。因此热致效率退化（摩擦↑、散热堵塞、热偏置）表现为 **r_res↓、Δa 小、r_therm↑** 的联合模式，补上 R69 定义 301/309 之后的**第三条正交通道**。

**定义 320（热脉冲指纹 TIR）** 标称热传递 h_0 由 (τ_th = R·C, G) 参数化。当 TDC 存疑或周期到期，在低风险窗口施加**有界、已认证**的热脉冲（已知的计算/力矩脉冲），估计 (τ̂_th, Ĝ) 并与 h_0 比对：散热堵塞 → τ̂↑、Ĝ↑；摩擦增大 → Ĝ↑；温度传感器欺骗 → Ĝ 与能量账本不自洽。脉冲本身是信息动作，有热价 q(probe) 与元 VoI；仅当 meta_VoI(probe) > μ_T·q(probe) 才执行（定义 316 的递归）。**「测自己的体力」也要值这个价。**

**定义 321（对抗热模型 AIC-MATCH）** ℰ_MATCH = ℰ_FLUID × ℰ_thermal，ℰ_thermal = {热 DoS（逼追/持续高负载）, 散热破坏（堵风道/占据冷却位/外部加温）, 温度传感器欺骗, 沙袋诱敌}。对手热注入有界 ‖u_adv‖ ≤ U_max，目标是最大化「热越限/降额致败」的概率。

**定义 322（硬储备约束与「绝不烧穿底线」）** 对所有 t 与任意计划 π：H_i(t) − R_safe,i(t) ≥ 0，且**预测执行后**仍 ≥ R_safe,i + margin。违反 ⇒ 否决冲刺、退回保守；若已因对手加热进入违反区 ⇒ 触发应急协议：卸载非安全负载（禁用信息动作、计算降到最低档、降速），并认证一条逃生机动。**这是硬约束，不进入效用函数。**

**定义 323（对手感知热节奏博弈 RACE）** 两玩家随机博弈 G = (S, A_self, A_opp, P, payoff)，状态含 (T_self, T_opp, S, t)，payoff 为胜率。定性策略：令 ΔH = H_self − H_opp，若 ΔH > 0 且对手临近关键段，则**提节奏**逼其降额；若 ΔH ≤ 0，则**守势、蓄热、把决战推迟到对手热峰**；否则稳态。离线求均衡策略、在线做带安全底线的 best response。

**定义 324（竞赛裁判 REF）** 审计：储备是否被违反、热债/认知债账本是否诚实、是否沙袋、温度是否被跨通道欺骗、冲刺是否「花大热换小分」。结论回灌为下一轮 TSP/TVOI 的成本先验。R69 的 VQAuditor-I 是其交互审计子模块。

**定义 325（证书 J_MATCH）** J_MATCH = (J_FLUID, T_profile_hash, reserve_min, D_th, D_epi, derating_events, μ_T_trace, r_therm_trend, debt_due_events, match_ver, referee_verdict)。Valid ⇔ Valid(J_FLUID) ∧ 储备从未被违反 ∧ TDC 自洽 ∧ 热账本平衡 ∧ 无未决违规。

**定义 326（分层时间尺度分离）** 三个环路：**战略层**（每场/每节，分钟级）TSP+RACE 算出准静态热影子价格 μ_T 与节奏；**战术层**（每个决策，10–100ms）TVOI+TAR+R69；**反射层**（亚毫秒）C-RAS-WM + 储备否决。分层成立的条件是 τ_th ≫ 决策周期，可用奇异摄动/双时间尺度分析；**反射层永不等待战略层**，安全自治。

**定义 327（严格包含接口）** 退化极限：散热 → ∞、R_ij → 0、τ_th → 0、μ_T → 0、q → 0 ⇒ TSP 退化为空操作、TVOI 退化为 R69 的 MINT、TAR 取常温档、TDC 退化为 FMA、RACE 退化为空操作 ⇒ MATCH-RAS 与 FLUID-RAS **逐指令相同**；再叠加 R69 的 VoI ≤ 成本 ⇒ R68。故 **R68 ⊂ R69 ⊂ R70**，且安全侧单调不降。

## 2. 关键算法骨架

```python
# IP-264 TMM：耦合热模型 + 温度观测器（热是 R68/R69 的参数，不是外挂）
class ThermalMatchModel:
    def predict(self, T, plan):                  # plan 含任务/计算/信息动作
        P = [self.gen_power(u) for u in plan]    # 产热向量
        return rollout_linear(self.A, self.B, self.E, T, P)
    def headroom(self, T):  return self.limits - T
    def reserve(self, T, match_state): return self.R_safe_fn(T, match_state)
    def available_heat(self, T): return self.headroom(T) - self.reserve(T, ...)

# IP-265 TSP：热影子价格 + 冲刺调度（硬储备是约束，不是罚项）
def shadow_price(T, t, match, mu_critic):
    return max(0.0, mu_critic(T, t, match))     # 离线 critic，在线兜底见定义 326

def choose_sprint(T, cands, mu_T, msm):
    best = None
    for a in cands:
        q = msm.heat(a)
        if not reserve_ok(T, q, a, msm):        # 冲完仍要留 R_safe
            continue
        util = msm.criticality() * perf_delta(a) - mu_T * q
        if best is None or util > best.util: best = (a, util)
    return best[0] if best and best.util > 0 else conserve()

def reserve_ok(T, q, a, msm):
    T_after = msm.TMM.predict(T, [a])[0]
    return all((msm.limits - T_after) >= msm.reserve(T_after, msm.match_state))

# IP-266 TVOI：按焦耳定价的交互（μ_T=μ_D=0 时即为 R69 MINT）
def choose_interaction_thermal(modes, w, o, T, mu_T, mu_D, budget, debt):
    best = None
    for g in info_action_candidates(modes):
        if not budget.allow(g, T) or not c_ras_wm.certify_info(g, o): continue
        if not reserve_ok(T, heat(g), g, msm): continue
        voi   = entropy(w) - expected_entropy(w, g, o)
        score = voi - cost(g) - mu_T*heat(g) - mu_D*debt.marginal(g)
        if best is None or score > best.score: best = (g, score)
    return best[0] if best and best.score > 0 else None

# IP-267 TED：认知债（推迟消歧不是保守，是借款，且计息）
class EpistemicDebt:
    def __init__(self, rho_fn): self.D, self.rho_fn = 0.0, rho_fn
    def step(self, U_epi_unres, t):
        self.D = (1 + self.rho_fn(t)) * self.D + U_epi_unres   # 越近关键时刻利息越高
        return self.D
    def marginal(self, g): return self.resolvable(g) * self.D_rate

# IP-268 TAR：热自适应计算（把 P99 保证从常温假设变成热态保证）
def thermal_compute_config(T, rt_budget):
    for c in TIERS:                              # K,N_step,tier,precision 由强到弱
        if latency(c, T) <= rt_budget and heat(c) <= available_heat(T):
            return c
    return MIN_SAFE_TIER                         # 绝不低于实时安全可执行档

# IP-269 TDC：第一定律残差（标定不可吸收的第三通道）
def thermo_residual(T_meas, T_amb, P_elec, C_eff, R_eff):
    return C_eff*dT(T_meas) + (T_meas - T_amb)/R_eff - P_elec

def tdc_suspect(r_res, a_score, r_therm, delta_a, trend):
    return (r_res < TAU_RES) and (delta_a < TAU_A) and (trend(r_therm) > TAU_THERM)

# IP-270 TIR：热脉冲指纹（自知也是有热价的信息动作）
def thermal_probe(T, msm, window, mu_T):
    g = make_bounded_heat_pulse()
    if not window.safe() or not reserve_ok(T, heat(g), g, msm): return None
    if meta_VoI(g, T) <= mu_T*heat(g): return None        # 测体力先算值不值
    return estimate_tau_gain(msm.execute(g))              # (τ_th, G) 指纹

# IP-272 RACE：对手感知的热节奏
def race_policy(msm, mu_T):
    dH = msm.headroom_self() - msm.headroom_opp()
    if dH > 0 and msm.criticality_soon(): return raise_pace()      # 逼对手降额
    if dH <= 0:                           return conserve_and_defend()
    return steady()

# IP-275 主闭环（R69 闭环 + 热层；热层只改预算与阈值，不改安全语义）
def MATCH_RAS_round(M, obs):
    # 0) 热先改写能力包络与所有预算
    T = M.tmm.observe(obs); derate = M.tmm.derate_map(T)
    mu_T = M.tsp.shadow_price(T, M.t, M.match, M.mu_critic)
    # 1) R69 在热修正后的包络内运行；TAR 决定 K/N_step
    z, o = M.mtm.forward(obs, derate)
    c = M.tar.compute_config(T, M.rt_budget_at(T))
    samples = M.fmp.sample(o, c.K, c.N_step)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    # 2) 第三通道：第一定律残差（补 R69 的标定吸收洞）
    r_th  = M.tdc.residual(...); a_hat = M.fma.flow_anomaly(...)
    fault = M.tdc.suspect(M.last_r_res, a_hat, r_th, M.last_delta_a, M.trend)
    # 3) 认知债记账 + 按焦耳定价的交互
    debt = M.ted.step(U_epi, M.t)
    g = (M.tvoi.choose(modes, ..., T, mu_T, M.ted, M.budget)
         if (U_epi > TAU_EPI and not fault) else None)
    U_epi_after = M.cia.update_belief(modes, M.cia.execute(g)) if g else U_epi
    # 4) 冲刺：硬储备 + 影子价格；故障时只保守
    cur = M.conserve if fault else M.tsp.choose_sprint(T, M.candidates, mu_T, M.msm)
    # 5) 风险缩放（U_ale 已含热噪声）
    U_floor = U_ale + (U_epi_after if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), M.lam_floor(U_floor))
    if fault: lam = max(lam, 0.8)
    # 6) 认证：储备是硬不变量，越界就收缩而不是冒险
    A = M.ach.propose(cur, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    if not M.reserve.ok(T, cur, k): k = M.c_ras_wm.shrink_to_reserve(A, k, T)
    tau = M.pi_sigma.prefix_dispatch(cur.a[:k]) * lam * derate.torque
    # 7) 裁判审计 + 证书
    M.ref.submit(g, cur, mu_T, M.ted, r_th, M.match)
    return k, lam, cur, (U_ale, U_epi_after), mu_T
```

## 3. 推导

**引理 19（冲刺阈值与边际热收益均衡）** 在得分-能力关系凹、热动力学线性、储备约束凸的 A95–A97 下，最优冲刺调度的 KKT 条件给出：被激活的每个冲刺窗口的「单位热量边际得分」相等，且等于热影子价格 μ_T(t)；冲刺当且仅当 ρ(t)·Δperf ≥ μ_T·q。μ_T 随热余量单调不增、随未来临界度单调不减。系：**关键时刻冲刺、空档期蓄热**；均匀用力在 criticality 随时间变化时严格次优——这正是赛车「进站/配速」策略的形式化。

**引理 20（热定价 VoI 与推迟的代价）** 采用定义 316 的判据，存在温度阈值 T* 使 T > T* 时即使 VoI>0 的交互也被推迟。若调度**忽略认知债项 μ_D**，则存在环境族（状态发散快 + 截止临近 + 热时间常数长）使期望损失随赛程增长而无界：省下的热价是 O(μ_T·q)，而到期债务按 e^{ρ_epi·Δt} 复利，且到期点恰好落在降额区（定义 317 的债务到期事件）。反之，含债账本的调度把损失压到「储备约束最优 + O(ε_ident)」。**这条引理说明认知债不是修辞，是必须进目标函数的一项。**

**引理 21（第一定律的标定不可吸收性）** 设 θ̂ 为满足传感器残差 r_res = 0 的任意标定。若真实故障改变机电效率 η（摩擦↑/散热堵塞），则由定义 319、A99–A100，能量残差满足 E[r_therm] ≥ (1 − η_fault/η_0)·P_mech − noise，且该下界与 θ̂ 无关（只要功率/温度通道不在 COF 的标定图内）。故 (r_res↓, Δa≈0, r_therm↑) 是 R68/R69 都不具备的判别方向。系：TIR 的 (τ_th, G) 漂移给出故障**类型**（堵塞 vs 摩擦 vs 传感器欺骗），而 r_therm 只给「有故障」。

**引理 22（对抗热可达性与主动储备）** 设对手热注入有界 U_max、散热 D(T)。若在 T = T_limit − R_safe 处 U_max > D(T)，则对手能在有限时间内把系统推入储备违反区；因此**任何只靠反应式降额**的策略都不安全。安全策略必须维持主动裕度 R_safe ≥ ∫_{0}^{τ_lead}(U_max − D(T))dt，其中 τ_lead 为对手最短加热提前量。系：热 DoS 的可行性判据是「对手能否跑赢散热」；防御 = 预防性蓄热 + 散热优先 + 规则层判罚（RACE/REF）。

**定理 18（MATCH-RAS 严格包含 FLUID-RAS）** 在 A95–A100 与定义 327 的退化极限下，MATCH-RAS 的两层策略与 FLUID-RAS **逐指令相同**；R69 的全部保证（定义 293 不变式、定理 16–17）被保留。反过来，FLUID-RAS 没有 μ_T，无法在热约束下分配冲刺，故存在竞赛场景使 MATCH-RAS 在**同等安全**下取得更高期望得分。于是 R68 ⊂ R69 ⊂ R70，安全侧单调不降、性能侧严格增强。

**定理 19（热安全、无突变与保守回退）** 在硬储备不变式（定义 322）、TAR 单调降级与每档仍过 C-RAS-WM 认证下：(i) 有界对抗加热且 R_safe 满足引理 22 时，热极限永不被违反；(ii) 降额映射单调且 Lipschitz，档位切换有滞回分隔 ⇒ 力矩/速度连续、无突变；(iii) 一旦 TDC 判故障或储备被威胁，λ 单调升至 R68 保守水平、全部信息动作被否决。故安全侧 MATCH ≥ FLUID ≥ R68。

**定理 20（双债无免费午餐）** 若调度只贴现热、不贴现认知债，则存在环境族使总期望损失随视界增长而无界（即使温度始终有界）；含债感知的调度（定义 317）则可把损失界在「储备约束最优 + O(ε_ident)」内。**推论：省热与还债必须在同一目标函数里结算，否则「省下的热」会以「关键时刻的认知崩盘」加倍偿还。**

## 6. 本轮最大风险

**一句话**：MATCH-RAS 第一次把「安全裕度」当成**可以花出去的预算**——全部胜负押在热模型与对手模型对「储备还剩多少」的估计上；一旦估计偏乐观（热参数漂移、散热被堵、温度被欺骗），系统就会在自以为还有余量时冲刺，恰好把储备烧穿在最需要保命的那一刻——**为了赢而主动越过的，正是前几轮用保守主义死死守住的底线**。

**次级风险与缓解**：
1. **热模型误差 / 参数漂移** → 在线辨识 + TIR 指纹 + 保守裕度 γσ_model；储备不足即 veto（定义 322）；
2. **认知债利率 ρ_epi 难估** → 上限纪律：未消解 U_epi 超阈值时禁止冲刺，优先还债（定义 317）；
3. **温度传感器欺骗** → 多通道交叉验证（能量守恒 / 电机电阻估计 / IR），RACE 与 REF 检测（定义 319、324）；
4. **影子价格 critic 分布外失效** → 回退到保守常数 μ_T^max + always-conserve，安全侧不受损（定理 19）；
5. **降额档位切换抖动** → 滞回 + Lipschitz 平滑 + 定理 19 的连续性保证；
6. **赛事规则不确定 / 沙袋争议** → REF 审计并把「规则未知」当作硬约束优先，安全 > 公平 > 得分。

## 2. 形式化定义（要点版）

**定义 310（总览与五不变式）** 实时零学习写；**硬安全储备不变式**（执行后 H−R_safe ≥ 0，违反者否决而非罚分）；**热预算记账**（无免费动作）；证据纪律继承；**严格包含**（散热→∞ 退化 R69）。

**定义 311–312（耦合热与能力包络）** `C_i Ṫ_i = P_i^{gen}(a,c,g) − Σ_j(T_i−T_j)/R_ij − (T_i−T_amb)/R_i^amb`；热改写 `τ_max(T), L(c;T), σ_s(T), b_s(T)`，故 `U_ale=U_ale(T)`、实时预算 `L(c;T)≤B_rt`。**热是前几轮所有模块的参数。**

**定义 313–314（余量/储备/赛况）** `H_i=T_limit,i−T_i`；`R_safe,i=max_m[ΔT_i(m)+γσ_model]`；冲刺可行 ⇔ `H_i−q_i ≥ R_safe,i`；criticality(t)=ρ(t)·perf_gap(t)。

**定义 315（TSP 热影子价格）** `max E[Σ ρ·u]` s.t. 热动力学 + 极限 + 硬储备；冲刺 ⇔ `ρ·Δperf ≥ μ_T·q`；最优时各激活冲刺窗口的单位热量边际得分相等；储备紧 ⇒ μ_T→∞。

**定义 316（TVOI）** `g*=argmax[VoI−c−μ_T q−μ_D δ_debt]`，s.t. 安全/预算/储备/认证；≤0 或储备不可行则不交互；μ_T=μ_D=0 即 R69 MINT。

**定义 317（双债）** `D_epi ← (1+ρ_epi)D_epi + U_epi^{unres}`；推迟省热为 `μ_T q`，代价是债务现值；债务到期事件 = 关键时刻 U_epi 超阈且处于降额区。

**定义 318（TAR）** `c*=argmax utility(c)` s.t. `L(c;T)≤B_rt`、`q_compute(c)≤available_heat(T)`；降级顺序 K:4→2→1、N_step:2→1、tier、precision，且有安全下限。

**定义 319–320（TDC/TIR）** `r_therm=C_eff Ṫ_meas+(T_meas−T_amb)/R_eff−P_meas^{elec}`；A99/A100 下对任意 `r_res=0` 的标定不变 ⇒ 热致故障联合模式 `(r_res↓, Δa≈0, r_therm↑)`；TIR 用有界认证热脉冲估计 `(τ̂_th, Ĝ)` 区分堵塞（τ↑,G↑）/摩擦（G↑）/传感器欺骗（能量不自洽）。

**定义 321–322（对抗与硬储备）** `ℰ_MATCH=ℰ_FLUID×ℰ_thermal`；对所有计划 `H_i−R_safe,i≥0` 且预测执行后仍留 margin，违反则否决/收缩/触发应急降载。

**定义 323–325（RACE/REF/J_MATCH）** 两玩家随机博弈 ΔH>0 提节奏、ΔH≤0 守势待热峰；REF 审计储备/双债/沙袋/温度欺骗；J_MATCH 并入热剖面、reserve_min、μ_T 轨迹、r_therm 趋势。

**定义 326–327（分层与严格包含）** 战略（分钟，TSP+RACE）/战术（10–100ms，TVOI+TAR+R69）/反射（亚毫秒，认证+储备否决），反射层不等待战略层；散热→∞、μ_T→0、q→0 时逐指令退化为 FLUID-RAS，再叠加 VoI≤成本退化为 R68。

## 3. 关键算法伪代码

```python
# IP-264 TMM：热是 R68/R69 的参数，不是旁挂模块
class ThermalMatchModel:
    def predict(self, T, plan):
        P = [self.gen_power(u) for u in plan]
        return rollout_linear(self.A, self.B, self.E, T, P)
    def reserve(self, T, m): return self.R_safe_fn(T, m)
    def available_heat(self, T, m): return (self.limits - T) - self.reserve(T, m)

# IP-265 TSP：硬储备约束下的冲刺调度
def choose_sprint(T, cands, mu_T, msm):
    best = None
    for a in cands:
        if not reserve_ok(T, msm.heat(a), a, msm): continue
        util = msm.criticality()*perf_delta(a) - mu_T*msm.heat(a)
        if best is None or util > best.util: best = (a, util)
    return best[0] if best and best.util > 0 else conserve()

def reserve_ok(T, q, a, msm):
    T2 = msm.TMM.predict(T, [a])[0]
    return all((msm.limits - T2) >= msm.reserve(T2, msm.match_state))

# IP-266 TVOI + IP-267 TED：按焦耳定价、按认知债贴现
def choose_interaction_thermal(modes, w, o, T, mu_T, mu_D, budget, debt):
    best = None
    for g in info_action_candidates(modes):
        if not budget.allow(g, T) or not c_ras_wm.certify_info(g, o): continue
        if not reserve_ok(T, heat(g), g, msm): continue
        score = (entropy(w) - expected_entropy(w, g, o)
                 - cost(g) - mu_T*heat(g) - mu_D*debt.marginal(g))
        if best is None or score > best.score: best = (g, score)
    return best[0] if best and best.score > 0 else None

class EpistemicDebt:
    def step(self, U_unres, t):
        self.D = (1 + self.rho_fn(t))*self.D + U_unres; return self.D

# IP-268 TAR：热态下的实时保证
def thermal_compute_config(T, rt_budget):

        if latency(c, T) <= rt_budget and heat(c) <= available_heat(T): return c
    return MIN_SAFE_TIER

    return r_res < TAU_RES and delta_a < TAU_A and trend(r_therm) > TAU_THERM

# IP-270 TIR：自知也要值这个价
def thermal_probe(T, msm, window, mu_T):
    g = make_bounded_heat_pulse()
    if not window.safe() or not reserve_ok(T, heat(g), g, msm): return None
    if meta_VoI(g, T) <= mu_T*heat(g): return None
    return estimate_tau_gain(msm.execute(g))

# IP-272 RACE：热节奏
def race_policy(msm):
    dH = msm.headroom_self() - msm.headroom_opp()
    if dH > 0 and msm.criticality_soon(): return raise_pace()
    if dH <= 0: return conserve_and_defend()
    return steady()

# IP-275 主闭环（R69 + 热层；热层只改预算/阈值，不改安全语义）
def MATCH_RAS_round(M, obs):

    mu_T = M.tsp.shadow_price(T, M.t, M.match, M.mu_critic)
    z, o = M.mtm.forward(obs, derate)                        # 热修正的条件编码

         if (U_epi > TAU_EPI and not fault) else None)
    U_epi = M.cia.update_belief(modes, M.cia.execute(g)) if g else U_epi
    cur = M.conserve if fault else M.tsp.choose_sprint(T, M.candidates, mu_T, M.msm)
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), M.lam_floor(U_floor))
    if fault: lam = max(lam, 0.8)
    A = M.ach.propose(cur, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    if not M.reserve.ok(T, cur, k): k = M.c_ras_wm.shrink_to_reserve(A, k, T)
    tau = M.pi_sigma.prefix_dispatch(cur.a[:k]) * lam * derate.torque
```

## 4. 推导

**引理 19（冲刺阈值与边际热收益均衡）** 凹得分、线性热动力学、凸储备约束下，KKT 给出：被激活冲刺窗口的单位热量边际得分相等且等于 μ_T(t)；冲刺 ⇔ `ρ·Δperf ≥ μ_T·q`。μ_T 随热余量单调不增、随临界度单调不减。系：关键时刻冲刺、空档蓄热；均匀用力在 criticality 时变时严格次优（形式化的赛车配速策略）。

**引理 20（热定价 VoI 与推迟代价）** 存在 T* 使 T>T* 时正 VoI 交互也被推迟。若忽略 μ_D，存在环境族（状态发散快 + 截止近 + τ_th 长）使期望损失随赛程无界：省热 O(μ_T q)，债务按 `e^{ρ_epi Δt}` 复利，且到期点落在降额区。含债账本则损失限于「储备最优 + O(ε_ident)」。**认知债必须进目标函数。**

**引理 21（第一定律不可吸收）** A99–A100 下，任意 `r_res=0` 的标定 θ̂ 都满足 `E[r_therm] ≥ (1−η_fault/η_0)P_mech − noise`，与 θ̂ 无关。故 `(r_res↓, Δa≈0, r_therm↑)` 是 R68/R69 不具备的判别方向；TIR 的 `(τ_th,G)` 进一步给出故障类型。

**引理 22（对抗热可达性）** 若 `U_max > D(T_limit−R_safe)`，对手可在有限时间内推入储备违反区；只靠反应式降额不安全。安全裕度须满足 `R_safe ≥ ∫_0^{τ_lead}(U_max−D)dt`。系：热 DoS 判据为「对手能否跑赢散热」，防御 = 预防蓄热 + 散热优先 + 规则判罚。

**定理 18（严格包含）** 定义 327 退化极限下 MATCH-RAS 与 FLUID-RAS 逐指令相同，R69 全部保证保留；反之 FLUID-RAS 无 μ_T 不能分配冲刺，存在同等安全下得分更高的竞赛场景。故 **R68 ⊂ R69 ⊂ R70**。

**定理 19（热安全、无突变、保守回退）** 硬储备 + TAR 单调降级 + 每档认证 ⇒ (i) 有界对抗加热且 R_safe 满足引理 22 时热极限永不违反；(ii) 降额单调 Lipschitz、档位滞回 ⇒ 控制连续无突变；(iii) TDC 判故障或储备受威胁时 λ 单调升至 R68、信息动作全否决。安全侧 MATCH ≥ FLUID ≥ R68。

**定理 20（双债无免费午餐）** 只贴现热、不贴现认知债 ⇒ 存在环境族使总损失随视界无界（即使温度有界）；含债调度则界在「储备最优 + O(ε_ident)」。**省下的热会以关键时刻的认知崩盘加倍偿还。**

## 7. 本轮最大风险

**一句话**：MATCH-RAS 第一次把「安全裕度」当成**可以花出去的预算**——全部胜负押在热模型与对手模型对「储备还剩多少」的估计上；一旦估计偏乐观（热参数漂移、散热被堵、温度被欺骗），系统就会在自以为还有余量时冲刺，恰好把储备烧穿在最需要保命的那一刻——**为了赢而主动越过的，正是前几轮用保守主义死死守住的底线**。

**次级风险与缓解**：热模型误差/参数漂移（在线辨识 + TIR + γσ_model，储备不足即 veto）；认知债利率难估（未消解 U_epi 超阈即禁止冲刺、优先还债）；温度欺骗（能量守恒/电机电阻/IR 多通道交叉 + RACE/REF）；影子价格 critic 分布外失效（回退保守常数 μ_T^max + always-conserve）；降额切换抖动（滞回 + Lipschitz + 定理 19）；规则不确定/沙袋争议（REF 审计，安全 > 公平 > 得分）。
