# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 1 轮（新循环）；本轮灵感：「意图识别」×「物体泛化」）

> 第 54 轮把技能组合建立在动作空间剖面 `α_S`、组合图 `G_S`、云边契约 `C_ce` 与联合证书 `J=(ρ,A_cert,γ_ce,δ_a)` 上。但整个体系默认了两个从未被检验的前提：**任务/意图 `T` 是正确、唯一且已给定的**；**物体 `o` 的实例与类别符号是固定的**。真实交互中，「把那个拿过来」里的意图 `I` 与指称物 `o` 是同一个待定变量的两面，物体的一次实例替换、位姿变化或类别漂移都会悄悄改变意图的可满足性。本轮把 **意图识别** 重写为**意图-物体联合接地消歧**，把 **物体泛化** 重写为**证书沿物体扰动群的等变迁移**。核心矛盾：H22：脱离物体接地的意图识别是不适定的，`res_intent=1` 不蕴含 `res_joint=1`；H23：物体泛化不是免费迁移，证书在物体轨道上非等变时 `ρ` 与 `α_S` 会系统失真；H24：意图错误与物体错误相互混淆，分别校准的两个模块会产生"双重自信"的假安全。

## 0. 直觉与动机

**灵感 1（意图识别 = 联合接地消歧，而非标签分类）**
直觉：用户说"把那个杯子拿过来"时，"那个"指哪个杯子、它算杯子还是碗，与"拿过来"这个意图是耦合的。若把意图识别做成一个 softmax 分类器、把物体识别做成另一个检测器，再相乘，就会漏掉"意图标签相同但指称物不同 → 计划/证书不同"的情形。正确对象不是意图标签 `I`，而是联合假设 `h=(I,β,κ)`（意图、指称绑定、类别指派）。识别的目标是把这个联合假设按"计划 + 证书签名"压到单一等价类，而不是把 `I` 分类对。

**灵感 2（物体泛化 = 沿扰动群的证书等变迁移，而非分布外硬试）**
直觉：一把技能在训练实例上成功，不代表换一个同类别实例、转 30°、换纹理、或换成相邻类别后仍成立。物体之间的差异可以被一个**扰动群** `𝒢_obj` 组织：位姿、光度、实例替换、类别替换。物体泛化于是有了可判定的形式：**证书在该群生成的轨道上是否保持（近似）等变**。若技能的占用剖面 `α_S` 与鲁棒性谱 `ρ` 随群作用近似等变，则证书可沿轨道迁移；否则泛化半径 `r_obj` 被等变缺陷 `ε_eq` 直接截断。这把"泛化"从口号变成"轨道内可证明、轨道外必须弃权"。

**灵感 3（意图-物体混淆 → 必须联合校准，不能相乘边际）**
直觉：把"碗"看成"杯子"可能被解释成另一个意图，把"拿"听成"放"也可能被归因成物体选错。两类错误在观测上常常不可分。若分别校准意图后验和物体后验再相乘，得到的是"两个边际都自信"的假联合分布；一旦存在相关性（例如大而深的容器既像碗又像"收纳"意图），联合可信集 `ℋ_α` 会低估真实歧义。必须直接对 `(I,β,κ)` 建后验，并在不可辨识时显式弃权。

**灵感 4（接地探针 = 用安全动作购买意图-物体信息）**
直觉：当联合商 `res>1` 时，系统可以花一次真实动作去消歧——凑近看标签、轻推看是否空、抬一下估重量、或直接询问。这些动作本身就是第 54 轮意义下的动作序列，因此必须先用 `J` 证明**对 `ℋ_α` 内每个假设都安全**，再谈信息价值。探针的选择是"安全约束下最大化联合决策增益/成本"，而不是自由的信息论游戏。

**灵感 5（意图-物体层的金字塔扩展）**
直觉：在第 54 轮动作层 `𝔸` 之上加一层**物体接地层 `𝕆`**：`𝕆_0` 多模态物体感知，`𝕆_1` 物体描述子与轨迹，`𝕆_2` 扰动群与轨道，`𝕆_3` 意图-物体联合商。跨层证书同时携带 `(J, b, ℋ_α, Q, 𝒢_obj, r_obj, ε_eq, Δ_obj)`：动作层保证"做得到"，物体层保证"对的东西在轨道内仍做得对"。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（联合意图-物体假设与信念）**
直觉：意图与物体指称是一个联合隐变量，先建联合后验，再谈任何单边结论。
设潜在联合假设 `h=(I,β,κ)`，其中 `I∈ℐ` 为意图，`β: ℛ→𝒪` 为指称表达式到物体轨迹的绑定，`κ: 𝒪→𝒞` 为物体类别指派。多模态观测史 `o_{1:t}`（语言、视觉、本体感受），联合信念 `b_t(h)=P(h|o_{1:t})`。可信集 `ℋ_α(b_t)` 为按后验降序、后验质量和首次达到 `1-α` 的最小假设集合。校准条件：`P(h*∈ℋ_α)≥1-α`，`h*` 为真实联合假设。开放世界下另设物体 OOD 分数 `ood_obj_t∈[0,1]` 与类别本体不完备标记。

**定义 122（决策相关接地商）**
直觉：只在"会改变可部署计划或其证书"的维度上区分联合假设。
设规划映射 `Π: ℋ→Plans∪{⊥}`，`⊥` 表示无可行计划。定义等价关系 `h≈_Π h'` 当且仅当 `Π(h)=Π(h')` 且两者证书签名 `sig(J_IO)` 相同（签名含物体轨道证书）。商空间 `Q=ℋ_α/≈_Π`，分辨率 `res=|Q|`。**意图-物体联合接地**即通过观测/探针把 `res` 降到 1；若只能降到 `res>1`，必须给出对所有单元都成立的鲁棒计划 `π_R` 或弃权。记 `res_intent` 为仅按意图标签 `I` 做商的**意图单边分辨率**。

**定义 123（物体扰动群与轨道）**
直觉：物体泛化的"邻域"应由真实世界会发生的变换生成，而不是任意噪声。
物体扰动群 `𝒢_obj` 由四类生成元张成：(i) 位姿 `g_pose∈SE(3)`；(ii) 光度/纹理 `g_app`；(iii) 同类别实例替换 `g_inst`；(iv) 相邻类别替换 `g_cat`。设物体描述子 `d: 𝒪→ℳ` 与群度量 `d_𝒢`，轨道 `Orb_r(o)={g·o : d_𝒢(g,e)≤r}`。**物体泛化半径** `r_obj` 为证书仍有效的最大半径。

**定义 124（物体等变缺陷与泛化缺口）**
直觉：泛化能不能迁移，取决于技能在群作用下是否"换个物体还是同一套动作语义"。
设技能 `S` 的动作剖面（定义 115）为 `α_S(a|h)`。等变缺陷
```
ε_eq(g) = sup_{a∈A_core} | α_S(g·a | g·h) - α_S(a | h) |
```
泛化缺口
```
Δ_obj(d; r) = sup_{g: d_𝒢(g)≤r} | ρ_S(d | g·o) - ρ_S(d | o) |
```
证书可迁移条件：`ε_eq(g) ≤ ε_max` 且 `Δ_obj(d;r) ≤ Θ_obj(d)` 对所有维度 `d` 成立。直观上 `ε_eq` 是"物体换了个样子，动作语义是否还对得上"的硬边界。

**定义 125（意图-物体证书）**
直觉：一张证书要么覆盖整个联合可信集并在物体轨道内有效，要么诚实地说"我还不知道/还没泛化"。
意图-物体证书 `J_IO=(J, b, ℋ_α, Q, res, 𝒢_obj, r_obj, ε_eq, Δ_obj, δ_IO, ood_obj, e_ev)`，其中 `J` 为第 54 轮联合证书，`e_ev` 为可选证据账本。`J_IO` **有效**当且仅当：
```
(i)  ∀q∈Q, ∀h∈q: J 对 Π(h) 有效（逐单元 soundness）；
(ii) res=1，或存在鲁棒计划 π_R 使 max_{h∈ℋ_α}(1-succ(π_R,h)) ≤ δ_IO；
(iii) 轨道有效：ε_eq ≤ ε_max 且 Δ_obj(d;r_obj) ≤ Θ_obj(d) ∀d；
(iv) ood_obj ≤ θ_ood，且类别本体未报"未知类别"。
```
部署条件：`(i)∧(ii)∧(iii)∧(iv)`；否则输出 `abstain` 或继续 `GAP` 探针。`deploy`（唯一单元）、`deploy_robust`（鲁棒计划）与 `abstain` 都是**合法且可审计**的输出。

**定义 126（接地探针与安全约束）**
直觉：探针是"能改变联合后验、且自身通过证书"的动作，其价值按联合决策风险下降计。
接地探针 `e=(A_e,𝒴_e,c_e,Safe_e)`：`A_e⊆A` 为动作序列，`𝒴_e` 为结果空间，`c_e` 为成本，`Safe_e=1 ⇔ ∀h∈ℋ_α, J(Π_e,h)` 有效且 `α_S` 覆盖 `A_e`。令联合风险 `R_IO(b;Π)=Σ_{h∈ℋ_α} b(h)(1-succ(Π(h),h))`，决策增益 `DG_IO(e|b)=R_IO(b;Π)-E_{Y_e}[R_IO(b|Y_e;Π)]`，选择分数 `score(e)=DG_IO(e|b)/c_e`。规划问题为
```
min_{e_1..e_k,τ} E[Σ_{k<τ} c(e_k) + λ(1-succ(π_τ,h*))]
s.t. Safe_{e_k}=1; Σc(e_k)≤B; τ=min{k: res(Q_k)=1 ∨ π_R feasible}
```

## 2. 关键算法 伪代码

### IP-121 IOBS（Intent-Object Belief State）

```python
def joint_belief(lang, vision, tracks, H_intent, H_bind, object_db, alpha=0.05):
    hyps = {}
    for I in H_intent.candidates(lang):
        for beta in H_bind.bindings(lang, tracks):
            kappa = object_db.categorize(beta)
            p = H_intent.likelihood(I, lang) * H_bind.likelihood(beta, vision, tracks)
            hyps[Hyp(I, beta, kappa)] = p
    b = normalize(hyps) if sum(hyps.values()) > 0 else hyps
    return BeliefState(b=b, H_alpha=credible_set(b, alpha),
                       ood_obj=object_db.ood_score(vision))
```

### IP-122 JOGQ（Joint Object-Intent Grounding Quotient）

```python
def grounding_quotient(H_alpha, planner, cert):
    cells = {}
    for h in H_alpha:
        pi = planner(h)
        sig = ('abstain',) if pi is None else (
            pi.id, cert.signature(pi, h), orbit_key(pi, h))
        cells.setdefault(sig, []).append(h)
    return [frozenset(v) for v in cells.values()]

def intent_only_quotient(H_alpha, planner):
    cells = {}
    for h in H_alpha:
        pi = planner((h.I, None, None))
        cells.setdefault('abstain' if pi is None else pi.id, set()).add(h.I)
    return [frozenset(v) for v in cells.values()]

def res(Q):
    return len(Q)
```

### IP-123 OEC（Object Equivariance Certificate）

```python
def equivariance_defect(skill, h, group, A_core, n=128):
    worst = 0.0
    for g in group.sample_orbit(n):
        for a in A_core.sample():
            d = abs(skill.alpha(g.act(a), g.apply(h))
                    - skill.alpha(a, h))
            worst = max(worst, d)
    return worst

def orbit_certificate(skill, o, group, radius, rho_dims, eps_max, thetas):
    orbit = group.orbit(o, radius)
    delta = {d: max(abs(skill.rho(d, g*o) - skill.rho(d, o)) for g in orbit)
             for d in rho_dims}
    eps = max(equivariance_defect(skill, Hyp(None, o, None), group,
                                  skill.A_core) for o in orbit)
    ok = eps <= eps_max and all(delta[d] <= thetas[d] for d in rho_dims)
    return OrbitCert(orbit=orbit, delta=delta, eps_eq=eps, ok=ok)
```

### IP-124 GAP（Grounding-Aware Probing）

```python
def plan_grounding_probes(b, cells, probes, budget, shield, planner):
    plan, spent = [], 0.0
    while res(cells) > 1 and spent < budget:
        cand = []
        for e in probes:
            if not shield.safe_for_all(e, b.H_alpha):   # 安全先于信息
                continue
            if e.cost > budget - spent:
                continue
            dg = expected_grounding_gain(e, b, cells, planner)
            cand.append((dg / max(e.cost, 1e-12), dg, e))
        if not cand:
            break
        _, dg, e = max(cand, key=lambda t: t[0])
        if dg <= 0:                                     # 信息已无决策价值
            break
        plan.append(e); spent += e.cost
        # 执行后：b = joint_belief(...); cells = grounding_quotient(...)
    return plan, spent, cells

def expected_grounding_gain(e, b, cells, planner):
    r0 = joint_risk(b, cells, planner)
    return r0 - sum(P(y | e, b) * joint_risk(update(b, e, y), cells, planner)
                    for y in e.outcomes)
```

### IP-125 IOC（Intent-Object Certificate）

```python
def intent_object_certificate(J, b, planner, cert, group, r_obj,
                              delta_IO, theta_ood, eps_max):
    if b.ood_obj > theta_ood or b.unknown_category:
        return ('abstain', 'open_world', b.ood_obj)
    Q = grounding_quotient(b.H_alpha, planner, cert)
    if len(Q) == 1:
        h0 = next(iter(Q[0]))
        oc = orbit_certificate(skill_of(planner(h0)), h0.beta, group,
                               r_obj, rho_dims, eps_max, thetas)
        if not oc.ok:
            return ('need_probe', 'object_orbit_gap', oc)
        return ('deploy', J_IO(J, b, Q, oc))
    pi_R = robust_plan(Q, planner)
    if pi_R is not None and worst_case_failure_IO(pi_R, b.H_alpha) <= delta_IO:
        return ('deploy_robust', J_IO(J, b, Q, pi_R))
    return ('need_probe', Q)
```

### IP-126 OGG（Object Generalization Guard）

```python
def object_generalization_guard(desc, category_db, conformal_p,
                                radius_est, r_max, theta_p=0.05):
    novel = category_db.is_novel(desc)
    p = conformal_p(desc)
    if novel or p <= theta_p or radius_est > r_max:
        return ('abstain', 'object_shift', novel, p, radius_est)
    return ('ok', p, radius_est)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| IOBS | O(|ℐ|·|ℛ|·|𝒪|·|𝒞|) | O(|ℋ|) | 联合校准、可信集覆盖率 |
| JOGQ | O(|ℋ_α|·(plan+cert)) | O(|ℋ_α|) | 签名稳定、商划分 sound |
| OEC | O(n·|A_core|·|𝒢_obj|) | O(|A_core|+|𝒟_ρ|) | 轨道采样覆盖、等变缺陷保守 |
| GAP | O(k·|ℰ|·|ℋ_α|·|𝒴|) | O(|ℰ|·|ℋ_α|) | 安全盾 sound、DG 自适应子模 |
| IOC | O(|Q|·cert + |ℋ_α|) | O(|Q|+|ℋ_α|) | 逐单元 sound、轨道证书闭合 |
| OGG | O(1) 增量 | O(1) | 共形覆盖、未知类别漏检受控 |

**正确性定理（Intent-Object Grounding Certification Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** 联合校准：`P(h*∈ℋ_α) ≥ 1-α`；**(A30)** `ℋ_α` 上联合假设闭合（真实意图-物体绑定未被漏掉）；**(A31)** 每单元计划证书失败率 `≤ δ`；**(A32)** 轨道覆盖：`h*` 的物体落在 `Orb_r(o)` 内且估计等变缺陷满足 `ε_eq≤ε_max`，违反概率 `≤ β_obj+β_eq`；**(A33)** 每个执行的探针 `e` 均通过 `J` 且动作被 `α_S` 覆盖，安全盾假阴性率 `≤ β_probe`；**(A34)** 物体描述子度量与轨道半径估计校准。则
```
P(部署后失败) ≤ α + δ + β_ood + β_obj + β_eq + β_probe
```
若预算耗尽仍未把 `res` 压到 1 且无鲁棒计划，系统输出 `abstain`，故上界约束的是**所有实际部署**的轮次。

**命题 1（意图-物体纠缠下界）**
存在开放式操作域使 `res_intent=1` 而 `res_joint=|𝒞_obj|`（同一意图标签下不同类别/实例对应不同计划或证书）。因此仅按意图单边签发的证书在该域上不 sound；`res_intent` 不能替代 `res_joint`。

**命题 2（等变缺陷截断泛化半径）**
若存在 `a∈A_core` 使 `ε_eq(g) ≥ 2θ_cov`，则沿 `g` 的轨道上覆盖谓词 `cover(S,A_T)` 会翻转，证书不可迁移。故物体泛化半径满足 `r_obj ≤ sup{r : ε_eq(g)≤ε_max ∀d_𝒢(g)≤r}`。这说明"泛化半径"不是超参，而是等变性质的推论。

**命题 3（弃权诚实性）**
若 `ood_obj>θ_ood`、或轨道证书无效、或无可证书鲁棒计划，`IOC` 必输出 `abstain` 或 `need_probe`；因此"沉默失败"只能来自 `β_ood/β_obj/β_eq` 的漏检，而不能来自证书逻辑本身。

## 4. 实验设计 E162–E168

| 实验 | 指标 | 目标 |
|---|---|---|
| E162 联合接地校准 | 联合 ECE、`ℋ_α` 覆盖率 | ECE ≤ 0.05，覆盖率 ≥ 1-α |
| E163 纠缠压力测试 | `res_intent=1` 但 `res_joint>1` 的失败率 vs 单边基线 | 单边证书失败率显著更高，联合方案 ≤ α+δ+β |
| E164 物体轨道泛化 | 成功率 vs 半径 `r`；成功率 vs `ε_eq` | 半径内成功率下降 ≤ 10%，与 `ε_eq` 强相关 |
| E165 意图-物体证书有效性 | 部署失败率 vs 单意图/单物体证书 | 失败率 ≤ α+δ+β，显著优于基线 |
| E166 探针安全与效率 | 不安全探针率、达 `res=1` 的成本 | 不安全率 = 0，成本开销 ≤ 15% |
| E167 未知类别压力 | 新类别弃权召回、误自信率 | 召回 ≥ 90%，误自信 ≤ 5% |
| E168 消融 | 去 IOBS / 去 JOGQ / 去 OEC / 去 OGG | 各组件贡献可分离且显著 |

**研究层对比协议（把"意图识别×物体泛化"本身做成可审计的比较）**
1. **预注册假设**：H22 单边意图证书在物体漂移下不 sound；H23 非等变技能无法靠重采样掩盖泛化缺口；H24 联合校准优于边际相乘。
2. **配对设计**：同一场景种子、同一初始状态，系统间做配对差。
3. **基线**：B1 意图分类器 + 物体检测器 + 单意图证书；B2 意图-物体边际相乘；B3 物体域随机化重训但无轨道证书；B4 只做 OOD 弃权；B5 本轮 `IOBS+JOGQ+OEC+GAP+IOC`。
4. **主指标**：物体轨道/未知类别上的部署失败率；**次指标**：探针数、弃权率、成本、泛化半径。
5. **统计**：配对均值差、95% CI、效应量（风险差/Cohen's h）、Holm–Bonferroni 校正；显式报告"负结果"——若 `res_joint≈res_intent` 在整个域成立，则说明该域物体绑定对决策不敏感，联合建模无收益。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 物体扰动群定义过窄/过宽 | 高 | 分层生成元 + 对抗轨道采样 + 数据驱动校准 `𝒢_obj` |
| 联合假设空间组合爆炸 | 高 | 因子化信念 + 稀疏绑定剪枝 + 商空间哈希 |
| 等变缺陷被乐观低估 | 高 | 证书下界（对抗采样取最大）+ 保守 `ε_max` + 红队轨道 |
| 意图-物体不可辨识 | 高 | 主动探针 + 明确 `abstain` + 外部澄清 |
| 未知类别 OOD 漏检 | 高 | 共形 p 值 + 开放集守卫 + 本体回退 |
| 探针安全与信息冲突 | 中 | 安全盾先行 + 预算化停止 + 不可证书则换探针 |
| 类别本体不完备 | 中 | 共享本体 + 未知类别标记 + 人工确认回路 |

## 6. 本轮最大风险

**一句话**：把意图识别与物体泛化统一为"意图-物体联合接地 + 物体扰动轨道上的证书等变迁移"，能堵住"意图对、对象错"的静默失败，但其 soundness 同时依赖 `ℋ_α` 真的覆盖真实联合假设、物体扰动群 `𝒢_obj` 真的包住部署时的位姿/外观/实例/类别漂移、以及 `α_S` 与 `ρ` 的等变缺陷被**保守**估计——一旦扰动群定义过窄或 `ε_eq` 被低估，系统就会在一个自洽的轨道证书上把 `res` 压到 1，并对未见物体系统性过度自信，故必须以 **共形联合可信集 + 对抗轨道采样 + 物体 OOD 守卫 + 弃权优先** 作为不可省略的前置护栏，宁可 `abstain`，也绝不把"轨道内可泛化"误当作"物体已泛化"。

## 3. 关键算法 伪代码

### IP-121 HIP

```python
def update_intent_belief(b_prev, y_t, T, u_max, theta_H):
    b = normalize((T @ b_prev) * likelihood(y_t))
    u = 1.0 - max(b.values())
    if u > u_max:
        return b, 'unknown'
    z = argmax(b)
    if b[z] >= theta_H and z in ('assist','interfere'):
        return b, z
    return b, 'unknown'
```

### IP-122 JAS

```python
def joint_safe_set(candidates, b, eps_p, theta_J):
    A_H = plausible_human_actions(b, eps_p)
    return [a_R for a_R in candidates
            if all(compat_J(a_R, a_H) >= theta_J for a_H in A_H)]
```

### IP-123 LEC

```python
def select_execution(safe_set, b, theta_leg):
    best, best_cost = None, float('inf')
    for a_R in safe_set:
        c = (w_t*(1-progress(a_R)) + w_s*surprise(a_R)
             + w_l*max(0, theta_leg-legibility(a_R, b)))
        if c < best_cost:
            best, best_cost = a_R, c
    return best
```

### IP-124 SAA

```python
def allocate_authority(mode_t, u_t, dist, phase, hist):
    if mode_t == 'unknown' or intrusion(dist):
        return escalate(hist, ['yield','wait','reobserve'])
    if mode_t == 'interfere':
        return 'yield'
    if mode_t == 'assist' and u_t < u_low:
        return 'shared' if phase.requires_human else 'robot_lead'
    return 'robot_lead'
```

### IP-125 HIC

```python
def interaction_certificate(J, b, safe_set, alpha, leg, delta_H, evidence):
    if not safe_set:
        return ('degrade','no_joint_safe_action')
    if delta_H > Delta_H or leg < theta_leg:
        return ('degrade','uncertain_or_illegible')
    if intrusion_rate(evidence) > eps_H:
        return ('reject','human_harm_risk')
    return ('ok', JointCert_HRI(J, b, safe_set, alpha, leg, delta_H))
```

### IP-126 HRL

```python
def human_robot_loop(obs, J54, theta):
    b = init_belief()
    while not done:
        b, mode = update_intent_belief(b, observe_human(obs), T,
                                       theta.u_max, theta.H)
        safe = joint_safe_set(skill_candidates(J54), b, theta.eps_p, theta.J)
        alpha = allocate_authority(mode, uncertainty(b), dist(obs),
                                   phase(obs), hist)
        a_R = select_execution(safe, b, theta.leg) if alpha != 'wait' else hold()
        execute(a_R)
        if surprise(a_R) > theta.surprise or intrusion(obs):
            exp = explain_failure(simulate(a_R, obs), sim_model)
            b = update_intent_belief(b, exp.counterfactual, T,
                                     theta.u_max, theta.H)
        obs, done = step()
    return b, alpha
```

## 4. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| HIP | O(|Z|²+|Y|·|Z|) | O(|Z|) | 后验校准、abstain 覆盖 |
| JAS | O(|A_R|·|A_H^plaus|) | O(|A_R|) | 人动作集覆盖 sound |
| LEC | O(|A_R^safe|) | O(1) | 只在安全域内选择 |
| SAA | O(1) | O(1) | 滞回、升级链单调 |
| HIC | O(|A_R|·|A_H|) | O(|A_R|) | 联合证书 sound、`δ_H` 记账 |
| HRL | 每步同 JAS+HIC | O(|Z|+|A_R|) | 闭环收敛、Explain 一致 |

**正确性定理（Human-Interaction-Aware Deployment Soundness）**
假设第 54 轮 (A26)–(A28) 成立；新增：
**(A29)** 后验校准：`P(z ∉ argmax b_t 且 mode_t≠unknown) ≤ δ_H`；
**(A30)** JAS sound：通过 `A_J^safe` 的动作对 `A_H^plaus(b_t)` 内任意人动作的碰撞概率 ≤ ε_H；
**(A31)** 可读性不参与安全约束（`Leg` 只影响效率项）。
则
```
P(task success ∧ no human harm | J_HRI)
  ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a) - δ_H - ε_H
```
关键：**组合前提先过联合安全筛**，**`unknown` 一律降级让行**，**可读性只买效率不买安全**。

## 5. 实验设计 E162–E166

| 实验 | 指标 | 目标 | 对照 |
|---|---|---|---|
| E162 人因后验校准 | ECE / Brier / abstain 率 | ECE ≤ 0.05，高风险 unknown 召回 ≥ 95% | 单帧分类器 |
