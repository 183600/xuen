### 第 1 轮灵感驱动研究记录

**灵感词**：情感语音、演示数据

**直觉与动机**：
前几轮证书链已把机器人的「物理结构、语义地图、重构机构、多机协同」纳入可证准入，却漏掉了两类最根本的「人」的信号。第一，操作者的情感语音（音高、能量、语速、停顿、颤抖）不是噪声，而是**实时的隐式风险先验**：急促高唤醒的语音应先验收紧能量/速度预算，犹豫低置信的语音应触发澄清而非盲执行。第二，演示数据（遥操作/动捕/人类示范）是技能与偏好的来源，但「演示是否覆盖部署分布、专家是否近似最优、是否存在混杂」从未被证书化。核心洞见：**情感语音是「人→机」的动态意图/风险调制信号，演示数据是「人→机」的静态技能/规范先验；二者共同构成人类意图证书的两面，前者调预算，后者调策略**。因此 v26 在 SRC-USC 基础上新增情感语音证书（VAC）、演示数据证书（DPC）与人类意图融合证书（HIFC），并把「语音说停但演示说继续」这类跨模态冲突纳入可证仲裁，而不是简单投票或后验覆盖。

**形式化目标**：
1. 情感语音证书（VAC）：对语音帧 a(t) 的韵律嵌入 h_emo，conformal 情感预测集满足 ℙ(e*∈C_α(a))≥1-α_emo；跨说话人/语料域差 d_MMD≤ε_dom；情感到风险预算的单调映射 g_risk 满足 arousal↑⇒E_max↓、v_max↓，且 |ΔE_emo|≤E_margin；语音指令与语义目标的绑定一致。
2. 演示数据证书（DPC）：演示集 D 对部署状态分布支撑覆盖 supp(ρ_π)⊆supp(ρ_D)⊕ε_sup；行为克隆泛化 E[ℓ(π_BC)]≤ε_BC 以概率 1-δ_demo；专家近似最优/因果充分 κ_causal；动作 OOD 拒绝率≥R_OOD。
3. 人类意图融合证书（HIFC）：语音先验 π_voice 与演示先验 π_demo 的冲突仲裁满足时序一致性与安全优先（保守动作优先），输出融合意图 π_human 并附带可解释冲突证据。
4. 构建九证统一门（ADUC）：USMC∪SMC∪RMC∪MCC∪VAC∪DPC∪HIFC，Exec_v26 = Exec_v25 ∩ Fil_affect ∩ Fil_demo ⊆ Exec_v25。
5. 证明在情感误判、演示漂移、跨模态冲突三种退化下，九证单调退化链保持。

**最大风险（本轮结尾一句话）**：
情感语音的 conformal 覆盖在反讽/跨文化/跨说话人下失效，演示数据的支撑覆盖无法保证专家语义正确，二者在「语音说停但演示继续」的冲突中出现仲裁延迟，可能让 ADUC 在人类真实意图已被误读后仍放行一个物理安全但语义错误的高风险动作。

# ============================================================
# IP-448 Vocal Affect Certificate (VAC) — 情感语音证书
# ============================================================
@dataclass
class VocalAffectCertificate:
    audio_frames: Tensor            # [T_a, F] 帧级声学特征
    prosody: Tensor                 # [T_a, d_p] F0/能量/语速/jitter/shimmer
    alpha_emo: float = 0.05         # 情感覆盖风险
    eps_dom: float = 0.1            # 跨说话人/语料域差容差
    emo_calibrator: 'ConformalCalibrator' = None
    ref_embedding: Optional[Tensor] = None   # 校准语料韵律嵌入
    E_margin: float = 0.1
    v_margin: float = 0.2
    risk_map: 'RiskMap' = None      # (arousal,valence,stress)->(ΔE,Δv)

    def verify_affect_coverage(self) -> bool:
        """ℙ(e* ∈ C_α(a)) ≥ 1-α_emo（说话人分离校准）"""
        if self.emo_calibrator is None:
            return False
        pred_sets = self.emo_calibrator.predict(self.prosody)
        if any(len(s) == 0 for s in pred_sets):
            return False
        return self._empirical_coverage(pred_sets) >= 1.0 - self.alpha_emo

    def verify_domain_gap(self) -> bool:
        """d_MMD(h_emo, ref) ≤ ε_dom，抑制跨说话人漂移"""
        if self.ref_embedding is None:
            return False
        return mmd_rbf(self.prosody.mean(dim=0, keepdim=True),
                       self.ref_embedding) <= self.eps_dom

    def verify_risk_monotonicity(self, arousal: float,
                                 valence: float, stress: float) -> bool:
        """情感只允许收紧预算，且高唤醒必须显著降速"""
        dE, dv = self.risk_map(arousal, valence, stress)
        if dE < 0 or dv < 0:              # 不允许放宽
            return False
        if dE > self.E_margin or dv > self.v_margin:
            return False
        if arousal > 0.8 and dv < 0.2:    # 高唤醒未降速即拒证
            return False
        return True

    def verify_command_grounding(self, cmd_embedding: Tensor,
                                 semantic_goal: 'SemanticEntity') -> bool:
        """语音指令与语义目标绑定一致性"""
        return cosine(cmd_embedding, semantic_goal.embedding) >= 0.8

    def verify_all(self, arousal, valence, stress,
                   cmd_embedding, semantic_goal) -> bool:
        return (self.verify_affect_coverage() and
                self.verify_domain_gap() and
                self.verify_risk_monotonicity(arousal, valence, stress) and
                self.verify_command_grounding(cmd_embedding, semantic_goal))

    def _empirical_coverage(self, pred_sets) -> float:
        hits = sum(int(self.emo_calibrator.true_label(i) in pred_sets[i])
                   for i in range(len(pred_sets)))
        return hits / len(pred_sets)


# ============================================================
# IP-449 Demonstration Provenance Certificate (DPC) — 演示数据证书
# ============================================================
@dataclass
class DemonstrationProvenanceCertificate:
    D_states: Tensor                 # [N_D, d_s]
    D_actions: Tensor                # [N_D, d_a]
    D_confounders: Optional[Tensor]  # [N_D, d_ξ]
    rho_pi_samples: Tensor           # [N_π, d_s] 部署状态样本
    eps_sup: float = 0.05
    eps_BC: float = 0.05
    delta_demo: float = 0.05
    R_OOD: float = 0.95
    policy: 'BehaviorClonedPolicy' = None

    def verify_support_coverage(self) -> bool:
        """supp(ρ_π) ⊆ supp(ρ_D) ⊕ ε_sup（双向 kNN 覆盖）"""
        d_pi_to_D = knn_distance(self.rho_pi_samples, self.D_states, k=1)
        covered = (d_pi_to_D <= self.eps_sup).float().mean().item()
        d_D_to_pi = knn_distance(self.D_states, self.rho_pi_samples, k=1)
        overlap = (d_D_to_pi <= self.eps_sup).float().mean().item()
        return covered >= 0.99 and overlap >= 0.90

    def verify_bc_generalization(self) -> bool:
        """PAC-Bayes/Rademacher 上界 E[ℓ(π_BC)] ≤ ε_BC (1-δ_demo)"""
        if self.policy is None:
            return False
        bound = pac_bayes_bound(self.policy, self.D_states,
                                self.D_actions, self.delta_demo)
        return bound <= self.eps_BC

    def verify_expert_optimality(self) -> bool:
        """逆强化学习恢复奖励后，专家动作最优性间隙 ≤ κ_causal"""
        if self.D_confounders is None:
            return False   # 无混杂变量 → 无法证明因果充分
        gap = inverse_rl_suboptimality_gap(
            self.D_states, self.D_actions, self.D_confounders)
        return gap <= 0.05

    def verify_ood_action_rejection(self, eval_states: Tensor) -> bool:
        """部署分布外的动作必须被拒绝（密度比门控）"""
        if self.policy is None:
            return False
        ratio = self.policy.density_ratio(eval_states)
        rejected = (ratio < 0.5).float().mean().item()
        return rejected >= self.R_OOD

    def verify_all(self, eval_states: Tensor) -> bool:
        return (self.verify_support_coverage() and
                self.verify_bc_generalization() and
                self.verify_expert_optimality() and
                self.verify_ood_action_rejection(eval_states))


# ============================================================
# IP-450 Human Intent Fusion Certificate (HIFC) — 人类意图融合证书
# ============================================================
@dataclass
class HumanIntentFusionCertificate:
    vac: VocalAffectCertificate
    dpc: DemonstrationProvenanceCertificate
    priority: str = 'safety_first'
    conflict_window: int = 5        # 冲突持续帧数阈值

    def fuse(self, t: int) -> 'Intent':
        """语音先验与演示先验融合；冲突时安全优先"""
        voice = self.vac.risk_map.at(t)          # (ΔE,Δv,stop_prob)
        demo = self.dpc.policy.intent_at(t)      # 期望技能/目标
        if voice.stop_prob > 0.8:
            return Intent(kind='stop', source='voice', risk=voice)
        if self._conflict(voice, demo):
            return Intent(kind='conservative', source='arbiter',
                          evidence=(voice, demo), risk=voice)
        return Intent(kind='execute', target=demo.target,
                      risk=voice, source='fused')

    def _conflict(self, voice, demo) -> bool:
        # 语音要求降速而演示要求加速，或否定/肯定语义互斥
        return (voice.speed_scale < 0.5 and demo.speed_scale > 1.0) or \
               (voice.negation and demo.target == voice.target)

    def verify_consistency(self) -> bool:
        """冲突仲裁满足安全优先 + 时序平滑（不抖动）"""
        return self._safety_first_holds() and self._temporal_smoothness()

    def _safety_first_holds(self) -> bool:
        for t in range(self.vac.prosody.shape[0]):
            it = self.fuse(t)
            if it.kind == 'conservative':
                if it.risk.dE < 0 or it.risk.dv < 0:
                    return False
            if it.kind == 'stop' and it.risk.stop_prob <= 0.8:
                return False
        return True

    def _temporal_smoothness(self) -> bool:
        kinds = [self.fuse(t).kind for t in range(self.vac.prosody.shape[0])]
        flips = sum(kinds[i] != kinds[i-1] for i in range(1, len(kinds)))
        return flips / max(len(kinds) - 1, 1) <= 1.0 / self.conflict_window

# IP-451 ADUC 九证统一准入门
# ============================================================
@dataclass
class AffectDemoUnifiedCertificate:
    src_usc: 'SemanticReconfigCoordUnifiedCertificate'
    vac: VocalAffectCertificate
    dpc: DemonstrationProvenanceCertificate
    hifc: HumanIntentFusionCertificate

    def admits(self, multi_plan, sensor_data: dict,
               arousal, valence, stress,
               cmd_embedding, semantic_goal) -> bool:
        # 1. 先通过 SRC-USC 七证（物理/语义/重构/协同）
        if not self.src_usc.admits(
                multi_plan, sensor_data,
                gt_entities=sensor_data.get('gt_entities'),
                queries=sensor_data.get('queries'),
                retrieved=sensor_data.get('retrieved')):
            return False
        # 2. 情感语音证书
        if not self.vac.verify_all(arousal, valence, stress,
                                   cmd_embedding, semantic_goal):
            return False
        # 3. 演示数据证书
        if not self.dpc.verify_all(sensor_data['eval_states']):
            return False
        # 4. 人类意图融合证书
        if not self.hifc.verify_consistency():
            return False
        # 5. 融合后的风险预算仍须被 USMC 能量/速度证书容纳
        fused = self.hifc.fuse(sensor_data['t'])
        return self._budget_compatible(fused, multi_plan)

    def _budget_compatible(self, intent: 'Intent', multi_plan) -> bool:
        # 情感只收紧预算：融合后 (E, v) 不得超过原计划上界
        return (intent.risk.dE <= multi_plan.E_max and
                intent.risk.dv <= multi_plan.v_max)

            'fusion_ok': self.aduc.hifc.verify_consistency(),
        }}


# 辅助函数
def mmd_rbf(x: Tensor, y: Tensor, sigma: float = 1.0) -> float:
    """RBF 核最大均值差异"""
    xx = torch.cdist(x, x).pow(2)
    yy = torch.cdist(y, y).pow(2)
    xy = torch.cdist(x, y).pow(2)
    k = lambda d: torch.exp(-d / (2 * sigma ** 2))
    return (k(xx).mean() + k(yy).mean() - 2 * k(xy).mean()).item()

def knn_distance(query: Tensor, ref: Tensor, k: int = 1) -> Tensor:
    """query 每点到 ref 集的第 k 近邻距离"""
    return torch.cdist(query, ref).topk(k, largest=False).values[:, -1]

## 3. 正确性论证（增量）

### 引理 13（情感语音证书的覆盖-域-风险-绑定四重保证）
**陈述**：`VAC.verify_all(...) = True` ⟺ 同时满足
(1) conformal 情感覆盖 ℙ(e*∈C_α(a))≥1-α_emo，
(2) 跨说话人/语料域差 d_MMD≤ε_dom，
(3) 风险映射只收紧不回退且高唤醒必降速，
(4) 语音指令与语义目标绑定一致。

**证明**：条件 (1) 由说话人分离的 conformal 校准与经验覆盖统计直接给出（Vovk et al. 2005 的边际覆盖）；条件 (2) 用 MMD 检验非平稳域，ε_dom 由校准集分位数确定；条件 (3) 的单调性由 g_risk 的构造保证（ΔE,Δv 非负且受 E_margin/v_margin 截断）；条件 (4) 用嵌入余弦阈值保证指令与语义实体指向同一目标。四条件分别对应统计有效性、域泛化、安全方向、语义绑定，缺一不可。∎

### 引理 14（演示数据证书的支撑-泛化-因果-拒绝四重保证）
**陈述**：`DPC.verify_all(...) = True` ⟺ 同时满足
(1) 部署状态被演示支撑覆盖 supp(ρ_π)⊆supp(ρ_D)⊕ε_sup，
(2) 行为克隆泛化界 E[ℓ(π_BC)]≤ε_BC（置信 1-δ_demo），
(3) 专家在恢复奖励下近似最优（κ_causal），
(4) 部署分布外动作拒绝率≥R_OOD。

**证明**：条件 (1) 由双向 kNN 覆盖统计给出，保证部署时不会进入演示从未覆盖的状态；条件 (2) 由 PAC-Bayes/Rademacher 上界给出有限样本泛化保证；条件 (3) 用逆强化学习恢复奖励并要求专家次优间隙有界，从而排除「次优/混杂演示被当成最优」；条件 (4) 用密度比门控保证 OOD 状态下不盲目执行 BC 动作。四条件共同构成「演示可信、可泛化、可归因、可拒绝」的闭环。∎

### 引理 15（人类意图融合的安全优先仲裁可靠性）
**陈述**：若 `HIFC.verify_consistency() = True`，则对任意冲突帧，融合意图必为保守/停止动作，且融合后的风险预算不超过语音与演示两侧预算的较小者；不存在「演示要求加速而系统放行」的路径。

**证明**：`_conflict` 检出语音降速与演示加速的互斥，`fuse` 在冲突时返回 `kind='conservative'` 并沿用语音的收紧风险；`_safety_first_holds` 逐帧校验保守意图的 dE,dv 非负且 stop 概率阈值成立；`_temporal_smoothness` 限制仲裁抖动。若任一不成立则 `verify_consistency=False`，ADUC 整除。故安全优先在证书层被强制，而非依赖运行时启发式。∎

### 引理 16（九证单调退化链终极延伸）
**陈述**：任意单点/组合失效下，`Exec_v26 ⊆ Exec_v25 ⊆ ... ⊆ Exec_v18` 恒成立。

**证明**：在引理 12 基础上增加三条退化路径：
- 情感误判/覆盖失效/OOD 语音 → `VAC.verify_all=false` → `ADUC` 拒证 → 退回 `Exec_v25`（忽略情感调制，按静态风险预算保守运行）。
- 演示漂移/支撑不足/专家因果失败 → `DPC.verify_all=false` → `ADUC` 拒证 → 退回 `Exec_v25`（禁用行为克隆策略，回退到证书化的规划器）。
- 跨模态冲突仲裁失败/抖动 → `HIFC.verify_consistency=false` → `ADUC` 拒证 → 退回 `Exec_v25`（冻结融合，执行最小风险停机/澄清动作）。
- 组合失效取交集，单调性保持。∎

### 定理（ADUC 九证准入门的人类意图-安全完备性）
**陈述**：对任意多机计划 Π，`ADUC.admits(Π)=True` ⟺ Π 同时满足 SRC-USC 的十项条件，以及
(11) 情感语音覆盖/域泛化/风险单调/指令绑定，
(12) 演示支撑覆盖/BC 泛化/专家因果/OOD 拒绝，
(13) 语音-演示融合的安全优先/时序一致/预算相容。

**证明**：必要性由 `admits` 的逐项连言直接给出；充分性由引理 13–16 保证：前三组条件把「人类意图」从不可观测的先验变成可证约束，且融合预算相容把情感收紧传递到 USMC 能量证书，从而执行集严格收缩。∎

## 6. 本轮最大风险（最终确认）

**一句话**：情感语音证书的 conformal 覆盖在反讽/跨文化/跨说话人下失效，演示数据证书的支撑覆盖又无法保证专家语义正确，二者在「语音说停但演示继续」的冲突中出现仲裁延迟，可能让 ADUC 在人类真实意图已被误读后仍放行一个物理安全但语义错误的高风险动作，削弱九证门「事前拦截」的承诺。
