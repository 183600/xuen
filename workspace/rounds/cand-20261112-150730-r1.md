# 第 61 轮（承接第 60 轮「场景感知闭环」IP-153~160；新灵感循环第 1 轮；本轮灵感：「夹爪控制」×「实例分割」）

> 第 60 轮实现了「认知驱动的场景-执行闭环」：SSM 把场景变成阻抗先验，CIEC 把意图变成实时约束，EPIR 保证执行证据在 ROS 丢包下的完整性，SERC 统一三者，PCE++++ 拓展认知预算。但**对象层面仍是空白**——执行层面对的是一个「无名的接触点」，而不是「被看见、被指认、被抓住的那个实例」。三个核心局限：
> 1. **对象语义缺席**：K_safe 知道「这个场景需要多硬的阻抗」，却不知道「抓的是杯身还是杯柄、是空杯还是满杯」。场景先验是全局的，对象可供性是个体的；缺少实例级物理表征，力分配只能靠试错。
> 2. **分割-接触通道断裂**：实例分割是「视觉侧的分区」，接触控制是「物理侧的分区」。二者恰好在最需要彼此时失联：接触发生瞬间，掩码被手指遮挡、被形变破坏、被透明材质穿透——身份在接触中丢失。
> 3. **语义-物理一致性无证书**：第 60 轮的 SIC 校验「场景-阻抗-置信度」，却不校验「看见的实例 = 摸到的实例 = 想抓的实例」。一个高置信度的错误掩码会产生一个高置信度的错误阻抗，且无法审计。

## 0. 直觉与动机

**灵感 1（实例分割 → 实例-可供性图 IAG）**
直觉：实例分割给出「哪些像素属于同一物体」，但抓取真正要问的是「这个物体的哪里可以抓、要用多大力、会不会碎」。把掩码从「像素集合」升级为**物理实体节点**：每个实例 m_i 附带一个可供性场 φ_i（局部曲率、法向、摩擦 μ̂、柔顺 ĉ、质量 m̂、强度 σ_break）。关键洞见：**可供性场是掩码到阻抗的「物理梯度」**——曲率决定接触几何，摩擦/质量决定最小夹持力，强度决定最大安全力，柔顺决定 K_p。实例于是从「分割结果」变成「可执行的物理假设」。

**灵感 2（夹爪控制 → 实例→阻抗接地 I2IG + 接触锚定跟踪 CAT）**
直觉：夹爪不是被动执行器，而是**物理探针**。它在接触瞬间测到的力/力矩/滑移时序，是对象的「物理指纹」——质量、摩擦、柔顺、内部连接方式。当视觉在接触中失效（遮挡、透明、形变），这个指纹仍能回答「我现在抓的是不是刚才那个实例」。关键洞见：**接触是分割的第二个观测通道**；实例身份不应只由外观 embedding 决定，而应由「外观先验 × 接触似然」贝叶斯融合决定，且视觉可靠性 α 越低，接触似然权重越高。

**灵感 3（对偶 → 主动抓取分割 AGS）**
直觉：既然接触能辨识实例，那么「轻轻地碰一下」本身就是一种**主动分割**：两个视觉上粘连的物体，推一下看是否一起动；一个疑似空心的物体，捏一下看柔顺。把夹爪探针动作视为「分割的信息获取动作」，用 VOI 选探针。关键洞见：**分割不仅指导抓取，抓取也消歧分割**——这是一条双向通道。

**灵感 4（合流 → 实例-接触对账 ICR + 实例-抓取闭环 IGL）**
直觉：视觉说「这是刚性木块」，接触说「它软且滑动」——这个残差就是**语义-物理失配**。ICR 把位置、法向、力、柔顺四类残差统一为马氏距离；超过阈值即触发重分割 / 重供性 / 降级 / 释放。IGL 把 IAG→I2IG→抓取→CAT→ICR→IAG 更新串成闭环。关键洞见：**对账的对象不是数值，而是「身份-物理假设」**。

**灵感 5（PCE+++++ → 第五维抓取预算 B_grasp）**
直觉：与探测不同，抓取是**不可逆**的：捏碎的杯子无法 un-crush，掉落的物体可能损毁。所以 B_grasp 必须是「单向预算」：最大夹持力、滑移预算、尝试次数、柔顺安全裕度。若 B_grasp 紧张 ⇒ 先做 AGS 低力探测；耗尽 ⇒ 保守捏取或主动释放。总原则：**先证后抓**。

## 1. 形式化定义（增量：定义 161–169）

**定义 161（实例-可供性图 IAG）** IAG = (V, E, Φ, Ψ)：
- **实例节点** v_i = (m_i, e_i, φ_i, Σ_i, h_i)：m_i 为实例掩码，e_i 为外观 embedding，φ_i 为可供性场，Σ_i 为不确定性（掩码边界、深度、材料），h_i 为接触历史。
- **可供性场** φ_i: ∂m_i ∪ m_i → A，A = (n(x), κ(x), μ̂_i, ĉ_i, m̂_i, σ_break,i)。其中 μ̂/ĉ 优先由接触历史校准，无接触时由外观先验给出。
- **关系边** E ⊆ V×V：空间相邻、遮挡、支撑、部件-整体（part-of）。
- **可行性谓词** Ψ(v_i, g)：候选抓取 g 是否在 v_i 的实例级安全包络内（见定义 162）。
- **部件实例** v_i^k ⊆ v_i：同一物体上可独立受力的子区域（杯身/杯柄、果柄/果体），用于多指力分配。

**定义 162（实例→阻抗接地 I2IG 与实例安全包络 ISE）** 接地算子 G: (φ_i, Σ_i, T) → π_grasp(K|v_i, T) = N(K; μ_g(v_i,T), Σ_g(v_i,T))。对候选抓取 g：
- **最小夹持力**：F_n^min = (1+κ_s)·m̂_i·g / (2μ̂_i)（两指平行夹持抗滑条件，κ_s 为滑移裕度）。
- **最大安全力**：F_n^max = σ_break,i·A_contact(g) / S_f（S_f 为强度安全系数）。
- **不确定性传播**：一阶传播得
  σ_Fmin² ≈ ((1+κ_s)g/(2μ̂))²σ_m² + ((1+κ_s)m̂g/(2μ̂²))²σ_μ²，
  σ_Fmax² ≈ (σ_break·A/S_f)²σ_A² + (A/S_f)²σ_break²。
- **实例安全包络** ISE(v_i,g) := F_n^min + z_{1-α}σ_Fmin ≤ F_n^max − z_{1-α}σ_Fmax。
- **阻抗映射**：K_p = clip(α_c / max(ĉ,ε), K_p^min, K_p^max)，K_d = 2ζ√(K_p·J_task)。
- **先验收窄**：π_grasp 截断到 ISE ∩ K_safe（复用 EEIS 安全包络）；若 ISE = ∅，则 g 不可抓，转 AGS 或放弃。

**定义 163（接触-部件对应 CPC）** 多指夹爪 F 个手指各产生接触 c_f = (p_f, n_f, λ_f, τ_f)。指派 π: {1..F} → {v_i^k} 与力分配 λ 满足：
```
π*, λ* = argmin_{π,λ} Σ_f E_compliance(c_f, v_{π(f)})
s.t.  Σ_f λ_f = W_desired,
      |λ_f| ≤ λ_max(v_{π(f)}),
      Σ_f (p_f − p_com) × λ_f = τ_desired
```
以 Hungarian 求指派、二次规划求力分配；柔顺部件承担更小法向力以避免局部压碎。

**定义 164（接触锚定实例跟踪 CAT）** 接触事件生成物理指纹 s_f = (∫λ_f dt, 力谱质心/带宽, 滑移起始时刻, τ/λ 比)。身份后验：
```
P(v_i | o_t) ∝ P(o_t^v | v_i)^{α_t} · P(o_t^c | v_i)^{1−α_t} · P(v_i | o_{t−1})
```
其中 α_t ∈ [0,1] 为视觉可靠性（由掩码置信度、遮挡率、透明/反光检测给出）。当 α_t→0（遮挡、透明、形变）时接触似然主导；当 α_t→1 时外观主导。CAT 保证接触期间身份不随掩码消失而丢失。

**定义 165（主动抓取分割 AGS）** 在实例歧义集合 A_amb 上选择探针：
```
a* = argmax_{a∈A_probe} E_{o|a}[ H(partition) − H(partition|o) ] − λ_cost·cost(a)
s.t. F_probe(a) ≤ F_probe^max, B_grasp.allows(a)
```
探针动作 A_probe = {轻叩（判连通性）, 轻捏（判柔顺）, 轻推/轻滑（判摩擦与附件）, 微提（判质量）}。AGS 是「抓取反哺分割」的显式信息获取。

**定义 166（实例-接触对账 ICR）** 对实例 v_i 与其接地先验 g，定义语义-物理残差：
```
r_IC = mahalanobis(
  [ p_contact − p_mask,
    angle(n_contact, n_mask),
    (F_measured − F_expected)/F_scale,
    (ĉ_measured − φ_i.ĉ)/ĉ_scale ],
  Σ = Σ_i )
```
- r_IC ≤ τ_ic ⇒ SAFE；
- F_measured > F_n^max ⇒ ABORT_RELEASE（硬力上限优先）；
- ĉ_measured ≪ φ_i.ĉ ⇒ REAFFORD_SOFT（重估可供性、降 K_p）；
- 位置残差超界 ⇒ RESEGMENT（掩码/实例划分重估）；
- 其余 ⇒ DEGRADE（退回保守阻抗）。

**定义 167（实例-抓取闭环 IGL）** 闭环算子 IGL(M, target_id, T)：
```
① IAG  ← build_iag(seg, depth, tactile_hist)
② if σ_mask > τ_mask and B_grasp.allows_probe():
       IAG ← AGS(IAG, σ_mask, B_grasp)
③ node ← IAG[target_id]
④ π_grasp ← I2IG(node, T, K_safe_env);  if ISE(node, g)=∅: AGS or ABORT
⑤ g ← select(π_grasp);  dispatch_grasp(g)
⑥ loop until done:
       w ← read_wrench();  append(contact_seq, w)
       z, post ← CAT(tracker, observe_instances(), w, α_t)
       verdict ← ICR(IAG[z], g, w, τ_ic)
       if verdict ≠ SAFE: safe_action(verdict); break
⑦ J_grasp ← build_ggc(node, π_grasp, g.K, contact_seq, r_trace)
⑧ if SAFE: IAG.update_from_contacts(contact_seq, J_grasp)
⑨ return (J_grasp, IAG)
```

**定义 168（抓取预算 B_grasp 与 PCE+++++）** B_cog = (B_scene, B_intent, B_ros, B_exec, B_grasp)，新增
```
B_grasp = (F_hard_cap, Slip_budget, Attempts_left, Compliance_margin)
```
PCE+++++ VOI 增加不可逆项：
```
voi_grasp(π) = voi_cog(π) − cost_grasp(π) − cost_irreversible(π)
cost_grasp = λ_F·F_used(π) + λ_slip·E[slip(π)] + λ_attempt·1[attempt]
cost_irreversible = λ_dmg·P(damage(π)) + λ_drop·P(drop(π))
```
降级：B_grasp 紧张 ⇒ 先 AGS 低力探测；B_grasp 耗尽 ⇒ 保守捏取或释放；F_hard_cap 为不可跨越的硬约束。

**定义 169（抓取接地证书 GGC / J_grasp）** J_grasp = (instance_id, mask_hash, φ_i 快照, π_grasp, K_applied, contact_seq, r_IC 轨迹, slip_margin_min, verdict ∈ {SAFE, DEGRADED, ABORTED})。哈希链覆盖 mask→φ→π→K→contact 全路径，任何一环被替换都会破坏链式校验——使「从像素到力」可审计。

## 2. 关键算法伪代码

### IP-161 IAG（实例-可供性图）

```python
class InstanceAffordanceGraph:
    def build(self, seg_out, depth, tactile_hist):
        self.nodes, self.edges = {}, []
        for det in seg_out:
            surf = extract_surface(det.mask, depth)      # normal, curvature
            phi = AffordanceField(
                normal=surf.n, curvature=surf.k,
                mu=self._friction(det.mask, surf, tactile_hist),
                comp=self._compliance(det.mask, surf, tactile_hist),
                mass=self._mass(det.mask, surf),
                strength=self._strength(det.mask, det.cls))
            self.nodes[det.id] = InstanceNode(
                mask=det.mask, emb=det.embedding, phi=phi,
                sigma=self._mask_uncertainty(det.mask, det.logits),
                hist=tactile_hist.get(det.id, []))
        self.edges = build_relations(self.nodes, depth, seg_out)
        return self
```

### IP-162 I2IG（实例→阻抗接地）

```python
def instance_to_impedance(node, task, K_safe_env, z=1.96):
    priors = []
    for g in enumerate_grasps(node.mask, node.phi, task):
        F_min = (1 + KAPPA_S) * node.phi.mass * G / (2 * node.phi.mu)
        F_max = node.phi.strength * g.contact_area / S_F
        s_min = first_order_sigma_Fmin(node, F_min)
        s_max = first_order_sigma_Fmax(node, F_max, g)
        if F_min + z * s_min > F_max - z * s_max:    # ISE empty
            continue
        Kp = clip(ALPHA_C / max(node.phi.comp, EPS), KP_MIN, KP_MAX)
        Kd = 2 * ZETA * sqrt(Kp * task.inertia)
        priors.append(GraspPrior(g, Kp, Kd, F_min, F_max))
    pi = GaussianMixture(priors, weights_from_scores(priors))
    return truncate_to(pi, K_safe_env)
```

### IP-163 CPC（接触-部件对应）

```python
def contact_part_correspondence(contacts, node_parts):
    cost = [[contact_part_cost(c, p) for p in node_parts] for c in contacts]
    assign = hungarian(cost)                         # finger -> part
    lam = solve_qp(
        minimize=compliance_energy(assign, contacts, node_parts),
        constraints=[sum_lambda_eq_W(contacts, W_desired),
                     per_part_force_caps(assign, node_parts),
                     torque_balance(contacts, tau_desired)])
```

### IP-164 CAT（接触锚定跟踪）

```python
def contact_anchored_track(tracker, obs_v, wrench, alpha):
    posts = {}
    for i, node in tracker.nodes.items():
        lv = obs_v.appearance_likelihood(node)
        lc = contact_likelihood(wrench, node.hist)   # physical fingerprint
        posts[i] = (lv ** alpha) * (lc ** (1 - alpha)) * tracker.prior[i]
    posts = normalize(posts)
    z = argmax(posts)
    tracker.prior = posts
    tracker.nodes[z].hist.append(wrench)
    return z, posts
```

### IP-165 AGS（主动抓取分割）

```python
def active_grasp_segmentation(iag, ambiguity, budget):
    best, best_voi = None, -inf
    for a in PROBE_ACTIONS:                          # tap/squeeze/slide/lift
        if not budget.allows(a) or probe_force(a) > F_PROBE_MAX:
            continue
        ig = expected_information_gain(ambiguity, a)
        voi = ig - LAMBDA_COST * probe_cost(a)
        if voi > best_voi:
            best, best_voi = a, voi
    if best is None:
        return iag
    o = execute_probe(best)
    return update_partition(iag, best, o)
```

### IP-166 ICR（实例-接触对账）

```python
def instance_contact_reconcile(node, g, w, tau_ic):
    r = mahalanobis(
        [w.p - g.p, angle(w.n, g.n),
         (w.F - g.F_expected) / g.F_scale,
         (w.comp - node.phi.comp) / node.phi.comp_scale],
        Sigma=node.sigma)
    if w.F > g.F_max:                    return ABORT_RELEASE
    if r <= tau_ic:                      return SAFE
    if w.comp < node.phi.comp * 0.5:     return REAFFORD_SOFT
    if distance(w.p, g.p) > TAU_P:       return RESEGMENT
    return DEGRADE
```

### IP-167 IGL（实例-抓取闭环）

```python
def instance_grasp_loop(M, target_id, task):
    iag = InstanceAffordanceGraph().build(M.seg, M.depth, M.tactile_hist)
    node = iag.nodes[target_id]
    if node.sigma.mask > TAU_MASK and M.budget_grasp.allows_probe():
        iag = active_grasp_segmentation(iag, node.sigma, M.budget_grasp)
        node = iag.nodes[target_id]
    pi = instance_to_impedance(node, task, M.K_safe_env)
    if pi.is_empty():
        return build_abort_certificate(node, ABORTED)
    g = select(pi)
    M.dispatch_grasp(g)
    contacts, r_trace = [], []
    while not g.done:
        w = M.read_wrench(); contacts.append(w)
        z, _ = contact_anchored_track(M.tracker, M.observe_instances(), w, M.vision_alpha())
        verdict = instance_contact_reconcile(iag.nodes[z], g, w, TAU_IC)
        r_trace.append(verdict)
        if verdict is not SAFE:
            M.safe_action(verdict); break
    cert = build_grasp_certificate(node, pi, g.K, contacts, r_trace)
    if cert.verdict is SAFE:
        iag.update_from_contacts(contacts, cert)
    return cert, iag
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| IAG | O(HW + N·\|∂m\|)/帧（分割主导） | O(N·\|∂m\|) | 掩码误差 ≤ δ_m，σ_mask 可被显式检测 |
| I2IG | O(\|G_i\|)/实例 | O(\|G_i\|) | 接地 L-Lipschitz：δm→δK ≤ L·δm |
| CPC | O(F³) 匈牙利 + QP | O(F·P) | 力/力矩平衡可行域非空 |
| CAT | O(N)/接触周期 | O(N + H) | 视觉失效时身份误差 ≤ ε_c |
| AGS | O(\|A_probe\|·N) | O(N) | 探针力 ≤ F_probe^max |
| ICR | O(1) | O(1) | 残差 > τ ⇒ 降级先于硬力越界 |
| GGC | O(\|contact_seq\|) | O(\|contact_seq\|) | 哈希链可重构全路径 |

**正确性定理（GIG）**：假设 A66–A71 成立。
**(A66)** 实例分割完备性：对每个可抓取真实实例，存在预测实例与其 IoU ≥ τ_iou，或 σ_mask 显式超过 τ_mask（可由 AGS 消歧）。
**(A67)** 可供性 Lipschitz：φ_i 与接地算子 G 关于掩码扰动满足 L-Lipschitz。
**(A68)** 接触可辨识性：不同实例的接触指纹分布 KL 散度 ≥ d_min。
**(A69)** 对账可靠性：r_IC ≤ τ_ic 时施加阻抗落在该实例 ISE 内；r_IC > τ_ic 时降级动作先于硬力上限 F_hard 被突破。
**(A70)** 预算单调性：B_grasp 单调消耗，抓取不可逆。
**(A71)** 证书完整性：GGC 哈希链覆盖 mask→φ→π→K→contact 全路径。

则：
1. **接地可靠性**：若 σ_mask ≤ τ_mask 且 ISE ≠ ∅，则 K_grasp 落入实例安全包络的概率 ≥ 1−α；掩码扰动引起的阻抗偏移 ≤ L·δ_m。
2. **接触身份连续性**：CAT 在 α_t→0 时仍以接触指纹维持身份，身份错误率 ≤ ε_c，避免「抓错对象」。
3. **失配安全降级**：任何 r_IC > τ_ic 的语义-物理失配都会触发 ABORT/REAFFORD/DEGRADE，不会在错误物理假设下静默压碎或滑落。
4. **证书可审计性**：J_grasp 可重构 mask→φ→π→K→contact 全路径，任一环篡改即断链。

## 2. 关键推导

### 推导 1（最小夹持力与不确定性）

两指平行夹持、接触法向力 F_n、摩擦系数 μ、质量 m，抗滑条件为 2μF_n ≥ mg。引入滑移裕度 κ_s：

```
F_n^min = (1 + κ_s) · m g / (2 μ)
```

对 m 与 μ 做一阶误差传播：

```
σ_Fmin² ≈ ( (1+κ_s) g / (2μ) )² σ_m²
         + ( (1+κ_s) m g / (2μ²) )² σ_μ²
```

质量/摩擦估计越不确定，所需最小力越要上浮——这正是「掩码边界不确定性 → 力裕度」的定量桥梁。

### 推导 2（最大安全力与不确定性）

```
F_n^max = σ_break · A_contact / S_f
σ_Fmax² ≈ (σ_break·A/S_f)² σ_A² + (A/S_f)² σ_break²
```

其中 A_contact 由掩码局部几何给出，σ_A 随掩码边界不确定性膨胀。

### 推导 3（可抓取可行性判据）

抓取 g 可行当且仅当实例安全包络非空：

```
F_n^min + z_{1−α} σ_Fmin  ≤  F_n^max − z_{1−α} σ_Fmax
```

即「为保证不滑所需的下界」与「为保证不碎所需的上界」在不确定区间下仍有交集。若交集为空：**不是调 PID，而是该抓取物理上不可行**——必须换抓取、AGS 探测或放弃。该判据把「分割质量」直接转成「抓取可行域」的收缩。

```python
def instance_to_impedance(node, task, K_safe_env, z=1.96):
    priors = []
    for g in enumerate_grasps(node.mask, node.phi, task):
        F_min = (1 + KAPPA_S) * node.phi.mass * G / (2 * node.phi.mu)
        F_max = node.phi.strength * g.contact_area / S_F
        s_min = first_order_sigma_Fmin(node, F_min)
        s_max = first_order_sigma_Fmax(node, F_max, g)
        if F_min + z * s_min > F_max - z * s_max:    # ISE empty
            continue
        Kp = clip(ALPHA_C / max(node.phi.comp, EPS), KP_MIN, KP_MAX)
        Kd = 2 * ZETA * sqrt(Kp * task.inertia)
        priors.append(GraspPrior(g, Kp, Kd, F_min, F_max))
    pi = GaussianMixture(priors, weights_from_scores(priors))
    return truncate_to(pi, K_safe_env)
```

```python
def contact_anchored_track(tracker, obs_v, wrench, alpha):
    posts = {}
    for i, node in tracker.nodes.items():
        lv = obs_v.appearance_likelihood(node)
        lc = contact_likelihood(wrench, node.hist)
        posts[i] = (lv ** alpha) * (lc ** (1 - alpha)) * tracker.prior[i]
    posts = normalize(posts)
    z = argmax(posts)
    tracker.prior = posts
    tracker.nodes[z].hist.append(wrench)
    return z, posts
```

### IP-166 ICR

```python
def instance_contact_reconcile(node, g, w, tau_ic):
    r = mahalanobis(
        [w.p - g.p, angle(w.n, g.n),
         (w.F - g.F_expected) / g.F_scale,
         (w.comp - node.phi.comp) / node.phi.comp_scale],
        Sigma=node.sigma)
    if w.F > g.F_max:                    return ABORT_RELEASE
    if r <= tau_ic:                      return SAFE
    if w.comp < node.phi.comp * 0.5:     return REAFFORD_SOFT
    if distance(w.p, g.p) > TAU_P:       return RESEGMENT
    return DEGRADE
```

```python
def instance_grasp_loop(M, target_id, task):
    iag = InstanceAffordanceGraph().build(M.seg, M.depth, M.tactile_hist)
    node = iag.nodes[target_id]
    if node.sigma.mask > TAU_MASK and M.budget_grasp.allows_probe():
        iag = active_grasp_segmentation(iag, node.sigma, M.budget_grasp)
        node = iag.nodes[target_id]
    pi = instance_to_impedance(node, task, M.K_safe_env)
    if pi.is_empty():
        return build_abort_certificate(node, ABORTED)
    g = select(pi)
    M.dispatch_grasp(g)
    contacts, r_trace = [], []
    while not g.done:
        w = M.read_wrench(); contacts.append(w)
        z, _ = contact_anchored_track(M.tracker, M.observe_instances(), w, M.vision_alpha())
        verdict = instance_contact_reconcile(iag.nodes[z], g, w, TAU_IC)
        r_trace.append(verdict)
        if verdict is not SAFE:
            M.safe_action(verdict); break
    cert = build_grasp_certificate(node, pi, g.K, contacts, r_trace)
    if cert.verdict is SAFE:
        iag.update_from_contacts(contacts, cert)
    return cert, iag
```

## 6. 与既有工作的边界

- **vs 抓取检测（GraspNet 等）**：它们输出「可抓位姿」，本方案输出「可抓位姿 + 物理可信区间 + 失败可审计链」。区别在于 ISE 把分割不确定性显式转化为力可行域。
- **vs 触觉 SLAM / 接触式感知**：它们重建几何；本方案用接触指纹做**实例身份再识别**与**语义-物理对账**，服务的是「抓错对象」而非「建图」。
- **vs 主动视觉分割**：它们移动相机；本方案用**夹爪作探针**（轻叩/轻捏/轻推/微提）消歧实例划分，是接触侧的信息获取。
- **vs 第 60 轮 SERC**：SERC 接地「场景→阻抗」，本轮接地「实例→阻抗→接触→身份」；SIC 升级为「场景-实例-物理一致性」。
