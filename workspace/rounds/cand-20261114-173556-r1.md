# 第 74 轮（承接第 73 轮「MODGAUGE-RAS 计量契约代数」IP-295~302；灵感循环第 4 轮；本轮灵感：「微调」×「SLAM」）

> R73 把 GAUGE 从「具身计量」推进到「**计量契约代数**」：证据契约 EC、模块注册表 MReg、串联/并联/否决组合 CCA、通道化反作用 ΣREFLEX、主张-证明绑定 CPB，并用引理 35（热替换安全保持）把 E362「换本体零改核心」升格为定理。但 R73 的三条支柱都建立在一个**未言明的静态假设**上：
> - **静态契约假设**：EC 是一张冻结的快照。现实中真正危险的不是「换实现」，而是**微调**——同一个 impl 被在线/离线微调后，类型签名不变、契约字段看起来不变、甚至旧证书仍然「通过」，但条件似然 p(y|s) 已经变了。引理 35 的前提是「同 EC」，而微调恰恰制造出「**同 EC、异世界**」的假等价：热替换定理因此从安全保证退化为**证书洗白机制**（certificate laundering）。R73 的审计查的是「实现是否满足契约」，却无法查「实现是否在微调中悄悄把契约的含义改了」。
> - **静态独立假设**：CCA 的并联缩窄依赖 |ρ̂|<ρ_max，R73 也把「隐共享物理过程耦合」列为最大风险 #5，但没有结构化解法。**SLAM 正是所有模块共享状态的那类系统**：地图 M_t 与位姿 x_t 是下游一切证据的**共因（common cause）**。在真实机器人上，「模块独立」不是常态，而是特例；R73 的独立性假设恰好在最主流的部署形态上系统性失效。
> - **静态世界/单步反作用假设**：ΣREFLEX 的 χ_R 是「一步动作 → 噪声调制」。SLAM 不是一步：建的地图改变未来可观测性，回环闭合**追溯改写过去位姿**；微调改变产生地图的那个估计器。这是一个有记忆、会自指的环，单步预算无法约束「状态是整段历史」的过程。
>
> 本轮两个灵感正好各补一刀，并合成第三刀：
> - **SLAM** → **SEM（SLAM Evidence Metrology）**：把「位姿-地图」当作一个**耦合证据对象**，给出 SLAM 六分量不确定度（里程计/回环/建图/感知混叠/时间同步/动态物），把**回环闭合建模为带门控的 PAR**、把**感知混叠（perceptual aliasing）建模为可致灾的 VETO**，并把「地图诱导相关 ρ_map」作为共因写入契约。SLAM 是对 R73 模块化主张的**极限压力测试**：若契约代数能扛住 SLAM，它才真的模块化。
> - **微调** → **FTG（Fine-Tuning Governance）/ ΔEC 体制**：把微调定义为**证书修订算子**，用契约增量 ΔEC=(Δ_cal, Δ_lik, Δ_dom, Δ_corr) 区分三种体制（R1 校准保持 / R2 契约扩展 / R3 契约破坏），并用**证书漂移监测器 CDM（任意时刻有效的 conformal e-process）**在运行时检测「交换性破裂」。核心命题：**不是禁止微调，而是让微调必须支付证书成本**；R3 微调 = 一次未申报的契约变更，必须被否决或走全量重认证。
> - **合成** → **SRL（Self-Referential Loop，自指环）与闭环收缩性**：三层环 L1 动作↔证据（R73 χ_R）、L2 位姿↔地图（SLAM）、L3 参数↔数据（微调）在结构上同构。R73 证的是**静态组合单调性**；R74 指出真正的安全不变式是**证书度量下的闭环收缩**：`d_C(Fz,Fz') ≤ κ·d_C(z,z')`，κ<1 时证书误差有界。**单调性是 κ=0 的特例。**
>
> 核心命题：**不要再问「模块契约是否有效」，而问「当契约自身随微调漂移、当模块通过共享地图成为彼此的共因时，安全证书能否在闭环中被保持为不变式？」** 把 R73 的「静态契约代数」升级为 **LOOPGAUGE-RAS**（Loop-certified, Online-adaptation-aware, Pose-map-unified GAUGE for RAS）——**可认证自指环**。

## 0. 直觉与动机

**灵感 1（SLAM → 地图是最大的「隐共享物理过程」，回环是最大的「凭空变好」诱惑）**
直觉：SLAM 的失效不是均匀的噪声上升，而是**离散的、灾难性的位姿跳变**。最典型的是**感知混叠导致的假回环**：走廊/仓库/工位长得一样，前端把 A 点认成 B 点，后端加入一条错误约束，整个图被「拉直」，定位瞬间偏移数米——此时所有局部残差都很小、优化都「收敛」，审计日志显示「每一步都合规」。这与 R73 批判的「在合规中组合出一个错误的世界」是同一件事，只是发生在时空图而非模块图上。
更深的观察：**回环闭合本质是一次复杂并联（PAR）**——把「当前观测证据」与「历史地图证据」融合。R73 的 PAR 规则要求先做一致性审计、再决定是否缩窄；SLAM 里这条规则恰好对应「回环门控（loop-closure gating）」。于是 SLAM 不是要新造一套规则，而是**逼出 CCA 一直缺的那半条**：单源证据不得缩窄、必须有独立模态打破平局（继承 E356/E357）。地图又是所有模块的**共因**：深度、触觉、意图都通过位姿读地图，因此「模块独立」在这里必然失效——R73 风险 #5 从「需要留意的隐患」变成「必须写进契约的一等对象 ρ_map」。
SLAM 还给了一个干净的「主动感知」放大版：**主动 SLAM**——走到哪里能让地图/位姿不确定度下降最多？这正是 R73 PVOP 的多步版本，但价值函数里必须出现「地图对未来可观测性的价值」，而不仅是单步深度不确定度。

**灵感 2（微调 → 微调是「类型正确、语义已变」的契约修订）**
直觉：微调在工程上被当作「改权重」，在计量上却是一次**条件似然的修改**。一个在部署域上微调过的材质后验网、意图网、不确定性头、地点识别网，其输出类型完全合法、接口完全兼容、旧的跑批测试甚至全过——但它对同一输入给出的置信分布已经不同。R73 的热替换定理说「同 EC + 证书有效 ⇒ 系统性质保持」；微调恰好构造出**两件都满足、语义却已变**的 impl′。这不是定理的边界情形，而是定理的**盲点**：它把「EC 相同」当成实现层面的字符串比较，而没有把「EC 的**含义**随时间是否守恒」纳入判定。
因此微调必须被建模为**证书修订**：产出契约增量 ΔEC，并强制进入三种体制之一。R1（校准保持）可以廉价重封；R2（契约扩展，如新增雨天/逆光域）需要**分域证书**，只在已认证域内放行；R3（契约破坏）则是否决——因为一个悄悄缩小有效域、或改变残差分布的微调，等于**未经申报地改写了安全前提**。
最关键的一点：**监测器本身也是模块**。如果 CDM 是可微调的、或它的校准集与训练集重叠，那么攻击者可以「微调出一个能证明自己安全的监测器」。这把最大风险从「契约表达力不足」推进到「**守卫者在它所守卫的环里**」。

**灵感 3（合成 → 三层自指环与收缩性）**
直觉：R73 的反作用是「动作改变我自己的证据质量」；SLAM 是「我建的地图改变我自己的定位与未来观测」；微调是「我产出的数据改变我自己的参数」。三者都是**估计器消费自己的输出**。静态地看每个环节都合规，动态地看误差可能被环放大。
一个自然的正确性问题：这个环什么时候是安全的？答案不是「每步误差小」，而是「环映射是压缩的」——在合适的**证书度量** d_C 下，一次环迭代把证书误差乘以 κ<1，于是误差收敛到 `ε/(1−κ)`。回环闭合是**恢复压缩性**的事件（把漂移的历史约束回来，κ 下降）；假回环则可能把 κ 推到 ≥1（地图撕裂，误差被放大）；微调可能抬高 κ（把模型推离校准分布）。于是「安全」变成一个可测量、可预算、可被否决的动力学性质，而不是静态的类型检查。
这一层也解释了 R73 为什么够用又不够用：R73 的组合单调性正是 κ=0（无记忆、无自指）的特例。R74 把「不许凭空变好」升级为「**不许闭环发散**」。

(iv) **主张绑定**：每个组件绑定 C1–C5 之一或降级为工程附件（扩展定义 374）；
(v) **严格退化链**：模块级 stub / 影子降级，安全侧只增不减（继承定义 375/381）；
(vi) **闭环收缩性**：每个自指环在安全不变集 K 上须满足 κ<1 且累计契约漂移 Δ_t ≤ Δ_max；κ≥1 的环不得进入控制域，只能影子运行。
**新增严格包含关系**：冻结 L2/L3（不更新地图、不微调、κ_map=κ_ft=0）时，LOOPGAUGE = MODGAUGE。

**定义 384（SLAM 证据对象与六分量 SEM）** 证据对象
`e_slam = (b(x_t), b(M_t), Σ_x, Σ_M, Ω_lc, τ_hist)`，
联合后验 `p(x_t, M_t | y_{1:t}, u_{1:t})`。不确定度分解：
`u_slam² = u_odom² + u_lc² + u_map² + u_alias² + u_sync² + u_dyn²`，
其中 u_odom（里程计漂移/尺度）、u_lc（回环约束不确定性）、u_map（地图表示与离散化）、u_sync（时间同步偏斜）、u_dyn（动态物体）。**u_alias 是感知混叠的「致灾项」，u_dyn 是「非高斯项」——二者不得压成高斯方差，只能以保守上界 + 否决语义参与组合**（否则又犯 R72/R73 反复批判的「把致灾不确定度误读为可平均噪声」）。
有效域 `D_slam = {alias_margin ≥ τ_alias} ∧ {inlier_ratio ≥ τ_in} ∧ {tracking_ok} ∧ {sync_skew ≤ τ_sync}`。
地图表示声明 `rep(M) ∈ {occupancy, TSDF, feature-graph, gaussian-splat}` 进入 `u_map`，使「换地图表示」也是一次可审计的契约变更。

**定义 385（回环闭合 = 门控 PAR + 追溯改写）** 候选回环是并联组合 `e_now ⊕_{gate} e_map(p)`。三道门：
G1 地点识别置信 ∈ 密封 conformal 集 C_α^place；
G2 几何验证内点率 ∈ C_α^geom；
G3 **独立模态打破平局**（轮式/腿式里程计、IMU 预积分、语义先验三者之一）。
仅当 G1∧G2∧G3 全过，才允许按 PAR 规则缩窄；否则返回 `PAR_AUDIT_FAIL` 并**拒绝该约束**（不是放宽后再融合）。**单源回环不得缩窄**（继承 E356/E357 原则）。
被接受的回环是一个**追溯算子** `LC: Σ_x^{1:t} → Σ_x'^{1:t}`：它改写过去位姿的协方差与 provenance。因此 `τ_merge` 必须是**时间可逆追溯（retro-merge）**，保留窗口 `W_lc`；窗口内证书须重算并记录 `δ_map ‖ Δu_retro`。

**定义 386（地图共因相关 ρ_map）** 读地图的模块构成共因团 `C_M = {i : M_t ∈ inputs_i}`。地图后验在模块对 (i,j) 上诱导**相关下界** `ρ_map(i,j) ≥ 0`（由 Σ_M 与各自对 M 的雅可比传播）。并联融合强制
`ρ̂_eff(i,j) = max(ρ̂_obs(i,j), ρ_map(i,j))`，
即**地图诱导的相关是假定相关的下界，只让融合更保守、绝不允许更激进**。这条规则把 R73 风险 #5 从「口头提醒」变成「代数硬约束」。

**定义 387（时变契约 EC_t 与契约漂移度量）** 契约不再是快照而是轨迹 `{EC_t}`。漂移
`δ_t = d_C(EC_t, EC_{t-1}) = w_1·W_2(𝔽_lik^t, 𝔽_lik^{t-1}) + w_2·d_H(D_t, D_{t-1}) + w_3·|ΔB|/B + w_4·‖ΔR_corr‖`，
累计漂移 `Δ_t = Σ_{τ≤t} δ_τ`。**有界漂移契约**：`δ_t ≤ δ_max ∧ Δ_t ≤ Δ_max`。组合单调性变为逐点成立，但下界随 Δ_t **单调变松**（`u_out(Δ_t)` 关于 Δ_t 非减）——漂移不被「吸收」，只被「记账」。

**定义 388（微调算子 FT 与契约增量 ΔEC）** `FT: (θ, D_adapt) ↦ θ'`。契约增量
`ΔEC(θ,θ') = (Δ_cal, Δ_lik, Δ_dom, Δ_corr)`：
- `Δ_cal = |coverage_{α}(θ') − coverage_{α}(θ)|`（在交换性保持集上）；
- `Δ_lik`：残差分布的双样本距离（MMD/能量距离代理 KL）；
- `Δ_dom`：有效域收缩/扩张指示（**静默收缩禁止**）；
- `Δ_corr`：微调导致的相关结构变化（例如共享特征使两模态相关上升）。
三体制：
- **R1 校准保持**（Δ_cal≤ε_c ∧ Δ_lik≤ε_l ∧ Δ_dom=0）：廉价重封，允许热替换；
- **R2 契约扩展**（新增域，旧域行为保持）：**分域证书**，仅在已认证域放行；
- **R3 契约破坏**（任一越界，或静默缩域）：**VETO**，不得入控制域，须全量重认证 + 契约修订 + 组合理由重证。
**关键**：R73 的引理 35 只在 `ΔEC=0` 时成立；R74 把等价关系从「EC 相等」放宽为「**EC 相等模有界 ΔEC**」，并显式给出退化量 ε(ΔEC)。

**定义 389（证书漂移监测器 CDM）** 对校准残差与在线流做**任意时刻有效（anytime-valid）的交换性检验**，用 conformal e-process / martingale：
`E_t = Π_{s≤t}(1 + λ_s·(g_s − α))`（g_s 为 conformal p 值变换/秩统计），当 `E_t ≥ 1/δ` 判定「校准仍有效」被否决。保证：若流与校准集可交换，则 `P(∃t: E_t ≥ 1/δ) ≤ δ`（无固定窗口、无 ECE 窗口选择问题）。触发后按体制降级：R1→影子审查，R2→缩回已认证域，R3→回滚。CDM 是**冻结组件**（在线不可微调、不可重训），其自身漂移只在离线密封集上审计。

**定义 390（自适应预算 ADB 与影子晋升门）** `B_adapt`：`Σ_t c_adapt^t ≤ B_A`，`c_adapt = 重认证成本 + 回滚风险 + 证书欠账（延迟重认）+ 影子算力`。**影子模式**：候选（微调后）模型的证据在控制路径上标 `u=∞`（等价于 R73 stub，但不产生观测、不参与 PAR 缩窄），仅在旁路记录与离线校验；晋升条件 = CDM 连续 N_min 步通过 ∧ ΔEC ∈ {R1,R2} ∧ 密封审计通过。**这是「微调」版本的严格退化链**：未晋升者不污染控制，晋升失败可无痛回滚。

**定义 391（自指环 SRL 与闭环收缩）** 环映射 `F: z=(x, M, θ, EC) ↦ z'`；证书度量 `d_C`。若在安全不变集 `K` 上
`d_C(Fz, Fz') ≤ κ·d_C(z,z')`（κ<1），则证书误差有界 `d_C(z_hat, z*) ≤ d_C(z_hat, z_0)/(1−κ)`。
三层环：L1 动作↔证据（R73 χ_R，κ_reflex）、L2 位姿↔地图（SLAM，κ_map）、L3 参数↔数据（微调，κ_ft）。
安全不变式：`κ = max(κ_map, κ_ft, κ_reflex) < 1`；任何抬高 κ 的操作须由 `B_adapt` 支付。回环闭合是**降低 κ**（恢复压缩）的事件；假回环可令 κ≥1（地图撕裂）⇒ 必须被门控否决。κ 由密封审计集上的有限差分/谱范数估计，并作为 EC 字段 `κ_cert` 声明。

**定义 392（SLAM 威胁面 AIC-SLAM）** `ℰ_slam = {感知混叠伪装（同构场景投毒）、回环注入、地图投毒（假障碍/删障碍）、GNSS/UWB 重放欺骗、动态物对抗、**地点识别后门**（微调注入的触发子）}`。防线：三门槛控 + ρ_map 保守融合 + CDM + 单源不定案 + 影子晋升；**后门检测**归入 R3（ΔEC 的 Δ_lik 在触发子簇上异常）。

                for m in ('odom','imu','semantic'))               # G3 独立模态

# IP-305 FTG：微调作为契约修订（三种体制）
def fine_tune_regime(theta, theta_p, holdout, stream, alpha):
    d_cal = abs(coverage(theta_p, holdout, alpha) - coverage(theta, holdout, alpha))
    d_lik = two_sample_distance(residuals(theta_p, holdout), residuals(theta, holdout))
    d_dom = domain_change(theta, theta_p)                         # 收缩即禁止
    d_cor = corr_change(theta, theta_p)

                                     return 'R1', (d_cal,d_lik,d_dom,d_cor)
    if d_dom > 0 and d_cal <= EPS_C:  return 'R2', (d_cal,d_lik,d_dom,d_cor)  # 分域证书
    return 'R3', (d_cal,d_lik,d_dom,d_cor)

# IP-306 CDM：任意时刻有效的证书漂移监测（冻结，不可在线微调）
class CertDriftMonitor:                     # conformal e-process
    def __init__(self, alpha, delta, lam=0.5):
        self.alpha, self.delta, self.lam = alpha, delta, lam
        self.logE = 0.0
    def update(self, p_value):
        g = 1.0 - p_value                  # 秩变换：小 p ⇒ 大 g
        self.logE += math.log1p(self.lam * (g - self.alpha))
        if self.logE >= math.log(1.0 / self.delta):
            return 'SHIFT_DETECTED'        # 证书失效 → 降级/回滚
        return 'OK'

## 3. 推导

**引理 38（SLAM 六分量的条件正交性）** 给定 (运动模式, 场景静态性, 时间偏斜, 地图表示) 条件下，u_odom/u_lc/u_map/u_sync 由独立机制产生（积分、约束求解、表示离散化、时钟），条件近似不相关；**u_alias 与 u_dyn 不满足可加方差语义**（多峰/重尾），必须作为 hazard 而非方差进入组合。遗漏 alias/dyn 的方差化 ⇒ 系统性低估且低估不可被平均稀释。系：**SLAM 不确定度不能用「一个 Σ」表达，必须「高斯部分 + hazard 部分」双轨。**

**引理 39（回环门控的保守性）** 若回环仅由单模态（如纯视觉）支持，则无论其置信多高，接受它都不能使 Σ_x 严格缩小（单源不定案）；三门槛控下，接受回环等价于一次通过 conformal 审计的 PAR，缩窄量受校准覆盖 (1−α) 约束。追溯改写使历史协方差单调不增仅在前向-后向一致性通过时成立。系：**「回环让一切变好」是错觉——只有被独立模态见证的回环才允许变好。**

**引理 40（ρ_map 下界的保守性）** 设真实融合协方差为 Σ_fuse(R_true)。若 R_true 含地图共因分量 R_map，则用 ρ̂_obs<R_map 计算的 Σ_fuse(ρ̂_obs) 在各向同性近似下 ≤ Σ_fuse(R_true)（低估方差）。取 `ρ̂_eff=max(ρ̂_obs,ρ_map)` 保证 `Σ_fuse(ρ̂_eff) ≥ Σ_fuse(R_true)`（保守）。系：**忽略地图共因 = 在系统层面制造认知免费午餐；ρ_map 下界把免费午餐收回去。**

**引理 41（微调安全性判据）** 若微调满足有界 ΔEC（`Δ_cal≤ε_c ∧ Δ_lik≤ε_l ∧ Δ_dom=0`）且 CDM 未触发，则候选模块证书仍有效，系统性质相对原证书的退化 `ε(ΔEC) → 0`（ΔEC→0）。反之存在**反例**：在「校准集同分布采样」上微调可令 Δ_cal≈0、类型全过，却在**触发子簇/长尾**上把误检率抬高数倍——类型检查与跑批测试均无法发现。系：**引理 35 在微调下不健全；须把「同 EC」升级为「同 EC 模有界 ΔEC + CDM 见证」。**

**引理 42（SRL 收缩 ⇒ 证书误差有界）** 若 F 在 K 上 κ-压缩且 K 前向不变，则由 Banach 不动点定理，证书误差被 `d_C(z_hat,z*) ≤ d_C(z_hat,z_0)/(1−κ)` 界定；κ 越小界越紧，κ→1 界发散。回环闭合在正确门控下降低 κ；假回环可使 κ≥1，此时不再存在有界证书（与定义 391 的准入否决一致）。系：**「安全」是压缩性，不是步长；R73 的单调性是 κ=0 的退化。**

**定理 30（LOOPGAUGE 严格包含 MODGAUGE）** 冻结 L2/L3（M_t 固定、θ 不更新、κ_map=κ_ft=0）、关闭 CDM/ADB 后，SEM 输出置为固定地图先验、LCAA 恒 REJECT、FTG 恒 R1，则 LOOPGAUGE 逐指令等于 MODGAUGE（R73）；再按 R73 定理 27 退化到 EMBODIED/R71/R68。**安全单调不减，效率与适应性仅在环收缩且 ΔEC 有界时获益。**

**定理 31（微调感知的热替换定理）** 把 R73 引理 35 的前提从 `EC(impl')=EC(impl)` 替换为 `EC(impl')=EC(impl) 模 ΔEC ∈ R1/R2`，且 CDM 在晋升窗口内未触发。则系统级性质（退化链、风险单调、时序隔离、审计覆盖）保持，误差界由 `ε(ΔEC)+(1/(1−κ_ft))·δ_t` 给出；R3 微调使前提不成立 ⇒ 定理不适用 ⇒ 必须否决。系：**热替换定理的「同契约」必须被重新定义为「同契约 + 漂移有界 + 监测见证」，否则微调把它变成证书洗白。**

**定理 32（SLAM 闭环证书）** 在 (i) 三门槛控、(ii) ρ_map 保守融合、(iii) CDM 在线、(iv) κ_map<1 下，`Valid(J_SLAM)` ⇒ 位姿-地图误差 ≤ `ε_slam/(1−κ_map)`；假回环被接受的概率 ≤ α_place·α_geom（conformal 覆盖），且每次接受都留可复算的追溯记录。系：**SLAM 从「整体不可审计的优化器」变为「可组合、可追溯、可否决的证据模块」。**

**定理 33（自适应预算与证书欠账有界）** 若每次 R1/R2 晋升成本有正下界、回滚成本上界有限、且 R3 一律否决，则 `B_adapt` 有限 ⇒ 有限步内要么晋升要么停止；证书欠账 `debt_t = Σ (延迟未重认成本)` 由 B_A 与 δ_max 共同界定，不会无界累积。系：**适应性是预算问题，不是意志问题。**

## 2. 形式化定义（要点版）

**定义 383（总览与六不变式）** 契约完整 / 组合单调（逐点）/ 反作用通道完备 / 主张绑定 C1–C5 / 严格退化链 / **闭环收缩（κ<1 且 Δ_t≤Δ_max）**。冻结 L2/L3 即退回 MODGAUGE。

**定义 384（SEM）** 联合后验 p(x_t,M_t|y,u)；六分量，其中 u_alias/u_dyn 为**致灾非高斯项**，只能 hazard + 否决，不得压成方差；地图表示 rep 进契约（换表示=可审计契约变更）。

**定义 385（LCAA）** 回环 = `e_now ⊕_gate e_map`；G1∧G2∧G3 全过才许缩窄，单源禁止；接受即 `LC: Σ_x^{1:t}→Σ_x'^{1:t}` 追溯改写，`τ_merge` 须 time-reversible，窗口 W_lc 内重算证书并记录 δ_map。

**定义 386（ρ_map）** 共因团 C_M；PAR 强制 `ρ̂_eff=max(ρ̂_obs,ρ_map)`；忽略地图共因即低估融合方差（引理 40）。

**定义 387（EC_t 与漂移）** `δ_t = w1·W2(𝔽_lik)+w2·d_H(D)+w3·|ΔB|/B+w4·‖ΔR_corr‖`；组合下界随 Δ_t 单调变松，漂移只记账不吸收。

**定义 388（FTG / ΔEC / 三体制）** 微调是证书修订算子；R1 廉价重封；R2 分域证书；R3 否决（含静默缩域）。引理 35 的「同 EC」升级为「同 EC 模有界 ΔEC」。

**定义 389（CDM）** 冻结的 conformal e-process，任意时刻有效；`P(∃t:E_t≥1/δ | 可交换)≤δ`；触发按体制降级/回滚。

**定义 390（ADB / 影子晋升）** 预算 B_adapt；候选证据 u=∞（影子）；晋升 = CDM 连续 N_min 步过 ∧ ΔEC∈{R1,R2} ∧ 密封审计；失败无痛回滚。

**定义 391（SRL / 闭环收缩）** 三层环 L1/L2/L3；`d_C(Fz,Fz')≤κd_C(z,z')` ⇒ 误差 ≤ `d_C(z_hat,z_0)/(1−κ)`；κ=max(κ_map,κ_ft,κ_reflex)<1；κ 由密封集谱范数估计并写入 EC 的 `κ_cert`。

**定义 392（AIC-SLAM 威胁面）** 感知混叠伪装 / 回环注入 / 地图投毒 / GNSS/UWB 重放 / 动态物对抗 / **地点识别后门（微调注入）**；后门检出归 R3（Δ_lik 触发子簇）。

# IP-303 SEM：位姿-地图耦合证据对象
class SLAMEvidenceMetrology:
    def update(self, scan, odom, imu, peers, map_db):
        x_pred, S_odom = self.odom_propagate(odom, imu)          # u_odom
        M, S_M         = self.map.query(x_pred)                  # u_map（含 rep）
        u_alias, margin = self.alias_discriminant(scan, M, imu)  # hazard（非高斯）
        u_sync         = self.clock.skew_bound(scan, imu)
        u_dyn          = self.dynamic_mass(scan)                 # hazard
        return SLAMEvidence(
            x=x_pred, M=M, S_x=self.propagate(S_odom, S_M),
            u=quad(u_odom, u_lc, u_map, u_sync),
            hazard=Hazard(alias=margin, dyn=u_dyn),
            domain=(margin >= TAU_ALIAS) and (self.inlier >= TAU_IN)
                   and self.tracking_ok and (u_sync <= TAU_SYNC),
            tau=self.tchain.merge(scan.tau, odom.tau, imu.tau))

# IP-304 LCAA：三门槛控 + 追溯
def loop_closure_gate(e_now, e_map, audit):
    if not audit.conformal_covers('place', e_now, e_map): return REJECT, 'G1'
    if not audit.conformal_covers('geom',  e_now, e_map): return REJECT, 'G2'
    if not any(audit.conformal_covers(m, e_now, e_map)
               for m in ('odom','imu','semantic')):            # G3
        return REJECT, 'G3_SINGLE_SOURCE'
    rho = max(audit.corr_obs(e_now, e_map), audit.rho_map(e_now, e_map))
    return ACCEPT, fuse(e_now, e_map, rho)                      # 仅此时缩窄

def apply_loop_closure(hist, lc, W_LC):
    hist = retro_update(hist, lc, window=W_LC)                  # 追溯改写
    hist.delta_map = recompute_cert(hist, window=W_LC)
    return hist

# IP-305 FTG：微调三体制
def fine_tune_regime(theta, theta_p, holdout, alpha):
    d_cal = abs(coverage(theta_p, holdout, alpha) - coverage(theta, holdout, alpha))
    d_lik = two_sample_distance(residuals(theta_p, holdout), residuals(theta, holdout))
    d_dom = domain_change(theta, theta_p)                       # 收缩<0 禁止
    d_cor = corr_change(theta, theta_p)
    if d_dom < 0:                      return 'R3', (d_cal,d_lik,d_dom,d_cor)
    if d_cal <= EPS_C and d_lik <= EPS_L and d_dom == 0:
                                       return 'R1', (d_cal,d_lik,d_dom,d_cor)
    if d_dom > 0 and d_cal <= EPS_C:   return 'R2', (d_cal,d_lik,d_dom,d_cor)
    return 'R3', (d_cal,d_lik,d_dom,d_cor)

# IP-306 CDM：任意时刻有效漂移监测（冻结，不可在线微调）
class CertDriftMonitor:
    def __init__(self, alpha, delta, lam=0.5):
        self.alpha, self.delta, self.lam, self.logE = alpha, delta, lam, 0.0
    def update(self, p_value):
        g = 1.0 - p_value
        self.logE += math.log1p(self.lam * (g - self.alpha))
        return 'SHIFT_DETECTED' if self.logE >= math.log(1.0/self.delta) else 'OK'

# IP-307 ADB：自适应预算 + 影子晋升
def adaptation_step(module, candidate, budget):
    regime, dec = fine_tune_regime(module.theta, candidate.theta,
                                   module.holdout, module.alpha)
    if regime == 'R3': return reject('CONTRACT_BREAK')
    if budget.spent + cost(regime) > budget.B_A:
        return shadow(candidate, reason='BUDGET')               # u=∞
    if regime == 'R1': return promote(candidate, cost=cost('R1'))
    return promote_partitioned(candidate, region=certified_region(candidate))

# IP-308 SRL：κ 估计与准入
def loop_contraction_gate(F, z0, dC, K_audit):
    kappa = spectral_norm_est(F, z0, dC, K_audit)
    return (kappa * (1 + MARGIN) < 1.0), kappa

# IP-309 LOOPGAUGE 主闭环（复用 R73 三域）
def LOOPGAUGE_round(M, obs, audio, tac, depth, scan, odom, imu):
    d_ev = M.dpe.update(depth, rgb, M.cam_state, M.motion, M.peers)
    s_ev = M.sem.update(scan, odom, imu, M.peers, M.map_db)
    if not s_ev.domain: s_ev = stub(M.sem)
    for cand in M.lc_frontend.propose(scan, M.map_db):
        status, payload = loop_closure_gate(s_ev, cand.e_map, M.audit)
        if status == ACCEPT:

    if M.clock.due_metric():
        b_t = M.bse.step_full(..., d_ev=d_ev, t_ev=M.dmem.last, s_ev=s_ev)
        if M.cdm.update(M.calib_pvalue(b_t)) == 'SHIFT_DETECTED':
            M.adapt.downgrade()
        g = M.ervoi.choose(...)
        if g:

            if s2 is not None: M.last_g, M.state = g, s2
        if not loop_contraction_gate(M.F, M.z, M.dC, M.audit.sealed)[0]:
            M.adapt.freeze_loops()
        M.mreg.audit(); M.snapshot.write(...)
    snap = M.snapshot.read_latest()

## 4. 推导

**引理 38（SLAM 六分量条件正交）** 给定运动模式/静态性/同步/表示，odom/lc/map/sync 独立机制近似不相关；alias/dyn 多峰重尾，不得方差化，只能 hazard。系：**SLAM 不确定度必须「高斯 + hazard」双轨。**

**引理 39（回环门控保守性）** 单源回环无论置信多高都不能严格缩小 Σ_x；三门槛控下接受等价于通过 conformal 审计的 PAR；追溯改写仅在前后向一致时单调不增。系：**「回环让一切变好」是错觉——只有独立模态见证的回环才允许变好。**

**引理 40（ρ_map 下界保守性）** 忽略地图共因会低估融合方差；`ρ̂_eff=max(ρ̂_obs,ρ_map)` 保证 `Σ_fuse(ρ̂_eff) ≥ Σ_fuse(R_true)`。系：**ρ_map 把「认知免费午餐」收回。**

**引理 41（微调安全判据）** 有界 ΔEC + CDM 未触发 ⇒ 证书有效，退化 ε(ΔEC)→0（ΔEC→0）；存在反例：校准集同分布微调令 Δ_cal≈0、类型全过，却在长尾/触发子簇抬高误检。系：**引理 35 在微调下不健全。**

**引理 42（SRL 收缩 ⇒ 误差有界）** F 在 K 上 κ-压缩且 K 前向不变 ⇒ `d_C(z_hat,z*) ≤ d_C(z_hat,z_0)/(1−κ)`；κ→1 界发散；假回环可致 κ≥1 而不再有界。系：**安全是压缩性，不是步长；R73 单调性是 κ=0 的退化。**

**定理 30（严格包含）** 冻结 L2/L3、SEM 置固定地图、LCAA 恒 REJECT、FTG 恒 R1 ⇒ 逐指令等于 MODGAUGE（R73），再退化到 EMBODIED/R71/R68。安全单调不减。

**定理 31（微调感知热替换）** 前提由「同 EC」替换为「同 EC 模 ΔEC∈{R1,R2}」且 CDM 晋升窗口未触发 ⇒ 系统性质保持，误差界 `ε(ΔEC)+δ_t/(1−κ_ft)`；R3 ⇒ 定理不适用 ⇒ 否决。系：**「同契约」必须重定义为「同契约 + 漂移有界 + 监测见证」。**

**定理 32（SLAM 闭环证书）** 三门槛控 + ρ_map + CDM + κ_map<1 ⇒ `Valid(J_SLAM)` ⇒ 位姿-地图误差 ≤ `ε_slam/(1−κ_map)`；假回环接受率 ≤ α_place·α_geom；接受留可复算追溯记录。系：**SLAM 从不可审计优化器变为可组合、可追溯、可否决的证据模块。**

**定理 33（自适应预算）** R1/R2 成本正下界、回滚成本有上界、R3 一律否决 ⇒ B_adapt 有限 ⇒ 有限步晋升或停止；证书欠账被 B_A 与 δ_max 共同界定，无无界累积。系：**适应性是预算问题。**

## 8. 本轮最大风险

**一句话**：LOOPGAUGE 把安全判据从「契约是否满足」推进到「环是否收缩、证书是否漂移」，但 **κ 估计器与 CDM 本身也在自指环内**——它们与被告对象共享数据/估计器族，一旦被微调污染或校准集与部署流共享隐变量，监测器就会「证明」一个已经撕裂的环仍然收缩；于是误差界用了错误的 κ、CDM 用了被污染的 p 值，系统在**监测器签字的合规日志**下闭环发散——**守卫者就在它所守卫的环里，而且它可以被微调。**

次级风险与缓解：
1. **κ 保守估计导致过度冻结（环长期 κ≥1 而系统本可运行）** → 分环估计 + 局部 κ + 只在必要时冻结 L2/L3；κ 低于阈值的证据缓存复用。
2. **CDM 与校准集共因污染** → CDM 冻结 + 独立硬件根信任 + 第三方密封审计集；CDM 自身的漂移只在离线审计。
3. **R2 分域证书的域边界模糊（连续域偏移）** → 域用可测统计量划分 + 边界处强制影子 + 保守并集。
4. **回环追溯窗口 W_lc 有限导致长程不一致** → 分层因子图 + 锚点证书 + 超窗只记账不静默丢弃。
5. **地图表示替换（rep 变更）被低估** → rep 进契约 + 换表示视为 R3（全量重证）。
6. **主动 SLAM 与任务目标冲突（探索 vs 安全）** → PVOP 多目标 + REG 时序契约 + V_safe 硬约束优先。
7. **MB4 过拟合/复现性** → SEAL-MB4 + 预注册 + 三方复现（E414）。
