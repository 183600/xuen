## 1. 直觉与动机（两个灵感的碰撞）

### 灵感 1：伦理审查 —— 不是合规成本，而是「治理不确定性」的工程学

**直觉**：伦理审查委员会问的从来不是「你准不准」，而是四件事：可能造成什么伤害（harm taxonomy）、谁负责（accountability）、能否证明（auditability）、能否撤回（reversibility）。把它翻译成策略设计就是：预先声明风险与停止规则（pre-registration）、逐决策留痕（audit ledger）、把「人的安全」设为不可交易的硬约束、其余任务风险才用期望值优化。

**严谨定义**：安全约束分两层——硬约束集合 `C_hard`（人身安全、关节/速度界、工作空间）按**字典序**优先，任何分数不能与之交换；软任务风险（掉落、碰撞、漏抓）才进入期望效用裁决。研究过程同样受审：进入真机的实验必须先预注册（假设/主指标/样本量/停止规则），结果全量报告，偏差留痕。形式化见产物区 §1.3、§1.4。

**反直觉点**：在存在不可逆失败（掉落、碰撞、终止）时，**校准过的「会弃权」不是分数的税，而是正期望收益**；但前提是弃权阈值被标定，而不是拍脑袋。

### 灵感 2：SLAM —— 不是建整间屋子的图，而是建「对象的信念」

**直觉**：桌面任务的「定位」大半由本体感知给出（EE 位姿在 base 系直接可读，腰/腿给出头部位姿），真正缺的是「目标对象此刻在哪、我有多确定、被手挡住后它去了哪」。全 SLAM 是杀鸡用牛刀；可迁移的内核是四件事：对象级地图、位姿协方差、遮挡期间预测、重观测时重定位/闭环。

**严谨定义**：M-SLAM = 以对象位姿为节点的滑动窗口因子图；观测来自头双目三角化与腕部近景，先验来自本体里程计与离线手眼标定；输出对象位姿 `(T_o, Σ_o)` 与可见性状态；**事件触发**更新（首次观测、抓取/释放、人干预起止、重投影残差超阈、最大间隔），非事件步用常速度预测并膨胀协方差。形式化见产物区 §1.1–§1.2。

**反直觉点**：SLAM 在这里的价值不是「更准的坐标」，而是「**知道自己有多不准**」——协方差是安全闸与弃权决策的输入，恰是端到端 VLA 最缺的东西。

### 碰撞：两者都是「对信念的治理」

SLAM 治理**空间信念**（地图一致性、闭环检测、漂移告警），伦理审查治理**行为信念**（伤害分类、责任链、可逆性、审计）。统一成一句话：**下一阶段的边际收益不在「更大的模型/更多的数据」，而在「受治理的不确定性」（governed uncertainty）——策略要知道自己不知道什么，保留可复核的空间记忆，并能证明自己的每个决定。**

与前两轮衔接：I1/I2 把训练分布搬进考纲，I5 造失败示教，I9 检索先验；本轮 I10 给它们一个「空间信念底座」，I11/I12 给整个系统一个「可审计的安全壳」。数据侧仍是主线，但本轮补上部署侧的可信度。

## 2. 对第 2 轮痛点的增量修订

- P3/P4（人干预/无触觉）：M-SLAM 的遮挡预测 + 重定位，为「手挡住目标」提供第二条恢复路径（第一条是 I5 合成示教）。
- P5（时间压力）：得分点制下，弃权只损失时间、不抹掉已得步骤分；因此「校准弃权」的代价可量化（产物 §1.3 的 `p*` 阈值）。
- P7（先手/可信度）：官方明示记录时延波动与动作统计规律作为可信度依据（F25）——I11 的审计链与 I6 的稳定时延同向，可信度本身可能影响成绩展示与裁判判断。
- 新增 **P9（空间信念缺口）**：端到端策略没有显式对象位姿/协方差，遮挡与干预后「目标在哪」只能靠隐状态猜。
- 新增 **P10（治理缺口）**：无预注册、无逐决策审计、无伤害分类；在稀缺真机通道上极易过拟合/选择性汇报，且难以向组委会证明合规。

## 3. 研究问题（本轮立项 Q9–Q11，Q1–Q8 保留）

- **Q9（对象级建图的最小充分性）**：只有头双目+腕部+本体位姿时，对象位姿与协方差的精度/延迟能否支撑抓取与插入？哪些任务族值得开 M-SLAM，哪些应退回纯端到端？
- **Q10（校准弃权的可迁移性）**：灾难概率 `p` 的离线标定能否迁移到「未见物品/人为干扰」分布？可靠性图（ECE/Brier）如何随轴偏移退化，退化到何时应放弃校准弃权、退回固定安全包络？
- **Q11（审计的可执行性）**：预注册 + 哈希链审计 + 来源清单，能否在不增加真机预算的前提下降低「选择性汇报/测试集污染」，并被组委会认可为可信度加分项？

## 4. 设计原则（新增 PR6–PR8，其余保留）

- **PR6 可审计律**：任何进入 L2 真机的实验必须先预注册（假设/指标/样本量/停止规则）；任何提交的 checkpoint 必须能导出逐 episode 审计摘要。不可审计的增益不采信。
- **PR7 安全字典序**：人身安全与硬约束永远优先于分数；软任务风险才允许期望值权衡。禁止用「期望收益」为可能伤人的动作辩护。
- **PR8 来源可追溯**：训练/检索/合成数据必须有 manifest（来源、许可、生成参数、种子）；评测数据不得进入训练或检索索引（防测试集污染）。
- PR1–PR5 保留。

## 6. 本轮最大风险（一句话）

**M-SLAM 的协方差与弃权阈值都依赖离线标定，而评测的「人为干扰/未见物品」恰是标定分布之外；若标定不迁移，安全闸要么过度弃权丢步骤分、要么在真正危险时失效——这是「治理不确定性」方案自身的不确定性，必须先过 L0 校准 + 真机小样本校准，才允许上计分通道。**

## 7. 下轮迭代计划（深化与修剪，不推倒）

- **深化 I10**：用官方数据做头双目/腕部标定的离线探针，给出对象位姿与协方差的实测分布（不是拍脑袋）；在官方 Isaac 仿真（F14）拿 GT 对象位姿做 NEES 校验。
- **深化 I11**：把 I8 注册表改造成「预注册 + 哈希链」最小可用版本，先在 L0 跑通，再用于首个 L2。
- **深化 I12**：在离线扰动上标定 `p(u)`，画可靠性图；只有 ECE < 0.1 且 AUC > 0.8 才允许开启校准弃权，否则退回固定保守包络并记录。
- **修剪**：I7 推理路径正式裁撤；I10 若 L0 显示对抓取/插入精度无增益，降级为仅训练期辅助监督（不占推理预算）。
- **待核实**：组委会对「几何组件是否属于单模型」的书面口径；评测是否允许策略内部做在线几何估计（非学习）；human-interference 的具体交互协议与安全责任边界。

- 风险：误检索伤原本会的任务（软偏置+阈值门控）；嵌入对同类不同外观不敏感（拼接几何描述/多 patch 池化）；合规性书面确认。

### I10 M-SLAM：对象级空间记忆（新） ★★★★
- **动机**：五轴中「人为干扰」会造成遮挡与对象位移；端到端 VLA 无显式对象位姿与协方差，遮挡后只能靠隐状态猜（P9）。无触觉（F8）下，几何位姿是接触段最便宜的替代信息。
- **与现有方案差异**：纯端到端靠数据隐式学空间；本点在策略内部维护一个**事件触发、episode 级、对象为中心**的轻量因子图，输出 `(T_o, Σ_o)`。不是全 SLAM：底座由 `action.pivot`/腿里程计积分，头部由腰部关节给出，EE 位姿直接可读（F20/F23），所以只解「对象在哪 + 多不确定」。
- **技术可行性**：中-高。头双目可三角化（F22/F26）；腕部用手眼标定（离线，用 EE 位姿 + 官方数据）；对象检测/分割用开放词汇模型；位姿用 PnP/ICP + 小窗口优化；事件触发使平均开销 <2ms。
- **所需资源**：离线标定 1 GPU 日；M-SLAM 工程 1 人 × 3 周；推理不新增 GPU（CPU/轻 GPU），事件触发 ≤10ms。
- **落地步骤**：①用官方数据标定头双目内外参与腕部手眼；②在 Isaac 仿真（F14）用 GT 对象位姿验证位姿误差与 NEES；③实现事件触发因子图与重定位；④接 I3（接触段）、I4（干预后重定位）、I9（稳定 crop）；⑤L0 消融后再上 L2。
- **风险**：标定误差、对象对称性歧义、遮挡期漂移；缓解见 §1.2（多假设、协方差膨胀、残差门控）。**单模型边界**：默认只在 reset 与事件点更新，且提供「仅训练期辅助监督」降级（见 §4）。

### I11 伦理审查式评测治理（新） ★★★★
- **动机**：真机通道稀缺且非独立同分布（同一批机器人、同一批场景），极易「在排行榜上做 p-hacking」；官方又明确用交互时延/动作统计评估可信度（F25）。治理缺口（P10）同时是科学风险与合规风险。
- **与现有方案差异**：多数队伍只记「跑通了/没跑通」；本点把每次 L2 当作一次**注册报告（registered report）**：先预注册，再执行，全量登记，偏差留痕，哈希链可验。
- **技术可行性**：高。纯流程 + 轻量脚本；不占 GPU。
- **所需资源**：1 人周工程；表格/脚本；无额外算力。
- **落地步骤**：①定义预注册 schema；②哈希链审计日志；③伤害分类表（§4）；④来源 manifest；⑤首个用例 = I2 孪生迁移家族消融；⑥把「审计摘要」接入 I6。
- **风险**：流程开销拖慢迭代（缓解：模板化 + 自动化，预注册只写 1 页）；审计暴露失败结果（缓解：这正是可信度来源，内部先脱敏）。

### I12 双层安全闸：硬约束 + 校准弃权（新） ★★★★
- **动机**：人干预轴要求「让位」；掉落/碰撞是不可逆失败。伦理审查要求安全不能被分数交换（PR7），但一刀切保守又会丢步骤分。
- **与现有方案差异**：I4 只做「检测到手→停」的启发式；本点把安全分成**硬约束层**（字典序，永不交易）与**软风险层**（期望值 + 校准弃权阈值 `p*`），并用 I10 的协方差给 `p` 提供输入。
- **技术可行性**：高。规则 + 小模型/几何，CPU <2ms。
- **所需资源**：1 人周；离线标定 1 GPU 日。
- **落地步骤**：①实现硬约束投影/急停；②实现 `p(u)` 标定与 `p*` 裁决；③可靠性图验收（ECE/AUC）；④L0 消融；⑤L2 小样本校准；⑥与 I6 的时延监控联动。
- **风险**：`p` 标定不迁移（本轮最大风险）；缓解：分层回退 + 只在高置信任务族启用校准弃权。

## 1. 方案与推导

### 1.1 M-SLAM 的因子图与协方差（严谨定义）

坐标系：世界系 `W`（reset 时 base 位姿锚定）、base 系 `B`（x 前/y 左/z 上，F23）、头系 `H`、腕系 `C_w`、EE 系 `E`、对象系 `o`。

位姿来源（关键：哪些是观测、哪些要积分）：
- `T^B_E`：直接观测（F20）。
- `T^W_B(t)`：**不可直接观测**（F23/F27 无绝对 base 位姿），由 `action.pivot` 的 `(vx, vy, ω_z)` 与腿/腰本体感知积分：`T^W_B(t+1) = T^W_B(t)·Exp(ξ_odom(t))`，带里程计噪声 `Σ_odom`。
- `T^B_H`：由 `lower_body` 中腰部 yaw/roll/pitch 给出。
- `T^E_{C_w}`：离线手眼标定。
- 于是 `T^W_H = T^W_B·T^B_H`，`T^W_{C_w} = T^W_B·T^B_E·T^E_{C_w}`。

观测模型（头双目）：对 rectified 头图上的像素 `u`、视差 `d`，深度 `z = f·b/d`，反投影 `p^H = z·K^{-1}[u,1]^T`，再变换到世界系。对象关键点 `X_o`（对象系）的重投影残差：
`r_{k,i} = u_{k,i} - π(K·(T^H_W·T^W_o·X_o))`，`T^H_W = (T^W_H)^{-1}`。

MAP 估计（滑动窗口 `K`，稳健核 `ρ`）：
`T* = argmin Σ_{k∈K} Σ_i ρ(‖r_{k,i}‖²_{Σ_pix}) + Σ_t ‖Log((T^W_B(t))^{-1}T^W_B(t+1)(ΔT_odom(t))^{-1})‖²_{Σ_odom} + ‖T^W_o − T^W_{o,0}‖²_{Σ_0} + (腕部近景项)`。

协方差（Laplace/信息矩阵，边缘化 base 与相机）：
令 `Λ = J^T Ω J` 按 `(o, B)` 分块，则对象位姿边缘协方差
`Σ_o = (Λ_oo − Λ_oB·Λ_BB^{-1}·Λ_Bo)^{-1}`。
`Σ_o` 的迹是「我有多不准」的标量摘要，直接进 I12。

非事件步预测（常速度）：
`T^W_o(t+Δ) = T^W_o(t)·Exp(ξ_o·Δ)`，`Σ_o(t+Δ) = Σ_o(t) + Q(Δ)`，`Q(Δ)=diag(q_p Δ², q_r Δ²)`。

事件触发条件（满足任一即优化）：
`首次观测 ∨ 抓取/释放 ∨ 人干预起止 ∨ tr(Σ_o)>τ_Σ ∨ ‖r‖²>τ_r ∨ Δt>Δt_max`。
事件率目标 `r_e ≤ 3/s`，单次 ≤10ms，平均 <2ms；非事件步只有常速度预测，<0.1ms。

### 1.2 事件循环与重定位伪代码

```python
class MSLAM:
    def reset(self):
        self.graph = FactorGraph(); self.hypotheses = []   # episode 级，reset 清空
        self.last_kf = None; self.obj_pose = None; self.Sigma = None
        self.frozen_index_hash = load_train_only_index_hash()  # I9 来源门禁

    def observe(self, obs):
        # 1) 里程计：base 不可直接观测（F23），用 pivot/腿积分
        self.T_W_B = integrate_odom(self.T_W_B, obs["action.pivot"] if "action.pivot" in obs else obs, obs["lower_body"])
        # 2) 头双目 -> 对象点云/关键点；腕部近景
        kp_head = stereo_keypoints(obs["cam_left_high"], obs["cam_right_high"])
        kp_wrist = wrist_keypoints(obs["cam_left_wrist"], obs["cam_right_wrist"])
        # 3) 事件判断
        ev = self.is_event(obs, kp_head, kp_wrist)
        if ev:
            self.graph.add_keyframe(self.T_W_B, self.T_W_H, kp_head, kp_wrist)
            self.obj_pose, self.Sigma = self.graph.solve(marginalize=["B", "H", "Cw"])
            self.last_kf = self.obj_pose
            self.audit_event("mslam_update", ev, trace=float(self.Sigma.trace()))
        else:
            self.obj_pose, self.Sigma = self.predict(self.obj_pose, self.Sigma)
        # 4) 对称/歧义：保留多假设，安全闸用最坏情况
        self.hypotheses = self.data_associate(kp_head, kp_wrist, keep_top=3)
        return self.obj_pose, self.Sigma, self.hypotheses

    def is_event(self, obs, kp_head, kp_wrist):
        return (self.last_kf is None
                or self.grasp_transition(obs)
                or self.intervention_edge(obs)
                or self.Sigma.trace() > TAU_SIGMA
                or self.reproj_residual(kp_head) > TAU_R
                or (now() - self.last_t) > DT_MAX)

    def relocalize(self):
        # 人干预结束后：数据关联 + 几何校验；位姿跳变超阈则闭环重锚
        cand = self.data_associate(last_kp, current_kp, keep_top=3)
        if min(cand, key=cost).pose_jump > TAU_JUMP:
            self.audit_event("loop_closure", "reanchor")
            self.graph.reanchor(cand)
```

### 1.3 双层安全闸与校准弃权（推导）

**第一层：硬约束（字典序，不可交易，PR7）**
`A_hard = { a : joint/velocity/workspace 合规 ∧ r_human(a) ≤ ε_h }`，
其中 `r_human(a)=P(S(a) ∩ (H_occ ⊕ B_margin) ≠ ∅ | 人体占据 H_occ)`，`S(a)` 是候选动作 chunk 的 EE 扫掠体，`B_margin` 是安全裕度。若 `A_hard = ∅` → 急停/让位（`a_stop`），不接受任何「期望收益更高」的例外。

**第二层：软任务风险的期望值裁决**
对 `a ∈ A_hard`，令：
- `g(a)`：若不出灾难，执行本 chunk 的期望剩余步骤分增量；
- `p(a)`：发生不可逆灾难（掉落/碰撞/终止）的概率，由 `Σ_o` 与动作几何给出；
- `R_lost`：灾难导致的剩余潜在分数损失；
- `D(a)`：不可逆损害/恢复成本（任务相关，伦理上只对「物」计价，不对人计价）；
- `c`：弃权（停/退/重规划）一步的时间成本。

继续的效用：`U_cont(a) = (1−p)g − p(R_lost + D)`；弃权的效用：`U_stop = −c`。
继续 iff `U_cont > U_stop`：
`(1−p)g − p(R_lost+D) > −c`
`⇔ g + c > p(g + R_lost + D)`
`⇔ p < (g + c)/(g + R_lost + D) =: p*`。

**弃权规则**：`abstain(a) ⇔ p(a) ≥ p*(a)`。
单调性：`∂p*/∂g>0`（剩余分越多越敢冒险）、`∂p*/∂c>0`（弃权越贵越敢继续）、`∂p*/∂R_lost<0`、`∂p*/∂D<0`（越不可逆越早收手）——与直觉一致。

**p 的标定**：取风险标量 `u(a)`（例如 EE 扫掠体与 `Σ_o` 椭球/人体占据的归一化重叠，或抓取点的马氏距离），用 logistic `p = σ(αu+β)`，在 I1 合成扰动 + L2 小样本上用 MLE 拟合。验收：可靠性图 + ECE + Brier + AUC；**只有 ECE<0.1 且 AUC>0.8 才开启校准弃权**，否则退回固定保守裕度并记录（分层回退）。

**多假设处理**：对象对称/遮挡歧义时保留 `K≤3` 个假设；安全判定取**最坏情况**（`max_k r_human`、`min_k` 安全裕度），任务收益取期望（按假设权重）。宁可保守，不用平均掩盖风险。

## 6. 本轮最值得押注（一句话）

**押「受治理的不确定性」：I10（M-SLAM 对象位姿+协方差）× I12（硬约束 + 校准弃权）× I11（预注册 + 哈希链审计）——前两轮把训练分布搬进考纲，这一轮把「知道自己多不确定、并能证明自己的决定」做成可计分、可合规、可复现的部署能力；它同时吃「人为干扰」轴、接触任务与可信度条款三块分数。**

## 7. 本轮最大风险（一句话）

**M-SLAM 的协方差与弃权阈值依赖离线标定，而评测的「人为干扰/未见物品」正是标定分布之外；若标定不迁移，安全闸要么过度弃权丢步骤分、要么在真正危险时失效——必须先过 L0 校准（NEES/ECE）与真机小样本校准，才允许上计分通道。**
