# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 1 轮；本轮灵感：「专利布局」×「语义分割」）

> 前 54 轮已建立「鲁棒性谱 ρ + 反向解释 Explain + 动作空间剖面 α_S + 云边联合证书 J」的层级体系。本轮引入两个新透镜：**语义分割**把能力从「单点/全局保证」推进为「任务-上下文-动作域上的稠密逐点标注」；**专利布局**把一组证书从「零散证据」推进为「有权利要求边界、篱笆与空隙账本的组合」。核心矛盾：H22：能力证书是粗粒度、二值/全局的，无法刻画部署域的稠密异质性，区域边界处存在系统性「语义渗漏」；H23：证书集合缺乏布局概念，既可能留下可被绕过的覆盖空洞，也可能大量冗余重叠，且无法回答「这项创新相对已有 IP 的新颖性与可规避性」。

## 0. 直觉与动机

**灵感 1（语义分割 → 把能力保证变成稠密能力图）**
直觉：此前 `ρ_S(d)` 是技能级的标量谱，`α_S(a)` 是动作占用剖面，仍不足以保证「在某个任务×上下文×动作点上是否真的能安全执行」。把部署域 `X = T × C × A` 想象成一张图像，每个点 `x=(τ,c,a)` 是一个像素，能力证书不是给整张图盖章，而是给**逐像素**打标签：`core`（可直接部署）、`buffer`（有条件、需缓冲）、`void`（禁止）、`unknown`（证据不足）。于是能力问题从「这个技能行不行」变成「这张能力图的 mIoU、边界 F1 与边界熵是多少」。分割的核心价值不是像素分类本身，而是**显式暴露边界**：真正危险的从来不是 core 内部，而是 core/buffer/void 三者的交界。

**灵感 2（专利布局 → 每条证书就是一条权利要求）**
直觉：一条能力证书 `c` 不只是「某区域能工作」，而是一条**权利要求**：它有作用域 `R_c`（claim scope）、可实施证据 `E_c`（enablement）、鲁棒性承诺 `ρ_c`、相对已有证书的新颖性 `n_c`，以及被他人「设计绕过」的风险。一组零散证书若各自为战，会同时出现**覆盖空洞**（gaps：关键路径上没人认领）与**冗余堆叠**（overlap：同一区域被多条弱证书重复覆盖）。专利布局的启示是：要像布置专利族一样布置证书——**核心权利要求守住 core，外围/篱笆权利要求包住边界，延续/分案在漂移后补位，并用空隙账本审计可绕过路径**。

**灵感 3（分割 × 布局 的耦合 → 先画图，再布点）**
直觉：语义分割回答「地形长什么样」，专利布局回答「在哪些地形上插旗、哪些边界要修篱笆、哪些空隙必须补」。若没有分割，布局只能凭经验撒点，无法知道边界在哪；若没有布局，分割只是漂亮的热力图，无法给出「部署承诺 + 责任边界」。二者耦合后，`buffer` 区域自然对应**篱笆权利要求**，`unknown` 区域对应**主动探测预算**，`void` 区域对应**禁止主张**（任何声称覆盖 void 的证书直接失效）。

**灵感 4（边界漂移 → 仿真到现实的分割迁移）**
直觉：分割模型在仿真里边界清晰，到真实边端会整体漂移（阈值、摩擦、延迟、传感器噪声）。专利布局里对应「权利要求的等同原则/外围篱笆」：不能只精确覆盖 `R_c`，还要按漂移上界 `ε_drift` 做**膨胀式篱笆**，让边界移动后仍落在护栏内；否则证书会在真实系统上「字面侵权落空」。

**灵感 5（研究贡献层面的专利布局 → 让创新点本身可辩护）**
直觉：本轮不只做技术，还做一次元层面的布局：把 v31 的 IP-115~120 视为已有权利要求，把本轮新算子视为新申请，要求每条新 IP 都有**非被包含性**（不被旧 IP 覆盖）、**可实施证据**（伪代码 + 实验）与**设计规避意识**（指出别人可能怎样绕过）。这把「找创新点」从灵感堆叠变成在**设计空间空白处**有意识地落子，直接服务于 UniBot 参赛叙事。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（能力语义域与分割映射）**
部署域 `X = T × C × A`（任务 × 上下文 × 动作），标签集 `L = {core, buffer, void, unknown}`。能力分割器 `f_θ : X → Δ(L)` 输出概率单纯形，预测 `ŷ(x) = argmax_ℓ f_θ(x)_ℓ`；区域 `R_ℓ = {x | ŷ(x)=ℓ}`。真值 `ℓ*(x)` 由回滚 oracle 给出：`core` = 连续 k 次成功且 `ρ≥ρ_min`，`buffer` = 有界成功率或需约束，`void` = 失败/越界/安全违规，`unknown` = 证据不足。

**定义 122（分割质量与边界）**
逐类 IoU：`IoU_ℓ = |R_ℓ ∩ R*_ℓ| / |R_ℓ ∪ R*_ℓ|`，`mIoU = (1/|L|)Σ_ℓ IoU_ℓ`。边界集 `∂R = {x∈R | ∃x'∈N(x), ŷ(x')≠ŷ(x)}`，边界 F1 为边界像素上的精确率/召回率调和均值。边界熵 `H_b = mean_{x∈∂R} H(f_θ(x))`，校准误差 `ECE = Σ_b (|B_b|/N)|acc(B_b)-conf(B_b)|`。

**定义 123（能力权利要求）**
一条权利要求 `c = (R_c, ρ_c, E_c, n_c, type_c)`：
- `R_c ⊆ X` 为作用域；`type_c ∈ {core, fence, continuation}`；
- `ρ_c = min_{x∈R_c} ρ(x)` 为区域内最差鲁棒性；
- `E_c` 为可实施证据（回滚样点、反例、仿真日志）；
- `n_c = dist(R_c, ⋃_{c'∈P} R_{c'})` 为相对已有组合 `P` 的新颖性裕度。
`valid(c) = [E_c ≠ ∅] ∧ [R_c ∩ R*_void = ∅] ∧ [ρ_c ≥ ρ_min] ∧ [n_c ≥ θ_n]`。

**定义 124（证书布局与空隙账本）**
布局 `L = {c_1,...,c_m}`，覆盖强度 `cov_L(x) = max_{c_i ∋ x} ρ_{c_i}`。关键域 `X_crit ⊆ X` 为任务必经点。空隙账本 `G_L = {x∈X_crit | cov_L(x) < θ_cov}`；冗余 `R_L = Σ_i |R_{c_i} ∩ ⋃_{j<i} R_{c_j}| / |⋃ R_{c_j}|`；篱笆 `F_L = {c∈L | type_c = fence ∧ ∂R ⊆ R_c ⊕ ε_drift}`。

**定义 125（布局目标）**
`min_L  J(L) = λ_g|G_L| + λ_r R_L + λ_v Σ_{c}(1 - valid(c)) + λ_b Bypass(L)`
约束：`∀x∈R*_core, cov_L(x) ≥ ρ_min`；`L` 对 `R*_void` 零覆盖；`Bypass(L)` 为从起点到目标、避开 `⋃R_c` 的最短可执行路径成本（越大越不可绕过）。

**定义 126（分割-布局联合证书 FTO）**
`F = (f_θ, L, ∂F, G_L, ε_drift, mIoU_core, evidence)`。若 `mIoU_core ≥ θ_iou`、`G_L = ∅` 或 `|G_L| ≤ δ_g`、`Bypass(L) ≥ τ_bypass`、`boundary_drift(L) ≤ ε_drift` 且 `L` 全 valid，则称 `F` **可部署**。它同时是技术部署凭证与「自由实施（freedom-to-operate）」凭证。

### IP-121 CSS（Capability Semantic Segmentation）

def capability_segmentation(domain, oracle, ensemble, budget):
    S = active_sample(domain, ensemble.disagreement, budget)   # 边界优先采样
    for x in S:
        y[x] = oracle.rollout_label(x)        # core / buffer / void
    f = ensemble.fit(S, y)
    boundary = extract_boundary(f, domain)    # 邻域标签变化点
    return f, boundary, seg_metrics(f, boundary)

### IP-122 CLAIM（Certificate Layout as Claim Portfolio）

```python
def build_portfolio(f, prior_claims, theta_n, budget):
    claims = []
    for R in connected_regions(f, labels={'core','buffer'}):
        c = Claim(R, rho=min_rho(R), evidence=probe(R), type='core')
        if valid(c, prior_claims) and not subsumed(c, claims):
            claims.append(c)
    G = critical_domain(f)
    while uncovered(G) and len(claims) < budget:
        c = argmax_candidate(covered_new(c)/cost(c))
        claims.append(c)
    return claims
```

### IP-123 FENCE 与 IP-124 GAP

```python
def fence(boundary, eps_drift):
    return [Claim(dilate(b, eps_drift), type='fence',
                  evidence=probe(dilate(b, eps_drift))) for b in boundary]

def audit_gaps(claims, X_crit, attacker_graph):
    cov = union(c.scope for c in claims)
    gaps = X_crit - cov
    bypass_cost = shortest_path(attacker_graph, blocked=cov)
    return gaps, bypass_cost
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| CSS | O(B·\|X\| + N·log N) | O(\|X\|) | 主动采样覆盖边界、校准 |
| CLAIM | O(m·\|X\| + m²) | O(m·\|X\|) | valid 的 soundness、非被包含 |
| FENCE | O(\|∂R\|·ε_drift^d) | O(\|∂R\|) | 漂移界覆盖 |
| GAP | O(\|X\| + \|E_att\| log \|V\|) | O(\|X\|) | 攻击图完备、路径成本下界 |

**正确性定理（Segmentation-Layout Deployment Soundness）**
假设 (A29) 分割在 core 上的误判率 `P(ŷ≠ℓ*) ≤ ε_seg`；(A30) 每条 valid 权利要求在其作用域内满足 `ρ ≥ ρ_min` 且不覆盖 void；(A31) 关键域空隙 `|G_L| ≤ δ_g` 且可绕过成本 `Bypass ≥ τ_bypass`；(A32) 边界漂移被篱笆吸收，`drift ≤ ε_drift`。则
`P(success | F deployable) ≥ 1 - ε_seg - Σ_d(1-ρ_min(d)) - δ_g - P(drift>ε_drift)`。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 分割标签昂贵且边界真值稀疏 | 高 | 主动学习 + 边界优先采样 + 主动探测 |
| 分割置信度与真实失败脱钩 | 高 | 校准（temperature/ensemble）+ 反例回灌 |

## 6. 本轮最大风险

**一句话**：语义分割提供稠密地图、专利布局提供插旗与篱笆策略，二者耦合能把「能力证书」升级为「可部署 + 可辩护」的自由实施凭证；但最大风险是**地图与权利要求同源而自洽**——分割器相信的区域恰好就是证书覆盖的区域，于是空隙账本永远为空、边界永远校准良好，真实的 void 与可绕过路径被系统性遮蔽，故必须以**独立真实回滚、对抗性绕过搜索、对旧 IP 的新颖性审计**作为三重外部证据，绝不能把「分割器自认为的 core」当作部署与创新主张的共同前提。

## 2. 关键算法 伪代码

### IP-121 CSS（Capability Semantic Segmentation）

```python
def active_sample(domain, ensemble, budget):
    # 优先采样高熵 / 高分歧 / 邻近边界的像素
    score = lambda x: entropy(ensemble(x)) + boundary_proximity(x)
    return topk(domain, key=score, k=budget)

def capability_segmentation(domain, oracle, ensemble, budget):
    S = active_sample(domain, ensemble, budget)
    Y = {x: oracle.rollout_label(x) for x in S}   # core/buffer/void
    f = calibrate(ensemble.fit(S, Y))             # temperature / isotonic
    boundary = {x for x in domain
                if any(pred(f,x) != pred(f,xp) for xp in neighbors(x))}
    return f, boundary, {
        'mIoU': mean_iou(f, oracle, domain),
        'boundary_f1': boundary_f1(f, boundary, oracle),
        'ece': expected_calibration_error(f, S, Y),
    }
```

### IP-122 CLAIM（Claim-Portfolio Layout）

```python
def subsumed(c, portfolio):
    return any(c.scope <= c2.scope and c2.rho >= c.rho for c2 in portfolio)

def build_portfolio(f, prior_claims, theta_n, theta_cov, budget):
    claims = []
    regions = connected_regions(f, labels={'core','buffer'})
    for R in regions:
        c = Claim(scope=R,
                  rho=min_rho(R),
                  evidence=probe_evidence(R),
                  novelty=min_dist(R, [p.scope for p in prior_claims]),
                  type='core')
        if valid(c) and not subsumed(c, claims):
            claims.append(c)
    G = critical_domain(f)
    while uncovered(G, claims) and len(claims) < budget:
        cand = best_candidate(G, claims, prior_claims)   # 边际覆盖/成本最大
        if not valid(cand) or subsumed(cand, claims + prior_claims):
            break
        claims.append(cand)
    return claims, gap_ledger(claims, G)
```

### IP-123 FENCE（Boundary Fence Claims）

```python
def fence_claims(boundary, eps_drift, rho_min):
    fences = []
    for b in boundary:
        R = dilate(b, eps_drift)                 # 按漂移界膨胀
        if covers_void(R):                       # 篱笆不得侵入 void
            R = R - void_region
        c = Claim(scope=R, rho=min_rho(R), type='fence',
                  evidence=probe_evidence(R), novelty=0.0)
        if valid_fence(c, rho_min):
            fences.append(c)
    return fences
```

### IP-124 GAP（Gap Ledger & Bypass Audit）

```python
def audit_gaps(claims, X_crit, attacker_graphs):
    cov = union(c.scope for c in claims)
    gaps = {x for x in X_crit if coverage_strength(claims, x) < theta_cov}
    worst_bypass = float('inf')
    for G in attacker_graphs:                    # 多攻击者 / 多起点
        cost = shortest_path(G, blocked=cov)     # 躲避所有权利要求
        worst_bypass = min(worst_bypass, cost)
    return gaps, worst_bypass
```

### IP-125 FTC（Freedom-to-operate Certificate）

```python
def fto_certificate(f, portfolio, X_crit, budgets):
    core = {x for x in X_crit if pred(f,x) == 'core'}
    if mIoU_core(f, core) < budgets.theta_iou:
        return ('reject', 'segmentation_weak', mIoU_core(f, core))
    for c in portfolio:
        if not valid(c):
            return ('reject', 'invalid_claim', c)
    gaps, bypass = audit_gaps(portfolio, X_crit, budgets.attacker_graphs)
    if len(gaps) > budgets.delta_g or bypass < budgets.tau_bypass:
        return ('reject', 'gap_or_bypass', gaps, bypass)
    drift = boundary_drift(portfolio, f)
    if drift > budgets.eps_drift:
        return ('reject', 'drift_exceeds_fence', drift)
    return ('ok', FTC(f=f, portfolio=portfolio, boundary=boundary(f),
                      gaps=gaps, drift=drift, evidence=collect_evidence(portfolio)))
```

### IP-126 NAP（Novelty Audit Placement）

```python
def place_novel_claims(prior_ips, design_space, budget):
    occupied = union(p.scope for p in prior_ips)
    whitespace = design_space - occupied
    candidates = enumerate_candidates(whitespace)      # 由本轮算子生成
    for c in candidates:
        c.novelty = min_dist(c.scope, occupied)         # 非被包含裕度
        c.enablement = evidence_strength(c)             # 伪代码/实验/定理
    sel = []
    while whitespace and len(sel) < budget:
        c = max(candidates, key=lambda c: covered_new(c, whitespace) * c.enablement)
        if c.novelty < theta_n or c.enablement < theta_e:
            break
        sel.append(c); whitespace -= c.scope
    chart = claim_chart(sel, prior_ips)                 # 新点 vs 旧 IP 差异表
    return sel, chart
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CSS | O(B·\|X\| + N·log N + \|X\|·\|L\|) | O(\|X\|) | 边界优先采样、校准后 ECE 可控 |
| CLAIM | O(m·\|X\| + m²·\|P\|) | O(m·\|X\|) | valid sound、非被包含可判定 |
| FENCE | O(\|∂R\|·ε_drift^d) | O(\|∂R\|) | 漂移界覆盖、不侵入 void |
| GAP | O(\|X_crit\| + K·(\|E_att\| log \|V\|)) | O(\|V\|+\|E_att\|) | 多攻击者、空隙保守 |
| FTC | O(\|L\|·\|X\| + GAP) | O(\|X\|+\|L\|) | 四项预算同时闭合 |
| NAP | O(\|Cand\|·\|P\| + budget·\|Cand\|) | O(\|Cand\|) | 新颖性/可实施双阈值 |

**正确性定理（Segmentation-Layout Deployment Soundness）**
假设第 54 轮 (A26)-(A28) 成立，并新增：
**(A29)** 分割在 core 上误判率 `P(ŷ≠ℓ*) ≤ ε_seg`；
**(A30)** 每条 valid 权利要求在其作用域内 `ρ≥ρ_min` 且 `R_c∩R*_void=∅`；
**(A31)** 关键域空隙 `|G_L|≤δ_g`，且任一攻击图上的可绕过成本 `Bypass(L)≥τ_bypass`；
**(A32)** 边界漂移被篱笆吸收，`drift≤ε_drift`。
则对可部署的 `F`：
```
P_success ≥ 1 - ε_seg - Σ_d(1-ρ_min(d)) - δ_g - P(drift>ε_drift)
```
且「自由实施」失败概率上界为 `P(∃ x∈X_crit: cov_L(x)<θ_cov)`，由 `G_L` 直接给出。

**命题 1（布局单调性）**：若 `L' ⊇ L` 且新证书均 valid，则 `|G_{L'}| ≤ |G_L|` 且 `Bypass(L') ≥ Bypass(L)`，但冗余 `R_{L'}` 可能上升——这正是布局需要 Pareto 优化而非「越多越好」的原因。

**命题 2（篱笆充分性）**：若 `∂R* ⊆ ∂R ⊕ ε_drift`，则真实边界漂移后仍被至少一条 fence 覆盖，证书不因边界迁移而失效。

## 7. 本轮最大风险

**一句话**：语义分割给出稠密能力图、专利布局给出权利要求与篱笆策略，使证书从「能跑」升级为「可部署且可辩护」；但最大风险是**地图与权利要求同源自洽**——分割器相信的区域正是证书覆盖的区域，于是空隙账本恒为空、边界恒校准、新颖性恒达标，真实的 void 和被绕过路径被共同遮蔽，故必须以**独立真实回滚、多攻击者绕过审计、对 v31 旧 IP 的外部新颖性审计**三重外部证据为锚，任何一条缺失都不得宣称自由实施。
