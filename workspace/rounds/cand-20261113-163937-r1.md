# 第 66 轮（承接第 65 轮「VISTA 视觉知情安全时序归因」IP-214~223；灵感循环第 3 轮；本轮灵感：「安全交互」×「嵌入式系统」）

> 第 65 轮用视觉与动作分块把 GRIP 的「几何可证伪」升级为「故障可归因」，其自述的最大风险一针见血：**FIR 假设故障属于有限假设集、且视觉与几何独立失效；未知复合故障会被强行塞进最近假设、只膨胀错误的球，系统还因「已经归因」而更自信地继续执行。** 本轮不再增加传感器，也不把归因做得更细，而是追问此前被默认掉的前提：**这张安全证书是在什么时间、什么平台上、替谁、以什么授权被执行的？** 当「人/伙伴」进入回路，「偏差」就不再只是故障；当平台有硬截止期，「证明」就不再与时间无关。本轮核心命题是：
>
> **把单机的「故障可归因」升级为交互的「契约可履行、时序可证明、平台可容错」：用安全交互把安全写成带假设与退出权的双向契约，用嵌入式系统的 WCET/混合关键级/分区容错把契约变成可实时执行的时敏证书；并接受一个反直觉结论——在硬截止期下，归因越久不一定越安全，过期的高置信可能比新鲜的保守更危险。**

## 0. 直觉与动机

**灵感 1（安全交互 → 安全不是「自证无罪」，而是「双方可履行的契约」）**
直觉：第 65 轮的 `J_vista` 本质是一张**自证**——「我算过、我归因了、我认为安全」。但真实的协作安全从来不是单方面的：人机协作里，机器人承诺「力不超过 F_lim、分离不小于 s_min、收到停止信号后 τ_stop 内停住」，这些承诺**只有在对方满足某些假设时才成立**（人不会突然以 3 m/s 冲进工作区、操作者不会在未授权时放开示教器、急停通道保持可用）。安全交互的关键词其实是三个：**承诺（commitment）、假设（assumption）、退出（withdrawal）**。把这三者显式化，安全证书就从「一次性的布尔判断」变成一个有状态的**双向契约**：对方进入监控区、松开 deadman、按下急停，**不是传感器故障，而是契约的合法退出**，系统应当暂停/交接，而不是把力残差硬塞进 `H_geo`。这直接修第 65 轮的一个盲点：它把「人做了意料之外但合法的事」误当成「某个模态坏了」。

**灵感 2（嵌入式系统 → 「证明」只在时间预算与分区内成立）**
直觉：第 65 轮反复强调「重推断在语义流，实时流只做轻量检查」，这在算法上是漂亮的，但在嵌入式安全工程里反而暴露了最大问题：**语义流是一个 best-effort、可被抢占、可能丢帧、可能延迟的不可信预言机**。一张由它生成、由实时流消费的证书，如果没有**时戳、有效期、WCET 预算、来源证明**，实时流根本无权相信它。嵌入式系统给的不是新算法，而是三条硬约束：(i) **WCET 与确定性**——最坏执行时间必须被界住，不能拿均值冒充；(ii) **混合关键级与分区**——学习任务与安全任务在时间/空间上隔离，过载时先削减低关键级任务；(iii) **失效语义**——halt、safe-stop、fail-operational、watchdog、lockstep、时钟/电压/温度导致的静默失效。于是本轮的深层动作是：把**学习栈显式降级为不可信分区**，让一个可认证的小核（TCC）只做有界检查并默认拒绝。

**灵感 3（两者合流的真正张力 → 认证时延悖论）**
直觉：设从「伙伴进入危险距离」到「必须停住」的总预算为 D，实际反应延迟 ≈ 感知 + **认证** + 决策 + 执行。认证不是免费的：归因支持集越大、假设越多、conformal 分位越细、认证前缀 `k*` 越长，花的时间越多，留给反应的时间越少。第 65 轮的「长预测、短执行」只优化了 `k*` 的**内容**，却没把**计算 `k*` 本身的时间**计入预算。于是出现一个自指：`k*` 的选择要花时间，而这段时间又必须从 `k*` 所依赖的预算里扣除；极端情况下，**越努力证明安全，越没有时间对危险作出反应**。这不是工程细节，而是一个可被形式化的**认证时延悖论**：在硬截止期外，增加归因精度不会提升可实现安全，反而可能降低它。它把「归因越充分越好」这条第 65 轮的隐含信念证伪了。

**灵感 4（合流 → PACT：Provable Assurance under Contracted Timing，时序契约下的可证明保证闭环）**
闭环：**交互承诺契约 ICC**（承诺/假设/退出/责任）→ **契约感知归因 C-FIR**（在 VISTA 的 6 假设上增 `H_partner/H_time/H_platform/H_consent`，区分「故障」与「合法退出/违约」）→ **时敏证书 TAC**（内容有效 + 时效有效 + 授权有效）→ **认证预算分配 CBA**（在硬截止期内选认证精度，解自指不动点）→ **可信时序契约核 TCC**（O(1) 检查、默认拒绝、只派发已认证包络内的动作）→ **契约保持的混合关键级调度 MCS**（过载时先削任务、绝不悄悄牺牲已武装契约的反应裕度）→ **归因新鲜度 FAI**（后验会老化，过期回先验）→ **反应时间分离监控 RSM**（把伙伴速度/遮挡的假设写成可实时验证的不等式）→ **同意/退出通道 CWC**（缺失 ≠ 中立，默认拒绝）→ 裁断 **fail-safe / fail-operational 逃生契约 FOP** → **防篡改安全轨迹 STR** 与 **AIC-P 对抗交互/时序认证**。不变式：**学习与归因永远在不可信分区；实时执行只由 TCC 依据「认知-时序-授权」三重有效性放行；任何一项缺失即默认拒绝。**

**灵感 5（VISTA 组件的原位升级）**
- **FIR → C-FIR**：假设集扩为 `ℋ_P = ℋ ∪ {H_partner, H_time, H_platform, H_consent}`；新增「合法退出/违约」语义；归因必须带时戳，过期自动降权。
- **AFA → AFA-T**：探针选择在硬截止期与授权约束下做；任何探测的时间成本计入反应预算；无有效授权不得探测。
- **CSC → T-CSC**：认证前缀保留，但 `k*` 必须满足「认证时间 + 执行时间 ≤ 截止期」的自指不动点，且证书带 TTL。
- **RSC-V → RSC-P**：不确定球增 `r_time / r_platform / r_partner`；时序故障膨胀 `r_time`、平台故障膨胀 `r_platform`；伙伴违约**不膨胀几何球**，而是挂起契约。
- **WCV-V → WCV-P**：搜索域再交「可调度集」——只保留能在保留预算内完成认证与执行的动作。
- **CSP-V → CSP-P**：在契约状态上规划；每条边需 TAC 三重有效；插入 `check_contract / request_consent / refresh_cert` 元技能。
- **AIC-V → AIC-P**：干扰集增对抗性不合作伙伴、被伪造/重放的同意信号、抖动/时钟漂移/位翻转/热节流。
- **OLP / DIR / SSB**：只在语义分区学习；其输出进入 TCC 前必须经 TAC 重新盖章，**学习结果不能直接改写实时契约**。
- **J_vista → J_pact**：证书增 `contract_state、tac(deadline/age/slack)、criticality_mode、consent_token_hash、timing_assumptions_ver、trace_hash`。

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（PACT 闭环）**：PACT = (VISTA, ICC, TAC, TCC, MCS, CBA, FAI, RSM, CWC, FOP, STR, AIC-P, J_pact)。定位：VISTA 的「交互契约 + 时序可证明 + 平台容错」升级。不变式：**语义分区（学习/归因/规划）不可信且可降级；实时分区只由 TCC 做有界检查、契约状态迁移、停止与派发；缺少认知/时序/授权任一有效性即默认拒绝。**
- **定义 234（交互承诺契约 ICC）**：ICC = (C, A, W, Σ, δ, L)。C 为机器人承诺的可测量、带时限的不变式（力/能量/分离/停止时间）；A 为承诺成立所依赖的伙伴与环境假设（人速上界、监控区、心跳频率、时钟界）；W 为同意/退出/权威令牌；Σ = {Proposed, Armed, Active, Suspended, Expiring, Aborted, Completed}；δ 为带时序守卫的状态迁移；L 为责任归因映射（承诺违约 vs 假设违约 vs 平台失效）。核心区分：**伙伴行使退出权或超出假设 ∈ 契约暂停，绝不记为 H_geo/H_force 等感知故障。**
- **定义 235（时敏证书 TAC）**：TAC = (J_vista, t_issue, τ_hold, b_wcet, age, prov_hash)。三重有效：**认知有效** Valid(J_vista)；**时序有效** `t ≤ t_issue+τ_hold ∧ age ≤ τ_hold ∧ slack ≥ 0`；**授权有效** consent_token 新鲜且在作用域内。其中 `τ_hold = min(τ_react_budget, τ_sensor_fresh, τ_model_drift)`。**过期是硬故障**（触发契约迁移），而非软降级。
- **定义 236（可信时序契约核 TCC）**：一个可认证的小核，只实现：TAC 三重检查、契约状态机、反应时间分离判定、停止/派发、watchdog 与安全轨迹落盘；指令与数据路径为 O(1) 有界查表/区间比较；时间/空间与学习分区隔离；其自身 WCET 经静态分析与目标机测量双重确认。TCC 的信任基 `T` 显式记录，且**学习分区永远不能写 TCC 的控制状态**。
- **定义 237（契约保持的混合关键级调度 MCS）**：关键级 `χ ∈ {LO 任务, HI 安全}`，预算对 `(C_LO,T_LO)`、`(C_HI,T_HI)`。每个已武装契约预留反应裕度 `R_c = τ_react + τ_stop + ε`。过载时先削减 LO 任务；**若 HI 模式下仍无法同时保住所有已武装契约的 `R_c`，则按优先级在截止期前逐个挂起并安全停车**。不变量：任何已武装契约要么承诺继续成立，要么在截止期前进入安全态。
- **定义 238（认证时延预算分配 CBA 与自指不动点）**：认证投入 `e`（支持集大小、前缀、采样数）给出认知保证 `G(e)`（单调增、凹）与认证时间 `C(e)`（单调增、凸）。硬截止期 `D`。可行域 `C(e) + τ_sense + τ_act + τ_margin ≤ D`。对认证前缀还须满足自指不动点：`k·Δt_act + C_cert(k) ≤ D − τ_sense − τ_margin`；若不存在 `k ≥ 1` 则回退到预认证的保守/停止包络。
- **定义 239（归因新鲜度与后验老化 FAI）**：信息年龄 `AoA(t) = t − t_obs`；后验按老化率 `λ` 退火，`τ_fresh` 后回到先验/均匀；定义归因半衰期 `τ_{1/2}=ln2/λ`。**过期的后验不得作为继续运动的依据**；`H_partner` 的后验尤其危险，因为伙伴在老化期间仍在移动。
- **定义 240（反应时间分离监控 RSM）**：对伙伴位置/速度的鲁棒 conformal 预测区间给 `s(t) − (v̂_h·τ_react + q_v(α)) ≥ d_safe`；含遮挡时把 `v_h` 退化为先验上界。等价的碰撞时间判据 `T_ic(t) ≥ τ_react + τ_stop + ε`。当伙伴超出假设上界，判为**假设违约**并触发保护性停止，而不是把它当作感知故障去「归因」。
- **定义 241（同意/退出通道与默认拒绝 CWC）**：同意令牌带作用域、时戳、MAC/attestation；心跳缺失、过期、作用域不符、签名无效一律 `DENY`。支持 deadman、release-to-move、双人规则与权威交接令牌。语义：**沉默不是同意，缺失不是中立**。
- **定义 242（契约感知故障/违约归因 C-FIR）**：`ℋ_P = ℋ ∪ {H_partner, H_time, H_platform, H_consent}`。`H_partner` 表示伙伴违约/合法退出（非故障）；`H_time` 表示抖动/延迟/时钟漂移/截止期错失；`H_platform` 表示位翻转/热节流/DVFS/内存破坏；`H_consent` 表示授权伪造/重放/作用域错误。可辨识性来自不同时间签名：`H_time` 同时在多通道出现且与时钟/抖动相关，`H_platform` 跨任务相关，`H_consent` 只在授权通道出现，`H_partner` 只在伙伴观测与分离通道出现。
- **定义 243（契约组合与权威交接）**：两个契约 `C1⊗C2` 可组合，当且仅当二者的承诺不冲突、假设相容、且任一时刻**至多一个权威令牌**有效；交接 `handover` 要求旧权威显式释放、新权威显式接受，并留下可审计轨迹。无有效权威 → 默认拒绝运动。
- **定义 244（失效运行逃生契约 FOP）**：当「停车」本身危险（搬运热物、楼梯、拥挤人群、悬挂负载）时，允许预认证的**有界退避/降级契约** `C_esc`，其承诺更弱但仍满足认知/时序/授权三重有效。系统在「停车的认证风险」与「逃生的认证风险」之间选较小者；二者都未认证时**不得自选「最小坏」**，必须交回人类授权或机械失效安全。
- **定义 245（安全轨迹与可审计日志 STR）**：时间触发记录契约状态、TAC 哈希/年龄/裕度、同意令牌哈希、关键级切换、调度证据与时钟证据；支持确定性重放与远程 attestation，使「为什么当时允许执行」可被事后重建。
- **定义 246（AIC-P 对抗交互与时序认证）**：`ℰ_P = ℰ_V × ℰ_inter × ℰ_time × ℰ_platform`。`ℰ_inter` 含不合作/对抗伙伴、伪造同意、欺骗性交接；`ℰ_time` 含抖动、时钟漂移、截止期错失、重放；`ℰ_platform` 含位翻转、热节流、DVFS、内存破坏。`n_cert` 128→192（64 给交互、时序、平台），最坏情形取 TCC WCET 上界与最坏伙伴行为。
- **定义 247（PACT 证书 J_pact）**：`J_pact = (J_vista, contract_state, tac, criticality_mode, consent_token_hash, timing_assumptions_ver, trace_hash, aic_p_ver)`。Valid ⇔ `Valid(J_vista)` ∧ 契约状态合法 ∧ TAC 三重有效 ∧（假设未违约 ∨ 契约已安全挂起）∧ 轨迹已落盘 ∧ `aic_p_ver` 为当前版本。
- **定义 248（PACT 闭环算子）**：语义分区 [VISTA → 实例化 ICC → C-FIR → CBA → T-CSC → CSP-P 规划]；实时分区 [TAC 三重检查 → consent 检查 → RSM → TCC 派发 → watchdog → STR]。**语义分区可以在任意时刻被降级或丢弃；已武装契约要么由预留裕度保住，要么由 TCC 在截止期前安全挂起。**

## 2. 关键算法骨架

```python
# TCC：默认拒绝 + 三重有效性（实时，O(1)，不可被学习分区抢占）
def tcc_step(action, tac, consent, now, sched):
    if now > tac.deadline:                    return SUSPEND('expired')      # 过期=硬故障
    if consent is None or not verify_mac(consent): return SUSPEND('unauthorized')
    if now - consent.t > CONSENT_TTL:         return SUSPEND('withdrawn')    # 沉默≠同意
    if sched.slack() < REACT_MARGIN:          return SUSPEND('timing')       # 无反应裕度
    if not within_certified_envelope(action, tac): return REJECT('oob')      # 超包络
    return DISPATCH(action)                    # 只有这一步能驱动执行器

# CBA：在硬截止期内选"认证精度"，解认证时延自指不动点
def allocate_budget(D, tau_sense, tau_act, margin):
    for e in effort_levels_desc():             # 支持集/前缀/采样，按精度降序
        if tau_sense + certify_cost(e) + tau_act + margin <= D:
            k = fixed_point_prefix(e, D, tau_sense, margin)   # k·dt + C_cert(k) <= B
            if k >= 1: return e, k
    return FALLBACK_PRE_CERTIFIED              # 不追精度，退回已验证的保守/停止包络

# FAI：后验会老化，过期回先验；H_partner 老化最快
def aged_posterior(post, age, lam):
    w = exp(-lam[argmax(post)] * age)
    return normalize({h: p * (w if h == argmax(post) else 1.0) for h, p in post.items()})

# MCS：关键级切换先保护已武装契约的反应裕度
def criticality_switch(contracts, mode):
    for c in sorted(active(contracts), key=priority):
        if c.reserved_slack < react_margin(c):
            suspend_and_stop(c)                # 在截止期前进入安全态
    return shed_mission_tasks_first(mode)      # 只削减 LO 任务

# CWC/RSM：伙伴违约是"退出/假设失效"，不是感知故障
def interaction_gate(post, partner_obs, consent, now):
    if consent_expired(consent, now):          return 'SUSPEND:withdrawn'
    if partner_speed(partner_obs) > V_H_MAX or not in_monitored_zone(partner_obs):
        return 'SUSPEND:assumption_violated'   # 不膨胀几何球、不归因 H_geo
    if inevitable_collision_time(partner_obs) < TAU_REACT + TAU_STOP:
        return 'SUSPEND:separation'
    return 'ACTIVE'
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（时敏证书健全性）**：在 A94（WCET/时钟完整性）与 A95（分区隔离）下，若 TCC 只派发 `age ≤ τ_hold` 且 `slack ≥ 0` 的 TAC，则任何被派发动作所依据的观测年龄都不超过 `τ_hold`，**过期前提被执行的概率按构造为 0**；与 `J_vista` 的认知保证联合，单步不安全派发概率 ≤ `α + P[时序信任基失效]`。注意这是**条件保证**：时序信任基失效则证明作废。
- **引理 10（契约保持的关键级切换）**：若每个已武装契约预留 `R_c ≥ τ_react+τ_stop+ε`，且过载时先削减 LO 任务，则关键级切换不会使任何已武装契约在无反应裕度下继续执行；若 HI 模式仍不可调度，则最迟在截止期前挂起。证明用调度不变量 + 无优先级反转。
- **定理 9（PACT 端到端交互安全）**：在 A94–A100 下，`Valid(J_pact)` ⇒（承诺成立 ∨ 契约已安全挂起）∧ 无未授权动作 ∧ 无超龄前提派发 ∧ 归因新鲜度受界 ∧ `fail-safe/fail-operational` 选择已认证。
- **定理 10（认证时延悖论与最优精度）**：设 `G` 单调增、`C` 单调增，`e_max = C⁻¹(D−τ0)`。则 (i) `e ≤ e_max` 时安全随 `G` 不减；(ii) `e > e_max` 时 PACT 回退到已验证的停止/保守包络，安全不降但任务可用性归零；(iii) **若像第 65 轮那样不检查时效**，超期后按老化危险率 `h(δ)=1−e^{−λδ}`，`S_naive(e)=G(e)(1−h(C(e)−B))` 在 `e>e_max` 上最终严格递减——**更多归因 = 更低安全**。故时效检查不是可选的优化，而是安全论证的一部分。
- **命题（过期高置信比新鲜保守更危险）**：当伙伴危险率 `λ>0` 时，存在 `τ*` 使 `L(过期后验) > L(均匀先验)`；直觉是「带着一个不再为真的强信念去接近一个仍在移动的他者」。这直接反驳第 65 轮「已经归因所以更自信」的副作用。
- **实时性**：TCC 三重检查 `<0.03ms`、consent 校验 `<0.02ms`、RSM `<0.05ms`、关键级检查 `<0.01ms`，实时新增 `<0.15ms`；重认证、C-FIR、CBA 全在语义分区，**可被丢弃而不破坏已武装契约**（由引理 10 保证）；目标实时最坏路径仍在 GRIP 的 2.5ms 预算内。

## 5. 本轮最大风险

## 2. 形式化定义（完整版）

**定义 233（PACT 闭环）** PACT 是 VISTA 的「交互契约 + 时序可证明 + 平台容错」升级：保留 VISTA 的语义流/实时流骨架，但把语义流显式标记为**不可信分区**，在其实时流之上插入可信时序契约核 TCC，并用 ICC、TAC、MCS、CBA、FAI、RSM、CWC 把「何时可以执行」写成带时限与授权的可检查条件；原位升级 FIR→C-FIR、CSC→T-CSC、RSC-V→RSC-P、WCV-V→WCV-P、CSP-V→CSP-P、AIC-V→AIC-P、J_vista→J_pact；新增 FOP 与 STR。不变式：**语义分区的任何输出在被 TCC 消费前都必须重新盖上含时戳与范围的 TAC 章；学习结果不得直接改写实时控制状态；缺认知/时序/授权任一有效性即默认拒绝。**

**定义 234（交互承诺契约 ICC）** 契约 `ICC=(C,A,W,Σ,δ,L)`：
- **承诺** `C = {c_i(t)}`：机器人保证在契约活跃期内成立的可测量不等式，例如 `F_n(t) ≤ F_lim`、`s(t) ≥ d_safe`、`‖ẋ‖ ≤ v_lim`、`收到退出后 τ_stop 内停住`。
- **假设** `A = {a_j}`：承诺成立所依赖的伙伴/环境/平台条件，例如 `v_h(t) ≤ v_h^max`、人在监控区内、心跳周期 `≤ T_hb`、时钟漂移 `≤ ρ_clk`、TCC WCET `≤ b_wcet`。
- **退出** `W`：合法终止或暂停契约的信号与权威令牌（急停、deadman、release-to-move、操作者撤回、交接）。
- **状态** `Σ` 与迁移 `δ`：`Proposed --arm--> Armed --authorize/refresh--> Active`；`Active --withdraw/assumption_violated/deadline_missed--> Suspended`；`Suspended --reauthorize--> Active` 或 `--> Aborted`；正常结束 `--> Completed`。
- **责任** `L`：把一次违约归入「机器人承诺违约」「伙伴假设违约」「平台/时序失效」「授权失效」四类之一。

语义约定：**伙伴行使退出权或超出假设不是感知故障**；`Active` 需要同时满足「认知有效 ∧ 时序有效 ∧ 授权有效 ∧ 假设未违约」。

**定义 235（时敏证书 TAC）** 令 `TAC=(J_vista,t_issue,τ_hold,b_wcet,age,prov_hash)`。定义三重有效性：
1. **认知有效**：`Valid(J_vista)`（第 65 轮定义 231）；
2. **时序有效**：`t ≤ t_issue+τ_hold`、`age = t−t_issue ≤ τ_hold`、`slack(t) ≥ 0`，其中 `slack` 为实时调度的剩余裕度；
3. **授权有效**：`consent_token` 的 MAC 可验证、作用域匹配、`t−token.t ≤ T_consent`。

`τ_hold = min(τ_react_budget, τ_sensor_fresh, τ_model_drift)`，即有效期同时受**反应预算、传感器新鲜度、世界模型漂移**三者约束。**任一失效即 `TAC` 无效；TAC 无效不是降级，而是硬故障**，触发契约迁移（默认安全停或进入预认证逃生契约）。`prov_hash` 绑定生成该证书的模型/版本/输入摘要，防止「旧证书复用到新场景」。

**定义 236（可信时序契约核 TCC）** TCC 是一个可认证的实时核，功能仅为：
- 读取 TAC 三元组与当前时间，做 `O(1)` 的有效性检查；
- 执行契约状态机 `δ`；
- 检查动作是否落在预认证包络 `𝒜_cert`（力/速度/分离/停止距离）内；
- 触发停止、派发、watchdog 复位与 STR 落盘。

TCC 与语义分区满足**时间隔离**（固定优先级/时间触发调度、无优先级反转）与**空间隔离**（MPU/MMU 分区、无共享可写控制态），其 WCET `b_wcet` 由静态分析与目标机测量双重确认。TCC 的信任基记为 `T=(WCET 证、时钟源、隔离配置、attestation 版本)`。**学习分区只能向 TCC 提交「候选证书」，永远不能直接写 actuator 命令或契约状态。**

**定义 237（契约保持的混合关键级调度 MCS）** 系统有两套预算：LO 模式 `(C_LO,T_LO)` 允许任务超时并降级；HI 模式 `(C_HI,T_HI)` 只保证安全任务。每个已武装契约 `c` 预留 `R_c = τ_react(c)+τ_stop(c)+ε`。调度不变量：
1. 任意时刻，已武装契约的 `Σ R_c` 必须被 HI 预算容纳；
2. 关键级切换时**先削减 LO（任务）负载**，安全任务预算不变；
3. 若切换后 HI 预算仍无法容纳所有 `R_c`，按契约优先级从低到高，在各自截止期前逐个 `suspend_and_stop`，并记录 `L=platform/timing`。

因此「削减任务」与「已武装契约」被显式解耦：宁可少做任务，不可悄悄吃掉反应裕度。

**定义 238（认证时延预算分配 CBA 与自指不动点）** 认证投入 `e` 决定认知保证 `G(e)` 与认证时间 `C(e)`；`G` 单调增且凹（信息收益递减），`C` 单调增且凸（组合复杂度递增）。硬截止期 `D`，固定延迟 `τ0 = τ_sense+τ_act+τ_margin`。可行条件：
`C(e)+τ0 ≤ D`。
对认证前缀还要求**自指不动点**：
`k·Δt_act + C_cert(k) ≤ D − τ_sense − τ_margin`，
其中 `C_cert(k)` 是验证前 `k` 步（对支持集内假设）的时间上界。由于 `C_cert` 随 `k` 增，满足条件的最大 `k` 可由单调解方程得到；若 `k<1`，则本块不可在预算内认证，回退到 `FALLBACK_PRE_CERTIFIED`（预认证的保守动作或停止包络）。这套约束把第 65 轮「算 `k*` 的时间」显式计入预算，消除了「长预测、短执行」中未计价的认证开销。

**定义 239（归因新鲜度与后验老化 FAI）** 定义信息年龄 `AoA(t)=t−t_obs`。后验按老化率 `λ` 退火：
`p_τ(H) = normalize( p(H|ρ)^{exp(−λ_H·τ)} )`，或工程近似 `p_τ = (1−w)·p + w·p_prior`，`w = 1−e^{−λτ}`。
超过 `τ_fresh` 后强制回到先验/均匀。归因半衰期 `τ_{1/2}=ln2/λ`。**运动许可只认新鲜后验**；`H_partner` 的老化率最大，因为伙伴在延迟期间仍在移动。过期后验若继续被用于「定向膨胀某个球」，等价于用不再为真的强信念接近一个移动对象。

**定义 240（反应时间分离监控 RSM）** 设伙伴位置/速度为 `(p_h,v_h)`，鲁棒预测区间用 split-conformal 给出 `v_h` 的上界分位 `q_v(α)`。分离判据：
`s(t) − (v̂_h·τ_react + q_v(α)) ≥ d_safe`，
等价地 `T_ic(t) ≥ τ_react+τ_stop+ε`。当视觉遮挡使 `v̂_h` 不可观测时，退化为先验上界 `v_h^max`。若观测到 `v_h > v_h^max` 或离开监控区，判为**假设违约** `H_partner`，触发保护性停止；**不得**把它当作 `H_geo` 去膨胀几何球。RSM 只依赖 TCC 可实时获得的位置/速度与固定常数，故其判定是 `O(1)`。

**定义 241（同意/退出通道与默认拒绝 CWC）** 同意令牌 `token=(subject, scope, t, nonce, mac)`。门控规则：
- 无令牌 / MAC 无效 / `nonce` 重放 / `scope` 不符 → `DENY`；
- `t_now−t > T_consent` → `DENY`（心跳丢失视为撤回，而非「无消息=继续」）；
- 交接采用双人规则/权威令牌：旧权威显式 `release`、新权威显式 `accept`，两者之间无有效权威时系统 `Suspended`；
- `release-to-move`（如 deadman）要求握持信号持续存在，松手即停。
不变式：**沉默不是同意，缺失不是中立；默认拒绝优先于任何性能考虑。**

**定义 242（契约感知故障/违约归因 C-FIR）** 假设集
`ℋ_P = {H0, H_geo, H_force, H_model, H_vis, H_policy, H_partner, H_time, H_platform, H_consent}`。
`H_partner`：伙伴违约或合法退出（**非故障**）；`H_time`：抖动/延迟/时钟漂移/截止期错失；`H_platform`：位翻转/热节流/DVFS/内存破坏；`H_consent`：授权伪造/重放/作用域错误。时间签名用于区分：
- `H_time` 同时在视觉/力/调度多通道出现，且与时钟/抖动统计相关；
- `H_platform` 跨任务相关、常伴随非物理的跳变或校验失败；
- `H_consent` 只在授权通道出现，其余通道健康；
- `H_partner` 只在伙伴位置/速度与分离通道出现，且力/几何残差可解释为其运动学后果。
归因后验必须带 `t_obs`；`C-FIR` 的输出直接写入 `TAC` 的认知有效字段，因而受 FAI 老化约束。

**定义 243（契约组合与权威交接）** 契约可组合 `C1⊗C2` 当且仅当：
(i) 承诺不冲突（如两个速度上限取 min）；
(ii) 假设相容（如两个 `v_h^max` 取 min）；
(iii) 任一时刻**至多一个权威令牌有效**（single-writer 原则）。
交接 `handover(C1→C2)` 要求 `release` 与 `accept` 均为已认证消息，且中间无未授权运动；若交接中断，默认 `Suspended`。这把第 65 轮的单机 `J_vista` 扩展成可组合的团队接口，同时避免多权威导致的「都以为对方负责」。

**定义 244（失效运行逃生契约 FOP）** 当停车本身危险（搬运热物、悬挂负载、楼梯、拥挤人群）时，允许预认证的**有界退避契约** `C_esc`：承诺更弱（如「沿预验证路径减速到安全放置点」），但必须满足与主契约相同的认知/时序/授权三重有效。选择规则：
`C* = argmin_{C ∈ {C_stop, C_esc}} Risk_cert(C)`，
其中 `Risk_cert` 是经 AIC-P 认证的风险上界（含二次伤害）。若二者均未认证，**不得自选「最小坏」**，必须交回人类授权或机械失效安全装置。FOP 不允许临场生成未认证的「聪明」动作。

**定义 245（安全轨迹与可审计日志 STR）** 时间触发记录：契约状态迁移、`TAC` 哈希与年龄、`slack`、关键级切换、同意令牌哈希、时钟证据、TCC 版本与信任基 `T`、以及每次派发/拒绝的理由码。日志写入独立防篡改存储并支持确定性重放；对外提供 attestation，使「当时为什么允许/拒绝」可被事后重建。STR 对应安全交互中的**问责**：不仅记录机器人做了什么，也记录它依据了谁的授权、在什么新鲜度下做的。

**定义 246（AIC-P 对抗交互与时序认证）** `ℰ_P=ℰ_V×ℰ_inter×ℰ_time×ℰ_platform`：
- `ℰ_inter`：不合作/对抗伙伴、伪造或重放同意、欺骗性交接、故意遮挡；
- `ℰ_time`：调度抖动、时钟漂移、截止期错失、消息延迟/重放；
- `ℰ_platform`：位翻转、热节流、DVFS、内存破坏、watchdog 失效。
`n_cert 128→192`（其中 64 给交互/时序/平台）；`ρ_force` 在最坏伙伴行为与最坏 WCET 下取最坏；`J_pact` 增 `timing_assumptions_ver` 与 `trace_hash`。认证目标改变：**不要求「归因正确」，只要求在最坏交互/时序下「契约不被违反，或能安全退出」**。

**定义 247（PACT 证书 J_pact）** `J_pact=(J_vista, contract_state, tac, criticality_mode, consent_token_hash, timing_assumptions_ver, trace_hash, aic_p_ver)`。验证规则：
`Valid(J_pact) ⇔ Valid(J_vista) ∧ contract_state ∈ {Active, Suspended-safe} ∧ TemporalValid(tac) ∧ Authorized(consent) ∧ (A 未违约 ∨ 已安全挂起) ∧ TraceRecorded ∧ aic_p_ver 当前`。
审计链新增：**为何此刻允许执行（TAC/age/slack）、谁授权（consent）、平台是否可信（T）、违约后如何退出（FOP）**。

**定义 248（PACT 闭环算子）** 语义分区：
`[VISTA → 实例化 ICC → C-FIR 归因 → CBA 选精度 → T-CSC 认证前缀 → CSP-P 契约状态规划 → 生成候选 TAC]`；
实时分区：
`[取 TAC → TCC 三重检查 → consent 检查 → RSM 判定 → 关键级/slack 检查 → 派发或挂起 → watchdog → STR]`。
跨分区协议：语义分区可被抢占、丢帧、降级甚至崩溃；**已武装契约由 MCS 预留裕度与 TCC 的过期检查共同保护**——前者保证有时间反应，后者保证不会拿过期前提反应。

class Contract:
    """有状态契约；承诺/假设/退出/责任。实时迁移只在 TCC 内发生。"""
    def __init__(self, commitments, assumptions, withdraw, priority=0):
        self.C, self.A, self.W = commitments, assumptions, withdraw
        self.state, self.priority = 'Proposed', priority
        self.reserved_slack = None

    def arm(self, tac, slack):
        assert 'Proposed' == self.state
        self.reserved_slack = max(slack, REACT_MARGIN(self))
        self.state = 'Armed'

    def authorize(self, token, now):
        if not verify_mac(token) or now - token.t > T_CONSENT:
            return 'Suspended:unauthorized'
        if token.scope != self.scope:
            return 'Suspended:scope'
        self.state = 'Active'
        return self.state


class TAC:
    """时敏证书：内容 + 时效 + 授权 + 来源。过期是硬故障。"""
    def __init__(self, j_vista, t_issue, tau_hold, b_wcet, prov_hash):
        self.j, self.t0, self.tau, self.b, self.prov = j_vista, t_issue, tau_hold, b_wcet, prov_hash

    def valid(self, now, slack):
        epistemic = Valid_j_vista(self.j)
        temporal = (now <= self.t0 + self.tau) and (slack >= 0.0)
        return epistemic and temporal


class TrustedTimingCore:
    """O(1) 检查；默认拒绝；学习分区不可写其控制态。"""
    def step(self, action, tac, contract, consent, now, sched):
        if not tac.valid(now, sched.slack()):
            return self._suspend(contract, 'expired_or_timing')
        if contract.state != 'Active':
            return self._suspend(contract, 'not_active')
        if consent is None or not verify_mac(consent) or now - consent.t > T_CONSENT:
            return self._suspend(contract, 'withdrawn')
        if not within_envelope(action, tac.j, contract.C):
            return self._reject(action, 'out_of_envelope')
        if not RSM_ok(now, contract.A):
            return self._suspend(contract, 'separation')
        return self._dispatch(action)          # 唯一能驱动执行器的分支

    def _suspend(self, contract, reason):
        contract.state = 'Suspended'
        record_trace(contract, reason, clock=now())
        return SafeStop(contract)

def certify_cost(e):
    """认证时间上界（WCET），不是均值：支持集 × 假设 × 采样。"""
    n_support, n_hyp, n_mc = e
    return C0 + C1 * n_support * n_hyp + C2 * n_mc

def epistemic_guarantee(e, calib):
    """由离线 conformal / 故障注入给出认知保证下界，单调凹。"""
    return calib.guarantee(e)

def fixed_point_prefix(e, D, tau_sense, tau_margin, dt_act):
    B = D - tau_sense - tau_margin
    k = 0
    for cand in range(1, MAX_H + 1):
        if cand * dt_act + certify_prefix_cost(cand, e) <= B:
            k = cand
        else:
            break
    return k

def allocate_budget(D, tau_sense, tau_act, tau_margin):
    for e in effort_levels_desc():              # 精度从高到低
        if tau_sense + certify_cost(e) + tau_act + tau_margin > D:
            continue                            # 认证时延悖论：越证越没时间反应
        k = fixed_point_prefix(e, D, tau_sense, tau_margin, DT_ACT)
        if k >= 1:
            return e, k
    return FALLBACK_PRE_CERTIFIED               # 预认证保守/停止包络

def aged_posterior(post, age, lam):
    # 后验老化：过期高置信不得驱动运动；H_partner 老化最快
    h_star = max(post, key=post.get)
    w = math.exp(-lam[h_star] * age)

## 4. 推导

**假设 A94–A100（证明的信任基，必须显式声明）**
- **A94 时间完整性**：TCC 的 WCET 上界在目标硬件（缓存锁定/无 DVFS/热设计受控）下经静态分析与测量双重确认；时钟漂移有界。
- **A95 分区隔离**：学习/语义任务与 TCC 在时间、空间上隔离，无优先级反转与共享缓存干扰（或干扰已计入 WCET）。
- **A96 伙伴有界**：伙伴速度/位置在契约假设集内；超出即触发退出（鲁棒 conformal）。
- **A97 同意可信**：consent token 经认证、不可重放、新鲜度可验证。
- **A98 归因新鲜**：`τ_hold ≤ min(τ_sensor_fresh, τ_model_drift)`；过期后验回先验。
- **A99 逃生已验证**：fail-operational 退避路径与主路径同等级认证。
- **A100 日志防篡改**：STR 与 attestation 保证审计可重建。

**引理 9（时敏证书健全性）** 设 A94、A95 成立，且 TCC 只派发满足 `age ≤ τ_hold` 与 `slack ≥ 0` 的 TAC。由 TCC 的分支结构，任何被派发动作在执行时刻所依据的观测年龄至多 `τ_hold`；因此「执行过期前提」这一事件**按构造不发生**（概率 0，而非靠统计）。与第 65 轮 `J_vista` 的认知保证（`Valid(J_vista)` 下不安全概率 ≤ α）联合，单次派发的不安全概率 ≤ `α + P[时序信任基失效]`。若 A94/A95 不成立，则 TCC 的 `age/slack` 判断本身不可信，本引理不适用——**这正是本轮的信任基而非可优化项**。∎

**引理 10（契约保持的关键级切换）** 设每个已武装契约 `c` 预留 `R_c ≥ τ_react(c)+τ_stop(c)+ε`，HI 预算容纳 `ΣR_c`，且切换时先削减 LO 任务。则对任意已武装 `c`，切换后其反应时窗内仍有足够预算完成 `τ_react+τ_stop`，承诺不因削减 LO 任务而失效。若 HI 预算不足以容纳所有 `R_c`，由定义 237 的规则在各自截止期前挂起最不优先的契约并安全停车；因此对每个契约，**要么承诺继续成立，要么在截止期前进入安全态**，不存在「既继续执行又无反应裕度」的中间态。证明用固定优先级调度的响应时间分析：削减 LO 任务只会减少高关键级任务的最坏响应时间；挂起按截止期顺序执行。∎

**定理 9（PACT 端到端交互安全）** 在 A94–A100 下：
1. **证书健全**：`Valid(J_pact)` ⇒ 执行所依据的前提在 `τ_hold` 内（引理 9），且认知保证来自 `J_vista`。
2. **契约可履行**：若假设 A 未被违约，已武装契约在 MCS 预留下保持 `R_c`（引理 10），承诺成立；若 A 被违约（伙伴超速/退出），C-FIR 判 `H_partner` 并迁移 `Suspended`，**不误膨胀几何球**。
3. **授权默认拒绝**：无有效同意令牌、过期、重放、作用域不符均 `DENY`（定义 241），故不存在未授权运动。
4. **过期不驱动运动**：TAC 过期/超龄触发 `Suspended`（定义 235、239），故过期高置信不能继续执行。
5. **失效语义已认证**：`fail-safe` 与 `fail-operational` 中选较小认证风险者；二者均未认证则交回人类（定义 244），禁止临场自选未认证动作。
6. **可审计**：STR 记录全部拒绝/派发理由码，`J_pact` 绑定 `trace_hash`（A100）。
因此 `Valid(J_pact)` ⇒（承诺成立 ∨ 契约安全挂起）∧ 无未授权/超龄派发 ∧ 选择可解释。∎

**定理 10（认证时延悖论与最优精度）** 设认证投入 `e`，认知保证 `G(e)`（单调增、凹），认证时间 `C(e)`（单调增、凸），总预算 `D`，固定延迟 `τ0=τ_sense+τ_act+τ_margin`，可行上界 `e_max=C⁻¹(D−τ0)`。
1. 对 `e ≤ e_max`：认证能在截止期内完成，可实现安全 `S(e)=G(e)`，随 `e` 不减；但任务可用性 `A(e)` 随 `C(e)` 递减（用于规划的剩余时窗变短）。故在可行域内是**安全-可用性前沿**，不是「越大越好」。
2. 对 `e > e_max`：PACT 走默认拒绝，回退到预认证的停止/保守包络，安全 `S ≥ G_fallback`，但任务可用性为 0。**继续增大 `e` 不再提升安全**。
3. 若像第 65 轮那样**不检查时效**，超期后按老化危险率 `h(δ)=1−e^{−λδ}`（`δ=C(e)−B`），有 `S_naive(e)=G(e)(1−h(C(e)−B))`。当 `e` 足够大时 `h→1`，`S_naive→0`；又因 `G` 有界，`S_naive` 在 `e>e_max` 上最终严格递减。因此存在区间使**归因越多、安全越低**。
4. 结论：最优策略不是「把支持集无限加大」，而是 `e* = min(e_max, argmax_{e≤e_max} U(G(e), A(e)))`（按任务效用权衡），并**必须**在运行时检查 `age` 与 `slack`；`k*` 还必须满足 `k·Δt_act+C_cert(k) ≤ D−τ_sense−τ_margin` 的自指不动点。这为「长预测、短执行」补上了被忽略的认证时间项。∎

**命题（过期高置信比新鲜保守更危险）** 设伙伴运动与错误信念导致的期望损失为 `L(p,τ) = p_correct(τ)·0 + (1−p_correct(τ))·L_mis + λτ·L_partner`，其中 `p_correct(τ)` 随 `τ` 衰减。由于 `L_mis > 0` 且 `λL_partner > 0`，存在 `τ*` 使 `τ>τ*` 时 `L(过期后验,τ) > L(均匀先验,0)`。直觉：带着一个「不再为真」的强信念去接近一个「仍在移动」的他者，比一开始就承认不知道更危险。故 `τ_fresh` 与过期回先验不是保守，而是**纠正第 65 轮「已归因所以更自信」的副作用**。∎

**命题（「不是故障」原则降低误降级）** 当观测异常由伙伴违约（`H_partner`）产生时，把它归入 `H_geo` 会膨胀几何球并降级一个正确的几何先验；而 ICC 直接 `Suspended` 不改变 `r_geo`。在「几何正确、伙伴违约」这一常见人机场景下，ICC 的期望代价严格更低（少一次错误膨胀 + 更早的保护性停止）。这把第 65 轮「只膨胀对的球」的道德直觉，推进为「有些偏差根本不该进入故障归因」。∎

| T-CSC 认证前缀（语义） | O(m·|supp|) **<1ms** | O(m) | 自指不动点：`k·Δt+C_cert(k)≤B` |
| CBA 预算分配（语义） | 精度档 × 固定点 **<2ms** | O(1) | 定理 10：超 e_max 不追精度，回退预认证 |
| C-FIR 归因（语义） | 10 假设 **<1ms** | O(1) | 时序签名区分故障/违约/平台；带时戳 |
| FAI 后验老化（语义） | O(|ℋ_P|) **<0.05ms** | O(1) | 过期回先验；运动许可只认新鲜后验 |
| CSP-P 契约规划（语义） | 契约状态 A* **<5ms** | O(|Σ|·|blocks|) | 边需 TAC 三重有效 |
| AIC-P 认证（语义） | n_cert=192 **<80ms** | O(n_cert) | 交互/时序/平台最坏；不要求归因正确，只要求契约不违约或安全退出 |
| FOP 裁断（语义） | 两个已认证风险 **<0.2ms** | O(1) | 都未认证→交回人类，禁止自选未认证动作 |
| PACT 实时新增 | 0.03+0.02+0.05+0.01+0.1 ≈ **<0.25ms** | — | 重认证全在语义分区，可丢弃而不破坏已武装契约（引理 10） |

**正确性定理（PACT-Complete）** 见定理 9：`Valid(J_pact)` 把第 65 轮的「故障可归因」补成「契约可履行 + 时序可证明 + 授权默认拒绝 + 过期不运动 + 失效语义已认证」。**核心新增不是更多的归因，而是承认归因的时间成本与信任边界**：语义分区可以错、可以慢、可以死；实时分区必须能在一个可证明的时限内判断「现在到底允不允许动」。

## 7. 已知风险

**一句话**：PACT 把安全论证从「感知/归因是否正确」转移到「时间与契约是否被遵守」，却依赖两个未被证明的信任基——**真实工况下硬件 WCET/时钟/功耗的界（DVFS、缓存、热节流、时钟漂移与位翻转会让「已证明的时限」静默失效）**，以及**人/伙伴会遵守契约假设**（同意、退出、限速假设可能不被理解、可被欺骗或本就不成立）；任一失效时，系统会因为「契约已认证」而给出比第 65 轮更强的虚假保证——**从「归因错误」升级为「证明健全性错误」**。

**次级风险与缓解**：
1. **WCET 界的静默失效**：测量在实验室成立、在高温/低电压/缓存竞争下失效。缓解：静态分析 + 目标机最坏工况测量 + 运行时计时看门狗 + 超界即安全停；把 DVFS/热纳入 AIC-P 的 `ℰ_platform`。
2. **安全论证的信任基过宽**：TCC 本身、编译器、链接器、时钟源都可能是漏洞。缓解：显式列出 `T`、最小化 TCC 代码、独立验证/形式化、lockstep 与多样化冗余；**绝不把学习栈的复杂度藏进「已认证」背后**。
3. **伙伴假设不成立/被欺骗**：人可能不懂契约、故意违反，或同意信号被伪造。缓解：鲁棒 conformal 与最坏行为认证；同意通道 MAC/attestation/防重放；默认拒绝；对「不理解」做交互设计与培训，而非只做算法。
4. **认证剧场（certification theater）**：小核被认证、外围全未认证，整体给出虚假安全感。缓解：端到端 AIC-P、公开信任基与覆盖范围、把「未认证部分」写进 `J_pact` 的显式字段。
5. **fail-safe 反而危险**：突然停车可能造成二次伤害（热物、悬挂、人群）。缓解：FOP 预认证逃生契约；但 FOP 本身也可能失效，故二者都未认证时强制交回人类，禁止自选。
6. **MCS 的最坏情形过保守**：为保住所有 `R_c` 可能频繁挂起，任务可用性骤降。缓解：按优先级/风险分级预留，在线重协商契约，区分「必须保」与「可放弃」的承诺。
7. **自指不动点可能无解**：高维支持集 + 长前缀在预算内不可认证。缓解：分层缓存预认证证书、缩小支持集、提高 `δ_fi` 换取时间、必要时直接安全停；把「无解」作为一等结果记录，而不是偷偷放宽时限。
8. **过度形式化掩盖真实需求**：安全交互的许多风险是组织/流程/人的问题，不是算法可解。缓解：把 ICC 的假设与责任交给人审查（可另设独立的伦理/审查流程），把 STR 用于组织学习，而非只做技术自证。
