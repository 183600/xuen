### 第 6 轮灵感驱动研究记录

**灵感词**：可靠性、分布外泛化

**继承关系**：第 5 轮 CADVS-v5（IP-493~496）把提议器升级为条件流匹配、记忆升级为固化闭环、人因升级为情感调制，并以定理 6「证书不变性」把框架推广为「任意生成器 + 认证边界」（CGE）。但 v5 自己在「诚实边界」里承认了两个结构性缺口：(a) 全部保证都是**分布内**的——密度型新颖度检测对 OOD 假接受「原理性无界」（v5 引理 43 后声明、R53）；(b) 「可靠性」只是定性叙述——fail-closed 回退依赖规则库覆盖，而规则库在漂移下同样退化，全链路没有一个**分布无关、可量化、任意时刻有效（anytime-valid）**的可靠性数字。本轮两个灵感词合为主题「可信分布外泛化的认证执行」（Certified Reliable Generalization, CRG），形成 CADVS-v6（IP-497~501）。本轮自律：**仍不增硬门**（维持七门，兑现 R52 的锚点维护负债），只在门**外面**加一层「可靠性包络」——共形校准 + 分布鲁棒化 + 漂移监控 + 认证恢复；执行集嵌套升级为 Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ … ⊆ Exec_v29。

**直觉与动机**：

1. **可靠性 → 把「证书」从二值谓词升级为带分布无关覆盖保证的「可靠性包络」**。可靠性工程关心的从来不是「能否通过一次检查」，而是「在任务周期内，失效概率能否被一个可验证的数字界定」。v5 的七门只回答「这一次是否合规」，且合规性只在标定分布附近有经验支撑。引入**共形风险控制（Conformal Risk Control, CRC）**：把「误认证（certified 但实际不安全）」当作损失，用留出校准集构造阈值 λ̂_α，使 E[误认证率] ≤ α **无需任何分布假设**（仅需可交换性）。这让 v6 第一次能说「在置信 1−δ 下误认证率 ≤ α」，而不是「经验上看起来安全」。可靠性的第二根支柱是**优雅降级**：可靠性块图把七门、监控、恢复串成可计算的系统可靠度 R_total = R_cert + (1−R_cert)·R_recover，并显式给出「安全 vs 可用」的帕累托前沿——承认可靠性不是免费的，而是可度量的取舍。

2. **分布外泛化 → 用「鲁棒化 + 加权/自适应共形 + 恢复」承接漂移，而不是押注更准的 OOD 检测器**。OOD 检测有**不可能性**（Fang et al. 2022：无假设则无法保证检出所有 OOD）。因此 v6 不把可靠性押在检测上，而押在三件可证明的事：(a) **分布鲁棒门（DRO）**：在 Wasserstein-ρ 球 B_ρ(P) 上，把每门的「不安全样本越阈概率」的最坏值压到 α_i 以下，得到鲁棒阈值 τ_i^ρ ≥ τ_i^5（只紧不松）；(b) **加权共形**（协变量漂移、密度比已知）与**自适应共形 ACI**（任意漂移下长程覆盖 ≥ 1−α−o(1)）；(c) **认证恢复核**：检测到漂移或覆盖跌破预算 → 升级保证模式（nominal→guarded→recovery），执行「合规停机 / 阻抗安全保持 / 交还人类」等同样过七门的恢复策略，把「硬失败」变成「安全降级完成」。检测只负责**更早收紧**，安全由鲁棒证书 + 恢复兜底——这正面回应 v5 的 OOD 原理性盲区。

3. **关键洞见**：v5 问「提议能否通过门」；v6 问「我们凭什么相信这些门在一个从未见过的分布上仍然成立，以及不成立时系统如何不伤人」。可靠性的落点从「检测器」迁移到「分布无关覆盖 + 鲁棒阈值 + 优雅降级 + 恢复」四元组；这把 v5 的 fail-closed 从**二值拒绝**升级为**可量化、任意时刻有效、随漂移自适应收紧**的连续保证。

**形式化目标（增量）**：
1. 非一致性分数 A(x) = −min_i (s_i(x) − τ_i^5)/scale_i（越小越安全）；共形风险控制阈值 λ̂_α 使 E[1(certified ∧ unsafe)] ≤ α（可交换性下）。
2. 分布鲁棒阈值 τ_i^ρ = min{τ : sup_{Q∈B_ρ(P)} E_Q[1(Y=unsafe)·1(s_i(X) ≥ τ)] ≤ α_i}，B_ρ(P) 为 Wasserstein-ρ 球；必有 τ_i^ρ ≥ τ_i^5，令 τ_i^6 = max(τ_i^5, τ_i^ρ)。
3. 漂移监控 e-process：e_t 满足 E[e_t|F_{t-1}] ≤ 1（H0：无漂移），E_t = Π e_s，Ville 不等式给出 anytime-valid 报警；保证模式 mode ∈ {0 nominal, 1 guarded, 2 recovery}。
4. 认证恢复核 RGDK：恢复策略集 Π_rec 亦须过七门；可靠度合成 R_total = R_cert + (1−R_cert)·R_recover。
5. 定理 9（分布无关可靠性/共形覆盖）、定理 10（DRO 健全性 + 嵌套）、定理 11（优雅降级单调性/帕累托）、定理 12（在线仅收紧自适应的安全性）、定理 13（OOD 检测不可能性→诚实边界）；引理 45（可靠性合成）。
6. Exec_CADVS-v6 = {x ∈ supp(π_θ^FM) : ∧_i kc_i(x; τ_i^6)=1 ∧ A(x) ≤ λ̂_α ∧ mode(x) ≤ 1} ⊆ Exec_CADVS-v5。

**本轮最大风险**：**「可靠性剧场」——分布无关覆盖依赖可交换性、DRO 依赖无法在线验证的漂移半径 ρ、共形依赖干净校准标签；三者都是「保证所依赖的前提」，在对抗性或全新漂移下系统可能一边报出很高的认证可靠度、一边在事实上失效，可靠度数字本身成为虚假保证与攻击面。**

## 2. 关键算法骨架

### IP-497 CRC：共形可靠性校准核（离线校准；在线 O(#gates)）

```python
@dataclass
class ConformalReliabilityCalibrator:
    """CRC：把「误认证」当损失做共形风险控制，得到分布无关上界。
    仅需可交换性；协变量漂移用密度比加权；任意漂移用 ACI。"""
    alpha: float = 0.05
    delta: float = 0.05
    lam_hat: float | None = None
    alpha_t: float | None = None          # ACI 运行目标
    gamma_aci: float = 0.01

    def score(self, x, gates, tau5, scale) -> float:
        # 非一致性：最接近违反的那一门的归一化余量（越小越安全）
        margins = [(s_i(x) - tau5[i]) / scale[i] for i, s_i in enumerate(gates)]
        return -min(margins)

    def fit(self, A_calib: np.ndarray) -> None:
        """CRC：选最小 λ 使 (n/(n+1))·R̂(λ) + 1/(n+1) ≤ α，
        R̂(λ) = (1/n)Σ 1[A_j > λ]（误认证指示，λ 越大越保守）。"""
        n = len(A_calib)
        for lam in np.sort(np.unique(A_calib)):
            risk = np.mean(A_calib > lam)
            if n / (n + 1) * risk + 1 / (n + 1) <= self.alpha:
                self.lam_hat = lam
                return
        self.lam_hat = float('inf')        # 不可行 → 全部拒绝（fail-closed）

    def weighted_fit(self, A_calib, w_calib) -> None:
        """协变量漂移：自归一化加权风险 R̂_w(λ)=Σw_j·1[A_j>λ]/Σw_j。
        覆盖保证从 P 转成 Q（Tibshirani et al. 2019 加权共形）。"""
        ...

    def aci_update(self, err_t: bool) -> None:
        """任意漂移：α_{t+1}=α_t+γ(α−err_t)；长程平均误认证 ≤ α + o(1)。
        err_t 由离线审计或延迟真值回填；无真值时保持 α_t 不变（保守）。"""
        if self.alpha_t is None:
            self.alpha_t = self.alpha
        self.alpha_t += self.gamma_aci * (self.alpha - float(err_t))

    def certified(self, x, gates, tau6, scale) -> bool:
        return self.score(x, gates, tau6, scale) <= self.lam_hat
```

### IP-498 DRGR：分布鲁棒门鲁棒化核（离线；在线 O(1) 查表）

```python
@dataclass
class DistributionallyRobustGateRobustifier:
    """DRGR：Wasserstein-ρ 鲁棒阈值。
    对球内任意 Q 控制误认证率；ρ=0 精确退化 v5。"""
    rho: float = 0.0
    alpha_i: dict = field(default_factory=dict)   # 每门最坏误认证预算

    def robust_threshold(self, s_unsafe_samples, alpha_i: float, rho: float) -> float:
        """τ^ρ = min{τ : sup_{Q∈B_ρ(P)} E_Q[1(s(X) ≥ τ)] ≤ α_i}
        （在 unsafe 子样本上）。一维 Wasserstein 球下，sup 风险随 τ 单调降，
        故用二分求最小可行 τ；有限样本用 Esfahani–Kuhn 型半径修正。"""
        lo, hi = s_unsafe_samples.min(), s_unsafe_samples.max() + 1e-9
        for _ in range(40):
            mid = 0.5 * (lo + hi)
            if worst_case_tail(s_unsafe_samples, mid, rho) <= alpha_i:
                hi = mid
            else:
                lo = mid
        return hi

    def thresholds(self, s_unsafe_by_gate, tau5) -> dict:
        tau6 = {}
        for i, s in s_unsafe_by_gate.items():
            tau_rho = self.robust_threshold(s, self.alpha_i[i], self.rho)
            tau6[i] = max(tau5[i], tau_rho)      # max ⇒ 只紧不松，嵌套保持
        return tau6

    def rho_from_budget(self, reliability_target: float, shift_stats) -> float:
```

### IP-499 SMRG：漂移监控与可靠性治理核（准入/10 Hz，与控制环解耦）

```python
@dataclass
class ShiftMonitorReliabilityGovernor:
    """SMRG：多信号漂移监控 + e-process + 保证模式升级。

    delta: float = 0.05
    mode: int = 0
    log_e: float = 0.0

                'n_flow': -fmpp.log_lik(x) / d_x}
```

### IP-500 RGDK：认证恢复与优雅降级核

```python
@dataclass
class RecoveryGracefulDegradationKernel:
    """RGDK：恢复策略同样过七门；可靠度合成 R_total。
    把「硬失败」变成「安全降级完成」。"""
    recovery_policies: list          # [π_stop, π_hold, π_handback]
    r_cert: float = 0.98
    r_recover: float = 0.90

    def execute(self, mode, x0_state, gates) -> RecoveryResult:
        if mode <= 1:
            return RecoveryResult(False, None, 'NOT_IN_RECOVERY')
        for pi in self.recovery_policies:            # 从最轻量到最保守
            x = pi.plan(x0_state)
            if all(kc(x) for kc in gates):           # 恢复也必须过七门
                return RecoveryResult(True, x, 'RECOVERED')
        return RecoveryResult(True, hardware_safe_stop(), 'HW_SAFE_STOP')

    def total_reliability(self) -> float:
        return self.r_cert + (1.0 - self.r_cert) * self.r_recover
```

### IP-501 EFA-v6：七硬门 + 可靠性包络

```python
@dataclass
class EvidenceForgingAssemblerV6:
    """EFA-v6：七硬门不变；阈值 τ^6=max(τ^5,τ^ρ)；共形过滤；模式门控。"""
    v5: EvidenceForgingAssemblerV5
    crc: ConformalReliabilityCalibrator
    drgr: DistributionallyRobustGateRobustifier
    smrg: ShiftMonitorReliabilityGovernor
    rgdk: RecoveryGracefulDegradationKernel
    tau6: dict = field(default_factory=dict)          # 离线预计算

    def select(self, x0_state, t_now, rule_id, context):
        mode = self.smrg.update(self.smrg.signals(...))
        if mode >= 2:
            return self.rgdk.execute(mode, x0_state, self.v5.gates)
        ok, x, tag = self.v5.select(x0_state, t_now, rule_id, context)  # 复用 v5
        if not ok:
            return self.rgdk.execute(2, x0_state, self.v5.gates)
        if not self.crc.certified(x, self.v5.gates, self.tau6, self.v5.scale):
            return self.rgdk.execute(2, x0_state, self.v5.gates)         # 共形拒绝
        return True, x, 'FORGED_CRG'

    def reliability(self) -> float:
        return self.rgdk.total_reliability()
```

### 集成流水线（v5 → v6）

```
离线/慢时域：
  校准：留出校准集（七门分数 + 安全标签 + 环境指纹）──▶ CRC.fit / weighted_fit ──▶ λ̂_α
  鲁棒化：每门 unsafe 分数分布 ──▶ DRGR.robust_threshold(ρ) ──▶ τ^ρ ──▶ τ^6=max(τ^5,τ^ρ)
  监控标定：多信号组合 z 的零分布 ──▶ e-value 校准（H0 下 E[e]≤1）
  维护排程：漂移率估计 ──▶ R(T)≥R_min ──▶ 重校准周期 T*
在线准入（异步，秒级）：
  SMRG.signals (energy/disagree/mahal/n_flow) ──▶ e-process ──▶ mode
      ├ mode=0/1 ──▶ EFA-v5 级联选证（用 τ^6）──▶ CRC 共形过滤 ──▶ 采纳
      ├ 共形拒绝/全灭 ──▶ RGDK 恢复
      └ mode=2 ──▶ RGDK 恢复（合规停机/安全保持/交还）
在线控制环（目标 ≤0.6 ms，不回归 R49）：
  τ^6 与 λ̂_α 均离线预计算；每周期仅 O(1) 查表 + EEK/BCK 事件触发
```

| CRC.certified | O(#gates)=O(7) | O(1) | — | < 0.01 ms |
| DRGR.robust_threshold | O(40·n) 二分 | O(n) | n~5k/门 | 离线，秒级/门 |
| DRGR.thresholds | O(1) 在线查表 | O(#gates) | — | < 0.001 ms |
| SMRG.signals | O(d_model + d_x) | O(1) | 10 Hz 准入 | ~2–5 ms（复用 n_flow） |
| SMRG.update (e-process) | O(1) | O(1) | — | < 0.01 ms |
| RGDK.execute | O(#policies) + 小 QP | O(1) | ≤3 策略 | ~1–5 ms，仅恢复态 |
| EFA-v6 在线增量 | O(1) | O(1) | — | **控制环 +<0.02 ms** |
| 端到端控制环 P99 | — | — | — | **0.55→0.56 ms（包络离线，不回归 R49）** |

**通信开销**：CRC 仅需上传校准摘要（分位数/阈值，~KB）与模式统计；DRGR 的 ρ 与 τ^ρ 由站内校准、签名下发；原始轨迹与标签不出端。可靠性中心维护的审计记录按 DP 聚合。

## 4. 正确性论证（增量更新）

### 引理 45（可靠性块图合成）

**陈述**：设认证路径可靠度 R_cert、恢复路径可靠度 R_recover，且恢复仅在认证失败时启用，则系统无事故概率 R_total = R_cert + (1−R_cert)·R_recover。若有 N 个异构监控冗余，漏报 ≤ Π miss_i，误报 ≤ 1−Π(1−fa_i)。
**证明**：全概率公式展开「认证成功 ∪ (认证失败 ∧ 恢复成功)」；冗余监控由独立性/联合界得。∎

### 定理 9（分布无关可靠性 / 共形风险控制）

**陈述**：设校准样本与测试样本可交换，损失 ℓ_λ(x)=1[certified_λ(x) ∧ unsafe] 关于 λ 单调不增且取值 [0,1]。CRC 阈值 λ̂=inf{λ : (n/(n+1))R̂_n(λ)+1/(n+1) ≤ α} 满足 E[ℓ_{λ̂}] ≤ α。协变量漂移且密度比 w 已知时，加权 CRC 在 Q 下同样 ≤ α；任意漂移下 ACI 满足 (1/T)Σ err_t ≤ α + (α_0−α_T)/(γT)。
**证明**：可交换性下秩统计量的有限样本界（Angelopoulos et al. 2023）；加权版本由重要性加权重写风险；ACI 由 Gibbs–Candès 2021 的在线学习界。∎

### 定理 10（DRO 健全性与嵌套）

**陈述**：设 τ_i^ρ = min{τ : sup_{Q∈B_ρ(P)} E_Q[1(unsafe)·1(s_i(X) ≥ τ)] ≤ α_i}，则 (i) τ_i^ρ ≥ τ_i^5（ρ≥0，球含 P，最坏风险 ≥ 名义风险）；(ii) 对任意 Q∈B_ρ(P)，第 i 门误认证率 ≤ α_i；(iii) 因此 Exec_v6 ⊆ Exec_v5。有限样本下用 Esfahani–Kuhn 半径修正，结论以置信 1−δ 成立。
**证明**：τ^ρ 的可行域随 τ 单调（被积函数关于 τ 递减），最小可行解存在且 ≥ 名义解；(ii) 由 sup 的定义；嵌套由阈值单调升与门谓词不变。∎

### 定理 11（优雅降级单调性 / 安全-可用帕累托）

**陈述**：对 ρ_1 ≤ ρ_2：τ^{ρ_2} ≥ τ^{ρ_1} ⇒ Exec^{ρ_2} ⊆ Exec^{ρ_1}；可用率 A(ρ)=P_Q(certified) 关于 ρ 单调不增；对任意满足 W(Q,P) ≤ ρ 的 Q，用 ρ-鲁棒证书的误认证率 ≤ α。故 (A(ρ), safety(ρ)) 构成单调帕累托前沿，不存在「同时更高安全与更高可用」的无偿改进。
**证明**：阈值单调 ⇒ 通过集单调缩；误认证界由定理 10(ii)；帕累托性由两单调方向相反直接得。∎

### 定理 12（在线仅收紧自适应的安全性）

**陈述**：若在线自适应动作限制在收紧锥 T={抬高 τ、增大 ρ、降低 α、抬高 mode}，则对所有 t：Exec_t ⊆ Exec_0 ⊆ Exec_v5，且不安全认证概率关于 t 不增；e-process 报警满足 P(存在误报) ≤ δ。
**证明**：收紧动作的复合保持各门通过集单调缩（定理 10/11）；e-process 为非负上鞅，Ville 不等式给出任意时刻的误报界。∎

### 定理 13（OOD 检测不可能性 → 诚实边界）

**陈述**：存在分布内 P 与 OOD Q，使任何无假设的检测器都无法区分（Fang et al. 2022）。因此 v6 的可靠性保证**不以检测为前提**：检测只加速收紧（定理 12）；安全由鲁棒证书（定理 10）+ 恢复（引理 45）承担。当真实漂移超出 ρ_budget 且被漏检时，保证失效——这是诚实边界而非缺陷。
**证明**：引用不可能性结果；逻辑上把保证从「检测正确」解耦为「鲁棒证书 + 恢复」。∎

### 定理 v6（可靠性包络总装）

**陈述**：在 v5 假设 (B1)~(B7) 及新增 (C1) 校准可交换或密度比有界、(C2) 真实漂移 W(Q,P) ≤ ρ_budget、(C3) 校准标签可信下：
(i) Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ … ⊆ Exec_v29；
(ii) E[误认证] ≤ α（定理 9），球内最坏 ≤ α（定理 10）；
(iii) 优雅降级单调、安全-可用帕累托（定理 11）；
(iv) 在线收紧保持嵌套与安全（定理 12）；
(v) 保证不依赖 OOD 检测（定理 13）；
(vi) 恢复与认证按块图合成（引理 45）。
**证明**：(i) 同门 + τ^6≥τ^5 + 共形过滤 + 模式门控；(ii)~(vi) 分别由定理 9~13、引理 45。∎

**诚实声明**：(C1)(C2)(C3) 均无法仅由数据在线验证；对抗性/无界漂移使保证失效；共形只保证**边际**覆盖，最差分组/条件覆盖无保证（实验中将显式报告缺口）；校准漂移只靠排程维护缓解，未证明；恢复策略自身的认证存在「用同一套门证明恢复安全」的循环依赖。

## 5. 实验设计与初步结果（仿真，单机；舰队/实机列入第 7 轮）

### 5.1 实验设计

- **平台**：MuJoCo 3.x + MJX；在 v5 基准上新增**受控漂移基准**：光照/纹理（协变量）、物体位姿、摩擦/负载（概念漂移）、传感器噪声、PGD 对抗轨迹；用 W-距离标定 split（train/calib/test）的漂移强度 ρ。
- **对照**：v5-full、v6-full；消融 B1（去 CRC）、B2（去 DRO，ρ=0）、B3（去 SMRG）、B4（去 RGDK）、B5（仅 OOD 检测、无鲁棒/共形）、B6（ACI 无 DRO）。
- **指标**：认证覆盖（目标 0.95）、误认证率、安全违例率随漂移强度的降级曲线、名义/严重漂移可用率、漂移检测延迟、恢复成功率、最差分组条件覆盖、控制环 P99/P99.9、任务周期内校准漂移。
- **协议**：每组 ≥5 个随机种子；覆盖用可靠性图与校准曲线报告；帕累托前沿画 A(ρ)–safety(ρ)。

## 7. 本轮最大风险（最终确认）

**一句话**：**「可靠性剧场」——分布无关覆盖依赖可交换性、DRO 依赖无法在线验证的漂移半径 ρ、共形依赖干净校准标签；三者都是「保证所依赖的前提」，在对抗性或全新漂移下系统可能一边报出很高的认证可靠度、一边在事实上失效，可靠度数字本身成为虚假保证与攻击面。**
