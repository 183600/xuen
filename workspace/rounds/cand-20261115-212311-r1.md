# 第 10 轮（「实例分割 × 移动底盘」灵感循环第 1 轮）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**实例接地 + 底盘动力学 + 遮挡保守**。v9 的块证书以「聚合间隙 + 单体力学」为安全锚，但有两个隐含假设：(a) 障碍可用一个标量「最近距离」代表；(b) 停车距离只由末端速度决定。移动操作场景下二者都不成立：标量间隙无法区分「待抓取的杯子」与「正在走近的人」，也无法表达「被沙发挡住的那条椅子腿」；移动底盘的旋转扫掠、制动距离、载荷与质心稳定则完全未被建模。两个灵感分别补这两个盲点，并在交叉处合成一个新失效模式。所有新组件仍遵守 v9 中立元退化律：任一失效 ⇒ 严格退回 v9。

## 0. 直觉与动机

**灵感 1（实例分割 → 对象接地安全）**
直觉：安全不是「离最近障碍多远」，而是「我承诺不碰哪些具体东西、它们此刻在哪里、我看不见的部分可能在哪里」。实例分割给出带持久 ID 的掩码，使证书从标量升级为**实例向量**：每个实例有独立的保守间隙、类别相关安全距离、遮挡状态与身份可信度。核心创新：**实例持久化证书器（InstancePersistentCertifier, IPC）**——掩码级 conformal 补全给出 amodal 占据，遮挡对象按「最坏补全」处理；实例 ID 漂移被显式为风险项 ϱ_id，而不是默认掩码永远正确。副产品：失败可追溯到具体实例 id（「因实例 #17 行人进入扫掠体而中止」），安全日志从数值变成对象级叙事。

**灵感 2（移动底盘 → 车身级安全与就位）**
直觉：v9 的停车不变式是「单臂 + 固定基座」的。移动底盘带来两个新自由度：平移/旋转产生的扫掠体，以及「底盘怎么摆才能操作」的就位问题。核心创新：**底盘扫掠体证书器（BaseSweptVolumeCertifier, BSV）**——块时域内 base footprint 的扫掠并集先与实例 amodal 占据求交，再判停车；停车距离按底盘动力学（v, ω, 载荷, 摩擦, 坡度）计算；增加倾斜/质心稳定证书；块生成联合规划 base（粗运动）与 arm（精操作），并求解**就位可达性**。

**灵感 3（二者交叉 → 感知-运动耦合，本轮真正的洞见）**
直觉：单独看，实例分割和移动底盘都只是「增强」；交叉处才出现新的失效模式——**底盘运动本身破坏实例分割的可靠性**。底盘加速带来运动模糊、视差跳变与相互遮挡，恰在 base 高速运动时实例掩码最不可信、ID 最容易漂移；而高速运动时又最需要实例级证书来保证扫掠体安全。这不是两个模块的简单叠加，而是一个**共模失效**：感知不确定性与运动风险同源于速度。核心创新：**感知-运动耦合门控（PerceptionMotionGate, PMG）**——把 ϱ_id(v,ω) 反馈为**底盘速度上限** v_perc，而不只是缩短动作块；系统可以选择「降速以保住感知可信度」，即「宁可慢，不可盲」。这把 v9 的 K_eff 门控从「块长自适应」升级为「运动自适应」。

## 1. 研究问题

- **Q1（实例证书保守性）**：amodal 补全在什么覆盖率下能保证实例级间隙不高于真实间隙？如何用 conformal 分割给出可校准的遮挡占据上界？
- **Q2（底盘-臂联合停车）**：扫掠体 + 旋转 + 载荷下，联合停车不变式的完备条件是什么？base 与 arm 的停止时序如何协调，才不产生「臂停了、底盘还在滑」的漏洞？
- **Q3（感知-运动耦合）**：ϱ_id 与 (v, ω, 遮挡率) 的因果曲线能否被在线估计？速度门控 v_perc 的反脆弱性如何证明（降速是否单调改善证书可靠性）？实例分割整体失效时如何严格退回 v9？

## 2. 设计原则（新增 P13–P15）

**P13 实例接地律（Instance-Grounded Certification, IPC）**
证书以实例为单位：Ĉ_t^{inst} = {(id_j, ĝ_j,min, o_j, P_j)}。安全 ⇔ 对每个实例 j：ĝ_j,min ≥ d_safe(cat_j) ∧ P_j ≥ τ_id。遮挡实例用保守 amodal 占据 O_j^amo（覆盖真实占据概率 ≥ 1−δ_j），禁止「看不见即放行」。实例分割失效 ⇒ 全部实例退化为单一包围球，严格退回 v9 聚合证书。

**P14 底盘扫掠律（Base Swept-Volume Certification, BSV）**
块内 base 运动产生扫掠体 SV_t；任何实例 j 的 amodal 占据与 SV_t 相交，则该实例必须被纳入联合中止点约束。停车距离用底盘动力学 d_brake^base(v, ω, m, μ, φ)，并附加倾斜/质心稳定证书 η_max ≤ η_tilt。base 模型失效 ⇒ v≡0、ω≡0（原地停驻，等价 v9 固定底盘），宁可不动。

**P15 感知-运动耦合律（Perception-Motion Coupling, PMG）**
定义实例身份漂移风险 ϱ_id(t)，由掩码 IoU 时序残差、底盘速度/角速度、遮挡率在线估计。门控：v_cap(t) = v_perc 使 ϱ_id(v_cap) ≤ τ_occ，且 K_eff^{IB} = max(1, ⌊K_eff·(1−ϱ_id/τ_occ)⌋)。当 ϱ_id 升高，系统**先降速再缩块**；ϱ_id 不可估计 ⇒ 取最保守 v_cap = v_safe_default。禁止在 ϱ_id > τ_occ 时签发实例证书。

## 3. 与基线的接口（如何退化）

- IPC 失效 / ϱ_id 超阈 ⇒ 实例证书退化为单体包围球 + 聚合 clearance，等价 v9（IP-354）证书；
- amodal 补全失效 ⇒ 所有遮挡实例视为满占据（最保守），仍可运行但更易中止；
- BSV 失效 / 底盘动力学模型失效 ⇒ v≡0、ω≡0、扫掠体退化为静态 footprint，等价 v9 固定底盘；
- BPP 失效 ⇒ 沿用 v9 原地操作策略；
- base-arm 联合规划失效 ⇒ base 停、仅 arm 动，等价 v9；
- 以上任一 ⇒ 严格退回 MetricVoiceGauge-ACMD v9（引理 91）；
- v9 的 AC/MW/ID 失效 ⇒ 按 v9 定义逐级退回 v8/v7。

## 4. 预期贡献

1. **实例-底盘联合证书**：把安全论证从标量间隙推进到「对象 × 车身扫掠」的联合不变式；
2. **amodal 遮挡安全**：conformal 分割把「看不见」变成可校准的保守占据，消除遮挡幽灵穿透；
3. **感知-运动耦合门控**：首次把分割可靠性作为底盘速度的约束反馈，证明「降速 → ϱ_id 降低 → 证书可信」的单调性；
4. **对象级可追溯安全日志**：中止可归因到实例 id，支撑 E571–E590 的遮挡/漂移/扫掠/就位实验。

## 5. 本轮最大风险

**一句话**：实例证书的安全性依赖 amodal 占据补全的覆盖率与实例 ID 的持久性，而移动底盘提速恰好同时放大遮挡视差与运动模糊——若 ID 漂移与补全误差在同一时刻叠加，系统会以高置信度对错误实例签发「安全」证书，即「唯一能证明安全的信息，恰恰在最需要它时最不可信」。

**定义 540（实例假设 InstanceHypothesis）** 实例分割前端每个控制周期输出 I(t) = {ι_j}。掩码 m_j ∈ {0,1}^{H×W}，位姿 T_j^{b→w} 由深度反投影 + 跟踪滤波得到；ID 跨帧持久，靠 mask-IoU、外观嵌入与深度一致性联合关联。未关联上的掩码进入「暂定实例」池，不参与安全证书（保守视为占据）。

**定义 541（实例持久化与身份可信度）** 实例轨迹 𝒯_j = {s_j(t), Σ_j(t)}。身份可信度
```
P_j(t) = σ( a·IoU(m_j(t), m_j(t−1)) + b·⟨e_j(t), e_j(t−1)⟩
            − c·age_occ(j,t) − d·blur(v,ω) )
```
其中 age_occ 为连续遮挡帧数，blur(v,ω) 为底盘速度/角速度诱导的运动模糊强度。P_j < τ_id ⇒ 身份不可信，实例按「身份未知」满膨胀处理。

**定义 542（amodal 保守占据）** 对每个实例 j，conformal 掩码补全器返回 O_j^amo，满足 P(O_j^true ⊆ O_j^amo) ≥ 1−δ_j（δ_j 为实例级名义风险）。对遮挡帧，O_j^amo 按遮挡时长与速度做各向异性膨胀：O_j^amo ← O_j^amo ⊕ B(ε_seg + ρ_occ·age_occ)。禁止用「掩码可见部分」直接当占据——这是 v9 的隐形漏洞。

**定义 543（实例级间隙）** g_j(t) = dist(robot_footprint(t), O_j^amo)，块内最坏界 ĝ_j,min = min_{k≤K} (F̂^{IB}_{g,j}(s, a^{1:k}) − β_j − ε_seg)，其中 F̂^{IB} 为实例条件前向模型，β_j 为其实例级误差余量。实例证书有效 ⇔ ∀j: ĝ_j,min ≥ d_safe(cat_j) ∧ P_j ≥ τ_id。

**定义 544（底盘运动学与扫掠体）** 底盘状态 b = (x, y, θ, v, ω)，满足运动学/动力学可行集 v ∈ V(b), ω ∈ Ω(b)。块时域扫掠体
```
SV_t = ⋃_{k=1..K} ( footprint(b_k) ⊕ B(ε_odom + ε_track) )
```
footprint 含机械臂在当前构型下的投影；旋转分量用扇形外包（与平移扫掠并集），保证不因角速度漏覆盖。

**定义 545（底盘感知停止距离）** 
```
d_brake^base = v·τ_react + v² / (2·a_brake) + (|ω|·R_base)² / (2·a_rot)
a_brake = min( μ·g·cosφ − a_lat(v,ω), a_max(m), a_floor )
```
a_lat 为转弯离心项，m 为载荷，μ/φ 为地面摩擦与坡度。d_brake^base 与 v9 的臂停车距离 d_brake^arm 在同一「停车路径长度」量纲下相加。

**定义 546（倾斜/质心稳定证书）** 块内最坏倾斜角 η_max = max_k η(b_k, arm_k, m_k)，质心支撑裕度 d_com = min_k dist(proj_{CoM}(k), ∂support(k))。证书有效 ⇔ η_max ≤ η_tilt ∧ d_com ≥ d_com,min。不稳定 ⇒ 块拒绝，不是简单降速。

**定义 547（实例-扫掠关联图）** G_t^{IB} 以实例与 base 为节点；边 (j,k) 存在 ⇔ O_j^amo ∩ SV_k ≠ ∅；边权 w_{j,k} = TTC_j(k)（预测接触时间）。关联图把「哪些实例真正会被这次底盘运动威胁」显式化，避免对所有实例统一保守膨胀。

**定义 548（实例-底盘联合证书）** Ĉ_t^{IB} = ({ĝ_j}, ê_max, η_max, ϱ_id, γ_grasp, ϱ_occ)。有效 ⇔
1. ∀j∈I: ĝ_j,min ≥ d_safe(cat_j) ∧ P_j ≥ τ_id；
2. η_max ≤ η_tilt ∧ d_com ≥ d_com,min；
3. ϱ_id ≤ τ_occ；
4. ∀j 在 G^{IB} 中有边 ⇒ 存在联合中止点（定义 551）。
任一不满足 ⇒ 该候选块拒绝；无候选 ⇒ K_eff=1 单步 fallback（等价 v9）。

**定义 549（底盘-机械臂联合动作块）** a_k = (a_k^base, a_k^arm)。协调模式 ∈ {stop_and_go, compensated, base_only, arm_only}：stop_and_go 下 base 先动、arm 保持并锁定相对位姿，base 到达后 arm 执行；compensated 下 base 与 arm 同动，但要求 base 加速度 ≤ a_comp 且 arm 补偿误差 ≤ ε_comp。模式切换在块边界，切换本身计入证书。

**定义 550（就位可达性）** 对目标实例 j 的预测位姿，臂可达集 R_arm(b)；可行就位集
```
B_j = { b : O_j^amo ⊆ R_arm(b) ⊕ 容差
          ∧ b ∈ FreeSpace
          ∧ SV(b) ∩ (O_j^amo ∪ O_other^amo) = ∅
          ∧ η_max(b) ≤ η_tilt }
```
b* = argmin_{b∈B_j} E[任务代价] s.t. 就位路径本身持联合证书。B_j=∅ ⇒ 退回「先靠近再抓」的两段式，且第二段 K_eff=1。

**定义 551（联合停车不变式与联合中止点）** 前缀索引 p 是联合中止点 ⇔ 对每个 G^{IB} 中的关联实例 j：
```
d_brake^base(v_p, ω_p) + d_brake^arm(v_p^arm) + d_safe(cat_j)
    ≤ dist(SV_p, O_j^amo) − |traj^{base,arm}_{p:K}|
```
P_t 为全体满足式的前缀集合。中块违规时取 p* = max{p ∈ P_t : p ≤ k_exec}；若 P_t ∩ [1, k_exec] = ∅ 则该块在生成期即须拒绝（骨架保证接受块时 P_t 覆盖首个受威胁前缀）。

**定义 552（实例身份漂移风险与感知-运动门控）** 
```
ϱ_id(t) = 1 − min_j P_j(t)            （最坏实例口径）
v_perc(τ_occ) = inf{ v : ϱ_id(v, ω) ≤ τ_occ }   （单调性见引理 90）
K_eff^{IB}(t) = max(1, ⌊K_eff(t)·(1 − min(1, ϱ_id(t)/τ_occ))⌋)
```
运行规则：先令 v_cap = min(v_desired, v_perc)，再按 K_eff^{IB} 定块长；若 v_perc 不可达（即使 v=0 仍 ϱ_id>τ_occ，如严重遮挡）则禁签实例证书，整体退回 v9 聚合证书。

## 2. 形式化定义（升级）

**升级定义 533（块证书，v10）** Ĉ_t ← Ĉ_t^{IB}。前向模型 F̂ 升级为实例条件版本 F̂^{IB}，输入 (s, a, 实例图 G^{IB})；β 改为实例级 β_j，按类别与遮挡态标定（E573/E589）。

**升级定义 536（中立元表，v10）** 新增行：IPC→单体包围球（v9 聚合）；BSV→v≡0,ω≡0；PMG→v_cap=v_safe_default；BPP→原地。其余行不变。

# IP-357 InstancePersistentCertifier：实例持久化证书器
class InstancePersistentCertifier:
    def __init__(self, segmenter, tracker, amodal, tau_id=0.6, delta=0.01):
        self.seg, self.trk, self.amo = segmenter, tracker, amodal
        self.tau_id, self.delta = tau_id, delta

    def update(self, rgbd, base_state):
        masks = self.seg(rgbd)                          # 掩码 + 置信度
        insts = self.trk.associate(masks, rgbd.pose)    # 持久 ID（定义 540）
        for j in insts:
            j.occ = self.amo.occlusion_state(j, base_state)
            j.O_amo = self.amo.complete(j, self.delta)  # conformal 补全（定义 542）
            j.P = self.identity_confidence(j, base_state)  # 定义 541
        return insts

    def instance_cert(self, insts, pred_clear, beta):
        cert = {}
        for j in insts:
            g_min = min(pred_clear[j]) - beta[j] - self.amo.eps_seg
            cert[j.id] = (g_min, j.O_amo, j.P)
        ok = all(g >= d_safe(j.cat) and j.P >= self.tau_id for j, (g, _, _) in cert.items())
        return ok, cert


# IP-358 BaseSweptVolumeCertifier：底盘扫掠体证书器
class BaseSweptVolumeCertifier:
    def __init__(self, kinodynamics, footprint, eta_tilt=0.12, d_com_min=0.03):
        self.kd, self.fp = kinodynamics, footprint
        self.eta_tilt, self.d_com_min = eta_tilt, d_com_min

    def swept_volume(self, base_seq):
        return union(self.fp(b_k).minkowski(B(self.kd.eps)) for b_k in base_seq)

    def stopping_distance(self, b, payload, mu, slope):
        a = min(mu * G * cos(slope) - self.kd.a_lat(b),
                self.kd.a_max(payload), self.kd.a_floor)
        return b.v * self.kd.tau_react + b.v**2 / (2*a) \
             + (abs(b.w) * self.fp.R)**2 / (2 * self.kd.a_rot)

    def coupling_graph(self, insts, base_seq):
        sv = self.swept_volume(base_seq)
        return {(j.id, k): ttc(j.O_amo, base_seq[k]) for j in insts
                for k in range(len(base_seq)) if intersects(j.O_amo, sv[k])}

    def stability_cert(self, base_seq, arm_seq, payload):
        eta = max(tilt(b_k, a_k, payload) for b_k, a_k in zip(base_seq, arm_seq))
        dcom = min(com_margin(b_k, a_k, payload) for b_k, a_k in zip(base_seq, arm_seq))
        return eta <= self.eta_tilt and dcom >= self.d_com_min


# IP-359 PerceptionMotionGate：感知-运动耦合门控
class PerceptionMotionGate:
    def __init__(self, drift_estimator, tau_occ=0.15, v_safe_default=0.15):
        self.est, self.tau_occ, self.v_safe = drift_estimator, tau_occ, v_safe_default

    def drift_risk(self, insts, v, w):
        return self.est.predict(insts, v, w)            # 定义 552

    def velocity_cap(self, insts, v_des):
        if not self.est.available:
            return self.v_safe                         # 估计失效：最保守
        lo, hi = 0.0, v_des
        if self.drift_risk(insts, 0.0, 0.0) > self.tau_occ:
            return None                                # 即使静止也不可信 → 禁签实例证书
        for _ in range(8):                             # 单调性下二分求 v_perc
            mid = 0.5 * (lo + hi)
            if self.drift_risk(insts, mid, 0.0) <= self.tau_occ:
                lo = mid
            else:
                hi = mid
        return lo

    def chunk_gate(self, K_eff_v9, rho):
        return max(1, int(K_eff_v9 * (1 - min(1.0, rho / self.tau_occ))))


# IP-360 BasePlacementPlanner：底盘就位规划器
class BasePlacementPlanner:
    def __init__(self, arm_reach, bsv, free_space):
        self.reach, self.bsv, self.fs = arm_reach, bsv, free_space

    def feasible_set(self, target, insts, base_state):
        out = []
        for b in self.fs.sample_candidates(base_state):
            if not self.reach.covers(target.O_amo, b):
                continue
            if not self.bsv.swept_safe_path(base_state, b, insts):
                continue
            out.append(b)
        return out

    def plan(self, target, insts, base_state):
        B = self.feasible_set(target, insts, base_state)
        return min(B, key=self.task_cost) if B else None

## 4. 推导

**引理 87（实例证书保守性）** 若 conformal 补全满足 P(O_j^true ⊆ O_j^amo) ≥ 1−δ_j，且实例条件前向模型误差 |F̂^{IB}_{g,j} − F_{g,j}| ≤ β_j，则 ĝ_j,min ≤ g_j,k（∀k≤K）至少以概率 1−δ_j 成立。故实例证书有效 ⇒ 真实间隙 ≥ d_safe(cat_j)。证明：真实间隙 g_j,k = F_{g,j}(s,a^{1:k}) ≥ F̂^{IB}_{g,j}(s,a^{1:k}) − β_j ≥ ĝ_j,min + ε_seg − ε_seg = ĝ_j,min；amodal 超集性保证 dist(·,O_j^amo) ≤ dist(·,O_j^true)。∎

**引理 88（遮挡无幽灵穿透）** 若 O_j^true ⊆ O_j^amo，则任何避开 O_j^amo 的扫掠体/轨迹也避开 O_j^true。结合引理 82 的块证书与定义 551，遮挡实例不会因「掩码不可见」而被放行。证明：集合包含的单调性直接给出。∎

**引理 89（底盘-臂联合停车完备性）** 若对每个 G^{IB} 中关联实例 j，存在前缀 p 满足定义 551，且 base/arm 的停止路径同向时取距离相加、异向时取较大者（保守估计），则任意中块违规时刻 k_exec 都存在 p* ≤ k_exec 使 base 与 arm 同时安全停驻，终点距 O_j^amo ≥ d_safe(cat_j)。证明：联合停车距离 d^joint = d_brake^base + d_brake^arm（同向），刹车轨迹为可行运动学子轨迹，故实际到达位置在保守距离内；对每个 j 的不变式给出终点间隙下界。∎

**引理 90（PMG 反脆弱单调性）** 在场景固定、遮挡率非减的假设下，ϱ_id(v,ω) 关于 |v|、|ω| 单调非减（模糊与视差随速度增强）。故 v_perc = inf{v: ϱ_id ≤ τ_occ} 良定义，且 ∀v ≤ v_perc 有 ϱ_id(v) ≤ τ_occ；降速不降低证书有效率。证明：单调性由模糊核方差 ∝ 速度、视差位移 ∝ 速度/深度给出；二分求 v_perc 正确性由单调性保证。⧫（依赖经验单调性假设，E578 检验。）

**引理 91（退化严格性）** 对 v10 每个新组件失效注入中立元：IPC→单实例包围球（与 v9 定义 533 的聚合 clearance 逐值一致）；BSV→v≡0,ω≡0, SV=静态 footprint（与 v9 固定底盘一致）；PMG→v_cap=v_safe_default（K_eff 退回定义 539）；BPP→原地（v9 策略）。MW 仅改变调度顺序，不改变取值集合。故 IBMC 可观测行为严格 ∈ v9 退化格点，再沿 v9→v8→v7 链退化。∎

**引理 92（漂移超阈不可签发）** 若 ϱ_id(t) > τ_occ，则定义 548 条件 3 不成立，任何候选块均被拒绝；系统只能降速至 v_perc 或退回 v9 聚合证书。故不存在「以实例证书名义对错误 ID 签发安全」的路径。证明：定义 548 有效性为合取，条件 3 失败即整体失败；退回路径见定义 552 运行规则。∎

## 8. 本轮最大风险

**一句话**：实例证书的安全性依赖 amodal 占据补全的覆盖率与实例 ID 的持久性，而移动底盘提速恰好同时放大遮挡视差与运动模糊——若 ID 漂移与补全误差在同一时刻叠加，系统会以高置信度对错误实例签发「安全」证书，即「唯一能证明安全的信息，恰恰在最需要它时最不可信」。
