# 第 47 轮（承接第 46 轮 v23；本轮灵感：运动控制 × 用户共创） · Co-Motion-Cert：共享控制权限仲裁下的动态证书与共创运动基元记忆（五层架构 v11）

> 承接第 46 轮 v23 Memory-Safety-Voice。v23 已把记忆检索、语音指令、安全绑定与能量租约串成闭环，但隐含假设 H5：姿态证书 P_t 是**瞬时静态几何集**，底层运动控制器可以无损实现它；用户是一次性发令者，而不是轨迹与偏好的共创者。UniBot 在透明/高光层上的证书半径常常与跟踪误差同一量级，一旦执行器饱和、控制延迟、人机共享输入或负载变化出现，H5 就崩塌：证书在感知层 sound，却在执行层因跟踪滞后而静默越界。**运动控制**提供动态可达性与不变性工具（跟踪误差管、控制屏障函数、收缩度量）；**用户共创**把用户从“下命令的人”变成“共同塑造运动的人”，引入控制权限分配、实时意图修正与可复用运动技能。三者耦合出新的核心问题：**当共享控制权限 α_t 在安全临界时让位过慢，或共创运动基元被跨用户/跨负载直接迁移时，动态证书会在执行过程中静默失效并级联到安全谓词**。

## 0. 直觉与动机

**灵感 1（运动控制 → 证书必须沿轨迹成立，而不是只在采样点成立）**
直觉：感知证书回答“我现在大致在哪”，运动控制回答“我下一步一定能到哪”。二者之间隔着跟踪误差。把参考轨迹记作 x̄_{0:H}，真实状态 x_k 与参考轨迹的误差满足 e_{k+1}=A_k e_k+w_k+d_k；其中 d_k 包含模型误差、执行器饱和残差和用户共享输入。只要闭环误差系统关于某个收缩度量 M_k 是 ρ-收缩的，真实轨迹就被包在参考轨迹周围的一条**管**里。证书应由“瞬时球 P_t”升级为“时变椭球管 T_{0:H}”，并在执行前用独立残差集共形校准管的膨胀量。

**灵感 2（用户共创 → 控制权限是可分配、可审计的稀缺资源）**
直觉：共创不是把控制权全部交给用户，也不是机器人假装听不见。用户提供 u^user（拖拽、遥操作、语音修正、示范轨迹），机器人提供 u^robot；真正的控制输入是二者按权限 α_t 的混合。α_t 越大，用户越有创造性，但安全余量越薄。于是 α_t 应由一个**安全滤波 QP** 在线求解：在控制屏障约束与动态管可行域内，尽量保留用户权限；一旦约束不可满足，就降低 α_t，再不行就 handover / fail-closed。用户共创还意味着用户会反复修改轨迹、给出偏好与修复动作，这些都应进入可审计的数据闭环。

**灵感 3（运动基元记忆 → 共创技能可复用，但不能盲复用）**
直觉：用户教过的“绕桌取杯”“轻放玻璃杯”是可复用的运动基元，而不是一次性轨迹。但运动基元的可执行性依赖用户体型、负载、电池、关节温升与当前感知模态。因此记忆条目必须绑定动力学条件，并在复用前**重新认证**：先按当前 θ_dyn 重算收缩管，再检查能量租约与安全绑定；若不合格，应用历史修复算子 δ_repair 或回退到保守规划，而不是直接播放旧轨迹。

**耦合升级：从四层到五层 v11**
根信任层同时持有姿态租约 ℓ_p、能量租约 ℓ_e 与**动力学租约 ℓ_d**（负载、关节限位、温升、执行器健康）；L1 几何层输出动态管 T_t 而非静态 P_t；L2 上下文层预测用户意图与可观测性；L3 CAR 守卫改为“管+CBF+权限”三重守卫；L4 DCL 采集闭环新增“共创运动基元 + 用户修复”样本；新增 **L3.5 共享权限仲裁层**，把用户输入投影到认证安全集内。五层不是简单叠加：α_t 的选择会改变 d_k 的界，d_k 又反过来决定 T_t 的宽度和 ℓ_d 的有效期，形成“权限-管-能量”三元耦合。

## 1. 形式化定义（增量：定义 59–63）

**定义 59（跟踪误差管与动态姿态证书）**
离散动力学 x_{k+1}=f(x_k)+B(x_k)u_k+w_k，参考轨迹 x̄_{0:H}，跟踪控制器 u_k=ū_k+K_k(x_k-x̄_k)，误差 e_k=x_k-x̄_k。若存在 0<ρ<1、M_k≻0、Q_k≻0 使收缩条件
A_k^T M_{k+1} A_k - ρ^2 M_k ⪯ -Q_k，A_k=∂f/∂x|_{x̄_k}+B(x̄_k)K_k
成立，且 ‖w_k+d_k‖_{M_{k+1}}≤ε̄，则管半径递推为
r_{k+1}=ρ r_k+ε̄，r_0=‖e_0‖_{M_0}。
用独立审计残差集做共形校准得到 q_{1-α_d}，定义**动态姿态证书**
T_k={x: ‖x-x̄_k‖_{M_k} ≤ r_k+q_{1-α_d}}。
与定义 52 的静态 J_t 相比，T_k 强制证书在整个执行时域 [0,H] 上成立；P_t 只是 T_t 在 k=0 的截面。

**定义 60（共享控制权限与共创许可证）**
用户输入 u^user_t、机器人输入 u^robot_t，权限 α_t∈[0,1]：
u_t=Π_{U_safe}(α_t u^user_t+(1-α_t)u^robot_t)。
**共创许可证** L_co=(α_max, U_user, X_license, τ_co) 规定用户可介入的最大权限、输入集合、允许共创的状态区域与时效。α_t 不是常数，而是每个控制周期由安全滤波求解的决策变量；α_t 的历史必须进入审计日志，作为“谁在何时拥有多少控制权”的凭证。

**定义 61（共创运动基元记忆 CMP）**
记忆库 M_co={(k_task,k_user,θ_dyn,p,T^p,δ_repair,outcome)}，其中 p 为参数化运动基元（DMP/proMP），T^p 为其认证管，δ_repair 为用户修复算子。检索距离
d(k,k')=d_task+λ_u d_user+λ_d d_dyn+λ_B|B_t-B_i|。
**复用判据**：仅当 d<τ_co、outcome=success、且 ReCert(p,θ_dyn,B_t,m_t)=1 时才允许复用；否则执行 δ_repair 或回退。

**定义 62（共创运动证书的联合 soundness）**
联合证书 J^co_t=(T_t,ℓ_p,ℓ_e,ℓ_d,L_co,α_t,p_t)。若收缩条件成立、共形校准集可交换、α_t 由带零松弛的 CBF-QP 给出、且 p_t 在当前动力学下重认证通过，则
Pr(∀k∈[0,H]: x_k∈T_k ∧ h(x_k)≥0 ∧ E(t)≥E_min) ≥ 1-α_p-α_d-α_co。
该式是感知误差、动态跟踪误差与共创权限误差三源的并集界；任何一项失效都必须触发降级，而不是继续用旧证书执行。

**定义 63（共创联合决策目标）**
π(c_t,ω_t,B_t,v_t,x_t)=(m_t,p_t,α_t) 求解
max U_co = E[Acc]+λ_r Reuse+λ_t Teach-λ_s Risk-λ_e Energy
s.t. T_{0:H} 在定义 62 下 sound，CBF-QP 存在零松弛解，ℓ_e、ℓ_d 有效，B_dyn(v_t,T_t)≥θ_safe。
其中 Acc 为用户接受度，Teach 为教学效率，Reuse 为基元复用收益；该目标显式承认“更安全”与“更好用”之间存在张力。

## 2. 三大新增产出与既有 IP 升级

**IP-69 DTC（Dynamic Tube Certificate）**
- 收缩度量与跟踪误差管：沿参考轨迹线性化，检查 LMI 收缩条件，递推半径
- 执行器饱和/延迟残差建模：把 sat(u)-u 与通信延迟并入 d_k 的界
- 共形校准：在独立审计轨迹上校准 q_{1-α_d}，按模态 m_t 与速度层分层
- 与静态 P_t 的兼容：P_t 取 T_0 的截面，旧接口无需推倒

**IP-70 SAA（Shared Authority Arbitrator）**
- 用户意图置信与权限偏好 α_pref
- CBF-QP 权限仲裁：在 h(x) 前向不变约束下最大化保留用户权限
- 共创许可证执行：α_max、允许区域、超时收回
- 降级链：降 α → handover → fail-closed，禁止“带病共享”

**IP-71 CMP（Co-Motion Primitive Memory）**
- 运动基元库：DMP/proMP + 认证管 + 修复算子 + 结果
- 动力学条件化检索：用户、负载、电池、关节健康共同进入 key
- 复用前重认证：按当前 θ_dyn 重算 T^p，不合格则修复或回退
- 数据回灌：用户修复动作与失败样本进入 DCL，形成“教-学-审”闭环

**既有 IP 升级**
IP-66 MVR：记忆键加入 θ_dyn、user_key 与运动基元，检索到“感知决策”时还要检索“可执行运动”。
IP-67 VAD：语音槽位从“看哪里”扩展为“怎么动/多快/多轻”，输出轨迹约束而非仅模态。
IP-68 SAB：绑定函数加入动态可行性 B_dyn(v_t,T_t)，静态几何可达但动态不可达时禁止执行。
IP-63 ECPS：能量租约把运动功耗 P_motion 计入，模态切换必须为运动预留能量。
IP-62 CCA：新增对抗性用户输入红队、跨用户基元迁移审计、收缩条件失效注入。
IP-51 CAR：守卫从“瞬时 P_t 包含”升级为“整个时域 T_k 包含 + h 前向不变 + 权限有效”。
IP-45 总线：新增 tube-cert / authority-qp / co-motion-primitive / handover 话题。

## 3. 算法骨架

每个控制周期：
1. 读 x_t、参考轨迹 x̄、用户输入 u^user、模态 m_t、能量租约 ℓ_e、动力学租约 ℓ_d。
2. 由 CMP 检索候选基元 p；命中则按当前 θ_dyn 重认证，未命中则用保守规划器生成 p。
3. 计算 α_pref=意图置信×许可证上限，并在 CBF-QP 中求 α_t 与松弛 s_t。
4. 若 s_t>0 或 α_t<α_min → handover；若仍不可行 → fail-closed。
5. 用 α_t 混合输入，DTC 递推 T_{0:H} 并做共形膨胀。
6. CAR 检查 ∀k: x_k∈T_k、h(x_k)≥0、ℓ_e/ℓ_d 有效；通过则执行并记录。
7. DCL 记录 (用户修复、权限轨迹、管宽、结果)，失败样本回灌重训。

**与 v23 的关系**：v23 的 MVR/VAD/SAB 仍在，但 SAB 不再只问“这条指令与当前姿态是否一致”，而是问“在给定权限下，这条指令能否被一条动态可行的管承接”。这把“语音-安全绑定”升级为“语音-动态-权限绑定”。

## 4. 本轮最大风险

**一句话**：共享权限 α_t 与收缩管都依赖“用户输入集合 U_user、模型误差界 ε̄、共形可交换性”这些建模假设，一旦真实用户行为突然越出假设或跨用户基元迁移忽略了体型/负载差异，动态证书会在模型内部 sound、在真实执行中静默越界；因此必须用独立对抗审计集校准 U_user 与 q_{1-α_d}，并在权限、管宽或动力学租约任一临界时无条件降 α 直至 fail-closed。

## 2. 关键推导：从静态证书到动态管

设离散动力学与跟踪控制器为
x_{k+1}=f(x_k)+B(x_k)u_k+w_k，u_k=ū_k+K_k(x_k−x̄_k)。
令 e_k=x_k−x̄_k，沿参考轨迹一阶展开得
e_{k+1}=A_k e_k+w_k+d_k，A_k=∂f/∂x|_{x̄_k}+B(x̄_k)K_k，
其中 d_k 吸收模型失配、执行器饱和残差 sat(u)−u、通信延迟与用户共享输入的影响。若存在 M_k≻0、Q_k≻0 使
A_k^T M_{k+1} A_k − ρ^2 M_k ⪯ −Q_k，
则 M_k 范数下的误差满足
‖e_{k+1}‖_{M_{k+1}} ≤ ρ‖e_k‖_{M_k}+‖w_k+d_k‖_{M_{k+1}}。
记 ε̄≥sup_k‖w_k+d_k‖_{M_{k+1}}，递推得
‖e_k‖_{M_k} ≤ ρ^k‖e_0‖_{M_0}+(1−ρ)^{−1}ε̄。
在独立审计轨迹上用非一致性分数 s_i=‖e_i‖_{M_i} 做共形校准，取 q_{1−α_d} 为 ⌈(n+1)(1−α_d)⌉/n 分位数，最终
T_k={x: ‖x−x̄_k‖_{M_k} ≤ ρ^k r_0+(1−ρ)^{−1}ε̄+q_{1−α_d}}。
**关键点**：饱和残差与用户权限耦合。更激进的 α_t 会产生更大的 d_k，从而扩大 ε̄；因此 α_t 不能独立于 T_t 选择，必须与管宽联合求解。

## 3. 关键算法伪代码

### IP-69 DTC 在线认证
```
def tube_certify(ref, f, Bmat, K, M, Q, rho, calib, alpha_d, H, sat_bound):
    r = norm_M(ref.e0, M[0]); eps = sat_bound
    T = []
    for k in range(H):
        A = jacobian(f, ref.x[k]) + Bmat(ref.x[k]) @ K[k]
        if not psd(A.T @ M[k+1] @ A - rho**2 * M[k] + Q[k]):
            return None, 'contraction_failed'
        eps = max(eps, model_bound(ref.x[k], sat_bound, alpha_t=ref.alpha[k]))
        r = rho*r + eps
        q = conformal_quantile(calib.residual[k], 1-alpha_d)
        T.append(ellipsoid(center=ref.x[k], metric=M[k], radius=r+q))
    return T, 'ok'
```

### IP-70 SAA 权限仲裁 QP
```
def authority_qp(x, user_u, robot_u, h, Lf_h, Lg_h, gamma,
                 alpha_pref, alpha_max, alpha_min, s_tol):
    # min (alpha-alpha_pref)^2 + lambda_s * s^2
    # s.t. Lf_h + Lg_h(alpha*user_u + (1-alpha)*robot_u) + gamma*h >= -s
    #      0 <= alpha <= alpha_max, s >= 0
    alpha, s = solve_convex_qp(x, user_u, robot_u, h, Lf_h, Lg_h, gamma,
                               alpha_pref, alpha_max)
    if s > s_tol:
        return None, s, 'handover'          # 零松弛不可行，交还用户/安全停机
    if alpha < alpha_min:
        return alpha, s, 'authority_too_low'
    return alpha, s, 'execute'
```

### IP-71 CMP 检索 + 重认证
```
def cmp_retrieve_recertify(task_key, user_key, theta_dyn, B_t, m_t,
                           M_co, calib, tau_co, rad_max):
    best = None
    for rec in M_co:
        d = d_task(task_key, rec.k_task) \
          + lu*d_user(user_key, rec.k_user) \
          + ld*d_dyn(theta_dyn, rec.theta_dyn) \
          + lb*abs(B_t - rec.B)
        if best is None or d < best.d:
            best, best.d = rec, d
    if best is None or best.d >= tau_co:
        return None, None, 'miss'
    if best.outcome != 'success':
        return None, None, 'blocked_failure_memory'
    p = best.p.apply_repair(best.delta_repair)      # 复用用户修复算子
    T, status = tube_certify(p.ref, theta_dyn.f, theta_dyn.B, theta_dyn.K,
                             theta_dyn.M, theta_dyn.Q, theta_dyn.rho,
                             calib, alpha_d=0.01, H=p.H,
                             sat_bound=theta_dyn.sat_bound)
    if status != 'ok' or max(t.radius for t in T) > rad_max:
        return p, T, 'recertify_failed'
    if not energy_lease_valid(B_t, p.motion_energy(), t+p.H, E_min):
        return p, T, 'energy_infeasible'
    return p, T, 'memory_recertified'
```

### 全局 Co-Motion 决策
```
def co_motion_step(c_t, omega_t, B_t, v_t, x_t, user_u, theta_dyn,
                   M_co, calib, lease_e, lease_d):
    m_t = ecps_or_mvr(c_t, omega_t, B_t, v_t)          # 继承 v23 感知决策
    if m_t is None:
        return 'fail_closed', 'perception'
    p, T, src = cmp_retrieve_recertify(c_t.task, v_t.user, theta_dyn,
                                       B_t, m_t, M_co, calib, tau_co, rad_max)
    if p is None or src in ('miss', 'recertify_failed'):
        p = conservative_planner(x_t, c_t, theta_dyn)   # 回退保守规划
        T, st = tube_certify(p.ref, theta_dyn.f, theta_dyn.B, theta_dyn.K,
                             theta_dyn.M, theta_dyn.Q, theta_dyn.rho,
                             calib, 0.01, p.H, theta_dyn.sat_bound)
        if st != 'ok':
            return 'fail_closed', 'tube'
    alpha_pref = intent_confidence(v_t, c_t) * lease_d.alpha_max
    alpha, s, st = authority_qp(x_t, user_u, p.robot_u(x_t), p.h,
                                p.Lf_h, p.Lg_h, p.gamma, alpha_pref,
                                lease_d.alpha_max, alpha_min, s_tol)
    if st != 'execute':
        return st, s                                  # handover / fail-closed
    u = project_to_safe(alpha*user_u + (1-alpha)*p.robot_u(x_t), p.U_safe)
    if not car_guard(T, p.h, lease_e, lease_d, alpha):
        return 'fail_closed', 'car'
    dcl_log(v_t, user_u, alpha, T, src, outcome=None) # 执行后回填 outcome
    return (u, m_t, p, alpha), 'execute'
```

## 4. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| DTC 在线管递推 | O(H·n²)（M_k 预分解） | O(H·n²) | 收缩条件 + 共形校准 ⇒ 全时域覆盖 |
| SAA 权限 QP | O(n³) 每周期（小规模） | O(n²) | 零松弛可行 ⇒ CBF 前向不变且保留 α |
| CMP 检索 | O(|M_co|·d) | O(|M_co|·d) | 距离阈值 + 重认证 ⇒ 不盲复用跨用户基元 |
| 全局决策 | O(H·n²+|M_co|·d) | O(H·n²) | 感知/动态/权限三源并集界 ⇒ 降级链完整 |

**正确性定理（Co-Motion Soundness）**：设 (i) 每个控制步的收缩条件成立；(ii) 共形校准集与部署残差可交换；(iii) SAA 返回零松弛解且 α_t∈[α_min,α_max]；(iv) CMP 复用条目在当前 θ_dyn、B_t 下重认证通过。则对任意 k∈[0,H]，
Pr(x_k∈T_k ∧ h(x_k)≥0 ∧ E(t)≥E_min) ≥ 1−α_p−α_d−α_co。
证明要点：感知误差以 1−α_p 覆盖、动态误差以 1−α_d 覆盖、权限/基元认证失败以 1−α_co 覆盖，三者取并集界；任一条不满足时算法进入 handover 或 fail-closed，从而不会输出未经认证的执行动作。**代价**：并集界偏保守，且 α_t 越大、ε̄ 越大，管越宽，可能触发更多 handover——这正是“共创自由度”与“安全余量”的显式折衷。

## 5. 实验设计 E115–E120

| 实验 | 指标 | 门槛 |
|---|---|---|
| E115 动态管覆盖率 | T_{0:H} 的经验覆盖率、平均管宽 | α_d=0.01 时覆盖 ≥ 99%；管宽 ≤ 1.5× 静态 P_t |
| E116 权限仲裁安全 | CBF 违例率、handover 次数、α 平滑度 | 违例 0；handover ≤ 0.5 次/任务；α 抖动 ≤ 0.1 |
| E117 共创教学效率 | 达到用户接受轨迹的迭代数、教学时间 | ≤ 3 次迭代；教学时间较无记忆基线降 ≥ 40% |
| E118 跨用户基元迁移 | 重认证拒绝率、迁移后违例率 | 违例 0；拒绝率 ≥ 30%（证明不是盲复用） |
| E119 运动-能量联合 | P_motion 估计误差、100h 停机次数 | 误差 ≤ 8%；停机 0 起；能量不足导致的权限降级 ≤ 2 次/小时 |
| E120 对抗用户输入红队 | 越界注入下的违例率、fail-closed 时延 | 违例 0；≤ 100ms 内进入 fail-closed |

**回退策略**：
- E115 覆盖率 < 95% → 增大 q_{1−α_d} 或降低 α_max，优先保 soundness。
- E116 handover 过多 → 放宽 α_min 但收紧 α_max，或提高 CBF γ。
- E118 迁移违例 > 0 → 关闭跨用户检索，仅允许同用户同负载复用。
- E119 能量-运动冲突 → 强制保守基元 + Depth On + fail-closed 模式。

## 6. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 用户输入越出 U_user 假设 | 高 | 独立对抗审计集校准 U_user；在线残差监测触发降 α |
| 跨用户运动基元迁移忽略体型/负载 | 高 | 复用前强制重认证；不同 user_key 提高 τ_co；违例即屏蔽 |
| 收缩条件在高速/重载下失效 | 高 | 分层收缩度量；失效即回退低速保守基元并 fail-closed |
| 共形可交换性被用户适应行为破坏 | 中 | 滚动校准 + 分布漂移检测；漂移时增大 q 或停用记忆 |
| 管过宽导致频繁 handover/冻结 | 中 | 自适应 α_max 与保守规划器切换；按任务风险分级 |
| 权限日志泄漏用户操作隐私 | 低 | 本地脱敏存储、仅保留审计所需摘要 |

## 7. 本轮最大风险

**一句话**：Co-Motion-Cert 的 soundness 完全依赖“用户输入集合 U_user、模型误差界 ε̄、共形可交换性”这三个建模假设，任何真实用户行为的突变或跨用户运动基元的隐性差异都会让动态管在模型内 sound、在真实执行中静默越界；因此必须把 U_user 与 q_{1−α_d} 放进独立对抗审计闭环，并在权限、管宽、动力学租约任一临界时无条件降 α 直至 fail-closed。
