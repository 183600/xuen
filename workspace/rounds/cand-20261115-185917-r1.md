# 第 9 轮（本次会话第 1 轮；技术基线 v8；本轮灵感：「多模态融合」×「目标检测」）
> **基线**：第 8 轮 MetricVoiceGauge-DA-SPR-Cal v8（定义 493–531；引理 77–81；实验 E531–E550）。
> **本轮纪律**：多模态融合只改变**证据如何组合**，目标检测只改变**证据从哪里来**；两者都不被允许放宽 M₀/M₁ 的物理安全语义。新增模块一律为**可选增强**，任一失效必须逐级退回 v8。

## 0. 直觉与动机

**灵感 1（多模态融合 → 把“证据组合”与“特征拼接”分开）**

直觉：工程上说的多模态融合，往往是“把几路特征 concat 起来再过一个网络”。这在统计上默认了一件几乎从不成立的事：**各模态的条件独立**。一旦相机、激光、深度图共享同一次雨雾、同一块脏镜头、同一批标注偏差，它们的错误就是相关的；此时“多数同意”只是**同一个错误的回声**，不是独立投票。更危险的是，安全系统会因此在自己最该怀疑的时刻（全模态同时看到同一个幻觉）最有信心。

因此本轮不把融合当作“提精度的小技巧”，而把它当作**证据代数**：每一路检测必须先变成带覆盖率保证的**上界证据**，再按“安全 / 任务”两条互不干扰的通道组合。安全通道只做**保守并集（OR）**，因为只有 OR 对相关误差稳健；任务通道才允许**一致性加权融合**，并且其置信增益被有效独立模态数 `n_eff` 硬性封顶——`n_eff→1` 时融合增益必须→0。一句话：**安全靠冗余，效率靠共识，二者绝不能混用**。

**灵感 2（目标检测 → 检测器输出不是“物体”，而是“带角色、带校准、带开放集标签的证据”）**

直觉：检测框看起来是客观的，其实每一个框都隐含了四个未声明的前提：(a) 置信度是校准过的；(b) 非极大值抑制（NMS）没有把真目标压掉；(c) 物体属于闭集里某个已知类；(d) 框的位置噪声可忽略。真实系统里这四条全都会破：检测器在分布外**过度自信**；NMS 会因为一个高置信误检压掉近处的真障碍物；开放世界里的未知物体会被硬塞进某个已知类或直接漏掉；小目标与遮挡目标的定位协方差大得惊人。

所以本轮把检测结果重新定义为**类型化证据** `d=(b,c,q̃,u,σ,role,m,t)`：`q̃` 是逐类、逐尺寸桶做保形校准后的**上置信界**；`σ` 是开放集新颖度；`role` 由几何与任务共同决定（SAFETY / TASK / IGNORE），并规定 **SAFETY 角色永不允许被“低置信度”或“一致性”删掉**，只能被更强的安全证据覆盖。再叠加两条检测器特有的审计：**NMS 抑制审计**（保留 pre-NMS 候选集，走廊内被压掉的框重新入安全集）与**指代消歧**（语音说“抓红色杯子”时，若候选不唯一，系统必须拒绝执行而不是猜）。

**交叉洞察（1+1>2）：agreement ≠ independence，共识不是证据**

把两条灵感合起来，会出现一个此前没有被显式建模、却足以毁掉整套证书的对象：**共识幻觉（consensus hallucination）**。多模态检测的一致性 `A` 只度量“它们此刻是否同意”，不度量“它们是否会一起错”。当各模态共享主干网络、共享训练分布、共享被污染的前端时，`A` 越高，恰恰可能是**相关误差越大**。于是“融合”会给出一个比任何单模态都更自信、但错误完全相同的结论，而所有证书看起来完美。

本轮的正面回答是把**相关结构**纳入证书：在线估计逐对误差相关 `ρ_mn`，折算有效独立模态数 `n_eff=K/(1+(K−1)ρ̄)`；`n_eff` 低时禁止用一致性抬升安全置信，并注入 `risk_FUSE`；同时用**模态贡献账本**识别“某一路长期独自覆盖全部安全目标”（覆盖塌缩 = 单点故障）与“名义可靠却长期零贡献”（静默失效）。这三者组合，使系统能够回答一个 v8 回答不了的问题：**这次“大家都同意”，到底是独立证据的收敛，还是同一个错误的合唱？**

## 1. 研究问题（本次会话第 1 轮）

- **Q1（角色分离的无空洞融合）**：如何把每个检测按角色分流，使安全通道的召回严格不低于任一单模态的校准召回（相关误差下仍成立），而任务通道可以自由追求精度与效率，且任务通道的删减**永不**反噬安全通道？
- **Q2（相关误差感知的置信封顶）**：如何在线估计模态间误差相关 `ρ_mn` 与有效独立模态数 `n_eff`，并给出一个可证明的置信增益上界，使得 `ρ→1` 时融合不产生任何“额外把握”，从而杜绝共识幻觉导致的假通过？
- **Q3（检测器特有失效的可审计性）**：NMS 抑制、开放集未知物、语音指代歧义这三类检测器/接口层失效，能否各自转成**保守方向**的证书条件（漏检→重入安全集、未知→按危险处理、歧义→拒绝执行），而不是静默通过？

## 2. 设计原则（P13–P15）

**P13 角色分离融合拓扑（Role-Separated Fusion Topology, RSFT）**
每条检测先定角色：
```
role(d) = SAFETY   若 b(d) ∩ C_brake(s,v) ≠ ∅
                  ∨ c(d) ∈ {human, animal, unknown}
                  ∨ TTC(d) ≤ T_brake
         = TASK     若 d 被语音指代或与当前任务目标匹配
         = IGNORE   其余
```
安全通道只做保守并集：`H_safe(r)=max_{m∈A_active} h̃_m(r)`；任务通道做一致性加权融合。**安全集对任务集单向吸收**：任务通道不得删除任何 `H_safe ≥ τ_det` 的簇，只能改变其优先级。

**P14 一致性≠独立性（Agreement-Not-Independence, ANI）**
融合置信增益的硬上界：
```
L_fuse(r) = min( Σ_m w_m·logit(h̃_m(r)),  max_m logit(h̃_m(r)) + ½·log n_eff(r) )
n_eff(r)  = K / ( 1 + (K−1)·ρ̄(r) ) ,  ρ̄ = 加权平均两两相关
```
当 `ρ̄→1` 时 `n_eff→1`，第二项→0，融合退化为 `max`（无增益）；当 `n_eff < τ_ind` 时，任务通道也不得用一致性提升置信，只能维持仲裁。

**P15 类型化保形检测（Typed Conformal Detection, TCD）**
每个模态、每个类别、每个尺寸/遮挡桶独立做保形校准，输出满足覆盖率的上置信界：
```
P( y=1 | q̃_m(d) ≥ α ) ≥ 1 − α − ε_fin ,   ∀ 桶
h̃_m(d) = min(1, q̃_m(d) + ε_cal,m(bucket))
```
`q̃` 只依赖校准集与当前输入，不读检测器内部 logit；M₀/M₁ 只接受 `h̃` 与几何硬检查，不接受未校准的 `q`。

## 3. 与基线的接口（如何退化）

- 保形校准不可用/校准集过期 ⇒ 使用离线最坏保守裕度 `ε_cal^max`，安全通道仍为 OR，语义退回 v8 的保守检测前端；
- 一致性/相关估计失效 ⇒ **关闭任务通道**，只保留安全 OR 通道；效率下降，安全不变；
- 贡献账本 / 共识监控失效 ⇒ 冻结为标定后的静态模态权重，`risk_FUSE≡0`；
- 开放集新颖度失效 ⇒ **所有检测按 unknown 处理**（最大保守，不允许落入 IGNORE）；
- NMS 审计失效 ⇒ 安全走廊内禁用激进 NMS（降阈值/不抑制），以算力换召回；
- 指代消歧失效 ⇒ 忽略语音指代，退回 v8 的 GCT 显式命令，不做开放词表绑定；
- 全部失效 ⇒ 安全 OR + 原始阈值 + v8 主环，逐位等价 MetricVoiceGauge-DA-SPR-Cal v8，再退回 v7。

## 4. 预期贡献

1. **角色分离融合拓扑（RSFT）**：把“安全靠冗余、效率靠共识”从口号变成可证明的通道隔离，给出安全召回不低于最佳单模态的定理；
2. **相关误差感知的置信封顶（ANI）**：显式建模模态间误差相关，给出 `n_eff` 与融合增益上界，从机制上消灭共识幻觉造成的假通过；
3. **类型化保形检测（TCD）**：把目标检测的置信度校准、NMS 抑制审计、开放集新颖度、语音指代消歧统一成**保守方向**的证书条件，检测器失效不再静默；
4. 完整的**语音-指代-检测-融合-角色-指标-动作**七元闭环：E551–E572 覆盖校准、通道隔离、相关误差、NMS、开放集、指代、退化与实机验证。

## 5. 本轮最大风险

**一句话**：整套安全论证建立在“安全通道的并集会覆盖真实危险”之上，可一旦所有模态共享同一个盲区（透明玻璃、逆光、罕见遮挡、共同训练分布缺失的类别），而开放集检测器又恰好在同一盲区上过度自信，那么 `n_eff` 与 `A` 会同时给出漂亮的数字，系统将在**全体模态一起错**的时刻签发出最自信、也最危险的证书。

**新增定义 532（类型化检测 TypedDetection）** 检测器的统一输出契约：
```
d = ( b ∈ SE(3), c ∈ C ∪ {unknown}, q ∈ [0,1], u = Σ_loc ∈ ℝ⁶ˣ⁶,
      σ ∈ [0,∞), role ∈ {SAFETY,TASK,IGNORE}, m ∈ A, t )
```
`q` 只用于日志；任何证书与阈值判断一律读 `h̃`（定义 533）。`u` 用于把定位不确定性传播到走廊占用与 TTC。

**新增定义 533（保形检测校准 ConformalDetectionCalibration）** 对每个桶 `β=(m,c,size,occlusion)` 在独立校准集 `D_cal` 上取上分位数：
```
q̃_m(d) = Quantile_{1−α}( { q̄(d′) : d′ ∈ D_cal, β(d′)=β(d) } )
h̃_m(d) = min(1, q̃_m(d) + ε_cal,m(β))
```
覆盖率保证：在可交换性假设下 `P(y=1 | h̃_m ≥ α) ≥ 1−α−ε_fin`。桶不足时上溯到父桶并乘保守系数；校准集漂移由 v8 的 OnlineCalib-FI 触发重标。

**新增定义 534（角色定型 SafetyRoleTyping）**
```
role(d) = SAFETY  若 b(d)∩C_brake(s,v) ≠ ∅ ∨ c(d)∈{human,animal,unknown}
                  ∨ TTC(d) ≤ T_brake
        = TASK    若 d ∈ Ref(cmd) ∨ c(d) ∈ C_task(s)
        = IGNORE  其余
```
`IGNORE` 仅对确定已知、确定走廊外、确定非任务类的检测开放；`unknown` 永不为 IGNORE。

**新增定义 535（安全通道融合 SafetyChannelFusion）** 对匹配簇 `r`：
```
H_safe(r) = max_{m ∈ A_active} h̃_m(r)
S_safe = { r : H_safe(r) ≥ τ_det } ∪ Novel(r) ∪ Ref(cmd)
```

## 2. 形式化定义（要点）

**定义 535（安全并集）** 安全集是各模态校准证据的并集，故对任意相关结构成立；这是本轮唯一被允许用于 M₀/M₁ 的融合语义。并集只增不减，任务通道无权删减。

**定义 537（任务融合封顶）** 右项 `max logit + ½log n_eff` 是“有效独立证据”的保守上界；相关越高，`n_eff` 越小，允许的抬升越少。它是**信息论式的封顶**而非调参技巧：即使一致性为 1，也不能凭空多出独立性。

**定义 539（共识幻觉）** 判据把“高一致”与“低有效独立”同时作为告警条件，纠正了“一致即正确”的直觉错误；`risk_FUSE` 对 A 单减、对 `n_eff` 单增、对支配/塌缩/幻觉单增。

**定义 544（八层闭合）** `M_DET/M_FUSE` 的判据均为可观测统计量（覆盖率、抑制率、`n_eff`、贡献），不依赖检测器内部不可验证的 logit；退化映射直接把“不安全”翻译成 M₀ 的几何硬检查。

**定义 547（阈值注入）** `τ_det` 的域偏移项与校准裕度项均非负，保证漂移时只会更保守；`τ_fuse` 随 `1−n_eff/K` 上升，保证相关增强时更不信任共识。

```python
# IP-354 ConformalDetectionCalibrator：逐桶保形校准
class ConformalDetectionCalibrator:
    def __init__(self, alpha=0.05, eps_fin=0.01, min_bucket=30):
        self.alpha = alpha
        self.eps_fin = eps_fin
        self.min_bucket = min_bucket
        self.quantiles = {}          # bucket -> q̃
        self.residuals = {}          # bucket -> list[|q - y|]

    def fit(self, calib_records):
        """calib_records: (bucket, q, y)；y∈{0,1} 真值"""
        from collections import defaultdict
        buckets = defaultdict(list)
        for b, q, y in calib_records:
            buckets[b].append((q, y))
        for b, recs in buckets.items():
            if len(recs) < self.min_bucket:
                continue
            recs.sort(key=lambda r: r[0])
            # 保形上分位：取 1-alpha 经验分位
            k = min(len(recs) - 1, int(np.ceil((1 - self.alpha) * len(recs))) - 1)
            self.quantiles[b] = recs[k][0]
            self.residuals[b] = [abs(q - y) for q, y in recs]

    def upper_bound(self, d, parent_bucket=None):
        b = d.bucket
        if b not in self.quantiles:
            b = parent_bucket if parent_bucket in self.quantiles else None
        if b is None:
            return 1.0, 1.0            # 无校准 ⇒ 最大保守
        q_tilde = self.quantiles[b]
        eps = max(self.residuals[b]) if self.residuals[b] else 1.0
        h = min(1.0, q_tilde + eps)
        return q_tilde, h


# IP-357 ErrorCorrelationEstimator：相关误差与有效独立模态数
class ErrorCorrelationEstimator:
    def __init__(self, K, tau_ind=0.5, ema=0.98):
        self.K = K
        self.tau_ind = tau_ind
        self.ema = ema
        self.rho = np.zeros((K, K))   # 两两相关
        np.fill_diagonal(self.rho, 1.0)

    def update(self, residuals):
        """residuals: K 维 0/1（对锚标是否同错），EMA 估计同号相关"""
        r = np.asarray(residuals, dtype=float)
        outer = np.outer(r, r)
        self.rho = self.ema * self.rho + (1 - self.ema) * outer
        np.fill_diagonal(self.rho, 1.0)

    def effective(self, weights):
        w = np.asarray(weights, dtype=float)
        w = w / (w.sum() + 1e-9)
        pair = 0.0
        denom = 1e-9
        for i in range(self.K):
            for j in range(i + 1, self.K):
                pair += w[i] * w[j] * self.rho[i, j]
                denom += w[i] * w[j]
        rho_bar = pair / denom
        n_eff = self.K / (1 + (self.K - 1) * rho_bar)
        return float(n_eff), float(rho_bar)


# IP-356 AgreementBoundedFusion：角色分离 + 相关封顶
class AgreementBoundedFusion:
    def __init__(self, tau_det=0.6, tau_fuse=0.7, tau_ind=0.5):
        self.tau_det = tau_det
        self.tau_fuse = tau_fuse
        self.tau_ind = tau_ind

    def fuse_cluster(self, cluster, weights, n_eff):
        """cluster: [(h_tilde, role, sigma, bbox), ...]"""
        h = np.array([c[0] for c in cluster])
        roles = [c[1] for c in cluster]
        # 安全通道：保守 OR，相关误差下仍成立
        H_safe = float(h.max())
        # 任务通道：一致性加权 + ½log n_eff 封顶
        logits = np.log(np.clip(h, 1e-6, 1 - 1e-6) /
                        np.clip(1 - h, 1e-6, 1))
        w = np.asarray(weights, dtype=float)
        w = w / (w.sum() + 1e-9)
        raw = float(np.dot(w, logits))
        capped = float(logits.max() + 0.5 * np.log(max(n_eff, 1.0)))
        L_task = min(raw, capped)
        return {
            'H_safe': H_safe,
            'L_task': L_task,
            'p_task': 1.0 / (1.0 + np.exp(-L_task)),
            'safety_roles': [r for r in roles if r == 'SAFETY'],
            'consensus_valid': n_eff >= self.tau_ind,
        }


# IP-360 NMS 抑制审计：走廊内被压掉的真候选重新入安全集
class NMSSuppressionAuditor:
    def __init__(self, tau_det=0.6, tau_iou=0.7, brake_corridor=None):
        self.tau_det = tau_det
        self.tau_iou = tau_iou
        self.corridor = brake_corridor

    def audit(self, pre, post):
        shadows = []
        for d in pre:
            if d['h_tilde'] < self.tau_det:
                continue
            if self.corridor is not None and not intersects(d['bbox'], self.corridor):
                continue
            merged = any(p['h_tilde'] >= self.tau_det
                         and iou3d(d['bbox'], p['bbox']) >= self.tau_iou
                         for p in post)
            if not merged:
                shadows.append(d)      # 被异类/低质框压掉 ⇒ 重入
        ratio = len(shadows) / (len(pre) + 1e-9)
        return shadows, ratio


# IP-358 ModalityContributionLedger：覆盖贡献/支配/静默失效
class ModalityContributionLedger:
    def __init__(self, K, delta_dom=0.8, delta_sil=0.05, window=200):
        self.K = K
        self.delta_dom = delta_dom
        self.delta_sil = delta_sil
        self.cover = np.zeros(K)
        self.window = window
        self.n = 0

    def update(self, h_tilde, safety_mask):
        h = np.asarray(h_tilde, dtype=float)
        if safety_mask.any():
            best = h[safety_mask].max(axis=0)         # per-cluster max
            need = best > 0
            for m in range(self.K):
                unique = (h[m] >= best - 1e-9) & need
                self.cover[m] += unique.sum()
        self.n += 1
        if self.n >= self.window:
            self.cover *= 0.5
            self.n = 0

    def state(self):
        total = self.cover.sum() + 1e-9
        dom = float(self.cover.max() / total)
        order = np.argsort(self.cover)
        silent = [int(i) for i in order[:-1] if self.cover[i] < self.delta_sil]
        collapse = bool(dom > self.delta_dom and len(silent) > 0)
        return {'cover': self.cover.tolist(), 'dom': dom,
                'silent': silent, 'collapse': collapse}


# IP-362 指代绑定：唯一才执行，歧义即拒绝
class ReferenceGroundingGate:
    def __init__(self, tau_margin=0.15, tau_det=0.6):
        self.tau_margin = tau_margin
        self.tau_det = tau_det

    def bind(self, candidates):
        candidates = sorted(candidates, key=lambda c: -c['score'])
        if not candidates:
            return None, 'not_found'
        if len(candidates) == 1:
            c = candidates[0]
            return (c['id'], 'ok') if c['h_tilde'] >= self.tau_det \
                else (None, 'low_evidence')
        margin = candidates[0]['score'] - candidates[1]['score']
        if margin >= self.tau_margin and candidates[0]['h_tilde'] >= self.tau_det:
            return candidates[0]['id'], 'ok'
        return None, 'ambiguous'      # 拒绝猜测

                + lambda_nms * nms_supp + lambda_ood * ood_rate(novelty)
                + lambda_tds * flicker)
    risk_fuse = (lambda_A * (1 - mean_agreement(clusters))
                 + lambda_rho * (1 - n_eff / max(len(post), 1))
                 + lambda_dom * cover_state['dom']
                 + lambda_col * float(cover_state['collapse'])
                 + lambda_ch * float(consensus_hallucination))
    risk_7d = np.array([*base_risk_5d(M, slam_risk), risk_det, risk_fuse])
    w_prime = compute_weights_7d(risk_7d, emotional_reweighter, M)

    # --- 10. 证书条件与 v8 主流程（阈值含 τ_det/τ_fuse） ---
    det_ok = (calib_coverage_ok(calibrator) and nms_supp <= tau_nms
              and ood_rate(novelty) <= tau_oodr)
    fuse_ok = (not consensus_hallucination) and (
        not cover_state['collapse'] or probe_passed(detector_bank))
    soft_ok = det_ok and fuse_ok and ref_ok
    tau = merge_thresholds(get_soft_thresholds(M, online_learner,
                                               domain_adapter, obs),
                           tau_det=tau_det, tau_fuse=tau_fuse)

    C, cert, claims, metrics, rewards = M.metricvoicegauge_round_8(
        M, s, obs, audio_stream, ell=ell, tau_override=tau,
        w_override=w_prime, soft_ok=soft_ok, extra_safety_obstacles=shadows)

    cert = attach(cert, S_safe=S_safe_from(H_safe, shadows, novelty),
                  S_shadow=shadows, A=mean_agreement(clusters),
                  n_eff=n_eff, cover=cover_state, Gamma_ref=None)
    return C, cert, claims, metrics, rewards
```

## 4. 推导

**引理 82（安全并集相对无漏检）** 设真实危险 `y_r=1`，若存在模态 m 满足 `h̃_m(r) ≥ τ_det`，则由定义 535 `H_safe(r)=max_n h̃_n(r) ≥ τ_det`，故 `r∈S_safe`。该校验只用 `max` 的单调性，不依赖 `ρ_mn` 或一致性 `A`，因此对任意相关结构成立。若所有 `h̃_m(r)<τ_det`，由定义 533 的覆盖率，漏判概率 ≤ `α+ε_fin`（每模态），并集不漏检是“任一命中即检出”的必要条件；相关只影响漏检概率能否用 `1−(α)^K` 合并界，不影响“已命中不丢”。∎

**引理 83（角色隔离非干扰）** 安全集 `S_safe` 仅由 `max_m h̃_m` 与 `Novel/Ref` 生成；任务通道输出 `p_task/L_task` 只写入排序与效率层，任何任务通道的删减操作都作用于 `S_task\S_safe`。故任务通道失效或对抗只会降低效率，不会减少 `S_safe`。`δ_DET/δ_FUSE` 均映射为“触发 M₀ 硬检查”，不经由任务通道。∎

**引理 84（一致性增益封顶与极限退化）** 设每模态提供对数似然比 `ℓ_m`，任务融合取 `Σw_mℓ_m`。当模态误差相关 `ρ̄` 时，有效独立观测数 `n_eff=K/(1+(K−1)ρ̄)`，其联合证据不超过 `n_eff` 个独立观测之和；由信息论（每独立观测最多 `ℓ_max` 的证据，平均互信息按 `½log n_eff` 的保守界），允许的额外置信不超过 `½log n_eff`。定义 537 取 `L_fuse ≤ maxℓ + ½log n_eff`。`ρ̄→1 ⇒ n_eff→1 ⇒ 右项→0 ⇒ L_fuse=maxℓ`；`ρ̄→0 ⇒ n_eff=K`，退化为独立融合的上界。故一致性永不产生超过独立证据允许的置信，`n_eff<τ_ind` 时禁用“通过”语义。∎

**引理 85（NMS 审计完备性）** 设 `C_pre` 为抑制前候选集，`C_post` 为 `C_pre` 经 NMS 后保留集，恒有 `C_post ⊆ C_pre`。定义 540 只把 `d∈C_pre\C_post` 且 `h̃≥τ_det`、走廊内、且未被任何 `h̃≥τ_det` 的保留框以 IoU≥τ_iou 正常合并者重入。故：① 若真目标被同类高置信真框正常合并，不重入（避免重复）；② 若真目标被异类/低质框压掉，必重入 `S_safe`。因此 NMS 不能在走廊内静默移除一个本可检出的危险，抑制率 `nms_supp` 同时暴露压制严重程度。∎

**引理 86（开放集保守性）** 未知/新颖区域按定义 541 进入 `S_safe` 并膨胀 `δ_novel`，且 `unknown` 永不为 IGNORE。故新颖度检测器的假阴性（把未知判为已知）至多使区域按“已知类”处理，仍受该类 `h̃` 与走廊几何约束；其假阳性（把已知判为未知）只增加保守裕度，不降低安全。`δ_novel` 覆盖新颖度不确定性，误判方向的代价不对称：偏向危险。∎

**引理 87（指代绑定可靠性）** 定义 542 要求 `|Cand|=1` 且 `margin≥τ_margin` 且 `h̃≥τ_det` 才可执行。若真实指代目标唯一且证据充分，`Cand` 含它且 margin 足够时绑定成功；若存在竞争候选（歧义）或证据不足，系统拒绝并请求澄清。故“执行的动作”对应的指代目标在阈值内唯一；错误绑定只能发生在“检测器把错误目标排在首位且 margin 足够”的情况，该事件概率由检测校准与 `τ_margin` 共同约束，且拒绝是安全动作。∎

**引理 88（模态丢失单调退化）** 设活跃模态集 `A_active` 收缩（传感器故障/降权/超时）。安全集 `H_safe=max_{m∈A_active} h̃_m` 随集合收缩单调不增，故不会因丢模态而“新增”虚假安全；系统退化为剩余模态的并集。若仅剩单模态，`H_safe=h̃_m`，等价单模态校准检测；若 `A_active=∅`，`H_safe` 未定义，直接触发 M₀ 停止。轨迹级跟踪（TDS）在模态丢失时抑制跳变，避免误删已跟踪危险。∎

**引理 89（七级退化正确性）** 七级接口两两正交：CDC 只改 `h̃` 来源，ABF/ECE 只改任务通道，MCL/CCM 只改 `risk_FUSE`，OSNM 只改角色保守度，NSA 只改安全集补集，RGG 只改指代可执行性。故任意子集失效可独立组合；全失效时 `h̃→保守阈值`、任务通道关闭、`risk_DET/risk_FUSE=0`、角色退回几何、指代退回显式命令，安全集为原始阈值并集，逐位等价 v8 的检测前端与主环。∎

## 8. 本轮最大风险

**一句话**：整套安全论证建立在“安全通道的并集会覆盖真实危险”之上，可一旦所有模态共享同一个盲区（透明玻璃、逆光、罕见遮挡、共同训练分布缺失的类别），而开放集检测器又恰好在同一盲区上过度自信，那么 `n_eff` 与 `A` 会同时给出漂亮的数字，系统将在**全体模态一起错**的时刻签发出最自信、也最危险的证书。
