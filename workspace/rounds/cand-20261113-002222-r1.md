# 第 63 轮（承接第 62 轮「ROSE 鲁棒在线场景进化闭环」IP-183~192；灵感循环 II 第 2 轮；本轮灵感：「决策规划」×「视觉伺服」）

> 第 62 轮构建了 ROSE：OLP 在线投影学习、WCV Wasserstein-CVaR 鲁棒编译、RSC 残差自校准、ARA 自适应鲁棒锚点、SBR 场景银行、SHC Hedge 课程、MEL-OA、Shield、OCB。ROSE 把 ESEC 从「静态闭环」推进到「学习-鲁棒动态闭环」。但 ROSE 自述的最大风险（J_φ 病态 / 残差被控制回路吸收 ⇒ CVaR 球覆盖失效）暴露出它仍是**单通道、无前瞻、双时间尺度**的系统：
> 1. **无显式决策规划**：ROSE 每个语义周期只对当前锚点做一次「感知 → 编译 K → 执行」，没有视界、没有技能排序、没有前瞻。场景银行只被当作课程（学什么），没有被当作**规划模型**（接下来做什么、按什么顺序做）。于是它无法「在进入湿滑区之前绕行」，也无法编排接触丰富技能的先后。
> 2. **鲁棒球是单通道观测**：RSC 的 r_t 完全由力/力矩残差经 J_φ 反演得到。A72（J_φ 良态）一旦失效，整条安全链退化为纸面保证。系统缺少一个**独立、高频、几何**的观测通道来交叉验证物理偏差。
> 3. **时间尺度断层**：语义流 10–100Hz 对视觉扰动太慢，力矩环 1–10kHz 又太底层、用不上视觉。中间缺少一个 100–1000Hz 的「视觉伺服」频带：它能在语义周期之间**保持计划并抑制几何漂移**。
> 4. **逐周期安全 ≠ 计划安全**：每一步都安全的动作序列，仍可能把信念状态缓慢带进危险区（漂向奇异位形/夹缝）。需要**信念空间的可达性/不变集**来保证「整条计划」安全，而非「每一拍」安全。

## 0. 直觉与动机

**灵感 1（决策规划 → SBP：场景信念规划器）**
直觉：ROSE 的场景银行其实已经是一个「经验动力学模型」——每个场景簇记录了在该类场景下的损失与险情。把它从课程信号升级为**规划用的生成模型**：维护物理参数 φ 与任务阶段的信念 b_t，从银行按 Hedge 权重采样出「场景树」，在树上做鲁棒滚动时域规划，选出一段技能/阻抗模式序列。规划目标不是期望损失，而是球内最坏 φ 下的 CVaR——与第 62 轮 WCV 一脉相承，但把「一拍编译」变成「H 步前瞻」。关键洞见：**规划不需要精确模型，只需要一个可采样的场景分布**，银行恰好提供它。规划器回答「学什么」之上的问题——「接下来做什么」。

**灵感 2（视觉伺服 → PVF：视觉-力觉交互矩阵融合）**
直觉：经典视觉伺服的核心是交互矩阵 ṡ = L_s·v，把相机运动映射到图像特征速度；第 62 轮的灵敏度 Jacobian J_φ 把物理参数映射到外力矩。两者在数学上同构——都是「隐变量 → 可观测量」的局部线性映射。于是把它们**纵向堆叠**成融合 Jacobian J_fuse = [J_φ; J_s]，用加权最小二乘/EKF 联合估计 φ。当力通道病态（σ_min(J_φ)→0）或残差被控制回路吸收时，视觉通道仍能提供秩——**可观测性从「脆弱的假设 A72」变成「可设计的特征选择条件 A77」**。这直接命中第 62 轮的最大风险。

**灵感 3（视觉伺服 → SgVS + MRS：语义门控的中频伺服环）**
直觉：语义流不该以 100Hz 去追视觉扰动，也不该让力矩环去理解图像。正确做法是插入一个 100–1000Hz 的中频环：语义流低频地选择「伺服什么特征、目标特征值是什么、用哪个阻抗模板」（SgVS 的语义门控），中频环高频地用 IBVS 把特征误差压到零并调制阻抗，力矩环再以 1–10kHz 跟踪。三个时间尺度各司其职：**语义决定做什么，视觉伺服决定怎么对准，力矩环决定多用力**。

**灵感 4（决策规划 × 视觉伺服 → PAW：规划感知鲁棒编译）**
直觉：规划与阻抗不能分开设计。一个几何上可行、但需要不可实现阻抗（超出 𝒦 或球内最坏 φ 下不安全）的计划，必须在**规划时**就被否决，而不是执行时才发现。于是 WCV 从「编译单个 K」升级为「编译 K 的调度」K_{t:t+H}，并与规划器做**可行性过滤**：只有存在鲁棒可行阻抗调度的计划才进入候选集。这把「计划可行性」和「控制可行性」统一成同一个约束。

**灵感 5（决策规划 → BSR：信念空间鲁棒安全）**
直觉：逐周期安全是必要不充分的。用鲁棒管（tube）把信念的不确定性沿计划传播，要求整条计划的信念管始终留在安全集内，并构造信念空间的不变集。配合「鲁棒选项顺序组合」：若后继技能的前置条件在球内最坏 φ 下被前驱技能的后置条件蕴含，且每个技能保持不变集，则整条计划安全——这是**组合式安全证书**，而不是逐拍检查。

**灵感 6（视觉伺服 → VSA：感知分歧监控）**
直觉：若力残差被控制器吸收（第 62 轮最大风险的另一半），视觉特征会先「露馅」——接触点滑动、物体位姿漂移在图像上可见。于是把视觉通道当作**独立安全监控器**：当视觉特征误差与力觉残差出现显著分歧时，判定「感知分歧」，触发保守回退（hold/brake/replan）。这是 Simplex 式双通道互检。

**灵感 7（合流 → VISTA：视觉伺服知情、场景驱动任务规划的鲁棒闭环）**
VISTA = ROSE + 决策规划 + 视觉伺服：SBP 回答「做什么、按什么顺序」（H 步前瞻），SgVS/MRS 回答「怎么高频对准」，PVF 回答「物理偏差是否被看见」，PAW/BSR 回答「整条计划是否安全」，VSA 回答「两个通道是否吵架」。第 62 轮是「学习-鲁棒」的闭环，VISTA 是「规划-视觉-学习-鲁棒」的四维闭环。

## 1. 形式化定义（增量：定义 185–196）

- **定义 185（VISTA 四维闭环）**：VISTA = (ROSE, SBP, OSL, PVF, SgVS, MRS, PAW, BSR, TCA, VSA, J_vista)。定位：在 ROSE 的「学习-鲁棒」之上增加「规划」与「视觉伺服」两维，并把 ARA 升级为 TCA。三时间尺度不变式：语义流 10–100Hz（规划/学习/记账）、中频视觉伺服 100–1000Hz（计划段执行/几何纠偏/零学习写）、力矩环 1–10kHz（阻抗跟踪/零学习写）。
- **定义 186（场景信念规划器 SBP）**：信念 b_t ∈ Δ(Φ×Q×ℋ)（物理参数 × 任务阶段 × 险情模式）。π* = argmin_{π∈Π_H} J_plan(π; b_t)，J_plan = sup_{φ∈B(φ̂,r)} CVaR_ε[Σ_{k=0}^{H} ℓ_task(o_k,φ) + λ_s ℓ_safe] + λ_c·cost(π)。候选计划须通过 PAW 可行性过滤；滚动时域只执行第一段，下一语义周期重规划。
- **定义 187（场景信念传播与场景树）**：从银行按 w_c 采样 N 个场景得场景树 T_N = {(φ_i,q_i,h_i)}_{i=1}^N；b_{k+1} = Prop(b_k, o_k, T_N) ⊕ D（D 为有界扰动集，Minkowski 和）。场景树既是规划 rollout 模型，也是 BSR 传播粒子。
- **定义 188（鲁棒选项库 OSL）**：选项 o = (skill, pre_o, post_o, servo_o, I_o)；pre/post 为在球 B(φ̂,r) 上求值的鲁棒谓词；servo_o = (w_s, s*, L_s, λ_gain, K_template)；I_o 为不变集。组合规则：post_{o_i}(B) ⊆ pre_{o_{i+1}}(B) 才允许拼接。
- **定义 189（视觉-力觉观测融合 PVF）**：J_fuse = [J_φ; J_s]，J_s = ∂s/∂φ|_(φ̂,K)；融合残差 r_fuse = [τ_ext^obs − τ_ext^pred; s^obs − s^pred]。加权 Gauss-Newton：δφ̂ = (J_fuseᵀ W J_fuse)⁻¹ J_fuseᵀ W r_fuse；Σ_fuse = (J_fuseᵀ W J_fuse)⁻¹；可观测度 ρ_obs = σ_min(W^{1/2} J_fuse)。
- **定义 190（语义门控视觉伺服 SgVS）**：语义流输出特征规格 spec = (w_s, s*, L_s, λ_gain)；中频环误差 e_s = w_s ⊙ (s − s*)；伺服律 v_cmd = −λ_gain·L_s⁺(s)·e_s，并在零空间调制阻抗 K = K_template + δK(e_s)。语义决定「伺服什么」，伺服决定「怎么对准」。
- **定义 191（中频伺服环 MRS）**：100–1000Hz 读 TCA 锚点的当前计划段与 feature_ref，执行 SgVS，输出 (v_cmd, K_servo)；**零学习写操作**。计划/锚点过期（plan_id 不匹配或 age > τ_fresh）时进入 hold/brake/replan 回退。
- **定义 192（规划感知鲁棒编译 PAW）**：对候选计划 π 编译阻抗调度 K_{t:t+H}：对每段 o_k 与场景树最坏 φ 调用 WCV 得 K_k；若任一 K_k 不可行（∉𝒦 或违反 I_o 或 ρ_rob<0）则 π 被否决。输出 (K_sched, ρ_plan = min_k margin_k)。规划与控制的可行性统一为同一约束。
- **定义 193（信念空间鲁棒安全 BSR）**：信念管 Tube(π) = {b_k}，b_{k+1} = Prop(b_k,o_k,T_N) ⊕ D；计划安全 ⇔ ∀k, support(b_k) ∩ 𝒰_unsafe = ∅ 且存在鲁棒不变集 I_π 使 b_H ⊆ I_π。与 OSL 组合规则共同构成计划级安全证书。
- **定义 194（任务条件锚点 TCA）**：Anchor_t = (x_t, φ̂_t, Σ_t, r_t, R̂_c(t), plan_id, plan_segment, feature_ref, belief_hash, version, checksum)。新鲜性 = (plan_id == current_plan_id) ∧ (age < τ_fresh)；计划过期比数据过期更危险，优先级更高。
- **定义 195（视觉异常监控 VSA）**：分歧统计 d_t = ‖e_s‖²_{Σ_fuse⁻¹}；若 d_t > τ_disagree 且力残差 ‖r_τ‖ < τ_force（力觉说没事、视觉说漂了），判定 perceptual_disagreement → 保守回退；若 d_t > τ_hard → 立即 hold/brake。
- **定义 196（VISTA 证书 J_vista）**：J_vista = (J_rose, plan_id, ρ_obs, ρ_plan, servo_stable, feature_mask_hash, belief_hash)。Valid ⇔ Valid(J_rose) ∧ ρ_obs ≥ ρ_min ∧ ρ_plan ≥ 0 ∧ servo_stable ∧ plan_fresh ∧ feature_mask_hash 一致。

## 2. 关键算法骨架（完整伪代码见产物区）

```python
# SBP：场景信念规划（H 步前瞻，银行采样场景树）
pi* = argmin_{pi∈Pi_H, PAW.feasible(pi)} sup_{φ∈B(φ̂,r)} CVaR_ε[ Σ_k ℓ_task(o_k,φ) + λ_s ℓ_safe ]
# PVF：视觉-力觉融合 Jacobian（力通道病态时由视觉补秩）
J_fuse = [J_phi; J_s];  dphi = (J_fuseᵀ W J_fuse)⁻¹ J_fuseᵀ W r_fuse;  rho_obs = sigma_min(W^{1/2} J_fuse)
# SgVS + MRS：语义门控的中频视觉伺服（零学习写）
v_cmd = -lambda_gain · L_s⁺(s) · (w_s ⊙ (s - s*));  K = K_template + dK(e_s)
# PAW + BSR：规划-阻抗协同 + 信念管安全
K_sched, rho_plan = PAW.compile(pi, tree);  safe = (Tube(pi) ∩ U_unsafe == ∅)
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 5（融合条件数不减）**：J_fuseᵀWJ_fuse = J_φᵀW_φJ_φ + J_sᵀW_sJ_s ⪰ 各项，故 ρ_obs ≥ max(ρ_φ, ρ_s)，且 Σ_fuse ⪯ Σ_φ（Loewner 序）——视觉通道只要满秩，力通道病态就不再致命。
- **定理 2（场景规划 ε-可行性）**：对有限计划集 Π，每候选采样 N ≥ (1/ε)(ln|Π| + ln(1/β)) 个银行场景，只接受零经验违约者，则 P(真违约率 > ε) ≤ β（Hoeffding + 联合界）；注意这是**对银行加权分布**的保证。
- **定理 3（鲁棒选项组合）**：若 post_{o_i}(B) ⊆ pre_{o_{i+1}}(B) 且每个 o_i 保持鲁棒不变集 I_i ⊆ 𝒮_safe，则整条计划对 ∀φ∈B 保持安全（对 H 归纳）。
- **定理 4（中频伺服漂移有界）**：L_s 行满秩时误差动态 ė_s = −λ e_s + d(t)，语义停摆 T_b 内 ‖e_s‖ ≤ e_0e^{−λT_b} + L_d/λ；超阈值由 VSA 触发回退。
- **遗憾分解**：R_T ≤ D·G̃√T（OLP）+ √(2T ln|Π|)（选项选择）+ T·O(√(d/N))（场景近似）；取 N ∝ T 后整体 O(√T)。
- **实时性**：中频与力矩环均零学习写操作（A82），实时路径 ≤1ms 契约不变。

## 5. 本轮最大风险

## 2. 形式化定义（完整版）

**定义 185（VISTA 四维闭环）** VISTA 在 ROSE 的「语义流 ∘ 实时流」骨架上插入中频视觉伺服带，形成三时间尺度：语义流（10–100Hz，规划/学习/记账）、中频 MRS（100–1000Hz，计划段执行/几何纠偏，零学习写）、力矩环（1–10kHz，阻抗跟踪，零学习写）。不变式：**所有学习写操作只发生在语义流；中频与力矩环只读锚点/计划并输出控制量**。

**定义 186（场景信念规划器 SBP）** 信念 b_t 由 PVF 融合估计与任务进度更新。规划
π* = argmin_{π∈Π_H} J_plan(π;b_t)，
J_plan(π;b) = sup_{φ∈B(φ̂_t,r_t)} CVaR_ε[ Σ_{k=0}^{H} (ℓ_task(o_k,φ) + λ_s ℓ_safe(o_k,φ)) ] + λ_c·cost(π)。
候选集先经 PAW 可行性过滤。滚动时域：执行 π* 的第一段，下一语义周期重规划（receding horizon）。

**定义 187（场景信念传播与场景树）** 从银行按 Hedge 权重 w_c 采样 N 个场景得 T_N；信念传播 b_{k+1} = Prop(b_k,o_k,T_N) ⊕ D，D 为有界扰动集。T_N 同时服务于规划 rollout 与 BSR 的鲁棒可达集计算。

**定义 188（鲁棒选项库 OSL）** o = (skill, pre_o, post_o, servo_o, I_o)。pre/post 在球 B(φ̂,r) 上按最坏 φ 求值；servo_o 含语义可选的特征权重 w_s、目标特征 s*、交互矩阵 L_s(·)、增益 λ_gain 与阻抗模板。组合规则：post_{o_i}(B) ⊆ pre_{o_{i+1}}(B) 且 I_{o_i} 为鲁棒不变集，才允许拼接成计划。

**定义 189（视觉-力觉观测融合 PVF）** 令 s 为图像特征，r_fuse = [τ_ext^obs − τ_ext^pred; s^obs − s^pred]。加权 Gauss-Newton 更新 δφ̂ = (J_fuseᵀWJ_fuse)⁻¹J_fuseᵀW r_fuse，Σ_fuse = (J_fuseᵀWJ_fuse)⁻¹，ρ_obs = σ_min(W^{1/2}J_fuse)。W = blkdiag(W_φ,W_s) 归一化力矩与像素量纲。

**定义 190（语义门控视觉伺服 SgVS）** 语义流给出 spec；中频环误差 e_s = w_s⊙(s−s*)，伺服 v_cmd = −λ_gain·L_s⁺(s)·e_s；在任务零空间调制阻抗 K = K_template + δK(e_s)，使大特征误差时自动增柔/减力。语义决定「伺服什么」，伺服决定「怎么对准」。

**定义 191（中频伺服环 MRS）** 以 100–1000Hz 读 TCA 的当前计划段与 feature_ref，执行 SgVS，输出 (v_cmd, K_servo)。计划过期（plan_id 不匹配或 age>τ_fresh）时进入 hold/brake/replan 回退；**任何路径均无学习写操作**。

**定义 192（规划感知鲁棒编译 PAW）** 对 π 逐段编译：对 o_k 与 T_N 中最坏 φ 调 WCV 得 K_k，检查 K_k∈𝒦、满足 I_o、ρ_rob≥0；任一失败则否决 π。输出 (K_sched, ρ_plan=min_k margin_k)。规划与控制可行性统一为同一约束。

**定义 193（信念空间鲁棒安全 BSR）** 计划安全 ⇔ ∀k, support(b_k)∩𝒰_unsafe=∅ 且存在鲁棒不变集 I_π 使 b_H⊆I_π。与 OSL 组合规则共同构成计划级安全证书（定理 3）。

**定义 194（任务条件锚点 TCA）** Anchor_t 扩为 (x_t,φ̂_t,Σ_t,r_t,R̂_c(t),plan_id,plan_segment,feature_ref,belief_hash,version,checksum)，CAS 原子写。新鲜性 = plan_id 匹配 ∧ age<τ_fresh；计划过期优先于数据过期触发回退。

**定义 195（视觉异常监控 VSA）** d_t = ‖e_s‖²_{Σ_fuse⁻¹}；若 d_t>τ_disagree 且 ‖r_τ‖<τ_force 判 perceptual_disagreement（力觉说没事、视觉说漂了）→ 保守回退；d_t>τ_hard → 立即 hold/brake。用于捕获「力残差被控制回路吸收」。

**定义 196（VISTA 证书 J_vista）** J_vista = (J_rose, plan_id, ρ_obs, ρ_plan, servo_stable, feature_mask_hash, belief_hash)。Valid ⇔ Valid(J_rose) ∧ ρ_obs≥ρ_min ∧ ρ_plan≥0 ∧ servo_stable ∧ plan_fresh ∧ feature_mask_hash 一致。审计链新增「计划版本、特征掩码、可观测度」。

### IP-193 SBP（场景信念规划器）

```python
class ScenarioBeliefPlanner:
    def __init__(self, H=8, N=64, eps=0.05, beta=0.05, lam_s=1.0, lam_c=0.1):
        self.H, self.N, self.eps, self.beta = H, N, eps, beta
        self.lam_s, self.lam_c = lam_s, lam_c

    def required_samples(self, n_plans):
        return int(np.ceil((np.log(n_plans) + np.log(1.0 / self.beta)) / self.eps))

    def plan(self, b_t, bank, hedge_w, options, paw):
        cands = list(enumerate_plans(options, self.H))      # 有限候选计划集 Pi_H
        N = max(self.N, self.required_samples(len(cands)))   # 定理 2 的样本量
        tree = [bank.sample(hedge_w) for _ in range(N)]      # 场景树 T_N
        best, best_obj = None, np.inf
        for pi in cands:
            if not paw.feasible(pi, tree):                   # 规划-阻抗协同过滤
                continue
            obj = self._robust_cvar(pi, tree, b_t)
            if obj < best_obj:
                best, best_obj = pi, obj
        return best if best is not None else options.safe_fallback(), tree

    def _robust_cvar(self, pi, tree, b_t):
        losses = [self._rollout(pi, phi, b_t) for phi in tree]   # 每场景累计损失
        losses.sort(reverse=True)
        k = max(1, int(self.eps * len(losses)))                  # 最坏 eps 尾部
        return float(np.mean(losses[:k])) + self.lam_c * cost(pi)

    def _rollout(self, pi, phi, b_t):
        return sum(ell_task(o, phi) + self.lam_s * ell_safe(o, phi) for o in pi.options)
```

### IP-194 OSL（鲁棒选项库与顺序组合）

```python
@dataclass
class Option:
    skill: str
    pre: Callable[[np.ndarray], bool]     # 在球内最坏 phi 上求值

def compose_plan(options, H):
    """只返回满足鲁棒顺序组合的候选计划（定理 3 前提）。"""
    plans = []
    for seq in itertools.product(options, repeat=H):
        ok = all(implies(seq[i].post, seq[i + 1].pre) for i in range(H - 1))
        if ok and all(o.invariant is not None for o in seq):

    return plans
```

### IP-195 PVF（视觉-力觉融合）

```python
class PerceptionJacobianFusion:
    def __init__(self, W_phi=1.0, W_s=None):
        self.W_phi, self.W_s = W_phi, W_s      # 量纲归一化权重

    def update(self, tau_obs, tau_pred, s_obs, s_pred, J_phi, J_s):
        r = np.hstack([tau_obs - tau_pred, s_obs - s_pred])
        J = np.vstack([J_phi, self.W_s * J_s])
        W = np.diag(np.hstack([self.W_phi * np.ones(len(tau_obs)),
                               np.ones(len(s_obs))]))
        A = J.T @ W @ J
        dphi = np.linalg.solve(A, J.T @ W @ r)          # 加权 Gauss-Newton
        Sigma = np.linalg.inv(A)                        # 融合协方差
        rho_obs = np.sqrt(np.linalg.eigvalsh(A).min())  # sigma_min(W^{1/2} J_fuse)
        return dphi, Sigma, rho_obs
```

### IP-196 SgVS（语义门控视觉伺服）

```python
class SemanticGatedVisualServo:
    def select(self, plan_seg, semantic_out):
        o = plan_seg.current_option
        w_s = o.servo.feature_mask(semantic_out)        # 语义选任务相关特征
        s_star = o.servo.target(semantic_out)           # 语义给目标特征值
        return FeatureSpec(w_s, s_star, o.servo.L_s, o.servo.lambda_gain)

    def step(self, s_now, spec, K_template):
        e = spec.w_s * (s_now - spec.s_star)
        L = spec.L_s(s_now)                             # 交互矩阵
        v_cmd = -spec.lambda_gain * (np.linalg.pinv(L) @ e)
        K = K_template + delta_K_from_error(e)          # 零空间阻抗调制
        return v_cmd, K
```

### IP-198 PAW（规划感知鲁棒编译）

```python
def paw_compile(pi, tree, olp, eeis, rsc_r, n_worst=16):
    K_sched, rho_plan = [], np.inf
    for o in pi.options:
        worst = worst_phis(tree, o, n=n_worst)           # 场景树中最坏 phi
        margins = []
        for phi in worst:
            K_k = wcv_compile(olp, o.x_ref, eeis, phi, rsc_r)[0]
            if (not in_box(K_k)) or (not o.invariant(K_k)) or safety_margin(K_k, phi) < 0:
                return None, -np.inf                     # 计划被否决
            margins.append(safety_margin(K_k, phi))
        K_sched.append(intersect_shrink([K_k]))          # 段内收缩
        rho_plan = min(rho_plan, min(margins))
    return K_sched, rho_plan
```

```python
class VisualServoSafetyMonitor:
    def check(self, e_s, Sigma_fuse, r_tau, tau_disagree=3.0, tau_force=0.1,
              tau_hard=6.0):
        d = float(e_s @ np.linalg.solve(Sigma_fuse, e_s))    # Mahalanobis^2

        return 'ok'
```

## 4. 推导

**引理 5（融合条件数不减 / 补秩）** 设 W=blkdiag(W_φ,W_s)≻0。则
J_fuseᵀWJ_fuse = J_φᵀW_φJ_φ + J_sᵀW_sJ_s。
对任意 PSD 矩阵 A,B 有 A+B⪰A 且 A+B⪰B，故
ρ_obs² = λ_min(J_fuseᵀWJ_fuse) ≥ max(λ_min(J_φᵀW_φJ_φ), λ_min(J_sᵀW_sJ_s)) = max(ρ_φ²,ρ_s²)。
同理由 Loewner 序 Σ_fuse=(J_fuseᵀWJ_fuse)⁻¹ ⪯ (J_φᵀW_φJ_φ)⁻¹=Σ_φ：融合协方差不超过力觉单通道。**推论**：若 σ_min(J_φ)→0（力通道病态），只要 ρ_s>0 则 ρ_obs>0，覆盖椭球保持有限；力觉单通道在 r_max 内无法覆盖。这正是对第 62 轮 A72 风险的机制性补丁（前提：安全相关参数在视觉可观子空间内，见 A77）。∎

**引理 6（同置信度下更紧）** 对固定置信水平 1−α_cal，按高斯近似覆盖椭球半轴 ∝ √λ_i(Σ)。由 Σ_fuse⪯Σ_φ 得各半轴不增，故融合 RSC 在**同样覆盖概率**下给出更小（更不保守）的 r_t；等价地，在相同 r 下覆盖概率更高。∎

**定理 2（场景规划 ε-可行性）** 设候选计划集 Π 有限，每计划从银行加权分布独立采样 N 个场景；仅当 N 个样本全部零违约时接受该计划。对固定 π，令 p_π 为真违约率。则 P(接受 π 且 p_π>ε) ≤ (1−ε)^N ≤ e^{−εN}。对 |Π| 个候选做联合界：P(任一被接受计划违约率>ε) ≤ |Π|e^{−εN}。取 N ≥ (1/ε)(ln|Π|+ln(1/β)) 即得 ≤β。**注意**：p_π 是相对**银行加权分布**的违约率；只有当银行分布是真实环境的 ε-近似（A78）时，结论才传递到真实环境。∎

**定理 3（鲁棒选项顺序组合安全）** 归纳。基础：b_0 的支撑在安全集内。归纳步：若 o_i 在球 B 上保持鲁棒不变集 I_i（即 φ∈B 时执行 o_i 后状态仍在 I_i⊆𝒮_safe），且 post_{o_i}(B)⊆pre_{o_{i+1}}(B)，则 o_{i+1} 在 B 上可执行且保持 I_{i+1}。于是对全部 H 段、全部 φ∈B，状态始终在 𝒮_safe。结合 BSR 的信念管不碰 𝒰_unsafe，得计划级安全。∎

**定理 4（中频伺服漂移有界）** L_s 行满秩时 L_sL_s⁺=I，特征误差动态 ė_s = −λ_gain e_s + d(t)，‖d‖≤L_d。解 ‖e_s(t)‖ ≤ e_0e^{−λ_gain t} + (L_d/λ_gain)(1−e^{−λ_gain t})。语义停摆 T_b 内 ‖e_s‖ ≤ e_0e^{−λ_gain T_b} + L_d/λ_gain，有界；超 τ_hard 由 VSA 触发 hold/brake。∎

**定理 5（遗憾分解）** 总遗憾 = OLP 参数遗憾 + 选项选择遗憾 + 场景近似遗憾：
R_T ≤ D·G̃√T + √(2T ln|Π|) + T·O(√(d/N))。
最后一项来自样本平均近似（SAA）的 O(√(d/N)) 逐次 gap。取 N=Θ(T) 则三项均 O(√T)，总遗憾 O(√T)。∎

## 5. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SBP 规划 | O(\|Π\|·N·H) | O(N·d_φ) | 定理 2：ε-可行性（对银行分布） |
| OSL 组合 | O(\|O\|^H) 预剪枝 | O(\|Π\|) | 定理 3：组合安全 |
| PVF 更新 | O(d_φ³)（融合求逆） | O(d_φ²) | 引理 5：ρ_obs≥max(ρ_φ,ρ_s) |
| SgVS | O(d_s·d_v + d_s²) | O(d_s·d_v) | 定理 4：误差指数收敛 |
| MRS | O(d_s²) @100–1000Hz | O(1) | 零学习写；漂移有界 |
| PAW 编译 | O(H·n_worst·C_eeis) | O(H·n_worst) | ρ_plan≥0 才放行 |
| BSR | O(H·N·d_φ) | O(N·d_φ) | 信念管不碰不安全集 |
| TCA | O(1) CAS | O(d_us+常数) | plan_id 单调、无撕裂读 |
| VSA | O(d_s²) | O(d_s²) | 检出率/误报可标定 |
| VISTA 实时路径 | ≤1ms（中频+力矩） | — | 零学习写（A82） |

**正确性定理（VISTA-Complete）** 假设 A61–A76（第 61/62 轮）及：
- **(A77) 融合可观测性**：安全相关参数子空间 Φ_safe 上 σ_min(W^{1/2}J_fuse)≥ρ_min；视觉不可观的隐藏子空间由先验球 B(φ̂_hid,r_hid) 覆盖。
- **(A78) 银行有效性**：银行加权分布与真实环境的 Wasserstein 距离 ≤ W_max（或为 ε-近似）；否则定理 2 仅对银行分布成立。
- **(A79) 选项组合**：post_{o_i}(B)⊆pre_{o_{i+1}}(B)，且每个 o_i 保持鲁棒不变集 I_o⊆𝒮_safe。
- **(A80) 伺服稳定**：L_s 行满秩，λ_gain∈(0,λ_max)，时间尺度分离 语义≪中频≪力矩。
- **(A81) 场景采样**：T_N 独立同分布于银行加权分布，N 满足定理 2。
- **(A82) 三尺度不变式**：中频与力矩环零学习写，锚点/计划原子读写。

则：
1. **计划 ε-可行性**：被接受计划在银行分布上违约率 ≤ε（概率 ≥1−β）；A78 成立时传递到真实环境。
2. **偏差双通道免疫**：ρ_obs≥ρ_min 时融合覆盖 P[φ*∈B]≥1−α_cal；力通道退化不再致命（引理 5/6）。
3. **计划级安全**：满足 A79 的整条计划对 ∀φ∈B 保持在 𝒮_safe，且信念管不碰 𝒰_unsafe。
4. **计划保持**：语义停摆期间中频伺服使特征误差有界（定理 4），不越 τ_hard。
5. **感知分歧可测**：力残差被吸收时视觉通道以 Mahalanobis 统计检出（VSA）。
6. **总遗憾亚线性**：R_T=O(√T)（定理 5）。
7. **实时性不变**：中频/力矩环零学习写，≤1ms 契约保持。

## 7. 已知风险

**一句话**：VISTA 并未消灭 A72，而是把它搬到了更高层——PVF 只对**视觉可观**的参数子空间补秩（摩擦、内部柔顺等隐藏参数仍单靠力通道），而定理 2/BSR 的保证只对**银行加权分布**成立；若安全关键参数视觉不可观且银行分布漂移，融合 Jacobian 的秩与场景规划的 ε-可行性会同时失效，本轮安全论证仍可能退化为纸面保证。

**次级风险与缓解**：
1. **视觉标定误差**：L_s 依赖相机内参/手眼标定，标定漂移使伺服律失稳 → 在线标定残差纳入 ρ_obs，ρ_obs<ρ_min 时退回纯力觉 + 保守球。
2. **选项库组合爆炸**：|O|^H 不可行 → 用类型化前置条件剪枝 + 只在接触邻域展开；规划预算由 OCB 的 cost 通道约束。
3. **场景树与真实分布漂移**：银行 stale → 监控 T_N 与在线残差的 MMD，超阈值时降低规划视界并回退反应式 ROSE。
4. **双环耦合振荡**：中频视觉伺服与 1kHz 阻抗环可能耦合 → 时间尺度分离（λ_gain < 0.1·ω_torque）+ 阻抗调制限幅。
5. **VSA 误报**：视觉遮挡/反光造成假分歧 → 用 Σ_fuse 的时变膨胀 + 连续 k 帧确认，误报率以 E218 标定。
