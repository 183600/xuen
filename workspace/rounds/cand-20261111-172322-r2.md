# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 2 轮；本轮灵感：「柔顺控制」×「视觉语言动作模型」）

> 第 54 轮把技能组合推到「动作空间剖面 + 云边协同」，但仍停在**运动学层面**：证书只约束“动作是否覆盖/可对齐”，不约束“接触时施加了多少力、注入了多少能量”。本轮引入 **柔顺控制（阻抗/导纳、被动性）** 与 **视觉语言动作模型（VLA）**，核心矛盾：H22：VLA 的语义泛化不在力/阻抗维度上接地，同一动作 token 在不同阻抗下对应截然不同的接触动力学，第 54 轮的动作证书在接触丰富任务中系统性失效；H23：柔顺控制的被动性/安全性是逐时刻的物理性质，而 VLA 以离散、可能大幅跃变的方式给设定点，二者朴素拼接会因设定点跃变注入能量而击穿被动性，出现“安全控制器 + 不安全命令”的假安全。

## 0. 直觉与动机

**灵感 1（柔顺空间是动作空间缺失的第三维）**
直觉：第 54 轮的技能占用是动作剖面 `α_S : A → [0,1]`。但真实接触任务里，同一个末端位姿可以“硬碰”也可以“轻触”，差别全在阻抗 `z = (M,D,K)`（惯量、阻尼、刚度）。因此技能的真实占用应是 `Occ(S) = A_S × Z_S`：动作空间 × 柔顺空间。柔顺剖面 `κ_S : Z → [0,1]` 标记哪些阻抗在力限内安全。组合技能时，除了 `A_i ∩ A_j ≠ ∅`，还必须 `Z_i ∩ Z_j ≠ ∅` 且阻抗切换连续，否则“动作兼容”只是**假兼容**。

**灵感 2（VLA 动作必须经过柔顺投影才算可执行）**
直觉：VLA 输出动作 token/路点，本质是“想要往哪动”，并不保证“用多大力、注入多少能量”。定义投影 `Π_Z : A_VLA → Z`，把一个语义动作落到物理可行的阻抗流形上（力限、速度限、关节限）。VLA 负责“想做什么”，柔顺投影负责“以什么物理姿态做”。**VLA proposes, compliance disposes**：语义层只提案，物理层有否决权。

**灵感 3（VLA 不确定度 → 刚度，是这轮最漂亮的耦合）**
直觉：VLA 对动作有分布（熵/方差），但从不表达“我不确定，所以该软一点”。我们让不确定度直接调制阻抗：`K(σ) = K_min + (K_max - K_min)·e^{-tr(Σ_a)/τ}`，越不确定越柔顺、越确定越硬。这既降低不确定时的接触力风险，又给“探索”一个物理含义：**不确定 = 主动让位**。这把语义置信度变成了可执行的物理参数，而不是一句“模型不确定”的空话。

**灵感 4（语言不只指定做什么，还指定“多柔”）**
直觉：“轻轻放下”“用力压紧”“小心滑入”不是同一个动作的不同措辞，而是不同阻抗契约。定义语言-阻抗接地 `g_LI : L → 𝒟_Z`。VLA 应当有“阻抗头”，或至少语言先验给出阻抗描述子。组合指令取阻抗约束交。这样**语义柔顺**首次被显式化：同一个轨迹，语言不同，刚度/阻尼/力限就不同。

**灵感 5（接触即验证：用接触证据给 VLA 做物理接地证书）**
直觉：VLA 可能“看起来对、力上错”。被动性与力/力矩传感给出硬证据。把每次接触事件 `(t_i, f_meas, slip)` 作为证据：若能量有界（被动性护栏）、接触力不超限、且接触签名与语言/任务意图一致（`Cons` 谓词），则该段 VLA 执行获得**物理接地通过**证书。这把第 53–54 轮的 Explain 反向信道升级为**力域反例**：力-语义不一致就是最硬的解释。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（柔顺空间与柔顺剖面）**
柔顺空间 `Z ⊆ R_+^3`，元素 `z = (M,D,K)`（惯量、阻尼、刚度）。技能 S 的柔顺剖面 `κ_S : Z → [0,1]`，`κ_S(z)=1` 表示阻抗 z 在任务安全域内可用。可用柔顺集 `Z_S = {z | κ_S(z) ≥ θ_z}`。承接定义 115，技能占用升级为 `Occ(S) = A_S × Z_S`。组合必要条件：
```
A_i ∩ A_j ≠ ∅ ∧ Z_i ∩ Z_j ≠ ∅ ∧ c_Z(S_i,S_j) ≤ τ_z
```
其中 `c_Z` 为阻抗切换成本（见定义 123 的连续化）。

**定义 122（VLA→柔顺投影）**
VLA 策略 `π_VLA : (I,l) → a_tok`（图像 I、语言 l → 动作 token）。物理可行流形 `𝔄_phys`。投影 `Π_Z : A_VLA → Z`，满足 `z = Π_Z(a_tok) ∈ Z_S`，且力、速度、关节均不越限。可执行三元组 `(x_d, z, ΔE_k)`，其中 `x_d` 为期望运动、`z` 为阻抗、`ΔE_k` 为该步注入能量。

**定义 123（能量有界更新 / 柔顺包络）**
第 k 次 VLA 更新，设定点跃变 `Δx_k = x_d(t_k) - x_d(t_{k-1})`，注入能量 `ΔE_k = ½ Δx_kᵀ K_k Δx_k`。柔顺包络约束：
```
ΔE_k ≤ E_b  ∧  D_k ⪰ D_min
```
由二次型上界推出**最大安全跃变** `||Δx_k|| ≤ sqrt(2 E_b / λ_max(K_k))`。满足包络的更新称**能量有界更新**。阻抗切换成本定义为 `c_Z(S_i,S_j) = ∫ ||dZ/dt|| dt`（切换过程需连续插值，禁止阻抗跳变）。

**定义 124（不确定度-刚度映射）**
`φ_UK : Σ_a → Z`，`tr(Σ_a) ↦ (K↓, D↑)`，满足 `K(0)=K_max`、`K(∞)=K_min`、`D ≥ D_min`，且 `K` 关于 `tr(Σ_a)` 单调不增、`D` 单调不减。三条单调性/边界是可验证契约，而非启发式。

**定义 125（语言-阻抗接地）**
`g_LI : L → 𝒟_Z`，阻抗描述子 `d_z = (K_scale, D_scale, f_max, contact_mode)`。例：`g_LI("gently place") = (K_scale↓, contact_mode=soft)`，`g_LI("firmly press") = (K_scale↑, f_max↑)`。组合指令 `l_1 ⊕ l_2` 满足 `g_LI(l_1 ⊕ l_2) = g_LI(l_1) ⊓ g_LI(l_2)`（阻抗约束交）。

**定义 126（接触-被动性联合证书）**
接触-柔顺证书 `C_ct = (Z_core, E_b, f_max, contact_evidence, passive_flag)`：
- `Z_core ⊆ Z_S` 为核心阻抗集；
- `E_b` 为单步能量预算；
- `f_max` 为接触力硬上界；
- `contact_evidence = {(t_i, f_meas^i, slip_i)}` 为接触事件证据；
- `passive_flag = 1` 当且仅当所有更新满足定义 123 且 `D ⪰ D_min`。

**物理接地通过**定义为：
```
passive_flag=1 ∧ max_i ||f_meas^i|| ≤ f_max ∧ Cons(l, contact_evidence)=1
```
`Cons` 为语义-力签名一致谓词，可取语言期望力剖面与实测力剖面的 DTW 距离 `≤ τ_cons`。任一不满足即拒绝部署。

## 2. 关键算法 伪代码

### IP-121 CSP（Compliance Space Profiling）

```python
def compliance_profile(skill, Z_grid, force_sampler):
    kappa = {}
    for z in Z_grid:
        f_peak, slip = force_sampler.run(skill, z)
        safe = (f_peak <= skill.f_max) and (not slip)
        kappa[z] = 1.0 if safe else 0.0
    return kappa

def admissible_impedance(kappa, theta_z=0.8):
    return {z for z, v in kappa.items() if v >= theta_z}
```

### IP-122 VCP（VLA Compliance Projection）

```python
def project_vla_action(a_tok, skill, Z_S, env, E_b):
    x_d = env.kinematics(a_tok)              # 语义动作 -> 期望运动
    z_unc = uncertainty_to_impedance(a_tok.sigma, skill)
    z_proj = closest_point(Z_S, z_unc, metric=energy_metric)  # 投影到可行柔顺集
    if z_proj is None:
        return ('reject', explain_no_feasible_impedance(a_tok, Z_S))
    dx = x_d - env.last_setpoint
    x_d, z_proj, dE, ok = energy_bounded_update(
        x_d, env.last_setpoint, z_proj.K, E_b, z_proj.D, D_MIN)
    if not ok:
        return ('reject', 'energy_budget_exceeded', dE)
    return ('ok', x_d, z_proj, dE)
```

### IP-123 EBG（Energy-Bounded Setpoint Governor）

```python
def energy_bounded_update(x_new, x_old, K, E_b, D, D_min):
    dx = x_new - x_old
    dE = 0.5 * dx @ K @ dx
    if dE > E_b and dE > 0:
        scale = sqrt(2 * E_b / (dx @ K @ dx))   # 缩放到能量预算边界
        x_new = x_old + scale * dx
        dE = E_b
    lam = min_eig(D)
    if lam < D_min:
        D = D + (D_min - lam) * I               # 抬阻尼，保证严格被动
    return x_new, Impedance(M=None, D=D, K=K), dE, (dE <= E_b)
```

### IP-124 UAI（Uncertainty-Aware Impedance）

```python
def uncertainty_to_impedance(sigma, skill, k_min, k_max, d_min, tau):
    s = trace(sigma)                             # 动作分布不确定度
    K = k_min + (k_max - k_min) * exp(-s / tau)
    D = d_min + 2.0 * sqrt(K * skill.M)         # 临界阻尼近似
    return Impedance(M=skill.M, D=D, K=K)
```

### IP-125 LIG（Language-to-Impedance Grounding）

```python
def ground_impedance(lang, parser, base_z):
    desc = parser(lang)                          # -> (K_scale, D_scale, f_max, contact_mode)
    z = base_z.scale(K=desc.K_scale, D=desc.D_scale)
    z.f_max = min(base_z.f_max, desc.f_max)      # 约束取交，只能更保守
    z.contact_mode = desc.contact_mode
    return z
```

### IP-126 CPA（Contact-Passivity Attestation）

```python
def contact_passivity_cert(skill_seq, vla_plan, env, E_b, f_max, tau_cons):
    Z_core = intersection([s.Z_S for s in skill_seq])
    if not Z_core:
        return ('reject', 'no_common_compliance')
    evidence, passive = [], True
    for step in vla_plan:
        r = project_vla_action(step, step.skill, Z_core, env, E_b)
        if r[0] != 'ok':
            return ('reject', r[1])
        _, x_d, z, dE = r
        if dE > E_b:
            passive = False
        f_meas, slip = env.execute_and_measure(x_d, z)
        evidence.append((step.t, f_meas, slip))
        if norm(f_meas) > f_max or slip:
            return ('reject', 'contact_violation', evidence)
    if not passive:
        return ('reject', 'passivity_violation', evidence)
    if not semantic_physical_consistent(vla_plan.intent, evidence, tau_cons):
        return ('reject', 'semantic_physical_gap', evidence)
    return ('ok', ComplianceCert(Z_core, E_b, f_max, evidence, passive=True))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| CSP | O(\|Z\|·T_force) | O(\|Z\|) | 柔顺剖面采样覆盖、力采样无偏 |
| VCP | O(\|Z\|·d + log\|Z\|) | O(\|Z\|) | `Π_Z` 保序、投影 idempotent |
| EBG | O(d³)（特征值） | O(d²) | 能量上界严格、`D_min` 硬生效 |
| UAI | O(d²) | O(d²) | `Σ_a` 经 conformal 校准 |
| LIG | O(\|L\|) | O(1) | 约束交 sound、保守性单调 |
| CPA | O(\|P\|·(\|Z\|+T_force)) | O(\|P\|) | 被动性闭合、力限硬生效 |

**正确性定理（Passivity-Shielded VLA Soundness）**
假设承接第 54 轮 (A26)–(A28)；新增 **(A29)** VLA 动作分布 `Σ_a` 经 conformal 校准（覆盖率 ≥ 1-α）；**(A30)** 力测量延迟 `≤ τ_f` 且 `τ_f ≤ τ_max`，阻抗模型 Lipschitz；**(A31)** `D_min > 0`、`E_b < ∞`，包络 governor 与力限器硬生效。

则对任意 VLA 计划，若 `C_ct` 有效，闭环满足 supply-rate 被动性：
```
∫_0^T (f·v) dt ≥ -V(0) - Σ_k E_b
```
且接触力 `||f(t)|| ≤ f_max`，从而
```
P(safe contact) ≥ 1 - P(Σ_a miscal) - P(Cons=0) - P(τ_f > τ_max)
```
关键：**VLA 只提案，被动性护栏与力限器拥有否决权**；`Σ_a` 一旦失准，`φ_UK` 会在最该让位时给出高刚度，这是全链条唯一无法由物理层兜底的假设。

## 6. 本轮最大风险

**一句话**：把 VLA 语义与柔顺控制耦合起来，真正赌的是「VLA 的不确定度是校准的、投影不破坏语义、离散更新不击穿被动性」这三点同时成立——一旦 `Σ_a` 失准，`φ_UK` 会恰好在最该让位时给出高刚度，而被动性护栏只保证“不炸”，却会制造“力学安全但语义错误”的假安全，故必须以 **conformal 校准 + 硬力限 + 语义-物理一致性检查** 三重护栏，绝不把“被动”等同于“正确”。

### IP-123 EBG

```python
def energy_bounded_update(x_new, x_old, K, E_b, D, D_min):
    dx = x_new - x_old
    dE = 0.5 * dx @ K @ dx
    if dE > E_b and dE > 0:
        scale = sqrt(2 * E_b / (dx @ K @ dx))
        x_new = x_old + scale * dx
        dE = E_b
    lam = min_eig(D)
    if lam < D_min:
        D = D + (D_min - lam) * I
    return x_new, Impedance(M=None, D=D, K=K), dE, (dE <= E_b)
```
