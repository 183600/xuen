# 第 1 轮（UniBot 线 · 本轮灵感：「分层规划」×「人机协作」）

> **承接声明**：本行接续既有 UniBot 基线（上一版以「抓取 × 技能学习 × 地形适应」组织，已确立四条硬结论：①计分近共线 ⇒ 只优化终态成功；②任务间专长准正交 ⇒ 通用=技能向量；③断点在最后对齐/插入/释放；④"做得快"无红利）。本轮**不推倒**，而是用「分层规划」重写其运行时结构、用「人机协作」重写其监督来源。编号切换：本轮启用定义 H1–H12、引理 HL1–HL7、实验 E701–E716；上一版 U1–U12 / L1–L7 / IP-01–IP-08 / E601–E618 作为**已封存基线**按需引用。榜单数字仍属 teaser/占位表（检索 2026-11-17），仅作结构参考。

## 0. 本轮一句话

上一版是"三层栈"的**隐喻**；本轮把它变成**可计算的分层规划（options / SMDP）**，并把"人"从被忽略的开发变量变成**唯一抗漂移的稀疏监督源**：人只在子目标边界与恢复事件上介入（训练/开发期），评测期零人工；赛场上的人则被当作**扰动源**而非求助对象。

## 1. 直觉（两灵感的第一性原理）

**灵感 1「分层规划」：上一版的六因子链，本来就是一棵计划树。**

上一版把成功拆成 `reach→grasp→transport→align→insert→release` 的乘积——这已经是分层规划的"计划骨架"，但实现上仍是**一个扁平 VLA 端到端吐 action chunk**，六因子只用于事后诊断。直觉上，扁平策略的问题是**误差随 horizon 单调累积**：一个 45 s、30 fps 的 episode ≈1350 步，任何 0.1%/步的偏差都会在末端放大；而榜单恰恰显示"能推进大半程、死在最后一环"。分层规划给的不是"更聪明的网络"，而是**三个结构性红利**：

- **信用分配**：失败可定位到某个 option，而非整条轨迹一个标量；
- **可组合恢复**：失败时只重跑某个 option（重抓/重对齐），不必整条重来；
- **误差截断**：每个 option 有独立终止/复位点，误差在边界被"截断"，不跨段累乘。

第一性原理：**分层的价值 = 把一条长 horizon 的乘性误差链，切成若干段可独立重置的短链。**

**灵感 2「人机协作」：上一版最大风险是"抓握真值只能靠伪标签"，而人是最便宜、最抗漂移的真值源。**

上一版自陈的最大风险是：抓握隐变量的唯一真值来自"抬起后物体随动"这类间接代理标签，在未见物品上分布漂移——**最需要它的泛化场景恰是它最不可信处**。人机协作恰好补上这个洞，但必须把"人"放在正确的位置。分层规划正好回答"人该在哪里介入"：**不在每个 timestep（太贵且打断策略），而在子目标边界与不可逆决策点（稀疏、信息密度最高）**。于是人机协作拆成三件**合规**的事：

- **训练期 HIL（human-in-the-loop）**：人在 option 边界给纠正/偏好，形成恢复与终止标签；
- **开发期 HOTL（human-on-the-loop）**：人看看板、按一键回滚，不逐步介入；
- **评测期 human-aware**：把第 5 类泛化"人为干扰"当作**非平稳扰动模式**显式检测，必要时 yield/abstain，而不是假装没人。

第一性原理：**人的监督带宽稀缺，应投在"决策不可逆点"；这些点恰好是分层结构的边界。** ⇒ 分层规划与人机协作在此任务是同一枚硬币的两面：**分层给出"该问人的地方"，人给出"分层最不可靠处的标签"。**

**合成**：分层提供骨架、终止条件与恢复接口；人机协作提供稀疏但抗漂移的锚点与安全闸门。两者共同把上一版的"伪标签赌注"换成"**少量人工锚点 + 结构化推断 + 可拒绝恢复**"。

## 2. 严谨定义（预览；完整符号与公式见产物区 §3）

- **计划骨架** `p=(g_1,…,g_K)`：把任务 `ℓ` 分解为带前置/后置谓词的子目标序列。
- **Option** `ω=(I,π,β,c)`：初始集 `I`、内部策略 `π`、三态终止监视器 `β∈{success,fail,continue}`、代价 `c`。
- **分层策略** `π_H = π_L3 ∘ π_L2 ∘ π_L1`：计划器选 `g`，option 执行器选 `ω`，VLA 在 option 内出 chunk。
- **人工查询策略** `q(o,β; B)`：在预算 `B` 内，只在 `β` 低置信且代价高时向人查询；查询只发生在离线/开发期。
- **干扰模式** `m_t∈{absent,distractor,blocker}`：与上下文 `c_t` 分开建模；`yield` 是由 `P(m_t|o)` 触发的**可拒绝**动作。
- **可拒绝恢复**：任何 retry/replan 必须过代价闸门 `E[c_recover] ≤ λ·E[c_fail]`，否则放弃并安全退出。

## 3. 研究问题（可证伪）

- **Q1（分层是否对症）**：把六因子链变成运行时 options，能否在最后一环任务上优于扁平策略？"误差截断"能否按 option 边界被**直接测量**（失败传播矩阵）？
- **Q2（人该在哪里介入）**：在固定人工预算 `B` 下，把标注投在"option 边界 + 主动查询"是否比均匀标注/逐步 DAgger 更省、更抗漂移？给出**预算-性能曲线**与"最不可靠点"排序。
- **Q3（监督的合规边界）**：训练期 HIL / 开发期 HOTL 是否被赛制允许？如何**可审计地证明**评测期零人工（AutonomyProof）？
- **Q4（人机共存）**：第 5 类泛化"人为干扰"下，显式 human-aware（检测→yield/abstain→恢复）是否比"忽略人"更安全？abstain 的计分代价是多少、何时值得？
- **Q5（分层与复用）**：能否用语言指令 + 少量人工计划骨架，构建跨任务复用的 option 库，使新任务只需高层重排而非低层重训？

## 4. 设计原则（在 P1–P6 上增补）

- **P7 分层最小充分性**：只在"能截断误差 / 能复用 / 能被监视"处加层；每层必须有**可观测终止条件**，否则不许存在。
- **P8 人在边界**：人只标注/纠正 option 边界与不可逆决策点；评测期零人工。
- **P9 监督可计量**：一切人工投入记为预算（分钟/标注数），报告"每单位人工的分数增益"，否则视为不可复现的黑箱调参。
- **P10 干扰 ≠ 协作者**：赛场上的"人"是扰动源，不是可求助对象；协作只发生在训练/开发阶段。
- **P11 恢复可拒绝**：任何 replan/retry 都要有代价估计与上限；沿用上版"≤3 次"的精神，但改为**按期望收益而非固定次数**触发。

## 5. 结构草图（运行时）

```
语言 ℓ ──► [L3 计划器] ──► p=[g1..gK]（检索/模板/小 LLM，每 episode 至多调 K+replan 次）
                │
                ▼
     [L2 option 执行器] ω_i=(I,π,β,c)
        │            ▲
        ▼            │ β=fail
  [L1 VLA chunk 执行]│
        │            ▼
        └──► [M 三态监视器] ──► [恢复算子 ρ] ──► 重抓/重对齐/换原语/放弃
                             │
                             └─(低置信/高代价)─► [H 人机层]
                                                  训练期: HIL 查询（离线）
                                                  开发期: HOTL 看板（非逐步）
                                                  评测期: m 检测 → yield
```

## 6. 与上一版的三处升级

1. **结构**：IP-01 的 skill token → **运行时 option**（含终止条件与代价），不再只是被动条件化输入。
2. **监督**：IP-02 的抓握伪标签 → **人工锚点 + 主动查询**，把上版最大风险显式转为可计量预算。
3. **鲁棒**：IP-04 的上下文适配 → **把"环境偏移 c"与"人的干扰 m"解耦**；对 m 用检测 + 屈服，而不是混进 c 做无差别调参。

**保留**：单一计分货币、单一 checkpoint/API、可审计工程层、保守介入（只在"确定失败"时介入）、代理评测相关性 `<0.3` 即砍微调的预注册。

## 7. 本轮最大风险

**本轮最大风险：分层把"边界"从误差截断点变成新的失败源——一旦子目标监视器在 OOD 上系统性误判，系统会在错误 option 上反复重试形成死循环，而人工锚点只覆盖训练分布、恰在最需要它的未见物品上缺席。**

## 0. 本轮结论摘要

**一句话路线**：把上一版的"三层栈"编译成 **分层计划器（L3）→ option 执行器（L2）→ VLA 执行（L1）→ 三态监视器（M）**，用 **人工锚点主动查询**只修最不可靠的边界，再用 **干扰检测 + 可拒绝恢复**保证人机共存安全；对外仍是单 checkpoint、单 API、评测期零人工。

**承接证据（复用上版，非新数据）**：

| 证据 | 数值 | 本轮用法 |
|---|---|---|
| step ≈ 1.337·succ + 0.09（R²=0.9955） | 两指标近共线 | option 代价 `c` 以"距终态成功的期望损失"计价，不奖励中途步数 |
| 跨任务 Kendall τ 均值 0.064 | 通用=技能向量 | option 库可跨任务复用（IP-16），新任务主要重排高层 |
| 最难任务在插入/旋转/细粒度 | 断点在最后一环 | 恢复 option 优先覆盖 align / insert / release（IP-14） |
| 任务内 corr(dur,succ) ≈ −0.011 | 快无红利 | 恢复/重试不设"提速"目标，只设"救回"目标 |

**合规红线（延续 P5）**：单一 checkpoint、单一 API；评测期无人工、无外呼；"人"只在离线/开发期；不硬编码任务分支；不利用未声明执行语义。

## 2. 创新点详述

### IP-11 · HALO-Plan 分层计划器（P0）

- **动机**：上一版已证明瓶颈在"最后一环"，但扁平 VLA 无法把"最后一环"作为独立可重试单元；六因子链只当诊断指标用，浪费了它的结构信息。
- **与现有方案的差异**：常见做法是"语言 → 端到端动作"（SayCan / Inner Monologue / 直接 VLA）。HALO-Plan 输出的是**带类型与谓词的子目标序列**，不是自由文本，也不是单步动作；计划本身可被谓词检查器验证，失败可回退到通用骨架。
- **技术可行性**：高。32 个官方任务名与数据集天然提供任务原型；相位标签可用上版 VLM + 腕部几何规则伪标，抽检 5%。
- **落地步骤**：①建子目标词表与谓词库（`holding(x)`、`at(x,l)`、`aligned(x,slot)`、`clear(x)`…）；②用语言 embedding 检索 top-k 任务原型 → 模板计划；③OOD 时用小 LLM 只做"重排/补槽"，不做自由生成；④谓词检查器验证；⑤失败回退到通用六因子骨架。
- **风险**：计划幻觉/槽位错配 → 谓词检查 + 模板优先 + 单次重排上限；LLM 延迟 → 每 episode 至多调用 `K + #replan` 次并缓存。

### IP-12 · Option 化技能执行器 + 三态监视器（P0）

- **动机**：分层若没有**可靠的终止条件**，就退化成"多了一层随机切换"，比扁平更糟（见 HL6）。监视器是分层正确性的前置条件。
- **与现有方案的差异**：上版 GraspVerify 只判"抓住没有"；本轮把同一套三信号（腕部几何 / EE 随动 / 夹爪标量）推广为**任意子目标的三态判定** `success / fail / continue`，并做概率校准与滞回。
- **技术可行性**：高。信号全部在官方观测里；失败样本可由"随动一致性 + 后续阶段是否推进"自动挖掘，再用人工锚点修最不可靠区。
- **落地步骤**：①定义每个 option 的成功/失败判据；②训练三态分类头（小 CNN/MLP）；③温度缩放校准 + 可靠性图；④k 连票 + 最小驻留时间的滞回，防抖；⑤保守偏置：只在"高置信 fail"时触发恢复（延续上版高精度低召回）。
- **风险**：OOD 校准崩坏（本轮最大风险）→ 见 §8 预注册与 §9 剪枝；滞回参数过强 → 误吞真实失败，需扫参。

### IP-13 · HumanAnchor 人工锚点主动查询（P0）

- **动机**：上版最大风险是伪标签在未见物品上漂移。人是最抗漂移的真值源，但带宽贵，必须投在"决策不可逆点"。
- **与现有方案的差异**：常见 HIL 是"逐步 DAgger / 全程遥操"（成本 `O(T)`）；本轮做**事件级 HIL**：只在 option 边界、监视器低置信、且误判代价高的地方查询（成本 `O(K+U)`，`K` 为子目标数，`U` 为不确定边界数）。
- **技术可行性**：高。查询界面只需"关键帧 + 2 s 片段 + 候选标签"；恢复可由人选择原语或给一段短的纠正片段（离线回放编辑，非真机遥操）。
- **落地步骤**：①定义查询价值 `V = H(β) · E[c_fail]`；②按任务/物体分层抽样，确保覆盖长尾；③双标注 + 一致性检查；④冻结进数据集/适配器，评测期只读；⑤记录人工分钟数到 BudgetLedger。
- **风险**：标注者偏差/漂移 → 留出人工复核 + 跨标注者一致性；查询过密 → 预算硬上限与价值阈值。

### IP-14 · RecoveryOption 恢复 option 库（P0）

- **动机**：分层的红利只有在"失败可被单独重试"时兑现；否则只是把失败诊断得更细。
- **与现有方案的差异**：上版 IP-02 有非抓取原语，但没有"代价感知的恢复调度"。本轮把恢复做成 option，与正常 option 同构，可被计划器/监视器统一调度。
- **落地步骤**：①实现四类恢复：`regrasp`（偏移/旋转重抓）、`realign`（视觉伺服微调）、`switch`（推/扫/倾倒/钩）、`abort`（安全退出）；②为每类估代价与成功率；③代价闸门：`E[c_rec] ≤ λ·E[c_fail]` 才执行；④恢复次数按期望收益而非固定 3 次。
- **风险**：恢复扰动场景 → 限单物体或设禁区；`abort` 被滥用 → 只在高碰撞风险或明确不可恢复时触发。

### IP-15 · HumanAware 干扰检测 + yield/abstain（P1）

- **动机**：第 5 类泛化是"人为干扰"；上版把人类干扰混进上下文 `c` 做无差别调制，既不安全也不可解释。
- **与现有方案的差异**：把 `m_t`（absent/distractor/blocker）从 `c_t` 中解耦；用突变检测（场景突变、非目标运动、前置条件反复失败）估计 `m`；高 `P(blocker)` 时执行**可拒绝的 yield**（暂停/后退/等待），并记录原因。
- **落地步骤**：①构造三类脚本化干扰（伸手遮挡、移动目标、故意挡路）；②训练/标定检测器；③按期望效用设 yield 阈值（见 HL4）；④多机并发时把"整份提交可信度"计入 `L_c`，使阈值更低（更早屈服）。
- **风险**：误屈服浪费 episode → 阈值校准 + 最长 yield 时间；无人体关键点输入 → 仅用视觉突变代理，需真机验证。

### IP-16 · SkillRetrieval 跨任务 option 复用（P1）

- **动机**：上版证明任务专长准正交 ⇒ 技能可复用；分层让"复用"发生在 option 而非整策略层，参数效率更高。
- **落地步骤**：①option 以（物体 affordance、子目标类型、初始位姿）建索引；②检索最近 option 并用计划器组合；③新任务=新计划而非新网络；④检索失配 → 回退通用 option。
- **风险**：组合泛化未必如猜想（HL5 已标注为猜想）→ E708 直接证伪。

### IP-17 · BudgetLedger 人工预算账本（P1）

- **动机**：人机协作若不可计量，就无法判断"值不值得"。
- **落地步骤**：结构化记录（任务、边界类型、标注数、分钟、标注者、置信）；产出"每人工分钟 Δsuccess"曲线；报告盈亏平衡点。
- **风险**：度量本身耗人力 → 全自动日志 + 抽样复核。

### IP-18 · AutonomyProof 自主性合规自证（P0）

- **动机**：人机协作最容易被质疑的点是"评测时是否偷偷喊人"。
- **落地步骤**：①评测进程禁用出站网络（除官方通道）；②所有人工数据在提交前冻结进 checkpoint/数据集；③静态扫描 socket / subprocess / 环境变量；④签名运行日志 + 代码哈希；⑤在 `metadata` 中声明 `human_service=disabled`；⑥产出可导出的自证报告。
- **风险**：官方可能不要求该证明、或格式不接受 → 仍作为可信度加分项保留。

## 3. 符号与定义（H1–H12）

| 符号 | 含义 |
|---|---|
| `ℓ` | 语言指令 |
| `p=(g_1,…,g_K)` | 计划骨架（子目标序列） |
| `g=(pre,post,type)` | 子目标：前置谓词、后置谓词、类型 |
| `ω=(I,π,β,c)` | option：初始集、内部策略、终止监视器、代价 |
| `β∈{S,F,C}` | 三态监视器（success / fail / continue） |
| `π_H` | 分层策略 `π_L3 ∘ π_L2 ∘ π_L1` |
| `q` | 人工查询策略 |
| `B` | 人工预算（分钟或标注数） |
| `ρ` | 恢复算子 |
| `m_t` | 干扰模式 latent |
| `d_t` | 干扰检测输出 |
| `c_fail, c_rec` | 失败代价、恢复代价 |

**定义 H1（计划骨架）** `p = Plan(ℓ, o_0) = (g_1,…,g_K)`，满足 `post(g_i) ⊨ pre(g_{i+1})`；若谓词检查失败，回退到通用骨架 `p_gen`（六因子顺序）。
**定义 H2（Option）** `ω=(I,π,β,c)`：`I⊆O` 为初始集，`π(a|o,ω)` 为 option 内策略，`β(o,ω)∈{S,F,C}` 为三态终止，`c(o,ω)` 为期望剩余代价。
**定义 H3（校准监视器）** `β(o,ω)=argmax_y P_θ(y|o,ω)`，其中 `P_θ` 经温度缩放校准；仅当连续 `k` 帧同判且满足最小驻留时间才切换状态（滞回）。
**定义 H4（分层策略）** `π_H(a_{1:T}|o,ℓ) = E_{p∼Plan}[ ∏_{i} π_{L2}(ω_i|g_i) ∏_{t∈τ_i} π_{L1}(a_t|o_t,ω_i) ]`，`τ_i` 为 option `i` 的驻留区间。
**定义 H5（人工查询）** `q(g,β; B) = 1` 当且仅当 `H(β) > H_0`、`E[c_fail|g] > c_0`、且 `spent(q) + cost(q) ≤ B`；查询只发生在离线/开发流程，**不进入评测期 `get_action`**。
**定义 H6（人工锚点集）** `D_H = {(g_j, y_j, conf_j, minutes_j)}`，`y_j∈{S,F}` 或恢复原语标签；双标注一致性 `κ ≥ 0.7` 才入库。
**定义 H7（恢复与代价闸门）** `ρ(o,ω) = argmax_{r∈R} [P(succ|r)·U − c_r]`，仅当 `E[c_rec] ≤ λ·E[c_fail]` 且 `n_retry` 未超期望收益上限时执行；否则 `abort`。
**定义 H8（干扰模式 POMDP）** 状态含 `m_t∈{absent,distractor,blocker}`，观测为视觉突变与非目标运动；`P(m_t|o_{1:t})` 由贝叶斯滤波/分类器给出。
**定义 H9（yield 判据）** 当 `P(m=blocker|d)·L_c > (1−P(m=blocker|d))·L_y` 时执行 `yield`，其中 `L_c` 为继续执行的期望损失（含多机并发下的可信度外部性），`L_y` 为屈服/放弃的计分损失。
**定义 H10（误差截断与失败传播）** 失败传播矩阵 `M_{ij}=P(失败首次发生在 g_i 且被 g_j 的监视器捕获)`；分层的截断能力由 `M` 的对角占优程度度量。
**定义 H11（人工预算-性能曲线）** `S(B) = E[成功率 | 人工预算 B]`；报告 `dS/dB` 与盈亏平衡点 `B*`。
**定义 H12（自主性证明）** 谓词 `AutonomyProof = (egress_disabled) ∧ (human_data_frozen) ∧ (no_human_call_in_eval) ∧ (signed_log_verified)`；四项全真才允许提交。

```python
# ===== L3：计划器（每 episode 至多调用 K + #replan 次）=====
class HALOPlanner:
    def __init__(self, prototypes, pred_lib, small_llm=None):
        self.prototypes, self.pred = prototypes, pred_lib
        self.llm = small_llm

    def plan(self, obs, lang):
        cands = self.retrieve(lang)                 # 语言检索 top-k 任务原型
        p = self.llm_rerank(lang, cands) if self.llm else cands[0].skeleton
        if not self.validate(p, obs):               # 谓词前置/后置检查
            p = self.generic_skeleton(lang)         # 安全回退：六因子顺序
        return p

    def validate(self, p, obs):
        return all(self.pred.check(g.pre, obs) for g in p[:1]) and \
               all(self.pred.entails(g.post, nxt.pre) for g, nxt in zip(p, p[1:]))
```

```python
# ===== L2 + M：option 执行 + 三态监视 + 代价感知恢复 =====
class OptionExecutor:
    def __init__(self, model, monitor, recoveries, lam=1.2):
        self.model, self.mon, self.rec, self.lam = model, monitor, recoveries, lam

    def step(self, obs, g, state):
        omega = g.option
        y, conf = self.mon(obs, omega)              # H3: 三态 + 置信度（已校准）
        if y == CONTINUE:
            return self.model.act(obs, omega.embedding), state
        if y == SUCCESS:
            return None, state.advance()
        # y == FAIL：只有高置信 fail 才走到这里（保守偏置）
        r = self.rec.best(obs, omega)
        if r and self.rec.expected_cost(r) <= self.lam * self.rec.expected_fail_cost(omega):
            return r.policy(obs), state.retry()
        return self.rec.abort(obs), state.fail()
```

```python
# ===== H：人工锚点采集（离线/开发期；评测期绝不调用）=====
class HumanAnchorCollector:
    def __init__(self, ui, ledger, H0=0.6, c0=0.3, budget_min=240):
        self.ui, self.ledger, self.H0, self.c0, self.B = ui, ledger, H0, c0, budget_min

    def query(self, boundary):
        if self.entropy(boundary.beta) < self.H0:      return None
        if self.expected_fail_cost(boundary) < self.c0: return None
        if self.ledger.minutes + boundary.est_min > self.B: return None
        label = self.ui.ask(boundary.keyframe_clip, boundary.candidates)
        self.ledger.record(boundary, label, boundary.est_min)
        return label
```

```python
# ===== 运行时主循环（单 checkpoint / 单 API / 评测期零人工）=====
class UniBotHALO:
    def __init__(self, planner, executor, humanaware, stitcher, audit):
        self.planner, self.executor = planner, executor
        self.ha, self.st, self.audit = humanaware, stitcher, audit
        self.sessions = {}                     # 每端口独立状态（隔离）

    @property
    def metadata(self):
        return {"control_space": "joint", "action_chunk_size": 8,
                "obs_delta_indices": DEFAULT_DELTA, "human_service": "disabled",
                "token": os.environ["UNIBOT_SUBMISSION_TOKEN"]}

    def reset(self, port=None):
        self.sessions[port] = Session()

    def get_action(self, obs, port=None):
        s = self.sessions[port]; t0 = time.perf_counter()
        if s.plan is None:
            s.plan = self.planner.plan(obs, obs["observation.language"]); s.idx = 0

        m = self.ha.detect(obs)                        # H8：干扰检测（不呼人）
        if self.ha.should_yield(m, obs):               # H9：可拒绝屈服
            a = self.ha.yield_action(obs)
            self.audit.log_yield(m, obs); return self.pack(a, obs)

        g = s.plan[s.idx]
        a, s = self.executor.step(obs, g, s)           # option + 监视 + 恢复
        if a is None:                                  # 子目标完成 → 推进计划
            s.idx += 1
            if s.idx >= len(s.plan) or s.failed:
                a = self.executor.finish(obs)
            else:
                a, s = self.executor.step(obs, s.plan[s.idx], s)

        a = self.st.stitch(a, s.last_action)           # 继承 IP-03
        a = self.audit.clamp_and_log(a, obs, t0, self.tau)
        s.last_action = a[-1]
        return self.pack(a, obs)
```

## 5. 推导（引理 HL1–HL7）

**HL1（分层误差截断）** 设任务分解为 `K` 段，扁平策略各段成功率 `p_i`（独立近似），则 `p_flat = ∏ p_i`。设监视器对真实失败的召回为 `r_i`、误报率为 `α_i`，恢复可恢复概率 `δ_i`、恢复成功率 `q_i`，误报导致破坏好状态的概率为 `h_i`。则分层每段成功率
`p_i^H = p_i + (1−p_i)·r_i·δ_i·q_i − p_i·α_i·h_i`，
故 `p_H = ∏ p_i^H`。当 `r_i·δ_i·q_i > [p_i/(1−p_i)]·α_i·h_i` 时 `p_H ≥ p_flat`。⇒ 分层的收益不是"更准"，而是**把单次失败的代价从"整段报废"降为"一次可拒绝的重试"**。
*示意（假设值，非实测）*：`p=[.95,.90,.90,.80,.70,.90]`、`r=.8, δ=.6, q=.7, α=.02, h=.5` ⇒ `p_flat≈38.8%`，`p_H≈51.6%`（+12.8 个百分点）。该数字只用于说明"截断项"的量级，**不可当作真机预期**。∎

**HL2（人工监督复杂度）** 扁平逐步 DAgger 每 episode 查询数 ≈ `T`（轨迹步数）。分层 HIL 只在 option 边界与 `β` 低置信点查询，查询数 ≈ `K + U`（`U` 为不确定边界数），且 `K ≪ T`。在"每次查询的信息增益 ∝ 该边界的决策影响"的假设下，达到同等成功率所需标注数满足 `N_hier/N_flat ≤ (K+U)/T`。
*示意*：`T≈1350, K=6, U=18` ⇒ 比值 ≈ `1.8%`，即理论上可省约两个数量级的人工。该结论依赖信息增益假设，**属命题而非定理**，由 E702 检验。∎

**HL3（保守查询不伤害）** 与上版 L3 同构：只在"高置信 fail"且恢复期望收益大于代价时介入；净收益 `= −α·Δ_loss + r·Δ_gain − overhead`。取阈值使 `α ≤ 0.02` 且 `Δ_gain ≥ 5·α·Δ_loss`，则净收益为正。∎

**HL4（干扰检测与屈服阈值）** 令 `π = P(m=blocker)`，检测 TPR 为 `r`、FPR 为 `α`。屈服的期望效用优于继续当
`P(m=blocker|d)·L_c > (1−P(m=blocker|d))·L_y`
⇔ `P(m=blocker|d) > L_y/(L_c+L_y)`。故阈值随 `L_c/L_y` 升高而降低；在 N 机并发评测中，`L_c` 含"影响整份提交可信度"的外部性，阈值应比单机更低（更早屈服）。
*示意*：`L_c/L_y = 1, 3, 9, 19` 对应阈值 `0.50, 0.25, 0.10, 0.05`。∎

**HL5（组合复用的数据效率 · 猜想）** 若 option 库在 `M` 个任务上共享低层参数、任务差异只体现在高层计划，则新任务需学习的自由度 ≈ `O(K·|plan vocabulary|)` 而非 `O(|θ|)`，因而固定数据下组合泛化误差上界随 `K` 线性而非随 `|θ|` 增长。**本轮明确标注为设计假设，不作定理**，由 E708 证伪。∎

**HL6（分层可劣化条件）** 若监视器对某子目标的判定与真实成功负相关（OOD 下 AUC<0.5）或终止条件系统性偏移，则 replan 会在错误子目标上增加尝试次数，成功率可低于扁平策略。由 HL1，`p_i^H < p_i` 当且仅当
`r_i·δ_i·q_i < [p_i/(1−p_i)]·α_i·h_i`。
⇒ **监视器质量是分层的前置条件，不是附属品**；这直接构成 §12 的最大风险。∎

**HL7（人工锚点的抗漂移界 · 草图）** 设伪标签偏差为 `b`，独立同分布的人工锚点 `n` 个，则锚定估计偏差 ≤ `b/(n+1) + Var_anchor` 项；若用不确定性/D-optimal 主动选点，锚点集中覆盖监视器最不确定区域，方差下降因子 ∝ `1/(1+λ_min)`。⇒ 少量锚点应投在**高不确定边界**而非均匀撒点。该界依赖独立性假设，**标注为草图**，由 E710 检验。∎

| 复用（E708） | 留出任务 ≥+2 分 | 不达标 ⇒ 只做单任务模板，放弃跨任务 option 库 |
| 自主性（E711） | 四项全真 | 任一不真 ⇒ 修复后才允许提交 |
| 端到端（E716） | ≥ 榜首 +3 分 | 逐 IP 消融定位无效项并剪枝 |

## 12. 本轮最大风险

**本轮最大风险：分层的收益完全取决于三态监视器在分布外的校准——一旦它在未见物品上把失败判成成功，分层不但不截断误差，反而会用"错误的重试"把原本偶然可成的单次尝试消耗成结构性死循环。**
