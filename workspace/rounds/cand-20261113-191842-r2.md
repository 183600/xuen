# 第 69 轮（承接第 68 轮「CALM-RAS 自标定风险自适应闭环」IP-243~252；灵感循环新循环第 2 轮；本轮灵感：「真实世界泛化」×「工具调用」）

> 第 68 轮把「测量可信度」升为一等公民：静态段自标定 + 自监督残差 + 单模型多任务，让系统能说「我的测量还准吗」。但它自陈的最大风险暴露了一个更深的元失败：**整条安全线假设「模型类是对的，只是标定参数在漂」**。真实世界泛化恰恰打破这个假设——进入新场景/新光照/新接触动力学时，观测模型、动力学、语义类别会**同时误设（misspecification）**，而不是参数漂移。此时 COF 会把系统误差当漂移「标好」（过标定），CFA 把 H_cal 后验推高，保守回退只会把 λ 抬到 0.8 缩着不动——**它能承认自己不确定，却没有任何动作去消除不确定**。这是被动泛化的天花板：静态鲁棒性无法覆盖任意漂移，再保守也只是「少做少错」。
>
> 本轮灵感恰好给出破局的两块积木，核心命题：
>
> **把「真实世界泛化」从被动泛化界问题，重构为主动实验设计问题：用「工具调用」作为可验证的认知动作（epistemic action），在体制失配被检出时，花最小的风险预算去调用「最能降低决策相关不确定性」的工具/实验，并给每次调用附上「可验证性契约 + 有效度计量 + 可辨识覆盖声明」——GATE-RAS（Generalization via Active Tool-use Epistemics for Risk-Adaptive Systems）。**
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「**我的测量还准吗**」，R69 问「**我的模型还适用吗，该做什么实验才知道**」——当模型不适用时，系统不是缩着不动，而是**主动做一次安全、可审计、算得清收益的实验**。

## 0. 直觉与动机

**灵感 1（真实世界泛化 → 泛化不是「更鲁棒」，而是「知道自己何时不适用并去查」）**
直觉：域泛化（domain generalization）十年来的教训是，靠不变表征去硬扛任意 shift 是做不到的——你能对齐训练见过的 shift，对齐不了没见过的 shift。真正可部署的泛化不是「对所有世界都准」，而是「在新世界里知道自己不准，并且有办法把不准变准」。这要求把预测分成两部分：**偶然不确定（世界本身随机，工具也降不了）**与**认知不确定（我的模型/体制判断错了，工具可以降）**。工具调用的本质，就是把第二类不确定性显式地「花代价买掉」。R68 只做了被动承认（U 高就收紧），R69 要补的是主动消解。

**灵感 2（工具调用 → 工具是新的传感器，必须重新过一遍计量）**
直觉：大模型 Agent 的工具调用已被证明威力巨大，但它的失败模式也正是传感器失败模式的翻版——工具选错（等效量程外）、参数幻觉（等效读数坏点）、检索陈旧（等效零点漂移）、被注入内容投毒（等效对抗扰动）、工具本身漂移（等效传感器老化）。R68 花了整轮建「计量层」来驯服传感器；R69 必须把同一套计量学**上提一层**用于工具：每个工具都带类型化契约、权限域、有效域 dom(τ)、在线有效度 ν_τ，工具输出先过计量再进后验。**没有计量的工具调用，就是没有标定的传感器。**

**灵感 3（工具调用 → 主动实验设计，而不是「问一下大模型」）**
直觉：最朴素的多模态 Agent 是「不确定就问 VLM/问人」。但「问谁、问什么、问几次、什么时候不该问」才是真问题。信息论给出干净答案：一次实验值不值得做，看它的**决策相关期望信息增益（VOI）**——不是降低任意不确定性，而是降低「可能改变我要执行的动作」的那部分不确定性；再扣掉实验的副作用（主动探测会改变世界！）、延迟、投毒风险，除以成本。这样泛化行为从「玄学 Agent」变成「可审计的实验序列」：每次调用都对应一个假设、一个预期观测、一个决策后果。这就是把 Bayesian experimental design 装进闭环。

**灵感 4（两者合流 → GATE-RAS 七组件）**
真实世界泛化提出「体制失配」这个新故障类，工具调用提供「主动辨识体制」这个新动作类。二者合成一条带证书的闭环：
1. **OMD Regime-Mismatch Detector**：把不确定性二分为偶然/认知，维护体制变量 m_t 的后验，输出决策相关认知赤字 Epi^dec 与失配触发；内建「剧场」反事实检测（偷偷撤掉工具看会不会露馅）；
2. **TRG Tool Registry & Contract**：类型化工具契约（schema / 前后置条件 / 成本 / 延迟 / 风险 / 权限 / 有效域），覆盖主动感知、数字孪生重渲染、记忆/手册检索、人类/强模型 oracle、自检子程序、重标定程序；
3. **AED Active Experiment Designer**：风险调整的 VOI/成本 选择器 + 迟滞门限，选「最划算的实验」，无划算实验时退回 R68 保守策略；
4. **TPV Tool Provenance & Validity**：工具即传感器，ν_τ 在线估计（canary + 跨工具一致 + 后置条件 + 陈旧度），ν 低则降权为「不可信但不误导」；
5. **TVC Tool Verifier & Contract Checker**：执行前类型/前置/权限/注入/预算五查，执行后后置条件与跨工具一致性校验，幻觉工具一票拒绝；
6. **RBG Risk-Budgeted Gate**：快慢双层——快路径仍是 R68 <2.6ms 无工具推理，慢路径才允许工具；慢路径期间执行最小风险保持策略 π_safe，绝不带着陈旧 m̂ 乐观动作；
7. **GCI Generalization Certificate & Epistemic Ledger**：J_GATE 显式写入**可辨识覆盖声明** cov(Π)——系统只敢声明工具集能分辨的体制范围，范围外一律降级，杜绝「工具一致=世界理解」的幻觉。

**灵感 5（对 R65–R68 遗留风险的对症下药）**
- R68「缓变故障被标定吸收」：缓变故障恰是「体制在变但慢到像漂移」。OMD 不再只看残差幅度，而看**残差的可辨识结构**——能被现有工具实验区分的才归 cal，否则进入体制后验；工具集里专门的 **T_diag**（R65 自检）与 **T_twin**（反事实仿真）负责给缓变故障「做实验」；
- R68「标定红线悖论」：J_GATE 的 coverage_claim 把「红线依赖的初始计量」变成可审计的版本链与覆盖声明，红线不再假装绝对；
- R67「WM 黑箱前瞻」：T_twin 重渲染是 WM 的**外部证伪工具**，AED 只在 VOI 为正时调用，避免把 WM 自己的想象当证据；
- R66「情绪欺骗」：T_oracle（人/强模型）是可调用的高成本验证通道，但必须过 TVC 与 ν 计量，且调用它本身受风险预算约束；
- 「过度放宽」总闸不变：任何工具失败/超时/ν 低/覆盖外，一律只走 R68 的 λ_floor 收紧，**工具永远不能成为放宽的借口**。

## 1. 形式化定义（增量：定义 293–309）

**定义 293（GATE-RAS 总览）** GATE-RAS = (OMD, TRG, AED, TPV, TVC, RBG, GCI, MGP, AIC-GATE, RAS-WM†)。三条新不变式：
(i) **认知动作可审计**：每次工具调用 = 账本中一条记录 `(hypothesis, tool, args, EIG, side_effect, verdict)`，缺记录即视为未发生、不得作为证据；
(ii) **工具即传感器**：任何工具输出必须先经 TPV 给出 `(ν_τ, U_tool, dom 命中)`，才能进入后验/归因；`ν_τ < ν_min` 的输出只能收紧、不可放宽；
(iii) **快慢双层**：快路径零工具、继承 R68 <2.6ms；工具只在慢路径，总等待 ≤ T_slow；超时/失败按 R68 `λ_floor` 保守回退。

**定义 294（体制变量）** `m_t ∈ ℳ = ℳ_env × ℳ_model`：`ℳ_env` 为环境体制（新场景/光照/物体/接触动力学/人），`ℳ_model` 为模型体制（哪个假设族/头在生成观测）。`p(m_t | H_t)` 由 OMD 粒子滤波维护。**真实世界泛化失败 := 部署后 `H(m_t | H_t)` 长期居高且先验失配**。

**定义 295（不确定性二分）** 对预测 `Y_t`：
`H(Y_t | H_t) = E_{m∼p(m|H_t)}[H(Y_t | m, H_t)] + I(Y_t; m_t | H_t)`。
第一项 = **偶然不确定** `Ale_t`（工具不可降）；第二项 = **认知不确定** `Epi_t`（工具可降）。GATE-RAS 只对后者花工具预算。

**定义 296（决策相关认知赤字）** `Epi^dec_t := E_{m∼p(·|H_t)}[ℓ(a*_t, m)] − min_a E_m[ℓ(a, m)]`，其中 `a*_t` 是当前策略在不确定性下的动作。语义：**「若知道真实体制，我能挽回多少损失」**——这就是一次工具调用最多值多少。`Epi^dec` 高的认知不确定才值得做实验。

**定义 297（工具注册表与契约）** 工具 `τ = (schema_τ, pre_τ, post_τ, cost_τ, latency_τ, risk_τ, ν_τ, scope_τ, dom_τ)`：类型化输入输出、Hoare 式前后置条件、成本、延迟上界、副作用风险、在线有效度、权限域（read-only / actuation / network / human-escalation）、**有效域 `dom_τ ⊆ ℳ`**（域外 ν 未定义、禁止采信）。工具族 Π：
- `T_probe`：主动感知（移动相机/打光/轻触）——**干预型**工具；
- `T_twin`：数字孪生重渲染/反事实仿真（对 WM 的外部证伪）；
- `T_retrieve`：情景记忆/手册检索（注意陈旧与投毒）；
- `T_oracle`：人类或强外部模型（高成本、高延迟、高价值）；
- `T_diag`：内建自检子程序（承接 R65 FIR）；
- `T_cal`：重标定程序（承接 R68 COF 自举）。

**定义 298（工具有效度 TPV）** 工具是测量通道，`ν_τ,t ∈ [0,1]` 由证据在线更新：`(a)` 已知真值 canary 项命中率；`(b)` 跨工具一致；`(c)` 后置条件满足；`(d)` 陈旧度衰减；`(e)` 历史被证伪率。用 Beta-Bernoulli（或对连续偏差用 EKF）维护后验，`U_tool = 1−ν̄_τ` 或后验方差。**可采信（admissible）⇔ `ν_τ ≥ ν_min` 且 `m̂_t ∈ dom_τ`**。

**定义 299（工具风险预算）** `B_tool(t) = (ε_side, ε_poison, T_slow, N_calls, $cost)`。干预副作用成本 `C_side(a) = E[Δrisk_{t+1:t+h} | do(a)]`，由数字孪生估计并保守放大。RBG 硬约束所有调用。

**定义 300（主动实验设计 AED）** 候选 `(τ, θ) ∈ Π_t`（可采信集合）：
`VOI(τ,θ) = E_{o∼p(o|τ,θ,H_t)}[ max_a E_{m|o,H_t}[U(a,m)] ] − max_a E_{m|H_t}[U(a,m)]`。
风险调整：`VOI_robust = VOI − λ_side·C_side − λ_pois·(1−ν_τ)·R_max − λ_T·latency_τ`。
选择：`(τ*,θ*) = argmax VOI_robust / (cost_τ + 1)`，s.t. `C_side ≤ ε_side`、`latency ≤ T_slow`、`N_calls` 未超、`τ` 可采信；仅当 `VOI_robust ≥ τ_VOI`（迟滞）才执行，否则**退回 R68 保守策略**。这是「泛化=主动实验」的核心算子。

**定义 301（工具调用验证器 TVC）** 执行前五查：`(1)` 类型/schema；`(2)` 前置条件；`(3)` 权限与 scope；`(4)` 对抗注入筛查（检索内容/外部文本进入参数时）；`(5)` 预算。执行后：后置条件检查 + **高风险动作要求 ≥2 个独立可采信工具交叉一致**。任一失败 → 该调用不产生证据，写入 ℰ_tool。

**定义 302（工具证据的体制后验更新）** `p(m | o, τ) ∝ p(o | m, τ)^{w(ν_τ)} · p(m | H_t)`，`w(ν)` 单调递增、`w(0)=0`。语义：**工具不可信时不是「给错证据」，而是「不给证据」**——这与 R68「标定不确定时只收紧」同构，避免坏工具把后验带偏。

**定义 303（快慢双层 RBG）** 快路径：每个控制周期跑 R68 CALM-RAS，零工具，用当前 `m̂`；慢路径：OOD 触发或每 `Δ_slow` 跑 AED+TVC+工具。慢路径期间机器人执行**最小风险保持策略 `π_safe`**（不是乐观动作），并硬约束等待 ≤ `T_slow`；决策所用 `m̂` 的年龄有上界，超龄即失效。

**定义 304（泛化证书 J_GATE）** `J_GATE = (J_CALM, m_posterior_hash, Epi^dec, tool_ledger_root, coverage_claim, fallback_policy_hash, gate_ver)`。
Valid ⇔ `Valid(J_CALM)` ∧ `m̂ ∈ coverage(Π)` ∧ 账本内所有调用均已裁决 ∧ 红线未越界。**coverage_claim 是硬字段**：系统必须显式声明「我这套工具能辨识哪个体制集合」，不得宣称覆盖之外。

**定义 305（可辨识覆盖）** `cov(Π) = { (m,m′) : ∃(τ,θ)∈Π, p(o|m,τ,θ) ≢ p(o|m′,τ,θ) }`。即工具集能区分开的体制对。`m ∉ cov(Π)` 的体制为**不可辨识**：任何只用 Π 的策略都无法把它与某个替身体制分开（引理 18）。

**定义 306（泛化剧场检测）** 「剧场事件」：系统在新体制上决策变好，但内部体制后验仍错（`m̂ ≠ m`），工具输出是「因错误原因而正确」（虚假的工具一致）。检测：**反事实撤工具**——周期性在影子策略里禁用某工具，比较决策与置信；若性能崩而体制置信没掉，则判剧场，触发 `coverage_claim` 收缩与 GCI 告警。辅以 `T_oracle` 与廉价工具的持续分歧监控。

**定义 307（干扰集）** `ℰ_GATE = ℰ_CALM × ℰ_tool × ℰ_epi`；`ℰ_tool = {参数幻觉, 检索陈旧, 手册投毒, oracle 被收买, schema 漂移, 权限越界}`；`ℰ_epi = {主动探测副作用, 探测反馈导致分布漂移, 不可辨识体制, 泛化剧场, 工具依赖导致的能力坍塌}`。

**定义 308（离线元泛化策略 MGP）** 从 GCI 账本离线学习 `π_meta: (Epi^dec, H(m), {ν_τ}, B_tool) → (tool, θ) | abstain`。经 R68 CAC 认证提交，新增第六关 **withheld-tool robustness**（撤掉最常调用工具后性能衰减 ≤ 5%）。这是「学会何时调用工具」，而非把工具选择硬编码进策略。

**定义 309（主管线）** 离线：R68 预训练 → 工具 canary 标定 → 从历史账本学 π_meta → CAC 六关提交。在线：快路径 CALM-RAS；OOD 触发 → `π_safe` → AED 选实验 → TVC 验证 → 执行工具 → 体制后验更新 → 带证书恢复；全程 GCI 记账；周期性影子刷新 π_meta。

# IP-253 OMD：体制失配检测 + 偶然/认知分解 + 剧场反事实
class RegimeMismatchDetector:
    def update(self, H_t, obs):
        self.particles.update(obs)                 # 体制粒子滤波
        Ale = mean([H(Y | m, H_t) for m in self.particles])
        Epi = H(Y | H_t) - Ale                     # 认知不确定
        Epi_dec = bayes_regret(self.particles, self.last_action)
        ood = Epi_dec > tau_epi or self.residual_shift(obs) > tau_ood
        theater = self.counterfactual_withhold(obs)  # 撤工具是否露馅
        return RegimeInfo(Ale, Epi, Epi_dec, ood, theater,
                          m_hat=self.particles.map())

# IP-255 AED：风险调整 VOI / 成本 选择 + 迟滞
class ActiveExperimentDesigner:
    def choose(self, regime, tools, budget):
        best, best_score = None, 0.0
        for tau in tools.admissible(regime.m_hat):
            for theta in tau.candidate_params(regime):
                voi = self.expected_value_of_info(tau, theta, regime)
                robust = (voi - LAMBDA_SIDE*tau.side_cost(theta)
                            - LAMBDA_POIS*(1-tau.validity)*R_MAX
                            - LAMBDA_T*tau.latency)
                score = robust / (tau.cost + 1.0)
                if robust >= TAU_VOI and score > best_score \
                   and tau.side_cost(theta) <= budget.eps_side \
                   and tau.latency <= budget.T_slow:
                    best, best_score = (tau, theta), score
        return best                                # None ⇒ 退回 R68 保守策略

# IP-256/257 TPV + TVC：工具计量与契约验证
class ToolProvenanceTracker:
    def update(self, tau, evidence):               # canary / 跨工具 / 后置条件
        self.beta[tau].update(hits=evidence.ok, fails=evidence.bad)
        self.staleness[tau] = decay(self.staleness[tau], evidence.dt)
    def validity(self, tau, regime):
        if regime.m_hat not in tau.dom: return 0.0  # 域外一律不可信
        return self.beta[tau].mean * self.staleness[tau]

class ToolVerifier:
    def verify_before(self, tau, args, regime):
        return (schema_ok(tau, args) and tau.pre(args, regime)
                and scope_ok(tau, args) and not injection_risk(args)
                and budget_ok(tau))
    def verify_after(self, tau, out, regime):
        ok = post_ok(tau, out, regime)
        if ok and tau.high_stakes:
            ok = self.cross_tool_agree(tau, out, regime, min_independent=2)
        return ok

# IP-258 RBG：快慢双层
def gate_round(M, obs):
    fast = M.calm_ras.fast_step(obs)               # R68 快路径，零工具
    info = M.omd.update(M.history, obs)
    if not info.ood:
        return fast                                # 稳定体制：不付工具成本
    # 慢路径：先保持最小风险，再做实验
    M.control.hold(M.pi_safe)
    plan = M.aed.choose(info, M.trg.tools, M.budget)
    if plan is None:                               # 无划算实验 → 保守回退
        return M.calm_ras.conservative(fast, reason='no_viable_experiment')
    tau, theta = plan
    if not M.tvc.verify_before(tau, theta, info):
        M.gci.log(info, tau, theta, verdict='REJECT_CONTRACT')
        return M.calm_ras.conservative(fast, reason='contract_reject')
    out = M.scheduler.run(tau, theta, timeout=M.budget.T_slow)
    nu = M.tpv.validity(tau, info)
    if out.timeout or not M.tvc.verify_after(tau, out, info):
        M.gci.log(info, tau, theta, verdict='REJECT_EVIDENCE')
        return M.calm_ras.conservative(fast, reason='tool_failed')
    M.omd.condition_on(out, nu)                    # 定义 302 后验更新
    M.gci.log(info, tau, theta, eig=plan.voi, verdict='ACCEPT')
    return M.calm_ras.certified_resume(M.omd.map(), cert=M.gci.j_gate())

# IP-260 MGP：从账本学「何时调用工具」
def train_meta_policy(ledger):
    # 特征：Epi_dec, H(m), nu, budget；标签：该调用是否使决策后悔下降
    data = [(feat(r), label(r)) for r in ledger if r.verdict == 'ACCEPT']
    return fit_calibrated_classifier(data)          # 经 CAC 六关后上线

## 3. 推导

**引理 16（VOI 非负与不可信工具零增益）** 对任意实验 `(τ,θ)`，`VOI ≥ 0`（Bayes 决策下 `E[max] ≥ max[E]`）。且当 `ν_τ = 0` 时 `p(m|o,τ)=p(m|H_t)`（定义 302 的 `w(0)=0`），观测不改变后验，故 `VOI = 0`——**无效工具既不能帮忙，也不能带偏**。系：TPV 的 `ν_min` 是「工具是否进入实验集合」的硬闸，而非软建议。

**引理 17（工具调用次数上界 → 实时预算可证）** 设决策后悔 `Epi^dec` 存在最小改进量子 `ε`，且被接受的调用都满足 `VOI_robust ≥ τ_VOI ≥ ε`；被拒绝的调用不执行。因 `Epi^dec ≤ R_max`，单次慢路径事件内的接受调用数 `N_accept ≤ R_max/ε`；叠加 `N_calls` 硬预算，慢路径总耗时 `≤ N_calls·(T_verify + T_slow)`,与快路径延迟解耦——**工具调用不破坏 R68 的 <2.6ms 实时不变式**。

**引理 18（可辨识覆盖的不可约风险）** 若 `(m,m′) ∉ cov(Π)`，即对所有 `(τ,θ)∈Π` 有 `p(o|m,τ,θ)=p(o|m′,τ,θ)`，则任何仅用 Π 的策略在这两个体制上的最小最大额外风险 `≥ ½·TV(ℓ(·,m), ℓ(·,m′))`。工具调用再多也无法分开，**只能靠扩充 Π（新工具）或承认覆盖外**。系：J_GATE 的 `coverage_claim` 不是形式主义，而是引理 18 的证书化。

**引理 19（主动探测的偏差-方差权衡）** 若探测动作 `a` 同时影响观测 `o` 与下一体制 `m′`，则朴素后验 `p(m|o,a)` 相对干预后验 `p(m|do(o))` 的偏差随 `a` 的干预强度单调上升；随机化探测可去偏但方差上升。故 `VOI_robust` 中的 `λ_side·C_side` 是必要折扣，且**高副作用探测应被"非扰动探测优先"规则抑制**。

**引理 20（跨工具投毒验证界）** 在 A95（工具间的投毒检测事件独立）下，要求 `k` 个独立可采信工具一致才接受高风险证据，则毒证据被接受概率 `≤ ∏_{i=1}^k (1−p_{d,i})`；`k=3, p_d=0.8` 时 `≤ 0.8%`。系：TVC 的 `min_independent=2` 只是下限，高风险动作应升到 3。

**定理 16（GATE-RAS 泛化风险分解）** 在 A92–A97 下，对新体制 `m_new`：
`R_new ≤ R_fast(m̂) + Δ_cov·1[m_new ∉ cov(Π)] + P_miss·R_max + P_fail·R_fallback`，
其中 `R_fast` 由 R68 定理 14 给出（体制匹配时的界），`Δ_cov` 为覆盖外不可约风险（引理 18），`P_miss` 为 OMD 漏检率，`P_fail` 综合不可采信/超时/投毒。且当 `m_new ∈ cov(Π)` 且 OOD 被检出时，`E[R_new] ≤ R_oracle(m_new) + ε`，`ε` 由 `τ_VOI` 控制。**每一项都对应一个组件与一个实验**——这是可分解、可归因的泛化证书，而非一个漂亮但空洞的 PAC 界。

**定理 17（证书可靠性与剧场免疫）** 若 `J_GATE` 以 `coverage_claim = C` 有效，则对任意 `m ∈ C`，系统行为要么被证明正确、要么显式降级（不会静默乐观）；且反事实撤工具检测在 `τ_theater` 内以概率 `≥ 1−δ` 捕获剧场事件（假设撤工具本身不触发 OOD）。覆盖单调性：`m ∉ C` 时**不可能**签发有效 J_GATE——系统不能为覆盖外的体制「背书」。

## 6. 本轮最大风险

**一句话**：GATE-RAS 的全部泛化保证只成立于工具集的**可辨识覆盖** `cov(Π)` 之内——一旦真实世界漂移对所有可用工具都不可观测（或主动探测本身扰动了待辨识的体制，引理 19/18），系统会把「工具互相一致」误当作「世界已被理解」，在自信的工具编排下上演**泛化剧场**：它看起来适应了新世界，实际只是用错误的体制后验执行了一个碰巧正确的动作，而 J_GATE 的 coverage_claim 一旦被工程化地写宽，就会从诚实声明退化为免责条款。

**次级风险与缓解**：
1. **工具依赖导致能力坍塌**：离线策略越来越依赖工具 → CAC 新增 withheld-tool 关 + 定期无工具影子演练；
2. **主动探测的副作用/反馈漂移**：π_safe 保持 + 副作用预算 + 非扰动探测优先 + 随机化去偏（引理 19）；
3. **检索/手册投毒与 oracle 被收买**：TVC 注入筛查 + 跨工具独立验证 + ν 计量（引理 20）；
4. **慢路径破坏实时性**：快慢双层 + `T_slow` 硬超时 + π_safe 兜底 + 调用次数上界（引理 17）；
5. **覆盖声明被写宽**：coverage_claim 纳入证书版本链与审计，覆盖外一律 refuse-to-certify（定理 17）。

        if regime.m_hat not in tau.dom: return 0.0     # 域外直接不可信
        self.beta[tau].update(hits=ev.ok, fails=ev.bad)
        return self.beta[tau].mean * self.staleness(tau)

class ToolVerifier:
    def verify_before(self, tau, args, regime):
        return (schema_ok(tau, args) and tau.pre(args, regime)
                and scope_ok(tau, args) and not injection_risk(args)
                and budget_ok(tau))
    def verify_after(self, tau, out, regime):
        ok = post_ok(tau, out, regime)
        if ok and tau.high_stakes:
            ok = self.cross_tool_agree(tau, out, regime, min_independent=2)
        return ok

# IP-258/259/262 RBG + GCI 主闭环
def gate_round(M, obs):
    fast = M.calm_ras.fast_step(obs)                    # R68 快路径，零工具
    info = M.omd.update(M.history, obs)
    if not info.ood:
        return fast                                     # 稳定体制：不付工具成本
    M.control.hold(M.pi_safe)                           # 慢路径先保持最小风险
    plan = M.aed.choose(info, M.trg.tools, M.budget)
    if plan is None:
        return M.calm_ras.conservative(fast, 'no_viable_experiment')
    tau, theta = plan
    if not M.tvc.verify_before(tau, theta, info):
        M.gci.log(info, tau, theta, verdict='REJECT_CONTRACT')
        return M.calm_ras.conservative(fast, 'contract_reject')
    out = M.scheduler.run(tau, theta, timeout=M.budget.T_slow)
    nu  = M.tpv.validity(tau, info)
    if out.timeout or not M.tvc.verify_after(tau, out, info):
        M.gci.log(info, tau, theta, verdict='REJECT_EVIDENCE')
        return M.calm_ras.conservative(fast, 'tool_failed')
    M.omd.condition_on(out, nu)                         # 定义 302 后验更新
    M.gci.log(info, tau, theta, eig=plan.voi, verdict='ACCEPT')
    return M.calm_ras.certified_resume(M.omd.map(), cert=M.gci.j_gate())

## 4. 推导

**引理 16（VOI 非负与不可信工具零增益）** Bayes 决策下 `E[max] ≥ max[E]` ⇒ `VOI ≥ 0`；`ν=0` 时 `w(0)=0` ⇒ 后验不变 ⇒ `VOI=0`。**坏工具不带偏**，TPV 的 `ν_min` 是硬闸。

**引理 17（调用次数上界）** 最小改进量子 `ε`、接受门限 `τ_VOI ≥ ε`、`Epi^dec ≤ R_max` ⇒ 单次慢路径接受调用 `N_accept ≤ R_max/ε`；加 `N_calls` 硬预算 ⇒ 慢路径耗时 `≤ N_calls·(T_verify+T_slow)`，与快路径解耦，**R68 实时不变式不被破坏**。

**引理 18（可辨识覆盖的不可约风险）** `(m,m′) ∉ cov(Π)` ⇒ 对所有 `(τ,θ)` 观测分布相同 ⇒ 任何只用 Π 的策略在二者上的最小最大额外风险 `≥ ½·TV(ℓ(·,m), ℓ(·,m′))`。**工具再多也分不开**，只能扩 Π 或承认覆盖外——`coverage_claim` 的理论依据。

**引理 19（主动探测偏差-方差权衡）** 探测 `a` 同时影响 `o` 与 `m′` ⇒ 朴素后验相对干预后验的偏差随干预强度单调上升；随机化去偏但增方差。故 `λ_side·C_side` 是必要折扣，高副作用探测应被「非扰动优先」抑制。

**引理 20（跨工具投毒验证界）** A95（投毒检测事件独立）下，要求 `k` 个独立可采信工具一致才接受高风险证据，毒证据接受概率 `≤ ∏(1−p_{d,i})`；`k=3, p_d=0.8 ⇒ ≤0.8%`。

**定理 16（泛化风险分解）** A92–A97 下 `R_new ≤ R_fast(m̂) + Δ_cov·1[m_new∉cov(Π)] + P_miss·R_max + P_fail·R_fallback`；且 `m_new∈cov(Π)` 且 OOD 检出时 `E[R_new] ≤ R_oracle(m_new)+ε`，`ε` 由 `τ_VOI` 控制。每项对应一个组件与一个实验。

**定理 17（证书可靠性与剧场免疫）** `J_GATE` 以 `coverage_claim=C` 有效 ⇒ 对任意 `m∈C`，行为要么被证明正确、要么显式降级（不静默乐观）；反事实撤工具在 `τ_theater` 内以 `≥1−δ` 捕获剧场（假设撤工具不触发 OOD）；覆盖单调性：`m∉C` 时**不可能**签发有效 J_GATE。

## 7. 本轮最大风险

**一句话**：GATE-RAS 的全部泛化保证只成立于工具集的可辨识覆盖 `cov(Π)` 之内——一旦真实世界漂移对所有可用工具都不可观测（或主动探测本身扰动了待辨识的体制，引理 18/19），系统会把「工具互相一致」误当作「世界已被理解」，在自信的工具编排下上演**泛化剧场**：它看起来适应了新世界，实际只是用错误的体制后验执行了一个碰巧正确的动作，而 `coverage_claim` 一旦被工程化地写宽，就会从诚实声明退化为免责条款。

**次级风险与缓解**：工具依赖导致能力坍塌（CAC 第六关 withheld-tool + 无工具影子演练）；主动探测副作用/反馈漂移（π_safe + 副作用预算 + 非扰动优先 + 随机化去偏）；检索投毒/收买 oracle（TVC 注入筛查 + 跨工具独立验证 + ν 计量）；慢路径破坏实时（快慢双层 + T_slow 硬超时 + 调用次数上界）；覆盖声明被写宽（coverage_claim 入证书版本链与审计，覆盖外 refuse-to-certify）。
