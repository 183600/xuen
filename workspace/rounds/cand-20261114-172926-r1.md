# 第 74 轮（承接第 73 轮「MODGAUGE-RAS 计量契约代数」IP-295~302；灵感循环第 1 轮；本轮灵感：「轻量化结构」×「嵌入式系统」）

> R73 把可信性从「传感器」契约化（MMS/DPEM/CCA/ΣREFLEX/CPB），并在「本轮最大风险」里亲手写下自己最大的洞：**隐共享物理过程耦合**——若两个模块因同一光源、同一振动、同一温度场而相关，并联一致性审计的 conformal 集并不覆盖这种相关，系统就会「证书齐全地组合出一个错误的世界」。R73 只能把它降级为一条次级风险，用「环境级共因审计」打补丁。
> 本轮的两个灵感，恰好是机器人上**最重要、又最容易被当成工程细节的两个共享物理过程**：
> - **轻量化结构**：为了让质量/惯性/速度达标，连杆变薄、点阵化、拓扑优化——机器人不再是一个刚体，而是一根**会弯、会振、会热胀、会迟滞、会疲劳**的梁。传感器不是装在「世界」上，而是装在这根梁上。结构柔度是**动作与负载条件化的证据畸变场**。
> - **嵌入式系统**：时间、能量、数值表示不是「实现细节」，而是**证据的属性**——快照年龄 = 过程噪声累积；热节流 = WCET 膨胀 + 结构热膨胀；定点量化 = 表示误差；共享 CPU/总线/热区 = 模块之间的**资源共因**。
> 于是本轮把 R73 的「风险 5」扶正为一等对象：**基底（Substrate）= 承载证据的物质与计算基础**。核心命题从「证据能否契约化」推进到：
> **证据的可信度能否对「承载它的基底」可观测、可预算、可组合？当结构柔度与计算时序成为共因噪声源时，独立性还能是假设吗——还是必须被证明？**
> 方案：**SUBSTRATE-GAUGE-RAS**（SUBstrate-aware GAUGE for RAS，基底计量）。六件套：
> - **SG / SMS（基底图与基底计量系统）**：机械/计算/热/电四类基底节点 + 模块绑定 σ + 基底状态 x_S；
> - **SCM（结构柔度计量）**：五分量结构畸变（static/dyn/thermo/hyst/fatigue）+ 一阶可观测性 + 负载反作用通道 χ_load；
> - **TEM（时序-能量计量）**：证据年龄/抖动/量化/热节流四分量 + 资源需求契约，把「时间也是不确定度」写进预算；
> - **CMR（共模观测与抑制）**：用应变/IMU/温度/时钟作基底观测器，把 R73 的「独立性」从**假设**变成**可测量、可证书化**的条件；
> - **CCA†（基底感知组合代数）**：共享基底模块的相关性下界、σ-不相交、共模扣除后的残余相关证书；
> - **ECLD（证据约束轻量化设计）**：把「每克能换多少证据质量」写进设计目标，给出安全轻量化的质量下界 m*。
> 一句话：**不再问「这个模块可信吗」，而问「这块材料与这台计算机，允许证据有多可信？」**

## 0. 直觉与动机

**灵感 1（轻量化结构 → 机器人不是刚体，而是一根会呼吸的梁）**
直觉：轻量化的本质不是「变轻的刚性体」，而是「变轻的柔性体」。把连杆做薄、换点阵、做拓扑优化，刚度重量比确实上去了，但**绝对刚度下来了**：重力下垂、负载挠曲、低频模态、热膨胀、关节迟滞与磨损。传感器不是固定在「世界坐标系」上，而是固定在「一根会弯的梁」上。因此深度相机的位姿误差、力/触觉坐标系的法向误差，有相当一部分根本不是标定误差，而是**结构的瞬时形变**；而形变又是**动作与负载的函数**——这恰好是既有 χ_R 通道的一个新实例，**不需要改主闭环**。
严谨地看，这与 R73 的 u_calib 有本质区别：标定漂移是**慢变、参数性、且无外部基准时不可观测**的；结构柔度是**快变、状态性、且可以用机载应变/IMU 在线观测**的。前者只能被「界住」，后者可以被「估计并扣除」。这个区别决定了本轮的方法论：不是再给深度加一个方差项，而是引入一个**可观测的共模状态**。
设计后果同样尖锐：轻量化把**质量**与**证据质量**放进同一个预算。纯刚度-重量优化会给出「更轻、更刚、但更不可信」的机体；正确的问题是一个**证据约束优化**——在 u_struct ≤ τ_struct、模态不混叠、安全证书有效的约束下最小化质量。由此定义「计量比刚度」（每克每单位柔度换来的证据可信度），也由此得到「安全轻量化的质量下界 m*」。
**模态混叠**是轻量化特有的采样定理问题：一阶模态可能落进控制/感知带宽，振动同时造成深度运动模糊与接触抖动。要么保证 f_1 ≥ 证据采样 Nyquist，要么在有效域 D 中显式排除激发该模态的动作集合——不存在「既轻、又让低频模态自由共振、还宣称证据有效」的第三条路。

**灵感 2（嵌入式系统 → 时间、能量、比特都是证据的属性）**
直觉：嵌入式系统的三个硬约束——**时间、能量、数值表示**——在这里全都变成不确定度。
- 时间：WCET、调度抖动、快照年龄。控制域读到的是一个「t-τ 时刻的世界」；τ 越大，过程噪声累积越多。所以 **u_time = 陈旧证据的代价**，它必须像 u_tact 一样进预算。
- 能量：功耗 → 热 → 降频（时序变差）+ 热膨胀（结构变差）。**同一个热场同时攻击计算基底与机械基底**，这不是两个问题，是一个问题的两面。
- 数值：定点/int8 量化有可界表示误差；浮点则不可逐位复现。审计若要「可复算」，契约就必须声明**数值确定性类**——证书不能依赖一个每次运行都不同的最后一位。
更深的一层：模块不是独立运行的。它们共享 CPU、总线、热区、电源。**一个模块的加入会降低所有共居模块的时效性**，提高它们的 u_time。R73 说「新模态 = 新模块、核心零改动」，这句话在**时间维度上是不成立的**——除非把「可调度性」也变成组合校验的一部分。于是本轮给出：资源需求契约（C_i,T_i,D_i,M_i,E_i）+ 计量可调度判据（τ_i ≤ τ_i^max ∧ ΣC_i/T_i ≤ U_max ∧ T ≤ T_max）。这直接产生一个新的降级轴：**时序/热导致的基底原子降级**。

**灵感 3（合流 → 基底是共因噪声的物理来源，CMR 把独立性变成证书）**
直觉：轻量化结构与嵌入式系统不是两个话题，它们通过**热**与**振动**耦合：功率→热→形变+降频；动作→振动→结构模态+相机运动。这恰恰是 R73 无法用模块契约表达的东西：**共因**。两个模块各自证书有效、各自有效域成立，却因为站在同一根梁、同一块热区、同一条总线上而**同时**出错——并联一致性审计看到它们「一致」，于是放心缩窄，结果把共模误差当成了相互印证。
正确的做法不是「怀疑相关时禁用并联」（那是保守的补丁），而是**把共模观测出来**：用应变片/IMU 估计结构模态，用温度/PMU 估计热-时序状态，得到基底状态估计 x̂_S；再从每个模块的证据里减去各自的一阶投影 J_i x̂_S。共模被扣除后，模块间的残余相关由**估计误差 Σ_e** 界定。于是「独立性」不再是不可验证的假设，而是一条**可测量、可审计、可随观测器质量缩放的证书条件**。代价是一个新的单点风险（见第 6 节）：如果观测器本身模型错了、或它就在被测的热路径里，那么减法会把一个**共享偏差**洗成「表面独立」，让系统更自信地错。

## 1. 形式化定义（增量：定义 383–395）

**定义 383（SUBSTRATE-GAUGE-RAS 总览与六不变式）**
SUBSTRATE-GAUGE-RAS = (SMS, MMS†, DPEM†, DMEM†, CCA†, ΣREFLEX†, CPB†, SG)。六不变式：
(i) **契约完整性**（继承 366(i)）：每个模块实例化完整 EC，且 EC 新增两个字段——基底绑定 σ_i（定义 384）与数值确定性类 N_i（定义 386）；
(ii) **组合单调性**（继承 366(ii)）：所有组合经 CCA† 校验（定义 392），不确定度不出现「凭空变好」；
(iii) **反作用通道完备**（继承 366(iii)）：除 χ_R 外，每个模块声明负载通道 χ_load（定义 385）与热-时序通道 χ_S（定义 393），可为平凡恒等；
(iv) **基底绑定完备**：∀i，σ_i ≠ ∅；σ_i 中每个节点要么被基底观测器覆盖（定义 388），要么其贡献被显式上界 u_S 计入；禁止「未声明基底」的模块入图；
(v) **主张绑定**（继承 366(iv)）：C1/C2/C3/C4 ↔ 组件/基准/消融/预注册指标（定义 395）；
(vi) **严格退化链扩展**：基底原子降级（定义 391）→ σ-闭包组 stub；观测器失效 → 回退相关下界 ρ_floor 并禁 PAR 缩窄；安全侧只增不减。

**定义 384（基底图 SG 与绑定 σ）**
SG = (V_S, E_S, σ, x_S)：
- V_S = V_mech ∪ V_comp ∪ V_therm ∪ V_power。V_mech = {连杆、关节、传感器支架、末端执行器}；V_comp = {CPU 核、NPU、内存总线、传感器总线}；V_therm = {热区}；V_power = {电源轨}。
- E_S ⊆ V_S × V_S，边上标注耦合类型 κ ∈ {load-path（机械传力）, interference（资源争用）, conduction（热传导）, draw（供电耦合）}。
- σ: M → 2^{V_S}，模块到其依赖的基底节点集合；**共享基底** Shared(i,j) ≜ σ_i ∩ σ_j。
- x_S(t) ∈ X_S 为基底状态：位移场/模态幅值/温度/利用率/频率。
- 观测 y_S = H_S x_S + v_S（应变 ε、IMU a、热敏 T、PMU/时钟计数器）。
- **基底可观测性**：在运行包络 𝒳 上，若 (H_S, A_S) 可观测且 Gramian 非奇异，则 x_S 可估；否则只保留上界 u_S。𝒳 本身是契约字段，超出即降级。

**定义 385（结构柔度计量 SCM）**
结构状态 x_s = (δ_static, η_modal, ΔT_thermo, h_hyst, κ_fatigue) ∈ R^{n_s}，n_s ≤ 24（与定义 377 同风格的结构上限）。线性化动力学：
M_s ẍ_s + D_s ẋ_s + K_s x_s = B_s u_load(q, a, payload) + w_s，
模态分解给出 {f_k, φ_k}。传感器位姿畸变的一阶模型：
p_i = p_i^nom + J_i(q) x_s + O(‖x_s‖²)，J_i = ∂p_i/∂x_s。
证据畸变协方差：Σ_i^struct = J_i Σ_s J_i^T + R_i(‖x_s‖³)。
**五分量**：
u_struct² = u_static² + u_dyn² + u_thermo² + u_hyst² + u_fatigue²，
分别对应重力/负载下垂、模态振动、热膨胀/模量漂移、迟滞/回差、疲劳刚度退化；每分量独立追溯链，与 DPEM 的六分量、DMEM 的四分量同构。
**有效域收缩** D_s = {|x_s| ≤ x_max} ∧ {f_1 ≥ 2 f_s ∨ 激发谱 ∩ 模态带 = ∅}（后者为**模态抗混叠**条件）。
**负载反作用通道 χ_load**: (a, payload, q) ↦ u_load ↦ x_s 的预测轨迹 ↦ (ΔΣ_i^struct, D_s′)。**关键区别**：χ_load 的输出不是「更差的界」，而是**可被观测器校正的偏差预测**（定义 388）。

**定义 386（时序-能量计量 TEM）**
对每次证据消费，记快照年龄 τ_i = t_consume − t_emit。**四分量**：
- u_age² = τ_i · q_diag + (ρ_clk · τ_i)²（过程噪声 + 时钟漂移）；
- u_jitter = v_rel · J_samp / √12（采样抖动经相对运动放大）；
- u_quant = (Δ/√12) · cond(Φ)（定点量化经条件数放大；浮点按区间证书计）；
- u_thermo-time = ∂C_i/∂T · (T − T_0)（热节流导致的时效退化，见定义 393）。
u_time = sqrt(u_age² + u_jitter² + u_quant² + u_thermo-time²)。
**数值确定性类** N ∈ {INT_EXACT（定点，逐位可复现）, FLOAT_BOUNDED（浮点 + 区间证书）, APPROX（近似，不可审计复算）}；控制关键路径要求 INT_EXACT 或 FLOAT_BOUNDED。
**资源需求契约** W = (C_i, T_i, D_i^rel, M_i, E_i)（执行时间、周期、相对截止期、内存、能量）。
**计量可调度判据**：∃ 调度使 ∀i，τ_i ≤ τ_i^max ∧ T(t) ≤ T_max ∧ U = Σ_i C_i(T)/T_i ≤ U_max。注意 C_i 是温度的函数。

**定义 387（基底相关下界）**
设共模 x_S ~ (0, Σ_S)，模块 i 的畸变 d_i = J_i x_S + n_i，n_i ⟂ n_j ⟂ x_S。则
Cov(d_i, d_j) = J_i Σ_S J_j^T，
ρ_ij^S = (J_i Σ_S J_j^T) / sqrt((J_iΣ_SJ_i^T + Σ_{n_i})(J_jΣ_SJ_j^T + Σ_{n_j}))。
**相关下界** ρ_floor(i,j) ≜ max_{v ∈ Shared(i,j)} ρ_v(g_v)，其中 g_v 为节点 v 的耦合增益（设计期由传递函数/资源争用模型给出）。对安全而言只关心**同向**共模（会伪装成相互印证），故按 |ρ| ≥ ρ_floor 做保守处理。Shared(i,j) = ∅ ⇒ ρ_floor = 0（σ-不相交）。

**定义 388（共模观测与抑制 CMR）**
基底观测器：x̂_S = E[x_S | y_S]，Σ_e = Cov(x_S − x̂_S)，Σ_e = (I − K H_S) Σ_S。
校正证据：d_i′ = d_i − J_i x̂_S = J_i e_S + n_i，e_S = x_S − x̂_S。
残余相关：Cov(d_i′, d_j′) = J_i Σ_e J_j^T。
**独立性证书条件**（取代 R73 的「|ρ̂| < ρ_max」假设）：
∀ i≠j: ‖J_i Σ_e J_j^T‖ ≤ ρ_max · sqrt(σ_i′² σ_j′²)，或 Shared(i,j) = ∅。
若观测器失效（u_S > τ_S 或可观测性丧失）⇒ 回退 ρ_floor 并**禁用 PAR 缩窄**。
一句话：**CMR 不能消除共因，只能把「不可控的共因」变成「有界的估计残差」；证书买的是这个残差，不是共因本身。**

**定义 389（证据约束轻量化设计 ECLD）**
设计变量 θ（拓扑、厚度、材料、阻尼布置）。**计量比刚度** M_eff(θ) ≜ K(θ) / (m(θ) · ū_struct(θ))（每克、每单位柔度换来的证据可信度）。优化：
min_θ m(θ)
s.t. (a) δ_max: |δ(q, load)| ≤ δ_max；(b) 抗混叠: f_1(θ) ≥ 2 f_s 或 D 排除共振动作集；(c) **证据预算**: max_{𝒳} u_struct(θ, q, load) ≤ τ_struct；(d) 相关预算: ρ_floor(θ) ≤ ρ_max 或 CMR 残差条件成立；(e) 热: ΔT ≤ ΔT_max；(f) J_SUB 有效（定义 390）。
**安全质量下界** m* ≜ inf{ m(θ) : (a)–(f) }。引理 41 保证可行域在质量上是上闭的，故 m* 良定义。

**定义 390（基底证书 J_SUB）**
J_SUB = (应变覆盖证书, 模态包络证书, 热包络证书, 可调度性证书（RTA 片段）, CMR 残差证书, 能量预算闭合, 数值确定性类)。Valid(J_SUB) ⇔ 对所有可达 x_S ∈ 𝒳，相关下界/残差条件成立、可调度、热包络内、能量未超。J_sub 与 J_MOD 正交：J_SUB 管「基底允许什么」，J_MOD 管「模块声明了什么」。

**定义 391（基底原子降级 SAD）**
失效粒度下沉到基底节点：结构节点异常（应变超模型 3σ / 冲击 / 裂纹指标）⇒ stub 所有 i 满足 v ∈ σ_i；计算节点失效 ⇒ stub 该核上的模块组；热失控 ⇒ 降频 + 组 stub；电源轨跌落 ⇒ 对应组 stub。
**σ-上闭性**：若节点 v 降级，则 {i : v ∈ σ_i} 全部降级——即使某个模块自身指标看起来正常。这堵死了「共享基底坏了但单模块读数仍漂亮」的**共因误信**。组 stub 仍参与 MReg 连通性校验；σ-不相交的模块继续工作。
与定义 381（单模块 stub）的关系：单模块 stub 是 σ 上闭集的退化特例（σ_i 单点）。

**定义 392（基底感知组合代数 CCA†）**
- **SER**：u_out ≥ u_A + L_B·u_A + u_S（基底贡献必须显式累加）；D_out = D_A ∩ D_B ∩ D_S；χ 串联。
- **PAR**：缩窄需三条件同时成立——(a) conformal 一致性审计通过；(b) |ρ̂| < ρ_max；(c) **基底条件**：Shared(i,j) = ∅，或 CMR 残差证书（定义 388）成立。否则用保守融合 u_out = fuse(u_A, u_B, ρ = max(ρ̂, ρ_floor))，并置 I⊥ ← I⊥ ∪ {SUBSTRATE_CORR}。
- **VETO**：有效性合取；新增**基底冲突否决**——若两模块的基底畸变估计之差超出 J_SUB 预测包络，判为共因对抗，整体否决。
**引理 34 的基底强化**：任何组合路径的输出不确定度 ≥ 路径输入贡献 + 基底贡献的单调函数；在共享基底上按独立性融合属于**违例路径**。

**定义 393（基底反作用通道 χ_S 与热-时序-结构慢回路）**
χ_S: (a, duty cycle) ↦ 功率 ↦ 热 ↦ (降频 ΔC, 热膨胀 Δx_s, 模态漂移 Δf_1) ↦ (Δu_time, Δu_struct, D′)。
**时间尺度分离**：基底回路为秒–分钟级，控制回路为毫秒级；在正常占空比下按准静态参数漂移处理（有界变化率 |ẋ_S| ≤ ν_S）。当占空比超过 d_c（热时间常数与控制带宽同量级）时，时间尺度分离失效，D 必须收缩或拒绝该动作。
**基底反作用预算**：Σ_t c_S^i ≤ E_total 且 ΔT_head ≥ 0；耗尽即降频/降级（按 ERVOI 证据价值排序，见定义 394）。这是 ΣREFLEX 的又一条通道，层数仍由模块声明，主闭环零改动。

**定义 394（计量预算调度 MBS）**
「**时间即不确定度**」：调度器不以最小化完成时间，而以最小化证据陈旧度为目标分配周期：
find {T_i} s.t. ∀i u_time^i(T_i, U) ≤ τ_i ∧ Σ_i C_i/T_i ≤ U_max，
目标 min Σ_i w_i · c_reflex^i（w_i 由 ERVOI 证据价值给出）。
不可行时，按 ERVOI 价值升序降级最低价值模块（先 stub，再降采样）。**引理 40**：新增模块一般提高共居模块的 u_time，故「模块可加性」在时间维度不成立——必须由 MBS 证书恢复。

**定义 395（主张-证明绑定 CPB† 与基底威胁面 AIC-SUBSTRATE）**
- **C1†（物理感知证据计量）** ← (DPEM, DMEM, SCM) ← MB1/MB4 ← AB1/AB4 ← (ECE, 覆盖率, 碰撞率, 误抓率, u_struct 校准)；
- **C2†（反作用预算组合）** ← (ΣREFLEX, ERVOI, PVOP, χ_load, χ_S) ← MB2 ← AB2 ← (交互次数, 停止方差, 能量闭合)；
- **C3†（契约式模块化）** ← (MMS, CCA†, J_MOD, J_SUB) ← MB3 ← AB3 ← (逐指令等价, 认证成本比, 迁移行数)；
- **C4（基底共因界，新）** ← (SG, SMS, CMR, MBS) ← MB4 ← AB4 ← (**相关低估率, 安全界违例率, m*/m_budget**)。
C4 的证伪方式很直接：构造共享基底的对抗场景，检验「未声明基底 / 未做 CMR / 按独立性融合」三组是否出现安全界违例，而 CCA† 组零违例。**AIC-SUBSTRATE**：谐振激励、热节流 DoS、时钟欺骗、应变伪装（附质量伪造负载）、定点位翻转；防线：观测器多样性 + 热包络否决 + RTA 松弛监控 + 逐位复算。

```python
# IP-303 SG/SMS：基底图与绑定、基底状态估计
@dataclass(frozen=True)
class SubstrateBinding:
    nodes: FrozenSet[str]                  # σ_i：模块依赖的基底节点
    J: np.ndarray                          # ∂(证据参数)/∂x_S，一阶投影
    coupling: Dict[str, float]             # 各节点耦合增益 g_v

class SubstrateGraph:
    def __init__(self):
        self.nodes = {}; self.edges = []; self.binding = {}
    def bind(self, module, sigma: SubstrateBinding):
        assert sigma.nodes, "无基底绑定的模块不得入图"      # 不变式 (iv)
        self.binding[module] = sigma
    def shared(self, a, b):
        return self.binding[a].nodes & self.binding[b].nodes
    def rho_floor(self, a, b):
        return max((self.nodes[v].coupling for v in self.shared(a, b)), default=0.0)

# IP-304 SCM：结构柔度计量（感知域 200Hz）
class StructuralComplianceMetrology:
    def update(self, strain, imu, torque, q, payload):
        x_s, P_s = self.ekf.predict_update(strain, imu, torque, q, payload)  # 定义 385
        f1 = self.modal.first_mode(x_s)                    # 一阶模态
        alias = (f1 < 2 * self.f_s) and self.excite_overlaps_mode(q)
        breakdown = (self.u_static(x_s), self.u_dyn(x_s), self.u_thermo(x_s),
                     self.u_hyst(x_s), self.u_fatigue(x_s))
        u = math.sqrt(sum(b*b for b in breakdown))
        valid = (max(abs(x_s)) <= self.x_max) and not alias
        return StructEvidence(x_s=x_s, cov=P_s, u=u, breakdown=breakdown,
                              valid=valid, chi_load=self.chi_load(q, payload))

# IP-305 TEM：时序-能量计量（控制域旁路，1kHz 采样）
class TimingEnergyMetrology:
    def update(self, t_emit, t_consume, utilization, temp, quant_step, cond):
        tau = t_consume - t_emit
        u_age = math.sqrt(tau * self.q_diag + (self.rho_clk * tau) ** 2)
        u_jit = self.v_rel * self.J_samp / math.sqrt(12)
        u_q   = quant_step / math.sqrt(12) * cond
        u_th  = self.dC_dT * max(0.0, temp - self.T0)
        u = math.sqrt(u_age**2 + u_jit**2 + u_q**2 + u_th**2)
        return TimingEvidence(u=u, breakdown=(u_age, u_jit, u_q, u_th),
                              stale=(tau > self.tau_max),
                              sched=self.check_schedulable(utilization, temp))  # 定义 386

# IP-306 CMR：共模观测与抑制（把独立性变成证书）
class CommonModeRejection:
    def observe(self, y_S):
        x_hat, Sigma_e = self.observer(y_S)                # E[x_S|y_S]
        return x_hat, Sigma_e
    def correct(self, ev, J, x_hat):
        return ev.corrected(delta=J @ x_hat)               # d_i' = d_i - J_i x_hat
    def independence_cert(self, i, j, J_i, J_j, Sigma_e, rho_max):
        shared = self.sg.shared(i, j)
        if not shared: return True                          # σ-不相交
        cross = J_i @ Sigma_e @ J_j.T
        return norm(cross) <= rho_max * math.sqrt(sigma_i2 * sigma_j2)

# IP-307 CCA†：基底感知组合（共享基底不得按独立融合）
def compose_substrate(a_ev, b_ev, op, sg, cmr, audit):
    if op == 'SER':
        return Ev(u=a_ev.u + lipschitz(b_ev, a_ev.u) + a_ev.u_S + b_ev.u_S,
                  D=a_ev.D & b_ev.D & a_ev.D_S & b_ev.D_S,
                  veto=a_ev.veto | b_ev.veto)
    if op == 'PAR':
        r = cross_modal_residual(a_ev, b_ev)
        if audit.conformal_covers(r) and abs(audit.rho_hat(a_ev, b_ev)) < RHO_MAX:
            if sg.shared(a_ev.id, b_ev.id):
                if cmr.independence_cert(a_ev.id, b_ev.id, a_ev.J, b_ev.J,
                                         cmr.Sigma_e, RHO_MAX):
                    return fuse(a_ev, b_ev, audit.rho_hat(a_ev, b_ev))
                return fuse(a_ev, b_ev, beta=max(audit.rho_hat(a_ev, b_ev),
                                                 sg.rho_floor(a_ev.id, b_ev.id)))
            return fuse(a_ev, b_ev, audit.rho_hat(a_ev, b_ev))   # σ-不相交
        return Ev(u=max(a_ev.u, b_ev.u), D=a_ev.D & b_ev.D,
                  veto=a_ev.veto | b_ev.veto | {'PAR_AUDIT_FAIL'})
    if op == 'VETO':
        if a_ev.veto or b_ev.veto: return Ev(valid=False,
                                            veto=a_ev.veto | b_ev.veto)
        if not sg.substrate_consistent(a_ev, b_ev): return Ev(valid=False,
                                            veto={'SUBSTRATE_CONFLICT'})
        return Ev(u=min(a_ev.u, b_ev.u), D=a_ev.D & b_ev.D)

# IP-308 ECLD：证据约束轻量化设计（离线拓扑优化 + 证据预算）
def ecld_optimize(topology, envelope, tau_struct, rho_max):
    def feasible(theta):
        return (deflection(theta, envelope) <= DELTA_MAX
                and first_mode(theta) >= 2 * F_S
                and max_u_struct(theta, envelope) <= tau_struct
                and (rho_floor(theta) <= rho_max or cmr_cert(theta))
                and delta_T(theta, envelope) <= DT_MAX)
    theta_star = min((t for t in topology.candidates() if feasible(t)),
                     key=lambda t: mass(t))                 # m* 由引理 41 良定义
    return theta_star, mass(theta_star), metrological_stiffness(theta_star)

# IP-309 MBS：计量预算调度（时间即不确定度）
def metrological_schedule(modules, tau_max, U_max):
    order = sorted(modules, key=lambda m: -m.evidence_value)   # ERVOI 价值
    periods = allocate_periods(order, lambda T, U: u_time(T, U) <= tau_max)
    if utilization(periods) > U_max or not periods:
        for m in sorted(modules, key=lambda m: m.evidence_value):  # 低价值先降
            m.degrade()                                    # stub / 降采样
            if utilization(realloc(modules)) <= U_max: break
    return periods
```

## 3. 推导（引理 38–42，定理 30–32）

**引理 38（结构畸变的一阶可观测性）**
在运行包络 𝒳 内，若 (H_s, A_s) 可观测且应变/IMU 观测 Gramian 非奇异，则 J_s x_s 可辨识，估计残差由 Σ_e 界定。系：**结构柔度可被校正，标定漂移只能被界住**——这是 SCM 不同于 u_calib 的方法论支点，也是 CMR 可行的前提。

**引理 39（共模抑制后的残余相关界）**
CMR 后 d_i′ = J_i e_S + n_i，故 |ρ_ij′| ≤ ‖J_i‖‖J_j‖‖Σ_e‖ / (σ_i′σ_j′)。⇒ 独立性可从「假设」改写为「证书条件」：只要观测器把 ‖Σ_e‖ 压到足够小，或让模块 σ-不相交，PAR 缩窄就合法。系：**R73 的 PAR 独立性假设在轻量化机体上一般是错的；CMR 是把它修对的唯一非保守手段。**

**引理 40（时间即不确定度 / 时间维不可加性）**
u_age 关于快照年龄 τ 单调增；在固定 CPU 预算下，新增模块使利用率 U 上升，队列时延上升，故共居模块的 τ 与 u_time 均上升。⇒ 「新模块 = 零改动」在时间维度不成立；组合的时效合法性必须由 MBS 证书（定义 394）恢复。系：**不确定度不只由传感器产生，也由调度产生。**

**引理 41（轻量化的计量代价单调性）**
在固定材料/拓扑族内，减小质量（提高细长比）单调提高静柔度并降低 f_1，故 ū_struct 单调增；因此证据预算 (c) 与抗混叠 (b) 给出质量下界 m* > 0。⇒ **纯刚度-重量优化会给出「过刚度检验、但过不了安全」的机体**。系：安全轻量化是可判定的约束优化，不是经验调参。

**引理 42（热-结构-时序的共同单调性）**
占空比上升 ⇒ 温度上升 ⇒ 结构柔度上升（膨胀/模量下降）且 WCET 上升（降频）；故 u_struct 与 u_time 同向增长。存在占空比上限 d*，超过后任何降级策略都无法把风险压回 ε 以下。系：**能量预算与证据预算在大占空比极限下是同一个预算。**

**定理 30（基底相关下界与 CCA† 的可靠性）**
设真实共模协方差 Σ_S ⪰ 0，模块共享基底。若按独立性融合（ρ=0），则声称方差可严格小于真实方差，安全界失效（给出双传感器同梁反例）。CCA† 取 ρ = max(ρ̂, ρ_floor) 或使用 CMR 残差证书，则声称协方差 ⪰ 真实协方差；因此保守、安全界保持。⇒ **R73 的最大风险（隐共享耦合）在本轮被转成可证伪的 C4，而不是继续当补丁。**

**定理 31（基底证书 ⇒ 系统安全；SUBSTRATE-GAUGE 严格包含 MODGAUGE）**
Valid(J_SUB) ∧ Valid(J_MOD) ⇒ 基底状态在包络内、相关界成立、可调度、热/能量闭合；结合定理 28 ⇒ 物理执行风险 ≤ ε。退化：刚体（J_s = 0 / x_s = 0）+ 理想嵌入（u_age = u_quant = 0，C 为常数，T = T_0）⇒ ρ_floor = 0、CMR 平凡、ECLD 退化为纯质量优化、MBS 退化为固定 WCET；此时 SUBSTRATE-GAUGE 逐指令等于 MODGAUGE，再退化等于 R72/R71/R68。**安全单调不减。**

**定理 32（ECLD 可行域与安全质量下界）**
由引理 41，可行域 {θ : (a)–(f)} 在质量上上闭且闭，故 m* = min 可达；若 m* > m_budget，则该拓扑族内不存在可认证的安全轻量化设计。ECLD 的解在 (质量, ū_struct) 平面上 Pareto 最优。⇒ **「轻多少」第一次有了可证伪的下界，而不是靠工程拍脑袋。**

## 6. 本轮最大风险

**一句话**：本方案把系统安全的最后一道防线押在**共模观测器本身**上——如果观测器模型错了（未建模的屈曲/非线性接触、热敏电阻恰好装在被测热路径里、应变片与被测形变同源），那么 `d_i′ = J_i(x_S − x̂_S)` 里的偏差 `J_i b_S` 会成为**所有模块共享的同一笔误差**；由于它共享，跨模态一致性审计会把「一致的错误」读成「相互印证」，CMR 于是把一个共因误差**洗成了表面上的独立性**——系统比不做校正时更自信地错，而每一步都「有证书、有观测、有扣除」。

次级风险与缓解：
1. **线性弹性模型失效（屈曲/间隙/非线性接触）** → 非线性区在 D 中硬边界；模型失配检测（残差 χ²）触发回退 u_S 上界并禁 PAR。
2. **观测器可观测性不足（应变片稀疏）** → 部署期可观测性检查；不足则只给上界、不扣除，CMR 自动降为「保守 ρ_floor 模式」。
3. **观测器与被测量同源（共模自举）** → 观测器必须**物理独立**（不同传力路径/不同热节点/独立时钟）；同源即判为不可用于 CMR，只作旁路审计。
4. **时序分析过悲观导致设计不可行** → 用带尾界的 pWCET（pWCET 仍须 sound）+ 测量校准；悲观只影响 m* 保守性，不破坏安全性。
5. **ECLD 过保守（禁掉所有轻量化）** → 增加设计自由度（多材料、点阵、主动阻尼、拓扑），并对 𝒳 做鲁棒优化而非单点。
6. **热时间常数与控制带宽交叉（快占空比）** → 占空比变化率限幅；把 d_c 写进 J_SUB，超限即降级。
7. **主张膨胀（C1–C4 四条）削弱论文聚焦** → 严格 CPB；C4 预注册、单点消融；附件不进正文。
8. **MB4 过拟合** → 密封保持集 SEAL-MB4 + 预注册 + 三方复现（E410）。

> - **SG / SMS**：基底图（机械/计算/热/电四类节点）+ 模块绑定 σ + 基底状态 x_S；「无基底绑定不入图」；
> - **SCM**：结构五分量畸变（static/dyn/thermo/hyst/fatigue）+ 一阶可观测性 + χ_load；结构柔度是**可校正**的，不是只能被界住的；
> - **TEM**：证据年龄/抖动/量化/热节流四分量 + 资源需求契约（C,T,D,M,E）+ 数值确定性类；「时间即不确定度」；
> - **CMR**：用应变/IMU/温度/时钟作基底观测器，把 R73 的 PAR 独立性**假设**改写为可测量的**证书条件**；
> - **CCA†**：共享基底不得按独立融合；相关性下界 ρ_floor + 共模残差证书 + σ-不相交；
> - **ECLD**：证据约束轻量化设计，给出安全质量下界 m* 与「计量比刚度」；
> - **MBS / SAD**：计量预算调度 + 基底原子降级（σ-上闭组 stub，堵死共因误信）。
>
> 核心命题：**证据的可信度不只由传感器与契约决定，还由承载它的物质基底（结构柔度）与计算基底（时序/能量/数值）决定；基底必须作为可观测、可预算、可组合的一等对象。**
>
> IP 编号：IP-303~309（共 7 个）+ R73 组件的 † 化；主张增至 C1†–C4（C4 为新可证伪主张：基底共因界）。理论姿态：**新基底是旧契约的严格泛化，刚体+理想嵌入下逐指令退化为 MODGAUGE，安全侧只增不减。**

## 2. 形式化定义（要点版）

**定义 383（总览与六不变式）** 契约完整性（EC 增 σ_i、N_i）/ 组合单调性 / 反作用通道完备（χ_R, χ_load, χ_S）/ 基底绑定完备（无绑定不入图；未覆盖节点须计入 u_S）/ 主张绑定（C1†–C4）/ 严格退化链扩展（基底原子降级 σ-上闭，安全只增不减）。

**定义 384（基底图 SG）** 四类节点 + 四种耦合边（load-path/interference/conduction/draw）；σ 绑定；x_S 由应变/IMU/热敏/PMU 观测；运行包络 𝒳 为契约字段，超包络即降级。

**定义 385（SCM）** 结构状态 x_s（n_s≤24）由线性化动力学驱动；传感器位姿一阶畸变 J_i x_s；五分量 u_struct；有效域含模态抗混叠（f_1≥2f_s 或排除共振动作集）；χ_load 输出**可校正的偏差预测**而非仅保守界。与 u_calib 的区别：结构快变、状态性、可在线观测；标定慢变、参数性、无外部基准不可观测。

**定义 386（TEM）** 快照年龄 τ、采样抖动、量化误差、热节流时效四分量；u_time = 其平方和开方；数值确定性类决定审计能否逐位复算；资源需求契约 + 温度相关 WCET C_i(T)；计量可调度判据 τ_i≤τ_i^max ∧ ΣC_i/T_i≤U_max ∧ T≤T_max。

**定义 387（基底相关下界）** d_i=J_i x_S+n_i ⇒ Cov(d_i,d_j)=J_iΣ_SJ_j^T；ρ_floor 取共享节点耦合增益的最大值；安全只关心同向共模（会伪装成相互印证）。

**定义 388（CMR）** x̂_S=E[x_S|y_S]，Σ_e=(I−KH)Σ_S；d_i′=J_i e_S+n_i；残余相关 = J_iΣ_eJ_j^T；独立性证书条件；观测器失效 ⇒ 回退 ρ_floor 且禁 PAR。**CMR 买的是估计残差，不是消除共因。**

**定义 389（ECLD）** min m(θ) s.t. 刚度/抗混叠/证据预算/相关预算/热/J_SUB；计量比刚度 M_eff；安全质量下界 m*；由引理 41 可行域质量上闭，故 m* 良定义。

**定义 390（J_SUB）** 应变覆盖 + 模态包络 + 热包络 + 可调度性 RTA 片段 + CMR 残差 + 能量闭合 + 数值类；J_SUB 管「基底允许什么」，与 J_MOD 正交。

**定义 391（SAD）** 失效粒度下沉到基底节点；σ-上闭组 stub；即使单模块读数正常也随共享基底一起降级，堵死共因误信；σ-不相交模块继续。

**定义 392（CCA†）** SER：u_out ≥ u_A+L_B u_A+u_S，D 交含 D_S；PAR：conformal ∧ \|ρ̂\|<ρ_max ∧（σ-不相交 ∨ CMR 证书），否则按 max(ρ̂,ρ_floor) 保守融合并加 I⊥；VETO：有效性合取 + 基底冲突否决。

**定义 393（χ_S 与慢回路）** (a, duty) ↦ 功率 ↦ 热 ↦ (降频/热膨胀/模态漂移) ↦ (Δu_time, Δu_struct, D′)；正常占空比下准静态（|ẋ_S|≤ν_S），超过 d_c 时时间尺度分离失效；基底反作用预算 E_total、ΔT_head。

**定义 394（MBS）** 以最小化证据陈旧度为目标分配周期；不可行时按 ERVOI 价值升序降级；由引理 40，时间维度不满足模块可加性，必须靠调度证书恢复。

**定义 395（CPB† + AIC-SUBSTRATE）** C1†←(DPEM,DMEM,SCM)；C2†←(ΣREFLEX,ERVOI,PVOP,χ_load,χ_S)；C3†←(MMS,CCA†,J_MOD,J_SUB)；C4←(SG,SMS,CMR,MBS)。C4 预注册指标：相关低估率、安全界违例率、m*/m_budget。威胁面：谐振激励/热节流 DoS/时钟欺骗/应变伪装/定点位翻转。

```python
# IP-303 SG/SMS：基底图与绑定
@dataclass(frozen=True)
class SubstrateBinding:
    nodes: FrozenSet[str]                  # σ_i
    J: np.ndarray                          # ∂(证据参数)/∂x_S
    coupling: Dict[str, float]             # 节点耦合增益 g_v

class SubstrateGraph:
    def bind(self, module, sigma):
        assert sigma.nodes, "无基底绑定的模块不得入图"
        self.binding[module] = sigma
    def shared(self, a, b): return self.binding[a].nodes & self.binding[b].nodes
    def rho_floor(self, a, b):
        return max((self.nodes[v].coupling for v in self.shared(a, b)), default=0.0)

# IP-304 SCM：结构柔度计量（200Hz）
class StructuralComplianceMetrology:
    def update(self, strain, imu, torque, q, payload):
        x_s, P_s = self.ekf.predict_update(strain, imu, torque, q, payload)
        alias = (self.first_mode(x_s) < 2*self.f_s) and self.excite_overlaps_mode(q)
        b = (self.u_static(x_s), self.u_dyn(x_s), self.u_thermo(x_s),
             self.u_hyst(x_s), self.u_fatigue(x_s))
        return StructEvidence(x_s=x_s, cov=P_s, u=math.sqrt(sum(v*v for v in b)),
                              breakdown=b, valid=(max(abs(x_s))<=self.x_max and not alias),
                              chi_load=self.chi_load(q, payload))   # 定义 385

# IP-305 TEM：时序-能量计量（1kHz 旁路）
class TimingEnergyMetrology:
    def update(self, t_emit, t_consume, util, temp, quant_step, cond):
        tau = t_consume - t_emit
        u_age = math.sqrt(tau*self.q_diag + (self.rho_clk*tau)**2)
        u_jit = self.v_rel*self.J_samp/math.sqrt(12)
        u_q   = quant_step/math.sqrt(12)*cond
        u_th  = self.dC_dT*max(0.0, temp-self.T0)
        return TimingEvidence(u=math.sqrt(u_age**2+u_jit**2+u_q**2+u_th**2),
                              breakdown=(u_age,u_jit,u_q,u_th),
                              stale=(tau>self.tau_max),
                              sched=self.check_schedulable(util, temp))   # 定义 386

# IP-306 CMR：共模观测与抑制（把独立性变成证书）
class CommonModeRejection:
    def observe(self, y_S):
        return self.observer(y_S)                     # (x_hat, Sigma_e)
    def correct(self, ev, J, x_hat):
        return ev.corrected(delta=J @ x_hat)          # d_i' = d_i - J_i x_hat
    def independence_cert(self, i, j, J_i, J_j, Sigma_e, rho_max):
        if not self.sg.shared(i, j): return True      # σ-不相交
        cross = J_i @ Sigma_e @ J_j.T
        return norm(cross) <= rho_max*math.sqrt(sigma_i2*sigma_j2)   # 定义 388

# IP-307 CCA†：共享基底不得按独立融合
def compose_substrate(a, b, op, sg, cmr, audit):
    if op == 'SER':
        return Ev(u=a.u+lipschitz(b,a.u)+a.u_S+b.u_S,
                  D=a.D & b.D & a.D_S & b.D_S, veto=a.veto | b.veto)
    if op == 'PAR':
        r = cross_modal_residual(a, b)
        if audit.conformal_covers(r) and abs(audit.rho_hat(a,b)) < RHO_MAX:
            if not sg.shared(a.id, b.id):
                return fuse(a, b, audit.rho_hat(a,b))          # σ-不相交
            if cmr.independence_cert(a.id, b.id, a.J, b.J, cmr.Sigma_e, RHO_MAX):
                return fuse(a, b, audit.rho_hat(a,b))          # CMR 证书
            return fuse(a, b, max(audit.rho_hat(a,b), sg.rho_floor(a.id,b.id)))
        return Ev(u=max(a.u,b.u), D=a.D & b.D,
                  veto=a.veto | b.veto | {'PAR_AUDIT_FAIL'})
    if op == 'VETO':
        if a.veto or b.veto: return Ev(valid=False, veto=a.veto|b.veto)
        if not sg.substrate_consistent(a,b): return Ev(valid=False, veto={'SUBSTRATE_CONFLICT'})
        return Ev(u=min(a.u,b.u), D=a.D & b.D)

# IP-308 ECLD：证据约束轻量化设计（离线）
def ecld_optimize(topology, envelope, tau_struct, rho_max):
    def feasible(t):
        return (deflection(t,envelope) <= DELTA_MAX and first_mode(t) >= 2*F_S
                and max_u_struct(t,envelope) <= tau_struct
                and (rho_floor(t) <= rho_max or cmr_cert(t))
                and delta_T(t,envelope) <= DT_MAX)
    return min((t for t in topology.candidates() if feasible(t)), key=mass)  # m*

# IP-309 MBS：计量预算调度（时间即不确定度）
def metrological_schedule(modules, tau_max, U_max):
    order = sorted(modules, key=lambda m: -m.evidence_value)
    periods = allocate_periods(order, lambda T,U: u_time(T,U) <= tau_max)
    if utilization(periods) > U_max or not periods:
        for m in sorted(modules, key=lambda m: m.evidence_value):
            m.degrade()                                   # 低价值先 stub/降采样
            if utilization(realloc(modules)) <= U_max: break
    return periods

# IP-300† SUBSTRATE-GAUGE 主闭环（在三域外增加基底旁路）
def SUBSTRATE_round(M, obs, audio, tac, depth):
    # === 基底旁路（100Hz）：先观测基底，再谈证据 ===
    x_S, Sigma_e = M.cmr.observe(M.y_S)                    # 应变/IMU/热/PMU
    s_ev = M.scm.update(M.strain, M.imu, M.torque, M.q, M.payload)
    t_ev = M.tem.update(M.t_emit, M.now(), M.util, M.temp, M.dq, M.cond)
    if not s_ev.valid or not t_ev.sched: M.sad.degrade_group(x_S)   # σ-上闭组 stub
    # === 感知域（100Hz）===
    d_ev = M.dpe.update(depth, rgb, M.cam_state, M.motion, M.peers)
    d_ev = M.cmr.correct(d_ev, M.sg.binding['DPEM'].J, x_S)         # 共模扣除
    if not d_ev.valid or t_ev.stale: d_ev = stub(M.dpe)
    # === 计量域（50Hz）===
    if M.clock.due_metric():
        b_t = M.bse.step_full(..., d_ev=d_ev, t_ev=t_ev, s_ev=s_ev)
        M.mbs.reallocate(M.mods)                            # 时间即不确定度
        M.mreg.audit_substrate(M.sg)                        # 组合+基底合法性
    # === 控制域（1kHz，只读快照）===
    snap = M.snapshot.read_latest()
    lam = embodied_risk_scale(snap.U_ale, snap.U_epi, snap.H_z,
                              max(snap.t_ev.u, snap.d_ev.u, snap.s_ev.u), M.risk)
    return M.c_ras_wm.certified_prefix(M.ach.propose_ctrl(...), lam), J_SUB(M), J_MOD(M)
```

## 4. 推导

**引理 38（结构畸变的一阶可观测性）** 包络内 (H_s,A_s) 可观测且 Gramian 非奇异 ⇒ J_s x_s 可辨识，残差由 Σ_e 界定。系：结构柔度可校正，标定漂移只能被界住。

**引理 39（CMR 残余相关界）** d_i′=J_i e_S+n_i ⇒ |ρ_ij′| ≤ ‖J_i‖‖J_j‖‖Σ_e‖/(σ_i′σ_j′)。⇒ 独立性从假设改写为证书条件；这是修正 R73 PAR 独立性的唯一非保守手段。

**引理 40（时间即不确定度 / 时间维不可加性）** u_age 关于 τ 单调；固定 CPU 预算下新增模块抬高 U 与队列时延，故共居模块 u_time 上升。⇒ 「新模块=零改动」在时间维度不成立，须由 MBS 证书恢复。

**引理 41（轻量化计量代价单调性）** 固定材料/拓扑族内减质量 ⇒ 静柔度升、f_1 降 ⇒ ū_struct 升；证据预算与抗混叠给出质量下界 m*>0。⇒ 纯刚度-重量优化可能过刚度检验却过不了安全。

**引理 42（热-结构-时序共同单调性）** 占空比↑ ⇒ 温度↑ ⇒ 柔度↑ 且 WCET↑ ⇒ u_struct 与 u_time 同向增长；存在 d*，超过后任何降级都压不回 ε。⇒ 大占空比极限下能量预算与证据预算是同一个预算。

**定理 30（基底相关下界与 CCA† 可靠性）** 共享基底上按独立性融合会低估方差（双传感器同梁反例）；CCA† 取 ρ=max(ρ̂,ρ_floor) 或 CMR 残差证书 ⇒ 声称协方差 ⪰ 真实协方差，安全界保持。⇒ R73 的「风险 5」被转成可证伪的 C4。

**定理 31（基底证书 ⇒ 系统安全；严格包含 MODGAUGE）** Valid(J_SUB) ∧ Valid(J_MOD) ⇒ 包络内、相关界成立、可调度、热/能量闭合；结合定理 28 ⇒ 风险 ≤ ε。刚体（J_s=0）+ 理想嵌入（u_age=u_quant=0，C 常数，T=T_0）⇒ ρ_floor=0、CMR 平凡、ECLD 退化为质量优化、MBS 退化为固定 WCET；逐指令等于 MODGAUGE，再退化等于 R72/R71/R68。安全单调不减。

**定理 32（ECLD 可行域与安全质量下界）** 由引理 41，可行域在质量上上闭且闭，m* 可达；m*>m_budget ⇒ 该拓扑族内无安全轻量化设计；ECLD 解在 (质量, ū_struct) 上 Pareto 最优。⇒ 「轻多少」第一次有可证伪下界。

## 7. 本轮最大风险

**一句话**：整个方案的最后一环押在**共模观测器本身**——若观测器模型失真（未建模屈曲/非线性接触）或与被测量同源（热敏电阻就在被测热路径、应变片与被测形变共用传力路径），那么 `d_i′ = J_i(x_S − x̂_S)` 中的共享偏差 `J_i b_S` 会被跨模态一致性审计读成「相互印证」，CMR 反而把一个共因误差洗成表面上的独立性，使系统比不做校正时更自信地错——而每一步都「有观测、有扣除、有证书」。

次级风险与缓解：
1. **线性弹性模型失效** → 非线性区硬边界 + 残差 χ² 检测触发 u_S 上界回退并禁 PAR。
2. **可观测性不足（应变片稀疏）** → 部署期可观测性检查；不足则只上界、不扣除，自动降为保守 ρ_floor 模式。
3. **观测器与被测量同源** → 观测器须物理独立（不同传力路径/热节点/时钟）；同源只作旁路审计、不得用于 CMR。
4. **时序分析过悲观** → 带尾界的 pWCET + 测量校准；仅影响 m* 保守性，不破坏安全性。
5. **ECLD 过保守** → 多材料/点阵/主动阻尼/拓扑自由度；对 𝒳 做鲁棒优化。
6. **热时间常数与控制带宽交叉** → 占空比变化率限幅，d_c 写入 J_SUB，超限即降级。
7. **主张膨胀（C1–C4）** → 严格 CPB + C4 预注册单点消融；附件不进正文。
8. **MB4 过拟合** → SEAL-MB4 + 预注册 + 三方复现（E410）。
