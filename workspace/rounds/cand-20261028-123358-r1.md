# 第 11 轮 · GEO-RESIDUAL：用动作条件化的三维残差，把接触、滑移和人为编辑分开

> 检索/复核日期：**2026-10-28（UTC）**。赛事身份不变：宇树 **UniBot 世界挑战赛**（unibot.unitree.com），G1 + Dex1，32 项桌面任务，通才单模型赛道，选手自部署 + 官方远程真机 API。本轮三个灵感词是「轻量化结构」「ROS2」「姿态估计」。本轮不推倒第 10 轮 FACT-VLA，而是把它最弱的一环——**标量视觉接触代理 + 手工相位标签**——换成米制、动作条件化、可在线运行的三维残差观察器。

## 0. 先给结论：不要只问“有没有接触”，要问“场景的运动能否被机器人自己的动作解释”

官方 API 没有力、没有触觉、没有深度图；但它给了**左右两路已校正的头部相机**，数据集又给了双目内参、双目 R/T、基线、以及 `state_d435`（头相机在 base 系的位姿）。这三样东西足够做一件比“再学一个接触分类器”更硬的事：

1. 用 t 到 t+1 的双目点云，估计夹爪附近场景的刚体位姿变化 `T_obj`；
2. 用已知的 EE 位姿变化 `ΔT_ee` 预测两种解释：物体静止 `I`，或物体随夹爪刚性运动 `ΔT_ee`；
3. 残差 `r_static = ||log(T_obj)||`、`r_grasp = ||log(ΔT_ee⁻¹ T_obj)||`；
4. 机器人能解释的运动是自由空间/抓取；解释不了的那部分，才是接触约束、滑移或人为编辑。

一句话：**接触不是学出来的隐变量，而是“机器人动作解释不了的三维残差”。**

这带来三个直接好处：

- **米制**：不是“接触 logit 0.73”，而是“夹爪到表面 4.2 mm、法向是 +z、物体相对夹爪滑了 8 mm”；
- **可解释**：自由、接近、接触、抓取、搬运、释放、滑移、外部编辑，都能在同一组几何量上分开；
- **轻量**：双目 SGBM + 局部 ICP + 表面法向，全是确定性几何，不新增第二个学习模型；CPU 即可，适合 N 端口并发。

## 1. 本轮新核实的事实（只列会改变方案的）

### 1.1 规则：单模型、32 任务、10 次/任务、5 类泛化各 2 次

官方参赛手册（2026-10-28 重新抓取）明确：

- 所有任务须基于**同一模型**完成，不得混合多个模型一起测试；模型类型不限（World Model、VLA 均可）。
- 32 个任务，每个任务 10 次独立运行；5 类泛化各 2 次：位置、干扰物、桌面背景、未见物品、人为干扰。
- 单次真机执行上限 180 s；排名先看 32 任务总平均成功率，成功率相同看总平均步骤分，再相同看更早提交。
- 评测跨 **N 台机器人**，提交须从 8765 起暴露 N 个连续端口；每端口独立完成交互，`reset()` 状态必须隔离。

这决定了 GEO-RESIDUAL 的形态：**不能是第二个策略模型；必须是每端口独立、CPU 轻量、不抢 GPU 的观察器。** 如果规则对“模型”作最宽解释，观察器只保留离线标注模式（C1），或把残差作为同一 checkpoint 的输入特征（C3）。

### 1.2 API：四路 RGB、无深度/力/触觉，但双目已校正

提交模板（2026-10-28 复核）给出：

- 观测：`cam_left_high`、`cam_right_high`、`cam_left_wrist`、`cam_right_wrist` 四路 RGB 480×640；双臂关节 `[7]`、EE 位姿 `[6]`（xyz+rpy，base 系）、夹爪 `[1]`、下身体 `[15]`、语言 `str`。
- 动作：`joint` 或 `ee` 互斥；`action_chunk_size` 固定；`meta.token` 每次 `get_action` 都要带。
- `obs_delta_indices` 决定传哪些键、堆叠几帧；`image_resize` 可缩放。**没有 depth、没有 camera_info、没有 force/torque/tactile。**
- 评测端逐调用记录延迟、波动和动作统计规律，作为结果可信度的一部分。

关键点：**左右高位相机是同一台头部双目的已校正图像**，不是两个无关视角。官方数据 `meta/info.json` 的 `camera_params.head_stereo` 给了 `camera_matrix_left/right`、`dist_coeffs_left/right`、`R`、`T`，并显式写 `rectified: true`。示例 HangCup 的基线约 **58.25 mm**，焦距约 **282 px**，图像 480×640。这个基线在 0.5–1.0 m 工作距离上对应约 16–33 px 视差，足够做毫米级局部深度。

### 1.3 数据：33,276 条 / 169.28 h，32 任务，94 个评分步骤

32 个 HF 数据集合计（2026-10-28 逐数据集读取 `meta/info.json`）：

| 项 | 数值 |
|---|---:|
| episodes | **33,276** |
| frames | **18,282,246** |
| 时长 | **169.28 h**（30 fps） |
| 任务数 | 32 |
| 评分步骤总数 | 94 |

| 示例 HangCup | 1,043 episodes / 194,564 frames |

任务文本里至少 **17/32** 明确出现插入、拔出、拧、拉拉链、合盖、倒、夹等接触动词；其中 10 个任务的终局就是插/拔/拧/拉链/合盖/锁。接触不是少数任务的特例，而是通才模型的主战场。

### 1.4 头相机位姿在数据里是可恢复的

`meta/info.json` 的特征里有 `observation.state.state_d435`（头相机在 base 系的 6D 位姿）和 `waist_state_joint`（3 维腰部关节）。实测 HangCup 第一帧：

```text
state_d435 = [0.13014, 0.01778, 0.45645, -0.00704, 1.01141, -0.01591]
waist_state_joint = [-0.00995, -0.00373, 0.18065]
lower_body[-3:] = [-0.00995, -0.00373, 0.18065]
```

也就是说：**`lower_body` 的最后 3 维就是腰部关节**，而 `state_d435` 随腰部/躯干缓慢变化。线下可以用这 33k 条数据拟合 `T_base_head = f(lower_body[-3:])`，或用 G1 URDF 的正运动学直接算；线上 API 虽不给 `state_d435`，但给 `lower_body`，因此头相机外参**可以在线恢复**。这是本轮最关键的可执行性事实。

补充验证（HangCup ep1042，6 帧）：按数据里固定的轴约定把 `left_ee_pose_gripper_base` 投影回左目，5/6 帧落在夹爪附近，投影点深度与 SGBM 深度的中位误差 **4.1 cm**；1 帧因深度空洞/背景失败。这说明 `state_d435` 可以作为头部双目外参的起点，但仍需逐机器人做一次重投影校准（G0），不能直接假设零误差。

### 1.5 排行榜仍是占位，步骤分不是独立测量

`leaderboard_data.json` 的 `generated_from` 仍是 `gen_leaderboard.py`；8 个模型 ×32 任务的 step score 对 success rate 逐模型回归，`R² > 0.999999`，最大残差 <0.006，形式是 `step ≈ k_model × success`。这不是“步骤分和成功率相关”，而是脚本写出来的线性缩放。榜单只能当难度先验，不能当 SOTA 证据，也不能用来推断失败分布。

### 1.6 人为干扰是“外部三维编辑”，不是随机噪声

32 个任务的 `generalization.human_1_note` / `human_4_note` 里，至少 **7 个任务**明确是“先完成再撤销”：插头拔起、拉链拉开、盖子拧回、毛巾翻开、笔盒打开、锁拿走、叠好的碗拿走。更多任务是平移目标、平移容器、拿走物体、把传送带目标放回起点。它们的共同点是：

> **机器人的动作解释不了这些物体运动。**

这正是 GEO-RESIDUAL 的定义。它不需要识别“人”，也不需要知道 human_1 对应第几次 trial；它只需要检测“局部场景发生了机器人动作无法解释的刚体变化”。

## 2. 为什么这是 FACT-VLA 缺的那一块，而不是又一个外挂

第 10 轮 FACT-VLA 的四层——FACTOR 接触代理、CPT 相位化 BC、CAC 柔顺执行、EGP 证据门控——方向是对的，但有一个结构性弱点：

| FACT-VLA 现状 | 问题 | GEO-RESIDUAL 的替换 |
|---|---|---|
| FACTOR 用夹爪滞止 + 视觉接触 logit | 2D、无尺度、任务相关、阈值难迁移 | 米制表面距离 + 法向 + 刚体残差 |
| CPT 相位标签靠人工抽检 200 帧 | 贵、不可复现、跨任务不一致 | 由 `d_t / r_t / 夹爪` 自动分段 |
| CAC 只按标量接触分数缩动作 | 不知道往哪个方向让 | 用法向/切向分解做方向性柔顺 |
| 人为干扰靠状态机/视觉变化 | 难以区分“机器人自己动的”与“外部动的” | 动作条件化残差直接分离 |
| 视觉接触 logit 不可校准 | 无法报告物理误差 | 毫米/度、重投影误差、深度有效比 |

换句话说：**FACT-VLA 已经有“相位”这个概念，但相位的观测量不够硬。GEO-RESIDUAL 把相位从“学出来的标签”变成“量出来的几何”。**

## 3. 方法：ACGR（Action-Conditioned Geometric Residual）

### 3.1 米制局部点云

- 输入：`cam_left_high`、`cam_right_high`（已校正）、`left/right_ee_pose_gripper_base`、`left/right_gripper`、`lower_body`。
- 用 SGBM/BM + 左右一致性检查得到视差，转深度：`Z = f B / d`；反投影得头部系点云，再用 `T_base_head` 转到 base 系。
- 只保留夹爪周围 **15–20 cm** 的 ROI，去掉桌面主平面（RANSAC）和机器人自身点（URDF 胶囊/网格投影掩码）。
- 得到局部场景点云 `P_t`，以及夹爪两个指尖点 `p_l,t, p_r,t`。

### 3.2 动作条件化的两种解释

对 `P_t` 和 `P_{t+1}` 做局部 point-to-plane ICP，得到场景刚体变换 `T_obj`。同时由 EE 位姿得到 `ΔT_ee = T_ee,t+1 T_ee,t⁻¹`。定义两个残差：

```text
r_static(t) = || log(T_obj) ||_W
r_grasp(t)  = || log(ΔT_ee⁻¹ T_obj) ||_W
```

其中 `||·||_W` 对平移和旋转分别归一化（例如平移用米，旋转用弧度乘特征长度）。解释：

| 观测 | 解释 |
|---|---|
| `r_static` 小、`r_grasp` 大 | 物体静止：自由空间/未抓住 |
| `r_static` 大、`r_grasp` 小 | 物体随夹爪动：抓取/刚性接触 |
| 两者都大 | 滑移、约束接触、或外部编辑 |
| 机器人几乎不动、`T_obj` 大 | 人为编辑/物体被拿走 |
| 机器人动、`T_obj` 方向与 `ΔT_ee` 不一致 | 接触约束/滑移/外部干扰 |

对“两者都大”的歧义，用**方向余弦**和**时间持续性**再分：

- `cosθ = <t_obj, t_ee> / (||t_obj|| ||t_ee||)`；外部编辑/滑移通常 `cosθ` 低；
- 人类编辑是阶跃式变化，滑移是渐进式变化；用 3–5 帧的 CUSUM/变化点检测区分；
- 若深度无效或点云太少，退回 FACTOR 的夹爪滞止 + 视觉接触。

### 3.3 表面距离与方向性柔顺

对每个指尖，取局部点云中最近点，得到：

- `d_t`：指尖到表面的最近距离（米）；
- `n_t`：最近点局部平面的法向（base 系）；
- `v_n = <Δp_ee, n_t>`：夹爪沿法向的位移；
- `v_t = Δp_ee - v_n n_t`：切向位移。

接触判据不是单一阈值，而是：

```text
contact  ⇔  d_t < δ_c  且  v_n > 0  且  d_t 的下降率 ≈ 0
free     ⇔  d_t > δ_f  且  v_n > 0
insert   ⇔  d_t ≈ δ_c  且  沿插入轴的位移继续增加，但法向距离不降
```

执行时：

- 接触段把动作分解为 `a = a_n n + a_t`；对 `a_n` 缩幅/低通，对 `a_t` 保留以做表面对齐；
- 若 `d_t` 卡在 `δ_c` 且 `|a_n|` 持续大于阈值，触发小回撤 + 重对齐；
- 若 `r_grasp` 突然变大、`r_static` 也大，判定滑移，重抓；
- 若机器人空闲而 `T_obj` 大，判定外部编辑，暂停/重观测/重做受影响步骤。

这就是“方向性柔顺”：不只是“接触了就慢一点”，而是“沿法向让、沿切向找”。

### 3.4 自动相位标签

用 `d_t`、`ḋ_t`、`r_static`、`r_grasp`、夹爪开度、EE 速度，过一个带迟滞的规则状态机（可选 HMM 平滑）：

```text
P0 free       d_t > δ_f, r_static 小
P1 approach   ḋ_t < 0, d_t 下降
P2 contact    d_t ≤ δ_c, ḋ_t ≈ 0
P3 grasp      gripper 闭合, r_grasp 小, r_static 大
P4 transport  gripper 闭合, r_grasp 小, EE 速度大
P5 release    gripper 打开, r_grasp 上升, r_static 回落
E  edit       robot idle 或方向不一致, T_obj 大, 持续 K 帧
```

这些标签直接喂给 FACT-VLA 的 CPT，替代人工 200 帧抽检；人工只保留每任务 1–2 条做验证，报告边界 F1，而不是“看起来对”。

### 3.5 与 FACTOR 融合

最终接触分数不再是一个黑箱 logit，而是：

```text
c_t = σ( α g_t + β v_t + γ (1 - d_t/δ_f) + η r_static_norm )
```

其中 `g_t` 是夹爪滞止，`v_t` 是视觉接触，`d_t` 是米制距离，`r_static_norm` 是物体开始随动的证据。深度无效时自动退化为 `α g_t + β v_t`；融合权重用成功演示的分位数校准，不手调全局阈值。

## 4. ROS2 运行时：观察器不是提交接口，是本地“几何裁判”

官方评测只认 `PolicyService` 的 Python 接口，不认 ROS2。因此 ROS2 只做**本地运行时/回放/隔离**，不改变提交协议：

```text
/cam_left_high  /cam_right_high  /joint_states  /ee_pose
        │              │               │            │
        └──────────────┴───────┬───────┴────────────┘
                               ▼
                    /geo_residual/observer
                    ├─ stereo_depth (SGBM, ROI)
                    ├─ robot_mask (URDF + joint_states)
                    ├─ local_icp (T_obj)
                    ├─ surface_distance (d_t, n_t)
                    └─ phase_posterior / edit_event
                               │
                               ▼
                    PolicyService (唯一学习模型)
                    └─ FACT-VLA: CPT / CAC / EGP
```

- `tf2` 管 `base → head`；`image_geometry` 管去畸变/反投影；`pcl`/Open3D 管 ICP；`ros2 bag` 管 33k 演示的回放。
- 观察器 30 Hz、固定 ROI、预分配缓冲；目标 p99 < 33 ms。若超预算，降到 15 Hz 并做时间插值，**绝不阻塞 `get_action`**。
- N 端口：每端口一个观察器实例/命名空间，只共享只读的标定和 URDF；`reset()` 清空局部地图、ICP 初值、相位后验。
- 回放：把官方 parquet/video 转成 ROS2 bag，离线跑同一套节点；这样“训练期标签”和“推理期观察”是同一份代码，避免离线/在线不一致。

## 5. 保留、升级、剪枝

**保留**：

- FACT-VLA 的 CPT 相位化 BC、CAC 柔顺执行、EGP 证据门控；
- 夹爪滞止 `g_t` 和视觉接触 `v_t` 作为低置信度回退；
- 33k 成功演示、官方 rubric、官方 human 备注。

**升级**：

- FACTOR：标量 `c_t` → 向量 `(d_t, n_t, r_static, r_grasp, edit_score)`；
- CPT：手工相位标签 → 几何自动标签 + 少量人工验证；
- CAC：标量缩幅 → 法向/切向分解的方向性柔顺；
- EGP：只分配 trial → 增加“编辑事件”后的恢复预算。

**剪枝**：

- 不做力/触觉闭环（API 与数据都没有）；
- 不做独立 6D 物体位姿网络（需要物体模型/检测，透明/可变形物体不可靠）；
- 不做第二个学习模型（观察器无学习权重）；
- 不做完整世界模型/MPC（延迟和 sim gap 不划算）；
- 不再以人工 200 帧相位标签为主路径；
- 不把占位排行榜当 SOTA 或难度表。

## 6. 先写死的实验门

| 门 | 问题 | 通过标准 | 失败动作 |
|---|---|---|---|
| G0 | 双目深度在 0.4–0.9 m 是否可用？ | 有效像素 ≥70%；夹爪重投影误差 ≤10 mm | 只用腕部视觉 + 夹爪滞止 |
| G1 | 接触检测是否准？ | 对人工接触标签 AUROC ≥0.85 | 退回 FACTOR 标量 |
| G2 | 相位自动标签是否准？ | 边界 F1 ≥0.75；跨任务不崩 | 只用 grasp/free 两相 |
| G3 | 抓取/滑移是否分得开？ | `r_grasp` vs `r_static` AUROC ≥0.80 | 只做抓取，不做滑移 |
| G4 | 人为编辑能否检出？ | 合成编辑 AUROC ≥0.85；正常集误报 ≤5% | 只做离线标注，不线上触发 |
| G5 | 方向性柔顺是否涨成功率？ | 接触密集任务 +5pp；自由任务不回归 | 只保留相位标签，不做控制 |
| G6 | 延迟是否可接受？ | p99 ≤33 ms；timeout 不升 | ROI 降采样/15 Hz/关闭 |

所有门先在离线回放和单任务不计分通道上过；没有过门，不烧正式提交。

## 7. 比赛算术：它到底值多少

- **人为干扰轴**占 20%（32×2=64 trials）。如果编辑检测 + 恢复把 human 轴成功率从 `p_h` 提到 `p_h+10pp`，全局约 **+2pp**。
- **接触密集任务**至少 17/32；如果其中 10 个终局接触任务 +5pp，全局约 **+1.6pp**；若 17 个都 +5pp，约 **+2.7pp**。
- **步骤分**只做同分决胜；自动相位标签更可能提高“步骤完成判定”的一致性，边际价值在平台期。
- 两项都成立时，乐观估计 **+3–5pp 全局**；但 320 trials 的单次标准误约 2.6pp，必须任务配对、bootstrap、多次独立回放，不能把 +1–2pp 当结论。

真正的主收益不是“多一个模块”，而是：**把 FACT-VLA 的接触相位从不可校准的隐变量，变成可复现、可解释、可离线验证的几何量。**

## 8. 风险与合规

- **透明/反光/可变形物体**：双目在药瓶、试管、杯子、毛巾上可能失败；用左右一致性置信度 + 腕部视觉 + 夹爪滞止回退，必要时只对刚体任务启用。
- **机械臂自遮挡**：头相机从上往下看，夹爪可能挡住物体；用 URDF 掩码 + ROI + 多帧置信度，遮挡严重时回退。
- **标定漂移/换机器人**：用 `state_d435` 离线拟合 + `lower_body[-3:]` 在线恢复；若重投影误差大，用夹爪已知 3D 点做一次 PnP 自标定；仍失败则关闭观察器。
- **单模型解释**：观察器是确定性几何 + URDF + 标定，没有学习权重；若官方把任何辅助模块都算“模型”，提供 C1 离线标注模式，或把残差作为同一 checkpoint 的输入特征（C3）。
- **延迟抖动**：观察器独立线程、固定 ROI、丢帧不阻塞；p99 不过门就关闭。
- **人类编辑不在头部视野**：用本体/夹爪/任务状态残差兜底；不声称 100% 检测。
- **阈值过拟合**：每任务分位数 + 留出 session + conformal 误报控制；不全局手调一个阈值。

## 9. 一句话押注

**用官方双目和已知 EE 位姿，把“场景运动能否被机器人自己的动作解释”做成米制、动作条件化的三维残差；解释不了的部分就是接触、滑移或人为编辑——用这个轻量、无学习权重的 ROS2 观察器自动标注 FACT-VLA 的相位、做方向性柔顺和编辑恢复，而不是再训一个模型。**

## 2. 问题形式化

### 2.1 符号与坐标系

| 符号 | 含义 |
|---|---|
| `B` | 机器人 base 系 |
| `H` | 头部左目/右目光学系 |
| `P_t` | t 时刻夹爪 ROI 内的局部场景点云（base 系） |
| `T_obj,t` | 从 `P_t` 到 `P_{t+1}` 的刚体变换（局部 ICP） |
| `T_ee,t` | t 时刻 EE 位姿（base 系） |
| `ΔT_ee,t` | `T_ee,t+1 · T_ee,t⁻¹` |
| `d_t` | 指尖到局部表面的最近距离（米） |
| `n_t` | 最近点局部平面法向（base 系） |
| `r_static` | `||log(T_obj)||_W` |
| `r_grasp` | `||log(ΔT_ee⁻¹ · T_obj)||_W` |

`||·||_W` 对平移和旋转分别归一化：平移用米，旋转用弧度乘特征长度 `L`（例如夹爪开度或物体半径），避免量纲混在一起。

### 2.2 动作条件化残差

场景在 t→t+1 的运动只有两种“机器人能解释”的假设：

1. **物体静止**：`T_obj ≈ I`；
2. **物体随夹爪刚性运动**：`T_obj ≈ ΔT_ee`。

于是：

```text
r_static = || log(T_obj) ||_W
r_grasp  = || log(ΔT_ee⁻¹ T_obj) ||_W
```

| 观测 | 解释 |
|---|---|
| `r_static` 小、`r_grasp` 大 | 物体静止：自由空间/未抓住 |
| `r_static` 大、`r_grasp` 小 | 物体随夹爪动：抓取/刚性接触 |
| 两者都大 | 滑移、约束接触，或外部编辑 |
| 机器人几乎不动、`T_obj` 大 | 人为编辑/物体被拿走 |
| `T_obj` 方向与 `ΔT_ee` 不一致 | 接触约束/滑移/外部干扰 |

“两者都大”的歧义用**方向余弦**和**时间持续性**再分：

```text
cosθ = <t_obj, t_ee> / (||t_obj|| ||t_ee||)
```

- 外部编辑/滑移通常 `cosθ` 低；
- 人类编辑是阶跃式变化，滑移是渐进式变化；用 3–5 帧 CUSUM/变化点检测区分；
- 深度无效或点云太少时，退回 FACTOR 的夹爪滞止 + 视觉接触。

### 2.3 可辨识性条件

残差要成立，需要满足：

1. **局部刚性**：ROI 内的物体/桌面在 t→t+1 内近似刚体；可变形物体（毛巾、拉链）会破坏 `T_obj` 的单一位姿假设。
2. **足够几何**：ROI 内有效深度点 ≥ 阈值（例如 300 点），且点分布不退化（不是一条边/一个平面）。
3. **动作可观测**：`ΔT_ee` 来自编码器/EE 位姿，短时间内的噪声小于物体运动。
4. **时间对齐**：图像与 EE 位姿的时间戳误差小于 1–2 帧；否则把 `ΔT_ee` 插值到图像时刻。
5. **外参准确**：`T_base_head` 的重投影误差 ≤10 mm；否则残差被标定误差污染。

失败时不是“硬判”，而是降低置信度并回退。

### 2.4 为什么不是第二个模型

- 观察器没有可学习参数；ICP、SGBM、平面拟合、状态机都是确定性算法。
- 它输出的是**几何量**（米、弧度、法向、有效点比例），不是策略动作。
- 它不改变 `PolicyService` 的接口；只把额外特征/标签喂给同一个 checkpoint。
- 若官方仍认为它是“模型”，走 C1 离线标注或 C3 同 checkpoint 特征，见 §5.3。

## 3. ACGR 流水线

### 3.1 双目深度

- 输入：`cam_left_high`、`cam_right_high`（已校正，无需再去畸变；若 API 缩放，内参按比例缩放）。
- 匹配：SGBM，`numDisparities=64`、`blockSize=5`、`P1=8*3*25`、`P2=32*3*25`、`disp12MaxDiff=1`、`uniquenessRatio=10`、`speckleWindowSize=100`、`speckleRange=2`。
- 后处理：左右一致性检查、唯一性检查、斑点过滤；无效视差置 0。
- 深度：`Z = f B / d`，`f` 用左右目 `fx` 的均值，`B=0.0582526 m`。
- ROI：以左右指尖投影为中心，取 15–20 cm 的 3D 球/图像矩形；只对 ROI 做稠密匹配以省 CPU。
- 质量：`valid_ratio`、`depth_p10/p50/p90`、`plane_residual`；低于阈值时回退。

**Pilot**（HangCup ep1042，左 t=178.5 s，右 t=133.0 s，通过 `meta/episodes` parquet 对齐）：全图有效视差 **62.5%**，中央 ROI **76.9%**，深度 p10/p50/p90 = **0.374 / 1.196 / 6.748 m**。中央 ROI 过 G0 的 70% 线，全图不过；因此线上只对 ROI 做深度，不追求全图。

### 3.2 机器人自掩码

- 用 `lower_body` + 双臂关节 + G1 URDF 做正运动学，得到各连杆在 base 系的位姿。
- 把连杆胶囊/网格投影到左目，得到机器人掩码；膨胀 3–5 px，避免边缘深度污染。
- 头部相机自身、桌面主平面（RANSAC）也从 ROI 去掉；保留物体、夹爪、被操作物。
- 如果 URDF 版本与真机不一致，用一次夹爪 PnP/手眼标定修正；仍不一致则关闭自掩码，改用深度不连续性。

### 3.3 局部点云与 ICP

- 把 ROI 像素反投影到左目系，再用 `T_base_head` 转到 base 系。
- 体素降采样 3–5 mm；法向估计用 2 cm 邻域。
- 点到面 ICP，初值 `T_obj = I`；鲁棒核（Huber，`δ=0.01 m`）；最多 30 次迭代。
- 收敛条件：平移增量 <1 mm、旋转增量 <0.2°；否则标记低置信度。
- 输出：`T_obj`、inlier ratio、残差中位数、协方差（用 J^T J 近似）。
- 退化检测：若点云协方差的最小特征值/最大特征值 <0.02，或法向分布过于集中，判为不可辨识。

### 3.4 残差与方向

```text
r_static = || log(T_obj) ||_W
r_grasp  = || log(ΔT_ee⁻¹ T_obj) ||_W
cosθ     = <t_obj, t_ee> / (||t_obj|| ||t_ee||)
edit_score = f(r_static, r_grasp, cosθ, robot_idle, duration)
```

`edit_score` 的建议形式：

```text
edit_score = σ( a·r_static_norm + b·(1-cosθ) + c·robot_idle - d·r_grasp_norm )
```

权重用成功演示的分位数初始化，再用少量人工编辑片段校准；不手调一个全局阈值。输出是连续分数 + 置信度，不是二值。

### 3.5 表面距离、法向与方向性柔顺

对每个指尖，取局部点云中最近点：

- `d_t`：指尖到表面的最近距离（米）；
- `n_t`：最近点局部平面的法向（base 系）；
- `v_n = <Δp_ee, n_t>`：夹爪沿法向的位移；
- `v_t = Δp_ee - v_n n_t`：切向位移。

接触判据：

```text
contact  ⇔  d_t < δ_c  且  v_n > 0  且  d_t 的下降率 ≈ 0
free     ⇔  d_t > δ_f  且  v_n > 0
insert   ⇔  d_t ≈ δ_c  且  沿插入轴的位移继续增加，但法向距离不降
```

执行：

- 接触段把动作分解为 `a = a_n n + a_t`；对 `a_n` 缩幅/低通，对 `a_t` 保留以做表面对齐；
- 若 `d_t` 卡在 `δ_c` 且 `|a_n|` 持续大于阈值，触发小回撤 + 重对齐；
- 若 `r_grasp` 突然变大、`r_static` 也大，判定滑移，重抓；
- 若机器人空闲而 `T_obj` 大，判定外部编辑，暂停/重观测/重做受影响步骤。

这就是“方向性柔顺”：不只是“接触了就慢一点”，而是“沿法向让、沿切向找”。

### 3.6 自动相位标签

用 `d_t`、`ḋ_t`、`r_static`、`r_grasp`、夹爪开度、EE 速度，过带迟滞的规则状态机（可选 HMM 平滑）：

```text
P0 free       d_t > δ_f, r_static 小
P1 approach   ḋ_t < 0, d_t 下降
P2 contact    d_t ≤ δ_c, ḋ_t ≈ 0
P3 grasp      gripper 闭合, r_grasp 小, r_static 大
P4 transport  gripper 闭合, r_grasp 小, EE 速度大
P5 release    gripper 打开, r_grasp 上升, r_static 回落
E  edit       robot idle 或方向不一致, T_obj 大, 持续 K 帧
```

这些标签直接喂给 FACT-VLA 的 CPT，替代人工 200 帧抽检；人工只保留每任务 1–2 条做验证，报告边界 F1，而不是“看起来对”。

### 3.7 与 FACTOR 融合

最终接触分数：

```text
c_t = σ( α g_t + β v_t + γ (1 - d_t/δ_f) + η r_static_norm )
```

- `g_t`：夹爪滞止；
- `v_t`：视觉接触；
- `d_t`：米制距离；
- `r_static_norm`：物体开始随动的证据。

深度无效时自动退化为 `α g_t + β v_t`；融合权重用成功演示的分位数校准。输出附 `valid_ratio`、`icp_inlier`、`reproj_error`，让下游知道该不该信。

### 3.8 回退链

1. 双目深度 + ICP + 残差（主路径）；
2. 单目深度/光流 + 夹爪滞止（深度无效）；
3. 仅夹爪滞止 + 视觉接触（点云退化）；
4. 仅 FACT-VLA 原策略（观察器超时/标定失败）。

每一级都有明确的触发条件和延迟预算；不允许观察器阻塞 `get_action`。

## 4. ROS2 运行时

### 4.1 节点图

```text
/cam_left_high  /cam_right_high  /joint_states  /ee_pose
        │              │               │            │
        └──────────────┴───────┬───────┴────────────┘
                               ▼
                    /geo_residual/observer
                    ├─ stereo_depth (SGBM, ROI)
                    ├─ robot_mask (URDF + joint_states)
                    ├─ local_icp (T_obj)
                    ├─ surface_distance (d_t, n_t)
                    └─ phase_posterior / edit_event
                               │
                               ▼
                    PolicyService (唯一学习模型)
                    └─ FACT-VLA: CPT / CAC / EGP
```

- `tf2` 管 `base → head`；`image_geometry` 管反投影；`pcl`/Open3D 管 ICP；`ros2 bag` 管 33k 演示的回放。
- 观察器 30 Hz、固定 ROI、预分配缓冲；目标 p99 < 33 ms。若超预算，降到 15 Hz 并做时间插值，**绝不阻塞 `get_action`**。
- N 端口：每端口一个观察器实例/命名空间，只共享只读的标定和 URDF；`reset()` 清空局部地图、ICP 初值、相位后验。
- 回放：把官方 parquet/video 转成 ROS2 bag，离线跑同一套节点；这样“训练期标签”和“推理期观察”是同一份代码，避免离线/在线不一致。

### 4.2 为什么 ROS2 不是提交接口

官方评测只认 `PolicyService` 的 Python 接口，不认 ROS2。ROS2 只做本地运行时/回放/隔离；提交包里仍然是 `PolicyService`，观察器作为同进程库或本地节点调用。这样既得到 ROS2 的工程化，又不违反提交协议。

### 4.3 延迟预算

| 阶段 | 预算 |
|---|---:|
| 双目 SGBM（ROI） | 8–12 ms |
| 反投影 + 自掩码 | 2–3 ms |
| 体素 + 法向 | 3–5 ms |
| ICP（30 次） | 5–8 ms |
| 残差 + 状态机 | 1–2 ms |
| 总计 p99 | ≤33 ms |

超过预算的降级顺序：ROI 缩小 → 体素增大 → ICP 迭代减半 → 15 Hz → 关闭观察器。

## 5. 与 FACT-VLA 集成

### 5.1 保留

- CPT 相位化 BC、CAC 柔顺执行、EGP 证据门控；
- 夹爪滞止 `g_t` 和视觉接触 `v_t` 作为低置信度回退；
- 33k 成功演示、官方 rubric、官方 human 备注。

### 5.2 替换/升级

| FACT-VLA 现状 | 问题 | GEO-RESIDUAL 的替换 |
|---|---|---|
| FACTOR 用夹爪滞止 + 视觉接触 logit | 2D、无尺度、任务相关、阈值难迁移 | 米制表面距离 + 法向 + 刚体残差 |
| CPT 相位标签靠人工抽检 200 帧 | 贵、不可复现、跨任务不一致 | 由 `d_t / r_t / 夹爪` 自动分段 |
| CAC 只按标量接触分数缩动作 | 不知道往哪个方向让 | 用法向/切向分解做方向性柔顺 |
| 人为干扰靠状态机/视觉变化 | 难以区分“机器人自己动的”与“外部动的” | 动作条件化残差直接分离 |
| 视觉接触 logit 不可校准 | 无法报告物理误差 | 毫米/度、重投影误差、深度有效比 |

### 5.3 单模型合规的三种模式

| 模式 | 做法 | 适用 |
|---|---|---|
| C1 离线标注 | 观察器只离线生成相位/编辑标签，训练 FACT-VLA；提交包不含观察器 | 最保守，绝对单模型 |
| C2 在线观察器 | 观察器作为确定性几何库，输出特征/门控，不产生动作 | 默认；若官方接受“非学习辅助模块” |
| C3 同 checkpoint 特征 | 把 `d_t,n_t,r_static,r_grasp` 作为同一策略网络的输入特征，端到端微调 | 若官方把任何辅助模块都算“模型” |

**建议**：默认 C2，提交材料明确写“观察器无学习权重、不改变动作接口”；同时保留 C1 开关。若官方书面回复不接受，切 C1/C3。

### 5.4 训练/推理数据流

```text
离线：
  parquet + video → 双目深度 → 局部 ICP → 残差/相位 → 标签
  → FACT-VLA CPT 训练（相位化 BC）
  → CAC 柔顺策略训练（可选）
  → EGP 恢复预算校准

在线：
  RGB + joint + EE → 观察器 → (d_t,n_t,r_t,phase,edit)
  → FACT-VLA 输入特征/门控 → 动作 chunk
  → CAC 方向性柔顺 → 机器人
```

观察器不反传梯度；C3 模式下只把残差向量拼到策略输入，梯度仍只更新同一个 checkpoint。

## 6. 实验协议与门

### 6.1 数据划分

- 32 任务，按 session/物体/背景分组划分训练/验证/测试，避免同一演示的相邻帧泄漏。
- 每任务留出至少 1 个 session 做测试；接触/编辑标签只在这些留出集上评估。
- 人为编辑：从 `human_1_note`/`human_4_note` 找“先完成再撤销”的任务，构造正样本；正常演示做负样本。
- 接触标签：用夹爪开度 + 人工抽检 200 帧 + 力/触觉（若有）做弱标签；报告标注不确定性。

### 6.2 门 G0–G6

| 门 | 问题 | 通过标准 | 失败动作 |
|---|---|---|---|
| G0 | 双目深度在 0.4–0.9 m 是否可用？ | ROI 有效像素 ≥70%；夹爪重投影误差 ≤10 mm | 只用腕部视觉 + 夹爪滞止 |
| G1 | 接触检测是否准？ | 对人工接触标签 AUROC ≥0.85 | 退回 FACTOR 标量 |
| G2 | 相位自动标签是否准？ | 边界 F1 ≥0.75；跨任务不崩 | 只用 grasp/free 两相 |
| G3 | 抓取/滑移是否分得开？ | `r_grasp` vs `r_static` AUROC ≥0.80 | 只做抓取，不做滑移 |
| G4 | 人为编辑能否检出？ | 合成编辑 AUROC ≥0.85；正常集误报 ≤5% | 只做离线标注，不线上触发 |
| G5 | 方向性柔顺是否涨成功率？ | 接触密集任务 +5pp；自由任务不回归 | 只保留相位标签，不做控制 |
| G6 | 延迟是否可接受？ | p99 ≤33 ms；timeout 不升 | ROI 降采样/15 Hz/关闭 |

所有门先在离线回放和单任务不计分通道上过；没有过门，不烧正式提交。

### 6.3 消融

| 消融 | 目的 |
|---|---|
| 双目 vs 单目 | 证明米制深度不是装饰 |
| ICP vs 光流 | 证明刚体残差比 2D 运动稳 |
| `r_static/r_grasp` vs 标量接触 | 证明动作条件化有用 |
| 自动相位 vs 人工 200 帧 | 证明标签可替代 |
| 法向/切向柔顺 vs 标量缩幅 | 证明方向性柔顺有用 |
| 编辑残差 vs 视觉变化状态机 | 证明动作条件化能降误报 |

### 6.4 在线评估

- 先 shadow：观察器只记录，不参与动作；比较离线标签与在线输出。
- 再 A/B：同一任务配对，奇偶 trial 交替开/关；至少 10 次/任务。
- 统计：任务配对 bootstrap，报告 95% CI；320 trials 的单次标准误约 **2.6pp**，不能把 +1–2pp 当结论。
- 安全：观察器触发回撤/重抓时限制速度与力，设置最大重试次数；失败即回退原策略。

## 7. 比赛算术

- **人为干扰轴**占 20%（32×2=64 trials）。如果编辑检测 + 恢复把 human 轴成功率从 `p_h` 提到 `p_h+10pp`，全局约 **+2pp**。
- **接触密集任务**至少 17/32；如果其中 10 个终局接触任务 +5pp，全局约 **+1.6pp**；若 17 个都 +5pp，约 **+2.7pp**。
- **步骤分**只做同分决胜；自动相位标签更可能提高“步骤完成判定”的一致性，边际价值在平台期。
- 两项都成立时，乐观估计 **+3–5pp 全局**；但 320 trials 的单次标准误约 2.6pp，必须任务配对、bootstrap、多次独立回放，不能把 +1–2pp 当结论。

真正的主收益不是“多一个模块”，而是：**把 FACT-VLA 的接触相位从不可校准的隐变量，变成可复现、可解释、可离线验证的几何量。**

## 8. 风险与合规

| 风险 | 影响 | 缓解 |
|---|---|---|
| 透明/反光/可变形物体 | 双目失败，残差噪声大 | 左右一致性置信度 + 腕部视觉 + 夹爪滞止回退；只对刚体任务启用 |
| 机械臂自遮挡 | 夹爪挡住物体 | URDF 掩码 + ROI + 多帧置信度；遮挡严重时回退 |
| 标定漂移/换机器人 | 残差被外参误差污染 | 逐机器人重投影校准；夹爪 3D 点 PnP 自标定；误差大则关闭 |
| 时间戳不同步 | `ΔT_ee` 与图像错位 | 插值 + 互相关找延迟；>2 帧则降级 |
| 单模型解释 | 被判定为第二个模型 | C1 离线 / C2 确定性观察器 / C3 同 checkpoint 特征 |
| 延迟抖动 | 拖慢 `get_action` | 独立线程、固定 ROI、丢帧不阻塞；p99 不过门就关闭 |
| 人类编辑不在头部视野 | 漏检 | 本体/夹爪/任务状态残差兜底；不声称 100% |
| 阈值过拟合 | 换任务就崩 | 每任务分位数 + 留出 session + conformal 误报控制 |
| 数据泄漏 | 离线指标虚高 | 按 session/物体/背景分组划分；相邻帧不跨 split |
| 安全 | 回撤/重抓撞到物体 | 限速、限力、最大重试次数；失败回退原策略 |

## 9. 实施计划

| 阶段 | 时间 | 交付 | 退出条件 |
|---|---:|---|---|
| P0 标定与回放 | 1 周 | `T_base_head` 拟合、双目 ROS2 bag、G0 报告 | ROI 有效 ≥70%，重投影 ≤10 mm |
| P1 几何观察器 | 2 周 | SGBM + 自掩码 + ICP + 残差，5 个任务离线 | G1/G3 过门 |
| P2 标签与集成 | 2 周 | 自动相位标签、FACT-VLA CPT 接口、C1/C2 开关 | G2 过门，训练可复现 |
| P3 运行时 | 1 周 | N 端口观察器、`reset()` 隔离、延迟报告 | G6 过门 |
| P4 在线验证 | 1–2 周 | shadow + 配对 A/B、G4/G5 报告 | 接触任务 +5pp 且自由任务不回归 |
| P5 提交 | 1 周 | 提交包、合规说明、回滚开关 | 全部门前过，或明确关闭观察器 |

**算力**：观察器 CPU 即可；离线标签可用 8–16 核并行。训练 FACT-VLA 仍用原 GPU 预算，不因观察器增加。

**人员**：1 人几何/标定，1 人策略集成，1 人评测/统计；可兼职。
