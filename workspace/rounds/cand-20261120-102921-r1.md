# 第 1 轮（新灵感循环第 1 轮；累计第 14 轮；本轮灵感：「触觉感知」×「碰撞避免」）

> **基线**：第 1 轮 MetricVoiceGauge-NCD-HUTDH-v16（定义 627–656；引理 131–136；实验 E671–E690）。
> 本轮纪律：**触觉为皮肤、碰撞为边界、反射为最后一道证书**。不推倒 v16：v16 的 BTS/TRM/WBC/CSC/NCS/MCA/WCB、v15 的 SCD/DSD/DCA/EDC、v14 的 SCD 继承、v13 的 AIO/RTIC/CPD/DGC/DDL/RTCR、v12 的 USG/TGC/BAA/GAGP/UC、v11 的 HAS/HCC/HATD/HDT、v10 的 NGE/DSL/CC/CWM/CAE/NCP、v9 的 AC/MW/ID、v8 的 DA/SPR/Cal 与历轮不变式全部保留。四个新组件——TCF（触觉证书场）、CEC（接触事件证书）、PCC（预测碰撞证书）、RVF（反射否决融合）——一律以**只收紧、不授权**的方式接入，失效即严格退回 v16（引理 137），再沿 v16→v15→v14→v13→v12→v11→v10→v9→v8→v7→v6 退化链退回。本轮只做三件事：把"触觉"改写为**皮肤上的分布式区域证书**、把"碰撞避免"改写为**跨接触事件视界的连续证书**、把"反射"改写为**只有否决权的硬实时安全层**。

## 0. 直觉与动机

**灵感 1（触觉感知 → 皮肤证书场与接触事件）**
直觉：v16 的所有证书都是"预测性"的——它们基于模型、在动作发生前判定"什么可以发生"。触觉恰恰相反：它是**后验的、局部的、无模型的**，只在接触已经发生之后告诉你"什么正在发生"。这不是缺陷，而是互补：预测证书有盲区（遮挡、形变、未建模障碍），触觉正好覆盖盲区；触觉也有盲区（未覆盖的皮肤、反应延迟），预测证书正好覆盖。核心创新：**触觉证书场（Tactile Certificate Field, TCF）**。皮肤被离散为贴片图 `G_S=(P,E_S)`，每个贴片携带局部状态 `(接触指示, 法向力, 切向力, 滑移, 置信度)`；单贴片可以故障，但**连通接触区域**的证书要求空间一致性，从而对单点失效有容错。关键反直觉点：**触觉不是"传感器读数"，而是"接触区域上的证书"**——一个贴片说"有接触"不算数，一个连通区域的所有贴片在容差内一致地说"有接触、在摩擦锥内、无滑移"才算数。区域证书是"空间上的合取"，而不是"单点的阈值"。

**灵感 2（碰撞避免 → 预测碰撞证书与反射否决）**
直觉：经典碰撞避免用几何距离 + 控制屏障函数（CBF），但 CBF 只保证"连续时间标称轨迹"不越界，不保证"采样保持 + 通信延迟 + 反射仲裁"下的安全。真实系统里，碰撞避免有两道防线：**慢的预测层**（10–50Hz，CBF/可达集，管"不要撞"）和**快的反射层**（≥1kHz，触觉/力矩，管"撞了立刻退"）。核心创新：**预测碰撞证书（Predictive Collision Certificate, PCC）+ 反射否决融合（Reflex-Veto Fusion, RVF）**。PCC 在离散采样下给出 `h(x_{k+1}) ≥ (1-γ)h(x_k)` 的保持性证书；RVF 是一个**只有否决权、没有授权权**的硬实时反射弧：它可以把 BTS/CSC 提议的动作从允许集中删掉，但永远不能新增动作。关键反直觉点：**反射的安全性不来自"反射判断正确"，而来自"反射只会做减法"**——即使反射误触发，最坏结果是保守（停机/柔顺），而不是危险；把"正确性"换成"单调性"，是让快反射可证的关键。

**灵感 3（触觉 × 碰撞 × v16 → 接触事件视界上的证书代数）**
直觉：把时间轴在接触点切开，得到四个相位：**接触前**（PCC 预测）、**冲击瞬间**（IC 冲量证书）、**盲区**（BZB 盲区界）、**接触后**（TCF 触觉）。四段拼起来才是完整的接触事件证书（CEC）。核心创新：**接触事件证书（Contact-Event Certificate, CEC）**：`CEC = (PCC, IC, BZB, TCF)`，要求四段覆盖整个事件视界 `[t^- - δ, t^+ + δ]`，且在接缝处用 Lipschitz 界 `BZB` 桥接。CEC 把"碰撞避免"和"触觉感知"从两个独立模块变成一个**跨接触边界的连续证书对象**。关键反直觉点：**最危险的不是接触前，也不是接触后，而是接触的"接缝"**——预测在这里失效（太晚），触觉在这里还没到（太早），而冲击的冲量恰好在这里注入；两侧都 sound，接缝却可能绝对不安全。

**三者如何统一**
统一为 **v16 行为层之下的接触安全层**：v16 回答"按里程碑、行为树、WBC 阶层能执行什么"，v17 回答"这个执行在接触事件视界上是否被连续覆盖"。TCF 提供接触后的局部证书，PCC 提供接触前的预测证书，CEC 把两者在事件视界上缝合，RVF 用只有否决权的反射弧保证"缝不上时也不会危险"。共享状态 `ζ_tac = (TCF_t, CEC_stack, c*, τ_gap, veto_t, hysteresis_t, coverage_t)`。**TCF 回答"现在碰到了什么"，PCC 回答"接下来会不会碰到"，CEC 回答"从预测到触觉的整段是否被证书覆盖"，RVF 回答"覆盖不上时这一毫秒该否决什么"**。四者不是四个传感器补丁，而是"局部—预测—接缝—反射"的同一条安全链。

## 1. 研究问题（轮次升级版）

- **Q1（触觉证书场的空间语义）**：如何为连通接触区域定义证书，使单贴片故障、贴片间标定漂移、接触边缘的模糊性都不破坏区域证书的可靠性？区域置信度如何与 v12 的 TGC 共形校准统一？"区域一致"应是合取、还是带容差的软合取？
- **Q2（接触事件证书的接缝）**：冲击是状态的不连续跳变，Lipschitz 盲区界 `BZB` 在冲击处恰好失效；如何定义"接缝证书"，使 `PCC` 与 `TCF` 在接缝处既不重叠也不留缝？冲量证书 `IC` 如何与 v16 的 WBC 动力学证书合成？
- **Q3（反射否决的实时性与活性）**：反射弧的硬实时延迟 `τ_ρ` 与"不可撤回窗口"如何界定？"反射只做减法"如何形式化？误触发导致的抖动/冻结如何用滞回证书抑制而不牺牲安全性？
- **Q4（四维单调退化与全失效）**：CSC 的三维 `(B_tick, m*, h*)` 加上间隙/盲区预算 `c*` 后，帕累托最优性与单调性是否保持？四者全失效时能否严格退回 v16，再沿退化链退回 v6？

## 2. 设计原则（在 P25–P27 基础上新增 P28–P30）

**P28 触觉即区域证书律（Tactile as Region Certificate）**
皮肤贴片图 `G_S` 上的接触区域 `R`（连通分量）的证书为 `Cert(R) = (F_n^R, F_t^R, s^R, q^R)`，要求：`F_n^R ∈ [F_min, F_max]`、`‖F_t^R‖ ≤ μ F_n^R`、`max_{p∈R} s_p ≤ s_max`、`min_{p∈R} q_p ≥ q_min`。区域证书必须**空间一致**：任意两贴片的法向力差 ≤ `ε_F`，否则区域降级为"边界模糊"，只允许保守回退。单贴片故障不得使区域证书从"不安全"翻转为"安全"：贴片卡在"无接触"只会让区域无法形成（保守），贴片卡在"有接触"只会让区域虚假扩大（也是保守）。

**P29 接触事件视界覆盖律（Contact-Event Horizon Coverage）**
每个接触动作必须携带 `CEC = (PCC, IC, BZB, TCF)`，且四段在时间上**首尾相接、无缝覆盖** `[t^- - δ, t^+ + δ]`。接缝处必须满足 `τ_gap = t^+ - t^- ≤ δ`，且 `BZB` 在 `(t^-, t^+)` 上给出状态界。任何一段缺失或失效，动作只能执行 `H_0` 纯柔顺回退，且回退动作必须属于 v16 已认证的安全集。

**P30 反射只做减法律（Reflex Veto-Only）**
反射弧 `ρ` 的输出是**否决集** `V(t) ⊆ ActionSpace`，不是动作。执行规则：`a_exec(t) = a_prop(t)` 若 `a_prop(t) ∉ V(t)`；否则 `a_exec(t) = fallback(t)`，且 `fallback(t) ∈ Exec_v16^{H_0} \ V(t)`。反射不得新增任何 v16 未授权的动作，不得放宽任何阈值，不得覆盖 BTS/CSC 的里程碑或阶层约束。反射误触发的代价只能是活性下降，不能是安全性下降。

## 3. 与基线的接口（如何退化）

- TCF 失效 ⇒ 触觉中立元：`Cert(R) ≡ ⊤`（不提供约束），CEC 退化为 `(PCC, IC, BZB)`，**等价 v16 + PCC 路径**；
- CEC 失效 ⇒ 事件中立元：只在采样点检查 `PCC`，接触后交给 v16 WBC，**等价 v16 + RVF 路径**；
- PCC 失效 ⇒ 预测中立元：`h ≡ +∞`（不预测），仅靠 TCF 反射，**等价 v16 + TCF 路径**；
- RVF 失效 ⇒ 反射中立元：`V(t) ≡ ∅`（不否决），**等价 v16 路径**；
- 四者全失效 ⇒ MetricVoiceGauge-NCD-HUTDH-v16，再沿 v16→v15→…→v6 退化链退回；
- **安全继承**：TCF 只收紧接触区域证书，CEC 只增加时间覆盖约束，PCC 只收紧碰撞边界，RVF 只删除动作。四端口均不能新增授权；`Exec_v17 ⊆ Exec_v16` 由引理 137/139 保证。

## 4. 预期贡献

1. **触觉证书场**：把触觉从"传感器读数"改写为"连通接触区域上的分布式证书"，给出空间一致性、单点容错与共形校准；
2. **接触事件证书**：把碰撞避免与触觉感知统一为跨接触事件视界的连续证书对象，首次显式处理"冲击接缝"；
3. **反射只做减法**：给出只有否决权的硬实时反射弧的形式化语义与安全继承证明，使"快反射"与"慢规划"的仲裁可证；
4. **四维单调退化**：把间隙/盲区预算加入 v16 的 CSC，保持帕累托最优与单调退化；
5. **实验 E691–E710**：覆盖区域证书、接缝覆盖、反射安全/活性、四维退化、盲区塌缩、端到端与消融。

## 5. 本轮最大风险

**一句话**：CEC 的接缝证书假设状态在盲区 `(t^-, t^+)` 内 Lipschitz 连续，但冲击本身是一个**冲量注入导致的速度跳变**——Lipschitz 界恰好在最需要它的地方失效；于是 `PCC` 在接缝前是 sound 的、`TCF` 在接缝后是 sound 的，而**接缝本身既没有被预测覆盖、也没有被触觉覆盖**，形成一条"两侧都正确、中间绝对不安全"的接触视界缝隙。

# IP-416 Tactile Certificate Field：皮肤区域证书
class TactileCertificateField:
    def __init__(self, skin_graph, conformal, alpha_T=0.05, eps_F=0.15):
        self.G = skin_graph                 # G_S=(P,E_S)
        self.conformal = conformal          # v12 TGC 共形校准器
        self.alpha_T = alpha_T
        self.eps_F = eps_F
        self.cm = ContactMap()              # IP-424

    def update(self, raw):
        """raw: {p: (c_p,f_p^n,f_p^t,s_p)}；返回 TCF(t)"""
        tcf = {}
        for p, (c, fn, ft, s) in raw.items():
            q = self.conformal.confidence(p, fn, ft, s, self.alpha_T)
            tcf[p] = TactileState(c, fn, ft, s, q)
        return tcf

    def regions(self, tcf):
        """并查集求 c_p=1 的连通分量 R"""
        return union_find_components(self.G, [p for p in tcf if tcf[p].c])

    def cert(self, R, tcf):
        """区域证书；不一致则降级为 BOUNDARY_AMBIGUOUS"""
        if not R:
            return RegionCert.none()
        if not self._consistent(R, tcf):
            return RegionCert.boundary_ambiguous(R)
        Fn = sum(tcf[p].fn for p in R)
        Ft = vector_sum(tcf[p].ft for p in R)
        s = max(tcf[p].s for p in R)
        q = min(tcf[p].q for p in R)
        ok = (F_MIN <= Fn <= F_MAX and norm(Ft) <= MU * Fn
              and s <= S_MAX and q >= Q_MIN)
        cert = RegionCert(R, Fn, Ft, s, q, ok)
        if ok:
            self.cm.record(R, tcf)          # 接触指纹入记忆
        return cert

    def _consistent(self, R, tcf):
        vals = [tcf[p].fn for p in R]
        return (max(vals) - min(vals)) <= self.eps_F


# IP-418 Predictive Collision Certificate：离散 CBF 保持
class PredictiveCollisionCertificate:
    def __init__(self, barrier, gamma=0.2, horizon=0.1):
        self.h = barrier                    # h(x), grad_h(x)
        self.gamma = gamma
        self.Delta = horizon

    def cert(self, x, u_nom, dynamics):
        """求最小修正 u，使 h(x_{k+1}) >= (1-gamma) h(x_k)"""
        h0 = self.h(x)
        if h0 < 0:
            return PCert.fail(h0)
        # 离散 CBF-QP：min ||u-u_nom||^2  s.t. 保持不等式
        u = solve_cbf_qp(self.h, x, u_nom, dynamics, self.gamma)
        h1 = self.h(dynamics.step(x, u, self.Delta))
        ok = h1 >= (1 - self.gamma) * h0
        return PCert(u, h0, h1, ok)

    def blind_zone_bound(self, x, v, Delta_b):
        """IP-422：盲区内 h 的下界（Lipschitz 界）"""
        L_h = self.h.lipschitz()
        h0 = self.h(x)
        return h0 - L_h * Delta_b            # 需 >= 0 才覆盖盲区


# IP-417 Contact-Event Certificate：四段缝合
class ContactEventCertificate:
    def __init__(self, pcc, tcf, bzb, ic, delta=0.02):
        self.pcc, self.tcf, self.bzb, self.ic = pcc, tcf, bzb, ic
        self.delta = delta

    def evaluate(self, event, x_pre, x_post, tcf_post):
        """返回 (covered, seam_gap, weakest_phase)"""
        pcc_ok = self.pcc.cert(x_pre, event.u_nom, event.dyn).ok
        bzb_ok = self.bzb.covers(x_pre, event.tau_gap)
        ic_ok = self.ic.holds(event.impulse, event.v_minus, event.v_plus)
        tcf_ok = self.tcf.cert(event.region, tcf_post).ok
        covered = pcc_ok and bzb_ok and ic_ok and tcf_ok
        seam = event.tau_gap > self.delta or not bzb_ok
        weakest = min(
            [('PCC', pcc_ok), ('BZB', bzb_ok),
             ('IC', ic_ok), ('TCF', tcf_ok)],
            key=lambda kv: kv[1])
        return covered, seam, weakest

    def seal(self, event):
        """接缝未覆盖时强制 H_0 柔顺，禁止任何接触动作"""
        return Exec_v16_H0_compliant(event.x)


# IP-419 Reflex-Veto Fusion：只做减法的硬实时反射
class ReflexVetoFusion:
    def __init__(self, reflex_arc, rhg, tau_rho=0.001, fallback_set=None):
        self.rho = reflex_arc               # TCF -> V(t)
        self.rhg = rhg                      # IP-425 滞回
        self.tau_rho = tau_rho
        self.F = fallback_set or Exec_v16_H0_compliant

    def veto(self, tcf, t):
        """只有否决：返回 V(t)"""
        severity = max_slip_severity(tcf)
        if not self.rhg.should_fire(severity, t):
            return set()
        return self.rho(tcf)               # 只包含要删除的动作

    def arbitrate(self, a_prop, tcf, t, last_a):
        V = self.veto(tcf, t)
        if a_prop not in V:
            return a_prop, False
        # 回退必须来自 v16 已认证的 H_0 安全集，且不在否决集
        fb = next((a for a in self.F if a not in V), None)
        if fb is None:
            return last_a, True            # 无安全回退：保持上一动作（保守）
        return fb, True

# IP-421 Clearance-Budget Scheduler：四维单调退化
class ClearanceBudgetScheduler(CertificateSchedulingChain):
    def schedule(self, x, hw_state, sw_cert, data_cov, tcf, drift=False):
        self.trm.update_state(hw_state, sw_cert, data_cov)
        m_star = self.trm.compute_reachable()
        h_max = self.trm.get_permitted_tier(m_star)
        # 第四维：由 PCC + BZB 计算的间隙预算
        c_star = min(self.pcc.h(x) - self.bzb.margin(x),
                     self.c_max)
        if c_star < 0:
            return self._safe_stop(x)      # 净空为负：直接 H_0
        plan = self._solve_ip_4d(x, m_star, h_max, c_star, drift)
        return self._execute_plan_4d(x, plan, tcf, drift)

    def _solve_ip_4d(self, x, m_star, h_max, c_star, drift):
        """在 (m,h,c) 乘积格上贪心回溯；c 只能单调减"""
        if drift:
            return {'m': 1, 'h': 0, 'c': 0,
                    'nodes': [self.bts.root.fallback_node], 'ticks': 1}
        best = None
        for m in range(m_star, 0, -1):
            for h in range(min(h_max, self.trm.get_permitted_tier(m)), -1, -1):
                for c in self._clearance_levels(c_star):
                    nodes, ticks, val = self._estimate_value(x, m, h, c)
                    if ticks <= self.B_max and (best is None or val > best['val']):
                        best = {'m': m, 'h': h, 'c': c,
                                'nodes': nodes, 'ticks': ticks, 'val': val}
        return best or {'m': 1, 'h': 0, 'c': 0, 'nodes': [], 'ticks': 0}

## 2. 推导（引理 137–142）

**引理 137（触觉区域证书的可靠性下界）** 设贴片在给定真实接触状态下条件独立，单贴片假阴性率 `β_p`，区域 `R` 连通且 `|R|=n`，共形校准显著性 `α_T`。则区域证书的假安全概率满足 `P(Cert(R)=safe | 真实不安全) ≤ ∏_{p∈R} β_p + α_T`；且任一贴片卡死不会把"不安全"翻成"安全"：卡在"无接触"使 `R` 不形成（保守），卡在"有接触"只使 `R` 虚假扩大而触发摩擦锥/一致性检查（保守）。证明：区域证书要求所有 `p∈R` 同时满足摩擦锥、滑移与一致性；真实不安全时至少一个贴片应以 `1-β_p` 报告异常，全部漏报的概率为 `∏β_p`，再叠加共形校准误差 `α_T`。卡死情形由合取结构直接得保守性。∎ 推论：**区域证书的可靠性随连通区域增大指数提高，但覆盖盲区（未贴皮肤处）不在保护范围内**。

**引理 138（接触事件视界的无缝覆盖）** 若 `PCC` 在 `[t^- - δ, t^-]` 成立，`BZB` 在 `(t^-, t^+)` 给出 `h(x(t)) ≥ h(x(t^-)) - L_h(t-t^-) ≥ 0`，`IC` 在 `t^-` 成立，`TCF` 在 `[t^+, t^+ + δ]` 成立，且 `τ_gap ≤ δ`，则事件视界 `H_e` 上每一点至少被一个有效证书覆盖。证明：把 `H_e` 分为 `[t^- - δ, t^-]`、`(t^-, t^+)`、`[t^+, t^+ + δ]` 三段，分别由 `PCC`、`BZB`、`TCF` 覆盖；`IC` 约束接缝处的状态跳变，使 `BZB` 的初值 `x(t^-)` 与末值 `x(t^+)` 相容；`τ_gap ≤ δ` 保证三段首尾相接。∎ 推论：**覆盖的充分条件不是"每段都强"，而是"段与段的初末状态相容"**；`IC` 正是这个相容性证书。

**引理 139（反射否决的安全继承）** 若 `fallback(t) ∈ Exec_v16^{H_0}` 且 `V(t)` 只删除动作，则对任意 `t` 有 `Exec_v17(t) ⊆ Exec_v16(t)`。进一步，若 `τ_ρ ≤ δ` 且 `BZB` 覆盖 `[t, t+τ_ρ]`，则不可撤回窗口 `W_irr` 内的已提交动作仍处于 `Allowed(t)`。证明：`a_exec = a_prop` 或 `a_exec = fallback`，前者在 `Exec_v16` 内，后者按假设在 `Exec_v16^{H_0} ⊆ Exec_v16` 内；`V` 只做集合差，故不可能新增。`W_irr` 内反射尚未生效，但 `BZB` 保证状态不越出认证包络。∎ 推论：**反射的正确性可以完全让位于单调性**——只要它只会删，就永远不能制造 v16 没有的危险。

**引理 140（滞回反射的活性界）** 设触觉严重度 `s(t)` 满足 `|s(t)-s(t')| ≤ ε_s|t-t'|`，反射阈值为 `s_min`，驻留时间 `T_dwell`，且 `s_min > 2ε_s T_dwell`。则任意长度 `T` 的区间内反射触发次数 ≤ `⌈T/T_dwell⌉ + 1`，且不发生抖动（两次触发间隔 ≥ `T_dwell`）。证明：滞回带 `[s_min - ε_s T_dwell, s_min + ε_s T_dwell]` 内不改变触发状态；驻留计时器强制最小间隔。∎ 推论：**反射的活性损失可被 `T_dwell` 定量控制**，但代价是更慢的响应——这正是接缝风险的来源之一。

**引理 141（四维单调退化的帕累托最优性）** 把引理 134 的调度域从 `(B_tick,m*,h*)` 扩展到 `(B_tick,m*,h*,c*)` 的乘积序。若价值 `val` 关于四维单调不减，且可行集是下集（order ideal），则 `CBS` 的贪心回溯返回帕累托最优解。证明：乘积偏序仍是格；可行集对逐维下降封闭（下集）；贪心从最大元向下枚举，每一子格上的局部最优即该子格全局最优；归纳即得。∎ 推论：**加入间隙维度不破坏 v16 的最优性论证**，只要 `c*` 的可行域也是下集。

**引理 142（触觉覆盖盲区界）** 设皮肤覆盖碰撞相关表面的比例为 `γ_skin`，碰撞位置在该表面上均匀分布，覆盖估计误差为 `ε_cov`。则未认证碰撞概率满足 `P(uncertified collision) ≤ (1-γ_skin)·P(collision) + ε_cov`。证明：未认证碰撞只能发生在未覆盖表面（概率 `1-γ_skin`）或覆盖估计低估处（误差 `ε_cov`）。∎ 推论：**触觉单独永远不能认证碰撞避免**；它是 PCC 的补集，不是替代品——这是 v17 必须与 v16 分层而非替换的根本原因。

## 6. 已知风险与失效模式

1. **接缝的冲量不连续（本轮核心风险）**：`BZB` 假设盲区内 Lipschitz 连续，但冲击是速度跳变，界在最需要处失效。缓解：把 `IC` 升格为接缝的一等证书、用冲量-动量守恒替代 Lipschitz、接缝期间强制 `H_0`。

2. **触觉总线在冲击瞬间的延迟抖动**：碰撞会引起机械振动/电磁干扰，恰好使 `τ_ρ` 超出预算，否决在不可撤回窗口之后才到达。缓解：硬实时专用链路、双缓冲时间戳、冲击前预否决（PCC 触发预备否决）。

3. **皮肤覆盖盲区**：引理 142 明确触觉单独不能认证碰撞避免；未覆盖表面（背部、足底边缘）是结构性盲区。缓解：与 PCC 分层、覆盖审计、关键表面冗余。

4. **接触边缘的区域模糊**：接触区域边缘的贴片可能半接触，导致 `consist(R)` 误判。缓解：软合取、边缘贴片降权、形态学腐蚀后再判连通。

5. **反射-规划的极限环**：反射否决 → 规划换动作 → 新动作又触发否决，形成抖动。缓解：RHG 滞回 + 驻留时间、否决集在 `T_dwell` 内冻结。

6. **反射误触发导致冻结（活性塌缩）**：传感器故障或标定漂移使 `V(t)` 恒非空，系统长期停在 `H_0`。缓解：否决集大小上界、误触发率监控、降级到 v16（关 RVF）。

7. **共形校准的分布漂移**：新物体/新材料的接触分布超出校准集，`q_p` 乐观。缓解：接触图 `CM` 触发重校准、开放集检测、保守 `α_T` 余量。

8. **CBF 模型失配**：软体/可变形障碍使 `h` 的梯度与真实距离不符，PCC 过于乐观。缓解：用触觉在线修正 `h`、区间化屏障、降速。

9. **四维退化的累积保守性**：`(m,h,c)` 每维都取交集并减间隙，多层后可行域可能清空。缓解：价值加权而非纯交集、选择性放宽（需证明）、动态 `α`。

10. **接触图的数据陈旧与隐私**：`CM` 记录材料指纹可能过时或含敏感信息。缓解：TTL、差分隐私聚合、本地化存储。

11. **多接触/自碰撞的歧义**：多个接触区域同时存在时，区域证书的合取可能把"两个各自安全"误判为"整体安全"。缓解：多区域联合证书、自碰撞对枚举、全身接触一致性检查。

12. **v17 与 v16 证书栈的累积保守性**：v17 的 `PCC/CEC/TCF` 与 v16 的 `BTS/WBC` 层层取交，可能把系统压到只剩 `H_0`。缓解：分层优先级、证书价值加权、元认证监控。

## 7. 本轮最大风险

**一句话**：`CEC` 的接缝证书假设盲区 `(t^-, t^+)` 内状态 Lipschitz 连续，但冲击是冲量注入导致的速度跳变——`BZB` 恰好在最需要它的地方失效；于是 `PCC` 在接缝前 sound、`TCF` 在接缝后 sound，而**接缝本身既无预测覆盖、也无触觉覆盖**，形成一条"两侧都正确、中间绝对不安全"的接触视界缝隙，且反射延迟抖动会让这条缝隙在真实碰撞时进一步变宽。
