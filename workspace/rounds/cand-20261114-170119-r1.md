# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；灵感循环新循环第 1 轮；本轮灵感：「场景驱动创新」×「语言指令」）

> R69 让系统学会了「问」：把不确定性拆成动作层的 aleatoric（噪声，收紧）与 epistemic（歧义，去求证），并用看/问/触去消解后者。但它有两个从未被质询的前提：**（一）任务指令与部署场景是给定的真值**；（二）「问」的对象在可信边界之外，所以要用「k 个正交证据源一致」防投毒。
>
> 这两个前提都不成立。真实部署里，安全从来不是绝对的，而是**相对某个场景契约**才成立——仓库里的「贴近」与医院里的「贴近」风险预算不同，对「谁有权让我靠近」的答案也不同。而语言指令不是命令，它是一个**带出处的、可错的、可能被伪造的提议**：它可能欠定（「把桌上那个拿来」——哪个？）、可能歧义（「快点」——快多少、能不能牺牲安全？）、也可能与当前场景失配（你在一个从没被认证过的走廊里执行一份为仓库写的指令）。
>
> 本轮两个灵感正好各补一刀：
> - **场景驱动创新**把「场景」提升为一等对象：安全与性能的断言只在具名**场景契约**下有意义；创新预算按「新开一个可被认证的场景」而非「把已覆盖场景再打磨 1%」分配。这把 R69 的「单任务闭环」升级为「**场景组合的认证覆盖**」。
> - **语言指令**把「人说的话」从信任面移到**威胁面**：指令被编译成契约假设集 + 无法接地的**残余义务**；默认只允许**收窄**，放宽是需要权限与认证的特权操作。指令层的歧义再三分：欠定（动作序一致，交集执行几乎无损，不必问）、歧义（动作序冲突，走 R69 VoI 提问）、失配/OOC（观测不再像这个场景，吊销契约）。
>
> 核心命题：**把「我要做什么/我在哪/谁有权改我的边界」从隐式前提变成显式、可追溯、可反驳的场景契约；用契约假设集的交集做鲁棒执行；用单向收窄把指令注入的危害限制为过度保守；用场景转移证书回答「换个场景我还安全吗」。** 命名 **SCRIPT-RAS**（Scenario-Contract Runtime for Instruction-grounded Policies with Trust）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我到底被要求做什么？我现在还在被授权的那个场景里吗？这句话有资格改我的安全边界吗**」——安全不再是一个全局常数，而是**一份写在场景契约里、由语言编译出来、随时可被观测吊销的承诺**。

## 0. 直觉与动机

**灵感 1（场景驱动创新 → 安全是契约相对的，创新以场景为计量单位）**
直觉：R68/R69 的 ε、λ_floor、交互预算都是全局标量，仿佛「安全」有一个与任务无关的绝对刻度。但同一个动作在仓库、家庭、医院、产线的风险权重完全不同；更关键的是，**「什么算完成」「谁的话能算数」也随场景而变**。一个把「场景」显式写下来的系统，才能回答「我现在是不是还在被认证的那个世界里」。而一旦场景成为一等对象，创新就有了正确的计量单位：不是「单任务成功率 +1%」，而是「我的**认证场景覆盖**多了一块」——这就是「场景驱动创新」落到工程上的样子：优先去做**能新开一个安全可认证场景**的事，而不是在已覆盖的场景里内卷。
形式化：维护已认证场景库 𝒮，优化 `cov(𝒮)=Σ_s π(s)·1[∃C∈𝒮: s∈Dom(C)]`，在组合风险预算下最大化覆盖（定义 321、326，定理 20 给出次模贪心保证）。

**灵感 2（语言指令 → 指令是可错的提议，不是可信的命令）**
直觉：人类听一句「把那个拿给我」时，会同时做三件事：解析指代、检查当前情境是否支持这个解读、判断说话人有没有资格下这个命令。机器人系统常把第二步和第三步省掉，直接当命令执行。正确姿态是：把指令编译成**若干契约假设**，每个假设标注它依赖了指令的哪个片段（出处），以及有哪些部分**根本接不了地**（残余义务，如情态「快一点」、指代「那个」、程度「稍微」）。残余义务不许静默丢——它要么被澄清，要么进入保守退避。这样「语言指令」既带来了灵活性，也被关进可审计的笼子。

**灵感 3（三分 → R69 的二分不够细，正确反应有三种而非两种）**
直觉：R69 说「epistemic 就去问」，但**有些 epistemic 不该问**：当多种解释在「该不该动、往哪动」上其实一致时，交集执行几乎无损，提问纯属浪费社交预算；而当观测已经不像这个场景时，提问也没用——你该做的是**吊销契约、降级**，而不是在错误的场景里礼貌地问。于是指令层不确定性三分：
- **欠定**（多种解释，动作序一致）→ 直接交集执行；
- **歧义**（多种解释，动作序冲突）→ 走 R69 MINT 的 VoI 提问；
- **失配/OOC**（观测与所有 live 契约都不一致）→ 契约吊销 + 场景转移/降级。
这把 R69 的「有 epistemic 就问」收敛为「**只在解释会改变动作排序时才问**」。

**灵感 4（交集 → 语义/指令只能加约束，不能减约束）**
直觉：如果一条指令说「前面是窗帘，可以穿过去」，而另一条证据说「前面可能是玻璃」，正确的不是投票选「最像」的标签，而是**把两种解释对应的可行动作集取交集**：按玻璃的几何约束，也按窗帘的可通行约束，再按「未知」的最坏情况约束。这样语义与指令永远只能在安全侧叠加限制；想「减约束」（把墙改判为可通行）必须走一条显式的、需要授权与认证的**释放路径**。这就是单向收窄（定义 318）：**默认收窄，放宽是特权**。

**灵感 5（把语言移到威胁面 → 注入最坏是「停」，不是「撞」）**
直觉：一旦系统听得懂指令，就有了新的攻击面：广播里的伪造指令、网页里的提示注入、路人冒充 operator、把危险意图包装成一句无害的话（契约洗白）、在长指令里夹带一条放宽约束（义务夹带）、重放别场景的合法指令。R69 的威胁模型只防「回答撒谎」，没防「指令本身就是攻击」。本轮用**权限账本 + 单向收窄 + 契约差分证书**把攻击的后果从「不安全放大」压成「过度保守」：攻击者最多把系统逼停或逼慢（DoS），无法让它越出基础安全内核。**但要注意：这只能防外部攻击，防不住编译器自己把危险意图误接地成一份「合法」契约**——这正是本轮最大风险（见第 6 节）。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（SCRIPT-RAS 总览与四不变式）** SCRIPT-RAS = (SCL, NLIC, UAD, CIM, CGA, ALO, SCP, J†)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **契约相对性**：任何安全/性能断言只在某个具名契约 C 下成立；脱离契约的「绝对安全」无定义（不是「安全」，而是「在 C 下足够安全」）；
(iii) **单向收窄**：任何未获授权或未认证的指令更新只能缩小可行动作集，不能扩大（定义 318）；
(iv) **残余义务不可丢弃**：指令中无法接地的部分成为显式 open obligation，必须参与保守退避，不得静默略过（定义 314）。

**定义 311（场景契约）** 契约 `C = (G, K, A, O, R, T, π)`：
- `G`：目标集（任务谓词与优先级）；
- `K`：硬约束（安全不变式、法规与社交禁令）；
- `A`：假设（环境类别、人类意图先验、传感器工况）；
- `O`：观测签名（该场景下状态/观测的期望分布参数，用于识别「我还在这吗」）；
- `R`：风险预算（`ε_task, λ_floor, c_max`，交互预算）；
- `T`：时域与失效触发条件；
- `π`：签发主体（authority，见定义 313）。
由语言指令 ℓ 与部署上下文编译得到。契约的安全域 `𝒮_C = {x,a : K(x,a) 成立}`。

**定义 312（语言指令编译与契约假设集）** 指令 ℓ。编译器输出 `H_ℓ = {(C_i, w_i, span_i)}_{i=1..n} ∪ ρ`：`C_i` 为契约假设，`w_i` 为其后验权重（解析、检索、世界模型一致性共同给出），`span_i ⊆ positions(ℓ)` 为该假设所依赖的指令片段（**出处**），`ρ` 为无法接地的残余（定义 314）。硬性落地约束：`K_i ⊇ K_core`，即任何解释都不得删掉基础安全内核。

**定义 313（权限账本 ALO）** 指令不是「内容」而是「带主体的提议」。账本 `L` 追加记录 `(principal, scope, signature, timestamp, parent, diff)`。主体分级：`owner > operator > bystander > environment_text`（标牌、网页、他人语音默认最低级）。规则：子主体权限不得高于父级；`environment_text` 永远无权签发「扩大类」更新。

**定义 314（未接地残余与开放义务）** `ρ = (ρ_sem, ρ_mot, ρ_ref)` 分别表示语义未覆盖、情态/程度未定、指代未定。每个残余生成一个 open obligation `o_j`，须在 `T` 内被满足、澄清或否定；未闭合期间，CGA 按「最保守一致解释」执行，其保守度计入 `U_resid`。

**定义 315（指令不确定性三分 UAD）** 相对指令 ℓ 与观测：
- **欠定**：`H_ℓ` 中多个 `C_i` 在安全相关动作排序上**一致** ⇒ 交集执行几乎无损（引理 19），不必提问；
- **歧义**：`C_i` 在动作排序上**冲突** ⇒ 必须走 R69 MINT 的 VoI 澄清；
- **失配/OOC**：观测与所有 live `C_i` 的 `O` 都不一致 ⇒ 场景漂移，进入契约吊销/转移（定义 319、322）。
三者对应三种正确反应：**执行 / 提问 / 降级或换契约**。R69 的 aleatoric/epistemic 只覆盖动作层，这里补上**指令-场景层**。

**定义 316（live 契约集）** `L_t = {C_i ∈ H_ℓ : OOC_t(C_i) ≤ τ_ooc 且 authority(C_i) 合法}`。若 `L_t = ∅` ⇒ 无契约，进入定义 325 的第三级。

**定义 317（契约相对可行动作集）** `𝒰(C) = {a : K_C(x,a) 成立}`；多契约鲁棒可行动作集 `𝒰(L_t) = ⋂_{C∈L_t} 𝒰(C)`。语义/指令只能通过**交集**加约束，不能取并放宽。基础内核 `𝒰_0 = ⋂` 所有不可协商约束的 `𝒰`，恒有 `𝒰(L_t) ⊆ 𝒰_0`。

**定义 318（单向收窄算子）** 指令更新 `u = (ℓ_new, principal)`：
- 未认证：`𝒰 ← 𝒰 ∩ 𝒰(compile(ℓ_new))`（只能收窄）；
- 仅当 `principal ≥ operator` 且 `ContractDiffCert(C_old→C_new)` 有效时，才允许 `𝒰 ← 𝒰(C_new)`（可在认证边界内放宽）。
即 **扩大安全集是特权操作，收窄是默认操作**。

**定义 319（OOC 分数）** 观测签名距离 `d_O(o, O_C)`；用序贯检验（e-value / CUSUM）：`OOC_t(C) = max_{s≤t} Σ_{k=s}^t log[p(o_k|O_C) / p(o_k|O_alt)]`。越过阈值即拒绝该契约，误报率 ≤ `α_OOC`。

**定义 320（契约差分证书 CDC）** `CDC(C_old→C_new) = (ΔG, ΔK, ΔA, ΔR, principal_sig, proof)`：只允许在 `ΔK` 不削弱基础内核、`ΔR` 不超部署上限、且 `ΔA` 被独立证据支持时签发。证书哈希并入 `J_SCRIPT`。

**定义 321（场景组合与认证覆盖）** 场景库 `𝒮 = {C_1..C_M}`（已认证）。覆盖 `cov(𝒮) = Σ_s π(s)·1[∃C∈𝒮 : s∈Dom(C)]`，`π(s)` 为部署场景分布。**场景驱动创新**由此形式化：创新预算按「新增认证场景带来的边际覆盖 × 风险降低」分配，而非按单一任务性能。

**定义 322（场景距离与转移）** 在 `(G,K,A,O,R)` 上加权距离 `d_𝒮(C,C')`；转移风险界 `risk(C') ≤ risk(C) + L·d_𝒮 + slack_conformal`（引理 22）。仅当 slack 可控且差异集中在非安全维（`ΔK≈0`）时准予转移。

**定义 323（指令干扰集 ℰ_instr）** 指令注入（外部文本冒充 operator）、场景伪装（伪造 `O` 使 OOC 不触发）、契约洗白（把危险意图编译成无害 `G`）、义务夹带（在长指令藏一条放宽约束）、跨场景重放（重放别场景的合法指令）。并入 AIC：`ℰ_SCRIPT = ℰ_FLUID × ℰ_instr × ℰ_scene`。

**定义 324（证书 J_SCRIPT）** `J_SCRIPT = (J_FLUID, contract_hash, instruction_provenance_hash, live_set_hash, ooc_p95, narrow_diff_cert, residue_obligations, coverage_delta, script_ver)`。Valid ⇔ `Valid(J_FLUID)` ∧ 契约链可追溯 ∧ 单向收窄未被违反 ∧ `ρ` 义务闭合（或已计入保守退避）。

**定义 325（三级保守退避）**
- **L1 契约内**：`L_t` 非空且无冲突 ⇒ `λ = λ_floor(U_ale)`（R69 的 resolution bonus，`U_epi` 按 R69 处置）；
- **L2 影子交集**：多契约冲突或欠定未闭合 ⇒ `λ = λ_floor(U_ale + U_epi + U_resid)`，动作限制在 `⋂𝒰(L_t)`（等价于「把所有解释都当真」）；
- **L3 无契约/OOC**：`L_t = ∅` ⇒ `λ = λ_floor(U_ale + U_epi + U_resid + U_OOC)`，回 R68 最保守，仅保留不可协商内核。
⇒ 安全侧逐级不弱，只有 L1 才拿效率。

**定义 326（场景驱动创新的优化目标）** 给定风险预算，选择场景 `s` 去认证/建图的收益 `= Δcov(s)·value(s) / c(s)`。覆盖函数对场景集合次模（定理 20），故贪心有 `(1−1/e)` 保证。这把「场景驱动创新」从口号变成可审计规则：**先做能新开一个认证场景的事，而不是把已覆盖场景再打磨 1%**。

## 2. 关键算法骨架

```python
# IP-265 NLIC：语言指令 → 契约假设集 + 残余（冻结 LLM，只读解析，带 span 出处）
def compile_instruction(ell, ctx):
    clauses = parse_typed(ell)                    # 输出 (语义子句, 字符区间 span)
    hyps, resid = [], Residue()
    for c in clauses:
        if groundable(c, ctx.ontology, ctx.world_model):
            hyps.append(make_contract(c, span=c.span, principal=ctx.principal))
        else:
            resid.add(c)                          # 不静默丢弃 → open obligation
    hyps = [H for H in hyps if H.K >= K_CORE]     # 任何解释不得删基础安全
    w = ground_posterior(hyps, ell, ctx)          # 解析/检索/一致性 → 权重
    return hyps, w, resid

# IP-268 UAD：三分（欠定 / 歧义 / 失配）——决定“执行 / 提问 / 降级”
def classify_instruction(hyps, w, o_t, cim):
    live = [H for H in hyps if cim.ooc(H, o_t) <= TAU_OOC]
    if not live:                     return 'mismatch'   # 观测不像任何 live 契约
    if action_ranking_agree(live, w): return 'underspec' # 动作序一致 → 交集即可
    return 'ambiguous'                                    # 动作序冲突 → 必须问

# IP-267 CGA：交集鲁棒执行——语义/指令只加约束
def contract_action(live, x, rho):
    U = intersect_admissible_sets(live, x)         # ⋂ K_C
    U = shrink_by_residue(U, rho)                  # 未接地残余 → 最保守解释
    return argmin_cost(U, x) if U else SAFE_STOP

# IP-269/270 ALO+CDC：默认收窄，放宽是特权
def instruction_update(ledger, ell, principal):
    if not ledger.authentic(principal):            # 冒充 → 只收窄
        return ledger.narrow(ell)
    diff = contract_diff(ledger.current, compile_instruction(ell, ledger.ctx))
    cert = contract_diff_cert(diff)                # 只许 ΔK 不削基础内核
    if cert.valid:
        return ledger.commit(ell, principal, cert) # 唯一可放宽路径
    return ledger.narrow(ell)                      # 失败 → 回默认收窄

# IP-266 CIM：场景漂移检测（序贯 e-value）
def ooc_score(contract, observations):
    return max_s_term(sum(log_p(contract.O, o) - log_p(O_alt, o)
                          for o in observations[s:]))

# IP-276 SCRIPT-RAS 主闭环（在 R69 的不确定性处置前插入契约层）
def SCRIPT_RAS_round(M, obs, ell):
    z, o = M.mtm.forward(obs)                       # R69 一次前向
    hyps, w, rho = M.nlic.compile(ell, M.ctx)
    kind = M.uad.classify(hyps, w, o, M.cim)        # underspec / ambiguous / mismatch
    live = M.cim.live_set(hyps, o)                  # 定义 316
    if kind == 'mismatch' or not live:              # L3：契约吊销
        lam = M.r68.lam_floor(U_ale + U_epi + U_resid + U_OOC)
        g = M.mint.choose_interaction(..., mode='reidentify')  # 最小再认证交互
        return M.r68.deploy(lam, g)
    # --- 以下沿用 R69 动作层：流匹配采样 + 不确定性二分 ---
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    g = None
    if kind == 'ambiguous' and U_epi > TAU_EPI:
        g = M.mint.choose_interaction(modes, o, M.budget)       # 只在冲突时问
    if g: U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    # --- 契约层：动作必须在所有 live 契约的交集内 ---
    a = M.cga.contract_action(live, x_t, rho)
    if kind == 'underspec':
        lam = M.r69.lam_floor(U_ale)                            # L1 欠定且一致
    else:
        lam = M.r69.lam_floor(U_ale + U_epi + U_resid)          # L2 影子交集
    a = project_into(a, intersect_admissible_sets(live, x_t))   # 再投影一次防越界
    M.vqa_i.submit_async(ell, live, kind, g, a)                 # 参与式审计
    return a, lam, (hyps, kind, rho)
```

## 3. 推导

**引理 19（欠定的廉价性）** 设 live 契约集在安全相关动作序上一致（存在公共最优 `a*`），则交集执行与任一契约单独执行的期望 regret 之差为 0；更一般地，若仅在概率质量 `μ` 上排序冲突、冲突代价上界 `Δ_max`，则期望 regret ≤ `2·Δ_max·μ`。要点：**欠定不等于要问**——只有当不同解释会改变「该不该动/往哪动」时才值得付交互成本。这是对 R69「有 epistemic 就问」的收敛：把提问预算从「熵大」移到「排序冲突」。

**引理 20（单向收窄 ⇒ 注入不可放宽）** 在权限账本（定义 313）与收窄算子（定义 318）下，任何未经认证的指令更新 `u` 都使 `𝒰` 单调不增：`𝒰_{t+1} ⊆ 𝒰_t`。故注入/洗白的物理后果被限制为**过度保守（DoS）**，而非不安全放大：`risk(a ∈ 𝒰_{t+1}) ≤ risk(a ∈ 𝒰_t) ≤ ε_0`。系：把「语言指令」从信任面移到威胁面后，最坏情况从「撞」降级为「停」。

**引理 21（OOC 检测时延）** 设 in-contract 观测分布 `P` 与漂移分布 `Q` 的 KL 率 `κ = KL(P‖Q) > 0`，序贯检验在误报率 `α` 下期望检测时延 `E[τ] ≤ log(1/α)/κ + 1`。故场景漂移可在有限步内被吊销；但对**慢漂移 `κ≈0`** 无检测保证——这是与 R68 缓变故障对偶的盲区（见最大风险）。

**引理 22（场景转移风险界）** 若 `risk(C)` 对契约参数 `(K,A,R)` 是 `L`-Lipschitz，且 `d_𝒮(C,C') = δ`，则 `risk(C') ≤ risk(C) + Lδ`；用 split-conformal 校准 slack。转移证书在 `ΔK≈0` 时 tight，在 `ΔK≠0` 时必须重新认证。系：**换场景不是换参数，是换安全证明**。

**引理 23（契约洗白上界）** 若编译器误接地率 `δ_c`、权限校验漏检率 `δ_a`，则「危险意图被编译成无害契约并通过差分证书」的概率 `≤ δ_c + δ_a − δ_c·δ_a`。系：authority 分离不能把风险降到 0，只能把风险从「运行时行为」转移到「编译与权限两个更小、可审计的面」。

**定理 18（SCRIPT 严格包含 FLUID/R68）** 当 ℓ 完全指定、`principal = owner`、`L_t` 单元素、无 OOC、`ρ = ∅` 时，SCRIPT 逐指令退化为 FLUID；当进一步 `VoI ≤ 成本` 时退化为 R68。故两层旧方案是 SCRIPT 在「单契约 + 可信 + 无漂移」边界上的截面；安全侧（`𝒰` 交集）恒不宽于 R68 基础内核。

**定理 19（注入下的安全性）** 在 (i) 权限账本、(ii) 单向收窄、(iii) 交集执行 下，任何 `ℰ_instr` 攻击都不能使实际执行动作越出 `⋂𝒰(L_t) ⊆ 𝒰_0`；物理风险 `≤ max_{C∈L_t} ε_C`。攻击者可影响的是**可用性/效率**（迫使降级 L2/L3），不是安全性。证明：由引理 20 与定义 317 直接合成；场景伪装至多把 `L_t` 改错，但改出的仍须是「合法且被认证」的契约，故仍受定义 320 的差分约束。

**定理 20（场景驱动创新的次模覆盖）** 覆盖函数 `cov(𝒮)` 关于场景集合单调次模；在预算 `Σc(s) ≤ B` 下贪心选场景满足 `cov(𝒮_greedy) ≥ (1−1/e)·cov(𝒮*) − ε_conc`。故「先开新认证场景」有形式化依据，创新分配从主观排序变成可审计的次模最大化。

**定理 21（场景切换的无突变）** 契约切换采用「交集过渡」：在 `T_handoff` 内始终执行 `𝒰(L_t) ∩ 𝒰(L_{t+1})`，`λ` 在过渡期单调不降；切换完成才释放旧约束。故控制连续、无突跳（继承 R68 定理 15 的换装不变式）。

## 6. 本轮最大风险

**一句话**：SCRIPT-RAS 把全部安全性押在「**编译出的契约忠实于人的真实意图，且此刻场景没有慢漂移**」上——单向收窄能挡住外部攻击者，却挡不住**编译器自己**把危险意图洗成一份「合法无害」的契约；再叠加慢漂移让 OOC（引理 21，`κ≈0`）形同虚设，系统就会拿着一份**看似已认证、实则锚错场景**的契约自信执行，把 R69 的「被证实的错误」升级成「**被认证的错误场景**」——这比说谎的回答更难被审计，因为它有一整条自洽的证据链。

**次级风险与缓解**：
1. **慢漂移检测盲区**（`κ≈0`）→ 与 R68 的残差/流似然通道联立（R69 Δa），场景签名不只比观测均值，也比「行为似然」这一不可被标定吸收的通道；
2. **契约洗白**（编译期误接地）→ span 级出处强制可审计 + 高风险子句双人复核 + E306 红队，但引理 23 说明只能降低、不能消除；
3. **OOC 误报导致 DoS**（环境本无害但被判定失配）→ 序贯检验的 `α_OOC` 与 L2/L3 分级退避，避免一次误报就全停；
4. **场景库过拟合**（只覆盖训练出现的场景）→ 覆盖目标显式惩罚 `π(s)` 长尾，保留「未知场景」的 L3 探底预算；
5. **多主体权限冲突**（owner 与 operator 指令矛盾）→ 权限账本严格偏序 + 冲突时默认收窄（定义 313），绝不取并。

## 3. 关键算法伪代码

```python
# IP-265 NLIC：语言指令 → 契约假设集 + 残余（冻结 LLM，只读解析，带出处）
def compile_instruction(ell, ctx):
    clauses = parse_typed(ell)                    # (语义子句, span)
    hyps, resid = [], Residue()
    for c in clauses:
        if groundable(c, ctx.ontology, ctx.world_model):
            hyps.append(make_contract(c, span=c.span, principal=ctx.principal))
        else:
            resid.add(c)                          # 不静默丢弃 → open obligation
    hyps = [H for H in hyps if H.K >= K_CORE]     # 任何解释不得删基础安全
    return hyps, ground_posterior(hyps, ell, ctx), resid

# IP-268 UAD：三分（欠定 / 歧义 / 失配）
def classify_instruction(hyps, w, o_t, cim):
    live = [H for H in hyps if cim.ooc(H, o_t) <= TAU_OOC]
    if not live:                     return 'mismatch'
    if action_ranking_agree(live, w): return 'underspec'
    return 'ambiguous'

# IP-267 CGA：交集鲁棒执行——语义/指令只加约束
def contract_action(live, x, rho):
    U = intersect_admissible_sets(live, x)         # ⋂ K_C
    U = shrink_by_residue(U, rho)                  # 未接地残余 → 最保守解释
    return argmin_cost(U, x) if U else SAFE_STOP

# IP-269/270 ALO+CDC：默认收窄，放宽是特权
def instruction_update(ledger, ell, principal):
    if not ledger.authentic(principal):
        return ledger.narrow(ell)                  # 冒充 → 只收窄
    diff = contract_diff(ledger.current, compile_instruction(ell, ledger.ctx))
    cert = contract_diff_cert(diff)                # ΔK 不削基础内核
    return ledger.commit(ell, principal, cert) if cert.valid else ledger.narrow(ell)

# IP-266 CIM：场景漂移检测（序贯 e-value）
def ooc_score(contract, observations):
    return max_s_term(sum(log_p(contract.O, o) - log_p(O_alt, o)
                          for o in observations[s:]))

# IP-276 主闭环
def SCRIPT_RAS_round(M, obs, ell):
    z, o = M.mtm.forward(obs)
    hyps, w, rho = M.nlic.compile(ell, M.ctx)
    kind = M.uad.classify(hyps, w, o, M.cim)
    live = M.cim.live_set(hyps, o)
    if kind == 'mismatch' or not live:              # L3：吊销契约
        lam = M.r68.lam_floor(U_ale + U_epi + U_resid + U_OOC)
        return M.r68.deploy(lam, M.mint.choose_interaction(..., mode='reidentify'))
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4   # 以下沿用 R69 动作层
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    g = (M.mint.choose_interaction(modes, o, M.budget)
         if kind == 'ambiguous' and U_epi > TAU_EPI else None)   # 只在冲突时问
    if g: U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    a = M.cga.contract_action(live, x_t, rho)                    # 契约层交集
    lam = (M.r69.lam_floor(U_ale) if kind == 'underspec'
           else M.r69.lam_floor(U_ale + U_epi + U_resid))
    a = project_into(a, intersect_admissible_sets(live, x_t))
    M.vqa_i.submit_async(ell, live, kind, g, a)
    return a, lam, (hyps, kind, rho)
```

## 4. 推导

**引理 19（欠定的廉价性）** live 契约在动作序上一致时，交集执行 regret 增量为 0；一般情形 `regret ≤ 2·Δ_max·μ`（`μ` 为排序冲突概率质量）。系：**欠定≠要问**，提问预算应从「熵大」移到「排序冲突」。

**引理 20（单向收窄 ⇒ 注入不可放宽）** 未认证指令更新使 `𝒰_{t+1} ⊆ 𝒰_t`，故注入/洗白的物理后果被限制为 DoS：`risk(a∈𝒰_{t+1}) ≤ risk(a∈𝒰_t) ≤ ε_0`。系：把语言移到威胁面后，最坏从「撞」降为「停」。

**引理 21（OOC 检测时延）** KL 率 `κ>0` 时 `E[τ] ≤ log(1/α)/κ + 1`；慢漂移 `κ≈0` 无检测保证（本轮最大风险）。

**引理 22（场景转移界）** `risk(C') ≤ risk(C) + L·d_𝒮 + slack_conformal`；`ΔK≈0` 时 tight，`ΔK≠0` 必须重认证。系：换场景不是换参数，是换安全证明。

**引理 23（契约洗白上界）** 误接地率 `δ_c`、权限漏检 `δ_a` ⇒ 洗白通过率 `≤ δ_c + δ_a − δ_cδ_a`。系：authority 分离只把风险转移到编译/权限两个更小的可审计面，不归零。

**定理 18（SCRIPT 严格包含 FLUID/R68）** 完整指令 + owner + 单 live 契约 + 无 OOC + `ρ=∅` 时逐指令退化为 FLUID；再 `VoI≤成本` 退化为 R68；安全集 `⋂𝒰` 恒不宽于 R68 内核。

**定理 19（注入下的安全性）** 权限账本 + 单向收窄 + 交集执行 ⇒ 任何 `ℰ_instr` 不能使动作越出 `⋂𝒰(L_t) ⊆ 𝒰_0`，物理风险 `≤ max_C ε_C`；攻击只影响可用性/效率，不影响安全性。

**定理 20（场景驱动创新的次模覆盖）** `cov(𝒮)` 单调次模；预算 `Σc(s)≤B` 下贪心 `cov ≥ (1−1/e)·cov* − ε_conc`。故「先开新认证场景」有形式化依据。

**定理 21（场景切换无突变）** 切换期执行 `𝒰(L_t) ∩ 𝒰(L_{t+1})`、`λ` 单调不降；完成才释放旧约束 ⇒ 控制连续，继承 R68 定理 15。

## 7. 本轮最大风险

**一句话**：SCRIPT-RAS 把全部安全性押在「**编译出的契约忠实于人的真实意图，且此刻场景没有慢漂移**」上——单向收窄能挡住外部攻击者，却挡不住**编译器自己**把危险意图洗成一份「合法无害」的契约；再叠加慢漂移让 OOC（引理 21，`κ≈0`）形同虚设，系统就会拿着一份**看似已认证、实则锚错场景**的契约自信执行，把 R69 的「被证实的错误」升级成「**被认证的错误场景**」——它有一整条自洽证据链，比说谎的回答更难被审计。

**次级风险与缓解**：慢漂移盲区 → 与 R68 残差/R69 流似然 `Δa` 联立，场景签名兼比行为似然；契约洗白 → span 出处 + 高风险子句双人复核 + E306，但引理 23 只能降不能消；OOC 误报致 DoS → `α_OOC` 与 L2/L3 分级退避；场景库过拟合 → 覆盖目标惩罚 `π(s)` 长尾并留 L3 探底预算；多主体冲突 → 严格偏序 + 冲突默认收窄，绝不取并。
