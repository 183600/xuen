## 1. 直觉与动机

### 灵感 1（自适应控制）：策略是开环动作块生成器，泛化缺口有一部分其实在「执行」不在「认知」

**直觉**：现在的 VLA 在 `get_action` 里一次吐出一整块位置目标，评测器开环执行到块尾才给下一次反馈。行为克隆的复合误差（covariate shift）、未见物体的质量/摩擦差异、以及 N 台机器人的标定/动力学差异，都会让「想让它去的位置」和「它实际到的位置」出现系统性偏差。这类偏差**不需要重训模型**，只需要在动作目标层加一个低维、有界、可冻结的自适应前馈——补偿标定零偏、重力下垂、物体引起的偏转。反直觉点：**泛化缺口的一部分不是模型没见过，而是机器人没被执行到位；这部分可以用控制律补，而不必用数据补。**

**严谨定义**：把「策略 + 评测器 + 机器人」看成一个离散时间闭环。设块边界时刻为 k，策略给出参考块 \(r_k \in \mathbb{R}^{T_a \times m}\)（绝对位置目标），实际状态为 \(y_k\)，plant 含未知常值/慢变扰动 \(d_k\) 与延迟 \(\tau\)：\(y_{k+1}=P(u_k)+d_k\)。自适应校正器维护低维参数 \(\theta_k\)（偏差 \(b\)，可选增益 \(g\)），按鲁棒自适应律

\[
b_{k+1}=\mathrm{Proj}_{[-b_{\max},b_{\max}]}\big((1-\sigma)b_k-\Gamma e_k\big),\qquad e_k=y_k-u_{k-1,\text{last}}
\]

输出 \(u_k = y_{\text{anchor}} + g\,(r_k-y_{\text{anchor}}) + \rho_k\odot b_k\)（\(\rho_k\) 为块内淡入斜坡，防指令突跳）。稳定条件：反馈周期 \(\Delta=T_a/f_c\) 大于 plant 延迟约 3 倍、\(\Gamma\) 取保守界 \(2/(L\Delta)\) 的 1/10、死区大于噪声、投影 + σ 修正保证有界、振荡/低激励时冻结。**这不是「再学一个模型」，而是给已有策略加一个控制律**，因此不触碰单模型边界。

**关键接口洞察**：`action_chunk_size` 是我们自己选的——它同时是「推理调用次数」和「反馈带宽」的旋钮。若推理 p99 小于单步预算（I6 目标 <40ms vs 15Hz≈66ms），可令 \(T_a=1\)，把反馈率拉到 15Hz，足以抑制 2–5Hz 的慢变偏差；若模型慢，则被迫用大 \(T_a\)，带宽下降。**I6 的低延迟不只是部署稳定，它是 I10 自适应带宽的前提**。

### 灵感 2（ROS2）：不在计分路径，但在「安全地测量与验证」路径

**直觉**：提交接口是 websocket/msgpack，不是 ROS2；把 ROS2 放进提交链路只会增加延迟与合规风险。但机器人底层是 CycloneDDS，ROS2 与 DDS 同源（F24），所以 ROS2 是「把真机实验从一次性、不可复现，变成可录制、可回放、可注入扰动的受控实验」的最低摩擦底座。没有它，任何在线自适应都是盲调——你不知道 plant 的延迟、增益、带宽，就不知道积分增益该取多大，第一次上真机就可能把稳定误差变成振荡。反直觉点：**ROS2 的价值不在「让策略跑得更快」，而在「让我们更早知道策略会不会把机器人搞坏、以及为什么」。**

**严谨定义**：构建一个 **HIL（hardware-in-the-loop）实验台**：`PolicyService`（与提交完全同协议）← websocket → `EvaluatorEmulator` → ROS2 节点图 → {`unitree_mujoco`/Isaac Lab 仿真 | G1 真机 via `unitree_ros2`}；旁路 `rosbag2` 飞行记录器与 `system_id` 激励器。它产出三样东西：(a) plant 的延迟/增益/带宽辨识；(b) 可回放的失败片段（仅用于我们自己的验证/调试，不回流评测数据）；(c) L0.5 级离线消融——比纯 L0 高保真、比真机 L2 便宜，专门验证 I10 的稳定性与 I11 的配比策略。ROS2 的 QoS/生命周期/实时执行器/rosbag2 正好覆盖这四件事（F26）。

### 灵感 3（自适应控制 × 数据引擎）：把上一轮的「负迁移」风险变成受控反馈回路

**直觉**：上一轮最大的风险是 110 语料淹没 32 考题、孪生任务负迁移，而官方 loader 的 weight 不生效（F11），只能手工家族权重。手工权重是开环的：你定完就不知道训练中哪一族正在伤害哪个任务。自适应控制提供现成范式——把「数据配比」当自校正调节器：plant 是每任务验证进度，控制器按反馈调整各族采样权重，检测到「加入孪生族 i 后挑战任务 j 退步」就自动降权。反直觉点：**负迁移不该靠人工预判，而该靠训练期的反馈回路自动止损。**

**严谨定义**：训练期多目标配比控制。设族权重 \(w_i\)，验证得到每任务进度 \(s_j\)；定义族效用 \(u_i=s_i-\lambda\sum_{(i,j)\in\text{TWIN}}[s_j<s_j^{-}-\delta]\)（负迁移惩罚），按乘性权重更新 \(w_i\propto w_i e^{\eta u_i}\)，投影到 \([w_{\min},w_{\max}]\)、归一化、加滞后与信任域防震荡。这是训练期优化，不涉及评测期在线学习，合规无虞。

**三者统一**：上一轮的数据引擎回答「训练时怎么补」，自适应控制回答「运行时怎么补」，ROS2 回答「怎么安全地测量和验证这个补」。三者合起来是一条闭环：**训练配比（I11）→ 策略（既有）→ 运行时校正（I10）→ HIL 测量（I12）→ 反哺配比与校正参数**。本轮结论：**数据侧红利见顶后，下一个分数增量来自执行侧闭环；而执行侧闭环的前提是可辨识的实验基础设施。**

## 2. 对上一轮痛点的增量修订

- P1（弱任务平均）/P5（时间压力）：I10 降低长程复合误差与块尾漂移，直接抬步骤分与成功率。
- P2（泛化缺口）：I10 用运行时前馈吸收质量/摩擦差异，是 I1（考纲增广）与 I9（检索类比）之外的**第三条路径**——前两条改训练分布，这一条改执行误差。
- P4（无触觉）：用 tracking error + 视觉滑移作「虚拟力」代理，自适应估计负载/接触刚度；不替代触觉，但补上「抓取力自适应」这一层。
- P6（部署）：I10 后处理开销微秒级，但 \(T_a\) 变小会增加推理调用 → 延迟预算需重算；I6 的 p99<40ms 从「加分项」升级为「I10 的前置条件」。
- P7（先手窗口）：先建 HIL 台架的队伍更早拿到可信的 plant 模型与失败片段，先手复利从「数据」扩展到「实验能力」。
- P8（示教质量）：飞行记录器把「失败」变成可分析资产；但**评测期数据不得回流训练**（诚信红线），只用于调试与验证。
- **新增 P9（反馈带宽硬约束）**：反馈只在 chunk 边界，带宽 ≈ \(f_c/T_a\)；小 \(T_a\) 受推理延迟约束，大 \(T_a\) 丢失扰动抑制——这是新的设计权衡。
- **新增 P10（N 台异构机器人）**：不同机器人标定/动力学/延迟不同；单一策略无 per-robot 适配。默认只做「每 episode 重置」的在线偏差补偿，跨 episode 持久化需书面确认。
- **新增 P11（plant 不可辨识）**：没有延迟/增益/带宽辨识，在线自适应只能盲调，真机预算被浪费。

## 3. 研究问题（本轮立项 Q9–Q11，Q1–Q8 保留）

- **Q9（动作层自适应的稳定性）**：在反馈周期 \(\Delta=T_a/f_c\)、未知延迟 \(\tau\)、仅位置目标通道下，何种自适应律（积分 + 死区 + 投影 + σ 修正 + 冻结）能保证有界稳定并吸收系统性偏差，且不与底层位置控制器打架？可证明的安全包络与在线冻结判据是什么？
- **Q10（自适应数据配比）**：以每任务验证进度为反馈的配比控制器，能否自动抑制孪生负迁移、替代手工家族权重？如何避免验证集过拟合、权重震荡与「饿死」远任务？
- **Q11（HIL 保真度）**：ROS2/DDS HIL 台架辨识出的延迟/增益/带宽，能否让 L0.5 离线消融对真机增益的相关性显著高于纯 L0（I8 注册表）？

## 4. 设计原则（新增 PR6–PR8，其余保留）

- **PR6 闭环执行律**：任何开环动作块都必须配一个有稳定性论证的闭环校正器；校正器的反馈带宽必须与接口反馈率 \(f_c/T_a\) 匹配，禁止「盲积分」。
- **PR7 可辨识律**：任何在线自适应必须先有 plant 系统辨识（延迟/增益/带宽）与 HIL 稳定性验证，否则不得上计分通道。
- **PR8 合规优先律**：运行时自适应默认「每 episode 重置、有界、不利用评测标签、不持久化」；任何跨 episode 持久化或跨机器人迁移，须先向组委会书面确认。
- PR1–PR5 保留（第 1/2 轮）。

## 6. 本轮最大风险

**一句话**：I10 的自适应律建立在「低频反馈 + 未辨识延迟」之上——若 plant 延迟接近或超过反馈周期，积分作用会把稳定偏差变成极限环，而「运行时自适应是否算在线适应评测分布」尚未获组委会确认；因此 I10 必须先过 I12 的 HIL 系统辨识与有界/可冻结验证，否则不得上计分通道。

## 0. 创新点清单（每点：动机 / 与现有方案差异 / 技术可行性 / 所需资源 / 落地步骤 / 风险）

### I10 动作空间自适应校正器（AAC）★★★★★

- **动机**：策略一次吐出一整块绝对位置目标，评测器开环执行到块尾才反馈（F20/F21）；行为克隆复合误差、未见物体质量/摩擦、N 台异构机器人的标定/动力学差异，都会造成「指令位姿」与「实际位姿」的系统性偏差（P1/P2/P9/P10）。位置通道（F22）不允许改底层控制器，但允许在**动作目标层**补偿低频偏差。
- **与现有方案差异**：直接 SFT 无运行时校正；I3 是接触段专用关键点伺服；I10 是全局、低维、有稳定性论证的偏差补偿，与 I3 互补（I3 提供接触观测源，I10 做动作修正）；I4 调 chunk 长度，I10 调 chunk 内容。核心差异是**用控制律而非新数据/新模型**吃执行误差。

### 1.1 动作层自适应校正器（I10，bias-only 基线 + gated gain）

```python
import numpy as np

class AdaptiveActionCorrector:
    """仅位置目标通道：补偿低频系统性偏差；不改策略权重。
    参考：积分型扰动观测器 + 投影/σ修正 + 死区 + 振荡冻结。"""
    def __init__(self, m=6, gamma_b=0.05, gamma_g=0.02, sigma=0.01,
                 deadband=2e-3, b_max=0.02, g_lo=0.8, g_hi=1.2,
                 excite=5e-3):
        self.b = np.zeros(m)            # 偏差估计（m/rad）
        self.g = np.ones(m)             # 增益估计（仅 ee 启用）
        self.gamma_b, self.gamma_g = gamma_b, gamma_g
        self.sigma, self.deadband = sigma, deadband
        self.b_max, self.g_lo, self.g_hi = b_max, g_lo, g_hi
        self.excite = excite
        self.prev_e, self.frozen = None, False

    def update(self, y_prev, y_now, u_prev_first, u_prev_last):
        dy = y_now - y_prev
        du = u_prev_last - u_prev_first
        e = dy - du                       # 位移跟踪误差（块间）
        if np.linalg.norm(e) < self.deadband:
            self.b *= (1 - self.sigma)     # 无偏差时缓慢遗忘，防漂移
            return
        # 振荡检测：误差方向在相邻 chunk 反复翻转 → 冻结自适应
        if self.prev_e is not None and np.dot(e, self.prev_e) < 0:
            self.frozen = True
        if self.frozen:
            return
        # 偏差积分 + 投影 + σ修正（保证有界，防积分饱和）
        self.b = np.clip((1 - self.sigma) * self.b - self.gamma_b * e,
                         -self.b_max, self.b_max)
        # 增益自适应只在持续激励时启用，避免低激励下的病态辨识
        if np.linalg.norm(du) > self.excite:
            self.g = np.clip(self.g + self.gamma_g * e / (np.abs(du) + 1e-6),
                             self.g_lo, self.g_hi)
        self.prev_e = e

    def correct(self, chunk, y_anchor):
        # chunk: (T,m) 绝对目标；y_anchor: 上一块结束时的实际状态
        T = len(chunk)
        ramp = np.linspace(0, 1, T)[:, None]   # 块内淡入，防指令突跳
        return y_anchor + self.g * (chunk - y_anchor) + ramp * self.b
```

**稳定性/鲁棒性条件（写入 I10 验收）**：
1. 反馈周期 \(\Delta=T_a/f_c\)，要求 \(\Delta \gtrsim 3\hat\tau\)（\(\hat\tau\) 由 I12 辨识）；否则降 \(\Gamma\) 或冻结。
2. \(\Gamma_b \le 0.1\cdot 2/(L\Delta)\)，\(L\) 为 plant 增量增益估计；先保守后放量。
3. 死区 > 传感器噪声 + 未建模动态；投影 + σ 修正保证 \(b\) 有界、无漂移。
4. 冻结条件：误差方向翻转、低激励、策略不确定度高、接触过渡期。
5. 只补偿「方向一致、跨 chunk 平滑」的低频分量；任务性误差不补。

### 1.2 抓取滑移自适应（I10-G，无触觉下的「虚拟力」）

```python
class GripperSlipAdapter:
    """视觉滑移 + 指令/实际开度差 → 抓取力自适应（无触觉，F8）。
    输出为夹爪目标开度的偏置；负值 = 更闭合。"""
    def __init__(self, g_min=-0.02, g_max=0.0, gamma=0.002,
                 slip_tau=0.5, gap_tau=2.0):
        self.bias = 0.0
        self.g_min, self.g_max, self.gamma = g_min, g_max, gamma
        self.slip_tau, self.gap_tau = slip_tau, gap_tau

    def update(self, cmd_open, act_open, obj_motion_in_gripper):
        slip = max(0.0, obj_motion_in_gripper)     # 视觉：物体相对夹爪滑移
        gap = max(0.0, cmd_open - act_open)        # 指令闭合但未到位
        if slip > self.slip_tau or gap > self.gap_tau:
            self.bias = np.clip(self.bias - self.gamma * (slip + gap),
                                self.g_min, self.g_max)
        else:
            self.bias *= 0.99                      # 缓慢释放，防越抓越紧
        return self.bias

    def correct(self, grip_cmd):
        return np.clip(grip_cmd + self.bias, 0.0, 1.0)
```

### 1.3 自适应时域（I4 v2，控制带宽预算）

```python
import math

def choose_chunk(L_p99, f_c, e_norm, tau_hat,
                 T_MIN=1, T_MAX=16, E_HI=0.01, E_LO=0.002):
    # 实时性：推理必须在 T_a/f_c 内完成，留 20% 余量
    T_min = max(1, math.ceil(L_p99 * f_c / 0.8))
    # 稳定性：反馈周期至少覆盖约 3 倍 plant 延迟
    T_stab = max(1, math.ceil(3 * tau_hat * f_c))
    T = max(T_min, T_stab)
    if e_norm > E_HI:
        T = max(T_MIN, T // 2)          # 误差大 → 加密反馈
    elif e_norm < E_LO:
        T = min(T_MAX, T * 2)           # 稳定 → 降调用、省延迟
    return int(min(max(T, T_MIN), T_MAX))
```

### 1.4 自适应数据配比控制器（I11，训练期）

```python
class AdaptiveMixtureController:
    """训练期自校正配比：plant = 每任务验证进度；仅训练用，无评测合规问题。"""
    def __init__(self, families, twins, eta=0.1, lam=0.5, delta=0.01,
                 w_min=0.02, w_max=0.6, smooth=0.5):
        n = len(families)
        self.w = {f: 1.0 / n for f in families}
        self.twins = twins          # {twin_family: [challenge_task, ...]}
        self.eta, self.lam, self.delta = eta, lam, delta
        self.w_min, self.w_max, self.smooth = w_min, w_max, smooth
        self.prev = None

    def step(self, score):          # score: {task: progress in [0,1]}
        if self.prev is None:
            self.prev = dict(score)
            return self.w
        util = {}
        for f in self.w:
            u = score.get(f, 0.0) - self.prev.get(f, 0.0)
            for j in self.twins.get(f, []):          # 负迁移检测
                if score[j] < self.prev[j] - self.delta:
                    u -= self.lam
            util[f] = u
        z = {f: self.w[f] * np.exp(self.eta * util[f]) for f in self.w}
        Z = sum(z.values())
        raw = {f: z[f] / Z for f in z}
        # 投影 + 平滑（信任域），防震荡与饿死
        self.w = {f: (1 - self.smooth) * self.w[f]
                     + self.smooth * float(np.clip(raw[f], self.w_min, self.w_max))
                  for f in self.w}
        s = sum(self.w.values())
        self.w = {f: v / s for f, v in self.w.items()}
        self.prev = dict(score)
        return self.w
```

## 4. 伦理合规 checklist（本轮新增两项）

- [ ] **I10 合规确认（新增）**：AAC 是对自身输出的确定性、有界、零权重更新后处理，不使用评测标签；仍需向组委会书面确认「运行时动作后处理/自适应」是否属于允许组件。
- [ ] **持久化边界（新增）**：默认每 episode 重置；跨 episode 的 per-robot 标定持久化一律关闭，除非书面确认。

## 5. 关键取舍（本轮新增）

- **I10 vs I7**：两者争同一延迟预算；I10 是低维控制律、可证明有界、成本低；I7 是高成本世界模型 rollout。I10 过 L0.5 即裁 I7。
- **小 \(T_a\) vs 推理负载**：\(T_a=1\) 给最高反馈带宽，但调用数 ×8；若 GPU 吞吐不足，退回 \(T_a=2\) 并用低增益。
- **在线自适应 vs 合规**：默认最小化（每 episode 重置、有界、冻结），把「跨 episode 学习」留到组委会确认之后。
