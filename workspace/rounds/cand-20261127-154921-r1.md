## 1. 直觉与动机（两个灵感的碰撞）

**灵感 1（模仿学习 → 这场考试的敌人是协变量偏移，不是模型容量）**
直觉：赛题本质是行为克隆（BC），而 BC 的死穴是训练态与部署态不匹配：策略一旦走偏，就进入示教里从未出现的状态，错误按 O(T²ε) 复合。32k 条示教全是干净成功，等于把「走偏后怎么回来」从训练分布里删掉了。第 2 轮提出「合成失败示教」方向正确，但把引擎押在仿真上——本轮核实发现仿真既不覆盖 32 任务，又与真机有单目/双目与视觉鸿沟（F20/F21），所以**恢复数据只能从真实示教里「重组」出来**：状态拼接（用 B 轨迹的专家动作标注 A 轨迹的偏离态）、位置轴的等变重标注、以及（若开发通道允许）真实 rollout 的过滤 BC。核心反直觉点：**恢复能力不是加一个恢复模块，而是把示教流形上原本零测的「偏离态→专家动作」补成有正测度的训练集；没有仿真也能做，但必须用「覆盖判据」防止标签幻觉。**

**灵感 2（迁移学习 → 语义像 ≠ 动力学像，孪生表必须被测量而不是被猜）**
直觉：110 语料里最像的源任务，未必是最该迁移的源任务。ZipUp 与 Unzip 在语言与视觉上几乎同义，但拉链受力方向相反——这正是负迁移的教科书案例；只看 VLM 嵌入会把它们排成最高相似。迁移学习的正确姿势是三件事：(a) 用 NTG/Ben-David 界把「负迁移」写成可检验命题；(b) 用**双因子**（视觉语义 × 动作动力学）给源任务打分，动力学因子做硬门禁；(c) 静态分数不可全信（F23 明确其对微调预测差），必须用**短代理跑**在族级校准后才可放量。核心反直觉点：**源任务选择的第一性指标是动作轨迹的相位对齐相似度，而不是语义相似度；语义只用来召回候选，动力学用来否决。**

**两者统一**：赛题 = 「冻结视觉骨干 + 多源离线 BC + 协变量偏移」的联合问题。两个失败模式——恢复数据缺失（IL）与源任务负迁移（TL）——都发生在数据侧，且都可以用**先测量、后放量**的同一条纪律治理。本轮结论：**数据引擎的下一步不是加数据，而是加两个仪表：恢复覆盖率与可迁移性分数。**

## 3. 研究问题（本轮立项 Q9–Q11，Q1–Q8 保留）

## 4. 设计原则（新增 PR6/PR7，PR1–PR5 保留）

- **PR6 代理效度门禁**：任何离线代理（仿真、WMA、可迁移性分数、动作一致性）在未用 ≥N 个真机点校准、且秩相关达阈值前，只能做排序参考，不能单独决定 L2 真机预算或数据放量。
- **PR7 恢复覆盖律**：每条新增训练数据必须回答「它是否增加了偏离态上的恢复监督」或「它是否有经测量的正迁移」；两者都答不出的数据默认零权重。与 PR5 互补：PR5 管「教什么行为」，PR7 管「教不教得到恢复」。
- PR1–PR5 保留（第 2 轮 §4）。

# UniBot-V1 参赛创新点清单（第 3 轮 v1.2）

> 检索日期：2026-11-26 / 2026-11-27 / 本轮 2026-11-27。承接 v1.1：I1/I2/I5/I8 深化，I3 略降，I7 裁撤测试时路径，新增 I10（迁移学习）与 I11（因果混淆）。清单只增改不重置。

## 0. 创新点清单（每点：直觉 / 严谨机制 / 与现有方案差异 / 资源 / 落地 / 风险）

### I1 v3 考纲校准五轴增广引擎 ★★★★★
- **直觉**：评测的 5 条泛化轴是开卷的；增广不是「多加点随机」，而是「按考纲出模拟题」，把零样本泛化尽量变成分布内泛化。
- **严谨机制**：每任务一张考纲卡（位置半径、干扰物集合、背景纹理集合、未见物品类别/外观范围），增广参数从考纲卡分布采样。v3 两处修正：①位置轴不再做「像素重拼接」（物理不可行），改为 I5 的**等变重标注**（对目标/夹爪施加 SE(2)，动作同步变换）；②背景/干扰物轴与 I11 的**反事实配对**共用同一渲染器，保证「只改冗余变量」的配对可追溯。
- **与现有方案差异**：直接 SFT 用标称数据；盲目增广用无校准随机化；本点把增广对准计分轴，并用因果阶段限制避免教出伪相关。
- **资源/落地**：32 张考纲卡（LLM 解析 wiki + 人工校对）；背景/干扰物按考纲放量；外观/位置先过 L0；剂量-响应定档；轴间交互 2 档析因。
- **风险**：考纲卡偏差；等变只对位置轴严格成立；背景增广可能引入伪相关（由 I11 的敏感度比 R 守门）。

### I2 v3 数据引擎 3.0：门禁式多源共训 ★★★★★
- **直觉**：110 源任务不是「越多越好」，而是「先证明它教的是 eval 分布内、且动力学不冲突的行为」。源选择从猜变成测。
- **严谨机制**：三件事。①**源选择**由 I10 的双因子 τ 与短代理跑 Δ 共同决定，未过门禁的源权重为 0（不再有「远任务一律 5%」的经验值）；②**族级加权采样**：patch 官方 ConcatDataset 的按样本数混采（F11），实现「32 全量 + 正迁移族按 τ 加权 + 负迁移族剔除」；③**示教质量加权**：progress efficiency × smoothness × success margin，剪最差 10%，并把「离流形过远」的合成样本降权（与 I5 覆盖判据共用）。
- **与现有方案差异**：均匀混训把容量浪费在已会/负迁移源上；本点每个源都有可审计的准入理由。
- **资源/落地**：孪生子集 ≈1–2TB；1×24GB 起步；先离线算 τ（不训练）→ 族级短代理跑 → patch sampler 单测（统计 batch 内族频率）→ 首轮共训 → L0 正/负迁移验证。
- **风险**：τ 与 Δ 的族级秩相关不达阈值时退化为「仅 32 任务 + 少量人工白名单」；相机配置不一致需先抽样核对。

### I3 接触任务族关键点视觉伺服回退 ★★★☆（略降）
- 六要素同 v1.1：接近段用通用 chunk 策略、接触段用几何伺服，同一 PolicyService 内混合推理（PR2 边界待书面确认）；`ee` 控制空间 + per-step 调用天然支持；开放词汇检测零训练起步；触发滞回 + 低置信回退。
- **本轮修正**：仿真验证路径作废（F21），接触段只能靠真机单任务通道抽测，故降半星；**降级预案 I3'** 保留（组委会若裁定混合推理违规，改为训练时辅助监督，推理纯端到端）。
- **风险**：无触觉 + 仿真不可验证，接触段调参依赖稀缺真机预算。

### I4 人手干预感知门控 + 自适应 chunk ★★★★（维持）
- 手部检测 + `obs_delta_indices` 历史栈判别干预（<50ms）；状态机 INTERFERED→停持→重估→续做；干预态短 chunk（4–6 步）/稳定态长 chunk（8–16 步），参照 WMA-0 15Hz/horizon 16 的量级（F12）。
- **风险**：误检导致频繁停持，需在真机标定滞回阈值。

### I5 v3 恢复示教合成（无仿真版） ★★★★★（↑）
- **直觉**：策略不会恢复，不是因为没有恢复模块，而是因为示教里没有「走偏」这个状态。数据集全是成功轨迹，偏离态是零测集；仿真又补不了（F20/F21），所以从**真实示教重组**出偏离态与恢复标签。
- **严谨机制**：构造 D_rec = {(s', a')}，三条来源：
  1. **状态拼接（最近邻重标注）**：s' = s_t^A，a' = a_u^B，u = argmin_{u: phase(u)=phase(t)} d(φ(s_t^A), φ(s_u^B))，要求 d < δ 且因果阶段一致。等价于在专家状态流形上做局部 DAgger——用 B 轨迹的专家动作标注 A 轨迹的偏离态。
  2. **等变重标注（位置轴）**：对目标/夹爪施加 T ∈ SE(2)，动作按 T 变换（`ee`-delta 等变），生成 (T·s, T·a)。仅用于任务对 T 等变的阶段（接近/放置/插入）。
  3. **真实 rollout 过滤 BC（可选，取决于开发通道合规性）**：用当前策略在单任务开发通道跑，按得分点里程碑保留「偏离→恢复→得分」片段，做 advantage-weighted BC；与计分评测严格隔离。
- **覆盖判据**（防止标签幻觉）：ρ_rec = P_{s'~D_rec}[d(s', manifold(D_E)) < δ]，κ = P[||a' − π_E(s')|| ≤ ε_a]。目标是一个**中间带** ρ_rec ∈ [ρ_lo, ρ_hi] 且 κ ≥ κ_min：太接近流形 = 没教恢复；太远 = 最近邻标签不可信。该带正对应 Goldilocks regime 的有限密度比假设（F22）。
- **与现有方案差异**：v1.0 手工恢复原语引入新动作分布；v1.1 依赖仿真/WMA；v3 只用真实数据重组，并用覆盖判据量化「教到了多少恢复」。
- **资源/落地**：状态拼接与等变重标注是 CPU/GPU 数据工程（2 人周）；φ 用冻结 VLM/DINOv2；3 个弱任务（PlugCharger/ZipUp/PourOutMedicine）先试点；LoRA 增量训练；单任务通道 A/B（恢复成功率、步骤分增量）。
- **风险**：最近邻在阶段错配时标签错误（用阶段切分 + 距离阈值 + κ 门禁）；等变对非位置轴不成立；开发通道数据使用需书面合规确认。

### I6 确定性低延迟部署服务 ★★★★（维持）

- **风险**：量化后动作分布漂移，需 PR4 动作健康度回归。

### I7 世界模型测试时前瞻 ★★（裁撤测试时路径）
- **本轮决定**：测试时 O(1–2) 次 rollout 择优**裁撤**——延迟预算与 F21 的仿真/世界模型保真度都不支持。WMA-0 仅保留为 I5 的**可选**数据源，且必须先过 PR6 的物理一致性门禁（生成段与真实段的关键点/动作一致性）。
- **风险**：WMA 生成数据若未过门禁，会污染 I5；默认关闭。

### I8 v3 评测运营闭环 + 代理效度校准器 ★★★★★
- **直觉**：真机预算稀缺，离线代理必须「持证上岗」；注册表的产出不是「哪个模块有效」，而是「哪个离线指标值得信」。
- **严谨机制**：L0/L1/L2 分级保留；注册表升级为**代理效度校准器**，登记四类代理与真机增益的配对：①仿真成功率（F21 后预计效度极低，作为反例基线）；②双因子 τ 的族级排名；③恢复覆盖 ρ_rec/κ；④离线动作一致性 Δact。每类代理滚动算 Spearman ρ；只有 ρ ≥ 0.6 且样本 ≥ N_min 的代理，才可单独决定 L2 准入（PR6）。
- **落地**：先用 3–4 个已知真机结果回填；首个真实用例 = I10 源族筛选；每次 L2 后自动回填。
- **风险**：相关性建立慢；早期只能用排序而非绝对值。

### I9 reset 期检索类比迁移 ★★★★（维持）
- 在 `reset()`（每 episode 一次，F18）用 VLM/DINOv2 嵌入把首帧目标物体映射到「物体-技能库」，检索到的动作参数作软先验；距离阈值门控，超阈退回无先验；零权重更新、episode 内缓存。
- **本轮复用**：其视觉嵌入直接作为 I10 的 V 因子，不重复建设。
- **风险**：误检索伤标称任务；「同类不同外观」嵌入不敏感；合规性待书面确认。

### I10 双因子可迁移性估计 + 负迁移门禁（新） ★★★★★
- **直觉**：语义像 ≠ 动力学像。ZipUp 与 Unzip 语言/视觉几乎同义，但拉链受力方向相反——只看 VLM 会把最危险的源排成最相似。正确顺序是：语义召回候选，动力学否决候选。
- **严谨机制**：
  - **视觉语义因子** V(s,t) = cos(mean_pool φ(o_s), mean_pool φ(o_t))，φ 为冻结 VLM/DINOv2 的多帧池化嵌入。
  - **动作动力学因子** D(s,t) = exp(−λ_d · DTW(ā_s, ā_t))，ā 为按**夹爪开合事件**分段、按任务相位与尺度归一化后的动作序列（`ee`-delta + gripper）；可用 OT/Wasserstein 替代 DTW。
  - **可迁移性分数** τ(s,t) = V^α · D^β；准入是**合取门**：D ≥ d_min 且 V ≥ v_min，否则权重 0（乘积会掩盖「V 极高、D 极低」的 ZipUp/Unzip 陷阱，故用门而非纯乘积）。
  - **代理跑校准**：把 110 源聚成 ~10 个族 F；每族做 target-only vs target+F 的短跑（B≈300 步、≥2 seed），Δ_F = L_val(target-only) − L_val(target+F)。只有族级 rank_corr(τ_F, Δ_F) ≥ ρ_min 且对已知负例符号一致时，才允许用 τ 替代短跑做全量筛选。
  - **负迁移早停**：训练中监控 per-source 梯度冲突（cos<0 比例）与 source/target 验证损失发散，触发即降权或裁剪该族。
- **与现有方案差异**：v1.1 的孪生表是 LLM 猜的相似度；本点用可计算的双因子 + 真实短跑校准，把「负迁移」从口头风险变成可拒绝的准入条件。
- **资源/落地**：τ 全量计算 1 GPU 日（只前向，不训练）；代理跑 ≈10 族 × 2 seed × 300 步 ≈1 GPU 日（1×24GB）；先出可审计排序表，再进 I2 采样器。
- **风险**：DTW 对相位/坐标系敏感；VLM 特征对同类不同外观不敏感（与 I9 同风险）；族划分本身是人为先验，需人工抽检。

### I11 因果混淆诊断 + 反事实不变性（新） ★★★★
- **直觉**：增广是双刃剑。背景/干扰物增广能打破「背景决定动作」的伪相关，也能亲手教出这种伪相关。必须先诊断策略到底在看什么，再决定增广。
- **严谨机制**：把观测分成因果变量 s_C 与冗余变量 s_I（近似：s_C = 目标物体/夹爪/接触相关，s_I = 背景/干扰物/光照）。定义**敏感度比** R = E[||π(o) − π(o ⊕ δ_I)||] / E[||π(o) − π(o ⊕ δ_C)||]；R 越大越混淆。训练时在**因果阶段内**（参考 RoCoDA 的夹爪事件分段）做反事实配对 (o, o')（只改 s_I），加不变性正则 L_inv = ||π(o) − π(o')||²（或动作专家中间特征一致性），仅在 s_I 因果无关的阶段施加，避免遮挡等把冗余变量变成因果相关。
- **与现有方案差异**：I1 只做增广、不检验增广教了什么；本点用 R 做 L0 诊断，用阶段受限的配对正则把「不变性」变成可优化目标。
- **资源/落地**：配对渲染复用 I1；R 的计算是前向推理（1 GPU 日）；先在 3 个有干扰物的任务上测 R，再决定是否加正则。
- **风险**：阶段切分错误会伤害接触段；不变性过强会抹掉必要的视觉反馈。

## 1. 严谨定义（本轮的理论骨架）

### 1.1 行为克隆的复合误差与「恢复覆盖」
设 MDP 为 M=(S,A,P,r,ρ₀,T)，专家策略 π_E，示教集 D_E ~ π_E。BC 目标：
  min_θ  E_{(s,a)~D_E}[ ℓ(π_θ(s), a) ]。
令 ε = E_{s~d_{π_E}}[ ℓ(π_θ(s), π_E(s)) ]（专家状态分布上的单步误差）。则最坏情形
  J(π_θ) ≤ J(π_E) + T²·ε        （BC，Ross et al. 2011；连续动作用有界损失/总变差替代 0-1）。
DAgger 在可在线查询专家时达到 J ≤ J* + uTε_N + O(1)（u 为有界优势）。Spencer et al. 2021 的 Goldilocks regime 进一步给出：固定 D_E + **高保真仿真**时
  J(π_θ) ≤ J* + min(T·C·u·ε, T²·ε)，其中 C = ||ρ_{π_θ} / ρ_{π_E}||_∞。
F21 的结论正是 C 无法用官方 sim 可靠估计——因此本方案把「降低 C」换成「用真实示教提高 D_rec 在偏离态的覆盖」：
  ρ_rec = P_{s'~D_rec}[ d(s', manifold(D_E)) < δ ]，κ = P[ ||a' − π_E(s')|| ≤ ε_a ]。
要求 ρ_rec ∈ [ρ_lo, ρ_hi]、κ ≥ κ_min：这是对「有限密度比、可学恢复」的可操作近似。

### 1.2 负迁移与双因子可迁移性
负迁移 gap（Wang et al. 2019）：
  NTG = ε_T(θ(S,T)) − ε_T(θ(∅,T))；NTG > 0 即负迁移。
Ben-David 界：
  ε_T(h) ≤ ε_S(h) + ½ d_{HΔH}(X_s, X_t) + λ。
它告诉我们源任务的价值由「源误差 + 域散度 + 固有难度」共同决定，单看语义相似度不够。定义双因子：
  V(s,t) = cos(mean φ(o_s), mean φ(o_t))；
  D(s,t) = exp(−λ_d · DTW(ā_s, ā_t))；
  τ(s,t) = V^α · D^β；准入合取门：D ≥ d_min ∧ V ≥ v_min。
族级校准：Δ_F = L_val(target-only) − L_val(target+F)，只接受 rank_corr(τ_F, Δ_F) ≥ ρ_min 的 τ 作为全量筛选用。

### 1.3 因果混淆与阶段受限不变性
设观测可分解为 s = (s_C, s_I)，π(s) = π(s_C)。敏感度比
  R = E[||π(o) − π(o ⊕ δ_I)||] / E[||π(o) − π(o ⊕ δ_C)||]。
R ≫ 1 表示策略更受冗余变量驱动（因果混淆）。反事实配对 (o, o') 只在 s_I 因果无关的因果阶段 Γ 内生成，训练目标：
  L = L_BC + λ_inv · E_{(o,o')~Γ}[ ||π(o) − π(o')||² ]。
阶段切分以夹爪开合事件为界（RoCoDA 做法），避免在接触段强制不变性。

```python
def two_factor_transferability(src, tgt, phi, lam=1.0, alpha=1.0, beta=1.0):
    V = cosine(mean_pool(phi(src.obs)), mean_pool(phi(tgt.obs)))
    a_s = phase_align_normalize(src.actions)   # 以夹爪开合事件分段并归一化
    a_t = phase_align_normalize(tgt.actions)
    D = exp(-lam * dtw(a_s, a_t))              # 也可换成 OT / Wasserstein
    return V, D, (V ** alpha) * (D ** beta)

def proxy_screen(families, tgt, base, steps=300, seeds=2):
    delta = {}
    for F in families:
        gains = []
        for seed in range(seeds):
            only = short_train(base, [tgt], steps, seed)
            both = short_train(base, [tgt] + F, steps, seed)
            gains.append(val_loss(only) - val_loss(both))
        delta[F] = mean(gains)
    return delta   # 与 tau 做族级 rank_corr；达阈值前 tau 只排序、不准入
```

### 2.2 无仿真恢复示教（I5 v3）

```python
def build_recovery_demos(demos, phi, delta=0.1, eps_a=0.05):
    out = []
    # (1) 状态拼接：用 B 的专家动作标注 A 的偏离态
    for A in demos:
        for t, s in enumerate(A.obs):
            ph = causal_phase(A, t)                       # 以夹爪事件切分
            cand = [(d(phi(s), phi(B.obs[u])), u, B)
                    for B in demos if B is not A
                    for u in phase_indices(B, ph)]
            if not cand: continue
            dist, u, B = min(cand, key=lambda x: x[0])
            if dist < delta:
                out.append((s, B.actions[u], "stitch"))
    # (2) 位置轴等变重标注
    for A in demos:
        for t, s in enumerate(A.obs):
            if not is_equivariant_phase(A, t): continue
            for T in sample_se2(A.syllabus_card):
                out.append((warp(s, T), transform_action(A.actions[t], T), "equiv"))
    return filter_by_consistency(out, eps_a)              # 用 kappa 门禁

def coverage(D_rec, D_E, phi, delta):
    rho = mean(min(d(phi(s), phi(s_e)) for s_e in D_E.obs) < delta
               for s, _, _ in D_rec)
    return rho                                           # 目标：中间带，不是越高越好
```

### 2.3 因果混淆诊断与阶段受限不变性（I11）

```python
def sensitivity_ratio(policy, o, intervene_causal, intervene_nuisance):
    dC = mse(policy(o), policy(intervene_causal(o)))
    dI = mse(policy(o), policy(intervene_nuisance(o)))
    return dI / (dC + 1e-8)                              # R >> 1 => 因果混淆

def counterfactual_invariance_loss(policy, batch, phases):
    o, a = batch
    o2 = intervene_nuisance(o, phases)                   # 仅背景/干扰物/光照
    return mse(policy(o), a) + LAM * mse(policy(o), policy(o2))
```

```python
class GatedSampler:
    def weight(self, src):
        if src in CHALLENGE_32: return 1.0
        V, D, tau = self.tau[src]
        if D < self.d_min or V < self.v_min: return 0.0       # 动力学/语义合取门
        if self.proxy_delta[self.family(src)] <= 0: return 0.0  # 代理跑筛掉负迁移
        return self.w_max * tau
    def episode_weight(self, ep):
        q = progress_efficiency(ep) * smoothness(ep)          # 0..1
        return 0.2 + 0.8 * q                                  # 软下限 + 剪最差 10%
```

## 7. 本轮最值得押注（一句话）

**押「可度量的数据引擎」：I10 用「语义×动力学」双因子 + 短代理跑筛掉负迁移源，I5 v3 用真实示教的拼接/等变补协变量偏移，I11 用阶段受限的反事实不变性拆掉增广引入的伪相关——在仿真不可信（F20/F21）的硬约束下，这是唯一能同时压低泛化缺口与负迁移风险的数据侧组合。**

**本轮最大风险（一句话）**：代理效度——仿真既缺 32 任务场景又与真机有单目/双目视觉鸿沟（F20/F21），而可迁移性分数是在冻结视觉特征上算的、文献明确其对微调迁移预测很差（F23）；若两个代理都失真，I5/I10 会静默灌入有害数据而离线指标看不出来。
