# 第 66 轮（承接第 65 轮「VISTA 视觉知情安全时序归因闭环」IP-214~223；灵感循环第 1 轮；本轮灵感：「多机评测」×「云端协同」）

> 第 65 轮把「几何可证伪」升级为「故障可归因」，其自述的最大风险非常尖锐：**归因依赖「故障属于有限假设集、且视觉与几何失效相互独立」；真实故障常是未知复合类型，透明/镜面/对抗 patch 会让视觉与几何共享同一个分布外失效源，FIR 于是把未知复合故障强行归入最近假设、只膨胀错误的球——第 64 轮的单点故障升级为「归因错误的复合故障」，而且系统会因为「已经归因」而更自信地继续执行（A88）。** 本轮不再增加第四个语义模态，也不再把「独立性」当作默认成立的前提，而是换一个提问对象：第 65 轮问「**这台机器上谁坏了**」，本轮问「**当一台机器无法独自区分故障时，哪些来自他机/云端的证据才可采信，它们究竟提供多少独立信息，又能信多久**」。核心命题是：
>
> **把「单机自证」升级为「跨机互证 + 云端可审计」：用机队异质性创造独立的故障对照，用证据来源图计算有效独立样本数，用带租约与版本钉扎的云端证书替代一次性本地证书，并把多机评测本身当作一种可证伪的实验设计——从「有几台机器同意」转向「这些同意里有多少是真正独立的信息」。**

## 0. 直觉与动机

**灵感 1（多机评测 → 机队是异质诊断仪器，不是冗余投票器）**
直觉：一台机器人只有一种位姿、一种工具、一种接触相位，因此它看到的「大残差」永远无法自证是几何错、传感器偏置还是模型错。多台机器人如果**异质**——不同站位、不同末端工具、不同负载、不同接触方向——就天然构成一组对照实验：若机器 A 的力残差高，而机器 B 在同一物体、同一几何、相近接触条件下正常，则故障更可能是 **A 的个体偏置**而非几何幻觉；反之若全机队在同一位姿类下同时偏，则更像**共享几何/共享模型**问题。这叫**差分诊断**：共享共因在跨机相减中抵消，个体故障被放大。
但必须诚实：**多数票是陷阱**。若所有机器人共享同一云端模型版本、同一批传感器、同一次标定、同一个 OOD 物体，它们的误差高度相关，十票实际只有一票的信息量。所以「多机」的价值不在数量，而在**独立性 × 异质性**。

**灵感 2（云端协同 → 云端既是共享先验与证书登记处，也是共因总线）**
直觉：云能给机队共享故障签名库、标定集、视觉世界模型与安全证书，让每台机器少探测、快归因、低带宽；这是「机队免疫」。但云端同时是**单点共因**：一次错误模型推送、一次标定集污染、一次网络分区或版本回滚，会让全机队同时错，而且错得一致、错得自信——这是「机队行为」。因此云端不能当「真值源」，只能当**带来源、带版本、带租约、可撤销的可错证据源**；证书必须有 TTL、版本钉扎、撤销纪元与证据根哈希，过期即失效。

**灵感 3（两灵感合流 → 有效独立性是新的「接地」）**
直觉：第 65 轮把「时间阶段」当作可辨识性来源；本轮把「跨机异质性」当作第二个可辨识性来源，并显式建模一个**共因隐变量 c**（云端模型版本、标定批次、OOD 物体类、环境条件）。在此模型下，不再问「有几台机器人」，而问「这批证据的有效独立样本数 n_eff 是多少」：等相关 ρ 下 n_eff = n/(1+(n−1)ρ)，ρ→1 时机队退化为一台。归因只在 n_eff 足够、来源多样、租约有效时放行；否则**拒答**（返回 ⊥）并主动向「最能消除共因」的同伴取证，而不是把相关证据当独立证据硬乘。

**灵感 4（HERD 闭环：Heterogeneous Evidence for Robust Diagnosis）**
闭环：本地 VISTA 产出阶段签名 → 压缩为跨机证据包 CEP → 在来源图 PRV 上匹配共享祖先、估计相关矩阵 R 与 n_eff → 层次贝叶斯 HCD（绝对证据 + 跨机差分）→ QAR 法定人数归因/拒答 → 拒答时 CFA 主动取证 → 云端签发带租约的证书 CCL，分区时 DCR 陈旧度回退 → FAI 抗拜占庭与投毒 → FEV 多机评测 → AIC-H 机队对抗认证 → J_herd。核心不变式仍是：**云端聚合、来源估计、层次归因、证书签发只在云端/语义流；实时流只做本地残差采集、租约校验、前缀执行与失效安全，零学习写操作。**

**灵感 5（对第 65 轮组件的原位升级）**
- **FIR → HCD**：从单机 15 维签名归因，升级为「绝对签名 + 跨机对比」的层次归因；共因 c 被显式边缘化。
- **AFA → CFA**：探针目标从「最大化故障假设互信息」扩展为「在异质机队中选一个能最大程度抵消共因的对照同伴」，并计入带宽/时延/隐私预算。
- **CSC → QAR/CSC-H**：认证前缀的前置条件增加「n_eff 达标且租约有效」；不达标时 k*→0，退回保守/暂停。
- **RSC-V → RSC-H**：不确定球增加 r_shared（共因半径）；当 n_eff 低时只膨胀 r_shared，不误伤个体几何。
- **AIC-V → AIC-H**：干扰集增网络分区、重放、时钟失步、拜占庭上传、共享模型投毒、跨机共因 OOD。
- **J_vista → J_herd**：证书增 evidence_root、n_eff、provenance_diversity、quorum_margin、lease_ttl、version_pins、herd_common_cause。
- **实验方法 → FEV**：把「多机评测」形式化为留出机器/留出实施例的层次化评测，报告相关失效率与 n_eff 校准误差，而非只报平均成功率。

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（HERD 闭环）**：HERD = (VISTA, CEP, PRV, HCD, QAR, CCL, DCR, CFA, FAI, FEV, AIC-H, J_herd)。定位：VISTA 的「跨机互证 + 云端可审计」升级。不变式：**云端聚合、来源图/独立性估计、层次归因、证书签发只在云端/语义流；实时流只做本地证据采集、租约校验、前缀执行、失效安全，零学习写操作。**
- **定义 234（跨机证据包 CEP）**：机器人 m 在块 t 发出 E_m(t)=(m,t,ρ_m,q_vis,q_force,v_m,e_m,sig_m,lease_ref)。v_m=(h_θ,h_cal,h_sensor) 为模型/标定/传感器批次版本钉；e_m=(pose,tool,payload,material) 为异质性元数据；只上传压缩统计量与哈希，不上传原始轨迹（带宽/隐私）。sig_m 绑定身份与内容，防止重放。
- **定义 235（来源图 PRV）**：G_p=(V_p,E_p) 为有向无环图，节点是模型检查点、标定集、传感器批次、故障注入活动、站点；边表示派生/复用。两证据包 i,j 的共享源强度 s(i,j)∈[0,1] 由最近共享关键祖先定义；来源多样性 D_p=1−(1/n²)Σ_{i,j}s(i,j)。**同一云端模型版本的十台机器，在来源图上是一个源，不是十个源。**
- **定义 236（共因隐变量与层次似然）**：c∈ℝ^{d_c} 为共享共因（云端模型、标定批次、OOD 类、环境）。p(ρ_{1:n}|H)=∫ ∏_m p(ρ_m|H,c) p(c|G_p) dc。线性高斯特例：ρ_m=S_mθ+B_m c+ε_m，ε_m∼N(0,Σ_m)，c∼N(0,Σ_c)，则跨机协方差由 B_mΣ_cB_jᵀ 决定。
- **定义 237（有效独立性与有效样本数）**：R 为给定 H 下证据残差的相关矩阵；n_eff=1ᵀR⁻¹1（等相关时退化为 n/(1+(n−1)ρ)）。**n_eff 才是可乘的样本数**；n 只是设备台数。R 由来源图先验 + 机队残差在线估计并收缩。
- **定义 238（差分诊断 HCD）**：对比量 Δ_{ij}=ρ_i−ρ_j。若 B_i=B_j=B，则 Δ_{ij}=(S_i−S_j)θ+ε_i−ε_j，共因 c 精确抵消。HCD 同时使用绝对证据与对比证据：当相关 ρ̄>ρ_hi 时提高对比证据权重，从而在「全机队绝对签名都被共因抬高」时仍能识别个体故障。
- **定义 239（法定人数归因与拒答 QAR）**：可采信集 A={m: 租约有效 ∧ 版本在允许钉扎内 ∧ 未被判拜占庭}。仅当 max_H P(H|E_A)≥1−δ_fi ∧ n_eff(A)≥n_min(δ_fi,κ) ∧ D_p(A)≥D_min ∧ 无共因告警时才定向归因；否则返回 ⊥（拒答），触发本地 null_test 或 CFA。n_min=⌈2 ln(1/δ_fi)/κ_fi⌉ 由 Laplace 集中给出。
- **定义 240（云端证书租约 CCL）**：租约 L=(claim,scope,v,t_issue,TTL,issuer,evidence_root,n_eff,quorum_margin,revoke_epoch,sig)。valid(L,t)⇔ t≤t_issue+TTL ∧ v 与本地一致 ∧ revoke_epoch 未增 ∧ evidence_root 可重算。证书不是「一次性判定」，而是「有保质期、有作用域、可撤销的承诺」。
- **定义 241（陈旧度与分区回退 DCR）**：age=t−t_issue。陈旧度惩罚 r(age)=r_0·(1+λ·age/TTL)。age>TTL 时不得产生新结论；仅当 age≤a_max 且版本钉扎一致时，允许「有限结转」：用旧租约 + 膨胀半径做保守执行；若版本失配或 age>a_max，则 safe_idle / 柔顺撤退。**绝不静默续租。**
- **定义 242（拜占庭与投毒免疫 FAI）**：敌手比例 ε_adv，含 Sybil、重放、投毒上传。聚合用坐标中位数/截尾均值/带衰减信誉加权；污染误差有界；来源图直接排除被污染的关键祖先。证书在 ε_adv 的最坏假设下重算。
- **定义 243（跨机主动取证 CFA）**：给定 A，候选同伴集 B，选
  b*=argmax_{b∈B} [I(H;ρ_b|E_A) − λ_c·cost(b) − λ_s·staleness(b) + λ_d·(1−s(a,b))]，
  s.t. 带宽/时延/隐私预算。末项鼓励选**来源差异大**的同伴以抵消共因；这既是主动诊断，也是「多机评测」的在线版本。
- **定义 244（多机评测协议 FEV）**：机器人嵌套于实施例/站点，按**机器**而非按 episode 划分训练/标定/测试，估计跨机泛化；指标含归因准确率、n_eff 校准误差、相关失效置信率 CFCR=P(≥k 台机器一致地错)、租约违规率、恢复时间、投毒鲁棒性。用层次 bootstrap 给机队级置信区间；只有留出机器上的下置信界达标，才称 fleet-certified。
- **定义 245（AIC-H 机队对抗认证）**：ℰ_H=ℰ_V×ℰ_net×ℰ_byz×ℰ_common。ℰ_net 含分区/延迟/重放/时钟失步；ℰ_byz 含 Sybil/投毒；ℰ_common 含共享 OOD 物体、共享模型版本、共享标定批次。ρ_dir 按「敌手可最大化相关」的最坏 n_eff 重算；证书不得假设来源独立。
- **定义 246（J_herd 证书）**：J_herd=(J_vista,evidence_root,n_eff,D_p,quorum_margin,lease_ttl,version_pins,herd_common_cause,fai_ver)。Valid ⇔ Valid(J_vista) ∧ valid(lease) ∧ (n_eff≥n_min ∨ 显式 single_source_conservative 标记) ∧ 版本钉扎一致 ∧ 共因已处理（成功归因或显式拒答）。审计链回答：**采信了谁、为什么独立、为什么现在可信、信到什么时候。**
- **定义 247（HERD 算子）**：云端/语义流 [本地 VISTA→CEP→PRV 匹配→HCD 层次归因→QAR 归因/拒答→CFA 取证→CCL/DCR 租约→AIC-H→J_herd]；实时流 [本地残差采集→租约校验→WCV-V 编译→前缀派发 k*→失效安全]。
- **定义 248（机队风险预算与异质性阈值）**：α_fleet=α_local+α_cc+α_net+α_byz，其中 α_cc 为相关失效预算。要求 D_p≥D_min(α_cc) 且 n_eff≥n_min，使最坏相关误差≤α_cc。若达不到，正确动作是**增加来源多样性或缩小 k***，而不是「增加信任」。

## 2. 关键算法骨架

```python
# CEP → PRV → HCD → QAR：跨机归因与拒答（云端/语义流）
E = [collect_packet(m) for m in fleet.nearby_and_healthy()]
R, src = provenance.correlation_prior(E)          # 共享祖先 → 先验相关
R = shrink(R, empirical_residual_corr(E))         # 在线收缩，避免噪声高估独立
n_eff = 1.0 / (ones @ solve(R, ones))             # = 1ᵀR⁻¹1
post, c_star = hcd.attribute(E, common_cause=True)  # 层次贝叶斯，c 显式边缘化
decision = qar.decide(post, n_eff, provenance.diversity(E), delta_fi)
if decision is REFUSE:
    b = cfa.choose_peer(E, budget=(bw, latency, privacy))
    E += [collect_packet(b)]; post, n_eff = hcd.refine(E)

# CCL：云端签发带租约、带版本钉扎的证书（云端）
lease = cloud.issue_lease(claim=post, scope=skill, pins=current_versions(),
                          ttl=ttl_for(skill), evidence_root=hash(E), n_eff=n_eff)

# 实时流：只校验租约，不重算归因
if not lease.valid(now(), local_versions()) or n_eff < n_min:
    k_star = 0; enter_safe_mode()
else:
    k_star = csc.certified_prefix(A, post, m, alpha_chunk)
    for a in A[:k_star]:
        dispatch(a)
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（有效独立性决定集中速率）**：等相关下 n_eff=n/(1+(n−1)ρ)；层次后验的 Laplace 误差 ≤ exp(−n_eff·κ_fi/2)。若把相关证据当独立（用 n 而非 n_eff），误差界**静默失效**——这正是第 65 轮独立性假设的量化后果。
- **引理 10（差分抵消共因）**：若两机共享同一共因载荷 B，则对比 Δ=ρ_i−ρ_j 中 c 精确抵消；因此即使 ρ̄→1、绝对签名全被共因抬高，个体故障仍可辨识。异质性是比数量更强的可辨识性资源。
- **定理 9（机队归因安全）**：在 A94–A99 下，QAR 放行 ⇒ P(误归因)≤exp(−n_eff·κ_fi/2)+δ_pin+δ_byz；QAR 拒答 ⇒ 走保守回退，不产生「自信的错误」。误判「独立性」是唯一能同时绕过两者的漏洞。
- **定理 10（租约新鲜度安全）**：若 TTL≤m/执行频率且版本钉扎一致，则陈旧证据不可能被用于越过不可逆视界；ctx 分区时 by construction 只能有限结转或安全停机，不会无限续信。
- **命题（机队免疫 vs 机队行为）**：共享证据使单机探测成本约降 1/n_eff，但相关失效概率随共享源比例上升；存在最优异质性 D*，**不是共享越多越好**。这给出了「云端协同」的定量边界。
- **实时性**：CEP 压缩、PRV、HCD、QAR、CFA、CCL 全在云端/语义流；实时流只增租约校验（<0.02ms）、版本比较（<0.01ms）、陈旧度检查（<0.01ms），目标 ≤2.2ms。

## 5. 本轮最大风险

**一句话**：HERD 的全部安全性押在「来源图能准确估计有效独立性 n_eff」这一假设上；一旦存在来源图看不见的隐藏耦合（同一供应商的隐性同批缺陷、同一场景的共享 OOD、同一训练数据泄漏），QAR 会把相关证据当独立证据做乘法，**「机队免疫」退化为「机队行为」——全机队一起错、一致地错，并用带有 n_eff 与租约的证书把这种相关错误认证得更可信**，这是本轮层次归因与租约安全论证共同依赖的隐藏假设（A94）。

# 第 66 轮产物 · 创新点清单 v3：HERD（Heterogeneous Evidence for Robust Diagnosis：多机异质互证 × 云端可审计租约的安全归因机队；CEP×PRV×HCD×QAR×CCL×DCR×CFA×FAI×FEV×AIC-H×J_herd）

> 承接第 65 轮 IP-214~223（VISTA：VPG×ACH×FIR×VCV×VSP/AFA×CSC×RSC-V×WCV-V×CSP-V×AIC-V×J_vista）。第 65 轮把「几何可证伪」升级为「故障可归因」，但其最大风险是**归因错误反而更自信**：有限假设集 + 视觉/几何独立假设被共因故障打破时，FIR 会强行归入最近假设、只膨胀错误的球。本轮不推倒，而是把「独立性」从隐含前提提升为**被测量、被认证、可拒答**的对象：用**多机异质性**构造跨机对照，用**来源图**估计有效独立样本数 n_eff，用**云端租约证书**把信任限定在版本与时间作用域内，用**多机评测协议**让「机队级安全」成为可证伪命题。实现 **「异质互证、有效独立、有期信任、可拒答」**。
>

## 2. 形式化定义（完整版）

**定义 233（HERD 闭环）** HERD 是 VISTA 的「跨机互证 + 云端可审计」升级：在 VISTA 的五层（几何-技能-干扰-接触-归因）之上加第六层「**证据的来源、独立性与有效期**」。组成 CEP（跨机证据包）、PRV（来源与版本图）、HCD（异质互证归因）、QAR（法定人数归因与拒答）、CCL（云端证书租约）、DCR（陈旧度回退）、CFA（跨机主动取证）、FAI（拜占庭免疫）、FEV（多机评测协议）、AIC-H（机队对抗认证）、J_herd。不变式：**云端聚合、来源图与独立性估计、层次归因、证书签发只发生在云端与语义流；实时路径只做本地阶段残差采集、租约校验、认证前缀执行与失效安全，零学习写操作。**

**定义 234（跨机证据包 CEP）** 机器人 m 在块 t 生成
E_m(t)=(m,t,ρ_m,q_vis,q_force,v_m,e_m,sig_m,lease_ref)，
其中 ρ_m∈ℝ^{15} 为第 65 轮阶段化签名，q_vis/q_force 为对应 conformal 分位，v_m 为模型/标定/传感器批次版本钉，e_m 为位姿/工具/负载/材质等异质性元数据，sig_m 为绑定身份与内容的消息签名，lease_ref 指向其当前本地租约。**只上传压缩统计量与哈希，不上传原始图像/轨迹**，以同时满足带宽、隐私与可审计需求；签名与单调计数器防重放。

**定义 235（来源图 PRV）** 定义有向无环图 G_p=(V_p,E_p)：节点 v∈V_p 表示模型检查点、标定集、传感器批次、故障注入活动、部署站点；边 (u,v)∈E_p 表示 v 由 u 派生或复用。两证据包 i,j 的共享源强度
s(i,j)=exp(−γ·d_p(a_{ij}))，
其中 a_{ij} 为最近共享关键祖先，d_p 为其在 G_p 上的加权距离；s∈(0,1]，同源为 1。来源多样性
D_p=1−(1/n²)Σ_{i,j}s(i,j)。
关键性质：**同一云端模型版本的十台机器人，在来源图上共享一个关键祖先，因此是一个源而非十个源。** PRV 还带撤销纪元与污染标记，供 FAI 使用。

**定义 236（共因隐变量与层次似然）** 引入共享共因 c∈ℝ^{d_c}（云端模型版本、标定批次、OOD 物体类、环境光照/摩擦条件）。给定故障 H 与来源图，证据联合似然
p(ρ_{1:n}|H)=∫ ∏_{m=1}^n p(ρ_m|H,c) p(c|G_p) dc。
线性高斯特例：
ρ_m=S_mθ+B_m c+ε_m，ε_m∼N(0,Σ_m)，c∼N(0,Σ_c)，
于是 Cov(ρ_i,ρ_j|H)=B_iΣ_cB_jᵀ（i≠j），Cov(ρ_m,ρ_m|H)=Σ_m+B_mΣ_cB_mᵀ。**共因不被当作噪声吞掉，而是显式建模为可被跨机对照抵消的结构项。**

**定义 237（有效独立性与有效样本数）** 令 R 为给定 H 下证据残差的相关矩阵（由 PRV 先验与机队残差在线估计并收缩）。定义有效独立样本数
n_eff=1ᵀR⁻¹1，
等相关 ρ 时 n_eff=n/(1+(n−1)ρ)。n_eff 是**唯一允许进入集中不等式与贝叶斯乘法的样本数**；设备台数 n 只用于描述规模。n_eff=1 表示机队退化为单台机器，n_eff≈n 才表示证据近似独立。

**定义 238（异质互证归因 HCD）** 在定义 236 的层次模型下计算
P(H|E_A)∝P(H)∫_c ∏_{m∈A}p(ρ_m|H,c)p(c|G_p)dc。
同时构造跨机差分 Δ_{ij}=ρ_i−ρ_j。若 B_i=B_j=B，则
Δ_{ij}=(S_i−S_j)θ+ε_i−ε_j，
共因 c 精确抵消。HCD 采用双通道证据：
- 当估计相关 ρ̄≤ρ_hi：以绝对签名为主，差分作辅助；
- 当 ρ̄>ρ_hi：提高差分权重（因为绝对签名已被共因污染），用「谁与众不同」定位个体故障。
输出后验、共因估计 ĉ、相关告警与每个假设的贡献分解。

**定义 239（法定人数归因与拒答 QAR）** 可采信集
A={m: valid(lease_m,t) ∧ v_m∈V_allowed ∧ ¬byzantine(m)}。
仅当同时满足
(i) max_H P(H|E_A)≥1−δ_fi；
(ii) n_eff(A)≥n_min=⌈2 ln(1/δ_fi)/κ_fi⌉；
(iii) D_p(A)≥D_min(α_cc)；
(iv) 无未处理的共因告警
时，才输出定向归因 Ĥ。否则输出 ⊥（拒答），并按优先级触发：本地 null_test → CFA 向来源差异最大的健康同伴取证 → 缩小 k* / 进入安全模式。**拒答是一等公民，不是失败。**

**定义 240（云端证书租约 CCL）** 云端签发的租约
L=(claim,scope,v,t_issue,TTL,issuer,evidence_root,n_eff,quorum_margin,revoke_epoch,sig)。
有效性
valid(L,t) ⇔ t≤t_issue+TTL ∧ v=current_versions(site) ∧ revoke_epoch≤current_epoch ∧ evidence_root=H(E_A)。
其中 scope 指定技能/物体/工况，避免跨域误用；n_eff 与 quorum_margin 记录签发时的独立性证据；revoke_epoch 支持云端主动撤销。**证书不是「一锤定音的真值」，而是「在版本与时间作用域内、可被审计与撤销的承诺」。**

**定义 241（陈旧度与分区回退 DCR）** 令 age=t−t_issue，陈旧度惩罚
r(age)=r_0·(1+λ·age/TTL)，λ>0。
- age≤TTL：正常使用；
- TTL<age≤a_max 且版本钉扎一致：仅允许「有限结转」——沿用旧租约的结论但用 r(age) 膨胀不确定球，且 k*≤⌊m·(1−age/a_max)⌋；
- age>a_max 或版本失配或收到撤销：禁止新结论，执行 safe_idle / 柔顺撤退。
**任何路径都不得静默延长 TTL。** 这把「云端协同」的可用性与安全性解耦：断网只降低能力，不降低安全。

**定义 242（拜占庭与投毒免疫 FAI）** 设敌手比例 ε_adv，攻击含 Sybil 身份伪造、证据重放、投毒上传、模型供应链污染。防御：
(i) 证据签名 + 单调计数器 + 站点配额，抑制 Sybil/重放；
(ii) 坐标中位数/截尾均值/信誉加权聚合，标量下 ε_adv<1/2、向量下 ε_adv<1/3 时估计误差有界；
(iii) PRV 将污染关键祖先的所有后代标为不可采信，而不是只看单条证据；
(iv) 证书在 ε_adv 的最坏可实现相关下重算。**重点是阻断「少数坏机器通过共享祖先污染多数好机器」。**

**定义 243（跨机主动取证 CFA）** 当 QAR 拒答或后验熵过高时，在候选健康同伴集 B 中选择
b*=argmax_{b∈B} [I(H;ρ_b|E_A) − λ_c·cost(b) − λ_s·staleness(b) + λ_d·(1−s(a,b))]，
s.t. 带宽、端到端时延、隐私/数据共享预算。末项鼓励选择**来源差异大**的同伴以最大化共因抵消；当预算不足时退回本地 null_test。这是把第 65 轮 AFA 的「探什么动作」升级为「向谁取证」，也是多机评测的在线版本。

**定义 244（多机评测协议 FEV）** 将评测对象从单个策略扩展为「策略 × 机队 × 云端」。数据按**机器人实例 / 实施例 / 站点**分层，训练/标定/测试的划分必须按机器（不得按 episode 随机划分，否则泄漏同一机器的相关误差）。指标：
- 归因准确率与混淆矩阵；
- n_eff 校准误差 = |log(n_eff/n) − log(n_eff^true/n)|；
- 相关失效置信率 CFCR=P(≥k 台机器一致地给出错误归因)；
- 租约违规率、陈旧执行率、恢复时间、投毒鲁棒性。
用层次 bootstrap 给机队级置信区间；只有**留出机器上的下置信界**达标，才称 fleet-certified。**单机平均成功率不能外推为机队级安全。**

**定义 245（AIC-H 机队对抗认证）** 干扰集
ℰ_H=ℰ_V×ℰ_net×ℰ_byz×ℰ_common。
ℰ_net 含网络分区、延迟/抖动、重放、时钟失步；ℰ_byz 含 Sybil、投毒上传、恶意撤销；ℰ_common 含共享 OOD 物体、共享模型版本、共享标定批次、同供应链批次缺陷。ρ_dir 在「敌手可最大化相关、从而最小化 n_eff」的最坏情形下重算；证书不得假设来源独立，n_cert 由 128 增至 160（其中 32 给网络/拜占庭/共因）。

**定义 246（J_herd 证书）** 
J_herd=(J_vista,evidence_root,n_eff,D_p,quorum_margin,lease_ttl,version_pins,herd_common_cause,fai_ver)。
验证：
Valid(J_herd) ⇔
Valid(J_vista)（本地）
∧ valid(lease)（云端作用域内）
∧ (n_eff≥n_min ∨ single_source_conservative 显式标记)
∧ version_pins 一致
∧ 共因已处理（成功归因，或显式拒答并安全降级）
∧ fai_ver 为当前版本。
审计链新增四问：**采信了谁（CEP 根哈希）、为何认为它们独立（PRV + n_eff）、为何现在可信（租约/版本）、信到何时（TTL/a_max）。**

**定义 247（HERD 算子）** 云端/语义流：[本地 VISTA→CEP→PRV 匹配→HCD 层次归因（绝对+差分）→QAR 归因/拒答→CFA 取证→CCL 签发/DCR 续期→AIC-H→J_herd]；实时流：[本地残差采集→租约与版本校验→陈旧度检查→WCV-V 编译→π_σ 前缀派发 k*→失效安全]。实时路径不访问云端、不重算归因、不做学习写操作。

**定义 248（机队风险预算与异质性阈值）** 定义机队级风险预算
α_fleet=α_local+α_cc+α_net+α_byz，
其中 α_cc 为相关失效预算。给定目标 α_cc，要求
D_p≥D_min(α_cc) ∧ n_eff≥n_min(δ_fi,κ_fi)。
若不同时满足，正确动作是**增加来源多样性（CFA 选异源同伴）或缩小 k*（减少承诺）**，而绝不是提高对现有证据的信任。该定义把「多机」从规模指标变成**可分配、可审计的安全预算**。

## 3. 关键算法伪代码

### IP-224/IP-225 CEP 与 PRV

```python
@dataclass(frozen=True)
class EvidencePacket:
    robot: str; t: int
    rho: np.ndarray                    # 15 维阶段签名（第 65 轮）
    q_vis: float; q_force: float
    pins: tuple                        # (h_theta, h_cal, h_sensor)
    meta: dict                         # pose/tool/payload/material
    sig: bytes; lease_ref: str

def provenance_strength(G, i, j, gamma=0.5):
    a = G.nearest_shared_critical_ancestor(i.pins, j.pins)
    return np.exp(-gamma * G.weighted_distance(a))

def correlation_prior(packets, G):
    n = len(packets)
    S = np.array([[provenance_strength(G, packets[i], packets[j])
                   if i != j else 1.0 for j in range(n)] for i in range(n)])
    R = (1.0 - S) * np.eye(n) + S          # 同源→高相关
    return R, S
```

### IP-226/IP-227 HCD + QAR

```python
class HeterogeneousDiagnosis:
    def attribute(self, packets, G, hyp=VISTA_HYP, delta_fi=0.15):
        R0, S = correlation_prior(packets, G)
        R = shrink(R0, empirical_residual_corr(packets), w=0.5)
        n_eff = float(1.0 / (np.ones(len(R)) @ np.linalg.solve(R, np.ones(len(R)))))
        # 层次贝叶斯：对 c 做 Laplace/采样边缘化
        post, c_hat = self._hierarchical_posterior(packets, R, hyp)
        # 差分通道：共因越强，差分权重越高
        rho_bar = offdiag_mean(R)
        w_diff = sigmoid((rho_bar - RHO_HI) / TAU_RHO)
        post = self._fuse_absolute_and_contrast(post, packets, w_diff, hyp)
        kappa = self._identifiability(post)
        return post, c_hat, n_eff, provenance_diversity(S), rho_bar, kappa

class QuorumAttribution:
    def decide(self, post, n_eff, Dp, kappa, delta_fi=0.15,
               D_min=0.6, common_cause=False):
        h_star = max(post, key=post.get)
        n_min = int(np.ceil(2.0 * np.log(1.0 / delta_fi) / max(kappa, 1e-6)))
        if (post[h_star] >= 1 - delta_fi and n_eff >= n_min
                and Dp >= D_min and not common_cause):
            return Decision(h_star, 'ATTRIBUTE', n_eff, n_min)
        return Decision(None, 'REFUSE', n_eff, n_min)   # 触发 CFA / null_test / safe mode
```

### IP-230 CFA（跨机主动取证）

```python
class CrossFleetAcquisition:
    def choose_peer(self, E_A, candidates, G, post, budget):
        best, best_score = None, -np.inf
        for b in candidates:
            if not budget.feasible(b):            # 带宽/时延/隐私
                continue
            ig = expected_mutual_info(post, b, lik=self.lik)
            score = (ig - budget.cost(b) - budget.staleness(b)
                     + LAMBDA_D * (1.0 - provenance_strength(G, E_A[-1], b)))
            if score > best_score:
                best, best_score = b, score
        return best
```

```python
class CloudCertificateLease:
    def issue(self, claim, scope, pins, evidence_root, n_eff, ttl):
        return Lease(claim=claim, scope=scope, pins=pins,
                     t_issue=now(), ttl=ttl, evidence_root=evidence_root,
                     n_eff=n_eff, revoke_epoch=cloud.revoke_epoch,
                     sig=cloud.sign((claim, scope, pins, evidence_root, ttl)))

    def valid(self, lease, t, local_pins):
        return (t <= lease.t_issue + lease.ttl
                and lease.pins == tuple(local_pins)
                and lease.revoke_epoch <= cloud.revoke_epoch
                and lease.evidence_root == local_evidence_root())

    def fallback_radius(self, lease, t, r0, a_max, lam=0.5):
        age = t - lease.t_issue
        if age <= lease.ttl:
            return r0, 1.0
        if age <= a_max and lease.pins == current_versions():
            return r0 * (1.0 + lam * age / lease.ttl), 1.0 - age / a_max
        return None, 0.0                      # 禁止结转 → safe_idle
```

```python
def HERD_round(M, obs, budget):
    # —— 本地实时/近实时 ——
    local = M.vista.local_evidence(obs)            # 阶段签名、q_vis/q_force、版本钉

    # —— 云端/语义流 ——
    peers = M.fleet.admissible(lease, now())
    E = [packet] + [collect_packet(p) for p in peers]
    R, S = correlation_prior(E, M.prv)
    post, c_hat, n_eff, Dp, rho_bar, kappa = M.hcd.attribute(E, M.prv)
    dec = M.qar.decide(post, n_eff, Dp, kappa, common_cause=(rho_bar > RHO_HI))
    if dec.kind == 'REFUSE':
        b = M.cfa.choose_peer(E, M.fleet.healthy(), M.prv, post, budget)
        if b is not None:
            E.append(collect_packet(b))
            post, c_hat, n_eff, Dp, rho_bar, kappa = M.hcd.attribute(E, M.prv)
            dec = M.qar.decide(post, n_eff, Dp, kappa, common_cause=(rho_bar > RHO_HI))

    # —— 证书：云端签发 / 分区回退 ——
    if M.cloud.reachable():
        lease = M.cloud.issue(dec.claim, scope=M.skill, pins=M.pins,
                              evidence_root=hash(E), n_eff=n_eff,
                              ttl=ttl_for(M.skill, M.m))
    else:
        r0, shrink = M.dcr.fallback_radius(lease, now(), M.balls.r_geo, M.a_max)
        if r0 is None:
            return M, None, enter_safe_idle()

    # —— 实时执行：只信租约，不重算归因 ——
    if not M.cloud.valid(lease, now(), M.pins) or n_eff < dec.n_min:
        return M, None, enter_safe_mode()
    k_star = M.csc.certified_prefix(M.ach.propose(M.x, M.H), post, M.m, M.alpha_chunk)
    for a in M.ach.propose(M.x, M.H)[:k_star]:
        dispatch(a)

    # —— 证书与在线更新（语义流） ——
    rho_dir = M.aic_h.certify(post, n_eff, E, M.prv, M.balls)
    return M, build_j_herd(local_j=M.j_vista, lease=lease, evidence_root=hash(E),
                           n_eff=n_eff, Dp=Dp, k_star=k_star,
                           common_cause=(rho_bar > RHO_HI), aic_h_ver=AIC_H_VERSION)
```

## 4. 推导

**引理 9（有效独立性决定集中速率）** 设证据在给定 H 与共因 c 后条件独立，联合分布如定义 236。对 ρ_{1:n} 做 Laplace 近似，Fisher 信息
J_fi=Sᵀ R⁻¹ S（S 为堆叠签名矩阵，R 为定义 237 的相关矩阵）。
等相关 ρ 时，R=(1−ρ)I+ρ11ᵀ，其逆的 1-二次型给出
n_eff=1ᵀR⁻¹1=n/(1+(n−1)ρ)。
后验集中误差 ≤ exp(−n_eff·κ_fi/2)，κ_fi=λ_min(R^{−1/2}SSᵀR^{−1/2})/λ_max(·)。当 ρ→1，n_eff→1，机队退化为一台；若错误地用 n 代替 n_eff，则声称的误差界 exp(−nκ/2) 与实际 exp(−n_effκ/2) 相差 n/n_eff 倍，界**静默失效**。这正是第 65 轮「独立性假设」的定量后果，也解释了为什么必须显式测量 n_eff。∎

**引理 10（差分抵消共因）** 在 ρ_m=S_mθ+B_m c+ε_m 中，若两机共享同一共因载荷 B_i=B_j=B，则
Δ_{ij}=ρ_i−ρ_j=(S_i−S_j)θ+(B_i−B_j)c+(ε_i−ε_j)=(S_i−S_j)θ+ε_i−ε_j，
c 精确抵消，且 Δ 的协方差为 Σ_i+Σ_j（不含 Σ_c）。因此无论 ρ̄ 多接近 1，只要 ε 非退化且 S_i≠S_j，个体故障 θ 在差分通道中仍可辨识；异质性（S_i≠S_j、不同位姿/工具）保证差分有信号。反之若两机完全同构且共享全部版本，则 S_i=S_j，差分信号消失——**同构冗余不提供可辨识性，只提供重复**。∎

**定理 9（机队归因安全）** 在 A94–A99 下：
1. **放行即安全**：若 QAR 返回 Ĥ，则由定义 239 的条件 (i)–(iv) 与引理 9，P(误归因)≤exp(−n_eff·κ_fi/2)+δ_pin+δ_byz；由引理 10，共因被显式边缘化或抵消，不会因共享模型而把个体故障误判为几何故障。
2. **拒答即保守**：若返回 ⊥，系统按定义 241/247 进入局部 null_test、CFA 或安全模式；不产生「自信的错误」，最坏只是能力下降。
3. **唯一漏洞是 n_eff 被高估**：若 PRV 遗漏隐藏耦合（供应链同批缺陷、训练数据泄漏、共享 OOD），实际 ρ 高于估计，真实的 n_eff 小于用于决策的 n_eff；此时放行条件可能被虚假满足。故 A94 必须要求「来源图对关键祖先的覆盖」，AIC-H 需在隐藏耦合下重算最坏 n_eff。
4. **降级链**：云端失效→DCR 有限结转或 safe_idle；机队证据不足→CFA 或本地 VISTA；个体故障→差分定位；共享故障→拒答并整体保守。∎

**定理 10（租约新鲜度安全）** 设执行频率为 f，不可逆视界为 m（以步计），TTL≤m/f。若 valid(L,t) 成立，则租约签发至执行之间最多经历 m 步，任何块内故障都能在越过不可逆点前被 CSC 早停或强制重规划。若分区导致 age>TTL，则由定义 241，仅允许在 age≤a_max 且版本一致时以 r(age) 膨胀并缩减 k*；当 age>a_max 或版本失配时禁止新结论。因此陈旧证据的作用域被 TTL 与 a_max 双重截断，**云端不可用不会转化为「无限期信任旧结论」**。∎

**命题（机队免疫 vs 机队行为）** 设单机独立探测成本为 c_p，机队共享使每机成本约降为 c_p/n_eff（因为可复用他机证据），但相关失效概率随共享源比例 s̄ 上升。令总风险
R_fleet(s̄)=c_p/n_eff(s̄)+c_f·P_cc(s̄)，
其中 n_eff 随 s̄ 递减、P_cc 随 s̄ 递增。故存在最优共享度 s̄*（内部解），**并非共享越多越好**；当 P_cc 的边际增长超过探测成本的边际节省时，应主动增加异质性/减少共享。这给出「云端协同」的定量边界，也解释了为什么 HERD 要保留 D_min 与 CFA 的异源偏好。∎

**命题（多机评测的可辨识性）** 若评测只在一台机器或按 episode 随机划分，则样本无法区分「跨机方差」与「episode 噪声」，机队级风险的下置信界不可识别；当真实相关 ρ>0 时，按机器留出会给出更宽的置信区间，从而**拒绝**单机评测的乐观结论。故 FEV 的按机器分层不是保守，而是可辨识性的必要条件。∎

## 7. 已知风险

**一句话**：HERD 的全部安全性押在「来源图能准确估计有效独立性 n_eff」这一假设上；一旦存在来源图看不见的隐藏耦合（同一供应商的隐性同批缺陷、同一场景的共享 OOD、同一训练数据泄漏），QAR 会把相关证据当独立证据做乘法，**「机队免疫」退化为「机队行为」——全机队一起错、一致地错，并用带有 n_eff 与租约的证书把这种相关错误认证得更可信**，这是本轮层次归因与租约安全论证共同依赖的隐藏假设（A94）。

**次级风险与缓解**：
1. **隐藏耦合导致 n_eff 高估**：PRV 无法枚举所有共享源；缓解：A94 要求关键祖先覆盖审计，AIC-H 采用「敌手最大化相关」的最坏 n_eff，必要时退回单机 VISTA；把「无法证明独立」默认当作「不独立」。
2. **相关矩阵估计在非平稳下失真**：机队残差相关随工况漂移；缓解：短窗估计 + 向来源图先验收缩 + 漂移检测触发重估；n_eff 只降不升。
3. **拒答过多导致可用性下降**：安全但「不愿动」；缓解：CFA 主动选异源同伴、分层 D_min、对低风险技能放宽 n_min；明确记录拒答率作为一等指标。
4. **拜占庭鲁棒界在小组下不可达**：n 很小时无法容忍 1/3 敌手；缓解：信任锚 + 硬件签名 + 站点配额；小机队直接要求同源证明或人工确认。
5. **租约可用性与安全冲突**：云端长期不可达时只能安全停机；缓解：DCR 有限结转 + 本地保守策略；把「离线可用性」写成显式 SLA，而非偷偷延长信任。
6. **多机评测成本与隐私**：跨站点/跨机器数据难获取；缓解：只共享统计量与哈希、联邦式标定、仿真 + 少量真机分层验证；FEV 的按机器留出优先于样本量。
7. **异质性本身破坏标定迁移**：不同工具/材质使 conformal 覆盖在跨机时失准；缓解：分实施例校准 q_vis、按实施例报告覆盖，不做全局平均。
8. **时钟与时间戳不可信**：租约 TTL 依赖时钟；缓解：单调计数器 + 云端签名时间 + 容忍窗口；时钟失步计入 H_time/ℰ_net。
