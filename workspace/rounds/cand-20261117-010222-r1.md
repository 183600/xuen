# 第 10 轮（灵感循环第 2 轮；本轮灵感：「VLA」×「成本控制」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**语义顾问化 + 成本一等化 + 双证书合取**。VLA 是本项目迄今最贵、最慢、最不可证的模块，却握着最强的开放词汇语义；成本控制是本项目首次把“每美元买到多少任务进展”写进安全论证。合流纪律：VLA 永远不直达执行器，成本永远不能挪用安全预算；任一新增环节不可用 ⇒ 注入中立元 `abstain`／“拒绝准入” ⇒ 严格等价退回 v9。

## 0. 直觉与动机

**灵感 1（VLA → 语义顾问，而非控制器）**
直觉：VLA 真正稀缺的是“开放词汇 + 语言接地 + 长程语义计划”，不是 50Hz 的力矩精度。让 VLA 直接出动作，等于用最贵、最慢、最不可证的模块承担最严格的安全责任。核心创新：**VLA 提案器（VLAProposer, VLA-P）** 以 ≤1Hz 输出语义提案 σ=(ℓ, Φ_σ, w_{1:K}, u_σ)——自然语言子目标、接地谓词、路点先验、标定置信；它只作为**软先验**进入块编译，绝不产生关节指令。落地闸门是**接地验证器（SemanticGrounder, SG）**：把 σ 编译成可判定谓词与语义证书。即 **P13 不可直达律**。

**灵感 2（成本控制 → 预算作为一等不变量）**
直觉：v9 的 ID 只问“哪个模块有贡献”，没问“每单位成本买到多少贡献”。VLA 使成本从工程常数变成决策变量，且成本具有“可被攻击”的一面（恶意提示诱发昂贵调用）。核心创新：**成本治理器（CostGovernor, CG）** 维护预算 B、影子价格 λ、计算价值 VOC：仅当 `VOC + κ·u ≥ λ·ĉ` 且预算可行才准入 VLA；模型级联（小模型草稿→大模型校验）压低单位语义成本；安全关键模块的预算**环栅隔离**。即 **P14 安全预算优先律**。

**灵感 3（合流 → 成本感知的语义—几何块编译）**
直觉：v9 的 AC 已把“安全”做成证书；现在再加一张“语义证书”，两证都过才允许 VLA 先验进入动作块。**成本感知块编译器（CostAwareChunkCompiler, CACC）** 在预算约束下做二级优化：选子目标（σ 或空 σ_∅）、选低层块；语义证书失效即丢 σ、退回纯几何块。这把“VLA 想做什么”与“机器人能安全做什么”解耦，成本与安全同时可证。即 **P15 双证书合取律**。

## 1. 研究问题（轮次升级版）

- **Q1（不可直达性与安全归约）**：如何把 VLA 限制为“可验证先验”，使含 VLA 系统的安全性完全归约到 v9 的 AC 证书 + 语义证书，不依赖 VLA 自身的可靠性或对齐质量？
- **Q2（预算最优与硬不变量）**：episode 级预算下，VOC/影子价格门控能否同时给出 (i) 硬性不超支、(ii) 安全模块永不断粮、(iii) 接近约束最优的任务收益？
- **Q3（价值估计的分布外偏差）**：VOC 价值头在同分布校准良好，但 VLA 的价值集中在长尾；如何用语义不确定度与乐观上界修正，避免成本门控在 OOD 处“饿死”唯一能救场的模块？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 VLA 不可直达律（Advisory-Only VLA）**
VLA 的输出只能是语义提案 σ，禁止写入执行器。执行指令必须由 CACC 生成，且同时携带 v9 的 AC 安全证书与 SG 的语义证书。σ 缺失/被拒/超时/过期 ⇒ `abstain` 中立元 ⇒ 系统行为严格等价 v9。VLA 运行在独立低频线程，控制环从不阻塞等待它。

**P14 安全预算优先律（Ring-Fenced Safety Budget）**
每 episode 预算 B 中划出 B_res(t) 作为安全关键路径（M₀、SpatialCert、FaultCert、MW、AC 守卫）的最坏情形预留；任何非安全模块（含 VLA）的准入都必须满足 `ĉ_max ≤ B_t − B_res(t)`。成本控制永远不能以安全预算为代价。

**P15 双证书合取律（Safety ⊗ Semantics）**
动作块的执行前提是 AC 证书 Ĉ_t 有效 **且** 语义证书 Ŝ_σ 有效。两者独立验证、独立失效：任一失效都触发“丢弃 VLA 先验 + 退回 v9 几何块”或“安全停驻”，不存在“语义通过而安全未证”的路径。

## 3. 与基线的接口（如何退化）

- VLA-P 超时／不可用／被 CG 拒绝／提案过期 ⇒ `abstain`，等价 v9（纯几何 AC）；
- SG 语义证书无效（幻觉／三源不一致／谓词不可判定／CBF 不可行）⇒ 丢 σ，等价 v9；
- CG 失效（λ 冻结、记账丢失、预算状态损坏）⇒ **关闭 VLA 准入**（最保守），等价 v9 + 纯几何；
- CACC 失效 ⇒ 直接调用 v9 的 ActionChunkCertifier，等价 v9；
- ROI 蒸馏器失效 ⇒ 冻结状态、全模块 active，等价 v9 ID；
- v9 任一模块失效 ⇒ 继续按 v9 五级退化链下沉到 v8／v7／v6。
- 关键约定：**新增中立元只有两种**——VLA 侧 `abstain`、CG 侧“拒绝准入/预算不可行”，二者都精确落到 v9 的同一代码路径与同一可观测行为。

## 4. 预期贡献

1. **VLA 顾问化架构**：把开放词汇语义封装为不可直达的软先验，安全证明与 VLA 规模、量化等级、甚至对齐质量解耦；
2. **成本作为一等不变量**：预算环栅 + VOC/影子价格准入，给出“硬不超支”与“安全不断粮”的可证边界（引理 88–89）；
3. **双证书块编译**：安全证书 ⊗ 语义证书的合取执行，VLA 幻觉最多造成性能损失，不能造成安全违背（引理 87/92）；
4. **ROI 蒸馏**：把 v9 的贡献归因升级为“每单位成本边际贡献”，在成本维度上重新做休眠/唤醒（引理 91）；
5. **预算-语义-安全三闭环**：E571–E590 覆盖接地精度、价值头校准、预算硬界、级联、幻觉拦截、OOD 召回与端到端任务。

## 5. 本轮最大风险

**一句话**：VOC 价值头用同分布配对回放估计 VLA 的边际价值，而 VLA 的价值恰恰集中在分布外长尾——若乐观修正不足，成本门控会在最需要语义先验的时刻把 VLA 关掉，系统被廉价的几何策略锁死在错误吸引子上。

## 1. 符号体系增量（定义 540–548）

| 符号 | 含义 |
|---|---|
| c(π)=(c_tok,c_flop,c_J,c_lat) | 单次计算的成本向量：token、FLOP、焦耳、时延 |
| ĉ(π), ĉ_max(π) | 标量成本（credit）与最坏情形上界；1 credit ≈ 归一化算力成本单位 |
| B, B_t, S_t | episode 预算、剩余预算、累计花费 |
| B_res(t) | 安全关键路径在剩余时域的最坏情形预算预留（环栅） |
| q, σ | 计算查询；语义提案 σ=(ℓ, Φ_σ, w_{1:K}, u_σ) |
| Φ_σ, u_σ | 接地谓词集合；标定后的提案置信度 |
| v^⊥_VLA = abstain | VLA 侧中立元：无提案，CACC 逐位走 v9 路径 |
| VOC_t(q), VOĈ^+_t | 计算价值及其乐观估计（含不确定度上界） |
| λ_t | 影子价格（credit 的对偶价格），由预算配速在线更新 |
| Ŝ_σ | 语义证书（agree, margin, cbf） |
| ROI_m | 模块 m 的成本加权边际贡献 |

**定义 540（成本向量与标量成本）** 对一次计算 π（模块调用、VLA 查询或块生成）定义成本向量 c(π)=(c_tok,c_flop,c_J,c_lat)∈R_+^4。以 credit 为统一记账单位：
```
ĉ(π) = α_tok·c_tok + α_flop·c_flop + α_J·c_J + α_lat·max(0, c_lat − D_π)
```
其中 D_π 为契约截止期，α 为部署期标定的换算权重（云价、电价、时延罚）。ĉ_max(π) 为在契约输入域上的最坏情形上界。

**定义 541（预算、花费与安全环栅）** episode 预算 B；S_t=Σ_{τ≤t} ĉ(π_τ)（仅计被准入者）；B_t=B−S_t。安全环栅
```
B_res(t) = Σ_{τ=t}^{T} Σ_{m∈M_safe} ĉ_max(π_{m,τ})
```
即剩余时域内所有安全关键调用的最坏成本之和。硬不变量：非安全计算 π 被准入的必要条件是 `ĉ_max(π) ≤ B_t − B_res(t)`。

**定义 542（计算价值 VOC）** 查询 q 在历史 h_t 下的计算价值
```
VOC_t(q) = E[J_{t:T}(π) | h_t, admit q] − E[J_{t:T}(π) | h_t, abstain]
```
J 为 v9 的块级任务价值（任务进展 − 安全罚）。用价值头 V_ψ(h_t,q) 估计 VOĈ，并定义不确定度 u_t(q)=三源不一致度 + 集成方差 + 归一化 Δ_dom 的加权和（定义 548）。价值头在**配对回放**（同种子 with/without q）上训练与校准。

**定义 543（影子价格、准入规则与配速）** λ_t∈R_+ 为 credit 的影子价格；r_B=B/T 为平均花费率。在线对偶/配速：
```
λ_{t+1} = [ λ_t + η·(ĉ_t/Δt − r_B) ]_+
```
准入规则（全部满足才问 VLA）：
```
admit q ⇔ (VOĈ_t(q) + κ·u_t(q) ≥ λ_t·ĉ(q))
       ∧ (ĉ_max(q) ≤ B_t − B_res(t))
       ∧ (q 在模型级联的预算名次内)
```
κ·u 是乐观上界（UCB），专门对抗“同分布价值头在 OOD 处系统性低估 VLA”。

**定义 544（语义提案与 abstain 中立元）** σ=(ℓ, Φ_σ, w_{1:K}, u_σ)：ℓ 为自然语言子目标；Φ_σ 为已知模式上的接地谓词；w_{1:K} 为路点先验；u_σ 为标定置信。提案有 TTL τ_sem 与新鲜度约束 ‖s_t−ŝ_t‖≤ε_fresh，过期即失效。中立元 `abstain` 满足
```
CACC.compile(state, abstain, ·) ≡ AC_v9.generate_chunk(state)   （逐位）
```
σ 永不进入执行器；它只能作为 CACC 的候选先验。

**定义 545（语义证书）** Ŝ_σ=(agree, margin, cbf) 有效当且仅当五条同时成立：
```
(a) 可判定：∀φ∈Φ_σ，φ 在当前 belief 下可判定且裕度 ≥ d_sem；
(b) 一致性：三源一致度 A(σ) ≥ τ_agree，且标定误差 ECE(u_σ) ≤ ε_cal；
(c) 可达性：∃ 动作块 ζ 使 AC 证书有效，且终态以裕度 d_sem 满足 Φ_σ；
(d) 语义 CBF：路点序列不迫使任何硬不变式 h 跌破 0（离散 CBF 条件）；
(e) 新鲜：age(σ) ≤ τ_sem ∧ ‖s_t−ŝ_t‖ ≤ ε_fresh。
```
任一条不成立 ⇒ Ŝ_σ=⊥ ⇒ 丢弃 σ（等价 abstain）。

**定义 546（成本感知块编译 CACC）** 在预算与证书约束下的二级优化：
```
max_{σ∈{σ_VLA, abstain}, ζ}  J(ζ; σ)
s.t.  AC(ζ) 有效；Ŝ_σ 有效（σ=abstain 时该项自动满足）；
      ĉ(ζ) + ĉ(σ) ≤ B_t − B_res(t)
```
若两个候选 J 相近，取成本更低者（成本作为次序判据）。VLA 参与的块携带 `semantic_provenance` 字段供审计与逐位等价测试。

**定义 547（ROI 归因与成本加权蒸馏）** v9 定义 537 的升级：
```
ROI_m(t) = EMA_β(ΔJ_m) / (EMA_β(ĉ_m) + ε_cost)
```
状态机沿用 v9 定义 538 的 Schmitt 双阈（阈值作用于 ROI），但增加：Δ_dom ≥ τ_dom **或** u_sem ≥ τ_u 时，1 周期内强制全唤醒并暂停休眠计数（OOD 反脆弱）。φ^elig=false 的安全关键模块仍永不消融。

**定义 548（语义不确定度与乐观价值上界）**
```
u_t = clip( w_a·(1−A(σ)) + w_e·std_ens(VLA) + w_o·min(1, Δ_dom/τ_dom), 0, 1 )
VOĈ^+_t = VOĈ_t + κ·u_t
```
κ 在长尾验证集上预注册标定：要求 OOD 场景的 VLA 召回率 ≥ 目标值（E580），而非单纯最大化平均收益。

## 3. 关键算法骨架

```python
from dataclasses import dataclass

@dataclass
class SemanticProposal:
    subgoal: str                 # ell
    predicates: list             # Phi_sigma（已知模式）
    waypoints: "np.ndarray"      # w_{1:K}
    confidence: float            # u_sigma（已标定）
    stamp: float                 # 生成时刻，用于 TTL
    state_snapshot: object       # 生成时状态，用于新鲜度

class VLAProposer:
    """异步低频语义顾问：只产出提案，绝不写执行器。"""
    def __init__(self, model, deadline_ms=800, ttl_s=2.0):
        self.model, self.deadline_ms, self.ttl = model, deadline_ms, ttl_s
    def propose(self, belief, instruction):
        # 运行在独立工作线程；控制环从不 join 等待
        raw = self.model.generate(belief, instruction, max_tokens=256)
        return SemanticProposal(raw.subgoal, raw.predicates,
                                raw.waypoints, raw.calibrated_conf,
                                now_s(), belief)

class SemanticGrounder:
    def __init__(self, scene_graph, tau_agree=0.8, d_sem=0.05,
                 eps_cal=0.05, eps_fresh=0.02):
        self.sg = scene_graph
        self.tau_agree, self.d_sem = tau_agree, d_sem
        self.eps_cal, self.eps_fresh = eps_cal, eps_fresh
    def verify(self, sigma, belief, ac):
        if age(sigma) > sigma.ttl: return None                 # (e) TTL
        if dist(sigma.state_snapshot, belief) > self.eps_fresh: # (e) 新鲜
            return None
        if not all(decidable(p, belief, self.d_sem)
                   for p in sigma.predicates): return None     # (a)
        A = agreement(sigma, belief, self.sg)                  # (b)
        if A < self.tau_agree or calib_err(sigma) > self.eps_cal:
            return None
        if not exists_ac_reaching(ac, belief, sigma): return None  # (c)
        if not semantic_cbf(sigma.waypoints, belief): return None  # (d)
        return SemanticCert(A, margin=self.d_sem, cbf=True)

class CostGovernor:
    def __init__(self, B, T, eta=0.01, kappa=1.0):
        self.B, self.T, self.eta, self.kappa = B, T, eta, kappa
        self.spent, self.lam = 0.0, 0.0
    def safety_reserve(self, t):                               # 定义 541
        return sum(unit_cost_max(m) * (self.T - t) for m in SAFETY_MODULES)
    def admit(self, voc_hat, u, cost_mean, cost_max, t):       # 定义 543
        feasible = cost_max <= (self.B - self.spent) - self.safety_reserve(t)
        worth = (voc_hat + self.kappa * u) >= self.lam * cost_mean
        return feasible and worth
    def charge(self, cost): self.spent += cost
    def pace(self, cost, dt):                                  # 定义 543
        r_B = self.B / self.T
        self.lam = max(0.0, self.lam + self.eta * (cost / dt - r_B))

class CostAwareChunkCompiler:
    def __init__(self, ac_v9, policy, d_sem=0.05):
        self.ac, self.policy, self.d_sem = ac_v9, policy, d_sem
    def compile(self, state, sigma, cert, gov, t):
        geo = self.ac.generate_chunk(state, ...)               # v9 路径，永远可用
        if sigma is None or cert is None:                      # abstain
            return geo                                         # 逐位等价 v9
        best = None
        for cand in self.policy.sample_sequences(state, K, prior=sigma):
            if not self.ac.certify(cand): continue             # AC 安全证书
            if not semantic_cbf(cand, sigma): continue         # 定义 545(d)
            if not reaches(cand, sigma.predicates, self.d_sem): continue
            if self.ac.cost(cand) + gov_cost(sigma) > gov.B - gov.spent - gov.safety_reserve(t):
                continue
            best = argmax_J(best, cand)
        return best or geo                                     # 先验无效 ⇒ 退回 v9

def metricvoicegauge_round_10(M, s, obs, instruction, gov, ...):
```

## 4. 推导

**引理 87（VLA 不可直达与安全归约）** 在 P13–P15 下，任何被执行的动作都经过 CACC，且携带有效 AC 证书；若 σ=abstain 或 Ŝ_σ=⊥，CACC 的输出与 v9 的 ActionChunkCertifier 逐位相同（同一代码路径、同一随机种子、无 VLA 影响）。因此无论 VLA 出现超时、幻觉还是对抗提示，可达行为集 ⊆ {v9 行为} ∪ {经语义证书约束的 v9 行为}，而后者由 AC 证书（引理 82）与语义 CBF（定义 545(d)）共同保证硬不变式。安全证明与 VLA 规模解耦。∎

**引理 88（预算硬上界与安全不断粮）** 设 ĉ_max 为有效上界，初值 B_0 ≥ B_res(0)，且 B_res(t) 随剩余时域单调不增（每周期安全成本有界）。在定义 541/543 的准入规则下，不变量 B_t ≥ B_res(t) 对所有 t 成立，故 S_T ≤ B，且任意未来安全关键调用都可被资助。证明：安全调用优先从环栅中支出，不变量由 B_res 定义保持；非安全准入满足 B_{t+1}=B_t−ĉ ≥ B_t−(B_t−B_res(t))=B_res(t) ≥ B_res(t+1)。归纳即得。∎

**引理 89（配速的对偶可行性与预算跟踪）** 在流近似、成本增量有界（ĉ∈[0,c_max]）且花费率对 λ 单调不增的假设下，定义配速误差 e_t=S_t−r_B·t 与 Lyapunov 函数 L_t=e_t²。当 |e_t| > c_max/η 时，λ 的更新方向使下一周期花费率朝 r_B 移动，故 E[L_{t+1}−L_t | e_t] ≤ −γ < 0。由随机逼近/漂移分析，e_t 收敛到半径 O(c_max/η) 的邻域；常数步长下收敛到邻域而非点，符合预注册的“偏差有界”判据。∎

**引理 90（拉格朗日松弛的界与门控近似最优）** 预算约束问题 max E[J] s.t. E[cost]≤B 的拉格朗日函数 L(π,λ)=E[J]−λ(E[cost]−B)。对固定 λ，逐点最优策略正是“VOC ≥ λ·ĉ 则准入”（定义 543）；对偶问题给原问题一个上界，且门控策略的次优性不超过对偶间隙 g(λ*)。当价值-成本权衡在流极限下为凹（如 LP 松弛）时强对偶成立，g(λ*)=0；一般情形由 E573/E582 实测间隙，并如实报告。∎

**引理 91（ROI 蒸馏不劣化与抗抖振）** 若 ROI 估计误差 ≤ ε，则一次 dormant 迁移带来的“每单位成本期望任务价值”变化至多 ε；在 τ_on>τ_off、H_off 回合确认与 T_abl 回合更新下，相邻迁移间隔 ≥ T_abl 周期（复用引理 85），无 Zeno。OOD 告警（Δ_dom 或 u_sem 越阈）在 1 周期内强制唤醒并暂停休眠，故分布突变期的缺模块窗口 ≤1 个控制周期。∎

**引理 92（语义证书的误放行界）** 设谓词对 belief 的 Lipschitz 常数为 L、标定误差 ECE ≤ ε_cal、感知噪声次高斯（参数 σ_n）。则对证书有效但实际语义违背的概率有
```
P(false-admit) ≤ |Φ_σ|·( ε_cal + 2·exp(−d_sem² / (2 L² σ_n²)) )
```
证明：对 |Φ_σ| 个谓词做联合界；单谓词误判来自“标定误差”与“噪声超过裕度 d_sem”两类事件，后者由次高斯尾界控制；cert 要求三者一致且 CBF 可行，只会进一步收缩事件。故 d_sem 增大或 ε_cal/σ_n 减小时误放行概率趋零。∎

## 9. 本轮最大风险

**一句话**：VOC 价值头用同分布配对回放估计 VLA 的边际价值，而 VLA 的价值恰恰集中在分布外长尾——若乐观修正不足，成本门控会在最需要语义先验的时刻把 VLA 关掉，系统被廉价的几何策略锁死在错误吸引子上。
