# 第 13 轮（新灵感循环第 1 轮）· MATE：最后 3 厘米不是「位姿偏了多少」，而是「你修的是不是那个实例」——用实例掩码做对比选择，用配对反事实做对比实验

> 日期：**2026-10-31（UTC）**。赛事身份不变：宇树 **UniBot 世界挑战赛**（unibot.unitree.com），G1 + Dex1，32 项桌面任务，通才单模型赛道，选手自部署 + 官方远程真机 API。本轮承接第 10 轮 **FACT-VLA**、第 11 轮 **GEO-RESIDUAL**、第 12 轮 **CHUNK-SERVO**；三个灵感词是「UniBot」「实例分割」「对比实验」。外部事实沿用第 12 轮已核实的 A 级材料（2026-10-28）；本轮新增内容除特别标注外均为 **C 级设计假设**，需 G8–G12 验证。本轮不推倒 CHUNK-SERVO 的「30 步规划 + 5 步伺服」，而是补它一直没有正面处理的参考层和验证层。

## 0. 先给结论：CHUNK-SERVO 让闭环变快，但没有保证闭环锁在正确的实例上

第 12 轮做对了一件关键的事：把 30 步开环 chunk 切成 5 步执行块，把接触段的反馈周期从约 1 s 压到 167 ms。但它对参考层做了三个未经检验的假设：

1. **目标实例已知。** 它假设演示检索到的 `T_target_ee*` 对应当前场景里的正确受器；真实桌面有同类杯、同类试管、多个网口、干扰物、遮挡。
2. **接触接口已知。** 它用局部 ICP/关键点估计 `T_base_target`，但「孔、槽、杯沿、拉链头、锁孔」不是物体中心，而是物体上的一个语义接口；中心对齐不等于接口对齐。
3. **目标移动后身份仍可追踪。** 它用几何残差做编辑检测，但没有实例级记忆：人把目标拿走又放回、把同类物体推近、手进入视野，残差会触发，却不一定能回答「现在该对哪个实例伺服」。

把一次最后 3 厘米的失败拆开，至少有三个误差源：

```text
P(fail) ≈ P(referent wrong)                  # 修错实例：目标选错 / 身份漂移
        + P(frame wrong | referent right)    # 修错接口：孔 / 杯沿 / 拉链 / 锁孔的轴或平面错
        + P(control fail | frame right)      # 修错动力学：延迟、接触、滑移
```

第 12 轮主要打第三项；第 11 轮主要打第二项的几何部分；第一项一直是一个隐含假设。**而实例分割恰好是把第一项变成可观测、可比较、可拒绝的问题的最小表示。**

所以本轮的押注是 **MATE（Matched-instance Assessment & Targeting for Execution，配对实例评估与目标执行）**：

> **用实例掩码给每个候选一个身份和描述子；用当前场景的其他实例做「场景校准」，把光照/背景/标定漂移这类共性扰动从目标描述子里减掉；用正/负例的对比分数选目标，并用 margin 决定「信」还是「拒答」；选中后用掩码拟合任务帧（平面/矩形/圆/线），把相对目标挂到任务帧上再做 5 步伺服；最后用「同场景只换目标」的配对反事实实验，而不是靠官方 10 次/任务的噪声去证明它。**

一句话：**第 12 轮把「预测 1 秒的动作」改成「预测 1 秒的意图 + 执行 167 ms 的闭环」；本轮把「闭环的参考」从「一个目标位姿」升级为「一个实例身份 + 一个任务帧 + 一个可检验的证据余量」。**

三个可验证创新点：

1. **CIR（Contrastive Instance Referent）**：场景校准的对比选择 + margin 拒答。验证它是否在同类干扰物、背景/光照漂移下优于绝对打分和 bbox 打分。
2. **MATF（Mask-Anchored Task Frame）**：从掩码拟合任务帧（孔轴/杯沿圆/拉链线/锁孔平面），把相对目标挂在任务帧上。验证它是否比「物体中心 + ICP」更抗接口误差。
3. **MIRROR（Matched-Instance Randomized Replication with Oracles）**：配对反事实 + 计算量匹配的 bbox 对照 + 打乱/时移掩码的安慰剂 + oracle 上界 + 剂量-反应 + 功效分析。验证增益是否真的来自「实例对比」，而不是更多计算或更多调参。

三个灵感词怎么落到方案里：

| 灵感词 | 落到哪里 | 不做什么 |
|---|---|---|
| **UniBot** | 32 任务、10 次/任务、5 类泛化、单模型、5 步 chunk、不计分单任务通道 | 不做第二个学习模型；不做 30Hz 广域网伺服；不把合成榜单当 SOTA |
| **实例分割** | 实例身份、描述子支撑、任务帧、掩码流残差、离线演示挖掘 | 不加载第二个分割大模型；不做逐任务实例分类器；不做 6D 物体位姿网络 |
| **对比实验** | 推理时的场景校准对比分数 + 评估时的配对反事实/安慰剂/功效分析 | 不用 10 次/任务做 per-task +10pp 声明；不把「多跑几次」当因果证据 |

## 1. 直觉：实例分割给的不是掩码，是「身份、支撑、可比较性」

掩码至少有三种不同于 bbox/关键点的用途：

1. **身份（identity）**：在同类物体中，bbox 会重叠、关键点会串，掩码 + 深度 + 运动可以维持「还是不是同一个」；这对「人把目标挪走」和「桌上有三个同款杯子」是决定性的。
2. **支撑（support）**：深度、法向、轮廓、颜色统计只取掩码内的像素，不被背景/相邻物体污染；这直接改善任务帧估计。
3. **可比较性（comparability）**：不同实例可以映射到同一个描述子空间，用「正例近、负例远」的对比分数比较，而不是分别做绝对分类。

「对比实验」在本轮有双重含义，这是我觉得最有意思的地方：

- **推理时的对比**：目标不是「像不像演示里的目标」，而是「在**当前场景的其他实例**作为负例时，它是否仍然最像演示里的目标」。当前场景的负例同时提供两件事：判别信息（谁是干扰物）和校准信息（共性漂移是多少）。
- **评估时的对比**：不是「跑 10 次看成功率」，而是「同一场景、同一初始状态，只换目标实例/只换算法」的配对反事实。配对把场景难度、物体摆放、光照这些方差消掉，剩下的差值才更接近因果效应。

为什么不是「再加一个分割大模型」？因为 UniBot 明确要求所有任务基于同一模型，不得混合多个模型。MATE 的合规阶梯是：

- **C1 离线标注**：分割/实例只在离线挖掘演示时用；线上只有 VLA + 确定性几何。
- **C2 确定性控制器**：在线分割用双目深度不连续、平面拟合、连通域、颜色/边缘，全是无学习权重的几何；VLA 仍是唯一学习模型。
- **C3 同 checkpoint 特征**：如果规则允许「同一模型的多任务头」，用 VLA 自己的视觉编码器特征做掩码/描述子，不加载第二个模型。

默认走 C2 + C1；C3 只在明确合规时启用。这个阶梯必须在提交材料里写清楚。

## 2. 形式化核心：三个定义、两个公式、一个门

先给最小定义，完整版在产物区 §2。

**实例观测**：时刻 \(t\) 的实例集合

```math
\mathcal{M}_t=\{(m_{t,i},\ell_{t,i},c_{t,i},D_{t,i})\}_{i=1}^{n_t},
```

其中 \(m_{t,i}\) 是二值掩码，\(\ell_{t,i}\) 是标签（可为 unknown），\(c_{t,i}\) 是置信度，\(D_{t,i}\) 是掩码内深度统计。

**实例描述子**：

```math
g_{t,i}=\phi(m_{t,i},D_{t,i},T^{ee}_t,\mathcal{M}_t)\in\mathbb{R}^{d_g},
```

包含形状（面积、长宽比、Hu 矩、轮廓傅里叶）、度量（质心、主轴、深度均值/方差、法向）、关系（相对夹爪位姿、到最近其他实例的距离）、外观（Lab 直方图，降权）。全部手工/确定性；C3 时可替换为同 checkpoint 特征。

**场景校准对比分数（ICC，Instance Contrastive Calibration）**：对候选 \(i\)，用除它以外的实例估计共性漂移

```math
\hat{\delta}_{t,-i}=\operatorname{med}_{j\ne i}\left(g_{t,j}-\mu_{\ell_{t,j}}\right),
```

其中 \(\mu_\ell\) 是演示库里标签 \(\ell\) 的原型。然后

```math
s_{t,i}=
\min_{p\in\mathcal{P}_{\tau,k}}\|g_{t,i}-\hat{\delta}_{t,-i}-p\|_W
-\lambda\min_{n\in\mathcal{N}_{\tau,k}}\|g_{t,i}-\hat{\delta}_{t,-i}-n\|_W.
```

选

```math
i^*=\arg\max_i s_{t,i},
```

但只有同时满足

```math
s_{t,i^*}\ge\theta_s,\quad
c_{t,i^*}\ge c_{\min},\quad
\Delta_t=s_{t,i^*}-\max_{j\ne i^*}s_{t,j}\ge\theta_m
```

才进入伺服；否则拒答，回退到上一帧目标、VLA 开环或安全探针。

**掩码任务帧与相对目标**：对任务 \(\tau\) 指定一个基元 \(F_\tau\in\{\text{plane, rectangle, circle, line, freeform}\}\)，从掩码内的深度点拟合

```math
\hat{T}^{task}_t=\mathcal{F}_{F_\tau}(m_{t,i^*},D_t,K),
```

原点在接口中心，\(z\) 轴是接近/插入法向，\(x\) 轴是面内主轴。相对目标从演示检索：

```math
T^d_t=\hat{T}^{task}_t\,T^*_{task\to ee},\qquad
T^*=\operatorname*{medoid}_{j\in\mathrm{TopK}}\left[(\hat{T}^{task}_{e,j})^{-1}T^{ee}_{e,j}\right].
```

伺服误差

```math
e_t=\log\left((T^{ee}_t)^{-1}T^d_t\right),
```

动作

```math
a_t=a^{ff}_t\circ\exp\left(\mathrm{clip}(K_t e_t+K_d\dot e_t,\pm\delta_p,\pm\delta_r)\right),
```

其中 \(K_t=K_0\gamma(c_{i^*},v_t,\rho_t,\sigma_g,\tau)\) 是置信度门控的增益。

**一个门**：\(\Delta_t\) 是「对比证据余量」。它不是「目标有多像」，而是「目标比第二像的候选多像多少」。余量小就拒答；这比绝对分数更接近「我知道我不知道」。

**可辨识性条件**：

1. 当前场景至少有 2 个实例，或至少 1 个已知类别的参考实例，否则 \(\hat{\delta}\) 不可辨识，退化为绝对打分；
2. 共性漂移假设：\(\hat{\delta}\) 的 MAD 小于阈值 \(\tau_\delta\)；如果目标被单独移动（目标特异位移），MAD 会变大，此时 ICC 失效，必须靠几何任务帧；
3. 任务帧基元必须可拟合：内点率 \(\rho_t\ge\rho_{\min}\)，可见度 \(v_t\ge v_{\min}\)，协方差 \(\mathrm{tr}(\Sigma_t)\le\sigma^2_{\max}\)；
4. 任务属于刚体接触类；变形/流体任务（毛巾、娃娃、书包、针管液体）不启用 MATF。

## 3. 算法：CIR + MATF + MIRROR

**CIR（离线 + 在线）**

离线：对每个任务/阶段的演示关键帧挖掩码（URDF 自投影 + 双目深度 + 平面移除 + 运动分割），算描述子，存正例/负例/类原型/相对目标；用 held-out session 校准 \(\theta_s,\theta_m\)，使拒答后的 referent error ≤2%。

在线每个 5 步块：

1. 分割 + 跨帧关联（Hungarian，IoU + 深度 + 运动）；
2. 对每个候选算 leave-one-out 校准 \(\hat{\delta}_{-i}\) 和分数 \(s_i\)；
3. 选 \(i^*\)，检查 margin/置信度/可辨识性；不满足就拒答；
4. 用 \(m_{i^*}\) 拟合任务帧，检索 top-k 相对目标，取 medoid，算 spread；
5. 门控增益，叠加 VLA 前馈，返回 5 步动作；
6. 更新掩码流残差，检测编辑/身份切换，必要时恢复。

**MATF（任务帧基元）**

| 任务族 | 基元 | 例子 |
|---|---|---|
| 插入/插拔 | 矩形/平面 + 法向 | PlugInEthernet、PlugCharger、ArrangeTestTubes |
| 挂/叠 | 圆/椭圆 + 平面法向 | HangCup、StackBowls、PaperCupStacking |
| 拉链/锁 | 线/平面 + 切向/法向 | ZipUp、Unlock |
| 收纳/摆放 | 平面/矩形 | ToolboxStorage、OrganizeStationery、PackPhone |
| 变形/流体 | freeform（不启用） | FoldTowel、PackDoll、SyringeWaterTransfer |

**MIRROR（配对反事实实验）**

不是「多跑几次」，而是：

- 同一场景生成一对：只换目标实例（同类难负例）或只移动目标，其他物体/相机/光照/背景全固定；
- 处理/对照在同一对上跑，随机化顺序；
- 对照必须是**计算量匹配的 bbox + 绝对打分**，否则「掩码更好」可能只是「多算了几个特征」；
- 安慰剂：打乱实例身份、时移掩码、只用 mask 不用对比校准；
- 上界：oracle 掩码 / oracle 位姿 / oracle 实例；
- 剂量-反应：掩码 IoU 从 0.5 扫到 1.0，看成功率在哪断；
- 中介分析：处理是否通过「referent 正确率」影响成功率；如果不是，机制就不是实例选择。

## 4. 「对比实验」不是附属，是本轮的核心贡献

这是本轮最反直觉、也最应该写进论文的一点：**官方 32×10 的设计，对 per-task 的 +10pp 声明几乎没有功效。**

用精确 McNemar 检验（配对二值结果）算最小可检测效应（MDE，\(p_0=0.25\)，80% 功效，单侧 \(\alpha=0.05\)）：

| 配对数 \(n\) | MDE（模型 A：独立误差） | MDE（模型 B：完全相关、无回退） | 解释 |
|---:|---:|---:|---|
| 5 | 74.9pp | 95.6pp | 第 12 轮 G3 的 5 次 A/B 基本只能看「几乎全对」 |
| 10（官方每任务） | 63.8pp | 58.1pp | **per-task +10pp 不可检验** |
| 20 | 43.7pp | 31.3pp | 仍不可行 |
| 50 | 25.8pp | 13.1pp | 不计分通道的最低可行规模 |
| 64 | 22.4pp | 10.3pp | 推荐的不计分通道规模 |
| 100 | 17.5pp | 6.6pp | 高相关时可看 6–7pp |
| 320（官方 pooled） | 9.3pp | 2.1pp | 只在「共同效应 + 配对」假设下成立 |

两个模型不是严格的上下界：模型 B 的配对方差更小，但 discordant 对数也更少，**小 \(n\) 时 MDE 反而可能更大**（n=5 就是如此）。真实 MDE 取决于效应在样本中的实现方式；表的作用是说明「10 次/任务不可检验」这个结论在两种极端下都成立。

三个直接推论：

1. **官方每任务 10 次不能支持「某任务 +10pp」的结论。** 即使 10 对全部不一致且全部偏向处理，也只能到 \(p=0.0107\)；而 10pp 效应在现实中不可能让 10/10 都翻转。第 12 轮的 G3「5 任务里 3 个 +10pp」在 \(n=5\) 时更是不可能显著，除非效应接近「全对」。这不是说 G3 没用，而是说它只能当**方向性筛查**，不能当因果证据。
2. **人为干扰轴只有 64 次（32 任务 ×2）。** 64 对的 MDE 是 10.3–22.4pp；如果真实增益是 +10pp，功效只有约 0.28–0.78（取决于相关）。所以「human 轴 +10pp → 全局 +2pp」的承诺，在官方评测里基本不可验证；必须用仿真 + 不计分通道做机制验证。
3. **官方 320 次是单臂评测，不是 A/B。** 它能估计「提交版本的成功率」（标准误约 2.4pp），但不能单独给出「相对基线 +5pp」的因果结论；版本、场景、机器人、网络都可能变。因果结论必须来自配对的不计分通道或预注册基线。

所以本轮把实验设计提升为算法的一部分：**MIRROR**。如果实验设计不成立，算法即使「看起来更好」也不可相信。

## 6. 一句话风险

**最大的风险是掩码在透明/遮挡/人手场景下身份漂移，导致对比选择自信地锁错实例；margin/abstain 与几何回退只能降低而不能消除这个风险。**

# 第 13 轮产物 · MATE 技术报告

> 日期：**2026-10-31（UTC）**。对象：宇树 **UniBot 世界挑战赛**（G1 + Dex1，32 项桌面任务，通才单模型赛道，选手自部署 + 官方远程真机 API）。本报告是第 13 轮想法区「MATE」的工程化产物；不替换第 10 轮 **FACT-VLA**、第 11 轮 **GEO-RESIDUAL**、第 12 轮 **CHUNK-SERVO**，而是在它们之上补「实例级参考层」与「配对反事实实验层」。**外部事实沿用第 12 轮已核实的 A 级材料（2026-10-28）；本轮没有重新抓取官网/数据/榜单，新增内容除特别标注外均为 C 级设计假设。**

## 0. 结论与边界

### 0.1 一句话结论

CHUNK-SERVO 把最后 3 厘米的反馈周期从约 1 s 压到 167 ms，但它默认「目标实例已知、接触接口已知、目标移动后身份仍可追踪」。**MATE（Matched-instance Assessment & Targeting for Execution，配对实例评估与目标执行）** 用实例掩码把这三个假设变成可观测的量：**场景校准的对比分数（ICC，Instance Contrastive Calibration）选实例（CIR，Contrastive Instance Referent）、margin 拒答、掩码拟合任务帧（MATF，Mask-Anchored Task Frame）、掩码流残差检测编辑**；并用**同场景只换目标的配对反事实 + 计算量匹配的 bbox 对照 + 打乱/时移掩码的安慰剂 + oracle 上界 + 剂量-反应 + 功效分析（MIRROR，Matched-Instance Randomized Replication with Oracles）**，把「涨点」从官方 10 次/任务的噪声里救出来。不新增学习模型，VLA 仍是唯一学习模型。

### 0.2 证据等级

| 等级 | 含义 | 本报告中的例子 |
|---|---|---|
| A | 官方文档、提交模板、数据集元数据、排行榜 JSON 直接核实；本轮沿用第 12 轮 | 规则、API、33,276 eps、WLA `chunk_size=30`、榜单 29.7% |
| B | 我们在公开数据/网页上做的分析；本轮沿用第 12 轮 | 榜单 `step~success` 回归、任务级相关 |
| C | 本轮设计假设，需 G8–G12 验证 | ICC 抗共性漂移、掩码任务帧 +8pp、配对实验 50–64 对在最佳相关下可看 10–13pp |

### 0.3 本轮不做什么

- 不从零训 VLA/World Model；官方 WLA 已开源 6B 基座。
- 不加载第二个学习模型（包括通用分割大模型、6D 物体位姿网络、逐任务实例分类器）。
- 不做完整 sim-to-real 策略训练；数字孪生只做机制/参数风洞。
- 不做力/触觉闭环；API 没有。
- 不做 30Hz 广域网伺服；沿用 5 步 chunk。
- 不把预览榜单的任务排名当实测难度；只当先验。
- 不伪造真机/仿真实验结果；本报告的「实验结果」是解析/数值核算，不是真机数据。

## 1. 事实基线与问题重述

### 1.1 沿用第 12 轮的 A 级事实（不重复取证）

| 项 | 事实 | 对 MATE 的约束 |
|---|---|---|
| 模型规则 | 所有任务须基于**同一模型**，不得混合多个模型 | 分割/实例必须走 C1/C2/C3 合规阶梯 |
| 任务/次数 | 32 任务 ×10 次；5 类泛化各 2 次 | 每任务 10 次不足以做 per-task 因果声明（§7） |
| 时限/排名 | 单次 180 s；先比总平均成功率，再比步骤分，再比更早提交 | 在线开销必须 <30 ms，不能拖慢 timeout |
| 观测 | 四路 RGB 480×640；双臂关节/EE/夹爪/下身体/语言；**无 depth/force/tactile/camera_info** | 深度只能来自头双目或腕部先验；实例分割必须轻量 |
| 动作 | `ee` 或 `joint` 互斥；`action_chunk_size` 固定；chunk 内无新观测 | 沿用 5 步双频；MATE 在每个 chunk 前做一次选择 |
| 数据 | 33,276 eps / 18.28M frames / 169.28 h / 32 任务；头双目已标定；无分割标注 | 掩码只能离线自监督/几何挖掘，或 C3 同 checkpoint |
| 基座 | WLA 6B，默认 chunk 30 @30Hz，24GB 可微调；54D 动作需 adapter | 不重训基座；MATE 只做 CPU/轻量在线层 |
| 榜单 | 头部 29.7% 是预览值，`step~success` 近线性，视频为占位 | 不从榜单任务排名挖创新点 |

### 1.2 CHUNK-SERVO 的三个隐含假设

第 12 轮的 `get_action` 逻辑是：

```text
VLA 30-step plan -> 每 5 步取 a_ff -> 从演示检索 T_target_ee*
-> 用头部双目/ICP 估计 T_base_target -> e = log(T_ee^-1 T_target_ee*)
-> a_cmd = a_ff ∘ exp(clip(K e)) -> 返回 5 步
```

它默认：

1. **referent 正确**：检索到的 `T_target_ee*` 对应当前场景的正确实例；
2. **frame 正确**：`T_base_target` 的估计对应正确的接触接口（孔/杯沿/拉链/锁孔），而不是物体中心；
3. **identity 稳定**：目标被移动/遮挡/人手介入后，仍能追踪同一个实例。

这三条在 32 个任务里并不总成立。尤其是：

- **同类干扰**：多个杯子/试管/网口/纸杯，bbox 与关键点会串；
- **接口 vs 中心**：插座中心对齐了，插口法向/入口可能还差 2–5 mm；
- **目标特异位移**：人把目标挪了 3 cm，背景没动；共性漂移模型会失效；
- **遮挡/透明**：深度和关键点失败，实例身份先丢，位姿再准也没用。

### 1.3 误差分解（设计启发式，不是严格恒等式）

把失败事件按**首个不可恢复的错误**分类：

```math
P(\text{fail}) \le
P(\text{referent wrong})
+ P(\text{frame wrong} \mid \text{referent right})
+ P(\text{control fail} \mid \text{frame right}).
```

这是 union bound 式的上界；实际事件可能重叠。它的用途是**分诊**：

| 误差源 | 典型现象 | 第 12 轮 | MATE |
|---|---|---|---|
| referent | 抓了旁边同款杯/插了旁边网口 | 隐含假设 | CIR：对比选择 + 拒答 |
| frame | 抓对了杯子，但没挂到钩上/没对插入射轴 | 部分（ICP/关键点） | MATF：掩码任务帧 |
| control | 对上了，但延迟/接触/滑移导致失败 | 主战场（5 步伺服） | 沿用 CHUNK-SERVO |
| edit/identity | 人移动目标后仍追旧目标 | 3D 残差触发 | 掩码流残差 + 重选 |

**本轮的重点是前两项和第四项，不抢第三项的功劳。**

## 2. 符号与形式化定义

### 2.1 实例观测

时刻 \(t\) 的观测为

```math
\mathcal{O}_t=(I^{head}_t,I^{wrist}_t,D_t,q_t,T^{ee}_t,\ell_t),
```

其中 \(D_t\) 是头双目深度（由左右 high 图计算，或由演示/物体尺寸给出的腕部单目先验），\(q_t\) 是关节/下身体，\(T^{ee}_t\) 是夹爪在 base 系的位姿，\(\ell_t\) 是任务语言/任务 ID。

实例分割/几何模块输出

```math
\mathcal{M}_t=\{(m_{t,i},\ell_{t,i},c_{t,i},D_{t,i})\}_{i=1}^{n_t},
```

- \(m_{t,i}\subset\Omega\)：二值掩码；
- \(\ell_{t,i}\)：标签，来自固定任务本体（杯、碗、网口、试管、拉链、锁、夹爪、手、桌面、unknown）；
- \(c_{t,i}\in[0,1]\)：分割/关联置信度；
- \(D_{t,i}\)：掩码内深度统计（均值、方差、法向、可见度）。

### 2.2 实例描述子

```math
g_{t,i}=\phi(m_{t,i},D_{t,i},T^{ee}_t,\mathcal{M}_t)\in\mathbb{R}^{d_g}.
```

分量：

| 组 | 分量 | 维度 | 作用 |
|---|---|---:|---|
| 形状 | 面积、长宽比、solidity、Hu 矩、轮廓傅里叶前 8 阶 | ~16 | 同类/异类区分，抗外观变化 |
| 度量 | 质心、主轴、深度均值/方差、平面法向 | ~10 | 任务帧先验，几何一致性 |
| 关系 | 相对夹爪位姿、到最近其他实例距离、支撑关系 | ~8 | 解决「同类物体选哪个」 |
| 外观 | Lab 颜色直方图（降权） | ~16 | 仅在颜色可靠时使用 |
| 可选 | 同 checkpoint VLA patch 特征（C3） | 64–256 | 开放词汇/未见物品 |

默认 \(d_g\le 64\)，全部手工/确定性。外观项权重 \(w_{app}\) 按背景/光照变化自适应降低；当颜色不可靠时置零。

### 2.3 演示库、正例、负例、类原型

演示库按任务/阶段分片：

```math
\mathcal{D}_{\tau,k}=\{(g^+_{e,j},T^{task}_{e,j},T^{ee}_{e,j},I^{wrist}_{e,j},q_{e,j})\}.
```

- 正例集合 \(\mathcal{P}_{\tau,k}\)：同任务、同阶段、目标实例的描述子；
- 负例集合 \(\mathcal{N}_{\tau,k}\)：同任务但错误阶段、同场景其他实例、其他任务的同类实例；
- 类原型 \(\mu_\ell=\operatorname{med}\{g_{e,i}:\ell_{e,i}=\ell\}\)（按标签的中位数，抗离群）；
- 相对目标 \(T^*_{task\to ee}=(\hat{T}^{task})^{-1}T^{ee}\)。

**关键**：正/负例不是「好/坏动作」，而是「目标/非目标实例」。这是实例级对比，不是动作级偏好。

### 2.4 场景校准对比分数（ICC）

对候选 \(i\)，用除它以外的实例估计共性漂移：

```math
\hat{\delta}_{t,-i}=\operatorname{med}_{j\ne i}\left(g_{t,j}-\mu_{\ell_{t,j}}\right).
```

若 \(n_t=1\) 或标签全 unknown，则 \(\hat{\delta}=0\)（不可辨识，退化为绝对分数）。

校准后的分数：

```math
s_{t,i}=
\underbrace{\min_{p\in\mathcal{P}_{\tau,k}}\|g_{t,i}-\hat{\delta}_{t,-i}-p\|_W}_{\text{正例接近度}}
-\lambda
\underbrace{\min_{n\in\mathcal{N}_{\tau,k}}\|g_{t,i}-\hat{\delta}_{t,-i}-n\|_W}_{\text{负例远离度}}.
```

选择与拒答：

```math
i^*=\arg\max_i s_{t,i},
```

启用条件：

```math
s_{t,i^*}\ge\theta_s,\quad
c_{t,i^*}\ge c_{\min},\quad
\Delta_t=s_{t,i^*}-\max_{j\ne i^*}s_{t,j}\ge\theta_m,\quad
\operatorname{MAD}(\hat{\delta}_{t,\cdot})\le\tau_\delta.
```

任一不满足 → `ABSTAIN`：

1. 上一帧目标仍在且关联置信度高 → 用上一帧目标 + 低增益伺服；
2. 否则 → VLA 开环，或安全探针到预接触位姿后重新观察；
3. 连续 \(K\) 个 chunk 拒答 → 请求 VLA 重规划（带新图 + 语言）。

**为什么 leave-one-out？** 若用候选自身估计 \(\hat{\delta}\)，候选会被「拉向」自己的类原型，分数有偏；排除候选后，校准与候选独立，拒答更可信。

### 2.5 掩码任务帧

对每个任务 \(\tau\) 指定基元 \(F_\tau\)：

| 基元 | 拟合 | 任务帧 | 适用 |
|---|---|---|---|
| plane | RANSAC 平面 + 法向 | 原点=平面质心；z=法向；x=面内主轴 | 锁孔、插座面、收纳格 |
| rectangle | 平面内最小外接矩形 | 原点=矩形中心；z=法向；x=长边 | 网口、充电口、手机槽 |
| circle/ellipse | 3D 圆拟合或图像椭圆反投影 | 原点=圆心；z=法向；x=面内主轴 | 杯沿、碗沿、瓶盖 |
| line/curve | 掩码骨架 + 主曲线 | 原点=线中点；z=局部法向；x=切线 | 拉链、边缘、书脊 |
| freeform | 不拟合 | — | 毛巾、娃娃、书包、针管液体 |

估计器：

```math
\hat{T}^{task}_t=\mathcal{F}_{F_\tau}(m_{t,i^*},D_t,K),
```

返回 \((T^{task},\rho_t,v_t,\Sigma_t)\)：内点率、可见度、协方差。

**符号消歧**：法向 \(z\) 有 \(\pm\) 二义，面内主轴 \(x\) 有 \(\pm\) 二义。用检索到的 top-k 相对目标选使目标差异最小的符号组合；若两个符号的目标差异接近（<1 mm/1°），拒答。

### 2.6 相对目标与门控伺服

top-k 检索（任务/阶段过滤 + 描述子距离 + 相对位姿先验重排）后，取 SE(3) medoid：

```math
T^*=\operatorname*{medoid}_{j\in\mathrm{TopK}}
\left[(\hat{T}^{task}_{e,j})^{-1}T^{ee}_{e,j}\right],
\qquad
\sigma_g=\operatorname{med}_{j}\left\|(T^*)^{-1}T^*_j\right\|.
```

目标与误差：

```math
T^d_t=\hat{T}^{task}_t T^*,\qquad
e_t=\log\left((T^{ee}_t)^{-1}T^d_t\right)\in\mathbb{R}^6.
```

增益门：

```math
K_t=K_0\cdot
\gamma_c(c)\,\gamma_v(v)\,\gamma_\rho(\rho)\,\gamma_\sigma(\sigma_g)\,
\frac{1}{1+\tau/\tau_0},
```

其中每个 \(\gamma\) 是 \([0,1]\) 上的单调斜坡：

```math
\gamma_z(z)=\mathrm{clip}\left(\frac{z-z_{\min}}{z_{\max}-z_{\min}},0,1\right).
```

动作：

```math
a_t=a^{ff}_t\circ\exp\left(\mathrm{clip}(K_t e_t+K_d\dot e_t,\pm\delta_p,\pm\delta_r)\right).
```

- \(a^{ff}_t\)：第 12 轮的 VLA 前馈（5 步切片）；
- \(\delta_p\le 1\) cm/块，\(\delta_r\le 0.05\) rad/块；
- 接触段：把 \(\Delta\) 分解为法向/切向，法向乘 0.3–0.5 并低通，切向保留；
- 若 \(\|\Delta\|\) 连续 3 块超阈值 → 判定目标/标定异常，回退。

### 2.7 掩码流残差与编辑检测

从命令动作预测下一帧掩码：

```math
\hat{m}_{t+1}=\mathrm{warp}\left(m_{t,i^*},\hat{\mathcal{F}}_{t\to t+1}\right),
```

其中 warp 由三部分组成：

1. 夹爪/物体的刚体运动（若已抓取，物体随夹爪）；
2. 头相机的运动（由 `state_d435`/下身体恢复，第 11 轮已验证）；
3. 目标静止假设（若未抓取）。

残差：

```math
r^{mask}_{t+1}=1-\mathrm{IoU}(\hat{m}_{t+1},m_{t+1,i^*})
+\beta\,d_{\mathrm{Chamfer}}(\partial\hat{m},\partial m).
```

编辑分数：

```math
r^{edit}_t=w_1r^{mask}_t+w_2r^{3D}_t+w_3\mathbb{1}[\text{identity switch}],
```

其中 \(r^{3D}_t\) 是第 11 轮的动作条件化 3D 残差，identity switch 由关联代价/ID 变化给出。

阈值 \(\theta_e\) 在 held-out 无编辑 episode 上校准到 ≤5% 误报；检测延迟在合成编辑上测。

### 2.8 配对实验的潜在结果与估计量

对场景对 \(p=(S^{(0)}_p,S^{(1)}_p)\)，两者只差目标实例的身份/位姿。令 \(Y_p(1)\) 为 MATE 的成功，\(Y_p(0)\) 为对照的成功。配对效应：

```math
D_p=Y_p(1)-Y_p(0),\qquad
\Delta=\mathbb{E}[D_p].
```

估计量：

```math
\hat{\Delta}=\frac{1}{P}\sum_{p=1}^P D_p.
```

对照必须是**计算量匹配**的 bbox + 绝对打分；安慰剂是打乱实例身份/时移掩码；oracle 是真实掩码/位姿/实例。这个估计量在随机化处理顺序下无偏；方差见 §6.5。

## 3. MATE 算法

### 3.1 离线管线

```text
for task τ in 32 tasks:
    for episode e in demos[τ]:
        phases = segment_phases(e)                 # FACT-VLA CPT
        for phase k:
            keyframes = select_keyframes(e, k)     # 第 12 轮 DG-KEYFRAME
            for frame t in keyframes:
                M = mine_masks(e, t)               # URDF + 双目 + 平面 + 运动
                for inst i in M:
                    g = descriptor(inst)
                    T_task = fit_primitive(inst, F_τ)
                    T_rel = inv(T_task) @ e.ee[t]
                    index.add(τ, k, g, T_rel, quality)
    prototypes[τ] = median descriptors by label
    threshold[τ] = calibrate_on_heldout_session(index, target_referent_error=0.02)
```

**掩码怎么来（没有分割标注）**：

1. **机器人/夹爪**：用 URDF + 关节状态 + 相机外参投影到图像，得到自掩码；这是免费的、精确的。
2. **桌面/背景**：头双目 RANSAC 平面移除。
3. **物体**：深度不连续 + 连通域 + 分水岭；对被抓物体用 ego-motion 补偿光流/运动分割。
4. **受器/接口**：任务 ROI + 静态掩码 + 平面/圆/线拟合；用任务语言先验缩小候选。
5. **验证**：人工标注 500–1000 帧（跨 32 任务，每任务 15–30 帧）算 IoU；任务级中位 IoU <0.7 时回退 bbox/关键点，不启用 MATF。

**为什么这不是第二个模型**：以上全是几何/运动/URDF 投影，无学习权重；离线也只生成数据索引，不训练网络。C3 同 checkpoint 特征是可选增强，不是默认。

### 3.2 在线 `get_action` 伪代码

```python
class MATE:
    def __init__(self, index, task_spec, cfg):
        self.index = index              # per-task/phase positive/negative descriptors
        self.spec = task_spec           # primitive type, phase, approach prior
        self.cfg = cfg                  # thresholds, gains, H_c=5
        self.track = {}                 # instance id -> last mask/pose/desc
        self.plan = None
        self.plan_idx = 0
        self.mode = "INIT"

    def get_action(self, obs):
        # 1) perception: deterministic geometry (or C3 same-checkpoint)
        M = segment_instances(obs, self.cfg)        # masks, labels, conf, depth
        M = associate(M, self.track, self.cfg)      # Hungarian + id-switch flag

        # 2) async VLA plan, unchanged from round 12
        self._maybe_request_plan(obs)

        # 3) contrastive referent selection (CIR)
        scores = {}
        for i in range(len(M)):
            delta_hat = self._loo_shift(M, i)
            scores[i] = self._score(M[i], delta_hat, obs)
        i_star, margin, ok = self._select(scores, M)

        if not ok:
            return self._fallback(obs, M)           # last target / VLA / probe

        # 4) mask-anchored task frame + relative goal (MATF)
        frame = fit_task_frame(M[i_star], obs.depth, self.spec)
        if not self._frame_ok(frame):
            return self._fallback(obs, M)

        goal = self._retrieve_goal(frame, M[i_star], obs)

        # 5) gated servo + VLA feedforward
        a_ff = self._next_plan_chunk(obs)
        e = se3_log(inv(obs.ee) @ goal.pose)
        K = self._gain(frame.conf, margin, goal.spread, obs.rtt)
        a = compose_relative(a_ff, clip(K @ e, self.cfg))

        # 6) edit / identity monitor
        r = self._mask_flow_residual(M, i_star, obs, a)
        if r > self.cfg.theta_e:
            self.mode = "RECOVER"

        # 7) API chunk
        return self._to_api(a, obs, self.cfg.chunk)

    def _loo_shift(self, M, i):
        if len(M) < 2:
            return zeros(self.cfg.d_g)
        diffs = []
        for j in range(len(M)):
            if j == i:
                continue
            proto = self.index.class_prototype(M[j].label, fallback=None)
            if proto is not None:
                diffs.append(M[j].desc - proto)
        if not diffs:
            return zeros(self.cfg.d_g)
        return median(diffs, axis=0)

    def _score(self, inst, delta_hat, obs):
        g = inst.desc - delta_hat
        d_pos = min(norm(g - p) for p in self.index.positive(obs.task, obs.phase))
        d_neg = min(norm(g - n) for n in self.index.negative(obs.task, obs.phase))
        return -d_pos + self.cfg.lambda_neg * d_neg

    def _select(self, scores, M):
        order = sorted(scores, key=scores.get, reverse=True)
        i = order[0]
        margin = scores[i] - (scores[order[1]] if len(order) > 1 else +inf)
        ok = (scores[i] >= self.cfg.theta_s
              and M[i].conf >= self.cfg.c_min
              and margin >= self.cfg.theta_m
              and mad(self._loo_shift(M, i)) <= self.cfg.tau_delta)
        return i, margin, ok
```

### 3.3 CIR 的四个细节

1. **正/负例过滤优先于外观**：先按任务/阶段过滤，再按描述子距离；不要让颜色把「插网线」匹配到「拔网线」。
2. **场景校准是「减」不是「加」**：只减共性漂移，不把负例当排斥项；同类目标与干扰物相似是正常的，排斥会伤害。
3. **margin 拒答是选择性的**：不追求 100% 覆盖；目标是在高风险场景拒答，在低风险场景保持覆盖。用 risk-coverage 曲线校准。
4. **拒答后的行为必须可预测**：上一帧目标 → 低增益；否则 VLA 开环或预接触位姿探针；绝不返回 NaN/错误形状。

### 3.4 MATF 的拟合与消歧

- **plane**：RANSAC 3 点平面，法向 = 最小特征向量；原点 = 内点质心投影；\(\rho\) = 内点比例。
- **rectangle**：内点投影到平面，最小外接矩形；\(x\) = 长边；\(z\) = 法向；原点 = 矩形中心。
- **circle/ellipse**：图像椭圆拟合 + 反投影，或 3D 圆拟合；\(z\) = 平面法向；\(x\) = 面内主轴。
- **line/curve**：掩码骨架 + RANSAC 直线/二次曲线；\(x\) = 切线；\(z\) = 局部平面法向。
- **freeform**：不拟合，直接回退 VLA；这是非回归设计的一部分。

**消歧**：对 top-k 相对目标，计算四个符号组合（±z, ±x）的目标差异；取最小；若最小与次小差 <1 mm/1°，拒答。

### 3.5 门控伺服与接触相位

- 远距离（>5 cm）：PBVS 主导，\(K\) 正常；
- 预接触（2–5 cm）：PBVS + IBVS 混合，降速；
- 接触（≤1 cm）：法向缩幅/低通，切向保留；\(r^{mask}\) 突变 → 滑移/编辑；
- 目标被遮挡但可见度 \(v>0.3\)：用刚体运动预测 + 低增益；
- 目标不可见/拒答：VLA 开环或探针，不硬做 IBVS。

### 3.6 身份关联与掩码流

**关联**：Hungarian，代价

```math
C_{ij}=-\mathrm{IoU}(m^{t-1}_i,m^t_j)
+\lambda_z|\bar z_i-\bar z_j|
+\lambda_x\|\bar x_i-\bar x_j\|.
```

若目标的最优匹配代价 > 阈值，或 ID 变化，记 identity switch。

**掩码流**：按 §2.7 预测/比较；编辑触发后：

```text
hold -> re-segment -> re-select (CIR) -> update task frame
     -> if target visible: resume low-gain servo
     -> else: VLA re-plan with new image + language
     -> retries > max: fail gracefully
```

### 3.7 状态机

```text
INIT -> PLAN -> SELECT -> SERVO -> CONTACT -> RECOVER -> DONE
         ^        |          |         |
         |        v          v         v
         +------ ABSTAIN <- FALLBACK <-+
```

- `SELECT`：CIR；失败 → `ABSTAIN`/`FALLBACK`。
- `SERVO`：MATF + 门控伺服。
- `CONTACT`：法向缩幅，切向保留。
- `RECOVER`：编辑/身份切换；重选/重规划。
- `DONE`：成功/最大步数；清理，等待 `reset()`。

### 3.8 合规阶梯

| 模式 | 在线用什么 | 风险 | 建议 |
|---|---|---|---|
| C1 离线标注 | 只离线用分割/实例；在线 VLA + 几何 | 最低 | 保守首选 |
| C2 确定性控制器 | 在线几何分割 + 手工描述子 + 控制律 | 低 | **主推** |
| C3 同 checkpoint 特征 | VLA 自己的视觉编码器出特征/掩码 | 低–中 | 明确合规时用 |

禁止：加载第二个学习策略/残差网络/独立视觉编码器做在线决策。

## 5. 正确性论证

### 5.1 命题 1：共性漂移不变性

**假设**：对所有实例 \(j\)，观测描述子 \(g_{t,j}=h_{t,j}+\delta_t\)，其中 \(\delta_t\) 是共性漂移；对 \(j\ne i\)，类原型 \(\mu_{\ell_j}=h_{t,j}\)（无实例噪声）。

**结论**：

```math
\hat{\delta}_{t,-i}
=\operatorname{med}_{j\ne i}(h_{t,j}+\delta_t-\mu_{\ell_j})
=\delta_t,
```

因此

```math
g_{t,i}-\hat{\delta}_{t,-i}=h_{t,i},
```

候选 \(i\) 的校准分数与 \(\delta_t\) 无关。若原型噪声的中位数为零，则估计误差的稳健尺度可由 \(\{h_{t,j}-\mu_{\ell_j}\}\) 的 MAD 估计；它不是严格上界，但足以做门控。

**证明**：直接代入中位数定义。**含义**：光照/背景/标定漂移这类共性扰动不会改变候选排序；这是 MATE 对「背景泛化/位置泛化」的机制。**边界**：目标被单独移动时 \(\delta_t\) 不是共性，MAD 会变大，ICC 失效；此时必须用几何任务帧（命题 3）。

### 5.2 命题 2：margin 选择的误差界

记 \(d_P(g)=\min_{p\in\mathcal{P}}\|g-p\|\)，\(d_N(g)=\min_{n\in\mathcal{N}}\|g-n\|\)，分数 \(s=-d_P+\lambda d_N\)。

**假设**：

```math
d_P(g^*)\le\epsilon_+,\quad
d_N(g^*)\ge\epsilon_-+\epsilon_+,
```

且对任意干扰物 \(g_j\)：

```math
d_P(g_j)\ge\epsilon_-+\epsilon_+,\quad
d_N(g_j)\le\epsilon_+.
```

**结论**：

```math
s^* - s_j \ge (1+\lambda)\epsilon_-.
```

**证明**：

```math
s^*\ge -\epsilon_+ + \lambda(\epsilon_-+\epsilon_+),
```

```math
s_j\le -(\epsilon_-+\epsilon_+) + \lambda\epsilon_+,
```

相减得 \((1+\lambda)\epsilon_-\)。

**含义**：只要观测 margin \(\Delta_t\) 大于门限，且描述子误差小于 \(\epsilon_-/2\)，选择正确；拒答门限把「可能错」的样本挡在伺服外。**边界**：这是充分条件，不是必要条件；真实 margin 分布由 calibration set 的经验 risk-coverage 曲线给出。

### 5.3 命题 3：任务帧等变性

**假设**：掩码/点云被刚体 \(G\in SE(3)\) 变换，且掩码完整（无遮挡）；基元拟合器对 plane/rectangle/circle/line 是等变的。

**结论**：

```math
\mathcal{F}(G\cdot m)=G\,\mathcal{F}(m),
```

因此

```math
T^d(G)=G\,T^d,\qquad
T^{ee}=G\,\hat{T}^{task}T^*
```

是闭环的平衡点集合。

**证明**：平面/矩形/圆/线的拟合只依赖相对几何，刚体变换与拟合可交换；相对目标 \(T^*\) 在任务帧内定义，故不变；代入 \(T^d=\hat{T}^{task}T^*\) 即得。**含义**：目标移动时，期望位姿随实例移动，而不是追一个 base 系固定点；这是「位置泛化/人为干扰」的几何机制。**边界**：法向/面内轴有离散二义；用 top-k 目标消歧，消歧失败则拒答。

### 5.4 命题 4：位姿误差传播与 RANSAC 样本复杂度

若 \(\hat{T}^{task}=\delta T\,T^{task}\)，则

```math
T^d=\delta T\,T^{task}T^*.
```

在次乘性度量下，粗略上界为

```math
\|T^d-T^d_{\text{true}}\|
\le \|\delta T\|\,\|T^{task}\|\,\|T^*\|.
```

该界依赖 \(T^{task}\) 的平移量级，实际误差应以标定/实验测量为准；它只用来解释「任务帧估计误差会被相对目标放大」的方向，不作为精度承诺。

RANSAC 的失败概率：

```math
P_{\text{fail}}\le(1-\rho^s)^N,
```

其中 \(\rho\) 是内点率，\(s\) 是样本点数（平面/圆/线取 3），\(N\) 是迭代数。给定失败概率 \(\eta\)：

```math
N\ge\frac{\log\eta}{\log(1-\rho^s)}.
```

数值：\(\rho=0.3,s=3,\eta=0.01\) → \(N=169\)；\(\rho=0.5\) → \(N=35\)；\(\rho=0.2\) → \(N=574\)。**含义**：可见度/内点率低时，不是「多迭代几次」的问题，而是应该关闭 MATF；这给出 G8/G11 的量化门限。

### 5.5 命题 5：延迟下的 ISS

无延迟的误差递推：

```math
e_{k+1}=(1-KH_c)e_k+w_k,
```

稳定条件 \(0<KH_c<2\)，ISS 界：

```math
\|e_k\|\le|1-KH_c|^k\|e_0\|+\frac{\|w\|_\infty}{KH_c}.
```

一个块延迟：

```math
e_{k+1}=e_k-KH_c e_{k-1}+w_k,
```

特征多项式

```math
z^2-z+KH_c=0.
```

Jury 稳定条件：\(0<KH_c<1\)。稳定时存在 \(\rho<1,C>0\) 使

```math
\|e_k\|\le C\rho^k\|e_0\|+\frac{C\|w\|_\infty}{1-\rho}.
```

**含义**：RTT 高时不是「把增益调大追上去」，而是降增益/加预测；门控在低置信度时把 \(K\) 压低，保持 \(\rho<1\)，但稳态误差界变大。**边界**：线性递推是局部近似；接触非线性/摩擦必须靠仿真和真机小步验证。

### 5.6 命题 6：配对实验的无偏性与方差

在随机化处理顺序下，\((Y_p(0),Y_p(1))\) 对处理分配是可交换的，故

```math
\mathbb{E}[\hat{\Delta}]
=\frac1P\sum_p\mathbb{E}[Y_p(1)-Y_p(0)]
=\Delta.
```

方差：

```math
\mathrm{Var}(\hat{\Delta})
=\frac1P\left[
\mathrm{Var}(Y(1))+\mathrm{Var}(Y(0))
-2\mathrm{Cov}(Y(1),Y(0))
\right].
```

当配对相关为正时，方差小于非配对。计算量匹配的 bbox 对照保证排除限制：若唯一差异是实例信息，则差值可归因于实例信息；安慰剂（打乱/时移掩码）控制「只要有掩码处理就会变好」的替代解释；oracle 给出上界。**边界**：SUTVA、无干扰、无隐藏混杂；仿真配对不一定外推到真机，必须用不计分通道桥接。

| 类型 | 只改变什么 | 保持什么 | 检验 |
|---|---|---|---|

每对随机化处理顺序；同一 pair 的处理/对照共享随机种子；pair 是分析单位。

### 6.4 对照、安慰剂、上界

| 控制 | 做法 | 排除的解释 |
|---|---|---|
| compute-matched bbox | bbox + 同样数量描述子/同样延迟 | 「多算特征/多花时间」 |
| shuffled identity | 掩码不变，实例 ID 随机打乱 | 「只要分割就有用」 |
| time-shifted mask | 用 \(t-1\) 或 \(t+1\) 的掩码 | 「时序对齐」 |
| mask+absolute | 有掩码，但没有 ICC/负例 | 「对比校准」 |
| anti-MATE | 选分数最差的实例 | 分数是否有判别性 |
| oracle mask | 真值掩码 | 分割误差上界 |
| oracle pose | 真值任务帧 | 几何估计上界 |
| oracle instance | 真值实例 | referent 上界 |

**关键**：如果 MATE 只在 oracle 上好看，而在真实掩码上不好看，问题在分割；如果 MATE 与 bbox 在所有场景都一样，问题在「实例信息没有增量」；如果 anti-MATE 不比随机差，分数没有判别性。

### 6.5 结果与分析

**主要**：完整任务成功、最后 3 cm 成功（仿真中用几何判据定义）。
**次要**：referent top-1、frame 平移/旋转误差、identity switch 次数、拒答率、恢复时间、路径长度、碰撞率、p99 延迟。
**中介**：referent 正确率。
**剂量**：mask IoU、clutter、nuisance 幅度。

分析：

1. **配对 McNemar**：主对比的 2×2 表，精确 p 值。
2. **混合效应 logistic**：

```text
success ~ treatment * nuisance + clutter + chunk + delay
          + (1 | task) + (1 | scene_pair)
```

报告边际效应 + 95% CI。
3. **中介分析**：`success ~ treatment + referent_correct`；用 bootstrap 估间接效应；若间接效应 <20%，增益不是来自 referent。
4. **剂量-反应**：success ~ logit(mask IoU)；找 80% 成功对应的 IoU 断点。
5. **risk-coverage**：选择错误率 vs 覆盖率；比较 AUC。
6. **多重比较**：预注册 1 个主对比；次要 Holm；探索 BH。

### 6.6 功效分析（本轮的核心数值结果）

精确 McNemar：设 \(n_{01}\) 为「对照失败、处理成功」，\(n_{10}\) 为「对照成功、处理失败」，\(n_d=n_{01}+n_{10}\)。零假设下 \(n_{01}\sim\mathrm{Bin}(n_d,0.5)\)；临界值 \(k(n_d)\) 是使 \(P(\mathrm{Bin}(n_d,0.5)\ge k)\le\alpha\) 的最小 \(k\)。

两种极端模型：

- **最坏情形（独立误差）**：\(p_{01}=(1-p_0)p_1\)，\(p_{10}=p_0(1-p_1)\)；
- **最好情形（完全相关、无回退）**：\(p_{01}=p_1-p_0\)，\(p_{10}=0\)。

| 20 | 15/20 | 0.02069 |
| 30 | 20/30 | 0.04937 |
| 50 | 32/50 | 0.03245 |
| 64 | 40/64 | 0.02997 |
| 320 | 176/320 | 0.04147 |

**解释**：

- 官方每任务 10 次：MDE 58–64pp。+10pp 不可能显著；第 12 轮 G3 的「3/5 任务 +10pp」在 \(n=5\) 时 MDE 75–96pp，只能当方向性筛查。
- 不计分通道 50–64 对：MDE 10–26pp，取决于配对相关；+10pp 只在最佳相关下可检验，+13–15pp 在 n=50 的最佳情形才可检验；这是唯一能认真做配对因果检验的地方。
- 人为干扰轴 64 次：MDE 10–22pp；+10pp 的功效约 0.28–0.78；不要承诺「human +10pp → 全局 +2pp」而不做更大评测。
- 官方 320 是**单臂**：标准误约 2.4pp，能估绝对成功率，不能单独给「相对基线 +5pp」的因果结论；因果结论来自配对的不计分通道/预注册基线。

### 6.7 三级实验协议

**离线（不烧真机）**

| 实验 | 数据 | 指标 | 门 |
|---|---|---|---|
| referent 选择 | 32 任务演示；按 session 划分 | top-1、risk-coverage、拒答率 | G8 |
| 掩码质量 | 500–1000 帧人工标注 | IoU、边界 F1、透明/反光子集 | G8 |
| 任务帧 | 合成噪声 + 真值 | 平移/旋转误差、RANSAC 失败率 | G8 |
| 检索 | leave-one-session-out | top-5 有效目标、spread | G8 |

**仿真（机制，不预测绝对成功率）**

- 3 个任务族：peg-in-hole、hang/stack、zip/unlock；
- 每 cell ≥50 对；主对比 MATE vs bbox；
- 剂量-反应、安慰剂、oracle、中介；
- 延迟/ chunk 扫描；
- 报告相对效应 + CI，不报告「真机成功率预测」。

**真机不计分通道（唯一认真做因果的地方）**

- 任务：PlugInEthernet（插入 + 干扰物）、HangCup（挂 + 位置）、StackBowls（同类叠放）、ZipUp（线/变形边界）、FoldTowel（非回归）；
- 每任务 50–64 对（若通道允许；否则尽量多，并如实报功效）；
- 随机化顺序；记录初始场景；主指标 referent 正确率 + 最后 3 cm 成功；
- 预注册决策规则（§6.8）。

**官方 32×10**

- 不用于 per-task 因果声明；
- 报告总成功率、步骤分、分轴成功率、拒答率、identity switch、p99、timeout；
- 用不计分通道的主对比作为因果证据；官方 run 作为泛化/排行榜证据。

## 7. 数值核算结果（非真机）

### 7.1 本轮真正得到的「结果」

本轮没有跑真机/仿真策略实验；以下是可复现的解析/数值核算：

1. **功效**：上表。结论是官方 10 次/任务不可检验 +10pp；不计分通道需 50–64 对；human 轴 64 次功效不足。
2. **RANSAC**：\(\rho=0.3\) 需 169 次迭代；\(\rho=0.5\) 需 35 次；\(\rho=0.2\) 需 574 次 → 低内点率应关闭而不是硬算。
3. **延迟**：分割 5–15 ms + 描述子 <1 ms + 检索 1–5 ms + RANSAC 2–5 ms + 打分 <1 ms ≤30 ms p95，落在 167 ms 块内。
4. **内存**：<1 GB，可随提交包分发。

### 7.2 这些数字改变了什么

| 第 12 轮 | 第 13 轮修正 |
|---|---|
| G3：5 任务 ×5 次 A/B，3/5 +10pp | 5 次的 MDE 75–96pp；改为不计分通道 50–64 对 + 混合效应/中介 |
| 「human +10pp → 全局 +2pp」 | 官方 human 仅 64 次，MDE 10–22pp；只能做机制/仿真，不承诺全局 |
| 「官方 320 次可验证 +4–7pp」 | 单臂 320 的标准误 2.4pp；因果结论必须来自配对通道 |
| 「相对目标 > 绝对目标」 | 需要区分「掩码」「对比校准」「任务帧」三个因子；用 MIRROR 消融 |

### 7.3 什么会让我们放弃

| 观察 | 结论 | 行动 |
|---|---|---|
| 64 对下 referent 增益 <5pp | 实例身份不是瓶颈 | 停 MATE，保留 CHUNK-SERVO |
| mask IoU 断点 >0.8 | 几何分割太脆 | 转 C3 或放弃 MATF |
| 中介间接效应 <20% | 增益不来自 referent | 重定位机制，别讲故事 |
| anti-MATE 不比随机差 | 分数无判别性 | 重校准/换描述子 |
| p99 增加 >30 ms | 实时性不达标 | 隔块/降 ROI/剪枝 |
