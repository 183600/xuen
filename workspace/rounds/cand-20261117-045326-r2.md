# 第 2 轮（UniBot 线 · 第 2 轮；本轮灵感：「主动交互」×「Isaac Sim」）

> 承接第 1 轮 **UniBot-SAGE**。本轮不推翻，只做两件事：**把"被动确认抓握"升级为"主动让抓握变得可观测"**（主动交互），**把"代理评测"升级为"反事实失效仪器"**（Isaac Sim）。编号续用：定义 **U13–U22**、引理 **L8–L13**、实验 **E619–E640**；v1 的 U1–U12 / L1–L7 / E601–E618 继续有效。

## 0. 情报核实（检索日期 2026-11-17）

**关于「主动交互」该取哪个义项**：有两条可能读法——(a) 社交/人机交互意义上的"主动发起交互"；(b) 具身操作意义上的**主动信息获取（active perception / epistemic action）**：智能体主动采取物理动作去降低关于世界状态的不确定性。对 UniBot 这种"单策略、桌面操作、成功率计分"的赛道，(b) 是可直接换算成分数的读法；(a) 在评测里几乎没有接口（评测不提供人类伙伴的交互通道，只有"人为干扰"作为扰动场景）。故本文以 (b) 为主线，把 (a) 降级为"对人为干扰的主动检测与恢复"这一小支线。这个选择本身可证伪：若 (b) 的边际收益在代理评测上不可见，则整条线降级。

关于 Isaac Sim / Isaac Lab / Isaac Lab-Arena 的事实（用于判定可行性，**不做性能断言**）：

1. Isaac Lab 的人类机器人 "batteries-included" 资产**已包含 Unitree G1**（与 H1 并列）。
2. 但内置 G1 任务用的是 `G1_MINIMAL_CFG` / `g1_minimal.usd`，其资产说明**为降低仿真开销移除了碰撞网格**；接触密集的桌面操作必须补回碰撞体。且内置遥操支持的是 Unitree 三指与 Inspire 五指，**与评测的 Dex1 单自由度夹爪并非同一手型** ⇒ G1+Dex1 的 USD 需**自建/转换并做接触校验**，不能假设开箱即用。
3. **Isaac Lab-Arena**（alpha v0.3，2026-01 起）提供 Scene×Embodiment×Task 的可组合评测、受控变化（光照/背景/相机/质量）、逐 episode 指标、谓词式子任务进度追踪与敏感性分析；它采用**策略服务端/客户端契约**（GR00T、π0.5 或自定义策略放在 server 后面）——这与 UniBot "选手自行部署服务、评测端远程调用"的形态同构，**我们的提交服务可几乎原样塞进 Arena 做离线评测**。
4. **硬件门槛**：Isaac Sim 的 RTX 渲染需要带 RT core 的 GPU；2026-10 的第三方横评明确指出 A100/H100 这类无 RT core 的卡**不受 Isaac Sim 支持**。⇒ 若训练集群是 A100/H100，则仿真评测节点必须是 RTX 节点（如 RTX 6000 Ada / 4090 / L40S），**训练与仿真基础设施必须分开**。这是本轮最容易被低估的工程约束。
5. Arena 仍为 **alpha，API 会变**；其 LIBERO/RoboCasa 套件是 Lightwheel 在 Isaac Lab 上的**改版**而非原 MuJoCo 基准 ⇒ 其分数只能当"另一个基准"，不能与官方真机分数直接比。
6. 主动感知的理论锚点：Bajcsy 的 active perception；ρ-POMDP（把状态奖励换成信念奖励）；Hsiao–Lozano-Pérez–Kaelbling 的"目标达成 / 信息增益"双模式切换；Ghasemi–Topcu 的 AP²-POMDP（感知动作与规划动作解耦）；ActiveGrasp（CVPR 2026）把信息增益定义为抓取分布的熵减。

**本轮没有新的真机或仿真实验数据**；下文出现的所有"判据 / 门槛"均为**预注册的设计目标**，不是已取得的实验结果。

## 1. 直觉解释（先讲人话）

第 1 轮把"抓住没有"当成一个要用三路信号**被动估计**的隐变量，并给它配了一条保守介入规则。这个做法有一个我们自己写进风险栏、但没正面解决的漏洞：**被动观测存在一个"不可辨识子空间"**。机械臂静止、夹爪闭合、腕部画面里物体好好待在夹爪中间——此时"牢牢夹住"和"只是靠在夹爪里、其实没吃上力"在观测上可以长得一模一样；单自由度夹爪没有触觉，更没有力反馈可以区分。你越需要它（未见物品、透明/反光物体、细长物），它越不可信。

「主动交互」给的解药很直接：**既然被动看不出来，就主动做一个小实验让它暴露。** 抬升 2–5 mm——真正夹住的物体会跟着走，没夹住的物体会留在桌面或滑回去。这是一次**物理询问**，不是一次估计。更妙的是第 1 轮自己算过：episode 时长与成功率的相关只有 −0.011，"做得快"没有分数红利 ⇒ **花 0.3–0.8 秒做一次探针，在计分上几乎是免费的**（唯一硬约束是 44 秒的固定时域）。这把第 1 轮"误判不对称"的风险结构整个翻了过来：与其带着空夹爪一路跑到超时（硬失败），不如花半秒问一句"你到底在不在"。

但主动交互不是免费的午餐，它有两个反身性代价：

- **观测者效应**：探针会改变它要测量的状态。一次过猛的拉拽可能把"本来只是没夹稳、还能重抓"变成"拉飞了、彻底没了"。所以探针必须"**最小充分激励**"：刚好大到超过传感器噪声，不要大到改变状态。
- **可信度审计**：官方会看动作的统计规律性与延迟波动。探针是**非单调的、看起来像犹豫的动作**，如果做得又频又抖，可能被读成"策略不稳定 / 脚本化"。所以探针要有**语法**：幅度、时长、jerk 上限、次数上限，并且能被审计层解释成"有意的信息获取"而非异常。

「Isaac Sim」补的是另一半：**我们缺失效数据**。官方 32 个数据集基本是成功演示——你没法从成功里学"怎么判断失败"，更没法标注"这一帧到底是滑移还是静止"。仿真的价值不是"训一个更强的策略"（接触密集的插入，sim-to-real 差距仍然大），而是当一台**反事实测量仪**：

- 它可以**注入**滑移、摩擦突变、抓偏 5 mm、遮挡、干扰物，然后告诉你**真值**（接触力、物体相对夹爪位姿、是否承重）；
- 它可以在同一次仿真里给出**阶段真值**（reach/grasp/transport/align/insert/release），这正好治第 1 轮 L7 的"阶段标签噪声"；
- 它可以让同一个探针在"抓住 / 没抓住"两种真值下各跑上千次，直接量出**测量模型** P(y|s,u) 和**扰动模型** P(s'|s,u)，而这两者正是主动交互做"值不值得问"的计算所需的输入；
- 而且因为 Arena 用服务端契约，**我们的提交服务可以原样接进去**，不需要为仿真写第二套策略。

**合成**：第 1 轮是"被动估计 → 低置信才介入"；第 2 轮是"**先问一个便宜的问题，让状态变得可辨识，再带着校准过的信念去执行**"。抓握确认器从"闸门"降级为"信念更新模型"，真正的主控变成一个**探针调度器**：它在"推进任务"和"花一步问清楚"之间按**期望信息增益 / 扰动风险**做取舍。Isaac Sim 不是策略训练场，而是这个取舍所需的**测量模型与反事实失效的发生器**。

## 2. 严谨定义（把直觉写成可检验的东西）

### 2.1 主动抓握消歧作为一个 ρ-POMDP

设抓握状态 $s_g \in S_g=\{\text{free},\text{closing},\text{held\_stable},\text{held\_slipping},\text{lost},\text{released}\}$，信念 $b_t(s)=P(s_{g,t}=s\mid o_{1:t},u_{1:t})$。动作分两类：**任务动作** $a\in A_{\text{task}}$ 与**探针** $u\in P=\{\text{micro\_lift}(h),\text{lateral\_tug}(d),\text{re\_close},\text{wiggle}(\theta)\}$。转移同时依赖 $u$：$T(s'\mid s,u)$；观测 $y$ 为探针响应特征（物体–夹爪相对位移、腕部光流、夹爪标量差分、EE 加速度响应）。

探针选择（单步贪心 VOI，带安全约束）：

$$u^\*=\arg\max_{u\in P}\big[\,\mathrm{IG}(u\mid b)-\lambda\,R(u\mid b)\,\big]$$
$$\text{s.t.}\quad a(u)\le a_{\max},\ \ \mathrm{IG}(u\mid b)\ge \mathrm{IG}_{\min},\ \ T_{\text{rem}}-T_{\text{probe}}(u)\ge T_{\text{task,need}}$$

其中 $\mathrm{IG}(u\mid b)=H(b)-\mathbb{E}_{y\sim P(\cdot\mid b,u)}H(b^+_u(y))$，$R(u\mid b)=P(s'\notin S_{\text{safe}}\mid b,u)$。

**关键点**：$R(u)$ 不是正则项，而是**真实的失败概率**（把物体拉飞）。所以 $\lambda$ 不是随便调的，是"一次硬失败 vs 一次成功"的代价比。第 1 轮已论证：终态成功是唯一计分货币 ⇒ 一次硬失败 = 该任务 0 分，多花 0.5 秒 = 0 分损失（只要不超时）。所以 $\lambda$ 应该**很大**——宁可少问，不可问坏。

### 2.2 可辨识性：为什么"主动"是必要的，不只是更好

**命题（直觉版）**：在单自由度、无触觉、机械臂准静态的观测下，存在一个非平凡的等价类

$$\mathcal{E}=\{\text{held\_stable},\ \text{resting\_in\_jaw},\ \text{contact\_not\_grasped}\}$$

使得对任意被动特征 $\phi(o_{\text{passive}})$，$\phi$ 在这三个状态上的分布可以完全重合。

**证明思路**：三者都满足"夹爪闭合量相同、腕部画面中物体位于两指之间、EE 速度为零"；若物体还同时被桌面支撑（resting / contact 情形），连重力形变都不产生可观测差异。被动观测是**零激励**下的观测，零激励对"承重 / 不承重"没有区分力。因此任何被动抓握分类器在 $\mathcal{E}$ 上的错误率下界 = 该等价类内先验的最小值——这正是第 1 轮 E603 的 AUROC 上不去、且"未见物品更差"的根本原因，而不是网络不够大。

**主动的充要性（直觉版）**：要打破 $\mathcal{E}$，必须施加一个**与重力 / 惯性可区分**的激励；最小的是竖直微抬（改变支撑条件），其次是水平轻拉（改变摩擦条件）。形式化地说，探针必须在状态转移上产生**与状态相关的观测灵敏度** $\partial M_u/\partial s \neq 0$，且激励幅度超过噪声底。完整引理见 L8 / L9。

### 2.3 Isaac Sim 的正确用法（与错误用法）

- **正确**：把 sim 当**测量模型估计器**与**反事实标签发生器**。它输出 $P(y\mid s,u)$、$P(s'\mid s,u)$、阶段真值、失败类型，而不是"我们在真机上能得多少分"。
- **错误**：把 sim 成功率当官方分数代理直接调参。接触密集的插入/旋拧，摩擦、柔顺、间隙、相机噪声的任何一项失配都会让绝对成功率失真。
- **桥接**：只让**测量模型的参数**过 sim-to-real（摩擦系数 $\mu$、质量 $m$、夹爪间隙 $\delta$、相机噪声 $\sigma$、控制延迟 $\tau$），用少量真机锚点（每个任务簇 ~20–30 次探针回放）做系统辨识；**策略参数不过 sim**。这是一个可检验的迁移假设，而不是信仰。

### 2.4 与第 1 轮的关系（深化与修剪）

- **深化**：IP-02 → **IP-02A**（被动确认 → 主动消歧 + 6 状态时序信念 + 滑移检测）；IP-06 → **IP-06 + IP-09**（真实数据 OOD 代理 + Isaac Sim 反事实仪器）；IP-03 → **IP-03A**（增加"探针模式"的短 chunk 调度）。
- **修剪**：IP-05（姿态先验）与 IP-07（双空间）本轮**冻结为 P2 探索**，不占主线资源；IP-04（在线适配）因合规未决，降为"episode 内、零权重更新"的保守形态。第 1 轮的剪枝规则原样保留：真实代理与真机相关 $|r|<0.3$ ⇒ 砍掉一切以代理指标为依据的**策略微调**。
- **方法论修正**：**IP-09 不是"分数代理"，它是"测量仪器"**。即使真实代理相关性低，它用于机制验证与测量模型估计的用途仍然成立。把这两件事分开，是本轮最重要的概念澄清。

## 3. 本轮研究问题

- **Q6（可辨识性）**：被动观测的等价类 $\mathcal{E}$ 有多大？最小充分探针是什么？在 sim 里能否把 $\mathcal{E}$ 缩小到单点？
- **Q7（探针调度）**：在固定时域下，IG 贪心调度相对"固定阈值介入"和"oracle 调度"差多少？有没有简单到能真机部署的近似？
- **Q8（测量模型迁移）**：哪些测量模型参数能过 sim-to-real、哪些必须真机标定？需要多少真机锚点才能把探针决策误差压到可接受？
- **Q9（观测者效应）**：探针把"可救失败"变成"硬失败"的概率有多大？"最小充分激励"能否在 sim 里被系统性地找出来？
- **Q10（审计兼容）**：多大的探针比例 / 幅度会被判成"不规则交互"？探针语法能否同时满足信息量与动作统计良构？
- **Q11（工程）**：同一份提交服务接 Arena 的改造量有多大？RTX 仿真节点与 A100/H100 训练集群如何分工？

## 4. 设计原则（在 P1–P6 上追加）

- **P7 最小充分激励**：探针只做到"刚好让状态可辨识"，绝不为了信息量牺牲状态。
- **P8 信息预算而非次数预算**：优化"每次探针的期望信息增益/风险"，而不是"探针次数"；风险按硬失败代价计。
- **P9 仿真只做仪器**：sim 可产出测量模型、反事实标签、阶段真值、机制排序；**禁止**把 sim 绝对成功率当官方分数代理。
- **P10 主动动作必须可审计**：任何非单调动作都进入探针语法（幅度/时长/jerk/频次上限），并在审计层可解释。

## 5. 本轮最值得押注

**把第 1 轮"抓握确认"这个最大风险点，用"主动微探针"从"估计问题"改写成"辨识问题"**：一次 2–5 mm 的抬升就能把被动不可辨识的等价类 $\mathcal{E}$ 打破，而第 1 轮已证明时间没有分数红利 ⇒ 这是少数"用赛制红利直接买掉最大风险"的改动。Isaac Sim 的角色是把这次改动的**测量模型、扰动模型、阶段真值**在真机之前算清楚。

## 6. 本轮最大风险（一句话）

**主动探针的观测者效应与仿真测量模型的不可迁移性叠加**：探针在仿真里可能"问得又准又安全"，但在真机上，未被建模的摩擦/柔顺会让它要么激励不足（白问）、要么把还能重抓的物体拉飞（把可救失败变成硬失败），而最需要探针的未见物品/泛化场景，恰恰是 sim-to-real 测量模型最不准的地方。

# 第 2 轮产物 · 创新点清单 v2（UniBot 线）：**UniBot-SAGE v2 · AIM**

> **AIM = Active Information Manipulation**（主动信息式操作）。在 v1 的"接地 / 技能 / 适应 / 工程"四层之上，加一层**主动性**：把"被动确认再介入"改成"主动询问再提交"；并用 **Isaac Sim / Isaac Lab-Arena** 作**反事实测量仪**，而不是策略训练场。
> **继承关系**：v1 = UniBot-SAGE（定义 U1–U12 / 引理 L1–L7 / 实验 E601–E618）继续有效；v2 新增定义 **U13–U22**、引理 **L8–L13**、实验 **E619–E640**。本轮是**深化 + 修剪**，不是重基线。
> **数据纪律**：v1 的 teaser 榜数字继续沿用并标注 "teaser"（`leaderboard_data.json` 由 `gen_leaderboard.py` 生成、官方未正式发布）；Isaac Sim / Isaac Lab / Arena 的陈述来自公开文档与第三方横评，属**可行性事实**而非性能断言；**本轮没有新的真机或仿真实验结果**，所有门槛均为预注册设计目标。

## 0. 本轮结论摘要

**一句话路线**：v1 的两根支柱各做一次"认识论升级"——

| v1 | v2 | 升级的实质 |
|---|---|---|
| 被动抓握确认（GraspVerify） | **主动抓握消歧（IP-02A）** | 从"估计隐变量"变成"用最小探针让隐变量**可辨识**" |
| 单一代理评测（IP-06） | **IP-06（真实 OOD 代理）+ IP-09（Isaac 反事实仪器）** | 把"分数代理"与"测量仪器"分开，各司其职、互不冒充 |
| 固定 chunk 缝合 | **IP-03A（任务模式 / 探针模式双模）** | 探针需要短 chunk + 高反馈，缝合与调度必须协同 |
| 审计是附加项 | **IP-08 升 P1** | 主动动作引入"非单调轨迹"，审计从监控变成**设计约束** |

**三条依据**：

| 依据 | 数值 / 事实 | 推出的设计 |
|---|---|---|
| v1 的时间—成功相关 | 任务内 corr(dur, succ) ≈ −0.011，episode 43.7–45.2 s | 探针的**计分**时间成本 ≈ 0，只受固定时域约束 ⇒ 主动交互在计分上近乎免费（L10） |
| 被动可辨识性 | 等价类 $\mathcal{E}=\{\text{held\_stable},\text{resting\_in\_jaw},\text{contact\_not\_grasped}\}$ 在零激励下特征分布可重合（L8） | 被动 AUROC 有**结构性上界**，与模型容量无关 ⇒ 必须主动激励（L9） |
| 官方数据构成 | 32 数据集 ≈ 32k episodes，以成功演示为主 | 失效 / 滑移 / 阶段标签稀缺 ⇒ 需要反事实发生器（IP-09） |

**合规红线（P5）不变**：单一 checkpoint、单一 API 服务；不用评测侧私有信息；不做硬编码任务分支。**新增红线**：探针不得读取评测端未声明的执行语义；探针语法必须在提交前自证良构（IP-08 / E629）。

## 2. 创新点详述

### IP-02A · ActiveGrasp 主动抓握消歧（P0）

- **动机**：v1 IP-02 的被动估计在等价类 $\mathcal{E}$ 上**不可辨识**（L8）；一次 2–5 mm 的竖直微抬即可打破（L9）；而 v1 已证明时间无分数红利 ⇒ 探针在计分上近乎免费（L10）。
- **与 v1 的差异**：
  1. 从"二值 $g_t$ + 固定阈值"变成"6 状态时序信念 $b_t$"；
  2. 从"低置信才**介入**（重抓）"变成"低置信先**询问**（探针），问清楚再提交"；
  3. 从"固定重抓规则"变成"探针库 + VOI 调度"；
  4. 抓握确认器从**闸门**降级为**测量模型 / 信念更新器**——这是角色上的根本变化。
- **状态机**（U13）：
  ```
  free --close--> closing --+--> held_stable --release--> released
                            +--> held_slipping --+--> held_stable（自恢复）
                            |                    +--> lost（滑脱）
                            +--> lost（空夹）
  ```
  滑移检测由三路融合：腕部光流（物体相对夹爪的像素位移）、物体–夹爪相对位姿（若可估）、夹爪标量微变。滑移是**主动探针的最强触发信号**。
- **探针库**（U15）：`micro_lift(h∈[2,5] mm, ṡ≤v_max)`、`lateral_tug(d≤3 mm)`、`re_close`、`wiggle(θ≤3°)`。每个探针都有测量模型 $M_u(y\mid s)$ 与扰动模型 $P(s'\mid s,u)$，由 IP-09 估计。
- **调度**（U19）：当 $\max_s b(s)<\tau_{\text{belief}}$ 时，取
  $u^\*=\arg\max_{u}[\mathrm{IG}(u\mid b)-\lambda R(u\mid b)]$，受幅度、剩余时域、单相位探针数 $n\le3$ 约束；否则直接 commit。
- **技术可行性**：中–高。探针本质是往任务动作流里插一小段受控轨迹，**接口层无需改**（仍是 action chunk）；难点在测量模型与真机摩擦标定，而非在策略结构。
- **所需资源**：无需新数据训练主干；需 IP-09 的仿真 + 少量真机锚点；在线决策开销 < 1 ms。
- **落地步骤**：①在 IP-09 里实现 6 状态与探针库；②估计 $M_u$、$P(s'\mid s,u)$；③真机锚点标定 $\mu,\delta,\sigma,\tau$；④实现 VOI 调度器；⑤在 6 个最难任务（Plug In Ethernet / Unlock / Spell robot / Organize Stationery / Open Pill Bottle / Pick Out Battery）做 A/B；⑥把探针语法接入 IP-08 审计。
- **风险**：①**观测者效应**（拉飞）；②测量模型失配；③探针过多触发审计；④未见物品上 $M_u$ 漂移（E634）。
- **与 v1 引理的关系**：v1 L3 说的是"保守介入不伤害基线"；L10/L11 把它加强为"在测量模型正确时，探针后提交的误差不大于不探针提交"——但**测量模型错时失效**，这是本轮最大的认识论缺口。

### IP-09 · SimCounterfactual 反事实失效仪器（P0）

- **动机**：官方数据以成功演示为主，失效 / 滑移 / 承重真值稀缺；而主动交互恰恰需要"失败长什么样"的**真值**来估计测量模型与扰动模型。
- **与"用 Isaac 训策略"的区别**：我们不把 sim 策略直接部署；**只取四样东西**：①测量模型 $M_u$；②扰动/转移模型 $P(s'\mid s,u)$；③阶段真值（治 L7 的标签噪声）；④失效类型标签（治"缺失败数据"）。绝对成功率**禁止**外推到官方分数（L12）。
- **构建**：
  - **机体**：Isaac Lab 的 G1 资产 + **自建 Dex1 单自由度夹爪**。注意两个坑：(a) 内置 `g1_minimal.usd` 移除了碰撞网格，接触任务必须补碰撞体；(b) 内置遥操手型是 Unitree 三指 / Inspire 五指，与 Dex1 不同 ⇒ 需 URDF→USD 转换 + 夹爪碰撞/驱动校验。先用"桌面抬升 / 夹持 / 滑脱"三个最小测试验证接触。
  - **场景**：尽量贴近官方任务的桌面几何与物体类别；拿不到官方资产时用重建/近似资产，并**把资产差异记为迁移协变量**。
  - **变化轴**（对应 5 类泛化 + 失效注入）：位置、干扰物、背景/光照、未见物体（替换资产）、人为干扰（脚本化扰动）、摩擦 $\mu$、质量 $m$、夹爪间隙 $\delta$、抓偏（±5 mm / ±5°）、滑移冲量、相机噪声 $\sigma$、控制延迟 $\tau$。
  - **真值**：接触力、物体–夹爪相对位姿、承重标志、阶段标签、失败类型。
  - **集成**：UniBot 提交通道服务 → Arena policy server 适配器；并行 episode。Arena 的"谓词式子任务进度追踪 + 敏感性分析"可直接产出六因子需要的东西。
- **迁移纪律**（U20 / L12）：只过**测量模型参数**，不过策略；真机锚点做系统辨识；绝对分数禁止外推；Arena alpha API 变更要预留适配层。

- **落地步骤**：①G1+Dex1 资产与碰撞校验；②探针测量模型扫描（每个探针 × 6 状态）；③失效注入与标签生成；④阶段真值 → 六因子分解（对齐 v1 IP-06 / L7）；⑤Arena 适配器 + 并行评测；⑥真机锚点标定 + 迁移误差报告。
- **风险**：①sim-to-real（接触/摩擦/柔顺/相机）；②资产不匹配；③Arena alpha；④RTX 硬件；⑤**纪律风险**：把 sim 分数误当官方分数。

### IP-03A · ChunkStitch + 探针模式（P0）

- **新增双模**：
  - **Task mode**：长 chunk（8–16 步），低抖动、低调用频率，用于接近 / 搬运。
  - **Probe mode**：短 chunk（1–2 步），高反馈，用于 micro_lift / tug / wiggle 的闭环执行。
- **模式切换**：只在块边界切换，带最小驻留时间；探针结束回 task mode 时保证 C0/C1 连续（复用 v1 U7 的一阶外推 + 残差）。

- **风险**：短 chunk 提高调用频率 ⇒ 并发压力上升；探针自身的加減速若不够平滑，会被审计判成"抖动"。

### IP-10 · ActiveInsertion 主动插入搜索（P1）

- **风险**：①接触代理不可靠；②搜索动作撞坏物体 / 把插头推歪；③审计风险。

**定义 U13（抓握状态空间）** $S_g=\{\text{free},\text{closing},\text{held\_stable},\text{held\_slipping},\text{lost},\text{released}\}$，转移约束：$\text{free}\to\text{closing}\to\{\text{held\_stable},\text{held\_slipping},\text{lost}\}$；$\text{held\_slipping}\to\{\text{held\_stable},\text{lost}\}$；$\text{held\_*}\to\text{released}$。

**定义 U14（抓握信念与更新）** $b_{t+1}(s)\propto M_{u_t}(y_{t+1}\mid s)\sum_{s'}T(s\mid s',u_t)\,b_t(s')$。任务动作与探针共用同一滤波器，区别只在 $u$ 是否被**设计**来最大化 $\mathrm{IG}$。

**定义 U15（探针库与探针语法）** $P=\{\text{micro\_lift}(h),\text{lateral\_tug}(d),\text{re\_close},\text{wiggle}(\theta)\}$；语法 $\mathcal{G}$：$|h|\le5$ mm、$|d|\le3$ mm、$|\theta|\le3^\circ$、jerk $\le J_{\max}$、单相位探针数 $\le3$、$\rho_{\text{probe}}\le\rho_{\max}$（初值 15%）。

**定义 U16（测量模型）** $M_u(y\mid s)\triangleq P(y_t\mid s_{g,t}=s,u_{t-1}=u)$，$y=(\Delta x_{\text{obj-grip}},\ \text{flow}_{\text{wrist}},\ \Delta g_{\text{grip}},\ a_{\text{ee}}\text{-response})$。

**定义 U17（期望信息增益）** $\mathrm{IG}(u\mid b)=H(b)-\mathbb{E}_{y\sim P(y\mid b,u)}H(b^+_u(y))$，其中 $P(y\mid b,u)=\sum_s b(s)M_u(y\mid s)$。

**定义 U18（扰动风险与最小充分激励）** $R(u\mid b)=\sum_s b(s)\,P(s'\notin S_{\text{safe}}\mid s,u)$；最小充分激励 $u^\*=\arg\min_{u\in P}\operatorname{cost}(u)$ s.t. $\mathrm{IG}(u\mid b)\ge\mathrm{IG}_{\min}$ 且 $R(u\mid b)\le R_{\max}$。

**定义 U19（VOI 调度）** 当 $\max_s b(s)<\tau_{\text{belief}}$ 且存在 $u$ 使 $\mathrm{IG}(u\mid b)\ge\mathrm{IG}_{\min}$、$R(u\mid b)\le R_{\max}$、$T_{\text{rem}}-T_{\text{probe}}(u)\ge T_{\text{task,need}}$ 时，执行 $u^\*=\arg\max_u[\mathrm{IG}(u\mid b)-\lambda R(u\mid b)]$；否则提交当前最优动作（commit）。取 $\lambda\ge10$（一次硬失败 ≈ 整个任务分数）。

**定义 U20（sim-to-real 测量模型映射）** $\Phi:\theta_{\text{sim}}\to\theta_{\text{real}}$，$\theta=(\mu_{\text{friction}},m_{\text{obj}},\delta_{\text{gap}},\sigma_{\text{cam}},\tau_{\text{ctrl}})$。仅当真机锚点集 $A$ 上的后验预测误差 $e(\Phi)\le e_{\max}$ 时，允许用 sim 的 $M_u$ 做调度；否则调度退化为"固定规则探针"（L12）。

**定义 U21（反事实数据集）** $D_{\text{cf}}=\{(s_g,u,y,s'_g,\text{phase},\text{failureType},\theta_{\text{sim}})\}$，由 IP-09 生成，用于估计 $M_u$、$T$、阶段真值与失效标签。

**定义 U22（审计良构性）** 探针动作序列满足：jerk $\le J_{\max}$、无非预期离群、$\rho_{\text{probe}}\le\rho_{\max}$、探针幅度落在任务动作支持集内；审计报告须能导出每段探针的 $(b_{\text{trigger}},u,\mathrm{IG},R)$。

## 4. 关键引理（L8–L13）

**引理 L8（被动不可辨识性）** 在假设 (i) 单自由度夹爪、(ii) 无触觉 / 力矩、(iii) 机械臂准静态（$v_{\text{ee}}\approx0$）、(iv) 物体可被桌面支撑下，等价类 $\mathcal{E}=\{\text{held\_stable},\text{resting\_in\_jaw},\text{contact\_not\_grasped}\}$ 对被动观测 $o=(g,w,v_{\text{ee}})$ 的似然可完全重合；因此任何被动分类器在 $\mathcal{E}$ 上的贝叶斯错误率下界为 $\min\{\text{prior}\}$，与模型容量无关。
*证明思路*：三者可构造出相同的 $g$、$w$、$v_{\text{ee}}=0$，且不产生可观测形变；被动观测不含激励，无法区分承重。∎

**引理 L9（主动可辨识性）** 若探针 $u$ 使支撑条件改变（如竖直微抬），且 $|\Delta x(u)|>\varepsilon$（$\varepsilon$ 为相对位移 / 光流的噪声底）、探针不跨越失败边界，则 $\mathcal{E}$ 在 $y$ 上的似然分裂：held_stable 响应为"物体随爪"，resting / contact 响应为"物体不随爪或滞后"，故 $\mathcal{E}$ 可辨识。更一般地，可辨识性要求探针在状态转移上产生**与状态相关的观测灵敏度** $\partial M_u/\partial s\neq0$。∎

**引理 L10（探针净收益分解）** 一次探针相对"直接提交"的期望收益
$$\Delta=P(\text{commit error}\mid b)\,\Delta_{\text{correction}}\,\mathrm{IG}_{\text{gain}}-R(u\mid b)L_{\text{hard}}-c_{\text{horizon}}$$
其中 $L_{\text{hard}}$ 为硬失败代价（≈ 该任务全部分数），$c_{\text{horizon}}$ 为时域占用风险。由于 v1 测得时间无分数红利（corr(dur,succ)≈−0.011），$c_{\text{horizon}}$ 仅在被探针拖到超时时非零 ⇒ 存在一个宽区间使 $\Delta>0$。∎（这是"主动交互在计分上近乎免费"的形式化。）

**引理 L11（探针后提交的误差上界）** 在测量模型正确、且各探针条件独立给定 $s$ 的假设下，按 U19 贪心选择探针使后验熵单调不增；提交时的期望错误率 $\le H(b_{\text{final}})/(2\ln2)$（Fano 界）。因此"探针后提交"的误差不大于"不探针提交"，只要 $R(u\mid b)\le R_{\max}$ 且 $\lambda$ 足够大。∎（**条件性结论**：测量模型错时失效——这正是 L12 的边界。）

**引理 L12（仿真的用途边界）** 令真实测量模型 $M_{\text{real}}$，仿真 $M_{\text{sim}}(\theta_{\text{sim}})$，映射 $\Phi$。若 $\mathrm{TV}(M_{\text{real}},M_{\text{sim}}(\Phi(\theta_{\text{sim}})))\le\delta_{\text{tv}}$，则基于 sim 的探针**排序**（哪个探针信息量大）在 $\delta_{\text{tv}}$ 小于探针间 IG 间隔时保持；但**绝对成功率**可因转移模型 $T$ 的误差而无界偏离。⇒ sim 可用于机制 / 排序 / 测量模型，**不可用于绝对分数代理**。∎

**引理 L13（审计良构性的可检验条件）** 若探针幅度落在任务动作支持集内、jerk $\le J_{\max}$、$\rho_{\text{probe}}\le\rho_{\max}$，则整体动作分布相对无探针基线的 KL 散度 $\le\rho_{\max}\cdot\mathrm{KL}_{\text{bound}}$；当 $\rho_{\max}$ 足够小时，动作统计检验（如 MMD / 离群率）在给定样本量下无法拒绝"与基线同分布"。这是**制定性条件**（须在 E629 实测），不是定理。∎

## 5. 算法骨架

```python
# ===== IP-02A + IP-09：主动抓握消歧 =====
class GraspBelief:                                   # U13 / U14
    STATES = ["free", "closing", "held_stable",
              "held_slipping", "lost", "released"]

    def update(self, b, u, y):
        pred = {s: sum(T(s, sp, u) * b[sp] for sp in self.STATES)
                for s in self.STATES}                 # 预测
        post = {s: M[u](y, s) * pred[s] for s in self.STATES}   # 观测更新
        z = sum(post.values()) or 1.0
        return {s: post[s] / z for s in self.STATES}

class ProbeLibrary:                                  # U15 / U16 / U17 / U18
    def __init__(self, M_sim, T_sim, phi):
        self.M, self.T, self.phi = M_sim, T_sim, phi  # 参数经 Φ 校准

    def candidates(self, phase, b):
        base = {"micro_lift": 2.0, "lateral_tug": 1.0,
                "re_close": 0.5, "wiggle": 1.5}
        return [u for u in base if self.allowed(u, phase, b)]

    def ig_and_risk(self, u, b):
        # P(y|b,u) = sum_s b(s) M_u(y|s);  R 由扰动模型 T 给出
        py = self.mixture(u, b)
        post = [self.belief_after(u, b, y) for y in py.support]
        ig = entropy(b) - sum(py.p(y) * entropy(bp) for y, bp in zip(py.support, post))
        risk = sum(b[s] * self.T.failure_mass(s, u) for s in b)
        return ig, risk

    def allowed(self, u, phase, b):
        return (abs(self.amplitude(u)) <= AMP_MAX[u]
                and self.jerk(u) <= J_MAX
                and self.probe_count(b) < 3)

class ActiveGraspScheduler:                          # U19
    def __init__(self, lib, tau_belief=0.9, ig_min=0.25,
                 r_max=0.01, lam=10.0):
        self.lib, self.tau, self.ig_min = lib, tau_belief, ig_min
        self.r_max, self.lam = r_max, lam

    def decide(self, b, phase, t_rem):
        if max(b.values()) >= self.tau:
            return ("commit", None)
        if t_rem < T_NEED.get(phase, 0):
            return ("commit", None)                    # 时域闸门（L10）
        best = None
        for u in self.lib.candidates(phase, b):
            ig, r = self.lib.ig_and_risk(u, b)
            if ig < self.ig_min or r > self.r_max:
                continue
            score = ig - self.lam * r                    # VOI
            if best is None or score > best[1]:
                best = (u, score)
        return ("probe", best[0]) if best else ("commit", None)

# ===== 与 v1 的统一服务：只加一个"探针模式"分支 =====
class UniBotSAGEv2Policy:
    def __init__(self, ckpt, ...):
        self.model = load_single_checkpoint(ckpt)
        self.belief = GraspBelief()
        self.sched = ActiveGraspScheduler(ProbeLibrary(*load_sim_models()))
        self.exec = ProbeExecutor()                    # 探针 -> 短 chunk
        self.st = Stitcher()                           # v1 U7
        self.audit = AuditLog()                        # v1 IP-08

    def get_action(self, obs, port):
        s = self.sessions[port]
        s.b = self.belief.update(s.b, s.last_u, featurize(obs))
        mode, u = self.sched.decide(s.b, phase(obs), s.t_rem)

        if mode == "probe":
            chunk = self.exec.generate(u, obs)         # 1–2 步短 chunk
            s.last_u = u
            self.audit.probe(u, s.b, self.sched.lib.last_ig_risk)  # U22
        else:
            zt, zp, c = self.route(obs)
            chunk = self.model.act(obs, zt, zp, c, self.chunk_len(zp))
            s.last_u = "task"
        chunk = self.st.stitch(chunk, s.last_action)   # C0/C1
        chunk = self.audit.clamp_and_log(chunk, obs, ...)
        s.last_action = chunk[-1]
        return pack(chunk, obs)
```

## 8. 预注册判据与处置

| 判据（预注册） | 门槛 | 未达标处置 |
|---|---|---|
| 被动不可辨识（E619 / L8） | 被动 AUC ≤ 0.6 | 若 ≥0.75 ⇒ **削弱主动线**，保留被动确认 + 小探针，把资源转回 IP-01/IP-03 |
| 探针信息量（E620/E623） | $\mathrm{IG}\ge0.5$ bits 且拐点 ≤5 mm | 无有效探针 ⇒ 放弃主动消歧，退回 v1 IP-02 |
| VOI 调度（E621） | ≥ 固定规则且后悔 ≤0.15 bits | 改用固定规则探针（简单、可审计） |
| 观测者效应（E622/E635） | 硬失败 ≤1–2% | >5% ⇒ 缩短幅度 / 提高 $\lambda$ / 改为"先重抓再探" |
| 测量模型迁移（E624） | $e(\Phi)\le e_{\max}$ | 不达标 ⇒ 退化为固定规则探针，sim 只做阶段真值与失效标签 |
| 反事实标签（E625） | sim AUROC ≥0.90，真机不降 | 标签噪声大 ⇒ 只做机制验证，不做阈值标定 |
| 阶段真值（E626） | 一致性 ≥0.80 | <0.80 ⇒ 回到 v1 VLM + 人工抽检 |
| Arena 集成（E627） | 适配器可用 | 失败 ⇒ 退回自建 mujoco/pybullet 仪器，但放弃照片级渲染 |
| 审计良构（E629） | MMD p>0.05 且 $\rho\le15\%$ | 收紧探针语法 / 降低探针比例 |
| 主动插入（E630/E631） | ≥20% 相对提升且接触代理 AUC ≥0.75 | 不达标 ⇒ IP-10 降为 P2，仅保留视觉小步试探 |
| 端到端（E637） | ≥ teaser 榜首 +3 分 | 逐 IP 消融定位无效项并剪枝 |

**继承 v1 的剪枝规则**：真实代理与真机相关 $|r|<0.3$ ⇒ 砍掉一切以代理指标为依据的**策略微调**。**但 IP-09 不受此规则约束**——它不是分数代理，而是测量仪器（L12）；它继续用于测量模型、阶段真值与失效标签，只是禁止把绝对成功率外推。

## 12. 本轮最大风险（一句话）

**主动探针的观测者效应与仿真测量模型的不可迁移性叠加**：探针在仿真里可能"问得又准又安全"，但在真机上，未被建模的摩擦/柔顺会让它要么激励不足（白问）、要么把还能重抓的物体拉飞（把可救失败变成硬失败），而最需要探针的未见物品/泛化场景，恰恰是 sim-to-real 测量模型最不准的地方。
