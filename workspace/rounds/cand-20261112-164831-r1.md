# 第 61 轮（承接第 60 轮「场景感知闭环」IP-153~160；灵感循环第 1 轮；本轮灵感：「演示数据」×「嵌入式系统」）

> 第 60 轮的 SGEC 把「场景→意图→约束→阻抗→执行→证据→场景更新」的认知闭环建立起来：SSM 场景语义建模、CIEC 认知意图约束、EPIR ROS 因果隔离、SERC 闭环、PCE++++ 四维认知预算。但它默认了一个**从未被审视的前提**：场景先验 π_scene、意图映射 ϕ、以及证据链的置信度，都可以在**边/云的大算力、浮点、可在线学习**条件下获得与维护。一旦把这套闭环落到**嵌入式系统**（MCU、定点、KB 级内存、硬实时、无 GPU、无在线训练），三个新的裂缝立刻暴露：
> 1. **先验从哪来？** SSM 的 π_scene(K|z) 在第 60 轮是「给定」的，但它真正的来源只能是**人类演示数据**——演示是唯一同时携带「场景语义 + 接触力 + 阻抗调节」的接地证据。而演示数据在嵌入式端**存不下、算不动、也不能在线训练**。
> 2. **证据在定点上还成立吗？** EV-exec / Cert_eeis / J_exec 全部按实数定义，但 MCU 用 Q 格式定点运算，量化误差会**吃掉安全裕度**；一份「浮点下正确」的证书在定点域里可能已经越界。
> 3. **演示的权威边界在哪？** 把演示编译成策略后，策略只在**演示覆盖的分布内**可信；而嵌入式端没有能力跑大模型做 OOD 检测，最容易发生「在未演示场景上给出自信而错误的阻抗」。

## 0. 直觉与动机

**灵感 1（演示数据 → 演示-约束编译 DCC）**
直觉：不要在 MCU 上训练策略，而是把演示**离线编译**成「少量、定点可表示、可审计」的阻抗原语 + 一张覆盖地图。演示不是要逐帧模仿的轨迹，而是**约束可行域的样本证据**：每一条演示只在阻抗-场景特征空间里给出一个「这里是安全的 K」的点。关键洞见：把 imitation 从「函数拟合」重写为「**约束推断 + 编译**」——DCC 输出分段仿射策略 P_imp 与每个单元的有效域 D_cov，域外一律回退保守控制。

**灵感 2（嵌入式系统 → 定点证据内核 FPEK）**
直觉：证据与证书的计算**本身必须可被嵌入式验证**。把 EV-exec 的哈希、比较、证书校验全部固定为 Qm.n 定点，并显式携带量化误差预算 ε_q；证书在定点域内重新推导，只有扣除 ε_q 后安全裕度仍 ≥ 0 才签发。关键洞见：**证书必须在「执行它的同一算术域」内可验证**——浮点签发的证书对定点执行体没有约束力。

**灵感 3（演示数据 × 嵌入式 → 演示溯源环 DPR）**
直觉：演示数据是一个**会腐坏的资产**——存储位翻转、采集标定漂移、恶意污染，都会让编译出的策略「有证但错」。在端侧维护一个小型环形缓冲，保存演示的**来源指纹**（操作者、时间、标定版本、传感器 hash）与蒸馏产物之间的**血缘**；回放或重编译时做「内容 hash + 血缘」双校验。关键洞见：**演示的合法性必须可追溯**，否则 DCC 会把污染数据编译成一份带证书的错误策略。

**灵感 4（三灵感合流 → 嵌入契约 DEC + 演示-执行一致性回放 DECon）**
直觉：DCC 给出策略、FPEK 给出可验证性、DPR 给出来源，但三者需要一个统一的**契约**：编译后的策略相对演示的偏差 ≤ δ_demo、量化误差经闭环放大后 ≤ ε_margin、资源占用 ≤ B_mcu、且能在端侧**回放演示并通过一致性检验**。把「离线编译 + 端侧回放」当作嵌入式版的「训练-验证」闭环。关键洞见：**离线学的，必须在端上以同一算术域、同一资源约束复现**。

**灵感 5（演示预算 → PCE+++++）**
直觉：演示带来新的预算维度 B_demo = (Storage, Distill_compute, Replay_budget, Provenance_check)。演示越多覆盖越好，但存储与蒸馏算力有限；必须把「演示覆盖收益」与「存储/回放开销」一起纳入 VOI，决定**采哪些演示、丢哪些、何时重采**。若 B_demo 耗尽⇒退回第 60 轮的通用场景先验 + 保守阻抗。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（演示数据 DD）** 一条演示
D = {(s_t, a_t, τ_t, Z_t)}_{t=1}^{T}，并携带来源元数据 ρ_D = (op_id, calib_ver, t_capture, hash_sensor)。
- **投影**：φ(s_t, Z_t, τ_t) = (x_t, K_t)，其中 x_t = (s_t, Z_t) ∈ X 为「位姿-环境」特征，K_t 为由接触力/位移反演的等效阻抗。
- **演示集**：D_set = {D_1, …, D_M}，投影点集 X_D = ∪_i φ(D_i)。
- **覆盖度**（归一化核密度）：ρ_cov(x) = [Σ_i K_h(x − x_i)] / [M · K_h(0)]，核 K_h 带宽 h。
- **有效域**：D_cov = {x ∈ X : ρ_cov(x) ≥ ρ_0}。
- **权威原则（authority ⊆ coverage）**：任何由演示导出的策略，只在 D_cov 内具有约束力；D_cov 外不得引用演示权威。

**定义 162（演示-约束编译 DCC）** 编译器
C_demo: (D_set, B_mcu, ε_q) → (P_imp, {D_cov^(j)}_{j=1}^{M_cells}, Cert_dcc)。
- **分段仿射策略**：P_imp(x) = A_j x + b_j，当 x ∈ D_cov^(j)（第 j 个 Voronoi/聚类单元）。
- **编译目标**：
  min_{P_imp, {A_j,b_j}} E_{x~D_set}[‖P_imp(x) − K(x)‖]  s.t.  M_cells ≤ M_max,  quant_err ≤ ε_q,  resource(P_imp) ≤ B_mcu。
- **编译证书**：Cert_dcc = (δ_demo, ε_q, ρ_0, resource_vector, provenance_digest)，其中 δ_demo = sup_{x∈D_cov}‖P_imp(x) − K(x)‖ 的置信上界。

**定义 163（定点证据内核 FPEK）** 定点域 Q(m,n)，scale = 2^{−n}，量化算子 q(x) = round(2^n x)，基础量化误差 ε_q0 = 2^{−(n+1)}。
- **误差传播**：对计算图 f，其定点实现满足 ‖f(q(x)) − f(x)‖ ≤ L_f · ε_q，L_f 为 f 的 Lipschitz 常数。
- **定点证书**：m_cert = m_real − L_f · ε_q − δ_demo；FPEK-valid ⇔ m_cert ≥ τ_margin ≥ 0。
- **域一致性**：证书签发域必须等于执行域；浮点证书在定点执行体上视为无效。

**定义 164（演示溯源环 DPR）** S_demo = (R_ring, L_lineage, V_verify)。
- **环形缓冲**：R_ring 容量 C_demo，记录 (demo_id, content_hash, calib_ver, op_id, ts)。
- **血缘**：L_lineage ⊆ demo_id × cell_id，记录哪些演示支撑了哪个策略单元。
- **校验**：V_verify 在回放/重编译时重算 content_hash 并比对 calib_ver；失配则 quarantine。
- **污染传播**：若演示 i 被隔离，则 {j : (i,j) ∈ L_lineage} 中所有单元标记 stale，必须触发局部重编译。

**定义 165（嵌入契约 DEC）** C_embed = (δ_demo, ε_q, B_mcu, ρ_0, τ_replay)。编译产物满足 DEC ⇔
1. `sup_{x∈D_cov} ‖P_imp(x) − K(x)‖ ≤ δ_demo`；
2. `L_f · ε_q ≤ ε_margin`（安全裕度已扣除量化误差）；
3. `resource(P_imp) ≤ B_mcu`（flash/RAM/WCET 三重预算）；
4. `τ_replay ≤ τ_deadline`（回放一致性检验可在实时约束内完成）。
- **发布守卫**：dispatch 时若 `ρ_cov(x) < ρ_0` 或 `Cert_dcc` 无效，则返回 K_conservative（保守阻抗），拒绝引用演示权威。

**定义 166（演示-执行一致性 DECon）** 对 n 次回放，经验一致性风险
R_emp = (1/n)Σ_i 1[‖EV-exec(P_imp, D_i) − EV-exec(D_i)‖ > δ_demo]。
Hoeffding 上界：以概率 ≥ 1−δ，R_true ≤ R_emp + √(ln(1/δ)/(2n))。
判定：`R_ub ≤ R_allow` 才接受该编译版本，否则回退旧版本或保守策略。

**定义 167（演示预算 B_demo 与 PCE+++++）** B_demo = (Storage_bytes, Distill_ops, Replay_budget, Provenance_rate)。
```
voi_demo(π_demo) = λ_cov · ΔCoverage(π_demo) − cost_demo(π_demo)
cost_demo = λ_s·Storage(π_demo) + λ_d·Distill(π_demo) + λ_r·Replay(π_demo) + λ_p·Provenance(π_demo)
```
若 B_demo < θ_demo：禁用演示权威，回退 π_scene^general + K_conservative。

**定义 168（演示抽象泄漏护栏 DALG）** 护栏元组 G = (ρ_0, ε_margin, V_verify, R_allow, fallback)。
- **泄漏判定**：`ρ_cov(x) < ρ_0` ∨ `m_cert < 0` ∨ `provenance mismatch` ∨ `R_ub > R_allow` ⇒ 触发 `DEMO_AUTHORITY_VIOLATION`。
- **处置**：回退 K_conservative，冻结相关 cell，记录违规证据；严禁「以降低 δ_demo 阈值的方式让证书通过」。

### IP-161/162 DD + DCC（演示投影与约束编译）

```python
def compile_demos(demos, B_mcu, eps_q, M_max=64):
    X, K = [], []
    for d in demos:
        for (s, a, tau, Z) in d.traj:
            x, k = project(s, Z, tau)        # 投影：(位姿,环境,力)->阻抗样本
            X.append(x); K.append(k)
    X, K = np.array(X), np.array(K)

    centers, labels = kmeans(X, M_max)       # 分段仿射的单元划分
    cells = []
    for j in range(len(centers)):
        Aj, bj = lstsq(X[labels == j], K[labels == j])   # 局部仿射拟合
        Aj_q, bj_q = quantize(Aj, bj, q_format=(16, 16))
        cells.append(Cell(A=Aj_q, b=bj_q, center=centers[j], domain=(labels == j)))

    rho = kernel_coverage(X, bandwidth=h)    # 覆盖度场（离线网格化，端上查表）
    delta_demo = confidence_upper_bound(X, K, cells)
    cert = Cert_dcc(delta_demo=delta_demo, eps_q=eps_q, rho_0=RHO_0,
                    resource=measure_resources(cells, rho), provenance=digest(demos))
    return ImpedancePolicy(cells=cells, coverage=rho), cert

def dispatch(policy, cert, s, Z):
    x = features(s, Z)
    if cert.valid and policy.coverage(x) >= RHO_0:   # authority ⊆ coverage
        return policy.eval(x)
    return K_conservative                           # 域外一律回退
```

### IP-163 FPEK（定点证据内核）

```python
def fpek_certify(margin_real, L_f, eps_q, delta_demo, tau_margin=0.0):
    m_cert = margin_real - L_f * eps_q - delta_demo
    return Cert(margin=m_cert, valid=(m_cert >= tau_margin),
                domain='fixed_point', eps_q=eps_q, L_f=L_f)

def fpek_verify_evidence(ev, q_format=(16, 16)):
    # 哈希/比较/证书校验全部在定点域完成，避免「浮点验证、定点执行」的域错配
    q_ev = quantize_dict(ev, q_format)
    h = sha256_fixed(q_ev)
    return (h == ev.hash) and (abs(q_ev.value - ev.value) <= eps_q_bound(q_format))
```

### IP-164 DPR（演示溯源环）

```python
class DemoProvenanceRing:
    def __init__(self, cap_bytes=64*1024):
        self.ring = deque()
        self.cap = cap_bytes
        self.lineage = {}          # demo_id -> set(cell_id)

    def add(self, demo):
        rec = Record(demo_id=demo.id, hash=sha256(demo.content),
                     calib_ver=demo.calib_ver, op_id=demo.op_id, ts=demo.ts)
        self.ring.append(rec)
        self.lineage[demo.id] = set(demo.cell_ids)

    def verify_and_quarantine(self):
        stale = set()
        for rec in list(self.ring):
            if sha256(read(rec.demo_id)) != rec.hash or calib_changed(rec.calib_ver):
                stale |= self.lineage.get(rec.demo_id, set())
                self.ring.remove(rec)
        return stale               # 相关 cell 触发局部重编译
```

### IP-165/166 DEC + DECon（契约与一致性回放）

```python
def dec_check(policy, cert, B_mcu, n, delta=1e-3):
    c1 = cert.delta_demo <= DELTA_DEMO
    c2 = cert.L_f * cert.eps_q <= EPS_MARGIN
    c3 = resource_ok(policy, B_mcu)
    R_emp = replay_risk(policy, n)
    R_ub = R_emp + math.sqrt(math.log(1/delta) / (2*n))
    c4 = R_ub <= R_ALLOW
    return c1 and c2 and c3 and c4, dict(c1=c1,c2=c2,c3=c3,c4=c4,R_ub=R_ub)
```

### IP-167 PCE+++++（演示预算）

```python
class DemoBudget:
    def __init__(self, storage=64*1024, distill_ops=1e6, replay=20, prov_rate=1.0):
        self.B = dict(storage=storage, distill=distill_ops,
                      replay=replay, prov=prov_rate)
        self.used = dict(storage=0, distill=0, replay=0, prov=0)
    def can_compile(self, need):
        return all(self.used[k] + need[k] <= self.B[k] for k in self.B)
    def fallback(self):
        return dict(mode='general_prior', K=K_conservative)  # B_demo 耗尽
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| DD 投影/覆盖 | O(M·T) 离线 | O(\|X_D\|) 离线 | 覆盖度 ρ_cov 为核密度的一致估计 |
| DCC | O(M_max·d^3) 离线 | O(M_max·d) | δ_demo ≤ ε_PA（分段仿射逼近界） |
| FPEK | O(1)/证书 | O(1) | m_cert = m_real − L_f ε_q − δ_demo ≥ 0 |
| DPR | O(1) 追加 / O(C_demo) 校验 | O(C_demo)=64KB | 污染演示被隔离，血缘单元置 stale |
| DEC/DECon | O(n) 回放 | O(1) | R_true ≤ R_emp + √(ln(1/δ)/2n) |

**正确性定理（DEED）**：假设 A66–A70 成立——
- **(A66)** 演示投影 φ 有界且覆盖度估计满足 \|ρ̂_cov − ρ_cov\| ≤ ε_ρ；
- **(A67)** 闭环映射 F 对 K 的 Lipschitz 常数为 L_K、收缩系数 ρ_F < 1；
- **(A68)** 分段仿射策略在 M_cells 单元上的逼近误差 ≤ L_P·diam·M_cells^{−1/d}；
- **(A69)** 定点计算图 Lipshitz 常数 L_f 已知，量化基础误差 ε_q0 = 2^{−(n+1)}；
- **(A70)** 回放样本独立同分布，δ_demo 阈值固定。

则：
1. **权威不越界**：∀x，若 dispatch 成功则 ρ_cov(x) ≥ ρ_0，故策略输出属于演示权威域；域外由发布守卫强制回退，DALG 不发生。
2. **定点安全**：稳态轨迹偏差 ≤ L_K·L_f·ε_q/(1−ρ_F)；当 `m_real ≥ L_K·L_f·ε_q/(1−ρ_F) + δ_demo` 时 m_cert ≥ 0，安全裕度在定点域内成立。
3. **一致性可泛化**：以概率 ≥ 1−δ，真实回放风险被 Hoeffding 上界控制，CERT 只在 R_ub ≤ R_allow 时签发。
4. **污染可隔离**：任何被篡改/失配的演示经 V_verify 检出并使依赖单元 stale，阻断「污染演示→带证错误策略」的传播。

## 5. 本轮最大风险

**一句话**：若演示数据稀疏且分布偏移（只演示了光滑桌面、从未演示湿滑地面），DCC 会把「演示覆盖范围内正确」误编译成「全局证书」，定点量化再吃掉最后一点安全裕度，最终造成「证据层证书完备、执行层在未覆盖场景灾难性失效」的抽象泄漏；必须以「覆盖度门槛 ρ_0 + 域外保守回退 + 定点误差显式扣除 + 演示溯源与回放一致性」四重护栏，确保「演示的权威」永不超出「演示的覆盖」。

### IP-161/162 DD + DCC（演示投影与约束编译）

```python
def compile_demos(demos, B_mcu, eps_q, M_max=64):
    X, K = [], []
    for d in demos:
        for (s, a, tau, Z) in d.traj:
            x, k = project(s, Z, tau)
            X.append(x); K.append(k)
    X, K = np.array(X), np.array(K)

    centers, labels = kmeans(X, M_max)
    cells = []
    for j in range(len(centers)):
        Aj, bj = lstsq(X[labels == j], K[labels == j])
        Aj_q, bj_q = quantize(Aj, bj, q_format=(16, 16))   # 端上可表示的定点系数
        cells.append(Cell(A=Aj_q, b=bj_q, center=centers[j], domain=(labels == j)))

    rho = kernel_coverage(X, bandwidth=h)
    delta_demo = confidence_upper_bound(X, K, cells)
    cert = Cert_dcc(delta_demo=delta_demo, eps_q=eps_q, rho_0=RHO_0,
                    resource=measure_resources(cells, rho), provenance=digest(demos))
    return ImpedancePolicy(cells=cells, coverage=rho), cert

def dispatch(policy, cert, s, Z):
    x = features(s, Z)
    if cert.valid and policy.coverage(x) >= RHO_0:
        return policy.eval(x)
    return K_conservative
```

### IP-163 FPEK（定点证据内核）

def fpek_certify(margin_real, L_f, eps_q, delta_demo, tau_margin=0.0):
    m_cert = margin_real - L_f * eps_q - delta_demo
    return Cert(margin=m_cert, valid=(m_cert >= tau_margin),
                domain='fixed_point', eps_q=eps_q, L_f=L_f)

def fpek_verify_evidence(ev, q_format=(16, 16)):
    q_ev = quantize_dict(ev, q_format)
    return (sha256_fixed(q_ev) == ev.hash) and \
           (abs(q_ev.value - ev.value) <= eps_q_bound(q_format))

### IP-164 DPR（演示溯源环）

```python
class DemoProvenanceRing:
    def __init__(self, cap_bytes=64*1024):
        self.ring = deque(); self.cap = cap_bytes; self.lineage = {}
    def add(self, demo):
        self.ring.append(Record(demo.id, sha256(demo.content),
                                demo.calib_ver, demo.op_id, demo.ts))
        self.lineage[demo.id] = set(demo.cell_ids)
    def verify_and_quarantine(self):
        stale = set()
        for rec in list(self.ring):
            if sha256(read(rec.demo_id)) != rec.hash or calib_changed(rec.calib_ver):
                stale |= self.lineage.get(rec.demo_id, set())
                self.ring.remove(rec)
        return stale          # 相关 cell 置 stale，触发局部重编译
```

### IP-165/166 DEC + DECon（契约与一致性回放）

```python
def dec_check(policy, cert, B_mcu, n, delta=1e-3):
    c1 = cert.delta_demo <= DELTA_DEMO
    c2 = cert.L_f * cert.eps_q <= EPS_MARGIN
    c3 = resource_ok(policy, B_mcu)
    R_emp = replay_risk(policy, n)
    R_ub = R_emp + math.sqrt(math.log(1/delta) / (2*n))
    c4 = R_ub <= R_ALLOW
    return c1 and c2 and c3 and c4, dict(c1=c1,c2=c2,c3=c3,c4=c4,R_ub=R_ub)
```

### IP-167/168 PCE+++++ + DALG（预算与护栏）

```python
class DemoBudget:
    def __init__(self, storage=64*1024, distill_ops=1e6, replay=20, prov_rate=1.0):
        self.B = dict(storage=storage, distill=distill_ops, replay=replay, prov=prov_rate)
        self.used = dict(storage=0, distill=0, replay=0, prov=0)
    def can_compile(self, need):
        return all(self.used[k] + need[k] <= self.B[k] for k in self.B)
    def fallback(self):
        return dict(mode='general_prior', K=K_conservative)

def dalg_guard(x, rho, cert, provenance_ok, R_ub):
    if rho < RHO_0 or not cert.valid or not provenance_ok or R_ub > R_ALLOW:
        raise DemoAuthorityViolation(x)   # 强制 K_conservative + 冻结 cell
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性 |
|---|---|---|---|
| DD / 覆盖 | O(M·T) 离线 | O(\|X_D\|) 离线 | 核密度估计一致收敛 |
| DCC | O(M_max·d^3) 离线 | O(M_max·d) | δ_demo ≤ L_P·diam·M_cells^{−1/d} |
| FPEK | O(1) / 证书 | O(1) | m_cert ≥ 0 ⇔ 定点安全 |
| DPR | O(1) 追加 / O(C_demo) 校验 | O(64KB) | 污染演示隔离、血缘 stale 无漏标 |
| DEC/DECon | O(n) 回放 | O(1) | R_true ≤ R_emp + √(ln(1/δ)/2n) |

### 推导 1（定点安全裕度）

设闭环 `x_{t+1} = F(x_t, K)`，F 对 K 的 Lipschitz 常数为 L_K、对状态的收缩系数为 ρ_F < 1。当 K 被量化为 K̂、‖K̂ − K‖ ≤ ε_q 时，稳态轨迹偏差满足
```
‖x̂_∞ − x_∞‖ ≤ L_K·ε_q / (1 − ρ_F) + O(ε_q²)
```
若计算图另有 Lipschitz 常数 L_f，则端到端量化误差约 `L_K·L_f·ε_q/(1−ρ_F)`。因此证书条件为
```
m_real ≥ L_K·L_f·ε_q/(1−ρ_F) + δ_demo + τ_margin
```
这正是 DEC 条件 (2) 的严格来源：**量化误差不是被忽略，而是被显式从安全裕度里扣除**。

### 推导 2（分段仿射逼近与资源权衡）

对 Lipschitz 常数为 L_P 的策略，在 d 维紧域上用 M 个直径 ≤ h 的单元做分段仿射拟合，逼近误差 ≤ L_P·h。由 M ≈ (diam/h)^d 得 `h ≈ diam·M^{−1/d}`，故
```
δ_demo(M) ≤ L_P · diam · M^{−1/d}
```
即 δ_demo 与单元数 M 呈 `M^{−1/d}` 权衡；d=3、M=64 时误差上限约为 M^{−1/3}≈0.25 倍常数因子。这直接驱动 B_demo 中「精度 vs 存储」的 VOI 决策：一味增加 M 的边际收益递减，而 flash 线性增长。

### 推导 3（回放一致性泛化）

n 次独立回放的经验风险 R_emp 与真实风险 R_true 满足 Hoeffding 不等式，以概率 ≥ 1−δ：
```
R_true ≤ R_emp + √(ln(1/δ)/(2n))
```
故 DECon 只在 `R_ub ≤ R_allow` 时接受编译版本；这把「端侧有限次回放」升级为对演示分布的**有限样本保证**。

### 正确性定理（DEED）

若 A66–A70 成立且 DEC 四条件满足，则：（1）任意被 dispatch 的输出满足 authority ⊆ coverage，DALG 不触发；（2）定点域安全裕度 m_cert ≥ 0；（3）真实回放风险被 R_ub 控制；（4）被污染演示经 DPR 隔离并使依赖单元 stale，阻断带证错误策略传播。证明由「域划分 + 误差分解 + Hoeffding + 血缘闭包」四步直接得到。

## 5. 本轮最大风险

**一句话**：若演示稀疏且分布偏移（只演示光滑桌面、从未演示湿滑地面），DCC 会把「覆盖范围内正确」误编译成「全局证书」，定点量化再吃掉最后一点安全裕度，导致「证书完备、执行灾难」的抽象泄漏被放大；必须用「覆盖度门槛 ρ_0、域外保守回退、定点误差显式扣除、演示溯源与回放一致性」四重护栏，保证「演示的权威」永不超出「演示的覆盖」。
