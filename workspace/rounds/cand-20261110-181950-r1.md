# 第 44 轮（新循环第 4 轮） · Coordination-Cert × Motion-Cert：把「多机协同」与「运动规划」纳入可验证证书闭环（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 自陈最大风险是「共形条件覆盖 + 多用户契约空集」，但它还压着两个未言明的假设：**(H1) 证书的单位是单机**——多机要么被当成「多个互不相关的单机」，要么被降格成一台标称机器人环境里的动态障碍，没有组合语义，更没有「一荣俱荣、一损俱损」的联合失效；**(H2) 证书的时域是瞬时**——运动规划被当作「找一条路」，证书只在采样点/关键帧成立，既不覆盖采样间隙，也不约束同一时刻谁在哪、谁让谁。本轮灵感词「多机协同」「运动规划」精确命中这两个假设：**多机协同**要求证书从单机谓词升级为**可组合的联合证书**（assume-guarantee + 组合失配检测 + 无死锁/活锁）；**运动规划**要求证书从瞬时 margin 升级为**路径级时空管道**（管道覆盖 + 同伦/编织类 + 交叉事件）。二者耦合处是本轮真正的新问题：**独立 sound 的单机证书不保证联合 sound（组合失配），路径级安全也不保证系统「活」（安全地冻死）**。

## 0. 直觉与动机

**灵感 1（多机协同 → 「证书不是复制品」，组合要显式付费）**：直觉上，两台都能证明「我会安全通过这扇门」并不等于「我们能一起安全通过」——如果各自的证明都默认「门此刻是空的」，联合执行就会在门内冲突。这是经典的 **composition gap**：单机证书的 soundness 是**有条件**的（条件是对其他机行为的假设），把条件藏起来做 N 份复制，就会得到一个「表面可信、联合失效」的系统。因此把多机协同定义为**带假设的联合证书**：每台机器人声明自己的保证 G_i（管道、速度界）和对别人的假设 A_i；只有当「所有人对别人的假设都被别人的保证蕴含」时，单机证书才真正可组合。依赖图无环时按拓扑序归纳即可；有环时必须要求**良基收紧**或**时间分离**，否则拒绝组合、请求集中仲裁。一句话：**组合不是把证书加起来，而是把假设抵掉**。

**灵感 2（运动规划 → 证书是「一整条轨迹」，不是「几个关键帧」）**：直觉上，点证书就像只在整点打卡：`t=0`、`t=1` 都安全，不代表 `t=0.5` 安全。所以要把运动证书做成**时空管道** U_i(t)=B(τ_i(t), ē_i(t))：只要控制器（CBF/不变集）保证真实状态始终落在管道里，而管道整体满足碰撞/动力学/任务谓词，那么**整段连续轨迹**都 sound，采样间隙不再是被漏掉的黑洞。再往上，用**同伦类/编织词**编码全局路由：只要局部重规划不产生「次序交换」（交叉事件），它就还在同一类里、仍然无碰撞；于是全局重证的代价被推迟到交叉事件，类内并行局部规划才真正可证。一句话：**证书要跟着轨迹走，而不是跟着时间戳走**。

**灵感 3（耦合 → 「安全不等于活」，死锁要给证书）**：多机最阴险的失效不是相撞，而是**所有机都安全地卡住**——每台都在等别人先走，联合轨迹永远停在安全集里。v20 完全没有这个概念：它的 soundness 只谈「不违例」，从不谈「能不能到」。因此引入独立的**无死锁/活锁证书**：资源序图 H 无环、等待图 W ⊆ H 即无死锁；存在良基进展函数 V，每轮要么 V 严格下降（有机器人推进），要么有限步内重协商，即无活锁。安全与活成为**两张必须同时持有的证书**，缺一不可。

**灵感 4（耦合的工程底座 → 通信有界才能组合**）**：多机组合一定依赖通信，A_i 依赖的是 j 的 G_j，而 G_j 是**传过来**的。所以必须把 v20 的证书租约升级为分布式版本：局部时钟有偏斜 δ、消息有时延 d_max、还会丢包；新鲜度判据必须用**最坏膨胀** age = t_i − τ_j + δ + d_max。断链时不允许沿用最后的假设，只能把假设**单调最坏化**（j 以 v_max 任意机动）。这样断网带来的只会是可用性下降（减速/让行/停机），而不是 soundness 被悄悄破坏。

**耦合升级**：CCC（联合证书合成器）负责 A/G 组合、组合失配检测、冲突搜索与降级阶梯；MCP（运动证书规划器）负责时空管道、同伦/编织路由、死锁免疫优先级与编队重构；CCV（协同证书验证器）在产品空间做对称约简反例搜索、A/G 循环对抗、死锁/活锁 fuzz 与通信故障注入。四层架构由 v8 的「个性化并发闭环」升级为 v9 的「个性化并发 + 多机组合 + 路径级运动」闭环。

## 1. 形式化定义（增量：定义 44–49）

**定义 44（联合证书与组合失配）**：设 n 台机器人，单机证书 C_i=(τ_i, U_i, P_i, θ_i)（轨迹、管道、谓词、阈值）。**孤立有效**指把其他机器人固定为其规划时标称轨迹时 C_i 成立。联合状态 X=(x_1,…,x_n)，联合证书 C_J 需同时满足：(a) 各机动力学/任务谓词 P_i；(b) 成对安全谓词 P_ij: dist(U_i(t),U_j(t)) ≥ d_safe(t)，∀t、∀i<j。**组合失配命题**：即使每个 C_i 孤立 sound，C_J 也未必 sound。反例（双向门）：两机都假设门可通行，各自路径合法，联合轨迹在门内相撞。定义**组合缺口** Γ = |Viol(C_J)| / |Viol(∨_i C_i)| 来量化「单机证书表面可信、联合失效」的程度；Γ 越大，越不能靠复制单机证书做多机。

**定义 45（Assume-Guarantee 协同契约与循环依赖）**：每机 i 声明保证 G_i（「我的管道 U_i(t) 在 [t0,t1] 内保持，速度 ≤ v_i^max」）与环境假设 A_i（「∀j≠i，U_j(t) 与 U_i(t) 距离 ≥ d_safe，且 j 的加速度 ≤ a_j^max」）。**组合规则**：若 ∀i，(⋀_{j≠i} G_j) ⟹ A_i 且 {P_i ∧ A_i} τ_i {P_i}，则 C_J sound。依赖图 D：边 i→j 表示 A_i 依赖 G_j。**定理（非循环组合）**：若 D 无环，按拓扑序归纳即得组合 sound。**循环条件**：若 D 有环，必须满足下列之一才接受——(i) **良基收紧**：存在秩 r，环上每轮假设严格收紧且无无穷下降链；(ii) **时间分离**：假设只依赖已冻结的过去时段 G_j（staggered），不使用同轮他机的未完成保证；否则拒绝组合并请求集中仲裁。

**定义 46（时空管道 / 运动证书）**：轨迹 τ_i:[0,T]→X_i，跟踪误差界 ‖x_i(t)−τ_i(t)‖ ≤ ē_i(t)，时空管道 U_i(t)=B(τ_i(t), ē_i(t))。运动证书 M_i=(τ_i, U_i, φ_i, ρ_min) 要求 ∀t∈[0,T]：(a) 管道内每点满足动力学界（v、a）；(b) 任务/安全谓词在管道内成立；(c) STL 鲁棒度 ρ_{φ_i}(τ_i) ≥ ρ_min > 0。**路级 sound 命题**：若控制器以 CBF/不变集保证真实状态始终在 U_i(t) 内，且 U_i(t) 满足 (a)(b)，则整段连续轨迹满足谓词；仅用采样点证书时「采样间隙」中的违例正是被漏掉的部分。**注**：这是对定义 41 租约的时间维推广——租约管「测量→使用」的新鲜度，管道管「规划→执行」的空间覆盖，二者共同构成「时间×空间」双新鲜度。

**定义 47（同伦类与编织证书）**：二维工作空间中 N 个圆盘机器人 + 静态障碍，联合配置空间减去碰撞集后按路径同伦分类，以成对次序交换序列编码**编织词** h ∈ B_N（braid group）。运动证书携带类标签 h。**类不变命题**：若联合轨迹 τ_J 属于类 h，且类内代表路径无碰撞，则任何连续局部重规划只要不产生**交叉事件**（某对机器人次序交换）就仍在 h 内、仍无碰撞；因此监控降维为「检测交叉事件 + 段内有效性」，交叉发生即证书失效、必须全局重证。**推论**：同伦标签把「全局联合重规划」延迟到交叉事件，使分布式局部规划在两次交叉之间可安全并行。

**定义 48（无死锁/活锁证书）**：协同协议状态含每机等待关系。**无死锁证书** = 全局优先级图 H（资源/走廊/门占用序）无环 ∧ 等待图 W 是 H 的子图（等待只沿高优先级→低优先级）⟹ W 无环 ⟹ 无死锁。**无活锁证书** = 存在良基进展函数 V(X)（如「已完成任务数 + 剩余走廊长度」的字典序），协议保证每个协调轮要么某机推进一个 segment（V 严格下降），要么触发重协商（V 不变但有限步内改变优先级）。**活性定理**：V 良基 + 每轮推进或有限步重协商 ⟹ 每台机器人最终到达目标或显式进入协商/停机，不存在「永远安全地卡住」。

**定义 49（分布式租约与时钟偏斜下的新鲜度）**：局部单调时钟 i 的时间戳 τ_i，真实偏斜 |τ_i−τ_j| ≤ δ，消息时延 ≤ d_max，丢包率 ≤ p_loss。j 的结论到达 i 的**有效年龄** age = t_i − τ_j + δ + d_max。**新鲜度判据**：m − λ·age ≥ θ 才可用于协同守卫。**定理**：在偏斜/时延有界下，用最坏膨胀 δ+d_max 的判据 sound（绝不误用陈旧假设）。**丢包回退**：若租约在 T_expire 内未续，i 必须把 j 的假设替换为**最坏假设**（j 以 v_max 任意机动），且假设只许单调收紧——即把「假设租约」与「证书租约」分离。**命题**：假设单调收紧不破坏 sound（只会更保守），故通信中断只造成可用性下降（减速/让行/安全停机），不会破坏 soundness。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 COORDINATION-CERT-COMPOSER（联合证书合成器 CCC）
1. **组合失配检测**：无 A/G 时先做联合快速检查，输出组合缺口 Γ 与冲突对集合；Γ 超阈值即拒绝对单机证书做「复制式」协同。
2. **A/G 契约合成**：构建依赖图 D，检查无环性；有环时尝试良基收紧或时间分离，失败则请求集中仲裁。
3. **冲突搜索（CBS-style）**：冲突 = 管道重叠或次序矛盾；沿冲突分支添加优先级/绕行/时间偏移，取最小代价的可行联合证书。
4. **降级阶梯**：联合不可行 → 优先级串行化 → 编队/等待区 → 安全停机；每一级都必须产出可审计的证书，绝不静默放宽。

### 2.2 IP-61 MOTION-CERT-PLANNER（运动证书规划器 MCP）
1. **时空管道证书**：轨迹 + 跟踪误差管 + STL 鲁棒度，路径级 sound；执行段长度自适应（误差变大即缩短段）。
2. **同伦/编织路由**：全局先选类（braid word），类内做局部优化；运行时只监控交叉事件，类内重规划免全局重证。
3. **死锁免疫优先级**：资源序图 H 无环 + 等待图 W ⊆ H；每步检查包含关系，违规即重排。
4. **可重构编队**：编队/重组视为**类切换**，切换窗口内减速/让行并单独出证书，切换本身也要过 E98。
5. **与既有层集成**：复用 IP-49 几何证书、IP-39 规划、CBF 约束与 IP-43 韵律调度。

### 2.3 IP-62 COORDINATION-CERT-VALIDATOR（协同证书验证器 CCV）
1. **联合反例搜索**：产品空间采样 + **对称性约简**（同构机器人只枚举相对位形），回灌失败轨迹。
2. **A/G 循环对抗**：构造环形假设依赖的对抗调度，专打「时序侥幸」满足的循环。
3. **死锁/活锁 fuzz**：窄走廊、双向门、同步起步、交叉流，测出「安全但冻结」。
4. **通信故障注入**：时钟偏斜、时延抖动、丢包、分区，验证「假设最坏化」是否真的兜底。
5. **多机 Isaac Sim 压力**：N=2..20，交叉/编队/重配置/重规划，测安全—可用性—完成时间三角。

## 5. 本轮最大风险

### IP-60 CCC：A/G 组合、冲突搜索与降级
```
def compose_joint_certificate(certs, ag, bounds):
    # 0) 组合失配快速探测：先假设无协同，看联合是否已违例
    if quick_joint_violation(certs):
        Gamma = composition_gap(certs)          # 定义 44
        if Gamma > GAMMA_MAX: return Reject("copy-composition")
    # 1) 构建 A/G 依赖图
    D = build_dependency_graph(ag)              # i->j : A_i 依赖 G_j
    if has_cycle(D):
        if not (well_founded_refinement(D) or staged_time_separation(D)):
            return RequestCentralArbitration(D) # 定义 45
    # 2) 冲突搜索（CBS-style）：冲突=管道重叠/次序矛盾
    conflicts = find_pairwise_conflicts(certs)  # dist(U_i(t),U_j(t)) < d_safe
    if not conflicts:
        return JointCert(certs, proof=AG_induction(D))
    best = None
    for c in conflicts:
        for op in [add_priority(c), add_detour(c), add_time_shift(c)]:
            child = refine(certs, op)
            cand = compose_joint_certificate(child.certs, child.ag, bounds)
            best = argmin_cost(best, cand)
    return best if best else degrade_ladder(certs)

def degrade_ladder(certs):
    # 每一级都产出可审计证书，绝不静默放宽
    for level in [PRIORITIZED_SERIAL, FORMATION_WAIT, SAFE_STOP]:
        if feasible(level, certs): return level
    return SAFE_STOP
```
