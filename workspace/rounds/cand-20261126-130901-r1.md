研究循环·第 3 轮；本轮灵感：「视觉编码器」×「碰撞避免」

> **基线**：第 3 轮产出 MetricVoiceGauge-NCD-HUTDH-v23+IP-431–439（其上承 v22 的 HDL/ACSC/DCSC/HPC-E/CFC++，v21 的 SDC/CAC/DCL/GIC，v20 的 PCA/CTS/CFC/HPC/CFCtrl，v19 的 DCM/OGCC/CCV/DRS/OGC，v17 的 CLP/S2C/HCG/PSV/APS/AMC）。
> 本轮纪律：**隐空间距离不是物理距离；度量可信 ≠ 语义完备；连续时间安全不能靠离散帧运气**。不推倒 v23：CESC/FSVC/IPAM/HPC-E+/CFC+++ 与 v22/v21/v20/v19/v17 各模块全部保留。本轮只做一件事：**在 v23 之上加一层“感知几何的可证度量层”，把视觉编码器的隐空间从“特征”升级为“带双向 Lipschitz 证书的物理坐标代理”，把碰撞避免从“离散快照几何检查”升级为“经度量证书放缩的、扫掠保守推进的隐空间控制屏障”，并用“度量—语义交叉信任门”把二者的失效面显式求交**。

## 0. 直觉与动机

**灵感 1（视觉编码器 → 隐空间是“度量代理”而不是“语义标签”，而度量代理必须先证伪再信任）**
直觉：视觉编码器把图像压进一个带距离的隐空间。碰撞避免真正需要的不是“这是什么”，而是“离障碍还有多远”，于是“直接在 φ 空间做最近邻碰撞检查”极其诱人：便宜、可微、可端到端。但这是个陷阱，原因是一条**单向 Lipschitz 鸿沟**：编码器通常只被训练/约束成 Lipschitz（`d_Z ≤ L·d_S`，图像小扰动→特征小扰动），却没有膨胀下界（`d_Z ≥ ℓ·d_S`）。上界只说“不会突变”，不说“不会塌缩”——两个物理上相距很远的构型可以被压到隐空间同一点（特征塌缩/各向异性/hubness），而渲染 `g` 又是多对一的（遮挡、透明、镜面、逆光、低纹理），于是存在**感知混叠**：不同的物理世界映到同一张图、同一个 φ。核心创新：**度量失真证书 (Metric Distortion Certificate, MDC) + 感知歧义证书 (Perceptual Ambiguity Certificate, PAC)**。MDC 显式标定并认证局部双 Lipschitz 常数 `(L_φ, ℓ_φ)`；PAC 显式刻画歧义集 `A(φ)=ψ^{-1}(φ)` 并对它取最坏情形。关键反直觉点：**对安全方向，Lipschitz 上界（压缩）是朋友而非敌人——压缩越强，`c(x) ≥ h_φ(x)/L` 的物理净空下界越保守；真正危险的是“度量上最可信、语义上却没看见”的交叉区，而不是“度量上不可信”的区域**（后者会保守退回 v20 点云 Hull）。

**灵感 2（碰撞避免 → 从“离散帧几何”到“连续时间前向不变”，但 CBF 不必穿透编码器求导）**
直觉：经典碰撞避免活在构型空间，两条铁律——**连续时间不能漏检**（20ms 的两帧之间足以穿过一根细杆），以及**前向不变**（控制屏障函数 CBF：`h≥0` 的安全集在控制下不越界）。v23 的 HPC 是逐快照几何，DCSC 是 10Hz 语义，二者之间正是碰撞避免最危险的“时间缝隙”。核心创新：**隐空间控制屏障证书 (Latent Control Barrier Certificate, LCBC) + 扫掠隐走廊证书 (Swept Latent Corridor Certificate, SLCC)**：安全屏障取 `h_safe(x)=h_φ(ψ(x))/L_φ − r_robot − margin`；但**不对编码器求导/反传**，而是用运动学界 `(v_max, a_max)` 与 APS 最坏新鲜度 `Δt` 做保守推进，把 Δt 内的扫掠体积折算成隐空间裕度的确定性膨胀 `L_φ·(v_max Δt + ½ a_max Δt²)`。关键反直觉点：**不需要编码器可微就能拿到连续时间安全——只需要它的 Lipschitz 上界加运动学界；这把一个高维感知问题降维成一个标量裕度膨胀问题**，从而能塞进 50Hz 控制环。

**灵感 3（二者如何统一，并回接 v21 的缺席证书）**
直觉：语义与度量是两张**必须同时成立**的证书，且失效面不同。语义证书（DCSC/SDC）保证 `O_latent ⊇ ψ(O_true)`（不漏障碍，是召回问题）；度量证书（MDC/PAC）保证“给定 `O_latent` 时物理净空可下界”（是几何问题）。只满足其一都不够：召回满分但度量塌缩会“看见了却算错距离”；度量完美但语义盲会“距离算得准却看不见东西”。核心创新：**度量—语义交叉信任门 (Distortion-Trust Gate, DTG)**——只在“度量可信区 `ℓ_φ ≥ ℓ_min`”与“语义高召回区”的**交集**内签发隐空间安全；交集之外一律保守退回 v20 Hull。副产品直接补强 v21 的 CAC：缺席证书（“覆盖区内无人”）只在编码器局部单射（`ℓ_g ≥ ℓ_min`）且召回达标处签发，混叠区（玻璃、镜面、逆光、低纹理）自动作废并翻转为“可能有人”。共享状态扩展为 `ζ_metric = ζ_ce ∪ (L_φ, ℓ_φ, A(φ), h_φ, metric_root)`。

**三者如何统一**
统一为 **v23 之上的“可证度量层”**：MDC 回答“隐空间距离在多大系数内忠实于物理距离”，PAC 回答“同一个隐空间点可能对应哪些物理世界、最坏有多近”，LCBC/SLCC 回答“在这些系数与运动学界下，未来 Δt 内是否仍前向不变”。统一准入门 **HPC-E++ = HPC-E+ ∧ MDC ∧ PAC ∧ LCBC（且 DTG 通过）**：只有“物理/规范/能量（v23）∧ 度量可信（MDC）∧ 歧义有界（PAC）∧ 连续时间安全（LCBC/SLCC）∧ 版本一致（CESC）”才进入执行；任一缺失退回 v23，再退 v22/v21/v20。安全继承方向由一条**单向不等式**保证：新增的每张证书只会把可达集与净空判据变严，绝不放松既有约束。

## 2. 设计原则（在 P41–P42 基础上新增 P43–P45）

**P43 度量双向证书律（Metric Two-Sided Certificate）**
对安全流形 `M_safe` 上每点 `x` 签发局部常数 `(L_φ(x), ℓ_φ(x))`，满足 `ℓ_φ(x)·d_S(a,b) ≤ d_Z(ψ(a),ψ(b)) ≤ L_φ(x)·d_S(a,b)`（`a,b` 在 `x` 的局部邻域内）。**安全判定只用下界**：`c(x) ≥ h_φ(ψ(x))/L_φ(x)`；**碰撞判定只用上界**：`c(x) ≤ h_φ/ℓ_φ`；两者任一不可证（`L_φ=∞` 或 `ℓ_φ=0`）时该点证书作废。`(L_φ, ℓ_φ, encoder_v)` 作为原子项纳入 CESC 版本五元组一起分发与回滚。

**P44 歧义最坏情形律（Ambiguity Worst-Case）**
任何隐空间证书必须对歧义集取最坏：`c_cert(x) = inf_{s∈Â(φ)} c(s)`，且 `Â ⊇ A(φ)`。只在 `Â` 可被有界外近似且 `ℓ_g ≥ ℓ_min`（渲染局部单射）处签发；否则退回点云 Hull。**缺席证书继承此律**：混叠区（透明/镜面/逆光/低纹理/遮挡边界）不得签发“无人”，必须翻转为“可能有人”。

**P45 扫掠保守推进律（Swept Conservative Advancement）**
连续时间安全由确定性膨胀保证：`h_φ(ψ(x_k)) ≥ L_φ·(r_robot + margin + v_max·Δt + ½·a_max·Δt² + d_latency)`，其中 `Δt` 取 APS 最坏新鲜度。膨胀随延迟**单调不降**，不因帧率提升而放松；离散 CBF 条件 `h_{k+1} ≥ (1−γ)h_k` 与该膨胀**联合**成立才准入。执行器延迟与编码器推理延迟以“等效附加位移”并入 `d_latency`，不得重复计数。

## 3. 与基线的接口（如何退化）

- MDC 失效（常数不可证/版本不符/谱界发散）⇒ 隐空间证书全部作废 ⇒ 退回 v20 点云 Hull ⇒ 等价或更保守；
- PAC 失效（歧义集不可界定 / `ℓ_g < ℓ_min`）⇒ 该区假设 `Â` 含障碍 ⇒ 保守；缺席证书拒发；
- LCBC/SLCC 失效（运动学界缺失/延迟未知）⇒ 退回 v23 的逐快照 HPC-E+（无连续时间承诺）；
- 编码器版本不一致 ⇒ CESC 拒绝原子切换，保留旧 `(L_φ, ℓ_φ)` 与旧模型 ⇒ 子集；
- DTG 交集为空（度量可信区与语义召回区不相交）⇒ 全域退回 v20 Hull + 主动感知 ⇒ 子集；
- 全部失效 ⇒ 完全回退 v23 ⇒ `Exec_v24 ⊆ Exec_v23 ⊆ Exec_v22 ⊆ … ⊆ Exec_v18`。
- **安全继承**：MDC 只收紧净空判据、PAC 只扩大障碍/缩小缺席、LCBC 只增加扫掠膨胀、DTG 只做交集；任意失效都向更保守方向退化，故新增层不可能放大可达集。

## 4. 预期贡献

1. **度量代理证书**：首次把视觉编码器的隐空间从“特征”提升为“带双向 Lipschitz 证书的物理度量代理”，给出可证、保守的物理净空下界 `c ≥ h_φ/L_φ`，并明确“压缩对安全是朋友”的单调方向；

## 5. 本轮最大风险

**一句话**：MDC 与 DCSC 的失效在“度量最可信、语义最自信”的交叉区可能**正相关**（透明、反光、低纹理、逆光目标恰使编码器局部近似等距，`ℓ_φ` 高而召回低），于是系统会在数学上最放心的位置签发“隐空间安全”，而那里恰恰是语义召回最脆弱的盲区——**“自信的盲点”**。

## 1. 关键算法骨架（在 IP-436–439 骨架上扩展）

```python
# ============================================================
# IP-440 Metric Distortion Certificate (MDC)
# ============================================================
@dataclass
class MetricCertificate:
    L: float          # 组合局部 Lipschitz 上界（latent / meter）
    ell: float        # 组合膨胀下界（latent / meter）；0 表示不可证
    delta_m: float    # 证书失败概率
    region_id: int
    encoder_v: int
    def valid(self, ell_min: float) -> bool:
        return self.ell >= ell_min and math.isfinite(self.L) and self.L > 0

def spectral_lipschitz(encoder) -> float:
    """谱归一化网络的全局 Lipschitz 上界 L̄ = ∏ ‖W_i‖₂（严格上界）。"""
    L = 1.0
    for m in encoder.modules():
        if hasattr(m, "weight") and m.weight.ndim == 2:
            L *= torch.linalg.matrix_norm(m.weight, ord=2).item()
    return L

def residual_expansion(encoder, x, rho: float) -> float:
    """残差构造 φ = P + r，r 为 ρ-Lipschitz ⇒ ℓ ≥ 1−ρ（严格下界）。
    仅当网络被约束为残差形式时可用；否则回落到经验 conformal 模式。"""
    return max(1.0 - rho, 0.0)

def empirical_expansion(encoder, x, n_probe=64, rad=1e-2, delta=1e-3) -> float:
    """经验膨胀下界：在 x 的 rad 球内采样，取 Jacobian 最小奇异值的下分位，
    再减去有限样本松弛。仅在校准分布覆盖内有效（conformal 口径）。"""
    sig = []
    for _ in range(n_probe):
        xp = x + rad * torch.randn_like(x)
        J = torch.autograd.functional.jacobian(lambda z: encoder(z), xp)
        sig.append(torch.linalg.svdvals(J).min().item())
    ell_emp = float(np.quantile(sig, 0.05))
    return max(ell_emp - math.sqrt(math.log(1 / delta) / (2 * n_probe)), 0.0)

def render_modulus(depth, tex, specular_mask, occlusion_mask, tau_tex=0.1):
    """渲染模数：L_g 由相机投影 Jacobian 上界给出；
    ℓ_g=0 当且仅当出现混叠（遮挡边界/镜面/低纹理/深度断裂）。"""
    if specular_mask.any() or (tex < tau_tex).any() or occlusion_mask.any():
        return math.inf, 0.0                 # 混叠区：不可证，PAC 作废
    J_proj = projection_jacobian_bound(depth)  # 相机几何 Lipschitz 上界
    L_g = J_proj * (1.0 + photometric_gain_bound(tex))
    ell_g = J_proj * max(tex.min().item(), tau_tex)   # 有纹理才有可逆性
    return L_g, ell_g

class MetricDistortionCertificate:
    def __init__(self, encoder, alpha_m=1e-3, ell_min=0.05):
        self.encoder, self.alpha_m, self.ell_min = encoder, alpha_m, ell_min
        self.L_bar = spectral_lipschitz(encoder)   # 全局上界，缓存
    def certify(self, img, depth, tex, spec_mask, occ_mask, region_id, encoder_v):
        L_g, ell_g = render_modulus(depth, tex, spec_mask, occ_mask)
        L_phi = self.L_bar
        if is_residual(self.encoder):
            ell_phi = residual_expansion(self.encoder, img, rho=0.2)
        else:
            ell_phi = empirical_expansion(self.encoder, img)
        return MetricCertificate(
            L=L_phi * L_g, ell=ell_phi * ell_g,
            delta_m=self.alpha_m, region_id=region_id, encoder_v=encoder_v)

# ============================================================
# IP-441 Perceptual Ambiguity Certificate (PAC)
# ============================================================
@dataclass
class AmbiguityCertificate:
    A_hat: "BoxSet"        # 外近似：⋃ 盒/椭球，Â ⊇ A(φ)
    diam: float
    ell_g: float
    injective: bool        # ℓ_g ≥ ℓ_min 且 diam 有界

class PerceptualAmbiguityCertificate:
    def __init__(self, ell_min=0.05, diam_max=0.5):
        self.ell_min, self.diam_max = ell_min, diam_max
    def build(self, phi, depth, multi_view, occ_mask, tex, spec_mask) -> AmbiguityCertificate:
        # 多视角三角化 + 深度不确定性 → 物理状态盒；再按遮挡/纹理/镜面扩张
        boxes = triangulate_preimage(phi, depth, multi_view)   # 外近似
        boxes = inflate_by_occlusion(boxes, occ_mask)
        diam = max_box_diameter(boxes)
        _, ell_g = render_modulus(depth, tex, spec_mask, occ_mask)
        injective = (ell_g >= self.ell_min) and (diam <= self.diam_max)
        return AmbiguityCertificate(boxes, diam, ell_g, injective)
    def worst_clearance(self, A: AmbiguityCertificate, clearance_fn) -> float:
        # 不枚举 Â：用盒的区间下界 + clearance 的 Lipschitz 常数求最坏下界
        return clearance_fn.interval_lower_bound(A.A_hat)

# ============================================================
# IP-442 Latent Control Barrier Certificate (LCBC)
# ============================================================
class LatentControlBarrier:
    def __init__(self, margin=0.05, gamma=0.1, ell_min=0.05, d_latency=0.03):
        self.margin, self.gamma = margin, gamma
        self.ell_min, self.d_latency = ell_min, d_latency
    def barrier(self, phi_x, O_latent, mdc: MetricCertificate) -> float:
        h_phi = min((latent_dist(phi_x, o) for o in O_latent), default=math.inf)
        return h_phi / max(mdc.L, 1e-9)          # 认证净空下界 c_cert
    def admissible(self, phi_x, O_latent, mdc, pac, r_robot, v, a, dt) -> tuple[bool, str]:
        if not (mdc.valid(self.ell_min) and pac.injective):
            return False, "metric-void"           # DTG 失败 → 退回点云 Hull
        h_phi = min((latent_dist(phi_x, o) for o in O_latent), default=math.inf)
        R = v * dt + 0.5 * a * dt * dt
        required = mdc.L * (r_robot + self.margin + R + self.d_latency)
        if h_phi < required:
            return False, "swept-violation"       # SLCC：连续时间不安全
        return True, "ok"

# ============================================================
# IP-443 Swept Latent Corridor Certificate (SLCC)
# ============================================================
class SweptLatentCorridor:
    def __init__(self, v_max, a_max, d_latency=0.03):
        self.v_max, self.a_max, self.d_latency = v_max, a_max, d_latency
    def required_latent_clearance(self, mdc, r_robot, margin, dt) -> float:
        R = self.v_max * dt + 0.5 * self.a_max * dt * dt
        return mdc.L * (r_robot + margin + R + self.d_latency)
    def check(self, phi_x, O_latent, mdc, r_robot, margin, dt) -> bool:
        h_phi = min((latent_dist(phi_x, o) for o in O_latent), default=math.inf)
        return h_phi >= self.required_latent_clearance(mdc, r_robot, margin, dt)

# ============================================================
# IP-444 Distortion-Trust Gate (DTG)
# ============================================================
class DistortionTrustGate:
    def __init__(self, ell_min=0.05):
        self.ell_min = ell_min
    def admit(self, mdc, pac, semantic_recall_ok: bool) -> tuple[bool, str]:
        metric_ok = mdc.valid(self.ell_min)
        amb_ok = pac.injective
        if not metric_ok:
            return False, "metric-untrusted"     # 度量不可信 → Hull
        if not amb_ok:
            return False, "aliasing"             # 混叠 → 缺席翻转 + Hull
        if not semantic_recall_ok:
            return False, "semantic-blind"       # 语义盲 → 主动感知
        return True, "trusted"

# ============================================================
# IP-445 BiLipschitz Encoder Training Contract (BLETC)
# ============================================================
def bi_lipschitz_loss(encoder, pairs, L_max, ell_min):
    """采样物理邻域对，双向惩罚：上界违约 + 下界违约。"""
    loss = 0.0
    for a, b, d_S in pairs:                       # d_S = 已知物理距离
        dz = torch.norm(encoder(a) - encoder(b))
        loss = loss + F.relu(dz - L_max * d_S)    # 防膨胀过快（保 L 上界）
        loss = loss + F.relu(ell_min * d_S - dz)  # 防塌缩（保 ℓ 下界）
    return loss / max(len(pairs), 1)

# ============================================================
# IP-446 HPC-E++ 统一五证准入门
# ============================================================
@dataclass
class HPCEPlusPlus:
    hpc_e_plus: "HPCEPlus"          # v23 四证（几何/规范/能量/云边/少样本/IP）
    mdc: MetricDistortionCertificate
    pac: PerceptualAmbiguityCertificate
    lcbc: LatentControlBarrier
    dtg: DistortionTrustGate
    def admits(self, plan, x, v, z, E_res, margin_req, modules, latent_ctx) -> bool:
        if not self.hpc_e_plus.admits(plan, x, v, z, E_res, margin_req, modules):
            return False
        mdc = self.mdc.certify(
            latent_ctx.img, latent_ctx.depth, latent_ctx.tex,
            latent_ctx.spec_mask, latent_ctx.occ_mask,
            latent_ctx.region_id, latent_ctx.encoder_v)
        pac = self.pac.build(
            latent_ctx.phi, latent_ctx.depth, latent_ctx.multi_view,
            latent_ctx.occ_mask, latent_ctx.tex, latent_ctx.spec_mask)
        ok, why = self.dtg.admit(mdc, pac, latent_ctx.semantic_recall_ok)
        if not ok:
            return False                          # DTG：交叉信任门
        ok, why = self.lcbc.admissible(
            latent_ctx.phi, latent_ctx.O_latent, mdc, pac,
            latent_ctx.r_robot, latent_ctx.v, latent_ctx.a, latent_ctx.dt)
        return ok
```

## 2. 推导：保守净空夹逼与“空证书”条件

设 `ψ` 在相关邻域内满足双向不等式 `ℓ·d_S(a,b) ≤ d_Z(ψ(a),ψ(b)) ≤ L·d_S(a,b)`。

**（安全方向）** 若潜在障碍集覆盖真实障碍的像，即 `O_latent ⊇ ψ(O_true)`，则
```
h_φ = d_Z(ψ(x), O_latent) ≤ d_Z(ψ(x), ψ(O_true)) ≤ L·c(x)
⇒  c(x) ≥ h_φ / L.
```
**（碰撞方向）** 若 `O_latent ⊆ ψ(O_true)`（无虚假障碍），则
```
h_φ ≥ d_Z(ψ(x), ψ(O_true)) ≥ ℓ·c(x)  ⇒  c(x) ≤ h_φ / ℓ.
```
两式合成夹逼 `h_φ/L ≤ c(x) ≤ h_φ/ℓ`。**注意方向**：签发“安全”只用左不等式（保守）；签发“碰撞/拒绝”才用右不等式。当 `ℓ→0`（塌缩或混叠）时右式发散、左式仍成立但可能极松——此时既不能精细拒绝、净空也近乎无信息，故定义**空证书条件** `ℓ < ℓ_min ∨ L = ∞ ⇒ 证书作废`。

**扫掠膨胀的推导**：若 `‖ẋ‖ ≤ v_max, ‖ẍ‖ ≤ a_max`，则 `Δt` 内位移 `≤ v_maxΔt + ½a_maxΔt²`。由 Lipschitz 上界，隐空间净空在 `Δt` 内最多下降 `L·R_swept`。要求在 `x_k` 处 `h_φ ≥ L(r + margin + R_swept + d_latency)`，则整段轨迹上 `c ≥ h_φ/L − R_swept ≥ r + margin`。∎

**数值算例**：取 `L_φ=8`（latent/m）、`L_g=1.5` ⇒ `L=12`；测得 `h_φ=3.0` ⇒ `c_cert=3.0/12=0.25 m`。若 `r_robot=0.30 m`，则 `c_cert<r_robot`，必须减速/停止。再取 `v_max=1.0, a_max=2.0, Δt=0.05, d_latency=0.03` ⇒ `R_swept=0.0525`，要求 `h_φ ≥ 12·(0.30+0.05+0.0525+0.03)=5.19 > 3.0`，SLCC 拒绝。可见扫掠项在 50Hz 下并非可忽略。

## 4. 正确性论证

### 引理 1（保守净空下界）
**陈述**：若 `ψ` 在相关邻域内 `L`-Lipschitz，且 `O_latent ⊇ ψ(O_true)`，则 `c(x) ≥ h_φ(ψ(x))/L`。
**证明**：`h_φ = d_Z(ψ(x),O_latent) ≤ d_Z(ψ(x),ψ(O_true)) = inf_o d_Z(ψ(x),ψ(o)) ≤ inf_o L·d_S(x,o) = L·c(x)`。∎
（`O_latent ⊇ ψ(O_true)` 正是 DCSC/SDC 的召回条件：不漏障碍。引理把“语义召回”与“几何下界”显式相乘。）

### 引理 2（碰撞上界，仅用于拒绝）
**陈述**：若 `ψ` 在相关邻域内 `ℓ`-膨胀，且 `O_latent ⊆ ψ(O_true)`，则 `c(x) ≤ h_φ/ℓ`。
**证明**：`h_φ ≥ d_Z(ψ(x),ψ(O_true)) ≥ ℓ·c(x)`。∎

### 引理 3（歧义最坏情形可靠性）
**陈述**：若 `Â ⊇ A(φ)` 且 `c_cert = inf_{s∈Â} c(s)`，则所有与观测一致的物理状态 `s∈A(φ)` 满足 `c(s) ≥ c_cert`。
**证明**：`A(φ) ⊆ Â`，故 `inf_{s∈Â} c(s) ≤ inf_{s∈A(φ)} c(s)`，即 `c_cert` 是 `A(φ)` 上净空的（可能更保守的）下界。∎

### 引理 4（扫掠连续时间安全）
**陈述**：若在 `x_k` 处 `h_φ(ψ(x_k)) ≥ L(r+margin+R_swept(Δt)+d_latency)`，且 `‖ẋ‖≤v_max, ‖ẍ‖≤a_max`，则 `∀t∈[t_k,t_k+Δt]: c(x(t)) ≥ r+margin`。
**证明**：位移 `≤ R_swept`，故 `h_φ(ψ(x(t))) ≥ h_φ(ψ(x_k)) − L·R_swept ≥ L(r+margin+d_latency)`；再由引理 1，`c(x(t)) ≥ h_φ/L ≥ r+margin+d_latency ≥ r+margin`。∎

### 引理 5（交叉信任门的安全单调性）
**陈述**：`Exec_v24 = Exec_v23 ∩ Fil_mdc ∩ Fil_pac ∩ Fil_lcbc ⊆ Exec_v23`。
**证明**：DTG 只做合取（`metric_ok ∧ amb_ok ∧ semantic_ok`），LCBC/SLCC 只增加标量下界约束；任一失效返回 `False` 并退回 v23。故新层只可能剔除计划，不可能新增计划。∎

### 引理 6（版本绑定与回滚）
**陈述**：若编码器版本切换，则 `(L_φ, ℓ_φ, encoder_v)` 随 CESC 原子五元组一起切换；切换失败回滚到旧三元组，证书链连续且 `Exec_v24` 单调不增。
**证明**：`metric_root` 纳入 `payload_hash`，`VersionTuple.verify` 要求 `v_m=v_c=v_p`；`atomic_switch` 仅当 `FewShotValid` 且 MDC 重标定通过时提交，否则 `_rollback` 保留 `V_active`。∎

### 定理（HPC-E++ 的五证可靠性）
**陈述**：在假设 (A1) `ψ` 在签发区域满足双向 Lipschitz；(A2) `Â ⊇ A(φ)`；(A3) `O_latent ⊇ ψ(O_true)`（语义召回，失败概率 `≤ α_sem`）；(A4) 运动学界成立；下，`HPCEPlusPlus.admits(π)=True ⇒ P(不安全执行) ≤ α_sem + δ_m + δ_amb + δ_ver`（联合界）。
**证明**：由引理 1/3/4/5/6 分别给出几何、歧义、连续时间、单调性与版本可靠性；对四类失效取联合界。∎
**注（联合界不刻画相关性）**：`α_sem` 与 `δ_m` 若在“度量可信但语义盲”区域正相关，联合界仍成立但过松——这正是本轮最大风险的来源，也是 Q15 要在线检测的“自信盲区”。
