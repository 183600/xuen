研究循环 · 新灵感第 1 轮；本轮灵感：「抓取」×「四足机器人」

> **基线**：第 3 轮产出 MetricVoiceGauge-NCD-HUTDH-v22 + IP-431–435（HPC-E、EVC、RGC、ACSC、DCSC、CFC++），其上承 v21 语义-规范层（HPC+/SDC/CAC/DCL/GIC）与 v20 联邦感知证书（PCA/CTS/CFC/HPC/CFCtrl）。本轮不推倒 v22：分层过滤器 `Fil_hierarchical`、能量可行性 EVC、机械臂配空间 ACSC、深度 conformal DCSC 全部保留。
> 本轮纪律：**抓取不是"允许碰撞"，而是"被许可且有界的接触"；四足不是"换了个底盘"，而是"支撑集随时间重配置的动态系统"；载物行走时，抓取稳定性与步态稳定性通过载荷力旋量强耦合，必须联合认证**。本轮只做一件事：在 v22 的 HPC-E 之上加一层**接触-行走层（Contact & Locomotion Layer, CLL）**，把"无碰撞 + 能量可持续"升级为"接触可控 + 落足可靠 + 动态稳定 + 抓取-步态联合可行"的 v23 证书体系，并顺手封堵 v22 的最大风险（分层边界模糊导致的层级振荡与活性坍缩）。

## 0. 直觉与动机

**灵感 1（抓取 → 从"接触=碰撞"到"被授权的有界接触"）**
直觉：v22 把世界二分为"本单位可占用"与"障碍物"，接触恒等于碰撞。但机械臂要抓杯子，必须主动接触——若接触一律当碰撞，系统永远无法完成任何操作任务；若简单放开接触，又等于取消了碰撞证书。真正缺的是第三种状态：**被授权、有界、可撤销的接触**。抓取还带来三件 v22 没有的东西：(a) **接触力可行性**——摩擦锥能否支撑外载荷，即力闭合/形闭合；(b) **滑移这种"进行中的失效"**——不是二值碰撞，而是连续退化，必须靠触觉负证据闭环；(c) **自模型变更**——抓稳后物体事实上并入机器人本体，本体几何、质量、惯量全部改变。

严谨地说，抓取由抓取映射 `G` 与摩擦锥 `FC_c(μ_c)` 描述：`W_g = G(∏_c FC_c)` 是可达力旋量集，对任意外载荷 `w_ext(t)`，存在接触力 `f` 使 `Gf = -w_ext` 即力闭合。裕度 `ε_fc` 是 `-w_ext` 到 `∂W_g` 的带符号距离。`μ_c, m_p, I_p` 不可精确已知，用 conformal 下界 `μ_c^-` 与参数集 `M_p × J_p` 取最坏顶点，得到**鲁棒力闭合裕度**。滑移证据（触觉切向/法向比超过 `μ_c^-`、物体相对夹爪漂移）是负信息，触发"结构上限内增力 / 降激进程度 / 安全落点释放"三级反应。

核心创新：**抓取接触证书（Grasp Contact Certificate, GCC）+ 接触许可（Contact Permit, CP）**。`CP = (目标, 接触面片, 时间窗, 接近速度上界, 法向冲量上界, 审计签名)`，是 v21 deontic 层的 P 型许可，只在**任务指定的目标物体**上签发；人类、动物、未知物体永不签发。接触许可不放松几何障碍集，只把"与指定目标的接触"从碰撞语义重标记为受控接触语义。

关键反直觉点：**抓取在集合论上是"自加约束"而非"解锁"**——接触许可让某条接触轨迹合法，但抓稳后载荷并入本体，使本体几何膨胀、加速度上限下降、能量预算增加，整体可行集反而更小。所以 v23 的接触模式不是 v22 的超集，而是 v22 之外一个被严格门控、且使此后的非接触模式更保守的"受控接触分支"。

**灵感 2（四足机器人 → 支撑集重配置、落足证据与摔倒这个新失效类）**
直觉：v20–v22 的证书默认连续支撑的轮式/固定底座：障碍物是静态几何，危险只是"会不会碰"。四足把两个前提都打破：支撑集随步态相位在接触调度 `σ(t) ∈ {0,1}^4` 下不断重配置；危险除了碰撞，还有**失去支撑而摔倒**。落足点选择因此变成一等公民：一个区域对机体不可通行，却可能对某个落足点可用；反过来，看起来平坦的地面可能暗藏空洞或低摩擦。

严谨地说，对接触调度 `σ` 定义支撑多边形 `P_sup(σ)`；合并质心 `r_com` 与捕获点 `ξ = r_com,xy + ṙ_com,xy/ω`（`ω = √(g/z_com)`）；稳定裕度 `ε_stab` 是 `ξ`（动态步态用 ZMP/质心动量）到**按落足误差侵蚀后**的支撑边界的带符号距离。落足证书要求：支撑面片 `S_i ⊆ TR`、所需地面反力在摩擦锥 `μ_g^-` 内、腿部 IK 可达且腿扫掠体积无碰撞、落足误差 `CertBox` 落在 `S_i` 内。地形 `T(x)` 的高度/摩擦带 conformal 不确定带；**未知地形一律 `TR=0`**——"没检测到洞"不等于"没有洞"。这与 v21 的 AbsCert 同源但更严格：障碍的缺席可以靠召回下界赎回，**支撑的缺席不能**，必须要求正面支撑证据。

核心创新：**落足与地形可通行证书（Foothold & Terrain Traversability Certificate, FTTC）+ 动态稳定证书（Dynamic Stability Certificate, DSC）**。

关键反直觉点：**腿把"障碍物单调律"从区域级降维到接触调度级**——障碍在区域内并不自动禁止该区域，只禁止机体扫掠与错误落足；于是 v21 的"自由空间有偿赎回"升级为"按接触调度赎回"。同时，**摔倒是 v22 完全没有的失效类**，必须显式建模、检测与恢复，而不能沿用碰撞证书的安全论证。

**灵感 3（交叉：抓取 × 四足 = 载物四足移动操作，耦合是新的本体）**
直觉：把两个灵感放在一起，会出现单看任一灵感都看不见的漏洞：载荷的质量/惯量改变合并质心与支撑裕度；步态的加速度/角速度又通过惯性力旋量反向加载到抓取上。**抓取证书与步态证书各自为真，联合起来仍可能为假**。反例很具体：静态力闭合通过（静止能夹住），空载小跑稳定通过，但载物小跑时惯性力旋量超出摩擦锥 → 滑移掉落；或载荷把质心推出支撑多边形 → 摔倒。

严谨定义：联合不变量 **CGLI**——存在共享控制权威 `λ ∈ [0,1]`（激进程度：步速/加速度/步长/抓取法向力），使得对步态时域内所有相位 `t`，`ε_fc(t;λ) ≥ ε_fc^min` 且 `ε_stab(t;λ) ≥ ε_stab^min`。关键性质（假设 A1）：两个裕度对 `λ` 单调，`λ` 越小越保守；故可行 `λ` 集是上区间，取最大可行 `λ*` 并加滞回。若 `λ*` 低于活性阈值，则拒绝任务或在已认证落点安全释放，而不是死锁。

关键反直觉点：**协调变量不是"夹得更紧"或"走得更慢"中的某一个，而是单一的激进程度 `λ`**——单独加大夹持力可能把质心推偏、反而降低稳定裕度；单独放慢步态可能因支撑时间过长而增大单足载荷。把两者投影到同一 `λ` 轴上，才有多目标单调性，才能在 200Hz 内做一维搜索而不是在联合空间里盲目搜索。

**三者如何统一**
统一为 v22 HPC-E 之上的**接触-行走层**。共享状态扩展为 `ζ_clcl = ζ_pgev ∪ (g, w_ext, ε_fc, CP, σ_gait, P_sup, r_com, ξ_cap, ε_stab, T, TR, λ)`。统一准入门 **HPC-C = HPC-E ∧ GCC ∧ FTTC ∧ DSC ∧ CGLI**，接触相额外要求有效 `CP`。这里必须诚实地修正一个集合论陷阱：v22 禁止一切接触，故接触分支**不可能**包含于 `Exec_v22`。因此 v23 继承的不是朴素的 `Exec_v23 ⊆ Exec_v22`，而是更强的**危害单调性**：非接触轨迹 `Exec_v23^{¬contact} ⊆ Exec_v22`；接触轨迹仅允许与任务目标 `T` 接触且受 `CP` 约束；对任意人类/未知障碍 `h ∉ T` 仍保持零接触。于是"意外碰撞与人身接触"的危害集单调收缩，同时承认受控接触是 v22 之外的显式新模式。这也顺带封堵了 v22 的最大风险：`λ` 的一维单调前沿 + 滞回消除层级振荡，拒绝/释放路径消除死锁。

## 1. 研究问题（轮次升级版）

- **Q12（接触许可的可靠性）**：如何定义 `CP` 的签发条件，使"预期接触"被授权而"意外碰撞"的危害单调不增？`CP` 的空间/时间/速度/冲量四重界定如何与 v21 的 DCL P 规则、AbsCert 人体在场检查、SDC 目标位姿证书衔接？误签发（把人类或未知物体当成目标）如何被结构性排除而非仅靠阈值？

- **Q13（鲁棒力闭合与滑移负证据）**：如何在 `μ_c, m_p, I_p` 的 conformal 参数集上高效计算最坏情形 `ε_fc`（200Hz 内）？摩擦锥线性化误差与保守性如何权衡？触觉/本体感受/视觉的滑移证据如何融合成可审计的负证据，并在结构/物体承压上限内闭环增力或降 `λ`？

- **Q14（载物自模型与分布漂移）**：抓取后 `m_p, I_p` 与载荷几何如何在线辨识并单调并入本体模型？接触瞬间样本分布从"空载"切到"载物"，conformal 的 exchangeability 假设失效，如何在不松开物体的前提下完成重校准（受控探针激励）？辨识不确定时如何保守回退而不破坏活性？

- **Q15（落足与地形负信息）**：落足点 `CertBox` 如何由地形高度/摩擦的 conformal 不确定带导出？"正面支撑证据"如何形式化为可审计谓词（深度、本体感受、足底力的模态冗余）？未知/遮挡/空洞地形如何强制 `TR=0`，并与 v21 AbsCert 的"召回下界"逻辑区分？

- **Q16（动态稳定与摔倒）**：如何用合并 CoM/惯量与间歇支撑严格定义 `ε_stab`？capture point、ZMP、质心动量三种判据在静态/动态步态下如何切换而不产生不连续？摔倒是新的失效类，如何检测、如何给出有界能量恢复证书、何时升级为保护性跌倒（SafeStop）？

- **Q17（联合不变量与活性）**：CGLI 如何在步态时域上量化全相位 `ε_fc` 与 `ε_stab`？单调性假设 A1 在什么条件下成立、如何在线验证？`λ*` 的滞回与活性阈值如何避免"证书可行但任务永远做不完"？GCC/FTTC/DSC/CGLI 的计算如何分配在 10–50Hz 规划与 200Hz–1kHz 控制环，且控制路径只做 O(1) 查询？

## 2. 设计原则（在 P34–P46 基础上新增 P47–P50）

**P47 接触许可单调律（Contact-Permit Monotonicity）**
默认接触 = 禁止（完整继承 v22 碰撞证书）。接触仅经 `CP` 授权，`CP` 绑定 `(target, patch, window, v_max, J_max)`；人类/动物/未知物体不可签发；`CP` 可随时撤销。抓取成功后载荷壳 `H_p` 并入本体几何、`m_p/I_p` 并入本体惯量，使此后的障碍集只增、加速度上限只降。任何标定漂移、触觉异常、目标位姿不确定度上升 → 撤销 `CP` 并退到安全距离。形式化：轨迹 `π` 的接触集 `C(π) ⊆ PermittedContacts(CP)`；非接触轨迹不变，故对未授权障碍的危害单调不增。

**P48 抓取闭合鲁棒律（Robust Grasp Closure）**
`ε_fc(μ^-, M_p, J_p) ≥ ε_fc^min`，对参数集取最坏顶点；力闭合是**必要非充分**，还须在时域上无滑移。滑移负证据触发三级反应：(i) 在物体/夹爪结构上限内增力；(ii) 降低 `λ`（减速/减小步幅）；(iii) 在认证落点安全释放。禁止"为保住抓取而把法向力加到超过结构/物体承压极限"——那只是把滑移失效换成压碎失效。

**P49 载荷感知步态稳定律（Payload-Aware Locomotion Stability）**
DSC 必须使用合并质心/惯量；支撑多边形按落足误差与地形不确定度侵蚀；未知地形 `TR=0`；落足需正面支撑 + 地面反力可行；摔倒作为独立失效事件 `V_fall`；恢复证书有界能量；stance width / cadence / body height 作为稳定裕度的调节手段，而非事后补救。

**P50 抓取-步态联合不变量律（Coupled Grasp–Locomotion Invariant）**
`∃λ ∈ [0,1]`，使 `∀t∈[0,T]`：`ε_fc(t;λ) ≥ ε_fc^min ∧ ε_stab(t;λ) ≥ ε_stab^min`。取 `λ* = max feasible`，施加减速/加速不对称滞回；`λ* < λ_live` 时拒绝任务或安全释放。新过滤器只收缩非接触模式；接触模式由 `CP ∧ GCC ∧ CGLI` 联合门控。故整体满足"危害单调"：`Exec_v23^{¬contact} ⊆ Exec_v22`，且对 `h ∉ T` 的接触集恒空。

## 3. 与基线的接口（如何退化）

- GCC 失效（抓取证书不可计算/滑移证据持续）⇒ 不抓取、保持夹持或安全放置，退回 v22 非接触移动 ⇒ 非接触分支 ⊆ v22；
- FTTC 失效（地形未知/遮挡/落足不可行）⇒ 冻结步态、加宽支撑、降速；最坏退回四足站立（静态稳定）⇒ 比 v22 更保守；
- DSC 失效（稳定裕度不可信/传感器失效）⇒ 蹲伏 + 静态步态 + 停止；不可恢复 ⇒ 保护性跌倒（SafeStop 升级，不属于正常 Exec）；
- CGLI 不可行 ⇒ 沿 `λ` 下降到 `λ*`；仍不可行 ⇒ 在认证落点释放/放弃任务，绝不静默死锁；
- CP 撤销（人进入接触走廊）⇒ 立即停止接近，保持夹持或退让，并复用 v21 GIC 的急停优先级；
- 全部失效 ⇒ 完全回退 v22 非接触保守模式；能量/几何/规范各层继续向 v21/v20 退化。
- **危害单调继承**：接触许可只作用于任务目标、GCC 只收缩接触相、FTTC/DSC 只收缩非接触可行域、CGLI 只降低激进程度；任意失效都向更保守方向退化，且对 `h ∉ T` 的接触集始终为空。

## 4. 预期贡献

1. **受控接触证书**：首次在碰撞证书体系内形式化"被授权的有界接触"，把接触许可 `CP` 与 deontic P 规则、AbsCert 人体在场、目标位姿证书统一，给出签发/撤销/不可伪造的条件；
2. **鲁棒力闭合**：conformal `μ/m/I` 下界 + 最坏情形力旋量裕度 + 滑移负证据闭环，把"抓得住"从静态几何判据升级为带概率保证的时域判据；
3. **载物自模型单调更新**：抓取后载荷并入本体几何/惯量，使 v21 的单调证据体系在操作后仍成立，并显式处理接触瞬间的分布漂移；
4. **四足落足/地形证书**：正面支撑证据 + 未知即不可通行 + 地面反力可行 + 腿扫掠，给出腿式平台的可审计可通行性判据；
5. **动态稳定证书**：载荷合并 CoM / capture point、间歇支撑与摔倒这个新失效类，补齐 v22 只覆盖碰撞的缺口；
6. **抓取-步态联合不变量**：证明独立证书不充分，给出共享权威 `λ` 的单调协调、滞回与活性阈值，形成 `HPC-C` 统一门；
7. **诚实的安全继承修正**：指出并修正"接触必然违反 v22 集合包含"的陷阱，改用危害单调性，使 `Exec_v23^{¬contact} ⊆ Exec_v22` 与"目标接触受控开放"同时成立；
8. **封堵 v22 最大风险**：`λ` 一维单调前沿 + 滞回抑制层级振荡，拒绝/释放路径消除死锁，FTTC/DSC 补齐四足场景下的新失效面。

## 5. 本轮最大风险

**一句话**：CGLI 的可靠性押在"载荷质量/惯量/摩擦与地形支撑参数可被在线可靠辨识"这一经验前提上；而接触瞬间恰恰是 exchangeability 失效、参数最不可观、且误差会经"载荷↔步态"双向放大的时刻——一次被低估的载荷质量或一段隐蔽低摩擦地形，就可能让抓取与步态两张证书在形式上同时成立、事实上同时失效，酿成"有证的掉落 / 有证的摔倒"。

## 0. 增量符号体系（定义 926–978）

## 1. 关键算法骨架（在 IP-431–435 骨架上扩展）

```python
# ---------- IP-436 抓取接触证书与接触许可 ----------
@dataclass(frozen=True)
class ContactPermit:
    target_id: str
    patch: frozenset           # 目标物体上的接触面片（世界系）
    t0: float
    t1: float
    v_approach_max: float      # 接近速度上界 m/s
    impulse_max: float         # 法向冲量上界 N·s
    signature: str             # merkle 审计签名


class GraspContactCertificate:
    def __init__(self, grasp_map, mu_lower, mass_set, inertia_set,
                 eps_fc_min=0.05, eps_struct=0.9):
        self.G = grasp_map             # w = G f
        self.mu_lower = mu_lower       # 逐接触 conformal 下界 μ^-
        self.mass_set = mass_set       # M_p 的有限顶点
        self.inertia_set = inertia_set # J_p 的有限顶点
        self.eps_fc_min = eps_fc_min
        self.eps_struct = eps_struct   # 物体/夹爪承压上限比例

    def worst_case_wrenches(self, accel_body, omega_body):
        """步态激励下载荷外力旋量的最坏顶点集合。"""
        out = []
        for m in self.mass_set:
            for J in self.inertia_set:
                out.append(payload_wrench(m, J, accel_body, omega_body))
        return out

    def robust_force_closure_margin(self, contacts, wrenches):
        """对每个最坏外旋量解摩擦锥 LP，返回最小带符号裕度。"""
        worst = float("inf")
        for w in wrenches:
            eps = solve_friction_cone_margin(
                self.G, contacts, -w, self.mu_lower)
            worst = min(worst, eps)
        return worst

    def issue_permit(self, target, patch, t_now, v_rel, task, humans):
        """只有任务指定、非生物、且不在人体接触走廊内的目标才可签发。"""
        if target.id not in task.target_ids or target.is_biological:
            return None                                  # 结构性排除人类/未知物体
        if humans.present_in_contact_corridor(target, patch):
            return None                                  # 复用 v21 AbsCert/GIC 在场检查
        if v_rel > task.v_approach_max:
            return None
        impulse = predict_normal_impulse(v_rel, target, task)
        if impulse > task.impulse_max:
            return None
        return ContactPermit(
            target.id, frozenset(patch), t_now,
            t_now + task.permit_ttl, task.v_approach_max,
            task.impulse_max, sign(target, patch, task))

    def slip_negative_evidence(self, tactile, delta=0.05):
        """切向/法向比逼近 conformal 摩擦下界 → 滑移负证据。"""
        for c in tactile.contacts:
            ratio = c.tangential / max(c.normal, 1e-9)
            if ratio > self.mu_lower[c.id] - delta:
                return True
        return False

    def slip_response(self, tactile, grasp_force, lam, has_drop_zone):
        """三级反应：增力（结构上限内）→ 降 λ → 认证落点释放。"""
        if self.slip_negative_evidence(tactile):
            if grasp_force * 1.2 <= self.eps_struct * grip_limit():
                return ("INCREASE_FORCE", grasp_force * 1.2, lam)
            if lam > 0.0:
                return ("REDUCE_LAMBDA", grasp_force, 0.5 * lam)
            if has_drop_zone:
                return ("RELEASE_AT_CERTIFIED_DROP", grasp_force, 0.0)
        return ("HOLD", grasp_force, lam)


# ---------- IP-437 落足与地形可通行证书 ----------
class FootholdTerrainCertificate:
    def __init__(self, terrain, slope_max, step_max, mu_ground_lower):
        self.terrain = terrain
        self.slope_max = slope_max
        self.step_max = step_max
        self.mu_ground_lower = mu_ground_lower

    def traversable(self, x):
        if not self.terrain.has_positive_support(x):
            return False                    # 未知/遮挡/空洞：没有正面支撑证据
        h_lo, h_hi = self.terrain.height_band(x)
        if (h_hi - h_lo) > self.step_max:
            return False
        return self.terrain.slope(x) <= self.slope_max

    def foothold_admissible(self, h, gait, payload, phase):
        if not all(self.traversable(p) for p in h.support_patch):
            return False
        grf = required_ground_reaction(gait, payload, phase, h)
        return (grf_in_friction_cone(grf, self.mu_ground_lower)
                and leg_ik_reachable(h, gait.body_pose)
                and leg_swept_volume_clear(h, gait))

    def all_footholds_admissible(self, plan, payload):
        return all(self.foothold_admissible(h, plan.gait, payload, phase)
                   for h, phase in plan.footholds())


# ---------- IP-438 动态稳定证书 ----------
class DynamicStabilityCertificate:
    def __init__(self, eps_stab_min=0.03, erosion=0.03):
        self.eps_stab_min = eps_stab_min
        self.erosion = erosion             # 落足误差 + 地形支撑不确定侵蚀

    def combined_com(self, robot, payload):
        m = robot.mass + payload.mass
        r = (robot.mass * robot.com + payload.mass * payload.com) / m
        return r, combined_inertia(robot, payload)

    def stability_margin(self, x, v, sigma_gait, payload):
        r_com, _ = self.combined_com_from_state(x, payload)
        omega = math.sqrt(9.81 / max(r_com.z, 1e-3))
        xi = r_com[:2] + v[:2] / omega              # capture point
        P = erode(support_polygon(sigma_gait), self.erosion)
        return signed_distance(xi, P)

    def fall_detected(self, pose, contacts):
        return (abs(pose.roll) > 1.0 or abs(pose.pitch) > 1.0
                or body_contact(contacts))


# ---------- IP-439 抓取-步态联合不变量 ----------
class CoupledGraspLocomotionInvariant:
    def __init__(self, gcc, dsc, lambdas, deadband=0.05):
        self.gcc = gcc
        self.dsc = dsc
        self.lambdas = sorted(lambdas, reverse=True)
        self.deadband = deadband

    def certify(self, plan):
        """从最激进到最保守扫描 λ；返回最大可行 λ*，无则 None。"""
        for lam in self.lambdas:
            gait = plan.gait_at(lam)
            ok = True
            for t in sample_phases(gait, plan.horizon):
                wrenches = self.gcc.worst_case_wrenches(
                    gait.accel(t), gait.omega(t))
                ef = self.gcc.robust_force_closure_margin(
                    plan.contacts_at(t), wrenches)
                es = self.dsc.stability_margin(
                    plan.state_at(t), gait.sigma(t), plan.payload)
                if ef < self.gcc.eps_fc_min or es < self.dsc.eps_stab_min:
                    ok = False
                    break
            if ok:
                return lam
        return None

    def co_regulate(self, plan, lam_prev):
        lam = self.certify(plan)
        if lam is None:
            return ("RELEASE_AT_CERTIFIED_DROP"
                    if plan.has_drop_zone else "REFUSE_TASK")
        if abs(lam - lam_prev) < self.deadband:     # 滞回：抑制 λ 边界抖动
            return lam_prev
        return lam


# ---------- IP-440 HPC-C 统一准入门 ----------
@dataclass
class HPCC:
    hpc_e: HPCE
    gcc: GraspContactCertificate
    fttc: FootholdTerrainCertificate
    dsc: DynamicStabilityCertificate
    cgli: CoupledGraspLocomotionInvariant
    permit: ContactPermit | None

    def admits(self, plan, x, v, z, E_res, margin_req):
        if not self.hpc_e.admits(plan, x, v, z, E_res, margin_req):
            return False
        if plan.touches_target and self.permit is None:
            return False                        # 无 CP 不得接触目标
        if plan.touches_target and not self.permit_covers(plan):
            return False                        # CP 必须覆盖面片/时间窗/冲量
        if not self.fttc.all_footholds_admissible(plan, plan.payload):
            return False
        if self.dsc.fall_detected(plan.pose, plan.foot_contacts):
            return False
        if self.dsc.stability_margin(x, v, plan.sigma, plan.payload) \
                < self.dsc.eps_stab_min:
            return False
        return self.cgli.certify(plan) is not None

    def permit_covers(self, plan):
        cp = self.permit
        return (plan.contact_target in cp.target_id
                and plan.contact_patch <= cp.patch
                and cp.t0 <= plan.contact_time <= cp.t1
                and plan.approach_speed <= cp.v_approach_max
                and plan.normal_impulse <= cp.impulse_max)


# ---------- IP-441 CFC+++ 接触感知共识 ----------
class ContactAwareConsensus(CFCPlusPlusHierarchical):
    CONTACT_MODALITIES = {"tactile", "proprio", "foot_force"}

    def consensus_round(self, timeout=5.0):
        out = super().consensus_round(timeout)
        for key, verdict in out.items():
            if verdict == "SAFE":
                modalities = {v.modality for v in self.votes[key].values()}
                if not (modalities & self.CONTACT_MODALITIES):
                    out[key] = "CI"     # 无接触接地模态佐证 → 不允许判 SAFE
        return out
```

## 2. 关键命题与证明梗概

**命题 1（独立证书不充分）**：存在载物四足场景，使 `GCC` 在静止/名义载荷下通过、`DSC` 在空载小跑下通过，但联合轨迹在某个相位 `t*` 同时违反 `ε_fc ≥ ε_fc^min` 或 `ε_stab ≥ ε_stab^min`。

*证明梗概*：GCC 的量化变量是名义 `w_ext`，DSC 的量化变量是空载 `r_com` 与 `P_sup(σ)`；两者的合取并未对联合轨迹 `(a_b(t), α_b(t), m_p, I_p)` 量化。取相位 `t*` 使 `w_grasp(t*) = -w_ext(t*) = -payload_wrench(m_p, I_p, a_b, α_b) ∉ W_g`，或使 `ξ_cap(t*) ∉ P_sup`。静止时 `a_b=0`，故 GCC 的静态检查看不到该项；空载时 `m_p=0`，故 DSC 也看不到该项。于是合取为真而事实为假。CGLI 以 `∀t` 在联合变量上量化，正是补上这一缺口的最小谓词。∎

**命题 2（危害单调，而非朴素集合包含）**：定义危害集 `H(π) = { 接触对象 o : o ∉ T }`（`T` 为任务目标集，含人类排除）。则 `∀π ∈ Exec_v23`，`H(π) = ∅`；且 `Exec_v23^{¬contact} ⊆ Exec_v22`。

*证明梗概*：(i) `CP` 的签发条件结构性地拒绝 `o ∉ T` 与生物对象，故受控接触只能发生在 `T` 上；(ii) 非接触轨迹不经过任何新许可，且 `HPC-C` 是 `HPC-E` 与 v22 各过滤器的合取，故其仍属 `Exec_v22`；(iii) 抓取后 `H_p` 并入障碍集、`m_p/I_p` 并入惯量，只可能使后续非接触轨迹更保守。因此危害集单调收缩。注意：**接触轨迹不属于 `Exec_v22`（v22 禁止一切接触），朴素包含 `Exec_v23 ⊆ Exec_v22` 不成立，必须用危害单调替代——这是本轮对 v22 安全继承论证的一处修正**。∎

**命题 3（单调协调与活性）**：在假设 A1（`ε_fc(t;λ)` 与 `ε_stab(t;λ)` 对 `λ` 单调不减）下，可行集 `Λ = {λ : ∀t, ε_fc ≥ ε_fc^min ∧ ε_stab ≥ ε_stab^min}` 是上区间，故 `λ* = max Λ` 存在；带滞回的一维下降保证有限步内到达可行点或触发拒绝/释放，不产生死锁。

*证明梗概*：上区间性由 A1 直接得到；有限性由 `λ` 的有限网格与每次严格下降 `≥ deadband` 保证；若网格耗尽仍不可行，则 `co_regulate` 返回 `RELEASE/REFUSE`，系统离开"继续尝试"循环，故无死锁。∎ **风险**：A1 是经验假设，需在线验证（见实验设计 A1-check），单次反例即意味着 `λ*` 搜索可能漏掉可行点或多做保守。

**命题 4（接触许可的不可伪造性）**：`CP` 绑定 `(target, patch, window, v_max, J_max, sig)`，且 `HPC-C` 校验覆盖关系；任何超出面片、时间窗、速度或冲量的接触都使 `admits = False`。签名链复用 v21 规则库 merkle 审计，故 `CP` 的签发与撤销可追溯、不可静默改写。∎

## 3. 实验设计（仿真优先，真机小规模验证）

**平台与任务**：四足 + 6-DoF 机械臂（Isaac Gym / RaiSim；真机取 Unitree B1/B2 + 轻量臂），任务为"抓取可变载荷箱 → 跨越台阶/斜坡/低摩擦垫 → 放置"。载荷质量/惯量在 `[0, 8] kg` 与形状偏心范围内随机；地形含台阶（≤ 15 cm）、斜坡（≤ 20°）、随机低摩擦区、隐蔽空洞（仅视觉不可见）。

**基线**：(B1) v22 + 独立 GCC/DSC（非联合）；(B2) v22 不抓取（纯移动）；(B3) v23 但用名义摩擦/质量（无 conformal 下界）；(B4) v23 无 `λ` 协调（固定激进程度）；(B5) v23 完整。

**指标**：证书覆盖率（`ε_fc ≥ 0 ∧ ε_stab ≥ 0` 的经验频率）、滑移率、掉落率、摔倒率、任务成功率、活性（单位时间完成运输次数）、`λ*` 分布、单周期计算时延（目标：GCC ≤ 2 ms，DSC ≤ 0.5 ms，CGLI 全相位 ≤ 5 ms）。

**消融**：(A1) 去掉 CGLI 联合量化；(A2) 去掉未知地形 `TR=0` 保守；(A3) 去掉滑移负证据；(A4) 去掉 `CP` 面片/冲量界定（接触当普通碰撞处理）；(A5) 分布漂移下不做探针重校准。

**A1-check（验证单调性假设）**：在 `λ` 网格上测量 `min_t ε_fc` 与 `min_t ε_stab`，检查是否随 `λ↓` 单调不减；若非单调，记录反例并切换为二维（速度 × 夹持力）搜索。

**失败分类与反应**：

| 事件 | 检测证据 | 证书谓词 | 反应 |
|---|---|---|---|
| 抓取滑移 | 触觉切向/法向比、物体位姿漂移 | `GCC.slip_negative_evidence` | 结构上限内增力 → 降 `λ` → 认证落点释放 |
| 掉落 | 物体位姿突变、接触力归零 | `GCC` 时域可行性失效 | 安全落点 / 退出任务 |
| 摔倒 | IMU 姿态、躯干触地、支撑丢失 | `DSC.fall_detected` | 保护性跌倒（SafeStop 升级） |
| 落足打滑 | 足底力/触觉、腿部本体感受 | `FTTC.foothold_admissible` | 重规划落足、加宽支撑、降速 |
| 人体进入 | v21 GIC/CAC 在场证据 | `CP` 撤销条件 | 立即停止接近、退让 |
| 耦合不可行 | `CGLI.certify = None` | `HPC-C.admits = False` | 降 `λ*`；仍不可行则释放/拒绝 |

**预期结果**：(1) B1 会复现"有证失败"案例（静态力闭合 + 空载稳定均通过，载物步态下掉落/摔倒）；(B2) 活性最低但不失败；(B5) 以适度活性代价显著降低掉落与摔倒；(B3) 在低摩擦/重载尾部出现覆盖率跌破 `1-α`，验证 conformal 下界的必要性；(A1) 消融后掉落率显著回升，直接支持命题 1。

## 4. 复杂度与实时性

- GCC 鲁棒裕度：接触数 `k ≤ 4`，摩擦锥线性化为 `8k` 不等式，最坏参数顶点数 `|M_p|·|J_p|` 很小；单次 LP 毫秒级，可缓存顶点解并做热启动。
- DSC：每个相位的 `ξ_cap`/多边形距离为 O(1)（支撑多边形顶点 ≤ 8），200Hz–1kHz 可行。
- CGLI：`λ` 网格 × 相位采样；用单调性做二分/提前终止，最坏 ~10×相位数的 LP，5 ms 内。
- 控制路径只查 O(1) 的 `λ*`、`CP` 有效性与 `ε_stab` 最新值；规划环（10–50Hz）负责重算证书。

## 5. 本轮最大风险

**一句话**：CGLI 把安全押在"载荷质量/惯量/摩擦与地形支撑可在线可靠辨识"上，而接触瞬间正是 exchangeability 失效、参数最不可观、误差又被"载荷↔步态"双向放大的时刻——一次被低估的载荷质量或一段隐蔽低摩擦地形，足以让抓取与步态两张证书在形式上同时成立、事实上同时失效，酿成"有证的掉落 / 有证的摔倒"。
