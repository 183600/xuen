# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；灵感循环新循环第 1 轮；本轮灵感：「动态避障」×「深度相机」）

> R69 把不确定性劈成两半：**aleatoric（不可约噪声，沿用 R68 的 λ_floor 铁律）** 与 **epistemic（可约歧义，交给"问/看/触"去消解）**。这条二分隐含了一个从未被检查的假设：**凡是可约的，都可以通过"标定"或"询问"来约**。深度相机 × 动态避障把这条假设当场击穿——
>
> **有些未知既不是噪声，也问不出来；它只是被挡住了。**
>
> 柱子后面的走廊、透明玻璃后的墙、远处稀疏到消失的细杆、被人群遮住即将横穿的行人：标定对它们无能为力（没有信号可校），提问也无处可问（没有人能替你看见墙后），**唯一能消解它的动作是移动视点本身**。而"移动"恰恰又制造碰撞风险——信息动作与风险动作第一次是**同一个自由度**。
>
> 核心命题：**把 R69 的 epistemic 再劈一刀——U_epi^ask（可问/可标定）与 U_occ（只能靠视差消解）；深度相机给出可计算的视差增益与深度噪声-速度界；动态避障给出"出没通道"与"未知非自由"两条硬约束；并用一个遮挡感知 CBF 把"看不见"制度化为"必须按最坏情况膨胀的障碍"。** 命名 **PARALLAX-RAS**（Parallax-driven Active perception for Risk-adaptive Avoidance under oXclusion）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我站在这里，看得见吗；换个角度，要付多少安全代价**」——不确定性不只是刹车踏板、也不只是一句提问，还可以是**一次侧身、一段减速积累的视差、一次绕行换来的可见体积**。

## 0. 直觉与动机

**灵感 1（深度相机 → 几何是"有视角的"）**
直觉：激光雷达给的是"周围一圈的距离"，深度相机给的是"从一个位姿出发、被遮挡裁剪过的可见面片"。深度图的每一块空白都不是中性的：它可能是远处、可能是透明、可能是被前面的东西挡住。把深度图当成"已知自由空间"是动态避障里最常见也最致命的错误。R68/R69 的不确定性是"对已观测量的不确定"；这里新增的是**"对未观测区域的结构化无知"（known unknown with geometry）**——它有一个形状、一个边界、一个随视点变化的体积。这正是本轮要显式建模的对象。

**灵感 2（动态避障 → 遮挡物本身会动，危险在"出没"）**
直觉：静态占据地图假设"看不见的地方一直没东西"。但真正的动态危险恰恰是**从遮挡边缘突然出现的东西**——柱子后冲出的行人、卡车后横穿的自行车。这类危险的本质不是"当前可见障碍太近"，而是"**出没通道的预警时间太短**"。于是避障的目标从"离可见障碍远一点"升级为"**保证每一个盲区出没通道的可见-到-抵达时间 ≥ 反应预算**"。深度相机在这里既提供观测量（深度/光流），又提供失效模式（透明/反光/稀疏），必须一起建模。

**灵感 3（视差 → 消解遮挡的第一性动作是换视角）**
直觉：R69 的信息动作是"看/问/触"，对象是人类或环境模态；本轮的信息动作是 **g_move = 移动视点/侧身/减速以积累视差**，对象是**世界几何本身**。深度测距的物理基础（三角测量/运动视差）恰好说明：**视差就是"从两个视角看同一处"的差异**；而遮挡只能通过视角变化被"绕开"。于是"信息动作"从社会性的"问"回到了物理性的"移动"——但代价是它同时改变碰撞风险。

**灵感 4（信息-风险同源 → 解耦优化会失效）**
直觉：R69 里探针方向/注视/问句的风险是有界的、且与任务动作大致可解耦；但在移动平台里，"侧身看清柱子后面"这个动作本身就是一段可能撞墙的位移。**你不能先决定'我要看'再让安全滤波去修**——因为被修正后的轨迹可能一步也没移动到能产生视差的位置，信息增益归零。这要求 VoI 只在**已认证安全的轨迹集合**上计算，且安全与信息联合优化。这是本轮最重要的结构性新结论。

**灵感 5（深度相机的诚实与不诚实 → 新的失效面）**
直觉：深度相机最危险的失效不是"噪声大"，而是"**自信地给出错误的结构**"：玻璃/镜面/黑色吸光面返回"空"，远处稀疏点云让细杆消失，强光/多机干扰把整个区域打成无效点，投影欺骗可以让深度凭空出现一个不存在的障碍或抹掉一个真实的。这些失效会被 R68 的标定"解释掉"（残差小），也能骗过 R69 的流似然（行为自洽但世界是假的）。所以本轮必须交付：深度有效性门、视差-几何对偶第二意见、未知非自由的安全膨胀、以及对抗性出没/深度欺骗的干扰集。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（PARALLAX-RAS 总览）** PARALLAX-RAS = (DVG, TOP, ECP, PAV, OCBF, SPO, PGD, RAS-WM‡)。四不变式：
(i) 继承 R69 的实时流零学习写操作（定义 276-i）与证据纪律（定义 293-iii）；
(ii) **未知非自由**：任何 `U`（unknown）体素不得被并入已认证自由空间，安全膨胀必须覆盖深度噪声；
(iii) **信息-风险联合认证**：视点动作 `g_move` 与任务动作共享控制自由度，必须作为同一条轨迹联合优化并联合过安全认证；
(iv) **严格退化链**：遮挡为空且禁用视点动作时 PARALLAX 逐指令等于 FLUID-RAS（R69）；再令 VoI ≤ 成本则逐指令等于 CALM-RAS（R68）——安全侧单调不降。

**定义 311（深度观测与有效性）** 观测 `o_t^D = (D_t, C_t, T_t, τ_t)`：深度图 `D`、置信图 `C`、相机位姿 `T`、时间戳 `τ`。有效掩码 `V = {u : C(u) > c_min ∧ z_min ≤ D(u) ≤ z_max ∧ ¬饱和}`。**无效点一律记为 U（未知），绝不记为 F（自由）。** 测距误差模型（三角/立体）：`σ_z(z) = (z² / (f·b))·σ_d ⊕ ε_sys`，其中 `f` 焦距、`b` 基线、`σ_d` 视差误差、`ε_sys` 系统项。

**定义 312（三态占据与遮挡边界）** 每个体素 `x` 取态 `S(x) ∈ {F, O, U}`（自由/占据/未知）。遮挡边界 `B_t = ∂(V ∩ 可见) ∩ U`，即"可见面片与未知区"的交界。`B_t` 同时包含"被物体挡住"与"传感器失效"两类——二者都不得当自由，但可由 PGD 区分（定义 319）。

**定义 313（动态出没通道 ECP）** 对每个边界元 `b ∈ B_t` 与时间窗 `τ`，定义出没概率 `p_em(b, τ) = P(障碍经 b 进入可见区且在 τ 内抵达 ego 路径)`。由时空视差线索估计：深度流的散度、边界法向方向的亮度/深度流不连续、以及边界外侧的历史运动外推。出没通道是"世界将要改变"的先验位置——计算与注意力应集中于此，而非均匀铺满全图。

**定义 314（视点动作与增广动作，扩定义 294）** 视点动作 `g_move = (Δpose, v, T_dwell) ∈ 𝒜_view`；增广动作 `ξ = (a, g, g_move)`。关键：`g_move` 与任务动作共享同一控制自由度，只是目标不同（信息 vs 任务）。因此不能把"信息动机的位移"当成零风险旁观量——它是同一条轨迹的一部分。

**定义 315（视差信息增益 VoI_view）** `VoI_view(Δpose) = H(occ(U)) − E_{y~p(·|Δpose,o)}[H(occ(U) | Δpose, y)]`。小角度近似：`VoI_view ≈ ∫_{V_new(Δpose)} h_U(x) dx − c_par(Δpose)`，其中 `V_new` 为换视点后新增可见体积、`h_U` 为未知区占据熵密度。由三角关系 `|V_new| ∝ ℓ_occ · |Δpose|`（`ℓ_occ` 为边界可见长度），故 `∂VoI_view/∂|Δpose| |_{0+} > 0`、在 `Δpose=0` 处为 0——**静止时视差增益恒为零**。

**定义 316（遮挡感知 CBF，OCBF）** 设 `d_free(x)` 为到"已知自由边界（不含 U）"的距离，`d_stop(v) = v²/(2a_brake) + v·t_react`，深度膨胀 `δ_d(z) = k_σ·σ_z(z)`。定义 `h_occ(x) = d_free(x) − d_stop(v) − δ_d(z)`。安全集 `S = {h_occ ≥ 0}`；控制须满足 `ḣ_occ + α·h_occ ≥ 0`。**未知区被当作障碍膨胀，而非自由。**

**定义 317（深度噪声-速度耦合界）** 由定义 316 与引理 20，`v ≤ v_max^depth(z) = sqrt(2·a_brake·(d_obs(z) − δ_d(z)))`。距离越远、深度越噪、系统项越大，允许速度越低。这是深度相机物理直接进入安全约束的通道。

**定义 318（速度-视差优化 SPO）** `v* = argmax_{v ∈ [0, v_OCBF]} [ λ_vis·Ṙ_vis(v) − λ_risk·Ṙ_risk(v) ]`，其中揭示率 `Ṙ_vis(v) ∝ v·ℓ_occ`，风险率 `Ṙ_risk(v) ∝ v²·ρ_U / d_free`。**硬约束 `v ≤ v_OCBF` 由 OCBF 给出，SPO 只在其内部做取舍。** 该目标一般非单调，存在内点最优（见定理 19）。

**定义 319（视差-几何对偶 PGD）** 两条独立通道：几何通道 `r_geo`（R68 的几何残差）与时序视差通道 `r_par`（由光流反推的"深度诱导流"与实际观测流之差）。`Δp = |r_geo − r_par|`。当深度判"自由"但光流显示有运动的闭合轮廓时，`Δp` 升高——捕捉透明/反光/动态遮挡等"深度自信地错"的失效。类比 R69 的 `Δa`（定义 301），但观测对象从"行为自洽"变成"几何-时间自洽"。

**定义 320（深度有效性门 DVG 与标定门 DCG）** DVG：透明/镜面/吸光/稀疏/强光/多机干扰 → 膨胀为 U；若无效比例 `|¬V|/|Ω| > τ_inv`，直接进入保守模式。DCG：深度-光流一致性校准误差 `ECE_d > τ_d` ⇒ 禁用 SPO，仅保留 OCBF 的最保守速度 `v_max^depth`，并禁止任何以"视差增益"为由的加速。

**定义 321（出没预警窗与硬约束）** 对边界元 `b`，`T_warn(b) = g_ext(b) / v_obs,max`，`g_ext` 为障碍出没后到抵达 ego 路径需跨越的自由间隙。可行性要求 `T_warn(b) ≥ t_react + t_lat + margin`。若某 `b` 违反，则该边界为"盲出没"，对应轨迹不得依赖"及时看见"——必须预先减速或改道（把不等式转为速度/路径约束）。

**定义 322（信息-风险联合预算，扩定义 293-ii / IP-258）** 统一预算：视点位移 `|Δpose| ≤ ε_v`、驻留 `T_dwell ≤ T_dwell,max`，且每个 `g_move` 必须同时通过 OCBF 与联合认证；**VoI 只在 OCBF 可行轨迹集合上计算**（反事实若不安全则其 VoI 无定义）。

**定义 323（审计与证书 J_PARALLAX）** `J_PARALLAX = (J_FLUID, visibility_map_hash, occlusion_assumption, emergence_ece, depth_validity_ratio, v_star, v_OCBF, T_warn_min, pgd_score)`。Valid ⇔ Valid(J_FLUID) ∧ DVG/DCG 通过 ∧ OCBF 有解 ∧ 出没预警窗全部满足。

**定义 324（遮挡干扰集 ℰ_occlusion）** 对抗性出没（故意躲在遮挡后突然窜出）、深度欺骗（投影/激光注入假障碍或抹除真障碍）、透明/反光/吸光面、移动遮挡物（窗帘/车门）、延迟注入。并入：`ℰ_PARALLAX = ℰ_FLUID × ℰ_occlusion`。

**定义 325（退化边界）** 遮挡为空（`U ∩ 前方走廊 = ∅`）且 `g_move` 禁用 ⇒ 逐指令等于 FLUID-RAS；再令 `VoI ≤ 成本`（定义 298）⇒ 逐指令等于 CALM-RAS（R68）。安全侧因 OCBF 硬约束而单调不弱于 R69。

## 2. 关键算法骨架

```python
# IP-264 DVG：深度有效性门（透明/反光/稀疏/失效 → 未知，绝不当自由）
def depth_validity_gate(D, C, pose):
    V = (C > C_MIN) & (D > Z_MIN) & (D < Z_MAX) & (~saturated(D))
    U = ~V                                   # 无效点一律未知
    if U.mean() > TAU_INV: mode = CONSERVATIVE
    sigma = lambda z: (z*z/(f*b))*SIGMA_D + EPS_SYS
    return V, U, sigma, mode

# IP-265/266 TOP+ECP：三态占据 + 出没通道预测
def trichotomy_and_emergence(D, V, U, flow, pose_hist):
    S = fuse_occupancy(D, V)                 # {F, O, U}
    B = occlusion_boundary(S, U)             # 可见面片 ∩ 未知
    p_em = predict_emergence(D, flow, B, pose_hist)   # b, tau -> 概率
    return S, B, p_em

# IP-267 PAV：视差主动视角（VoI 只在 OCBF 可行轨迹上算）
def parallax_viewpoint(S, B, p_em, budget, ocbf):
    best = None
    for g in viewpoint_candidates(B, budget):        # 侧身/减速/绕行/驻留
        if not ocbf.feasible(g): continue            # 信息动作必须是安全轨迹
        voi  = expected_revealed_volume(B, g) - parallax_cost(g)
        if best is None or voi > best.voi: best = (g, voi)
    return best if best and best.voi > 0 else None   # 无收益 → 不移动（退化 R69）

# IP-268/269 OCBF+SPO：安全速度上界 + 非单调速度-视差优化
def safe_speed(d_free, z, v_ocbf, ell_occ, rho_U, lam):
    v_max = min(v_ocbf, sqrt(2*a_brake*max(0.0, d_free - k_sigma*sigma_z(z))))
    # 内点最优：揭示率 ∝ v·ell，风险率 ∝ v^2·rho/d
    v_star = lam * ell_occ * d_free / (2.0*rho_U + EPS) if rho_U > 0 else v_max
    return max(0.0, min(v_star, v_max))              # 硬约束优先，绝不突破 v_max

# IP-270 PGD：视差-几何对偶第二意见
def parallax_geometry_dual(D, flow, r_geo):
    flow_pred = depth_induced_flow(D)                # 深度诱导流
    r_par = residual(flow, flow_pred)
    return abs(r_geo - r_par)                        # 高 → 透明/动态/欺骗疑

# IP-276 主闭环（继承 R69，仅在不确定性与安全处插入 PARALLAX 层）
def PARALLAX_RAS_round(M, obs):
    V, U, sigma, mode = M.dvg.gate(obs.D, obs.C, obs.pose)
    S, B, p_em = M.top.predict(obs.D, V, U, obs.flow, obs.pose_hist)
    # 1) 第二意见：几何-时间自洽（标定/流似然都吸收不了的失效）
    pgd = M.pgd.score(obs.D, obs.flow, M.last_r_geo)
    depth_suspect = pgd > TAU_PGD
    # 2) 退化决策：是否值得为"看见"而移动（且移动必须安全）
    g = None
    if (B.size > 0 and not depth_suspect and mode != CONSERVATIVE):
        g = M.pav.plan(S, B, p_em, M.budget, M.ocbf)
    # 3) OCBF 硬安全：未知按最坏情况膨胀，绝不并入自由
    h = M.ocbf.margin(S, U, obs.v, obs.z)
    v_max = M.spo.safe_speed(d_free=S.d_free, z=obs.z, v_ocbf=h.v_bound,
                             ell_occ=B.length, rho_U=U.density, lam=M.lam)
    if depth_suspect or mode == CONSERVATIVE:
        v_max = min(v_max, M.spo.conservative_bound(obs.z))   # 回最保守
    # 4) 出没预警窗硬约束：看不见的必须来得及反应
    for b in B:
        if M.ecp.T_warn(b) < t_react + obs.t_lat:
            v_max = min(v_max, M.ecp.speed_for_warning(b))    # 盲出没不可依赖
    # 5) 执行：任务动作 + 视点动作 + 速度界，统一认证
    traj = M.policy.propose(obs, v_max, g)
    k    = M.c_ras_wm.certified_prefix(traj, ..., wm_preds)
    # 6) 审计 + 证书
    M.vqa_o.submit_async(g, pgd, B, p_em, v_max)
    return k, v_max, traj, (B, p_em, pgd)
```

## 3. 推导

**引理 19（遮挡的视差不可约性——第三种不确定性）** 固定视点时，遮挡体积与观测量在给定视点下条件独立，故 `I(occ(U); y | pose) = 0`，任何驻留/标定/询问都不能增加它；而换视点 `Δpose` 后新增可见体积 `|V_new| ∝ ℓ_occ·|Δpose|`，于是 `∂I(occ(U); y)/∂|Δpose| |_{0+} > 0`。**故 U_occ 既非 aleatoric（可减但非靠平均），也非 R69 的 U_epi^ask（可由询问/标定消解），而是"视角可约"的第三类。** 系：R69 的二分在本轮严格细化为三分 `U = (U_ale, U_epi^ask, U_occ)`，且三者的合法消解动作互不相同（平均/询问/移动）。

**引理 20（深度噪声-距离律）** 三角测距 `z = f·b/d`，由误差传播 `σ_z = (z²/(f·b))·σ_d`，且叠加系统项 `ε_sys`。故远处自由空间的置信半径随 `z²` 增长，`d_eff(z) = d_obs(z) − k_σ·σ_z(z)` 单调收缩。系：**同一障碍在远处"看起来更安全"是错觉**——深度噪声恰在远处最大，安全速度必须随距离下降（定理 19 的输入）。

**引理 21（OCBF 充分安全速度界）** 若把未知按最坏情况视为障碍、ego 可用减速度 `a_brake` 制动，则"永不在未知/占据区内停下前越界"的充分条件是 `v ≤ sqrt(2·a_brake·(d_free − δ_d))`。这是充分非必要界（保守）。结合引理 20 得 `v_max^depth(z)`，即定义 317。

**引理 22（出没预警窗下界）** 设动态障碍最大速度 `v_obs,max`，出没后需跨越的自由间隙 `g_ext` 才触及 ego 路径，则从"首次可见"到"抵达路径"的时间 `T_warn = g_ext / v_obs,max`。若 `T_warn < t_react + t_lat`，则即使看见也已来不及——**"看见"不再是充分信息**。此时必须预减速或改道，把盲出没转化为速度/路径约束（定义 321）。

**定理 18（PARALLAX 严格包含 FLUID 与 R68）** 在 A99–A104 下，PARALLAX 在任意状态的期望风险 ≤ FLUID-RAS ≤ CALM-RAS；且当遮挡为空、视点动作禁用时逐指令等于 FLUID-RAS，再令 `VoI ≤ 成本` 时逐指令等于 R68。安全侧因 OCBF 为硬约束、未知按最坏情况膨胀而单调不弱；效率侧仅在"可安全揭示"时获得视差收益。**新层是旧层的严格泛化，而非并列替代。**

**定理 19（速度-视差非单调与内点最优）** 在 `Ṙ_vis(v)=c₁·v·ℓ_occ`、`Ṙ_risk(v)=c₂·v²·ρ_U/d_free` 下，SPO 目标对 `v` 严格凹，内点最优 `v* = c₁·ℓ_occ·d_free/(2·c₂·ρ_U)`，并被硬约束截断为 `min(v*, v_OCBF)`。于是：(a) `v*` 随未知密度 `ρ_U` 单调不增（越遮挡越该慢）；(b) 但在低遮挡区 `v*` 可以**大于** R68 的纯保守速度——因为加速缩短了暴露时间、并快速揭示前方体积。**故"越不确定越慢"不是普遍规律，只是高遮挡密度下的局部结论**，这正面修正 R68 的单调 λ 铁律。

**定理 20（信息-风险不可分，联合认证必要）** 由于 `g_move` 与任务动作共享控制自由度，存在场景使 `argmax_g VoI(g) ∉ S`（定义 316），而"先选最大 VoI 的视点动作、再投影到安全集"得到的动作 `Π_S(g*)` 有 `VoI(Π_S(g*)) = 0`（位移被削到无法产生视差）；同时存在联合可行解 `g'∈S` 满足 `VoI(g') > 0`。故**解耦式"先信息后安全"可严格劣于联合优化**，甚至不可行。这是 R69 所没有的新结论：当信息动作与风险动作同源时，`VoI` 必须在安全集内定义。

## 6. 本轮最大风险

**一句话**：PARALLAX-RAS 的全部安全性都押在"未知被正确识别为未知"上——**一旦深度相机把透明/反光/远处稀疏或被动态遮挡的物体误判为"已知自由"，OCBF 的未知膨胀就会静默失效，系统会以"已被认证"的速度自信地撞上唯一没看见的东西；看漏，比看不见更危险。**

**次级风险与缓解**：
1. **深度相机的"自信地错"**（玻璃/镜面/吸光/稀疏/强光）→ DVG 无效即未知 + PGD 视差-几何对偶 + DCG 标定门（失效即禁 SPO 加速）；
2. **SPO 被优化器钻空子**（为"揭示更多"而加速）→ SPO 只能在 OCBF 硬约束内搜索，`v_OCBF` 为不可越过的上界（定理 19）；
3. **出没预测失准导致预警窗虚高** → 定理 21/定义 321 用 `v_obs,max` 最坏情况计算，ECE 越界进保守；
4. **视点动作本身不安全** → 信息-风险联合认证（定理 20），VoI 仅在 OCBF 可行集上定义；
5. **实时预算被三态占据/ECP 击穿** → 近场体素 + 边界稀疏化 + 下采样 DVG，P99 < 2.2ms；预算越界即退化为"只减速不侧身"的 R69 边界。

# IP-264 DVG：深度有效性门（无效即未知，绝不当自由）
def depth_validity_gate(D, C):
    V = (C > C_MIN) & (D > Z_MIN) & (D < Z_MAX) & (~saturated(D))
    sigma = lambda z: (z*z/(f*b))*SIGMA_D + EPS_SYS
    return V, ~V, sigma, (CONSERVATIVE if (~V).mean() > TAU_INV else NORMAL)

# IP-265/266 TOP+ECP：三态占据 + 出没通道
def trichotomy_and_emergence(D, V, U, flow, pose_hist):
    S = fuse_occupancy(D, V)                    # {F, O, U}
    B = occlusion_boundary(S, U)
    return S, B, predict_emergence(D, flow, B, pose_hist)

# IP-267 PAV：视差视角（VoI 只在安全轨迹上算）
def parallax_viewpoint(S, B, p_em, budget, ocbf):
    best = None
    for g in viewpoint_candidates(B, budget):
        if not ocbf.feasible(g): continue       # 信息动作必须是安全轨迹
        voi = expected_revealed_volume(B, g) - parallax_cost(g)
        if best is None or voi > best.voi: best = (g, voi)
    return best if best and best.voi > 0 else None    # 无收益 → 退化 R69

# IP-268/269 OCBF+SPO：安全上界 + 非单调最优（硬约束优先）
def safe_speed(d_free, z, v_ocbf, ell_occ, rho_U, lam):
    v_max = min(v_ocbf, sqrt(2*a_brake*max(0.0, d_free - k_sigma*sigma_z(z))))
    v_star = lam*ell_occ*d_free/(2.0*rho_U + EPS) if rho_U > 0 else v_max
    return max(0.0, min(v_star, v_max))

# IP-270 PGD：视差-几何对偶
def parallax_geometry_dual(D, flow, r_geo):
    return abs(r_geo - residual(flow, depth_induced_flow(D)))

# IP-276 主闭环（继承 R69）
def PARALLAX_RAS_round(M, obs):
    V, U, sigma, mode = M.dvg.gate(obs.D, obs.C)
    S, B, p_em = M.top.predict(obs.D, V, U, obs.flow, obs.pose_hist)
    pgd = M.pgd.score(obs.D, obs.flow, M.last_r_geo)
    suspect = pgd > TAU_PGD
    g = (M.pav.plan(S, B, p_em, M.budget, M.ocbf)
         if (B.size > 0 and not suspect and mode != CONSERVATIVE) else None)
    h = M.ocbf.margin(S, U, obs.v, obs.z)
    v_max = M.spo.safe_speed(S.d_free, obs.z, h.v_bound, B.length, U.density, M.lam)
    if suspect or mode == CONSERVATIVE:

    for b in B:                                  # 盲出没 ⇒ 预减速/改道

            v_max = min(v_max, M.ecp.speed_for_warning(b))
    traj = M.policy.propose(obs, v_max, g)
    k = M.c_ras_wm.certified_prefix(traj, ..., wm_preds)
    M.vqa_o.submit_async(g, pgd, B, p_em, v_max)
    return k, v_max, traj, (B, p_em, pgd)

## 4. 推导

**引理 19（遮挡的视差不可约性）** 固定视点下 `I(occ(U); y | pose) = 0`，驻留/标定/询问均无法增加；换视点后 `|V_new| ∝ ℓ_occ·|Δpose|`，故 `∂I/∂|Δpose| |_{0+} > 0`。⇒ 存在第三类不确定性 `U_occ`（视角可约），R69 的二分细化为三分 `(U_ale, U_epi^ask, U_occ)`，三者合法消解动作分别为平均 / 询问 / 移动。

**引理 20（深度噪声-距离律）** `z = f·b/d` ⇒ `σ_z = (z²/(f·b))σ_d`；`d_eff(z) = d_obs − k_σ σ_z(z)` 随距离单调收缩。⇒ 远处"看起来更安全"是错觉，安全速度须随距离降（喂给定理 19）。

**引理 21（OCBF 充分安全速度界）** 未知按最坏情况当障碍、可制动减速 `a` 时，`v ≤ sqrt(2a(d_free − δ_d))` 可保证不在越界前停下。得 `v_max^depth(z)`。

**引理 22（出没预警窗下界）** `T_warn = g_ext / v_obs,max`；若 `T_warn < t_react + t_lat`，看见也已来不及，必须预减速/改道。把遮挡几何转成硬约束。

**定理 18（串行严格包含）** PARALLAX ≤ FLUID ≤ CALM-RAS（期望风险）；遮挡为空且禁视点动作时逐指令等于 FLUID，再令 `VoI ≤ 成本` 时逐指令等于 R68。安全侧单调不弱，效率侧仅获"可安全揭示"的视差收益。

**定理 19（速度-视差非单调）** `Ṙ_vis = c₁vℓ`、`Ṙ_risk = c₂v²ρ/d` 下目标严格凹，`v* = c₁ℓd/(2c₂ρ)`，截断 `min(v*, v_OCBF)`；`v*` 随 `ρ_U` 单调不增，但低遮挡区可高于 R68 纯保守速度。⇒ "越不确定越慢"仅为高遮挡密度下的局部结论，修正 R68 单调 λ。

**定理 20（信息-风险不可分）** `g_move` 与任务动作同源，存在 `argmax VoI ∉ S`；"先选 VoI 再投影到安全集"可得 `VoI(Π_S g*) = 0`，而联合可行解 `g'∈S` 有 `VoI(g') > 0`。⇒ 解耦式"先信息后安全"可严格劣于联合优化（R69 无此结论）。

## 7. 本轮最大风险

**一句话**：PARALLAX-RAS 的全部安全性都押在「未知被正确识别为未知」上——**一旦深度相机把透明/反光/远处稀疏或被动态遮挡的物体误判为"已知自由"，OCBF 的未知膨胀会静默失效，系统将以"已被认证"的速度自信地撞上唯一没看见的东西；看漏，比看不见更危险。**

**次级风险与缓解**：深度相机"自信地错"（DVG 无效即未知 + PGD 对偶 + DCG 校准门）；SPO 被优化器钻空子（`v_OCBF` 硬上界，定理 19）；出没预测失准（按 `v_obs,max` 最坏情况算预警窗，ECE 越界进保守）；视点动作自身不安全（定理 20 联合认证）；实时预算被击穿（近场体素 + 下采样 + 预算越界退化 R69 边界）。
