# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「迁移学习」×「仿真到现实迁移」）

> R69 教会系统「去问」：把不确定性拆成 aleatoric 与 epistemic，前者收紧、后者用流匹配多模态策略显形，再以注视/探针/问句主动消解，并用流似然做标定不可吸收的第二意见。它回答的是「**我该向谁求证、还能问什么**」。但 R69 有一个它自己无法审计的前提：**它据以提问、据以生成、据以标定的全部先验知识，是在「这里」学到的吗？** 流策略训练用的仿真分布、标定用的历史数据、模态权重背后的任务先验，全都来自「别处」。R69 把「我的测量还准吗」（R68）和「我该问谁」（R69）都问了，却没问最根本的一句：**「我这条经验，凭什么适用于此刻此地？」**
>
> 两个灵感正好刺中两层盲点：
> - **迁移学习**：知识不是一整块模型，而是一束**可分离的单元**（表征 / 动力学 / 执行器 / 语义 / 不确定性 / 安全契约 / 交互先验）。每个单元的可迁移性不同，**负迁移（negative transfer）恰恰来自「把不该搬的单元也搬了」**。所以正确的动作不是「迁移 or 不迁移」，而是**逐单元签发可迁移性证书**。
> - **仿真到现实迁移**：sim-to-real 的间隙不是一个标量，而是一个**物理参数的后验集合**（质量、摩擦、电机参数、延迟、传感/渲染偏差）。仿真只是「关于现实的一个先验」，现实是「用少量干预条件化后的后验」。在辨识之前，唯一诚实的做法是对**整个间隙管**做鲁棒；而辨识本身，正是 R69 信息动作在物理域的延伸——**探针也是一种提问，只不过问的是身体和世界，而不是人**。
>
> 核心命题：**不确定性除了「大小」（R68）与「可约性」（R69），还有「可迁移性」（transportability）。把先验分解为知识单元，逐单元用「适用域 + 条件不变性 + 间隙后验」签发证书；只让获证单元进入实时信任集，未证单元一律冻结或弃权；用 anytime-valid 的 e-process 在线否决负迁移并回滚；把 sim-to-real 间隙写成可辨识后验，用主动探针收缩、用鲁棒安全包络兜底；当迁移净收益 ≤ 0 时，最优动作是「不迁移」。** 命名 **MIGRATE-RAS**（Multisource, Interactive, Gap-aware, Risk-Adaptive Transfer Engine for RAS）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我的经验从哪来、哪一部分还适用于这里、我凭什么相信它**」——**迁移的自信，比不迁移的无知更危险。**

## 0. 直觉与动机

**灵感 1（迁移学习 → 迁移的单位不是模型，而是可分离的不变量）**
直觉：人从自行车迁移到摩托车，迁移的是「平衡靠转向」这条不变量，而不是「脚怎么蹬」这条源域技能。深度迁移里，底层特征可迁、任务头不可迁；机器人里，物理定律可迁、具体摩擦系数不可迁；语言里，语义可迁、具体指称不可迁。**负迁移几乎总是因为把「源域特有的偶然性」当成「跨域必然的不变量」搬了过去。** 所以 R70 的第一个动作是**拆**：把 R69 的 `θ_S` 拆成带类型与来源的知识单元，对每个单元问三件事——它在目标域**落在支撑内吗**（适用域）、它在目标域的**条件关系还一样吗**（条件不变性）、它在物理间隙的哪些取值下**仍然成立**（间隙后验）。三问全过才发证书。这等于把「迁移学习」从一次训练技巧升级为一条**运行时准入制度**。
关键反面：适用域通过而条件关系变了，就是**概念漂移**——输入分布一样，`p(动作|输入)` 变了。这是最阴险的负迁移，因为只看输入的密度比、支撑重叠、域分类器 AUC，全都会放行。

**灵感 2（仿真到现实 → 间隙是一个集合，不是一个数；辨识是一次安全的干预）**
直觉：说「sim-to-real gap 是 0.3」没有物理意义。真正有意义的是 `m∈[2.1,2.4]kg, μ∈[0.4,0.7], R_s∈[0.11,0.14]Ω, τ_delay∈[8,20]ms` 这样一个**可行集**。仿真不是现实，它是现实的一个**先验分布**；域随机化不是「让策略见过所有现实」，而是「把先验铺宽到覆盖可能的现实」。部署时用极少量真实数据把它**条件化**成后验，后验的 credible set 直径就是间隙的大小。辨识之前不敢说安全，就只能在**整个 credible set** 上做鲁棒；辨识之后集合收缩，才敢放松。更关键：收缩需要**持续激励**——被动地看，很多参数根本不可辨识（匀速直线运动无法把摩擦与阻尼分解开）。所以「向现实学习」必须**主动做实验**，而实验有磨损、有安全边界、有社交成本。这把 R69 的「看/问/触」扩展成**「激励/换载/试探」**：同样的 value-of-information，只是被问的对象变成了物理身体与仿真模型。

**灵感 3（二者相乘 → 迁移净收益 = 源样本优势 − 间隙惩罚 − 适应成本）**
直觉：迁移之所以有用，是因为源域样本多、覆盖广，能降低方差；之所以有害，是因为源-目标偏差引入偏差。于是存在一个**结构性的盈亏平衡点**：`NB = B_source − D_gap − c_adapt`。源数据越多、间隙越小、适应越便宜，迁移越值；反之，**不迁移（ABSTAIN）才是最优**。这解释了为什么工程上「先在一个域训好再用」有时神效、有时灾难：不是方法好坏，而是 NB 的符号。R70 要做的不是「永远迁移」，而是**在运行时估计 NB 的符号，并据此选择冻结/残差/重辨识/重训/弃权**。这与 R69「VoI ≤ 成本就不问」完全同构：R69 让「不问」成为一等公民，R70 让「不迁移」成为一等公民。

**灵感 4（负迁移必须有一票否决，而且必须 anytime 有效）**
直觉：性能目标会诱惑系统「先迁了再说」。所以负迁移检测不能是离线报表，而必须是**有否决权、任意时刻有效、可回滚**的在线证据过程。用 e-process / confidence sequence，可以在不预设样本量的情况下保证「曾经错误采纳负迁移策略」的概率 ≤ α；一旦证据反转立即回滚到上一个已证快照。这把 R69 的「证据纪律」从「多个证据源一致才定案」推进为「迁移这份先验本身必须持续自证，且可被随时撤职」。
为什么必须是**硬否决**而非软惩罚：因为存在**概念漂移且任务收益很高**的场景，任何有限软惩罚都会在收益足够大时被优化器交易掉；「不迁移」这条边界只能由约束守，不能由奖励守（对应 R69 的 MCG 门也是硬门）。

**灵感 5（安全与遗忘 → 迁移中最不能迁的，恰恰是最该冻结的）**
直觉：表征、动力学残差可以慢慢适应；但**安全契约**与**语义接地**一旦悄悄漂移，后果不可逆——安全包络在源域成立，不代表在目标域成立；「停」在源域表示急停，在目标域可能不是。所以引入**塑性图谱**：不同单元有不同学习率与写预算，安全/语义默认 `p=0`（冻结，只允许人工重绑定），所有更新必须在**间隙管上保持安全证书不回退**，并留可回滚快照。这继承 R68/R69「实时零学习写操作」，把学习严格推到中/慢环：**实时环只读证书，不写知识。**

**灵感 6（最深的陷阱 → 支撑重叠 ≠ 可迁移）**
直觉：域适应文献最容易被误用的结论是「只要目标落在源支撑内就能迁移」。这仅对协变量漂移成立。真实世界里更常见的是**概念漂移**：同一个观测在源域对应动作 A，在目标域对应动作 B（换了操作者意图、换了任务规则、换了物体刚性）。此时密度比、MMD、域分类器都可能漂亮地通过，而策略在目标域系统性犯错。**识别概念漂移必须靠干预或目标侧反馈，不能靠被动观测。** 这条判据直接决定本轮最大的风险：一个只做被动可迁移性认证的系统，会以「已验证」的姿态自信地负迁移。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（MIGRATE-RAS 总览）** MIGRATE-RAS = (TKG, TCG, NTV, GAP, S2R-Probe, DRS, PAR, SIR, TBA, VQAuditor-T, RAS-WM‡)。四不变式：
(i) **实时零学习写操作**（继承 R68 定义 276-i / R69 定义 293-i）：实时环只读证书与参数，任何写/更新都在中环或慢环；
(ii) **单元级准入**：知识按单元分解，任一单元的可迁移性未获证前不得进入实时信任集；未证单元的默认处置是「冻结 + 保守」，不是「平均一下」；
(iii) **负迁移否决权高于性能目标**：任何迁移或更新若未通过 anytime-valid 负迁移检验或使安全证书回退，必须回滚；
(iv) **证书按单元独立签发**：禁止用「整体模型平均分高」掩盖某一关键单元（执行器、安全包络、语义）的失效。

**定义 311（迁移知识单元 TKG）** 把先验知识 `θ_S` 分解为单元集合 `K={κ_i}`，每单元带类型：
`κ^R` 表征（编码器/感知特征）、`κ^D` 动力学（`f`、摩擦、质量、接触）、`κ^E` 执行器（电机 `R_s/L/ψ_f`、延迟、齿隙）、`κ^S` 语义（任务/目标/语言接地）、`κ^U` 不确定性（模态权重、噪声尺度、校准）、`κ^C` 安全契约（包络、CBF、限幅）、`κ^I` 交互先验（VoI 成本、社交/物理预算）。
`θ_S = ⊕_i θ^{(i)}`。每单元携带来源标签 `src(i)⊆𝒮`、版本 `ver(i)`、以及可选的迁移算子（定义 312）。

**定义 312（迁移算子菜单）** 对单元 `i` 选择 `φ_i ∈ Φ = {FROZEN, RESIDUAL, REIDENT, REWEIGHT, REBIND, RETRAIN, ABSTAIN}`：
- `FROZEN`：`θ_t^{(i)}=θ_S^{(i)}`，仅当证书全通过；
- `RESIDUAL`：`θ_t=θ_S+Δθ`，`Δθ` 小容量、带校准不确定性、域外自动归零；
- `REIDENT`：用目标域数据重新辨识物理参数（贝叶斯系统辨识）；
- `REWEIGHT`：保留源模型，按密度比 `w(o)=p_t(o)/p_S(o)` 重加权或拒绝采样；
- `REBIND`：重新接地符号/标签/角色（语义重绑定，只允许慢环 + 人工确认）；
- `RETRAIN`：目标域重训（仅离线、可回滚、带遗忘防护）；
- `ABSTAIN`：不迁移，直接使用兜底策略。
`φ` 的选取是带约束的优化：`max E[迁移收益]  s.t.  负迁移风险 ≤ α,  安全证书不回退,  写预算 ≤ b`。

**定义 313（可迁移性证书 TCG）** 对单元 `i`，证书 `C_i = (AD_i, CI_i, G_i, n_i)`：
- `AD_i`（适用域）：`AD_i = P_{o~P_t}[ r_i(o) ≤ τ_ad ]`，`r_i(o)=log p_t(o)/p_S(o)`，或单类/支撑估计；
- `CI_i`（条件不变性）：检验 `p_t(a|o)`（或 `p_t(y|o)`）是否与源一致，统计量可用核条件矩检验 `sup_{φ∈ℱ_i} |E_{P_t}[φ(o)(a−μ_S(o))]|`；**必须包含干预/目标反馈数据，否则只能给出「未判定」而非「通过」**（引理 19）；
- `G_i`（间隙后验投影）：物理间隙后验（定义 314）在该单元上的 credible set 直径；
- `n_i`：等效目标样本量（含主动探针折算）。
`Valid(C_i) ⇔ AD_i ≥ α_ad ∧ CI_i 未拒绝 ∧ diam(G_i|_i) ≤ ε_i ∧ 该单元安全证书在 𝒢_ε 上成立`。

**定义 314（仿真到现实间隙模型 GAP）** 真实动力学 `f_t(x,u) = f_S(x,u;ξ) + δ(x,u)`，其中 `ξ~(p(ξ))` 为域随机化先验（质量、摩擦、阻尼、电机参数、延迟、传感/渲染/接触参数），`δ` 为结构性残差。由真实数据 `D_t={(x,u,x')}` 经 SBI/ABC/变分得到联合后验 `p(ξ,δ|D_t)`；定义间隙管 `𝒢_ε = {ξ : p(ξ|D_t) ≥ ε}`（HPD 集）。**关键**：只有**持续激励**的目标数据才显著收缩 `𝒢`；被动数据在不可辨识方向上几乎不收缩（引理 21）。

**定义 315（主动间隙探针 S2R-Probe）** 在 R69 增广动作空间上加入信息动作 `g_id`（小幅激励、变负载、多方向试探），以间隙参数的互信息为目标：
`g* = argmax_g [VoG(g) − c_wear(g) − c_social(g)]`，`VoG(g)=H(ξ|D_t) − E_{y~p(·|g)}H(ξ|D_t∪{y})`。
探针必须过 C-RAS-WM 认证（R69 定义 302）、共享交互预算、满足持续激励的安全幅度/频率约束，并遵守「单次探针不得单独定案」的证据纪律。

**定义 316（间隙鲁棒安全包络 DRS）** 对候选动作 `a`，安全证书必须 `∀ξ∈𝒢_ε` 成立：
`safe(a) ⇔ min_{ξ∈𝒢_ε} h(x,a;ξ) ≥ 0`，`h` 为 CBF / 可达性裕度。若 `𝒢_ε` 太大导致不可行：先主动收缩，再降额（derate）；仍不可行则不执行。

**定义 317（负迁移否决 NTV）** 设损失 `ℓ∈[0,1]`、兜底策略 `π_∅`、迁移策略 `π_T`。构造任意时间有效的 e-process
`E_t = ∏_{s=1}^t (1 + λ_s(ℓ_∅(s) − ℓ_T(s) − μ_0))`（或 betting e-process），零假设 `H_0: E[ℓ_T] ≤ E[ℓ_∅]`（不优于兜底）。当 `E_t ≥ 1/α` 采纳迁移；一旦新样本使证据反转，立即回滚。由 Ville 不等式，`P(∃t: 采纳了负迁移策略) ≤ α`。`μ_0` 为要求的最小收益（margin），用于抑制无差异时的来回横跳。

**定义 318（塑性分配与回滚 PAR）** 每单元有塑性 `p_i∈[0,1]` 与写预算 `b_i`：
- 快环 `p_i=0`（实时零写）；
- 中环（任务后）允许小 `p_i`，须过 NTV 且 `KL(π_new‖π_old) ≤ ε_kl`；
- 慢环（维护窗/人工）允许 `REIDENT/RETRAIN/REBIND`，须离线验证 + 回滚快照；
- `κ^C, κ^S` 默认 `p=0`（安全与语义冻结），只允许人工 `REBIND`；
- 每次更新产生 `(版本, 证书 hash, 快照 id)`，支持原子回滚。

**定义 319（源选择与源可靠性 SIR）** 多源 `𝒮={仿真变体, 历史机器人, 他机数据, 公开数据}`。源权重 `w_s` 由**目标域验证集**上的 stacking/regret 估计，而非源内验证；若某源在目标上不可辨识（支撑不交或标签漂移），权重衰减至 0（源淘汰）。防投毒：任一源不得凭单源证据获得高权重（继承 R69 证据纪律）。

**定义 320（协变量漂移 vs 概念漂移判别）** 令 `D_cov = d(P_t(o), P_S(o))`（边缘差异），`D_con = CI_i`（条件差异）。判别：
- `D_cov` 大、`D_con` 小 ⇒ 协变量漂移，可用 `REWEIGHT/RESIDUAL`；
- `D_cov` 小、`D_con` 大 ⇒ **概念漂移**，禁止 `FROZEN`，只能 `REBIND/RETRAIN/ABSTAIN`；
- 两者都大 ⇒ 双重漂移，默认 `ABSTAIN + 主动探针`。
**这是本轮最关键的判别**：R69 的残差/似然通道只能看「输入是否异常」，看不到「输入到动作的条件关系是否变了」。

**定义 321（迁移预算与收益分解 TBA）** 设目标样本 `n_t`、间隙 `D_gap`、源样本优势 `B_source`、适应成本 `c_adapt`：
`NB = B_source − D_gap − c_adapt`；期望超额风险 `≤ O(√(C/n_t)) − B_source + D_gap`（目标域单训为第一项）。当 `NB ≤ 0` 选择 `ABSTAIN`。TBA 在「交互（R69 MINT）/ 辨识（S2R-Probe）/ 适应（PAR）/ 弃权」四类预算间分配，以边际净收益相等为最优条件。

**定义 322（迁移证书 J_TRANS）** `J_TRANS = (J_FLUID, {C_i}, source_set, gap_posterior_hash, φ_map, ntv_evalue, plasticity_map, rollback_id, trans_ver)`。
`Valid ⇔ Valid(J_FLUID) ∧ ∀i∈参与决策的单元 C_i Valid ∧ NTV 未否决 ∧ 𝒢_ε 下安全成立 ∧ 无未回滚的失败更新`。

**定义 323（迁移审计 VQAuditor-T）** 审计：是否发生未认证的单元复用；源选择是否被单一源主导；探针是否越界/过频/损伤；更新是否可回滚；负迁移否决是否被绕过；**概念漂移是否被误判为协变量漂移**；给用户/维护者的迁移说明是否与证书一致。

**定义 324（威胁模型 AIC-XFER）** `ℰ_XFER = ℰ_FLUID × ℰ_source_poison × ℰ_sim_gap × ℰ_concept × ℰ_probe_side_effect`：投毒源/后门迁移、对抗性间隙（隐藏物理参数）、概念漂移伪装成协变量漂移、探针本身改变系统或造成磨损/泄露。并入 AIC。

**定义 325（退化边界）** 若 `𝒮` 与 `T` 同分布、`𝒢={0}`、所有单元 `FROZEN` 且证书全通过 ⇒ MIGRATE-RAS ≡ FLUID-RAS（逐指令相同）；若所有单元 `ABSTAIN` ⇒ 退化为 R68/R69 最保守兜底。故新层严格包含旧层，安全侧不做让步。

**定义 326（三环时序调度）** 快环（实时）：推理 + 证书查询 + 鲁棒安全检查，零写；中环（任务后）：NTV、轻量残差更新、间隙后验增量更新；慢环（维护窗/人工）：`REIDENT/RETRAIN/REBIND`、源重选、快照与回滚。自适应探针频率受「可辨识性收益 / 安全 / 磨损」三者约束，设最小间隔与总预算。

## 2. 关键算法骨架

```python
# IP-264 TKG：知识单元分解与登记（离线）
class TransferKnowledgeGraph:
    def __init__(self, theta_S, provenance):
        self.units = decompose_into_units(theta_S, provenance)  # R/D/E/S/U/C/I
    def trusted(self, certs):
        return [u for u in self.units if certs[u.id].valid]

# IP-265 TCG：单元级可迁移性证书（离线/中环）
def certify_unit(u, D_t, gap_post, alpha):
    AD = applicability_domain(u, D_t)             # 密度比 / 支撑重叠
    CI = conditional_invariance_test(u, D_t)      # 需干预/目标反馈，非仅被动
    G  = gap_projection(gap_post, u)              # 后验 credible set 投影
    return Cert(ad_ok=(AD >= alpha.ad), ci_ok=(not CI.reject),
                gap_ok=(diam(G) <= u.eps), n_eff=CI.n_eff)

# IP-266 NTV：anytime-valid 负迁移否决
class NegativeTransferVeto:
    def step(self, loss_fallback, loss_transfer):
        self.E *= 1 + self.lam * (loss_fallback - loss_transfer - self.mu0)
        if self.E >= 1 / self.alpha: self.adopted = True
        elif self.adopted and self.E < 1 / self.alpha:
            self.rollback()                        # 证据反转 → 原子回滚
        return self.adopted

# IP-267 GAP + IP-268 S2R-Probe：间隙后验与主动辨识
def gap_update(prior, D_t):
    return sbi_infer(prior, D_t)                   # p(xi|D_t), HPD -> G_eps

def choose_probe(gap_post, budget):
    best = None
    for g in probe_candidates():                   # 小激励 / 变载 / 多方向
        if not budget.allow(g) or not c_ras_wm.certify_info(g): continue
        score = mutual_info(gap_params, outcome | g) - wear(g) - social(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None   # 不可辨识方向 → 不探

# IP-269 DRS：间隙管上的鲁棒安全
def robust_safe(a, G_eps):
    return min(cbf_margin(x, a, xi) for xi in G_eps) >= 0

# IP-270 PAR：塑性分配与可回滚合并（中/慢环）
def consolidate(units, snapshot, D_val):
    for u in units:
        if u.type in (SAFETY, SEMANTIC): continue   # 冻结，只允许人工 REBIND
        if not ntv.passes(u) or not safety_nondecreasing(u):
            rollback(snapshot); continue
        if kl(pi_new(u), pi_old(u)) > eps_kl: reject(u); continue
        commit(u); snapshot.save(u)

# IP-276 主闭环（只在 R69 FLUID 层外加「准入 + 否决 + 鲁棒」）
def MIGRATE_RAS_round(M, obs, D_t):
    # 0) 继承 R69：不确定性二分 + 流策略 + 交互消歧
    z, o = M.mtm.forward(obs)
    U_ale, U_epi, modes = M.aud.decompose(M.fmp.sample(o, K=M.adaptive_K(z)), z)
    # 1) 单元级准入：只有获证单元进入实时信任集
    certs   = M.tcg.batch_certify(D_t, M.gap_post)
    trusted = M.tkg.trusted(certs)
    # 2) 间隙是否大到需要主动辨识（与 R69 交互共享预算）
    g_id = M.s2r.choose_probe(M.gap_post, M.budget) if M.gap_post.wide else None
    if g_id is not None:
        D_t = D_t + M.s2r.execute(g_id); M.gap_post = gap_update(M.gap_post, D_t)
    # 3) 负迁移否决：在线、逐单元、可回滚
    usable = [u for u in trusted if M.ntv.step(u, D_t)]
    # 4) 风险缩放：未获证单元的 epistemic 视同 aleatoric（安全不弱于 R69）
    U_unknown = sum(u.weight * u.U for u in M.tkg.units if u not in usable)
    lam = max(M.efs.risk_scale(), lam_floor(U_ale + U_epi + U_unknown))
    # 5) 选模态 + 间隙鲁棒安全
    a = select_mode(modes, U_epi, lam).a
    if not M.drs.robust_safe(a, M.gap_post.hpd):
        a, lam = M.fallback(a), max(lam, 0.8)      # 不可鲁棒 → 兜底 + 收紧
    # 6) 审计与证书（写操作全在中/慢环）
    M.vqa_t.submit_async(certs, usable, g_id, M.gap_post, M.ntv.evalue)
    return a, lam, certs
```

## 3. 推导

**引理 19（支撑重叠 ≠ 可迁移 / 被动不可识别性）** 存在两个目标分布 `P_t^1, P_t^2` 与同一源 `P_S`，使得边缘适用域指标 `AD`（或任意仅依赖 `P_t(o)` 的密度比、MMD、域分类 AUC）在两者上完全相同，但条件分布 `p_t(a|o)` 不同。仅凭被动观测 `o` 无法区分二者；需干预数据（`do(a)`）或目标侧动作/标签反馈才能识别 `CI`。故：**边缘域对齐指标的通过，不能推出可迁移；概念漂移必须在证书中显式保留「未判定」状态。** 这是本轮最重要的理论警示。

**引理 20（负迁移的 anytime 控制）** 若 `E_t` 在 `H_0` 下为非负上鞅，则 Ville 不等式给出 `P_{H_0}(∃t: E_t ≥ 1/α) ≤ α`。故「曾经错误采纳负迁移策略」的概率 ≤ α，且与检验次数/部署时长无关；回滚机制把已发生的错误限制在有限时间窗内。系：负迁移否决不需要预设样本量，适合在线部署；`μ_0>0` 把「无差异」与「明确更差」分开，避免在噪声上反复切换。

**引理 21（间隙管、安全与可辨识性）** 若真实参数 `ξ*` 以概率 `≥1−δ` 落在 `𝒢_ε` 内，则 `robust_safe(a,𝒢_ε) ⇒ P(safe(a;ξ*)) ≥ 1−δ`。进一步，`𝒢_ε` 的收缩速率由 Fisher 信息 `I(ξ)` 决定：在不可辨识方向（`I` 奇异）上，无论多少被动数据 `𝒢` 都不收缩；主动探针的价值恰是增加这些方向的激励能量。系：**探针并非越多越好——只在 `I(ξ)` 的近零空间上探，收益最大、磨损最小。**

**引理 22（迁移-适应权衡）** 在源-目标偏差 `D`、目标样本 `n_t` 下，迁移净收益 `NB(n_t)=B(n_t)−D−c_adapt`；存在最优塑性 `p*` 使期望遗憾最小。`p*` 随 `D` 增大而减小、随 `n_t` 增大而增大；当 `D > B_source` 时 `p*=0`（`ABSTAIN`）。这给出「何时微调（`RESIDUAL`）、何时重辨识（`REIDENT`）、何时别动（`FROZEN/ABSTAIN`）」的结构性边界。

**定理 18（MIGRATE-RAS 严格包含 FLUID-RAS）** 在定义 325 的同分布/零间隙/全 `FROZEN` 全证书条件下，MIGRATE-RAS 与 FLUID-RAS **逐指令相同**；全 `ABSTAIN` 时退化为 R68/R69 最保守兜底。中间情形下，未获证单元的 epistemic 被并入 `λ_floor`（算法第 4 步），故安全侧永不弱于 R69，效率侧仅在获证单元上获得迁移收益。R69/R68 是 MIGRATE 在「无别处经验」边界上的退化。

**定理 19（间隙鲁棒的安全迁移）** 若 (a) 所有参与实时决策的单元证书 `Valid`；(b) 每次更新通过 NTV 且安全证书不回退；(c) 执行动作在 `𝒢_ε` 上 `robust_safe`；则单步安全概率 `≥ 1 − δ_gap − α_ntv − α_cert`，且换装/回滚不引入控制跳变（继承 R69 定理 17 的换装不变式）。证明要点：三个失效事件取并集界；回滚在快环外完成，快环只切换已验快照，故连续。

**定理 20（多源选择的遗憾界）** 若有 `M` 个源，权重由目标验证遗憾最小化选取（stacking），则相对最优单源的超额遗憾 `≤ O(√(log M / n_t))`；若某源在目标上可分离地有害（后门/概念漂移），其权重以指数速率衰减至 0（NTV 与 SIR 联合）。系：**源选择必须在目标域验证；用源域验证选源，等价于用同一条有偏的尺子量自己。**（与引理 19 同源）

## 6. 本轮最大风险

**一句话**：MIGRATE-RAS 的全部安全性押在「可迁移性可由目标域少量观测被识别」这一前提上——**若真实迁移违背的是概念层（`p(a|o)` 改变）而非输入层（`p(o)` 改变），那么支撑重叠、密度比、域分类器都会漂亮地通过，系统会以「已验证可迁移」的姿态自信执行；这比 R69 的「诚实的不知道」更危险：迁移错了，却以为自己有资格不提问。**

**次级风险与缓解**：
1. **适用域假阳性**（支撑内但条件变）→ 定义 313 的 `CI` 必须含干预/反馈，且在无干预时输出「未判定」而非「通过」（引理 19）；
2. **间隙后验过度自信**（SBI 在小样本下过窄）→ 校准检验 E304 + 保守 `ε` + 未校准则扩大 `𝒢_ε`；
3. **探针损伤/打扰**（激励越界、磨损）→ 定义 315 的安全认证 + 只在 `I(ξ)` 近零空间探 + 磨损预算；
4. **负迁移否决被性能目标绕过** → NTV 硬否决 + 回滚 + 审计（定义 317/323），否决权高于奖励；
5. **安全/语义单元被悄悄适应** → 塑性图谱冻结 `κ^C/κ^S`，只允许人工 `REBIND` 与慢环回滚；
6. **源投毒/后门迁移** → 目标域选源（SIR）+ 单源不得主导 + `ℰ_source_poison` 对抗训练 + E310。

**最大风险一句话收束**：**最危险的不是「经验不适用」，而是「系统误以为自己已经证明它适用」——负迁移一旦被盖上官方的证书，就再也不会去问。**

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** 单元级准入；实时零学习写；负迁移否决权高于性能；证书按单元独立签发（禁止平均分掩盖关键单元失效）。

**定义 313–314（TCG 与 GAP）** 证书四元组；`Valid ⇔ AD 过 ∧ CI 未拒绝 ∧ diam(G)≤ε ∧ 单元安全证书在 𝒢_ε 成立`；间隙为 SBI 后验，只有持续激励才收缩。

**定义 319–321（SIR、漂移判别、收益分解）** 源权重在目标域验证；`D_cov` 小 `D_con` 大 = 概念漂移 ⇒ 禁 `FROZEN`；`NB≤0 ⇒ ABSTAIN`。

## 4. 推导

**引理 19（支撑重叠 ≠ 可迁移 / 被动不可识别性）** 存在目标分布 `P_t^1, P_t^2` 与同一源 `P_S`，使所有仅依赖 `P_t(o)` 的指标（适用域、密度比、MMD、域分类 AUC）完全相同，但 `p_t(a|o)` 不同。故边缘域对齐通过不能推出可迁移；概念漂移只能靠干预或目标侧反馈识别。→ 证书必须允许「未判定」，禁止把 `AD` 通过当作迁移许可。

**引理 20（负迁移的 anytime 控制）** 若 `E_t` 在 `H_0` 下为非负上鞅，则 `P_{H_0}(∃t: E_t ≥ 1/α) ≤ α`（Ville）。故错误采纳概率与部署时长无关；回滚把损害限制在有限窗口。`μ_0>0` 分离「无差异」与「明确更差」，抑制抖动。

**引理 21（间隙管、安全、可辨识性）** 若 `P(ξ*∈𝒢_ε) ≥ 1−δ`，则 `robust_safe(a,𝒢_ε) ⇒ P(safe) ≥ 1−δ`。`𝒢_ε` 收缩速率由 Fisher 信息 `I(ξ)` 决定；在 `I` 的奇异方向上被动数据不收缩，主动探针的价值正比于该方向的激励能量。系：只在近零空间探测，收益最大、磨损最小。

**引理 22（迁移-适应权衡）** `NB = B(n_t) − D − c_adapt`；最优塑性 `p*` 随 `D` 增大而减小、随 `n_t` 增大而增大；`D > B_source ⇒ p*=0`（ABSTAIN）。给出 `RESIDUAL/REIDENT/FROZEN/ABSTAIN` 的结构性边界。

**定理 18（严格包含 FLUID-RAS）** 同分布、`𝒢={0}`、全 `FROZEN` 且证书全通过时逐指令相同；全 `ABSTAIN` 时退化为 R68/R69 最保守兜底。未获证单元的 epistemic 并入 `λ_floor`，故安全侧不弱于 R69。

**定理 19（间隙鲁棒的安全迁移）** 单元证书 `Valid` + 更新过 NTV 且安全不回退 + 动作在 `𝒢_ε` 上 `robust_safe` ⇒ 单步安全概率 `≥ 1 − δ_gap − α_ntv − α_cert`，且换装/回滚不引入跳变。

**定理 20（多源选择遗憾界）** `M` 个源、目标验证 stacking ⇒ 相对最优单源超额遗憾 `≤ O(√(log M / n_t))`；可分离的有害源权重指数衰减至 0。系：源选择必须在目标域做，源域验证是有偏的尺子。

## 7. 本轮最大风险

**一句话**：MIGRATE-RAS 的安全性押在「可迁移性可由目标域少量观测被识别」上——**若真实迁移违背的是概念层（`p(a|o)` 改变）而非输入层（`p(o)` 改变），支撑重叠、密度比、域分类器都会漂亮通过，系统会以「已验证可迁移」的姿态自信执行；这比 R69 的「诚实的不知道」更危险：迁移错了，却以为自己有资格不提问。**

**次级风险与缓解**：适用域假阳性（`CI` 必须含干预，否则「未判定」）；SBI 过窄（E304 校准 + 保守 `ε`）；探针损伤（只在 `I(ξ)` 近零空间探 + 磨损预算 + C-RAS-WM）；否决被性能绕过（NTV 硬否决 + 回滚 + 审计）；安全/语义漂移（塑性图谱冻结 `κ^C/κ^S`）；源投毒（目标域选源 + 单源不得主导 + E310）。

**收束**：**最危险的不是「经验不适用」，而是「系统误以为自己已经证明它适用」——负迁移一旦被盖上官方的证书，就再也不会去问。**
