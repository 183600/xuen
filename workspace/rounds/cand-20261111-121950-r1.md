# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环重启第 1 轮；本轮灵感：「传感器融合」×「社会影响」）

> 第 54 轮把技能组合推进到动作空间与云边协同，但留下两个未言明的前提：动作剖面 `α_S` 与鲁棒性谱 `ρ` 的“证据”从何而来？组合与部署的“代价”由谁承担？本轮把 **传感器融合** 视为证书的证据供应链，把 **社会影响** 视为与鲁棒性、动作空间并列的第一性约束，而非事后伦理审查。核心矛盾：H22：融合越追求精度/覆盖，越可能以隐私、监视与群体间误差不对称为代价，而现有证书对此完全不可见；H23：社会影响不是可加标量，而是多主体、分布性、跨时间的向量，且含不可交易的 rights 硬约束，不能简单塞进 `cost_align`。

## 0. 直觉与动机

**灵感 1（融合是证据供应链，不是感知精度）**
直觉：技能 `S` 的动作剖面 `α_S(a)` 不是技能固有属性，而是在某个感知证据集下“可达”的估计。同一只灵巧手，用 RGB 还是 RGB-D、用不用力触觉、融合在边端还是云端，都会改变 `α_S` 与 `ρ_S`。因此第 54 轮的剖面应写成条件剖面 `α_{S|Φ_f}`，其中 `Φ_f` 是融合证书：它不仅记录“准不准”，还记录时间同步、任务相关状态的可观测裕度、标定漂移、隐私预算与数据来源。融合配置因此成为技能组合的**证据前提**，而不是部署后的调参细节。

**灵感 2（社会影响是带 rights 硬约束的向量资源）**
直觉：不能只算“平均社会收益”。隐私泄露、有效同意、群体间误差公平、可撤销性属于**不可交易的权利边界**；信任、可及性、环境成本才是可权衡的福利维度。把隐私或公平折成一个权重塞进总成本，等价于允许“用更多隐私换更高成功率”，这在伦理上不成立。于是社会可行性采用字典序：先过 `Adm_rights`，再谈社会预算 `B_s`。

**灵感 3（融合拓扑本身就是社会杠杆）**
直觉：传感器选择与融合位置直接决定隐私与公平。全程上传原始视频的云端融合精度最高，但泄露面最大；边端融合 + 只上传任务相关表征，可能损失几个点精度，却把隐私预算降低一个量级。群体间误差也不是“数据不够”的自然现象，而是传感器覆盖、标定条件与融合先验共同放大的结果。隐私/公平感知的融合选择应成为显式优化问题，而非事后补丁。

**灵感 4（来源与同意是证书字段，撤销要级联）**
直觉：没有来源追踪的证书在数据撤销后仍然“有效”，这是系统性风险。每份融合证据都应有 `provenance` 叶节点与 `consent_token`；一旦某数据源撤销同意或被判定违规，依赖它的 `Φ_f`、`α_{S|Φ_f}`、`J+` 必须在 `τ_rev` 内级联失效。社会影响中的“可逆性/可审计性”因此不是文档要求，而是运行时可检查的状态。

**灵感 5（社会约束组合与可争辩参数）**
直觉：技能组合图上的路径搜索要同时携带动作、鲁棒性、隐私、公平与同意资源；权利约束做硬过滤，福利预算用 CVaR 做鲁棒约束，得到 Pareto 前沿而非单一“最优”。更关键的是：社会权重 `w` 不应由工程师单独拍定。方案必须报告 `w` 的敏感性，允许利益相关者争辩与否决，并保留“该任务不可部署”的拒绝选项。

## 1. 形式化定义（增量：定义 121–128）

**定义 121（融合配置与融合算子）**
融合配置 `F = (I, ⊕, place)`：`I` 为参与融合的传感流集合，`⊕` 为融合算子（贝叶斯滤波、因子图、注意力融合等），`place ∈ {edge, cloud, hybrid}` 为融合位置。证据空间 `E = ⊕_{i∈I} E_i`，并附带来源映射 `prov : E → 2^D`，`D` 为原始数据源集合。

**定义 122（融合证书）**
融合证书 `Φ_f = (F, τ_sync, o_min, NEES_cover, ε_dp, drift, fallback)`：
- `τ_sync`：传感流最大时间同步误差；
- `o_min`：任务相关隐状态 `Z_T` 的可观测裕度下界（Fisher 信息/条件数归一化）；
- `NEES_cover`：标定一致性覆盖率，`P(NEES ≤ χ²_{d,1-δ}) ≥ 1-δ_f`；
- `ε_dp`：按数据主体计账的差分隐私预算；
- `drift`：标定漂移上界；
- `fallback`：融合退化时的降级模式与可观测性承诺。

**定义 123（技能感知契约与条件动作剖面）**
技能 `S` 的感知契约 `K_S = (Z_req, o_req, τ_max, g_req, ε_req)`。在融合证书 `Φ_f` 下，技能可执行当且仅当
```
o(Φ_f, Z_req) ≥ o_req ∧ τ_sync ≤ τ_max ∧ worst_gap(Φ_f) ≤ g_req ∧ ε_dp ≤ ε_req
```
条件动作剖面记为 `α_{S|Φ_f}(a)`；第 54 轮的 `α_S` 是其在标称融合下的边际化。鲁棒性谱同理记为 `ρ_{S|Φ_f}`。

**定义 124（社会影响向量与利益相关者）**
社会影响向量 `s = (s_priv, s_fair, s_consent, s_rev, s_access, s_env, s_trust) ∈ ℝ_+^7`，每个分量是对受影响群体 `G` 的分布，而非总体均值。利益相关者集合 `𝕊`，权重 `w_j ≥ 0, Σ_j w_j = 1`。`s_priv` 为隐私泄露（如成员推断优势、重构误差），`s_fair` 为任务相关误差的群体间差距，`s_consent` 为有效同意覆盖率缺口，`s_rev` 为撤销传播延迟，`s_access` 为可及性损失，`s_env` 为能耗/材料外部性，`s_trust` 为可解释性与可争辩性不足带来的信任成本。

**定义 125（权利可行性与社会预算）**
权利可行性 `Adm_rights(π) = 1` 当且仅当
```
consent_cover(π)=1 ∧ privacy_leak(π) ≤ cap_priv ∧ worst_group_gap(π) ≤ cap_fair
∧ ¬deceptive_use(π) ∧ revocable(π)
```
这些是不可交易的硬约束。非权利维度进入社会预算：
```
SocialRisk_α(π) = CVaR_α(⟨w, s(π)⟩) + λ_u·uncertainty(s)
```
`π` 社会可接受当且仅当 `Adm_rights(π)=1 ∧ SocialRisk_α(π) ≤ B_s`。字典序：`Adm_rights` 优先于任何成功率收益。

**定义 126（来源-同意图）**
`P = (D, E_prov, T_consent)`：`D` 为数据源/主体，`E_prov` 为数据到证据再到证书的依赖边，`T_consent` 记录同意范围、有效期与撤销事件。撤销算子 `rev(D')` 返回需失效的证书集合 `{J+ : prov_leaves(J+) ∩ D' ≠ ∅}`。证书有效必须满足 `prov_leaves(J+)` 全部在 `T_consent` 中处于有效状态。

**定义 127（社会约束技能组合）**
组合图 `G_S^+ = (V,E)`，边资源 `r_e = (c_trans, Δρ, Δa, Δs, Δε_dp, consent_status)`。社会约束组合问题为
```
find π: root → task
s.t. Adm_rights(π)=1,
     cost_align(π) ≤ C_max,
     SocialRisk_α(π) ≤ B_s,
     Δε_dp(π) ≤ ε_task
minimize  (cost_align(π), SocialRisk_α(π), -ρ_min(π))
```
一般情形是多资源约束最短路，NP-hard；输出 Pareto 前沿，而非单点。

**定义 128（社会-动作-鲁棒性联合证书）**
`J+ = (J, Φ_f, S_cert, P, consent_token, social_audit)`：
- `J` 为第 54 轮动作-鲁棒性联合证书；
- `Φ_f` 为融合证书；
- `S_cert = (s, w, uncertainty, rights_witness, cvar)` 为社会影响证书；
- `P` 为来源-同意图切片；
- `consent_token` 为可验证的同意凭证；
- `social_audit` 为外部/参与式审计记录。
部署条件：`J` 可部署 ∧ `Adm_rights=1` ∧ `SocialRisk_α ≤ B_s` ∧ `prov` 有效 ∧ 审计未否决。

## 2. 关键算法 伪代码

### IP-121 SFS（Socially-constrained Fusion Selection）

```python
def select_fusion(skill, context, sensors, B_s, rights, groups, top_k=8):
    # 候选：传感器子集 x 融合拓扑 x 放置位置；大规模时用贪心/束搜索
    candidates = enumerate_fusion_configs(sensors, context, max_sensors=top_k)
    best = None
    for F in candidates:
        phi = certify_fusion(F, context)          # 同步/NEES/漂移/隐私/来源
        if not satisfies_perception_contract(skill, phi):
            continue
        if not rights_ok(phi, rights):            # 隐私上限、同意、禁用用途
            continue
        s_hat, unc = social_oracle(phi, context, groups)  # 向量 + 不确定性
        if cvar(s_hat, w) + unc > B_s:
            continue
        utility = task_utility(phi) - lam_e*energy(F) - lam_l*latency(F)
        best = argmax(best, (utility, phi))
    return best  # 可能为 None：拒绝部署
```

`enumerate_fusion_configs` 在小规模用 MILP；大规模利用任务效用的子模性做带约束贪心，得到 `(1-1/e)` 近似，随后用 `certify_fusion` 做 soundness 复核。

### IP-122 FFC（Fair Fusion Calibration）

```python
def fair_fusion_calibrate(F, groups, data, eps_req):
    theta = init(F)
    for t in range(T):
        losses = {g: task_loss(theta, data[g]) for g in groups}
        # 群体 DRO：最小化最差组，同时约束平均性能与隐私预算
        obj = max(losses.values()) + mu * mean(losses.values())
        theta = theta - eta * grad(obj, theta)
    worst_gap = max(losses.values()) - min(losses.values())
    if worst_gap > g_req or privacy_spent(theta, data) > eps_req:
        return ('reject', worst_gap, privacy_spent(theta, data))
    return ('ok', theta, worst_gap)
```

### IP-123 PCA（Provenance-Consent Audit）

```python
def provenance_consent_audit(J_plus, revoked, t_now):
    leaves = prov_leaves(J_plus.Phi_f)
    if leaves & revoked:
        return ('reject', 'revoked_source', leaves & revoked)
    for d in leaves:
        if not consent_valid(d, J_plus.use_scope, t_now):
            return ('reject', 'consent_gap', d)
    if not lineage_closed(J_plus, leaves):
        return ('reject', 'lineage_gap', missing_edges(J_plus))
    return ('ok', lineage_witness(J_plus))
```

### IP-124 SCC（Socially-Constrained Composition）

```python
def socially_constrained_compose(G, task, C_max, B_s, eps_task, rights, w):
    labels = {root: [Label(cost=0, social=0, dp=0, rho=INF, path=[])]}
    pq = PriorityQueue([(0, root, labels[root][0])])
    while pq:
        _, v, lab = pq.pop()
        if v == task:
            continue
        for e in G.out_edges(v):
            if not edge_rights_ok(e, rights):
                continue
            new = extend(lab, e)
            if new.cost > C_max or new.dp > eps_task:
                continue
            if cvar(new.social, w) > B_s:
                continue
            if any(dominates(old, new) for old in labels[e.to]):
                continue
            labels[e.to] = [old for old in labels[e.to] if not dominates(new, old)]
            labels[e.to].append(new)
            pq.push((new.cost, e.to, new))
    return pareto_front(labels.get(task, []))
```

### IP-125 SIA（Social Impact Accounting）

```python
def social_accounting(J_plus, stakeholders, oracle, alpha=0.9):
    samples = oracle.sample(J_plus, stakeholders, n=N_s)
    cvar = quantile([dot(w, s) for s in samples], alpha)
    worst_group = max_group_risk(samples)
    rights_witness = rights_certificate(J_plus)
    return SocialCert(
        s=mean(samples), w=stakeholders.weights, uncertainty=oracle.width,
        rights_witness=rights_witness, cvar=cvar, worst_group=worst_group,
        audit_log=oracle.log)
```

`oracle` 不是“自动伦理裁判”，而是由参与式工作坊、领域专家与受影响群体共同校准的**带不确定性社会影响模型**；其参数 `w`、`B_s`、`cap_*` 必须可争辩、可审计，并允许否决。

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| SFS | 精确 MILP 指数级；贪心 `O(|C|·|A|·T_cert)` | `O(|C|)` | 证书复核、权利硬过滤 |
| FFC | `O(G·n·T)` | `O(G·n)` | 群体覆盖、隐私计账 |
| PCA | `O(|D|+|E_prov|)` | `O(|D|+|E_prov|)` | 来源闭包、撤销完备 |
| SCC | 多资源最短路 NP-hard；标签设置 `O(|E|·Π R_i)` 最坏 | `O(|E|·Π R_i)` | 资源单调、Pareto 支配 |
| SIA | `O(N_s·k + |π|)` | `O(N_s·k)` | 校准覆盖、不确定性报告 |

**正确性定理（Socially-Aware Composition Soundness）**
承接第 54 轮 (A26)–(A28)；新增：
**(A29)** `Φ_f` sound：`Z_req` 上可观测裕度与 NEES 覆盖率按证书成立；
**(A30)** 社会 oracle 校准：真实 `s` 落在报告区间内的概率 ≥ `1-δ_o`，且已建模 rights 的编码 sound；
**(A31)** 来源/同意完备：撤销传播延迟 ≤ `τ_rev`，`consent_cover` 检查无漏；
**(A32)** 参与式参数冻结：部署期内 `w, B_s, cap_*` 未被未授权修改。

则对任一通过 `J+` 的社会可行路径 `π`：
```
P(success ∧ ¬rights_violation) ≥
  1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a)
    - δ_f - δ_o - P(τ_rev>τ_rev_max) - P(consent_gap)
```
且
```
P(SocialRisk_α(π) > B_s) ≤ δ_o + P(CVaR 估计失效)
```
**定理边界**：该界只覆盖**已建模**的动作、鲁棒性、隐私、公平与同意维度；未建模的社会伤害不由公式兜底，因此 `social_audit` 与拒部署权是证书体系的一部分，而不是附属品。

## 4. 实验设计 E162–E168

| 实验 | 指标 | 目标 |
|---|---|---|
| E162 融合证书 soundness | NEES 覆盖率、`τ_sync` P95、漂移检出率 | 覆盖率 ≥ 95%，P95 ≤ 10ms |
| E163 隐私-精度 Pareto | `ε_dp` vs 任务成功率 | 同等成功率下隐私泄露降 ≥ 40% |
| E164 群体公平 | worst-group gap、平均性能 | gap ≤ 2%，平均下降 ≤ 3% |
| E165 社会约束组合 | 权利违规率、预算违规率、成功率 | 已建模权利违规 = 0，预算违规 ≤ 5% |
| E166 同意撤销级联 | `τ_rev` 分布、撤销后陈旧使用率 | P95 ≤ 200ms，陈旧使用 = 0 |
| E167 参与式社会审计 | 感知合法性、分歧度、否决率 | 与固定权重基线对比，记录否决与拒部署 |
| E168 消融 | 去 provenance / 去公平 / 去社会约束 | 分别量化泄露、gap、社会成本恶化 |

**负结果也要报告**：E165 必须统计“因权利约束而被拒绝的可行任务比例”（false refusal）。若拒绝率过高，说明 `cap_*` 或 oracle 过保守，需要用参与式校准修正，而不是悄悄放宽权利约束。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 社会影响不可通约、指标化即伦理洗白 | 高 | rights-first 硬约束 + 可争辩权重 + 外部审计 + 拒部署权 |
| 融合证书在分布漂移下失效 | 高 | 在线 NEES/漂移监测 + 降级 fallback + 证书到期 |
| 隐私预算组合计账错误 | 高 | 形式化 accountant + 保守上界 + 边端融合优先 |
| 公平指标被 Goodhart 化 | 中 | 多指标 + worst-group + 参与式复核 |
| 来源/同意图有缺口 | 高 | lineage gate + 撤销演练 + 无来源数据默认拒绝 |
| 多资源组合计算爆炸 | 中 | Pareto 剪枝 + anytime + 任务分层 |
| 利益相关者代表性不足 | 高 | 分层抽样 + 否决记录 + 敏感性分析 |

## 6. 本轮最大风险

**一句话**：把“社会影响”做成可计算证书的最大风险是**伦理洗白**——用一个价值负载、覆盖不全的代理指标替代真实的分配正义与隐私伤害，让不可接受的社会后果获得“合规”外观；因此必须坚持 **rights-first 硬约束、可争辩参数、外部与参与式审计、以及明确的拒部署权**，并始终声明定理只覆盖已建模维度。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-SocioFuse（SFS×FFC×PCA×SCC×SIA×JSC）

> 承接第 54 轮产物 v31。本轮不推翻动作空间与云边协同，而是补上它们缺失的两层：
> - **证据层**：技能的动作剖面与鲁棒性谱是条件量 `α_{S|Φ_f}`、`ρ_{S|Φ_f}`，由 **融合证书** `Φ_f` 供给；
> - **社会层**：社会影响是带 **rights 硬约束** 的多主体向量，不是可加标量；融合拓扑是隐私与公平的一等杠杆。
>
> 新增算子：
> - **SFS（Socially-constrained Fusion Selection）**：在任务可观测性、隐私、公平、延迟约束下选择传感集与融合拓扑；
> - **FFC（Fair Fusion Calibration）**：群体 DRO 校准，压 worst-group gap；
> - **PCA（Provenance-Consent Audit）**：来源-同意图审计与撤销级联；
> - **SCC（Socially-Constrained Composition）**：权利硬过滤 + 多资源 Pareto 组合；
> - **SIA（Social Impact Accounting）**：带不确定性的参与式社会影响计账；
> - **JSC（Joint Social Certificate）**：`J+` 联合证书。
>
> IP 编号：IP-121~IP-126（新增 6 个），升级 IP-115/118/120 以纳入融合证据与社会资源。

## 1. 符号体系增量（新增定义 121–128）

| 符号 | 含义 |
|---|---|
| `F=(I,⊕,place)` | 传感集 `I`、融合算子 `⊕`、位置 `place∈{edge,cloud,hybrid}` |
| `Φ_f=(F,τ_sync,o_min,NEES_cover,ε_dp,drift,fallback)` | 融合证书 |

| `α_{S\|Φ_f}, ρ_{S\|Φ_f}` | 条件动作剖面与条件鲁棒性谱 |
| `s=(s_priv,s_fair,s_consent,s_rev,s_access,s_env,s_trust)` | 多主体社会影响向量 |
| `Adm_rights(π)` | 权利可行性（同意/隐私/公平/可逆/非欺骗） |
| `SocialRisk_α(π)` | `CVaR_α(⟨w,s⟩)+λ_u·uncertainty` |
| `P=(D,E_prov,T_consent)` | 来源-同意图 |

**关键关系**：第 54 轮的 `α_S` 是 `α_{S|Φ_f}` 在标称融合下的边际化；因此“动作兼容”不再是技能对的二元关系，而是**在融合证书条件下的三元关系** `compat(S_i,S_j|Φ_f)`。同理，`ρ_{S_i⊗S_j}` 必须升级为 `ρ_{S_i⊗S_j|Φ_f}`。

## 2. 关键算法 伪代码

### IP-121 SFS

```python
def select_fusion(skill, context, sensors, B_s, rights, groups, top_k=8):
    best = None
    for F in enumerate_fusion_configs(sensors, context, max_sensors=top_k):
        phi = certify_fusion(F, context)          # 同步/NEES/漂移/隐私/来源
        if not satisfies_perception_contract(skill, phi):
            continue
        if not rights_ok(phi, rights):
            continue
        s_hat, unc = social_oracle(phi, context, groups)
        if cvar(s_hat, w) + unc > B_s:
            continue
        utility = task_utility(phi) - lam_e*energy(F) - lam_l*latency(F)
        best = argmax(best, (utility, phi))
    return best   # None 表示拒绝部署，而不是偷偷放宽约束
```

小规模用 MILP 精确求解；大规模利用 `task_utility` 的子模性做带约束贪心，得到 `(1-1/e)` 近似，再由 `certify_fusion` 做 soundness 复核。

### IP-122 FFC

```python
def fair_fusion_calibrate(F, groups, data, eps_req, g_req):
    theta = init(F)
    for t in range(T):
        losses = {g: task_loss(theta, data[g]) for g in groups}
        obj = max(losses.values()) + mu * mean(losses.values())
        theta = theta - eta * grad(obj, theta)
    worst_gap = max(losses.values()) - min(losses.values())
    if worst_gap > g_req or privacy_spent(theta, data) > eps_req:
        return ('reject', worst_gap, privacy_spent(theta, data))
    return ('ok', theta, worst_gap)
```

def provenance_consent_audit(J_plus, revoked, t_now):
    leaves = prov_leaves(J_plus.Phi_f)

### IP-124 SCC

```python
def socially_constrained_compose(G, task, C_max, B_s, eps_task, rights, w):
    labels = {root: [Label(cost=0, social=0, dp=0, rho=INF, path=[])]}
    pq = PriorityQueue([(0, root, labels[root][0])])
    while pq:
        _, v, lab = pq.pop()
        if v == task:
            continue
        for e in G.out_edges(v):
            if not edge_rights_ok(e, rights):
                continue
            new = extend(lab, e)
            if new.cost > C_max or new.dp > eps_task:
                continue
            if cvar(new.social, w) > B_s:
                continue
            if any(dominates(old, new) for old in labels[e.to]):
                continue
            labels[e.to] = [old for old in labels[e.to] if not dominates(new, old)]
            labels[e.to].append(new)
            pq.push((new.cost, e.to, new))
    return pareto_front(labels.get(task, []))
```

### IP-125 SIA

```python
def social_accounting(J_plus, stakeholders, oracle, alpha=0.9):
    samples = oracle.sample(J_plus, stakeholders, n=N_s)
    cvar = quantile([dot(w, s) for s in samples], alpha)
    return SocialCert(
        s=mean(samples), w=stakeholders.weights, uncertainty=oracle.width,
        rights_witness=rights_certificate(J_plus), cvar=cvar,
        worst_group=max_group_risk(samples), audit_log=oracle.log)
```

`oracle` 由参与式工作坊、领域专家与受影响群体共同校准；`w`、`B_s`、`cap_*` 必须可争辩、可审计、可冻结，并允许否决。

### IP-126 JSC

```python
def issue_joint_social_certificate(J, phi, s_cert, provenance, consent, audit):
    if not deployable(J):
        return ('reject', 'action_robustness')
    if not rights_certificate_ok(s_cert):
        return ('reject', 'rights')
    if s_cert.cvar > B_s or s_cert.uncertainty_unreported:
        return ('reject', 'social_budget')
    if not provenance_consent_audit((J, phi, provenance), revoked=∅, t_now=now()):
        return ('reject', 'provenance_consent')
    if audit.vetoed or not audit.frozen:
        return ('reject', 'audit')
    return ('ok', J_plus(J, phi, s_cert, provenance, consent, audit))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SFS | MILP 指数；贪心 `O(|C|·|A|·T_cert)` | `O(|C|)` | 融合证书 sound、rights 硬过滤 |
| FFC | `O(G·n·T)` | `O(G·n)` | 群体覆盖、隐私计账 |
| PCA | `O(|D|+|E_prov|)` | `O(|D|+|E_prov|)` | 来源闭包、撤销完备 |
| SCC | `O(|E|·Π R_i)` 最坏 | `O(|E|·Π R_i)` | 资源单调、Pareto 支配 |
| SIA | `O(N_s·k+|π|)` | `O(N_s·k)` | oracle 校准覆盖、不确定性报告 |

**正确性定理（Socially-Aware Composition Soundness）**
假设第 54 轮 (A26)–(A28) 成立；新增 **(A29)** `Φ_f` sound；**(A30)** 社会 oracle 校准且在已建模 rights 上编码 sound；**(A31)** 撤销传播 ≤ `τ_rev` 且同意覆盖检查无漏；**(A32)** 参与式参数在部署期冻结。则对任一通过 `J+` 的路径 `π`：
```
P(success ∧ ¬rights_violation) ≥
  1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a)
    - δ_f - δ_o - P(τ_rev>τ_rev_max) - P(consent_gap)
P(SocialRisk_α(π) > B_s) ≤ δ_o + P(CVaR 估计失效)
```
**边界声明**：定理只覆盖已建模维度；未建模的社会伤害不由此界兜底，必须由 `social_audit`、透明报告与拒部署权处理。

## 5. 实验设计 E162–E168

| 实验 | 指标 | 目标 |
|---|---|---|
| E162 融合证书 soundness | NEES 覆盖率、`τ_sync` P95、漂移检出 | ≥95%，P95≤10ms |
| E163 隐私-精度 Pareto | `ε_dp` vs 成功率 | 同等成功率下泄露降 ≥40% |
| E164 群体公平 | worst-group gap、平均性能 | gap ≤2%，平均降 ≤3% |
| E165 社会约束组合 | 权利违规率、预算违规率、成功率、false refusal | 权利违规=0，预算违规≤5% |
| E166 撤销级联 | `τ_rev` P95、陈旧使用率 | ≤200ms，陈旧使用=0 |
| E167 参与式审计 | 感知合法性、分歧度、否决率 | 与固定权重基线对比 |
| E168 消融 | 去 provenance / 去公平 / 去社会约束 | 量化泄露、gap、社会成本恶化 |

**结果呈现规范**：所有实验必须同时报告“被拒绝的可行任务比例”和“未建模伤害清单”。禁止只报成功率而隐藏拒部署与权利边界。

## 6. 本轮最大风险

**一句话**：把“社会影响”做成可计算证书的最大风险是**伦理洗白**——用一个价值负载、覆盖不全的代理指标替代真实的分配正义与隐私伤害，让不可接受的社会后果获得“合规”外观；因此必须坚持 **rights-first 硬约束、可争辩参数、外部与参与式审计、以及明确的拒部署权**，并始终声明定理只覆盖已建模维度。
