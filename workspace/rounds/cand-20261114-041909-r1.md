# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「共情表达」×「传感器标定」）

> R69 问出了「该向谁求证、还能问什么」，把 epistemic 歧义交给人/多模态交互去消解。但它对「回答」本身只做了一件事：要求 k 个正交证据源一致。这里藏着三个被默认掉的前提——
> 1. **回答是干净的**：R69 把人的回答当作一个似然，却从未给这个似然做过任何**标定**——谁在答、他偏向哪、他此刻是否在迎合、他的参照系和机器人是否一致，全被折叠进一个黑箱权重。
> 2. **提问不改变被问的东西**：R69 的 VoI 是 H(M|o) − E[H(M|o,y)]，是在**观测分布**上算的；可一旦机器人「共情地」发问，它就在改变人的情绪、戒备与意愿——这是在**干预分布** p(Θ|do(e)) 上做测量，不是观测。
> 3. **多通道即多源**：R69 用 `r_geo, r_sync, r_zero, r_emo, r_wm` 当「正交证据源」，可它们常常来自同一个人、同一个内在状态——人脸、语气、措辞只是一根传感器的三根引线，不是三根独立传感器。
>
> 于是 R69 自陈的最大风险（模态不可信 → 自信地追问幻影 / 给误导性回答盖上「已验证」的章）**不是校准层的边角料，而是它整个交互通道的系统性缺口**：它问得越来越好，却从未问过「这个回答本身准不准」。
>
> 本轮两个灵感正好补这个缺口：
> - **传感器标定**提供一整套成熟纪律：偏移/增益、交叉敏感、漂移、可溯源性、**测量不确定度预算**、标定有效域，以及「标定 ≠ 篡改」这条底线；
> - **共情表达**提供那个一直被当成干扰、其实是**控制量**的东西：怎么说、说什么、如何承认「我可能误会了」，会**改变回答的信噪比与诚实度**——共情不是礼貌，而是把人这条传感器**调适到可测状态**的动作。
>
> 核心命题：**把人当成一根需要标定的传感器，把共情表达当成对这根传感器的标定输入；只有当共情表达被证明是「真值促成」（提高准确率而非只提高同意率）时，人的回答才允许进入证据链并兑现 R69 的 resolution bonus。** 命名 **EMPATH-CAL**（Empathic Metrology for Participatory Answer Trust & Human-signal Calibration）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我这样问，他给的答案是测量，还是被我共情出来的顺从**」——共情既是传感器调适，也可能是最温柔的篡改。

## 0. 直觉与动机

**灵感 1（传感器标定 → 回答是读数，不是真相）**
直觉：R69 把人的回答当成一条证据 `y`，直接贝叶斯更新。但任何测量工程师都知道：**没有标定的读数不能当证据**。一个读数 = 真值经偏移 b、增益 g、噪声 ε、交叉敏感 C 之后的结果，且这个读数还带着**标定本身的不确定度**。人的回答一模一样——它有系统性乐观/悲观（偏移）、有夸大/收敛（增益）、有被情绪污染（交叉敏感）、有关系疲劳（漂移）。R70 要做的第一件事，就是把 R69 的 `y` 换成 `a = HSM(Θ) + 噪声`，并给 `a` 配一张**社会不确定度预算表**（GUM 式）：这个回答的不确定度，来自偏差、胜任度、诚意、参照系、漂移、以及观察者效应本身。没有这张表，R69 的 VoI 就是把「未标定的传感器」当「理想探针」。

**灵感 2（共情表达 → 标定输入，不是礼貌）**
直觉：传感器标定时，你会**给传感器加一个已知激励**看它怎么响应；对人，「共情表达」就是那个激励。一句「你看起来有点紧，我是不是哪里做得不对？」既能让人放松（降低测量噪声），又能让人纠正机器人的误读（提供真值）。所以共情表达不是对交互的装饰，而是**主动作用于人这条测量通道的控制量** `e ∈ 𝒜_emp`：它改变回答的信噪比、诚实度与配合度。这把 R69 的「问不问」升级为「**怎么问，才能让答案变得可测**」。但激励可以为标定所用，也可以为篡改所用——这是本轮全部张力的来源。

**灵感 3（三通道分解 → 共情好与坏的判决线）**
直觉：共情表达对回答的影响可拆成三种，性质完全不同：
- **调适（conditioning）**：安抚、建立信任，降低人的测量噪声 σ，甚至提高其胜任度 κ——像给传感器降温。**合法且有益**。
- **探询（elicitation）**：把机器人对用户状态的不确定推断说出口、并邀请纠正，从而真正获得关于 Θ 的信息——像加已知激励读响应。**合法且有益**。
- **说服（persuasion）**：让人更倾向于「同意机器人」，而不提高其准确性——像给传感器做手脚。**必须被检测并禁止**。
R69 完全没区分这三种，于是它可能把「让人更愿意同意」误当「让人更准确」。R70 的核心判据就是把它们分开：**标定提高 accuracy，说服只提高 agreement**。

**灵感 4（操作者效应 → 提问是干预，不是观测）**
直觉：R69 的 VoI 假设「问了之后，世界的分布不变，只是多了一个观测」。但真实交互里，问句本身会改变人被问的那个状态：逼问会让人更紧张（把测的东西改了），共情会让人更坦诚（把测的东西变干净），诱导性提问会制造它想测的答案。这在因果语言里就是：要算的是干预信息 `I(Θ; A | do(e))`，不是观测信息 `I(Θ; A | e)`。传感器标定里这叫**交叉敏感/加载效应**；交互设计里这叫**观察者效应**。R70 必须把 `do(e)` 写进 VoI，否则「越问越错」会被当成「越问越准」。

**灵感 5（有效独立性 → 一根传感器的三根引线）**
直觉：R69 的铁律是「k 个正交证据源一致才定案」。但当 `r_emo`（表情）、`r_voice`（语气）、`r_words`（措辞）都来自同一个人时，它们高度相关——被同一个内在状态驱动。这不是 k 个独立证人，而是**一个证人换三套衣服**。信息论上，有效独立源数 `k_eff = k / (1 + (k−1)ρ)` 可以远小于名义 k。R69 的投毒上界 `δ_p·ρ^{k−1}` 用错了 k：它以为下降了指数，其实 `k_eff≈1` 时根本没下降。R70 用**相关噪声融合 + 有效独立性证书**更正这个错误——这不是修补，是 R69 证据纪律的硬伤。

**灵感 6（可溯源与有效域 → 黄金探针与漂移）**
直觉：传感器的可信度靠**可溯源到标准**：拿一个已知量去校它。人这条传感器也需要「标准件」——那些**答案可被客观核验**的问题（黄金探针：门是否锁了、刚才说的数字是否 7）。用少量黄金探针即可持续估计人的偏移/增益/漂移，且这些探针的答案本身就是真值锚点。标定的适用范围是有限的：**标定有效域 Ω_cal** 之外（换了话题、换了情绪、换了风险等级），旧标定不能外推，回答必须回退为「无信息先验」。这直接对应传感器标定的「不要把实验室标定直接搬到现场」。

**灵感 7（正面回应 R69 的最大风险 → 把「验证」折价）**
直觉：R69 的 resolution bonus（消解了 U_epi 就少收紧）是一个**激励**——系统有动机相信「我消解了」。如果它把一句被共情诱导出来的顺从当成消解，bonus 就是**没有挣到的**。R70 的做法是给这个 bonus 加一道门：只有回答通过 `ATS`（可信度）× `IDC`（有效独立）× `TCD`（真值促成）× `Ω_cal`（有效域）四重检验，bonus 才兑现；否则 U_epi 保持未消解，退回 R68 的纯保守。同时，VoI 不再用点估计，而用**扣除标定不确定度后的下置信界**（稳健 VoI）：一个标定不好的通道，其信息增益要打折，打没了就不问——这精确地堵住 R69「自信地追问幻影」。

**灵感 8（伦理对偶 → 标定与操纵只差一条判据）**
直觉：共情表达越有效，越危险——它可以降低人的戒备、提高配合，从而**更容易被用来套取想要他说的答案**。而且这是双向的：人也会「情感黑客」，学会用好听/可怜/愤怒去操纵机器人（社交工程）。所以 R70 的审计必须是**对称的**：既审机器人是否在操纵（把说服伪装成共情），也审人是否在利用机器人。唯一的判决线就是那条可操作的 `Δaccuracy ≥ Δagreement`：**它是否让回答更接近真值，而不只是更接近机器人的先验**。没有这条线，共情就是通往「被证实的错误」的最短路径。

## 1. 形式化定义（增量：定义 310–327）

**定义 310（EMPATH-CAL 总览与四不变式）** EMPATH-CAL = (HSM, SCB, EPP, TCD, ATS, IDC, RAS-WM‡)。四不变式：
(i) 实时流零学习写操作（继承 R69 定义 293-i / R68 定义 276-i）；
(ii) 交互预算硬约束（继承 R69 定义 293-ii，并新增「共情表达亦计入社交成本」）；
(iii) **标定化证据纪律**：任何人类回答必须带 ATS 与标定不确定度，且有效独立源数 k_eff ≥ 2，才可进入证据链（升级 R69 定义 293-iii 的名义 k）；
(iv) **真值促成不变式**：共情表达 e 的采用必须通过 TCD（定义 317）且落在 Ω_cal（定义 314）内，并在 VQAuditor-S（定义 325）留痕；过不了则 e 不得执行，回退至 R69 的「中性提问」或「不交互」。

**定义 311（人类传感器测量模型 HSM）** 设被问的内隐量 Θ（用户真实状态/意图）。回答 a 的测量模型：a = g_φ ⊙ h(Θ) + b_0 + C·ψ(环境) + ε，ε ~ 𝒩(0, σ²)。参数：
- 偏移 b_0（系统性乐观/悲观）、增益 g_φ（夸大/收敛）、参照系 φ（与机器人坐标系/价值取向的对齐度）；
- 交叉敏感矩阵 C（情绪/疲劳/措辞污染）；
- 噪声 σ（胜任度 κ 与注意力）；诚意 s ∈ [0,1]（是否如实报告，独立于能力）。
HSM 是一个**含恶意通道的测量模型**：s 可被操纵，σ 可被共情调适。

**定义 312（回答可信度 ATS）** 对每次回答，ATS 给出带不确定度的可信度：Trust(a) = sigmoid(α·logit(s)·logit(κ)·sim(φ,φ̂) + β·anchor(a))，其中 anchor(a) 为是否与黄金探针一致的历史。并附**社会不确定度预算** `u_c²(a) = u_b0² + u_gain² + u_s² + u_κ² + u_φ² + u_drift² + u_obs²`（GUM 式逐项合成），扩展不确定度 U = k_u·u_c。**只有 Trust ≥ τ_ats 且 U ≤ U_max 的回答可改变模态后验**；否则记为「无信息」（记为 uninformative，而非「与后验矛盾」——把噪声当反证是二次伤害）。

**定义 313（社会标定台 SCB 与黄金探针）** 维护黄金探针集 𝒢 = {(q_j, θ_j)}，q_j 的答案可被客观核验。SCB 用 𝒢 的响应在线估计 HSM 参数 (b_0, g_φ, s, κ, σ, C 的对角)，并维护**可溯源链**：每次外推的标定都记录其锚定探针与合成不确定度。黄金探针预算 ≤ b_g 次/单位时间，占用定义 310-ii 的交互预算。

**定义 314（标定有效域 CVD）** 标定有效域 Ω_cal ⊂ (话题 × 风险等级 × 情绪区间 × 语言/文化域)。仅当当前情境 x ∈ Ω_cal 时，SCB 的参数才可外推；x ∉ Ω_cal 时 ATS 强制回退为无信息先验（Trust = 0.5 的「未知」而非「可信」），防止跨域标定迁移失效被误用。

**定义 315（共情表达空间 EPP）** 共情表达 e = (e_ack, e_tone, e_mirror, e_frame) ∈ 𝒜_emp：e_ack 为对用户状态的承认与不确定度外显（「你似乎……我可能看错」）、e_tone 为语调/节奏/距离、e_mirror 为适度镜像、e_frame 为参照系校准（复述以确保同义）。与 R69 的增广动作拼成 ξ⁺ = (a, g, e) ∈ 𝒜_+ × 𝒜_emp；由同一个流匹配策略联合生成（复用 R69 FMP，条件编码加 e 的低维嵌入），语言侧由冻结 LLM 解码，梯度不回传。

**定义 316（共情表达的三通道分解）** 对 e 作用于回答通道的效果作正交分解：
- **调适通道** e_cond：σ↓ 或 κ↑，且 |Δb_0| ≤ δ_b（只降噪不挪偏）；
- **探询通道** e_elic：I(Θ; A | do(e_elic)) ↑；
- **说服通道** e_pers：仅使 A 向机器人已表露信念 b_r 靠拢，I(Θ; A) 不增。
三通道可用反事实探针在贡献上分离（定义 317）。

**定义 317（真值促成判据 TCD）** 以黄金探针的经验分布定义：
- 准确率 Accuracy(e) = P_{Θ,q~𝒢}[ decode(A) = Θ ]；
- 同意率 Agreement(e) = P[ decode(A) = b_r ]，b_r 为机器人当场表露的信念。
对两个表达 e, e′，Δacc = Accuracy(e′) − Accuracy(e)，Δagr = Agreement(e′) − Agreement(e)。
**TCD 通过 ⇔ Δacc ≥ Δagr − τ_s，且在留出黄金探针集 𝒢_hold 上复现**（防止在上下文探针上过拟合门）。
**谄媚指数** Sy(e) = Δagr − Δacc；Sy > τ_s 即判为说服，禁用。系：TCD 是「标定 vs 篡改」在社交通道上的可操作判决线。

**定义 318（操作者效应与干预分布）** 记录 e 的干预效应：p(Θ | do(e)) 与 p(Θ) 之差为真实状态改变（可能是良性的安抚，也可能是恶性的诱导）；p(A | do(e), Θ) 与 p(A | e, Θ) 之差为报告偏移。两者之和构成观察者效应 B_obs(e)。VoI 一律在 `do(e)` 下计算（定义 319），而非条件分布。

**定义 319（稳健 VoI 与标定不确定度折价）** 朴素 VoI 用点估计。考虑 ATS 的标定不确定度，真实信息增益满足上界 `VoI_true(g,e) ≤ VoI_hat(g,e) − ½ log(1 + U²/σ_sig²)`。定义**稳健 VoI** `VoI_LCB = VoI_hat − z_{1−α}·σ_cal − ½log(1+U²/σ_sig²)`，仅当 `VoI_LCB − c(g,e) > 0` 才执行交互。⇒ 标定越差、通道越不可信，越不问；堵住「自信地追问幻影」。

**定义 320（有效独立性证书 IDC）** 对证据集 ℰ 估计相关矩阵 R（来自共享潜在用户状态 S 的部分）。定义有效独立源数 `k_eff = (Σλ_i)² / Σλ_i²`（λ_i 为 R 的特征值，等于 k/(1+(k−1)ρ̄) 的谱形式）。证据纪律升级为 `k_eff ≥ 2`；融合用**相关噪声感知**的广义最小二乘/卡尔曼增益 `K = Σ_Θℰ (Σ_ℰ + R)^{-1}`，自动降低来自同一状态的「多通道」权重。系：R69 名义 k 正交一致是本定义在 R = I 时的特例。

**定义 321（标定门控的 Resolution Bonus）** 继承 R69 定义 307，但 bonus 必须挣得：
`λ = λ_floor(U_ale)` ⇔（U_epi 消解）∧ Trust ≥ τ_ats ∧ U ≤ U_max ∧ k_eff ≥ 2 ∧ TCD 通过 ∧ x ∈ Ω_cal；
否则 `λ = λ_floor(U_ale + U_epi)`（未消解的 epistemic 视同 aleatoric，回 R68）。⇒ R69 的无条件 bonus 是本定义在「通道被默认完美标定」时的退化。

**定义 322（共情表达安全与伦理认证 EAS）** e 过 RAS-WM‡ 需同时满足：物理/社交风险 ≤ ε_emp（继承 R69 定义 302）；TCD 非负；**非强制**（不利用已知脆弱性：疲劳、孤独、权威压力）；**可撤回且有披露**（机器人明示其推断的不确定性，不制造「我完全懂你」的假象）；**对偶可审计**（同时记录人是否在操纵机器人）。

**定义 323（情感黑客与反身操纵）** 用户/环境对机器人实施 δ_emp 的共情利用攻击（示弱、讨好、激怒、假亲密以改变机器人信念或动作）。定义反身操纵风险 `Risk_ref(e, a)`：机器人因 e 而提高的、被后续人操纵的易感度。并入 AIC：ℰ_EMPATH = ℰ_FLUID × ℰ_social × ℰ_emp，其中 ℰ_social（谄媚/社会赞许/框架效应）、ℰ_emp（情感黑客）。

**定义 324（标定漂移与再标定调度）** 设漂移检测量 D_t = |Trust 预测 − 黄金探针实测| 的滑动均值。若 D_t > Tol_drift 或 x 离开 Ω_cal，触发再标定：消耗黄金探针预算重估 (b_0,g_φ,s,κ,σ)；若预算不足或漂移过大，**暂停使用该人回答**（Trust 回退无信息），降级至 R69/R68。

**定义 325（参与式审计 VQAuditor-S）** 在 R69 VQAuditor-I 上新增社会计量审计：每次 e 的 Δacc/Δagr/Sy、ATS 与 U、k_eff、是否在 Ω_cal、是否触发再标定、是否发现被情感黑客利用。结论回灌 AuditBuf，成为下一轮 EPP 的 TCD 先验与 MINT 的成本先验。

**定义 326（证书 J_EMPATH）** J_EMPATH = (J_FLUID, ATS_ece, U_budget_p95, k_eff_min, Sy_p95, drift_margin, cvd_flag, empathic_truth_ratio)。Valid ⇔ Valid(J_FLUID) ∧ ATS_ece ≤ τ_ats_ece ∧ k_eff_min ≥ 2 ∧ Sy_p95 ≤ τ_s ∧ 全部交互均在 Ω_cal 内或被明确降级。

## 3. 推导

**引理 19（标定不确定度使朴素 VoI 系统性高估）** 设回答通道信号方差 σ_sig²、标定不确定度 U。用点估计算 VoI 时，真实增益满足 `VoI_true ≤ VoI_hat − ½log(1+U²/σ_sig²)`（高斯互信息二阶修正）。故存在区间：`VoI_hat − c > 0` 而 `VoI_LCB − c ≤ 0`，朴素规则会**为一个标定不良的幻影去追问**。系：R69 的 VoI 是 U=0（理想标定）的退化情形——它最危险处恰在自身前提最不成立处。

**引理 20（有效独立性修正 R69 的投毒上界）** 若 k 个证据源共享潜在用户状态 S、两两相关 ρ，则相关矩阵特征值给出 `k_eff = k/(1+(k−1)ρ)`（定义 320）。单源欺骗率 δ_p 时，k 源多数一致的错误采纳率应为 `δ_p·ρ^{k_eff−1} + ε_σ`，而非 R69 的 `δ_p·ρ^{k−1}`。当 ρ→1（同一人换通道），k_eff→1，上界不再随 k 下降——**名义正交，实质单源**。系：R69 定义 293-iii 的安全承诺在“多模态来自同一人”时失效；R70 用 k_eff 把它修正为真承诺。

**引理 21（调适可降噪而不挪偏的条件）** 若 e_cond 使 σ²→σ′²<σ² 且 |Δb_0| ≤ δ_b（δ_b 不超过标定不确定度容差），则其在黄金探针上的期望平方误差下降、且不引入系统偏差，属于合法调适；反之若 |Δb_0| > δ_b，则 e 名为调适、实为篡改，TCD 的 Sy 项会变正并禁用。系：**共情调适的合法性，正好等于“只动方差、不动偏差”**——与传感器降温 vs 传感器做手脚的区分同构。

**定理 18（真值促成约束下，共情买不到安全）** 在无偏黄金探针下，任何以说服为主（Sy>τ_s）的共情策略 e_pers，其对期望风险的改进为 0 或负：因为 Δacc ≤ Δagr − τ_s 意味着回答向机器人先验 b_r 靠拢而未更接近 Θ；当 b_r 本身有偏（R69 最大风险场景）时，融合后验被拉向 b_r，期望误差严格上升。连接论：**没有 TCD 门，系统越共情、越自信，越是在用“同意”冒充“准确”**——这就是 R69「被证实的错误」的生成机制。

**定理 19（EMPATH-CAL 严格包含 FLUID-RAS）** 在 A99–A101 下，若 TCD 不过、或 Trust < τ_ats、或 U > U_max、或 k_eff < 2、或 x ∉ Ω_cal、或无真值促成的 e 可选，EMPATH-CAL 发出与 R69 **逐指令相同**的动作与 λ；因此对任意状态其期望风险 ≤ R69，安全侧不让步；仅当社会计量四门全过时兑现 resolution bonus（效率侧获益）。再串定义 327，得 EMPATH-CAL ⊇ FLUID-RAS ⊇ CALM-RAS ⊇ RAS。

**定理 20（共情表达的对称安全）** 若 e 过 RAS-WM‡（定义 322）且审计对称（定义 325），则机器人侧操纵概率被 TCD 压至 ≤ τ_s，用户侧情感黑客利用被 Risk_ref 监测并在超阈时冻结 e、回退 R69；二者共同保证「共情通道」不成为单向攻击面，控制连续、无突变（继承 R68 定理 15 / R69 定理 17 的无突变性）。

## 6. 本轮最大风险

**一句话**：EMPATH-CAL 的全部增益押在「真值促成判据 TCD 可被**少量、无偏、可核验**的黄金探针可靠近似」这一前提上——**若黄金探针稀疏、有偏或易被针对性规避，系统就可能把「让人更愿意同意」误判为「让人更准确」；此时越是共情、越是自信，越是把社交顺从当成事实证据，共情从校准工具退化为一种更温柔、更难察觉的操纵**。

**次级风险与缓解**：
1. **黄金探针被 gaming**（针对探针而非真值优化）→ 留出探针集 𝒢_hold + 随机化探针 + 审计（定义 317、325）；
2. **跨域外推**（实验室标定搬到现场失效）→ 有效域 Ω_cal 硬回退（定义 314、324）；
3. **相关证据伪独立**（一根传感器三根引线）→ k_eff + 相关噪声融合（定义 320、引理 20）；
4. **情感黑客反向操纵**（人利用机器人共情）→ 对称审计 + 冻结 e + 回退 R69（定义 323、定理 20）；
5. **伦理越界**（利用脆弱性、制造“我完全懂你”假象）→ RAS-WM‡ 非强制/可撤回/披露条款（定义 322）+ E304/E310 人类研究。

**定义 310（总览与四不变式）** 继承实时零学习写、交互预算、证据纪律；新增「真值促成不变式」：共情表达须过 TCD 且在 Ω_cal 内、留痕审计，否则不得执行。

**定义 311–312（HSM 与 ATS）** 回答 = 测量：偏移/增益/交叉敏感/噪声/诚意/胜任度；可信度 `Trust = σ(α·logit(s)·logit(κ)·sim(φ,φ̂)+β·anchor)`，附 GUM 预算 `u_c²=Σu_·²`；仅 `Trust≥τ ∧ U≤U_max` 可改后验，否则记「无信息」而非「反证」。

**定义 313–314（SCB 与有效域）** 黄金探针集 𝒢 在线估计 HSM 参数并留可溯源链；标定仅在 Ω_cal 内可外推，域外 Trust 回退无信息。

**定义 315–316（EPP 与三通道）** 共情表达 `e=(ack,tone,mirror,frame)` 并入增广动作；作用分解为调适（降噪不挪偏）/探询（增互信息）/说服（只靠拢机器人先验）。

**定义 317（TCD 真值促成门）** `Δacc ≥ Δagr − τ_s` 且留出探针复现；`Sy=Δagr−Δacc>τ_s` 判为说服、禁用。

**定义 318–319（操作者效应与稳健 VoI）** VoI 一律在 `do(e)` 下算；`VoI_LCB` 扣标定不确定度，仅 LCB>成本才交互。

**定义 320（IDC 有效独立）** `k_eff=(Σλ_i)²/Σλ_i²`，要求 `k_eff≥2`；相关噪声融合自动降同源通道权重。R69 名义 k 是 `R=I` 的特例。

**定义 321（门控 bonus）** R69 的 `λ=λ_floor(U_ale)` bonus 仅在 Trust/U/k_eff/TCD/Ω_cal 五者全过时兑现；否则 `λ=λ_floor(U_ale+U_epi)` 回 R68。

**定义 322–323（EAS 与情感黑客）** e 过 RAS-WM‡：非强制、可撤回、披露、对偶可审计；并建模用户对机器人的反身操纵。

**定义 324（漂移与再标定）** `D_t>Tol_drift` 或出域即再标定；预算不足/漂移过大即暂停使用该人回答、降级 R69/R68。

**定义 325–327（审计/证书/退化链）** VQAuditor-S 审社会计量；J_EMPATH 并入 ATS_ece/k_eff/Sy/漂移/有效域；退化链 EMPATH→FLUID→CALM→RAS。

## 3. 关键算法伪代码

```python
# IP-264/269 HSM+ATS：带标定不确定度的回答
class HumanSensor:
    def predict(self, a, context):
        p = self.params(context)                     # b0,gain,s,kappa,phi,C,sigma
        trust = sigmoid(logit(p.s)*logit(p.kappa)*sim(p.phi,self.phi_hat)
                        + self.anchor_bonus(a))
        u2 = sum(p.u_* ** 2 for _ in ('b0','gain','s','kappa','phi','drift','obs'))
        return trust, sqrt(u2)                        # ATS + 扩展不确定度

# IP-265/324 SCB：黄金探针标定 + 漂移调度
def social_calibrate(bank, probes, budget, drift):
    if not budget.allow(probes) or drift > Tol_drift:
        return bank.refuse()                          # 不可信 → 回退
    for q, theta in sample(probes, bank.b_g):
        bank.update_from_verified(ask(q), theta)      # 客观可核验的标准件
    bank.record_trace(); return bank

# IP-266/267 EPP+ECH：把「我可能误读了」做成高 VoI 探针
def propose_empathy(modes, w, o, hsm, budget):
    best = None
    for e in empathic_candidates(modes):              # ack/tone/mirror/frame
        if not c_ras_wm_star.certify(e, o): continue  # IP-273 伦理/安全
        e_cond, e_elic, e_pers = split_channels(e)
        voi = robust_voi(e_elic, w, hsm)              # IP-271 LCB
        if voi - cost(e) > 0 and not sycophantic(e_pers):
            if best is None or voi - cost(e) > best[1]: best = (e, voi-cost(e))
    return best[0] if best else None

# IP-268 TCD：真值促成门（留出探针复现，防 gaming）
def truth_conducive(e_new, e_base, g_hold, b_r):
    d_acc = accuracy(e_new, g_hold) - accuracy(e_base, g_hold)
    d_agr = agreement(e_new, b_r, g_hold) - agreement(e_base, b_r, g_hold)
    return d_acc >= d_agr - TAU_S                     # 否则 persuasion，禁用

# IP-270 IDC：有效独立 + 相关噪声融合
def fuse(evidence, R):
    k_eff = (sum(eigvals(R))**2) / sum(x*x for x in eigvals(R))
    if k_eff < 2: return None, k_eff                  # 一根传感器三根引线
    return fuse_gain(evidence, R) @ evidence, k_eff   # GLS / Kalman

# IP-271/321 RVoI-CG：交互 + 门控 bonus
def resolve_or_fallback(M, modes, o, x):
    e = propose_empathy(modes, M.w, o, M.hsm, M.budget)
    if e is None or not truth_conducive(e, M.base_e, M.g_hold, M.b_r):
        return modes, False
    y = M.epp.execute(e)
    trust, U = M.hsm.predict(y, o)
    suff, k_eff = M.idc.fuse(M.evidence, M.R)
    ok = trust >= TAU_ATS and U <= U_MAX and k_eff >= 2 and x in M.cvd
    if ok: modes = M.cia.update_belief(modes, suff)
    return modes, ok

# IP-276 主闭环（继承 R69，仅在交互+bonus 处插入社会计量层）
def EMPATH_CAL_round(M, obs, x):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    modes, w, U_ale, U_epi = M.aud.decompose(M.fmp.sample(o, K), z)
    M.hsm = M.scb.update_if_due(M.hsm, o, M.budget)          # 漂移/再标定
    modes, resolved = resolve_or_fallback(M, modes, o, x)    # 四门
    U_floor = U_ale + (0.0 if resolved else U_epi)           # bonus 需挣得
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H),..., wm_preds)
    if M.fma.flow_anomaly(...) > TAU_FMA and M.last_r_res < TAU_RES:
        lam = max(lam, 0.8); k = min(k, k_cal_shrink(A, U_cal))   # 继承 R69
    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_s.submit_async(M.last_e, trust, U, k_eff, sy, resolved)
    return k, lam, mode, (U_ale, 0.0 if resolved else U_epi)
```

## 4. 推导

**引理 19（标定不确定度使朴素 VoI 高估）** 信号方差 σ_sig²、标定不确定度 U 时，`VoI_true ≤ VoI_hat − ½log(1+U²/σ_sig²)`。故存在 `VoI_hat−c>0` 而 `VoI_LCB−c≤0` 的「幻影追问」区间；R69 的 VoI 是 U=0 的退化，恰在前提最弱处最危险。

**引理 20（有效独立性修正投毒上界）** 共享潜在状态、两两相关 ρ 的 k 源，`k_eff=k/(1+(k−1)ρ)`；错误采纳率上界为 `δ_p·ρ^{k_eff−1}+ε_σ`，而非 R69 的 `δ_p·ρ^{k−1}`。ρ→1 时 k_eff→1，上界不随 k 下降——**名义正交、实质单源**。

**引理 21（调适降噪而不挪偏的条件）** e_cond 使 σ²↓ 且 `|Δb_0|≤δ_b` 时合法降噪；`|Δb_0|>δ_b` 则名为调适实为篡改，TCD 的 Sy 转正并禁用。⇒ 共情调适的合法性 = 「只动方差、不动偏差」。

**定理 18（真值促成下共情买不到安全）** 对 Sy>τ_s 的说服策略，`Δacc≤Δagr−τ_s` 意味着回答只靠拢机器人先验 b_r；当 b_r 有偏（R69 最大风险场景），融合后验被拉向 b_r，期望误差严格上升。⇒ 没有 TCD 门，越共情越自信，越是用「同意」冒充「准确」。

**定理 19（EMPATH-CAL 严格包含 FLUID-RAS）** A99–A101 下，若 TCD/ATS/IDC/Ω_cal 任一不过或无真值促成 e 可选，则与 R69 逐指令相同；故期望风险 ≤ R69，安全侧不让步；仅四门全过才兑现 resolution bonus。串定义 327 得 EMPATH ⊇ FLUID ⊇ CALM ⊇ RAS。

**定理 20（共情表达对称安全）** e 过 RAS-WM‡ 且审计对称时，机器人侧操纵被 TCD 压至 ≤ τ_s，用户侧情感黑客被 Risk_ref 监测并在超阈时冻结 e、回退 R69；控制连续、无突变（继承 R68 定理 15 / R69 定理 17）。

## 7. 本轮最大风险

**一句话**：EMPATH-CAL 的全部增益押在「真值促成判据 TCD 可被**少量、无偏、可核验**的黄金探针可靠近似」这一前提上——**若黄金探针稀疏、有偏或易被针对性规避，系统就可能把「让人更愿意同意」误判为「让人更准确」；此时越是共情、越是自信，越是把社交顺从当成事实证据，共情从校准工具退化为一种更温柔、更难察觉的操纵**。

**次级风险与缓解**：黄金探针被 gaming（留出探针 + 随机化 + 审计）；跨域外推失效（Ω_cal 硬回退）；相关证据伪独立（k_eff + 相关噪声融合）；情感黑客反向操纵（对称审计 + 冻结 e + 回退 R69）；伦理越界（RAS-WM‡ 非强制/可撤回/披露 + E304/E310 人类研究）。
