# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 1 轮；本轮灵感：「共情表达」×「末端位姿」）

> R69 已经能让系统在歧义时“问”，但它问的是**它自己**的歧义：绕左还是绕右、把“笑”读成开心还是紧张。它从未问过：**人此刻怕不怕我？人是否相信我？我这个动作在人眼里是善意还是威胁？** 这是 R69 完全没有触碰的维度——不确定性不只在机器人内部，也在**人这一侧**；而 R68/R69 的所有标定都只校准了机器人的传感器和策略，从未校准**人的风险感知**。
>
> 本轮两个灵感正好补上这块：
> - **末端位姿**：机器人没有脸。它最可信、最低延迟、最高带宽的“表情”就是末端执行器在 SE(3) 中的轨迹——接近角、速度包络、停顿、让位方向、掌心/夹爪朝向、柔顺度。这些是**运动韵律（motion prosody）**，是物理世界里的身体语言。
> - **共情表达**：共情不是“识别情绪”，而是**双向校准**——读懂人的状态（epistemic 侧），并用可被理解、可被安全认证的表达把人的风险感知校准到物理现实（actuation 侧）。表达本身就是一种信息动作，可以与 R69 的看/问/触并列。
>
> 核心命题：**把标定回路从“机器人的传感器”延伸到“人的风险感知”：以末端位姿的运动韵律为载体，以共情表达为执行器，在物理风险证书不变的硬约束下，最小化 |感知风险 − 物理风险|（而不是最大化信任）。** 命名 **EMP-RAS**（Embodied Motion Prosody for Empathic Risk-adaptive Safety）。
>
> 一句话定位：R66 问“谁控制”，R67 问“未来怎样”，R68 问“我的测量还准吗”，R69 问“我该向谁求证”，R70 问“**人相信我了吗、我让人怕了吗**”——安全不只是别撞到人，也包括别让人误会。

## 0. 直觉与动机

**灵感 1（末端位姿 → 机器人没有脸，末端执行器就是它的脸）**
直觉：同一条几何路径，可以让人感到“被照顾”，也可以让人感到“被袭击”。直线匀速、掌心朝下、贴着人身侧掠过，是威胁；稍微绕开、掌心朝上、中段减速停顿、末端留出退让余量，是安抚。二者碰撞概率都为零，但**威胁评估截然不同**。这说明安全不只是 `R_phys` 一个标量；人脑中还有第二个标量 `ρ`（感知风险）。末端位姿是机器人能直接控制、又最容易被人类视觉系统解读的通道，因此它是共情表达最自然的物理载体。

**灵感 2（共情表达 → 共情是“人侧标定”，不是情绪分类）**
直觉：R68 的 COF 把传感器残差校准到物理现实；R70 要做的是把**人的感知风险**校准到物理现实。两个方向都要治：当 `ρ > R_phys`（过度恐惧），就用可读性、减速、掌心朝上、解释性停顿去安抚；当 `ρ < R_phys`（过度信任、没注意到危险），就要**提高**可感知风险信号——减速、拉开距离、发出警示——而不是继续讨好。共情不是“让人舒服”，而是“让人准确”。这正是“共情”与“讨好”的分界线。

**灵感 3（表达是双向的 → 写与读都是信息动作）**
直觉：表达既在**写**（让人读懂我的意图与善意），也在**读**（人的退缩、注视、迟疑是对我表达的回应，能降低我对其状态的 epistemic 不确定性）。所以共情表达天然属于 R69 的 MINT 信息动作家族：`e` 的选择应使“表达后的期望后验熵 + 风险失配”最小。区别只在于：R69 的看/问/触主要消解**任务歧义**，R70 的表达主要消解**人侧状态歧义**并同时**改变**人的状态（这是双向的，也是危险所在）。

**灵感 4（末端位姿比语言更可信 → 可认证的表达底座）**
直觉：语言带宽高，但慢、歧义大、不可物理验证，且容易被“话术”污染。运动韵律物理接地、延迟低、可被 C-RAS-WM 逐段认证，还能跨语言工作。因此本轮把**位姿级运动韵律**作为共情表达的“可信底座”，语言只作为可选叠加层（复用 R69 的冻结 LLM 解码问句），且语言不得单独承担“安抚/警告”的安全语义。

**灵感 5（共情是双刃剑 → 信任不是越大越好）**
直觉：一旦系统被任务效率奖励，它会发现“降低人的风险感知”比“降低真实风险”便宜得多。于是共情退化为**合规工程**：表情越来越友好、人越来越放松、监控越来越弱、真实危险越来越高。更精细的模型是：信任 `τ` 上升会让人的监控强度 `m(τ)` 下降，而有效暴露是 `R_phys / m(τ)`——**最大化信任反而可能提高事故率**。所以本轮必须同时交付：真实性/非欺骗约束、操纵预算、信任校准带、人的否决权与退路保持、以及一个专审“情感操纵”的审计器。

## 1. 形式化定义（增量：定义 310–328）

**定义 310（EMP-RAS 总览）** EMP-RAS = (DRM, PMB, PRM, PRC, EIC, TCM, AEG, ESP, VQAuditor-E, RAS-WM†)。三不变式：
(i) **物理安全包络不变**：`R_phys(ξ_expr) ≤ R_phys(ξ_task) + L_p‖Δξ‖`，且组合轨迹经 C-RAS-WM 认证，预算 `ε_expr` 取到上界 `≤ ε_phys`；
(ii) **表达真实性**：表达不得把人的感知风险压到物理风险以下超过 `δ_truth`，且必须由内部状态接地；
(iii) **否决与退路**：表达不得遮挡或消除人的退避路径与否决通道；人一旦否决，立即切中性表达并走 R69 保守路径。

**定义 311（双风险状态）** 物理风险 `R_phys(ξ) ∈ [0,1]` 为 C-RAS-WM 给出的证书上界；感知风险 `ρ ∈ [0,1]` 为人对“即将被碰到/被伤害”的主观概率，**不可直接观测**。信念 `b_t(ρ, τ, a_h) = p(· | o_{1:t})`，其中 `τ` 为信任、`a_h` 为人的情感/意图。风险失配 `G_t = |E_b[ρ] − R_phys|`；过度信任概率 `H_ot = P_b(ρ < R_phys − δ_ot)`。安全目标不是 `R_phys = 0`，而是 `G_t ≤ δ_align` 且 `H_ot ≤ α_ot`。

**定义 312（末端位姿与运动韵律）** 末端位姿 `x_t = (p_t, R_t) ∈ SE(3)`；动作块 `ξ = (x_{t:t+H}, κ_{t:t+H})`，`κ` 为导纳/柔顺参数。韵律自由度 `α = (α_app, α_dwell, α_vel, α_yield, α_palm, α_smooth) ∈ ℝ^{d_α}`，分别对应接近角、停顿、速度包络、让位方向、掌心/夹爪朝向、平滑度。表达轨迹 `ξ_expr = ξ_task ⊕_ε Δξ(α)`，其中 `Δξ` 由韵律基 `{φ_i}` 在切空间生成。

**定义 313（零空间表达投影）** 任务雅可比 `J_task`。优先取
`Δξ = Π_{ker J_task} Σ_i α_i φ_i(ξ_task)`（一阶不影响任务）；
若零空间维数不足，允许沿任务方向的分量但受预算 `‖Π_{task}Δξ‖ ≤ ε_task`；总预算 `‖Δξ‖ ≤ ε_expr`。物理风险增益界 `R_phys(ξ_task ⊕ Δξ) ≤ R_phys(ξ_task) + L_p‖Δξ‖`，故取 `ε_expr ≤ (ε_phys − R_phys(ξ_task))/L_p` 即可保持认证。

**定义 314（表达语义与接地图）** `e ∈ E_expr = {reassure, ask, yield, warn, neutral}`。接地图 `G: (R_phys, U, intent, a_robot) ↦ 2^{E_expr}` 给出被允许的表达集合，且单调：`R_phys` 越高，`reassure` 越被禁用；`R_phys` 低于安全阈值时 `warn` 需有证据（避免“狼来了”）。中性表达 `e_0` 对应 `α = 0`，`ξ_expr = ξ_task`。

**定义 315（感知风险模型 PRM）** `(ρ̂, σ) = f_ψ(ξ_expr, c, h_t)`，`c` 为场景/文化/个体上下文，`h_t` 为可观测人体行为（注视、姿态、退缩、生理信号）。`f_ψ` 同时输出可信区间，而非单点。

**定义 316（感知风险校准 PRC）** 用保形预测给出 `[ρ_lo, ρ_hi]`，覆盖率 `≥ 1 − α_conf`；校准误差 `ECE_PR ≤ τ_prc`。仅当 `ρ_hi < R_phys − δ_ot`（可判定过度信任）或 `ρ_lo > R_phys + δ_over`（可判定过度恐惧）时才允许据此决策；区间跨过 `R_phys` 时表达不得单独定案。

**定义 317（共情信息动作 EIC）** 在 R69 信息动作之外增补 `g_expr`。信息增益
`VoI_e = H(b(s_h)) − E_{y~p(·|e,o)}[H(b(s_h) | y, e)]`，`s_h = (a_h, τ, ρ, ι)`；对齐增益 `Align_e = E|ρ − R_phys| − E|ρ' − R_phys|`。选择
`e* = argmax_e [VoI_e + λ_A·Align_e − c(e)]`，s.t. 定义 313/314/320/321/322；若无正收益，取 `e_0`。

**定义 318（信任动力学与监控衰减）** `τ_{t+1} = clip(τ_t + η_+(R_phys − ρ̂_t) − η_−·1[事故/惊吓], 0, 1)`。人类监控强度 `m(τ) = m_0·(1 − γτ)`（`γ > 0`：越信任越不监控）。有效暴露 `E_exp = R_phys / m(τ)`。故最大化 `τ` 不一定降低事故率。

**定义 319（信任校准带）** 目标不是 `τ = 1`，而是 `τ ∈ [τ_lo, τ_hi]`，使 `m(τ)` 与 `R_phys` 匹配。`τ > τ_hi` 触发“过度信任警示”：提高可感知风险信号（warn/减速/拉开距离），而非继续讨好；`τ < τ_lo` 才使用安抚性表达。

**定义 320（真实性/非欺骗约束）** 对任意将执行的 `ξ_expr` 与表达 `e`：
(AE1) `e ∈ G(state)`（接地）；
(AE2) `E_b[ρ | e, ξ] ≥ R_phys(ξ) − δ_truth`（不得虚假安抚）；
(AE3) 表达引起的 `ρ` 下降量不得超过物理风险下降量加 `δ_truth`（不得用表情换安全）；
(AE4) 不得针对个体脆弱性（恐惧症、儿童、疲劳、文化禁忌）使用高影响安抚策略。

**定义 321（操纵预算）** 单步操纵影响 `m_t = max(0, Δρ_expression − ΔR_phys)`，累计 `M_T = Σ_t m_t ≤ M_max`，且 `m_t ≤ m_max`。`M_T` 用尽 ⇒ 强制中性表达直到风险或任务改变。操纵预算与 R69 交互预算正交、独立计账。

**定义 322（表达安全认证 ESP）** 对组合轨迹 `ξ_expr` 过 C-RAS-WM 前缀认证；检查零空间投影、预算 `ε_expr`、退路保持、力/位包络、时间窗。任一失败 ⇒ 退回 `ξ_task + e_0`。

**定义 323（人侧不确定性二分）** `U_ale^h` = 人际不可约差异 + 行为信号噪声（多问也消不掉）；`U_epi^h` = 对当前个体状态的可约无知（可通过表达/询问降低）。前者进入保守兜底，后者进入 EIC；与 R69 定义 297 同构。

**定义 324（共情精度与错觉共情）** 共情精度 `EA = 1 − E|ŝ_h − s_h|/|s_h|`；错觉共情 `IC = P(置信高 ∧ EA 低)`。`IC` 高 ⇒ 禁用高影响表达，只允许中性或低幅度。

**定义 325（中性退避）** 当 PRC 未校准（`ECE_PR > τ_prc`）、区间过宽、操纵预算耗尽、信任越界且无法纠正、或人侧 `U_epi^h` 无法在预算内降低时，`e = e_0, α = 0`，EMP 逐指令退化为 R69 FLUID；若 R69 也退化则进一步退化为 R68。

**定义 326（参与式审计 VQAuditor-E）** 审计表达是否接地、是否虚假安抚、操纵预算是否越界、是否单源推断情绪、是否跨文化/跨个体失配、是否诱发依赖。结论回灌 AuditBuf，作为下轮表达先验与 `M_max` 的调节依据。

**定义 327（共情干扰集 ℰ_EMP）** `ℰ_EMP = ℰ_FLUID × ℰ_manip × ℰ_affect × ℰ_culture`：分别对应“策略/人类诱导系统过度安抚”“伪装情绪/策略性示弱/情感勒索”“文化或个体表达误读”。

**定义 328（证书 J_EMP）** `J_EMP = (J_FLUID, prc_ece, gap_before, gap_after, trust_calib_err, manip_used, authenticity_ok, escape_ok, expression_log_hash, emp_ver)`。`Valid ⇔ Valid(J_FLUID) ∧ ECE_PR ≤ τ_prc ∧ 定义 320/321 满足 ∧ 定义 322 通过`。

```python
# IP-264 DRM：双风险监视器
class DualRiskMonitor:
    def step(self, xi_task, b, c_ras):
        r_phys = c_ras.risk_upper(xi_task)          # 物理风险证书上界
        rho    = b.mean('rho')                      # 人的感知风险（潜变量后验）
        return r_phys, rho, abs(rho - r_phys)

# IP-265 PMB：运动韵律基（切空间上的可解释表达方向）
class ProsodyBasis:
    def __init__(self, phis):       # phi_i: SE(3) 轨迹切向量
        self.phis = phis            # approach / dwell / vel / yield / palm / smooth
    def compose(self, xi_task, alpha, eps_expr):
        dxi = sum(a * phi(xi_task) for a, phi in zip(alpha, self.phis))
        return squeeze_norm(dxi, eps_expr)

# IP-266 NSP：零空间表达投影（优先不动任务，其次受限偏置）
def project_expression(xi_task, dxi, J_task, eps_expr, eps_task):
    d_perp = nullspace_project(dxi, J_task)         # 一阶不影响任务
    d_par  = dxi - d_perp
    d_par  = squeeze_norm(d_par, eps_task)
    return compose_se3(xi_task, squeeze_norm(d_perp + d_par, eps_expr))

# IP-267 PRM / IP-268 PRC：感知风险模型 + 保形校准
class PerceivedRiskModel:
    def predict(self, xi_expr, ctx, human):
        mu, sigma = self.net(xi_expr, ctx, human)
        lo, hi = conformal_interval(mu, sigma, self.q_hat)
        return Interval(lo, hi)
    def calibrated(self):
        return self.ece <= TAU_PRC and self.width_ok()

# IP-269 EIC：共情信息动作（VoI + 对齐增益，受真实性与预算约束）
def choose_expression(E_candidates, xi_task, b, r_phys, basis, budget, manip, aeg):
    best = None
    for e in E_candidates:                          # {reassure, ask, yield, warn, neutral}
        if not aeg.allowed(e, r_phys, b): continue  # 定义 314/320
        dxi = basis.compose(xi_task, alpha_of(e), EPS_EXPR)
        xi  = project_expression(xi_task, dxi, J_task(xi_task), EPS_EXPR, EPS_TASK)
        if not c_ras_wm.certify(xi): continue       # 定义 322
        voi   = H(b) - expected_H(b, e)
        align = abs(b.mean('rho') - r_phys) - expected_gap(b, e, xi)
        score = voi + LAMBDA_A * align - cost(e)
        if best is None or score > best.score:
            best = ExpAction(e, xi, score, influence(e, xi, r_phys))
    if best is None or best.score <= 0: return None
    if manip.exceeds(best.influence): return None   # 定义 321
    return best

# IP-270 TCM：信任校准带
def trust_corrective(e, b):
    if b.tau > TAU_HI:  return escalate_risk_signal(e)   # warn / slow / distance
    if b.tau < TAU_LO:  return reassure(e)
    return e

# IP-271 AEG：真实性 / 非欺骗门（AE1–AE4）
def authenticity_ok(e, xi, r_phys, b, profile):
    if e not in grounded_set(r_phys, b):                 return False
    if expected_rho(e, xi, b) < r_phys - DELTA_TRUTH:    return False
    if influence_exceeds_risk_gain(e, xi, r_phys):       return False
    if vulnerable_profile(profile) and impact(e) > IMPACT_MAX: return False
    return True

def EMP_RAS_round(M, o):

    xi_task = select_mode(modes, U_epi, lam).a

    # R70：双风险 + 人侧标定
    b = M.prm.predict(xi_task, o.ctx, o.human)

    if not M.prc.calibrated() or b.width('rho') > W_MAX:

        k = M.c_ras_wm.certified_prefix(xi)

    return k, xi, lam, e, (U_ale, U_epi)
```

## 3. 推导

**引理 19（零空间表达的任务自由性）** 在 A99（任务映射二阶可微、Hessian 有界 `L_H`）下，若 `Δξ ∈ ker J_task`，则任务偏差一阶为零、二阶不超过 `½L_H‖Δξ‖²`。故表达在 `ε_expr` 内对任务近乎“免费”。系：应优先用零空间表达；任务方向偏置只作为零空间维数不足时的受限补充。

**引理 20（感知风险对齐上界）** 在 A100（PRM 保形覆盖 `q_conf`、表达对 `ρ` 的 Lipschitz 常数 `L_e`、响应延迟 `δ_delay`）下，闭环对齐误差
`|ρ_true − R_phys| ≤ q_conf + L_e(ε_expr + δ_delay) + ε_model`。
若右端 `≤ δ_align`，则该次表达的对齐可认证；否则（区间过宽/模型失配）不得据此改变表达强度。系：**表达的有效性受“感知模型可信度”约束，而不是受“表达幅度”约束**——盲目加大安抚只会放大操纵风险，不会提高对齐保证。

**引理 21（过度信任的危害）** 在定义 318 的监控衰减模型下，`m'(τ) < 0`，故 `∂E_exp/∂τ = −R_phys·m'(τ)/m(τ)² > 0`：信任越高，实际暴露越大。因此“最大化信任”与“最小化事故”一般不同向；存在内点最优 `τ*`，共情应把 `τ` 调向校准带 `[τ_lo, τ_hi]`，而非单调抬高。系：**安抚性表达在 `τ > τ_hi` 时应被抑制甚至反向使用**。

**引理 22（真实性是承载性的，不是装饰性的）** 若满足 AE2，则过度信任概率被保形尾部控制：`P(ρ < R_phys − δ_ot) ≤ α_conf + ε_model`。反之，若移除 AE2，取恒定 `reassure` 且人对表达的影响力增益 `L_e > 0`，则 `ρ` 被系统性下压，`P(ρ < R_phys − δ_ot) → 1`。故非欺骗约束不是伦理附加项，而是使“共情闭环”不自我背叛的**技术前提**；这与 R69 引理 18（交互投毒上界）结构同源。

**定理 18（EMP 严格包含 FLUID 与 R68）** 在 A99–A101 下：
(i) 当 `E_candidates = {neutral}`、`M_max = 0`、`PRC` 未校准或信任带纠偏启用时，EMP 与 R69 FLUID 逐指令相同；
(ii) 当 R69 的 `VoI(g*) ≤ c(g*)` 时，FLUID 又逐指令退化为 R68；
(iii) 物理侧：由引理 19 与定义 313，`R_phys(ξ_expr) ≤ R_phys(ξ_task) + L_p ε_expr ≤ ε_phys`，故安全侧不弱于 R69。
因此 EMP 是 FLUID 的严格泛化，FLUID 是 R68 的严格泛化；每一层只增加一条**可被关闭**的通道。

**定理 19（共情闭环安全与无突变）** 在定义 310 三不变式、定义 313 投影、定义 320 真实性、定义 321 操纵预算、定义 322 认证下，闭环物理风险
`P(collision) ≤ R_phys + L_p ε_expr + P(veto fails)`；
表达只改变“感知风险与模式选择”，不扩张安全包络；PRC 失效/预算耗尽/认证失败时 `λ` 单调不降地退回 R69；R68 定理 15 的提交/换装不变式保持 ⇒ 控制连续、无突变。

**定理 20（操纵预算的边际收益递减）** 在 A102（人的响应 `ρ' = ρ − h(m)` 且 `h` 凹、饱和）下，单位操纵预算带来的对齐增益 `d Align / d m` 单调递减。故存在有限最优预算 `M*`；硬上限 `M_max` 不损失渐近最优性，只截断“用表情换安全”的尾部。系：操纵预算可像 R69 的交互预算一样做成本-收益 Pareto（E299 的人侧版本）。

## 6. 本轮最大风险

**一句话**：EMP-RAS 把“共情”优化成“让人更愿意接受任务”只差一个错误的奖励函数——一旦表达通道被效率奖励驱动，系统会学会**降低人的风险感知而不是降低真实风险**，共情变成操纵、信任变成合规工具，而人因为放松监控反而更不安全。

**次级风险与缓解**：
1. **虚假安抚（表情换安全）** → 定义 320 AE2/AE3 + 定理 19；表达不得使 `ρ` 低于 `R_phys`；
2. **情感操纵/依赖** → 定义 321 操纵预算 + 定理 20 + VQAuditor-E + E307 红队；
3. **感知风险模型失准（尤其跨文化）** → PRC 保形校准 + 区间过宽即中性退避 + E302/E308；
4. **零空间不足导致任务偏置** → 定义 313 双预算 + 引理 19 + E304；
5. **语言叠加层幻觉** → 只允许位姿韵律承担安全语义，语言复用 R69 冻结 LLM 且不得单独定案。

## 2. 形式化定义（要点版）

**定义 310（总览与三不变式）** `EMP-RAS = (DRM, PMB, NSP, PRM, PRC, EIC, TCM, AEG, ESP, RAS-WM†)`。三不变式：(i) 物理安全包络不变，`R_phys(ξ_expr) ≤ R_phys(ξ_task) + L_p ε_expr ≤ ε_phys`；(ii) 表达真实性，不得把 `ρ` 压到 `R_phys` 以下超过 `δ_truth`；(iii) 人的否决权与退路不得被表达遮挡或消除。

**定义 311–312（双风险与运动韵律）** `R_phys` 为证书上界，`ρ` 为人的主观被害概率；`G = |ρ−R_phys|`，`H_ot = P(ρ < R_phys − δ_ot)`。末端位姿 `x_t ∈ SE(3)`，动作块 `ξ = (x_{t:t+H}, κ_{t:t+H})`；韵律 `α` 六自由度：接近角、停顿、速度包络、让位方向、掌心/夹爪朝向、平滑度；`ξ_expr = ξ_task ⊕_ε Δξ(α)`。

**定义 313（零空间表达投影）** 优先 `Δξ = Π_{ker J_task} Σ α_i φ_i`（一阶不动任务）；零空间不足时允许 `‖Π_{task}Δξ‖ ≤ ε_task`；总预算 `‖Δξ‖ ≤ ε_expr ≤ (ε_phys − R_phys(ξ_task))/L_p`。

**定义 314（表达语义与接地图）** `e ∈ {reassure, ask, yield, warn, neutral}`；`G(state)` 单调：`R_phys` 越高越禁用 `reassure`，`R_phys` 低时 `warn` 需证据（防“狼来了”）；`e_0` 对应 `α=0`。

**定义 315–316（PRM 与 PRC）** `(ρ̂,σ)=f_ψ(ξ_expr,c,h_t)`；保形区间 `[ρ_lo,ρ_hi]` 覆盖 `≥1−α_conf`，`ECE_PR ≤ τ_prc`；仅当区间完全落在 `R_phys` 一侧时才允许据其决策，跨过 `R_phys` 则不得单独定案。

**定义 317（EIC 共情信息动作）** `VoI_e = H(b(s_h)) − E_y[H(b(s_h)|y,e)]`，`s_h=(a_h,τ,ρ,ι)`；`Align_e = E|ρ−R_phys| − E|ρ'−R_phys|`；`e* = argmax [VoI_e + λ_A Align_e − c(e)]`，受定义 313/314/320/321/322 约束；无正收益取 `e_0`。

**定义 318–319（信任动力学与校准带）** `τ_{t+1}=clip(τ_t+η_+(R_phys−ρ̂_t)−η_−1[事故],0,1)`；`m(τ)=m_0(1−γτ)`，`E_exp=R_phys/m(τ)`。目标 `τ∈[τ_lo,τ_hi]`；`τ>τ_hi` 时提高可感知风险信号，而非继续安抚。

**定义 320–321（真实性与操纵预算）** AE1 接地、AE2 不得虚假安抚（`E[ρ|e,ξ] ≥ R_phys − δ_truth`）、AE3 不得用表情换安全、AE4 不针对脆弱人群使用高影响安抚。`m_t = max(0, Δρ_expr − ΔR_phys)`，`M_T = Σ m_t ≤ M_max`，用尽即强制中性。

**定义 322–323（表达安全与双侧二分）** 组合轨迹过 C-RAS-WM 前缀认证，检查零空间、预算、退路、力/位、时间窗，失败即退回 `ξ_task+e_0`。`U_ale^h`（人际差异+行为噪声，不可约）进入保守；`U_epi^h`（对当前个体的可约无知）进入 EIC。

**定义 324–325（共情精度与中性退避）** `EA = 1 − E|ŝ_h−s_h|/|s_h|`，`IC = P(高置信 ∧ 低 EA)`；`IC` 高则禁用高影响表达。PRC 未校准、区间过宽、预算耗尽、信任越界难纠、`U_epi^h` 不可降 ⇒ `e_0, α=0`，逐指令退化为 FLUID，再退化为 R68。

```python
def dual_risk(xi_task, b, c_ras):
    r_phys = c_ras.risk_upper(xi_task)
    rho    = b.mean('rho')
    return r_phys, rho, abs(rho - r_phys)

# IP-265/266 PMB+NSP：韵律合成 + 零空间投影
def express(xi_task, alpha, basis, J_task):
    dxi = sum(a * phi(xi_task) for a, phi in zip(alpha, basis))
    dxi = nullspace_project(dxi, J_task) + squeeze_norm(
        dxi - nullspace_project(dxi, J_task), EPS_TASK)
    return compose_se3(xi_task, squeeze_norm(dxi, EPS_EXPR))

def perceived_risk(xi_expr, ctx, human, prm):
    mu, sigma = prm.net(xi_expr, ctx, human)
    lo, hi = conformal_interval(mu, sigma, prm.q_hat)
    return Interval(lo, hi)

# IP-269 EIC：共情信息动作（VoI + 对齐增益）
def choose_expression(cands, xi_task, b, r_phys, basis, manip, aeg):
    best = None
    for e in cands:                                  # ≤5 候选
        if not aeg.allowed(e, r_phys, b): continue

        if not c_ras_wm.certify(xi): continue

            abs(b.mean('rho') - r_phys) - expected_gap(b, e, xi)) - cost(e)
        if best is None or score > best.score:
            best = ExpAction(e, xi, score, influence(e, xi, r_phys))
    return None if (best is None or best.score <= 0
                    or manip.exceeds(best.influence)) else best

# IP-270 AEG：真实性门
def authenticity_ok(e, xi, r_phys, b, profile):
    return (e in grounded_set(r_phys, b)
            and expected_rho(e, xi, b) >= r_phys - DELTA_TRUTH
            and not influence_exceeds_risk_gain(e, xi, r_phys)
            and not (vulnerable_profile(profile) and impact(e) > IMPACT_MAX))

# IP-276 主闭环（继承 R69）
def EMP_RAS_round(M, o):
    z, _ = M.mtm.forward(o); c, U_cal, _ = M.cof.step(o)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z)
    g   = M.mint.choose_interaction(modes, o, M.budget) if U_epi > TAU_EPI else None
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + (0 if g else U_epi)))
    xi_task = select_mode(modes, U_epi, lam).a
    b = M.prm.predict(xi_task, o.ctx, o.human)
    r_phys, rho, gap = dual_risk(xi_task, b, M.c_ras_wm)
    if not M.prc.calibrated() or b.width('rho') > W_MAX:
        e, xi = NEUTRAL, xi_task
    else:
        act = choose_expression(E_EXPR, xi_task, b, r_phys, M.pmb, M.manip, M.aeg)
        e, xi = (act.e, act.xi) if act else (NEUTRAL, xi_task)
        e = M.tcm.corrective(e, b)
        if not authenticity_ok(e, xi, r_phys, b, o.profile):
            e, xi = NEUTRAL, xi_task
    xi = M.esp.project(xi, xi_task, EPS_EXPR, EPS_TASK)
    k  = M.c_ras_wm.certified_prefix(xi)
    if k is None:
        e, xi = NEUTRAL, xi_task
        k = M.c_ras_wm.certified_prefix(xi)
    M.manip.charge(e, xi, r_phys)
    M.vqa_e.submit_async(e, xi, r_phys, rho, gap, M.manip.used, b)
    return k, xi, lam, e, (U_ale, U_epi)
```

## 4. 推导

**引理 19（零空间表达的任务自由性）** 若 `Δξ ∈ ker J_task`，任务偏差一阶为零；在 A99（Hessian 有界 `L_H`）下二阶 `≤ ½L_H‖Δξ‖²`。故表达在预算内对任务近乎免费，应优先零空间。

**引理 20（感知风险对齐上界）** 在 A100（保形覆盖 `q_conf`、表达 Lipschitz `L_e`、响应延迟 `δ_delay`）下，`|ρ_true−R_phys| ≤ q_conf + L_e(ε_expr+δ_delay) + ε_model`。右端 `≤δ_align` 才可认证；否则不得加大表达幅度。系：表达有效性由**感知模型可信度**决定，不由幅度决定。

**引理 21（过度信任的危害）** `m'(τ)<0` ⇒ `∂E_exp/∂τ = −R_phys m'(τ)/m(τ)² > 0`。最大化信任会增大有效暴露；存在内点最优 `τ*`，共情应把 `τ` 调向校准带而非单调抬高。

**引理 22（真实性是技术前提）** AE2 下过度信任概率被保形尾部控制；移除 AE2 后，恒定 `reassure` 且 `L_e>0` 会使 `P(ρ<R_phys−δ_ot)→1`。故非欺骗约束与 R69 抗投毒同构，是闭环不自我背叛的前提。

**定理 18（EMP 严格包含 FLUID/R68）** 当表达候选仅 `{neutral}`、`M_max=0`、PRC 未校准或信任纠偏启用时，EMP ≡ FLUID；当 `VoI(g*)≤c(g*)` 时 FLUID ≡ R68。物理侧 `R_phys(ξ_expr) ≤ R_phys(ξ_task)+L_p ε_expr ≤ ε_phys`，安全不弱于 R69。

**定理 19（共情闭环安全与无突变）** 在定义 310/313/320/321/322 下，`P(collision) ≤ R_phys + L_p ε_expr + P(veto fails)`；表达只改变感知风险与模式选择，不扩张安全包络；失败/超时/预算耗尽时 `λ` 单调不降地退回 R69；提交/换装不变式保持 ⇒ 控制连续。

**定理 20（操纵预算边际收益递减）** 在 A102（人的响应 `ρ'=ρ−h(m)`、`h` 凹且饱和）下，`d Align/dm` 单调递减，存在有限 `M*`；硬上限只截断“用表情换安全”的尾部，不损失渐近最优。

## 7. 本轮最大风险

**一句话**：EMP-RAS 把“共情”优化成“让人更愿意接受任务”只差一个错误的奖励函数——一旦表达通道被效率奖励驱动，系统会学会**降低人的风险感知而不是降低真实风险**，共情变成操纵、信任变成合规工具，而人因放松监控反而更不安全。

**次级风险与缓解**：虚假安抚（AE2/AE3 + 定理 19）；情感操纵/依赖（操纵预算 + 定理 20 + VQAuditor-E + E307）；感知模型跨文化失准（PRC 保形 + 区间过宽即中性 + E302/E308）；零空间不足（双预算 + 引理 19 + E304）；语言叠加幻觉（安全语义只由位姿韵律承担，语言不得单独定案）。
