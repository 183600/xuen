# 第 3 轮（灵感循环第 3 轮；本轮灵感：「边缘计算」×「技术路线图」）

> **基线继承**：第 2 轮 **ToolGauge**（IP-315–320；定义 416–431；引理 46–50；实验 E426–E440）。
> 本轮纪律：**继续在前人基础上叠加，而不是推倒重来**——ToolGauge 的三个核心模块
> （L-Box / T-Box+TCV / MP-Φ+AP-Cal）全部保留；MODGAUGE 五不变式、语言扩展（定义 423）、
> 严格退化链全部保留；同时审计并修复第 2 轮遗留的**六处**缺陷（见 §5）。
> 新增两条正交轴：**能力轴**（哪台设备 / 哪种能力包络）与**时间轴**（哪段技术路线图）。

## 双轴映射（在 ToolGauge 上叠加）

| 灵感词 | 第 2 轮对象 | 升级为 | 一句话动机 |
|---|---|---|---|
| 边缘计算 | 完整工具库 T₀ + 中心化 MP-Φ + 单机算力 | **能力包络 CE + 云边拆分计量 SMM + 跨设备迁移 X-Xfer** | 真实机队异构、受限、间歇联网：校准不是「一个点」，而是「机队中的一片能力区域」 |
| 技术路线图 | 静态契约宇宙（定义永不过期） | **能力路线图 RM + 时序有效性窗 TVW + 路线图验收门 G-Gate** | 固件/工具/契约随版本演进：证书不是「永久真理」，而是「到下一个里程碑为止的带期限断言」 |

**核心命题**：把 ToolGauge 的「单机、静态、中心化」盲区修复，升级为
「**机队-能力索引 × 路线图-时序索引**」的**区域化认证**：
第 1–2 轮修复的是 R 中的一个格子 s；第 3 轮认证的是 (设备包络 d × 时间窗 t) 张量中的**一片区域**，
区域越大，就越要为「能力差」与「时间漂移」支付两种新的风险代价。

**集成链与退化方向**（与第 2 轮记号对齐）：
增强方向 `MODGAUGE ⊂ LeanGauge ⊂ ToolGauge ⊂ EdgeGauge`；退化方向相反。
EdgeGauge 失效（无工具 / 无预算 / 能力证明不可信 / OOD / 证书过期）⇒ 退回 ToolGauge 单机路径
⇒ 再退回 LeanGauge 纯数值路径 ⇒ 最后 MODGAUGE 原样。

**不变式保持声明**：
- MODGAUGE 五不变式（契约完整性、组合单调性、反作用通道完备、主张绑定、严格退化链）全部保留；
- 主张绑定（定义 423）扩展为**跨设备/跨时间主张**：语言主张必须引用「在其 Support 与 TVW 内有效」的回执，否则剥离（定义 440/441）；
- **严格退化链延长为四级**：EdgeGauge ⇐ ToolGauge ⇐ LeanGauge ⇐ MODGAUGE；
- **新增时序不变式（有效区域单调性）**：任何证书的有效区域只能因里程碑或漂移**收缩**，不得在无新证据时扩张（定义 440/445）。

## 0. 直觉与动机

**灵感 1（边缘计算 → 校准的「能力索引」）**
直觉：前两轮默认「一台全能设备 + 完整工具库 T₀ + 中心化预训练先验」。真实部署是**异构边缘机队**：
有的机器人没有敲击执行器，相机分辨率差一档，算力只有 1/20，网络时断时续。
于是「设备 A 上校准好的盲区」在设备 B 上可能**根本不可辨识**（缺工具导致某些方向无信息）。
边缘计算给我们的第一课不是「把模型压小」，而是：**把可复用性当作一个需要证明的量**——
一份校准能迁移到 B，必须证明 B 的能力包络在「与风险相关的子空间」上足够接近 A（能力差界，定义 435 / 引理 51）。
第二课是**分工**：重训练留在云，摊销后验蒸馏到边（SMM），只上传充分统计量（DP 证据，定义 437/438）；
本地算不动或信息不足时**离载**到对等设备/云（定义 446），而不是硬撑。

**灵感 2（技术路线图 → 证书的「时间索引」）**
直觉：路线图不是愿望清单，而是**一份对未来的、可被验收的契约**：它承诺在某里程碑交付某能力、淘汰某工具、改某 schema。
前两轮把「修复证书」当成永久真理；一旦 OTA 升级换了工具或改了契约参数语义，
旧证书会**静默过期**——系统继续拿着一个「当时正确、现在错误」的校准当依据，比没有校准更危险。
路线图的启示是把证书改成**带期限、带迁移映射、带验收门**的对象：
证书只在 `[签发, min(过期, 下一个影响它的里程碑, 漂移告警))` 内有效（TVW，定义 440）；
跨越里程碑时必须提供参数迁移 μ_k 或主动失效（RCC，定义 441）；
每个里程碑是一次 go/no-go 验收（G-Gate，定义 442），未通过不得发布。
第三层是**制度**：用证据账本（定义 444）把「能力主张」与「证据等级」绑定，禁止路线图跑在证据前面。

**为什么这是「叠加」而不是「换题」**
第 1–2 轮的错误模型是「单机局部修复」；第 3 轮只是把 R 从矩阵升为张量 `R[d,s,t]`，
把每份证书的 `Support` 从隐式的「全世界」显式化为「一个能力集合 × 一个时间窗」。
当 `Support = 全集、TVW = ∞、offload = ∅、ε_dp = 0` 时，EdgeGauge **逐字退化为 ToolGauge**（定义 447）。

## 1. 形式化定义（增量：定义 432–447）

**定义 432（能力包络 CE）** 设备 d 的能力包络 `CE_d = (T_d ⊆ T₀, S_d, A_d, Res_d, v_d)`：
可用工具子集；传感器规格（分辨率 / 噪声底 / 基线）；执行器包络；资源（FLOPs / 内存 / 功耗 / 带宽）；固件版本。
工具 t 在 d 上的有效观测为 `N(μ, σ_{t,d}²)`，且 `σ_{t,d} ≥ σ_{t,d*}`（d* 为参考设备）。

**定义 433（能力证明 CA）** `attest(d) = (每工具在参考标准件上的实测 σ̂_{t,d}, 资源遥测, 固件哈希, sig, ts)`，
带有效期与信任级。缺失 / 过期 / 不可信 ⇒ 采用**保守包络** `CE_d⁻`（最大噪声、最小工具集、降档分辨率）。
关键：能力包络是**实测**而非自报。

**定义 434（能力索引契约 CIC）** 第 2 轮契约 C 升级为 `C = (u, χ_R, claims, Support(C) ⊆ 2^{CE}, ver)`，
`Support(C)` 是**经探测/验证覆盖的能力集合**，不是全集。

**定义 435（能力差与 Fisher 缺陷）** 设风险相关参数 u 的观测设计向量 φ_t，设备信息阵
`I_d = Σ_{t∈T_d} σ_{t,d}^{-2} φ_t φ_t^T`。源 A → 目标 B 的能力差定义为
`g(A,B) = λ_max( (I_B^{-1} − I_A^{-1})|_{风险子空间} )`（当 `I_B ⪯ I_A` 时非负）；
若风险相关方向落在 `ker(I_B)`（缺工具导致不可辨识），记 `g = ∞`。

**定义 436（跨设备迁移策略 X-Xfer）** 给定目标 d 与契约 C：
- 若 `g(A,d) ≤ g_max` 且 attest 可信 ⇒ **reuse**（后验按定义 435 膨胀）；
- 若工具/预算可支持 ⇒ **local-reprobe**；
- 若本地不可但存在包络超集的 peer/cloud ⇒ **offload**（定义 446）；
- 否则 **stub + RED**。

**定义 437（云边拆分计量 SMM）** 云侧 `MP-Φ_θ`（完整预训练）；边侧蒸馏 `MP-Φ_e^d`，
参数/算力受 `Res_d` 约束，认证近似误差 `‖q_e^d − q_cloud‖ ≤ ε_a`。
运行期先用 `q_e^d`；OOD 分数超阈或 ε_a 敏感方向被触发 ⇒ 升级到云。

**定义 438（证据蒸馏与隐私预算 DP-Evidence）** 仅上传充分统计量 `s_j = (φ_j, y_j, w_j)`（或粗化摘要），
不上传原始传感器数据；每设备在窗口内 DP 预算 `ε_dp`，聚合时裁剪 + 加噪。效用损失计入引理 53。

**定义 439（能力路线图 RM）** `RM = {M_0,…,M_K}`，`M_k = (t_k, Δ_k, G_k)`，
`Δ_k = (工具增删, schema/契约变更, 弃用)`；里程碑之间能力宇宙不变，里程碑处**离散跳变**；
未计划 OTA 视为外生里程碑，按最坏 Δ 处理。

**定义 440（时序有效性窗 TVW）** 证书 C 的有效期为
`[t_issue, min(t_exp, 下一个影响 Support(C) 的里程碑, 漂移告警时刻))`；
到期即降级，对应盲区回到 UNKNOWN 并排队再验证。

**定义 441（路线图一致契约 RCC）** C 必引用路线图段 `seg(C)`；对与 seg 相交的每个影响性里程碑，
须给出参数迁移 `μ_k` 或显式失效；无迁移而跨越 ⇒ C 不得声明跨该里程碑有效。

**定义 442（路线图感知验收门 G-Gate）** 里程碑 M_k 的 go/no-go：
(i) 所有活跃 C 在其所有活跃包络上 RCC 成立；(ii) 重放对抗盲区测试集；
(iii) 跨包络契约回归；(iv) 过期证书数 = 0，或带风险接受显式豁免。

**定义 443（边缘资源契约 ER-Contract）** `ER_d = (C_max, M_max, P_max, BW_max, L_max, τ_repair)`；
最弱设备上 50Hz 路径必须仍在 `C_max` 内；修复调度不得突破 `P_max / τ_repair`。

**定义 444（证据账本 / TRL）** 每个能力主张附证据级
`e ∈ {E0 轶事, E1 单机, E2 多包络, E3 路线图重放, E4 机队实测}`；
路线图提升能力需达到对应级别（制度约束，防止「路线图跑在证据前面」）。

**定义 445（失效与再验证策略）** 证书过期 / 能力证明变更 / 漂移告警 ⇒ 标记该 (d,t) 单元失效，
在下一个静默窗调度再验证，期间回退父级路径；**无新证据不得续期**。

**定义 446（边缘离载协议）** 本地不可验证（缺工具 / 超预算 / OOD / 证明不可信）⇒
委托给包络超集的 peer/cloud；返回的 CIC 只有当 `g(本地, 受托方) ≤ g_max` 时才能把本地包络纳入 Support，
否则只覆盖受托方包络；记录数据最小化与离载时延界。

**定义 447（继承与路线图一致不变式）** 沿用第 1–2 轮全部记号与五不变式；
新增**有效区域单调性**（只收缩不扩张）与**跨设备支撑性**（无 Support 不施加）；
EdgeGauge 在 `CE=全集、RM=单里程碑、offload=∅、ε_dp=0、TVW=∞` 时 ≡ ToolGauge。

## 2. 关键算法骨架

```python
# IP-321 C-Box：能力包络 + 能力证明（实测而非自报）
@dataclass
class CapabilityEnvelope:
    tools: frozenset; sensor: SensorSpec; actuator: ActuatorSpec
    res: Resources; fw: str

def attest(device, phantom) -> Attestation:
    try:
        return measure_sigma(device, phantom)      # 参考标准件实测
    except (Missing, Expired, Untrusted):
        return conservative(device)                # CE_d⁻，降级包络

# IP-322 X-Box：能力差迁移
class Xfer:
    def resolve(self, C, d, att):
        if not trusted(att):            return ("stub", None)
        g = fisher_gap(C.envelope, d)              # 定义 435
        if g <= self.g_max:
            return ("reuse", inflate(C.posterior, g))
        if self.can_reprobe(d):         return ("local_reprobe", None)
        if self.find_superset_peer(d):  return ("offload", None)
        return ("stub", None)

# IP-323 F-Box：云边拆分计量 + DP 证据
class SplitMetrology:
    def calibrate(self, receipts, H, s, d):
        q = self.mp_phi_edge[d](featurize(receipts, H, s))   # 蒸馏先验
        q = clamp_min(q.Sigma, KAPPA_PHYS)                   # 继承保守性夹紧
        if self.ood_score(q) > self.tau_ood:
            return self.cloud_fallback(receipts, H, s)        # 升级到云
        return q
    def upload(self, stats, dp_budget):
        return clip_noise(stats, dp_budget)                   # 只传充分统计量

# IP-324 R-Map：路线图 + 时序有效性
class Roadmap:
    def next_change(self, C, t):
        return min([m.t for m in self.milestones
                    if m.affects(C.Support) and m.t > t], default=INF)
    def valid(self, C, d, t):
        return (d in C.Support
                and C.rcc_ok(self.segment(t))          # 定义 441
                and t < self.next_change(C, t)         # TVW，定义 440
                and not drift_alarm(C))

# IP-325 G-Gate：路线图验收门
def gate(M_k, fleet):
    ok  = all(C.rcc_ok(M_k) for C in fleet.active_contracts())
    ok &= fleet.replay_adversarial(M_k)                # 对抗重放
    ok &= fleet.regression_across_envelopes()          # 跨包络回归
    ok &= (fleet.stale_certificates() == 0 or M_k.waive_approved)
    return ok

# IP-326 EdgeGauge 主闭环（在 ToolGauge 外层叠加，50Hz 路径不动）
def edgegauge_round(dev, obs, t):
    if not dev.attestation_trusted():
        return ToolGauge_round(dev, obs, t)            # 退化第 1 级
    for s in dev.dbox.detect_blind_spot():
        C = dev.contracts.get(s)
        if C and dev.roadmap.valid(C, dev, t):
            continue                                   # 区域内有效，免修
        act, payload = dev.xfer.resolve(C, dev, dev.attestation)
        if act == "reuse":
            dev.apply(payload); continue
        if act == "offload":
            dev.offload_repair(s); continue            # 异步
        dev.schedule(toolgauge_6c, s)                  # 本地再探测
    if dev.roadmap.gate_due(t):
        dev.run_gate()                                 # 定义 442
    return ToolGauge_round(dev, obs, t)                # 主控不变
```

## 3. 推导

**引理 51（能力差迁移界）** 亚高斯观测下，对风险相关线性泛函 vᵀu，迁移后验方差满足
`Var_B^{xfer}(vᵀu) ≥ Var_A(vᵀu) + vᵀ(I_B^{-1} − I_A^{-1})v`；方向 `v ∈ ker(I_B)` 时不可迁移（方差 ∞）。
证明思路：高斯模型下后验精度即 Fisher 信息，`I_B ⪯ I_A ⇒ I_B^{-1} ⪰ I_A^{-1}`；不可辨识方向对应无穷方差。
**系 51.1**：`reuse` 仅在风险相关方向 `g ≤ g_max` 时安全；否则必须复探或离载（定义 436）。

**引理 52（时序健全性 / 路线图一致性主定理）** 若
(i) 所有活跃 C 在其 Support 上 RCC 成立；(ii) Support 内每个包络有可信且未过期的证明；
(iii) 漂移监控与 P-Quarantine 未触发；
则 MODGAUGE 五不变式与第 2 轮安全命题在**整个覆盖的 (d,t) 区域**成立，而非仅在签发时刻。
证明思路：对里程碑归纳——基准时刻成立；每跨一个 `Δ_k`，由迁移 `μ_k` 与 G-Gate 通过保持不变式；
里程碑之间仅发生漂移事件，由 TVW 与 P-Quarantine 兜底。

**引理 53（拆分先验 + DP 的组合界）** 端到端超额风险
`R̄ − R̄* ≤ [引理 47 项] + ε_a + C_dp·ε_dp + 2η`。
证明思路：云先验—蒸馏误差 `ε_a` 与 DP 噪声项各自可加；`η` 为 sim→real 偏移（沿用第 2 轮）。
**系 53.1**：压缩误差与隐私噪声可加，且可用更多本地样本 `N_bl` 抵消，得到「延迟-隐私-风险」三者可计算的预算分配。

**引理 54（边缘时延与资源保持）** 在最弱可信包络上，50Hz 路径周期 ≤ `T_budget`
（第 2 轮 <0.2ms 回执验证 + 常量）；修复要么在 ER-Contract 内完成、要么离载且 ≤ `τ_repair`、要么降级；
硬实时（引理 45）与预算不变式保持。

**引理 55（机队放大受支撑性约束）** 一份契约 C 只能施加于 `Support(C)` 内、或经 X-Xfer 证明 `g ≤ g_max` 的包络；
结合 G-Gate 每包络对抗重放与 P-Quarantine，任何单一坏先验的最大污染区域被「证明可信的包络集合」限制；
要造成全机队相关失效，必须**同时**伪造能力证明、骗过能力差界、并通过验收门——三者失败概率相乘。
**系 55.1**：第 2 轮「跨盲区相关偏差」因此不会自动升级为「跨机队相关偏差」，**除非能力证明本身被攻破**——这正是本轮最大风险的所在。

## 4. 复杂度分析（边缘视角）

| 组件 | 域 | 算力 / 时延 | 内存 | 功耗 | 正确性锚 |

| 云升级 / 离载 | 网络 | RTT + 云前向 | — | 中 | 定义 446 |
| DP 上传 | 窗口 | O(d_e) | O(d_e) | 低 | 定义 438 |
| TVW / RCC 查询 | 每周期 | O(log K) | O(K) | 可忽略 | 定义 440/441 |
| G-Gate | 里程碑 | 离线批处理 | O(机队) | — | 定义 442、引理 52 |
| 50Hz 路径 | 内联 | 同第 2 轮 ≤ 0.2ms | 同 | 同 | 引理 54 |

**相对第 2 轮**：新增每周期 O(log K) 的 TVW 查询与 O(1) 能力证明状态位；
重活（迁移、蒸馏、离载、G-Gate）全在异步 / 离线。代价换来的是一份证书从「单机永久」变为「机队区域 + 有限期」。

## 6. 本轮最大风险（一句话）

**一句话**：整套「能力差界 + 时序有效性 + 验收门」都建立在**能力证明**这一自我测量的元数据之上——
一旦某次 OTA / 硬件改版让设备**自称的证据**与现实漂移（或证明被伪造 / 过期未被发现），
系统会用一套自洽、带审计背书、且「看起来已验收」的合同，把错误校准**合法地复制到整个机队和整条时间线**；
这比第 1–2 轮的局部错误更危险，因为它不再是「一个盲区错了」，而是「一类设备在一段历史里全错了，且每一步都有证书」。

**次级风险与缓解**：
1. **证明可信度** → 能力证明用参考标准件实测 + 周期性再证明 + 缺失即保守包络（定义 433），并以 E442 做误报/漏报压力测试；
2. **时间线漂移（未计划 OTA）** → 把外生 OTA 当最坏 Δ 里程碑，TVW 主动收缩并触发再验证（定义 439/440，E455）；
3. **隐私-效用权衡被滥用** → DP 预算硬上限 + 充分统计量最小化（定义 438，E446）；
4. **离载放大时延/依赖** → 离载仅在本地不可辨识时触发，且 τ_repair 硬界（定义 446，E449）；
5. **G-Gate 变成橡皮章** → 证据账本 TRL 门槛 + 对抗重放不可豁免（定义 442/444，E454）；
6. **蒸馏先验过度自信** → 沿用保守性夹紧 `Σ ≽ κ_phys·I`，并新增 ε_a 认证（定义 437，引理 53）；
7. **路线图跑在证据前面** → TRL 证据等级制度使「未达级不得写入路线图」（定义 444）。

## 2. 形式化定义（要点）

**定义 432/433（CE / 能力证明）** 能力包络是 `(工具子集, 传感器规格, 执行器包络, 资源, 固件版本)`；工具有效观测 `N(μ,σ_{t,d}²)` 且 `σ_{t,d}≥σ_{t,d*}`。能力证明必须**实测**（参考标准件 + 资源遥测 + 固件哈希 + 签名 + 有效期）；缺失/过期/不可信 ⇒ 保守包络 `CE_d⁻`。
**定义 434（CIC）** 第 2 轮契约升级为带 `Support(C) ⊆ 2^{CE}` 与 `ver` 的能力索引契约；Support 是已验证覆盖，不是全集。
**定义 435（能力差）** `I_d = Σ_{t∈T_d} σ_{t,d}^{-2} φ_t φ_t^T`；`g(A,B)=λ_max((I_B^{-1}−I_A^{-1})|_风险子空间)`，风险方向落入 `ker(I_B)` 记 ∞。
**定义 436（X-Xfer）** `g≤g_max ∧ attest 可信 ⇒ reuse`（按 g 膨胀）；可复探 ⇒ local-reprobe；有超集 peer/cloud ⇒ offload；否则 stub+RED。
**定义 437（SMM）** 云 `MP-Φ_θ`、边 `MP-Φ_e^d`，`‖q_e−q_cloud‖≤ε_a`；OOD 或 ε_a 敏感方向触发 ⇒ 升级云。
**定义 438（DP-Evidence）** 只上传充分统计量，不上传原始传感器数据；每设备窗口 `ε_dp`，裁剪+加噪。
**定义 439/440（RM / TVW）** 里程碑间能力宇宙不变，里程碑处离散跳变；外生 OTA 按最坏 Δ。证书有效期取「过期 / 下一相关里程碑 / 漂移告警」三者最小。
**定义 441/442（RCC / G-Gate）** 跨里程碑须有 `μ_k` 否则不得声明有效；门检查 RCC、对抗重放、跨包络回归、过期证书清零。
**定义 443/444（ER / TRL）** 最弱设备 50Hz 仍须在 `C_max` 内；能力主张附证据级 E0–E4，未达级不得写入路线图。
**定义 445/446/447（再验证 / 离载 / 继承）** 失效即回退父级、无新证据不续期；离载仅当本地不可辨识，且只有当 `g(本地,受托方)≤g_max` 才把本地包络纳入 Support；`CE=全集、RM=单里程碑、offload=∅、ε_dp=0、TVW=∞` 时 ≡ ToolGauge。

## 3. 关键算法骨架

```python
# IP-321 C-Box：能力证明（实测优先，失败即保守）
def attest(device, phantom):
    try:    return measure_sigma(device, phantom)
    except (Missing, Expired, Untrusted): return conservative(device)

# IP-322 X-Box：Fisher 能力差迁移
class Xfer:
    def resolve(self, C, d, att):
        if not trusted(att):            return ("stub", None)
        g = lambda_max(psd_solve(Info(d), -1) - psd_solve(Info(C.env), -1), subspace=C.risk)
        if g <= self.g_max:             return ("reuse", inflate(C.posterior, g))
        if self.can_reprobe(d):         return ("local_reprobe", None)
        if self.find_superset_peer(d):  return ("offload", None)
        return ("stub", None)

# IP-323 F-Box：云边拆分 + 保守夹紧 + OOD 升级
class SplitMetrology:
    def calibrate(self, receipts, H, s, d):
        q = self.mp_phi_edge[d](featurize(receipts, H, s))
        q.Sigma = clamp_min(q.Sigma, KAPPA_PHYS)          # 继承定义 420
        return self.cloud_fallback(receipts, H, s) if self.ood(q) > self.tau else q
    def upload(self, stats, eps_dp): return clip_noise(stats, eps_dp)

# IP-324 R-Map：TVW + RCC
class Roadmap:
    def valid(self, C, d, t):
        return (d in C.Support and C.rcc_ok(self.segment(t))
                and t < self.next_change(C, t) and not drift_alarm(C))

# IP-325 G-Gate
def gate(M_k, fleet):
    return (all(C.rcc_ok(M_k) for C in fleet.active_contracts())
            and fleet.replay_adversarial(M_k)
            and fleet.regression_across_envelopes()
            and (fleet.stale_certificates() == 0 or M_k.waive_approved))

# IP-326 EdgeGauge 主闭环（50Hz 路径不变）
def edgegauge_round(dev, obs, t):
    if not dev.attestation_trusted(): return ToolGauge_round(dev, obs, t)
    for s in dev.dbox.detect_blind_spot():
        C = dev.contracts.get(s)
        if C and dev.roadmap.valid(C, dev, t): continue
        act, payload = dev.xfer.resolve(C, dev, dev.attestation)
        if   act == "reuse":   dev.apply(payload)
        elif act == "offload": dev.offload_repair(s)
        else:                  dev.schedule(toolgauge_6c, s)
    if dev.roadmap.gate_due(t): dev.run_gate()
    return ToolGauge_round(dev, obs, t)
```

## 4. 推导

**引理 51（能力差迁移界）** 亚高斯观测下，`Var_B^{xfer}(vᵀu) ≥ Var_A(vᵀu) + vᵀ(I_B^{-1}−I_A^{-1})v`；`v∈ker(I_B)` 时不可迁移。**系**：reuse 仅在风险方向 `g≤g_max` 时安全，否则复探/离载。
**引理 52（时序健全性主定理）** 若 RCC 成立、Support 内证明可信未过期、漂移/P-Quarantine 未触发，则五不变式与第 2 轮安全命题在**整个 (d,t) 覆盖区域**成立（对里程碑归纳；段内由 TVW 与隔离器兜底）。
**引理 53（拆分先验+DP 组合界）** `R̄−R̄* ≤ [引理 47 项] + ε_a + C_dp·ε_dp + 2η`；**系**：压缩、隐私、样本量可互相补偿，形成可计算的延迟-隐私-风险预算分配。
**引理 54（边缘时延资源保持）** 最弱可信包络上 50Hz 周期 ≤ T_budget；修复在 ER-Contract 内完成、或离载 ≤ τ_repair、或降级 ⇒ 硬实时与预算不变式保持。
**引理 55（机队放大受支撑性约束）** 契约只能施加于 Support 或 `g≤g_max` 的包络；结合对抗重放与 P-Quarantine，全机队相关失效需**同时**伪造证明、骗过 g 界、通过验收门，概率相乘。**系 55.1**：跨盲区偏差不会自动升级为跨机队偏差，**除非能力证明被攻破**（本轮最大风险所在）。

这比第 1–2 轮的局部错误更危险，因为它不再是「一个盲区错了」，而是「一类设备在一段历史里全错了，且每一步都有证书」。
三重兜底：实测能力证明 + 周期性再证明（定义 433，E442）、最坏 Δ 外生里程碑 + TVW 收缩（定义 439/440，E455）、
TRL 证据门槛 + 不可豁免的对抗重放（定义 442/444，E454）。
