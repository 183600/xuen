# 第 11 轮（承接第 10 轮 MetricVoiceGauge-STF-NRB-LS；本轮灵感：「续航能力」×「语义分割」）

> **基线**：第 10 轮 MetricVoiceGauge-STF-NRB-LS（定义 540–548；引理 87–91；实验 E571–E590）。
> 本轮纪律：**物理守恒 + 稠密语义证据 + 界源分离**。v10 把信任空间化（STF）、规范数据化（NRB）、模型轻量化（LS），但留下两处系统性盲区：其一，块证书是**瞬时几何**的，默认「中止点总能到达」，而 8 小时任务里先失效的可能是**到达中止点所需的能量**；v10 的 `E_m` 只是单模块功率配额与瞬时 25W 约束，`E_budget` 这一层跨时间能量守恒根本不存在。其二，v10 的信任场是**稀疏地标级**的（|V|≤512），而「地面能不能走、走起来多费电、语义边界在哪」本质是**稠密**问题——走廊中央一块湿滑、一片沙地、一扇玻璃门，未必对应任何地标，却恰是能量误差与可通行风险最大处。必须保持 v10 铁律：任一新模块失效 ⇒ 注入声明中立元，行为严格**等价**或**支配**于 v10，而非行为漂移。

## 0. 直觉与动机

**灵感 1（续航能力 → 从瞬时几何证书到能量可达证书）**
直觉：v10 的证书回答「此刻几何上安全吗」，但安全的前提是「出事时到得了 p*」。在一次 8 小时任务的后半程，限制系统的往往不是瞬时 25W 功率、也不是总电量，而是**中止可行性的能量余量**：Π_r 的减速、绕行、语音披露、返航都在耗电；低电量时一个几何上完美的块，可能因为执行完它之后再也到不了最近中止点而失效。核心创新：**续航可达证书（Endurance Reachability Certificate, ERC）**——把块执行能量、到最近中止点能量、停驻能量与保守误差 `ε_E^⊙` 合成为 `r_t`；证书条件升级为 `r_t ≤ E_usable − E_res` 且 `E_mission + r_t ≤ E_budget`。`E_res` 是**不可动保留能量**，只用于安全停驻/返航/救援，任务永远不能借用。关键性质：能量守恒是**物理约束**，不依赖嵌入距离、不依赖 τ_sem，因此它是对「低电量诱发的证书失效」的**非语义兜底**——对抗纹理骗得过嵌入，骗不过焦耳。

**灵感 2（语义分割 → 从稀疏地标信任场到稠密语义—可通行成本场）**
直觉：v10 的 STF 是「地标级」的：它告诉你某个已知地标变了，但走廊地板上一块湿滑、一片草地、一段台阶、一扇透明玻璃门，未必对应任何地标。语义分割给出**逐像素**的可通行性、边界与不确定性；而「走起来费不费电」同样由材质/坡度/动态人类决定。核心创新：**稠密语义—可通行成本场（Dense Semantic-Traversability Cost Field, DSCF）**——复用 v8 已有分割/检测骨干，低分辨率（64×64）+ INT8 + 多帧时序融合，输出逐格类别分布 `p(x)`、任务侧单位能耗 `c_sem(x)`、不确定度 `u(x)`（归一化熵 + 边界梯度 + unknown 类）。它同时进入两个地方：`u(x)` 抬高语义安全余量 `β^⊙`，`c_sem(x)` 只用于任务侧选路/计费。**关键纪律（P18 界源分离）**：安全能量界 `r_t` 只用**语义无关**的最坏单位能耗 `c_max`，`c_sem` 永远不许把 `r_t` 往下修——否则「语义 + 能量」就不再是两条独立证据，而会一起被同一块没见过的地形骗过。DSCF 对 v10 最大风险（τ_sem 被长尾/对抗语义穿透）只提供**第二路语义证据**（逐像素熵/边界/unknown，覆盖稀疏地标看不见的空地），并**不声称**消除语义风险；真正的非语义兜底是 ERC。

**两者咬合**：ERC 管「跑不动」，DSCF 管「看不清 / 走错地 / 算错电」。DSCF 把语义不确定度**加进**能量误差上界（坏地形 → 更保守），ERC 用语义无关的 `c_max` 给 DSCF 兜底（语义全错，能量界仍成立）。联合证书 `Ĉ^⊙ = (ĝ_min, ê_max, γ̂_grasp, β^⊙, n_t, r_t, U_seg)`：`U_seg` 是足迹内 unknown/高熵占比，既进证书也进门控。

## 1. 研究问题（轮次升级版）

- **Q1（能量可达）**：如何把块证书从瞬时几何条件升级为「执行块 + 到达最近中止点 + 停驻 + 保留 `E_res`」的能量可达条件，使 8h 任务中「证书有效但中止不可达」= 0，同时把模型误差以保守 `ε_E^⊙` 吸收而不显著牺牲任务完成率？
- **Q2（稠密语义）**：如何用低分辨率、INT8、时序融合的稠密语义场，把语义证据从「地标级」推进到「逐足迹级」，并在 `c_sem` 不参与安全能量界的约束下，仍让不确定度/unknown 提高证书保守性（而不是制造新的相关失效）？
- **Q3（联合退化）**：当 ERC 或 DSCF 任一失效时，如何保证行为**等价或支配**于 v10，且 50Hz 五检守卫 ≤20ms、功率 ≤25W、任务完成率不低于 v10？

## 2. 设计原则（在 P13–P15 基础上新增 P16–P18）

**P16 中止优先能量律（Abort-First Energy Discipline, ERC）**
能量保留 `E_res` 是硬不变式，不可被任务预算借用；任何块的可行性以「执行块 + 到达最近中止点 + 停驻 + ε_E」为最小能量单位；`ε_E^⊙` 必须取标定误差上界并加上语义不确定度；能量证书失效或能量状态不可观测时，只许收缩（停驻/返航/降 K），不许沿用瞬时功率假设继续跑。

**P17 稠密语义证据律（Dense Semantic Evidence, DSCF）**
语义证据必须落到**足迹级**且携带不确定度；不确定度只能**抬高**保守界，不能被平均掉或抵消；unknown/透明/高熵区域默认不可通行或加严；稀疏 STF 与稠密 DSCF 是**互补而非替代**——任一可见即用，两者不一致时取更保守者。

**P18 安全—任务界源分离律（Certificate/Task Bound Separation）**
安全证书只许使用与语义内容无关的物理上界（`c_max`、`e_phys^+`、`e_stop^+`、`ε_base`）加上**单向**的语义保守增量（`λ_u·u`、`λ_b·R_bnd`）；语义能耗估计 `c_sem` 只许用于任务选路/计费，永不许降低安全能量界或安全余量。界源一旦混用，联合证书就不再是两条独立证据。

## 3. 与基线的接口（如何退化）

- **ERC 失效**（电量计不新鲜 / 标定版本不匹配 / `E_usable` 不可得）⇒ 不再信任实时能量：取保守上界 `r_t^max`（满电减去已知消耗的最坏情况）；若上界仍不可得 ⇒ 立即安全停驻并返航（动作集 ⊆ v10，支配）；
- **DSCF 失效**（分割超时 / 新鲜度 > `T_seg` / INT8 校验失败）⇒ `u≡0`、`R_bnd≡0`、`c_sem←c_base`、`U_seg` 不参与门控：`β^⊙=β_STF` 精确回退 v10，`r_t` 不变（本就只用 `c_max`）——**行为等价于 v10**，只是失去稠密语义增益；
- **ESL 失效**（写失败 / 链头校验失败 / 缺口）⇒ 下一块 `Π_r`（同 v10 台账缺口规则）；
- **STF 失效** ⇒ v10 Level-1（K=1、β_base）；**NRB 失效** ⇒ v10 `Π_r`；**AC 失效** ⇒ K=1；**ID 失效** ⇒ 全模块 active、归因冻结（新增 ERC/DSCF/ESL 一律 `φ^elig=false`，仅「能量模型标定」与「DSCF 时序融合缓存」可蒸馏）；**MW 失效** ⇒ v10 手写网关；**v8 失效** ⇒ 中立元注入 ⇒ v7 ⇒ v6。

## 4. 预期贡献

1. **能量可达证书**：把 v10「瞬时安全但到不了中止点」的盲区显式化，给出保留能量不变式与可测的 `ε_E^⊙` 覆盖（引理 92–93），并提供**非语义**物理兜底；
2. **稠密语义—可通行成本场**：把语义证据从地标级推进到足迹级（unknown/透明/边界/高熵），并证明其只增不减地细化 v10 的保守性、失效时精确回退（引理 94–95）；
3. **界源分离下的联合证书与退化代数**：`Ĉ^⊙` 五检守卫与全故障路径的等价/支配证明（引理 96–98），保持 50Hz/25W；
4. **E591–E610** 覆盖能量标定、低电量注入、语义—能量联合对抗、稠密语义标定、透明/未知类、界源混用检验、故障消融、长跑与竞赛。

## 5. 本轮最大风险

**一句话**：`c_max`、`ε_base` 与分割标定都是离线常数——真正没见过的地形（沙/泥/冰/透明/镜面）可能同时让分割把它判成「良性且低耗」、让能量模型低估实际滚阻，而两者又共享同一套位姿/深度状态估计；一旦 `c_max` 本身被超出，所谓「物理兜底」与「语义证据」会以相关方式同时失效，v11 会比 v10 更难发现（v10 至少只欠一份语义证据，v11 却可能错误地相信自己有两份）。

**新增定义 549（能量状态与续航信任域）**
`E_usable(t) = η(T(t), age)·SoC(t)·E_nom − E_res`；`U_t^E ⇔` 电量计新鲜度 ≤ `T_E=1s` ∧ `E_usable(t) ≥ E_min` ∧ 标定版本哈希匹配。`E_res` 永不计入 `E_usable`，即中止能量不可被任务借用。能量状态不可观测时视作 `U_t^E=false`，不做乐观推断。

**新增定义 550（安全能量上界与续航可达裕量）**
对块 ζ、中止点集 `P*(ζ)`、足迹 `Φ(ζ)`（长度 L）：
```
e_safe(ζ) = e_phys⁺(ζ) + c_max·L(Φ(ζ)) + e_compute(ζ) + ε_base
r_t(ζ)    = e_safe(ζ) + max_{p∈P*(ζ)} e_reach⁺(p) + e_stop⁺ + ε_E^⊙(Φ(ζ))
```
其中 `e_phys⁺` 是执行器功率积分上界，`c_max` 是**语义无关**的最坏单位路程能耗上界，`e_reach⁺` 用 `c_max` 的最短路上界，`ε_E^⊙` 见定义 553。
**能量可行** `E-feas(ζ) ⇔ r_t(ζ) ≤ E_usable(t) ∧ E_mission(t) + r_t(ζ) ≤ E_budget(t)`。
注意：`c_sem` 不出现在 `r_t` 中（P18）。

**新增定义 551（任务能量预算与保留不变式）**
`E_budget(t) = E_usable(0) − E_res − E_return(B)`，B 为最近返航/补给点。预算按块更新、块内不变；超预算候选在**生成期**即拒绝，而不是运行期再补救。保留不变式：任何时刻 `E_usable(t) ≥ 0` 必须成立，且 `E_res` 借用量恒为 0。

**新增定义 552（稠密语义—可通行成本场 DSCF）**
DSCF 为低分辨率（`H×W=64×64`）逐格三元组场 `S(x)=(p(x), c_sem(x), u(x))`，由 v8 分割/检测骨干（INT8）+ 多帧时序融合得到：
- `p(x)∈Δ^{C−1}`：类别分布（含 `unknown`/`glass` 类）；
- `c_sem(x) = Σ_c p_c(x)·κ_c`：任务侧单位路程能耗（`κ_c` 为类先验能耗系数，仅用于选路/计费）；
- `u(x) = clip( H(p(x))/log C + ‖∇p(x)‖/τ_b + 1[unknown∨glass](x), 0, 1 )`：归一化熵 + 边界梯度 + 未知类指示。

维护规则：只在位姿可追踪时融合；`freshness(S) ≤ T_seg=200ms`；增量 ≤0.4ms/次、≤96KB。

**新增定义 553（语义不确定度—能量误差耦合）**
`ε_E^⊙(Φ) = ε_base + λ_u·sup_{x∈Φ} u(x) + λ_b·R_bnd(Φ)`，`R_bnd(Φ)=sup_{x∈Φ}‖∇p(x)‖`（边界带熵上界）。`λ_u, λ_b ≥ 0`（E597 标定），故 `ε_E^⊙ ≥ ε_base`。
联合语义余量 `β^⊙(ζ) = β_base + λ_s·sup_{x∈Φ} T(x) + λ_u·sup_{x∈Φ} u(x) + λ_b·R_bnd(Φ)`。三项均非负 ⇒ `β^⊙ ≥ β_STF`；DSCF 失效时后两项为 0 ⇒ `β^⊙ = β_STF`（精确保退）。

**新增定义 554（联合证书；升级定义 543）**
`Ĉ_t^⊙ = (ĝ_min, ê_max, γ̂_grasp, β^⊙, n_t, r_t, U_seg)`，`U_seg = |{x∈Φ: u(x)>τ_u}| / |Φ|`。
`Ĉ_t^⊙ valid ⇔` v10 定义 543 全条件（以 `β^⊙` 替换 `β_STF`）∧ `E-feas` ∧ `U_seg ≤ τ_U` ∧ `freshness(G_LM) ≤ T_fresh`。任一项不可得即 invalid（保守）。

**新增定义 555（安全—任务能量界分离）**
安全界 `r_t` 只依赖 `e_phys⁺、c_max、e_reach⁺、e_stop⁺、ε_E^⊙`；任务界 `e_task(ζ) = e_phys(ζ) + ∫_{Φ(ζ)} c_sem(x) dℓ` 只用于候选打分与能量账本。**单调性要求**：DSCF 的任何输出只能使 `r_t` 不降（通过 `u, R_bnd`），不能使 `r_t` 下降；`c_sem` 的任何低估不影响 `E-feas`。当 DSCF 失效时 `e_task` 退回 `e_phys + c_base·L`。

**新增定义 556（五检守卫；升级定义 547）**
50Hz 五检（O(k)，k≤8；DSCF 查询 O(1) 缓存）：
1. 证书有效（`Ĉ^⊙`，v10 检 1 升级）；
2. 停车不变式（v10 检 2）；
3. **语义双源检查**：`max( sup_{ℓ∈N_k} ν̄_ℓ, U_seg_local, R_bnd_local ) > τ_sem`（稀疏 STF 与稠密 DSCF 互补，取更保守）；
4. 快规范（v10 检 4）；
5. **能量可达**：`E-feas(剩余块)`。

任一失败 ⇒ 沿 v10 定义 534 切最近中止点（或收缩）；总预算 ≤0.7ms。

**新增定义 557（未知/透明/高熵保守否决）**
足迹内若 `U_seg > τ_U`，或存在 `glass`/`unknown` 且其后仍有自由空间（透明障碍不可见风险），则该块**不可认证**：要么绕行（重采样），要么以 `c_max` 重估能量后降 K；不得以「分割置信度低但平均可通行」放行。此规则只收缩，不扩权。

**新增定义 558（能量—语义台账 ESL）**
在 v10 `Λ` 上扩展记录：`ΔE, E_usable, r_t, e_task, u_max, U_seg, 裁决, 中止/返航事件`。记录为 append-only 哈希链
`H(prev ‖ t ‖ ζ_id ‖ ΔE ‖ E_usable ‖ r_t ‖ e_task ‖ u_max ‖ U_seg ‖ verdict)`；
每 `C_w=64` 块设一次链头校验点；缺口（漏写/校验失败）⇒ 下一块 `Π_r`。

**新增定义 559（双速 DSCF 更新与新鲜度）**
感知侧 10–20Hz 更新（≤0.4ms/次，INT8）；5Hz 块级对整条足迹复算 `U_seg, R_bnd` 与 `c_sem` 积分（≤0.5ms 摊销，并入块生成）。`freshness(S) > T_seg=200ms` 或 INT8 校验失败 ⇒ 注入中立元 `u≡0, R_bnd≡0, c_sem←c_base`，`U_seg` 不参与门控 ⇒ 精确保退 v10（`β^⊙=β_STF`，`r_t` 不变）。

**新增定义 560（有效块长，v11；升级定义 539）**
```
K_eff(t) = 1   若 ¬U_t^sem ∨ ¬U_t^E ∨ Ĉ_t^⊙ 不可得
         = 2   若 NRB 失效（Π_r）
         = max(1, ⌊K_max·(1 − min(1, max(Δ_dom/τ_dom,
                                          sup_Φ T/τ_sem,
                                          U_seg/τ_U,
                                          ρ_E)))⌋)   否则
ρ_E = (E_mission + r_min)/E_budget
```
`r_min` 为「单步执行 + 最近中止 + 停驻」的最小安全能量。四门控取 max：域偏移、稀疏语义、稠密 unknown、能量预算任一越阈即收缩；能量越紧块越短，极端 K=1 退回逐步模式。

# IP-361 EnduranceReachabilityCertifier：续航可达证书器（语义无关的物理兜底）
class EnduranceReachabilityCertifier:
    def __init__(self, battery, reserve, eps_base, c_max, T_E=1.0, E_scale=1.0):
        self.batt, self.reserve = battery, reserve
        self.eps_base, self.c_max = eps_base, c_max
        self.T_E, self.E_scale = T_E, E_scale

    def state_ok(self):                                  # 定义 549
        return (self.batt.fresh(self.T_E) and self.batt.calib_version_ok())

    def usable(self):                                    # 定义 549
        if not self.state_ok():
            return None
        return (self.batt.eta() * self.batt.soc() * self.batt.E_nom
                - self.reserve)

    def r_t(self, chunk, pred, dscf):                    # 定义 550 / 553
        L = chunk.footprint.length()
        e_safe = (chunk.actuator_energy_upper(pred)
                  + self.c_max * L                        # 语义无关最坏单位能耗
                  + pred.compute_energy)
        e_reach = max(self.batt.energy_to_upper(p, self.c_max)
                      for p in chunk.abort_points)
        eps = (self.eps_base
               + dscf.lambda_u * dscf.sup_u(chunk.footprint)
               + dscf.lambda_b * dscf.boundary_risk(chunk.footprint))
        return e_safe + e_reach + self.batt.e_stop_upper() + eps

    def task_cost(self, chunk, pred, dscf):              # 定义 555：仅计费/选路
        return (chunk.actuator_energy(pred)
                + dscf.integrate(chunk.footprint, 'semantic'))

    def feasible(self, chunk, pred, dscf):               # 定义 550
        E = self.usable()
        if E is None:
            return False, float('inf')
        r = self.r_t(chunk, pred, dscf)
        ok = (r <= E and self.batt.mission_used + r <= self.batt.budget)
        return ok, r

    def ratio(self):                                     # 定义 560 的 rho_E
        E = self.usable()
        if E is None or E <= 0:
            return 1.0
        return min(1.0, (self.batt.mission_used + self.batt.r_min)
                   / max(1e-9, self.batt.budget))


# IP-362 DenseSemanticTraversabilityField：稠密语义—可通行成本场（第二路语义证据）
class DenseSemanticTraversabilityField:
    def __init__(self, seg_int8, tau_u=0.5, tau_b=0.3,
                 T_seg=0.2, lambda_u=0.05, lambda_b=0.05):
        self.seg = seg_int8
        self.tau_u, self.tau_b, self.T_seg = tau_u, tau_b, T_seg
        self.lambda_u, self.lambda_b = lambda_u, lambda_b
        self.field = None

    def update(self, rgbd, pose):                        # 定义 559：10–20Hz
        if not pose.tracked():
            return
        logits = self.seg.infer_int8(rgbd)               # 复用 v8 骨干
        p = softmax(logits)
        self.field = temporal_fuse(self.field, p, pose)

    def available(self):
        return (self.field is not None
                and self.field.age() <= self.T_seg)

    def u(self, x):                                      # 定义 552
        if not self.available():
            return 0.0                                   # 中立元（精确 v10 回退）
        p = self.field.at(x)
        h = -sum(pc * log(pc + 1e-9) for pc in p) / log(len(p))
        return clip(h + self.field.boundary(x) / self.tau_b
                    + float(self.field.is_unknown(x)), 0, 1)

    def c_sem(self, x):                                  # 定义 552：仅任务侧
        if not self.available():
            return self.field.c_base if self.field else 0.0
        return sum(pc * KAPPA[c] for c, pc in enumerate(self.field.at(x)))

    def sup_u(self, footprint):
        return max((self.u(x) for x in footprint.samples()), default=0.0)

    def boundary_risk(self, footprint):                  # 定义 553
        if not self.available():
            return 0.0
        return max((self.field.grad_norm(x) for x in footprint.samples()),
                   default=0.0)

    def unknown_ratio(self, footprint):                  # 定义 554 的 U_seg
        if not self.available():
            return 0.0
        xs = list(footprint.samples())
        return sum(self.u(x) > self.tau_u for x in xs) / max(1, len(xs))

    def integrate(self, footprint, mode):                # 任务侧能耗（不用于安全）
        if not self.available() or mode != 'semantic':
            return (self.field.c_base * footprint.length()
                    if self.field else 0.0)
        return sum(self.c_sem(x) * footprint.ds()
                   for x in footprint.samples())


# IP-364（升级）：联合证书分块执行器
class JointSemanticEnergyCertifier(StructuredChunkCertifier):
    def generate_chunk(self, state, ctx, stf, nrb, erc, dscf):
        K = self.effective_K(ctx.delta_dom, ctx.tau_dom,
                             trust_ok=stf.trust_ok(ctx),
                             energy_ok=erc.state_ok(),
                             energy_ratio=erc.ratio(),
                             unknown_ratio=dscf.unknown_ratio(ctx.footprint))
        if K == 1:
            return self._single_step_fallback(state)
        best = None
        for cand in self.policy.sample_sequences(state, K, n=64):
            pred = self.Fq.rollout(state, cand)               # v10 INT8 前向模型
            fp = pred.corridor
            beta = (self.beta_base
                    + self.lam * stf.field_on_footprint(fp)
                    + dscf.lambda_u * dscf.sup_u(fp)          # 定义 553
                    + dscf.lambda_b * dscf.boundary_risk(fp))
            g_min = pred.min_clearance - beta
            e_max = pred.max_effort + beta
            if g_min < self.d_safe or e_max > state.tau_eff:
                continue
            if dscf.unknown_ratio(fp) > dscf.tau_u:            # 定义 557：保守否决
                continue
            pts = self._abort_points(state, cand, pred)
            if not pts:
                continue
            chunk = Chunk(cand, CertStar(g_min, e_max, beta), pts)
            feas, r_t = erc.feasible(chunk, pred, dscf)       # 定义 550
            chunk.cert.r_t = r_t
            chunk.cert.U_seg = dscf.unknown_ratio(fp)
            if not feas:
                continue
            chunk, verdict = nrb.review_chunk(chunk, stf, ctx)  # v10
            if chunk is None:
                continue
            chunk.task_cost = erc.task_cost(chunk, pred, dscf)   # 定义 555：仅打分
            if best is None or self._better(chunk, best):
                best = chunk
        return best or self._single_step_fallback(state)

    def _better(self, a, b):                                  # 定义 555：安全优先
        if a.cert.margin != b.cert.margin:
            return a.cert.margin > b.cert.margin
        return a.task_cost < b.task_cost                      # 同安全层再省电

    def midchunk_guard(self, chunk, k_exec, live_obs, stf, nrb, erc, dscf):
        """50Hz 五检 ≤0.7ms；返回 ('continue', k+1) 或 ('abort', p*)"""
        if not chunk.cert_still_valid(live_obs):              # 检 1（v10 升级）
            return self._nearest_abort(chunk, k_exec)
        stop_inv = (live_obs.nearest_clearance
                    - self.d_brake(live_obs.speed) - self.d_safe)
        if stop_inv < chunk.remaining_len(k_exec):            # 检 2（v10）
            return self._nearest_abort(chunk, k_exec)
        sem = max(stf.surprise_near(live_obs.pose),            # 检 3：语义双源
                  dscf.sup_u(live_obs.local_footprint),
                  dscf.boundary_risk(live_obs.local_footprint))
        if sem > stf.tau_sem:
            return self._nearest_abort(chunk, k_exec)
        if nrb.fast_norms(live_obs).violated:                  # 检 4（v10）
            return self._nearest_abort(chunk, k_exec)
        pred = self.Fq.rollout_from_live(live_obs, chunk.remaining(k_exec))
        feas, _ = erc.feasible(chunk.remaining(k_exec), pred, dscf)
        if not feas:                                          # 检 5：能量可达
            return self._nearest_abort(chunk, k_exec)
        return ('continue', k_exec + 1)

## 4. 推导

**引理 92（能量可达的物理兜底性）** 设 `e_safe`、`e_reach⁺`、`e_stop⁺` 均为保守上界，`ε_E^⊙` 覆盖能量模型误差与语义不确定度，且电池不再充电。若 `E-feas(ζ)` 成立，则执行完 ζ 后至少存在 `p∈P*(ζ)`，使得到达 p 并停驻的能量足够。该结论只依赖能量守恒与上界性质，**不依赖** STF、DSCF、嵌入距离或 τ_sem。证明：能量单调递减；`r_t` 是「执行 + 最坏中止 + 停驻 + 误差」的上界；`E_usable` 已扣除不可动 `E_res`；`E_budget` 条件排除跨任务透支。∎

**引理 93（界源分离下 DSCF 任意错误不破坏能量兜底）** 因 `r_t` 不含 `c_sem`，且 `ε_E^⊙` 关于 `u, R_bnd` 单调不减，DSCF 对任意地形（同名/错名/透明）的误判只能通过 `u/R_bnd` **抬高** `r_t`（更保守）或完全不影响 `r_t`；不存在 DSCF 输出使 `r_t` 低于其语义无关基线
`r_t^base = e_safe(c_max) + e_reach⁺(c_max) + e_stop⁺ + ε_base`。
故引理 92 的保证在任意 DSCF 错误下保持。这是对「语义 + 能量联合证据相关失效」的结构性防守。∎

**引理 94（稠密语义余量的单调细化与精确保退）** `β^⊙ = β_STF + λ_u·sup u + λ_b·R_bnd`，两项非负 ⇒ `β^⊙ ≥ β_STF`；DSCF 失效时两项为 0 ⇒ `β^⊙ = β_STF`。稠密 unknown/glass 否决只删除候选，不新增动作。故 v11 在 DSCF 正常时只会更保守或删候选，失效时精确等价 v10。∎

**引理 95（DSCF 补足稀疏 STF 的盲区，但不消除语义风险）** 设 (A1) 分割对「足迹内可通行类变化」的召回 ≥1−ε_d（E596）；(A2) `u` 对高熵/边界/unknown 的校准误差 ≤ε_u（E597）。则对发生在足迹内、但远离任何地标的可通行性变化，检 3 经 DSCF 分支触发的概率 ≥1−ε_d−ε_u；这是 v10 STF 在无地标处无法覆盖的事件类。但 DSCF 仍是**语义**证据：对抗纹理/长尾透明物仍可以 ≤ε_d 概率穿透。故 DSCF 缩小而非消除 v10 最大风险；非语义兜底由 ERC 提供（引理 92–93）。∎

**引理 96（联合失效分解与残余事件）** 将 `Ĉ^⊙` 失效分为 E 类（沿真实路径 `E-feas` 失败）与 S 类（能量可行但语义/几何/规范条件被破坏）。E 类由检 5 在生成期或中块 1 帧内拦截（引理 92）；S 类由 v10 检 1/2/4 与检 3 双源拦截。残余需「S 漏检 ∧ E 漏检」。在界源分离（引理 93）下，E 类概率与 DSCF 语义内容无关；但两者共享位姿/电量计与同一前向模型，故非完全独立——独立性是「界源」层面而非「状态估计」层面。∎

**引理 97（联合退化等价/支配）** 按定义 549–560：DSCF 故障 ⇒ 中立元 `u=R_bnd=0, c_sem=c_base` ⇒ 精确保退 v10（引理 94）；ERC 故障 ⇒ `r_t^max` 或停驻返航（动作 ⊆ v10，引理 92 的保守版）；ESL 故障 ⇒ `Π_r`；STF/NRB/AC/ID/MW 沿 v10 链。逐项比较动作集与触发条件，故障路径不新增任何 v10 不可执行动作，故等价（仅审计/计费面）或支配（收缩）。∎

**引理 98（续航约束下的条件活性）** 若 `E_budget(0)` 覆盖「任务完成 + 从任意任务点返航到 B」的保守能量，则 ERC 不阻止任务完成；反之，ERC 在预算耗尽前触发返航/停驻，任务完成率下降但在 A4（能量上界成立）下安全停驻概率为 1。活性是条件保证而非无条件保证。∎

## 8. 本轮最大风险

**一句话**：`c_max`、`ε_base` 与分割标定都是离线常数——真正没见过的地形（沙/泥/冰/透明/镜面）可能同时让分割把它判成「良性且低耗」、让能量模型低估实际滚阻，而两者又共享同一套位姿/深度状态估计；一旦 `c_max` 本身被超出，所谓「物理兜底」与「语义证据」会以相关方式同时失效，v11 会比 v10 更难发现（v10 至少只欠一份语义证据，v11 却可能错误地相信自己有两份）。
