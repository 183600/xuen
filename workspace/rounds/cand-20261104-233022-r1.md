# 第 16 轮（研究线累计；本轮灵感循环第 1 轮）· HCR-VLA：分层规划 + 常识推理的分布外泛化门控

> 检索/复核日期：**2026-11-04（UTC）**。赛事身份不变：宇树 UniBot 世界挑战赛，G1 + Dex1，32 项桌面任务，通才单模型赛道。本轮灵感词：分布外泛化、分层规划、常识推理。**不推倒**第 10-15 轮成果；HCR-VLA 在 ZEST-VLA 胜任力层之上加 **分层规划层 L5** 与 **常识推理层 L6**，把 OOD-G 从不可检测边界转为可验证的常识冲突。

## 0. 直觉：ZEST 能发现「做错」，但发现不了「想错」

第 15 轮 ZEST-VLA 用动作-观测残差 + conformal/CUSUM 建立风险受控信任门，成功处理 OOD-E、部分 OOD-S，但明确承认 OOD-G 不可检测：VLA 与语义地图共享错误先验时，残差像 ID，系统会自信执行错误目标。

本轮直觉是：**分布外泛化需要独立于感知-控制闭环的锚点**。常识推理提供这样的锚点：物理可行性、因果顺序、 affordance。它不依赖视觉 grounding，且与 VLA 训练分布正交。分层规划把任务拆成高层语义子目标与低层几何原语，使得 OOD 可以在不同层被不同信号捕获：低层靠残差，高层靠常识一致性。

一句话押注：
> 用分层计划做「何时做」，用常识做「能不能做」，用残差做「做得对不对」。三层不确定性形成 OOD 漏斗，把不可检测的 OOD-G 转为可证明的常识冲突，系统级零样本泛化从「受控降级」升级为「主动规避」。

三个灵感词落地：

| 词 | 落地 | 不做什么 |
|---|---|---|
| 分布外泛化 | OOD 按 E/S/G 拆分；E 靠残差，S 靠进度，G 靠常识冲突 + 分层不一致 | 不把泛化等同于模型鲁棒性 |
| 分层规划 | 指令→语义子图→几何原语；逐层一致性检查 | 不引入学习式规划器 |
| 常识推理 | 手工符号 KB：affordance、支持、因果序、物理守恒；确定性规则评分 | 不训练常识模型 |

## 1. 研究日志

### 1.1 ZEST 留下的盲区
A1 执行者胜任：ZEST 已覆盖。
A2 目标分布正确：仍是风险，ZEST 只能部分检测。
A3 失败可见：对 OOD-G 不成立。

本轮付账 A2：引入常识层作为独立判别器，降低 VLA 与地图共构错误的概率。

### 1.2 新判断
1. **常识是分布外锚点**。常识规则在 ID/OOD 上稳定，因其来自物理常识而非数据分布。
2. **分层是 OOD 放大器**。高层语义错误在低层残差中被平滑，分层不一致会暴露。
3. **风险受控仍是目标**。常识冲突不直接触发 fallback，而是提高风险分数，仍由 conformal 控制假警报。

## 2. 机制草图

符号：指令 u，语义子目标序列 G = [g1..gk]，几何原语序列 P。常识 KB K = {affordance, support, precedence, conservation}。

常识一致性：
c_s(g, o, K) = 1 - max_{k∈K} violation(k, g, o)
分层不一致：
h_t = 1 - sim(plan_high(t), plan_low(t))
融合风险：
ρ_t = w_r s_t + w_c (1 - c_s) + w_h h_t
其中 s_t 为 ZEST 归一化分数。

门控：ρ_t > q_{α}^{ρ} 触发 OOD，高层计划重规划或降级。

## 3. 可证伪假设
H1 常识冲突能区分 OOD-G，AUROC ≥0.75
H2 HCR 在 OOD-G 任务上成功率提升 ≥8pp，ID 不回归 >2pp
H3 分层不一致信号对语义错误有增益
H4 常识 KB 覆盖率 >80% 时收益显著

## 4. 本轮最大风险
**常识 KB 不完整或过度保守导致在新奇但合理的任务上误报，引发过度保守的降级，抵消 OOD 收益。** 常识是手工规则，覆盖盲区会直接成为系统盲区。

# 第 16 轮产物 · HCR-VLA 技术报告

> 检索/复核日期：2026-11-04。对象：UniBot 世界挑战赛。本报告在 ZEST-VLA 之上增加分层规划与常识推理层，形成 L6 常识验证 / L5 分层规划 / L4 胜任力 / L3 VOI-MAP / L2 WAVE-SERVO / L1 VLA 的六层架构。

## 0. 结论
HCR-VLA 不训练新参数。分层计划提供语义-几何对齐检查，常识 KB 提供物理可行性锚点，与 ZEST 残差融合形成分布外风险分数 ρ_t。门控仍用 self-normalized conformal + CUSUM，保证 ID 假警报控制。零样本泛化从被动降级升级为主动规避。

## 1. 符号定义
指令 u。语义子图 G_u = (V,E)。每个 v∈V 有类型 τ(v) 与 affordance 需求 a(v)。几何原语 p∈P。常识 KB K 含规则 r_i。
观测 o_t，地图 M_t，VLA 计划 A_t。ZEST 分数 s_t。
常识一致性 c_s ∈ [0,1]，分层不一致 h_t ∈ [0,1]。
融合风险 ρ_t = σ(w_r s_t + w_c (1-c_s) + w_h h_t)。

## 2. 算法步骤
1. 解析：u → 语义子图 G_u， via 规则语法。
2. 常识过滤：对每个 g∈G_u 计算 c_s(g,o,K)，若 c_s < θ_c 则标记不可行。
3. 分层规划：为可行子目标生成几何原语序列 P。
4. 执行：每 5 步块执行当前动作 a∈{SERVO, LOOK, VLA, FALLBACK}。
5. 残差：计算 ZEST 三残差，得到 s_t。
6. 分层一致：比较高层子目标进度与低层几何进度，得到 h_t。
7. 融合：ρ_t 计算，e_t = 1[ρ_t > q_α]，CUSUM 更新。
8. 门控：若触发，禁用 SERVO，尝试重规划或 fallback。
9. 复检：每 r 块探针，允许恢复。

## 3. 复杂度
常识检查 O(|G_u|·|K|)，分层一致 O(|G_u|)。整体每块 <1 ms，内存 <15 MB。

## 4. 正确性论证
命题1：常识规则独立于感知，因此在 OOD-G 下仍保持区分力。
命题2：融合风险在 ID 下仍满足 conformal 边际保证，因 ρ_t 是确定性函数。
命题3：分层不一致单调不减于语义错误。

## 5. 已知风险
常识 KB 覆盖不足导致误报；分层语法对新奇任务不匹配；常识冲突与残差冲突时权重选择敏感。

## 6. 实验设计
G13' 常识 AUROC ≥0.75
G14' HCR vs ZEST 在 OOD-G 任务上 +8pp
预注册假设 H1-H4 如上。

本轮最大风险：常识 KB 不完整导致在合理新奇任务上过度保守降级，收益被抵消。
