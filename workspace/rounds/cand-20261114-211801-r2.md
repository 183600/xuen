# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；本轮灵感：「传感器融合」×「抓取位姿估计」）

> R69 让闭环学会了「问」：把不确定性拆成 aleatoric 与 epistemic，用流匹配多模态策略呈现歧义，用主动多模态交互（看/问/触）消解歧义，并用动作似然做标定不可吸收的第二意见。但 R69 的三个隐含假设在**传感器融合 × 抓取位姿估计**面前同时失效：
> 1. 它假设「多个证据源一致」就等于「独立验证」——可传感器融合里视觉、深度、语言先验常常共享同一个物体位姿主干，**一致性可能只是共模误差在自我复读**；
> 2. 它假设「多峰 = 真歧义」——可抓取的位姿分布天然多峰，其中大量峰来自物体的**对称性**（把圆柱转 90° 不是另一个抓取，是同一个抓取的规范等价类），R69 会为这种「规范冗余」去问一个物理上无意义的问题；
> 3. 它假设信息动作是安全、近乎可逆的——可**抓取是一句不能撤回的问句**：夹爪一合、接触一发生，世界就被改变了；而唯一非学习的物理证人（触觉/力）偏偏只在承诺之后才到场。
>
> 核心命题：**在 FLUID-RAS 之下再嵌一层「位姿级融合层」，把不确定性细化为 aleatoric / epistemic / gauge 三分；用对称群商掉规范冗余，用有效证据秩审计「共识」的真实独立性，用不可逆承诺感知的 VoI 决定何时从「问」切换到「抓」，并把接触残差作为不可被共享学习主干吸收的物理锚点。** 命名 **GRIP-RAS**（Gauge-quotiented, Reliability-audited, Irreversibility-aware, Physical-anchored Pose-fusion RAS）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我听到的一致是真的独立吗，我这一问还收得回来吗**」——在抓取里，最贵的问题不是「问谁」，而是「问了之后还能不能不抓」。

## 0. 直觉与动机

**灵感 1（传感器融合 → 一致不等于独立）**
直觉：把 N 个传感器取平均，误差看起来会以 1/√N 缩小；但如果所有传感器共享一个标定误差、一个外参、一个物体位姿先验，那么它们的共识只是在重复同一个错误。此时「N 源一致」并不意味着 N 份证据，系统会**越融合越自信，越自信越错**。这正是 R69「k 个正交证据源一致」纪律的盲区：纪律只管数量，不管**证据的有效秩**。传感器融合的正确直觉是：先把共同模态（common mode）从独立噪声里分出来，再谈收益；否则融合只是把偏差洗白成方差。

**灵感 2（抓取位姿估计 → 多峰里有真歧义，也有规范冗余）**
直觉：一个杯子的可行抓取从来不是单峰的：从上面抓、从侧面抓、换一个手指朝向抓，都成立。但其中有一类「多峰」是**物体的对称性**造成的——旋转对称的杯子，绕其轴转任意角度其实是同一个物理抓取；平行夹爪本身还有绕接近轴 180° 的手指交换对称。R69 的轨迹聚类会把这些等价代表数成不同模态，算出很高的 U_epi，然后主动交互去「消解」一个**根本不需要也根本无法被消解**的区分。真正该做的是在商空间 SE(3)/G 上做判断：**先除对称，再谈歧义**。反过来，如果把近似对称当成精确对称，就会把两个真实不同的抓取悄悄合并——商掉得太多，比不商更危险。

**灵感 3（抓取的不可逆性 → 信息动作也有承诺成本）**
直觉：看、问、轻触是近乎可逆的；抓取不是。夹爪闭合、接触建立、物体被抬起之后，你无法「取消这一次接触」。R69 的 VoI 只看信息增益减成本，隐含假设动作可逆；但在抓取里，**信息本身是通过承诺换来的**：只有真正接触，才能知道位姿对不对。于是决策变成一个最优停止问题——在若干次可逆探询之后，什么时候值得把剩余的不确定性押在一次不可逆的抓取上？直觉是：物体越脆、抓错代价越高，就越应该在接触前多问；探询越有效，阈值越低。

**灵感 4（接触是唯一非学习的物理锚点 → 正面对付 R69 的最大风险）**
直觉：R69 的最大风险是「流模型幻觉出模态、或把人类误导答案盖章为已验证」——因为它的两条通道（传感器残差、动作似然）最终都经过同一个学习主干。接触不一样：力/触觉残差是**物理定律**给出的，不经过视觉主干。若视觉融合很自信、但接触残差很大，就说明视觉的自信是共模幻觉。接触锚点因此是 R69 缺失的「第三方证人」。但它有两个残酷限制：(a) 它只在承诺之后出现，救不了这一次，只能救下一次；(b) 如果读它的力学模型与相机外参共享同一个标定误差，它就不再独立。**触觉是证人，前提是读它的尺子不是被审计的那把。**

**灵感 5（三分法 → R69 是「对称群平凡」的退化）**
直觉：R69 的二分在 G 平凡（无对称）、源独立（无共模）、动作可逆时完全正确。GRIP 不推翻它，而是把这三个前提显式化：G 平凡 ⇒ U_gauge=0，退化为 R69 的 (U_ale,U_epi)；无共模 ⇒ N_eff=N，k 纪律有效；无可逆动作可用 ⇒ 自动进入承诺最优停止，风险门控回 R69 保守。这是本轮的理论姿态：**新层必须能在旧层前提成立时逐指令退化，且安全侧永不更弱**。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（GRIP-RAS 总览）** GRIP-RAS = (GPF, SFQ, ECR, ADX, CCV, CPA, OSP, RAS-WM†)，嵌在 FLUID-RAS 的位姿层。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **规范不变性**：所有抓取决策必须是轨道不变的（orbit-invariant），策略输出在 G 作用下等变；
(iii) **证据充分性**：以有效证据秩 N_eff ≥ k_req 取代「原始源数 ≥ k」，并报告共模占比 β；
(iv) **承诺纪律**：不可逆信息动作必须满足 C-VoI > 0、承诺风险 ≤ ε_commit，且接触残差入证；不可逆动作不得单独定案（继承 R69 定义 293-iii 的精神）。

**定义 311（多传感器位姿后验 GPF）** 传感器 i∈{RGB-D, 触觉阵列, 力/力矩, 本体} 给出位姿估计 (T_i, Σ_i) 与抓取构型（夹爪宽度、预成形）。误差模型显式分离共模与独立项：e_i = b + η_i，b ~ 𝒩(0,Σ_b) 为共享标定/系统性偏差，η_i ~ 𝒩(0,Σ_i) 为独立噪声。融合 posterior p(T|{T_i}) = Σ_k w_k 𝒩_{SE(3)}(T; μ_k, Σ_k)，并在李代数上做局部高斯化。naive 逆方差融合在 Σ_b≠0 时系统性低估后验方差。

**定义 312（抓取轨道与对称群）** 抓取位姿 T ∈ SE(3)（含接近方向、夹爪朝向、预抓取深度）。物理对称群 G = G_obj × G_grip：G_obj 为物体对称（连续如圆柱 S¹、离散如立方体 24 阶、或平凡），G_grip 为夹爪对称（平行夹爪绕接近轴 180° 手指交换）。物理抓取是轨道 [T] = {gT : g∈G}，决策空间为分层商流形 ℳ_G = SE(3)/G。近似对称以容差 ε_sym 与置信 s_sym 表示。

**定义 313（不确定性三分：ale / epi / gauge）** 把 R69 定义 297 的二分细化为：
- U_ale = 轨道内、模态内的接触/摩擦/控制噪声（不可约）；
- U_epi = **轨道之间**的歧义（可约，交给 R69 的交互消解）；
- U_gauge = 轨道内因对称等价产生的散布（决策无关、交互 VoI=0）。
三者不做简单加和，分通道处置。边界情形：若对称破缺证据 e_sym 在容差外把轨道内位姿分开，则相应分量从 U_gauge **提升**为 U_epi（近似对称的「显式破缺」）。

**定义 314（有效证据秩 ECR）** 由缓存残差估计源误差相关阵 R；有效源数 N_eff = (Σ_i λ_i)² / Σ_i λ_i²（参与率），等相ρ情形 N_eff = N/(1+(N−1)ρ)；共模占比 β = trΣ_b / trΣ_total。证据充分 ⇔ N_eff ≥ k_req 且 β ≤ β_max。**「N 个高度相关的源一致」在证据上等价于一个源**——这是对 R69 定义 293-iii 的严格收紧。

**定义 315（协同一致性证书 CI-slack）** 同时计算 naive 融合 Σ_naive 与协方差交叉 Σ_CI（未知相关下仍一致）。定义 slack s_CI = log det Σ_naive − log det Σ_CI。s_CI 大 ⇒ 隐藏共模/相关被 naive 融合吞掉；s_CI 作为证书字段，超过 τ_CI 即禁止把融合置信当作独立证据。

**定义 316（主动去相关探针 ADX）** 选择信息动作 g_dx 改变** nuisance 条件**（视点基线、光照、接触位置、预载、抓取前轻微移动）以打破共模：g_dx* = argmax_g [ Δrank(R|g) + ΔI(calib; y|g) − c(g) ]，s.t. 过 C-RAS-WM 认证与交互预算。ADX 的收益是降低 β、提高 N_eff，而不仅是降低模态熵。

**定义 317（承诺感知 VoI，C-VoI）** 对信息动作 g，设不可逆概率 p_irr(g)、回退成本 c_rev、接触风险 L_c，则
C-VoI(g) = VoI(g) + VoI_contact(g) − c(g) − p_irr(g)·(c_rev + L_c) − κ·E[U_epi^{res} after commit]。
只有 C-VoI>0 且 risk(g)≤ε_commit 才允许不可逆动作；否则只能走可逆探询或 R69 保守兜底。

**定义 318（信息-承诺前沿与最优停止）** 可逆探询序列 g_1,…,g_n 使残余 epistemic 尺度按 σ←ρσ 收缩（ρ<1），单次探询成本 c_p；承诺的期望损失 L(σ)=L_0+L_1σ²。值函数 V(σ)=min{L(σ), c_p+V(ρσ)}。**承诺阈值** σ* = √( c_p / (L_1(1−ρ²)) )：当 σ>σ* 继续探询，当 σ≤σ* 且 C-VoI>0 则承诺。抓取前的「接近—预成形—轻触」被视为软探询，避免把接近动作当成纯任务动作白白浪费信息。

**定义 319（接触位姿锚 CPA）** 接触后测得力/触觉 w_m 与接触点，几何-力学模型预测 w_p(T̂; φ)（φ 为手指运动学/摩擦锥参数，**非**视觉学习参数 θ）。接触残差 r_ct = ‖w_m − w_p(T̂;φ)‖_{Σ_w}。若 r_ct 大而视觉融合置信高 ⇒ 疑似共模幻觉（视觉自洽但物理不自洽）。r_ct 是 R69 定义 301 流似然的**物理对偶**：似然测行为自洽，接触测物理自洽。

**定义 320（接触约束位姿更新与可观测性）** 接触把位姿估计从「自由 6-DoF」约束到接触流形：部分自由度（沿法向、绕接触边）只在接触后可观测。定义可观测矩阵 O(T̂, contact)；提升（lift）前若存在高风险不可观测自由度，则禁止抬升，只允许滑动/再接触等低风险动作。

**定义 321（轨道级选择 OSP）** 选择轨道 [T]* 而非单个模态代表：min_{[T]} E_{T~p(·|[T])}[risk(T)] + λ_rob·Robustness([T])；轨道内代表 T_c = argmin_{g∈G} risk(gT)（最坏情况最小或稳健裕度最大）。避免 R69 「随机挑一个模态原型」在对称流形上选到脆弱代表。

**定义 322（对称与共模威胁模型 AIC-GRIP）** ℰ_GRIP = ℰ_FLUID × ℰ_sym × ℰ_common × ℰ_contact：对称性欺骗（物体伪装成对称/非对称，诱导错误商）、共模标定投毒（污染共享标定检查使 N_eff 虚高）、接触煤气灯（篡改触觉使 r_ct 看起来正常）、幻影轨道注入（伪造一个不存在的对称等价类）。威胁模型并入证书与审计。

**定义 323（融合证书 J_GRIP）** J_GRIP = (J_FLUID, N_eff, β_common, s_CI, s_sym, U_gauge, U_epi_orbit, commit_risk, r_ct, grip_ver)。Valid ⇔ Valid(J_FLUID) ∧ N_eff≥k_req ∧ β≤β_max ∧ s_CI≤τ_CI ∧ s_sym≥τ_sym ∧（接触后）r_ct≤τ_ct ∧ 承诺纪律满足。

**定义 324（对称置信门 SCG）** 物体对称分类置信 s_sym；若 s_sym<τ_sym，**禁止商**，把 U_gauge 视同 U_epi（保守，退化为「潜在都不同」）。只商「可证明的对称」——商掉不确信的对称等价于在无证据时删除真实区分，是本轮最危险的错误方向。

**定义 325（接触触发重标定）** 若 r_ct 越界或 s_CI 激增，冻结商、更新 Σ_b、将 U_gauge 临时还原为 U_epi，回退到 R69 纯保守；直到 ECR 恢复（N_eff≥k_req）才解冻。回退过程 λ 单调不降，保证无突变。

**定义 326（双阶段估计语义）** 阶段 A（接触前）：GPF→SFQ→ECR/ADX→CCV，输出轨道级计划与承诺阈值；阶段 B（接触后）：CPA→接触约束更新→（若抬升）保持证书。明确「抓取位姿估计在接触前只是部分可观测」——没摸到之前，你并不知道这次抓取。

# IP-270 GPF：SE(3) 融合 + 共模/相关审计（复用 R69 的 z_t 与传感器标定 c）
def fuse_grasp_poses(estimates, calib):
    Sigma_naive = inv(sum(inv(Si) for _, Si in estimates))
    Sigma_CI    = covariance_intersection(estimates)          # 未知相关下一致
    R           = residual_corr(calib.recent_residuals)       # 源误差相关阵
    N_eff       = participation_ratio(R)                      # (sum li)^2 / sum li^2
    beta        = common_mode_fraction(calib.Sigma_b, estimates)
    slack       = logdet(Sigma_naive) - logdet(Sigma_CI)      # CI-slack
    post        = mixture_on_SE3(estimates)                   # 多峰位姿后验
    return post, N_eff, beta, slack

# IP-264 SFQ：对称商（不确信就不商）
def quotient_grasp_modes(post, sym):
    if sym.confidence < TAU_SYM:
        return post.modes, 0.0, post.entropy          # 禁止商：gauge 视同 epi
    orbits = group_by_orbit(post.modes, sym.G, eps=sym.eps)
    U_gauge = within_orbit_spread(orbits) / sym.scale
    U_epi   = between_orbit_entropy(orbits)
    return orbits, U_gauge, U_epi

# IP-265/266 ECR + ADX：先证明独立，再谈一致
def evidence_ok(N_eff, beta, slack):
    return (N_eff >= K_REQ) and (beta <= BETA_MAX) and (slack <= TAU_CI)

def choose_decorrelation(candidates, calib, budget):
    best = None
    for g in candidates:                                  # 换视点/接触点/预载/光照
        if not budget.allow(g) or not c_ras_wm.certify_info(g): continue
        score = (expected_rank_gain(calib.R, g)
                 + expected_epi_gain(g, calib) - cost(g))
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None

# IP-267 CCV：承诺阈值（最优停止的闭式解）
def commit_threshold(c_p, L1, rho):
    return sqrt(c_p / (L1 * (1.0 - rho * rho)))

def decide_probe_or_commit(sigma, c_p, L1, rho, C_VoI, risk):
    if sigma > commit_threshold(c_p, L1, rho):
        return "probe"
    return "commit" if (C_VoI > 0 and risk <= EPS_COMMIT) else "fallback_R69"

# IP-268 CPA：接触锚点（唯一非学习证人）
def contact_anchor(w_meas, T_hat, contact_model, visual_conf):
    r_ct   = mahalanobis(w_meas, contact_model.predict(T_hat))
    flag   = (r_ct > TAU_CT) and (visual_conf > TAU_VIS)   # 视觉自信但物理不认
    return r_ct, flag

# IP-275 GRIP-RAS 主闭环（嵌在 R69 FLUID_RAS_round 的位姿层）
def GRIP_RAS_round(M, obs):
    # 0) R69 一次前向 + R68 标定
    z, o = M.mtm.forward(...); c, U_cal, _ = M.cof.step(...)
    # 1) 位姿级融合 + 证据审计
    post, N_eff, beta, slack = M.gpf.fuse_grasp_poses(M.sensors(obs), M.calib)
    adequate = M.ecr.evidence_ok(N_eff, beta, slack)
    orbits, U_gauge, U_epi = M.sfq.quotient_grasp_modes(post, M.sym(obs))
    # 2) 证据不足：先去相关；仍不足则回到 R69 保守
    if not adequate:
        g_dx = M.adx.choose_decorrelation(M.info_candidates(), M.calib, M.budget)
        if g_dx is not None: M.execute_info(g_dx, certified=True)
        else: U_epi = U_epi + U_gauge; adequate = False
    # 3) 承诺决策：可逆探询 vs 不可逆抓取
    sigma = residual_scale(U_epi)
    action = M.ccv.decide_probe_or_commit(sigma, M.c_p, M.L1, M.rho,
                                          M.ccv.C_VoI(...), M.commit_risk)
    if action == "probe":
        g = M.mint.choose_interaction(orbits, o, M.budget)   # 复用 R69 MINT
        if g is not None: U_epi = M.cia.update_belief(orbits, M.cia.execute(g))
    elif action == "fallback_R69":
        U_epi = U_epi + U_gauge                                # 未商、未解 = 保守
    # 4) 轨道级选择 + R69 风险缩放
    orbit  = M.osp.select_orbit(orbits, U_epi, M.risk)
    T_c    = M.osp.canonical_rep(orbit)                       # 轨道内最稳健代表
    lam    = max(M.efs.risk_scale(...), lam_floor(U_gauge if action != "probe" else 0.0
                                                  + U_epi))
    k      = M.c_ras_wm.certified_prefix(M.ach.propose(T_c, M.vista.H), ..., wm_preds)
    # 5) 接触后：物理锚点 + 接触约束更新
    w_meas = M.sensors.contact_wrench()
    r_ct, suspect = M.cpa.contact_anchor(w_meas, T_c, M.contact_model, M.vis_conf)
    if suspect:
        M.cof.freeze_and_recalibrate(); orbit = M.r69_conservative(orbits)
    # 6) 证书 + 参与式审计（审计「证据来源」而非只审结论）
    M.vqa_g.submit_async(post, orbits, N_eff, beta, slack, r_ct, action)
    return J_GRIP(M.j_fluid, N_eff, beta, slack, M.sym.conf, U_gauge, U_epi,
                  M.commit_risk, r_ct)
```

## 3. 推导

**引理 19（规范冗余不携带信息）** 设 G 紧致、后验 p 在 G 下不变，决策 d 轨道不变。则轨道内坐标与轨道变量在不变测度下独立，故 I(轨道内坐标; d)=0：为消解 U_gauge 而交互的 VoI 恒为 0。若对称只是近似（不变性缺陷/破缺裕度 δ_sym），则 0 < VoI ≤ O(δ_sym log(1/δ_sym))，且错误商的代价 ≤ P(sym 误判)·L_grasp。**系**：对称置信门 SCG 把「商错」的代价显式化——不确信时不商，宁可浪费一次探询，也不删掉一个真实区分。

**引理 20（有效秩与共识幻觉）** 设 e_i=b+η_i，b~𝒩(0,σ_b²)、η_i~𝒩(0,σ_η²)，相关系数 ρ=σ_b²/(σ_b²+σ_η²)。naive 融合均值的方差为 σ_b²+σ_η²/N → σ_b² (N→∞)，即存在**不随 N 收缩的方差地板**；且 R 的参与率 N_eff=N/(1+(N−1)ρ)→1/ρ。因此：任意多个共模源都能满足「N≥k」，但真实证据至多 1/ρ 份，而报告置信会低估真实误差达 N 倍量级。**系**：R69 的 k-正交纪律必须升级为 N_eff≥k_req；不先估计 ρ，任何「多源一致」都可能只是一个源在复读。

**引理 21（承诺阈值）** 令 L(σ)=L_0+L_1σ² 且一次可逆探询成本 c_p、收缩因子 ρ<1。值函数 V=min{L(σ), c_p+V(ρσ)}；因 L 单调增且凸、c_p>0，探询区是上集 σ>σ*，且 σ* 由 L(σ*)=c_p+L(ρσ*) 解出：
σ* = √( c_p / (L_1(1−ρ²)) )。
**系**：物体越脆（L_1 大）→ σ* 越小 → 接触前探询越多；探询越有效（ρ 小）或越便宜（c_p 小）→ 阈值越低。这给了「接近—轻触—再抓」一个可证明的最优停止依据，而不是启发式。

**引理 22（接触锚点的独立性与其边界）** r_ct 只依赖测得的 w_m 与几何/力学模型 φ，不依赖视觉主干参数 θ；故沿接触可观测方向，共模视觉偏差 b 使 E[r_ct] 至少增加 c‖b‖，而视觉残差可被标定吸收。这是 R69 引理 17 的物理镜像：**（视觉自信↑, r_ct↑）是共模幻觉的判别模式**。但若 φ 与相机外参共享标定误差，或触觉被篡改，则独立性失效——该边界必须写进证书假设，不能默认。

**定理 18（GRIP 严格包含 FLUID）** 在 A99–A103 下：(i) 当 G 平凡、β=0、无可逆探询可用时，GRIP 逐指令退化为 FLUID；(ii) 对称可信时，轨道级风险 ≤ FLUID（商掉规范冗余获得 resolution bonus，而轨道内差异物理等价，故不降安全）；(iii) 共模使 N_eff<k_req 时，GRIP 升级为保守/去相关，而 FLUID 会误信一致——故 GRIP 风险 ≤ FLUID。**GRIP 是 FLUID 在「对称平凡、源独立、动作可逆」边界上的严格退化，安全侧不让步。**

**定理 19（承诺安全与无突变）** 在 C-VoI 门 + 承诺风险门 + 接触可观测性约束下，执行越出安全位姿包络的抓取概率 ≤ ε_commit；最优停止策略在期望成本上不劣于任意固定探询次数基线；接触触发重标定使 λ 单调不降，且继承 R69 定理 15–17 的换装/提交不变式 ⇒ 控制连续、无突变。

**定理 20（证书可靠性）** 若 J_GRIP 有效，则决策要么是「商已认证 + N_eff≥k_req + 承诺安全」的轨道不变决策，要么处于 R69 保守回退；两种情况下所报不确定性的低估量不超过共模上界 β（由 CI-slack 约束）。**系**：在威胁模型内不存在「自信且错误」的有效证书——要么证据够独立，要么系统承认自己不够独立并退回保守。

**A99–A103（假设）** A99 对称群及置信可估；A100 共模可由独立残差/去相关探针估计；A101 接触模型 φ 与视觉标定可分离（否则降级）；A102 可逆探询在承诺前可用；A103 位姿后验局部高斯化误差有界。

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** GRIP-RAS 嵌于 FLUID 位姿层；零学习写操作继承；规范不变性（决策轨道不变、策略 G-等变）；证据充分性（N_eff≥k_req 且 β≤β_max，取代源数≥k）；承诺纪律（不可逆动作须 C-VoI>0、risk≤ε_commit，接触残差入证）。

**定义 311–312（GPF 与轨道）** 误差 `e_i=b+η_i`；SE(3) 混合后验。对称群 `G=G_obj×G_grip`，物理抓取为轨道 `[T]`，决策在 `SE(3)/G` 上；近似对称以容差 `ε_sym` 与置信 `s_sym` 表示。

**定义 313（三分）** `U_ale` 轨道内/模态内噪声（不可约）；`U_epi` 轨道间歧义（可交互消解）；`U_gauge` 轨道内对称等价散布（决策无关、VoI=0）。对称破缺证据可把相应 gauge 分量提升为 epi。

**定义 314–315（ECR 与 CI-slack）** `N_eff=(Σλ)²/Σλ²`；等相 ρ 时 `N_eff=N/(1+(N−1)ρ)→1/ρ`；`β=trΣ_b/trΣ_total`。证据充分 ⇔ `N_eff≥k_req ∧ β≤β_max ∧ s_CI≤τ_CI`。「N 源一致」在证据上可能只是一个源。

**定义 316（ADX）** `g_dx*=argmax[Δrank(R|g)+ΔI(calib;y|g)−c(g)]`，过 C-RAS-WM 与预算；目标是降 β、升 N_eff。

**定义 317–318（CCV 与最优停止）** `C-VoI=VoI+VoI_contact−c−p_irr(c_rev+L_c)−κE[U_epi^res]`。可逆探询使 `σ←ρσ`，承诺损失 `L(σ)=L_0+L_1σ²`；`σ*=√(c_p/(L_1(1−ρ²)))`：σ>σ* 继续探询，σ≤σ* 且 C-VoI>0 才承诺。

**定义 319–320（CPA 与接触可观测性）** `r_ct=‖w_m−w_p(T̂;φ)‖`，φ 为力学/运动学模型而非视觉 θ；`r_ct↑ ∧ visual_conf↑ ⇒ 共模幻觉疑`。接触后才可观测的自由度用可观测矩阵 `O(T̂)` 判定，抬升前高风险不可观测自由度禁止抬升。

**定义 321（OSP）** 选轨道 `[T]*` 最小化 `E[risk]+λ_rob·Robustness`，轨道内取 `argmin_{g∈G} risk(gT)` 的稳健代表。

**定义 322–323（威胁与证书）** `ℰ_GRIP=ℰ_FLUID×ℰ_sym×ℰ_common×ℰ_contact`（对称欺骗/共模投毒/接触煤气灯/幻影轨道）。`J_GRIP` 有效 ⇔ `J_FLUID` 有效 ∧ N_eff≥k ∧ β≤β_max ∧ s_CI≤τ_CI ∧ s_sym≥τ_sym ∧（接触后）r_ct≤τ_ct ∧ 承诺纪律满足。

# IP-270 GPF：SE(3) 融合 + 共模/相关审计
def fuse_grasp_poses(estimates, calib):
    Sigma_naive = inv(sum(inv(Si) for _, Si in estimates))
    Sigma_CI    = covariance_intersection(estimates)          # 未知相关下一致
    R           = residual_corr(calib.recent_residuals)
    N_eff       = participation_ratio(R)                      # (sum li)^2 / sum li^2
    beta        = common_mode_fraction(calib.Sigma_b, estimates)
    slack       = logdet(Sigma_naive) - logdet(Sigma_CI)
    return mixture_on_SE3(estimates), N_eff, beta, slack

def quotient_grasp_modes(post, sym):

    U_epi   = between_orbit_entropy(orbits)

    if sigma > commit_threshold(c_p, L1, rho): return "probe"
    return "commit" if (C_VoI > 0 and risk <= EPS_COMMIT) else "fallback_R69"

# IP-268 CPA：接触锚点（唯一非学习证人）
def contact_anchor(w_meas, T_hat, contact_model, visual_conf):
    r_ct = mahalanobis(w_meas, contact_model.predict(T_hat))
    flag = (r_ct > TAU_CT) and (visual_conf > TAU_VIS)   # 视觉自信但物理不认
    return r_ct, flag

# IP-275 主闭环（嵌在 R69 FLUID_RAS_round 的位姿层）
def GRIP_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, _ = M.cof.step(...)       # R69/R68
    post, N_eff, beta, slack = M.gpf.fuse_grasp_poses(M.sensors(obs), M.calib)
    adequate = M.ecr.evidence_ok(N_eff, beta, slack)
    orbits, U_gauge, U_epi = M.sfq.quotient_grasp_modes(post, M.sym(obs))
    if not adequate:                                               # 先证明独立
        g_dx = M.adx.choose_decorrelation(M.info_candidates(), M.calib, M.budget)
        if g_dx is not None: M.execute_info(g_dx, certified=True)
        else: U_epi, adequate = U_epi + U_gauge, False
    action = M.ccv.decide_probe_or_commit(residual_scale(U_epi), M.c_p, M.L1,
                                          M.rho, M.ccv.C_VoI(...), M.commit_risk)
    if action == "probe":
        g = M.mint.choose_interaction(orbits, o, M.budget)         # 复用 R69 MINT
        if g is not None: U_epi = M.cia.update_belief(orbits, M.cia.execute(g))
    elif action == "fallback_R69":
        U_epi += U_gauge
    orbit = M.osp.select_orbit(orbits, U_epi, M.risk)
    T_c   = M.osp.canonical_rep(orbit)
    lam   = max(M.efs.risk_scale(...), lam_floor((0.0 if action=="probe" else U_gauge)+U_epi))
    k     = M.c_ras_wm.certified_prefix(M.ach.propose(T_c, M.vista.H), ..., wm_preds)
    r_ct, suspect = M.cpa.contact_anchor(M.sensors.contact_wrench(), T_c,
                                         M.contact_model, M.vis_conf)
    if suspect: M.cof.freeze_and_recalibrate(); orbit = M.r69_conservative(orbits)
    M.vqa_g.submit_async(post, orbits, N_eff, beta, slack, r_ct, action)
    return J_GRIP(M.j_fluid, N_eff, beta, slack, M.sym.conf, U_gauge, U_epi,
                  M.commit_risk, r_ct)
```

## 4. 推导

**引理 19（规范冗余不携带信息）** G 紧致、p 在 G 下不变、决策 d 轨道不变 ⇒ 轨道内坐标与轨道变量独立，I(轨道内; d)=0，为消解 U_gauge 交互的 VoI=0；近似对称缺陷 δ_sym 下 0<VoI≤O(δ_sym log(1/δ_sym))，错误商代价 ≤ P(sym 误判)·L_grasp。系：SCG 把「商错」代价显式化，不确信不商。

**引理 20（有效秩与共识幻觉）** `e_i=b+η_i`，`ρ=σ_b²/(σ_b²+σ_η²)`；naive 融合方差 `σ_b²+σ_η²/N→σ_b²`，存在不随 N 收缩的方差地板；等相时 `N_eff=N/(1+(N−1)ρ)→1/ρ`。故任意多共模源都能满足「N≥k」，真实证据至多 1/ρ 份，报告置信低估真实误差达 N 倍量级。系：k-正交纪律必须升级为 N_eff≥k_req。

**引理 21（承诺阈值）** `L(σ)=L_0+L_1σ²`，探询成本 `c_p`、收缩 `ρ`；值函数 `V=min{L(σ), c_p+V(ρσ)}`，探询区为上集 `σ>σ*`，`σ*=√(c_p/(L_1(1−ρ²)))`。系：越脆（L_1 大）、探询越有效（ρ 小）/越便宜（c_p 小），σ* 越小、越应多探后抓。

**引理 22（接触锚点独立性与边界）** `r_ct` 只依赖 `w_m` 与力学模型 φ，不依赖视觉 θ；沿接触可观测方向，共模视觉偏差使 `E[r_ct]` 至少增加 `c‖b‖`，而视觉残差可被标定吸收。故 `(visual_conf↑, r_ct↑)` 是共模幻觉判别模式，为 R69 引理 17 的物理镜像。边界：φ 与相机外参共享标定或触觉被篡改时独立性失效，须写入证书假设。

**定理 18（GRIP 严格包含 FLUID）** A99–A103 下：(i) G 平凡、β=0、无可逆探询可用时逐指令退化为 FLUID；(ii) 对称可信时轨道级风险 ≤ FLUID（商掉规范冗余得 resolution bonus，轨道内物理等价故不降安全）；(iii) N_eff<k_req 时 GRIP 升级为保守/去相关，而 FLUID 会误信一致 ⇒ GRIP 风险 ≤ FLUID。安全侧不让步。

**定理 19（承诺安全与无突变）** C-VoI 门 + 承诺风险门 + 接触可观测性约束 ⇒ 越出安全位姿包络的抓取概率 ≤ ε_commit；最优停止在期望成本上不劣于任意固定探询次数基线；接触触发重标定使 λ 单调不降，继承 R69 定理 15–17 的换装/提交不变式 ⇒ 控制连续、无突变。

**定理 20（证书可靠性）** 若 J_GRIP 有效，则决策要么是「商已认证 + N_eff≥k_req + 承诺安全」的轨道不变决策，要么处于 R69 保守回退；两种情况下不确定性的低估量不超过共模上界 β（由 CI-slack 约束）。系：威胁模型内不存在「自信且错误」的有效证书。

**A99–A103** 对称群及置信可估；共模可由独立残差/去相关探针估计；接触模型 φ 与视觉标定可分离（否则降级）；可逆探询在承诺前可用；位姿局部高斯化误差有界。

## 7. 本轮最大风险

**一句话**：GRIP-RAS 的对称商与接触锚点共用同一个「物理/几何模型可信」前提，而接触证据只在不可逆承诺**之后**才出现——**若对称被误判（把真实差异当成等价）或接触力学模型与相机外参共享标定误差，系统会先自信地删掉一个真实区分，再亲手用同一把被审计的尺子把它「证实」；触觉是证人，但只有当读它的尺子不是被审计的那把时才算独立**。

**次级风险与缓解**：近似对称边界误商（定义 324 SCG + 引理 19 代价界 + E301/E302）；共模标定投毒（定义 314–315 + ADX + E303/E315）；接触煤气灯/触觉篡改（A101 可分离性检查 + 交叉模态残差 + E315）；接触锚点事后性（定义 318 承诺阈值 + 接触可观测性门，先探后抓）；实时预算叠加（位姿层按需触发、CPA 仅接触后）；OOD 对称幻觉（定义 325 冻结商 + 回退 R69 纯保守）。
