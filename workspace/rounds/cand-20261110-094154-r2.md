# 第 43 轮（新循环第 3 轮） · 从「可进化的证书」到「可证的创新」：把论文创新点做成 Claim 证书，把通用机器人平台做成不停机的复制实验装置（四层架构 v8）

> 承接第 42 轮 v19（Sim-Cert-RAG 飞轮：SCV × CKB × ECR）。第 42 轮自陈最大风险是「仿真偏差累积 + 检索幻觉」。本轮两个灵感词正好把这两条风险从「工程隐患」升格为「科学方法论问题」：**论文创新点**——v19 把安全做成了可证对象，却仍把「这为什么算创新」留在散文里，于是同一套检索幻觉从「检索证书模板」蔓延到「检索相关工作」；**通用机器人平台**——v19 只把平台当部署靶子，而平台真正的独特性是：它是一台能对同一主张在多种本体、多种任务上反复做复制实验与消融的**实验装置**。于是本轮把「创新点」变成带判别性实验的 Claim 证书，把「通用平台」变成 Claim 的复制电池；安全证书仍是 worst-case sound，创新/泛化证书是 distributional statistical——两者**绝不混用**。一句话：v19 让证书进化，v20 让创新可证、让平台本身成为论文的证据生产器。

## 0. 直觉与动机

**灵感 1（论文创新点 = 差异化机制 + 判别性实验 + 可复现，而不是「没人这样写过」）**：绝大多数「创新点」写成「我们把 A 和 B 结合」，审稿人一句「相比 X 呢」就塌。真正可辩护的创新是可操作的：与最近的**可执行**基线，在**匹配预算与随机种子**下，于**预注册指标**上有显著且**可归因**的差异。这里有一个和 v19 同源的陷阱：RAG 式的相关工作检索同样会「检索幻觉」——召回到措辞相似但机制不同、或漏掉真正最接近的工作。解法不是「更信任检索」，而是**执行先验艺术（Executable Prior Art, E-PA）**：最近邻基线必须在仿真/平台上被复现，否则不算「已知方法」。通用平台的关键价值就在此——基线复现是一次性成本，摊薄到平台上的所有 Claim。归因则用 2×2 因子消融把「我们的机制」与「其它可能解释」分离。**新颖性不能被证明，只能被证伪**：一个 Claim 一旦被某个 E-PA 在匹配预算内达到同样效果，就是再发现（rediscovery）。

**灵感 2（通用机器人平台 = 跨本体复制实验装置；可移植性是证书的第一性度量）**：v19 的每条证书绑定单一本体与单一环境。可平台横跨机械臂、移动底盘、双臂、人形，若每个本体都从头认证，平台就退化成 N 个孤立系统，「通用」名不副实。直觉是把安全裕度**因式分解**：`m(x) = m_task(σ(x)) − δ_emb(β, x)`，其中 `σ` 是本体无关的任务状态投影，`β` 是本体画像，`δ_emb` 是本体诱导的有界惩罚。只要 `δ_emb` 在画像空间 Lipschitz（常数 `L_β`），把一个证书从 `β` 迁到 `β'` 只需承担 `L_β·‖β'−β‖` 的预算，而任务层证书可复用。于是得到**可移植指数 PI** 与**重认证增量 Δ_cert**。更深一层：每上一个新本体，就是对「证书可跨形态迁移」这个 Claim 的一次**复制实验**；平台越全，样本越多，泛化证书越硬——平台从「展示台」变成「实验台」。

**灵感 3（耦合：Claim↔Cert↔Deploy 科学飞轮，但两种证据语义必须分家）**：一次部署同时产出两样东西——安全证书（worst-case，单条轨迹/状态上 sound）与主张证据（statistical，跨平台分布上的效应与泛化）。v19 的 Sim→RAG→Edge 是**安全飞轮**；本轮再叠一条 Claim→Experiment→Evidence→Claim 的**科学飞轮**。二者共享平台、CKB、SCV，但必须用类型系统强制隔离：运行时只接受 `Cert<Sound>`，论文结论才引用 `Cert<Stat>`；把统计泛化证书当安全保证用，是**类别错误**，也是本轮最容易被误用的地方。由此 v19 的知识库从「证书/反例/课程」扩展为「主张—先验—消融—复制」的证据台账。

## 1. 形式化定义（增量：定义 38–45）

**定义 38（主张对象 Claim）**：`c = (h, m, e, f, τ, B_range)`：`h` 假设；`m` 机制（可开关的架构/算法部件）；`e` 效应谓词（在预注册指标 `κ`、阈值 `μ`、预算 `B` 下的比较陈述）；`f` 证伪实验（能推翻 `c` 的最小实验）；`τ` 任务契约；`B_range` 声称适用的本体画像范围。**可采纳性**：`c` 可进入台账，当且仅当 `f` 可执行、`e` 已预注册、且带可复现指纹（定义 41）。禁止「事后挑指标」。

**定义 39（可执行先验艺术与证伪裕度）**：`E-PA(c) = {p ∈ Top-k_retrieve(c) : reproduce(p, τ, B) = OK}`——只有被**实际复现**的最邻近方法才算「已知」。定义**证伪裕度**
`ρ(c) = inf{ b ≥ 0 : ∃p∈E-PA(c), p 在预算 B+b 下达到 e }`。
`ρ(c) ≤ 0` 当且仅当 `c` 被某个可执行先验在匹配预算内**支配** → 判定为 **Rediscovery**；`ρ(c) > 0` 只说明「尚未被已执行先验证伪」（Not-Yet-Dominated），**不是**新颖性的证明。新颖性证书 `N(c) = (E-PA, matched 集, ρ, 判别性实验 D(c), 复现指纹)`。`ρ` 是一个可审计的「护城河宽度」，而非论文措辞。

**定义 40（判别性实验与归因证书）**：`D(c)` 为匹配预算、共享种子的因子实验：条件 = {ours, ablate(m)} ∪ {每个 p∈E-PA}。**归因效应** `ATE(c) = E[Y | m=1] − E[Y | m=0]`（其余因子固定），用配对 bootstrap 给置信区间。**归因有效**当且仅当 (i) CI 不含 0；(ii) 与竞争机制的交互项不显著（排除混杂）；(iii) 与 `ablate(m)` 仅差机制本身。归因证书 `A(c) = (ATE, CI, 交互检验, 条件清单)`——这是「增益由我们的创新导致」而非「相关」的唯一依据。

**定义 41（可复现证书）**：`R(c) = (种子集, sim_config_hash, 硬件指纹, 容差 ε_rep, 重跑方差)`。要求 `Var_{seed}(metric) ≤ ε_rep`，且独立重跑与原始结果的相对误差有界。无 `R(c)` 的 Claim 不进台账。

**定义 42（任务–本体因式分解与能力契约）**：`σ: X → S_task` 为本体无关的任务状态投影；技能组合自动机 `A_τ` 定义任务行为。**可分离性假设**：`m(x) = m_task(σ(x)) − δ_emb(β, x)`。证书 `C = (C_task, C_emb)`：任务层条款（守卫/不变式/阈值）与本体层适配条款。可分离性本身是**待检验假设**（定义 43 的可移植性 soundness 以此为条件）。

**定义 43（可移植性与重认证增量）**：设 `δ_emb` 对画像满足 Lipschitz：`|δ_emb(β',x) − δ_emb(β,x)| ≤ L_β·‖β'−β‖`。把 `C` 从 `β` 迁到 `β'` 时，任务层条款若满足 `L_β·‖β'−β‖ ≤ 预算裕度` 则可**免重证**，否则落入 `Δ_cert` 需重新推导。**可移植指数** `PI(C, β→β') = 1 − |Δ_cert| / |C|`。**命题（条件 soundness）**：若可分离性成立、`L_β` 的界成立（置信 `1−δ_p`）、且 `Δ_cert` 被补全，则迁移后证书在 `β'` 上保 sound；任一条件不成立，PI 不得用于放行。

**定义 44（平台复制电池与泛化证书）**：电池 `ℬ = {(τ_i, β_j, pert_k)}` 覆盖任务×本体×扰动。对 Claim `c` 跑电池得复制记录 `{y_{ijk}}`。**泛化证书** `G(c)`：在平台分布 `P_platform` 上，用保形预测/经验 Bernstein 给出 `E_{(τ,β)∼P_platform}[effect]` 的 `1−α` 下界。**明确边界**：`G(c)` 是 **distributional** 的（依赖电池单元可交换性），**不是** worst-case 安全保证；分布外本体必须拒绝外推。

**定义 45（证据台账与创新分）**：`L = {(c, N(c), A(c), R(c), G(c), 复制记录)}`。**创新分** `IS(c) = ρ(c) · ATE(c) · breadth(c) · repro(c)`，其中 `breadth` 为有效复制单元占比。`IS` **仅作投资排序的决策辅助**，禁止作为重要性/正确性的证明；其可被刷分这一点是第一类风险，必须配审计。

## 2. 三大产出设计（新增 IP-57/58/59 + 升级既有）

### 2.1 IP-57 CLAIM-NOVELTY-ORACLE（CNO，主张–新颖性神谕）
1. **可执行先验艺术**：Top-k 相关工作/仓库/榜单条目 → 自动拉起基线复现（sim 或平台），失败者不计入 `E-PA`；复现结果缓存，跨 Claim 复用。
2. **证伪裕度求解**：对每个 `p∈E-PA`，二分/递增预算直到 `p` 达到 `e` 或超上限，得 `ρ`；`ρ≤0` 直接判 Rediscovery 并**退役**该 Claim（禁止静默保留）。
3. **判别性实验生成**：自动构造匹配预算的因子实验；预注册种子与指标。
4. **归因与复现**：2×2 因子 + 配对 bootstrap + 交互检验；重跑方差写指纹。

### 2.2 IP-58 MORPHO-PORTABILITY-CONTRACT（MPC，形态可移植契约）
1. **画像向量 `β`**：自由度/臂展/负载/传感配置/驱动带宽/形态图 → 归一化画像。
2. **可分离性检验**：在 SCV 电池上回归 `δ_emb`，做可分离性/残差检验；不通过则对相关条款标记「不可迁移」。
3. **`L_β` 估计**：沿画像轴做受控扰动，估 Lipschitz 界及置信；作为迁移预算硬约束。
4. **迁移编译器**：`C, β→β'` → 保留无损条款、列出 `Δ_cert`、给出 `PI`；`Δ_cert` 交给既有 LCS/CEGAR 补全。

### 2.3 IP-59 CLAIM-EVIDENCE-LEDGER（CEL，证据台账与复制引擎）
1. **台账结构**：Claim ↔ 先验 ↔ 消融 ↔ 复现 ↔ 复制记录，带版本与哈希；支持回滚、审计、自动退役。
2. **复制电池调度**：按本体族分层抽样，留出 held-out 本体族防过拟合；预算感知调度。
3. **泛化证书**：分层保形 + 经验 Bernstein；报告效应异质性（不能只报均值）。
4. **反刷分审计**：红队构造「措辞新颖但 `ρ≤0`」的主张，评估神谕召回；`IS` 仅作排序。

## 5. 本轮最大风险

**一句话**：本轮最大风险是「可证创新」退化为**自我参照的同义反复**——用我们自己的检索、消融与复制电池去证明我们自己的新颖性，平台越通用、证据越像自洽闭环，越可能产出「审稿人一追问先验艺术就塌」的伪创新；因此 E87（可执行先验艺术）与 E88（新颖性判别）必须作为红线实验，任何一项不达标，整条「创新证书」链就降级为人类评审的辅助材料，而不是论文结论。

## 1. 符号体系（增量：定义 38–45 符号）

|---|---|---|
| `c = (h,m,e,f,τ,B_range)` | 主张对象 | 机制 `m` 可开关；效应谓词 `e` 预注册；`f` 可执行 |
| `E-PA(c)` | 可执行先验艺术集 | 仅计「已复现成功」的 Top-k 最近邻 |
| `ρ(c)` | 证伪裕度 | `inf{b≥0 : ∃p∈E-PA, p 在 B+b 达 e}`；`ρ≤0` ⇒ Rediscovery |
| `D(c)` | 判别性实验 | 匹配预算/种子；条件含 ours/ablate/E-PA |
| `A(c)` | 归因证书 | 2×2 因子 ATE + 配对 bootstrap CI + 交互检验 |
| `R(c)` | 可复现证书 | 种子/配置哈希/硬件指纹/ε_rep/重跑方差 |
| `σ, β, δ_emb, L_β` | 任务投影/本体画像/本体惩罚/画像 Lipschitz | `m = m_task(σ(x)) − δ_emb(β,x)` |
| `Δ_cert, PI` | 重认证增量/可移植指数 | `PI = 1 − |Δ_cert|/|C|` |
| `ℬ = {(τ_i,β_j,pert_k)}` | 平台复制电池 | 分层覆盖任务×本体×扰动 |
| `G(c)` | 泛化证书 | `P_platform` 上 effect 的 `1−α` 下界（distributional） |
| `L` | 证据台账 | `{(c, N(c), A(c), R(c), G(c), 复制记录)}` |
| `IS = ρ·ATE·breadth·repro` | 创新分 | **仅排序辅助**，禁止作为正确性/重要性证明 |

**类型纪律**：`Cert<Sound>`（worst-case，可进运行时） ⊥ `Cert<Stat>`（distributional，只进论文/决策）。跨类型引用编译期报错。

## 2. 关键算法（伪代码）

### IP-57 CNO：新颖性证书与归因
```
INF = float('inf')

def certify_novelty(c, prior_kb, platform, B, budget_max):
    # 1) 检索只是候选，不构成"已知"
    neigh = prior_kb.retrieve(c.embedding, k=K=5)
    # 2) 执行先验艺术：复现失败者剔除（对抗检索幻觉）
    e_pa = []
    for p in neigh:
        r = reproduce_baseline(p, c.tau, platform, B)   # 真跑，不信文本
        if r.ok and r.fidelity_rel_err <= 0.02:
            e_pa.append((p, r))
    # 3) 证伪裕度：最近的已执行先验要多少额外预算才达到 e
    matched, best_b = [], INF
    for p, r in e_pa:
        b = budget_to_match(r, c.e, B, B + budget_max)   # 二分/递增
        if b <= 0:
            matched.append(p)
        best_b = min(best_b, b)
    if matched:
        return NoveltyCert(rho=0.0, verdict='REDISCOVERY', matched=matched)
    rho = best_b if best_b < INF else INF
    # 4) 判别性实验（匹配预算 + 预注册种子）
    dexp = Experiment(
        conditions=[('ours', c.m), ('ablated', ablate(c.m))] +
                   [(p.name, p.m) for p, _ in e_pa],
        seeds=PREREG_SEEDS, metric=c.e.metric, budget=B)
    return NoveltyCert(rho=rho, verdict='CANDIDATE',
                       experiment=dexp, e_pa=e_pa,
                       repro=fingerprint(c, platform))


def attribution_certificate(c, dexp):
    y = run_experiment(dexp)                         # 同种子/预算跨条件
    ate = mean(y['ours']) - mean(y['ablated'])
    ci = paired_bootstrap_ci(y, alpha=0.05)
    inter = interaction_test(y, factor='competing_mechanism')
    valid = (ci.lo > 0) and (not inter.significant)  # 效应存在且无混杂
    return AttrCert(ate=ate, ci=ci, interaction=inter, valid=valid)
```

### IP-58 MPC：跨本体迁移编译
```
def port_certificate(C, beta_from, beta_to, task, delta_p=0.05):
    # 可分离性检验（不通过则该条款不可迁移）
    if not separability_ok(task, beta_from, C):
        return None, list(C.task_clauses), 0.0
    # 画像 Lipschitz 界（来自 SCV 沿画像轴的受控扰动）
    L_beta, L_lo = estimate_profile_lipschitz(task, beta_from, conf=1-delta_p)
    budget = L_lo * profile_distance(beta_from, beta_to)   # 保守用下界
    keep, delta = [], []
    for cl in C.task_clauses:
        # 免重证条件：迁移预算不超过该条款裕度
        if budget <= cl.margin_budget:
            keep.append(cl)
        else:
            delta.append(cl)
    C_trans = Certificate(task=keep, emb=adapt(C.emb, beta_to),
                          source=beta_from, L_beta=L_lo)
    total = len(C.task_clauses) + len(C.emb.clauses)
    PI = 1.0 - len(delta) / max(1, total)
    return C_trans, delta, PI     # delta -> IP-52 LCS 迁移档补全
```

### IP-59 CEL：平台复制电池 + 泛化证书 + 台账
```
def run_replication_battery(claim, battery, platform):
    recs = []
    for (tau, beta, pert) in battery.cells:          # 按本体族分层
        C_t, delta, PI = port_certificate(
            claim.cert, claim.beta_ref, beta, tau)
        if C_t is None or delta:
            C_t = recertify(C_t, delta, tau, beta)   # 补全后才可执行
        out = run_task(tau, beta, pert, cert=C_t)    # 只接受 Cert<Sound>
        recs.append(Record(tau, beta, pert, out, PI))
    return recs


def generalization_certificate(claim, recs, alpha=0.1):
    valid = [r.effect for r in recs if r.valid]
    n = len(valid)
    mu = mean(valid)
    # 分层保形 + 经验 Bernstein 下界；显式声明分布内假设
    lower = mu - conformal_quantile(recs, alpha) / sqrt(n)
    return GenCert(effect=mu, lower=lower, coverage=1-alpha,
                   heterogeneity=iqr(valid),
                   caveat='distributional over P_platform; NOT worst-case safety')


def update_ledger(L, claim, nov, attr, gen):
    L.append(Entry(claim, nov, attr, gen, ts=now(),
                   hashes=fingerprint_bundle(claim, nov, attr, gen)))
    if nov.verdict == 'REDISCOVERY':
        L.retire(claim)          # 自动退役，禁止静默保留
    else:
        L.set_rank(claim, innovation_score(nov.rho, attr.ate,
                                           breadth(gen), repro=claim.repro))
    return L


def audit_anti_gaming(L, red_team_claims):
    # 对抗主张：措辞新颖但 rho<=0 / 效应不可归因
    flagged = [c for c in red_team_claims
               if certify_novelty(c, ...).verdict == 'REDISCOVERY'
               or not attribution_certificate(c, ...).valid]
    return len(flagged) / max(1, len(red_team_claims))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性/边界 |
|---|---|---|---|
| CNO 检索 | O(log N) + 重排 O(k·d) | O(N·d) | 检索只产生候选；**不证明新颖性** |
| CNO 基线复现 | O(k·C_baseline)，跨 Claim 缓存摊薄 | O(k) | 只有复现成功者计入 E-PA，抗检索幻觉 |
| CNO 证伪裕度 | O(k·log(budget_max/ε)) | O(k) | `ρ≤0` ⇒ 可判 Rediscovery；`ρ>0` 仅「未被证伪」 |
| 归因 A(c) | O(#cond·N_seed·T) | O(#cond) | CI 排除 0 且交互不显著才有效；否则降级为相关 |
| 可复现 R(c) | O(重跑次数·T) | O(1) | 重跑方差 ≤ ε_rep 才可采纳 |
| MPC 迁移编译 | O(|C|·d) | O(|C|) | sound **条件于**可分离性 + `L_β` 界 + Δ_cert 补全 |
| CEL 复制电池 | O(|ℬ|·C_task) | O(|ℬ|) | 需要单元可交换；分布外本体拒绝外推 |
| 泛化 G(c) | O(|ℬ|·log|ℬ|) | O(|ℬ|) | distributional（1−α），**非** worst-case 安全 |
| 台账/审计 | O(1) 追加；审计 O(N_red·C_check) | O(N) | IS 仅排序；可刷分是已知风险 |

## 4. 论文创新点（本轮明确抽取，含基线与消融）

> 每个创新点都是一个 Claim，须附 `N(c), A(c), R(c), G(c)`；未过红线的一律标 `[candidate]`，不得以肯定语气写入摘要。

| # | 创新点 | 最近基线 | 消融（判别机制） | 预注册指标 | 目标类型 |
|---|---|---|---|---|---|
| P1 | **可证创新飞轮**：把安全证书与主张证据统一到同一平台的持续闭环，Claim 可自动退役 | 静态认证控制器 / 运行时监控；单轮 RAG | 去掉 CNO → 冷启动；去掉 CEL → 无复制 | 安全违例率、Nominal 占比、COT、伪新颖率 | 系统/方法 |
| P2 | **可执行先验艺术 + 证伪裕度**：用「执行基线」把新颖性从措辞变成可审计的 `ρ` | LLM/人工相关工作判断；纯检索 | 检索不执行（文本相似）→ 暴露检索幻觉 | 伪新颖率、复现率、`ρ` 校准 | 方法论/评测 |
| P3 | **形态可移植证书契约**：任务×本体因式分解 + `L_β` 迁移预算 + PI | 逐本体从头认证 | 关闭因式分解（逐本体重证） | PI、重认证成本、迁移后违例 | 主方法 |
| P4 | **平台即实验**：预注册跨本体复制电池产出 distributional 泛化证书 | 单本体评测 / 事后汇总 | 只报均值不报异质性 → 过拟合 | 保形覆盖率、效应异质性、held-out 本体族 | 平台/基准 |

**诚实边界**：P2 只能证伪不能证明新颖性；P4 的泛化证书依赖电池单元可交换性，属于分布内结论；P1 的 `IS` 是可刷分的排序指标，不能当作贡献度量。

## 6. 风险与缓解（增量）

| 风险 | 等级 | 缓解 |
|---|---|---|
| 元循环自证：自家检索/消融/电池自证新颖，检索偏差被放大 | 高 | 强制 E-PA 执行、外部基线、预注册、红队复现；E88 红线 |
| 平台过拟合：复制电池单元同源，共享失败模式 | 高 | 按本体族分层 + 留出 held-out 本体族 + 汇报异质性 |
| 类别错误：把 distributional `Cert<Stat>` 当 worst-case 安全用 | 高 | 类型系统强制 `Cert<Sound>` ⊥ `Cert<Stat>`；运行时只收 Sound |
| 先验艺术复现成本爆炸 | 中 | 缓存摊薄、top-1 + 解析下界、超预算降级 advisory |
| 创新分 IS 被刷 | 中 | 仅作投资排序；审计 + 反例集；不进论文结论 |
| 可分离性/`L_β` 假设不成立 | 中 | 可分离性检验 + 残差建模；不成立则 PI=0、逐本体认证 |
| 泛化证书违反可交换性 | 中 | 分层保形、分布外检测、超阈值拒绝外推 |
| 归因被混杂（组合增益错归因子机制） | 中 | 2×2 因子 + 交互检验；乘积 Claim 必含子主张基线 |

## 7. 本轮最大风险

**一句话**：本轮最大风险是「可证创新」退化为**自我参照的同义反复**——用我们自己的检索、消融与复制电池去证明我们自己的新颖性，平台越通用、证据越像自洽闭环，越可能产出「审稿人一追问先验艺术就塌」的伪创新；因此 E87（可执行先验艺术）与 E88（新颖性判别）必须作为红线实验，任何一项不达标，整条「创新证书」链就降级为人类评审的辅助材料，而不是论文结论。
