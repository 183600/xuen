# 第 57 轮（承接第 56 轮「证据地图×主动探询×信任协商」IP-127~132；新灵感循环第 1 轮；本轮灵感：「手眼标定」×「交互设计」）

> 第 56 轮把「模型置信」换成「证据质量」，用证据门、探询 VOI、地图溯源与协商护盾把坏证据挡在承诺之前；但它自陈的风险暴露了一个更底层的默认假设——**所有证据与所有承诺都活在一个共同且可信的坐标系里**。可证据来自眼（分割/视觉）、手（足端接触/本体感受）、人（标注/指点）、云（全局先验），它们分处不同帧；一旦手眼变换漂移，证据门会「诚实地」为**系统性错位**放行，而且这种错误因自洽而不可见。**手眼标定**补的正是这条腿：变换本身是一个带协方差、可观性、版本与漂移的**信念**，必须在线、可激励、可审计；**交互设计**补的是另一条腿：人机之间的「帧对齐」不是一次工厂标定，而是一场**共享、可读、可协商、有界**的对话——人提供的是「对应/锚点」，不是决策。核心命题由「证据说可信」升级为 **「帧被接地的证据才可信」**，标定由一次性离线工序升级为 **活标定（living calibration）**。

核心矛盾：
- **H26**：𝓜 的证据没有帧索引——旧证据在漂移后的新帧里被静默重表达，置信度不会自动下降；帧误差是**自洽的**，证据门无法用证据自身发现它。
- **H27**：经典手眼标定是离线、一次性、无人参与的；部署中变换会漂移（热、负载、磨损、腿柔顺），而最廉价的独立锚点恰恰是人（指点、放标定物），但频繁要求人标定会引发疲劳，且无界的人类输入会重新打开第 56 轮堵住的洞。交互设计的要求是让标定**稀有、可读、可回报**。

## 0. 直觉与动机

**灵感 1（手眼标定 → 帧是一个会漂移的信念，必须被激励才可观测）**
直觉：经典手眼标定解 `AX = XB`，其可解性依赖运动激励——没有足够的旋转与非退化平移，方程本身就有零空间；在线手眼标定则要持续监测残差并重标。映射到本轮：**眼**是视觉/语义地图帧，**手**是足端接触/本体执行帧，**人**是人类参照帧。关键洞察不是「求得一个 T」，而是「维护一个关于 T 的可观测后验」：**在未被激励的自由度上，协方差小只是错觉**。于是标定动作是一种**认知动作**——为了看清，必须先「动对」；这与第 56 轮探针同源，只是探针探的是区域，标定探针探的是**帧本身**。

**灵感 2（交互设计 → 标定是一场关于「共同参照」的对话）**
直觉：HRI 的 common ground / grounding 说，人和机器人必须先对齐「我们说的是同一个东西」，人指「那块石头」本质上就是一次跨帧对应。交互设计给出的不是界面皮肤，而是硬约束：**parity**（人看到与机器人同一份帧置信）、**progressive disclosure**（只在帧不确定性改变决策时才暴露）、**bounded repair**（人只能改帧信念，不能改决策规则）、**reversibility**（每次标定可撤销、可审计）。因此「标定请求」本身是一种必须设计的互动：**必须说清为什么现在需要、要多久、能换回多少确定性**。

**灵感 3（融合 → 活标定：任务条件化、激励驱动、人类锚定）**
直觉：标定探针 `π_cal ∈ {gaze, vergence, self_touch, fiducial_track, human_anchor}` 与第 56 轮的 view/tap/shift 并列，进入同一个 VOI 竞价——但优化的是**决策风险的下降**，而不是单纯协方差下降（看得更准但决策不变的标定不值钱）。人提供的对应进入 `EV-anchor` 证据类，带权重上界与隔离区。标定从「开机一次」变成「按需、按任务、按风险」的持续过程：**任务只在某个方向上需要精度，就只在该方向上买可观性**。

**灵感 4（帧索引证据 + 帧见证 + 帧证书 → 无帧证不承诺）**
直觉：每条证据都必须记住「我是用什么版本、哪条变换链表达的」；一个承诺除了挂证据类，还必须挂**帧见证 FW**：要么链上每条变换 `obs ≥ obs_min` 且重投影协方差 `≤ ε_frame`，要么有独立锚点（人类/外部 fiducial）验证，要么动态裕度足以吞下最坏帧误差。这把第 56 轮的「证据门」升级为「**帧 × 证据双门**」——没有帧见证，再好的区域信念也不能承诺。

**灵感 5（标定经济学 → 社会 VOI，把打扰算进代价）**
直觉：人的一次指点有社会成本 `c_h`（打断、注意力、信任磨损）。只有当 `VOI_frame − c_h ≥ θ` 时才请求；请求有预算与冷却；超预算则改用自主激励、或降低任务风险（绕行/降档/停）。这把 PCE 的「用时间能量买信息」扩展为「**用打扰买共同参照**」，也让人机交互第一次有了可计算的预算边界。

## 1. 形式化定义（增量：定义 133–138）

**定义 133（标定帧图）** `𝓕 = (𝒱_F, ℰ_F, {T_ab}, {Σ_ab}, obs, ver, drift)`：帧节点 `𝒱_F = {E(眼), B(身), L_i(足), M(地图), H(人)}`；边 `(a,b) ∈ ℰ_F` 带刚体变换后验 `T_ab ∈ SE(3)`、协方差 `Σ_ab`、可观性 `obs(e)=λ_min(I_e)`（Fisher 信息最小特征值/条件数）、版本 `ver(e)`、漂移模型 `drift(e)`。复合 `T_ac = T_ab ∘ T_bc`，协方差一阶传播 `Σ_ac = Ad_{T_bc^{-1}} Σ_ab Ad^T_{T_bc^{-1}} + Σ_bc`。

**定义 134（标定探针与可观测性公理）** `π_cal ∈ A_epis`，含 `{gaze, vergence, self_touch, fiducial_track, human_anchor}`；对边 e 产生观测 `z` 与 Fisher 增量 `ΔI_e(π_cal)`。可观性公理：`π_cal` 合法 ⇔ 非破坏（继承 A34 力帽）∧ `obs(e; π_cal) ≥ obs_min`（对任务所需方向）∧ 激励了原先未激励子空间 `S_deg`。退化检测：`rank(I_e) < dim` 或 `λ_min(I_e) < obs_min` 时，该边不得单独充当帧见证。

**定义 135（帧索引证据与重投影）** `e = (region, type, payload, t, src, T_ref, ver_ref)`；在当前帧下表达需复合 `T_now←ref`，重投影协方差 `Σ_proj = J_T Σ_T J_T^T`。有效性：`valid(e) ⇔ age ≤ τ_stale ∧ d_SE3(T_now, T_ref) ≤ δ_frame ∧ Σ_proj ⪯ ε_frame I`；否则标记 **frame-stale**，须重标或重观测，禁止参与承诺。

**定义 136（帧 VOI 与社会 VOI）** `VOI_frame(π)=E[ΔRisk_red(Σ_T)] − λ_deg·1[退化未消]`；人类请求的社会价值 `VOI_social(π_h)=VOI_frame(π_h) − c_h − λ_req·load`；仅当 `VOI_social ≥ θ_voi` 时发起 L1/L2 标定请求，并受 `k_cal`、冷却与请求预算约束。

**定义 137（标定交互契约）** 请求对象 `ReqCal=(边 e, 当前不确定度可视化, 期望下降量, 预计时长, 可选{自主/人工/跳过}, 回报解释)`；人提供**对应/锚点** `(p_human, p_robot)` 而非标签，作为 `EV-anchor` 经有界权重 `w_a ≤ w_max` 与隔离区进入帧信念；决策规则仍与人类输入隔离。设计公理：parity、progressive disclosure、bounded repair、reversibility。

**定义 138（帧证书 J_f）** `J_f=(J_m, 𝓕_core, obs_min, Σ_T, drift_bound, corr_log, frame_consistency)`；每个承诺接触除证据类外必须带**帧见证 FW**；帧一致性不变量：排程内所有证据所用变换与当前估计偏差 `≤ δ_frame`，否则拒绝。证据类扩展为 `{EV-probe, EV-visit, EV-margin, EV-human, EV-frame, EV-anchor}`。

## 2. 关键算法伪代码（完整版见产物区）

### IP-133 FMM（Frame Map Maintenance）

```python
def frame_fuse(F, batch):
    for m in batch:                                  # m=(edge,z,t,src,cov,task_dirs)
        e = m.edge
        F.T[e], F.Sigma[e] = se3_bayes_update(F.T[e], F.Sigma[e], m.z, m.cov)
        F.obs[e] = fisher_min_eig(F.history[e], task_dirs(F.task))
        if F.obs[e] < obs_min and risk_depends_on(e):
            F.degenerate[e] = unexcited_subspace(F.history[e])  # 未激励方向
        F.drift[e] = drift_estimate(F.history[e], half=tau_drift)
        F.ver.bump(e)
    return F

def frame_health(F, e, task):
    if F.obs[e] < obs_min:                        return 'degenerate'
    if F.drift[e] * dt_since(F.ver[e]) > delta_frame: return 'drifted'
    return 'ok'
```

### IP-134 OAC（Observability-driven Active Calibration）

```python
def observability_driven_calibration(x0, F, task, risk, budget, consent):
    log = []
    while budget.cal_left > 0 and any_unwitnessed(task, F):
        cands = [p for p in calib_primitives(x0, F, F_abs)
                 if p.nondestructive and excites(p, F.degenerate_edges(task))]
        if not cands: break
        p = argmax(cands, key=lambda q: voi_frame(q, F, risk) - cost(q))
        if voi_frame(p, F, risk) < theta_voi: break
        F, _ = frame_fuse(F, execute_calib(p, cap=F_abs))
        budget.spend(p); log.append(p.evidence())
        if not can_self_excite(F, task):          # 自主激励不足，需独立锚点
            req = grounded_calib_request(F, task, expected_gain=voi_frame, cost=c_h)
            if voi_social(req) >= theta_voi and consent.grant(req):
                F, _ = frame_fuse(F, [human_anchor_evidence(req)])
            else:
                return 'downgrade_or_reroute', log
    return 'ok', log
```

### IP-135 FEI（Frame-Evidence Indexing & Reprojection）

```python
def frame_indexed_gate(e, F, task, now):
    T_now = compose_chain(F, e.chain)                  # E→B→L_i→M 复合
    Sigma_proj = reproject_cov(e.Sigma_ref, F, e.chain)
    if now - e.t > tau_stale:                        return 'frame_stale'
    if se3_distance(T_now, e.T_ref) > delta_frame:   return 'frame_stale'
    if not psd_leq(Sigma_proj, eps_frame * I):       return 'frame_stale'
    if any(F.obs[edge] < obs_min for edge in e.chain): return 'frame_unobservable'
    return 'fresh'

def admit_to_commit(e, F, now):
    st = frame_indexed_gate(e, F, task, now)
    if st != 'fresh': return False, st                 # 禁止承诺；触发 OAC/重观测
    return True, 'EV-frame'
```

### IP-136 CIC（Calibration Interaction Contract）

```python
def grounded_calib_request(F, task, expected_gain, cost):
    return ReqCal(edge=most_uncertain_edge(F, task),
                  vis=ghost_overlay(F.visual_frame, F.live_frame),   # parity: 可见错位
                  gain=expected_gain, eta=estimate_duration(F),
                  options=['auto', 'human_anchor', 'skip'],
                  repay='这次标注如何闭环、如何减少未来重标')

def handle_human_anchor(req, pts, op_hist, audit):
    if not calibratable(req): return 'reject'
    pairs = match_correspondences(pts, req.edge)          # 人点 → 机器人帧
    w = min(w_max, w0 * anchor_score(op_hist, req.edge))  # A40 有界
    if not holdout_consistent(pairs):                     # 不用同一批数据自证
        return 'quarantine'
    F, _ = frame_fuse(F, [anchor_evidence(pairs, weight=w)])
    audit.append((req, pairs, w, t_now))
    return 'ok'
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| FMM | O(|ΔM|·d_T) 增量 | O(|𝒱_F|·d_T) | 协方差诚实、漂移可检、退化标记 |
| OAC | O(k_c·(C_VOI+|ℰ_F|)) | O(|𝒱_F|+|log|) | 激励覆盖、社会 VOI 有界、k_c 终止 |
| FEI | O(depth(chain)) | O(|证据|) | 帧陈旧即拒绝、重投影协方差计入 |
| CIC | O(1)+O(H_op) | O(|对应|) | 请求稀有可读、锚点有界隔离 |
| FSC | O(|σ|·depth) | O(|σ|) | 无帧证不承诺、帧一致性 |

**正确性定理（Frame-Grounded Commitment Soundness, FGCS）**：继承 A22–A36，新增 **(A37)** 帧信念校准（真实变换误差落在报告 `Σ_T` 的 `1−ε_f` 置信域）且融合保校准；**(A38)** 标定激励覆盖（任务所需方向 `obs ≥ obs_min`，否则标退化且不得单独作帧见证）；**(A39)** 帧索引证据闸门（`τ_stale`、`δ_frame`、重投影协方差）严格执行；**(A40)** 人类锚点有界、隔离、留出校验独立于拟合数据。则：(i) 承诺失效率 `≤ δ_f + ε_cal + δ_probe + ε_h + ε_f + ε_proj + ε_anchor`；(ii) **帧安全单调性**：标定与交互只能更新帧信念或触发更保守动作，不存在升险路径；(iii) **无帧证不承诺**：不存在缺帧见证的承诺接触；(iv) OAC/PCE 在 `k_cal+k_probes` 内终止于 {承诺, 绕行, 降档, 协商, 安全停}。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 循环标定：系统用自己的地图验证自己的帧，自洽错误不可见 | 高 | 独立锚点 + 留出/交叉验证；禁止同一批数据既拟合又认证 |
| 可观性错觉：VOI 用同一失准模型选到不激励的动作 | 高 | obs 下界 + 强制激励覆盖 + 退化检测 + 外部 fiducial |
| 人类锚点疲劳/敷衍 | 中高 | 社会 VOI + 请求预算/冷却 + parity + 锚点质量监控 |
| 帧门过度保守 → 频繁重标、可用性下降 | 中 | 只在帧不确定性改变决策时开门 + 帧预算 + 增量重投影 |
| 帧版本爆炸 / 失效级联 | 中 | 限定失效作用域 + 溯源 + 增量化 |
| 云帧先验与本地冲突 | 中 | 边端帧主权：云可下发激励计划，但不得无本地帧见证强行改帧 |

## 6. 本轮最大风险

**一句话**：本轮把安全赌注再下沉到「帧可信」，但标定最危险的失败不是不准，而是**自洽地不准**——用同一批数据既拟合又认证、用偏向的 VOI 选到不激励的自由度、或一条被敷衍的人类锚点，都会让系统在协方差「看起来很小」时保持一个系统性错帧，于是所有帧见证与证据门一起「诚实地为错位放行」；必须以独立锚点+留出校验、激励覆盖+退化检测、锚点隔离+请求预算三重护栏，宁可承认「此帧不可观」，绝不采信「自洽的确定」。

| `e=(...,T_ref,ver_ref)` | 帧索引证据；重投影协方差 `Σ_proj=J_TΣ_TJ_T^T` |
| `δ_frame, ε_frame, τ_stale` | 帧位移阈值 / 重投影协方差阈值 / 证据帧陈旧期 |

## 2. 关键算法伪代码

### IP-133 FMM（Frame Map Maintenance）

```python
def frame_fuse(F, batch):
    changed = []
    for m in batch:                                    # m=(edge,z,t,src,cov,task_dirs)
        e = m.edge
        F.T[e], F.Sigma[e] = se3_bayes_update(F.T[e], F.Sigma[e], m.z, m.cov)
        F.obs[e] = fisher_min_eig(F.history[e], task_dirs(F.task))
        if F.obs[e] < obs_min and risk_depends_on(e):
            F.degenerate[e] = unexcited_subspace(F.history[e])   # 未激励方向
        F.drift[e] = drift_estimate(F.history[e], half=tau_drift)
        F.ver.bump(e); changed.append(e)
    return F, changed

def frame_health(F, e, task):
    if F.obs[e] < obs_min:                            return 'degenerate'
    if F.drift[e] * dt_since(F.ver[e]) > delta_frame: return 'drifted'
    return 'ok'

def compose_chain(F, chain):                          # 例: E→B→L_i→M
    T, S = identity(), zeros()
    for e in chain:
        T, S = T @ F.T[e], propagate_cov(S, F.Sigma[e], T)
    return T, S
```

### IP-134 OAC（Observability-driven Active Calibration）

```python
def observability_driven_calibration(x0, F, task, risk, budget, consent):
    log = []
    while budget.cal_left > 0 and any_unwitnessed(task, F):
        cands = [p for p in calib_primitives(x0, F, F_abs)
                 if p.nondestructive and excites(p, F.degenerate_edges(task))]
        if not cands: break                            # A38: 无法自激励
        p = argmax(cands, key=lambda q: voi_frame(q, F, risk) - cost(q))
        if voi_frame(p, F, risk) < theta_voi: break
        F, _ = frame_fuse(F, execute_calib(p, cap=F_abs))
        budget.spend(p); log.append(p.evidence())
        if not can_self_excite(F, task):               # 需独立锚点
            req = grounded_calib_request(F, task, voi_frame(p, F, risk), c_h)
            if voi_social(req) >= theta_voi and consent.grant(req):
                F, _ = frame_fuse(F, [human_anchor_evidence(req)])   # 经 CIC 校验
            else:
                return 'downgrade_or_reroute', log     # 纤维不足：降档/绕行/停
    return 'ok', log

def voi_frame(p, F, risk):
    d_sigma = expected_sigma_reduction(p, F)           # 悲观界
    d_risk  = risk.sensitivity_to(F.edges_involved) @ d_sigma
    return d_risk - lambda_deg * int(still_degenerate(p, F))

def voi_social(req):
    return voi_frame(req.probe, req.F, req.risk) - req.c_h - lambda_req * req.load
```

### IP-135 FEI（Frame-Evidence Indexing & Reprojection）

```python
def frame_indexed_gate(e, F, task, now):
    T_now, _ = compose_chain(F, e.chain)               # E→B→L_i→M 复合
    Sigma_proj = reproject_cov(e.Sigma_ref, F, e.chain)
    if now - e.t > tau_stale:                          return 'frame_stale'
    if se3_distance(T_now, e.T_ref) > delta_frame:     return 'frame_stale'
    if not psd_leq(Sigma_proj, eps_frame * I):         return 'frame_stale'
    if any(F.obs[edge] < obs_min for edge in e.chain): return 'frame_unobservable'
    return 'fresh'

def admit_to_commit(e, F, now):
    st = frame_indexed_gate(e, F, task, now)
    if st != 'fresh':
        return False, st                               # 禁承诺，触发 OAC 或重观测
    return True, 'EV-frame'

def reproject_cov(Sigma_ref, F, chain):
    J = jacobian_of_chain(F, chain)                    # ∂T_now←ref / ∂T_ref
    return J @ Sigma_ref @ J.T + add_chain_noise(F, chain)
```

### IP-136 CIC（Calibration Interaction Contract）

```python
def grounded_calib_request(F, task, expected_gain, cost):
    e = most_uncertain_edge(F, task)
    return ReqCal(edge=e,
                  vis=ghost_overlay(F.visual_frame, F.live_frame),   # parity: 可见错位
                  gain=expected_gain, eta=estimate_duration(e),
                  options=['auto', 'human_anchor', 'skip'],
                  repay='此标注将如何闭环、如何减少未来重标',

def handle_human_anchor(req, pts, op_hist, audit):
    if not calibratable(req): return 'reject'
    pairs = match_correspondences(pts, req.edge)       # 人点 → 机器人帧
    w = min(w_max, w0 * anchor_score(op_hist, req.edge))   # A40 有界
    if not holdout_consistent(pairs):                  # 不用同一批数据自证
        return 'quarantine'                            # 隔离，待独立佐证
    F, _ = frame_fuse(F, [anchor_evidence(pairs, weight=w)])
    audit.append((req, pairs, w, t_now))
    return 'ok'
```

### IP-137 FSC（Frame-Safety Certificate）

```python
def frame_certificate(sched, F, J_m, budgets):
    for c in contacts(sched):
        fw = c.frame_witness
        if fw is None: return ('reject', 'no_frame_witness', c)
        if fw.kind == 'observable':
            ok = (all(F.obs[e] >= budgets.obs_min for e in fw.chain)
                  and psd_leq(fw.Sigma_proj, budgets.eps_frame * I))
        elif fw.kind == 'anchor':
            ok = fw.anchor.verified and fw.anchor.op_cal >= theta_cal
        elif fw.kind == 'margin':
            ok = fw.worst_case_reach >= fw.frame_error_bound
        else:
            ok = False
        if not ok: return ('reject', 'frame_witness_insufficient', c)
    if not frame_consistent(sched, F, budgets.delta_frame):
        return ('reject', 'frame_inconsistent')
    return ('ok', FrameCert(F.core, budgets.obs_min, F.Sigma, F.drift_bound,
                            corr_log(F), J_m))

def frame_consistent(sched, F, delta):
    for c in contacts(sched):
        T_now, _ = compose_chain(F, c.evidence.chain)
        if se3_distance(T_now, c.evidence.T_ref) > delta: return False
    return True
```

### IP-138 LCF（Living Calibration Framework：把标定嵌入 PCE 决策环）

```python
def probe_commit_evolve_v33(x0, M, F, task, budget, consent):
    route = plan_on_map(M, task, risk_model)
    sched, log = [], []
    for cp in route.checkpoints:
        # 1) 先做帧可行性：未接地则不进入区域探询
        fst, flog = observability_driven_calibration(x0, F, task, risk, budget, consent)
        if fst != 'ok': return negotiate_or_stop(cp, M, None, None, consent, F)
        # 2) 帧索引闸门：旧证据先过帧门，再过第 56 轮证据门
        fresh = [e for e in cp.evidence if admit_to_commit(e, F, t_now)[0]]
        M_cp = restrict_map(M, fresh)                  # 帧陈旧证据淡出该检查点
        # 3) 第 56 轮 PCE（在帧接地的地图上）
        sigma, rlog, M = pce_core(x0, M_cp, cp, budget, consent)
        if sigma is None: return negotiate_or_stop(cp, M, None, None, consent, F)
        # 4) 双门：证据门 + 帧见证门
        if not frame_certificate(sigma, F, J_m=None, budgets)[0] == 'ok':
            return negotiate_or_stop(cp, M, sigma, None, consent, F)
        sched.append(sigma); log += rlog + flog
    return sched, log, M, F
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| FMM | O(\|ΔM\|·d_T) 增量 | O(\|𝒱_F\|·d_T) | SE(3) 协方差诚实、漂移可检、退化标记（A37/A38） |
| OAC | O(k_c·(C_VOI+\|ℰ_F\|)) | O(\|𝒱_F\|+\|log\|) | 激励覆盖、悲观帧 VOI、k_c 终止（A38） |
| FEI | O(depth(chain)) | O(\|证据\|) | 帧陈旧即拒绝、重投影协方差计入（A39） |
| CIC | O(1)+O(H_op) | O(\|对应\|) | 请求稀有可读、锚点有界隔离、留出校验（A40） |
| FSC | O(\|σ\|·depth) | O(\|σ\|) | 无帧证不承诺、帧一致性 |
| LCF | 同 PCE + OAC | O(\|𝒱_F\|+\|σ\|) | 帧门先于证据门、双门合取 |

**正确性定理（Frame-Grounded Commitment Soundness, FGCS）**
假设 A22–A28（53/54 轮）、A29–A32（55 轮）、A33–A36（56 轮）成立；新增：
**(A37) 帧信念校准**：真实变换误差落在报告 `Σ_T` 的 `1−ε_f` 置信域内，融合算子保校准且漂移模型悲观；
**(A38) 激励覆盖**：对任务所需方向 `obs(e) ≥ obs_min`，否则标退化且不得单独充当帧见证；
**(A39) 帧索引证据**：`τ_stale`、`δ_frame`、`Σ_proj ⪯ ε_frame I` 三闸严格执行；
**(A40) 人类锚点有界**：`w_a ≤ w_max`、隔离区、锚点质量随校准衰减，且**留出校验数据独立于拟合数据**。则：

1. **承诺健全性**：每个承诺接触 `P(fail) ≤ δ_f + ε_cal + δ_probe + ε_h + ε_f + ε_proj + ε_anchor(w_max)`；
2. **帧安全单调性**：标定探针、人类锚点、L1/L2 协商只经（a）帧/区域信念更新或（b）触发更保守动作影响系统，不存在升险路径；
3. **无帧证不承诺**：不存在缺 `FW` 的承诺接触；帧一致性被破坏即拒绝；
4. **终止性**：`OAC+PCE` 在 `k_cal+k_probes` 内终止于 {承诺, 绕行, 降档, L2 协商, 安全停}；
5. **部署界**（对检查点与帧边取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_cal + δ_probe + ε_h + ε_f + ε_proj + ε_anchor)
             − P(帧退化未被检出) − P(帧漂移超 δ_frame 未检出)
             − P(锚点独立性/留出校验失效) − P(护盾回退失败) − P(τ_int 超时 ∧ 安全停失效)
```

关键新增：**帧门先于证据门**（错帧的证据再新也不采信）；**标定不可用则任务降级**（无帧证 → 绕行/降档/停，而非硬猜）；**拟合与认证数据分离**（打破循环标定的自洽陷阱）。

## 6. 本轮最大风险

**一句话**：本轮把安全赌注再下沉到「帧可信」，但标定最危险的失败不是不准，而是**自洽地不准**——用同一批数据既拟合又认证、用偏向的 VOI 选到不激励的自由度、或一条被敷衍的人类锚点，都会让系统在协方差「看起来很小」时保持一个系统性错帧，于是所有帧见证与证据门一起「诚实地为错位放行」；必须以独立锚点+留出校验、激励覆盖+退化检测、锚点隔离+请求预算三重护栏，宁可承认「此帧不可观」，绝不采信「自洽的确定」。
