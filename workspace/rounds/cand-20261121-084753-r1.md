# 第 1 轮（新灵感循环第 1 轮；本轮灵感：「云端协同」×「抓取位姿估计」）

> **基线**：上一轮（灵感「大语言模型」×「机器人」×「智能体」）MetricVoiceGauge-NCD-HUTDH-v17（定义 657–686；引理 137–142；实验 E691–E710）。
> 本轮纪律：**云端只是更远的提议者，证书不可外包，发散是新的缝隙**。不推倒 v17：v17 的 CLP/S2C/HCG/PSV/APS/AMC 与 v16→v6 全部保留。六个新组件——CPQ（证书保持量化器）、GCL（抓取证书格）、CDV（云边发散验证器）、CMR（证书余量排序器）、ACR（异步证书调和器）、CFA（云端失效衰减器）——一律以**中立元接入 v17 语言层之上**，失效即严格退回 v17（引理 146/147），再沿 v17→v16→…→v6 退化链退回。本轮只做三件事：把"云端协同"改写为**证书保持的跨网压缩与传输**、把"抓取位姿估计"改写为**抓取证书格与认证盆地**、把"云边状态不一致"改写为**可界定的发散证书**。

## 0. 直觉与动机

**灵感 1（云端协同 → 位姿可压缩，证书不可压缩）**
直觉：云端的价值是看得更多、模型更大，因此能给出**抓取位姿的分布**而非单点；边缘的价值是实时与安全，因此只能执行**当前场景下被本地证书覆盖**的抓取。两者之间的链路是窄的、慢的、会断的。传统做法在两端之间传位姿（压缩有损，证书随之失效）或传模型（带宽/时延不可行）。核心创新：**证书保持量化器（Certificate-Preserving Quantizer, CPQ）**——云端不传分布，而传分布的**有限 δ-网**，每个网点携带 `(位姿, 证书余量, Lipschitz 界)`。关键反直觉点：**真正该无损传输的是证书，不是位姿**；证书在 Lipschitz 意义下可"外推"到整个 δ-邻域，于是边缘选邻域内任意位姿都能得到一个可证明的证书下界 `m_j − L_j·δ`。压缩的代价被记在**余量**账上，而不是**安全**账上。

**灵感 2（抓取位姿估计 → 抓取不是一个点，是一个认证盆地）**
直觉：学习式抓取位姿估计输出的是多峰分布，"最高置信度"的抓取常恰好落在碰撞边界或力闭合退化区——置信度不等于证书。核心创新：**抓取证书格（Grasp Certificate Lattice, GCL）**：把抓取安全性拆成四个可独立验证的分量——力闭合余量 FC、无碰撞且可达余量 CF、感知/位姿不确定度余量 PU、与 v17 计划缝的相容余量 SC——取逐分量最小（格的 meet）作为抓取证书 `cert_G`。关键反直觉点：**抓取的价值不是成功率，而是认证盆地的体积** `vol{g' : cert_G(g') ≥ 0}`；应选"证书最厚"的抓取，而不是"最像成功"的抓取。并行夹爪的对称群 `Sym`（绕接近轴旋转 π）要在度量里商掉，否则 δ-网会在一半冗余方向上浪费带宽。

**灵感 3（云端协同 × 抓取 → 状态发散是新的"缝隙"）**
直觉：v17 的风险是**计划缝**——每个 BT 节点都有证书，节点交接处没有。v18 的风险是**云边缝**——云端在它以为的场景上算出的抓取证书，与边缘此刻真实场景之间隔着时间、遮挡、运动、压缩与重放。核心创新：**云边发散验证器（Cloud-Edge Divergence Verifier, CDV）**：定义场景发散 `D(s_c, s_e)`（时间×物体速度、重叠区 ICP/Chamfer、物体身份/位姿变化、标定漂移），把云端证书按 `m' = m − L_s·D` 传输到边缘；`m' < 0` 即拒绝。关键反直觉点：**v17 的 TTL 只是发散的一个分量**；重放攻击不过是 `D → ∞` 的极端情形。时间不是新鲜度的本质，**状态一致性**才是。

**三者如何统一**
统一为 **v17 语言层之上的云端抓取层**：v17 回答"哪些语言计划能被安全编译并调度"，v18 回答"在云端给出的抓取位姿分布中，边缘此刻能安全执行哪一个抓取，以及它如何作为计划的一个缝被组合进 v17"。共享状态 `ζ_ce = (epoch, scene_id, δ, net, D, q̂_grasp, mem_index, mode_ce)`。CPQ 是传输侧（压缩 + 证书外推），GCL 是认证侧（四分量格 + 盆地），CDV 是一致性侧（发散界 + 传输），CMR 是排序侧（盆地体积），ACR 是协议侧（乱序/丢包/重放/幂等），CFA 是退化侧（云失效→边缘自持→v17）。**云端提议"抓哪里"，CPQ 决定"能传多少"，GCL 决定"哪些被认证"，CDV 决定"证书还能不能信"，CMR 决定"先抓哪个"，ACR 决定"这条消息算不算数"，CFA 决定"云没了怎么办"**。

## 1. 研究问题（轮次升级版）

- **Q1（证书压缩率）**：δ-网大小随 δ 如何增长？在 `SE(3)/Sym` 上能否用任务子流形降维？δ 如何随链路带宽/时延自适应？证书 Lipschitz 界如何得到**可证明且不过保守**的值（Lipschitz 网络 / 区间界 / 随机平滑）？覆盖率与余量折减如何联合标定？
- **Q2（抓取证书格的量纲与可组合性）**：FC（牛顿/力）、CF（米）、PU（概率）、SC（状态集体积）量纲不同，如何归一化为可比余量？格的 meet 是否过保守？抓取作为计划缝时，SC 与 v17 的 `SC_i` 如何求交而不双重计数？
- **Q3（发散界与证书传输）**：`D(s_c,s_e)` 在遮挡下可观测吗？不可观测的发散如何用保守上界（物体最大速度、可达空间）兜底？`L_s` 如何估计？发散触发**重投影**还是**直接拒绝**？发散与 TTL 如何统一？
- **Q4（协议与退化）**：乱序/重复/部分消息下如何保证 at-most-once 与幂等？epoch 漂移、重放、拜占庭云端如何只损活性？云边同时规划时如何确定性仲裁？δ-网分片丢失时如何安全降级？

## 2. 设计原则（在 P28–P30 基础上新增 P31–P33）

**P31 证书不可外包律（No Certificate Outsourcing）**
边缘对每个抓取计算最终证书 `cert_final(g) = min( cert_edge(g), max_j[m_j − L_j·d(g,g_j)] − L_s·D )`，其中 `cert_edge` 由边缘本地模型给出（CF 本地必算；FC 用本地保守模型或云端值经发散折减后的下界；PU 用边缘传感器；SC 用 v17 PSV）。**云端只能提供候选与证据，永远不能提供最终授权**。任何云端字段都按"上界再折减"使用，不得直接作为 `cert_final`。

**P32 抓取即计划缝律（Grasp is a Plan Seam）**
抓取 `g` 只有在 `B(g) ∩ SC_i ≠ ∅ ∧ cert_G(g) ≥ 0` 时才能接在 v17 计划的第 `i` 个缝上，其中 `B(g)={g': d(g,g')<m_g/L_g}` 是认证盆地，`SC_i` 是 v17 缝证书。抓取不是计划的"附属动作"，而是**计划的一个缝**：接近节点的 Post、抓取的前置、抓取的后置、搬运节点的 Pre 必须同时被覆盖；求交为空即该抓取不可组合，退回上一个已认证节点。

**P33 发散单调律（Divergence Monotonicity）**
可执行抓取集 `G_exec` 关于场景发散 `D` 单调不增：`D1 ≤ D2 ⇒ G_exec(D2) ⊆ G_exec(D1)`。发散只能通过 `m − L_s·D` 折减余量或触发拒绝，**不得**通过任何"补偿/平滑/重打分"恢复证书。重放、超时、丢包、乱序都归约为 `D` 的增大或消息无效，而不是新的授权通道。

## 3. 与基线的接口（如何退化）

- CPQ 失效（云端不传 δ-网）⇒ 边缘只用本地抓取估计（EDGE_ONLY）——**等价 v17 路径**；
- GCL 失效（某分量不可算）⇒ 该分量取 0（最保守），仍只减不增；
- CDV 失效（发散不可估）⇒ 取 `D=∞`，拒绝所有云端抓取，退 EDGE_ONLY；
- CMR 失效 ⇒ 不排序，按到达顺序执行认证集内抓取——**等价 v17**；
- ACR 失效 ⇒ 只接受当前 epoch 的完整消息，其余丢弃——**等价更保守**；
- CFA 失效 ⇒ 直接 v17 默认；
- 六者全失效 ⇒ MetricVoiceGauge-NCD-HUTDH-v17，再沿 v17→v16→…→v6 退化链退回；
- **安全继承**：CPQ 只外推下界，GCL 只求交，CDV 只折减，CMR 只重排，ACR 只丢弃，CFA 只降级。六端口互不相交，均不能新增授权或放宽任何阈值；`Exec_v18⊆Exec_v17` 由引理 146/147 保证。

## 4. 预期贡献

1. **证书保持压缩**：首次把"云端抓取分布→边缘执行"改写为"δ-网 + 证书 Lipschitz 外推"，证明压缩误差只折减余量、不新增不安全，给出带宽-安全权衡的可证明边界；
2. **抓取证书格**：把力闭合、无碰撞可达、感知不确定度、计划缝相容统一为乘积格，用认证盆地体积替代置信度排序，使"抓取位姿估计"从打分问题升级为认证问题；
3. **云边发散证书**：把 TTL 泛化为场景发散界，使超时/遮挡/运动/重放统一为 `D`，给出证书传输定理与单调退化；
4. **抓取即计划缝**：把抓取嵌入 v17 PSV 的缝语义，使抓取安全与语言计划安全可组合，关闭"节点都有证书、抓取这一关节没有证书"的缺口；
5. **协议级鲁棒**：ACR 的幂等/at-most-once/epoch 机制使乱序、重复、拜占庭云端只损活性；
6. **云边单调退化**：用 `Exec_v18⊆Exec_v17⊆Exec_v16` 把云端抓取、语言计划、行为执行、路线、动力学、实时全解耦；E711–E730 覆盖压缩、发散、拜占庭、带宽、时延与端到端。

## 5. 本轮最大风险

**一句话**：证书的 Lipschitz 界与场景发散界都是"估计出来的界"，而云端的价值恰恰在边缘看不清、发散最大的场景（遮挡、运动、新物体）里最大——发散界一旦低估，证书传输就会在**最需要它的地方**系统性失效：云端在边缘最不确定时给出的抓取，恰是传输误差最大、最可能被错误认证的抓取。

# IP-415 Certificate-Preserving Quantizer：证书保持的 δ-网压缩
class CertificatePreservingQuantizer:
    def __init__(self, cert_fn, lipschitz_fn, sym_group):
        self.cert = cert_fn            # cert_G(g, s) -> margin
        self.L = lipschitz_fn          # 每个分量的 Lipschitz 上界
        self.sym = sym_group           # 商掉夹爪对称

    def build_net(self, dist, s_c, delta):
        anchors, cover = [], CoveringSE3(delta, self.sym)
        for g in dist.sample_stream():          # 云端大模型采样
            if not cover.add(g):                # 已在 δ-邻域内：跳过
                continue
            m = self.cert(g, s_c)
            if m < 0:
                continue                        # 云端自身都不认证
            anchors.append(Anchor(g=g, m=m, L=self.L(g), prior=dist.prior(g)))
        return CertSketch(epoch=..., scene_id=..., t=now(),
                          delta=delta, anchors=anchors)

    def transport(self, sketch, g):
        best = None
        for a in sketch.anchors:
            lb = a.m - a.L * distance(g, a.g, self.sym)
            if best is None or lb > best:
                best = lb
        return best                             # None => 无覆盖，拒绝


# IP-416 Grasp Certificate Lattice：四分量乘积格
class GraspCertificateLattice:
    def __init__(self, fc, cf, pu, psv, norm):
        self.fc, self.cf, self.pu, self.psv = fc, cf, pu, psv
        self.norm = norm                       # 各分量归一化到无量纲余量

    def components(self, g, s, plan, i):
        return {
            'FC': self.norm.fc(self.fc.margin(g, s)),
            'CF': self.norm.cf(self.cf.margin(g, s)),
            'PU': self.norm.pu(self.pu.lower_bound(g, s)),
            'SC': self.norm.sc(self.psv.seam_margin(plan, i, g)),
        }

    def cert(self, g, s, plan, i):
        c = self.components(g, s, plan, i)
        return min(c.values()), c              # meet = 逐分量最小

    def basin_volume(self, g, s, plan, i, r_max):
        m, _ = self.cert(g, s, plan, i)
        L = self.norm.max_lipschitz(g)
        r = min(r_max, max(0.0, m / max(L, 1e-9)))
        return ball_volume(r)                  # 认证盆地体积


# IP-417 Cloud-Edge Divergence Verifier：场景发散与证书传输
class CloudEdgeDivergenceVerifier:
    def __init__(self, motion_bound, icp, calib_bound, semantic):
        self.vmax, self.icp = motion_bound, icp
        self.calib, self.sem = calib_bound, semantic

    def divergence(self, s_c, s_e, dt):
        d_time = self.vmax * abs(dt)                 # 物体运动上界
        d_geo = self.icp.overlap_residual(s_c, s_e)  # 重叠区几何残差
        d_sem = self.sem.change(s_c, s_e)            # 身份/位姿变化
        return d_time + d_geo + d_sem + self.calib

    def transport_margin(self, m, L_scene, D):
        return m - L_scene * D                       # <=0 => 拒绝

    def verify(self, sketch, s_e, now):
        if sketch.epoch < current_epoch():           # 重放/过期
            return None, float('inf')
        D = self.divergence(sketch.scene, s_e, now - sketch.t)
        return D, [(a, self.transport_margin(a.m, L_scene(a), D))
                   for a in sketch.anchors]


# IP-418 Certificate-Margin Ranker：盆地体积排序（只重排）
class CertificateMarginRanker:
    def __init__(self, gcl, amc):
        self.gcl, self.amc = gcl, amc

    def rank(self, cands, s_e, plan, i, D, L_scene, r_max):
        scored = []
        for g, cloud_lb in cands:
            m_cloud = cloud_lb - L_scene * D
            m_local, comp = self.gcl.cert(g, s_e, plan, i)
            m_final = min(m_cloud, m_local)          # P31：证书不可外包
            if m_final < 0:
                continue                             # 未认证：移除
            vol = self.gcl.basin_volume(g, s_e, plan, i, r_max)
            prior = self.amc.success_prior().score(g)  # 只重排（v17 引理 141）
            scored.append((vol * prior, g, m_final, comp))
        return sorted(scored, key=lambda x: (-x[0], hash(x[1])))


# IP-419 Asynchronous Certificate Reconciler：幂等 / at-most-once
class AsynchronousCertificateReconciler:
    def __init__(self):
        self.epoch = -1
        self.seen = set()
        self.partial = {}

    def ingest(self, msg):
        if msg.id in self.seen:
            return None                         # 重复：幂等丢弃
        self.seen.add(msg.id)
        if msg.epoch < self.epoch:
            return None                         # 旧纪元：重放，拒绝
        if msg.epoch > self.epoch:
            self.epoch = msg.epoch
            self.partial.clear()                # 新纪元：旧分片作废
        if msg.complete:
            return msg.sketch
        self.partial[msg.id] = msg              # 分片：仅缓存，永不授权
        return None


# IP-420 Cloud Failure Attenuator：单调降级
class CloudFailureAttenuator:
    LEVELS = ['CLOUD_FULL', 'CLOUD_COARSE', 'EDGE_ONLY', 'V17', 'V16']

    def __init__(self, link, edge_estimator):

## 3. 推导

**引理 143（证书保持压缩）** 设 `cert_G(·,s)` 关于商度量 `d` 为 `L`-Lipschitz，CPQ 发送的 δ-网满足覆盖 `∀g∈supp, ∃a_j: d(g,a_j) ≤ δ` 且 `a_j.m = cert_G(a_j,s)`, `a_j.L ≥ L`。则对任意 `g`，
`cert_G(g,s) ≥ max_j [a_j.m − a_j.L·d(g,a_j)] ≥ a_{j*}.m − L·δ`。
若 `δ ≤ min_j a_j.m/L_j`，则整个 δ-网邻域内证书非负。证明：由 Lipschitz 定义 `cert_G(g) ≥ cert_G(a_j) − L·d(g,a_j)`，再对覆盖点取最大；覆盖性保证 `j*` 存在。∎ 推论：**量化误差只记在余量账上，不记在安全账上**；δ-网规模 `N(δ)=O((diam/δ)^6)`，商掉并行夹爪 π 对称后约减半，吸盘连续对称可再降维。

**引理 144（发散传输）** 设 `cert_G(g,·)` 关于场景状态 `s` 为 `L_s`-Lipschitz。若 `D(s_c,s_e) ≤ ε`，则 `|cert_G(g,s_c) − cert_G(g,s_e)| ≤ L_s·ε`，故 `cert_G(g,s_e) ≥ m − L_s·ε`；`m − L_s·ε < 0` 时无法认证。证明：Lipschitz 与三角不等式直接得；`D` 单调则下界单调递减。∎ 推论：**陈旧/对抗云端只能收缩可执行集**；重放是 `s_c` 属于旧纪元、`D` 取 `v_max·Δt` 或直接 `∞` 的极端情形，由引理 150 的 epoch 规则拒绝。

**引理 145（抓取-计划可组合）** 设 v17 计划 `π` 在第 `i` 缝的缝证书 `SC_i = Post_{n_i} ∩ Pre_{n_{i+1}}`，抓取 `g` 的认证盆地 `B(g)`。若 `B(g) ∩ SC_i ≠ ∅ ∧ cert_G(g) ≥ 0`，则经过该缝的状态轨迹被 `NC_{n_i} ∪ SC_i ∪ NC_{n_{i+1}} ∪ B(g)` 覆盖，抓取转移不越出已认证集合；若交集为空，必须**拒绝**该抓取而非降序，否则计划与抓取之间的关节无证书。证明：v17 引理 139 覆盖节点与计划缝；`B(g)` 覆盖抓取盆地；交集非空提供连接状态，执行路径落在并集内。∎ 推论：**抓取安全 = 计划安全 ∧ 盆地安全**，抓取是缝的参与者，不是外挂动作。

**引理 146（云边单调退化）** CFA 各级只做三类操作：移除候选源、增大 δ（经引理 143 以 `Lδ` 降低余量）、或令 `D=∞`；三者均不新增候选、不提高余量。ACR 只丢弃，CMR 只重排，GCL 只求交，CDV 只折减，CPQ 只外推下界。故
`G_exec(CLOUD_FULL) ⊇ G_exec(CLOUD_COARSE) ⊇ G_exec(EDGE_ONLY) ⊇ G_exec(V17) ⊇ G_exec(V16)`，
且 `Exec_v18 ⊆ Exec_v17`。证明：每个算子对候选集与余量单调非增，复合保持单调。∎

**引理 147（证书不可外包 / 拜占庭云端）** 对任意云端消息（含恶意），边缘最终证书 `cert_final(g) = min(cert_edge(g), max_j[a_j.m − a_j.L·d] − L_s·D)`。由引理 143/144，云端项是真实证书的**上界再折减**；`cert_edge` 由边缘独立计算。故 `cert_final(g) ≤ cert_edge(g)`，云端无法把证书抬到边缘本地可验证之上。新增授权基数 `|NewAuth|=0`。证明：`min` 与本地上界复合；恶意云端只能降低或错置候选，错置者在本地 `CF/PU/SC` 检查处失败。∎ 推论：**拜占庭云端的最坏后果是"抓不到"，不是"抓错"**。

**引理 148（带宽-时延解耦）** 证书草图规模 `S(δ)=O(N(δ)·c)=O((diam/δ)^6·c)`，与云端模型规模 `M` 无关；边缘每次抓取事件的工作量 `O(S(δ))`，不在 50Hz 控制节拍内；渐进细化（先粗后细）给出 anytime 证书界。故边缘控制 `p99` 与云端 `p99`、带宽解耦，仅异步抓取事件路径受其影响。证明：δ-网只依赖 δ 与度量，重建为线性扫描，控制环读取缓存 `g_star`。∎

**引理 149（盆地排序安全）** CMR 输出是认证集 `C={g: cert_final(g) ≥ 0}` 的一个排列；从排序结果中任选一个仍在 `C` 内，故不安全率不变，仅成功率/鲁棒性次序改变。AMC 先验只重排（v17 引理 141），不扩集。证明：排序是双射，选择不改变集合成员关系。∎

**引理 150（调和幂等与 at-most-once）** ACR 以 `msg.id` 去重、以 `epoch` 单调拒绝旧消息、分片消息永不授权。则任意乱序/重复/重放/分片序列至多授权一次，且过期纪元不能授权。证明：`seen` 集合保证 id 至多处理一次；`epoch` 单调保证旧纪元被拒；`partial` 分支不返回草图，故无授权路径。∎ 推论：**网络层攻击（重放/乱序/丢包）全部归约为活性损失**，与 P33 一致。

## 7. 已知风险与失效模式

1. **Lipschitz 界过松**：`L` 取保守上界会使 `Lδ` 折减过大，δ-网整体退化不可用。缓解：按分量独立估 `L`、Lipschitz 网络/区间界、在线校准 `L`。
2. **发散界低估**：遮挡下物体运动不可观测，`D` 被低估，传输余量虚高。缓解：用 `v_max·Δt` 作不可观测兜底、OOD/遮挡检测触发 `D=∞`、拒绝优先。
3. **本地 FC 模型过保守**：边缘无法复算精确力闭合，只能保守近似，导致 EDGE_ONLY 长期退化。缓解：云端提供接触模型证据但仍由本地折减、周期抽检、证书族共享。
4. **δ-网维数灾难**：6 维 `N(δ)` 随 δ 指数增长，带宽爆炸。缓解：任务子流形降维、对称商、渐进细化、按需细化。
5. **对称群误设**：把不等价位姿商掉会漏抓，商得不够会浪费带宽。缓解：按夹爪类型配置 `Sym`、离线验证等价类。
6. **发散分量量纲不可加**：`v_max·Δt`（米）与 `Δsem`（语义）直接相加无意义。缓解：各分量归一到同一状态度量、用最大值或加权范数。
7. **epoch/时钟漂移**：边缘与云端时钟不同步，`epoch` 误判导致接受过期或拒绝有效。缓解：逻辑时钟、单调计数、消息签名与 TTL 双保险。
8. **分片 δ-网永久不完整**：链路长期丢分片，`partial_net` 永不授权，活性塌缩。缓解：分片重传、渐进细化允许粗网先用、CFA 降级。
9. **边缘算力争用**：CPQ 外推/GCL/CMR 与 50Hz 控制争 CPU，影响实时。缓解：抓取事件异步化、预算上限、隔离核。
10. **证书 ≠ 任务成功**：力闭合与无碰撞不保证物体不滑、不变形、不遮挡后续。缓解：把滑移/变形纳入 FC 保守模型、任务级证书链、失败回写 AMC。
11. **多物体杂波**：`D` 应按物体邻域而非全场景估计，否则被无关运动污染。缓解：物体中心化发散、按实例跟踪。
12. **仿真到现实证书鸿沟**：仿真中估的 `L` 与 `FC` 在现实中偏移。缓解：实机标定、域随机化、在线残差监控。

## 8. 本轮最大风险

**一句话**：证书的 Lipschitz 界与场景发散界都是"估计出来的界"，而云端的价值恰恰在边缘看不清、发散最大的场景（遮挡、运动、新物体）里最大——发散界一旦低估，证书传输就会在**最需要它的地方**系统性失效：云端在边缘最不确定时给出的抓取，恰是传输误差最大、最可能被错误认证的抓取。
