# 第 41 轮 · 双通道实证接地 v18：碰撞检测即硬标签 × 标注溯源类型 × 保形证书校准（四层架构 v6）

> 承接第 40 轮（v17：可认证流匹配执行 × 度量语义几何锚定 × 证书驱动课程引擎，四层架构 v5）。本轮灵感词「数据标注、碰撞检测」驱动的不是再加一层机制，而是正面攻击第 40 轮自己承认的命门——**证书紧致性/装饰性**。思路：把「碰撞检测」当作免费、物理可靠、可连续的**硬标签源**，把「人工标注」当作昂贵、可溯源、带噪声的**软标签源**，再用**保形（conformal）校准**把两条证据通道熔成有有限样本覆盖保证的证书。证书从「解析推导的黑箱承诺」第一次获得**可测的实证覆盖率**。

## 0. 直觉与动机

**灵感 1（碰撞检测 → 免费且可靠的硬标签）**：机器人每个 rollout 都天然产生「接触 / 未接触」事件流，这比人工标注便宜无数倍，而且**无法伪造**——物理接触是真的。更关键的是它对应证书里最核心的那个谓词：安全（h_min ≥ 0）。但朴素离散碰撞检测有两个致命错：a) **隧穿（tunneling）**——高速或薄壁下相邻采样步之间发生穿透被漏检；b) **状态不确定性**——真值位姿在漂移球 B_t 内，点检测不代表整球安全。于是本轮不直接用现成碰撞库，而是构造**保守连续碰撞检测（conservative CCD）**：把机器人包络沿运动原语扫掠、按 B_t 膨胀、未知空间一律视为占据，用 conservative advancement 推进到接触或到达目标。这样得到的 SAFE/CONTACT 是**对认证障碍集声学（sound）的布尔 oracle**——允许保守误报，但**不允许漏报**。这是「免费硬标签」能当校准金标准的前提。

**灵感 2（数据标注 → 带 provenance 的软标签与预算分配）**：人工标注能提供碰撞检测给不出的语义谓词（「这是可抓取的把手」「这是人」「这句话的指代对象」），但它昂贵、有标注者偏差、有时效性。第 40 轮的 C_ms=(φ_sem,B) 只记了「谓词 + 几何球」，**没有任何关于标签从哪来、谁会错、错多少的记账**。本轮把标注升格为一等公民：每条证据 a=(ℓ, φ, κ_annot, σ_noise, t) 带标注者/协议 provenance 与噪声模型 σ，语义类型变成**带证据支持的判断**；并且标注不是均匀撒钱，而是**主动标注**——只在「证书处于判定边界、系统自己拿不准」的样本上花钱（不确定性采样 × 证书歧义值），把有限标注预算对准证书最脆弱的接缝。

**灵感 3（二者对偶 → 保形校准把证据变覆盖率）**：碰撞检测标「物理是否发生」，人工标注标「语义是什么」，两者是同一真值的两条**互补且有噪测量通道**。而「解析证书到底准不准」本身是一个统计问题，正好是保形预测（conformal prediction）的用武之地：把证书的余量取成非一致性分数 S(x)，用一条**已经过碰撞 oracle / 标注核验的校准集**取分位数 q̂，就得到**分布无关、有限样本**的覆盖保证：Cert_α(x) ⟺ S(x) ≤ q̂ ⟹ 认证样本的违约率 ≤ α（在可交换性下）。非平稳（策略在学、分布在漂）时用自适应保形 ACI 在线调 α_t，天然接上第 40 轮课程引擎的「非平稳移动目标」。至此三块咬合：**CCD 造标签 → 主动标注补语义 → 保形校准给覆盖率**，证书从「文档」变成「有统计口径的测量仪器」。

**三灵感的耦合与对第 40 轮风险的正面回应**：第 40 轮说「若 L_v/κ/漂移界比真值松 10~100 倍，一切沦为装饰」。本轮的答案不是「把界算得更紧」（那是硬骨头且可能算不动），而是「**承认界会松，但用实证覆盖把它校正到标称水平**」——解析界给方向与形状，保形给尺度与置信，碰撞检测给免费真值，标注给语义真值。证书体系由此获得「自测」能力。

## 1. 形式化定义

**定义 27（带溯源的标注证据）**：一条标注证据 a = (ℓ, φ, κ, σ, t)，ℓ 为标签值，φ 为其所标注的谓词（点云/图像区域 + 语义槽），κ 为标注者与协议标识（provenance），σ 为标签噪声模型（如 P(ℓ | truth) 的混淆矩阵或 Beta 后验），t 为时间戳。带标注的语义类型 C_ann = (φ_sem, {a_i})，其判断带支持度 Supp(φ) = f({a_i}, σ)，只有当多条独立证据一致且后验超过阈值 τ_sup 时 φ 才「成立」。provenance 传播规则：由 a 推出的下游类型继承最弱一环的 κ 与 σ（污染不可被后续推断洗白）。

**定义 28（保守连续碰撞 oracle）**：给定相邻构型/位姿 (x_t, x_{t+1})、漂移球 B_t、占据地图 M：O_ccd(x_t, x_{t+1}, B_t, M) ∈ {SAFE, CONTACT}。做法：以机器人几何包络扫掠出 swept volume，按 B_t 闵可夫斯基膨胀，未知/未观测空间视为占据；用 conservative advancement 在运动上推进直到最小距离 ≤ 0（CONTACT）或走完全程（SAFE）。**声学性（soundness）**：若真实接触在认证障碍集意义下不发生，则 O_ccd 不以概率 > δ 报 SAFE 之外；等价地，**漏报（false negative：真实接触却报 SAFE）概率 ≤ δ**。误报（保守 SAFE→CONTACT）允许，作为安全侧代价。硬标签 y = 1[CONTACT]。

**定义 29（保形证书与覆盖率）**：定义非一致性分数 S(x) = −m̂(x)，m̂ 为证书预测的安全余量（可由 h_min、B_t、ε_ode 组合）。给定校准集 D_cal = {(x_i, y_i)}，y_i 来自 O_ccd 的硬标签（语义谓词则来自核验过的标注），取 q̂ = Quantile_{⌈(n+1)(1−α)⌉/n}({S(x_i): y_i=SAFE})。定义 Certified_α(x) ⟺ S(x) ≤ q̂ ∧ ValidRegion(x)。**校准定理（split conformal）**：若 D_cal 与测试样本可交换，则 P(测试真实安全 | Certified_α) ≥ 1−α。非平稳下用 ACI：α_{t+1} = α_t + γ(α − err_t)，err_t = 1[被认证却发生违约]，长期违约率收敛到 α。**证书包 CertBundle 升级为 (解析界, q̂, α_t, 覆盖率统计)**。

**定义 30（双通道融合与主动标注预算）**：物理通道 D_phys（O_ccd，廉价、连续、只标接触谓词）与语义通道 D_sem（人工，昂贵、标非接触语义谓词、带 σ）。融合用证据似然：P(violation | x) ∝ P_phys(y | x) · ∏_i P_sem(a_i | x)。主动标注选择规则：在预算 B_ann 下选 x* = argmax_x H(predicate | x) · Amb(x)，Amb(x) = |S(x) − q̂| 的边界接近度（证书越接近判据、标注越值钱）；用子模最大化贪心保证 (1−1/e) 近似覆盖增益。

## 2. 三大产出设计

### 2.1 IP-51 COLLISION-ORACLE-CCD（连续、保守、含不确定性的碰撞 oracle）
1. 几何：机器人自碰撞 + 环境碰撞统一到 swept-volume 查询，凸包分解 + BVH，薄壁/高速走 conservative advancement 而非离散步进。
2. 不确定性：按 B_t 做体膨胀；未知空间按占据处理（安全侧保守）。
3. 输出：接触事件流（时间、部位、法向、冲量代理）+ 每次 rollout 的 SAFE/CONTACT 硬标签，直接进校准集 D_cal。
4. 自检：对每个接触事件回放细粒度验证，量测漏报率，E73 守门。

### 2.2 IP-52 ANNOTATION-PROVENANCE-TYPING（带溯源与噪声模型的主动标注）
1. 每条标注带 provenance（标注者/协议/工具版本）与噪声模型 σ（混淆矩阵或 Beta 后验）。
2. 语义类型 C_ann 带支持度；provenance 单调传染——下游类型继承最弱证据。
3. 主动标注：按证书歧义 Amb(x) × 不确定性做子模贪心选样，只标判据附近样本；标注后回灌校准集与语义图。
4. 与 IP-50 课程联动：标注预算按证书赤字 D(τ) 分配，赤字高且歧义大的任务优先。

### 2.3 IP-53 CONFORMAL-CERT-CALIBRATION（保形证书校准与双通道融合）
1. 分数构造：S(x) = −m̂(x)，m̂ 融合解析余量（h_min、B_t、ε_ode、κ 收缩项）。
2. 校准：split conformal 给 q̂；非平稳用 ACI 在线更新 α_t；漂移检测触发布新校准集。
3. 双通道融合：物理硬标签 + 语义软标签的贝叶斯证据融合，覆盖语义谓词的违约。
4. 组合安全：k 个技能组合时按 α/k（Bonferroni）或组件级联合校准，避免覆盖率的并集失效。
5. 输出覆盖率仪表盘：实测违约率 vs 标称 α，成为总线的物理级熔断依据（出区或覆盖率破线即熔断）。

## 5. 本轮最大风险

**一句话**：整套实证接地都建立在「碰撞 oracle 声学」这一根钉子上——只要 CCD 在薄壁/高速/未知空间出现哪怕极低概率的漏报，保形校准就是拿错标签自我安慰，覆盖率保证会系统性失真，证书将比第 40 轮的解析界更具欺骗性，因此 E73 必须是不可让路的第一守门实验。

## 2. 关键算法

### IP-51 保守连续碰撞 oracle（伪代码）
```
def o_ccd(x_t, x_next, B_t, map_M, delta):
    robot = inflate(geometry_envelope, B_t)          # 漂移球体膨胀
    occ   = map_M.occupied | map_M.unknown           # 未知按占据（安全侧）
    swept = swept_volume(robot, x_t, x_next)
    d = conservative_advance(swept, occ)             # 推进到接触或走完全程
    verdict = CONTACT if d <= 0 else SAFE
    return verdict, contact_event(verdict, d)        # 事件流进校准集

def assert_soundness(oracle, adversarial_set):       # E73 守门
    fn = count(truth_contact and oracle == SAFE)
    assert fn == 0                                  # 无漏报才允许做校准标签
```

### IP-52 带溯源主动标注（伪代码）
```
def supported_type(pred, evidences, tau_sup):
    support = posterior(pred, evidences)             # 融合 σ 噪声模型
    weakest = min(evidences, key=lambda a: a.kappa.trust)
    return C_ann(pred, support, provenance=weakest.kappa) if support >= tau_sup else UNKNOWN

def active_annotate(cert, pool, budget, ann_ctx):
    gain = lambda x: H(pred | x) * Amb(x)            # 歧义×不确定
    chosen = submodular_greedy(pool, gain, budget)   # (1-1/e) 近似
    return [ann_ctx.label(x) for x in chosen]        # 回灌校准集+语义图
```

### IP-53 保形证书校准（伪代码）
```
def split_conformal(D_cal, alpha):
    scores = [(-margin(x), y) for x, y in D_cal]
    q_hat = quantile([S for S, y in scores if y == SAFE],
                     ceil((len(D_cal)+1)*(1-alpha))/len(D_cal))
    return q_hat

def certified(x, q_hat, valid_region):
    return S(x) <= q_hat and valid_region(x)

def aci_update(alpha_t, err_t, gamma, alpha):
    return alpha_t + gamma * (alpha - err_t)          # 长期违约率→α

def compose_coverage(alpha, k):
    return alpha / k                                  # Bonferroni，保 family-wise
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 正确性保证 |
|---|---|---|
| IP-51 CCD | 每原语 O(log N_bvh · A)（A 为推进步数），保守可中止 | **声学**：漏报率 ≤δ（未知按占据 + B_t 膨胀） |
| IP-51 事件流 | O(1)/事件 | 接触样本直接进 D_cal，零人工成本 |
| IP-52 主动标注 | 子模贪心 O(B_ann·|pool|) | (1−1/e) 近似最大覆盖增益 |
| IP-52 支持度 | O(#evidence) | provenance 单调传染，污染可追溯 |
| IP-53 split conformal | 校准 O(n log n)，推理 O(1) | **定理**：可交换下 P(安全\|Certified_α)≥1−α |
| IP-53 ACI | O(1)/步 | 长期违约率 → α（非平稳） |
| IP-53 组合覆盖 | O(k) | Bonferroni/联合校准保 family-wise ≥1−α |
| 端到端 | 校准集随证书版本滚动 | 解析界给形状、保形给尺度，覆盖可测 |

## 4. 实验设计（E73-E78，硬门槛）

| 实验 | 指标 | 门槛 |
|---|---|---|
| E73 CCD 声学性 | 对抗性薄壁/高速/退化场景漏报率（细粒度回放核对） | 漏报率 = 0（或 ≤δ=1e-3），第一守门 |
| E74 保形覆盖 | 实测违约率 vs 标称 α（含分布漂移） | \|实测−α\|≤0.5%，覆盖≥1−α |
| E75 标注效率 | 达同等谓词 F1 所需标注量 vs 均匀标注 | 节省≥40% |
| E76 双通道融合 | 违约预测 AUROC vs 单通道 | 提升≥5 个点 |
| E77 组合覆盖 | k 技能组合端到端违约率 vs 组件和 | 不劣化 |
| E78 有效域非空 | ValidRegion 非空率 + 覆盖率达标率 | ≥90% 场景区域非空且达标 |

失败即回退：E73 不达标 → 校准集不可信，回退 v17 解析证书，保形仅作离线诊断；E74 不达标 → 放弃边际覆盖宣称，改用保守 α 与人工抽检。

## 5. 风险与缓解

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| CCD 漏报（薄壁/高速/退化）使校准标签失真 | 高 | unknown 按占据、B_t 膨胀、conservative advancement；E73 第一守门并回放核对 |
| 可交换性不成立 → 覆盖保证失效 | 高 | ACI 在线调 α_t + 漂移检测重建校准集；按场景分层校准 |
| 标注噪声模型 σ 误设 → 支持度虚高 | 中 | 混淆矩阵用重复标注/金标抽检估计；provenance 惩罚不可靠来源 |
| 主动标注长期只标边界 → 分布外盲区 | 中 | 保留 ε-均匀探索配额 + 课程赤字加权 |
| 组合 Bonferroni 过保守 → 有效域缩水 | 中 | 组件级联合校准替代 α/k；必要时按依赖结构放缩 |
| 校准集与在线策略不同分布（旧标签校新策略） | 高 | 校准集版本绑定证书版本，热更新时强制重校 |
| CCD 计算开销拖慢实时 | 中 | BVH + 凸包 + 原语级缓存；与 IP-48 流式块对齐增量校验 |

## 6. 本轮最大风险

**一句话**：整套实证接地都建立在「碰撞 oracle 声学」这一根钉子上——只要 CCD 在薄壁/高速/未知空间出现哪怕极低概率的漏报，保形校准就是拿错标签自我安慰，覆盖率保证会系统性失真，证书将比第 40 轮的解析界更具欺骗性，故 E73 必须是不可让路的第一守门实验。
