# 第 4 轮（新灵感循环第 1 轮；本轮灵感：「数据标注」×「语音识别」）

> **基线**：第 3 轮 InstructGauge（IP-321–327；定义 432–447；引理 51–58；实验 E441–E456）。第 2 轮 ToolGauge、第 1 轮 LeanGauge / MODGAUGE 骨架继续继承不变。
> 本轮纪律：**增量升级 + 严格退化**。语音与标注各沿一条新轴增强 InstructGauge；任一环节不可用都必须能退回文本指令 / 全局校准 / ToolGauge / LeanGauge / MODGAUGE。

## 0. 直觉与动机

**灵感 1（语音识别：不要把 1-best 文本当成指令，要把「听错」建模成一族可能指令）**
直觉：第 3 轮把自然语言指令当成已经写好的文本 ℓ，这是实验室假设。真实接口是麦克风：同音词、数字/单位、否定词、指代和条件触发都可能被听错，而且错误高度集中——「5 毫米」听成「0.5 毫米」、「不要加热」听成「要加热」远比随机词错危险。正确的对象不是一条转写，而是**类型化指令上的后验分布** `p(ι|x)`；ASR 的 n-best 与置信度必须一路传到接地层，而不是在门口被 argmax 掉。关键结构是：**尾部质量显式归入 ⊥**、**关键槽位单独验证/读回**、**只有稳定且验证过的话语才提交**。

**灵感 2（数据标注：标注不是真值，是带来源、带可靠度的人类证据）**
直觉：校准集里的标签也是人给的，会错、会偏、会被标注规范误导；主动挑样本标注还会改变校准分布。把标注当 ground truth，会把「标注者一致」误当成「物理正确」。正确口径是：**标注规范即类型系统**（与运行时共享本体/工具/物理包线），**标注记录带来源图**（谁、何时、哪版 schema、是否仲裁），**标注者可靠度用混淆矩阵/金标估计**，**主动选择必须记录倾向并用加权共形校正**。标注能改善先验与校准，但**不能给安全关键槽位发许可证**。

**灵感 3（两者耦合：两条有损的人类通道 + 两个提交点）**
直觉：说话人→ASR 和标注者→标签，是两条关于「意图」的有损通道；它们都不直接观测「执行结果」。最危险的耦合不是 WER 或标签噪声本身，而是**虚假置信**：标注者高度一致、ASR 文本很流畅，于是系统对一句其实没验证过关键槽位的指令产生高置信，再让动作分块把它原子性地执行 K 步。再加上流式 ASR 的 partial 与动作块的提交点如果不分开，半句话就可能进入执行器。解法是三根结构支柱：**证据分层**（意图证据 ≠ 动作证据）、**双提交屏障**（话语提交先于动作提交）、**标注即类型与来源**（schema 闭包 + 选择偏差校正）。

## 1. 研究问题（本轮要回答什么）

- **Q1（语音的安全性）**：如何把 ASR 的 n-best 不确定性传播到类型化指令，而不让假设空间爆炸、也不让不安全指令获得正质量？关键槽位验证与读回能否给出可审计的保守错误界？
- **Q2（标注的可校准性）**：在标签有噪声、且标注样本被主动选择的情况下，共形校准还能否保持分层覆盖？可靠度模型缺少金标锚点时，哪些结论是**不可识别**的？
- **Q3（耦合的边界）**：标注证据能否让语音接口更安全？在什么意义上「不能」——能否形式化「标注只约束意图、不认证执行」这一分离，并把端到端风险分解为可检验的四个分量？

## 2. 三条设计原则（雏形，正式化见产物区定义 448–462）

**P4 证据分层（Evidential Layering）**
ASR 后验与标注后验都是**意图证据**；只有回执、读回确认、CVC/Barrier 通过才是**动作证据**。任何不可逆动作的授权不得由意图证据单独完成。形式化方向：动作提交谓词只引用 `receipts/ChunkCert/CSV`，标注量只进入先验与校准阈值。

**P5 双提交屏障（Dual Commit Barrier）**
话语提交 `τ_utt`（端点 + 后验稳定 + 关键槽位验证）必须先于动作块提交；流式 partial 只能更新后验，不能驱动执行器。形式化方向：`Commit_act(C,t) ⇒ τ_utt<t ∧ CVC ∧ Barrier`，并把证据陈旧上界写成 `K+Δ_c`。

**P6 标注即类型与来源（Annotation as Type & Provenance）**
标注规范编译为与运行时同源的类型文法；每条标注带 schema hash 与来源 DAG；安全关键标签必须仲裁。主动选择记录倾向 `π_sel`，校准用来源加权共形，低样本层逐级回退。

## 3. 与基线的接口（如何退化）

- 语音不可用 / 无 n-best / 后验过散 / 放弃 ⇒ 使用文本指令 ℓ，等价于 InstructGauge；
- 关键槽位验证不可用或读回失败 ⇒ 不执行安全关键动作，退回纯文本确认或 ToolGauge 的可逆单步；
- 标注者可靠度模型不可用 ⇒ 均匀可靠度 + 全局共形（InstructGauge SC-Cal）；
- 主动标注不可用 ⇒ 被动标注、`π_sel` 均匀；来源加权不可用 ⇒ 全局/分层共形；
- schema 编译器不可用 ⇒ 冻结旧 schema，拒绝未知标签；
- InstructGauge 失效 ⇒ ToolGauge；ToolGauge 失效 ⇒ LeanGauge；LeanGauge 失效 ⇒ MODGAUGE 原样。

## 4. 预期贡献

1. 一个将 ASR n-best 转为**类型化指令后验**的接口，配合关键槽位验证/读回与双提交屏障，把「听错」从无界文本错误压成可审计的槽位风险；
2. 一个**标注规范编译器 + 可靠度/来源模型 + 主动标注调度**，把标注从「真值注入」改成「可加权、可追溯的证据注入」；
3. 一个在**选择偏差 + 标签噪声**下仍给出覆盖界的来源加权共形方案，并明确低样本/无金标时的回退与不可识别边界；
4. 一条可证伪路径：E457–E472 覆盖语音闭包、关键槽位、双提交、schema 闭包、可靠度、主动标注、加权覆盖、对抗音频与 50Hz 时序。

## 5. 本轮最大风险

**一句话**：语音后验与标注共识都只是关于「意图」的证据，二者越干净越容易制造「已经验证」的错觉；若把双提交屏障或关键槽位验证降级成可选项，系统就会用高置信的意图证据去授权一个物理上未经回执确认的动作——真正的残余风险在**证据类型边界**，而不在 ASR 的 WER 或标注噪声本身。

## 2. 形式化定义（要点）

**定义 448（语音指令后验 SID）**
设 `x ∈ X` 为音频，`A_ASR: X → Δ(H)` 给出 n-best 假设及校准后验 `q(h|x)`，`Γ` 为第 3 轮类型化接地映射。定义
`p(ι|x) = Σ_{h∈H(x): Γ(h)=ι} q(h|x)`，`p(⊥|x) = 1 − Σ_{ι∈Plan_ToolGauge} p(ι|x)`。
只保留累计质量 `≥ 1−ε_tail` 的 top-k 假设，其余尾部质量显式并入 `⊥`。要求 `q` 经温度/共形校准，满足 `‖q̂−q‖_TV ≤ ε_cal`。退化：无 n-best 时 `q = δ_{h_1best}`，即 InstructGauge 文本路径。

**定义 449（关键槽位与槽位后验）**
`S_crit = {magnitude, unit, sign/negation, comparison, referent-id, priority, condition-trigger}`。对槽位 `s`，`z_s(ι)` 为其投影；`p_s(z|x) = Σ_{ι: z_s(ι)=z} p(ι|x)`。记 top-1/top-2 概率为 `p_s^(1), p_s^(2)`，`m_s = p_s^(1) − p_s^(2)`，`H_s = H(p_s(·|x))`。关键槽位错误代价 `c_s` 显著高于普通槽位，因此安全判断按槽位分解，而不是只看整句似然。

**定义 450（关键槽位验证 CSV）**
给定校准误差 `ε_cal` 与读回通道 `V`（错误率 `e_rb`），槽位被接受当且仅当：
`p_s^(1) ≥ τ_slot`、`m_s ≥ μ_slot`，且对数值/单位/否定/指代/优先级执行读回确认 `V=1`；否则输出 `clarify(s)` 或 `⊥`。接受后的保守错误界由贝叶斯公式给出。令 `e_0 = 1−p_s^(1)+ε_cal`、`c_0 = p_s^(1)−ε_cal`，若读回满足 `P(V=1|错) ≤ e_rb`、`P(V=1|对) ≥ 1−e_rb`，则
`r_s ≤ e_rb·e_0 / [e_rb·e_0 + (1−e_rb)·c_0]`。
未读回时 `r_s ≤ e_0`；若 `c_0 ≤ 0` 则必须放弃。安全关键槽位不得用 `q_i`（标注后验）替代 `V` 或回执。

**定义 451（话语提交点 τ_utt）**
流式后验 `p_t(ι)`，稳定窗 `W`，稳定阈值 `ε_stab`，端点检测 `e_t ∈ {0,1}`。定义
`τ_utt = min{ t : e_t=1, max_{t'∈[t−W,t]} TV(p_{t'}, p_t) ≤ ε_stab, ∀s∈S_crit: CSV_s=accept }`。
若超过 `T_clarify` 仍不存在，则 `clarify/abstain`。未提交的 partial 只能更新后验，不能进入执行器；提交是动作路径的必要条件。

**定义 452（双提交屏障 DCC）**
动作块 `C` 在时刻 `t` 可提交当且仅当
`τ_utt < t ∧ ¬pending_clarify ∧ CVC(C,t) ∧ Barrier(C)`。
形式化安全不变式：`Commit_act(C,t) ⇒ Committed_utt(τ_utt<t) ∧ CVC ∧ Barrier`。定义提交偏斜 `Δ_c = t−τ_utt ≥ 0`；块内第 `i` 步的证据年龄为 `t+i−τ_utt ≤ Δ_c+K`。`Δ_c` 必须有硬上界 `Δ_max`，否则后验虽稳定也可能已过期。

**定义 453（端到端风险证书）**
`R = (r_slot, r_ground, r_annot, r_exec)`，其中 `r_slot = 1 − Π_{s∈S_crit}(1−r_s)`，`r_ground` 为已提交文本下的接地/解析错误上界，`r_annot = α+δ+η` 为标注参与校准时相对目标覆盖的缺口，`r_exec` 为 CVC/Barrier 违反率。安全提交要求**每个分量**低于预注册阈值，而不是只看平均任务成功率。由联合界：
`P_unsafe ≤ 1 − Π_i(1−R_i) ≤ Σ_i R_i`。

**定义 454（标注模式 A 与编译器 ASC）**
`A = (O_onto, S_slots, T_types, C_constraints, v_schema)`；`Compile(A) = (G_A, H_A)`，其中 `G_A` 为带类型标注文法，`H_A = hash(A)`。合法标注 `y` 满足 `y ⊢ G_A`、`types(y) ⊆ O_onto`、`mag(y) ⊆ M_phys`，且不存在自由文本直达执行器的槽位。标注与运行时共享同一 `O_onto/T₀/M_phys`；`H_A` 绑定标注、训练集与校准集版本，schema 不一致的标签一律拒收。

**定义 455（标注记录与来源图）**
`a = (i, annotator, y, H_A, t, channel, conf, adjudication, pool)`；来源图 `P` 为 DAG：`raw audio → transcript → label → adjudication → calibration`。每条边记录工具版本、模型版本、时间与操作者；`Prov(y)` 返回 `y` 的全部祖先。无来源或 schema hash 不明的标签不得进入校准集；这是审计可复现性的最低条件。

**定义 456（标注者可靠性模型 ARM）**
标注者 `a` 有混淆矩阵 `π_a(ỹ|y*)`，先验 `p(y)`，金标集 `G`。标注后验
`q_i(y) ∝ p(y) · Π_{a∈A_i} π_a(ỹ_{ia}|y)`。
可靠度可取 `ρ_a = I(Y;Ỹ_a)` 或 `ρ_a = 1 − E[1−π_a(ỹ|y*)]`。**可识别性**：若每类至少有一个金标锚点，或已知 `π_a` 的先验/约束，则混淆矩阵可识别；否则仅能识别到标签置换与类先验等价类。安全关键标签必须经仲裁成为 `G`，不得只靠未锚定的 `q_i`。

**定义 457（标注证据与置信分层）**
`c_i = max_y q_i(y)`，`ŷ_i = argmax_y q_i(y)`，`H_i = H(q_i)`；证据权重 `w_i = c_i`（或 `ρ_a` 的聚合）。按层统计噪声率 `η_s = E[1−q_i(ŷ_i)]`，置信桶 `b_i = bin(c_i)`。标注标签只作为**证据**进入先验/校准；安全关键项的 `η_s` 只用于报告不确定性，不用于授权动作。

**定义 458（主动标注调度 AAS）**
选择倾向 `π_sel(i|F_r) ∝ exp(β·U_i)`，其中 `U_i = EIG(i)/cost_i + λ_cov·1[s_i 覆盖不足]`，
`EIG(i) = H(ι|F_r) − E_{y}[H(ι|F_r∪(i,y))]`。
记录每次选择的 `π_sel` 与随机种子；安全关键项按不确定性优先且强制仲裁。主动选择改变校准分布，因此必须由定义 459 的权重校正，否则共形覆盖会在稀有层失效。

**定义 459（来源加权共形 PWC）**
校准集 `{(x_i,y_i,w_i)}`，`w_i ∝ ρ_i / π_sel(i)` 并归一化；非一致性分数 `s(x,y)`；加权分位
`q = inf{ q : Σ_{i:s_i≤q} w_i / Σ_i w_i ≥ 1−α }`，预测集 `C(x) = {y : s(x,y) ≤ q}`。
在加权可交换性下覆盖 `≥ 1−α`；若权重与真实选择权重的 TV 误差为 `δ`、标签噪声率为 `η`，则覆盖 `≥ 1−α−δ−η`（引理 64）。低样本层逐级回退到粗层，再到全局。

**定义 460（标注感知分层）**
`stratum(ι) = (goal_type, ref_count, condition_flag, critical_slot_count, conf_bin)`；层级为 `s → s_coarse → GLOBAL`。每层独立取分位；层样本 `< n_min` 时逐级回退，并记录回退惩罚 `η_fallback`。分层的目的不是追求更细，而是避免语音/标注条件化破坏可交换性后，全局阈值在关键层系统性失效。

**定义 461（虚假置信缺口）**
标注共识度 `A_ann = 1 − H(q_i)/log|Y|`；槽位验证风险 `r_slot = max_{s∈S_crit} r_s`。定义
`G_fc = max(0, A_ann − (1−r_slot))`。
`G_fc > 0` 表示「标注共识比语音/槽位验证实际支持的更自信」。此缺口只能触发澄清/降级，绝不能作为授权依据；它把「标注很干净」与「动作已验证」在数值上分开。

**定义 462（EchoCert 审计证书）**
`EchoCert = (hash(x), H(x), τ_utt, ι, {CSV_s}, H_A, Prov refs, C, ChunkCert, receipts, claims)`，把第 3 轮 `RepairCert′` 扩展为五级证据链：**音频 → n-best → 指令 → 动作块 → 回执/主张**。审计者可重放提交决策、检查关键槽位验证、追溯标注来源与 schema 版本，并确认没有任何标注证据越过 `DCC/Barrier` 直接授权执行。

## 3. 关键算法骨架

```python
# IP-328 SID：音频 → 类型化指令后验（尾部质量显式入 ⊥）
class SID:
    def posterior(self, x, k=5, tail_eps=1e-3):
        hyps = self.asr.nbest(x, k)                  # [(h, q(h|x))]
        out = {}
        for h, q in hyps:
            iota = self.gamma(h)                     # 越权/不可解析 → ⊥
            out[iota] = out.get(iota, 0.0) + q
        tail = max(0.0, 1.0 - sum(out.values()))
        out[BOT] = out.get(BOT, 0.0) + tail
        return out

# IP-329 CSV：关键槽位验证（阈值 + margin + 读回）
class CSV:
    def verify(self, p_iota, readback=None):
        results = {}
        for s in S_CRIT:
            z, p1, p2 = project_slot(p_iota, s)
            if p1 < TAU_SLOT or (p1 - p2) < MU_SLOT:
                return Clarify(s)
            if s in NEEDS_READBACK:
                if readback is None or readback(s) != z:
                    return Clarify(s)
            results[s] = Accept(z, p1, p1 - p2)
        return Accepted(results)

# IP-330 DCC：话语提交先于动作提交
class DCC:
    def commit_utterance(self, stream, csv):
        for t in stream.frames():
            if not stream.endpoint(t): continue
            if stream.tv(t, W) > EPS_STAB: continue
            if not csv.verify(stream.posterior(t)).accepted: continue
            return t
        return None

    def can_commit_action(self, tau_utt, C, env, iota):
        if tau_utt is None or tau_utt >= env.t: return False
        if env.pending_clarify: return False
        if not CVC.check(C, env, iota): return False
        if crosses_irreversible(C): return False   # Barrier 强制 K=1 + 独立验证
        return True

# IP-331 ASC：标注规范 → 与运行时同源的类型文法
class ASC:
    def compile(self, schema):
        G = TypedGrammar(schema.O_onto, schema.S_slots,
                         schema.T_types, schema.C_constraints)
        return G, hash_schema(schema)

    def validate(self, y, G, H_A):
        return conforms(y, G) and schema_hash(y) == H_A

# IP-332 ARM：标注者可靠度 + 金标锚点
class ARM:
    def fit(self, annotations, gold):
        if not identifiable(annotations, gold):
            return UniformReliability()              # 退化：均匀可靠度
        return DawidSkene(annotations, gold).fit()

    def evidence(self, item):
        return posterior_over_labels(item, self.reliability)

# IP-333 AAS：期望信息增益/成本 + 覆盖缺口
class AAS:
    def select(self, pool, state, budget):
        score = {i: eig(i, state) / cost(i)
                    + LAMBDA_COV * coverage_bonus(i, state)
                 for i in pool}
        probs = softmax(BETA * score)
        chosen = sample(pool, probs, budget)
        log_propensity(chosen, probs)                # 供 PWC 校正
        return chosen

# IP-334 PWC：来源加权共形分位
def weighted_quantile(scores, weights, alpha):
    order = argsort(scores)
    w = weights[order] / weights.sum()
    cw = cumsum(w)
    j = searchsorted(cw, 1 - alpha)
    return scores[order][j]

# IP-335 EchoGauge-8C：语音/标注异步；动作只在双提交后
def echo_8c(M, s, x, ell=None):
    if x is None:
        return instructgauge_7c(M, s, ell)           # 语音不可用 ⇒ 文本路径
    P = M.sid.posterior(x)
    if P.get(BOT, 0.0) > BOT_MAX:
        return clarify_or_abstain(s, x)              # 不动作
    iota = argmax_plan(P)
    if iota is None:
        return clarify_or_abstain(s, x)
    csv_out = M.csv.verify(P, readback=M.readback)
    if not csv_out.accepted:
        return clarify_or_abstain(s, x)
    tau_utt = M.dcc.commit_utterance(M.asr_stream, M.csv)
    if tau_utt is None:
        return clarify_or_abstain(s, x)
    H = M.lbox.hypothesize(s, M.dbox.R[s], iota)     # 指令仅重排先验
    C = M.iac.plan_chunk(iota, H, M.tools,
                         M.budget_left(s), M.drift_bound(s))
    if not M.dcc.can_commit_action(tau_utt, C, M.env, iota):
        return no_action(s, "commit_barrier")
    cert = M.cvc.commit(C, M.env, iota)
    receipts = cert.receipts
    if len(receipts) < n_min(s):
        return stub_and_red(s, "insufficient")
    mu, Sig = M.apcal.calibrate(receipts, H, s)
    if not M.apcal.cross_validate(mu, Sig, M.cross_receipt(s)):
        return stub_and_red(s, "cross_failed")
    new_ec = M.apcal.update_contract(M.dpe, mu, Sig, s)
    if not contract_regression(new_ec):
        return stub_and_red(s, "regression")
    M.mreg.hot_replace_at_quiescence(M.dpe, new_ec, cert.boundary)
    # 标注证据只进入校准/审计，不进入动作授权
    if M.arm is not None:
        M.pwc.update(M.arm.evidence(receipts), propensities=M.aas.log)
    M.asc.validate_claims(cert, iota)                 # 未知 schema 标签拒收
    M.aas.maybe_schedule(M.annotation_pool, s, P)     # 异步
    claims = bind_claims(cert, iota, receipts)
    return EchoCert(x, P, tau_utt, iota, csv_out, cert, claims)

# 主闭环：流式 ASR/标注异步；50Hz 路径不变
def EchoGauge_round(M, obs, audio, tac, depth, det, ell=None):
    M.asr_stream.push(audio)
    for s, tau in M.dcc.drain_committed(M.asr_stream):  # 只取已提交话语
        if s not in M.inflight:
            M.inflight.add(s)
            submit_async(echo_8c, M, s, tau.audio)
    M.aas.maybe_schedule(M.annotation_pool)             # 异步
    return MODGAUGE_round(M, obs, audio, tac, depth, det)
```

## 4. 推导

**引理 59（语音后验的能力闭包）** 若接地映射 `Γ` 对每个文本假设返回 `Plan_ToolGauge` 中的类型化指令或 `⊥`，则对任意音频 `x`，`p(ι|x)=0` 对所有 `ι ∉ Plan_ToolGauge` 成立；ASR 尾部质量与越权质量全部进入 `p(⊥|x)`。因此第 3 轮引理 51 从「单条文本」提升为「后验分布」，语言/语音层仍不能扩张能力。
*证明*：对 `h` 逐个使用 `Γ(h) ∈ Plan_ToolGauge ∪ {⊥}`，再对 `q(h|x)` 求和；非 `Plan_ToolGauge` 的 `ι` 不在任何求和项中，尾部被显式并入 `⊥`，故总质量仍为 1。

**引理 60（关键槽位验证的保守错误界）** 在定义 450 的校准与读回假设下，若槽位被接受，则其真实值不等于 top-1 的条件概率不超过
`e_rb(1−p^(1)+ε_cal) / [e_rb(1−p^(1)+ε_cal) + (1−e_rb)(p^(1)−ε_cal)]`。
未读回时不超过 `1−p^(1)+ε_cal`。故 `τ_slot/μ_slot/e_rb` 可直接换算为可审计的槽位风险上界，并用于定义 453 的 `r_slot`。
*证明*：令 `E` 为 top-1 错误、`C` 为正确，则 `P(E) ≤ 1−p^(1)+ε_cal`、`P(C) ≥ p^(1)−ε_cal`；对读回事件 `V=1` 用贝叶斯公式，并代入 `P(V=1|E) ≤ e_rb`、`P(V=1|C) ≥ 1−e_rb`，即得。

**引理 61（双提交安全与陈旧界）** 若动作提交满足定义 452，则任何被执行的动作块都使用已提交话语；流式 partial 不可能驱动执行器。块内证据年龄上界为 `K+Δ_c`；当 `Δ_c ≤ Δ_max` 时，陈旧窗口有界。若 `τ_utt` 的关键槽位验证通过且 CVC 在每个提交边界复核 `still_grounded`，则已执行前缀保持第 3 轮引理 52 的安全不变式。
*证明*：对动作块归纳。首个块由 `Commit_act ⇒ τ_utt<t` 得话语已提交；块内每步由 CVC 复核；跨块时上一块已 drain/截断，下一块仍满足同一提交谓词。证据年龄由 `t+i−τ_utt` 直接估计。

**引理 62（标注模式的标签侧能力闭包）** 若 `A` 与运行时共享 `O_onto/T₀/M_phys`，且 `ASC` 只接受 `y ⊢ G_A` 的标签，则任何被接受的标注都描述 `Plan_ToolGauge` 中的类型化指令；schema hash 不一致的标签被拒收。故标注侧不会引入运行时不存在的新工具/新物理量，也不会因本体错位产生系统性标签漂移。
*证明*：对 `G_A` 的产生式结构归纳。基础槽位取自 `O_onto`；复合标注只对类型/约束做过滤与重排，不新增工具或幅值；越权产生式不满足 `y ⊢ G_A`，被 `validate` 拒绝。

**引理 63（标注者可靠度的可识别性边界）** 在 Dawid–Skene 模型下，若每类至少有一个金标锚点，或已知混淆矩阵的强先验，则 `π_a` 与 `q_i` 可识别；若既无锚点也无先验，则仅能识别到标签置换与类先验的等价类。推论：无锚点估计出的 `ρ_a` 只能用于弱先验/排序，不能用于安全关键标签的认证。
*证明*：对任意标签置换 `σ`，令 `π'_a(σ(ỹ)|σ(y*)) = π_a(ỹ|y*)`、`p'(σ(y))=p(y)`，则似然不变；金标锚点打破置换对称性，强先验打破类先验对称性。

**引理 64（来源加权共形的覆盖界）** 在加权可交换性下，PWC 的覆盖 `≥1−α`。若记录的选择倾向与真实倾向的 TV 误差为 `δ`，校准标签与真实标签的翻转率为 `η`，则对真实标签的覆盖 `≥1−α−δ−η`。低样本层回退到全局时，额外损失不超过 `η_fallback`。
*证明*：用耦合把加权样本与真实分布对齐，权重误差事件概率 `≤δ`；在标签一致事件（概率 `≥1−η`）上非一致性分数相同，故覆盖损失不超过两事件概率之和；回退情形由分层覆盖的凸组合与全局覆盖直接放缩。

**引理 65（标注不能认证执行：分离定理）** 设安全谓词 `Safe(σ,a)` 依赖物理状态 `σ`，而标注证据在给定意图 `I` 下与 `σ` 条件独立。若存在两个物理状态 `σ,σ'`，其意图与标注分布相同但 `Safe(σ,a*) ≠ Safe(σ',a*)`，则任何只依赖 `(x, annotation)` 的授权规则在其中一个环境必错。故增加标注者/标注样本不能把 `r_exec` 降到 0；安全必须由读回、回执、CVC/Barrier 等**动作证据**提供。
*证明*：构造两个环境，使音频后验与标注后验完全相同而执行器标定不同；任何标注-only 规则输出同一动作，故不可能同时安全。该构造与标注样本量无关。

**引理 66（端到端风险分解与双提交的作用）** 在定义 453 下，`P_unsafe ≤ Σ_i R_i`。双提交与 Barrier 降低 `r_exec` 并压缩暴露窗口 `K+Δ_c`，但不降低 `r_slot` 与 `r_annot`；因此不能把「任务成功率提高」误读为「安全风险下降」。
*证明*：联合界给出求和；`r_exec` 由引理 61 的提交谓词控制；`r_slot` 由引理 60 的 ASR/读回通道决定；`r_annot` 由引理 64 的覆盖缺口决定。三者来源不同，不能相互抵消。

**引理 67（异步语音/标注与 50Hz 保全）** SID、CSV、AAS、ARM 拟合均可在异步线程执行；`EchoGauge_round` 只消费已提交话语的快照，主循环新增内联工作为 `O(1)` 的队列检查与快照，50Hz 路径仍为 `MODGAUGE_round` 原路径。端到端新增延迟由 `T_endpoint + T_commit + T_clarify` 构成，不进入 20ms 硬实时预算。
*证明*：语音流与标注调度不共享可变执行状态；`τ_utt` 之后才进入 `echo_8c`，其余为离线/异步；热替换仍受第 3 轮 `q_quiesce` 约束。内联操作只做队列 drain 与指针交换，故不改变主循环复杂度。

**引理 68（主动标注的贪心近似）** 若 `EIG` 在自适应子模意义下单调子模，且预算为基数约束，则贪心选择达到最优期望信息增益的 `1−1/e`；若加入覆盖约束，则需用带覆盖下界的背包/贪心变体，并记录 `π_sel` 供 PWC 使用。
*证明*：标准自适应子模贪心的 `1−1/e` 近似；覆盖约束下先满足下界再按边际增益分配剩余预算，选择倾向由定义 458 显式记录，保证引理 64 的权重可计算。

| 端到端（E466/E471） | 成功率 ≥ 85%，退化 ≤ 10% | 回退文本确认或纯 ToolGauge |

预期：E457/E460/E461/E468/E469 为「结构级」判据，应严格成立；E458/E462/E464/E465 为「统计级」判据，按置信区间验收；E463/E466/E471/E472 为「系统级」判据，报告效应量与标注预算曲线。特别地，E472 必须包含一个**标注-only 认证失败**的构造性反例，以验证引理 65 的分离不是空话。

## 8. 本轮最大风险

**一句话**：最大风险是双提交屏障与关键槽位验证被当成「可选增强」而逐步降级——一旦它们缺席，ASR 后验与标注共识会共同制造「已经确认」的假象，而物理执行仍可能越过不可逆屏障；因此 P4/P5 必须是硬门，而不是可以被平均任务成功率掩盖的统计指标。
