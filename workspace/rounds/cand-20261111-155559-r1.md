# 第 56 轮（承接第 55 轮 v32 语义-接触接地；灵感循环第 1 轮；本轮灵感：「状态隔离」×「动作空间」）

> 第 55 轮把可行性判据推进到“接触在语义上可信、全身耦合下可行”，但留下一个结构性难题：生存核 `K(Σ)` 是质心动力学把四肢耦合出的高维对象，第 55 轮的求核与护盾只能靠采样近似；动作空间越大、接触越多，验证越不可组合。本轮把视角从“如何检查整个动作空间”转向 **“能否把动作空间切成互不串扰的隔间，使验证可组合、误差可隔离”**。核心矛盾：
> **H24**：全身控制本质上是耦合的，严格的状态隔离（某模块的动作完全不改变平衡/接触状态）几乎不存在，只有**近似隔离 + 有界泄漏**；一旦把“近似”当成“严格”，隔间之间就会互相污染。
> **H25**：动作空间的模块化（臂/腿/躯干/基座）是工程约定而非动力学事实；按工程模块做隔离，会把真正耦合的通道切在隔间内部，使隔离证书在接触切换处失效。
> **H26**：隔离不是免费的——越隔离越保守，可行动集收缩、任务能力下降；隔离收益与能力损失之间必须有显式预算，否则“安全隔间”会退化为“安全地什么都不做”。

## 0. 直觉与动机

**灵感 1（状态隔离 → 受保护状态 + 隔离膜，而非全局不变式）**
直觉：不要要求“整个状态不变”，而把状态分成 **受保护状态** `x_P`（质心、支撑多边形、基座姿态、接触力是否在摩擦锥内）与 **工作状态** `x_W`（末端位姿、关节构型、任务进度）。状态隔离不是把 `x_P` 冻结，而是在 `x_P` 外设一层 **隔离膜**：工作动作 `u_W` 对 `x_P` 的推动必须被证明有界，并由一层“泄漏预算”吸收。这比“全状态不变”现实，又比“什么都不保证”可证。

**灵感 2（动作空间 → 隔离商空间，把连续动作压成有限隔间）**
直觉：`A_WB` 连续且巨大，但大量动作对受保护状态的 **泄漏签名** 相同。用隔离签名把动作商掉：`A/~ = {动作隔间}`，每个隔间携带 `(接触模式, 激活模块, 泄漏上界, 可用隔离窗口)`。规划与验证在商空间上进行，护盾再映射回具体动作。这把第 54 轮的动作剖面 `α_S` 从“占用度”推进到 **“可隔离度”**。

**灵感 3（小增益 → 把循环耦合写成一个可计算的放大因子）**
直觉：泄漏会互相放大：臂的泄漏扰动质心，质心偏移改变腿的接触力，接触力再反馈给臂。用 **小增益定理** 把这种循环耦合写成增益矩阵 `Γ`；只要谱半径 `ρ(Γ)<1`，隔间误差就被 `(I-Γ)^{-1}` 有界放大，而非无限累积。`1-ρ(Γ)` 就是隔离证书的“剩余隔离度”。

**灵感 4（隔离窗口 → 接触切换前必须重新隔离）**
直觉：隔离质量随接触模式剧烈变化：双支撑时臂-腿耦合弱，单支撑/腾空时耦合强。因此隔离只在 **隔离窗口** 内成立；窗口由最小驻留时间 `τ_min` 与预算耗尽共同定义。动作序列必须携带 **重新隔离** 计划（主动回到双支撑、降臂速），而不是一路“隔离到黑”。

**灵感 5（隔离故障 → 云边状态隔离/检疫，而非共享同一个状态假设）**
直觉：云端粗动作假设了受保护状态 `x_P^c`，边端 `x_P^e` 会漂移。若二者差异耗尽了泄漏预算，边端必须 **检疫（quarantine）** 云端动作：冻结该动作隔间准入，执行本地重新隔离，回传泄漏证据；云端据此重排隔离窗口。这把第 55 轮的语义-动作重剖分升级为 **隔离-动作联合重剖分**。

## 1. 形式化定义（增量：定义 127–132）

**定义 127（状态-动作隔离分解）**
状态 `x=(x_P,x_W)`，`x_P∈X_P` 为受保护状态（质心/支撑/基座姿态/接触力状态），`x_W∈X_W` 为工作状态。动作 `u=(u_1,...,u_m)∈A=A_1×...×A_m`（臂/腿/躯干/基座）。受保护漂移分解
`ẋ_P = f_P^0(x_P) + Σ_i h_i(x_P)u_i + Δ(x_P,x_W,u)`，
其中 `Δ` 为 **泄漏项**（工作状态与模块间的交叉耦合）。

**定义 128（隔离增益矩阵与小增益条件）**
在隔离窗口内设 `||D_iΔ_j|| ≤ Σ_j γ_{ij}||x_{W,j}||`（`D_i` 为模块 i 的受保护投影），得增益矩阵 `Γ=[γ_{ij}]`。若 `ρ(Γ)<1`，称 `(x_P,x_W,u)` **可隔离**，隔离度 `ι=1-ρ(Γ)`，泄漏放大因子 `κ_L=||(I-Γ)^{-1}||`。

**定义 129（动作隔间与隔离商空间）**
动作隔间 `cell=(mode,S_active,ℓ,W_iso)`：接触模式、激活模块集、泄漏上界 `ℓ`、可用隔离窗口。商空间 `A/~={cell}`，映射 `q:A→A/~`。隔离版动作剖面 `α_S^iso(cell)=P_{a∼cell}(α_S(a)≥θ_cov)`。

**定义 130（隔离生存核）**
`K_iso(Σ,ε) = {(x_P,x_W) | x_P∈K_P(ε_P), x_{W,i}∈K_{W,i}(ε_{W,i})}`，
其中 `ε≤κ_L·ε_L(T)`，`ε_L(T)=∫_0^T||Δ||dt` 为泄漏预算消耗。若隔离窗口覆盖轨迹、`supp(λ)⊆C^+(Σ)` 且 `ε≤θ_margin`，则 `K_iso⊆K(Σ)`（sound over-approximation）。

**定义 131（泄漏预算护盾）**
预算状态 `b_t`，`b_{t+1}=b_t-||Δ(u_t,x_t)||Δt`。护盾
`u* = argmin_u ||u-u_nom||²_W s.t. x_{t+1}∈K_iso, b_{t+1}≥0, cell(u) 与当前隔离窗口兼容, λ∈FC(μ)`。
若不可行：先尝试 **重新隔离动作** `u_reiso`（回到低增益接触模式），仍不可行则安全制动。预算耗尽是动作隔间准入的硬约束。

**定义 132（状态隔离证书）**
`J_iso=(x_P^*, W_iso, Γ, ι, b_0, ε, K_margin, evidence)`：
- `x_P^*` 受保护状态名义值；`W_iso` 覆盖轨迹的隔离窗口序列（含驻留时间）；
- `Γ/ι` 隔离增益与隔离度；`b_0` 初始泄漏预算；`ε` 放大量；
- `evidence` 含泄漏反例、重新隔离日志、云边状态差 `δ_P=||x_P^c-x_P^e||`。
若 `ι≥θ_γ`、`W_iso` 满足 `τ_min`、`b_t≥0` 全程、`K_margin≥θ_K` 且 `ε≤θ_margin`，则状态隔离可部署。

## 2. 关键算法 伪代码

### IP-127 SID（State-Isolation Decomposition）

```python
def state_isolation_split(x, task):
    x_P = project(x, ['com', 'support_polygon', 'base_attitude', 'contact_wrench'])
    x_W = project(x, ['ee_pose', 'joint_config', 'task_progress'])
    modules = partition_actions(A_WB, ['arm_L','arm_R','leg_L','leg_R','torso','base'])
    return x_P, x_W, modules

def isolation_drift(f, x, module, u_i, lam):
    u = zero_action(); u[module] = u_i
    return project_P(f(x, u, lam)) - project_P(f(x, zero_action(), lam))
```

### IP-128 LEAK（Isolation Gain Estimation）

```python
def estimate_gain_matrix(x_P, x_W, modules, sim, contact_modes):
    Gamma = zeros((len(modules), len(modules)))
    for mode in contact_modes:
        for j, mj in enumerate(modules):
            for x in perturb_ball(x_P, x_W, eps):
                num = norm(isolation_drift(sim.f, x, mj, sim.max_u(mj), mode))
                den = norm(x_W[j]) + norm(sim.max_u(mj)) + eps
                Gamma[:, j] = maximum(Gamma[:, j], num / den)   # robust upper bound
    return Gamma, spectral_radius(Gamma)

def isolation_degree(Gamma):
    rho = spectral_radius(Gamma)
    return max(0.0, 1.0 - rho), inverse_norm(eye - Gamma)
```

### IP-129 AQS（Action Quotient Space）

```python
def quotient_action_space(A_WB, Gamma, contact_modes, ell_grid, W_grid):
    cells = {}
    for mode in contact_modes:
        for S_active in subsets(modules):
            for ell in ell_grid:
                for W in W_grid:
                    members = {a for a in A_WB
                               if mode_of(a) == mode and active(a) == S_active
                               and leakage_bound(a, Gamma) <= ell
                               and window_of(a) >= W[0]}
                    if members:
                        cells[(mode,S_active,ell,W)] = ActionCell(members, ell, W)
    return cells      # planner 在 cell 上搜索，shield 再把 cell 映射回具体 a
```

### IP-130 IKB（Isolation Kernel Bound）

```python
def isolation_kernel(Sigma, C_plus, Gamma, eps_L, horizon, tau_min):
    kappa_L = inverse_norm(eye - Gamma)
    eps = kappa_L @ eps_L(horizon)                 # 泄漏放大
    K_P = viability_kernel(Sigma, C_plus, x_P_dims)
    K_W = {i: viability_kernel(Sigma, C_plus, x_W_dims[i]) for i in modules}
    if spectral_radius(Gamma) >= 1.0 or eps > theta_margin:
        return ('reject', 'isolation_not_sound', spectral_radius(Gamma), eps)
    return KernelApprox(product(K_P, K_W), eps=eps, isolation_degree=1-spectral_radius(Gamma))

def window_schedule(mode_seq, tau_min, eps_L):
    W, b = [], budget()
    for mode in mode_seq:
        if gain_margin(mode) < theta_gamma:
            W.append(('reiso', mode)); b.reset()   # 进入高耦合模式前先重新隔离
        elif b.would_exhaust(mode):
            W.append(('reiso', mode))
        else:
            W.append(('iso', mode)); b.consume(mode)
    return W
```

### IP-131 LAF（Leakage-Aware Firewall Shield）

```python
def leakage_shield(u_nom, x, b, Kernel, C_plus, cells):
    cell_nom = q(u_nom)
    if not cell_admissible(cell_nom, Kernel.W_iso, b):
        u_re = reisolation_action(x, C_plus)       # 回到低增益接触模式
        if u_re is not None and budget_after(x, u_re) >= 0:
            return u_re, 'reiso'
        return safe_brake(x), 'budget_exhausted'
    u = qp_solve(H=W, g=-W @ u_nom, constraints=[
            viability_constraint(x, u, Kernel.K_in),
            leakage_budget(x, u, b),               # ||Delta(u,x)||dt <= b
            contact_constraint(u, C_plus),
            friction_cone_constraint(u, mu)])
    return (u, 'ok') if u is not None else (safe_brake(x), 'shield_infeasible')
```

### IP-132 SIC（State-Isolation Certificate & Quarantine）

```python
def isolation_certificate(traj, Sigma, Gamma, budgets, cloud_xP, edge_xP):
    W_iso = window_schedule([mode_at(t) for t in traj], budgets.tau_min, budgets.eps_L)
    if not windows_cover(traj, W_iso, budgets.tau_min):
        return ('reject', 'isolation_window_gap')
    iota = 1 - spectral_radius(Gamma)
    eps = inverse_norm(eye - Gamma) @ budgets.eps_L
    b, worst_margin = budgets.b0, inf
    for t in traj:
        b -= leakage(t)
        worst_margin = min(worst_margin, distance_to_boundary_K(x_t, Sigma))
        if b < 0:
            return ('reject', 'leakage_budget_exceeded', t)
    delta_P = norm(cloud_xP - edge_xP)
    if delta_P > budgets.delta_P_max:
        return ('quarantine', 'cloud_edge_state_drift', delta_P)   # 边端冻结云端隔间
    if iota < budgets.theta_gamma or eps > budgets.theta_margin:
        return ('reject', 'isolation_not_sound', iota, eps)
    return ('ok', StateIsolationCert(W_iso, Gamma, iota, b, eps, worst_margin))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| SID | O(|X|) | O(|X|) | 受保护状态投影完备、模块划分覆盖 A |
| LEAK | O(|M|²·\|X\|·\|U\|) | O(|M|²) | 增益为鲁棒上界、接触模式枚举完备 |
| AQS | O(\|A\|·\|Γ\|) | O(\|cells\|) | 隔间签名保守、cell→a 映射满射 |
| IKB | O(|X|·T·QP·m) | O(|X|) | `ρ(Γ)<1`、`K_iso⊆K`、窗口覆盖 |
| LAF | O(QP) 每次 | O(\|A\|) | 预算单调、回退有界、re-iso 可达 |
| SIC | O(\|轨迹\|·\|Ω\|) | O(\|Ω\|) | 预算闭合、窗口驻留、云边差阈值 |

**正确性定理（Isolation-Sound Compositional Viability）**
假设第 55 轮 (A29)–(A32) 成立；**(A33)** `Γ` 是 `W_iso` 内所有接触模式下的鲁棒上界；**(A34)** 预算 `b_t` 诚实、且无隔间外模块被激活；**(A35)** 重新隔离能在 `τ_reiso` 内到达低增益模式并回充预算。
则对覆盖轨迹的每一时刻，
```
K_iso(Σ,ε) ⊆ K(Σ)
P_safe ≥ 1 - P(ρ(Γ) ≥ 1) - P(ε > θ_margin) - P(budget underestimate) - P(reiso fails)
```
关键：隔离买来的是**可组合性**，代价是**保守放大 `κ_L`** 与**强制的重新隔离调度**；`ρ(Γ)` 越接近 1，隔离收益越趋近于零。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 增益矩阵低估耦合（接触切换处尤甚） | 高 | 分模式鲁棒上界 + 在线泄漏监测 + 保守裕度 |
| `ρ(Γ)→1` 导致核膨胀、动作“冻结” | 高 | 只隔离低维核心 `x_P`，分层核 + 隔离度预算 |
| 泄漏预算积分漂移累积 | 高 | 保守积分器 + 硬预算屏障 + 定期重新隔离 |
| 动作商空间把不同动作误并为一类 | 高 | 签名细化 + 反例见证 + Lipschitz 保守 |
| 云边检疫频繁切换造成抖振/活锁 | 中 | 滞回 + 最小驻留 + 本地安全控制优先 |

## 6. 本轮最大风险

**一句话**：状态隔离把可组合性押在“泄漏增益矩阵 `Γ` 是接触切换下所有模式的真上界”这一前提上，而全身控制最危险的恰是支撑切换瞬间的耦合突变；一旦 `Γ` 低估、或动作商空间把高泄漏动作误并为“同签名”，泄漏预算就会在护盾“自认为隔离”的隔间里悄悄耗尽，最终一次支撑切换把累积误差放大成不可逆跌倒——因此必须以 **分模式鲁棒增益 + 在线泄漏监测 + 切换前强制重新隔离** 三重护栏，宁可牺牲隔间容量，也不把“近似隔离”当作“严格隔离”。

# 第 56 轮产物 · 创新点清单 v32：IsoEdge-GenSim++++（SID×LEAK×AQS×IKB×LAF×SIC）

> 承接第 55 轮 v32 语义-接触接地（IP-121~126）与第 54 轮 v31 动作-协同层（IP-115~120）。本轮在“感知语义可信、全身接触可行”之上，新增 **状态隔离层**，解决第 55 轮遗留的组合爆炸：`K(Σ)` 只能采样近似、`A_WB` 无法整体验证。四个转换：

### IP-128 LEAK

```python
def estimate_gain_matrix(x_P, x_W, modules, sim, contact_modes, eps):
    Gamma = zeros((len(modules), len(modules)))
    for mode in contact_modes:
        for j, mj in enumerate(modules):
            for x in perturb_ball(x_P, x_W, eps):
                num = norm(isolation_drift(sim.f, x, mj, sim.max_u(mj), mode))
                den = norm(x_W[j]) + norm(sim.max_u(mj)) + eps
                Gamma[:, j] = maximum(Gamma[:, j], num/den)   # 鲁棒上界
    return Gamma, spectral_radius(Gamma)

def isolation_degree(Gamma):
    rho = spectral_radius(Gamma)
    return max(0.0, 1.0-rho), inverse_norm(eye - Gamma)
```

### IP-130 IKB

```python
def isolation_kernel(Sigma, C_plus, Gamma, eps_L, horizon):
    kappa_L = inverse_norm(eye - Gamma)
    eps = kappa_L @ eps_L(horizon)
    if spectral_radius(Gamma) >= 1.0 or eps > theta_margin:
        return ('reject','isolation_not_sound', spectral_radius(Gamma), eps)
    K_P = viability_kernel(Sigma, C_plus, x_P_dims)
    K_W = {i: viability_kernel(Sigma, C_plus, x_W_dims[i]) for i in modules}
    return KernelApprox(product(K_P,K_W), eps=eps, isolation_degree=1-spectral_radius(Gamma))

def window_schedule(mode_seq, tau_min, eps_L):
    W, b = [], budget()
    for mode in mode_seq:
        if gain_margin(mode) < theta_gamma or b.would_exhaust(mode):
            W.append(('reiso',mode)); b.reset()
        else:
            W.append(('iso',mode)); b.consume(mode)
    return W
```

### IP-132 SIC + 云边检疫

```python
def isolation_certificate(traj, Sigma, Gamma, budgets, cloud_xP, edge_xP):
    W_iso = window_schedule([mode_at(t) for t in traj], budgets.tau_min, budgets.eps_L)
    if not windows_cover(traj, W_iso, budgets.tau_min):
        return ('reject','isolation_window_gap')
    iota = 1-spectral_radius(Gamma)
    eps = inverse_norm(eye-Gamma) @ budgets.eps_L
    b, worst = budgets.b0, inf
    for t in traj:
        b -= leakage(t)
        worst = min(worst, distance_to_boundary_K(x_t, Sigma))
        if b < 0:
            return ('reject','leakage_budget_exceeded',t)
    delta_P = norm(cloud_xP-edge_xP)
    if delta_P > budgets.delta_P_max:
        return ('quarantine','cloud_edge_state_drift',delta_P)
    if iota < budgets.theta_gamma or eps > budgets.theta_margin:
        return ('reject','isolation_not_sound',iota,eps)
    return ('ok', StateIsolationCert(W_iso,Gamma,iota,b,eps,worst))

def quarantine_loop(cloud_cells, edge):
    xP_c, xP_e = cloud_cells.assumed_xP, edge.estimate_xP()
    while True:
        st = isolation_certificate(edge.traj, edge.Sigma, edge.Gamma,
                                   edge.budgets, xP_c, xP_e)
        if st[0] == 'quarantine':
            edge.freeze_cells(cloud_cells.active)      # 冻结，不接收云端新动作
            edge.run_local_reiso()                     # 本地重新隔离
            cloud_cells.reprofile(edge.leakage_evidence(), region=st[2])
        elif st[0] == 'ok':
            edge.admit(cloud_cells.active)
        else:
            edge.safe_brake(); cloud_cells.reprofile(edge.evidence)
        yield st
```

**正确性定理（Isolation-Sound Compositional Viability）**
假设第 55 轮 (A29)–(A32) 与第 54 轮 (A26)–(A28) 成立；新增：
**(A33)** `Γ` 是 `W_iso` 内所有接触模式的鲁棒上界；**(A34)** `b_t` 诚实、无隔间外模块被激活；**(A35)** 重新隔离在 `τ_reiso` 内到达低增益模式并回充预算。
则覆盖轨迹的每时刻 `K_iso(Σ,ε)⊆K(Σ)`，且
```
P_safe ≥ 1 - P(ρ(Γ)≥1) - P(ε>θ_margin) - P(budget underestimate) - P(reiso fails)
        - P(语义/接触层失守)      # 第 55 轮项
```
关键：隔离把“整空间验证”换成“隔间验证 + 有界放大 + 定期重新隔离”，可组合性以保守性为代价。

## 6. 与第 55 轮的接口

- **语义 → 隔离**：`C^+(Σ)` 决定哪些接触模式可进入低增益窗口；语义边界不可信时，`gain_margin(mode)` 自动收紧。
- **隔离 → 语义**：泄漏反例（某接触点在隔离窗口内实际高耦合）回传给第 55 轮 `CEB`，触发边界重分割与 `κ` 在线更新。
- **证书合并**：`J_s` 与 `J_iso` 联合判定——语义可部署且隔离可部署，才允许跨隔间并行动作；任一失守即降级为单隔间保守执行。

## 7. 本轮最大风险

**一句话**：状态隔离把 v32 的可组合性押在“泄漏增益矩阵 `Γ` 是接触切换下所有模式的真上界”上，而全身控制最危险的是支撑切换瞬间的耦合突变；一旦 `Γ` 低估、或动作商空间把高泄漏动作误并为“同签名”，泄漏预算就会在护盾“自认为隔离”的隔间里悄悄耗尽，最终一次支撑切换把累积误差放大成不可逆跌倒——故必须以 **分模式鲁棒增益 + 在线泄漏监测 + 切换前强制重新隔离 + 云边检疫** 四重护栏，宁可牺牲隔间容量，也不把“近似隔离”当作“严格隔离”。
