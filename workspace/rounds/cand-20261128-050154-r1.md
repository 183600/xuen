### 第 1 轮灵感驱动研究记录（新循环；继承 CADVS-v5）

**灵感词**：演示方案、迁移学习

**继承关系**：承接上一循环第 5 轮 CADVS-v5（IP-493~496，认证生成式执行 CGE，Exec_v5 ⊆ Exec_v4 ⊆ … ⊆ Exec_v29）。v5 把提议从规则库升级为流匹配生成器、把记忆做成固化闭环、把人因升级为情感调制，理论上很强，但它的**最大风险 R57 仍未偿还**：固化回路在自己铸证的片段上训练、价值模型又在线自适应，「铸证→学习→再铸证」缺乏外部真值，策略可能学会博弈门（形式合规、实质违背）。本轮两个灵感词恰好是 R57 的**两种外部锚**：迁移学习提供「跨域/跨本体的结构先验」——知识不必从零学；演示方案提供「人类验证过的外部真值 + 采集协议」——背书不再只靠自我。据此提出 CADVS-v6「认证迁移与演示锚定」（Certified Transfer with Demonstration Anchoring, CTDA），核心是**门仍是唯一信任边界；迁移与演示只做「提议扩展 + 附加合取证据」，绝不修改门谓词**。本轮自律：**硬门数量不增**（维持七门，延续 R52 锚点维护负债的偿还），执行集在源域上只紧不松，跨域则通过「重锚 + 双证合取」另立新证书，而非悄悄扩大旧集合。

**直觉与动机**：

1. **迁移学习 → 证书不是可任意搬运的不变量，量纲与阈值必须「重锚」。** 直觉：一个在 3 kg 轻臂上认证的力矩阈值，直接搬到 30 kg 重臂上要么过度保守、要么直接不安全；同一个 ZMP 支撑多边形在轮足与双足上根本不是一个物理量。v5 隐含假设「门谓词与域无关」，这在跨本体时是**结构性错误**。v6 把门升级为**域索引门** kc_i^D(x; τ_i^D)，并引入重锚算子 Rg_{S→T}：目标阈值为 τ_i^T = ρ_i^* · τ_i^{phys,T}，其中 ρ_i^* 是从源域认证出的**无量纲安全比**（定理 12：跨本体迁移的守恒律）。迁移算子经抽象映射 φ_{S→T} 连接两域，只有满足**裕度非扩张** |m_i^T(x) − m_i^S(φ(x))| ≤ δ_i 且目标门重锚通过，迁移候选才被接受——这是「双证合取」：目标物理门 ∧ 源证书拉回。关键：迁移不继承证书，只产生候选；证书必须在目标域**重新挣得**（定理 9）。

2. **演示方案 → 演示是外部真值，「方案」是主动采集协议，二者一起把自指回路钉在外部锚上。** 直觉：R57 的病根是「没有外部真值」，而人类演示恰恰是独立的、结局可观测的外部真值。但演示不能随手采：要覆盖的正是门的**近边界壳层**与稀有门区域，否则采再多也只是在容易区自我表扬。v6 的 DAK 把留出演示集当审计器：策略在人类标注的演示上跑，统计门违例，给出真实违例率上界（定理 10），这个界**独立于策略的自我铸证**，直接切断自指。DPD 则把「演示方案」形式化为**子模覆盖优化**：在门裕度特征空间 z(x)=(m_1..m_7) 上贪心最大化覆盖，优先近边界壳层与稀有模态，得到 (1−1/e) 近似（定理 11）与样本复杂度下界。演示方案因此从「拍脑袋拍场景」变成「给定预算买最大可认证区域」的实验设计问题。

3. **二者互补但必须警惕「伪独立」。** 迁移负责 reach（够得着新域），演示负责 trust（信得过），reach × trust 才构成可认证区域 R_cert = R_transfer ∪ R_anchor。但二者都经由同一个表示 φ 与同一套门裕度代理空间构造——若 φ 存在系统性盲区（某类接触模态、物体、操作者、文化），迁移与演示会在**同一盲区上同时通过**，双证退化为相关性背书。这是本轮最深的风险，必须在理论里写清楚、在实验里专门压测（共享 φ 的相关盲区压力测试）。

**关键洞见**：v5 回答「提议可换成任意生成器时证书边界是否不变」；v6 回答「当知识跨域/跨本体搬运、并用人类演示提供外部真值时，如何保证搬运与背书不悄悄放松门」。答案：**门谓词不可迁移、不可学习，只能重锚**；迁移与演示都是**提议扩展 + 附加合取证据**，只让执行集更窄或另立新证书，绝不让旧边界变松。新增的只是「域索引证书」与「锚定信任区域」，不是新锚点。

**形式化目标（增量）**：
1. 域索引门 kc_i^D(x; τ_i^D)、重锚算子 Rg_{S→T}、抽象映射 φ_{S→T}、归一化裕度 m_i^D(x)=(s_i^D−τ_i^D)/scale_i^D。
2. 迁移证书：非扩张条件 |m_i^T(x)−m_i^S(φ(x))| ≤ δ_i；跨本体无量纲守恒 τ_i^T = ρ_i^*·τ_i^{phys,T}。
3. 演示锚 D={(x,o,h)}；覆盖函数 Cov(D) 在 z(x) 上单调子模；信任区域 R_cert = R_transfer ∪ R_anchor。
4. 定理 9（迁移保守/双证合取）、定理 10（演示锚定外部有效性）、定理 11（演示方案子模近似 + 样本复杂度）、定理 12（跨本体无量纲守恒）、定理 13（七锚完备性保持）。
5. Exec_v6^D = {x ∈ supp(π_T) : ∧_i kc_i^D(x;τ_i^D)=1 ∧ (φ(x) ∈ Exec_v5^S ∨ anchor_ok(x))}；源域上 ⊆ Exec_v5。
6. EFA-v6 级联前置迁移/锚定信任过滤；ECS_v6 = ECS_v5 · η_transfer · η_anchor。

**本轮最大风险**：**伪独立外部锚**——迁移证书与演示锚都经由同一个抽象映射 φ 和同一套门裕度代理空间构造，并非独立证据源；若 φ 在某类接触模态/物体/操作者/文化上存在系统性盲区，迁移与演示会在同一盲区上「同时通过」，双证合取退化为相关性背书，而定理 10 的外部有效性界只在该代理分布内成立、界外静默失效，系统因此获得「已被外部验证」的错觉。

### IP-497 DTCK：域索引迁移证书核（离线重锚 + 在线 O(1) 双证）

```python
@dataclass
class DomainTransferCertificateKernel:
    """DTCK：域索引迁移证书核。
    定理 9：迁移不继承证书——必须重锚 + 双证合取；源域上执行集只紧不松"""
    phi: Any                  # φ_{S→T}: 目标轨迹 → 源表示（跨本体经运动学对应）
    reground: Any             # Rg_{S→T}: 用目标本体物理参数重算 τ^T
    delta: dict               # 每门非扩张容差 δ_i
    source_cert: Any          # 源域 Exec_v5^S 的证书索引（冻结只读）

    def reground_thresholds(self, phys_T, rho_star: dict) -> dict:
        # 定理 12：无量纲守恒，禁止拷贝量纲阈值
        # τ_i^T = ρ_i^* · τ_i^{phys,T}（ρ^* 由源域认证，phys_T 为目标本体实测）
        return {i: rho_star[i] * phys_T.limit[i] for i in SEVEN_GATES}

    def margin(self, x, domain: str) -> dict:
        # m_i^D(x) = (s_i^D(x) − τ_i^D)/scale_i^D；阈值经 Rg 预计算，O(1)
        return {i: (gate_score[i](x, domain) - tau[domain][i]) / scale[i]
                for i in SEVEN_GATES}

    def attest(self, x, ctx) -> tuple[bool, dict]:
        """双证合取（派生谓词，非新门）：目标重锚门 ∧ 非扩张 ∧ 源证书拉回"""
        m_T = self.margin(x, 'T')
        m_S = self.margin(self.phi(x), 'S')
        # (C2) 裕度非扩张：两域归一化裕度差有界
        non_expansive = all(abs(m_T[i] - m_S[i]) <= self.delta[i]
                            for i in SEVEN_GATES)
        target_ok = all(m_T[i] >= 0.0 for i in SEVEN_GATES)   # 目标物理门
        source_ok = self.source_cert.contains(self.phi(x))    # 源证书拉回
        ok = target_ok and non_expansive and source_ok
        return ok, {'m_T': m_T, 'm_S': m_S,
                    'd_margin': max(abs(m_T[i]-m_S[i]) for i in SEVEN_GATES),
                    'domain': 'T'}

    def validity(self, x) -> bool:
        return x in self.phi.valid_region          # φ 有效域，越界即拒
```

### IP-498 DAK：演示锚定外部真值审计核（离线审计 + 在线覆盖判定）

```python
@dataclass
class DemonstrationAnchorKernel:
    """DAK：演示锚定外部真值审计核。
    定理 10：外部抽检给出真实违例率界，独立于策略自我铸证（切断 R57 自指）"""
    audit_set: Any            # D_audit：人类验证的留出演示（与固化集不相交）
    eps_fn: float             # 审计假阴性率保守上界（经验 + 安全余量）
    delta_conf: float = 0.05  # 置信水平 1−δ
    n_min: int = 200          # 每审计窗口最小样本
    cov: Any = None           # 演示覆盖判定器（由 DPD 构建）

    def audit(self, policy, n: int = None) -> AnchorResult:
        """在留出演示上跑 policy，人类标签为真值；只统计门违例"""
        n = max(n or self.n_min, self.n_min)
        violations = 0
        for (x, outcome, human_ok) in self.audit_set.sample(n):
            pred = policy.propose_and_gate(x.cond)
            # 真值 = 人类验证；违例 = 策略放行但人类判不可行，或反之
            if pred.accepted != human_ok or not self._gates_hold(pred.x):
                violations += 1
        # 单边 Hoeffding/Clopper–Pearson 上界（真实违例率）
        ub = violations / n + sqrt(log(1.0 / self.delta_conf) / (2 * n))
        return AnchorResult(pass_audit=(violations == 0),
                            violation_ub=ub, n=n,
                            external_only=True)   # 不读策略自证

    def anchor_ok(self, x, region) -> bool:
        # 仅当 x 落在演示覆盖区域且最近审计通过才放行（界外 fail-closed）
        return (self.last_audit.pass_audit
                and self.cov is not None
                and self.cov.contains(x, region))

    def _gates_hold(self, x) -> bool:
        return all(kc_i(x) for i in SEVEN_GATES)   # 独立重算，不复用策略缓存
```

### IP-499 DPD：演示方案设计器（主动采集，离线）

```python
@dataclass
class DemonstrationPlanDesigner:
    """DPD：演示方案设计器。
    定理 11：Cov 在 z(x) 上单调子模 ⇒ 贪心 (1−1/e) 近似；
    PAC 覆盖样本复杂度下界 Ω(N(ε,R)·log(1/δ))"""
    budget: int                       # 演示预算（条数）
    eps: float                        # 裕度分辨率（覆盖球半径）
    near_boundary_shell: float = 0.15 # 近边界壳层权重（优先采）
    rare_gate_weight: float = 0.25    # 稀有门区域权重

    def z(self, x, domain: str) -> tuple:
        return tuple(margin_i(x, domain) for i in SEVEN_GATES)

    def coverage(self, D: list, R) -> float:
        # Cov(D) = μ( ∪_{x∈D} B_eps(z(x)) ∩ R )
        cells = set()
        for x in D:
            cells |= ball_cells(self.z(x), self.eps)
        return measure(cells & R.cells) + self.near_boundary_shell * measure(
            cells & R.boundary_shell) + self.rare_gate_weight * measure(
            cells & R.rare_modes)

    def plan(self, pool: list, R) -> list:
        """贪心最大化边际覆盖；预算 B 条演示"""
        D = []
        for _ in range(self.budget):
            best = max(pool, key=lambda c: self.coverage(D + [c], R)
                                           - self.coverage(D, R))
            D.append(best)
            pool = [p for p in pool if p is not best]
        return D

    def sample_complexity(self, R, eps, delta) -> int:
        # 覆盖 R 到分辨率 eps、置信 1−δ 所需样本数（覆盖数下界）
        return ceil(covering_number(R, eps) * log(1.0 / delta) / eps)
```

### IP-491 扩展 CERTCALC-v6：新增定理 9~13（离线理论）

```python
# 定理 9：迁移保守性 / 双证合取
def theorem_transfer_conservativeness() -> str:
    """
    定理 9（迁移保守性）：设目标门已重锚（C1）、φ 在 V_φ 上裕度非扩张（C2）、
```

### IP-500 EFA-v6：七硬门 + 迁移/锚定信任过滤 + v5 级联

```python
@dataclass
class EvidenceForgingAssemblerV6:
    """EFA-v6：七门不变；级联前置「迁移/锚定信任过滤」（附加合取，只紧）"""
    fmpp: FlowMatchingProposalPolicyKernel
    lmem: LongTermMemoryEmbeddingConsolidation
    famk: FacialAffectModulationKernel
    dtck: DomainTransferCertificateKernel
    dak: DemonstrationAnchorKernel
    v5: EvidenceForgingAssemblerV5          # 复用七门 + 调制 + 级联，逻辑不改

    def select(self, x0_state, t_now, rule_id, context) -> tuple[bool, Trajectory | None, str]:
        s_emo = self.famk.observe(context.face, t_now)
        gamma = self.famk.gamma(s_emo)                     # 全 1.0 = 退化 v5/v4
        c = build_ctx(context, s_emo, self.lmem)           # 含域/本体指纹 + 记忆 token
        cands = self.fmpp.propose(c, self.fmpp.K)
        # 前置信任过滤：迁移双证 OR 演示锚覆盖（域索引；只做合取，不改门）
        trusted = [x for x in cands if self._in_trust_region(x, context)]
        if not trusted:
            return self._fallback_rule_proposal(gamma)     # fail-closed 回退规则提议
        # 后续完全沿用 v5 级联：廉价门 → VACK → BCK；门谓词与阈值逻辑不变
        ok, best, tag = self.v5._cascade(trusted, gamma, context)
        return ok, best, (tag + '+CTDA' if ok else tag)

    def _in_trust_region(self, x, context) -> bool:
        if not self.dtck.validity(x):                      # φ 有效域外直接拒
            return self.dak.anchor_ok(x, context.region)
        ok_t, info = self.dtck.attest(x, context)          # 目标门 ∧ 非扩张 ∧ 源证书
        return ok_t or self.dak.anchor_ok(x, context.region)

    def ecs_v6(self, x, context, n_flow: float, s_emo) -> float:
        base = self.v5.ecs_v5(x, context, n_flow, s_emo)
        _, info = self.dtck.attest(x, context)
        eta_transfer = (1.0 if info['d_margin'] <= DELTA_MAX else 0.0)
        eta_anchor = (1.0 if self.dak.cov.contains(x, context.region) else 0.6)
        return base * eta_transfer * eta_anchor
```

## 4. 正确性论证（增量更新）

### 引理 45（裕度非扩张的传递误差界）

**陈述**：设 φ 在 V_φ 上对每门裕度满足 |m_i^T(x) − m_i^S(φ(x))| ≤ δ_i，且源域 φ(x) ∈ Exec_v5^S（即 m_i^S ≥ 0）。则目标域 m_i^T(x) ≥ −δ_i；若再要求 m_i^T(x) ≥ δ_i（保守缓冲），则 m_i^T(x) ≥ 0 且相对源的裕度损失 ≤ 2δ_i。∎

### 引理 46（审计上界的有限样本有效性）

**陈述**：n 个独立审计样本、审计器假阴性率 ≤ ε_fn，则策略真实违例率 p_v 的单边上界 ub = k/n + √(log(1/δ)/(2n)) 满足 P(p_v > ub + ε_fn) ≤ δ（k 为观测违例数）。证明：Hoeffding 不等式 + 审计漏检并集。∎

### 引理 47（覆盖函数的子模性）

**陈述**：Cov(D)=μ(∪_{x∈D} B_ε(z(x)) ∩ R) 对 D 单调且子模：Cov(A∪{c})−Cov(A) ≥ Cov(B∪{c})−Cov(B)（A⊆B）。证明：集合覆盖函数的标准子模性。∎

### 引理 48（无量纲守恒的误差传播）

**陈述**：若 ρ_i^T = ρ_i^* ± ε_ρ，则 τ_i^T 的相对误差为 ε_ρ/ρ_i^*；绝对安全裕度误差 ≤ ε_ρ·τ_i^{phys,T}。证明：比值误差传播。∎

### 定理 9（迁移保守性 / 双证合取）

**陈述**：在 (C1) 目标门重锚、(C2) φ 裕度非扩张、(C3) 迁移接受为附加合取 κ^transfer = ∧_i kc_i^T ∧ non_expansive ∧ source_attested 下：
(i) Exec_v6^T ⊆ V_φ ∩ Exec_gate^T ∩ φ^{-1}(Exec_v5^S)；
(ii) 源域 T=S 时 Exec_v6^S = Exec_v5^S ∩ anchor_ok ⊆ Exec_v5^S（只紧不松）；
(iii) 迁移不继承证书：存在源域认证但目标域违反的轨迹（反例见定理 12），故必须重锚。
**证明**：合取只缩不扩；源域 φ=id 使 non_expansive 恒真、source_attested 退化为门内，余 anchor_ok。(iii) 由量纲反例。∎

### 定理 10（演示锚定外部有效性 / 切断自指）

**陈述**：设 D_audit 从人类验证分布 i.i.d. 抽取，审计器假阴性率 ≤ ε_fn。若策略在 n 个审计样本上零违例通过，则其真实违例率 p_v 满足 P(p_v > ε_fn + √(log(1/δ)/(2n))) ≤ δ，且该界不依赖策略自我铸证。推论：R_anchor 内自指博弈率被外部真值约束；R_anchor 外无界，故 fail-closed。**证明**：引理 46。**诚实边界**：仅在 D_audit 分布内成立；选择偏差、分布偏移、审计器与策略共享盲区都会使界失效。∎

### 定理 11（演示方案子模近似与样本复杂度）

**陈述**：Cov 单调子模（引理 47），贪心预算 B 下 Cov(D_greedy) ≥ (1−1/e)·OPT；覆盖 R 到分辨率 ε、置信 1−δ 需 n ≥ Ω(N(ε,R)·log(1/δ))。**证明**：NEMHAUSER 贪心近似 + 覆盖数下界。∎

### 定理 12（跨本体无量纲守恒）

**陈述**：拷贝量纲阈值跨本体不 sound（反例：弱本体沿用强本体力矩阈值→不安全；强本体沿用弱本体→过度保守）。若无量纲安全比 ρ_i 跨本体守恒（容差 ε_ρ），则 τ_i^T = ρ_i^*·τ_i^{phys,T} 保持相对安全裕度，误差 ≤ ε_ρ·τ_i^{phys,T}。**证明**：量纲分析 + 引理 48。**诚实边界**：只保证相对裕度，绝对安全仍需目标本体物理标定。∎

### 定理 13（七锚完备性在迁移/锚定下保持）

**陈述**：v6 不增删锚点；DTCK/DAK/DPD 分别是域重锚通道、外部审计通道、离线采集程序。七锚 {3DCF, MSRG, HICK, EEK, LTEM, VACK, BCK} 完备性（v4 定理 4）保持。**证明**：锚点集合不变 + 附加合取只紧（定理 9）+ 审计不改门谓词。∎

### 定理 v6（执行集收缩与外部锚定，总装）

**陈述**：在 v5 假设 (B1)~(B7) 及新增 (B8) 重锚物理参数已知、(B9) 审计集与固化集不相交 下：
(i) 源域 Exec_v6^S ⊆ Exec_v5^S ⊆ … ⊆ Exec_v29（附加合取只紧）；
(ii) 迁移域 Exec_v6^T ⊆ Exec_gate^T ∩ φ^{-1}(Exec_v5^S)（双证交集，不继承证书）；
(iii) 锚定外部有效性由定理 10 界（分布内），界外 fail-closed；
(iv) 演示方案覆盖由定理 11 保证近似最优；
(v) 跨本体相对裕度由定理 12 守恒；
(vi) 七锚完备性保持（定理 13）。
**证明**：(i)(ii) 定理 9；(iii) 定理 10；(iv) 定理 11；(v) 定理 12；(vi) 定理 13。∎

**诚实声明**：(B8) 目标本体物理参数可能标定不全；(B9) 审计集与固化集若有泄漏则外部性失效；φ 的系统性盲区使迁移与演示非独立（本轮最大风险）；演示选择偏差与审计器漏检无结构兜底；绝对安全仍需实机标定。

## 7. 本轮最大风险（最终确认）

**一句话**：**伪独立外部锚**——迁移证书与演示锚都经由同一个抽象映射 φ 和同一套门裕度代理空间构造，并非独立证据源；若 φ 在某类接触模态/物体/操作者/文化上存在系统性盲区，迁移与演示会在同一盲区上「同时通过」，双证合取退化为相关性背书，而定理 10 的外部有效性界只在该代理分布内成立、界外静默失效，系统因此获得「已被外部验证」的错觉。
