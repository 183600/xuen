# 第 58 轮（承接第 57 轮「少样本×多模态×个性化」IP-133~138；本轮灵感：「单模型多任务」×「视觉-语言-动作模型」）

> 第 57 轮把安全的赌注从"模型置信"换到"证据质量"，再用元先验/OOD/共形、跨模态对账、个性化信任状态机把"证据质量"做成可校准、可对账、可有界的。但它仍默认两件事：**(a) 当前任务/上下文是已知且正确的**——所有证据都挂在一个已给定的"这是要做什么"上；**(b) 模型的产出只有动作与测量**——语言至多是解释（MXI），不参与承诺。本轮两个灵感正好击穿这两个默认：**单模型多任务**让一个共享主干同时承担行走、操作、导航等技能，效率来自参数共享，危险也来自参数共享——"共享参数"会被误当成"共享能力/共享证据"，一次错误的任务路由就能让 A 任务的校准证书去担保 B 任务的不可逆接触；**视觉-语言-动作模型（VLA）**把自然语言变成动作入口，流畅的 rationale 看起来像证据，实则只是"可信度很高的提议"——语言是**提案通道**，不是**测量通道**，把语言当证据就是"接地幻觉"。本轮核心升级：**证据必须任务作用域化（task-scoped），语言只能提案、每个承重命题必须被独立物理证据接地**。命题由"证据说可信"升级为 **"任务可识别、语言可提案、命题可接地的证据说可信"**（共享参数 ≠ 共享证据）。

核心矛盾：
- **H29（参数共享 vs 证据共享）**：单模型多任务用一套参数换效率与迁移；但能力、校准、证据都是按 (任务, 上下文) 切片定义的。共享主干让不同任务的置信度相互纠缠，错误路由会使"A 的证据"被当作"B 的证书"——效率与安全在"共享什么"上直接冲突。
- **H30（语言流利 vs 物理接地）**：VLA 的语言输出连贯、可解释、能被人理解，但连贯不等于正确；把 rationale 当证据，会把"最会说"的模型变成"最敢赌"的系统。可若完全不听语言，就丢掉了自然语言任务入口与人类监督。
- **H31（任务识别 vs 歧义鲁棒）**：任务身份本身是推断出来的，且有歧义。按单一 MAP 任务认证最省事，但第二可能的任务可能更危险；对歧义集取最坏情形最安全，却可能让系统过度冻结。安全与可用性在"如何对待歧义"上拉扯。

## 0. 直觉与动机

**灵感 1（单模型多任务 → 切片语义 + 迁移证书）**
直觉：一个共享主干同时学会走路、抓取、开门、导航，是边缘平台唯一付得起的"通用性"。但"一套参数"很容易被误读成"一套能力"：模型在 A 任务上校准良好，不代表它在 B 任务上也可靠；更糟的是，一次错误的任务路由会让 A 的证书去担保 B 的不可逆动作。真正的第一性原理是：**能力、校准、证据都必须按 (任务, 上下文) 切片来记账**。共享参数只提供"迁移的可能"，不提供"迁移的正确"；每一条跨切片复用都要有迁移证书 TransferCert 在留出切片上验过，否则按负迁移处理。于是"单模型"省下的是参数与样本，不是举证责任。

**灵感 2（VLA → 语言是提案，不是测量）**
直觉：VLA 让人可以用自然语言指任务，输出既有动作又有 rationale，读起来像"它知道自己在干什么"。但语言是**生成**的，不是**测量**的；流畅的理由和正确的世界之间没有必然联系。把 rationale 当证据，等于把"最会解释"的模型变成"最敢冒险"的系统。正确的分工是：**VLA 负责提出"该检查什么"（目标、计划、以及计划里那些承重命题——"这块地能站""这条路没堵"），物理证据负责回答"是否成立"**。rationale 的最大价值不是当证据，而是把隐含前提**显式化**为一张可检验命题清单；每一个承重命题都必须由独立探针/模态/访问接地。语言通道还要处理来源与权限：谁说这句话，决定它能否成为"意图"，但永远不能提升"证据等级"。这里有一个隐蔽陷阱：若把 lang 当成一个模态塞进第 57 轮的 XMC，由于语言由视觉派生，vision 与 language 会"天然一致"，制造出假的跨模态共识——所以本轮明确 **lang ∉ ℳ，且禁止任何 EV-lang**。

**灵感 3（合流 → 任务作用域证据 + 语言非增信）**
直觉：第 57 轮的安全界是"对检查点取 union bound"；本轮它要变成"**先对歧义任务集取并，再对检查点取并**"——因为真正危险的往往不是最可能的任务，而是第二可能的那个。于是证据键从 (区域, 模态, 断言) 变成 (区域, 任务切片, 模态, 断言)；不可逆承诺要求歧义集内每个任务都被认证、且所有承重命题都被接地。两条新的"非增信"性质把语言和共享参数都关进笼子：**语言越流畅不改变 P_fail，共享参数越多也不改变 P_fail**——它们只能改善效率、提案质量与解释可读性，只能经"更准（含消歧）"或"更保守（拒答/降档/询问）"两个安全通道起作用。

**灵感 4（证据门：新增接地与迁移两类，明确一条禁列）**
直觉：不靠堆类，而是补齐语义：**EV-ground**（为承重命题提供独立物理证据）与 **EV-trans**（带迁移证书的跨任务证据，仅 L0/L1）；同时**禁止 EV-lang**，并把 EV-xmodal 也任务作用域化。不可逆接触的必要证据集 = 歧义集内每个任务的 {EV-probe*∨EV-margin} + 接地覆盖 cov=1，EV-xmodal/EV-trans/EV-human 永不入此集。两条硬规则：**接地否决优先于语言提议**；**来源越权不能变成证据**。

**灵感 5（PCE-T → 探-识-接-诺-演）**
直觉：把 PCE+ 的检查点循环前面加两级——**先识别任务、再接地命题**，最后才是原来的探询/承诺。消歧探针与接地探针共享预算但用途不同：前者分开"这是哪个任务"，后者回答"这个前提是否成立"。任何一级失败都退回保守默认（询问/绕行/降档/L2/停），而不是继续用 MAP 任务硬闯。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（单模型多任务切片语义 TSS）** 共享主干 f_θ 与任务族 𝒯={t_1,…,t_K}，技能 π_t；上下文 c∈𝒞（地形/材质/负载/指令域）。部署切片 s=(t,c)。切片能力证书 Cap(t,c)=(n_{t,c}, ECE_{t,c}, k\*_{t,c}, cover_{t,c}, certified)，certified(t,c)⇔n_{t,c}≥n_min ∧ ECE_{t,c}≤ε_slice ∧ cover_{t,c}≥1−α_slice。任务后验 β_t=P(t|o_{1:k},ℓ,c)，歧义集 𝒯_amb(α_t)={t:β_t≥ε_t}（或最小 top-set 使 Σ_{t∈𝒯_amb}β_t≥1−α_t）。证据键 key=(r,t,m,claim)，断言必须语义属于 t 方可写入。迁移证书 TransferCert(t→t′)=(I_{t→t′},n_ver,ε_tr)：声明共享表示不变式 I 并在留出切片上验证 n_ver 次、误差≤ε_tr；无证书禁止跨切片复用证据（按负迁移默认）。**路由门**：执行 π_t 需 certified(t,c) ∧ t∈𝒯_amb ∧ max_t β_t≥θ_task。

**定义 140（语言提案通道 LPC）** VLA 输出 V(o,ℓ)=(π̂,R,conf,ℓ)，提案 Prop=(g,π̂,P_LB,I(ℓ),source)：目标 g、计划 π̂、承重命题集 P_LB（"地面可承重""通道无障""物体可抓"…）、语言诱导意图集 I(ℓ)、来源 source(ℓ)。**接地义务**：∀p∈P_LB 存在独立物理证据 e_p（探针/模态/访问），记入接地台账 L；grounded(p)⇔L(p) 存在且版本有效；覆盖率 cov=|grounded|/|P_LB|。**禁列**：ℓ、R、conf 不得作为任何 EV-\*；lang∉ℳ（否则成为共同因，伪造 XMC 一致）。**歧义**：|I(ℓ)|>1 且未被接地消歧 ⇒ 需 L2 询问或保守默认。**来源权威**：authority(source)∈授权格，只能决定 ℓ 能否作为意图（经 PTM），永不提升证据等级；注入/越权由 source 标签与授权格拦截。

**定义 141（任务识别与消歧门 TIG）** 更新 β/𝒯_amb；**任务 OOD**：max_t β_t<θ_task 或 𝒯_amb 跨越不同危险级 ⇒ 按 OOD 处置（禁不可逆）。消歧：选 π_d=argmax_q[IG(q;𝒯_amb)−cost(q)]，预算 k_dis；仍歧义且危险级跨级 ⇒ 询问（L2）或保守默认。路由仅在 certified 切片且任务确定后进行。

**定义 142（接地台账 GLC 与接地门 G-gate）** 台账 L:(p→(key,modality,version))；cov 如上。G-gate 通过 ⇔ cov=1 ∧ 每个 e_p 的 version 在提交时有效（沿用第 57 轮证据版本思想，本轮只要求版本一致，不引入完整事务）。**接地否决**：若 e_p 与某 t∈𝒯_amb 的结论矛盾 ⇒ 拒绝该提案，优先级高于任何语言提议。

**定义 143（任务作用域证据门 TSE 与证书 J_t）** 证据类 EV-probe\*(t)/EV-visit(t)/EV-margin(t)/EV-xmodal(限L1,t-scoped)/EV-human/**EV-trans**(须TransferCert,限L0/L1)/**EV-ground**(命题接地)；**禁 EV-lang**。不可逆接触必要证据集 = ∀t∈𝒯_amb:{EV-probe\*(t)∨EV-margin(t)} ∪ {cov=1}；EV-xmodal/EV-trans/EV-human 不入此集（human 只作佐证）。J_t=J_p⊕(β,𝒯_amb,Cap,transfer_log,L,cov,source_log,disambig_log)，继承 J_p 全检。

**定义 144（探-识-接-诺-演 PCE-T）** 每检查点：①VLA 提案 Prop；②任务识别 β/𝒯_amb/任务 OOD；③接地 P_LB，预算 k_grnd；④跨危险级歧义 ⇒ 消歧探针 k_dis 或询问；⑤承诺 ⇔ T-gate（歧义集全 certified ∧ max_t β_t≥θ_task）∧ G-gate（cov=1）∧ TSE；⑥否则对最坏任务取悲观 VOI 探询；⑦探尽→绕行→降档→L2(τ_int)→安全停；终止于 k_probes+k_cons+k_grnd+k_dis。

## 2. 关键算法伪代码（完整版见产物区）

```python
def task_route(o, ell, c, model, cert, eps_t, theta_task):
    beta = model.task_posterior(o, ell, c)          # 单主干 → 任务后验
    amb  = {t for t, p in beta.items() if p >= eps_t}
    if max(beta.values()) < theta_task: return None, amb, 'task_ood'
    if spans_danger(amb):               return None, amb, 'need_disambig'
    t = argmax(beta)
    if not cert.certified(t, c):        return None, amb, 'slice_uncertified'
    return t, amb, 'ok'

def ground(prop, M, probes, budget):     # IP-140/142: 语言只提案，物理接地
    ledger = {}
    for p in prop.P_LB:
        if p.only_from_language: return None, 'ungrounded_proposition'
        e = acquire_independent_evidence(p, M, probes, budget)
        if e and e.version_valid(): ledger[p] = e
    return ledger, len(ledger) / max(1, len(prop.P_LB))

def commit_gate(T, G, ev, taskev):       # T-gate ∧ G-gate ∧ TSE
    return T.ok and G.cov == 1.0 and taskev.ok and 'EV-lang' not in ev
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| TSS | O(K·d_φ+\|𝒯_amb\|) | O(\|𝒯\|·\|𝒞\|·d_cert) | 切片证书诚实、路由完备（A41） |
| LPC | O(\|P_LB\|·d_p) | O(\|Prop\|) | P_LB 完整、来源可审（A43/A44） |
| TIG | O(K·d_φ+k_dis·d_o) | O(K) | 任务 OOD 漏检 ≤δ_task（A45） |
| GLC | O(\|P_LB\|·d_grnd) | O(\|P_LB\|) | 接地独立、版本有效（A42） |
| TSE | O(\|σ\|·\|𝒯_amb\|) | O(\|σ\|·\|𝒯_amb\|) | 歧义集全覆盖、禁 EV-lang |
| PCE-T | O(\|CP\|·(\|𝒯_amb\|·k_p+k_c+k_grnd+k_dis)·(C_VOI+d_φ)) | O(\|V\|+\|σ\|+\|Prop\|) | 预算终止、四态完备 |

**正确性定理（任务-接地健全性 TGS 概要）**：在 A33–A40 上加 (A41) 切片能力证书诚实且路由完备；(A42) 接地证据独立于提案且版本有效；(A43) P_LB 覆盖计划的所有承重前提（完整性假设）；(A44) 语言来源/权限与信任台账诚实，语言永不进入证据类；(A45) 任务族覆盖真实任务且任务别名可检出。则：(i) **任务作用域健全性** P(fail|不可逆)≤Σ_{t∈𝒯_amb}[δ_f+ε_meta^t(k)+δ_probe+ε_h+δ_ood·α_conf+δ_xm·1[L1]]+δ_tr·N_trans，歧义集越大界越松——界本身成为"该消歧"的信号；(ii) **语言非增信**：固定来源权限下，P_fail 对 rationale 内容与置信度不敏感，语言只能改变提案质量/解释，不能改变证据等级；(iii) **接地必要性**：cov<1 或存在未接地承重命题 ⇒ 不可逆承诺被拒，接地否决优先；(iv) **迁移健全性**：跨切片复用仅在 TransferCert 下，负迁移漏检 ≤δ_tr；(v) **终止性**：PCE-T 在 k_probes+k_cons+k_grnd+k_dis 内终止于 {承诺, 绕行, 降档, L2 协商, 安全停}。

## 6. 本轮最大风险

**一句话**：本轮的安全界是相对两张"清单"成立的——任务清单 𝒯 与承重命题清单 P_LB；真实世界可以同时越出这两张清单：未知任务伪装成已知任务（任务别名），计划的隐含前提又没被列进 P_LB（命题遗漏），而单模型越自信、语言越流畅，这两张清单的缺口越难被人发现——任务作用域证书只能保证"对 𝒯_amb 中的任务安全"，对 𝒯 之外、命题之外的世界无能为力。

# 第 58 轮产物 · 创新点清单 v35：Task-Grounded-VLA（任务切片×语言提案×接地承诺，TSS×LPC×TIG×GLC×TSE×PCE-T）

> 承接第 57 轮 IP-133~138（MFSL/XMC/PTM/MXI/FSE/PCE+）与第 56 轮 IP-127~132（SMM/PCE/BVK/ISE/TAF/MEC）。本轮把部署前提从"少样本可校准、跨模态可对账、个性化有界的证据承诺"推进为 **"任务可识别、语言可提案、命题可接地的证据承诺"**：单主干多任务的共享参数不再被当作共享证据，能力/校准/证据一律按 (任务, 上下文) 切片记账并要求迁移证书；VLA 的自然语言只作为**提案通道**，其 rationale 用来把隐含前提显式化为承重命题，每个命题必须被独立物理证据接地，语言本身被明确排除在证据类之外。第 57 轮"一切判定器走隔离"在本轮推广为"**一切承重命题走接地，一切任务结论走切片证书**"。

## 2. 关键算法伪代码

### IP-139 TSS（切片语义、路由门与迁移证书）

```python
def task_posterior(o, ell, c, model):
    return softmax(model.shared_trunk_and_task_head(o, ell, c))   # 单主干多任务

def ambiguity_set(beta, eps_t):
    return {t for t, p in beta.items() if p >= eps_t}             # 或最小 top-set

def route_skill(o, ell, c, model, cert, eps_t, theta_task):
    beta = task_posterior(o, ell, c, model)
    amb  = ambiguity_set(beta, eps_t)
    if max(beta.values()) < theta_task:
        return None, amb, 'task_ood'                              # 任务不确定 → OOD
    if spans_danger(amb):
        return None, amb, 'need_disambig'                         # 危险级跨级
    t = argmax(beta)
    if not cert.certified(t, c):
        return None, amb, 'slice_uncertified'                     # 该切片未认证
    return t, amb, 'ok'

def evidence_reuse_ok(t_from, t_to, transfer_log, n_ver, eps_tr):
    cert = transfer_log.get((t_from, t_to))
    if cert is None: return False                                 # 无证书 = 负迁移默认
    return cert.invariant_tested() and cert.error(n_ver) <= eps_tr
```

### IP-140 LPC + IP-142 GLC（语言提案 → 承重命题 → 物理接地）

```python
def vla_propose(o, ell, src):
    plan, rationale, conf = vla(o, ell)
    P_LB = load_bearing_propositions(plan)       # 把"能站/没堵/可抓"等显式化
    I    = intent_set(ell)                       # 语言诱导的意图集
    return Proposal(goal=plan.goal, plan=plan, P_LB=P_LB, I=I,
                    source=src, rationale=rationale, conf=conf)

def ground_propositions(prop, M, probes, budget):
    ledger = {}
    for p in prop.P_LB:
        if p.only_from(('language', 'rationale')):
            return None, 0.0, 'ungrounded_proposition'            # 语言不是测量
        e = acquire_independent_evidence(p, M, probes, budget)    # 探针/模态/访问
        if e is None or not e.version_valid():
            continue
        ledger[p] = e
    cov = len(ledger) / max(1, len(prop.P_LB))
    return ledger, cov, 'ok'

def grounding_gate(ledger, P_LB, commit_time):
    if any(p not in ledger for p in P_LB): return 'reject'
    if any(not ledger[p].version_valid(commit_time) for p in P_LB):
        return 'reject'                                          # 提交时读版本已失效
    for p, e in ledger.items():
        if contradicts_any(amb, p, e): return 'reject'           # 接地否决优先
    return 'ok'
```

### IP-141 TIG（任务识别、任务 OOD 与消歧）

```python
def identify_and_disambiguate(o, ell, c, model, budget):
    beta = task_posterior(o, ell, c, model)
    amb  = ambiguity_set(beta, eps_t)
    if max(beta.values()) < theta_task:
        return None, amb, 'task_ood'
    while len(amb) > 1 and spans_danger(amb):
        if budget.disambig_left <= 0:
            return None, amb, 'ambiguous_no_budget'              # 保守默认
        q = argmax_disambiguating_probe(amb, o, model,
              key=lambda x: IG(x, amb) - cost(x))
        o = o + execute_probe(q); budget.spend_disambig(q)
        beta = task_posterior(o, ell, c, model)
        amb  = ambiguity_set(beta, eps_t)
    if len(amb) > 1 and still_spans_danger(amb):
        return None, amb, 'ask_human'                            # L2 询问
    return max(beta, key=beta.get), amb, 'ok'
```

### IP-143 TSE（任务作用域证据门 + 证书 J_t）

```python
def task_sliced_evidence_gate(c, M, persona, ood_reg, task_ctx):
    amb, ledger = task_ctx.amb, task_ctx.ledger
    if c.ev == 'EV-probe*':
        ok = all(calibrated_slice(c, t) and c.slice_t == t for t in amb)
    elif c.ev in ('EV-visit', 'EV-margin'):
        ok = all(round56_checks(c.scope(t), M) for t in amb)
    elif c.ev == 'EV-xmodal':
        ok = c.level == 'L1' and c.slice_t in amb and D(c.region) <= theta_D
    elif c.ev == 'EV-trans':
        ok = c.level in ('L0', 'L1') and evidence_reuse_ok(
                c.src_task, c.slice_t, c.transfer_log, c.n_ver, eps_tr)
    elif c.ev == 'EV-ground':
        ok = c.proposition in ledger and ledger[c.proposition].version_valid()
    elif c.ev == 'EV-human':
        ok = persona[c.op].auth >= 'A1' and c.corrob >= quarantine_exit(persona[c.op].auth)
    elif c.ev == 'EV-lang':
        return ('reject', 'language_is_not_evidence', c)          # 硬禁令
    else:
        return ('reject', 'no_evidence_class', c)
    if c.irreversible and c.ev in ('EV-xmodal', 'EV-trans'):
        return ('reject', 'xmodal_or_trans_on_irreversible', c)
    if not ok:
        return ('reject', 'evidence_insufficient', c)
    return ('ok', c)

def task_grounded_certificate(sched, M, task_ctx, transfer_log, persona, ood_reg):
    if task_ctx.ledger_cov < 1.0:
        return ('reject', 'grounding_incomplete')
    if not all(certified(t, task_ctx.c) for t in task_ctx.amb):
        return ('reject', 'slice_uncertified')
    for c in contacts(sched):
        st = task_sliced_evidence_gate(c, M, persona, ood_reg, task_ctx)
        if st[0] != 'ok': return st
    if min(x.K_margin for x in sched) < budgets.theta_K: return ('reject', 'K_margin')
    if rho_sem(sched, M) < budgets.rho_min:              return ('reject', 'rho_sem')
    if not all(l2.resolved for l2 in consent_log):       return ('reject', 'consent_open')
    return ('ok', Jt(task_ctx.beta, task_ctx.amb, task_ctx.cap, transfer_log,
                     task_ctx.ledger, task_ctx.cov, source_log, disambig_log,
                     M.core, probe_log, consent_log))
```

### IP-144 PCE-T（探-识-接-诺-演）

```python
def task_grounded_commit(x0, o, ell, M, budget, consent, personas):
    prop = vla_propose(o, ell, src=active_source())             # ① 语言提案
    t, amb, st = identify_and_disambiguate(o, ell, ctx(o), model, budget)  # ② 任务识别
    if st not in ('ok',):
        return conservative_default(st, prop, consent)          # 询问/绕行/降档/停
    ledger, cov, gst = ground_propositions(prop.P_LB, M, admissible_probes, budget)  # ③ 接地
    if gst != 'ok' or cov < 1.0:
        return ask_or_abstain(prop, ledger, amb)                # 接地不满即不冒险
    task_ctx = TaskCtx(t=t, amb=amb, cap=Cap, ledger=ledger, cov=cov)
    route = plan_on_map(M, prop.goal, risk_model, tasks=amb)     # 对歧义集规划
    sched, log = [], []
    for cp in route.checkpoints:
        inf = meta_few_shot_infer(M, cp.region, M.obs[cp.region], meta, slice=t)
        M.b[cp.region] = inf.post if inf.cls == 'ID' else worst_in(inf.belt)
        sigma = foothold_schedule(x0, cp, M); R = schedule_risk(sigma, M)
        while select_gait(R) == 'halt' and budget.probes_left > 0:
            p = argmax(admissible_probes(cp, M, F_abs),
                       key=lambda q: voi_meta_pessimistic_over(amb, q, M) - cost(q))
            if voi_meta_pessimistic_over(amb, p, M) < theta_voi: break
            M, _, D = xmodal_fuse(M, cp.region, execute_probe(p, cap=F_abs))
            if D > theta_D and 'consensus' not in cp.done:
                M, _, D = xmodal_fuse(M, cp.region,
                          execute_probe(most_disagreeing_modality_probe(M, cp.region)))
                cp.done.add('consensus')
            sigma = reselect_footholds(x0, cp, M); R = schedule_risk(sigma, M)
            budget.spend(p)
        T = max(beta, key=beta.get) in amb and certified(t, cp.context)
        G = grounding_gate(ledger, prop.P_LB, commit_time=now())
        ev = tag_evidence_p(sigma, M, contact_level(cp), slice=t)
        if select_gait(R) != 'halt' and T and G == 'ok' \
           and task_grounded_certificate(core_contact(cp), M, task_ctx,
                                         transfer_log, personas, ood_reg)[0] == 'ok':
            sched.append(commit(sigma, select_gait(R))); log.append(ev); continue
        alt = reroute_over(amb, M, cp, risk_model)
        if alt and select_gait(schedule_risk(alt, M)) != 'halt': route = alt; continue
        return negotiate_or_stop(cp, M, sigma, R, consent,
                                 tau_int=tau_int(personas.active.auth))
    return sched, log, M
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| TSS | O(K·d_φ+\|𝒯_amb\|) / 路由；O(\|A_s\|) 证书查询 | O(\|𝒯\|·\|𝒞\|·d_cert) | 切片证书诚实、路由完备（A41） |
| LPC | O(\|P_LB\|·d_p) 解析 | O(\|Prop\|) | P_LB 完整、来源可审（A43/A44） |
| TIG | O(K·d_φ+k_dis·d_o) | O(K) | 任务 OOD 漏检 ≤δ_task（A45） |
| GLC | O(\|P_LB\|·d_grnd) | O(\|P_LB\|) | 接地独立、版本有效（A42） |
| TSE | O(\|σ\|·\|𝒯_amb\|) | O(\|σ\|·\|𝒯_amb\|) | 歧义集全覆盖、禁 EV-lang |
| PCE-T | O(\|CP\|·(\|𝒯_amb\|·k_p+k_c+k_grnd+k_dis)·(C_VOI+d_φ)+\|CP\|·A\*) | O(\|V\|+\|σ\|+\|Prop\|) | 预算终止、四态完备 |

**正确性定理（Task-Grounded VLA Soundness, TGVS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 切片能力证书诚实且路由完备：certified(t,c) 为真时该切片的 ECE/覆盖声明可信，未认证切片不得路由；**(A42)** 接地证据独立于 VLA 提案（不来自语言/rationale），且提交时读版本有效；**(A43)** P_LB 完整覆盖计划的所有承重前提（若前提被遗漏，则 cov 会虚高——这是显式假设而非可证性质）；**(A44)** 语言来源/权限与信任台账诚实，语言永不进入证据类；**(A45)** 任务族 𝒯 覆盖真实任务且任务别名可检出（漏检率 ≤δ_alias）。则：

1. **任务作用域健全性**：不可逆承诺的失效率

```
P(fail | irreversible) ≤ Σ_{t∈𝒯_amb} [δ_f + ε_meta^t(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1]]
                        + δ_tr·N_trans
```

歧义集越大，界越松；该界本身就是"此处应当消歧/询问"的可计算信号，而不再是一个需要人工调参的启发式。

2. **语言非增信（Language neutrality）**：固定 source 权限后，P(fail) 对 rationale 的内容与 VLA 自评 conf 不敏感。语言只能经 (a) 提供提案目标（仍须过 T/G/TSE 门）或 (b) 生成解释影响系统；不存在"更流畅 ⇒ 更敢赌"的通道。
3. **接地必要性**：若 cov<1 或存在未接地承重命题，或接地证据与歧义集内某任务结论矛盾，则不可逆承诺被拒；接地否决的优先级高于任何语言提议。
4. **迁移健全性**：跨切片证据复用仅在 TransferCert 成立时被接受，负迁移漏检 ≤δ_tr；无证书默认按负迁移。
5. **终止性**：每检查点消歧探针 ≤k_dis、共识探针 ≤k_cons、接地探针 ≤k_grnd，PCE-T 在 k_probes+k_cons+k_grnd+k_dis 内终止于 {承诺, 绕行, 降档, L2 协商, 安全停}。
6. **部署界**（对检查点、歧义任务取联合界）：

```
P_safe ≥ 1 − Σ_cp Σ_{t∈𝒯_amb} (δ_f + ε_meta^t(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1])
             − δ_tr·N_trans − δ_grnd·N_grnd − δ_alias·N_task
             − P(接地台账陈旧未检出) − P(询问/超时失效)
```

关键：**共享参数给效率与迁移，切片证书给责任边界**；**语言给"该检查什么"，物理证据给"是否成立"**；**歧义集给可计算的保守性**。三条设计共同保证：单模型与 VLA 只能经"更准（含消歧）"或"更保守（询问/拒答/降档）"两个安全通道改变风险，绝不能因为"参数共享"或"说得流畅"而提高承诺等级。

## 6. 本轮最大风险

**一句话**：本轮的安全界是相对两张"清单"成立的——任务清单 𝒯 与承重命题清单 P_LB；真实世界可以同时越出这两张清单：未知任务伪装成已知任务（任务别名），计划的隐含前提又没被列进 P_LB（命题遗漏），而单模型越自信、语言越流畅，这两张清单的缺口越难被人发现——任务作用域证书只能保证"对 𝒯_amb 中的任务安全"，对 𝒯 之外、命题之外的世界无能为力。
