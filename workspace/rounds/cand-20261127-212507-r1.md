## 1. 直觉与动机（两个灵感的碰撞）

### 灵感 1（柔顺控制 → 没有力传感器时，柔顺不是力控环，是「会退让的离散轨迹」）

直觉：经典柔顺控制（阻抗/导纳）要求力/力矩闭环，至少要有 F/T 或关节力矩；F21/F22 明确评测接口只有绝对位姿目标，连速度都没有。所以**主动柔顺在计分面上不能直接实现**。但柔顺的本质不是「算力矩」，而是「接触时不要硬顶」：接近慢、接触软、受阻退、滑移停、卡住重试。这些都可以在**动作块层面**用离散轨迹纪律实现：

1. **跟踪误差是免费的接触代理**：我们命令 `T_c`，观测到 `T_o`；接触受阻时 `e = log(T_c^{-1} T_o)` 会在运动反方向持续增大。它不需要额外传感器，是接口免费给的一阶信号。
2. **离散导纳 = 把目标按比例拉回观测**：不直接命令 `T_d`，而命令 `T_c = T_o · Exp(Λ · log(T_o^{-1} T_d))`，`Λ` 小则软、大则硬。受阻时 `T_o` 不动，`T_c` 自然只前进一小步——这是**位置接口上的被动退让**。
3. **块内无反馈，块间有反馈**：F23 意味着一个 chunk 内不能根据接触实时改动作；但下一帧观测的叠帧历史（F26）给了块内轨迹，可用于估计实际速度与接触起始。柔顺的反馈带宽被 `T_a` 锁死，这是设计约束而不是实现细节。
4. **无源预算**：不知道接触刚度，就假设最坏刚度 `K_max`，把每步命令位移限制在 `F_safe/K_max`，并给整段接触一个能量预算 `B_max`。这不是力控，但是可审计的「不会越顶越狠」的保证。

核心反直觉点：**在位置接口上，最好的柔顺不是「加一个力控器」，而是「把接触时不再前进编码成离散导纳 + 位移/能量预算 + 块边界退让」；跟踪误差是信号，但它的可用带宽由 `T_a` 决定。**

### 灵感 2（末端执行器控制 → 真正的战场是 SE(3) 几何，不是「选 ee 模式」）

直觉：看到「末端执行器控制」，第一反应是把 `control_space` 设成 `"ee"`。但 F21 说 EE 动作是**绝对位姿 + RPY**，这带来三类隐形损失：

1. **表示病**：RPY 在 ±π 处有包裹跳变，在 pitch≈±90° 有万向锁；模型在 RPY 空间做回归/线性插值，会在块边界产生 2π 跳变、腕部翻转、非测地线插值。
2. **坐标病**：绝对 base 坐标要求模型记住「桌子在哪、目标在哪」；同一技能换个位置就要重新回归，浪费了 SE(3) 的平移/旋转等变性。
3. **冗余病**：7 自由度单臂对 6 维 EE 位姿有 1 维零空间（F27）；原生 `ee` 模式的 IK 选哪组肘部构型是黑箱，块间可能突然换构型，导致腕部相机抖动、抓取失败。

对应的三步修复：
- **SE(3) 规范化**：RPY→旋转矩阵/四元数，沿块做符号连续与角度解包，测地线重采样，再转回连续 RPY；
- **相对位姿参数化**：训练时让动作头预测「相对 chunk 起点的 SE(3) 增量」，推理时与当前观测位姿复合，天然平移不变、无 RPY 包裹；
- **可行性治理**：用关节状态做 FK/Jacobian 校验，检测奇异/不可达/超限，向当前位姿回缩；必要时改用关节空间 OSC 包装，显式控制零空间姿态。

核心反直觉点：**末端控制的最大收益不在「换控制空间」，而在「把 RPY 绝对位姿换成 SE(3) 相对位姿 + 测地线整形」——这一步对 32 个任务都免费生效，且不依赖任何新传感器。**

### 灵感 3（两者统一 + 现有清单）

- 柔顺控制回答「接触任务怎么不硬顶」：I11 的离散无源柔顺壳 + I12 的任务流形虚拟夹具；
- 末端执行器控制回答「动作块怎么在 SE(3) 上合法、平滑、可达」：I10 的几何层 + I13 的可选 OSC；
- 现有数据引擎（I1/I2/I5）回答「这些纪律怎么变成训练信号」：EE 相对轨迹增广、接触相位标签、卡死/滑移/冲击的失败示教；
- 现有评测闭环（I8）回答「怎么在稀缺真机上验证」：把接触 AUROC、朝向连续性、能量预算、`T_a` 扫描纳入 L0/L1/L2。

本轮结论：**前两轮把胜负手押在数据侧；本轮把它推进到动作侧纪律——模型可以不变，但同一组动作块经过 SE(3) 几何 + 离散无源柔顺，会变得更平滑、更会退让、更少卡死。数据侧与动作侧不是竞争关系：动作侧纪律决定「同样的模型能拿多少分」，数据侧决定「模型上限在哪」。**

### 1.4 严谨定义（先直觉后形式化）

**D1（SE(3) 动作块与连续性）**：一个 chunk 是 `A = {(p_k, η_k)}_{k=0}^{T_a-1}`，`p_k∈R^3`，`η_k∈R^3` 为 RPY。令 `T_k=(R(η_k), p_k)∈SE(3)`。定义朝向连续性 `Φ(A)=max_k d_SO3(R_k,R_{k+1})`，RPY 跳变 `Ψ(A)=max_k ||η_{k+1}-η_k||`。规范化为 `C(A)`：选四元数 `q_k` 使 `q_k·q_{k-1}≥0`，并对 `η_k` 加 `2π n_k` 使 `Ψ(C(A))` 最小。目标是最小化 `Φ` 与 `Ψ`，同时不改变 `R_k` 的物理含义。

**D2（离散导纳）**：给定观测 `T_o=(R_o,p_o)` 与期望 `T_d=(R_d,p_d)`，任务系各向异性增益 `Λ_p,Λ_R≻0`，命令
`p_c = p_o + R_o Λ_p R_o^T (p_d-p_o)`，
`R_c = R_o Exp(Λ_R log(R_o^T R_d))`。
`Λ=αI` 时退化为各向同性软硬调节；`α→0` 为保持，`α=1` 为直接跟踪。对 chunk 内每个 `T_d,k` 施加同一 `T_o`（chunk 起点），得到 `T_c,k`。

**D3（无源预算）**：设接触刚度上界 `K_max`，安全力 `F_safe`，令 `Δ_max=F_safe/K_max`。若 chunk 满足
`||p_c,k-p_c,k-1|| ≤ Δ_max` 且 `Σ_k (||Δp_k||+r||Δθ_k||) ≤ B_max`，
则准静态最坏接触力 ≤ `F_safe`，注入功 ≤ `F_safe B_max`（假设环境被动、低层能跟踪命令）。这是保守的可审计界，不是力控稳定性证明；它不覆盖冲击，冲击由速度/加速度限与接近相位软启动控制。

**D4（接触可辨识性）**：令跟踪误差 `e_k=||log(T_c,k^{-1} T_o,k)||`，观测速度 `v_o,k`。若 `e_k>ε`、`e_k-e_{k-1}>δ`（误差没有在收敛）、且 `v_o,k` 与 `p_c,k-p_o,k` 方向相反，连续 `m` 个 chunk 成立，则判为接触；若 `e_k` 大但在收敛，判为执行器滞后而非接触。用 AUROC 评估检测器（标签来自仿真接触真值或人工标注），误报成本 = 变怂导致的时间/步骤分损失。

**D5（柔顺带宽）**：控制频率 `f`、块长 `T_a` 时，最坏情况下策略每 `T_a/f` 秒才能更新一次柔顺决策，接触反应带宽 ≤ `f/(2T_a)`（Nyquist）。因此 `T_a` 不只是速度参数，而是**柔顺设计参数**：接触任务需要小 `T_a`，自由空间需要大 `T_a`；一次提交只能选一个，必须在 L0/L1 上做全局折中。

**D6（任务流形虚拟夹具）**：任务流形 `M⊂SE(3)`（直线插入/圆弧倾倒/铰链旋转/竖直堆叠）。投影 `T_proj=Π_M(T_d)`，命令 `T_c=T_o Exp(Λ log(T_o^{-1}T_proj))`，其中法向刚度高（不允许偏出流形）、切向刚度低（允许沿任务方向运动）。例如插入：`M={p=p0+s a, R=R_align(a)R_roll(φ)}`，投影消去横向误差并对齐工具轴。

## 2. 对前两轮痛点的增量修订

- P4（无触觉）从「不可解」降级为「可绕过」：I11 用跟踪误差 + 位移预算，I12 用任务流形先验；都不要求评测时有力。
- P5（时间压力）补充：`T_a` 固定（F20）→ 删除「自适应 chunk 长度」，改为「固定 `T_a`、块内容相位化」；`T_a` 的选择本身成为实验变量。
- P6（延迟）升级：接触任务需要更小的 `T_a` 才够反应，但小 `T_a` 增加推理频率；用 p99 + 柔顺带宽共同定档。
- P8（示教质量）补充：接触段质量不只看进度，还要看「跟踪误差是否平滑、有无冲击、有无卡死」；I5 增加接触失败模式。
- 新增 P9（RPY/绝对位姿病）：朝向跳变、万向锁、绝对坐标回归、7 自由度零空间黑箱，是全局性、低成本的隐性损失。
- 新增 P10（跟踪误差歧义）：`e` 也受执行器滞后、重力、摩擦影响；误判接触会让策略变怂，必须方向一致性 + 持续性 + 视觉确认。
- 新增 P11（柔顺带宽）：`T_a` 锁死块间反馈频率；任何「实时柔顺」的承诺都必须按 `f/(2T_a)` 打折。
- 新增 P12（单模型边界）：I11/I12 是动作后处理还是「第二模型」，需书面确认；确认前只上纯运动学/几何 guard，或把流形先验蒸馏进策略。
- 新增 P13（原生 IK 黑箱）：`ee` 模式的 IK/零空间不可控；I13 的关节空间 OSC 是备选，不是默认。

## 4. 设计原则（新增 PR6–PR10，其余保留）

- **PR6 动作几何先行律**：任何柔顺/guard 之前，先把动作块规范化到 SE(3)（符号连续、测地线、可行性）。几何错误会放大后续所有补偿。
- **PR7 离散无源律**：每条接触轨迹必须有有界单步位移 `Δ_max` 与总预算 `B_max`；禁止无界向阻力方向推进；预算耗尽即退让/重试。
- **PR8 退让优先律**：跟踪误差持续且方向与运动相反时，先保持/微退，再重试；绝不靠加大命令去「顶过去」。
- **PR9 单一动作空间律**：一次提交只选 `joint` 或 `ee`；I13 的 OSC 是独立候选，不与 I10/I11 混在同一提交里；禁止在同一 episode 内切换控制空间。
- **PR10 可审计律**：记录 `α`、`e`、`B`、接触相位、朝向连续性 `Φ/Ψ`，供 L0/L1/L2 归因；没有日志的柔顺不算柔顺。
- PR1–PR5 保留（第 2 轮 §4）。

| I11 | 离散无源柔顺壳（新） | 新增：跟踪误差接触检测 + 各向异性导纳 + 位移/能量预算 + 块边界退让 | P4/P5 | 12–15 接触任务 | 高 | 低 | ★★★★★ |

## 6. 本轮最大风险

**一句话**：整轮押在「跟踪误差能在一个 chunk 内可靠区分接触与执行器滞后/重力/摩擦」——若接触检测 AUROC 不够高，I11 会让策略在自由空间也变怂（丢时间/步骤分），或在真接触时仍硬顶（卡死/撞飞）；而 `T_a` 锁死的反馈带宽让「实时柔顺」最多只能做到 `f/(2T_a)`，所以 I11 必须先过 L0 的 AUROC/误报-漏报成本闸，再谈真机放量。

## 0. 核心决策：把「动作块」当成一等公民

| 层 | 输入 | 输出 | 本轮落点 | 是否在计分路径 |
|---|---|---|---|---|
| 数据层 | 32 任务 + 110 语料 + 增广 | 示教、权重、失败示教 | I1 / I2 / I5 | 训练期 |
| 表示层 | RPY 绝对位姿 chunk | SE(3) 规范化 chunk | I10 | 推理期（<1ms） |

**一句话**：**模型不变，先把动作块在 SE(3) 上弄干净（I10），再用离散无源柔顺让它学会退让（I11），最后用任务流形把退让约束在正确的方向上（I12）；I13 是可选的关节空间对照，不是默认。**

## 1. 创新点清单（每点：动机 / 与现有方案差异 / 技术可行性 / 所需资源 / 落地步骤 / 风险）

### I10 v1 SE(3) 末端动作几何层（SAGL） ★★★★★

- **动机**：`ee` 模式的观测与动作都是 base 系绝对 `xyz+rpy`（F21）；RPY 有包裹跳变与万向锁；绝对坐标回归浪费平移/旋转等变性；7 自由度对 6 维位姿有零空间黑箱（F27）；动作校验不查可达性（F24）。这些是全局性、低成本的隐性损失，尤其伤害朝向变化大的任务（PourOutMedicine、Unlock、HangCup、ArrangeTestTubes、FoldTowel、SpellRobot、PlacePhotoFrame、RemovePinnedNote）。
- **与现有方案差异**：直接 SFT 队伍把 RPY 当普通 6 维向量回归/插值；本点把动作块当 SE(3) 对象处理：符号连续、测地线重采样、相对 chunk 起点参数化、FK/Jacobian 可行性治理。**推理侧版本不需要重训；训练侧版本只动动作头。**
- **技术可行性**：高。
  - **I10-A（推理侧，零重训）**：RPY→`SO(3)`→符号连续四元数→测地线/SLERP 重采样→连续 RPY；chunk 间用 SE(3) 测地线混合；若做动作集成，用 Karcher/四元数平均，禁止 RPY 分量平均。
  - **I10-B（训练侧，LoRA）**：动作头改预测「相对 chunk 起点的 SE(3) 增量」`ξ_k=log(T_o^{-1}T_k)`，用测地线损失；推理时 `T_k=T_o Exp(ξ_k)`。天然平移不变、无 RPY 包裹。
  - **I10-C（可行性治理）**：用关节状态做 FK，与观测 EE 位姿对齐（顺带验证 RPY 约定）；用 Jacobian 条件数检测奇异；IK 残差/关节限位超阈时向当前位姿回缩（比例回缩，不硬切）。
- **所需资源**：I10-A 1 人周；I10-B 1×24GB GPU 1–2 天 LoRA；I10-C 1 人周 + URDF/FK。
- **落地步骤**：① 用 FK 在官方示教上验证 RPY 旋转顺序/内外旋；② 实现 `C(A)` 与 `Φ/Ψ` 指标；③ 接入推理后处理并做 L0 对比；④ 训练相对位姿头（可选）；⑤ 加 FK/Jacobian 回缩；⑥ 在 8 个朝向重任务上做 L0 + L2 抽测。
- **风险**：RPY 约定假设错（缓解：FK 对齐，错了只影响回缩不影响主链）；相对位姿复合误差累积（缓解：每 chunk 从当前观测重新锚定，不跨 chunk 累加）；RPY 输出在万向锁附近仍不可避免（缓解：检测 `|pitch|>85°` 时降低朝向增益，或把该任务交给 I13）。

### I11 v1 离散无源柔顺壳（DPCS） ★★★★★

- **动机**：评测没有力/触觉，也没有刚度/阻尼指令（F21/F22）；接触任务（PlugCharger、PlugInEthernet、DisconnectEthernet、SyringeWaterTransfer、Unlock、PourOutMedicine、StackBowls、PaperCupStacking、StoreCups、HangCup、ZipUp、FoldTowel）失败的主因是「硬顶/卡死/撞飞/滑移」；跟踪误差 `e=log(T_c^{-1}T_o)` 是接口免费给的接触代理；但 chunk 级反馈把柔顺带宽锁在 `f/(2T_a)`（F23/D5）。
- **与现有方案差异**：基线把策略目标直接下发；本点先做离散导纳（把目标按 `Λ` 拉回观测），再做接触检测，再做相位化增益调度，最后用 `Δ_max/B_max` 预算与微退重试兜底。**纯动作后处理，不改模型，不依赖力传感器。**
- **技术可行性**：高。
  - **D2 导纳**：`p_c=p_o+R_oΛ_pR_o^T(p_d-p_o)`，`R_c=R_oExp(Λ_R log(R_o^T R_d))`；`Λ` 可按任务系各向异性（插入轴软、横向硬）。
  - **D4 接触检测**：`e_k>ε`、`e_k-e_{k-1}>δ`、`v_o` 与命令方向相反，连续 `m` 块；误差在收敛时判为滞后而非接触。
  - **相位调度**：APPROACH→ALIGN→CONTACT→INSERT/MANIPULATE→RELEASE/RETREAT；每相位不同 `Λ`、速度限、`Δ_max`。
  - **预算与退让**：`||Δp||≤Δ_max=F_safe/K_max`，`Σ(||Δp||+r||Δθ||)≤B_max`；预算耗尽或 `e` 超阈 → 微退 2–5mm → 重对齐 → 重试。
- **所需资源**：1 人周工程；L0 AUROC 1 GPU 日；真机 L2 只在 6–8 个接触任务上。
- **落地步骤**：① 实现导纳混合与 `Φ/Ψ` 日志；② 用现有示教 + Isaac Lab 接触真值（F28）离线标定 `ε,δ,m,Δ_max,B_max`；③ 实现相位调度与微退；④ `T_a∈{2,4,8}` 扫描；⑤ L0 误报/漏报成本；⑥ L2 接触任务 A/B。
- **风险**：跟踪误差被滞后/重力/摩擦污染 → 自由空间也变怂（缓解：方向一致性 + 误差导数 + 视觉滑移二次确认 + 每任务阈值）；准静态预算不覆盖冲击（缓解：接近相位软启动 + 速度/加速度限 + 冲击检测退让）；微退浪费时间（缓解：只在连续 `m` 块接触后触发，且微退距离可调）。

### I12 v1 任务流形虚拟夹具（TMVF） ★★★★

- **动机**：接触任务有已知运动流形——插头/网线/注射器沿直线插入，倾倒绕瓶口圆弧，开锁绕铰链轴，堆叠沿竖直线。策略的横向误差是卡死主因；I11 的各向同性导纳不知道该往哪个方向软。任务流形把「软」放在切向、「硬」放在法向，直接对齐步骤分。
- **与现有方案差异**：通用柔顺壳不知道任务几何；本点从任务指令 + 首帧关键点/开放词汇检测估计流形，再做软投影与各向异性刚度。**零训练，纯几何先验；误约束时置信门控回退到 I11。**
- **技术可行性**：中-高。
  - **直线**：`M={p=p0+s a, R=R_align(a)R_roll(φ)}`；投影消去横向误差、对齐工具轴。适用 PlugCharger / PlugInEthernet / DisconnectEthernet / SyringeWaterTransfer。
  - **圆弧**：绕瓶口中心 `c`、半径 `r`、轴 `u`；投影到圆弧并保持瓶口贴合。适用 PourOutMedicine / SyringeWaterTransfer。
  - **铰链**：绕固定轴 `u` 过点 `c` 的旋转；位置约束在圆弧、朝向与旋转角耦合。适用 Unlock。
  - **竖直线**：目标上方竖直轴 + 保持水平朝向。适用 StackBowls / PaperCupStacking / StoreCups / ArrangePlates。
  - **软投影**：`T_c = T_o Exp(Λ log(T_o^{-1} Π_M(T_d)))`，法向 `Λ` 小、切向 `Λ` 大；置信度低时 `Π_M` 退化为恒等。
- **所需资源**：1–2 人周；关键点/检测 1 GPU；每任务模板来自任务描述 wiki（F17）。
- **落地步骤**：① 任务名→流形模板表（先 6–10 个接触任务）；② 首帧开放词汇检测/关键点估计；③ 流形拟合 + 置信度；④ 软投影接入 I11；⑤ L0 几何误差 + L2 步骤分 A/B；⑥ 失败即回退 I11。
- **风险**：流形估计错误导致「越夹越偏」（缓解：软投影 + 置信门控 + 法向刚度上限 + L0 验证）；任务描述 wiki 的得分点与流形不一致（缓解：以首帧视觉为准，wiki 只做模板先验）；单模型边界（缓解：纯几何后处理，向组委会书面确认；不行则蒸馏进策略）。

### I13 v1 关节空间 OSC 包装（J-OSC，备选） ★★★☆

- **动机**：原生 `ee` 模式的 IK/零空间是黑箱（F27）；7 自由度冗余导致块间可能换肘部构型，腕部相机抖动、抓取失败；近奇异时 IK 可能饱和。关节空间 OSC 让我们显式控制零空间姿态、关节限位、奇异阻尼。
- **与现有方案差异**：不换模型，只换执行层：`control_space="joint"`，把策略的 EE 位姿目标经阻尼最小二乘 IK 转成关节目标，叠加零空间姿态保持与关节限位裁剪；笛卡尔导纳仍在 EE 空间算，再映射到关节。
- **技术可行性**：中。需要准确 URDF/FK/Jacobian、关节限位、速度限；IK 失败与额外延迟是主要风险。
- **所需资源**：2 人周；1 GPU 做离线 IK 成功率/延迟；L2 对照。
- **落地步骤**：① 用官方关节状态验证 URDF/FK；② DLS IK + 零空间姿态；③ 奇异阻尼与限位裁剪；④ 离线 IK 成功率/p99；⑤ 与原生 `ee` 做 L2 对照；⑥ 只在胜出任务上启用，否则保持 `ee`。
- **风险**：IK 失败/模型失配/延迟超预算（缓解：默认 `ee`，I13 只作 L2 对照；DLS 阻尼 + 残差回缩；p99 门禁不过即裁撤）；关节目标与训练分布不一致（缓解：模型仍输出 EE 位姿，只换执行映射）。

### I1 v3 考纲校准五轴增广引擎 ★★★★★（维持）

- **动机**：计分的 320 次真机评测每次都在 5 轴上偏离训练分布（P2/F2），泛化缺口是全局乘性损失；官方考纲公开（F2/F17），增广可以按考纲校准而不是盲随机。
- **与现有方案差异**：直接 SFT 队伍用标称数据；盲目增广队伍用无校准随机化。本点维护 32 张「考纲卡」（每任务 5 轴的具体扰动范围 + 官方示例锚点），增广参数从考纲卡分布采样，把零样本泛化转化为分布内泛化。
- **技术可行性**：高。考纲卡由 LLM 解析 wiki + 人工校对（每任务约 10 分钟）；每轴 3 档剂量（考纲内/边缘/外）。
- **所需资源**：分割/inpainting 1×24GB GPU；磁盘同 v1.0。
- **落地步骤**：① 32 张考纲卡；② 背景/干扰物两轴按考纲放量；③ 外观/位置两轴 L0 先行；④ 剂量-响应定档；⑤ 轴间交互（位置×干扰物）2 档析因。
- **风险**：考纲卡与真实评测仍有偏差（缓解：单任务通道抽测 + 示例截图对齐）；位置重拼接物理不可行（L0 判据：不可行动作占比 >5% 即降级为平移不变增广）。
- **本轮新增用途**：I1 的增广器同时作为 I11 的 L0 接触扰动源（位置/外观/背景/干扰物），让接触检测在「分布内但非标称」的留出集上评估，而不是只在干净示教上。

### I2 v3 数据引擎 2.0：110 语料孪生迁移 + 加权共训 ★★★★★（v3 微调）

- **动机**：单模型平均分被最弱任务支配（P1）；示教语料与质量双重浪费（P8）。
- **与现有方案差异**：均匀混训把容量浪费在已会任务与低质示教上；本点诊断先行、孪生定向、权重受控——32 考题全量 + 孪生任务半权重 + 远任务 ≤5% 防遗忘；loader 按族级权重 patch（官方 ConcatDataset 只按样本数比例混采，F11）。
- **技术可行性**：高（frozen-VLM/LoRA 单卡起步，F11；全参 action expert 4–8 卡）。
- **所需资源**：孪生子集 ≈1–2TB + 32 任务 ≈2TB；训练 1×24GB 起步、8×A100 上限。
- **落地步骤**：① 孪生表构建（LLM 初筛 + 人工校对）；② 下载孪生子集；③ loader patch + 单元测试（统计 batch 内任务频率验证权重生效）；④ 首轮共训；⑤ 族级 L0 验证正迁移后放量。
- **风险**：负迁移（孪生任务动态相反，如 ZipUp↔Unzip 的拉链受力方向）——家族级 L0 消融、低权重起步、退步即裁剪；110 语料相机配置与 32 任务不一致——先抽样核对 4 相机命名/分辨率。
- **本轮新增两条与 I10 对齐的数据处理**：① 把示教动作规范化为「相对 chunk 起点的 SE(3) 增量」用于 I10-B，同一技能换绝对位置可直接对齐；② 给接触段打「相位 + 跟踪误差 + 是否卡死/滑移/冲击」标签，供 I5/I11 使用。

### I7 v1 世界模型测试时前瞻 ★★（缓，维持）

- **动机**：高险节点（插入/倾倒/堆叠）用 WMA-0 做 O(1–2) 次小规模 rollout 择优，理论上可降失败率。
- **与现有方案差异**：纯策略一次前向；本点在测试时做短视前瞻，用世界模型比较候选动作块。
- **技术可行性**：中；WMA-0 仿真模式可用（F15），但延迟高。
- **所需资源**：高（额外推理 + 视频生成）。
- **落地步骤**：仅在第 3 轮基线延迟余量充足时启动；否则裁撤。
- **风险**：延迟吃掉 66ms 预算；世界模型不生成力，对接触任务帮助有限。**本轮判断**：优先级不升，维持待裁撤；资产（WMA-0 仿真模式）转 I5 数据引擎用途。

### 2.1 SE(3) 规范化与相对位姿（I10）

```python
import numpy as np
from scipy.spatial.transform import Rotation as Rot, Slerp

def rpy_to_R(rpy):                       # 约定待 FK 核实；先按 URDF Rz*Ry*Rx
    return Rot.from_euler("ZYX", rpy).as_matrix()

def R_to_rpy_continuous(R, prev_rpy):
    rpy = Rot.from_matrix(R).as_euler("ZYX")
    return prev_rpy + wrap_to_pi(rpy - prev_rpy)   # 连续分支，消除 2π 跳变

def geodesic_lift(Ts):
    """把 chunk 的旋转统一到符号连续的四元数分支，并做 SLERP 重采样。"""
    quats = [Rot.from_matrix(T.R).as_quat() for T in Ts]
    for i in range(1, len(quats)):
        if np.dot(quats[i], quats[i - 1]) < 0:
            quats[i] = -quats[i]
    return quats

def blend_chunks(prev_Ts, new_Ts, w=0.5):
    """chunk 间在 SE(3) 上做测地线混合，禁止 RPY 分量平均。"""
    return [se3_exp(w * se3_log(se3_inv(a) @ b)) @ a
            for a, b in zip(prev_Ts, new_Ts)]

def relative_action_target(current_T, gt_Ts):
    """I10-B 训练目标：相对 chunk 起点的局部 SE(3) 增量。"""
    return [se3_log(se3_inv(current_T) @ T) for T in gt_Ts]

def compose_relative(current_T, xis):
    """I10-B 推理：从当前观测位姿复合，不跨 chunk 累加误差。"""
    return [current_T @ se3_exp(xi) for xi in xis]

def feasibility_governor(T_o, T_d, q, urdf, eps_ik=5e-3):
    T_fk = forward_kinematics(q, urdf)
    if se3_dist(T_fk, T_o) > eps_ik:          # 顺带暴露 RPY/FK 约定错误
        log.warning("FK/obs mismatch; fall back to identity governor")
        return T_d
    J = jacobian(q, urdf)
    if np.linalg.cond(J) > COND_MAX:          # 近奇异：向当前位姿回缩
        return se3_exp(0.5 * se3_log(se3_inv(T_o) @ T_d)) @ T_o
    if ik_residual(T_d, q, urdf) > IK_TOL:    # 不可达：比例回缩
        return se3_exp(0.5 * se3_log(se3_inv(T_o) @ T_d)) @ T_o
    return T_d
```

### 2.2 离散无源柔顺壳（I11）

```python
class DiscreteComplianceShell:
    def __init__(self, K_max, F_safe, B_max, r=0.05):
        self.Delta_max = F_safe / K_max
        self.B_max = B_max
        self.r = r

    def command(self, T_o, T_d_chunk, phase, state):
        # 1) 任务系各向异性导纳（D2）
        Lam_p, Lam_R = PHASE_GAINS[phase]      # 插入轴软、横向硬
        cmds = []
        for T_d in T_d_chunk:
            dp = T_o.R @ (Lam_p @ (T_o.R.T @ (T_d.p - T_o.p)))
            dR = T_o.R @ expm(Lam_R @ logm(T_o.R.T @ T_d.R))
            T_c = SE3(dR, T_o.p + dp)
            T_c = clip_step(T_c, cmds[-1] if cmds else T_o, self.Delta_max)
            cmds.append(T_c)

        # 2) 接触检测（D4）：误差在发散 + 观测速度与命令反向
        e = se3_dist(T_o, cmds[-1])
        contact = (e > EPS and e - state.e_prev > DELTA
                   and dot(state.v_obs, cmds[-1].p - T_o.p) <= 0)
        state.contact_run = state.contact_run + 1 if contact else 0

        # 3) 预算与退让（D3）
        state.B += path_length(cmds, self.r)
        if state.contact_run >= M or state.B > self.B_max:
            return micro_retract(T_o, state), "RETREAT"
        return cmds, ("CONTACT" if contact else phase)
```

def project_line(T_d, p0, axis):
    p = p0 + axis * np.dot(axis, T_d.p - p0)          # 消去横向误差
    R = align_tool_axis(T_d.R, axis)                   # 工具轴对齐插入轴

def project_arc(T_d, center, radius, axis, phi):
    # 瓶口/铰链绕 axis 过 center 的圆弧
    radial = normalize(project_perp(T_d.p - center, axis))
    p = center + radius * radial
    R = rotate_about(T_d.R, axis, phi)

def virtual_fixture(T_o, T_d, manifold, conf):

def osc_step(q, T_d, urdf, q_rest, dt):
    T_o = forward_kinematics(q, urdf)
    e = se3_log(se3_inv(T_o) @ T_d)
    J = jacobian(q, urdf)
