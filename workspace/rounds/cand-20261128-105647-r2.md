### 第 6 轮灵感驱动研究记录（本轮循环第 2 轮）

**灵感词**：点云配准、语义建图

**继承关系**：承接第 5 轮 CADVS-v5（IP-493~496，Certified Generative Execution, CGE）：七硬门 fail-closed、证书不变性（定理 6）、调制单调性（定理 5）、固化有界（定理 7）、执行集 Exec_CADVS-v5 ⊆ … ⊆ Exec_v29。v5 把提议器一般化为任意生成器，但保留了一个未言明的「世界模型假设」：门所消费的位姿/几何/语义上下文 (obj, g_emb, θ_fp, …) 被默认为已在正确坐标系中、语义标签正确、地图新鲜。真实系统里这些量全部来自**点云配准 + 语义建图**：配准错一个位姿，所有几何门就在错误坐标系里盖章；语义图过期或标错，门就在错误前提上成立。两个灵感词统一为主题「认证的空间-语义接地」（Certified Spatial-Semantic Grounding, CSSG），形成 CADVS-v6（IP-497~500）。本轮自律：**逐轨迹硬门仍为七**；接地是「前提层/元层 G0」，不是第八道逐轨迹门。执行集嵌套升级为 Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ … ⊆ Exec_v29。

**直觉与动机**：

1. **点云配准 → 证书从「绝对坐标系」降级为「带误差球的相对坐标系」，再用阈值膨胀把它抬回可靠证书**。直觉：ICP/深度配准给出的不是真值 T*，而是 T̂ 加上一个误差球；在对称走廊、无纹理平面、动态遮挡下，T̂ 可能高置信地错。引入 PCRK：多假设配准（RANSAC 多解 + SE(3) 聚类 + ICP 精化），输出配准证书 (T̂, Σ_T, δ_T, d, a)：δ_T 是保形校准得到的有限样本误差上界，d=λ_min/λ_max 是退化指数，a 是前两名假设的内点率差（歧义边际）。关键一步是**定理 9（配准误差传播/阈值膨胀）**：若门分数 s_i 对位姿满足 L_i-Lipschitz，且 d_SE3(T̂,T*) ≤ δ_T，则 s_i(x;T̂) ≥ τ_i + L_iδ_T ⇒ s_i(x;T*) ≥ τ_i。于是 v6 用 τ_i^6 = τ_i^5 + L_iδ_T（只紧不松）把相对坐标系的证书抬成真值坐标系下的可靠证书；反过来给出**证书预算分配**：要让某门保持原阈值，配准误差必须满足 δ_T ≤ (s_i − τ_i^5)/L_i。这把感知误差第一次显式纳入证书代数，而不是当作工程噪声。

2. **语义建图 → 语义前提从「确定性标签」升级为「集合值标签 + 时效」**。直觉：地图说「这是杯子」，但分割/开放世界识别给出的可能是一个标签集合；地图还可能是 30 秒前甚至上周的。引入 SMK：每个物体维护保形标签集 C_α(o)（覆盖真标签的概率 ≥ 1−α）、关系图、可供性、最后观测时间与变化检测标志。门不再对单标签求值，而是采用**「必须」语义**：安全关键前提要求 ∀ℓ∈C_α(o), Pre^crit(ℓ)=1；非关键前提按违反标签的概率质量 r_sem 给出语义惩罚 Δτ_sem=κ_sem·r_sem，超过 r_sem_max 则 fail-closed。**定理 10（语义前提可靠性）**：若 C_α 以 ≥1−α 覆盖真标签，且门要求 C_α 中所有标签满足前提，则门在真标签下成立的概率 ≥1−α。这把「标签可能错」从不可处理的噪声变成可计算的集合约束。

3. **统一 → 接地核把配准证书、语义证书、几何-语义一致性合成前提证书 G_cert，只做两件事：收紧或阻断**。SSGK 检查：δ_T≤δ_max、d≥d_min、歧义 a≥a_min、安全关键前提全满足、地图年龄≤τ_age、无变化标志、活点云与地图模型的 Chamfer/IoU 一致性≥c_min。通过则输出 Δτ_i=L_iδ_T+κ_sem·r_sem，供 EFA-v6 做阈值膨胀；不通过则 fail-closed 到「重扫/慢速/人工确认」保守模式。**定理 11（接地合成与嵌套）**：G_cert=1 时，膨胀阈值下通过的门在真值下以 ≥1−α_reg−α_sem 成立；G_cert=0 时执行集为空（或退到保守子集），故 Exec_v6 ⊆ Exec_v5。软评分 ECS_v6 = ECS_v5 · η_ground · η_sem。

**关键洞见**：v5 回答「提议是任意生成器时，证书边界如何不变」；v6 回答「边界所在的坐标系与语义前提本身不确定时，证书如何仍然可靠」。核心不是加门，而是把证书的**参考系**从「隐含真值」显式化为「带误差球的估计」，再用只紧不松的阈值膨胀把误差球吸收进证书；语义侧则用集合值标签把「可能错」变成「必须全对」。七硬门 kc_evidence_forged_v5 原样复用；本轮新增的只有：配准证书 (T̂,Σ_T,δ_T,d,a)、语义证书 (C_α,age,change,consistency)、接地前提 G_cert 与阈值膨胀 Δτ。执行集 Exec_v6 ⊆ Exec_v5 由「同门 + Δτ≥0 + G_cert 前提」三重保证。接地层不是第八锚：它不评价轨迹谓词，只限制七锚被应用的**定义域**；七锚在轨迹层面的完备性（v5 定理 8）保持不变。

**形式化目标（增量）**：
1. PCRK：多假设配准；δ_T 由保形分位数校准；d=λ_min(H)/λ_max(H)；歧义 a=r_(1)−r_(2)；输出 RegCert=(T̂,Σ_T,δ_T,d,a,r_in,frame_id,map_version)。
2. SMK：M=(O,Rel,Aff,t_last,ver)；C_α(o) 保形标签集；age(o)=t−t_last；change(o) 由占据/自由空间差分；consistency(o) 由活点云-地图模型 Chamfer/IoU；区分安全关键前提 Pre^crit 与非关键前提 Pre^soft。
3. SSGK：G_cert=1[δ_T≤δ_max ∧ d≥d_min ∧ a≥a_min ∧ (∀o,∀ℓ∈C_α(o):Pre^crit(ℓ)=1) ∧ age≤τ_age ∧ ¬change ∧ consistency≥c_min ∧ r_sem≤r_sem_max]；Δτ_i=L_iδ_T+κ_sem·r_sem。
4. 定理 9（配准误差传播/阈值膨胀）、定理 10（语义前提可靠性）、定理 11（接地合成与执行集嵌套）、定理 12（地图时效的条件界，含诚实边界）。
5. EFA-v6：G0 接地 → 流提议（上下文含配准/语义 token）→ 廉价门（τ^6=τ^5+Δτ）→ VACK → BCK；G0 失败回退重扫/慢速/人工。
6. Exec_CADVS-v6 = {x ∈ supp(π) : G_cert=1 ∧ ∧_i kc_i(x,c; τ_i^5+Δτ_i)=1} ⊆ Exec_CADVS-v5。

**本轮最大风险**：**「地图即真值」的自指接地**——配准与语义图都由同一套感知/建图管线产生，接地证书只证明「执行与地图一致」，并不证明「地图与世界一致」；系统性地图误差（回环漂移、过期语义、对抗性点云/标签投毒、标定偏置）不会被随机误差的保形界覆盖，反而可能被阈值膨胀「合法化」。独立模态交叉校验、地图版本/来源链、变化检测与人工抽检只能缓解，无法根除。

### IP-497 PCRK：多假设配准与保形误差界（慢时域 5–20 Hz；不在 1 kHz 环）

```python
@dataclass
class PointCloudRegistrationKernel:
    """PCRK：多假设配准 + 保形误差界 + 退化/歧义检测。
    定理 9：配准误差经 Lipschitz 门分数传播为阈值膨胀（只紧不松）"""
    voxel: float = 0.02
    max_iter: int = 30
    n_hyp: int = 8
    alpha: float = 0.05          # 保形误覆盖水平
    d_min: float = 0.05          # 退化指数下限
    a_min: float = 0.15          # 歧义边际下限
    eps_sep: float = 0.05        # 假设分离阈值（m/rad）
    rho_max: float = 0.30        # 动态点异常比上限

    def register(self, scan: PointCloud, submap: PointCloud,
                 T_init: SE3) -> RegCert:
        # 1) 体素降采样 + 法向 + 特征（FPFH / 学习描述子）
        # 2) RANSAC 多假设 → SE(3) 聚类 → 前 n_hyp 个候选
        # 3) 每个候选 ICP 精化，记录内点率 r_j 与残差
        # 4) 取最优 T̂；H=J^T J（point-to-plane），特征分解
        #    d = λ_min/λ_max；Σ_T = σ̂² H^{-1}（稳健三明治协方差）
        # 5) 歧义 a = r_(1) − r_(2)（仅当前两名 SE(3) 距离 > ε_sep）
        # 6) δ_T = 保形分位数（离线校准集 d_SE3(T̂,T_gt) 的 1−α 分位）
        # 7) 动态点剔除；异常比 > ρ_max ⇒ 配准不可信
        return RegCert(T_hat=..., Sigma_T=..., delta_T=...,
                       d=..., a=..., r_in=..., frame_id=...,
                       map_version=...)

    def calibrate(self, calib_pairs) -> float:
        """离线 split-conformal：q_reg = d_SE3(T̂,T_gt)；
        δ_T = q_{(⌈(n+1)(1−α)⌉)}；分布内覆盖 ≥ 1−α，分布外无保证"""
        scores = [d_se3(self.register(s, m, T0).T_hat, T_gt)
                  for (s, m, T0, T_gt) in calib_pairs]
        return quantile(scores, 1 - self.alpha)

    def degenerate(self, cert: RegCert) -> bool:
        return cert.d < self.d_min or cert.a < self.a_min \
               or cert.r_in < 0.3 or cert.outlier_ratio > self.rho_max
```

### IP-499 SSGK：空间-语义接地核（G0；只收紧或阻断）

```python
@dataclass
class SpatialSemanticGroundingKernel:
    """SSGK：接地前提 G0。只做两件事：收紧（Δτ≥0）或阻断（fail-closed）。
    不是第八道逐轨迹门：不评价轨迹谓词，只限制七锚的定义域"""
    pcrk: PointCloudRegistrationKernel
    smk: SemanticMappingKernel
    delta_max: float = 0.02
    d_min: float = 0.05
    a_min: float = 0.15
    tau_age: float = 30.0
    c_min: float = 0.7
    r_sem_max: float = 0.10
    kappa_sem: float = 0.10
    L: dict = field(default_factory=dict)   # 每门 Lipschitz 常数

    def ground(self, scan, submap, T_init, queries, t_now) -> GroundCert:
        reg = self.pcrk.register(scan, submap, T_init)
        sem = [self.smk.query(q.obj_id, t_now) for q in queries]
        frame_ok = (reg.delta_T <= self.delta_max
                    and reg.d >= self.d_min
                    and reg.a >= self.a_min)
        crit_ok, r_sem = True, 0.0
        for q, s in zip(queries, sem):
            ok, r = self.smk.must_precondition(s, q.Pre_crit, q.Pre_soft)
            crit_ok &= ok
            r_sem = max(r_sem, r)
        sem_ok = (crit_ok
                  and all(s.age <= self.tau_age and not s.changed
                          and s.consistency >= self.c_min for s in sem)
                  and r_sem <= self.r_sem_max)
        if not (frame_ok and sem_ok):
            return GroundCert(ok=False, reg=reg, sem=sem,
                              r_sem=r_sem, reason='GROUNDING_FAIL')
        dtau = {i: self.L[i] * reg.delta_T + self.kappa_sem * r_sem
                for i in self.L}
        return GroundCert(ok=True, reg=reg, sem=sem, dtau=dtau,
                          r_sem=r_sem, reason='GROUNDED')

    def fallback(self, g: GroundCert):
        """fail-closed：重扫 / 慢速 / 人工确认；
        不产生新的执行集成员（Exec_v6 只可能为空或保守子集）"""

    famk: FacialAffectModulationKernel
    ssgk: SpatialSemanticGroundingKernel
    v5: EvidenceForgingAssemblerV5

    def select(self, state, t_now, context) -> tuple[bool, Trajectory | None, str]:
        # 第 0 层：接地（前提层，不是轨迹门）
        g = self.ssgk.ground(context.scan, context.submap,
                             context.T_init, context.queries, t_now)
        if not g.ok:
            return self.ssgk.fallback(g)       # fail-closed：重扫/慢速/人工
        s_emo = self.famk.observe(context.face, t_now)
        gamma = self.famk.gamma(s_emo)
        tau5 = {i: gamma[i] * TAU4[i] for i in TAU4}
        tau6 = {i: tau5[i] + g.dtau[i] for i in tau5}   # Δτ ≥ 0
        c = build_ctx(context, s_emo, self.lmem, g)     # 配准/语义 token
        cands = self.fmpp.propose(c, self.fmpp.K)
        # 第 1 层：廉价门（coverage/physics/memory/novelty）
        surv = [x for x in cands if self._cheap_gates(x, tau6)]
        if not surv:
            return self._fallback_rule_proposal(tau6)
        # 第 2 层：VACK 仅评 ≤3 幸存者
        surv.sort(key=self._prefilter_score, reverse=True)
        finals = []
        for x in surv[:3]:
            vac = self.v5.vack.evaluate(x, context_with(s_emo, g), t_now)
            if self.v5.vack.kc_val(vac, tau=tau6['val']):
                finals.append(x)
        # 第 3 层：BCK 轨迹预览（事件触发 QP + 缓存证书内插）
        ok = [x for x in finals if self._bck_preview(x, tau6)]
        if not ok:
            return False, None, 'ALL_CANDIDATES_REJECTED'
        best = max(ok, key=lambda x: certified_margin(x) - grounding_risk(g))
        return True, best, 'FORGED_CSSG'

    def ecs_v6(self, base, g) -> float:
        eta_ground = (sigmoid((self.ssgk.delta_max - g.reg.delta_T)
                              / self.ssgk.delta_max)
                      if g.ok else 0.0)
        age = max((s.age for s in g.sem), default=0.0)
        eta_sem = ((1.0 - g.r_sem)
                   * sigmoid((self.ssgk.tau_age - age) / self.ssgk.tau_age)
                   * (0.0 if any(s.changed for s in g.sem) else 1.0))
        return base * eta_ground * eta_sem
```

### 集成流水线（v5 → v6）

```
离线/慢时域：
  配准校准：held-out 配准对 ──▶ 保形分位数 δ_T ──▶ PCRK 证书表
  语义校准：held-out 标注 ──▶ 保形标签集阈值 q_α ──▶ SMK
  Lipschitz 估计：各门分数对位姿有限差分/解析界 ──▶ L_i 高 quantile ──▶ SSGK
  地图维护：多视角融合/回环/变化检测 ──▶ 版本号 + 来源链（签名哈希）
  记忆固化：v5 LMEM-v2 固化只改 θ_FM（门、地图、校准参数冻结只读）

在线准入（异步，秒级）：
  PCRK.register（scan↔submap，多假设）──▶ RegCert
  SMK.query（标签集/关系/时效/变化/一致性）──▶ SemCert
  SSGK.ground ──▶ G_cert + Δτ
    ├─ 失败 ──▶ fail-closed：重扫 / 慢速 / 人工确认（不扩执行集）
    └─ 通过 ──▶ τ^6=τ^5+Δτ ──▶ 流提议 → 廉价门 → VACK → BCK → 取边际最大者

在线控制环（目标 < 0.6 ms）：
  每周期：EEK + BCK（事件触发缓存证书）；配准/语义在慢时域，
  证书带 frame_id/map_version，控制环只消费预计算阈值与缓存证书
```

## 4. 正确性论证（增量更新）

### 引理 45（SE(3) 误差的 Lipschitz 传播）

**陈述**：若门分数 s_i(x;·) 在相关定义域上对 SE(3) 满足局部 Lipschitz 常数 L_i，则对任意 T_1,T_2，|s_i(x;T_1)−s_i(x;T_2)| ≤ L_i·d_SE3(T_1,T_2)。∎

**证明**：Lipschitz 定义直接展开。∎

### 引理 46（配准保形覆盖）

**陈述**：在校准对与测试对可交换（exchangeable）的假设下，δ_T 取校准集 q_reg=d_SE3(T̂,T_gt) 的 ⌈(n+1)(1−α)⌉ 分位数，则 P(q_reg^test ≤ δ_T) ≥ 1−α。∎

**证明**：标准 split-conformal 秩论证。∎

**诚实边界**：可交换性在新传感器/新环境/新动态模式下不成立；δ_T 只是分布内界，分布外无保证。

### 引理 47（语义标签集保形覆盖）

**陈述**：同上，非一致性分数 q_sem=1−p_o(y_o)，C_α(o)={ℓ:1−p_o(ℓ)≤q̂_α}，则 P(y_o∈C_α(o)) ≥ 1−α（可交换性下）。∎

**诚实边界**：边际覆盖，不是条件覆盖；开放世界标签空间外的新类别不被覆盖；关系/多物体联合前提需 Bonferroni 或联合保形。

### 定理 9（配准误差传播 / 阈值膨胀）

**陈述**：设 d_SE3(T̂,T*) ≤ δ_T，门分数 s_i 满足 L_i-Lipschitz。若 s_i(x;T̂) ≥ τ_i^5 + L_iδ_T，则 s_i(x;T*) ≥ τ_i^5。

**证明**：s_i(x;T*) ≥ s_i(x;T̂) − L_i·d_SE3(T̂,T*) ≥ (τ_i^5 + L_iδ_T) − L_iδ_T = τ_i^5。∎

**推论（证书预算）**：要让门 i 保持 v5 阈值 τ_i^5，配准误差必须满足 δ_T ≤ (s_i(x;T̂)−τ_i^5)/L_i。多门同时时取 min_i；这把感知精度预算与安全边际预算显式耦合。

**诚实边界**：L_i 在接触/碰撞等非光滑边界附近可能很大甚至无界；需用局部 Lipschitz + 安全裕度，或对非光滑门单独用保守膨胀。

### 定理 10（语义前提可靠性）

**陈述**：设 P(y_o∈C_α(o)) ≥ 1−α。若 ∀ℓ∈C_α(o)，Pre(ℓ)=1，则 P(Pre(y_o)=1) ≥ 1−α。若存在违反标签，则 fail-closed 或按 r_sem 膨胀；残余语义风险 ≤ α + r_sem。

**证明**：在事件 {y_o∈C_α} 上，所有 C_α 标签满足 Pre ⇒ y_o 满足 Pre；事件概率 ≥1−α。违反质量 r_sem 由标签分布直接给出，与 α 取并集界。∎

**诚实边界**：只对标签空间内的前提有效；关系/可供性前提若依赖多个物体，需联合覆盖；开集识别失败时 C_α 可能不覆盖真标签。

### 定理 11（接地合成与执行集嵌套）

**陈述**：在 (B8) 配准保形覆盖与 (B9) 语义保形覆盖下，若 G_cert=1 且 x 在 τ_i^6=τ_i^5+L_iδ_T+κ_sem·r_sem 下通过所有门，则 x 在真值下满足 v5 门，概率 ≥ 1−α_reg−α_sem。且对任意 G_cert，Exec_v6 ⊆ Exec_v5；G_cert=0 时 Exec_v6=∅（或保守回退子集）。

**证明**：定理 9 给几何门；定理 10 给语义前提；union bound 合并；阈值只增 ⇒ 各门通过集只缩；G_cert 是额外合取前提 ⇒ 执行集只缩。∎

**诚实边界**：结论相对**地图系与地图标签**成立；若地图系统性错误，T* 与 y 不是世界真值——见定理 12 与最大风险。

### 定理 12（地图时效的条件界）

**陈述**：假设 (B10) 查询区域的变化服从速率 λ_c 的 Poisson 过程，变化检测延迟 ≤ Δ_d、漏检率 ≤ β。则年龄为 a 的语义事实「仍有效但未被检测到变化」的概率 ≤ 1−exp(−λ_c(a+Δ_d)) + β。若 a≤τ_age 且该界 ≤ ε_age，则事实以 ≥1−ε_age 有效。

**证明**：Poisson 无变化概率 exp(−λ_c(a+Δ_d))；检测漏报 β；并集界。∎

**诚实边界**：λ_c 未知且环境相关；该界是建模假设，不是保证。高动态人因场景只能靠实时重观测/重扫，不能靠地图年龄阈值。

### 定理 v6（总装）

**陈述**：在 v5 假设 (B1)~(B7) 及新增 (B8) 配准保形覆盖、(B9) 语义保形覆盖、(B10) 变化模型下：
(i) Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ … ⊆ Exec_v29（严格：Δτ>0 或 G_cert 限制）；
(ii) G_cert=1 时，膨胀阈值下的证书在真值系下以 ≥1−α_reg−α_sem 成立；
(iii) G_cert=0 时 fail-closed 到保守回退，不扩执行集；
(iv) 七锚完备性保持：接地是前提层 G0，不评价轨迹谓词，不是第八锚；
(v) 地图时效由定理 12 条件界；系统性地图误差不在保形覆盖内。

**证明**：(i) 同门 + Δτ≥0 + G_cert 合取；(ii) 定理 9/10 + union bound；(iii) 定义；(iv) 锚点集合不变 + 接地只限制定义域；(v) 定理 12。∎

**诚实声明**：(B8)/(B9) 依赖可交换性，分布漂移下失效；(B10) 是建模假设；L_i 可能保守/非光滑处无界；开放世界语义与对抗投毒不在覆盖内；过度保守会降低可用性。接地层能保证「相对地图正确」，不能保证「地图相对世界正确」——这是 v6 的根本边界。

## 7. 本轮最大风险（最终确认）

**一句话**：**「地图即真值」的自指接地**——配准与语义图都由同一套感知/建图管线产生，接地证书只证明「执行与地图一致」，并不证明「地图与世界一致」；系统性地图误差（回环漂移、过期语义、对抗性点云/标签投毒、标定偏置）不会被随机误差的保形界覆盖，反而可能被阈值膨胀「合法化」。独立模态交叉校验、地图版本/来源链、变化检测与人工抽检只能缓解，无法根除。
