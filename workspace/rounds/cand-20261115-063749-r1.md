# 第 4 轮（灵感循环第 4 轮；本轮灵感：「创新点」×「实时推理」）

> **基线**：第 3 轮 InstructGauge（IP-321–327；定义 432–447；引理 51–58；实验 E441–E456）。第 2 轮 ToolGauge、第 1 轮 LeanGauge / MODGAUGE 骨架继续继承不变。
> 本轮纪律：**增量升级 + 严格退化**。创新点与实时推理各沿一条轴升级 InstructGauge，且任一环节不可用都必须能一键退回；增量复用与时序调度是增强项，不是依赖项。

## 0. 直觉与动机

**灵感 1（创新点 → 把「新」操作化为「失效集」）**
直觉：研究者说「本轮的创新点是 X」时，往往只说了「我加了什么」，却没回答「哪个旧结论因此必须改变、改变多少、什么实验能证伪它」。在一个已经带证书的推理系统里，「新」有天然的操作定义：**当前观测使哪些缓存的中间结论不再可信**。必须重算的节点集合就是失效集 `I`；`I` 之外的计算，在证书意义上与全量重算不可区分。于是「创新点」不再是修辞，而是可定位、可度量、可消融的集合：`I` 越大，输入带来的新信息越多；`I` 越小，可复用的旧结论越多。研究贡献同理：每个 IP 都必须能定位到它改变了哪段推理/哪条契约，并给出相对基线的可证伪增量（`InnovCert`）。口号：**不能定位到失效集的创新，不是可审计的创新。**

**灵感 2（实时推理 → 截止期内的「带证书降级」，而不是更快的模型）**
直觉：实时不是「模型更快」，而是「在截止期内给出一个带误差界、可降级的结果」。平均延迟再低，单次超时也可能让执行器拿到过期或未认证的输出。正确结构是任意时间（anytime）+ 分级降级：mandatory 部分保证最低可用精度与认证，optional 部分在 slack 里逐步精化；截止期到了就丢 optional，绝不丢认证。实时系统还必须回答「最坏情况下这一拍要花多久」，而不是「通常多久」。口号：**可以慢一点，可以旧一点，但不能不知道它是对的还是错的。**

**灵感 3（两者耦合 → 复用率就是 1 − 创新率，失效模式是「自信地陈旧」）**
直觉：复用买来实时，创新禁止复用，两者是同一个量的两端：**复用率 = 1 − 创新率**。最危险的耦合是：实时压力越大，系统越倾向复用；而分布漂移越强，复用证书越可能已经失效。于是失效模式不是「算得慢」，而是「自信地陈旧」——系统以实时为名，把旧观测的结论贴上新时间戳继续用。解法不是禁用复用，而是四根结构支柱：**证书复用**（无证书不重用）、**失效集归因**（只重算 `I` 并记录增量 `Δ`）、**意外度监控**（预测失效 vs 实际失效，模型错了就保守全量）、**新鲜度盾**（宁可用已认证的旧值，也不用未认证的新值），再叠加**增量契约**与**创新点账本**。

## 1. 研究问题（本轮要回答什么）

- **Q1（创新的可操作性）**：能否把「创新点」定义为带证书的失效集 `I`，使「只重算 `I`」在输出语义上等价于全量重算？其最小性与归因边界是什么？
- **Q2（实时的安全交换）**：在截止期约束下，任意时间推理 + 创新感知调度能否在保持 50Hz 的同时给出最坏情况保证？质量-延迟前沿如何量化？
- **Q3（模型错误的放大）**：当失效预测/复用半径在漂移下失效时，「自信地陈旧」能否在造成伤害前被意外度监控捕获，并安全退化？

## 2. 三条设计原则（雏形，正式化见产物区定义 448–463）

**P1 无证书不复用（No Reuse Without Certificate）**
任何被复用的中间结果都必须携带 `ReuseCert`：输入指纹、复用半径 `ρ`、误差容差 `ε`、时效 `A`。缺证书、指纹不匹配、超半径或超时效 ⇒ 该节点进入失效集，必须重算。这把「可复用」从实现细节提升为可审计的证明义务。

**P2 创新点即失效集（Innovation = Invalidation Set）**
每拍只重算失效集 `I` 及其后代闭包，并显式输出增量 `Δ`。`I` 之外的结果在 `ε` 内与全量重算不可区分；因此行为差异必须可归因到 `I`。这条同时是性能来源与审计来源：**没有失效集之外的「暗改」**。

**P3 认证优先于新鲜度，新鲜度优先于精度（Certification ≻ Freshness ≻ Fidelity）**
截止期压力下允许丢 optional 精度，允许回退到旧的已认证值，但绝不允许把未认证的新值送进执行器。降级顺序固定：精化 → 新鲜度 → 保持安全位姿；认证级别只升不降。

## 3. 与基线的接口（如何退化）

- 无 `ReuseCert` / 指纹不可计算 / 区间分析失败 ⇒ 全量重算，等价 InstructGauge 逐步路径；
- 调度不可行 / 过载 ⇒ 关闭 optional 并退回同步周期，等价 ToolGauge 周期；
- 意外度超阈 / 再认证失败 ⇒ `I := V` 保守全量，并回退全局共形（SC-Cal）；
- 新鲜度盾不可用 ⇒ 只使用当前拍认证输出，禁止 stale（实时性下降，安全不降）；
- 增量契约失败 ⇒ 整契约重建（ToolGauge 全量）；
- 逐级退化：DeltaGauge → InstructGauge → ToolGauge → LeanGauge → MODGAUGE；
- 创新点账本不可用 ⇒ 纯解释，剥离为审计文本，不影响数值路径。

## 4. 预期贡献

1. 一个「创新点 = 带证书失效集」的操作定义，连同复用可靠性、最小性与归因三条定理，把「只重算新东西」变成可证伪命题；
2. 一个任意时间 + 创新感知的实时调度器，给出 EDF 可调度条件与质量-预算的最优分配；
3. 一个新鲜度盾 + 意外度监控，把「自信地陈旧」从无界风险压成可检测、可退化的有界风险；
4. 一个增量契约与创新点账本，使每次行为差异都能归因到具体创新点并接受消融审计；
5. 一条完整可证伪路径：E457–E472 覆盖复用可靠性、失效最小性、截止期、质量剖面、意外检测、新鲜度、归因、过载、对抗、50Hz 与 sim→real。

## 5. 本轮最大风险

**一句话**：复用证书是「用没看过来换速度」的承诺，其失效模式不是慢，而是**自信地陈旧**——指纹碰撞、复用半径在分布漂移下过宽、过载时用旧值顶替，都会让系统以实时为名输出未经当前观测认证的结论；真正的残余风险在「证书可靠性假设 × 降级策略」的接口，而不在单个组件。

## 2. 形式化定义（要点）

**定义 448（推理 DAG 与输入指纹）** `G = (V, E, {f_v}, {fp_v})`，节点 `v` 计算 `y_v = f_v(x_v; θ_v)`，`x_v = (y_u)_{u∈Pa(v)} ∪ o`。指纹 `fp_v(o) = H(Q(x_v(o)), θ_v, ver_v, env_id)`，`Q` 为按下游敏感度设计的量化器（对 `ε_v` 以下的变化不敏感）。`Desc(I)` 为 `I` 的后代闭包。指纹必须与证书联用：单靠指纹相同**不构成**可复用证明。

**定义 449（复用证书 ReuseCert）** `R_v = (v, fp_v, ρ_v, ε_v, t_v, A_v, src)`，`src ∈ {interval, lipschitz, conformal, hybrid}`。可靠性条件：对任意 `o'`，若 `fp_v(o') = fp_v(o)`、`d_v(x'_v, x_v) ≤ ρ_v` 且 `now − t_v ≤ A_v`，则 `‖f_v(x'_v) − y_v‖ ≤ ε_v`。证书由区间传播/Lipschitz 界或保形校准签发；不可证 ⇒ 不签。`A_v` 把「空间邻域」与「时间邻域」同时纳入复用条件。

**定义 450（失效集 / 创新点 / 增量）** 对新观测 `o'`，
`I(o') = {v : fp_v(o') ≠ fp_v(o) ∨ d_v(x'_v, x_v) > ρ_v ∨ now − t_v > A_v} ∪ Desc(I)`，
`Δ(o') = {y_v : v ∈ I}`。称 `I` 为**创新点集**（novelty / invalidation set），`Δ` 为**创新增量**。工程含义：本拍真正「新」的计算；研究含义：相对基线可定位、可消融的变化。注意 `I` 由证书前提决定，不由预测器决定。

**定义 451（实时任务与任意时间结果）** 每个节点 `v` 分解为 mandatory 成本 `C^m_v` 与 optional 成本 `C^o_v`。结果 `y_v(b)`，`b ∈ [0, C^o_v]`：`b = 0` 给最低精度 `y_v^m`（误差 `ε^m_v`），`b = C^o_v` 给全精度；`ε_v(b)` 单调不增。任务有截止期 `D_v`。这是 imprecise-computation 模型：先保证能交付，再在 slack 中精化。

**定义 452（调度与分级降级）** 调度 `π` 为每个任务分配时间窗，`feasible(π) = ∀v, finish_v ≤ D_v`。降级算子 `degrade` 的固定顺序：(i) 削 optional 预算；(ii) 缩减并发/块长/工具集；(iii) 回退到 `FreshnessShield` 的 last-certified；(iv) `SAFE_HOLD` 保持安全位姿。禁止任何绕过认证的降级。

**定义 453（预测失效与意外度）** `Î(o')` 为廉价预测器（上拍失效集 + 漂移界 + 轻量 novelty score）给出的预测；`S = I Δ Î`（对称差）；`σ_S = E[|S| / max(1,|V|)]`。**分工公理**：预测器只用于**分配**，不用于**失效判定**；实际失效一律由 `fp/ρ/A` 决定。预测错了的代价是性能，不是正确性；但持续高意外说明证书模型失效，必须再认证。

**定义 454（创新感知分配）** 给定 optional 预算 `b`，求
`max Σ_{v∈I} ν_v · ι_v · Q_v(b_v)  s.t.  Σ b_v ≤ b, 0 ≤ b_v ≤ C^o_v`，
其中 `ν_v` 为新颖度（输入位移/`ρ_v` 或指纹变化幅度），`ι_v` 为下游影响（到输出的敏感度 × 任务相关度），`Q_v` 为定义 461 的凹质量剖面。凹 ⇒ 边际增益贪心/注水最优；线性 + 整块 ⇒ 0/1 背包。

**定义 455（新鲜度盾 FreshnessShield）** `admit(v,t) = 1` 当且仅当 `R_v` 有效、`t − t_v ≤ A_v` 且指纹匹配；否则回退 `last_certified(v)`（要求 `t − t_last ≤ A_max`）；再否则 `SAFE_HOLD`。输出携带 `FreshnessTag(fresh | stale | hold, age, ε_bound)`。安全不变式：执行器只看到 admitted 值。

**定义 456（增量契约与更新）** 契约 `EC = (EC_0, Δ, ver)`，`EC' = EC ⊕ Δ` 只允许修改 `I ∪ Desc(I)`；未触及子图必须逐指令同构。更新后须通过 MODGAUGE 五不变式与 ToolGauge 退化检查；失败 ⇒ 全量重建 `EC_0`。

**定义 457（可调度条件）** `U_m = Σ_v C^m_v / D_v`；单处理器、抢占式、有界阻塞 `B` 下 EDF 可行的一个充分条件为 `U_m + B/D_min ≤ 1`。optional 只在 `slack = 1 − U_m − B/D_min` 中执行，故不影响可行性。创新感知调度以 `I` 为 mandatory 集：`U_m(I) = Σ_{v∈I} C^m_v / D_v`；若 `U_m(I) + B/D_min > 1`，必须先降级再执行。

**定义 458（复用半径再认证）** 抽样节点上的实测残差 `r_v = ‖y_v^{recomputed} − y_v^{cached}‖`。若 `r_v > ε_v` 或 `S` 超阈，则 `ρ_v ← γρ_v`、`A_v ← γ_A A_v`（`γ, γ_A < 1`），并在校准集上重签证书；连续 `q` 次失败 ⇒ 该节点永久退出复用，直到重新标定。这是对证书本身的控制回路。

**定义 459（创新点账本 IL 与 InnovCert）** `InnovCert(ip) = (mechanism, baseline, delta_claim, falsifier, ablation, degeneracy)`，`IL` 只追加，`status ∈ {proposed, supported, demoted}`。每个 IP 必须回答五个问题：改变了哪段推理/契约？相对哪个基线？哪个实验能证伪？去掉它后差多少？不可用时如何退化？账本不参与数值路径。

**定义 460（归因映射 Attr）** 对输出偏差 `δ`，`Attr(δ) = {v ∈ I : |∂y_out/∂y_v| · ‖Δ_v‖ > τ_attr}`。要求：若 `I = ∅` 且所有证书可靠，则 `δ ≤ ε_acc` 且 `Attr = ∅`；因此超出容差的行为差异必须能由 `I` 解释。账本据此拒绝「无失效集支撑」的创新声明。

**定义 461（质量-预算剖面）** `Q_v(b) = −log(ε_v(b) / ε_v(0))`（或任务特定的凹效用），要求单调、凹、可测。它把「多花一点算力能换多少精度」变成可比较的边际量，供定义 454 与引理 62 使用。

**定义 462（端到端预算与 50Hz 条件）** `C_period = C_fixed + Σ_{v∈I} C^m_v + Σ_v b_v + C_verify + C_shield`，要求 `C_period ≤ T_50Hz − margin`。其中 `slack = T_50Hz − C_fixed − Σ C^m_v − C_verify − C_shield` 是 optional 的可用预算；`slack < 0` ⇒ 不可调度，进入降级，不进入执行。

**定义 463（DeltaGauge 审计证书）** `DeltaCert(s) = (I, {R_v}, Δ, π, {FreshnessTag_v}, S, Attr, IL_entry)`；把第 3 轮 `RepairCert′` 的「指令→块→回执→主张」扩展为「观测→复用证书→失效集→增量→调度→新鲜度→归因」，使人类可复现「哪些旧结论被复用、哪些被重算、为什么、新在哪里」。

# IP-328 DRC：复用证书（区间/Lipschitz 证明 + 保形采样兜底）
class ReuseCertifier:
    def certify(self, v, x, ctx):
        fp = fingerprint(v, x, ctx)                  # 量化指纹（含参数/版本/环境）
        rho = self.radius(v, x)                     # 区间传播或经验校准给出的安全半径
        eps = self.tolerance(v, x, rho)             # 局部 Lipschitz 界 / 保形分位
        if rho <= 0 or eps < 0:
            return None                             # 不可证 ⇒ 不发证，每拍重算
        return ReuseCert(v, fp, rho, eps, now(), v.A, src=self.source(v))

# IP-329 DE：增量失效 + 只重算创新点
class DeltaEngine:
    def invalidate(self, G, o):
        I = set()
        for v in topo(G):
            if not cert_valid(G.cert.get(v), o):
                I.add(v)
            elif any(p in I for p in G.parents[v]):
                I.add(v)                            # 后代闭包
            else:
                G.y[v] = G.cache[v]                 # 证书复用
        return I

    def compute(self, G, I, o, alloc):
        for v in topo_induced(G, I):
            G.y[v] = G.f[v](o, b=alloc.get(v, 0))   # 只重算 I，可任意时间
            G.cache[v] = G.y[v]
        return G.y, DeltaCert(I, alloc, ...)

# IP-330 RTS：EDF 保底 + 创新感知 slack 分配
class RTScheduler:
    def schedule(self, I, D, slack):
        mand = sum(Cm[v] for v in I)
        if mand > D:                                # mandatory 不可行 ⇒ 先降级
            return self.degrade(I, D)
        b = D - mand
        order = sorted(I, key=lambda v: nu[v] * iota[v] * dQ[v], reverse=True)
        alloc, used = {}, 0
        for v in order:                             # Q_v 凹 ⇒ 边际贪心/注水最优
            take = min(Co[v], b - used)
            if take <= 0: break
            alloc[v] = take
            used += take
        return Schedule(alloc, feasible=True)

# IP-331 FSH：新鲜度盾（认证 > 新鲜度 > 精度）
def freshness_admit(v, now):
    c = CERT.get(v)
    if c and now - c.t <= c.A and fp_match(c):
        return Y[v], FreshnessTag("fresh", age=now - c.t)
    last = LAST_CERTIFIED.get(v)
    if last and now - last.t <= A_MAX:
        return last.y, FreshnessTag("stale", age=now - last.t)
    return SAFE_HOLD(v)                             # 不输出未认证结果

# IP-332 SM：意外度监控（模型错了就保守全量）
class SurpriseMonitor:
    def update(self, I_pred, I_actual):
        S = I_pred ^ I_actual
        rate = len(S) / max(1, len(I_actual))
        if rate > TAU_S:
            for v in S:
                SHRINK(v, gamma=0.5)                # 定义 458：收缩半径/时效
            recertify(S)
            return True                             # 触发 I := V 保守回退
        return False

# IP-333 ICU：增量契约差分（未触及子图逐指令等价）
def contract_update_delta(EC, dcert):
    touched = dcert.I | descendants(dcert.I)
    EC2 = rebuild_subgraph(EC, touched, dcert)
    if not check_five_invariants(EC2) or not check_degeneracy(EC2):
        return rebuild_full(EC)                     # 退化：整契约重建
    return EC2

# IP-335 DeltaGauge-8C 闭环
def deltagauge_8c(M, s, ell, o):
    I_hat = M.sm.predict(o)                         # 廉价预测，只用于分配
    I = M.de.invalidate(M.G, o)                     # 指纹 + 证书，决定实际失效
    if M.sm.update(I_hat, I):                       # 意外 ⇒ 保守全量
        I = set(M.G.nodes)
    sched = M.rts.schedule(I, M.deadline(s), M.slack(s))
    if not sched.feasible:
        return M.fsh.hold(s)                        # 不输出未认证结果
    y, dcert = M.de.compute(M.G, I, o, sched.alloc)
    y, tag = M.fsh.admit(y)                         # 新鲜度盾
    if not M.icu.update(dcert):
        return M.fsh.fallback(s)                    # 增量失败 ⇒ 全量/同步
    M.il.attribute(dcert, M.baseline(s))            # 创新点归因
    return y, dcert, tag

# IP-335 主闭环（50Hz 路径不变）
def DeltaGauge_round(M, obs, audio, tac, depth, det, ell=None):
    out = InstructGauge_round(M, obs, audio, tac, depth, det, ell)  # 继承
    if M.delta_ready:
        submit_async(deltagauge_8c, M, M.current_spot, ell, out)
    return out

## 4. 推导

**引理 59（复用可靠性 / 误差传播）** 设所有复用节点证书可靠、所有重算节点精确，且 `f_v` 对其父输入的 Lipschitz 常数为 `L_v`。则输出误差
`e_out ≤ Σ_{v∈Frontier} ε_v · Π_{u∈path(v→out)} L_u`，
其中 `Frontier` 是复用与重算的边界；若路径长 ≤ `d`、`ε_v ≤ ε`，则 `e_out ≤ |V| ε L^d`。
*证明*：按拓扑序归纳。复用节点的误差 ≤ `ε_v`；重算节点的误差由父误差经 `L_v` 放大；沿 DAG 用三角不等式求和即得。证书把「未重算」从假设变成可检查的前提。

**引理 60（失效集的必要性 / 最小性）** 在节点粒度与定义 449 的可靠性口径下，若 `v ∈ I`（指纹改变、超半径或超时效），则在不获得新证据且不重签证书的前提下，任何只用 `R_v` 的增量算法都无法把 `y_v` 认证到 `ε_v` 内，故必须重算 `v`。因此 `I` 是证书相对的最小必重算集；额外重算只增加成本，不增加正确性。
*证明*：若不复算且不重签，唯一可用值是 `cache[v]`，但可靠性条件的前提已被违反，无法推出误差界。取证书边界外的输入即可构造误差恰超过 `ε_v` 的反例。推论：`I` 的规模就是本拍必须支付的「创新成本」。

**引理 61（EDF 可调度性与任意时间质量）** 在单处理器、抢占式、有界阻塞 `B` 下，mandatory 集 EDF 可行当且仅当 `U_m + B/D_min ≤ 1`；optional 只在 slack 中执行，故不破坏可行性。若 `ε_v(b)` 单调不增，则任意预算 `b` 的结果都满足对应误差界，且响应时间 `R_v ≤ D_v`。
*证明*：标准 EDF 利用率界 + imprecise computation 的 mandatory/optional 分离；optional 不参与可行性判定，只消耗剩余松弛。

**引理 62（创新感知分配的最优性）** 若 `Q_v` 凹、成本线性，则按边际增益 `ν_v ι_v Q'_v(b_v)` 从大到小注水得到最优分配；若 `Q_v` 线性且 `b_v ∈ {0, C^o_v}`，则为 0/1 背包，贪心达 `1/2` 近似（或 FPTAS）。
*证明*：KKT 条件给出等边际原则；凹函数的边际递减保证交换任意两块预算都不改进；线性情形用标准背包近似界。故「把算力花在最新的地方」有可证的最优性形式。

**引理 63（意外度与「自信地陈旧」的界）** 设意外检测漏检率为 `p_miss`、单节点最大陈旧误差为 `ε_max`。则一个实际已失效但被复用的节点对输出的期望污染 ≤ `p_miss · ε_max · L^d`；一旦 `S` 超阈触发 `I := V` 全量回退，污染为 0。抽样率为 `m` 时，漂移检测延迟 ≤ `⌈1/m⌉` 拍。
*证明*：全概率公式：只有漏检才可能污染，检出即回退；抽样等待时间服从几何分布。该界把「自信地陈旧」从无界风险压成由检测率控制的有界风险。

**引理 64（新鲜度盾的安全性）** 新鲜度盾保证进入执行器的每个值要么有有效 `ReuseCert` 且 `age ≤ A_v`，要么是 `last_certified` 且 `age ≤ A_max`，要么 `SAFE_HOLD`。因此输出误差 ≤ `max(ε_acc, L·A_max)`，且不存在「未认证新值」路径。截止期错过只降低新鲜度/精度，不降低认证级别。
*证明*：对 `admit` 的三种分支逐一检查；`SAFE_HOLD` 不产生运动，故安全；`stale` 分支的误差由状态漂移界 `L·age ≤ L·A_max` 给出。

**引理 65（增量契约与不变量保持）** 若 `EC_0` 满足 MODGAUGE 五不变式且 `Δ` 在 `I ∪ Desc(I)` 上可靠，则 `EC' = EC_0 ⊕ Δ` 仍满足五不变式；在 `V \ (I ∪ Desc(I))` 上与 `EC_0` 逐指令同构；所有行为变化可归因到 `I`。
*证明*：结构归纳。未触及节点的证书与输入未变，故其值不变；五不变式均为局部谓词，只依赖被修改节点及其邻域；差分未触碰的边保留原证明。退化到 ToolGauge/InstructGauge 时，只需令 `Δ` 覆盖全图。

**引理 66（端到端实时界 / 复用 Amdahl 律）** 设全量重算成本 `C_full`、失效集成本 `C_I`、复用比例 `r = 1 − C_I / C_full`、固定开销 `C_0`。则 `C_period = C_0 + C_I`，相对全量加速 `S = C_full / (C_0 + C_I) ≤ 1/(1 − r)`。50Hz 可行的充分条件为 `C_0 + C_I ≤ T_50Hz − margin`；当 `r → 1` 时收益饱和，说明实时上限由「不可复用部分」决定。
*证明*：直接代入；Amdahl 律的标准形式。推论：要让场景规模增长而周期不变，必须让失效集（而非全图）随规模增长。

**引理 67（创新点归因与账本可审计）** 若 (i) 所有证书可靠；(ii) `I = ∅`；(iii) 上下文未变，则由引理 59，`‖y − y_base‖ ≤ ε_acc`，故任何超过容差的行为差异必须来自 `I` 或证书失效。若各 `InnovCert` 的消融节点集两两不交，则账本中各 IP 的实测贡献之和 ≤ 总改进（无重复计数）；贡献不显著者必须降级为 `demoted`。
*证明*：引理 59 的逆否命题；消融是 DAG 上的 do-操作，不交节点集的效应可加；交集节点会被重复计入，故要求不交。这条把「创新点清单」从叙述变成可审计对象。
