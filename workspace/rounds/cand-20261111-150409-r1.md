# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「在线学习」×「抓取规划」）

> 第 54 轮把技能组合从能力匹配升级为动作-鲁棒性双证书（`α_S`、`γ_ce`、`J`），但隐含一个关键假设：动作剖面是**离线校准且静态**的（A26）。本轮聚焦 **证书的时间失效与在线自适应**。核心矛盾：**H22：证书合法性 ≠ 技能有效性**，分布漂移下离线 `α_S/ρ` 会陈旧，出现"证还在、技已废"；**H23：在线学习必须探索，而探索本身会侵入已验证的安全动作核心**，破坏证书 soundness。抓取规划（接触丰富、接触模式跳变）是把这两个矛盾逼到极限的试金石。

## 0. 直觉与动机

**灵感 1（证书会过期 → 给证书装"保质期 + 漂移计"）**
直觉：静态证书 `J` 像一张没有生产日期的合格证。现实里物体材质、光照、夹爪磨损都在变，`α_S` 与 `ρ` 都会漂移。应把证书升级为 **时间锁定证书 DLC**：附带校准时刻 `t_cal`、有效期 `τ_C`、分布漂移预算 `ε_C`、以及动作覆盖/鲁棒性的**置信下界** `α^-、ρ^-`。部署判据从 `δ_a < Θ_a` 强化为 `未过期 ∧ 漂移未超预算 ∧ 下界仍覆盖`。证书因此从"布尔判定"变为"带时间维的谓词 `valid(C,t)`"。

**灵感 2（抓取是把动作剖面推向极限的试金石 → 接触模式分段的可供性场）**
直觉：抓取动作空间 `G = SE(3) × 夹爪配置` 是**接触模式分段**的：自由空间、稳定接触、滑动、卡死，各模式内部平滑、模式边界跳变。第 54 轮用全局平滑假设定义 `α_S`，在接触边界会系统性失真，`compat` 与 `γ_ce` 也会在模式跳变处崩。应引入 **抓取可供性场 GAF**：按接触模式 `m ∈ M` 分段定义剖面，模式内 Lipschitz、模式间有界跳变；抓取规划变成"带模式节点的增广图搜索 + 力闭合残差门"。它同时是上一轮证书体系的压力测试。

**灵感 3（在线学习必须"带着证书"学 → 安全探索治法）**
直觉：在线更新 `α_S` 需要新样本，但最缺样本的地方恰是高风险边界。无约束探索会先把安全核心 `A_core` 破坏掉。应设 **安全探索治法 SEG**：探索只允许发生在缓冲带 `A_buffer \ A_core`；核心区冻结为"只读验证"；任何更新先做**证书回归检查**，不通过则原子回滚并把该动作区域拉黑 `T_cool`。在线学习因此是**证书约束下的学习**，而非自由探索。

**灵感 4（组合图要"保鲜" → 增量组合与失效传播）**
直觉：第 54 轮 `G_S` 的边是一次性构建的。在线漂移下，某技能剖面更新可能让一条边失效，而失效会沿缓存路径传播。应做 **增量组合图 ISC**：边带时间戳与置信下界 `compat^-`，路径重规划由**失效传播半径** `R_inv(S_k)` 触发，而非全图重建。这等价于对组合图做增量一致性维护，把 `O(|S|²)` 重建摊还到 `O(deg(k)+|P_c|)`。

**灵感 5（把在线自适应纳入金字塔 → 时间自适应层 𝕋）**
直觉：在动作-协同层 `𝔸` 之上加 **时间自适应层 `𝕋`**：`𝕋_0` 分布漂移检测，`𝕋_1` 在线剖面更新，`𝕋_2` 证书再认证，`𝕋_3` 组合图失效传播。跨层传递的不再是静态证书，而是 **(证书, 有效期, 漂移, 置信下界)** 四元组。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（漂移锁定证书 DLC）**
证书 `C = (payload, t_cal, τ_C, ε_C, α^-, ρ^-)`，其中 `payload = J`（第 54 轮联合证书）。有效性谓词：
```
valid(C,t) = (t - t_cal ≤ τ_C)                        # 未过期
           ∧ (D̂_t ≤ ε_C)                              # 漂移未超预算
           ∧ (∀ a∈A_core: α^-_S(a) ≥ θ_cov)            # 覆盖下界仍成立
           ∧ (∀ d∈𝔇_ρ: ρ^-(d) ≥ ρ_min)                 # 鲁棒性下界仍成立
```
其中 `D̂_t` 为在线漂移估计（特征空间 MMD 或 KL 的保守上界）。`valid=⊥` 记为**证书休克**，必须再认证或降级。

**定义 122（在线动作剖面 OAP）**
在时刻 `t` 观测批 `Z_t`，按动作分组的经验均值 `μ̂_a`、无偏方差 `σ̂²_a`、样本数 `n_a`。递推更新：
```
α_S^{(t)}(a) = Proj_[0,1]((1-η_t)·α_S^{(t-1)}(a) + η_t·μ̂_a)
```
学习率满足 Robbins–Monro：`Σ_t η_t = ∞`，`Σ_t η_t² < ∞`。安全决策只用**经验 Bernstein 下界**：
```
α^-_S(a) = α_S^{(t)}(a) - sqrt(2·σ̂²_a·ln(2/δ)/n_a) - (7/3)·ln(2/δ)/(n_a-1)
```
仅当 `n_a ≥ n_min` 时该动作可进入证书。

**定义 123（抓取可供性场 GAF）**
`G_S : SE(3) × G × M → [0,1]`，`M = {free, contact, slip, jam}` 为接触模式。要求：
- 模式内 `L_m`-Lipschitz：`|G_S(a,m) - G_S(a',m)| ≤ L_m·d(a,a')`；
- 模式间有界跳变：`|G_S(a,m) - G_S(a,m')| ≤ J_M`；
- 成功抓取存在模式序列 `m_0→…→m*`，满足 `G_S(a*,m*) ≥ θ_g` 且力闭合残差 `r_fc(a*) ≤ ε_fc`。
抓取规划 = 在增广图 `(action, mode)` 上搜索，模式切换边权为 `c_mode`。

**定义 124（安全探索区域与 SEG 治法）**
探索域 `A_explore = A_buffer \ A_core`，并叠加风险门 `risk(a) ≤ δ_exp`。更新 `α^{new}` 必须通过**证书回归检查**：
```
regress(α^{new}, α^{old}) = max_{a∈A_core} ( α^-_{old}(a) - α^-_{new}(a) )_+ ≤ ε_reg
```
不通过则原子回滚，并把相关动作拉黑 `T_cool`（滞回）。探索预算 `B_exp(t)` 随证书停滞时间衰减。

**定义 125（增量组合图与失效传播）**
边 `e=(i,j)` 携带 `(t_e, compat^-_e)`。边有效当且仅当
```
valid_edge(e) = (compat^-_e ≥ θ_a) ∧ valid(DLC_i) ∧ valid(DLC_j)
```
技能 `S_k` 更新时，失效半径 `R_inv(S_k) = { e | e 与 k 关联 ∨ e 落在经过 k 的缓存路径上 }`。只对与 `R_inv` 相交的路径重规划。

**定义 126（时间自适应证书 TAC）**
跨层传递四元组 `T = (C_static, t_cal, τ_C, ε_C)`，并把漂移分解为环境漂移与策略漂移 `D̂_t = D_env + D_pol`。部署要求 `valid(C,t)=⊤` 且漂移引起的鲁棒性退化 `Δρ_drift ≤ δ_ρ`，否则降级到"仅监控"状态。

## 2. 关键算法 伪代码

### IP-121 OAP（Online Action Profiling）

```python
def online_profile_update(alpha_prev, obs_batch, eta_t, delta):
    alpha_new, stats = {}, {}
    for a, rewards in group_by_action(obs_batch).items():
        n = len(rewards)
        if n < 2:
            alpha_new[a] = alpha_prev.get(a, 0.5); stats[a] = (0.0, n); continue
        mu, var = mean(rewards), var_unbiased(rewards)
        mu_t = clip((1 - eta_t) * alpha_prev.get(a, 0.5) + eta_t * mu, 0.0, 1.0)
        lcb = mu_t - sqrt(2 * var * log(2 / delta) / n) - 7 * log(2 / delta) / (3 * (n - 1))
        alpha_new[a] = mu_t
        stats[a] = (max(0.0, lcb), n)
    return alpha_new, stats

def certifiable(alpha_stats, A_core, theta_cov, n_min):
    return all(alpha_stats[a][1] >= n_min and alpha_stats[a][0] >= theta_cov
               for a in A_core)
```

### IP-122 DLC（Drift-Locked Certificate）

```python
def drift_locked_valid(C, t, drift_est):
    if t - C.t_cal > C.tau_C:            return ('stale', 'timeout')
    if drift_est > C.eps_C:              return ('stale', 'drift')
    if any(C.alpha_lb[a] < C.theta_cov for a in C.A_core):
        return ('stale', 'coverage')
    if any(C.rho_lb[d] < C.rho_min for d in C.dims):
        return ('stale', 'robustness')
    return ('valid', None)

def recertify(C_old, alpha_new, stats, t):
    if not certifiable(stats, C_old.A_core, C_old.theta_cov, C_old.n_min):
        return ('reject', 'regression_or_underpowered')
    return ('ok', C_old._replace(t_cal=t, alpha_lb={a: stats[a][0] for a in stats}))
```

### IP-123 GAF（Grasp Affordance Field）

```python
def grasp_affordance(skill, pose, gripper, mode, model, eps_fc):
    if mode == 'free':
        return model.free_reachability(pose, gripper)
    if mode == 'contact':
        q = model.contact_quality(pose, gripper)
        return q if model.force_closure_residual(pose, gripper) <= eps_fc else 0.0
    if mode == 'slip':
        return model.stick_probability(pose, gripper) * (1 - model.slip_margin(pose))
    if mode == 'jam':
        return 0.0  # 卡死视为不可用，仅用于检测回退
    raise ValueError(mode)

def mode_aware_plan(G_aug, start, goal, theta_g, J_M):
    # G_aug 节点为 (pose,gripper,mode)，模式切换边带 c_mode 与跳变上界 J_M
    return a_star(G_aug, start, goal,
                  heuristic=lambda n: cost_align(n) + J_M * mode_distance(n, goal))
```

### IP-124 SEG（Safe Exploration Governor）

```python
def safe_explore_update(alpha, A_core, A_buffer, obs, eta, eps_reg, budget):
    if budget <= 0:
        return alpha, 'budget_exhausted'
    A_explore = A_buffer - A_core
    obs_safe = [z for z in obs if z.a in A_explore and risk(z.a) <= DELTA_EXP]
    alpha_new, stats = online_profile_update(alpha, obs_safe, eta, DELTA)
    if regress_lcb(alpha_new, alpha, stats, A_core) > eps_reg:
        blacklist({z.a for z in obs_safe}, T_COOL)
        return alpha, 'rollback'
    return alpha_new, 'ok'
```

### IP-125 ISC（Incremental Skill Composition）

```python
def invalidate_and_replan(G, k, cached_paths, theta_a):
    affected = set(incident_edges(G, k))
    for p in cached_paths:
        if k in p.nodes:
            affected.update(p.edges)
    for e in affected:
        G[e].fresh = (G[e].compat_lb >= theta_a
                      and valid_edge(G, e))
    return replan_intersecting(G, affected, cached_paths)

def refresh_edge(G, e):
    G[e].compat_lb = min(compat_lb(G, e.u), compat_lb(G, e.v))
    G[e].fresh = G[e].compat_lb >= THETA_A
```

### IP-126 TAC（Temporal Adaptive Certificate）

```python
def temporal_cert(C_static, t_cal, tau_C, eps_C, drift_env, drift_pol, delta_rho_budget):
    drift = drift_env + drift_pol
    if age(t_cal) > tau_C or drift > eps_C:
        return ('reject', 'cert_expired', drift)
    if drift * sensitivity(C_static) > delta_rho_budget:
        return ('degrade', 'monitor_only', drift)
    return ('ok', TemporalCert(C_static, t_cal, tau_C, eps_C, drift))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| OAP | `O(Σ_t n_t)`（摊还 `O(|A|·n_t)`） | `O(|A|)` | Bernstein 下界有效、`n_min` 把关 |
| DLC | `O(|A_core| + |𝔇_ρ|)` | `O(|A|+|𝔇_ρ|)` | 漂移估计保守、有效期单调 |
| GAF | `O(|SE(3)_d|·|G|·|M|)` 离线；`O(|M|)` 在线 | `O(|SE(3)_d|·|G|·|M|)` | 模式内 Lipschitz、模式间跳变有界 |
| SEG | `O(|obs_safe| + |A_core|)` | `O(|A_core|+|A_buffer|)` | 回归检查原子、回滚幂等 |
| ISC | `O(deg(k)+|P_c|)`（增量）vs `O(|S|²)` 重建 | `O(|V|+|E|)` | 失效传播完备、边保鲜 sound |
| TAC | `O(|𝔇_ρ|)` | `O(|𝔇_ρ|)` | 漂移可加、灵敏度有界 |

**正确性定理（Online Certified Adaptation Soundness）**
假设第 54 轮 (A26)–(A28) 成立，并新增：
**(A29)** 在线更新使用经验 Bernstein 下界，置信度 `1-δ_cb` 逐动作成立；
**(A30)** 漂移估计器保守：`D̂_t ≥ D_true - β_D` 以概率 `≥ 1-δ_D`；
**(A31)** SEG 保证探索不修改 `A_core` 超过 `ε_reg`，且回滚原子幂等；
**(A32)** 抓取模式误分类概率 `≤ p_m`，模式间跳变上界 `J_M`。

则对任意部署时刻 `t`，在 `valid(C,t)=⊤` 条件下：
```
P(fail at t | valid(C,t)) ≤ |A_core|·δ_cb + β_D + β_E
                          + P(δ_a > Θ_a) + p_m·J_M
```
且在线剖面的非平稳累积遗憾：
```
Regret_T ≤ O( sqrt(|A|·T·ln(1/δ_cb)) + sqrt(|A|·T·V_T) )
```
其中 `V_T` 为分布总变差预算。关键：**下界化使"证书合法 ⇒ 真实覆盖"成为概率保证**，**有效期与漂移预算把非平稳性显式计价**，**SEG 把探索隔离在缓冲带**。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 漂移阈值难校准、证书频繁休克 | 高 | conformal 双阈值 + 分级降级证书 + 休克缓存 |
| 在线学习灾难性遗忘 | 高 | 核心区冻结 + 经验回放 + EWC 正则 |
| 抓取接触模式跳变使证书边界失效 | 高 | 模式分层剖面 + 保守跳变上界 `J_M` + 力闭合硬门 |
| 探索预算与安全硬冲突 | 中 | 安全盾 + 原子回滚 + 拉黑滞回 |
| 失效传播半径低估导致陈旧路径 | 中 | 反向依赖索引 + 周期性全量审计 |

## 6. 本轮最大风险

**一句话**：把静态证书升级为"在线学习 + 时间锁定"虽解决了分布漂移下的证书陈旧，但其 soundness **同时依赖三条脆弱假设——漂移估计的保守性、在线下界在非平稳流上的有效性、以及接触模式跳变界 `J_M` 的真实性**；一旦漂移被低估、或抓取在模式边界发生未建模的跳变，`valid(C,t)=⊤` 会给出**虚假的安全感**，系统在"证书合法"的名义下持续部署已失效技能，因而必须以 **conformal 漂移校准 + 非平稳下界复核 + 抓取力闭合硬门** 三重护栏，宁可频繁休克降级，也绝不把"未检测到漂移"当作"没有漂移"。

## 2. 关键算法 伪代码

### IP-121 OAP

```python
def online_profile_update(alpha_prev, obs_batch, eta_t, delta):
    alpha_new, stats = {}, {}
    for a, rewards in group_by_action(obs_batch).items():
        n = len(rewards)
        if n < 2:
            alpha_new[a] = alpha_prev.get(a, 0.5); stats[a] = (0.0, n); continue
        mu, var = mean(rewards), var_unbiased(rewards)
        mu_t = clip((1 - eta_t) * alpha_prev.get(a, 0.5) + eta_t * mu, 0.0, 1.0)
        lcb = mu_t - sqrt(2 * var * log(2 / delta) / n) - 7 * log(2 / delta) / (3 * (n - 1))
        alpha_new[a] = mu_t
        stats[a] = (max(0.0, lcb), n)
    return alpha_new, stats

def certifiable(alpha_stats, A_core, theta_cov, n_min):
    return all(alpha_stats[a][1] >= n_min and alpha_stats[a][0] >= theta_cov
               for a in A_core)
```

### IP-122 DLC

```python
def drift_locked_valid(C, t, drift_est):
    if t - C.t_cal > C.tau_C:            return ('stale', 'timeout')
    if drift_est > C.eps_C:              return ('stale', 'drift')
    if any(C.alpha_lb[a] < C.theta_cov for a in C.A_core):
        return ('stale', 'coverage')
    if any(C.rho_lb[d] < C.rho_min for d in C.dims):
        return ('stale', 'robustness')
    return ('valid', None)

def recertify(C_old, alpha_new, stats, t):
    if not certifiable(stats, C_old.A_core, C_old.theta_cov, C_old.n_min):
        return ('reject', 'regression_or_underpowered')
    return ('ok', C_old._replace(t_cal=t, alpha_lb={a: stats[a][0] for a in stats}))
```

### IP-123 GAF

```python
def grasp_affordance(skill, pose, gripper, mode, model, eps_fc):
    if mode == 'free':
        return model.free_reachability(pose, gripper)
    if mode == 'contact':
        q = model.contact_quality(pose, gripper)
        return q if model.force_closure_residual(pose, gripper) <= eps_fc else 0.0
    if mode == 'slip':
        return model.stick_probability(pose, gripper) * (1 - model.slip_margin(pose))
    if mode == 'jam':
        return 0.0  # 卡死视为不可用，仅用于检测回退
    raise ValueError(mode)

def mode_aware_plan(G_aug, start, goal, theta_g, J_M):
    # G_aug 节点为 (pose,gripper,mode)，模式切换边带 c_mode 与跳变上界 J_M
    return a_star(G_aug, start, goal,
                  heuristic=lambda n: cost_align(n) + J_M * mode_distance(n, goal))
```

def safe_explore_update(alpha, A_core, A_buffer, obs, eta, eps_reg, budget):
    if budget <= 0:
        return alpha, 'budget_exhausted'
    A_explore = A_buffer - A_core
    obs_safe = [z for z in obs if z.a in A_explore and risk(z.a) <= DELTA_EXP]

def temporal_cert(C_static, t_cal, tau_C, eps_C, drift_env, drift_pol, delta_rho_budget):

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| OAP | `O(Σ_t n_t)`（摊还 `O(|A|·n_t)`） | `O(|A|)` | Bernstein 下界有效、`n_min` 把关 |
| DLC | `O(|A_core|+|𝔇_ρ|)` | `O(|A|+|𝔇_ρ|)` | 漂移估计保守、有效期单调 |
| GAF | `O(|SE(3)_d|·|G|·|M|)` 离线；`O(|M|)` 在线 | `O(|SE(3)_d|·|G|·|M|)` | 模式内 Lipschitz、模式间 `J_M` 有界 |

| ISC | `O(deg(k)+|P_c|)`（增量）vs `O(|S|²)` 重建 | `O(|V|+|E|)` | 失效传播完备、边保鲜 sound |
| TAC | `O(|𝔇_ρ|)` | `O(|𝔇_ρ|)` | 漂移可加、灵敏度有界 |

**正确性定理（Online Certified Adaptation Soundness）**
假设第 54 轮 (A26)–(A28) 成立，新增：
**(A29)** 在线更新使用经验 Bernstein 下界，置信度 `1-δ_cb` 逐动作成立；
**(A30)** 漂移估计器保守：`D̂_t ≥ D_true - β_D`，概率 `≥ 1-δ_D`；
**(A31)** SEG 保证探索不修改 `A_core` 超过 `ε_reg`，回滚原子幂等；
**(A32)** 抓取模式误分类概率 `≤ p_m`，模式间跳变上界 `J_M`。

则对任意部署时刻 `t`，在 `valid(C,t)=⊤` 下：
```
P(fail at t | valid(C,t)) ≤ |A_core|·δ_cb + β_D + β_E
                          + P(δ_a > Θ_a) + p_m·J_M
```
非平稳累积遗憾界：
```
Regret_T ≤ O( sqrt(|A|·T·ln(1/δ_cb)) + sqrt(|A|·T·V_T) )
```
关键：**下界化 ⇒ 证书合法即真实覆盖的概率保证**；**有效期+漂移预算 ⇒ 非平稳性显式计价**；**SEG ⇒ 探索与安全核心物理隔离**；**ISC ⇒ 失效沿依赖图传播而非全图重建**。

## 5. 本轮最大风险

**一句话**：把静态证书升级为"在线学习 + 时间锁定"虽解决了分布漂移下的证书陈旧，但其 soundness **同时依赖三条脆弱假设——漂移估计的保守性、在线下界在非平稳流上的有效性、以及接触模式跳变界 `J_M` 的真实性**；一旦漂移被低估、或抓取在模式边界发生未建模的跳变，`valid(C,t)=⊤` 会给出**虚假的安全感**，系统在"证书合法"的名义下持续部署已失效技能，因而必须以 **conformal 漂移校准 + 非平稳下界复核 + 抓取力闭合硬门** 三重护栏，宁可频繁休克降级，也绝不把"未检测到漂移"当作"没有漂移"。
