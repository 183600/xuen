# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「具身智能」×「关节空间控制」）

> R69 问出了「我该向谁求证、还能问什么」，但它的提问始终是**无身体**的：信息动作 `g=(凝视/探针/问句)` 直接定义在任务空间，系统默认「只要想得出这个动作，就做得出；只要做得出，就看得清」。这个隐含前提在真实机器人上处处断裂——手够不到那个能看清反光的位姿、腕部接近奇异时力觉分辨率骤降、为了分辨两种抓法而转动的手腕把自己顶到了关节限位、零空间里悄悄补偿的力矩把任务空间的残差抹平了。**具身智能**提醒我们：身体不是执行器，而是推理的一部分，形态决定了「什么问题问得出来」；**关节空间控制**则指出：真正被约束、被饱和、被奇异支配的是 `q, q̇, τ`，而 R69 的全部证书都写在任务空间。
>
> 于是本轮的问题从「我该向谁求证」下沉一层，变成：**我的身体允许我把这个问题问清楚吗？我能否在不移动任务位姿、不消耗安全裕度的前提下，重排身体构型让歧义变得可观测？** 这把「主动交互」从任务空间的符号动作，升级为**关节空间的可实现性 + 可辨识性 + 裕度预算**三者的联合规划。
>
> 核心命题：**继承 R69 的 aleatoric/epistemic 二分与「安全永不弱化」姿态，但把 epistemic 的可解性判据从任务空间搬到关节空间：只有当存在一个关节空间可行、任务位姿可保持（或扰动 ≤ ε_probe）、且可辨识性 κ(q) ≥ κ_min 的探针时，歧义才是「可问的」；否则它在本体上就是不可约的，必须按 R69 兜底保守处理。** 命名 **EMBODY-RAS**（Embodied Morphology-aware Body-configuration Observability & Yield-aware Risk-Adaptive Safety）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我的身体允许我问这个问题吗，代价是什么，会不会问着问着把自己摆到危险里**」。

## 0. 直觉与动机

**灵感 1（具身智能 → 形态是可辨识性的先验）**
直觉：同样一双眼睛，站在正面看得清表情，站在侧面只能看见轮廓；同样一只触觉手，指尖正对表面时能分辨纹理，斜着蹭过去只能感到「粗糙」。观测质量不是策略的属性，而是**构型的函数** `p(y | q, M)`。R69 把「看清」当成一个抽象的 VoI 项，EMBODY 把它具体化为：在可达构型集里，两种模态的观测分布到底分不分得开。具身智能的第一性原理因此不是「有身体」，而是**身体把「不确定性」投影成了「几何」**——有些歧义在某个位形下是显然的，在另一个位形下是原理上不可分辨的。

**灵感 2（关节空间控制 → 任务空间证书是盲的）**
直觉：R68/R69 的安全证书都长在任务空间（`x, ẋ` 与 WM 前缀）。但一个任务空间完全安全的前缀，可能在关节空间里：逼近奇异（`σ_min(J)→0`，逆解爆炸）、顶住关节限位、力矩饱和、热降额、甚至自碰撞。**任务空间的「安全」只是关节空间「可行」的一个投影**，投影会把不可行的部分全部抹掉。这给出本轮的第一条硬贡献：任务证书与关节证书是**交**而不是**或**；只过前者，安全侧就是漏的。

**灵感 3（冗余 → 零空间是「免费」的提问通道）**
直觉：7 自由度机械臂在固定末端位姿下仍有一维自运动流形。人也是这样：手不动，肘可以转。这条零空间不是浪费，而是**可以在不改变任务位姿的前提下改变观测几何**的免费自由度——把相机/腕部转到反光消失的角度、把接触点绕到更易分辨的边缘、把力探针换一个杠杆臂。关键判据很干净：**可辨识性梯度在零空间上的投影非零**，才能「不动手地问」。若它在行空间里，想看得更清就必须动任务本身——那就不是免费的了。

**灵感 4（身体也会「吸收」错误 → 第三条冗余通道）**
直觉：R68 的自陈风险是缓变故障被标定吸收（`r_res≈0`）；R69 用流似然 `Δa` 做第二意见。但这两种都还在「任务/行为」层。关节空间控制里有一种更隐蔽的吸收：**控制器用零空间力矩、关节柔顺或饱和边缘把误差吃掉了**，任务位姿看起来完美，实际上力矩已经贴边、某个关节在偷偷超常发力。于是需要第三条独立通道 `t_res`（关节力矩残差/裕度），它与 `r_res`、`Δa` 正交。三条通道同时看，才可能把「传感器骗人 / 行为骗人 / 身体骗人」分开。**这是对 R69 「用冗余通道做第二意见」思想的继续下沉，而不是重复。**

**灵感 5（提问要花裕度 → 信息不能与安全做交易）**
直觉：任何探针都要动关节，动关节就要占用力矩/速度/限位裕度，靠近奇异还会放大误差。R69 的预算只算了时间与社交成本，没算**本体安全裕度**。EMBODY 立铁律：安全可行集与 epistemic 收益**无关**；探针只能在「裕度 ≥ δ_min」的内点里选，绝不能为了看得更清把身体推到奇异或限位边缘。**信息的单位是焦耳与毫米裕度，不是比特。**

**灵感 6（身体决定可问性 → 正面拆掉 R69 的幻影提问风险）**
直觉：R69 最大的风险是「自信地追问一个幻影」。身体给了我们一个**先验的否决权**：如果对所有可达构型 `q`，两种模态的观测分布 KL 都小于可分阈值，那么无论怎么问都问不出来——这不是策略没学好，而是**这个问题对本体不可答**。系统应当在动手之前就算出来、直接判为不可约并保守退避，而不是花一次昂贵交互去「确认自己问不出来」。这把 R69 的「问错比不问更危险」变成「**先证明问得出来，再问**」。

## 1. 形式化定义（增量：定义 310–327）

**定义 310（EMBODY-RAS 总览）** EMBODY-RAS = (JSC, COI, EPP, NSA, EAR, MINT-E, RAS-WM§)。四条不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i；内环逐指令 = R69 FLUID-RAS + 关节安全门）；
(ii) **双证书合取**：任何动作必须同时通过 C-RAS-WM 任务证书与 JSC 关节证书，任一不过即拒；
(iii) **安全集与信息收益无关**：`F = F_task ∩ F_joint` 不随 `M` 的后验或 VoI 改变，探针只在 `F` 内点（裕度 ≥ δ_min）选取；
(iv) **可问性先行**：只有存在 `κ(q) ≥ κ_min` 的可实现探针时，`U_epi` 才被视为可约；否则立即按 R69 兜底。

**定义 311（关节空间嵌入）** 关节构型 `q ∈ Q ⊆ ℝ^n`，任务坐标 `x = f(q) ∈ 𝒳 ⊆ SE(3)^m`，雅可比 `J(q) = ∂f/∂q ∈ ℝ^{6m×n}`，冗余度 `r = n − rank J(q)`。R69 的任务动作块 `a_{t:t+H}` 经全身逆解 `IK(a; q_0)` 映射为关节轨迹 `q_{t:t+H}`；同一 `a` 的原像构成自运动流形（fiber）。

**定义 312（关节空间安全证书 JSC）** 对时域 H 的关节轨线，定义约束集
`C_joint = { q ∈ Q_lim, |q̇| ≤ q̇_max(τ,T), τ ∈ [τ_min(q̇), τ_max(q̇,T)], σ_min(J(q)) ≥ σ_floor, d_self(q) ≥ d_min, T_joint ≤ T_max }`，
其中 `τ_max` 随速度与温度降额。`F_joint = f(C_joint)`。JSC 有效 ⇔ `q_{t:t+H} ∈ C_joint`。它与 R68/R69 的任务证书**独立且必须同时满足**（定义 310-ii）。

**定义 313（位形可辨识性 COI）** 隐藏模态 `M ∈ {1..K̂}`（来自 R69 定义 296）。观测模型 `y = h(q, M) + ε`。对模态对 `(i,j)` 定义位形分离度
`D_ij(q) = KL( p(y | q, i) ‖ p(y | q, j) )`，
`κ(q) = min_{i≠j} D_ij(q)`。称 `(i,j)` 在 `q` 处 **δ-可分** ⇔ `D_ij(q) ≥ δ_sep`。连续模态时以 Fisher 信息 `I_M(q)` 的 `λ_min` 替代（`κ(q)=λ_min(I_M(q))`）。

**定义 314（位形探针）** 关节空间探针 `g_q = (q_probe(·), 接触/注视调度)`，是一段短时关节空间偏移（零空间或任务空间），其目的不是执行任务而是改变观测通道 `h(·, M)`。R69 的信息动作 `g` 实现为某个 `g_q`；若不存在实现，则 `g` 不可执行。

**定义 315（提问可实现集）** `G_reach(o) = { g_q | ∃ q(·) ∈ C_joint, x(q(t)) 与当前任务位姿偏差 ≤ ε_probe（零空间探针要求偏差 = 0）, 且末态回到安全集 }`。称 `g_q` 对该体**可实现**。EMBODY 只允许在 `G_reach` 内提问。

**定义 316（具身信息价值 MINT-E）** 对 `g_q ∈ G_reach`：
`VoI_e(g_q) = H(M|o) − E_{y~p(·|g_q,o)}[H(M|o,y)] − c_q(g_q)`，
`c_q = λ_e·E∫τ^T R τ dt + λ_m·(裕度消耗) + λ_t·时间`；选择 `g_q* = argmax VoI_e`，s.t. 裕度 `m(q,τ) ≥ δ_min` 且预算未超。若 `max VoI_e ≤ 0` 或 `G_reach=∅`：不交互，走 R69 兜底。

**定义 317（零空间分解与投影）** 全身力矩 `τ = J^T F_task + N τ_null`，零空间投影 `N = I − J^T J^{†T}`（`J^{†}` 为伪逆）。`N τ_null` 不改变任务位姿的一阶效应。

**定义 318（任务保持探针）** 自运动 `q_null(t)` 满足 `f(q_null(t)) = f(q_0)`（或偏差 ≤ ε_null 的准零空间），称为任务保持探针。其信息增益完全来自 `D_ij(q)` 随 `q` 的变化，任务前缀证书保持不变。

**定义 319（冗余三用途分配 NSA）** 零空间力矩按优先级分配：
(i) 限位/奇异规避（硬）；
(ii) 可辨识性提升 `∇_q κ(q)` 的零空间分量（软，受定义 316 预算约束）；
(iii) 探针/次级任务。
即 `τ_null = Π_{hard}(τ) + Π_{soft}(∇_qκ) + τ_probe`，且硬项永远优先、软项不得使 `m < δ_min`。

**定义 320（具身吸收残差 EAR）** 定义关节侧残差
`t_res = max(0, 1 − min_i (τ_max,i(q̇,T) − |τ_i|)/τ_max,i)`（力矩贴边度）
与 `α_null = ||N^T e_task|| / (||J^T e_task|| + ε)`（任务误差被零空间吸收的比例）。**具身吸收判据**：`r_res↓ ∧ α_null↑ ∧ t_res↑` ⇒ 控制器/柔顺在替任务空间「吃掉」误差。它与 R69 的 `Δa`（行为似然）、R68 的 `r_res`（传感器残差）构成**三正交通道**。

**定义 321（双时间尺度）** 内环（控制频率）逐指令 = R69 闭环 + JSC 快速检查（O(n)）；外环（~1Hz）执行 COI 估计、EPP 探针规划、NSA 慢分配。信息动作天然是慢过程，不挤占实时安全环。

**定义 322（关节安全门 JSG）** 执行前检查 `σ_min(J) ≥ σ_floor`、`m ≥ δ_min`、`|q̇|` 与 `T_joint` 未越界。任一越界 ⇒ 取消探针/交互，`U_epi` 视为未消解，退化为 R69 纯保守；`λ` 单调不降。

**定义 323（证书 J_EMBODY）** `J_EMBODY = (J_FLUID, jsc_valid, κ_min, σ_min, probe_realizable, margin_min, t_res_p95, nsa_log_hash, embody_ver)`。Valid ⇔ `Valid(J_FLUID) ∧ jsc_valid ∧ probe_realizable ∧ margin_min ≥ δ_min`。

**定义 324（本体证据集）** 在 R69 的 `ℰ = {r_geo, r_sync, r_zero, r_emo, r_wm}` 上增加本体证据 `ℰ_proprio = {τ_res, q_res, f_contact, T_joint}`，用于主动选择判别力最大的证据对（继承 CIA，定义 300）。

**定义 325（具身干扰集 ℰ_embody）** 体模攻击（伪造雅可比/负载/连杆参数，让系统误判可辨识方向）、关节编码器欺骗、奇异陷阱（把探针引向奇异使逆解爆炸）、自碰撞诱饵、零空间漂移。并入 AIC：`ℰ = ℰ_FLUID × ℰ_embody`。

**定义 326（本体不可约退避）** 若 `∀ q ∈ Q_reach: κ(q) < κ_min`，或 `G_reach=∅`，或检测到体模失配，则 `U_epi` 判为**本体不可约**；`λ = λ_floor(U_ale + U_epi)`（逐指令等于 R69 兜底），且不发起交互。

**定义 327（幻影提问过滤器 PQF）** 模态对 `(i,j)` 称为**本体现可问** ⇔ `max_{q∈Q_reach} D_ij(q) ≥ δ_sep`。只有现可问的对才允许进入 R69 的 MINT；不可问的对直接并入 `U_epi` 的不可约部分。此定义把 R69 的「追问幻影」风险转成一次先验几何判定。

## 2. 关键算法骨架

```python
# IP-264 JSC：关节空间安全证书（内环 O(n)，随 R69 每步执行）
def joint_certificate(q, qd, tau, T, J):
    if not in_joint_limits(q):                         return False
    if max_abs(qd) > qd_max(tau, T):                   return False
    if not torque_ok(tau, qd, T):                      return False   # 含热降额
    if sigma_min(J) < SIGMA_FLOOR:                     return False   # 奇异
    if self_collision(q):                              return False
    return safety_margin(q, qd, tau, T) >= DELTA_MIN   # 裕度内点

# IP-265 COI：位形可辨识性（外环 ~1Hz，枚举可达候选位形）
def configurational_identifiability(modes, q_candidates):
    best = []
    for q in q_candidates:
        if not reachable_and_safe(q):                  continue
        D = {(i, j): kl_div(obs_dist(q, i), obs_dist(q, j))
             for i in modes for j in modes if i < j}
        best.append((min(D.values()), q, D))
    return best                                        # κ(q) 与逐对可分度

# IP-266 EPP：具身探针规划（只问「问得出来」的问题）
def embodied_probe_planner(modes, w, o, budget):
    cands = []                                         # 零空间探针优先（免费）
    for q in nullspace_candidates(o.q0):
        if task_pose_preserved(q) and joint_certificate(*kinematics(q)):
            cands.append((q, kind='null'))
    for q in task_space_candidates(o.q0):              # 需扰动任务，代价更高
        if pose_deviation(q) <= EPS_PROBE and joint_certificate(*kinematics(q)):
            cands.append((q, kind='task'))
    best = None
    for q, kind in cands:
        if not cia.pair_questionable(modes, q):        # 定义 327：先过可问性
            continue
        voi = entropy(w) - expected_entropy(w, probe=q, kind=kind)
        score = voi - joint_cost(q, kind)              # τ^T R τ + 裕度 + 时间
        if safety_margin_after(q) < DELTA_MIN:
            continue                                   # 信息绝不换安全
        if best is None or score > best.score:
            best = (q, kind, score)
    return best if best and best.score > 0 else None  # 否则本体不可约

# IP-267 NSA：零空间三用途分配（硬 > 可辨识性 > 探针）
def nullspace_allocate(q, task_err, probe_dir):
    tau_hard  = avoid_limits_and_singularity(q)
    g_kappa   = null_project(grad_identifiability(q))  # N ∇κ
    tau_soft  = clip_by_margin(g_kappa)                # 不得使 m < δ_min
    tau_probe = null_project(probe_dir) if probe_dir is not None else 0
    return tau_hard + tau_soft + tau_probe             # = N τ_null

# IP-268 EAR：具身吸收残差（第三通道）
def embodiment_absorption(tau, tau_model, task_err, J):
    t_res  = torque_headroom_deficit(tau)              # 贴边度
    a_null = norm(null_project(task_err)) / (norm(J.T @ task_err) + 1e-9)
    return t_res, a_null                               # 与 r_res、Δa 联合诊断

# IP-274 主闭环（内环=R69+JSC；外环=COI/EPP/NSA）
def EMBODY_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)     # R69 前向
    # 1) R69 的歧义检测与模态分解（不变）
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    # 2) 关节可行性：先把「任务安全但关节不可行」的候选剔除
    q_plan = M.ik.solve(M.last_action)
    task_safe = True
    if not M.jsc.certify(q_plan): task_safe = False
    # 3) 本体可问性：只在可实现且可分位形上提问（避免幻影追问）
    probe = M.epp.plan(modes, o, M.budget) if (U_epi > TAU_EPI and task_safe) else None
    if probe is not None:
        tau_null = M.nsa.allocate(o.q, M.last_task_err, probe.dir)
        answer   = M.cia.execute(probe, tau_null)               # 看/触/问
        U_epi_after = M.cia.update_belief(modes, answer)
    else:
        U_epi_after = U_epi                                      # 本体不可约 → R69 兜底
    # 4) R69 风险缩放 + 关节侧三通道第二意见
    U_floor = U_ale + (U_epi_after if probe is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    t_res, a_null = M.ear.measure(M.last_tau, M.last_tau_model, M.last_task_err, M.last_J)
    absorbed = (M.last_r_res < TAU_RES) and (M.last_a_score < TAU_FMA) and (t_res > TAU_T)
    if absorbed: lam = max(lam, 0.8)                             # 身体在骗人 → 最保守
    # 5) 双证书前缀：任务证书 ∩ 关节证书
    A = M.ach.propose(x_prime, H=M.vista.H)
    k_task = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    k = min(k_task, M.jsc.max_feasible_prefix(M.ik.solve(A), ...))
    mode = select_mode(modes, U_epi_after, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_i.submit_async(probe, U_epi, t_res, a_null)            # 参与式审计
    return k, lam, mode, (U_ale, U_epi_after), (t_res, a_null)

## 3. 推导

**引理 19（位形可辨识性上界）** 设观测模型局部光滑、`∂h/∂M` 有界（A99）。任何探针 `g_q` 在时间 T、力 F 预算下对模态对 `(i,j)` 的可达分离度满足 `D_ij(q) ≤ C·(T·F)·λ_max(I_M(q))`；故当 `κ(q) < κ_min` 时，不存在可行探针能把该对分离到 `δ_sep` 之上。系：**分辨率不是意愿的函数，而是位形的函数**；想在坏位形上「多问几次」是徒劳，必须换位形或承认不可约。

**引理 20（零空间可观测性条件）** 令 `γ(q) = ∇_q κ(q)`。存在任务保持自运动使 `κ` 增大到目标，当且仅当 `N γ ≠ 0`（可辨识性梯度有零空间分量）且所需自运动落在 `C_joint` 内；若 `γ` 只在行空间，则任何 `κ` 的改变都必须扰动任务位姿。可量化的「免费信息」为 `γ^T N γ`。系：**零空间探针之所以免费，正是因为它作用在 `γ` 的零空间分量上**；这也给出何时必须为观测付出任务扰动代价。

**引理 21（具身吸收的判别性）** 若控制器用零空间力矩或柔顺补偿未建模扰动，使任务残差 `r_res ≈ 0`，则补偿力矩使 `t_res`（贴边度）与 `α_null` 单调增大；在补偿方向超出训练力矩分布（A100）时，`t_res` 的期望增量 ≥ `c_t·||τ_comp||`。故 `(r_res↓, t_res↑)` 是「身体吸收错误」的判别性联合模式，与 R69 的 `(r_res↓, Δa↑)`、R68 的传感器吸收互补。因 `t_res` 由关节传感/电流估计直接测得，不受任务空间标定影响，故对「标定+行为联合吸收」仍保留一定检出力。

**引理 22（探针的裕度预算）** 定义安全裕度 `m(q,τ) = min_c (slack_c / limit_c)`。任何探针的裕度消耗 `Δm(g_q) ≥ 0`。EMBODY 只接受 `m − Δm ≥ δ_min` 的探针，故 `Δm ≤ m − δ_min`；信息增益被裕度预算硬性上界约束，**不可能**用降低安全裕度到阈值以下来换取信息。系：信息-安全 Pareto 前沿在 `δ_min` 处被截断，安全侧恒不弱于 R69。

**定理 18（EMBODY 严格包含 FLUID-RAS）** 在 A99–A101 下，任意状态上 EMBODY 的期望风险 ≤ FLUID-RAS；且当 `J(q)` 良态（`σ_min ≥ σ_floor`）、关节约束不活跃（`F_joint` 内部）、`κ(q) ≥ κ_min` 且 `Nγ = 0`（无零空间可辨识性增益）时，EMBODY 与 FLUID **逐指令相同**。即 **R69 = 「理想等距、无奇异、无冗余可用」身体边界上的退化**。安全侧：`F_task ∩ F_joint ⊆ F_task`，永不更弱；效率侧：零空间免费探针只增不减。

**定理 19（任务保持探针的无突变性）** 任务保持零空间探针不改变任务位姿与前缀证书，故任务空间控制连续、无突变；任务扰动型探针必须同时过 C-RAS-WM 与 JSC 且偏差 ≤ ε_probe，失败/超时/越界时 `λ` 单调不降地退化为 R69，提交/换装不变式（R68 定理 15）保持。**交互只改变「在哪个位形观测」，不改变「任务安全包络」；零空间内的探询对任务是透明的。**

**定理 20（幻影提问的排除）** 若对模态对 `(i,j)` 有 `max_{q∈Q_reach} D_ij(q) < δ_sep`（定义 327 判为不可问），则任何 `g_q ∈ G_reach` 都无法分离该对；EMBODY 将其判为本体不可约并直接走 R69 保守，**不发起交互**。因此在 `κ` 估计无误时，对「身体不可答」歧义的幻影追问率为 0；在 `κ` 估计有误时，其误判率被 COI 的估计误差项界定（A99 的 Lipschitz 界）。系：这正面拆解了 R69 的最大风险（E300）——**先证明问得出来，再问**。

## 6. 本轮最大风险

**一句话**：EMBODY-RAS 的全部「免费提问」论证都押在**体模（雅可比、力矩模型、观测几何）是准的**这一前提上——一旦体模有误或被人为污染，系统会朝一个**它以为可分、实则奇异/超限/不可分**的位形探询，于是「为了看得更清而重排身体」变成了**把自己摆进危险位形**；这把 R69 的「问错比不问更危险」升级成「**为了问而把自己弄伤**」。

**次级风险与缓解**：
1. **体模失配/攻击**（伪造雅可比、负载、连杆参数）→ 定义 325 ℰ_embody + 体模一致性在线校验 + E314；失配即判本体不可约、退 R69；
2. **零空间消耗安全裕度**（探询挤占限位/力矩/热裕度）→ 定义 319 硬优先 + 引理 22 裕度预算 + 定义 322 JSG 门；
3. **奇异附近数值放大**（逆解爆炸、力觉失真）→ `σ_min ≥ σ_floor` 硬门 + 探针一律远离奇异；
4. **任务保持探针的动力学耦合**（零空间力矩经柔顺/摩擦泄漏到任务）→ 慢外环 + 任务误差在线监控 + 越界即取消；
5. **热/长时程漂移**（降额使原本可行的探针变不可行）→ 温度感知 `τ_max(q̇,T)` + E313 + 自适应降低探询频率。

def joint_certificate(q, qd, tau, T, J):
    return (in_joint_limits(q) and max_abs(qd) <= qd_max(tau, T)
            and torque_ok(tau, qd, T) and sigma_min(J) >= SIGMA_FLOOR
            and not self_collision(q)
            and safety_margin(q, qd, tau, T) >= DELTA_MIN)

# IP-265 COI：位形可辨识性
def configurational_identifiability(modes, q_candidates):
    out = []
    for q in q_candidates:
        if reachable_and_safe(q):
            D = {(i, j): kl_div(obs_dist(q, i), obs_dist(q, j))
                 for i in modes for j in modes if i < j}
            out.append((min(D.values()), q, D))
    return out                                       # κ(q) 与逐对可分度

# IP-266 EPP + IP-270 PQF：只问「问得出来」的问题
def embodied_probe_planner(modes, w, o, budget):
    cands = [q for q in nullspace_candidates(o.q0)
             if task_pose_preserved(q) and joint_certificate(*kin(q))]
    cands += [q for q in task_space_candidates(o.q0)
              if pose_deviation(q) <= EPS_PROBE and joint_certificate(*kin(q))]
    best = None
    for q in cands:
        if not questionable(modes, q): continue       # max D_ij < δ_sep → 不问
        voi = entropy(w) - expected_entropy(w, probe=q)
        score = voi - joint_cost(q)                   # τ^T R τ + 裕度 + 时间
        if safety_margin_after(q) < DELTA_MIN: continue
        if best is None or score > best.score: best = (q, score)
    return best if best and best.score > 0 else None  # 否则本体不可约

    tau_soft  = clip_by_margin(null_project(grad_identifiability(q)))

    return tau_hard + tau_soft + tau_probe

    a_null = norm(null_project(task_err)) / (norm(J.T @ task_err) + 1e-9)
    return t_res, a_null

    U_floor = U_ale + (U_epi if probe is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    t_res, a_null = M.ear.measure(M.last_tau, M.last_tau_model, M.last_task_err, M.last_J)
    if (M.last_r_res < TAU_RES) and (M.last_a_score < TAU_FMA) and (t_res > TAU_T):
        lam = max(lam, 0.8)                            # 身体在骗人 → 最保守
    A = M.ach.propose(x_prime, H=M.vista.H)
    k = min(M.c_ras_wm.certified_prefix(A, ..., wm_preds),
            M.jsc.max_feasible_prefix(M.ik.solve(A), ...))
    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_i.submit_async(probe, U_epi, t_res, a_null)
    return k, lam, mode, (U_ale, U_epi), (t_res, a_null)
```

## 4. 推导

**引理 19（位形可辨识性上界）** A99 下，预算 `(T,F)` 的探针对 `(i,j)` 可达分离度 `D_ij(q) ≤ C·(T·F)·λ_max(I_M(q))`；`κ(q)<κ_min` 时无可实现探针达 `δ_sep`。系：分辨率是位形的函数，坏位形上多问无益。

**引理 20（零空间可观测性条件）** `γ=∇_qκ`；存在任务保持自运动提升 `κ` ⇔ `Nγ≠0` 且自运动在 `C_joint` 内；否则必须扰动任务位姿。可量化的免费信息为 `γ^T N γ`。

**引理 21（具身吸收的判别性）** 零空间/柔顺补偿未建模扰动使 `r_res≈0` 时，`t_res` 与 `α_null` 单调增大；补偿方向超出训练力矩分布（A100）时 `E[t_res] ≥ c_t‖τ_comp‖`。故 `(r_res↓,t_res↑)` 与 R69 的 `(r_res↓,Δa↑)`、R68 的标定吸收互补，且 `t_res` 由关节/电流传感直测，不受任务空间标定影响。

**引理 22（探针的裕度预算）** `m(q,τ)=min_c slack_c/limit_c`；任何探针 `Δm≥0`，只接受 `m−Δm≥δ_min`，故 `Δm ≤ m−δ_min`。信息增益被裕度预算硬上界约束，**不可能**以安全裕度降到阈值以下换取信息。

**定理 18（EMBODY 严格包含 FLUID-RAS）** A99–A101 下 EMBODY 任意状态期望风险 ≤ FLUID；当 `σ_min≥σ_floor`、`F_joint` 内点、`κ≥κ_min` 且 `Nγ=0` 时二者逐指令相同。R69 = 理想等距/无奇异/无冗余可用身体的退化；`F_task∩F_joint ⊆ F_task`，安全永不更弱。

**定理 19（任务保持探针的无突变性）** 零空间探针不改任务位姿与前缀证书 ⇒ 任务控制连续；任务扰动型探针须同时过 C-RAS-WM 与 JSC 且偏差 ≤ ε_probe；失败/超时/越界时 `λ` 单调不降退 R69，提交/换装不变式（R68 定理 15）保持。

**定理 20（幻影提问的排除）** 若 `max_{q∈Q_reach} D_ij(q) < δ_sep`，任何 `g_q∈G_reach` 都无法分离该对；EMBODY 判本体不可约并直接退 R69、不发起交互。故 `κ` 估计无误时对「身体不可答」歧义的幻影追问率为 0，估计有误时由 A99 的 Lipschitz 界控制误判。系：正面拆解 R69 最大风险（E300）——先证明问得出来，再问。

## 7. 本轮最大风险

**一句话**：EMBODY-RAS 的「免费提问」全押在**体模（雅可比、力矩模型、观测几何）准确**这一前提上——体模一旦有误或被污染，系统会朝一个**自以为可分、实则奇异/超限/不可分**的位形探询，于是「为了看得更清而重排身体」变成**把自己摆进危险位形**；这把 R69 的「问错比不问更危险」升级成「**为了问而把自己弄伤**」。

**次级风险与缓解**：体模失配/攻击（ℰ_embody + 在线一致性校验 + E314，失配即判不可约退 R69）；零空间消耗安全裕度（硬优先 + 引理 22 预算 + JSG 门）；奇异数值放大（`σ_min≥σ_floor` 硬门，探针远离奇异）；任务保持探针的动力学耦合（慢外环 + 任务误差在线监控，越界即取消）；热/长时程漂移（温度感知 `τ_max` + E313 + 自适应降低探询频率）。
