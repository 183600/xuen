### 第 2 轮灵感驱动研究记录

**灵感词**：点云配准、物体泛化

**直觉与动机**：
SRC-USC v25 把「结构-力学-语义-重构-协同」七证串成单调退化链，却把整条链的几何根基压在一个从未被证书化的隐含前提上：**所有语义实体、碰撞体与载荷方向所依赖的位姿，都来自一次"足够好"的点云配准**。配准一旦在低重叠、平面/圆柱对称、动态遮挡下发生偏移，SMC 的 Hausdorff 一致性、MCC 的时空占用体、SOC 的载荷主轴就会在错误坐标系里"正确地"通过验证——证书链越完备，错误反而越隐蔽。受「点云配准」启发：配准本身必须附带可复核的**重叠-残差-退化-不确定度-循环一致**证书，并显式给出"哪些自由度可信、哪些不可信"。受「物体泛化」启发：conformal 校准集只覆盖已知物体，证书必须刻画从已知分布 D_S 到新实例/新类别 D_T 的**分布外延拓半径**，否则 1-α 覆盖承诺在未知物体上静默失效。核心洞见：**配准是证书的几何锚定算子，物体泛化是证书的分布延拓算子；一个证书只有在"锚点可信且外延有界"时才对未知世界成立**。

**形式化目标**：
1. 定义点云配准证书（PCRC）：对 T̂ ∈ SE(3) 与对应集 𝒞，附带
   (a) 重叠率 O = |I| / min(|P|,|Q|) ≥ τ_O（允许部分重叠）；
   (b) 鲁棒内点残差 RMSE_I(T̂) ≤ ε_reg；
   (c) 退化证书：Gauss–Newton Hessian H = Σ_i J_iᵀΩJ_i 的最小特征值 λ_min(H) ≥ λ_0，并输出可观测子空间 𝒪 与不可观测子空间 𝒰（对称轴/平面法向等退化方向）；
   (d) 不确定度证书：Cramér–Rao 下界 Σ_T ≈ σ²H⁺，Mahalanobis 误差 (ξ̂-ξ*)ᵀΣ_T⁻¹(ξ̂-ξ*) ≤ χ²_6(1-α)，在线无真值时退化为"不确定度半径 r̂ = q̂·√λ_max(Σ_T) ≤ ε_unc"；
   (e) 循环一致：T_ijT_jkT_ki ≈ I，‖log(T_ijT_jkT_ki)‖ ≤ ε_cycle。
2. 定义物体泛化证书（OGC）：对目标分布 D_T，附带
   (a) 加权 conformal 覆盖 ℙ(y ∈ C(x)) ≥ 1-α-Δ_shift，Δ_shift 为可证分布偏移（MMD + 均匀收敛修正，或 Pinsker 上界）；
   (b) 对称群 G 下的类别级位姿误差 min_{g∈G} d_SE3(T̂, T*g) ≤ ε_pose 与形状 Chamfer 误差 ≤ ε_shape；
   (c) 可供性迁移失败率 Clopper–Pearson 上界 ≤ α_task；
   (d) 域偏移 Δ_shift + Δ_sim2real ≤ Δ_max。
3. 定义形变感知配准：新物体对齐到类别先验 M_c 时联合估计 (T̂, D)，证书要求残差 ≤ ε_reg 且形变能量 E_def = ‖D‖²_ℋ ≤ E_max^def，并用锚点/gauge 固定消除位姿-形变不可辨识（gauge freedom）。
4. 构建配准-泛化统一准入门（RGUG）：USMC ∪ SMC ∪ RMC ∪ MCC ∪ PCRC ∪ OGC 九证一体，Exec_v26 = Exec_v25 ∩ Fil_reg ∩ Fil_gen ⊆ Exec_v25。
5. 证明退化几何/低重叠/分布外物体下的单调退化链保持，并给出"方向性信任"降级语义：仅允许沿 𝒪 执行，沿 𝒰 的运动须先由主动感知（next-best-view）消歧，否则拒证而非静默放行。

**一句话最大风险（预告）**：退化检测与分布偏移估计都依赖阈值，若 λ_min 与 Δ_shift 被噪声或校准误差系统性低估，RGUG 会把"不可观测的对称方向"与"分布外新物体"误判为可执行，从而在几何锚点已漂移时仍放行九证。

## 1. 关键算法骨架（在 IP-447 骨架上扩展）

```python
# ============================================================
# IP-448 Point Cloud Registration Certificate (PCRC) — 点云配准证书
# ============================================================
@dataclass
class RegistrationResult:
    T: Tensor                  # [4,4] 齐次变换
    xi: Tensor                 # [6] 局部 se(3) 扰动（左乘）
    src: Tensor                # [N_s,3]
    tgt: Tensor                # [N_t,3]
    corr: Tensor               # [M,2] 对应索引 (i,j)
    residuals: Tensor          # [M] 点到面/点残差
    H: Tensor                  # [6,6] Gauss-Newton Hessian
    sigma2: float              # 噪声方差估计


@dataclass
class PointCloudRegistrationCertificate:
    reg: RegistrationResult
    tau_overlap: float = 0.30
    eps_reg: float = 0.01        # m
    lam_min: float = 1e-3        # 可观测性下限
    kappa_max: float = 1e4
    alpha_reg: float = 0.05
    eps_cycle: float = 1e-3
    eps_unc: float = 0.02        # 不确定度半径上限 (m/rad)
    eps_u: float = 1e-3          # 计划沿 𝒰 的允许投影能量

    def verify_overlap(self) -> tuple[bool, float]:
        O = self.reg.corr.shape[0] / min(self.reg.src.shape[0], self.reg.tgt.shape[0])
        return O >= self.tau_overlap, O

    def verify_residual(self) -> tuple[bool, float]:
        r = self.reg.residuals
        inlier = r.abs() <= 3.0 * self.reg.sigma2 ** 0.5
        rmse = torch.sqrt((r[inlier] ** 2).mean()).item() if inlier.any() else float('inf')
        return rmse <= self.eps_reg, rmse

    def observable_subspace(self) -> tuple[Tensor, Tensor, Tensor, float]:
        """H 的特征分解：𝒪=span(λ≥λ0)，𝒰=span(λ<λ0)，返回 (O,U,eigvals,kappa)"""
        eigvals, eigvecs = torch.linalg.eigh(self.reg.H)
        obs = eigvals >= self.lam_min
        O = eigvecs[:, obs]           # [6,k]
        U = eigvecs[:, ~obs]          # [6,6-k]
        kappa = (eigvals[-1] / eigvals[0].clamp_min(1e-12)).item()
        return O, U, eigvals, kappa

    def verify_degeneracy(self) -> tuple[bool, Tensor, Tensor]:
        O, U, eigvals, kappa = self.observable_subspace()
        ok = (eigvals[0].item() >= self.lam_min) and (kappa <= self.kappa_max)
        return ok, O, U

    def verify_uncertainty(self, xi_star: Optional[Tensor] = None,
                           q_hat: Optional[float] = None) -> tuple[bool, Tensor]:
        """CRLB：Σ_T = σ² H⁺；在线用校准分位数 q̂ 给预测半径，离线有 GT 用 χ²_6"""
        Sigma = self.reg.sigma2 * torch.linalg.pinv(self.reg.H)
        lam_max = torch.linalg.eigvalsh(Sigma).max().clamp_min(0.0)
        q = 1.0 if q_hat is None else q_hat
        radius = q * torch.sqrt(lam_max).item()
        ok = radius <= self.eps_unc
        if xi_star is not None:
            from scipy.stats import chi2
            d2 = (self.reg.xi - xi_star) @ torch.linalg.pinv(Sigma) @ (self.reg.xi - xi_star)
            ok = ok and (d2.item() <= chi2.ppf(1 - self.alpha_reg, df=6))
        return ok, Sigma

    def verify_cycle_consistency(self, cycles: list[tuple[Tensor, Tensor, Tensor]]) -> bool:
        for T_ij, T_jk, T_ki in cycles:
            err = torch.linalg.norm(se3_log(T_ij @ T_jk @ T_ki)).item()
            if err > self.eps_cycle:
                return False
        return True

    def verify_plan_direction(self, planned_twists: Tensor) -> bool:
        """方向性信任：计划 twist 在不可观测子空间 𝒰 上的投影能量必须受限"""
        _, U, _, _ = self.observable_subspace()
        if U.shape[1] == 0:
            return True
        proj = planned_twists @ U                       # [T,k]
        return torch.linalg.norm(proj, dim=-1).max().item() <= self.eps_u

    def verify_all(self, cycles=None, planned_twists=None,
                   xi_star=None, q_hat=None) -> tuple[bool, dict]:
        ok_o, O = self.verify_overlap()
        ok_r, rmse = self.verify_residual()
        ok_d, obs, unobs = self.verify_degeneracy()
        ok_u, Sigma = self.verify_uncertainty(xi_star, q_hat)
        ok_c = True if cycles is None else self.verify_cycle_consistency(cycles)
        ok_p = True if planned_twists is None else self.verify_plan_direction(planned_twists)
        ok = ok_o and ok_r and ok_d and ok_u and ok_c and ok_p
        return ok, {'overlap': O, 'rmse': rmse, 'observable': obs,
                    'unobservable': unobs, 'Sigma': Sigma,
                    'cycle_ok': ok_c, 'plan_direction_ok': ok_p}


# ============================================================
# IP-449 Object Generalization Certificate (OGC) — 物体泛化证书
# ============================================================
@dataclass
class ObjectGeneralizationCertificate:
    category: str
    shape_prior: 'CategoryShapePrior'      # 类别规范形状 M_c
    calib_scores: Tensor                   # [n] 源分布 conformal 非一致性分数
    weights: Optional[Tensor] = None       # [n] dD_T/dD_S 重要性权重
    alpha: float = 0.05
    delta_shift_max: float = 0.10
    delta_conf: float = 0.05
    symmetry_group: 'SymmetryGroup' = None
    eps_pose: float = 0.02                 # 对称约化后的位姿误差
    eps_shape: float = 0.01                # Chamfer (m)
    alpha_task: float = 0.05

    def estimate_shift(self, feats_src: Tensor, feats_tgt: Tensor) -> float:
        """可证分布偏移：MMD + 均匀收敛修正（Rademacher 复杂度项）"""
        mmd = self._mmd_rbf(feats_src, feats_tgt)
        n = min(feats_src.shape[0], feats_tgt.shape[0])
        rademacher = math.sqrt(2.0 * math.log(2.0 / self.delta_conf) / n)
        return mmd + rademacher

    def conformal_quantile(self) -> float:
        n = self.calib_scores.numel()
        if self.weights is None:
            k = min(math.ceil((n + 1) * (1 - self.alpha)), n)
            return torch.kthvalue(self.calib_scores, k).values.item()
        # 加权 conformal：score 的加权经验 (1-α) 分位数
        order = torch.argsort(self.calib_scores)
        s, w = self.calib_scores[order], self.weights[order]
        cum = torch.cumsum(w, 0) / w.sum()
        idx = torch.searchsorted(cum, torch.tensor(1 - self.alpha))
        return s[min(idx.item(), n - 1)].item()

    def verify_generalization(self, test_scores: Tensor,
                              delta_shift: float) -> tuple[bool, float]:
        q = self.conformal_quantile()
        cover = (test_scores <= q).float().mean().item()
        return cover >= 1 - self.alpha - delta_shift, cover

    def verify_shape_pose(self, T_hat, shape_hat, T_gt, shape_gt
                          ) -> tuple[bool, float, float]:
        pose_err = min(se3_distance(T_hat, T_gt @ g)
                       for g in self.symmetry_group.elements())
        shape_err = chamfer_distance(shape_hat, shape_gt)
        ok = (pose_err <= self.eps_pose) and (shape_err <= self.eps_shape)
        return ok, pose_err, shape_err

    def verify_affordance(self, failures: int, n_trials: int) -> tuple[bool, float]:
        """Clopper–Pearson 失败率上界 ≤ α_task（单侧置信 1-δ_conf）"""
        from scipy.stats import beta
        ub = (1.0 if failures >= n_trials else
              beta.ppf(1 - self.delta_conf, failures + 1, n_trials - failures))
        return ub <= self.alpha_task, ub

    def verify_domain_gap(self, delta_shift: float,
                          delta_sim2real: float = 0.0) -> bool:
        return delta_shift + delta_sim2real <= self.delta_shift_max

    def verify_all(self, test_scores, delta_shift, T_hat, shape_hat,
                   T_gt, shape_gt, failures, n_trials,
                   delta_sim2real: float = 0.0) -> tuple[bool, dict]:
        ok_g, cover = self.verify_generalization(test_scores, delta_shift)
        ok_s, pe, se = self.verify_shape_pose(T_hat, shape_hat, T_gt, shape_gt)
        ok_a, ub = self.verify_affordance(failures, n_trials)
        ok_d = self.verify_domain_gap(delta_shift, delta_sim2real)
        return ok_g and ok_s and ok_a and ok_d, {
            'coverage': cover, 'pose_err': pe, 'shape_err': se,
            'affordance_fail_ub': ub, 'delta_shift': delta_shift}


def deformation_aware_register(src, tgt, shape_prior, lam_def=1e-2,
                               anchor_mask=None, max_iter=30):
    """联合估计 (T,D)：min_{T,D} Σρ(‖T(p_i+D(p_i))-q_j‖) + λ‖D‖²_ℋ
    gauge 固定：anchor_mask 指定低曲率锚点区域，禁止其形变以消除位姿-形变不可辨识"""
    T = init_from_pcr(src, tgt)
    D = torch.zeros_like(src)
    for _ in range(max_iter):
        T = solve_pose(src + D, tgt, T)          # 固定 D，GNC/ICP 解位姿
        D = solve_deformation(T @ (src + D), tgt, lam_def, anchor_mask)
        if anchor_mask is not None:
            D[anchor_mask] = 0.0                 # 锚点零形变，固定 gauge
    E_def = (D ** 2).sum().item()
    return T, D, E_def

# IP-450 RGUG 配准-泛化统一准入门
# ============================================================
@dataclass
class RegistrationGeneralizationUnifiedCertificate:
    src_usc: 'SemanticReconfigCoordUnifiedCertificate'
    pcrc: PointCloudRegistrationCertificate
    ogc: ObjectGeneralizationCertificate
    eps_def: float = 0.05

    def admits(self, multi_plan: 'MultiRobotPlan', sensor_data: dict) -> bool:
        # 1) 七证（v25）先行
        if not self.src_usc.admits(
                multi_plan, sensor_data,
                sensor_data.get('gt_entities'),
                sensor_data.get('queries'),
                sensor_data.get('retrieved')):
            return False
        # 2) 几何锚定证书（配准必须先于一切几何断言）
        ok_reg, reg_info = self.pcrc.verify_all(
            cycles=sensor_data.get('registration_cycles'),
            planned_twists=multi_plan.twists,
            xi_star=sensor_data.get('xi_star'),
            q_hat=sensor_data.get('q_hat'))
        if not ok_reg:
            return False
        # 3) 形变感知配准（新物体对齐类别先验）
        if sensor_data.get('novel_object', False):
            T, D, E_def = deformation_aware_register(
                sensor_data['src'], sensor_data['tgt'],
                self.ogc.shape_prior,
                anchor_mask=sensor_data.get('anchor_mask'))
            if E_def > self.eps_def:
                return False
        # 4) 分布延拓证书
        ok_gen, gen_info = self.ogc.verify_all(
            sensor_data['test_scores'], sensor_data['delta_shift'],
            sensor_data['T_hat'], sensor_data['shape_hat'],
            sensor_data['T_gt'], sensor_data['shape_gt'],
            sensor_data['failures'], sensor_data['n_trials'],
            sensor_data.get('delta_sim2real', 0.0))
        if not ok_gen:
            return False
        # 5) 方向性信任：沿不可观测子空间 𝒰 的运动必须受限
        if not self.pcrc.verify_plan_direction(multi_plan.twists):
            return False
        return True

# 扩展：端到端流水线前置配准证书，后置泛化证书
# ============================================================
class RegistrationGeneralizationPipeline:
    def __init__(self, config: dict):
        self.v25_pipeline = MultiRobotPerceptionComplianceEnergyPipeline(config)
        self.rgug = RegistrationGeneralizationUnifiedCertificate(
            src_usc=self.v25_pipeline.src_usc,
            pcrc=PointCloudRegistrationCertificate(reg=config['reg']),
            ogc=ObjectGeneralizationCertificate(
                category=config['category'],
                shape_prior=config['shape_prior'],
                calib_scores=config['calib_scores'],
                weights=config.get('weights'),
                symmetry_group=config['symmetry_group'])
        )
        self.ipam.register_module("pcrc", ["IP-448"],
            ["overlap_residual", "degeneracy_subspace", "crlb_uncertainty",
             "cycle_consistency", "directional_trust"])
        self.ipam.register_module("ogc", ["IP-449"],
            ["weighted_conformal_generalization", "symmetry_aware_pose",
             "affordance_transfer_bound", "domain_gap_certificate"])
        self.ipam.register_module("rgug", ["IP-450"],
            ["nine_certificate_gate", "registration_generalization_monotonic_chain"])

    def step(self, sensor_data: dict, cloud_update=None) -> tuple[bool, dict]:
        # 0. 配准证书：先于任何几何/语义断言
        self.rgug.pcrc.reg = estimate_registration(
            sensor_data['src'], sensor_data['tgt'])
        ok_reg, reg_info = self.rgug.pcrc.verify_all(
            cycles=sensor_data.get('registration_cycles'),
            planned_twists=sensor_data.get('planned_twists'),
            q_hat=sensor_data.get('q_hat'))
        if not ok_reg:
            return False, {'reason': 'PCRC_reject', 'info': reg_info,
                           'fallback': 'active_perception_for_disambiguation'}
        # 1-11. 复用 v25 七证流水线
        admitted, info = self.v25_pipeline.step(sensor_data, cloud_update)

        # 12. 泛化证书（按新物体事件触发，低频）
        if sensor_data.get('novel_object', False):
            ok_gen, gen_info = self.rgug.ogc.verify_all(
                sensor_data['test_scores'], sensor_data['delta_shift'],
                sensor_data['T_hat'], sensor_data['shape_hat'],
                sensor_data['T_gt'], sensor_data['shape_gt'],
                sensor_data['failures'], sensor_data['n_trials'],
                sensor_data.get('delta_sim2real', 0.0))
            if not ok_gen:
                return False, {'reason': 'OGC_reject', 'info': gen_info,
                               'fallback': 'instance_level_registration_only'}
        return True, {**info, 'registration': reg_info}
```

## 3. 正确性论证（增量）

### 引理 13（点云配准证书的锚定可靠性）
**陈述**：若 `PCRC.verify_all(...) = True`，则 T̂ 同时满足：(1) 部分重叠下对应充分（O≥τ_O）；(2) 内点残差有界；(3) 全部 6 自由度可观测（λ_min(H)≥λ_0），否则显式给出退化子空间 𝒰；(4) 真实位姿以 ≥1-α 概率落在 CRLB 椭球内（有真值）或不确定度半径 ≤ε_unc（在线）；(5) 多视图循环一致；(6) 计划 twist 在 𝒰 上投影 ≤ε_u。

**证明**：
1. `verify_overlap`/`verify_residual` 为直接谓词，内点集 I 由 3σ 截断定义，O 与 RMSE_I 可复算。
2. 对局部扰动 ξ，残差线性化 r_i ≈ r_i⁰ + J_i ξ，Gauss–Newton 信息矩阵 H=ΣJ_iᵀΩJ_i。`eigh(H)` 将切空间正交分解为 𝒪⊕𝒰；λ_min≥λ_0 当且仅当所有方向均有信息增益，κ≤κ_max 排除病态放大。
3. 在高斯噪声假设下，任何无偏估计的协方差满足 Cramér–Rao 下界 Σ_T ⪰ σ²H⁻¹；取 Σ_T=σ²H⁺，则 Mahalanobis 统计量服从 χ²_6，给出 1-α 椭球覆盖。无真值时，用离线校准的 q̂ 将预测半径 r̂=q̂√λ_max(Σ_T) 与任务容差 ε_unc 比较，仍是可复核的充分条件。
4. 循环一致来自 SE(3) 群闭合：真实变换满足 T_ijT_jkT_ki=I，残差范数给出可计算的一致性度量。
5. 方向性信任把"标量误差小"升级为"切空间子空间可信"：即使 RMSE 达标，沿 𝒰 的运动仍不可认证，故显式拒绝。
∎

### 引理 14（物体泛化证书的分布延拓保证）
**陈述**：设源/目标分布满足协变量偏移且 w=dD_T/dD_S 已知或可估；若 `OGC.verify_all(...) = True`，则目标分布上的 conformal 覆盖 ≥1-α-Δ_shift，且对称约化位姿误差、形状误差、可供性失败率均满足各自阈值。

**证明**：
1. 加权 conformal（Tibshirani et al. 2019）：以权重 w(x) 重加权校准分数，构造的预测集满足 ℙ_{D_T}(Y∈C(X))≥1-α（权重精确时）。当权重由数据估计、偏移由 Δ_shift 界定，覆盖下界松弛为 1-α-Δ_shift；Δ_shift 由 MMD 的均匀收敛界（Rademacher 复杂度 O(√(log(2/δ)/n))）给出，故为可证量。
2. 对称群 G 下取 min_{g∈G} d_SE3(T̂,T*g)，消除圆柱/长方体等对称导致的"伪位姿误差"，使误差度量在 G 商空间上良定义。
3. 可供性失败率用 Clopper–Pearson 单侧上界，是二项比例的精确置信上界，无需正态近似。
4. 域偏移条件 Δ_shift+Δ_sim2real≤Δ_max 保证仿真校准与真实目标同处证书有效域内。
∎

### 引理 15（RGUG 九证单调退化链）
**陈述**：任意单点/组合失效下 `Exec_v26 ⊆ Exec_v25 ⊆ ... ⊆ Exec_v18` 恒成立。

**证明**：在引理 12 基础上增加两条退化路径：
- 配准退化/低重叠/对称不可观测 → `PCRC.verify_all=false` → RGUG 拒证 → 退回 Exec_v25，并触发主动感知消歧；若消歧失败则沿 𝒰 的运动被冻结，降级为"仅可观测子空间内的保守执行"。
- 分布外物体/偏移超限/形变能量超预算 → `OGC.verify_all=false` → RGUG 拒证 → 退回 Exec_v25（仅用实例级配准与已知物体证书，不做类别先验外推）。
- 组合失效：Exec_v26 为九条件交集，交集的子集仍是 Exec_v25 的子集，单调性保持。
∎

### 定理（RGUG 九证准入门的安全-合规-可部署-可保护-结构-语义-重构-协同-锚定-泛化完备性）
**陈述**：对任意多机计划 Π={π_1..π_N}，`RGUG.admits(Π)=True` ⟺ Π 同时满足 v25 的十项条件，外加：
(11) 配准锚定达标：重叠/残差/可观测/不确定度/循环一致/方向性信任；
(12) 物体泛化达标：加权覆盖/对称位姿/形状/可供性/域偏移。

**证明**：直接由 `RGUG.admits` 的连言结构与引理 1–15 可得。必要性：任一条件缺失即拒证，对应十二类风险之一未被缓解。充分性：十二条件全满足，由引理 12、15 保证执行集单调链与"锚点可信且外延有界"，构成从单机物理、群体协同到未知物体的完整闭环。
∎

## 6. 本轮最大风险（最终确认）

**一句话**：**点云配准证书（PCRC）的退化检测在低重叠/对称几何下可能把不可观测方向误判为可观测，物体泛化证书（OGC）的分布偏移估计在特征高维/权重失配时可能低估 Δ_shift——两者叠加会让 RGUG 在"锚点已漂移 + 物体已分布外"的复合场景下仍放行九证，使整条单调退化链的"事前拦截"承诺在最需要它的未知世界里最先失效。**
