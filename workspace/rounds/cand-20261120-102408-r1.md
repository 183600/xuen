# 第 1 轮（新灵感循环第 1 轮；本轮灵感：「长程任务」×「多模态融合」）

> **基线**：第 14 轮 MetricVoiceGauge-NCD-HUTDH-v16（定义 627–656；引理 131–136；实验 E671–E690）。
> 本轮纪律：**长程为轴、模态为证、检查点为节拍**。不推倒 v16：v16 的 BTS/TRM/WBC/CSC、v15 的 SCD/DSD/DCA/EDC、v14 的 SCD/DSD/DCA/EDC、v13 的 AIO/RTIC/CPD/DGC/DDL/RTCR、v12 的 USG/TGC/BAA/GAGP/UC、v11 的 HAS/HCC/HATD/HDT、v10 的 NGE/DSL/CC/CWM/CAE/NCP、v9 的 AC/MW/ID、v8 的 DA/SPR/Cal 与历轮不变式全部保留。四个新组件——LHCM（长程证书管理器）、CMF（证书化多模态融合）、SGC（子目标契约编译器）、HMC（长程-模态链调度器）——一律以**中立元**接入，失效即严格退回 v16（引理 141），再沿 v16→v15→v14→v13→v12→v11→v10→v9→v8→v7→v6 退化链退回。本轮只做三件事：把"长程任务"改写为**带风险预算与进度下界的子目标契约链**、把"多模态融合"改写为**带支撑域-误差帕累托证书的融合算子**、把"长程执行"改写为**检查点续期下的单调风险记账**。

## 0. 直觉与动机

**灵感 1（长程任务 → 风险预算与进度下界的双账本）**
直觉：v16 的行为树保证了"每一步都在证书内"，但长程任务的危险恰恰不在单步：一万步里每步 10^{-6} 的违规概率，累积起来就不可忽略；更隐蔽的是"安全地原地打转"——每步都安全，却永远到不了目标。现有证书只记"安全账"，不记"进度账"和"风险账"。核心创新：**长程证书（Horizon Certificate, HC）**，同时维护三个量：剩余时域 `H_rem`、剩余风险预算 `α_rem`、已证进度下界 `π_low`。每一步必须同时满足：消耗风险 `δ_t ≤ α_rem/H_rem`（或按非均匀风险日程分配）、产生可证的进度增量 `Δπ_t ≥ 0`、且 `π_low + Δπ_t` 仍朝目标推进。关键反直觉点：**长程安全不是"每步安全的合取"，而是"风险预算的守恒 + 进度下界的单调"**；前者防违规累积，后者防安全地无效。

**灵感 2（多模态融合 → 支撑域与误差的帕累托证书）**
直觉：多模态融合通常被当成"越多越好"：视觉+语言+本体感觉+触觉，融合后更准。但真实情况是：每个模态都有自己的**可证支撑域**（校准集覆盖的状态区域）、**误差界**、**覆盖率**、**延迟**和**新鲜度**。融合只在所有参与模态的支撑域交集上有效——增加一个模态会**提高精度但收缩支撑域**；丢掉一个模态会**扩大支撑域但放宽误差界**。现有融合把"精度"当唯一目标，忽略了"可证支撑域"这个安全维度。核心创新：**证书化多模态融合（Certified Multimodal Fusion, CMF）+ 模态证书（Modality Certificate, ModC）**。`ModC_m = (S_m, ε_m, ρ_m, λ_m, τ_m)`；融合证书 `FuseCert(A) = (S_A=∩S_m, ε_A, ρ_A, λ_A)`，满足**支撑反单调、误差单调**：`A⊆B ⇒ S_B⊆S_A ∧ ε_B≤ε_A`。关键反直觉点：**融合不是取并集，而是取交集的支撑 + 收紧的误差**；当支撑交集为空时，融合必须失败而不是"折中"。

**灵感 3（长程 × 多模态 → 检查点续期的风险记账链）**
直觉：长程任务不可能一路不检查点。真实系统靠"里程碑/检查点"分段：到达一个已验证的检查点，就"重置"风险账本，继续下一段。但这里藏着一个致命假设：检查点验证与执行使用的是**同一套可能相关的模态与校准集**——如果视觉漂移同时骗过了执行和检查点，风险账本被"合法地"清零，长程误差却继续累积。核心创新：**长程-模态链（Horizon-Modality Certificate Chain, HMCC）+ 检查点续期（Checkpoint Renewal, CR）**。HMCC 把每个子目标契约、每一步融合证书、每一段风险预算串成一条链；检查点续期只在**独立证据**（不同模态子集、不同校准集、或外部验证）下才允许扣减累计风险，否则风险**原样结转**。关键反直觉点：**检查点不是"清零"，而是"有条件再融资"**；没有独立证据的续期等价于风险洗白。

**四者如何统一**
统一为 **v16 行为层之上的长程多模态层**：v16 回答"当前里程碑下这一帧能安全 tick 哪个行为树节点"（`Exec_v16`），v17 回答"在剩余时域与风险预算内、用哪组模态的融合证书、沿哪条子目标契约链、在哪个检查点续期，能既安全又真正推进目标"（`Exec_v17`）。LHCM 管风险/进度双账本；CMF 管模态支撑/误差帕累托；SGC 把子目标编译成 v16 可执行的 BTS 子树与契约；HMC 在模态查询预算、时域预算、风险预算三者间做单调分配。共享状态 `ζ_lh=(H_rem, α_rem, π_low, A_mod, SC_stack, CP_next, R_ledger, drift_lh, mode_lh)`。四者不是四个补丁，而是"时域—模态—契约—记账"的实现链。

## 1. 研究问题（轮次升级版）

- **Q1（长程风险的可加性与非均匀日程）**：如何把总风险 α 分配到 H 步，使 `Σδ_t ≤ α` 且不因保守分配导致活性丧失？非均匀日程（前期宽松/后期收紧）在分布漂移下如何保持有效？进度下界 `π_low` 如何与 v16 的证书价值 `val(n)` 对齐而不产生"安全地刷进度"？
- **Q2（模态融合证书的支撑-误差前沿）**：如何在有限校准数据下给出 `S_A`、`ε_A`、`ρ_A` 的共形下界？模态冲突（两个模态给出矛盾估计）时，融合应失败还是降权？支撑交集为空时的"模态交接桥"如何定义才不产生支撑缝隙？
- **Q3（子目标契约的编译与合成）**：如何把长程目标分解为 SC 链，使 `Post_i ⊆ Pre_{i+1}` 且每条契约可编译为 v16 的 BTS 子树？契约的时域/风险预算如何与 v16 的 tick 预算、里程碑预算兼容？失败时如何沿契约链回退而不跳跃？
- **Q4（检查点续期的独立性与活性）**：如何在线判定检查点证据的"独立性"？独立证据不足时风险结转的代价如何量化？续期失败导致长程活性下降时，如何在"不清零"和"不冻死"之间取帕累托折中？全失效时能否严格退回 v16？

## 2. 设计原则（在 P25–P27 基础上新增 P28–P30）

**P28 长程双账本守恒律（Long-Horizon Double-Ledger Conservation）**
每个长程状态维护 `(H_rem, α_rem, π_low)`，转移满足：`H_rem' = H_rem - 1`、`α_rem' = α_rem - δ_t`、`π_low' = π_low + Δπ_t`，且 `δ_t ≥ 0`、`Δπ_t ≥ 0`、`α_rem' ≥ 0`。任何一步若 `δ_t > α_rem/H_rem`（在均匀日程下）或 `Δπ_t` 不可证，则拒绝执行并走契约回退。**风险只能消耗不能凭空产生，进度只能下界不能上界**。

**P29 融合支撑反单调律（Fusion Support Anti-Monotonicity）**
对任意模态子集 `A ⊆ B ⊆ M`，融合证书必须满足 `S_B ⊆ S_A`、`ε_B ≤ ε_A`、`ρ_B ≤ ρ_A`。融合算子只在 `S_A ≠ ∅` 时返回值；`S_A = ∅` 时必须返回 `FUSION_FAILURE`，禁止用加权平均"抹平"支撑缺口。模态子集切换必须经由**支撑桥** `Bridge(A,B)=S_A∩S_B`，且桥非空。

**P30 检查点有条件续期律（Checkpoint Conditional Renewal）**
检查点 `CP_j` 的续期算子 `Renew` 只有在证据独立度 `ind(CP_j) ≥ θ_ind` 时才允许将 `α_rem` 重置为 `α_j^fresh`；否则 `α_rem' = α_rem - δ_t`（风险结转）。独立度由"证据模态子集与执行模态子集的不相交度、校准集版本差异、外部验证信号"三者合成。**没有独立证据的检查点只是又一个普通状态，不是续期点**。

## 3. 与基线的接口（如何退化）

- LHCM 失效 ⇒ 单步中立元：`H_rem≡1, α_rem≡α_step, π_low≡0`，退化为 v16 的逐步证书，**等价 v16 路径**；
- CMF 失效 ⇒ 单模态中立元：`A≡{m_0}`（主模态），`FuseCert≡ModC_{m_0}`，退化为 v16 的单传感器输入，**等价 v16（+LHCM）路径**；
- SGC 失效 ⇒ 单契约中立元：整条长程任务视为一个 SC，直接编译为 v16 根子树，**等价 v16（+LHCM+CMF）路径**；
- HMC 失效 ⇒ 静态分配：固定模态子集与均匀风险日程，无预算感知，**等价 v16 调度路径**；
- 检查点续期失效 ⇒ 不续期中立元：`α_rem` 永不重置，**严格比 v16 更保守**；
- 五者全失效 ⇒ MetricVoiceGauge-NCD-HUTDH-v16，再沿 v16→v15→v14→v13→v12→v11→v10→v9→v8→v7→v6 退化链退回；
- **安全继承**：LHCM 只减不加风险预算，CMF 只收缩支撑域不放宽误差，SGC 只合成已有契约，HMC 只做单调分配，CR 只做有条件续期。五端口均不能新增授权或放宽任何阈值；`Exec_v17⊆Exec_v16` 由引理 141 保证。

## 4. 预期贡献

1. **长程双账本证书**：把"长程安全"从每步安全的合取，改写为风险预算守恒 + 进度下界单调的双账本，给出可组合的风险日程与活性条件；
2. **证书化多模态融合**：给出支撑域-误差帕累托前沿、模态冲突的失败语义、以及支撑桥交接，填补"多模态融合不可证"的空白；
3. **子目标契约编译**：把长程任务分解为可合成、可回退、可编译到 v16 行为树的契约链，打通"长程规划—行为执行"的接口；
4. **检查点有条件续期**：把"检查点清零风险"改写为"独立证据下的再融资"，给出无免费午餐界与活性折中；
5. **五层语义分离**：v12 管允许什么、v13 管时限内实现多少、v15 管技能扩散、v16 管全身行为、v17 管长程多模态推进，用 `Exec_v17⊆Exec_v16⊆Exec_v15⊆Exec_v13⊆Exec_v12` 全解耦；E691–E710 覆盖融合校准、风险累积、契约合成、续期独立性、漂移、端到端与消融。

## 5. 本轮最大风险

**一句话**：检查点续期的"独立性"只能靠在线代理指标估计，而最危险的分布漂移恰恰会让执行模态与检查点模态**同时**出错——此时 `ind(CP_j)` 被高估、风险账本被合法清零，长程误差却在每一段"已认证"的区间里继续累积，最终得到一个**每段都通过证书、整条链却绝对不安全的长程行为**。

## 1. 关键算法骨架

```python
# IP-417 Certified Multimodal Fusion：支撑-误差帕累托融合
class CertifiedMultimodalFusion:
    def __init__(self, modality_certs, calibrator, alpha=0.05, fusion_gap=0.01):
        self.certs = modality_certs          # {m: ModC_m}
        self.cal = calibrator                # 共形校准器（按模态子集）
        self.alpha = alpha
        self.gap = fusion_gap                # 固定融合开销，与 |A| 无关

    def fuse(self, obs, A):
        """返回 FusionResult(ok, S_A, eps_A, rho_A, x_hat, reason)"""
        if not A:
            return FusionResult.failure("empty_modality_set")

        # 1. 支撑域取交集：融合不能制造支撑
        S_A = set.intersection(*(self.certs[m].S for m in A))
        if not S_A:
            return FusionResult.failure("empty_support")

        # 2. 误差与覆盖率：A⊆B ⇒ eps_B≤eps_A, rho_B≤rho_A
        eps_A = min(self.certs[m].eps for m in A) + self.gap
        rho_A = min(self.certs[m].rho for m in A)
        rho_A = min(rho_A, self.cal.conformal_lower(A, self.alpha))

        # 3. 冲突检测：两模态估计距离超过误差和即失败，禁止加权抹平
        estimates = {m: self.certs[m].estimate(obs) for m in A}
        if not self._compatible(estimates, A):
            return FusionResult.failure("modality_conflict")

        # 4. 鲁棒组合（仅在兼容时）
        x_hat = self._robust_combine(estimates, A)
        return FusionResult(True, S_A, eps_A, rho_A, x_hat, "ok")

    def _compatible(self, estimates, A):
        for m in A:
            for n in A:
                if m < n:
                    d = self.certs[m].distance(estimates[m], estimates[n])
                    if d > self.certs[m].eps + self.certs[n].eps:
                        return False
        return True

    def pareto_front(self, obs):
        """枚举/剪枝所有可行 A，按 (支撑体积大, 误差小) 取帕累托前沿"""
        frontier = []
        for A in self._subsets_by_size(self.certs.keys()):
            res = self.fuse(obs, A)
            if res.ok and not self._dominated(res, frontier):
                frontier = [f for f in frontier if not self._dominates(res, f)]
                frontier.append(res)
        return frontier


# IP-416 Long-Horizon Certificate Manager：风险/进度双账本
class LongHorizonCertificateManager:
    def __init__(self, H, alpha, goal_progress, min_progress_rate, theta_ind=0.8):
        self.H_rem = H
        self.alpha_rem = alpha
        self.alpha_cap = alpha               # 续期不得超过初始总预算
        self.pi_low = 0.0
        self.goal_progress = goal_progress
        self.min_rate = min_progress_rate    # 每步最小可证进度率
        self.ledger = RiskLedger()
        self.checkpoints = []

    def admissible(self, delta_risk, delta_progress, cert):
        """P28：风险守恒 + 进度单调 + 活性可达"""
        if delta_risk < 0 or delta_progress < 0:
            return False
        if self.H_rem <= 0 or not cert.valid:
            return False
        if delta_risk > self.alpha_rem / self.H_rem + 1e-12:
            return False
        if self.pi_low + delta_progress > self.goal_progress + 1e-9:
            return False
        # 即使此后只按最小速率推进，也必须在剩余时域内可达目标
        if self.pi_low + delta_progress + self.H_rem * self.min_rate < self.goal_progress:
            return False
        return True

    def commit_step(self, delta_risk, delta_progress, cert):
        if not self.admissible(delta_risk, delta_progress, cert):
            return None                      # 交由 SGC/HMC 走契约回退
        self.H_rem -= 1
        self.alpha_rem -= delta_risk
        self.pi_low += delta_progress
        self.ledger.record_step(self.H_rem, delta_risk, delta_progress)
        return self.snapshot()

    def renew(self, credit):
        """只允许在 alpha_cap 内补充长程预算；不放宽 v16 证书"""
        if credit < 0:
            raise ValueError("negative renewal credit")
        self.alpha_rem = min(self.alpha_cap, self.alpha_rem + credit)
        self.ledger.record_renewal(credit, self.alpha_rem)
        return self.snapshot()

    def reachable(self):
        return self.pi_low + self.H_rem * self.min_rate >= self.goal_progress

    def snapshot(self):
        return HC(self.H_rem, self.alpha_rem, self.pi_low, self.next_checkpoint)


# IP-418 Subgoal Contract Compiler：长程目标 → 契约链 → BTS 子树
class SubgoalContractCompiler:
    def __init__(self, bts, trm):
        self.bts = bts
        self.trm = trm

    def compile(self, goal, budget):
        subgoals = self._decompose(goal, budget.H)
        contracts = []
        prev_post = None
        for i, sg in enumerate(subgoals):
            sc = SubgoalContract(
                idx=i,
                pre=sg.pre,
                post=sg.post,
                H_i=sg.H,
                alpha_i=sg.alpha,
                fallback=contracts[-1] if contracts else self.bts.root.nc.Fallback,
            )
            if prev_post is not None and not prev_post.issubset(sc.pre):
                raise ContractCompositionError(i)
            if sc.H_i <= 0 or sc.alpha_i < 0:
                raise ContractBudgetError(i)
            contracts.append(sc)
            prev_post = sc.post
        return ContractChain(contracts)

    def to_bt_subtree(self, sc):
        """每条契约编译为 v16 BTS 子树；子树证书必须蕴含契约后置"""
        subtree = self.bts.build_subtree(sc.pre, sc.post, sc.H_i, sc.alpha_i)
        if not sc.post.issubset(subtree.nc.Post):
            raise ContractCompileError(sc.idx)
        return subtree


# IP-419 Horizon-Modality Chain Scheduler：三重预算下的单调分配
class HorizonModalityChainScheduler:
    def __init__(self, cmf, lhcm, sgc, hmcc, budget):
        self.cmf = cmf
        self.lhcm = lhcm
        self.sgc = sgc
        self.hmcc = hmcc
        self.budget = budget                # (B_mod, B_hor, B_risk)

    def schedule(self, obs, x):
        candidates = []
        for fuse in self.cmf.pareto_front(obs):
            if not self.lhcm.admissible(0.0, 0.0, fuse):
                continue
            for sc in self.sgc.permitted_contracts(self.lhcm, x):
                cost_mod = self.cmf.query_cost(fuse.A)
                cost_hor = sc.H_i
                cost_risk = sc.alpha_i
                if (cost_mod > self.budget.B_mod or
                        cost_hor > self.budget.B_hor or
                        cost_risk > self.budget.B_risk):
                    continue
                val = self._value(fuse, sc, x)
                candidates.append(Plan(fuse.A, sc, cost_risk, val))

        if not candidates:
            return self._degrade(obs, x)     # 单调退化到 v16 路径

        # 单调价值 + 基数预算下贪心；子模时给 (1-1/e) 近似
        return self._greedy_pack(candidates)

    def _value(self, fuse, sc, x):
        # 进度增益 + 安全余量 − 风险代价 − 模态代价；各项均为可证下界/上界
        return (sc.progress_lower
                + self._safety_margin(fuse.eps_A, fuse.rho_A)
                - self._risk_cost(sc.alpha_i)
                - self._modality_cost(fuse.A))

    def _degrade(self, obs, x):
        # 逐维单调：先降模态子集，再降契约，再降风险日程，最后交回 v16
        for A in self._modality_ladder(obs):
            for sc in self._contract_ladder(x):
                return Plan(A, sc, 0.0, 0.0)
        return None


# IP-421 Checkpoint Renewal Regulator：有条件续期
class CheckpointRenewalRegulator:
    def __init__(self, theta_ind=0.8, max_credit=0.5):
        self.theta_ind = theta_ind
        self.max_credit = max_credit

    def independence(self, evidence, exec_modalities, exec_calib_version):
        # 三项代理：模态不相交度、校准版本差异、外部验证
        disjoint = 1.0 - self._jaccard(evidence.modalities, exec_modalities)
        calib = 1.0 if evidence.calib_version != exec_calib_version else 0.0
        external = 1.0 if evidence.external_verified else 0.0
        return 0.5 * disjoint + 0.3 * calib + 0.2 * external

    def renew(self, lhcm, checkpoint, evidence):
        ind = self.independence(evidence, checkpoint.exec_modalities,
                                checkpoint.calib_version)
        if ind < self.theta_ind:
            lhcm.ledger.record_renewal_rejected(checkpoint, ind)
            return lhcm.snapshot()           # P30：风险原样结转

        credit = self.max_credit * ind * evidence.credit_scale
        credit = min(credit, lhcm.alpha_cap - lhcm.alpha_rem)
        lhcm.renew(max(0.0, credit))
        lhcm.checkpoints.append(checkpoint)
        lhcm.ledger.record_renewal_accepted(checkpoint, ind, credit)
        return lhcm.snapshot()
```

## 2. 关键不变式

- **I1（风险守恒）**：除 `Renew` 外，`α_rem` 单调不增；`Renew` 后 `α_rem ≤ α_cap`，且 `α_cap` 等于初始总风险预算。
- **I2（进度单调）**：`π_low` 单调不减；任何一步的 `Δπ_t` 必须由可证进度证书给出，不能由模型自评"我觉得前进了"。
- **I3（支撑反单调）**：`A⊆B ⇒ S_B⊆S_A ∧ ε_B≤ε_A ∧ ρ_B≤ρ_A`；融合不能制造支撑。
- **I4（失败吸收）**：空支撑、模态冲突、证据过期时，CMF 必须返回失败；禁止用加权平均继续。
- **I5（契约传递）**：`SC_i.Post⊆SC_{i+1}.Pre`；回退只能到 `SC_{i-1}` 或根 Fallback，禁止跳跃。
- **I6（续期闸门）**：`ind(CP_j)<θ_ind ⇒ credit=0`；续期只补充长程预算，不放宽 v16 证书。
- **I7（包含性）**：`Exec_v17⊆Exec_v16`；每个 v17 动作仍须通过 v16 的 BTS/TRM/WBC/CSC 证书。
- **I8（中立退化）**：任一组件失效 ⇒ 注入 `η_lh` ⇒ 等价 v16；五者全失效 ⇒ v16→v15→…→v6。

## 3. 推导

**引理 137（融合证书的可靠性与支撑反单调）** 设每个 `m∈A` 的 `ModC_m` 在 `S_m` 上有效，误差界 `ε_m`、覆盖率 `ρ_m`，且融合开销 `g_fuse` 为与 `|A|` 无关的固定常数。若 `A≠∅` 且 `S_A=∩_{m∈A}S_m≠∅`，则对任意 `x∈S_A`，融合估计 `x̂_A` 的误差不超过 `ε_A=min_{m∈A}ε_m+g_fuse`，覆盖率不低于 `min( min_{m∈A}ρ_m, ρ_conf(A) )`。进一步，对 `A⊆B` 有 `S_B⊆S_A`、`ε_B≤ε_A`、`ρ_B≤ρ_A`。证明：`x∈S_B ⇒ x∈S_m (∀m∈B) ⇒ x∈S_m (∀m∈A) ⇒ x∈S_A`；误差取所有参与模态的最小界再加固定开销，加入模态只能使最小值不增；覆盖率取最小，加入模态只能使最小值不增。冲突检测保证只在估计互相兼容时融合，故组合估计仍落在各模态误差球交集内。∎ 推论：**多模态融合的收益是"误差收紧"，代价是"支撑收缩"；两者构成帕累托前沿，不能同时最优。**

**引理 138（长程风险联合界与进度活性）** 设第 `t` 步的违规概率不超过 `δ_t`，且 `Σ_{t=1}^H δ_t ≤ α`。则 `P(∃t≤H: 违规) ≤ α`。若每步 `Δπ_t≥0` 且由有效证书给出，则 `π_low(t) ≤ 真实进度(t)`。若存在可证最小进度率 `ρ_π` 使 `π_low(t)+H_rem·ρ_π ≥ g`，则任务在剩余时域内可达。证明：第一式由联合界（Boole 不等式）直接得到；第二式对步数归纳；第三式由 `ρ_π` 的定义与 `H_rem` 单调递减直接得到。∎ 推论：**长程安全与长程活性是两个独立账本**：只有风险账本会"安全地失败"，只有进度账本会"不安全地成功"；必须同时记账。

**引理 139（子目标契约的传递合成）** 若契约链满足 `SC_i.Post⊆SC_{i+1}.Pre`，且每个 `SC_i` 在 `H_i`、`α_i` 内从 `Pre_i` 到达 `Post_i`，则合成链 `SC_1∘…∘SC_n` 在 `ΣH_i`、`Σα_i` 内从 `Pre_1` 到达 `Post_n`。若第 `i` 段失败并回退到 `SC_{i-1}`（或根 Fallback），回退动作仍在 `SC_{i-1}.Pre` 内，不产生跳跃。证明：对 `n` 归纳。`n=1` 平凡。设前 `n-1` 段合成成立，末段前置 `Pre_n` 被 `Post_{n-1}` 包含，故末段可在前段结束后启动；时域与风险预算相加；回退由 `Fb_i=SC_{i-1}` 的定义保证。∎ 推论：**长程规划的正确性可以局部验证**：只需验证每条契约的内部证书与相邻契约的 `Post⊆Pre`，无需全局重证。

**引理 140（检查点续期的无免费午餐界）** 设检查点证据 `E_j` 与执行误差 `U_j` 的互信息为 `I(E_j;U_j)=c`，执行误差熵为 `H(U_j)`。则续期可扣除的风险信用满足 `credit ≤ credit_0·(1−c/H(U_j))`；当 `ind(CP_j)<θ_ind` 时 `credit=0`。特别地，若 `E_j` 由与执行完全相同的模态子集和同一校准集产生，则 `c=H(U_j)`，`credit=0`，风险原样结转。证明：由数据处理不等式，相关证据不能增加关于隐藏误差的信息；`c=H(U_j)` 时证据与误差完全相关，条件熵不降，故无可扣除信用。`ind<θ_ind` 时由 P30 直接令 `credit=0`。∎ 推论：**检查点不是"风险清零"，而是"用独立信息换信用"**；同一套传感器自证清白不产生任何信用。

**引理 141（长程-模态联合退化与包含性）** 若 LHCM/CMF/SGC/HMC/CRR 中任一失效并替换为中立元 `η_lh`，则 `Exec_v17⊆Exec_v16`；五者全失效时严格等价 v16，并可继续沿 v16→…→v6 退化。证明：v17 的每个动作仍须通过 v16 的 BTS 节点证书、TRM 里程碑许可、WBC 阶层证书与 CSC 调度；LHCM 只施加额外的风险/进度约束，CMF 只收缩支撑域并收紧误差，SGC 只把子目标编译为 v16 子树，HMC 只做预算分配，CRR 只补充长程风险预算而不放宽 v16 证书。故 v17 可行动作集合是 v16 可行动作集合的子集。∎ 推论：**v17 的所有新组件都是"减法器"**：它们只能让系统更保守，不能新增授权。

**引理 142（三重预算分配的近似最优性）** 设 `val_lh` 对模态子集 `A` 单调子模、对契约选择单调，预算为基数约束 `|A|≤B_mod`、`ΣH_i≤B_hor`、`Σα_i≤B_risk`。则 HMC 的贪心打包达到 `(1−1/e)` 近似；若 `val_lh` 可分解为各步边际价值之和（模函数），则贪心精确。证明：单调子模函数在基数约束下的贪心近似是标准结论；模函数下贪心按边际价值排序即最优。三重预算可视为拟阵交的松弛，贪心给出可行且近似最优解。∎ 推论：**在线调度不需要解 NP-hard 整数规划**；只要价值函数保持单调子模，`(1−1/e)` 界足够覆盖实时预算。

## 7. 已知风险与失效模式

1. **支撑交集维数灾难**：模态越多，`S_A=∩S_m` 体积指数衰减，长程轨迹很快走出交集，导致 CMF 持续失败。缓解：按任务相关子空间投影、模态子集主动交接、支撑桥在线扩张、限制同时融合的模态数。

2. **相关模态误差**：视觉与语言共享同一训练分布，冲突检测无法发现共同偏差，融合证书被高估。缓解：独立校准集、模态去相关审计、外部验证、对抗采样。

3. **检查点风险洗白**：`ind(CP_j)` 被在线代理指标高估，风险账本被合法清零。缓解：提高 θ_ind、随机外部审计、续期信用上限、账本不可篡改日志。

4. **风险日程过保守导致冻死**：均匀 `α_rem/H_rem` 在早期过紧，系统只敢执行最小动作，长程活性下降。缓解：非均匀风险日程、进度感知分配、检查点续期、保守但可调的 `min_rate`。

5. **进度证书被"刷"**：模型自评进度，安全地原地打转。缓解：进度必须由外部可观测谓词/几何度量给出、进度与目标因果链审计、对抗性进度测试。

6. **契约分解与真实前置不匹配**：`Post_i⊆Pre_{i+1}` 在仿真成立、实机不成立。缓解：实机前置标定、保守前置扩张、契约回归测试、仿真-实机差异证书。

7. **模态校准非平稳**：校准集与部署分布漂移，`ρ_A` 乐观。缓解：在线共形、漂移检测、滑动窗口重校准、保守下界。

8. **延迟与新鲜度**：融合使用了过期模态，证书时间戳不一致。缓解：时间戳证书、过期拒绝、状态预测与补偿、同步屏障。

9. **融合组合爆炸**：`2^M` 子集枚举在 M 大时不可行。缓解：帕累托剪枝、贪心子集选择、分层融合、限制 M≤8。

10. **长程状态估计漂移**：融合观测的误差沿轨迹累积，检查点状态本身漂移。缓解：检查点重定位、SLAM 式闭环、状态证书与观测证书分离。

11. **续期预算膨胀**：频繁检查点导致 `α_rem` 反复补充，总风险超过初始预算。缓解：`α_cap` 硬上限、信用总量预算、续期次数上限、全局审计。

12. **与 v16 证书栈的累积保守性**：v16 已有多层交集，v17 再叠加支撑/风险/进度约束，可行域可能接近空集。缓解：中立元快速退化、选择性放宽（需形式化证明）、价值加权而非纯交集、监控可行域体积。

## 8. 本轮最大风险

**一句话**：检查点续期的"独立性"只能靠在线代理指标估计，而最危险的分布漂移恰恰会让执行模态与检查点模态**同时**出错——此时 `ind(CP_j)` 被高估、风险账本被合法清零，长程误差却在每一段"已认证"的区间里继续累积，最终得到一个**每段都通过证书、整条链却绝对不安全的长程行为**。
