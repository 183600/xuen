# 第 74 轮（承接第 73 轮「MODGAUGE-RAS 计量契约代数」IP-295~302；新灵感循环第 1 轮；本轮灵感：「云边协同」×「关节驱动」）

> R73 把证据计量从单体审计提升为可组合契约（EC / MMS / CCA / ΣREFLEX / CPB），并用 ECG（IP-302）与 MIC 补了因果链与形态无关性。但 R73 有两个**未言明的物理与信任前提**，恰好被「云边协同」与「关节驱动」同时击穿：
> - **同址同步前提**：MReg 默认所有模块在同一计算域、同一时钟、同一版本、同一信任边界内；证据的**位置、来源、新鲜度、版本**不是契约字段。云边协同把重感知、大模型、长期校准放到云上，把实时否决与执行留在边缘，于是出现**陈旧证据**（stale evidence）、**版本错配**（version skew）、**时钟偏斜**（clock skew）、**链路丢失/压缩**、**云端拜占庭**。把云证据当本地证据组合，等于把不同实验室、不同时间、不同标定链的尺子当成同一把——R73 的「组合单调性」会在跨信任域时**静默失效**。
> - **动作即指令前提**：R73 的 χ_R(g) 与安全证明把动作 g 当作已经实现的物理动作。但关节驱动有摩擦、齿隙、饱和、热降额、电流环延迟、编码器量化；**命令动作 u_cmd ≠ 实现动作 a_real**。更严重的是，驱动本身也是传感器（电流/力矩/编码器），其噪声被它所执行的动作污染（PWM、热、齿隙），于是驱动同时是「最后一个执行模块」和「一个新证据模块」，而 R73 的类型系统里**没有动作类型**。用 u_cmd 写安全界，等于证明了一个世界中从未发生过的动作。
>
> 本轮两个灵感正好补这两个前提：
> - **云边协同 → SPLIT 架构（Split-trust, Provenance-aware, Link-instrumented, Instantiated-action, Trusted-edge）**：把「网络」升级为**计量模块 LinkMet**（延迟/丢包/压缩/时钟/版本各有不确定度分量或否决指示），把云证据升级为**位置化证据契约 DEC**（locus / provenance / freshness / trust / version），并定义**委派代数 CDA**（PROP / ATTEST / COMMIT / REVOKE）：云只能**提议**，边缘**验证并提交**；未经边缘独立见证的云证据不得进入安全证书。安全界与云的正确性、可用性、延迟**解耦**，云只影响能力保留率。
> - **关节驱动 → JDRC + DRX**：每个关节声明**驱动证据契约**（可达动作集 A_adm、实现映射 R、六分量实现不确定度 u_act、热/能量预算、故障模式、驱动反作用通道 χ_D）；引入**动作-证据对偶 AED**：驱动是双端口换能器（动作边 u_cmd→a_real，证据边 x_drive→e_drive），所有下游安全证明必须吃 a_real；χ_D 把「动作→热/磨损/齿隙→未来能力与证据质量」作为第五反作用层 L5 加入 ΣREFLEX。
>
> 核心命题：**不再问「证据能否组合」，而问：当证据跨信任域、动作经物理换能器时，组合规则能否仍然给出与云无关、与命令无关的安全界？** 把 MODGAUGE-RAS 重构为 **SPLIT-GAUGE-RAS**——**信任分域 + 动作实现**的证据计量。

## 0. 直觉与动机

**灵感 1（云边协同 → 不确定度不是位置不变量，证据需要「护照」）**
直觉：同一个深度模型，在边缘用本地标定、当前帧、本地时钟推理，和在云上用三天前的模型、压缩后的证据、另一套标定推理，输出的「u = 0.03 m」根本不是同一个量。云边的差别不是「算得快/算得慢」，而是**计量学上的可追溯性差异**：证据来自哪个模型版本、哪套数据、哪次标定、经过哪条链路、现在是否过期、由谁签名。R73 把所有证据压成一个标量 u 和一张追溯链 τ，但 τ 只在同一信任域内可复算；跨域后，**来源（provenance）和新鲜度（freshness）本身就是不确定度的一部分**。因此云边协同的正确抽象不是「把模块搬到云上」，而是给每条证据发一本**护照**：位置、来源哈希、逻辑时间、信任等级、语义版本、有效期、带宽预算。没有护照的云证据不是证据，只是建议。

**灵感 2（云边协同 → 边缘不是云的下游，而是云的公证人）**
直觉：云有全机队数据、大模型、长期校准趋势，因此它擅长**扩大有效域**（识别长尾材质、预测关节磨损、给出前馈轨迹）；但云是非确定性的、可被攻击的、会断网的、会版本升级的，因此它不能持有**安全提交权**。正确分工是：云做**提议者**，边缘做**公证人/提交者**。云可以提出「这个材质是镜面，深度有效域应扩大」「这个关节的齿隙已增大，u_act 应上调」「前方可通行」；边缘用本地独立见证（关节力矩、接触、已知几何、当前深度残差）做**见证审计**，通过后才允许写入 MReg 并进入安全证书。这样云越强，系统能力越高；云越坏，系统越保守，但**不会更危险**。这把 R73 的 MMS 从「单机模块图」提升为「跨信任域的提议-证据图」。

**灵感 3（关节驱动 → 命令是给执行器的建议，a_real 才是世界的输入）**
直觉：控制器发出 τ_cmd = 1.0 N·m，并不意味着世界收到 1.0 N·m。谐波减速器的摩擦、齿隙、柔度、电流环带宽、母线电压跌落、绕组温升导致的力矩常数漂移，都会让 a_real 偏离 u_cmd；在饱和、换向、低速爬行、热降额时偏差最大。R73 的 χ_R(g) 用 g 调制传感器噪声，但 g 是**命令**；如果实际动作是 0.7 N·m，则「动作→视角→深度噪声」的映射、接触力上界、碰撞风险全部按错误的动作计算。这不是建模精度问题，而是**类型错误**：命令动作与实现动作是两种类型，R73 允许它们隐式转换。修复必须在类型系统里加一条：任何消费动作的模块只能吃 `A_real`；从 `U_cmd` 到 `A_real` 必须经过带有效 `u_act` 的 JDRC。

**灵感 4（关节驱动 → 驱动也是传感器，且被自己的动作污染）**
直觉：关节驱动器测量电流、母线电压、编码器、温度，这些是**最靠近物理接触的证据**：电流×力矩常数≈力矩，编码器差分≈速度，温度→热降额。但执行动作会污染这些测量：PWM 开关噪声进入电流采样，热使力矩常数和电阻漂移，齿隙使编码器与输出端出现死区，多关节共母线造成交叉耦合。于是驱动是**动作-证据对偶**：同一个物理端口既输出动作，又输出关于动作的证据，二者通过热/磨损/齿隙状态耦合。R73 的 EC 只有证据端口；SPLIT 给驱动增加动作端口，并要求两个端口的契约同时成立。驱动的反作用也不止 L4 视角层：动作→热/磨损/齿隙→未来可达力矩与证据质量→动作，这是 **L5 驱动反作用层**。

**灵感 5（两者交汇 → 边缘是动作与证据唯一物理相遇的地方）**
直觉：云里没有摩擦，没有齿隙，没有接触力；云只有数据和模型。**动作与证据的物理相遇只发生在边缘的驱动器和传感器上**。因此边缘不仅是低延迟计算节点，更是**物理锚点**：它可以用关节力矩/接触证据去验证云关于「物体在哪、抓没抓住、路能不能走」的提议；也可以用云的全机队先验去补偿本地磨损。云边协同的计量学本质是：**用边缘的物理见证锚定云的高容量先验**，而不是用云的先验替代边缘的物理见证。这个视角把「云边协同」从系统工程问题提升为**跨信任域的计量可追溯性问题**。

**灵感 6（与 R73 的关系 → 严格泛化，而非另起炉灶）**
直觉：SPLIT 不新增一套安全哲学，而是把 R73 的每个对象加两个坐标：**位置**与**实现**。EC 加 locus/provenance/freshness；CCA 加委派与链路算子；ΣREFLEX 加 L5 驱动通道；退化链加断云、断链、驱动故障；CPB 加两条可证伪主张。理想条件（云=边缘、链路理想、驱动无误差）下，SPLIT 必须逐指令退化为 MODGAUGE。这样 R73 的全部定理、实验与审计资产不废弃，只是获得**分布外与跨域**的适用条件。R73 的 MIC 也由此获得执行语义：**MIC† = 契约对形态/位置参数化，locus 是运行时绑定而非契约常量**；同一 MIC 可在 EDGE/CLOUD/不同本体上实例化，但任何跨域绑定仍必须经 CDA。

## 1. 形式化定义（增量：定义 383–402）

**定义 383（SPLIT-GAUGE-RAS 总览）** SPLIT-GAUGE-RAS = (MODGAUGE-RAS†, DEC, CDA, LinkMet, JDRC, AED, DRX, CEC, CLG, J_SPLIT, CPB†)。六不变式：
(i) **提交权在边**：云只能产生提议，只有边缘可 COMMIT 到 MReg 与安全证书；
(ii) **跨域不免费融合**：任何跨 locus 的并联/串联必须先经 LinkMet 与 ATTEST，未见证的云证据不得降低 u、不得扩大 D；
(iii) **新鲜度单调**：陈旧只会增大 u、收缩 D，过期即 stub；
(iv) **实现动作守恒**：任何动作消费模块只接受 `A_real`，安全界不得使用 `U_cmd`；
(v) **驱动反作用完备**：每个关节声明 χ_D 与热/能量预算，ΣREFLEX 预算闭合；
(vi) **退化安全单调**：断云/断链/驱动故障 → 对应模块 stub 或边缘自治，能力可降，安全界不升。

**定义 384（位置化证据契约 DEC）** DEC = (EC, λ, π, φ, κ, ν, β, τ_ttl, C_cap)：
- λ ∈ {EDGE, CLOUD}：证据产生/驻留位置；EDGE 证据可含 LINK/DRIVE 子类型；
- π：溯源链 `H(h_code ‖ h_model ‖ h_data ‖ h_calib ‖ π_parent)`，带签名；
- φ = (lc, t_wall, δ_clock, Δ_max)：逻辑时钟、墙钟、允许偏斜、最大新鲜期；
- κ ∈ {revoked ≺ declared ≺ attested ≺ verified}：信任等级格；
- ν：语义版本；`ν_edge ⊑ ν_cloud` 为兼容关系（主版本必须相等，次版本可前向兼容）；
- β = (b_min, q_max)：链路带宽与压缩预算；
- τ_ttl：证书有效期；C_cap：声明的能力扩展（域扩展/先验/前馈），**不是安全承诺**。
类型规则：EC 的输入/输出类型现在带 locus 标签；`EDGE ⇄ CLOUD` 不存在隐式转换，必须经 CDA。

**定义 385（云边委派代数 CDA）** 四个算子：
- **PROP（提议）** `A ⇝ B`：边缘收到云证据 (ξ, u, D, π, φ, κ=declared)。当且仅当 π 验签通过、ν 兼容、φ 在 Δ_max 内时，输出 `(ξ, inflate(u, Δ), contract(D, Δ), κ=declared)`；否则输出 stub（定义 399）。PROP **永不降低 u、永不扩大 D**。
- **ATTEST（见证）** `A ⊲_α B`：边缘在独立见证集 W 上运行验证器，得到 conformal p 值；若 p > α，则 `u' = max(u, u_att(W))`，`D' = D ∩ (D_edge ∪ D_wit(W))`，κ=attested；否则投否决票并 REVOKE 该 π。
- **COMMIT（提交）** `B ⊨ A`：仅边缘可调用；把 (ξ, u', D', π, κ) 写入 MReg，签名并计入 J_SPLIT。COMMIT 前必须满足 LinkMet 有效、ATTEST 通过、u' ≥ u_att、D' 有本地见证支撑。
- **REVOKE（撤销）** `A ⊣`：把 π 加入撤销表；所有由 π 派生的证据递归置 stub；幂等。
代数律：PROP 单调（u 不减、D 不增）；ATTEST 有本地地板（不得低于 u_att/W 能支撑的精度）；COMMIT 单边（云无提交权）；REVOKE 幂等且吸收。

**定义 386（网络链路计量模块 LinkMet）** LinkMet 是一个合法 EC：
`LinkEC = (T_in=E, T_out=E, u_fields=(u_lat,u_loss,u_quant,u_clock,u_skew), χ_R=id, D_link, τ_merge=append, I⊥={LINK_UNAUTH, VERSION_INCOMPAT, REPLAY}, W_link, seal_ref=SEAL-LINK)`。
`u_link² = u_lat² + u_loss² + u_quant² + u_clock² + u_skew²`：
- u_lat：延迟/抖动导致的新鲜度损失，`u_lat = L_ev·Δ`；
- u_loss：丢包/部分传输导致的缺失证据；
- u_quant：证据摘要压缩误差（带宽预算 β）；
- u_clock：墙钟偏斜超过 δ_clock 时的排序不确定度；
- u_skew：语义版本漂移（兼容但不相同）导致的模型差异。
`D_link = {已认证} ∧ {RTT ≤ τ_rtt} ∧ {loss ≤ ℓ_max} ∧ {ν 兼容} ∧ {时钟偏斜 ≤ δ_clock}`。**链路不是管道，而是一台有校准证书的测量仪器**；云边组合 = CCA 的 SER 组合，无需特殊代数。

**定义 387（关节驱动证据契约 JDRC）** JDRC = (A_adm, R, u_act, D_drive, P_th, E_budget, χ_D, F_fault, seal_ref)：
- `A_adm(x) = {a : |τ| ≤ τ_max(T), |ω| ≤ ω_max(T), |P| ≤ P_max, E_rem ≥ 0}`：当前状态下的可达动作集；
- `R: (u_cmd, x) ↦ a_real`：实现映射；契约声明其误差上界 u_act；
- `u_act² = u_TC² + u_fric² + u_back² + u_th² + u_quant² + u_delay²`（定义 389）；
- `D_drive = {T ≤ T_max, |τ| ≤ τ_max, 总线延迟 ≤ d_max, 健康标志正常}`；
- `P_th: T_{t+1} = f(T_t, τ, ω, T_amb)`：电-热模型；
- `E_budget`：能量/热预算；
- `χ_D`：驱动反作用通道（定义 390）；
- `F_fault = {overheat, encoder_loss, driver_fault, bus_timeout, brake_stuck}`。

**定义 388（动作-证据对偶 AED）** 驱动模块是一个双端口换能器：
`Drive = (T_action: U_cmd → A_real, T_evidence: X_drive → E_drive)`。
类型规则：任何模块的动作输入必须是 `A_real`；`U_cmd → A_real` 的唯一合法通道是带有效 JDRC 的驱动模块。证据端口可以读取 `(τ_meas, q, i, T, V_bus)`，但其有效域依赖动作端口的状态（热、饱和、齿隙）。**这条类型规则把 R73 的「动作即指令」隐式假设变成编译期/运行期可检查的约束。**

**定义 389（驱动实现不确定度六分量与证据似然）** 给定 (T, ω, load, direction, bus state) 条件下：
`u_act² = u_TC² + u_fric² + u_back² + u_th² + u_quant² + u_delay²`。
证据端口 `e_drive = (τ_meas, q, i, T, V_bus)` 的条件似然
`p_drive(e_drive | x, a_real, load) = 𝒩(e_drive; h_drive(x, a_real, load), Σ_drive)`，
其中 Σ_drive 由**同一六分量在证据端口重新标定**给出（记 u_drv）；动作端口用 u_act，证据端口用 u_drv，二者共享热/齿隙状态但各自有独立校准证书。
- u_TC：力矩常数随温度/磁饱和漂移；
- u_fric：Stribeck/Coulomb 摩擦与负载相关项；
- u_back：谐波/行星减速器齿隙与迟滞；
- u_th：热降额与绕组电阻变化；
- u_quant：编码器/电流采样量化；
- u_delay：电流环、总线、控制周期的总延迟。
六分量由独立物理机制产生，条件近似不相关；遗漏任一（尤其 u_back 与 u_delay）会系统性低估，与 DPEM 六分量、DMEM 四分量同型。有效域 `D_drive` 之外 ⇒ 关节 stub 或安全停。

**定义 390（驱动反作用通道 DRX / L5）** `χ_D: (u_cmd, x) → (ΔT, Δwear, Δback, Δu_act)`：动作如何改变热状态、磨损、齿隙与未来实现不确定度。反作用成本
`c_reflex^D = w_T·ΔT + w_E·ΔE + w_u·E[Δu_act]`，
安全集 `D_safe^D = {T_{t+1} ≤ T_max − margin, E_rem ≥ 0, u_act ≤ τ_d}`。
把 `c_reflex^D` 加入 R73 定义 371：`Σ_t (Σ_i c_reflex^i + Σ_j c_reflex^{D,j}) ≤ B_total`，`Ω_safe = Ψ_safe ∩ Z_safe ∩ C_safe ∩ V_safe ∩ D_safe`。L5 与 L4 同构但不同：L4 是「动作→视角→证据质量」，L5 是「动作→执行器状态→未来能力与证据质量」。

**定义 391（云边提交协议 CEC）** 状态机：
`EDGE_ONLY → DELEGATED → ATTESTED → COMMITTED`，任一状态 `→ REVOKED`。
- EDGE_ONLY：仅本地模块；云提议缓存但不入安全路径；
- DELEGATED：收到云提议，已做 PROP 膨胀，未见证；
- ATTESTED：边缘见证通过，尚未提交；
- COMMITTED：边缘签名写入 MReg，进入 J_SPLIT；
- REVOKED：π 撤销，派生证据递归 stub。
转移守卫：COMMIT 需要 `LinkMet.valid ∧ ATTEST.pass ∧ u' ≥ u_att ∧ D' ⊆ D_edge ∪ D_wit ∧ ν 兼容`。云状态机没有 COMMIT 边。

**定义 392（新鲜度与陈旧膨胀）** 契约声明漂移 Lipschitz 常数 L_u 与最大新鲜期 Δ_max：
`inflate(u, Δ) = min(u + L_u·Δ, ∞)`，`D(Δ) = D ∩ {状态漂移 ≤ L_x·Δ}`；Δ 用逻辑时钟差 `lc_now − lc_produced`，墙钟仅作交叉校验。若墙钟差与逻辑差超过 δ_clock，追加 u_clock；若 Δ > Δ_max，输出 stub。**没有任何跨域操作可以把 u 降到 u0 以下——新鲜度不是免费的。**

**定义 393（溯源链与证书新鲜度）** 证书 `Cert = (π, sig, ν, ttl, nonce, claims)`；`π` 是模型/数据/标定/代码/父证书的哈希链；边缘维护撤销表与 nonce 缓存防重放。证书 TTL 到期 → 自动降级为 declared 或 stub；版本不兼容 → `I⊥={VERSION_INCOMPAT}`；签名失败 → `I⊥={LINK_UNAUTH}`。

**定义 394（分体证书 J_SPLIT）**
`J_SPLIT = ⊗_{i∈V_edge} J(m_i) ⊗ J_comp(MReg_edge) ⊗ J_link(LinkMet) ⊗ J_deleg(CEC) ⊗ J_drive({JDRC_j})`。
云侧只产生 `J_prop`（提议回执、溯源、TTL），**不与安全证书合取**。`Valid(J_SPLIT)` 要求：边缘模块证书有效、组合校验通过、链路有效、所有云派生证据已 COMMIT 或已 stub、所有关节 JDRC 有效。理想条件下 `Valid(J_SPLIT) ⇒ Valid(J_MOD)`。

**定义 395（能力-安全分解）** `SafetyInv: P(unsafe execution) ≤ ε`；`CapRet = E[可完成安全任务集 | split] / E[可完成安全任务集 | edge-only]`。C4 的可证伪形式：在拜占庭云下 SafetyInv 不变（0 违例），而 CapRet 随云质量单调变化；若云诚实，CapRet > 1。

**定义 396（因果-位置图 CLG）** CLG = (V, E_c, E_t, λ)：V 为证据/动作节点，E_c 为 R73 ECG 的因果边，E_t 为跨 locus 的传输边，λ 标注 locus/provenance。规则：任何跨 locus 的因果路径必须包含至少一条 ATTEST 边；若某条因果边的残差超出 conformal 集，则该路径触发否决，而非仅增加方差。这把 R73 的 ECG 从「因果追踪」升级为「跨域因果可追溯性」。

**定义 397（云边威胁面 AIC-CLOUD）** ℰ_cloud = {陈旧证书重放、模型投毒、版本降级、时钟偏斜注入、链路 DoS/带宽耗尽、证据篡改、split-brain、隐私侧信道}。防线：溯源链 + nonce + TTL + 逻辑时钟 + 边缘否决 + 压缩预算 + 最小化上传。**单源云证据不定案**（继承 E356/E357 原则）。

**定义 398（驱动威胁面 AIC-DRIVE）** ℰ_drive = {力矩/编码器欺骗、温度传感器欺骗、齿隙注入（磨损加速）、总线延迟注入、旧驱动证书重放、云端恶意前馈}。防线：动作-证据残差、独立热模型、编码器-力矩一致性、JDRC 有效域、边缘 COMMIT、安全停/抱闸。

**定义 399（分体退化链）** 云断 → EDGE_ONLY；链路异常 → LinkMet stub（云证据全 stub，本地证据保留）；版本不兼容 → REVOKE 对应 π；JDRC 失效 → 关节 stub + 安全停/抱闸；u_act 超阈值 → 动作钳位到 A_adm；DPEM/DMEM/IRL 失效 → R73 定义 381 的模块 stub。安全侧只增不减；能力损失有上界。

**定义 400（MBench-S 分体基准）** MB4（云边分体：受控延迟/丢包/版本/时钟/拜占庭云注入 + 3 个操作任务）、MB5（驱动实现：饱和/齿隙/摩擦/热降额矩阵 + 3 个装配任务）。每个 ≤3 小时单卡 + 一台边缘设备可复现；预注册脚本、固定种子、密封保持集 SEAL-MB-S。

**定义 401（CPB 扩展）** 新主张：
- **C4（认证委派）** ← (DEC, CDA, LinkMet, CEC, J_SPLIT) ← MB4 ← AB4（delegated vs trusted-cloud vs edge-only）←（拜占庭云下安全违例，CapRet，边缘 WCET，陈旧容忍，版本错配检出）。
- **C5（动作实现计量）** ← (JDRC, AED, DRX) ← MB5 ← AB5（realized vs commanded vs no-thermal）←（力超调率，饱和下碰撞率，热违例，抓取成功率，停止步数方差）。
非绑定组件 = 工程附件，不进 MReg、不进正文。

**定义 402（证明局部性与认证成本）** `CertCost_split = O(|V_edge| + |E_edge| + |J|·|W|)`，与云模型参数量、机队规模、云端训练数据量无关。边缘安全证书只需要边缘模块 + 链路证书 + 驱动证书；云 `J_prop` 只作为输入，不进入证明的合取式。这是 C4 的成本可证伪形式：机队从 1 台扩到 100 台，边缘 CertCost 不变。

@dataclass(frozen=True)
class DelegatedContract(EvidenceContract):
    locus: str                       # EDGE / CLOUD
    provenance: Provenance           # 哈希链 + 签名
    freshness: Freshness             # lc/t_wall/delta_max

    semver: SemVer
    bandwidth: BandwidthBudget
    ttl_s: float
    capability: FrozenSet[str]       # 能力扩展声明，不是安全承诺

# IP-304 CDA：PROP / ATTEST / COMMIT / REVOKE
def prop(cloud_ev, edge, now):
    if not verify(cloud_ev.provenance) or not compatible(cloud_ev.semver, edge.semver):
        return stub(cloud_ev)
    d = logical_delta(now, cloud_ev.freshness)
    if d > cloud_ev.freshness.delta_max:
        return stub(cloud_ev)
    u = inflate(cloud_ev.u, d, cloud_ev.freshness.L_u)
    D = shrink(cloud_ev.D, d, cloud_ev.freshness.L_x)
    return replace(cloud_ev, u=u, D=D, trust='declared')

def attest(ev, witness_set, alpha):
    p = conformal_pvalue(witness_set.residual(ev))
    if p <= alpha:
        return veto(ev, reason='ATTEST_FAIL'), revoke(ev.provenance)
    u_att = witness_set.uncertainty_floor(ev)
    D_wit = witness_set.supported_domain(ev)
    return replace(ev, u=max(ev.u, u_att), D=ev.D & (ev.D_local | D_wit),
                   trust='attested'), None

def commit_edge(ev, edge, mreg, now):
    if not (ev.trust == 'attested' and edge.link.valid(now)
            and ev.u >= edge.attestation_floor(ev)
            and ev.D <= (edge.local_domain(ev) | edge.witness_domain(ev))):
        return False
    mreg.add(sign(edge.key, ev)); return True            # 云无此路径

# IP-305 LinkMet：网络作为计量模块
def link_step(ev, link_state, now):
    u_lat = link_state.L_ev * max(0, now - link_state.tx_time)
    u_loss = link_state.loss_uncertainty()
    u_quant = link_state.compression_error(ev, link_state.bandwidth)
    u_clock = link_state.clock_skew_uncertainty()
    u_skew = link_state.model_skew_uncertainty(ev.semver, link_state.semver)
    D = link_state.valid_domain()
    u = math.sqrt(u_lat**2 + u_loss**2 + u_quant**2 + u_clock**2 + u_skew**2)
    return replace(ev, u=u, D=ev.D & D,
                   veto=ev.veto | link_state.vetoes())   # O(1)/包

# IP-306 JDRC + AED：驱动实现与动作-证据对偶
class JointDriveContract:
    def admissible(self, x):          # A_adm(x)
        T, w, E = x.temp, x.omega, x.energy_remaining
        return (abs(x.tau) <= self.tau_max(T) and abs(w) <= self.omega_max(T)
                and x.power <= self.p_max and E >= 0)
    def realize(self, u_cmd, x):      # U_cmd -> A_real
        a = self.plant.map(u_cmd, x)  # 含摩擦/齿隙/饱和/热
        u_act = self.u_act_six(x, u_cmd)
        return RealizedAction(a=a, u_act=u_act,
                              domain=self.domain(x) & inside(a, self.A_adm(x)))
    def u_act_six(self, x, u_cmd):
        return math.sqrt(self.u_TC(x)**2 + self.u_fric(x, u_cmd)**2
                         + self.u_back(x, u_cmd)**2 + self.u_th(x)**2
                         + self.u_quant(x)**2 + self.u_delay(x)**2)

# IP-307 DRX：第五反作用层 L5
def drive_reflex_step(drives, u_cmd, state, budget):
    total, states2 = 0.0, {}
    for j, d in drives.items():
        dT, dWear, dBack, du = d.ec.chi_D(u_cmd, state[j])
        c = d.ec.w_T*dT + d.ec.w_E*d.energy(dT) + d.ec.w_u*du
        if d.ec.temp_next(state[j], dT) > d.ec.T_max - d.ec.margin:
            return None, total                       # 热稳态越界 → 拒绝
        states2[j], total = d.step(state[j], dT, u_cmd), total + c
    if budget.spent + total > budget.B:
        return None, total
    return states2, total

# IP-308 CEC + J_SPLIT：边缘提交与分体证书
def cec_round(edge, cloud, mreg, now):

        return edge_only(edge, mreg, now)     # LinkMet stub，安全不降

    return edge_only(edge, mreg, now)

# IP-309 CLG：因果-位置图审计
def clg_audit(clg, residuals, alpha):

## 3. 推导

**引理 38（陈旧膨胀的单调性与 Lipschitz 上界）** 若证据状态的漂移满足契约声明的 Lipschitz 界 `‖x(t+Δ)−x(t)‖ ≤ L_x·Δ`，且不确定度对状态 Lipschitz，则 `inflate(u,Δ) = u + L_u·Δ` 关于 Δ 单调不减；`D(Δ)` 关于 Δ 单调收缩；存在 Δ_max 使证据退化为 stub。**证明**：由 Lipschitz 与三角不等式，u 的增量不超过 L_u·Δ；域约束随漂移界收紧。系：**跨域不存在「越新越好」的免费午餐；TTL 是安全参数，不是工程参数。**

**引理 39（委派不降低证据质量）** 对任意 PROP/ATTEST/REVOKE 序列，输出满足 `u_out ≥ u_in` 且 `D_out ⊆ D_in ∪ D_wit`；ATTEST 只能在本地见证能支撑的域上扩展 D，且 u 不得低于本地见证地板 u_att。**证明**：PROP 的 inflate 非负、D 收缩；ATTEST 取 max 与交集；REVOKE 置 stub（u=∞）。“云声称更准”不是降低 u 的合法理由。系：**云只能扩大能力域（在见证支撑处），不能缩小安全不确定度。**

**引理 40（链路是合法 EC）** LinkMet 满足定义 367 的全部字段；其不确定度五分量条件独立，且 D_link 显式声明有效域；因此 R73 的 CCA 单调性（引理 34）在串联 LinkMet 后仍成立。**证明**：逐字段检查 + 引理 34 的 Lipschitz 传播。系：**云边协同不需要新的组合语义；它需要的是把链路当模块，而不是当零延迟管道。**

**引理 41（实现间隙反例）** 存在负载/温度/换向状态使 `|a_real − u_cmd| > 0` 且该偏差不被任何仅依赖 u_cmd 的界覆盖；因此若安全证明使用 u_cmd 而实际执行 a_real，则存在状态使物理风险超过证明界。**证明**：构造齿隙死区 + 摩擦 + 热降额同时发生的状态；命令力矩不变而输出力矩落入死区，任何 u_cmd 的函数都无法区分。系：**命令级安全界不是保守，而是类型错误；它证明的是另一个动作。**

**引理 42（DRX 的有限停止与热安全）** 若每个非平凡动作的 `c_reflex^D` 有正下界 ε_D，且边际任务增益非增，则 ΣREFLEX（含 L5）存在有限停止步 n*；若热模型 P_th 满足 `T_{t+1} ≤ T_t + a·τ² − b·(T_t−T_amb)` 且预算按 `T_max − margin` 拒绝，则热安全不变式成立。**证明**：与 R71 引理 31 / R73 引理 36 同型；热部分由归纳与拒绝规则直接得。系：**增加 L5 不破坏停止性；热预算与反作用预算可以合算。**

**定理 30（不可信云下的委派安全）** 设边缘见证验证器 sound（无假接受）、边缘回退控制器安全、LinkMet 契约有效、JDRC 有效。则对任意云行为（含拜占庭、断网、延迟、陈旧、版本降级），`Valid(J_SPLIT) ⇒ SafetyInv`，且安全界不依赖云的正确性/可用性/延迟；云只影响 CapRet。**证明**：对委派 DAG 归纳。云输出只能经 PROP 进入，PROP 只增 u、缩 D；ATTEST 以本地见证为地板；COMMIT 仅边缘可调用；任何未见证/过期/不兼容证据在 CEC 中落为 stub 或 EDGE_ONLY；J_SPLIT 的合取式不含 J_prop。由定理 31（J_SPLIT 有效性）与 R73 定理 28 得安全界。**证明重量落在「见证独立且 sound」与「回退安全」上。**

**定理 31（J_SPLIT 有效性 ⇒ 系统安全）** `Valid(J_SPLIT)` ⇒ (i) 边缘模块证书有效；(ii) MReg_edge 组合校验通过；(iii) LinkMet 有效且所有跨域证据已 COMMIT 或 stub；(iv) 所有关节 JDRC 有效且安全证明使用 a_real；(v) ΣREFLEX 含 L5 预算闭合。在 A114–A116（见证独立性、驱动契约表达力、链路校准）下，物理执行风险 ≤ ε_split（相对跨域证据模型与驱动实现模型）。**证明**：由定义 394 展开 + 定理 30 + 定理 32 + 引理 42。系：R73 的 J_MOD 是 J_SPLIT 在无云、无链路、理想驱动下的特例。

**定理 32（动作实现守恒 ⇒ 具身安全）** 若所有动作消费模块满足 AED 类型规则，且 JDRC 的 u_act 在有效域内是真实实现误差的上界，则使用 `a_real ∈ A_adm` 的安全证明对物理世界成立；反之，若以 u_cmd 替代 a_real 且 u_act > 0，则不成立（引理 41）。**证明**：由类型规则，风险泛函的输入是 a_real；u_act 上界吸收 R 的偏差；JDRC 有效域保证 A_adm 包住实际可达集。系：**「命令-实现间隙」必须在契约里被计量，而不是在控制器里被忽略。**

**定理 33（云边-驱动联合预算不变式）** 若 `Σ_i c_reflex^i + Σ_j c_reflex^{D,j} + Σ_k c_link^k ≤ B_total`，且每项有正下界、边际增益非增，则联合系统有限停止；若 COMMIT 守卫与 JDRC 热守卫成立，则热预算与证据预算在任意有限时程内不超支。**证明**：引理 38–42 的预算代数 + 归纳。系：**L4（视角）、L5（驱动）与链路延迟共享同一个可审计预算，而不是三套互不知情的限制。**

**定理 34（严格包含与退化）** 当 λ 全为 EDGE、LinkMet=id、u_act=0、无断链/无故障时，SPLIT-GAUGE 逐指令等于 MODGAUGE-RAS；当云不可用且 JDRC 平凡时，退化为 R73 的模块 stub 系统；再退化等于 R72/R71/R68。**证明**：由定义 383(vi)、394、定理 31 与引理 35（R73 热替换）逐项代入。系：**安全单调不减；SPLIT 只增加适用条件，不删除旧保证。**

**定理 35（证明局部性）** J_SPLIT 的边缘校验只依赖 `|V_edge|`、`|E_edge|`、`|J|` 与有界见证集 W，不依赖云模型规模、训练数据规模或机队规模；因此 `CertCost_split = O(|V_edge| + |E_edge| + |J|·|W|)`，机队扩展时边缘认证成本不变。**证明**：定义 394 的合取式不含 J_prop；CEC 的 COMMIT 守卫只查本地见证与 LinkMet。系：**C4 的「认证成本与云规模解耦」是可证伪的结构性质，不是工程口号。**

## 6. 本轮最大风险

**一句话**：SPLIT 的全部安全性押在「边缘见证与云端提议相互独立」上——如果二者共享同一个物理或数据共因（同一台相机、同一光源、同一套标定、同一负载-热场、同一训练数据），那么 ATTEST 只是云的回声而不是校验，系统会在「边缘已认证、证书齐全、预算闭合」的情况下，用云自己的影子证明云，给出一个**审计日志完美但物理上错误**的安全界。

次级风险与缓解：
1. **见证独立性不可证**：共同因无法从数据中完全排除 → 显式声明见证依赖图（CLG 的独立性子图）+ 至少一个异质物理模态（驱动/接触）+ E413 红队审计；无法证明独立时禁止 PAR 缩窄与域扩展。
2. **驱动契约表达力不足**（磨损/负载/温度分布外）→ 在线辨识 + 有效域硬边界 + u_act 上界回退 + E402/E404；超域即关节 stub/安全停。
3. **陈旧膨胀过保守**：CAP 保留率崩塌 → 分模态 TTL + 云主动推送校准摘要 + 边缘增量重校准；CapRet 与 SafetyInv 同时报告，不以能力换安全的口号掩盖可用性损失。
4. **版本/溯源工程复杂度**：签名、撤销、nonce、逻辑时钟引入新故障面 → 最小可信基（TCB）限定在边缘提交器；形式化状态机（CEC）+ 模型检查；云侧完全可替换。
5. **热/能量预算不可加**：多关节共母线/共驱动器 → 板级热耦合项 + 联合预算（定义 390/定理 33），拒绝按关节独立相加。
6. **云端投毒经 ATTEST 漏检**：长尾攻击只在部署后触发 → 密封保持集 + 影子模式 + 撤销传播 <100ms + 单源云证据不定案。
7. **论文主张被质疑为系统工程**：C4/C5 必须各自有隔离消融与预注册安全指标（E411/E412），且明确「不发明摩擦模型/网络控制/云机器人，创新在跨信任域计量契约与动作实现类型规则」。

## 2. 形式化定义（要点版）

**定义 383（SPLIT-GAUGE 总览与六不变式）** 提交权在边；跨域不免费融合；新鲜度单调；实现动作守恒；驱动反作用完备；退化安全单调。

**定义 384（DEC）** 在 EC 上加 locus / provenance / freshness / trust / semver / bandwidth / TTL / capability。类型系统禁止 `EDGE ⇄ CLOUD` 隐式转换。

**定义 385（CDA）** PROP 只增 u、缩 D；ATTEST 输出 `u'=max(u,u_att)`、`D'=D∩(D_edge∪D_wit)`；COMMIT 仅边缘；REVOKE 幂等。云没有 COMMIT 边。

**定义 386（LinkMet）** 链路是合法 EC：延迟/丢包/压缩/时钟/版本五分量 + 三类否决（未认证/版本不兼容/重放）；云边组合就是 CCA 的 SER，不需要特殊语义。

**定义 387（JDRC）** 关节声明可达动作集、实现映射、u_act 六分量、有效域、电-热模型、能量预算、故障模式、χ_D。

**定义 388（AED）** 驱动是双端口换能器；任何动作消费者只接受 `A_real`；`U_cmd→A_real` 的唯一合法通道是有效 JDRC。

**定义 389（u_act 六分量与驱动似然）** 力矩常数漂移 + 摩擦 + 齿隙/迟滞 + 热降额 + 编码器/电流量化 + 总线/控制延迟；条件近似正交，遗漏即系统性低估。证据端口 `e_drive=(τ_meas,q,i,T,V_bus)` 有 `p_drive(e_drive|x,a_real,load)=𝒩(h_drive,Σ_drive)`，Σ_drive 用同一六分量重标定为 u_drv；动作端口 u_act 与证据端口 u_drv 共享热/齿隙状态但独立校准。

**定义 390（DRX / L5）** 动作→热/磨损/齿隙→未来能力与证据质量；c_reflex^D 与热稳态集进入 ΣREFLEX；L5 与 L4 同构但不同：L4 是动作→视角→证据，L5 是动作→执行器状态→能力。

**定义 391（CEC）** 五状态提交协议；COMMIT 守卫 = 链路有效 ∧ 见证通过 ∧ u'≥u_att ∧ D' 有本地见证 ∧ 版本兼容；云状态机无 COMMIT。

**定义 392（陈旧膨胀）** `inflate(u,Δ)=u+L_uΔ`，`D(Δ)=D∩{漂移≤L_xΔ}`；Δ 用逻辑时钟；墙钟偏差超 δ 追加 u_clock；Δ>Δ_max 即 stub。

**定义 393（溯源与新鲜度）** 证书 = (π, sig, ν, ttl, nonce, claims)；撤销表 + nonce 缓存防重放；TTL 到期降级；版本不兼容/签名失败 = 否决。

**定义 394（J_SPLIT）** 边缘模块证书 ⊗ 组合校验 ⊗ 链路证书 ⊗ 委派证书 ⊗ 驱动证书；云 J_prop 仅作输入，不进入安全合取式。

**定义 395（能力-安全分解）** SafetyInv: P(unsafe)≤ε；CapRet = split 安全任务集 / edge-only 安全任务集；C4 要求拜占庭云下 SafetyInv 不变而 CapRet 随云质量变化。

**定义 396（CLG）** R73 ECG 的节点/边加 locus/provenance；跨域因果路径必须含 ATTEST 边；因果边残差超 conformal 界 ⇒ 否决。

**定义 397（AIC-CLOUD）** 陈旧重放 / 模型投毒 / 版本降级 / 时钟偏斜 / 链路 DoS / 证据篡改 / split-brain / 隐私侧信道；防线：溯源 + nonce + TTL + 逻辑时钟 + 边缘否决 + 压缩预算。

**定义 398（AIC-DRIVE）** 力矩/编码器欺骗 / 温度欺骗 / 齿隙注入 / 总线延迟 / 旧证书重放 / 云端恶意前馈；防线：动作-证据残差 + 独立热模型 + 编码器-力矩一致性 + JDRC 有效域 + 安全停/抱闸。

**定义 399（退化链）** 云断→EDGE_ONLY；链路异常→LinkMet stub；版本不兼容→REVOKE；JDRC 失效→关节 stub + 安全停；u_act 超阈→动作钳位；DPEM/DMEM/IRL 失效→R73 模块 stub。安全侧只增不减。

**定义 400（MBench-S）** MB4 云边分体（延迟/丢包/版本/时钟/拜占庭云 × 3 任务）；MB5 驱动实现（饱和/齿隙/摩擦/热降额 × 3 装配任务）；预注册 + 固定种子 + SEAL-MB-S。

**定义 401（CPB†）** C4 ← (DEC,CDA,LinkMet,CEC,J_SPLIT) ← MB4 ← AB4 ←（拜占庭云安全违例、CapRet、边缘 WCET、陈旧容忍、版本错配检出）；C5 ← (JDRC,AED,DRX) ← MB5 ← AB5 ←（力超调、饱和碰撞、热违例、抓取成功率、停止方差）。

**定义 402（证明局部性）** `CertCost_split = O(|V_edge|+|E_edge|+|J|·|W|)`，与云模型规模、训练数据、机队规模无关；机队 1→100 台边缘 CertCost 不变。

# IP-303 SPLIT-GAUGE：位置化证据
@dataclass(frozen=True)
class DelegatedContract(EvidenceContract):
    locus: str                       # EDGE / CLOUD
    provenance: Provenance           # 哈希链 + 签名
    freshness: Freshness             # lc/t_wall/delta_max
    trust: TrustLevel                # revoked<declared<attested<verified
    semver: SemVer
    bandwidth: BandwidthBudget
    ttl_s: float
    capability: FrozenSet[str]       # 能力扩展声明，不是安全承诺

# IP-304 CDA：PROP / ATTEST / COMMIT / REVOKE
def prop(cloud_ev, edge, now):
    if not verify(cloud_ev.provenance) or not compatible(cloud_ev.semver, edge.semver):
        return stub(cloud_ev)
    d = logical_delta(now, cloud_ev.freshness)
    if d > cloud_ev.freshness.delta_max:
        return stub(cloud_ev)
    return replace(cloud_ev,
                   u=inflate(cloud_ev.u, d, cloud_ev.freshness.L_u),
                   D=shrink(cloud_ev.D, d, cloud_ev.freshness.L_x),
                   trust='declared')

def attest(ev, witness_set, alpha):
    p = conformal_pvalue(witness_set.residual(ev))
    if p <= alpha:
        return veto(ev, reason='ATTEST_FAIL'), revoke(ev.provenance)
    return replace(ev,
                   u=max(ev.u, witness_set.uncertainty_floor(ev)),
                   D=ev.D & (ev.D_local | witness_set.supported_domain(ev)),
                   trust='attested'), None

def commit_edge(ev, edge, mreg, now):
    if not (ev.trust == 'attested' and edge.link.valid(now)
            and ev.u >= edge.attestation_floor(ev)
            and ev.D <= (edge.local_domain(ev) | edge.witness_domain(ev))):
        return False
    mreg.add(sign(edge.key, ev)); return True            # 云无此路径

# IP-305 LinkMet：网络作为计量模块
def link_step(ev, link_state, now):
    u_lat = link_state.L_ev * max(0, now - link_state.tx_time)
    u_loss = link_state.loss_uncertainty()
    u_quant = link_state.compression_error(ev, link_state.bandwidth)
    u_clock = link_state.clock_skew_uncertainty()
    u_skew = link_state.model_skew_uncertainty(ev.semver, link_state.semver)
    u = math.sqrt(u_lat**2 + u_loss**2 + u_quant**2 + u_clock**2 + u_skew**2)
    return replace(ev, u=u, D=ev.D & link_state.valid_domain(),
                   veto=ev.veto | link_state.vetoes())   # O(1)/包

# IP-306 JDRC + AED：驱动实现与动作-证据对偶
class JointDriveContract:
    def admissible(self, x):          # A_adm(x)
        T, w, E = x.temp, x.omega, x.energy_remaining
        return (abs(x.tau) <= self.tau_max(T) and abs(w) <= self.omega_max(T)
                and x.power <= self.p_max and E >= 0)
    def realize(self, u_cmd, x):      # U_cmd -> A_real
        a = self.plant.map(u_cmd, x)  # 含摩擦/齿隙/饱和/热
        return RealizedAction(a=a, u_act=self.u_act_six(x, u_cmd),
                              domain=self.domain(x) & inside(a, self.A_adm(x)))
    def u_act_six(self, x, u_cmd):
        return math.sqrt(self.u_TC(x)**2 + self.u_fric(x, u_cmd)**2
                         + self.u_back(x, u_cmd)**2 + self.u_th(x)**2
                         + self.u_quant(x)**2 + self.u_delay(x)**2)

# IP-307 DRX：第五反作用层 L5
def drive_reflex_step(drives, u_cmd, state, budget):
    total, states2 = 0.0, {}
    for j, d in drives.items():
        dT, dWear, dBack, du = d.ec.chi_D(u_cmd, state[j])
        c = d.ec.w_T*dT + d.ec.w_E*d.energy(dT) + d.ec.w_u*du
        if d.ec.temp_next(state[j], dT) > d.ec.T_max - d.ec.margin:
            return None, total                       # 热稳态越界 → 拒绝
        states2[j], total = d.step(state[j], dT, u_cmd), total + c
    if budget.spent + total > budget.B:
        return None, total
    return states2, total

# IP-308 CEC + J_SPLIT：边缘提交与分体证书
def cec_round(edge, cloud, mreg, now):
    if not edge.link.valid(now):
        return edge_only(edge, mreg, now)            # LinkMet stub，安全不降
    prop_ev = prop(cloud.latest, edge, now)
    if prop_ev.is_stub:
        return edge_only(edge, mreg, now)
    att_ev, veto = attest(prop_ev, edge.local_witness(now), edge.alpha)
    if veto:
        edge.revoke(prop_ev.provenance); return edge_only(edge, mreg, now)
    if commit_edge(att_ev, edge, mreg, now):
        return replace(edge.snapshot, cloud_ev=att_ev)
    return edge_only(edge, mreg, now)

# IP-309 CLG：因果-位置图审计
def clg_audit(clg, residuals, alpha):
    for path in clg.cross_locus_paths():
        if not any(e.kind == 'ATTEST' for e in path):
            return False                       # 跨域因果路径缺见证
        if any(r > clg.conformal_bound(e, alpha)
               for e, r in zip(path, residuals)):
            return False                       # 因果边断裂 → 否决
    return True

# IP-310 主闭环（边缘实时；云异步，永不在关键路径）
def SPLIT_GAUGE_round(M, obs, audio, tac_frame, depth_img, cloud):
    # 感知域（100Hz）
    d_ev = M.dpe.update(depth_img, obs.rgb, M.cam, M.motion, M.peers)
    t_ev = M.dmem.update(tac_frame, M.last_action)
    e_drv = M.drivem.update(M.joint_sensors, M.last_u_cmd)
    # 云提议异步到达：只做 PROP，不阻塞控制
    if cloud.available and M.clock.due_cloud():
        M.cloud_ev = prop(cloud.latest, M.edge, M.clock.now)
    # 计量域（50Hz）
    if M.clock.due_metric():
        if M.cloud_ev and M.cloud_ev.trust == 'declared':
            M.cloud_ev, _ = attest(M.cloud_ev,
                                   M.edge.witness(t_ev, e_drv, d_ev), M.alpha)
        b_t = M.bse.step_full(..., d_ev=d_ev, t_ev=t_ev, e_drv=e_drv)
        z_dist, _, _ = M.irl.update(M.y_intent_buf, M.psi, b_t)
        g_cmd = M.ervoi.choose(b_t, M.psi, z_dist, t_ev.c_dist,
                               M.budget, M.fmp, M.bse)
        # JDRC：命令 → 实现动作；所有后续用 a_real
        a_real = M.drive.realize(g_cmd, M.drive_state)
        if not a_real.domain.ok: a_real = M.drive.safe_stop()
        s2, _ = sigmareflex_step(M.mods, a_real, M.state, M.budget)
        sD, _ = drive_reflex_step(M.drives, g_cmd, M.drive_state, M.budget)
        if s2 is not None and sD is not None:
            M.last_u_cmd, M.state, M.drive_state = g_cmd, s2, sD
        M.snapshot.write(b_t, z_dist, d_ev, t_ev, e_drv, M.state, M.drive_state)
        M.mreg.audit(); M.clg.audit()      # 组合 + 因果-位置审计
    # 控制域（1kHz，只读快照，零分配）
    snap = M.snapshot.read_latest()
    lam = embodied_risk_scale(snap.U_ale, snap.U_epi, snap.H_z,
                              max(snap.t_ev.u, snap.d_ev.u, snap.a_real.u_act),
                              M.risk_params)
    k = M.c_ras_wm.certified_prefix(M.ach.propose_ctrl(..., pvop_bias=snap.pvop), lam)
    M.ctrl_out.publish(k, lam)
    return k, lam, J_SPLIT(M.mreg, M.edge)

## 4. 推导

**引理 38（陈旧膨胀单调）** 漂移满足 `‖x(t+Δ)−x(t)‖≤L_xΔ` 且 u 对状态 Lipschitz ⇒ `inflate(u,Δ)=u+L_uΔ` 关于 Δ 单调不减；D(Δ) 单调收缩；Δ>Δ_max 退化为 stub。系：**TTL 是安全参数，不是工程参数。**

**引理 39（委派不降低证据质量）** 任意 PROP/ATTEST/REVOKE 序列满足 `u_out≥u_in`、`D_out⊆D_in∪D_wit`；ATTEST 的 u 不低于本地见证地板 u_att。云声称更准不是降低 u 的合法理由。系：**云只能扩大能力域，不能缩小安全不确定度。**

**引理 40（链路是合法 EC）** LinkMet 满足定义 367 全部字段；五分量条件独立、D_link 显式；串联 LinkMet 后 CCA 单调性（引理 34）仍成立。系：**云边协同不需要新的组合语义，只需要把链路当模块。**

**引理 41（实现间隙反例）** 存在齿隙死区 + 摩擦 + 热降额同时发生的状态，使 `|a_real−u_cmd|>0` 且不被任何仅依赖 u_cmd 的界覆盖。若安全证明使用 u_cmd 而实际执行 a_real，则存在状态使物理风险超过证明界。系：**命令级安全界不是保守，而是类型错误。**

**引理 42（DRX 有限停止与热安全）** 非平凡动作的 c_reflex^D 有正下界 ε_D、边际任务增益非增 ⇒ 含 L5 的 ΣREFLEX 存在有限停止 n*；热模型满足耗散不等式且守卫按 T_max−margin 拒绝 ⇒ 热安全不变式成立。

**定理 30（不可信云下的委派安全）** 若边缘见证 sound（无假接受）、回退安全、LinkMet 有效、JDRC 有效，则对任意云行为（拜占庭/断网/延迟/陈旧/降级），`Valid(J_SPLIT) ⇒ SafetyInv`，安全界不依赖云的正确性/可用性/延迟；云只影响 CapRet。**证明**：对委派 DAG 归纳；云输出只能经 PROP（只增 u、缩 D），ATTEST 以本地见证为地板，COMMIT 仅边缘，J_SPLIT 不含 J_prop；由定理 31 + R73 定理 28 得界。证明重量在**见证独立性与回退安全**。

**定理 31（J_SPLIT 有效性 ⇒ 系统安全）** `Valid(J_SPLIT)` ⇒ 边缘模块证书有效 ∧ MReg_edge 组合校验通过 ∧ 跨域证据已 COMMIT 或 stub ∧ 关节 JDRC 有效且安全证明用 a_real ∧ ΣREFLEX（含 L5）预算闭合。在 A114–A116（见证独立性、驱动契约表达力、链路校准）下，物理执行风险 ≤ ε_split。系：J_MOD 是 J_SPLIT 在无云、无链路、理想驱动下的特例。

**定理 32（动作实现守恒）** 若所有动作消费模块满足 AED 类型规则且 JDRC 的 u_act 在有效域内是真实实现误差上界，则使用 `a_real∈A_adm` 的安全证明对物理世界成立；若以 u_cmd 替代且 u_act>0，则不成立（引理 41）。系：**命令-实现间隙必须在契约里被计量，而不是在控制器里被忽略。**

**定理 33（云边-驱动联合预算）** 若 `Σ_i c_reflex^i + Σ_j c_reflex^{D,j} + Σ_k c_link^k ≤ B_total` 且每项正下界、边际增益非增，则联合系统有限停止；COMMIT 守卫与 JDRC 热守卫成立 ⇒ 任意有限时程内热预算与证据预算不超支。系：**L4/L5/链路共享一个可审计预算，而不是三套互不知情的限制。**

**定理 34（严格包含与退化）** λ 全 EDGE、LinkMet=id、u_act=0、无故障 ⇒ SPLIT 逐指令等于 MODGAUGE；云不可用且 JDRC 平凡 ⇒ R73 模块 stub 系统；再退化 ⇒ R72/R71/R68。系：**安全单调不减；SPLIT 只增加适用条件，不删除旧保证。**

**定理 35（证明局部性）** J_SPLIT 边缘校验只依赖 `|V_edge|、|E_edge|、|J|、|W|`，不依赖云模型规模/训练数据/机队规模；`CertCost_split=O(|V_edge|+|E_edge|+|J|·|W|)`，机队 1→100 台边缘认证成本不变。系：**C4 的「认证成本与云规模解耦」是结构性质，不是口号。**

## 7. 本轮最大风险

**一句话**：SPLIT 的安全性押在「边缘见证与云端提议相互独立」上——如果二者共享同一物理/数据共因（同一相机、光源、标定、负载-热场、训练数据），ATTEST 只是云的回声而非校验，系统会在「边缘已认证、证书齐全、预算闭合」时，用云自己的影子证明云，给出**审计日志完美但物理上错误**的安全界。

次级风险与缓解：
1. **见证独立性不可证** → CLG 显式依赖图 + 至少一个异质物理模态（驱动/接触）+ E413 红队审计；无法证明独立时禁止 PAR 缩窄与域扩展。
2. **驱动契约表达力不足**（磨损/负载/温度分布外）→ 在线辨识 + 有效域硬边界 + u_act 上界回退 + E402/E404；超域即关节 stub/安全停。
3. **陈旧膨胀过保守**（CapRet 崩塌）→ 分模态 TTL + 云推送校准摘要 + 边缘增量重校准；CapRet 与 SafetyInv 同时报告。
4. **版本/溯源工程复杂度** → 最小可信基限定在边缘提交器；CEC 形式化状态机 + 模型检查；云侧完全可替换。
5. **热/能量预算不可加**（共母线/共驱动器）→ 板级热耦合项 + 联合预算（定义 390/定理 33），拒绝按关节独立相加。
6. **云端投毒经 ATTEST 漏检**（长尾攻击部署后触发）→ 密封保持集 + 影子模式 + 撤销传播 <100ms + 单源云证据不定案。
7. **被质疑为系统工程** → C4/C5 各自隔离消融与预注册安全指标（E411/E412）；明确不发明摩擦模型/网络控制/云机器人，创新在**跨信任域计量契约**与**动作实现类型规则**。
