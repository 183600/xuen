## 1. 两个灵感的第一性原理

### 灵感 1 ·「论文发表」→ 把工程栈拆成「可迁移 / 可证伪 / 可复现」三层主张

第一性原理：论文不是「把做过的事写下来」，而是**提炼出一个在本榜单之外仍然为真的知识单元**。榜单是固定的 32 项任务，论文必须回答「离开这 32 项，我们学到了什么」。据此把 SAGE 的主张分三层：

- **可迁移主张（thesis）**：操作域 VLA 缺少显式感知状态层；SLAM 的「估计-地图-重定位」三件套可迁移，且在**低数据**时比扩大策略容量更高效。这是 IP-13 的论文骨架，也是第 3 轮所有工程动作的共同底座。
- **可证伪预测（prediction）**：由 thesis 推出的、可用隐藏榜单一次性检验的「方向 + 阈值 + 口径」（U20）。例：等底座下，SAGE 在位置/干扰物/人为干扰三轴相对 baseline 增益 Δ>0，且 2× 参数 scale-only 基线追不平；步骤开销 ≤1.1×。**必须在榜单开放前落盘**（P15），否则就变成「看榜后编故事」。
- **可复现产物（artifact）**：IP-06 代理评测 + 消融矩阵 + 协议桩，独立可复跑。基准/评测贡献常与方法贡献同等可引用——在「情报真空期」里，**谁能定义可复现的评测，谁就先握住叙事权**。

关键纪律：**主张-分数同构（P13）**——论文里每条主张都要能在代理评测上操作化、在隐藏榜单上验证；不能操作化的「叙事性洞见」降级为工程笔记、不进主表。这条纪律同时是反 Goodhart 装置：故事优化方向被强制对齐到与分数同一的可测口径。

### 灵感 2 ·「轻量化结构」→ 轻量不是省钱，而是让「结构优于缩放」这句话变得可检验

第一性原理：单说「我加了状态层、分数涨了」无法区分是**结构**的功劳还是**容量**的功劳（混淆变量）。轻量化给的不是省算力，而是**科学控制**：固定总预算，比较「把钱花在结构上」vs「把钱花在缩放上」（P14 / U19）。只有等预算对照下结构仍胜，thesis 才成立。三个落点：

- **结构 vs 缩放的效率前沿（IP-16 / L15）**：结构零预算边际收益高但饱和快（r0 小），策略缩放边际收益低但天花板高（c0 大）。当前 32 任务、挑战语料冻结 ⇒ 有效预算 B 小 ⇒ 位于交叉预算 B* 左侧 ⇒ **现在该投结构、不该投缩放**。这给第 3 轮「IP-13 优先于 IP-01 放大」补上了定量依据，而不是仅凭直觉。
- **把最重的 IP 变轻（IP-01 → IP-01-Lite）**：第 1–2 轮的 IP-01 是全专家 MoE（8×A100），既是最高成本又是最难复现。改写为**技能条件 LoRA-MoE**（skill-token 门控的轻量 LoRA 专家），与等参 dense 基线对照——既降本、又天然满足「单 checkpoint + 自部署软件」的合规约束，还把一个「烧钱项」变成论文里可写的「轻量化结构」贡献。
- **轻量状态层（IP-13 深化 / L16）**：检测器选型不看「参数少」，而看**延迟-精度 Pareto 前沿 + 过 E628 校准门槛**；低频调度把有效附加延迟压到 τ_d/N ≤ β·τ_step。这样「零新大模型」从口号变成可验收的资源条款（E636 / E633）。

**综合**：论文发表给了「要证明什么」，轻量化结构给了「怎么证明才不算作弊」。两者合并成一句可预注册的主预测：**在等底座、等预算、等步骤开销下，显式状态层带来的泛化增益在低数据区严格高于策略缩放带来的增益，且该优势随数据预算增长而收敛。**

## 2. 研究问题（新增 Q13–Q15，接第 1–3 轮 Q1–Q12）

- **Q13（预注册-审计）**：SAGE 的核心主张能否写成预注册的可证伪预测（方向 + 阈值 + 代理口径 + 时间戳），并在榜单开放后一次审计通过/否决，且预测误差不被「分叉花园」放大（L14）？（E635）
- **Q14（结构 vs 缩放）**：算力对齐预算下，五个泛化轴上结构的边际收益是否高于策略缩放？交叉预算 B* 估计在哪，当前 32 任务位于哪一侧？（E634）
- **Q15（轻量状态层）**：满足 E628 校准门槛的最小检测/跟踪器在延迟-精度 Pareto 前沿上的位置？轻量化后断言精度下降多少、P99 延迟是否在 U12 预算内？（E636）

## 3. 设计原则（新增 P13–P15，接第 1–3 轮 P1–P12）

- **P13（主张-分数同构）**：进论文主表的每条科研主张必须绑定代理评测上的可操作化与隐藏榜单上的可验证口径；无操作化者降级为工程笔记，不进主表。
- **P14（算力对齐对照）**：任何「结构 X 有效」的结论必须在等参/等 FLOP 的 scale-only 基线上比较；否则记为容量混淆，不得声称。
- **P15（先预注册后开榜）**：主主张、预测方向、阈值、探索配置数 M 必须在榜单开放前写入 ClaimLedger 并留可验证时间戳；开榜后只审计、不改主张。

## 5. 本轮最大风险

**一句话：算力对齐对照可能揭穿结构增益实为容量混淆——若在等预算下结构点不优于 scale-only，论文主论点「结构优于缩放」将被自家基准推翻。** 对冲：①先在小规模（单任务族）把 E634 跑通再写主表主张；②把 B* 作为带置信区间的估计而非单点结论（L15）；③若结构不占优，主张退化为「结构在低数据区等效但更省算力」——仍是可发表结论，但标题与贡献排序须改。次要风险：Dex1 语料更新使「语料冻结」前提失效 → B* 估计的「有效预算」须随语料规模滚动重估；预注册被质疑「看过榜单边缘信息」→ 用可验证时间戳 + 代理-榜单盲映射规避。

## 6. 下一轮迭代计划（深化与修剪，不推倒重来）

- **深化**：IP-16 的 B* 估计方法（饱和曲线拟合 + bootstrap CI）；IP-01-Lite 的 LoRA 专家门控与等参 dense 对照协议；IP-17 的主张条目模板与代理-榜单盲映射表。
- **修剪预案**：E634 显示结构点等效果但显著更省算力 → 论文从「结构优于缩放」改题为「等效果下的轻量化结构」；E636 显示轻量化后校准跌破 E628 → 状态层退化为 Level-1.6 固定阈值、IP-13 只保留重定位触发器；Dex1 增量经复核规模可观 → 重估 B* 并重排 IP-12/14 数据线优先级。

## 5. 符号与定义（新增 U19–U21；U1–U18 沿用第 1–3 轮）

- **定义 U19（预算向量与算力对齐）**：预算向量 `B = (N_params, F_infer, D_data, T_wall)`，按约定单位归一化为标量 `‖B‖`。结构栈 `S = π_base ⊕ M`（M 为 IP-13/14/15 等结构模块）与 scale-only 基线 `S_scale = π_big` 称**算力对齐（compute-matched）** ⇔ `‖B(S)‖ = ‖B(S_scale)‖`；否则对照无效，结论记为容量混淆。
- **定义 U20（可预注册主张）**：一条主张 `c = (X, dir, δ, O, H, t_pre, M)`：X=可测对象，dir∈{>,<,=} 与阈值 δ=方向判据，O=代理评测口径，H=隐藏榜单口径，t_pre=锁盘时间戳（必须早于榜单开放 t_open），M=探索配置数（供 L14 折扣）。`c` **可预注册** ⇔ O→H 的映射在 t_pre 前固定且 X 在 O 上可操作化。
- **定义 U21（效率前沿与 EAES）**：在预算 B 上，泛化增益 `G(B) = max_{分配} GenGain`；配置点集 `{(G, B)}` 的 Pareto 前沿称**效率前沿**。**效率校正效应量** `EAES = ΔGen / Δ‖B‖`（每单位额外预算换来的泛化增益），作为论文主图纵轴与 IP-16 的决策量。

# ===== IP-13 深化: 检测器延迟-精度 Pareto 选择（L16）=====
def select_detector(cands, delta_max, beta, tau_step):
    feas   = [d for d in cands if d.cal_error <= delta_max]        # 过 E628 校准门
    pareto = [d for d in feas if not any(dominates(e, d) for e in feas)]
    # 有效附加延迟 = tau_d / N，要求 N >= tau_d / (beta * tau_step)
    return min(pareto, key=lambda d: (d.latency, d.params))

## 7. 推导（新增引理 L14–L16；L1–L13 沿用第 1–3 轮）

**引理 L14（预注册消除选择偏差）** 设 M 个候选配置真实效应同为 Δ，观测效应 `Δ+ε_i`，`ε_i iid N(0,σ²)`。事后择优报告 `E[max_i(Δ+ε_i)] − Δ = σ·E[max_i z_i]`，大 M 时 `E[max_i z_i] ≈ √(2 ln M)`，即虚高随探索配置数 M 以 `√(2 ln M)` 增长。若在 t_pre 预注册**单一**配置并用留出集估计，则偏差为 0（或单次噪声 O(σ)），**与 M 无关**。⇒ 探索越多，预注册的证据价值越大；论文必须同时报告 M 与预注册预测，否则审稿人无法区分真实效应与「分叉花园」虚高。∎

**引理 L15（结构 vs 缩放的效率前沿交叉）** 设泛化增益对预算的分配为结构 r 与策略容量 c（`c+r=B`），二者均饱和：`G = a(1−e^{−c/c0}) + b(1−e^{−r/r0})`。则：
(i) 近零预算边际收益为 `b/r0` 与 `a/c0`，**结构占优 ⇔ b/r0 > a/c0**（结构零预算边际更高）；
(ii) `B→∞` 由渐近上限决定，**缩放占优 ⇔ a > b**；
(iii) 若 `b/r0 > a/c0`、`a > b` 且结构饱和更快（`r0 < c0`），令 `f(B)=b(1−e^{−B/r0})−a(1−e^{−B/c0})`，则 `f(0)=0`、`f'(0)>0`、`f(∞)=b−a<0`；又 `f'(B)=0` 至多一解（因 `(b/r0)/(a/c0)=e^{B(1/r0−1/c0)}` 右端对 B 严格单调），故存在**唯一交叉预算 B***：`B<B*` 结构占优、`B>B*` 缩放占优。
⇒ 当前 32 任务、挑战语料冻结 ⇒ 有效预算 B 小 ⇒ 位于 B* 左侧 ⇒ 应优先投结构（IP-13/14/15）而非放大 IP-01。论文应报告 **B*** 与其 CI，而非只报单点增益；Dex1 若扩充（F4）使有效 B 右移时，须重判所处区间。∎

**引理 L16（轻量状态层的延迟-精度 Pareto 门槛）** 设单次检测延迟 τ_d、基线每步预算 τ_step、状态层更新周期 N、允许附加延迟占比 β。则有效附加延迟 `= τ_d/N ≤ β·τ_step ⇔ N ≥ τ_d/(β·τ_step)`。在满足 E628 校准门 `{δ_cal ≤ δ_max}` 的检测器集合 D 中，应选 Pareto 最小元（同时最小化 τ_d 与参数量）；任何更大检测器只有在贡献**可测**校准/精度增益时才允许替换。⇒ 轻量化的判据不是「参数少」，而是「在延迟-精度 Pareto 前沿上且过 E628 门」；低于该门的检测器不得因「更小」入选，高于该门的必须给出增益证据。∎
