# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC IP-153~160；灵感循环第 7 轮；本轮灵感：「闭环控制」×「模型量化」）

> 第 60 轮把「执行层→证据层」升级为「认知驱动的场景-执行闭环」：SSM 场景语义建模、CIEC 认知意图约束、EPIR 执行感知隔离区、SERC 场景感知闭环、PCE++++ 认知预算。但**三个核心局限**尚未根本解决：
> 1. **「闭环」只是流程闭环，不是控制闭环**：SERC 的①~⑪ 只是数据流的有向图，缺少**收缩性/稳定性**的严格判据。当意图延迟 τ_response、场景误判、ROS 抖动叠加时，系统可能进入**振荡或发散**，第 60 轮只能用「置信度 < 0.7 回退」这种事后护栏。
> 2. **认知模型无法在边端实时运行**：SSM 的 Kalman 场景识别、CIEC 的意图推断在边缘算力下延迟过高，必须**模型量化**（int8/int4、混合精度）；但量化误差是**未建模扰动**，会沿「场景→阻抗→接触力→证据→场景」的回路被放大。
> 3. **量化误差没有进入证据链**：EV-exec 只记录执行数值，不记录「该数值由哪个比特宽度/量化方案产生」；复现失败时无法区分是场景误判还是量化误差，证据链的**可审计性**被削弱。

## 0. 直觉与动机

**灵感 1（闭环控制 → 把 SGEC 当作受扰动的离散动力系统 QACL）**
直觉：第 60 轮的闭环是「流程图」，真正的闭环控制要回答「扰动会不会被放大」。把场景信念 b_t、阻抗 K_t、接触力 f_t、证据状态 s_t 组成状态 x_t，量化模型输出 u_t = Q_b(π_θ(x_t))，则量化误差 e_q = Q_b(π_θ) − π_θ 就是**有界扰动**。只要名义闭环是**收缩的**（谱半径 ρ < 1），量化误差只会线性叠加进稳态误差，而不会指数放大——这就是 ISS（输入-状态稳定）。关键洞见：**比特宽度可以换算成稳定性裕度**：Δ(b) = R/2^b，要求 Δ ≤ (1−ρ)·ε_target/‖B‖。

**灵感 2（模型量化 → 灵敏度感知的量化误差预算 QEB）**
直觉：不是所有模块都该用同一比特。场景分类器输出离散后验，误判代价极高（湿滑→桌面），应多给比特；低频的意图先验可以少给。把总闭环误差分解为 E_cl ≤ Σ_i L_i·R_i/2^{b_i}（L_i 为模块 Lipschitz 敏感度），「给谁多比特」就变成**带约束的比特分配问题**：min Σ b_i s.t. Σ L_i R_i 2^{−b_i} ≤ ε_cl。关键洞见：**量化预算应按敏感度 L_i 分配，而不是均匀 int8**。

**灵感 3（闭环控制 × 模型量化 → 双速率自适应量化 AQC）**
直觉：比特宽度本身可以作为**控制变量**。快环（控制频率 ~1kHz）用固定比特保证确定性；慢环（~100ms）根据稳定性裕度和误差估计调整比特。慢环必须**迟滞**（bit-width hysteresis），否则会形成「比特抖动→误差抖动→再调比特」的极限环。关键洞见：**量化器也在闭环里**——它的更新速率必须远慢于被控对象，否则会引入新的不稳定模态（类似采样控制中的 Zeno 现象）。

**灵感 4（三灵感合流 → 闭环-量化协同 CLQC）**
直觉：QACL 给稳定性判据 → QEB 给比特下界 → AQC 在线调比特 → CLSM 监控收缩性 → 若违反则回退全精度保守阻抗。形成**双层闭环**：外层是「场景-意图-阻抗」的认知闭环，内层是「比特宽度-量化误差-稳定性裕度」的量化闭环。关键洞见：**安全的关键不是「认知先行」，而是「认知-量化-执行三者同时满足收缩性」**。

**灵感 5（PCE+++++ → 五维预算含量化预算）**
直觉：第 60 轮的四预算要加入 B_quant = (bit_budget, adaptation_period, dequant_overhead, switch_cost)。若 B_quant 耗尽 ⇒ 固定最低比特 + 全精度安全回退；若稳定性裕度不足 ⇒ 从低敏感模块「借比特」给高敏感模块。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（量化感知闭环 QACL）** 受扰动离散闭环系统
```
x_{t+1} = A x_t + B u_t + w_t,   u_t = Q_b(π_θ(x_t)) = π_θ(x_t) + e_q(t)
```
其中 x_t ∈ R^n 为「场景信念-阻抗-接触力-证据」联合状态，u_t 为阻抗指令，w_t 为环境/ROS 扰动，Q_b 为 b 比特对称均匀量化器，|e_q(t)| ≤ Δ(b) = R/2^b。QACL = (A, B, π_θ, Q_b, ρ, ε_cl)，其中名义闭环满足 **ρ-收缩**：‖(A+BK)‖₂ ≤ ρ < 1。
**ISS 界**：若 ‖w_t‖ ≤ w̄，则
```
‖x_t‖ ≤ ρ^t‖x_0‖ + (‖B‖·Δ(b) + w̄)/(1−ρ)
```
即量化误差以 1/(1−ρ) 的增益进入稳态误差，而不会指数放大。**稳定性-比特约束**：要使稳态误差 ≤ ε_target，需
```
Δ(b) ≤ (1−ρ)·ε_target/‖B‖  ⇔  b ≥ log2( ‖B‖·R / ((1−ρ)ε_target) )
```

**定义 162（量化误差预算 QEB）** 模块集 M = {scene, intent, policy}，各模块敏感度 L_i（输出对闭环误差的 Lipschitz 上界）、动态范围 R_i、比特 b_i ∈ [b_min, b_max]。
```
E_cl(b) = Σ_i L_i·R_i·2^{−b_i},      B(ε_cl) = { b | E_cl(b) ≤ ε_cl }
b* = argmin_{b∈B(ε_cl)} Σ_i b_i
```
拉格朗日乘子 λ 给出闭式解 **b_i* = log₂(λ·L_i·R_i·ln2)**：比特随「敏感度×动态范围」单调增加，再按整数向上取整。整数化后用贪心边际增益（每次给边际误差下降最大的模块加 1 bit）作 ε-最优近似。

**定义 163（闭环稳定性监控 CLSM）** 由 DARE 求 Lyapunov 矩阵 P：(A+BK)ᵀP(A+BK) − P = −Q。收缩证书：
```
V(x) = xᵀPx
V(x_{t+1}) ≤ (1−α)V(x_t) + β(‖e_q‖² + ‖w‖²)
```
定义违规计数 c_t：条件不成立则 c_{t+1}=c_t+1，否则清零；当 c_t ≥ c_max（连续 W 步违规）⇒ 发出 `STABILITY_ALERT`，触发回退。稳定性裕度 margin = (1−α) − V(x_{t+1})/V(x_t)。

**定义 164（自适应量化控制器 AQC）** 双速率：控制周期 T_c，量化适配周期 T_q = m·T_c（m ≫ 1）。适配律
```
b_i(t+1) = clip( b_i(t) + η·g_i(margin, E_cl), b_min, b_max )
```
其中 g_i 为「裕度不足则加比特、裕度充足且误差小则减比特」的方向项。**迟滞** h：仅当估计误差跨过阈值带 [ε_lo, ε_hi] 才允许切换；**无 Zeno 条件**：T_q ≥ τ_dwell（最短驻留时间），保证比特序列有限次切换。

**定义 165（SICQ 场景-阻抗-置信-量化四元组）** 在 SIC 三元组上增加量化确定性：
```
SICQ = (scene_conf(z), K_certainty(K|z), q_certainty(K|b), execution_feasibility(K|z))
q_certainty(K|b) = P(|e_q| ≤ margin(K)) ≈ 1 − Δ(b)/margin(K)
SICQ_valid = scene_conf ≥ τ_scene ∧ K_certainty ≥ τ_K ∧ q_certainty ≥ τ_q ∧ feasibility = true
```
安全裕度 margin(K) 为阻抗参数到最近安全边界的距离；量化误差一旦接近该边界，q_certainty 下降，强制加比特或回退。

**定义 166（QEPIR 量化证据链）** 量化证据消息
```
EV-exec^q = (content, q_meta, timestamp, seq_id, hash)
q_meta = (bit_widths, scales, zero_points, scheme, err_bound)
hash = H(content ‖ q_meta)
```
**可审计性**：hash 同时覆盖数值与量化元数据，任何「用不同比特复现同一证据」的尝试都会 hash 失配；若 q_meta 缺失或 hash 失配 ⇒ 标记 `EVIDENCE_DEGRADED`，云端不得据此更新场景信念。

**定义 167（PCE+++++ 五维预算）** B = (B_scene, B_intent, B_ros, B_quant, B_exec)，新增
```
B_quant = (bit_budget, adaptation_period, dequant_overhead, switch_cost)
cost_quant(π) = λ_bit·Σ_i b_i + λ_switch·N_switch + λ_deq·Latency_deq
voi₅(π) = voi_cog(π) − cost_quant(π)
```
若 B_quant < θ_quant：冻结比特为 b_min 并启用全精度安全回退；若 margin 不足：从低敏感模块回收比特补给高敏感模块（预算内重分配）。

**定义 168（闭环-量化协同算子 CLQC）** 算子 CLQC(M, δ_f_req, intent)：
```
① 慢环：bits ← AQC.current_bits();  bits ← QEB.allocate(ε_cl, margin)
② SSM:  z_scene ← R_scene.update(obs; bits['scene'])
③ CCM:  K_safe^scene ← EEIS.compile_with_scene_prior(π_scene, δ_f_req, bits['policy'])
④ CIEC: C_intent ← ϕ(intent; bits['intent']);  ERTC.lock(C_intent)
⑤ 快环：EV-exec ← closed_loop_exec_probe(K_safe^scene; bits)   # 比特固定，确定性
⑥ QEPIR: EV-exec^q ← S_shadow.append(EV-exec, bits, q_meta); S_sync.push()
⑦ CLSM:  status ← stability_monitor.step(x_t, x_{t+1}, e_q, w)
⑧ if status = STABILITY_ALERT: return rollback_full_precision(M)
⑨ 慢环：AQC.update(margin, E_cl(bits));  XMC++ 融合 EV-exec^q
⑩ Return (z_scene, K_safe, EV-exec^q, SICQ, bits, status)
```

## 2. 关键算法伪代码

### IP-161 QACL（量化感知闭环界）

```python
def iss_bound(rho, B_norm, w_bar, bit_width, R):
    delta = R / (2 ** bit_width)
    return lambda t, x0: (rho ** t) * x0 + (B_norm * delta + w_bar) / (1 - rho)

def required_bits(rho, B_norm, R, eps_target):
    import math
    delta_max = (1 - rho) * eps_target / max(B_norm, 1e-9)
    return math.ceil(math.log2(R / max(delta_max, 1e-12)))
```

### IP-162 QEB（灵敏度感知比特分配）

```python
class QuantizationErrorBudget:
    def __init__(self, sensitivities, ranges, b_min=4, b_max=16):
        self.L = sensitivities          # {'scene': Ls, 'intent': Li, 'policy': Lp}
        self.R = ranges                 # {'scene': Rs, ...}
        self.b_min, self.b_max = b_min, b_max

    def induced_error(self, bits):
        return sum(self.L[k] * self.R[k] / (2 ** bits[k]) for k in self.L)

    def allocate(self, eps_cl, safety=0.8):
        target = eps_cl * safety       # 预留 20% 安全余量
        bits = {k: self.b_min for k in self.L}
        while self.induced_error(bits) > target:
            gains = {
                k: self.L[k] * self.R[k] * (2 ** -bits[k] - 2 ** -(bits[k] + 1))
                for k in self.L if bits[k] < self.b_max
            }
            if not gains:
                return None            # 预算不可行，触发全精度回退
            bits[max(gains, key=gains.get)] += 1
        return bits

    def marginal_value(self, bits, k):
        # 供 AQC 做「借比特」：模块 k 再加 1 bit 的误差下降
        return self.L[k] * self.R[k] * (2 ** -bits[k] - 2 ** -(bits[k] + 1))
```

### IP-163 CLSM（Lyapunov 收缩监控）

```python
class ClosedLoopStabilityMonitor:
    def __init__(self, A, B, K, Q, alpha=0.1, beta=1.0, c_max=3):
        from scipy.linalg import solve_discrete_are
        self.P = solve_discrete_are(A, B, Q, np.eye(A.shape[0]))
        self.alpha, self.beta, self.c_max = alpha, beta, c_max
        self.violations = 0
        self.margin = 1.0

    def step(self, x, x_next, e_q, w):
        V0 = float(x @ self.P @ x)
        V1 = float(x_next @ self.P @ x_next)
        slack = (1 - self.alpha) * V0 + self.beta * (e_q @ e_q + w @ w)
        self.margin = (1 - self.alpha) - V1 / max(V0, 1e-12)
        self.violations = self.violations + 1 if V1 > slack else 0
        return 'STABILITY_ALERT' if self.violations >= self.c_max else 'OK'
```

### IP-164 AQC（双速率自适应量化）

```python
class AdaptiveQuantizationController:
    def __init__(self, qeb, eps_cl, dwell=10, hysteresis=0.1):
        self.qeb, self.eps_cl = qeb, eps_cl
        self.dwell, self.h = dwell, hysteresis
        self.bits = qeb.allocate(eps_cl)
        self.ticks_since_switch = dwell
        self.eps_lo, self.eps_hi = (1 - hysteresis) * eps_cl, (1 + hysteresis) * eps_cl

    def update(self, margin, est_error, period_idx):
        self.ticks_since_switch += 1
        if self.ticks_since_switch < self.dwell:
            return self.bits                       # 驻留时间约束，避免 Zeno
        if margin < 0.0:                           # 收缩性受损：整体收紧
            tighter = self.qeb.allocate(self.eps_cl * 0.5)
            if tighter: self.bits, self.ticks_since_switch = tighter, 0
        elif margin > 0.2 and est_error < self.eps_lo:   # 裕度充足：整体放松
            relaxed = self.qeb.allocate(self.eps_cl * 1.2)
            if relaxed: self.bits, self.ticks_since_switch = relaxed, 0
        return self.bits
```

### IP-168 CLQC（闭环-量化协同）

```python
def closed_loop_quantized_cognition(M, delta_f_req, intent):
    M.aqc.update(M.clsm.margin, M.qeb.induced_error(M.aqc.bits), M.period_idx)
    bits = M.aqc.bits

    M.scene_model.update(M.telem_force, M.telem_pos, bits['scene'])
    scene_dist = M.scene_model.get_scene_distribution()
    K_scene = M.eeis.compile_with_scene_prior(scene_dist, delta_f_req, bits['policy'])

    if intent:
        M.intent_ctrl.receive_intent(intent, bits['intent'])

    M, fused, D_plus, EV_exec, cert = closed_loop_exec_probe(
        M, M.current_cp, delta_f_req, bits=bits)

    ev_q = M.qepir.append(EV_exec.__dict__, bits, M.quant_meta)

    status = M.clsm.step(M.x_prev, M.x_curr, M.last_e_q, M.last_w)
    if status == 'STABILITY_ALERT':
        return rollback_full_precision(M), ev_q, status

    M, fused, D_plus = xmodal_fuse_plus(M, M.current_cp.region, M.inf_latest, ev_q)
    sicq = (scene_dist['scene_conf'], K_scene.certainty,
            1 - M.qeb.induced_error(bits) / max(K_scene.margin, 1e-9),
            K_scene.feasible)
    return M, ev_q, sicq, bits, status
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| QACL | O(1) 每步误差界计算 | O(n²) 矩阵 | ISS 稳态误差 ≤ ε_target |
| QEB | O((b_max−b_min)·\|M\|) 贪心 | O(\|M\|) | 比特分配在 ε_cl 预算内 ε-最优 |
| CLSM | O(n²) 每步二次型 | O(n²) | 收缩性违规检测延迟 ≤ c_max 步 |
| AQC | O(\|M\|) 每慢环 | O(\|M\|) | 切换次数有界（驻留时间 ≥ τ_dwell） |
| QEPIR | O(1) 追加 | O(window=100) | hash 覆盖数值+量化元数据 |

**正确性定理（CLQC）**：假设 A66–A70 成立，则
1. **ISS 稳定性**：若 b_i ≥ log₂(‖B‖R_i/((1−ρ)ε_i)) 且 ‖w‖ ≤ w̄，则 ∀t，‖x_t‖ ≤ ρᵗ‖x_0‖ + ε_cl/(1−ρ)。
2. **比特分配可行性**：若 B(ε_cl) 非空，QEB 返回 b 满足 E_cl(b) ≤ ε_cl，且贪心解的总比特数不超过最优解 +|M|。
3. **监控可靠性**：若 CLSM 在 W 步内未触发告警，则闭环在 W 步内满足 (α,β)-收缩证书；触发告警则回退全精度，保证安全。
4. **证据可审计**：EV-exec^q 的 hash 同时绑定内容与 q_meta，任何比特/量化方案变更都会导致 hash 失配。

## 5. 本轮最大风险

**一句话**：若敏感度 L_i 被低估或动态范围 R_i 漂移，QEB 会给出「看似满足预算、实则越界」的比特分配，使量化误差沿闭环被放大为振荡甚至发散——「认知先行」反而变成「量化诱发的灾难性失效」；必须以 CLSM 的 Lyapunov 证书在线兜底、QEB 预留 20% 安全余量、b_min 比特下限、以及 STABILITY_ALERT 的全精度保守回退四重护栏，保证任何时刻「量化闭环」都不突破「执行安全」。

### IP-161 QACL（量化感知闭环界）

```python
def iss_bound(rho, B_norm, w_bar, bit_width, R):
    delta = R / (2 ** bit_width)
    return lambda t, x0: (rho ** t) * x0 + (B_norm * delta + w_bar) / (1 - rho)

def required_bits(rho, B_norm, R, eps_target):
    import math
    delta_max = (1 - rho) * eps_target / max(B_norm, 1e-9)
    return math.ceil(math.log2(R / max(delta_max, 1e-12)))
```

### IP-162 QEB（灵敏度感知比特分配）

```python
class QuantizationErrorBudget:
    def __init__(self, sensitivities, ranges, b_min=4, b_max=16):
        self.L = sensitivities          # {'scene': Ls, 'intent': Li, 'policy': Lp}
        self.R = ranges
        self.b_min, self.b_max = b_min, b_max

    def induced_error(self, bits):
        return sum(self.L[k] * self.R[k] / (2 ** bits[k]) for k in self.L)

    def allocate(self, eps_cl, safety=0.8):
        target = eps_cl * safety
        bits = {k: self.b_min for k in self.L}
        while self.induced_error(bits) > target:
            gains = {
                k: self.L[k] * self.R[k] * (2 ** -bits[k] - 2 ** -(bits[k] + 1))
                for k in self.L if bits[k] < self.b_max
            }
            if not gains:
                return None            # 预算不可行，触发全精度回退
            bits[max(gains, key=gains.get)] += 1
        return bits
```

### IP-163 CLSM（Lyapunov 收缩监控）

```python
class ClosedLoopStabilityMonitor:
    def __init__(self, A, B, K, Q, alpha=0.1, beta=1.0, c_max=3):
        from scipy.linalg import solve_discrete_are
        self.P = solve_discrete_are(A, B, Q, np.eye(A.shape[0]))
        self.alpha, self.beta, self.c_max = alpha, beta, c_max
        self.violations = 0
        self.margin = 1.0

    def step(self, x, x_next, e_q, w):
        V0 = float(x @ self.P @ x)
        V1 = float(x_next @ self.P @ x_next)
        slack = (1 - self.alpha) * V0 + self.beta * (e_q @ e_q + w @ w)
        self.margin = (1 - self.alpha) - V1 / max(V0, 1e-12)
        self.violations = self.violations + 1 if V1 > slack else 0
        return 'STABILITY_ALERT' if self.violations >= self.c_max else 'OK'
```

### IP-164 AQC（双速率自适应量化）

```python
class AdaptiveQuantizationController:
    def __init__(self, qeb, eps_cl, dwell=10, hysteresis=0.1):
        self.qeb, self.eps_cl = qeb, eps_cl
        self.dwell, self.h = dwell, hysteresis
        self.bits = qeb.allocate(eps_cl)
        self.ticks_since_switch = dwell
        self.eps_lo, self.eps_hi = (1 - hysteresis) * eps_cl, (1 + hysteresis) * eps_cl

    def update(self, margin, est_error, period_idx):
        self.ticks_since_switch += 1
        if self.ticks_since_switch < self.dwell:
            return self.bits
        if margin < 0.0:
            tighter = self.qeb.allocate(self.eps_cl * 0.5)
            if tighter: self.bits, self.ticks_since_switch = tighter, 0
        elif margin > 0.2 and est_error < self.eps_lo:
            relaxed = self.qeb.allocate(self.eps_cl * 1.2)
            if relaxed: self.bits, self.ticks_since_switch = relaxed, 0
        return self.bits
```

### IP-166 QEPIR（量化证据链）

```python
class QuantizedEvidenceChain:
    def __init__(self, window=100):
        self.shadow, self.last_seq = {}, 0
        self.window = window

    def append(self, ev_exec, bits, quant_meta):
        q_meta = {**quant_meta, 'bits': dict(bits)}
        payload = json.dumps({'content': ev_exec, 'q_meta': q_meta},
                             sort_keys=True, ensure_ascii=False)
        msg = {
            'content': ev_exec,
            'q_meta': q_meta,
            'timestamp': time.time(),
            'seq_id': self.last_seq + 1,
            'hash': hashlib.sha256(payload.encode('utf-8')).hexdigest(),
        }
        self.shadow[msg['seq_id']] = msg
        self.last_seq += 1
        if len(self.shadow) > self.window:
            del self.shadow[min(self.shadow)]
        return msg

    def verify(self, msg):
        payload = json.dumps({'content': msg['content'], 'q_meta': msg['q_meta']},
                             sort_keys=True, ensure_ascii=False)
        return hashlib.sha256(payload.encode('utf-8')).hexdigest() == msg['hash']
```

```python
def closed_loop_quantized_cognition(M, delta_f_req, intent):
    M.aqc.update(M.clsm.margin, M.qeb.induced_error(M.aqc.bits), M.period_idx)
    bits = M.aqc.bits

    M.scene_model.update(M.telem_force, M.telem_pos, bits['scene'])
    scene_dist = M.scene_model.get_scene_distribution()
    K_scene = M.eeis.compile_with_scene_prior(scene_dist, delta_f_req, bits['policy'])

    if intent:
        M.intent_ctrl.receive_intent(intent, bits['intent'])

    M, fused, D_plus, EV_exec, cert = closed_loop_exec_probe(
        M, M.current_cp, delta_f_req, bits=bits)

    status = M.clsm.step(M.x_prev, M.x_curr, M.last_e_q, M.last_w)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性 |
|---|---|---|---|
| QACL | O(1) / 步 | O(n²) | ISS 稳态误差 ≤ ε_target |
| QEB | O((b_max−b_min)·\|M\|) | O(\|M\|) | 预算内 ε-最优比特分配 |
| CLSM | O(n²) / 步 | O(n²) | 告警延迟 ≤ c_max 步 |
| AQC | O(\|M\|) / 慢环 | O(\|M\|) | 切换有界（≥ τ_dwell） |
| QEPIR | O(1) 追加 | O(window=100) | hash 绑定数值+量化元数据 |

**正确性定理（CLQC）**：若 A66–A70 成立，则：
1. **ISS 稳定性**：b_i ≥ log₂(‖B‖R_i/((1−ρ)ε_i)) ⇒ ‖x_t‖ ≤ ρᵗ‖x_0‖ + ε_cl/(1−ρ)。
2. **比特分配可行性**：B(ε_cl) 非空时 QEB 输出满足 E_cl(b) ≤ ε_cl，总比特数 ≤ 最优 +|M|。
3. **监控可靠性**：W 步无告警 ⇒ (α,β)-收缩成立；告警 ⇒ 全精度回退，安全不失守。
4. **证据可审计**：hash 覆盖 content‖q_meta，比特或量化方案变更必致 hash 失配。

## 5. 本轮最大风险

**一句话**：若敏感度 L_i 被低估或动态范围 R_i 漂移，QEB 会给出「看似满足预算、实则越界」的比特分配，使量化误差沿闭环放大为振荡甚至发散——「认知先行」反而变成「量化诱发的灾难性失效」；必须以 CLSM 的 Lyapunov 证书在线兜底、QEB 预留 20% 安全余量、b_min 比特下限、以及 STABILITY_ALERT 的全精度保守回退四重护栏，保证任何时刻「量化闭环」都不突破「执行安全」。
