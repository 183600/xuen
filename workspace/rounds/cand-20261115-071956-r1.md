# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「创新点挖掘」×「课程学习」）

> R69 让系统学会了「问」，却留下两个更上位的问题没有回答。第一，**该往哪里创新**？FMP、AUD、MINT、CIA、FMA 都是手工选定的层；一个只会「再加一层」的研究循环，最终会积累一堆各自需要独立信任的黑箱。第二，**新能力凭什么被信任、按什么顺序上线**？R69 只用 MCG 的标量 ECE 给「模态权重」发许可证，但「我会问」不是标量，而是随场景难度变化的**胜任度**；一上来就在全状态空间开启主动交互，正是 R69 自陈最大风险（问错比不问更危险）的温床。
>
> 本轮两个灵感分别回答这两个问题：
> - **创新点挖掘**把「下一步做什么」从直觉变成一个可计算、可审计的排序问题：从系统的失败账本、近失事件、未消解 epistemic 状态里挖出「缺口—杠杆—可验证性」三元组，只开采能被反事实探针证伪的创新点；
> - **课程学习**把「能力」从一个布尔开关变成**难度索引的胜任度函数**：在最近发展区（ZPD）内按难度递增获取能力，用 LCB 晋级门逐段扩大使能掩码；没拿到证的能力自动退回到已认证的前置层。
>
> 核心命题：**把研究循环本身也做成闭环——CURIO-RAS 在 FLUID-RAS 之上加一层「元循环」：挖掘创新点（IPM）→ 维护能力先修格（CPL）→ 在 ZPD 内排课（CSD）→ 过晋级门才扩使能（PG）→ 挖掘结果用盲探针审计（MAG）→ 未认证能力逐指令退回前置层。** 于是 R69 的「会问」不再是默认能力，而是必须被「挣来」的能力：在它被认证之前，系统逐指令等于 R69；在 R69 被认证之前，逐指令等于 R68。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我下一步该长哪种本事，又凭什么说我已经学会了**」——研究循环的产出不该是又一层黑箱，而是一条**可认证、可回退、有先修顺序的能力阶梯**。

## 0. 直觉与动机

**灵感 1（创新点挖掘 → 缺口是数据，不是灵感）**
直觉：人类研究者说「这里有个创新点」，往往是因为他看见了一个反复出现的失败模式、一个别人没填的坑、或一个能被实验区分的猜想。把这三件事形式化，创新点就不是玄学：**(缺口 Γ, 杠杆 Λ, 可验证性 V)**。缺口来自系统自己的审计流（VQAuditor 的未消解事件、近失、被降级的模态）；杠杆是该能力在缺口上的边际风险下降 / 成本；可验证性是「能不能设计一个反事实探针，让增益在统计上被看见」。一个挖不出探针的「创新点」，本轮明确拒绝开采——**拒绝开采也是一等公民**，这正是不让研究循环变成许愿池的关键。

**灵感 2（课程学习 → 能力是难度索引的函数，不是开关）**
直觉：小孩不是「某天突然会问问题」，而是先会看、再会在熟悉情境里问、再会在陌生/高风险情境里问。把能力 c 写成 K(c,d)：在难度 ≤ d 的实例上的正确率（任务正确 ∧ 证据纪律满足）。于是「上线一个能力」变成一个偏序：先认证它在低难度的 LCB，再逐段扩到高难度。R69 的 MCG 只是 K 的一个点估计，本轮把它升级成**沿难度轴的胜任度曲线 + 晋级门**。

**灵感 3（ZPD → 太难和太易都不学习，也不安全）**
直觉：难度太低，信息量为零（系统只会重复已会的）；难度太高，成功信号淹没在噪声里，而且一旦失败代价不可接受。最近发展区 ZPD(c) = {d : p_lo ≤ K(c,d) ≤ p_hi} 正是「跳一跳够得着」的带。课程调度器只在 ZPD 内采样难度，并在带边界留少量探索。这把 R69 的「全状态空间交互」收缩成「**只在我学得动的状态上交互**」。

**灵感 4（先修格 + 使能掩码 → 严格包含旧层）**
直觉：能力之间有先修关系（不会「看」就不该「问」；不会「问」就不该「边问边做」）。把能力组织成 DAG，已认证集合必须是**下闭的理想（order ideal）**。使能掩码 m_c(s) 逐状态决定某能力是否开启，且只在晋级事件后扩张。于是调度器永远选「当前状态下最高的已认证能力」，没有认证就退回前置层。R69 = 所有 m_ask ≡ 0 的边界，R68 = 更下面一层。这是本系列一贯的理论姿态：**新层是旧层的保守扩张，而不是并列替代**；安全侧永不做让步。

**灵感 5（Goodhart → 挖掘目标会自我实现，必须盲测）**
直觉：一旦「创新」由系统自己打分，它就会去挖「最容易证明自己有用」的能力——便宜的探针、熟悉的分布、能立刻让指标好看的补丁。这是 Goodhart 的教科书形态，而且比 R69 更危险：R69 至少知道自己不确定，CURIO 会给每个自欺的进步盖一个「已认证」的章。所以挖掘必须在**与训练/验证不相交的盲探针集**上结算，至少两条正交证据族，并对新增层数施加 MDL/复杂度惩罚。口号：**在你挖的地方测量，在你没挖的地方结算。**

## 1. 形式化定义（增量：定义 310–320）

**定义 310（CURIO-RAS 总览与三不变式）** CURIO-RAS = (IPM, CPL, CSD, ZPD-E, PG, MAG, EMD, RAS-WM‡)：一个运行在 FLUID-RAS 之上的**元循环层**，不进入实时控制路径。三不变式：
(i) **严格包含**：若某状态下没有更高层能力获认证并使能，则调度结果逐指令等于 FLUID-RAS（若连 FLUID 层也未认证，则等于 CALM-RAS）；
(ii) **先修下闭 + 单调使能**：已认证集 C_cert(t) 恒为 (𝒞,≺) 的 order ideal；使能掩码只在晋级事件后扩张，降级必须留 demotion 记录并立即回滚；
(iii) **挖掘独立性**：创新点排序只用与能力训练/验证不相交的证据，结算只在盲探针集 ℬ 上完成，且至少两族正交探针 ℬ₁ ⊥ ℬ₂。

**定义 311（能力与能力先修格 CPL）** 能力 c: 𝒮 → 可选动作/交互构造子（如「注视」「探针」「问句」「边问边做」）；pre(c) ⊆ 𝒞 为其直接前置。关系 ≺ 取 pre 的传递闭包，构成 DAG，格 (𝒞, ≺) 的已认证子集须下闭。认证层级 ℓ_c ∈ {0,1,…,L}，0 表示未认证，ℓ 对应允许的最大难度带 d_{ℓ}。C_cert = {c : ℓ_c ≥ 1}。

**定义 312（难度与课程）** 任务实例 τ 的难度 d(τ) ∈ [0,1]，由可观测统计给出，例如 d = 1 − Δ_min/(Δ_min + κσ_in)（歧义越不可分越难）与风险/时窗的组合。课程是难度分布序列 D₀,…,D_T，满足 supp(D_{t+1}) ⊇ supp(D_t) 且 E_{D_{t+1}}[d] ≥ E_{D_t}[d]（覆盖单调扩张、均值单调变难）。

**定义 313（胜任度函数与置信下界）** K(c,d) = P(任务正确 ∧ 证据纪律满足 | difficulty ≤ d)。由 n 个样本估计，K_lcb(c,d) = K̂ − β·σ̂/√n（β 与目标置信水平对应）。把「答对」与「程序对」都计入 K，防止「答对但单源采纳」这种程序性作弊。

**定义 314（晋级门 PG，含滞回）** 晋级 c: ℓ → ℓ+1（把使能难度上界从 d_ℓ 扩到 d_{ℓ+1}）当且仅当 K_lcb(c, d_{ℓ+1}) ≥ κ_promote、校准误差 ECE(c) ≤ τ_ece、且对抗探针集 ℰ_probe 无失败样例。降级当且仅当滑动窗口内 K̂(c,·) < κ_keep（κ_keep < κ_promote，形成滞回）或审计发现证据纪律违规；降级立即回滚使能掩码。

**定义 315（最近发展区 ZPD-E）** ZPD(c) = {d : p_lo ≤ K(c,d) ≤ p_hi}，0 < p_lo < p_hi < 1。课程调度只在 ZPD(c) ∪ ∂ZPD(c)（边界 ε 探索）上采样难度：太易无信息量，太难不安全且不可学。

**定义 316（创新点与挖掘目标 IPM）** 创新点 p = (Γ_p, c_p, Λ_p, V_p)。Γ_p 是未被认证能力覆盖的失败/近失/未消解 epistemic 事件簇（来自 AuditBuf 与反事实探针）；Λ_p = E_{s~Γ_p}[ΔU(s; c_p)] / cost(c_p)，ΔU 为风险下降或 VoI 提升；V_p 为探针检验力（1−β_power），要求能构造出让 H₀: 增益=0 被拒绝的探针。挖掘排序：
U(p) = Λ_p · V_p / (1 + MDL(c_p))，
s.t. pre(c_p) ⊆ C_cert（先修可行）、探针可构造、度量通道与训练通道独立。若 max 无可行 p ⇒ **本轮不开采**（正当结果）。

**定义 317（挖掘审计 MAG 与反 Goodhart）** 盲探针集 ℬ 与训练/验证/挖掘证据不相交；ℬ₁ ⊥ ℬ₂（如仿真反事实 vs 真实留出）。挖掘精度 P_mine = |{晋级点中在 ℬ 上实现增益 ≥ δ}| / |{晋级点}|。若 P_mine < τ_mine 或两族结论冲突 ⇒ 冻结挖掘、回退 FLUID-RAS；新增层超过 MDL 预算 ⇒ 强制合并/剪枝。

**定义 318（使能掩码与分层调度 EMD）** m_c: 𝒮 → {0,1}，m_c(s)=1 当且仅当 c 已认证且 d(s) ≤ d_{ℓ_c}。m 只在晋级时单调扩张。分层调度：在候选能力里取「已使能且其已使能前置中无更大元」的最高元执行；否则递归回退到 pre(c) 中最高的已认证者。将 R68、R69 的既有能力注册为格中自下而上的已认证最低层，R69 = 「所有交互能力 m ≡ 0」的边界。

**定义 319（课程陷阱证书 CTC）** 陷阱判据：(a) 覆盖 cov(D_t) 停止增长（不再接触新难度层）而挖掘效用仍高；(b) 挖掘效用与「训练分布内可测性」高度相关（自指）；(c) 已认证能力的平均难度长期停滞。触发 ⇒ 强制把 ≥ ε 探索预算放到「最难未覆盖层」，并暂停晋级直到覆盖恢复。trap_flag 与逃逸动作入证书。

**定义 320（证书 J_CURIO）** J_CURIO = (J_FLUID, C_cert, curriculum_coverage, promotion_log_hash, mining_precision, probe_family_hash, trap_flag, curio_ver)。Valid ⇔ Valid(J_FLUID) ∧ P_mine ≥ τ_mine ∧ 先修下闭 ∧ 无 pending demotion ∧ 无未处理 trap_flag。

```python
# IP-264 CPL：能力先修格（已认证集必须下闭）
class CapabilityLattice:
    def __init__(self, caps, prereq): ...
    def certifiable(self, c):  return set(prereq[c]) <= self.certified
    def promote(self, c, level): assert self.certifiable(c); ...
    def demote(self, c): ...                         # 立即回滚使能

# IP-268 IPM：创新点挖掘（缺口 → 杠杆 → 可验证性）
def mine_innovation_points(audit, lattice, probe_bank):
    gaps = cluster_unresolved(audit)                 # 未消解 epistemic / 近失 / 降级事件
    pts  = []
    for g in gaps:
        for c in candidate_capabilities(g):          # 由缺口反推能力提案
            if not lattice.certifiable(c): continue   # 先修必须先认证
            probe = probe_bank.design(g, c)           # 反事实探针
            if probe.power < 1 - BETA: continue       # 挖不出探针 → 不开采
            pts.append(Point(g, c, leverage(g, c), probe.power))
    return rank_by(pts, key=lambda p: p.U / (1 + mdl(p.c)))

# IP-265/266/267：课程调度 + ZPD + 晋级门（带滞回）
def curriculum_step(cap, lattice, competence, budget):
    d_lo, d_hi = competence.zpd(cap)                  # 最近发展区
    for d in schedule(d_lo, d_hi, budget):            # 覆盖单调、均值单调变难
        batch = sample_tasks(d)                       # 只在 ZPD(±ε) 上采样
        update(competence, cap, batch)
        if competence.lcb(cap, d) >= KAPPA_PROMOTE:
            if adverse_probe_clean(cap) and ece(cap) <= TAU_ECE:
                lattice.promote(cap, next_level(d))
        elif competence.hat(cap) < KAPPA_KEEP:
            lattice.demote(cap)                       # 滞回 + 立即回滚

# IP-269/271：盲结算与课程陷阱检测
def mining_audit(points, blind_probes, lattice):
    if coverage_stalled(lattice) and mining_selfcorrelated(points):
        return Trap(escape='force_explore_hardest_uncovered')
    realized  = [gain(p, blind_probes) for p in points if p.promoted]
    precision = mean(g >= DELTA for g in realized)
    if precision < TAU_MINE or probes_disagree(blind_probes):
        freeze_mining(); rollback_to(FLUID_RAS)
    return precision

# IP-274 主元循环（在 FLUID-RAS 外层，不进入实时控制路径）
def CURIO_meta_round(M, audit_window):
    pts = M.ipm.mine(audit_window, M.cpl, M.probe_bank)
    if not pts: return NoInnovation()                 # 正当结果
    p = pts[0]
    M.csd.schedule(p.c, M.cpl, M.competence, M.budget)
    ok = M.mag.audit(pts, M.blind, M.cpl)
    if ok:   M.emd.rebuild_dispatch(M.cpl)            # 仅扩使能掩码
    else:    M.emd.rollback(); M.cpl = last_certified # 逐指令回退
    M.vqa_m.submit_async(pts, ok, M.ctc.flag)
    return J_CURIO(M)

# 实时控制路径（与 R69 同构，仅多一次 O(1) 使能查询）
def CURIO_RAS_round(M, obs):
    c = M.emd.select(obs)                             # 最高已使能能力
    return M.layers[c].step(obs)                      # 未认证 → 自动退回 R69/R68
```

## 3. 推导

**引理 19（先修下闭的包含性）** 若 C_cert 恒为 (𝒞,≺) 的 order ideal，且使能掩码只在晋级后扩张，则在 A100（晋级门健全：K_lcb 为有效下界、κ_promote 不低于前置层已认证的胜任度）下，任意状态 s 上分层调度选出的能力层不超过当前认证前沿；在「新能力均未认证」时调度逐指令等于 FLUID-RAS。故 CURIO 的在线期望风险 ≤ FLUID-RAS，等号在无晋级事件时精确成立。

**引理 20（挖掘的选择偏差与盲结算）** 设从 |𝒞| 个候选中按样本内估计选最大者，则其样本内增益相对真实增益的期望高估 ≥ σ√(2 log|𝒞|/n)（赢家诅咒 / 多重比较）。若在 𝒜 上排序、在 𝒜⊥ 的盲探针 ℬ 上结算，则一阶高估消失，残差仅来自探针功效不足的漏检；两族正交探针不一致时误判概率 ≤ 2 exp(−2nδ²)（Hoeffding）。系：**挖掘与结算的证据必须不相交**，否则「创新」只是把噪声选成了信号。

**引理 21（ZPD 内课程的单调性）** 在 A99（K(c,·) 对 d 单调不增）下，若 D_t 支撑嵌套、均值单调，则认证前沿 {ℓ_c} 单调不减；每次晋级把 ZPD 上界推高，ZPD 宽度按 O(σ̂/√n) 收缩。若难度覆盖不扩张而只重复已会层，则 K 的估计方差下降但前沿停滞——这正是课程陷阱（定义 319-a）的可观测特征。

**定理 18（CURIO 严格包含 FLUID 与 CALM）** 在 A99–A100 下，CURIO 的期望风险 ≤ FLUID-RAS ≤ CALM-RAS；且当无创新点可开采、挖掘精度未过门、或无晋级事件时，三者逐指令相同。故 R69、R68 分别是 CURIO 在「m_ask ≡ 0」与「连 FMP 层也未认证」边界上的退化：安全侧不让步，效率侧获得按难度分级的 resolution bonus。

**定理 19（无黑箱爆炸 / 挖掘可靠性）** 若每次晋级都要求两族盲探针一致且 P_mine ≥ τ_mine，则被保留的新增层其真实边际增益 ≥ δ 的概率 ≥ 1−α（α 由探针功效与多重比较校正给出），期望新增层数上界为 O(log(1/α)/δ²)；超过 MDL 预算的新增被强制剪枝。故研究循环不能靠「再加一层」无限堆积需要独立信任的黑箱。

**定理 20（课程陷阱的覆盖性逃逸）** 若每次触发 trap_flag 后强制在最难未覆盖层分配 ≥ ε 探索预算，且该层在 K 上存在非零学习梯度带（可学），则 supp(D_t) 单调扩张并最终覆盖整个难度支撑；若存在不可学层，则 trap_flag 永久置位、系统停在该层之下——**明确地知道自己没学会**，而不是假装学会。

## 6. 本轮最大风险

**一句话**：CURIO-RAS 的元循环把「创新」交给了系统自己打分，于是它有强烈的动机去挖**最容易证明自己有用**的能力（便宜探针、熟悉分布、能让指标立刻好看的补丁），课程又把它锁在「已经看起来不错」的难度带上；结果是**被认证的进步很可能是被设计出来的进步**——一个自我表扬、局部可证、全局盲视的研究循环，而且每一层都盖了「已验证」的章，使这种虚假信心比 R69 的「诚实的不知道」更危险。

2. **课程陷阱 / 只刷熟题**（覆盖停滞而分数虚高）→ 定义 319 CTC + 强制探索最难未覆盖层；E306/E307；
3. **先修关系被绕过**（能力格失效、偷偷上线）→ 定义 311/318 下闭理想 + 逐指令包含检查；E305；
4. **晋级门统计不足**（小样本 LCB 过宽或过窄）→ 多重比较校正 + 滞回 + 探针功效下限；E308/E311；
5. **离线元循环拖慢研究节奏**（挖掘/排课成本）→ 全部离线、与实时环解耦，实时仅 +O(1) 掩码查询；E309/E310。

## 3. 关键算法伪代码

```python
# IP-268 IPM：创新点挖掘（缺口 → 杠杆 → 可验证性）
def mine_innovation_points(audit, lattice, probe_bank):
    gaps = cluster_unresolved(audit)
    pts  = []
    for g in gaps:
        for c in candidate_capabilities(g):
            if not lattice.certifiable(c): continue      # 先修必须先认证
            probe = probe_bank.design(g, c)
            if probe.power < 1 - BETA: continue          # 挖不出探针 → 不开采
            pts.append(Point(g, c, leverage(g, c), probe.power))
    return rank_by(pts, key=lambda p: p.U / (1 + mdl(p.c)))

# IP-265/266/267：ZPD 内排课 + LCB 晋级 + 滞回降级
def curriculum_step(cap, lattice, competence, budget):
    d_lo, d_hi = competence.zpd(cap)
    for d in schedule(d_lo, d_hi, budget):              # 覆盖单调、均值单调变难
        update(competence, cap, sample_tasks(d))        # 只在 ZPD(±ε) 上采样
        if competence.lcb(cap, d) >= KAPPA_PROMOTE \
           and adverse_probe_clean(cap) and ece(cap) <= TAU_ECE:
            lattice.promote(cap, next_level(d))
        elif competence.hat(cap) < KAPPA_KEEP:
            lattice.demote(cap)                         # 滞回 + 立即回滚

# IP-269/271：盲结算 + 课程陷阱检测
def mining_audit(points, blind_probes, lattice):
    if coverage_stalled(lattice) and mining_selfcorrelated(points):
        return Trap(escape='force_explore_hardest_uncovered')
    precision = mean(gain(p, blind_probes) >= DELTA for p in points if p.promoted)
    if precision < TAU_MINE or probes_disagree(blind_probes):
        freeze_mining(); rollback_to(FLUID_RAS)
    return precision

# IP-274 主元循环（离线）+ 实时 O(1) 调度
def CURIO_meta_round(M, audit_window):
    pts = M.ipm.mine(audit_window, M.cpl, M.probe_bank)
    if not pts: return NoInnovation()                   # 正当结果：不开采
    M.csd.schedule(pts[0].c, M.cpl, M.competence, M.budget)
    ok = M.mag.audit(pts, M.blind, M.cpl)
    if ok:   M.emd.rebuild_dispatch(M.cpl)              # 仅扩使能掩码
    else:    M.emd.rollback(); M.cpl = last_certified   # 逐指令回退
    M.vqa_m.submit_async(pts, ok, M.ctc.flag)
    return J_CURIO(M)

def CURIO_RAS_round(M, obs):                            # 实时路径，与 R69 同构
    return M.layers[M.emd.select(obs)].step(obs)        # 未认证 → 自动退回 R69/R68
```

## 4. 推导

**引理 19（先修下闭的包含性）** C_cert 恒为 order ideal 且使能只在晋级后扩张；在 A100（晋级门健全：K_lcb 为有效下界、κ_promote 不低于前置层胜任度）下，任意状态 s 选出的层不超过认证前沿；新能力均未认证时逐指令等于 FLUID。故在线期望风险 ≤ FLUID，无晋级事件时精确相等。

**引理 20（挖掘的选择偏差与盲结算）** 从 |𝒞| 个候选中按样本内估计取最大，其增益期望高估 ≥ `σ√(2log|𝒞|/n)`（赢家诅咒）。在 𝒜 上排序、𝒜⊥ 的盲探针上结算可消一阶偏差；两族不一致误判 ≤ `2exp(−2nδ²)`。系：**挖掘与结算的证据必须不相交**。

**引理 21（ZPD 内课程单调性）** A99（K 对 d 单调不增）下，D_t 嵌套且均值单调 ⇒ 认证前沿单调不减；每次晋级推高 ZPD 上界，带宽按 `O(σ̂/√n)` 收缩；若覆盖停滞只重复熟题，则方差降而前沿停滞——即陷阱可观测特征。

**定理 18（CURIO 严格包含 FLUID 与 CALM）** A99–A100 下期望风险 ≤ FLUID ≤ CALM；无创新点、精度未过门或无晋级时逐指令相同。R69/R68 分别为「m_ask≡0」与「FMP 层未认证」的退化边界。

**定理 19（无黑箱爆炸 / 挖掘可靠性）** 每次晋级都要求两族盲探针一致且 `P_mine ≥ τ_mine`，则保留层真实增益 ≥ δ 的概率 ≥ 1−α，期望新增层数 ≤ `O(log(1/α)/δ²)`；超 MDL 预算强制剪枝。研究循环不能无限堆积黑箱。

**定理 20（课程陷阱的覆盖性逃逸）** 触发 trap_flag 后强制在最难未覆盖层分配 ≥ ε 预算且该层可学 ⇒ 覆盖单调扩张至全支撑；若存在不可学层，则 trap_flag 永久置位、系统停在其下——**明确知道没学会**，而非假装学会。
