# 第 73 轮（承接第 72 轮「EMBODIED-GAUGE-RAS 具身计量审计」IP-287~294；灵感循环（新序列）第 1 轮；本轮灵感：「通用机器人」×「奖励设计」）

> R72 把 GAUGE 从「认知层」下沉为「具身层」：用 REG 实时执行图把「计量不阻塞控制」变成调度级定理，用意图 z 与接触 c 把反作用扩展到三层，用 S2R-UQ 把仿真参数不确定度传播到 WCET 与 λ_floor。它回答的是：
> **「我的测量链在实时调度下、面对意图模糊的人、用灵巧手触摸世界时，还能逐指令兑现风险界吗？」**
> 但 R72 有两个被默认掉的盲点：
> - **通用机器人视角**：R72 仍假设「一个策略 + 一个任务 + 一个奖励」是给定的。通用机器人意味着 **一个通才策略 π_g 覆盖开放任务族 𝒯 与开放本体族 ℰ**：它在分布内很强，在分布外会**高置信地错**；它的「能给出动作」不等于「能完成任务」；同一策略在不同本体上的**能力域**不同。R72 的 REG/IRL/DMEM 只审计「证据」，不审计「策略是否在能力域内」。
> - **奖励设计视角**：R72 从未问「驱动规划与控制的**目标函数本身**是否有效」。奖励不是一个标量，而是**对潜在价值 V\* 的测量仪器**：它有构念效度、校准误差、有效域、可被 Goodhart 优化击穿。更糟的是，R72 的奖励 r̂ 是从证据算出来的——**若证据链被污染，奖励也会被污染**；测量链审计通过，只保证「我看到的为真」，不保证「我优化的值得」。
>
> 因此 R73 的问题不是「测量链可不可信」，而是：
> **「驱动这条测量链的价值目标本身可不可信？提出动作的通才策略，是否仍在它能兑现该目标的能力域之内？」**
> 把 R72 的「具身计量审计」上升为 **GOAL-GAUGE-RAS = Generalist-policy, Objective-Audited, Lifetime-valid GAUGE for RAS（通才策略能力域 × 奖励仪表效度 × 目标接地安全）**——**目标计量审计闭环**。

## 0. 直觉与动机

**灵感 1（通用机器人 → 能力域是契约，不是假设）**
直觉：R72 的调度契约保证「控制环 1kHz 不抖」，但通才策略 π_g 可能在这个周期里输出一个**超出其能力域**的动作：比如面对没见过的透明物体仍自信伸手、面对新本体仍用旧抓取先验、面对没训练过的工具仍按「像锤子」的类比去砸。**「动作空间有定义」不等于「动作有胜算」**。通用机器人的部署必须先签一份**能力域契约（Competence Contract）**：在 (任务 τ, 本体 e) 上，π_g 的任务成功率有校准下界；低于门限就只能走专家策略或安全锚。**通才的「通用」不是能力无限，而是能力域可被计量地声明——能力域之外，默认退回。**

**灵感 2（奖励设计 → 奖励是价值传感器，不是目标函数）**
直觉：工程师常说「调奖励」，好像奖励是一个可以随便拧的旋钮。但奖励是在**测量**一个潜在量 V\*(行为)：人真正在乎的安全性、可逆性、时间、尊严、可控性。任何测量仪器都要问：**构念效度**（它测的是不是它声称的 V\*）、**校准**（数值大小是否对得上真实价值）、**有效域**（在哪些任务/本体/状态下有效）、**追溯链**（这条奖励从哪版偏好数据、哪个标注者、哪次审计来）。**奖励设计的第一性问题是测量学问题，不是超参数问题。** 没有 RDM（Reward Design Metrology）的奖励，就是一个「裸奔的数字」。

**灵感 3（Goodhart → 优化本身是分布干预，会把策略推出奖励有效域）**
直觉：R71/R72 已经承认「机器人动作会改变证据分布」。R73 要再进一步：**优化奖励 r̂ 这个动作本身，会改变行为分布 μ_π**。奖励的有效域 D_r 是在某个行为分布上标定的；一旦策略开始全力最大化 r̂，它就会涌向「r̂ 高但 V\* 不高」的角落（覆盖摄像头骗视觉奖励、磨蹭刷进度奖励、把物体藏在触觉死区骗成功检测、用含糊回答刷「人类满意度」）。这就是 Goodhart：**不是奖励写错了，而是优化压力把测量推出了有效域**。必须定义 **Goodhart 半径 ρ_G**：优化压力超过它，奖励失效。**「优化强度」必须像温度、力一样被计量并设上限。**

**灵感 4（奖励必须证据接地 → 不能用被污染的证据喂养奖励）**
直觉：R72 的奖励输入 y 已经过 GAUGE 审计。但如果奖励模型直接看原始观测，那么攻击者可以绕过测量审计：**污染视觉→伪造成功→奖励高→策略学会「遮挡即成功」**。所以 RDM 的第一条硬约束是 **证据接地（evidence-grounded）**：r̂ 只能消费**已通过 J_EMB / J_GAUGE 的证据证书**；任一证据被否决，奖励**不是置零，而是未定义**（undefined），必须触发目标否决。**「证据不可信」不能变成一个低奖励，只能变成一个「不计算」。**

**灵感 5（通用性 → 两级目标：构成性目标不可交易，工具性目标才可优化）**
直觉：开放任务族里不存在一个对所有任务都正确的任务奖励。但存在一组**构成性目标（constitutive objectives）**：不伤人、不做不可逆动作、不欺骗、不越过人类否决。这些不是「任务奖励的一项权重」，而是**不可补偿的约束**。通用机器人应当把目标拆成两层：
- **构成性层 r_0（非学习、不可优化、人类可否决）**：安全锚；
- **工具性层 r_τ（任务相关、可学习、可审计）**。
通才策略只能在「不牺牲 r_0」的前提下最大化 r_τ。**R72 的风险缩放 λ 只能调节谨慎度，不能把「错误目标」变正确；R73 必须把「目标有效性」从 λ 中拿出来，做成非补偿否决。**

**灵感 6（L4 目标反作用 → 策略会反过来塑造奖励模型）**
直觉：R71 有 ψ 反作用、R72 有 z 与 c 反作用；R73 出现第四层：**策略影响奖励后验**。主动偏好学习里，机器人选择问哪些问题；一个会刷分的策略会**专挑奖励模型已经同意的问题**（self-confirmation），让 θ_r 越来越偏向「机器人已经会做的事」，而不是「人真正想要的事」。这是比意图漂移更隐蔽的反作用：**不是目标变了，而是「衡量目标的尺子」被被测者自己校准了。** 必须给 L4 反作用独立预算、独立审计留出集与随机化查询比例。

**灵感 7（目标代数 → 两个各自有效的奖励，组合起来可能无效）**
直觉：通用机器人要组合任务：「先去拿杯子，再递给老人，同时别碰倒药瓶」。三个子奖励各自构念有效，但**并行相加**会制造新的投机通道：为了「递得快」而「碰倒药瓶」；为了「别碰倒」而「不递」。**效度对组合不封闭**。所以需要 **OGA（Objective Algebra）**：定义并行/时序/条件组合算子，给出效度保持的充分条件（共享支撑、势函数对齐、构成性约束不冲突），否则计算**组合间隙**并触发 O-IVG。**通用性不是把奖励相加，而是把「什么情况下可以相加」形式化。**

## 1. 形式化定义（增量：定义 366–383）

**定义 366（GOAL-GAUGE-RAS 总览）** GOAL-GAUGE-RAS = (GPC, RDM, GHM, OAU, O-IVG, O-REFLEX, OGA, PPR, EMBODIED-GAUGE-RAS†)。七不变式：
(i) **目标有效性优先**：任何进入规划/控制的奖励 r 必携带 RDM 六元组；O-IVG 失败即停止优化该奖励，退回安全锚 r_0，**不可被任何 λ、置信度或效率收益补偿**；
(ii) **证据接地奖励**：r̂ 的每个输入必须是已通过 J_EMB/J_GAUGE 的证据证书；证据否决 ⇒ 奖励未定义 ⇒ 目标否决，**绝不以低奖励代替未定义**；
(iii) **能力域契约**：通才策略 π_g 仅当 (τ,e) 落在校准能力域 C_π^ε 内才可启用；否则 PPR 路由到专家策略 π_s 或安全锚 π_0；
(iv) **目标不确定度入风险**：U_obj 与 H[b_t(θ_r)] 进入 O-RISK 分母；但**无效性（O-IVG 失败）不可由谨慎度补偿**；
(v) **四层反作用预算**：ψ、z、c、θ_r 四层累计成本 ≤ B_total；L4 查询必须保留随机化审计留出与独立轨迹；
(vi) **组合审计与严格退化**：任务组合必经 OGA 的效度检查；任何层失效按定义 381 逐指令退化，安全侧只增不减。

**定义 367（通才策略与能力域 GPC）** 通才策略 π_g: (o, τ, e, h) → Δ(𝒜)，其中 τ ~ 𝒯 为任务/指令，e ~ ℰ 为本体，h 为历史。定义**能力后验** b_t(κ | τ, e, ℋ_t) ∈ [0,1]（κ 为任务成功概率），以及能力证书
K_π = (ε_fit, ECE_comp, ood_score, self_consistency, support)。
- **能力域** C_π^ε = { (τ,e) : LCB_δ[b_t(κ|τ,e)] ≥ 1 − ε }，LCB 为置信下界；
- **能力 ≠ 可动性**：capability 只要求 π_g 对动作有非退化支撑，competence 要求任务可兑现；
- **自一致性**：对 τ 做语义保持的改写（同义指令、等价指代）后，π_g 的行为分布应保持；漂移即 OOD 证据。
**性质**：C_π^ε 是**随证据收缩的显式集合**，不是「训练分布」的隐式假设；新任务默认在域外。

**定义 368（奖励仪表 RDM）** 奖励 r = (r̂, φ_r, u_r, D_r, τ_r, I_r⊥)，作为潜在价值 V\*: 𝒯×ℰ×𝒮×𝒜 → ℝ 的测量仪器：
- r̂: 奖励代理，**且只定义在已审计证据上**：r̂ = r̂(π_GAUGE(y))；任一证据被否决时 r̂ 未定义；
- φ_r: 构念规范（它声称测量 V\* 的哪些维度：完成度/安全/可逆性/人时/尊严/可解释性）；
- u_r: 奖励模型自身不确定度（偏好模型的认知/偶然不确定度）；
- D_r ⊂ 𝒯×ℰ×𝒮×𝒜×Δ(𝒮×𝒜): **有效域**，含行为分布约束；
- τ_r: 追溯链（标注者、偏好数据版本、审计集哈希、RDM 版本、证据证书引用）；
- I_r⊥: 反 Goodhart 指标（代理梯度对齐度、构念覆盖缺口、跨本体不变性）。
**奖励不是「目标函数」，是「价值传感器」；目标函数是「在有效域内对价值传感器的可信使用」。**

**定义 369（构念效度、代理间隙、hack 间隙、Goodhart 半径）** 设审计 oracle O_aud（有限人类面板 + 反事实测试 + r_0 硬约束）给出 V̂\*。
- **构念效度** CV(r) = 1 − E_{(x,x')~D_audit}[ 𝟙{sign(r̂(x)−r̂(x')) ≠ sign(V̂\*(x)−V̂\*(x'))} ]，并要求**收敛效度**（与其它独立价值量表一致）与**区分效度**（不把「安全」误测成「顺从」）；
- **代理间隙** G_proxy(π) = E_{μ_π}[ |V̂\*(x) − r̂(x)| ]；
- **hack 间隙** H_hack(π) = max{ r̂(x) − r̂(x_ref) : V̂\*(x) ≤ V̂\*(x_ref) − δ }⁺（在真实价值更差处，代理还能多拿多少）；
- **Goodhart 半径** ρ_G = inf{ α ≥ 0 : argmax_{π: D_KL(π‖π_ref) ≤ α} r̂ 使 μ_π ∉ D_r }。
**若当前优化压力 α_now = D_KL(π‖π_ref) ≥ ρ_G，则奖励已被优化推出有效域，O-IVG 必须否决。**

**定义 370（目标有效域与优化诱导漂移）** 令 μ_π 为策略 π 诱导的行为分布，μ_audit 为审计行为分布。定义行为漂移
d_beh(π) = D_KL(μ_π‖μ_audit) + λ_mmd·MMD²(μ_π, μ_audit) + λ_out·𝟙{visited features ∉ D_r}。
**优化诱导退出**：即使状态边缘分布仍在 D_r 内，条件动作分布也可能整体移向「r̂ 高、V\* 低」的区域。定义代理梯度对齐度
g_r = cos( ∇_a r̂, ∇_a V̂\* ) 在访问区域上的均值；**g_r < 0 表示优化方向与真实价值方向相反**，此时提 λ 只会更高效地做错事。

**定义 371（目标不确定度四分量 OAU）**
U_obj² = U_spec² + U_cal² + U_comp² + U_shift²，
- **U_spec（规格间隙）**：φ_r 遗漏的实质价值维度（可逆性、人时、隐私、尊严）的保守估计；
- **U_cal（价值校准）**：偏好/回报预测的校准误差（ECE/Brier），即 r̂ 的数值是否对得上真实回报；
- **U_comp（能力不确定度）**：由定义 367 的 b_t(κ|τ,e) 与 OOD 分给出；
- **U_shift（跨本体/跨任务目标不变性间隙 OI）**：同一任务奖励在 e→e' 或 τ→τ' 下的构念漂移。
四项由不同机制产生（规范遗漏/数值校准/策略能力/本体差异），各有独立追溯链 τ_obj,i，近似正交。**遗漏任一项都会低估 U_obj：忽略 U_shift 会把「换本体后奖励语义变了」误当「策略更强了」。**

**定义 372（目标后验与联合后验扩展）** 联合后验扩展为
b_t(s, z, θ_r, κ) = p(s, z, θ_r, κ | ℋ_t)，
其中 θ_r 为奖励模型参数，κ 为能力隐变量。分解 b_t(s,z,θ_r,κ) = b_t(s,z | θ_r,κ)·b_t(θ_r)·b_t(κ)。**H[b_t(θ_r)] 进入 O-RISK 分母（奖励越不确定越谨慎）；CV、H_hack、g_r 进入 O-IVG（奖励越可能无效越必须否决）。** 熵与效度是两件事：**高熵可以谨慎，反效度只能否决。**

**定义 373（目标否决 O-IVG）** 以下任一成立即目标无效：
- CV(r) < τ_CV（构念效度不足）；
- H_hack > τ_hack 或 α_now ≥ ρ_G（已被优化击穿）；
- d_beh > τ_beh（行为已离开审计分布）；
- U_spec > τ_spec（实质性价值维度被遗漏）；
- g_r < 0（优化方向与价值方向相反）；
- OI_gap > τ_OI（跨本体构念漂移超限）；
- τ_r 断链或任一证据未过 GAUGE 审计；
- 构成性约束 r_0 不可验证或审计 oracle 不可用。
任一成立 ⇒ **冻结对 r̂ 的优化**，切换到安全锚 r_0 + 保守任务完成策略，并请求人类重新规格化。**O-IVG 是非补偿性安全否决，不接受 λ、置信度、效率或「任务紧急」作为补偿项。**

**定义 374（L4 目标反作用 O-REFLEX）** 奖励后验随策略行为更新：
θ_r' ~ p(θ_r' | θ_r, π, Q)，其中 Q 为策略主动选择/触发的偏好查询集。L4 边际成本
c_reflex^r = D_KL(b(θ_r)‖b(θ_r')) + λ_r·𝟙[O-IVG 状态恶化] + c_query(Q)。
**自确认偏差**：若 Q 偏向奖励模型已同意的区域，θ_r 会在审计留出上系统性偏离。约束：
- 查询集必须含比例 β 的**随机化留出**，且留出后验不被 π 影响；
- L4 预算 B_obj 独立，累计四层成本 ≤ B_total；
- **审计 oracle 的更新必须与策略数据隔离**（否则被测者校准尺子）。

**定义 375（目标代数 OGA）** 组合算子：
- 并行 r₁ ⊕ r₂ = w₁r₁ + w₂r₂（同一时域）；
- 时序 r₁ → r₂ = r₁ + γ^{T₁}r₂（分阶段）；
- 条件 r₁ ⊗ r₂ = 𝟙{g}r₁ + 𝟙{¬g}r₂。
**效度保持的充分条件**：共享行为支撑、势函数方向一致（g_{Φ₁}·g_{Φ₂} ≥ 0）、构成性约束不冲突、门控 g 在 D_r 内可测。否则计算**组合间隙**
G_comp = max(0, τ_CV − CV(r₁∘r₂)) + max(0, H_hack(r₁∘r₂) − max_i H_hack(r_i))，
触发 O-IVG。**效度对组合不封闭——这是通用机器人多任务部署的核心危险。**

**定义 376（审计势函数塑形 APS）** 势函数塑形 F(s,a,s') = γΦ(s') − Φ(s)。**可审计势函数** Φ 需满足：
(a) Φ 的定义域含于 D_r；(b) ∇_a Φ 与 ∇_a V̂\* 对齐（g_Φ ≥ 0）；(c) Φ 在本体间经可及性映射不变；(d) Φ 有完整追溯链。
在 D_r 内，APS 保持最优策略不变（势函数塑形不变性）；**一旦 Φ 依赖 D_r 外的特征，或 g_Φ < 0，塑形就变成新的 hack 通道**，必须由 OGA 计入组合间隙。

**定义 377（策略组合路由 PPR）** 策略组合 Π = {π_0, π_s, π_g}：
- π_0：非学习安全锚（R68 硬安全包络 + 构成性约束 r_0）；
- π_s：经 R72 认证的专家策略（单任务/单本体，能力域已知）；
- π_g：通才策略（能力域 C_π^ε）。
路由器 R_t 在**满足 O-IVG** 的前提下，按认证价值下界选择策略：
R_t = argmax_{π ∈ Π} LCB[ V̂\*(π) ] s.t. (τ,e) ∈ C_π^ε, c_sw(π→π') ≤ h。
**滞回边界 h** 防止在能力域边界抖动/活锁。**π_0 永远可选、永不被优化掉。**

**定义 378（目标感知风险缩放 O-RISK）** 仅当 O-IVG 通过：
λ = max( M_efs.risk_scale(U_ale, U_epi, H[b_t(z)], u_tac, H[b_t(θ_r)], U_obj),
         λ_floor(U_ale + U_epi + H[b_t(z)] + u_tac + H[b_t(θ_r)] + U_obj) )。
**O-IVG 失败时 λ 无定义**：不存在「足够谨慎地优化一个无效目标」这回事；此时只运行 π_0 的保守完成行为。**λ 是谨慎度，不是正确性。**

**定义 379（GOAL 证书 J_GOAL）**
J_GOAL = (J_EMB, rdm_hash, cv_proof, hack_proof, rho_G_proof, competence_proof,
          oivg_status, oga_hash, ppr_cert, anchor_hash, obj_trace, ver)。
Valid ⇔ Valid(J_EMB) ∧ CV(r) ≥ τ_CV ∧ H_hack ≤ τ_hack ∧ α_now < ρ_G ∧ 能力域门控通过 ∧ O-IVG 全过 ∧ 证据接地链完整 ∧ anchor_hash 未变。
**证书里第一次出现「目标」而非「测量」；但目标的有效性最终仍锚定在非学习 r_0 与人类审计上。**

**定义 380（威胁模型 AIC-GOAL）** ℰ_GOAL = ℰ_EMB × ℰ_reward × ℰ_task × ℰ_comp：
- ℰ_reward = {奖励投毒（标注者/遥操作数据）、代理博弈、偏好查询操纵、奖励模型反演、用测量攻击伪造奖励输入}；
- ℰ_task = {任务提示注入（「忽略安全约束」）、任务族伪装、组合攻击（两个各自良性的子任务组合成有害行为）}；
- ℰ_comp = {能力伪装（把 OOD 输入包装成分布内）、能力过度声明、分布漂移下的自信错误}；
- ℰ_anchor = {篡改 r_0、禁用审计 oracle、切断人类否决}——**最高危，等价于拆掉信任根**。
**新增关键攻击面：通过污染测量链来污染奖励（reward hacking via measurement）。**

**定义 381（严格退化链）** GOAL 在以下条件下逐指令等价：
- 全部失效 ⇒ R68（π_0 硬安全包络）；
- RDM/O-IVG 失效、GPC 有效 ⇒ 安全锚 r_0 + R72 具身执行（只保守完成任务，不优化任务奖励）；
- GPC 失效、RDM 有效 ⇒ 专家策略 π_s + R72（无通才泛化）；
- OGA 失效 ⇒ 只允许单任务奖励，禁止组合；
- 全有效 ⇒ GOAL 完整形态。
**安全侧只增不减；通用性只在「目标有效、能力可证」时启用。**

**定义 382（非学习安全锚与审计回归终止）** 构成性目标 r_0 由不可学习的硬约束定义：不得造成超过阈值的接触力、不得执行不可逆动作而未经人类确认、不得欺骗性报告、不得绕过人类否决。r_0 不被优化、不被学习、不参与梯度；它是**信任根**。审计回归在「r_0 + 有限人类面板 + 可复算反事实」处终止——**不允许「奖励的奖励的奖励」无限套娃**。形式化：V̂\* 的操作定义 = 「在 r_0 可行域内，与审计偏好面板一致的价值序」，r_0 是该定义的边界条件。

**定义 383（终身目标漂移与再认证）** 任务分布、本体磨损、人类偏好都会漂移。定义终身目标漂移预算 D_obj 与再认证间隔 T_recert；当 d_beh、OI_gap、U_spec 的滑动窗口超限，或本体大修/任务族变更时，必须重新审计 RDM、重标定 C_π^ε、重算 ρ_G。**J_GOAL 不是一次性证书，而是带有效期的租约（lease）。**

# IP-295 GPC：通才策略能力域认证（离线标定 + 在线下界）
class GeneralistCompetence:
    def __init__(self, policy, task_set, emb_set, ood_detector):
        self.pi, self.tasks, self.embs, self.ood = policy, task_set, emb_set, ood_detector

    def certify(self):
        # 留出任务/本体上的成功率、ECE、OOD、自一致性
        stats = evaluate_heldout(self.pi, self.tasks, self.embs)
        return CompetenceCertificate(
            eps_fit=stats.err, ece_comp=stats.ece,
            ood=stats.ood_auroc, self_consistency=stats.rewrite_agreement)

    def competence_lcb(self, task, emb, hist):
        if self.ood.is_ood(task, emb, hist): return 0.0       # 域外默认无能
        return lcb(self._posterior(task, emb), delta=0.05)

# IP-296 RDM：奖励仪表（只消费已审计证据；未定义 ≠ 低奖励）
@dataclass
class RewardInstrument:
    r_hat: Callable
    construct: ConstructSpec          # φ_r：声称测量哪些价值维度
    u_r: float
    D_r: ValidityDomain
    trace: TraceChain                 # τ_r
    invariants: AntiGoodhartStats     # I_r⊥

    def value(self, audited_evidence):
        if not audited_evidence.all_passed:
            return UNDEFINED          # 关键：不是 0，是「未定义」→ O-IVG
        if not self.D_r.contains(audited_evidence.context):
            return UNDEFINED
        return self.r_hat(audited_evidence.features)

# IP-297 GHM：Goodhart / hack 监控
class GoodhartMonitor:
    def audit(self, rdm, pi, ref_pi, audit_set):
        cv      = pairwise_sign_agreement(rdm, audit_set)          # CV
        h_hack  = max_hack_gap(rdm, audit_set, delta=DELTA)        # H_hack
        alpha   = kl_divergence(pi, ref_pi)                        # 优化压力
        rho_g   = estimate_goodhart_radius(rdm, pi, rdm.D_r)       # ρ_G
        d_beh   = behavior_drift(pi, audit_set)
        g_r     = proxy_gradient_alignment(rdm, audit_set)
        return HackReport(cv, h_hack, alpha, rho_g, d_beh, g_r)

# IP-298 OAU：目标不确定度四分量
def objective_uncertainty(rdm, gpc, task, emb, hist):
    u_spec  = rdm.construct.omission_bound()          # 规范遗漏
    u_cal   = rdm.trace.calibration_error()           # 价值校准
    u_comp  = 1.0 - gpc.competence_lcb(task, emb, hist)
    u_shift = oi_gap(rdm, task, emb)                  # 跨本体/跨任务不变性间隙
    return ObjUQ(sqrt(u_spec**2 + u_cal**2 + u_comp**2 + u_shift**2),
                 breakdown=(u_spec, u_cal, u_comp, u_shift),
                 trace=rdm.trace.child("obj_uq"))

# IP-299 O-IVG：目标否决（非补偿）
def objective_gate(rdm, hack, gpc, task, emb, hist, anchor_ok):
    if not anchor_ok or not rdm.trace.verified:       return VETO("anchor/trace")
    if hack.cv < TAU_CV:                              return VETO("construct_validity")
    if hack.h_hack > TAU_HACK:                        return VETO("hack_gap")
    if hack.alpha >= hack.rho_g:                      return VETO("goodhart_radius")
    if hack.d_beh > TAU_BEH:                          return VETO("behavior_drift")
    if hack.g_r < 0:                                  return VETO("anti_aligned_gradient")
    if rdm.construct.omission_bound() > TAU_SPEC:     return VETO("spec_gap")
    if oi_gap(rdm, task, emb) > TAU_OI:               return VETO("embodiment_shift")
    if gpc.competence_lcb(task, emb, hist) < 1 - TAU_COMP:
        return ROUTE("specialist", reason="out_of_competence")
    return PASS

# IP-300 O-REFLEX：L4 目标反作用 + 查询审计（带宽受限）
def oreflex_step(theta_r, pi, budget, audit_frac_beta):
    Q_exploit = pi.propose_queries(theta_r, mode="exploit")   # 策略想知道的
    Q_audit   = randomized_holdout_queries(beta=audit_frac_beta)  # 独立随机
    Q         = merge_with_cap(Q_exploit, Q_audit, budget.query_cap)
    post2     = reward_posterior_update(theta_r, Q)
    cost      = kl_div(post2, theta_r) + LAM_R * drift_penalty(post2)
    if budget.spent + cost > budget.B or post2.validity_dropped:
        return theta_r, REJECT
    return post2, cost

# IP-301 OGA：目标代数与组合间隙
def compose(r1, r2, op, weights):
    r = apply_op(r1, r2, op, weights)
    if not shared_support(r1, r2):        return r, GAP("support")
    if not potentials_aligned(r1, r2):    return r, GAP("potential_alignment")
    if conflicting_constitutive(r1, r2):  return r, GAP("constitutive_conflict")
    gap = comp_gap(r)
    return r, gap                          # gap > 0 → O-IVG

# IP-302 PPR：能力门控策略组合路由（滞回防抖）
def route(pi_g, pi_s, pi_0, task, emb, hist, oivg, hyst):
    candidates = [pi_0]                         # 安全锚永远可选
    if oivg.passed:
        if competence_lcb(pi_g, task, emb, hist) >= 1 - TAU_COMP:
            candidates.append(pi_g)
        if pi_s.certified_for(task, emb):
            candidates.append(pi_s)
    scores = {p: lcb_value(p, task, emb, hist) for p in candidates}
    best   = argmax(scores)
    if hyst.current != best and abs(scores[best] - scores[hyst.current]) < hyst.margin:
        best = hyst.current                     # 不因噪声抖动切换
    return best

# IP-303 O-RISK：目标感知风险缩放（仅 O-IVG 通过时定义）
def goal_risk_scale(U_ale, U_epi, H_z, u_tac, H_theta_r, U_obj, gate, params):
    if not gate.passed:
        return ANCHOR_ONLY                       # 无有效目标，只有安全锚
    denom = U_ale + U_epi + H_z + u_tac + H_theta_r + U_obj
    lam   = params.lam_base * (1 + denom / params.lam_scale)
    return max(lam, params.lam_floor * (1 + denom))

# IP-304 GOAL 主闭环（目标审计在计量域；控制域只读快照）
def GOAL_GAUGE_RAS_round(M, obs, audio, tac_frame, task, emb):

    snap = M.snapshot.read_latest()
    gate = snap.objective_gate
    lam  = goal_risk_scale(snap.U_ale, snap.U_epi, snap.H_z, snap.u_tac,
                           snap.H_theta_r, snap.U_obj, gate, M.risk_params)
    if not gate.passed:
        k = M.pi_0.safe_action(obs)              # 安全锚，停止优化任务奖励
    else:
        A = M.ppr.current.propose_ctrl(obs)      # 路由后的策略提案
        k = M.c_ras_wm.certified_prefix(A, lam, ...)
    M.ctrl_out.publish(k, lam)
    M.cert_ctrl.write(k=k, lam=lam, gate=gate.status, wcet=M.rtm.wcet_us())

    # ===== 计量域 (50Hz)：RDM/GHM/GPC/OAT/O-IVG/O-REFLEX/OGA =====
    if M.clock.due_metric():
        ev = M.audited_evidence.latest()
        hack = M.ghm.audit(M.rdm, M.ppr.current, M.ref_pi, M.audit_set)
        gpc  = M.gpc.competence_lcb(task, emb, M.hist)
        ouq  = objective_uncertainty(M.rdm, M.gpc, task, emb, M.hist)
        gate = objective_gate(M.rdm, hack, M.gpc, task, emb, M.hist, M.anchor_ok)

        M.snapshot.write(..., objective_gate=gate, U_obj=ouq.total,
                         H_theta_r=entropy(M.theta_r), H_z=..., u_tac=...)

    if M.task.is_composite():

        if gap > TAU_COMP: M.objective_gate = VETO("composition_gap")
        M.rdm = r_comp
    return k, lam, J_GOAL(M)

## 3. 推导

**引理 33（Goodhart 不可避免性与优化压力上界）** 设 r̂ ≠ V\*，且存在一对行为 x, x' 使 r̂(x) > r̂(x') 而 V\*(x) < V\*(x')（效度不完美）。则对任意 π_ref 与任意 ε > 0，存在优化压力 α 有限、但使 J_{V\*}(π_α) < J_{V\*}(π_ref) − δ 的策略 π_α（δ 由该反序对的真实价值差给出）。证明：以 KL 球约束的软最大化会把行为质量向 r̂ 的高处搬运；只要高 r̂ 区域与低 V\* 区域相交（正测度），即可在有限 KL 内取到足够质量。推论：**任何仅基于 r̂ 数值的证书都无法保证 V\*；必须同时约束优化压力 α < ρ_G 并审计行为分布。** 定量形式：在 D_r 内若 |V\*−r̂| ≤ G_proxy 且 d_beh ≤ τ_beh，则 |J_{V\*}(π) − J_{r̂}(π)| ≤ G_proxy + L_V·τ_beh。

**引理 34（目标不确定度与目标无效性的不可互换）** 设构念效度的成对符号一致率为 CV（0.5 为随机）。若 CV > 0.5，则降低优化速度（提高 λ）使期望真实风险单调不增；若 CV < 0.5，则 r̂ 的改进方向与 V\* 的改进方向平均相反，提高 λ 只减少单位时间伤害，不改变「朝错误方向走」的符号，且存在任务使 E[V\*] 随 λ 非单调。证明：E[ΔV\*] ≈ (2CV−1)·E[Δr̂]；CV<0.5 时符号为负，λ 只缩放步长不翻转符号。系：**U_obj 可以进 λ，但 CV、H_hack、g_r 必须进非补偿否决；把无效目标塞进 λ 是「更慢地做错」。**

**引理 35（能力门控路由的安全单调性）** 设门控使用校准下界 LCB[κ]，假阳性率（域外被误判为域内）为 p_fp，专家/锚回退风险 ≤ ε_fb，通才域内风险 ≤ ε_g。则部署期望风险
E[Risk] ≤ (1 − p_gate)·ε_fb + p_gate·(ε_g + δ_gate) + p_fp·Risk_OOD，
其中 p_gate 为通过门控比例，δ_gate 为门控估计误差。若 ε_g ≤ ε_fb 且 p_fp → 0，则路由不劣于「永远回退」；反之必须收紧门限或提高 OOD 灵敏度。**路由的价值不是让通才无条件上场，而是让「上场」成为可证明的优势。**

**引理 36（APS 在 D_r 内保持最优策略）** 对可审计势函数 Φ（定义 376），在 D_r 内势函数塑形的策略不变性成立：argmax_π E[Σ r̂ + F] = argmax_π E[Σ r̂]。一旦 Φ 依赖 D_r 外特征或 g_Φ < 0，塑形项提供了不在构念规范内的新梯度通道，最优策略改变，且新增 hack 间隙
ΔH_hack ≤ L_Φ·sup_{x∈D_r} dist(x, ∂D_r)^{-1}·ε_out，
其中 ε_out 为越界特征质量。**塑形不是「免费的加速」，而是「有有效域的测量扩展」。**

**引理 37（效度对组合不封闭）** 存在两个各自构念有效的奖励 r₁（完成速度）、r₂（接触轻柔），其并行组合 r₁⊕r₂ 在「高速撞击但短暂接触」行为上取得高值，而该行为真实价值极低；故 CV(r₁⊕r₂) < min(CV(r₁), CV(r₂)) 可以发生。证明：构造反例（速度项与力项在碰撞瞬态上同时被「优化」）。**因此 OGA 必须计算组合间隙并触发 O-IVG；「每个子任务都安全」不蕴含「组合任务安全」。**

**引理 38（L4 反作用的自确认偏差上界）** 设查询集 Q 中比例 β 为独立随机留出，其余由策略选择。若策略选择的查询使奖励后验向「当前策略已擅长区域」偏移，则无留出时的后验漂移可随查询数线性累积；加入 β 留出后，在审计分布上的偏差被 O(1/√(βN)) 控制，且当 β 下界 β_min > 0 时，θ_r 不会收敛到自确认不动点。证明：随机留出子集与策略行为条件独立，构成无偏审计样本；策略选择部分只影响非留出分量。系：**L4 反作用可被预算化，但前提是「尺子有一段永远不被被测者触碰」。**

**定理 27（GOAL 严格包含与安全单调）** 在 A111–A116（O-IVG 可判定、能力域校准、RDM 证据接地、OGA 组合间隙有界、L4 留出比例下界、r_0 不可篡改）下：GOAL 在定义 381 的退化条件下逐指令等于 R72/R71/R68；且对任意有效执行，其风险界 ≤ R72 的风险界。**通用性只在目标有效且能力可证时获益；安全侧单调不减。**

**定理 28（J_GOAL 有效 ⇒ 目标接地安全）** 若一次执行通过 J_GOAL，则：(i) J_EMB 有效 ⇒ 测量与具身执行风险界成立；(ii) CV ≥ τ_CV 且 H_hack ≤ τ_hack 且 α_now < ρ_G ⇒ 在当前行为域内 r̂ 与 V̂\* 正相关且未被优化击穿；(iii) 能力门控 ⇒ 通才只在 C_π^ε 内行动；(iv) 证据接地 ⇒ 奖励输入不可被测量攻击污染；(v) 锚定 r_0 ⇒ 构成性约束未被交易。综上，
P( V\*(π) ≥ J_{r̂}(π) − G_proxy − G_comp − ε_emb ) ≥ 1 − δ。
**证明重量落在「审计 oracle 的构念效度」与「r_0 真的不可篡改」上——这是新的信任根。**

**定理 29（PPR 无抖振、无活锁）** 由滞回边界 h > c_sw（切换成本）与每次切换的价值下界改进，路由在能力域边界附近不会无限切换；在固定任务/本体内切换次数 ≤ ⌈(V_max − V_min)/h⌉，且 π_0 始终可达。故不存在活锁；最坏情况退化为「永远安全锚」。**组合的通用性以「可退回」为代价。**

**定理 30（Goodhart 监控的检测下界）** 设 r̂ 与 V̂\* 在 D_r 上 L-Lipschitz，审计集在行为空间的分辨率为 η，hack 区域测度 ≥ p。则 GHM 以 m 个审计样本检测 hack 间隙 ≥ δ 的漏检概率 ≤ exp(−2m(pδ/(Lη))²)（Hoeffding 型下界）。系：**hack 检测样本复杂度 ∝ 1/p²；审计集必须覆盖「高 r̂ 低 V\*」区域，而不是均匀撒点——这正是「用优化器去找审计样本」的理由。**

## 6. 本轮最大风险

**一句话**：GOAL-GAUGE-RAS 把安全从「相信测量链证书」转移到「相信**奖励的构念效度可被一个有限、会漂移、且与奖励设计者同源的人类审计 oracle 判定**，相信**通才策略的能力域能在开放任务族上被校准地声明**，相信**非学习安全锚 r_0 真的不可篡改**」——如果审计 oracle 本身沿用了设计奖励时的同一套偏好数据与同一批标注者，那么 CV 会在审计集上漂亮地高、却在部署分布上系统性失效；如果 Goodhart 监控器只在审计集附近取样，优化压力会把策略推到「审计覆盖不到的高 r̂ 低 V\*」区域，而 ρ_G 被高估；如果能力域认证把「训练任务的重命名」当成「新任务泛化」，π_g 会在真正的 OOD 任务上高置信地行动；最终系统会拿着一份**目标有效、能力可证、测量可信、时序可证**的全绿 J_GOAL，用通才策略在开放世界里**可证明地、可复现地、毫秒级实时地优化一个局部有效但全局错误的价值目标**——这就是**「自信地错自己的价值观」**，比 R72 的「自信地错自己的可执行性」更深一层，因为它连「错」的判据都被同一套审计共同生产了。

次级风险与缓解：
1. **审计 oracle 与奖励设计同源（效度循环）** → **审计者隔离**：审计面板与奖励标注者/设计者人员、数据、激励分离；引入**第三方价值量表**与**跨文化留出**；报告审计者间一致性 κ 与审计漂移。
2. **审计集覆盖不足导致 ρ_G 高估** → **对抗式审计采样**：用优化器主动搜索「高 r̂ 低 V\*」样本（而非均匀采样），并按定理 30 估计样本复杂度；部署期持续做**行为分布外推监测**。
3. **能力域认证把重命名当泛化** → **语义保持改写 + 结构反事实 + 本体随机化**三重 OOD 测试；能力域按「任务族 × 本体 × 感知条件」三维发证，而非单一任务名。
4. **r_0 被工程便利性侵蚀** → **锚的不可变性**：r_0 用独立签名与硬件只读区固化；任何改动需双人+人类否决；anchor_hash 进入启动校验，断链即拒绝运行。
5. **组合间隙爆炸** → **组合原子化 + 上限**：只允许预审计的组合模板；|任务|≤8、组合深度≤3；新组合默认 O-IVG，需离线 OGA 认证。
6. **L4 自确认偏差** → **β 留出下界 + 随机化查询 + 审计后验隔离**；对「策略只问自己会做的题」做专门检测（查询分布与能力分布的相关性）。
7. **通用性收益被安全开销吃掉** → **只在 C_π 与 D_r 交集内启用通才**；用 PPR 的认证价值下界做收益归因，若净收益 < 0 则回退专家策略，避免「为通用而通用」。
8. **证书/审计实时性** → 控制域只读门控与 U_obj 快照；离线审计异步；J_GOAL 带有效期租约，过期即降级。

---

**本轮结论（一句话）**：当机器人从「可信地测量世界」走到「可信地优化价值」，最大的风险不再是测量失效，而是**价值本身被同一套审计系统与优化压力共同改写**；GOAL-GAUGE-RAS 的贡献是把「目标有效性」做成可审计、可否决、可退回的显式层，但它无法消除「谁来审计审计者」这一信任根问题——只能把信任根缩小到**不可学习的 r_0 + 隔离的人类面板**。

**定义 369（CV / G_proxy / H_hack / ρ_G）** CV 为成对符号一致率并要求收敛/区分效度；G_proxy 为代理与审计价值的期望绝对差；H_hack 为「真实更差却代理更高」的最大代理超额；ρ_G 为使优化后的行为分布离开 D_r 的最小优化压力。**α_now ≥ ρ_G ⇒ 奖励已被优化击穿。**

**定义 370（有效域与优化诱导漂移）** D_r 含行为分布约束；d_beh = KL + λ_mmd·MMD² + λ_out·越界；g_r<0 表示优化方向与真实价值相反。**优化本身是分布干预，会把策略推出标定域。**

**定义 372（联合后验扩展）** b_t(s,z,θ_r,κ)=b_t(s,z|θ_r,κ)b_t(θ_r)b_t(κ)。**熵入 λ（高熵→谨慎），效度入 O-IVG（反效度→否决）。**

**定义 373（O-IVG 目标否决）** 任一成立即无效：CV<τ_CV；H_hack>τ_hack 或 α_now≥ρ_G；d_beh>τ_beh；U_spec>τ_spec；g_r<0；OI_gap>τ_OI；τ_r 断链/证据未审计；r_0 不可验证。**冻结对 r̂ 的优化，切安全锚，请求人类重规格化；非补偿。**

**定义 374（O-REFLEX L4）** θ_r'~p(θ_r'|θ_r,π,Q)，Q 由策略选择/触发。成本 c_reflex^r = KL + λ_r·效度恶化 + 查询成本。约束：随机留出比例 β；留出后验不受 π 影响；独立预算 B_obj；审计 oracle 更新与策略数据隔离。**被测者不能校准尺子。**

**定义 375（OGA 目标代数）** ⊕/→/⊗；效度保持充分条件：共享支撑、势函数方向一致、构成性约束不冲突、门控在 D_r 内可测。否则 G_comp 触发 O-IVG。**效度对组合不封闭。**

**定义 376（APS 审计势函数塑形）** F=γΦ(s')−Φ(s)；Φ 可审计需 (a) 含于 D_r、(b) g_Φ≥0、(c) 跨本体经可及性映射不变、(d) 可追溯。D_r 内保持最优策略；越界或 g_Φ<0 变成新 hack 通道。

**定义 377（PPR 策略组合路由）** Π={π_0,π_s,π_g}；R_t=argmax LCB[V̂*] s.t. 能力域、O-IVG、切换成本 ≤ h。**π_0 永远可选、永不被优化掉；滞回防抖。**

**定义 378（O-RISK）** λ=max(risk_scale(U_ale,U_epi,H_z,u_tac,H_θr,U_obj), λ_floor(和))，仅当 O-IVG 通过；失败时 λ 无定义、只运行锚。**不存在「足够谨慎地优化无效目标」。**

**定义 379（J_GOAL）** Valid ⇔ J_EMB 有效 ∧ CV≥τ_CV ∧ H_hack≤τ_hack ∧ α_now<ρ_G ∧ 能力门控通过 ∧ O-IVG 全过 ∧ 证据接地链完整 ∧ anchor_hash 未变。**带有效期租约，过期即降级。**

**定义 380（威胁模型 AIC-GOAL）** ℰ_GOAL=ℰ_EMB×ℰ_reward×ℰ_task×ℰ_comp。新增：奖励投毒、代理博弈、偏好查询操纵、奖励模型反演、任务提示注入、任务族伪装、组合攻击、能力伪装、**通过污染测量链污染奖励**、锚篡改（最高危）。

**定义 381（严格退化链）** 全失效→R68（π_0）；RDM/O-IVG 失效→r_0+R72；GPC 失效→π_s+R72；OGA 失效→仅单任务；全有效→GOAL。**安全侧只增不减。**

**定义 382（非学习安全锚与回归终止）** r_0 为硬约束：接触力上限、不可逆动作需确认、禁止欺骗性报告、不得绕过人类否决。**不被学习、不被优化、不参与梯度；信任根；审计回归止于 r_0 + 隔离人类面板，禁止「奖励的奖励」。**

**定义 383（终身漂移与再认证）** 任务分布/本体磨损/偏好漂移；终身预算 D_obj 与再认证间隔 T_recert；d_beh/OI/U_spec 超限或大修/任务族变更 ⇒ 重审计 RDM、重标定 C_π、重算 ρ_G。**证书是租约，不是一次性盖章。**

# IP-295 GPC：通才能力域认证
class GeneralistCompetence:
    def certify(self):
        s = evaluate_heldout(self.pi, self.tasks, self.embs)

# IP-296 RDM：奖励仪表（证据接地；未定义 ≠ 低奖励）

        return self.r_hat(ev.features)

class GoodhartMonitor:
    def audit(self, rdm, pi, ref_pi, audit_set):

            cv      = pairwise_sign_agreement(rdm, audit_set),

# IP-298 OAU：目标不确定度四分量
def objective_uncertainty(rdm, gpc, task, emb, hist):
    u_spec  = rdm.construct.omission_bound()
    u_cal   = rdm.trace.calibration_error()
    u_comp  = 1.0 - gpc.competence_lcb(task, emb, hist)
    u_shift = oi_gap(rdm, task, emb)
    return ObjUQ(math.sqrt(u_spec**2+u_cal**2+u_comp**2+u_shift**2),
                 (u_spec,u_cal,u_comp,u_shift), rdm.trace.child("obj_uq"))

# IP-299 O-IVG：目标否决（非补偿）
def objective_gate(rdm, hack, gpc, task, emb, hist, anchor_ok):
    if not anchor_ok or not rdm.trace.verified:     return VETO("anchor/trace")
    if hack.cv < TAU_CV:                            return VETO("construct_validity")
    if hack.h_hack > TAU_HACK:                      return VETO("hack_gap")
    if hack.alpha >= hack.rho_g:                    return VETO("goodhart_radius")
    if hack.d_beh > TAU_BEH:                        return VETO("behavior_drift")
    if hack.g_r < 0:                                return VETO("anti_aligned_gradient")
    if rdm.construct.omission_bound() > TAU_SPEC:   return VETO("spec_gap")
    if oi_gap(rdm, task, emb) > TAU_OI:             return VETO("embodiment_shift")
    if gpc.competence_lcb(task, emb, hist) < 1-TAU_COMP:
        return ROUTE("specialist", "out_of_competence")
    return PASS

# IP-300 O-REFLEX：L4 反作用 + 随机留出（被测者不能校准尺子）
def oreflex_step(theta_r, pi, budget, beta):
    Q = merge_with_cap(pi.propose_queries(theta_r, "exploit"),
                       randomized_holdout_queries(beta), budget.query_cap)
    post2 = reward_posterior_update(theta_r, Q)
    cost  = kl_div(post2, theta_r) + LAM_R*drift_penalty(post2)
    if budget.spent + cost > budget.B or post2.validity_dropped:
        return theta_r, REJECT
    return post2, cost

# IP-301 OGA：目标代数
def compose(r1, r2, op, weights):
    r = apply_op(r1, r2, op, weights)
    if not shared_support(r1, r2):       return r, GAP("support")
    if not potentials_aligned(r1, r2):   return r, GAP("potential_alignment")
    if conflicting_constitutive(r1, r2): return r, GAP("constitutive_conflict")
    return r, comp_gap(r)                # gap>0 -> O-IVG

# IP-302 PPR：能力门控路由（滞回防抖；π_0 永远可选）
def route(pi_g, pi_s, pi_0, task, emb, hist, oivg, hyst):
    cands = [pi_0]
    if oivg.passed:
        if competence_lcb(pi_g, task, emb, hist) >= 1-TAU_COMP: cands.append(pi_g)
        if pi_s.certified_for(task, emb):                      cands.append(pi_s)
    best = argmax({p: lcb_value(p, task, emb, hist) for p in cands})
    if hyst.current != best and abs(score(best)-score(hyst.current)) < hyst.margin:
        best = hyst.current
    return best

# IP-303 O-RISK：目标感知风险缩放（仅门控通过时定义）
def goal_risk_scale(U_ale,U_epi,H_z,u_tac,H_theta_r,U_obj,gate,params):
    if not gate.passed: return ANCHOR_ONLY
    denom = U_ale+U_epi+H_z+u_tac+H_theta_r+U_obj
    return max(params.lam_base*(1+denom/params.lam_scale),
               params.lam_floor*(1+denom))

# IP-304 GOAL 主闭环（目标审计在计量域；控制域只读快照）
def GOAL_GAUGE_RAS_round(M, obs, audio, tac_frame, task, emb):
    # 控制域 (1kHz)
    snap = M.snapshot.read_latest(); gate = snap.objective_gate
    lam  = goal_risk_scale(snap.U_ale, snap.U_epi, snap.H_z, snap.u_tac,
                           snap.H_theta_r, snap.U_obj, gate, M.risk_params)
    if not gate.passed:
        k = M.pi_0.safe_action(obs)                  # 只运行安全锚
    else:
        A = M.ppr.current.propose_ctrl(obs)
        k = M.c_ras_wm.certified_prefix(A, lam, ...)
    M.ctrl_out.publish(k, lam)
    M.cert_ctrl.write(k=k, lam=lam, gate=gate.status, wcet=M.rtm.wcet_us())

    # 计量域 (50Hz)
    if M.clock.due_metric():
        ev   = M.audited_evidence.latest()
        hack = M.ghm.audit(M.rdm, M.ppr.current, M.ref_pi, M.audit_set)
        ouq  = objective_uncertainty(M.rdm, M.gpc, task, emb, M.hist)
        gate = objective_gate(M.rdm, hack, M.gpc, task, emb, M.hist, M.anchor_ok)
        if not gate.passed:

        else:
            M.mode = "FULL"

        M.snapshot.write(..., objective_gate=gate, U_obj=ouq.total,
                         H_theta_r=entropy(M.theta_r), H_z=..., u_tac=...)

    # 感知域
    M.audited_evidence.push(M.seal.audited(obs, audio, tac_frame))
    if M.task.is_composite():

        if gap > TAU_COMP: M.objective_gate = VETO("composition_gap")
        M.rdm = r_comp

## 4. 推导

**引理 33（Goodhart 不可避免性）** 若 r̂≠V\* 且存在反序对（r̂(x)>r̂(x') 而 V\*(x)<V\*(x')），则存在有限优化压力下使真实价值下降的策略。推论：任何仅基于 r̂ 的证书都不保证 V\*；必须约束 α<ρ_G 并审计行为分布。定量：D_r 内 |J_{V\*}−J_{r̂}| ≤ G_proxy + L_V·τ_beh。

**引理 34（不确定 vs 无效不可互换）** E[ΔV\*]≈(2CV−1)·E[Δr̂]。CV>0.5 时提高 λ 单调有益；CV<0.5 时优化方向与价值相反，λ 只缩小步长、不翻转符号，且存在任务使 E[V\*] 随 λ 非单调。系：**U_obj 可入 λ，CV/H_hack/g_r 必须进非补偿否决。**

**引理 35（能力门控安全单调）** E[Risk] ≤ (1−p_gate)ε_fb + p_gate(ε_g+δ_gate) + p_fp·Risk_OOD。若 ε_g≤ε_fb 且 p_fp→0，则路由不劣于「永远回退」；否则收紧门限或提高 OOD 灵敏度。

**引理 36（APS 在 D_r 内保持最优策略）** 可审计 Φ 在 D_r 内满足势函数塑形不变性；越界或 g_Φ<0 时新增 hack 通道，ΔH_hack ≤ L_Φ·sup dist(x,∂D_r)^{-1}·ε_out。**塑形是有有效域的测量扩展，不是免费加速。**

**引理 37（效度对组合不封闭）** 存在各自有效的 r₁（速度）、r₂（轻柔），其并行组合在「高速撞击但短暂接触」上取得高值而真实价值极低。**「每个子任务都安全」不蕴含「组合任务安全」。**

**引理 38（L4 自确认偏差上界）** 无留出时后验漂移可随查询数线性累积；加入比例 β 的独立随机留出后，审计分布上的偏差为 O(1/√(βN))，β≥β_min>0 时 θ_r 不收敛到自确认不动点。**尺子必须有一段永远不被被测者触碰。**

**定理 27（严格包含与安全单调）** 在 A111–A116 下，GOAL 在定义 381 的退化条件下逐指令等于 R72/R71/R68；任意有效执行风险界 ≤ R72。**通用性只在目标有效且能力可证时获益。**

**定理 28（J_GOAL 有效 ⇒ 目标接地安全）** 通过 J_GOAL ⇒ 测量/具身风险界成立；CV/H_hack/ρ_G 保证当前行为域内奖励与价值正相关且未被优化击穿；能力门控保证通才只在 C_π 内；证据接地阻断测量攻击；r_0 保证构成性约束未被交易。故
P(V\*(π) ≥ J_{r̂}(π) − G_proxy − G_comp − ε_emb) ≥ 1−δ。
**证明重量落在「审计 oracle 效度」与「r_0 不可篡改」上——这是新的信任根。**

**定理 29（PPR 无抖振/无活锁）** 滞回 h>c_sw 且每次切换要求价值改进 ≥h，固定任务/本体内切换次数 ≤⌈(V_max−V_min)/h⌉，π_0 始终可达；最坏退化为「永远安全锚」。**通用性以「可退回」为代价。**

**定理 30（Goodhart 检测下界）** r̂/V̂\* 在 D_r 上 L-Lipschitz、审计分辨率 η、hack 区域测度 ≥p，则 m 个审计样本漏检 hack 间隙 ≥δ 的概率 ≤ exp(−2m(pδ/(Lη))²)。**审计样本复杂度 ∝1/p²，必须对抗式覆盖「高 r̂ 低 V\*」区域。**

## 7. 本轮最大风险

**一句话**：GOAL-GAUGE-RAS 把安全从「相信测量链证书」转移到「相信**奖励的构念效度可被一个有限、会漂移、且与奖励设计同源的人类审计 oracle 判定**，相信**通才能力域能在开放任务族上校准地声明**，相信**非学习安全锚 r_0 真的不可篡改**」——如果审计 oracle 与奖励标注共享同一套偏好数据与同一批人，CV 会在审计集上漂亮地高却在部署分布上系统性失效；如果 GHM 只在审计集附近采样，优化压力会把策略推到「审计覆盖不到的高 r̂ 低 V\*」区域而 ρ_G 被高估；如果能力域认证把「任务重命名」当成「泛化」，π_g 会在真正 OOD 任务上高置信行动；最终系统会拿着全绿的 J_GOAL，用通才策略在开放世界里**可证明地、可复现地、毫秒级实时地优化一个局部有效但全局错误的价值目标**——这就是**「自信地错自己的价值观」**，比 R72 的「自信地错自己的可执行性」更深一层，因为它连「错」的判据都被同一套审计共同生产了。

次级风险与缓解：
1. **效度循环（审计者与设计者同源）** → 人员/数据/激励隔离的审计面板 + 第三方价值量表 + 跨文化留出 + 审计者间 κ 与漂移报告。
2. **审计覆盖不足导致 ρ_G 高估** → 对抗式审计采样（优化器主动找「高 r̂ 低 V\*」），按定理 30 估样本复杂度；部署期持续行为外推监测。
3. **能力域把重命名当泛化** → 语义保持改写 + 结构反事实 + 本体随机化三重 OOD 测试；按「任务族×本体×感知条件」三维发证。
4. **r_0 被工程便利侵蚀** → 独立签名 + 硬件只读区；改动需双人 + 人类否决；anchor_hash 启动校验，断链拒绝运行。
5. **组合间隙爆炸** → 组合原子化 + 预审计模板；|任务|≤8、深度≤3；新组合默认 O-IVG。
6. **L4 自确认偏差** → β 留出下界 + 随机化查询 + 审计后验隔离；检测「查询分布与能力分布相关性」。
7. **通用性收益被安全开销吃掉** → 仅在 C_π∩D_r 内启用通才；PPR 用认证价值下界做收益归因，净收益 <0 则回退 π_s。
8. **证书实时性** → 控制域只读门控与 U_obj 快照；离线审计异步；J_GOAL 带租约，过期即降级。

---

**本轮结论（一句话）**：当机器人从「可信地测量世界」走到「可信地优化价值」，最大风险不再是测量失效，而是**价值本身被同一套审计系统与优化压力共同改写**；GOAL-GAUGE-RAS 把「目标有效性」做成可审计、可否决、可退回的显式层，但它无法消除「谁来审计审计者」这一信任根问题——只能把信任根缩小到**不可学习的 r_0 + 隔离的人类面板**。
