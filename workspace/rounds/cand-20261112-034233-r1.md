# 第 58 轮（承接第 57 轮 IP-133~138「少样本×跨模态×个性化」；灵感循环第 4 轮；本轮灵感：「课程学习」×「意图识别」）

> 第 57 轮把安全的赌注从"模型置信"移到"证据承诺"，再用少样本摊销、跨模态对账、个性化有界加了三层护栏；但它留下的问题其实共享一个盲点：**系统从未显式决定"先学什么、该在哪一层建立自信"，也从未显式表示"人说的到底是哪一个命题"**。**课程学习**说：经验的组织顺序本身塑造泛化与校准——于是探针不再按地图均匀铺开，而是按难度分层、由易到难地建立校准，每次"升层"都要通过留出的突击审计；课程只改"去哪、先探什么"，绝不改"多少证据算够"。**意图识别**说：人的确认不是关于世界的直接证据，而是关于"人所欲确认的命题 φ"的证据——于是人类证据升级为意图条件证据，歧义高时优先"问人"而非继续探世界，不可逆接触必须先把 φ 澄清。核心命题由"证据说可信"升级为 **"按安全顺序获取、指向被正确澄清的意图、且不越权的证据，才说可信"**：课程给效率、意图给语义，二者都只走"重排顺序 / 显式不确定性 / 更保守动作"的通道。

核心矛盾：
- **H29（课程 vs 校准）**：由易到难能加速校准，但"易"由元模型的难度估计定义；若"看起来易"恰是语料外的新世界，课程会在最不该自信处系统性少探针，且这种错误跨区域相关，不是单点。
- **H30（意图 vs 证据）**：确认的价值取决于"确认的是什么"；意图是证据链上新插入的隐变量，一旦认错，人的诚实与校准救不了世界证据——把意图置信当世界证据，等于把"我听懂了"当成"世界安全"。
- **H31（意图的博弈面）**：意图可从语言/凝视/行为推断，也就可以被表演；若"意图-行为一致"能升授权，"先表演一致、再滥用"就是第 57 轮授权养成攻击的新变种。

## 0. 直觉与动机

**灵感 1（课程学习 → 课程化证据获取 CEC）**
直觉：不是所有探针等价。区域有难度——新颖度、共形带宽度、跨模态分歧、与元语料的相似度共同定义一个难度序。先在最容易校准的层把元推断器的 ECE 压到阈值以下，再逐层"升班"；省下来的探针预算不是拿走，而是**转移给更难层**。关键纪律：课程是**排序启发式**，不是证据政策——对任何实际用到的证据集，证据门判定与无课程时完全相同；课程只能说"先探这里"，不能说"这里够了"。

**灵感 2（反课程审计 ACA）**
直觉：由易到难最大的副作用，是"用简单世界训练出的自信去打困难世界"。必须定期插入**突击考试**：留出的困难/对抗样本（伪装表面、歧义指令、罕见材质），考试集轮换、与升层决策隔离。若难易泛化差距过大，课程立即降级、退回第 57 轮共形保底带、并提高 θ_voi（更愿意探），而不是继续升层。

**灵感 3（意图识别 → IRM + 意图探针）**
直觉：人说的、指的、看的、做的可能指向四个不同命题。系统应显式维护意图假设后验 b_i（目标/指代/范围/紧迫性/可逆性），度量歧义 A_I 与边际 m_I；歧义高时最划算的动作往往不是再探世界，而是**澄清**——问一句、指一下、让人演示一遍。意图解码器按难度与人群分层校准，且它的置信只回答"我是否听懂"，不回答"世界是否安全"。

**灵感 4（意图条件证据门 ICEG + 意图-行为账本 ICL）**
直觉：人类证据只在"φ 被正确识别且被明确记录"时才算数——账本记的是命题，不是"ok"。再用"声明意图 vs 显露行为"的一致性做早期误解与胁迫检测；但一致性只能**降权/触发澄清**，不能升权、不能降低证据要求，否则又回到可表演的信任通胀。

**灵感 5（合流 → PCE++：双通道 VOI）**
直觉：每个检查点有两种可买的信息——世界信息与意图信息。VOI 分解为 VOI_world 与 VOI_intent，选边际收益大者；意图未决时不可逆接触被硬性禁止；课程决定访问顺序，审计决定能否升层，意图决定证据指向哪个命题。三者都经"信念更准 / 动作更保守"两个安全通道起作用。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（课程化证据获取 CEC）** 难度 d(r,π)=g(n_ood(r), |C_cf(r)|, D(r), 1−sim(z_r,𝒟_meta))∈[0,1]；分层 S_1≺…≺S_L。课程是受限排序 σ 与预算切分 {B_l}，满足：(C1) 总预算不变 ΣB_l≤B；(C2) **门不变性**：∀ 证据集 E，Gate_σ(E)=Gate_base(E)；(C3) **升层门** promote(S_l→S_{l+1}) ⇔ ECE_l≤ε_l ∧ cov_l≥1−α_l ∧ ACA_l=pass；(C4) 每区域达到门限即停（satisficing），结余转高难层。证书 C_cur=(σ,{S_l},{B_l},{promote_l},audit_log)。

**定义 140（反课程审计 ACA）** 考试分布 𝒟_exam 与部署难层重叠但**留出、轮换、操作者不可预知**；H={伪装表面, 歧义指令, 罕见材质}。泛化差距 G(σ)=Risk(S_hard|σ)−Risk(S_easy|σ)。规则：(A1) G≤θ_g 才可升层；(B1) 训练/考试样本隔离，任何人不得用考试集既调参又计分；(C1) 审计失败 ⇒ 课程降级 + 回退共形带 + θ_voi↑；(D1) 审计只可保守化参数，不得放宽证据门。

**定义 141（意图识别 IRM）** 意图 i=(g,ref,scope,urg,rev)∈ℐ；观测通道 O_I={speech,gesture,gaze,demo,timing,prior}；后验 b_i=q_ψ(i|o_I,z,s_o)；歧义 A_I=H(b)/log|ℐ|，边际 m_I=b_(1)−b_(2)，命题 φ=decode(argmax b_i)。校准契约：∀层 l，ECE_I,l≤ε_I(l)，漏报歧义率≤δ_amb。意图差距 P_misintent=P(φ≠φ*)。风险分离：P(fail|E)=P(world fails|E,φ)+P_misintent·1[action depends on φ]+高阶，**意图置信不进入世界似然**。

**定义 142（意图条件证据门 ICEG）** EV-intent 细化 EV-human：有效 ⇔ (I1) m_I≥θ_m(l) ∧ A_I≤θ_A(l)；(I2) 解码器在该层/人群校准且非 OOD；(I3) 账本记录完整 φ 与渲染模态 m_E；(I4) ICL 检查非"矛盾"（矛盾只可降权/澄清）。硬规则：不可逆接触需 m_I≥θ_m^irr 且显式确认 φ，否则澄清/L2/安全停。证书 J_c 扩展 J_p：(curriculum_log,strata,promotion_audits,intent_log,intent_cal_log,ambiguity_trace,clarification_log,consistency_ledger,intent_consent_log)。

**定义 143（课程-意图联合探询 CCIP / PCE++）** 每检查点：①课程层定位；②元推断+跨模态对账（第 57 轮）；③意图推断（b_i,A_I,m_I,φ）；④双通道 VOI：VOI_world(π) 与 VOI_intent(χ)=E[风险降幅|澄清]−cost，若 A_I>θ_A 且 VOI_intent≥θ_vi 先澄清；⑤承诺 ⇔ FSE ∧ ICEG ∧ ∃g:R≤δ_f；否则 reroute→协商→安全停。终止：每检查点探针 ≤k_p+k_c+k_i。

**定义 144（意图-行为一致性账本 ICL）** 声明轨迹 Φ_t={φ_τ}，行为轨迹 B_t={命令,修正,覆盖,时延,凝视}；一致性 I_t=sim(Φ_t,B_t)。规则：(a) I_t<θ_I ⇒ A_I↑、触发澄清、入审计；(b) I_t 高**不**提高 auth、**不**降低证据要求（单向）；(c) 持续不一致归因于{误解,胁迫,意图漂移}，进入 L2 或安全停；(d) 全量入账，供复盘与元训练，但复盘样本与考试集隔离。

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| CEC | O(\|CP\|log\|CP\|) | O(\|CP\|) | 门不变性、升层需审计 |
| ACA | O(\|H\|·C_risk) | O(\|H\|) | 考试留出/轮换/隔离 |
| IRM | O(d_ψ)/次 | O(\|ℐ\|) | 分层校准、歧义诚实 |
| ICEG | O(1) | O(\|φ\|) | 意图非放大、不可逆硬门 |
| ICL | O(1)+O(H_op) | O(H_op) | 一致性单向（只降不升） |
| PCE++ | +O(k_i·d_ψ) | O(\|V\|+\|σ\|) | 双 VOI、k_p+k_c+k_i 终止 |

**正确性定理（CICS 概要）**：在 A33–A40 之上加 (A41) 课程仅排序/切预算、门不变、升层过审且共形覆盖保持；(A42) 反课程考试与部署难层重叠且留出轮换（漏考率≤δ_cur）；(A43) 意图解码分层校准 ECE_I≤ε_I 且歧义漏报≤δ_amb；(A44) 意图-行为一致性单向（不升权、不降证据要求），意图置信不入世界似然。则：(i) P(fail) ≤ δ_f+ε_meta(k)+ε_I(l)+δ_probe+ε_h+δ_ood·α_conf+δ_xm·1[L1]+δ_cur；(ii) **课程不增险**：任何课程序下，给定同一证据集的安全性与基序相同，排序只影响成本；(iii) **意图可分离**：无论世界证据多强，意图未决即触发澄清/停，误意图风险不可被高世界置信掩蔽；(iv) PCE++ 在 k_p+k_c+k_i 内终止。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 课程 easy-first 过自信 | 高 | 门不变性 + 升层审计 + ACA + 回退共形带 |
| 意图解码自信但错 | 高 | 分层校准 + 歧义显式 + 不可逆意图硬门 + 澄清 |
| 意图推断越界/隐私 | 中高 | 最小观测通道、任务内推断、可关闭、全审计 |
| 澄清负担与操作者疲劳 | 中 | VOI 门控、批量澄清、自适应阈值；不可逆下限不降 |

## 6. 本轮最大风险

**一句话**：本轮真正的新攻击面不是单点错误，而是**全局相关的元错误**——课程用"难度估计"决定先信哪里，意图识别用"意图后验"决定证据指向哪个命题；二者都是对隐变量的自信推断，一旦难度估计把"看似易的新世界"归入易层，或意图解码器在某一类人群/指令上系统性认错，错误会通过排序与澄清策略**跨检查点、跨会话地同向放大**，比第 57 轮的局部坏证据更难被事后证伪；护栏必须是"课程只排序不改门、意图只澄清不放大、不可逆接触意图硬门、审计留出且轮换、所有隐变量推断单向保守"。

### IP-139 CEC（课程化证据获取）

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CEC | O(\|CP\|log\|CP\|) | O(\|CP\|) | 门不变性、升层需审计（A41） |
| ACA | O(\|H\|·C_risk) | O(\|H\|) | 考试留出/轮换/隔离（A42） |
| IRM | O(d_ψ)/次 | O(\|ℐ\|) | 分层校准、歧义漏报≤δ_amb（A43） |
| ICEG | O(1) | O(\|φ\|) | 意图非放大、不可逆硬门（A43/A44） |
| ICL | O(1)+O(H_op) | O(H_op) | 一致性单向：只降不升（A44） |
| PCE++ | +O(k_i·d_ψ) | O(\|V\|+\|σ\|) | 双 VOI、k_p+k_c+k_i 终止 |

**正确性定理（Curriculum-Intent Calibrated Soundness, CICS）**
假设 A22–A32（第 53–55 轮）、A33–A36（第 56 轮）、A37–A40（第 57 轮）成立；并新增：
**(A41) 课程非放宽**：课程仅改变检查点/探针的访问顺序与预算切分，证据门函数逐点不变；升层须通过留出审计，且共形覆盖保持 ≥1−α_conf。
**(A42) 反课程覆盖**：考试分布与部署难层重叠，留出、轮换、与升层决策隔离，漏考率 ≤δ_cur；训练/考试样本不交叉。
**(A43) 意图校准**：意图解码器在每个难度层与人群分层上 ECE_I≤ε_I(l)，歧义漏报率 ≤δ_amb，澄清通道错误模型诚实。
**(A44) 意图非放大**：意图置信不进入世界证据似然；意图-行为一致性只可增加不确定性或触发澄清，不得提高授权、不得降低证据要求；不可逆接触要求意图边际 m_I≥θ_m^irr。
则：

1. **少样本-课程承诺健全性**：
   `P(fail) ≤ δ_f + ε_meta(k) + ε_I(l) + δ_probe + ε_h(w_max) + δ_ood·α_conf + δ_xm·1[L1] + δ_cur`
   其中课程贡献被 δ_cur 隔离，意图贡献被 ε_I(l) 隔离，二者都不是乘性放大项。

2. **课程不增险（顺序-证据分离）**：对任意课程序 σ 与任意证据集 E，`Gate_σ(E)=Gate_base(E)`；因此课程序与基序在"给定同一证据集"下安全性相同，排序只改变达到该证据集的期望成本。课程无法把"没探够"判成"够了"。

3. **意图可分离（非掩蔽）**：`P(fail) ≥ P_misintent·1[action depends on φ]`，该下界与 P(world fails|E,φ) 的大小无关；因此"世界证据极强"不能掩蔽"意图认错"，歧义时必须澄清或停。

4. **个性化与课程的单向性兼容**：第 57 轮 A39 仍成立；课程升层、意图识别、一致性账本的新增更新只出现在"更保守"方向（θ_voi↑、回退共形、A_I↑、auth↓、澄清/停），不存在升险路径。

5. **终止性**：每检查点世界探针 ≤k_p+k_c、澄清 ≤k_i，PCE++ 必在 k_p+k_c+k_i 内终止于 {承诺, 绕行, L2 协商, 安全停}。

6. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + ε_I(l) + δ_probe + ε_h
                   + δ_ood·α_conf + δ_xm·1[L1] + δ_cur)
             − P(𝓜 陈旧未检出) − P(护盾回退失败)
             − P(意图通道失效 ∧ 澄清超时 ∧ 安全停失效)
```

关键：**课程给效率、共形与审计给保底**（顺序与安全解耦，效率不押在"难度估计正确"上）；**意图给语义、澄清给保底**（人类证据只在 φ 被明确时有效，世界置信不能掩蔽意图错误）；**所有隐变量推断单向保守**（难度只排序、意图只澄清、一致性只降权）。

## 6. 本轮最大风险

**一句话**：本轮真正的新攻击面不是单点错误，而是**全局相关的元错误**——课程用"难度估计"决定先信哪里，意图识别用"意图后验"决定证据指向哪个命题；二者都是对隐变量的自信推断，一旦难度估计把"看似易的新世界"归入易层，或意图解码器在某一类人群/指令上系统性认错，错误会通过排序与澄清策略**跨检查点、跨会话地同向放大**，比第 57 轮的局部坏证据更难被事后证伪；必须以"课程只排序不改门、意图只澄清不放大、不可逆接触意图硬门、审计留出且轮换、所有隐变量推断单向保守"五重护栏，宁可退回又慢又宽的路径，也不让一个自信的隐变量推断代替证据。
