# 第 55 轮（承接第 54 轮 v16++ GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「机械臂」×「共情表达」）

> 第 54 轮已把技能组合提升为“动作-鲁棒性双证书”，并建立了云边动作映射闭环。本轮引入两个看似异质的灵感：**机械臂**（具身、接触、力/位混合、安全包络、动作不可逆）与**共情表达**（多模态、校准、时序、边界、个体差异）。核心判断：二者不是“物理层 + 社交层”的简单叠加，而是**同一动作的双重语义**——机械臂的一次触碰既是力/位动作，也是情感信号；一次共情表达也必须由物理动作（面部、语音、姿态、触碰）实现。由此产生两个新矛盾：
> **H22（安全-合宜冲突）**：物理安全与情感合宜可能相互矛盾。稳固的扶持在物理上安全，却可能被读作支配性接触；轻柔安抚在情感上合宜，却可能在脆弱对象附近物理危险。二者必须同时认证，且不可用一方抵消另一方。
> **H23（慢推断-快表达错配）**：共情有严格时序窗口，而云端情感推断是慢环路、边端机械臂控制是快环路。若等云端推断完成再表达，就会产生“迟到的共情”；若边端先表达，则可能在错误的情感假设上做出**不可撤回**的接触。

## 0. 直觉与动机

**灵感 1（把共情当作动作 → 情感动作空间）**
直觉：共情表达不是一句“我理解你”，而是一组可执行、可度量、可失败的动作。把它写成情感动作空间 `E = M × I × T`：`M` 是模态（面部、语音、姿态、触碰），`I` 是强度，`T` 是时序。技能 `S` 在 `E` 上的**共情剖面** `ε_S : E → [0,1]` 刻画“它能把这种情感动作做到多真、多稳”。这样共情从主观宣称变成和 `α_S` 同构的占用剖面，可以被覆盖检查、被组合、被认证。

**灵感 2（物理-情感双向耦合 → 同一动作的两层语义）**
直觉：机械臂的安抚性触碰 `a` 同时携带物理后果与情感载荷。用 `Ψ: A → Δ(E)` 表示“这个物理动作会被感知成什么情感信号”，用 `Φ: E → 2^A` 表示“想表达这个情感，需要哪些物理实现”。只做单向（先想情感再找动作，或先做动作再解释）都会漏掉另一半风险。关键是：**情感动作一旦通过机械臂落到物理世界就不可撤回**——表情可以收回，触碰不能。不可逆性把共情的容错预算压得比纯软件代理小一个量级。

**灵感 3（共情校准带 → 不是误差越小越好，而是“刚刚好”）**
直觉：共情不是镜像。用户悲伤时，合宜回应是“温和关切”，而不是同样悲伤。因此先定义**共情响应算子** `R: Δ(E_u) → Δ(E_r)`，再衡量机器人表达 `e_r` 与 `R(e_u)` 的距离 `κ` 以及**表达增益** `g = ||e_r|| / ||R(e_u)||`。`g` 太小是冷漠/忽视，`g` 太大是过度表达、情感操控甚至恐怖谷。所以可接受域是一个**带** `[g_lo, g_hi]`，而不是一个点。这与前几轮“越小越好”的鲁棒性直觉相反，是本轮第一个非平凡的结构变化。

**灵感 4（共情时序 + 推测式共情 → 云慢边快的错配）**
直觉：共情对时间极其敏感，安慰晚三秒就可能变成二次伤害。设情感事件在 `t0`，表达窗口 `W_emp = [t0+τ_min, t0+τ_max]`。云端多模态推断准但慢，边端先验快但粗。于是引入**推测式共情**：边端在本地先验上立即给出“暂定表达” `e_prov`，云端在窗口内异步细化；若细化结果与暂定表达差异小则静默采纳，差异大则做**最小修复**而非整体推翻（整体推翻会造成二次突兀）。若云端结果晚于窗口，则宁可保留暂定表达，也不做迟到的大幅更正。

**灵感 5（同意-边界 → 机械臂接触的第一性约束）**
直觉：对机械臂而言，“能不能碰”不是情感问题，而是边界与同意问题。设身体区域 `R_b`，同意函数 `consent(u, r, a) ∈ {granted, denied, unknown}`。可接触动作子空间 `A_touch(u)` 只包含已同意区域、力/位在安全包络内、且运动学可达的动作。**`unknown` 一律视为 `denied`**。这条硬约束必须独立于情感推断——因为情感模型可能被诱导、可能犯错，而越界触碰的代价不可逆。共情只能在这个硬门内部做软校准。

**灵感 6（双向联合证书 → 从 J 到 J_emp）**
直觉：第 54 轮的联合证书 `J=(ρ,A_cert,γ_ce,δ_a)` 只认证了“物理-鲁棒性”。本轮把它扩成双向：既要认证“物理动作在情感上是否合宜”（`Ψ, κ, g`），也要认证“情感意图在物理上是否安全可实现”（`Φ, A_touch, 力/位包络`），并叠加情感鲁棒性谱 `ρ_aff` 与共情时序证书 `T_cert`。只有双向都过，才允许部署。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（情感动作空间与共情剖面）**
情感动作空间 `E = M × I × T`，其中 `M` 为模态集合（面部/语音/姿态/触碰），`I ⊂ ℝ≥0` 为表达强度，`T` 为时序。技能/平台 `S` 的共情剖面 `ε_S : E → [0,1]`，表示在情感动作 `e` 上的可表达度与保真度（由多评分者一致性加权校准）。**共情覆盖** `cover_emp(S, E_T) = 1` 当且仅当 `∀ e ∈ E_T, ε_S(e) ≥ θ_emp`。

**定义 122（物理-情感双向耦合）**
耦合对 `(Ψ, Φ)`：
- `Ψ : A → Δ(E)`：物理动作 `a` 被感知为情感信号 `e` 的分布（物理→情感）；
- `Φ : E → 2^A`：情感意图 `e` 的可行物理实现集合（情感→物理）。

联合动作 `a ⊗ e` **可行**当且仅当
```
a ∈ Φ(e)  ∧  supp Ψ(a) ∩ N_δ(e) ≠ ∅
```
其中 `N_δ(e)` 为情感意图 `e` 的 δ-邻域。此定义强制“物理能实现”与“情感被读对”同时成立。

**定义 123（共情响应算子与校准带）**
共情响应算子 `R : Δ(E_u) → Δ(E_r)`（用户情感分布→合宜回应分布，**非镜像**）。对机器人表达 `e_r` 与估计用户情感 `e_u`：
- 校准差 `κ(e_r, e_u) = d(E_r, R(e_u))`；
- 表达增益 `g(e_r, e_u) = ||E_r|| / ||R(e_u)||`。

可接受带 `B_emp = { (κ,g) | κ ≤ κ_max ∧ g ∈ [g_lo, g_hi] }`。`g > g_hi` 记**过表达风险**（操控/恐怖谷），`g < g_lo` 记**欠表达风险**（冷漠/忽视）。

**定义 124（共情时序证书）**
对情感事件 `u_evt` 发生于 `t0`，表达窗口 `W_emp = [t0+τ_min, t0+τ_max]`。时序证书 `T_cert = (t_express, W_emp, τ_loop, repair_cost)`，**有效**当且仅当 `t_express ∈ W_emp`。其中 `τ_loop = τ_infer + τ_plan + τ_exec` 必须满足 `τ_loop ≤ τ_max - τ_min`，否则窗口内不可闭合。

**定义 125（同意-边界证书）**
身体区域集合 `R_b`，同意函数 `consent : U × R_b × A → {granted, denied, unknown}`。可接触动作子空间
```
A_touch(u) = { a ∈ A | region(a) ∉ R_denied(u)
               ∧ force(a) ≤ F_max(u)
               ∧ within_safety_envelope(a,u)
               ∧ consent(u, region(a), a) = granted }
```
其中 `unknown` 视为 `denied`。边界证书 `B_cert = (A_touch, F_max, region_map, consent_state)`。

**定义 126（共情-物理联合证书）**
```
J_emp = (ρ, ρ_aff, ε_S, Ψ, Φ, κ, g, T_cert, B_cert, evidence)
```
其中 `ρ` 为第 53/54 轮物理鲁棒性谱，`ρ_aff` 为情感维度（文化/个体/语境漂移）鲁棒性谱，`evidence` 含多评分者标注、边端推测-修复日志、同意状态快照与力/位轨迹。**可部署**当且仅当
```
dom_J(T)=in ∧ cover_emp(S,E_T) ∧ κ≤κ_max ∧ g∈[g_lo,g_hi]
∧ T_cert valid ∧ A_core ⊆ A_touch(u)
```

## 2. 关键算法 伪代码

### IP-121 EAP（Empathic Action Profiling）

```python
def empathic_profile(skill, E_mod, E_int, E_t, raters):
    eps = {}
    for m in E_mod:
        for i in E_int:
            for t in E_t:
                e = (m, i, t)
                feats = skill.render_affect(e)        # 面部/语音/姿态/触碰参数
                score, conf = raters.score(feats)     # 多评分者一致性加权
                eps[e] = conf * agreement(raters)
    return eps

def cover_emp(eps, E_T, theta_emp=0.8):
    return all(eps.get(e, 0.0) >= theta_emp for e in E_T)
```

### IP-122 PAC（Physical-Affective Coupling）

```python
def coupling_maps(skill, A, E, perception_model, delta_e):
    Psi = {a: perception_model.infer_affect(skill.execute(a)) for a in A}
    Phi = {}
    for e in E:
        Phi[e] = [a for a in A
                  if support_overlap(Psi[a], neighborhood(e, delta_e))
                  and skill.motion_planner.feasible(a)]
    return Psi, Phi

def joint_action_feasible(a, e, Psi, Phi, delta_e):
    return a in Phi[e] and support_overlap(Psi[a], neighborhood(e, delta_e))
```

### IP-123 ECB（Empathic Calibration Band）

```python
def empathic_calibration(e_user, R, e_robot, kappa_max, g_lo, g_hi, EPS=1e-6):
    e_target = R(e_user)                              # 合宜回应，非镜像
    kappa = affect_distance(e_robot, e_target)
    g = norm(e_robot) / max(norm(e_target), EPS)
    if kappa > kappa_max:
        return ('reject', 'calibration_gap', kappa)
    if g > g_hi:
        return ('reject', 'over_expression', g)       # 操控/恐怖谷
    if g < g_lo:
        return ('reject', 'under_expression', g)      # 冷漠/忽视
    return ('ok', kappa, g)
```

### IP-124 SET（Speculative Empathic Timing）

```python
def speculative_empathy(u_evt, t0, edge_prior, cloud_model, W_emp, delta_repair):
    e_prov = edge_prior.respond(u_evt)                # 边端先验：立即暂定表达
    t_express = now()
    if not within(t_express, W_emp):
        return ('miss', t_express)
    e_ref = cloud_model.refine(u_evt, timeout=remaining(W_emp))
    if e_ref is None:
        return ('ok_provisional', e_prov)             # 云端未及时到：不打断
    if affect_distance(e_ref, e_prov) <= delta_repair:
        return ('ok', e_ref)                          # 差异小：静默采纳
    return ('ok_repaired', minimal_repair(e_prov, e_ref),
            repair_cost(e_prov, e_ref))               # 差异大：最小修复
```

### IP-125 CBC（Consent-Boundary Certificate）

```python
def consent_boundary_certificate(user, arm, A, region_map, F_max):
    consent = user.consent_state                       # granted/denied/unknown
    A_touch = []
    for a in A:
        r = region_map(a)
        if consent.get(r, 'unknown') != 'granted':
            continue                                   # unknown 一律视为 denied
        if arm.peak_force(a) > F_max[user]:
            continue
        if not arm.within_safety_envelope(a, user):
            continue
        A_touch.append(a)
    return BoundaryCert(A_touch, F_max[user], region_map, consent)
```

### IP-126 JEC（Joint Empathic-Physical Certificate）

```python
def joint_empathic_certificate(skill_seq, user, J_phys, E_T, R,
                               kappa_max, g_lo, g_hi, W_emp):
    rho = J_phys.rho
    rho_aff = affective_robustness(skill_seq, user)    # 文化/个体/语境漂移谱
    eps = compose_empathic_profiles(skill_seq)
    if not cover_emp(eps, E_T):
        return ('reject', 'expression_coverage')
    e_robot = compose_expression(skill_seq)
    ok, kappa, g = empathic_calibration(user.affect, R, e_robot,
                                        kappa_max, g_lo, g_hi)
    if ok != 'ok':
        return ('reject', ok, kappa, g)
    t_cert = timing_certificate(skill_seq, user.event, W_emp)
    if not t_cert.valid:
        return ('reject', 'timing_miss', t_cert)
    b_cert = consent_boundary_certificate(user, arm, J_phys.A_core,
                                          region_map, F_max)
    if not is_subset(J_phys.A_core, b_cert.A_touch):
        return ('reject', 'consent_boundary', b_cert)
    return ('ok', J_emp(rho, rho_aff, eps, Psi, Phi, kappa, g,
                        t_cert, b_cert, evidence=J_phys.evidence))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| EAP | O(|E|·|S|·|R|) | O(|E|) | 多评分者一致性、剖面可复现 |
| PAC | O(|A|·|E| + plan) | O(|A|·|E|) | Ψ 校准、Φ 完备、δ_e 有界 |
| ECB | O(|E_u|·|E_r|) | O(|E_u|+|E_r|) | R 非镜像、带边界可判定 |
| SET | O(1) 在线 + O(|E|) 修复 | O(|E|) | 窗口命中、修复最小性 |
| CBC | O(|R_b|·|A|) | O(|A|) | unknown=denied、硬门独立于情感 |
| JEC | O(|S|·|A| + |E| + |R_b|) | O(|A|+|E|) | 双向闭合、任一失败即否决 |

**正确性定理（Empathic-Physical Coupled Deployment Soundness）**
承接第 53/54 轮 (A22)–(A28)，新增假设：
- **(A29)** `ε_S` 由多评分者校准，评分者一致性 `Krippendorff α ≥ 0.8`，`cover_emp` 可判定；
- **(A30)** `Ψ` 在目标人群上校准，`affect_distance` 有界且对输入 Lipschitz；
- **(A31)** 边端推测式共情在 `W_emp` 内的命中率 `≥ 1-ε_t`，云端细化延迟可观测；
- **(A32)** 同意状态显式可得，`unknown` 保守拒绝；力/位安全包络**独立于情感推断**。

则“既安全又合宜”的部署概率满足：
```
P(safe ∧ appropriate)
  ≥ 1 - Σ_d (1-ρ(d)) - P(κ>κ_max) - P(g∉[g_lo,g_hi])
      - P(T_cert invalid) - ε_consent - β_E
```
其中 `ε_consent` 为同意状态误判率（对显式 `denied` 区域由硬门保证为 0）。定理的要点不是把各项相加，而是强调：**物理/边界是硬门，情感是门内软带**；硬门不通过时，任何共情增益都不参与计算。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 情感标注主观噪声大 | 高 | 多评分者 + 一致性阈值 + 不确定度传播 |
| 文化/个体非平稳导致校准带漂移 | 高 | 在线个性化 + 带宽自适应 + 保守默认带 |
| 同意状态推断错误 | 高 | `unknown=denied` + 显式确认 + 独立力/位安全层 |
| 过表达滑向情感操控/过度依恋 | 高 | 增益带上界 + 操控审计 + 透明化表达意图 |
| 推测式修复造成二次突兀 | 中 | 最小修复 + hysteresis + 修复预算 |
| 云端情感推断超窗 | 中 | 边端先验 + 推测执行 + 降级为中性表达 |

## 6. 本轮最大风险

**一句话**：物理-情感双向耦合把“安全”与“合宜”绑在同一动作上，但合宜性依赖**噪声大、文化非平稳、且可被对抗诱导的情感推断**；一旦推断误差渗入动作选择，系统会在“过度保守的僵硬”与“看似温柔实则越界的触碰”之间摇摆，而越界往往恰好发生在物理仍安全的区域——因此必须让**力/位安全包络与同意边界成为不依赖情感推断的硬门（`unknown=denied`），把情感校准限制在硬门之内的软带里**，宁可表达不足，绝不把“共情”当作放宽物理或边界约束的理由。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（EAP×PAC×ECB×SET×CBC×JEC）

> 承接第 54 轮产物 v31。本轮把 v16++ 的“动作-鲁棒性双证书”扩展为 **物理-情感双向证书体系**，核心是承认机械臂的一次动作同时具有物理后果与情感载荷，且触碰不可逆：

> - **ECB（Empathic Calibration Band）**：共情校准差 `κ` 与表达增益带 `g`；

> - **CBC（Consent-Boundary Certificate）**：同意-边界硬门 `A_touch`；
> - **JEC（Joint Empathic-Physical Certificate）**：双向联合证书 `J_emp`。

## 2. 关键算法 伪代码

### IP-121 EAP

```python
def empathic_profile(skill, E_mod, E_int, E_t, raters):
    eps = {}
    for m in E_mod:
        for i in E_int:
            for t in E_t:
                e = (m, i, t)
                feats = skill.render_affect(e)
                score, conf = raters.score(feats)
                eps[e] = conf * agreement(raters)
    return eps

def cover_emp(eps, E_T, theta_emp=0.8):
    return all(eps.get(e, 0.0) >= theta_emp for e in E_T)
```

### IP-122 PAC

```python
def coupling_maps(skill, A, E, perception_model, delta_e):
    Psi = {a: perception_model.infer_affect(skill.execute(a)) for a in A}
    Phi = {}
    for e in E:
        Phi[e] = [a for a in A
                  if support_overlap(Psi[a], neighborhood(e, delta_e))
                  and skill.motion_planner.feasible(a)]
    return Psi, Phi

def joint_action_feasible(a, e, Psi, Phi, delta_e):
    return a in Phi[e] and support_overlap(Psi[a], neighborhood(e, delta_e))
```

### IP-123 ECB

```python
def empathic_calibration(e_user, R, e_robot, kappa_max, g_lo, g_hi, EPS=1e-6):
    e_target = R(e_user)
    kappa = affect_distance(e_robot, e_target)
    g = norm(e_robot) / max(norm(e_target), EPS)
    if kappa > kappa_max:
        return ('reject', 'calibration_gap', kappa)
    if g > g_hi:
        return ('reject', 'over_expression', g)
    if g < g_lo:
        return ('reject', 'under_expression', g)
    return ('ok', kappa, g)
```

### IP-124 SET

```python
def speculative_empathy(u_evt, t0, edge_prior, cloud_model, W_emp, delta_repair):
    e_prov = edge_prior.respond(u_evt)
    t_express = now()
    if not within(t_express, W_emp):
        return ('miss', t_express)
    e_ref = cloud_model.refine(u_evt, timeout=remaining(W_emp))
    if e_ref is None:
        return ('ok_provisional', e_prov)
    if affect_distance(e_ref, e_prov) <= delta_repair:
        return ('ok', e_ref)
    return ('ok_repaired', minimal_repair(e_prov, e_ref),
            repair_cost(e_prov, e_ref))
```

### IP-125 CBC

```python
def consent_boundary_certificate(user, arm, A, region_map, F_max):
    consent = user.consent_state
    A_touch = []
    for a in A:
        r = region_map(a)
        if consent.get(r, 'unknown') != 'granted':
            continue
        if arm.peak_force(a) > F_max[user]:
            continue
        if not arm.within_safety_envelope(a, user):
            continue
        A_touch.append(a)
    return BoundaryCert(A_touch, F_max[user], region_map, consent)
```

### IP-126 JEC

```python
def joint_empathic_certificate(skill_seq, user, J_phys, E_T, R,
                               kappa_max, g_lo, g_hi, W_emp):
    rho = J_phys.rho
    rho_aff = affective_robustness(skill_seq, user)
    eps = compose_empathic_profiles(skill_seq)
    if not cover_emp(eps, E_T):
        return ('reject', 'expression_coverage')
    e_robot = compose_expression(skill_seq)
    ok, kappa, g = empathic_calibration(user.affect, R, e_robot,
                                        kappa_max, g_lo, g_hi)
    if ok != 'ok':
        return ('reject', ok, kappa, g)
    t_cert = timing_certificate(skill_seq, user.event, W_emp)
    if not t_cert.valid:
        return ('reject', 'timing_miss', t_cert)
    b_cert = consent_boundary_certificate(user, arm, J_phys.A_core,
                                          region_map, F_max)
    if not is_subset(J_phys.A_core, b_cert.A_touch):
        return ('reject', 'consent_boundary', b_cert)
    return ('ok', J_emp(rho, rho_aff, eps, Psi, Phi, kappa, g,
                        t_cert, b_cert, evidence=J_phys.evidence))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| EAP | O(|E|·|S|·|R|) | O(|E|) | 多评分者一致性 α≥0.8，剖面可复现 |
| PAC | O(|A|·|E| + plan) | O(|A|·|E|) | Ψ 校准、Φ 完备、δ_e 有界 |
| ECB | O(|E_u|·|E_r|) | O(|E_u|+|E_r|) | R 非镜像、带边界可判定 |
| SET | O(1) 在线 + O(|E|) 修复 | O(|E|) | 窗口命中、修复最小性 |
| CBC | O(|R_b|·|A|) | O(|A|) | `unknown=denied`、硬门独立于情感 |
| JEC | O(|S|·|A| + |E| + |R_b|) | O(|A|+|E|) | 双向闭合、任一失败即否决 |

**正确性定理（Empathic-Physical Coupled Deployment Soundness）**
承接第 53/54 轮 (A22)–(A28)，新增：
**(A29)** `ε_S` 由多评分者校准（Krippendorff α ≥ 0.8），`cover_emp` 可判定；
**(A30)** `Ψ` 在目标人群上校准，`affect_distance` 有界且 Lipschitz；
**(A31)** 边端推测式共情窗口命中率 `≥ 1-ε_t`，云端细化延迟可观测；
**(A32)** 同意状态显式可得，`unknown` 保守拒绝；力/位安全包络独立于情感推断。
则：
```
P(safe ∧ appropriate)
  ≥ 1 - Σ_d(1-ρ(d)) - P(κ>κ_max) - P(g∉[g_lo,g_hi])
      - P(T_cert invalid) - ε_consent - β_E
```
关键：**物理/边界是硬门，情感是门内软带**；硬门不通过时，共情增益不参与计算。

## 5. 本轮最大风险

**一句话**：物理-情感双向耦合把“安全”与“合宜”绑在同一动作上，但合宜性依赖**噪声大、文化非平稳、且可被对抗诱导的情感推断**；一旦推断误差渗入动作选择，系统会在“过度保守的僵硬”与“看似温柔实则越界的触碰”之间摇摆，而越界往往恰好发生在物理仍安全的区域——因此必须让**力/位安全包络与同意边界成为不依赖情感推断的硬门（`unknown=denied`），把情感校准限制在硬门之内的软带里**，宁可表达不足，绝不把“共情”当作放宽物理或边界约束的理由。
