# 第 47 轮（承接第 46 轮 v23；本轮灵感：地形适应 × 模型蒸馏） · Terrain-Distilled Certificate Transport：地形条件化蒸馏证书迁移与自适应可信降级（五层架构 v11）

> 承接第 46 轮 v23（MVR × VAD × SAB 记忆-语音-安全全局决策）。前 46 轮把姿态证书 P_t、数据护照、能量租约 ℓ_e、记忆/语音安全绑定逐步补齐，但隐含假设 H5：**标定与蒸馏所用的世界模型与部署地形同分布，且底座（base）近似静止**。UniBot 跨越草地、碎石、斜坡、软垫、湿滑瓷砖时，地形 τ_t 会同时改变两件事：(a) 接触与底座漂移使位姿观测噪声、可观测性分层 r_ω 随地形变化；(b) 为把大模型（VLM 上下文预测器、大位姿精化器）搬上机器人，必须蒸馏出小模型，而蒸馏只在训练地形分布上保证平均保真。两个灵感词精确命中 H5：**地形适应**把“单一证书”抬升为“地形索引的证书族 + 证书迁移操作”；**模型蒸馏**把“模型替换”从平均精度问题变成“带误差包络与时效的证书契约”。耦合出的新问题是：**当地形 OOD、蒸馏小模型的误差被放大时，如何判定旧证书能否安全迁移到新的（地形, 模型）组合；若判定错误，证书会静默失效并级联穿透安全谓词**。

## 0. 直觉与动机

**灵感 1（地形适应 → 证书的地形条件化与迁移）**
直觉：站在瓷砖上的姿态估计，和站在碎石/软垫/斜坡上的姿态估计不是同一个问题。地形 τ_t =（粗糙度, 坡度, 可变形性, 摩擦, 接触置信）会改变底座漂移与观测噪声，因此证书不是一张，而是一族 P_t(τ)。“地形适应”（换步态、换接触模型、换支撑策略）本质上是一次**证书迁移**：旧的 P_t(τ_old) 不能直接当作 P_t(τ_new) 的保证，必须显式支付迁移代价（半径膨胀或重新标定），否则跨越地形的瞬间证书就会静默失效。

**灵感 2（模型蒸馏 → 教师-学生证书契约而非平均精度）**
直觉：蒸馏常用平均精度/参数量衡量，但安全证书关心的是**逐地形最坏情况误差**。定义地形 τ 上的蒸馏间隙 δ_S(τ)=sup_x‖f_T(x)−f_S(x)‖。学生模型只有在 δ_S(τ) 有界且被覆盖时才可替代教师。因此蒸馏应被建模为带误差包络与时效的**蒸馏租约 ℓ_d=(τ, δ_S(τ), coverage, expiry)**，学生签发的证书必须以 L_φ·δ_S(τ) 膨胀半径后才能继承教师的覆盖率。

**灵感 3（地形适应 × 模型蒸馏 → 地形信任域内的可信降级）**
直觉：不是所有地形都适合用小模型。定义地形信任域 Ω_known={τ: δ_S(τ)≤δ_max 且地形后验 q(τ)≥τ_conf}。当 τ_t∈Ω_known，用蒸馏学生换取低功耗高频率，证书通过膨胀安全迁移；当 τ_t∉Ω_known（OOD、高不确定、地形切换中），**升级回教师**或触发保守姿态盒/fail-closed。于是形成“地形识别 → 信任域判定 → 模型路由 → 证书迁移”的闭环，把蒸馏的安全风险前置到路由门。

**耦合升级**：在 v10 四层上插入**地形-蒸馏层（Terrain-Distill Layer）**，根信任层增加蒸馏租约 ℓ_d，L1 几何层证书按地形索引，L2 上下文层给出地形后验，L3 CAR 守卫加入地形 OOD 与蒸馏租约有效性，L4 DCL 采集任务加入 OOD 地形与蒸馏失配样本。五层 v11 中，全局决策 Π 扩展为 (地形模式, 模型, 感知模态) 三元选择。

## 1. 形式化定义（增量：定义 59–63）

**定义 59（地形索引与地形后验）**
地形特征 τ_t=(ρ_rough, s_slope, d_deform, μ_fric, κ_contact)∈T。本体感受与稀疏视觉给出地形后验
q_t(τ)=P(τ | proprio_t, m_t, c_t)。
地形模式 k_t=argmax_τ q_t(τ)。切换判据：若 D_KL(q_t‖q_{t−1})>τ_switch 或 k_t≠k_{t−1}，则进入“迁移中”状态，**禁止证书直接复用**，并冻结依赖旧地形的姿态租约。

**定义 60（地形条件姿态证书族与迁移算子）**
对地形模式 τ，证书
P_t(τ)={x: ‖x−x̂_t‖ ≤ r_{ω,m}(τ)}，
满足分层条件覆盖
P( X_t∈P_t(τ) | ω_t, m_t, τ_t=τ ) ≥ 1−α_p。
地形迁移算子 T_{τ→τ'}：若复用旧半径，则必须满足迁移不等式
r(τ') ≥ r(τ) + L_φ·W(τ,τ') + L_φ·δ_S(τ')，
其中 W(τ,τ') 为地形扰动/Wasserstein 距离，δ_S 为蒸馏间隙；否则必须重标定（recalibrate）后才能签发。

**定义 61（蒸馏租约与间隙）**
教师 f_T、学生 f_S。地形 τ 上的蒸馏间隙
δ_S(τ)=sup_{x∈D_τ} ‖f_T(x)−f_S(x)‖_φ。
蒸馏租约 ℓ_d=(τ, δ_S(τ), cov_S(τ), t_d, δ_max, T_d)，有效条件：
δ_S(τ)≤δ_max 且 cov_S(τ)≥1−α_d 且 t−t_d≤T_d。
**契约**：学生签发的证书必须膨胀 L_φ·δ_S(τ)；ℓ_d 失效等价于学生模型不可用于签发证书。

**定义 62（地形信任域与 OOD 门）**
Ω_known={τ∈T: δ_S(τ)≤δ_max, q_t(τ)≥τ_conf, ℓ_d(τ) 有效}。
OOD 判据：τ̂_t∉Ω_known 或 epistemic 不确定度 U(τ_t)>U_max。门函数
g_t=Gate(q_t, δ_S, ℓ_d) ∈ {student, teacher, fail-closed}。
**风险前置**：g_t=teacher 时禁止学生签发；g_t=fail-closed 时只允许保守姿态盒。

**定义 63（地形-模型-模态联合调度策略）**
策略
π(τ_t, q_t, B_t, ω_t, v_t)=(k_t, f_t, m_t)=argmax U(k,f,m)
约束：ℓ_e 有效；若 f=student 则 ℓ_d 有效；迁移不等式（定义 60）成立；g_t 允许该 f。
效用
U = [ E_{τ~q_t}[ E_{ω~P(·|τ,m)}[ S_φ(ω)·Δrad(m,ω;τ) ] ] + λ_a·AdaptGain(k,τ) ] / [ P_m + P_f + c_risk·Risk(τ,g_t) ]，
其中 AdaptGain 为地形适应带来的稳定性/可观测性收益，P_f 为模型推理功耗，Risk(τ,g_t) 为地形 OOD 惩罚。若“迁移中”或 g_t=fail-closed，则禁止 student 并冻结证书复用。

## 2. 三大新增产出与既有 IP 升级

**IP-69 TDCA（Terrain-Distilled Certificate Adapter）**
- 地形索引半径表 r_{ω,m}(τ)：按地形模式分别共形校准
- 证书迁移算子：实现定义 60 的不等式，输出膨胀半径或触发重标定
- 蒸馏间隙膨胀：学生证书一律加 L_φ·δ_S(τ)，并写入证书元数据（地形、模型、租约）

**IP-70 TDR（Terrain Distillation Router）**
- 地形后验估计与切换检测（KL 门 + epistemic 不确定度）
- OOD 门与 teacher/student/fail-closed 三态路由
- 蒸馏租约 ℓ_d 跟踪：间隙、覆盖率、时效，失效即降级

**IP-71 TTA（Terrain-Triggered Adaptation）**
- 地形模式切换与步态/接触模型切换
- 切换冻结窗口：暂停证书复用与记忆命中，强制教师/重标定
- 证书重签发：切换完成后以新地形重新签发 P_t(τ)

**既有 IP 升级**
- IP-63 ECPS：状态加入 τ_t，决策从 m 升级为 (k,f,m) 三元；联合求解 ℓ_e 与 ℓ_d
- IP-64 DEPTH-CERT ADAPTER：深度质量按地形分层（斜坡/高光/软地单独标定），r_ω(m,τ)
- IP-65 CONTEXT PREDICTOR：输出地形后验 q_t(τ) 与 OOD 预测，供 TDR 前置
- IP-66 MVR：记忆键加入地形 τ，跨地形记忆禁止直接复用（只作候选，需重验租约）
- IP-68 SAB：绑定函数加入坡度/可达性项，斜坡上降低可执行阈值
- IP-62 CCA：新增地形 shift 红队与蒸馏失配注入审计
- IP-51 CAR：守卫加入 g_t≠fail-closed 与 ℓ_d 有效性检查
- IP-45 总线：新增 terrain-mode / distill-lease / teacher-escalation 话题

## 3. 算法骨架

TDR/TDCA/TTA 每控制周期（50–100ms）：
1. 读取 proprio_t, c_t, ω_t, B_t，估计地形后验 q_t(τ) 与切换标志
2. TTA：若切换/迁移中 → 冻结证书复用，置 force_teacher，进入重标定
3. TDR：OOD 门输出 g_t∈{student, teacher, fail-closed}
4. TDCA：查地形索引半径 r_{ω,m}(τ)，执行迁移不等式或重标定；学生证书按 δ_S(τ) 膨胀
5. 在 ℓ_e、ℓ_d、迁移约束与 g_t 下求解 (k,f,m) 三元联合效用
6. 若不满足约束 → 教师回退或 fail-closed；否则签发 P_t(τ) 并发布 terrain-mode/distill-lease/teacher-escalation
7. CAR 用 P_t(τ)、ℓ_p、ℓ_e、ℓ_d 联合守卫，SAB 用含地形项的绑定函数决定执行/入队

## 4. 本轮最大风险

**一句话**：地形切换瞬间的后验抖动会把“OOD”误判为“信任域内”，使系统用蒸馏学生加旧半径完成证书迁移，而真实底座漂移远超膨胀量，导致姿态证书在斜坡/软地/湿滑层静默失效并级联穿透安全谓词；因此必须以“切换冻结 + 保守膨胀 + 教师回退”三重门限制迁移，并把地形 OOD 判据纳入独立审计集持续校准。

## 2. 关键算法 伪代码

### IP-70 TDR（地形后验 + OOD 路由）
```
def terrain_posterior(proprio, m_t, c_t):
    return softmax(terrain_head(proprio, c_t))          # q_t(τ)

def ood_gate(q_t, delta_S, lease_d, tau_conf, U_max, delta_max):
    tau_hat = argmax(q_t)
    epistemic = entropy(q_t)
    if q_t[tau_hat] < tau_conf or epistemic > U_max:
        return 'fail-closed', tau_hat
    if (not lease_d.valid(tau_hat)) or delta_S[tau_hat] > delta_max:
        return 'teacher', tau_hat                        # OOD/失配 → 升级教师
    return 'student', tau_hat
```

### IP-69 TDCA（证书迁移 + 蒸馏膨胀）
```
def transport_radius(r_old, tau, tau_new, L_phi, W, delta_S, mode):
    if mode == 'recalibrate':
        return calibrate_radius(tau_new)                 # 重标定分支
    return r_old + L_phi * W(tau, tau_new) + L_phi * delta_S[tau_new]

def issue_certificate(x_hat, tau, omega, m, model, delta_S, L_phi):
    r = terrain_radius(tau, omega, m)
    if model == 'student':
        r = r + L_phi * delta_S[tau]                     # 契约：间隙膨胀
    if not transport_ok(r, tau):                         # 迁移不等式不成立
        return None                                      # 交 CAR/教师 fail-closed
    return PoseCert(x_hat, r, tau, model, expiry=now + T_d)
```

### IP-71 TTA（切换检测 + 冻结）
```
def terrain_adapt(q_t, q_prev, k_prev, tau_switch):
    if kl_div(q_t, q_prev) > tau_switch:
        return {'state': 'migrating', 'freeze_cert': True,
                'force_teacher': True, 'mode': k_prev}
    k_t = argmax(q_t)
    if k_t != k_prev:
        return {'state': 'switch', 'freeze_cert': True,
                'recalibrate': True, 'mode': k_t}
    return {'state': 'stable', 'mode': k_t}
```

### 联合决策 Π'（地形-模型-模态）
```
def terrain_model_modality(c_t, q_t, omega_t, B_t, v_t, leases, calib):
    adapt = terrain_adapt(q_t, q_prev, k_prev, tau_switch)
    if adapt['freeze_cert']:
        g_t, tau_hat = 'teacher', adapt['mode']          # 冻结期只走教师
    else:
        g_t, tau_hat = ood_gate(q_t, delta_S, leases.d,
                                tau_conf, U_max, delta_max)
    if g_t == 'fail-closed':
        return 'fail-closed', adapt
    best, best_u = None, -inf
    for k in modes(q_t):
        for f in allowed_models(g_t):                    # student 受门约束
            for m in modalities():
                r = issue_certificate(x_hat(k, m), tau_hat, omega_t,
                                      m, f, delta_S, L_phi)
                if r is None:
                    continue
                u = utility(k, f, m, q_t, omega_t, B_t) / cost(f, m)
                if energy_ok(leases.e, f, m) and u > best_u:
                    best, best_u = (k, f, m, r), u
    return best if best else ('fail-closed', adapt)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| TDR 地形后验/门 | O(\|T\|) | O(\|T\|) | τ̂∉Ω_known ⇒ 强制 teacher/fail-closed |
| TDCA 迁移 | O(\|T\|·\|Ω\|) 查表 + O(1) 迁移 | O(\|T\|·\|Ω\|) | 迁移不等式成立 ⇒ 覆盖可迁移 |
| TTA 切换检测 | O(\|T\|) KL | O(\|T\|) | 切换/迁移中 ⇒ 冻结复用 |
| 联合决策 Π' | O(\|K\|·\|F\|·\|M\|) | O(\|T\|·\|Ω\|) | 三重约束下才有解，否则 fail-closed |

**正确性定理**：设学生误差包络 δ_S(τ) 覆盖真实教师-学生偏差，且地形迁移不等式 r(τ')≥r(τ)+L_φ·W(τ,τ')+L_φ·δ_S(τ') 成立。若 τ̂∈Ω_known 且 ℓ_d 有效，则学生签发的膨胀证书满足 P(X_t∈P_t(τ')) ≥ 1−α_p−α_d；若 τ̂∉Ω_known 或迁移不等式不成立，则 TTA 冻结 + TDR 升级/失败关闭，因此**不存在“未支撑地形上签发的证书”**。切换期间一切跨地形复用被禁止。

| E119 地形-能量-模型平衡 | 学生占比、能耗、帧率 | 学生占比 ≥ 60%；能耗降 ≥ 30% |

回退策略：E116 包络命中 < 95% → 收紧 δ_max，学生仅在稳定地形启用；E117 膨胀比 > 2× → 禁用迁移，改全量重标定；E118 OOD 召回 < 90% → 强制教师 + 保守姿态盒；E119 学生占比 < 40% → 检查地形头或回退全教师模式。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 地形切换后验抖动导致 OOD 误判 | 高 | 切换冻结窗口 + KL 门 + 教师回退 |
| 蒸馏间隙包络低估（长尾地形） | 高 | 独立审计集 + 共形上界 + 收紧 δ_max |
| 迁移膨胀过度导致证书不可用 | 中 | 自适应重标定阈值，监控膨胀比 |
| 地形头本身欠拟合/被蒸馏 | 中 | 地形头单独校准，不与位姿学生共享误差预算 |
| 记忆库跨地形复用失效 | 中 | 记忆键强制含 τ，跨地形只作候选需重验 |
| 教师回退能耗突增 | 中 | 能量租约预留 teacher 预算，预算不足 fail-closed |

## 6. 本轮最大风险

**一句话**：地形切换瞬间的后验抖动若把 OOD 误判为信任域内，系统会用蒸馏学生加旧半径完成证书迁移，而真实底座漂移超过膨胀量，导致姿态证书在斜坡/软地/湿滑层静默失效并穿透安全谓词；因此必须以切换冻结、保守膨胀、教师回退三重门限制迁移，并对地形 OOD 判据做独立审计校准。
