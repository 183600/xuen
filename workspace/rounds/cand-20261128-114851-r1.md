### 第 6 轮灵感驱动研究记录

**灵感词**：数据集、推理延迟

**继承关系**：第 5 轮 CADVS-v5（IP-493~496）把提议升级为条件流匹配、记忆升级为嵌入+固化、人因升级为情感调制，并用定理 6（证书不变性/提议无关性）把框架从「规则系统」推广为「任意生成器 + 认证边界」。本轮不推翻 v5，而是攻击 v5 两个「被当作背景条件、其实从未被认证」的支柱：(a) 所有门阈值、软评分标定与固化接受准则都默认「存在一个可信的数据集」，但 v5 没有回答数据集从哪来、是否被污染、是否代表部署分布——这正是 R57 自指回路的真正病根；(b) 所有实时性论证都以「P99 < 0.6 ms」为经验结论，但 v5 没有把延迟写进证书语义——证书没有发行时间、没有有效期、也没有截止期违约时的降级语义。两个灵感词统一为主题「见证数据集 + 延迟预算的认证执行」（Witness-Data-Anchored, Deadline-Budgeted Certified Execution, WDB），形成 CADVS-v6（IP-497~500）。本轮自律：**硬门仍为七**；数据集与延迟只作为「元证书/外部锚」接入，只紧不松；执行集嵌套升级为 Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ … ⊆ Exec_v29。

**直觉与动机**：

1. **数据集 → 把「外部真值」从口号变成可审计对象：见证数据集（Witness Dataset）**。v5 的固化用「已铸证 ∧ 结局验证成功 ∧ 人工抽检」片段训练策略，再用同一批门的判定去验收——裁判和考生是同一套数据、同一套门，这是 R57 的结构根源。直觉上，打破自指不能只靠更强的正则，而要靠一个**学习回路永远碰不到的外部裁判**。引入见证数据集 W = (W_cert, W_audit, W_red, W_lat)：内容寻址、带溯源链、由独立托管方冻结版本；四划分互斥。W_audit 只在「验收」时使用，从不进入训练；固化后的策略必须在 W_audit 上取得严格改进且无分群体回退才允许上线。这把「数据集」从训练材料升级为**证书的外部锚**。同时，数据集的支撑范围本身要被认证：对上下文 c 计算支持分 s_supp(c)（到 W_cert 的 kNN 距离），超出阈值即「落在认证数据域之外」，fail-closed 回退 v4 规则提议——并入 kc_mem，不新增门。

2. **推理延迟 → 把「时间」写进证书：带有效期的证书与截止期感知的 fail-closed**。v5 的证书是「无时间戳的谓词」，隐含假设「此刻通过 ⇒ 下一刻仍通过」。但真实控制环里，证书生成要花时间、世界在证书签发后还会演化。直觉上，证书应该像食品一样有**生产日期和保质期**。给每张证书附加 (t_issue, T_val, W_version, θ_version)，其中有效期由安全边际除以状态变化上界给出：T_val = m_slack / (L_s · v_max)。当认证流水线在截止期 D 内无法产出新证书时，系统不执行未认证的新动作，而是执行**最近一张仍然有效的证书所对应的动作（certificate hold）**，否则安全停机。于是「延迟」不再是一个可能被违反的性能指标，而成为证书语义的一部分：**任何时刻被执行的动作，要么被一张新鲜证书覆盖，要么被一张未过期证书覆盖，要么是安全停机**。

3. **两者合流 → 数据域 × 时间域的双重 fail-closed**。数据集回答「这个上下文我是否有资格认证」，延迟回答「这张证书此刻是否还算数」。二者正交，且都只收紧：支持分不足 → 回退；证书过期 → 持有/停机。于是安全性不再依赖「模型足够好」或「算力足够快」，而依赖两个可审计的边界。代价是**活性/自主性**：数据域外或算力紧张时，系统会更多回退与持有，覆盖率下降——这是一个诚实的覆盖-延迟前沿，而不是可以两全的优化问题。

**关键洞见**：v5 证明了「换提议不换门，证书边界不动」；v6 进一步指出，门本身的**标定数据**和证书的**生效时间**同样是边界的一部分，只是 v5 把它们留在了未认证的背景里。WDB 的核心不是加门，而是把这两个背景条件提升为**元证书**：数据溯源/支持证书（provenance & support）与时间有效性证书（freshness & deadline）。七硬门 kc_evidence_forged_v4 原样复用；新增的只有：见证数据集 W 与支持分 s_supp（并入 kc_mem）、证书有效期 T_val 与持有算子 Hold（并入 BCK 的证书消费逻辑）、漂移重标定 ρ_t（只增不减）、软评分 ECS_v6 = ECS_v5 · η_data · η_lat。执行集 Exec_v6 ⊆ Exec_v5 由「同门 + 支持域受限 + 阈值只紧 + 证书时效约束」保证。同时正面偿还 R57（自指固化）与 R54/R49（延迟）：R57 用外部 W_audit 裁判，R54 用截止期语义与持有降级。

**形式化目标（增量）**：
1. 见证数据集 W = (W_cert, W_audit, W_red, W_lat)，内容哈希 H(W)，溯源记录 p_i，四划分互斥；污染度 C(E_loop, W_audit) ≤ δ_c 才允许用 W_audit 验收。
2. 支持证书：s_supp(c) = (1/k)Σ_{j∈kNN_k(φ(c);W_cert)} d(φ(c), φ(c_j))；τ_supp 取 W_cert 上 (1−α) 分位；s_supp > τ_supp ⇒ 数据域外，回退规则提议并收紧。
3. 外部裁判验收：固化策略 π_new 仅在 R(π_new;W_audit) ≤ R(π_old;W_audit) − ε_gain 且所有分层无回退时上线，否则回滚；验收与训练数据严格不相交。
4. 时间证书：cert = (x, m, t_issue, T_val, W_v, θ_v)；T_val = m_slack/(L_s·v_max)；有效条件 t−t_issue ≤ T_val ∧ W_v=W_now ∧ θ_v=θ_now。
5. 截止期语义：控制环截止 D；流水线各阶段 WCET 预算 Σ b_i ≤ D−ε；超时 → Hold(最近有效证书) 或 SafeStop；每时刻被执行动作必须被有效证书覆盖。
6. 漂移重标定：ρ_t = 1 + λ·max(0, D_t−δ_drift) ≥ 1，τ^6 = ρ_t·τ^5；D_t > δ_max ⇒ 冻结执行并请求人类重标定。
7. 定理 9（外部裁判解自指/见证泛化界）、定理 10（截止期感知 fail-closed 不变量）、定理 11（证书陈旧界）、定理 12（数据漂移单调收紧）、定理 13（覆盖-延迟前沿：安全与活性分离）。
8. 软评分：η_data = σ((τ_supp−s_supp)/β)，η_lat = 1[cert 有效]·σ((T_val−(t−t_issue))/β_t)，ECS_v6 = ECS_v5 · η_data · η_lat。
9. Exec_CADVS-v6 = {x ∈ Exec_v5 : s_supp(c) ≤ τ_supp ∧ cert 有效} ⊆ Exec_v5。

**本轮最大风险**：**见证数据集自身不可见证**——它可能被污染（训练泄漏/投毒）、会漂移（不代表部署分布）、且更新滞后；一旦「外部裁判」失真，定理 9 的保证就退化为「在错误数据上正确」，系统会以更精致的方式自证正确，而延迟压力又会推动系统更频繁地复用旧证书。数据集与延迟两个锚同时失效时，fail-closed 保住了物理安全，却保不住语义正确。

## 2. 关键算法骨架

### IP-497 WDPK：见证数据集与溯源核（支持查询 O(log|W|)；污染审计离线）

```python
@dataclass
class WitnessDatasetProvenanceKernel:
    """WDPK：见证数据集 + 溯源 + 污染检测 + 支持域证书。
    红线：W_audit 永不进入训练；固化验收只在 W_audit 上进行"""
    W_cert: Any; W_audit: Any; W_red: Any; W_lat: Any
    H_W: str                      # 内容哈希，版本锚 W_v
    emb: Any                      # 冻结 φ(c)，不被 C_cons 更新
    k: int = 8
    tau_supp: float = None        # W_cert 上 (1-alpha) 分位，离线固定
    delta_c: float = 0.02
    eps_gain: float = 0.01

    def support_score(self, c) -> float:
        phi = self.emb(c)
        d, _ = self.faiss_cert.search(phi.reshape(1, -1), self.k)
        return float(np.mean(d))                       # s_supp

    def support_ok(self, c) -> bool:
        return self.support_score(c) <= self.tau_supp   # 数据域内

    def contamination(self, episodes) -> float:
        # 近重复率（LSH）+ 金丝雀记忆率（W_red 中唯一合成片段是否被复现）
        dup = near_dup_rate(episodes, self.W_audit, eps_d=0.05)
        canary = canary_memorization(episodes, self.W_red)
        return max(dup, canary)

    def audit_accept(self, pi_new, pi_old, outcome_fn, train_episodes) -> tuple[bool, dict]:
        """外部裁判：训练分布与验收分布严格不相交（定理 9）"""
        if self.contamination(train_episodes) > self.delta_c:
            return False, {'reason': 'AUDIT_CONTAMINATED', 'H_W': self.H_W}
        r_new = outcome_fn(pi_new, self.W_audit)
        r_old = outcome_fn(pi_old, self.W_audit)
        no_regress = all(r_new[g] <= r_old[g] + 1e-6
                         for g in strata(self.W_audit))
        ok = (r_new['all'] <= r_old['all'] - self.eps_gain) and no_regress
        return ok, {'r_new': r_new, 'r_old': r_old, 'H_W': self.H_W}
    # 数据域外 → EFA-v6 回退规则提议；W_lat 用于标定 T_val 与延迟压测切片
```

### IP-498 DACS：截止期感知证书调度器（每周期 O(1)）

```python
@dataclass
class DeadlineAwareCertificateScheduler:
    """DACS：证书带时间戳与有效期；截止期违约 → Hold/SafeStop。
    定理 10：每时刻被执行动作都被有效证书覆盖 ⇒ 安全不变量保持"""
    D: float = 1.0e-3             # 控制截止期（1 kHz）
    eps_margin: float = 0.05e-3   # 预留余量
    L_s: float = 1.0              # 门分数对状态的 Lipschitz 常数
    v_max: float = 1.0            # 状态变化速率上界
    m_required: float = 0.0

    def issue(self, x, margin, gate_vec, W_v, theta_v, t_now) -> 'Cert':
        m_slack = max(0.0, margin - self.m_required)
        T_val = m_slack / (self.L_s * self.v_max)       # 陈旧界（引理 47）
        return Cert(x=x, m=margin, t_issue=t_now, T_val=T_val,
                    W_v=W_v, theta_v=theta_v, gates=gate_vec)

    def valid(self, cert, t_now, W_v, theta_v) -> bool:
        return (t_now - cert.t_issue <= cert.T_val
                and cert.W_v == W_v and cert.theta_v == theta_v)

    def step(self, t_now, fresh_cert, held_cert, W_v, theta_v):
        # 优先新鲜证书；其次仍有效的旧证书；否则安全停机
        if fresh_cert is not None and self.valid(fresh_cert, t_now, W_v, theta_v):
            return fresh_cert.x, 'FRESH'
        if held_cert is not None and self.valid(held_cert, t_now, W_v, theta_v):
            return held_cert.x, 'HOLD'                  # 降级但安全
        return SAFE_STOP, 'SAFE_STOP'                   # fail-closed
```

### IP-499 DTRP：漂移触发重标定（在线 O(1) 草图；离线 MMD 全量）

```python
@dataclass
class DriftTriggeredRecalibrationProtocol:
    """DTRP：数据集漂移 → 阈值只紧不松；漂移过大 → 冻结执行"""
    delta_drift: float = 0.05
    delta_max: float = 0.20
    lam: float = 2.0

    def update(self, W_audit_now, W_audit_ref, tau5) -> tuple[float, float, bool]:
        D_t = mmd(W_audit_now, W_audit_ref)             # 或在线核均值草图
        if D_t > self.delta_max:
            return 1.0, tau5, True                      # freeze：请求人类重标定
        rho = 1.0 + self.lam * max(0.0, D_t - self.delta_drift)
        return rho, rho * tau5, False                   # rho >= 1，只紧不松
```

### IP-491 扩展 CERTCALC-v6：新增定理 9~13（离线理论）

```python
# 引理 45：污染检测功效
def lemma_contamination_power() -> str:
    """引理 45：m 个独立金丝雀 + 近重复 LSH（召回 ρ_lsh），
    对污染比例 δ 的检测功效 ≥ 1−(1−δ)^m；组合检测取 max 提升至
    1−(1−δ)^m·(1−ρ_lsh·δ)。误报由金丝雀唯一性与 DP 噪声控制。∎"""
    return "Proven"

# 引理 46：支持域覆盖
def lemma_support_coverage() -> str:
    """引理 46：τ_supp 取 W_cert 的 (1−α) 分位 ⇒ 在 W_cert 上误拒 ≤ α；
    但协变量漂移下误接受原理性无界（密度模型盲区），故必须叠加 DTRP。∎"""
    return "Proven (in-distribution); OOD unbounded"

# 引理 47：边际漂移 Lipschitz 界
def lemma_margin_drift() -> str:
    """引理 47：|m(x_t)−m(x_{t0})| ≤ L_s‖x_t−x_{t0}‖ ≤ L_s·v_max·(t−t0)。
    令其 ≥ m_required 得 T_val=(m_issue−m_required)/(L_s·v_max)。∎"""
    return "Proven"

# 定理 9：外部裁判解自指 / 见证泛化界
def theorem_external_referee() -> str:
    """定理 9：设博弈事件 G={门通过 ∧ 真实结局失败}，部署博弈率 g，
    W_audit 独立同分布取自部署且污染度 ≤ δ_c，则 |ĝ−g| ≤
    sqrt(ln(2/β)/(2N)) + δ_c·L_gap 以概率 ≥1−β。故验收要求 ĝ≤ε_rej
    即把部署博弈率约束到 ε_rej+slack。诚实边界：W_audit 与部署分布
    不一致（OOD）时界失效——外部裁判只在其覆盖域内有效。∎"""
    return "Proven (within W_audit coverage)"

# 定理 10：截止期感知 fail-closed 不变量
def theorem_deadline_failclosed() -> str:
    """定理 10：若 (A1) 安全集 S；(A2) 新鲜证书经引理 47 保证动作在 T_val
    内保持 S；(A3) Hold 只用有效证书；(A4) SafeStop∈S，则对任意延迟分布，
    每时刻 x_exec(t)∈S。证明：按 FRESH/HOLD/SAFE_STOP 三分情形归纳。∎"""
    return "Proven"

# 定理 11：证书陈旧界
def theorem_certificate_staleness() -> str:
    """定理 11：m(t) ≥ m_issue − L_s·v_max·(t−t_issue)；故 t−t_issue>T_val
    时证书可能失效。T_val 对 L_s、v_max 单调不增：动力学越快，证书越短命。∎"""
    return "Proven"

# 定理 12：数据漂移单调收紧
def theorem_drift_monotone() -> str:
    """定理 12：ρ_t≥1 ⇒ τ^6=ρ_t·τ^5 逐分量 ≥ τ^5 ⇒ 各门通过集收缩 ⇒
    Exec_v6⊆Exec_v5；ρ_t=1 且支持域内且证书有效时精确退化为 v5。∎"""
    return "Proven"

# 定理 13：覆盖-延迟前沿（安全与活性分离）
def theorem_coverage_latency_frontier() -> str:
    """定理 13：覆盖率 κ(D)=P_c(support_ok ∧ D 内完成认证 ∧ 证书有效)。
    对固定 D，κ(D) ≤ P_c(C(c) ≤ D)。C(c) 有重尾时，κ=1、零陈旧、
    有限 D 三者不可兼得：超时上下文只能 Hold（承担陈旧）或 Stop（损失活性）。
    fail-closed 保安全，但自主性由延迟预算上界。∎"""
    return "Proven (tradeoff); no free lunch"
```

### IP-500 EFA-v6：七硬门 + 支持域 + 时间证书 + 外部验收

```python
@dataclass
class EvidenceForgingAssemblerV6:
    """EFA-v6：门集合不变（τ^6=ρ·γ·τ^4 只紧）+ 数据/时间双 fail-closed"""
    fmpp: Any; lmem: Any; famk: Any
    wdpk: WitnessDatasetProvenanceKernel
    dacs: DeadlineAwareCertificateScheduler
    dtrp: DriftTriggeredRecalibrationProtocol
    v5: EvidenceForgingAssemblerV5

    def select(self, x0_state, t_now, rule_id, context) -> tuple[str, Any, str]:
        # 1) 数据域：域外直接回退，不消耗昂贵认证
        if not self.wdpk.support_ok(context.c):
            return 'FALLBACK', self.v5._fallback_rule_proposal(context), 'OUT_OF_CERT_DOMAIN'
        # 2) 漂移重标定（只紧不松；超限冻结）
        rho, tau6, freeze = self.dtrp.update(
            self.wdpk.W_audit_now, self.wdpk.W_audit_ref, TAU5)
        if freeze:
            return 'SAFE_STOP', None, 'DATA_DRIFT_FREEZE'
        # 3) 提议 → 级联选证（复用 v5；门阈值换 tau6）
        s_emo = self.famk.observe(context.face, t_now)
        gamma = self.famk.gamma(s_emo)
        ok, x, why = self.v5.select_with_tau(x0_state, t_now, rule_id, context,
                                             tau=compose(tau6, gamma))
        if not ok:
            return 'SAFE_STOP', None, why
        # 4) 签发时间证书（边际 m 来自 VACK/BCK；有效期由引理 47）
        cert = self.dacs.issue(x, margin=why.margin, gate_vec=why.gates,
                               W_v=self.wdpk.H_W, theta_v=self.fmpp.version,
                               t_now=t_now)
        self.held = cert
        return 'FORGED', x, 'FORGED_WDB'

    def control_step(self, t_now, fresh_cert):
        """1 kHz 环：只做证书调度，O(1)；不跑提议/认证"""
        x, mode = self.dacs.step(t_now, fresh_cert, self.held,
                                 self.wdpk.H_W, self.fmpp.version)
        return x, mode                     # FRESH / HOLD / SAFE_STOP

    def ecs_v6(self, base_v5, n_flow, s_emo, c, cert, t_now) -> float:
        eta_data = sigmoid((self.wdpk.tau_supp - self.wdpk.support_score(c)) / BETA)
        eta_lat = (sigmoid((cert.T_val - (t_now - cert.t_issue)) / BETA_T)
                   if self.dacs.valid(cert, t_now, self.wdpk.H_W,
                                      self.fmpp.version) else 0.0)
        return base_v5 * eta_data * eta_lat
```

### 集成流水线（v5 → v6）

```
数据侧（慢时域，独立托管）：
  采集 ──▶ 溯源记录 p_i + 同意令牌 ──▶ 内容哈希 H(W) ──▶ 四划分互斥冻结
       ──▶ 支持阈值 τ_supp（W_cert 分位）──▶ 金丝雀植入 W_red
       ──▶ 延迟压测切片 W_lat（算力争用/GPU 抖动下采集）

离线/慢时域：
  固化：E_loop 片段 ──▶ DP-SGD+KL（v5）──▶ W_audit 外部验收（定理 9）
        ├─ 污染度 > δ_c ──▶ 拒绝上线
        └─ 改进 ∧ 无分层回退 ──▶ 上线；否则回滚
  漂移：W_audit_now vs W_audit_ref ──▶ D_t ──▶ ρ_t 或冻结（DTRP）

在线准入（异步，秒级）：
  支持域检查（s_supp）──域外──▶ 回退 v4 规则提议
  域内 ──▶ 漂移重标定 τ^6=ρ·γ·τ^4 ──▶ v5 级联选证 ──▶ 签发 cert(t_issue,T_val)

在线控制环（目标 < 0.6 ms）：
  每周期：cert 有效？──是──▶ 执行（FRESH）
                   └─否──▶ 有仍有效旧证书？──是──▶ Hold（降级）
                                              └─否──▶ SafeStop
  全程：任一被执行动作都被一张有效证书覆盖（定理 10）
```

## 3. 复杂度分析（增量更新，含延迟预算）

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 | 实时性指标 |
|---|---|---|---|---|
| WDPK.support_score | O(log\|W_cert\|)+O(k) FAISS | O(\|W\|·d) | \|W\|≤200k, k=8 | < 0.2 ms（可缓存） |
| WDPK.contamination | O(\|E\|·d) 离线 / LSH O(\|E\|) | O(\|E\|) | δ_c=0.02 | 离线分钟级 |
| WDPK.audit_accept | O(\|W_audit\|) 推理 | O(1) | N_audit~20k | 离线，固化后一次 |
| DACS.issue/valid/step | O(1) | O(1) | — | < 0.005 ms/周期 |
| DTRP.update | O(1) 草图 / O(N·m) MMD 离线 | O(1) 草图 | δ_drift=0.05 | 在线 < 0.05 ms |
| EFA-v6 新增开销 | O(1) 支持检查 + O(1) 调度 | O(1) | — | +~0.02 ms |
| 控制环总 | O(1) | O(1) | — | **P99 ~0.57 ms（v5 0.55 ms）** |
| 端到端在线 | ~0.6 ms 环 + 异步准入 | — | — | 正面偿还 R54/R49 |

**通信开销**：W 版本哈希（32 B）随证书下发；支持参考原型（DP，~2 KB/站）；溯源链仅存本地，不传输原始条目。延迟压测切片与金丝雀只存在于托管侧，站点不可写。

**延迟预算分解（D=1.0 ms，ε=0.05 ms）**：EEK 0.03 + BCK(事件触发，均值) 0.30 + 证书校验/调度 0.005 + 余量 0.05 ≈ 0.385 ms（P50）；P99 触发率上升时 ~0.57 ms。FMPP/VACK/FAMK 全部在准入异步域，不计入环内截止期。

## 4. 正确性论证（增量更新）

### 引理 45（污染检测功效）

**陈述**：m 个独立金丝雀、近重复 LSH 召回 ρ_lsh，则对污染比例 δ 的检测功效 ≥ 1−(1−δ)^m·(1−ρ_lsh·δ)。∎

**诚实边界**：金丝雀只能抓「被整体记忆/复现」的泄漏；对语义等价但近重复不命中的隐性泄漏，功效下降，需配合影响函数/成员推断做离线抽检。

### 引理 46（支持域覆盖）

**陈述**：τ_supp 取 W_cert 的 (1−α) 分位，则在 W_cert 上误拒 ≤ α；协变量漂移下误接受无上界。∎

### 引理 47（边际漂移 Lipschitz 界）

**陈述**：|m(x_t)−m(x_{t0})| ≤ L_s·v_max·(t−t0)，故 T_val=(m_issue−m_required)/(L_s·v_max)。∎

### 定理 v6（数据/时间双锚与执行集收缩，总装）

**陈述**：在 v5 假设 (B1)~(B7) 及新增 (B8) W_audit 与部署同分布（在覆盖域内）且污染度 ≤ δ_c、(B9) L_s、v_max 为真实上界 下：
(i) Exec_CADVS-v6 ⊆ Exec_CADVS-v5（严格：支持域与时效约束非恒真）⊆ … ⊆ Exec_v29；
(ii) 外部裁判：固化上线后部署博弈率由定理 9 界约束（覆盖域内）；
(iii) 截止期安全：任意延迟分布下 x_exec(t)∈S（定理 10），Hold 不破坏不变量；
(iv) 时效：t−t_issue > T_val 的证书可能失效，必须刷新/Hold/Stop（定理 11）；
(v) 漂移单调：ρ_t≥1 ⇒ 执行集只缩不涨（定理 12）；ρ=1 且域内且新鲜时精确退化 v5；
(vi) 覆盖-延迟：κ(D) ≤ P(C(c)≤D)，安全可保、自主性有上界（定理 13）。

**证明**：(i) 同门 + 支持域 + 阈值只紧 + 时效约束；(ii)(iii)(iv)(v)(vi) 分别由定理 9~13。∎

**诚实声明**：(B8) 是全局最脆弱假设——W_audit 与部署同分布只在覆盖域内成立，OOD 下外部裁判失效；(B9) 的 L_s/v_max 若低估，T_val 会偏大，陈旧证书可能不安全（故需在线速率监控 + 保守上界）；定理 9 只界「可观测博弈」，不可观测的语义违背仍可能存在于 W_audit 覆盖之外；数据集溯源与同意令牌的合规性随辖区变化。

## 7. 本轮最大风险（最终确认）

**一句话**：**见证数据集自身不可见证**——它可能被污染（训练泄漏/投毒）、会漂移（不代表部署分布）、且更新滞后；一旦「外部裁判」失真，定理 9 的保证就退化为「在错误数据上正确」，系统会以更精致的方式自证正确，而延迟压力又会推动系统更频繁地复用旧证书；数据集与延迟两个锚同时失效时，fail-closed 保住了物理安全，却保不住语义正确。
