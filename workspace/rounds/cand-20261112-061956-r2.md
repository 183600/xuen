# 第 60 轮（承接第 59 轮「执行接地层」IP-145~151；灵感循环第 2 轮；本轮灵感：「任务规划」×「多机评测」）

> 第 59 轮把证据承诺一路钉到执行层物理：BUQ 在线辨识电机结构性不确定、ERTC 契约化嵌入式实时性、EEIS 把 δ_f 编译成带证书的阻抗参数、CLEP 让执行实测回流为第 5 模态、PCE+++ 四预算保证绝不冒险。但整条论证链仍默认两件事：**其一，计划是给定的**——仿佛检查点序列天然正确，局部安全可以线性相加成全局安全；**其二，评测是单机的**——仿佛一台机器人跑出的成功率就是「能力」的无偏估计。本轮两个灵感正好击穿这两个默认：**任务规划**告诉我们，计划是带前置条件、资源约束、可修复分支的**长程随机过程**，检查点之间存在强相关与不可逆承诺，逐点 δ_f 的联合界会在长任务上**指数式破产**；**多机评测**告诉我们，排行榜不是真值，而是**带机器人随机效应、任务抽样、共享训练污染与选择偏差的统计估计**，N 台机器人的一致可能只是 `n_eff ≪ N` 的**相关证据幻觉**。本轮核心命题：**把「局部检查点安全」升级为「计划级风险会计」；把「单机评测」升级为「群体级有效性证书」；并用非对称律锁死：评测提升的是「我们有多知道」，绝不能直接兑换成「这台机器人此刻有多安全」。**

核心矛盾：
- **H32（长程风险破产·逐点联合界的空洞化）**：第 59 轮按检查点给出 δ_f，并用联合界 `P_safe ≥ 1 − Σ_cp δ_f`。但真实任务动辄数十到数百检查点：δ_f=10⁻⁴、n=100 时联合界已退化到 1% 量级；若再叠加探针/微调/执行各项误差，长任务的安全声明几乎必然空洞。更糟的是，检查点共享地形、信念、电机状态与固件，失败事件**高度正相关**；盲目用独立联合界既过保守（忽略正相关可收紧），又可能在负相关/共因失效下**不安全**。必须把「风险」从标量相加升级为**带依赖结构的计划级代数**，并承认：**长程保证的可信度，取决于依赖结构估计的可信度**。
- **H33（规划抽象泄漏·符号可行 ≠ 几何/执行可行）**：任务规划器在符号层产出「抓取—移动—放置」序列，前置条件与效果被当作确定性；但符号前置条件到几何/力/执行约束的**接地**存在不确定性（可抓但抓不稳、可达但会碰、能放置但会滑）。计划可能「符号上完全合法、执行上处处惊险」。若计划层不携带**风险账本与修复义务**，下层只能在每个检查点临时救火，局部最优会累积成全局死局。
- **H34（评测相关性与古德哈特·排行榜不是真值）**：多机评测中，机器人共享策略权重、仿真器、训练数据、传感器批次与操作员；任务与场景从有限分布抽样；排行榜按同一批任务选择模型。于是 `N` 台机器的成功率不是 `N` 个独立样本，排名存在选择偏差与**评测泄漏**。若把「榜上第一」当作安全证据，就是把**评测分布内的插值**冒充**部署分布外的泛化**。评测必须自带**有效样本量、随时有效置信序列、交换性检验与污染检测**，否则它只是更精致的过拟合。

## 0. 直觉与动机

**灵感 1（任务规划 → 计划级风险代数 PCRA）**
直觉：计划不是一条直线，而是一张带分支、重试、回退与放弃边的 **DAG**。安全不是「每个点都安全」，而是「沿着这张图走，失败概率被控制在预算内，且任何失败都有出路」。就像电路里的**风险电流**：串联节点把风险逐级累加，并联冗余把风险分流，重试把单次风险变成几何级数，修复边则把「失败」重新路由到「可恢复态」。关键洞见：**检查点之间的相关结构不是噪声，而是计划的一等公民**。同一段碎石地上的三次落脚点，其失败事件应由一个共同的「地形难度」潜变量解释；同一固件的三次探针，其误差应由一个共同的「标定漂移」解释。PCRA 用**依赖图 + copula/共因因子**给出计划失败概率的区间 `[L_lo, L_hi]`：安全用 `L_hi`，规划乐观用 `L_lo`；当依赖结构未知时退回联合界。这样长任务不再只有「空洞的保守」或「危险的独立」两个选项，而是可以**用估计依赖来换取非空洞的保证**。

**灵感 2（任务规划 → 分层承诺-修复 HCR）**
直觉：长程自主的本质不是「一次算对」，而是「错了能修」。人类完成任务时一直在修复：抓偏了重抓、门推不开换角度、路径堵了绕行、实在不行放弃子任务求助。HCR 把这种能力形式化：计划是一个**条件计划/策略**，每个节点标注承诺等级（L0 观察、L1 可逆、L2 不可逆），每条失败边挂接修复算子（重试、局部重规划、回退、子任务替换、人工接管、安全停）。承诺不是「押上全部」，而是「在当前可修复包络内向前走一步」。计划证书必须证明：从承诺前沿的任一可达失败态出发，存在一条在 `T_repair_max` 内到达安全节点的修复路径，或能安全停；否则该计划**没有资格承诺**。这把第 59 轮的「单点执行契约」升级为「计划级修复契约」。

**灵感 3（多机评测 → 群体评测协议 PEP）**
直觉：把 N 台机器人跑同一套任务，看起来像 N 次独立实验；实际上它们可能共享同一个策略、同一个仿真器、同一批训练场景、甚至同一个工程师的调参偏好。统计上这叫**聚类/设计效应**：有效样本量 `n_eff = N / (1 + (m−1)ρ̄)`，其中 `ρ̄` 是簇内相关。若 `ρ̄=0.5`、每簇 10 台，则 100 台机器人只值约 18 台独立样本。PEP 因此不报「N 台平均成功率」，而报：**机器人随机效应、任务随机效应、策略效应、`n_eff`、以及在这些效应下的区间估计**。排名用 Bradley-Terry/混合效应模型，并给**随时有效**的置信序列——允许你随时看榜、随时停实验，覆盖率仍不低于 `1−α`。这不是统计装饰，而是防止「多机评测」变成「多副本自欺」。

**灵感 4（合流 → 计划-群体证据耦合 PPEC）**
直觉：群体评测对单机最有价值的地方，不是「别人也过了」，而是**借用群体先验来估计稀有失败率**：单机几百次接触可能一次都没遇到某种失效，但群体上万次里遇到过；分层贝叶斯的部分池化（partial pooling）能把这种信息以**收缩（shrinkage）**的方式借给单机。但借用有前提：机器人之间必须**可交换（exchangeable）**。若某台机器人换了电机、改了固件、处在不同地形，强行借用就是**负迁移**。PPEC 因此先做交换性检验，再决定收缩系数 `λ_r`；并且执行非对称律：**群体证据可以抬高某台机器人的风险估计（发现异常），但不能单独把它的安全风险界压到本地证据之下**。群体可以让我们「更知道」，但不能替这台机器人「担保」。

**灵感 5（评测感知规划 EAP + 六预算 PCE++++）**
直觉：既然评测是统计实验，那么「跑哪些任务、用哪些机器人、跑多少次」本身就是**可规划的实验设计**。EAP 把任务规划与评测设计联合优化：一边选动作序列，一边选能最大程度区分候选策略/发现失败模式的评测任务；但必须设**评测防火墙**——规划器不能直接窥视留出集结果，只能通过消耗 `B_eval` 的查询协议获得粗化统计；假设必须预注册；训练/评测任务分布要做污染检测。否则「评测感知」会迅速退化为「对着考卷改答案」的古德哈特机器。第 59 轮的四预算因此扩展为六预算：`B_probe / B_ft / B_ux / B_exec / B_repair / B_eval`，彼此硬隔离、单调消耗、耗尽即保守。

## 1. 形式化定义（增量：定义 153–161）

**定义 153（计划 DAG 与计划级风险代数 PCRA）** 直觉：计划是带控制结构的图，风险沿边流动并被共因结构放大或收紧。形式化：计划
```
π = (V, E, ℓ, pre, eff, p, c, R_dep)
```
`V` 为检查点/动作节点，`E` 的边标签 `ℓ(e) ∈ {seq, par, branch, retry(k), repair, abort}`；`pre_v/eff_v` 为符号前置/效果；`p_v(ξ_exec, b_r, ε_plan)` 为局部失败概率；`c_v` 为执行成本；`R_dep` 为依赖模型。共因结构用潜变量集合 `Z = {Z_C}` 表示：同一地形段、同一固件、同一信念源、同一操作员下的节点共享 `Z_C`。给定依赖模型，计划失败概率定义为
```
P_fail(π) = P( ∃v∈V : F_v ),
F_v = { Z_C(v) 越过阈值 θ_v(ξ_exec,b_r) }
```
当 `R_dep` 已知（如高斯 copula 相关矩阵 `R`）时用多元正态积分精确/数值计算；当 `R_dep` 仅有置信集 `ℛ` 时输出区间
```
L_lo(π) = min_{R∈ℛ} P_R(∃v F_v),   L_hi(π) = max_{R∈ℛ} P_R(∃v F_v).
```
安全判定只用 `L_hi`；规划排序可用 `L_lo`。**退化护栏**：`ℛ` 含独立 copula 时 `L_hi = 1−∏(1−p_v)`，含完全正相关时 `L_hi ≤ Σ p_v` 可被显著收紧——这正是长任务从「联合界空洞」走向「非空洞保证」的关键。风险代数给出组合规则：`seq` 串联、`par` 冗余、`branch` 择一、`retry(k)` 几何折减、`repair` 将失败重路由到修复子图；所有规则必须**单调**（局部风险增加不得降低 `L_hi`）且**可组合**（子图风险可替换为区间）。

**定义 154（风险预算分配 RBA）** 直觉：给定计划总风险预算，如何把 `δ_plan` 分给各节点，使执行成本最小且联合失败不超预算。形式化：局部风险预算 `δ_v` 与实现成本 `c_v(δ_v)`（更多探针/更慢动作可降低 `δ_v`，`c_v` 凸增）。分配问题
```
min_{δ_v}  Σ_v c_v(δ_v)
s.t.       L_hi(π; {δ_v}) ≤ δ_plan
           δ_v ∈ [δ_min(v), δ_max(v)],  Σ_v δ_v ≤ δ_plan·(1+slack)
```
`L_hi` 对 `δ_v` 单调，故用**注水/贪心 + 区间传播**求解；离线预计算计划模板的分配表，在线按新证据热启动。**随时有效再分配**：每完成一个检查点，用观测更新 `p_v` 与 `R_dep`，并以鞅/超级鞅记账 `M_t = Σ_v (δ_v − 1[F_v])`，保证「随时重分配、随时看结果」不破坏 `δ_plan` 的覆盖率。若 RBA 不可行（`δ_plan` 小于 `L_hi` 下界），计划必须**降档**（缩短、绕行、加冗余）或**拒绝承诺**。

**定义 155（分层承诺-修复 HCR）** 直觉：承诺是按等级、按可修复性逐步加深的；修复能力是计划的一部分。形式化：条件计划
```
π_cond = (G, κ, Repair, Commit, Stop)
```
`G` 为带观测分支的计划图；`κ: V→{L0,L1,L2}` 为承诺等级；`Repair` 为失败边上的修复算子集合 `{retry, local_replan, backtrack, subtask_replace, human_handover, safe_stop}`；`Commit` 为承诺前沿（当前允许进入的 L2 节点集合）；`Stop` 为安全停流形。修复预算 `B_repair=(N_repair, T_repair_max, E_repair_max)`。**修复完备性**：对承诺前沿 `F_commit` 的每个可达失败态 `s`，存在修复轨迹 `ρ(s)` 使 `ρ(s)` 在 `T_repair_max` 内到达 `Stop` 或某个 `κ≤L1` 的安全节点；若 `s` 已不可修复，则 `safe_stop(s)` 必须在 `T_stop_max` 内可达。计划证书
```
Cert_plan = (π, {δ_v}, L_hi, F_commit, Repair_policy,
             B_repair, deadend_free, repair_complete, version)
```
`deadend_free=true` 当且仅当不存在「进入后既不能修复也不能安全停」的可达态。**非对称律**：修复只能把计划变得**更保守**（降低承诺等级、增加回退边），不得用「修复成功率高」去抵消未验证的 L2 风险。

**定义 156（群体评测协议 PEP）** 直觉：多机评测是带随机效应的分层抽样，不是 N 次独立抛硬币。形式化：评测设计
```
Ξ = (R, T, E, S, assignment, pairing)
```
`R` 为机器人总体抽样，`T~D_task` 为任务，`E~D_env` 为环境，`S` 为随机种子；`pairing` 表示同任务同环境的配对比较。观测模型
```
y_{r,t,e,s} = μ + τ_{policy} + b_r + c_t + d_{r,t} + ε_{r,t,e,s}
b_r ~ N(0,σ_b²), c_t ~ N(0,σ_c²), ε ~ N(0,σ_ε²)
```
`b_r` 为机器人随机效应，`c_t` 为任务随机效应，`d_{r,t}` 为机器人×任务交互。**设计效应**：对按机器人聚类的 `m` 个样本、簇内相关 `ρ̄`，
```
n_eff = N / (1 + (m−1)ρ̄),   N=|R|·|T|·|E|·|S|.
```
PEP 输出 `(τ̂, CI, b̂_r, ĉ_t, n_eff, design_effect, D_task, D_env, pairing_scheme)`，并对**策略选择后的偏差**给出修正：若同一批 `(T,E)` 被反复用于选模型，报告必须区分「选择集」与「确认集」，或使用嵌套/交叉拟合。**护栏**：`n_eff < n_min` 的结论标为「探索级」，不得进入安全证据门。

**定义 157（随时有效排名证书 AVR）** 直觉：排行榜会被反复查看、随时停实验；普通置信区间在可选停止下失效。形式化：用 Bradley-Terry 混合效应模型
```
P(i ≻ j | b) = σ(β_i − β_j + b_i − b_j),   b_r ~ N(0,σ_b²)
```
对每个策略对/秩构造**置信序列** `CS_t(β)`：对任意停时 `τ`，
```
P( β ∈ CS_τ 对所有 τ ) ≥ 1−α.
```
由混合鞅构造 `M_t(β)=exp(λ S_t(β) − ψ(λ)V_t(β))`，取 `CS_t={β: sup_{s≤t} [λ_s S_s − ψ(λ_s)V_s − log(1/α) − ...] ≤ 0}`。排名证书
```
Rank_cert = (rank_intervals_i, pairwise_CS, coverage=1−α, anytime_valid=true,
             contamination_flag, n_eff, version)
```
**污染检测**：对训练任务分布与评测任务分布做 MMD/能量距离检验，并做近重复场景检索；`contamination_flag=true` 时排名只能标「污染风险」，不得用于发布级结论。

**定义 158（计划-群体证据耦合 PPEC）** 直觉：群体先验只在可交换时借给单机；借来的只能是「关于能力的先验」，不能是「关于这台机器此刻安全的担保」。形式化：分层模型
```
θ_r ~ N(μ_pop, τ²),   y_r | θ_r ~ N(θ_r, σ_r²/n_r)
λ_r = τ² / (τ² + σ_r²/n_r) ∈ [0,1]
θ̂_r^pop = (1−λ_r) θ̂_r^local + λ_r μ_pop.
```
**交换性检验** `H_ex: {θ_r}` 在给定协变量（机型、固件、地形族）下可交换；用先验预测检验/MMD，显著性 `α_ex`。若拒绝，按协变量分层或令 `λ_r=0`；**负迁移护栏**：对任一单机，若 `λ_r>0` 但 `θ̂_r^pop` 使其安全风险估计低于本地下界，则强制取本地下界。群体对安全的作用是**单向的**：
```
δ_f^safety(r) = max( δ_f^local(r), δ_f^pop(r) · 1[exchangeable] )
```
即群体只能**抬高**风险估计（发现异常失效模式），不能单独**降低**某台机器人的安全界。群体对**能力估计/排名**的作用则可以是双向的，只要交换性通过且报告 `n_eff`。执行模态之外的扩展模态集记 `ℳ⁺⁺ = ℳ⁺ ∪ {pop}`，`pop` 仅参与对账与先验构造，**不得**作为 EV-xmodal/EV-human 的独立佐证。

**定义 159（评测感知规划 EAP）** 直觉：评测设计是可规划的实验；但必须防火，防止对着考卷改答案。形式化：联合决策
```
max_{π, Ξ}  E[U_task(π)] − λ_risk·L_hi(π) − λ_cost·cost(Ξ)
             + λ_info·I(θ; y_Ξ | π)
s.t.        cost(Ξ) ≤ B_eval,   Ξ ⊂ 𝒯_visible,
            firewall(π, 𝒯_holdout)=true,
            preregister(H) ∧ contamination_test(𝒯_train, 𝒯_eval) ≤ ε_contam
```
`𝒯_visible` 为规划器可见任务集，`𝒯_holdout` 为留出确认集；`firewall` 规定规划器只能通过**预注册查询协议**获得粗化统计，不能读取逐样本结果。古德哈特间隙
```
|R_bench(π) − R_true(π)| ≤ δ_goodhart
```

### IP-152 PCRA（计划级风险代数）

```python
@dataclass
class RiskInterval:
    lo: float
    hi: float
    def __add__(self, o):  # 串联：风险预算可加（上界保守）
        return RiskInterval(self.lo + o.lo, min(1.0, self.hi + o.hi))
    def __mul__(self, o):  # 独立冗余：失败需同时发生
        return RiskInterval(self.lo * o.lo, self.hi * o.hi)

class PlanRiskAlgebra:
    """计划 DAG 的失败概率区间计算与算子组合。"""
    def __init__(self, dependence_model, alpha_dep=0.05):
        self.R = dependence_model          # copula 相关矩阵或相关置信集
        self.alpha_dep = alpha_dep

    def local_risk(self, node, xi_exec, belief, env):
        # 复用第 59 轮执行接地证据：节点失败 = 几何/力/执行/证据门联合失败
        p_geo = node.geo_risk(belief, env)
        p_force = node.force_risk(xi_exec, belief)
        p_exec = node.exec_risk(xi_exec)          # 来自 BUQ/ERTC
        p_evid = node.evidence_risk(belief)       # 来自七类证据门
        return 1 - (1-p_geo)*(1-p_force)*(1-p_exec)*(1-p_evid)

    def failure_interval(self, plan, xi_exec, belief, env):
        p = {v: self.local_risk(v, xi_exec, belief, env) for v in plan.V}
        # 共因簇：同簇节点由同一潜变量驱动
        clusters = plan.common_cause_clusters()   # list[set[node]]
        if self.R.known:
            # 高斯 copula：数值积分/蒙特卡洛 + 保守分位数
            lo = self._copula_union(p, clusters, self.R, q=self.alpha_dep/2)
            hi = self._copula_union(p, clusters, self.R, q=1-self.alpha_dep/2)
            return RiskInterval(lo, hi)
        # 依赖未知：退回联合界（安全）与 Fréchet 下界（乐观）
        hi = 1.0 - np.prod([1.0 - p[v] for v in plan.V])
        lo = max(p.values()) if p else 0.0
        return RiskInterval(lo, hi)

    def compose(self, op, children):
        """按控制结构组合子计划风险区间。"""
        if op == 'seq':
            out = RiskInterval(0.0, 0.0)
            for c in children: out = out + c
            return out
        if op == 'par':       # 冗余：全部失败才失败
            out = RiskInterval(1.0, 1.0)
            for c in children: out = out * c
            return out
        if op == 'branch':    # 择一：所有分支都失败才失败
            out = RiskInterval(1.0, 1.0)
            for c in children: out = out * c
            return out
        if op.startswith('retry'):
            k = int(op.split('(')[1].rstrip(')'))
            p = children[0]
            return RiskInterval(p.lo**(k+1), p.hi**(k+1))
        if op == 'repair':
            p_fail, p_repair = children[0], children[1]
            return RiskInterval(
                p_fail.lo * (1 - p_repair.hi),
                p_fail.hi * (1 - p_repair.lo)
            )
        if op == 'abort':
            return RiskInterval(0.0, 0.0)  # 放弃不算失败，但由上层效用扣除
        raise ValueError(op)

    def _copula_union(self, p, clusters, R, q):
        # 简化：按簇聚合后用相关矩阵采样；生产版用高维正态 CDF 界
        samples = sample_gaussian_copula(R, n=4096, seed=0)
        fail = np.zeros(samples.shape[0], dtype=bool)
        for C in clusters:
            z = samples[:, list(C)]
            thr = [norm.ppf(1-p[v]) for v in C]
            fail |= np.any(z < np.array(thr), axis=1)
        return float(np.quantile(fail.astype(float), q))
```

### IP-153 RBA（风险预算分配）

```python
class RiskBudgetAllocator:
    def __init__(self, risk_algebra, delta_min=1e-8, delta_max=1e-2):
        self.ra = risk_algebra
        self.dmin, self.dmax = delta_min, delta_max

    def allocate(self, plan, delta_plan, xi_exec, belief, env):
        # 初始局部风险
        p = {v: self.ra.local_risk(v, xi_exec, belief, env) for v in plan.V}
        if sum(p.values()) <= delta_plan:
            return {v: p[v] for v in plan.V}, True

        # 注水：按降低单位风险的边际成本排序，向高风险节点购买“探针/减速”
        delta = {v: self.dmax for v in plan.V}
        budget = delta_plan
        # 先给每个节点最小预算，保证可执行
        for v in plan.V:
            delta[v] = self.dmin
            budget -= self.dmin
        if budget < 0:
            return None, False

        # 贪心：每次把预算给“边际风险下降/成本”最大的节点
        while budget > 1e-12:
            best, best_gain = None, -1.0
            for v in plan.V:
                if delta[v] >= self.dmax: continue
                step = min(self.dmax - delta[v], budget)
                gain = (self._risk_reduction(plan, delta, v, step)
                        / (self._marginal_cost(v, delta[v], step) + 1e-12))
                if gain > best_gain:
                    best, best_gain = v, gain
            if best is None: break
            step = min(self.dmax - delta[best], budget)
            delta[best] += step
            budget -= step

        # 用风险代数验证上界
        L = self._ledger_upper(plan, delta)
        return (delta, True) if L <= delta_plan else (None, False)

    def _ledger_upper(self, plan, delta):
        # 把节点预算代入依赖模型，返回计划失败上界
        return self.ra.failure_interval(
            plan.with_local_risk(delta), None, None, None
        ).hi

    def reallocate_anytime(self, ledger, observed_failures, delta_plan):
        """鞅记账：M_t = Σ(δ_v − 1[F_v])；超界即降档。"""
        M = sum(ledger.delta[v] - int(v in observed_failures) for v in ledger.delta)
        if M > delta_plan:
            return None, "risk_bank_exhausted"
        return ledger, "ok"
```

```python
@dataclass
class ConditionalPlan:
    G: nx.DiGraph                 # 计划图，失败边指向修复算子
    kappa: dict                   # node -> L0/L1/L2
    repair: dict                  # failure_state -> repair_operator
    commit_frontier: set
    stop_manifold: set

class CommitmentRepairPlanner:
    def __init__(self, repair_budget):
        self.B = repair_budget

    def build(self, symbolic_plan, risk_ledger, belief, xi_exec):
        G = self._expand_repair_edges(symbolic_plan, belief, xi_exec)
        kappa = self._assign_commit_levels(G, risk_ledger)
        return ConditionalPlan(G, kappa, self._repair_policy(G), set(), set())

    def verify(self, pi_cond, start):
        """修复完备性 + 无死局检查（BFS 于承诺前沿可达失败态）。"""
        reachable = self._reachable_states(pi_cond.G, start)
        frontier = {s for s in reachable if pi_cond.G.nodes[s].get('level') == 'L2'}
        for s in frontier:
            if not self._has_repair_path(s, pi_cond.G, self.B.T_repair_max):
                if not self._safe_stop_within(s, self.B.T_repair_max):
                    return False, f"deadend:{s}"
        # 修复次数预算
        if self._min_repairs(pi_cond, frontier) > self.B.N_repair:
            return False, "repair_budget"
        return True, "ok"

    def _has_repair_path(self, s, G, T_max):
        # 在修复图上做时间约束可达性；修复边代价 = 估计修复时长
        return nx.has_path(G, s, self._safe_set(G)) or self._safe_stop_within(s, T_max)

    def _repair_policy(self, G):
        # 优先级：retry < local_replan < backtrack < subtask_replace < human < safe_stop
        return {s: self._cheapest_feasible(G, s) for s in G.nodes if G.out_degree(s) > 0}
```

### IP-155 PEP（群体评测协议）

```python
class PopulationEvaluation:
    def __init__(self, n_min=30, rho_prior=0.3):
        self.n_min = n_min
        self.rho_prior = rho_prior

    def effective_sample_size(self, groups):
        """groups: list[list[episode]]，按机器人聚类。"""
        N = sum(len(g) for g in groups)
        if len(groups) <= 1: return float(N)
        m = N / len(groups)
        rho = self._estimate_icc(groups)          # ANOVA/混合模型估计
        rho = max(rho, self.rho_prior)            # 保守：先验下界
        return N / (1 + (m - 1) * rho)

    def fit_mixed_effects(self, data):
        # data: (robot, task, env, seed, policy, y)
        # 用 REML/变分近似拟合 y = μ + τ_policy + b_r + c_t + d_rt + ε
        model = MixedEffectsModel(formula='y ~ policy + (1|robot) + (1|task) + (1|robot:task)')
        fit = model.fit(data)
        return {
            'tau': fit.params['policy'],
            'ci': fit.conf_int(alpha=0.05),
            'b_r': fit.random_effects('robot'),
            'c_t': fit.random_effects('task'),
            'n_eff': self.effective_sample_size(self._group_by_robot(data)),
            'design_effect': len(data) / max(1.0, self.effective_sample_size(self._group_by_robot(data))),
            'level': 'publish' if self.effective_sample_size(self._group_by_robot(data)) >= self.n_min else 'explore'
        }

    def selection_bias_correction(self, select_set, confirm_set):
        """选择集用于挑模型，确认集用于报结论；交叉拟合避免赢家诅咒。"""
        tau_sel = self.fit_mixed_effects(select_set)['tau']
        tau_conf = self.fit_mixed_effects(confirm_set)['tau']
        return tau_conf, abs(tau_sel - tau_conf)

    def _estimate_icc(self, groups):
        # 单因素随机效应 ICC = σ_b²/(σ_b²+σ_w²)
        return icc_from_groups(groups)
```

### IP-156 AVR（随时有效排名）

```python
class AnytimeValidRanking:
    def __init__(self, alpha=0.05):
        self.alpha = alpha

    def pairwise_confidence_sequence(self, outcomes):
        """outcomes: 按时间顺序的 (i,j,winner)；返回每对的 CS。"""
        cs = {}
        for (i, j) in self._pairs(outcomes):
            S, V, t = 0.0, 0.0, 0
            seq = []
            for (a, b, w) in outcomes:
                if {a, b} != {i, j}: continue
                t += 1
                x = 1.0 if w == i else 0.0
                S += x
                V += x * (1 - x) + 1e-9
                # 混合鞅：对 β 网格取上确界，构造 CS
                m = max(self._martingale(beta, S, V, t) for beta in self._beta_grid())
                seq.append((t, m))
            cs[(i, j)] = self._cs_from_martingale(seq, self.alpha)
        return cs

    def rank_certificate(self, cs, n_eff, contamination_flag):
        # 由成对 CS 推秩区间：i 的秩 = 1 + #j 使得 P(j≻i) 的 CS 下界 > 0.5
        intervals = {}
        for i in self._policies(cs):
            better = sum(1 for j in self._policies(cs)
                         if i != j and self._prob_lower(cs, j, i) > 0.5)
            intervals[i] = (better + 1, better + 1 + self._ties(cs, i))
        return RankCertificate(
            rank_intervals=intervals,
            pairwise_CS=cs,
            coverage=1 - self.alpha,
            anytime_valid=True,
            contamination_flag=contamination_flag,
            n_eff=n_eff,
            version=self.version
        )

    def _martingale(self, beta, S, V, t):
        # 简化：M_t = exp(β S − (e^β−1) V)；生产版用混合先验积分
        return np.exp(beta * S - (np.exp(beta) - 1) * V) / (1 + t)

    def _cs_from_martingale(self, seq, alpha):
        # 取 sup_{s<=t} M_s <= 1/alpha 的 β 集合
        return [b for b in self._beta_grid()
                if max(m for (_, m) in seq) <= 1 / alpha]
```

### IP-157 PPEC（计划-群体证据耦合）

```python
class PlanPopulationCoupler:
    def __init__(self, alpha_ex=0.05):
        self.alpha_ex = alpha_ex

    def borrow(self, local_post, pop_post, covariates):
        """local_post: (mean, var, n)；pop_post: (mu_pop, tau2, b_r)。"""
        if not self.exchangeable(local_post, pop_post, covariates):
            return local_post, 0.0, "not_exchangeable"
        lam = pop_post.tau2 / (pop_post.tau2 + local_post.var / max(1, local_post.n))
        lam = float(np.clip(lam, 0.0, 1.0))
        mean = (1 - lam) * local_post.mean + lam * pop_post.mu_pop
        var = (1 - lam) * local_post.var + lam * pop_post.tau2
        return LocalPosterior(mean, var, local_post.n), lam, "borrowed"

    def exchangeable(self, local_post, pop_post, covariates):
        """按协变量分层后做先验预测检验/MMD；返回是否可交换。"""
        if not self._same_stratum(covariates):
            return False
        return prior_predictive_pvalue(local_post, pop_post) > self.alpha_ex

    def safety_bound(self, delta_local, delta_pop, borrowed, exchangeable):
        # 非对称律：群体只能抬高安全风险界
        if exchangeable and borrowed:
            return max(delta_local, delta_pop)
        return delta_local

    def population_disagreement(self, beliefs, rho_pop):
        """群体作为第 6 类对账模态；一致不得减少探针需求。"""
        D_pop = 0.0
        for r in beliefs:
            tv = tv_distance(beliefs[r].label_dist, beliefs['local'].label_dist)
            q = abs(beliefs[r].quantile(0.99) - beliefs['local'].quantile(0.99))
            D_pop += rho_pop[r] * (tv + q / MU_SCALE)
        return D_pop
```

### IP-158 EAP（评测感知规划）

```python
class EvaluationAwarePlanner:
    def __init__(self, risk_algebra, pep, avr, firewall, eval_budget):
        self.ra = risk_algebra
        self.pep = pep
        self.avr = avr
        self.firewall = firewall
        self.B_eval = eval_budget

    def joint_plan(self, task, candidates, belief, xi_exec, budget):
        best = None
        for pi in candidates:
            ledger, ok = budget.rba.allocate(pi, budget.delta_plan, xi_exec, belief, task.env)
            if not ok: continue
            L = budget.rba._ledger_upper(pi, ledger)
            # 评测设计：仅在 firewall 可见集内选择，最大化信息增益
            xi = self._select_eval_design(pi, belief, budget.B_eval)
            if xi is None: continue
            info = self._expected_info_gain(xi, belief)
            cost = budget.cost_exec(pi) + budget.cost_repair(pi) + budget.cost_eval(xi)
            util = expected_task_utility(pi, belief) - budget.lambda_risk * L \
                   - budget.lambda_cost * cost + budget.lambda_info * info
            if best is None or util > best.util:
                best = (pi, ledger, xi, L, info, util)
        if best is None:
            return None, "no_feasible_plan"
        pi, ledger, xi, L, info, util = best
        # 古德哈特护栏：评测结果只能粗化返回，且不得写入安全证据
        if not self.firewall.pre_registered(xi):
            return None, "firewall_violation"
        return (pi, ledger, xi, L, info, util), "ok"

    def _select_eval_design(self, pi, belief, B_eval):
        # 在可见任务集上做贪心 D-最优/信息增益选择，留出集不可见
        return self.firewall.query_visible(belief, B_eval, strategy='d_optimal')

    def _expected_info_gain(self, xi, belief):
        # 互信息 I(θ; y_Ξ)；用后验采样近似
        return mutual_information_mc(belief.theta_post, xi, n=256)

    def update_after_eval(self, eval_result, belief, budget):
        # 评测结果只更新“能力/排名”信念，不更新安全证据
        rank_cert = self.avr.rank_certificate(
            eval_result.cs, eval_result.n_eff, eval_result.contamination_flag
        )
        belief.capability = self.pep.fit_mixed_effects(eval_result.data)
        belief.rank_cert = rank_cert
        budget.spend_eval(eval_result.cost)
        return belief
```

### IP-159 PCE++++（六预算）

```python
class SixBudget:
    def __init__(self, probe, ft, ux, exec_, repair, eval_):
        self.B = {'probe': probe, 'ft': ft, 'ux': ux,
                  'exec': exec_, 'repair': repair, 'eval': eval_}
        self.spent = {k: 0 for k in self.B}

    def spend(self, kind, amount):
        assert kind in self.B
        if self.spent[kind] + amount > self.B[kind]:
            return False
        self.spent[kind] += amount
        return True

    def voi_plan(self, pi, xi, meta_voi, info_gain, costs):
        return (meta_voi + self.lambda_info * info_gain
                - costs.exec_ - costs.repair - costs.eval)

    def degrade_order(self):
        # 预算耗尽的降级顺序：先停评测/解释，再缩计划/加修复，最后安全停
        return ['eval', 'ux', 'ft', 'repair', 'probe', 'exec']
```

```python
class PlanPopulationCertificate:
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| PCRA | O(\|V\|·d_C + S·d_Z)（S 为 copula 采样数，典型 4096） | O(\|V\|+\|E\|) | 依赖已知时区间覆盖；未知时退回联合界（安全） |
| RBA | O(k·\|V\|·log(1/ε))（注水迭代）；在线 O(\|V\|) 热启动 | O(\|V\|) | 分配后 `L_hi ≤ δ_plan`；鞅记账保持随时有效 |
| HCR | O(\|V\|+\|E_repair\|+N_frontier·(T_max/Δt)) | O(\|V\|+\|E\|) | 修复完备 + 无死局 + 修复预算不超 |
| PEP | O(N·d²)（混合效应 REML/变分） | O(N) | `n_eff` 保守估计、选择/确认分离、探索级/发布级分级 |
| AVR | O(P²·T)（P 策略数、T 样本数） | O(P²·T) | 任意停时覆盖 ≥1−α；污染一票否决 |
| PPEC | O(R·d + 检验) | O(R·d) | 交换性拒绝即 `λ=0`；群体对安全单向保守 |
| EAP | O(\|Π\|·(\|V\|+I_eval)) | O(\|Π\|+\|Ξ\|) | 防火墙预注册；留出集隔离；`δ_goodhart` 有界 |
| PCE++++ | O(1)/预算操作 | O(1) | 六预算单调、硬隔离、耗尽即降档 |
| J_planpop | O(1)/接触追加 | O(接触数+评测数) | 账本自洽、修复完备、排名有效、污染可审计 |

**正确性定理（Plan-Population Evidence Soundness, PPES）**
假设 A22–A55（第 53–59 轮）成立；**(A56)** PCRA：计划风险代数对 `seq/par/branch/retry/repair` 的区间组合是**单调且包含真实计划失败概率**；依赖模型已知时 `L_hi` 覆盖真实 copula 下的失败概率；未知时退回的联合界是有效上界。**(A57)** RBA：分配解满足 `L_hi(π;{δ_v}) ≤ δ_plan`；在线再分配的鞅记账保证任意停时风险不超预算。**(A58)** HCR：修复完备性检查是音完备的（不漏掉不可修复态）；`deadend_free=true` 蕴含从承诺前沿任一可达失败态存在 `T_repair_max` 内的修复/安全停路径；修复算子成本诚实上界。**(A59)** PEP：混合效应模型与 `n_eff` 估计保守；选择集/确认集分离；探索级结论不进入安全门。**(A60)** AVR：成对置信序列在任意停时覆盖真实参数，秩区间由成对 CS 保守导出；污染检测漏报率 ≤δ_contam。**(A61)** PPEC：交换性检验漏检率 ≤α_ex；`λ_r>0` 仅在同协变量层内；群体对单机安全界的非对称规则成立（只能抬高、不能单独压低）。**(A62)** EAP：评测防火墙不可绕过；预注册假设不可事后修改；留出集与训练/评测集无泄漏；`|R_bench−R_true| ≤ δ_goodhart`。**(A63)** PCE++++：六预算单调消耗、互不挪用；任一耗尽 ⇒ 保守降档。则：

1. **计划级安全界**：对任一通过 RBA 与 HCR 验证的计划 `π`，
```
P_fail(π) ≤ L_hi(π) ≤ δ_plan,
```
且若 `deadend_free=true`，则计划执行要么在 `B_repair` 内完成，要么在 `T_stop_max` 内到达安全停；不存在「进入后无法修复也无法安全停」的可达态。

2. **长程非空洞性**：当依赖模型 `R_dep` 的估计误差满足 `‖R̂−R‖_F ≤ ε_R` 时，
```
L_hi(π) ≤ Σ_v p_v − Δ_corr(π) + O(ε_R·|V|²),
```
其中 `Δ_corr ≥ 0` 为正相关带来的收紧量。因此长任务的安全界可以在**依赖可估**时显著优于独立联合界；反之 `ε_R` 过大时自动退回联合界，保证不因错误收紧而不安全。

3. **评测有效性**：对任意停时 `τ`，
```
P( β ∈ CS_τ, ∀τ ) ≥ 1−α,
P( true_rank(i) ∈ rank_interval_i ) ≥ 1−α,
```
且报告的 `n_eff` 不超过真实有效样本量（保守）；`contamination_flag=true` 时排名不得作为发布级结论。

4. **群体借用的负迁移界**：若交换性检验通过且 `λ_r` 按上式取，则
```
E[‖θ̂_r^pop − θ_r‖²] ≤ E[‖θ̂_r^local − θ_r‖²] + (1−λ_r)²·bias_ex²,
```
其中 `bias_ex` 为层内残余异质性；当交换性被拒绝时强制 `λ_r=0`，负迁移为 0。对安全界，
```
δ_f^safety(r) = max(δ_f^local(r), δ_f^pop(r)·1[exchangeable])
```
故群体证据只能使安全判定更保守或不变。

5. **古德哈特护栏**：在预注册 + 留出集 + 污染检测下，选择偏差满足
```
E[R_true(π̂)] − max_π R_true(π) ≤ δ_goodhart + δ_contam,
```
其中 `π̂` 为基于可见评测选择的计划；`δ_goodhart` 随留出集大小 `n_hold` 以 `O(1/√n_hold)` 收缩。

6. **终止性与部署界**：PCE++++ 在 `k_probe+k_cons+k_ft+k_ux+k_exec+k_repair+k_eval` 内终止于 `{承诺(带 Cert_plan), 绕行, 降档, 修复, L2 协商, 安全停, 评测降级}`。对检查点与评测轮次取联合界：
```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1]
                   + δ_ft·1[回滚窗口] + δ_kg·1[检索失败] + δ_ux·1[μ_mis>θ_mis]
                   + δ_exec·1[ξ_exec漂移] + δ_ξ_ood·1[执行OOD] + δ_ertc·1[契约违例]
                   + δ_eeis·1[μ分析漏报] + δ_plan·1[计划联合失败]
                   + δ_repair·1[修复失败] + δ_eval·1[评测泄漏]
                   + δ_rank·1[排名错误] + δ_pop·1[非交换借用]
                   + δ_goodhart·1[基准-真值间隙])
         − P(𝒢 结构性错误未检出) − P(护盾回退失败) − P(τ_int 超时 ∧ 安全停失效)
         − P(固件回滚失败) − P(修复策略失效) − P(评测防火墙被绕过).
```

关键：**PCRA 把「长程安全」从标量加法升级为依赖结构上的风险会计**——依赖可估则收紧，不可估则退回联合界；**HCR 把「一次算对」升级为「承诺+修复」**——不可逆承诺必须有修复完备性证书；**PEP/AVR 把「多机评测」从排行榜升级为统计协议**——随机效应、`n_eff`、随时有效、污染检测；**PPEC 把「群体一致」升级为「可交换的部分池化」**——群体只能抬高安全风险，不能单独压低；**EAP 把「评测」纳入规划但设防火墙**——可以为了知道而评测，不能对着考卷改答案；**PCE++++ 六预算**确保任何一项资源耗尽都只会让系统更保守。
