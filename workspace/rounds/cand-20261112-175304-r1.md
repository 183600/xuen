# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC IP-153~160；本轮灵感：「比赛策略」×「长期记忆」）

> 第 60 轮用 SSM×CIEC×EPIR×SERC×PCE++++ 把闭环从「执行层→证据层」推进到「认知驱动的场景-执行闭环」。但它仍建立在三个未言明的假设上：
> 1. **单场次无历史（H61）**：SSM 每个场次从均匀先验 π_scene 重新估计，SIC 的 β 只是同一场次内的置信度平滑；没有跨场次/跨场地/跨任务的**长期记忆**——同样的桌面、同样的楼梯，第二次比赛仍要重新试探，有限尝试次数被浪费在「已经知道的事」上。
> 2. **目标错配（H62）**：SERC 优化的是 D⁺/ECE/场景适应时间，而比赛优化的是**名次与总得分**。在时间、尝试次数、名次压力下，「更安全的单步」未必是「更高的比赛期望分」；第 60 轮没有「何时冒险、何时保分、把探针花在哪个任务上」的元决策。
> 3. **记忆与策略割裂（H63）**：SIC 只更新 scene_conf，不记录「该场景下哪种策略赢了/输了」，也不区分领先/落后；系统无法从历史比赛学到**策略知识**，更无法在赛前决定「哪些记忆值得花钱重新验证」。
>
> 本轮两个灵感正好互补：**长期记忆**把证据从「当轮变量」变成「跨轮资本」，**比赛策略**把「安全闭环」提升为「有限预算下的得分博弈」。核心命题：**同一份长期记忆在不同赛态下的价值不同；比赛策略应主动决定「赛前整备哪些记忆、赛中信任哪些记忆、赛后沉淀哪些策略」——即「赛忆耦合」（Competition–Memory Coupling, CMC）**：记忆只加速收敛，绝不替代当轮证据。

## 0. 直觉与动机

**灵感 1（长期记忆 → 三层竞赛记忆 LCM）**
直觉：机器人不是每场比赛都「失忆」。长期记忆应像人一样分层：**语义记忆**记住「湿滑地面该用什么阻抗」这类物理先验，**情节记忆**记住「第 3 场、落后 2 分、用轻触策略拿到 15 分」这类比赛经历，**程序记忆**记住「落后且剩余时间 < 20% 时，优先高价值高风险任务」这类可复用策略。关键洞见：**记忆的基本单位不是「场景标签」，而是「带覆盖域、新鲜度、来源链、有效谓词的一条可审计资产」**——否则跨场地复用就是把陈旧经验当真理。

**灵感 2（比赛策略 → 预算化得分组合）**
直觉：比赛不是「把每个任务都做对」，而是「在 T_max、N_try、能量约束下选一个任务子集与顺序，使总期望分最大」。这是一场**有限时域的得分组合优化**，且失败往往不可逆（摔倒、出界）。关键洞见：**策略必须风险敏感**——比赛近似一次性，均值最优不等于名次最优，应优化下尾（CVaR）而不是期望。

**灵感 3（合流 → 赛态条件记忆估值 MCMV）★核心创新**
直觉：同一份「上次在木桌上用中等刚度成功」的记忆，在**领先**时应作为「低方差保分依据」，在**落后且时间将尽**时应作为「高上行搏分弹射器」。静态记忆库对所有赛态一视同仁，是最大的浪费。关键洞见：**记忆的价值应被赛态 ρ 条件化**，用一个随分数差/剩余时间/对手方差变化的指数 Ψ(m|ρ) 排序检索，从而把「记忆复用」和「比赛策略」统一成一个决策。

**灵感 4（双时间尺度 → 赛前整备 × 赛中检索）**
直觉：赛中没有时间重新验证陈旧记忆，所以「要不要相信记忆」必须在**赛前**决定。把优化拆成两个时间尺度：**赛前整备（PMC）**用有限预算决定刷新/压缩/剪枝哪些记忆；**赛中检索（CMSD）**在毫秒级用记忆做策略选择。关键洞见：**赛前应把预算花在「预期任务分布 × 记忆缺口」的交叉处**，且该收益是子模的——覆盖越满，边际收益越低，贪心有近似保证。

**灵感 5（可证伪 → 记忆-策略证书 MSC）**
直觉：不要只说「用了长期记忆所以更强」，而要说「在记忆覆盖域与新鲜窗口内，以 1−α_s 置信保证最终得分 ≥ S_lb 且不发生不可恢复失败」。一旦漂移超界、记忆失效或超出覆盖，证书**立即作废**并回退 SERC 默认策略。关键洞见：**用证书给「记忆驱动的比赛策略」划出可审计的适用边界**，让弃权成为显式行为。

**灵感 6（闭环 → 双时间尺度 CM-MEM）**
直觉：赛前整备 → 赛中检索/决策/执行/记分 → 赛后归因与巩固，形成闭环。赛后把「哪个记忆、哪条策略贡献了多少分」做**信用分配**，再巩固为程序记忆或标记失效；下一场赛前据此重新整备。关键洞见：**记忆因比赛而增值，比赛因记忆而提速**，但必须靠新鲜度/漂移门控防止「越用越自信地错」。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（长期竞赛记忆 LCM）** 长期记忆库 M_LT = (M_sem, M_epi, M_proc, meta)。其中：
- **语义记忆** M_sem：物理先验，如场景-阻抗先验 π_scene^LT(K|φ)、意图-约束映射 ϕ^LT；
- **情节记忆** M_epi：一条比赛经历 e = (match_id, ρ_t, σ, outcome, t)，outcome = (score, success, failure, time, scene)；
- **程序记忆** M_proc：可复用策略 σ = (task_order, probe_depth, K_mode, recovery_policy)；
- **元数据**：每个记忆项 m = (id, c, type, n, t₀, provenance, h, V_m)，其中 c 为覆盖域、n 为支撑样本数、h 为新鲜度、V_m 为有效谓词。
- **新鲜度**：h(m) = exp(−λ_age·Δt)·exp(−λ_dom·d_domain)，d_domain 为记忆来源与当前场地的域距离。
- **收缩权重**：α(m) = n/(n+n₀)·h(m)，用于把记忆先验与当轮证据做贝叶斯收缩 `K_post = α·μ_m + (1−α)·K_obs`。
- **有效谓词**：V_m = (h(m) ≥ h_min) ∧ (d_domain ≤ ε_dom) ∧ version_match ∧ ¬invalidated。

**定义 162（比赛约束 MDP 与策略空间）** 比赛 𝒞 = (S, A, P, R, T_max, N_try, F_unrec)，赛态 ρ = (S_self, S_gap, T_rem, N_rem, E_rem, z_cur)。其中 S_gap = S_target − S_self（正为落后）。
- **得分过程**：S_{t+1} = S_t + R(s_t, a_t) − c_fail·1[f_t ∈ F_unrec]。
- **策略** σ 决定任务子集/顺序、探针深度、阻抗模式与恢复策略；候选策略集 Σ(ρ)。
- **风险敏感目标**（比赛近似一次性，优化下尾）：
  `max_σ E[Score(σ; M_LT, ρ)] − λ_risk(ρ)·CVaR_α⁻(Score(σ))`
  s.t. `T(σ) ≤ T_rem`，`P(F_unrec | σ) ≤ p_max`。
- **赛态风险偏好**：
  `λ_risk(ρ) = clip(λ₀ − κ·S_gap/σ_opp + μ·urgency·(−sign(S_gap)), λ_min, λ_max)`，
  urgency = 1 − T_rem/T_max。落后且时间将尽 ⇒ λ_risk↓（搏分）；领先 ⇒ λ_risk↑（保分）。

**定义 163（赛态条件记忆估值 MCMV）** 给定记忆 m 与赛态 ρ：
```
ΔS(m|ρ) = Score(使用 m) − Score(无记忆基线)
Q_mem(m|ρ) = E[ΔS | m, ρ] − λ_risk(ρ)·CVaR_α⁻(ΔS | m, ρ) − c_ret(m)
Ψ(m|ρ) = Q_mem(m|ρ) / max(ε, c_ret(m))          # 记忆策略指数
```
检索按 Ψ 降序，在检索时延预算 B_ret 内取前 k 条。两种极端情形给出可解释行为：
- **保分态**（S_gap<0）：λ_risk 高 ⇒ Ψ 偏好低方差、高确定性的记忆；
- **搏分态**（S_gap>0 且 urgency 高）：λ_risk 低 ⇒ Ψ 偏好高上行、可承受方差的记忆。

**定义 164（赛前记忆整备 PMC）** 给定预期任务分布 D_task、赛前预算 B_pre，为每条记忆选动作 a_m ∈ {reuse, revalidate, compress, prune}，最大化
```
max_{A ⊆ M}  Σ_{τ∈D_task} w_τ·[1 − Π_{m∈A}(1 − cov(m,τ))] − Σ_{m∈A} cost(a_m)
s.t.  Σ cost(a_m) ≤ B_pre ,   m∈SAFETY_FLOOR 不可 prune
```
其中 cov(m,τ) 为记忆 m 对任务 τ 的覆盖强度。**性质**：目标函数对 A 单调子模（覆盖收益递减），预算约束下贪心达到 `1−1/e` 近似。

**定义 165（赛中记忆-策略联合决策 CMSD）**
```
σ*(ρ) = argmax_{σ∈Σ_M(ρ)} [ E[Score(σ;ρ)] − λ_risk(ρ)·CVaR_α⁻(Score(σ)) ]
s.t.  T(σ) ≤ T_rem,  P(F_unrec|σ) ≤ p_max,
      ∀m∈used(σ): V_m = true
Σ_M(ρ) = { σ_m : m∈M_proc, Ψ(m|ρ) ≥ θ_Ψ } ∪ { σ_SERC }
```
若 Σ_M(ρ) 中无有效记忆策略，则退化为第 60 轮的 SERC 默认策略。探针深度由记忆 VOI 与执行预算联合确定：`d* = argmax_d [VOI_mem(d) − c_probe(d)]`。

**定义 166（记忆-策略证书 MSC）** 证书 C_strat = (σ*, S_lb, α_s, H(M_used), [t₀,t₁], cov, ρ)，其中 H 为所用记忆的摘要。**可靠性**：
```
在 t∈[t₀,t₁]、ρ 的覆盖域内：
P( S_final ≥ S_lb(t) ∧ 全程 f∉F_unrec | σ*, M_used ) ≥ 1 − α_s
S_lb(t) = S_lb⁰ − L_S·ε_TV(t) − L_S·d_domain
```
L_S 为得分对分布漂移的 Lipschitz 常数，ε_TV(t) 为记忆漂移的 TV 上界。**作废条件**：t>t₁、域漂移 > ε_dom、任一 m∈M_used 失效，或新颖性门控判定当前场景超出记忆覆盖 ⇒ 证书作废并回退 SERC。

**定义 167（双时间尺度闭环 CM-MEM）** 算子
```
CM-MEM(M_LT, D_task, B):
  赛前:
    ① M_pre ← PMC(M_LT, D_task, B_pre)          # 刷新/压缩/剪枝
    ② for episode: reset ρ, M_used ← ∅
  赛中(每个决策周期):
    ③ z ← SSM.update(telem);  (必要时) SERC 观测
    ④ R ← retrieve_topk(M_LT, ρ, B_ret)  by Ψ(m|ρ)
    ⑤ σ* ← CMSD(ρ, R);  C ← MSC(σ*, R, ρ)
    ⑥ if C 作废: σ* ← σ_SERC;  C ← Cert_eeis
    ⑦ CIEC.lock(σ*.intent约束); 执行; EV-exec ← build_exec_evidence(...)
    ⑧ 记分 S ← S + R(σ*); 更新 ρ;  MEM-conflict? ⇒ 冻结/降权冲突记忆
  赛后:
    ⑨ 信用分配: credit(m,σ*) ← 归因得分增量（Shapley/反事实）
    ⑩ 情节写入 M_epi;  巩固为程序记忆 M_proc;  更新 h/V_m
    ⑪ 回填证书与实际得分，标记漂移记忆，供下一场整备
```

**定义 168（赛忆预算 PCE++++++）** B_cmc = (B_pre, B_match, B_ret, B_cons, B_exec)。其中 B_pre 为赛前整备预算，B_match 为比赛时间/尝试次数，B_ret 为检索时延/带宽，B_cons 为赛后巩固算力，B_exec 沿用第 60 轮。
- B_pre 耗尽 ⇒ 只复用不刷新（保守整备）；
- B_match 将尽 ⇒ BANK（锁定已有分数）；
- B_ret 耗尽 ⇒ 跳过记忆检索，直接 SERC 默认；
- B_cons 耗尽 ⇒ 推迟巩固，情节记忆先落盘不压缩；
- B_exec 耗尽 ⇒ 沿用第 60 轮执行降级。

### IP-161 LCM（长期竞赛记忆库）

```python
@dataclass
class MemoryItem:
    id: str
    kind: str            # 'sem' | 'epi' | 'proc'
    content: object      # prior / episode / strategy
    coverage: Coverage   # 覆盖的状态-任务域
    support: int         # n
    issue_time: float
    provenance: dict
    retention: str       # 'EPHEMERAL' | 'OPERATIONAL' | 'SAFETY_FLOOR'

class LongTermCompetitionMemory:
    def __init__(self, n0=5, lam_age=0.02, lam_dom=1.0, h_min=0.2):
        self.items = {}
        self.n0, self.lam_age, self.lam_dom, self.h_min = n0, lam_age, lam_dom, h_min

    def freshness(self, m, now, dom_dist):
        return math.exp(-self.lam_age * (now - m.issue_time)) * math.exp(-self.lam_dom * dom_dist)

    def valid(self, m, now, dom_dist, version_ok=True):
        h = self.freshness(m, now, dom_dist)
        return h >= self.h_min and dom_dist <= 1.0 and version_ok and m.retention != 'TOMBSTONED'

    def store_episode(self, episode):
        # 情节先落盘，赛后巩固时再压缩为程序记忆
        m = MemoryItem(id=f"epi-{episode.match_id}-{len(self.items)}", kind='epi',
                       content=episode, coverage=episode.coverage,
                       support=1, issue_time=now(), provenance=episode.provenance,
                       retention='EPHEMERAL')
        self.items[m.id] = m
        return m

    def consolidate(self, cluster):
        # 相似情节 → 一条更宽覆盖的程序记忆；留出验证后才提升 support
        strategy = synthesize_strategy(cluster)
        m = MemoryItem(id=f"proc-{uuid4().hex[:8]}", kind='proc', content=strategy,
                       coverage=union_cover(cluster), support=sum(c.support for c in cluster),
                       issue_time=now(), provenance=merge_provenance(cluster),
                       retention='OPERATIONAL')
        self.items[m.id] = m
        return m
```

### IP-162 MCMV（赛态条件检索）

```python
def match_conditioned_risk(lam0, kappa, mu, rho, sigma_opp, T_max):
    urgency = 1.0 - rho.T_rem / T_max
    gap = rho.S_gap
    lam = lam0 - kappa * gap / (sigma_opp + 1e-6) + mu * urgency * (-np.sign(gap))
    return float(np.clip(lam, LAM_MIN, LAM_MAX))

def memory_strategy_index(m, rho, lam_risk, baseline_score):
    # 用记忆 m 的回放/模型估计 ΔS 分布（n 足够时用经验分位，否则用共形界）
    dS = estimate_delta_score(m, rho, baseline=baseline_score)   # 样本数组
    up = float(np.mean(dS))
    down = float(-np.quantile(dS, ALPHA))                        # -CVaR_alpha^-
    c_ret = retrieve_cost(m)
    return (up - lam_risk * down - c_ret) / max(1e-6, c_ret)

def retrieve_topk(memory, rho, B_ret, baseline_score, theta_psi):
    lam = match_conditioned_risk(LAM0, KAPPA, MU, rho, SIGMA_OPP, T_MAX)
    scored = []
    for m in memory.items.values():
        if not memory.valid(m, now(), rho.dom_dist, rho.version_ok):
            continue
        psi = memory_strategy_index(m, rho, lam, baseline_score)
        if psi >= theta_psi:
            scored.append((psi, m))
    scored.sort(key=lambda x: x[0], reverse=True)
    picked, spent = [], 0.0
    for psi, m in scored:                        # 时延预算下的贪心
        if spent + retrieve_cost(m) > B_ret:
            continue
        picked.append(m); spent += retrieve_cost(m)
    return picked
```

### IP-163 PMC（赛前整备，子模贪心）

```python
def pre_match_consolidation(memory, task_dist, B_pre):
    candidates = [m for m in memory.items.values() if m.retention != 'SAFETY_FLOOR']
    selected, spent = [], 0.0
    covered = {tau: 0.0 for tau in task_dist}
    while True:
        best, best_ratio = None, 0.0
        for m in candidates:
            if m in selected:
                continue
            gain = 0.0
            for tau, w in task_dist.items():
                gain += w * max(0.0, coverage(m, tau) - covered[tau])
            cost = maintenance_cost(m, action='revalidate')
            if spent + cost > B_pre:
                continue
            ratio = gain / max(1e-6, cost)
            if ratio > best_ratio:
                best, best_ratio = (m, cost, gain), ratio
        if best is None:
            break
        m, cost, gain = best
        revalidate(m)                              # 刷新 h(m)、version、provenance
        selected.append(m); spent += cost
        for tau in task_dist:
            covered[tau] = 1.0 - (1.0 - covered[tau]) * (1.0 - coverage(m, tau))
    return selected
```

### IP-164/165 CMSD + MSC（赛中决策与证书）

```python
def select_competition_strategy(rho, retrieved, baseline_score):
    lam = match_conditioned_risk(LAM0, KAPPA, MU, rho, SIGMA_OPP, T_MAX)
    best, best_val = None, -inf
    for m in retrieved:
        sigma = m.content if m.kind == 'proc' else derive_strategy(m)
        if not feasible(sigma, rho):               # T(σ)≤T_rem, P(F_unrec)≤p_max
            continue
        scores = estimate_scores(sigma, rho)       # 用记忆 + 当轮证据
        val = float(np.mean(scores)) - lam * (-np.quantile(scores, ALPHA))
        if val > best_val:
            best, best_val = (sigma, m), val
    if best is None:
        return DEFAULT_SERC_STRATEGY, None
    sigma, m = best
    return sigma, issue_memory_strategy_certificate(sigma, [m], rho)

def issue_memory_strategy_certificate(sigma, used, rho):
    if any((not m.valid) or not covers(m, rho) for m in used):
        return None                                # 证书作废 ⇒ 回退 SERC
    S_lb0 = conservative_score_bound(sigma, rho)
    eps_tv = max(tv_drift_upper(m, now()) for m in used)
    S_lb = S_lb0 - L_SCORE * eps_tv - L_SCORE * max(d_domain(m) for m in used)
    return MemoryStrategyCertificate(sigma=sigma, S_lb=S_lb, alpha_s=ALPHA_S,
                                     digest=digest(used), window=valid_window(used),
                                     coverage=intersect_cover(used), rho=rho)
```

def cm_mem_loop(M, D_task, budget):
    M_pre = pre_match_consolidation(M.ltm, D_task, budget.B_pre)
    rho = init_match_state(M)
    while not match_over(rho):
        M.scene_model.update(M.telem_force, M.telem_pos)
        retrieved = retrieve_topk(M.ltm, rho, budget.B_ret, baseline_score(rho), THETA_PSI)
        sigma, cert = select_competition_strategy(rho, retrieved, baseline_score(rho))
        if cert is None:

            cert = M.eeis.issue_certificate(sigma)
        M.intent_ctrl.lock(sigma.intent_constraints)
        execute(sigma)
        ev = build_exec_evidence(M)
        M.epir.append(ev.__dict__)
        S_before = rho.S_self
        rho.S_self += score(rho, sigma)
        if memory_conflicts(retrieved, ev):
            freeze_or_downweight(M.ltm, retrieved, ev)

    credits = credit_assignment(rho.trajectory, M.ltm)   # Shapley/反事实
    M.ltm.store_episode(build_episode(rho))
    M.ltm.consolidate(cluster_by_context(rho.trajectory))

1. **赛前整备近似最优性**：PMC 贪心解满足 `V(A_greedy) ≥ (1−1/e)·V(A*)`（子模+预算）。

3. **证书可靠性**：若当前赛态落在记忆覆盖域且 t∈[t₀,t₁]，则 `P(S_final ≥ S_lb ∧ 无 F_unrec) ≥ 1−α_s`；漂移使 S_lb 按 L_S·ε_TV 线性折扣。
4. **安全回退**：任一 m 失效/超覆盖/证书作废 ⇒ 系统退回 SERC 默认策略，记忆绝不取代当轮证据。

## 2. 关键推导

### 2.1 MCMV 的赛态分区行为（解释「为什么记忆价值要条件化」）

设记忆 m 的得分增量分布 ΔS 的均值 μ、下尾风险 `R = −CVaR_α⁻(ΔS)`（R≥0 越大风险越大），则
```
Q_mem(m|ρ) = μ(m) − λ_risk(ρ)·R(m) − c_ret(m)
```
对两条记忆 m₁（低均值低风险）与 m₂（高均值高风险），选择 m₂ 的条件为
```
[μ(m₂) − μ(m₁)] > λ_risk(ρ)·[R(m₂) − R(m₁)]
```
于是：
- **保分态**（领先，λ_risk 高）：右侧变大 ⇒ 只有上行足够大才选高方差记忆，等价于「锁分优先」；
- **搏分态**（落后且 urgency 高，λ_risk 低）：右侧变小 ⇒ 更易选高方差高上行记忆，等价于「以小博大」。
这正是第 60 轮静态 SIC 无法表达的：**同一记忆库，在不同赛态下给出不同策略排序**。

### 2.2 PMC 的子模性与近似比（推导骨架）

对任务 τ，覆盖函数取噪声或模型：
`F_τ(A) = 1 − Π_{m∈A}(1 − cov(m,τ))`。
因 `F_τ(A∪{m}) − F_τ(A) = cov(m,τ)·Π_{m'∈A}(1−cov(m',τ))` 随 A 增大而单调不增，故 F_τ 单调子模；加权和 `F = Σ_τ w_τ F_τ` 与负成本 `−Σ cost` 之和仍子模。预算约束下贪心选择「边际收益/成本」最大项，标准结论给出
`F(A_greedy) ≥ (1 − 1/e)·F(A*) ≈ 0.632·F(A*)`。
因此赛前整备不必穷举组合，贪心即可用对数级开销买到接近最优的覆盖。

### 2.3 MSC 的漂移折扣（为什么证书要带有效期）

设签发时记忆分布 P、当前部署分布 Q 满足 `TV(P,Q) ≤ ε_TV(t)`，得分泛函对分布变化 Lipschitz 常数为 L_S。则对任意策略
`|E_Q[Score] − E_P[Score]| ≤ L_S·TV(P,Q) ≤ L_S·ε_TV(t)`。
把签发时的保守下界 S_lb⁰ 平移到当前分布，得到
`S_lb(t) = S_lb⁰ − L_S·ε_TV(t) − L_S·d_domain`。
这给出证书的**显式有效期**与**显式作废条件**：ε_TV(t) 单调增，一旦 `S_lb(t)` 低于可接受分位或 `t>t₁`，证书作废、策略回退 SERC——把「记忆可能过期」从口号变成可计算的门。

### 2.4 负迁移的得分代价上界

若把来源域 A 的记忆直接用于目标域 B，额外得分损失可界为
`ΔScore_neg ≤ L_S·d_domain(A,B) + L_S·ε_TV(age)`。
因此「域距离门控 d_domain ≤ ε_dom」与「新鲜度门控 h ≥ h_min」不是拍脑袋的阈值，而是把负迁移代价压到可接受范围的**充分条件**：只要上界 ≤ 允许的失分，就允许复用；否则强制整备或回退。

```python
def pre_match_consolidation(memory, task_dist, B_pre):
    pool = [m for m in memory.items.values() if m.retention != 'SAFETY_FLOOR']
    selected, spent = [], 0.0
    covered = {tau: 0.0 for tau in task_dist}
    while True:
        best, best_ratio = None, 0.0
        for m in pool:
            if m in selected:
                continue
            gain = sum(w * max(0.0, coverage(m, tau) - covered[tau])
                       for tau, w in task_dist.items())
            cost = maintenance_cost(m, 'revalidate')
            if spent + cost > B_pre or gain <= 0:
                continue
            if gain / cost > best_ratio:
                best, best_ratio = (m, cost, gain), gain / cost
        if best is None:
            break
        m, cost, _ = best
        revalidate(m)                    # 重置 h、校验版本、刷新来源链
        selected.append(m); spent += cost
        for tau in task_dist:
            covered[tau] = 1 - (1 - covered[tau]) * (1 - coverage(m, tau))
    return selected
```

### IP-162/164/165（赛中检索 → 决策 → 证书）

```python
def in_match_decide(memory, rho, B_ret, baseline_score):
    lam = clip(LAM0 - KAPPA * rho.S_gap / (SIGMA_OPP + EPS)
               + MU * urgency(rho) * (-sign(rho.S_gap)), LAM_MIN, LAM_MAX)
    cand = []
    for m in memory.items.values():
        if not memory.valid(m, now(), rho.dom_dist, rho.version_ok):
            continue
        dS = estimate_delta_score(m, rho, baseline_score)
        risk = -quantile(dS, ALPHA)
        psi = (mean(dS) - lam * risk - retrieve_cost(m)) / max(EPS, retrieve_cost(m))
        if psi >= THETA_PSI:
            cand.append((psi, m))
    cand.sort(key=lambda x: x[0], reverse=True)

    sigma_best, mem_used, val_best = None, [], -inf
    for psi, m in cand:                       # 预算内贪心
        sigma = strategy_of(m)
        if not feasible(sigma, rho):
            continue
        scores = estimate_scores(sigma, rho)
        val = mean(scores) - lam * (-quantile(scores, ALPHA))
        if val > val_best:
            sigma_best, mem_used, val_best = sigma, [m], val
    if sigma_best is None:
        return DEFAULT_SERC_STRATEGY, None   # 无有效记忆 ⇒ 回退 SERC

    cert = issue_certificate(sigma_best, mem_used, rho)
    return (sigma_best, cert) if cert is not None else (DEFAULT_SERC_STRATEGY, None)
```

def cm_mem_loop(M, D_task, budget):

### IP-168 SMCA（赛后信用分配，反事实/Shapley）

```python
def score_memory_credit_assignment(trajectory, ltm, n_perm=32):
    # 对每次「用记忆 m 做的决策」计算边际得分贡献
    credit = defaultdict(float)
    for step in trajectory.decisions:
        used = step.memory_ids
        v_all = step.realized_score
        for m in used:
            v_wo = counterfactual_replay(step, exclude=m)   # 去掉 m 的回放得分
            credit[m] += (v_all - v_wo) / max(1, len(used))
    return credit
```
