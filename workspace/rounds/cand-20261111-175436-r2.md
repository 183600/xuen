# 第 56 轮（承接第 55 轮语义-接触生存核与第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 2 轮；本轮灵感：「数据集」×「角色一致性」）

> 第 55 轮把“感知标签”升级成“可执行的语义-接触约束”，并让证书携带 `δ_s` 与 `K_margin`。但整条证书链仍把两件事当作背景：**证据是从一个中性的数据集上测得的**；**被认证的始终是同一个“角色”**。本轮用「数据集」与「角色一致性」拆这两个背景假设。数据集不是证据容器，而是带切片测度的定义域；角色一致性（character consistency）原本指生成式内容跨镜头保持同一角色身份，在具身系统里它变成：同一技能组合、接触风格与职责承诺必须在数据集切片之间保持可辨识的同一性，而不是逐切片“换角式泛化”。核心矛盾：**H24（切片非中性）**：证书统计量对切片重加权敏感，聚合会把“场景更难”与“角色漂移”混为一谈，使在一个切片构成上成立的证书在部署切片构成下失效；**H25（平均性能不可辨识角色）**：单看平均成功率无法区分“同一角色适应了不同场景”与“不同角色在各自场景分别表演”，缺少身份锚与反事实探针时，数据集评测会奖励换角而非泛化。

## 0. 直觉与动机

**灵感 1（数据集 → 数据集是舞台，不是中性的证据容器）**
直觉：证书不是从“数据”里长出来的，而是从“数据的切片构成”里长出来的。同一个策略，重加权数据集切片（更多夜间、更多载荷、更多异构身体、更多操作者）就会得到不同的成功率与不同的生存核主张。因此数据集必须被写成带测度的**定义域** `(D,w)`，证书是定义在切片测度上的泛函，而不是一个与分布无关的标量。否则我们只是在用一个切片的证据替另一个切片背书。

**灵感 2（角色一致性 → 平均性能无法区分“泛化”与“换角”）**
直觉：生成模型可以在每一帧都画得很像主角，却在帧与帧之间悄悄换了演员；只看平均相似度发现不了。机器人同理：一个策略可以在每个场景切片上分别调成局部最优，平均成功率高，但跨切片已经不是同一个“角色”——技能组合、接触风格、职责承诺都变了。部署时真正需要的是**同一个角色连续承担多个场景**，这种“换角式泛化”在需要连续承诺的任务上会崩。角色一致性要求的是身份守恒，而不是逐场景最优。

**灵感 3（角色表 → 身份探针数据集）**
直觉：动画保证角色一致性靠 turnaround sheet：固定角色，系统改变视角、表情、姿态、光照。机器人也需要一张“角色表”：固定技能与职责契约，系统改变场景、载荷、观测与身体实现，做**因子化反事实探针**。没有探针，一致性与场景难度不可分离；有了探针，才能把“场景可解释的变化”从“身份漂移”里减掉。数据集在这里不是被动采集物，而是**主动排戏**出来的证据装置。

**灵感 4（身份-场景分解 → 双分离，而不是单指标）**
直觉：角色一致性不是“所有行为都不变”，那会退化成冻结。真正的要求是**双分离**：场景/身体变化不应改变身份特征；身份变化必须显著改变身份特征。前者防“场景伪装成身份”，后者防“身份被场景抹平”。这给出可检验的证书条件，而不只是一个相似度分数。

**灵感 5（数据集溯源 → 选角完整性）**
直觉：如果评测集里同一场景以不同“身份”重复出现，或训练/测试共享底片，数据集会伪造出一致性。角色一致性因此不仅是模型属性，也是**数据集属性**：需要角色-场景的溯源账本，检测重复场景、身份泄漏与投毒，保证“选角”没有被数据本身作弊。

**灵感 6（身份保持更新 → 新数据集上继续训练时的角色连续性）**
直觉：部署后总要用新数据继续适配；朴素微调会把新场景的捷径写进身份。正确做法是在**身份零空间**里适配：新数据只允许改变场景特定实现，不允许改变身份特征；一旦身份漂移超过预算就回滚。这把“持续学习”从“越训越强”改成“越训越要是同一个角色”。

## 1. 形式化定义（增量：定义 127–132）

**定义 127（切片数据集与证书泛函）**
数据集 `D = {(x_i, τ_i, b_i, s_i, y_i)}_{i=1}^{N}`，其中 `b_i` 为身体/构型，`s_i` 为场景（视角、光照、材质、操作者、时间），`y_i` 为结局；切片 `d_i=(b_i,s_i)∈𝒮=ℬ×𝒮_c`，切片测度 `w∈Δ(𝒮)`，重采样数据集记为 `D_w`。证书泛函 `C(D,w)∈ℝ^k` 把切片测度映射为失败概率、可行率或鲁棒谱。部署分布到评测分布的切片位移
`δ_D(w) = W_1(p_deploy, p_w)`（一阶 Wasserstein）。**关键**：`C(D,w)` 不是常量，改变 `w` 就改变了证书所断言的论域。

**定义 128（行为角色签名）**
策略 `π_θ` 在切片 `d` 上的行为角色签名
`ζ(π_θ|d) = (γ_role, α_style, κ_pref, ρ_profile)`：
- `γ_role` 角色契约：承诺、让行、支撑职责的时序约束，取为可观测行为迹上的语言/概率自动机；
- `α_style` 身体归一化后的动作风格剖面（第 54 轮 `α_S` 去掉可实现幅度后的形状）；
- `κ_pref` 接触偏好（第 55 轮 `κ` 在策略侧的投影）；
- `ρ_profile` 鲁棒性谱形状（第 53 轮 `ρ` 归一化去均值）。
度量 `d_ζ = w_γ d_γ + w_α d_α + w_κ d_κ + w_ρ d_ρ`，各分量先归一化，`d_γ` 用行为迹语言对称差/互模拟距离。

**定义 129（身份-实现分解与双分离）**
存在编码器 `(h_id, h_real)` 使
`ζ(π_θ|d) = h_id(z) + h_real(b_d, s_d) + ε_d`，`||ε_d|| ≤ ε_a`，
其中身份变量 `z=(θ, 技能集, 角色契约)`，实现变量 `(b_d,s_d)` 是身体与场景。**角色一致性**要求双分离：
- **(C1) 场景/身体反事实不变性**：固定 `z`，改变 `(b,s)` 时
  `sup_{d,d': z_d=z} ||h_id(z|d) - h_id(z|d')|| ≤ ε_id`；
- **(C2) 身份反事实可分辨性**：固定 `(b,s)`，改变 `z` 时
  `inf_{z≠z'} ||h_id(z) - h_id(z')|| ≥ θ_id`。
`(C1)` 防场景伪装身份，`(C2)` 防身份被场景抹平；二者缺一不可。

**定义 130（角色一致性裕度）**
`m_char = inf_{z≠z'} ||h_id(z) - h_id(z')|| - sup_{z; d,d'} ||h_id(z|d) - h_id(z|d')||`。
第一项是身份可分辨信号，第二项是场景/身体造成的身份漂移；`m_char` 是扣掉可解释变化后的净身份裕度，要求 `m_char ≥ θ_char`。

**定义 131（角色一致性证书）**
`J_c = (ζ*, 𝒫, m_char, ρ_data, δ_D, L_D, evidence)`：
- `ζ*` 为角色表上的锚定签名；
- `𝒫` 为身份探针集，`cov(𝒫)` 为身份×场景因子覆盖度；
- `ρ_data(ε_D) = inf_{w: δ_D(w)≤ε_D} C(D_w)` 为切片重加权球内的最坏证书；
- `δ_D` 为部署切片位移实测量；
- `L_D` 为数据溯源账本（重复场景、身份泄漏、投毒）。
若 `cov(𝒫)≥θ_cov`、`m_char≥θ_char`、`ρ_data≥ρ_min`、`δ_D≤Θ_D` 且 `L_D.clean`，则角色-数据可部署。**注意**：`J_c` 不替代第 55 轮 `J_s`；`J_s` 证接触可行，`J_c` 证“被认证的仍是同一角色”，二者并发成立才可部署。

**定义 132（角色漂移预算与身份保持更新）**
角色漂移 `drift(θ'|θ) = d_ζ(ζ(π_{θ'}), ζ(π_θ))`。身份保持更新算子
`U_η^{⊥}(θ; D_new) = θ - η Π_{⊥(ℐ_ζ)} ∇L_{D_new}(θ)`，
其中 `ℐ_ζ = span{∂ζ/∂θ}` 为身份敏感子空间，`Π_{⊥}` 为正交补投影。更新可接受当且仅当 `drift ≤ Θ_drift` 且 `m_char(θ') ≥ θ_char`；否则回滚。这把“用新数据集继续训练”变成“在身份约束下做场景适配”。

## 2. 关键算法 伪代码

### IP-127 DIP（Dataset Identity Probe）

```python
def identity_probe_suite(scene_factors, identity_factors, task):
    probes = []
    for z in identity_factors:          # policy / skill set / contract variants
        for s in scene_factors:         # view / light / material / payload / body
            probes.append(Probe(task=task, identity=z, scene=s,
                                counterfactual_pair=(z_ref, s_ref)))
    return probes, probe_coverage(probes, scene_factors, identity_factors)

def probe_coverage(probes, F_s, F_z):
    return min(frac_covered(probes, F_s),
               frac_covered(probes, F_z),
               balance(probes))          # 不许所有探针只落在少数因子上
```

### IP-128 BID（Behavioral Identity Decomposition）

```python
def identity_decomposition(policy, probes, eps_a):
    Z = [(p, behavior_signature(policy, p)) for p in probes]
    h_id, h_real = fit_additive(Z, eps_a)      # zeta = h_id(z) + h_real(b,s) + eps
    eps_id = max_scene_counterfactual_drift(Z, h_id)   # 固定 z，改 b/s
    theta_id = min_identity_counterfactual_gap(Z, h_id) # 固定 b/s，改 z
    m_char = theta_id - eps_id
    return IdentityCodec(h_id, h_real), m_char, eps_id, theta_id
```

### IP-129 CRC（Character-Role Certificate）

```python
def character_certificate(policy, probes, codec, D, ledger, budgets):
    if probe_coverage(probes, ...) < budgets.theta_cov:
        return ('reject', 'probe_coverage_gap')
    if not ledger.clean:
        return ('reject', 'cast_integrity', ledger.evidence)
    _, m_char, eps_id, theta_id = identity_decomposition(
        policy, probes, budgets.eps_a)
    if m_char < budgets.theta_char:
        return ('reject', 'character_drift', m_char)
    rho_data = dataset_slice_robustness(policy, D, budgets.eps_D)
    delta_D = wasserstein(probe_slice_dist(probes), deploy_slice_dist(D))
    if rho_data < budgets.rho_min or delta_D > budgets.Theta_D:
        return ('reject', 'dataset_shift', rho_data, delta_D)
    return ('ok', CharCert(codec.anchor, probes, m_char,
                           rho_data, delta_D, ledger.hash))
```

### IP-130 IPA（Identity-Preserving Adaptation）

```python
def identity_preserving_adapt(policy, D_new, probes, codec, eta, drift_budget):
    I = identity_jacobian(codec, probes, policy)   # zeta 对 theta 的敏感方向
    P_perp = orthogonal_projector(I)
    snapshot = clone(policy)
    for batch in D_new:
        g = grad(task_loss(policy, batch))
        policy = sgd_step(policy, eta, P_perp @ g)  # 只改身份零空间
        if role_drift(snapshot, policy, probes, codec) > drift_budget:
            return snapshot, 'identity_drift_rollback'
    return policy, 'ok'
```

### IP-131 DSR（Dataset Slice Robustness）

```python
def dataset_slice_robustness(policy, D, eps_D, certificate_functional):
    worst = 1.0
    for w in reweight_ball(D, eps_D, worst_case=True):
        worst = min(worst, certificate_functional(policy, D, w))
    return worst          # 切片重加权球内最坏证书，而非平均证书
```

### IP-132 DPL（Dataset Provenance Ledger）

```python
def dataset_provenance_ledger(D, dup_tau, overlap_tau):
    h = merkle_hash(lineage(D))               # 采集/清洗/标注全链路
    dups = near_duplicate_scenes(D, dup_tau)  # 同场景换身份重复
    leaks = train_deploy_scene_overlap(D, overlap_tau)
    outliers = provenance_outliers(D)         # 来源异常/疑似投毒
    clean = not dups and not leaks and not outliers
    return Ledger(h, dups, leaks, outliers, clean)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| DIP | O(|F_z|·|F_s|) | O(|𝒫|) | 因子覆盖完整、身份/场景可干预 |
| BID | O(|𝒫|·|ζ| + fit) | O(|𝒫|·|ζ|) | 加性分解误差有界、双分离可检验 |
| CRC | O(|𝒫|+|D|+N_w·|D|) | O(|D|) | 切片球覆盖部署位移、账本干净 |
| IPA | O(|θ|+|𝒫|) 每步 | O(|θ|) | 身份子空间估计可靠、漂移预算闭合 |
| DSR | O(N_w·|D|) | O(|D|) | 重加权球最坏情形可复现 |
| DPL | O(|D| log |D|) | O(|D|) | 哈希抗碰撞、近重复/泄漏可检出 |

**正确性定理（Character-Consistent Dataset Soundness）**
假设第 55 轮 (A29)–(A32) 成立；新增 **(A33)** 探针 `𝒫` 覆盖真实身份×场景因子空间，且部署切片支撑落在重加权球内；**(A34)** 身份-实现分解的加性误差 `≤ε_a`，双分离 `(C1)(C2)` 成立；**(A35)** 切片球半径 `ε_D` 覆盖部署分布位移，`ρ_data` 的最坏情形可复现；**(A36)** 溯源账本抗碰撞且能检出 `≤δ_max` 的重复/泄漏，IPA 的身份子空间估计误差有界。则
```
P_char ≥ 1 - P(probe coverage gap) - P(δ_D > Θ_D) - P(m_char < θ_char)
          - P(ρ_data < ρ_min) - P(L_D not clean)
```
与第 55 轮安全证书并发时，由并集界：
```
P_safe ∧ char ≥ 1 - [P(||Σ-Σ̂||>ε_s)+P(κ miscal.)+P(K_out\K_in≠∅)+P(shield fail)]
                   - [P(coverage gap)+P(δ_D>Θ_D)+P(m_char<θ_char)+P(ρ_data<ρ_min)+P(ledger unsound)]
```
关键：**角色证书与语义-接触证书正交**，前者管“身份是否守恒”，后者管“接触是否可行”；数据集切片是二者的共同定义域，`ζ` 中的 `κ,ρ` 是二者的共享接口。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 身份因子未覆盖，角色表本身不完整 | 高 | 因子化探针 + 主动探针选择 + 部署期残差监测 |
| 身份与场景混淆，分解学到捷径 | 高 | 反事实干预 + 双分离检验 + 独立锚定集 |
| 身份约束过强导致“角色冻结” | 中 | 软身份预算 + 场景适配层 + 定期重认证 |
| 切片球未覆盖真实部署位移 | 高 | 在线切片监测 + 球半径自适应 + 超界重认证 |
| 溯源账本可被伪造/隐私泄露 | 中 | 密码学哈希 + 可信锚点 + 最小化原始数据上链 |

## 6. 本轮最大风险

**一句话**：角色一致性证书把“数据集切片”和“被认证角色”从背景变成一等公民，但其 soundness **三重依赖身份探针的因子覆盖、身份-场景双分离的可辨识性、以及切片重加权球对真实部署位移的包住能力**；一旦角色表漏掉关键身份因子、或加性分解把场景捷径误判为身份、或部署切片逃出重加权球，系统就会在“自认为同一个角色”的证书下持续用换角式策略部署，承诺与接触风格在连续任务中悄悄断裂——因此必须以 **因子化探针 + 反事实双分离 + 在线切片监测** 三重护栏，宁可拒绝认证，绝不把数据集平均性能当作角色身份守恒的证据。

# 第 56 轮产物 · 创新点清单 v32：CharCert-X（DIP×BID×CRC×IPA×DSR×DPL）

## 2. 关键算法 伪代码

### IP-127 DIP

```python
def identity_probe_suite(scene_factors, identity_factors, task):
    probes = []
    for z in identity_factors:          # policy / skill set / contract variants
        for s in scene_factors:         # view / light / material / payload / body
            probes.append(Probe(task=task, identity=z, scene=s,
                                counterfactual_pair=(z_ref, s_ref)))
    return probes, probe_coverage(probes, scene_factors, identity_factors)

def probe_coverage(probes, F_s, F_z):
    return min(frac_covered(probes, F_s),
               frac_covered(probes, F_z),
               balance(probes))          # 防止探针只覆盖少数因子
```

### IP-128 BID

```python
def identity_decomposition(policy, probes, eps_a):
    Z = [(p, behavior_signature(policy, p)) for p in probes]
    h_id, h_real = fit_additive(Z, eps_a)              # zeta = h_id(z)+h_real(b,s)+eps
    eps_id = max_scene_counterfactual_drift(Z, h_id)   # 固定 z，改 b/s
    theta_id = min_identity_counterfactual_gap(Z, h_id) # 固定 b/s，改 z
    m_char = theta_id - eps_id
    return IdentityCodec(h_id, h_real), m_char, eps_id, theta_id
```

### IP-129 CRC

```python
def character_certificate(policy, probes, codec, D, ledger, budgets):
    if probe_coverage(probes, ...) < budgets.theta_cov:
        return ('reject', 'probe_coverage_gap')
    if not ledger.clean:
        return ('reject', 'cast_integrity', ledger.evidence)
    _, m_char, eps_id, theta_id = identity_decomposition(
        policy, probes, budgets.eps_a)
    if m_char < budgets.theta_char:
        return ('reject', 'character_drift', m_char)
    rho_data = dataset_slice_robustness(policy, D, budgets.eps_D)
    delta_D = wasserstein(probe_slice_dist(probes), deploy_slice_dist(D))
    if rho_data < budgets.rho_min or delta_D > budgets.Theta_D:
        return ('reject', 'dataset_shift', rho_data, delta_D)
    return ('ok', CharCert(codec.anchor, probes, m_char,
                           rho_data, delta_D, ledger.hash))
```

### IP-130 IPA

```python
def identity_preserving_adapt(policy, D_new, probes, codec, eta, drift_budget):
    I = identity_jacobian(codec, probes, policy)   # zeta 对 theta 的敏感方向
    P_perp = orthogonal_projector(I)
    snapshot = clone(policy)
    for batch in D_new:
        g = grad(task_loss(policy, batch))
        policy = sgd_step(policy, eta, P_perp @ g)  # 只改身份零空间
        if role_drift(snapshot, policy, probes, codec) > drift_budget:
            return snapshot, 'identity_drift_rollback'
    return policy, 'ok'
```

### IP-131 DSR

```python
def dataset_slice_robustness(policy, D, eps_D, certificate_functional):
    worst = 1.0
    for w in reweight_ball(D, eps_D, worst_case=True):
        worst = min(worst, certificate_functional(policy, D, w))
    return worst          # 最坏切片证书，而非平均证书
```

def dataset_provenance_ledger(D, dup_tau, overlap_tau):

## 3. 证书合成与部署判定

**并发部署规则**：`deploy ⇔ J_s.ok ∧ J_c.ok`。
- `J_s`（第 55 轮）回答“接触是否可信、全身是否可行”，依赖 `Σ,C^+(Σ),K(Σ)`；
- `J_c`（本轮）回答“跨切片被认证的仍是同一角色”，依赖 `𝒫,m_char,ρ_data,δ_D,L_D`；
- 二者共享 `ζ` 中的 `κ_pref,ρ_profile`：`J_s` 的语义/鲁棒证据进入 `ζ`，`J_c` 的切片球把 `J_s` 的论域从单一数据集扩展到部署切片。

**失败码**：`probe_coverage_gap`（探针不足）→ 先补探针；`cast_integrity`（数据污染）→ 隔离切片重认证；`character_drift`（身份漂移）→ 回滚到锚定策略；`dataset_shift`（切片越界）→ 触发主动采样或拒绝部署；`robustness_fail`（切片最坏鲁棒不足）→ 降级到保守策略并要求人工复核。

**与护盾的联动**：`IPA` 的适配只能在 SSF 语义护盾的保护下执行；适配过程本身被视为一段“低风险测量轨迹”，其接触动作受 `C^+(Σ)` 与 `u_stop` 回退约束。角色漂移超预算时立即回滚，且回滚动作由护盾兜底，避免“边适配边跌倒”。

## 4. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| DIP | O(|F_z|·|F_s|) | O(|𝒫|) | 因子覆盖完整、身份/场景可干预 |
| BID | O(|𝒫|·|ζ| + fit) | O(|𝒫|·|ζ|) | 加性分解误差有界、双分离可检验 |
| CRC | O(|𝒫|+|D|+N_w·|D|) | O(|D|) | 切片球覆盖、账本干净、身份裕度闭合 |
| IPA | O(|θ|+|𝒫|) 每步 | O(|θ|) | 身份子空间可靠、漂移预算闭合 |
| DSR | O(N_w·|D|) | O(|D|) | 重加权球最坏情形可复现 |
| DPL | O(|D| log |D|) | O(|D|) | 哈希抗碰撞、近重复/泄漏可检出 |

**正确性定理（Character-Consistent Dataset Soundness）**
假设第 55 轮 (A29)–(A32) 成立；新增 **(A33)** 探针覆盖真实身份×场景因子空间且部署切片落在重加权球内；**(A34)** 身份-实现分解误差 `≤ε_a` 且双分离 `(C1)(C2)` 成立；**(A35)** 切片球半径 `ε_D` 覆盖部署位移、`ρ_data` 最坏情形可复现；**(A36)** 溯源账本抗碰撞、能检出 `≤δ_max` 的重复/泄漏，IPA 身份子空间估计误差有界。则
```
P_char ≥ 1 - P(probe coverage gap) - P(δ_D > Θ_D) - P(m_char < θ_char)
          - P(ρ_data < ρ_min) - P(L_D not clean)
```
与第 55 轮证书并发时：
```
P_safe ∧ char ≥ 1 - [P(||Σ-Σ̂||>ε_s)+P(κ miscal.)+P(K_out\K_in≠∅)+P(shield fail)]
                   - [P(coverage gap)+P(δ_D>Θ_D)+P(m_char<θ_char)+P(ρ_data<ρ_min)+P(ledger unsound)]
```
关键：**角色证书不重证接触安全，语义证书不重证身份守恒；二者正交，用数据集切片与 `ζ` 的共享分量对齐。**

## 7. 本轮最大风险

**一句话**：CharCert-X 把“数据集切片”和“被认证角色”提升为证书的一等公民，但其 soundness **三重依赖身份探针的因子覆盖、身份-场景双分离的可辨识性、以及切片重加权球对真实部署位移的包住能力**；一旦角色表漏掉关键身份因子、加性分解把场景捷径误判为身份、或部署切片逃出重加权球，系统就会在“自认为同一角色”的证书下持续用换角式策略部署，承诺与接触风格在连续任务中悄悄断裂——因此必须以 **因子化探针 + 反事实双分离 + 在线切片监测** 三重护栏，宁可拒绝认证，绝不把数据集平均性能当作角色身份守恒的证据。
