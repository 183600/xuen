# 第 68 轮（承接第 67 轮「SimRAS 仿真增强闭环」IP-233~242；新一轮灵感循环第 1 轮；本轮灵感：「安全性」×「避障控制」）

> 第 67 轮 SimRAS 用「仿真预训练 × 世界模型滚动 × 视觉问答审计」把闭环推到了「可预测、可解释」的层次。但它有一个根本性的安全缺口：**整套体系输出的是软风险量 λ_risk 与软认证前缀，而不是一个可证明的不变集**。λ_risk 再怎么调，也只能说明“当前看起来更危险/更安全”，无法回答「在障碍物速度有界、感知有误差、模型会漂移的情况下，系统是否**一定**不会离开安全集」。换言之，SimRAS 擅长“风险叙事”，不擅长“安全承诺”。
>
> 本轮灵感的两个词恰好补上这块短板：
> - **安全性**不是“低风险分数”，而是**集合不变性（set invariance）**——存在安全集 C，系统在任意有界扰动下都不离开 C；
> - **避障控制**不是“绕开当前障碍”，而是**带动态障碍可达性的约束控制**——预测、外扩、并用备份策略保证递归可行。
>
> 本轮核心命题：
>
> **把 SimRAS 的「软风险缩放」外包给一个「硬安全壳」：用动态障碍可达管（DOR）处理运动不确定性，用共形预测（CPQ）把世界模型误差变成有统计保证的障碍膨胀，用自适应控制屏障函数（ACBF）做最小干预安全滤波，用备份策略证书（BPC）保证递归可行，再用近失审计（NMA）与仿真标定（SRC）闭环收紧。核心不变式是「安全单调原则」：情绪、世界模型、视觉问答的一切输出只能收紧硬约束，绝不能放宽。**
>
> 一句话：**RAS/SimRAS 决定“想怎么走”，CASA 决定“最多能怎么走”。**

## 0. 直觉与动机

**灵感 1（安全性 → 从风险分数到不变集）**
直觉：SimRAS 的 λ_risk ∈ (0.5, 1.2) 是一个连续旋钮，旋钮往右拧就是“放宽容差”。但安全工程里，“宽容差”必须对应一个可验证的集合：只要状态在集合内，故障注入、扰动、模型误差都不会把状态推出去。因此安全性的正确形式化不是 `R_emotion < τ`，而是 `∀t: x(t) ∈ C_t`，其中 `C_t` 由控制屏障函数 `h(x,t) ≥ 0` 定义。CBF 的美妙之处在于：它把“永远不撞”这个全局性质，降解为每个时刻一个**局部线性约束**，从而能在 QP 里实时求解。

**灵感 2（避障控制 → 动态可达管 + 备份策略）**
直觉：静态障碍的 CBF 只需 `dist(p, O) ≥ r`。但真实避障的难点是**运动障碍**：人、其他机器人、被风吹动的物体。只预测一条轨迹不够，因为预测必然错；正确做法是预测一个**可达管（reachable tube）**——在速度界内，障碍未来可能占据的所有位置。控制只需远离这个管，就不依赖单条预测的准确性。更进一步，仅有 CBF 还不够：QP 在某些时刻会不可行（狭窄通道、突发障碍）。因此必须预置一个**经过证书的备份策略** `π_b`，保证“一旦主约束不可行，仍能安全停住或退到安全区”。这就是 safety filter + backup 的经典硬安全结构。

**灵感 3（与 SimRAS 的耦合 → 预测器只提供“分布”，不提供“保证”）**
直觉：世界模型 `WM_θ` 天然可以输出障碍未来位置的均值与方差；SimEngine 能生成海量对抗性动态障碍场景；VQAuditor 能对“近失事件（near-miss）”做因果审计。但它们都是黑箱，不能直接提供安全保证。正确的耦合方式是：
- WM 只负责**给出预测分布**；
- CPQ 用共形预测把该分布转成**有覆盖率保证的膨胀半径** `q_{1-δ}`；
- SRC 在仿真里标定扰动界 `d_max`、障碍速度界 `v_i^max`、备份可行性；
- NMA 把近失事件蒸馏成**只能增大的安全边距** `κ_margin`。
这样，安全保证不依赖 WM 的“正确”，只依赖其误差分布可被校准——这是从“相信模型”到“审计模型”的关键转变。

**灵感 4（核心张力 → 安全单调原则）**
直觉：第 66 轮 RAS 的最大风险是“情绪误判导致过度放宽容差”。第 67 轮 SimRAS 的最大风险是“世界模型/视觉问答黑箱导致基于虚假前瞻信心放宽容差”。两者同源：**软风险信号被允许放宽硬约束**。本轮用一条不可协商的不变式斩断它：
> **安全单调原则**：软信号（情绪 λ、WM 预测、VQA 建议、任务激励）只能让 `α_risk ≤ α_0`（更严格），永远不能让 `α_risk > α_0`（更宽松）。
于是，无论 RAS/SimRAS 输出多“乐观”，CASA 的安全集都不会因此缩小；最坏情况是系统变得更保守、更早停，而不是更冒险。

**灵感 5（三合流 → CASA：Certified Adaptive Safety Avoidance）**
CASA 把六件东西装进一个闭环：
1. **DOR**：动态障碍可达管，外扩所有可能的未来位置；
2. **CPQ**：共形预测校准 WM 误差，给出统计覆盖的膨胀量；
3. **ACBF**：自适应 CBF 约束 + QP 最小干预安全滤波；
4. **BPC**：备份策略证书，保证 QP 不可行时仍递归可行；
5. **NMA**：VQA 近失审计，离线单调收紧边距；
6. **SRC**：SimEngine 对抗场景标定，产出证书参数。
它们与 SimRAS 的关系不是替代，而是**包裹**：`u_cmd = ACBF_Filter(SimRAS_Control, DOR, CPQ)`。

## 1. 形式化定义（增量：定义 266–280）

- **定义 266（CASA 总览）**：`CASA = (DOR, CPQ, ACBF, BPC, NMA, SRC)`。定位：SimRAS 的「软风险闭环」外层的「硬安全壳」。不变式：ACBF/BPC 在实时流（≤2ms）；DOR/CPQ 的预测在语义流；NMA/SRC 在离线/异步流。所有软信号只能经定义 271 的单调门进入硬约束。
- **定义 267（动态障碍可达管 BRT）**：对障碍 i，给定当前观测 `(p_i, v_i)`、速度界 `v_i^max` 与时间窗 `T`，可达管
  `B_i(t) = { y | ∃τ∈[0,T], ∃ p_i(·): p_i(t)=p_i, ||ṗ_i||≤v_i^max, y=p_i(t+τ) }`。
  工程上用 Hamilton–Jacobi level-set 或保守椭球/凸多边形外近似；外近似必须满足 `B̂_i ⊇ B_i`。
- **定义 268（共形预测不确定性 CPQ）**：校准集 `D_cal = {(p̂_i^k, p_i^k)}`，非一致性分数 `s = ||p̂_i^k - p_i^k||`。分位数
  `q_{1-δ} = Quantile_{⌈(n+1)(1-δ)⌉/n}({s})`。
  分布漂移时用自适应共形推断（ACI）在线更新 `δ_t`，维持长期覆盖率。有效膨胀半径
  `r_i^eff(t) = r_i^obs + r_robot + q_{1-δ_t} + v_i^max·τ_react + κ_margin·σ_wm(t)`。
- **定义 269（时变安全集）**：`h_i(x,t) = dist(p, B_i(t)) - (r_robot + r_i^eff(t))`，`h(x,t) = min_i h_i(x,t)`。安全集 `C_t = {x | h(x,t) ≥ 0}`。多障碍时用光滑下包络 `h_τ = -(1/τ)·log Σ_i exp(-τ·h_i) ≤ h`，保证保守性。
- **定义 270（自适应 CBF 约束）**：控制仿射系统 `ẋ = f(x) + g(x)u + d(t)`，`||d|| ≤ d_max`。安全条件
  `L_f h + L_g h·u + ||∇_x h||·d_max + L_t h ≥ -α_risk(h)`，
  其中 `L_t h` 捕获障碍运动与膨胀半径变化的漂移，`α_risk(h) = max(α_min, min(1, λ_risk)·α_0)·h`。
- **定义 271（安全单调原则）**：对任意软信号 `λ_risk`（含情绪、WM、VQA、任务激励的合成），
  `α_risk ≤ α_0`，且可容许控制集满足 `U_safe(λ_risk) ⊆ U_safe(1)`。
  即：软信号只能收紧、不能放宽硬安全约束。等价地，`λ_risk ← min(1, λ_risk)` 在进入 CBF 前被强制裁剪。
- **定义 272（ACBF 安全滤波器）**：
  `u* = argmin_{u∈U} ||u - u_nom||²` s.t. 对所有 i：`L_f h_i + L_g h_i·u + ||∇h_i||d_max + L_t h_i ≥ -α_risk(h_i)`。
  若可行域为空，切换到 BPC 保证的备份策略 `π_b`；安全滤波器是最小干预投影。
- **定义 273（备份策略证书 BPC）**：备份集 `S_b ⊆ C_t` 与策略 `π_b`，满足
  `L_f h_b + L_g h_b·π_b + ||∇h_b||d_max + L_t h_b ≥ -α_b(h_b)`，`h_b ≥ 0` 定义 `S_b`；
  且 `π_b` 在 `T_stop` 内把系统带入“安全停/退区” `S_stop ⊆ S_b`。
- **定义 274（递归可行前缀）**：C-RAS-WM 前缀 `A[:k]` 上，若对每个 `s ≤ k` 都存在备份轨迹 `π_b(x_s)` 使 `x_{s+1} ∈ S_b`，则称前缀递归可行。`k_casa = max{k ≤ k*RAS | 前缀递归可行}`。
- **定义 275（近失事件审计 NMA）**：当 `h_i(x,t) < ε_nm` 时记录近失事件；VQAuditor 输出结构化报告 `{cause, counterfactual, margin_recommend}`。离线更新只允许 `κ_margin ← κ_margin + Δ`（`Δ ≥ 0`）与场景权重增加，不允许在线放宽。
- **定义 276（仿真标定 SRC）**：SimEngine 生成对抗动态障碍（突发横穿、遮挡后重现、群体挤压），标定 `d_max, v_i^max, α_min, α_0, δ` 与备份可行性；输出 `sim_calib_ver` 与覆盖率证据。
- **定义 277（安全状态机）**：`safety_state ∈ {CERTIFIED, DEGRADED, BACKUP, STOP}`。触发条件：
  `CERTIFIED`：QP 可行 ∧ 覆盖率 ≥ 1-δ ∧ `wm_consist`；
  `DEGRADED`：`wm_drift` 或 OOD 但 QP 仍可行（冻结 `λ_risk=1`，仅收紧）；
  `BACKUP`：QP 不可行但 BPC 可行；
  `STOP`：BPC 也不可行（进入认证紧急停止）。
- **定义 278（J_CASA 证书）**：`J_CASA = (J_SimRAS, brt_hash, q_conformal, alpha_risk, cbf_margin, backup_feasible, nma_hash, sotif_odd_ver)`。
  `Valid ⇔ Valid(J_SimRAS) ∧ cbf_margin ≥ 0 ∧ backup_feasible = True ∧ coverage ≥ 1-δ`。
- **定义 279（SOTIF 运行域 ODD）**：`ODD = {障碍密度, 速度上限, 遮挡时长, 光照, 地面摩擦, 通信延迟}`。在线检测 `x ∉ ODD` 时强制 `safety_state ≥ DEGRADED`，并按定义 277 收紧。
- **定义 280（安全停止回退）**：`S_stop` 内存在一条认证轨迹，使系统在 `T_stop` 内速度归零且 `h_i ≥ 0, ∀i`；该轨迹由 SRC 与 BPC 联合验证，写入证书 `stop_traj_hash`。

## 2. 关键算法骨架

```python
# DOR + CPQ：动态障碍可达管 + 共形膨胀
class DynamicObstacleReachability:
    def __init__(self, wm, conformal, horizon=2.0, tau_react=0.2):
        self.wm, self.cpq = wm, conformal
        self.T, self.tau_react = horizon, tau_react

    def reachable_tubes(self, obs_t, v_max):
        preds = self.wm.predict_obstacles(obs_t, horizon=self.T)
        tubes = {}
        for i, pred in enumerate(preds):
            q = self.cpq.quantile(i)                 # q_{1-δ_t}
            r_eff = (pred.radius + q
                     + v_max[i] * self.tau_react
                     + self.cpq.margin_scale * pred.sigma)
            tubes[i] = self._inflate_brt(pred.mean, v_max[i], r_eff)
        return tubes                              # B̂_i(t) ⊇ B_i(t)


# ACBF：自适应控制屏障函数安全滤波（实时流）
class AdaptiveCBFFilter:
    def __init__(self, alpha0=1.2, alpha_min=0.2, d_max=0.05):
        self.alpha0, self.alpha_min, self.d_max = alpha0, alpha_min, d_max

    def alpha_risk(self, h, lambda_risk):
        lam = min(1.0, max(0.0, lambda_risk))     # 定义 271：安全单调
        return max(self.alpha_min, lam * self.alpha0) * h

    def filter(self, x, u_nom, barriers, lambda_risk):
        # barriers: [(h, Lf_h, Lg_h, Ldot_h, grad_h), ...]
        constraints = []
        for (h, Lf_h, Lg_h, Ldot_h, grad_h) in barriers:
            drift = Lf_h + Ldot_h + norm(grad_h) * self.d_max
            rhs = -self.alpha_risk(h, lambda_risk) - drift
            constraints.append((Lg_h, rhs))       # Lg_h·u ≥ rhs
        u = solve_min_norm_qp(u_nom, constraints)
        if u is None:
            return None, False                    # → BPC
        return u, True


# BPC：备份策略证书
class BackupPolicyCertificate:
    def __init__(self, backup_policy, h_b, S_b, S_stop, sim_calib):
        self.pi_b, self.h_b = backup_policy, h_b
        self.S_b, self.S_stop = S_b, S_stop
        self.calib = sim_calib

    def feasible(self, x, tubes):
        if not inside(x, self.S_b):
            return False
        # 在仿真/解析模型上滚动验证：T_stop 内进入 S_stop 且全程 h_i ≥ 0
        traj = rollout(self.pi_b, x, self.calib.d_max, horizon=self.calib.T_stop)
        return all(all(h_i(y, t) >= 0 for i in tubes) for t, y in enumerate(traj)) \
               and inside(traj[-1], self.S_stop)


# NMA / SRC：近失审计与离线单调标定
class NearMissAuditor:
    def audit(self, near_miss_clip, scene_ctx):
        report = self.vqa.ask(near_miss_clip, self.prompts['near_miss'])
        return parse_near_miss(report)            # {cause, counterfactual, margin_recommend}

    def distill(self, reports):
        extra = max(0.0, max(r['margin_recommend'] for r in reports))
        return extra                              # 只允许增大 κ_margin


# CASA 在线闭环：包裹 SimRAS
def CASA_round(M, obs):
    # 1) 原 SimRAS 前向（软风险）
    k_ras, lambda_risk, joint_post, face_gate, wm_preds = SimRAS_round(M, obs)

    # 2) DOR + CPQ：动态障碍可达管（语义流）
    v_max = M.src.speed_bounds(obs)
    tubes = M.dor.reachable_tubes(obs.state, v_max)

    # 3) ACBF：用 SimRAS 控制做标称输入，求解硬安全滤波
    u_nom = M.simras.control(k_ras, lambda_risk, joint_post)
    barriers = [M.barrier.build(x, tubes[i]) for i in tubes]
    u_safe, ok = M.acbf.filter(obs.state, u_nom, barriers, lambda_risk)

    # 4) BPC：不可行则切换备份，并检查前缀递归可行
    if not ok:
        if M.bpc.feasible(obs.state, tubes):
            u_safe, safety_state = M.bpc.pi_b(obs.state), 'BACKUP'
        else:
            u_safe, safety_state = M.stop.act(obs.state), 'STOP'
    else:
        safety_state = 'CERTIFIED' if M.cpq.coverage() >= 1 - M.delta else 'DEGRADED'
        if not M.bpc.feasible(obs.state, tubes):
            safety_state = 'DEGRADED'             # 保留证书但不承诺完整前缀

    # 5) 证书
    cert = M.cert.build(
        J_simras=M.simras.certificate, brt_hash=hash(tubes),
        q_conformal=M.cpq.q, alpha_risk=M.acbf.alpha0,
        cbf_margin=min(h_i for i in barriers),
        backup_feasible=M.bpc.feasible(obs.state, tubes),
        nma_hash=M.nma.last_hash, sotif_odd_ver=M.odd.version)

    # 6) 近失事件异步审计（不阻塞实时）
    if min(h_i for i in barriers) < M.epsilon_nm:
        M.nma.submit_async(obs.clip, {'scene': obs.state, 'tubes': tubes})

    return u_safe, safety_state, cert
```

## 3. 推导

**引理 13（软信号的安全单调性）** 因 `λ_risk` 在进入 CBF 前被 `min(1, ·)` 裁剪，故 `α_risk(h) ≤ α_0·h` 恒成立。CBF 约束右端 `-α_risk(h)` 随 `α_risk` 减小而减小（更严格），故 `U_safe(λ_risk) ⊆ U_safe(1)`。结论：情绪/SimRAS 的任何“乐观”输出都不能扩大可容许控制集。

**引理 14（共形膨胀的边际覆盖）** 在可交换性下，`P(||p̂_i - p_i|| ≤ q_{1-δ}) ≥ 1-δ`。因此 `r_i^eff ≥ r_i^obs + r_robot + 真实误差` 的概率至少 `1-δ`；即真实障碍被膨胀管 `B̂_i` 覆盖的概率至少 `1-δ`。若分布漂移，ACI 将长期覆盖率维持在 `1-δ` 附近（在给定学习率下）。

**引理 15（QP 最小干预）** ACBF 滤波器的解是 `u_nom` 到凸可行集 `U_safe` 的欧氏投影，故 `||u* - u_nom|| = dist(u_nom, U_safe)`；当 `u_nom ∈ U_safe` 时不干预（`u*=u_nom`）。干预量被约束违反量线性上界：`||u* - u_nom|| ≤ (1/σ_min(L_g h))·max(0, -α_risk(h) - drift)`。

**定理 14（概率前向不变性 / 无碰撞）** 假设：(A) CPQ 覆盖成立（引理 14）；(B) 每个时刻要么 ACBF-QP 可行，要么 BPC 可行；(C) `B̂_i ⊇ B_i` 且 `d_max` 为真实扰动上界。则对任意 `t ≤ T_stop`，
`P(∀t: x(t) ∈ C_t) ≥ 1 - δ - δ_b`，其中 `δ_b` 为 BPC 验证误差。即系统以至少 `1-δ-δ_b` 的概率全程无碰撞。

**定理 15（安全与任务性能的分离）** 令 `u_nom` 为 SimRAS 的任务控制。若其导致的 CBF 约束违反量为 `v(t) ≥ 0`，则 `||u_safe - u_nom|| ≤ v(t)/σ_min`。故任务性能损失只发生在“本就不安全”的控制上；SimRAS 越保守（`λ_risk` 越小），`v(t)` 越小，干预越少。这给出了软风险与硬安全之间的可解释权衡。

**定理 16（备份递归可行性）** 若 BPC 的 `h_b` 条件与 `S_stop ⊆ S_b ⊆ C_t` 成立，则 QP 不可行时切换 `π_b` 仍保持 `x ∈ S_b`，并在 `T_stop` 内进入 `S_stop`；由于 `S_b ⊆ C_t`，该过程无碰撞。故安全滤波器的最坏情况不是碰撞，而是“安全停止”。

**定理 17（与 SimRAS 的组合安全性）** `u_cmd = CASA_filter(u_SimRAS)` 的无碰撞保证只依赖 `(q_{1-δ}, d_max, v_i^max, BPC)`，不依赖 `WM_θ`、`emo_head`、`VQA` 的内部正确性。因此 SimRAS 的黑箱误差只影响任务性能与保守程度，不影响安全承诺——这修正了第 67 轮“世界模型黑箱可直接放行安全”的隐患。

## 6. 本轮最大风险

**一句话**：CASA 的概率安全保证建立在「共形校准集与在线障碍分布可交换 / 缓慢漂移」这一统计假设上，一旦真实场景出现强分布漂移（突发群体、传感器系统性偏差）或狭窄通道使 BPC 也不可行，覆盖率与递归可行性同时失效，系统会退化为「保守急停」甚至无解——即**安全壳在最需要它的长尾场景里最先失效**。

**次级风险与缓解**：
1. **保守性过高**：DOR 外扩 + 共形膨胀 + 最小 CBF 可能让机器人在人群中寸步难行 → 引入自适应边距（NMA 只收紧、SRC 可在认证域内按场景标定），并报告“保守度”指标；
2. **BPC 不可行**：狭小空间无安全停止轨迹 → 预留认证 `S_stop` 区域，或提前在 ODD 外触发绕行/不进入；
3. **ACI 覆盖率振荡**：学习率过大会导致覆盖率长期偏低 → 用加权共形 + 慢更新，且将 `coverage` 写入证书门槛；
4. **QP 求解延迟**：多障碍约束导致 QP 变慢 → 只保留最近 k 个障碍的约束（其余用 `h_τ` 光滑聚合），并做热启动；
5. **证书自证陷阱**：J_CASA 的 `backup_feasible` 若由同一仿真器自证，可能过拟合 → 用独立验证集与形式化 BRT 交叉校验。

## 2. 形式化定义（完整版）

**定义 266（CASA 总览）** CASA 是 SimRAS 的硬安全外壳：
```
CASA = (DOR, CPQ, ACBF, BPC, NMA, SRC)
```
不变式：ACBF/BPC 在实时流；DOR/CPQ 预测在语义流；NMA/SRC 在离线/异步流。所有软信号只经定义 271 的单调门进入硬约束。

**定义 267（动态障碍可达管）** 对障碍 i，给定 `(p_i, v_i)` 与速度界 `v_i^max`：
```
B_i(t) = { y | ∃τ∈[0,T], ∃p_i(·): p_i(t)=p_i, ‖ṗ_i(τ)‖≤v_i^max, y=p_i(t+τ) }
```
工程近似 `B̂_i ⊇ B_i`（HJ level-set 或保守椭球/凸多边形）。

**定义 268（共形预测不确定性）** 校准分数 `s = ‖p̂_i - p_i‖`，分位
```
q_{1-δ} = Quantile_{⌈(n+1)(1-δ)⌉/n}({s})
```
漂移时用 ACI 更新 `δ_t`。有效半径
```
r_i^eff(t) = r_i^obs + r_robot + q_{1-δ_t} + v_i^max·τ_react + κ_margin·σ_wm(t)
```

**定义 269（时变安全集）**
```
h_i(x,t) = dist(p, B_i(t)) - (r_robot + r_i^eff(t))
h(x,t)   = min_i h_i(x,t)
C_t      = {x | h(x,t) ≥ 0}
```

**定义 270（自适应 CBF 约束）** 对 `ẋ = f(x)+g(x)u+d`，`‖d‖≤d_max`：
```
L_f h + L_g h·u + ‖∇_x h‖·d_max + L_t h ≥ -α_risk(h)
α_risk(h) = max(α_min, min(1, λ_risk)·α_0)·h
```

**定义 271（安全单调原则）** 对任意软信号，
```
α_risk ≤ α_0  ⇔  U_safe(λ_risk) ⊆ U_safe(1)
```
软信号只能收紧、不能放宽硬安全约束；进入 CBF 前强制 `λ_risk ← min(1, λ_risk)`。

**定义 272（ACBF 安全滤波器）**
```
u* = argmin_{u∈U} ‖u - u_nom‖²
s.t. ∀i: L_f h_i + L_g h_i·u + ‖∇h_i‖d_max + L_t h_i ≥ -α_risk(h_i)
```
可行域为空时切换到 BPC 的 `π_b`。

**定义 273（备份策略证书）** 存在 `S_b ⊆ C_t`、`π_b`、`h_b`，使
```
L_f h_b + L_g h_b·π_b + ‖∇h_b‖d_max + L_t h_b ≥ -α_b(h_b),  h_b ≥ 0
```
且 `π_b` 在 `T_stop` 内进入 `S_stop ⊆ S_b`。

**定义 274（递归可行前缀）** 若对前缀 `A[:k]` 的每个 `s≤k`，备份轨迹满足 `x_{s+1} ∈ S_b`，则前缀递归可行：
```
k_casa = max{k ≤ k*RAS | 前缀递归可行}
```

**定义 275（近失事件审计）** 当 `h_i(x,t) < ε_nm` 时记录近失；VQA 输出
```
NearMissReport = {cause, counterfactual, margin_recommend}
```
蒸馏只允许 `κ_margin ← κ_margin + max(0, margin_recommend)`。

**定义 276（仿真标定）** SRC 用 SimEngine 对抗场景标定 `d_max, v_i^max, α_min, α_0, δ, T_stop`，输出 `sim_calib_ver` 与覆盖率证据。

**定义 277（安全状态机）**
```
CERTIFIED: QP 可行 ∧ coverage ≥ 1-δ ∧ wm_consist
DEGRADED : wm_drift ∨ OOD，但 QP 仍可行（冻结 λ_risk=1，仅收紧）
BACKUP   : QP 不可行但 BPC 可行
STOP     : BPC 不可行 → 认证紧急停止
```

**定义 278（J_CASA 证书）**
```
J_CASA = (J_SimRAS, brt_hash, q_conformal, alpha_risk, cbf_margin,
          backup_feasible, nma_hash, sotif_odd_ver)
Valid ⇔ Valid(J_SimRAS) ∧ cbf_margin ≥ 0 ∧ backup_feasible ∧ coverage ≥ 1-δ
```

**定义 279（SOTIF 运行域）** `ODD = {障碍密度, 速度上限, 遮挡时长, 光照, 地面摩擦, 通信延迟}`。`x ∉ ODD ⇒ safety_state ≥ DEGRADED`。

**定义 280（安全停止回退）** `S_stop` 内存在认证轨迹，使系统在 `T_stop` 内速度归零且 `h_i ≥ 0, ∀i`；其哈希写入 `stop_traj_hash`。

```python
# IP-243 + IP-244：DOR + CPQ
class DynamicObstacleReachability:
    def __init__(self, wm, cpq, horizon=2.0, tau_react=0.2):
        self.wm, self.cpq = wm, cpq
        self.T, self.tau_react = horizon, tau_react

    def reachable_tubes(self, state, v_max):
        preds = self.wm.predict_obstacles(state, horizon=self.T)
        tubes = {}
        for i, pred in enumerate(preds):
            q = self.cpq.quantile(i)
            r_eff = (pred.radius + q + v_max[i] * self.tau_react
                     + self.cpq.margin_scale * pred.sigma)
            tubes[i] = inflate_brt(pred.mean, v_max[i], r_eff, self.T)
        return tubes                       # B̂_i ⊇ B_i


# IP-244：ACI 共形校准
class ConformalQuantile:
    def __init__(self, delta=0.1, n_cal=2000, gamma=0.01):
        self.delta, self.gamma = delta, gamma
        self.errors = []

    def update(self, y_hat, y_true):
        self.errors.append(abs(y_hat - y_true))

    def quantile(self, i):
        n = len(self.errors)
        k = math.ceil((n + 1) * (1 - self.delta_t(i)))
        return sorted(self.errors)[min(k, n) - 1]

    def delta_t(self, i, covered=False):
        # ACI：未覆盖则收紧 delta，覆盖则放松，长期维持 1-δ
        self.delta = min(0.5, max(0.01,
            self.delta + self.gamma * (self.delta - (1.0 if covered else 0.0))))
        return self.delta


# IP-245：ACBF 最小干预安全滤波
class AdaptiveCBFFilter:
    def __init__(self, alpha0=1.2, alpha_min=0.2, d_max=0.05):
        self.alpha0, self.alpha_min, self.d_max = alpha0, alpha_min, d_max

    def alpha_risk(self, h, lambda_risk):
        lam = min(1.0, max(0.0, lambda_risk))     # 安全单调原则
        return max(self.alpha_min, lam * self.alpha0) * h

    def filter(self, x, u_nom, barriers, lambda_risk):
        constraints = []
        for (h, Lf_h, Lg_h, Ldot_h, grad_h) in barriers:
            drift = Lf_h + Ldot_h + norm(grad_h) * self.d_max
            constraints.append((Lg_h, -self.alpha_risk(h, lambda_risk) - drift))
        u = solve_min_norm_qp(u_nom, constraints)
        return (u, True) if u is not None else (None, False)


# IP-246：备份策略证书
class BackupPolicyCertificate:
    def __init__(self, pi_b, h_b, S_b, S_stop, calib):
        self.pi_b, self.h_b = pi_b, h_b
        self.S_b, self.S_stop, self.calib = S_b, S_stop, calib

    def feasible(self, x, tubes):
        if not inside(x, self.S_b):
            return False
        traj = rollout(self.pi_b, x, self.calib.d_max,
                       horizon=self.calib.T_stop)
        ok_safe = all(all(h_i(y, t) >= 0 for i in tubes)
                      for t, y in enumerate(traj))
        return ok_safe and inside(traj[-1], self.S_stop)

def CASA_round(M, obs):
    # 1) SimRAS 软闭环
    k_ras, lambda_risk, joint_post, face_gate, wm_preds = SimRAS_round(M, obs)

    # 2) DOR + CPQ（语义流）

    tubes = M.dor.reachable_tubes(obs.state, v_max)

    # 3) ACBF 硬安全滤波
    u_nom = M.simras.control(k_ras, lambda_risk, joint_post)
    barriers = [M.barrier.build(obs.state, tubes[i]) for i in tubes]
    u_safe, ok = M.acbf.filter(obs.state, u_nom, barriers, lambda_risk)

    # 4) BPC / 安全状态机
    backup_ok = M.bpc.feasible(obs.state, tubes)
    if not ok:
        if backup_ok:
            u_safe, safety_state = M.bpc.pi_b(obs.state), 'BACKUP'
        else:
            u_safe, safety_state = M.stop.act(obs.state), 'STOP'
    else:
        safety_state = ('CERTIFIED'
                        if M.cpq.coverage() >= 1 - M.delta and not M.wm_drift
                        else 'DEGRADED')
        if not backup_ok:
            safety_state = 'DEGRADED'

    # 5) 近失异步审计（只收紧）
    margin = min(b[0] for b in barriers)
    if margin < M.epsilon_nm:
        M.nma.submit_async(obs.clip, {'scene': obs.state, 'tubes': tubes})

    # 6) 证书
    cert = M.cert.build(
        J_simras=M.simras.certificate, brt_hash=hash(tubes),
        q_conformal=M.cpq.q, alpha_risk=M.acbf.alpha0,
        cbf_margin=margin, backup_feasible=backup_ok,
        nma_hash=M.nma.last_hash, sotif_odd_ver=M.odd.version)

    return u_safe, safety_state, cert
```

## 4. 推导

**引理 13（软信号的安全单调性）** `λ_risk` 进入 CBF 前被 `min(1, ·)` 裁剪，故 `α_risk(h) ≤ α_0·h`。CBF 约束右端 `-α_risk(h)` 随 `α_risk` 减小而减小（更严格），故 `U_safe(λ_risk) ⊆ U_safe(1)`。任何“乐观”软信号都不能扩大可容许控制集。

**引理 14（共形膨胀的边际覆盖）** 在可交换性下 `P(‖p̂-p‖ ≤ q_{1-δ}) ≥ 1-δ`，故真实障碍被 `B̂_i` 覆盖的概率至少 `1-δ`。ACI 在漂移下维持长期覆盖率约 `1-δ`。

**引理 15（QP 最小干预）** ACBF 解是 `u_nom` 到凸可行集的欧氏投影，`‖u*-u_nom‖ = dist(u_nom, U_safe)`；`u_nom ∈ U_safe` 时零干预。干预量满足
```
‖u* - u_nom‖ ≤ (1/σ_min(L_g h))·max(0, -α_risk(h) - drift)
```

**定理 14（概率前向不变性 / 无碰撞）** 假设 (A) CPQ 覆盖；(B) 每时刻 QP 可行或 BPC 可行；(C) `B̂_i ⊇ B_i`、`d_max` 为真实扰动上界。则
```
P(∀t: x(t) ∈ C_t) ≥ 1 - δ - δ_b
```
即系统以至少 `1-δ-δ_b` 的概率全程无碰撞。

**定理 15（安全与任务性能分离）** 令 `v(t) ≥ 0` 为 `u_nom` 的 CBF 约束违反量，则 `‖u_safe-u_nom‖ ≤ v(t)/σ_min`。任务损失只发生在“本就不安全”的控制上；`λ_risk` 越小，`v(t)` 越小，干预越少。

**定理 16（备份递归可行性）** 若 BPC 的 `h_b` 条件与 `S_stop ⊆ S_b ⊆ C_t` 成立，则 QP 不可行时 `π_b` 保持 `x ∈ S_b`，并在 `T_stop` 内进入 `S_stop`，全程无碰撞。安全滤波器的最坏情况是安全停止，而非碰撞。

**定理 17（与 SimRAS 的组合安全性）** `u_cmd = CASA_filter(u_SimRAS)` 的无碰撞保证只依赖 `(q_{1-δ}, d_max, v_i^max, BPC)`，不依赖 `WM_θ/emo_head/VQA` 的内部正确性。SimRAS 的黑箱误差只影响任务性能与保守程度，不影响安全承诺。

## 7. 本轮最大风险

**一句话**：CASA 的概率安全保证建立在「共形校准集与在线障碍分布可交换 / 缓慢漂移」这一统计假设上，一旦真实场景出现强分布漂移（突发群体、传感器系统性偏差）或狭窄通道使 BPC 也不可行，覆盖率与递归可行性同时失效，系统会退化为「保守急停」甚至无解——即**安全壳在最需要它的长尾场景里最先失效**。

**缓解**：ACI 慢更新 + 覆盖率写入证书门槛；ODD 外提前降级；认证 `S_stop` 预置；独立验证集与形式化 BRT 交叉校验，避免证书自证陷阱。
