### 第 8 轮灵感驱动研究记录

**灵感词**：移动底盘、手眼标定

**继承关系**：第 7 轮 CADVS-v7（IP-501~IP-504）在「指令-几何-力学三元凿」上叠加了「需求-意图-一致性三角桥」，用 DIM/DRC/DAC 把系统从「被动接受指令」推向「主动推导意图」。但 v6/v7 的所有几何门（GGC 的抓取几何、MCTM 的空间拓扑、STM 的指令-轨迹映射）都默认了一个从未被审计的前提：**相机-机械臂-底盘之间的坐标变换是已知且不变的**。本轮回到「几何地基」，把「移动底盘」与「手眼标定」作为一对耦合变量处理，提出「标定-底盘-证书三元地基」，用**第零硬门（Gate-0）**保护其余七硬门的前置假设。

**直觉与动机**：

1. **手眼标定 → 从「离线常量」到「带协方差的在线证书」**。经典 AX=XB 标定把相机到末端的外参 X 当作一次性求出的常量，只在换相机/撞机后才重标。但真实系统里 X 会因温漂、振动、夹爪更换而缓慢漂移；更关键的是，**残差小不等于标定好**——一组退化的运动（旋转轴几乎平行、机械臂几乎不动）可以给出极低残差却极大的参数协方差。因此本轮把 X 建模为随机变量，同时输出**残差 r_rms、参数协方差 Σ_X、以及运动激励度 ξ**，三者共同构成「标定证书」。

2. **移动底盘 → 从「已知基座」到「时变不确定基座」**。v7 的 MCTM 把底盘位姿当作查询输入，却没有把底盘定位协方差 Σ_B(t) 传下去。底盘在导航中里程计漂移、在对接时被几何约束收紧，这种时变性会沿着「世界 W → 底盘 B → 末端 E → 相机 C」的链传播：**即使手眼标定很准，底盘一漂，喂给 GGC/MCTM 的有效几何照样错**。关键洞见是：真正该进几何门的是合成协方差 Σ_WC，而不是手眼协方差 Σ_EC。

3. **移动底盘 × 手眼标定 → 标定图的联合可观测性**。两个灵感词不是并列的：它们在同一条位姿链上耦合。若标定靶固定在底盘上，底盘运动对相对运动是「公共左乘」而相互抵消，手眼标定不受益也不受害，但世界系位姿仍不可观测；若标定靶固定在世界系而底盘运动，底盘运动会混入相机相对运动却不进入末端相对运动，AX=XB 被污染。**因此「靶标装在哪、底盘动不动」直接决定标定是否可辨识**——这是本轮最硬的结论。

**关键洞见**：前七轮一直在加固「证书的内容」，本轮加固「证书所依赖的坐标系本身」。新增模块只有四个：
- IP-505 CFG（标定因子图，Calibration Factor Graph），
- IP-506 HEC（手眼标定核，AX=XB + 可观测性），
- IP-507 CCC（标定证书编译器，Gate-0），
- IP-508 EFA-v8（第零硬门 + 协方差传播的软因子）。

**形式化目标（增量）**：

1. **CFG（标定因子图）**：以帧集合 V={W,B,E,C} 为节点，以带协方差的变换为边；维护联合估计与边缘协方差：
   - 边：T_W←B(t)（底盘定位，Σ_B(t)），T_B←E（正运动学，Σ_FK），T_E←C（手眼，Σ_X）；
   - 合成：T_W←C = T_W←B · T_B←E · T_E←C；
   - 协方差传播：Σ_WC = J Σ_ξ Jᵀ，ξ=(ξ_WB, ξ_BE, ξ_EC)。

2. **HEC（手眼标定核）**：
   - 数据：相对运动对 (A_i,B_i)，A_i=T_E(i)←E(0)，B_i=T_C(i)←C(0)；
   - 约束：A_i X = X B_i，X=T_E←C；
   - 残差：r_i = ||log(T_A_i X (X T_B_i)^{-1})||_SE3，r_rms=sqrt(mean r_i²)；
   - 协方差：Σ_X ≈ (Jᵀ Σ_r^{-1} J)^{-1}（Gauss-Newton 后验）；
   - 激励矩阵：G = Σ_i (R_A_i - I)ᵀ(R_A_i - I)，可观测当且仅当 rank(G)=3。

3. **CCC（标定证书编译器 / Gate-0）**：
   - η_calib = exp(-r_rms²/(2ρ₀²)) · exp(-σ_max²/(2σ₀²)) ∈ (0,1]；
   - kc_calib：r_rms ≤ ρ_max ∧ σ_max(Σ_X) ≤ σ* ∧ ξ ≥ ξ_min；
   - 未通过则**拒绝一切依赖几何的提议**（fail-closed），而非降级执行。

4. **EFA-v8**：
   - Gate-0 通过后，有效几何不确定性取 Σ_WC（而非 Σ_EC），安全余量 d_eff = d - k·σ_max(Σ_WC)；
   - 阈值反向收紧：τ_i^v8 = τ_i^v7 / η_calib ≥ τ_i^v7（注意 η_calib≤1，与前几轮 η≥1 的方向相反，必须显式处理）；
   - ECS_v8 = ECS_v7 · η_calib。

5. **形式化定义**：给定标定数据 D={(A_i,B_i)}、底盘位姿序列 {T_W←B(t)}：
   - (r_rms, Σ_X, ξ) = HEC(D)；
   - Gate-0: kc_calib(r_rms, Σ_X, ξ) = 1；
   - Σ_WC = CFG.propagate(Σ_B(t), Σ_FK, Σ_X)；
   - 若 Gate-0=0：return REFUSE_CALIBRATION；
   - 否则执行 EFA-v7 流程，但所有几何门消费 Σ_WC 与收紧后的 τ_i^v8。

**本轮最大风险**：**标定可观测性的「静默失效」**：Gate-0 只能看见激励所张成的子空间——当底盘静止、机械臂小幅度运动、靶标被遮挡时，漂移的标定仍可能给出低残差并通过 Gate-0，从而在「错误几何」上产出「局部正确」的轨迹；这种失效在结构上无法被残差单独捕获。

## 2. 关键算法骨架

### IP-505 CFG：标定因子图

```python
@dataclass
class CalibrationFactorGraph:
    """CFG：在帧图 V={W,B,E,C} 上维护变换与协方差。
    关键：几何门消费的是合成协方差 Σ_WC，而非手眼协方差 Σ_EC。"""

    def compose(self, T_WB, T_BE, T_EC):
        return T_WB @ T_BE @ T_EC  # T_WC

    def propagate(self, T_WB, T_BE, T_EC, S_WB, S_BE, S_EC):
        """左扰动下：δ_WC = δ_WB + Ad(T_WB)δ_BE + Ad(T_WB·T_BE)δ_EC。
        故 J = [I, Ad(T_WB), Ad(T_WB·T_BE)]，Σ_WC = J·blkdiag(Σ)·Jᵀ。"""
        J_WB = torch.eye(6)
        J_BE = se3_adjoint(T_WB)
        J_EC = se3_adjoint(T_WB @ T_BE)
        J = torch.cat([J_WB, J_BE, J_EC], dim=1)          # 6×18
        S = block_diag(S_WB, S_BE, S_EC)                   # 18×18
        return J @ S @ J.T                                 # 6×6

    def sigma_max(self, S):
        return torch.linalg.eigvalsh(S).max().clamp(min=0).sqrt()
```

### IP-506 HEC：手眼标定核

```python
@dataclass
class HandEyeCalibrationKernel:
    """HEC：AX=XB 求解 + 可观测性 + 后验协方差。
    注意：残差小 ≠ 标定好，必须同时看 ξ 与 Σ_X。"""
    rho0: float = 0.002
    sigma0: float = 0.005
    rho_max: float = 0.005          # ~5 mm / 0.3°
    sigma_star: float = 0.01
    xi_min: float = 0.1

    def solve(self, pairs):
        X0 = self.tsai_lenz(pairs)                  # 闭式初值
        X = self.gauss_newton(X0, pairs)            # SE(3) 精化
        S_X = self.posterior_cov(X, pairs)          # (JᵀΣ_r⁻¹J)⁻¹
        G = sum((R_A - I).T @ (R_A - I) for R_A, _ in self.rot_parts(pairs))
        xi = torch.linalg.eigvalsh(G).min().clamp(min=0).item() / 3.0
        r_rms = self.residuals(X, pairs).pow(2).mean().sqrt().item()
        return X, r_rms, S_X, xi

    def residual(self, X, A, B):
        """A·X = X·B  ⇒  A·X·B⁻¹·X⁻¹ = I"""
        return se3_log(A @ X @ B.inverse() @ X.inverse())

    def certificate(self, r_rms, S_X, xi):
        s = self.sigma_max(S_X)
        eta = math.exp(-(r_rms ** 2) / (2 * self.rho0 ** 2)) \
            * math.exp(-(s ** 2) / (2 * self.sigma0 ** 2))
        ok = (r_rms <= self.rho_max) and (s <= self.sigma_star) and (xi >= self.xi_min)
        return eta, ok
```

### IP-507 CCC：标定证书编译器（Gate-0）

```python
@dataclass
class CalibrationCertificateCompiler:
    """CCC：把 HEC 输出编译成 Gate-0 与软因子，并合成 Σ_WC。"""
    hec: HandEyeCalibrationKernel
    cfg: CalibrationFactorGraph

    def compile(self, pairs, T_WB, T_BE, S_WB, S_BE):
        X, r_rms, S_X, xi = self.hec.solve(pairs)
        eta_calib, gate0 = self.hec.certificate(r_rms, S_X, xi)
        T_WC = self.cfg.compose(T_WB, T_BE, X)
        S_WC = self.cfg.propagate(T_WB, T_BE, X, S_WB, S_BE, S_X)
        return CalibrationCertificate(
            X=X, r_rms=r_rms, S_X=S_X, xi=xi, eta_calib=eta_calib,
            T_WC=T_WC, S_WC=S_WC, gate0=gate0)
```

### IP-508 EFA-v8：第零硬门 + 协方差传播

```python
@dataclass
class EvidenceForgingAssemblerV8:
    """EFA-v8：先证明坐标系可信（Gate-0），再进入 v7 的七硬门流程。"""
    v7: EvidenceForgingAssemblerV7
    ccc: CalibrationCertificateCompiler
    k: float = 2.0          # 安全余量倍数（2σ）
    eta_min: float = 0.5    # 防止 1/η 无界

    def select(self, L, t_now, context):
        # 0. Gate-0：坐标系本身不可信时，任何几何动作都拒绝
        cert = self.ccc.compile(
            pairs=context.calib_pairs,
            T_WB=context.T_WB, T_BE=context.T_BE,
            S_WB=context.Sigma_B, S_BE=context.Sigma_FK)
        if not cert.gate0:
            return False, None, 'REFUSE_CALIBRATION'

        # 1. 协方差感知：几何门消费 Σ_WC，安全余量按 2σ 收缩
        sigma_wc = self.ccc.cfg.sigma_max(cert.S_WC)
        inflate = self.k * sigma_wc

        # 2. 阈值反向收紧（η_calib ≤ 1 ⇒ τ/η_calib ≥ τ）
        eta_calib = max(cert.eta_calib, self.eta_min)
        tau_scale = 1.0 / eta_calib

        # 3. 进入 v7，注入 Σ_WC 与收紧比例
        ok, x, tag = self.v7.select(
            L, t_now, context.with_geometry(cert, inflate, tau_scale))
        if not ok:
            return False, None, tag
        return True, x, tag + '+GATE0'
```

### 集成流水线（v7 → v8）

```
慢时域（标定维护，秒~分钟级）：
  靶标固定于底盘、底盘静止 → 采集相对运动对 {(A_i,B_i)}
  HEC.solve → (X, r_rms, Σ_X, ξ)
  CFG.propagate(Σ_B(t), Σ_FK, Σ_X) → Σ_WC
  CCC.compile → 证书（Gate-0 判定 + η_calib）→ 签名缓存下发

在线（每控制周期，亚毫秒级）：
  读取 T_WB(t), Σ_B(t)（里程计 / 对接 / 重定位）
  Gate-0 = [r_rms≤ρ_max ∧ σ_max(Σ_X)≤σ* ∧ ξ≥ξ_min]
  若 Gate-0=0 → REFUSE_CALIBRATION（不降级执行任何几何动作）
  否则 → EFA-v7 流程：
      GGC 余量 d_eff = d − 2σ_max(Σ_WC)
      MCTM 可达性按 Σ_B(t) 膨胀
      所有硬门阈值 × (1/η_calib)，ECS × η_calib
```

## 4. 正确性论证（增量更新）

### 定理 13（标定可观测性 / 可辨识性）

**陈述**：眼在手上（eye-in-hand），靶标刚性固定于底盘 B。线性化 AX=XB 的平移块为
`(R_A_i − I) t_X = R_X t_B_i − t_A_i`，堆叠得 `G t_X = b`，`G = Σ_i (R_A_i − I)ᵀ(R_A_i − I)`。
则 X 局部可辨识当且仅当 `rank(G)=3`；等价地，相对运动至少包含两个旋转轴不平行的分量。
若靶标固定于世界系而底盘运动，则 B_i 含底盘运动、A_i 不含，AX=XB 被污染，X 在未增广 T_WB 时不可辨识。

**证明**：`G` 为半正定对称阵，`G t_X = b` 有唯一解当且仅当 `null(G)={0}`。当所有 R_A_i 绕同一轴 α 旋转时，`(R_A_i − I)` 的零空间含 α，故 `rank(G)≤2`，沿 α 的平移分量不可观测。至少两个非平行轴时，其零空间交集为 {0}，`rank(G)=3`。世界系靶标情形下 B_i 混入 T_W←B，与 A_i 不再满足同一 X，故残差无法唯一归因于 X。

### 定理 14（协方差传播下界 / 底盘漂移不可被标定抵消）

**陈述**：在左扰动下 `δ_WC = δ_WB + Ad(T_WB) δ_BE + Ad(T_WB T_BE) δ_EC`，故
`Σ_WC = Σ_WB + Ad(T_WB)Σ_BE Ad(T_WB)ᵀ + Ad(T_WB T_BE)Σ_EC Ad(T_WB T_BE)ᵀ`（独立时交叉项为零）。
于是 `λ_max(Σ_WC) ≥ λ_max(Ad(T_WB T_BE)Σ_EC Ad(T_WB T_BE)ᵀ)`，即底盘/正运动学不确定性只能增大、不能减小有效几何不确定性。

**证明**：三项均为半正定（合同变换保半正定），半正定矩阵之和的最大特征值不小于任一被加项的最大特征值。因此即使 Σ_EC 极小，Σ_WB 仍可主导 Σ_WC，标定无法在数学上抵消底盘漂移。

### 定理 15（Gate-0 的 fail-closed 单调性）

**陈述**：若 Gate-0 通过，则 `Exec_CADVS-v8 ⊆ Exec_CADVS-v7`；若 Gate-0 不通过，则 `Exec_CADVS-v8 = ∅`。
因此标定/底盘状态在任何情况下都不能扩大执行集。

**证明**：Gate-0 通过时 `d_eff = d − k·σ_max(Σ_WC) ≤ d`（可行集收缩）；`η_calib ≤ 1 ⇒ τ_i^v8 = τ_i^v7/η_calib ≥ τ_i^v7`（硬门更严）；`ECS_v8 = ECS_v7·η_calib ≤ ECS_v7`（排序不放宽）。三者叠加得执行集不扩张。Gate-0 不通过时 `select` 直接返回 `REFUSE_CALIBRATION`，执行集为空。**注意**：这与 v7 中 η≥1 的「放宽方向」相反，必须显式取倒数，否则会破坏 fail-closed。

### 诚实声明

- **可观测性以运动为代价**：Gate-0 需要足够激励。静止底盘 + 小幅机械臂运动时 ξ 会很低，Gate-0 会拒绝——这是安全但降低可用性的权衡，不能靠调低 ξ_min 来「提高成功率」。
- **协方差独立性假设**：传播公式假设 Σ_WB、Σ_BE、Σ_EC 独立；实际中正运动学误差与相机内参误差可能相关，忽略交叉项会**低估** Σ_WC。缓解：保守放大系数 k，并在离线用蒙特卡洛校验。
- **靶标安装的取舍**：靶标固定于底盘使手眼标定对底盘运动免疫，但 T_WB 的世界系可观测性仍需外部定位；靶标固定于世界系则相反。二者不可同时由同一数据集获得。
- **AX=XB 的局部性**：线性化与 Gauss-Newton 只保证局部收敛；大初值误差需 RANSAC/多初值，且退化数据可能收敛到「低残差、大协方差」的伪解——这正是必须同时检查 ξ 的原因。

## 5. 实验设计与验证计划（仿真 → 实机）

### 5.1 实验设计（MuJoCo 3.x + MJX + 实机）

- **平台**：UR10e（6DOF）+ 2DOF 差速移动底盘 + 眼在手上 RealSense D435i + AprilTag 36h11 标定靶。
- **标定数据**：
  - (a) 底盘固定、靶标固定于底盘，采集 20 组相对运动对（含 ≥2 个非平行旋转轴）；
  - (b) 退化对照：仅绕单轴旋转 20 组（应触发 `rank(G)≤2` → Gate-0 拒绝）；
  - (c) 底盘导航，注入 1% / 5% / 10% 里程计漂移；
  - (d) 对接场景（坞站 AprilTag）使 Σ_B 收紧；
  - (e) 靶标遮挡 30% 帧；
  - (f) 世界系靶标 + 运动底盘（验证 AX=XB 被污染，需增广 T_WB）。
- **消融**：A21 无 CFG（标定视为常量）、A22 仅残差门（无 ξ、无协方差）、A23 不传播协方差（只用 Σ_EC）、A24 关闭 Gate-0、A25 世界系靶标 + 动底盘。
- **指标**：
  - Gate-0 在注入漂移下的**假通过率**（核心安全指标）；

  - 任务成功率、拒绝率（可用性）、在线增量延迟。

## 7. 本轮最大风险（最终确认）

**一句话**：**标定可观测性的「静默失效」**——Gate-0 只能看见激励所张成的子空间；当底盘静止、机械臂小幅度运动、靶标被遮挡时，漂移的标定仍可能以低残差通过 Gate-0，在「错误几何」上产出「局部正确」的轨迹，而残差本身无法揭示这一失效。
