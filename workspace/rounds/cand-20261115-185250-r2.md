# 第 9 轮（灵感循环第 9 轮；本轮灵感：「材料选型」×「大语言模型」）
> **基线**：第 8 轮 MetricVoiceGauge-DA-SPR-Cal（定义 493–540；引理 77–81；实验 E531–E550）。
> 本轮纪律：**材料成为可观测状态 + 语言成为受约束的规格提议者**。两个灵感都必须以“可选增强”的方式接入，任一模块失效都平滑退回 v8；LLM 永远不直接获得写 `τ` / `w` / `sensor_weight` 的权限。

## 0. 直觉与动机

**灵感 1（材料选型 → 对象材料感知 + 末端执行器选型）**

直觉：v8 的抓取命令类型化（GCT）只解析了“抓什么、怎么抓”的**几何**，却把物体当成刚体、把接触面当成理想摩擦面。现实中同一条抓取轨迹作用在玻璃杯、番茄、钢块上，安全法向力区间、滑移裕度、可允许接触压强完全不同：低摩擦物体会滑落，易碎物体会被捏碎，可变形物体会在力控下发散。因此“材料”应当是指标体系中的**一阶可观测状态**，而不是隐含常量。

“材料选型”还有第二层含义：给定对象材料与任务，从候选夹爪/接触材料库中选一个最合适的末端执行器（软指 vs 硬指、橡胶 vs 金属、吸盘 vs 平行夹）。这天然是一个**带约束的离散优化 + 可行性证书**问题，而不是拍脑袋的经验规则。

于是本轮把材料拆成两条支线：
- **对象侧**：材料状态估计（刚度 E、摩擦 μ、密度 ρ、可变形度 δ、透明/反光度 α）及其不确定性；材料风险注入指标阈值与抓取力规划。
- **执行器侧**：材料选型优化器，在候选材料库上求最小代价可行解，并输出可验证的选型证书；无可行解时明确拒绝抓取。

**灵感 2（大语言模型 → 受约束的规格编译器）**

直觉：自然语言是最自然的任务接口——“把番茄轻轻放到篮子里，别捏碎”。LLM 擅长把这句话翻译成结构化的约束候选（材料假设、层级阈值、权重偏好），但它本质是随机近似：会幻觉、会漏掉否定词、会把单位搞错、会被提示注入。让 LLM 直接写控制参数，等于把安全关键系统交给一个不可形式化保证的预言机。

正确姿势是 **LLM-as-Proposer, Verifier-as-Judge**：
1. LLM 只输出**类型化约束 DSL**（候选 AST），不输出可执行控制量；
2. 确定性验证器做 schema / 单位 / 范围 / 硬层单调性 / 材料证据一致性检查；
3. 通过后做**安全投影**：硬约束层只允许“收紧或不变”，永远不允许放宽；
4. 提案有**信任域**与速率上限，且异步生成、缓存消费，不进入 50Hz 主环；
5. 每个被接纳的提案都带**溯源证书**（模型哈希、提示哈希、AST 哈希、验证器版本、证据引用），可审计、可回放。

**两者合流**：LLM 把“轻轻”“易碎”“别捏碎”翻译成材料假设与约束候选，材料估计器给出触觉/视觉/声学证据；当语言与证据冲突时**证据优先**，语言先验权重封顶。语言提供先验，材料提供证据，证书提供可审计性，指标层提供最终裁决。

## 1. 研究问题（轮次升级版）

- **Q1（材料状态可观测化）**：如何在 ≤2ms 感知预算内估计材料向量 `m=(E,μ,ρ,δ,α)` 及其协方差，并把材料风险单调、可逆地注入 v8 的阈值与抓取力规划？
- **Q2（材料选型可验证化）**：如何把末端执行器材料选型形式化为约束优化，并给出“可行/不可行”的证书，使无解时系统明确拒绝而非冒险抓取？
- **Q3（LLM 受约束接入）**：如何设计类型化 DSL 与确定性验证器，使 LLM 提案在硬约束层只能收紧、影响有界、失败关闭，并且不破坏 50Hz WCET？
- **Q4（语言-材料证据融合）**：当 LLM 的材料假设与传感器估计冲突时，如何用封顶的语言先验与证据优先规则得到可解释、可回滚的后验？

## 2. 设计原则（在 P7–P9 基础上升级为 P10–P12）

**P10 材料条件化阈值（Material-Conditioned Ladder, MCTL）**

材料状态不再隐含，而是显式进入阈值：

```
τᵢ(t) = clip( τᵢ^{v8}(t) + κᵢ^mat · h(m_t), ε_min,i, ε_max,i )
```

其中 `h(m_t) ∈ [0,1]` 为材料风险（滑移、压损、可变形不确定性），`κᵢ^mat ≥ 0` 为层级材料敏感度（M₀/M₁ 大，M₂/M₃ 小）。`h` 只增不减地“收紧”安全相关阈值，保证陌生材料优先保安全。

**P11 材料选型证书（Material Selection Certificate, MSC）**

候选末端执行器 `e ∈ E`，每个 `e` 有材料属性 `(E_e, μ_e, p_max_e, cost_e)`。选型问题：

```
e* = argmin_{e∈E}  cost_e + λ_d · risk_damage(e, m)
     s.t.          F_min(e, m) ≤ F_max(e, m)
                   payload(e) ≥ m_obj
```

若可行集为空，输出**不可行证书**并拒绝抓取，退化到 M₀ 的保守动作。选型结果不是一个数，而是“选谁 + 为什么可行 + 边界在哪”的证书。

**P12 LLM 约束编译器（Certified LLM Compiler, CLC）**

自然语言 → 类型化约束 DSL → 确定性验证 → 安全投影 → 缓存。LLM 的权限被严格限制为“提议”：

```
NL ──LLM──▶ AST ──Verifier──▶ {accept, amend, reject} ──Projection──▶ cached spec
```

硬约束层（M₀/M₁）的提案只允许 `τ' ≥ τ`（收紧），信任域 `‖Δτ‖∞ ≤ ε_trust`，速率 `≤ K` 次/`T` 秒；验证器对未识别 token、单位缺失、越界、证据冲突一律 fail-closed。LLM 异步运行（0.5–2Hz），主环只读取不可变缓存快照。

## 3. 与基线的接口（如何退化）

- 材料估计模块失效 ⇒ `m` 退回“刚性 + 保守摩擦下界”默认值，`h(m) ≡ h₀`，等价于 v8 的固定材料假设；
- 材料条件阈值失效 ⇒ `τᵢ` 退回 v8 的 DA-OTL 输出；
- 材料选型优化器失效或不可行 ⇒ 拒绝抓取 / 退回固定夹爪与 v8 GCT；
- LLM 编译器失效 / 超时 ⇒ 退回 v8 的规则解析器（GCT + VoiceCommandTyping）；
- 验证器失效 / 未知状态 ⇒ 全部 LLM 提案拒绝（fail-closed），继续用 v8 缓存；
- 语言-材料融合失效 ⇒ `γ=0`，纯证据后验，行为等价于 v8 + MPE；
- 全部失效 ⇒ 完整退回 MetricVoiceGauge-DA-SPR-Cal v8，再退回 v7/v6。

## 4. 预期贡献

1. **材料状态可观测化**：把对象材料与末端执行器材料都提升为指标体系的一等状态，提出材料条件化阈值与鲁棒抓取可行区间；
2. **可验证的材料选型**：把末端执行器选型形式化为带可行性证书的约束优化，无解时明确拒绝，避免“硬抓”；
3. **LLM 的安全接入范式**：LLM-as-Proposer + 确定性验证器 + 信任域 + 硬层单调投影 + 溯源证书，给出“语言可以提议、但不能放宽安全”的可证明边界；
4. **语言-材料证据融合**：封顶语言先验、证据优先的贝叶斯后验，使“轻轻”“易碎”等模糊语义落到可审计的材料参数上；
5. 完整闭环：**材料-语言-指标-动作-反馈**，实验 E551–E570 覆盖材料估计、选型、LLM 验证、对抗提示注入、实时性与五级退化。

## 5. 本轮最大风险

**一句话**：LLM 的语义先验与材料估计的不确定性在“提议-验证”接口处耦合——若验证器本身存在语义盲区（单位、否定、量词、比较方向），幻觉可能以“语法合法但语义错误”的约束通过，从而系统性地放宽材料条件阈值或让抓取力越过材料上限；本方案的最大风险是**验证器成为单点信任瓶颈**，把“LLM 不安全”悄悄转化为“验证器不完备”。

## 2. 形式化定义

**定义 541（材料状态 MaterialState）** 材料状态为带不确定性的随机向量：
```
m ~ N(μ_m, Σ_m),   μ_m = (E, μ_s, μ_k, ρ, δ, α) ∈ ℝ⁶
```
其中 `E` 为杨氏模量估计（Pa，对数尺度），`μ_s/μ_k` 静/动摩擦，`ρ` 密度，`δ∈[0,1]` 可变形度，`α∈[0,1]` 透明/反光度。估计器同时输出置信下界 `μ_LB` 与上界 `p_max`。

**定义 542（材料属性估计器 MaterialPropertyEstimator, MPE）** 多模态贝叶斯融合：
```
p(m | z_vis, z_tac, z_aud) ∝ p(z_vis|m) p(z_tac|m) p(z_aud|m) p₀(m)
```
- `z_vis`：材料分类头（ResNet-18 + 材质标签）给出的离散材料类先验；
- `z_tac`：轻触探测的力-位移曲线拟合 `F=K·x^β`，反解 `E`；
- `z_aud`：敲击声谱的共振峰，辅助判别刚度与空心结构。
后验均值进入 `m`，后验协方差进入 `Σ_m`；所有下游模块只使用置信下界/上界（鲁棒化）。

**定义 543（材料风险 MaterialRisk）** 标量化材料风险：
```
h(m) = σ( β_s·r_slip + β_d·r_damage + β_u·r_unc )
r_slip   = max(0, (μ_ref − μ_LB) / μ_ref)
r_damage = max(0, (p_req − p_max(m)) / p_req)
r_unc    = trace(Σ_m) / (trace(Σ_m) + σ₀²)
```
`σ(·)` 为 logistic，`μ_ref` 为任务参考摩擦，`p_req` 为标称所需压强。`h` 单调：摩擦越低、压强越接近上限、估计越不确定，风险越大。

**定义 544（材料条件化阈值 MaterialConditionedThreshold, MCTL）** 在 v8 DA-OTL 之上叠加材料项：
```
τᵢ(t) = clip( τᵢ^{v8}(t) + κᵢ^mat · h(m_t), ε_min,i, ε_max,i )
κ^mat = (1.0, 0.9, 0.3, 0.2, 0.4, 0.4, 0.8)   # 对应 M₀…M_SLAM,M_mat
```
材料项**只收紧安全相关层**（`κ₀^mat, κ₁^mat, κ_mat^mat` 最大），效率/完善层敏感度低，避免材料不确定导致过度保守。

**定义 545（鲁棒抓取可行区间 RobustGraspFeasibility）** 给定切向载荷 `F_t`、安全系数 `ε_g`：
```
F_min(m) = F_t · (1 + ε_g) / μ_LB
F_max(m) = p_max(m) · A_contact
可行 ⇔ F_min(m) ≤ F_max(m)
```
选力规则：`F_n* = argmin_{F∈[F_min,F_max]} damage(F;m)`，默认取区间几何中心；若可行集为空 ⇒ `REJECT_GRASP`，触发 M₀ 保守动作（放下/换夹爪/求援），绝不“硬捏”。

**定义 546（末端执行器材料选型 MaterialSelectionProblem）** 候选库 `E`，每个 `e` 有 `(E_e, μ_e, p_max_e, payload_e, cost_e)`：
```
e* = argmin_{e∈E}  cost_e + λ_d · risk_damage(e, m)
     s.t.          F_min(e,m) ≤ F_max(e,m)
                   payload_e ≥ m_obj·g
                   compatibility(e, m) = 1
```
`compatibility` 编码硬性禁忌（如金属指不得抓取高反光易碎品）。离散规模 `|E| ≤ 32`，可在线枚举 + 剪枝。

**定义 547（材料选型证书 MaterialSelectionCertificate）** 选型输出为四元组：
```
cert_mat(e) = (e*, F_min*, F_max*, witness)
witness = {约束编号, 实际值, 边界值, 证据哈希}
```
不可行时输出 `cert_mat = (∅, ⊥, ⊥, infeasibility_witness)`，其中见证指出是哪条约束（摩擦/压强/载荷/兼容）导致无解。

**定义 548（约束 DSL 语法 ConstraintDSL）** LLM 只允许输出如下类型化 AST：
```
spec      ::= stmt*
stmt      ::= LAYER <id∈0..6> <op∈{<=,>=,within}> <value> <unit>
            | MATERIAL <obj> <prop∈{E,mu,rho,delta,alpha}> <dist>
            | WEIGHT <layer> <delta∈[−1,1]>
            | CONSTRAINT <id> <expr>
```
所有 `<unit>` 必须属于白名单（`Pa, N, m, 1, kg/m^3, ratio`）；`MATERIAL` 语句只产生**先验假设**，不直接改状态；`WEIGHT` 只产生候选增量。

**定义 549（信任域提案 TrustRegionProposal）** 提案 `p=(Δτ, Δw)` 合法当且仅当：
```
‖Δτ‖∞ ≤ ε_trust,   ‖Δw‖₁ ≤ δ_trust,   |p| ≤ K 次 / T 秒
```
超出信任域的提案由 TRP 投影而非直接采纳：
```
π(p) = argmin_{q∈TrustRegion} ‖q − p‖₂
```

**定义 550（确定性约束验证器 CertifiedConstraintVerifier, CCV）** 验证器是纯函数，返回三值判定：
```
V: AST → {accept, amend, reject} × Cert
```
检查顺序（fail-closed）：
1. **Schema**：token/AST 是否属于定义 548 的文法；未知 token ⇒ reject；
2. **单位**：量纲是否匹配白名单；缺失或歧义 ⇒ reject；
3. **范围**：`τ ∈ [ε_min, ε_max]`、`w ∈ Δ`；越界 ⇒ amend（clip）或 reject；
4. **硬层单调性**：对 `i∈{0,1,6}`，要求 `τ_i' ≥ τ_i`（只收紧）；若 `Δτ_i < 0` ⇒ reject（不可 amend 后放行）；
5. **跨层一致性**：M₀ 激活时不得放宽 M₁/M₂；`M_mat` 风险高时不得放宽效率层；
6. **证据一致性**：`MATERIAL` 声明若落在 MPE 后验 `±3σ` 之外 ⇒ amend（按证据收缩 `γ`），严重冲突 ⇒ reject；
7. **依赖完整性**：每个 `WEIGHT` 必须引用已定义层；悬空引用 ⇒ reject。

**定义 551（安全投影 SafetyProjection）** 对 `accept/amend` 结果：
```
π(τ)_i = τ_i                       if i ∈ {0,1,6}  # 硬层：不采纳任何放宽
π(τ)_i = clip(τ_i + Δτ_i, …)      otherwise
π(w)   = softmax(α·risk + β·emo·Ṽ + η_llm·Δw)
```
其中 `η_llm ∈ [0, 0.2]` 限制语言对权重的最大影响。

**定义 552（溯源证书 ProvenanceCertificate）** 每个被采纳规格附带：
```
cert_prov = (hash(model), hash(prompt), hash(AST), verifier_version,
             verdict, evidence_refs, timestamp, signer)
```
写入只追加日志，任何控制路径不得读取 `cert_prov` 作为输入（防止证书被污染为控制信号）。

**定义 553（语言-材料证据融合 LanguageMaterialGrounding）** 语言只作为**封顶先验**：
```
p(m | z, text) ∝ p(z | m) · p(m | text)^γ,   γ ∈ [0, 0.5]
```
`γ` 由验证器根据“文本是否含明确材质词 + 与视觉类别是否一致”动态给出；不一致时 `γ→0`，即证据优先。此式保证文本永远不能推翻强证据（引理 86）。

**定义 554（材料条件化触发 MaterialConditionedTrigger）** 在 v8 `δ_trigger` 上扩展：
```
δ_trigger = {σ < τ_safe ∧ γ_grasp valid ∧ Δ_dom < τ_dom
             ∧ risk_SLAM < τ_SLAM ∧ r_mat < τ_mat ∧ spec_valid}
```
任一条件违背 ⇒ 退到 M₀；`spec_valid = (V(AST)=accept|amend) ∧ (now − t_spec < spec_ttl)`。

**定义 555（缓存规格消费 CachedSpecConsumption）** 主环读取不可变快照 `spec_t = (τ^{spec}, w^{spec}, cert_prov)`；LLM 线程只写新快照（原子替换）。若 `spec_ttl` 超时或验证器不可用，主环使用 v8 规则解析结果。主环从不阻塞等待 LLM。

**定义 556（材料选型-抓取联合拒绝 JointRefusal）** 若 `cert_mat=∅` 或 `F_min>F_max` 或 `r_mat ≥ τ_mat`，则：
```
action = REFUSE_GRASP → {open_hand, retreat, request_human, switch_gripper}
```
拒绝是**显式动作**而非静默失败，记入证书链，供事后审计。

**定义 557（LLM 提案预算 ProposalBudget）** 每次任务至多 `K_task` 次 LLM 调用，单次超时 `T_llm`；超预算或超时 ⇒ 冻结当前规格，记录 `budget_exhausted`，不降级安全。

**定义 558（材料漂移监测 MaterialDriftMonitor）** 长时运行中 `m` 的后验漂移：
```
Δ_mat(t) = ‖μ_m(t) − μ_m(t−W)‖_{Σ_m^{-1}}
```
超过 `τ_mat_drift` ⇒ 触发重新探测（轻触/敲击），不直接改阈值，避免一次性误估导致阈值跳变。

**定义 559（六维风险向量 SixDimRisk）** v8 的 5 维风险扩展为：
```
risk(s) = [risk_SEN, risk_SEM, risk_EFF, risk_PERF, risk_SLAM, risk_mat] ∈ ℝ⁶
risk_mat = λ_slip·r_slip + λ_damage·r_damage + λ_unc·r_unc
```
MetaWeight / ER 的 softmax 维度同步升到 6，保持凸组合与可逆性。

**定义 560（系统标识 SystemIdentity）** 完整系统与各级退化基线：
```
Φ_MatLC = {τᵢ^{v8}+κ^mat·h(m), risk 6-dim, mpe, eems, llm→AST→CCV→π, provenance}
Φ_v8    = {τᵢ^{v8},             risk 5-dim, material≡m₀, rule-parser}
```

# IP-453 MaterialPropertyEstimator：多模态材料估计（感知侧 ≤ 2ms）
class MaterialPropertyEstimator:
    def __init__(self, vis_head, tactile_model, audio_model, prior, sigma0=0.1):
        self.vis_head = vis_head            # 冻结材料分类头
        self.tactile_model = tactile_model  # F=K*x^beta 拟合
        self.audio_model = audio_model      # 敲击声谱特征
        self.prior = prior                  # p0(m)
        self.sigma0 = sigma0
        self.post_mean = prior.mean.copy()
        self.post_cov = prior.cov.copy()

    def update(self, z_vis=None, z_tac=None, z_aud=None):
        # 每个模态给出 (mean, cov)，按精度加权融合（信息滤波形式）
        infos, means = [], []
        if z_vis is not None:
            mu_v, S_v = self.vis_head(z_vis)
            infos.append(np.linalg.inv(S_v)); means.append(S_v @ mu_v)
        if z_tac is not None:
            mu_t, S_t = self.tactile_model.fit(z_tac)   # 力-位移反解 E, mu
            infos.append(np.linalg.inv(S_t)); means.append(S_t @ mu_t)
        if z_aud is not None:
            mu_a, S_a = self.audio_model(z_aud)
            infos.append(np.linalg.inv(S_a)); means.append(S_a @ mu_a)
        if not infos:
            return self.post_mean
        S0_inv = np.linalg.inv(self.prior.cov)
        S_post_inv = S0_inv + sum(infos)
        self.post_cov = np.linalg.inv(S_post_inv)
        self.post_mean = self.post_cov @ (S0_inv @ self.prior.mean + sum(means))
        return self.post_mean

    def robust_bounds(self, z=1.645):
        # 摩擦置信下界、压强上限（用于鲁棒抓取）
        i_mu, i_p = 1, 2
        mu_lb = self.post_mean[i_mu] - z * np.sqrt(self.post_cov[i_mu, i_mu])
        p_max = self.prior.p_max_fn(self.post_mean)
        return max(0.0, mu_lb), p_max

    def uncertainty(self):
        return float(np.trace(self.post_cov))


# IP-454 MaterialConditionedLadder：材料项注入阈值
class MaterialConditionedLadder:
    def __init__(self, kappa_mat=(1.0, 0.9, 0.3, 0.2, 0.4, 0.4, 0.8),
                 beta=(1.0, 1.0, 0.5), mu_ref=0.5, p_req=1.0):
        self.kappa_mat = np.array(kappa_mat)
        self.beta = beta
        self.mu_ref = mu_ref
        self.p_req = p_req

    def material_risk(self, m, mu_lb, p_max, trace_cov, sigma0=0.1):
        r_slip = max(0.0, (self.mu_ref - mu_lb) / self.mu_ref)
        r_damage = max(0.0, (self.p_req - p_max) / self.p_req)
        r_unc = trace_cov / (trace_cov + sigma0**2)
        z = self.beta[0]*r_slip + self.beta[1]*r_damage + self.beta[2]*r_unc
        return 1.0 / (1.0 + np.exp(-z)), (r_slip, r_damage, r_unc)

    def apply(self, tau_v8, h, eps_min, eps_max):
        return {i: float(np.clip(tau_v8[i] + self.kappa_mat[i] * h,
                                 eps_min[i], eps_max[i]))
                for i in range(7)}


# IP-455 MaterialAwareGraspPlanner：鲁棒可行力区间
class MaterialAwareGraspPlanner:
    def __init__(self, eps_grasp=0.1):
        self.eps_grasp = eps_grasp

    def feasible_interval(self, F_t, mu_lb, p_max, A_contact):
        if mu_lb <= 1e-6:
            return None
        F_min = F_t * (1.0 + self.eps_grasp) / mu_lb
        F_max = p_max * A_contact
        if F_min > F_max:
            return None
        return (F_min, F_max)

    def plan(self, F_t, mu_lb, p_max, A_contact, damage_fn=None):
        interval = self.feasible_interval(F_t, mu_lb, p_max, A_contact)
        if interval is None:
            return {'action': 'REFUSE_GRASP', 'reason': 'empty_force_interval'}
        F_min, F_max = interval
        if damage_fn is None:
            F_n = 0.5 * (F_min + F_max)
        else:
            grid = np.linspace(F_min, F_max, 32)
            F_n = float(grid[np.argmin([damage_fn(f) for f in grid])])
        return {'action': 'GRASP', 'F_n': F_n,
                'F_min': F_min, 'F_max': F_max,
                'slip_margin': (mu_lb * F_n - F_t) / max(F_t, 1e-9)}


# IP-456 EndEffectorMaterialSelector：材料选型 + 证书
class EndEffectorMaterialSelector:
    def __init__(self, library, lam_damage=0.3):
        self.library = library          # [{name, E, mu, p_max, payload, cost, compat}]
        self.lam_damage = lam_damage

    def select(self, m, m_obj, F_t, A_contact, compatibility_fn):
        feasible = []
        witness_infeasible = []
        for e in self.library:
            if e['payload'] < m_obj * 9.81:
                witness_infeasible.append((e['name'], 'payload'))
                continue
            if not compatibility_fn(e, m):
                witness_infeasible.append((e['name'], 'compatibility'))
                continue
            mu_lb = e['mu'] * 0.9           # 材料选型阶段保守折扣
            planner = MaterialAwareGraspPlanner()
            interval = planner.feasible_interval(F_t, mu_lb, e['p_max'], A_contact)
            if interval is None:
                witness_infeasible.append((e['name'], 'force_interval'))
                continue
            risk_damage = max(0.0, (1.0 - e['E'] / (e['E'] + m['E'] + 1e-9)))
            cost = e['cost'] + self.lam_damage * risk_damage
            feasible.append((cost, e, interval))
        if not feasible:
            return {'e': None, 'cert': {'feasible': False,
                                        'witness': witness_infeasible}}
        cost, e, (F_min, F_max) = min(feasible, key=lambda x: x[0])
        return {'e': e, 'cert': {'feasible': True, 'F_min': F_min,
                                 'F_max': F_max, 'cost': cost,
                                 'witness': ('force_interval', F_min, F_max)}}


# 定义 548：DSL 解析（只接受白名单 token）
ALLOWED_LAYERS = set(range(7))
ALLOWED_OPS = {'<=', '>=', 'within'}
ALLOWED_UNITS = {'Pa', 'N', 'm', '1', 'kg/m^3', 'ratio'}
MATERIAL_PROPS = {'E', 'mu', 'rho', 'delta', 'alpha'}


def parse_ast(text):
    ast = []
    for raw in text.strip().splitlines():
        tok = raw.strip().split()
        if not tok:
            continue
        head = tok[0]
        if head == 'LAYER' and len(tok) == 5:
            layer, op, val, unit = int(tok[1]), tok[2], float(tok[3]), tok[4]
            if layer not in ALLOWED_LAYERS or op not in ALLOWED_OPS \
               or unit not in ALLOWED_UNITS:
                raise ValueError(f'unknown layer/op/unit: {raw}')
            ast.append(('LAYER', layer, op, val, unit))
        elif head == 'MATERIAL' and len(tok) == 4:
            if tok[2] not in MATERIAL_PROPS:
                raise ValueError(f'unknown material prop: {raw}')
            ast.append(('MATERIAL', tok[1], tok[2], tok[3]))
        elif head == 'WEIGHT' and len(tok) == 3:
            ast.append(('WEIGHT', int(tok[1]), float(tok[2])))
        elif head == 'CONSTRAINT':
            ast.append(('CONSTRAINT', raw))
        else:
            raise ValueError(f'unrecognized statement: {raw}')
    return ast


# IP-459 CCV：确定性验证器（fail-closed）
class CertifiedConstraintVerifier:
    def __init__(self, eps_min, eps_max, eps_trust=0.05, delta_trust=0.2,
                 allowed_spec_ttl=2.0):
        self.eps_min, self.eps_max = eps_min, eps_max
        self.eps_trust, self.delta_trust = eps_trust, delta_trust
        self.spec_ttl = allowed_spec_ttl

    def verify(self, ast, tau_cur, w_cur, mpe, gamma=0.0):
        verdict, reasons, dtau, dw = 'accept', [], {}, {}
        for st in ast:
            if st[0] == 'LAYER':
                _, i, op, val, unit = st
                if unit not in ALLOWED_UNITS:          # 1. schema/unit
                    return 'reject', ['bad_unit'], None, None
                target = val
                if target < self.eps_min[i] or target > self.eps_max[i]:
                    target = float(np.clip(target, self.eps_min[i], self.eps_max[i]))
                    verdict, _ = 'amend', reasons.append(f'clip_layer_{i}')
                d = target - tau_cur[i]
                if i in (0, 1, 6) and d < -1e-9:        # 4. 硬层只收紧
                    return 'reject', [f'loosen_hard_layer_{i}'], None, None
                if abs(d) > self.eps_trust:             # 5. 信任域
                    d = float(np.sign(d) * self.eps_trust)
                    verdict, _ = 'amend', reasons.append(f'trust_clip_{i}')
                dtau[i] = d
            elif st[0] == 'WEIGHT':
                _, i, delta = st
                if abs(delta) > self.delta_trust:
                    delta = float(np.sign(delta) * self.delta_trust)
                    verdict, _ = 'amend', reasons.append(f'trust_clip_w{i}')
                dw[i] = delta
            elif st[0] == 'MATERIAL':
                _, obj, prop, val = st
                if not mpe.consistent(prop, float(val), sigma=3.0):
                    if gamma > 0.5:                     # 证据优先
                        return 'reject', [f'conflict_{prop}'], None, None
                    verdict, _ = 'amend', reasons.append(f'shrink_gamma_{prop}')
        return verdict, reasons, dtau, dw


# IP-461 LMG：语言先验封顶 + 证据优先
class LanguageMaterialGrounding:
    def __init__(self, gamma_max=0.5):
        self.gamma_max = gamma_max

    def posterior(self, mpe, text_prior, has_explicit_material_word, visual_agree):
        gamma = self.gamma_max if (has_explicit_material_word and visual_agree) \
                else (0.25 if has_explicit_material_word else 0.0)
        # 在 log 空间做封顶先验修正，强证据下 gamma 影响可忽略
        log_post = np.log(mpe.post_mean + 1e-9) + gamma * np.log(text_prior + 1e-9)
        return np.exp(log_post) / np.exp(log_post).sum(), gamma


# IP-446 主闭环集成片段：MetricVoiceGauge-MatLC
def metricvoicegauge_round_9(M, s, obs, audio_stream=None, ell=None,
                             mpe=None, mctl=None, magp=None, selector=None,
                             spec_cache=None, ccv=None, trp=None,
                             online_learner=None, emotional_reweighter=None,
                             domain_adapter=None, slam_risk=None, calib_fi=None):
    """50Hz WCET 保全；LLM 仅消费缓存快照，新增材料侧预算 ≤1ms"""

    # --- 0. 读取缓存规格（原子快照，永不阻塞）---
    spec = spec_cache.get() if spec_cache is not None else None
    spec_valid = spec is not None and spec.is_fresh()
    tau_spec = spec.tau if spec_valid else None

    # --- 1. 材料估计（感知侧 ≤1ms，与 SLAM 读取并行）---
    m, h, r_mat = None, 0.0, 0.0
    if mpe is not None:
        m = mpe.update(obs.get('vis'), obs.get('tac'), obs.get('aud'))
        mu_lb, p_max = mpe.robust_bounds()
        h, (r_slip, r_damage, r_unc) = mctl.material_risk(
            m, mu_lb, p_max, mpe.uncertainty())
        r_mat = r_slip + r_damage + r_unc

    # --- 2. v8 继承：域自适应阈值 + 在线学习 ---
    if domain_adapter is not None and online_learner is not None:
        delta_dom = domain_adapter.update_and_shift(obs)
        online_learner.update_domain_shift(delta_dom)
    tau_v8 = online_learner.get_thresholds() if online_learner \
             else M.metric_ladder.thresholds

    # --- 3. 材料条件化阈值（MCTL），LLM 规格仅在信任域内叠加 ---
    tau = mctl.apply(tau_v8, h, M.eps_min, M.eps_max) if mctl is not None else tau_v8
    if spec_valid:
        tau = trp.project_layers(tau, spec.dtau, hard_only=True)

    # --- 4. 抓取规划 + 选型（材料感知）---
    grasp = None
    if m is not None and magp is not None:
        F_t = obs.get('tangential_load', 0.0)
        mu_lb, p_max = mpe.robust_bounds()
        grasp = magp.plan(F_t, mu_lb, p_max, obs.get('A_contact', 1e-4))
        if grasp['action'] == 'REFUSE_GRASP':
            return M.refuse_and_certify(s, 'material_infeasible', grasp)

    # --- 5. 语音/LLM 规格：规则解析兜底 ---
    iota_seq = [M.default_iota]
    if audio_stream is not None:
        if spec_valid:
            iota_seq = [spec.iota]          # 已验证的语义规格
        elif M.grasp_typing is not None:
            iota_voice, ok, _ = M.grasp_typing.process(audio_stream)
            iota_seq = [iota_voice] if ok else [M.default_iota]

    # --- 6. 六维风险 + 情感/元权重 ---
    base_risk_5d = M.reward_decomposer._compute_risk(M.env.state)
    risk_6d = np.array([*base_risk_5d, r_mat])
    emo = 0.0
    V_vec = np.array([0.3, 0.4, 0.2, 0.1, 0.1, 0.1])
    if emotional_reweighter is not None and audio_stream is not None:
        emo = emotional_reweighter.extract_emotion(obs.get('audio_feats', {}),
                                                   obs.get('text_sentiment', {}))
    w = emotional_reweighter.compute_emotional_weights(risk_6d, emo, V_vec) \
        if emotional_reweighter is not None else M.reward_decomposer.w_6d(risk_6d)
    if spec_valid:
        w = trp.project_weights(w, spec.dw, eta_llm=0.2)

    # --- 7. 继承 v8 核心流程：Hypothesis → IAC → RT-CVC → 七层监控
    #       → SpatialCert → FaultCert → δ_trigger（含 r_mat/ spec_valid）
    #       → 奖励 → 软校准 σ_R → ROS 证书发布
    C, spatial_cert, claims, metrics, rewards = M.metricvoicegauge_round_8(
        M, s, obs, audio_stream, ell=ell)
    metrics['material'] = {'m': m, 'h': h, 'r_mat': r_mat,
                           'tau': tau, 'spec_valid': spec_valid}
    rewards = M.apply_weights(rewards, w)
    return C, spatial_cert, claims, metrics, rewards

## 4. 推导

**引理 82（材料项单调收紧）** `h(m) ≥ 0`、`κᵢ^mat ≥ 0`，故定义 544 的材料项 `κᵢ^mat·h(m) ≥ 0`；clip 单调不减，故 `τᵢ(t) ≥ τᵢ^{v8}(t)` 对全部 i 成立，且材料不确定性增大（`trace(Σ_m)↑`）时 `h↑`，安全层阈值只会更严。**证明**：逐项由非负性与 clip 的单调性直接得到。∎

**引理 83（鲁棒抓取可行性）** 若 `F_min = F_t(1+ε_g)/μ_LB ≤ F_max = p_max·A_contact`，则对任意真实摩擦 `μ ≥ μ_LB` 与任意真实压强上限 `p ≥ p_max`，存在 `F_n ∈ [F_min,F_max]` 同时满足不滑移 `μF_n ≥ F_t(1+ε_g)` 与不压损 `F_n/A ≤ p`。**证明**：取 `F_n=F_min`，则 `μF_n ≥ μ_LB F_n = F_t(1+ε_g)`；又 `F_n=F_min ≤ F_max = p_max A ≤ pA`，两约束同时满足。∎ 该引理把“材料估计的置信下界”转化为“力控的确定性保证”。

**引理 84（选型证书可靠性）** 若 `cert_mat(e*)` 可行，则 `e*` 满足载荷、兼容、力区间三条约束；若 `cert_mat=∅`，则不存在任何 `e∈E` 同时满足三约束。**证明**：selector 枚举全库并对每条约束显式检查，可行集为空当且仅当所有候选至少违反一条；见证列表覆盖全部候选。∎ 证书的“不可行”分支与“可行”分支互斥且穷尽（在给定 `E` 与 `compatibility` 下）。

**引理 85（验证器 fail-closed 安全性）** 对任意 AST，若 CCV 返回 `accept` 或 `amend`，则安全层 `i∈{0,1,6}` 满足 `τ_i' ≥ τ_i`；若返回 `reject`，投影不产生任何变更（规格保持 v8）。**证明**：第 4 步显式拒绝任何 `Δτ_i<0`；amend 只做 clip 与信任域收缩，均不改变符号方向；reject 分支直接丢弃提案。∎ 注意该引理只保证“不放宽”，不保证“语义正确”——这是本轮风险的来源。

**引理 86（语言先验影响有界）** 对任意文本先验与证据，`γ≤0.5` 且 `η_llm≤0.2`，故 `‖τ^{MatLC}−τ^{v8}‖∞ ≤ ε_trust + κ_max·h_max`，`‖w^{MatLC}−w^{v8}‖₁ ≤ η_llm·δ_trust / Z`（Z 为 softmax 归一化常数）。**证明**：阈值侧由引理 82（材料项有界）与 TRP 的信任域投影直接相加；权重侧由 softmax 的 Lipschitz 性与 `η_llm` 封顶得到。∎ 即语言最多带来有界扰动，不会造成阈值/权重的数量级跳变。

**引理 87（五级退化正确性）** 任意单模块失效均可退回对应 v8 子集；任意组合失效互不级联；全失效等价于 v8。**证明**：各模块接口正交——MPE 只写 `m`，MCTL 只写材料项，EEMS 只写选型证书，LCC 只写候选 AST，CCV/TRP 只写已验证规格；每条退化路径把对应写入置为恒等（`h=0`/`γ=0`/`spec_valid=false`/`reject`），其余模块不受影响。∎

**引理 88（异步隔离与 WCET 保全）** LLM 调用、解析、验证全部在独立线程；主环只做 O(1) 快照读取与 O(|AST|) 投影（`|AST|≤16`），故主环新增开销 ≤ 1ms，与 LLM 延迟无关。**证明**：主环执行路径不含任何锁等待或远程调用；快照为原子指针替换；超时由 `spec_ttl` 在主环外判定。∎

**引理 89（证据优先的可回滚性）** 当语言与证据冲突（`MATERIAL` 声明落在 MPE `±3σ` 外且 `γ>0.5`）时 CCV 返回 reject，`γ` 实际取值被钳到 0，后验不更新；否则后验只做 `γ`-加权修正。故任何语言修正都可在下一周期被证据覆盖，且不改变已发生动作的安全证书。**证明**：由定义 553 的封顶先验与定义 550 的第 6 步检查直接得到；证书只追加不修改。∎

## 8. 本轮最大风险

**一句话**：LLM 的语义先验与材料估计的不确定性在“提议-验证”接口处耦合——若验证器存在语义盲区（单位、否定、量词、比较方向），幻觉可能以“语法合法但语义错误”的约束通过，从而系统性放宽材料条件阈值或让抓取力越过材料上限；**本方案的最大风险是验证器成为单点信任瓶颈，把“LLM 不安全”悄悄转化为“验证器不完备”**。
