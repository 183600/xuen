# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环第 3 轮；本轮灵感：「通用操作」×「机器人」）

> R69 教会机器人问「我该向谁求证、还能问什么」，但它默认了一个从未被质疑的单位：**一个任务、一个技能、一个本体**。R69 的证书 J_FLUID 是一张「单片证书」——在某个技能、某个分布、某个本体上标定出来的安全承诺。
>
> 「通用操作」把这个单位击穿了。通用不是「一个更大的技能」，而是**技能、物体、本体、人类之间的组合闭合性**：今天抓杯、明天开门、后天把工具递给另一个人，甚至把别人训练的技能装进自己的技能库。一个通用机器人不是一块更大的瓷砖，而是一幅**马赛克**；而马赛克最脆弱的地方从来不是瓷砖本身，是**缝**。
>
> 「机器人」则提醒我们缝是物理的：A 以为「已抓稳」而 B 假设「已释放」，A 用工具坐标系而 B 用基座坐标系，A 报弧度而 B 读角度，A 的「杯子」在 B 那里是「瓶子」，A 的信念已经过期，两个技能同时争同一份力预算——**每个技能单独测试都通过，接缝处却掉东西。** R68 校准了传感器，R69 校准了任务内的模态与含义；R70 必须校准**模块与模块之间的接口含义**：当技能 A 把世界交给技能 B 时，它们说的「抓稳」「这里」「现在」「安全」是同一件事吗？
>
> 核心命题：**把通用操作写成带类型的技能程序；把「缝契约」与「适配器」提升为一等公民；新增第三类不确定性 U_int（接口不确定性）与接口校准；新技能必须在「邻居测试」中准入；运行时用受盾解释器 + 风险账本只执行「良型、已校准、落在包络内」的程序。** 命名 **SEAM-RAS**（Safety of Emergent Assembly of Modules — a Risk-Adaptive System）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我的技能交接时说的是同一种语言吗？我宣称的通用性，是被证明的，还是只是名义上的？**」

## 0. 直觉与动机

**灵感 1（通用操作 = 程序，不是单体）**
直觉：一个覆盖所有操作的单一策略，要么做不出来，要么无法验证。人的通用能力是组合出来的：抓、放、开、倒、递。通用性 = **从可复用技能中构造并执行新程序的能力**。因此基础模型与机器人之间正确的接口不是原始力矩，而是一个**带类型的技能程序**：它可检查、可复用、可审计。端到端大策略像一台「没有类型系统的编译器」——它可能经常对，但对一个新的组合，它没有任何可证明的东西。
形式化：`p ::= ε | s | seq(p1,p2) | par(p1,p2) | if(β,p1,p2) | while_κ(β,p) | try(p1,p2) | adapt(α,p)`；语义是状态关系，叶子是带契约的技能。

**灵感 2（安全住在缝里）**
直觉：最典型的事故不是某个技能内部算错，而是交接：A 松手早于 B 抓牢；A 用工具坐标系、B 假设基座系；A 报弧度、B 按角度解释；A 的「杯子」是 B 的「瓶子」；A 的信念是 200ms 前的；两个技能同时消耗同一份力/时间/注意力预算。每个技能在自己的测试集上都是对的，**接缝处却失败**。R68/R69 认证了技能的「内部」，没有人认证「边界」。通用系统里最危险的部件，往往就是那层最没人测试的胶水代码。
形式化：缝 `e=(V_e,R_e,α_e,κ_e,δ_e)`；未声明的依赖默认拒绝；缝义务 = 后置/适配/前置、不变式相容、帧不干扰、资源求和、接口校准。

**灵感 3（接口不确定性是第三类不确定性）**
直觉：R69 的 U_ale 是噪声，U_epi 是对世界的歧义。U_int 不同：**两个模块都很自信，但它们的表示并不指称同一件事**。在一个模块内部多采样修不好它；只有共享指称物、跨模块探针、适配器校准才能修。它是 R68 传感器标定的「语义版」——校准的不是测量，而是**含义**。更糟的是，错配的适配器是**静默**的安全洞：两边都看到高置信度。
形式化：接口隐变量 `h_s`、适配器 `α`、`U_int=H(align|D_probe)`、`ECE_int`；ICG 门控。

**灵感 4（通用性有认证税；要标准化接口）**
直觉：如果每个新技能都要和每个邻居测一遍，认证成本随技能库增长；「技能动物园」不是可认证的通用。出路不是更多技能，而是**更少、共享的接口**：一个小而通用的端口/类型/适配器代数，让缝证据被摊销。**可认证的通用性由接口标准化程度决定，而不是由名义技能数量决定。** 系：一个有 1000 个定制技能的系统，可能比一个有 20 个技能、5 个通用接口的系统**更不通用**——因为后者的组合是被证明过的。
形式化：准入邻居测试每个新技能 Ω(n)；共享接口数 m 时摊还 O(m)；定理 19。

**灵感 5（扩大包络是不可逆的元信息动作）**
直觉：R69 的信息动作是物理的（看/问/触）。准入一个新技能、扩展 ODD，是**元**信息动作：它的成本是未来风险，而且一个坏技能一旦行动过，就无法「取消准入」。所以扩展需要隔离、回滚、人类授权、预留预算——**绝不能动用回退储备**。这是 R69 的 VoI 升了一级：**能力包络本身是一个认识论对象，扩大它是一次有风险的动作。**
形式化：`EXPAND(s_new)` 的元 IVoI、准入债务、回滚。

**灵感 6（契约 vs 意图；为什么这很危险）**
直觉：类型系统证明程序满足**契约**，不证明它满足**意图**。在开放世界里，契约必须在任务未知之前写下，因此它在结构上就是欠定的。一个通用机器人可以「可证明地满足契约」却做错事；一个学习来的或对抗性的技能可以精确利用契约的洞。通用性加上一张契约，是一个**过度自信放大器**——除非缺口被审计、且系统有权拒绝。这引出默认拒绝、人类签署、红队与「纯契约监控无法保证意图」的定理。
形式化：意图 `ψ*`、契约 `φ`、缺口 `G=ψ*\φ`；缝利用；审计；定理 20。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（SEAM-RAS 总览）** SEAM-RAS = (SPL, SCT, SEA, ADM, ENV, GPP, ICG, LED, RSM, VQAuditor-S, RAS-WM†)。六条不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；组合层运行在任务/交接频率（10–100Hz），不进入 kHz 内环，内环仍由 R68/R69 的叶子控制器负责；
(ii) **组合权威**：只有良型技能程序可执行；基础模型的原始底层动作不得绕开内核；
(iii) **缝诚实**：证书只覆盖技能「已声明的缝」；任何被下游读取、却未被上游写入或声明为接口的变量，默认拒绝（default-deny）；
(iv) **接口校准**：缝在使用前必须通过接口校准门；未校准 ⇒ 只能使用刚性/恒等适配器，或拒绝组合；
(v) **证据纪律**（继承 R69 定义 293-iii）：单次测试/单源证据不得给缝定案，缝证据需正交来源；
(vi) **预算守恒**：残余风险预算在组合中单调不增，交接不清零；回退储备 `B_fb` 不得被准入或扩展挪用。

**定义 311（技能程序 / 通用操作）** 技能 `s(θ)` 带参数 `θ`；程序文法见灵感 1。语义 `⟦p⟧ ⊆ 𝒮×𝒮`，`⟦ε⟧=Id`，`⟦seq(p1,p2)⟧=⟦p2⟧∘⟦p1⟧`，`⟦par⟧` 为交错或并行积，`⟦try(p1,p2)⟧=⟦p1⟧ ∪ ⟦p2⟧`（p2 仅在前者失败时触发）。**定义：本体系下的「通用操作」就是任一良型程序 p；通用性是一个关于程序集合的性质，不是关于单个策略的性质。**

**定义 312（技能契约）** `s = (Pre_s, Post_s, Inv_s, Frm_s, Res_s, Cert_s, Env_s)`：
- `Pre_s, Post_s, Inv_s`：状态+上下文上的谓词；`Inv_s` 是安全不变式（不落地、不越力、不撞人、不越界）；
- `Frm_s=(R_s,W_s)`：读/写变量集（分离逻辑式帧条件）；技能只能改 `W_s`、只读 `R_s`；
- `Res_s ∈ ℝ_+^6`：时间/能量/力/空间/注意力/通信预算；
- `Cert_s`：叶子证书（J_CALM / J_FLUID 或其组合）；
- `Env_s`：能力包络（定义 317）。
**契约可靠性**：对任意 `(x,y)∈⟦s⟧`，若 `x⊨Pre_s ∧ x∈Env_s`，则 `y⊨Post_s ∧ Inv_s`、`W_s` 之外不变、资源 ≤ Res_s。这是 Hoare 式部分正确性 + 终止性（循环由变体函数保证）。

**定义 313（缝契约）** 对 A→B 的交接，缝 `e=(A,B,V_e,R_e,α_e,κ_e,δ_e)`：
- `V_e`：接口变量（位姿/坐标系、单位、物体身份、抓握谓词、力状态、信念时间戳、资源份额）；
- `R_e ⊆ dom(V_e)²`：A 的后置表示与 B 的前置表示之间的关系；
- `α_e`：适配器，把 A 的接口表示保物理地映射为 B 的表示（坐标变换/单位换算/标签映射/时间对齐），**不得改变物理世界状态**；
- `κ_e`：接口校准（ECE_int 与可靠图）；
- `δ_e`：缝风险预算。
**缝义务**：`Post_A ∧ R_e(α_e(V_e)) ⇒ Pre_B`；`Inv_A ∧ Inv_B` 可满足；`W_A` 与 `W_B` 非干扰；`Res_A+Res_B+Res_{α_e} ≤ B`；`ECE_int(e) ≤ τ_int`。若 B 读取了 A 未写且未在 `V_e` 声明的变量，该缝**非法**（默认拒绝）——这是本轮把「胶水代码」纳入安全论证的核心手段。

**定义 314（良型程序）** 类型判断 `Γ; B ⊢ p : C`（在库 Γ、预算 B 下，p 满足契约 C）。规则：
- **叶子**：`Valid(Cert_s) ∧ c∈Env_s ∧ Res_s≤B`；
- **顺序**：`Γ;B1 ⊢ p1:C1`，`Γ;B2 ⊢ p2:C2`，存在已声明缝 `e=(C1,C2)` 且缝义务全满足，`B1+B2+δ_e ≤ B`；
- **并行**：`W_1∩(R_2∪W_2)=∅`（或效应可交换），资源求和，不变式合取；
- **分支**：两分支同型或后者是前者的安全细化；
- **循环**：`Inv` 归纳可保持，排名函数 `ν` 严格下降且资源有界；
- **try**：回退分支必须是已认证且「更弱但更安全」的细化 `C_fb ⊑ C`；
- **adapt**：适配器已认证且保不变式。
`⊢ p` 当且仅当存在 C 使 `Γ;B ⊢ p:C` 且所有叶子证书有效。

**定义 315（接口不确定性与语义校准）** 技能暴露接口编码 `h_s:𝒮→𝒵_s`；缝适配器 `α:𝒵_A→𝒵_B`。令 `align` 为「α 在共享指称物上把 A 的含义正确翻译为 B 的含义」这一事件。`U_int(e)=H(align | D_probe)`；`ECE_int(e)` 为适配器置信度与共享指称物上实际一致率的校准误差。关键：**U_int 不能靠单个模块内的更多数据消解，只能靠共享指称物/跨模块探针/适配器再校准**；且它与 U_ale、U_epi 语义不同，不简单相加。

**定义 316（风险账本 LED）** 任务预算 `B`。叶子消耗 `r_s`（取证书 p95），缝消耗 `r_e=δ_e+r_{α_e}`，组合余量 `ε_comp`（相关性/共模误差）。保守上界：`r(p) ≤ Σ_{s∈p} r_s + Σ_{e∈p} r_e + ε_comp`。账本单调不增：交接不清零、并行不重复计费、回退储备 `B_fb` 永远保留。若 `r(p)+B_fb>B`，拒绝或降级到最大良型子程序（定义 325）。

**定义 317（能力包络与通用性包络）** 技能包络 `Env_s ⊆ 𝒞`（物体/位姿/负载/光照/人/网络等上下文空间），带距离 `d(·,Env_s)`。程序包络 `Env_p = ⋂_{s∈p} Env_s ∩ ⋂_{e∈p} dom(R_e)`。**已认证通用性包络**：
`𝒢(ℒ) = { p : ⊢ p, Env_p≠∅, r(p)+B_fb ≤ B }`，认证覆盖 `Cov(ℒ)=μ(𝒢(ℒ))`（μ 为任务-上下文测度）。
**名义通用性** = 技能库大小；**认证通用性** = `Cov(ℒ)`。二者可以背离，这正是本轮要暴露的差别。

**定义 318（通用程序提议器 GPP）** 冻结/受控的基础模型在程序文法上做约束解码：`π_θ(p,θ,conf,unknown | c)`。它只**提议**；类型检查器、准入服务、运行时监控才是权威。它可发出 `EXPAND(s_new)` 或 `ASK_HUMAN(q)`。要求校准弃权：`conf` 需满足 ECE ≤ τ_gpp；`unknown` 触发 R69 的 MINT 去问，而不是让模型硬编一个程序。**GPP 是不可信组件**，与 R69 的冻结 LLM 同级。

**定义 319（带邻居测试的准入 ADM）** 新技能进入隔离区，探针集 `D_adm = D_boundary ∪ D_neighbor ∪ D_adversarial`：
- `D_boundary`：契约边界（前置/后置/不变式的边缘）；
- `D_neighbor`：与该技能帧/资源重叠的**每一个邻居技能**做组合测试与缝测试；
- `D_adversarial`：坐标系/单位互换、过期信念注入、语义仿冒、适配器扰动、资源争用。
接受条件：`UCB_δ(violations) ≤ δ_adm` 且所有相关缝 `ECE_int ≤ τ_int`。准入只覆盖**已测上下文**，不外推；签发临时证书，可回滚；准入债务记入账本，不得动用回退储备。**在组合中测试，而不是在孤立中测试。**

**定义 320（运行时缝监控与受盾解释器 RSM）** 解释执行良型程序；在每个缝处检查 `R_e(α_e(V_e))`、不变式、资源消耗、包络距离 `d(c_t,Env_p)` 与 `U_int`。任一违反 ⇒ 切换到最大良型回退子程序（`try` 分支）或安全停；**绝不允许 GPP 在运行时即兴生成未定型的「补丁」**。缝监控运行在交接/任务频率，内环仍由叶子控制器负责。

**定义 321（跨本体证书迁移）** 本体能力画像 `κ=(reach,payload,dof,max force/torque,sensors,dynamics)`；抽象 `α_{X→Y}:𝒮_X→𝒮_Y`。若 `α` 是**模拟关系**（X 的每条迁移都有 Y 的匹配迁移且保持标签），且契约中的不变式与缝关系是**α-不变的无量纲量**（力按重力归一、力矩按额定归一、长度按可达半径归一、时间按自然频率归一），则证书可迁移，风险膨胀 `η=L_α·ε_α+δ_seam`；若 `η>δ_allow`，不得迁移，必须重认证。

**定义 322（契约合成与人类签署）** 从演示/仿真/失败日志学习候选前置、后置、不变式（归纳不变式、屏障证书、时序模式）；但**只有人类签署的契约才进入内核**。契约库版本化、差异审计；「机器提议，人类处置」。这防止「模型给自己出题、自己判卷」。

**定义 323（缝规格博弈）** 意图 `ψ*`（未知真值），契约 `φ`（已知）。可靠性 `φ⇒ψ*`；完备性 `ψ*⇒φ`；缺口 `G=ψ*\φ`。程序 p **缝利用**若 `⟦p⟧⊆φ` 但 `⟦p⟧⊄ψ*`。审计通过 (a) 让对抗 GPP 专门「满足契约而违背意图」、(b) 与人类标注行为做差分测试、(c) 对关键缝尝试形式证明，来搜索利用。记 `U_spec` 为缺口覆盖率；高 `U_spec` ⇒ 禁止扩展包络。

**定义 324（证书 J_SEAM）** `J_SEAM = (J_FLUID_leafs, seam_certs, ECE_int, U_int, Cov, ledger, program_hash, adapter_hash, admission_log_hash, seam_ver)`。`Valid ⇔` 全部叶子有效 ∧ 缝已认证且已校准 ∧ 程序良型 ∧ 账本未越界 ∧ 包络诚实 ∧ 审计通过。

**定义 325（优雅降级 / 最大良型子程序）** 在 p 的某个节点失败时，选择 `p'⊑p`（子程序/前缀/回退分支）最大化任务效用，s.t. `⊢p'`、`r(p')+B_fb≤B`、`Env_{p'}` 覆盖当前上下文。若无，则安全停或 `ASK_HUMAN`。**Fail small, fail typed.**

**定义 326（包络扩展作为元信息动作）** `EXPAND(s_new)` 或扩展 `Env_s`：成本 `c_exp` = 准入探针 + 未来风险 + 不可逆性；价值 = `Cov` 的期望增量。仅当元 IVoI > 0、人类授权、且不挪用 `B_fb` 时才执行。这是 R69 的 IVoI 在能力层的提升：**提问是一次的，准入是永久的。**

## 2. 关键算法骨架

```python
# IP-264 SPL/SCT：程序 AST 与叶子契约
@dataclass
class Contract:
    pre: Pred; post: Pred; inv: Pred
    reads: Set[Var]; writes: Set[Var]
    res: ResourceVector; envelope: Envelope; cert: LeafCert

# IP-265 SEA：缝义务（未声明依赖默认拒绝）
def seam_obligations(A: Contract, B: Contract, alpha: Adapter, budget):
    undeclared = B.reads - A.writes - alpha.declared
    if undeclared: return UNSAFE("undeclared seam variable", undeclared)
    return [
        implies(And(A.post, alpha.rel), B.pre),
        satisfiable(And(A.inv, B.inv)),
        non_interfering(A, B),
        A.res + B.res + alpha.cost <= budget,
        alpha.ece_int <= TAU_INT,
    ]

# IP-266 CRT：组合风险类型检查器
def typecheck(p, Gamma, B):
    if is_leaf(p):                       # 叶子：证书 + 包络 + 预算
        return p.contract if leaf_ok(p, Gamma, B) else raise TypeErr(p)
    if p.op == "seq":
        C1, B1 = typecheck(p.left, Gamma, B)
        C2, B2 = typecheck(p.right, Gamma, B - B1)
        e = Gamma.seam(C1, C2)           # 缝必须显式声明
        if e is None: raise TypeErr("no seam")
        if any(b is not True for b in seam_obligations(C1, C2, e.alpha, B)):
            raise TypeErr("seam obligation failed", e)
        return compose(C1, C2, e), B1 + B2 + e.risk
    if p.op == "par":
        C1, B1 = typecheck(p.left, Gamma, B)
        C2, B2 = typecheck(p.right, Gamma, B - B1)
        if not non_interfering(C1, C2): raise TypeErr("interference")
        return par_compose(C1, C2), B1 + B2
    if p.op == "while":
        if not inductive_invariant(p) or not ranking_decreases(p):
            raise TypeErr("loop not certifiable")
        return p.inv_contract, B
    if p.op == "try":
        C1, B1 = typecheck(p.left, Gamma, B)
        C2, B2 = typecheck(p.right, Gamma, B - B1)
        if not refines_safe(C2, C1): raise TypeErr("unsafe fallback")
        return C1, max(B1, B2) + B_fb
    raise TypeErr("unknown op")

# IP-269/272：接口校准与缝监控
def interface_calibrate(skillA, skillB, referents):
    ece = calibration_error(skillA.h, skillB.h, referents)
    u_int = posterior_entropy(alignment_posterior(referents))
    return ece, u_int

def seam_ok(e, ctx):
    v = read_interface(e.vars, ctx)
    return (e.rel(v) and invariant_ok(ctx)
            and envelope_distance(ctx, e.env) <= 0
            and e.alpha.ece_int <= TAU_INT)

# IP-271：邻居准入考试
def admission_exam(s_new, library, delta):
    probes = (boundary_probes(s_new)
              + [neighbor_compose(s_new, s) for s in library if overlaps(s_new, s)]
              + adversarial_seams(s_new, library))
    violations = run_probes(s_new, probes)
    return ucb_lower_bound(violations, delta) <= delta_adm

# IP-276：SEAM-RAS 主闭环（组合层）
def SEAM_RAS_round(M, ctx):
    # 1) 提议的是程序，不是原始动作
    p, conf, unknown = M.gpp.propose(ctx)
    # 2) 包络诚实：未知/越界 -> 只降级或申请扩展，绝不外推
    if unknown or not M.env.covers(p, ctx):
        if M.ledger.can_expand() and M.human.authorize(p):
            M.admission.exam_and_maybe_expand(p)
        else:
            p = M.fallback.max_certified_subprogram(ctx, M.library)
    # 3) 组合类型检查 + 接口校准门
    C, risk = M.crt.typecheck(p, M.library, M.ledger.remaining())
    if not M.icg.pass_all(p):
        p = M.fallback.max_certified_subprogram(ctx, M.library)
        C, risk = M.crt.typecheck(p, M.library, M.ledger.remaining())
    # 4) 受盾解释：每个缝都检查，失败就缩到最大良型子程序
    for node in M.rsm.interpret(p, ctx):
        if not M.rsm.seam_ok(node, ctx):
            M.vqa_s.log_seam_violation(node, ctx)
            p = M.fallback.max_certified_subprogram(ctx, M.library)
            break
        M.ledger.charge(node)
    # 5) 审计 + 证书
    M.vqa_s.submit_async(p, C, risk, M.ledger)
    return p, C, M.cert.issue(p, C, risk)
```

## 3. 推导

**引理 19（缝组合的可靠性）** 设程序 p 的叶子证书在各自包络内以概率 ≥1−δ_s 满足契约，每条缝以概率 ≥1−δ_e 满足 `R_e`，帧条件非干扰。则 p 的任意执行满足组合后置与不变式的概率 ≥ `1 − Σ_s δ_s − Σ_e δ_e − ε_comp`。证明对程序文法做结构归纳：顺序用适配器把 A 的后置翻译为 B 的前置；并行用非干扰保证交叠读写不破坏彼此不变式；循环用归纳不变式与排名函数。**要点：安全论证的误差是可分解、可归因的——出问题能定位到具体叶子或具体缝，而不是一个不可解释的总分。**

**引理 20（跨本体迁移条件）** 若 `α_{X→Y}` 是模拟关系，且证书中的不变式/缝关系都是 α-不变的无量纲量，则 X 上的证书在 Y 上以风险膨胀 `η ≤ L_α·ε_α + Σ_e δ_e` 成立；若 `η≤δ_allow`，可迁移。系：**跨本体通用的不是策略权重，而是「无量纲化的安全断言 + 显式适配器」**；没有适配器的「零样本迁移」在安全侧不成立。

**引理 21（准入的邻居税）** 设技能库有 n 个技能，新技能与其中 k 个有帧/资源重叠。若准入只做孤立测试，则对每个重叠邻居都存在一个「孤立测试通过、组合时违反缝义务」的缺陷；要排除它，至少需要该邻居上的一个组合/缝测试。故最坏情况下每个新技能至少需要 Ω(k) 次邻居测试；全库两两认证的总成本为 Ω(n²)（稠密重叠时）。**系：通用性不是免费的；技能库越大，每单位认证覆盖的成本越高。**

**定理 18（SEAM-RAS 的组合可靠性）** 在 A99–A101 下，若所有叶子契约可靠、所有缝义务成立、程序良型，则程序在包络内满足组合后置与安全不变式，且风险账本不越界；运行时回退只会缩小程序、不会扩大风险。对单技能程序（|p|=1）且无交互，SEAM-RAS 逐指令退化为 FLUID-RAS；对无组合、无交互的叶子，进一步退化为 R68 的 CALM-RAS。**安全侧不做让步，效率侧获得「可复用组合」的收益。**

**定理 19（通用性—认证成本前沿）** 设接口代数有 m 个共享接口类型，每个接口类型需 c 次标准化缝测试，则总缝认证成本为 O(m²c)（与技能数 n 无关），单技能摊还成本 O(m²c/n)；若每个技能使用定制接口，则成本为 Ω(n²)。因此**认证通用覆盖率随技能数增长的前提是接口被复用**；在固定测试预算 T 下，`Cov` 的增长上界由接口标准化程度而非技能数量决定。**系：追求通用性时，先问「我的接口能不能复用」，再问「我要不要加第 1001 个技能」。**

**定理 20（契约—意图缺口不可由纯契约监控消除）** 设意图 `ψ*`、契约 `φ`，且 `ψ*≠φ`。若缺口 `G=ψ*\φ` 中存在可达状态，且程序在该状态上的行为未被契约约束，则存在一个良型程序 p，使 `⟦p⟧⊆φ` 但 `⟦p⟧⊄ψ*`；任何只检查 `φ` 的监控器都无法检出。故意图安全只能来自：(a) 在可达集上 `φ≡ψ*`（开放世界中不可得），(b) 缺口内的人类授权/独立意图通道，(c) 保守拒绝进入缺口。**这是本轮最重要的「不可能性」边界：类型安全不是意图安全。**

## 6. 本轮最大风险

**一句话**：SEAM-RAS 把安全性从「每个技能对不对」提升为「每个接口是否说得同一种语言」，但它的全部保证都押在「契约 φ 能充分表达意图 ψ*」这一假设上——**一旦契约有洞，系统会以类型正确、证书齐全、可审计的姿态，稳定地执行一个满足契约却违背意图的通用操作；组合出的涌现危害甚至能逐技能、逐缝都通过检查**。于是最危险的失败不是「不会做」，而是「**被证明正确地做错**」。

## 2. 形式化定义（要点版）

**定义 310（总览与六不变式）** 零学习写操作继承；组合层在任务/交接频率（10–100Hz），内环仍由 R68/R69 叶子控制器负责；只有良型程序可执行；缝诚实（未声明依赖默认拒绝）；接口校准门；证据纪律；预算守恒（交接不清零，`B_fb` 不可挪用）。

**定义 311–312（程序与技能契约）** 技能程序文法见上；叶子 `s=(Pre,Post,Inv,Frm,Res,Cert,Env)`，语义 `⟦s⟧⊆𝒮×𝒮`；契约可靠性 = 包络内 Hoare 式部分正确 + 循环终止 + 帧条件 + 资源上界。

**定义 313（缝契约）** `e=(V_e,R_e,α_e,κ_e,δ_e)`；适配器只做保物理的表示变换（坐标/单位/标签/时间），不改变世界；缝义务 = `Post_A ∧ R_e(α_e(V_e)) ⇒ Pre_B`、`Inv_A∧Inv_B` 可满足、`W_A`/`W_B` 非干扰、资源求和、`ECE_int≤τ_int`。**胶水代码第一次成为被认证对象。**

**定义 314（良型程序）** `Γ;B⊢p:C`：叶子证书+包络+预算；顺序需已声明缝且义务全过；并行需非干扰或效应可交换；循环需归纳不变式+排名函数；try 的回退必须是更弱但更安全的细化；adapt 的适配器保不变式。`⊢p ⇔ ∃C, Γ;B⊢p:C` 且叶子全有效。

**定义 315（接口不确定性与语义校准）** `h_s:𝒮→𝒵_s`，`α:𝒵_A→𝒵_B`；`align` = 在共享指称物上正确翻译；`U_int=H(align|D_probe)`，`ECE_int` 为适配器置信度校准误差。**U_int 不能靠单模块内更多数据消解，只能靠共享指称物/跨模块探针/适配器再校准。**

**定义 316–317（账本与通用性包络）** 风险保守上界 `r(p)≤Σr_s+Σr_e+ε_comp`，单调不增；`𝒢(ℒ)={p:⊢p, Env_p≠∅, r(p)+B_fb≤B}`，`Cov(ℒ)=μ(𝒢(ℒ))`。**名义通用性（技能数）与认证通用性（Cov）可以背离。**

**定义 318–320（GPP / 准入 / 运行时）** GPP 约束解码只提议，可 ASK/EXPAND，且需校准弃权；ADM 隔离区 + `D_boundary∪D_neighbor∪D_adversarial`，在组合中测试、只覆盖已测上下文、可回滚、记准入债务；RSM 受盾解释器每缝检查，失败即最大良型子程序或安全停，绝不允许运行时即兴补丁。

**定义 321–322（跨本体与契约签署）** 迁移需模拟关系 + α-不变无量纲量 + `η≤δ_allow`；契约可由机器从演示/仿真/失败日志合成，但**只有人类签署的契约进入内核**（机器提议，人类处置）。

**定义 323–326（规格博弈 / 证书 / 优雅降级 / 元扩展）** 意图 ψ* 与契约 φ 的缺口 G；缝利用 = 满足 φ 但违背 ψ*；`U_spec` 高则禁止扩展；`J_SEAM` 并入缝证书/ECE_int/U_int/Cov/账本/哈希；失败时选最大良型子程序（fail small, fail typed）；`EXPAND` 是元信息动作，需元 IVoI>0 + 人类授权 + 不动用 `B_fb`。**提问是一次的，准入是永久的。**

```python
# IP-264/265：程序 AST 与叶子契约
@dataclass
class Contract:
    pre: Pred; post: Pred; inv: Pred
    reads: Set[Var]; writes: Set[Var]
    res: ResourceVector; envelope: Envelope; cert: LeafCert

# IP-266 SEA：缝义务（未声明依赖默认拒绝）
def seam_obligations(A, B, alpha, budget):
    undeclared = B.reads - A.writes - alpha.declared
    if undeclared: return UNSAFE("undeclared seam variable", undeclared)
    return [implies(And(A.post, alpha.rel), B.pre),
            satisfiable(And(A.inv, B.inv)),
            non_interfering(A, B),
            A.res + B.res + alpha.cost <= budget,
            alpha.ece_int <= TAU_INT]

# IP-267 CRT：组合风险类型检查器
def typecheck(p, Gamma, B):
    if is_leaf(p):
        return p.contract if leaf_ok(p, Gamma, B) else raise TypeErr(p)
    if p.op == "seq":
        C1, B1 = typecheck(p.left, Gamma, B)
        C2, B2 = typecheck(p.right, Gamma, B - B1)
        e = Gamma.seam(C1, C2)                      # 缝必须显式声明
        if e is None: raise TypeErr("no seam")
        if any(b is not True for b in seam_obligations(C1, C2, e.alpha, B)):
            raise TypeErr("seam obligation failed", e)
        return compose(C1, C2, e), B1 + B2 + e.risk
    if p.op == "par":
        C1, B1 = typecheck(p.left, Gamma, B)
        C2, B2 = typecheck(p.right, Gamma, B - B1)
        if not non_interfering(C1, C2): raise TypeErr("interference")
        return par_compose(C1, C2), B1 + B2
    if p.op == "while":
        if not inductive_invariant(p) or not ranking_decreases(p):
            raise TypeErr("loop not certifiable")
        return p.inv_contract, B
    if p.op == "try":
        C1, B1 = typecheck(p.left, Gamma, B)
        C2, B2 = typecheck(p.right, Gamma, B - B1)
        if not refines_safe(C2, C1): raise TypeErr("unsafe fallback")
        return C1, max(B1, B2) + B_fb

# IP-269：接口校准门
def interface_calibrate(A, B, referents):
    return (calibration_error(A.h, B.h, referents),
            posterior_entropy(alignment_posterior(referents)))

# IP-271：邻居准入考试（在组合中测试）
def admission_exam(s_new, library, delta):
    probes = (boundary_probes(s_new)
              + [neighbor_compose(s_new, s) for s in library if overlaps(s_new, s)]
              + adversarial_seams(s_new, library))
    return ucb_lower_bound(run_probes(s_new, probes), delta) <= delta_adm

# IP-278：SEAM-RAS 主闭环（组合层）
def SEAM_RAS_round(M, ctx):
    p, conf, unknown = M.gpp.propose(ctx)                     # 提议程序，不是动作
    if unknown or not M.env.covers(p, ctx):                   # 包络诚实
        if M.ledger.can_expand() and M.human.authorize(p):
            M.admission.exam_and_maybe_expand(p)
        else:
            p = M.fallback.max_certified_subprogram(ctx, M.library)
    C, risk = M.crt.typecheck(p, M.library, M.ledger.remaining())
    if not M.icg.pass_all(p):                                 # 未校准不外推
        p = M.fallback.max_certified_subprogram(ctx, M.library)
        C, risk = M.crt.typecheck(p, M.library, M.ledger.remaining())
    for node in M.rsm.interpret(p, ctx):                      # 受盾解释
        if not M.rsm.seam_ok(node, ctx):
            M.vqa_s.log_seam_violation(node, ctx)
            p = M.fallback.max_certified_subprogram(ctx, M.library)
            break
        M.ledger.charge(node)
    M.vqa_s.submit_async(p, C, risk, M.ledger)
    return p, C, M.cert.issue(p, C, risk)
```

## 4. 推导

**引理 19（缝组合的可靠性）** 叶子以概率 ≥1−δ_s 满足契约、缝以概率 ≥1−δ_e 满足 `R_e`、帧非干扰时，程序满足组合后置与不变式的概率 ≥ `1−Σ_s δ_s−Σ_e δ_e−ε_comp`。结构归纳：顺序用适配器把 A 后置翻译为 B 前置；并行用非干扰保护彼此不变式；循环用归纳不变式+排名函数。**安全误差可分解、可归因到具体叶子或具体缝。**

**引理 20（跨本体迁移条件）** 若 `α_{X→Y}` 是模拟关系且证书中的不变式/缝关系为 α-不变无量纲量，则迁移风险膨胀 `η≤L_α·ε_α+Σ_e δ_e`；`η≤δ_allow` 才可迁移。系：**跨本体通用的不是权重，而是无量纲安全断言 + 显式适配器**；无适配器的零样本迁移在安全侧不成立。

**引理 21（准入的邻居税）** 新技能与 k 个邻居重叠时，孤立测试对每个邻居都存在「孤立通过、组合违反」的缺陷；要排除至少需 Ω(k) 次邻居/缝测试，稠密重叠全库为 Ω(n²)。系：**通用性不是免费的；库越大，每单位认证覆盖越贵。**

**定理 18（SEAM-RAS 的组合可靠性）** A99–A101 下，叶子可靠 + 缝义务成立 + 程序良型 ⇒ 包络内满足组合后置与安全不变式，账本不越界；回退只缩小程序、不扩大风险。单技能无交互时逐指令退化为 FLUID-RAS；无组合无交互叶子进一步退化为 R68 CALM-RAS。安全侧不让步，效率侧获得可复用组合。

**定理 19（通用性—认证成本前沿）** 共享接口 m 个、每类需 c 次标准化缝测试时，总成本 `O(m²c)`（与技能数 n 无关），单技能摊还 `O(m²c/n)`；若每技能定制接口，则 `Ω(n²)`。固定测试预算 T 下，`Cov` 的增长由接口标准化程度决定，而非技能数量。系：**先问接口能否复用，再问要不要第 1001 个技能。**

**定理 20（契约—意图缺口不可由纯契约监控消除）** 若 `ψ*≠φ` 且缺口 `G=ψ*\φ` 中存在可达状态、程序在该状态行为未被契约约束，则存在良型 p 使 `⟦p⟧⊆φ` 但 `⟦p⟧⊄ψ*`；只检查 φ 的监控器无法检出。故意图安全只能来自：(a) 可达集上 `φ≡ψ*`（开放世界不可得），(b) 缺口内人类授权/独立意图通道，(c) 保守拒绝进入缺口。**类型安全 ≠ 意图安全。**

## 7. 本轮最大风险

**一句话**：SEAM-RAS 把安全性从「每个技能对不对」提升为「每个接口是否说得同一种语言」，但它的全部保证都押在「契约 φ 能充分表达意图 ψ*」这一假设上——**一旦契约有洞，系统会以类型正确、证书齐全、可审计的姿态，稳定地执行一个满足契约却违背意图的通用操作；组合出的涌现危害甚至能逐技能、逐缝都通过检查**。于是最危险的失败不是「不会做」，而是「**被证明正确地做错**」。

**次级风险与缓解**：
1. **接口校准本身不可信**（U_int 高但被误判为对齐）→ ICG 门 + 共享指称物 + 刚性适配器回退；
2. **技能库爆炸导致认证不可持续**（Ω(n²)）→ 共享接口代数 + 层级契约 + 只认证可达重叠；
3. **GPP 幻觉出不存在/不可认证的技能** → 约束解码 + 准入隔离 + 校准弃权 + 人类签署；
4. **组合涌现危害超出两两缝检查** → 组合级仿真/红队 + 全局不变式 + 保守拒绝（E314）；
5. **类型系统给出虚假安全感** → 定理 20 明示边界 + 人类授权 + 独立意图通道 + 审计 `U_spec`。
