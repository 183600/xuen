# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「最优控制」×「行为树」）

> R69 教会了闭环「提问」：把不确定性拆成 aleatoric 与 epistemic，用流匹配策略把歧义呈现为多个动作模态，再用注视/探针/问句去主动消解；消解不了才退回 R68 的纯保守。它回答了「**我该向谁求证、还能问什么**」。但它没有回答一个更底层的问题：**这些决定本身是被什么结构组织起来的，这个结构安全吗？**
>
> 回看 R69 的主闭环，它仍是一段单体 `if/else`：`select_mode` 是一个没有最优性依据的 argmax，`ask / act / fallback` 的切换没有驻留时间与防抖，交互预算与证据纪律靠代码约定而非结构保证，审计只能看事后日志。换句话说，R69 造出了很多**好的零件**（FMP、AUD、MINT、CIA、FMA），却没有给它们一个**可认证的装配图**。一旦零件在分布外失效，单体函数会把局部错误直接放大成全局错误，而且没有人能在运行前说清「哪条路径一定还有兜底」。
>
> 本轮两个灵感正好补上「装配图」与「连续底座」：
> - **行为树**给出离散决策的结构化骨架——Sequence / Fallback / Parallel / Decorator 把「感知—消歧—行动—兜底—监控」写成显式、可组合、可被人读懂、可被逐节点认证的树；
> - **最优控制**给出连续动作的定量底座——每个叶节点不再是一个查表动作，而是一个有限时域最优控制问题（iLQR/MPC + CBF 安全滤波），带值函数、代价-to-go 与鲁棒裕度。
>
> 核心命题：**把 R69 的单体闭环重写为一棵「携带契约的行为树」：树的离散结构负责反应式决策与安全兜底，树的叶子是带证书的最优控制原语；用混合切换的最优性 + 驻留/滞回替代 R69 的 `select_mode`，用 cost-to-go VoI 替代熵 VoI，用契约代数把每个节点的证书组合成整棵树的证书；任何节点、监控或调度失效，都沿树结构确定性回退到 R68 兜底。** 命名 **ARBOR-RAS**（Adaptive Risk-aware Behavior-tree Orchestrated Regulation）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**用什么结构组织这些决定，并证明这个结构本身安全**」——安全不只是选对一个动作，更是选对一棵树。

## 0. 直觉与动机

**灵感 1（行为树 → 决策的结构本身就是可审计对象）**
直觉：R69 的闭环像一段写得很聪明的脚本：它知道何时该问、何时该慢、何时该退。但脚本的「聪明」散落在控制流里，无法被单独检查。行为树把控制流从代码里抽出来，变成一棵**显式的、有类型的树**：Sequence 表示「先看再问再做」，Fallback 表示「能走就走，不能走就停」，Parallel 表示「一边执行一边监控」，Decorator 表示「最多问一次」「必须驻留 200ms」「证据不足就失败」。这带来三个 R69 没有的东西：
1. **反应性**：任何时刻一个 guard 失效，Fallback 立刻换分支，不需要重跑整条管线；
2. **组合性**：子树可以单独认证、单独替换、单独做对抗测试；
3. **可解释性**：一次 tick 的活动路径就是一句人类可读的理由——「我停，是因为 AskNode 的证据纪律失败，Fallback 落到了 SafeStop」。
但朴素行为树只给「离散开关」，不给「连续最优」，也不保证切换不抖、不 Zeno、不饿死。所以它必须与最优控制配对。

**灵感 2（最优控制 → 每个叶子都要有值函数，而不只是一个动作）**
直觉：R69 的每个模态最终只吐出一段动作 `mode.a`，`select_mode` 凭启发式挑一个。最优控制则要求：对每个候选模态/叶子，定义一个有限时域代价 `J_ℓ = ∫(任务代价 + 风险惩罚) + 终端代价`，在动力学与安全集约束下求 `u*_ℓ`，并得到值函数 `V_ℓ(x)`。于是「选哪个模态」不再是拍脑袋，而是**混合最优切换**：比较各叶子的 `V_ℓ(x) + 切换成本`，只有优势超过滞回阈值才切。值函数还给出一条 R69 缺失的通道——**cotstate / 值函数梯度告诉我们「哪种不确定性真的影响任务代价」**，这正是下一段 cost-to-go VoI 的基础。
更关键的是：最优控制叶子的安全证书（不变集、CBF、鲁棒裕度、值函数上界）是**可以逐叶子验证**的，这使行为树的「组合认证」第一次有了可用的原子。

**灵感 3（行为树 × 最优控制 = 混合系统，而不是两个流行词的拼接）**
直觉：行为树本质上是离散事件监督器，最优控制叶子本质上是连续被控对象；二者拼在一起就是一个**混合自动机**：离散状态 = 当前活动路径/模态，连续状态 = 机器人状态与信念，离散转移 = tick 边界上的 guard 与切换，连续流 = 叶子控制律。R69 的 `ask/act/fallback` 正是这个混合系统里的离散转移，但它没有离散转移的语义，也没有切换稳定性。把 BT 当离散监督器、OC 当连续控制器，我们就能借用混合系统成熟的三件工具：**不变集/契约、驻留时间/滞回、Zeno 排除**。这不是把两个热词相加，而是把一个含糊的「策略」变成一个可分析的混合对象。

**灵感 4（最优控制反过来修正 R69 的 VoI → 只问「对任务代价有用」的问题）**
直觉：R69 的 `VoI(g)=H(M|o)−E[H(M|o,y)]` 是**熵**的减少。熵对所有方向一视同仁，于是系统可能花一次宝贵的交互去消除一个「对任务毫无影响」的歧义：杯子是左手还是右手握的、云是积云还是层云、对方的笑是礼貌还是开心——如果任务只是把杯子递过去，这些答案不改变任何代价。最优控制给出正确的度量：**cost-to-go VoI**，即「获取信息后，期望最优代价-to-go下降多少」。在二次型近似下，它等于 `½ tr(H_V · ΔΣ)`：只有值函数 Hessian 大的方向（真正影响任务的敏感方向）才值钱；Hessian 为零的方向，信息再多也不值一次提问。熵 VoI 是它在「任务对所有方向等权」时的退化情形。**这把「该不该问」从信息论问题修正为控制论问题**，也直接降低 R69 自陈的「问错比不问更危险」的风险——不该问的，根本不会进入 AskNode。

**灵感 5（新结构带来新攻击面 → 树本身需要威胁模型）**
直觉：一旦系统由行为树调度，攻击者就有了新的着力点：**guard 欺骗**（伪造黑板条件，让树走错分支）、**节点饿死**（让某节点永远 Running，从而永远到不了兜底）、**兜底洪泛**（反复触发安全停，制造可用性 DoS）、**tick 重放/注入**（重放过期决策）、**子树伪装**（冒充已认证节点）。更隐蔽的是**组合认证盲区**：每个叶子都「通过认证」、每个节点契约都成立，不代表整棵树在分布外安全；局部正确可以被组合成全局自信。所以本轮必须同时交付：契约代数、有界活性、驻留/滞回、结构风险预算、树外独立看门狗、以及树特有的对抗干扰集。否则 ARBOR 只是把 R69 的黑箱换成一棵更漂亮的、会自己说服自己的树。

## 1. 形式化定义（增量：定义 310–327）

**定义 310（ARBOR-RAS 总览）** ARBOR-RAS = (CCT, OCL, HSC, CGV, CCA, SLM, SRB, RAS-WM†)。三不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **结构性兜底**：根到 SafeStop 的兜底路径在每个 tick 都可被有界步数到达，且任何叶子/监控超时都会使祖先 Fallback 失败并向下回退；
(iii) **组合认证**：只有携带有效契约的节点才允许被 tick；根证书 Valid 当且仅当所有活动节点契约成立、结构风险预算未超、且 J_FLUID 仍 Valid。

**定义 311（带类型 tick 的行为树语义）** 黑板 `B`，tick 序号 `τ`。节点 `n` 的语义是转移 `tick_n : (B, τ) → (status, B', τ', κ)`，其中 `status ∈ {Success, Failure, Running}`，`Running` 携带承诺 `κ`（子树状态、下一次唤醒时刻、已消耗预算）。规定：
(a) **tick 边界切换**：除显式 `Halt` 外，只在 tick 边界抢占；叶子内部可在更高频率运行；
(b) **有界 tick**：每个节点有 `T_max`，超时即 `Failure`；
(c) **承诺单调**：`Running` 节点在承诺窗口内不得被无 `Halt` 地替换。
这三点把「反应性」与「控制连续性」隔离开：离散决策只在边界发生，连续控制不因每次 tick 跳变。

**定义 312（最优控制叶子 OCL）** 叶子 `ℓ = (f_ℓ, c_ℓ, g_ℓ, C_ℓ, H_ℓ)`：动力学 `ẋ=f_ℓ(x,u)`，运行代价 `c_ℓ(x,u)`，终端代价 `g_ℓ`，安全集 `C_ℓ`，时域 `H_ℓ`。控制律 `u*_ℓ(x)=argmin J_ℓ`，`J_ℓ = ∫_0^{H_ℓ}(c_ℓ + ρ_ℓ·r_risk)dt + g_ℓ(x(H_ℓ))`，s.t. `x(t)∈C_ℓ, u∈U`。值函数 `V_ℓ(x)=min J_ℓ`；用 iLQR/MPC 求解、CBF 滤波保证 `C_ℓ` 前向不变。叶子契约 `C_ℓ^ct = (A_ℓ, G_ℓ, I_ℓ, V̄_ℓ, δ_ℓ)`：假设、保证、不变式、值函数上界、鲁棒裕度。

**定义 313（行为树节点与契约）** 内部节点类型：`Sequence`、`Fallback`、`Parallel(k)`；装饰器：`Retry(n)`、`Timeout(T)`、`Dwell(τ_d)`、`Guard(p)`、`Budget(c,T)`、`Evidence(k-of-n)`。每个节点 `n` 带契约 `C_n=(A_n,G_n,I_n,J_n,T_n)`。契约偏序：`C ⊑ C'` 当且仅当 `A'⇒A`、`G⇒G'`、`I'⇒I`、`J'≤J`、`T'≤T`（更强、更省）。组合规则见定义 316。

**定义 314（混合切换最优控制 HSC）** 设候选模式/叶子集合 `{ℓ_k}`，切换成本 `s_{jk}(x)=c_int(g_{jk})+c_risk(x)+c_evidence`（交互、风险跳变、证据成本）。定义切换优势 `Adv_k(x)=[V̂_k(x)+e_k+s_{k_prev,k}] − [V̂_{k_prev}(x)+e_{k_prev}]`。切换规则：
`k* = argmin_k [V̂_k(x)+e_k+s_{k_prev,k}]`，仅当 `Adv_{k*} < −η`（滞回）且上一模式驻留 `≥τ_d` 且处于承诺边界时才真正切换；否则保持。
R69 的 `select_mode` 是 `V̂≡0, s≡0, η=0, τ_d=0` 的退化情形。

**定义 315（cost-to-go VoI）** 对信息动作 `g`：`VoI_OC(g) = E_{y∼p(·|g,o)}[V*(x) − V*(x|y)] − c(g)`，即以最优代价-to-go的期望下降衡量信息价值；`g* = argmax_g VoI_OC(g)`，`VoI_OC≤0` 则不交互。与 R69 的熵 VoI 并列：`VoI_ent` 是 `V` 对所有方向等敏感时的特例（引理 20）。

**定义 316（契约代数 CCA）** 组合规则：
- `Sequence(n_1..n_m)`：`A=∧A_i`，`G=G_m`，要求 `G_i⇒A_{i+1}`；`I=∩I_i`；`J=ΣJ_i`；`T=ΣT_i`。
- `Fallback(n_1..n_m)`：`A=∧A_i`，`G=∨G_i`，`I=∩I_i`；要求「对每个可达黑板态，至少一个子节点可被 tick，或存在到 SafeStop 的路径」；`J=max J_i`；`T=ΣT_i`。
- `Parallel(k)`：`A=∧A_i`，`G=(至少 k 个 G_i 成立)`，`I=∧I_i`，`J=⊕J_i`。
- 装饰器：`Timeout`/`Retry` 只增大 `T` 并显式记账；`Budget` 失败即 `Failure`（fail-closed）；`Evidence(k-of-n)` 未达 k 即 `Failure`；`Dwell` 增加驻留约束。
组合对 `⊑` 单调：子契约更强 ⇒ 父契约不更弱。

**定义 317（安全停叶子 SLM 与有界活性）** 叶子 `SafeStop` 满足 `I_safe⊆C_safe` 且前向不变，控制律为可达的停靠/阻尼。定义兜底响应时间 `T_fb`：从任意可达 `(B,τ)` 出发，根在至多 `T_fb` 个 tick 内要么 `Success`，要么 `SafeStop` 处于 `Running/Success`。**结构兜底可达**：每个 `Fallback` 节点至少有一条子路径通向 `SafeStop`，且每个 `Running` 节点都有 `Timeout`。

**定义 318（交互作为树节点）** `AskNode = Sequence(Guard(VoI_OC>c ∧ ECE≤τ_ece ∧ budget.allow), ExecuteInfo, Evidence(k-of-n), UpdateBelief)`。证据不足/预算越界 → `Failure` → 祖先 `Fallback` → R68 保守叶；交互动作仍须过 C-RAS-WM 前缀认证。R69 的整个 MINT/CIA 逻辑被折叠成一个可替换子树。

**定义 319（切换证书与无 Zeno）** 切换证书要求：(a) 只在承诺边界切换；(b) `τ_d` 驻留；(c) 滞回 `η>0`；(d) 安全集上值函数有界。定义切换计数 `N_sw(T)`；在 A100（安全集紧、`V` 有界、相邻模式值差有下界）下 `N_sw(T) ≤ min(T/τ_d, ΔV/η)`，故有限区间内切换有限，排除 Zeno。

**定义 320（多速率调度 MRS）** BT 决策频率 `f_BT`（如 20Hz），OC 控制频率 `f_OC`（如 200Hz），监控频率 `f_mon`。黑板带时戳与签名；定义陈旧度 `staleness`；BT 读取的数据必须 `staleness≤Δ_max`，否则 `Guard` 失败；OC 叶子在承诺窗口内按自身频率运行，只跟踪 BT 提交的 setpoint。承诺视界 `H_c` 与 R68 的 certified prefix 对齐。

**定义 321（结构风险预算 SRB）** 总风险预算 `ε_total`，沿树分配：`ε_total ≥ Σ_ℓ ε_ℓ + Σ_switch ε_sw + ε_mon + ε_stale + ε_unknown`。每个节点有配额；运行时记账；任何节点不得静默借用他人配额；超配额 → 主 Fallback → 保守。这把 R69 的「λ_floor 标量」升级为「沿结构可归因的风险账本」。

**定义 322（树感知运行时监控 TAM）** 每个节点运行时检查 `A/G/I` 与代价上界 `V̄`；违约 → `Halt` 当前子树 + 记录 + 向根传播 `Failure`。监控器必须**在树外独立调度**（看门狗），不得依赖被监控子树 tick，否则节点饿死会同时饿死监控。TAM 产出人类可读的 tick 轨迹与审计记录。

**定义 323（树特有威胁模型 ℰ_tree）** `ℰ_tree = {guard_spoof, node_starvation, fallback_flood, tick_replay, subtree_masquerade, contract_drift}`。并入 AIC：`ℰ_ARBOR = ℰ_FLUID × ℰ_tree`。对应缓解：签名黑板、超时、兜底速率限制与升级、nonce/时戳、证书链哈希、训练-运行契约对齐。

**定义 324（J_ARBOR 证书）** `J_ARBOR = (J_FLUID, tree_hash, node_certificates, switch_count, dwell_min, T_fb, contract_violations, srb_used, staleness_p99, arbor_ver)`。`Valid ⇔ Valid(J_FLUID) ∧ 所有活动节点契约 Valid ∧ N_sw 与 dwell 合规 ∧ T_fb≤T_fb^* ∧ srb_used≤ε_total ∧ 无未归因契约违约`。

**定义 325（R69/R68 的退化树 DEG）** `T_FLUID = Fallback(Sequence(Perceive, Disambiguate, Act), ConservativeLeaf)`；`T_CALM = Fallback(Sequence(Perceive, Calibrate, Act), ConservativeLeaf)`。当 `V̂≡0`、`s≡0`、`η=0`、`τ_d=0`、`VoI_OC=VoI_ent`、叶子动作取 R69 的 `mode.a` 时，`T_FLUID` 的 tick 序列与 R69 主闭环逐指令一致；再禁用 `AskNode` 即退化为 R68。

**定义 326（切换连续性）** 在承诺边界切换时，新旧叶子的首批控制共享同一 certified prefix，且切换前后 setpoint 差 `≤L_v·H_c`；定义控制跳变上界 `ε_cont`。驻留 + 滞回保证切换次数有界，因此累积跳变有界，闭环无突变。

**定义 327（树感知审计与解释）** 每个 tick 输出活动路径、被拒分支及原因、guard 真值、契约检查结果、风险账本增量。审计接口 `Explain(tick) → (path, why_not_alt, evidence)`；VQAuditor-I 升级为 `VQAuditor-T`，把交互决策审计扩展为「结构决策审计」。

## 2. 关键算法骨架

```python
# IP-264 CCT：带契约的行为树节点
class Node:
    contract: Contract          # (A, G, I, J, T)
    def tick(self, B, tau): ... # -> (status, B, tau, commitment)

class Sequence(Node):
    def tick(self, B, tau):
        for child in self.children:
            st, B, tau, k = child.tick(B, tau)
            if st != SUCCESS: return st, B, tau, k
        return SUCCESS, B, tau, None

class Fallback(Node):
    def tick(self, B, tau):
        for child in self.children:
            st, B, tau, k = child.tick(B, tau)
            if st == SUCCESS: return st, B, tau, k
            if st == RUNNING: return st, B, tau, k
        return FAILURE, B, tau, None

class Dwell(Node):              # 驻留装饰器：承诺窗口内不换分支
    def tick(self, B, tau):
        if tau - self.last_switch < self.tau_d and self.active:
            return self.active.tick(B, tau)
        st, B, tau, k = self.child.tick(B, tau)
        if st != RUNNING: self.last_switch = tau
        return st, B, tau, k

# IP-265 OCL：有限时域最优控制叶子（iLQR + CBF 滤波 + 值函数上界）
class OCLeaf(Node):
    def solve(self, x, warm):
        u = ilqr(self.f, self.c, x, self.H, warm)      # 暖启动 iLQR
        u = cbf_filter(u, x, self.C)                   # 安全集前向不变
        V_hat = self.V_net(x) + self.e_bound            # 悲观上界
        return u, V_hat

    def tick(self, B, tau):
        u, V_hat = self.solve(B.x, B.warm[self.id])
        B.commit(self.id, u[:self.H_c])                # 承诺前缀，供连续性
        return RUNNING, B, tau, Commitment(self.id, u[:self.H_c])

# IP-266 HSC：混合切换（值函数 + 切换成本 + 滞回 + 驻留）
def hybrid_switch(leaves, x, prev, tau, last_switch, eta, tau_d, H_c):
    cand = [(V_hat(l, x) + l.e + switch_cost(prev, l, x), l) for l in leaves]
    best, k = min(cand, key=lambda t: t[0])
    hold = (tau - last_switch < tau_d) or (best > cost(prev, x) - eta)
    k = prev if hold else k
    return k, (tau if hold else tau)

# IP-267 CGV：cost-to-go VoI（任务敏感，而不是熵敏感）
def voi_cost_to_go(g, x, belief, value_fn):
    gain = value_fn(x) - expected_y(value_fn, x, g, belief)   # E[V*(x)-V*(x|y)]
    return gain - cost(g)

# IP-268 CCA：契约组合
def compose(node, child_contracts):
    if isinstance(node, Sequence): return seq_contract(child_contracts)
    if isinstance(node, Fallback): return fallback_contract(child_contracts)
    if isinstance(node, Parallel): return parallel_contract(child_contracts)
    return decorator_contract(node, child_contracts)

# IP-275 主 tick（ARBOR = R69 的零件装进可认证的树）
def ARBOR_tick(M, B, tau):
    # 0) 树外看门狗先检查活性与陈旧度（定义 322）
    if M.watchdog.stale(B) or M.watchdog.starved(B, tau):
        return M.safe_stop.tick(B, tau)
    # 1) 根树：感知 -> 消歧/交互 -> 最优控制行动 -> 并行监控 -> 兜底
    st, B, tau, kappa = M.root.tick(B, tau)
    # 2) 活动叶子与切换（HSC）
    k_leaf, last_switch = M.hsc.select(M.active_leaves(B), B.x, M.prev_leaf, tau)
    # 3) 契约组合与结构风险预算
    cert = M.cca.compose(M.root, M.active_contracts(B))
    if not cert.valid() or M.srb.over_budget(B):
        st, B, tau,_ = M.safe_stop.tick(B, tau)       # 结构性回退
    # 4) 提交 certified prefix + 审计
    M.vqa_t.submit(B, k_leaf, cert, M.srb.snapshot())
    return k_leaf, cert, (st, B, tau, kappa)
```

## 3. 推导

**引理 19（契约组合的安全性）** 设树 `T` 的每个叶子在其假设 `A_ℓ` 下保持不变式 `I_ℓ`，且每个内部节点满足定义 316 的组合侧条件（Sequence 的 `G_i⇒A_{i+1}`、Fallback 的「至少一子可 tick 或可达 SafeStop」、Parallel 的联合不变式）。若根假设成立、`SafeStop` 的 `I_safe` 前向不变且结构兜底可达，则闭环在任意 tick 上满足 `I_root`；且从任意可达状态，至多 `T_fb` 个 tick 内要么根 `Success`，要么 `SafeStop` 活动。证明：对树高与 tick 归纳；叶子用各自不变式，内部节点用侧条件传递；活性用有界 tick 与结构兜底可达。**系**：组合认证把「整棵树安全」化归为「每个原子 + 每条组合规则」，不再需要信任单体黑箱。

**引理 20（cost-to-go VoI 的二次型展开）** 在 A99（值函数二阶可微、Hessian `H_V` 在安全集有界）下，对小信息量观测 `y`：
`E[V*(x|y)] ≈ V*(x) − ½ tr(H_V·(Σ_prior−Σ_post)) + O(‖ΔΣ‖²)`，
故 `VoI_OC ≈ ½ tr(H_V·ΔΣ) + O(‖ΔΣ‖²)`。而熵 VoI `≈ ½ tr(Σ_prior^{-1}ΔΣ)`。两者仅在 `H_V ∝ Σ_prior^{-1}` 时一致。**系**：任务不敏感方向（`H_V=0`）的信息价值为零；R69 的熵 VoI 会把宝贵的交互浪费在这些方向上，ARBOR 的 CGV 不会。

**引理 21（驻留-滞回排除 Zeno）** 在 A100（安全集紧、各模式 `V` 有界、切换优势有下界）下，每次切换要求优势至少 `η` 且距上次切换至少 `τ_d`，故 `N_sw(T) ≤ min(T/τ_d, ΔV/η)`。因此在任意有限区间内切换次数有限且切换时刻有正间隔，不存在 Zeno/抖振。**系**：R69 中 `select_mode` 在证据边界来回跳变的隐患被结构性排除。

**引理 22（交互预算的结构封闭性）** 若所有 `AskNode` 都被包在 `Budget(1,T)` 与 `Evidence(k-of-n)` 装饰器内，且 `Budget` 失败即 `Failure`（fail-closed），则无论树的分支如何组合、重试如何发生，单位时间内的信息动作数不超过 1，且单源回答无法通过 `Evidence`。**系**：R69 定义 293-ii/iii 的纪律从「代码约定」变成「树结构性质」。

**定理 18（ARBOR 严格包含 R69 与 R68）** 在 A99–A101 下，取退化树 `T_FLUID`（定义 325）：当 `V̂≡0`、`s≡0`、`η=0`、`τ_d=0`、`VoI_OC=VoI_ent`、叶子动作等于 R69 的 `mode.a` 时，ARBOR 的 tick 序列与 R69 主闭环逐指令一致；再令 `AskNode` 不可达即退化为 R68。故 R69/R68 是 ARBOR 在「无值函数、无切换成本、无驻留、无树结构」边界上的严格退化；安全侧因结构兜底不做让步，效率侧因 OC 与 CGV 获得增益。

**定理 19（组合安全 + 有界活性）** 在 A100–A102 下，若根契约由 CCA 组合得到且 `SafeStop` 由树外看门狗独立保证，则：(i) 闭环满足 `I_root`；(ii) 任意可达状态在 `T_fb` 个 tick 内进入 `SafeStop` 或成功；(iii) 任一叶子/监控契约违约只会触发祖先 `Failure` 与回退，不会直接进入未认证动作。证明：引理 19 + 看门狗独立性 + 定义 322 的传播规则。**系**：即使某个叶子在 OOD 下失效，失效被限制在子树内，根仍有结构性兜底。

**定理 20（切换连续性与无突变）** 在 A100、A103（承诺视界 `H_c`、setpoint Lipschitz `L_v`）下，所有切换只发生在承诺边界，且相邻叶子共享同一 certified prefix，故提交控制序列的跳变 `≤L_v·H_c≤ε_cont`；结合引理 21 的有限切换，闭环控制连续、无突变。R68 的换装不变式与 R69 的交互安全认证作为叶子/装饰器契约被保留。

**定理 21（兜底洪泛的可用性上界）** 若 `SafeStop` 进入受 `FallbackRate(F,T)` 限制，且连续 `F` 次兜底后升级到人类/远程接管，则对抗性 `fallback_flood` 在任意窗口 `T` 内最多造成 `F` 次安全停，之后系统进入显式降级而非无限停摆。**系**：安全性优先，但可用性损失有上界且可审计，避免「安全地永远不动」。

## 6. 本轮最大风险

**一句话**：ARBOR 的安全性建立在「每个叶子的值函数/契约在分布外仍然成立，且契约真的能组合」这一前提上——**一旦最优控制叶子外推错误、或黑板上某个 guard 被投毒，行为树会把「每个节点都通过认证」组合成「整棵树都安全」的错觉，系统可能沿一条每一步都合规的 fallback 路径，稳稳地停死或稳稳地走错，而审计日志上每一行都是绿的**；组合认证的盲区，比单体黑箱更难被发现。

**次级风险与缓解**：
1. **值函数近似误差导致错误切换** → 用悲观上界 `V̂+e`、CBF/鲁棒 MPC、驻留与滞回（引理 21、定理 20）；
2. **组合认证盲区** → 契约代数 + 结构风险预算 SRB + 运行期 TAM，任何未归因违约即回退（定义 316/321/322）；
3. **节点饿死/guard 欺骗** → 树外独立看门狗、签名黑板、超时、tick nonce（定义 320–323）；
4. **兜底洪泛的可用性 DoS** → `FallbackRate` + 升级接管，安全性不让步但可用性损失有界（定理 21）；
5. **多速率失配/陈旧观测** → 时戳 + 陈旧度门 + 承诺视界 `H_c` 与 R68 certified prefix 对齐（定义 320、定理 20）；
6. **行为树使攻击面更「结构化」** → ℰ_tree 对抗训练 + 证书链哈希 + 子树伪装检测（定义 323、E315）。

**定义 315（CGV）** `VoI_OC(g)=E[V*(x)−V*(x|y)]−c(g)`；二次型近似下 `VoI_OC≈½tr(H_V·ΔΣ)`，只有任务敏感方向值钱；熵 VoI 是 `H_V∝Σ^{-1}` 的特例。

**定义 316（CCA）** Sequence：`G_i⇒A_{i+1}`；Fallback：至少一子可 tick 或可达 SafeStop；Parallel：联合不变式；装饰器 fail-closed；组合对契约偏序 `⊑` 单调。

**定义 317（SLM/有界活性）** SafeStop 前向不变；任意可达状态在 `T_fb` 内成功或 SafeStop 活动；每个 Fallback 有到 SafeStop 的路径，每个 Running 有 Timeout。

**定义 318（AskNode）** `Sequence(Guard(VoI_OC>c ∧ ECE≤τ_ece ∧ budget.allow), ExecuteInfo, Evidence(k-of-n), UpdateBelief)`；失败 → 祖先 Fallback → R68 保守叶。

**定义 319（无 Zeno）** 承诺边界切换 + `τ_d` 驻留 + `η` 滞回 + 值函数有界 ⇒ `N_sw(T)≤min(T/τ_d,ΔV/η)`。

**定义 320（MRS）** BT 20Hz、OC 200Hz、监控独立；黑板时戳/签名；`staleness>Δ_max` ⇒ guard 失败；OC 在承诺窗口跟踪 setpoint。

**定义 321（SRB）** 风险预算沿树分配、运行期记账、禁止静默借用；超配额 → 主 Fallback → 保守。

**定义 322（TAM/VQAuditor-T）** 树外看门狗 + 节点违约传播 + 人类可读 tick 轨迹；审计结构决策（为何走/为何不走/证据）。

**定义 323（ℰ_tree）** `ℰ_ARBOR=ℰ_FLUID×ℰ_tree`；缓解：签名黑板、超时、兜底速率限制与升级、nonce/时戳、证书链哈希、契约对齐。

**定义 324–327（证书/退化/连续性/解释）** `J_ARBOR` 并入树哈希、节点证书、切换/驻留/响应/违约/SRB；`T_FLUID`/`T_CALM` 在退化参数下逐指令等于 R69/R68；切换共享 certified prefix，跳变 `≤L_v·H_c`；`Explain(tick)` 输出活动路径与被拒分支原因。

## 3. 关键算法伪代码

```python
# IP-264 CCT：带契约行为树
class Node:
    contract: Contract                     # (A,G,I,J,T)
    def tick(self, B, tau): ...            # -> (status,B,tau,commitment)

class Sequence(Node):
    def tick(self, B, tau):
        for c in self.children:
            st,B,tau,k = c.tick(B,tau)
            if st != SUCCESS: return st,B,tau,k
        return SUCCESS,B,tau,None

class Fallback(Node):
    def tick(self, B, tau):
        for c in self.children:
            st,B,tau,k = c.tick(B,tau)
            if st in (SUCCESS,RUNNING): return st,B,tau,k
        return FAILURE,B,tau,None

class Dwell(Node):                         # 驻留：承诺窗口内不换分支
    def tick(self, B, tau):
        if tau-self.last_switch < self.tau_d and self.active:
            return self.active.tick(B,tau)
        st,B,tau,k = self.child.tick(B,tau)
        if st != RUNNING: self.last_switch = tau
        return st,B,tau,k

# IP-265 OCL：最优控制叶子
class OCLeaf(Node):
    def solve(self, x, warm):
        u = cbf_filter(ilqr(self.f,self.c,x,self.H,warm), x, self.C)
        return u, self.V_net(x)+self.e_bound
    def tick(self, B, tau):
        u,V = self.solve(B.x, B.warm[self.id])
        B.commit(self.id, u[:self.H_c])    # 承诺前缀
        return RUNNING,B,tau,Commitment(self.id,u[:self.H_c])

# IP-266 HSC：混合切换
def hybrid_switch(leaves, x, prev, tau, last_switch, eta, tau_d):
    best,k = min(((V_hat(l,x)+l.e+switch_cost(prev,l,x),l) for l in leaves),
                 key=lambda t:t[0])
    hold = (tau-last_switch < tau_d) or (best > cost(prev,x)-eta)
    return (prev if hold else k), (last_switch if hold else tau)

# IP-267 CGV：cost-to-go VoI
def voi_cost_to_go(g,x,belief,V):
    return (V(x)-expected_y(V,x,g,belief))-cost(g)   # 只问对任务代价有用的

# IP-268 CCA：契约组合
def compose(node, child_contracts):
    return {Sequence:seq_contract, Fallback:fallback_contract,
            Parallel:parallel_contract}.get(type(node),
            lambda c: decorator_contract(node,c))(child_contracts)

# IP-276 主 tick
def ARBOR_tick(M, B, tau):
    if M.watchdog.stale(B) or M.watchdog.starved(B,tau):   # 树外看门狗
        return M.safe_stop.tick(B,tau)
    st,B,tau,kappa = M.root.tick(B,tau)                    # 感知→消歧→行动→监控
    k,last = M.hsc.select(M.active_leaves(B),B.x,M.prev_leaf,tau)
    cert = M.cca.compose(M.root, M.active_contracts(B))
    if not cert.valid() or M.srb.over_budget(B):
        st,B,tau,_ = M.safe_stop.tick(B,tau)               # 结构性回退
    M.vqa_t.submit(B,k,cert,M.srb.snapshot())
    return k,cert,(st,B,tau,kappa)
```

## 4. 推导

**引理 19（契约组合安全性）** 叶子在各自假设下保持不变式、内部节点满足组合侧条件、SafeStop 前向不变且结构兜底可达 ⇒ 任意 tick 满足 `I_root`，且任意可达状态在 `T_fb` 内成功或进入 SafeStop。系：整树安全化归为原子契约 + 组合规则，无需信任单体黑箱。

**引理 20（cost-to-go VoI 的二次型展开）** A99 下 `E[V*(x|y)]≈V*−½tr(H_V·ΔΣ)`，故 `VoI_OC≈½tr(H_V·ΔΣ)`；熵 VoI `≈½tr(Σ^{-1}ΔΣ)`。二者仅在 `H_V∝Σ^{-1}` 时一致。系：任务不敏感方向（`H_V=0`）信息价值为零，R69 的熵 VoI 会在此浪费交互。

**引理 21（驻留-滞回排除 Zeno）** A100 下每次切换需优势 `≥η` 且间隔 `≥τ_d`，故 `N_sw(T)≤min(T/τ_d,ΔV/η)`，有限区间内切换有限，无 Zeno/抖振。

**引理 22（交互预算结构封闭）** 所有 AskNode 包在 fail-closed 的 `Budget(1,T)` 与 `Evidence(k-of-n)` 内 ⇒ 单位时间信息动作 ≤1，单源回答不能通过；R69 定义 293-ii/iii 从代码约定变成树结构性质。

**定理 18（严格包含 R69/R68）** 退化树 `T_FLUID` 在 `V̂≡0,s≡0,η=0,τ_d=0,VoI_OC=VoI_ent`、叶子动作取 R69 `mode.a` 时逐指令等于 R69；禁用 AskNode 即退化为 R68。安全侧因结构兜底不让步，效率侧因 OC/CGV 获益。

**定理 19（组合安全 + 有界活性）** A100–A102 下，根契约由 CCA 组合且 SafeStop 由树外看门狗独立保证 ⇒ 闭环满足 `I_root`、`T_fb` 内进入 SafeStop 或成功、叶子/监控违约只触发祖先回退不进入未认证动作。

**定理 20（切换连续性与无突变）** A100/A103 下，切换只在承诺边界、共享 certified prefix ⇒ 控制跳变 `≤L_v·H_c≤ε_cont`；结合引理 21 有限切换 ⇒ 控制连续、无突变；R68 换装不变式与 R69 交互安全认证作为叶子/装饰器契约保留。

**定理 21（兜底洪泛可用性上界）** SafeStop 进入受 `FallbackRate(F,T)` 限制，连续 F 次后升级人类/远程接管 ⇒ 任意窗口内最多 F 次安全停，之后显式降级而非无限停摆；安全性优先，可用性损失有界且可审计。

## 7. 本轮最大风险

**一句话**：ARBOR 的安全性建立在「每个叶子的值函数/契约在分布外仍成立，且契约真的能组合」这一前提上——**一旦最优控制叶子外推错误、或黑板上某个 guard 被投毒，行为树会把「每个节点都通过认证」组合成「整棵树都安全」的错觉，系统可能沿一条每一步都合规的 fallback 路径稳稳地停死或稳稳地走错，而审计日志上每一行都是绿的**；组合认证的盲区比单体黑箱更难被发现。

**次级风险与缓解**：值函数近似误差（悲观上界 `V̂+e` + CBF/鲁棒 MPC + 驻留滞回）；组合认证盲区（CCA + SRB + TAM，未归因违约即回退）；节点饿死/guard 欺骗（树外看门狗 + 签名黑板 + 超时 + nonce）；兜底洪泛（FallbackRate + 升级接管，定理 21）；多速率失配（时戳 + 陈旧度门 + 承诺视界对齐 R68 prefix）；树结构化攻击面（ℰ_tree 对抗训练 + 证书链哈希 + 子树伪装检测）。
