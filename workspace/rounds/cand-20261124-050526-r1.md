## 1. 两个灵感的第一性原理

### 灵感 1 ·「共享控制」→ 从「硬切换栈」升级为「权威混合 + 安全过滤」

**直觉**：第 1–3 轮的执行栈本质上是一条 `if/else` 硬门链——断言通过就跑策略，失败就介入，状态层失效就退化。硬门在边界上必然抖：要么全信策略、要么全信伺服/介入，切换瞬间动作跳变，且「部分可信」无处安放。共享控制的直觉是：**永远没有「谁接管」，只有「各源此刻各占多少权威」**；安全不靠提前判死，而靠一个永远在线的安全集合把混合后的动作投影回去。

**严谨化**（U19/U20、L14/L15）：
- **权威向量替代布尔门**：连续动作流上 `a_raw = Σ_k w_k a_k`，`w ∈ Δ^{K-1}`；硬切换只是 `w` 退化为 one-hot 的极限。于是「策略 / 伺服 / 重定位 / 保持 / 让步」全部变成同一总线上的**源**，IP-02/09/13/15 不再互相 if-else。
- **离散选项不可平均**：抓哪、去哪个路标是**选项**不是向量，凸组合两个合法抓姿会得到「既不可抓也不可达」的伪动作。故 U19 明确二分：**连续流做权威混合，离散选项做带驻留/滞回的软选择**——这是本轮最重要的形式约束（见 §5 最大风险）。
- **安全过滤是最外层硬约束**：`a_t = Π_{A_safe}(a_raw)`。凸安全集上的二次投影恰是「最小干预」——原始动作安全就原样放行，不安全才按最小距离拉回（L15）。这把「安全」从**概率性预判**变成**可证明的集合不变性**，并把步骤分损失限定在约束真正激活的时刻（P14）。
- **人不是要合作的共享者，而是「对抗性权威主张者」**：评测里的人是干扰源，不能假设其意图可推断。共享控制在此的正确转译不是「猜人要什么」，而是「人只拥有对**安全包络**的否决权，不拥有对任务目标的投票权」——接触→让步、遮挡→保持、位移→重定位，全部实现为安全权威的**最小激活**（U20），而非任务层硬切。

**策略含义**：第 3 轮的状态层回答「现在信什么」，本轮的总线回答「信多少、怎么平滑地用」。它把第 1–3 轮所有硬门统一成「可调权威 + 安全集合」的一次架构收口；硬切换降级为总线在安全失效时的 Level-1.5 回退形态，系统不新增单点故障。

### 灵感 2 ·「数据集构建」→ 原始数据不产生价值，**标注编译**才产生价值

**直觉**：语料从「暂停」变成「放量」，但放出来的是 `parquet + mp4` 的**原始轨迹**，没有一项直接标注了「这是滑移」「此刻该重定位」「这个源更可信」。VLA 的瓶颈从来不是帧数，而是**每帧对哪个模块有用**。因此「数据集构建」的正确定义不是「多收数据」，而是**造一台把原始轨迹 + 仿真真值编译成模块级监督的编译器**。

**严谨化**（U21、L16）：
- **标签是编译产物**：编译器 `C: (τ, GT_sim?) → {l_state, l_slip, l_arb, l_fail}`。官方 USDS 场景第一次给了「对象位姿/接触/可分支动力学」的真值源，使 `l_slip`（相对位姿漂移）与 `l_state`（场景图）从人工标注变成**真值导出**；`l_arb` 用**分支反事实**（同一状态让不同源执行、回放结果）生成。
- **反事实仲裁数据集（新数据类型）**：在一批状态上分别执行策略/伺服/重定位/保持，记录结果并标出「事后最优权威」。它不是示范、是**裁决**——第 1–3 轮完全没有。IP-16 的仲裁器由此训练，而非拍权重。
- **数据选择是子模最大化**：标注预算有限，按「边际失败覆盖率 / 标注成本」贪心选集；覆盖率函数子模 ⇒ 贪心有 `(1−1/e)` 保证（L16）。这把「该标哪 1000 条」从直觉变成可计算的排序。
- **跨本体归一化是构建前置**：Dex1（16 维 / 4 相机 / 有腕）与 Brainco（26 维 / 2 相机 / 无腕）不能混池直训。构建前先定义规范动作空间与传感器掩码，否则「更多数据」会以负迁移出现（IP-18）。
- **域差纪律**：248 条 G1 通用语料 ≠ 32 项挑战任务。标签编译器必须在**留任务**（leave-task-out）切分上验证可迁移性，通用语料只做预训练/课程，不用来直接拟合挑战分布。

**策略含义**：第 3 轮把「未知物体」变成档案问题；本轮把「更多数据」变成**可复用监督**问题——谁的编译器能把同一批原始轨迹压出更多模块级标签，谁才真正吃到这波放量。

## 3. 设计原则（新增 P13–P15，接第 1–3 轮 P1–P12）

- **P13（软仲裁，非硬切换）**：在线控制一律表达为「权威分配 + 安全过滤」；连续流可凸混合，离散选项只可软选择+驻留；硬切换是 `w∈{0,1}` 的极限，仅在安全过滤不可用（Level-1.5）时回退。
- **P14（最小干预）**：安全权威仅在安全约束激活时启用，其余时刻任务权威最大化；任何为「稳妥」而常开的保守动作必须过步骤分账（与 P12/L13 合并核算），否则不许上线。
- **P15（标注即数据）**：任何数据新增必须声明目标模块、标注保真度、边际价值/成本；无模块级标签的原始轨迹不计入数据资产，只计为待编译库存。

## 5. 本轮最大风险

**共享控制的「混合谬误」——把离散决策（抓哪个、去哪个路标、是否让步）当连续向量做凸组合，会生成既不可抓也不可达的伪动作，比任何单一源的失败都更隐蔽、更难诊断。** 对冲：①U19 强制二分「连续流 / 离散选项」，离散侧只做带驻留的软选择、绝不平均位姿；②安全过滤作为最外层硬投影，仲裁器无权越过安全集；③E634 预注册「伪动作率 = 0」门槛，未达标则离散侧完全退回硬选择、只保留连续流混合。次要风险：反事实数据集的 sim-to-real 偏差使仲裁器在真机过拟合仿真（缓解：只学相对权威、限幅、真数据校准）；通用语料与 32 项任务域差导致标注编译白做（缓解：留任务验证 + 只做预训练）。

## 3. 新增 IP 详述

### IP-16 · SharedAuthority 权威总线 + 安全过滤 + 对抗性让步（P0，新）

- **动机**：v3 的断言/介入/退化是硬门，边界抖动与「部分可信」缺失；人干扰轴用硬状态机切换，切换瞬间动作不连续且步骤分受损。共享控制提供「权威连续分配 + 安全集合投影」的统一形式，是把整栈收口的正确抽象。
- **与现有方案差异**：v3 是「选择器选一个源」；v4 是「在安全集内按权威混合源」。关键差异在离散决策——不做向量平均，而做带驻留的软选择（避免混合谬误）。
- **技术可行性**：高。安全投影为小规模 QP（关节速度/EE 速度 + 线性化 CBF 约束），单步 <1 ms；仲裁器为轻量 MLP/GBDT（输入=不确定度、源分歧、安全裕度、阶段）；无新大模型。
- **资源**：数据=IP-17 的 `l_arb`；算力=小（在线）；接口=策略内部，无新增字段（合规）。
- **落地步骤**：①定义源接口（每个源输出连续动作 + 不确定性/置信）；②连续流凸混合 + 离散选项软选择（softmax + dwell time + 滞回）；③安全集合与 QP 投影（关节限位/自碰撞/CBF）；④仲裁器训练（IP-17 反事实标签，交叉熵/成对排序）；⑤干扰源接入并做「最小激活」；⑥E634 A/B + 伪动作率审计。
- **风险**：混合谬误（离散侧伪动作）；仲裁器过拟合 sim 反事实；安全集合建模不全（漏约束）。对冲见 §10。

### IP-17 · DataFoundry 标签编译器 + 反事实仲裁集 + 子模选集（P1，新）

- **动机**：语料放量但只有原始 parquet+mp4；官方 USDS 首次提供对象/场景真值。价值应体现在「同一批轨迹能编译出多少模块级监督」，而非帧数。
- **与现有方案差异**：v3 数据线（IP-10/IP-12）只用现成负样本与课程；v4 增加**标签编译器**与**反事实裁决数据**两种全新产物，且用子模选集替代人工挑数据。
- **技术可行性**：中高。`l_state/l_slip` 由 USDS 真值 + 现成检测/跟踪导出；`l_arb` 需在 sim 分支执行（费用高，故用子模选集控制预算）；`l_fail` 由阶段完成度/回放自动判定。
- **资源**：USDS（apache-2.0）+ 248 G1 语料 + 32 挑战（评测用）+ 中算力（分支 rollout 是主要开销）。
- **落地步骤**：①统一 episode schema（LeRobot v3 已定，16/26 维、相机键不同→交 IP-18）；②`l_state` 导出（对象位姿/掩膜/参考系）；③`l_slip` 导出（相对位姿漂移→滑移标签）；④`l_arb` 反事实分支器（每状态 4 源×结果，落盘）；⑤`l_fail` 阶段判定；⑥子模选集（覆盖失败模式、成本=标注/rollout 步数）；⑦留任务验证域差。
- **风险**：sim-to-real 偏差污染 `l_arb`；标签误差沿级联放大；通用语料与 32 项域差导致伪增益。

### IP-18 · EmbodimentNormalizer 跨本体归一化（P1，新）

- **动机**：新语料跨 Dex1（16 维/4 相机/有腕）、Brainco（26 维/2 相机/无腕）、Inspire；直接混池会负迁移，且 IP-14 的腕部滑移在无腕本体不可用。
- **差异**：定义**规范动作空间**（EE 位姿增量 + 夹爪标量 + 可选手指模式）与**传感器掩膜**，每本体一个轻量适配头；下游模块只吃规范表示。
- **可行性**：高。LEFRobot v3 schema 已含 state/action/相机键；归一化以 EE 空间为公共锚。
- **资源**：新多末端语料即可，算力小。
- **步骤**：①本体描述表（维数/相机/手型）；②动作映射（关节/末端→规范 EE 增量）；③传感器掩膜（无腕→滑移源标记 unavailable，走 Level-1.6 类降级）；④每本体适配头 + 共享主干；⑤E638 跨末端迁移。
- **风险**：映射不可逆/丢手指细节；归一化掩盖本体特有能力；掩膜导致模块静默失效（必须显式降级而非静默）。

## 5. 符号与定义（新增 U19–U21；U1–U18 沿用第 1–3 轮）

- **定义 U19（共享控制权威分配）**：状态 `x` 下源集 `{a_k}_{k=1..K}`，权威 `w∈Δ^{K-1}`。**连续流**动作 `a_raw=Σ_k w_k a_k`；**离散选项**集 `O` 按 `π(o)=softmax_k(w_k/τ)` 逐驻留窗选择（不平均位姿）。最终 `a_t=Π_{A_safe(x)}(a_raw)`。硬切换为 `w∈{0,1}^K` 的极限；安全过滤不可用时退回 Level-1.5b。
- **定义 U20（对抗性权威 / 最小激活）**：干扰事件 `e∈{occlusion,target_moved,distractor_added,contact}` 只主张对**安全包络**的否决，不参与任务目标投票。安全权威 `w_safe(t)` 为满足 `h_j(x,u)≥0` 的**最小**修正量（QP 解 `argmin_w ||w||` s.t. 约束成立）；任务权威在约束不激活时取满。响应映射 `π_I(e)` 为 U20 的特例：保持=维持当前选项+冻结任务权威；重定位=切到重定位源；入图=更新 IP-13 场景图；让步=安全权威临时置满。
- **定义 U21（标签编译器 / 数据构造）**：编译器 `C:(τ,GT_sim?)→L`，`L={l_state,l_slip,l_arb,l_fail}`。数据价值 `V(A)=E_{τ~D}[Σ_module ΔM_module(C(τ))]/cost(A)`，`A` 为标注/rollout 选集；在覆盖率子模假设下按边际 `V` 贪心选 `A*`，得 `(1−1/e)` 近似（L16）。

```python
# ===== IP-16: 权威总线（连续流混合 + 离散选项软选择）=====
def control_step(state, sources, options, x):
    # 1) 连续流：按不确定度先验 + 仲裁器修正分配权威
    w = state.authority_prior()                 # w_k ∝ exp(-sigma_k / TAU)
    w = ARBITER.mix(w, features(state, sources))# 学习仲裁（IP-17 数据训练）
    a_raw = sum(w[k] * sources[k].act(x) for k in sources)
    # 2) 离散选项：绝不平均位姿，只软选择 + 驻留/滞回
    if options:
        o = select_option(options, pi=softmax(w, tau=TAU_OPT), dwell=DWELL)
        a_raw = options[o].act(x) if options[o].is_primary else blend_streams(...)
    # 3) 最外层安全投影（最小干预）
    a_safe = project_qp(a_raw, A_safe(x))       # CBF/关节限位/自碰撞
    return a_safe
```

```python
# ===== IP-16: 最小干预安全过滤（QP）=====
# min ||u - a_raw||_Q^2  s.t.  u ∈ [u_min,u_max],  ḣ_j(x,u) + gamma*h_j(x) >= 0
def project_qp(a_raw, cons):
    u = solve_osqp(H=Q, f=-Q@a_raw, A=cons.A, l=cons.l, u=cons.u)
    return u if u is not None else FAILSAFE_HOLD   # 不可行→保持（Level-1.5b 触发）
```

## 7. 推导（新增引理 L14–L16；L1–L13 沿用第 1–3 轮）

**引理 L14（权威斜坡的抖动上界）** 设各源动作逐帧变化有界、切换时硬切跳变为 `D`。若用 `M` 步把权威从 one-hot 线性过渡到目标分布，则每步动作变化 ≤ `D/M + 源漂移`；取 `M ≥ D/J_budget` 即可保证边界 jerk 不超预算。且若源集凸、`A` 凸，则任意 `w∈Δ` 的混合仍在源凸包内。⇒ **软仲裁可按预算连续调平滑度**；但该结论只对连续流成立，离散位姿不在凸包语义内（故 U19 二分）。∎

**引理 L15（最小干预安全投影）** 设 `A_safe` 凸、代价为严格凸二次 `||u−a_raw||_Q²`。则 `u*=Π_{A_safe}(a_raw)` 唯一，且 `a_raw∈A_safe ⇒ u*=a_raw`；干预幅度 `||u*−a_raw||` 随违规程度单调不减。⇒ **安全过滤「只在必要时介入」，且介入量可微**——这给 P14 一个可证明的实现，并把步骤分损失严格限定在约束激活区间。∎

**引理 L16（数据选集的贪心保证）** 若模块收益对标注集的边际递增满足子模性（覆盖/边际递减），在基数预算 `|A|≤B` 下，按 `V` 边际贪心选出的 `A_g` 满足 `V(A_g) ≥ (1−1/e)·max_{|A|≤B} V(A)`。⇒ **DataFoundry 的「边际价值/成本」排序有近似最优保证**；若成本异质，用价值/成本贪心得相应加权版本。∎
