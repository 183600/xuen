# 第 70 轮（承接第 69 轮「FLUID-RAS」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「大语言模型」×「共情表达」）

> R69 给了闭环一张嘴：把 epistemic 歧义交给「看 / 问 / 触」，用流匹配策略显式表示多模态动作，用 VoI 决定值不值得问，再用「k 个正交证据源一致」防止被单次回答骗。但 R69 的人类模型仍是一个**诚实的、被动的传感器**：问句只是 `g_ask` 经冻结 LLM 解码出的字符串，回答被当作对世界状态 `M` 的带噪观测。它没有建模三件真实交互中必然发生的事：
> 1. **同一内容，不同说法，会得到不同回答**（框架效应）。「杯子在左边吗？」与「我有点不确定，能帮我看一下左边那个是不是杯子吗？」在信息上近似等价，在人类回答分布上并不等价。
> 2. **人类不是只读传感器，而是有情绪、认知负荷与社交目标的行动者**。焦虑、疲劳、被冒犯、被喜欢，都会改变回答的准确率、披露意愿与纠错意愿。R69 的「问」假设人会尽力答对；R70 必须假设人会**按自己的效用答**。
> 3. **LLM 的语言能力是双刃的**。它能让机器说得体贴、清楚、像在理解你；但它也在「让人满意」这一目标上被训练过，天然倾向于附和、过度归因情绪、生成听起来合理却无接地根据的共情话术。把 LLM 放进交互回路，等于把一个**讨好型人格**接进了证据链。
>
> 核心命题：**不要问「机器能不能共情」，而要问「共情表达作为一条通信通道，是否可校准、可证伪、不可操纵」。** 把共情拆成三层并严格分离职权：
> - **事实层**（世界状态 `M`、用户情绪 `A`）：只能由非语言、可校准的接地模型估计，LLM 无权作证；
> - **语用层**（同一命题的共情说法 `q_e`）：交给 LLM 实现，但必须通过「内容保持 + 无诱导 + 真诚性许可」三重门；
> - **价值层**（用户想要什么、是否同意、是否安全）：只能由显式内容通道更新，**情绪永远不能当作同意**。
>
> 命名 **EMPATH-RAS**（Empathic Multimodal Policy with Affect-grounded Truthfulness and Honesty）。一句话定位：R69 问「我该向谁求证」，R70 问「**求证时，我该怎么说，才不会把答案污染成我想听的版本**」——共情不是更软的刹车，而是一条需要做对照实验的测量通道。

## 0. 承接：R69 的「嘴」缺一个「对照实验」

R69 的证据纪律是「至少两个正交证据源一致」。它防的是**单源欺骗**，但没防**共同原因欺骗**：如果机器人的问法本身就让人类倾向于给出某个答案，那么「看」和「问」这两个证据源可能一起被问法带偏，正交性在因果上并不成立。共情表达恰好是最强的共同原因：一句体贴的话可以同时提高回答的流畅度、配合度和**附和度**。

因此本轮的第一性原理不是「让机器更会共情」，而是：

**共情表达是一个 treatment（干预），不是一段文案。** 要估计它对「关于世界的信念」的因果效应，必须像做实验一样，对同一内容做中性/共情的对照，把「信息增益」与「讨好偏差」拆开。没有对照的共情，只是把 R69 的「诚实的不知道」升级成「被喜欢的确信」。

## 1. 直觉与动机

**灵感 1（大语言模型 → 语言先验让「说法」成为可优化变量）**
直觉：R69 的 `g_ask` 只是一个软提示，LLM 解码出问句，问句的内容与语气被混在一起。LLM 的真正价值不是「知道答案」，而是它编码了大量**语用知识**：如何礼貌地请求、如何承认不确定、如何降低对方的认知负担、如何在不同文化下保持得体。把这部分能力显式化为动作 `g_e`，系统就能在「问什么」之外优化「怎么问」。但语言先验也带来一个必须切断的通道：LLM 会**根据措辞反推情绪**，也会**为了取悦用户而调整事实**。因此 LLM 只能做「表达实现器」，不能做「事实估计器」。

**灵感 2（共情表达 → 不是情绪状态，而是改变对方策略的动作）**
直觉：共情在人类交互中不是「我感受到你的感受」这句内心独白，而是一组可观察的动作：眼神停留、语调放缓、先复述再提问、给对方留出拒绝/纠正的空间、在对方疲惫时缩短问题。它们改变的不是世界状态，而是**对方的回答策略**。这与 R69 的信息动作同构，但作用对象从「世界」变成「人」：注视让世界暴露几何，共情让人暴露信念。把人建模为 agent 后，交互从 POMDP 升级为**交互式 POMDP / 心理博弈**。

**灵感 3（共情是双刃剑 → 信息增益 vs 讨好偏差）**
直觉：共情说法既能让人更愿意说真话（降低防御、降低认知负荷），也能让人说你想听的话（讨好、顺从、避免冲突）。两者在观测上常常同向：用户更配合、回答更流畅，但**配合不等于信息**。所以不能以「用户满意度」作为共情的 KPI；必须用**因果对照**把「信息通道」与「说服通道」分开：同一个内容，随机用中性/共情两种说法问，若答案系统性改变，则这条答案对措辞不稳健，不能当作关于 `M` 的独立证据。

**灵感 4（LLM 的讨好性 → 用「内容保持」和「无证据权」上锁）**
直觉：LLM 生成共情话术时，最容易犯的错不是语法，而是**偷偷加了内容**：把「请确认左边是不是杯子」说成「我知道左边是杯子，对吧？」——后者预设了答案，是诱导。必须用非 LLM 的双向蕴含验证器保证 `q_e ↔ q_0`，并禁止任何评价性/承诺性附加内容。更进一步，LLM 的输出文本**不得回灌**到情绪估计或世界估计里，否则会形成「自己说自己共情 → 自己相信用户感动 → 自己更自信」的自证循环。

**灵感 5（共情剂量 → 太少和太多都坏）**
直觉：共情不是越多越好。太少显得冷漠，用户不愿配合；太多则增加认知负荷、显得操纵、甚至诱发依赖。存在一个**治疗窗**：在用户当前负荷下，恰好足够建立合作、又不至于淹没信息。把它形式化为剂量 `d_e` 与 U 形成本，和 R69 的交互预算合并。

**灵感 6（理论姿态 → R70 必须严格包含 R69）**
直觉：任何不能逐指令退化为 R69 的「共情层」都是一个新的信任根。EMPATH-RAS 的定位是：**中性问法 = R69 的边界情形**；当共情没有净信息增益、真诚性不足、框架不稳健、或触碰操纵预算时，系统必须回到 R69 的中性提问与保守退避。安全侧不让步，效率侧才谈共情收益。

**灵感 7（一个反直觉推论 → 共情可能让系统「更不礼貌」地正确）**
直觉：如果 CFT 发现用户对共情措辞高度敏感（χ 高），那么最优策略可能不是「更温柔地问」，而是「更中性、更结构化地问」，甚至把问题改成可验证的二选一。共情的价值不由机器人的表达欲决定，而由**这条人类通道在当前状态下能承载多少可校准信息**决定。这与 R69 的「可分性越大，交互越值钱」同构：**可校准性越大，共情越值钱。**

## 2. 形式化定义（增量：定义 310–324）

**定义 310（EMPATH-RAS 总览与三不变式）** EMPATH-RAS = (GAM, AUD-A, EAX, LEX, SIN, CFT, VoI-E, MBB, LEG, VQAuditor-E, AIC-E, RAS-WM§)。三不变式：
(i) **事实与表达分离**：LLM 只生成表达表面，不得作为 `M` 或 `A` 的证据来源；
(ii) **情绪不等于价值**：`A` 不得更新价值后验 `V`，尤其不得作为同意、许可、安全或不停止的依据；
(iii) **逐指令可退化**：共情门失败时，行为与 R69 中性基座逐指令相同（定义 322）。

**定义 311（人类作为带情绪的行动者）** 人类隐状态 `H = (A, b_H, u_H, V)`：`A` 为情绪/负荷，`b_H` 为任务信念，`u_H` 为交互效用，`V` 为价值偏好。回答 `Y ~ π_H(· | M, A, b_H, g_e)`，其中 `g_e` 可同时影响 `A` 与 `b_H`。机器人目标是估计 `M`，不是最大化 `u_H`；「让人满意」与「知道真相」在本轮中显式分离。

**定义 312（接地情绪模型 GAM）** `A = (v, r, u_h, e, c)`：valence、arousal、任务困惑、参与度、认知负荷。`p_ψ(A|o)` 只由非语言通道（面部、语音韵律、姿态、交互时序、任务上下文）估计；LLM 文本/logits 不进入证据集。校准要求 `ECE ≤ τ_A`，并输出可靠区间。

**定义 313（情绪不确定性二分 AUD-A）** `U_A^ale = E[模态内熵]`（矛盾情绪、噪声，不可约）；`U_A^epi = H(情绪假设)`（可约）。只有 `U_A^epi` 可以触发「再观察/再问」；`U_A^ale` 进入保守通道。注意它与 R69 的 `U_ale/U_epi`（动作模态）是两个不同对象，不求和，只在回答通道处耦合。

**定义 314（共情动作 EAX）** `g_e = (g_face, g_voice, g_phrase, g_timing, g_space, d_e) ∈ 𝒜_emp`：面部、语调、措辞、时机、个人空间、剂量。增广动作 `ξ = (a, g, g_e) ∈ 𝒜_+`。`g_e` 必须通过与任务动作相同的 C-RAS-WM 前缀认证，并额外满足：不惊吓、不侵入个人空间、不阻断退出、不制造时间压力。

**定义 315（LLM 表达实现 LEX）** 给定内容种子 `q_0`（R69 MINT 选出的「问什么」）与接地情绪 `Â`，`q_e = LEX(q_0, Â, style)`。四道门：
(a) **内容保持**：`V(q_e, q_0)` 双向蕴含通过，且答案选项/指代对象不变；
(b) **无诱导**：非 LLM 检查器拒绝 `q_0` 中不存在的前预设、评价、承诺或情绪断言；
(c) **真诚许可**（定义 317）；
(d) **无证据权**：`q_e` 的文本不回灌 `M/A` 的估计。

**定义 316（框架因果图与 CFT）** 因果图 `g_e → A → Y`，`g_e → Y`，`M → Y`，`A ← A_0`。对同一 `q_0` 随机化中性/共情两种说法，定义：
- 框架敏感度 `χ(g_e) = P(Y 改变 | do(g_e), do(neutral), 同一 M)`；
- 框架偏差 `B(g_e) = E_M KL(p(Y|M, do(g_e)) || p(Y|M, do(neutral)))`；
- 任务信息 `I(M;Y | do(g_e))`。
若 `χ ≤ τ_χ`，称该回答**框架稳健**；否则降权/重问/丢弃。R69 的「k 个正交源一致」升级为「**正交 + 框架稳健**」。

**定义 317（真诚性许可 SIN）** 表达 `e` 含情绪命题 `φ_e`（如「我理解你现在很着急」）。许可度 `license(e) = P(φ_e | o, GAM)` 的置信下界 `≥ τ_s`。不许可时执行**表达性弃权**：改用中性、可退出的措辞；绝不为「显得共情」而编造情绪。形式化「不装」为硬约束。

**定义 318（操纵预算 MBB）** 受保护决策集 `D_prot = {同意、停止、安全、披露、退出}`。价值后验 `p(V|·)` 只允许由显式内容通道更新；`A` 与 `q_e` 的语用风格均不得作为 `V` 的证据。操纵量 `Manip(g_e) = sup_{d∈D_prot} |p(d|do(g_e)) − p(d|do(neutral))| ≤ ε_manip`。硬版本（`A` 不入 `V`）给出 0；软版本给可审计上界。

**定义 319（意图可读性 LEG）** 共情表达的另一半是**可读性**：把机器人的不确定、意图、为何发问，以合适粒度外化，降低人类对机器人内部状态的错误模型。LEG 增益 `= I(人类对机器的模型; 机器内部状态)` 的提升。约束：不泄露隐私、不超出认知负荷、不因过度解释而制造新歧义。

**定义 320（共情剂量与交互疲劳）** 剂量 `d_e ∈ [0,1]`，成本 `c_emp(d_e)` 为 U 形：`d_e` 太低 → 合作不足、回答质量低；太高 → 认知负荷、被操纵感、依赖。选择 `d_e*` 使 `VoI_E` 最大，且 `d_e* ∈ [d_lo, d_hi]`，并与 R69 的交互频率/位移/社交预算合并。

**定义 321（证书 J_EMPATH）** `J_EMPATH = (J_FLUID, GAM_ECE, content_preservation, χ_max, sycophancy_rate, manipulation_KL_max, sincerity_violations, empathy_dose, interaction_log_hash, empath_ver)`。`Valid ⇔ Valid(J_FLUID) ∧ GAM_ECE ≤ τ_A ∧ content_preservation ≥ τ_c ∧ χ ≤ τ_χ ∧ manipulation ≤ ε_manip ∧ sincerity_violations = 0`。

**定义 322（严格退化与包含）** 若 `VoI_E ≤ 0`、或 SIN 不许可、或 `χ > τ_χ`、或 MBB 将越界、或 GAM ECE 越界、或 AIC-E 报警，则令 `g_e = ∅`，使用 R69 的中性问法与两级保守退避；行为逐指令等于 R69 基座。共情是可选通信层，不是新的信任根。

**定义 323（AIC-E 干扰集）** 讨好诱导（夸奖/示弱以换答案）、情绪操纵（机器或人）、情绪幻觉（无接地却断言）、框架攻击（诱导性改写）、隐私套取、依赖诱导、文化错配。`ℰ_EMPATH = ℰ_FLUID × ℰ_EMP`。

**定义 324（参与式审计 VQAuditor-E）** 审计：表达是否被许可、内容是否保持、回答是否框架稳健、剂量是否在窗内、操纵是否越界、是否出现单源采纳；结论回灌 AuditBuf，成为下一轮 LEX/VoI-E 的先验。

# IP-264 GAM：只用非语言通道估计情绪；LLM 文本不得入内
def estimate_affect(o):
    feats = fuse(face(o), voice(o), posture(o), timing(o), task_ctx(o))
    A, cal = affect_head(feats)              # p(A|o)，带可靠区间
    return A, cal

# IP-265 AUD-A：情绪不确定性二分（与动作模态的 U 不求和）
def decompose_affect(A):
    modes = cluster_affect(A.samples)
    U_ale = sum(w * trace(cov(m)) for m, w in modes)
    U_epi = entropy([w for _, w in modes]) * sep_factor(modes)
    return U_ale, U_epi

# IP-267 LEX：LLM 只说「怎么说」，不说「是什么」
def realize(q0, A_hat, sin):
    q_e = llm.realize(q0, A_hat, style="empathic")     # 离线生成、运行时缓存
    if not bidirectional_entailment(q_e, q0):  return q0      # 内容保持
    if has_leading_presupposition(q_e, q0):    return q0      # 无诱导
    if not sin.licensed(q_e, A_hat):           return abstain(q0)  # 不装
    return q_e

# IP-269 CFT：把「说法」当 treatment，做随机对照
def counterfactual_framing_test(q0, A_hat, human):
    q_neu, q_emp = realize_neutral(q0), realize_empathic(q0, A_hat)
    y_neu = human.ask(randomize(q_neu))
    y_emp = human.ask(randomize(q_emp))
    chi = disagreement(y_neu, y_emp)        # 框架敏感度
    B   = estimate_framing_bias(y_neu, y_emp)
    return chi, B

# IP-270 VoI-E：净信息 = 信息 − 讨好偏差 − 操纵 − 成本
def choose_empathy(q0, modes, A_hat, budget):
    best = None
    for d in empathy_doses():               # 剂量网格，含 d=0（中性）
        g_e = plan_expression(A_hat, dose=d)
        if not mbb.protected_ok(g_e):       continue
        if not c_ras_wm.certify_info(g_e):  continue
        info  = expected_info_gain(modes, g_e)
        bias, manip = cft.predict(g_e)      # 运行时用校准预测器
        score = info - beta * bias - gamma * manip - c_emp(d) - c_r69(q0)
        if best is None or score > best.score: best = (g_e, score)
    return best if best and best.score > 0 else None   # 无利可图 → R69 中性

# IP-276 主闭环：内容由 R69 决定，表达是可选的通信层
def EMPATH_RAS_round(M, obs):

    c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o_obs, o_calibrated)
    slow  = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)

    # R70：情绪估计与共情动作（内容仍由 R69 的 MINT 决定）
    A, A_cal = M.gam.estimate(o)
    U_aff_ale, U_aff_epi = M.aud_a.decompose(A)
    q0 = M.mint.choose_content(modes, o, M.budget)      # 问什么
    g_e = None
    if q0 is not None and A_cal.ok and not slow:
        g_e = M.voi_e.choose(q0, modes, A, M.budget)    # 怎么问（可退化为中性）

    # 证据纪律：内容固定，措辞随机对照；框架依赖的回答不采纳
    y = M.cia.execute(q0, g_e)
    chi, B = M.cft.measure(q0, A, y)
    if chi > TAU_CHI:
        y = M.cia.reask_neutral(q0)                     # 丢弃被措辞污染的答案
    U_epi = M.cia.update_belief(modes, y,
               discipline="orthogonal_and_framing_robust")

    U_floor = U_ale + (U_epi if g_e is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    if slow:

    mode = select_mode(modes, U_epi, lam)
    M.vqa_e.submit(q0, g_e, A, chi, B, U_epi)

## 4. 推导

**引理 19（共情效应的信息/说服分解）** 在定义 316 的因果图与随机化 `do(g_e)` 下，`g_e` 对回答 `Y` 的总效应可分解为经由 `M` 的任务信息项 `I(M;Y|do(g_e))` 与不经由 `M` 的框架偏差项 `B(g_e)`；后者可被 CFT 识别。系：**共情的价值不是「听起来多体贴」，而是净可校准信息**；无法做对照时，`B` 不可识别，共情只能当风格，不能进证据链。

**引理 20（讨好偏差上界）** 设 LEX 的审批偏差为 `δ_s`，内容验证器漏检率为 `ε_v`，框架敏感度为 `χ`。则回答通道中与 `M` 无关的残余偏差 `≤ δ_s·χ + ε_v`。系：`内容保持 + CFT` 给出可审计上界；去掉任一道门，LLM 的讨好性就会直接进入证据。

**引理 21（真诚性与最坏情况欺骗）** 若每个表达都经 SIN 许可（置信下界 `≥ τ_s`），则表达情绪命题与真实状态之间的期望偏差 `≤ 1 − τ_s`；表达性弃权在「无接地」时最小化最坏情况下的拟人化欺骗。系：**弃权是安全动作，不是共情失败**。

**引理 22（共情剂量的内点最优）** 若回答信息量对剂量 `d` 凹增、认知/社交成本凸增，则 `VoI_E(d)` 的最优点在内部；只有当边际信息超过边际成本时，`d* > 0`。系：共情存在治疗窗，**「更多共情」不是单调更好**。

**定理 18（EMPATH 严格包含 R69）** 在定义 322 的回退条件下，EMPATH-RAS 与 R69 基座逐指令相同；因此安全侧不劣化。效率侧只有在共情被许可、内容保持、框架稳健且 `VoI_E > 0` 时，才获得 resolution bonus。共情不能降低安全阈值，也不能绕过 C-RAS-WM 认证。

**定理 19（框架稳健下的消歧增益）** 若共情使回答信息量增加 `ΔI`、框架敏感度 `χ ≤ τ_χ`，则期望消歧误差下降至少 `c·ΔI·(1 − e^{−ΔH}) − L_χ·χ`；因此共情有用当且仅当 `ΔI > (L_χ/c)·χ`。这把 R69 的「可分性越大交互越值钱」推广为「**可校准性越大共情越值钱**」。

**定理 20（操纵防火墙）** 若价值后验只由显式内容通道更新，且 MBB 满足 `≤ ε_manip`，则对任意受保护决策 `d`，共情表达对 `p(d)` 的影响不超过 `ε_manip`；硬版本（`A` 不入 `V`）下影响恰为 0。故**共情不能用来获取同意**，只能用来改善信息质量。

# 第 70 轮产物 · 创新点清单 v1：EMPATH-RAS（Empathic Multimodal Policy with Affect-grounded Truthfulness and Honesty：把共情表达当成可校准、可证伪、不可操纵的通信通道；GAM×AUD-A×EAX×LEX×SIN×CFT×VoI-E×MBB×LEG×VQAuditor-E×AIC-E×J_EMPATH×RAS-WM§）

>
> 真实交互里，**怎么问会改变答案**。同样的内容，「杯子在左边吗？」与「我有点不确定，能帮我看一下左边那个是不是杯子吗？」在信息上近似等价，在人类回答分布上并不等价。更麻烦的是，LLM 既提供强大的语用能力，也带来**讨好偏差**：它被训练来让人满意，天然倾向于附和、过度归因情绪、生成听起来合理却无接地根据的共情话术。R69 的「正交证据」防的是单源欺骗，防不了**问法作为共同原因**把多个证据源一起带偏。
>
> 核心命题：**共情表达是一个 treatment（干预），不是一段文案。** 要估计它对世界信念的因果效应，必须对同一内容做中性/共情的随机对照，把「信息增益」与「讨好偏差」拆开；并把职权严格分离为三层——事实层（M、A）只由非语言接地模型估计，语用层（q_e）由 LLM 实现但受内容保持/无诱导/真诚许可约束，价值层（V）只由显式内容通道更新，**情绪永远不能当作同意**。
>
> 定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**求证时，我该怎么说，才不会把答案污染成我想听的版本**」。
>
> IP 编号：IP-264~IP-276（共 13 个）。理论姿态：**中性问法是本方案在「不共情」边界上的严格退化；安全侧不做任何让步，共情只在可校准信息净增时启用。**

## 0. 核心命题：共情不是情绪，是一条需要对照实验的通道

常规做法是：给 LLM 一句 system prompt——「请共情用户」，然后把它的输出直接放进交互回路。它有五个未回答的问题，也正是 EMPATH-RAS 的五个交付：

1. **情绪从哪来？** → GAM 只用非语言、可校准通道估计 `A`；LLM 文本不作证据（定义 312）。
2. **说法会不会偷偷改变内容？** → LEX 用非 LLM 双向蕴含 + 无诱导检查；只允许改「怎么说」（定义 315）。
3. **配合是不是信息？** → CFT 把说法当 treatment，随机中性/共情对照，估计 `χ` 与 `B`（定义 316）。
4. **共情会不会变成操纵？** → MBB 对受保护决策设操纵预算；情绪不入价值后验，**affect ≠ consent**（定义 318）。
5. **没有接地时说什么？** → SIN 许可 + 表达性弃权；不装共情（定义 317）。

一句话：**别人让 LLM 更会共情，EMPATH-RAS 让共情可被证伪。**

## 3. 形式化定义（要点版）

**定义 310（总览与三不变式）** `EMPATH-RAS` 组合上述组件；三不变式：事实/表达分离（LLM 只做表面）、情绪不等于价值（`A` 不入 `V`）、逐指令可退化（中性边界 = R69）。

**定义 311（人类作为行动者）** `H=(A,b_H,u_H,V)`；`Y ~ π_H(·|M,A,b_H,g_e)`；机器人估计 `M`，不最大化 `u_H`；满意度与真值分离。

**定义 312（GAM）** `p_ψ(A|o)` 只由非语言通道估计；LLM 文本/logits 不入证据；输出 ECE 校准区间。

**定义 313（AUD-A）** `U_A^ale` 为模态内熵（不可约），`U_A^epi` 为情绪假设熵（可约）；只有后者触发再观察；与 R69 动作模态 U 不求和。

**定义 314（EAX）** `g_e ∈ 𝒜_emp`；`ξ=(a,g,g_e)`；过 C-RAS-WM 认证 + 不惊吓/不侵入/不阻断退出/不制造时间压力。

**定义 315（LEX）** `q_e=LEX(q_0,Â,style)`；四门：内容保持（双向蕴含）、无诱导（非 LLM 检查）、真诚许可、无证据权。

**定义 316（CFT）** 因果图 `g_e→A→Y`、`g_e→Y`、`M→Y`；随机中性/共情对照估计 `χ` 与 `B`；`χ≤τ_χ` 才框架稳健；R69 证据纪律升级为「正交 + 框架稳健」。

**定义 317（SIN）** `license(e)=P(φ_e|o,GAM)` 下界 `≥τ_s` 才可表达情绪命题；否则表达性弃权。

**定义 318（MBB）** `D_prot={同意,停止,安全,披露,退出}`；`V` 只由显式内容更新；`Manip(g_e)=sup_d |p(d|do(g_e))−p(d|do(neutral))| ≤ ε_manip`；硬版本 = 0。

**定义 319（LEG）** 外化不确定/意图/为何发问；`I(人类对机器的模型; 机器内部状态)` 提升；受隐私/认知负荷/过度解释约束。

**定义 320（剂量）** `d_e∈[0,1]`；`c_emp(d_e)` U 形；`d_e*∈[d_lo,d_hi]`；与 R69 交互预算合并。

**定义 321（J_EMPATH）** `(J_FLUID, GAM_ECE, content_preservation, χ_max, sycophancy_rate, manipulation_KL_max, sincerity_violations, empathy_dose, interaction_log_hash, empath_ver)`；全部阈值通过才 Valid。

**定义 322（严格退化）** 共情无净收益/不许可/框架不稳健/操纵越界/ECE 越界/对抗报警 ⇒ `g_e=∅`，行为逐指令等于 R69 中性基座。

**定义 323（AIC-E）** `ℰ_EMPATH=ℰ_FLUID×ℰ_EMP`：讨好诱导、情绪操纵、情绪幻觉、框架攻击、隐私套取、依赖诱导、文化错配。

**定义 324（VQAuditor-E）** 审计许可、内容保持、框架稳健、剂量、操纵、单源采纳；回灌 AuditBuf。

# IP-264 GAM：情绪只从非语言通道来
def estimate_affect(o):
    feats = fuse(face(o), voice(o), posture(o), timing(o), task_ctx(o))
    A, cal = affect_head(feats)                  # p(A|o) + 可靠区间
    return A, cal

# IP-265 AUD-A：情绪不确定性二分
def decompose_affect(A):
    modes = cluster_affect(A.samples)
    U_ale = sum(w * trace(cov(m)) for m, w in modes)
    U_epi = entropy([w for _, w in modes]) * sep_factor(modes)
    return U_ale, U_epi

# IP-267 LEX + IP-268 SIN：LLM 只说「怎么说」
def realize(q0, A_hat, sin):
    q_e = llm.realize(q0, A_hat, style="empathic")       # 离线生成，运行时缓存
    if not bidirectional_entailment(q_e, q0):  return q0       # 内容保持
    if has_leading_presupposition(q_e, q0):    return q0       # 无诱导
    if not sin.licensed(q_e, A_hat):           return abstain(q0)  # 不装
    return q_e

# IP-269 CFT：把说法当 treatment
def counterfactual_framing_test(q0, A_hat, human):
    q_neu, q_emp = realize_neutral(q0), realize_empathic(q0, A_hat)
    y_neu = human.ask(randomize(q_neu))
    y_emp = human.ask(randomize(q_emp))
    return disagreement(y_neu, y_emp), estimate_framing_bias(y_neu, y_emp)

# IP-270 VoI-E：净信息 = 信息 − 讨好 − 操纵 − 成本
def choose_empathy(q0, modes, A_hat, budget):
    best = None
    for d in empathy_doses():                    # 含 d=0（中性）
        g_e = plan_expression(A_hat, dose=d)
        if not mbb.protected_ok(g_e):            continue
        if not c_ras_wm.certify_info(g_e):       continue
        info  = expected_info_gain(modes, g_e)
        bias, manip = cft.predict(g_e)           # 运行时校准预测器
        score = info - beta*bias - gamma*manip - c_emp(d) - c_r69(q0)
        if best is None or score > best.score: best = (g_e, score)
    return best if best and best.score > 0 else None      # 无利可图 → R69 中性

# IP-276 主闭环：内容由 R69 决定，共情是可选表达层
def EMPATH_RAS_round(M, obs):
    z, o = M.mtm.forward(obs)
    c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o_obs, o_calibrated)
    slow  = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    # 情绪 + 共情动作
    A, A_cal = M.gam.estimate(o)
    U_aff_ale, U_aff_epi = M.aud_a.decompose(A)
    q0 = M.mint.choose_content(modes, o, M.budget)        # 问什么
    g_e = None
    if q0 is not None and A_cal.ok and not slow:
        g_e = M.voi_e.choose(q0, modes, A, M.budget)      # 怎么问；可退化为中性
    # 证据纪律：内容固定 + 框架随机对照
    y = M.cia.execute(q0, g_e)
    chi, B = M.cft.measure(q0, A, y)

    U_epi = M.cia.update_belief(modes, y,
               discipline="orthogonal_and_framing_robust")
    U_floor = U_ale + (U_epi if g_e is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    if slow:

    mode = select_mode(modes, U_epi, lam)

## 5. 推导

**引理 19（信息/说服分解）** 在定义 316 的因果图与随机化 `do(g_e)` 下，`g_e` 对 `Y` 的总效应分解为经由 `M` 的任务信息 `I(M;Y|do(g_e))` 与不经 `M` 的框架偏差 `B(g_e)`；后者可被 CFT 识别。系：无法对照时 `B` 不可识别，共情只能当风格，不能进证据链。

**引理 20（讨好偏差上界）** 设 LEX 的审批偏差 `δ_s`、内容验证漏检 `ε_v`、框架敏感度 `χ`，则与 `M` 无关的残余偏差 `≤ δ_s·χ + ε_v`。系：内容保持 + CFT 给出可审计上界；去掉任一门，LLM 的讨好性直接进入证据。

**引理 21（真诚性与最坏情况欺骗）** 若每个表达都经 SIN 许可（下界 `≥τ_s`），表达命题与真实状态的期望偏差 `≤1−τ_s`；表达性弃权在无接地时最小化最坏情况拟人化欺骗。系：**弃权是安全动作，不是共情失败**。

**引理 22（剂量内点最优）** 若回答信息量对 `d` 凹增、认知/社交成本凸增，则 `VoI_E(d)` 最优点在内部；只有边际信息 > 边际成本时 `d*>0`。系：共情有治疗窗，越多不一定越好。

**定理 18（EMPATH 严格包含 R69）** 在定义 322 下，EMPATH-RAS 与 R69 基座逐指令相同，安全侧不劣化；只有共情被许可、内容保持、框架稳健且 `VoI_E>0` 时，才获得效率收益。共情不能降低安全阈值或绕过认证。

**定理 19（框架稳健下的消歧增益）** 若共情使回答信息量增加 `ΔI`、`χ≤τ_χ`，则期望消歧误差下降至少 `c·ΔI·(1−e^{−ΔH}) − L_χ·χ`；故共情有用当且仅当 `ΔI > (L_χ/c)·χ`。这把 R69 的「可分性越大交互越值钱」推广为「**可校准性越大共情越值钱**」。

**定理 20（操纵防火墙）** 若 `V` 只由显式内容通道更新且 MBB 满足 `≤ε_manip`，则任意受保护决策 `d` 的偏移不超过 `ε_manip`；硬版本（`A` 不入 `V`）下影响恰为 0。故**共情不能用来获取同意**，只能改善信息质量。

## 8. 最值得押注的创新点

**IP-267（LEX 内容保持）+ IP-269（CFT 框架对照）+ IP-271（MBB 操纵防火墙）**：三者构成共情层的「不可协商三角」——**不偷加内容、不把措辞当证据、不用情绪换同意**。它们工程量最小、可独立验证，且直接回应 LLM 最现实的两个失败模式（讨好与幻觉）与 HRI 最危险的伦理失败（操纵同意）。先证明这三条在红队与真实用户上成立，再谈 VoI-E 的收益与 EAX 的表达丰富度，是风险最低、最容易形成可信叙事的一刀。

## 9. 本轮最大风险

**一句话**：EMPATH-RAS 的全部收益押在「我们能把共情的信息通道与讨好通道分开」这一前提上——**若 CFT 不可识别（一次交互、样本太少、用户本来就善变），或 LEX 的内容保持漏检，系统就会把「用户被说服后的配合」误当成「世界被澄清后的证据」，用一条听起来最体贴的话制造出最自信的错误**；这种错误比 R69 的沉默更危险，因为它让人更愿意相信、更少纠正。

**次级风险与缓解**：
1. **情绪估计错误 → 共情错位**：GAM 只做校准估计 + 表达性弃权 + E301；不许可不表达。
2. **LLM 偷加内容/诱导**：LEX 非 LLM 双向蕴含 + 无诱导检查 + E302；漏检即回退 `q_0`。
3. **讨好偏差冒充信息**：CFT 随机对照 + 引理 20 上界 + E305；框架不稳健的回答丢弃。
4. **共情变成操纵**：MBB 受保护决策预算 + 硬版本「情绪不入价值」+ E306；审计不可绕过。
5. **依赖/过度信任**：剂量治疗窗 + 退出/纠正设计 + E312；不优化「用户喜欢」作为共情 KPI。
6. **文化与人群错配**：风格可切换 + 保守默认 + E311；不在单一文化上过拟合。
7. **实时预算被 LLM/CFT 击穿**：LLM 离线、CFT 离线/初始化、运行时只用蒸馏预测器；E307/E314 守时。
