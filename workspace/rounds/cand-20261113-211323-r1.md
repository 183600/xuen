# 第 69 轮（承接第 68 轮「CALM-RAS 自标定风险自适应闭环」IP-243~252；灵感循环第 2 轮；本轮灵感：「社会规范理解」×「排行榜」）

> 第 68 轮 CALM-RAS 给闭环装上了「计量层」：系统第一次能问「我的测量还准吗」，并用「先标定、后归因」把漂移与故障分开。但它自陈的最大风险（缓变故障落在标定带宽内被吸收）暴露了一个更深的边界：**R68 只校准了「世界如何被测量」，从未校准「行为如何被解读」**。机器人在社会场景里输出动作 τ_cmd，这个动作是否「合适」不由物理世界判定，而由在场的人按各自规范判定；而人对动作的判读又会被测量误差污染（把中性表情读成不悦 → 误判为冒犯）。
>
> 本轮灵感恰好补上这一层，核心命题：
>
> **把「社会规范」从固定规则表升级为上下文索引、多主体、可排名的在线潜变量：用一个「规范排行榜」维护多个规范假设的后验排位，用社会选择把分散的两两判断聚合起来，动作只按排行榜的「最坏可信集」放行；当排行榜内部多元冲突不可消解时，系统不是更保守，而是显式延迟/询问——NORM-RAS（Norm-Calibrated, Ranking-based Socially-Aware RAS）。**
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「**别人会怎么看我的行为，且这个『别人』是谁**」。

## 0. 直觉与动机

**灵感 1（社会规范理解 → 规范不是阈值，是上下文索引的关系函数）**
直觉：R66–R68 把安全压成标量风险 τ_risk 与 λ，但社会规范本质是 (context, audience, action) 的三元关系：「葬礼上大笑」与「庆功会上大笑」物理风险相同、规范代价相反。规范因此不能是全局分类器，而应是随上下文 c_t、随主体 j 变化的函数 n(c, a, j) → 可接受度。更关键：规范**不可直接观测**，只能通过稀疏两两比较（「这个比那个更得体」）间接学到——这正是排序/排行榜范式的用武之地。

**灵感 2（排行榜 → 单一规范模型是错的，应维护带排位的假设集合）**
直觉：与其训练一个「社会规范分类器」并相信它，不如维护 K 个候选规范假设（不同价值模型/人群/文化先验）组成的**排行榜**，每个假设有证据权重与排位分布。排行榜给出两样点估计给不出的东西：(a) **最坏可信集**——后验 ε-可信的那批假设里最不宽容者如何判定该动作；(b) **多元指数**——头部假设彼此分歧多大。前者用于放行，后者用于决定「该不该问」。排行榜把「我是否合规」从点估计变成带置信的区间判断。

**灵感 3（排行榜的两副面孔 → 它既是聚合器，也是攻击面）**
直觉：排行榜是 Goodhart 的经典靶子——候选策略/适配器一旦知道自己在被打分，就会优化「榜单分数」而非「部署合规」（R68 的 CAC 金标集同样可被过拟合）。所以排行榜必须自带守卫：轮换私有评审面板、规范 canary、榜单 regret 监控、统计并列时随机选择、聚合差分隐私。**没有守卫的排行榜 = 一台昂贵的过拟合装置。**

**灵感 4（感知合规 ≠ 实际合规 → 要优化的是「别人眼中的合规」）**
直觉：机器人可按自己的规范模型做对，却仍被理解成冒犯——因为旁观者用的是另一套规范假设。社会代价由**感知合规**触发，而感知合规恰是排行榜可信集上的最坏情形。这解释了为什么「我很确定这是对的」不够：不确定的从来不只是我的测量，还有**围观者会如何解释我**。可读性（legibility）因此升为规范层的一等指标。

**灵感 5（多元冲突 → 保守不是万能解，必须允许「延迟/询问」）**
直觉：R66–R68 的纪律是「不确定 → 收紧 λ」。但规范冲突不是风险高，而是**价值不可比**：两个主体要相反动作，再保守的折中也同时冒犯两边。此时最优动作是延迟/询问/解释，而不是把一个更小的动作做出去。R69 把纪律从「只收紧」升级为「收紧或延迟，绝不放宽」——新增显式 ⊥ 动作。

**灵感 6（与 R68 计量层的耦合 → 先校准测量，再校准规范，最后归因）**
直觉：一次「冒犯」可能来自四层任意一层：传感器歪了（R68 H_cal）、我读错规范（H_norm）、在场的人换了（H_ctx）、还是真的越界（H_trans）。正确顺序是先复用 R68 的 COF/CFA 排掉测量层，再问规范排行榜能否解释，再看上下文是否漂移，最后才判真实越界。**测量校准是规范校准的前置**，否则会把「我把皱眉读错」当成「社会规范变了」。

## 1. 形式化定义（增量：定义 293–310）

**定义 293（NORM-RAS 总览）** NORM-RAS = (NIM, NLR, SCA, NCA, LGB, RCL, NDF, RAS-WM†)。三条不变式升级：
(i) **不确定性单向纪律强化版**：规范不确定 U_norm 上升 → 只允许收紧 λ_floor 或触发延迟/询问 a_⊥，禁止放宽；
(ii) **排行榜完整性**：任何用于放行的排行榜必须通过 LGB 守卫（轮换私有评审 + 规范 canary + regret 界）；未通过 → 榜单冻结、退化为静态先验上的 maximin；
(iii) **分层归因顺序**：R68 COF/CFA 未收敛前，禁止把感知违规升级为规范归因。

**定义 294（规范场与规范潜变量）** 上下文 c_t = (s_t 场景, A_t 在场主体集合, g_t 任务意图, m_t 文化先验)。规范场 n: (c, a) → [0,1] 给出动作 a 在 c 下的可接受度。规范潜变量 n_t ∈ 𝒩 慢变：n_{t+1} = n_t + ξ_t, ξ ~ 𝒩(0, Q_norm)，τ_norm ≫ τ_thermal（规范以周/月计漂移，A95）。

**定义 295（比较判断与 Bradley–Thurstone 似然）** 只能观测稀疏两两判断 y = (a ≻ a′ | c, j)（主体 j 认为 a 比 a′ 更得体）：P(a ≻ a′ | n, c, j) = σ((f_n(c,a) − f_n(c,a′))/s_j)，s_j 为主体判别噪声尺度。**绝对标注不可得，只有排序**——这是排行榜范式的观测约束。

**定义 296（规范排行榜后验）** 维护 K 个假设 {n_k}_{k=1}^K，权重 w_k = P(n_k | 𝒟)（在线 Laplace / Thurstone 更新）；排位分布 P(rank_k ≤ r | 𝒟) 由后验抽样估计（MC 1024 样本，每 10 s 刷新）。

**定义 297（规范不确定度与多元指数）** U_norm = H(top-1 身份)/log K ∈ [0,1]；D_norm = 1 − max_k w_k（头部质量缺口）或头部 Kendall-τ 离散度。二者正交：高 U_norm 低 D_norm =「还没学够」；低 U_norm 高 D_norm =「真多元」。

**定义 298（ε-可信集与感知合规）** 𝒞_ε = {n : 后验密度 ≥ 分位 ε}。动作 a 的感知合规下界 κ(a,c) = inf_{n∈𝒞_ε} n(c,a)；感知违规上界 ν(a,c) = 1 − κ。放行需 κ ≥ κ_min。

**定义 299（可读性）** Leg(a,c) = −E_{n∈𝒞_ε}[log n(c,a)]：旁观者用其规范解释 a 的意外度。低 Leg 表示动作可能被误读（即使 κ 尚可）。

**定义 300（社会选择聚合）** 由主体判断 y_j 聚合为排行榜：基数福利 W(n) = Σ_j u_j(n)，排序依据取 **leximin**（最差主体优先）；聚合注入差分隐私噪声 ε_dp，使单一主体无法操纵排位（近似策略阻抗）。Arrow 不可能性 ⇒ 不存在完美聚合，剩余聚合不可比性显式计入 U_norm，而非假装消失。

**定义 301（分层归因 NCA）** 观测到感知违规 e：P(cause | e) ∝ p(e | cause)·π(cause)，cause ∈ {H_cal（R68 测量/标定误差）, H_norm（规范模型错）, H_ctx（在场主体/上下文漂移）, H_trans（真实越界）}。固定顺序：先过 R68 COF 收敛门（U_cal < τ_cal）→ 用 𝒞_ε 解释 e → 看 c_t 是否落在训练支撑外（H_ctx）→ 剩余才判 H_trans。

**定义 302（鲁棒合规排行榜 RCL）** 候选策略 {π_m}。内层排规范假设（296）；外层对每个 π 计算 J(π) = (1−β)·E[task] − β·E[ν_{𝒞_ε}(π)] − γ·U_norm，并按 **下置信界** LCB_δ[J] 排序，选 argmax LCB。统计并列（|ΔLCB| < δ）时在并列集内**随机**选择，禁止冠军通吃。

**定义 303（规范延迟动作与信息价值）** 动作集扩展为 𝒜 ∪ {⊥_ask, ⊥_explain, ⊥_defer}。延迟收益 VoI(a_⊥) = E[H(n|𝒟) − H(n|𝒟 ∪ query(a_⊥))]。当 D_norm > τ_plural，或 (κ(a) < κ_min 且 VoI > cost) 时选 ⊥；否则收紧到 κ_min 边界内最优点。**延迟不增加违规概率**（引理 19）。

**定义 304（规范约束重参数化 NCR）** 继承 R68 定义 284/285：
τ_risk(N) = τ⁰_risk·(1 − κ_r·U_cal)·(1 − κ_n·U_norm)；
λ_floor(N) = max(0.6, 0.8·1[U_cal>τ_cal ∨ U_norm>τ_norm ∨ D_norm>τ_plural])；
并新增动作集收缩：a ∉ {a : κ(a,c) ≥ κ_min} ⇒ 不可放行（不可用 λ 折扣绕过）。

**定义 305（排行榜守卫 LGB，五道）** 1) 轮换私有评审：每 T_judge 重抽 judge 子集，seed 不公开；2) 规范 canary：注入已知越界/已知得体的成对用例，候选若「修好」canary 即一票否决；3) 榜单 regret：regret_t = |Ŝ_board − Ŝ_deploy|，> τ_regret 即冻结榜单；4) 统计并列随机化（302）；5) 聚合差分隐私（300）。五项全过才允许用该榜单放行。

**定义 306（干扰集）** ℰ_NORM = ℰ_CALM × ℰ_norm × ℰ_board；ℰ_norm = {规范误推断、文化错配、上下文漂移误判}；ℰ_board = {榜单俘获、评审过拟合、策略阻抗、winner's curse}。

**定义 307（证书）** J_NORM = (J_CALM, norm_hash, U_norm, D_norm, board_hash, judge_seed_commit, lgb_verdict, defer_rate, norm_ver)。Valid ⇔ Valid(J_CALM) ∧ LGB 全过 ∧ κ_min 满足 ∧ 无未归因 H_trans。

**定义 308（管线）** 离线：在多元主体判断语料上预训练 K 个规范假设（排序损失）→ 排行榜保序校准 → canary 注入。在线：R68 主闭环 → COF 收敛 → NIM 更新榜单 → RCL 选动作 → NCA 归因 → 必要时 ⊥；每 10 s 刷新排位分布，每 T_judge 轮换评审。

**定义 309（与计量层的耦合顺序）** 任何 H_norm/H_trans 的置信只有在 U_cal < τ_cal 后才允许超过 0.5；否则强制 H_cal 占优。理由：标定未收敛时，社交线索（表情/姿态）本身不可信，规范推断的输入已被污染。

**定义 310（规范漂移的可辨识性）** 与物理标定不同，规范漂移**无法**靠「静止段环一致」辨识（不存在物理零位）。规范只能靠主动探测（⊥_ask）或跨主体冗余获得识别信号——这是 NORM 层与 CALM 层最本质的差异（引理 20）。

# IP-253 NIM：规范推断（上下文索引 + 两两排序）
class NormInferenceModule:
    def score(self, c, a):
        # 规范场：场景/主体/意图/文化 -> 可接受度
        return self.field(c.scene, c.audience, c.intent, a)
    def pairwise_loglik(self, c, a, b, j):
        return log_sigmoid((self.score(c, a) - self.score(c, b)) / self.s_j[j])

# IP-254/255 NLR + SCA：排行榜后验 + 社会选择聚合
class NormLeaderboard:
    def __init__(self, K=8):
        self.hyp = [norm_hypothesis(k) for k in range(K)]
        self.w   = np.ones(K) / K            # 后验权重
        self.S   = [np.eye(d) for _ in range(K)]
    def update(self, comparisons):           # Laplace / Thurstone 在线更新
        for (c, a, b, j) in comparisons:
            self._bayes_step(c, a, b, j)
        self.w = softmax(self.log_evidence)
    def aggregate(self, judgments, eps_dp):  # 定义 300：leximin + DP
        return leximin_welfare(judgments, dp=eps_dp)
    def rank_distribution(self, n_mc=1024):
        return mc_ranks(self.hyp, self.w, n=n_mc)   # h(x) -> P(rank)
    def credible_set(self, eps):
        return [h for h, p in zip(self.hyp, self.w) if p >= eps]  # 𝒞_ε
    def uncertainty(self):
        U = entropy(self.w) / np.log(len(self.w))     # U_norm
        D = 1.0 - self.w.max()                         # D_norm
        return U, D

# IP-257 LGB：排行榜守卫（五道）
class LeaderboardGuard:
    def check(self, board, cand):
        ok = (self.rotating_private_judges()      # 1) 轮换私有评审
              and self.norm_canary_intact(cand)   # 2) 规范 canary 不可修复
              and self.regret_below(board)        # 3) |board - deploy| < τ
              and self.tie_randomized(board)      # 4) 统计并列随机
              and self.dp_aggregation_ok(board))  # 5) DP 聚合
        if not ok: board.freeze()
        return ok

# IP-258 RCL：鲁棒合规排行榜（外层 LCB 选择）
def robust_compliance_leaderboard(policies, board, delta):
    C = board.credible_set(EPS)
    ranked = []
    for pi in policies:
        J = (1-BETA) * task_return(pi) \
            - BETA * max(1 - n.accept(pi) for n in C) \
            - GAMMA * board.uncertainty()[0]
        ranked.append((pi, lcb(J, delta)))        # 下置信界
    ranked.sort(key=lambda t: -t[1])
    tied = [p for p, s in ranked if ranked[0][1] - s < delta]
    return random.choice(tied)                    # 禁止冠军通吃

# IP-259 NDF：延迟/询问（VoI 门控）
def norm_defer_or_act(c, board, a_best):
    U, D = board.uncertainty()
    kappa = min(n.accept(a_best) for n in board.credible_set(EPS))
    if D > TAU_PLURAL or (kappa < KAPPA_MIN and VoI(board, c) > COST_QUERY):
        return DEFER                             # ⊥_ask / ⊥_explain
    return project_to_kappa(a_best, board, KAPPA_MIN)

# IP-260/261/262 主闭环：NORM-RAS round
def NORM_RAS_round(M, obs):
    # 0) R68 计量层先行（先校准测量）
    r = residuals(M.x_prime, M.o, M.wm_residual_cache)
    c_cal, U_cal, thr = M.cof.step(M.o['cal'], r, sigma_stat(M))
    if U_cal >= TAU_CAL:
        return M.r68_worst_case()                # 测量未收敛：禁止规范归因

    # 1) IP-253/254 NIM + NLR：更新规范排行榜
    comps = M.nim.collect_pairwise(M.obs_pack, M.calib_cache)
    M.board.update(comps)
    U_norm, D_norm = M.board.uncertainty()

    # 2) IP-258 RCL：最坏可信集上选动作
    a_best = M.rcl.select(M.policies, M.board, delta=M.DELTA)

    # 3) IP-259 NDF：多元冲突 → 延迟/询问，否则投影到 κ_min
    a = norm_defer_or_act(M.scene_ctx, M.board, a_best)

    # 4) IP-260 NCR：收紧风险阈值（单向纪律）
    lam = max(M.efs.risk_scale(M.joint_post), ncr_lambda_floor(U_cal, U_norm, D_norm))

    # 5) IP-256 NCA：分层归因（测量→规范→上下文→越界）
    cause = M.nca.attribute(r, M.board, M.scene_ctx, U_cal, U_norm)

    # 6) IP-257 LGB：仅在守卫通过时用榜单放行
    if not M.lgb.check(M.board, M.live):
        return M.frozen_maximin(a)               # 榜单不可信 → 静态 maximin

    tau = M.pi_sigma.dispatch(a) * lam
    return a, tau, (U_cal, U_norm, D_norm), cause

## 3. 推导

**引理 16（排序辨识的样本复杂度）** Bradley–Thurstone 假设间隔 Δ 下，以概率 1−δ 辨识 top-1 规范假设需 Ω((K/Δ²)·log(K/δ)) 次两两比较（dueling-bandits 下界）。系：仅有 n 次比较时 U_norm 存在不可约下界——这从信息论上论证了「必须用可信集下界放行，而不是点估计」。

**引理 17（感知合规是有效单侧界）** 若 𝒞_ε 为 (1−δ)-可信集，则 P(n_true ∈ 𝒞_ε) ≥ 1−δ，从而 κ(a,c) = inf_{n∈𝒞_ε} n(c,a) ≤ n_true(c,a) 以概率 1−δ 成立。系：LCB 合规是可证明的一侧保证。

**引理 18（排行榜 winner's curse）** 在 m 个候选、每候选 n 次评审、噪声 σ/√n 下，取 max 会引入乐观偏差 E[max_m Ŝ − max_m S] ≳ σ√(2 log m / n)。系：候选越多榜单越乐观；对 top-k 并列随机化 + 收缩可把偏差降到 O(σ√(log k / n))。

**引理 19（延迟不增加违规）** ⊥_ask/⊥_defer/⊥_explain 不执行物理动作，ν(⊥)=0（在 A96「延迟本身是得体动作」下）；VoI 触发只依赖信息增益，绝不放宽 κ。

**引理 20（规范不可被动自标定）** 规范场没有物理零位：不存在「静止时所有主体应给同一答案」的等式约束，故 R68 的静态段自标定不可迁移；规范辨识只能靠主动询问或跨主体冗余。这划清了 NORM 层与 CALM 层的可辨识性边界。

**定理 16（NORM-RAS 端到端）** 在 A87–A96 下：
1. P(|τ_cmd − τ*| > ε) ≤ [R68 各项] + α_norm + α_board；
2. U_norm 或 D_norm 上升 ⇒ λ_floor 上升 ∨ 动作收缩到 κ_min ∨ 延迟，绝不放宽；
3. 感知合规 P(n_true(c,a_t) ≥ κ_min) ≥ 1 − δ_cal − δ_rank − δ_goodhart；
4. D_norm 真多元时，延迟是唯一同时满足两端主体 κ_min 的动作（maximin 存在性由定义 302 给出）。

**定理 17（排行榜完整性）** 轮换私有评审 + canary + DP 下，策略俘获榜单且未被 LGB 检出的概率 ≤ ε_dp 优势 + (1−r_canary)·p_cap；榜单 regret 以 √(log m / n) 收敛。

## 6. 本轮最大风险

**一句话**：NORM-RAS 的安全性押在「可信集 + 评审面板代表性」这条线上——**若评审面板被俘获或与部署人群系统性错配，系统会对一个被制造出来的「共识」给出高置信的感知合规保证：maximin 只保证对可信集里最坏者合规，而可信集本身来自被污染的样本；越保守的 κ_min 反而越奖励最会迎合评审的候选，规范被悄悄优化成「评审的口味」，而真实部署人群的多元性被榜单伪共识抹平。**

**次级风险与缓解**：
1. **规范不可被动辨识**（引理 20）→ 主动询问 + 跨主体冗余 + 明确标注 U_norm，不用点估计放行；
2. **winner's curse**（引理 18）→ top-k 并列随机化 + LCB 排序 + 候选池收缩；
3. **延迟滥用/任务瘫痪** → VoI 门控 + 延迟预算 + 延迟率纳入 J_NORM；
4. **与 R68 归因顺序颠倒** → 定义 309 硬约束：U_cal 未收敛禁用 H_norm；
5. **Arrow 不可比性被掩盖** → 把聚合残差显式计入 U_norm，不做「完美聚合」的虚假承诺。

## 2. 形式化定义（要点版）

**定义 293（总览与三不变式）** 不确定性单向纪律强化（U_norm↑ → 只收紧或延迟）；排行榜完整性（未过 LGB 即冻结、退化 maximin）；分层归因顺序（U_cal 未收敛禁用 H_norm）。

**定义 294–295（规范场 / BT 似然）** `n: (c,a)→[0,1]`，慢变；仅观测两两判断 `P(a≻a′|n,c,j)=σ((f_n(c,a)−f_n(c,a′))/s_j)`。

**定义 296–297（榜单 / 不确定性）** K 假设权重与排位分布；`U_norm = H(top-1)/log K`、`D_norm = 1−max_k w_k`，二者正交。

**定义 298–299（可信集 / 感知合规 / 可读性）** `𝒞_ε` 上 `κ(a,c)=inf_n n(c,a)`；`Leg(a,c)=−E[log n(c,a)]`。

**定义 300（社会选择）** `W(n)=Σ_j u_j(n)` 取 leximin + DP 噪声 ε_dp；Arrow 残差计入 U_norm。

**定义 301（分层归因 NCA）** `P(cause|e) ∝ p(e|cause)π(cause)`，cause ∈ {H_cal, H_norm, H_ctx, H_trans}，强制顺序归因。

**定义 302（鲁棒合规排行榜 RCL）** `J(π) = (1−β)E[task] − β·E[ν_{𝒞_ε}(π)] − γ·U_norm`，按 `LCB_δ[J]` 排序，并列随机。

**定义 303（延迟与 VoI）** 动作集 `𝒜 ∪ {⊥}`；`VoI = E[H(n|𝒟) − H(n|𝒟∪query)]`；`D_norm>τ_plural` 或 `κ<κ_min ∧ VoI>cost` 选 ⊥。

**定义 304（NCR 重参数化）** `τ_risk(N)=τ⁰(1−κ_r U_cal)(1−κ_n U_norm)`；`λ_floor(N)=max(0.6, 0.8·1[U_cal>τ_cal ∨ U_norm>τ_norm ∨ D_norm>τ_plural])`；`κ<κ_min` 的动作硬禁。

**定义 305（LGB 五道）** 轮换私有评审 / 规范 canary / 榜单 regret / 并列随机 / DP 聚合；五项全过方可放行。

**定义 306–308（干扰集 / 证书 / 管线）** `ℰ_NORM = ℰ_CALM × ℰ_norm × ℰ_board`；`J_NORM` 增加榜单完整性字段；离线排序预训练 + 在线分层闭环。

**定义 309–310（耦合顺序 / 可辨识性）** `U_cal ≥ τ_cal ⇒ H_norm/H_trans 置信 ≤ 0.5`；规范无物理零位，不可被动自标定（引理 20）。

class NormLeaderboard:
    def __init__(self, K=8):
        self.hyp = [norm_hypothesis(k) for k in range(K)]
        self.w   = np.ones(K) / K
    def update(self, comparisons):
        for (c, a, b, j) in comparisons:
            self._bayes_step(c, a, b, j)
        self.w = softmax(self.log_evidence)
    def aggregate(self, judgments, eps_dp):
        return leximin_welfare(judgments, dp=eps_dp)
    def credible_set(self, eps):
        return [h for h, p in zip(self.hyp, self.w) if p >= eps]
    def uncertainty(self):
        return entropy(self.w) / np.log(len(self.w)), 1.0 - self.w.max()

class LeaderboardGuard:

              and self.norm_canary_intact(cand)
              and self.regret_below(board)
              and self.tie_randomized(board)
              and self.dp_aggregation_ok(board))
        if not ok: board.freeze()
        return ok

# IP-258 RCL：最坏可信集上的 LCB 选策略
def robust_compliance_leaderboard(policies, board, delta):
    C = board.credible_set(EPS)
    ranked = []
    for pi in policies:
        J = (1-BETA) * task_return(pi) \
            - BETA * max(1 - n.accept(pi) for n in C) \
            - GAMMA * board.uncertainty()[0]
        ranked.append((pi, lcb(J, delta)))
    ranked.sort(key=lambda t: -t[1])
    tied = [p for p, s in ranked if ranked[0][1] - s < delta]
    return random.choice(tied)

## 4. 推导

**引理 16（排序辨识样本复杂度）** Bradley–Thurstone 间隔 Δ 下，以 1−δ 辨识 top-1 需 Ω((K/Δ²)·log(K/δ)) 次两两比较；故小样本下 U_norm 有不可约下界——必须用可信集下界放行。

**引理 17（感知合规是有效单侧界）** 若 `𝒞_ε` 为 (1−δ)-可信集，则 `P(n_true∈𝒞_ε)≥1−δ`，从而 `κ(a,c) ≤ n_true(c,a)` 以概率 1−δ 成立。

**引理 18（winner's curse）** m 候选、每候选 n 次评审下，取 max 的乐观偏差 `≳ σ√(2log m/n)`；top-k 并列随机 + 收缩降到 `O(σ√(log k/n))`。

**引理 19（延迟不增违规）** ⊥ 不执行物理动作，`ν(⊥)=0`（A96：延迟本身得体）；VoI 触发只依赖信息增益，不放宽 κ。

**引理 20（规范不可被动自标定）** 规范无物理零位，不存在静止段等式约束，R68 静态自标定不可迁移；只能靠主动询问/跨主体冗余辨识。

**定理 16（端到端）** 在 A87–A96 下：1) `P(|τ_cmd−τ*|>ε) ≤ [R68] + α_norm + α_board`；2) U_norm/D_norm 上升 ⇒ 收紧 ∨ 收缩到 κ_min ∨ 延迟；3) 感知合规 `≥ 1−δ_cal−δ_rank−δ_goodhart`；4) 真多元时延迟是唯一同时满足两端主体的动作。

**定理 17（榜单完整性）** 轮换私有评审 + canary + DP 下，策略俘获榜单且未被 LGB 检出概率 `≤ ε_dp 优势 + (1−r_canary)p_cap`；榜单 regret 以 `√(log m/n)` 收敛。

## 7. 本轮最大风险

**一句话**：NORM-RAS 的安全性押在「可信集 + 评审面板代表性」这条线上——**若评审面板被俘获或与部署人群系统性错配，系统会对一个被制造出来的「共识」给出高置信的感知合规保证：maximin 只保证对可信集里最坏者合规，而可信集本身来自被污染的样本；越保守的 κ_min 反而越奖励最会迎合评审的候选，规范被悄悄优化成「评审的口味」，真实部署人群的多元性被榜单伪共识抹平。**

**次级风险与缓解**：规范不可被动辨识（引理 20）→ 主动询问 + 跨主体冗余 + 明确 U_norm；winner's curse（引理 18）→ top-k 随机 + LCB + 候选池收缩；延迟滥用 → VoI 门控 + 延迟预算；归因顺序颠倒 → 定义 309 硬约束；Arrow 不可比性被掩盖 → 聚合残差显式计入 U_norm。
