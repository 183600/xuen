# 第 47 轮（承接第 46 轮 v23 / 第 45 轮 v10；本轮灵感：扩散策略 × 机械臂） · Diffusion-Cert：去噪轨迹上的可验证安全投影与证书-能量联合调度（五层架构 v11）

> 承接 v23 Memory-Safety-Voice 与 v10 Energy-Context-Depth。v23 已把「记忆检索—语音意图—安全绑定」闭合，v10 已把「能量租约—深度模态—上下文预测」闭合，但动作生成侧仍是一个黑箱，隐含假设 **H5：动作生成器输出的动作块天然落在机械臂安全集内，且动作生成的计算/能量成本可忽略**。**扩散策略**以多模态动作分布与迭代去噪显著提升长程操作、多任务泛化和从演示中学习的能力，却同时暴露三个新裂缝：(i) 随机采样没有逐样本安全保证；(ii) 去噪步数 K 是天然的计算/能量旋钮；(iii) 条件（语音/上下文）与生成动作之间缺少可验证绑定。**机械臂**把这三个裂缝放大为硬约束：关节限位、速度/加速度、力矩、自碰撞、工作空间与奇异裕度。三者耦合出的新问题：**如何在去噪链的末段/每一步做可验证安全投影，把去噪预算纳入能量租约，并对整段动作块签发轨迹级证书，使扩散策略的泛化性不以机械臂安全为代价**。

## 0. 直觉与动机

**灵感 1（扩散策略 → 去噪链是可干预的安全注入点）**
直觉：扩散策略的价值不只是「生成得像人」，而是把动作生成暴露成一条可逐级干预的去噪链。传统做法是生成完再过滤，代价是大量样本被丢弃；我们改为**在去噪末段注入安全投影**：`x_{k-1} = Proj_C(D_θ(x_k,k))`。这样越靠近 `x_0`，样本越接近安全集，投影代价越小；同时去噪步数 K 直接对应计算/能量，可被能量租约裁剪。关键洞察：**安全投影既是约束，也是分布偏移源**——必须同时度量「投影后离原意图多远」。

**灵感 2（机械臂 → 安全集必须可线性化、可证伪）**
直觉：机械臂的动态可行域可写成一组标量约束函数 `h_j(a) ≥ 0`（关节限位、速度、力矩、碰撞距离、奇异裕度）。在动作块上做完整非线性投影太贵，因此在每个控制周期线性化并解一个小型 QP，等价于离散控制障碍函数（CBF）约束。机械臂还提供两个宝贵性质：约束是**可测的**（编码器/力矩传感器），因此投影是否生效可在线验证；约束是**局部的**（单步关节增量），因此可以给逐动作证书并向上组合成轨迹证书。

**灵感 3（耦合 → 证书-能量-意图的三方预算）**
直觉：更多去噪步 → 动作分布更尖、证书更窄，但更耗能；更强投影 → 安全裕度更大，但意图偏移更大；记忆热启动 → 更省算力，但可能复用过期条件。于是把三者放进同一个「证书—能量帕累托」：在能量租约允许的 `K_max` 内，选择使「任务效用 − 能量成本 − 意图偏移惩罚」最大的去噪预算与投影强度，并给出提前停止导致的证书宽度保守上界。

**耦合升级**：在 v10/v23 架构上新增 **证书化生成层（L2.5 Diffusion-Cert Layer）**。DCP 负责带安全投影的去噪；CDS 把去噪步数纳入能量租约；TCA 对动作块签发轨迹级证书并在线审计；DSM 复用带证书的种子；VCB 把语音条件与生成动作绑定；ARMGUARD 提供机械臂约束投影与不可行时的 fail-closed。五层 v11：根信任层（姿态租约 + 能量租约 + **动作证书租约**）、L1 几何层、L2 上下文/记忆层、**L2.5 证书化扩散生成层**、L3 CAR 守卫、L4 DCL 采集。

## 1. 形式化定义（增量：定义 59–64）

**定义 59（扩散动作轨迹与去噪预算）**
条件扩散策略在观测 `o_t`、上下文 `c_t`、语音 `v_t` 下生成动作块 `a_{t:t+H} ∈ A ⊂ R^{H×d}`。反向链
`x_K → x_{K-1} → … → x_0 = a_{t:t+H}`，
每步去噪成本为 `e_d` 焦耳。由能量租约 `ℓ_e=(B_t,P_m,τ_e,λ_b,B_min)` 得到最大步数
`K_max(t) = ⌊(E(t) − E_min)/e_d⌋`。
预算截断策略记作 `a^{K}`，`K ≤ K_max`。**预算语义**：K 同时是精度旋钮与能量旋钮，不能无偿增大。

**定义 60（机械臂安全集与约束函数）**
安全集 `C = { a ∈ A : h_j(a) ≥ 0, j=1..m }`，其中 `h_j` 覆盖关节限位、速度/加速度、力矩、自碰撞距离、工作空间与最小奇异值裕度。离散机械臂动力学 `a_{t+1}=f(a_t,u_t)`。给定建模误差界 `w` 与 Lipschitz 常数 `L_h`，定义鲁棒安全裕度
`ρ(a) = min_j h_j(a) − L_h·w`。
**安全判据**：`ρ(a) ≥ 0`。注意 `ρ` 是标量，便于做证书与在线监控。

**定义 61（安全投影算子与意图偏移）**
以加权范数 `‖·‖_M` 定义投影
`Proj_C(x) = argmin_{y∈C} ‖y − x‖_M`。
每步投影产生意图偏移 `d_proj = ‖x − Proj_C(x)‖_M`。给定语音/任务锚点 `g(v_t)`，定义意图保持度
`I(a) = sim(g(v_t), a)`。
**投影语义**：末段投影保证 `ρ(Proj_C(x)) ≥ 0`（QP 可行时），但若 `d_proj > ε_intent` 或 `I(a) < θ_intent`，则判定「安全但做错事」，必须重问或进入安全队列，而不是直接执行。

**定义 62（轨迹级联合证书）**
对动作块 `a_{t:t+H}` 签发证书
`A_t = (A_t^act, A_t^pose, α_a, K_t)`，
其中 `A_t^act` 为逐关节/逐时刻的区间或约束满足集合，`A_t^pose` 为执行该动作块后末端姿态的条件覆盖集。**轨迹 soundness**：
`P( ∀τ∈[t,t+H], ρ(a_τ) ≥ 0 | o_t,c_t,v_t,K_t ) ≥ 1 − α_a`。
**组合规则**：若每个子步条件证书的失败概率 ≤ `α_a/H`，由 union bound 得整段 ≥ `1−α_a`。姿态传播用 Lipschitz 合成：
`A_t^pose = P_t ⊕ Reach(A_t^act)`，其中 `Reach` 用 `L_φ` 放大，`P_t` 为 v9 的分层姿态证书。

**定义 63（证书—能量帕累托与证书感知提前停止）**
设证书宽度 `W(K)=E[rad(A_t^act(K))]` 随 K 单调不增，且边际收益递减。任务效用 `U_task(K)` 随 K 单调不减并饱和。定义
`K* = argmax_{K ≤ K_max} [ U_task(K) − λ_e·e_d·K − λ_i·d_proj(K) ]`
约束 `W(K) ≤ W_req`（任务要求的证书宽度）。
**提前停止准则**：若 `W(K) − W(K−1) < τ_W·e_d`，或剩余能量不足一步，则停在 `K_stop`。为保证 soundness，用离线校准曲线给保守上界：
`W(K_stop) + ΔW_max(τ_W) ≤ W_req`，否则不允许提前停止。

**定义 64（扩散种子记忆与条件绑定）**
种子记忆 `M_z = {(z_K, c, v, outcome, A, version)}`。热启动复用 `z_K^mem`。**接受条件**：
(i) 条件球半径 `dist(c_t,c_mem)+dist(v_t,v_mem) ≤ r_c`；
(ii) 证书版本与校准器版本一致；
(iii) 至少重跑 `K_v` 步验证去噪，且 `ρ(a^{K_v}) ≥ 0`；
(iv) 绑定 `B(g(v_t), a) ≥ θ_safe`。
记热启动证书转移间隙
`G_trans = sup_{‖c−c_mem‖≤r_c} ‖a^{K_v}(z_mem) − a^{K_v}(z_new)‖`，
并要求 `G_trans` 不超过证书宽度的校准裕度，否则拒绝热启动、回退全步去噪。

## 2. 新增 IP 与既有 IP 升级

**IP-69 DCP（Diffusion-Cert Policy）**
- 带条件（观测/上下文/语音/记忆种子）的去噪生成器
- 末段安全投影接口：可配置从第 `K_s` 步起每步投影
- 投影后意图偏移与绑定检查，超阈值即重问/排队
- 输出动作块 + 轨迹证书 `A_t`

**IP-70 CDS（Certificate-aware Denoising Scheduler）**
- 把 `K_max` 绑定到能量租约，与 ECPS 共享模态/算力预算
- 维护 `W(K)` 离线校准曲线，在线做证书感知提前停止
- 输出 `K_stop` 与保守证书宽度上界，禁止无校准的激进早停

**IP-71 TCA（Trajectory Certificate Auditor）**
- 逐动作块计算 `ρ(a)`、证书宽度、覆盖率的在线监控
- 用独立审计集做共形校准，输出 `α_a` 的经验覆盖
- 检测「投影后仍越界」「证书宽度漂移」「早停失效」并触发 fail-closed

**IP-72 DSM（Diffusion Seed Memory）**
- 存 `(z_K, c, v, outcome, A, version)`，按条件球 + 能量代价检索
- 证书版本校验与 `K_v` 步再验证，拒绝过期种子
- 命中时复用去噪轨迹，降低算力与能量；失败样本回灌 DCL

**IP-73 VCB（Voice-Conditioning Binder）**
- 把 VAD 的槽位/需求分布 `R(v)` 转成扩散条件（文本嵌入 + 空间锚点）
- 在动作块级计算绑定 `B(g(v_t), a)`，而非只绑定单帧姿态
- 绑定失败进入 `Q_safe`，并用语音二次确认或视觉互检消歧

**IP-74 ARMGUARD（Arm Safety Projection Layer）**
- 约束函数库：关节限位、速度/加速度、力矩、自碰撞、工作空间、奇异裕度
- 线性化离散 CBF-QP 投影；不可行时返回 infeasible 而非最小二乘兜底
- 与 CAR 联动：投影不可行 → 立即停车/柔顺保持 → fail-closed

**既有 IP 升级**
- IP-63 ECPS：能量租约新增「去噪预算」维度，与模态预算联合分配
- IP-66 MVR：记忆键新增扩散种子与证书版本，检索支持「种子热启动」
- IP-67 VAD：输出扩散条件，需求分布 `R(v)` 与生成动作分布做 KL 对齐
- IP-68 SAB：从「单帧姿态绑定」升级为「动作块轨迹绑定」
- IP-51 CAR：守卫新增 `ρ(a)≥0` 与轨迹证书 `A_t` 有效性
- IP-61 DCL：采集任务加入「投影失败/早停失效/热启动拒绝」样本
- IP-62 CCA：新增扩散采样红队、投影绕过、种子投毒测试
- IP-45 总线：新增 diffusion-budget / action-cert / seed-memory / project-status 话题

## 3. 算法骨架

每控制周期：
1. 读 `o_t, c_t, v_t, B_t, ℓ_e, ω_t`
2. DSM 检索带证书种子；若通过条件球 + 版本 + `K_v` 再验证，则热启动，否则随机初始化
3. ECPS/CDS 计算 `K_max` 与候选预算；TCA 查 `W(K)` 校准曲线
4. 沿去噪链执行 `D_θ`；从 `K_s` 步起对 `x_{k-1}` 做 `Proj_C`
5. 若投影不可行或 `d_proj>ε_intent` → 重问/安全队列/fail-closed
6. 若证书边际收益低于阈值或能量不足 → `K_stop`，并用保守上界复核 `W≤W_req`
7. VCB 计算动作块级绑定 `B(g(v),a)`；SAB 决定执行或排队
8. TCA 签发 `A_t`；CAR 用 `ρ(a)≥0 ∧ A_t 有效` 守卫；结果回灌 DCL/DSM

## 4. 本轮最大风险

**一句话**：安全投影可能把「语义正确但越界」的动作拉回安全集，却同时把「语义错误」的动作变成「合法但危险地错误」——如果 `d_proj` 与轨迹绑定 `B(g(v),a)` 未能捕获这种意图漂移，系统会以 100% 约束满足率执行错误动作，扩散策略的泛化性反过来放大了语义级安全风险。

**定义 65（投影可行性与执行语义）**
投影 QP
`min_{Δ} ‖Δ‖_M^2  s.t.  h_j(a_t+Δ) + γ h_j(a_t) ≥ 0, ∀j`
若可行，返回 `Δ*` 且 `ρ(a_t+Δ*)≥0`；若不可行，返回 `INFEASIBLE`。
执行语义三值化：`EXECUTE`（可行且绑定通过）/ `REQUEUE`（可行但意图偏移或绑定失败）/ `FAIL_CLOSED`（投影不可行或证书失效）。**禁止用最小二乘兜底替代 infeasible**，避免把不可行伪装成可行。

## 2. 关键算法 伪代码

### IP-74 ARMGUARD：约束与投影
```
def constraint_margin(a, model):
    h = []
    h += [a.joint_hi - a.q]                  # 关节上限
    h += [a.q - a.joint_lo]                  # 关节下限
    h += [v_max - abs(a.dq) / dt]            # 速度
    h += [tau_max - abs(a.tau)]              # 力矩
    h += [a.collision_dist - d_safe]         # 自碰撞/环境距离
    h += [a.sigma_min - sigma_req]           # 奇异裕度
    return h, min(h) - model.L_h * model.w   # 返回约束向量与鲁棒裕度

def project_C(x, a_t, model, gamma=0.3):
    h_x, _ = constraint_margin(x, model)
    A, b = linearize(h_x, x, a_t, gamma)     # 一阶离散 CBF 约束
    try:
        delta = solve_qp(H=model.M, c=-model.M @ x,
                         A_ineq=-A, b_ineq=b, bounds=model.bounds)
    except Infeasible:
        return None, 'INFEASIBLE', inf
    x_proj = x + delta
    _, rho = constraint_margin(x_proj, model)
    d_proj = weighted_norm(delta, model.M)
    return x_proj, ('OK' if rho >= 0 else 'INFEASIBLE'), d_proj
```

### IP-69 DCP：证书化扩散策略
```
def dcp_generate(o_t, c_t, v_t, lease, calib, model,
                 K_s=None, K_v=3, eps_intent=0.05, theta_intent=0.8):
    cond = encode_condition(o_t, c_t, v_t)
    K_max = max(0, floor((lease.remaining() - E_min) / e_d))
    if K_max < K_min:
        return 'FAIL_CLOSED', 'energy'
    seed, hit = dsm_lookup(c_t, v_t, lease, calib)   # IP-72
    if hit:
        x, K = seed.z_K, K_v
        x, rho = rerun_denoise(x, K_v, cond)         # 至少 K_v 步再验证
        if rho < 0 or dsm_gap(seed, c_t, v_t) > calib.G_max:
            x, K = init_noise(), K_max               # 拒绝热启动，回退全步
    else:
        x, K = init_noise(), K_max

    K_s = K_s if K_s is not None else max(1, K // 4)
    for k in range(K, 0, -1):
        eps = eps_theta(x, k, cond)
        x = ddim_step(x, eps, k)
        if k <= K_s:
            x_new, status, d_proj = project_C(x, a_t, model)
            if status == 'INFEASIBLE':
                return 'FAIL_CLOSED', 'projection'
            if d_proj > eps_intent or I(x_new, v_t) < theta_intent:
                return 'REQUEUE', d_proj
            x = x_new
        lease.spend(e_d)
        if k <= K_early and cert_gain(x, k, calib) < tau_W * e_d:
            if cert_width(x, calib) + calib.dW_max <= W_req:
                K_stop = k
                break
        if lease.remaining() < e_d:
            K_stop = k
            break
    a = x
    if cert_width(a, calib) > W_req:
        return 'FAIL_CLOSED', 'certificate'
    A_t = sign_certificate(a, o_t, c_t, v_t, K_stop, calib)
    B_prob = vcb_bind(v_t, a)                         # IP-73
    if B_prob < theta_safe:
        push(Q_safe, v_t); return 'REQUEUE', B_prob
    return a, A_t, K_stop
```

### IP-70 CDS：证书感知去噪调度
```
def schedule_budget(K_max, W_req, calib, task):
    # 离散帕累托：任务效用 - 能量 - 意图偏移
    best = (None, -inf)
    for K in range(K_min, K_max + 1):
        W = calib.width_curve[K]
        if W > W_req:
            continue
        d = calib.expected_proj_shift[K]
        obj = task.utility(K) - lambda_e * e_d * K - lambda_i * d
        if obj > best[1]:
            best = (K, obj)
    if best[0] is None:
        return None
    # 早停只允许在有保守上界的情况下发生
    K_star = best[0]
    if calib.dW_max(K_star) + calib.width_curve[K_star] > W_req:
        return None
    return K_star
```

### IP-71 TCA：轨迹证书审计
```
def audit(a, A_t, calib, model):
    _, rho = constraint_margin(a, model)
    if rho < 0:
        return 'VIOLATION', rho
    W = cert_width(a, calib)
    if W > A_t.W_req:
        return 'CERT_WIDENED', W
    if not conformal_cover(A_t, calib.audit_set, alpha_a):
        return 'COVERAGE_DROP', None
    calib.update_online(rho, W)      # 仅记录，不用于签发本轮证书
    return 'VALID', rho
```

### IP-72 DSM：证书种子记忆
```
def dsm_lookup(c_t, v_t, lease, calib):
    cands = [m for m in M_z if m.version == calib.version]
    cands.sort(key=lambda m: seed_distance(m, c_t, v_t, lease))
    for m in cands:
        if seed_distance(m, c_t, v_t, lease) <= r_c:
            return m, True
    return None, False

def seed_distance(m, c_t, v_t, lease):
    return (w_c * dist(m.c, c_t) + w_v * dist(m.v, v_t)
            + w_b * max(0, lease.P - m.P) + w_e * max(0, m.E - lease.E))
```

### IP-73 VCB：语音条件绑定
```
def vcb_bind(v_t, a):
    g_v = anchor_from_intent(v_t)         # 语音槽位→任务空间锚点
    traj = to_cartesian(a)
    closest = min(traj, key=lambda p: norm(p - g_v))
    d = norm(closest - g_v)
    B_prob = exp(-gamma_b * d / (a.cert_radius + eps))
    return B_prob
```

def execute_cycle(o_t, c_t, v_t, lease, calib, model):
    if not empty(Q_safe):

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| DCP 去噪 | `O(K·(d_ε + QP(m,d)))` | `O(Hd + m)` | 末段投影可行 ⇒ `ρ(a)≥0`；否则 fail-closed |
| CDS 预算选择 | `O(K_max)` | `O(K_max)` | 仅在 `W(K)+ΔW_max≤W_req` 时早停 |
| TCA 审计 | `O(Hd + |S_audit|)` | `O(m)` | 共形覆盖 ≥ `1−α_a`（可交换性假设下） |
| DSM 检索 | `O(|M_z|·d_c)` | `O(|M_z|·d_c)` | 版本一致 + `K_v` 再验证 + `G_trans≤G_max` |
| VCB 绑定 | `O(Hd)` | `O(1)` | `B≥θ_safe` 才执行，否则排队 |
| ARMGUARD QP | `O(m^3)` 最坏 | `O(m^2)` | 可行解满足线性化 CBF；不可行显式返回 |

**定理 1（投影安全）**：若 `Proj_C(x)` 的 QP 可行，且约束线性化误差被 `L_h·w` 覆盖，则 `ρ(Proj_C(x)) ≥ 0`。若 QP 不可行，DCP 不输出动作并进入 fail-closed。
**证明**：可行解满足 `h_j(a_t+Δ)+γh_j(a_t)≥0` 与 `h_j(a_t)≥0`，故线性化后 `h_j(a_t+Δ)≥−(1−γ)h_j(a_t)` 不保证非负？——因此额外用精确 `constraint_margin` 复检；复检 `ρ≥0` 才返回 OK，否则标记 INFEASIBLE。故输出动作满足鲁棒裕度。∎

**定理 2（轨迹证书组合）**：若动作块每个时刻的条件失败概率 ≤ `α_a/H`，且各时刻失败事件由 union bound 控制，则 `P(∀τ,ρ(a_τ)≥0) ≥ 1−α_a`。若末段每步投影且最终复检通过，则可取 `α_a` 更小的经验覆盖（由 TCA 共形校准给出）。
**定理 3（早停 soundness）**：若使用离线校准的保守曲线满足 `W(K_stop)+ΔW_max≤W_req`，则早停输出的证书宽度仍满足任务要求；否则 CDS 拒绝早停并回退到 `K_star` 或 fail-closed。
**定理 4（热启动安全）**：若 `version` 一致、条件球半径 ≤ `r_c`、`K_v` 步再验证 `ρ≥0`、`G_trans≤G_max` 且绑定通过，则热启动动作块以与全步去噪相同的证书宽度上界执行；任一条件失败则回退全步。

## 6. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 投影把错误意图「洗白」为安全动作 | 高 | `d_proj` + `I(a)` + 动作块级 `B(g(v),a)` 三重门；失败重问 |
| 早停破坏证书覆盖 | 高 | 保守校准上界 `ΔW_max`；无上界禁止早停 |
| 热启动种子携带过期条件 | 高 | 证书版本 + 条件球 + `K_v` 再验证 + `G_trans` 上界 |
| QP 在狭窄空间频繁不可行 | 中 | 显式 INFEASIBLE → 柔顺保持/停车；DCL 采集不可行场景 |
| 扩散尾部采样越界 | 中 | 末段逐步投影 + TCA 在线巡检 + 红队采样 |
| 语音条件歧义导致绑定失败 | 中 | `Q_safe` + 语音二次确认 + 视觉互检 |
| 校准集与实机分布漂移 | 中 | 在线只记录不签发；定期重校准并升版本号 |

## 7. 本轮最大风险

**一句话**：安全投影可能把「语义正确但越界」的动作拉回安全集，却同时把「语义错误」的动作变成「合法但危险地错误」——如果 `d_proj` 与动作块级绑定 `B(g(v),a)` 未能捕获这种意图漂移，系统会以 100% 约束满足率执行错误动作，扩散策略的泛化性反过来放大了语义级安全风险。
