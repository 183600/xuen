# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC IP-153~160；灵感循环第 1 轮；本轮灵感：「机器人」×「步态规划」）

> 第 60 轮把闭环推进为「场景→意图→约束→阻抗→执行→EV-exec→场景更新」，用 SSM×CIEC×EPIR×SERC×PCE++++ 让机器人具备了「认知驱动的场景落地」能力。但它默认了一个从未被证明的前提：**机器人始终站在一个连续、稳定、可瞬时调节的支撑之上**。步态规划恰好把这个前提撕开：腿式机器人的支撑集 S(t) 是**时变的、离散切换的、会发生冲击与滑移的**。由此暴露四个结构性局限：
> 1. **从空间接地到时间接地的缺口**：第 60 轮的 K_safe、SIC、J_exec 都是对单个接触构型的证书；而步态是 touchdown/liftoff/load-transfer 组成的事件序列。逐接触点的证书都为真，并不意味着整段步态安全——冲击、载荷转移、漏接触、错相位恰恰发生在**切换瞬间**。
> 2. **场景语义停在「阻抗」层，未进入「步态可行域」**：π_scene(K|z) 描述的是柔顺/摩擦下的阻抗先验，但腿式机器人还需要地形承载、沉陷、坡度、落足可用性与步态族选择。同一个「湿滑桌面」对机械臂是 K_safe 收窄，对腿式机器人则是落足点、步长、节拍、占空比的联合收缩。
> 3. **证据最终一致 ≠ 控制相位一致**：EPIR 保证 EV-exec 最终能在云端重建，但腿式机器人常按腿/关节分成多个 ROS 节点。若某条腿未收到「支撑相开始」就抬腿，局部证据完全正确，全局支撑集却已经破裂。**证据可以迟到，控制不能超前。**
> 4. **意图缺少承诺点与终止状态语义**：第 60 轮的 CIEC 把「慢点/停」映射为连续约束，但摆动腿不能在半空瞬时冻结。意图必须在**承诺点之前**投影到步态可行域；「停」必须是一个「完成当前摆动到最近安全落足点再站立」的安全停止计划，而不是一次参数写入。

## 0. 直觉与动机

**灵感 1（机器人 → 步态是「时序接触」而非静态姿态）**
直觉：机械臂的接地问题是「在哪里、用多大力」；腿式机器人的接地问题是「哪只脚、在什么时刻、以什么顺序、在多长窗口内」。支撑集 S(t) 是一段段离散区间，身体在两次接触之间处于欠驱动飞行/单支撑状态。关键洞见：**第 60 轮给出的是「空间接地点证书」，步态需要的是「时间轴上的接触事件证书」**——安全不再是一个点的属性，而是一个事件序列加相位切换的属性。

**灵感 2（步态规划 → 接触事件契约 CEC）**
直觉：每次 touchdown 都像一次带物理副作用的工具调用：前置条件是摆动腿已到达落足点、足端速度/姿态在窗口内、地面摩擦与承载可用；后置条件是法向力建立、滑移小于阈值、载荷转移完成；安全包络是冲击速度、法向/切向冲量、关节力矩；见证是 EV-contact；回退是收腿、换落足点或进入相位冻结。关键洞见：**接触是「带物理副作用的离散承诺」**——没有见证的 touchdown 不算 touchdown，未 discharge 的事件不得推进全局相位。

**灵感 3（地形 → 地形-步态先验 TGP）**
直觉：场景对操作臂是阻抗标签，对腿式机器人是**落足点可用性 + 承载 + 摩擦 + 沉陷**的联合先验。把 π_scene(K|z) 扩展为 π_gait(θ|z)，其中 θ=(步态族, 节拍 f, 占空比 β, 步高 h, 步长 ℓ, 质心高度 z_c, 站宽 w, 相位阻抗调度)。关键洞见：**场景不是阻抗标签，而是步态参数的可信可行域**；地形参数 (μ, 沉陷 c, 坡度 α, 粗糙度 ρ) 必须直接进入落足点与支撑集选择，而不是等执行失败后再回退。

**灵感 4（相位 → 相位索引阻抗协同编译 GICC 与混合接触证书 HCC）**
直觉：摆动相需要「低刚度、高阻尼」以抬腿避障并抵抗扰动；支撑相需要「按地形先验的支撑刚度」；冲击瞬间需要「力限幅 + 高阻尼」。若仍用单一 K_safe，摆动与支撑会互相拉扯，且相位切换处的阻抗跳变本身就会制造冲击。关键洞见：**阻抗应是相位 φ 的函数 K_ℓ(φ)，切换处必须满足连续性/冲量界**；证书不能逐相位独立拼接，必须给出**序列级混合接触证书**——同时约束接触可行性、生存域、冲击界、相位顺序与「任意状态下都存在安全停止计划」。

**灵感 5（ROS → 相位因果隔离 PCI）**
直觉：分布式腿式机器人中，每条腿都可能是一个 ROS 节点；相位消息会乱序、丢包、重复。若控制只依赖「最终会到达」的证据，某条腿可能在全局支撑集尚未确认时就开始摆动。关键洞见：**必须把 EPIR 从「证据不丢」升级为「控制不超前」**——用相位向量时钟保证因果交付；一旦检测到相位间隙，进入「相位冻结」（保持当前支撑集、降低质心、增大支撑阻尼、禁止 liftoff），宁可不走，也不带着未验证相位走。

**灵感 6（意图 → 意图-步态约束投影 GICP；预算 → PCE+++++；闭环 → GGCL）**
直觉：用户说「慢点/别晃/停」时，映射的不只是 v_max，而是节拍、占空比、步高、站宽、质心高度与终止状态。「停」不能在半空冻结，必须先完成当前摆动到最近安全落足点再站立。关键洞见：**意图要在承诺点 t_c 之前投影到「步态可行域 ∩ 生存域」**；不可行时显式拒绝或进入安全停止，而不是静默忽略。预算相应扩展为 B_gait=(B_plan, B_contact, B_sync, B_exec)：规划、接触探测、相位同步、执行任一耗尽，都触发对应的保守模式；最终由步态接地闭环 GGCL 把地形先验、意图投影、协同编译、混合证书、相位隔离与证据更新串成闭环。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（时序接触计划 TCS 与接触事件契约 CEC）**
一个步态计划是带时间的接触事件序列
```
G = (L, E, τ, Φ, S)
E = E_TD ∪ E_LO ∪ E_LT,   e = (ℓ, type, t, p, W, wit)
```
其中 L 为腿集合，type ∈ {touchdown(TD), liftoff(LO), load_transfer(LT)}，t 为事件时刻，p 为落足点，W 为期望扳手，wit 为该事件的见证规范，Φ=(φ₀,φ₁,...) 为相位序列，S(t)={ℓ | TD_ℓ≤t<LO_ℓ} 为支撑集。
**良构条件**：(C1) 每条腿的 TD/LO 严格交替，且支撑时长 ≥ τ_stance_min；(C2) 任意 t 有 S(t)≠∅；(C3) 同一腿的摆动区间互不重叠；(C4) 相位只在事件时刻切换。
每个事件携带**接触事件契约**：
```
CEC_e = (Pre_e, Post_e, Env_e, Wit_e, Fallback_e, dl_e)
```
- Pre_e：落足点可达、足端速度/姿态在窗口内、无自碰撞、地面摩擦下界可用；
- Post_e：法向力建立、滑移比 s≤s_max、载荷转移完成；
- Env_e：冲击速度、法向/切向冲量、关节力矩/功率包络；
- Wit_e：必须写入 EV-contact 的最小字段（phase_id, seq_id, t, 实测力/位/电流, hash）；
- Fallback_e：收腿/换落足点/相位冻结/安全站立；
- dl_e：该事件的决策截止时刻。
定义两个判定：**可派发** `admissible(e) ⇔ Pre_e ∧ Env_e⊆E_env ∧ deadline_ok(e)`；**已结算** `settled(e) ⇔ Post_e(EV-contact_e)`。只有 `admissible` 的事件可以执行，只有 `settled` 的事件才能推进相位。

**定义 162（地形-步态先验 TGP）**
地形隐变量 z=(μ, c, α, ρ, η)：摩擦系数、柔顺/沉陷、坡度、粗糙度、承载屈服。步态参数 θ=(family, f, β, h, ℓ, z_c, w, K(φ))，其中 family ∈ {walk, trot, pace, bound, crawl, wheel-leg}。地形-步态先验为
```
π_gait(θ|z) = P(family|z) · N(θ_cont; μ_g(z), Σ_g(z))
```
并维护**接触证据更新**：由 EV-contact 计算滑移比 s=‖v_t‖/max(v_n,ε)、沉陷 d、法向冲量 J_n，用贝叶斯/粒子滤波更新 (μ,c,η) 的后验。安全约束使用**保守分位**：
```
μ_req(θ,e) ≤ q_α(μ|z),   c_req(θ,e) ≤ q_α(c|z)
```
即落足点所需摩擦/承载必须落在地形后验的 α 下分位以内，而不是均值。TGP 使「场景改变」在规划前就收缩步态可行域，而不是执行下滑后再回退。

**定义 163（相位索引阻抗协同编译 GICC）**
协同编译算子
```
C_g: (G, π_gait, C_intent, H) → (K_ℓ(φ), P_foot, Cert_g) ∪ {⊥}
```
为每条腿、每个相位编译阻抗调度
```
K_ℓ(φ) = (K_p(φ), K_d(φ), F_max(φ), v_max(φ))
```
典型语义：摆动相 `K_p↓, K_d↑`（抬腿避障、抗扰）；支撑相 `K_p` 取地形先验的支撑刚度，`K_d` 保证载荷转移不振荡；冲击相 `F_max` 限幅、`K_d↑` 吸收法向冲量。
必须满足：
1. **硬件包络**：K_ℓ(φ)∈E_K(H)，且力矩/速度/功率/热约束可行；
2. **相位连续/冲量界**：相邻相位的阻抗跳变满足 `‖K(φ⁺)−K(φ⁻)‖ ≤ ΔK_max`，且预测冲击 `J_n≤J_n_max`；
3. **意图相容**：K_ℓ(φ) 落在 GICP 投影后的约束集内；
4. **可回退**：编译结果附带至少一个可执行的安全停止计划 σ_stop。
**可靠性（soundness）**：若 C_g 返回非 ⊥ 且硬件按 H 执行，则每个相位的安全包络不被突破，且相位切换的冲击不超过 Env_e。

**定义 164（混合接触证书 HCC）**
混合接触证书是序列级六元组
```
J_gait = (J_contact, J_balance, J_impact, J_phase, J_fallback, J_evidence)
```
- **J_contact**：∀e∈E，落足点 p_e 在可达集内、摩擦锥裕度 `μ_req ≤ q_α(μ|z)`、无自碰撞；
- **J_balance**：∀相位边界及相位内采样点 t，生存量 ξ(t)（捕获点/质心角动量）满足 `ξ(t)∈V_ε`，其中 V_ε 为带不确定度 ε 的生存核；
- **J_impact**：∀TD，`J_n≤J_n_max`、`|J_t|≤μ_lo·J_n`、`v_impact≤v_impact_max`；
- **J_phase**：TCS 良构、S(t) 非空、事件全序且无非法并发；
- **J_fallback**：∀q∈Φ，存在时长 ≤T_stop 的安全停止计划 σ_stop(q)，终止于静态稳定站立；
- **J_evidence**：每个事件都有满足 Wit_e 的 EV-contact，且 phase_id/seq_id/hash 可验证。
```
J_gait_valid ⇔ J_contact ∧ J_balance ∧ J_impact ∧ J_phase ∧ J_fallback ∧ J_evidence
```
关键点：**J_gait 不是逐相位证书的合取**。它显式包含切换瞬间的冲击、载荷转移与回退可达性；任一项为假，整段步态不得派发。

**定义 165（相位因果隔离 PCI）**
每个控制节点维护局部相位 clock，消息
```
m = (phase_id, VC, seq, kind, hash)
```
其中 VC 为向量时钟，kind∈{TD,LO,LT,PHASE_ADVANCE}。**因果交付**规则：节点仅当 m 的所有因果前驱均已交付时才接受；**全局相位推进**条件：
```
advance(φ→φ') ⇔ ∀n∈Nodes: VC_n[φ] ≥ required(φ')  ∧  no_gap(seq)
```
若出现 seq 间隙、VC 落后或超时，进入**相位冻结**算子：
```
Freeze(S) = (保持当前支撑集 S, z_c↓, K_stance↑, D_stance↑, 禁止任何 liftoff)
```
冻结期间从 S_shadow 做确定性重放；重放成功后恢复，超时则转入受控站立/安全停止。**PCI 不追求证据最终一致，而保证控制绝不基于未验证的未来相位。**

**定义 166（意图-步态约束投影 GICP）**
意图集 I_gait={慢, 稳, 快, 停, 危险}。投影算子
```
ϕ_gait: I_gait × Θ_feasible → Θ_constrained ∪ {⊥}
```
- 「慢」：f≤0.8f_nom，β≥β_nom+0.1，h≤0.8h_nom，站宽 w↑；
- 「稳」：w↑、z_c↓、K_d↑、减小摆动腿抬升速度；
- 「快」：f≤f_max^safe，但 HCC 必须成立，不允许以牺牲生存裕度为代价；
- 「停」：选择安全停止计划 σ_stop：若处于双支撑则直接站立；若处于摆动中，则完成当前摆动到最近安全落足点后站立；**禁止半空冻结或强制收腿**；
- 「危险」：立即触发 σ_estop（就近落足/受控下蹲/保护性支撑）。
**承诺点**：对事件 e 定义 `t_c(e)=t_e−τ_commit(e)`。意图若在 t_c(e) 之后到达，只能在下一个事件边界生效，不得在摆动中途突变参数；安全关键意图除外。若 `Θ_constrained=∅` 或投影破坏生存域，返回 E_INTENT_INFEASIBLE 并请求澄清或进入安全停止，绝不静默忽略。

**定义 167（步态认知预算 PCE+++++）**
```
B_gait = (B_plan, B_contact, B_sync, B_exec)
```
- B_plan：重规划次数/规划时延；
- B_contact：主动接触探测步数（用于估计 μ、沉陷）；
- B_sync：相位同步消息/重传/因果恢复开销；
- B_exec：原有 WCET/总线/热/优先级余量。
价值函数扩展为
```
voi_gait(π) = VOI_meta_pessimistic(π) − cost_plan − cost_contact − cost_sync − cost_exec
```
预算耗尽策略：B_plan 耗尽⇒使用高占空比 crawl 保守步态；B_contact 耗尽⇒使用 μ 的下分位、不做探索步；B_sync 异常⇒退化为集中式相位或直接冻结；B_exec 耗尽⇒安全站立/停止。**任一预算耗尽都必须触发对应的显式模式，绝不允许静默放宽安全约束。**

**定义 168（步态接地闭环 GGCL）**
算子 GGCL(M, task, intent)：
```
① z_t ← M.scene.update(telemetry, EV-contact)              # 地形/场景后验
② Θ ← M.tgp.sample(z_t)                                     # 地形-步态先验采样
③ Θ_c ← M.gicp.project(intent, Θ)                           # 意图投影（含承诺点检查）
④ G ← M.tcs.plan(Θ_c, task)                                 # 时序接触计划
⑤ (K_sched, Cert_g) ← M.gicc.compile(G, π_gait, C_intent, H)
⑥ J_gait ← M.hcc.certify(G, K_sched, z_t)                   # 混合接触证书
⑦ if ¬J_gait.valid: G ← M.tcs.repair(G, J_gait); goto ⑤     # 修复/回退保守步态
⑧ dispatch(G, K_sched, J_gait)                              # 带证书派发
⑨ EV-contact ← wait_contact_events()                        # 逐事件见证
⑩ if ¬M.pci.consistent(EV-contact): Freeze(S); replay       # 相位因果隔离
⑪ M.tgp.update(EV-contact); M.budget.consume(...)           # 地形/预算更新
⑫ return (G, K_sched, J_gait, EV-contact, M.mode)
```
闭环的关键不是「规划完再执行」，而是**执行中的每一个接触事件都反过来更新地形先验与相位一致性**；失败不是异常，而是证书与回退路径必须覆盖的一等状态。

## 2. 关键算法伪代码

### IP-161 TCS（时序接触计划与接触事件契约）

```python
from dataclasses import dataclass, field

@dataclass
class ContactEvent:
    leg: str
    kind: str                 # 'TD' | 'LO' | 'LT'
    t: float
    foot: np.ndarray
    wrench: np.ndarray
    phase_id: int
    seq: int
    witness: dict = field(default_factory=dict)

class TimedContactSchedule:
    def __init__(self, legs, events, phases):
        self.legs, self.events, self.phases = legs, events, phases

    def support_set(self, t):
        return {e.leg for e in self.events
                if e.kind == 'TD' and e.t <= t and
                   not any(o.kind == 'LO' and o.leg == e.leg
                           and e.t <= o.t <= t for o in self.events)}

    def validate(self):
        for leg in self.legs:
            ev = sorted([e for e in self.events if e.leg == leg], key=lambda e: e.t)
            kinds = [e.kind for e in ev if e.kind in ('TD', 'LO')]
            if any(a == b for a, b in zip(kinds, kinds[1:])):
                return False, f'{leg}: TD/LO not alternating'
            for a, b in zip(ev, ev[1:]):
                if b.t <= a.t:
                    return False, f'{leg}: non-monotone event time'
        for e in self.events:
            if not self.admissible(e):
                return False, f'event {e.seq} inadmissible'
        return True, 'ok'

    def admissible(self, e):
        return (e.leg in self.legs and e.t >= 0 and
                self._precondition(e) and self._envelope_ok(e))

    def settle(self, e, ev_contact):
        e.witness = ev_contact
        return self._postcondition(e, ev_contact)
```

### IP-162 TGP（地形-步态先验）

```python
class TerrainGaitPrior:
    def __init__(self, families=('walk', 'trot', 'pace', 'bound', 'crawl')):
        self.families = families
        self.belief = {}          # z -> (mu_g, Sigma_g, family_post)

    def update(self, ev_contact):
        s = np.linalg.norm(ev_contact['v_t']) / max(ev_contact['v_n'], 1e-6)
        d = ev_contact['sinkage']
        jn = ev_contact['normal_impulse']
        self._bayes_update(mu_latent=(ev_contact['mu_hat'], ev_contact['c_hat']),
                           slip=s, sinkage=d, impact=jn)
        if s > self.slip_threshold:
            self._penalize_family('bound'); self._penalize_family('pace')

    def sample(self, z, n=16):
        fam = self._posterior_over_families(z)
        out = []
        for family in fam:
            params = np.random.multivariate_normal(*self._gaussian(z, family), size=n)
            out += [self._to_theta(family, p) for p in params
                    if self._robust_friction_ok(family, p, z)]
        return out

    def robust_friction(self, z, alpha=0.05):
        return self._quantile(self.belief[z].mu, alpha)
```

**正确性定理（TGG）**：
假设 A66–A72 成立：
- **(A66)** TCS 良构：事件有限、逐腿 TD/LO 交替、任意 t 支撑集非空；
- **(A67)** 地形后验校准：真实 μ、c 以概率 ≥1−α 落在 q_α 以上；
- **(A68)** GICC 可靠：编译结果在硬件包络内，相位切换冲击不超界；
- **(A69)** HCC 的 J_balance 蕴含在不确定度 ε 下有界生存；
- **(A70)** PCI 的因果交付或冻结保证不存在未验证相位推进；
- **(A71)** GICP 投影不放松任何安全包络，且「停/危险」终止于安全状态；
- **(A72)** B_gait 单调消耗，任一耗尽触发对应保守模式。

则：
1. **接触序列安全性**：若 J_gait_valid，则每个接触事件满足摩擦锥、冲击界与支撑集非空，且所有事件均可由 EV-contact 结算——逐点安全被提升为序列安全。
2. **生存性**：若 J_balance 成立，则相位边界与相位内状态保持在 V_ε 内；且每个状态存在 ≤T_stop 的安全停止计划，不会出现「证书为真但无路可退」。
3. **相位一致性**：PCI 下不存在节点在未获得因果证据时推进相位；冻结期间支撑集保持不变，证据链可由 shadow 确定性重建。
4. **意图安全性**：GICP 投影后的意图只会收紧、不会放松 Env；不可行意图被显式拒绝或转为安全停止，不会静默降级。
5. **预算安全性**：任一 B_gait 耗尽都必须进入对应保守模式，不存在「预算耗尽仍按原计划执行」。

### IP-161 TCS/CEC

```python
@dataclass
class ContactEvent:
    leg: str
    kind: str                 # 'TD' | 'LO' | 'LT'
    t: float
    foot: np.ndarray
    wrench: np.ndarray
    phase_id: int
    seq: int
    witness: dict = field(default_factory=dict)

class TimedContactSchedule:
    def __init__(self, legs, events, phases):
        self.legs, self.events, self.phases = legs, events, phases

    def support_set(self, t):
        return {e.leg for e in self.events
                if e.kind == 'TD' and e.t <= t and
                   not any(o.kind == 'LO' and o.leg == e.leg
                           and e.t <= o.t <= t for o in self.events)}

    def validate(self):
        for leg in self.legs:
            ev = sorted([e for e in self.events if e.leg == leg], key=lambda e: e.t)
            kinds = [e.kind for e in ev if e.kind in ('TD', 'LO')]
            if any(a == b for a, b in zip(kinds, kinds[1:])):
                return False, f'{leg}: TD/LO not alternating'
            if any(b.t <= a.t for a, b in zip(ev, ev[1:])):
                return False, f'{leg}: non-monotone event time'
        for e in self.events:
            if not self.admissible(e):
                return False, f'event {e.seq} inadmissible'
        return True, 'ok'

    def admissible(self, e):
        return (e.leg in self.legs and self._precondition(e)
                and self._envelope_ok(e) and self._deadline_ok(e))

    def settle(self, e, ev_contact):
        e.witness = ev_contact
        return self._postcondition(e, ev_contact)
```

### IP-162/163 TGP + GICC

class TerrainGaitPrior:
    def update(self, ev_contact):
        s = np.linalg.norm(ev_contact['v_t']) / max(ev_contact['v_n'], 1e-6)
        self._bayes_update(mu=(ev_contact['mu_hat'], ev_contact['c_hat']),
                           slip=s, sinkage=ev_contact['sinkage'],
                           impact=ev_contact['normal_impulse'])
        if s > self.slip_threshold:
            self._penalize_family('bound'); self._penalize_family('pace')

    def sample(self, z, n=16):
        return [self._to_theta(f, p)
                for f in self._posterior_over_families(z)
                for p in np.random.multivariate_normal(
                    *self._gaussian(z, f), size=n)
                if self._robust_friction_ok(f, p, z)]

    def robust_friction(self, z, alpha=0.05):
        return self._quantile(self.belief[z].mu, alpha)

def compile_gait_impedance(gait, prior, intent_constraints, hardware):
    K_sched, footholds = {}, {}
    for phase in gait.phases:
        for leg in gait.legs:
            K = phase_impedance(phase.kind, leg, prior, intent_constraints)
            if not in_hardware_envelope(K, hardware):
                return None, None
            if not continuity_ok(K_sched.get((leg, phase.prev_id)), K):
                return None, None
            K_sched[(leg, phase.id)] = K
        if not impulse_bound_ok(phase, K_sched):
            return None, None
    if not all(intent_compatible(e, K_sched, intent_constraints) for e in gait.events):
        return None, None
    return (K_sched, footholds), build_compile_cert(gait, K_sched)

## 4. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性 |
|---|---|---|---|
| TCS | O(|E| log|E|) | O(|E|) | 事件全序、支撑集非空、TD/LO 交替 |
| TGP | O(N_s·d_θ) | O(N_s·d_θ) | 地形 α 分位保守约束 |
| GICC | O(|Φ|·|L|·d_K + QP) | O(|Φ|·|L|) | 包络 + 相位连续 + 冲击界 |
| HCC | O(|E| + N_v + |Φ|·T_stop) | O(|E| + V_ε) | 序列级证书 + 回退可达 |
| PCI | O(1)/O(|N|) | O(|N|·|Φ|) | 因果交付或冻结 |
| GICP | O(d_θ) | O(1) | 承诺点 + 终止安全 |
| GGCL | O(规划视界) | 复用 | 证书失败可修复或安全停止 |

**正确性定理（TGG）**：若 A66–A72 成立，则
1. **接触序列安全性**：J_gait_valid ⇒ 每个事件的摩擦锥/冲击界/支撑集满足，且全部事件可由 EV-contact 结算。
2. **生存性**：J_balance ∧ J_fallback ⇒ 状态保持在 V_ε 且任意状态存在 ≤T_stop 的安全停止计划。
3. **相位一致性**：PCI ⇒ 无节点基于未验证相位推进；冻结时支撑集不变，证据链可确定性重建。
4. **意图安全性**：GICP ⇒ 意图只收紧不放松 Env；不可行意图被拒绝或转为安全停止。
5. **预算安全性**：任一 B_gait 耗尽 ⇒ 进入对应保守模式，不存在静默放宽。

## 6. 本轮最大风险

**一句话**：最大风险是把步态当成「一串独立的连续阻抗证书」，而真正的危险集中在 touchdown/liftoff/load-transfer 这些**离散切换瞬间**——连续时间的不变式在冲击与未建模接触下可能瞬间失效，一次错相位或漏接触就能让整条证书链作废并导致跌倒；因此必须以「接触事件契约 + 序列级 HCC + 相位因果冻结 + 始终可达的安全停止」作为硬门，任何一项证书不成立都只能停，不能赌。
