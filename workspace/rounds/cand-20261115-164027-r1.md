# 第 1 轮（灵感循环第 1 轮；本轮灵感：「零样本泛化」×「专利布局」）

> **基线纪律**：本轮为冷启动第 1 轮。工作区已有的 MetricVoiceGauge v7（OTL/GCT/ER）整体视为 **prior art**，只继承三条工程常识——软→硬退化、语音指令类型化、证书可发布。新的独立权利要求必须落在 v7 的 claim space 之外，否则本轮在专利意义上只是 v7 的从属改进，而非独立创新。

## 0. 直觉与动机

**灵感 1（零样本泛化 → 从“逐任务认证”转向“原语包络 + 组合闭包”）**

直觉：人类面对没见过的任务，不是重新训练，而是把任务拆成见过的动作原语，并知道每个原语的“安全使用范围”。只要新任务是这些原语的合法组合，且组合深度不深、输入分布不离谱，就应能给出一个保守但非空的安全下界；否则退回硬约束。

形式化直觉：把每个能力原语 \(p\) 看作一个带包络的算子 \(E_p=(Pre_p, Post_p, \rho_p, c_p)\)，其中 \(\rho_p\) 是认证安全裕度。任务 \(\tau\) 是原语序列 \(p_1\circ\cdots\circ p_n\)。若每次组合至多损失 \(\lambda\) 的裕度、输入偏移至多损失 \(\nu(d)\)（\(d\) 为新颖度距离），则

```
ρ(τ) ≥ min_i ρ_{p_i} − λ(n−1) − ν(d)
```

这个不等式就是“零样本”的全部内容：不保证具体性能，只保证一个可计算、可退化、可审计的安全下界。

**灵感 2（专利布局 → 把技术模块写成权利要求图）**

直觉：一个研究想法是否“值钱”，取决于它能否被写成一条独立权利要求，并且有从属权利要求守住变体、有 FTO 分析避开 prior art。专利布局反过来会逼我们把“零样本”从口号变成可实施、可验证、可界定的技术特征。

形式化直觉：把权利要求集合写成图 \(C=(V,E)\)，\(V\) 中每个节点 \(c\) 有覆盖域 \(S(c)\)、新颖性裕度 \(\eta(c)\)、可实施性 \(e(c)\)，\(E\) 表示“从属/更窄”关系。组合覆盖 \(\mathrm{Cov}(P)=\cup S(c)\)。于是专利布局变成一个带约束的集合覆盖问题：在有效性/FTO 约束下最大化覆盖，同时用设计绕行距离 \(\Delta(c)\) 衡量每条权利要求的“防绕行强度”。

**协同**：零样本泛化提供“宽”的技术覆盖（组合闭包），专利布局提供“窄”的合法性约束（新颖性/创造性/可实施性）。二者形成 **技术宽度 ↔ 法律宽度** 的双向调节环：技术太宽 → 证书空洞、权利要求易被无效；技术太窄 → 易被设计绕行。

## 1. 研究问题（第 1 轮）

- **Q1（组合证书）**：如何为未见任务组合 \(\tau\) 给出非空的安全下界，并显式刻画“组合深度—松弛项”的权衡？
- **Q2（新颖度监测）**：如何在运行时判断输入是否落在认证覆盖集内，并把“不确定”转成可退化的条件执行而非 crash？
- **Q3（权利要求图）**：如何把 CCG/ZSC/NCM 写成独立+从属权利要求，并量化每条权利要求的覆盖范围与设计绕行距离？
- **Q4（协同演化）**：专利布局发现的“绕行缺口”如何反向生成下一轮技术研究问题？

## 2. 设计原则（P1–P5）

**P1 组合能力文法（Compositional Capability Grammar, CCG）**
任务不是“一个任务”，而是原语文法 \(G\) 的句子。文法同时约束可执行性和可认证性；不可解析的指令直接落入退化分支。

**P2 组合零样本证书（Zero-Shot Certificate, ZSC）**
证书输出三态：Certified / Conditional / Refused。Certified 给出下界 \(\rho(\tau)\)；Conditional 要求人工确认或缩短任务；Refused 退回硬约束 \(\pi_0\)。绝不允许“未认证但照常执行”。

**P3 新颖度覆盖监测（Novelty-Coverage Monitor, NCM）**
用嵌入距离 \(d(x)\) 判断输入是否落在参考分布覆盖集 \(C_\delta\) 内。NCM 只负责“报警”，不负责“决策”；决策权在 ZSC，保证模块可替换。

**P4 包络一致退化（Envelope-Consistent Fallback, ECF）**
退化策略 \(\pi_0\) 自身必须带硬包络 \(E_0\)；若连 \(Pre_0\) 都不满足，则安全停机。退化不是“降级到另一个未验证策略”。

**P5 权利要求图协同设计（Claim-Graph Co-Design, CGCD）**
每个技术模块至少映射到一条权利要求；每条独立权利要求必须有可实施实施例、新颖性论证和至少一个从属变体；若某模块无法写成权利要求，则它不应成为本轮的核心贡献。

## 3. 与 prior art 的接口（如何不侵权地退化）

- CCG 解析失败 ⇒ 退回原语级执行 + 人工确认；
- NCM 失效 ⇒ \(\delta=0\)，只执行已认证原语；
- ZSC 下界 \(\le 0\) ⇒ 退回硬约束策略 \(\pi_0\)；
- 权利要求被 prior art 阻断 ⇒ 走 DAR 最小的设计绕行分支，而不是放弃整个方案。

## 4. 预期贡献

1. **组合零样本证书**：给出随组合深度线性衰减、随新颖度单调衰减的安全下界，并给出非空证书的最大深度公式；
2. **运行时新颖度监测 + 条件执行**：把 OOD 检测从“分类问题”改造成“证书状态机”；
3. **权利要求图方法**：把技术模块映射为 claim graph，定义覆盖/绕行距离，并证明覆盖最大化是子模集合覆盖问题；
4. **双轨实验协议**：零样本任务套件 + 专利景观/FTO 分析，同时评估技术有效性与法律可主张性。

## 5. 本轮最大风险

**一句话**：组合证书的松弛项会随组合深度线性增长，导致在最需要保证的长程未见任务上证书恰好变为空，而专利布局又可能把独立权利要求写得过窄，被竞争者的等价替换轻易绕开。

## 1. 符号体系（定义 1–12）

| 符号 | 含义 |

| `P = {p₁,…,p_m}` | 能力原语集合 |
| `E_p = (Pre_p, Post_p, ρ_p, c_p)` | 原语 p 的认证包络：前置、后置、安全裕度、最坏成本 |
| `G = (P, ⊗, ⊕, S)` | 组合能力文法；⊗ 顺序组合，⊕ 并行组合 |
| `τ` | 任务规格；`seq(τ)=p₁…p_n` 为原语序列，`n` 为组合深度 |
| `φ: X → R^q` | 状态/场景嵌入 |
| `d(x)` | 新颖度距离 |
| `ν(d)` | 新颖度惩罚函数（单调不减，ν(0)=0） |
| `λ` | 组合松弛系数 |
| `ρ(τ)` | 组合零样本安全下界 |
| `ρ_min` | 部署所需最小安全裕度 |
| `C = (V,E)` | 权利要求图 |
| `S(c)` | 权利要求 c 的覆盖域 |
| `η(c), e(c)` | 新颖性裕度、可实施性 |
| `Δ(c)` | 设计绕行距离 |
| `Cov(P)` | 专利组合覆盖域 |

**定义 1（能力原语包络 CPE）** 能力原语 \(p\) 的包络为

```
E_p = (Pre_p, Post_p, ρ_p, c_p)
Pre_p  : S → {0,1}
Post_p : S × A → {0,1}
ρ_p ∈ R_{>0},  c_p ∈ R_{≥0}
```

称 \(p\) 在状态 \(s\) 上**已认证**，若 \(Pre_p(s)=1\)，且对任意执行 \(a=p(s)\) 有 \(Post_p(s,a)=1\) 且安全裕度不低于 \(\rho_p\)。

**定义 2（组合能力文法 CCG）**

```
G = (P, ⊗, ⊕, S)
S → p | S ⊗ S | S ⊕ S,   p ∈ P
```

任务规格 \(\tau\) 属于 \(L(G)\) 当且仅当存在原语序列 \(seq(\tau)=p_1\cdots p_n\) 与组合树 \(T(\tau)\)。记 \(n=|seq(\tau)|\) 为组合深度。

**定义 3（组合零样本证书 ZSC）** 对 \(\tau\in L(G)\)，令

```
ρ(τ) = min_{i=1..n} ρ_{p_i} − λ(n−1) − ν(d(x))
```

其中 \(\lambda\ge 0\) 为组合松弛系数，\(d(x)\) 为新颖度距离，\(\nu\) 为新颖度惩罚函数。三态判决：

```
ZSC(τ,x) = Certified    if ρ(τ) ≥ ρ_min ∧ n ≤ n_max ∧ d(x) ≤ δ
         = Conditional  if 0 < ρ(τ) < ρ_min
         = Refused      if ρ(τ) ≤ 0 ∨ n > n_max ∨ d(x) > δ
```

**定义 4（新颖度覆盖监测 NCM）**

```
φ : X → R^q
D_ref = {φ(x_i)}_{i=1}^M
d(x) = min_{z∈D_ref} ||φ(x) − z||_2
C_δ = {x : d(x) ≤ δ}
NCM(x) = (d(x), 1[d(x) ≤ δ])
```

NCM 只输出距离与覆盖标志，不直接决定动作；决策权属于 ZSC。

**定义 5（包络一致退化 ECF）**

```
E_0 = (Pre_0, Post_0),   π_0 : S → A
∀s: Pre_0(s)=1 ⇒ Post_0(s, π_0(s))=1
```

若 \(Pre_0(s)=0\)，执行安全停机 `stop`，而不是执行 \(\pi_0\)。

**定义 6（语音→约束编译 VCT）**

```
ℓ_voice → ASR → (text, conf)
conf < τ_voice                      ⇒ ι ← ι_0（退化）
text → NLI → ι,  type(ι) ∉ Σ_ι      ⇒ ι ← ι_0（退化）
ι → K → τ ∈ L(G)  或  ⊥
```

\(K\) 为约束编译器；\(\perp\) 表示无法编译，进入退化分支。

**定义 7（权利要求图 CG）**

```
C = (V, E)
c ∈ V : (id, S(c), indep(c), η(c), e(c), B(c))
E ⊆ V×V : (c,c') ∈ E ⇔ S(c') ⊂ S(c)
Cov(C) = ∪_{c∈V} S(c)
```

\(S(c)\) 为覆盖的技术特征集合，\(\eta(c)\) 为新颖性裕度，\(e(c)\in\{0,1\}\) 为可实施性，\(B(c)\) 为实施例集合。

**定义 8（设计绕行距离 DAR）**

```
Δ(c) = min_{y ∈ Avoid(c)} dist(y, S(c))
Avoid(c) = { y : y ∉ S(c), 且 y 实现同一功能目标 }
```

`dist` 为技术特征编辑距离。\(\Delta(c)\) 越大，权利要求越难被绕开；但 \(S(c)\) 越大，\(\eta(c)\) 通常越小（越易被 prior art 无效）。

**定义 9（专利覆盖与 FTO）**

```
P = {C_1,…,C_k}
Cov(P) = ∪_{i} Cov(C_i)
FTO(x) = 1 ⇔ x ∉ ∪_{a∈PriorArt} S(a)
```

称组合**完整**当且仅当 \(Cov(P) \supseteq D\)（设计空间）。权利要求选择问题为

```
max_P |Cov(P) ∩ D|
s.t.  η(c) ≥ η_min, e(c)=1, FTO(x)=1  ∀x ∈ Cov(P)
```

**定义 10（三态执行策略）**

```
Exec(τ,x) = compose_execute(seq(τ))                    if ZSC=Certified
          = guard(compose_execute(seq(τ)), human=1)    if ZSC=Conditional
          = ECF.act(x)                                 if ZSC=Refused
```

**定义 11（ZSG-Gauge 主闭环）**

```
ℓ_voice → VCT → τ → CCG.parse → (seq,T)
x → NCM → (d, cover)
(seq,T,d) → ZSC → (status, ρ(τ))
status → Exec → a
(a, status, ρ(τ), d) → CertLog → ROS/审计
```

**定义 12（专利-技术协同指标）**

```
TechCov  = |{τ ∈ ZSB : ZSC(τ)=Certified}| / |ZSB|
LegalCov = |Cov(P) ∩ D| / |D|
Leverage = TechCov · LegalCov / (1 + λ·n̄)
```

`Leverage` 用于惩罚“靠加深组合换取覆盖率”的虚假繁荣。

## 2. 形式化推导

**引理 1（组合下界）** 设每个原语 \(p_i\) 在相邻状态上满足局部 Lipschitz 条件，单次组合引入的裕度损失至多 \(\lambda\)，输入偏移引入的新颖度损失至多 \(\nu(d)\)。则对任意 \(\tau\in L(G)\)，

```
ρ(τ) ≥ min_{i=1..n} ρ_{p_i} − λ(n−1) − ν(d)
```

**证明（归纳）**：\(n=1\) 时 \(\rho(\tau)=\rho_{p_1}-\nu(d)\)，成立。设对 \(n-1\) 成立，将 \(\tau\) 写成 \(\tau'\otimes p_n\)。由局部 Lipschitz 条件，组合接缝处裕度损失不超过 \(\lambda\)，且输入偏移损失不重复计入（次可加性），故

```
ρ(τ) ≥ ρ(τ') − λ ≥ min_i ρ_{p_i} − λ(n−2) − ν(d) − λ
     = min_i ρ_{p_i} − λ(n−1) − ν(d)
```

得证。

**引理 2（非空证书的最大深度）** 在引理 1 的假设下，

```
ρ(τ) > 0  ⇔  n < 1 + (min_i ρ_{p_i} − ν(d)) / λ
n* = floor( (min_i ρ_{p_i} − ν(d)) / λ ) + 1
```

因此当 \(\lambda>0\) 固定时，长程未见任务必然落入 Refused。这正是本轮的核心张力：**证书的非空性与组合深度成反比**。

**引理 3（退化安全性）** 若 \(Pre_0(s)=1\)，ECF 执行 \(\pi_0\) 后仍满足硬包络 \(Post_0\)；若 \(Pre_0(s)=0\)，系统安全停机。故 Refused 分支不会执行任何未验证动作。

**证明**：由 ECF 定义直接得到；停机分支不产生动作，硬约束平凡满足。

**引理 4（覆盖单调性与绕行权衡）** 若 \(S(c')\subset S(c)\)，则

```
Cov({c'}) ⊆ Cov({c})
Δ(c') ≤ Δ(c)
```

即从属权利要求以“更窄的覆盖”换取“更小的绕行距离/更低的无效风险”。独立权利要求覆盖最大，但新颖性裕度最低。专利布局必须在两端之间配置组合。

**证明**：由集合包含关系与 \(\Delta\) 关于 \(S\) 的单调性直接得到。

**命题 1（权利要求选择的 NP-hardness 与贪心近似）** 定义 9 的权利要求选择问题推广了集合覆盖问题；当覆盖函数 \(P\mapsto |Cov(P)\cap D|\) 为单调子模时，贪心算法达到 \(1-1/e\) 近似比。

**证明要点**：令每个候选权利要求对应一个集合 \(S(c)\cap D\)，设计空间元素为被覆盖元素，即得集合覆盖归约，故 NP-hard。集合覆盖函数是单调子模的，标准贪心界成立。

**命题 2（可主张性过滤）** 若某技术模块不存在任何权利要求 \(c\) 使其 \(e(c)=1\) 且 \(\eta(c)\ge\eta_{min}\)，则该模块不能作为本轮核心贡献，只能进入防御性公开登记 DPR。该规则把“技术新颖”与“法律可主张”绑定，防止产出无法保护的伪创新。

## 3. 关键算法骨架

```python
from dataclasses import dataclass, field
from typing import Any, Callable, Optional


@dataclass
class PrimitiveEnvelope:
    name: str
    pre: Callable[[Any], bool]
    post: Callable[[Any, Any], bool]
    margin: float
    cost: float


@dataclass
class CompositionalGrammar:
    primitives: dict[str, PrimitiveEnvelope]
    max_depth: int

    def parse(self, task_spec: dict) -> Optional[list[str]]:
        seq = task_spec.get("primitive_sequence")
        if not seq or len(seq) > self.max_depth:
            return None
        if any(p not in self.primitives for p in seq):
            return None
        return list(seq)


class NoveltyCoverageMonitor:
    def __init__(self, encoder, reference_embeddings, delta: float):
        self.encoder = encoder
        self.ref = reference_embeddings
        self.delta = delta

    def measure(self, x) -> tuple[float, bool]:
        z = self.encoder(x)
        d = min(float(((z - r) ** 2).sum() ** 0.5) for r in self.ref)
        return d, d <= self.delta


class ZeroShotCertifier:
    def __init__(self, grammar, monitor, lam=0.1, nu=None,
                 rho_min=0.2, n_max=8, delta=0.5):
        self.grammar = grammar
        self.monitor = monitor
        self.lam = lam
        self.nu = nu or (lambda d: d)
        self.rho_min = rho_min
        self.n_max = n_max
        self.delta = delta

    def certify(self, task_spec, x) -> tuple[str, float, str]:
        seq = self.grammar.parse(task_spec)
        if seq is None:
            return "Refused", 0.0, "grammar"
        n = len(seq)
        if n > self.n_max:
            return "Refused", 0.0, "depth"
        d, covered = self.monitor.measure(x)
        if not covered:
            return "Refused", 0.0, "novelty"
        rho = (min(self.grammar.primitives[p].margin for p in seq)
               - self.lam * (n - 1) - self.nu(d))
        if rho >= self.rho_min:
            return "Certified", rho, "compositional"
        if rho > 0:
            return "Conditional", rho, "certificate-shrink"
        return "Refused", rho, "certificate-empty"


@dataclass
class Claim:
    cid: str
    scope: frozenset
    independent: bool
    novelty: float
    enabled: bool
    embodiments: list = field(default_factory=list)


class ClaimGraph:
    def __init__(self, claims: list[Claim]):
        self.claims = {c.cid: c for c in claims}

    def coverage(self, ids=None) -> set:
        ids = ids or list(self.claims)
        out = set()
        for cid in ids:
            out |= self.claims[cid].scope
        return out

    def design_around_distance(self, cid: str, avoid: list[set]) -> int:
        s = self.claims[cid].scope
        return min(edit_distance(y, s) for y in avoid)

    def fto_ok(self, system_scope: set, prior_scopes: list[set]) -> bool:
        return all(not system_scope <= p for p in prior_scopes)

    def claimability_filter(self, eta_min=0.3) -> tuple[list[str], list[str]]:
        core, defensive = [], []
        for c in self.claims.values():
            if c.enabled and c.novelty >= eta_min:
                core.append(c.cid)
            else:
                defensive.append(c.cid)
        return core, defensive


def zsg_patentgauge(task_spec, x, voice, vct, certifier, executor, fallback):
    iota, ok, _ = vct.process(voice)
    if not ok:
        return fallback.act(x), "voice-degraded"
    status, rho, reason = certifier.certify(task_spec, x)
    if status == "Certified":
        return executor.compose(task_spec["primitive_sequence"], x), "certified"
    if status == "Conditional":
        return executor.guarded(task_spec["primitive_sequence"], x,
                                human=True), "conditional"
    return fallback.act(x), "refused"
```

## 8. 预期结果（待验证）

- 短程未见组合（n ≤ n*）应获得高比例 Certified，且实测裕度不低于预测下界；
- 长程任务应如实地大量落入 Refused，而不是靠“蒙对”通过——这是证书诚实性的关键；
- 专利侧应得到至少 3 条独立权利要求、6 条从属权利要求，核心独立权利要求的 DAR ≥ 3；
- 若 E2/E11 显示 n* 过小，则本轮的技术主线应从“加长组合”转向“降低 λ 或分段认证”。

## 9. 本轮最大风险

**一句话**：组合证书的松弛项会随组合深度线性增长，导致在最需要保证的长程未见任务上证书恰好变为空，而专利布局又可能把独立权利要求写得过窄，被竞争者的等价替换轻易绕开。
