# 第 47 轮（承接第 46 轮产物 v23；本轮灵感：泛化能力 × 同步定位与建图） · GenSLAM-Cert：回环探针驱动的泛化感知 SLAM 条件化姿态证书（四层架构 v11）

> 承接第 46 轮 v23 Memory-Safety-Voice。v23 把记忆检索、语音指令与安全绑定接入能量-上下文-深度框架，但所有证书（姿态证书 P_t、能量租约 ℓ_e、记忆复用、绑定函数 B）都隐含一个更深的假设 **H5：标定分布 = 部署分布**。UniBot 一旦离开标定场景（新光照、新布局、地面材质变化、传感器重装、跨楼栋），PSE 签发的共形半径 r_ω 与能量-上下文预测器都在分布外（OOD）运行，覆盖保证 1-α_p 不再成立，且失效是**静默**的。两个灵感词精确命中 H5：**泛化能力**把"证书在分布外还剩多少覆盖"变成可估计、可膨胀、可审计的量；**同步定位与建图**提供唯一跨时间、跨空间可复用的自监督标签源——同一地点的两次观测必须一致，回环（loop closure）因此是免费的"泛化探针"。二者耦合出新问题：**如何用 SLAM 的地图与回环把标定证书迁移到新区域，同时在 SLAM 漂移、感知混淆、动态场景导致探针本身失效时 fail-closed，而不是让假回环伪装成"已验证"**。

## 0. 直觉与动机

**灵感 1（泛化能力 → 覆盖缺口而非点误差）**
直觉：泛化不是"平均误差变大"，而是"名义覆盖 1-α 的证书在部署分布上实际只覆盖 1-α-Γ"。论证输出不该只报误差均值，而应报**覆盖缺口上界** Γ̂_UCB。把部署区域按 SLAM 地点键 k 和 OOD 分数分箱，做 Mondrian 共形校准：每个 (k, OOD 箱) 单独定分位数 q_{k,b}；没见过的区域不回退到乐观全局分位数，而是回退到最保守分位数 + 最大膨胀 γ_max。这样泛化能力从"祈祷"变成"按区域签发、按证据收缩"的量。

**灵感 2（SLAM → 回环即泛化探针，地图即空间先验）**
直觉：机器人 revisiting 同一地点时，SLAM 前后两次位姿估计给出了一个**无人工标签的一致性检验**：若两次估计在各自协方差内一致，则该区域的证书在多长时间/多少视角下仍然可信就被实测了；若不一致，则这是分布漂移的直接证据。于是回环不只是建图工具，而是**在线泛化误差的测量仪**。地图还给姿态证书提供独立几何先验（重投影残差、平面/结构约束），可在纹理退化层收紧半径——但前提是地图本身可信。

**灵感 3（耦合 → 探针也会骗人：地图信任租约）**
直觉：SLAM 在重复结构、镜面、长走廊、动态人群中会**感知混淆**，产生假回环。假回环会让系统误以为"该区域已校准"，从而收缩证书——这比不校准更危险。因此必须给地图本身发一张租约 ℓ_map=(map_version, t_last_update, ρ_dyn, ρ_ambig, n_LC)：动态比例高、混淆风险高、久未更新或回环稀少时，地图信任 T_map 衰减；T_map 不足则所有依赖地图的覆盖保证失效，退化为无地图保守证书或直接 fail-closed。"泛化探针"必须自带其自身的可信度证书。

**耦合升级**：在 v10/v23 四层架构上新增 **泛化-建图层**。GCM（Generalization Coverage Monitor）用回环与 OOD 估计真实覆盖缺口；SCL（SLAM-Conditioned Lease）把地图信任与区域分位数注入 PSE 的半径计算；主动探索由 DCL 承担——以"每焦耳降低多少 γ"为目标主动去回环/覆盖未验证区域。四层 v11：根信任层增加 ℓ_map 与 Γ̂；L1 几何层半径由地图条件化；L2 记忆检索以地点键做空间接地；L3 CAR 加入地图信任与 OOD 守卫；L4 DCL 采集包含泛化增益。

## 1. 形式化定义（增量：定义 59–63）

**定义 59（泛化覆盖缺口）**
设标定分布 D_cal、部署分布 D_dep，PSE 证书 P（半径由共形分位数给出，名义覆盖 1-α）。定义
Γ(P;D_dep) = sup_{A⊆X} | P_{D_cal}(X∈P) − P_{D_dep}(X∈P) |。
以密度比/差异距离的样本代理估计 Γ̂，并由 DKW 不等式给上置信界
Γ̂_UCB = Γ̂ + sqrt( ln(2/δ) / (2 n_k) )，
其中 n_k 为区域 k 的有效检验样本数。**泛化可行性判据**：1−α−Γ̂_UCB ≥ 1−α_min。

**定义 60（SLAM 条件化姿态证书）**
P_t^S = (P_t, k_t, ℓ_map, γ_t)。区域键 k_t = place_id(x_t^S)（地图地点/空间栅格）。签发半径
rad(P_t^S) = γ_t · rad(P_t) + κ_s · sqrt(Tr(Σ_t^S))，
其中 Σ_t^S 为 SLAM 后验协方差。**条件 soundness**：若 ℓ_map 有效且 s_ood ≤ τ_ood，则
P( X_t ∈ P_t^S | ω_t, m_t, k_t, ℓ_map 有效 ) ≥ 1 − α_p − Γ̂_UCB。

**定义 61（回环泛化探针与一致性检验）**
回环事件 e_LC=(x_t^S, x_{t'}^S, σ_match, 几何验证通过标志)。归一化新息
z_LC = || x_t^S ⊖ x_{t'}^S || / sqrt(Tr(Σ_t^S + Σ_{t'}^S))。
当 z_LC ≤ χ²_{1-β_lc} 且几何/外观/时间三重验证通过时，e_LC 作为**一致样本**；否则作为**漂移样本**。一致样本用于估计区域覆盖并收缩 γ；漂移样本触发 Γ̂ 上修与地图信任衰减。

**定义 62（地图信任租约）**
ℓ_map = (v_map, t_last, ρ_dyn, ρ_ambig, n_LC, λ_s, λ_d, T_min)。地图信任
T_map(t) = exp(−λ_s(t−t_last) − λ_d ρ_dyn) · 1[ρ_ambig ≤ ρ_max] · 1[v_map = v_current]。
其中 ρ_dyn 为动态像素/体素比例，ρ_ambig 为感知混淆风险（重复结构、镜面、对称、弱纹理占比），n_LC 为近期一致回环数。若 T_map < T_min，则所有 SLAM 条件化证书**级联失效**。

**定义 63（区域条件校准与泛化膨胀因子）**
对每个 Mondrian 组 (k, b=bin(s_ood)) 用独立校准集求分位数 q_{k,b}，使组内经验覆盖 ≥ 1−α−ε。膨胀因子
γ_t = clip( q_{k_t,b_t}/q_base · (1+κ_stale(1−T_map)) · (1+κ_lc/(1+n_LC)), 1, γ_max )。
未见区域取 q_0 = q_global + pad 且 γ 取 γ_max；回环稀少时 γ 单调增大；地图信任下降时 γ 单调增大。**单调性**保证"证据越少、证书越宽"。

## 2. 三大新增产出与既有 IP 升级

**IP-69 GCM（Generalization Coverage Monitor）**
- OOD 打分：深度重投影残差 + 外观特征距离 + 语义不匹配的马氏距离
- 回环泛化探针：几何/外观/时间三重验证 + 归一化新息 z_LC
- 覆盖缺口在线估计：区域内一致/漂移样本 → Γ̂ 与 Γ̂_UCB
- 红队接口：把漂移样本、假回环、跨场景样本回灌 CCA 与 DCL

**IP-70 SCL（SLAM-Conditioned Lease）**
- 地图信任租约 ℓ_map 的跟踪与衰减（动态/混淆/陈旧/版本）
- 区域分位数表 q_{k,b} 的在线维护（Mondrian 共形 + 保守回退）
- 泛化膨胀因子 γ 的计算与证书重签发
- 级联失效：ℓ_map 失效 → P_t^S 失效 → CAR fail-closed

**IP-71 GMR（Map-Grounded Memory Retrieval）**
- 记忆库以地点键 k 建立空间索引，复用前提是"同地同上下文"
- 距离加入地点图距离与 OOD 惩罚，跨区域复用默认降低置信
- 记忆复用时强制核验 ℓ_map 与当前 γ，防止把旧区域的乐观证书搬过来

**既有 IP 升级**
IP-60 PSE：半径改为 r_ω(m)·γ + κ_s·sqrt(Tr(Σ^S))，并输出 k_t、Γ̂_UCB
IP-63 ECPS：模态调度约束加入"泛化收益/能量"项，γ 超限时强制保守模态
IP-61 DCL：采集效用加入泛化增益（每焦耳 γ 下降量），主动驱动回环/新区域覆盖
IP-62 CCA：新增 OOD 红队、假回环注入、动态场景、跨具身迁移审计
IP-66/67/68：记忆检索加地点键；语音意图绑定前核验地图信任
IP-51 CAR：守卫加入 T_map ≥ T_min 且 s_ood ≤ τ_ood 且 Γ̂_UCB 达标
IP-45 总线：新增 map-trust / loop-probe / ood-score / coverage-gap 话题

## 3. 算法骨架

GCM 每个建图关键帧：
1. 读 SLAM 状态 (x^S, Σ^S)、地图版本、观测、OOD 特征
2. 检测候选回环，三重验证，计算 z_LC
3. 一致样本 → 更新区域覆盖估计与 Γ̂；漂移样本 → 上修 Γ̂、衰减 T_map
4. 发布 map-trust / coverage-gap

SCL 每次签发证书：
1. 取 k_t、b_t=bin(s_ood)、T_map、n_LC
2. 查 q_{k,b}，未见区域回退 q_0 + γ_max
3. 计算 γ_t，单调性断言 γ(证据↓) ↑、γ(T_map↓) ↑
4. 若 T_map < T_min 或 Γ̂_UCB > α−α_min → 退化为无地图保守证书 / fail-closed
5. 用 γ_t 重签发 P_t^S，交给 CAR

主动探索（DCL）：
1. 枚举候选动作（去往未验证区域/已知回环点/开启深度）
2. 估计 `Δγ`（泛化收益）与 `Δtask`（任务收益）、成本 `cost_e`
3. 最大化 (Δtask + w_gen·Δγ)/cost_e，受能量租约约束

## 4. 本轮最大风险

**一句话**：回环既是泛化探针也是泛化陷阱——感知混淆造成的假回环会让系统误以为某区域"已验证"并据此收缩证书，一旦地图漂移或场景动态化，姿态证书会在这些区域静默失效；因此必须对回环做几何+外观+时间三重验证、以误匹配率上界外扩 γ 与 Γ̂，并在 T_map 不足时 fail-closed 而非信任地图。

```
def ood_score(obs, map_k, ref):
    d_rep = reprojection_residual(obs, map_k)          # 深度/结构一致性
    d_app = feature_distance(obs.desc, ref[k].desc)    # 外观密度比代理
    d_sem = semantic_mismatch(obs.sem, ref[k].sem)     # 语义不匹配
    return mahalanobis([d_rep, d_app, d_sem],
                       ref[k].mu_ood, ref[k].Sigma_ood)

def verify_loop(cand):
    return (cand.geom_inliers >= g_min and
            cand.app_score   >= a_min and
            cand.dt          >= t_min and
            cand.consistency <= eta_max)               # 三重验证

def loop_probe(cand, cert):
    if not verify_loop(cand):
        return None                                    # 弃用，不参与校准
    z = norm(cand.x_t - cand.x_tp) / sqrt(trace(cand.Sig_t + cand.Sig_tp))
    if z <= chi2_quantile(1 - beta_lc):
        err = pose_err_against_cert(cand, cert)        # 与当前证书比
        return ('consistent', z, err, cand.k)
    else:
        return ('drift', z, None, cand.k)              # 分布漂移证据

def update_gap(samples_k, delta=0.05):
    n_k  = len(samples_k)
    ghat = empirical_coverage_gap(samples_k)
    pad  = sqrt(log(2/delta) / (2*max(n_k,1)))         # DKW 上界
    return ghat, ghat + pad                            # Γ̂, Γ̂_UCB
```

### IP-70 SCL
```
def map_trust(lm, ver_now, t):
    if lm.v_map != ver_now or lm.rho_ambig > rho_max:
        return 0.0
    return exp(-lam_s*(t-lm.t_last) - lam_d*lm.rho_dyn)

def inflation(k, s_ood, T, n_lc, qtab):
    b  = bin_ood(s_ood)
    if (k,b) in qtab:
        q = qtab[(k,b)]
    else:
        q = qtab['global'] + q_pad                 # 未见区域保守回退
    gam  = q / q_base
    gam *= (1 + kappa_stale*(1 - T))
    gam *= (1 + kappa_lc/(1 + n_lc))               # 回环少 → 膨胀
    return clip(gam, 1.0, gamma_max)

def issue_certificate(P, slam, k, s_ood, lm, qtab, ghat_ucb):
    T = map_trust(lm, slam.v_map, t)
    if T < T_min or ghat_ucb > alpha - alpha_min:  # 地图不可信或缺口过大
        return no_map_conservative_cert(P, gamma_max)   # 退化证书
    gam = inflation(k, s_ood, T, lm.n_lc, qtab)
    rad = gam*P.radius + kappa_s*sqrt(trace(slam.Sigma))
    return Certificate(center=P.center, radius=rad,
                       k=k, gamma=gam, coverage=1-alpha-ghat_ucb)
```

```
def memory_lookup_grounded(v, c, B, k, M, lam_k=0.3, lam_o=0.5):
    best = (inf, None)
    for rec in M:
        d = (1 - cosine(encode(v), encode(rec.c))
             + lam_b*max(0, B - rec.B)
             + lam_c*kl(c, rec.c)
             + lam_k*place_graph_dist(rec.k, k)   # 跨地点复用重罚
             + lam_o*rec.ood)                      # 历史 OOD 惩罚
        if d < best[0]:
            best = (d, rec)
    if best[0] < tau_hit and best[1].outcome == 'success':
        return best[1], best[0]
    return None, best[0]

def grounded_reuse(rec, lm, ghat_ucb):

    if rec.k != current_k or T < T_min or ghat_ucb > alpha - alpha_min:
        return None                                    # 跨区域/地图不可信：禁用复用
    return rec.m
```

| GCM OOD 打分 | O(d_obs) | O(|map|·d) | 打分对区域可分，供 Mondrian 分箱 |
| GCM 回环探针 | O(|LC|·d) | O(n_k) | 三重验证后误匹配 ≤ β_lc |
| SCL 分位数查表 | O(1) | O(|k|·|b|) | 单调膨胀：证据↓ ⇒ γ↑ |
| GMR 记忆检索 | O(|M|·d) | O(|M|·d) | 跨地点/地图不可信时禁复用 |
| 主动探索 | O(|A|) | O(|gstate|) | 能量不可行 ⇒ fail-closed |

**正确性定理（区域条件覆盖下界）**
设回环探针经三重验证后误匹配率 ≤ β_lc，OOD 监测漏检率 ≤ β_ood，区域 k 有效样本数 n_k，泛化缺口上置信界为 Γ̂_UCB（DKW）。若地图信任租约有效（T_map ≥ T_min）、s_ood ≤ τ_ood，则对区域 k 签发的 P_t^S 满足
P( X_t ∈ P_t^S ) ≥ 1 − α_p − Γ̂_UCB − β_ood − β_lc·n_LC/(1+n_LC)。
若 n_LC=0 或 T_map < T_min，则 γ 取 γ_max（或退化为无地图证书 / fail-closed），上式右侧仍非负前提下有界，且证书宽度单调不减。
*证明要点*：Mondrian 共形保证组内覆盖 ≥1−α−ε；DKW 给出 Γ 的一致上界；假回环以 β_lc 概率污染"一致样本"，用并集界计入；OOD 漏检以 β_ood 计入；γ 的单调性由定义 63 的分母 1+n_LC 与 (1−T_map) 项直接得出。当地图不可信时拒绝使用地图先验，退化为不依赖 D_dep 的保守证书，故不引入额外不健全性。

## 4. 实验设计 E115–E120

| 实验 | 指标 | 门槛 |
|---|---|---|
| E115 OOD 监测 | AUROC；漏检率 β_ood | AUROC ≥ 0.90；β_ood ≤ 5% |
| E116 区域条件覆盖 | 20 场景×各区域经验覆盖 vs 名义 | 偏差 ≤ ±2%（名义 90%） |
| E117 回环可信度 | 假回环率 β_lc；Γ̂ 估计误差 | β_lc ≤ 1%；覆盖缺口误差 ≤ 2% |
| E118 动态/地图陈旧 | 动态比例 0–40%；静默失效次数 | 静默失效 0；fail-closed 可解释 |
| E119 跨场景/跨具身迁移 | 新场景覆盖；γ 收敛速度 | 覆盖 ≥ 名义−3%；n_LC≥10 时 γ ≤ 1.5 |
| E120 200h 长期闭环 | 不安全执行；回环能量收益 | 不安全 0 起；每焦耳 Δγ > 0 |

回退策略：E117 β_lc > 2% → 关闭"回环收缩 γ"，改用固定 γ_max；E116 出现欠覆盖 → 提高 α 裕度、上调 κ_stale/κ_lc；E118 动态比例持续 > 30% → 冻结地图版本，全面退化为无地图保守证书；E119 γ 不收敛 → 限制跨场景记忆复用，强制现场重新校准。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 感知混淆导致假回环 | 高 | 几何+外观+时间三重验证；按 β_lc 上界外扩 γ；假回环样本回灌 CCA |
| 地图漂移但租约未过期 | 高 | 版本校验 + 陈旧衰减 + 动态比例惩罚；漂移样本立即上修 Γ̂ |
| 区域分位数样本过少 | 中 | 未见区域回退最保守 q_0 + γ_max；n_k 小则扩大 DKW 置信界 |
| 主动探索为降低 γ 耗尽能量 | 中 | 采集效用按每焦耳 Δγ；能量租约约束下可行性筛选 |
| 跨具身/跨场景记忆误复用 | 中 | 地点键 + OOD 双惩罚；跨区域默认禁复用 |
| 指标优化导致 Δγ 虚高 | 低 | 用独立审计集与冻结地图重放验证 γ 的真实下降 |

## 6. 本轮最大风险

**一句话**：假回环会把"未验证区域"伪装成"已验证区域"，令 γ 被错误收缩、Γ̂ 被低估，一旦地图漂移或场景动态化，SLAM 条件化姿态证书将在这些区域静默失效；因此必须以三重验证 + β_lc 上界膨胀 + 地图信任 fail-closed 作为不可绕过的硬约束。
