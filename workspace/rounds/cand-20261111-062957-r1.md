# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「传感器标定」×「迭代验证」）

> 第 54 轮把技能组合提升为动作-鲁棒性双证书 J。本轮再向下追问一层：**这些证书所依赖的测量本身是否可信、是否还在有效期内？** 核心矛盾：H22：鲁棒性谱 ρ 与动作剖面 α 都是传感器读数的函数，若标定缺失或漂移，证书会"精确地错误"；H23：标定不是一次性动作，而是"激励—估计—验证—再标定"的迭代过程，缺少收缩性与停止准则的迭代验证会把噪声误当改进。

## 0. 直觉与动机

**灵感 1（传感器标定 = 计量溯源 → 证书从"点估计"变"带不确定度的区间"）**
直觉：`ρ_S(d)` 不是一个确定的数，而是"用某套传感器、在某次标定有效期内、以某不确定度测得的估计"。就像工业测量必须给出 `y ± U` 并声明溯源链，鲁棒性证书也必须携带 **标定证书 `C_cal`** 与 **不确定度预算 `u`**。部署判据从 `ρ ≥ ρ_min` 改为 **置信下界** `ρ_lo = ρ̂ − k·u_ρ ≥ ρ_min`（守带 / guard band）。这直接继承 ISO 14253 的决策规则：宁可保守判不合格，也不把测量噪声当作能力。

**灵感 2（迭代验证 → 标定循环是 κ-压缩的不动点迭代）**
直觉：标定不是"标一次"，而是 `标定 → 用校验标准验证 → 检测残差 → 再标定`。若每轮验证能把不确定度压缩一个固定比例，则该过程是压缩映射，存在不动点，也能算出"再验几轮就够"。于是"迭代验证"可形式化为算子 `V` 的收缩性 `U_{k+1} ≤ κ U_k + c`，并给出最短验证轮数 `k*`。这把"再多验几轮"从经验直觉变成可证明的预算决策；当 `κ ≥ 1` 时必须显式宣布"不可标定"。

**灵感 3（可观测/可激励动作空间 → 不是所有动作都能被标定验证）**
直觉：标定数据往往只激励了动作空间的一部分（低速、无接触、常温）。在未被激励的方向上标定雅可比接近奇异、Fisher 信息小，此时 `α_S(a)=1` 只是"仿真里能跑"，不是"测量上可信"。因此引入 **可观测剖面 `β(a)`**，有效动作剖面 `α̃_S(a) = α_S(a)·1[β(a) ≥ β_min]`。组合可行域必须同时落在 `A_val` 内，避免"未标定动作上的虚假覆盖"。

**灵感 4（漂移触发再标定 → 静态有效期升级为在线状态机）**
直觉：证书上的"有效期 `T_val`"是静态承诺，但真实漂移由温度、磨损、振动驱动。用内置校验标准做残差监控（CUSUM/EWMA），把静态有效期升级为 **漂移触发状态机**：`CALIBRATED → SUSPECT → DRIFTED → RECALIBRATING`。任何下游证书在状态非 `CALIBRATED` 时自动降级为"不可部署"。这把标定从"一次性签字"变为"持续在线验证"。

**灵感 5（云边标定迁移 → 云端高保真标定向边端廉价传感器迁移）**
直觉：云端可负担高精度参考标准与大量标定数据，边端只有廉价、易漂移的传感器。把云端标定直接下发会忽略传感器域差；需要 **标定迁移证书 `T_cal`**，显式度量 `Σ_gap = sup ||f_cal^c − φ_cal∘f_cal^e||`。只有域差在预算内且边端本地迭代验证收敛，迁移才成立。这与第 54 轮的 `γ_ce` 动作映射形成"标定域 × 动作域"的双重对齐。

**灵感 6（金字塔再向下扩一层 → 计量可信层 𝕄）**
直觉：在 𝕃（鲁棒性）与 𝔸（动作协同）之下再加一层 **计量层 `𝕄`**：`𝕄_0` 传感器原始读数，`𝕄_1` 单传感器标定，`𝕄_2` 多传感器时空标定，`𝕄_3` 云边标定迁移，`𝕄_4` 在线漂移验证。所有上层证书必须携带从 `𝕄` 层传来的不确定度，否则视为"无溯源"，其 soundness 不得被引用。

## 1. 形式化定义（增量：定义 121–128）

**定义 121（传感器标定证书）**
标定证书 `C_cal = (s, 𝓡, f_cal, θ̂, Σ_θ, u_budget, [t_0, t_0+T_val], D, trace)`：
- `s` 为传感器标识；`𝓡` 为参考标准及其自身溯源链；
- `f_cal : X_raw → Y_phys` 为标定映射，参数 `θ̂`，协方差 `Σ_θ`；
- `u_budget` 为 GUM 式不确定度分量（重复性、分辨率、参考标准、迟滞、漂移）；
- `[t_0, t_0+T_val]` 为名义有效期；`D` 为漂移模型；`trace` 为证据链。
**已标定测量集** `M_cal = { y : t ∈ [t_0,t_0+T_val] ∧ residual_test(y)=pass }`。只有落在 `M_cal` 内的读数才允许进入上层证书。

**定义 122（不确定度传播与鲁棒性置信下界）**
设鲁棒性泛函 `ρ = g(θ, m)`，其一阶传播为
```
u_ρ²(d) = J_θ(d) Σ_θ J_θ(d)^T + u_meas²(d) + u_model²(d),   J_θ = ∂g/∂θ
```
**置信下界** `ρ_lo(d) = ρ̂(d) − k_α · u_ρ(d)`，其中 `k_α` 由覆盖因子给出（95% 取 1.96 或 t 分位）。部署判据改为 **守带判据** `ρ_lo(d) ≥ ρ_min`，∀d。组合若为单调算子，则用区间算术取 `[ρ_comp]_lo`；非单调算子必须先做保守包络再取 `lo`。

**定义 123（可观测 / 可激励剖面）**
沿动作 `a` 的标定雅可比 `J_a = ∂f_cal/∂θ`，Fisher 信息 `F(a) = J_a^T Σ_θ^{-1} J_a`。**可观测度** `β(a) = λ_min(F(a))`。**可验证动作域** `A_val = { a : β(a) ≥ β_min }`。**有效动作剖面** `α̃_S(a) = α_S(a)·1[a ∈ A_val]`，覆盖判据升级为 `∀a∈A_T, α̃_S(a) ≥ θ_cov`。

**定义 124（漂移触发再标定状态机）**
对内置校验标准的残差序列 `r_k`，取 CUSUM 统计量
```
S_k = max(0, S_{k-1} + |r_k| − μ_0 − k_slack)
```
当 `S_k > h` 触发 `SUSPECT`，确认后进入 `DRIFTED` 并请求再标定，验证通过后回到 `CALIBRATED`。状态空间 `Q_cal = {CALIBRATED, SUSPECT, DRIFTED, RECALIBRATING}`，转移函数 `δ_state : Q_cal × 证据 → Q_cal`。**证书仅在 `CALIBRATED` 状态有效**，其余状态一律视为 `dom=out`。

**定义 125（迭代验证算子与收缩性）**
验证算子 `V : (C_cal, U_k) → (C_cal', U_{k+1})`，其中 `U` 为标量化的不确定度（或 `u_ρ` 的范数）。若存在 `0 ≤ κ < 1, c ≥ 0` 使
```
U_{k+1} ≤ κ U_k + c
```
则 `U_k ≤ κ^k U_0 + c(1−κ^k)/(1−κ)`，不动点 `U* = c/(1−κ)`。`V` 的**收敛验证证书** `V_trace = ⟨(k, U_k, bound_k, evidence_k)⟩` 记录每轮不确定度、最坏界与证据。

**定义 126（验证停止准则）**
给定目标 `U_target` 与最大轮数 `K_max`，
```
k* = min { k ≤ K_max : κ^k U_0 + c(1−κ^k)/(1−κ) ≤ U_target }
```
若不存在，则返回 `abort`，宣布该技能在该动作域上 **不可标定 / 需升级硬件**。带成本时取
`k* = argmin_k [ c_val·k + c_fail·P(U_k > U_target) ]`。

**定义 127（云边标定迁移证书）**
`T_cal = (C_cal^c, C_cal^e, φ_cal, Σ_gap, ε_gap, V_edge)`：
- `C_cal^c` / `C_cal^e` 为云端 / 边端标定证书，`φ_cal` 为两端测量空间对齐；
- `Σ_gap = sup_{x∈dom} || f_cal^c(x) − φ_cal(f_cal^e(x)) ||`；
- 迁移有效当且仅当 `Σ_gap ≤ ε_gap ∧ V_edge.converged ∧ C_cal^e.state = CALIBRATED`。

**定义 128（标定-动作-鲁棒性三元联合证书）**
`J_cal = (C_cal, ρ_lo, α̃, β, V_trace, T_cal, γ_ce, δ_a, evidence)`。**可部署**当且仅当：
```
C_cal.state = CALIBRATED
∧ ∀d: ρ_lo(d) ≥ ρ_min(d)
∧ A_core ⊆ A_val                 (可观测)
∧ V_trace.converged              (迭代验证收敛)
∧ (T_cal 有效，若为云边部署)
∧ δ_a < Θ_a                      (动作对齐，承接第 54 轮)
```
任一条件失败即拒绝部署，并输出失败证据供上层 `Explain` 使用。

## 2. 关键算法 伪代码

### IP-121 CALCERT（标定证书与不确定度预算）

```python
def build_cal_cert(sensor, ref, cal_data, T_val):
    theta_hat, Sigma = fit_calibration(sensor, ref, cal_data)   # 加权最小二乘
    u = uncertainty_budget(sensor, ref, cal_data, theta_hat, Sigma)
    D = fit_drift_model(sensor.history) if sensor.history else None
    return CalCert(sensor.id, ref.trace, theta_hat, Sigma, u,
                   window=(now(), now() + T_val), drift=D,
                   trace=ref.trace + cal_data.ids)
```

### IP-122 RSPU（鲁棒性谱不确定度传播 / LCB）

```python
def rho_lcb(skill, dims, cal_certs, alpha=0.05):
    rho_hat, u = {}, {}
    for d in dims:
        theta, Sigma = aggregate_params(cal_certs, d)
        g = lambda th: robustness_estimate(skill, d, th)
        rho_hat[d] = g(theta)
        J = numerical_jacobian(g, theta)
        u[d] = sqrt(J @ Sigma @ J.T + u_meas(d)**2 + u_model(d)**2)
    k = norm.ppf(1 - alpha/2)
    return {d: rho_hat[d] - k*u[d] for d in dims}, u     # 守带下界
```

### IP-123 COBS（可观测 / 可激励剖面）

```python
def observability_profile(skill, A, cal_data, beta_min):
    beta, A_val = {}, set()
    for a in A:
        J_a = cal_jacobian(a, cal_data)
        F = J_a.T @ inv(cal_data.Sigma_theta) @ J_a
        beta[a] = min_eig(F)
        if beta[a] >= beta_min:
            A_val.add(a)
    return beta, A_val

def effective_cover(alpha_s, beta, A_T, theta_cov, beta_min):
    return all(alpha_s.get(a, 0) >= theta_cov and beta.get(a, 0) >= beta_min
               for a in A_T)
```

### IP-124 DRTM（漂移触发再标定状态机）

```python
def drift_monitor(cert, check_standard, stream, h, k_slack, mu0):
    S, state = 0.0, 'CALIBRATED'
    for r_k in residuals(stream, check_standard, cert):
        S = max(0.0, S + abs(r_k) - mu0 - k_slack)
        if state == 'CALIBRATED' and S > h:
            state = 'SUSPECT'
        elif state == 'SUSPECT' and confirm_drift(stream):
            state = 'DRIFTED'
        if state == 'DRIFTED':
            state = 'RECALIBRATING'
            cert = recalibrate(cert, check_standard)
            if verify_certificate(cert):        # 用定义 121 的 residual_test
                state, S = 'CALIBRATED', 0.0
        yield state, cert, S
```

### IP-125 ITVL（κ-压缩迭代验证与停止）

```python
def iterative_validate(cert, V, U0, U_target, kappa, c, K_max):
    U, trace = U0, []
    for k in range(1, K_max + 1):
        cert_new, U_new, evidence = V(cert)
        bound = kappa * U + c                  # 最坏情形收缩界
        trace.append((k, U_new, bound, evidence))
        if U_new <= U_target and bound <= U_target:
            return ('converged', cert_new, trace, k)
        cert, U = cert_new, U_new
    return ('abort', cert, trace, K_max)       # 不可标定 / 升级硬件
```

### IP-126 CETC（云边标定迁移证书）

```python
def cloud_edge_cal_transfer(cert_c, cert_e, phi_cal, eps_gap, V_edge, U0):
    gap = sup_norm(lambda x: cert_c.f(x) - phi_cal(cert_e.f(x)), cert_e.domain)
    if gap > eps_gap:
        return ('reject', 'calibration_gap', gap)
    status, cert_e2, trace, k = iterative_validate(
        cert_e, V_edge, U0, U_target=eps_gap, kappa=V_edge.kappa,
        c=V_edge.c, K_max=V_edge.K_max)
    if status != 'converged':
        return ('reject', 'edge_validation_not_converged', trace)
    return ('ok', TransferCert(cert_c, cert_e2, phi_cal, gap, trace))
```

### IP-127 JCC（三元联合证书装配）

```python
def joint_cal_certificate(J54, cert, rho_lo, alpha_eff, beta,
                          V_trace, T_cal, budgets):
    if cert.state != 'CALIBRATED':
        return ('reject', 'uncalibrated', cert.state)
    if any(rho_lo[d] < budgets.rho_min[d] for d in rho_lo):
        return ('reject', 'rho_lcb_fail', rho_lo)
    A_val = {a for a, b in beta.items() if b >= budgets.beta_min}
    if not J54.A_core <= A_val:
        return ('reject', 'unobservable_action', J54.A_core - A_val)
    if not V_trace.converged:
        return ('reject', 'validation_not_converged', V_trace)
    if T_cal is not None and not T_cal.valid:
        return ('reject', 'cal_transfer_invalid', T_cal.gap)
    if J54.delta_a >= budgets.Theta_a:
        return ('reject', 'action_misalignment', J54.delta_a)
    return ('ok', JointCalCert(cert, rho_lo, alpha_eff, beta,
                               V_trace, T_cal, J54))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| CALCERT | O(N·p² + p³) | O(N·p) | 参考标准可溯源、残差检验通过 |
| RSPU | O(|𝔇|·p) | O(|𝔇|) | 一阶传播有效、覆盖因子正确 |
| COBS | O(|A|·p²) | O(|A|) | 激励充分、`λ_min(F)` 数值稳定 |
| DRTM | O(1)/样本 | O(1) | 漂移模型匹配、CUSUM 阈值标定 |
| ITVL | O(K·T_V) | O(K) | `κ<1`、`V` 单调保序 |
| CETC | O(|dom|·p + K·T_V) | O(|dom|) | 域差 sup 范数可估、边端验证收敛 |
| JCC | O(|S|·|A| + |𝔇|) | O(|A|+|𝔇|) | 六条判据全部闭合 |

**引理 1（收缩收敛）**
若 `V` 满足 `U_{k+1} ≤ κ U_k + c, κ<1`，则 `U_k ≤ κ^k U_0 + c(1−κ^k)/(1−κ)`，且 `U_∞ = c/(1−κ)`；定义 126 的 `k*` 有限。

**引理 2（不可观测即不可证）**
若 `β(a) < β_min`（`F(a)` 近奇异），则存在 `Σ_θ` 的零空间方向使 `u_ρ(a) → ∞`；任何声称 `a` 处 `ρ_lo` 有限的证书都无溯源，必须从 `α̃` 中剔除。故有效动作剖面是 soundness 的必要条件。

**正确性定理（Calibration-Aware Certificate Soundness）**
假设第 53/54 轮 (A22)–(A28) 成立；新增：
**(A29)** `C_cal` 在观测窗内可溯源且有效，参考标准不确定度有界；
**(A30)** 一阶不确定度传播有效，覆盖因子 `k_α` 给出至少 `1−α_cov` 的区间覆盖；
**(A31)** `V` 为 `κ`-压缩且漂移检验漏检率 `≤ p_fn`；
**(A32)** 云边迁移域差以 sup 范数度量且边端验证收敛。
则部署成功概率满足
```
P_success ≥ 1 − Σ_d (1 − ρ_lo(d)) − n_d·α_cov − p_fn
            − P(Σ_gap > ε_gap) − β_E − P(δ_a > Θ_a)
```
关键：**证书的可信度 = 测量的可信度**；`ρ_lo` 的保守性吸收随机误差，`β` 与 `V_trace` 吸收系统性的"未激励/未收敛"误差，`DRTM` 吸收时变漂移误差。

## 6. 本轮最大风险

### IP-122 RSPU

```python
def rho_lcb(skill, dims, cal_certs, alpha=0.05):
    rho_hat, u = {}, {}
    for d in dims:
        theta, Sigma = aggregate_params(cal_certs, d)
        g = lambda th: robustness_estimate(skill, d, th)
        rho_hat[d] = g(theta)
        J = numerical_jacobian(g, theta)
        u[d] = sqrt(J @ Sigma @ J.T + u_meas(d)**2 + u_model(d)**2)
    k = norm.ppf(1 - alpha/2)
    return {d: rho_hat[d] - k*u[d] for d in dims}, u   # 守带下界
```

### IP-123 COBS

```python
def observability_profile(skill, A, cal_data, beta_min):
    beta, A_val = {}, set()
    for a in A:
        J_a = cal_jacobian(a, cal_data)
        F = J_a.T @ inv(cal_data.Sigma_theta) @ J_a
        beta[a] = min_eig(F)
        if beta[a] >= beta_min:
            A_val.add(a)
    return beta, A_val

def effective_cover(alpha_s, beta, A_T, theta_cov, beta_min):
    return all(alpha_s.get(a, 0) >= theta_cov and beta.get(a, 0) >= beta_min
               for a in A_T)
```

### IP-124 DRTM

```python
def drift_monitor(cert, check_standard, stream, h, k_slack, mu0):
    S, state = 0.0, 'CALIBRATED'
    for r_k in residuals(stream, check_standard, cert):
        S = max(0.0, S + abs(r_k) - mu0 - k_slack)
        if state == 'CALIBRATED' and S > h:
            state = 'SUSPECT'
        elif state == 'SUSPECT' and confirm_drift(stream):
            state = 'DRIFTED'
        if state == 'DRIFTED':
            state = 'RECALIBRATING'
            cert = recalibrate(cert, check_standard)
            if verify_certificate(cert):
                state, S = 'CALIBRATED', 0.0
        yield state, cert, S
```

### IP-125 ITVL

```python
def iterative_validate(cert, V, U0, U_target, kappa, c, K_max):
    U, trace = U0, []
    for k in range(1, K_max + 1):
        cert_new, U_new, evidence = V(cert)
        bound = kappa * U + c                 # 最坏情形收缩界
        trace.append((k, U_new, bound, evidence))
        if U_new <= U_target and bound <= U_target:
            return ('converged', cert_new, trace, k)
        cert, U = cert_new, U_new
    return ('abort', cert, trace, K_max)      # 不可标定 / 升级硬件
```

### IP-126 CETC

```python
def cloud_edge_cal_transfer(cert_c, cert_e, phi_cal, eps_gap, V_edge, U0):
    gap = sup_norm(lambda x: cert_c.f(x) - phi_cal(cert_e.f(x)), cert_e.domain)
    if gap > eps_gap:
        return ('reject', 'calibration_gap', gap)
    status, cert_e2, trace, k = iterative_validate(
        cert_e, V_edge, U0, U_target=eps_gap, kappa=V_edge.kappa,
        c=V_edge.c, K_max=V_edge.K_max)
    if status != 'converged':
        return ('reject', 'edge_validation_not_converged', trace)
    return ('ok', TransferCert(cert_c, cert_e2, phi_cal, gap, trace))
```

### IP-127 JCC

```python
def joint_cal_certificate(J54, cert, rho_lo, alpha_eff, beta,
                          V_trace, T_cal, budgets):
    if cert.state != 'CALIBRATED':
        return ('reject', 'uncalibrated', cert.state)
    if any(rho_lo[d] < budgets.rho_min[d] for d in rho_lo):
        return ('reject', 'rho_lcb_fail', rho_lo)
    A_val = {a for a, b in beta.items() if b >= budgets.beta_min}
    if not J54.A_core <= A_val:
        return ('reject', 'unobservable_action', J54.A_core - A_val)
    if not V_trace.converged:
        return ('reject', 'validation_not_converged', V_trace)
    if T_cal is not None and not T_cal.valid:
        return ('reject', 'cal_transfer_invalid', T_cal.gap)
    if J54.delta_a >= budgets.Theta_a:
        return ('reject', 'action_misalignment', J54.delta_a)
    return ('ok', JointCalCert(cert, rho_lo, alpha_eff, beta,
                               V_trace, T_cal, J54))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CALCERT | O(N·p² + p³) | O(N·p) | 参考标准可溯源、残差检验通过 |
| RSPU | O(|𝔇|·p) | O(|𝔇|) | 一阶传播有效、覆盖因子正确 |
| COBS | O(|A|·p²) | O(|A|) | 激励充分、`λ_min(F)` 数值稳定 |
| DRTM | O(1)/样本 | O(1) | 漂移模型匹配、CUSUM 阈值标定 |
| ITVL | O(K·T_V) | O(K) | `κ<1`、`V` 单调保序 |
| CETC | O(|dom|·p + K·T_V) | O(|dom|) | 域差 sup 范数可估、边端验证收敛 |
| JCC | O(|S|·|A| + |𝔇|) | O(|A|+|𝔇|) | 六条判据全部闭合 |

**引理 1（收缩收敛）**：若 `U_{k+1} ≤ κU_k + c, κ<1`，则 `U_k ≤ κ^k U_0 + c(1−κ^k)/(1−κ)`，`U_∞ = c/(1−κ)`，`k*` 有限。

**引理 2（不可观测即不可证）**：若 `β(a) < β_min`，`F(a)` 近奇异，存在 `Σ_θ` 零空间方向使 `u_ρ(a)→∞`；任何有限 `ρ_lo(a)` 证书均无溯源，必须从 `α̃` 剔除。

**正确性定理（Calibration-Aware Certificate Soundness）**
假设第 53/54 轮 (A22)–(A28) 成立；新增 **(A29)** `C_cal` 可溯源且有效，参考标准不确定度有界；**(A30)** 一阶不确定度传播有效且覆盖因子给 `1−α_cov` 覆盖；**(A31)** `V` 为 `κ`-压缩，漂移漏检率 `≤ p_fn`；**(A32)** 云边域差以 sup 范数度量且边端验证收敛。
则
```
P_success ≥ 1 − Σ_d(1−ρ_lo(d)) − n_d·α_cov − p_fn
            − P(Σ_gap > ε_gap) − β_E − P(δ_a > Θ_a)
```
关键：**证书可信度 = 测量可信度**；随机误差由 `ρ_lo` 吸收，系统性"未激励/未收敛"误差由 `β` 与 `V_trace` 吸收，时变漂移误差由 `DRTM` 吸收。
