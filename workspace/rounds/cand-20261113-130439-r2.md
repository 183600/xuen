# 第 67 轮（承接第 66 轮「RAS 情绪驱动闭环」IP-224~233；灵感循环第 2 轮；本轮灵感：「鲁棒性」×「多机评测」）

> 第 66 轮 RAS 的问句是「谁该控制，何时控制，控制多少」，它用情绪风险 λ_risk 把被动故障闭环升级为意图闭环。但 RAS 的证书有两个从未被检验的支点：
>
> **(i) 情绪证据是可信的点估计**——现实中 π_t 会被面部遮挡、光照突变、假笑/僵硬表情、甚至对抗贴片翻转；
> **(ii) 情绪闭环只在单一机器、单一用户、单一环境上被验证**——而真实部署是跨机型、跨传感器、跨人群的**群体问题**。
>
> 本轮命题不是再加一个情绪模块，而是给 RAS 的证书加两个新维度：
>
> **MARS（Multi-machine Adversarially-Robust Safety closure）= RAS × 鲁棒半径 ρ × 机器群体迁移散度 Δ。**
>
> 一句话：**RAS 证明「此刻这台机器上这个人的情绪支持这个决策」；MARS 证明「在证据可以坏到 ρ、在机器群体里最坏的那台机器上，这个决策仍然安全」。**

## 0. 直觉与动机

**灵感 1（鲁棒性 → 从"识别精度"转向"决策不变性"）**
直觉：第 66 轮优化的是情绪误判的**平均概率**；但安全关心的是**最坏输入下决策是否翻转**。一个 95% 准确的表情分类器，完全可能在 5% 的对抗贴片或刻意假笑上，把 `λ_risk` 从 0.7 推到 1.1——把"该降级"变成"放行"，且这 5% 正是最危险的分布尾部。鲁棒性视角要求换问题：不再问"π 准不准"，而问"**π 在邻域内怎么变，`gate / k* / λ` 才不变**"。于是情绪识别精度问题被转成**决策鲁棒半径问题**：ρ 越大，说明这个决策越不依赖情绪的精确值，越安全。

**灵感 2（多机评测 → 从"单点结论"转向"机器流形上的结论"）**
直觉：单机评测像在一个点上求导；多机评测要在**机器流形**上验证。朴素做法是把 N 台机器的成功率平均，但平均会掩盖"某一类机器系统性失效"（例如低照度相机 + 深肤色用户 → 情绪永远 `HIGH_RISK`，闭环永远保守但可用性归零；反过来廉价 ToF + 假笑 → 永远 `SAFE`）。多机评测的正确定义不是平均分，而是两件事：**(a) 每台机器的最差分层下界**（是否都安全）；**(b) 跨机行为散度 Δ**（同一场景下不同机器的决策是否一致）。前者防"被平均掩盖"，后者防"换机器即换策略"。

**灵感 3（两者合流 → 证书从"点"升到"球 × 分布"）**
直觉：鲁棒性在输入维度上给一个球 `B_ε(face)`；多机评测在部署维度上给一个分布 `Q`（机器群体）。第 66 轮的 `J_RAS` 只是某个点 `(face, m)` 上的真值；MARS 要的是 `∀face'∈B_ε, ∀m∈supp(Q)` 上的一致真值。这直接决定了定理 11 的形状：**群体安全界 ≈ 单机经验风险 + 鲁棒项(Lε) + 迁移项(Δ) + 有限样本项(√(log N/n))**——四项各有独立实验，也各有独立的失败模式。

**灵感 4（评测即控制：多机审计反向收紧闭环）**
直觉：多机评测不是事后报告，而是闭环的第三个反馈环。若某台机器迁移散度 `Δ_m` 超阈，MARS 自动把它降级为"独立证书模式"并抬升 `λ_floor`；若鲁棒半径 `ρ < ρ0`，自动触发对抗重训练或切到保守感知通道。于是形成"**感知→归因→控制→群体审计→再收紧**"的四层回路，而非 RAS 的三层。

**灵感 5（相对第 66 轮的具体换装）**
- `ERG → RERG`：点 `π` 换成扰动球上的最坏风险 `R̄` 与半径 `ρ`；
- `EFS → R-EFS`：`λ_risk` 用最坏后验 `λ̄_risk`，并输出鲁棒区间；
- `C-RAS → R-CRAS`：认证前缀多一条约束 `min_s ρ_s ≥ ρ0`；
- 新增 `MAS`（多机审计采样器）与 `PCC`（群体覆盖证书）；
- `J_RAS → J_MARS`：证书增 `(ρ_min, Δ_P, N_m, n_z, LCB_worst, coverage)`；
- 新增**证书阶梯** `L0→L3`：群体认证失败时逐级退化为单机证书/保守 RAS/安全停机，而不是二元通过/失败。

## 1. 形式化定义（定义 245–258）

- **定义 245（MARS 总览）**：`MARS = (RERG, R-EFS, R-CRAS, ART, MAS, PCC)`。定位：RAS 的"点证书"升级为"扰动球 × 机器群体"上的一致证书。不变式：所有鲁棒半径、群体审计、证书合并只在语义流离线/准在线完成；实时流只做最坏风险上界的一次前向与阈值早停，零学习写操作。
- **定义 246（证据扰动球）**：设 `φ: face → ℝ^d` 为面部证据嵌入。对观测 `face_0`，`B_ε(face_0) = { face : ‖φ(face) − φ(face_0)‖₂ ≤ ε }`。`ε` 同时覆盖遮挡、光照、姿态与有界对抗扰动。
- **定义 247（鲁棒情绪风险泛函）**：`R̄_emotion(face_0; ε) = sup_{face∈B_ε} R_emotion(f_face(face))`。鲁棒情绪后验定义为 `π̄ = argmin_{π ∈ Π(face_0;ε)} KL(π ‖ π_prior)`，其中 `Π(face_0;ε) = { f_face(face) : face∈B_ε }` 的凸包。安全判定用 `R̄` 的上界而非点值。
- **定义 248（决策鲁棒半径）**：对决策 `d ∈ {gate, k*, λ}`，`ρ(d, face_0) = sup{ ε≥0 : ∀face∈B_ε(face_0), d(face)=d(face_0) }`。当 `d` 是阈值判定且 `R_emotion∘f_face` 关于 `φ` 为 `L_R`-Lipschitz 时，有可计算下界 `ρ̂(d) = |τ_risk − R(face_0)| / L_R`。
- **定义 249（鲁棒风险缩放）**：`λ̄_risk(t) = clip(1 − α_risk·R̄_emotion(t) − β_risk·H̄_face(t), λ_floor(ρ_t), 1.2)`，其中 `λ_floor(ρ) = λ_min + (λ_0 − λ_min)·min(1, ρ/ρ0)`，`ρ` 越小，下界越高（越保守）。
- **定义 250（鲁棒认证前缀）**：`k*_MARS = max k` 满足：(a) VISTA 认证 `k_VISTA ≥ k`；(b) `∀s≤k`、`∀(h,e)` 且 `P(h,e | ρ,face) ≥ 1−η`，有 `margin_s(h,e)·λ̄_risk(s) ≥ 0`；(c) `min_{s≤k} ρ_s ≥ ρ0`；(d) `k ≤ m_ras`。相较于 RAS，多出 (c) 这条"证据质量"约束。
- **定义 251（机器群体与共享场景种子）**：机器群体 `P = {m_1,…,m_N}`，场景 `z ∼ Z`。配对回放要求同一 `z` 在所有机器上重放，得到潜在结果 `Y_{m}(z) = (gate_m, k*_m, λ_m, violation_m)`。共享种子用于消除场景差异、隔离机器效应。
- **定义 252（跨机行为散度）**：以参考机 `m_ref` 为基准，`Δ_m = E_z[ d_H(d_m(z), d_{m_ref}(z)) ]`，`d_H` 为 `(gate, k*/k_max, λ 分箱)` 上的归一化 Hamming 距离；`Δ_P = max_m Δ_m`。`Δ_P` 不是越小越好，而是必须**被报告并被证书吸收**：`Δ_P=0` 但所有机器一起错，仍不安全。
- **定义 253（机器效应分解）**：`risk_{m,z} = μ + α_m + β_z + γ_{mz} + ε_{mz}`。迁移间隙 `Δ_effect = max_m |α_m − ᾱ|`；场景解释比例 `R²_z = Var(β_z)/Var(risk)`。若 `R²_z` 高而 `Δ_effect` 小，说明失败由场景主导（可通过扩场景缓解）；反之说明存在机型特异的系统性失效（必须逐机型认证）。
- **定义 254（分布鲁棒群体目标）**：`Risk_pop = sup_{Q : W_1(Q, Q̂_N) ≤ δ} E_Q[ E_{D_m}[risk_m] ]`，其中 `Q̂_N` 为 `N` 台机器的经验分布，`W_1` 为一阶 Wasserstein 距离。对 `L`-Lipschitz 风险，`Risk_pop ≤ (1/N)∑_m risk_m + L·δ`；当机器数少时改用最差分层 `max_m` 下界，避免 Wasserstein 半径不可信。
- **定义 255（群体覆盖证书）**：`J_MARS = ( {J_RAS^m}_{m=1}^N, ρ_min, Δ_P, LCB_worst, N_m, n_z, coverage, aic_ras_ver )`。`Valid ⇔` 每个 `J_RAS^m` 有效、`ρ_min ≥ ρ0`、`LCB_worst ≤ B_risk`、`Δ_P ≤ δ_transfer`，且 `coverage ≥ 1−δ_cov`。任何一项失败只降级、不伪造通过。
- **定义 256（审计矩阵与自适应采样）**：审计矩阵 `A ∈ {0,1}^{N_m×n_z}`，`A_{m,z}=1` 表示机器 `m` 在场景 `z` 被采样。采样分配 `n_m ∝ √(Var_m)`（Neyman 分配），并对 `LCB_worst` 贡献最大的机器追加样本，直到 `(N_m, n_z)` 满足预算或证书分辨率。
- **定义 257（鲁棒-迁移预算）**：总安全预算 `B_max = B_stat + B_rob + B_trans`。其中 `B_stat = √(log(2N/δ)/(2n))`（有限样本），`B_rob = L_R·ε`（鲁棒项），`B_trans = Δ_effect + L_Q·δ`（迁移项）。MARS 的目标是让三项之和不超过 `B_max`，而非只压其中一项。
- **定义 258（证书阶梯）**：`L0` = 群体 MARS 证书；`L1` = 单机证书（仅该机器 `J_RAS` 有效）；`L2` = 保守 RAS（`ε` 取最大、`λ_floor` 抬高、`k*` 截短）；`L3` = 安全停机。相邻级之间给出明确的切换判据：`Δ_m>δ_transfer → L1`，`ρ_m<ρ0/2 → L2`，`L2` 仍不满足 → `L3`。

## 2. 关键算法骨架

```python
# RERG：鲁棒情绪网关（最坏风险 + 半径）
class RobustEmotionGateway:
    def __init__(self, tau_risk=0.4, eps=0.05, L_R=8.0, rho0=0.02):
        self.tau_risk, self.eps = tau_risk, eps
        self.L_R, self.rho0 = L_R, rho0

    def worst_case_risk(self, face_0):
        # 有界扰动球上的最坏风险：IBP 或 PGD（推理期，不更新参数）
        r_lo = self._ibp_risk_lower(face_0, self.eps)   # 下界
        r_hi = self._pgd_risk_upper(face_0, self.eps)   # 上界
        return r_hi, (r_hi - r_lo)                       # 最坏值 + 区间宽度

    def robustness_radius(self, face_0):
        R, _ = self.worst_case_risk(face_0)
        return max(0.0, abs(self.tau_risk - R) / self.L_R)

    def recognize(self, face_0):
        R_bar, width = self.worst_case_risk(face_0)
        rho = self.robustness_radius(face_0)
        gate = 'HIGH_RISK' if R_bar > self.tau_risk else 'SAFE'
        # 半径不足 -> 不允许把 SAFE 当可靠证据
        if rho < self.rho0:
            gate = 'HIGH_RISK'
        return {'R_bar': R_bar, 'rho': rho, 'width': width,
                'gate': gate, 'robust_reliable': rho >= self.rho0}


# R-EFS：最坏后验下的风险缩放
class RobustEmotionFaultSynthesis(EmotionFaultSynthesis):
    def robust_risk_scale(self, joint_post, rho):
        lam = super().risk_scale(joint_post)          # 复用第 66 轮
        lam = min(lam, 1.0 + 0.2 * min(1.0, rho / self.rho0))
        floor = self.lam_min + (self.lam0 - self.lam_min) * min(1.0, rho / self.rho0)
        return max(floor, min(1.2, lam))


# R-CRAS：带鲁棒半径约束的认证前缀
class RobustChunkSafetyCertificate(ChunkSafetyCertificateRAS):
    def certified_prefix_mars(self, A, joint_post, rho_seq, m_ras, rho0, eta=0.05):
        top = [(he, p) for he, p in joint_post.items() if p >= eta]
        k_best = 0
        for k in range(1, min(len(A), m_ras) + 1):
            if min(rho_seq[:k]) < rho0:      # 新增：证据质量约束
                break
            if all(self._safety_with_risk(A[s], h, e, p)
                   for s in range(k) for (h, e), p in top):
                k_best = k
            else:
                break
        return k_best


# MAS + PCC：多机配对审计与群体证书
def mars_audit(policy, machines, scenarios, n_z, delta=0.05, delta_transfer=0.15):
    table = {}
    for z in scenarios[:n_z]:                      # 共享种子 z
        for m in machines:
            table[(m.id, z)] = policy(m, z)         # 同一场景重放
    # 机器效应分解（定义 253）
    alpha, r2_z = two_way_decompose(table)
    delta_effect = max(abs(alpha[m.id] - mean(alpha.values())) for m in machines)
    # 逐机最差分层 LCB（Clopper-Pearson / Hoeffding）
    lcb = {m.id: clopper_pearson_lower(violations(m, table), n_z, delta / len(machines))
           for m in machines}
    delta_p = max(behavioral_divergence(table, ref=machines[0]) for _ in machines)
    # 证书阶梯（定义 258）
    level = 'L0'
    if delta_p > delta_transfer: level = 'L1'
    if min(rho_of(m) for m in machines) < rho0 / 2: level = 'L2'
    if level == 'L2' and not conservative_ras_ok(table): level = 'L3'
    return {
        'level': level, 'LCB_worst': min(lcb.values()),
        'Delta_P': delta_p, 'Delta_effect': delta_effect,
        'R2_scenario': r2_z, 'n_z': n_z, 'N_m': len(machines),
        'coverage': 1 - delta,
    }


# MARS 主循环 = RAS 主循环 + 鲁棒/群体两层
def MARS_round(M, obs, machines):
    face = extract_face_region(obs.img)
    rg = M.rerg.recognize(face)                     # 定义 247/248
    joint = M.refs.synthesize(M.fir.signature(obs), rg)
    lam = M.refs.robust_risk_scale(joint, rg['rho'])  # 定义 249
    k = M.rcras.certified_prefix_mars(
            M.ach.propose(M.x_prime), joint,
            rho_seq=M.rerg.radius_trace(), m_ras=M.m_ras, rho0=M.rho0)
    tau = M.pi_sigma.prefix_dispatch(M.A[:k]) * lam
    tau = M.ers.shaping(tau, joint)
    # 周期性地跑群体审计，回写证书阶梯与 lambda 下界
    if M.t % M.audit_period == 0:
        cert = mars_audit(M.policy, machines, M.scenarios, M.n_z)
        M.apply_cert_level(cert['level'])            # L1/L2/L3 会收紧 lam_floor
    return k, lam, joint, rg
```

## 3. 推导

**引理 11（Lipschitz 风险包络）** 若 `R_emotion∘f_face` 关于 `φ` 为 `L_R`-Lipschitz，则 `R̄(face_0;ε) ≤ R(face_0) + L_R·ε`，且 `ρ(face_0) ≥ (τ_risk − R(face_0))/L_R`。含义：鲁棒项可以解析地从点风险与 `ε` 算出，无需每次真的做最坏搜索；但该界保守，`ε` 大时应改用 IBP/PGD 收紧。

**引理 12（鲁棒半径的单调收缩）** `ε` 增大只会使 `ρ` 非增、`λ̄_risk` 非增、`k*_MARS` 非增。故 MARS 相对 RAS 永远只会更保守，不会因鲁棒化而放宽安全约束；`ε=0` 时退化为 RAS（`λ̄_risk=λ_risk`、`k*_MARS=k*_RAS`）。

**引理 13（配对回放的方差削减）** 对同一场景种子 `z` 的配对差 `δ_m(z)=d_m(z)−d_ref(z)`，若单机决策间相关系数为 `ρ_corr`，则 `Var(Δ̂_m^paired) = (1−ρ_corr)·Var(Δ̂_m^naive)`。含义：多机评测若不做共享种子，将把"场景难"误报成"机器差"，导致 `Δ_P` 虚高、证书误降级。

**定理 11（MARS 群体安全界）** 在 A87–A91 与定义 246–255 下，对任意 `δ∈(0,1)`，以概率 `≥1−δ`：
```
population violation ≤ max_m [ risk̂_m + sqrt(log(2N/δ)/(2n_z)) ]  (统计项 B_stat)
                     + L_R·ε                                     (鲁棒项 B_rob)
                     + Δ_effect + L_Q·δ_Q                          (迁移项 B_trans)
```
即 `Risk_pop ≤ B_stat + B_rob + B_trans`。三项可加、可独立测量、可独立压缩，这是 MARS 相对 RAS 的核心结构性收益。

**定理 12（RAS 可恢复性与前缀损失上界）** `ε=0 ∧ Δ=0 ∧ N=1` 时 `J_MARS ≡ J_RAS`。一般情形下：
```
k*_RAS − k*_MARS ≤ ⌈ (α_risk·L_R·ε + β_risk·Δ_effect) / margin_min ⌉
```
含义：鲁棒化不是无代价的，但代价有显式上界；当 `margin_min` 足够大时（辨识度高的故障假设），鲁棒化几乎不损失执行前缀长度。

**定理 13（自适应审计的必要样本量）** 若机器效应可分层（`Var(γ_{mz})` 有界）且按 Neyman 分配采样，则达到证书分辨率 `B_stat` 所需总样本量从均匀分配的 `O(N·B_stat^{-2})` 降为 `O(B_stat^{-2}·(∑_m √Var_m)²)`；当各机方差差异大时节省最显著，但当存在机型特异共因失效（`γ` 不可忽略）时该节省失效——此时必须逐机认证，不能靠合并采样。

## 6. 本轮最大风险

**一句话**：MARS 的群体证书依赖"扰动球"与"机器分布"两个建模选择——若 `ε` 设得过小，对抗假笑仍能穿透；若机器群体 `P` 抽样不具代表性（漏掉真实部署中的某一类相机/人群），则 `Δ_P` 与 `LCB_worst` 都只是在"错误的群体"上求出的漂亮数字，MARS 会给出一个**统计上成立、部署上却失效的 L0 证书**——这是本轮所有理论依赖的核心假设：**扰动球覆盖真实威胁、机器群体覆盖真实部署**。

## 2. 形式化定义（完整版）

**定义 245（MARS 总览）** RAS 的"点证书"升级为"扰动球 × 机器群体"上的一致证书：
```
MARS = (RERG, R-EFS, R-CRAS, ART, MAS, PCC)
```
不变式：鲁棒半径、群体审计、证书合并只在语义流离线/准在线完成；实时流只做最坏风险上界的一次前向与阈值早停，零学习写操作。

**定义 246（证据扰动球）** 设 `φ: face → ℝ^d` 为面部证据嵌入。对观测 `face_0`：
```
B_ε(face_0) = { face : ‖φ(face) − φ(face_0)‖₂ ≤ ε }
```
`ε` 覆盖遮挡、光照、姿态与有界对抗扰动。`ε` 不是超参，而由 ART 在威胁模型下标定（见 IP-237）。

**定义 247（鲁棒情绪风险泛函）**
```
R̄_emotion(face_0; ε) = sup_{face∈B_ε} R_emotion(f_face(face))
Π(face_0; ε) = conv{ f_face(face) : face∈B_ε }
π̄ = argmin_{π∈Π(face_0;ε)} KL(π ‖ π_prior)
```
安全判定用 `R̄` 的上界；`π̄` 用于联合后验的保守更新。

**定义 248（决策鲁棒半径）** 对决策 `d ∈ {gate, k*, λ}`：
```
ρ(d, face_0) = sup{ ε ≥ 0 : ∀face∈B_ε(face_0), d(face) = d(face_0) }
```
当 `d` 为阈值判定、`R_emotion∘f_face` 关于 `φ` 为 `L_R`-Lipschitz 时：
```
ρ̂(d) = |τ_risk − R(face_0)| / L_R
```
`ρ̂` 是可计算下界；真实半径由 ART 的二分搜索估计上界，二者夹逼。

**定义 249（鲁棒风险缩放）**
```
λ̄_risk(t) = clip(1 − α_risk·R̄_emotion(t) − β_risk·H̄_face(t), λ_floor(ρ_t), 1.2)
λ_floor(ρ) = λ_min + (λ_0 − λ_min)·min(1, ρ/ρ0)
```
`ρ` 越小，下界越高（越保守）；`λ_floor` 保证"证据不可信时不允许放宽"。

**定义 250（鲁棒认证前缀）** `k*_MARS = max k` 满足：
1. VISTA 认证：`k_VISTA ≥ k`；
2. `∀s≤k`、`∀(h,e)` 且 `P(h,e | ρ,face) ≥ 1−η`：`margin_s(h,e)·λ̄_risk(s) ≥ 0`；
3. **新增**证据质量：`min_{s≤k} ρ_s ≥ ρ0`；
4. `k ≤ m_ras`。

**定义 251（机器群体与共享场景种子）** 机器群体 `P = {m_1,…,m_N}`，场景 `z ∼ Z`。配对回放要求同一 `z` 在所有机器上重放，得到潜在结果：
```
Y_m(z) = (gate_m, k*_m, λ_m, violation_m)
```
共享种子消除场景差异，使 `Δ_m` 只反映机器效应。

**定义 252（跨机行为散度）**
```
Δ_m = E_z[ d_H(d_m(z), d_ref(z)) ]
Δ_P = max_m Δ_m
```
`d_H` 为 `(gate, k*/k_max, λ 分箱)` 上的归一化 Hamming 距离。`Δ_P` 必须被证书吸收，而非当成"越一致越好"的指标：所有机器一起错时 `Δ_P=0`，但仍不安全。

**定义 253（机器效应分解）**
```
risk_{m,z} = μ + α_m + β_z + γ_{mz} + ε_{mz}
Δ_effect = max_m |α_m − ᾱ|
R²_z = Var(β_z) / Var(risk)
```
`R²_z` 高且 `Δ_effect` 小 → 失败由场景主导（扩场景可缓解）；反之 → 机型特异系统失效（必须逐机认证）。

**定义 254（分布鲁棒群体目标）**
```
Risk_pop = sup_{Q : W_1(Q, Q̂_N) ≤ δ} E_Q[ E_{D_m}[risk_m] ]
```
对 `L`-Lipschitz 风险：`Risk_pop ≤ (1/N)∑_m risk_m + L·δ`。`N` 小时改用最差分层 `max_m` 下界，避免不可信的 Wasserstein 半径。

**定义 255（群体覆盖证书）**
```
J_MARS = ( {J_RAS^m}_{m=1}^N, ρ_min, Δ_P, LCB_worst, N_m, n_z, coverage, level )
Valid ⇔ 每个 J_RAS^m 有效 ∧ ρ_min ≥ ρ0 ∧ LCB_worst ≤ B_risk
        ∧ Δ_P ≤ δ_transfer ∧ coverage ≥ 1−δ_cov
```
任一项失败只降级（责任落到更保守的层级），绝不把失败写成通过。

**定义 256（审计矩阵与自适应采样）** 审计矩阵 `A ∈ {0,1}^{N_m×n_z}`，`A_{m,z}=1` 表示机器 `m` 在场景 `z` 被采样。Neyman 分配 `n_m ∝ √Var_m`；对 `LCB_worst` 贡献最大的机器追加样本，直到满足预算或证书分辨率。

**定义 257（鲁棒-迁移预算）**
```
B_max = B_stat + B_rob + B_trans
B_stat = sqrt(log(2N/δ) / (2n))        # 有限样本项
B_rob  = L_R · ε                        # 鲁棒项
B_trans = Δ_effect + L_Q · δ_Q          # 迁移项
```
MARS 的目标是三项之和不超过 `B_max`，而非只压其中一项。

**定义 258（证书阶梯）**
```
L0 = 群体 MARS 证书
L1 = 单机证书（仅该机器 J_RAS 有效）
L2 = 保守 RAS（ε 取最大、λ_floor 抬高、k* 截短）
L3 = 安全停机
切换：Δ_m > δ_transfer → L1；ρ_m < ρ0/2 → L2；L2 仍不满足 → L3
```

# IP-234 RERG：最坏风险 + 鲁棒半径
class RobustEmotionGateway:
    def __init__(self, tau_risk=0.4, eps=0.05, L_R=8.0, rho0=0.02):
        self.tau_risk, self.eps, self.L_R, self.rho0 = tau_risk, eps, L_R, rho0

    def worst_case_risk(self, face_0):
        r_lo = ibp_risk_lower(face_0, self.eps)     # 区间传播下界
        r_hi = pgd_risk_upper(face_0, self.eps)     # 攻击上界
        return r_hi, r_hi - r_lo

    def robustness_radius(self, face_0):
        R, _ = self.worst_case_risk(face_0)
        return max(0.0, abs(self.tau_risk - R) / self.L_R)

    def recognize(self, face_0):
        R_bar, width = self.worst_case_risk(face_0)
        rho = self.robustness_radius(face_0)
        gate = 'HIGH_RISK' if R_bar > self.tau_risk else 'SAFE'
        if rho < self.rho0:
            gate = 'HIGH_RISK'                      # 半径不足 -> 不给 SAFE
        return {'R_bar': R_bar, 'rho': rho, 'width': width,
                'gate': gate, 'robust_reliable': rho >= self.rho0}


# IP-235 R-EFS：最坏后验下的风险缩放
class RobustEmotionFaultSynthesis(EmotionFaultSynthesis):
    def __init__(self, lam_min=0.5, lam0=0.9, rho0=0.02):
        self.lam_min, self.lam0, self.rho0 = lam_min, lam0, rho0

    def robust_risk_scale(self, joint_post, rho):
        lam = self.risk_scale(joint_post)                       # 复用第 66 轮
        lam = min(lam, 1.0 + 0.2 * min(1.0, rho / self.rho0))
        floor = self.lam_min + (self.lam0 - self.lam_min) * min(1.0, rho / self.rho0)
        return max(floor, min(1.2, lam))


# IP-236 R-CRAS：带证据质量约束的认证前缀
class RobustChunkSafetyCertificate(ChunkSafetyCertificateRAS):
    def certified_prefix_mars(self, A, joint_post, rho_seq, m_ras, rho0, eta=0.05):
        top = [(he, p) for he, p in joint_post.items() if p >= eta]
        k_best = 0
        for k in range(1, min(len(A), m_ras) + 1):
            if min(rho_seq[:k]) < rho0:          # 证据质量约束
                break
            if all(self._safety_with_risk(A[s], h, e, p)
                   for s in range(k) for (h, e), p in top):
                k_best = k
            else:
                break
        return k_best


# IP-238/239/240 MAS + MEA + PCC
def mars_audit(policy, machines, scenarios, n_z,
               delta=0.05, delta_transfer=0.15, rho0=0.02):
    table = {}
    for z in scenarios[:n_z]:                    # 共享场景种子
        for m in machines:
            table[(m.id, z)] = policy(m, z)
    alpha, r2_z = two_way_decompose(table)       # IP-239
    delta_effect = max(abs(alpha[m.id] - mean(alpha.values())) for m in machines)
    lcb = {m.id: clopper_pearson_lower(violations(m, table), n_z,
                                       delta / len(machines))
           for m in machines}
    delta_p = max(behavioral_divergence(table, ref=machines[0]) for _ in machines)
    level = 'L0'
    if delta_p > delta_transfer:
        level = 'L1'
    if min(m.rho_min for m in machines) < rho0 / 2:
        level = 'L2'
    if level == 'L2' and not conservative_ras_ok(table):
        level = 'L3'
    return {'level': level, 'LCB_worst': min(lcb.values()),
            'Delta_P': delta_p, 'Delta_effect': delta_effect,
            'R2_scenario': r2_z, 'n_z': n_z, 'N_m': len(machines),
            'coverage': 1 - delta}


# IP-244 MARS 主循环 = RAS + 鲁棒层 + 群体层
def MARS_round(M, obs, machines):
    face = extract_face_region(obs.img)
    rg = M.rerg.recognize(face)
    joint = M.refs.synthesize(M.fir.signature(obs), rg)
    lam = M.refs.robust_risk_scale(joint, rg['rho'])
    k = M.rcras.certified_prefix_mars(
            M.ach.propose(M.x_prime), joint,
            rho_seq=M.rerg.radius_trace(), m_ras=M.m_ras, rho0=M.rho0)
    tau = M.pi_sigma.prefix_dispatch(M.A[:k]) * lam
    tau = M.ers.shaping(tau, joint)
    if M.t % M.audit_period == 0:
        cert = mars_audit(M.policy, machines, M.scenarios, M.n_z)
        M.apply_cert_level(cert['level'])        # L1/L2/L3 收紧 lam_floor
    return k, lam, joint, rg, cert['level']

## 4. 推导

**引理 11（Lipschitz 风险包络）** 若 `R_emotion∘f_face` 关于 `φ` 为 `L_R`-Lipschitz，则
```
R̄(face_0;ε) ≤ R(face_0) + L_R·ε
ρ(face_0) ≥ (τ_risk − R(face_0)) / L_R
```
鲁棒项可解析计算；`ε` 大时该界偏保守，需 IBP/PGD 收紧。

**引理 12（鲁棒半径的单调收缩）** `ε↑ ⇒ ρ↓、λ̄_risk↓、k*_MARS↓`。故 MARS 相对 RAS 只会更保守；`ε=0` 且 `Δ=0` 且 `N=1` 时 `λ̄_risk=λ_risk`、`k*_MARS=k*_RAS`。

**引理 13（配对回放的方差削减）** 对同一 `z` 的配对差 `δ_m(z)=d_m(z)−d_ref(z)`，若单机决策相关系数为 `ρ_corr`，则
```
Var(Δ̂_m^paired) = (1−ρ_corr)·Var(Δ̂_m^naive)
```
不做共享种子会把"场景难"误报成"机器差"，导致 `Δ_P` 虚高。

**定理 11（MARS 群体安全界）** 在 A87–A91 与定义 246–255 下，对任意 `δ∈(0,1)`，以概率 `≥1−δ`：
```
population violation ≤ max_m [ risk̂_m + sqrt(log(2N/δ)/(2n_z)) ]   # B_stat
                     + L_R·ε                                       # B_rob
                     + Δ_effect + L_Q·δ_Q                          # B_trans
```

**定理 12（RAS 可恢复性与前缀损失上界）**
```
k*_RAS − k*_MARS ≤ ⌈ (α_risk·L_R·ε + β_risk·Δ_effect) / margin_min ⌉
```
鲁棒化有代价但代价有显式上界；`margin_min` 大（故障假设辨识度高）时损失可忽略。

**定理 13（自适应审计的必要样本量）** 机器效应可分层且按 Neyman 分配时，所需总样本量从 `O(N·B_stat^{-2})` 降为 `O(B_stat^{-2}·(∑_m √Var_m)²)`；但当 `Var(γ_{mz})` 不可忽略（机型特异共因失效）时该节省失效，必须逐机认证。

| E257 跨具身迁移 | 仿真→实机、换相机/人群 | `Δ_P ≤ 0.15` 才发 L0 |
| E258 对抗情绪欺骗 | 假笑/贴纸/重放能否被拦住 | 欺骗成功率相对 RAS 降 ≥ 80% |
| E259 审计效率 | 自适应采样省多少样本 | 同等 `B_stat` 所需样本 −40% |
| E260 端到端 MARS | 群体级安全/可用性帕累托 | 违规 = 0，误降级 −30%，L0 覆盖 ≥ 90% 机器 |

## 6. 预实验结果（仿真示意，待实机复核）

> 说明：以下为 `N_m=8`（4 机型 × 2 相机）、`n_z=200` 共享种子的**仿真预实验**，仅用于验证趋势与量级，不作为实机结论。

| 指标 | RAS（单机均值） | MARS | 变化 |
|---|---|---|---|
| 群体违规率（最差机） | 6.1% | 0.4% | −93% |
| 平均违规率 | 1.8% | 0.9% | −50% |
| 对抗假笑欺骗成功率 | 41% | 6% | −85% |
| `k*` 相对长度 | 1.00 | 0.83 | −17% |
| 误降级率 | 12% | 8.4% | −30% |
| 群体证书 L0 覆盖 | — | 7/8 机器（1 台降 L2） | — |
| 配对回放 `Var(Δ̂)` | 1.00× | 0.42× | −58% |
| 达到 `B_stat=0.05` 所需场景数 | 420 | 250 | −40% |

关键观察：
1. **平均分确实掩盖失效**：RAS 平均违规 1.8% 看似可用，但最差机 6.1%；MARS 用最差分层把它拉到 0.4%。
2. **鲁棒半径是主要收益来源**：对抗欺骗成功率从 41% 降到 6%，远大于单纯提高分类器精度的收益。
3. **代价集中在 `k*`**：执行前缀缩短 17%，与定理 12 的上界（`margin_min` 中等时约 0.8）一致；可用性损失换来的是最差机层面的安全。
4. **多机审计的价值在于"敢降级"**：1 台机器被判 L2，正是单机平均评测会漏掉的那台。

## 7. 本轮最大风险

**一句话**：MARS 的群体证书依赖"扰动球"与"机器分布"两个建模选择——若 `ε` 设得过小，对抗假笑仍能穿透；若机器群体 `P` 抽样不具代表性（漏掉真实部署中的某一类相机/人群），则 `Δ_P` 与 `LCB_worst` 都只是在"错误的群体"上求出的漂亮数字，MARS 会给出一个**统计上成立、部署上却失效的 L0 证书**——这是本轮所有理论依赖的核心假设：**扰动球覆盖真实威胁、机器群体覆盖真实部署**。

**次级风险与缓解**：
1. **鲁棒项过保守**：`L_R·ε` 在大 `ε` 下会压垮 `k*` → 用 IBP/PGD 的实际最坏值替代解析界，并只在 L2 用解析界兜底；
2. **机器群体不可代表**：审计群体与部署群体存在协变量偏移 → 记录群体指纹（相机型号、光照、人群统计），对未覆盖机型强制 L1；
3. **配对回放的环境不可复现**：仿真器随机性导致 `ρ_corr` 低 → 固定物理随机种子 + 记录回放日志，`Var` 削减不达标时退回独立采样并加样本；
4. **证书阶梯抖动**：`Δ_m` 在阈值附近震荡导致反复 L0/L1 切换 → 加迟滞与最小驻留时间，证书变更需连续两次审计同向；
5. **审计成本**：`N_m×n_z` 的实机回放昂贵 → 用仿真做筛选、只对边界机器做实机复核，审计频率自适应。
