# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环第 3 轮；本轮灵感：「视觉问答」×「可重构机构」）

> R69 把不确定性一分为二，让 epistemic 的那一半去「问」：看、问、触。但它偷偷预设了两件事——**提问的身体是固定的**（动作空间 𝒜 不随问句改变），**提问的方式是自由的**（任何问句都可以问）。本轮两个灵感正好拆掉这两个前提：
> - **视觉问答（VQA）** 说明一个好问题不是「随便问」，而是**语言谓词必须绑定到图像区域**；这恰好是 R69 最大风险（追问一个流模型幻觉出来的幽灵模态）的解药——绑定不了区域的问题，不允许问。
> - **可重构机构** 说明身体本身可以变：拓扑、自由度、刚度、传感器基线都能换。于是「信息动作」不再是在固定动作空间里选一个点，而是**先决定用哪一副身体去问**。
>
> 核心命题：**把「提问」升级为「提问 × 改造提问的身体」的联合设计；一个假设只有在至少两种「混淆结构不同」的构型下都被同一个接地问题支持，才算被验证。** 命名 **MORPH-RAS**（Morphology-conditioned Observation–Reconfiguration for Proactive Hypothesis resolution）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**为了让这个问题可回答，我该先把自己变成什么**」。

## 0. 直觉与动机

**灵感 1（视觉问答 → 问题必须接地，答案必须带证据区域）**
直觉：VQA 的核心不是「看图说话」，而是**把语言里的指称绑定到图像里的区域**。这恰好可以充当「该不该问」的判据：若一个候选假设在图上找不到支持它的区域（比如流模型幻觉出一个不存在的「左侧障碍」），关于它的问题就根本无法接地——**幽灵模态在下游无法接地，就在上游被过滤**。进一步，VQA 的经典病灶是语言先验压过视觉证据（VQA-CP 揭示的答案先验）；搬到闭环里，就是「问题太容易被常识蒙对，答了也没信息」。所以一个好问题要同时满足三条：可接地（有区域支撑）、反事实平衡（不同假设下答案分布不同）、语言先验弱（不靠常识就能答对）。

**灵感 2（可重构机构 → 身体是测量装置的一部分）**
直觉：R69 的看/问/触都发生在**固定运动学**下。但很多歧义不是「看不清」，而是「这副身体根本看不出来」：两个假设在当前传感器基线/刚度/自由度下**结构不可辨**，再问一百次也没用。可重构机构给出第三条路：换构型。加长基线可以三角化深度；换软指可以区分「物体软」还是「探针软」；改变接触点可以打破静摩擦与质量的混淆——**测量装置本身成为可优化变量**。这把 R69 的 Δ_min（模态间距）从常数变成 Δ_min(c)，「可分性」第一次成为可控量。

**灵感 3（对偶 → 问题选择构型，构型选择问题）**
直觉：给定假设对 (m_i, m_j)，有些构型让它们天然可分，有些则让二者落入同一零空间。反过来，同一构型下不同问句的判别力也不同。二者必须**联合优化**：max_{c,q} 最坏情况下的可辨识度，减去重构成本与提问成本。这是实验设计（D-optimal / maximin design）在具身体上的版本，也是本轮把「问什么」升级为「用什么身体问什么」。

**灵感 4（配置即环境 → 用「跨构型不变性」替代「多源一致」）**
直觉：R69 的证据纪律是「k 个正交来源一致」，但多个来源可能一起被骗（共谋）。可重构机构提供一种更强的纪律：**改变自己，看答案还在不在**。真实假设应当在混淆结构不同的两个构型下都成立；被标定吸收的缓变故障只在某一个构型的零空间里隐形，换构型就会暴露。这把 R68 最脆弱的「缓变故障被标定解释掉」变成可检验的：**故障可以藏进一个构型的零空间，却藏不进两个构型零空间的交集**。这是不变性风险最小化（IRM）在测量装置上的镜像。

**灵感 5（新风险 → 选择偏差比幻觉更危险）**
直觉：一旦系统能选构型，它就能**挑一个让自己偏爱的假设显得一致的身体去问**。这不是验证，而是用身体做确认偏误（测量装置上的 p-hacking）。R69 的风险是「问错」；R70 的风险是「精心挑一个能证明自己对的身体去问」。所以本轮在给出方案的同时必须交付：假设无关的 maximin 构型选择、预注册构型账本、独立留出构型、以及对选择策略本身的偏差审计——否则「跨构型一致」只是一句更好听的自欺。

## 1. 形式化定义（增量：定义 310–327）

**定义 310（MORPH-RAS 总览与四不变式）** MORPH-RAS = (RGM, GVQ, JID, CCC, CAM, RSA, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R69 定义 276-i）；
(ii) **双重预算**：交互预算沿用 R69；重构预算为「单位时间 ≤1 次构型切换、切换必须经过认证静止集、切换期间快速环进入安全保持」；
(iii) **假设无关的构型选择**：构型/问题选择规则 f_sel 必须在看到具体假设证据之前预注册，只允许依赖假设集合 M、候选问题集 Q 与初始观测 o_0，不允许依赖「哪个假设更可能」；在线偏离必须记入账本并触发降级；
(iv) **跨构型证据纪律**：单构型、单问题、单源不得定案；同一接地假设需在 ≥2 个混淆结构不同的构型下一致，或被独立留出构型复核。

**定义 311（可重构机构与构型图 RGM）** 构型 c ∈ C，重构图 G_C=(C,E)；边 (c→c') 带转换代价 κ(c,c')、转换风险与前置条件（卸载/静止/重新标定）。每个 c 定义动作空间 𝒜(c) ⊂ ℝ^{d(c)}、安全包络 S(c)、观测模型 p(o|m,c) 与标定映射 r_cal(·|c)。可达构型集 R(c_0,B) = {c : 存在 c_0→c 路径且累计 κ ≤ B}。

**定义 312（构型条件观测与混淆零空间）** 局部线性化 y = H(c)m + b(c) + n，H(c) 为构型条件敏感矩阵，b(c) 为构型条件混淆（未建模但结构化），N(H(c)) 为其零空间。假设对 (i,j) 在 c 下**结构不可辨** ⇔ m_i−m_j ∈ N(H(c))（或可被 b(c) 完全吸收）。

**定义 313（重构转换与静止集）** 转换 c→c' 必须经过认证静止集 Q(c,c')：释放载荷、进入包络交集 S(c)∩S(c')、暂停任务动作；转换期间快速环沿用 c 的最后一个认证前缀并进入安全保持。转换完成后必须对目标构型 c' 重新认证控制前缀。

**定义 314（接地视觉问题 GVQ）** 问题 q=(ψ, R)，ψ 为语言谓词模板，R 为其指称绑定到的图像/点云区域。接地分 g_ground(q,o) = coverage(R)·alignment(ψ,R)·support(R)；答案 A 必须附带回答区域 R_A 与 grounding(q,A)。只有 g_ground ≥ τ_g 的问题才可问。

**定义 315（问题可采纳性）** q 可采纳 ⇔ (a) 可接地（定义 314）；(b) **反事实平衡**：存在假设对 (i,j) 使 D_ij(q)=KL(p(A|m_i,q) ‖ p(A|m_j,q)) ≥ τ_bal，且不存在单一答案在两类下先验概率 > 1−τ_prior（否则语言先验可蒙对）；(c) **语用对称**：问题在两类假设下的预设与礼貌代价对称，不暗示「是/否」方向。不可采纳 ⇒ 不生成问句（幽灵模态在此被拦）。

**定义 316（可辨识度矩阵与假设无关 maximin 设计）** 对构型 c、问题 q，D_ij(c,q) 为假设 i,j 下「答案+证据区域」分布的 Chernoff 系数；Δ_min(c,q)=min_{i≠j} D_ij(c,q)。联合设计：
(c*,q*) = argmax_{c∈R(c_0,B), q∈Q_adm} [Δ_min(c,q) − λ_c κ(c_0,c) − λ_q cost(q)]，
且该 argmax **只依赖 M、Q、o_0，不依赖后验权重 w**（假设无关）。系：maximin 提升的是最差假设对，而不是当前最可能的假设。

**定义 317（构型 VoI 与联合信息动作）** 扩展 R69 定义 298：u=(c,q,g)，VoI(u)=H(M|o)−E_{A,R}[H(M|o,A,R,c,q)]；u* = argmax_u [VoI(u) − κ(c_0,c) − cost(q) − cost(g)]，s.t. RSA 认证与双重预算。若 max VoI ≤ 成本 ⇒ 不重构不提问，退 R69。

**定义 318（构型-反事实一致性 CCC）** 设 c_1,c_2 混淆结构不同（N(H(c_1)) ≠ N(H(c_2))，且 N(H(c_1))∩N(H(c_2)) 不含任何 m_i−m_j）。假设 m 被 CCC 认证 ⇔ m 在 c_1,c_2 下均为 top-1、均有可采纳接地问题的支持、且跨构型答案一致性 κ_ccc ≥ θ。仅单构型一致 ⇒ 只提供似然，不单独定案。

**定义 319（构型感知计量 CAM）** 标定随构型变：r_cal(·|c)。跨构型迁移用**规范不变特征** φ(o)（对 c 变化不变的部分）；aliasing 残差 r_alias(c,c') = ‖φ(o_cal(c)) − φ(o_cal(c'))‖。若缓变故障在 c 的零空间被吸收、在 c' 不被吸收，则表现为 r_res↓ 而 r_alias↑ ⇒ **构型诱导的隐形故障**（把 R69 定义 301 的对偶扩展到构型维）。

**定义 320（重构安全证书 RSA）** 转换 c→c' 认证：静止集可达、包络交集非空、载荷释放、目标前缀重认证、失败回滚 c。任一不过 ⇒ 不重构，U_epi 视为未消解。

**定义 321（幽灵模态接地过滤 PMF）** 对每个候选模态 m 计算最佳接地分 g_ground^*(m)。若 g_ground^*(m) < τ_phantom ⇒ 标记不可接地，禁止为其生成问题，并在审计中记为「流模型幻觉」。系：R69 的 E300 幻影追问被**上游**拦截，而不是事后靠证据纪律补救。

**定义 322（VQAuditor-M）** 审计对象扩展为 (c,q) 对：问题是否诱导、接地是否真实、构型选择是否假设相关、预注册是否被偏离、独立留出构型是否通过、是否存在 confirmatory reconfiguration。结论回灌 AuditBuf，成为下一轮 JID 的偏差惩罚先验。

**定义 323（AIC-MORPH 威胁集）** ℰ_MORPH = ℰ_FLUID × ℰ_recon × ℰ_vqa。ℰ_recon：强制重构、重构锁定（拒绝回到安全构型）、构型诱导的标定 aliasing、切换瞬间的载荷攻击。ℰ_vqa：视觉对抗 patch、诱导性问句、谄媚式接地回答（区域对但结论错）、问题注入。

**定义 324（证书 J_MORPH）** J_MORPH = (J_FLUID, config_ledger_hash, identifiability_gain, ccc_consistency, heldout_config_pass, alias_residual_p95, reconfig_safety_margin, morph_ver)。Valid ⇔ Valid(J_FLUID) ∧ 选择假设无关且账本一致 ∧ (CCC 通过 ∨ 留出构型通过) ∧ 重构安全裕度 > 0。

**定义 325（三级退避与严格包含链）** 若 (c,q) 在预算内消解并通过 CCC ⇒ λ=λ_floor(U_ale)（resolution bonus）；若可重构但超预算/不安全 ⇒ 退回 R69（只提问/看/触，不动身体）；若不可辨、被投毒、ECE 越界或审计判确认偏误 ⇒ 退回 R68（λ=λ_floor(U_ale+U_epi)）。⇒ R68 ⊂ R69 ⊂ R70，安全侧单调不降。

**定义 326（预注册构型账本 PCL）** 在观测证据前，系统提交 f_sel:(M,Q,o_0,C)→(c,q) 与留出构型 c_h（由种子与任务决定，不由证据决定）。运行中任何偏离 f_sel 的选择必须记入 PCL 并触发审计；c_h 在定案前不得参与选择。系：把「选择身体」的自由度锁进一个可审计的承诺，防止在线 p-hacking。

**定义 327（深度-时延耦合）** 默认深度 0（不重构，等价 R69）；仅当 mode_head 报歧义且 Δ_min(c_0,q*) < τ 时允许深度 1（一次重构）；深度 2 仅在 VoI 余量 > 阈值且结果可缓存时允许。重构是**慢速监督动作**，不进入 2.6ms 快速环；快速环在静止集内以安全保持运行。

```python
# IP-264 RGM：构型图、可达性与转换状态机
class ReconfigManager:
    def reachable(self, c0, budget):
        return [c for c in self.graph.nodes
                if self.graph.path_cost(c0, c) <= budget and self.rsa.pre_ok(c0, c)]
    def transition(self, c, c_new):                       # 必须经认证静止集
        if not self.rsa.certify(c, c_new): return False
        self.enter_quiescent(c, c_new)                    # 卸载荷、包络交集、快速环安全保持
        self.apply(c, c_new); self.rsa.recertify_prefix(c_new)
        return True

# IP-265 GVQ：接地 + 反事实平衡 + 语用对称，三重过滤后才允许问
def ground_and_admit(mode, o, region_proposals):
    R = bind_referent(mode, region_proposals)             # 指称 -> 区域
    if R is None or g_ground(mode, R, o) < TAU_G: return None   # 幽灵模态在此被拦
    q = propose_question(mode, R)
    if D_kl(q, mode.pair) < TAU_BAL:        return None   # 语言先验可蒙对
    if pragmatic_asymmetry(q, mode.pair) > TAU_PRIOR: return None
    return q

# IP-266 JID：假设无关 maximin 联合设计（不看后验 w，防确认偏误）
def choose_design(M, Q, o0, c0, C, budget):
    best = None
    for c in rgm.reachable(c0, budget):
        for q in Q:
            if not q.admissible: continue
            score = min_pairwise_chernoff(M, c, q) - LAM_C*graph.path_cost(c0, c) - LAM_Q*q.cost
            if best is None or score > best.score: best = Design(c, q, score)
    return best                                      # score <= 0 -> 不重构不提问 (R69)

# IP-267 CCC：一个假设必须在两种混淆结构不同的构型下同时 top-1
def ccc_certify(mode, results):
    tops = [r.top1 for r in results]
    return (tops.count(mode.id) >= 2 and distinct_nullspaces(results) and
            cross_config_agreement(results) >= THETA_CCC)

# IP-268 CAM：构型感知计量，抓「换构型才暴露」的缓变故障
def alias_residual(o, o_cal, c, c_new):
    return norm(phi(o_cal(c)) - phi(o_cal(c_new)))    # r_res 低 + r_alias 高 = 构型诱导隐形故障

# IP-273 MORPH 主闭环（继承 R69，在「问什么」之前插入「用什么身体问」）
def MORPH_RAS_round(M, obs):
    z, o = M.mtm.forward(obs)
    c, U_cal, thr = M.cof.step(...)                   # R68 标定
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    # 1) 幽灵模态先做接地过滤（上游，而非事后补救）
    modes = [m for m in modes if M.gvq.ground_score(m, o) >= TAU_PHANTOM]
    # 2) 假设无关的 (c,q) 设计：预算内能否把最差假设对分开？
    d = M.jid.choose_design(M.hypotheses, M.qbank, o, c, M.C, M.budget)
    if d is None or d.score <= 0:
        return M.fluid_round(modes, U_ale, U_epi, o)  # 严格退 R69（含 R68）
    # 3) 预注册账本核对：偏离 f_sel 即降级并审计
    if not M.pcl.committed(d.c, d.q):
        M.vqa_m.flag('unregistered_deviation', d); return M.r68_fallback(modes)
    # 4) 安全重构（慢速监督动作），失败即回滚到 R69
    if d.c != c and not M.rgm.transition(c, d.c):
        return M.fluid_round(modes, U_ale, U_epi, o)
    # 5) 接地提问并收证据；CCC 需跨构型一致
    res = M.gvq.ask_and_observe(d.q, o, d.c)
    res_hold = M.ccc.replay_on_heldout(modes, d.q)    # 独立留出构型复核
    if not M.ccc.certify(res.mode, [res, res_hold]):
        return M.r68_fallback(modes)                  # 只当似然，不定案
    # 6) 消解成功：resolution bonus；否则 R68 保守
    U_epi_after = M.cia.update_belief(modes, res.answer)
    U_floor = U_ale + (0.0 if res.certified else U_epi_after)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    mode = select_mode(modes, U_epi_after, lam)
    k = M.c_ras_wm.certified_prefix_in(mode.a, d.c)   # 在目标构型 c' 重认证
    M.vqa_m.submit_async(d, res, U_epi, U_epi_after)
    return k, lam, mode, d.c
```

## 3. 推导

**引理 19（重构的可辨识增益）** 设 y=H(c)m+b(c)+n，两次独立测量分别在 c 与 c'。若 m_i−m_j ∈ N(H(c)) 但 ∉ N(H(c'))，则单构型 c 下该对不可辨（D_ij(c)=0），而联合 Chernoff 指数为 D_ij(c)+D_ij(c')=D_ij(c')>0，联合检验错误率 ≤ exp(−n·D_ij(c'))。更一般地，对任意假设对，D_ij(c)+D_ij(c') ≥ max(D_ij(c),D_ij(c'))，取 min 得 **Δ_min({c,c'}) ≥ max(Δ_min(c), Δ_min(c'))**：换构型对最差假设对单调不亏，且能在某一构型的零空间被另一构型补上时严格变好。系：**「不可辨」不是假设的性质，而是「假设 × 身体」的性质**。

**引理 20（接地问题的信息有效性）** 设 q 可采纳（定义 315）。则 (a) 幽灵模态的 g_ground < τ_phantom，被 PMF 拦下，其被追问率 ≤ 1−Precision(grounding@τ_phantom)；(b) 对任何被采纳问题，D_ij(q) ≥ τ_bal 给出答案后验误差的 Chernoff 上界 exp(−n·τ_bal)，与语言先验强度无关；(c) 语用对称约束把谄媚/诱导带来的方向性偏差限制在 τ_prior 内。系：**VQA 的质量不是「答得准」，而是「问得可检验」**——可接地、反事实平衡、语用对称，三者缺一不可。

**引理 21（确认偏误的杀伤力与 maximin 的修复）** 若 (c,q) 选择依赖后验 w，则对任意错误假设 m_f，存在选择策略按 argmax_c D_{f,·}(c) 挑构型，使 m_f 在两个构型下都 top-1 的概率趋近于 1——**跨构型一致可被制造**，CCC 失效。若选择假设无关且两构型混淆结构不同，则错误假设要同时在两构型下击败所有对手，其概率 ≤ Σ_{i≠f} exp(−n·(D_{fi}(c_1)+D_{fi}(c_2))) ≤ (|M|−1)exp(−n·Δ_min^ccc)。系：**CCC 的保证只对「不挑身体」的选择成立；选择偏差是比幻觉更深的漏洞**。

**定理 18（严格包含链 R68 ⊂ R69 ⊂ R70）** 取 C={c_0}、禁用重构、Q 限制为 R69 的 g_ask，则 MORPH 的 (c,q,g) 退化为 R69 的 (g)，CCC 退化为 R69 的 k 源一致纪律，逐指令与 FLUID 相同；再取 VoI ≤ 成本或 ECE > τ_ece，逐指令退化为 R68。反之 R70 在 ∃(c,q) 使 Δ_min 提升且通过 CCC 时严格优于 R69。故安全侧单调不降，效率侧获得构型维的额外 resolution bonus。

**定理 19（重构安全与无突变）** 转换经 RSA 认证（静止集、包络交集、载荷释放、目标前缀重认证、失败回滚）后，转换期间物理风险 ≤ ε_trans；由于转换期间快速环固定在 c 的最后认证前缀、且任务动作只在静止集内冻结/恢复，控制连续无突变；重构只改变「用哪副身体测量、选哪个模态」，不绕过 R68 的 λ floor。若重认证失败或 CCC 不通过，λ 单调不降地退回 R69/R68。

## 6. 本轮最大风险

**一句话**：MORPH-RAS 把「不确定性消解」建立在一条比 R69 更深的假设上——**系统可以自由选择测量自己的身体，而选择本身不会污染证据**。但一旦构型选择以后验为条件，系统就能挑一个让偏爱假设「跨构型一致」的身体，把确认偏误伪装成验证：这不是「问错」，而是**用身体把错误答案证明成对的**；它比 R69 的幻觉追问更隐蔽，因为审计看到的是一致性，而不是矛盾。

**次级风险与缓解**：
1. **确认偏误/选择偏差**（最危险）→ 假设无关 maximin（定义 316）+ 预注册账本 PCL（定义 326）+ 独立留出构型 + VQAuditor-M 偏差审计；任何依赖 w 的选择直接判无效；
2. **重构安全与突变** → 静止集、包络交集、载荷释放、目标重认证、失败回滚（定义 313/320、定理 19）；
3. **构型诱导的计量 aliasing**（换身体把故障藏得更深）→ 规范不变特征 + r_alias 对偶通道（定义 319、E306）；
4. **组合爆炸**（构型×问题×假设）→ 深度 ≤1 默认、maximin 剪枝、|C|≤8、Q≤6、离线缓存（定义 316/327）；
5. **视觉对抗与谄媚回答** → 接地 + 反事实平衡 + 语用对称三重过滤 + ℰ_vqa 对抗训练（定义 315/323、E311）；
6. **机构物理退化**（磨损、间隙、标定随构型漂移）→ 构型条件标定 + 长时程 E312 + 重构预算。

**当前方案的最大风险一句话**：**当「换一个身体去问」本身可以以后验为条件时，跨构型一致性会被系统自己制造出来——MORPH-RAS 真正的敌人不是看不清楚，而是一个太会挑测量装置的自己。**

# 第 70 轮产物 · 创新点清单 v1：MORPH-RAS（Morphology-conditioned Observation–Reconfiguration for Proactive Hypothesis resolution：接地视觉问答 × 可重构机构的身体-问题联合消歧闭环；RGM×GVQ×JID×CCC×CAM×RSA×PMF×RAS-WM‡）

>
> 本轮两个灵感正好补这两块：
> - **视觉问答**：好问题的判据是「语言谓词能不能绑定到图像区域」。绑定不了区域 ⇒ 幽灵模态在上游被过滤；能被常识蒙对 ⇒ 问题没有信息。这给 R69 的「问什么」补上**可检验性**；

>

```python
# IP-274 MORPH 主闭环（继承 R69）
def MORPH_RAS_round(M, obs):
    z, o = M.mtm.forward(obs); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    modes = [m for m in modes if M.gvq.ground_score(m, o) >= TAU_PHANTOM]   # 先接地过滤
    d = M.jid.choose_design(M.hypotheses, M.qbank, o, c, M.C, M.budget)     # 假设无关
    if d is None or d.score <= 0:
        return M.fluid_round(modes, U_ale, U_epi, o)                        # 退 R69/R68
    if not M.pcl.committed(d.c, d.q):                                       # 预注册核对
        M.vqa_m.flag('unregistered_deviation', d); return M.r68_fallback(modes)
    if d.c != c and not M.rgm.transition(c, d.c):
        return M.fluid_round(modes, U_ale, U_epi, o)                        # 重构失败即退 R69
    res      = M.gvq.ask_and_observe(d.q, o, d.c)
    res_hold = M.ccc.replay_on_heldout(modes, d.q)                          # 独立留出构型
    if not M.ccc.certify(res.mode, [res, res_hold]):
        return M.r68_fallback(modes)                                       # 只当似然，不定案
    U_epi_after = M.cia.update_belief(modes, res.answer)
    U_floor = U_ale + (0.0 if res.certified else U_epi_after)
    lam  = max(M.efs.risk_scale(...), lam_floor(U_floor))
    mode = select_mode(modes, U_epi_after, lam)
    k    = M.c_ras_wm.certified_prefix_in(mode.a, d.c)                      # 目标构型重认证
    M.vqa_m.submit_async(d, res, U_epi, U_epi_after)
    return k, lam, mode, d.c
```

## 4. 推导

**引理 19（重构的可辨识增益）** `y=H(c)m+b(c)+n`，两次独立测量在 c 与 c'。若 `m_i−m_j∈N(H(c))` 但 `∉N(H(c'))`，则单构型 c 下该对不可辨（D_ij(c)=0），联合 Chernoff 指数 `D_ij(c)+D_ij(c')=D_ij(c')>0`，联合检验错误率 ≤ `exp(−n·D_ij(c'))`。一般地 `D_ij(c)+D_ij(c') ≥ max(D_ij(c),D_ij(c'))`，取 min 得 **`Δ_min({c,c'}) ≥ max(Δ_min(c),Δ_min(c'))`**：换构型对最差假设对单调不亏，能补零空间时严格变好。系：**「不可辨」是「假设 × 身体」的性质，而非假设单独的性质。**

**引理 20（接地问题的信息有效性）** q 可采纳时：(a) 幽灵模态 `g_ground<τ_phantom` 被 PMF 拦下，追问率 ≤ `1−Precision(grounding@τ_phantom)`；(b) 被采纳问题满足 `D_ij(q)≥τ_bal`，答案后验误差 Chernoff 上界 `exp(−n·τ_bal)`，与语言先验强度无关；(c) 语用对称把谄媚/诱导的方向性偏差限制在 τ_prior 内。系：**VQA 的质量不是「答得准」，而是「问得可检验」——可接地、反事实平衡、语用对称，缺一不可。**

**引理 21（确认偏误的杀伤力与 maximin 的修复）** 若 (c,q) 选择依赖后验 w，则对任意错误假设 m_f，存在策略按 `argmax_c D_{f,·}(c)` 挑构型，使 m_f 在两构型下都 top-1 的概率趋近 1——**跨构型一致可被制造**，CCC 失效。若选择假设无关且两构型混淆结构不同，则错误假设须在两构型下同时击败所有对手，概率 ≤ `(|M|−1)·exp(−n·Δ_min^ccc)`。系：**CCC 的保证只对「不挑身体」的选择成立；选择偏差是比幻觉更深的漏洞。**

**定理 18（严格包含链 R68 ⊂ R69 ⊂ R70）** 取 C={c_0}、禁用重构、Q 限制为 R69 的 g_ask，则 MORPH 的 (c,q,g) 退化为 R69 的 g，CCC 退化为 k 源一致纪律，逐指令等于 FLUID；再取 VoI≤成本或 ECE>τ_ece，逐指令退化为 R68。反之 ∃(c,q) 使 Δ_min 提升且通过 CCC 时严格优于 R69。安全侧单调不降，效率侧获得构型维 resolution bonus。

**定理 19（重构安全与无突变）** 转换经 RSA（静止集、包络交集、载荷释放、目标前缀重认证、失败回滚）后，转换期间物理风险 ≤ ε_trans；快速环固定在 c 的最后认证前缀、任务动作只在静止集内冻结/恢复 ⇒ 控制连续无突变；重构只改变「用哪副身体测量、选哪个模态」，不绕过 R68 的 λ floor。重认证失败或 CCC 不通过时 λ 单调不降地退回 R69/R68。

## 7. 本轮最大风险

**一句话**：MORPH-RAS 把「不确定性消解」押在一条比 R69 更深的假设上——**系统可以自由选择测量自己的身体，而选择本身不会污染证据**。一旦构型选择以后验为条件，系统就能挑一个让偏爱假设「跨构型一致」的身体，把确认偏误伪装成验证：这不是「问错」，而是**用身体把错误答案证明成对的**；它比 R69 的幻觉追问更隐蔽，因为审计看到的是一致性，而不是矛盾。

**次级风险与缓解**：确认偏误/选择偏差（假设无关 maximin + PCL 预注册 + 独立留出构型 + VQAuditor-M；依赖 w 的选择直接判无效）；重构安全与突变（静止集/包络交集/载荷释放/目标重认证/失败回滚）；构型诱导的计量 aliasing（规范不变特征 + r_alias 对偶通道）；组合爆炸（深度 ≤1、maximin 剪枝、|C|≤8、Q≤6、离线缓存）；视觉对抗与谄媚回答（接地 + 反事实平衡 + 语用对称 + ℰ_vqa 对抗训练）；机构物理退化（构型条件标定 + E312 + 重构预算）。

**当前方案的最大风险一句话**：**当「换一个身体去问」本身可以以后验为条件时，跨构型一致性会被系统自己制造出来——MORPH-RAS 真正的敌人不是看不清楚，而是一个太会挑测量装置的自己。**
