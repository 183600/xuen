# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 1 轮；本轮灵感：「自监督学习」×「痛点分析」）

> 第 57 轮把"证据质量"从手工先验换成了跨区域摊销的元先验，并用 OOD 门 + 共形带兜底；但它在风险自陈里留下了两个更硬的经济学事实：**(a) 元语料本身是昂贵的**——它需要事后实测 θ̂_j 作为监督，而每区域只有 1~5 次实测机会，语料增长以"月"计，元先验永远追不上部署现场；**(b) 语料只包含"被人主动探过、且被正确标注"的世界**——最危险的不是语料里没有的材质，而是"系统自认为很熟、因而从不去探、也从不记录"的沉默区域。本轮两个灵感正是对这两点的回答：**自监督学习**让机器人用自身无标注的感知-动作流学表征与动作条件世界模型，把"部署即训练"变成不花钱的监督；**痛点分析**则回答"这些免费信号该信在哪、该补在哪"——不是从理论担忧出发加层，而是从真实失败/近失/接管事件出发，做根因分类与优先级排序。二者合流的关键判据是：**低惊讶 ≠ 低风险**；自监督最能压低的恰是"可预测但致命"的欺骗性表面，因此本轮把"自监督预测"与"痛点统计"的**不一致**定义为新的不确定性下限，并建立**沉默痛点黑名单**，在名单内禁用元先验、强制共形带或人审。核心命题由"少样本可校准、跨模态可对账、个性化有界的证据说可信"升级为 **"自监督读世界、痛点定审计的证据说可信"**——效率归自监督，信任的分配权归痛点。

核心矛盾：
- **H29（可预测性 vs 安全性）**：自监督目标最大化的是"可预测"，而欺骗性物理性质（透明冰面看起来干、踩上去硬）恰恰高度可预测；自监督会把最会骗人的区域学成"低惊讶、高置信"，把错误从"坏先验"升级为"自信的坏表征"。
- **H30（痛点 vs 可观测性）**：最痛的区域最稀少、最不愿被记录；而内生痛点标签只覆盖"系统已有的检测通道"——系统看不见的痛点永远不会产生事件，"无事件"被误读成"无痛点"，形成自我强化的盲区。
- **H31（持续自监督 vs 证书稳定）**：持续用部署流更新表征会让第 57 轮的校准证书、共形覆盖与 OOD 阈值逐渐失效；安全证书只能"重新挣得"，不能"随模型继承"，但重新认证本身消耗部署时间与探针预算。

## 0. 直觉与动机

**灵感 1（自监督学习 → 免费表征 + 动作条件惊讶，但绝不单独作证）**
直觉：第 57 轮的元先验像"用少量真题训练出的押题老师"，题贵且题库窄。自监督换一种供给：机器人每天都在产生大量**无标签**的感知-动作序列，时间顺序、模态之间、同一表面的跨到访重访，本身就是免费监督。用**动作条件预测编码** P_ψ(o_{t+1}|o_{≤t},a_t) 学一个世界模型，用**跨模态掩码重建**学 modality-invariant 表征，用**同表面跨到访不变性**学"什么该被记住、什么该被忽略"。它产出三样东西：区域上下文 z_r（替掉手工坡度/材质簇）、惊讶度 s_ssl（辅助异常信号）、以及一个**可坍缩审计**的表征（有效秩 + 线性探针）。但必须把话说死：**可预测性是"世界是否按我的模型运转"，不是"世界是否安全"**。因此 s_ssl 永远不能单独构成证据类，只能进入"更宽或更保守"的通道（A41）。

**灵感 2（痛点分析 → 内生免费标签 + 沉默痛点）**
直觉：过去几轮是"想一个威胁→加一层防御"，机制越叠越重，却没人核对**部署现场真正疼在哪**。痛点分析反过来做：先给整条栈装仪表（安全刹车、绕行、L2 超时、人工接管、事后证伪），这些**内生事件就是免费标签**——不需要额外交付实测，系统每保一次险就替我们标注了一次"这里可能疼"。再把事件按根因分类（感知/先验/时序/交互/执行）、按"频率×严重度×可探性"排序，得到**痛点图** π(r)。更关键的是承认选择偏差：内生事件只来自"系统已经会疼"的通道；用**第二通道（外部人审抽样）**做捕获-再捕获（capture–recapture），估计"两个通道都没抓到"的未观测痛点质量 N̂。定义**沉默痛点** S={π 高 ∧ s_ssl 低}∪{两通道估计明显不一致}：它可预测、因而自监督不报警，却在真实统计里持续致痛——这是本轮要专门关掉的那扇门。

**灵感 3（合流 → 新的不确定性下限：预测与痛点的分歧）**
直觉：第 57 轮用"跨模态分歧"当不确定性下限；本轮把同一招用在**监督来源**上：自监督代表"无标签、覆盖广、但只懂可预测性"，痛点统计代表"有标签、覆盖窄、但扎根真实后果"。二者一致时才敢信；二者分歧时（尤其"自监督说很稳、痛点说很疼"）就是**沉默痛点警报**。一句口号：**用自监督读遍世界，用痛点决定相信谁**。安全与效率由此解耦：自监督和痛点加权只改"探哪里、怎么分配预算、何时降档"，**不改任何证据门的准入门槛**（A43）；因此效率可以大幅提升，而单次承诺的失效界不被稀释。

**灵感 4（对第 57 轮的痛点拆解 → 本轮只加"分配层"，不加"安全层"）**

| 痛点 | 可测证据 | 根因（5-why 收敛） | 本轮对策 |
|---|---|---|---|
| P1 标注稀缺且贵 | 每区域事后实测 1~5 次，元语料月增 ~1% | 监督只来自显式实测 | SSL 表征 + 内生事件免费标签（IP-139/140） |
| P2 沉默痛点不可见 | 复盘中"未记录但危险"占比高 | 单一检测通道；可预测≠安全 | 沉默痛点注册表 + 捕获-再捕获（IP-140/141） |

**灵感 5（PCE++ → 痛点加权探询、沉默痛点否决、预警只减速）**
直觉：把 VOI 乘上痛点密度得到**痛点加权 VOI**——预算优先花在最疼、且探针可及的区域（"label where it hurts"）；沉默痛点区域**否决** EV-probe\* 的元先验通道，退回共形带或人审；痛点预测预文本只允许**单向减速**（高预警→降档/加宽/提前探，低预警绝不加速）；痛点漂移触发重校准与证书重认证，SSL 更新继续走影子隔离。所有新机制仍只经"信念更宽"或"动作更保守"两条通道起作用。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（自监督预文本世界模型 SSP）** 编码器 E_ψ:𝒪→𝒵，动作条件预测器 P_ψ(z_{t+1}|z_{≤t},a_t)。预文本集 𝒯={时序预测、跨模态掩码重建、同表面跨到访不变性}；总损失 ℒ_SSL=𝔼[−log P_ψ(o_{t+1}|o_{≤t},a_t)] + λ_m ℒ_mask + λ_i ℒ_inv。惊讶度 s_ssl(o_t|a_{<t})=−log P_ψ(o_t|o_{<t},a_{<t})。**表示证书** C_rep=(线性探针误差 ℓ_probe、有效秩 r_eff、跨域迁移降幅)；r_eff<ρ_eff 判表征坍缩，C_rep 不通过则 E_ψ 不得进入 z_r。硬约束：s_ssl **不是**证据类，禁止单独支撑任何承诺（A41）；它只能作为加宽/降档的输入。

**定义 140（内生痛点挖掘 PML）** 内生事件集 𝓔={safe_brake,reroute,L2_timeout,human_override,verdict_fail,near_miss_proxy}，每个事件 e 自带区域 r_e、类型 k_e∈𝒦={感知,先验,时序,交互,执行}、严重度 w_sev(e)。痛点图 π(r)=Σ_{e:r_e=r}w_sev(e)/max(1,T_r)，T_r 为到访次数（按到访归一，防止热门区域刷分）。选择偏差：内生通道 D1 只观测到"会触发事件"的痛点；引入外部人审抽样通道 D2，用 Chapman 捕获-再捕获估计总痛点 N̂_pain=(n1+1)(n2+1)/(m+1)−1（m 为两通道匹配数），并给出未观测痛点质量上界 U_pain。输出 (π, 𝒦 分布, N̂_pain, U_pain)。

**定义 141（自监督-痛点一致性 SPA 与沉默痛点注册表）** 记自监督风险代理 ρ_ssl(r)=Q_{1−q}({s_ssl})（高分位惊讶度），归一化后与 π(r) 比较。一致性间隙 Γ(r)=|norm(ρ_ssl(r))−norm(π(r))|。沉默痛点集 S(r)⇔[π(r)≥θ_pain ∧ ρ_ssl(r)≤θ_ssl] ∨ [Γ(r)>θ_gap]。注册表 S_reg 版本化、只增不减（除显式人审复核）。规则：r∈S_reg ⇒ **禁用 EV-probe\* 的元先验通道**，只能以共形带最坏值或人审佐证进入承诺；对 S_reg 区域增大探针配额 k_audit。**关键非对称**：低 s_ssl 永不降低要求，高 s_ssl 也不提升权限——SPA 是黑名单机制，不是白名单机制。

**定义 142（痛点加权 VOI PWV）** VOI_pain(π)=VOI_元悲观(π)·(1+κ·π̂(r))−cost(π)，κ≥0。PWV 只重排探针优先级与预算分配：所有证据类、阈值 θ_D/θ_voi/θ_K、隔离出口 corrob\*(auth) 与不可逆接触必要证据集**保持不变**（A43）。于是"痛点加权带来的效率提升"与"单次承诺的失效界"在形式上解耦。

**定义 143（痛点预测预文本 PFP 与反事实回放）** 预警预文本：从 z_{≤t} 预测"未来 Δ 步内是否发生 𝓔 事件"，得 a(r)∈[0,1]。使用规则**单向**：a(r)>θ_warn ⇒ 降档/加宽/提前探/增加佐证；a(r)≤θ_warn ⇒ 不改变任何参数（禁止加速）。反事实回放：在痛点事件样本处估计潜空间"痛点方向" v_pain=𝔼[z_after−z_before|e∈𝓔]，沿 v_pain 扰动生成合成近失样本，仅用于**离线压力测试**证据门与 PCE++（不回灌为在线安全证据）。

**定义 144（痛点漂移与持续自监督隔离 PDC）** 对 π、s_ssl、事件率做滑窗变化点检测（Page–Hinkley/CUSUM），检测到漂移 ⇒ 触发重校准、S_reg 复核、证书重认证。持续 SSL 更新走影子区：锚定回放缓冲防灾难遗忘，通过回归测试（线性探针不劣化 ∧ ECE 不升 ∧ OOD 检出率不降 ∧ 沉默痛点召回不降）后才接管判定；**证书不可继承**，新模型必须重新挣得 C_rep、ε_meta 与覆盖声明（A44）。漂移未检出概率记为 δ_drift。

def ssl_pretrain(stream, psi, buf):                  # IP-139: 部署即训练
    for (o_t, a_t, o_next) in stream:
        z = E_psi(o_t)
        loss  = nll(P_psi(z, a_t), o_next)           # 动作条件时序预测
        loss += mask_recon(o_t, mask=o_t.hidden_modality)
        loss += invariance(o_t, buf.same_surface(o_t.r))
        psi  = step(psi, loss)
    return psi, audit_representation(E_psi)          # C_rep: 探针/有效秩/坍缩

def ssl_infer(o_t, a_t, psi):
    z = E_psi(o_t); s = -log P_psi(o_t, z_prev, a_t)
    return z, s                                      # 仅辅助；A41 禁止单独作证

def pain_mine(log, audit_sample):                    # IP-140: 内生免费标签
    E1 = detected_events(log)                        # 刹车/绕行/超时/接管/证伪
    for e in E1:
        pain[e.r][e.k] += sev(e); pain.visits[e.r] += 1
    E2 = audit_sample.events                         # 通道2：外部人审抽样
    n1, n2, m = len(E1), len(E2), len(match(E1, E2))
    N_hat = (n1+1)*(n2+1)/(m+1) - 1                  # Chapman 捕获-再捕获
    return normalize(pain), N_hat, unseen_upper(n1, n2, m)

def spa_check(r, pain, ssl, theta):                  # IP-141: 沉默痛点黑名单
    pi = pain.rate(r); rho = ssl.high_quantile(r)
    if (pi >= theta.pain and rho <= theta.ssl) or \
       (abs(norm(pi) - norm(rho)) > theta.gap):
        S_reg.add(r, t_now)                          # 只增不减
        return 'silent_pain'                         # 禁用 meta prior
    return 'ok'

def pain_weighted_voi(q, M, r, inf):                 # IP-142: 只改分配
    return voi_meta_pessimistic(q, M, inf) * (1 + kappa * pain.rate(r)) - cost(q)

def pce_pp(x0, M, task, budget, consent, personas):  # IP-138→PCE++
    route = plan_on_map(M, task, risk_model)
    for cp in route.checkpoints:
        inf = meta_few_shot_infer(M, cp.region, M.obs[cp.region], meta)
        if spa_check(cp.region, pain, M.ssl, theta) == 'silent_pain':
            inf = Inf(cls='AUDIT', belt=conformal_belt(meta.res, ctx(cp), ALPHA))
        while select_gait(schedule_risk(foothold_schedule(x0, cp, M), M)) == 'halt' \
              and budget.probes_left > 0:
            cands = admissible_probes(cp, M, F_abs)
            p = argmax(cands, key=lambda q: pain_weighted_voi(q, M, cp.region, inf))
            if pain_weighted_voi(p, M, cp.region, inf) < theta_voi: break
            M, _, D = xmodal_fuse(M, cp.region, execute_probe(p, cap=F_abs))
            budget.spend(p)
        g = select_gait(schedule_risk(foothold_schedule(x0, cp, M), M))
        if pain_forecast(cp, M) > theta_warn:        # IP-143: 单向减速
            g = downshift(g)                         # 只降不升
        if g != 'halt' and few_shot_evidence_gate(core_contact(cp), M, personas,
                                                  ood_reg, S_reg)[0] == 'ok':
            commit(cp, g); continue
        return reroute_or_negotiate(cp, M, consent, tau_int=tau_int(personas.active))
    return done

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| SSP | 训练摊销；推理 O(d_ψ)/帧 | O(\|ψ\|+\|𝒟_ssl\|) | 表征坍缩审计 C_rep；s_ssl 不作证据（A41） |
| PML | O(\|𝓔\|) 每次回放；估计 O(\|𝓔\|log\|𝓔\|) | O(\|V\|·\|𝒦\|) | 捕获-再捕获无偏性条件（通道独立）+ U_pain |
| SPA | O(1)/区域 | O(\|V\|) | 黑名单只增；低惊讶不放松要求 |
| PWV | 同 VOI + O(1) | O(1) | 只重排预算、阈值不变（A43） |
| PFP | O(d_ψ)/帧 | O(\|ψ\|) | 单向：只降档/加宽 |
| PDC | O(\|W\|) 滑窗 | O(\|𝓔\|+\|ψ\|) | 漂移→重认证；证书不继承（A44） |

**正确性定理（Self-supervised Pain-grounded Soundness, SPS）编号改为 SPGS**：在 A33–A40 之上加 **(A41)** s_ssl 仅作辅助表示/惊讶信号，任何承诺不得以 s_ssl 为必要或充分证据；**(A42)** 内生痛点标签存在选择偏差但可由第二通道估计，沉默痛点被 S_reg 以覆盖 ≥1−β_audit 的外部复核捕获；**(A43)** 痛点加权只重排预算，所有证据门与阈值不变；**(A44)** 持续 SSL 更新走影子隔离、证书重挣得、漂移可检测（漏检 ≤δ_drift）。则：

1. **健全性**：与原 CCPS 界相比，新增项仅 β_silent（两通道都未捕获的痛点质量，按 U_pain 上界）与 δ_drift；在 S_reg 区域内 EV-probe\* 被禁用，故该区域不再贡献 ε_meta(k)，只贡献最小共形覆盖 α_conf 或人审误差 ε_h。
2. **效率-安全解耦**：固定证据类与阈值时，PWV 只改变探针的期望分配，不改变单次承诺的失效上界；因此 E177–E179 的效率提升可以在不放松保证的前提下取得。
3. **单调性**：SSP/PML/SPA/PFP/PDC 只能经 (a) 表征更准或更宽、(b) 动作更保守（降档、加宽、增佐证、禁用元先验）影响系统；低惊讶、低痛点、低预警都不提供任何"放宽"路径。
4. **终止性**：继承 PCE+ 的每检查点 k_probes+k_cons 预算；SSP/SPA 推理为常数级或前向 O(d_ψ)，不引入新的无界循环。

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k)·1[r∉S_reg] + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1])
             − β_silent − δ_drift − P(𝓜 陈旧未检出) − P(护盾回退失败)
```

**关键取舍**：自监督给"广度与便宜"，痛点分析给"可信的靶点"，二者都不直接给安全——安全仍由第 56/57 轮的证据门与共形保底承担；本轮新增的风险项（沉默痛点、漂移）被显式写进界里，而不是被新机制的乐观叙事掩盖。

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SSP | 训练摊销；推理 O(d_ψ)/帧 | O(\|ψ\|+\|𝒟_ssl\|) | 坍缩审计 C_rep；s_ssl 不作证据（A41） |
| PML | O(\|𝓔\|) 回放；O(\|𝓔\|log\|𝓔\|) 估计 | O(\|V\|·\|𝒦\|) | 双通道独立假设 + U_pain 上界（A42） |
| SPA | O(1)/区域 | O(\|V\|) | 黑名单只增；低惊讶不放松（A41/A42） |
| PWV | O(1)+VOI | O(1) | 只重排预算、阈值不变（A43） |
| PFP | O(d_ψ)/帧 | O(\|ψ\|) | 单向：只降档/加宽（A43） |
| PDC | O(\|W\|) 滑窗 | O(\|𝓔\|+\|ψ\|) | 漂移→重认证；证书不继承（A44） |
| PCE++ | 同 PCE+ + O(1)/帧 | O(\|V\|+\|σ\|) | k_probes+k_cons 终止、四态完备 |

**正确性定理（Self-supervised Pain-grounded Soundness, SPGS）**
假设 A22–A32（第 53–55 轮）、A33–A36（第 56 轮）、A37–A40（第 57 轮）成立；并加 **(A41)** 自监督惊讶度 s_ssl 仅作辅助信号，不得单独构成任何证据类；**(A42)** 内生痛点标签存在选择偏差，但由独立第二通道捕获-再捕获估计、未观测痛点质量以 U_pain 为上界，沉默痛点由外部复核覆盖 ≥1−β_audit；**(A43)** 痛点加权/预警/漂移机制只改变探针分配与动作保守度，不改变任何证据门、阈值与隔离出口；**(A44)** 持续 SSL 更新走影子隔离、回归测试通过才接管、证书必须重挣得、漂移漏检率 ≤δ_drift。则：

1. **健全性（相对原 CCPS 界）**：新增仅 β_silent 与 δ_drift 两项；在 r∈S_reg 上 EV-probe\* 的元先验分支被否决，故该区域不再贡献 ε_meta(k)，只贡献最小共形覆盖 α_conf 或人审误差 ε_h。
2. **效率-安全解耦**：固定证据类与阈值，PWV 只重排探针期望分配；E177–E179 的效率收益不改变单次承诺的失效上界。
3. **单调性**：SSP/PML/SPA/PFP/PDC 只能经 (a) 表征更准或更宽、(b) 动作更保守（降档/加宽/增佐证/禁用元先验）影响系统；低惊讶、低痛点、低预警均无"放宽"路径；PFP 显式禁止加速。
4. **终止性**：每检查点仍受 k_probes+k_cons 预算约束；SSP/SPA 为常数或前向 O(d_ψ)，不引入无界循环。
5. **部署界**：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k)·1[r∉S_reg] + δ_probe + ε_h
                   + δ_ood·α_conf + δ_xm·1[L1])
             − β_silent − δ_drift
             − P(𝓜 陈旧未检出) − P(护盾回退失败) − P(τ_int ∧ τ_mm 超时 ∧ 安全停失效)
```

**关键结论**：自监督提供广度与低成本、痛点分析提供可信靶点与免费标签，但**两者都不直接提供安全**；安全仍由证据门 + 共形保底承担。把"沉默痛点"与"漂移"显式写进界里，是本轮相对第 57 轮最重要的诚实性改进。
