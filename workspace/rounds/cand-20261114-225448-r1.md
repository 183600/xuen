# 第 3 轮（灵感循环第 3 轮；本轮灵感：「推理延迟」×「上下文理解」）

> **基线继承**：第 2 轮 **ToolGauge**（IP-315–320；定义 416–431；引理 46–50；实验 E426–E440）。
> 本轮纪律：**继续在前人基础上改进，而不是推倒重来**——ToolGauge 已把探测动作契约化、把先验质量可审计化、
> 把 VLA 降格为被审计角色。但其全部安全结论仍压在一个未言明的**「实验室时空」假设**上：
> 证据一旦 `valid` 就永远、处处有效。真实的 50Hz 具身系统里，证据同时受两条轴约束：
> **时间轴（推理/探测在决策截止前能否给出可用后验）** 与 **上下文轴（证据在采集它的场景包络内才可复用）**。
> 第 3 轮把这两条轴显式化，升级为 **KairosGauge**（καιρός：恰当时机 × 恰当情境），
> 并把 ToolGauge 作为「瞬时、单一上下文」的严格退化特例完整保留。

## 双轴映射（升级而非重写）

| 灵感词 | 第 2 轮对象 | 升级为 | 一句话动机 |
|---|---|---|---|
| 推理延迟 | T-Box 无 deadline 的异步探测；AP-Cal「单前向」后验 | **La-Box + DDL-Sched**：任意时刻有效后验 + 截止期调度 + 延迟致弃权 | 决策截止后才到的证据不是「慢证据」，而是**无效证据**；静默沿用旧值比弃权更危险 |
| 上下文理解 | L-Box 按盲区 s 提假设；P-Quarantine 全局残差序列 | **C-Box + CEL**：上下文包络/指纹、上下文条件共形、上下文证据账本、混淆与新颖性检测 | 「同一盲区」不等于「同一上下文」；回执只在采集它的上下文包络内有效，跨上下文复用必须显式付「上下文税」 |

**核心命题**：把 ToolGauge 的 `valid(r)`（格式/签名有效）升级为**情境化有效性**
`valid_use(r, c, t) ⇔ 上下文匹配 ∧ 新鲜度达标 ∧ 截止期内可认证`；
把 6C 升级为 **DDL-6C**（带看门狗与弃权），新增 **La-Box（时间轴）** 与 **C-Box（上下文轴）**。
一句话：**证据的正确性从「是不是真的」升级为「在此刻、在此地、是否还来得及」**。

**不变式保持声明**：
- MODGAUGE 五不变式 + 第 2 轮语言扩展全部保留；
- 新增「**情境完备性**」（主张绑定的强化）：任何进入 EC 的数值主张必须携带
  `(receipt_id, φ_r, ts_r, h_r, deadline_slack)`；缺失或不满足 `valid_use` 的证据不得支撑热替换——
  这是**纯元数据**扩展，不改变任何数值语义；
- **严格退化链延长**：KairosGauge 失效（截止期不可达 / 上下文 UNVERIFIED / 账本不一致）
  ⇒ 冻结在最后认证 EC 并退回 ToolGauge 单机 ⇒ 再退回 LeanGauge 数值探测 ⇒ 再退回 MODGAUGE。

## 0. 直觉与动机

### 灵感 1（推理延迟 → 迟到的证据是无效证据，不是慢证据）
直觉：控制回路在 20ms 内要动作，而一个盲区修复可能耗时 0.2–0.8s（VLA 前向）到数秒（物理探测）。
ToolGauge 引理 50 已经把修复放到异步路径，却只证明了「平均时延 ≤ τ_repair」——
它没有回答：**在等待期间，系统该用什么？** 现实中最常见的实现是「继续用上一个后验」，
于是系统用**旧世界**的后验去解释**新观测**，并且因为它是「已经 valid 的回执」，审计上无懈可击。
三个升级：
(a) **任意时刻后验**：把 AP-Cal 从「一次前向一次性输出」改为产出一条**置信序列 / e-process**——
在每个计算检查点都能给出在该时刻有效的后验；提前退出条件为「半宽 ≤ ε 或到达 deadline」。
可选停止（optional stopping）不再破坏覆盖率，因为对象从「一次性 CI」换成了 anytime-valid 对象。
(b) **延迟进规划**：TCV 目前的预算是「代价 Σc_t ≤ B_tools」，没有时间维度。升级为
「时间 × 代价」二维可行性，并把信息增益按**截止期折扣**：来不及完成的探测，增益为 0。
(c) **延迟致弃权**：若在 τ_s 前无法达到 ε-精度，显式进入 `SAFE_HOLD`（stub + RED + 排队），
而不是悄悄用旧后验。**弃权是安全侧动作**，静默陈旧不是。

### 灵感 2（上下文理解 → 证据有坐标，不是标量）
直觉：R2 的格子 `s=(d,m,i)` 只标记「哪个深度/材质/光照组合没验证」，但**没有记录证据是在什么工况下采的**。
同一格子在 5°C 与 45°C、静态与 1.5m/s 运动、洁净与油污镜头下，是完全不同的测量问题。
更危险的是统计上的「边际掩盖」：全局共形覆盖 0.92 可以漂亮地达标，而高风险的高温/高反光桶内覆盖只有 0.6。
四个升级：
(a) **显式上下文代数**：上下文变量、偏序、包络半径、距离度量与指纹；
(b) **上下文条件共形（C3）**：分层部分池化，保证**逐桶**覆盖，而不是只保证边际覆盖；
(c) **上下文证据账本（CEL）**：每条回执带 `φ_r` 与新鲜度；跨上下文复用要付方差税
`L_C²·d_C²`，超过 ε 预算就重探；
(d) **上下文混淆检测**：系统必须先知道自己**处在哪个上下文**；混淆风险高或遇到未见上下文时，
`CONTEXT_UNVERIFIED` ⇒ 不跨上下文复用，必要时**主动做上下文探测**（变光/敲击/多视本身就是测量）。
这条轴同时正面回答第 2 轮最大风险：AP-Cal 的「跨盲区相关偏差」本质上是**上下文偏移**，
只是 R2 用一个全局 P-Quarantine 去监控它，会被不同上下文的相反偏差互相抵消（Simpson 式掩盖）。

### 灵感 3（交叉：时效上下文 → 最坏的不是慢或错，而是「快且自信地错」）
直觉：时间轴与上下文轴不是可加的，它们会**相乘地放大**失效：
上下文估计器把 c′ 误判为 c（置信度高），账本于是允许复用 c 下的旧证据（新鲜度模型低估漂移），
任意时刻后验又在 deadline 压力下**提前退出**，给出一个很窄的后验。
结果：错误答案不仅错，而且**以高置信度、在截止期之前**到达，抢在不确定性能触发弃权之前完成热替换。
反过来，单纯慢或单纯上下文不确定都还能被「弃权」兜住。因此本轮的核心安全对象不是精度，而是
**认证决策（certified decision）**：`上下文 LIVE ∧ 证据 FRESH ∧ 后验按时达到 ε ∧ 混淆风险 ≤ κ_max`
四者同时成立才允许热替换；否则弃权。这给出一个可审计的、词典序的安全目标：
**安全约束优先，认证吞吐次之**。

## 1. 形式化定义（增量：定义 432–447）

**定义 432（上下文空间、指纹与包络）**
上下文 `c = (c_scene, c_mat, c_light, c_therm, c_motion, c_health, c_task) ∈ C`，
`C` 配偏序 `⊑` 与度量 `d_C`；包络 `E_ρ(c) = {c′ : d_C(c,c′) ≤ ρ_C}`。
指纹 `φ(c) ∈ {0,1}^k` 为离散化/学习嵌入的粗粒度索引（用于账本分桶），
细粒度匹配用 `d_C`。上下文不确定性用可信集 `Ĉ_t ⊆ C` 表示。

**定义 433（情境化证据与四态）** 回执扩展为
`r = (t, args, obs=(μ,σ_decl), sig, ts, seq, φ_r, c_r, h_r)`，其中 `h_r` 为新鲜度视界（定义 434）。
对一次「证据使用」`(r, c, t)`：
`valid_use(r,c,t) ⇔ valid(r) ∧ d_C(c_r,c) ≤ ρ_C ∧ t − ts_r ≤ h_r(ε_s)`。
四态：`LIVE`（全部满足）、`FOREIGN`（`d_C > ρ_C`）、`STALE`（超视界）、`VOID`（签名/schema 失败）。
**只有 LIVE 证据可进入校准样本集与热替换**；`STALE/FOREIGN` 永不静默降级使用。

**定义 434（漂移模型与新鲜度视界）** 设参数随时间的漂移为
`u_{t+Δ} = u_t + w_Δ`，`w_Δ ~ N(νΔ, ρ²Δ)`（ν 为系统偏差率，ρ 为扩散率）。用证据 `r` 在时刻 `t` 预测的
`(1−α)` 半宽为
`H_r(Δ) = z_{1−α/2}·√(σ_r² + ρ²Δ) + νΔ`。
新鲜度视界 `h_r(ε) = min{Δ ≥ 0 : H_r(Δ) ≤ ε}`；`ν=0` 时闭式
`h_r = ((ε/z_{1−α/2})² − σ_r²)_+ / ρ²`（与第 2 轮定义 426 同构：**样本效率 ↔ 时间效率**）；
`ν>0` 时解二次方程 `z²(σ_r²+ρ²h) = (ε−νh)²`，取 `[0, ε/ν)` 内根。
若 `ν ≥ ε/Δt_min`（漂移偏差本身已吃掉整份误差预算）⇒ `h_r = 0`，证据**一秒都不可复用**。

**定义 435（延迟契约与任意时刻后验）** 盲区 `s` 的决策截止期 `τ_s`（由控制回路与 IV/TB-Contract 继承）；
各阶段时延预算 `Σ_i τ_i ≤ τ_s − τ_m`。AP-Cal 升级为**任意时刻后验**
`q^{(j)} = (μ^{(j)}, Σ^{(j)})`，`j` 为计算检查点，满足：
对任意停时 `T ≤ τ_s`，`P(u* ∈ CS_α(q^{(T)})) ≥ 1−α−δ_cs`。
「可用」判据：`λ_max(Σ^{(j)}) ≤ ε_s²` 且 `elapsed_j ≤ τ_s`。
**延迟致弃权集** `A_s = {τ_s < inf{j : λ_max(Σ^{(j)}) ≤ ε_s²}}`；落此集合即 `SAFE_HOLD`，禁止热替换。

**定义 436（上下文条件共形 C3 与分层池化）** 对上下文桶 `b = φ(c)` 维护校准集 `C_cal^b`；
分位数 `τ_h^b` 由桶内经验分位与父桶分位按 `C_cal^b` 大小收缩得到（部分池化）。
保证 `P(h* ∈ H_s | c ∈ b) ≥ 1−α − δ_b`，`δ_b = δ_pool(b) + L_C·ρ_b`，
`δ_pool(b)` 为桶内有限样本覆盖缺口，`ρ_b` 为桶包络半径。
运行期监控**上下文覆盖缺口** `gap = max_b[(1−α) − \hat{cov}_b]`；`gap > δ_cov` ⇒ 该桶降级为 UNKNOWN。

**定义 437（上下文证据账本 CEL）** 只追加账本
`CEL[(φ_r, s)] → {r}`，记录 `(c_r, ts_r, h_r, ε_s, lineage)`。
`query_live(s,c,t,ε)` 只返回 `valid_use` 的回执；
账本强制**证据血缘**（哪次探测、哪个上下文、何时），供 V 阶段与审计使用。
跨桶导入必须显式标注并计上下文税（定义 438），禁止隐式复用。

**定义 438（上下文税与复用判据）** 设参数对上下文的 Lipschitz 常数 `L_C`：
`‖u*(c) − u*(c′)‖ ≤ L_C·d_C(c,c′)`。把 `c_r` 的证据复用到 `c` 的预测半宽为
`H_reuse = z·√(σ_r² + L_C²·d_C(c_r,c)² + ρ²Δt) + νΔt`。
**复用判据**：`H_reuse ≤ ε_s` 才可复用；否则重探。
**上下文税**定义为方差增量 `L_C²·d_C²`——它是「跨上下文借用经验」的显式价格，而不是隐藏偏差。

**定义 439（上下文混淆与新颖性）** 上下文估计器输出可信集 `Ĉ_t`；
混淆风险 `κ_t = P(c* ∉ Ĉ_t | 观测)`；新颖性 `novel(c) ⇔ min_{c_cal} d_C(c,c_cal) > ρ_new`。
策略：`κ_t > κ_max` 或 `novel` ⇒ `CONTEXT_UNVERIFIED`（不跨上下文复用、只用保守物理先验、
降低探测幅值）；上下文层因此是**安全侧单调**的。

**定义 440（主动上下文探测）** 上下文本身是可测量量：允许调用
`ctx.probe ∈ {illum.dither, tap.percuss, stereo.parallax, thermal.ramp}` 以降低 `κ_t`。
其收益为混淆熵下降 `ΔH(Ĉ_t)`，与定义 419 的增益注合并：
`β_ctx = ΔH(Ĉ_t) − c_t`；与参数探测共享同一预算与截止期。

**定义 441（DDL-Sched 延迟感知调度）** 给定 `H_s`、工具库 `T₀`、截止期 `τ_s`、代价预算 `B_tools`，
选择程序 `Π` 与计算分配 `n`：
`max_{Π,n} E[Ĝ(Π,n)]·P(finish(Π,n) ≤ τ_s) − c(Π,n)`
`s.t. Σ τ_tool + τ_compute(n) ≤ τ_s − τ_m`，`Σ c_t ≤ B_tools`，且存在检查点满足 `λ_max(Σ) ≤ ε_s²`。
来不及的探测按截止期折扣视为**零增益**（不是负增益，也不是免费）。

**定义 442（DDL-6C 闭环与看门狗）** `H→C→E→C→V→U` 每段带看门狗与情境检查：
1. H：C-Box 估计 `Ĉ_t`；`κ_t > κ_max` ⇒ `SAFE_HOLD`；否则 L-Box 在 `φ(c)` 桶内做 C3 假设；
2. C：DDL-Sched 编译 `Π`，TCV 增加**时间可行性**检查（`finish ≤ τ_s`）；
3. E：执行时逐条检查 `valid_use`；超时立即中止（前缀完成态，零副作用）；
4. C：AnytimeAPCal 在截止期内输出可用后验，否则弃权；
5. V：交叉验证必须同时是**时间留出**（未参与拟合的更新时刻回执）与**上下文留出**
   （`d_C > ρ_C` 的独立回执，或明确标注为同上下文则降级为时间留出）；再跑契约回归；
6. U：仅当 `LIVE ∧ 按时 ∧ 覆盖达标 ∧ 回归通过` 才热替换；写 TCR（定义 445）与上下文分桶的 P-Quarantine。
任一阶段看门狗超时 ⇒ `SAFE_HOLD`，不产生部分热替换。

**定义 443（认证决策与弃权）** 一次热替换是**认证的**当且仅当
`LIVE ∧ FRESH ∧ on-time ∧ gap_b ≤ δ_cov ∧ κ_t ≤ κ_max`。
否则系统执行**弃权**：`stub + RED + 排队`，并保持最后认证 EC 不变。
联合风险 `R_TC = P(使用非 LIVE 证据 ∨ 超截止 ∨ 上下文覆盖缺口超标 ∨ 混淆风险超标)`；
目标是 `R_TC ≤ δ_total`，且弃权不劣于「用无效证据行动」（安全支配，引理 55）。

**定义 444（可信时间戳与新鲜度证明）** `ts` 由单调安全时钟签发，`sig` 覆盖 `(ts, seq, φ_r, payload)`；
`seq` 单调 + nonce 防重放；漂移率 `ρ,ν` 的在线估计进入账本。
冻结时钟、回放旧包、跨设备克隆 `seq` 一律判 `VOID`（不可用时钟比坏时钟更危险）。

**定义 445（时效上下文修复证书 TCR）** `TCR(s) = (H_s, Π_s, receipts, φ_r, h_r, deadline_slack, compute_trace, 文字解说)`，
绑定进 `EC.claims`；每个数值必须引用 `LIVE` 回执，`deadline_slack = τ_s − elapsed` 必须可复算。
证书同时服务人工审计与事故复盘（E456）。

**定义 446（严格退化链延长）** 状态机：
`NOMINAL → LATENCY_DEGRADED`（丢弃慢工具/VLA，走数值路径）
`→ CONTEXT_UNVERIFIED`（冻结 EC，保守先验，可主动上下文探测）
`→ ToolGauge`（单上下文、无截止期约束的原闭环）
`→ LeanGauge → MODGAUGE`。每级只允许更保守，不允许更激进（安全侧单调）。

**定义 447（继承与退化特例）** 取 `C={c₀}`、`ρ=ν=0`、`τ_s=∞`、`κ_max=1`、`L_C=0`、
C3→边际共形、AnytimeAPCal→单次 AP-Cal，则 **KairosGauge ≡ ToolGauge**；
再取 VLA=∅、T₀={被动观测} 则 → LeanGauge；再退化 → MODGAUGE。

## 2. 关键算法骨架

```python
# IP-321 C-Box：上下文估计、指纹、混淆/新颖性
class CBox:
    def infer(self, num_feats):
        c_hat, cred = self.ctx_model(num_feats)      # 白名单数值输入（定义 429 继承）
        return c_hat, self.confusion(cred), self.novelty(c_hat)

# IP-322 CEL：情境化证据账本 + 复用门
class CEL:
    def __init__(self): self.ledger = defaultdict(list)
    def add(self, r): self.ledger[(r.phi, r.s)].append(r)
    def live(self, s, c, t, eps, L_C, rho, nu):
        for r in self.ledger.get((phi(c), s), ()):
            if valid(r) and dC(r.c, c) <= RHO_C and reuse_ok(r, c, t, eps, L_C, rho, nu):
                yield r           # 只有 LIVE 才进入校准

# IP-323 La-Box：任意时刻后验 + 延迟致弃权
class AnytimeAPCal:
    def posterior(self, ctx, tau_s, eps):
        for j in self.checkpoints(ctx):
            mu, Sig = self.mp_phi.partial(ctx, j)
            if lam_max(Sig) <= eps**2: return Usable(mu, Sig, j)   # 提前退出
            if elapsed() > tau_s - TAU_M: break
        return Abstain("deadline")                                 # 禁止静默使用旧后验

# IP-324 DDL-Sched：截止期感知的探测/上下文探测调度
def ddl_schedule(H, tools, tau_s, B, rho, nu):
    cand = [c for c in tools if feasible_time(c, tau_s) and c.cost <= B]
    # 单调次模的信息增益 + 二维预算：部分枚举贪心（单预算时 1-1/e）
    return greedy_enumerate(cand, key=lambda c: gain(c)*on_time_prob(c, rho, nu))

# IP-325 DDL-6C 闭环
def kairos_6c(M, s):
    c_hat, kappa, novel = M.cbox.infer(featurize_num(s, M.dbox.R[s]))
    if kappa > KMAX or novel:
        return safe_hold(s, "context_unverified")            # 定义 439/446
    H = M.lbox.hypothesize(s, M.dbox.R[s], bucket=phi(c_hat)) # C3（定义 436）
    prog = M.sched.plan(H, M.tau(s), M.budget_left(s))        # 定义 441
    receipts = M.tcv.execute_with_watchdog(prog, M.env, M.tau(s) - TAU_M)
    live = [r for r in receipts if M.cel.live_one(r, c_hat, now(), M.eps(s))]
    if len(live) < M.n_min(s): return stub_and_red(s, "insufficient_live")
    r = M.apcal.posterior(featurize_ctx(live, H, c_hat), M.tau(s), M.eps(s))
    if isinstance(r, Abstain): return safe_hold(s, "latency")      # 定义 435
    if not M.apcal.cross_validate(r, M.cross_receipt(s, c_hat)):  # 时间+上下文留出
        return stub_and_red(s, "cross_context_failed")
    new_ec = M.apcal.update_contract(M.dpe, r.mu, r.Sig, s)
    if not contract_regression(new_ec): return stub_and_red(s, "regression")
    M.mreg.hot_replace(M.dpe, new_ec)
    bind_tcr(new_ec, H, prog, live, c_hat, M.tau(s))              # 定义 445
    M.pquar.record_by_context(phi(c_hat), M.apcal.last_gain, realized_gain(live))
    return True

# IP-326 主闭环：50Hz 路径只加 O(1) 情境标签与新鲜度检查
def KairosGauge_round(M, obs, audio, tac, depth, det):
    M.cel.ingest(M.passive_receipts(obs, audio, tac, depth, det))  # 带 ts/φ 入账
    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight and M.deadline_ok(s):
            M.inflight.add(s); submit_async(kairos_6c, M, s)
    return MODGAUGE_round(M, obs, audio, tac, depth, det)
```

## 3. 推导（引理 51–56 + 定理 3）

**引理 51（任意停止下的后验有效性）**
若 `q^{(j)}` 由在线混合构造的置信序列给出（如 `μ^{(j)} ± b·√(2 log log(2j/δ)/j)` 型或 e-process），
则对任意 `T ≤ τ_s`（可依赖历史与计算进度）有 `P(u* ∈ CS_α(q^{(T)})) ≥ 1−α−δ_cs`。
证明思路：混合鞅在可选停止下仍是鞅，Ville 不等式给出任意停时的第一类错误控制；
截止期截断只是把停时限制在 `[0,τ_s]`，不破坏上界。系：提前退出不会因「反复偷看」而系统性放宽后验。

**引理 52（新鲜度-漂移覆盖界）**
在定义 434 的漂移模型下，对任意 `Δ = t−ts_r`，
`P(|u*_t − μ_r| ≤ H_r(Δ)) ≥ 1−α`；因此若 `Δ ≤ h_r(ε_s)` 则证据在 `ε_s` 精度内仍可信。
若强行使用 `Δ > h_r(ε_s)` 的旧证据，超额误差下界为 `H_r(Δ) − ε_s ≥ 0`，且随 `Δ` 单调增长。
证明：随机游走 + 偏差的方差可加，正态分位；`H_r` 关于 `Δ` 单调不减故视界良定义。
系：**「新鲜度」不是工程启发式，而是由 `(ρ,ν,σ_r,ε)` 唯一决定的闭式量**。

**引理 53（上下文迁移误差界）**
若 `‖u*(c)−u*(c′)‖ ≤ L_C d_C(c,c′)`，则把 `c′` 的证据用于 `c` 的后验满足
`E‖u*(c) − μ_{c′}‖² ≤ σ_{c′}² + L_C² d_C(c,c′)²`。
故只要 `z√(σ² + L_C²d_C² + ρ²Δ) + νΔ ≤ ε`，跨上下文复用就是 `ε`-安全的；
上下文税 `L_C²d_C²` 是**可加、可审计、可拒绝**的显式项。证明：三角不等式 + Lipschitz + 独立噪声。

**引理 54（上下文条件共形覆盖）**
对每个桶 `b`，若校准与部署在桶内可交换，则 `P(h*∈H_s | b) ≥ 1−α`；
有限样本下以 `1−δ` 概率有 `|\hat{cov}_b − (1−α)| ≤ √(log(2|B|/δ)/(2n_b))`（对 `|B|` 个桶取联合界）。
若 `n_b` 过小，部分池化把父桶分位作为先验，代价是额外的 `δ_pool(b)`。
系：**边际覆盖达标不蕴含桶内覆盖达标**；运行期监控 `max_b gap`，超标即退化为 UNKNOWN。

**引理 55（弃权的安全支配与联合风险上界）**
设「用非 LIVE 证据热替换」的最坏损失为 `ℓ_bad`，「弃权」的损失为 `ℓ_hold`，且系统保证
`ℓ_hold ≤ ℓ_bad`（冻结认证 EC 不会比错误替换更差）。则对任一策略，
`E[loss] ≤ ℓ_hold + ℓ_bad·R_TC`，其中
`R_TC ≤ P(STALE) + P(FOREIGN) + P(deadline miss) + P(gap>δ_cov) + P(κ>κ_max)`（联合界）。
证明：把失败事件并起来，在失败外系统等价于安全策略；失败内损失至多 `ℓ_bad`。
系：**提高弃权率只会把损失推向 `ℓ_hold`，不会制造新的更坏分支**——这就是「安全侧单调」。

**引理 56（延迟感知调度的可行性与时序保持）**
(a) 若信息增益 `Ĝ` 单调次模、时间按单位槽离散、且只有截止期一个预算，部分枚举贪心达到 `(1−1/e)` 最优；
(b) 双预算（时间 + 代价）时用二维枚举贪心，得到常数因子近似（本文按 E454 实测其常数），
且任何被调度项满足 `finish ≤ τ_s`；(c) 50Hz 路径新增开销为 `O(1)` 的指纹/新鲜度检查（<0.3ms/周期），
修复事件仍在 50Hz 外，`P99` 修复时延由看门狗硬性截断在 `τ_s`。
证明：(a) 次模 + 背包的标准部分枚举；(c) 看门狗把「平均界」升级为「最坏界」。

**定理 3（时效上下文认证安全）** 若 (i) 定义 435 的任意时刻后验以 `δ_cs` 满足可选停止有效性；
(ii) 定义 436 的 C3 以 `δ_cov` 满足逐桶覆盖；(iii) 定义 439 的混淆风险被门控在 `κ_max`；
(iv) 定义 437/438 只允许 LIVE 证据进入校准；则在真实上下文 `c*` 下，任一被认证的热替换满足
`P(后验半宽 ≤ ε ∧ 覆盖 ≥ 1−α) ≥ 1 − δ_cs − δ_cov − κ_max`，
且未认证时系统**弃权而非替换**。故 `R_TC ≤ δ_cs + δ_cov + κ_max + P(deadline miss)`。
证明：失败事件取并；认证分支四条件同时成立；非认证分支由定义 442/443 强制 `SAFE_HOLD`，
由引理 55 不会引入比弃权更坏的损失。

## 6. 本轮最大风险（一句话）

**一句话**：**上下文混淆与任意时刻提前退出会相乘放大**——系统在真实上下文 `c′` 中被高置信地误判为 `c`，
账本于是允许复用 `c` 下仍在「新鲜度视界」内的旧证据，AnytimeAPCal 又在 deadline 压力下提前收窄后验，
使一个**快、窄、且自信地错误**的结论在弃权机制触发之前完成热替换——这是比第 2 轮「慢而相关的偏差」更危险的
「快且自信的错误」，因为延迟优化本身把发现错误的时间窗口也一起压缩了。

**次级风险与缓解**：
1. **上下文桶稀疏** → 分层池化 + 上下文税 + `gap` 监控；不足即 UNKNOWN（引理 54）；
2. **上下文估计器被欺骗**（对抗纹理/照明诱导误判）→ 新颖性检测 + 主动上下文探测 + 数值白名单（定义 429/439/440）；
3. **时钟/新鲜度攻击**（冻结时钟、回放）→ 签名单调时钟 + nonce + 账本血缘（定义 444）；
4. **任意时刻有效性的模型误设** → 校准审计 + `δ_cs` 计入 `R_TC`，并在 E441 做可选停止压力测试；
5. **过度弃权导致可用性下降** → 词典序指标 + 认证吞吐监控（E442/E454），弃权不是免费的；
6. **上下文税过保守导致修复停滞** → 自适应重探 + 税后收益比较（定义 438/441）；
7. **看门狗与物理探测冲突** → PROBING 显式态 + 力矩硬限 + 前缀完成态（继承定义 430）。

## 3. 关键算法骨架

```python
# IP-321 C-Box：上下文 + 混淆/新颖性
class CBox:
    def infer(self, num_feats):
        c_hat, cred = self.ctx_model(num_feats)          # 仅白名单数值输入
        return c_hat, self.confusion(cred), self.novelty(c_hat)

# IP-322 CEL：情境化证据账本（只有 LIVE 可入校准）
class CEL:
    def __init__(self): self.ledger = defaultdict(list)
    def add(self, r): self.ledger[(r.phi, r.s)].append(r)
    def live(self, s, c, t, eps, L_C, rho, nu):
        return [r for r in self.ledger.get((phi(c), s), ())
                if valid(r) and dC(r.c, c) <= RHO_C
                and z*sqrt(r.var + L_C**2*dC(r.c, c)**2 + rho**2*(t-r.ts)) + nu*(t-r.ts) <= eps]

# IP-323 La-Box：任意时刻后验，提前退出 / 截止弃权
class AnytimeAPCal:
    def posterior(self, ctx, tau_s, eps):
        for j in self.checkpoints(ctx):
            mu, Sig = self.mp_phi.partial(ctx, j)
            if lam_max(Sig) <= eps**2: return Usable(mu, Sig, j)
            if elapsed() > tau_s - TAU_M: break
        return Abstain("deadline")                        # 不静默使用旧后验

# IP-324 DDL-Sched：时间×代价二维调度
def ddl_schedule(H, tools, tau_s, B, rho, nu):
    cand = [c for c in tools if feasible_time(c, tau_s) and c.cost <= B]
    return greedy_enumerate(cand, key=lambda c: gain(c)*on_time_prob(c, rho, nu))

# IP-325 DDL-6C
def kairos_6c(M, s):
    c_hat, kappa, novel = M.cbox.infer(featurize_num(s, M.dbox.R[s]))
    if kappa > KMAX or novel: return safe_hold(s, "context_unverified")
    H = M.lbox.hypothesize(s, M.dbox.R[s], bucket=phi(c_hat))
    prog = M.sched.plan(H, M.tau(s), M.budget_left(s))
    receipts = M.tcv.execute_with_watchdog(prog, M.env, M.tau(s) - TAU_M)
    live = M.cel.live(s, c_hat, now(), M.eps(s), L_C, RHO, NU)
    if len(live) < M.n_min(s): return stub_and_red(s, "insufficient_live")
    r = M.apcal.posterior(featurize_ctx(live, H, c_hat), M.tau(s), M.eps(s))
    if isinstance(r, Abstain): return safe_hold(s, "latency")
    if not M.apcal.cross_validate(r, M.cross_receipt(s, c_hat)):   # 时间+上下文留出
        return stub_and_red(s, "cross_context_failed")
    new_ec = M.apcal.update_contract(M.dpe, r.mu, r.Sig, s)
    if not contract_regression(new_ec): return stub_and_red(s, "regression")
    M.mreg.hot_replace(M.dpe, new_ec)
    bind_tcr(new_ec, H, prog, live, c_hat, M.tau(s))
    M.pquar.record_by_context(phi(c_hat), M.apcal.last_gain, realized_gain(live))
    return True

# IP-326 主闭环：50Hz 只加 O(1) 情境标签与新鲜度检查
def KairosGauge_round(M, obs, audio, tac, depth, det):
    M.cel.ingest(M.passive_receipts(obs, audio, tac, depth, det))
    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight and M.deadline_ok(s):
            M.inflight.add(s); submit_async(kairos_6c, M, s)
    return MODGAUGE_round(M, obs, audio, tac, depth, det)
```

## 4. 推导

**引理 51（任意停止下的后验有效性）** 在线混合置信序列（e-process / CS）在可选停止下保持
`P(u*∈CS_α(q^{(T)}))≥1−α−δ_cs`（Ville 不等式）；截止期截断只是限制停时范围，不破坏上界。
**引理 52（新鲜度-漂移覆盖界）** `P(|u*_t−μ_r|≤H_r(Δ))≥1−α`；
`Δ≤h_r(ε)` 内证据仍 `ε`-可信，超出后超额误差 `H_r(Δ)−ε` 随 `Δ` 单调增长；
`ν=0` 时 `h_r=((ε/z)²−σ_r²)_+/ρ²`。新鲜度是由 `(ρ,ν,σ_r,ε)` 唯一决定的闭式量。
**引理 53（上下文迁移界）** `E‖u*(c)−μ_{c′}‖² ≤ σ_{c′}²+L_C²d_C(c,c′)²`；
上下文税 `L_C²d_C²` 可加、可审计、可拒绝。
**引理 54（逐桶共形覆盖）** 桶内可交换 ⇒ `P(h*∈H_s|b)≥1−α`；有限样本偏差
`√(log(2|B|/δ)/(2n_b))`；边际达标不蕴含桶内达标，运行期监控 `max_b gap`。
**引理 55（弃权安全支配）** 若 `ℓ_hold≤ℓ_bad`，则 `E[loss]≤ℓ_hold+ℓ_bad·R_TC`，
`R_TC≤P(STALE)+P(FOREIGN)+P(deadline miss)+P(gap>δ_cov)+P(κ>κ_max)`；弃权只推向 `ℓ_hold`。
**引理 56（调度与时序）** 单预算单调次模 + 离散时间 ⇒ 部分枚举贪心 `(1−1/e)`；
双预算用二维枚举贪心给常数因子（实测 E454）；任何调度项 `finish≤τ_s`；
50Hz 新增 <0.3ms/周期，`P99` 修复时延由看门狗硬截断。
**定理 3（时效上下文认证安全）** 在 (i)–(iv) 成立时，任一认证热替换满足
`P(半宽≤ε ∧ 覆盖≥1−α) ≥ 1−δ_cs−δ_cov−κ_max`，未认证则弃权；
故 `R_TC ≤ δ_cs+δ_cov+κ_max+P(deadline miss)`。

## 8. 本轮最大风险

**一句话**：**上下文混淆 × 任意时刻提前退出**会让系统得到「快、窄、且自信地错误」的结论——
真实上下文被误判、旧证据在「新鲜度视界」内被复用、后验又在 deadline 压力下提前收窄，
错误结果在弃权机制触发前完成热替换；这比第 2 轮的「慢而相关偏差」更危险，因为延迟优化同时压缩了
发现错误的时间窗口。缓解：C3 逐桶覆盖（436）、CEL 四态（433）、混淆门控（439）、
时间+上下文留出（442）、看门狗与安全侧单调弃权（443/引理 55）、以及 E441/E445/E449/E453 的证伪实验。
