# 第 66 轮（承接第 65 轮「VISTA 故障可归因安全时序」IP-214~223；灵感循环第 3 轮；本轮灵感：「场景落地」×「数据采集」）

> 第 65 轮把「几何可证伪」升级为「故障可归因」，其自述最大风险一针见血：**归因能力同时依赖"故障属于有限假设集 ℋ"与"视觉和几何的失效相互独立"两个假设；真实故障常是未知类型的组合，透明/镜面/对抗 patch 又会让视觉与几何共享同一个分布外失效源，此时 FIR 会把未知复合故障强行归入最近假设、只膨胀错误的球——系统反而因为"已经归因"而更自信地继续执行。** 本轮不继续往闭环里加模块，而是换一个提问方式：第 65 轮问「**该怎么归因**」，本轮问「**这套归因与证书究竟在哪些场景里成立、校准数据从哪来、遇到从未见过的故障时如何不装作认得**」。本轮核心命题是：
>
> **把"闭环内的离线证书"升级为"部署场景内的可验证证书"：用 ODD 显式圈定证书的有效域，用开放集 conformal 让"未知故障"能被判成未知而非最近假设，用部署校准 conformal 在非交换数据流上守住覆盖率预算，用数据充分性证书把"数据不够"升为一等公民，并用价值信息驱动的安全采集把稀缺的故障数据花在刀刃上。**

## 0. 直觉与动机

**灵感 1（场景落地 → 证书必须先有"有效域"）**
直觉：实验室里可以穷举故障、反复注入、独立同分布采样；真实产线里没有这样的奢侈。VISTA 的 `Valid(J_vista)` 是一个**无坐标的布尔值**——它没说"在哪些物体、哪些接触几何、哪些光照与力区间里有效"。落地不是多录几段 demo，而是把"证书在哪儿成立"写进系统：定义一个**运行设计域 ODD**，把场景描述子 s（物体类别/几何/柔顺性/视觉条件/力区间/杂乱度）映射到"证书可被信任"的集合。落在 ODD 内才允许自主执行，出域即降级——这才是"场景落地"的工程含义。
严谨地说：把证书从 `Valid(J)` 改成 `Valid(J, s)`，并把 ODD 定义为一个**由 conformal 新颖度刻画的集合**，而不是一张手工白名单。

**灵感 2（数据采集 → 真正稀缺的是"带标签的故障数据"，不是算力）**
直觉：FIR 的似然 `p(ρ|H)`、conformal 的 `q_vis(α)`、RSC-V 的初始半径，全都靠离线故障注入标定。现场数据 99% 是健康样本、故障极稀疏、且**没有标签**（你不知道这次力残差是偏置还是几何幻觉）。于是"数据采集"不是被动记录，而是一个**控制问题**：在有限预算下，选择记录/注入/人问询哪些场景，才能最大程度降低"证书本身的不确定度"。第 65 轮的 AFA 只在"归因模糊时"花一次物理探针；本轮把它推广为**长期的、分层的数据投资**。关键区分：模型精度 ≠ 证书可信度，后者需要**每个假设的数据充分性**。

**灵感 3（未知故障 → 开放集，而不是软最大化到最近邻）**
直觉：有限 ℋ 上做 softmax，数学上**永远**会给出一个答案——哪怕真实故障根本不在 ℋ 里。这不是模型不够好，是问题被问错了。正确做法是把归因从"分类"改成"**带拒识的假设检验**"：用 conformal 给出假设**预测集** `C_α(ρ)`，当它为空、或同时含有多个高概率假设、或签名的密度在所有已知假设下都异常低时，输出 `H_unknown` 并降级，而不是硬塞进 H_geo/H_force。这直接对冲第 65 轮的头号风险：**"归因错误"最危险的形式不是分错，而是"不知道自己分错"。**

**灵感 4（非交换性 → 部署流会自己制造分布漂移）**
直觉：conformal 的 `1−α` 覆盖率依赖可交换性。部署数据不是可交换的：时间相关、分布漂移、而且**策略本身会改变数据分布**（你越敢在某些场景执行，就越常采到那些场景）。更要命的是，安全策略一旦生效就减少了故障样本——形成"幸存者偏差"，把校准集越洗越"健康"。于是第 65 轮那些写在纸上的 α_vis/α_chunk 在部署中会名不副实。本轮用**自适应 conformal（ACI）**在任意漂移下守住长程覆盖率，并用**策略诱导的协变量偏移加权**修正反馈回路偏差。

**灵感 5（三灵感合流 → FIELD：Fault-Informed Evidence from Live Deployment，部署数据驱动的故障证据闭环）**
闭环：场景描述与 ODD 规格（ODD-S）→ 场景分层校准 → 开放集归因（OSS）→ 数据充分性证书（DSC）→ 价值信息驱动的安全采集（DAE/SAC，含数字孪生合成故障 DTX 与人工问询）→ 部署校准 conformal（DFC/ACI）→ 证书 J_field → 部署阶梯门控（LADDER：影子→辅助→监督自主→自主）→ 现场监控与 ODD 扩张/收缩 → 回到采集。**第 65 轮是"闭环内的归因"，FIELD 是"归因闭环本身的落地与喂养"。** 它把"场景落地"变成可证的 ODD 门控，把"数据采集"变成可优化的信息投资，把"未知故障"变成一等输出。

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（FIELD 闭环）**：FIELD = (VISTA, ODD-S, OSS, DFC, DSC, DAE/SAC, DTX, PROV, LADDER, J_field)。定位：VISTA 的"部署有效域 + 开放集归因 + 数据充分性 + 数据引擎"升级。不变式：**ODD 判定、开放集检测、数据充分性与证书只在语义流；实时流只做现场残差采集、覆盖率与漂移监控、门控执行与回滚，零学习写操作。**
- **定义 234（场景描述子与 ODD）**：场景 `s=(o, g, κ, v, f, c)`：物体类别 o、接触几何 g、柔顺性/刚度 κ、视觉条件 v（光照/透明/纹理/遮挡）、力区间 f、杂乱度 c。ODD `S_odd={s : z_odd(s)≤τ_odd}`，其中 `z_odd` 为在已验证场景上的 conformal 新颖度分数，`τ_odd` 取标定集 `⌈(n+1)(1−α_odd)⌉/n` 分位。证书仅对 `s∈S_odd` 生效。
- **定义 235（场景分层与分层可交换性）**：把标定/部署样例按离散化场景键 `stratum(s)` 分层；假设层内可交换，只在层内计算 conformal 分位。跨层不做可交换性假设。分层不足的层标记 `stratum_underpowered`，其证书只能用保守并集界。
- **定义 236（开放集故障与未知判据）**：扩充 `ℋ⁺=ℋ∪{H_unknown}`。归因不再取 `argmax`，而是构造 conformal 假设预测集 `C_α(ρ)={H∈ℋ : 1−p(H|ρ) ≤ q_fi(α)}`；若 `C_α=∅`、或 `|C_α|>1` 且后验熵 `H(P(H|ρ))>τ_H`、或开放集新颖度 `z_os(ρ)=max_H p(ρ|H)/p_0(ρ)<τ_os`，则判 `H_unknown`（`p_0` 为已验证签名空间的参考密度，`τ_os` 用 conformal 定）。**未知是一种合法输出，不是异常分支。**
- **定义 237（部署校准 conformal DFC/ACI）**：对视觉残差、接触验证、块风险各维护自适应显著性 `α_t`，按 `α_{t+1}=α_t+γ(α_target−err_t)`，`err_t=1[Y_t∉C_{α_t}]` 更新。对策略诱导的协变量偏移，用密度比 `w(s)=p_deploy(s)/p_calib(s)` 做加权 conformal；密度比估计漂移过大即判 `calib_invalid` 并停用自主执行。
- **定义 238（数据充分性证书 DSC）**：对假设 H 与最强竞争假设 `H'`，最小可辨识样本数 `n_H ≥ 2 log(|ℋ|/δ)/D_KL(P_H‖P_{H'})`（局部 `D_KL≈½θᵀJ_fiθ`，`J_fi` 为定义 222 的 Fisher 信息）。记录每假设已成对样本数 `n̂_H`（按场景层、按故障幅度分箱）。证书携带 `sufficiency=min_H n̂_H/n_H`；`sufficiency<1` 时禁止把该假设用于定向处置，只能保守联合膨胀。
- **定义 239（采集价值与数据引擎 DAE）**：采集动作 q=(场景层, 探针/注入/问询, 预算)，信息价值 `I(q)=H(ℋ|ρ_{1:t})−E[H(ℋ|ρ_{1:t},ρ_new(q))]`；在预算 B 下选批量最大化 `I` 且满足安全与数据充分性缺口加权 `Σ_H λ_H·max(0,1−n̂_H/n_H)`。采集目标函数在给定 H 的条件独立近似下单调次模 → 贪心 ≥(1−1/e)。
- **定义 240（安全采集 SAC）**：每次采集须满足预测 `f_n≤f_safe`、形变 `≤ε_strain`、且不越过不可逆视界 m；易损/高价值物体只允许"零接触采集"（shadow 日志、视觉-only 探针、数字孪生注入、人工问询）。采集预算与安全预算分离记账，绝不挪用安全裕度换数据。
- **定义 241（数字孪生合成故障 DTX）**：用仿真/数字孪生按场景层生成合成故障签名 `ρ_syn`，以 `w_ratio=p_real(ρ)/p_syn(ρ)` 做重要性加权并入标定集；合成数据可**加密未知故障覆盖**，但只有通过"真实-合成一致性检验"（分层 two-sample / 分类器不可分）的层才计入 `n̂_H`，否则只作先验不作证据。
- **定义 242（溯源与污染控制 PROV）**：每条样本带 `prov=(来源, 时间块, 场景层, 是否注入, 标签来源)`。标定集与部署集按**时间块 + 场景层**双阻隔切分；同一物体/轨迹的近邻样本不得跨切分。检测到泄漏（近邻重复、时间穿越、标签回灌）即令相关证书 `contaminated=True` 失效。审计链记录"这条证书用了哪些数据"。
- **定义 243（部署阶梯与门控 LADDER）**：四级 `rung∈{shadow, assist, supervised, autonomous}`。升级条件：在该场景层，`Valid(J_field)`、ACI 实测覆盖率 `≥1−α−ε_cov`、现场 CUSUM/SPRT 未告警、数据充分性 `sufficiency≥1`、且连续 N 个块的现场风险上界 `≤budget`。任一条件破坏即降级/回滚。门控是单调承诺：**证书只能随场景层逐层解锁，不能全局一次性放开。**
- **定义 244（现场监控统计量）**：实时维护阶段化残差 `ρ_t` 的 CUSUM 与 conformal 残差分位；漂移检测用分位数的 EWMA 或 two-sample 检验；监控输出 `drift_score, coverage_gap, os_rate`。监控只触发"停/降/重标定"，不做学习写操作。
- **定义 245（FIELD 证书 J_field）**：`J_field=(J_vista, odd_membership, stratum_key, aci_coverage, sufficiency, open_set_flag, prov_hash, drift_stat, rung, data_budget_used)`。Valid ⇔ `Valid(J_vista) ∧ s∈S_odd ∧ aci_coverage≥1−α−ε_cov ∧ sufficiency≥1 ∧ ¬open_set_flag ∧ ¬contaminated ∧ rung≥requested_rung`。
- **定义 246（降级/回滚算子）**：按触发源定向降级：`open_set_flag→H_unknown→safe_idle/compliant_retreat`；`odd_membership=False→拒绝自主、交人/遥操作`；`coverage_gap>ε→收紧 α、停止升级、触发重标定`；`drift_score>τ_d→缩短 H 与 k*、扩大联合球`；`contaminated→作废证书并回退到上一版已验证标定`。降级不等于停机，而是**回到证书仍成立的最强保守策略**。
- **定义 247（ODD 扩张/收缩算子）**：`S_odd←S_odd ∪ {s}` 需该层 `sufficiency≥1` 且 ACI 覆盖达标且现场零违规；`S_odd←S_odd \ {s}` 当该层漂移/违规/数据陈旧（超期未再验证）。扩张是**有成本的承诺**：每次扩张都需重新冻结一版标定与证书版本号。
- **定义 248（FIELD 闭环算子）**：语义流 [场景描述→ODD 判定→分层校准→VISTA 归因→OSS 开放集→DSC 充分性→DAE/SAC 采集规划→DTX 合成/人工问询→DFC/ACI 重标定→CSP-V 规划→CSC→J_field→LADDER 门控→PROV 写入]；实时流 [场景键读取→残差/覆盖率/漂移监控→门控/回滚→执行→J_field 构建]。采集与重标定在低频语义流，绝不进实时环。

```python
def FIELD_step(M, obs, scenario, requested_rung):
    s_key = M.scenario.key(scenario)
    if not M.odd.contains(scenario, s_key):
        return M.safe_handover(s_key, reason='out_of_odd')       # 出域不自主
    phases = M.stage.split(M.residual_log, M.vpg.last)
    post, C_alpha = M.fir.attribute_open(phases, M.dfc.alpha(s_key))
    if M.oss.is_unknown(phases, post, C_alpha):
        M.prov.log(scenario, phases, label='H_unknown')
        M.ladder.demote(s_key, 'open_set')
        return M.safe_idle(s_key)
    if M.dsc.sufficiency(phases) < 1:
        M.dae.request(scenario, kind='targeted_injection')       # 差什么补什么
        post = M.fir.conservative_union(phases)                  # 只联合膨胀
    else:
        M.fir.directed_demote(post.argmax, M.balls, M.w_vis, M.H)
    q = M.dae.next_batch(scenario, post, M.dsc.deficit(), M.budget)
    M.prov.record(q)
    A, k_star = M.vista.plan_and_certify(post)
    rung = M.ladder.maybe_promote(s_key, M.monitor.stats(s_key),
                                  M.cert.build(post, s_key), requested_rung)
    return M.execute_if_allowed(A, k_star, rung)
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（开放集覆盖与未知拒识）**：分层可交换性下，conformal 假设集满足 `P(H_true∈C_α)≥1−α`；结合新颖度门 `z_os≥τ_os`（在已知数据上以 `≥1−α_os` 成立），未知故障被"静默误归因"的概率 `≤α+α_os+overlap`，其中 overlap 是未知故障与已知假设在参考密度下的似然比重叠质量。**重叠大（共因故障）时检测本身不可保证——这是诚实的边界。**
- **引理 10（ACI 漂移下长程覆盖）**：`α_{t+1}=α_t+γ(α−err_t)`，若 `err_t` 有界，则 `|(1/T)Σerr_t−α|≤(α_1+γ)/(γT)→0`。故任意漂移下长程误覆盖率仍收敛到目标 α；`α_vis、α_chunk` 不再因分布漂移而名不副实。
- **引理 11（数据充分性 ⇒ 可归因）**：由 Chernoff–Stein，区分 `P_H` 与 `P_{H'}` 到错误率 δ 至少需 `log(1/δ)/D_KL` 样本；对 |ℋ| 个假设用联合界得 `n_H≥2log(|ℋ|/δ)/min_{H'}D_KL(P_H‖P_{H'})`。充分性未达时定向处置的置信度不可证，必须退回联合膨胀。
- **定理 9（FIELD 端到端部署安全）**：在 A94–A99 下，`Valid(J_field)` ⇒ 部署块越界概率 `≤α_vis+α_chunk+α_os+α_data`，且未知故障或出 ODD 的场景**在执行前**被门控拦下（`H_unknown`/handover/safe_idle），不存在"默认 H0 继续跑"的路径。证书从"五层安全"扩为"五层安全 + 有效域 + 数据可信"。
- **定理 10（采集的近似最优性）**：在给定 H 的条件独立采集模型下，期望信息增益单调次模，贪心在预算 B 下达 `(1−1/e)` 最优；加入数据充分性缺口与新颖度探索项可缓解"只采集模型已理解场景"的偏差，但**不消除**未知未知的系统性漏采。
- **实时性**：ODD 键查询、残差/覆盖率/漂移监控、门控与回滚在实时流（<0.3ms）；开放集 conformal、充分性、采集规划、重标定、数字孪生注入全在低频语义流与离线。

## 2. 形式化定义（完整版）

**定义 233（FIELD 闭环）** FIELD 是 VISTA 的"部署有效域 + 开放集归因 + 数据充分性 + 数据引擎"升级：在 VISTA 的语义流/实时流骨架上挂载 ODD-S（场景与有效域）、OSS（开放集签名与未知拒识）、DFC（部署校准 conformal）、DSC（数据充分性证书）、DAE/SAC（价值信息驱动的安全采集）、DTX（数字孪生故障合成）、PROV（溯源与污染控制）、LADDER（部署阶梯与现场监控），并将 `J_vista` 扩展为 `J_field`。不变式：**场景判定、开放集检测、充分性计算、采集规划、重标定与证书只发生在语义流与低频/离线线程；实时路径只做场景键读取、残差/覆盖率/漂移监控、门控执行与回滚，零学习写操作。**

**定义 234（场景描述子与 ODD）** 场景 `s=(o,g,κ,v,f,c)`，其中 o 为物体类别/实例，g 为接触几何（面/边/角、法向、局部曲率），κ 为刚度/柔顺性档，v 为视觉条件（光照、透明/镜面、纹理、遮挡），f 为力区间档，c 为杂乱度/可达性。在已验证场景集上拟合新颖度 `z_odd(s)`（如归一化流/马氏距离/能量分数），令 `τ_odd` 为标定集非一致性分数的 `⌈(n+1)(1−α_odd)⌉/n` 分位，定义
`S_odd={s : z_odd(s) ≤ τ_odd}`。
`Valid(J,s)` 仅在 `s∈S_odd` 时可自主成立。出域不是错误，而是"证书不覆盖"的显式状态。

**定义 235（场景分层与分层可交换性）** 令 `stratum(s)` 为 s 的离散化键（o×g×v×f 的粗分箱）。标定集 `D_stratum` 按层切分；conformal 分位只在层内计算。假设"层内可交换"，**不假设跨层可交换**。若某层样本数 `< n_min`，标记 `stratum_underpowered`，只能用并在标定集上计算的保守并集界，证书带 `coarse=True`。这避免用"全局平均覆盖"掩盖某一危险场景层的系统性失准。

**定义 236（开放集故障与未知判据）** 扩充 `ℋ⁺=ℋ∪{H_unknown}`。对签名 ρ 与显著性 α：
1. 由标定集构造假设非一致性分数 `s(ρ,H)=1−p(H|ρ)`，取 `q_fi(α)` 为其 `⌈(n+1)(1−α)⌉/n` 分位，得预测集 `C_α(ρ)={H∈ℋ: s(ρ,H)≤q_fi(α)}`；
2. 在已验证签名空间上估计参考密度 `p_0(ρ)`，开放集新颖度 `z_os(ρ)=max_{H∈ℋ} p(ρ|H)/p_0(ρ)`，其门限 `τ_os` 同样用 conformal 定；
3. 判 `H_unknown` 当且仅当 `C_α=∅` **或** `z_os(ρ)<τ_os` **或**（`|C_α|>1` 且 `H(P(H|ρ))>τ_H`）。
`H_unknown` 是**一等输出**：它触发数据登记、部署降级与定向采集，而不是异常分支。此定义直接替换第 65 轮"有限 ℋ 上取 argmax"的封闭集假设。

**定义 237（部署校准 conformal DFC/ACI）** 对视觉残差、接触验证、块风险分别维护自适应显著性 `α_t`，按
`α_{t+1}=α_t+γ(α_target−err_t)`，`err_t=1[Y_t∉C_{α_t}]`，
并裁剪到 `[α_lo,α_hi]`。对策略诱导的协变量偏移，令 `w(s)=p_deploy(s)/p_calib(s)`，用加权 conformal 的加权分位代替均匀分位；当密度比估计的 TV 距离或有效样本量低于阈值时，判 `calib_invalid`，暂停自主升级。ACI 保证长程平均误覆盖收敛到目标（引理 10），因此第 65 轮的 `α_vis、α_chunk` 在漂移下仍有意义。

**定义 238（数据充分性证书 DSC）** 对每个假设 H，定义其与最强竞争假设 `H'(H)=argmin_{H'≠H}D_KL(P_H‖P_{H'})` 的最小可辨识样本数
`n_H = 2 log(|ℋ|/δ) / D_KL(P_H‖P_{H'})`。
局部线性化下 `D_KL(P_H‖P_{H'})≈½(θ_H−θ_{H'})ᵀJ_fi(θ_H−θ_{H'})`，与定义 222 的 Fisher 信息一致。实际按场景层与故障幅度分箱统计已成对样本数 `n̂_H`，定义
`sufficiency = min_H n̂_H/n_H`。
当 `sufficiency<1` 时，**禁止**用该假设做定向处置（定义 221 的 `H_geo→r_geo↑` 等），只能执行保守联合膨胀；`J_field` 记录缺口最大的假设与建议采集量。这把"数据不够"从隐含假设变成可审计的一等公民。

**定义 239（采集价值与数据引擎 DAE）** 采集动作 `q=(场景层, 采集方式, 预算)`，方式∈{真实注入, 物理探针, 视觉-only 探针, 数字孪生注入, 人工问询, shadow 日志}。定义信息价值
`I(q)=H(ℋ|ρ_{1:t})−E[H(ℋ|ρ_{1:t},ρ_new(q))]`，
采集目标
`max_{batch⊆Q, |batch|≤B} Σ_{q∈batch} [I(q) + Σ_H λ_H·deficit_H(q) + λ_ex·novelty(q)]`，
其中 `deficit_H(q)=max(0,1−n̂_H/n_H)` 的期望下降，`novelty(q)` 为对未知区域的探索奖励。在给定 H 的条件独立采集近似下目标单调次模，贪心达 `(1−1/e)` 近似（定理 10）。`λ_ex` 显式对冲"模型相对信息增益偏好已理解场景"的系统偏差。

**定义 240（安全采集 SAC）** 每次采集须满足预测法向力 `≤f_safe`、形变 `≤ε_strain`、且不越过不可逆视界 m；采集预算 `B_data` 与安全裕度预算分离记账，绝不以"为了采数据"降低安全阈值。易损/高价值物体只允许零接触采集：shadow 日志、视觉-only 探针、数字孪生注入、人工问询。物理注入需先过 CSC 的最坏情况检查（定义 226）。

**定义 241（数字孪生合成故障 DTX）** 用仿真/数字孪生按场景层生成合成故障签名 `ρ_syn`，以密度比 `w_ratio=p_real(ρ)/p_syn(ρ)` 做重要性加权并入标定集。合成数据可低成本覆盖稀有故障与未知组合，但只有通过**真实-合成一致性检验**的层（分层 two-sample 检验不可分 / 域分类器 AUC≈0.5）才把合成样本计入 `n̂_H`；否则合成样本只作先验，不作证据。防止"在错误的孪生里刷够了数据"。

**定义 242（溯源与污染控制 PROV）** 每条样本带 `prov=(来源,时间块,场景层,是否注入,标签来源)`。标定集与部署集按**时间块 + 场景层**双阻隔切分；同一物体/轨迹的近邻样本不得跨切分。检测到泄漏（近邻重复、时间穿越、标签回灌、策略自证）即令相关证书 `contaminated=True` 失效，并回退到上一版已验证标定。`J_field` 记录 `prov_hash`，审计可回答"这条证书用了哪些数据"。

**定义 243（部署阶梯与门控 LADDER）** 四级 `rung∈{shadow,assist,supervised,autonomous}`，按场景层分别维护。升级条件（全部满足）：该层 `Valid(J_field)`、ACI 实测覆盖 `≥1−α−ε_cov`、现场 SPRT/CUSUM 未告警、`sufficiency≥1`、且连续 N 个块的现场风险上界 `≤budget`。任一破坏即按定义 246 定向降级并回滚该层。门控是**单调承诺**：证书随场景层逐层解锁，不能全局一次性放开；不同层可处于不同阶梯。

**定义 244（现场监控统计量）** 实时维护阶段化残差 `ρ_t` 的 CUSUM（对偏置/漂移）与 conformal 残差分位 EWMA；漂移检测用分位数 EWMA 或 two-sample 检验；监控输出 `drift_score, coverage_gap, os_rate`。监控只触发"停/降/重标定/采集请求"，不做学习写操作，满足 A93 的实时契约。

**定义 245（FIELD 证书 J_field）** 
`J_field=(J_vista, odd_membership, stratum_key, aci_coverage, sufficiency, open_set_flag, prov_hash, drift_stat, rung, data_budget_used)`。
验证规则：
`Valid(J_field)` ⇔ `Valid(J_vista)` ∧ `s∈S_odd` ∧ `aci_coverage≥1−α−ε_cov` ∧ `sufficiency≥1` ∧ `¬open_set_flag` ∧ `¬contaminated` ∧ `rung ≥ requested_rung`。
审计链新增：为何认为场景在域内（ODD）、覆盖率是否被漂移破坏（ACI）、归因是否缺数据（sufficiency）、是否出现过未知（open_set_flag）、数据是否干净（prov_hash）、当前允许到哪一级（rung）。

**定义 246（降级/回滚算子）** 按触发源定向处置：
- `open_set_flag` → `H_unknown` → safe_idle / compliant_retreat + 登记未知样本；
- `odd_membership=False` → 拒绝自主，交人/遥操作，登记新场景层；
- `coverage_gap>ε_cov` → 收紧 α、停止升级、请求重标定；
- `drift_score>τ_d` → 缩短 H 与 k*、扩大联合球、降 rung；
- `contaminated` → 作废相关证书，回退上一版已验证标定；
- `sufficiency<1` → 禁用定向处置，仅联合膨胀。
降级不是停机，而是"回到证书仍成立的最强保守策略"。

**定义 247（ODD 扩张/收缩算子）** `S_odd←S_odd∪{s}` 需该层 `sufficiency≥1`、ACI 覆盖达标、现场零违规、并通过真实-合成一致性；`S_odd←S_odd\{s}` 当该层漂移/违规/数据陈旧（超期未再验证）。每次扩张/收缩冻结新的标定版本号与 `J_field` 版本，做到"证书可回溯到具体场景与数据集"。

**定义 248（FIELD 闭环算子）** 语义流：[场景描述→ODD 判定→分层校准→VISTA 归因→OSS 开放集→DSC 充分性→DAE/SAC 采集规划→DTX 合成/人工问询→DFC/ACI 重标定→CSP-V 规划→CSC→J_field→LADDER 门控→PROV 写入]；实时流：[场景键读取→残差/覆盖率/漂移监控→门控/回滚→执行 k* 步→J_field 构建]。采集与重标定在低频语义流，绝不进实时环。

## 3. 关键算法伪代码

### IP-224 OSS（开放集归因）

```python
class OpenSetSignatures:
    """conformal 假设预测集 + 新颖度门；未知是合法输出。"""
    def __init__(self, fir, p0, q_fi, tau_os, tau_H):
        self.fir, self.p0, self.q_fi, self.tau_os, self.tau_H = fir, p0, q_fi, tau_os, tau_H

    def decide(self, rho, alpha):
        post = self.fir.posterior(rho)
        C = {h for h in self.fir.HYP if 1.0 - post[h] <= self.q_fi[alpha]}
        z_os = max(self.fir.lik[h](rho) for h in self.fir.HYP) / max(self.p0(rho), 1e-12)
        if (not C) or (z_os < self.tau_os) or (len(C) > 1 and self.fir.entropy(post) > self.tau_H):
            return 'H_unknown', C, post, z_os
        h_star = max(C, key=lambda h: post[h])
        return h_star, C, post, z_os
```

### IP-226 DFC/ACI（部署校准 conformal）

```python
class AdaptiveConformal:
    def __init__(self, alpha_target=0.05, gamma=0.01, a_lo=0.005, a_hi=0.3):
        self.alpha = alpha_target
        self.alpha_target, self.gamma, self.a_lo, self.a_hi = alpha_target, gamma, a_lo, a_hi

    def update(self, y_true, C_alpha):
        err = 0 if y_true in C_alpha else 1
        self.alpha = float(np.clip(self.alpha + self.gamma * (self.alpha_target - err),
                                   self.a_lo, self.a_hi))
        return self.alpha

    def weighted_quantile(self, scores, weights, alpha):
        # 加权 conformal：应对策略诱导协变量偏移
        order = np.argsort(scores)
        s, w = np.asarray(scores)[order], np.asarray(weights)[order]
        cw = np.cumsum(w) / np.sum(w)
        idx = np.searchsorted(cw, 1 - alpha)
        return float(s[min(idx, len(s) - 1)])
```

### IP-227 DSC（数据充分性）

```python
class DataSufficiencyCertificate:
    def __init__(self, lik, HYP, delta=0.05):
        self.lik, self.HYP, self.delta = lik, HYP, delta

    def need(self, h):
        rivals = [kl_div(self.lik[h], self.lik[h2]) for h2 in self.HYP if h2 != h]
        dmin = max(min(rivals), 1e-9)
        return 2.0 * np.log(len(self.HYP) / self.delta) / dmin

    def score(self, counts, strata):
        gaps = {}
        for h in self.HYP:
            n_need = self.need(h)
            n_hat = sum(counts[(h, s)] for s in strata if (h, s) in counts)
            gaps[h] = n_hat / n_need
        return min(gaps.values()), gaps          # sufficiency<1 → 禁止定向处置
```

### IP-228 DAE（价值信息驱动的安全采集）

```python
def plan_acquisition(post, deficits, scenarios, budget, lam_H=1.0, lam_ex=0.2, n_greedy=32):
    def score(q):
        ig = expected_mutual_info(post, q, lik)                 # I(H; rho_new)
        deficit_gain = sum(lam_H * (1 - deficits[h][q]) for h in deficits)
        novelty_bonus = lam_ex * scenario_novelty(q)           # 对冲模型相对偏差
        safety_pen = 1e9 if not safe(q) else 0.0               # f_n<=f_safe, strain<=eps
        return ig + deficit_gain + novelty_bonus - safety_pen

    chosen = []
    for _ in range(n_greedy):
        if sum(q.cost for q in chosen) >= budget:
            break
        rest = [q for q in scenarios if q not in chosen and sum(c.cost for c in chosen) + q.cost <= budget]
        if not rest:
            break
        chosen.append(max(rest, key=score))                    # 次模贪心
    return chosen
```

```python
def split_provenance(data, time_block=7 * 24 * 3600):

def ladder_gate(layer, cert, stats, requested_rung, alpha, eps_cov=0.02, N=50):
    ok = (cert.valid(layer)
          and stats.aci_cov >= 1 - alpha - eps_cov
          and not stats.cusum_alarm
          and stats.sufficiency >= 1
          and stats.consecutive_ok >= N)
    if ok:
        return min(stats.rung + 1, requested_rung)
    return max(0, stats.rung - 1)      # 定向降级，回退到仍成立的保守策略
```

### IP-233 FIELD 闭环算子（整合）

```python
def FIELD_round(M, obs, scenario, requested_rung):
    V, T, P, L, P_cloud, W_meas, tactile, img, depth, flow = obs
    s_key = M.scenario.key(scenario)

    # 0) ODD：出域即不自主，登记新场景层
    if not M.odd.contains(scenario, s_key):
        M.prov.log(scenario, kind='out_of_odd')
        return M.safe_handover(s_key, reason='out_of_odd')

    # 1) VISTA 语义流：视觉/阶段/归因（用该层的自适应 alpha）
    alpha = M.dfc.alpha(s_key)
    y_vis = M.f_vis(img, depth, flow)
    M.lsf.update_geometry(P_cloud)
    x_prime = M.lsf.fuse(M.usr.fuse(V, T, P, L))
    A = M.ach.propose(x_prime, H=M.H)
    visual = M.vpg.verify_and_predict(y_vis, A, M.mws.last_contacts)
    phases = M.stage.split(M.residual_log, visual)

    # 2) 开放集归因：未知是合法输出
    h_star, C_alpha, post, z_os = M.oss.decide(phases.signature, alpha)
    if h_star == 'H_unknown':
        M.prov.log(scenario, phases, label='H_unknown')
        M.dae.request(scenario, kind='unknown_characterization')
        M.ladder.demote(s_key, 'open_set')
        return M.safe_idle(s_key)

    # 3) 数据充分性：不足则只能联合膨胀
    suff, gaps = M.dsc.score(M.counts, M.strata)
    if suff < 1:
        M.dae.request(scenario, kind='targeted_injection',
                      targets=[h for h, g in gaps.items() if g < 1])
        post = M.fir.conservative_union(phases)
    else:
        M.balls, M.w_vis, M.H = M.fir.directed_demote(h_star, M.balls, M.w_vis, M.H)

    # 4) 采集规划（低频、离线执行；不进实时环）
    batch = plan_acquisition(post, gaps, M.scenarios, M.budget)
    M.prov.record(batch)

    # 5) 规划 + 认证前缀 + 阶梯门控
    A, = [M.ach.propose(x_prime, H=M.H)]
    k_star = M.csc.certified_prefix(A, post, M.m, M.alpha_chunk)
    rung = ladder_gate(s_key, M.cert.build(post, s_key),
                       M.monitor.stats(s_key), requested_rung, alpha)

    # 6) 实时执行与监控（零学习写）
    K_safe, EV_exec, cert_exec = realtime_step_field(
        M, A, k_star, x_prime, y_vis, rung)
    M.monitor.update(s_key, M.residual_log, M.oss.last_z, M.dfc.alpha(s_key))

    # 7) 离线：PROV 审计、DTX 补样、重标定（非实时）
    if M.prov.contaminated:
        M.dfc.rollback(s_key)
    M.dtx.maybe_synthesize(gaps)
    return M, K_safe, EV_exec, build_j_field(
        cert_exec, J_vista=M.j_vista, odd_membership=True, stratum_key=s_key,
        aci_coverage=M.dfc.cov(s_key), sufficiency=suff,
        open_set_flag=False, prov_hash=M.prov.hash(s_key),
        drift_stat=M.monitor.drift(s_key), rung=rung,
        data_budget_used=M.budget.used)
```

## 4. 推导

**引理 9（开放集覆盖与未知拒识）** 在场景层内可交换、且 `C_α` 由定义 236 的 conformal 非一致性分数构造时，对已知假设的真实标签 `H_true∈ℋ`，有
`P(H_true∈C_α(ρ)) ≥ 1−α`。
于是当 `C_α≠∅` 时，以 `≥1−α` 的概率真实假设未被排除；归因只在 `C_α` 内进行，故"已知故障被错误排除"的概率 `≤α`。
对未知故障 `H_true∉ℋ`，需要检测而非覆盖。新颖度门 `z_os<τ_os` 由已知分布标定：在已知样本上 `P(z_os<τ_os)≤α_os`。若未知故障分布在参考密度 `p_0` 下与所有已知假设的似然比重叠质量为 `overlap`，则由全概率与联合界，
`P(未知故障被静默误归因) ≤ α_os + overlap`。
特别地，若未知签名与已知签名在 `p_0` 下几乎奇异（overlap→0），检测概率 `→1−α_os`。**当 overlap 不可忽略（共因故障、同一 OOD 物体同时骗过多通道）时，本引理不提供保证——这是开放集的诚实边界，也是第 65 轮风险的延续而非消除。** ∎

**引理 10（ACI 漂移下长程覆盖）** 令 `err_t=1[Y_t∉C_{α_t}]`，更新 `α_{t+1}=α_t+γ(α−err_t)`。将更新式对 t=1..T 求和并整理：
`α_{T+1}=α_1+γΣ_{t=1}^T(α−err_t)`。
由于 `α_t∈[α_lo,α_hi]`，有 `|α_{T+1}−α_1|≤α_hi−α_lo`，故
`|(1/T)Σ_{t=1}^T err_t − α| ≤ (α_hi−α_lo+γ)/(γT) → 0`。
即无论数据是否可交换、分布如何漂移，长程平均误覆盖率收敛到目标 α。因此第 65 轮写在证书里的 `α_vis、α_chunk` 在部署中仍可被解释为**长程预算**，而非一次性保证。若进一步需要高概率界，可叠加 ACI 的 concentration 结果（以额外 `O(1/√T)` 项为代价）。 ∎

**引理 11（数据充分性 ⇒ 可归因）** 对两个签名分布 `P_H、P_{H'}`，Chernoff–Stein 引理给出把第二类错误压到 δ 所需样本数满足 `n ≥ log(1/δ)/D_KL(P_H‖P_{H'})`（渐近最优）。对 `|ℋ|−1` 个竞争假设用联合界，要求每个竞争对错误率 `≤δ/(|ℋ|−1)`，得
`n_H ≥ log((|ℋ|−1)/δ)/D_KL(P_H‖P_{H'})`，
取保守常数 2 得上式。局部线性化 `P_H=N(θ_H,Σ)` 时 `D_KL≈½(θ_H−θ_{H'})ᵀΣ⁻¹(θ_H−θ_{H'})`，正是定义 222 的 Fisher 二次型，故 `n_H` 与可辨识裕度 `κ_fi` 同源：阶段对比度越大、列越正交，所需样本越少。反之，若 `sufficiency<1`，MAP 归因的置信度无法由样本量支撑，**必须**退回联合膨胀（定义 238）。 ∎

**定理 9（FIELD 端到端部署安全）** 在假设 A94–A99（层内可交换、ODD 新颖度可标定、ACI 长程覆盖、充分性可达、真实性-合成一致性可检、监控延迟有界）下，若 `Valid(J_field)` 成立，则：
1. **场景在域**：`s∈S_odd`，证书的统计假设只在该层标定集上成立；出域场景在**执行前**被 `safe_handover` 拦下，不存在"拿域内证书跑域外场景"的路径。
2. **未知被拒识而非误归因**：`¬open_set_flag` 意味着 `C_α≠∅` 且 `z_os≥τ_os` 且后验不超熵；由引理 9，已知故障误排除概率 `≤α`，未知故障静默误归因概率 `≤α_os+overlap`。
3. **归因被数据支撑**：`sufficiency≥1` 保证定向处置有 Chernoff–Stein 意义下的样本支撑；否则系统已退回联合膨胀，不会只膨胀错误的球。
4. **覆盖率在漂移下仍可信**：`aci_coverage≥1−α−ε_cov` 由引理 10，`α_vis、α_chunk` 的解释在部署流中保持长程有效。
5. **数据干净**：`¬contaminated` 保证标定/部署双阻隔，证书可回溯（`prov_hash`）。
6. **阶梯受控**：`rung≥requested_rung` 且升级需连续现场安全，违规即定向回滚。
由联合界，部署块越界概率
`P[越界] ≤ α_vis + α_chunk + α_os + α_data + O(1/(γT))`，
且以上每一项都在 `J_field` 中被显式记录，不再隐藏于"离线已标定"的假设里。∎

**定理 10（采集的近似最优性）** 设采集对签名的影响在给定 H 下条件独立，采集集合 S 的期望信息增益 `f(S)=H(ℋ|ρ_{1:t})−E[H(ℋ|ρ_{1:t},ρ_new(S))]`。在此模型下 `f` 非负、单调、次模（信息增益的经典次模性）。预算约束 `Σ_{q∈S}cost(q)≤B` 下的贪心算法满足
`f(S_greedy) ≥ (1−1/e)·f(S_OPT)`。
加入充分性缺口项 `Σλ_H·deficit_H`（对每个 H 为覆盖函数，仍次模）与新颖度探索项后，若探索项取覆盖函数形式，目标仍次模，保证不变。**注意**：此项"最优"是相对于模型给的信息度量而言；模型未表征的未知区域，`I(q)` 可能系统性低估其价值——故引入 `λ_ex·novelty(q)` 作为显式探索，但该修正只能缓解、不能消除未知未知的漏采（见第 7 节风险 1）。 ∎

**命题（FIELD 相对 VISTA 的过保守/过自信双向改进）** VISTA 在未知故障上会给出一个有限 ℋ 上的 argmax，其"自信"与真实正确率脱钩；FIELD 的 `H_unknown` 把它转为可观测的拒识事件，并用 `sufficiency` 阻止无数据支撑的定向处置。另一方面，VISTA 对所有场景用同一套全局 conformal，某危险层欠采样时会被其他层的平均覆盖"洗白"；FIELD 的分层 + 出域门控把这种掩盖变为 `stratum_underpowered`/`out_of_odd` 的显式状态。二者共同把"过自信"与"过保守"从不可见变为可审计。∎

## 7. 已知风险

**一句话**：FIELD 把"证书有效域"寄托在 ODD 与开放集检测上，但 ODD 新颖度、开放集新颖度与故障签名往往**共享同一套学习表征与同一批盲区**；当真实部署遇到表征分布外的东西时，"出域"与"未知故障"会一起失效，系统可能用自己定义的有效域把自己认证进一片从未真正见过的世界——而价值信息驱动的采集又天然偏好"模型已理解、熵下降快"的场景，系统性地少采那些最该被采到的未知未知。

**次级风险与缓解**：
1. **未知未知的系统性漏采**：信息增益是模型相对的，模型不知道自己不知道；缓解：`λ_ex·novelty` 探索项、主动 OOD 压力测试、红队场景注入、对 `H_unknown` 事件强制登记并优先采集；但这只能缓解，不能消除。
2. **ODD 与 OSS 共因失效**：透明/镜面/对抗 patch 同时让二者失去新颖性信号；缓解：用**正交表征**（几何/触觉/本体感觉）分别计算新颖度，任一通道异常即出域；引入人工抽检与第三方审计。
3. **conformal 分层样本不足**：危险层天然稀疏，`stratum_underpowered` 导致证书只能用粗界；缓解：合并相邻层、合成数据补样（须过一致性检验）、主动采样优先补危险层。
4. **ACI 的短程/高概率失效**：长程平均覆盖不代表每个短窗口安全；缓解：叠加 CUSUM 检测与保守 α_hi，窗口级用 Hoeffding/联合界，升级需连续 N 块达标。
5. **数字孪生一致性伪装**：孪生与真实共享同一建模错误，域分类器也可能被对抗；缓解：多源孪生、真实-合成事件对齐检验、合成样本只作先验并限制权重上限。
6. **数据采集的伦理/成本约束**：真实注入可能损坏物体或违反产线节拍；缓解：SAC 零接触优先、安全预算独立、人工问询替代物理注入；高风险层不追求充分性而直接标 `manual_only`。
7. **溯源切分的可操作性**：真实产线难以严格时间块切分、物体复用导致近邻泄漏；缓解：样本指纹去重、按轨迹/物体 ID 阻隔、部署前做泄漏审计；污染时自动回退旧证书。
8. **证书组合爆炸与实时预算**：分层 × 阶梯 × 版本导致证书数量膨胀；缓解：证书按 `(stratum, rung, calib_ver)` 缓存、只对活跃层维护、离线预计算并单调版本化；实时路径仍 ≤2.8ms。
