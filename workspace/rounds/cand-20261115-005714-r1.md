# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「迭代验证」×「语音合成」）

> R69 把不确定性一分为二，问出「我该向谁求证、还能问什么」，并用「k 个正交证据源一致」把交互变成可审计的动作。但它有两个未拆的假设：其一，**交互是一次性的**——问一次、信一次、做一次，证据纪律是静态阈值而非收敛过程；其二，**问句是免费的、不可验的**——冻结 LLM 吐出的 g_ask 直接上线，系统从不检查自己「问得清不清楚」，更不检查「问得对不对」。R69 自陈的最大风险正是后者的极端情形：**问错，比不问更危险**。
>
> 本轮两个灵感各补一刀：
> - **迭代验证**把「问一次」升级为「边问边验、验到可停为止」；更重要的是，它逼出一个常被忽视的统计学事实——**当系统自己决定何时停止时，朴素的置信阈值全部失效（可选停止会膨胀错误率）**。R69 的证据纪律必须升级为 **anytime-valid** 的序贯检验，否则「问到满意为止」本身就是 p-hacking。
> - **语音合成**把「问句」从一个抽象 token 序列落成一个**可自验证的物理过程**：合成→播放→被听见→被复述（TTS→ASR 往返）构成一条自洽性检查；韵律可以把置信「说」出来；但它同时打开一个全新攻击面（语音克隆、重放、对抗韵律），而且 **往返只能验证「问得清楚」，永远不能验证「问对了」**。
>
> 核心命题：**把握手式的一次性交互升级为「迭代验证环 + anytime-valid 证书 + 语音往返自验证 + 反回音室门」；但必须明确承认：自验证只能保证自洽，外部接地不可省。** 命名 **ECHO-RAS**（Echo-verified Convergent Hypothesis Optimization for Risk-Adaptive Safety）。ECHO 同时是褒义（用回声自检）与贬义（回音室自我确认）——本轮的核心张力正在于此。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我怎么知道我问对了、答得可信、且没有把自己问进死胡同**」——验证不是盖一次章，而是一个可能以「仍然不知道」结尾的收敛过程。

## 0. 直觉与动机

**灵感 1（迭代验证 → 一次性证据纪律在统计上是错的）**
直觉：R69 说「单源不得定案，需 k 个正交源一致」。但「k 个源一致」只有在**事先固定**时才是合法证据。真实闭环里，系统是先看结果再决定要不要多问一句的——这个「问不问」的自由度，就是可选停止。可选停止下，即使每个源都独立无害，只要允许「不满意就再问」，假阳率就会随轮数无界膨胀。人们熟悉的 A/B 测试「偷看」问题在这里是同一件事。**迭代验证的第一性要求不是多验，而是：停止规则本身必须被证明不会作弊。** e-value / 测试鞅提供这个证明：Ville 与 Markov 不等式保证，在任意自适应停止时间上，错误决议概率都被预算 α 控制住。这把 R69 的启发式纪律变成一个可交付的定理（定理 18）。

**灵感 2（语音合成 → 问句是一个可自检的物理过程）**
直觉：R69 的问句是冻结 LLM 的一次解码，没人检查它是否清晰。可人问路时会下意识自检：「我这样问对方听得懂吗？会不会被带偏？」语音合成给了系统同样的自检机会——把要问的话合成出来、再让 ASR 复述一遍，比较语义是否保真。保真高、诱导低、可懂度高，才允许发出。这是第一条**不依赖外部真值**的验证通道。加一句：它检查的是「问得清」，不是「问得对」——一个关于幻影的问句也能被合成得字正腔圆（引理 19）。所以语音自验证只关掉一类门，不能替代模态校准。

**灵感 3（韵律 → 把不确定「说」出来，但也把攻击面「说」出来）**
直觉：R69 的交互成本 c(g) 里有一项「社交打扰」。系统如果总是用笃定语气问一个自己没把握的问题，既冒犯又危险。语音合成可以把 U_ale/U_epi 映射成韵律：升调、停顿、hedge（「我不太确定……」）。这能让听者的主观置信与系统真实置信对齐（ECE_prosody），并降低「被笃定语气胁迫而随口作答」的诱导压力。但同样的韵律通道可被克隆与合成伪造——**收益与风险同源**（引理 21）。所以韵律证据只能当辅助源，且被反欺骗分门控。

**灵感 4（反回音室 → 迭代验证最危险的失败模式）**
直觉：迭代验证听起来天然更好，但它有一个致命退化：如果每一轮都用同一条自指通道（自己的模型、自己的合成、自己的复述），那么这些证据高度相关。相关证据的有效样本 n_eff = k/(1+(k−1)ρ) 会随 ρ→1 退化到 1。也就是说，**反复问自己同一个问题，只会让初始信念越来越自信，而信息量不增**。这就是回音室。它不是 bug，是「同源重复」的数学必然。所以本轮必须把「条件独立度」提升为一等约束（定义 313、318、319），并用「外部接地不可省」（命题 1）划出边界：纯自指验证无论迭代多少轮，可达信息量都有上界。

**灵感 5（语音是双刃剑 → 新的威胁模型与实时性约束）**
直觉：一旦系统真的「开口」，攻击面从文本扩展到声学：语音克隆冒充权威、重放旧回答、对抗韵律伪造情绪、TTS 幻觉出不存在的犹豫、甚至 TTS 与 ASR 同源导致的「共谋式自洽」（合成器和识别器共享偏置，往返全过关但语义已错）。同时，TTS 有几十毫秒到上百毫秒的延迟，绝不能塞进 R69 那条 2.6ms 的控制环路。所以必须：语音动作全部**预合成 + 缓存 + 异步**，派发时只查表；反欺骗分 S_asv 门控韵律证据；把这一切并入干扰集 ℰ_echo 与审计器 VQAuditor-V。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（ECHO-RAS 总览）** ECHO-RAS = (IVL, TTC, AVC, PAI, IVG, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **语音/合成永不进控制关键路径**：TTS/ASR 一律预合成缓存、异步复核，派发处只做查表与认证（定义 321）；
(iii) **反回音室账本**：每轮验证必须使用与已用证据集「条件独立度 ≥ ρ_min」的新源，禁止同源重复充数（定义 318–319）；
(iv) **停止由 anytime-valid 判据决定**，交互 + 验证总预算硬约束，不允许「验到满意为止」（定义 314、325）。

**定义 311（验证轮次与验证状态）** 第 r 轮验证状态 V_r = (b_r, ℰ_r, e_r, τ_r)：b_r 为模态身份后验（初值由 R69 的 AUD 给出）；ℰ_r 为已用证据源集合；e_r 为累积 e-value（定义 314）；τ_r 为已消耗预算。验证动作 g_r 与 R69 定义 294 同属 𝒜_info。

**定义 312（迭代验证环 IVL）** 循环 r = 0,1,…：
观测 y_r = Execute(g_r)（看 / 问 / 触 / 听）；更新 b_{r+1} = Bayes(b_r, y_r)；更新 e_{r+1} = e_r · Λ_r(y_r)（e-value 乘子）。停止条件三选一：
(a) **决议**：∃m，b_r(m) ≥ 1 − α_r；
(b) **证伪/回滚**：某模态被排除（b_r(m) < ε_rej），触发定义 320 回滚；
(c) **预算/停滞**：τ_r > τ_max，或验证进度 Δ_r < ε_stag 连续两轮（回音室预警）。
未决议 ⇒ 退 R69 保守（R69 定义 307）。

**定义 313（验证信息增益与采集）** 与 R69 的 VoI（单步熵减，定义 298）不同，验证采集最大化的是「**每单位成本的后验收缩 × 条件独立度**」：
G(g) = E_{y|g}[D_KL(b_{r+1} ‖ b_r)] / c(g)，G̃(g) = G(g)·κ(g)，κ(g) = 1 − Î(g; ℰ_r)/H_eff。
选 g_r = argmax G̃(g)，s.t. 认证与预算。**同一通道重复使用 ⇒ Î 升高 ⇒ κ→0 ⇒ 采集器自动拒用该源**（把反回音室写进采集目标，而非事后惩罚）。

**定义 314（anytime-valid e-value 与几何 α-spending）** 对假设对 (m, ¬m)，单轮似然比 Λ_r(y) = p(y|m) / p(y|¬m)（其条件期望 ≤ 1 时称为 e-value 乘子）；累积 e-value E_R = ∏_{r≤R} Λ_r。取 α_r = α·2^{−(r+1)}（几何支出，Σ_r α_r = α）。每轮检验 `E_r ≥ 1/α_r` 即拒绝 H0。由 Markov 不等式 P_{H0}(E_r ≥ 1/α_r) ≤ α_r·E[E_r] ≤ α_r，再对 r 取并集界：`P_{H0}(∃r : E_r ≥ 1/α_r) ≤ Σ_r α_r = α`。**该界对任意自适应停止时间成立**——这就是可选停止下的合法性来源。

**定义 315（语音合成往返自验证 TTS-SV / TTC）** 问句 q = Decode_LLM(g_ask) 不直接发出，先过往返：
`q → TTS(音色 v, 韵律 π) → a → ASR → q̂`。
三道门：(i) 语义保真 `sim(q, q̂) ≥ τ_sem`（冻结句嵌入）；(ii) 无诱导 `Ind(q) ≤ τ_ind`（反事实问句的答案漂移）；(iii) 可懂/置信 `Cal(a) ≥ τ_int`。任一不过 ⇒ 改 π/措辞重合成（至多 R_tts 次）；仍不过 ⇒ **不许问**，U_epi 保持未消解。**诚实声明：往返只验证「问清 ≠ 问对」**（引理 19）。

**定义 316（韵律-不确定性映射 PUM）** π = PUM(U_ale, U_epi, b_r) = (F0 轮廓、语速、停顿、句末升调、hedge 短语)。目标：**置信-韵律校准**，使听者主观置信满足 ECE_prosody ≤ τ_p；高 U_epi 时用升调/hedge **主动降低社交成本与诱导压力**，绝不把不确定伪装成确定。

**定义 317（韵律-语义不一致 PAI）** 回答 y = (y_lex, y_ac)；r_pro = D_inc(y_lex, y_ac)（否定词 vs 升降调、承诺词 vs 犹豫停顿、情绪词 vs 基频）。作为 R69 证据集 ℰ 的新成员；与 r_emo 联合提高欺骗检出，但**二者均可被共谋/克隆伪造**（定义 322、引理 21）。

**定义 318（条件独立度与有效样本）** κ_ij = 1 − Î(e_i; e_j)/min(H_i, H_j)。若 k 个源两两相关 ρ̄，则有效样本 `n_eff = k / (1 + (k−1)ρ̄)`。**ρ̄→1 时 n_eff→1**：重复同一自指通道 k 次，验证等效于 1 次。

**定义 319（反回音室门 AEG）** 若下一轮计划使用的证据源与 ℰ_r 满足 Î > Î_max，或连续两轮 Δ_r < ε_stag，则**禁止继续自验证**，只允许：(a) 换正交模态；(b) 升级到外部真值通道（人 / 离线标定 / 异质传感器）；(c) 停止并退保守。这是结构性防御，不是事后惩罚。

**定义 320（信念回滚 BRR）** 维护后验快照 {b_r} 与每轮证据贡献。当新证据方向反转且显著（似然比跨零），回滚到冲突前快照，并把该证据源标记为可疑送入审计。R69 无回滚；R70 允许「撤回一个已验证的章」。

**定义 321（合成通道安全与实时性 SCS）** 候选问句在空闲期**预合成**并缓存（key = 意图簇 × 韵律档）；派发时仅查表 + 认证，延迟 < 0.1ms。语音输出过与任务动作相同的安全包络（音量/时长/内容过滤），问句**不得包含可执行的动作指令**（防止用语音间接驱动执行）。

**定义 322（回音室/克隆干扰集 ℰ_echo）** 自我确认（同源自验证）、验证协议被对手学习后反向利用（adversarial verification gaming）、语音克隆/重放/对抗韵律、TTS 幻觉出不存在的情感韵律、TTS-ASR 同源偏置导致的「共谋式自洽」。并入 AIC：ℰ_ECHO = ℰ_FLUID × ℰ_echo。

**定义 323（证书 J_ECHO）** J_ECHO = (J_FLUID, e_value_final, stopping_time R, alpha_spent, n_eff, independence_min, tts_roundtrip_sim, prosody_ece, aeg_triggered, echo_ver)。Valid ⇔ Valid(J_FLUID) ∧ e-value 达决议门 ∧ TTS-SV 全过 ∧ 条件独立度 ≥ ρ_min ∧ 停止由 anytime-valid 判据（而非「验到满意」）作出。

**定义 324（两级验证退避，安全侧加强）** 若迭代验证在预算内**决议**：λ = λ_floor(U_ale)（继承 R69 的 resolution bonus）；若**未决议/停滞/触发 AEG/证书无效/疑似回音室**：λ = λ_floor(U_ale + U_epi)（回到 R69）；若**验证本身命中投毒/克隆攻击**：λ = λ_floor(U_ale + U_epi) **且冻结交互一个冷却窗**（比 R69 更保守一档）。⇒ R70 安全侧是 R69 的分层加强。

**定义 325（验证预算的几何分配）** 总预算 B_v；第 r 轮分配 b_r = B_v·γ^r（γ<1），保证有限轮收敛、不因单轮高成本饿死后续；R_max = ⌈log_γ(ε_b/B_v)⌉。

**定义 326（语音接地审计 VQAuditor-V）** 审计对象从「交互决策」升级为「**验证链**」：问句往返是否被跳过、韵律是否与置信一致、是否用同源重复充数、回滚是否被隐瞒、克隆/重放是否被识别。结论回灌 AuditBuf，成为 AEG 阈值与 TTS 缓存策略的先验。

# IP-264 IVL：迭代验证环（替代 R69 的一次性 MINT）
def iterative_verification(b0, budget, sources, alpha=0.05):
    b, used, E, spent, hist = b0, set(), 1.0, 0.0, [b0]
    for r in range(R_MAX):
        a_r = alpha * 2.0 ** (-(r + 1))                 # 几何 alpha-spending
        g = argmax_gain(sources, b, used, kappa=independence)   # 定义 313
        if g is None:                                   # AEG：无正交源 → 停
            break
        y = execute_certified(g)                        # 过 C-RAS-WM 认证
        b_new = bayes(b, y)
        E *= likelihood_ratio(y, top2(b))               # e-value 乘子
        hist.append(b_new); used.add(source_of(g)); spent += cost(g)
        if b_new.top_conf >= 1 - a_r:                   # 决议
            return Decision(b_new.argmax, E, r, 'resolved')
        if b_new.top_conf < EPS_REJ:                    # 证伪 → 回滚
            b_new = rollback(hist); flag_source(g)
        if E >= 1.0 / a_r:                              # anytime-valid 拒绝
            return Decision(b_new.argmax, E, r, 'valid')
        if stagnation(hist, 2) or spent > budget:       # 停滞 / 超支
            break
        b = b_new
    return Decision(None, E, r, 'undecided')            # → R69 保守兜底

# IP-265 TTS-SV：语音合成往返自验证（问句上线前的必要非充分门）
def tts_self_verify(q, tts, asr, prosody):
    for _ in range(R_TTS):                              # 迭代重合成
        a  = tts(q, prosody)                            # 预合成缓存命中则零延迟
        qh = asr(a)
        if (sim(q, qh) >= TAU_SEM and                   # 问清：语义保真
            inductiveness(q) <= TAU_IND and             # 非诱导
            intelligibility(a) >= TAU_INT):             # 可懂
            return a, True
        prosody = refine_prosody(prosody, q, qh)        # 迭代验证 = 重合成
    return None, False                                  # 问不清 → 不许问

# IP-267 AEG：反回音室门（结构性，而非事后惩罚）
def anti_echo_gate(used, plan_g, hist):
    if mutual_info(plan_g, used) > I_MAX:               # 同源重复
        return retry_with_orthogonal(used) or None
    if stagnation(hist, 2):                             # 两轮无进展
        return escalate_external() or None              # 外部真值，否则停
    return plan_g

# IP-268 BRR：信念回滚（撤回一个已验证的章）
def rollback(hist, r):
    return hist[-1] if r == 0 else hist[r - 1]          # 回到冲突前快照

# IP-274 主闭环（R69 FLUID 环 + 迭代验证 + 语音自验证）
def ECHO_RAS_round(M, obs):
    z, o = M.mtm.forward(obs); c, U_cal, _ = M.cof.step(...)
    b0 = M.aud.decompose(M.fmp.sample(o, K_for(M, z)), z)   # R69 后验
    U_ale, U_epi = b0.ale, b0.epi
    d = None
    if U_epi > TAU_EPI and not slow_fault(M):
        d = iterative_verification(b0, M.budget, M.sources)  # 定义 312
        U_epi = residual_epi(d.b) if d.status in ('resolved', 'valid') else b0.epi
    # 语音动作：预合成 + 往返门 + 韵律校准，全部异步/缓存
    if d is not None and d.pending_question:
        audio, ok = tts_self_verify(d.pending_question, M.tts, M.asr, M.pum(b0))
        if not ok:
            U_epi = b0.epi                               # 问不清 = 不问
    resolved = d is not None and d.status in ('resolved', 'valid')
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + (0.0 if resolved else U_epi)))
    if slow_fault(M) or (d is not None and d.aeg_triggered):
        lam = max(lam, 0.8)                              # 回最保守
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., M.wm_preds)
    tau = M.pi_sigma.prefix_dispatch(select_mode(d.b if d else b0, ...).a[:k]) * lam
    M.vqa_v.submit_async(d, audio, U_epi)                # 验证链审计
    return k, lam, d

## 3. 推导

**引理 19（往返保真的语义盲区）** TTS→ASR 往返保真 `sim(q, q̂) ≥ 1−ε` 仅约束**信道失真**，与 q 是否指向真实模态 m* 无关：存在 q ≠ q*(m*) 使 sim(q, q̂) 任意高（例如一句语法完美、发音清晰、但指向幻影模态的问句）。故 TTS-SV 是「问清」的**必要非充分**条件：它挡住「含糊/诱导/不可懂」，**挡不住「问一个幻影」**。幻影指称由 R69 的模态校准门 MCG 与本轮的 AEG/外部接地负责。系：语音自验证只降低表达错误，不降低指称错误。

**引理 20（回音室的有效样本衰减）** 若各轮证据源两两相关 ρ̄，则 `n_eff = k/(1+(k−1)ρ̄)`，后验对数几率的每轮期望增量正比于 n_eff 而非 k。ρ̄→1 时 n_eff→1：重复同一自指通道 k 次，验证等效于 1 次。故「多问几遍」若同源，只增加自信、不增加信息——这正是回音室。定义 318–319 把它变成结构约束而非劝告。

**定理 18（anytime-valid 决议）** 在 H0（真实模态不在候选集，或问句非信息性）下，采用定义 314 的几何 α-spending 与可选停止，`P(在任意停止时间作出错误决议) ≤ Σ_r α_r = α`。证明：每个 α_r 下 P(E_r ≥ 1/α_r) ≤ α_r E[E_r] ≤ α_r（Markov + 鞅性），再对 r 取并集界。⇒ R69 的「k 源一致」启发式升级为**对自适应停止有效的**错误控制；「验到满意为止」在统计上被禁止。

**命题 1（外部接地不可省）** 纯自指验证（只用自身模型 / TTS / ASR）可达信息量上界为 `I(M; self) + I(M; b_0)`，与真值无关。若 M 的真实身份不由 self 通道决定，则错误决议概率不随轮数趋于 0：存在 δ>0，使 ∀R, P_err ≥ δ。⇒ 必须在某轮引入外部源（人 / 离线标定 / 异质传感器），否则迭代只是自我确认。这为定理 18 中 H0 的可检验性提供了前提。

**定理 19（ECHO 严格包含 FLUID / R68）** 当 R_max=1、TTS-SV 平凡通过、AEG 不触发、α 取 R69 等价阈值时，ECHO 与 FLUID 逐指令相同（因 IVL 退化为单次 MINT）；验证未决议/停滞/证书无效时回到 R69；命中克隆/投毒时比 R69 多冻结一个冷却窗。故安全侧单调不弱于 R69，效率侧仅在「anytime-valid 决议」成立时才取得 resolution bonus。

**引理 21（韵律校准的收益与可伪造性）** 当韵律-置信校准使听者主观置信满足 ECE_prosody ≤ τ_p 时，误读「确定/不确定」导致的错误动作率下降；但 r_pro 可由语音克隆/合成伪造（对抗韵律），故 r_pro **只能作辅助源**，其权重被反欺骗分 S_asv 门控：S_asv < τ_s 时权重置零。系：语音既是验证通道也是攻击面，收益与风险同源。

## 6. 本轮最大风险

**一句话**：迭代验证把「问一次」变成「问很多次」，若这些轮次共享同一条自指通道（自己的模型 / TTS / ASR），验证只会**单调放大初始信念**——**问得越多，错得越自信**；语音合成让这个陷阱更隐蔽，因为「问得清楚、答得流畅、韵律自信」全都像证据，却只证明**自洽**、不证明**问对**。ECHO-RAS 的最大风险不是问错一次，而是**把回音室误认为收敛**。

**次级风险与缓解**：
1. **可选停止膨胀错误率** → anytime-valid e-value + 几何 α-spending（定理 18）；
2. **语音克隆/重放/对抗韵律** → 反欺骗分 S_asv 门控 + r_pro 仅作辅助源 + ℰ_echo 对抗训练；
3. **TTS 延迟进关键路径** → 预合成缓存 + 异步复核 + 定义 321 硬约束；
4. **回滚被滥用或隐瞒** → VQAuditor-V 审计回滚链 + 证书含 stopping_time/alpha_spent；
5. **验证协议被对手学习 gaming** → 随机化验证策略 + 强制外部接地（命题 1）。

def iterative_verification(b0, budget, sources, alpha=0.05):
    b, used, E, spent, hist = b0, set(), 1.0, 0.0, [b0]
    for r in range(R_MAX):
        a_r = alpha * 2.0 ** (-(r + 1))
        g = argmax_gain(sources, b, used, kappa=independence)
        if g is None:                          # AEG：无正交源 → 停
            break
        y = execute_certified(g)
        b_new = bayes(b, y); E *= likelihood_ratio(y, top2(b))
        hist.append(b_new); used.add(source_of(g)); spent += cost(g)
        if b_new.top_conf >= 1 - a_r:          # 决议
            return Decision(b_new.argmax, E, r, 'resolved')
        if b_new.top_conf < EPS_REJ:           # 证伪 → 回滚

        if stagnation(hist, 2) or spent > budget:
            break
        b = b_new
    return Decision(None, E, r, 'undecided')   # → R69 保守兜底

## 4. 推导

**引理 19（往返保真的语义盲区）** `sim(q,q̂) ≥ 1−ε` 只约束信道失真，与 q 是否指向真实模态 m* 无关；存在指向幻影的 q 使往返保真任意高。故 TTS-SV 是「问清」的必要非充分条件，挡不住「问一个幻影」——后者靠 MCG + AEG + 外部接地。

**引理 20（回音室有效样本衰减）** 两两相关 ρ̄ 的 k 个源满足 `n_eff = k/(1+(k−1)ρ̄)`；ρ̄→1 ⇒ n_eff→1。重复同源自验证只增自信、不增信息。定义 318–319 把它变成结构约束。

**定理 18（anytime-valid 决议）** 几何 α-spending + 可选停止下，`P(错误决议) ≤ Σ_r α_r = α`（Markov + 鞅性 + 并集界）。R69 的「k 源一致」由此升级为对自适应停止有效的错误控制。

**命题 1（外部接地不可省）** 纯自指验证的信息上界为 `I(M; self)+I(M; b_0)`，与真值无关；若真身份不由 self 通道决定，则错误决议概率不随轮数趋于 0。必须在某轮引入外部源，否则迭代只是自我确认。

**定理 19（ECHO 严格包含 FLUID/R68）** `R_max=1 ∧ TTS-SV 平凡通过 ∧ AEG 不触发` 时逐指令等于 FLUID；未决议/停滞/证书无效回 R69；命中投毒/克隆再加冷却窗。安全侧单调不弱于 R69。

**引理 21（韵律校准的收益与可伪造）** ECE_prosody ≤ τ_p 降低「确定/不确定」误读导致的错误动作；但 r_pro 可被克隆/合成伪造，故仅作辅助源，权重受 `S_asv ≥ τ_s` 门控，否则置零。

## 7. 本轮最大风险

**一句话**：迭代验证把「问一次」变成「问很多次」，若这些轮次共享同一条自指通道（自己的模型 / TTS / ASR），验证只会**单调放大初始信念**——**问得越多，错得越自信**；语音合成让陷阱更隐蔽，因为「问得清、答得流畅、韵律自信」全都像证据，却只证明**自洽**、不证明**问对**。ECHO-RAS 的最大风险不是问错一次，而是**把回音室误认为收敛**。

**次级风险与缓解**：可选停止膨胀错误（anytime-valid e-value + 几何 α-spending，定理 18）；语音克隆/重放/对抗韵律（S_asv 门控 + r_pro 仅辅助 + ℰ_echo 对抗训练）；TTS 延迟进关键路径（预合成缓存 + 异步 + 定义 321）；回滚滥用/隐瞒（VQAuditor-V 审计 + 证书含 stopping_time/alpha_spent）；协议被学习 gaming（随机化验证策略 + 强制外部接地，命题 1）。
