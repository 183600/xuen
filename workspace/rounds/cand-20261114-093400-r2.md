# 第 73 轮（承接第 72 轮「EMBODIED-GAUGE-RAS」IP-287~294；灵感驱动研究循环第 2 轮；本轮灵感：「嵌入式系统」×「移动操作」）

> R72 把测量链从「认知层算法」推进到「具身闭环」：REG 调度契约、意图隐变量、灵巧手接触计量、三层反作用、S2R-UQ、三域分离。R72 的定理很漂亮，但它默默依赖了两个从未写进假设的工程前提：
> - **算力无限假设**：REG 跑在 Linux + ROS 2 + DDS 上，允许动态分配、float64、持续供电、风扇散热；「控制环 1kHz」默认有一个不受能量约束的 X86/AGX。
> - **世界静止假设**：所有坐标系固定，底座不动，base-arm 标定是常量，时间同步是零误差；「接触」只发生在手上。
>
> 但在真实移动操作机器人上，这两个前提**同时失效**：安全关键的控制/稳定/看门狗跑在 **KB 级 RAM、无 MMU、可能无 FPU 的 MCU** 上；而 manipulation 发生在 **一个每秒都在漂、会打滑、会腾空、电池会掉、芯片会热降频的移动底座** 上。R72 的证书在「大电脑 + 固定底座」成立，不等于在「小芯片 + 移动底座」成立。
>
> 本轮两个灵感正好补两块：
> - **嵌入式系统**：把「计量审计」下沉到**资源受限、定点运算、能量受限、失效可注入**的执行体；量化误差、pWCET、能量预算、MPU 隔离、锁步核、安全启动不再是实现细节，而是**证书的一部分**。
> - **移动操作**：把「世界状态」扩展到**带不确定度的坐标系图**；把「底座接触/打滑/稳定性」纳入接触计量；把「把底座停在哪」升级为**主动测量动作**；把「边移动边操作」的 ego-motion 失真纳入观测模型。
>
> 核心命题：**不再只问「测量链在 ROS 实时调度下、面对意图模糊的人、用灵巧手触摸世界时能否兑现风险界」，而问「当这条测量链被压进一块只有几百 KB 内存、靠电池供电、会热降频的 MCU，并装在一个正在移动、会打滑、坐标系每秒都在漂的底座上时，它还能逐指令兑现风险界吗？」** 把 R72 的 EMBODIED-GAUGE-RAS 下沉/外扩为 **EM²-GAUGE-RAS**（Embedded-Mobile, Metrologically-valid, Energy-aware, …）：**嵌入式 × 移动操作 × 计量审计闭环**。

## 0. 直觉与动机（先直觉，后定义）

**直觉 1（嵌入式 → 每一个比特、每一焦耳、每一微秒都是安全预算）**
R72 说「控制环 WCET ≤ 1ms」。在 MCU 上，这句话不是一个性能数字，而是三件事的乘积：**指令周期 × 缓存/Flash 等待状态 × 中断/DMA 争用**。更致命的是，MCU 通常**没有 FPU**，belief 必须定点化；定点化的舍入误差会沿 BSE→λ→控制律一路传播。**如果量化误差把 λ 向下舍入，安全侧就被悄悄削减了**。同理，电池电压下降会让 DVFS 降频 → pWCET 变化 → deadline 风险；热降频会让「昨天验证过的 WCET」今天失效。**「算得动」不是性能问题，是安全问题。**

**直觉 2（定点不是浮点的近似，定点是另一套计量体系）**
直觉上大家会把 `float64` 换成 `Q16.16` 然后祈祷。严谨做法是：belief、协方差、λ 全部用**区间表示 + 外向舍入（outward rounding）**。每一次加法向下取 lo、向上取 hi；每一次乘法按四个端点组合取极值；每次除法、开方都朝保守方向膨胀。这样得到的是 **λ 的保守上界**，而不是「大概差不多」。**关键哲学**：量化不确定度不是「世界的不确定度」，而是「**我们对世界的不确定度估计本身的不确定度**」；但它必须和世界不确定度一样进 λ 分母，否则系统会「因为算不准而显得很确定」。

**直觉 3（移动操作 → 标定不是常量，标定是持续估计的随机过程）**
固定底座上，base-arm 标定是出厂一次的表；移动底座上，它是**每时每刻都在漂的随机过程**：轮式编码器打滑、腿部触地冲击、IMU 零偏、激光/视觉定位跳变、时间戳错位。一个具体数量级：底座 0.5 m/s、时间同步误差 20 ms ⇒ **1 cm 空间误差**，与灵巧抓取的容差同量级。更隐蔽的是**杠杆放大**：底座 0.3 rad/s 的角速度误差 × 0.8 m 臂展 ⇒ 末端 2.4 cm/s 的伪运动。**R72 把 u_tac 分解成四分量，却把 u_frame 当成了 0。**

**直觉 4（移动操作 → 底座停在哪，是一个主动测量动作）**
移动操作不只是「走过去 + 伸手」。底座位置同时决定：**(i) 可观测性**（视角、遮挡、双目基线）；**(ii) 可达性**（工作空间、奇异位形）；**(iii) 稳定性**（支撑多边形、CoM 投影）；**(iv) 运动风险**（地面材质、坡度、动态障碍）。所以 base placement 不是导航的子问题，而是 **VoI 意义下的主动测量 + 风险塑形动作**：换一个站位，可能信息增益翻倍、也可能翻车。必须把它放进与「问人」「伸手」同一层级的动作空间。

**直觉 5（移动操作 → 底座接触是第二类接触，稳定性是硬否决）**
灵巧手的接触模式是 free/sticking/sliding/rolling/breaking；移动底座的接触模式是 **stuck/rolling/slipping/airborne/impact**。轮子打滑会**同时**破坏定位（frame 漂移）与稳定（侧翻），腿式底座腾空会造成 instantaneous CoM 失稳。这里有一个和 R71/R72 一脉相承的结论：**稳定性裕度 m < m_min 是硬否决，不能被任何信息增益补偿**——就像 R71 的非补偿性安全否决。**信息再多也不能阻止翻倒。**

**直觉 6（嵌入式 → 机器人自身资源是第四层反作用）**
R72 有 L1 情感、L2 意图、L3 接触。嵌入式引入 **L4 自身资源**：电量、温度、可用内存、故障计数。低电量 → 计量频率下降 → 后验熵上升 → λ 上升 → 动作变保守；热降频 → pWCET 变长 → 控制余量变小 → 必须降级。这是**反作用**：机器人对自己资源状态的反应，会改变它获取证据的能力，从而改变它对世界的判断。**「省电」和「安全」不是两个目标，是同一个预算的两个投影。**

**直觉 7（两灵感相乘 → 资源约束放大空间不确定性）**
单独看，量化误差很小（Q16.16 下 ~1e-5）；单独看，时间同步误差很小（20 ms）。但**在移动中它们相乘**：速度越快，同样的时间误差 → 越大的空间误差；算力越紧，越倾向降低计量频率 → 越大的后验熵 → 越依赖陈旧的 frame → 更大的 u_frame。**「省算力」和「动得快」会联合把系统推向「高置信地错」。** 这正是本轮要防的。

## 1. 形式化定义（增量：定义 366–384）

**定义 366（EM²-GAUGE-RAS 总览）** EM²-GAUGE-RAS = (EML, FRAME, MBM, EREFLEX-L4, REG-M, EMBODIED†)。六不变式：
(i) **硬软核分离契约（HS-split）**：硬实时核 `core_h` 只运行确定性代码（控制、稳定性否决、看门狗、熔断），无缓存/TCM/锁步/静态分配；软实时核 `core_s` 运行 BSE/IRL/DMEM/FRAME/证书组装；两核只经**共享内存 seqlock + CRC + 序列号**通信；
(ii) **定点计量完整性**：每个 belief、协方差、λ 都携带区间 `[lo, hi]` 与外向舍入证明；任何可能影响安全侧的比较必须用保守端点；
(iii) **坐标系计量完整性**：每条测量携带 **frame path**、SE(3) 右不变协方差、时间戳、有效期域；
(iv) **移动稳定性否决**：稳定性裕度下界 `m_lo` ≥ m_min 是硬约束，非补偿性，不进入 VoI 交换；
(v) **四级反作用预算**：`Σ(c^ψ+c^z+c^c+c^r) ≤ B_total`，且四层稳态集全满足；
(vi) **严格逐指令退化链**：资源/量化/坐标系/稳定性任一失效，逐级退化到 R72→R71→R68，安全侧只增不减。

**定义 367（定点区间信念 Q-Belief）** belief 用概率或 log-odds 的区间 `b^± = [b_lo, b_hi]` 表示，底层为定点 `Qm.n`。每个基本运算 `⊕` 定义为区间扩张且**外向舍入**：
`[a_lo,a_hi] ⊕ [b_lo,b_hi] = [rd(a_lo⊕b_lo), ru(a_hi⊕b_hi)]`，其中 `rd/ru` 分别向 −∞/+∞ 取整。不确定性合成时，区间宽度 `w(b^±)=b_hi−b_lo` 满足 `w(A⊕B) ≤ w(A)+w(B)+ε_q`，`ε_q = 2^{-(n+1)}` 为单次舍入界。**λ 只用区间上界计算**：`λ^± = [λ_lo, λ_hi]`，控制使用 `λ_hi`；任何「用 λ_lo 放行」的代码路径被静态禁止。

**定义 368（量化不确定度 u_q）** 定义 `u_q := λ_hi − λ_exact` 的保守上界（可由区间传播离线标定）。它不是世界不确定度，而是**计算不确定度**。风险缩放分母扩展为
`D = U_ale + U_epi + H[b_t(z)] + u_tac + u_frame + u_q`，
并约定：`D` 的每一项都是**保守上界**（对独立失效模式取 union bound，不假定方差可相消）。**任何一项缺失都可能导致 λ 低估。**

**定义 369（EMB-REG 与分级 deadline）** REG-M = (N_h, N_s, E_hs, π, δ_h, δ_s, μ, ξ, Φ)：
- `N_h`：硬核节点（`n_ctrl`, `n_stab`, `n_wd`, `n_breaker`），`δ_h` 为**确定性硬 deadline**，WCET 由静态分析 + 测量双重给定，缓存关闭、TCM、锁步；
- `N_s`：软核节点（`n_bse`, `n_irl`, `n_dmem`, `n_frame`, `n_energy`, `n_cert`），`δ_s` 为**概率软 deadline**，pWCET 在超越概率 `10^{-9}` 下由 MBPTA 给出；
- `E_hs`：跨核边，载荷 `(payload, seq, crc, timestamp)`；写者两阶段（seq 奇偶 + CRC），读者重试到一致；
- **硬 deadline 只在硬核承诺**；软核迟到不破坏硬核，只通过 `H_inflate` 反映为 λ 上升。**「probabilistic hard real-time」是伪命题，本方案不承诺。**

**定义 370（能量-计量预算 EN-BUDGET）** 能量预算 `B_E(t)`、热预算 `B_T(t)`。每个计量动作 `g` 消耗 `e(g)` 焦耳、获得信息增益 `IG(g)`。定义**能量效率** `η_E(g) = IG(g)/e(g)`（nat/J）。调度器在 `Σe(g) ≤ B_E`、`T_core ≤ T_max` 下最大化 `Σ VoI(g)`（或按 `η_E` 贪心 + 背包）。**电量不足时降低计量频率**，并强制 `H_inflate := H[b] + ΔH_stale(Δt)`（按预测熵膨胀），保证降级是**风险单调**的（引理 35）。

**定义 371（坐标系图 FRAME）** 坐标系图 `G_F = (V_F, E_F)`，节点 `V_F = {W, M, O, B, A, E, X, C, T}`（世界/地图/里程计/底座/臂/末端/物体/相机/触觉）。每条边 `(i,j)` 携带 `T_ij ∈ SE(3)`、右不变协方差 `Σ_ij`、时间戳 `t_ij`、有效期域 `D_ij`。测量 `y` 在坐标系 `f` 下表达，必须沿一条 frame path 组合到 `W`，并给出**组合协方差上界**。**frame path 的有效性、时间戳、协方差三者缺一，测量不得进入 BSE。**

**定义 372（frame 组合不确定度）** 一阶右不变组合：`T_AC = T_AB T_BC`，误差 `ξ_AC ≈ ξ_AB + Ad_{T_BC^{-1}} ξ_BC`，协方差 `Σ_AC ≈ Σ_AB + Ad_{T_BC^{-1}} Σ_BC Ad_{T_BC^{-1}}^T + O(‖ξ‖²)`。定义 frame 不确定度四分量：
`u_frame² = u_loc² + u_calib² + u_time² + u_motion²`，
其中 `u_loc` 定位/里程计漂移，`u_calib` base-arm/相机标定残差，`u_time = (|v| + |ω|·r_lever)·σ_Δt`，`u_motion` 为 ego-motion 畸变（见定义 373）。**R72 的 `u_tac` 四分量只覆盖“手内接触”，`u_frame` 四分量覆盖“坐标系”，二者不可互相替代。**

**定义 373（ego-motion 条件观测与空间陈旧）** 观测模型扩展为 `p(y | s, v, ω)`：运动模糊、卷帘快门、点云去畸变残差都依赖 `(v,ω)`。定义**空间陈旧寿命** `L(y) = ℓ_tol / (|v| + |ω|·r_lever + ε)`：当 `Δt > L(y)` 时，该观测自动失效，不再参与后验。这防止「用 50 ms 前的 frame 做一个 20 ms 内必须完成的抓取」。

**定义 374（移动底座接触模式与稳定性）** 底座接触模式 `c_b ∈ C_b = {stuck, rolling, slipping, airborne, impact}`，条件证据 `p(y_base | s, c_b)`（轮编码器 vs IMU vs 视觉里程计/腿关节力矩）。**稳定性裕度** `m(q, m_p) = ` CoM 投影到支撑多边形边界的带符号距离，`m_p` 为负载质量。考虑负载不确定度 `u_payload`，使用**下界** `m_lo = m(q, m_p^{upper})`。硬否决：`m_lo < m_min ⇒ 立刻停止臂运动、冻结底座、进入 base re-placement`。**不进入 VoI、不可补偿。**

**定义 375（底座放置作为主动测量动作）** 动作空间扩展为 `A = A_arm × A_base × A_query`。底座候选 `g_b ∈ SE(2)` 的效应：改变可观测性（视角/遮挡/基线）、可达性（工作空间/奇异）、稳定性（支撑多边形）、运动风险（地面/坡度/障碍）。`g_b` 与手臂动作、主动提问**同级**进入 VoI 竞争。

**定义 376（L4 自身资源反作用）** 资源状态 `r_t = (E_bat, T_core, M_free, n_fault)`，动力学 `r_{t+1} = T^r(r_t, load_t)`；成本 `c_reflex^r = α_E·ΔE + α_T·max(0,T−T_soft) + α_M·max(0,ε_M−M_free) + α_F·n_fault`。稳态集 `R_safe = {E_bat ≥ ε_E, T_core ≤ T_max, M_free ≥ ε_M, n_fault ≤ ε_F}`。**L4 越界 ⇒ 降计量频率；降到下限仍越界 ⇒ 退化为 R72 固定底座假设不可用的最小安全形态（R68 硬核）。**

**定义 377（四级反作用预算）** `C(n) = Σ_{t≤n}(c^ψ_t + c^z_t + c^c_t + c^r_t) ≤ B_total(ψ_0,z_0,c_0,r_0)`；各层稳态集 `Ψ_safe, Z_safe, C_safe, R_safe` 全满足。任一层越界 ⇒ E-IVG† 降级。**注意：L4 是唯一会“主动降低计量能力”的层，因此它必须与 `H_inflate` 联动，否则越省电越自信。**

**定义 378（EM²-VoI：含底座放置与能量效率）**
`VoI^{EM²}(g) = c(ψ)·IG_s + η·IG_z + ζ·IG_frame − (c^ψ+c^z+c^c+c^r) − γ·E[L_future]`，
约束 `λ^±` 上界、`m_lo ≥ m_min`、`Σe ≤ B_E`、四层稳态。选择 `g* = argmax VoI^{EM²}`；当 `VoI^{EM²} ≤ 0` 或 `η_E(g) < η_min` 时停止/降级。`IG_frame` 是「选择该站位/该视角带来的坐标系与物体位姿信息增益」。

**定义 379（EM²-RISK）**
`λ = max( risk_scale(U_ale, U_epi, H_z, u_tac, u_frame, u_q),
          λ_floor(U_ale+U_epi+H_z+u_tac+u_frame+u_q) )`，
所有项取**保守上界**，`H_z` 在低计量频率下用 `H_inflate`。**稳定性不进 λ，而是独立硬否决**——因为「多一分保守的软阻抗」无法防止翻倒，只有「不执行」可以。

**定义 380（E-MIB† 指标扩展）** 在 R72 E-MIB 上新增：
- **嵌入族**：量化区间宽度、`λ_hi−λ_exact`、pWCET 分位、energy/nat、热降频次数、MPU 违规次数、CRC 重试率；
- **坐标系族**：`tr(Σ_frame)`、时间戳偏差、NEES 一致性、frame path 失效率、空间陈旧丢帧率；
- **移动族**：滑移检出率/延迟、稳定性裕度最小值、负载估计误差、底座放置后的 IG/风险比；
- **耦合族**：速度 × 时间误差的交互项、低电量 × frame 漂移的联合压力指标。
所有指标同遵循定义 332 六元组与定义 333 DAG 分层。

**定义 381（E-IVG† 门控）** 新增失效条件：
- 嵌入：`u_q > τ_q`、pWCET 超越概率超限、energy/nat < η_min、MPU/CRC 异常、热降频导致 `δ_h` 余量 < 0；
- 坐标系：`tr(Σ_frame) > τ_frame`、时间戳偏差 > τ_t、NEES 越界、frame path 断裂；
- 移动：`m_lo < m_min`、滑移检出延迟 > τ_slip、负载估计误差 > τ_payload；
- 耦合：速度超 `v_safe(u_frame, σ_Δt)`。
任一致命项 ⇒ **硬否决或逐级降级**：稳定性/时序 ⇒ R68 硬核；坐标系 ⇒ 用局部 frame 或退 R72；量化 ⇒ 提高定点位宽或降级到 R71；能量 ⇒ 降计量频率。

**定义 382（EM² 证书 J_EM²）** `J_EM² = (J_EMB, qmet_proof, pwcet_evidence, energy_ledger, frame_graph_hash, stability_trace, boot_chain, emv)`。Valid ⇔ `Valid(J_EMB)` ∧ 量化区间证明有效 ∧ pWCET 在声明超越概率内 ∧ 能量账本闭合 ∧ frame 图哈希匹配 ∧ 稳定性全程 `m_lo ≥ m_min` ∧ 安全启动链完整。

**定义 383（威胁模型 AIC-EM²）** `ℰ_EM² = ℰ_EMB × ℰ_emb × ℰ_frame × ℰ_mobile`：

```python
# IP-295 Q-BELIEF：定点区间信念 + 外向舍入（硬核/软核共用，纯函数、无分配）
@dataclass(frozen=True)
class Ival:
    lo: float; hi: float                       # 已按 Qm.n 量化
    def __add__(self, o): return Ival(rd(self.lo + o.lo), ru(self.hi + o.hi))
    def __mul__(self, o):
        ps = (self.lo*o.lo, self.lo*o.hi, self.hi*o.lo, self.hi*o.hi)
        return Ival(rd(min(ps)), ru(max(ps)))
    def __truediv__(self, o):                  # 保守：拒绝跨越 0 的除数
        assert not (o.lo <= 0.0 <= o.hi), "division by interval containing 0"
        ps = (self.lo/o.lo, self.lo/o.hi, self.hi/o.lo, self.hi/o.hi)
        return Ival(rd(min(ps)), ru(max(ps)))

def belief_update_q(prior: Ival, lik: Ival) -> Ival:
    unnorm = prior * lik                      # 外向舍入已含 ε_q
    z = unnorm + Ival.EPS                      # 防止下溢为 0
    return unnorm / z                          # 结果仍是区间

# IP-296 EMB-REG：硬/软核分级 deadline 验证（部署期）
def verify_reg_m(contract) -> bool:
    # 硬核：确定性 WCET（无缓存、TCM、锁步）+ 中断预算
    if not static_wcet(contract.N_h) <= contract.delta_h: return False
    # 硬核内存全静态、无堆、MPU 分区隔离
    if any(n.alloc != 'static' for n in contract.N_h): return False
    # 软核：pWCET 超越概率 ≤ 1e-9（MBPTA）
    if contract.pwcet_exceedance(contract.N_s) > 1e-9: return False
    # 跨核：仅 seqlock+CRC+seq，无跨核锁、无跨核动态分配
    if any(e.kind != 'seqlock' for e in contract.E_hs): return False
    return contract.proof_hash == hash_proof(contract)

# IP-297 EN-BUDGET：能量感知计量调度（软核）
def schedule_metrology(actions, B_E, B_T, vois, energies):
    # 0/1 背包 + VoI 门槛 + energy/nat 下限；返回本周期允许的计量动作
    cand = [(g, vois[g], energies[g]) for g in actions
            if vois[g] > 0 and energies[g] <= B_E
            and energies[g]/max(vois[g], EPS) <= 1/ETA_MIN]
    return knapsack(cand, B_E, B_T)            # 超预算的 g 被省略 -> H_inflate

def inflate_entropy(H, dt, rate_upper):
    return H + rate_upper * dt                 # 未测量期间的预测熵膨胀

# IP-298 FRAME：坐标系组合（右不变，一阶 + 二阶上界）
def compose_frame(T_AB, S_AB, T_BC, S_BC, dt_AB, dt_BC, v, w, r_lever):
    T_AC = T_AB @ T_BC
    Ad   = adjoint(inv(T_BC))
    S_AC = S_AB + Ad @ S_BC @ Ad.T + second_order_bound(T_AB, T_BC)
    u_time = (abs(v) + abs(w)*r_lever) * (dt_AB + dt_BC)
    u_motion = motion_distortion_bound(v, w, shutter)
    return Frame(T=T_AC, Sigma=S_AC,
                 u_frame=sqrt(trace(S_AC) + u_time**2 + u_motion**2),
                 t=max(dt_AB, dt_BC), valid=(u_time < U_TIME_MAX))

# IP-299 MBM：移动底座接触模式 + 稳定性（硬核）

    m_p_up = payload_mu + 1.645*sqrt(payload_var)      # 保守上分位

                     veto=(m_lo < M_MIN or slip_p > TAU_SLIP_BASE))

# IP-300 BPLACE：底座放置作为主动测量（软核）
def base_placement_voi(b_t, frame_graph, candidates, budget):

    for g_b in candidates:
        ig_f = expected_frame_info_gain(frame_graph, g_b, b_t)
        r_m  = motion_risk(g_b) + stability_risk(g_b, b_t.payload_up)
        cost = c_reflex_c(g_b) + c_reflex_r(g_b)
        if stability_risk(g_b, b_t.payload_up) >= M_MIN: continue   # 硬否决
        score = ZETA*ig_f - r_m - cost
        if best is None or score > best.score: best = (g_b, score)
    return best if best and best.score > 0 else None

# IP-301 L4：自身资源反作用（软核规划，硬核执行）
def self_resource_step(r, load, budget):

    cost = ALPHA_E*(r.E-r2.E) + ALPHA_T*max(0, r2.T-T_SOFT) \
         + ALPHA_M*max(0, EPS_M-r2.M) + ALPHA_F*(r2.fault-r.fault)
    if r2.E < EPS_E or r2.T > T_MAX or r2.M < EPS_M:
        return r, None, cost                                 # 拒绝高耗计量
    return r2, cost, cost
```

## 3. 推导

**引理 33（外向舍入 ⇒ λ 保守）** 若 belief/协方差/λ 的每一步都用区间扩张 + 外向舍入，且 `λ` 对每个不确定度分量单调非减，则 `λ_hi ≥ λ_exact`。证明：区间算术的包含单调性（inclusion isotonicity）保证真值落在区间内；外向舍入只扩大区间；单调性保证端点运算不改变方向。系：**量化误差不会让系统「显得更确定」；唯一代价是保守性（λ 略大、动作略软），这正是安全侧该付的价。** 注意：区间比较必须保守（当区间重叠时取「不确定」分支，禁止乐观放行）。

**引理 34（frame 时间分量的杠杆放大与不可忽略性）** 设时间同步误差 `σ_Δt`，底座线速度 `v`、角速度 `ω`、杠杆 `r`。则一阶空间误差下界 `u_time ≥ (|v|+|ω|r)σ_Δt`。取 `v=0.5 m/s, ω=0.3 rad/s, r=0.8 m, σ_Δt=20 ms`，得 `u_time ≥ (0.5+0.24)·0.02 ≈ 1.48 cm`，与灵巧抓取容差同量级。系：**R72 把 `u_frame` 当 0，在移动底座上是系统性低估；且误差随速度线性增长，速度越快越不能「用旧帧」。**

**引理 35（能量降级 ⇒ 风险单调）** 设计量频率下降为 `1/k`，两次测量间 posterior 熵按 `H_inflate = H + ρ·Δt` 膨胀（`ρ` 为预测熵增上界）。若 λ 对 `H` 单调非减，则降级后 `λ_hi` 不小于全速计量时的 `λ_hi`。证明：未测量期间信息不增 ⇒ 真熵不减；用 `H_inflate` 覆盖上界 ⇒ λ 上界不减。系：**「省电」不会偷偷降低安全裕度，只会让动作更保守——这是嵌入式降级的可证明安全性。** 前提是必须真的做 `H_inflate`，否则降级会变成「自信地饿着」。

**引理 36（底座放置 VoI 的有限性与可观测性）** 设每次 base placement 的边际 `IG_frame` 非增、运动/稳定成本有正下界 `ε_m`，则存在有限 `n*` 使第 `n*+1` 次放置的净 VoI ≤ 0。又因 `IG_frame` 在视角/基线上严格凹（观测 Fisher 信息对基线），存在唯一最优邻域；贪心 + 局部精化达到 `1−1/e` 近似。系：**「停在哪」可以在有限步内决定，不是无限搜索。** 但该凹性依赖传感器模型，分布外需保守回退。

**引理 37（稳定性否决的非补偿性）** 若 `m_lo < m_min`，则存在翻倒轨迹使后续任何动作都无法完成；信息增益只能改变 belief，不能改变已发生的动力学。故对任意 `IG`，`VoI(执行 | m_lo<m_min) = −∞`。系：**稳定性是 lexicographic 安全约束，与 R71 的非补偿性否决同构。** 任何把它塞进 λ 的「软化」做法都是错的。

**定理 27（EM² 严格包含与退化等价）** 在 A111–A116（硬核静态 WCET 成立、区间运算保守、frame 协方差上界有效、稳定性裕度可计算、能量账本闭合、反作用 Lipschitz）下，EM² 在定义 384 的每个退化条件下逐指令等于 R72/R71/R68；且对任意有效执行，风险界 ≤ R72 风险界。**安全单调不减，效率仅在「核可信、坐标系可计量、能量充足、底座稳定」时获益。**

**定理 28（J_EM² 有效性 ⇒ 物理安全）** 若一次执行通过 J_EM²，则 (i) 硬核 WCET ≤ δ_h ⇒ 控制/稳定/看门狗时序安全；(ii) 区间 λ_hi 保守 ⇒ 风险缩放不会低估；(iii) frame 协方差上界覆盖真实误差（声明置信度内）⇒ 位姿组合不下穿；(iv) `m_lo ≥ m_min` 全程成立 ⇒ 无翻倒；(v) 能耗降级满足引理 35 ⇒ 低电量仍保守；(vi) `J_EMB` 有效 ⇒ R72 层结论。综上，物理执行风险 ≤ ε_em²（相对**嵌入式 + 移动 frame** 测量模型）。**证明重量落在：硬核 WCET 的静态分析是否覆盖硅片实测、frame 协方差上界是否在分布外仍成立、以及故障注入是否会跳过区间检查。**

**定理 29（HS-split 无跨核干扰）** 硬核与软核物理隔离（不同核/不同时钟域/MPU 分区），跨核仅 seqlock 共享内存 + CRC + 序列号；硬核从不获取跨核锁、从不等软核、从不动态分配。由 seqlock 的无锁读者协议，**硬核读取要么得到一致版本、要么重试有限次后使用上一版**，不存在优先级反转、不存在死锁、不存在无界重试（重试上限静态给定，超限即用旧版并记录）。**硬核控制环永远在 δ_h 内完成。**

**定理 30（四级预算的有限停止与无计量饥饿）** 能量严格单调递减（`e(g)>0`），边际 VoI 非增，故存在有限步后 `VoI ≤ 0` 或 `B_E` 不足以支持任何 `η_E ≥ η_min` 的计量动作；此时算法停止计量并进入保守降级，**不会无限期「再测一次」**。系：**「何时停测」与 R72 的「何时停问」共享同一个有限停止结构，只是预算从反作用成本换成了能量。**

**一句话**：EM²-GAUGE-RAS 把安全从「相信调度契约与计量证书」进一步转移到「相信 **量化区间在硅片上真的保守**、**frame 协方差上界在分布外真的有效**、**稳定性裕度在负载/地面突变时真的算对**」——**如果编译器/FPU 仿真把外向舍入优化掉（`-ffast-math` 一类的语义漂移）、或者外参慢漂移制造出「NEES 看起来很好」的一致性假象、或者地面材质突变让 `slipping` 概率在 20ms 内从 0.01 跳到 1 而稳定性裕度已经来不及重算，系统就会拿着一份「每一层都通过、每个区间都保守、每次启动都验签」的证书，在移动中捏碎物体或翻倒；事后审计发现「所有指标当时都在声明的有效域内」——这就是**嵌入式 + 移动操作层面的「自信地错自己的可计算性与可移动性」**。**

次级风险与缓解：
1. **量化保守性被编译器破坏** → 证书携带编译标志与算术语义哈希；关键路径用**整数/定点参考实现**做差分测试；禁止 `-ffast-math`，CI 静态检查。
2. **frame 上界在分布外失效** → 分段/分位数协方差 + 外参在线自标定 + **保守膨胀因子**；SEAL-Frame 隐藏跨地面/跨光照场景，在线只看通过位。
3. **稳定性裕度算错** → 硬核独立实现 + 冗余 IMU/关节力矩交叉校验；`m_lo` 用最坏负载上分位 + 冲击动力学上界；越界即冻结，不做「再算一次」。
4. **能量降级导致计量失明** → 强制 `H_inflate`；低电量时优先保留「稳定性 + frame 自检 + 意图校准」三条最小计量链。
5. **跨核共享内存撕裂** → seqlock + CRC + 序列号 + 有限重试；硬核超限用旧版并记录，禁止无界等待。
6. **故障注入跳过检查** → 区间检查双份（硬核/锁步）+ 控制流完整性 + 代码 CRC + 安全启动；毛刺检测器独立供电域。
7. **复杂度爆炸** → 模块上限：`|V_F|≤16`、`|C_b|≤5`、`|G_b|≤12`、`|A|≤32`；每个 veto 一条可复算证明；复杂度本身纳入审计。

**定义 370（EN-BUDGET）** 能量/热预算下最大化 `ΣVoI`，按 `η_E` 门槛筛选；省略的计量动作强制 `H_inflate`，使降级风险单调（引理 35）。

```python
@dataclass(frozen=True)
class Ival:
    lo: float; hi: float
    def __add__(self, o): return Ival(rd(self.lo+o.lo), ru(self.hi+o.hi))
    def __mul__(self, o):
        p = (self.lo*o.lo, self.lo*o.hi, self.hi*o.lo, self.hi*o.hi)
        return Ival(rd(min(p)), ru(max(p)))
    def __truediv__(self, o):
        assert not (o.lo <= 0 <= o.hi)
        p = (self.lo/o.lo, self.lo/o.hi, self.hi/o.lo, self.hi/o.hi)
        return Ival(rd(min(p)), ru(max(p)))

        te = M.dmem.update(tac, M.last_action)
        fr = M.frame.compose_path(obs.path, obs.stamp, M.v, M.w)
        gate = M.e_ivg2.check(b, z, te, fr, base)
        if not gate.valid: M.mode = gate.fallback; M.registry.freeze(gate.reason)
        gb = M.bplace.choose(b, fr, M.base_candidates, M.budget)
        if gb: M.nav.plan(gb)
        M.shm.write_seq_crc(b, z, fr, te, base)
        M.cert_s.append(J_EM2(M))
    return k, lam, J_EM2(M)
```

## 4. 推导

**引理 33（外向舍入 ⇒ λ 保守）** 区间包含单调 + 外向舍入 + λ 对各分量单调非减 ⇒ `λ_hi ≥ λ_exact`。区间比较重叠时取「不确定」分支，禁止乐观放行。系：量化只增加保守性，不制造虚假确定性。

**引理 34（frame 时间分量杠杆放大）** `u_time ≥ (|v|+|ω|r)σ_Δt`；`0.5m/s, 0.3rad/s, 0.8m, 20ms ⇒ ≥1.48cm`，与抓取容差同量级。系：旧 frame 不可跨速度复用，必须用 `L(y)` 判废。

**引理 35（能量降级 ⇒ 风险单调）** 降频导致信息不增、`H_inflate` 覆盖预测熵上界 ⇒ `λ_hi` 不减。系：省电只让动作更保守；前提是必须真的 `H_inflate`。

**引理 36（底座放置 VoI 有限停止）** 边际 `IG_frame` 非增、成本有正下界 ⇒ 存在有限 `n*` 使净 VoI ≤ 0；Fisher 信息对基线/视角凹 ⇒ 局部最优邻域可达 `1−1/e` 近似。系：选位可在有限步决定。

**引理 37（稳定性否决非补偿）** `m_lo < m_min` 时存在翻倒轨迹，信息不改变动力学 ⇒ `VoI = −∞`。系：稳定性与 R71 安全否决同构，不能塞进 λ 补偿。

**定理 27（严格包含与风险单调）** 在 A111–A116 下，EM² 在定义 384 各退化条件逐指令等于 R72/R71/R68；有效执行的风险界 ≤ R72。**安全单调不减，效率仅在资源可信、frame 可计量、底座稳定时获益。**

**定理 28（J_EM² ⇒ 物理安全）** 硬核 WCET ≤ `δ_h` ∧ 区间 λ 保守 ∧ frame 协方差上界覆盖 ∧ `m_lo≥m_min` 全程 ∧ 降级风险单调 ∧ `J_EMB` 有效 ⇒ 执行风险 ≤ `ε_em²`。证明重量在：硅片实测是否落在静态 WCET 内、frame 上界是否分布外有效、故障注入是否跳过区间检查。

**定理 29（HS-split 无跨核干扰）** 物理隔离 + seqlock 无锁读者 + 有限重试（超限用旧版并记录）⇒ 无优先级反转、无死锁、无无界重试；硬核永远在 `δ_h` 内完成。

**定理 30（四级预算有限停止）** 能量严格递减、边际 VoI 非增 ⇒ 有限步后 `VoI≤0` 或 `B_E` 不支持 `η_E≥η_min`，算法停止计量并保守降级。系：与 R72「何时停问」共享同一有限停止结构。

## 7. 本轮最大风险

**一句话**：EM²-GAUGE-RAS 把安全从「相信调度契约与计量证书」进一步转移到「相信 **量化区间在硅片上真的保守**、**frame 协方差上界在分布外真的有效**、**稳定性裕度在负载/地面突变时真的算对**」——**如果编译器把外向舍入优化掉、外参慢漂移制造出 NEES 良好的假象、或地面突变让 slipping 概率在 20ms 内跃迁而 `m_lo` 来不及重算，系统就会拿着一份每层都通过、每个区间都保守、每次启动都验签的证书，在移动中捏碎物体或翻倒；事后审计发现所有指标当时都在声明的有效域内——这就是嵌入式 + 移动操作层面的「自信地错自己的可计算性与可移动性」。**

次级风险与缓解：
1. **编译器破坏量化保守性** → 编译标志/算术语义哈希进证书；整数参考实现差分测试；禁 `-ffast-math`。
2. **frame 上界分布外失效** → 分段/分位协方差 + 外参在线自标定 + 保守膨胀；SEAL-Frame 隐藏跨地面/光照场景。
3. **稳定性裕度算错** → 硬核独立实现 + 冗余 IMU/关节力矩交叉校验；`m_lo` 取最坏负载上分位 + 冲击上界；越界即冻结。
4. **能量降级导致计量失明** → 强制 `H_inflate`；低电量保留「稳定性 + frame 自检 + 意图校准」最小链。
5. **跨核共享内存撕裂** → seqlock + CRC + 序列号 + 有限重试；超限用旧版并记录。
6. **故障注入跳过检查** → 区间检查双份（硬核/锁步）+ 控制流完整性 + 代码 CRC + 安全启动 + 独立供电域毛刺检测。
7. **复杂度爆炸** → `|V_F|≤16`、`|C_b|≤5`、`|G_b|≤12`、`|A|≤32`；每个 veto 一条可复算证明。
