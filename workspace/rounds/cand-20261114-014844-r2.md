# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧闭环」IP-253~263；灵感循环第 2 轮；本轮灵感：「全身控制」×「参数高效微调」）

> R69 把不确定性一分为二，用「流匹配多模态策略 + 主动多模态交互」去追问，定位极准——不确定性可以是一句提问、一次注视、一次轻触。但它留下一个自己诊断得出、却无力修复的结构性缺口：**实时流零学习写操作**。于是问来的答案只活一个 episode，下一集同样的歧义要重新问（E297 的「交互疲劳」正是征兆）；它对自身最大风险——模态分布不可信——只能靠 MCG 门「关掉智能」来应对：**能检测自己不可信，却没有「变可信」的路径。会问，但不会记；能自检，但不能自愈。**
>
> 本轮两个灵感正好补上这两刀：
> - **全身控制**给出「把多模态参考投影进硬约束流形」的物理安全壳，并附赠一个几何对象——**认证安全零空间**：冗余自由度不是累赘，而是「可以安全地改哪里」的答案；更妙的是，很多策略歧义在任务空间里根本不可分辨，**身体自己就能消歧**；
> - **参数高效微调**给出「只在零空间里、只加秩很低的增量、可版本化、可回滚」的机制：改得少、改得可审计、改错能拔掉。
>
> 核心命题：**把 R69 的「问」升级为「问—记—长—拔」的闭环**——交互与 rollout 证据经慢环整合成冻结主干上的**低秩适配器**；适配器只允许作用在全身控制壳认证的**安全零空间**内；每次适配都过**影子验证 → 原子版本切换 → 漂移监控**，且可随时回滚到已验证的父版本。命名 **CAGE-RAS**（Certified Adaptation in a Guarded Envelope）：适配被关进一个由身体认证的笼子。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**求证之后，我能不能把答案安全地长进身体里，并且随时拔得出来**」——学习不该是全有或全无的重训，而应是一颗可以种下、也可以摘除的器官。

## 0. 直觉与动机

**灵感 1（全身控制 → 冗余是资产，不是负债）**
直觉：R69 把任务动作、注视、探针、问句拼成高维动作 $\xi=(a,g)$，却用「前缀认证 + 若不安全就整条作废」的方式处理冲突——这既浪费了信息动作，又把「物理可执行」当成事后过滤。全身控制的做法相反：把所有模态当成**参考**，交给一个按优先级分层的 QP，硬约束（关节/力矩/接触摩擦锥/自碰撞/非完整约束）放最高级，任务放中间，姿态放最低。它返回两样东西：认证后的可执行动作 $a_{exec}$，以及**剩余自由度** $\mathcal{S}_{free}$。直觉上，这就是「身体告诉你哪里可以动」。冗余不再是负担，而是自由度预算。

**灵感 2（全身控制 → 身体能免费消歧）**
直觉：R69 把「两个模态」当成必须消解的歧义。但很多模态差异只体现在零空间（比如手臂两种肘部构型、同一注视下的两种微姿态），经 WBS 投影后得到**完全相同的任务执行**——它们在物理上不可分辨，也就不需要问。R69 的 VoI 因此系统性高估了交互价值：它在一个比任务实际需要的更大的空间里统计分歧。**先让身体把「不影响任务的歧义」吃掉，再对真正可观测的分歧去问**，这是本轮最便宜的收益。

**灵感 3（参数高效微调 → 学习不是改权重，是长出一颗可拔的器官）**
直觉：R69 的「问」有去无回，根因是实时流不允许学习写操作。PEFT（LoRA：$W \to W + BA$，$r \ll \min(d,k)$）给出了另一条路：主干完全冻结——于是 R66–R69 的全部安全论证原封不动；增量是低秩的——于是存储、计算、审计都可控；适配器可以版本化、按上下文切换、正交合并、一键回滚。**学习从「重训一个黑箱」变成「加一颗可插拔、可检查、可拔除的器官」。**

**灵感 4（两者合起来 → 零空间是「可学习 / 不可学习」的分界线）**
直觉：这是本轮最重要的理论姿态。高优先级安全任务 + 硬约束构成**不可动**子空间；它们的零空间构成**可动**子空间。把低秩增量投影到认证零空间（一阶意义下 $J_{safe}G_\theta \delta\theta = 0$），就得到「只在不影响安全的地方学习」的严格版本。R68/R69 一直靠「门控 + 退避」维持的安全，在 R70 变成**结构性不越界**（到一阶）：不是「学完再检查安不安全」，而是「安全的地方才允许学」。

**灵感 5（双刃剑 → 学到的东西会被投毒，必须同轮交付）**
直觉：一旦系统能「记」和「长」，攻击面从「投毒一次回答」升级为「投毒一条证据链 / 一个适配器 / 一个零空间估计 / 一次版本回滚」。更阴险的是：单个适配器看起来无害，两个各自安全的适配器**合并**后却可能越界（组合攻击）；而如果全身模型本身就是错的，那么「认证零空间」根本不安全——**笼子建在错误蓝图上**，低秩微调会把模型误差洗成「完全合规」的行为并沿版本扩散。所以本轮必须同时交付：整合门、影子验证、组合认证、漂移/泄漏监控、原子回滚与证据纪律。否则 R70 不是让 R69 变聪明，而是给一个会问的系统装上了一条会**自我确认**的错误信念。

## 1. 形式化定义（增量：定义 310–322）

**定义 310（全身控制壳 WBS）** 状态 $q \in \mathbb{R}^n$。任务按优先级分层 $T_1 \succ \cdots \succ T_m$，其中**安全级** $T_{\le k_{safe}}$ 与硬约束 $\mathcal{C}$（关节限位、力矩上限、接触力/摩擦锥、自碰撞、非完整约束）必须满足。每个控制 tick 解分层 QP：
$$\min_{\dot q,\tau}\ \textstyle\sum_i w_i \|J_i \dot q - \dot y_i^{ref}\|^2 \quad \text{s.t. 动力学},\ \mathcal{C}.$$
逐级求解并维护零空间投影 $N_i = N_{i-1}(I - J_i^\dagger J_i)$。输出认证执行动作 $a_{exec}$、安全任务 Jacobian $J_{safe}$ 与剩余自由度 $\mathcal{S}_{free} = \mathrm{range}(N_{k_{safe}})$。

**定义 311（认证安全零空间 $\mathcal{S}_{safe}$）** 设策略对参数的 Jacobian 为 $G_\theta = \partial \pi/\partial \theta$。适配器增量 $\delta\theta$ 对高优先级任务的一阶泄漏为 $J_{safe}G_\theta\,\delta\theta$。定义
$$\mathcal{S}_{safe} = \ker(J_{safe}G_\theta),\qquad P_{safe} = I - (J_{safe}G_\theta)^{+}(J_{safe}G_\theta).$$
所有候选适配器先投影：$\delta\theta \leftarrow P_{safe}\delta\theta$。

**定义 312（低秩适配器）** 冻结权重 $W$，适配增量 $\Delta W = BA$，$B\in\mathbb{R}^{d\times r}$、$A\in\mathbb{R}^{r\times k}$、$r \ll \min(d,k)$。适配器 $a=(B,A)$；运行时**只读**，主干 $W$ 永不改写。

**定义 313（适配器银行与注册表）** $\mathcal{A} = \{a_j\}$，每个适配器带内容哈希 $\mathrm{hash}_j$、训练证据指纹、影子验证报告与父版本指针。当前激活版本 $v_t$ 在一个 episode 内**不可变**；银行容量与总秩预算有硬上限。

**定义 314（慢环整合 SCL）** 证据缓冲 $\mathcal{B}$ 收集 R69 的交互四元组 $(o_t, g, y, \hat m)$、执行结果与在线 rollout。离线/后台以流匹配损失 + 模态校准损失 + 对认证动作 $a_{exec}$ 的行为克隆损失训练低秩增量 $\delta\theta$，每步投影到 $\mathcal{S}_{safe}$，产出**候选**适配器。

**定义 315（整合门与影子验证）** 候选适配器 $d$ 只有同时满足才可提交：(i) 证据量 $\ge N_{min}$ 且去重后有效样本 $\ge n_{eff}$；(ii) 模态 ECE $\le \tau_{ece}$；(iii) 在影子场景集上硬约束违规 $=0$、泄漏 $\ell \le \varepsilon_{leak}$、成功率 $\ge$ 基线 $-\varepsilon_{perf}$；(iv) 漂移监控为绿。任一不过 ⇒ 不提交，保持当前版本并继续交互。

**定义 316（身体诱导消歧）** 模态 $m_i, m_j$ 经 WBS 映射为可达执行集 $E(m_i), E(m_j)$。若二者在任务空间上的差完全落在 $\mathcal{S}_{free}$（即任务等价），记 $m_i \sim m_j$。决策相关的不确定性只计任务不等价部分：
$$U_{epi}^{eff} = H(\tilde M),\quad \tilde M = \text{任务等价类上的模态分布},\qquad U_{epi}^{eff} \le U_{epi}.$$

**定义 317（适配器漂移/泄漏监控 ADM）** 监控指标：任务泄漏 $\ell = \|J_{safe}G_\theta \delta\theta\| / \|\delta\theta\|$、零空间裕度 $\mathrm{margin}=\sigma_{min}(J_{safe}G_\theta)$、适配器范数 $\|BA\|$、与已激活适配器的子空间主角、影子任务指标回归量。任一越阈 ⇒ 冻结当前版本、回滚到父版本、并把相关证据标脏。

**定义 318（组合认证 ACM）** 合并适配器 $\Delta W = \sum_j B_j A_j$。认证：(i) 合并泄漏 $\le \sum_j \ell_j + \text{交叉项}$，交叉项由两两子空间主角 $\theta_{ij}$ 上界（见引理 21）；(ii) 两两 $\theta_{ij} > \theta_{min}$（近似正交）或改为按上下文**串行**激活（不同时合并）。否则拒绝合并。

**定义 319（证书 J_CAGE）** $J_{CAGE} = (J_{FLUID},\ \mathrm{adapter\_version\_hash},\ \mathrm{nullspace\_fingerprint},\ \ell,\ \mathrm{margin},\ \mathrm{shadow\_report},\ \mathrm{rollback\_ptr},\ \mathrm{consolidation\_epoch})$。$\mathrm{Valid} \Leftrightarrow \mathrm{Valid}(J_{FLUID}) \wedge \ell \le \varepsilon_{leak} \wedge$ 组合认证通过 $\wedge$ 回滚指针可达已验证版本。

**定义 320（威胁模型 $\mathcal{E}_{CAGE}$）** $\mathcal{E}_{CAGE} = \mathcal{E}_{FLUID} \times \{$适配器后门/投毒, 零空间估计攻击（污染 QP 模型使「安全」子空间并非安全）, 回放/证据链投毒, 组合攻击（单安全、合并不安全）, 版本回滚攻击$\}$。并入 AIC。

**定义 321（保留不变式）** (i) 实时流只读 $v_t$，零学习写操作（继承 R68/R69）；(ii) 所有写入仅在慢环；(iii) 新版本只在 **episode 边界或显式安全态**原子切换（只换指针）；(iv) 切换前后行为差经影子验证有界 $\le \varepsilon_b$ ⇒ 控制连续、无中途突变。

**定义 322（问 vs 整合的统一预算调度）** 每轮在「交互」与「整合」间分配同一份预算账本，取
$$\max\{\,VoI(g)-c(g),\ \textstyle\sum_{\text{future}} \widehat{VoI}_{after}-\text{cost}_{consolidate}\,\}$$
较大者；第二项为**摊销 VoI（consolidation surplus）**：整合把当前证据长成先验，降低将来同类歧义的交互成本。二者互斥不可同时越预算。

## 2. 关键算法骨架

```python
# IP-264 WBS：全身控制壳（分层 QP + 认证零空间）
class WholeBodyShell:
    def solve(self, refs, q, dq):
        N, J_safe = np.eye(self.n), np.zeros((0, self.n))
        for lvl in self.hierarchy:                  # 安全 -> 平衡 -> 任务 -> 姿态
            J  = self.jacobian(lvl, q)
            dq = dq + N @ np.linalg.pinv(J @ N) @ (lvl.ref - J @ dq)
            N  = N @ (np.eye(self.n) - np.linalg.pinv(J) @ J)
            if lvl.is_safe: J_safe = np.vstack([J_safe, J])
        return self.integrate(dq), N, J_safe       # range(N) = S_free

# IP-265/266 安全零空间投影 + 版本化适配器银行
def project_to_safe(dtheta, J_safe, G_theta):
    L = J_safe @ G_theta                            # 高优先级任务泄漏算子
    return dtheta - np.linalg.pinv(L) @ (L @ dtheta)  # -> ker(L) = S_safe

class AdapterBank:
    def __init__(self, frozen_trunk): self.base, self.v, self.pending = frozen_trunk, None, None
    def activate(self, version, at_boundary):       # 定义321：只换指针
        assert at_boundary
        self.v = self.registry.get(version)
    def forward(self, x):                           # 运行时只读
        W = self.base.W
        return (W + sum(a.B @ a.A for a in self.v.adapters)) @ x
    def rollback(self, at_boundary): self.activate(self.v.parent, at_boundary)

# IP-267/270 慢环整合（离线，不在实时路径）
def consolidate(evidence, bank, shell, cfg):
    if not gate.evidence_enough(evidence): return None          # 定义315
    dtheta = train_lowrank(
        loss = fm_loss + mode_calibration_loss + bc_loss(certified_actions),
        data = evidence.replay(), freeze = bank.base)
    dtheta = project_to_safe(dtheta, shell.J_safe, bank.base.G_theta)
    cand = bank.make_candidate(dtheta)
    rep  = shadow_validate(cand, scenarios=cfg.shadow_set)
    if rep.violations == 0 and rep.leak <= EPS_LEAK and rep.perf >= base - EPS_PERF:
        return bank.commit(cand, parent=bank.v.version)         # 版本化提交
    return None

# IP-268/269 漂移监控 + 组合认证
def monitor_and_compose(bank, shell, stats):
    ell = norm(shell.J_safe @ bank.base.G_theta @ bank.v.delta)
    if ell > TAU_LEAK or stats.regression > TAU_REG:
        bank.rollback(bank.at_boundary); evidence.mark_dirty(); return None
    if len(bank.v.adapters) > 1:
        return acm.certify(bank.v.adapters, theta_min=THETA_MIN)   # 主角 + 泄漏界

# IP-273 主闭环（R69 之上加「问—记—长—拔」）
def CAGE_RAS_round(M, obs):
    # ---- 快速路：与 R69 相同，只是动作作为参考交给 WBS ----
    z, o = M.mtm.forward(...); c, U_cal, _ = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z)
    # ---- 身体诱导消歧：先扣掉不影响任务的分歧 ----
    U_epi_eff = M.wbs.task_equivalence(modes)        # 定义316，常 << U_epi
    _, N, J_safe = M.wbs.solve(modes, M.q, M.dq)
    # ---- 只对残余可观测歧义去问 ----
    g = (M.mint.choose_interaction(modes, o, M.budget)
         if U_epi_eff > TAU_EPI else None)
    answer = M.cia.execute(g) if g else None
    if answer: U_epi_eff = M.cia.update_belief(modes, answer)
    # ---- 认证执行：多模态参考 -> 硬约束可行流形 ----
    a_exec, N, J_safe = M.wbs.solve(select_mode(modes, U_epi_eff), M.q, M.dq)
    lam = max(M.efs.risk_scale(...),
              lam_floor(U_ale + (0.0 if answer else U_epi_eff)))
    # ---- 慢路：证据入库；版本只在 episode 边界原子切换 ----
    M.evidence.push(o, g, answer, modes, a_exec, J_safe)
    if M.at_episode_boundary and M.scm.ready():
        M.bank.activate(M.scm.consolidate(M.evidence, M.bank, M.wbs, M.cfg),
                        at_boundary=True)
    M.adm.check(M.bank, M.wbs, M.stats)              # 泄漏/漂移 -> 回滚
    M.vqa_i.submit_async(g, answer, U_epi_eff, a_exec, M.bank.v.version)
    return a_exec, lam, M.bank.v.version
```

## 3. 推导（增量：引理 19–21、定理 18–19；假设 A99–A101）

**A99（全身模型误差有界）** $\|\hat J_{safe} - J_{safe}\| \le e_J$，且 $e_J$ 进入泄漏上界。
**A100（证据偏移有界）** 回放证据相对部署分布的 importance weight 有界。
**A101（影子集覆盖）** 影子验证集对部署分布有覆盖（否则整合门失效）。

**引理 19（身体诱导消歧上界）** 设任务等价关系 $\sim$（定义 316）。则 $U_{epi}^{eff}=H(\tilde M)\le H(M)=U_{epi}$，等号当且仅当任意两模态均任务可分。证明：由熵的链式法则 $H(M)=H(\tilde M)+H(M\mid\tilde M)$，而任务等价类内模态对执行分布无影响，故 $H(M\mid\tilde M)\ge 0$ 且对执行无贡献。**系：机器人冗余度越大、主任务维数越低，身体免费消歧越多；R69 的 VoI 越被高估——交互应当发生在「可观测的矛盾」上，而非「空间的富余」上。**

**引理 20（零空间适配的一阶安全）** 若 $\delta\theta = P_{safe}\delta\theta$，则一阶泄漏 $J_{safe}G_\theta\delta\theta=0$。任务输出二阶展开 $y(\theta+\delta\theta)=y+J\delta\theta+\tfrac12\delta\theta^\top H\delta\theta$，故 $\|\Delta y\|\le \tfrac12 L_H\|\delta\theta\|^2$。取 $\|\delta\theta\|\le\sqrt{2\varepsilon/L_H}$ 即保证 $\|\Delta y\|\le\varepsilon$。注意：这是**局部**结论，需 A99 与重新认证，跨大范围迁移不成立。

**引理 21（适配器组合泄漏界）** 合并 $\Delta W=\sum_j B_jA_j$，泄漏算子线性。两适配器交叉项 $\le C\,\|\delta_j\|\,\|\delta_l\|\cos\theta_{jl}$，$\theta_{jl}$ 为其参数子空间主角；正交时交叉项为零。**系：组合认证应优先「近正交合并」，否则退化为上下文串行激活——绝不让两个各自安全的适配器在叠加后悄悄越界。**

**定理 18（CAGE 严格包含 FLUID）** 取空适配器银行并关闭整合，则 FMP/AUD/MINT/CIA/FMA 与 R69 逐指令一致；WBS 只把参考投影到可行集 $\subseteq$ 原动作空间，故认证执行风险不高于 R69；身体诱导消歧只降低 $U_{epi}^{eff}$ 而不改变执行。因此期望风险 $\le$ R69，且在「无冗余、无任务等价」时退回 R69 的逐指令行为。**安全侧不做任何让步，效率侧额外获得「身体消歧 + 保留学习」两项增益。**

**定理 19（安全保留：问—记—长—拔）** 在 A99–A101、零空间投影（定义 311）、整合门（定义 315）、组合认证（定义 318）、原子切换与回滚（定义 321）下：(i) 实时流零学习写不变式保持；(ii) 任一激活版本可回滚到已验证父版本；(iii) 版本间行为差 $\le\varepsilon_b$，控制连续、无中途突变；(iv) 每步整合满足不劣于基线 $-\varepsilon_{perf}$，且证据编码使未来同类 VoI 期望不增 ⇒ 累计交互成本次线性（摊销），风险增量 $\le\varepsilon$。**R70 把 R69 的「一次性追问」变为「越用越少问、但不会学坏」的闭环。**

## 6. 本轮最大风险

**一句话**：CAGE-RAS 把全部安全押在「全身控制壳所声明的认证零空间确实安全」这一前提上——**笼子是否安全，取决于画出笼子的那张蓝图**；一旦 QP 的动力学/接触/雅可比模型本身有误（或被投毒），低秩适配器就会在「已认证」的名义下把模型误差洗成看似完全合规的行为，再经版本化与组合沿时间与上下文扩散，**而这恰恰发生在系统最自信、最少交互的时候——越高效微调，越危险。**

**次级风险与缓解**：
1. **组合攻击**（单安全、合并不安全）→ 定义 318 主角/泄漏界 + 近正交或串行激活 + E306；
2. **适配器后门/证据投毒** → 整合门 + 影子验证 + 证据指纹与去重 + 定义 320 对抗训练；
3. **局部线性化的二阶越界**（大范围迁移）→ 引理 20 的范数上限 + 版本重新认证 + E303；
4. **版本膨胀与长时程漂移** → 银行容量/总秩硬预算 + ADM 回滚 + E313；
5. **慢环训练挤压资源** → 后台低优先级训练 + 仅 episode 边界提交，绝不进入实时路径。

## 2. 形式化定义（要点版）

**定义 310（WBS 全身控制壳）** 任务分层 $T_1 \succ \cdots \succ T_m$，安全级与硬约束 $\mathcal{C}$ 最高；每 tick 解分层 QP，返回 $a_{exec}$、$J_{safe}$、$\mathcal{S}_{free}$。

**定义 311（认证安全零空间）** $\mathcal{S}_{safe}=\ker(J_{safe}G_\theta)$；候选增量先过 $P_{safe}$。

**定义 312–313（低秩适配器与银行）** $\Delta W=BA$，$r\ll\min(d,k)$，主干冻结；适配器带哈希/指纹/父版本；$v_t$ episode 内不可变，银行有容量与总秩硬预算。

**定义 314–315（慢环整合与整合门）** 离线用 `fm+calibration+bc` 训练并投影；提交须过：证据量、ECE、影子零违规/低泄漏/不劣基线、监控绿。

**定义 316（身体诱导消歧）** 任务等价模态 $\sim$ 不计入决策相关不确定性；$U_{epi}^{eff}=H(\tilde M)\le U_{epi}$。

**定义 317（漂移/泄漏监控 ADM）** 监控 $(\ell,\ \mathrm{margin},\ \|BA\|,\ \theta_{ij},\ \text{regression})$，越阈冻结并回滚、证据标脏。

**定义 318（组合认证 ACM）** 合并泄漏 $\le\sum\ell_j+\text{交叉项}(\theta_{ij})$；近正交合并或上下文串行。

**定义 319–321（证书/威胁/保留不变式）** $J_{CAGE}$ 并入版本哈希与回滚指针；$\mathcal{E}_{CAGE}$ 增五类学习期攻击；实时只读 $v_t$、写只在慢环、episode 边界原子切换、版间行为差有界。

**定义 322（问 vs 整合统一预算）** $\max\{VoI-c,\ \sum\widehat{VoI}_{after}-\text{cost}_{consolidate}\}$；摊销 VoI 与交互共享预算账本。

```python
class WholeBodyShell:
    def solve(self, refs, q, dq):
        N, J_safe = np.eye(self.n), np.zeros((0, self.n))
        for lvl in self.hierarchy:                    # 安全 -> 平衡 -> 任务 -> 姿态
            J  = self.jacobian(lvl, q)
            dq = dq + N @ np.linalg.pinv(J @ N) @ (lvl.ref - J @ dq)
            N  = N @ (np.eye(self.n) - np.linalg.pinv(J) @ J)
            if lvl.is_safe: J_safe = np.vstack([J_safe, J])
        return self.integrate(dq), N, J_safe          # range(N) = S_free

    return dtheta - np.linalg.pinv(L) @ (L @ dtheta)  # -> ker(L)
```

## 4. 推导

**引理 19（身体诱导消歧上界）** 熵链式分解 $H(M)=H(\tilde M)+H(M\mid\tilde M)$；任务等价类内模态对执行无影响 ⇒ $U_{epi}^{eff}=H(\tilde M)\le U_{epi}$，等号当且仅当所有模态任务可分。系：冗余度越大，R69 的 VoI 越高估；交互应聚焦「可观测矛盾」，而非「空间富余」。

**引理 20（零空间适配一阶安全）** $\delta\theta\in\ker(J_{safe}G_\theta)\Rightarrow$ 一阶泄漏为零；二阶 $\|\Delta y\|\le\frac12 L_H\|\delta\theta\|^2$，取 $\|\delta\theta\|\le\sqrt{2\varepsilon/L_H}$ 得 $\|\Delta y\|\le\varepsilon$。局部结论，跨域需 A99 与重新认证。

**引理 21（组合泄漏界）** 合并泄漏线性可加，交叉项 $\le C\|\delta_j\|\|\delta_l\|\cos\theta_{jl}$；正交时为零。系：优先近正交合并，否则上下文串行。

**定理 18（CAGE 严格包含 FLUID）** 空银行 + 关整合 ⇒ 逐指令退化为 R69；WBS 只把参考投影进可行集，风险不增；身体消歧只降 $U_{epi}^{eff}$。故期望风险 $\le$ R69，退化边界行为一致，安全不让步、效率有增益。

**定理 19（安全保留：问—记—长—拔）** 在 A99–A101、零空间投影、整合门、组合认证、原子切换与回滚下：(i) 实时零学习写保持；(ii) 任一版本可回滚到已验证父版本；(iii) 版间行为差 $\le\varepsilon_b$，控制连续；(iv) 每步整合不劣于基线 $-\varepsilon_{perf}$，未来同类 VoI 不增 ⇒ 累计交互成本次线性、风险增量 $\le\varepsilon$。

## 7. 本轮最大风险

**一句话**：CAGE-RAS 把全部安全押在「全身控制壳所声明的认证零空间确实安全」这一前提上——**笼子是否安全取决于画出笼子的那张蓝图**；一旦 QP 的动力学/接触/雅可比模型有误（或被投毒），低秩适配器就会在「已认证」的名义下把模型误差洗成看似完全合规的行为，再经版本化与组合沿时间与上下文扩散，**而这恰恰发生在系统最自信、最少交互的时候——越高效微调，越危险。**

**次级风险与缓解**：组合攻击（定义 318 主角/泄漏界 + 近正交或串行 + E306）；适配器后门/证据投毒（整合门 + 影子验证 + 指纹去重 + 定义 320 对抗训练 + E308/E310）；局部线性化二阶越界（引理 20 范数上限 + 版本重新认证 + E303）；版本膨胀与长时程漂移（容量/总秩硬预算 + ADM 回滚 + E313）；慢环训练挤占资源（后台低优先级 + 仅边界提交，绝不进实时路径）。
