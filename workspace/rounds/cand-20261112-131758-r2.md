# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC；灵感驱动研究循环第 2 轮／全局第 61 轮；本轮灵感：「通用机器人平台」×「数据集」）

> 第 60 轮实现了「认知驱动的场景-执行闭环」：场景语义建模 SSM、认知意图约束 CIEC、ROS 因果隔离 EPIR、场景感知闭环 SERC、四维认知预算 PCE++++。但它是在**单一机器人实例**上闭合的。当把系统放到「通用机器人平台」（不同自由度、连杆长度、末端工具、力传感器、驱动能力）并面对持续积累的「数据集」时，暴露出**三个新的根本局限**：
> 1. **平台锁定（Embodiment Lock-in）**：第 60 轮的场景-阻抗先验 π_scene(K|z)、意图-约束映射 ϕ、执行证书 J_exec 全部以具体平台的绝对量纲（N、N/m、m/s）表达；换一台负载更大、连杆更长的机械臂，同一场景的最优 K_safe 完全不同——先验与证书**不可迁移**。
> 2. **数据集回路断裂（Dataset Flywheel Missing）**：第 60 轮的 EV-exec 只回灌到当前机器人自身的场景信念，没有形成**可持久、可溯源、可版本化的证据数据集**；无法回答「我们是否见过这种工况」「某份证书到底由哪些数据支撑」，也就无法判断一个安全声明在**未覆盖工况**下是否依旧成立。
> 3. **覆盖率盲区（Coverage Blindness）**：认证只针对「见过并验证过」的样本，却默认其有效性可外推到整个工作域；一旦工作域出现**分布偏移**（新地面材质、新负载、新平台），证书仍被当作有效——这是「证据层高度确定、执行层灾难性失效」在**数据集层面**的放大。

## 0. 直觉与动机

**灵感 1（通用机器人平台 → 平台无关表征归一化 EIN）**
直觉：不同机器人之间真正共享的不是「绝对阻抗」，而是「相对自身能力包络的阻抗」。把 K 用平台描述符 E（负载 F_peak、速度 v_peak、可达性 R、自由度 dof、力传感器量程）归一化：K̃ = K ⊙ diag(c(E))，c(E) = (F_peak/F_ref, v_peak/v_ref, ...)。关键洞见：**场景先验应在归一化空间学习**——「湿滑地面」在归一化空间里对小型机械臂与大型机械臂呈现相同的 K̃ 分布，于是先验可以**跨平台迁移**，只需在目标平台做少量校准。

**灵感 2（数据集 → 证据数据集契约 EDC）**
直觉：每一轮的执行证据 EV-exec 不应随手丢弃，而应成为一个**带契约的数据集样本**：schema、平台 ID、场景 ID、意图、证书 ID、时间戳、哈希、覆盖单元。关键洞见：**安全声明 = 数据集覆盖声明**——「K_safe 在工况 (z, I, E) 下安全」只有在数据集中存在足够密度的支撑样本时才成立；无数据支撑的声明必须降级为「待探索」。

**灵感 3（数据集 → 覆盖感知证书 CAC）**
直觉：证书 J_exec 不该是一个布尔值，而应携带**有效性域 V(J)**：它只覆盖数据集里实际验证过的工况单元集合。运行时先查「当前工况是否落在 V(J) 内且密度 ≥ τ_cov」，否则证书**自动失效**并触发探索。关键洞见：**把「安全认证」从「一次性判定」变成「带定义域的谓词」**，杜绝「局部证据全局外推」。

**灵感 4（通用平台 + 数据集 → 保形跨平台迁移 CPTC）**
直觉：源平台已有充分数据集，目标平台只给少量锚点接触。用低秩变换 T（仿射/线性校准）把源先验收敛到目标平台：K_tgt = T(K_src) + b，并用**保形预测（conformal prediction）**给出**分布无关**的迁移误差上界。关键洞见：**迁移不是「相信源数据」，而是「用目标平台的少量数据给迁移结果套一个有限样本保证」**——这正是通用平台落地的工程底线。

**灵感 5（合流 → 平台通用接地闭环 UERC + 数据-执行双预算 PCE+++++）**
直觉：EIN 归一化 → EDC 数据集契约 → CAC 覆盖感知证书 → CPTC 保形迁移 → 执行 → EV-exec → 更新数据集（增加覆盖）→ 证书定义域扩大。同时预算从「认知预算」拓展为「数据-执行双预算」：B_data（存储/覆盖/采集）、B_transfer（校准次数）、B_validity（证书覆盖率），任一耗尽即回退到「保守通用证书 + 主动探索」——安全优先级高于覆盖扩展。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（平台描述符与归一化 EIN）** 平台描述符 E = (F_peak, v_peak, R_reach, dof, F_range, T_sensor, M_tool)。归一化算子：
- **能力包络**：c(E) = diag(F_peak/F_ref, v_peak/v_ref, R_reach/R_ref, M_tool/M_ref)
- **归一化阻抗**：对每个阻抗分量 k_i：k̃_i = k_i / c_i(E)（必要时再做维度一致化 K̃ = c(E)^{-1} K c(E)^{-1}）
- **归一化证据**：EV-exec 中的力/速度/位移均除以对应 c_i(E)，得到平台无关证据 ẼV
- **零样本迁移前提**：若源 E_s 与目标 E_t 在归一化空间共享同一先验 π̃_scene(K̃|z)，则当 ‖c(E_s) − c(E_t)‖ ≤ δ_E 时可直接迁移；否则须经 CPTC 校准。

**定义 162（证据数据集契约 EDC）** 证据数据集 D = {(x_j, y_j, p_j)}_{j=1}^{M}，其中：
- **样本** x_j = ẼV_j（归一化证据），y_j = 执行结果标签（成功 / 失败 / 边缘 D⁺），p_j = 溯源元组 (platform_id, scene_id, intent, cert_id, timestamp, hash)
- **契约** C_D = (Schema, Provenance, Version, Coverage)：Schema 固定字段；Provenance 保证样本可回溯到平台/场景/证书；Version = H(D)（默克尔根哈希）；Coverage = 覆盖映射 γ_D: (z, I, E-cell) → 样本数密度
- **覆盖单元**：把工作域离散为 u = (z, I, E_bin)，γ_D(u) = #{j : p_j 落入 u}；覆盖度 cov_D(U) = |{u ∈ U : γ_D(u) ≥ n_min}| / |U|
- **证书支撑集**：Supp_D(J) = {u : γ_D(u) ≥ n_min}

**定义 163（覆盖感知执行证书 CAC）** 证书 J_cov = (J_exec, V_J, τ_cov, ρ_J)：
- **有效性域** V_J ⊆ U，是 J_exec 被验证过的工况单元集合
- **密度阈值** n_min：单元需至少 n_min 个样本支撑
- **运行时判定**：
  ```
  valid_J(z, I, E) = [ (z, I, bin(E)) ∈ V_J ]
                     ∧ [ γ_D(z, I, bin(E)) ≥ n_min ]
                     ∧ [ DSD_shift(z, I, E) = false ]
  ```
- **半衰与失效**：若分布偏移检测 DSD 报警，则 V_J 收缩（移除受污染单元），剩余可信度 ρ_J 按 exp(−κ·shift_magnitude) 衰减
- **与 J_exec 的关系**：J_exec 只是 V_J = U_full 且无偏移时的特例；**CAC 把证书从「点判定」升级为「带定义域的谓词」**——域外一律零默认通过。

**定义 164（保形跨平台迁移 CPTC）** 给定源数据集 D_s（在 E_s 上）与目标平台 E_t 的锚点集 A = {(x_i, y_i)}_{i=1}^{n}（少量真机接触）：
- **迁移模型**：p̂_t(y|x) = T_θ(p̂_s(y|x))，θ 为低秩仿射变换（rank r ≪ dim）
- **非一致性分数**：α_i = |y_i − ŷ_t(x_i)|（或一般损失 ℓ(y_i, ŷ_t(x_i))）
- **保形阈值**：q̂ = Quantile_{⌈(n+1)(1−α)⌉/n}({α_i})
- **迁移保证**：对新样本 x，P(|y − ŷ_t(x)| ≤ q̂) ≥ 1−α（仅需**可交换性**，不需与源同分布）
- **校准成本**：每锚点消耗 1 单位 B_transfer；θ 估计需 n ≥ n_min = O(r·log d)；锚点不足则回退「通用保守先验」。

**定义 165（数据集主动采集 DAA）** 采集策略 π_acq：在预算 B_data 下选择下一个采集单元 u：
```
u* = argmax_{u ∈ U \ V_J} [ E[Δcov(u)] · V_info(u) ] / [ cost_acq(u) + λ_fail·P_fail(u) ]
```
其中 Δcov(u) 为该单元带来的覆盖增益，V_info(u) 为对证书定义域扩张的边际信息价值，cost_acq 为采集成本，P_fail 为采集失败风险。**只对「证书盲区」采集，不对已充分覆盖区域浪费预算。**

**定义 166（分布偏移检测 DSD）** 运行时证据流 ẼV_t 与数据集 D 的差异度量：
- **单元级偏移**：MMD²(ẼV_t|_u, D|_u) 或基于保形的 p 值 p_u
- **报警规则**：若 p_u < α_shift 且持续 w 个周期，则单元 u 标记为偏移
- **证书响应**：V_J ← V_J \ {u}，并触发 DAA 对该单元采集；ρ_J ← ρ_J·exp(−κ·MMD²)
- **关键**：**偏移检测是「证书定义域」的动态维护机制**，不是孤立的告警灯。

**定义 167（平台通用接地闭环 UERC）** 算子 UERC(M, E_t, z, I, δ_f_req)：
```
① EIN: K̃, ẼV ← normalize(E_t, ·)
② EDC.load(D); v ← CAC.valid_J(z, I, E_t)
③ if not v: CPTC.calibrate(A_t) 或 u* ← DAA.select()
④ SSM/CIEC: 归一化空间场景先验 π̃_scene、意图约束 C_intent
⑤ EEIS: K_safe = compile_with_scene_prior(π̃_scene, δ_f_req); ERTC.lock(C_intent)
⑥ Dispatch + Execute + wait_contact
⑦ EV-exec → 归一化 ẼV → EDC.append(溯源) → D 增量更新（Version 更新）
⑧ CAC.expand(V_J); DSD.monitor(); 返回 (K_safe, J_cov, D.status)
```

**定义 168（数据-执行双预算 PCE+++++）** B_dataexec = (B_data, B_transfer, B_validity, B_cog, B_exec)。其中：
- **B_data** = (Storage, Coverage_gain_rate, Acquisition_ops)
- **B_transfer** = (Anchor_budget, Calibration_ops, Transfer_error_allowance)
- **B_validity** = (Certificate_coverage, Accepted_shift, Revalidation_freq)
- 其余 B_cog / B_exec 承接第 60 轮
- **降级链**：B_transfer 耗尽 → 禁止迁移，回退「通用保守证书」；B_data 耗尽 → 停止采集，冻结 V_J 并只允许域内执行；B_validity 低于阈值 → 强制主动探索（即便 B_data 紧张，安全优先）。

### IP-161 EIN（平台无关表征归一化）

```python
class EmbodimentInvariantNorm:
    REF = {'F_peak': 50.0, 'v_peak': 1.0, 'R_reach': 0.8, 'M_tool': 2.0}

    def __init__(self, descriptor: dict):
        self.E = descriptor
        self.c = {
            'F_peak': descriptor['F_peak'] / self.REF['F_peak'],
            'v_peak': descriptor['v_peak'] / self.REF['v_peak'],
            'R_reach': descriptor['R_reach'] / self.REF['R_reach'],
            'M_tool': descriptor['M_tool'] / self.REF['M_tool'],
        }

    def normalize_K(self, K: dict) -> dict:
        return {k: K[k] / self.c[self._axis(k)] for k in K}

    def denormalize_K(self, K_tilde: dict) -> dict:
        return {k: K_tilde[k] * self.c[self._axis(k)] for k in K_tilde}

    def normalize_evidence(self, ev: dict) -> dict:
        return {
            'force': ev['force'] / self.c['F_peak'],
            'velocity': ev['velocity'] / self.c['v_peak'],
            'displacement': ev['displacement'] / self.c['R_reach'],
            'ts': ev['timestamp'], 'seq': ev['seq_id'],
        }

    def zero_shot_ok(self, src_descriptor: dict, delta_E=0.15) -> bool:
        src = EmbodimentInvariantNorm(src_descriptor)
        return sum(abs(self.c[k] - src.c[k]) for k in self.c) <= delta_E

    def _axis(self, k):
        return 'F_peak' if 'F' in k or 'K_p' in k else (
               'v_peak' if 'v' in k else 'R_reach')
```

```python
class EvidenceDataset:
    def __init__(self, n_min=5, schema=None):
        self.samples = []          # [(x, y, provenance)]
        self.n_min = n_min
        self.schema = schema or ('x', 'y', 'platform_id', 'scene_id',
                                 'intent', 'cert_id', 'timestamp', 'hash')
        self.version = self._merkle_root()

    def append(self, x, y, provenance: dict):
        self._check_schema(provenance)
        self.samples.append((x, y, provenance))
        self.version = self._merkle_root()

    def coverage(self, z, I, e_bin) -> int:
        return sum(1 for _, _, p in self.samples
                   if (p['scene_id'], p['intent'], p['platform_bin']) == (z, I, e_bin))

    def support_units(self):
        return {u for u in self._units() if self.coverage(*u) >= self.n_min}

    def _merkle_root(self) -> str:
        h = hashlib.sha256()
        for x, y, p in self.samples:
            h.update(json.dumps([x, y, p], sort_keys=True).encode())
        return h.hexdigest()


class CoverageAwareCertificate:
    def __init__(self, dataset: EvidenceDataset, exec_cert, tau_cov=0.6):
        self.D = dataset
        self.J = exec_cert
        self.V = set(dataset.support_units())   # 有效性域
        self.tau_cov = tau_cov
        self.rho = 1.0                          # 剩余可信度

    def valid(self, z, I, e_bin, dsd) -> bool:
        u = (z, I, e_bin)
        if u not in self.V:
            return False
        if self.D.coverage(z, I, e_bin) < self.D.n_min:
            return False
        if dsd.shifted(u):
            return False
        return True

    def expand(self, u):
        if self.D.coverage(*u) >= self.D.n_min:
            self.V.add(u)

    def shrink(self, u, shift_mag):
        self.V.discard(u)
        self.rho *= math.exp(-0.5 * shift_mag)
```

### IP-164 CPTC（保形跨平台迁移）

```python
class ConformalTransfer:
    def __init__(self, alpha=0.1, rank=2):
        self.alpha = alpha
        self.rank = rank
        self.T = None
        self.q_hat = None

    def calibrate(self, anchors):
        X = np.array([a[0] for a in anchors]); y = np.array([a[1] for a in anchors])
        if len(anchors) < self._n_min():
            return False
        U, S, Vt = np.linalg.svd(X, full_matrices=False)
        Ur = U[:, :self.rank]; Vr = Vt[:self.rank, :]
        self.T = Vr.T @ np.diag(S[:self.rank]) @ Ur.T   # 低秩仿射
        b = y.mean(axis=0) - X.mean(axis=0) @ self.T.T
        scores = np.abs(y - (X @ self.T.T + b))
        n = len(scores)
        self.q_hat = np.quantile(scores, min(1.0, np.ceil((n+1)*(1-self.alpha))/n))
        return True

    def predict_interval(self, x):
        y_hat = x @ self.T.T
        return y_hat - self.q_hat, y_hat + self.q_hat

    def _n_min(self):
        return max(10, self.rank * 4)
```

```python
class DatasetActiveAcquisition:
    def __init__(self, dataset, budget):
        self.D = dataset; self.budget = budget

    def select(self, blind_units, V, cost_fn, fail_prob_fn):
        best, best_score = None, -1.0
        for u in blind_units:
            if u in V:
                continue
            delta_cov = 1.0 / (self.D.coverage(*u) + 1.0)
            info = math.log1p(self.D.coverage(*u, )) if False else np.exp(-self.D.coverage(*u))
            score = delta_cov * info / (cost_fn(u) + 0.5 * fail_prob_fn(u))
            if score > best_score:
                best, best_score = u, score
        return best


class DistributionShiftDetector:
    def __init__(self, dataset, alpha_shift=0.05, patience=3):
        self.D = dataset
        self.alpha_shift = alpha_shift
        self.patience = patience
        self.counts = {}

    def p_value(self, u, window):
        ref = self.D.unit_window(u)
        if len(ref) < self.D.n_min or len(window) < self.D.n_min:
            return 1.0
        stat = self._mmd2(ref, window)
        return self._permutation_p(stat, ref, window)

    def shifted(self, u) -> bool:
        return self.counts.get(u, 0) >= self.patience

    def monitor(self, u, window):
        if self.p_value(u, window) < self.alpha_shift:
            self.counts[u] = self.counts.get(u, 0) + 1
        else:
            self.counts[u] = 0
        return self.shifted(u)
```

### IP-167 UERC（平台通用接地闭环）

```python
def universal_grounded_loop(M, E_t, z, intent, delta_f_req):
    ein = EmbodimentInvariantNorm(E_t)
    D, cac = M.dataset, M.certificate
    valid = cac.valid(z, intent, ein.bin(E_t), M.dsd)

    if not valid:
        if M.budget.can_transfer():
            anchors = M.collect_anchor_contacts(n=M.budget.anchor_n)
            ok = M.transfer.calibrate(anchors)
            if not ok:
                K_safe = M.eeis.compile_conservative(delta_f_req)
                return M, K_safe, cac, {'status': 'conservative_no_calib'}
        else:
            u_star = M.acquisition.select(M.blind_units(), cac.V,
                                          cost_fn=M.cost, fail_prob_fn=M.p_fail)
            K_safe = M.eeis.compile_conservative(delta_f_req)
            M.dataset.schedule_probe(u_star)
            return M, K_safe, cac, {'status': 'explore', 'u': u_star}

    prior = M.ssm.get_prior_normalized(z)          # 归一化空间场景先验
    K_safe = M.eeis.compile_with_scene_prior(prior, delta_f_req)
    if intent:
        M.intent_ctrl.receive_intent(intent)        # CIEC 约束锁定
    M, fused, D_plus, ev, cert = closed_loop_exec_probe(M, M.current_cp, delta_f_req)
    ev_tilde = ein.normalize_evidence(ev.__dict__)
    D.append(ev_tilde, D_plus_label(D_plus),
             provenance={'platform_id': E_t['id'], 'scene_id': z,
                         'intent': intent, 'cert_id': cert.id,
                         'timestamp': ev.timestamp, 'hash': ev.hash})
    u = (z, intent, ein.bin(E_t))
    if M.dsd.monitor(u, D.unit_window(u)):
        cac.shrink(u, M.dsd.shift_magnitude(u))
    else:
        cac.expand(u)
    return M, K_safe, cac, {'status': 'grounded', 'coverage': cac.V}
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| EIN | O(dim) 归一化 | O(dim) | 归一化误差 ≤ δ_E；能力包络标定自检 |

则：
1. **跨平台迁移正确性**：若目标平台锚点数 n ≥ n_min 且可交换性成立，则归一化空间迁移的覆盖误差 ≤ q̂，概率 ≥ 1−α。
2. **证书定义域安全性**：对任意运行工况，若 CAC.valid_J = false，则系统绝不将其视为已认证（域外零默认通过）。
3. **数据集溯源一致性**：Version 哈希与样本溯源保证数据集不可静默篡改；任一证书可反查其支撑样本。
4. **偏移安全**：DSD 报警后 V_J 收缩，旧证书不会在偏移单元上继续生效。
5. **预算安全**：任一 B_dataexec 分量耗尽触发降级链，且 B_validity 优先于 B_data（安全 > 覆盖）。

### IP-161 EIN（平台无关表征归一化）

```python
class EmbodimentInvariantNorm:
    REF = {'F_peak': 50.0, 'v_peak': 1.0, 'R_reach': 0.8, 'M_tool': 2.0}

    def __init__(self, descriptor: dict):
        self.E = descriptor
        self.c = {k: descriptor[k] / self.REF[k] for k in self.REF}

    def normalize_K(self, K: dict) -> dict:
        return {k: K[k] / self.c[self._axis(k)] for k in K}

    def denormalize_K(self, K_tilde: dict) -> dict:
        return {k: K_tilde[k] * self.c[self._axis(k)] for k in K_tilde}

    def normalize_evidence(self, ev: dict) -> dict:
        return {
            'force': ev['force'] / self.c['F_peak'],
            'velocity': ev['velocity'] / self.c['v_peak'],
            'displacement': ev['displacement'] / self.c['R_reach'],
            'ts': ev['timestamp'], 'seq': ev['seq_id'],
        }

    def zero_shot_ok(self, src: dict, delta_E=0.15) -> bool:
        s = EmbodimentInvariantNorm(src)
        return sum(abs(self.c[k] - s.c[k]) for k in self.c) <= delta_E

    def _axis(self, k):
        return 'F_peak' if ('F' in k or 'K_p' in k) else (
               'v_peak' if 'v' in k else 'R_reach')
```

```python
class EvidenceDataset:
    def __init__(self, n_min=5):
        self.samples = []
        self.n_min = n_min
        self.version = self._merkle_root()

    def append(self, x, y, provenance: dict):
        self.samples.append((x, y, provenance))
        self.version = self._merkle_root()

    def coverage(self, z, I, e_bin) -> int:
        return sum(1 for _, _, p in self.samples
                   if (p['scene_id'], p['intent'], p['platform_bin']) == (z, I, e_bin))

    def support_units(self):
        return {u for u in self._units() if self.coverage(*u) >= self.n_min}

    def _merkle_root(self) -> str:
        h = hashlib.sha256()
        for x, y, p in self.samples:
            h.update(json.dumps([x, y, p], sort_keys=True).encode())
        return h.hexdigest()


class CoverageAwareCertificate:
    def __init__(self, dataset: EvidenceDataset, exec_cert, tau_cov=0.6):
        self.D = dataset
        self.J = exec_cert
        self.V = set(dataset.support_units())
        self.tau_cov = tau_cov
        self.rho = 1.0

    def valid(self, z, I, e_bin, dsd) -> bool:
        u = (z, I, e_bin)
        return (u in self.V
                and self.D.coverage(z, I, e_bin) >= self.D.n_min
                and not dsd.shifted(u))

    def expand(self, u):
        if self.D.coverage(*u) >= self.D.n_min:
            self.V.add(u)

    def shrink(self, u, shift_mag):
        self.V.discard(u)
        self.rho *= math.exp(-0.5 * shift_mag)
```

### IP-164 CPTC（保形跨平台迁移）

```python
class ConformalTransfer:
    def __init__(self, alpha=0.1, rank=2):
        self.alpha, self.rank = alpha, rank
        self.T, self.q_hat = None, None

    def calibrate(self, anchors):
        X = np.array([a[0] for a in anchors]); y = np.array([a[1] for a in anchors])
        if len(anchors) < self._n_min():
            return False
        U, S, Vt = np.linalg.svd(X, full_matrices=False)
        Ur, Vr = U[:, :self.rank], Vt[:self.rank, :]
        self.T = Vr.T @ np.diag(S[:self.rank]) @ Ur.T
        b = y.mean(0) - X.mean(0) @ self.T.T
        scores = np.abs(y - (X @ self.T.T + b))
        n = len(scores)
        self.q_hat = np.quantile(scores, min(1.0, np.ceil((n+1)*(1-self.alpha))/n))
        return True

    def predict_interval(self, x):
        y_hat = x @ self.T.T
        return y_hat - self.q_hat, y_hat + self.q_hat

    def _n_min(self):
        return max(10, self.rank * 4)
```

### IP-165/166 DAA（主动采集）与 DSD（分布偏移检测）

```python
class DatasetActiveAcquisition:
    def __init__(self, dataset, budget):
        self.D, self.budget = dataset, budget

    def select(self, blind_units, V, cost_fn, fail_prob_fn):
        best, best_score = None, -1.0
        for u in blind_units:
            if u in V:
                continue
            delta_cov = 1.0 / (self.D.coverage(*u) + 1.0)
            info = np.exp(-self.D.coverage(*u))
            score = delta_cov * info / (cost_fn(u) + 0.5 * fail_prob_fn(u))
            if score > best_score:
                best, best_score = u, score
        return best


class DistributionShiftDetector:
    def __init__(self, dataset, alpha_shift=0.05, patience=3):
        self.D = dataset
        self.alpha_shift, self.patience = alpha_shift, patience
        self.counts = {}

    def shifted(self, u) -> bool:
        return self.counts.get(u, 0) >= self.patience

    def monitor(self, u, window):
        if self._p_value(u, window) < self.alpha_shift:
            self.counts[u] = self.counts.get(u, 0) + 1
        else:
            self.counts[u] = 0
        return self.shifted(u)
```

```python
def universal_grounded_loop(M, E_t, z, intent, delta_f_req):
    ein = EmbodimentInvariantNorm(E_t)
    D, cac = M.dataset, M.certificate
    valid = cac.valid(z, intent, ein.bin(E_t), M.dsd)

            anchors = M.collect_anchor_contacts(n=M.budget.anchor_n)

        else:

            M.dataset.schedule_probe(u_star)
            return M, M.eeis.compile_conservative(delta_f_req), cac, {'status': 'explore', 'u': u_star}

    prior = M.ssm.get_prior_normalized(z)
    K_safe = M.eeis.compile_with_scene_prior(prior, delta_f_req)
    if intent:
```
