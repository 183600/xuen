### 第 5 轮灵感驱动研究记录（继承 v4；本轮为新一轮循环第 1 轮）

**灵感词**：深度学习、论文创新点

**继承关系**：第 4 轮 CADVS-v4（IP-489~492）在 v3 五锚点（3DCF/MSRG/HICK/EEK/LTEM）与联邦锚 FFA 之上，追加价值锚 VACK（kc_val）与平衡锚 BCK（kc_bal），形成七硬门 kc_evidence_forged_v4 = kc_coverage ∧ kc_physics ∧ kc_human ∧ kc_ee ∧ kc_mem ∧ kc_val ∧ kc_bal，fail-closed；软评分 ECS_v4 = ECS_v3 · η_val · η_bal；执行集 Exec_CADVS-v4 ⊆ … ⊆ Exec_v29。v4 已把最大矛盾说透：**越强的证据锚越贵**——VACK ~10–50 ms、BCK ~1–5 ms，直接撞穿 1 kHz 控制环；且 VACK 的加性价值模型、BCK 的动力学模型都存在规约失配/脆性。本轮不推翻 v4，也不再加一个「更贵」的锚点，而是引入一条正交的**深度学习 + 统计认证层**，形成 CADVS-v5 = NCEF（Neural-Conformal Evidence Forging），执行集嵌套升级为 Exec_CADVS-v5 ⊆ Exec_CADVS-v4 ⊆ … ⊆ Exec_v29。

**直觉与动机**：

1. **深度学习：把「证书求解」从在线计算变成离线编译 + 在线摊销**。安全关键系统里，网络最危险的用法是「用一个黑箱替代证书」；正确用法是「用网络摊销证书」。v4 的精确核（QP 解 Wrench 锥、偏好模型推理）在离线/慢时域有充分算力，可批量生成 (状态, 精确证书) 对；训练一个 SE(3)-等变图神经网络 NCA 去拟合这些对，把 BCK 的 QP 与 VACK 的价值推理摊销成 ~0.1 ms 的前向。再蒸馏成带认证 Lipschitz 常数的单调小网络 MCC，部署到边缘/FPGA。关键纪律：**证书语义仍由 v4 定义，网络只负责「快速近似」，永远不负责「定义安全」**。

2. **深度学习 + 统计：共形预测给黑箱兜底**。这是本轮的核心创新。NCA 无论多准，都只是点估计；把点估计直接当硬门，等于用「模型不出错」这一无法证明的假设换安全。共形预测只要求校准集与测试点**可交换**，就能给任意黑箱输出有限样本、分布无关的区间：P(精确证书 ∈ 区间) ≥ 1−α。于是定义**共形硬门**：不用点估计，而用**保守下置信界** LCB = Ĉ − q̂·σ̂ 去比阈值。只要 LCB 过门，精确证书必然过门（在覆盖事件内），故**假通过率 ≤ α，且不依赖网络正确性**。这把「学出来的门」变成了「统计意义上可证的门」。

3. **论文创新点：从「模块堆叠」升级为四个可证伪的理论贡献**。v1~v4 的工程模块已足够多，继续堆模块边际收益递减；真正可发表的是把「学习 + 安全」的张力凝练成定理：
   (C1) **Conformal Hard Gate（CHG）**：首个把共形预测用于机器人 fail-closed 安全硬门的工作，给出与模型无关的假通过率上界；
   (C2) **摊销间隙界**：把「神经网络误差 / Lipschitz 常数 / 共形区间宽度 / 门保守度」串成一个可测的界，量化「快」与「稳」的兑换率；
   (C3) **统计单调收缩定理**：把 v4 的代数执行集收缩推广到概率情形，证明「引入学习不会放大执行集」（w.p. ≥ 1−α）；
   (C4) **选择性价值对齐**：用共形价值集 + 歧义弃权，把「价值多元/奖励黑客」变成有风险-覆盖上界的弃权决策，而非强行二值判定。
   一句话论文主张：**Certificates are compiled, not trusted（证书是被编译与校准的，不是被信任的）**。

4. **选择性价值对齐：让「不知道」成为一种合法输出**。v4 的 VACK 强制输出 α_val 并二值判定，在价值冲突/语境歧义时会被迫「装作知道」，这正是奖励黑客与规约失配的温床。v5 用偏好头集成 + 共形价值集 S_val(x)：若 τ_val 落在 S_val 内部（不可判定），显式弃权转教师；只有 S_val 整体位于阈值之上才接受。这样「接受即对齐」有可证的风险上界，弃权率则成为价值歧义的诚实度量。

5. **单调证书编译器：让摊销可组合**。为了让学习层能被 v4 的证书演算安全消费，MCC 采用架构级单调性（证书裕度对安全松弛单调）、认证 Lipschitz 正则、OOD 检测回退：一旦输入落在校准分布外，直接回退精确核（慢但可信）。学习层因此是「保守的、可回退的、可组合的」，而不是一个必须被无条件信任的新锚点。

**关键洞见**：v4 回答「证据够不够」；v5 回答「证据在有限样本、非平稳、黑箱近似下还可不可信」。深度学习负责「快」，共形预测负责「可信」，证书演算负责「可组合」——三者正交：快而不信是危险的，信而不快不可部署，可组合才能跨轮收缩。v5 不新增安全锚点，而是给 v4 的七个锚点加一层「统计认证外壳」：kc_evidence_forged_v5 = kc_evidence_forged_v4 的每个 kc_i 替换为保守共形门 kc_i^conf，再叠加价值歧义弃权门 kc_val^sel；软评分 ECS_v5 = ECS_v4 · η_conf，其中 η_conf 由共形区间宽度决定。

**形式化目标（增量）**：
1. 定义神经证书摊销器 NCA_θ：f_θ: (q, q̇, τ, 接触, 点云, 上下文) → (Ĉ ∈ R^m, σ̂ ∈ R^m_+)，m 为证书分量数；训练目标 = 蒸馏损失 + 物理残差 + 单调正则 + Lipschitz 正则。
2. 定义归一化非一致性分数 r_j(x) = |Ĉ_j(x) − C_j(x)| / σ̂_j(x)，共形分位 q̂_j（按接触模式 Mondrian 分组，Bonferroni α_j = α/m），共形区间 I_j(x) = [Ĉ_j − q̂_j σ̂_j, Ĉ_j + q̂_j σ̂_j]。
3. 定义共形硬门 kc_j^conf = (LCB_j ≥ θ_j)，LCB_j = Ĉ_j − q̂_j σ̂_j；总门 kc^conf = ∧_j kc_j^conf；软因子 η_conf = exp(−λ · mean_j(q̂_j σ̂_j / scale_j))。
4. 证明定理 5（CHG 可靠性）：可交换性下 P(kc^conf 通过 ∧ kc^exact 失败) ≤ α，对任意网络成立。
5. 证明定理 6（摊销间隙与区间宽度界）：q̂ 的经验分位以高概率逼近总体分位；期望区间半宽 ≤ E[σ̂]·(q* + √(log(1/δ)/(2n_cal)))；若残差满足 Lipschitz 型界则宽度随输入到训练分布距离收缩。
6. 证明定理 7（统计单调收缩）：覆盖事件 E 上 Exec_CADVS-v5 ⊆ Exec_CADVS-v4，且 P(E) ≥ 1−α；q̂→0 时 Exec_v5 ↑ Exec_v4。
7. 定义选择性价值对齐核 SVAK：共形价值集 S_val(x) 与弃权规则；证明定理 8（风险-覆盖界）P(α_val < τ_val | 接受) ≤ α_val / P(接受)。
8. 定义单调证书编译器 MCC：架构单调 + 认证 Lipschitz + OOD 回退；定义退化阶梯 full_conf → exact_fallback → static_safe。
9. 定义 EFA-v5 与 ECS_v5 = ECS_v4 · η_conf；证明任意退化级别都不放大 v4 执行集。

**本轮最大风险**：**共形硬门的有限样本保证依赖校准集与测试点的可交换性，而接触丰富操作的本质非平稳性会破坏该假设——分布漂移下覆盖率会静默失效，「统计认证」反而退化为一种比没有保证更危险的虚假安全感。**

### IP-493 NCA：神经证书摊销器（离线训练，在线 ~0.05–0.15 ms）

@dataclass
class NeuralCertificateAmortizer:
    """NCA：SE(3)-等变图神经网络 + 可微QP教师；蒸馏 v4 精确核；不定义安全，只摊销安全"""
    encoder: nn.Module          # SE(3)-equivariant message passing over contact graph
    qp_layer: nn.Module         # differentiable QP (OptNet/cvxpylayers)，仅训练时作教师信号
    heads: dict[str, nn.Module] # m 个证书分量头 + 1 个 log-sigma 头
    lipschitz_reg: float = 1e-3
    monotone_reg: float = 1e-2

    def forward(self, q, qd, tau, contacts, cloud, context) -> NCAResult:
        z = self.encoder(q, qd, tau, contacts, cloud)        # 等变嵌入
        c_hat = torch.stack([self.heads[k](z) for k in CERT_KEYS])  # (m,)
        sigma = self.heads["sigma"](z).exp().clamp_min(1e-6)       # (m,)
        return NCAResult(c_hat=c_hat, sigma=sigma, z=z)            # 推理不跑 QP 层

    def train_step(self, batch, oracle: "EvidenceForgingAssemblerV4"):
        c_exact = oracle.certify_exact(batch)     # 离线/慢时域精确证书（教师）
        out = self(batch)
        nll = gaussian_nll(c_exact, out.c_hat, out.sigma)         # 异方差蒸馏
        phys = self._dynamics_residual(batch)                      # PINN 残差 Mq̈+h−τ−JᵀF
        mono = self._monotone_penalty(out.c_hat, batch)            # 裕度对安全松弛单调
        lip = self._lipschitz_penalty()                            # 谱范数/随机投影估计
        return nll + 0.1 * phys + self.monotone_reg * mono + self.lipschitz_reg * lip

### IP-494 CCC：共形证书校准器（离线校准，在线门查询 O(m)）

```python
@dataclass
class ConformalCertificateCalibrator:
    """CCC：归一化 split/group-conditional conformal；把 NCA 点估计变成保守下置信界"""
    alpha: float = 0.05
    m: int = 7
    mode_key: Callable = lambda x: contact_mode(x)   # Mondrian 按接触模式分组
    q_hat: dict = field(default_factory=dict)        # (mode, j) -> q̂

    def calibrate(self, cal_loader, nca: NeuralCertificateAmortizer, oracle):
        scores = defaultdict(list)
        for batch in cal_loader:                       # 校准集必须与测试可交换且不参与训练
            out = nca(batch)
            c_exact = oracle.certify_exact(batch)
            for j in range(self.m):
                r = (out.c_hat[j] - c_exact[j]).abs() / out.sigma[j]
                scores[(self.mode_key(batch), j)].append(float(r))
        for (mode, j), s in scores.items():
            alpha_j = self.alpha / self.m              # Bonferroni
            n = len(s)
            level = min(1.0, math.ceil((n + 1) * (1 - alpha_j)) / n)
            self.q_hat[(mode, j)] = float(np.quantile(s, level, method="higher"))

    def conservative_gate(self, out: NCAResult, x) -> tuple[bool, str, np.ndarray]:
        mode = self.mode_key(x)
        lcb = np.empty(self.m)
        for j, key in enumerate(CERT_KEYS):
            q = self.q_hat[(mode, j)]
            lcb[j] = float(out.c_hat[j] - q * out.sigma[j])
            if lcb[j] < THRESHOLDS[key]:
                return False, f"{key.upper()}_CONF_REJECT", lcb
        return True, "FORGED_CONF", lcb

    def mean_width(self, out: NCAResult, x) -> float:
        mode = self.mode_key(x)
        return float(np.mean([self.q_hat[(mode, j)] * out.sigma[j]
                              for j in range(self.m)]))
```

### IP-496 SVAK：选择性价值对齐核（规则准入时异步，~1–5 ms）

```python
@dataclass
class SelectiveValueAlignmentKernel:
    """SVAK：偏好头集成 + 共形价值集 + 歧义弃权；kc_val^sel"""
    ensemble: list[nn.Module]
    alpha_val: float = 0.05
    tau_val: float = 0.6
    q_val: float = 0.0            # 价值共形余量（离线校准得到）

    def conformal_value_set(self, x) -> tuple[float, float]:
        preds = np.array([float(m(x)) for m in self.ensemble])
        lo = np.quantile(preds, self.alpha_val / 2) - self.q_val
        hi = np.quantile(preds, 1 - self.alpha_val / 2) + self.q_val
        return float(lo), float(hi)

    def kc_val_sel(self, x) -> tuple[bool, str]:
        lo, hi = self.conformal_value_set(x)
        if lo < self.tau_val <= hi:
            return False, "VALUE_AMBIGUOUS_ABSTAIN"   # 不可判定 → 教师（合法输出）
        if lo >= self.tau_val:
            return True, "VALUE_ALIGNED"
        return False, "VALUE_MISALIGNED"
```

### IP-497 EFA-v5：保守共形门 + 选择性价值 + 退化阶梯

```python
@dataclass
class EvidenceForgingAssemblerV5:
    """EFA-v5：v4 七硬门 → 共形保守门；价值门 → 选择性弃权；任意退化不放大执行集"""
    nca: NeuralCertificateAmortizer
    ccc: ConformalCertificateCalibrator
    mcc: MonotoneCertificateCompiler
    svak: SelectiveValueAlignmentKernel
    exact: EvidenceForgingAssemblerV4          # 教师/回退 oracle
    lam: float = 1.0

    def hard_gate(self, x, t_now, rule_id, hic, eec, bcc, ctx, traj, context) -> tuple[bool, str]:
        # 最高优先级旁路：人因否决不经过任何学习/统计层
        if self.exact.hic.veto_active(hic):
            return False, "HIC_STOP"
        level, out = self.mcc.deploy_step(x, self.exact, self.ccc)
        if level == "exact_fallback":
            return self.exact.hard_gate(x, t_now, rule_id, hic, eec, bcc,
                                        ctx, traj, context)   # 慢但可信
        if level == "reject":
            return False, out
        ok_v, reason_v = self.svak.kc_val_sel(x)
        if not ok_v:
            return False, reason_v
        return True, "FORGED_CONF"

    def ecs_v5(self, x, t_now, rule_id, A_att=0.0, eta_mem=0.5,
               eta_val=0.5, eta_bal=0.5) -> float:
        base = self.exact.ecs_v4(x, t_now, rule_id, A_att, eta_mem, eta_val, eta_bal)
        width = self.ccc.mean_width(self.nca(x), x)
        return base * float(np.exp(-self.lam * width))
```

  每周期：

      ├─ full_conf     → CCC.conservative_gate（O(m)）

  full_conf ──(OOD 或 覆盖告警)──▶ exact_fallback ──(超时/算力不足)──▶ static_safe

## 4. 正确性论证（增量更新）

### 定理 5（共形硬门可靠性，C1）

**陈述**：设校准集 D_cal 与测试点 x 可交换，非一致性分数 r_j 定义如上，q̂_j 取有限样本共形分位。则对任意 NCA（无论其是否准确、是否被对抗扰动），有

  P(kc^conf(x) 通过 ∧ kc^exact(x) 失败) ≤ Σ_j α_j = α。

**证明**：kc^conf 通过 ⇒ 对所有 j，LCB_j = Ĉ_j − q̂_j σ̂_j ≥ θ_j。若 kc^exact 失败，则存在 j 使 c_j < θ_j ≤ LCB_j ≤ Ĉ_j，故 c_j < LCB_j，即 c_j ∉ I_j（下界已越过 c_j），是分量 j 的误覆盖事件。由共形覆盖定理，P(c_j ∉ I_j) ≤ α_j；对 m 个分量取并集界得 ≤ Σα_j = α。全程未使用网络正确性。∎

**工程含义**：这是本轮最重要的安全性结果——它把「相信模型」替换为「相信校准集可交换 + 有限样本分位」，且假通过率可调（α）。HIC veto 不经过此层，保持最高优先级。

### 定理 6（摊销间隙与区间宽度界，C2）

**陈述**：设 r_j 的总体 (1−α_j) 分位为 q_j*，经验分位 q̂_j 由 n_cal 个 i.i.d. 样本得到。则对任意 δ∈(0,1)，以概率 ≥ 1−δ，

  q̂_j ≤ q_j* + √(log(1/δ) / (2 n_cal))。

从而期望区间半宽 E[q̂_j σ̂_j] ≤ E[σ̂_j]·(q_j* + √(log(1/δ)/(2n_cal)))。若进一步存在嵌入空间上的 L_j-Lipschitz 残差界 |Ĉ_j(x) − C_j(x)| ≤ L_j·d(x, D_train) + ε_j，则区间半宽随 d(x, D_train) 线性增长，且在训练分布内收缩到 ε_j 量级。

**证明**：经验 CDF 的 DKW/Hoeffding 界给出分位估计的集中；宽度期望由 q̂_j 与 σ̂_j 的独立性/有界性直接放大。Lipschitz 部分代入定义。∎

**工程含义**：q̂ 是「快」的代价的显式度量——网络越准、σ̂ 越紧、校准越多，门越不保守；反之门自动变保守。这给出了可调的安全-吞吐兑换旋钮。

### 定理 7（统计单调收缩，C3）

**陈述**：令 E 为定理 5 的覆盖事件，P(E) ≥ 1−α。则

  (i) 在 E 上 Exec_CADVS-v5 ⊆ Exec_CADVS-v4，故 P(Exec_v5 ⊄ Exec_v4) ≤ α；
  (ii) 若 q̂_j → 0（完美摊销），则 Exec_v5 ↑ Exec_v4（逐点）；
  (iii) 若 q̂_j > 0，新增拒绝区域为「不确定性缓冲带」{x : θ_j ≤ c_j < LCB_j}，其宽度 ∝ q̂_j σ̂_j。

**证明**：(i) 在 E 上 c_j ∈ I_j ⇒ c_j ≥ LCB_j；kc^conf 通过 ⇒ LCB_j ≥ θ_j ⇒ c_j ≥ θ_j，即 v4 对应门通过；对全部门取合取得 Exec_v5 ⊆ Exec_v4。(ii) q̂=0 时 LCB_j = Ĉ_j → c_j，两门重合。(iii) 由 LCB 与 c_j 的差直接得到。∎

**工程含义**：学习层不可能偷偷放大执行集——这是对 v4「单调信任收缩」的统计版本。任何吞吐提升都以「保守缓冲带」为代价，且该代价可测量。

### 定理 8（选择性价值对齐的风险-覆盖界，C4）

**陈述**：设共形价值集满足 P(α_val(x) ∈ S_val(x)) ≥ 1−α_val。定义接受集 A = {x : lo(x) ≥ τ_val}，弃权集 B = {x : τ_val ∈ int S_val(x)}。则

  P(α_val < τ_val | x ∈ A) ≤ α_val / P(A)。

且弃权率 P(B) 随 α_val 与价值异构度单调上升。推论：在价值不可判定的语境下，「弃权转教师」比「强行二值判定」具有可证的选择风险上界。

**证明**：若 x∈A 且 α_val(x) < τ_val，则 α_val ∉ S_val（因 lo ≥ τ_val > α_val），即覆盖失败。故 P(misaligned ∧ A) ≤ P(覆盖失败) ≤ α_val；条件化得 P(misaligned | A) ≤ α_val / P(A)。∎

**工程含义**：v4 的 VACK 在歧义时被迫输出一个数；v5 允许「不知道」，并把「接受即对齐」变成有上界的承诺。弃权率本身是价值歧义的诚实仪表。

### 定理 v5（共形证据铸造的总保证）

**陈述**：在 (B1)~(B6)（继承 v4）之外追加 (B7) 校准集与部署分布可交换、(B8) OOD 回退触发率有界 下：

  (i) P(Exec_CADVS-v5 ⊆ Exec_CADVS-v4) ≥ 1−α（定理 7）；
  (ii) 共形门假通过率 ≤ α（定理 5）；
  (iii) 摊销区间宽度由定理 6 界，且随校准规模收缩；
  (iv) 价值选择风险 ≤ α_val / P(A)（定理 8）；
  (v) 任意退化级别（full_conf / exact_fallback / static_safe）执行集均 ⊆ Exec_v4；
  (vi) 证书演算在统计投影 ⊕_α 下仍构成有界分配格（逐点 ∧/∨ 保持，覆盖事件内与 v4 同构）。

**证明**：(i)(ii) 由定理 5、7；(iii) 定理 6；(iv) 定理 8；(v) full_conf 由 (i)，exact_fallback 就是 v4 本身，static_safe 是 v4 的子集；(vi) 在 E 上 ⊕_α 退化为恒等，故保持格公理。∎

**诚实声明**：(B7) 可交换性是全部统计保证的命门——接触丰富操作的非平稳性、负载/摩擦漂移、站点异构都会破坏它。缓解：按接触模式 Mondrian 分组、在线自适应共形（ACI）维持长期覆盖率、分布漂移检测触发 OOD 回退、每站点独立校准。但这些只保证「长期平均」或「条件于模式」，**不保证逐轨迹安全**；单条关键轨迹仍应走 exact_fallback。(B8) 回退触发率若失控，实时性会退回 v4 的困境。价值端 (B4) 仍假设价值可由 R_val 表达，SVAK 的弃权只是把「不可判定」显式化，并未解决价值本体论问题。
