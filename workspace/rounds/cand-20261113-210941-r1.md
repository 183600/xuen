# 第 70 轮（承接第 69 轮「FLUID-RAS」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「失败恢复」×「平衡控制」）

> R69 做了两件大事：把不确定性拆成 aleatoric / epistemic，并让系统学会「问」。但它和 R68 共享一条从未被检验的公理——**危险或不确定 ⇒ 收紧（λ 变大、动作变慢、包络变小）**。平衡控制恰恰提供了一个反例：被人从背后推一把时，最安全的动作通常不是「刹住、站直、变慢」，而是**立刻迈出一步**——此时增加运动、放松标称约束，才是恢复平衡的唯一方式。**「只收紧」在某些状态上不是保守，而是把可恢复的扰动变成不可恢复的摔倒。**
>
> 本轮两个灵感正好补上这条公理的另一半：
> - **平衡控制**告诉我们，安全的边界不该用「离失败有多远」度量，而该用「离『再也回不来』有多远」度量；capture point / DCM / 可落脚集给出了这个边界的一个可计算内近似；
> - **失败恢复**告诉我们，失败不是一个二值事件，而是一个带「认证出口」的区域；恢复不是异常处理分支，而是与平衡同一条控制律在标称集之外的**延拓**。
>
> 核心命题：**把安全目标从「避免离开安全集 K」升级为「最大化可恢复性」**——定义嵌套的**可恢复包络** K ⊆ B_δ（从 B_δ 内存在认证恢复策略、以 ≥1−δ 概率在 T 内回到 K）。在 K 内沿用 R68/R69；在 B_δ\K 内允许**经认证的风险再分配**（放松标称任务约束、把预算花在恢复上，但绝不越过认证的恢复能力）；在 B_δ 外则退化为认证的**受控倒地 / R68 最保守**。命名 **RESIL-RAS**（Recoverability-Envelope Safety with Interactive Learning）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**如果我已经在倒，还回得来吗——代价是多少**」——安全不只是刹车踏板，也可以是一次果断的迈步。

## 0. 直觉与动机

**灵感 1（平衡控制的本质是「可恢复」，不是「站稳」）**
直觉：一个静止站立的人和一个缓慢行走的人，谁更「安全」？取决于度量。若以「偏离标称姿态的方差」度量，静止者更安全；若以「被推后能否不摔」度量，行走者往往更强——因为行走者已经在持续练习「把要倒的身体接住」。平衡控制里的 capture point（DCM）说的正是这件事：系统的危险程度不由当前质心位置决定，而由「当前动量把质心推向哪里、以及脚还能落到哪里」决定。安全集因此不是姿态空间里的一个球，而是一个**随动力学与执行能力变形的可恢复域**。这把 R68「不确定就收缩安全集」升级为「先算清楚这个安全集到底该长什么样」。

**灵感 2（失败恢复是平衡控制在 K 外的延拓）**
直觉：传统控制把「平衡」和「摔倒」当两个世界，中间画一条线，线内正常控制、线外异常处理。但真实的双足系统不是这样：被推歪后，踝策略→髋策略→迈步→手臂→受控倒地，是一条**连续的降级链**，每一级都在「用更大的动作换回稳定」。失败恢复不是 try/catch，而是把这条降级链显式建模成一个**恢复模式库**，每级都有进入条件、恢复时间、能耗与认证成功率。于是「失败」被重新定义：**不是偏离 K，而是再也回不到 K**——即到达 B_δ 的边界（point of no return, PNR）。这正好给 R68/R69 提供一个缺失的坐标：离 PNR 还有多远。

**灵感 3（R68 的「只收紧」在恢复区可能致命）**
直觉：R68 的风险缩放 λ 对不确定/异常一律取 max，等价于「更慢、更小、更保守」。在标称集 K 内这是对的；一旦进入 B_δ\K，正确动作常常是**更快、更大、更果断**（迈步、摆臂、降低重心）。如果此时还按 R68 收紧，等于在身体已经越过支撑面时把脚钉在地上——**保守反而制造不可恢复**。所以 R70 提出「风险再分配」：在认证可恢复的区域内，允许把原本用于任务精度/平滑性的预算，**定向**挪给恢复动作；这不是放松安全，而是把安全预算花在刀刃上。关键约束是：放松量 Δλ 必须被恢复证书的余量严格上界（引理 22）。

**灵感 4（恢复动作天然多模态，正好接住 R69 的流策略）**
直觉：迈哪只脚、向哪个方向迈、用踝还是髋、要不要抓一把扶手——恢复是多峰的，不是单峰高斯能糊住的。R69 的流匹配多模态策略在这里获得第二个用途：**恢复模式分解（RMD）**。K 条采样轨迹聚类后，模态就是恢复策略（左步/右步/髋/臂/倒地），模态权重就是「当前该走哪条恢复链」的后验，模态间距就是「这些恢复方式是否真的不同」。R69 的 U_epi 在 R70 被重新解释为「恢复模式歧义」：不确定的不是世界，而是**该用哪种方式救自己**。

**灵感 5（恢复能力必须被认证，否则越接近边界越敢冒险）**
直觉：一旦系统知道「我有恢复策略」，它就可能主动把状态推到标称集外，去换取任务收益——这叫**恢复过度自信（recovery overconfidence）**。如果恢复证书在分布外过于乐观，系统会自信地进入一个真实 PNR 之外的状态，然后把 R68 那种「保守地失败」变成「激进地失败」。**误以为能救，比直接刹车更危险。** 所以本轮必须同时交付：可恢复包络的保守内近似（宁可低估 B）、分布外检测作为安全关键件、恢复动作的硬上限、以及「证书失效即退回 R68 + 受控倒地」的单调兜底。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（RESIL-RAS 总览）** RESIL-RAS = (RCE, RML, RMD, RVS, ARG, CFA, RAS-WM††)，其中 RCE 可恢复证书估计器、RML 恢复模式库、RMD 恢复模式分解、RVS 恢复价值选择器、ARG 自适应风险再分配器、CFA 认证倒地仲裁器。三不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i / R69 定义 293-i）；
(ii) **认证式放松**：任何对标称约束的放松，必须携带一个 valid 的可恢复证书，且放松量被包络余量严格上界（定义 317、引理 22）；
(iii) **单调兜底**：证书失效、OOD 越界或状态出 B_δ 时，逐指令退化为 R68/R69 最保守动作 + 认证受控倒地，安全侧永不弱于 R68。

**定义 311（可恢复包络 B_δ^T）** 设 K ⊆ X 为标称生存核（R68 的安全集）。给定恢复策略族 Π_rec、时限 T 与容差 δ，
B_δ^T(K) = { s ∈ X : ∃ π_rec ∈ Π_rec, P^{π_rec}(∃ t ≤ T, s_t ∈ K | s_0 = s) ≥ 1−δ }。
于是 K ⊆ B_δ^T ⊆ X；B_δ^T 是「还能被救回来」的状态集合，K 是「不需要救」的集合。δ 与 T 是可审计的显式契约，而非隐含参数。

**定义 312（不可恢复边界 PNR 与可恢复余量）** 不可恢复边界 ∂B_δ^T 称为 point of no return（PNR）。定义可恢复余量
ρ(s) = clip( d(s, ∂B_δ^T) / d_ref, 0, 1 )，
其中 d_ref 为归一化尺度。约定：s ∈ ∂B ⇒ ρ=0；s ∈ K 深部 ⇒ ρ=1；s ∉ B ⇒ ρ=0 且进入兜底。ρ 是 R70 的核心坐标——R68 用「不确定度」，R70 用「离再也回不来还有多远」。

**定义 313（平衡坐标下的解析 PNR 内近似）** 对 LIPM，发散分量（DCM）ξ = x + ẋ/ω（ω=√(g/z_c)）。给定可落脚集 𝒰_step(x)（步长下/上界、侧向可达、地形允许），迈步恢复存在当且仅当 ξ ∈ ⋃_{u∈𝒰_step} Reach(u)。据此定义解析内近似 B_LIPM ⊆ B_δ^T：
B_LIPM = { s : d(ξ, 𝒰_step(x)) ≤ 0 }（ξ 落在可落脚可达域内）。
当 ξ 离开 𝒰_step 时，只能依赖髋/臂策略或受控倒地——解析 PNR 给出**可计算、可验证的 B 下界**，学习部分只负责补 B_LIPM 之外无法解析建模的维度（摩擦、柔性、时延）。

**定义 314（恢复模式库 RML）** Π_rec = {π_m}_{m=1}^{M}，每个模式 m 携带：
进入前置条件 Pre_m ⊆ X（含 ρ ≥ ρ_m^min）、后置条件 Post_m ⊆ K、恢复时限 T_m、能耗/社交成本 c_m、以及认证成功率下界 p_m^cert（来自仿真 + 真实回放的分位数下界）。
典型模式：m=1 踝策略、m=2 髋策略、m=3 左迈步、m=4 右迈步、m=5 摆臂、m=6 降低重心、m=7 认证受控倒地。**倒地不是异常，是最后一个认证模式**。

**定义 315（恢复模式分解 RMD）** 把 R69 的 FMP 在「恢复上下文」c_t = (s, ρ, 接触状态) 下条件化，采样 K 条恢复轨迹 {ξ^{(j)}}，轨迹聚类得恢复模态 {m_k}、权重 ŵ_k、原型 ξ̄_k、模态内协方差 Σ_k。定义恢复熵 H_rec = −Σ ŵ_k log ŵ_k 与恢复可分性 Δ_min。R69 的 U_epi 在此被重解释为「恢复模式歧义」：不确定的不是世界状态，而是**该走哪条恢复链**。

**定义 316（恢复价值 RVS）** 对候选恢复模式 m，定义其相对「直接收紧/刹车」的恢复价值
RV(m|s) = E[ P_irrec(brake | s) − P_irrec(m | s) ] − c_m / λ_c，
其中 P_irrec 为到达 PNR 的概率。选择 m* = argmax_m RV(m|s)，仅当 RV(m*)>0 且 m* 通过证书门（定义 319）才允许放松。若无利可图，则「不恢复」也是合法决策——退化为 R68 的收紧。这与 R69 的 VoI 同构：VoI 选「问什么」，RV 选「怎么救」。

**定义 317（自适应风险再分配 ARG，两区制）** 设 λ 为 R68 的保守度标量。定义
- s ∈ K：λ(s) = λ_RAS(U)（沿用 R68/R69，只收紧）；
- s ∈ B_δ\K：λ(s) = λ_RAS(U) − Δλ_rec(ρ)，其中 Δλ_rec(ρ) = Δλ_max · h(ρ)，h 单调增、h(0)=0、h(1)≤1，且 Δλ_max 由证书余量与模式认证成功率上界给出；同时硬下界 λ(s) ≥ λ_hard > 0；
- s ∉ B_δ 或证书 invalid：λ(s) = λ_fallback(R68 最大保守) 并触发 CFA。
关键：**λ 可以下降，但只在认证可恢复区内，且下降量被 ρ 与证书严格封顶**。这是「风险再分配」，不是「风险否认」。

**定义 318（可恢复性主动探测 RPB）** 继承 R69 的 MINT：当恢复模式歧义大（H_rec 高、Δ_min 小）且预算允许时，执行一次**微探测** g（极小步、轻触、短时卸载），其本身必须让 s 始终留在 B_δ 内且余量 ≥ ε_probe。探测把「我处在哪条恢复链」从后验变为可观测，再交给 RVS。探测失败/超时/被扰动污染 ⇒ 不放松，直接走 R68 兜底。这把 R69 的「问」从「问世界」扩展到「**问自己的身体**」。

**定义 319（可恢复证书 J_REC）** J_REC = (B_version, certified_modes, p_cert_p10, ρ, ood_score, T_recover, fallback_plan, hash)。Valid ⇔ ρ ≥ ε_cert ∧ 所有被用模式的 p_cert_p10 ≥ 1−δ ∧ ood_score ≤ τ_ood ∧ fallback_plan 可用 ∧ B 版本与在线估计器一致。**证书是放松的唯一钥匙**；没有 valid J_REC，ARG 不得降低 λ。

**定义 320（稀有失败生成式增广 RFA）** 失败/恢复样本天然稀缺。用流模型作为**失败条件生成器**，在仿真中对失败流形做重要性采样，合成恢复轨迹；以分布鲁棒半径 ε_dr 约束合成分布与真实失败分布的偏离。目标是扩大 B 的**可验证覆盖**，而不是扩大 B 的**声称范围**——合成数据只用于收紧证书下界，不用于放宽。

**定义 321（认证受控倒地 CFA）** 当 s ∉ B_δ、或无可认证恢复模式、或时间窗已不足时，执行受控倒地：最小化冲击能量与关键部位风险（护头、屈膝、顺势滚动），并满足地形/高度前置条件。CFA 是带前置条件的认证模式，其决策与执行必须入审计。**把「摔」也变成一次被认证、可复盘的动作，而不是控制的崩溃点。**

**定义 322（恢复审计 VQAuditor-R）** 审计对象新增：放松是否由 valid 证书触发、恢复模式是否被恰当选择、探测是否越出 B 余量、倒地是否遵守前置条件、以及「反事实回放」——同一状态若走 R68 收紧是否会更好。结论回灌 AuditBuf，成为下一轮 RVS 的成本与置信先验。

**定义 323（失败分类与威胁模型 ℰ_RESIL）** ℰ_RESIL = ℰ_FLUID × ℰ_recovery，新增：
(a) **恢复剧场**：恢复策略只在仿真有效；
(b) **幸运吸引子**：某次恢复成功但缩小了后续可恢复域（短视恢复）；
(c) **可恢复性投毒**：对抗扰动把系统推入一个「估计 PNR 过乐观」的状态；
(d) **时延幻影**：传感器/执行时延使 ξ 看起来仍落在可落脚集内，实际已越界；
(e) **证书套利**：利用 B 估计器的分布外盲区主动越界换任务收益。

**定义 324（时间契约与活性）** 恢复不仅是安全（不越过 PNR），也是活性（在 T_m 内回到 K）。定义时限违约率 D_T = P(T_recover > T_m)。RESIL 同时优化安全（P_irrec）与活性（D_T），二者通过模式选择与 λ_hard 显式折中；只安全不活性的「永不动」不是合法解。

**定义 325（区制切换的滞回与无突变）** 在 K/B 边界设置滞回带 [ρ_in, ρ_out]，并对平衡控制器与恢复控制器做 CBF 混合：u = (1−α(ρ))·u_bal + α(ρ)·u_rec，α 连续、在滞回带外取 0/1。继承 R68 定理 15 的换装不变式，保证区制切换不引入控制突变。

**定义 326（RESIL-RAS 闭环与严格包含）** RESIL = R69 + (RCE, RML, RMD, RVS, ARG, CFA)。当 B_δ=K（无恢复余量）、或 Π_rec=∅、或 J_REC 恒 invalid 时，ARG 的放松量为 0，RESIL 逐指令退化为 R69/R68。因此 R68 是 RESIL 在「不可恢复」边界上的退化，安全侧不做任何让步，只在**确认可恢复**的状态上换取效率与成功率。

## 2. 关键算法骨架

```python
# IP-264 RCE：可恢复证书估计（解析 LIPM 内近似 + 学习残差 + OOD）
class RecoverabilityEstimator:
    def margin(self, s):                     # 返回 rho in [0,1] 与 ood
        rho_lipm = lipm_step_reach_margin(s) # capture point vs feasible step set, O(1)
        rho_learn = self.residual(s)         # 学习补摩擦/柔性/时延
        return min(rho_lipm, rho_learn), self.ood_score(s)   # 取保守 min

    def certificate(self, s, modes):
        m = self.margin(s)
        return J_REC(m.rho, modes.p10, m.ood, fallback=CFA.plan(s))

# IP-265/266 RML + RMD：恢复模式库与流式恢复模式分解
class RecoveryLibrary:
    def sample_modes(self, s, rho, K=4):
        ctx = recover_context(s, rho)
        trajs = fmp.sample(ctx, K)           # 复用 R69 流策略
        return cluster_trajectories(trajs)   # 左步/右步/髋/臂/倒地

# IP-267 RVS：恢复价值选择（无利可图即退化 R68）
def choose_recovery(s, modes, cert, lam_c):
    best = None
    for m in modes:
        if not cert.covers(m) or not m.pre(s): continue
        rv = (p_irrec(s, brake=True) - p_irrec(s, mode=m)) - m.cost / lam_c
        if best is None or rv > best.rv: best = (m, rv)
    return best if best and best.rv > 0 else None   # 不救 = R68 收紧

# IP-268/275 ARG + 主闭环：两区制风险再分配
def RESIL_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    # 1) R69：不确定性二分 + 交互（略，同 FLUID_RAS_round）
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, M.K), z, M.fmp.mode_head)
    # 2) RCE：算离 PNR 还有多远，而不是离 K 有多远
    rho, ood = M.rce.margin(z)
    cert = M.rce.certificate(z, M.rml.modes)
    # 3) 三种区制
    if rho <= 0 or not cert.valid or ood > TAU_OOD:
        lam = M.efs.max_conservative()          # 出 B 或证书失效 → R68 最保守
        plan, k = M.cfa.select(z, o)            # 认证受控倒地 / 兜底
        return finish(k, lam, plan), mark_fallback(cert)
    if rho >= RHO_IN:                           # 在 K 内：R68/R69，只收紧
        lam = M.efs.risk_scale(...)
        return M.fluid_round(z, o, lam)         # 原 FLUID-RAS
    # 4) B\K：恢复价值 + 认证放松
    rec_modes = M.rml.sample_modes(z, rho, K=4)
    m = M.rvs.choose_recovery(z, rec_modes, cert, M.lam_c)
    if m is None:
        return M.fluid_round(z, o, M.efs.risk_scale(...))   # 不救 → 收紧
    dlam = M.arg.relax(rho, cert)               # <= Delta_lambda_max * h(rho)
    lam  = max(M.efs.risk_scale(...) - dlam, LAM_HARD)
    k    = M.c_ras_wm.certified_prefix(m.action(t=0), ..., wm_preds, rho_min=EPS_CERT)
    M.vqa_r.submit(m, cert, rho, dlam, counterfactual='brake')   # 反事实审计
    return finish(k, lam, m)
```

## 3. 推导

**引理 19（认证放松的安全性）** 设 A99：B_δ^T 在恢复库 Π_rec 下是可控不变的（任何 π_m 的恢复轨迹在到达 K 前不离开 B_δ^T 的保守内近似），且每个被用模式的认证成功率下界为 1−δ_m。若 s ∈ B_δ\K 且 J_REC valid，则按定义 317 放松后的不可恢复失败概率 ≤ Σ_m ŵ_m δ_m + δ_B ≤ δ_total，其中 δ_total 是证书声明的总容差。要点：**放松的安全性不来自「少收紧」，而来自「存在一条被认证的回路」**；这解释了为什么只在 B 内允许 λ 下降。

**引理 20（LIPM 的解析 PNR 与余量下界）** 对 LIPM，若 DCM ξ 落在可落脚可达域 𝒰_step 内，则存在迈步恢复使 ξ 在一步内进入 K；ξ 到 𝒰_step 边界的距离给出 ρ 的一个可计算下界 ρ ≥ d(ξ, ∂𝒰_step)/d_ref。系：**解析内近似 B_LIPM 可以否决学习估计的过度乐观**——两者取 min 即得保守 B，这是定义 313 用 min 而非 max 的原因。

**引理 21（恢复过度自信的分布偏移上界）** 若证书在 D_train 上以 1−δ 成立，而在线分布为 P，则真实成功率 ≥ 1−δ−TV(P, D_train)−ε_model。因此 **OOD 检测是安全关键件而非可选件**：当 ood_score > τ_ood 时，即便 ρ 看起来很大，也必须视同证书 invalid（定义 319）。这把 R69 的「问错比不问更危险」翻译成行为侧：**救错比不救更危险**。

**引理 22（放松的单调封顶）** 定义 317 的放松量满足 Δλ_rec(ρ) ≤ Δλ_max·h(ρ)，且 h(0)=0。故 ρ→0 时 Δλ_rec→0，RESIL 连续退化为 R68；ρ→1 时放松取最大但仍受 λ_hard 与证书约束。系：**不存在「越接近失败越激进」的无界激励**——越接近 PNR，可用的放松越少，而不是越多。

**定理 18（RESIL 严格包含 R68/R69，且在可恢复状态上更优）** 在 A99 下，对任意状态 s，RESIL 的期望不可恢复失败 ≤ R68/R69；当 B_δ=K、Π_rec=∅ 或 J_REC invalid 时逐指令相同（定义 326）。在 s ∈ B_δ\K 且「刹车会导致不可恢复、而认证恢复存在」的状态上，RESIL 以 ≥1−δ 的概率避免 R68 会发生的失败——即 **R68 的保守在恢复区不是安全，而是失败**。这说明「只收紧」只是安全策略的一个边界情形。

**定理 19（区制切换的连续性与无突变）** 采用定义 325 的滞回 + CBF 混合后，u 在 K/B 边界连续；切换只在 ρ 越过 [ρ_in, ρ_out] 时发生，且继承 R68 定理 15 的换装不变式 ⇒ 控制连续、无突变、无抖振。附加：CFA 触发时进入一个显式的「受控倒地流形」，其入口与常规控制共享同一状态，不产生跳变。

**定理 20（恢复活性与时限）** 若 s ∈ B_δ^T，则存在 π_m ∈ Π_rec 使 P(回到 K 的时间 ≤ T) ≥ 1−δ；若所有模式的时限上界 T_m 之和仍小于 T，则证书不得声明 s ∈ B_δ^T（定义 324）。系：**「可恢复」必须同时是「及时可恢复」**，否则只是把不可恢复延迟了 T 秒；这防止证书用「最终会好」掩盖「来不及」。

## 2. 形式化定义（要点版）

**定义 310（总览与三不变式）** RESIL-RAS=(RCE,RML,RMD,RVS,ARG,CFA,RAS-WM††)；零学习写操作继承；认证式放松（放松须有 valid J_REC 且被 ρ 封顶）；单调兜底（证书失效/OOD/出 B ⇒ R68 最保守 + 认证倒地，安全永不弱于 R68）。

**定义 311–312（可恢复包络与 PNR）** `B_δ^T={s:∃π_rec, P(∃t≤T,s_t∈K)≥1−δ}`，`K⊆B`；`∂B` 为 PNR；`ρ(s)=clip(d(s,∂B)/d_ref)`。安全坐标从「离失败多远」改为「离再也回不来多远」。

**定义 313（解析内近似）** LIPM 的 DCM `ξ=x+ẋ/ω`；迈步恢复存在 ⇐ `ξ∈⋃Reach(𝒰_step)`；`B_LIPM={s:ξ∈𝒰_step}`；在线 ρ 取 `min(ρ_lipm, ρ_learn)` 以否决学习估计的过度乐观。

**定义 314–315（恢复库与分解）** `Π_rec` 七模式（踝/髋/左右步/臂/降重心/受控倒地），各带 `Pre/Post/T/c/p_cert`；RMD 把 FMP 条件在 `(s,ρ,接触)`，聚类得恢复模态与 `H_rec`；R69 的 U_epi 重解释为「恢复模式歧义」。

**定义 316（恢复价值）** `RV(m|s)=E[P_irrec(brake)−P_irrec(m)]−c_m/λ_c`；`m*=argmax RV`，仅当 `RV>0` 且通过证书门才放松；否则「不救」= 退 R68。与 R69 的 VoI 同构：VoI 选问什么，RV 选怎么救。

**定义 317（两区制风险再分配）** `s∈K`: `λ=λ_RAS`；`s∈B\K`: `λ=λ_RAS−Δλ_max·h(ρ)`，硬下界 `λ≥λ_hard`；`s∉B` 或证书 invalid: `λ=λ_fallback` + CFA。λ 可下降，但只在认证可恢复区内且下降量被 ρ 与证书封顶——风险再分配，不是风险否认。

**定义 318（可恢复性主动探测）** 恢复模式歧义大且预算允许时，执行微探测 g；g 必须使 s 始终留在 B 内、余量 ≥ ε_probe；探测揭示「我在哪条恢复链」，再交 RVS；失败/超时/污染 ⇒ 不放松、退 R68。

**定义 319–321（证书/增广/倒地）** J_REC 为放松唯一钥匙，`valid ⇔ ρ≥ε_cert ∧ 所有用模式 p_cert_p10≥1−δ ∧ ood≤τ ∧ fallback 可用`；RFA 用流模型合成稀有恢复轨迹、只收紧证书下界；CFA 让受控倒地成为最小冲击能量、护头、可审计的最后认证模式。

**定义 322–325（审计/威胁/活性/无突变）** VQAuditor-R 审放松依据、模式选择、探测越界、倒地前置条件与反事实；ℰ_RESIL 新增恢复剧场、幸运吸引子、可恢复性投毒、时延幻影、证书套利；`D_T=P(T_recover>T_m)` 度量活性；K/B 边界用滞回 + CBF 混合保证连续无突变。

**定义 326（严格包含）** `B_δ=K`、`Π_rec=∅` 或 `J_REC` 恒 invalid 时，放松量为 0，RESIL 逐指令退化为 R69/R68。R68 是 RESIL 在「不可恢复」边界上的退化。

```python
# IP-264 RCE：可恢复证书（解析 LIPM + 学习残差 + OOD，取保守 min）
class RecoverabilityEstimator:
    def margin(self, s):
        return min(lipm_step_reach_margin(s), self.residual(s)), self.ood_score(s)

    def certificate(self, s, modes):
        rho, ood = self.margin(s)
        return J_REC(rho, modes.p10, ood, CFA.plan(s))

# IP-265/266 RML + RMD：恢复库 + 流式恢复模式分解（复用 R69 FMP）
class RecoveryLibrary:
    def sample_modes(self, s, rho, K=4):
        trajs = fmp.sample(recover_context(s, rho), K)
        return cluster_trajectories(trajs)          # 踝/髋/左步/右步/倒地

# IP-267 RVS：恢复价值选择（无利可图即退化 R68）
def choose_recovery(s, modes, cert, lam_c):
    best = None
    for m in modes:
        if not cert.covers(m) or not m.pre(s): continue
        rv = (p_irrec(s, brake=True) - p_irrec(s, mode=m)) - m.cost / lam_c
        if best is None or rv > best.rv: best = (m, rv)
    return best if best and best.rv > 0 else None

# IP-268/275 ARG + 主闭环：两区制风险再分配
def RESIL_round(M, obs):

    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, M.K), z, M.fmp.mode_head)

    if rho >= RHO_IN:                               # K 内：R68/R69 只收紧

    m   = M.rvs.choose_recovery(z, rec, cert, M.lam_c)

    dlam = M.arg.relax(rho, cert)                   # <= Delta_lambda_max * h(rho)
```

## 4. 推导

**引理 19（认证放松的安全性）** A99（B 在 Π_rec 下可控不变、各模式认证成功率下界 1−δ_m）下，s∈B\K 且 J_REC valid 时，放松后的不可恢复失败概率 ≤ Σ ŵ_m δ_m + δ_B。安全性来自「存在一条被认证的回路」，而非「少收紧」；这解释了为何只在 B 内允许 λ 下降。

**引理 20（LIPM 解析 PNR 与余量下界）** DCM ξ 落在可落脚可达域内 ⇒ 存在一步恢复使 ξ 进 K；ρ ≥ d(ξ, ∂𝒰_step)/d_ref。系：解析内近似可否决学习估计的过度乐观，故在线 ρ 取 min。

**引理 21（恢复过度自信的分布偏移上界）** 证书在 D_train 上以 1−δ 成立、在线分布 P 时，真实成功率 ≥ 1−δ−TV(P,D_train)−ε_model。因此 OOD 检测是安全关键件：`ood>τ` 即便 ρ 大也视为证书 invalid——「救错比不救更危险」。

**引理 22（放松的单调封顶）** `Δλ_rec(ρ)≤Δλ_max·h(ρ)`、`h(0)=0` ⇒ ρ→0 时放松→0，RESIL 连续退化为 R68；不存在「越接近失败越激进」的无界激励——越接近 PNR 可用放松越少。

**定理 18（严格包含且可恢复状态更优）** A99 下 RESIL 期望不可恢复失败 ≤ R68/R69；`B=K`/`Π_rec=∅`/证书 invalid 时逐指令相同。在「刹车会导致不可恢复、认证恢复存在」的状态上，RESIL 以 ≥1−δ 概率避免 R68 会发生的失败——**R68 的保守在恢复区不是安全，而是失败**。

**定理 19（区制切换无突变）** 滞回 + CBF 混合使 u 在 K/B 边界连续；切换仅在 ρ 越过 [ρ_in,ρ_out] 时发生，继承 R68 定理 15 换装不变式 ⇒ 连续、无突变、无抖振；CFA 入口与常规控制共享状态，不产生跳变。

**定理 20（恢复活性与时限）** s∈B_δ^T ⇒ 存在 π_m 使 P(回 K 时间 ≤ T) ≥ 1−δ；若所有模式时限上界之和仍小于 T，证书不得声明 s∈B_δ^T。系：可恢复必须「及时可恢复」，否则只是把不可恢复延迟 T 秒。

## 7. 本轮最大风险

**一句话**：RESIL-RAS 的全部收益押在「可恢复包络 B_δ 保守且可校准」这一前提上——**若 RCE 在分布外把真实 PNR 估得过于乐观（时延、摩擦、柔性、地形未建模），系统就会主动进入「看起来能救、实际回不来」的状态，把 R68 的「保守地失败」升级成「自信地失败」：误以为能救，比直接刹车更危险。**

**次级风险与缓解**：解析 B 过保守导致效率损失（以 B_LIPM 为下界 + 学习残差补覆盖，E301）；恢复剧场/仿真到现实差距（真实回放 + 证书 p10 下界 + E313）；恢复过度自信（OOD 安全关键件 + λ_hard + E307）；短视恢复缩小后续包络（反事实回放 + 幸运吸引子检测，E310）；倒地本身伤害（CFA 认证 + 冲击能量约束，E309）；区制切换抖振（滞回 + CBF，定理 19）。
