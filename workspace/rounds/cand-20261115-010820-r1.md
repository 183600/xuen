# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 1 轮；本轮灵感：「交互设计」×「社会影响」）

> R69 把交互变成一等动作，问出「我该向谁求证、还能问什么」，并用「k 个正交证据源一致」给提问上了证据纪律。但它仍把交互当成**一次性的、孤立的、发生在单个用户身上的信息交易**：
> 1. **它只优化「此刻问什么」，不设计「这套交互本身长什么样」**——R69 的 `g=(g_gaze,g_probe,g_ask)` 是无类型、无 signifier、无 feedforward 的裸动作空间；人看到的不是「它为什么问、我可以拒绝吗」，而是「机器突然凑过来」。设计的缺位直接污染了数据：**不是人不想说，是交互没给他说真话的条件**。
> 2. **它假设被问者是孤立的**——但同一个系统会在一个人群里反复交互；别人怎么答、系统表现得多自信，都会改变这个人怎么答。R69 的「k 源一致」在相关撒谎面前失效，而社会影响最擅长的恰恰是**批量制造相关性**。
>
> 两个灵感正好补上这两块：
> - **交互设计**：交互的价值不只在「取到什么信息」，更在**被设计出来的可理解性 / 可拒绝性 / 可预期性**——affordance、signifier、progressive disclosure、feedback、contestability。糟糕的设计会让人**给不出真话**，也会让系统**问出假话**。
> - **社会影响**：**系统不是在测量人群，系统在塑造人群**。人的回答被他人、被系统的语气与自信度、被「大家都这么说」所影响；交互策略一旦公开，人群会学习它、利用它、或被它操纵。
>
> 核心命题：**把 R69 的「逐次最优提问」升级为「交互设计选择 + 社会均衡评估」：优化对象从单个信息动作 `g` 变成交互语法 `Γ` 与策略 `π_I`；评估对象从「这一次的 VoI」变成「人群对该设计的均衡响应下、含外部性的福利」；并加三道硬闸——不可操纵（偏好不变性）、可争辩（拒绝/反转/不报复）、负担公平（谁被问得更多）。** 命名 **POLIS-RAS**（Population-aware, Opacity-bounded, Legible, Incentive-compatible, Socially-equilibrium 风险自适应闭环）——城邦：一个被设计出来的公共空间，公民如何行动，取决于这个空间给了什么 affordance、立了什么规矩。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我设计的这套交互，在所有人身上反复发生之后，会造出怎样一个世界——以及我有没有在用提问操纵人**」。

## 0. 直觉与动机

**灵感 1（交互设计 → 问句不是消息，是一次被设计出来的体验）**
直觉：R69 的 `ask` 是从动作空间里采样的一句软提示，评价它只看 VoI。但人接收到的从来不是「一个信息动作」，而是一整套设计：一个 **signifier**（机器人看向我 = 它注意到了我）、一段 **feedforward**（「我可以帮你确认一下吗？」）、一条**拒绝路径**（「不用」）、以及事后**反馈**。同一句「你还好吗」，用突然逼近 + 高音量说，和用先停下、眼神征询、给出「如果不想说也没关系」的选项来说，取到的信息天差地别。所以交互设计引入的第一性对象不是 `g`，而是**交互语法 `Γ`**：一组带类型、signifier、前/后置条件、成本、可逆性的「可执行动作」。R69 的自由动作空间只是 `Γ` 缺失时的退化情形。

**灵感 2（legibility = 可识别性，是测量的前提而不是装饰）**
直觉：R69 的 VoI 隐含 `p(y|M,g)` 已知。但如果人根本猜不准系统为什么问（把「确认安全」听成「怀疑我」），他的回答就是对**错误意图**的响应。此时无论采多少数据，偏差都不会消失——这是 **bias，不是 variance**。**可理解性给可识别性设了一个天花板**：legibility 必须作为可测的硬约束（人对系统下一步动作及理由的预测准确率），而不是「体验优化」的软指标。推论：当歧义大且可理解性差时，**改设计比多问更值钱**。

**灵感 3（社会影响 → k 源一致在相关面前是幻觉）**
直觉：R69 用「k 个正交源一致」对抗投毒，前提是源之间条件独立。但社会影响最擅长的就是**制造相关**：一个人看到别人都点头他也点头；一家人被同一种话术说服；系统越笃定，人越容易附和。这时 k 个「独立」源其实只是一个源被复制了 k 次。需要的是**有效样本量** `n_eff = k/(1+(k−1)ρ)` 与「主动挑低相关源」，而不是数人头。更狠的是，当从众系数 × 网络谱半径趋近 1，系统会出现**级联**：一个种子信号就能造出「共识」。**观测到的共识，可能只是一台放大器。**

**灵感 4（系统在塑造人群：performativity）**
直觉：R69 的观测模型假设数据分布由世界决定。但系统的交互策略会**训练**人：总问「你没事吧」，人学会秒答「没事」；总奖励顺从回答，人学会给系统想听的。于是数据漂移里混入了 **D_policy**（策略自己造出来的）与 **D_world**（世界真的变了）。只看单一策略，二者**不可识别**。必须留一条**随机的设计留出（design holdout）**作工具变量——一小部分交互跑参照策略，才能把因果效应分离出来。这是本轮最硬的技术要求：**没有外生变化，就没有社会影响的因果结论**。

**灵感 5（不可操纵与可争辩 → 把伦理写成硬约束，而不是事后声明）**
直觉：R69 的最深风险是「问错比不问更危险」。R70 的版本更严重：**一套被设计得很顺滑的交互，可以系统性地改变人的偏好而不只是告知事实**——这就越过了测量、进入了操纵。所以要有**偏好不变性**硬约束：交互只能改变人对**事实**的信念，不能改变人的**效用 / 选择排序**；用「同事实、不同框架」的配对反事实来检测（`Δ_pref > κ_max` 即判操纵）。再加**可争辩性**：任何动作可拒绝、可反转、拒绝不受惩罚、人可以反过来提议问什么。这不是道德装饰——**被胁迫的回答本身就是有偏的**，可争辩性同时是数据有效性的条件。

**灵感 6（统一视角 → 为「你的问题所造出的世界」而设计）**
直觉：把上面五条合成一句话：R69 在**一个给定的世界里**选最优问题；R70 必须**为一个由自己的问题所塑造的世界**选设计。目标不是一个状态的 `argmax VoI`，而是一个**设计-响应不动点**：系统承诺 `π_I` → 人群对其最优响应 → 系统在这个被诱发的分布上做推断。R69 的「逐次贪婪」只是该不动点在「单用户、无耦合、无偏好效应」处的切线性近似。这决定了本轮的理论姿态：**R69 是 POLIS 在「孤立、无影响」边界上的严格退化**（与 R68⊂R69 同构，安全侧继续不让步）。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（POLIS-RAS 总览）** POLIS-RAS = (IGD, LEG, PCG, SIE, IPB, CAV, EBA, PDR, EQV, RAS-WM§)。五不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **交互即设计动作**：任何信息动作必须属于当前交互语法 `Γ`，带 signifier、feedforward、反馈与拒绝路径；`Γ` 之外的裸动作被禁止；
(iii) **交互语法静默不变**：`Γ` 有版本号，只在 episode 边界经设计治理（定义 326）变更，episode 内冻结——不允许「边部署边偷偷改问法」；
(iv) **社会硬闸**：不可操纵（定义 318–319）、可争辩（定义 320）、负担公平（定义 321）在每次交互前逐项检查；
(v) **单调包含**：任一社会层条件不可识别或越界 ⇒ 逐指令退回 R69（再退回 R68），风险链 `POLIS ⊆ R69 ⊆ R68`。

**定义 311（交互语法 Γ）** `Γ = {(g_i, τ_i, pre_i, post_i, σ_i, φ_i, c_i, rev_i)}`：类型、前置条件、后置条件（可观测的响应类型）、signifier（人感知到什么）、feedforward（被告知将发生什么）、成本、可逆性。交互策略 `π_I : (state, uncertainty) → Δ(Γ)`。R69 的 `𝒜_info` 是 `Γ` 退化为「无类型、无 signifier、`pre≡⊤`」的特例。

**定义 312（legibility 与信息上限）** `L(π_I) = I(S; g)`（系统内部不确定性签名 `S` 与所选动作的可观测互信息）+ 人类预测准确率 `A_h = P(human predicts (g, reason) | σ(g), ctx)`。约束 `L ≥ ℓ_min`、`A_h ≥ a_min`。设人把真实意图 `I` 误读为 `Î` 的概率为 `ε`，则响应偏差下界 `|E[ŷ]−E[y]| ≥ ε·Δ_resp − σ/√n`（`Δ_resp` 为意图条件响应差）——**legibility 是可识别性的天花板，不随样本量消失**。

**定义 313（渐进披露阶梯）** 在 `Γ` 上定义打扰度全序 `≺`：注视 `≺` 等待 `≺` 闭合式提问 `≺` 开放式提问 `≺` 物理探针。策略须遵守：采用更高打扰度动作，必须已尝试或已排除所有更低打扰度且 `PVoI>0` 的动作（安全紧急可越过，但须留审计理由）。

**定义 314（人群博弈与均场均衡）** 人群类型 `θ ∈ Θ`（合作 / 隐私敏感 / 投机 gaming / 脆弱 / 对抗），先验 `μ`。系统承诺 `π_I`；每个人观察交互历史（或摘要）后选择响应策略 `r(θ)` 最大化 `u_h(r;θ,π_I) − cost`。不动点处得到**诱导响应核** `K_{π_I}(y|M,θ)`——这才是系统真正的数据生成过程，而不是「诚实的」`p(y|M,g)`。

**定义 315（诱导核与均衡后验）** 系统看到的数据由 `K` 生成；均衡后验 `b_eq(M) ∝ p(M)∏_t K_{π_I}(y_t|M)`。R69 的后验用 `p` 代替 `K`，在 `K≠p` 时是**误设**的：它会自信地收敛到一个被策略诱发出来的世界。

**定义 316（有效证据与同侪相关）** 证据源 `i=1..k`，由社会图 `G_soc`（同户 / 同角色 / 同社区 ⇒ 高相关）估计两两响应相关 `ρ_ij`。有效样本量 `n_eff = (Σw)²/Σw²` 或 `k/(1+(k−1)ρ̄)`。R69 的「k 个正交源」升级为「`n_eff ≥ k_req`」，且源选择主动最大化多样性（最小化 `ρ`）。

**定义 317（从众放大与级联）** 响应 `y_i = h(M_i, s_i, θ_i)`，`s_i` 为观察到的社会信号（他人回答 / 系统表达的自信度）；从众系数 `c_i = ∂y_i/∂s_i`。网络谱半径 `λ_G` 下，线性响应放大 `A = 1/(1−c̄λ_G)`。`A` 大时，观测到的「共识」可能来自单个种子信号的级联；证据权重须按 `1/A²` 折减。`c̄λ_G→1` 为可监测的临界预警。

**定义 318（影响力与偏好不变性）** 把响应分解为事实通道与框架通道 `y = f(facts, framing)`。**偏好不变性**：对任意预算内 `π_I`，给定相同事实信息，人的最优动作分布 `P(a_h^*)` 与效用排序不变；交互只能更新人对**事实**的信念，不能改变其**效用 `u` / 选择排序**。影响力 `κ(π_I) = sup |Δ(action) 仅由非事实框架引起|`，硬约束 `κ ≤ κ_max`。

**定义 319（操纵检测）** 对「同事实、不同框架」的匹配对 `(Γ, Γ')`，`Δ_pref = W_1(P(a_h^*|Γ), P(a_h^*|Γ'))`。`Δ_pref > κ_max` ⇒ 判操纵，动作作废；自动化偏差 / 权威偏差表现为 `Δ_pref` 随系统表达自信度单调上升。

**定义 320（可争辩性与能动性 CAV）** 每个动作支持拒绝 / 反转 / 不报复：拒绝不得提高后续打扰度、不得降低服务水平；反转须恢复先前状态；人可**反过来**提议问什么。度量「能动性保持率」。被胁迫的回答视为无效证据（同时是**偏差源**，不只是伦理问题）。

**定义 321（负担与公平账本 EBA）** 每人注意力预算 `B_h`；群体 `g` 负担 `b_g = E[cost]`，约束 `max_g b_g − min_g b_g ≤ δ` 且 `b_g ≤ B_g`。外部性：成本由人承担、收益归任务 ⇒ 记账；若某群体负担高而收益低，判**抽取性交互**并禁止。另设慢变量「合法性/信任预算」，被过度打扰消耗、被有效帮助补充。

**定义 322（performativity 与设计留出）** 观测漂移 `D_t = D_world + D_policy(π_I) + noise`。单一策略下二者**不可识别**（观测等价）。引入**随机设计留出**：一小部分交互按参照策略 `π_0`（R69 默认）执行，作为工具变量；`D_policy` 仅在重叠状态上可识别，方差 `~1/(c·n)`。故最小留出覆盖率 `c_min` 是**必要条件**，不能靠「盯着漂移看」替代。

**定义 323（均衡感知 VoI / PVoI）** `PVoI(g;Γ,π_I) = [H_{b_eq}(M|o) − E_{y~K_{π_I}}H_{b_eq}(M|o,y)] + Δ_future − c(g) − e(g)`，其中 `Δ_future` 含三项动态代价：`−Δ n_eff`（提问可能降低未来证据独立性）、`−Δ legitimacy`（打扰耗信任）、`−Δ legibility`（若引入新动作破坏可理解性）。熵在诱导核 `K` 下计算，而非 `p`。R69 的 VoI 是 `Δ_future=0, K=p` 的特例。

**定义 324（两级包含退避）** 若出现任一：社会模型不可识别（留出覆盖不足）、影响力检测失败/不可用、公平越界、`n_eff<k_req` 且源多样化后仍不足、`legibility<ℓ_min`、performativity 疑似未决 ⇒ 关闭 POLIS 设计层，**逐指令**运行 R69；R69 再按自身条件退回 R68。风险链单调。

**定义 325（证书 J_POLIS）** `J_POLIS = (J_FLUID, grammar_ver, L, A_h, n_eff, κ, Δ_pref_max, disparity, holdout_coverage, performativity_est, design_audit_hash)`。`Valid ⇔ Valid(J_FLUID) ∧ L≥ℓ_min ∧ A_h≥a_min ∧ κ≤κ_max ∧ disparity≤δ ∧ n_eff≥k_req ∧ coverage≥c_min`。

**定义 326（设计治理与版本化 DGV）** `Γ` 的任何离线变更须过设计审查门：影子/AB 评估、明确的人类影响评估、变更日志、可回滚；episode 内冻结；回滚到旧 `Γ` 始终可用。这是「社会影响」要求下的**制度层**，与算法层同等必要。

# IP-264 IGD：交互语法——类型化、可感知、可拒绝
class InteractionGrammar:
    def __init__(self, moves, version):          # Γ，版本冻结
        self.moves, self.version = moves, version
    def legal(self, s):                          # 只允许 Γ 内动作 + 阶梯
        return [m for m in self.moves
                if m.pre(s) and self.ladder.allows(m, s)]
    def present(self, m):                        # signifier + feedforward + 拒绝路径
        return Signaled(m.sigma, m.phi, refuse=m.revocable, reverse=m.rev)

# IP-265 LEG：可理解性（互信息 + 人类预测准确率）
def legibility(pi_I, grammar, human_model, s):
    L   = mutual_info(internal_uncertainty_signature(s), grammar.choose(pi_I, s))
    A_h = human_model.predict_accuracy(s, grammar.signifier_of, grammar.choose(pi_I, s))
    return L, A_h

# IP-267 SIE：有效样本量 + 从众放大
def effective_evidence(sources, G_soc, conformity):
    rho  = pairwise_response_corr(sources, G_soc)
    n_eff = kish_neff(rho)                        # k / (1 + (k-1)*rho)
    amp   = 1.0 / max(1e-6, 1.0 - mean(conformity) * spectral_radius(G_soc))
    return n_eff, amp                              # amp 大 ⇒ 共识打折

# IP-268 IPB：偏好不变性（同事实、不同框架的配对反事实）
def preference_invariant(move, probe):
    d = wasserstein(probe.human_action_dist(move.framing),
                    probe.human_action_dist(move.neutral_control))
    return d <= KAPPA_MAX                          # 否则判操纵

# IP-272 EQV：均衡感知 VoI（含外部性与动态代价）
def pvoi(move, b_eq, K_induced, social, budget):
    gain = entropy(b_eq) - expected_entropy(b_eq, move, K_induced)
    dyn  = -delta_future_neff(move) - delta_legitimacy(move) - delta_legibility(move)
    return gain + dyn - move.cost - externality(move)
    # R69 的 VoI = 此式在 K=p, dyn=0, externality=0 的边界

# IP-277 主闭环（继承 R69，仅在交互处置处插入 POLIS 设计/社会层）
def POLIS_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, _ = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    # 0) 社会层可识别性与硬闸（不满足 → 逐指令退回 R69）
    if not (M.pdr.holdout_ok() and M.pcg.identified()):
        return M.fluid_round(obs)
    n_eff, amp = M.sie.effective_evidence(M.evidence, M.G_soc, M.conformity)
    # 1) 只在交互语法内、且守阶梯地选动作
    best = None
    for g in M.igd.legal(o):
        if not M.cav.ok(g):            continue       # 可拒绝/可反转/不报复
        if not M.ipb.preference_invariant(g): continue  # 不可操纵
        if not M.eba.burden_ok(g, o):  continue       # 负担公平
        s = M.eqv.pvoi(g, M.pcg.posterior(), M.pcg.induced_kernel(),
                       (n_eff, amp), M.budget)
        if best is None or s > best.s: best = (g, s)
    if best is None or best.s <= 0:
        return M.fluid_round(obs)                     # 无利可图/不安全 → R69
    g = best[0]
    y = M.igd.present_and_execute(g)                  # signifier+feedforward+拒绝路径
    M.pcg.update(y, n_eff, amp)                       # 在诱导核下更新后验
    M.eba.charge(g, y)                                # 负担/公平账本
    M.pdr.observe(M.pcg)                              # performativity 监测
    M.vqa_s.submit_async(g, y, n_eff, amp)            # 社会审计
    return M.fluid_continue(modes, y)                 # R69 下游（λ/认证/执行）
```

## 3. 推导

**引理 19（社会相关击穿 k 源一致）** 设 k 个源各自出错率 `δ_p`，但错误两两相关 `ρ`。则「k 源同时错且一致」的概率下界不再按 `ρ^{k}` 指数衰减，而是由共同因（herding）主导：`P(all wrong & agree) ≥ δ_common`（与 k 无关），且 `n_eff = k/(1+(k−1)ρ) < k`。**系**：R69 引理 18 的 `δ_p ρ^{k−1}` 只在 `ρ=0` 成立；一旦存在社会耦合，`k` 源一致**不构成**证据，必须改用 `n_eff≥k_req` + 主动多样化（跨户/跨角色，最小化 `ρ`）+ 可验证锚点。

**引理 20（legibility 是可识别性天花板）** 设真实意图 `I`，感知意图 `Î`，`P(Î≠I)=ε`，响应 `y~p(·|Î,g)`。则响应偏差下界 `|E[ŷ]−E[y]| ≥ ε·Δ_resp − σ/√n`，其中 `Δ_resp=‖E[y|I]−E[y|Î]‖`。**系**：该偏差是系统性的（不随 `n` 消失）；当 `ε` 大时，提高 legibility 的边际收益高于增加样本或增加提问次数；R69 的 VoI 用 `p` 计算，会系统性高估此类交互的价值。

**引理 21（从众临界与级联）** 在谱半径 `λ_G`、平均从众 `c̄` 的网络上，线性响应放大 `A=1/(1−c̄λ_G)`。当 `c̄λ_G→1` 时，独立扰动被无界放大，单个种子即可造成「共识」；此时观测一致性对应的有效证据量按 `∝1/A²` 折减。**系**：`A` 是可在线监测的**早期预警**；`A` 高时，任何「大家都同意」都必须降权，否则系统会把级联误读为真值。

**引理 22（performativity 的可识别性需要外生变化）** 单一策略 `π_I` 下，`(D_world, D_policy)` 在观测上等价，不可分别识别。给定随机留出覆盖 `c` 与参照策略 `π_0`，在重叠状态上 `D_policy` 可识别，估计方差 `~1/(c·n)`。**系**：`c_min` 是**必要条件**；「只监控漂移、不设留出」在因果上不成立。

**定理 18（POLIS 严格包含 R69/R68）** 当人群规模为 1 或社会耦合 `c̄=0`（`ρ=0`）、无投机（`K=p`）、无偏好效应（`κ=0`）、`Γ` 等价于 R69 全动作空间且 `ε=0`（完全 legible）、无外部性时，`PVoI` 逐项化为 R69 的 VoI，社会硬闸与均衡后验均退化为恒等，决策**逐指令相同**。故 R69 是 POLIS 在「孤立、无影响」边界上的退化；叠加 R69⊇R68，得 `POLIS ⊆ R69 ⊆ R68` 的单调安全链，安全侧不做任何让步。

**定理 19（不可操纵 ⇒ 福利序不变）** 在偏好不变性（定义 318–319）下，人动作的任何变化只经由**事实信念**中介；由 Blackwell 信息序，给定真实效用 `u`，更多事实信息下人的期望效用不降。故系统无法通过框架降低人的效用来自利；反之，任何 `Δ_pref>κ_max` 都是可检测的违规。**系**：操纵在本框架里不是「坏结果」，而是**可判定的约束违反**。

**定理 20（贪婪 VoI 可任意有害；均衡感知严格更优）** 构造：便宜问题 `q1` 给出可被人群迅速学会的低成本回答，昂贵问题 `q2` 给出可验证锚点。R69 贪婪 VoI 永远选 `q1`，人群学会后 `q1` 的回答趋于与真值无关，后验以高置信收敛到错误 `M`，误差不降；POLIS 的 `PVoI` 含 `−Δn_eff`、`−Δlegitimacy` 与 `q2` 的验证价值，会选择 `q2`，误差收敛到 0。当投机成本 `→0` 时，二者误差差**无界**。**系**：逐次贪婪不只是次优，而是**会自信地错**——这是 R70 必须替换 R69 目标的根本原因。

**定理 21（含退避的无新害）** 所有设计动作仍是动作，逐个过 C-RAS-WM 认证（继承 R69 定义 302）；三个社会硬闸可在线检查；任一闸失败或不可识别 ⇒ 逐指令执行 R69。故约束成立时 `risk(POLIS) ≤ risk(R69)`，失败时 `=risk(R69)`，无新增物理风险。（**前提**：闸门检查本身是可靠的——若社会模型错设使闸门误通过，则本定理不保，这正是本轮最大风险。）

    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    if not (M.pdr.holdout_ok() and M.pcg.identified()): return M.fluid_round(obs)  # 退 R69
    n_eff, amp = M.sie.effective_evidence(M.evidence, M.G_soc, M.conformity)
    best = None
    for g in M.igd.legal(o):
        if not M.cav.ok(g) or not M.ipb.preference_invariant(g): continue
        if not M.eba.burden_ok(g, o): continue
        s = M.eqv.pvoi(g, M.pcg.posterior(), M.pcg.induced_kernel(), (n_eff, amp), M.budget)
        if best is None or s > best.s: best = (g, s)
    if best is None or best.s <= 0: return M.fluid_round(obs)                       # 退 R69
    g = best[0]; y = M.igd.present_and_execute(g)
    M.pcg.update(y, n_eff, amp); M.eba.charge(g, y); M.pdr.observe(M.pcg)
    M.vqa_s.submit_async(g, y, n_eff, amp)
    return M.fluid_continue(modes, y)
```

## 4. 推导

**引理 19（社会相关击穿 k 源一致）** 错误两两相关 `ρ` 时，「k 源同时错且一致」由共同因主导，`P(all wrong & agree) ≥ δ_common`（与 k 无关），`n_eff=k/(1+(k−1)ρ)<k`。R69 引理 18 的 `δ_p ρ^{k−1}` 仅 `ρ=0` 成立；须改用 `n_eff≥k_req` + 跨户/跨角色多样化 + 可验证锚点。

**引理 20（legibility 是可识别性天花板）** 误读概率 `ε` 下，偏差 `|E[ŷ]−E[y]| ≥ ε·Δ_resp − σ/√n`，是系统性 bias、不随 n 消失。**系**：ε 大时，提升 legibility 的边际收益高于多问/多样本；R69 的 VoI 会高估此类交互。

**引理 21（从众临界与级联）** `A=1/(1−c̄λ_G)`；`c̄λ_G→1` 时单种子即可造「共识」，有效证据按 `∝1/A²` 折减；`A` 可在线作早期预警。

**引理 22（performativity 需外生变化）** 单一策略下 `(D_world,D_policy)` 观测等价；随机留出覆盖 `c` 时在重叠状态可识别，方差 `~1/(c·n)`。故 `c_min` 是必要条件，「只看漂移」不成立。

**定理 18（POLIS 严格包含 R69/R68）** 单用户或 `c̄=0`、无投机（`K=p`）、`κ=0`、`Γ` 等价 R69 全空间且 `ε=0`、无外部性时，`PVoI` 化为 R69 的 VoI，硬闸恒等，决策逐指令相同 ⇒ `POLIS ⊆ R69 ⊆ R68` 单调安全链，安全不让步。

**定理 19（不可操纵 ⇒ 福利序不变）** 偏好不变性下动作变化只经事实信念中介；由 Blackwell 信息序，给定真实 `u`，更多事实信息期望效用不降；任何 `Δ_pref>κ_max` 是可检测违规。系：操纵在本框架中是**可判定的约束违反**。

**定理 20（贪婪 VoI 可任意有害；均衡感知严格更优）** 便宜可游戏问题 `q1` vs 昂贵可验证问题 `q2`：R69 贪婪恒选 `q1`，人群学会后误差不降且自信；POLIS 含 `−Δn_eff/−Δlegitimacy` 与验证价值，选 `q2`，误差→0；投机成本→0 时误差差无界。系：逐次贪婪会**自信地错**。

**定理 21（含退避的无新害）** 设计动作仍逐个过 C-RAS-WM；三社会硬闸可在线检查；任一失败/不可识别 ⇒ 逐指令 R69。故约束成立时 `risk(POLIS)≤risk(R69)`，失败时相等，无新增物理风险（前提：闸门检查可靠；若社会模型错设致误通过，本定理不保——即最大风险）。

## 7. 本轮最大风险

**一句话**：POLIS-RAS 的全部收益押在「能正确建模并**因果识别**人群响应」上——一旦社会模型错设、留出失效或人群协同对抗，legibility/公平/可争辩就会沦为**合法化外衣**：系统以更少内疚、更大规模，把**自己制造的共识**当真相，把**对人群的操纵**当关怀——**设计错了，比问错更危险。**

**次级风险与缓解**：社会模型错设（混合效应 + 在线反向验证 + 留出覆盖门）；留出被规避/失效（随机化审计 + 不可被策略影响的外部抽样）；协同社会工程（n_eff 多样化 + 可验证锚点 + ℰ_pop 对抗训练）；legibility 下降（Γ 版本化 + 人类预测准确率硬门）；公平被平均掩盖（分层负担账本 + 最差组约束）；制度层被绕过（DGV 设计审查 + 可回滚 + 审计哈希入证书）。
