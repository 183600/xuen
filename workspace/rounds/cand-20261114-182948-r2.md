# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧」IP-253~263；本轮灵感：「长程任务」×「语义建图」）

> R69 把不确定性一分为二（aleatoric / epistemic），并给了系统一张嘴：可以看、可以问、可以触。但 R69 的全部推理都是**当下、局部、无记忆**的——VoI 是单步的，λ_floor 是单步的，模态分解只覆盖眼前这一个动作块。它能回答「此刻我该不该问」，却回答不了三个长程问题：**（a）十分钟前我记下的那个地方，还是那个地方吗？（b）为一个远期岔路，现在多问一句值不值？（c）一个早期的小错，会不会沿整条视界越滚越大？**
>
> 本轮两个灵感正好补上基质与账本：
> - **长程任务**把逐点安全升级为**全程风险预算**：误差不是加法的，是沿路径相关复利的；局部 λ_floor 保证每步不冒进，却不保证 H 步累计不越界。
> - **语义建图**给出唯一能承载长程记忆的持久基质——一个带标签、位姿、来源、版本、有效期的**地图信念**；但它同时引入 R69 从未面对的对象：一个会自信地说谎、且说过的话会被后来反复引用的世界记忆。
>
> 核心命题：**把 R69 的「逐点不确定性」提升为「定义在地图信念上的长程不确定性场」；用非近视 VoI 决定何时获取信息，用风险账本决定何时收紧，用「k 正交写纪律 + 溯源 + 隔离 + 回滚」约束地图这个最危险的新证据源；地图可疑时逐级退避到 FLUID/R68。** 命名 **ATLAS-RAS**（Auditable Topological Long-horizon Adaptive Semantics for Risk-adaptive Autonomy）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我记住的世界，还是那个世界吗；我为记住它，愿意在当下付多少**」——不确定性从刹车踏板、一句提问，进一步变成一个**可审计的记忆**。

## 0. 直觉与动机

**灵感 1（长程任务 → 误差会复利，单步刹车不是全程预算）**
直觉：R69 的 λ_floor 像每走一步就摸一次刹车——每步都安全，但没人统计「这一趟总共还剩多少刹车片」。长程任务里，位姿漂移、语义误标、模态误选都会沿路径相关累积；若每一步都恰好卡在局部安全阈值，几十步后累计风险可以远超任何单步上界。工程上这叫「误差预算」，理论上它是**不确定性沿轨迹的传输**：步间协方差非对角，H 步累计不是 √H 独立叠加，而可能线性甚至超线性。于是需要一个跨视界的账本 B_H：每一步的 λ 不仅看当前 U，还要看**剩余视界**与**已支出预算**；超支就回退到更保守档。

**灵感 2（语义建图 → 记忆是长程的接口，也是新的谎言源）**
直觉：没有地图，机器人每到一个地方都要从零重建「这是哪、这里有什么、上次的结论还算不算数」。语义地图把每步认知固化为可复用、可版本化的持久信念：同一把椅子不必反复问，同一条走廊不必反复探。但地图一旦持久，就有三种 R69 没有的失效：**别名**（两个不同地点长得一样，被错误合并）、**陈旧**（曾经为真，如今已变）、**投毒**（一次恶意或幻觉写入，被整条视界引用）。地图因此既是长程效率的来源，也是长程错误自我认证的源头。

**灵感 3（严格包含 → H=1 且空图 = R69）**
直觉：如果本轮只是「在 R69 上再接一个地图模块」，那就多了一个需要独立信任的黑箱，违背这条研究线一贯的姿态。正确做法是让 R70 在边界上塌缩成 R69：视界 H=1、地图为空、无历史证据时，非近视 VoI 退化为单步 VoI，λ_H 退化为 λ_floor，地图写不发生——两者逐指令相同。地图可疑时不是「相信地图但调低权重」，而是**显式退避**：L1 禁用长程信息获取、只用已确认节点，退到 FLUID；L2 禁用地图写、只用瞬时观测，退到 R68 纯保守。安全侧只允许单调不降。

**灵感 4（对偶通道 → 地图是第三条可观测通道，且必须被写纪律约束）**
直觉：R69 的 FMA 用「行为在策略密度下的似然」作为标定不可吸收的第二意见。地图给了第三条：**同一动作在「有地图条件」与「无地图条件」下的似然差 Δa_map**。传感器残差测「测量自洽」，行为似然测「行为自洽」，地图似然差测「记忆自洽」。三者联合可三角定位：`(r_res↓, Δa↑)` 是传感器缓变故障；`(r_res 正常, Δa_map↑)` 是地图在撒谎；三者齐升是世界真变了或正被攻击。更关键的是，R69 为交互建立的「k 个正交证据源一致」纪律，本质上不是交互纪律而是**信念写纪律**——地图写入正是「环境给出的长期回答」，与人类回答同构，因此可直接复用引理 18 的上界。

**灵感 5（持久化 → 攻击面从一次性升级为复利型）**
直觉：R69 的风险是「问错一次」。R70 的风险是「记错一次，然后信它一辈子」：一旦某个别名/投毒/陈旧节点被写进地图，后续的规划、交互、甚至新的地图写都会把它当证据引用，置信度在最错的地方反而单调上升。这不是单点错误，而是**自我认证的污染**。所以本轮必须交付：写入前的正交证据门、隔离区与有效期衰减、append-only 溯源哈希链、epoch 快照与回滚、以及污染半径的显式界定。否则 R70 不是把 R69 的记忆补上，而是给 R69 装了一块**永远擦不掉的错误黑板**。

## 1. 形式化定义（增量：定义 310–327）

**定义 310（ATLAS-RAS 总览）** ATLAS-RAS = (SMG, HUB, NMV, MRI, MAD, SLD, HVP, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i；在线只做门控写，全局重排/重标注仅离线，见定义 326）；
(ii) **地图写纪律**：任何地图写都非终局，必须 k 个正交证据源一致，否则只能写入隔离区并带有效期衰减（定义 317–318）；
(iii) **长程风险预算**：沿任务视界的累计不确定性支出 ≤ B_H，且每次支出可审计（定义 314）；
(iv) **溯源完整性**：每个地图节点/边携带 append-only 的来源链与版本号，可回滚、可界定污染半径（定义 327）。

**定义 311（语义地图图 SMG）** 地图是一个**信念**而非数据库：M_t = (V, E, L, X, P, Vld, Q)。
- 节点 v ∈ V：语义标签分布 p_ℓ(v) ∈ Δ(𝒞)、位姿分布 p_x(v) ∈ 𝒫(SE(3))、语义嵌入 e(v)、有效期 τ(v)、来源 provenance ρ(v)、版本 ν(v)、隔离标志 q(v) ∈ {0,1}；
- 边 E：可达 / 共视 / 隶属 / 时序；
- 地图后验记作 b_t(M)，我们对「地图本身」也保持一个分布（这是与只维护一张确定图的关键区别）。

**定义 312（轨迹条件下的地图更新）** 写算子 W: (M_t, e_t) → M_{t+1}，写类型为 {create, merge, relabel, move, delete}。每次写携带证据集 ℰ_w 与来源，产生写后置信 p_write 与污染半径 R_write（定义 327）。地图更新与 R69 的动作选择共享同一个 z_t，不引入第二套表征。

**定义 313（长程不确定性三重分解）** 在 R69 的 (U_ale, U_epi) 上再按时间/结构细分：
- U_ale：模态内不可约噪声（继承）；
- U_epi^loc：当前可见、可在本次交互消解的歧义（继承 R69 的 U_epi）；
- U_epi^hist：历史信念歧义——过去写入、当前无法再直接观测，只能重建或绕行；
- U_epi^struct：地图拓扑/语义结构错误（别名合并、层级错置）。
沿视界 H 的地图项

```
U_map(H) = ∫_0^H Σ_v π_t(v)·[ tr Σ_x(v) + H(p_ℓ(v)) + λ_topo·I_topo(v) ] dt
```

其中 π_t(v) 是规划路径对节点 v 的占用概率，I_topo(v) 是 v 处的拓扑不确定度。总不确定性 U_H = U_step + U_map(H) + U_task，其中 U_task 是任务目标本身的欠定程度。**注意：三项语义不同，不做简单加和进入同一通道**（继承 R69 定义 297 的原则）。

**定义 314（长程风险账本 HUB）** 给定视界预算 B_H，已支出 e(t)，剩余视界 H_rem。定义

```
λ_H(t) = λ_floor(U_ale + U_epi^未消解) ⊕_H budget_term(e(t), B_H, H_rem)
```

要求：(a) λ_H ≥ λ_floor（安全侧永不更弱）；(b) λ_H 关于 H_rem 单调不降（越接近终点越不允许新增大不确定）；(c) 当 H=1 且 M=∅ 且无历史证据时 λ_H = λ_floor（严格包含 R69）。budget_term 取「风险预算 / 剩余视界」的比值型调度：预算吃紧或剩余视界过短时强制抬升保守度；e(t) > B_H 直接回退到 R68 最保守档。

**定义 315（非近视 VoI，NMV）** 单步 VoI 只看当前后验熵；长程要看「这个信息对未来整条计划的价值」。定义

```
VoI_H(g) = E_{y~p(·|g,o)}[ Regret_H(π_{¬g}) − Regret_H(π_{g,y}) ] − c(g) − S(g)
```

其中 Regret_H 是视界内相对 oracle 的累计代价，S(g) 是**迟滞惩罚**。定义可行动窗口 W_act(g)：若信息 y 的期望到达时刻晚于它所服务的决策点，则该信息的 VoI_H 截断为 0（晚到的信息不仅无用，还可能诱发计划 thrash，故允许取负）。R69 的 VoI 恰为 VoI_H 在 H=1、S≡0、Regret_H≈后验熵时的退化。选择 g* = argmax_g VoI_H(g)，s.t. risk(g) ≤ ε_int 且预算未超。

**定义 316（地图别名度与可辨识性）** 对节点对 (u, v)：外观相似度 sim_A(u,v)，位姿/上下文差异 d_C(u,v)。别名风险

```
AM(u,v) = sim_A(u,v)·(1 − min(1, d_C(u,v)/d_ref))
```

false-merge 风险 FM = E[AM | 真实不同]，false-split 风险 FS = E[1−AM | 真实相同]。可辨识性 κ = AM 在两个条件下的分布可分度。与 R69 的 Δ_min 构成对偶：R69 怕「分不开的歧义」，R70 怕「看起来一样、实际不同的两个地方」——前者让系统不敢选动作，后者让系统错误地合并记忆。

**定义 317（地图写纪律 SLD）** 写类型 create/merge/relabel/move/delete 均需 **k 个正交证据源一致**（几何一致性、语义一致性、时序连续性、地图接地交互确认）；不足 k 源一致时只能写入隔离区（q=1）。写日志 append-only 并用哈希链串联；支持 epoch 快照与 rollback。

**定义 318（隔离与有效性衰减）** 隔离节点 q(v)=1 的有效期 τ(v) 按半衰期衰减：只能作为「假设」参与规划，并显式计入 U_map；被正交证据确认后 promote 为 q=0；超期未确认则 delete 或 demote。**任何节点都不因「被引用过」而提升置信**——引用不计为新证据。

**定义 319（地图-策略对偶异常 MAD）** 定义

```
a_score_map = −log p_θ(ξ_obs | o, M_t)
Δa_map     = | a_score_map − a_score_nomap |
```

联合三角定位：`(r_res↓, Δa↑, Δa_map≈0)` ⇒ 传感器缓变故障（R69 FMA 覆盖）；`(r_res 正常, Δa_map↑)` ⇒ **地图在撒谎**（别名/陈旧/投毒）；`(r_res↑, Δa↑, Δa_map↑)` ⇒ 世界真变了或正被攻击。这是 R69 引理 17 在记忆侧的镜像：标定层吸收不了行为通道，行为通道也吸收不了记忆通道。

**定义 320（地图接地交互 VIA）** R69 的信息动作 g 指向具体的地图节点/区域；回答写回节点并更新 provenance。已确认节点可作为未来交互的先验证据（摊销 VoI），但复用时必须计入证据相关性 ρ 与陈旧度 decay(τ)，不得重复计数——**同一份证据不能被用两次来「确认」自己**。

**定义 321（长程价值规划 HVP）** 分层规划：任务层（子目标/检查点序列）→ 地图层（路径、重识别、写决策）→ 动作层（R69 FLUID 执行）。承诺视界 H_commit < H：只对前 H_commit 做硬承诺，其余为软计划；越靠近承诺边界，越倾向先获取信息再承诺。

**定义 322（重规划触发）** 触发集合 = {预算越界, U_map 超阈, AM 超阈, Δa_map 超阈, 检查点失败, 新证据与已提交写冲突}。触发时安全退避（λ 单调不降），但**不回滚已认证并正在执行的片段**（避免执行期突变）。

**定义 323（地图证书 J_ATLAS）** J_ATLAS = (J_FLUID, map_ECE, aliasing_rate, false_merge_rate, staleness_p95, provenance_hash, budget_utilization, H, H_commit, atlas_ver)。Valid ⇔ Valid(J_FLUID) ∧ map_ECE ≤ τ_map ∧ false_merge_rate ≤ τ_fm ∧ 溯源链完整 ∧ 预算未越界。

**定义 324（对抗地图干扰集 ℰ_ATLAS）** ℰ_ATLAS = ℰ_FLUID × ℰ_map，其中 ℰ_map = {地图投毒, 重放攻击, 对抗性路标/标识, 环境文本语义注入, 别名攻击（复制场景）, 渐进式地图漂移}。并入 AIC：ℰ_ATLAS 同时覆盖「一次性错误」与「复利型污染」。

**定义 325（地图信任级联退避）** 三级：L0 正常（NMV + HVP 全开）；L1 地图可疑（禁长程信息获取，仅用 q=0 已确认节点，规划退到 FLUID，交互退到 R69）；L2 地图不可信（禁一切地图写，仅用瞬时观测，退到 R68 纯保守）。每一级 λ 单调不降，切换有迟滞带（防止在阈值附近抖动）。

**定义 326（离线固化 vs 在线门控写）** 运行期只允许定义 317 的门控写；全局重定位、拓扑重排、语义重标注仅在离线/停机窗口进行并需证书。在线做全局重排会破坏「零学习写」不变式，也让污染无法界定。

**定义 327（视界内一致性与回滚）** 每次写产生 epoch ν 与污染半径

```
R_write = { 所有直接或间接把该写当作证据而派生的节点/决策 }
```

若后续证据证伪该写，回滚到写前快照，并将 R_write 内节点降级复检；回滚只影响未执行计划，不影响已认证执行片段（与定义 322 一致）。

## 2. 关键算法骨架

```python
# IP-264 SMG：语义地图图（节点=标签分布+位姿分布+来源+版本+有效期+隔离位）
class SemanticMapGraph:
    def query(self, region):                       # 返回规划路径相关节点及其信念
        return [v for v in self.nodes if self.reach_prob(v, region) > EPS]
    def write(self, op, payload, evidence, epoch):  # 只走 SLD 门控
        return self.sld.gate_and_commit(op, payload, evidence, epoch)

# IP-265 HUB：长程风险账本（H=1 且空图时严格等于 R69 的 λ_floor）
def horizon_floor(U_ale, U_epi, spent, B_H, H_rem, M):
    lam_local = lam_floor(U_ale + U_epi)            # R69
    if H_rem <= 1 and M.is_empty(): return lam_local
    ratio = spent / max(B_H - spent, EPS)           # 预算吃紧度
    return max(lam_local, combine(lam_local, ratio, H_rem))

# IP-266 NMV：非近视 value-of-information（含迟滞惩罚与可行动窗口）
def choose_interaction_H(modes, w, o, map_belief, plan, budget, H_rem):
    best = None
    for g in info_action_candidates(modes, map_belief):
        if not budget.allow(g, H_rem):                 continue
        if not c_ras_wm.certify_info(g, o):            continue
        if g.decision_time < g.expected_arrival:       continue   # 晚到 → VoI=0
        voi = regret_reduction_H(plan, g, H_rem) - social_physical_cost(g) - staleness(g)
        if best is None or voi > best.voi: best = (g, voi)
    return best if best and best.voi > 0 else None

# IP-267 MRI：别名守卫（假合并/假分裂的双向风险）
def aliasing_guard(u, v, map_belief):
    am = sim_A(u, v) * (1 - min(1, d_C(u, v) / d_ref))
    return am, false_merge_risk(am), false_split_risk(am)

# IP-268 MAD：地图-策略对偶异常（第 3 条不可互吸收的通道）
def map_anomaly(policy, xi_obs, o, M):
    a_map  = -policy.log_likelihood(xi_obs, o, cond=M)
    a_none = -policy.log_likelihood(xi_obs, o, cond=None)
    return abs(a_map - a_none)                      # Δa_map

# IP-269 SLD：写纪律（k 正交一致，否则隔离；append-only + 哈希链）
class SemanticWriteDiscipline:
    def gate_and_commit(self, op, payload, evidence, epoch):
        agree = orthogonal_agree_count(evidence)    # 几何/语义/时序/交互确认
        if agree >= K_ORTHO:
            node = self.commit(op, payload, evidence, epoch, q=0)
        else:
            node = self.quarantine(op, payload, evidence, epoch, half_life=TAU_Q)
        self.log.append_hash(node, prev=self.log.tail)  # 不可篡改溯源
        return node

# IP-270 HVP：长程分层规划 + 重规划触发
def plan_H(task, map_belief, H, H_commit):
    plan = hierarchical_plan(task, map_belief)      # 任务层 → 地图层 → 动作层
    return plan, replan_triggers(plan, map_belief, H, H_commit)

# IP-274 主闭环：R69 FLUID + 地图信念 + 长程账本 + 写纪律
def ATLAS_RAS_round(M, obs, task, H_rem):
    z, o = M.mtm.forward(obs)
    c, U_cal, thr = M.cof.step(...)                 # R68 标定
    Mb = M.smg.belief()                             # 地图信念（可为空）
    # 1) 地图项并入不确定性，但单独成通道
    U_ale, U_epi_loc, modes = M.aud.decompose(M.fmp.sample(o, M.adaptive_K(z)), z)
    U_epi_hist, U_epi_struct = M.smg.epistemic_terms(Mb)
    # 2) 三角异常定位：传感器 / 行为 / 记忆
    da       = M.fma.flow_anomaly(M.fmp, M.last_action, o_obs, o_cal)
    da_map   = M.mad.map_anomaly(M.fmp, M.last_action, o, Mb)
    trust    = trust_level(M.last_r_res, da, da_map)       # L0/L1/L2（定义 325）
    # 3) 非近视交互：仅在 L0 且预算允许时开长程 VoI
    g = (M.nmv.choose_interaction_H(modes, o, Mb, M.plan, M.budget, H_rem)
         if trust == L0 else None)
    if g is not None:
        ans = M.via.execute(g)                     # 看/问/触，带 R69 认证与证据纪律
        node = M.smg.write('relabel' if ans else 'create', ans, ans.evidence, M.epoch)
    # 4) 长程风险账本：λ 随剩余视界与预算单调
    U_floor = U_ale + (U_epi_loc if g is None else 0.0) + U_epi_hist + U_epi_struct
    lam = M.hub.horizon_floor(U_ale, U_floor, M.spent, M.B_H, H_rem, Mb)
    if trust == L1: lam = max(lam, lam_L1)          # 退 FLUID
    if trust == L2: lam = max(lam, lam_L2)          # 退 R68
    # 5) 分层规划与执行（承诺视界内）
    plan, triggers = M.hvp.plan_H(task, Mb, H_rem, M.H_commit)
    A = M.ach.propose(plan.first(H_commit), H=M.H_commit)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    mode = select_mode(modes, U_epi_loc, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    # 6) 重规划/回滚/审计/证书
    if triggers: M.hvp.replan_or_rollback(Mb, triggers)    # 只动未执行计划
    M.vqa_i.submit_async(g, U_ale, U_epi_loc, U_epi_hist, da, da_map, trust)
    return k, lam, mode, (U_ale, U_epi_loc, U_epi_hist, U_epi_struct)
```

## 3. 推导

**引理 19（长程误差复利）** 设第 i 步残余风险 r_i ≤ λ_i·u_i，u_i 为步内不确定性测度。若 λ_i 只依赖当前 u_i（R69 的逐点策略）且不确定性沿路径正相关（相邻步协方差非零），则存在任务使 Σ_{i=1}^H r_i ≥ H·r̄（线性复利），而独立假设下的 √H 界不再成立。引入定义 314 的 λ_H（依赖 B_H 与 H_rem）后，累计风险满足 Σ_i λ_{H,i}·u_i ≤ B_H + Σ_i λ_floor(u_i)·u_i。要点：**局部安全的乘积不等于全局安全**；账本项正是把「剩余视界」编码进每一步的保守度。

**引理 20（非近视 VoI 的支配性与近视的任意次优）** (a) 当 Regret_H 可分解且选项价值非负时，VoI_H(g) ≥ VoI_1(g) − S(g)；(b) 存在任务族使单步 VoI ≤ 0 而 VoI_H > 0：查询的物理成本固定，但其价值只在 τ 步后的岔路兑现，单步收益为零。故 R69 的近视 VoI 会系统性地跳过「为远方做准备」的信息动作，其遗憾可随 H 无界增长；R70 在 H>1 时严格更优，H=1 且 S≡0 时两者相同。系：**信息的价值是它服务的那次决策的函数，而不是它被获取的那一刻的函数**。

**引理 21（别名与地图投毒的 k-正交上界）** 设单源别名率 δ_a、单源投毒率 δ_p（二者同构：都是「错的东西看起来对」），k 个正交证据源的欺骗相关 ρ<1，则 false-merge / 错误采纳率 ≤ max(δ_a, δ_p)·ρ^{k−1} + ε_σ。这是 R69 引理 18 的直接复用，但意义升级：**证据纪律不是交互的局部纪律，而是所有信念写（包括对世界记忆的写）的通用纪律**。

**定理 18（ATLAS 严格包含 FLUID/R69）** 在 A95–A99 下：(i) 当 H=1、M=∅、无历史证据时，NMV 退化为 R69 VoI、λ_H 退化为 λ_floor、无写发生，故与 R69 逐指令相同；(ii) 一般情形下，ATLAS 的期望风险 ≤ R68，且长程因预算化 resolution bonus 获得效率收益；(iii) 地图可疑时按定义 325 级联退避，λ 单调不降。因此 R69 是 ATLAS 在「无记忆、单步」边界上的退化，安全侧不做任何让步。

**定理 19（持久化污染的有限传播）** 在 SLD（定义 317）+ 隔离（318）+ 溯源（327）下，任意单次被投毒/别名写，在被 MAD/AM 检出之前，其影响的决策数 ≤ 一个 epoch 内的引用次数，且污染半径 R_write 有界；若检出延迟为 d，则期望污染代价 ≤ c_d·d + c_r·|R_write|。要点：**持久化本身不等于无界传播**——只要写有版本、引用有溯源、回滚有半径，一次错误可以被「圈起来」而不是「扩散开」。

**定理 20（长程安全与无突变）** HUB 使沿视界的累计风险 ≤ B_H + Σ 局部 λ_floor 项；重规划触发时 λ 单调不降，且只作用于未执行计划；已认证执行片段与换装/提交不变式（R68 定理 15）保持。故控制连续、无执行期突变；超过预算或地图不可信时退化为 R68 纯保守。

## 6. 本轮最大风险

**一句话**：ATLAS-RAS 的全部长程效率押在「地图信念是可信的」这一前提上——但地图是**持久且自我引用**的：一次别名合并 / 投毒 / 陈旧写入，会被后续规划、交互甚至新的写当作证据反复引用，系统在最错的地方置信度反而单调上升，形成**自我认证的谎言**；`Δa_map` 与 `SLD` 只能缩短发现延迟、界定污染半径，无法保证「记忆一旦错了就一定能被及时抓住」——**记错，比不记更危险**。

**次级风险与缓解**：
1. **别名假合并**（同貌异地）→ MRI 双向风险度量 + k 正交写纪律 + 隔离半衰期 + E304；
2. **地图投毒/重放/语义注入** → ℰ_map 对抗训练 + append-only 溯源 + 回滚半径 + E305/E313；
3. **陈旧地图误导规划** → 有效期衰减 + MAD 第三通道 + 级联退避（L1/L2）+ E306/E311；
4. **长程误差复利未被账本覆盖** → HUB 随剩余视界单调 + 预算越界回退 R68 + E301/E312；
5. **实时预算被地图层击穿** → LSH/增量规划 + 可疑时反而更快（退避路径更短）+ E314。

**当前方案的最大风险**：它把 R69「诚实的不知道」升级成了一张会自我强化的记忆网——**一旦地图在某个节点撒了谎，长程执行会把这个谎当作地基，越走越自信地走错**。

**定义 321–322（HVP 与重规划）** 任务层→地图层→动作层分层规划；`H_commit<H` 只硬承诺近端；触发 = {预算越界, U_map/AM/Δa_map 超阈, 检查点失败, 新证据与已提交写冲突}；触发时 λ 单调不降，但不动已认证执行片段。

**定义 323–324（证书与干扰）** `J_ATLAS=(J_FLUID,map_ECE,aliasing_rate,false_merge_rate,staleness_p95,provenance_hash,budget_utilization,H,H_commit,atlas_ver)`；`ℰ_ATLAS=ℰ_FLUID×ℰ_map`，`ℰ_map`={投毒,重放,对抗路标,语义注入,别名攻击,渐进漂移}。

**定义 325–327（退避与回滚）** L0 全开 / L1 禁长程信息获取、仅用 q=0 节点、退 FLUID / L2 禁地图写、仅瞬时观测、退 R68；每级 λ 单调不降并有迟滞带。在线只门控写，全局重排仅离线（零学习写）。写产生 epoch 与污染半径 `R_write`，证伪则回滚至写前快照并复检 `R_write`。

class SemanticMapGraph:
    def query(self, region):
        return [v for v in self.nodes if self.reach_prob(v, region) > EPS]
    def belief(self):
        return Belief(self.nodes, self.edges)          # 含每节点标/姿/有效期/隔离位
    def write(self, op, payload, evidence, epoch):
        return self.sld.gate_and_commit(op, payload, evidence, epoch)

# IP-265 HUB：长程风险账本（H=1 且空图 → R69）
def horizon_floor(U_ale, U_epi, spent, B_H, H_rem, M):
    lam_local = lam_floor(U_ale + U_epi)
    if H_rem <= 1 and M.is_empty(): return lam_local
    ratio = spent / max(B_H - spent, EPS)
    return max(lam_local, combine(lam_local, ratio, H_rem))

# IP-266 NMV：非近视 VoI（迟滞惩罚 + 可行动窗口）
def choose_interaction_H(modes, w, o, Mb, plan, budget, H_rem):
    best = None
    for g in info_action_candidates(modes, Mb):
        if not budget.allow(g, H_rem) or not c_ras_wm.certify_info(g, o): continue
        if g.decision_time < g.expected_arrival:       continue     # 晚到 → VoI=0
        voi = regret_reduction_H(plan, g, H_rem) - social_physical_cost(g) - staleness(g)
        if best is None or voi > best.voi: best = (g, voi)
    return best if best and best.voi > 0 else None       # 无利可图 → 退化 R69

# IP-267 MRI：别名守卫（假合并/假分裂双向）
def aliasing_guard(u, v):
    am = sim_A(u, v) * (1 - min(1, d_C(u, v) / d_ref))
    return am, false_merge_risk(am), false_split_risk(am)

# IP-268 MAD：地图-策略对偶异常（第 3 条通道）
def map_anomaly(policy, xi_obs, o, M):
    a_map  = -policy.log_likelihood(xi_obs, o, cond=M)
    a_none = -policy.log_likelihood(xi_obs, o, cond=None)
    return abs(a_map - a_none)                          # Δa_map

# IP-269 SLD：写纪律（k 正交一致，否则隔离；append-only 哈希链）
class SemanticWriteDiscipline:
    def gate_and_commit(self, op, payload, evidence, epoch):
        if orthogonal_agree_count(evidence) >= K_ORTHO:
            node = self.commit(op, payload, evidence, epoch, q=0)
        else:
            node = self.quarantine(op, payload, evidence, epoch, half_life=TAU_Q)
        self.log.append_hash(node, prev=self.log.tail)
        return node

# IP-270 HVP：长程分层规划 + 重规划触发
def plan_H(task, Mb, H, H_commit):
    plan = hierarchical_plan(task, Mb)                  # 任务层→地图层→动作层
    return plan, replan_triggers(plan, Mb, H, H_commit)

# IP-274 主闭环（继承 R69，仅替换不确定性的“定义域”与“时间尺度”）
def ATLAS_RAS_round(M, obs, task, H_rem):
    z, o = M.mtm.forward(obs); c, U_cal, thr = M.cof.step(...)
    Mb = M.smg.belief()
    # 1) 长程三重分解（地图项单独成通道）
    U_ale, U_epi_loc, modes = M.aud.decompose(M.fmp.sample(o, M.adaptive_K(z)), z)
    U_epi_hist, U_epi_struct = M.smg.epistemic_terms(Mb)
    # 2) 三角异常定位：传感器 / 行为 / 记忆
    da     = M.fma.flow_anomaly(M.fmp, M.last_action, o_obs, o_cal)
    da_map = M.mad.map_anomaly(M.fmp, M.last_action, o, Mb)
    trust  = trust_level(M.last_r_res, da, da_map)       # L0/L1/L2
    # 3) 非近视交互（仅 L0 开长程 VoI）
    g = (M.nmv.choose_interaction_H(modes, o, Mb, M.plan, M.budget, H_rem)
         if trust == L0 else None)
    if g is not None:
        ans = M.via.execute(g)
        M.smg.write('relabel', ans, ans.evidence, M.epoch)
    # 4) 长程账本 + 级联退避
    U_floor = U_ale + (U_epi_loc if g is None else 0.0) + U_epi_hist + U_epi_struct
    lam = M.hub.horizon_floor(U_ale, U_floor, M.spent, M.B_H, H_rem, Mb)
    if trust == L1: lam = max(lam, lam_L1)               # → FLUID
    if trust == L2: lam = max(lam, lam_L2)               # → R68
    # 5) 分层规划与承诺视界执行
    plan, triggers = M.hvp.plan_H(task, Mb, H_rem, M.H_commit)
    A = M.ach.propose(plan.first(M.H_commit), H=M.H_commit)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    mode = select_mode(modes, U_epi_loc, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    # 6) 重规划/回滚/审计/证书
    if triggers: M.hvp.replan_or_rollback(Mb, triggers)  # 只动未执行计划
    M.vqa_i.submit_async(g, U_ale, U_epi_loc, U_epi_hist, da, da_map, trust)
    return k, lam, mode, (U_ale, U_epi_loc, U_epi_hist, U_epi_struct)

## 4. 推导

**引理 19（长程误差复利）** 若第 i 步残余风险 `r_i ≤ λ_i·u_i`，R69 取 `λ_i` 仅依赖当前 `u_i`，且不确定性沿路径正相关，则存在任务使 `Σ_{i=1}^H r_i ≥ H·r̄`（线性复利），独立假设的 `√H` 界失效。引入 HUB 的 `λ_H(·,B_H,H_rem)` 后 `Σ_i λ_{H,i}u_i ≤ B_H + Σ_i λ_floor(u_i)u_i`。要点：局部安全的乘积不等于全局安全；账本把「剩余视界」编码进每一步的保守度。

**引理 20（非近视 VoI 的支配性与近视的任意次优）** (a) Regret_H 可分解且选项价值非负时 `VoI_H(g) ≥ VoI_1(g) − S(g)`；(b) 存在任务族使单步 `VoI ≤ 0` 而 `VoI_H > 0`——查询成本固定、价值只在 τ 步后的岔路兑现。故 R69 的近视 VoI 会系统性跳过「为远方做准备」的信息动作，其遗憾随 H 无界增长；R70 在 H>1 严格更优，H=1 且 S≡0 时相同。系：信息的价值是它服务的那次决策的函数，而非被获取那一刻的函数。

**引理 21（别名与地图投毒的 k-正交上界）** 单源别名率 δ_a、单源投毒率 δ_p（同构：错的东西看起来对），k 源欺骗相关 ρ<1，则 false-merge / 错误采纳率 ≤ `max(δ_a,δ_p)·ρ^{k−1}+ε_σ`。这是 R69 引理 18 的复用与升级：证据纪律是**所有信念写**（含世界记忆）的通用纪律，而非交互的局部纪律。

**定理 18（ATLAS 严格包含 FLUID/R69）** A95–A99 下：(i) H=1 ∧ M=∅ ∧ 无历史时，NMV→R69 VoI、λ_H→λ_floor、无写发生，与 R69 逐指令相同；(ii) 一般情形期望风险 ≤ R68，长程获预算化 resolution bonus；(iii) 地图可疑时按定义 325 级联退避，λ 单调不降。故 R69 是 ATLAS 在「无记忆、单步」边界上的退化，安全侧不让步。

**定理 19（持久化污染的有限传播）** 在 SLD + 隔离 + 溯源下，任意单次被投毒/别名写，在 MAD/AM 检出前影响的决策数 ≤ 一个 epoch 的引用次数，且污染半径 `R_write` 有界；检出延迟 d 时期望污染代价 ≤ `c_d·d + c_r·|R_write|`。要点：持久化不等于无界传播——写有版本、引用有溯源、回滚有半径，错误可被「圈起来」。

**定理 20（长程安全与无突变）** HUB 使累计风险 ≤ `B_H + Σ 局部 λ_floor`；重规划触发时 λ 单调不降且只作用于未执行计划；已认证执行片段与换装/提交不变式（R68 定理 15）保持，故控制连续无突变；超预算或地图不可信时退化为 R68 纯保守。

## 7. 本轮最大风险

**一句话**：ATLAS-RAS 的全部长程效率押在「地图信念可信」这一前提上——但地图是**持久且自我引用**的：一次别名合并 / 投毒 / 陈旧写入会被后续规划、交互与新写反复当作证据引用，系统在最错的地方置信度反而单调上升，形成**自我认证的谎言**；`Δa_map` 与 `SLD` 只能缩短发现延迟、界定污染半径，无法保证「记忆一旦错了就一定能被及时抓住」——**记错，比不记更危险**。

**次级风险与缓解**：别名假合并（MRI 双向度量 + k 正交写纪律 + 隔离半衰期 + E304）；地图投毒/重放/语义注入（ℰ_map 对抗训练 + append-only 溯源 + 回滚半径 + E305/E313）；陈旧地图误导规划（有效期衰减 + MAD 第三通道 + 级联退避 + E306/E311）；长程误差复利未覆盖（HUB 随剩余视界单调 + 越界退 R68 + E301/E312）；实时预算被地图层击穿（LSH/增量规划 + 退避路径更短 + E314）。
