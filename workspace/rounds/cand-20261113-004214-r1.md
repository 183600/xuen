# 第 63 轮（承接第 62 轮「ROSE 鲁棒在线场景进化闭环」IP-183~192；灵感循环 II 第 2 轮；本轮灵感：「步态规划」×「技能组合」）

> 第 62 轮构建了 ROSE：OLP 在线投影、WCV 鲁棒编译、RSC 残差自校准、SBR 场景银行、MEL-OA、Shield、OCB、J_rose 证书。它修复了 ESEC 的「离线、无鲁棒、经验即弃」三个动力学缺口，并自述最大风险是 **RSC 的球覆盖依赖 J_φ 良态与外力矩残差可观测（A72 单点假设）**。
>
> 但把 ROSE 放进真实的长程具身任务，会暴露五个更基础的结构性空白：
> 1. **无时序（无步态）**：实时流每个周期独立解一个阻抗 K，从不回答「何时换支撑脚、下一步落在哪、接触力如何沿时域分配」。ROSE 能「站稳并柔顺」，却不能「走起来」。
> 2. **无结构（无技能）**：场景银行存的是「场景」不是「技能」；没有技能库、没有前置/后置条件、没有组合语义。多阶段任务（走过去→跨过→抓取→搬回）只能靠外部手写状态机。
> 3. **无相位（阻抗错配）**：OLP 学一个全局映射 K(x)，但摆动相需要低刚度跟踪、支撑相需要高刚度/力控；且支撑样本远多于摆动样本，在线学习会被支撑相支配。
> 4. **无组合安全（切换即裸奔）**：WCV 的 CVaR 只覆盖单个接触模式内的一个周期；跨技能、跨接触模式的**切换脉冲**（触地冲击、重心交接、抓取瞬间外力）没有任何证书。安全性在「组合缝」处失效。
> 5. **遗憾停在参数层**：ROSE 的遗憾界是投影头 W 的 O(√T)；「选哪种步态、走哪条技能链」这一离散决策层没有遗憾保证，也没有把 SBR 的场景遗憾接到技能选择上。

## 0. 直觉与动机

**灵感 1（步态规划 → 步态是接触相技能的循环组合）**
直觉：很多人把步态当成一个整体控制器去调参；但步态的本质是**离散接触事件的时序结构**：哪条腿在支撑、哪条在摆动、何时双支撑、落脚点在哪。接触相本身就是一个「技能」——摆动相技能负责抬脚与落点跟踪，支撑相技能负责承重与平衡，转移相技能负责重心交接。于是「步态规划」= **选择一个循环技能组合 + 一条接触调度 + 一串落脚点**。这不是把步态塞进技能框架，而是发现二者本来就是同一件事在两个尺度上的投影：步态是技能的循环组合，技能组合是步态的泛化。关键洞见：把步态的参数（周期 T_c、占空比 β、抬腿高度、步长）和接触调度 σ(θ) 显式暴露为**可规划变量**，而不是埋在控制器里。

**灵感 2（技能组合 → 带契约的代数，而非黑箱 option）**
直觉：技能不应只是「一个能跑的策略」，而应是一份**可组合的契约**：它在什么状态下能启动（Pre）、执行中什么永远成立（Inv）、结束时交付什么（Post）、何时算结束（Term）、多久内必须结束（进度变元）。组合算子（顺序 ;、并行 ∥、事件监督 ▷、选择 ⊕、循环 ^ω）只在契约能衔接时合法；于是「组合是否正确」变成一个**可本地检查、可结构化归纳证明**的问题，而不是跑一遍看看。组合的安全性用 rely-guarantee 表达：并行的两个技能各自声明「我依赖别人不破坏什么（rely）」与「我保证不破坏什么（guarantee）」，只要 G_1⊆R_2 且 G_2⊆R_1，并行就非干扰。这样，「走到桌前→伸手→抓→搬回」的每一段都能带证组合，缝里的安全性不再靠祈祷。

**灵感 3（鲁棒步态规划 → 把 ROSE 的 CVaR 球推进到轨迹层）**
直觉：ROSE 的 WCV 是「单周期、单接触模式」的鲁棒编译；步态天然是「多接触模式、有时域」的。关键洞见：**固定一条接触调度后，最坏摩擦就是 μ_min = μ̂ − r_μ**，鲁棒摩擦锥只是被收缩的锥；质量/惯量用区间，ZMP 对接触力线性。因此每一条候选调度的鲁棒可行性是一个**凸 SOCP/QP**（不是混合整数爆炸）。接触调度的离散选择退化为在有限步态库里选 + 微调相位，再交给遗憾调度器。这把「鲁棒」从单周期点估计升级为**时域可行域**。

**灵感 4（相位-阻抗耦合 → 步态给 OLP 打拍子）**
直觉：同一个 K 在摆动相和支撑相含义完全不同。应该让阻抗**随相位调制**：K(θ) = K_phase(θ) + h(x)ᵀW，其中 K_phase 由当前各腿接触模式查表/插值（摆动：低刚度 + 轨迹 PD；支撑：高刚度 + 力控），W 仍是 OLP 的在线修正。同时 OLP 的损失按接触模式重加权（逆频率加权），避免支撑相样本淹没摆动相。WCV 则使用**接触模式条件的球半径** r_t^{(m)}——这正是对第 62 轮「球只在当前模式被校准」这一缝隙的直接修补。

**灵感 5（技能-场景桥 → 把 SBR 的场景簇变成技能/步态先验）**
直觉：第 62 轮的场景银行已经用集群遗憾回答了「学习力往哪投」；现在它还能回答第二个问题：「在这个场景簇里，先试哪个技能、哪种步态」。湿滑簇 → 增大占空比、缩短步长、抬高 r；崎岖簇 → 选高抬腿/慢速步态；窄通道 → 选侧步技能。场景簇到技能/步态的先验是一个可在线更新的映射，其更新信号仍是集群遗憾。这样「场景驱动创新」从「挖场景」升级为「场景→技能/步态选择」的闭环。

**灵感 6（安全失败与组合遗憾 → 恢复组合子 + 分级遗憾）**
直觉：组合不能假设永不失败。当不变式监视器发现 Inv 即将被破坏，最安全的动作不是硬撑，而是**组合一个恢复技能**（踉跄步、抓握支撑、屈膝卸力），恢复技能本身也有契约；若恢复不可行，进入「受保护跌倒」以最小化伤害。另一方面，离散选择层需要自己的遗憾：步态族用 Hedge、技能链用 EXP3，损失=执行损失+跌倒惩罚+鲁棒裕度亏空。组合遗憾可以分解为「各子技能遗憾之和 + 每次切换的上下文偏移代价 + 步态库近似误差」——有界，但不免费，这是本轮必须诚实声明的理论缝隙。

**灵感 7（总框架 TANGO → ROSE 之上的时序-结构层）**
直觉：ROSE 是「学习-鲁棒」的动态闭环，但它是平的；TANGO 在其上加两层：**技能层**（0.5–5Hz，技能图规划 + 组合校验 + 场景先验）与**步态层**（20–100Hz，鲁棒接触规划 + 相位-阻抗耦合），底层仍是 ROSE 的实时流（1–10kHz，零学习写、WCV 编译、不变式监视）。三层用同一套证书串起来：J_rose 的单周期安全 + 组合不变式 + 鲁棒步态裕度 ρ_gait + 恢复就绪位。TANGO 不推翻 ROSE，而是给 ROSE 装上「骨骼（时序）」与「语法（组合）」。

TANGO = **T**emporal composition **A**lgebra with **N**ested **G**ait and skill **O**rchestration（时序组合代数 + 嵌套步态-技能编排）。

## 1. 形式化定义（增量：定义 185–196）

- **定义 185（TANGO 总闭环）**：TANGO = (ROSE, SGL, SCA, GPG, RGP, PIC, SGR, SCS, SCB, RRC, J_tango)。定位：ROSE 之上的时序-结构层，三层频带（技能层 / 步态层 / 实时层），全部新增组件挂载，不改变 ROSE 既有接口与实时流契约。
- **定义 186（技能模式与契约）**：技能 s = (Pre_s, Inv_s, Post_s, Term_s, π_s, ℓ_s, κ_s, ver_s)，其中 κ_s 为进度变元（ranking function，沿执行严格下降或循环计数有界）。契约成立 ⇔ 从任意 x_0∈Pre_s∩Inv_s 出发，π_s 使轨迹恒在 Inv_s 内、在 κ_s 界内进入 Term_s、且终态 ∈ Post_s。
- **定义 187（技能组合代数 SCA）**：算子
  - 顺序 `s1 ; s2`，要求 `Post_{s1} ⊆ Pre_{s2}`，Inv = Inv_1∩Inv_2；
  - 并行 `s1 ∥ s2`，要求非干扰 `(G_1⊆R_2) ∧ (G_2⊆R_1)` 且写集不相交，Inv = Inv_1∩Inv_2；
  - 事件监督 `s1 ▷_E s2`，E 触发时切换，要求边界保 Inv；
  - 选择 `s1 ⊕ s2`（守卫互斥）、循环 `s^ω`（相位不变式）、恒等 `skip`。
  合法（well-formed）⇔ 所有算子前置条件成立 + 进度变元可组合。
- **定义 188（步态原语与接触调度）**：g = (σ, T_c, β, {ρ_e}, F_0, 𝒫)，σ: [0,T_c)→2^E 为分段常值接触调度（E 为末端集合），β 为占空比，ρ_e 为各腿相位偏移，F_0 为标称落脚点，𝒫 为接触相技能集合。步态库 𝒢_L = {walk, trot, pace, bound, …} 及参数化族；步态 = 接触相技能的循环组合 `(swing_L ; stance_L ; swing_R ; stance_R)^ω`。
- **定义 189（鲁棒步态规划 RGP）**：在时域 H 与步态族 g 上求解
  `min J_gait = ∫(ℓ_track + w_e·E + w_s·slip_risk) dt`
  s.t. 对 **所有** φ∈B(φ̂_t, r_t) 满足质心动力学、摩擦锥 `|f_τ|≤μ(φ)f_n`、ZMP∈support(σ(θ))、运动学可达、力矩上限与避障；终态落入恢复集。对固定 σ，最坏摩擦为 μ_min=μ̂−r_μ，故为凸 SOCP/QP。鲁棒可行域 ℱ_g(φ̂,r)；裕度 `ρ_gait = min_{约束,φ∈B} margin`。接触模式条件半径 r_t^{(m)} 由 RSC 按模式分别维护。
- **定义 190（相位-阻抗耦合 PIC）**：`K_t = K_phase(θ_t) + h(x_t)ᵀW_t`，其中 `K_phase(θ)=Σ_m 1[mode_t=m]·K_m(θ)`（摆动低刚度轨迹跟踪，支撑高刚度/力控，转移平滑插值）；OLP 损失按模式逆频率加权；WCV 使用 r_t^{(m)}。
- **定义 191（组合不变式证书）**：组合技能 S 的证书 `C_S = (Inv_S, κ_S, {C_i}, 转移证明, 非干扰证明, 进度证明)`。S 合法且原子契约成立 ⇒ 执行 S 恒在 Inv_S 内并按 κ_S 终止。
- **定义 192（技能-步态遗憾 SGR）**：步态族选择用 Hedge，`ℓ_g(t)=norm(执行损失+λ_fall·1[fall]+λ_ρ·max(0,ρ_min−ρ_gait))`，伪遗憾 ≤ √(2T log|𝒢_L|)；技能链选择用 EXP3 over 技能图中 P 条候选路径，伪遗憾 ≤ √(2T log P)。组合遗憾 `R_S ≤ Σ_i R_{s_i} + C_comp·N_trans + |S|·ε_g`。
- **定义 193（技能-场景桥 SCB）**：对 SBR 的簇 c，维护先验 `(p_g(c), p_s(c), r(c))`，以该簇集群遗憾 R̂_c 在线更新；湿滑簇→高占空比/短步长/大 r，崎岖簇→高抬腿/慢速，窄通道→侧步技能。
- **定义 194（恢复组合子 RRC）**：恢复技能库 𝓡={stumble_step, capture_step, knee_brace, sit_down, protected_fall}；触发 `Inv 破坏风险 > τ_inv` 或 `ρ_gait < 0`；组合规则 `S ▷_violation R`；`recovery_ready = ∃R∈𝓡 使 Inv 在 T_rec 内可恢复`。
- **定义 195（TANGO 证书 J_tango）**：`J_tango = (J_rose, plan_id, σ_hash, gait_family, ρ_gait, inv_trace_hash, comp_cert_hash, sgr_arm, recovery_ready, ver)`；Valid ⇔ Valid(J_rose) ∧ ρ_gait≥0 ∧ 无 Inv 违规 ∧ C_S 有效 ∧ recovery_ready。
- **定义 196（TANGO 三层算子）**：技能层（0.5–5Hz：技能图搜索 + 组合校验 + SGR/SCB）∘ 步态层（20–100Hz：RGP + 相位推进 + PIC，只读锚点）∘ 实时层（1–10kHz：WCV 编译 + 派发 + 不变式监视，**零学习写操作**）。

## 3. 保证概要与推导要点（完整推导见产物区）

- **定理 1（组合不变式保持）**：若每个原子技能满足其契约，且组合 S 良构（顺序 Post⊆Pre、并行 G_i⊆R_j、切换保 Inv、进度变元可组合），则执行 S 恒满足 Inv_S 并在界内终止。证明：对组合树结构归纳 + 并行 rely-guarantee + 循环相位归纳。
- **定理 2（鲁棒步态安全）**：若 P[φ*∈B(φ̂,r)]≥1−α_cal，RGP 返回 ρ_gait≥0 的鲁棒可行计划，且实时层 WCV 按模式约束编译，则在冲击锥（A79）成立时，执行轨迹在 H 内保持于鲁棒生存核 𝒱 内，概率 ≥1−α_cal。
- **定理 3（分级遗憾）**：步态 Hedge 伪遗憾 ≤√(2T log|𝒢_L|)，技能链 EXP3 ≤√(2T log P)；组合遗憾 ≤ΣR_i+C_comp·N_trans+|S|·ε_g——有界但不免费。
- **定理 4（安全性不因组合而退化）**：组合证书只做交集（Inv_S=∩Inv_i），故 Inv_S⊆Inv_i；任何单技能安全集在组合后只会更小、不会更大。风险全部集中在「缝」：非干扰与切换冲击。
- **实时性**：步态层只读锚点、技能层不在实时路径，实时层仍零学习写，保持 ROSE ≤1ms 契约。

## 2. 形式化定义（完整版）

**定义 185（TANGO 总闭环）** TANGO 是在 ROSE 之上的时序-结构层。它把原「语义流 ∘ 实时流」的双流扩展为三层频带：技能层负责「做什么、按什么顺序做」，步态层负责「怎么落地、何时换接触」，实时层负责「这一毫秒的力与阻抗」。不变式：**所有学习与规划写操作只发生在技能层与步态层；实时层零学习写、只做原子锚点读 + PIC 前向 + WCV 编译 + 派发 + 不变式监视**。TANGO 复用 ROSE 的 OLP/WCV/RSC/ARA/SBR/Shield/OCB 接口。

**定义 186（技能模式与契约）** 技能 s 是一个八元组 `(Pre_s, Inv_s, Post_s, Term_s, π_s, ℓ_s, κ_s, ver_s)`：
- `Pre_s ⊆ 𝒳`：可启动状态集；`Inv_s ⊆ 𝒳`：执行全程必须保持的安全集；
- `Post_s ⊆ 𝒳`：终止时交付的状态集；`Term_s ⊆ 𝒳`：终止判定集；
- `π_s: 𝒳×Θ → 𝒰`：控制器（原子技能为策略，复合技能为子组合）；
- `ℓ_s`：执行损失泛函；`κ_s: 𝒳 → ℕ`：进度变元（ranking function）；
- `ver_s`：模型/参数版本（写入审计链）。
契约成立（sound）⇔ 对任意 `x_0 ∈ Pre_s ∩ Inv_s`，`π_s` 的轨迹 `x(t)` 满足 `∀t<T_end: x(t)∈Inv_s`，在 `κ_s` 界内进入 `Term_s`，且 `x(T_end)∈Post_s ∩ Inv_s`。

**定义 187（技能组合代数 SCA）** 在技能集上定义：
- **顺序** `s1 ; s2`：良构当且仅当 `Post_{s1} ⊆ Pre_{s2}`；`Pre=Pre_{s1}∩Inv_{s2}`，`Inv=Inv_{s1}∩Inv_{s2}`，`Post=Post_{s2}`，`Term=Term_{s2}`。
- **并行** `s1 ∥ s2`：技能声明 rely `R_i` 与 guarantee `G_i`；良构当且仅当写集不相交或 `G_1⊆R_2 ∧ G_2⊆R_1`；`Pre=Pre_1∩Pre_2`，`Inv=Inv_1∩Inv_2`，`Post=Post_1∩Post_2`。
- **事件监督** `s1 ▷_E s2`：执行 s1 至事件 E，边界要求 `Inv_1∩Inv_2` 保持；`Post=Post_{s2}`。
- **选择** `s1 ⊕ s2`：守卫 `g_1,g_2` 互斥且覆盖 Pre；**循环** `s^ω`：每次迭代保持相位不变式 `Inv_phase`。
- **恒等** `skip`：`Pre=Inv=Post=𝒳`。
良构（well-formed）⇔ 递归满足上述全部条件，且进度变元可组合：顺序取字典序、并行取 max、循环以相位/计数为界。

**定义 188（步态原语与接触调度）** `g=(σ,T_c,β,{ρ_e},F_0,𝒫)`，`σ:[0,T_c)→2^E` 为分段常值接触调度，`β` 为占空比，`ρ_e` 为各腿相位偏移，`F_0` 为标称落脚点，`𝒫` 为接触相技能集。一个双足步态即循环组合
`(swing_L ; transfer_LR ; stance_R ; swing_R ; transfer_RL ; stance_L)^ω`。
步态库 `𝒢_L={walk,trot,pace,bound,amble,crawl}` 及参数化族（步长 L、周期 T_c、抬腿 h_f、躯干高度 h_b）。参数化使「步态规划」= 在 `𝒢_L×参数域` 上选调度并优化落脚。

**定义 189（鲁棒步态规划 RGP）** 给定 `φ̂_t`、模式条件半径 `r_t^{(m)}`、步态族 g、时域 H，求解
`min_{c(t),f(t),p_foot} J_gait = ∫(‖c−c_ref‖²_Q + w_e·E + w_s·slip_risk)dt`
s.t. `∀φ∈B(φ̂_t,r_t)`：
1. 质心动力学 `ṗ=m⁻¹Σf + g`；
2. 摩擦锥 `|f_τ| ≤ μ(φ)·f_n`，`f_n ≥ 0`；
3. `ZMP(c,ċ,c̈,f) ∈ conv(support(σ(θ)))`；
4. 运动学可达 `‖p_foot,e − hip_e‖ ≤ ℓ_max` 与碰撞约束；
5. 力矩上限 `|τ| ≤ τ_max`；终态 ∈ 恢复集 `𝒱_rec`。
由于 μ 线性出现，最坏情形为 `μ_min=μ̂−r_μ`；质量/惯量用区间，ZMP 对 f 线性，故固定 σ 时可行域为凸，问题是 SOCP/QP。输出 `(plan, ρ_gait)`；`ρ_gait<0` 即不可行，交 SGR 换族或交 RRC 恢复。

**定义 190（相位-阻抗耦合 PIC）** 令 `θ_t` 为步态相位，接触模式 `m(θ)`：
`K_t = K_phase(θ_t) + h(x_t)ᵀW_t`，`K_phase(θ)=Σ_m 1[m(θ)=m]·K_m(θ)`；
`K_swing`：低刚度 + 轨迹 PD（保证抬脚跟踪）；`K_stance`：高刚度 + 力控（保证承重）；`K_transfer`：两者平滑插值（重心交接）。OLP 更新损失按模式逆频率加权：
`ℓ̃_t^PIC = Σ_m (N/N_m)·1[m(θ_t)=m]·ℓ̃_t`。
WCV 编译使用当前模式的 `r_t^{(m)}` 与模式相关约束。

**定义 191（组合不变式证书）** 对组合技能 S，证书 `C_S=(Inv_S,κ_S,{C_i},转移证明,非干扰证明,进度证明)`。`Inv_S=∩_{i∈S}Inv_i`。证书有效 ⇔ 每个原子契约成立、每个顺序边 `Post⊆Pre`、每个并行对满足 rely-guarantee、每个切换保 Inv、进度变元良基。

**定义 192（技能-步态遗憾 SGR）** 步态族用 Hedge：`w_g∝exp(η·Ĝ_g)`，`Ĝ_g` 为损失 `ℓ_g(t)` 的指数加权均值，伪遗憾 ≤√(2T log|𝒢_L|)。技能链用 EXP3 over 技能图中 P 条候选路径，奖励 = −ℓ_g，伪遗憾 ≤√(2T log P)。组合遗憾 `R_S ≤ Σ_i R_{s_i} + C_comp·N_trans + |S|·ε_g`，其中 `C_comp` 为切换上下文偏移代价、`ε_g` 为步态库近似误差。

**定义 193（技能-场景桥 SCB）** 对 SBR 簇 c，维护 `(p_g(c), p_s(c), r(c))`：`p_g` 为步态族先验（Hedge 权重投影），`p_s` 为技能边先验（EXP3 权重投影），`r(c)` 为模式半径先验。更新信号 = 该簇集群遗憾 `R̂_c`；规则示例：湿滑 → `β↑, L↓, r↑`；崎岖 → `h_f↑, T_c↑`；窄通道 → 侧步技能。SCB 只提供先验与初值，不取代在线遗憾决策。

**定义 194（恢复组合子 RRC）** 恢复技能库 `𝓡={stumble_step, capture_step, knee_brace, sit_down, protected_fall}`，各带契约。触发条件：`risk(Inv)` 超过 `τ_inv`、`ρ_gait<0`、或不变式监视器预测 `T_rec` 内将违规。组合规则 `S ▷_violation R`；`recovery_ready=∃R∈𝓡` 使 `Pre_R` 在 `T_rec` 内可达且 `Inv_R` 使系统回到安全集。若均不可行，执行 `protected_fall`（最小化冲击/关节损伤），并写入不可恢复证书。

**定义 195（TANGO 证书 J_tango）** `J_tango=(J_rose, plan_id, σ_hash, gait_family, ρ_gait, inv_trace_hash, comp_cert_hash, sgr_arm, recovery_ready, ver)`。
Valid ⇔ `Valid(J_rose) ∧ ρ_gait≥0 ∧ inv_trace 无违规 ∧ C_S 有效 ∧ recovery_ready`。
审计链：`σ_hash` 锁定接触调度、`comp_cert_hash` 锁定组合证明、`ver` 锁定技能/模型版本。

**定义 196（TANGO 三层算子）** 见 IP-202：
- 技能层（0.5–5Hz）：技能图搜索 → 组合校验 → SGR/SCB → 提交 `plan_id`；
- 步态层（20–100Hz）：读锚点 → RGP 解算 → 相位推进 → PIC 更新 W/θ → 提交 `σ_hash, ρ_gait`；
- 实时层（1–10kHz）：PIC 前向读 → WCV 编译 → 派发 → 不变式监视 → 触发 RRC。零学习写。

```python
@dataclass
class SkillContract:
    pre: Set; inv: Set; post: Set; term: Set
    rely: Dict[str, Set]; guarantee: Dict[str, Set]
    progress: Callable          # κ(s) ranking
    version: int

class SkillGraphLibrary:
    def __init__(self):
        self.skills = {}        # id -> (policy, contract, loss)
        self.edges  = {}        # (s1, s2) -> guard  (Post_{s1} ∩ Pre_{s2})

    def add(self, sid, policy, contract, loss):
        assert contract.inv <= contract.pre | contract.inv   # 启动即可保持
        self.skills[sid] = (policy, contract, loss)

    def search(self, task, prior, costs):
        # A*：节点=状态谓词，边=技能；代价=预计损失 − 先验加成 + 风险罚
        return a_star(self.skills, self.edges, task.goal, task.start,
                      cost=lambda e: costs[e] + RISK_W(e) - LOGPRIOR(prior, e))
```

```python
def compose_seq(s1, s2):
    c1, c2 = s1.contract, s2.contract
    assert c1.post <= c2.pre, "Post(s1) ⊄ Pre(s2)"
    return Composite(children=[s1, s2],
                     pre=c1.pre & c2.inv, inv=c1.inv & c2.inv,

                     progress=lex(c1.progress, c2.progress))

def compose_par(s1, s2):
    c1, c2 = s1.contract, s2.contract
    assert writes(s1).isdisjoint(writes(s2)) or \
           (c1.guarantee <= c2.rely and c2.guarantee <= c1.rely), \
           "非干扰条件失败"
    return Composite(children=[s1, s2],
                     pre=c1.pre & c2.pre, inv=c1.inv & c2.inv,
                     post=c1.post & c2.post, progress=max_rank(c1, c2))

def well_formed(S):
    # 结构递归：每个内部节点检查算子条件 + 进度良基 + 无零进度环
    if S.is_atomic: return True
    return S.operator_check() and all(well_formed(c) for c in S.children) \
```

```python
def make_gait(family, T_c, beta, h_f, L, phase_offsets, feet):
```

### IP-196 RGP（鲁棒步态规划）

```python
def robust_gait_plan(phi_hat, r_mode, gait, H, x0):
    mu_min = phi_hat.mu - r_mode['mu']              # 球内最坏摩擦
    m_lo, m_hi = phi_hat.mass - r_mode['mass'], phi_hat.mass + r_mode['mass']
    prob = ConvexProblem(H, modes=gait.modes)
    c, f, p = prob.vars('com', 'wrench', 'foothold')

    for k, mode in enumerate(gait.modes_over(H)):
        S = support_polygon(mode, p)
        prob.add(centroidal_dynamics(c, f, m_lo, m_hi))
        prob.add(unilateral(f[k]) >= 0)
        prob.add(norm(f[k][:2]) <= mu_min * f[k][2])   # 收缩摩擦锥
        prob.add(zmp(c[k], c[k+1], f[k]) in S)
        prob.add(reach(p[k], x0, k) <= L_MAX)
        prob.add(torque(c, f, x0) <= TAU_MAX)
    prob.add(terminal(c[-1], f[-1]) in RECOVERY_SET)
    plan = prob.solve()
    rho_gait = prob.min_margin_over_constraints()
    return plan, rho_gait

def mode_radii(rsc_history, modes):
    # 模式条件半径：每个接触模式独立 EWMA，避免“单球跨模式”失效
    return {m: ewma([h.e for h in rsc_history if h.mode == m], beta=0.1)
            for m in modes}
```

### IP-197 PIC（相位-阻抗耦合）

```python
def phase_impedance(theta, x, W, gait):
    m = gait.mode_at(theta)
    K_base = gait.K_phase[m](theta)                  # swing/stance/transfer 查表插值
    K = K_base + frozen_features(x) @ W              # OLP 修正

def pic_weighted_loss(losses, modes, N, Nm):
    # 按接触模式逆频率加权，防止支撑相样本淹没摆动相
    w = np.array([N / max(Nm[m], 1) for m in modes])
```

### IP-198 SGR（分级遗憾调度）

```python
class SkillGaitRegret:
    def __init__(self, gait_families, skill_plans, eta_g=0.2, eta_s=0.3):
        self.wg = np.ones(len(gait_families)) / len(gait_families)
        self.ws = np.ones(len(skill_plans)) / len(skill_plans)
        self.eta_g, self.eta_s = eta_g, eta_s

    def select(self, cluster):
        g = sample(self.wg * prior_g(cluster))       # SCB 先验 @ Hedge
        p = sample(self.ws * prior_s(cluster))       # SCB 先验 @ EXP3
        return g, p

    def update(self, gi, pi, exec_loss, fell, rho_gait, rho_min):
        loss = norm(exec_loss + LAM_FALL*fell + LAM_RHO*max(0, rho_min-rho_gait))
        self.wg *= np.exp(-self.eta_g * loss); self.wg /= self.wg.sum()
        reward = -loss
        rhat = reward / max(self.ws[pi], 1e-6) / len(self.ws)
        self.ws[pi] *= np.exp(self.eta_s * rhat / len(self.ws))
        self.ws /= self.ws.sum()
```

```python
def recovery_compose(S, x, rho_gait, risk):

        return S
    for R in sorted(RECOVERY_LIB, key=lambda r: r.cost):

           and R.contract.inv <= S.contract.inv | SAFE_SET:
            return compose_sup(S, R, guard='violation')      # S ▷_violation R
    return compose_seq(S, PROTECTED_FALL)                     # 受保护跌倒兜底
```

### IP-202 TANGO 三层闭环（整合）

```python
def TANGO_round(M, task, obs):
    # —— 技能层（0.5–5Hz）——
    cluster = M.bank.cluster_of(M.anchor)
    prior_g, prior_s, r_mode_prior = M.scb.prior(cluster)
    plan = M.sgl.search(task, prior_s, M.sgr.costs())[0]
    assert well_formed(plan) and recompute_cert(plan)        # 组合即证明
    g_family = M.sgr.select_gait(cluster, prior_g)

    # —— 步态层（20–100Hz）——
    phi_hat = M.mel.infer(obs)
    r_modes = M.rgp.mode_radii(M.rsc.history, gait_modes(g_family))
    gait_plan, rho_gait = M.rgp.solve(phi_hat, r_modes, g_family, H=2.0)
    if rho_gait < 0:
        g_family = M.sgr.fallback_gait(cluster)             # 更保守族
        gait_plan, rho_gait = M.rgp.solve(phi_hat, r_modes, g_family, H=2.0)

    # —— 实时层（1–10kHz，零学习写）——
    for theta in advance_phase(gait_plan):
        anchor, fresh = M.ara.read_latest()
        K, m = phase_impedance(theta, anchor.x, M.olp.W, gait_plan)
        K_safe, rho = M.wcv.compile(K, anchor.phi_hat, r_modes[m])
        cert_exec = M.ertc.dispatch(K_safe)
        EV = wait_contact_and_build_evidence()
        if not in_invariant(EV, plan.current.inv):
            plan = M.rrc.recovery_compose(plan, EV, rho_gait, risk(EV))
            break                                            # 交回技能层重规划

    # —— 回到技能层/步态层：记账与学习 ——
    M.sgr.update(g_family, plan.id, loss_of(EV), EV.fell, rho_gait, RHO_MIN)
    M.scb.update(cluster, loss_of(EV), loss_of(EV))
    M.bank.mine(EV, M.anchor); M.hedge.step(cluster, loss_of(EV), baseline_loss(EV))
    M.rsc.update_modes(EV.tau_ext_obs, predict_ext_torque(anchor.phi_hat, K_safe), m)
    M.olp.online_step(anchor.x, execution_loss_grad(K_safe, EV, worst_phi_in_ball(phi_hat, r_modes[m])))
    return M, K_safe, EV, build_j_tango(cert_exec, plan, gait_plan, rho_gait,
                                        inv_trace=EV.inv_trace, recovery_ready=has_recovery(plan))
```

## 4. 推导

**引理 1（组合的 Inv 闭包）** 对任意良构组合 S，`Inv_S = ∩_{i∈S}Inv_i ⊆ Inv_i (∀i)`。顺序组合的每个转移点满足 `Post_{s_i}⊆Pre_{s_{i+1}}`，故终态仍在 `Inv_{i+1}`；并行组合的 rely-guarantee 保证一方写不破坏另一方的 Inv。∎

**引理 2（鲁棒摩擦的凸收缩）** 固定接触调度，摩擦约束 `|f_τ|≤μ f_n` 对 μ 线性单调；故 `∀μ∈[μ̂−r_μ, μ̂+r_μ]` 成立 ⇔ 在 `μ_min` 处成立。质量/惯量区间使质心动力学为线性区间约束；ZMP 对 f 线性。因此固定 σ 的鲁棒可行域是凸集的交，问题为 SOCP/QP。∎

**定理 1（组合不变式保持）** 设每个原子技能 s 的契约成立，且组合 S 良构。则从任意 `x_0∈Pre_S∩Inv_S` 出发，执行 S 的轨迹恒在 `Inv_S` 内，并在组合进度变元界内终止于 `Post_S`。
证明：对组合树结构归纳。原子情形由契约成立。顺序：由归纳假设 s1 终止于 Post_{s1}∩Inv_{s1}；良构给出 Post_{s1}⊆Pre_{s2}，故 s2 可启动，归纳得 s2 保持 Inv_{s2} 并终止于 Post_{s2}；合并得 Inv_S。并行：由非干扰 `G_1⊆R_2∧G_2⊆R_1`，s1 的保证不破坏 s2 的依赖，反之亦然；两轨迹交错时 Inv_1∩Inv_2 保持。循环：相位不变式 Inv_phase 在每次迭代边界保持，由归纳。监督：切换事件处良构要求边界保 Inv。终止性：进度变元在顺序取字典序、并行取 max、循环有界，且无零进度环 ⇒ 良基 ⇒ 终止。∎

**定理 2（鲁棒步态安全）** 若 (i) `P[φ*∈B(φ̂_t,r_t)]≥1−α_cal`；(ii) RGP 返回 `ρ_gait≥0` 的鲁棒可行计划；(iii) 实时层 WCV 按模式约束编译且 PIC 前向确定；(iv) 切换冲击满足冲击锥（A79）。则执行轨迹在时域 H 内保持于鲁棒生存核 `𝒱` 内的概率 ≥1−α_cal。
证明：由引理 2，鲁棒可行 ⇒ 对真实 φ* 可行；生存核 `𝒱` 对反馈策略控制不变（ZMP/捕获点条件在每个接触模式内成立）。对接触模式序列归纳：每个模式内轨迹在 `𝒱`；模式切换点由冲击锥保证不越出 `𝒱`；故全程在 `𝒱`。概率来自 φ*∈B 的事件。∎

**定理 3（分级遗憾）** 步态 Hedge 的伪遗憾 ≤√(2T log|𝒢_L|)；技能链 EXP3 ≤√(2T log P)。对组合 S，由于每次切换改变上下文，子技能的最优比较器在组合后不再是最优，产生上下文偏移；标准同时化论证给出 `R_S ≤ Σ_i R_{s_i} + C_comp·N_trans + |S|·ε_g`，其中 `C_comp` 是切换前后损失函数的 Lipschitz 差异上界、`ε_g` 是有限步态库相对最优连续族的近似误差。∎

**定理 4（组合安全不放大）** `Inv_S=∩Inv_i⊆Inv_i`，故组合后的安全集只会更小。组合不会引入新的「安全状态」，但可能引入**新的不安全转移**；因此证书必须显式证明转移与冲击，而不能只证明各子技能内部安全。∎

**命题（活性/无死锁）** 若技能图的每条候选路径有限、每个技能在 κ_s 界内终止、且守卫选择覆盖 Pre，则监督自动机在任何公平调度下不会无限停留在非终止状态；若进度停滞则触发 RRC，活性由恢复技能的有界 T_rec 保证。∎

**命题（模式条件半径优于单球）** 若各模式残差分布均值不同，单球半径需覆盖并集而模式条件球只需覆盖各自分布，故 `Σ_m r^{(m)}` 的保守度低于 `r` 的并集覆盖；当模式间偏差方向相反时尤为显著。∎

## 5. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SGL 图搜索 | O(E log V)（每任务一次） | O(V+E) | 契约衔接可判定 |
| SCA 良构检查 | O(|S|)（组合树） | O(|S|) | 定理 1：不变式保持 |
| GPG 步态生成 | O(|E|·|modes|) | O(|E|) | 接触调度与相位一致 |
| RGP 单调度 | 凸 SOCP/QP，O(n³)~O(n³.5)，H 固定 | O(H·n) | 引理 2 + 定理 2：鲁棒可行 |
| PIC 前向（实时） | O(d_us·m + m·d_out) < 0.05ms | O(m·d_out) | 相位一致 + 定理 2 |
| SGR Hedge/EXP3 | O(|𝒢_L|+P) | O(|𝒢_L|+P) | 定理 3：分级遗憾 |
| SCS 监视 | O(1)/周期 | O(1) | 不变式不可欺骗；违规即恢复 |
| SCB 先验 | O(C) | O(C·(G+P)) | 仅先验，不损遗憾界 |
| RRC 恢复组合 | O(|𝓡|·T_rec) | O(|𝓡|) | 命题：活性；否则受保护跌倒 |
| TANGO 实时层 | ≤1ms 保持 | — | 零学习写（沿用 A75） |

**正确性定理（TANGO-Complete）** 假设 A61–A76（第 62 轮）及：
- **(A77) 原子契约可靠性**：每个原子技能在其 `Inv` 内执行且满足 `Pre/Post/Term`，对 φ∈B 鲁棒成立。
- **(A78) 并行非干扰**：并行技能的写集不相交，或 `G_1⊆R_2 ∧ G_2⊆R_1` 且共享耦合有界。
- **(A79) 切换兼容性**：接触模式切换的冲击脉冲落在冲击锥内；切换边界保持 `Inv` 连续（或离散跳变仍在 `Inv` 内）。
- **(A80) 步态库覆盖**：任务最优步态落在 `𝒢_L×参数域` 的 ε_g 邻域内。
- **(A81) 鲁棒接触凸性**：固定调度下约束为凸（摩擦线性、ZMP 线性、质量区间）。
- **(A82) 组合遗憾分解**：上下文偏移有界 `C_comp<∞`；候选路径集 P 有限。
- **(A83) 恢复可用性**：任一时刻存在 `R∈𝓡` 在 `T_rec` 内可达，或 `protected_fall` 合同成立。

则：
1. **组合安全**：良构组合在契约成立的原子技能上保持 `Inv_S`（定理 1）；组合不放大安全集（定理 4）。
2. **鲁棒步态**：`P[执行保持于 𝒱]≥1−α_cal`（定理 2）；模式条件半径降低单球跨模式的保守度。
3. **分级遗憾**：步态 ≤√(2T log|𝒢_L|)、技能链 ≤√(2T log P)、组合 ≤ΣR_i+C_comp·N_trans+|S|·ε_g（定理 3）。
4. **相位适配**：PIC 使摆动/支撑获得不同阻抗，OLP 损失逆频率加权消除支撑支配。
5. **场景驱动**：SCB 把 SBR 集群遗憾接到技能/步态先验，使学习力投向最亏钱的场景。
6. **安全失败**：RRC 在 Inv 风险或 `ρ_gait<0` 时组合恢复；否则受保护跌倒并写入不可恢复证书（A83）。
7. **实时性不变**：实时层零学习写，≤1ms 契约与 ROSE 一致。

## 7. 已知风险

**一句话**：组合安全完全押在「并行非干扰（A78）+ 切换冲击锥（A79）」上——真实腿-臂耦合与触地冲击恰在契约最脆弱的「缝」处；保守放大非干扰界会使鲁棒可行域被压空（安全但拒绝行动），乐观缩小则所有组合证书退化为纸面证明。

**次级风险与缓解**：
1. **组合遗憾不可加**：上下文偏移使 `ΣR_i` 不能直接转为组合遗憾 → 显式记账 `C_comp·N_trans`；切换频繁的链优先用复合技能（把切换内化）以减少 N_trans。
2. **步态库有限**：`ε_g` 不可忽略 → 参数化族在库内连续优化步长/周期；用 E214 监控库外最优差距。
3. **RGP 实时性**：SOCP/QP 在步态层（20–100Hz）求解可能超时 → 热启动 + 固定调度预解 + 只在线修正落脚；超时即触发 RRC 安全回退。
4. **模式半径样本稀疏**：某些接触模式出现少，`r^{(m)}` 估计噪声大 → 用 SCB 的 `r(c)` 先验做 shrinkage，并设 `r_min` 下限。
5. **契约版本漂移**：RL 策略更新后旧契约可能失效 → 技能 `ver_s` 与证书绑定；契约变更即令 `J_tango` 失效并要求重新校验（与 ROSE 的 `adapter_ver` 共用审计链）。
6. **恢复技能本身失败**：级联恢复可能震荡 → 恢复技能最多嵌套 1 层，超出即 `protected_fall`；记录「恢复失败」为新的 SBR 场景并触发场景课程。
