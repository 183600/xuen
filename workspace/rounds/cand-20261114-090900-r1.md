# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配×主动交互消歧」IP-253~263；本轮灵感：「中间件」×「遥操作」）

> R69 给闭环装上了「眼」和「嘴」：看不清就凑近看、拿不准就问、摸不透就触一下，并用 VoI 决定值不值得求证。但它有一个从未写进定义的默认前提——**问题发出之后，答案会以零延迟、零失真地回到提问者的同一个世界里**。它把 `o_t` 当作「此刻的世界」，把交互当作「本地事件」，把证据当作「可以相加的独立来源」。
>
> **遥操作**从三个方向同时撕开这个前提：
> - 回答者（人）在远方，答案必须穿过一条**中间件**才到达；这条通路有延迟、抖动、丢包、时钟域、坐标系、QoS 与版本漂移。
> - 在答案往返的时间里，机器人自己在动。等答案回来，它回答的那个东西可能已经不在原处——**答案本身是对的，但它回答的是过去的世界**。
> - 操作者看到的也是同一条链路压缩、延迟后的画面。他不是一个独立的全知见证者，而是与你共享同一个盲区、同样迟到的人。
>
> 所以本轮的核心不是「再加一个传感器」，而是两句话：
> **中间件不是管道，而是闭环里的一个动态参与者；遥操作不是「人来遥控」，而是「两个各自迟到、各自局部正确的观察者，试图对同一个世界达成一致」。**
>
> 核心命题：把 R69 的交互从「瞬时、本地、无中介的求证」升级为「**有时限、有参照物、有传输资格**的远程求证」——
> 1. 显式引入 **U_mw（中介不确定性）**：证据是否新鲜、语义是否正确、来源是否可信、是否完整；它不能靠「问世界」消除，只能靠修通道、换路径、等待。
> 2. 把 VoI 换成 **可执行 VoI（AVoI）**：答案必须在决策截止前到达，且其参照物在往返期间没有被自己的动作改变；**晚到的答案不是信息，是噪声**。
> 3. 用**双时钟**（墙钟 + 因果/动作年龄）与**时域膨胀安全包络**替代 R69 的标量 λ：证据越老，可认证的前缀越短，最终必须停下重看；速度缩放只是它的特例。
> 4. 引入**参照物保持的可问性**：只有在能安全停住、且停住期间参照物不变时，才允许向远方提问——**能停下来，才配问**。
> 5. 把「沉默」从证据里彻底驱逐：**缺消息 ≠ 无事件，不回应 ≠ 同意**；阴性安全断言必须携带活性见证。
> 6. 权威按**证据新鲜度**而非角色分配：迟到的远程指令不能扩张本地认证安全集；本地死手永远独立于通道。
>
> 命名 **TETHER-RAS**（Timed-Evidence Transport with Horizon Expansion & Remote-authority arbitration for Risk-Aware Systems）——牵引绳（tether）既是遥操作的物理隐喻，也是中间件的功能隐喻：它会拉长（延迟）、会磨损（丢包）、会传力（力反馈），而且**它不是一根透明的绳子，它本身在闭环里振动**。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我等的这个回答，回来时还属于这个世界吗**」。

## 0. 直觉与动机

**灵感 1（中间件 → 透明的幻觉）**
直觉：中间件最成功的宣传语是「透明」——发布者不必知道订阅者，节点不必知道网络。但「透明」在安全语境里恰恰是一个危险词：发布与订阅之间实际发生了**选择、缓冲、序列化、坐标变换、时间戳重写、QoS 降级、版本协商**。数值可以一字不差，而它的**语义资格**已经变了。一条以 `best_effort` 送达的障碍物消息、一条超过 `lifespan` 的位姿、一条经未认证 tf 变换的坐标，看起来和合格证据完全一样。中间件的失败不是「数据错了」，而是「数据对，但它已经不是你以为的那条数据」。这就是 U_mw：不是传感器噪声，也不是世界歧义，而是**证据在运输途中失去资格**。

**灵感 2（遥操作 → 控制回路穿过通道）**
直觉：遥操作的本质不是「人按按钮」，而是**闭环被一条通信链路切开**。链路一被切进回路，物理性质就变了：时延让修正迟到、抖动让相位漂移、丢包让操作者看到的世界断续、力反馈会把能量注入回路导致振荡。经典结论是必须用无源性（wave variable / time-domain passivity）来保证稳定。R69 的「不确定就收紧 λ」在单机上是对的，但在遥操作里，**增加阻尼会改变操作者感知到的阻抗，可能把「更安全」变成「更难控」**。安全与稳定必须分开处理：安全靠状态空间几何（包络/时域），稳定靠能量（无源性）。

**灵感 3（双重迟到 → 两个都以为自己即时的人）**
直觉：机器人按 `o_{t−a}` 决策，操作者按 `o_{t−a−d}` 判断，两个人都在用自己的「现在」谈论世界。更糟的是，操作者的画面和机器人共享同一路相机：他看到的不是「另一个视角」，而是**同一个延迟视角**。于是「问操作者」经常不是第二意见，而是回声。R69 的「k 个正交证据源」在这里会被中间件轻易骗过：同一路相机经不同 topic 转发三次，仍然是同一个盲区。

**灵感 4（参照物会过期 → 提问的静止条件）**
直觉：一个问题总是「关于某个东西」的。问「左边那扇门能过吗」，前提是「那扇门」还在你左边。可如果机器人一边问一边继续走，等回答回来，门已经在身后了。**答案没有错，问题失效了。** 这给出一个非常具体、可执行的规则：远程提问必须配合一个**保持参照物**的动作——停住，或至少不改变被问对象的相对位姿。于是「等待」不再只是等消息，而是**让问题与答案谈论同一个世界**。这也解释了人类为什么会在岔路口停下来问路：不是不会走，而是要先冻结参照系。

**灵感 5（沉默不是证据 → 阴性证据需要活性证明）**
直觉：安全系统里最危险的证据是「没有消息」。感知节点挂了，下游看到的不是「故障」，而是「没有障碍物」；操作者没回话，系统读到的不是「失联」，而是「没有异议」。中间件把「缺失」翻译成了「空」。因此本轮必须立一条硬规矩：**任何阴性安全断言（无障碍、无事件、无异议）都必须附带活性见证**——心跳、序列连续、覆盖该区域的可观测源全部在线。沉默只有两种含义：没发生，或没听见；在证明「听见了」之前，不能当成第一种。

**灵感 6（权威随证据走，死手不随通道走）**
直觉：传统遥操作按角色分配权限：人为主、机为辅，或反之。但角色不知道谁更「当下」。如果操作者的画面已经冻结两秒，他的高权限就是高风险；如果机器人本地证据新鲜且认证完整，它应当有权拒绝执行一条基于过期世界的指令。因此权威应当由**证据新鲜度、传输完整性、校准后的胜任度**共同决定，而不是由头衔决定。但权威再动态，**本地急停/安全保持必须独立于通道**——因为「停止」永远是收缩安全集的动作，必须无条件接受。**安全不需要信任人，只需要本地强制；信任只影响效率。**

**灵感 7（对 R69 的姿态 → 理想通道是边界情形）**
直觉：TETHER 不推翻 FLUID，而是把它变成「理想中间件 + 全知操作者」的极限：延迟为零、无变换、无限有效期、操作者与机器人共享同一时刻的世界。此时 U_mw = U_op = 0，AVoI 退化为 VoI，时域膨胀退化为常数，证据加权权威退化为 R69 的决策。**新层必须是旧层在边界上的严格退化**——这样每加一层，不会多一个需要独立信任的黑箱，只是把旧层没写出来的前提显式化。

## 1. 形式化定义（增量：定义 310–327）

**定义 310（TETHER-RAS 总览）** TETHER-RAS = (MPL, STC, TSE, AVoI, QAA, OAM, EWA, PCL, TID, NEL, RAS-WM‡)。四条不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **时间资格**：任何用于安全证书的证据必须在其认证有效期内（墙钟 + 因果双时钟）；证书自身携带有效期，过期即失效；
(iii) **阴性证据需活性见证**：任何「无事件 / 无障碍 / 无异议」必须由心跳、序列连续与覆盖性见证证明；缺消息 ≠ 无事件，沉默 ≠ 同意；
(iv) **局部死手与权威不对称**：与通道无关的本地安全保持/急停永远可用；远程命令只能收缩、不能扩张本地认证安全集；权威按证据新鲜度分配而非角色。

**定义 311（证据包与血缘账本 MPL）** 证据包 e = (v, src, τ_src^wall, τ_src^causal, clock_domain, frame_chain, schema(id,ver), qos, seq, path_id, sig)。血缘链 T_e = [(xform_i, agent_i, ver_i, sig_i)]；账本为只追加哈希链 H_e = H(H_prev, e)，记录每条证据进入每条证书的完整路径。
**语义同一**：e ≡ e′ 当且仅当存在已认证变换把 v, v′ 映射为同一物理量、同一坐标系、同一因果时刻。仅数值相等不构成同一。

**定义 312（中介不确定性四分解 STC）** U_mw = (U_stale, U_sem, U_prov, U_comp)，四者语义不同、不可相加：
- **U_stale（时效）**：由墙钟年龄 a_wall = t − τ_src^wall 与因果年龄 a_causal（自证据产生以来已提交的决策数/积分控制权限）共同决定；U_stale = E‖x_t − Π_{τ_src→t} x_{τ_src}‖，即用预测器把旧证据推到现在的误差。
- **U_sem（语义）**：坐标系、量纲、IDL/schema 版本漂移导致的语义失真期望；来自未认证或跨版本的变换链。
- **U_prov（来源）**：发布者身份、时钟域、变换签名不可信的程度与概率。
- **U_comp（完整）**：丢失、乱序、重复、late-join 部分历史导致的不完整；注意「缺消息」在此只意味着 missingness，不意味着 absence。
四者对应四种不同的修复动作：等待/重传（stale）、重算/重变换（sem）、重认证（prov）、请求 QoS/换路径/要见证（comp）。**绝不能把 U_mw 丢给「问世界」——你不能让一块石头替你修时间戳。**

**定义 313（双时钟与认证有效期）** 每条证据有有效期 V(e) = [τ_src, τ_src + L(e)]，L(e) = min(L_qos, L_dyn, L_sem, L_ref)。其中 L_dyn 由目标动力学与安全裕度给出，L_ref 由参照物保持条件给出。墙钟年龄决定「消息多旧」，因果年龄决定「世界被我们改了多少」：**静止一秒不等于运动一秒**。过期证据可以作先验，不得作证书。

**定义 314（参照物保持与可问性 QAA）** 每条证据指向一个参照物 R(e)（物体 / 区域 / 场景）。自 τ_src 以来，机器人自身的动作历史诱导一个变换 φ。定义参照有效性 ρ(e,t) = 1[φ(R(e)) ∩ R(e) ≠ ∅，或 φ 在 R 上可逆且已被认证]。
一个远程查询 g 是**可问的**当且仅当：存在一个安全保持策略，在往返时延 d_g 内使 ρ ≡ 1 且不越出预算与安全包络。**能停下来，才配问**；停不住时，提问不是求知，是制造一条关于过去的证词。

**定义 315（可执行 VoI / AVoI）** 对候选信息动作 g、期望往返 d_g、决策截止 H：
VoI_act(g; d_g, H) = 1[d_g ≤ H] · E[I(M_t; y_{t+d_g})] · ρ̄(g, d_g) · (1 − ρ_echo) − c(g)。
其中 ρ̄ 是往返期间参照物保持的期望概率，ρ_echo 是操作者与机器人共享视角导致的证据相关性（回声折价）。若 d_g > H，VoI_act ≡ 0：**赶不上决策的答案没有信息价值**。R69 的 VoI 是 d_g = 0、ρ̄ = 1、ρ_echo = 0 的特例。

**定义 316（静止换信息 / wait-to-ask）** 允许选择一个安全保持动作 h(w) 持续 w，把决策截止从 H 延到 H + w，同时把 ρ̄ 拉回 1。选择：
(g*, w*) = argmax_{g,w} [VoI_act(g; d_g, H+w) − c(g) − c_hold(w)]，s.t. SafeHold(w) ∧ 预算未越界。
若不存在安全保持，则禁止交互，退回 R69 的本地估计。系：**停不下来时，最诚实的选择是承认不知道并本地保守，而不是问一个注定过时的问题。**

**定义 317（操作者觉察模型 OAM）** 操作者收到的是延迟/压缩视图 v_op = π_τ(E)，其回答 y ~ p(y | M, b_op, v_op)，b_op 为其信念与先验。把远程证据拆成两部分：**互补信息** κ = I(y; M | o_robot) 与**共享回声** I(y; M) − κ。若 κ ≈ 0（他看到的就是你看到的），提问只是回声。定义 U_op = 关于「操作者此刻到底知道什么、何时看到、是否理解任务」的不确定性；U_op 高时不得把权威让渡给操作者，而应发出 **g_explain**（把机器人已认证的状态/证据回传给操作者），这是一种新的信息动作——它降低 U_op，而不是降低世界歧义。

**定义 318（证据加权权威 EWA）** 权威 α ∈ [0,1]，但安全合成不是简单线性混合，而是先投影到本地认证安全集：
a_cmd = Proj_{𝒮_local}( blend(α·a_human, (1−α)·a_auto) )，α = σ(cred_h − cred_a)，
cred 由证据新鲜度、传输完整性、校准后的任务胜任度共同给出。三条硬规则：(a) **停止永远接受**（停止只会收缩安全集）；(b) 远程命令不得扩张 𝒮_local；(c) 当 U_mw / U_prov / U_op 越界时，α 退回本地保持，而不是退给一个过期的操作者。**权威跟随证据新鲜度，而非头衔。**

**定义 319（时域膨胀安全包络 TSE）** 给定 R68/R69 的认证安全集 S、动力学 Lipschitz 常数 L、证据年龄 a、执行延迟 d_act、预测误差 ε_pred 与语义误差 ε_sem，定义腐蚀后的安全集
S_τ = S ⊖ B(ε(a))，ε(a) = L·(a + d_act) + ε_pred + ε_sem。
认证前缀长度 k(a) = max{k : 执行长度 k 的前缀的预测管道始终落在 S_τ 内，且在第 k 步之前完成重观测}。风险缩放 λ_τ 只在 S_τ 上生效。系：**a 增大 ⇒ k(a) 单调不增；k(a)=0 时必须停下重看。λ 只是 k 不变时的一种特例。**

**定义 320（无源性补偿层 PCL）** 双边通道往返时延 d、丢包率 ℓ。用波变量 (u, v) 编码力/速度，时域无源控制器注入耗散；定义通道能量 E_ch(t)，要求任意时间窗内 E_ch ≥ 0 且留有裕度 m_p。安全的 (λ, 无源参数) 必须联合选取：λ 增大阻尼有利于本地安全，但会改变操作者感知阻抗，必须由 PCL 同时补偿。**安全与稳定分离：安全靠几何，稳定靠能量。**

**定义 321（证书 J_TETHER）** J_TETHER = (J_FLUID, provenance_root, staleness_p95, transform_cert, U_mw_tuple, causal_age, referent_validity, authority_log_hash, horizon_k(a), passivity_margin, path_diversity, liveness_witnesses, tether_ver)。
Valid ⇔ Valid(J_FLUID) ∧ 全部证据在有效期内 ∧ 变换链已认证 ∧ 全部阴性断言有活性见证 ∧ 权威不变式成立 ∧ m_p ≥ 0 ∧ 退化边界可复现（定理 18）。

**定义 322（中介与遥操作干扰集）**
ℰ_mw：陈旧缓存重放、QoS 静默降级、时钟偏移注入、坐标系/IDL 版本漂移、topic 冒充、tf 投毒、late-join 部分历史、融合节点隐去相关性的「假独立」。
ℰ_teleop：时延攻击、抖动放大、力反馈能量注入、操作者身份重放、幽灵操作者、死手旁路。
ℰ_TETHER = ℰ_FLUID × ℰ_mw × ℰ_teleop。

**定义 323（传输独立性与去回声 TID）** 两条路径 p, q **传输独立**当且仅当其时钟源、变换链、发布者血缘、物理感知模态四者两两不相交。独立证据的有效源数
n_eff = 1 + Σ_{独立对} w_{pq}（受路径数上限约束），**不是消息条数**。融合包若不声明其组成源与相关性，下游按单源处理（保守）。R69 的「k 个正交源一致」在本层必须把「正交」落实为传输独立，否则同一路相机转发的三条消息会伪造出三重一致。

**定义 324（阴性证据与活性见证 NEL）** 阴性断言 ¬X（无障碍 / 无碰撞 / 无异议）可认证，当且仅当：
(a) 所有可能观测到 X 的源在线且满足 deadline/liveliness；
(b) 见证集 W 覆盖 X 的支撑域（support(X)）；
(c) 断言在有效期内。
否则结论只能是「unknown」，不是「safe」。**沉默的似然是 missingness 的似然，不是 absence 的似然。** 遥操作推论：操作者不回应 = 失联，不是默许；不能把「没人反对」当作「批准执行」。

**定义 325（证据生命周期与修复动作）** 证据状态机 fresh → aging → expired；修复动作 r ∈ {retransmit, resync_clock, re-derive_transform, request_qos, re-authenticate, switch_path, request_witness}。修复本身是一种信息动作，有自己的 VoI、成本与安全认证；修复失败或超时 ⇒ 该证据作废，而不是降级使用。

**定义 326（四通道不确定性处置）** 在 R69 的 (U_ale, U_epi) 之外显式增加两通道：
- U_ale → R68 的 λ_floor（不可约噪声）；
- U_epi → R69 的本地信息动作（看/触/本地问）；
- U_mw → 修通道 / 等待 / 冗余路径（**不能问世界**）；
- U_op → 告知操作者（g_explain）/ 重分配权威（**不能假设**）。
四者不做简单加和，各自有独立门控与证书字段。R69 恰为「理想通道 U_mw=0 + 全知操作者 U_op=0」的边界。

**定义 327（严格包含声明）** 当 d=0、L=∞、无变换、时钟完美、操作者全知（κ=1, U_op=0）、且不存在依赖沉默的阴性断言时，TETHER 的证书与逐指令动作与 FLUID 完全一致；当 VoI ≤ 成本时退化为 CALM。安全侧只增加「证据作废 / 本地保持」两种收缩操作，故永不弱于 R69/R68。

## 3. 推导

**引理 19（相关路径的不可加性）** 设 k 条证据路径估计同一物理量 x，其中至少两条共享同一时钟/变换链/发布者，即共享偏置 b。则任意加权平均满足 E[(x̂−x)²] = b² + σ²/Σw；当 k→∞ 时误差趋于 b² 而非 0。系：**相关路径再多也不能消除共同偏置；有效证据数 n_eff ≤ 偏置正交补的维数。** R69 的「k 个正交源一致」若不按传输独立性计数，会被同一路相机的多次转发伪造；这也是中间件融合节点最隐蔽的危害——它把相关误差包装成一条「干净」消息。

**引理 20（标量 λ 的不足）** 设状态动力学 Lipschitz 常数为 L，安全集 S 的可用裕度为 m，证据年龄为 a。认证所需的预测误差下界 e(a) ≥ L·a − δ。若 e(a) > m，则无论 λ 取多小，都挡不住「证据所示状态已偏离真实状态」这一事实：速度缩放只能减慢未来的漂移，不能撤销已经积累的偏差，也不能弥补执行延迟。故此时唯一的正确动作是缩短认证前缀 k(a) 并尽快重观测；当 k(a)=0 时必须停止。**λ 是 k 固定时的特例，不是万能的刹车。**

**引理 21（AVoI 的期限单调性与静止换信息）** VoI_act 关于 d_g 单调不增，且 d_g > H 时恒为 0（减去成本后为负）。因此当往返延迟超过截止时间时，任何正成本交互都严格劣于不交互。若存在安全保持 w，使 H→H+w 且 ρ̄→1，则 VoI_act 增加；当且仅当该增量超过 c_hold(w) 时，停下来问才划算。系：**「停下来问」只在「停得住且参照物不漂」时成立；停不住时应本地保守，而不是发出一个注定关于过去的问题。** 这也把 R69 的交互预算从「次数约束」升级为「时间与参照系约束」。

**引理 22（权威仲裁的安全性）** 在 EWA 中，远程命令先与本地认证命令混合，再投影回 𝒮_local，且停止命令无条件接受、死手独立于通道。则对任意远程指令 a_h（包括恶意、重放、过期）与任意 α，执行后的闭环状态仍落在 𝒮_local 内。故权威仲裁不能增加物理风险，只能影响任务性能。系：**安全不需要信任操作者，只需要本地强制；对操作者的信任只影响效率，不影响安全性。** 这同时防止了「责任扩散」——安全由本地证书负责，不由「人应该会注意」负责。

**定理 18（TETHER 严格包含 FLUID 与 CALM）** 在理想条件（d=0、L=∞、无变换、时钟完美、κ=1、U_op=0、无沉默型阴性断言）下，TETHER 的四类不确定性中 U_mw=U_op=0，AVoI 退化为 VoI，TSE 的 k(a) 退化为常规前缀，EWA 退化为 R69 的决策，NEL 对不存在依赖沉默的断言恒真。逐项代入定义 310–327 得证书与动作与 FLUID 一致；再令 VoI ≤ 成本，得 CALM。安全侧 TETHER 只新增「证据作废」与「本地保持」，两者都是收缩操作，故任意状态下风险不高于 R68/R69。

**定理 19（安全与稳定的分离）** 在 TSE（定义 319）与 PCL（定义 320）同时满足时：(a) 只要证据年龄与执行延迟有界，时域膨胀保证认证前缀的预测管道落在 𝒮_τ ⊆ S 内，与操作者行为无关——这是**状态安全**；(b) 无源性保证人—机—通道闭环的能量非增，与 λ 的取值无关——这是**稳定性**。两者约束的数学对象不同（几何 vs 能量），因此可以独立验证、独立失效。系：R68/R69 的「不确定就同时收紧一切」在遥操作里是过度耦合的；正确做法是**安全靠时域几何、稳定靠能量、效率靠 AVoI**，三者分开调节。

**定理 20（中介故障的可检出性边界）** 设血缘账本哈希链完整，且至少存在一条与主路径传输独立的副路径。则任何单点语义故障（陈旧重放、坐标系漂移、QoS 静默降级）若改变证据的物理含义，在以认证公共坐标比较两条路径时会产生超过噪声水平的残差，从而可检出；若只有单一路径，则系统性的变换错误与真实物理偏移在观测上等价，**不可检出**。系：**签名证明「谁说的」，证明不了「变换在物理上对不对」；语义正确性必须由物理锚点或传输独立路径接地。** 这是 R69「标定不可吸收」引理在运输层的镜像，也是本轮最脆弱处的伏笔。

## 6. 本轮最大风险

**一句话**：TETHER-RAS 的全部安全论证都建立在「中间件自报的血缘、时钟与 QoS 元数据是诚实的」这一前提上——**但签名只能证明「谁说了这句话」，证明不了「这个坐标变换在物理上是对的」；一条始终如一、签名完整、哈希链自洽的错变换，会把整个证书变成一份盖了章的谎言，而单路径系统在观测上根本无法把它和真实物理偏移区分开。** 换言之，最危险的不是掉包，而是**一个从不改口、且被认证过的错**。

**次级风险与缓解**：
1. **元数据撒谎**（QoS/时延/时钟自报）→ 硬件时间戳 + 传输独立路径 + 回声/往返测距，拒绝单路径认证；
2. **操作者回声/共谋** → OAM 估计 κ，要求独立视角或物理见证，κ≈0 时禁用远程定案；
3. **过度保持导致任务停滞** → 有界保持 + 分阶段重观测 + 保持成本进入 AVoI；
4. **时延下的人—机振荡** → PCL 无源性层 + 定理 19 的安全/稳定分离；
5. **权威仲裁被博弈** → 权威日志上链、停止无条件、责任与证书绑定；
6. **沉默被当作同意** → NEL 强制活性见证，阴性断言无见证即 unknown。

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** 时间资格（双时钟有效期，过期证据不得作证书）；阴性证据需活性见证（缺消息≠无事件，沉默≠同意）；局部死手独立于通道；远程命令只能收缩、不能扩张本地认证安全集。

**定义 311–312（MPL 与 U_mw）** 证据包带血缘链与只追加哈希账本；语义同一需经认证变换映射到同一物理量/坐标系/因果时刻，数值相等不算。U_mw 四分解：时效、语义、来源、完整；分别对应等待/重变换/重认证/要见证，**不能靠问世界消除**。

**定义 313–314（双时钟与参照物保持）** 有效期取 QoS/动力学/语义/参照四者最短；墙钟年龄与因果年龄同时约束。远程查询可问，当且仅当存在安全保持使参照有效 ρ≡1 且不越预算——**能停下来，才配问**。

**定义 315–316（AVoI 与静止换信息）** `VoI_act` 对往返延迟单调不增，`d>H` 时为 0；安全保持把 `H→H+w` 且 `ρ̄→1`，当且仅当增益超过 `c_hold(w)` 时停下来问才划算。

**定义 317（OAM）** 操作者回答 = 互补信息 κ + 共享回声；κ≈0 时提问是回声。U_op 高时不得让渡权威，应发 `g_explain` 告知已认证状态（降 U_op，不降世界歧义）。

**定义 318（EWA）** `a_cmd = Proj_{𝒮_local}(blend(α a_h,(1−α)a_auto))`，`α=σ(cred_h−cred_a)`；停止无条件、远程不扩张、U_mw/U_op 越界退回本地保持。**权威跟随证据新鲜度，而非头衔。**

**定义 319（TSE）** `ε(a)=L(a+d_act)+ε_pred+ε_sem`，`S_τ=S⊖B(ε(a))`，`k(a)` 为预测管道留在 `S_τ` 内且能及时重观测的最大前缀。a↑ ⇒ k(a)↓；k=0 必须停。**λ 是 k 不变时的特例。**

**定义 320（PCL）** 波变量 + 时域无源控制，要求任意窗口 `E_ch ≥ 0` 且裕度 `m_p ≥ 0`；安全的 `(λ, 无源参数)` 联合选取。**安全靠几何，稳定靠能量。**

**定义 321–322（证书与干扰集）** J_TETHER 并入血缘根、时效分位、U_mw 元组、因果年龄、参照有效性、权威日志、k(a)、无源裕度、路径多样性、活性见证。ℰ_TETHER = ℰ_FLUID × ℰ_mw（重放/降级/时钟/漂移/冒充/假独立）× ℰ_teleop（时延攻击/能量注入/幽灵操作者/死手旁路）。

**定义 323–324（TID 与 NEL）** 传输独立 = 时钟/变换/血缘/模态四者两两不相交；融合包不声明组成源则按单源处理。阴性断言需活性 + 覆盖 + 有效期内，否则只能「unknown」。

**定义 325–327（修复/四通道/包含）** 证据 fresh→aging→expired，修复本身是带 VoI 的信息动作，失败即作废。U_ale→λ；U_epi→本地交互；U_mw→修通道；U_op→告知/重分配。理想通道 + 全知操作者时严格退化为 FLUID，VoI≤成本再退化为 CALM。

# IP-264 MPL：证据摄入与血缘（时间资格在此强制）
class MediationLedger:
    def ingest(self, now):
        out = []
        for e in self.bus.drain():
            e.age_wall   = now - e.tau_src_wall
            e.age_causal = self.causal_clock.now() - e.tau_src_causal
            e.valid      = (e.age_wall  <= self.L_qos(e)
                            and e.age_causal <= self.L_dyn(e)
                            and self.verify_chain(e))       # tf/schema/sig
            self.hashchain.append(e)                         # 只追加
            if e.valid: out.append(e)
        return out

# IP-265 STC：U_mw 四分解（分别门控，不可加和）
def assess_transport(E, now):
    return (max(pred_error(now - e.tau_src_wall) for e in E),   # stale
            max(transform_distortion(e.frame_chain) for e in E),# sem
            max(1.0 - trust(e.src, e.sig) for e in E),          # prov
            1.0 - coverage(E))                                  # comp

# IP-266 TSE：证据越老，认证前缀越短（λ 只是特例）
def certified_horizon(a_wall, a_causal, L, S, eps_pred, eps_sem, d_act):
    a = max(a_wall, a_causal)
    S_tau = erode(S, L*(a + d_act) + eps_pred + eps_sem)
    k = 0
    while k < K_MAX and tube_in(prefix(k), S_tau): k += 1
    return max(k - 1, 0), S_tau          # k=0 ⇒ 必须停下重看

# IP-267/268 AVoI + QAA：期限 × 参照物 × 去回声；静止换信息
def choose_interaction(modes, o, H, budget):
    best = (None, 0.0)
    for g in info_action_candidates(modes):
        d = expected_round_trip(g)
        for w in hold_grid:                        # 0, d/2, d, ...
            if not safe_hold(o, w) or not budget.allow(g, w): continue
            Hw  = H + w
            rho = 1.0                              # 停住 ⇒ 参照物不漂
            voi = (mutual_info(mode_identity, g) * rho * (1 - rho_echo)
                   if d <= Hw else 0.0) - cost(g) - c_hold(w)
            if voi > best[1]: best = (g, w)
    return best if best[1] > 0 else (None, 0)

# IP-269 OAM：操作者 = 延迟、相关、有限的证据源
def operator_evidence(y, shared_feed, b_op):
    kappa = complementarity(y, shared_feed)        # I(y;M|o_robot)
    U_op  = situation_awareness_uncertainty(b_op, shared_feed.age)
    return update_posterior(y, weight=kappa, meta_unc=U_op)

# IP-270 EWA：权威随证据走，投影回本地安全集
def arbitrate(a_h, a_auto, cred_h, cred_a, U_mw, U_op):
    if U_mw.high or U_op.high: return local_safe_hold()
    alpha = sigmoid(cred_h - cred_a)
    return project_to_local_safe_set(alpha*a_h + (1-alpha)*a_auto)

# IP-276 主闭环（继承 FLUID，插入证据资格 / 时域 / 权威 / 无源）
def TETHER_RAS_round(M, now):
    E = M.mpl.ingest(now)
    U_stale, U_sem, U_prov, U_comp = M.stc.assess_transport(E, now)
    if max(U_stale, U_prov) > TAU_MW:
        E = M.mpl.repair_or_wait(E, deadline(now))
        if max(U_stale, U_prov) > TAU_MW:
            return M.local_hold('transport')            # 证据作废
    o = align_to_now(E, now)
    U_ale, U_epi, modes = M.flu.forward(o)              # R69 层
    g, w = M.qaa.choose_interaction(modes, o, decision_deadline(M), M.budget)
    if w > 0: M.hold(w)                                 # 静止换信息
    if g is not None:

    k, S_tau = M.tse.certified_horizon(max(e.age for e in E), ..., M.safety.S)
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + unresolved(U_epi)))
    cmd = M.policy.prefix_dispatch(modes, k) * lam
    cmd = M.ewa.arbitrate(M.human_cmd, cmd, ...)
    cmd = M.pcl.project(cmd, M.delay_stats)
    M.ledger.commit(cmd)
    return cmd, J_TETHER(...)

## 4. 推导

**引理 19（相关路径不可加）** 两条以上路径共享时钟/变换/发布者 ⇒ 共享偏置 b，任意加权平均误差 → b²（k→∞），不随消息条数消失；故 n_eff 必须按传输独立性计。融合节点隐去相关性会伪造「干净的第二意见」。

**引理 20（标量 λ 不足）** 证据年龄 a 导致预测误差下界 `e(a) ≥ L·a − δ`。若 `e(a) > m`（安全裕度），再小的 λ 也无法撤销已积累的偏差或补偿执行延迟；必须缩短认证前缀 k(a)，k=0 时停止。λ 只是 k 固定时的特例。

**引理 21（AVoI 期限单调性与静止换信息）** VoI_act 关于 d 单调不增，d>H 时为 0；安全保持可把 H→H+w、ρ̄→1，仅当增益 > c_hold(w) 时值得停下来问。停不住时应本地保守，而非问一个关于过去的问题。

**引理 22（权威仲裁安全性）** EWA 先混合再投影回 𝒮_local，停止无条件、死手独立于通道 ⇒ 对任意远程指令与任意 α，闭环状态仍在 𝒮_local 内。故权威仲裁不增加物理风险，只影响任务性能；**安全不需要信任人，信任只影响效率。**

**定理 18（严格包含）** 理想通道 + 全知操作者 ⇒ U_mw=U_op=0、AVoI→VoI、k(a)→常规前缀、EWA→R69 决策、NEL 恒真 ⇒ 证书与动作逐条等价 FLUID；VoI≤成本 ⇒ CALM。TETHER 只新增「证据作废/本地保持」两种收缩，安全永不更弱。

**定理 19（安全—稳定分离）** TSE 保证状态管道落在 𝒮_τ（几何安全），PCL 保证通道能量非增（闭环稳定）；二者约束不同对象，可独立验证。故「不确定就同时收紧一切」是过度耦合：安全靠时域几何，稳定靠能量，效率靠 AVoI。

**定理 20（中介故障可检出性边界）** 血缘哈希链完整 + 至少一条传输独立副路径 ⇒ 单点语义故障在公共坐标比较中产生超噪残差，可检出；单路径 ⇒ 系统性变换错误与真实物理偏移观测等价，不可检出。系：**签名证明「谁说的」，证明不了「变换在物理上对不对」；语义正确性必须由物理锚点或独立路径接地。**

## 7. 本轮最大风险

**一句话**：TETHER-RAS 的全部安全论证都建立在「中间件自报的血缘、时钟与 QoS 元数据是诚实的」之上——**但签名只能证明「谁说了这句话」，证明不了「这个坐标变换在物理上是对的」；一条始终如一、签名完整、哈希链自洽的错变换，会把整个证书变成一份盖了章的谎言，而单路径系统在观测上根本无法把它与真实物理偏移区分开。** 最危险的不是掉包，而是**一个从不改口、且被认证过的错**。

**次级风险与缓解**：元数据撒谎（硬件时间戳 + 传输独立路径 + 往返测距，拒绝单路径认证）；操作者回声/共谋（OAM 估 κ，要求独立视角或物理见证）；过度保持致任务停滞（有界保持 + 分阶段重观测 + 保持成本入 AVoI）；时延下的人—机振荡（PCL + 定理 19 分离）；权威仲裁被博弈（日志上链、停止无条件、责任绑证书）；沉默被当同意（NEL 强制活性见证，无见证即 unknown）。
