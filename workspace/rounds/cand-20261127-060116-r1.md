## 1. 直觉与动机（三个灵感的碰撞）

**灵感 1（强化学习训练 → 这道题有奖励函数，但没有可交互环境；于是 RL 的产物不是策略，而是数据）**
直觉：官方步骤分（F17/F20）本质是一个**稠密化的势函数奖励**：每达成一个得分点，分数单调上升，满分 100。RL 的本能是「直接优化奖励」，但这里没有可反复试错的真机环境——评测 320 次是终局考，不是训练场。于是只剩两条路：(a) 在仿真/世界模型里 RL；(b) 把 RL 降级为**离线数据选择**。而高自由度人形 + 稀疏奖励 + 从零探索在仿真里也不现实（sim 资产未对齐、分辨率低）。所以本轮的核心判断是：**RL 在这场比赛里的最小可行形态，不是「从零学一个新策略」，而是「在强 BC 先验的示教流形上，用奖励给轨迹重新加权/筛选」**——即 advantage-weighted BC / filtered BC，而非 PPO 式探索。反直觉点：**RL 训练在这里的主要产出是「哪条合成轨迹值得模仿」，不是「一个会探索的智能体」。**

**灵感 2（虚实迁移 → 缺口的价值不均匀：仿真不该补「量」，该补「失败流形」）**
直觉：真机示教全是成功轨迹（P8），策略从没见过「抓偏了之后怎么救」。仿真/世界模型的最大价值不是再造 32k 条标称数据（那只会放大视觉 gap），而是**在真机数据永远到不了的失败态附近生成反事实轨迹**：把物体推偏 2cm、把抓取点错开 1cm、把插头偏转 15°，然后看哪种修正能回到得分点。这正是 I5 想要的「偏离→修正」示教，但 I5 之前只能靠手工扰动，缺少**自动判优器**——RL 的 advantage 正好补上。同时，sim-to-real 的缺口是**各向异性**的：背景/纹理可随机化（便宜），动力学/接触/延迟才是杀手（贵），人为干扰根本不可仿真。所以正确姿势是：**先量缺口，再按任务分配仿真预算；刚性接触任务多用，可变形物体（毛巾/袋子/玩偶）不用。** 反直觉点：**仿真数据的正确 KPI 不是「像真机」，而是「覆盖真机数据没有的失败态，且不引入新的动力学偏置」。**

**灵感 3（与第 2 轮数据引擎的合流 → 数据引擎缺一个「质量判官」，RL+sim 正好是它）**
直觉：第 2 轮把胜负手押在数据引擎（I2/I5），但留下一个空洞：合成示教的「好坏」靠里程碑检测器硬过滤（I5），没有利用「同一初始态下多条轨迹的相对优劣」。RL 提供**相对优势**（同一扰动下，哪条恢复更好），sim/世界模型提供**反事实初始态**，两者相乘就是一台**失败态数据飞轮**：真机示教 → 训练 BC + 世界模型 → 在仿真里对扰动初始态 rollout → 用得分点势函数判优 → 优势加权回炉 → 真机 L2 抽测。反直觉点：**I5 负责「造数据」，I10 负责「选数据」，I11 负责「验数据」；三者不是三个模块，而是一条流水线的三个工位。**

**三者统一**：RL 训练回答「如何用奖励给合成数据排序」，虚实迁移回答「哪些任务/哪些轴值得用仿真补」，第 2 轮的数据引擎回答「数据如何进模型」。本轮结论：**中期胜负手仍是数据引擎，但引擎的下一级放大器是「奖励判优 + 仿真反事实」；不做这两件事，数据引擎只能造标称数据的复制品。**

## 2. 严谨定义（先直觉，后形式化）

### 2.1 把赛题写成 MDP

对任务 t，定义 M_t = (S, A, P_t, r_t, γ, H)：

- 状态 s = (o, h)，o 为 4 路相机 + 本体感觉 + 语言指令，h 为历史栈（`obs_delta_indices`，F18）；
- 动作 a 为一个 chunk（长度 T_a，`ee` 或 `joint`，F18）；
- 时域 H = 180s × 15Hz ≈ 2,700 步（F12/F20）；
- 奖励 r_t 由官方得分点定义。令 Φ_t(s) ∈ [0,100] 为「当前状态已达成得分点的累计分」，则

  r_t(s, s') = Φ_t(s') − Φ_t(s)。

这是**势函数奖励塑形**（potential-based shaping）：不改变最优策略集合，只改变学习信号密度。其价值在于：即使 Φ̂ 有误差，塑形本身不引入「刷分」激励；误差只通过 Φ̂ 的偏差进入。

- 关键性质：因为奖励是势差，**一条轨迹的回报可望远镜化为终态势**：

  R_t = Σ_{k=t}^{T} γ^{k−t} r_k ≈ Φ_t(s_T) − Φ_t(s_t)（γ=1 时精确）。

于是「长程信用分配」退化为「终态进度比较」——这正是离线判优可行的根本原因。

### 2.2 离线 RL 的最小形式：优势加权行为克隆（AWBC）

设 π_BC 为第 2 轮的 SFT/流匹配策略。我们不解从零 RL，而解 KL 正则化问题：

  max_θ  E_{s~d^{π_θ}}[Φ̂_t(s)] − β · KL(π_θ(·|s) ‖ π_BC(·|s))。

其最优解为 π*(a|s) ∝ π_BC(a|s) · exp(Q*(s,a)/β)。用 AWR/MARWIL 的等价回归形式：

  L(θ) = − E_{(s,a)~D}[ w(s,a) · log π_θ(a|s) ],  w = clip(exp(Â(s,a)/β), 0, w_max)。

其中 D = 真机示教 ∪ 仿真/世界模型的反事实 rollout；Â(s,a) ≈ Φ̂(s_T) − V̂(s)（V̂ 可用 π_BC 的期望终态势回归，或直接用 Φ̂(s) 作势基线）。

**为什么这是「RL 而非 SFT」**：SFT 对所有 (s,a) 等权；AWBC 按「同一初始态下相对终态进度」重加权，等价于在示教支撑集内做一步策略改进。**为什么不会跑飞**：KL 项把策略钉在 π_BC 的支撑集上；仿真只负责「在支撑集附近生成反事实状态」，不负责「发现全新动作」。

### 2.3 虚实缺口的形式化与「仿真有用度」

令真实动力学 P、仿真动力学 P_ξ（ξ = 摩擦/质量/延迟/相机外参等低维参数）。定义：

- 观测缺口 d_obs = 真实/仿真在冻结视觉特征上的可分性（域分类器 AUC 或代理 A-distance）；
- 动力学缺口 d_dyn = sup_{s,a} W_1(P(·|s,a), P_ξ(·|s,a))；
- 任务缺口 d_task = 仿真资产与真机物体在可供性（affordance）上的差异。

单任务仿真有用度定义为

  U_t = c_t · (1/n_t) · (1 − ĝ_t) · a_t，

其中 c_t 为接触丰富度，n_t 为真机示教条数（稀缺性），ĝ_t 为综合缺口估计，a_t 为仿真资产可用度。

**分配律**：仿真预算 ∝ U_t；且**只把仿真用于「失败态补全」，不用于「标称态扩容」**。这条律可被 E5 直接证伪（若高 U_t 任务的 ΔJ_real ≤ 0，则 I11 降级为纯诊断工具）。

### 2.4 奖励可证伪性（PR6 的形式化）

任何自建奖励 r̂ 在使用前必须通过「与官方步骤分的一致性检验」：

  κ_t = Spearman( Φ̂_t 在留出真机轨迹上的排序, 官方步骤分排序 )。

仅当 κ_t > 0.7（且成功/失败分类 AUC > 0.9）才允许进入 I10 训练；否则该任务的 RL 分支关闭，退回 I5 的硬过滤。**这是把「奖励黑客」从工程风险升级为可测门槛。**

## 3. 对第 2 轮痛点的增量修订

- P1（弱任务拖平均）补充：I10 的 advantage 天然把训练信号集中到「同一初始态下可改进」的弱任务/弱阶段，是对 I2 质量加权的策略侧补充。
- P4（无触觉）补充：仿真接触段可提供「接触力导致滑移」的反事实视觉（仅刚性物体），但**不可替代触觉**；I3 仍是主缓解。
- P5（时间压力）补充：势函数奖励使长程信用分配退化为终态比较，降低 I5 进度头的建模难度。
- P8（示教质量）补充：从「静态质量分」升级为「相对优势分」——同一扰动下更优的恢复轨迹获得更高权重。
- 新增 P9（奖励错配）：自建 Φ̂/里程碑检测器可能与官方步骤分不一致，RL 会放大该误差（reward hacking）。
- 新增 P10（仿真缺口各向异性）：盲目全量仿真共训可能在视觉/动力学上引入负迁移，尤其是可变形物体与低分辨率世界模型。

### I1 考纲校准五轴增广引擎 ★★★★★（维持 v2）

## 1. 关键推导与伪代码

### 1.1 为什么势函数奖励适合本赛题

官方步骤分是「达成得分点则加分」的单调过程。令 Φ_t(s) 为累计分，则 r_t = Φ_t(s') − Φ_t(s) 是势函数塑形。由 Ng et al. (1999) 的结论：势函数塑形不改变最优策略集合，只改变值函数的起点。因此：

- **好处**：即使 Φ̂ 不完美，塑形不会制造「刷分」激励；误差只体现为 Φ̂ 的偏差，可通过 PR6 的 κ_t 度量。
- **好处**：γ=1 时回报望远镜化 R_t = Φ_t(s_T) − Φ_t(s_t)，长程信用分配退化为「终态分数比较」。
- **代价**：若 Φ̂ 系统性高估某些「看起来像达成」的状态，策略会朝这些状态偏移——这正是 I10 的最大风险，必须用真实步骤分做一致性门禁。

### 1.2 AWBC 目标与「为什么不跑飞」

KL 正则化问题的最优解 π*(a|s) ∝ π_BC(a|s)·exp(Q*(s,a)/β)。当 β→0 时退化为贪婪；当 β→∞ 时退化为 π_BC。AWR 的回归形式是对该解的离线近似：

```
L(θ) = - E_{(s,a)~D}[ w(s,a) * log π_θ(a|s) ]
w(s,a) = clip( exp( (Φ̂(s_T) - V̂(s)) / β ), 0, w_max )
```

三点保证：

1. **支撑集约束**：π_θ 只在 D 中出现过的 (s,a) 上被拉高，不会凭空生成 OOD 动作；
2. **信任域**：KL 项（或 w_max 截断）限制单步改进幅度；
3. **保守判优**：用 advantage 的置信下界（多 Φ̂ 集成的最小值）而非均值，避免被单个检测器的乐观误差带偏。

### 1.3 缺口计与 U_t 的可证伪性

U_t 是一个**可被真机证伪的预测器**，不是解释性指标。E1 先验证：在已有真机结果的 3–4 个任务上，Spearman(U_t, ΔJ_real) 是否 >0.6；若不过，I11 只保留「缺口诊断」功能，不参与数据配比。这样避免「用未经验证的缺口计给仿真加权」的循环论证。

```python
# ---------- 势函数奖励（I5 提供检测器，I10 使用） ----------
def potential(obs, task):
    # 每任务一组里程碑检测器；返回累计得分点（0..100）
    return sum(w * milestone[task][m].score(obs)
               for m, w in SCORING_STEPS[task].items())

# ---------- 反事实生成 + 短程 rollout + 判优（I5 + I7/I11 + I10） ----------
def generate_counterfactuals(real_eps, policy_bc, env, K=8, horizon=60):
    samples = []
    for s0 in real_eps.initial_states:          # 真机初始态
        for _ in range(K):
            s0p = perturb(s0, syllabus_card[task])   # I1 考纲卡采样
            traj = env.rollout(policy_bc, s0p, horizon)   # WMA-0 / Isaac Lab
            if not physically_plausible(traj): continue
            phi_T = potential(traj.terminal_obs, task)
            samples.append((s0p, traj, phi_T))
    return samples

# ---------- 优势加权 BC（I10） ----------
def awbc_finetune(policy, D_real, D_syn, phi_ensemble, beta=0.1, w_max=10.0):
    # V̂：用 π_BC 的期望终态势回归（离线，一次拟合）
    V = fit_value_head(D_real + D_syn, phi_ensemble)
    for s, a, traj in loader(D_real + D_syn):
        phi_T = min(head(traj) for head in phi_ensemble)   # 保守下界
        adv = phi_T - V(s)
        w = clamp(exp(adv / beta), 0.0, w_max)
        loss = -w * policy.log_prob(a, s) + KL(policy, policy_bc_ref)
        update(policy, loss)
    return policy

# ---------- 缺口计 + 系统辨识 + 选择性仿真（I11） ----------
def sim_usefulness(task, real_eps, sim_env):
    g_obs = domain_gap(features(real_eps.obs), features(sim_env.obs))   # A-distance
    xi_star, g_dyn = system_id(sim_env, real_eps, params=XI_SPACE)      # CMA-ES
    c = contact_richness(task)
    n = len(real_eps)
    a = sim_asset_availability(task)
    return c * (1.0 / n) * (1.0 - g_obs) * (1.0 - g_dyn) * a

def allocate_sim(tasks):
    U = {t: sim_usefulness(t, REAL[t], SIM[t]) for t in RIGID_CONTACT_TASKS}
    budget = {t: min(0.25 * len(REAL[t]), U[t] / sum(U.values()) * SIM_TOTAL)
              for t in U}
    return budget   # 只生成失败态/接触段，不做标称态扩容

# ---------- 部署侧（不变）：唯一确定性策略，无探索 ----------
class PolicyService:
    def reset(self): self._state = {}          # 每端口/每 episode 隔离（F22）
    def get_action(self, obs):                 # 无采样噪声、无在线更新
        return self.policy.deterministic_chunk(obs)
```

## 2. 实验设计（分级消融 + 证伪协议）

### 2.1 六个实验

| 编号 | 假设 | 设计 | 代理/主指标 | 通过判据 |
|---|---|---|---|---|
| E1 | 缺口计能预测仿真迁移 | 3–4 个已有真机点的任务上算 ĝ_t/U_t，与 ΔJ_real 排序 | Spearman | >0.6 才让 I11 参与配比 |
| E2 | 系统辨识能缩小 sim-real 轨迹误差 | 留出真机轨迹，比较辨识前/后 sim 预测误差 | 轨迹 ADE / 接触段误差 | 误差下降 >30% |
| E3 | Φ̂ 与官方步骤分一致 | 留出真机轨迹，Φ̂ 排序 vs 官方分；成功分类 | κ_t、AUC | κ_t>0.7 且 AUC>0.9 才开 I10 |
| E4 | RL 有边际价值 | 同预算：SFT / 硬过滤 BC / best-of-N 蒸馏 / AWBC | L0 终态 Φ̂ + 动作一致性；L2 步骤分 | AWBC−硬过滤 >1 分，否则砍 RL |
| E5 | 仿真配比有正迁移 | 3 刚性任务，sim 比例 {0,10%,25%}，各 2 seed | L0 Δprog；L2 ΔJ_real | 任一任务负迁移 >1 分即砍该任务仿真 |
| E6 | 飞轮整体有效 | 全流水线 vs 无 I10/I11 基线 | L2 成功率 + 步骤分 | 相对基线 ≥+3 分才放量 |

### 2.2 分级消融（L0/L1/L2）

| 级别 | 内容 | 通道/成本 | 通过判据 |
|---|---|---|---|
| L0 | I1 各轴剂量；I2 四源配比；I5 合成质量；I9 先验；I10 advantage 分布；I11 缺口计 | 离线（免费） | 各模块 Δprog≥0 且无家族退步 |
| L1 | 2^(k-p)：增广 4 轴、四源开关、AWBC on/off、sim 比例 | 离线 + 少量真机 | 主效应显著的 ≤3 组合进 L2 |
| L2 | top 组合真机确认：≥2 任务 × 各 2 次 | 单任务通道 | 真机增益 ≥ 离线预测 50% |
| 门禁 | PR4：run_client 全流程 + p99 + 动作健康度 | 本地 stub | 0 拒绝动作、p99<40ms |

### 2.3 裁撤/止损判据（falsification gates）

- **PR6 未过**（κ_t≤0.7 或 AUC≤0.9）：该任务关闭 I10，退回 I5 硬过滤。
- **E1 未过**（Spearman≤0.6）：I11 降级为诊断工具，不参与数据配比。
- **E4 未过**（AWBC 相对硬过滤 ≤1 分）：砍掉 RL 组件，保留「生成-过滤」。
- **E5 出现负迁移**（任一任务 >1 分）：该任务仿真数据清零；同族任务降权。
- **E2 未过**（轨迹误差下降 <30%）：系统辨识只做可视化，不做 DR 中心。
