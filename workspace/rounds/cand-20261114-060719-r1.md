# 第 73 轮（承接第 72 轮「EMBODIED-GAUGE-RAS 具身计量审计闭环」IP-287~294；灵感循环第 1 轮；本轮灵感：「演示方案」×「MuJoCo」）

> R72 把安全从「认知层算法」下沉到「具身实时闭环」：REG 调度契约、IRL 意图隐变量、DMEM 接触四分量、EREFLEX 三层反作用、S2R-UQ 残差桥接，并用 J_EMB 把「控制环时序 + 意图 + 接触 + 参数不确定度」全部盖进一张证书。但 R72 有一个**从未被当作研究对象**的缺口：
>
> **R72 的所有定理都只是在说「如果系统按证书运行，则风险有界」；它没有回答「你拿什么向一个怀疑者证明这一点」。** 论文里的 demo 仍被默认为工程附属品——一段视频、一组漂亮曲线、一次精心挑选的种子、一个「在我们实验室里能跑」的现场演示。**演示（demonstration）被当成修辞，而不是测量。**
>
> 「演示方案」这个灵感词要求我们把 demo 本身当成**可审计的测量程序**：它必须声明**被测量是什么**（claim，而不是「我们的系统很稳」）、**定义域是什么**（哪些物体/摩擦/光照/人/故障）、**仪器是什么**（MuJoCo 的哪套接触模型与求解器参数）、**不确定度是多少**（仿真数值误差 + 场景采样误差 + 策略过拟合误差 + sim2real 残差）、**什么结果会证伪它**（预先注册的接受谓词与反例集）、以及**它能否被独立复现**。
>
> 「MuJoCo」这个灵感词则要求我们承认一个更硬的事实：**MuJoCo 不是「现实」，它是一台有系统误差的仪器。** 它的软接触 `solref/solimp`、锥近似 `cone=pyramidal/elliptic`、`impratio`、积分器与步长 `timestep`、`iterations`、`margin` 都不是物理真理，而是**测量模型的选择**。把 `timeconst` 调小可以让穿透变小、把 `cone` 从 pyramidal 换成 elliptic 可以让滑移晚发生、把 `timestep` 调小可以让接触事件更「准时」——**同一个机器人、同一段轨迹，可以因为仪器参数不同而得到相反的结论。** 于是 **MuJoCo 的仿真参数必须像真实传感器一样带标定与不确定度预算**，否则「在 MuJoCo 里通过了」只是一句关于 MuJoCo 的话，不是一句关于机器人的话。
>
> 本轮的核心位移：**从「我的系统能不能跑通一个 demo」转向「这个 demo 本身是不是一次可审计、可反驳、可复现、可迁移的测量」**。把 R72 的「具身计量审计」再下沉一层，得到 **DEMO-GAUGE-RAS**（Demonstration-Evidence Metrology & Operational Governance for Embodied, Auditable RAS）——**演示计量学**。
>
> 一句话：**claim 是被测量，场景是采样方案，MuJoCo 是仪器，证书是校准报告，反例是测量必须能够失败的方式。**

## 0. 直觉与动机

**灵感 1（演示方案 → demo 是测量程序，不是营销动作）**

直觉：计量学里，一个测量结果若没有 `(measurand, method, instrument, uncertainty, traceability)` 五要素，就不是结果，只是读数。今天的机器人 demo 恰恰只有「读数」：一段成功视频、一条成功率曲线、一次现场表演。它缺的正是这五要素——

- **measurand（被测量）**：不是「系统表现」，而是一个可判定真假的 claim：例如「在摩擦系数 μ∈[0.2,0.8]、物体质量 m∈[0.1,2]kg、意图后验熵 H[z]≤τ 的域内，峰值夹持力 ≤ F_max 且滑移位移 ≤ 2mm」。
- **method（方法）**：不是「跑一下」，而是**预先注册**的场景分布、种子、故障注入表、接受谓词。
- **instrument（仪器）**：MuJoCo 模型 + **带版本的配置**（timestep、solref、solimp、cone、impratio、integrator、iterations）。
- **uncertainty（不确定度）**：仿真数值 + 场景采样 + 策略选择 + sim2real 残差，四项缺一不可。
- **traceability（溯源）**：从 claim 到场景到种子到遥测哈希到 replay 的完整链。

直觉结论：**没有「会失败的方式」的 demo 不是证据，只是存在性演示。** 一个只在标称场景里成功 100 次的 demo，和「我在草稿纸上构造了一个解」在证据等级上没有本质区别——它只证明了「存在一条成功轨迹」，没有证明「在声明的域内安全」。

**灵感 2（MuJoCo → 仿真器是有系统误差的仪器，不是真理）**

直觉：真实实验里，换一把卡尺要重标；仿真里，换一个接触模型却常常被当成「同样的物理」。这是错的。MuJoCo 的接触是**软约束 + 互补性求解**：`solref=(timeconst, dampratio)` 决定接触的等效刚度与阻尼；`timeconst` 越小，接触越硬、穿透越小、但也越容易数值爆炸；`solimp` 控制阻抗随穿透的非线性上升；`cone` 决定摩擦锥是金字塔还是椭圆；`impratio` 改变摩擦锥阻抗；`timestep` 决定事件分辨率；`iterations` 决定求解器收敛程度。

这些参数不是「实现细节」，而是**测量模型的一部分**：

- 把 `timeconst` 从 0.02 调到 0.01，等效刚度约变为 4 倍，同样夹持力下穿透约变为 1/4——**「滑移是否发生」的判据被仪器参数改变了**。
- 把 `cone` 从 pyramidal 换成 elliptic，法向/切向耦合被改变，**同样的抓取在金字塔锥下可能「更不容易滑」**。
- 把 `timestep` 从 2ms 调到 0.5ms，接触事件的相位变了，**峰值力与滑移检出延迟都会变**。

所以「MuJoCo 里没滑」不是结论，**「在某组 (timestep, solref, solimp, cone, impratio, iterations, margin) 下没滑，且这些参数的不确定度传播后仍不滑」才是结论**。这就是 MuJoCo 的**仪器不确定度预算（MJ-UQ）**。

**灵感 3（演示 × 仿真 → coverage 与 power 才是 demo 的两个硬指标）**

直觉：demo 的常见话术是「我们跑了 N=1000 次，成功率 98%」。这句话在统计上几乎无信息，除非同时回答两个问题：

1. **覆盖（coverage）**：这 1000 次落在声明定义域的哪里？如果全部落在「μ=0.6、m=0.5kg、无遮挡、意图明确」的中心，那它只覆盖了定义域的一个小邻域，**边缘与角落（μ=0.2、m=2kg、虚晃意图、接触滑动）可能一次都没测到**。
2. **功效（power）**：如果系统真的在某个子域上违反了 claim（违反幅度 ≥ ε），这 1000 次以多大概率能把它抓出来？如果场景采样在违反集上测度为零，**功效就是 0——再多次也抓不到**。

因此 demo 的正确抽象不是「跑多少次」，而是**「场景套件是否是定义域的 ε-网 + 对违反集的统计功效是否足够」**。前者用覆盖几何度量，后者用假设检验/反例搜索度量。两者共同决定「这个 demo 能支持多大的 claim」。

**灵感 4（演示 × 反作用 → demo 本身会成为 Goodhart 目标，且会改变系统）**

直觉：R71/R72 已经建模了「机器人行为改变人」「控制改变接触」。演示又引入两层新的反作用：

- **L4 演示反作用（对内）**：团队为了让 demo 好看，会调参、挑种子、剪掉失败片段、在标称场景反复排练——**策略被过拟合到 demo 分布上**。这不是恶意，是激励的自然结果。于是「demo 成功率」上升，而「真实分布上的安全性」可能下降。这是**演示层面的 Goodhart**。
- **L5 演示反作用（对外）**：现场演示中，人看到机器人伸向自己会改变意图（R72 的 L2）；观众的存在改变人的配合度（R71 的 L1）；演示本身的重复会让人对风险脱敏（信任账户被透支）。

防御不是「要求大家诚实」，而是**结构性的**：**预注册（claim/接受谓词/种子在跑之前哈希锁定）+ 留出种子（训练/演示种子与验证种子分离）+ 多重比较校正 + 对抗性场景套件 + 独立 replay**。让「挑樱桃」在数学上无法提高证书置信度，而不是靠道德约束。

**灵感 5（演示 × 退化链 → 只演示成功，等于只演示了标称策略，没演示安全）**

直觉：R72 的安全论证有一半在**退化行为**上：时序熔断 → R68、意图失效 → 固定先验 + R71、接触失效 → 视觉/语言 + R71。**如果 demo 只展示「全模块正常时的漂亮抓取」，它就没有演示安全，只演示了性能。** 真正的安全 demo 必须包含**故障注入场景**：杀掉计量节点、堵住 `/cmd_torque`、注入虚假滑移、让意图识别 OOD，然后展示系统在 1 秒内**优雅降级**且不产生硬安全违规。**安全性是「坏情况下仍然有界」，所以安全 demo 的主角必须是坏情况。**

## 1. 形式化定义（增量：定义 366–380）

**定义 366（DEMO-GAUGE-RAS 总览）** DEMO-GAUGE-RAS = (DPC, MJUQ, FALS, COVA, REPRO, T2R, DDEBT, DEGR-DEMO, J_DEMO)。六不变式：
(i) **claim 可测量**：每个进入 demo 的 claim 必须写成 (谓词 φ, 定义域 D, 容差 ε, 置信度 1−δ, 作用域 scope)，不可测量者只能叫「叙事」，不能进证书；
(ii) **仪器有标定**：所有 MuJoCo 结果必须携带 MJ-UQ 预算与配置哈希，缺一不可进 claim 推断；
(iii) **反例优先**：场景套件必须包含对抗/角落/故障场景，并报告对违反集的功效 β(ε)，只报标称成功率的 demo 视为无效证据；
(iv) **覆盖可核算**：必须报告覆盖 κ 与 demo-claim gap g=1−κ，以及 ε-网半径；域外不产生 claim；
(v) **预注册与复现**：claim、接受谓词、场景分布、种子在运行前提交哈希；验证用留出种子；独立 replay 必须通过；
(vi) **作用域不膨胀**：sim 证据只能支持 sim claim；要支持 real claim，必须经 T2R（S2R-UQ）桥接并给出迁移有效度 TV，否则证书无效。

**定义 367（claim 对象）** claim C = (φ, D, ε, δ, scope, τ)，其中：
- φ: Ξ → {0,1} 为轨迹谓词（如「∀t: 峰值接触力 ≤ F_max ∧ 滑移位移 ≤ s_max ∧ 不进入人体包络」）；
- D = D_robot × D_object × D_env × D_human ⊆ 𝒳 × 𝒰 × 𝒲 为声明定义域（含摩擦/质量/位姿/光照/意图分布/故障率）；
- ε 为可容忍违反幅度，δ 为允许的证书错误率，1−δ 为置信度；
- scope ∈ {sim, real, mixed}；
- τ 为时间窗与采样分辨率。
称 C **可测量**，若存在场景套件 S 与运行时监控器 m，使得 supp(S) 构成 D 的有限 ε-网且 m 能逐轨迹判定 φ。不可测量者称**叙事 claim**，不得写入 J_DEMO。

**定义 368（演示方案 / Demonstration Plan）** DP = (C, S, M, ρ, Π, A, R, J)，其中：
- C 为 claim（定义 367）；
- S = (S_nom, S_corner, S_adv, S_fault) 为分层场景套件（标称/角落/对抗/故障），带混合权重 w；
- M = (MJCF 模型, MuJoCo 版本, 配置 θ_MJ, MJ-UQ 预算) 为仪器；
- ρ = (ρ_train, ρ_test) 为预注册种子向量（训练/留出分离）；
- Π 为演示协议（策略、控制器、故障注入时间表、人因脚本）；
- A 为接受谓词（含违反幅度 ε、置信度 δ、多重比较校正方式）；
- R 为复现包（代码提交、MJCF 哈希、平台指纹、种子承诺、遥测哈希、replay 容差）；
- J 为演示证书（定义 376）。
**DP 是一次测量，不是一次表演。**

**定义 369（MuJoCo 测量模型）** 仿真状态转移记为
x_{t+1} = f_MJ(x_t, u_t; θ_MJ) + η_t,
θ_MJ = (h, integrator, solref, solimp, cone, impratio, iterations, jacobian, margin)，
η_t 为数值扰动（浮点舍入、求解器未收敛、接触事件相位抖动）。观测 y_t = g(x_t) + ν_t。claim 谓词在仿真轨迹上求值：φ_MJ = φ(ξ_MJ(θ_MJ, ρ))。
**关键**：θ_MJ 是测量模型参数，不是物理真值；改变 θ_MJ 会改变 φ_MJ。

**定义 370（MuJoCo 不确定度预算 MJ-UQ）** 将 claim 的仿真不确定度分解为
u_MJ² = u_disc² + u_contact² + u_solver² + u_act² + u_float²，
分别对应时间离散/积分误差、接触模型误差（solref/solimp/cone/impratio）、求解器收敛误差、执行器/传感模型误差、跨平台浮点误差。用灵敏度系数 S_i = |∂φ/∂θ_MJ,i| 传播：
u_claim² = Σ_i (S_i u_i)² + u_scen² + u_policy² + u_resid²，
其中 u_scen 为场景采样不确定度、u_policy 为策略在 demo 分布上的过拟合不确定度、u_resid 为 sim2real 残差（R72 S2R-UQ）。**任一 u_i 未报告，MJ-UQ 不完整，J_DEMO 无效。**

**定义 371（场景套件与反驳功效）** 设违反集 V_ε = {x ∈ D : φ 在 x 上被违反且违反幅度 ≥ ε}。场景套件 S 在 V_ε 上的可测度 q = μ_S(V_ε)。定义**反驳功效**
β_S(ε) = P_{x∼S}[ monitor 判定违反 | x ∈ V_ε ]。
若 q = 0，则 β_S(ε)=0——该套件对这类违反**原理上不可证伪**。称 S 为**反驳优先（falsification-first）**，若 S_adv ∪ S_fault 在 V_ε 上的测度不低于预设下限 q_min，且接受谓词包含「必须有反例尝试记录」。

**定义 372（覆盖、ε-网与 demo-claim gap）** 覆盖
κ(S, D) = μ(D ∩ supp(S)) / μ(D)，
gap g = 1−κ。更实用的是 ε-网覆盖：若 ∀x∈D, ∃s∈S: d(x,s) ≤ ε_net，则称 S 是 D 的 ε_net-网。若 φ 在 D 上 L-Lipschitz，则对 n 个样本的监控估计 φ̂ 有
sup_{x∈D} |φ̂(x) − φ(x)| ≤ L·ε_net + √(log(2/δ)/(2n))。
**含义**：demo 能支持的 claim 强度由「网半径 + 样本数」共同决定，而不是由「跑了多少次」单独决定。定义 **demo-claim gap** 为 D 中未被 S 的 ε_net-网覆盖部分的测度（按风险加权）。

**定义 373（复现与预注册证书）** REPRO = (code_hash, mjcf_hash, mj_version, platform_fingerprint, seed_commit, telemetry_hash, τ_replay)，并绑定 prereg_hash = H(C, A, S, ρ_train, δ)。**replay 等价**定义为两次独立运行的最大轨迹偏差
max_t ‖x_t^(1) − x_t^(2)‖ ≤ τ_replay。
跨平台浮点差异不是「bug 忽略」，而是 u_float 的一项，必须计入 MJ-UQ。**预注册先于运行**：prereg_hash 在首次仿真前写入且不可修改，否则证书无效。

**定义 374（演示-实机迁移有效度 T2R 与作用域膨胀）** 设实机轨迹与仿真轨迹的残差 Δ = ξ_real − ξ_sim ∼ P_Δ（由 R72 S2R-UQ 估计）。定义迁移有效度
TV(ε_transfer) = P_{Δ∼P_Δ}( |φ(ξ_sim+Δ) − φ(ξ_sim)| ≤ ε_transfer )。
若 scope=real 而 TV < 1−δ_transfer，则称发生**作用域膨胀（scope inflation）**：sim demo 至多支持「仿真中存在一条安全轨迹」，**不能支持「真机在 D 上安全」**。J_DEMO 必须拒绝作用域膨胀。

**定义 375（演示债务与多重比较账本）** 对 claim 集合 {C_i}，定义演示债务
D_debt = Σ_i w_i · (1 − κ_i) · (1 − β_i(ε_i)) · Risk_i，
即「既没覆盖、又没功效、且风险高」的 claim 质量。**债务不是靠多跑标称场景能还的，只能靠覆盖角落/对抗/故障来还。** 对 m 个场景-指标对，若取最好结果报告，必须做多重比较校正（Bonferroni δ/m，或 e-value/anytime-valid 推断）；未校正的「最佳 demo」不得进证书。

**定义 376（演示证书 J_DEMO）** J_DEMO = (claim_hash, suite_hash, mj_uq_budget, seed_commit, prereg_hash, coverage, power, repro_hash, transfer_validity, multiplicity_method, degradation_covered, ver)。
Valid(J_DEMO) ⇔
C 可测量 ∧ (scope∈{real,mixed} ⇒ 上游 J_EMB 有效) ∧ κ ≥ κ_min ∧ β(ε) ≥ β_min ∧ prereg_hash 匹配 ∧ seed_commit 匹配 ∧ replay 通过 ∧ 多重比较已校正 ∧ (scope=real ⇒ TV ≥ 1−δ_transfer) ∧ degradation_covered=1。
**域外、种外、仪器参数外，一律不产生 claim。**

**定义 377（演示威胁模型 ℰ_DEMO）** ℰ_DEMO = ℰ_claim × ℰ_scen × ℰ_sim × ℰ_stat × ℰ_scope：
- ℰ_claim = {事后改 claim（HARKing）、指标替换、把「不崩」写成「安全」}；
- ℰ_scen = {挑种子（seed lottery）、只采样中心、隐藏失败片段、训练/验证污染}；
- ℰ_sim = {调 solref/solimp 隐藏穿透、换 cone 让滑移晚发生、调 timestep 改事件相位、篡改 MJCF/模型}；
- ℰ_stat = {不做多重比较、只报均值不报 CVaR、用训练种子算置信度}；
- ℰ_scope = {把 sim demo 说成 real 结论、把单机器人说成多机器人、把短时程说成 24h}。
**每个威胁都必须有结构性对策，而不是「我们不会这么做」。**

**定义 378（退化演示契约 DEGR-DEMO）** 对每个含退化链的 claim，演示方案必须包含故障注入表 F = {(故障, 注入时刻, 期望降级, 最大恢复时间, 硬安全保持谓词)}，并验证：
(i) 任一单点故障后，系统在 τ_rec 内进入声明降级态（R71 或 R68）；
(ii) 降级期间硬安全包络与 λ_floor 仍成立；
(iii) 恢复后不出现「隐形状态回滚」（例如未重新验证就回到 FULL）。
**只演示 FULL 模式成功，视为安全 claim 未覆盖。**

**定义 379（演示报告 / Demo Report）** 一份人类可读的诚实报告 DR = (claim, 域, 仪器与 MJ-UQ, 场景表与种子, 覆盖与功效, 反例记录, 失败片段, 迁移有效度, 债务, 复现指令)。报告必须显式写出「**本 demo 不能支持什么**」。**没有「不能支持什么」的 demo 报告，按叙事处理。**

**定义 380（演示代数 / Demo Algebra）** 设两个演示 DP_A, DP_B 支持 C_A, C_B。定义合取组合 DP_A ⊕ DP_B：
- 支持的 claim 为 C_A ∧ C_B；
- 定义域为 D_A ∩ D_B；
- 覆盖 κ_⊕ ≤ min(κ_A, κ_B)（交集覆盖只会更小）；
- 反驳功效 β_⊕ 需在交集上重新估计，不能简单取 max；
- 若两 demo 共享同一仪器与同一批种子，其误差不独立，置信度不能相加。
**系**：不能通过「分别演示两个子 claim」自动得到「联合 claim」。**合取的覆盖是交，不是并。**

# IP-295 DPC：claim -> 预注册演示方案（离线，运行前）
@dataclass
class Claim:
    phi: Callable[[Trajectory], bool]
    domain: DomainSpec            # 摩擦/质量/位姿/意图/故障分布
    eps: float; delta: float      # 违反幅度 / 允许错误率
    scope: Literal['sim','real','mixed']
    risk_weight: float

def compile_demo_plan(C: Claim, robot, budget) -> DemoPlan:
    # 1) 定义域离散化：角落 + 分层网格 + 对抗子域
    D = discretize(C.domain, resolution=budget.grid)
    S_nom, S_corner = stratified_suite(D)
    S_adv  = adversarial_suite(D, C.phi, budget.adv_eps)   # 最大化预测违反
    S_fault= fault_suite(robot.degradation_chain)
    # 2) 预注册：claim/接受谓词/套件/训练种子在运行前锁定
    prereg = H(C, S_nom, S_corner, S_adv, S_fault, rho_train)

    M = mujoco_instrument(robot.mjcf, budget.mj_configs)

                    rho=(rho_train, rho_test), A=acceptance(C), 
                    prereg_hash=prereg, R=repro_bundle())

# IP-296 MJ-UQ：把 MuJoCo 当仪器，算仿真不确定度预算
def mujoco_uq(mjcf, theta_base, theta_priors, phi_mj, n_mc=256):
    # theta = (timestep, solref, solimp, cone, impratio, iterations, margin)
    u = {}
    u['disc']   = sensitivity(phi_mj, theta_base, 'timestep', theta_priors)
    u['contact']= sensitivity(phi_mj, theta_base, ('solref','solimp','cone','impratio'),
                              theta_priors)
    u['solver'] = sensitivity(phi_mj, theta_base, 'iterations', theta_priors)
    u['float']  = cross_platform_replay_spread(mjcf, n_mc)
    # 预算：各分量按 |dphi/dtheta| * u(theta) 传播
    return MJUQ(components=u, total=sqrt(sum(v**2 for v in u.values())),
                config_hash=H(mjcf, theta_base))

# IP-297 FALS：反驳优先套件 + 功效估计
def demo_power(S, phi, eps, monitor, n_test):
    # 在留出种子上估计：违反集上被判违反的概率
    hits = total = 0
    for x in sample(S, rho_test, n_test):
        if violation_magnitude(phi, x) >= eps:
            total += 1
            hits  += int(monitor(x) == 'violate')
    return BetaPosterior(hits, total).mean() if total else 0.0

# IP-298 COVA：覆盖与 ε-网 gap 核算
def coverage_gap(S, D, eps_net, risk_weights):
    if is_eps_net(S, D, eps_net):
        kappa = 1.0
    else:
        kappa = covered_measure(S, D) / measure(D)
    gap = sum(risk_weights[x] for x in D if not covered(S, x, eps_net))
    return Coverage(kappa=kappa, gap=gap, eps_net=eps_net)

# IP-299 REPRO：预注册 + 留出种子 + 独立 replay
def certify_repro(plan, telemetry_run1, telemetry_run2):
    ok_prereg = H(plan.C, plan.A, plan.S, plan.rho[0]) == plan.prereg_hash
    ok_seed   = commit(plan.rho) == plan.seed_commit
    ok_replay = max_traj_dev(telemetry_run1, telemetry_run2) <= plan.R.tau_replay
    return Reproducibility(prereg=ok_prereg, seed=ok_seed, replay=ok_replay,
                           float_uq=cross_platform_spread(telemetry_run1))

# IP-300 T2R：sim -> real 迁移有效度（消费 R72 S2R-UQ 残差）
def transfer_validity(claim, s2r_residual, eps_transfer):
    # 用 S2R-UQ 的残差分布做蒙特卡洛，而不是取均值
    sims = [phi_value(claim, traj + s2r_residual.sample()) for traj in replay_set]
    return TV = mean(|phi_real - phi_sim| <= eps_transfer for ...)

# IP-301 DDEBT：多重比较 + 演示债务账本
def demo_ledger(claims, demos, alpha):
    m = sum(len(d.metrics) for d in demos)
    alpha_corr = alpha / m                     # Bonferroni；或用 e-value 聚合
    debt = sum(c.risk_weight * (1 - d.coverage) * (1 - d.power)
               for c, d in zip(claims, demos))
    return Ledger(fwer=alpha_corr, debt=debt, m=m)

# IP-302 DEGR-DEMO：退化演示（主角是坏情况）
def run_degradation_demo(robot, fault_table, tau_rec=1.0):

        assert not mode.is_illegal_rollback()
        assert now() - t0 <= tau_rec

    prereg = commit(plan.prereg_hash)           # 运行前上链/写日志

## 3. 推导

**引理 33（种子抽奖与多重比较膨胀）** 设 m 个场景-指标对在零假设下各自以概率 δ 误报，若报告其中最好者且不做校正，则族错误率 FWER = 1−(1−δ)^m ≈ mδ；要保证 FWER ≤ δ，必须用 Bonferroni 阈值 δ/m（或 e-value 聚合）。系：**「我们挑了一个最好的种子」本身就是一次未校正的多重比较；不校正的 demo 证书没有统计意义。**

**引理 34（MuJoCo 接触参数敏感性界）** 在 MuJoCo 隐式软接触下，接触等效刚度近似 k ≈ m_eff/timeconst²（dampratio 固定时），同样法向力 F 下的稳态穿透 p ≈ F/k ∝ F·timeconst²/m_eff。于是
|Δp|/p ≤ 2|Δtimeconst|/timeconst + |ΔF|/F + |Δm_eff|/m_eff。
把 cone 从 pyramidal 换成 elliptic 等价于改变切向可行域的体积/各向异性，滑移起始的切向力阈值发生 O(1) 变化；timestep 变化改变接触事件相位，峰值力误差 O(h)。**结论：claim 对 θ_MJ 是 Lipschitz 的；MJ-UQ 不是可选项，而是 claim 误差的一阶来源。**

**引理 35（ε-网覆盖 ⇒ 均匀 claim 界）** 设 φ 在 D 上 L-Lipschitz，S 是 D 的 ε_net-网，n 个样本上的监控估计为 φ̂。则
sup_{x∈D} |φ̂(x) − φ(x)| ≤ L·ε_net + √(log(2/δ)/(2n))
（Hoeffding + 网覆盖）。系：**把覆盖从「跑了 N 次」改写为「网半径 ε_net 与样本数 n」，demo 的 claim 强度才可计算；仅增加中心样本而不减小 ε_net，界不会改善。**

**引理 36（反驳优先的功效支配）** 设违反集 V_ε 测度为正。若标称套件 S_nom 在 V_ε 上测度为 0，则 β_{S_nom}(ε)=0；若对抗套件 S_adv 在 V_ε 上测度 q>0，则 β_{S_adv}(ε) ≥ q·(1−β_monitor)，且期望检出样本数 E[N_detect] ≤ 1/(q·(1−β_monitor))。**系：只采样标称场景的 demo 对「角落违反」在原理上无功效；这不是样本量问题，是采样支撑问题。**

**定理 27（演示证书的域内可靠性）** 若 J_DEMO 有效，则 claim C 在覆盖域 D_κ（κ 覆盖部分）上以置信度 ≥1−δ 成立（容差 ε），且该结论**不能外推到 D_κ 之外**。证明：由定义 366/376，J_DEMO 绑定 claim、套件、MJ-UQ、预注册与多重比较；引理 35 给出覆盖域内的均匀界，引理 33 控制「挑最好」带来的膨胀；MJ-UQ（定义 370）把仪器误差计入 ε/δ；故在 D_κ 上成立。域外无覆盖，引理 35 不适用，故不可外推。**证书的边界就是覆盖的边界。**

**定理 28（没有免费 demo：不可证伪的 claim 无法被 demo 支持）** 若 claim 的违反集在演示套件的支撑上测度为零（q=0），则无论样本量多大，β_S(ε)=0，J_DEMO 不能给出任何关于该违反的保证。因此「安全」claim 必须附带**可证伪的违反集**与**在其上有正测度的套件**，否则它只是叙事。**证明**：由定义 371，违反事件在采样分布下是零概率事件；任何基于 S 的统计量都无法区分「无违反」与「未采样到违反」。系：**demo 的第一项设计任务不是选场景，而是先写出「什么会让我失败」。**

**定理 29（预注册 + 留出种子 ⇒ Goodhart 抗性）** 若 (i) claim、接受谓词、场景分布、训练种子在运行前被 prereg_hash 锁定；(ii) 置信度只在留出种子 ρ_test 上计算；(iii) 对 m 个指标做 δ/m 校正，则任何基于训练种子的挑参/挑场景策略，都不提高留出证书的虚假通过概率超过 δ。**证明**：训练阶段的任意自适应选择是对锁定种子的函数，不影响 ρ_test 上的样本独立性；留出评估的 FWER 由 Bonferroni 控制；故虚假通过概率 ≤ δ。系：**反 Goodhart 不靠自觉，靠「改不了预注册、碰不到留出种子」。**

**定理 30（演示-实机分离：sim 证书不能冒充 real 证书）** 若 scope=real 而 TV(ε_transfer) < 1−δ_transfer，则 J_DEMO 无效；即便 sim demo 的覆盖 κ=1、功效 β=1、replay 完美，它也只能支持「在 P_Δ 支撑之外无结论」的 sim claim。**证明**：由定义 374，real claim 的谓词作用在 ξ_sim+Δ 上；Δ 的不确定度未被 sim 证书覆盖，定义 376 的 scope 条件不满足。系：**仿真越完美，越要小心它只证明了自己；「sim-to-real gap」不是工程调参，是证书的作用域边界。**

**定理 31（演示代数：合取的覆盖取交）** 对 DP_A ⊕ DP_B，κ_⊕ ≤ min(κ_A, κ_B)，且若不重新在 D_A∩D_B 上估计 β，则 β_⊕ 无下界保证。**证明**：supp(S_A ⊕ S_B) ⊆ supp(S_A)∩supp(S_B)，故覆盖取交；违反集在交集中的测度可能远小于在各自域中的测度，故功效不能继承。系：**「我们分别演示了 A 和 B」不等于「我们演示了 A∧B」；组合 claim 必须组合覆盖并重新估功效。**

## 6. 本轮最大风险

**一句话**：DEMO-GAUGE-RAS 把「演示」从修辞升级为测量，但它最终仍要相信三件无法被 demo 自身证明的事——**claim 的定义域 D 选得对（没漏掉真正的危险区域）、场景套件的对抗测度 q 在每个角落都真的为正（而不是只在工程师能想到的角落为正）、以及 MuJoCo 的 MJ-UQ 与 S2R 残差模型在分布外仍然成立**；一旦这三者中任一被「预注册的漂亮流程」掩盖，系统就会拿出一份**覆盖率高、功效高、replay 完美、预注册无可挑剔、却系统性错过了真实危险模式**的演示证书——它证明的是「我们的演示方案内部一致」，不是「机器人在世界上安全」，这正是**演示层面的「自信地证明了自己想证明的东西」**。

次级风险与缓解：
1. **覆盖/功效的估计依赖 Lipschitz 常数与违反集测度，而这两者在尾部不可知** → 用**保守上界 + 自适应对抗搜索（CMA-ES/贝叶斯优化）+ 尾部 CVaR**；报告「未知未知」而非假装覆盖。
2. **MuJoCo 仪器参数被事后调参以通过 demo** → **MJ-UQ 参数在预注册时锁定**，任何改动要求新 prereg_hash；E375 专门做对抗性利用。
3. **sim2real 残差重尾导致 TV 虚高** → 用 R72 的分位数残差与 **held-out 真机场景**估计 TV；scope=real 时强制报告「迁移覆盖域」。
4. **预注册流程形式化、内容仍可被巧妙措辞** → 预注册模板强制填写「**不能支持什么**」与「**什么会证伪**」；由独立 red-team 审查。
5. **演示债务被「刷标称场景」掩盖** → 债务按风险加权且只由角落/对抗/故障覆盖偿还；E377 长时程跟踪。
6. **多机器人/多 claim 组合的覆盖取交导致证书碎片化** → 演示代数（定义 380）显式报告交集中的 gap；禁止「分别安全=联合安全」。
7. **演示报告过度复杂导致无人复现** → 报告分三层：一页 claim/域/边界、场景表与种子、完整 replay 包；独立第三方复现纳入验收。

> 承接第 72 轮 IP-287~294（EMBODIED-GAUGE-RAS）。R72 把安全做到了「具身实时闭环」：REG 调度契约、IRL 意图、DMEM 接触四分量、EREFLEX 三层反作用、S2R-UQ、J_EMB。但它对「**如何证明**」仍停留在前科学阶段：
> - **演示方案缺失**：demo 被当成工程附属品（视频/曲线/挑种子），没有声明被测量、定义域、接受谓词、反例集、复现包；
> - **MuJoCo 被当真理**：`solref/solimp/cone/impratio/timestep/iterations` 被当实现细节，而不是**测量模型参数**；同一轨迹可因仪器配置不同得到相反结论；
> - **覆盖与功效缺失**：「跑了 N 次成功率 98%」既没说采样落在域的哪里，也没说对角落违反的检出概率；
> - **演示反作用缺失**：demo 会改变策略（过拟合 demo 分布）与人的意图/信任（L4/L5 反作用），没有预注册与留出种子就会被 Goodhart；
> - **退化演示缺失**：只演示 FULL 模式成功，等于只演示了性能，没有演示 R72 的安全退化链；
> - **作用域膨胀缺失**：sim demo 被直接当成 real 结论，S2R-UQ 没有接到演示证书上。
>
> 本轮四个补齐：
> - **DPC（演示方案编译器）**：claim → 预注册、分层、反驳优先的场景套件；
> - **MJ-UQ（MuJoCo 仪器不确定度）**：把仿真器当有系统误差的仪器，五分量预算（离散/接触/求解器/执行器/浮点）；
> - **FALS + COVA + REPRO**：反驳功效、ε-网覆盖、预注册+留出种子+跨平台 replay；
> - **T2R + DDEBT + DEGR-DEMO**：迁移有效度/作用域膨胀、演示债务与多重比较、退化演示契约。
>
> 核心命题：**从「我的系统能不能跑通一个 demo」进化为「这个 demo 本身是不是一次可审计、可反驳、可复现、可迁移的测量」** —— **演示计量学**。
>
> IP 编号：IP-295~303（共 9 个）。理论姿态延续：**没有反例集的 demo 是叙事；没有仪器预算的仿真是自证；没有覆盖边界的证书是作用域膨胀。**

## 2. 形式化定义（要点版）

**定义 366（DEMO-GAUGE-RAS 总览与六不变式）** (DPC, MJUQ, FALS, COVA, REPRO, T2R, DDEBT, DEGR-DEMO, J_DEMO)。六不变式：claim 可测量、仪器有标定、反例优先、覆盖可核算、预注册与复现、作用域不膨胀。

**定义 367（claim 对象）** C=(φ,D,ε,δ,scope,τ)。φ 是轨迹谓词；D 是摩擦/质量/位姿/意图/故障的声明域；可测量 ⇔ 存在 ε-网场景套件与逐轨迹监控器。不可测量者只能叫叙事，不能进 J_DEMO。

**定义 368（演示方案）** DP=(C,S,M,ρ,Π,A,R,J)。**测量五要素**：被测量 C、方法 S/Π、仪器 M、不确定度 MJ-UQ/场景/策略/残差、溯源 R（代码/MJCF/种子/遥测哈希）。

**定义 369（MuJoCo 测量模型）** x_{t+1}=f_MJ(x_t,u_t;θ_MJ)+η_t，y_t=g(x_t)+ν_t。θ_MJ 是测量模型参数而非物理真值；φ_MJ=φ(ξ_MJ(θ_MJ,ρ)) 随 θ_MJ 改变。

**定义 370（MJ-UQ 预算）** u_MJ²=u_disc²+u_contact²+u_solver²+u_act²+u_float²；u_claim²=Σ_i(S_i u_i)²+u_scen²+u_policy²+u_resid²。**任一 u_i 未报告 ⇒ J_DEMO 无效。**

**定义 371（反驳优先与功效）** 违反集 V_ε；套件测度 q=μ_S(V_ε)；β_S(ε)=P[判违反|x∈V_ε]。q=0 ⇒ 原理上不可证伪。反驳优先要求 S_adv∪S_fault 在 V_ε 上测度 ≥q_min 且接受谓词含反例尝试记录。

**定义 372（覆盖与 gap）** κ=μ(D∩supp(S))/μ(D)；ε-网覆盖 + Lipschitz 给出均匀界；demo-claim gap 为风险加权未覆盖测度。**「N 次」不是覆盖，ε_net 才是。**

**定义 373（复现与预注册）** REPRO 绑定 code/MJCF/版本/平台/种子承诺/遥测/replay 容差；prereg_hash=H(C,A,S,ρ_train,δ) 必须先于运行；replay 偏差 ≤τ_replay；跨平台浮点差异计入 u_float。

**定义 374（迁移有效度与作用域膨胀）** Δ=ξ_real−ξ_sim∼P_Δ（R72 S2R-UQ）；TV(ε_transfer)=P(|Δφ|≤ε)。scope=real 且 TV<1−δ_transfer ⇒ 作用域膨胀，J_DEMO 必须拒绝。

**定义 375（演示债务与多重比较）** D_debt=Σ_i w_i(1−κ_i)(1−β_i)Risk_i；m 个指标取最好者必须做 δ/m 校正或 e-value 聚合；未校正的「最佳 demo」不得进证书。

**定义 376（演示证书）** Valid(J_DEMO) ⇔ C 可测量 ∧ (scope∈{real,mixed}⇒J_EMB 有效) ∧ κ≥κ_min ∧ β≥β_min ∧ prereg 匹配 ∧ seed 承诺匹配 ∧ replay 通过 ∧ 多重比较已校正 ∧ (scope=real⇒TV≥1−δ_transfer) ∧ degradation_covered。

**定义 377（演示威胁模型）** ℰ_DEMO=ℰ_claim×ℰ_scen×ℰ_sim×ℰ_stat×ℰ_scope：事后改 claim、挑种子、调 solref 隐藏穿透、忽略多重比较、sim 冒充 real。

**定义 378（退化演示契约）** 故障注入表 F={(故障,时刻,期望降级,最大恢复τ_rec,硬安全谓词)}；要求 τ_rec 内进入 R71/R68、降级期硬安全与 λ_floor 保持、恢复无非法回滚。

**定义 379（演示报告）** DR=(claim,域,仪器与 MJ-UQ,场景与种子,覆盖与功效,反例记录,失败片段,TV,债务,复现指令)。**必须显式写出「本 demo 不能支持什么」。**

**定义 380（演示代数）** DP_A⊕DP_B 支持 C_A∧C_B，D=D_A∩D_B，κ_⊕≤min(κ_A,κ_B)，β_⊕ 必须在交集重估；不独立则置信度不可相加。**合取覆盖取交，不是并。**

## 3. 关键算法伪代码

```python
# IP-295 DPC：claim -> 预注册演示方案（运行前完成，之后只读）
@dataclass
class Claim:
    phi: Callable[[Trajectory], bool]
    domain: DomainSpec          # 摩擦/质量/位姿/光照/意图/故障
    eps: float                  # 可容忍违反幅度
    delta: float                # 允许证书错误率
    scope: Literal['sim','real','mixed']
    risk_weight: float

def compile_demo_plan(C, robot, budget):
    D = discretize(C.domain, grid=budget.grid)
    S_nom    = stratified_center(D)
    S_corner = domain_corners(D)                  # μ_min/max, m_min/max, H[z] max, ...
    S_adv    = adversarial_search(D, C.phi, budget.adv)  # 最大化预测违反
    S_fault  = fault_suite(robot.degradation_chain)      # 见 IP-302
    rho_train, rho_test = split_seeds(budget.seeds)      # 预注册且分离
    A = acceptance_predicate(C, method=budget.multiplicity)
    prereg = H(C, A, S_nom, S_corner, S_adv, S_fault, rho_train)
    M = mujoco_instrument(robot.mjcf, budget.mj_configs)  # IP-296
    return DemoPlan(C, (S_nom,S_corner,S_adv,S_fault), M,
                    (rho_train,rho_test), protocol(budget), A,
                    repro_bundle(), prereg_hash=prereg)

# IP-296 MJUQ：把 MuJoCo 当仪器，计算五分量预算 + 配置哈希
def mujoco_uq(mjcf, theta0, priors, phi_mj, n_mc=256):
    u = {}
    u['disc']    = sensitivity(phi_mj, theta0, 'timestep', priors)
    u['contact'] = sensitivity(phi_mj, theta0,
                               ('solref','solimp','cone','impratio'), priors)
    u['solver']  = sensitivity(phi_mj, theta0, 'iterations', priors)
    u['act']     = actuator_model_spread(mjcf, priors)
    u['float']   = cross_platform_replay_spread(mjcf, n_mc)
    return MJUQ(components=u,
                total=math.sqrt(sum(v**2 for v in u.values())),
                config_hash=H(mjcf, theta0))
# 例：接触刚度 k ~ m_eff / timeconst^2 ⇒ 穿透 p ~ F/k；timeconst 变 2x ⇒ p 变 4x
#     故 ∂φ/∂timeconst 非零，timeconst 的不确定度必须进 u_contact

# IP-297 FALS：留出种子上的反驳功效（不是训练成功率）
def power(S, phi, eps, monitor, rho_test, n):
    hits = total = 0
    for x in sample(S, rho_test, n):
        if violation_magnitude(phi, x) >= eps:
            total += 1
            hits  += int(monitor(x) == 'violate')
    if total == 0:
        return 0.0          # 违反集零测度 => 不可证伪，证书拒绝
    return BetaPosterior(hits, total).mean()

# IP-298 COVA：ε-网覆盖 + Lipschitz 均匀界
def coverage_gap(S, D, eps_net, risk_weights):
    kappa = 1.0 if is_eps_net(S, D, eps_net) else covered_measure(S,D)/measure(D)
    gap   = sum(risk_weights[x] for x in D if not covered(S, x, eps_net))
    return Coverage(kappa=kappa, gap=gap, eps_net=eps_net)
def uniform_claim_bound(L, eps_net, n, delta):
    return L*eps_net + math.sqrt(math.log(2/delta)/(2*n))

# IP-299 REPRO：预注册 + 留出种子 + 独立 replay
def certify_repro(plan, run1, run2):
    return Reproducibility(
        prereg=H(plan.C, plan.A, plan.S, plan.rho[0]) == plan.prereg_hash,
        seed=commit(plan.rho) == plan.seed_commit,
        replay=max_traj_dev(run1, run2) <= plan.R.tau_replay,
        float_uq=cross_platform_spread(run1))

# IP-300 T2R：用 R72 S2R-UQ 的残差分布做蒙特卡洛，而非取均值
def transfer_validity(claim, s2r, replayed_trajs, eps_transfer):
    diffs = []
    for xi in replayed_trajs:
        for _ in range(64):
            xi_real = xi + s2r.sample_residual()     # 重尾/多峰也照采
            diffs.append(abs(phi_value(claim, xi_real) - phi_value(claim, xi)))
    return sum(d <= eps_transfer for d in diffs) / len(diffs)

# IP-301 DDEBT：多重比较 + 风险加权债务
def demo_ledger(claims, demos, alpha):
    m = sum(len(d.metrics) for d in demos)
    alpha_corr = alpha / m
    debt = sum(c.risk_weight*(1-d.coverage)*(1-d.power)
               for c,d in zip(claims,demos))
    return Ledger(fwer=alpha_corr, debt=debt, m=m,
                  cvar=cvar_of_violations(demos, 0.95))

# IP-302 DEGR-DEMO：退化演示，主角是坏情况
def run_degradation_demo(robot, F, tau_rec=1.0):
    results = []
    for (fault, t_inject, expected, tau, safety_pred) in F:
        inject(fault, at=t_inject)
        t0 = now()
        reached = wait_until(lambda: robot.mode in {'R71','R68'}, tau_rec)
        results.append(DegrResult(
            fault=fault,
            reached=reached and robot.mode == expected,
            latency=now()-t0,
            safety_ok=hard_safety_envelope_holds(robot) and safety_pred(robot),
            illegal_rollback=robot.did_rollback_without_revalidate()))
    return results

# IP-303 DEMO-GAUGE 主流水线
def demo_gauge(claim, robot, budget):
    plan  = DPC.compile(claim, robot, budget)
    commit_prereg(plan.prereg_hash)                 # 运行前锁定
    mj_uq = MJUQ.budget(plan.M)
    fit_on_train(robot.policy, plan.rho[0])         # 只能在训练种子上调
    runs  = run_mujoco(plan, seeds=plan.rho[1])     # 留出种子只测不调
    cov   = COVA.compute(plan.S, claim.domain)
    power = FALS.power(plan.S, claim.phi, claim.eps, monitor, plan.rho[1], n)
    repro = REPRO.certify(plan, runs[0], runs[1])
    tv    = T2R.estimate(claim, plan.M.s2r) if claim.scope != 'sim' else None
    degr  = DEGR_DEMO.run(robot, plan.faults)
    led   = DDEBT.compute([claim], [plan], alpha=claim.delta)
    J     = J_DEMO(claim, plan, mj_uq, cov, power, repro, tv, led, degr)
    return J, DemoReport(claim, plan, cannot_support=complement(plan))
```

## 4. 推导

**引理 33（种子抽奖与多重比较膨胀）** m 个零假设下各以 δ 误报，取最好者 FWER≈mδ；Bonferroni 阈值 δ/m 才能保证 FWER≤δ。**挑种子是一次未校正多重比较。**

**引理 34（MuJoCo 接触参数敏感性界）** 隐式软接触下 k≈m_eff/timeconst²，穿透 p≈F/k∝F·timeconst²/m_eff，故
|Δp|/p ≤ 2|Δtimeconst|/timeconst + |ΔF|/F + |Δm_eff|/m_eff。
cone 从 pyramidal 换 elliptic 改变切向可行域，滑移阈值发生 O(1) 变化；timestep 改变事件相位，峰值力误差 O(h)。**claim 对 θ_MJ Lipschitz，MJ-UQ 是一阶误差源。**

**引理 35（ε-网覆盖 ⇒ 均匀 claim 界）** φ 为 L-Lipschitz，S 为 ε_net-网，则
sup_D|φ̂−φ| ≤ L·ε_net + √(log(2/δ)/(2n))。
**增加中心样本而不减小 ε_net，界不变。**

**引理 36（反驳优先的功效支配）** q_{S_nom}(V_ε)=0 ⇒ β=0；q_{S_adv}>0 ⇒ β≥q(1−β_monitor)，E[N_detect]≤1/(q(1−β_monitor))。**角落违反是采样支撑问题，不是样本量问题。**

**定理 27（演示证书的域内可靠性）** J_DEMO 有效 ⇒ claim 在覆盖域 D_κ 上以 ≥1−δ 成立（容差 ε），且不可外推。证明用引理 33/35 + MJ-UQ + 预注册；域外无覆盖，界不适用。

**定理 28（没有免费 demo）** 若违反集在套件支撑上测度为零，则任意样本量下 β=0，J_DEMO 不能给出该违反的任何保证。**安全 claim 必须自带可证伪的违反集与正测度套件，否则是叙事。**

**定理 29（预注册+留出种子 ⇒ Goodhart 抗性）** claim/接受谓词/套件/训练种子运行前锁定，置信度仅在 ρ_test 上算，m 指标做 δ/m 校正 ⇒ 任意基于训练种子的挑参策略，其留出证书虚假通过概率 ≤δ。**反 Goodhart 靠「改不了预注册、碰不到留出种子」。**

**定理 30（演示-实机分离）** scope=real 且 TV<1−δ_transfer ⇒ J_DEMO 无效；即使 κ=1、β=1、replay 完美，也只是 sim claim。**仿真越完美，越要小心它只证明了自己。**

**定理 31（演示代数：合取覆盖取交）** DP_A⊕DP_B 的 supp⊆supp(S_A)∩supp(S_B)，故 κ_⊕≤min；β_⊕ 不重估则无下界。**「分别演示 A 和 B」≠「演示 A∧B」。**

## 5. 复杂度分析

## 7. 本轮最大风险

**一句话**：DEMO-GAUGE-RAS 把 demo 升级成测量，但它的有效性最终依赖三件**demo 自身无法证明**的事——**定义域 D 选得对（没漏掉真正危险的区域）、对抗测度 q 在工程师没想到的角落仍为正、以及 MJ-UQ 与 S2R 残差在分布外仍成立**；一旦这三者被「预注册的漂亮流程」掩盖，我们就会得到一份**覆盖率、功效、replay、预注册全部完美、却系统性错过真实危险模式**的演示证书——它证明的只是「我们的演示方案内部一致」，而不是「机器人在世界上安全」，这正是**演示层面的「自信地证明了自己想证明的东西」**。

次级风险与缓解：
1. **尾部覆盖/功效不可知** → 保守上界 + 自适应对抗搜索（CMA-ES/贝叶斯优化）+ CVaR；报告「未知未知」。
2. **仪器参数事后调参** → θ_MJ 预注册锁定，改动即新 prereg_hash；E375 对抗性检验。
3. **sim2real 残差重尾** → 用 R72 分位数残差与 held-out 真机场景估计 TV；scope=real 强制报告迁移覆盖域。
4. **预注册形式化** → 强制填写「不能支持什么/什么会证伪」，独立 red-team 审查。
5. **债务被标称场景掩盖** → 风险加权债务只由角落/对抗/故障覆盖偿还；E377 长时程跟踪。
6. **组合 claim 覆盖取交导致证书碎片化** → 演示代数显式报告交集 gap；禁止「分别安全=联合安全」。
7. **报告过复杂无人复现** → 三层报告（一页边界 / 场景种子表 / 完整 replay 包），独立复现纳入验收。
