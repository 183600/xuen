### 第 7 轮灵感驱动研究记录

**灵感词**：仿真到现实迁移、多机协同

**继承关系**：第 6 轮 CADVS-v6（IP-497~500）在「七硬门不增」下引入 GGC/MCTM/STM 三元凿，把流匹配提议约束到「几何可达、空间连通、语义可解释」的亚族，并用软因子链 η_g·η_topo·η_interp·η_cmd 只收紧阈值。但 v6 的全部证书仍隐含两个未被审视的假设：**(A) 执行环境与训练仿真同分布**；**(B) 系统中只有一个被认证的智能体**。本轮的两个灵感词恰好各击穿一个：仿真到现实迁移打破 (A)，多机协同打破 (B)。v7 的任务不是再造一个生成器，而是回答「**证书在分布外（环境分布外、智能体分布外）如何仍然有效，且不新增硬门**」。

**直觉与动机**：

1. **仿真到现实迁移 → 会失真的是「证书」，而不只是「策略」**。v5/v6 的七硬门是在仿真转移核 P_sim 上标定的：门分数 s_i(x) 在仿真里过线，不代表在真实核 P_real 下仍过线。直觉上大家会去做域随机化训练策略，但这治不了证书——证书是「分数函数 + 阈值」，不是策略权重，策略再鲁棒也无法保证某个具体候选轨迹在现实中的门分数不塌陷。关键洞见：**把「现实差距」从训练噪声升级为证书裕度**。用成对 sim-real 回放估计每个门分数的迁移残差，用保形预测（conformal prediction）给出有限样本、高概率的加性裕度 Δ_i；把 Δ_i 直接加进门阈值，于是「仿真里过 τ+Δ_i」⇒「现实里过 τ」。这不是新增硬门，而是给已有硬门**加一层可证明的保守垫片**。直觉上这像控制里的「tube MPC」：不去猜真实扰动，而是用可证明的管半径把名义约束收紧。

2. **多机协同 → 局部证书的「合取」并不等于全局安全**。每台机器人各自跑 EFA-v6 都能拿到合格证书，但两两轨迹仍可能在同一时空相交；更糟的是通信延迟会把「我以为你会让」变成「我们都以为对方会让」。直觉上大家会做集中式规划，但这破坏端侧自治与隐私。关键洞见：**用 assume-guarantee 契约把局部证书组合成全局证书**。每台机器人执行前在共享时空账本里原子预留一条「时空走廊」C_i；BCK 门的障碍集从静态/预测障碍 O 扩展为 O ∪ {C_j}_{j≠i}（**门的数量与语义不变，只是输入集变大**）；只要所有走廊两两时空不相交，组合定理即保证全局无碰撞。通信延迟不靠新门兜底，而是把走廊按 v_max·τ_comm 膨胀成「延迟管」，并强制契约续约。

**统一洞见**：两个灵感词是同一枚硬币——**都是「证书的分布外有效性」**。仿真到现实是环境转移核的分布外，多机是联合状态空间的分布外；v7 的回答是：**不新增硬门，而是用「保形加性裕度 Δ_i」处理环境漂移、用「时空走廊契约松弛」处理智能体耦合，二者都表现为对既有七门阈值的保守收紧**。七硬门 kc_evidence_forged_v5 记号原样复用；本轮新增的只有：
- IP-501 S2RGC（仿真-现实差距证书器，保形加性裕度 Δ_i），
- IP-502 RRM（现实残差监控器，触发证书失效 → safe-harbor），
- IP-503 DAGC（分布式 assume-guarantee 时空走廊契约），
- IP-504 CDT（通信延迟管 + 契约续约），
- IP-505 EFA-v7（加性裕度 + 软评分）。

**形式化目标（增量）**：

1. **S2RGC（Sim2Real Gap Certifier）**：<br>
   - 门分数 Lipschitz 常数 L_i：|s_i(x)−s_i(x')| ≤ L_i·d(x,x')；成对校准集 D_cal = {(x_k,a_k)}，残差 ρ_{i,k} = |s_i^real(x_k) − s_i^sim(x_k)|<br>
   - 保形裕度 Δ_i(α_i) = Quantile_{1−α_i}({ρ_{i,k}})，满足 P(|s_i^real(x) − s_i^sim(x)| ≤ Δ_i) ≥ 1−α_i（有限样本修正）<br>
   - 加性收紧阈值：τ_i^v7 = γ_i·τ_i^v5·Π_factor_i + Δ_i(α_i)，其中 Δ_i ≥ 0，只收紧不放松<br>
   - 迁移执行集 Exec_v7 = {x : s_i^sim(x) ≥ τ_i^v7, ∀i}，则 w.p. ≥ 1−α：Exec_v7 ⊆ Exec_real^v6（α 由七门 Bonferroni 分摊）

2. **RRM（Reality Residual Monitor）**：<br>
   - 在线残差 r_t = d(x_{t+1}^obs, f_sim(x_t,u_t))；认证包络 B_t 由 D_cal 的残差分位给出<br>
   - 若 r_t > B_t 连续 m 次，宣布证书失效，fail-closed 进入 safe-harbor（预认证的鲁棒不变集 + 保守制动），**不回退 v5**（v5 同样是仿真证书，现实里未必成立）<br>
   - 软因子 η_real = σ(−(r_t − B_t)/σ_r) ∈ (0,1]

3. **DAGC（Distributed Assume-Guarantee Contract）**：<br>
   - 机器人 i 的局部契约 (A_i, G_i)：G_i =「停留在时空走廊 C_i 内」，A_i =「∀j≠i, C_i ∩ C_j = ∅」<br>
   - 预留协议：分布式账本对 C_i 原子提交；优先级全序避免死锁；冲突时低优先级让行重规划<br>
   - 组合定理：若 ∀i G_i 成立且 ∀i≠j C_i ∩ C_j = ∅，则联合执行对任意 t 无碰撞<br>
   - 走廊松弛软因子 η_coord = σ(min_{i≠j} margin(C_i,C_j) / r_safe)，margin 为扣除安全半径后的时空净间隔

4. **CDT（Communication-Delay Tube）**：<br>
   - 通信上界 τ_comm，走廊膨胀 C_i^⊕ = C_i ⊕ B(v_max·τ_comm)（闵可夫斯基和）<br>
   - 契约在 [t, t+τ_comm] 内视为「暂定」，到期需续约；续约失败则自动收缩走廊<br>
   - 软因子 η_delay = σ(−τ_comm/σ_comm) ∈ (0,1]

5. **EFA-v7 软评分**：ECS_v7 = ECS_v6 · η_s2r · η_real · η_coord · η_delay，其中 η_s2r = exp(−ε_s2r/σ_s2r)，ε_s2r = max_i Δ_i/L_i 为归一化现实差距半径（仅用于排序，不用于放松阈值）。阈值 τ_i^v7 = γ_i·τ_i^v5·Π_factor_i + Δ_i；BCK 输入障碍集扩展为 O ∪ {C_j}_{j≠i}。

6. **形式化定义**：给定指令 L、多机集合 R={1..N}、记忆 M：<br>
   - x = EFA-v6.select(L)（先拿到 v6 候选与 v6 阈值）；<br>
   - C_i = CDT.inflate(corridor_of(x))；res = DAGC.reserve(i, C_i)；<br>
   - 若 ¬res.granted → 让行重规划（COORDINATION_YIELD）；<br>
   - surv = [x : BCK(x, O ∪ {C_j}_{j≠i}) ∧ S2RGC.transferable(x, s_sim ≥ τ^v7)]；<br>
   - Exec_CADVS-v7 = {x ∈ surv : ∧_i kc_i^v5(x,c; τ_i^v7)=1}，七门数量/语义不变。

**本轮最大风险**：**分布外证书的联合置信度与可用性双重崩溃**——保形裕度 Δ_i 与延迟管膨胀叠加，使 Exec_v7 在高保真（α 小、N 大）时几乎为空，系统频繁 safe-harbor 停机；而七门×N 机的并集界使联合置信度随规模线性稀释，「认证」趋于名存实亡。

## 2. 关键算法骨架

### IP-501 S2RGC：仿真-现实差距证书器

```python
@dataclass
class Sim2RealGapCertifier:
    """S2RGC：用成对 sim-real 回放 + split conformal 给每个硬门的分数加可证明的加性裕度 Δ_i。
    红线：Δ_i ≥ 0 只加不减，保证 Exec_v7 ⊆ Exec_v6；不新增任何门。"""
    lipschitz: dict[str, float]                 # L_i：门分数对状态的 Lipschitz 常数
    alpha: float = 0.05                          # 总误覆盖上界
    residuals: dict[str, list[float]] = field(default_factory=dict)

    def calibrate(self, gate_names: list[str], paired_rollouts) -> dict[str, float]:
        """离线：对每条 (x,a) 计算 |s_real - s_sim|，取保形分位（Bonferroni）。"""
        n = len(paired_rollouts)
        alpha_i = self.alpha / max(len(gate_names), 1)
        deltas = {}
        for name in gate_names:
            res = sorted(self.residuals[name])
            k = math.ceil((n + 1) * (1 - alpha_i)) - 1   # 有限样本修正
            k = min(max(k, 0), n - 1)
            deltas[name] = res[k] if res else math.inf
        return deltas

    def inflate(self, tau_v6: dict[str, float], deltas: dict[str, float]) -> dict[str, float]:
        """加性收紧：τ^v7 = τ^v6 + Δ_i。"""
        return {name: tau_v6[name] + deltas[name] for name in tau_v6}

    def transferable(self, x, s_sim: dict[str, float], tau_v7: dict[str, float]) -> bool:
        """在仿真分数上检查 v7 阈值；过线即可迁移到现实（w.p. ≥ 1-α）。"""
        return all(s_sim[name] >= tau_v7[name] for name in tau_v7)
```

### IP-502 RRM：现实残差监控器

```python
@dataclass
class RealityResidualMonitor:
    """RRM：在线比较预测与观测，残差超认证包络即宣布证书失效 → safe-harbor。"""
    envelope_quantile: float = 0.99
    m_consecutive: int = 3
    sigma_r: float = 0.1

    def certified_envelope(self, calibration_residuals: list[float]) -> float:
        return float(np.quantile(calibration_residuals, self.envelope_quantile))

    def observe(self, x_next_obs, f_sim_pred, B_t: float,
                streak: int) -> tuple[float, int, bool]:
        """返回 (η_real, 连续越界计数, 是否证书失效)。"""
        r_t = float(torch.linalg.norm(x_next_obs - f_sim_pred))
        violated = r_t > B_t
        streak = streak + 1 if violated else 0
        invalid = streak >= self.m_consecutive
        eta_real = float(torch.sigmoid(torch.tensor(-(r_t - B_t) / self.sigma_r)))
        return eta_real, streak, invalid
```

### IP-503 DAGC：分布式 assume-guarantee 走廊契约

```python
@dataclass
class DistributedAssumptionGuaranteeContract:
    """DAGC：每台机器人预留时空走廊 C_i；BCK 障碍集扩展为 O ∪ {C_j}。
    门数量/语义不变，只是输入集变大。"""
    ledger: SpaceTimeLedger                  # 分布式账本（原子提交 + 签名 + quorum）
    r_safe: float = 0.15                     # 安全半径
    priority_key: Callable = lambda rid: rid # 全序，避免死锁

    def reserve(self, rid: int, corridor: Corridor, t_now) -> Reservation:
        """原子预留；冲突则按优先级让行，低优先级返回 REJECT 需重规划。"""
        return self.ledger.atomic_reserve(rid, corridor, key=self.priority_key(rid))

    def margin(self, C_i: Corridor, C_j: Corridor) -> float:
        """时空最近距离减去各自安全半径后的净间隔。"""
        return space_time_distance(C_i, C_j) - 2 * self.r_safe

    def eta_coord(self, C_i: Corridor, others: list[Corridor]) -> float:
        if not others:
            return 1.0
        m = min(self.margin(C_i, C_j) for C_j in others)
        return float(torch.sigmoid(torch.tensor(m / self.r_safe)))

    def extended_obstacles(self, static_obs, others: list[Corridor]) -> list:
        """BCK 输入扩展：静态/预测障碍 + 其他机器人已提交走廊。"""
        return list(static_obs) + list(others)
```

### IP-504 CDT：通信延迟管

```python
@dataclass
class CommunicationDelayTube:
    """CDT：通信上界 τ_comm → 走廊按 v_max·τ_comm 膨胀；契约到期需续约。"""
    tau_comm: float = 0.2
    v_max: float = 1.0
    sigma_comm: float = 0.1

    def inflate(self, C: Corridor) -> Corridor:
        return C.minkowski_sum(ball(radius=self.v_max * self.tau_comm))

    def eta_delay(self) -> float:
        return float(torch.sigmoid(torch.tensor(-self.tau_comm / self.sigma_comm)))

    def renew(self, reservation: Reservation, t_now) -> bool:
        """在 [t, t+τ_comm] 内暂定；到期未续约则自动收缩走廊。"""
        return reservation.valid_until >= t_now
```

### IP-505 EFA-v7：七硬门不变 + 加性裕度 + 软因子链

```python
@dataclass
class EvidenceForgingAssemblerV7:
    """EFA-v7：七硬门数量/语义不变；加性裕度 Δ_i + 软因子链。"""
    v6: EvidenceForgingAssemblerV6
    s2r: Sim2RealGapCertifier
    rrm: RealityResidualMonitor
    dagc: DistributedAssumptionGuaranteeContract
    cdt: CommunicationDelayTube
    safe_harbor: SafeHarborPolicy
    deltas: dict[str, float] = field(default_factory=dict)

    def select(self, L, rid: int, t_now, context,
               peers: list[Corridor]) -> tuple[bool, Trajectory | None, str]:
        # 1. 复用 v6 生成 + 软因子，拿到候选与 v6 阈值
        ok, x, why = self.v6.select(L, t_now, context)
        if not ok or x is None:
            return False, None, why

        # 2. 多机契约：膨胀走廊后原子预留，冲突则让行重规划
        C_i = self.cdt.inflate(corridor_of(x, self.cdt.tau_comm))
        res = self.dagc.reserve(rid, C_i, t_now)
        if not res.granted:
            return False, None, 'COORDINATION_YIELD'
        others = self.dagc.ledger.committed_excluding(rid)
        eta_coord = self.dagc.eta_coord(C_i, others)
        eta_delay = self.cdt.eta_delay()

        # 3. 用扩展障碍集做 BCK（门不变，输入变大）
        obs_ext = self.dagc.extended_obstacles(context.obstacles, others)
        if not self.v6.v5.bck.preview(x, obs_ext):
            self.dagc.ledger.release(rid)
            return False, None, 'CONTRACT_BCK_REJECT'

        # 4. 仿真分数 + 加性裕度做迁移判定（τ^v7 = τ^v6 + Δ_i）
        s_sim = self.v6.v5.gate_scores(x, context)
        tau_v6 = self.v6.tau_v6(self.v6.famk.gamma(context.s_emo))
        tau_v7 = self.s2r.inflate(tau_v6, self.deltas)
        if not self.s2r.transferable(x, s_sim, tau_v7):
            self.dagc.ledger.release(rid)
            return False, None, 'TRANSFER_CERT_FAIL'

        # 5. 记录本步软因子，供 ECS 排序
        eps_s2r = max(self.deltas[i] / max(self.s2r.lipschitz[i], 1e-6)
                      for i in self.deltas)
        self._eta = {'s2r': math.exp(-eps_s2r / SIGMA_S2R),
                     'coord': eta_coord, 'delay': eta_delay}
        return True, x, 'FORGED_CGE_V7'

    def on_step(self, x_next_obs, f_sim_pred, B_t,
                streak: int) -> tuple[bool, str]:
        """控制环每步调用；连续越界 → 证书失效 → safe-harbor。"""
        eta_real, streak, invalid = self.rrm.observe(x_next_obs, f_sim_pred, B_t, streak)
        self._eta['real'] = eta_real
        if invalid:
            return False, 'CERT_INVALIDATED_SAFE_HARBOR'
        return True, 'OK'

    def ecs_v7(self, x, n_flow, s_emo, eta_factors: dict) -> float:
        """ECS_v7 = ECS_v6 · η_s2r · η_real · η_coord · η_delay。"""
        return self.v6.ecs_v6(x, n_flow, s_emo, eta_factors) \
               * eta_factors['s2r'] * eta_factors['real'] \
               * eta_factors['coord'] * eta_factors['delay']
```

### 集成流水线（v6 → v7）

```
离线/慢时域：
  S2RGC 标定（小时级）：N 对 sim-real 回放 → 每门残差 ρ_{i,k} → 保形裕度 Δ_i（Bonferroni α/7）
  safe-harbor 预认证：鲁棒不变集 + 保守制动曲线 → 独立现实证书
  多机账本部署：签名 + quorum；τ_comm 上界实测；优先级全序注册
在线准入（异步，秒级）：
  v6.select ──▶ 候选 x（含 GGC/MCTM/STM 软因子）
  CDT.inflate(C_i) ──▶ DAGC.reserve ──▶ 冲突则 COORDINATION_YIELD 重规划
  BCK(障碍集 O ∪ {C_j}) ──▶ 契约一致
  s_sim ≥ τ^v6 + Δ_i ──▶ 迁移证书通过
在线控制环（目标 < 1 ms）：
  RRM 每步 r_t vs B_t；连续 m 次越界 ──▶ safe-harbor
  CDT 到期续约；否则收缩走廊并让行
```

## 4. 正确性论证（增量更新）

### 定理 11（保形证书迁移）

**陈述**：设校准残差 {ρ_{i,k}} 与测试样本满足可交换性，Δ_i 为 split-conformal 分位（单门 α_i=α/7）。则对任意 x ∈ Exec_v7（即 s_i^sim(x) ≥ τ_i^v6 + Δ_i, ∀i），有
P(∧_{i=1..7} s_i^real(x) ≥ τ_i^v6) ≥ 1 − α。

**证明**：单门由 split conformal 得 P(s_i^real(x) ≥ s_i^sim(x) − Δ_i) ≥ 1−α_i；又 s_i^sim(x) ≥ τ_i^v6 + Δ_i ⇒ s_i^real(x) ≥ τ_i^v6。对七门取并集界，Σ α_i = α，故联合概率 ≥ 1−α。∎

**注**：可交换性是硬前提；非平稳现实会破坏覆盖，只能由 RRM 事后发现，不能事前保证。

### 定理 12（assume-guarantee 组合安全）

**陈述**：设每台机器人 i 的控制器满足屏障证书 B_i(x_i(t)) ≥ 0 ⇒ x_i(t) ∈ C_i，且 ∀i≠j, C_i ∩ C_j = ∅。则联合执行对任意 t 无碰撞。

**证明**：由 G_i 得 x_i(t) ∈ C_i。若 t 时刻发生碰撞，则存在 i≠j 使 x_i(t)=x_j(t)，即该点 ∈ C_i∩C_j，与走廊不交矛盾。∎

**推论（延迟鲁棒）**：若走廊按 v_max·τ_comm 膨胀，则即使消息在 τ_comm 内丢失，已提交走廊仍两两不交，组合安全在延迟界内保持。

### 定理 13（不增门不变式）

**陈述**：v7 的硬门集合与 v6 完全相同（七个、同名、同语义）。v7 只做两件事：(a) 加性抬高阈值 Δ_i ≥ 0；(b) 扩大 BCK 输入集 O → O ∪ {C_j}_{j≠i}。因此 Exec_v7 ⊆ Exec_v6 ⊆ Exec_v5（在仿真核上），且 fail-closed 结构不变。

**证明**：阈值单调抬升 ⇒ 通过集合单调收缩；BCK 障碍集扩大 ⇒ 屏障证书更难满足 ⇒ 收缩；全程未引入新的判定谓词，门的数量与语义不变。∎

### 诚实声明

- 保形迁移依赖可交换性；现实非平稳、长尾或对抗扰动会破坏覆盖，RRM 只能事后发现，不能事前保证。
- Δ_i 的紧致性依赖 L_i 估计与校准集代表性；Δ_i 过大会使 Exec_v7 空集（可用性崩塌）。
- 多机组合假设「每台都诚实执行屏障证书」；拜占庭机器人可伪造走廊，签名/quorum 可缓解但仍有合谋风险。
- safe-harbor 自身必须在现实中独立认证，否则「兜底」只是把风险转移给停机策略。
- 联合置信度：7 门×N 机用 Bonferroni 会随规模线性稀释；e-value / anytime-valid / 分级认证可缓解，但代价是更保守。

## 5. 实验设计与验证计划（仿真 → 实机）

### 5.1 实验设计（MuJoCo 3.x + MJX，实机 UR10e + TurtleBot4）

- **平台**：单机 UR10e（6DOF）+ 移动底盘；多机 2–4 台异构机器人共享工位。
- **数据集**：
  - S2RGC：5k 对 sim-real 回放（光照/摩擦/负载/传感器噪声随机偏移）；
  - 多机：200 次共享工位任务，通信延迟注入 0–300 ms、丢包 0–20%；
  - safe-harbor：鲁棒不变集与制动曲线独立标定 500 次。
- **对照**：v6-full、v7-full、消融 A16（无 S2RGC，Δ=0）、A17（无 RRM）、A18（无 DAGC，独立规划）、A19（无 CDT）、A20（固定 Δ 而非保形）、A21（Bonferroni vs e-value）。
- **场景**：
  - (a) sim-to-real：光照/摩擦/负载/噪声偏移；透明与柔性物体抓取；
  - (b) 多机：交叉路口、共享工位、对向走廊、通信抖动/丢包、单机故障；
  - (c) 隐私：多机仅交换签名走廊摘要，不交换原始轨迹/点云/语音。
- **指标**：保形经验覆盖率 vs 名义 1−α、真实门通过率偏差、碰撞率、死锁率、safe-harbor 停机频率、任务可用性、通信字节、控制环 P99。

## 7. 本轮最大风险（最终确认）

**一句话**：**分布外证书的联合置信度与可用性双重崩溃**——保形裕度 Δ_i 与延迟管膨胀叠加，使 Exec_v7 在高保真（α 小、N 大）时几乎为空，系统频繁 safe-harbor 停机；而七门×N 机的并集界使联合置信度随规模线性稀释，「认证」趋于名存实亡。
