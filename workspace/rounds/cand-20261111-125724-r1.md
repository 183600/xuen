# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 1 轮；本轮灵感：「示教学习」×「情感语音」）

> 第 54 轮把技能组合推进为动作空间与鲁棒性的双证书，但证书的“证据从哪来”仍默认由仿真采样提供。本轮把 **示教（LfD）作为证据源**、把 **情感语音作为示教证据的元标注与部署扰动源**。核心矛盾：H22：示教只覆盖动作空间的稀疏流形，却被当作 α_S 的充分证据；H23：情感语音同时携带“教师此刻有多确信/多紧迫”的元信息与“部署用户此刻的情绪分布”，证据与扰动同源，越依赖情感证据，证书越脆弱于情感漂移。

## 0. 直觉与动机

**灵感 1（示教不是用来克隆策略，而是用来给动作空间“作证”）**
直觉：行为克隆会把教师的因果混淆（他看哪里、何时停）一起学走；但证书需要的不是“教师怎么做”，而是“哪些动作被教师证明可达、哪些被证明危险、证据有多密”。因此把示教降级为 **动作剖面的稀疏证据**：每条轨迹是 α_S 上的一个样本点，而不是策略的监督标签。这样 LfD 的 covariate shift 不再直接污染证书，先证后学。

**灵感 2（情感语音是示教的元标注，不是情绪分类题）**
直觉：教师边说边教时，韵律（音高、能量、语速、停顿、抖动）泄露的是 **认知状态**：确信、犹豫、催促、纠正。把它压成“高兴/生气”七分类会丢掉最有用的信息；应抽取 **示教情感向量** e=(confidence, urgency, valence, arousal)，映射为“这条示教有多可信、这条约束有多硬”。情感在这里是证据的权重与约束的硬度，不是奖励。

**灵感 3（情感只能收紧约束，不能放宽安全）**
直觉：如果教师语气轻松就让机器人放宽安全阈值，系统会被“哄着”越过边界；反之，紧张、急促、负价的语音若只提高成功率权重，也会被平均掉。因此规定 **单向性**：情感可以降低示教权重、可以提高约束硬度，但任何情感都不得把约束降到默认安全线以下。情感不进入奖励函数，只进入“证据权重 + 约束收紧”两个通道，从机制上阻断情感操纵与 reward hacking。

**灵感 4（语音-动作对齐 + 冲突保守融合）**
直觉：教师常在同一时刻说“慢一点”而手却加速，或嘴上说“没事”声音却发紧。语音片段与动作片段需要时间对齐，形成 **情感示教单元**；当语义通道与韵律通道冲突时，取“更不信任、更硬约束”的保守融合，而不是投票平均。冲突本身还是高价值信号，说明该段示教不可靠或任务处于边界。

**灵感 5（证据-扰动同源：情感回声悖论）**
直觉：情感语音既是证书的证据来源，又定义了部署时的输入分布。更多同一教师的示教能降低覆盖不确定性，却不能消除 **教师情感分布 → 用户情感分布** 的偏移；越是用教师情感给证书加权，证书越可能只在该教师的情感风格下成立。这就是“情感回声悖论”：证据越精细，越容易被同一来源的分布锁死。因此必须显式定义 **情感域间隙 ADG**，并把“间隙可控”写进证书生效条件，而不是假定情感标签可迁移。

**灵感 6（示教-情感金字塔层 𝔼）**
直觉：在第 54 轮的鲁棒性层 𝕃 与动作协同层 𝔸 之上叠加 **示教-情感层 𝔼**：`𝔼_0` 示教采集与同意/溯源，`𝔼_1` 语音-动作对齐，`𝔼_2` 情感→证据权重/约束硬度编译，`𝔼_3` 跨教师/跨用户情感迁移。证书从 `(ρ, A_cert)` 扩展为 `(ρ, A_cert, D_cert, E_cert)`，形成 **鲁棒-动作-示教-情感四证书**。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（情感示教单元 ADU）**
一条示教记录 `D = {(ξ_k, s_k, e_k, π_k)}_{k=1..K}`，其中 `ξ_k` 为动作轨迹片段，`s_k` 为与 `ξ_k` 时间对齐的语音片段，`π_k` 为溯源信息（教师 ID、采集硬件、时间戳、同意状态）。示教情感向量：
```
e_k = (c_k, u_k, v_k, a_k) ∈ [0,1]×[0,1]×[-1,1]×[0,1]
```
分别表示 confidence（确信）、urgency（紧迫）、valence（效价）、arousal（唤醒）。`e` 由韵律特征 `φ(s_k)` 与文本语义 `ℓ(s_k)` 联合估计，估计器须给出校准置信度。

**定义 122（情感→约束编译器 Φ）**
`Φ: E → (r, h, g)`，`r∈[0,1]` 为示教可靠性权重，`h ∈ [h_0, h_max]` 为约束硬度，`g∈{allow, ask}` 为是否允许自主补采样。要求：
```
(M1) ∂r/∂c ≥ 0, ∂r/∂u_hesitation ≤ 0
(M2) ∂h/∂u ≥ 0 (当 v<0), ∂h/∂a ≥ 0 (当 v<0)
(M3) h(e) ≥ h_0  对所有 e   // 情感只能收紧，不能放宽
(M4) 冲突融合：r = min(r_lex, r_pros), h = max(h_lex, h_pros)
```
`h_0` 为第 54 轮 `A_cert` 的默认安全硬度。`Φ` 用保序回归/单调网络实现，保证 (M1)–(M3) 可验证。

**定义 123（情感条件下的动作剖面）**
对给定情感上下文 `e`，技能 `S` 的剖面用可靠性加权核估计：
```
α_S(a|e) = Σ_k r_k · K_h(a - a_k) · 1[||e_k - e||_Σ ≤ ε] / Σ_k r_k · 1[...]
```
其局部有效样本量 `ESS(a|e) = (Σ_k r_k 1[...])² / Σ_k r_k² 1[...]`，认知不确定性 `U(a|e) = 1/√ESS(a|e)`。**情感覆盖**：
```
cover_e(S, A_T) = 1  ⇔  ∀a∈A_T: α_S(a|e) ≥ θ_cov ∧ U(a|e) ≤ θ_U
```
当 `U(a|e) > θ_U` 且 `g=allow` 时，触发主动补采样（仿真或追加示教）；`g=ask` 时请求教师澄清，而不是猜。**示教边界即证书边界**：`a ∉ support(𝒟)` 时禁止外推。

**定义 124（情感域间隙 ADG）**
令 `P_teach` 为示教情感分布，`P_deploy` 为部署用户情感分布，`ψ` 为情感嵌入：
```
ADG(P_teach, P_deploy) = W_2(ψ_#P_teach, ψ_#P_deploy) + λ·|E_teach[h] - E_deploy[h]|
```
其中第二项度量“约束硬度语义”的漂移。证书只在 `ADG ≤ Δ_e` 时有效；`ADG > Δ_e` 时不是调阈值，而是触发**重新示教请求**或降级为“情感不可用、仅用运动证据”的保守模式。

**定义 125（示教-情感证书 D_cert）**
```
D_cert = (hash(π), support(𝒟), r̄, ESS_min, e_dist, δ_demo, ADG, ECE, consent)
```
- `support(𝒟)`：示教覆盖的动作子集；
- `δ_demo = d(α_S^demo, α_S^sim)`：示教剖面与仿真剖面的差异（模型偏差指示）；
- `ECE`：情感→可靠性/硬度映射的校准误差；
- `consent`：语音原始数据的使用授权与保存策略。

**定义 126（示教-情感联合证书 J_AD）**
```
J_AD = (ρ, A_cert, γ_ce, δ_a, D_cert, E_cert, evidence)
E_cert = (ADG, ECE, channel_conflict_log, per_user_gate)
```
部署判据（全部满足）：
```
ρ(d) ≥ ρ_min ∀d  ∧  δ_a ≤ Θ_a  ∧  cover_e(S,A_T)
∧ δ_demo ≤ Θ_d  ∧  ADG ≤ Δ_e  ∧  ECE ≤ ε_cal
```
任一不满足即拒绝部署；情感证据不得用于覆盖第 54 轮的动作/鲁棒性硬约束。

### IP-121 DAA（Demonstration-Affect Alignment）

```python
def align_demo_affect(traj, speech, aligner):
    units = aligner.forced_align(speech.words, speech.timestamps)
    segments = segment_motion(traj)
    pairs = []
    for seg in segments:
        ss = units.overlap(seg.t0, seg.t1)
        e, e_conf = estimate_epistemic_affect(ss.prosody, ss.text)
        pairs.append(ADU(seg, ss, e, e_conf))
    return merge_short(pairs, min_len=0.2)
```

### IP-122 A2C（Affect-to-Constraint Compiler）

```python
def compile_affect(e, e_conf, h0):
    r_lex = lexical_reliability(e.text)
    r_pros = prosody_reliability(e.prosody)
    r = min(r_lex, r_pros) * e_conf
    h = max(h0, hardness_from_urgency(e.urgency, e.valence))
    g = 'allow' if r >= r_query else 'ask'
    return r, h, g

def fit_monotone_compiler(data):
    return MonotoneCalibratedModel(data, axioms=[M1, M2, M3, M4])
```

### IP-123 ACP（Affect-Conditioned Profile）

```python
def affect_profile(demos, e_ctx, kernel, theta_cov, theta_U):
    num, den = defaultdict(float), defaultdict(float)
    for d in demos:
        if dist(d.e, e_ctx) > eps: continue
        for a in d.actions:
            num[a] += d.r * kernel(a - d.a)
            den[a] += d.r
    alpha = {a: num[a] / den[a] for a in num}
    ess = {a: (den[a] ** 2) / sum_r2[a] for a in num}
    U = {a: 1 / sqrt(ess[a]) for a in num}
    need = [a for a in A_T
            if alpha.get(a, 0) < theta_cov or U[a] > theta_U]
    return alpha, U, need
```

### IP-124 ADG（Affective Domain Gap）

```python
def affective_domain_gap(D_teach, D_deploy, psi, hardness, n_proj=64):
    X = [psi(e) for e in D_teach]
    Y = [psi(e) for e in D_deploy]
    w2 = sliced_wasserstein(X, Y, n_proj)
    dh = abs(mean([hardness(e) for e in D_teach]) -
             mean([hardness(e) for e in D_deploy]))
    return w2 + lam * dh
```

def demo_affect_certificate(demos, sim_profile, alpha_demo):

    delta_demo = profile_distance(alpha_demo, sim_profile)
    e_dist = fit_affect_distribution([d.e for d in demos])

def joint_affect_demo_certificate(J54, D_cert, ADG, ECE, budget):

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| DAA | O(T·W)（带带宽 DTW） | O(T) | 对齐置信门控 |
| A2C | O(|𝒟|) 推理；O(|𝒟| log|𝒟|) 拟合 | O(|𝒟|) | 单调性 (M1)–(M4) 可验证 |
| ACP | O(|𝒟|·|A_T|) | O(|A_T|) | ESS 覆盖、主动补采样 |
| ADG | O(n log n·L)（切片 Wasserstein） | O(n) | 置换检验控制假阳性 |
| DAC/ADJC | O(|𝒟| + |A|) | O(|A|) | 六项判据全部闭合 |

**正确性定理（Affect-Weighted Demonstration Certification Soundness）**
承接第 54 轮 (A22)–(A28)；新增：
**(A29)** 情感→可靠性/硬度映射满足 (M1)–(M4) 且 ECE ≤ ε_cal；
**(A30)** 在 `cover_e` 覆盖的动作上，示教与仿真剖面差 `δ_demo ≤ Θ_d`；
**(A31)** 部署情感分布与示教情感分布满足 `ADG ≤ Δ_e`。
则部署成功概率：
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - δ_cov - P(ADG>Δ_e)
            - ε_cal - δ_demo - β_E
```
**命题（情感单向性的安全单调性）**：由于 Φ 满足 (M3) `h(e) ≥ h_0` 且情感不进入奖励，情感层相对“无情感基线”只会收紧可行域，不会增加安全违约率；其代价是可能牺牲成功率。即“情感可以让人更保守，但不能让人更冒险”。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 情感识别噪声/文化差异 | 高 | 个体基线校准 + 只取相对变化 + 保守融合 |
| 示教覆盖稀疏、因果混淆 | 高 | 先证后学 + 主动补采样 + 仿真交叉验证 |
| 情感被策略利用/操纵 | 高 | 情感不进奖励 + 单向收紧 + 审计日志 |
| 语音隐私与同意 | 高 | 端侧处理 + 仅存特征 + consent 进入证书 |
| ADG 门控过严导致拒部署 | 中 | 降级到运动证据模式 + 快速重新示教 |
| DTW 对齐错误 | 中 | 多模态对齐 + 置信门控 + 人工抽检 |

## 6. 本轮最大风险

**一句话**：本方案把“示教轨迹 + 教师情感韵律”升格为证书证据，但其 soundness 依赖一个危险的同源假设——**教师情感是可校准、可迁移的监督信号**；一旦情感校准在跨教师/跨文化/跨用户时失效，ADG 门控要么放行虚假证据、要么过度拒部署，证书会在“看起来更懂人”的同时系统性学偏，故必须以 **情感单向收紧 + 保守冲突融合 + 独立用户门控** 把情感严格限制为“只能降低信任、不能放宽安全”的辅助证据。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（DAA×A2C×ACP×ADG×DAC×ADJC）

> 承接第 54 轮产物 v31。本轮回答“证书的证据从哪来、教师的副语言信号算不算证据”，新增 **示教-情感层 ATP（Affective Teaching Protocol）**：
> - **DAA（Demonstration-Affect Alignment）**：把语音单元与动作片段对齐为情感示教单元 ADU；
> - **A2C（Affect-to-Constraint Compiler）**：把示教情感编译为“可靠性权重 + 约束硬度”，且只收紧不放宽；
> - **ACP（Affect-Conditioned Profile）**：用可靠性加权示教估计情感条件下的动作剖面与认知不确定性；
> - **ADG（Affective Domain Gap）**：度量教师情感分布与部署用户情感分布之间的间隙；
> - **DAC（Demo-Affect Certificate）**：把示教覆盖、溯源、校准、同意写进证书；
> - **ADJC（Affect-Demo Joint Certificate）**：与第 54 轮 `(ρ, A_cert)` 联合生效的四证书。
>
> IP 编号：IP-121~IP-126（共 6 个新增）；升级 IP-115/117/118 以接收示教证据与情感门控。核心识别：**证据-扰动同源**——情感语音既是示教的元标注，又是部署分布的一部分，证书必须显式携带 `ADG` 才能谈 soundness。

### IP-123 ACP

```python
def affect_profile(demos, e_ctx, kernel, eps, theta_cov, theta_U):
    num, den, den2 = defaultdict(float), defaultdict(float), defaultdict(float)
    for d in demos:
        if dist(d.e, e_ctx) > eps: continue
        for a, r in zip(d.actions, d.reliabilities):
            num[a] += r * kernel(a - d.a)
            den[a] += r
            den2[a] += r * r
    alpha = {a: num[a] / den[a] for a in num}
    ess = {a: den[a] ** 2 / den2[a] for a in num}
    U = {a: 1 / sqrt(ess[a]) for a in num}
    need = [a for a in A_T
            if alpha.get(a, 0) < theta_cov or U[a] > theta_U]
    return alpha, U, need
```

**示教边界即证书边界**：`a ∉ support(𝒟)` 时禁止外推；`g=allow` 时主动补采样，`g=ask` 时请求教师澄清。该策略把 LfD 的多模态与 covariate shift 挡在证书之外。

### IP-124 ADG

```python
def affective_domain_gap(D_teach, D_deploy, psi, hardness, n_proj=64):
    X = [psi(e) for e in D_teach]
    Y = [psi(e) for e in D_deploy]
    w2 = sliced_wasserstein(X, Y, n_proj)
    dh = abs(mean([hardness(e) for e in D_teach]) -
             mean([hardness(e) for e in D_deploy]))
    score = w2 + lam * dh
    p = permutation_test(X, Y, n_perm=999)
    return score, p
```

`ADG > Δ_e` 时不调阈值，直接触发重新示教或降级到“仅运动证据”模式；门控按用户簇分别维护，避免整体平均掩盖单一用户漂移。

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| DAA | O(T·W) | O(T) | 对齐置信门控，低置信段降权 |
| A2C | O(|𝒟|) 推理；O(|𝒟| log|𝒟|) 拟合 | O(|𝒟|) | (M1)–(M4) 可验证，ECE 可测 |
| ACP | O(|𝒟|·|A_T|) | O(|A_T|) | ESS 覆盖，超出 support 不外推 |

| DAC/ADJC | O(|𝒟|+|A|) | O(|A|) | 六项判据闭合，失败即拒 |

**正确性定理（Affect-Weighted Demonstration Certification Soundness）**
承接第 54 轮 (A22)–(A28)；新增：
**(A29)** 情感→可靠性/硬度映射满足 (M1)–(M4) 且 ECE ≤ ε_cal；
**(A30)** 在 `cover_e` 覆盖的动作上 `δ_demo ≤ Θ_d`；
**(A31)** 部署情感分布与示教情感分布满足 `ADG ≤ Δ_e`。
则：
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - δ_cov - P(ADG>Δ_e)
            - ε_cal - δ_demo - β_E
```
**命题 1（安全单调性）**：因 `h(e) ≥ h_0` 且情感不进奖励，ATP 层相对无情感基线只会收紧可行域，不增加安全违约率，代价是可能牺牲成功率。

**命题 2（证据-扰动同源下界）**：设 `D_teach` 全部来自同一教师，则无论增加多少条示教，`ADG(P_teach,P_deploy)` 不下降；因此 `P(ADG>Δ_e)` 是**不可由同源示教消除的 irreducible term**。这解释了“情感回声悖论”，也给出了必须引入跨用户校准/门控的理论依据。

**推论（先证后学的收益）**：把示教仅用于覆盖/约束证据、而非行为克隆，可避免 covariate shift 直接进入策略；策略学习误差被隔离在 `J_AD` 之外，证书可在策略替换时保持有效。

## 6. 本轮最大风险

**一句话**：本方案把“示教轨迹 + 教师情感韵律”升格为证书证据，但其 soundness 依赖一个危险的同源假设——**教师情感是可校准、可迁移的监督信号**；一旦情感校准在跨教师/跨文化/跨用户时失效，ADG 门控要么放行虚假证据、要么过度拒部署，证书会在“看起来更懂人”的同时系统性学偏，故必须以 **情感单向收紧 + 保守冲突融合 + 独立用户门控** 把情感严格限制为“只能降低信任、不能放宽安全”的辅助证据。
