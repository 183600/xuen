# 第 1 轮（新灵感循环）·「四足机器人」×「微调」：把“扰动恢复”从一个模块变成一套可微调的训练配方

> 承接 v2 的 UIP-01′~15。前两轮回答“在远程 `observation→action` 接口内要做什么”；本轮回答一个更根上的问题：**“检测进度被撤回→重做”这项能力，参数从哪里来、数据从哪里来、怎样微调才不把基座的泛化性训坏？**
> 结论先行：四足机器人真正可迁移的不是“四条腿”，而是它已被反复验证的训练栈——**特权教师→学生蒸馏、步态/技能库+残差、地形/推力课程、域随机化**；“微调”则把答案收紧为**单模型下的 LP-FT/低秩适配 + 权重插值 + OOD 选模**。两者合起来，构成本轮旗舰：**PTS × TRC × RFT 的“恢复能力微调管线”**。

## 0. 事实基线（承接 2026-11-12，本轮不重复检索）

| 已核实约束 | 内容 | 对本轮的含义 |
|---|---|---|

**本轮新增的工作假设（需验证，不作为事实）**：
- **H0**：官方基座大概率已在同源 32 任务数据上预训练或微调过；若成立，则在 32 个数据集上“再全量微调一遍”的边际收益低，真正的增量在**执行期分布偏移与扰动恢复**。
- **H6**：公开数据里的动作片段足以构造“进度撤回”的**反事实观测**（见 §2.6 TRC），从而在完全不引入外部数据的前提下训练撤回检测。

## 1. 先给直觉：四足机器人教我们的不是“走路”，而是“怎么学会不摔倒”

### 1.1 四足训练栈的四件套

四足在野外能活下来，靠的不是一个端到端大模型，而是一套结构：

1. **特权教师（privileged teacher）**：训练时能看到地形高度、摩擦、外部推力、机体速度、接触状态等真值；因此在仿真里能学会“被推一下如何站稳/迈步恢复”。
2. **学生蒸馏（student distillation）**：部署时看不到特权信息，只靠本体感觉（关节角、速度、力矩、IMU）和深度/视觉；用一个**历史编码器**从近期 `(o,a)` 序列推断出“当前环境/扰动”的隐变量，再据此行动。代表性的 RMA 思路就是“环境参数由历史推断，策略条件化在隐变量上”。
3. **步态库 + 选择器 + 残差**：不要求一个网络从零生成所有步态，而是准备一组参数化步态原语（walk/trot/pace/bound），由选择器选型、残差策略做局部修正。
4. **课程 + 域随机化**：地形由平到陡、推力由小到大、摩擦/负载/延迟随机化；先学会走，再学会被推，再学会被推倒后恢复。

### 1.2 迁移到 UniBot：把“被推一下”换成“被撤回一步”

桌面操作里的人类干扰，结构上与“被推一下”同构：**已经拿到的进度被外力抹掉，但任务没有结束**。差别是：

- 四足恢复是连续的、毫秒级、本体感觉闭环；
- 操作恢复是离散的（重抓/重对准/重新插入）、观测只在块边界、折叠/插入等接触**不可逆**。

这个差别恰好给出本轮的设计原则：**把“反射”做成可蒸馏的隐变量与技能原语，把“恢复决策”放在块边界，把“训练”放在离线**。这也与 v2 的 UIP-01′/09′/13/15 完全兼容——本轮只是补上它们缺失的**参数与数据来源**。

### 1.3 微调：不是“再训一遍”，而是“补基座没有的能力”

“微调”这个词容易诱导一个错误动作：把 32 个公开数据集混在一起，把基座全参数再训一轮。直觉上这有三个问题：

1. **任务知识可能已经在了**（H0），重复训练只增加过拟合；
2. **公开数据没有人扰恢复样本**，全量微调学不会“被撤回后怎么办”；
3. **评测是分布偏移的**（位置/干扰物/背景/未见物品/人扰五轴），朴素全量微调会**扭曲基座特征**，把零样本泛化换成了训练集拟合。

所以本轮把“微调”拆成三个可控旋钮：

- **微调什么参数**：全参数 / LP-FT（先线性探测再解冻）/ LoRA 或适配器 / 只训技能选择器与参数头；
- **用什么数据微调**：公开演示 + 物理仿真恢复数据 + **由公开演示做时间反演得到的反事实数据**；
- **用什么目标微调**：动作损失 + 教师蒸馏 + 撤回检测 + 对基座的保真正则（防遗忘）。

## 2. 再给严谨定义

### 2.1 任务、观测与特权状态

把第 $j$ 个任务写成部分可观测决策过程 $\mathcal M_j=(\mathcal S,\mathcal O,\mathcal A,T,\Phi)$：

- $o_t\in\mathcal O$：接口可得的观测（多路图像、关节状态、语言、历史）；
- $x_t\in\mathcal X$：**特权状态**（物体真值位姿、接触标志、摩擦、外力、基座速度、当前计分步），只在离线仿真/教师侧可见；
- $a_t\in\mathcal A$：接口动作（关节目标或末端位姿，含 `pivot` 等）；
- $\Phi:\mathcal S\to[0,100]$：**进度势函数**，定义为已完成计分步的累计权重。若计分步权重为 $w=(w_1,\dots,w_m)$，当前完成到第 $L$ 步，则 $\Phi= \sum_{i\le L} w_i$。

### 2.2 进度撤回算子

**定义 1（撤回事件）**：在时刻 $\tau$ 发生人为干扰，若任务进度从 $L$ 回退到 $r\le L$，即
$$
\Phi(s_{\tau^+})-\Phi(s_{\tau^-}) = -\sum_{i=r+1}^{L} w_i < 0,
$$
则称发生一次**进度撤回（regression）**。撤回强度定义为被抹掉的分数
$$
m=\sum_{i=r+1}^{L} w_i,\qquad m\in(0,100].
$$

**定义 2（撤回风险）**：若当前处于第 $L$ 步，则后缀风险为
$$
\mathrm{VaR}(L)=\sum_{i=L+1}^{m} w_i .
$$
恢复策略的目标不是最大化“下一步成功率”，而是
$$
\max\ \mathbb E\big[\Phi_T\big]\quad\text{s.t.}\quad \text{延迟与可信度预算}.
$$
这解释了为什么“检测到撤回就重做”在计分上是对的：它保的是**前缀分**，而不是赌整集成功。

### 2.3 技能/步态库与残差

**定义 3（参数化技能原语库）**：令
$$
\Pi=\{\pi_i(\cdot;\phi)\}_{i=1}^{K},\qquad \phi\in\Phi_i,
$$
其中每个原语是一段可执行的低层控制（如 `reach/grasp/lift/place/insert/twist/fold/zip/pour/stack/sort`），$\phi$ 是目标位姿、接近方向、速度、力限、相位时长等参数。高层策略输出
$$
(u_t,\phi_t)=\sigma(o_{\le t}),\qquad a_t=\pi_{u_t}(\cdot;\phi_t)+\rho(o_{\le t}),
$$
$\sigma$ 为选择器，$\rho$ 为残差策略。四足的“步态库+选择器+残差”在这里变成“操作技能库+选择器+残差”。

**定义 4（相位边界）**：每个原语有一个相位时钟 $\varphi_t\in[0,1]$，$\varphi=0/1$ 为接触安全点。块边界若落在 $\varphi\approx0/1$，则称**相位对齐块边界**。这为 v2 的 UIP-13（自适应块长）提供了物理约束：**不要把开环块截断在插入中途、拉链半开或折叠半程。**

### 2.4 特权教师—学生蒸馏

**定义 5（教师与学生）**：
$$
\text{教师：}\ \pi_T(a_t\mid o_t,x_t),\qquad
\text{学生：}\ \pi_S(a_t\mid o_t,z_t),\quad z_t=E_\psi(o_{t-h:t},a_{t-h:t}),
$$
其中 $z_t$ 是**扰动/接触隐变量**（环境编码），$E_\psi$ 是历史编码器。教师只在离线训练时使用，部署时不存在。

**定义 6（蒸馏目标）**：
$$
\mathcal L_{\text{distill}}
=\mathbb E_{(o,x,a)\sim\mathcal D}\Big[
-\log \pi_S(a\mid o,z)
+\lambda_{\mathrm{kl}}\,D_{\mathrm{KL}}\big(\pi_T(\cdot\mid o,x)\,\|\,\pi_S(\cdot\mid o,z)\big)
+\lambda_z\|z\|_2^2
\Big].
$$
可加 DAgger 项：用学生 rollout 的观测让教师重新标注动作，减少协变量偏移。

### 2.5 扰动课程

**定义 7（撤回课程）**：一次训练扰动由三元组 $c=(m,\tau,\nu)$ 描述：撤回强度 $m$、发生时刻 $\tau$、撤回速度 $\nu$。课程是一个分布序列
$$
p_0(c)\prec p_1(c)\prec\cdots\prec p_{K}(c),
$$
从“无扰动/小 $m$/远离接触点”逐步过渡到“大 $m$/接触密集步/快速撤回”。训练时按学生当前恢复成功率自适应推进（类似地形课程）。

### 2.6 时间反演反事实（TRC）

公开演示只有“正向完成”，没有“被撤回”。但规则告诉我们，人扰大量是**把已完成进度反向撤回**。因此可以用公开演示构造反事实：

1. 取一条成功演示 $\tau=(o_0,a_0,\dots,o_T)$，找到进度势单调上升的片段 $[i,j]$（$\Phi$ 从低到高）；
2. 构造反事实观测序列：从已完成态 $o_j$ 出发，倒放该片段得到 $o_{j-1},o_{j-2},\dots,o_i$，模拟“被撤回”；
3. 训练目标：在反事实观测之后，模型应输出**正向恢复动作** $a_i,a_{i+1},\dots,a_{j-1}$，把进度重新做回去；
4. 标签：在拼接点处 $y_\tau=1$（发生撤回），此前 $y=0$，用于训练撤回检测器。

**严谨边界**：时间反演的动作本身通常不满足真实动力学（摩擦、重力、接触不可逆），所以 **TRC 只用于“观测/检测/恢复动作标签”的增强，不作为唯一的动力学来源**；物理可行的恢复数据仍由 v2 的 UIP-12 DRF（仿真扰动工厂）提供。两者是“便宜的反事实”与“可信的物理”之互补。

### 2.7 鲁棒微调

**定义 8（LP-FT 与权重插值）**：设基座参数 $\theta_0$，在混合数据上微调得到 $\theta_{\mathrm{ft}}$。

- **LP-FT**：先冻结骨干、只训动作头/适配器（线性探测阶段），再解冻做低学习率微调；
- **权重插值**：$\theta_\alpha=\alpha\theta_0+(1-\alpha)\theta_{\mathrm{ft}}$，$\alpha\in[0,1]$；
- **选模**：在构造好的 OOD 验证集上选 $\alpha$ 与检查点，而不是在训练分布上选。

**定义 9（OOD 验证集）**：按五个泛化轴构造与训练集**场景级不重叠**的验证集：未见物品实例、位置偏移、干扰物、背景/光照、人为撤回（TRC+DRF）。"场景级不重叠"是防止泄漏的关键。

### 2.8 本体感觉撤回签名

**定义 10（本体感觉残差）**：设关节参考 $q_t^{\mathrm{ref}}$ 与实际 $q_t$，跟踪误差 $e_t=q_t-q_t^{\mathrm{ref}}$，力矩/电流残差 $s_t$。定义撤回/滑移签名
$$
\psi_t=\big(\|e_t\|,\ \|s_t\|,\ \dot e_t,\ \text{gripper force},\ \text{base IMU}\big).
$$
一个轻量时序检测器 $D_\omega(\psi_{t-h:t})\to[0,1]$ 输出“进度被撤回/抓取滑移”的概率。它与视觉验证器做**对数几率融合**：
$$
\mathrm{logit}\,P(\text{regressed})=\mathrm{logit}\,P_{\text{vis}}+\mathrm{logit}\,P_{\text{prop}}+\mathrm{bias}.
$$
优点是：视觉被遮挡、JPEG 压缩、光照变化时仍可用；且检测器可以是主骨干内的小头，满足单模型合规。

## 3. 瓶颈假设（本轮更新）

- **H1（最高杠杆）**：恢复能力的主要瓶颈不是“有没有验证器”，而是**验证器与恢复策略没有训练信号**。四足式“特权教师+学生隐变量”能在不增加推理期外部模型的前提下补上这个信号。
- **H2（微调悖论）**：在 32 任务上全量微调会提升训练分布内成功率，却可能降低五轴 OOD；**LP-FT + 权重插值 + OOD 选模**应显著缩小这个 trade-off。若 H2 不成立，则“微调”退化为“只训检测/恢复小头”。
- **H3（数据可行性）**：TRC 能用公开演示造出“撤回检测”的监督，但造不出物理可信的恢复动作；因此 **TRC 负责“看见撤回”，DRF/真机负责“学会恢复”**。
- **H4（参数化）**：技能库把动作空间从“高维连续块”压成“原语选择+低维参数”，使微调自由度大幅下降，可能只用选择器/参数头就能适配新任务，降低灾难性遗忘。
- **H5（合规不确定性）**：仿真数据、外部数据、微调本身是否被允许仍未从手册核实；必须保留**仅公开数据的 TRC + 运行时恢复**这条合规退路。

## 4. 与 v2 清单的关系：升级、合并、新增

- **升级 UIP-09′ → UIP-09″（DCR-R+）**：撤回检测从手工几何规则，升级为“视觉验证 + 本体感觉签名 + 学习式隐变量”的融合；恢复动作由 PTS 蒸馏得到。
- **升级 UIP-12 → UIP-12′（DRF+）**：数据工厂除了仿真“反向撤回”，新增 TRC 反事实分支（仅用公开数据）与课程采样器。
- **升级 UIP-14 → UIP-16（GSL）**：把“模块化技能路由”具体化为“参数化技能/步态库 + 选择器 + 残差”，并成为微调的低维参数化底座。
- **继承 UIP-01′/02′/11/13/15**：滚动验证、计分步安全网、仿真 oracle、自适应块长、可信度安全阀不变；本轮只替换它们的“能力来源”。
- **新增**：
  - **UIP-16 GSL**（Gait/Skill Library + residual fine-tuning）；
  - **UIP-17 PTS**（Privileged Teacher–Student distillation）；
  - **UIP-18 TRC**（Time-Reversal Counterfactual augmentation）；
  - **UIP-19 RFT**（Robust Fine-Tuning：LP-FT + 插值 + OOD 选模）；
  - **UIP-20 PSR**（Proprioceptive Regression Signature）。

**旗舰**：**UIP-17 PTS × UIP-18 TRC × UIP-19 RFT** 组成的“恢复能力微调管线”，由 **UIP-16 GSL** 提供动作参数化，由 **UIP-20 PSR** 提供运行期检测，最终接入 v2 的 UIP-01′/09″ 状态机。

## 5. 本轮最大风险

**一句话**：如果“微调”在赛规里受限、或官方基座并未在同源数据上预训练，那么本轮整套“先蒸馏再鲁棒微调”的收益会大幅缩水；此时必须能一键退回“只用公开数据做 TRC + 运行时恢复”的合规路径。

## 2. UIP-18 · TRC：用时间反演从公开演示造“被撤回”监督

### 2.1 构造

给定一条成功演示 $\tau=(o_0,a_0,\dots,o_T)$ 与进度势 $\Phi$，切出单调上升片段 $[i,j]$（$\Phi$ 在该片段内非降且至少跨过一个计分步）。构造两个样本：

- **正样本（撤回）**：上下文为倒放观测
  $$
  \tilde o=(o_j,o_{j-1},\dots,o_i),
  $$
  目标动作为正向恢复动作 $a_{i:j}=(a_i,\dots,a_{j-1})$，撤回标签 $y=1$。
- **负样本（正常）**：上下文为正向观测 $o_{i:j}$，目标动作同为 $a_{i:j}$，$y=0$。

**监督信号的双重用途**：
- 训练撤回检测器：$D_\omega(o_{\le t})\to y$；
- 训练恢复策略：给定“已经退回 $o_i$”的上下文，输出把进度做回 $o_j$ 的动作序列。

### 2.2 算法

```python
def build_trc(demo, phi, min_len=3, max_len=None):
    """demo: (obs[0..T], act[0..T-1]); phi: progress potential at each t."""
    out = []
    for (i, j) in monotone_segments(phi, min_len=min_len, max_len=max_len):
        if j - i < min_len:
            continue
        ctx_rev = [demo.obs[j], demo.obs[j-1], ..., demo.obs[i]]   # 倒放观测
        target  = demo.act[i:j]                                     # 正向恢复动作
        out.append(Sample(ctx=ctx_rev, target=target, label=1, source="trc"))
        ctx_fwd = demo.obs[i:j]
        out.append(Sample(ctx=ctx_fwd, target=target, label=0, source="trc"))
    return out
```

### 2.3 严谨边界与修正

时间反演不满足真实动力学（摩擦、重力、接触不可逆），所以必须限制其用途：

1. **只用于“观测/检测/恢复动作标签”的增强**，不把倒放动作当作真实动作执行；
2. **动作目标始终取正向演示动作**，而不是倒放动作；
3. 用**片段长度 $j-i$** 作为撤回强度 $m$ 的代理，做课程采样；
4. 用 DRF 的物理可行样本做**一致性校验**：若 TRC 训练出的检测器在 DRF 上 AUROC 明显下降，则说明反事实存在域差，需要域随机化或只保留检测用途。

### 2.4 与 v2 的 UIP-12 合并

- **TRC 分支**：零外部数据、便宜、覆盖广，负责“看见撤回”；
- **DRF 分支**：物理可信、可含接触、负责“学会恢复”；
- 采样权重按任务的人扰类型设置：对“叠好后翻开/拉上后再拉开/合上后再打开”等**可逆型**，TRC 权重大；对“把锁拿走/挪底座”等**不可逆/移动型**，DRF 权重大。

## 3. UIP-17 · PTS：特权教师→学生隐变量蒸馏

### 3.1 教师：两种可行形态

| 形态 | 输入 | 训练方式 | 适用 | 风险 |
|---|---|---|---|---|
| **T-SUP（默认）** | $o_t$ + 特权 token $x_t$（物体真值位姿、接触、撤回标签、摩擦） | 在 $D_{\text{pub}}\cup D_{\text{drf}}$ 上监督微调同一 VLA，特权信息作为额外 token | 长程操作、算力有限 | 教师质量受仿真标注精度限制 |
| **T-RL（可选）** | $o_t$ + 特权状态 | 在仿真中用非对称 actor-critic / PPO 微调恢复原语 | 接触密集的短技能 | 训练不稳定、sim2real gap |

**关键工程**：不要把教师做成另一个大模型。教师与学生共享同一骨干，教师只是**多了若干特权 token** 的训练期变体；这样蒸馏是“同架构、不同输入”的自蒸馏，参数效率高，也避免“多模型”歧义。

```python
class PrivilegedTeacherStudent(nn.Module):
    def __init__(self, backbone, action_head, state_encoder, z_dim=32):
        self.backbone = backbone
        self.action_head = action_head
        self.priv_proj = nn.Linear(x_dim, d_model)   # 特权 token 投影
        self.z_enc = state_encoder                   # 历史编码器 E_ψ
        self.z_proj = nn.Linear(z_dim, d_model)

    def teacher(self, o, x):
        tokens = self.backbone.encode(o) + [self.priv_proj(x)]
        return self.action_head(self.backbone(tokens))

    def student(self, o_hist):
        z = self.z_enc(o_hist)                       # 从 (o,a) 历史推断扰动
        tokens = self.backbone.encode(o_hist[-1]) + [self.z_proj(z)]
        return self.action_head(self.backbone(tokens)), z
```

### 3.2 学生：隐变量 $z_t$ 推断“看不见的扰动”

学生只拿到接口观测，但历史里保留了“刚刚发生了什么”的痕迹：关节跟踪误差、被抓物体是否还在手中、图像中物体位姿是否回退。编码器
$$
z_t=E_\psi(o_{t-h:t},a_{t-h:t})
$$
把这些痕迹压成一个低维扰动码。它类似四足的 RMA 环境编码器，但推断的是“进度/接触/外力”而不是地形。

**为什么这比手工规则强**：
- 手工几何验证器只能判“当前子目标是否 done”，难以区分“被撤回”和“正常过渡”；
- 隐变量可以利用**时序差分**与**本体感觉**，在视觉模糊时仍工作；
- 隐变量是连续的低维表示，可被蒸馏目标直接监督，不需要额外标注。

### 3.3 蒸馏目标与 DAgger

$$
\mathcal L_{\text{PTS}}
=\underbrace{\mathbb E[-\log \pi_S(a\mid o,z)]}_{\text{动作模仿}}
+\lambda_{\mathrm{kl}}\underbrace{\mathbb E[D_{\mathrm{KL}}(\pi_T(\cdot\mid o,x)\|\pi_S(\cdot\mid o,z))]}_{\text{教师软标签}}
+\lambda_z\underbrace{\mathbb E[\|z\|_2^2]}_{\text{码本正则}}
+\lambda_r\underbrace{\mathbb E[\mathrm{BCE}(D_\omega(o),y)]}_{\text{撤回检测}}
$$

DAgger 轮次（建议 2–3 轮）：
1. 用当前学生在仿真/回放环境 rollout，收集学生访问到的状态；
2. 教师在这些状态上用特权信息给出动作与软标签；
3. 把新样本加入 $D_{\text{agg}}$，继续蒸馏。

**收敛判据**：学生恢复成功率 ≥ 教师的 $70\%$，且学生不再访问特权输入。若低于 $30\%$，判定蒸馏失败，回退到“只用手工验证器 + TRC 检测”。

### 3.4 运行期不变式

- 不更新任何权重；$z_t$ 与检测概率都是前向计算。
- 教师不参与推理；提交物只有一个学生 checkpoint。
- 若延迟预算紧张，可把 $z$ 编码器做成小 GRU/TCN，或直接复用主骨干的末端隐状态。

## 4. UIP-19 · RFT：单模型鲁棒微调，别把基座泛化训坏

### 4.1 数据混合

$$
D_{\text{mix}}=w_{\text{pub}}D_{\text{pub}}+w_{\text{trc}}D_{\text{trc}}+w_{\text{drf}}D_{\text{drf}}+w_{\text{teacher}}D_{\text{teacher}}.
$$

默认权重（以公开数据为主）：$w_{\text{pub}}=1.0,\ w_{\text{trc}}=0.5,\ w_{\text{drf}}=0.5,\ w_{\text{teacher}}=0.3$。若合规开关关闭仿真/教师数据，则 $w_{\text{drf}}=w_{\text{teacher}}=0$，退化为“公开 + TRC”。

### 4.2 三阶段配比

| 阶段 | 冻结/可训 | 数据 | 目的 |
|---|---|---|---|
| **A. 线性探测（LP）** | 冻结 VLM 骨干；只训动作头、$z$ 编码器、PSR/检测头 | $D_{\text{mix}}$ | 先把新能力装到“输出端”，避免特征被早期梯度扭曲 |
| **B. 低秩适配（LoRA/Adapter）** | 解冻 LoRA（rank 16–32）+ 上述头；骨干主体冻结 | $D_{\text{mix}}$ | 以极少参数适配接触/恢复，保留基座特征 |
| **C. 权重插值与选模** | 不训练；在 $\theta_0$ 与 $\theta_{\mathrm{ft}}$ 之间插值 | OOD 验证集 | 在 ID 与 OOD 之间选 Pareto 膝点 |

### 4.3 权重插值：为什么会有效（一阶直觉，不是定理）

令 $\theta_{\mathrm{ft}}=\theta_0+\Delta$，插值 $\theta_\alpha=\theta_0+(1-\alpha)\Delta$。对 OOD 风险做一阶展开：
$$
R_{\text{out}}(\theta_\alpha)
\approx R_{\text{out}}(\theta_0)+(1-\alpha)\,\nabla R_{\text{out}}(\theta_0)^\top\Delta+O(\|\Delta\|^2).
$$
若微调方向在 OOD 上是有害的（$\nabla R_{\text{out}}^\top\Delta>0$），则取 $\alpha<1$ 可把 OOD 退化从 $O(\|\Delta\|)$ 压到 $O((1-\alpha)\|\Delta\|)$，代价是 ID 收益也按 $(1-\alpha)$ 缩水。于是存在一个由 OOD 验证集决定的折中点。**注意**：这是一阶局部论证；当 $\|\Delta\|$ 很大或 OOD 梯度方向改变时可能失效，所以必须用 OOD 选模而不是拍脑袋取 $\alpha=0.5$。

LP-FT 的补充直觉：先线性探测可以避免“随机初始化的新头”在早期把骨干特征拉走，降低特征畸变，从而让后续微调更接近“在原特征上做小修正”。

### 4.4 OOD 验证集：五轴、场景级不重叠

| 轴 | 构造方式 | 防泄漏要求 |
|---|---|---|
| 未见物品 | 按物体实例/类别分组留出 | 同一实例不得同时出现在训练与验证 |
| 位置 | 按初始位置分箱留出（左/右/前/后） | 同一场景的多机位不得跨集 |
| 干扰物 | 加入未在训练出现的干扰物 | 干扰物实例留出 |
| 背景/光照 | 换背景、色温、亮度、JPEG 质量 | 按背景分组 |
| 人为撤回 | TRC + DRF 生成；按撤回类型/强度分层 | 撤回轨迹不得来自验证场景 |

**选模目标**：
$$
J(\theta)=\text{Success}_{\text{OOD}}+\lambda_s\frac{\text{StepScore}_{\text{OOD}}}{100}-\lambda_\ell\,\mathrm{p95Latency}-\lambda_c\,\text{CredibilityRisk}.
$$
约束：$\text{Success}_{\text{ID}}$ 不低于基座 $-\epsilon$（例如 $\epsilon=2$ 个点）。只有同时满足 ID 不降、OOD 提升的检查点才进入候选。

### 4.5 参考超参（起点，不是结论）

| 项 | 值 |
|---|---|
| 骨干 | 官方基座；bf16；冻结主体（阶段 A） |
| LoRA rank / alpha | 16 / 32（阶段 B 可扫 8/16/32） |
| 学习率（头 / LoRA） | $1\times10^{-4}$ / $1\times10^{-5}$ |
| batch / epoch | 32 / 3–5 |
| warmup / clip | 5% / 1.0 |
| 插值 $\alpha$ | $\{1.0,0.75,0.5,0.25,0\}$ 网格，OOD 选模 |
| 正则 | L2-SP 到 $\theta_0$（$10^{-3}$）；可选 OOD 锚点 KL |
| 蒸馏温度 | 2.0（软标签） |

### 4.6 伪代码

```python
def robust_finetune(base, teacher, D_pub, D_trc, D_drf, ood_val):
    theta0 = clone(base.state_dict())
    D_mix = mix(D_pub, D_trc, D_drf, weights=(1.0, 0.5, 0.5))

    # A. linear probe
    freeze(base.backbone)
    train(base.head_and_encoders(), D_mix, lr=1e-4, epochs=2)

    # B. low-rank adapt
    add_lora(base, rank=16, alpha=32)
    train(base.lora_and_heads(), D_mix,
          loss=lambda b: action_loss(b) + 0.5 * distill_kl(teacher, b)
                         + 0.1 * reversal_bce(b) + 1e-3 * l2sp(base, theta0),
          lr=1e-5, epochs=3)
    theta_ft = clone(base.state_dict())

    # C. interpolate + OOD select
    best = None
    for alpha in [1.0, 0.75, 0.5, 0.25, 0.0]:
        theta = interp(theta0, theta_ft, alpha)
        m = evaluate(theta, ood_val)
        if m.id_success >= m.id_base - 2 and (best is None or m.J > best.J):
            best = (alpha, theta, m)
    return best
```

## 5. UIP-16 · GSL：技能/步态库把微调自由度压下来

### 5.1 原语库

| 原语 | 参数 $\phi$ | 典型任务 | 关键接触 |
|---|---|---|---|
| `reach` | 目标位姿、接近向量、速度 | 全部 | 无 |
| `grasp` | 抓取点、宽度、力限、闭合速度 | 抓取类 | 摩擦/滑移 |
| `lift` / `place` | 高度、放置姿态、释放速度 | 搬运/堆叠 | 稳定性 |
| `insert` | 对位位姿、插入深度、力阈值、微调步长 | 插网线/插头/钥匙 | 公差/卡阻 |
| `twist` | 轴、角度、力矩上限 | 开锁/拧瓶盖 | 旋转接触 |
| `fold` | 折线、次数、压实力 | 叠毛巾/叠衣 | 可逆形变 |
| `zip` | 起点、方向、张力 | 拉链 | 连续接触 |
| `pour` | 倾角、流速、停止条件 | 倒药/倒水 | 液体/颗粒 |
| `stack` | 目标层、对中容差 | 叠碗/纸杯 | 堆叠稳定 |
| `sort` | 颜色/类别条件、目标槽 | 分拣 | 语义+放置 |

### 5.2 选择器 + 残差

高层输出 $(u_t,\phi_t)$，低层原语执行，残差 $\rho$ 只做小修正。微调时可以只训：

- 选择器头（$u_t$ 分类）与参数回归头（$\phi_t$）；
- 或再叠加低秩适配器。

**假设 H4 的可证伪形式**：只训选择器/参数头（<5% 参数）即可在新任务上达到全量微调 90% 的成功率，且 OOD 退化更小。若达不到，则 GSL 的“降维”假设不成立。

### 5.3 相位对齐的块边界

相位时钟 $\varphi_t$ 到 $0/1$ 时是接触安全点。与 UIP-13 联动：

```python
def pick_chunk_length(phase, stage, k_max):
    # 优先让块结束在相位边界，其次才考虑固定 k
    for k in range(k_max, 0, -1):
        if crosses_phase_boundary(phase, k) is False:
            return k
    return 1   # 最保守：每步重观测
```

这条规则不改模型、不改接口，只改“块在哪里结束”，是最便宜的恢复性提升。

## 6. UIP-20 · PSR：本体感觉撤回签名

### 6.1 特征与检测器

$$
\psi_t=\big(\|q_t-q_t^{\mathrm{ref}}\|,\ \|\tau_t-\tau_t^{\mathrm{ref}}\|,\ \dot e_t,\ f_t^{\mathrm{grip}},\ a_t^{\mathrm{IMU}}\big).
$$

检测器 $D_\omega$ 用 1D 卷积/GRU 处理 $\psi_{t-h:t}$，输出撤回/滑移概率。训练标签来自：
- TRC 的拼接点（撤回标签）；
- DRF 的物理撤回事件；
- 可选的真机少量标注（若允许）。

### 6.2 与视觉验证器融合

$$
\mathrm{logit}\,P(\text{regressed})
=\mathrm{logit}\,P_{\text{vis}}(o_t,g)
+\mathrm{logit}\,P_{\text{prop}}(\psi_{t-h:t})
+b.
$$

融合的好处：视觉被遮挡/JPEG 压缩/光照变化时，本体感觉仍能提供证据；而本体感觉无法区分“被撤回”与“正常释放”时，视觉补位。

### 6.3 触发规则

```python
def on_block_boundary(obs, state):
    p_reg = fuse(vis_verifier(obs, state.g), psr(obs))
    if p_reg > theta_hi and state.redo < max_redo:
        state.redo += 1
        return "redo"          # 重做同一子目标
    if p_reg < theta_lo and state.done_conf > theta_done:
        state.g += 1           # 前进
        return "advance"
    return "continue"
```

阈值 $\theta_{hi},\theta_{lo}$ 在 OOD 验证集上按“误报重做成本 vs 漏报丢分成本”调，不拍脑袋。

## 7. 与 v2 运行期的接线

```python
class RHPVD_Plus:                 # UIP-01′ + UIP-09″ + UIP-13 + UIP-15 + UIP-20
    def __init__(self, policy, teacher_free_student, psr, csg, K_MAX=8):
        self.policy = teacher_free_student
        self.psr, self.csg, self.K_MAX = psr, csg, K_MAX

    def reset(self):
        self.g = 0; self.redo = 0; self.buf = []
        self.hist = []

    def get_action(self, obs):
        self.hist.append(obs)
        if not self.buf or self._boundary(obs):
            p_reg = self._regression_prob(obs)
            if p_reg > 0.7 and self.redo < 2 and self.csg.allow("redo"):
                self.redo += 1
                self.buf = list(self.policy.redo(obs, self.g))[:self.K_MAX]
            else:
                if p_reg < 0.3:
                    self.g += 1; self.redo = 0
                k = self._pick_k(obs)
                self.buf = list(self.policy.get_action(obs, k))[:k]
        return self.buf.pop(0)
```

**要点**：运行期只有前向；`self.policy.redo` 是蒸馏得到的恢复技能/动作块，不是在线学习；所有重做受 UIP-15 的延迟与次数预算约束。

## 8. 实验设计 E201–E210（可证伪）

> 本轮为设计与推导，**未跑真机**；以下为预注册的对照、指标与判定门槛。所有仿真结果标注为“代理”，不得当成真机结论。

| 实验 | 对照 | 指标 | 预注册判定 |
|---|---|---|---|
| **E201** 微调策略消融 | 全量微调 vs LP-FT vs LoRA vs 只训头 | ID 成功率、OOD 成功率、基座遗忘率、步骤分 | LP-FT/LoRA 的 OOD 比全量高 ≥5 点，ID 降 ≤2 点；否则 RFT 降级 |
| **E202** 插值 $\alpha$ 扫描 | $\alpha\in\{0,0.25,0.5,0.75,1\}$ | ID-OOD Pareto | 存在 $\alpha$ 同时满足 ID 不降、OOD 提升；否则退回 LP-FT |
| **E203** TRC 消融 | 无 TRC vs 有 TRC vs DRF-only | 撤回检测 AUROC/F1、误报率、恢复成功率 | TRC 在留出撤回片段上 AUROC ≥0.80；<0.65 则 TRC 只能当辅助 |
| **E204** PTS 消融 | 无教师 vs 教师上限 vs 学生蒸馏 | 教师/学生恢复成功率、特权信息依赖度 | 学生达到教师恢复增益的 ≥70%；<30% 判蒸馏失败 |

| **E207** PSR 融合 | 仅视觉 vs 仅本体 vs 融合 | 遮挡/压缩下的漏检率 | 融合把遮挡场景漏检降 ≥30% |

| **E209** 合规退路 | 全量数据 vs 公开+TRC-only | 性能差、检测 AUROC | 公开+TRC 保留 ≥70% 的恢复增益；否则合规退路不成立 |

### 8.1 预期结果（方向性，不是实测）

| 实验 | 预期方向 | 可能的反例/杀点 |
|---|---|---|
| E201 | LP-FT/LoRA 的 OOD 优于全量，ID 略低 | 若基座特征本就很适配，全量微调可能不降 OOD → RFT 价值下降 |
| E203 | TRC 对“可逆型”撤回检测强，对“拿走/挪底座”弱 | 若倒放观测与真实撤回域差过大，AUROC 崩 |
| E204 | 学生接近教师但在接触密集步下降 | 若教师本身在仿真里学不会恢复，蒸馏无源 |
| E205 | 课程显著加速 | 若撤回类型异质，课程可能负迁移 |
| E206 | 只训头即可适配新任务 | 若原语库覆盖不足，选择器无法表达新任务 |
| E207 | 融合在遮挡下明显更好 | 若本体信号噪声大，融合反而误报 |
| E208 | 人扰子集步骤分明显提升 | 若评测人扰与训练分布不匹配，提升有限 |

### 8.2 预注册的“停止规则”

- E203 的 AUROC <0.65 且 E204 学生增益 <30% ⇒ **停止“学习式恢复”主线**，退回 v2 的手工验证器 + TRC 仅做检测。
- E201/E202 找不到 ID 不降的 OOD 提升点 ⇒ **停止 RFT 主线**，只保留 LoRA 做轻量适配。
- E209 公开+TRC 的恢复增益 <50% ⇒ **合规退路不足**，需要重新评估是否参赛或只做工程优化。

## 9. 合规与风险

| 风险 | 说明 | 缓解 |
|---|---|---|
| **单模型合规** | 教师、外部 VLM、多个独立模型都可能被判违规 | 教师只训练期存在；提交单一学生 checkpoint；所有头共享骨干；外部模型不进推理 |
| **外部/仿真数据** | 手册未确认是否允许仿真/外部数据训练 | 所有 `D_drf/D_teacher` 挂在合规开关后；默认跑 `D_pub + D_trc`；随时可一键关闭 |
| **在线更新** | 在线梯度更新可能违规且危险 | 运行期只前向；$z_t$ 与检测器都是推断，不更新权重 |
| **sim2real gap** | 教师/DRF 来自仿真，接触与视觉可能不保真 | 教师只教“结构与顺序/恢复意图”；真机锚点校准；不把仿真当像素级裁判 |
| **TRC 动力学不成立** | 倒放动作不可执行 | 只用倒放观测 + 正向动作标签；物理可行样本由 DRF/真机补 |
| **遗忘** | 微调可能损伤基座零样本能力 | LP-FT、LoRA、L2-SP、权重插值、OOD 选模；保留基座 checkpoint 可回退 |
| **评测语义未知** | 榜单聚合与步骤分语义可能非线性 | 报告多组 $(S,P)$ 聚合下的 Pareto，不押单一假设 |

## 11. 本轮最大风险

**一句话**：本轮把赌注压在“恢复能力可以通过特权蒸馏与鲁棒微调获得”，但如果赛规不允许仿真/外部数据、或官方基座并未在同源数据上预训练，那么收益最大的两条数据来源会同时失效，只剩 TRC 这条较弱的合规退路——因此所有收益都必须按“公开+TRC-only”的下界来报告，而不是按全量数据的上界来承诺。
