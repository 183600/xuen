# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC/IP-153~160；灵感循环第 7 轮；本轮灵感：「面部表情识别」×「全身控制」）

> 第 60 轮把「执行层→证据层」升级为「认知驱动的场景-执行闭环」SSM×CIEC×EPIR×SERC×PCE++++，但仍留三处结构性缺口：
> 1. **意图通道只有「显式对话 / 场景」两条，且都是离散或事后的**：人的不适、恐惧、犹豫往往先以面部表情出现（比语言早数百毫秒），第 60 轮的 CIEC 却只能等一句「慢点」。缺失**前语言情感证据**这一连续、前置、非侵入通道。
> 2. **执行体始终是单臂阻抗 K_safe**：真实全身（底盘 + 躯干 + 双臂 + 头）存在平衡、支撑多边形、接触力锥、关节力矩与自碰撞的强耦合。单臂模型无法表达「为了看清人脸而前倾 15° 导致 ZMP 越界」这类全身耦合失效。
> 3. **闭环只覆盖物理执行，没有社交-情感闭环**：机器人自身的表情 / 姿态是影响人类信任与行为的作动器，却一直被视为输出末端，既未进入控制层级，也未进入预算与证据链。

## 0. 直觉与动机

**灵感 1（面部表情识别 → 情感状态证据 ASE）**
直觉：表情不是「命令」，而是**带噪声的似然证据**。一句「我没事」之前，人脸上可能已经出现 0.3–0.8s 的皱眉、屏息、后仰。把 FER 输出建模为情感状态 a = (valence, arousal, discomfort, trust) 的概率后验，并配一个**保形预测集**给出覆盖率保证，作为 XMC+++ 的一个**新证据模态** EV-aff。关键洞见：**FER 的价值在「提前量」，不在「精确度」**——只要它能在语言到达前把约束收紧一格，收益就已经兑现。

**灵感 2（全身控制 → 情感调制的分层 QP，AHQP）**
直觉：WBC 是一个严格的任务层级（安全 / 自碰撞 ≻ 平衡 ≻ 接触稳定 ≻ 操作 ≻ 表情 / 注视）。情感不应直接给关节目标，而应**调制层级内的边界、增益与优先级**：高 discomfort ⇒ 退避任务上浮、操作速度下调、刚度变软、平衡裕度加大。关键洞见：**情感只作用于「软层」与「收缩的硬边界」，永远不能突破硬约束**。

**灵感 3（FER 不可靠 → 非对称安全原则：只许收紧）**
直觉：FER 会误判、会被社会性掩蔽（强颜欢笑）、有文化与个体差异。若允许「正性表情」放宽约束，一次误判就可能放大风险。因此设**非对称安全原则**：情感证据只能令约束**单调收紧**（取交集）；任何放宽必须由「显式确认令牌 ρ + 持续平静窗口 + 跨模态一致性」三重释放（棘轮机制）。关键洞见：**把 FER 的准确性从「安全命题」中解耦**——安全性只依赖「只收紧」这一构造，FER 准不准只影响任务效率。这是本轮最重要的结构性论证。

**灵感 4（合流 → 情感-全身闭环 EWBC）**
直觉：ASE → ACM → WBA（全身可行）→ AHQP → 执行 → EV-exec → XMC+++ 更新，形成「表情→情感→约束→全身可行→分层 QP→证据→信念」闭环；第 60 轮的 SIC 三元组升级为 **SIC+**（加入全身可行性与情感一致性）。

**灵感 5（双向表情通道 + 情感预算）**
直觉：机器人的脸也是作动器。把机器人表情 e_r 作为**最低优先级的 WBC 任务**，并强制「诚实性契约」：置信度低时必须显示犹豫 / 不确定，主动给人类干预窗口。预算 PCE+++++ 增加 B_aff（FER 时延 / 保形覆盖率 / 表情刷新率）与 B_wbc（QP 求解时延 / 力矩裕度 / 平衡裕度）；B_aff 耗尽 ⇒ 情感通道冻结在 last-safe（sticky），B_wbc 紧张 ⇒ 先丢表情 / 注视任务。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（情感状态证据 ASE）** 情感状态空间 A = V × R × D × T，其中 V ∈ [−1,1]（效价）、R ∈ [0,1]（唤醒度）、D ∈ [0,1]（不适度）、T ∈ [0,1]（信任度）。估计器：
- **FER 后验**：f_fer : X_face × X_ctx → Δ(A)，经温度标定 p = softmax(z/τ_temp)。
- **保形集**：给定非一致性分数 s(x,a)，C_α(x) = {a : s(x,a) ≤ q̂_{1−α}}，满足有限样本覆盖率 P(a* ∈ C_α(x)) ≥ 1−α。
- **情感证据**：EV-aff = (p(a), C_α, t_aff, src, H(a))，其中 H(a) 为后验熵（不确定度）。
- **提前量**：ℓ_lead = t_verbal − t_aff；只有 ℓ_lead > 0 时，情感证据才具备「认知先行」价值。

**定义 162（情感-约束单调映射 ACM）** 定义谨慎水平 c(a) = σ(α_D·D + α_T·(1−T) + α_V·(−V) + α_R·R)。约束族 C_aff(c) 的分量全部对 c 单调：
- v_max(c) = v_nom − c·(v_nom − v_min)，F_max(c) = F_nom − c·(F_nom − F_min)
- d_safe(c) = d_nom + c·(d_max − d_nom)，K_cmd(c) = K_nom + c·(K_soft − K_nom)
- β_bal(c) = β_nom + c·(β_max − β_nom)（平衡裕度）
于是 c' ≥ c ⇒ C_aff(c') ⊆ C_aff(c)（**安全单调**）。有效约束按**棘轮**更新：
```
C_eff(t) = C_base ∩ C_aff(c_t)                     若释放事件 R_t 成立
C_eff(t) = C_eff(t−1) ∩ C_aff(c_t)                 否则
```
关键性质：**恒有 C_eff(t) ⊆ C_base**。因此无论 FER 如何误判，可行命令集只会缩小、不会越过基线安全集。释放事件 R_t 需同时满足：显式确认令牌 ρ、持续平静 ≥ T_hyst、跨模态一致性 κ ≥ τ_κ。

**定义 163（情感调制分层 QP，AHQP）** 决策变量 ξ = (q̈, τ, f_c)。任务层级 T_1 ≻ … ≻ T_k 依次为：硬安全 / 自碰撞 ≻ 平衡 ≻ 接触稳定 ≻ 操作 ≻ 表情 / 注视。硬约束：
```
M(q)q̈ + h(q,q̇) = Sᵀτ + J_cᵀ f_c
f_c ∈ K_fric,  τ ∈ [τ_min, τ_max],  q ∈ [q_min, q_max]
dist_self(q) ≥ d_min,  CoM(q) ⊕ ZMP(q) ∈ P_support(β_bal(c))
```
软层任务 i 的优先级 P_i(c) 与权重 w_i(c) 由 c 调制：c↑ ⇒ 退避 / 注视任务 P_i↑、操作速度与刚度↓、接触力上限↓。求解采用零空间级联 QP：每层在上一层零空间内优化，**硬约束始终在最高层**。

**定义 164（全身可行性与 SIC+）** 给定 ξ 与 c：
```
WB-Adm(ξ, c) ⇔ ∃ ξ 满足上述全部硬约束且平衡裕度 ≥ β_bal(c)
SIC+ = (scene_conf, K_certainty, WB_feasibility, affect_consistency, balance_margin)
SIC+_valid ⇔ scene_conf ≥ τ_scene ∧ K_certainty ≥ τ_K
             ∧ WB_feasibility = true ∧ affect_consistency ≥ τ_κ
```
`affect_consistency = 1 − D_KL(p_aff ‖ p_behav)`，其中 p_behav 由接近速度、受力反应、语音韵律等行为通道给出；一致性低时自动下调情感权重。

**定义 165（情感-全身闭环 EWBC）** 算子 EWBC(M, task, x_face)：
```
① ASE:  EV-aff = (p(a), C_α, H(a)) ← ase.estimate(x_face, ctx)
② Gate: if H(a) > τ_H or coverage < 1−α or B_aff exhausted: a ← a_sticky
③ ACM:  C_eff(t) ← ratchet(C_eff(t−1), C_aff(c(a)), R_t)
④ WBA:  if ¬WB-Adm(ξ_prev, c): task ← task.relax_non_safety(); 收紧 C_eff
⑤ AHQP: ξ* ← affect_hierarchical_qp(task, C_eff, priorities(c), w(c))
⑥ Exec: EV-exec ← execute_and_evidence(ξ*)
⑦ Fuse: M, D⁺ ← xmodal_fuse_plus_plus(M, EV-aff, EV-exec)   # 情感成为新模态
⑧ Release: if ρ ∧ calm_sustained ∧ κ ≥ τ_κ: 允许一次棘轮释放
⑨ Return: (ξ*, a, C_eff, SIC+, EV-exec)
```

**定义 166（双向表情通道 BEC）** 机器人表情 e_r ∈ E 作为最低优先级任务，幅值与变化率受 `C_eff` 约束。诚实性契约：
- 若自置信度 conf_self < τ_conf，则 e_r 必须包含不确定标记 EXPR_UNCERTAIN（犹豫 / 困惑），不得表现过度自信。
- 若 e_r 与内部状态不一致（over-claim），则判定为「表达违约」并记录到证据链，用于后续信任校准。

**定义 167（情感预算 B_aff 与 PCE+++++）** B_cog+ = (B_scene, B_intent, B_ros, B_exec, B_aff, B_wbc)：
- **B_aff** = (FER_latency, Coverage_1−α, Expression_rate)
- **B_wbc** = (QP_solve_slack, Torque_headroom, Balance_margin_budget)
- **PCE+++++ VOI**：
```
voi_cog+(π) = VOI_meta_pessimistic(π) − cost_cog(π) − cost_exec(π) − cost_aff(π)
cost_aff = λ_fer·FER_latency + λ_cal·(α − α_target)⁺ + λ_wbc·max(0, QP_time − QP_slack)
```
降级链：B_aff 耗尽 ⇒ 情感通道 sticky（冻结在 last-safe，不消失）；B_wbc 紧张 ⇒ 先丢表情 / 注视任务，再简化软层；B_scene / B_intent / B_ros / B_exec 沿用第 60 轮策略。

**定义 168（情感一致性与反事实探针 ATCE）** 掩蔽检测与主动探测：
```
κ = 1 − D_KL(p_aff ‖ p_behav)
masking_suspect ⇔ (V_aff > 0) ∧ (D_behav > τ_D)        # 强颜欢笑
should_probe ⇔ H(a) > τ_H ∧ risk(task) > τ_R
probe(u) = argmin_u [ risk(u) − λ_info·IG(a; y_u) ]      # 低成本高信息动作
```
探针动作集含：暂停、后退半步、转向侧脸、简短确认问句；耗用 B_aff，且探针本身必须通过 WB-Adm。

### IP-161 ASE（情感状态证据）

```python
class AffectiveStateEstimator:
    def __init__(self, fer_model, alpha=0.1, temp=1.5):
        self.fer, self.alpha, self.temp = fer_model, alpha, temp
        self.q_hat = None                       # 保形分位数（离线校准）

    def estimate(self, face, ctx):
        logits = self.fer(face)
        p = softmax(logits / self.temp)
        a_map = decode_affect(p)                # V, R, D, T
        C = self.conformal_set(p, self.q_hat)   # coverage >= 1-alpha
        return AffectiveEvidence(p=p, a=a_map, C=C,
                                 t=time.time(), H=entropy(p))
```

### IP-162 ACM（情感-约束单调映射）

```python
class AffectConstraintMonotone:
    def __init__(self, base):
        self.C_eff = base
        self.release_tokens = 0

    def caution(self, a):
        return sigmoid(1.2*a.D + 1.0*(1-a.T) + 0.8*(-a.V) + 0.5*a.R)

    def map(self, c):
        return Constraint(
            v_max=lerp(v_nom, v_min, c),  F_max=lerp(F_nom, F_min, c),
            d_safe=lerp(d_nom, d_max, c), K_cmd=lerp(K_nom, K_soft, c),
            beta_bal=lerp(beta_nom, beta_max, c))

    def update(self, a, release=False):
        c_new = self.caution(a)
        C_new = self.map(c_new)
        if release and self.release_tokens > 0:
            self.release_tokens -= 1
            C_next = intersect(self.C_base, C_new)   # 允许回到基线
        else:
            C_next = intersect(self.C_eff, C_new)     # 只收紧
        self.C_eff = C_next
        return self.C_eff
```

### IP-163 AHQP（情感调制分层 QP）

```python
def affect_hierarchical_qp(model, task, C_eff, c):
    xi = solve_hard_constraints(model, C_eff)        # 动力学/摩擦锥/平衡/限位
    for level in task.hierarchy:                     # safety > balance > contact > task > expression
        if level.name == 'expression' and not C_eff.allow_expression:
            continue
        level_bounds = modulate_bounds(level.bounds, c)
        xi = solve_level_qp(model, level, xi, level_bounds)  # 零空间级联
    return xi
```

### IP-165 EWBC（情感-全身闭环）

```python
def affective_whole_body_loop(M, task, face):
    ev = M.ase.estimate(face, M.ctx)
    a = M.a_sticky if (ev.H > tau_H or M.budget.affect_exhausted()) else ev.a
    if a is not M.a_sticky:
        M.a_sticky = a

    release = M.consent.token_ready() and calm_sustained(M)
    C_eff = M.acm.update(a, release=release)

    if not whole_body_admissible(M.model, M.last_xi, C_eff):
        task = task.relax_non_safety()
        C_eff = C_eff.relax_task_bounds()            # 绝不放松硬安全层

    xi = affect_hierarchical_qp(M.model, task, C_eff, M.acm.caution(a))
    ev_exec = execute_and_evidence(M, xi)
    M, D_plus = xmodal_fuse_plus_plus(M, ev, ev_exec)
    M.record(SIC_plus(M, ev, ev_exec, xi))
    return M, xi, a, C_eff, ev_exec
```

### IP-166 BEC（诚实表情通道）

```python
class ExpressionChannel:
    def __init__(self, tau_conf=0.6, max_rate=1.0):
        self.tau_conf, self.max_rate = tau_conf, max_rate

    def render(self, conf_self, intent, affect, C_eff):
        if conf_self < self.tau_conf:
            e = EXPR_UNCERTAIN                # 诚实性契约：低置信必须显示犹豫

            e = expression_from(intent, affect)
        return bound_expression(e, C_eff.allow_expression, self.max_rate)

    def check_overclaim(self, e, conf_self):
        return (e == EXPR_CONFIDENT and conf_self < self.tau_conf)
```

### IP-167 情感预算

```python
class AffectBudget:
    def __init__(self, fer_ms=30, qp_ms=5, expr_hz=15):
        self.B_fer, self.B_qp, self.B_expr = fer_ms, qp_ms, expr_hz
        self.used_fer = self.used_qp = 0

    def affect_exhausted(self):
        return self.used_fer > self.B_fer

    def wbc_tight(self):
        return self.used_qp > 0.8 * self.B_qp

    def degrade(self):
        if self.wbc_tight():
            return 'drop_expression_then_gaze'
        if self.affect_exhausted():
            return 'sticky_affect_local_loop'
        return 'normal'
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| ASE | O(d_face) 推理 / 帧，约 10–30ms | O(1) / 帧 | 保形覆盖率 ≥ 1−α；ECE ≤ 0.05 |
| ACM | O(|C|) = O(1) | O(1) | 严格单调：c'≥c ⇒ C_aff(c') ⊆ C_aff(c) |
| AHQP | O((n+m)³) / 层，30–40 DOF 约 1–5ms | O(n+m) | 硬约束 100% 满足 |
| WBA | O(n³) | O(n) | 平衡 / 摩擦锥 / 限位不可违反 |
| EWBC | 2 次 QP + 1 次带约束探针 | 复用 | 端到端 ≤ τ_aff_deadline |
| ATCE | O(K) 跨模态 | O(K) | 掩蔽检测召回 ≥ 80% |

**推导（安全不变量）**：只需证明对任意 t 有 C_eff(t) ⊆ C_base。初始 C_eff(0) = C_base。非释放分支为两个子集的交，仍 ⊆ C_eff(t−1) ⊆ C_base；释放分支为 C_base ∩ C_aff ⊆ C_base。归纳成立。AHQP 只在 C_eff(t) 内求 ξ*，故对任意 FER 误差序列，执行命令天然落在基线安全集内。**换言之，FER 误判只可能让机器人「过度保守」，不可能让它「越过基线安全」**——这是非对称设计换来的、与 FER 精度无关的安全保证。

**正确性定理（EWBC-Safe）**：设 (A66) FER 保形覆盖 ≥ 1−α；(A67) ACM 单调且释放需三重条件；(A68) WBA 对硬约束编码可靠；(A69) 表情任务优先级严格低于安全 / 平衡且幅值有界；(A70) 各预算单调消耗。则：
1. **情感安全不变量**：∀t，C_eff(t) ⊆ C_base，情感证据无法扩大可行域。
2. **全身可行性**：若 WB-Adm(ξ,c) 为真，则执行 (τ, f_c) 满足动力学、摩擦锥、平衡与限位。
3. **闭环稳定性**：棘轮 + 迟滞 T_hyst + 释放令牌严格限制切换次数，消除情感抖动导致的约束抖振。
4. **证据一致性**：κ < τ_κ 时情感权重自动收缩，掩蔽样本无法长期主导信念。
5. **表情诚实性**：conf_self < τ_conf 时禁止输出 EXPR_CONFIDENT，避免误导性社会信号。

## 4. 实验设计 E192–E196

| 实验 | 指标 | 目标 |

| E193 ACM 单调性 | 随机 a 的性质测试；释放违规率 | 10⁵ 采样「只收紧」零违规 |

| E195 EWBC 端到端 | 安全违规；任务成功率；情感响应时延 | 0 次基线安全违规；成功率 ≥ 基线 −2%；≤ 200ms |
| E196 BEC | 表情诚实性；人类可读性 / 适当性评分 | over-claim 率 ≤ 1%；评分 ≥ 4/5 |

## 5. 本轮最大风险

### IP-162 ACM（情感-约束单调映射）

```python
class AffectConstraintMonotone:
    def __init__(self, base):
        self.C_eff, self.C_base = base, base
        self.release_tokens = 0

    def caution(self, a):
        return sigmoid(1.2*a.D + 1.0*(1-a.T) + 0.8*(-a.V) + 0.5*a.R)

    def map(self, c):
        return Constraint(
            v_max=lerp(v_nom, v_min, c),  F_max=lerp(F_nom, F_min, c),
            d_safe=lerp(d_nom, d_max, c), K_cmd=lerp(K_nom, K_soft, c),
            beta_bal=lerp(beta_nom, beta_max, c))

    def update(self, a, release=False):
        C_new = self.map(self.caution(a))
        if release and self.release_tokens > 0:
            self.release_tokens -= 1
            self.C_eff = intersect(self.C_base, C_new)   # 允许回到基线
        else:
            self.C_eff = intersect(self.C_eff, C_new)    # 只收紧
        return self.C_eff
```

## 3. 关键推导

**命题 1（安全不变量，与 FER 精度无关）**：对任意情感证据序列 {EV-aff_t}，EWBC 的执行命令恒满足基线安全约束。
*证明*：归纳证明 C_eff(t) ⊆ C_base。t=0 时 C_eff(0)=C_base。非释放分支为交集，C_eff(t) ⊆ C_eff(t−1) ⊆ C_base；释放分支为 C_base ∩ C_aff ⊆ C_base。AHQP 仅从 C_eff(t) 内取 ξ*，WBA 再校验硬约束。故无论 FER 输出什么，ξ* 都不会越出 C_base。∎
*推论*：FER 的 ECE / 覆盖率只决定 C_eff 收紧得是否「恰到好处」，决定效率，不决定安全；这是「只收紧」构造的结构性红利。

**命题 2（端到端时延预算）**：情感提前量需满足
```
τ_e2e = ℓ_cam + ℓ_fer + ℓ_ase + ℓ_acm + ℓ_qp + ℓ_wbc  <  ℓ_lead + τ_deadline
```
若 ℓ_fer + ℓ_qp 逼近上界，则按优先级降级：① 表情任务降频 → ② FER 帧步进 / 降分辨率 → ③ 情感证据 sticky。降级只降低「情感分辨率」，不改变 C_eff ⊆ C_base 的安全不变量。

**命题 3（棘轮切换上界）**：设释放需持续平静窗口 T_hyst 且每次消耗一个令牌，则任意长度 T 的交互内约束切换次数 ≤ T/T_hyst + N_token，从而消除情感抖动引起的约束抖振。

## 4. 正确性定理（EWBC-Safe）

设 **(A66)** FER 保形覆盖 ≥ 1−α；**(A67)** ACM 分量单调且释放需「令牌 ρ + 持续平静 T_hyst + 一致性 κ ≥ τ_κ」；**(A68)** WBA 对动力学 / 摩擦锥 / 平衡 / 限位编码可靠；**(A69)** 表情任务优先级严格低于安全与平衡且幅值有界；**(A70)** 各预算单调消耗。则：
1. 情感安全不变量：∀t，C_eff(t) ⊆ C_base（命题 1）。
2. 全身可行性：WB-Adm(ξ,c) ⇒ 执行 (τ,f_c) 满足动力学、摩擦锥、平衡、限位、自碰撞。
3. 闭环稳定性：棘轮 + 迟滞 + 令牌 ⇒ 切换次数有界（命题 3），无约束抖振。
4. 证据一致性：κ < τ_κ 时情感权重收缩，掩蔽无法长期主导信念。
5. 表情诚实性：conf_self < τ_conf 时禁止 EXPR_CONFIDENT。
