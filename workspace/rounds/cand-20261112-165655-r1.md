# 第 61 轮（承接第 60 轮「场景感知闭环」IP-153~160；灵感循环第 7 轮；本轮灵感：「柔顺控制」×「云边协同」）

> 第 60 轮用 SSM×CIEC×EPIR×SERC 把「场景/意图/证据」接进了执行闭环，但**执行层的物理本质仍被当作「参数选择」而非「能量过程」**，且**云端只收证据、不反哺策略**。三个未解局限：
> 1. **柔顺控制的能量盲区**：K_safe 只是一组刚度/阻尼参数，EEIS 编译时只检查「参数在安全域内」，却从不检查**这组阻抗在接触瞬间是否向系统注入能量**。刚度增大、阻尼为负、前馈补偿都可能使接触从「柔顺」变成「泵能」，出现「参数合规、动力学失稳」的抽象泄漏。
> 2. **云边协同的策略断层**：EPIR 只做了边→云的单向证据回传，云端的强算力（场景策略学习、长期能量规划、跨机经验聚合）**没有安全地反哺边端**；而云端策略天生「陈旧」，直接下发会与边端实时状态错位。
> 3. **证据完整 ≠ 控制稳定**：EV-exec 完整只能证明「发生了什么」，不能证明「下一次仍稳定」。缺少**能量账本**与**云边信任状态**，无法在模型失配时及时收回云端权限。

## 0. 直觉与动机

**灵感 1（柔顺控制 → 柔顺能量包络 CEE）**
直觉：柔顺不是「把刚度调小」，而是「在能量守恒下顺从外力」。把执行器看作端口哈密顿系统：注入的主动能量必须从一只「能量罐」E_t 里扣除，耗散时回充；罐空则强制投影到耗散锥（卸刚度、去负阻尼）。关键洞见：**把阻抗调度从「参数合规」升级为「能量可证」**——每次下发 K_safe 都必须附带一张可被边端 O(1) 校验的「能量护照」Cert_cee。

**灵感 2（云边协同 → 云边柔顺契约 CECC）**
直觉：云强于「慢」，边强于「快」。场景-阻抗策略、长期能量预算、跨机经验是慢变量，适合上云；接触力、能量罐、安全包络是快变量，必须留边。关键洞见：**云边之间传的不是「策略」，而是「带能量边界的契约」**——云端承诺这批动作最多注入 E_margin 能量，边端核对能量罐后要么接受、要么「能量裁剪」，并保留一票否决权。

**灵感 3（时标分层 → 分布式无源性 TSEL）**
直觉：只要云策略「足够慢」（T_c ≫ T_e）、每次下发都过边端无源滤波、且场景变化不快于 Δ_stale 允许的范围，那么「慢云 + 快边」拼起来仍是无源稳定的。关键洞见：**时间尺度分离 + 边端能量滤波 = 分布式无源性的充分条件**，这为「云端可以大胆学、边端始终安全」提供理论护栏。

**灵感 4（能量对账 → 信任与陈旧度自适应 EBR×CEAT）**
直觉：云端预测「本次耗 3.2J」，边端实测「耗 5.1J」，差额不是噪声而是「云端世界模型错了」。用能量差 D_E 驱动信任 γ_ce：差得越多越不信云，越倾向本地保守柔顺；同时按场景变化率动态收紧陈旧窗 Δ_stale。关键洞见：**能量是比日志更硬的信任信号**——它直接对应稳定性。

**灵感 5（五维预算与闭环 → PCE+++++ × CECL）**
直觉：第 60 轮的认知预算再加两维：B_energy（能量罐容量/回充率/余量比例）与 B_link（带宽/时延/丢包/陈旧预算）。五维预算共同决定「云端策略值不值得等、边端能量够不够撑」。CECL 把它们串成「证据→对账→信任→契约→无源滤波→执行→能量账本」的云边柔顺闭环。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（柔顺能量包络 CEE）** 端口哈密顿柔顺模型 Σ_c = (q, p, E_t; K, D, u)，储能 H(q,p)=½pᵀM⁻¹p+V(q)，控制律分解为耗散项与主动项：
u = u_diss + α(E_t)·u_act,  α(E_t)=clip(E_t/E_ref, 0, 1)
能量罐动力学：Ė_t = η·P_diss − P_act，其中 P_diss = ½ẏᵀDẏ 为耗散功率，P_act = max(0, u_actᵀẏ) 为主动注入功率。
- **无源性条件**：∀t, E_t(t) ≥ 0；等价地 E_t(0) ≥ ∫₀^T P_act dt。
- **能量裁剪投影**：当 E_t ≤ ε_tank，将控制投影到耗散锥 Π_diss(u)：关闭负阻尼与超出储能的额外刚度（K ← K_min + (E_t/E_margin)(K−K_min)）。
- **能量护照**：Cert_cee = (E_t(0), E_max, P_diss_max, P_act_bound, T_horizon, hash, passivity_flag)，满足 E_t(0) ≥ P_act_bound·T_horizon 时 passivity_flag=true。

**定义 162（云边柔顺契约 CECC）** 契约 C = (pid, π_comp, t_gen, Δ_stale, E_margin, σ_trust, hash)：
- **策略域**：π_comp：(scene, intent) → (阻抗时序 K(t), 预测能量曲线 Ê(t))。
- **能量边界**：E_margin = sup_{τ∈[0,T_horizon]} ∫₀^τ P_act(π_comp) dt（云端模型下的最坏注入能量）。
- **边端接受谓词**：Accept(C) = (now − t_gen ≤ Δ_stale) ∧ (E_t ≥ E_margin) ∧ hash_ok(C) ∧ (γ_ce ≥ θ_trust)。
- **边端否决/裁剪**：若 E_t < E_margin，则执行能量裁剪并通过「否决回执」上报云端：reject_reason = ENERGY_INSUFFICIENT，同时 K ← Π_diss(K)。

**定义 163（时标能量分层 TSEL）** 设云更新周期 T_c、边控制周期 T_e、比 ρ = T_c/T_e，层映射 π_comp = Φ_cloud(history)、K_edge = Φ_edge(π_comp, telemetry)。**组合无源性条件 A66**：(i) ρ ≥ ρ_min；(ii) 每个契约都通过 CEE 无源滤波；(iii) 场景变化率 λ_scene ≤ λ_max。在 A66 下，「慢云 + 快边」复合系统保持无源与接触稳定。
- **场景相关陈旧窗**：Δ_stale(z) = c_s / (λ_scene(z) + ε)。

**定义 164（能量预算对账 EBR）** 能量账本 L_E ← append(pid, E_pred, E_meas, D_E, t)，其中
D_E = |E_pred − E_meas| / max(E_pred, ε)，并区分超支 D_E⁺ = max(0, E_meas−E_pred)/E_pred 与结余 D_E⁻。
- **对账动作**：若 D_E⁺ > θ_E，则 γ_ce ↓、Δ_stale ↓，并把该 pid 标记为「模型失配」，要求云端重训/重估 E_margin。
- **账本不变式**：Σ E_meas 与 Σ E_pred 的累积偏差 |Σ(E_meas−E_pred)| ≤ κ·Σ E_pred，否则判「能量模型失效」。

**定义 165（云边自适应信任 CEAT）** 信任状态 γ_ce ∈ [0,1]，更新：
γ_ce ← clip(γ_ce + α_g(1 − D_E) − β_g·1[violation] − δ_g·1[latency > τ_link] − ε_g·1[hash_fail] − ζ_g·D_E⁺, 0, 1)
三档模式：M_cloud（γ≥0.8，云端策略权威）、M_assist（0.5≤γ<0.8，云端仅建议）、M_local（γ<0.5，本地保守柔顺）。模式决定云端策略的采纳率与刷新频率。

**定义 166（云边柔顺闭环 CECL）** 算子 CECL(M, scene, intent, telemetry)：
```
① EdgeObs: E_t, contact ← observe(telemetry)
② EBR:     D_E ← reconcile(L_E[-1]); γ_ce, Δ_stale ← CEAT.update(D_E, latency, hash)
③ Cloud:   if γ_ce ≥ θ_trust: π_comp ← Φ_cloud(aggregate(L_E, EV-exec, scene))
④ Contract:C ← CECC.pack(π_comp, E_margin, Δ_stale, γ_ce)
⑤ Filter:  if Accept(C): K* ← CECC.compile(C, K_scene_prior, C_intent)
            else:       K* ← Π_diss(K_scene); reject_reason ← ENERGY_INSUFFICIENT
⑥ Guard:   dispatch(K*); E_t ← CEE.guard(K*, telemetry)
⑦ Evidence:EV-exec ← build_exec_evidence(...); L_E.append(pid, Ê, E_meas, D_E)
⑧ Return:  (K*, E_t, D_E, γ_ce, mode, Cert_cee)
```

**定义 167（五维预算 PCE+++++）** 在 R60 的 B_cog 基础上增加 B_energy、B_link：
- B_energy = (E_tank, E_refill_rate, E_margin_frac, E_max)
- B_link = (Bandwidth, Latency, Loss_rate, Staleness_budget)
- 价值函数：
```
voi_ce(π) = VOI_meta(π) − cost_cog(π) − cost_energy(π) − cost_link(π)
cost_energy = λ_E·max(0, E_margin − E_t) + λ_ref·Refresh_energy(π)
cost_link   = λ_bw·Bandwidth(π) + λ_lat·Latency(π) + λ_loss·Loss(π)
```
- **降级阶梯**：B_energy 耗尽 ⇒ Π_diss 纯阻尼柔顺；B_link 耗尽或 D_E 超限 ⇒ M_local 本地闭环；B_scene/B_intent 耗尽 ⇒ 沿用 R60 的通用先验/默认约束。

**定义 168（时序最优柔顺提交 TOCC）** 提交时刻 t* 权衡「新鲜度」与「云算/链路成本」：
J(t) = E[D_E(t)] + λ_s·Δ_stale(t) + λ_e·E_exp(t) + λ_c·C_cloud(t)
t* = argmin_{t∈[t_now, t_now+T_c]} J(t)。
- **无源证书提交约束**：仅当 Cert_cee 在整个 T_horizon 上成立才允许提交；否则推迟到下一个场景边界或本地保守执行。
- **提交原子性**：契约必须携带完整 (pid, E_margin, hash)，边端要么整体接受、要么整体否决，禁止「半份契约」生效。

### IP-161 CEE（柔顺能量包络）
```python
class CompliantEnergyEnvelope:
    def __init__(self, E_max=10.0, E_ref=1.0, eps_tank=0.05, eta=0.9):
        self.E_t = E_max; self.E_max = E_max; self.E_ref = E_ref
        self.eps = eps_tank; self.eta = eta

    def guard(self, K, telemetry):
        P_diss = 0.5 * telemetry.vel @ K.D @ telemetry.vel
        P_act  = max(0.0, telemetry.u_act @ telemetry.vel)
        self.E_t += self.eta * P_diss * telemetry.dt - P_act * telemetry.dt
        self.E_t = min(self.E_max, max(0.0, self.E_t))
        if self.E_t <= self.eps:
            return self.project_dissipative(K)   # 卸刚度、去负阻尼
        return K

    def project_dissipative(self, K):
        K.Kp = K.Kp_min
        K.D  = self.psd_damping(K.D)             # 强制阻尼半正定
        K.ff = 0.0                               # 关闭前馈注入
        return K

    def make_passport(self, K, horizon):
        P_act_bound = self.active_power_bound(K)
        ok = self.E_t >= P_act_bound * horizon
        return CertCEE(self.E_t, self.E_max, P_act_bound, horizon,
                       hash=sha256(serialize(K)), passivity=ok)
```

### IP-162 CECC（云边柔顺契约）
```python
class CloudEdgeComplianceContract:
    def __init__(self, trust_gate=0.5):
        self.trust_gate = trust_gate

    def pack(self, pid, pi_comp, E_margin, delta_stale, gamma):
        return Contract(pid=pid, pi=pi_comp, t_gen=now(),
                        delta_stale=delta_stale, E_margin=E_margin,
                        sigma_trust=gamma, hash=sha256(serialize(pi_comp)))

    def accept(self, C, E_t, gamma, now):
        if now - C.t_gen > C.delta_stale: return False, 'STALE'
        if not hash_ok(C):                return False, 'HASH'
        if gamma < self.trust_gate:       return False, 'TRUST'
        if E_t < C.E_margin:              return False, 'ENERGY_INSUFFICIENT'
        return True, 'OK'

    def compile(self, C, K_scene_prior, C_intent):
        K = C.pi.select(C_intent)                   # 云端策略给出阻抗时序
        return project(K, K_scene_prior, C_intent)  # 仍受场景/意图约束裁剪
```

### IP-163/164/165 TSEL×EBR×CEAT（对账与信任）
```python
class CloudEdgeTrust:
    def __init__(self, gamma=1.0):
        self.gamma = gamma; self.mode = 'cloud'

    def update(self, D_E, D_E_plus, violation, latency, hash_fail,
               alpha=0.2, beta=0.5, delta=0.2, eps=0.5, zeta=0.3, tau=0.2):
        self.gamma = clip(self.gamma + alpha*(1-D_E) - beta*violation
                          - delta*(latency > tau) - eps*hash_fail
                          - zeta*D_E_plus, 0.0, 1.0)
        self.mode = ('cloud' if self.gamma >= 0.8 else
                     'assist' if self.gamma >= 0.5 else 'local')
        return self.gamma, self.mode

def reconcile_energy(E_pred, E_meas, eps=1e-6):
    D_E = abs(E_pred - E_meas) / max(E_pred, eps)
    D_E_plus = max(0.0, E_meas - E_pred) / max(E_pred, eps)
    return D_E, D_E_plus

def scene_staleness_bound(lambda_scene, c_s=0.5, eps=1e-3):
    return c_s / (lambda_scene + eps)
```

### IP-166 CECL（云边柔顺闭环）
```python
def cloud_edge_compliant_loop(M, scene, intent, telemetry):
    E_t, contact = observe(telemetry)
    D_E, D_E_plus = reconcile_energy(M.L_E[-1].E_pred, E_t)
    gamma, mode = M.trust.update(D_E, D_E_plus, M.violation,
                                 M.link_latency, M.hash_fail)
    delta_stale = scene_staleness_bound(M.scene_rate(scene))

    if mode != 'local':
        pi_comp = M.cloud.update(aggregate(M.L_E, M.EV_exec, scene))
        C = M.cecc.pack(pid=next_pid(), pi_comp=pi_comp,
                        E_margin=M.cloud.energy_margin(pi_comp),
                        delta_stale=delta_stale, gamma=gamma)
        ok, why = M.cecc.accept(C, E_t, gamma, now())
    else:
        ok, why = False, 'TRUST_LOCAL'

    if ok:
        K = M.cecc.compile(C, M.K_scene_prior, M.intent_constraint)
    else:
        K = M.cee.project_dissipative(M.K_scene_prior)

    K = M.cee.guard(K, telemetry)
    dispatch_impedance(K)
    EV_exec = build_exec_evidence(telemetry, K)
    M.L_E.append(pid, M.cloud.predicted_energy(K), E_t, D_E)
    return M, K, E_t, D_E, gamma, mode, why
```

### IP-167 PCE+++++（五维预算）
```python
class FiveDimBudget:
    def __init__(self, cog, E_max=10.0, E_refill=1.0, link=None):
        self.B_cog = cog
        self.B_energy = EnergyBudget(E_max, E_refill)
        self.B_link = link or LinkBudget(bw=1e6, lat=50e-3, loss=0.01)

    def voi_ce(self, pi, E_t, bandwidth, latency, loss):
        return (self.voi_meta(pi) - self.cost_cog(pi)
                - self.cost_energy(pi, E_t)
                - self.cost_link(bandwidth, latency, loss))

    def fallback(self, state):
        if state.B_energy <= 0:    return 'dissipative_only'
        if state.B_link <= 0:      return 'local_loop'
        if state.B_cog_scene <= 0: return 'general_prior'
        if state.B_cog_intent <= 0:return 'default_constraint'
        return 'normal'
```

### IP-168 TOCC（时序最优提交）
```python
def time_optimal_commit(pi_comp, now, T_c, horizon, lam):
    best, t_star = float('inf'), now
    for t in candidates(now, now + T_c):
        E_exp = cloud.expected_energy(pi_comp, t)
        if not cert_cee(pi_comp, t, horizon):   # 无源证书不成立则不提交
            continue
        J = lam['D']*expected_discrepancy(t) + lam['s']*staleness(t) \
            + lam['e']*E_exp + lam['c']*cloud.cost(t)
        if J < best: best, t_star = J, t
    return t_star
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CEE | O(d) 每次能量守卫 | O(1) | E_t ≥ 0 恒成立；接触无源 |
| CECC | O(1) 接受判定/O(k) 编译 | O(1) | 契约原子性；E_margin 覆盖注入 |
| TSEL | 云端 O(cloud) / 边 O(1) | 复用 | A66 下复合系统无源 |
| EBR | O(1) | O(window) 账本 | 能量模型失配可检出 |
| CEAT | O(1) | O(1) | 信任可回退，模式切换有界 |
| CECL | O(闭环) | 复用 | 能量-证据-信任闭合 |
| TOCC | O(|candidates|) | O(1) | 仅提交带无源证书的契约 |

**正确性定理（CECP，云边柔顺协同）**：假设 A22–A66 成立。**(A66)** 时标分离 ρ≥ρ_min、每个契约过 CEE 无源滤波、λ_scene≤λ_max；**(A67)** EBR 的 D_E 与真实模型误差单调相关；**(A68)** CEAT 的信任在违例后有限步内不超过原值（无虚假恢复）。则：
1. **接触无源性**：CEE 保证 E_t≥0，投影 Π_diss 保证 u∈耗散锥，接触响应无自激。
2. **云边组合稳定**：在 A66 下，「慢云 + 快边」复合闭环无源且 Lyapunov 稳定。
3. **契约安全**：Accept(C)=true ⇒ 契约能量边界被 E_t 覆盖，且 K* 同时满足场景先验与意图约束。
4. **失配可检**：若云端能量模型偏差超阈值，EBR 使 D_E⁺ 上升、CEAT 降权，系统退回 M_local。

## 5. 本轮最大风险

**一句话**：若云端能量模型系统性低估注入能量，而边端能量观测又存在时延，则「能量护照」会退化为基于陈旧遥测的虚假无源保证——证书说安全、接触却在泵能；必须用「边端独立能量观测器 + 硬性能量地板 E_t≥ε_tank 无条件投影 + 契约原子否决 + EBR 失配降权」四重硬护栏，确保云端再聪明也不能覆盖边端物理。

# 第 61 轮产物 · 创新点清单 v2：CECP（云边柔顺协同：柔顺能量包络×云边柔顺契约×时标能量分层，CEE×CECC×TSEL×EBR×CEAT×CECL×PCE+++++×TOCC）

> 承接第 60 轮 IP-153~160（场景感知闭环 SSM×CIEC×EPIR×SERC×PCE++++）。本轮把「参数合规的执行」升级为「能量可证的柔顺」，并把「边→云证据回传」升级为「云→边带能量边界的策略契约」。核心：**CEE** 让每次阻抗下发都携带无源能量护照；**CECC** 让云端只能以「能量契约」形式反哺边端并接受边端否决；**TSEL** 给出「慢云+快边」分布式无源性的充分条件；**EBR×CEAT** 用能量对账驱动信任回退；**CECL** 将四者串成闭环；**PCE+++++** 增加能量与链路两维预算；**TOCC** 决定契约提交时机。最终实现「云端可大胆学、边端始终安全、证据与能量双闭合」。

> IP 编号：IP-161~IP-168（共 8 个），新增「云边柔顺协同」6 项核心能力。

## 2. 关键算法伪代码

### IP-161 CEE（柔顺能量包络）
```python
class CompliantEnergyEnvelope:
    def __init__(self, E_max=10.0, E_ref=1.0, eps_tank=0.05, eta=0.9):
        self.E_t = E_max; self.E_max = E_max; self.E_ref = E_ref
        self.eps = eps_tank; self.eta = eta

    def guard(self, K, telemetry):
        P_diss = 0.5 * telemetry.vel @ K.D @ telemetry.vel
        P_act  = max(0.0, telemetry.u_act @ telemetry.vel)
        self.E_t += self.eta * P_diss * telemetry.dt - P_act * telemetry.dt
        self.E_t = min(self.E_max, max(0.0, self.E_t))
        if self.E_t <= self.eps:
            return self.project_dissipative(K)
        return K

    def project_dissipative(self, K):
        K.Kp = K.Kp_min
        K.D  = self.psd_damping(K.D)
        K.ff = 0.0
        return K

    def make_passport(self, K, horizon):
        P_act_bound = self.active_power_bound(K)
        ok = self.E_t >= P_act_bound * horizon
        return CertCEE(self.E_t, self.E_max, P_act_bound, horizon,
                       hash=sha256(serialize(K)), passivity=ok)
```

### IP-162 CECC（云边柔顺契约）
```python
class CloudEdgeComplianceContract:
    def __init__(self, trust_gate=0.5):
        self.trust_gate = trust_gate

    def pack(self, pid, pi_comp, E_margin, delta_stale, gamma):
        return Contract(pid=pid, pi=pi_comp, t_gen=now(),
                        delta_stale=delta_stale, E_margin=E_margin,
                        sigma_trust=gamma, hash=sha256(serialize(pi_comp)))

    def accept(self, C, E_t, gamma, now):
        if now - C.t_gen > C.delta_stale: return False, 'STALE'
        if not hash_ok(C):                return False, 'HASH'
        if gamma < self.trust_gate:       return False, 'TRUST'
        if E_t < C.E_margin:              return False, 'ENERGY_INSUFFICIENT'
        return True, 'OK'

    def compile(self, C, K_scene_prior, C_intent):
        K = C.pi.select(C_intent)
        return project(K, K_scene_prior, C_intent)
```

### IP-163/164/165 TSEL×EBR×CEAT（对账与信任）
```python
class CloudEdgeTrust:
    def __init__(self, gamma=1.0):
        self.gamma = gamma; self.mode = 'cloud'

    def update(self, D_E, D_E_plus, violation, latency, hash_fail,
               alpha=0.2, beta=0.5, delta=0.2, eps=0.5, zeta=0.3, tau=0.2):
        self.gamma = clip(self.gamma + alpha*(1-D_E) - beta*violation
                          - delta*(latency > tau) - eps*hash_fail
                          - zeta*D_E_plus, 0.0, 1.0)
        self.mode = ('cloud' if self.gamma >= 0.8 else
                     'assist' if self.gamma >= 0.5 else 'local')
        return self.gamma, self.mode

def reconcile_energy(E_pred, E_meas, eps=1e-6):
    D_E = abs(E_pred - E_meas) / max(E_pred, eps)
    D_E_plus = max(0.0, E_meas - E_pred) / max(E_pred, eps)
    return D_E, D_E_plus

def scene_staleness_bound(lambda_scene, c_s=0.5, eps=1e-3):
    return c_s / (lambda_scene + eps)
```

### IP-166 CECL（云边柔顺闭环）
```python
def cloud_edge_compliant_loop(M, scene, intent, telemetry):
    E_t, contact = observe(telemetry)
    D_E, D_E_plus = reconcile_energy(M.L_E[-1].E_pred, E_t)
    gamma, mode = M.trust.update(D_E, D_E_plus, M.violation,
                                 M.link_latency, M.hash_fail)
    delta_stale = scene_staleness_bound(M.scene_rate(scene))

    if mode != 'local':
        pi_comp = M.cloud.update(aggregate(M.L_E, M.EV_exec, scene))
        C = M.cecc.pack(pid=next_pid(), pi_comp=pi_comp,
                        E_margin=M.cloud.energy_margin(pi_comp),
                        delta_stale=delta_stale, gamma=gamma)
        ok, why = M.cecc.accept(C, E_t, gamma, now())
    else:
        ok, why = False, 'TRUST_LOCAL'

    if ok:
        K = M.cecc.compile(C, M.K_scene_prior, M.intent_constraint)
    else:
        K = M.cee.project_dissipative(M.K_scene_prior)

    K = M.cee.guard(K, telemetry)
    dispatch_impedance(K)
    EV_exec = build_exec_evidence(telemetry, K)
    M.L_E.append(pid, M.cloud.predicted_energy(K), E_t, D_E)
    return M, K, E_t, D_E, gamma, mode, why
```

### IP-167 PCE+++++（五维预算）
```python
class FiveDimBudget:
    def __init__(self, cog, E_max=10.0, E_refill=1.0, link=None):
        self.B_cog = cog
        self.B_energy = EnergyBudget(E_max, E_refill)
        self.B_link = link or LinkBudget(bw=1e6, lat=50e-3, loss=0.01)

    def voi_ce(self, pi, E_t, bandwidth, latency, loss):
        return (self.voi_meta(pi) - self.cost_cog(pi)
                - self.cost_energy(pi, E_t)
                - self.cost_link(bandwidth, latency, loss))

    def fallback(self, state):
        if state.B_energy <= 0:    return 'dissipative_only'
        if state.B_link <= 0:      return 'local_loop'
        if state.B_cog_scene <= 0: return 'general_prior'
        if state.B_cog_intent <= 0:return 'default_constraint'
        return 'normal'
```

### IP-168 TOCC（时序最优提交）
```python
def time_optimal_commit(pi_comp, now, T_c, horizon, lam):
    best, t_star = float('inf'), now
    for t in candidates(now, now + T_c):
        E_exp = cloud.expected_energy(pi_comp, t)
        if not cert_cee(pi_comp, t, horizon):
            continue
        J = lam['D']*expected_discrepancy(t) + lam['s']*staleness(t) \
            + lam['e']*E_exp + lam['c']*cloud.cost(t)
        if J < best: best, t_star = J, t
    return t_star
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性 |
|---|---|---|---|
| CEE | O(d) / 守卫 | O(1) | E_t ≥ 0 恒成立，接触无源 |
| CECC | O(1) 判定 / O(k) 编译 | O(1) | 契约原子，E_margin 覆盖注入 |
| TSEL | 云端 O(cloud) / 边 O(1) | 复用 | A66 下复合系统无源 |
| EBR | O(1) | O(window) | 能量模型失配可检出 |
| CEAT | O(1) | O(1) | 信任可回退，切换有界 |
| CECL | O(闭环) | 复用 | 能量-证据-信任闭合 |
| TOCC | O(|candidates|) | O(1) | 仅提交带无源证书的契约 |

**正确性定理（CECP，云边柔顺协同）**：若 A22–A66 成立，则：
1. **接触无源性**：CEE 保证 E_t≥0，Π_diss 保证 u∈耗散锥，接触无自激。
2. **云边组合稳定**：「慢云 + 快边」在 A66 下无源且 Lyapunov 稳定。
3. **契约安全**：Accept(C)=true ⇒ 能量边界被 E_t 覆盖，K* 同时满足场景先验与意图约束。
4. **失配可检**：云端能量模型偏差超阈值 ⇒ D_E⁺ 上升、CEAT 降权、退回 M_local。

## 5. 本轮最大风险

**一句话**：若云端能量模型系统性低估注入能量、边端能量观测又有时延，则「能量护照」会退化为基于陈旧遥测的虚假无源保证——证书说安全、接触却在泵能；必须用「边端独立能量观测器 + 硬性能量地板 E_t≥ε_tank 无条件投影 + 契约原子否决 + EBR 失配降权」四重硬护栏，确保云端再聪明也不能覆盖边端物理。
