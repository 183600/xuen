# 第 71 轮（承接第 70 轮「BELIEF-RAS」IP-264~274；灵感循环新循环第 1 轮；本轮灵感：「痛点分析」×「抓取」）

> R70 把 epistemic 落到显式状态后验 b_t，用 H[b_t] 作不确定性的「真身」，并用贝叶斯 VoI 决定「看/问/触」。但它默认了两件在接触式操作里根本不成立的事：(1) **不确定性是可自由查询的**——信息动作 g 与任务动作 a 可分离、可逆、便宜；(2) **不确定性是对称的**——H[b_t] 把「不重要的模糊」与「会出事的模糊」等量齐观。真实机器人最贵的信息只能靠**抓取**获得：物体的质量、摩擦、质心、柔顺性、是否易碎，视觉看不见，必须接触；而接触是**不可逆承诺**——抓错会掉、会碎、会伤人。R70 的 VoI 于是会在「熵最高处」花钱，却可能恰好漏掉那个「熵不高但一碰就出事」的痛点。
>
> 本轮两个灵感正好补上两块缺失：
> - **痛点分析**：不问「哪里最不确定」，而问「哪里最疼」——把不确定性按**任务损失**重加权，得到痛点密度与「不确定性的代价」（COU）；预算只花在痛点上，并强制保留一份「盲区探索」预算，防止只盯着已知痛点；
> - **抓取**：把 grasp 从「任务动作」升级为「承诺式实验」——它同时是探针与承诺，信息增益与不可逆风险在同一个动作里耦合，不能再用可逆信息动作的 VoI 公式处理。
>
> 核心命题：**用「痛点泛函」替代「熵」做 epistemic 的排序与预算；用「抓取即实验」把信息获取从可逆查询升级为带不可逆约束的接触动作；不可逆动作必须走「渐进接触升级 + 双通道证据」才允许提交；并把一部分预算强制投向痛点图的盲区。** 命名 **PAIN-GRASP**（Pain-point-Aware Interactive Grasping for Safe Probing）。
>
> 一句话定位：R68 问「测量还准吗」，R69 问「该向谁求证」，R70 问「我相信的世界是什么」，R71 问「**哪里一碰就疼，值不值得为它伸手**」。

## 0. 直觉与动机

**灵感 1（痛点分析 → 熵是错的排序信号）**
直觉：医生不会按「病人哪里最说不清」排优先级，而按「哪里最可能要命」。R70 的 H[b_t] 恰恰是「哪里最说不清」：如果机器人在「背景是灰还是蓝」上熵很高，VoI 会建议去查背景；而在「杯子是满的还是空的（差 50g，可能压垮手腕）」上熵也许只有 1 bit，却必须查。信息论的熵对**损失不敏感**。痛点分析的关键对象是**不确定性的代价**（cost of uncertainty, COU）：在完美信息下我能少损失多少。把 COU 按状态假设分解，就得到「痛点图」——哪里的、多大的概率错误会带来多大损失。

**灵感 2（抓取 → 信息与承诺不可分离）**
直觉：R69 把信息动作 g（看/问/触/等）和任务动作 a 分开，R70 用 VoI 选 g。但在接触操作里，最值钱的信息**只能通过承担风险来获得**：不知道多重就抬一下（可能过载），不知道多滑就试一下（可能滑落），不知道多脆就捏一下（可能碎）。grasp 同时是「实验」和「承诺」，二者不可分离。于是信息价值必须减去「执行这一实验本身带来的期望痛苦」和一个**不可逆惩罚**；信息不是免费的，它有时是用不可撤销的物理后果买来的。

**灵感 3（渐进接触 → 不可逆动作的证据纪律）**
直觉：人拿一个未知重物不会直接猛提，而是「先轻轻托一下 → 感受重心 → 再小幅抬 → 确认后再全抬」。这是把一次不可逆承诺拆成一串**逐级可中止、每级非破坏**的接触。R69 的「单次交互不得单独定案」在物理世界应升级为「不可逆动作前必须有非破坏证据链」。这既给了安全性，也让每一级的观测去更新痛点图。

**灵感 4（痛点图会过时 → 盲区治理）**
直觉：痛点分析最大的陷阱是**只优化已记录的痛点**。部署日志里的痛点是「上次疼过的地方」，而下次事故往往在模型没标出的地方（未知未知）。所以 epistemic 预算必须强制分出一份给**新奇/高分歧**区域做探索，并对痛点图本身的覆盖率做认证；否则 PAIN-GRASP 会变成一台「高效地防御上次事故」的机器。

**灵感 5（严格包含 → 痛点=熵、抓取=可逆查询时退化为 R70）**
直觉：若把损失设成对状态均匀、把抓取当成可逆零成本的信息查询，则 COU 随 H[b] 单调，cVoI 退化为 R70 的 VoI，渐进升级退化为单步查询。PAIN-GRASP 必须在这个边界上**逐指令等于 BELIEF-RAS**，否则新层又是一个需要独立信任的黑箱。这是本轮的理论底线：新层只能是旧层的严格泛化。

## 1. 形式化定义（增量：定义 331–349）

**定义 331（PAIN-GRASP 总览）** PAIN-GRASP = (PPM, GE, CVE, PCE, BSG, GRASP-WM†, BSE†)。三不变式：
(i) **实时流零学习写操作**（继承 R68/R70）；
(ii) **预算二分**：单位时间 epistemic 预算按固定比例 (1−ε_explore) : ε_explore 分给「痛点消解」与「盲区探索」，ε_explore 不得为 0；
(iii) **不可逆纪律**：任何不可逆抓取（R(g) < R_min）必须满足「非破坏前驱证据链 + 双通道一致 + 疼痛预算未越界」，否则禁止提交。

**定义 332（痛点泛函与 COU）** 设任务损失 ℓ(s,a) ≥ 0，最优动作 a*(b) = argmin_a E_{s∼b}[ℓ(s,a)]。定义 Bayes 风险 P[b] = E_{s∼b}[ℓ(s,a*(b))]，以及**不确定性的代价**
COU(b) = E_{s∼b}[ℓ(s,a*(b))] − min_a E_{s∼b}[ℓ(s,a)]（等价于完美信息价值 VoPI）。
**痛点密度** ρ(s) = b(s)·regret(s)，其中 regret(s) = ℓ(s, a*(b)) − min_a ℓ(s,a)。于是 COU(b) = ∫ ρ(s) ds。**痛点集** 𝒫_τ(b) = { s : ρ(s) ≥ τ }。

**定义 333（痛点图 PPM）** 对信念空间做可度量划分 {C_i}，估计每格的风险贡献 COU_i 与密度 ρ_i，并用审计/近失事件做在线校准；输出「痛点排序表」供 CVE 使用。PPM 带版本号与覆盖率证书，参与 J_PAG（定义 344）。

**定义 334（抓取动作与接触状态）** 抓取 g = (p, q, K_p, K_d, F_max, T_g) ∈ 𝒢，含位姿、阻抗、力上限、时长。接触参数 θ_c = (m, μ, c_com, κ, fragility)（质量、摩擦、质心、刚度、易碎度）。接触结果 y = (wrench, slip, tactile, haptic, proprio)。状态 s = (s_task, θ_c)。

**定义 335（抓取即实验 GE）** 抓取同时产生观测与后果：观测模型 p(y | θ_c, g, s_task)，执行损失 ℓ_exec(s, g)。二者共享同一物理动作，**不可分离**——这就是与 R69/R70「信息动作 g 与任务动作 a 可分离」的根本区别。

**定义 336（承诺式信息价值 cVoI）** 对抓取 g，令 b' = BSE(b, y) 为观测后信念：
cVoI(g) = COU(b) − E_{y∼p(·|b,g)}[COU(b')]。
即「抓一次能挽回多少不确定性代价」，这是 R70 VoI（熵降）在损失加权下的推广。

**定义 337（执行痛苦与不可逆惩罚）** 执行痛苦 Pain_exec(g) = E_{s∼b,y}[ℓ_exec(s,g)]；灾难集 Ω_cat（跌落/压碎/伤人的状态-动作对），风险度量 Risk_cat(g) = CVaR_α[ℓ_cat | b, g]。**可逆裕度** R(g) ∈ [0,1]：g 执行后状态可恢复到执行前的程度（0=完全不可逆，如压碎；1=完全可逆，如空载注视）。抓取选择：
g* = argmax_{g∈𝒢} [ cVoI(g) − β·Pain_exec(g) ]，s.t. Risk_cat(g) ≤ ε_cat，且若 R(g) < R_min 则须满足定义 339 的不可逆纪律；若最优值 ≤ 0 则不抓、退回 R70 兜底。

**定义 338（渐进接触升级 PCE）** 构造链 g_1 ≺ g_2 ≺ … ≺ g_n（如：悬停测距 → 轻触 → 微夹持 → 微抬 → 全抬），要求对 i<n 有 R(g_i) ≥ R_min 且 Risk_cat(g_i) ≤ ε_cat。仅当上一级 cVoI 未消解、且上一级观测双通道一致时，才升级到 g_{i+1}。PCE 把一次不可逆承诺拆成「逐级可中止的非破坏证据链」。

**定义 339（痛点门控证据纪律）** 不可逆抓取 g 被允许，当且仅当同时满足：
(a) 存在非破坏前驱 g_prev ≺ g 且 cVoI(g_prev) > θ_irrev；
(b) 至少两个正交通道（力/触觉 vs 视觉/本体 vs 流似然 FMA†）对「痛点假设」判断一致，或 cVoI(g) > θ_high；
(c) Pain_exec(g) 与 Risk_cat(g) 在预算内。
任一条不满足 ⇒ g 作废，保持保守（定义 347）。

**定义 340（盲区治理 BSG）** 定义新奇/分歧分 novel(s) = 后验预测分歧 + 密度模型低支持度。强制把 ε_explore 比例预算投向 argmax novel 的非破坏探针；并输出**覆盖率证书** cov(PPM) = 已认证覆盖的损失质量占比。盲区探索只允许非破坏动作。

**定义 341（痛点预测头）** 廉价 head(z_t, b_t) → (ρ̂, COU_hat) 以 O(1) 给出痛点排序，避免每步对全 loss 场积分；仅当 head 报高痛或 FMA† 异常时调用精算。

**定义 342（接触可辨识性）** 接触前观测 o_0 对 θ_c 的 Fisher 信息 J_pre = E[−∇² log p(o_0|θ_c)]。若 J_pre 在 μ、m 方向秩亏或为零，则称这些参数**接触前不可辨识**；此时任何非接触策略都无法把 H[θ_c|o_0] 降到阈值以下（引理 24）。

**定义 343（痛点图校准门 PCG）** 用可靠图与 ECE_pain 校准 PPM 的 `ρ̂`：ECE_pain > τ_pain ⇒ 禁用痛点排序、退回 R70 的熵排序与纯保守；同时禁止不可逆抓取。

**定义 344（证书 J_PAG）** J_PAG = (J_BELIEF, pain_map_ver, COU_before, COU_after, cVoI, CVaR_exec, reversibility_margin, contact_cert, coverage_cert, pain_ver)。Valid ⇔ Valid(J_BELIEF) ∧ ECE_pain ≤ τ_pain ∧ 定义 339 纪律满足 ∧ 预算二分未越界 ∧ 覆盖率不低于下限。

**定义 345（接触干扰集 ℰ_contact）** 并入 AIC：ℰ_PAG = ℰ_BELIEF × ℰ_contact，其中 ℰ_contact = {滑移误判, 卡死, 压碎, 力传感器饱和, 接触模型失配, 摩擦锥外推}。

**定义 346（参与式审计 VQAuditor-III）** 新增审计：痛点图是否校准、不可逆决策是否有前驱证据链、盲区探索是否被执行、是否出现「为探索而越界」。结论回灌 PPM 与 CVE 的成本先验。

**定义 347（两级退避†，含 Pain Bonus）** 若痛点消解成功且双通道一致：λ = λ_floor(U_ale)（Pain Bonus，比 R70 更不保守但不更低安全）；若未消解/超时/被投毒/ECE_pain 越界/不可逆纪律不满足：λ = λ_floor(U_ale + H[b_t])（未消解 epistemic 视同 aleatoric），且禁止不可逆抓取。⇒ R70 恰为「永不接触/损失均匀」边界。

**定义 348（痛点图持续更新）** PPM 由审计事件、近失事件、抓取结果增量更新；更新在离线/准静态完成，不违反实时流零学习写操作。版本化并可回滚。

**定义 349（损失规范的安全侧约束）** ℓ = ℓ_task + ℓ_safety + ℓ_human，其中 ℓ_safety、ℓ_human 由人工规范给定且不可被在线学习覆盖；任何试图降低安全项权重的更新视为失效（证据纪律的损失侧镜像）。

## 2. 关键算法骨架

```python
# IP-275 PPM：痛点图 + 廉价痛点预测头
class PainPointMap:
    def __init__(self, loss_field, head, ece_gate):
        self.loss, self.head, self.ece = loss_field, head, ece_gate

    def pain_density(self, b_t):
        rho = self.head(b_t)                      # O(1) 廉价排序
        if rho.max() > TAU_PAIN or ECE_bad(self.ece):
            rho = exact_regret_density(b_t, self.loss)   # 精算
        return rho

    def cou(self, b_t):
        return integrate(self.pain_density(b_t))  # ∝ COU(b)

# IP-277 CVE：承诺式 VoI（含执行痛苦与不可逆惩罚）
def choose_grasp(b_t, ppm, budget, c_ras_wm):
    best = None
    for g in grasp_candidates(b_t):               # 由 top 痛点假设生成
        if not budget.allow(g):                      continue
        if not c_ras_wm.certify_contact(g, b_t):      continue
        cvoi  = ppm.cou(b_t) - expected_cou_after(b_t, g, ppm)
        pain  = expected_exec_pain(b_t, g)
        risk  = cvar_catastrophic(b_t, g, alpha=0.05)
        if risk > EPS_CAT or (reversibility(g) < R_MIN and not has_evidence_chain(g)):
            continue                              # 不可逆纪律
        score = cvoi - BETA * pain
        if best is None or score > best.score:
            best = (g, score, cvoi, risk)
    return best if best and best.score > 0 else None

# IP-278 PCE：渐进接触升级
def progressive_contact(b_t, ppm, budget):
    for g in escalation_chain(b_t):               # 悬停→轻触→微夹→微抬→全抬
        if not safe_step(g, b_t) or not budget.allow(g): break
        y = execute(g)
        b_t = BSE_step(b_t, y)
        if ppm.cou(b_t) < TAU_RESOLVED:            # 痛点消解即停
            return b_t, True
        if not two_channel_agree(y, b_t):          # 通道矛盾 ⇒ 不升级
            break
    return b_t, False

# IP-280 BSG：盲区探索（只允许非破坏动作）
def blind_spot_probe(b_t, ppm, budget):
    if budget.explore_remaining <= 0: return None
    s_star = argmax_novelty(b_t, ppm)              # 分歧 + 低支持度
    g = cheapest_non_destructive_probe(s_star)
    return g if g is not None and safe_step(g, b_t) else None

# IP-285 PAIN-GRASP 主闭环
def PAIN_GRASP_round(M, obs):
    z, o = M.mtm.forward(...)
    b_t  = M.bse.step(M.b_prev, o, M.last_action, M.last_g, M.last_y)
    # 1) 痛点排序（熵只作备用通道）
    rho  = M.ppm.pain_density(b_t)
    if M.ppm.ece.breach():                          # PCG 越界 → 退 R70 熵排序
        U_ale, U_epi, modes, _ = M.aud.decompose_from_belief(b_t, M.fmp, o)
        g = None
    else:
        # 2) 预算二分：盲区探索 vs 痛点消解
        g = M.bsg.probe_or(M.cve.choose_grasp(b_t, M.ppm, M.budget, M.c_ras_wm))
        U_ale = expectation(b_t, lambda s: trace(obs_noise_cov(s)))
        U_epi = M.ppm.cou(b_t)                      # 用 COU 替代 H[b_t]
    # 3) 执行：抓取走渐进升级 + 双通道；不可逆需证据链
    resolved = False
    if g is not None:

        else:

            b_t = M.bse.step(b_t, y)
            resolved = two_channel_agree(y, b_t)
        U_epi = M.ppm.cou(b_t)
    # 4) 风险缩放 + 不可逆纪律兜底
    U_floor = U_ale + (0.0 if resolved else U_epi)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    A = M.ach.propose(x_prime, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    if not resolved or M.fma.suspect(M.last_action, o, o_cal, b_t):
        lam = max(lam, 0.8); k = min(k, k_cal_shrink(A, U_epi))
        M.grasp_gate.kill_pending()                 # 禁止后续不可逆抓取
    # 5) 选模态执行 + 审计 + 证书
    mode = select_mode_from_belief(M.fmp, b_t, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_iii.submit_async(b_t, g, resolved, rho, U_ale, U_epi)
    M.ppm.update_offline_async(M.vqa_iii.events)
    M.b_prev = b_t
    return k, lam, mode, (U_ale, U_epi, resolved)
```

## 3. 推导

**引理 23（熵既非 COU 的上界也非下界）** 存在两类反例：(i) 损失对某方向完全平坦而 H[b] 该方向极大 ⇒ COU ≈ 0 而熵高；(ii) 信念以 o(1) 熵集中在一个「最小损失随动作剧烈变化」的窄边界上 ⇒ COU = Ω(L_max) 而熵低。故按 H 分配预算与按 COU 分配预算可以任意不一致。系：R70 在痛点不均匀的真实任务上系统性错配 epistemic 预算。

**引理 24（接触必要性/可辨识性下界）** 设 o_0 为接触前观测。若 Fisher 信息 J_pre 在 θ_c 的某损失相关方向（如 μ 或 m）为零（p(o_0|θ_c) 在该方向不变），则对任意接触前策略，H[θ_c | o_0] ≥ H_prior(θ_c) − tr(J_pre^{-1}) 的下界无法越过阈值；若方向为零则熵完全不降。系：对这些参数，接触不是「可选的更好查询」，而是**唯一**的信息来源。

**引理 25（承诺式 VoI 的贪心近似）** 在抓取结果条件独立、COU 沿证据链近似子模的假设下，PCE 的贪心升级在预算约束下达 (1−1/e) 的 cVoI 近似最优；且每一步的非破坏约束只会收紧可行集，不破坏子模性。系：渐进升级既安全又近似最优，不必枚举全链。

**定理 20（PAIN-GRASP 严格包含 BELIEF-RAS）** 令 ℓ(s,a) 对 a 均匀（所有动作损失相同）、R(g)≡1、Pain_exec≡0、ε_explore=0，则 COU(b) 与 H[b] 同向，cVoI→R70 VoI，PCE→单步查询，定义 339 空真。故在此边界上 PAIN-GRASP 与 BELIEF-RAS **逐指令相同**；一般情况下安全侧不变差（定义 347、339 只收紧可行集）。R68=FLUID=BELIEF=PAIN-GRASP 在「永不交互、损失均匀、接触无信息」的退化边界上一致。

**定理 21（不可逆抓取的风险上界）** 在 ℰ_contact 下，若 PCE 每级 Risk_cat ≤ ε_cat、定义 339 证据链成立、双通道欺骗相关 ρ<1，则每次不可逆抓取的灾难风险 CVaR_α ≤ (1−ε_cat)^{n}·ε_cat + δ_model + δ_p·ρ^{k−1}，其中 n 为升级步数、δ_model 为接触模型误差、δ_p 双通道各自误判率。系：**升级步数不是越多越好**——它降低灾难概率但累积模型误差与时间成本，存在最优 n*。

**定理 22（盲区失配的遗憾界）** 设真实损失场与 PPM 在覆盖证书未覆盖的集合 Ω_blind 上偏差 ≤ Δ，且 |Ω_blind| 的损失质量为 δ。则 PAIN-GRASP 的期望超额遗憾 ≤ (1−ε_explore)·δ·Δ + ε_explore·L_max·δ_explore_gain。系：ε_explore=0 时遗憾随时滞/分布漂移线性增长；有限样本无法把 δ 证到 0，所以只能交付「可测覆盖率」而非「安全保证」——这是痛点分析的结构性盲区。

## 2. 形式化定义（要点版）

**定义 331（总览与三不变式）** 继承 BELIEF-RAS 全部组件（† 升级），新增 PPM/CVE/PCE/GE/BSG/GraspGate。不变式：(i) 零学习写操作；(ii) 预算二分 `(1−ε_explore):ε_explore`，ε_explore>0；(iii) 不可逆纪律（非破坏前驱 + 双通道 + 预算）。

**定义 332（痛点泛函）** `COU(b)=E_b[ℓ(s,a*)]−min_a E_b[ℓ(s,a)]`，`ρ(s)=b(s)·regret(s)`，`𝒫_τ={s:ρ(s)≥τ}`。痛点分析 = 对 ρ 做分解与排序，而非对 H[b] 排序。

**定义 333（PPM）** 信念空间可度量划分 {C_i}，估计每格 COU_i/ρ_i，审计与近失事件在线校准，输出痛点排序表；带版本与覆盖率证书。

**定义 334–335（抓取与抓取即实验）** 抓取 g 同时产生观测 y∼p(y|θ_c,g,s_task) 与后果 ℓ_exec(s,g)。观测与后果共享同一动作，**不可分离**；这是相对 R69/R70「信息动作可分离」的本质差异。

**定义 336（承诺式 VoI）** `cVoI(g)=COU(b)−E_y[COU(b')]`，b'=BSE 更新后信念。

**定义 337（抓取选择）** `g*=argmax[cVoI−β·Pain_exec]` s.t. `Risk_cat≤ε_cat` 且「R(g)<R_min ⇒ 定义 339」；最优值 ≤0 则不抓、退 R70 兜底。

**定义 338（PCE）** 链 `g_1≺…≺g_n`，i<n 时 R(g_i)≥R_min、Risk_cat(g_i)≤ε_cat；仅当上一级未消解且双通道一致才升级。

**定义 339（痛点门控证据纪律）** 不可逆 g 允许 ⇔ (a) 存在非破坏前驱且 cVoI(g_prev)>θ_irrev；(b) ≥2 正交通道一致或 cVoI(g)>θ_high；(c) Pain_exec/Risk_cat 在预算内。任一不满足则作废。

**定义 340（BSG）** 新奇分 `novel(s)=后验预测分歧+密度低支持度`；强制 ε_explore 预算投向非破坏探针；输出覆盖率证书 `cov(PPM)`。

**定义 341（痛点预测头）** `head(z_t,b_t)→(ρ̂,COU_hat)` O(1) 排序；仅高痛/FMA 异常触发精算。

**定义 342（接触可辨识性）** 接触前 Fisher 信息 `J_pre` 在 μ/m 等方向秩亏或为零 ⇒ 接触前不可辨识，接触是唯一信息来源（引理 24）。

**定义 343（PCG 痛点校准门）** `ECE_pain>τ_pain` ⇒ 禁用痛点排序、退回 R70 熵排序，且禁止不可逆抓取。

**定义 344（证书 J_PAG）** 见符号表；Valid ⇔ J_BELIEF 有效 ∧ ECE_pain≤τ_pain ∧ 定义 339 成立 ∧ 预算二分未越界 ∧ cov(PPM)≥下限。

**定义 345（接触干扰集）** `ℰ_PAG=ℰ_BELIEF×ℰ_contact`，`ℰ_contact={滑移误判,卡死,压碎,力饱和,接触模型失配,摩擦锥外推}`。

**定义 346（VQAuditor-III）** 审计痛点图校准、不可逆决策链、盲区执行、探索越界；结论回灌 PPM 与 CVE 成本先验。

**定义 347（两级退避†，含 Pain Bonus）** 痛点消解且双通道一致：`λ=λ_floor(U_ale)`（Pain Bonus）；否则 `λ=λ_floor(U_ale+H[b_t])` 且禁不可逆抓取。R70 为「永不接触/损失均匀」边界。

**定义 348（痛点图持续更新）** 审计/近失/抓取结果触发离线增量更新；版本化、可回滚；不违反实时流零学习写操作。

**定义 349（损失规范安全侧约束）** `ℓ=ℓ_task+ℓ_safety+ℓ_human`；安全/人类项由人工规范给定且不可被在线学习覆盖，违规降低权重即失效。

```python
    def __init__(self, loss_field, head, ece_gate):
        self.loss, self.head, self.ece = loss_field, head, ece_gate

    for g in grasp_candidates(b_t):

        if not c_ras_wm.certify_contact(g, b_t):       continue

    return best if best and best.score > 0 else None

    if g is not None:
        if is_grasp(g):
            b_t, resolved = M.pce.run(b_t, g, M.ppm, M.cia, M.fma)
        else:
            y = M.cia.execute(g)
            b_t = M.bse.step(b_t, y)
            resolved = two_channel_agree(y, b_t)
        U_epi = M.ppm.cou(b_t)
    # 3) 风险缩放 + 不可逆兜底
    U_floor = U_ale + (0.0 if resolved else U_epi)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    A = M.ach.propose(x_prime, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    if not resolved or M.fma.suspect(M.last_action, o, o_cal, b_t):
        lam = max(lam, 0.8); k = min(k, k_cal_shrink(A, U_epi))
        M.grasp_gate.kill_pending()
    # 4) 执行 + 审计 + 证书
    mode = select_mode_from_belief(M.fmp, b_t, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_iii.submit_async(b_t, g, resolved, rho, U_ale, U_epi)
    M.ppm.update_offline_async(M.vqa_iii.events)
    M.b_prev = b_t
    return k, lam, mode, (U_ale, U_epi, resolved)
```

## 4. 推导

**引理 23（熵既非 COU 上界也非下界）** 反例 (i)：损失在某方向平坦而 H[b] 在该方向极大 ⇒ COU≈0、熵高；反例 (ii)：信念以 o(1) 熵集中于「动作间损失反差极大」的窄边界 ⇒ COU=Ω(L_max)、熵低。故按 H 与按 COU 分配预算可任意不一致；R70 在痛点不均匀任务上系统性错配。

**引理 24（接触必要性/可辨识性下界）** 若接触前 Fisher 信息 J_pre 在 θ_c 的损失相关方向（μ、m）为零（p(o_0|θ_c) 沿该方向不变），则任意接触前策略无法降低该方向后验熵，接触是唯一信息来源。

**引理 25（承诺式 VoI 贪心近似）** 抓取结果条件独立、COU 沿证据链近似子模时，PCE 贪心升级在预算下达 (1−1/e) 的 cVoI 近似最优；非破坏约束只收紧可行集、不破坏子模性。

**定理 20（PAIN-GRASP 严格包含 BELIEF-RAS）** 令 ℓ 对 a 均匀、R≡1、Pain_exec≡0、ε_explore=0，则 COU 与 H 同向、cVoI→R70 VoI、PCE→单步查询、定义 339 空真 ⇒ 逐指令等于 BELIEF-RAS；一般情形安全侧不变差（定义 339/347 只收紧可行集）。R68=FLUID=BELIEF=PAIN-GRASP 在「永不交互、损失均匀、接触无信息」边界一致。

**定理 21（不可逆抓取风险上界）** ℰ_contact 下，若每级 Risk_cat≤ε_cat、定义 339 成立、双通道欺骗相关 ρ<1，则单次不可逆抓取灾难风险 `CVaR_α ≤ (1−ε_cat)^n·ε_cat + δ_model + δ_p·ρ^{k−1}`。系：升级步数 n 存在最优 n*（降灾难概率 vs 累积模型误差/时间成本）。

**定理 22（盲区失配遗憾界）** 设真实损失场与 PPM 在未覆盖集 Ω_blind 上偏差 ≤Δ、其损失质量为 δ，则 `E[excess regret] ≤ (1−ε_explore)·δ·Δ + ε_explore·L_max·δ_explore_gain`。系：ε_explore=0 时遗憾随漂移线性增长；有限样本无法把 δ 证到 0，只能交付「可测覆盖率」。

## 7. 本轮最大风险

**一句话**：PAIN-GRASP 把全部安全与效率押在「损失场 ℓ 正确、痛点图 PPM 覆盖了真正会疼的地方」——若 ℓ 漏掉某类安全项，或 PPM 被历史事故过拟合，系统会高效防住「上次疼过的地方」，却自信地伸手探向从未标注、一碰就不可逆出事的盲区；它用不可逆抓取行动，把认知上的不确定直接兑换成物理上的不可逆伤害——**为止痛而伸手，可能正好制造新的痛**。
