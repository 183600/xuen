# 第 59 轮（承接第 58 轮「MSP×LOMO×FEX×EPX×MEG×AGE」IP-139~144；灵感循环第 2 轮；本轮灵感：「产学研合作」×「开源生态」）

> 第 58 轮把证据的独立单位从"模态"细化到"机器谱系簇"，把解释从渲染旁路升级为承诺前的忠实性证书，把评测密封成留一机最差界。它的风险自陈同时暴露了两个更深的缺口：**(a)** 机器谱系只是"技术血缘"，而证据的生产者是**有激励的主体**——产业界隐瞒失败、学界夸大泛化、供应商教会系统应试；当所有主体都希望某个结论成立时，它们会**共同生产**这个结论，而第 58 轮的相关阵 C 只建模误差相关，不建模"动机相关"。**(b)** 依赖血缘比机器血缘更隐蔽——两台"异谱系"机器可能共享同一个 CV 库、同一份预训练权重、同一个数据集；开源生态让这种共享成为默认，也让单点维护者成为单点共因失败，上游一次恶意提交可同时毒化整批"独立"复现。本轮两个灵感各补一条腿：**产学研合作**把"谁说的"升级为"谁有动机说真话"，用 proper scoring + 押金 + 独立复现构造诚实披露的（弱）占优策略，并把"实验室→现场"的死亡谷显式化为成熟度迁移折扣 κ；**开源生态**把"独立"从工件身份推进到**依赖闭包**，用 SBOM/模型卡/数据卡算联合相关上界与有效独立度，用 pinned provenance + 可复现构建 + 密封行为探针隔离供应链。核心命题由"多机可独立、解释可证伪、评测不反身"升级为 **"来源可追责、依赖可复现、激励可相容的证据说可信"**。

核心矛盾：
- **H32（激励不相容 vs 死亡谷）**：声誉若由主体自评或被市场宣传驱动，就奖励最会讲故事的人；而诚实披露依赖"事后可观测"——不可逆接触的真实结果恰恰来得最晚。更麻烦的是成熟度：TRL4 实验室证据迁移到 TRL8 现场会系统性失效，不做迁移折扣，等于把"论文里的成功率"直接当"现场的成功率"。
- **H33（依赖共谋 vs 供应链）**：工件不同 ≠ 证据独立。传递依赖、fork、共享预训练权重与数据集构成隐藏共因；n_eff 若只按工件身份计会虚高。更糟的是单点维护者：一个 bus-factor=1 的库是所有下游的共因失败点，一次上游投毒可同时污染整批"独立"复现。
- **H34（追责 vs 可复现）**：追责要求证据归属到可担责主体，可复现要求第三方能独立重建；但专有数据/闭源权重让二者冲突——最强追责的证据往往最不可复现，最可复现的证据可能无人认领。必须给"可复现等级"分档并按档折扣，且"无人认领的证据"一律拒收。

## 0. 直觉与动机

**灵感 1（产学研合作 → 激励相容的证据生产）**
直觉：证据不是从真空里长出来的，是从"谁出钱、谁验收、谁担责"里长出来的。让同一个受益方既生产证据又评估证据，等于让它给自己判卷。做法：每条证据挂署名主体 p(e)、利益关系 I(p,d)∈{受益/中性/受损} 与押金 stake(e)；用 **proper scoring rule**（Brier/log）对"声明 vs 事后实测"计分，使诚实报告的期望得分最高；由利益冲突方或独立机构做**复现审计**；主体可信度 χ(p) 只由事后实测的指数加权得分生成，**不可自评、不可购买**。声誉从"自我声明"变成"事后清算的账本"。

**灵感 2（产学研合作 → TRL 迁移折扣与死亡谷）**
直觉：实验室里 95% 成功率、现场 70%，差的不是模型而是"世界没按论文长"。把证据按成熟度分档 τ∈{lab, sim, field, fleet}，用历史"同主体同区域从 τ 迁移到 τ' 的失效率"估计迁移折扣 κ(τ→τ')，且**只取上界**（与第 58 轮相关上界 C 同构：宁可低估迁移收益）。承诺规则：证据成熟度必须 ≥ 目标接触等级所需成熟度，或经 κ 折减后的有效证据强度仍过门。死亡谷不再是隐喻，而是一条可审计的折扣系数。

**灵感 3（开源生态 → 依赖闭包有效独立度）**
直觉：两个库长得不一样，可能都 `import` 同一个没人维护的解析器；两个模型哈希不同，可能微调自同一份预训练权重。独立性不能看"成品像不像"，要看"**依赖闭包里有多少是同一个东西**"。给每条证据配 Dep(e)（SBOM + 模型卡 + 数据卡，含传递依赖），定义依赖相关上界 C_dep，与机器谱系相关 C_lin 合成联合上界 C*=1−(1−C_lin)(1−C_dep)，再用它算 n_eff。fork 检测（commit/权重祖先）与 bus-factor 检测（某依赖维护者集中度≤1）一律把下游并入同一共谋簇。共享一条依赖，就共享一份失败。

**灵感 4（开源生态 → 可复现供应链隔离）**
直觉：开源让你默认信任上游，也让一次上游投毒同时击穿所有下游。上游更新进入系统必须过四关：**pinned provenance**（版本+哈希+签名）、**可复现构建**（rebuild；不行则退化为确定性 replay；再不行只能 attestation）、**密封行为探针**（更新前后在隐藏探针集上做行为 diff，防"编译通过但行为被改"）、**隔离期**（影子运行，不接管承诺）。证据据此带可复现等级 r_e∈{rebuild, replay, attest}，按档给权重折扣：能重建的才配"强证据"，只能自证的只配"弱佐证"。

**灵感 5（两灵感合流 → 证据物料清单、追责链与七类证据门）**
直觉：第 58 轮证书 J_q 记录了"结果对不对"，本轮还要记录"**谁认领、依赖什么、能不能重建**"。引入 **EBOM（证据物料清单）**：每条证据追溯到 (主体, 押金, Dep, r_e, τ, 审计记录)；引入**追责链** Acc: d→责任主体集合，要求无环且全覆盖，**无人认领的证据直接拒收**（来源不明的预训练权重 = 孤儿信任）。证据门六类扩为七类：EV-fleet 升级为 **EV-collab**（多机器∧多机构∧利益不冲突），新增 **EV-os**（可复现开源证据，仅 rebuild 级可进不可逆必要集）。纵深从七层到九层：元先验错 ∧ OOD 漏检 ∧ 模态共谋 ∧ 机器共谋 ∧ 依赖共谋 ∧ 供应链投毒 ∧ 激励虚报 ∧ 解释不忠实 ∧ 人也错。

## 1. 形式化定义（增量：定义 145–150）

**定义 145（激励相容来源 ICS）** 主体集 𝒫，证据 e 携带署名 p(e)、利益关系 I(p(e),d)∈{benefit,neutral,harm}、押金 stake(e)。披露机制 M 用 proper scoring rule S(r,o)（Brier/log 的严格 proper 变体）对报告 r 与事后实测 o 计分；诚实占优条件：∀r，E_o[S(θ,o)]≥E_o[S(r,o)]，且押金按"虚报受损"结算。独立审计由 I=harm 或第三方机构在密封复现区执行。可信度 χ(p)=exp-weighted(Σ_t γ^{t}S_t)∈[χ_min,1]，只由事后实测生成，不可自评/购买；证据权重 w_e=w0·χ(p(e))·κ(τ(e)→τ_req)。虚报在长期使 χ 单调下降，故虚报收益 ≤ 一次性收益 − 押金 − 声誉损失。

**定义 146（成熟度迁移折扣 TRD）** 成熟度 τ∈{0:lab,1:sim,2:field,3:fleet}。迁移折扣 κ(τ→τ')=1−F̂_transfer(τ→τ')，其中 F̂_transfer 是历史"从 τ 的证据承诺到 τ' 实测"的失效率**上界**；κ 对 τ 单调不增、对 τ' 单调不增。承诺规则：τ(e)≥τ_req(g) 或 w_e·κ(τ(e)→τ_req)≥θ_w；否则只允许 L0/L1 或触发探询。禁止外推 τ' 未覆盖的迁移。

**定义 147（依赖闭包有效独立度 DCE）** 每源 e 有依赖闭包 Dep(e)（软件 SBOM/模型卡/数据卡，含传递依赖）与祖先集 Anc(e)（commit/权重哈希祖先）。C_dep(i,j)=h(Σ_{m∈Dep(i)∩Dep(j)} ω_m·(1+1[bf(m)≤1]))，其中 ω_m 依赖关键度、bf(m) 维护者集中度。联合相关上界 **C\*_{ij}=1−(1−C_lin,ij)(1−C_dep,ij)**，且若 Anc(i)∩Anc(j)≠∅ 或存在 bf(m)≤1 的共享依赖，则令 C\*_{ij}=1（强制同簇）。有效独立度 n_eff(E)=(Σw_e)²/Σ_{i,j}w_iw_jC\*_{ij}。EV-collab 判据为 n_eff≥N_rep 且跨≥2 机构且利益不冲突，而非台数或工件数。

**定义 148（供应链可复现隔离 SRI）** 上游更新 u 须过：①pin(u)（版本+哈希+签名）；②可复现等级 r_u=max{r: rebuild(u)|replay(u)|attest(u)}；③密封行为 diff d_beh(u,𝒮_hidden)≤θ_b（𝒮_hidden 为隐藏探针集）；④隔离期 T_q（影子运行、不接管承诺）。证据可复现等级 r_e∈{rebuild,replay,attest}，权重乘子 λ_r 满足 λ_rebuild=1>λ_replay>λ_attest>0。行为漂移或签名不符 ⇒ 拒绝更新并回溯依赖该上游的全部历史证据；attest 级证据不得单独进入不可逆接触必要证据集。

**定义 149（证据物料清单 EBOM 与追责链）** EBOM(e)=(p(e),stake(e),Dep(e),r_e,τ(e),audit_log(e),I(p,d))。追责映射 Acc: d→2^𝒫 要求：①全覆盖（每条支撑证据都有署名主体）；②无环（责任不能循环转嫁）；③无主即拒（存在 Dep 中无法署名或无许可证/来源的组件 ⇒ 整条证据作废）；④分摊（各主体责任比例 = 其证据贡献权重，Σ=1）。追责链与权重解耦：**认领责任不因权重小而免责**。

**定义 150（协同证据门 CEG 与七类证据）** 证据类 {EV-probe\*, EV-visit, EV-margin, EV-xmodal, EV-collab, EV-os, EV-human}。EV-collab ⇔ 跨≥2 利益不冲突机构 ∧ n_eff(C\*)≥N_rep ∧ 各源 χ/ρ 声明 ∧ 与融合同侧 ∧ 等级=L1；EV-os ⇔ r_e=rebuild ∧ Dep 全覆盖且无主依赖=0 ∧ 供应链隔离通过 ∧ 行为 diff≤θ_b；EV-os 仅当 r_e=rebuild 时可替代不可逆接触的一条佐证，replay/attest 只限 L1。EV-collab 与 EV-xmodal 合计最多占一个 L1 佐证槽位。不可逆必要证据集={EV-probe\*∨EV-margin∨EV-os(rebuild)}∪human 佐证。证书 J_r 继承 J_q 全检并增补 EBOM/acc/χ/κ/r_e/供应链日志。

## 2. 关键算法伪代码（完整版见产物区）

```python
def incentive_credit(p, claims, outcomes, gamma):
    # 只能吃事后实测；不可自评。χ 是"清算账本"不是"市场口碑"
    s = sum(gamma ** t * proper_score(c, o)
            for t, (c, o) in enumerate(zip(claims, outcomes)))
    return clamp(exp_weighted(s), CHI_MIN, 1.0)

def evidence_weight(e, req_tau):
    return W0 * chi[e.subject] * kappa(e.tau, req_tau) * lambda_r[e.repro]

def dependency_closure(sbom, model_cards, data_cards):
    dep = transitive_closure(sbom) | weights_of(model_cards) | datasets_of(data_cards)
    return dep, {m: bus_factor(m) for m in dep}

def joint_corr(C_lin, dep_i, dep_j, ancestors):
    if ancestors[i] & ancestors[j]: return 1.0          # fork → 同簇
    if any(bf[m] <= 1 for m in dep_i & dep_j): return 1.0
    c_dep = dep_corr(dep_i, dep_j)
    return 1 - (1 - C_lin[i][j]) * (1 - c_dep)          # 上界合成

def collab_evidence(sources, req_tau):
    if len({s.org for s in sources}) < 2: return None
    if any(I(s.subject, 'commit') == 'benefit' for s in sources): return None
    w = [evidence_weight(s, req_tau) for s in sources]
    return 'EV-collab' if fleet_ess(sources, C_star) >= N_REP else None

def supply_chain_admit(u, hidden_probes):
    if not (pin(u) and signature_ok(u)): return 'reject'
    r = max_repro_level(u)                               # rebuild|replay|attest
    if behavior_diff(u, hidden_probes) > theta_b: return 'reject_backtrack'
    return ('quarantine', r) if r != 'rebuild' else ('admit', r)
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| ICS | O(T_p)/主体清算 | O(\|𝒫\|·T) | proper scoring 严格、χ 不可自评、押金可执行 |
| TRD | O(1)/证据 | O(\|τ\|²) 迁移表 | κ 取失效率上界、禁止未覆盖外推 |
| DCE | O(\|Dep\|²)/证据门 | O(\|Dep\|²) | C\* 为上界、fork/bus-factor 强制同簇 |
| SRI | O(T_build+\|𝒮_hidden\|)/更新 | O(更新集) | pin/签名/行为 diff/隔离期 |
| EBOM | O(\|E\|·\|Dep\|) | O(\|E\|·\|Dep\|) | 无环、全覆盖、无主即拒 |
| CEG | O(\|σ\|+\|E\|²) | O(\|σ\|) | 七类证据、EV-os 分级、单槽防重复 |

**正确性定理（PROVE 概要）**：在 A33–A45 上加 (A46) proper scoring + 押金 + 独立审计可执行，χ 仅由事后实测生成；(A47) 迁移折扣 κ 取失效率上界且不做未覆盖外推；(A48) 依赖闭包与祖先诚实完整（SBOM/模型卡/数据卡无遗漏，fork 可检）；(A49) 供应链隔离健全（pin+签名+行为 diff+隔离期）；(A50) 追责链无环且全覆盖，无主证据被拒；(A51) EBOM 与署名不可伪造。则：(i) **激励相容**：诚实披露是弱占优策略，长期虚报使 χ 与权重单调下降，虚报的期望净收益 ≤0；(ii) **依赖保守**：C\*≥C_lin 且 n_eff(C\*)≤n_eff(C_lin)，fork/共享/bus-factor 合并只会降低 n_eff，故 EV-collab 伪复现失效率 ≤δ_rep+ε_eff(n_eff)+δ_sc；(iii) **迁移保守**：成熟度错配的承诺被拒，死亡谷失效率 ≤δ_transfer(κ)；(iv) **追责完备**：任何接受的承诺都有无环且全覆盖的责任链，不存在"孤儿信任"；(v) **单调性**：新机制只经"降权/加佐证/转探询/拒收"影响系统，不存在升险路径；(vi) **终止性与部署界**：每检查点在 k_probes+k_cons+k_expl+k_os 内终止，联合界新增 δ_sc、δ_transfer、δ_claim、δ_os。

## 6. 本轮最大风险

**一句话**：本轮把信任押在"追责可归属、依赖可复现、激励可相容"上，但 χ、押金、SBOM、成熟度迁移表这些**参数本身都由被审计方申报**——一个由产业方与上游维护者组成的联盟，完全可以制造一条"已签名、可重建、依赖干净、责任有人认领"的假证据链，而不可逆接触的真实结果来得最晚，proper scoring 在"结果永远不到"时退化为声誉游戏；开源"多双眼睛"也可能被单一维护者文化收编。必须以有真实牙齿的责任押金、不可被审计对象优化的地面真值探针、供应链密封隔离与"无主即拒"四重护栏兜底，绝不让"可复现/可追责"替代真正的现场验证。

### IP-145 ICS（激励相容来源与可信度清算）

```python
def proper_score(claim, outcome):
    # 严格 proper：诚实报告的期望得分最大（Brier/log 变体）
    return -(claim.p - outcome.y) ** 2 if claim.kind == 'prob' \
           else log(claim.p if outcome.y else 1 - claim.p)

def incentive_credit(p, claims, outcomes, gamma=0.98):
    # 只能吃事后实测；不可自评、不可购买
    s = 0.0
    for t, (c, o) in enumerate(zip(claims, outcomes)):
        s += (gamma ** (len(outcomes) - 1 - t)) * proper_score(c, o)
    return clamp(exp_weighted(s), CHI_MIN, 1.0)

def settle(e, outcome):
    e.stake -= penalty_if_overclaim(e, outcome)       # 押金有牙齿
    chi[e.subject] = incentive_credit(
        e.subject, e.subject.claims, e.subject.outcomes)
    if overclaim(e, outcome):
        backtrack_all(e.subject)                       # 虚报 → 回溯其历史证据
    return chi[e.subject]

def evidence_weight(e, req_tau):
    return W0 * chi[e.subject] * kappa(e.tau, req_tau) * lambda_r[e.repro]
```

### IP-146 TRD（成熟度迁移折扣）

```python
TRL = {'lab': 0, 'sim': 1, 'field': 2, 'fleet': 3}

def transfer_discount(tau_from, tau_to, registry):
    assert TRL[tau_to] >= TRL[tau_from]
    # 历史失效率的保守上界；禁止未覆盖迁移外推
    f = registry.failure_upper_bound(tau_from, tau_to)      # 分层：机构×材质×季节
    return 1.0 - f

def maturity_ok(e, req_tau, theta_w):
    if TRL[e.tau] >= TRL[req_tau]:
        return True
    k = transfer_discount(e.tau, req_tau, transfer_registry)
    return evidence_weight(e, req_tau) * k >= theta_w      # 否则只许 L0/L1 或探询
```

### IP-147 DCE（依赖闭包与联合相关上界）

```python
def dependency_closure(sbom, model_cards, data_cards):
    dep = transitive_closure(sbom)
    dep |= weights_of(model_cards)                         # 预训练权重祖先
    dep |= datasets_of(data_cards)                         # 数据集祖先
    return dep, {m: bus_factor(m) for m in dep}

def joint_corr(C_lin, dep_i, dep_j, anc_i, anc_j, bf):
    if anc_i & anc_j:                                      # fork / 同权重祖先
        return 1.0
    shared = dep_i & dep_j
    if any(bf[m] <= 1 for m in shared):                    # 单点维护者
        return 1.0
    c_dep = dep_corr(shared, key_weight=OMEGA)
    return 1.0 - (1.0 - C_lin) * (1.0 - c_dep)             # 联合上界

def effective_independence(sources, C_star):
    W = sum(evidence_weight(s, s.req_tau) for s in sources)
    denom = sum(w_i * w_j * C_star[i][j] for i in sources for j in sources)
    return W * W / denom

def collab_evidence(sources, C_star, req_tau):
    if len({s.org for s in sources}) < 2:
        return None                                        # 单机构不算产学研复现
    if any(I(s.subject, 'commit') == 'benefit' for s in sources):
        return None                                        # 利益冲突方不能自证
    return 'EV-collab' if effective_independence(sources, C_star) >= N_REP else None
```

```python
def max_repro_level(u):
    if rebuild_bitwise_identical(u): return 'rebuild'

def supply_chain_admit(u, hidden_probes, theta_b):
```

```python
def build_ebom(e):
    dep, bf = dependency_closure(e.sbom, e.model_cards, e.data_cards)
    return EBOM(subject=e.subject, stake=e.stake, dep=dep, bf=bf,

def accountability_chain(d, evidence_set):
    owners = {ebom.subject for e in evidence_set for ebom in e.ebom}
    if any(unowned(e) for e in evidence_set):
        return ('reject', 'orphan_evidence')                # 来源不明 = 孤儿信任
    if has_cycle(ownership_graph(evidence_set)):
        return ('reject', 'responsibility_cycle')
    shares = {p: sum(e.weight for e in evidence_set if p in e.ebom.subject)
              / sum(e.weight for e in evidence_set) for p in owners}
    return ('ok', Acc(d, owners=owners, shares=shares))      # Σ shares = 1
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| ICS | O(T_p) 每次清算 | O(\|𝒫\|·T) | proper scoring 严格、χ 不可自评（A46） |
| TRD | O(1)/证据 | O(\|τ\|²) | κ 取上界、未覆盖不外推（A47） |
| DCE | O(\|Dep\|²)/证据门 | O(\|Dep\|²) | C\* 为上界、fork/bus-factor 强制同簇（A48） |
| SRI | O(T_build+\|𝒮_hidden\|)/更新 | O(更新集) | pin/签名/行为 diff/隔离（A49） |
| EBOM | O(\|E\|·\|Dep\|) | O(\|E\|·\|Dep\|) | 无环、全覆盖、无主即拒（A50/A51） |
| CEG | O(\|σ\|+\|E\|²) | O(\|σ\|) | 七类证据、EV-os 分级、单槽防重复 |
| AGE+ | 离线 O(\|ℱ_hidden\|·T_eval) | O(评测集) | 密封、独立副本、谱系/依赖熵 |
| PCE+++ | O(\|CP\|·(k_p+k_c+k_expl+k_os)·(C_VOI+d_φ)) | O(\|V\|+\|σ\|) | 四预算终止、四态完备 |

**正确性定理（Provenance-Reproducible Incentive Verified Evidence, PROVE）**
假设 A22–A45 成立；**(A46)** 激励相容：S 为严格 proper scoring，押金与独立审计可执行，χ 仅由事后实测生成且不可自评/购买；**(A47)** 迁移折扣保守：κ(τ→τ') 取历史失效率上界、分层估计、未覆盖迁移不外推；**(A48)** 依赖闭包与祖先诚实完整：SBOM/模型卡/数据卡无遗漏，传递依赖与 fork 祖先可检测；**(A49)** 供应链隔离健全：pin+签名+可复现等级+密封行为 diff+隔离期；**(A50)** 追责链无环且全覆盖，无主证据被拒；**(A51)** EBOM 与署名不可伪造、许可证/来源可核验。则：

1. **激励相容性**：诚实披露是弱占优策略；对任意虚报策略，长期期望净收益 ≤ 一次性虚报收益 − 押金 − χ 下降导致的权重损失，且当审计覆盖率 >0 时严格 ≤0；χ 随真实结果单调校准，虚报后回溯其全部历史证据。
2. **依赖保守性**：C\*_{ij} ≥ max(C_lin,ij, C_dep,ij) 且 C\*≥真相关；n_eff(C\*) ≤ n_eff(C_lin) ≤ N；fork/共享依赖/bus-factor 合并只降低 n_eff，故 EV-collab 伪复现失效率 ≤ δ_rep + ε_eff(n_eff) + δ_sc，且随依赖上界收紧单调不增。
3. **迁移保守性**：若 τ(e)<τ_req 且 w_e·κ<θ_w，承诺被拒；由 κ 上界，成熟度错配导致的死亡谷失效率 ≤ δ_transfer。
4. **追责完备性**：任何被接受的承诺都存在无环、全覆盖、Σshares=1 的责任链；无主/循环/未覆盖证据一律拒收，故不存在"孤儿信任"路径。
5. **单调性**：ICS/DCE/SRI/EBOM 只能经 (a) 降低证据权重、(b) 增加佐证数/探询、(c) 拒收或维持不变影响系统；EV-collab/EV-os 只在独立度/可复现等级达标时充当有限的 L1 佐证，不存在"上游更新→更高承诺"的升险路径。
6. **终止性与部署界**：每检查点在 k_probes+k_cons+k_expl+k_os 内终止于 {承诺, 绕行, L2 协商, 安全停}。按检查点取联合界：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta^m(k) + δ_probe + ε_h + δ_ood^m·α_conf
                   + δ_xm·1[L1] + δ_collab·1[L1] + δ_expl_audit
                   + δ_claim(χ) + δ_sc + δ_transfer + δ_os)
             − P(𝓜 陈旧未检出) − P(相关阵/依赖闭包低估未审计)
             − P(评测泄漏) − P(追责链伪造) − P(τ_int ∧ τ_mm 超时 ∧ 安全停失效)
```

关键：**声誉不是自评而是清算**（proper scoring 让诚实成为占优策略）；**独立度按依赖闭包记账而不是按工件记账**（fork 与共享权重挡在门外）；**死亡谷是显式折扣而不是隐含假设**（κ 上界）；**无主证据不是弱证据而是零证据**（孤儿信任直接拒收）；**可复现等级决定证据强度**（rebuild 才配强证据，attest 只能做弱佐证）。

云边协议 CEB+++ → **CEB++++**：云端可下发机构先验、依赖 SBOM、模型卡/数据卡与迁移折扣表，但**上游与被审计对象分离**——任何上游/元更新必须先过供应链隔离（pin+签名+rebuild/replay/attest+密封行为 diff+隔离期），且只能在密封隐藏机队与独立机构复现上通过（逐机最差 ECE 不劣化 ∧ OOD 检出率不降 ∧ n_eff 记账不回退 ∧ 解释忠实率不降 ∧ 追责链无新增无主依赖）才可接管承诺。边端回传证伪事件、依赖漂移与虚报清算进入云端"补盲集"，但**评测隐藏集与责任押金账本永不回流被评测对象**。第 58 轮"评测者与被评测者双隔离"在本轮推广为"**生产者-审计者、上游-下游、被评测-评测三重隔离**"。

## 6. 本轮最大风险

**一句话**：本轮把信任押在"追责可归属、依赖可复现、激励可相容"上，但 χ、押金、SBOM、成熟度迁移表这些参数本身都由被审计方申报——一个由产业方与上游维护者组成的联盟，完全可以制造一条"已签名、可重建、依赖干净、责任有人认领"的假证据链，而不可逆接触的真实结果来得最晚，proper scoring 在"结果永远不到"时退化为声誉游戏，开源"多双眼睛"也可能被单一维护者文化收编；必须以有真实牙齿的责任押金、不可被审计对象优化的地面真值探针、供应链密封隔离与"无主即拒"四重护栏兜底，绝不让"可复现/可追责"替代真正的现场验证。
