# 第 4 轮（灵感循环第 4 轮；本轮灵感：「预测性维护」×「比赛策略」）

> **基线**：第 3 轮 InstructGauge（IP-321–327；定义 432–447；引理 51–58；实验 E441–E456）。第 2 轮 ToolGauge 与第 1 轮 LeanGauge / MODGAUGE 骨架继续继承不变。
> 本轮纪律：**增量升级 + 严格退化**。预测只允许「提前」、不允许「推迟」安全动作；博弈只允许「分配剩余」、不允许「削减底线」；任一环节不可用都必须能一键退回。预测与博弈是增强项，不是依赖项。

## 0. 直觉与动机

**灵感 1（预测性维护 → 把「事后隔离」升级为「事前换约」）**
直觉：ToolGauge / InstructGauge 目前是**反应式**的——等到逐条回执显示漂移越界，才隔离并重校准。工业预测性维护（PHM）的做法相反：用**退化过程 + 生存分析**预测剩余可用寿命（RUL），在「潜在失效 P」到「功能失效 F」之间的 P-F 间隔内提前维护。映射到本系统：被维护的「设备」不是机械臂，而是**校准契约本身**——它在每次探测回执里留下退化痕迹；把回执残差当作状态监测信号，就能估计「契约覆盖即将跌破 1−α」的 RUL。关键增量在于：**不需要新传感器**，预测器复用已有回执轨迹。关键纪律在于：预测性维护只能**把维护提前**，绝不能**把反应式隔离推后**——否则预测就从安全网变成了赌注。

**灵感 2（比赛策略 → 预算是被争夺的稀缺资源，用赛制化分配）**
直觉：盲区不是排队等预算，而是在**竞争**同一份探测预算与同一段安全时限。比赛策略给出三种现成武器：(a) **最小最大 / 混合策略**——若缺陷位置可被视为对手选择，则任何确定性探测顺序都可被针对，必须随机化；(b) **锦标赛 / 拍卖式配置**——让每个盲区按边际价值「竞价」，用诚实机制（VCG 或截止期感知的价密排序）分配，得到可审计、激励相容的预算配置；(c) **后悔最小化**——多轮对抗下用 EXP3 类算法保证不逊于事后最优固定赛程。随机化与可审计天然冲突，解法是**承诺-揭示**（commit-reveal）：随机种子先承诺后揭示，审计可精确复放，而对手在承诺前无法预测。

**灵感 3（两者耦合 → 「维护窗口即暴露窗口」的时序博弈）**
直觉：预测性维护会挑一个它认为「安全」的时刻去换约 / 重校准；可这个时刻恰恰是契约覆盖最弱、系统最盲的窗口。一个能观察或学习维护节律的对手，会把缺陷注入精确对准这个窗口。更隐蔽的耦合是：RUL 预测给出的「安全余量」会被预算竞争当成可交易筹码——把今天的维护推迟，去换别处更多覆盖，等于**向未来借安全**。所以本轮不是「预测 + 博弈」简单相加，而要加三根结构支柱：**预测-反应双闸**（预测只提前）、**维护-暴露对偶守卫**（窗口内用影子契约压暴露）、**维护债务上限**（禁止无界借未来），再叠加**可审计混合策略**与**截止期感知的诚实分配**。

## 1. 研究问题（本轮要回答什么）

- **Q1（预测的支配性）**：预测性维护在什么条件下**严格支配**反应式隔离（不提高失效概率）？预测误差多大时支配性失效？
- **Q2（博弈的收益与代价）**：随机化 + 竞价配置能在多大程度上降低最坏情况漏检，同时保持预算可行与审计可复现？
- **Q3（耦合的时序风险）**：预测性维护窗口是否成为新的攻击面？能否用影子契约与维护债务上限把暴露压回可界？

## 2. 三条设计原则（雏形，正式化见产物区定义 448–463）

**P1 预测只提前（Predict-Only-Advance）**
预测性维护触发时刻 `t_maint^pred` 只能与反应式阈值取 `min`：`t_maint = min(t_maint^pred, t_maint^react)`。预测的作用是**把维护提前**；任何「预测说还健康所以先不维护」都不得越过反应式隔离线。这保证预测器即使完全失准，系统也不会比 InstructGauge 更差。

**P2 底线不参与竞价（Safety Floor Off-Auction）**
拍卖 / 锦标赛只能分配**剩余预算** `B − B_floor`。安全底线（不可逆屏障、最小回执数、影子契约覆盖下限）是**硬预留**，不进入竞价。竞争策略优化的是「剩余怎么花」，不是「底线能不能卖」。

**P3 窗口必须被双重覆盖（Dual Coverage over Maintenance Window）**
换约 / 重校准窗口内主契约覆盖率下降，必须由**影子契约**提供不低于 `c_min` 的降级覆盖，否则窗口本身就不合法。窗口暴露 `E_s(W) = ∫_W (1 − coverage(t)) dt` 受硬上界约束。

## 3. 与基线的接口（如何退化）

- 无退化历史 / 生存模型不可校准 / 单调风险率假设不成立 ⇒ 关闭 PHM，回到 ToolGauge 反应式隔离；
- 无重复回合 / 无对手模型 / 随机数不可承诺 ⇒ 关闭 Arena，回到 InstructGauge 确定性信息增益分配；
- 影子契约不可用 ⇒ 禁止开启维护窗口，维护退回反应式隔离（此时窗口 ≡ 隔离窗，等价 ToolGauge）；
- 维护债务触顶 ⇒ 强制立即维护并冻结新增预算；
- InstructGauge 失效 ⇒ ToolGauge；ToolGauge 失效 ⇒ LeanGauge；LeanGauge 失效 ⇒ MODGAUGE 原样。

## 4. 预期贡献

1. 一个「回执即状态监测」的契约健康度 / RUL 预测口径，配合**预测-反应双闸**，使预测性维护在不提高失效概率的前提下获得提前量；
2. 一个**截止期感知 + 激励相容**的预算锦标赛，把盲区竞争显式化、可审计化；
3. 一个**承诺-揭示混合策略**，在对抗性缺陷放置下降低可被利用性，同时保持审计可复现；
4. 一个**维护-暴露对偶守卫 + 维护债务上限**，把「预测安全余量被竞争性借出」的风险压回可界；
5. 可证伪路径：E457–E472 覆盖 RUL 校准、P-F 触发、混合策略可被利用性、激励相容、维护窗口暴露与 50Hz 保全。

## 5. 本轮最大风险

**一句话**：预测性维护把一个「未知即安全」的系统改造成「已知即赌注」的系统——一个看似校准良好的 RUL 预测会诱使调度把维护推迟到 P-F 边界，而比赛策略又在预算压力下把这份预测出来的安全余量当作可交易筹码借出；一旦分布漂移让预测失准，推迟的维护恰好落在对手选定的维护-暴露窗口里，形成相关性失效。

## 2. 形式化定义（要点）

**定义 448（健康状态与退化过程）** 组件 / 契约 `s` 的健康度 `h_s(t) ≥ 0` 服从单调退化过程（默认 Gamma 过程：`h_s(t+Δ) − h_s(t) ~ Gamma(ν_s Δ, ν_s/η_s)`；备选逆高斯）。观测量为逐条回执残差 `r_t`，满足 `r_t = h_s(t) + ζ_t`（`ζ_t` 零均值观测噪声）。单调性 `h_s(t+Δ) ≥ h_s(t)` 是后续支配性引理的前提，非单调退化一律拒绝进入 PHM。

**定义 449（RUL 生存函数与风险率）** 设功能失效阈值 `h_fail`，`RUL_s(t) = inf{τ ≥ 0 : h_s(t+τ) ≥ h_fail}`；生存函数 `S_s(τ) = P(RUL_s(t) > τ | 回执 1:t)`，风险率 `λ_s(τ) = −d/dτ log S_s(τ)`。后验由贝叶斯更新逐回执递推，并输出 **PIT 校准残差**（`S_s(RUL_s^obs)` 应近似 U(0,1)）供 E457 检验。

**定义 450（P-F 间隔与预测触发）** `[t_P, t_F]` 为潜在失效到功能失效的间隔。预测维护触发：`t_maint^pred = inf{ t : P(RUL_s(t) ≤ H_maint) ≥ p_fail^max }`，且必须留边距 `t_maint^pred ≤ t_F − δ_m`，`δ_m` 吸收估计误差。`H_maint < t_F − t_P`，否则 P-F 窗口不够完成换约，退回反应式。

**定义 451（预测-反应双闸）** `t_maint = min(t_maint^pred, t_maint^react)`，其中 `t_maint^react = inf{t : drift(σ_t) > δ_c}` 沿用 ToolGauge 定义 435。即预测只能**提前**触发，永不能把反应式隔离**推后**。`PHM off ⇒ t_maint^pred = +∞`，自动退回 ToolGauge。

**定义 452（维护债务）** `D_s(t) = ∫_0^t max(0, λ_s(τ) − λ_ref) dτ`，度量「相对基线风险率多冒的险」。系统级约束 `Σ_s D_s(t) ≤ D_max`；触顶即冻结一切「借未来」的推迟，强制维护。债务随维护归零。

**定义 453（维护-暴露对偶与影子契约）** 维护窗口 `W_s = [t_maint, t_maint + TW_s]` 内主契约覆盖率下降。影子契约 `s'` 提供降级覆盖 `coverage_{s'}(t) ≥ c_min`，窗口暴露 `E_s(W) = ∫_{W_s}(1 − coverage(t)) dt`，其中 `coverage(t) = max(coverage_s, coverage_{s'})`。若 `c_min` 无法满足或 `E_s(W) > E_max`，则窗口不合法，维护退回反应式隔离。

**定义 454（预算锦标赛）** 每个盲区 `s` 报出价值函数 `v_s(x)`（`x` 为分配预算），与截止期 `d_s`（来自 RUL 的 `t_maint^pred`）。配置问题：`max Σ_s v_s(x_s) s.t. Σ_s x_s ≤ B_avail, x_s ≥ 0`，其中 `B_avail = B − B_floor`。底线 `B_floor`（不可逆屏障 + 最小回执 + 影子契约开销）**不进入竞价**。

**定义 455（截止期感知价密分配）** 若 `x_s ∈ {0,1}`（选或不选），按价密 `ρ_s = v_s / (cost_s + risk_s)` 降序做贪心，并对 `d_s` 做 EDF 可行性检查；不可行则拒绝最低价密者。该规则是分数背包的最优解、0-1 背包的 `1/2` 近似，且对截止期单调。

**定义 456（诚实机制）** 分配 + 支付 `M = (allocation, pay)` 满足：真实报 `v_s` 是弱占优策略（DSIC）；`pay` 不超过报价（个体理性）；总收入 / 支出不超预算（预算可行）。默认实现为截止期约束下的 VCG 变体；若 VCG 不可行，退回定义 455 的固定价密规则（此时放弃 DSIC，保留可审计）。

**定义 457（混合策略检查博弈）** 零和博弈：对手在 `N` 个盲区中放置缺陷（分布 `y`），检查者选探测分布 `p ∈ Δ(A)`；收益为漏检损失 `L(p,y) = Σ_i (1−p_i) y_i loss_i`。值 `V* = min_p max_y L(p,y) = min_p max_i (1−p_i) loss_i`。任何纯策略 `p=e_i` 可被 `y=e_j, j≠i` 完全利用；混合策略把可被利用性从 `max_i loss_i` 降到 `V*`。

**定义 458（可审计随机：承诺-揭示）** 本轮开始前发布 `commit = H(ξ)`（`ξ` 为种子），按 `ξ` 从 `σ` 抽样；轮末揭示 `ξ` 供审计重放。性质：(i) 审计者由 `(commit, ξ, σ)` **逐位复现**随机抽样；(ii) 未揭示前对手无法从 `commit` 预测 `ξ`（抗前向性）；(iii) 分布仍是 `σ`，故安全保证不变。随机性只改**顺序**，不改**配额**与**底线**。

**定义 459（后悔最小化赛程）** 多轮对抗下用 EXP3：第 `t` 轮按 `w_i(t) ∝ exp(η_t · 估计收益_i)` 抽样，观测后更新。后悔 `Regret_T = max_i Σ_t v_i(t) − Σ_t v_{a_t}(t) ≤ O(√(N T log N))`。仅当 `T ≥ T_min` 时启用，否则回到 InstructGauge 的单轮确定性分配。

**定义 460（健康度-预算联合准入）** 仅当 `S_s(H_maint) ≥ 1−p_fail^max` **且** 分配后 `B_avail ≥ 0` 时，才把预算准入给 `s`；否则先安排维护。即：健康度不足者不参与竞价，避免「病号抢预算」。

**定义 461（维护窗口时序博弈与抖动披露）** 对手以概率 `q` 观测维护节律。为降低被定时，维护时刻加入抖动 `j(t) ∈ [0, J_max]`（由承诺种子生成、可审计）；部分披露策略：只公布 `J_max` 上界，不公布具体 `j(t)`。抖动不得使 `t_maint` 越过 `t_F − δ_m`。

**定义 462（窗口暴露预算）** `Σ_s E_s(W_s) ≤ E_max` 且单窗口 `E_s(W_s) ≤ E_max^{single}`。暴露预算与探测预算**分账**：不能用手头的探测预算「购买」一段更长的暴露窗口。

**定义 463（ArenaGauge 主闭环契约与审计证书）** `ArenaCert = (ι, {h_s}, {t_maint^pred}, allocation, σ, commit, receipts, claims)`。审计链：指令 ι → 健康度 / RUL → 维护时刻 → 预算配置 → 随机抽样（承诺-揭示）→ 回执 → 主张（继承 NCB）。任一环不可复现即证书无效，退回上一轮基线。

# IP-328 PHM-Cal：回执即状态监测，输出 RUL 生存函数 / 风险率
class PHMCal:
    def update(self, s, receipts):
        hist = self.history[s]
        if len(hist) < N_HIST or not monotone(hist):
            return None                                  # 不可校准 ⇒ 关闭 PHM
        post = self.bayes_update(self.deg_model[s], hist + receipts)  # Gamma/IG 后验
        S    = lambda tau: post.survival(tau, h_fail=self.h_fail[s])
        lam  = lambda tau: post.hazard(tau, h_fail=self.h_fail[s])
        pit  = post.pit(receipts)                        # PIT 校准残差（E457）
        return RULPosterior(S=S, hazard=lam, pit=pit)

# IP-329 PFS：P-F 间隔内提前维护；预测只提前
class PFScheduler:
    def trigger(self, s, rul, drift_ok):
        if rul is None:                                  # PHM 关闭
            return self.reactive(s)                      # ToolGauge 隔离
        t_pred = rul.first_time(lambda tau: rul.S(tau) < 1 - P_FAIL_MAX)
        t_pred = min(t_pred, rul.t_F - DELTA_M)          # 留边距
        t_react = self.reactive(s) if not drift_ok else INF
        jitter  = self.commit_sample(s)                  # IP-331 生成，可审计
        return min(t_pred + jitter, t_react)             # 双闸：只取更早者

# IP-330 Arena：截止期感知 + 诚实分配（只分剩余预算）
class BudgetArena:
    def allocate(self, spots, B):
        B_avail = max(0, B - B_FLOOR)                    # 底线硬预留
        live = [s for s in spots if self.joint_admit(s)] # 健康度-预算联合准入
        if not live: return {}
        if self.vcg_feasible(live, B_avail):
            return self.vcg_with_deadlines(live, B_avail)  # DSIC
        order = sorted(live, key=lambda s: s.rho, reverse=True)  # 价密贪心
        return self.edf_pack(order, B_avail)             # 截止期可行检查

# IP-331 MixStrat：承诺-揭示混合策略（可审计随机）
class MixStrategy:
    def begin_round(self, sigma):
        xi = os.urandom(32)
        self.commit[round] = sha256(xi)
        self.publish(self.commit[round])
        self.draw = sample(sigma, seed=xi)               # 顺序随机化
        return self.draw
    def end_round(self, sigma, draw):
        xi = self.reveal(round)                          # 揭示种子
        assert sample(sigma, seed=xi) == draw            # 审计逐位复现
        return AuditOK(draw, xi)

# IP-332 DWG：维护-暴露对偶守卫（影子契约覆盖）
def dual_window_guard(s, W, shadow):
    if shadow is None or shadow.coverage < C_MIN:
        return None                                      # 窗口不合法 ⇒ 退回隔离
    E = integrate(lambda t: 1 - max(ctrl_cov(s, t), shadow.coverage), W)
    if E > E_MAX_SINGLE:
        return None
    return WindowCert(W, shadow, E)

# IP-333 AgroGauge-8C 闭环（在 7C 前加预测与竞价）
def arenagauge_8c(M, s, ell):
    out  = M.nlib.ground(ell, M.scene, M.ontology)       # I
    iota = out[0] if out else M.default_iota
    H    = M.lbox.hypothesize(s, M.dbox.R[s], iota)      # H
    C    = M.iac.plan_chunk(iota, H, M.tools, M.budget_left(s), M.drift_bound(s))
    rul  = M.phmcal(s, M.receipts(s))                    # P：预测 RUL
    if rul is not None and M.pfs.trigger(s, rul, M.drift_ok(s)):
        win = dual_window_guard(s, M.pfs.window(s), M.shadow(s))
        if win is not None:
            M.schedule_maintenance(s, win)               # 提前换约（只提前）
    alloc = M.arena.allocate(M.spots(), M.budget_left(s))  # A：预算锦标赛
    if not M.mix.audit_ok():
        alloc = M.deterministic_alloc(M.spots(), M.budget_left(s))  # 退回 InstructGauge
    cert = M.cvc.commit(C, M.env, iota)                  # E：块执行 + 否决点
    receipts = cert.receipts
    mu, Sig = M.apcal.calibrate(receipts, H, s)
    if not M.apcal.cross_validate(mu, Sig, M.cross_receipt(s)):
        return stub_and_red(s, "cross_failed")
    M.mreg.hot_replace_at_quiescence(M.dpe, M.apcal.update_contract(M.dpe, mu, Sig, s),
                                     cert.boundary)
    return ArenaCert(iota, rul, alloc, M.mix.commit, receipts)

# IP-334 主闭环（50Hz 路径不变，预测/竞价异步下沉）
def ArenaGauge_round(M, obs, audio, tac, depth, det, ell=None):
    if M.round % ROUND_STRIDE == 0:
        M.mix.begin_round(M.sigma)                       # 承诺先于观测
        submit_async(M.phm_refresh_all)                  # 异步健康度刷新
        submit_async(M.arena_routine)                    # 异步竞价
    for s in M.dbox.detect_blind_spot():
        if s not in M.maint_inflight:
            M.maint_inflight.add(s)
            submit_async(arenagauge_8c, M, s, ell)
    return MODGAUGE_round(M, obs, audio, tac, depth, det)

## 4. 推导

**引理 59（预测性维护的安全支配）** 在单调退化、双闸 `t_maint = min(t^pred, t^react)` 与相同反应式基线下，预测性维护的累积失效概率不超过纯反应式：`P(失效≤t) ≤ P_react(失效≤t)`。*证明*：双闸保证任何维护时刻不晚于反应式阈值；单调退化下「更早维护 ⇒ 健康度随机占优」，故首次越阈时刻的随机变量被逐点支配。`PHM off` 时 `t^pred=+∞`，退化为等号。

**引理 60（RUL 误差的鲁棒支配）** 设 RUL 估计误差在 P-F 间隔内一致有界 `|RUL^est − RUL^true| ≤ ε`，且安全边距 `δ_m ≥ ε`。则预测触发仍满足 `t_maint^pred ≤ t_F`，引理 59 的支配性保持；当 `ε > δ_m` 时支配性可能失效，须回退反应式。*证明*：由 `t_maint^pred ≤ RUL^est ≤ RUL^true + ε ≤ t_F − δ_m + ε ≤ t_F` 得触发仍早于功能失效；误差超过边距时上界不再成立，构造反例即可证必要。

**引理 61（维护-暴露对偶界）** 影子契约覆盖 `c_min > 0` 时，窗口暴露 `E_s(W) ≤ (1 − c_min)|W_s|`；无影子契约时 `E_s(W) = |W_s|`。若对手以概率 `q` 已知窗口且在窗口内注入，则注入成功概率下降至少 `(1 − c_min)` 倍。*证明*：`coverage(t) ≥ c_min` 逐点代入定义 453 的积分即得；无影子时 `coverage_s=0`（换约中）给出上界 `|W_s|`。

**引理 62（混合策略的最小最大优势与可审计性）** 对定义 457 的零和博弈，`V* ≤ min_i loss_i`，且纯策略的最坏情况损失为 `max_i loss_i`；随机化把可被利用性降低 `max_i loss_i − V*`。承诺-揭示不改 `σ` 的分布，故安全保证不变，同时审计可逐位复放。*证明*：`p` 取均匀分布得上界；纯策略 `e_j` 被 `y=e_i (i≠j)` 利用到 `max_i loss_i`。承诺-揭示下抽样仅在揭示后才可验证，未揭示前 `ξ` 对对手是均匀随机的，分布不变。

**引理 63（激励相容、预算可行与截止期可行）** 定义 456 的 VCG 变体在截止期约束可分离时满足 DSIC、IR、预算可行；不可分时退回定义 455 的价密贪心，预算可行与截止期可行仍保持，但放弃 DSIC（转为可审计）。*证明*：VCG 的 DSIC 来自支付等于外部性；预算可行由 `B_avail` 的硬约束给出；EDF 在单机可抢占 / 单位任务下可行当且仅当对任意区间 `Σ cost ≤ 长度`。

**引理 64（后悔界与竞争比）** EXP3 赛程满足 `Regret_T ≤ O(√(N T log N))`；相对事后最优固定赛程的竞争比 `→ 1`（`T→∞`）。单轮 / 短回合 `T < T_min` 时退化为确定性分配，后悔界不适用但等价 InstructGauge。*证明*：标准 EXP3 分析（Auer et al. 2002）在 `η_t = √(log N/(N t))` 下给出；退化情形由 `T_min` 截断。

**引理 65（维护债务上界与相关性失效抑制）** 在 `Σ_s D_s ≤ D_max` 且债务随维护归零下，任一时刻「被推迟的维护」总风险有界，且不会形成跨组件的相关性推迟链；维护窗口叠加数受 `E_max` 与 `B_floor` 双重约束。*证明*：债务是各组件风险的加性度量，上界限制总推迟量；`E_max` 限制同时打开的窗口数，避免「全系统同时换约」的相关性失效。

**引理 66（严格退化与 50Hz 保全）** 新增预测 / 竞价全部异步下沉，主循环仅增加常数次任务提交；PHM 不可校准 ⇒ `t^pred=+∞` 回反应式；Arena 不可审计 ⇒ 确定性分配；影子契约缺失 ⇒ 窗口不合法回隔离。故 `ArenaGauge → InstructGauge → ToolGauge → LeanGauge → MODGAUGE` 逐级等价。主循环新增周期继承 InstructGauge 引理 58，`< 0.2ms`。*证明*：逐模块检查退化条件与接口不变量；异步任务不占 50Hz 关键路径。

## 8. 本轮最大风险

**一句话**：预测性维护把「未知即安全」改造成「已知即赌注」——校得越准的 RUL 越会诱使调度把维护推到 P-F 边界，而预算锦标赛会把这份预测出来的安全余量当成可交易筹码借给未来；一旦分布漂移使预测失准，推迟的维护恰好落进对手选定的维护-暴露窗口，形成相关性失效。缓解只能依赖结构（双闸使预测只提前、影子契约使窗口暴露有界、维护债务上限禁止无界借未来、承诺-揭示使随机化可审计），并以 E458/E460/E466/E469 主动证伪。
