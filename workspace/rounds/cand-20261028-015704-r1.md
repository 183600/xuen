# 想法区 · 新循环第 1 轮（承接 v9.0 ICF-PACT）：当 NO 很便宜、YES 很贵时，二分不再是答案

**灵感词**：竞争分析 / problem transformation / 平均情况分析

**起点**：v9.0 ICF-PACT 已经把「状态即部分证书」做出来了：`(L,U,s,m,\pi)` 在每次 probe 后都可审计，`L=U` 时自动最优；252 例 356 次状态审计 0 失败、252/252 最终认证。它留下的最大风险是：`lower-first` 在 252 例上一次闭合，可能只是因为这批语料的 LP 下界过紧；多叶 frontier 和割循环还没真正跑起来。

本轮不想再改证书层，而是问一个更窄的问题：**外层 probe 策略到底在优化什么？** v9.0 把每次 probe 的代价当成 1，于是 `lower-first` 和二分只是在比较 probe 次数。但固定 \(h\) 判定器的代价不是均匀的：NO 往往在根 LP 就结束，YES 却可能展开一棵很深的调度树。如果 NO 便宜、YES 贵，那么「probe 次数最少」不等于「LP 最少」，单位代价下的二分最优性也不再成立。

## 一、先量一下：弱语料上的代价是极端不对称的

我用了 `hap.weak_rows(4)` 的 160 例（初始 gap 4–13），对每个 \(h\in[L,U-1]\) 都跑一次完整 `pact_decide`，记录 verdict、搜索 LP、证书 LP 和 \(C_{\max}\)。全量 profile 见 `exp/v8u/cabs_profile.json`。几个数字：

- **NO**（\(h<\mathrm{OPT}\)）：315 次，平均 1.39 个搜索 LP；\(h\le\mathrm{OPT}-2\) 时几乎是 1.0，\(h=\mathrm{OPT}-1\) 时 1.82。
- **YES**（\(h\ge\mathrm{OPT}\)）：583 次，平均 5.60 个搜索 LP；\(h=\mathrm{OPT}\) 时 3.90，\(h=\mathrm{OPT}+1\) 时 5.14，\(h=\mathrm{OPT}+2\) 时 6.36，最坏到 20。
- 160 例里只有一个 UNKNOWN：`base/large_het/7` 在 \(h=L=39\) 上返回 UNKNOWN。

这直接推翻了 v9.0 的隐含假设。弱语料上：

| 策略 | probes | 搜索 LP | 证书 LP | 总 LP |
|---|---:|---:|---:|---:|
| `binary` | 421 | 1581 | 248 | 1829 |
| `lower-first` | 554 | 1746 | 351 | 2097 |
| `linear`（永远问 L） | 469 | 1037 | 387 | 1424 |
| `cabs-1`（本轮） | 367 | 1017 | 277 | **1294** |

二分在单位代价下是最优的，但在非对称代价下比「从 L 开始一格一格问」还差 51%；`lower-first` 在弱语料上更差，因为它的第一问之后马上转二分，仍然会买到昂贵的 YES。`lower-first` 在 252 例上的优势没有迁移过来——这正是 v9.0 最后一句风险的具体形态。

## 二、第一次试错：给 probe 加一个固定偏置

最自然的修正是「按代价比偏置二分」：如果 YES 比 NO 贵 \(\rho\) 倍，就把分割点从 \(1/2\) 移到 \(1/(1+\rho)\) 附近。我试了一个固定偏置的版本，结果在两个语料上都尴尬：偏置太小，退化成 `linear`，浪费 probe；偏置太大，在 \(\mathrm{OPT}=L\) 的实例上第一问就买到昂贵 YES。更根本的是，最优偏置依赖 \(P(\mathrm{OPT}=L)\)、gap 和当前已经观测到的 NO/YES，而不是一个全局常数。

这次失败给出一个有用的结论：**外层不是「带权二分」，而是一个带先验的阈值决策树**。每个 \(h\) 的代价取决于结果（NO/YES），而结果又取决于未知的 OPT；这正是决策树而不是二分该处理的东西。

## 三、把外层问题变换成「非对称代价的区间决策树」

设初始括号 \([L_0,U_0]\)，未知量 \(d=\mathrm{OPT}-L_0\in\{0,\dots,g_0\}\)。给定先验 \(w_d\)，在状态 \([i,j]\)（对应 \([L_0+i,L_0+j]\)）问 \(h\) 的期望代价是

\[
P_{i,h}\,c_Y(h)+(1-P_{i,h})\,c_N
+P_{i,h}V(i,h)+(1-P_{i,h})V(h+1,j),
\]

其中 \(P_{i,h}=\sum_{d=i}^h w_d/\sum_{d=i}^j w_d\)，\(V(i,i)=0\)，\(V(i,j)\) 取所有 \(h\in[i,j-1]\) 的最小值。YES 把上界压到 \(h\)，NO 把下界抬到 \(h+1\)；UNKNOWN 不改变区间，只是把 \(h\) 加入 blocked。这个 DP 就是「非对称代价的最优字母决策树」，是标准最优 BST DP 的一个变体。

代价模型用弱语料拟合：

\[
c_N\approx 1.39,\qquad
c_Y(h)\approx 4.10+0.84\,(h-\mathbb E[\mathrm{OPT}\mid \mathrm{OPT}\le h]).
\]

先验 \(P(d\mid g)\) 用 Laplace 平滑，并向全局 \(d\)-先验收缩（shrinkage 5），避免稀有 gap 把先验压到一个点上。每个测试实例的先验和代价模型都在其余 159 例上拟合（leave-one-out），测试实例的 OPT 不参与任何决策。

## 四、第二次试错：全 DP 的先验过拟合

一开始我跑的是「每一步都用 DP」的 `cabs-dp`。在 5 折交叉验证上，它的搜索 LP 是 1027，确实比 `linear` 的 1037 好，但最坏竞争比冲到 14：稀有 gap 的先验被一两个训练样本主导，第一问会跳到 \(L+2\) 甚至更高；一旦 \(\mathrm{OPT}=L\)，这个 YES 很贵。后来加了 shrinkage，第一问稳定在 \(L+1\)（159/160），最坏竞争比降到 4。再后来发现，**第一步之后 DP 的 continuation 在弱语料上几乎总是退回 `linear`**，所以 `cabs-1`（第一问用 DP，之后永远问 L）和 `cabs-dp` 的 160 例结果完全相同（367 probes / 1017 搜索 LP / 277 证书 LP）。于是本轮的默认算法是 `cabs-1`，全 DP 保留为理论核。

## 五、关键结构：第一步是一个 ski-rental 赌注

只看第一步，假设之后从新的 L 开始 `linear`，可以严格算出「问 L」和「问 L+1」的差别。令 \(p_0=P(\mathrm{OPT}=L)\)，\(p_1=P(\mathrm{OPT}=L+1)\)，\(p_2=P(\mathrm{OPT}>L+1)\)。

- 问 L：\(\mathrm{OPT}=L\) 时付 \(c_Y(L)\) 直接闭合；\(\mathrm{OPT}=L+1\) 时付 \(c_N+c_Y(L+1)\)；\(\mathrm{OPT}>L+1\) 时付一个 NO，再从 \(L+1\) 继续。
- 问 L+1：\(\mathrm{OPT}=L\) 时付 \(c_Y(L+1)+c_Y(L)\)（先 YES 到 \(L+1\)，再 YES 到 L）；\(\mathrm{OPT}=L+1\) 时付 \(c_Y(L+1)+c_N\)；\(\mathrm{OPT}>L+1\) 时付一个 NO，但从 \(L+2\) 继续，比问 L 少一个 NO。

把共同项消掉，问 \(L+1\) 的期望优势是

\[
p_2\,c_N-p_0\,c_Y(L+1).
\]

所以「先问 \(L+1\)」当且仅当

\[
p_0<\frac{(1-p_1)c_N}{c_N+c_Y(L+1)}.
\]

在弱语料的拟合下，阈值约 \(1.39/(1.39+4.10)=0.253\)。全局先验的 \(p_0\approx 9/160=0.056\)，所以第一步几乎总是 \(L+1\)；在 9 个 \(\mathrm{OPT}=L\) 的实例上，这个赌注会输，最多多付 20 个 LP。这就是 `cabs-1` 的收益与损失的来源：**用少数 \(\mathrm{OPT}=L\) 的昂贵 YES，换多数 \(\mathrm{OPT}>L\) 的廉价 NO 和证书工作**。

这个结构也让「竞争分析」有了一个具体的对象。对 `linear` 来说，`cabs-1` 的最坏情况只发生在 \(\mathrm{OPT}=L\)：它多付一个 \(c_Y(L+1)\)，所以

\[
\frac{C_{\rm cabs}}{C_{\rm lin}}\le 1+\frac{c_Y(L+1)}{c_Y(L)}.
\]

在弱语料的代价模型下，实测最大是 4.0；而 `linear` 对 clairvoyant 的实测最大是 5.0，`binary` 是 8.0，`lower-first` 是 6.67。`cabs-1` 不是「对 clairvoyant 一致最优」——没有先验时任何确定性首问都会被 \(\mathrm{OPT}=L\) 或 \(\mathrm{OPT}=U\) 惩罚——但它对 `linear` 有一个有限的最坏情况上界，并且在平均情况下更接近 clairvoyant。

## 六、洞：UNKNOWN 不是证书错误，而是策略信息

`base/large_het/7`（弱语料，\(L=39,U=52,\mathrm{OPT}=41\)）在 \(h=39\) 返回 UNKNOWN。v9.0 的 `run_icf` 遇到 UNKNOWN 直接 break，返回 \(L=39,U=52\) 的部分证书；这没有错，但没有前进。本轮把 UNKNOWN 当成「这个 \(h\) 被 blocked」：状态不变，证书不变，策略换一个 \(h\) 继续。CABS 在这个例子上走 39(UNKNOWN) → 42(YES) → 40(NO) → 41(YES)，4 次 probe 后认证；`linear` 走 39(UNKNOWN) → 40(NO) → 41(YES)，3 次 probe、19 LP，比 CABS 便宜。CABS 在这里不是最优，但它从「停住」变成了「闭合」，并且证明了 blocked 逻辑与部分证书兼容。

## 七、平均情况分析与主 252 的回归

leave-one-out 的弱语料结果是 160/160 认证、0 次部分证书审计失败：

- `cabs-1`：367 probes，1017 搜索 LP + 277 证书 LP = 1294；
- `linear`：469 / 1037 / 387 / 1424；
- `binary`：421 / 1581 / 248 / 1829；
- `lower-first`：554 / 1746 / 351 / 2097；
- `pact`：518 / 1487 / 370 / 1857。

但要诚实：`cabs-1` 相对 `linear` 的搜索 LP 只省了 20（1.9%），总 LP 的 130 节省里 110 来自证书 LP。它不是一个「搜索快一个数量级」的算法，而是一个「用同样的证书层，把 probe 预算花得更聪明」的策略。

在主 252 上，用主语料自己的 leave-one-out 先验，`cabs-1` 精确退化成 `lower-first`：104 probes / 429 搜索 LP / 135 证书 LP / 564（加 pin 273 后 837），252/252。把弱语料先验直接迁移到主 252 会多花 1 次 probe / 18 个搜索 LP（因为唯一的 gap5 实例会先问 \(L+1\)）；仍然 252/252。这说明先验是语料相关的，但迁移的代价很小。

## 八、这一轮真正的新东西

1. **把外层从单位代价搜索变成非对称代价决策树**：NO/YES 的代价不同，DP 的节点代价依赖结果；这是 problem transformation 的核心。
2. **把第一步解释成 ski-rental 赌注**：阈值 \(p_0<(1-p_1)c_N/(c_N+c_Y(L+1))\)；这给竞争分析一个可计算的对象。
3. **`cabs-1`：一次 Bayes 探测 + `linear` 阶梯**：在弱语料上 160/160、1294 总 LP；搜索 LP 比 `binary` 省 35.7%，比 `lower-first` 省 41.8%。
4. **UNKNOWN 的 blocked 处理**：不改变证书，只改变策略；把 v9.0 的一个「停住」实例变成闭合。
5. **主 252 回归**：CABS 不破坏 v9.0 的 252/252 和 356 次状态审计；语料匹配时与 `lower-first` 完全一致。

## 九、当前方案最大的风险

**最大风险是：收益主要来自证书 LP（110/130），搜索 LP 只比 `linear` 省 1.9%；而且这个「先问 L+1」的赌注是在 160 个弱实例上校准的，9 个 OPT=L 的实例已经证明它会输；多叶 frontier 的 live 搜索仍然没有跑起来。**

# 产物区 · v9.1 CABS：非对称代价的括号搜索与一次 Bayes 探测

## 0. 本轮产物与一句话结论

**CABS**（Cost-Asymmetric Bracket Search）把 ICF-PACT 的外层 probe 策略从「单位代价搜索」改造成「非对称代价的区间决策树」：

1. **代价诊断**：弱 160 例上 NO 平均 1.39 个搜索 LP，YES 平均 5.60 个；`binary` 用 1581 个搜索 LP，`linear` 只用 1037 个，`lower-first` 要 1746 个。单位代价假设在弱语料上失效。
2. **问题变换**：把「下一次 probe 问哪里」变成未知 OPT 的阈值决策树；节点代价 \(c_Y(h)\) / \(c_N\) 依赖结果，区间 DP 求 Bayes 最优策略。
3. **CABS-1**：第一问用 DP，之后永远问 \(L\)（`linear` 阶梯）。弱 160 例上 367 probes / 1017 搜索 LP / 277 证书 LP / **1294 总 LP**，160/160 认证，0 次部分证书审计失败。
4. **竞争分析**：第一步是一个 ski-rental 赌注，阈值 \(p_0<(1-p_1)c_N/(c_N+c_Y(L+1))\)；对 `linear` 的最坏情况比不超过 \(1+c_Y(L+1)/c_Y(L)\)，弱语料实测 max 4.0。
5. **UNKNOWN 处理**：把返回 UNKNOWN 的 \(h\) 加入 blocked 集，状态和证书不变，策略换一个 \(h\) 继续；修复弱语料中唯一一个「遇到 UNKNOWN 就停住」的实例。
6. **主 252 回归**：CABS-1 与 `lower-first` 完全一致（104 probes / 429 搜索 LP / 135 证书 LP / 564，加 pin 273 后 837），252/252，356 次状态审计 0 失败。

一句话：**CABS 没有改证书层，而是把「下一次 probe 问哪里」变成一个带先验和结果代价的决策问题；在弱语料上它把总 LP 从 `linear` 的 1424 降到 1294，但搜索 LP 只省 1.9%，收益主要来自证书 LP，且先验仍是最大风险。**

## 2. 问题、状态与代价诊断

### 2.1 ICF 外层状态

沿用 v9.0 的单叶部分证书：

\[
\mathcal C=(L,U,s,m,\pi),
\]

其中 \(\pi\) 证明 \(\mathrm{NO}(L-1)\)，\((s,m)\) 是 \(C_{\max}=U\) 的可行调度，\(L\le U\)。不变量 \(\mathcal I(\mathcal C)\) 与 v9.0 相同。一次 probe 在 \(h\in[L,U-1]\) 上调用

\[
\mathrm{Decide}(F,h)\in\{\mathrm{NO}(\pi'),\ \mathrm{YES}(s',m'),\ \mathrm{UNKNOWN}\}.
\]

- NO：\(L\leftarrow h+1\)，\(\pi\leftarrow\pi'\)；
- YES：\(U\leftarrow\min(U,C_{\max}(s'))\)，\((s,m)\leftarrow(s',m')\)；
- UNKNOWN：状态不变。

全局拟合：

## 3. 非对称代价的区间决策树

### 3.1 符号

- 初始括号 \(L_0,U_0\)，\(g_0=U_0-L_0\)；
- 未知量 \(d=\mathrm{OPT}-L_0\in\{0,\dots,g_0\}\)；
- 先验 \(w_d=P(d\mid g_0)\)，\(\sum_d w_d=1\)；
- 状态索引用 \(i=L-L_0\)，\(j=U-L_0\)，所以当前候选是 \(d\in[i,j]\)；
- 问 \(h\) 的 YES 概率
  \[
  P_{i,h}=\frac{\sum_{d=i}^{h}w_d}{\sum_{d=i}^{j}w_d};
  \]
- NO 代价 \(c_N\)（常数），YES 代价 \(c_Y(h)\)。

### 3.2 DP

定义 \(V(i,j)\) 为在候选区间 \([i,j]\) 上继续搜索的最小期望搜索 LP，\(V(i,i)=0\)。则

\[
V(i,j)=\min_{h\in[i,j-1]\setminus B}
\Bigl[
P_{i,h}\,c_Y(h)+(1-P_{i,h})\,c_N
+P_{i,h}V(i,h)+(1-P_{i,h})V(h+1,j)
\Bigr],
\]

其中 \(B\) 是已 blocked 的 horizon 集合。选择表

\[
C(i,j)=\arg\min_{h}\ \text{上式}.
\]

YES 把候选压到 \([i,h]\)，NO 把候选压到 \([h+1,j]\)。这是一个「非对称节点代价的最优字母决策树」：标准最优 BST DP 的每个节点代价为 1，这里节点代价依赖结果。

### 3.3 后验更新

- NO：\(i\leftarrow h+1\)；
- YES：\(j\leftarrow h\)（实际实现中 \(U\leftarrow\min(U,C_{\max}(s'))\)，可能比 \(h\) 更小；DP 假设 \(j=h\)，实际区间是它的子区间，因此策略仍然可用，只是 DP 的代价估计偏保守）；
- UNKNOWN：\(B\leftarrow B\cup\{h\}\)，\(i,j\) 不变。

### 3.4 代价模型

DP 只需要 \(c_N\) 和 \(c_Y(h)\)。\(c_N\) 取训练 profile 上所有 NO 的平均搜索 LP。\(c_Y(h)\) 用线性模型

\[
c_Y(h)=a+b\max(0,h-\mathbb E[\mathrm{OPT}\mid \mathrm{OPT}\le h]),
\]

其中 \(a,b\) 由训练 profile 的 YES 点 \((h-\mathrm{OPT},\ \mathrm{lp})\) 做最小二乘得到。期望 \(\mathbb E[\mathrm{OPT}\mid \mathrm{OPT}\le h]\) 在当前先验下用前缀加权和计算。这样 DP 在选 \(h\) 时会把「YES 越往高处越贵」考虑进去，而不是只数 probe 次数。证书 LP 没有进入 DP 目标；它是评估时的额外收益。

### 3.5 先验

先验 \(P(d\mid g)\) 由训练集按 gap 分组，Laplace 平滑（\(\epsilon=0.5\)），再向全局 \(d\)-先验收缩：

\[
w_g=\frac{n_g\,w_g^{\rm local}+\kappa\,w^{\rm global}}{n_g+\kappa},
\]

实验中 \(\kappa=5\)。对训练集中没有出现过的 gap，用相邻 gap 插值；仍然没有时退化为「\(d=0\)、\(d=g\) 各 0.4、其余 0.01」的 hedge 先验。所有测试实例的先验和代价模型都在其余实例上拟合（leave-one-out），测试实例的 OPT 不参与决策。

## 4. 算法

### 4.1 CABS-DP（理论核）

```text
CABS-DP(I, calibration, max_probes):
    (L,U,s,m,pi) = ICF-Init(I)
    L0,U0 = L,U
    w = Prior(calibration, g0=U0-L0)
    cN,a,b = CostModel(calibration)
    C,V = BuildDP(w, cN, a, b)
    B = empty
    probes = 0
    while L < U and probes < max_probes:
        i,j = L-L0, U-L0
        if C[i][j] is blocked:
            h = best non-blocked h in [L,U-1]
        else:
            h = L0 + C[i][j]
        r = Decide(I,h)
        probes += 1
        if r is UNKNOWN:
            B.add(h); continue
        if r is NO(pi2):
            L = h+1; pi = pi2
        if r is YES(s2,m2):
            U = min(U, Cmax(s2)); s,m = s2,m2
        Audit(PartialCertificate(I,L,U,s,m,pi))
    if L == U:
        return ICFCertificate(I,U,s,m,pi)
    return PartialCertificate(I,L,U,s,m,pi)
```

### 4.2 CABS-1（默认）

```text
CABS-1(I, calibration, max_probes):
    same initialization and DP table
    first = True
    while L < U and probes < max_probes:
        if first:
            h = L0 + C[0][g0]          # one Bayes probe
        else:
            h = L                       # linear ladder
        h = nearest non-blocked horizon in [L,U-1]
        r = Decide(I,h)
        ...
        first = False after a non-UNKNOWN outcome
```

在弱语料的 leave-one-out 拟合下，`C[0][g0]` 对 159/160 个实例给出 \(L+1\)；唯一给出 \(L\) 的是 `large_het/7`（随后遇到 UNKNOWN，blocked 后走 42）。在第一步之后，DP 的 continuation 在弱语料上几乎总是 `linear`，所以 `CABS-1` 与 `CABS-DP` 的 160 例结果完全相同。`CABS-1` 的优点是简单、可解释、对先验的尾部不敏感；`CABS-DP` 保留为一般化的理论版本。

### 4.3 CABS-guard（可选的风险旋钮）

在 CABS-1 的第一问上，若 DP 选择的 \(h\) 满足

\[
P_{0,h}>\theta,
\]

就把 \(h\) 向下移到最大的满足 \(P_{0,h}\le\theta\) 的 horizon。实验中 \(\theta=0.5\)。它牺牲约 8 个搜索 LP，换取略好的平均 clairvoyant 比（1.214 vs 1.229）和相同的 max 4.0。默认不开；当先验被认为不可信时打开。

### 4.4 校准

1. 用 `profile_cabs.py` 在训练语料上收集所有 \(h\) 的 verdict / 搜索 LP / 证书 LP / Cmax。
2. 按 gap 分组拟合先验，Laplace 平滑 + shrinkage。
3. 用 YES 点拟合 \(c_Y(h)=a+b\,d\)，用 NO 点拟合 \(c_N\)。
4. 测试时按测试实例的 gap 取先验权重；若 gap 未见过，插值或 hedge。
5. 整个过程不使用测试实例的 OPT。

### 4.5 与 v9.0 的关系

- **相同的内层**：`pact_decide`、`SDLP`、`BranchProof`、Farkas/empty 叶子、`check_schedule`、`PartialCertificate`、`ICFCertificate`。
- **相同的不变量**：每次 probe 后审计 \(L\le\mathrm{OPT}\le U\)；UNKNOWN 不改变状态。
- **不同的外层**：v9.0 的 `_choose_h` 是 `lower-first` / `binary` / `pact` 的固定规则；CABS 用先验 + 非对称代价 DP 选择 \(h\)。
- **不同的失败语义**：v9.0 遇到 UNKNOWN 直接 break；CABS 把 \(h\) 加入 blocked，继续寻找其他 horizon。
- **新增的正确性分离**：策略只影响代价，不影响证书；任意策略（甚至随机策略）都不会破坏 ICF 的 soundness。

## 5. 正确性

### 5.1 不变量

沿用 v9.0：

\[
\mathcal I(\mathcal C)\equiv
\begin{cases}
\pi.h=L-1,\\
\pi.\mathrm{audit\_rdf}()=\mathrm{True},\\
(s,m)\ \text{可行且}\ C_{\max}(s)=U,\\
L\le U.
\end{cases}
\]

### 5.2 策略独立性定理

**定理 5.1（policy independence）** 若初始状态满足 \(\mathcal I\)，且循环中每次选择一个 \(h\in[L,U-1]\) 调用 `Decide`，按 NO / YES / UNKNOWN 的规则更新，则每个可达状态都满足 \(\mathcal I\)。特别地，策略如何选 \(h\) 不影响证书的 soundness。

**证明**：NO 分支是 ICF 的 PROBE-NO 转移，\(\pi'\) 证明 \(\mathrm{NO}(h)\) 且 \(L'=h+1\)，所以 \(\pi'.h=L'-1\)；YES 分支只降低 \(U\) 且换上一个 `check_schedule` 通过的调度，由括号引理 \(L\le U'\)；UNKNOWN 分支不改变任何证书字段。逐条检查 \(\mathcal I\) 即可。\(\square\)

这个定理是本轮设计的核心：**CABS 只是一个策略层，证书层完全继承 v9.0。** 即使 DP 的先验错了、代价模型错了、甚至策略是随机的，只要它选的是合法 horizon，证书仍然 sound。

### 5.3 UNKNOWN 处理

**引理 5.2（blocked soundness）** 若在 \(h\) 上返回 UNKNOWN，则把 \(h\) 加入 blocked 集并保持 \((L,U,s,m,\pi)\) 不变，仍然满足 \(\mathcal I\)。

**证明**：UNKNOWN 不产生 NO/YES 结论，状态字段未变，所以 \(\mathcal I\) 原样成立。\(\square\)

**引理 5.3（blocked progress）** 若所有 \(h\in[L,U-1]\) 都被 blocked，则循环可以停止并返回 \(\mathcal I\) 成立的部分证书；它不声称最优。

**证明**：停止时状态未变，由引理 5.2 得到部分证书；\(L<U\) 时它不是最优性证书，但仍是有效括号。\(\square\)

### 5.4 终止性

**定理 5.4（termination）** 若 `Decide` 对每个 \(h\) 最多返回一次 UNKNOWN（同一实例的同一 horizon 是确定性的），则循环在至多 \(2g_0\) 次 probe 内停止，其中 \(g_0=U_0-L_0\)。

**证明**：每次成功的 NO 或 YES 都把 \(U-L\) 减少至少 1，所以成功 probe 至多 \(g_0\) 次。每次 UNKNOWN 把一个 \(h\in[L_0,U_0-1]\) 加入 blocked，blocked 集至多 \(g_0\) 个元素，所以 UNKNOWN 至多 \(g_0\) 次。总计至多 \(2g_0\) 次 probe。\(\square\)

这个界与策略无关：CABS 的 DP 只改变代价，不改变最坏情况下的 probe 数上界。

### 5.5 终局

**引理 5.5（finalization）** 若 \(\mathcal I\) 且 \(L=U\)，则 \(\mathrm{OPT}=L=U\)，且 `ICFCertificate` 的 `NO(U-1)` + \(C_{\max}=U\) 调度是最优性证书。

**证明**：与 v9.0 引理 3.2 相同；NO 给下界 \(U\)，调度给上界 \(U\)。\(\square\)

### 5.6 DP 的 Bayes 最优性

**定理 5.6（DP optimality for the model）** 在简化代价模型（\(c_N\) 常数，\(c_Y(h)\) 只依赖 \(h\) 和当前候选区间）下，\(V(0,g_0)\) 是所有「在候选区间上选阈值 \(h\)、按 YES/NO 收缩区间」的策略中最小的期望搜索 LP；\(C(i,j)\) 是对应的最优选择。

**证明**：状态 \([i,j]\) 是充分的：后验是先验在 \([i,j]\) 上的限制，代价和转移只依赖 \(i,j,h\)。Bellman 方程对 \(j-i\) 做归纳；\(V(i,i)=0\)，每个 \(V(i,j)\) 取所有 \(h\) 的最小值，因此是最优子结构。\(\square\)

注意：这是对**模型**的最优性，不是对真实 `pact_decide` 的最优性。真实代价有噪声、有 UNKNOWN、有 \(C_{\max}<h\)，所以 CABS 是启发式；它的 soundness 由定理 5.1 保证，不由定理 5.6 保证。

### 5.7 一步 ski-rental 阈值

**引理 5.7（one-step threshold）** 在 3.1 的简化模型下，假设第一步之后从新的 \(L\) 开始 `linear`，令 \(p_0=P(\mathrm{OPT}=L)\)，\(p_1=P(\mathrm{OPT}=L+1)\)，\(p_2=P(\mathrm{OPT}>L+1)\)。则「先问 \(L+1\)」的期望代价低于「先问 \(L\)」当且仅当

\[
p_0<\frac{(1-p_1)c_N}{c_N+c_Y(L+1)}.
\]

**证明**：逐项比较。问 \(L\) 的代价：\(\mathrm{OPT}=L\) 为 \(c_Y(L)\)；\(\mathrm{OPT}=L+1\) 为 \(c_N+c_Y(L+1)\)；\(\mathrm{OPT}>L+1\) 为一个 NO 加从 \(L+1\) 的 `linear`。问 \(L+1\) 的代价：\(\mathrm{OPT}=L\) 为 \(c_Y(L+1)+c_Y(L)\)；\(\mathrm{OPT}=L+1\) 为 \(c_Y(L+1)+c_N\)；\(\mathrm{OPT}>L+1\) 为一个 NO 加从 \(L+2\) 的 `linear`，比问 \(L\) 少一个 NO。相减得期望差 \(p_0c_Y(L+1)-p_2c_N\)，令其小于 0 即得。\(\square\)

在拟合值 \(c_N=1.39\)、\(c_Y(L+1)\approx 4.10\) 下，阈值约 0.253。弱语料全局 \(p_0\approx 0.056\)，所以「先问 \(L+1\)」在平均意义上正确；9 个 \(\mathrm{OPT}=L\) 的实例是它的「租金」。

### 5.8 对 `linear` 的竞争比

**定理 5.8（one-step regret vs linear）** 对 CABS-1，设第一问为 \(h^*\)，之后 `linear`。则

\[
C_{\rm cabs}\le C_{\rm lin}+c_Y(h^*),
\]

并且当第一问为 NO 时 \(C_{\rm cabs}\le C_{\rm lin}-c_N\)；当第一问为 YES 且 \(\mathrm{OPT}=L+1\) 时两者相等；只有 \(\mathrm{OPT}=L\) 时多付 \(c_Y(h^*)\)。

**证明**：若第一问 NO，CABS 从 \(h^*+1\) 开始 `linear`，而 `linear` 从 \(L\) 开始，前者少走 \(h^*-L+1\) 个 NO；若第一问 YES，分 \(\mathrm{OPT}=L\) 和 \(\mathrm{OPT}=L+1\) 两种情况直接比较；\(\mathrm{OPT}>h^*\) 时第一问不可能是 YES。\(\square\)

因此最坏乘法比不超过

\[
1+\frac{c_Y(h^*)}{c_Y(L)}
\]

（在 \(\mathrm{OPT}=L\) 的坏情况下）。CABS-1 在 159/160 个实例上 \(h^*=L+1\)，弱语料实测 max 4.0。这个界是对 `linear` 的，不是对 clairvoyant 的；没有先验时任何确定性首问都会被 \(\mathrm{OPT}=L\) 或 \(\mathrm{OPT}=U\) 惩罚，所以不存在对 clairvoyant 的常数最坏比。

### 5.9 审计

证书审计沿用 v9.0：

- `PartialCertificate.audit_rdf()`：检查 \(\pi.h=L-1\)、\(\pi.\mathrm{audit\_rdf}()\)、\(L\le U\)、\(C_{\max}(s)=U\)、`check_schedule`；
- `ICFCertificate.audit_rdf()`：检查 \(\pi.h=U-1\)、\(\pi.\mathrm{audit\_rdf}()\)、`check_schedule`、\(C_{\max}=U\)。

CABS 的 `run_case` 在初始状态和每次成功 probe 后调用 `PartialCertificate.audit_rdf()`。UNKNOWN 不改变状态，所以不会引入新的证书义务；blocked 集是策略状态，不进入证书。弱 160 例共 526 次状态审计、0 失败；主 252 例 356 次状态审计、0 失败。

## 6. 复杂度

### 6.1 DP

对初始 gap \(g_0\)，DP 有 \(O(g_0^2)\) 个区间，每个区间枚举 \(O(g_0)\) 个 \(h\)，所以

\[
T_{\rm DP}=O(g_0^3),\qquad M_{\rm DP}=O(g_0^2).
\]

弱语料 \(g_0\le 13\)，完全可忽略；主 252 的 \(g_0\le 5\)。若未来出现大 gap，可以只对前 \(W\) 个候选做 lookahead（窗口 DP），得到 \(O(W^3)\) 的一步策略；或者直接用 CABS-1，只建一次表。

### 6.2 单次 probe

一次 `Decide` 的复杂度与 v9.0 相同：若 NO 证书高度为 \(k\)，则

\[
T_{\rm Decide}=O\bigl(2^k(T_{\rm LP}+T_{\rm cert})\bigr).
\]

策略选择 \(h\) 的额外开销是 \(O(1)\)（查表）或 worst case \(O(g_0)\)（blocked 时找最近可用 horizon），远小于一次 LP。

### 6.3 总复杂度

\[
T_{\rm CABS}=O\bigl(g_0^3+P\,T_{\rm Decide}+P\,T_{\rm audit}\bigr),
\]

其中 \(P\le 2g_0\) 由定理 5.4。证书审计 \(T_{\rm audit}\) 与 v9.0 相同。内存是 \(O(g_0^2+V)\)，\(V\) 是当前 SDLP 的变量数。

### 6.4 校准

先验和代价模型在 \(|D|\) 个 profile 上拟合，时间 \(O(|D|+g_0^2)\)；leave-one-out 对每个测试实例重拟合一次，实验中 \(|D|=160\)，总开销远小于一次完整搜索。

## 7. 实验

### 7.1 设置

- **弱语料**：`hap.weak_rows(4)` 的 160 例，初始 gap 4–13；`base=61, pert=54, stress=45`。
- **主语料**：v9.0 的 252 例，`base=141, pert=60, stress=51`；初始 gap 0/1/5。
- **内层 oracle**：`pact_decide(inst, h, depthcap=None, nodecap=None)`，完整搜索。
- **校准**：每个测试实例用其余实例拟合先验和代价模型（leave-one-out），测试实例的 OPT 不参与决策。
- **缓存**：所有策略共享 `ProbeCache`，只删除重复 LP，不改变 verdict 或代价；因此 LP 计数可比较，墙钟不可直接比较。
- **验收**：`ok = (L==U==known) and certified and partial_fail==0 and partial_final`；`known` 只用于离线验收。
- **hole-continue**：所有策略遇到 UNKNOWN 都 blocked 后继续，而不是停住；这让弱语料的 `lower-first` 从旧的 159/160 变成 160/160。

**先验收缩。** `cabs-1` 在不同 shrinkage 下的弱 160 结果：

| shrinkage | probes | 搜索 LP | 证书 LP | 总 LP | 认证 |

结果很稳定，shrinkage 1 最好，shrinkage 5 是默认的保守选择。没有 shrinkage 时第一问会在稀有 gap 上跳到 \(L+2\)，5 折 CV 的最坏 clairvoyant 比曾达到 14；shrinkage 5 把它压到 4。

**Guard。** \(\theta=0.5\) 时，shrinkage 5 的 `cabs-guard` 是 377 probes / 1025 搜索 LP / 290 证书 LP / 1315 总 LP，比 `cabs-1` 多 21 个总 LP；但平均 clairvoyant 比从 1.229 降到 1.214，max 仍为 4.0。Guard 是可选的风险旋钮，默认不开。

**CABS-1 vs CABS-DP。** 在 leave-one-out 弱语料上，两者的 160 例结果完全相同（367 / 1017 / 277 / 1294）。第一步之后 DP 的 continuation 几乎总是 `linear`。因此默认用 `cabs-1`；`cabs-dp` 保留为一般化的理论版本。

### 7.5 竞争分析

定义 clairvoyant 两探针下界 \(C^\star\)：若 \(L<\mathrm{OPT}\) 必须问 \(\mathrm{OPT}-1\)（NO），若 \(\mathrm{OPT}<U\) 必须问 \(\mathrm{OPT}\)（YES），代价取实际 profile 的搜索 LP；\(L=U=\mathrm{OPT}\) 时 \(C^\star=0\)。这是任何策略都必须支付的下界，不是完整离线最优，但足以做竞争比。

| 策略 | 平均 \(C/C^\star\) | 中位数 | p90 | max | \(\le 1.5\) |
|---|---:|---:|---:|---:|---:|
| **`cabs-1` (shrink 5)** | **1.229** | **1.000** | **1.667** | **4.000** | **141/160** |
| `cabs-1` (shrink 1) | 1.222 | 1.000 | 1.667 | 4.000 | 142/160 |
| `cabs-guard` | 1.214 | 1.000 | 1.667 | 4.000 | 141/160 |
| `linear` | 1.330 | 1.167 | 1.800 | 5.000 | 140/160 |
| `binary` | 1.843 | 1.500 | 3.250 | 8.000 | 83/160 |
| `lower-first` | 2.166 | 1.900 | 3.400 | 6.667 | 58/160 |
| `pact` | 1.844 | 1.500 | 3.250 | 6.000 | 86/160 |

`cabs-1` 的平均比、中位数、p90 和 max 都优于 `linear`、`binary`、`lower-first`、`pact`。但 max 4.0 说明它仍然会被 \(\mathrm{OPT}=L\) 的实例惩罚；这不是一个对 clairvoyant 的一致最优算法。

### 7.6 对 `linear` 的逐实例胜负

`cabs-1` vs `linear`（搜索 LP）：

- 更好 112 例，持平 39 例，更差 9 例；
- 平均比 0.967，中位比 0.866，p90 1.0，max 4.0；
- 9 个更差实例中 8 个 \(\mathrm{OPT}=L\)，1 个是 `large_het/7` 的 hole 实例；
- 最大损失 +20 LP（`large_het/5` 41 vs 21；`large_b/1` 40 vs 20）；最大收益来自 \(\mathrm{OPT}>L+1\) 的实例，省一个廉价 NO 和一部分证书 LP。

这正是 ski-rental 的结构：大多数时候省一次 NO，少数 \(\mathrm{OPT}=L\) 的时候付一次昂贵 YES。

### 7.7 UNKNOWN / hole 实例

`base/large_het/7`（弱语料，\(L=39,U=52,\mathrm{OPT}=41\)）：

| 策略 | steps | probes | 搜索 LP | 证书 LP | 认证 |
|---|---|---:|---:|---:|---:|
| `linear` | 39 UNKNOWN, 40 NO, 41 YES | 3 | 19 | 6 | 是 |
| `cabs-1` | 39 UNKNOWN, 42 YES, 40 NO, 41 YES | 4 | 37 | 8 | 是 |
| `binary` | 45 YES, 42 YES, 40 NO, 41 YES | 4 | 60 | 10 | 是 |
| v9.0 `lower-first`（hole-stop） | 39 UNKNOWN，停 | 1 | 1 | 1 | 否（返回部分证书） |

CABS 在这里比 `linear` 贵，但它把「停住」变成了「闭合」。这说明 blocked 逻辑是有效的，也说明 CABS 的投机第一问在 hole 附近可能不划算；这是一个已知的局部风险。

### 7.8 主 252 回归

用主语料自己的 leave-one-out 先验和代价模型，CABS-1 与 `lower-first`、`linear` 完全一致：

| 策略 | probes | 搜索 LP | 证书 LP | 总 LP | 认证 | 部分审计失败 |
|---|---:|---:|---:|---:|---:|---:|
| `cabs-1` | 104 | 429 | 135 | 564 | 252/252 | 0 |
| `lower-first` | 104 | 429 | 135 | 564 | 252/252 | 0 |
| `linear` | 104 | 429 | 135 | 564 | 252/252 | 0 |
| `binary` | 106 | 468 | 140 | 608 | 252/252 | 0 |

主 252 的 pin LP 是 273；加上 pin 后 CABS-1 的总 LP 是 837，与 v9.0 `lower-first` 的 837 一致。v9.0 的 PACT-C 是 105 / 450 / 138 / 273 / 861；CABS 保持了 `lower-first` 的 24 个 LP 优势，没有回退。

**先验迁移。** 把弱语料先验直接用于主 252（profile replay，不是 live）：CABS-1 是 105 probes / 447 搜索 LP / 137 证书 LP / 584，仍然 252/252。多出的 1 次 probe / 18 个搜索 LP 全部来自主 252 唯一的 gap5 实例 `large_het/7`：弱先验让它先问 \(L+1\)，而主语的先验会先问 \(L\)。这个差异很小，但说明先验必须与目标语料匹配。

### 7.9 审计

- 弱 160 例：`cabs-1` 526 次状态审计，0 失败；160/160 最终 `ICFCertificate`。
- 主 252 例：`cabs-1` 356 次状态审计，0 失败；252/252 最终认证。
- 审计器没有信任生成器的 `certified` 标志；它只调用 `PartialCertificate.audit_rdf()` / `ICFCertificate.audit_rdf()`，后者复用 v9.0 的 `verify`、`check_schedule`、`_domain`。
- UNKNOWN 的状态没有改变，因此仍然满足不变量；blocked 集不进入证书。

### 7.10 解释与边界

- **主收益是证书 LP，不是搜索 LP。** 搜索 LP 相对 `linear` 只省 20（1.9%）；总 LP 的 130 节省里 110 来自证书 LP。CABS 不是「搜索快一个数量级」的算法。
- **`linear` 是弱语料上的强基线。** 因为 NO 便宜、OPT 通常离 L 很近，从 L 一格一格问反而比二分便宜。这个观察本身是对 v9.0 `lower-first` 的重要修正。
- **先验是语料相关的。** 主语料自己的先验让 CABS 退化成 `lower-first`；弱先验迁移到主 252 只多 18 个搜索 LP。这说明算法需要一个「先验选择」步骤，而不是一个固定先验。
- **多叶 frontier 仍未 live。** 本轮 CABS 是单括号策略；它可以在多叶 frontier 的每个 open 叶子上复用，但 live 的多叶搜索没有跑。

## 8. 与 v9.0 的差异

| 维度 | v9.0 ICF-PACT | v9.1 CABS |
|---|---|---|
| 外层目标 | 最少 probe 次数 | 最小期望搜索 LP |
| 代价模型 | 每次 probe = 1 | \(c_N=1.39\), \(c_Y(h)=4.10+0.84d\) |
| 策略 | `lower-first` / `binary` / `pact` | 非对称代价区间 DP；默认 `cabs-1` |
| 先验 | 无 | \(P(d\mid g)\) + Laplace + shrinkage，leave-one-out |
| 第一步 | 固定问 L | ski-rental 阈值，弱语料几乎总问 L+1 |
| UNKNOWN | 直接 break，返回部分证书 | 加入 blocked，继续；仍返回部分证书 |
| 竞争分析 | 无 | clairvoyant 比 + 对 `linear` 的一步 regret 界 |
| 语料 | 252（gap 0/1/5） | 弱 160（gap 4–13）+ 主 252 回归 |
| 证书层 | ICF 部分证书 | 完全不变 |
| 多叶 frontier | 形式化 + replay | 仍未 live；CABS 可复用到叶子 |

## 9. 已知风险与限制

1. **搜索 LP 增益很小。** `cabs-1` 相对 `linear` 只省 20 个搜索 LP（1.9%）；总 LP 的 9.1% 节省主要来自证书 LP（110/130）。不能把 CABS 说成搜索速度的数量级提升。
2. **先验是 160 个弱实例校准的。** 9 个 \(\mathrm{OPT}=L\) 的实例已经证明「先问 L+1」会输；base 分语料的总 LP 比 `linear` 多 6。先验只按 gap 分组，没有利用「下界可信度」、语料标签或实例特征。
3. **主 252 的语料偏置。** 主 252 的 gap 只有 0/1/5；CABS 在主语料自己的先验下退化成 `lower-first`，所以主 252 不能证明 CABS 的优势，只能证明不回退。
4. **代价模型是简化的。** \(c_Y(h)=a+b(h-\mathbb E[\mathrm{OPT}\mid \mathrm{YES}])\) 忽略了证书 LP、UNKNOWN、\(C_{\max}<h\) 和实例异质性；DP 只优化搜索 LP，证书 LP 的收益是副作用。
5. **`cabs-dp` 的 continuation 在弱语料上退化为 `linear`。** 因此本轮的 live 结果不能证明全 DP 的持续多步优势；它只证明了「第一步 DP + linear」足够好。更大的 gap 或不同的代价模型可能让全 DP 的后续步骤重新有价值。
6. **多叶 frontier 未 live。** v9.0 的最大风险仍在：我们没有在 252 或弱语料上真正生长一棵多叶 frontier；SPLIT / LIFT / CLOSE / CUT 的 live 行为没有测到。CABS 只是外层单括号策略。
7. **竞争比是对 `linear` 的，不是对 clairvoyant 的。** 对 clairvoyant 的最坏情况比无常数上界；表中的 clairvoyant 比是 160 例经验值，不是定理。
8. **UNKNOWN 的确定性假设。** 定理 5.4 假设同一实例的同一 horizon 不会时而 UNKNOWN 时而 NO/YES；如果求解器有超时/随机性，blocked 集可能需要重试或预算，终止界会变松。
9. **时间不可直接比较。** 所有策略共享 `ProbeCache`，后面的策略命中缓存，所以 `t` 字段只反映策略循环开销，不是真实 LP 时间。LP 计数是可靠指标。
10. **证书审计依赖外部检查器。** `verify`、`check_schedule`、`_domain`、`SDLP` 的数值容差仍是信任基；160 + 252 例通过不代表病态 LP 下也通过。
11. **stress 行不能按 `name/idx` 去重。** 弱 160 和主 252 的 stress 都有同名不同加工时间的行；实验按 `corpora()` / `weak_rows()` 的顺序对齐，profile 和 bench 用同一顺序。
12. **`known` 只用于离线验收和训练先验。** 测试实例的 `known` 不参与决策；但训练集的 `known` 用于拟合先验，这是监督式校准，部署时需要历史数据或合成数据。
13. **Guard 没有显著收益。** \(\theta=0.5\) 的 guard 多花 21 个总 LP，只把平均 clairvoyant 比从 1.229 降到 1.214；它不是免费的鲁棒性。
14. **代码规模。** `cabs.py` 是研究原型，没有覆盖多叶 frontier、割循环、并行或大规模 gap 的窗口 DP；这些是下一轮的工作。

---

## 10. 最大风险（一句话）

**最大风险是：收益主要来自证书 LP（110/130），搜索 LP 只比 `linear` 省 1.9%；「先问 L+1」的赌注是在 160 个弱实例上校准的，9 个 OPT=L 的实例已经证明它会输，而多叶 frontier 的 live 搜索仍然没有跑起来。**

---

## 11. 本轮结论（1–2 句）

**CABS 把 ICF-PACT 的外层从「单位代价 probe 搜索」改造成「非对称代价的区间决策树」，默认的 `cabs-1`（一次 Bayes 探测 + `linear` 阶梯）在弱 160 例上做到 160/160 认证、1294 总 LP（`linear` 1424、`binary` 1829、`lower-first` 2097），并在主 252 上以 104/429/135/564、252/252 精确回退到 `lower-first`；但搜索 LP 只比 `linear` 省 1.9%，收益主要还是证书 LP，先验迁移和多叶 frontier 仍是下一轮的主要风险。**
