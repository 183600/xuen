### 第 8 轮灵感驱动研究记录（本次循环第 2 轮，承接第 7 轮）

**灵感词**：排行榜、世界模型

**继承关系**：第 7 轮 CADVS-v7（IP-501~IP-504）把系统从「指令驱动」推进到「需求驱动」：DIM 推断 ρ_demand、DRC 用 LLM 推理链量化 η_demand、DAC 捕获情感态度，EFA-v7 在七硬门不变的前提下把软因子链接长到 6 项。但 v7 仍有一个结构性缺口：它只会「逐个验证候选是否合规」，缺少对「多个都合规的候选之间该选谁」的**相对判断**，也缺少对「执行后会发生什么」的**前瞻预演**。本轮延续「硬门不增」原则，聚焦「**想象-排序-诚信三角**」：用世界模型把候选轨迹在潜空间里预演一遍，用排行榜把幸存候选排出相对次序，再用诚信雷达判断这份排行榜是否可信。

**直觉与动机**：

1. **世界模型 → 从「事后验证」到「事前预演」**。v7 的七硬门是在轨迹生成之后做证书检查；它回答「这条轨迹是否安全」，却不回答「这条轨迹执行后世界会变成什么样」。引入「世界模型集合」(World Model Manifold, WMM)：在潜空间对每条候选做 H 步想象 rollout，得到预测收益 Û、预测风险 R̂ 与集成分歧 D_epi。关键洞见是：**世界模型是「心理沙盘」**——它让系统在真实执行前就能比较不同未来的代价，而不是等硬门在现实中失败。

2. **排行榜 → 从「绝对阈值」到「相对排序」**。v7 的软因子与硬门都是绝对量：一条轨迹要么过阈值、要么不过。但当多条轨迹都合规时，「谁更好」是一个**相对**问题。引入「排行榜排序器」(Leaderboard Ranker, LBR)：用 Bradley-Terry/Elo 对幸存候选做两两比较，输出排序 π、头名优势 Δ 与决胜度 η_rank。关键洞见是：**排行榜把「绝对合规」转成「相对择优」**——它不新增硬门，只在硬门之后的幸存集内重排。

3. **排行榜 × 世界模型 → 必须自带「诚信雷达」**。排行榜的相对性天然诱导 Goodhart：只要提议器学会「刷榜」，它就能利用世界模型的盲区爬到头名，而头名越稳（η_rank 越高）反而越危险。引入「Goodhart 诚信雷达」(Goodhart Integrity Radar, GIR)：用留一模型排序稳定性 τ_K、集成分歧 D_epi、OOD 分数与**排序校准误差 RCE**（预测排序 vs 真实执行结果）共同给出 η_integrity。关键洞见是：**排行榜的可信度本身要可测量**——决胜度高的排行榜未必可信，只有「决胜且稳定且校准」的排行榜才允许影响选择；否则回退到 v7 的 margin 排序。

**关键洞见**：v7 回答「如何从用户需求出发推导正确行为」；v8 回答「**在多个都正确的行为里，如何借助世界模型与相对排行榜选出更优的那个，同时不被排行榜本身欺骗**」。七硬门 kc_evidence_forged_v5 记号原样复用；本轮新增的只有：
- IP-505 WMM（世界模型集合，想象 rollout），
- IP-506 LBR（排行榜排序器，Bradley-Terry/Elo），
- IP-507 GIR（Goodhart 诚信雷达，排序校准），
- IP-508 EFA-v8（门透明排序：只重排、不放行）

**形式化目标（增量）**：

1. **WMM（World Model Manifold）**：<br>
   - 潜动力学 f_θ: (z_t, a_{t:t+H}) ⟼ (ẑ_{t+H}, r̂, ĉ)<br>
   - 集成 {f_θk}_{k=1}^K；对候选 x 得 S_k(x) = U_k(x) - λ·R_k(x)<br>
   - 共识 S̄(x) = (1/K)·Σ_k S_k(x)，认知分歧 D_epi(x) = Var_k(S_k(x))<br>
   - 只产出软评分，不做任何放行/拒绝决定

2. **LBR（Leaderboard Ranker）**：<br>
   - 两两偏好 P(x≻y) = σ((S̄(x)-S̄(y))/β)<br>
   - 排序 π = Bradley-Terry MLE 或 Elo；头名优势 Δ = S̄_(1)-S̄_(2)<br>
   - 决胜度 η_rank = 1 - exp(-Δ/β) ∈ [0,1)<br>
   - 终身排行榜：真实执行结果回写 archetype Elo

3. **GIR（Goodhart Integrity Radar）**：<br>
   - 留一模型排序稳定性 τ_K = Kendall τ(π_full, π_{-k})<br>
   - 排序校准误差 RCE = 预测 P(x≻y) 与真实 pairwise 结果的 Brier/ECE<br>
   - η_integrity = clip(1 - α1·D̃_epi - α2·OOD - α3·(1-τ_K) - α4·RCE, 0, 1)

4. **EFA-v8（门透明排序）**：<br>
   - 排名信任 T = η_rank·η_integrity；仅当 T ≥ τ_rank 用排行榜，否则回退 v7 margin<br>
   - 收紧因子 η_wml = 1 + ε_w·φ(T) ∈ [1, 1+ε_w]，φ(T)=max(0,(T-τ_rank)/(1-τ_rank))<br>
   - 选择域始终是 v7 硬门后的幸存集 S_v7 ⇒ Exec_v8 ⊆ Exec_v7<br>
   - 不新增硬门；排行榜只置换，不放行

5. **形式化定义**：给定 v7 幸存集 S_v7：<br>
   - 慢环：{S_k(x)} = WMM.imagine(x, H)，S̄, D_epi<br>
   - π, Δ = LBR.rank(S_v7)；η_rank = 1 - e^{-Δ/β}<br>
   - η_integrity = GIR.assess(S_v7, {S_k}, RCE)<br>
   - T = η_rank·η_integrity<br>
   - 若 T ≥ τ_rank：x̂ = argmax_{x∈S_v7} S̄(x)<br>
   - 否则：x̂ = argmax_{x∈S_v7} margin_v7(x)（完全退回 v7）<br>
   - 执行后：LBR.update_elo(realized)，GIR.update_calibration(realized)

**本轮最大风险**：**排行榜-世界模型共谋（Goodhart 塌缩）**：当提议器、世界模型与排行榜共享同一训练分布时，三者可能共同收敛到一个「高分但物理上错误」的共识，集成分歧与排序稳定性都无法识别这种共谋式盲区，而相对排名会让错误显得异常自信。

## 2. 关键算法骨架

### IP-505 WMM：世界模型集合

```python
@dataclass
class WorldModelEnsemble:
    """WMM：K 个潜动力学世界模型，对候选轨迹做 H 步想象 rollout。
    只产出软评分与分歧，不做任何放行/拒绝决定。"""
    models: list[nn.Module]        # {f_theta_k}, K=5
    latent_dim: int = 64
    horizon: int = 16
    risk_weight: float = 0.5
    gamma: float = 0.99

    @torch.no_grad()
    def imagine(self, x: Trajectory, z0: Tensor) -> tuple[Tensor, Tensor]:
        """单条候选：返回每个模型的 S_k(x) 与集成分歧 D_epi"""
        per_model = []
        for f in self.models:
            z = z0
            utility, risk = 0.0, 0.0
            for t in range(self.horizon):
                z, r_hat, c_hat = f.step(z, x.action[t])
                utility += (self.gamma ** t) * r_hat
                risk = torch.maximum(risk, c_hat)   # 预测约束违反概率
            per_model.append(utility - self.risk_weight * risk)
        scores = torch.stack(per_model)             # [K]
        return scores, scores.var(unbiased=False)

    @torch.no_grad()
    def imagine_batch(self, survivors: list[Trajectory], z0: Tensor) -> tuple[Tensor, Tensor]:
        """批量想象：返回 S̄ [N] 与 D_epi [N]"""
        scores, dis = [], []
        for x in survivors:
            s, d = self.imagine(x, z0)
            scores.append(s.mean())
            dis.append(d)
        return torch.stack(scores), torch.stack(dis)
```

### IP-506 LBR：排行榜排序器

```python
@dataclass
class LeaderboardRanker:
    """LBR：在硬门后的幸存集内做相对排序；只置换，不放行。"""
    beta: float = 0.5
    elo: dict[str, float] = field(default_factory=dict)
    calibration: RankingCalibration = field(default_factory=RankingCalibration)

    def pairwise(self, si: float, sj: float) -> float:
        return torch.sigmoid(torch.tensor((si - sj) / self.beta)).item()

    def rank(self, scores: Tensor) -> tuple[list[int], float]:
        """Bradley-Terry 排序（N<=8，用两两 Copeland 近似 MLE）"""
        n = len(scores)
        wins = [0.0] * n
        for i in range(n):
            for j in range(i + 1, n):
                p = self.pairwise(scores[i], scores[j])
                wins[i] += p
                wins[j] += 1.0 - p
        order = sorted(range(n), key=lambda i: wins[i], reverse=True)
        delta = (scores[order[0]] - scores[order[1]]).item() if n > 1 else float('inf')
        return order, delta

    def update_elo(self, winner: Trajectory, losers: list[Trajectory], k: float = 16.0):
        """真实执行后回写终身排行榜（archetype 级）"""
        for y in losers:
            p = self.pairwise(self.elo.get(winner.archetype, 1000.0),
                              self.elo.get(y.archetype, 1000.0))
            self.elo[winner.archetype] = self.elo.get(winner.archetype, 1000.0) + k * (1.0 - p)
            self.elo[y.archetype] = self.elo.get(y.archetype, 1000.0) - k * (1.0 - p)
```

### IP-507 GIR：Goodhart 诚信雷达

```python
@dataclass
class GoodhartIntegrityRadar:
    """GIR：判断排行榜是否可信；不可信时只触发回退，不改变执行集。"""
    alpha: tuple[float, float, float, float] = (0.3, 0.2, 0.3, 0.2)
    d_epi_scale: float = 0.5

    def assess(self, survivors, per_model_scores: Tensor, ood: Tensor,
               calibration: RankingCalibration) -> float:
        # 1. 留一模型排序稳定性
        full = self._rank(per_model_scores.mean(dim=0))
        taus = []
        for k in range(per_model_scores.shape[0]):
            mask = torch.arange(per_model_scores.shape[0]) != k
            loo = per_model_scores[mask].mean(dim=0)
            taus.append(kendall_tau(full, self._rank(loo)))
        tau_k = float(np.mean(taus))
        # 2. 集成分歧 + OOD + 排序校准
        d_epi = float(per_model_scores.var(dim=0, unbiased=False).mean())
        rce = calibration.ranking_calibration_error()
        a1, a2, a3, a4 = self.alpha
        eta = (1.0
               - a1 * min(1.0, d_epi / self.d_epi_scale)
               - a2 * float(ood.mean())
               - a3 * (1.0 - tau_k)
               - a4 * rce)
        return max(0.0, min(1.0, eta))

    @staticmethod
    def _rank(scores: Tensor) -> list[int]:
        return torch.argsort(scores, descending=True).tolist()
```

### IP-508 EFA-v8：门透明排序

```python
@dataclass
class EvidenceForgingAssemblerV8:
    """EFA-v8：七硬门完全不变；排行榜只在幸存集内重排，不放行。"""
    v7: EvidenceForgingAssemblerV7
    wmm: WorldModelEnsemble
    lbr: LeaderboardRanker
    gir: GoodhartIntegrityRadar
    tau_rank: float = 0.6
    eps_w: float = 0.15
    rank_cache: RankCache = field(default_factory=RankCache)

    def select(self, L, t_now, context) -> tuple[bool, Trajectory | None, str, dict]:
        # 1. v7 只读导出「硬门后幸存集」与 v7 排序（七硬门逻辑零改动）
        ok, survivors, order_v7, meta = self.v7.select_survivors(L, t_now, context)
        if not ok or not survivors:
            return False, None, 'V7_REJECT', {}
        if len(survivors) == 1:
            return True, survivors[0], 'SINGLETON', {}

        # 2. 慢环排行榜缓存；过期则用 v7 排序兜底
        cache = self.rank_cache.get(context.scene_key, t_now)
        if cache is None:
            return True, order_v7[0], 'V7_DEFERRED_STALE', {'T': 0.0, 'eta_wml': 1.0}

        # 3. 门透明选择：两条分支都只从 survivors 里选
        if cache.T >= self.tau_rank:
            best = survivors[int(torch.argmax(cache.scores))]
            tag = 'FORGED_CGE_V8_RANKED'
        else:
            best = order_v7[0]
            tag = 'V7_DEFERRED_LOW_TRUST'

        # 4. 收紧因子：η_wml ≥ 1，只可能收紧阈值，绝不放松
        phi = max(0.0, (cache.T - self.tau_rank) / (1.0 - self.tau_rank))
        eta_wml = 1.0 + self.eps_w * phi
        return True, best, tag, {'T': cache.T, 'eta_wml': eta_wml, 'rank': cache.order}

    def slow_rank(self, survivors, z0, context, t_now) -> float:
        """慢环（10–20 Hz）：世界模型预演 + 排行榜 + 诚信雷达"""
        scores, dis = self.wmm.imagine_batch(survivors, z0)
        order, delta = self.lbr.rank(scores)
        eta_rank = 1.0 - math.exp(-delta / self.lbr.beta) if len(survivors) > 1 else 1.0
        per_model = self._per_model_scores(survivors, z0)
        ood = self._ood_scores(survivors, z0)
        eta_integrity = self.gir.assess(survivors, per_model, ood, self.lbr.calibration)
        T = eta_rank * eta_integrity
        self.rank_cache.put(context.scene_key, scores, order, T, t_now)
        return T

    def on_executed(self, winner, survivors, realized_ok, realized_scores):
        """执行后异步回写：终身 Elo + 排序校准"""
        self.lbr.update_elo(winner, [x for x in survivors if x is not winner])
        self.lbr.calibration.update(winner, survivors, realized_scores)
```

## 4. 正确性论证（增量更新）

### 定理 13（门透明保守性）

**陈述**：设 S_v7 为 v7 七硬门后的幸存集，v8 的选择域恒为 S_v7，且 η_wml ∈ [1, 1+ε_w]。则 Exec_CADVS-v8 ⊆ Exec_CADVS-v7。

**证明**：v8 不修改任何硬门判定，故幸存集 S_v8 = S_v7。排行榜 argmax 与 v7 margin 都是 S_v7 上的全序，二者选出的轨迹均 ∈ S_v7。η_wml ≥ 1 ⇒ τ_i^v8 ≥ τ_i^v7，软阈值只可能单调升、执行集只可能收缩。缓存过期或 T < τ_rank 时直接返回 v7 的 argmax。综上，v8 不可能放行任何 v7 未放行的轨迹。

### 定理 14（排序遗憾界）

**陈述**：设真实评分 s(x)，估计评分 ŝ(x) 满足 ||ŝ - s||_∞ ≤ ε（x ∈ S）。令 x* = argmax s，x̂ = argmax ŝ。若真实头名优势 Δ* = s_(1) - s_(2) > 2ε，则 x̂ = x*；否则遗憾 s(x*) - s(x̂) ≤ 2ε。

**证明**：由 |ŝ(x)-s(x)| ≤ ε，有 ŝ(x̂) ≥ ŝ(x*) ≥ s(x*) - ε，进而 s(x̂) ≥ ŝ(x̂) - ε ≥ s(x*) - 2ε。若 Δ* > 2ε，则对任意 x ≠ x* 有 ŝ(x*) > ŝ(x)，故 argmax 唯一为 x*。将 RCE 经单调 link 的逆映射到 ε，即得「排序校准误差越小，遗憾上界越紧」的推论。

### 定理 15（低信任回退等价性）

**陈述**：若 T < τ_rank 或缓存过期，v8 在当步返回的轨迹与 v7 完全相同，且 η_wml = 1。

**证明**：T < τ_rank ⇒ φ(T)=0 ⇒ η_wml=1；选择分支直接取 order_v7[0]。缓存过期分支同样取 order_v7[0]。因此该步行为与 v7 逐位一致，不引入任何新风险。

### 诚实声明

- **世界模型长时域复合误差**：H 步 rollout 的误差随 H 增长，H=16 时预测风险可能显著偏离真实；集成方差只能捕捉模型间差异，无法捕捉「所有模型共享的偏差」。
- **排行榜 Goodhart**：相对排名天然诱导刷榜；Elo 存在「富者愈富」与曝光偏差，冷启动 archetype 可能长期被低估。
- **校准反馈稀疏且延迟**：真实结果只在执行后获得，跨 H 步的信用分配困难，RCE 的在线估计可能滞后于分布漂移。
- **排行榜不提供安全保证**：它只做相对排序；真正的安全边界仍完全由 v7 七硬门承担，世界模型表征之外的危险无法被排行榜发现。
- **缓存陈旧**：慢环与快环之间存在最长 100 ms 的场景变化窗口，快速动态场景下排行榜可能对已失效的幸存集排序。

## 7. 本轮最大风险（最终确认）

**一句话**：**排行榜-世界模型共谋（Goodhart 塌缩）**：当提议器、世界模型与排行榜共享同一训练分布时，三者可能共同收敛到一个「高分但物理上错误」的共识，集成分歧与排序稳定性都无法识别这种共谋式盲区，而相对排名会让错误显得异常自信。
