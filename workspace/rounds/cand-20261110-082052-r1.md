# 第 43 轮（新循环第 3 轮） · Causal-Agent 证书飞轮：把「相关性迁移」换成「可运输的因果机制」，让智能体主动设计证据（四层架构 v8）

> 承接第 42 轮 v19（SCV × CKB × ECR）。第 42 轮自陈最大风险是「仿真偏差累积」与「检索幻觉」导致证书**静默失效**——本质都是拿**相关性**（Wasserstein 距离、嵌入相似度）去外推**因果性**（“阈值搬过去实机也安全”）。本轮灵感词「因果推理」「智能体」精准击中这一点：**因果推理**把 Sim-to-Real 从「分布像不像」升级为「结构机制是否可**识别、可运输**（identifiability / transportability）」——用 SCM + do-calculus + 选择图 + 不变因果预测区分真因果与环境相关，并显式检测未观测混杂，不可识别时**拒绝签发**而非“再保守一点”；**智能体**把第 42 轮“铺参数空间的被动域随机化”升级为“**主动设计证伪实验**”——维护对 SCM 的信念分布，选最能区分「证书成立/被证伪」的 do-干预，仿真里自由干预、实机只落在已验证安全集内，失败时用反事实归因定位是哪条机制变了。二者互锁：因果推断给智能体可证伪的假设空间，智能体主动获取干预数据消除识别歧义。但必须防一个反噬——优化“求证”目标本身会诱发**奖励黑客**（在仿真里专挑自洽证据），故引入智能体自证 + 认识论护栏 + 留出实机干预审计，识别不足时**主动弃权**。

## 0. 直觉与动机

**灵感 1（因果推理 → 从「分布距离」到「机制运输」）**：第 42 轮用 `W_1(D_real, D_sim) ≤ ε_w` 推 `m_real ≥ m_sim − L_m·ε_w`。这个界的致命假设是“分布足够近”，而仿真与实机**永远不会足够近**（接触摩擦、柔性、传感器老化都是长尾）。因果视角的直觉是：仿真与实机共享的是**结构机制**——“接触力如何经雅可比传到横向边际”“延迟如何经闭环增益放大到超调”——而不是边缘分布。分布变了，机制往往不变。于是正确问题变成：把 `m` 对动作 `A`、状态 `X` 的**因果效应**从源域（仿真+少量实机）**运输**到目标域，需要什么假设？答：do-calculus 的选择图可识别性 + 不变机制集。ICP 的直觉：把所有环境切分成多个“域”，只保留**跨域预测残差方差最小**的父节点集作为因果父集；用变域（variant）机制外推是幻觉，用不变（invariant）机制外推才 sound。这把第 42 轮的 `α_e` 从“经验拟合的魔数”变成“由可识别性决定、可为 `UNIDENTIFIED` 的结构量”。

**灵感 2（智能体 → 从「被动采样」到「主动证伪」）**：第 42 轮的域随机化是“均匀铺参数空间”，昂贵且不针对证书薄弱面。智能体直觉：把证书验证当成**贝叶斯实验设计**问题。信念 `b(SCM)` 是对因果结构的后验；每个候选实验 `e`（在仿真里 do 某变量、或采一小段实机标定）的价值 = 期望信息增益（关于“证书是否 sound”的熵减）/ 成本 / 风险。智能体会自动发现“该去推摩擦还是该去测延迟”——因为只有那些**能翻转证书结论**的实验才有高信息量。更进一步，它是**反事实推理者**：失败发生后做 abduction（由观测反推外生噪声 `u`）、action（假设某机制回到标称）、prediction，得到“若无此机制变化是否会失败”的反事实边际，从而把归因从相关性的“时间切片打标签”升级为结构性的“锁定结构方程”。

**灵感 3（自证与弃权 → 智能体本身要被证书约束）**：智能体越强，越可能**奖励黑客**：它会被激励去找“让当前模型自洽”的实验，而不是“挑战模型”的实验。因此本轮把第 42 轮的“人确认草案”升级为**智能体自证契约**：部署前必须同时满足 (i) 因果效应可识别；(ii) 对 soundness 的后验置信 ≥ 1−δ_epi；(iii) 留出实机干预与仿真机制一致性未超阈值。任一不满足 → `ABSTAIN`（SafeStop 或请求人类），而不是“加个裕度继续跑”。这把第 42 轮的“静默的自信”转成“**显式的、可审计的置信与弃权**”。

**耦合升级**：Causal-Cert-Engine 产出可运输证书与反事实归因 → 主动实验智能体据此设计下一个证伪实验 → 新干预数据回灌信念与 CKB → 自证器在每次签发/热更新前做认识论审计。飞轮由“Sim→RAG→Edge→Sim”升级为 **Causal→Experiment→Audit→Causal** 的**主动求证闭环**。

## 1. 形式化定义（增量：定义 38–44）

**定义 38（证书结构因果模型 SCM）**：`M = ⟨V, U, F, P(U)⟩`，`V = X ∪ A ∪ Θ ∪ {m}`，其中 `X` 状态、`A` 动作、`Θ` 环境/硬件参数、`m` 安全边际；每个 `V_i = f_i(pa_i, u_i)`，`u_i` 独立外生。**因果证书** `C_causal = ⟨M̂, Dom_do, I, β⟩`，`M̂` 学到的结构，`Dom_do` 允许干预域，`I` 不变机制集，`β` 由 `I` 导出的运输界。**直觉**：证书不再是“一个阈值”，而是“一张结构与一组不变机制 + 它们的运输误差”。

**定义 39（证书可运输性）**：给定源域 `π*`、目标域 `π`，选择图 `G` 在 `S` 处有选择节点（populate `S`：域差异发生的变量）。若 `m` 对 `do(a)` 的效应在 `G` 中**可识别**（无 `S` 遮挡的 backdoor/frontdoor 路径不可控），则 `P_π(m | do(a), x) = Σ_{z} P_{π*}(m | do(a), x, z)·P_π(z | x)`（transport formula）。**运输界**：`m_π(x) ≥ m_{π*}(x) − β`，`β = Σ_{φ∈I} err(φ) + L_m·δ_var`，其中 `δ_var` 是 variant 机制在目标域的**可观测**偏移（不是全 `W_1`）。若不可识别 → 输出 `UNIDENTIFIED`，证书**不签发**。

**定义 40（不变机制集与 ICP 证书）**：对域族 `E = {e_1..e_K}`（随机种子、实机场次、硬件批次），机制 `f_i` 若在 `E` 上条件分布 `P(m | pa_i, e)` 稳定（残差方差跨域上界 ≤ σ_inv）则 `f_i ∈ I`。**ICP 证书**：只用 `I` 中机制的父集构造 `m̂`；`m̂` 在任意与 `E` 同分布的偏移下 sound（在 `I` 完备且无混杂假设下）。非不变机制只用于**预警**，绝不用来外推。

**定义 41（反事实根因证书）**：给定观测轨迹 `ξ` 与失败事件 `F`：(1) **abduction** 反推 `u = M̂.abduct(ξ)`；(2) **action** 对机制 `f_j` 施加 `do(f_j = f_j^nom)`；(3) **prediction** 得反事实边际 `m_{cf}^{(j)}`。**归因分数** `blame(j) = m(ξ) − m_{cf}^{(j)}`；`j* = argmax_j blame(j)`。**结构化归因**：`blame` 直接指向结构方程，而非时间窗标签，可作为 CKB 的可执行反例。

**定义 42（因果实验智能体 CEA）**：约束 POMDP `⟨B, E, O, T, R, C, H⟩`，信念 `b ∈ B` 为 SCM 后验；动作空间 `E = E_sim ∪ E_real ∪ {abstain, deploy}`；奖励 `R = EIG(证书结论 | e) − λ_c·cost(e)`；**安全约束** `H`：`e ∈ E_real` 必须落在已验证安全集 `Safe_verified`（shield）。策略 `π*(b) = argmax_E R s.t. H`。**停止准则**：当 `EIG_max < ε_info` 或预算耗尽。

**定义 43（智能体自证契约 / 认识论护栏）**：部署动作 `deploy` 允许当且仅当 `(i) Identified(C_causal); (ii) b(sound) ≥ 1−δ_epi; (iii) MechDiv(π_sim, π_real^heldout) ≤ τ_audit` 同时成立，否则 `abstain` 并报原因。`b(sound)` 由智能体的联合后验给出，`τ_audit` 是**留出实机干预**与仿真机制的一致性阈值。

**定义 44（因果接口与组合）**：模块 `C1, C2` 经接口变量集 `I_12` 组合 sound，当且仅当在 `I_12` 上 `d-separated(C1.SCM, C2.SCM)` 且无对 `I_12` 的**未观测共同原因**（`C1 ⊥ C2 | I_12` 成立）。否则组合返回 `LATENT_CONFOUNDING_AT_INTERFACE`，拒绝拼装。这把第 42 轮“接口契约检查”升级为“**因果可分离性检验**”。

## 2. 产出设计（新增 IP-57/58/59 + 升级 IP-54/55/56/51/50/47/45）

### 2.1 IP-57 CAUSAL-CERT-ENGINE（因果证书引擎 CCE）
1. **多域结构学习**：对 `E` 个域联合做因果发现（GES/NoTears + 物理先验：接触图、运动学连边作白名单），得到 `G` 与选择节点 `S`。
2. **不变机制分解**：对每个节点的父集做跨域不变性检验（ICP / 环境残差方差）；输出 `I` 与 `V\I`。
3. **运输界计算**：对每条 CAR 边 `e`，按 transport formula 计算 `β_e`；不可识别边打 `UNIDENTIFIED` 并禁止签发，而不是回落经验 `α_e`。
4. **反事实归因器**：abduction–action–prediction 三段式，输出 `blame` 分布与 `j*`，反例含 `(SCM 版本, u, do-干预, blame)` 入 CKB。

### 2.2 IP-58 CAUSAL-EXPERIMENT-AGENT（因果实验智能体 CEA）
1. **信念维护**：SCM 后验用粒子集/结构 MCMC 表示；每次干预数据后做贝叶斯更新。
2. **实验提议器**：候选 = 能翻转至少一条边证书结论的 do-干预；用“证书敏感度 × 结构不确定度”排序。
3. **信息-成本-风险三元决策**：`EIG/cost` 贪心 + beam search；实机动作先过 shield（`Safe_verified` 白名单 + 单调保守回退）。
4. **主动弃权**：达到停止准则或触发认识论护栏即 `abstain`，把不确定性交还人类，绝不“加裕度硬上”。

### 2.3 IP-59 AGENT-SELF-CERTIFIER（智能体自证器 ASC）
1. **三重闸门**：`Identified ∧ b(sound)≥1−δ_epi ∧ MechDiv≤τ_audit`，否则 `ABSTAIN`。
2. **反奖励黑客审计**：留出**实机干预集**（智能体不可见、不可用于训练/信念更新）定期测机制一致性；若仿真机制与实机机制背离超阈值，判定“智能体在自洽幻觉中”，熔断。
3. **审计轨迹**：每次 deploy/abstain 记录 (SCM 版本, 证据集, EIG, 弃权原因) 到总线，供 RCA 与认证回溯。
4. **证书版本语义**：签发证书携带 `(可运输域 Dom_do, I, β, 置信下界)`；超域即自动失效并降级。

## 4. 实验设计（E87–E94 硬门槛，承接 E79–E86）

回退：E87 运输界不成立 → 判定“目标域不可识别”，回退到 SafeStop 双态并扩大实机标定；E88 `I` 不稳 → 关闭因果外推，退回第 42 轮保守 `α_e`；E90/E91 智能体不安全或低效 → 关闭主动实验，退回固定域随机化；E92 自证器失效 → 关闭自动签发，全人工确认；E93 接口检出失效 → 禁止组合，只跑单技能。

## 5. 本轮最大风险

**一句话**：因果智能体可能“科学地说服自己”——若存在**未观测混杂**或它对“求证”目标做了错误设定，它会**主动去搜集支持自身模型的证据**（把确认偏误形式化为实验设计），产出内部更自洽、外部更错误的证书；因此 E91（留出实机干预审计）与 E92（自证器校准）是红线，且留出审计集必须对智能体**不可见**，否则整个因果飞轮只是把第 42 轮的静默失效换成了更擅长自我辩护的版本。

## 2. 关键算法（伪代码）

### IP-57 CCE：因果证书学习、运输与反事实归因
```
def learn_causal_certificate_model(trajs_sim, trajs_real, domains):
    # 1. 结构学习：多域联合 + 物理先验白名单（接触图/运动学连边）
    G = joint_causal_discovery(trajs_sim + trajs_real, domains,
                               whitelist=physics_edges())
    # 2. 机制分解：跨域不变性检验（ICP / 环境残差方差）
    I = set()
    for node in G.nodes:
        if residual_variance_across(domains, node) <= sigma_inv:
            I.add(node)
    # 3. 选择图：标注域差异发生位置
    S = selection_nodes(trajs_sim, trajs_real)
    return SCM(G, invariant=I, selection=S)

def transportable_margin_bound(scm, x, a, theta_sim, target='real'):
    # do-calculus：P_target(m | do(a), x) 用 transport formula
    if not is_transportable(scm, source='sim', target=target):
        return None, 'UNIDENTIFIED'          # 触发 ASC 弃权，禁止签发
    m_hat = interventional_mean(scm, m, do={A: a, X: x})
    # 只用不变机制传播误差；variant 机制只报警，不外推
    beta = sum(err(mech) for mech in scm.invariant) \
           + scm.L_m * scm.observed_variant_shift(target)
    return m_hat - beta, 'IDENTIFIED'

def counterfactual_attribution(scm, traj, failure_event):
    # abduction：由观测反推外生噪声 u
    u = scm.abduct(traj.obs)
    # action + prediction：逐个假设机制回到标称
    blame = {}
    for node in scm.variant_nodes:           # 只在非不变机制上找根因
        cf = scm.predict(m, u, intervention={node: scm.nominal[node]})
        blame[node] = failure_event.margin - cf.margin
    j_star = argmax(blame)
    return {'root_cause': j_star, 'blame': blame, 'u': u,
            'scm_version': scm.version}
```

### IP-58 CEA：主动证伪实验设计
```
def causal_experiment_agent(belief, budget_sim, budget_real, cert):
    # 约束 POMDP：动作 = sim_intervention | real_calibration | abstain | deploy
    while budget_sim > 0 or budget_real > 0:
        cands = propose_interventions(belief.scm, cert, target='falsify')
        best, best_score = None, -inf
        for e in cands:
            e.eig  = expected_information_gain(belief, e, about='cert_sound')
            e.cost = cost_model(e, budget_sim, budget_real)
            e.risk = shield_risk(e)          # 实机动作必须落在 Safe_verified
            if e.risk >= INF or e.cost > budget_remaining(e):
                continue
            score = e.eig / max(e.cost, EPS)
            if score > best_score:
                best, best_score = e, score
        if best is None or best.eig < EPS_INFO:   # 停止准则：无高信息实验
            break
        obs = execute(best)                       # sim: do(x)；real: 有界标定
        belief = bayes_update(belief, best, obs)
        if belief.p_sound(cert) < 1 - delta_epi:
            cert = refine_or_abstain(cert, belief)
    return cert, belief

def shield_risk(experiment):
    # 仿真实验不设限；实机实验必须在已验证安全集内
    if experiment.on_real and not in_verified_safe_set(experiment):
        return INF
    return 0.0
```

### IP-59 ASC：智能体自证与反奖励黑客审计
```
def self_certify(belief, cert, runtime):
    # 三重闸门：可识别 ∧ 后验置信 ∧ 机制一致性
    if cert.status == 'UNIDENTIFIED':
        return ABSTAIN('unidentified_causal_effect')
    if belief.p_sound(cert) < 1 - delta_epi:
        return ABSTAIN('insufficient_epistemic_confidence')
    if mechanism_divergence(runtime.sim, runtime.heldout_real) > tau_audit:
        return ABSTAIN('sim_real_mechanism_mismatch')  # 疑似自洽幻觉
    return DEPLOY(cert)

def audit_heldout_discipline(agent, heldout_real):
    # 留出实机干预集对智能体不可见：不参与训练/信念更新/实验提议
    assert heldout_real not in agent.visible_data
    return mechanism_divergence(agent.scm, heldout_real)
```

### IP-47 升级：因果接口组合
```
def compose_causal_certificates(C1, C2, interface_vars):
    # 接口上必须无未观测共同原因，否则组合不可运输
    if not d_separated(C1.scm, C2.scm, interface_vars):
        return None, 'LATENT_CONFOUNDING_AT_INTERFACE'
    combined = product_scm(C1.scm, C2.scm)
    beta = propagate_transport_bound(combined, C1.beta, C2.beta)
    return Certificate(scm=combined, beta=beta, invariant=I1 ∪ I2), 'OK'
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性保证 |
|---|---|---|---|
| IP-57 多域因果发现 | O(d^3·K)（GES/NoTears，d=变量数，K=域数） | 结构+样本 O(K·N) | 忠实性+充分性假设下骨架可识别；白名单降低搜索空间 |
| IP-57 不变机制分解 | O(K·N·|E|) | O(K·N) | ICP：不变父集在任意与 E 同分布偏移下预测稳定 |
| IP-57 运输界 | O(|E|·d) | O(1) | transport formula 可识别 ⟹ `m_target ≥ m_sim − β` sound；不可识别则拒绝签发 |
| IP-57 反事实归因 | O(d·T)（每个 variant 机制一次前向） | O(d) | 在 SCM 正确且无混杂假设下反事实可计算 |
| IP-58 实验提议 | O(|cand|·(d + EIG估计)) | 信念粒子 O(P·d) | EIG 用后验熵差近似；贪心保证 1−1/e 近似（子模时） |

| IP-59 留出审计 | O(N_heldout) 离线 | O(N_heldout) | 留出集不可见 ⟹ 审计不受智能体优化偏差污染 |

| IP-47 因果组合 | O(d^2) 分离检验 | O(d^2) | `C1⊥C2|I` ⟹ 组合机制可运输；否则拒绝 |

## 6. 本轮最大风险

**一句话**：因果智能体可能“科学地说服自己”——若存在未观测混杂或它对“求证”目标做了错误设定，它会主动搜集支持自身模型的证据（把确认偏误形式化为实验设计），产出内部更自洽、外部更错误的证书；因此 E91（留出实机干预审计）与 E92（自证器校准）是红线，且留出审计集必须对智能体不可见，否则整个因果飞轮只是把第 42 轮的静默失效换成了更擅长自我辩护的版本。
